数位 DP ​

把 $[0,n]$ 的计数写成沿十进制位的自动机 DP：是否贴上界、是否前导零、以及题目要的模或数字特征。

—— 据数字位 DP 的标准教材技法；自动机计数对照[KMP](/cs/kmp) 整理

上一课树形 DP沿树边。本课对象是整数的十进制（或 \(b\) 进制）写法。缺口是数位 DP：dfs(pos, tight, lead, state) 记忆化。不重写树合并。后课单调队列优化换转移形状。

问题 ​

计 \([l,r]\) 中满足性质的个数 \(=F(r)-F(l-1)\)。\(F(n)\)：从高位填，tight 表示是否等于 \(n\) 的前缀；lead 前导零；state 为模、是否出现 49、与模式串匹配等。位数 \(O(\log n)\)，状态乘 tight/lead 仍小。

术语翻译：tight（贴界）表示「目前填的数字与 \(n\) 的前缀一模一样」。某一位一旦取了比 \(n\) 更小的数字，后面爱填啥填啥，tight 永久解除；取相等则继续贴着。每个数只沿一条贴界链被数到，这正是枚举不重不漏的原因。

缺口是这台自动机，不是 Lucas 模 \(p\) 组合数（那是另一计数）。

前导零不是装饰 ​

「含数字 0 的个数」对前导零敏感。lead 要把未真正开始的位数排除。不要漏。

常见误区：数「含 0 的数」时忘了前导零——若把 \(5\) 当成 \(00005\) 来逐位填，会凭空数出 4 个 0。lead 状态就是把「还没真正开始的位」排除在外：纸上补的位数不算数，不参与性质统计。

数位 DP 是竞赛标准。与自动机：KMP 失败函数可做 state。后课单调队列优化数值 DP 转移，不是位数。

方法 ​

拆位数组。记忆化。进制 \(b\) 同构。区间减。性质用 state 压缩。

无上界（无穷）不适合本模板。

数字实例：要数 \([1,10^9]\) 里含 49 的数，不是枚举十亿个数，而是算 \(F(10^9)\)——只有 10 个数位、每位 0..9，加上 tight/lead 两个开关，状态总共不到几万个，瞬间完成；\([l,r]\) 的答案是 \(F(r)-F(l-1)\) 这样两次计算相减。

机制 ​

贴界时下一数字上限为 \(n\) 的该位，否则 \(0..b-1\)。与生成函数：数位 DP 是有限自动机接受的整数计数。与状压：掩码可做 state（出现过的数字集合）。

上面那张图画「整个模板四件套怎么串」；这张放大到单独一位：tight 为真时这一位怎么分叉，分叉之后各自的处境差在哪。

边界 ​

本课不写 \(n\) 为 \(10^{10^6}\) 的大数位（要矩阵或自动机最短路）。后课默认：\([l,r]\) 数字性质用数位 DP。下一课单调队列优化。

小结 ​

  • \(F(r)-F(l-1)\)；沿位、贴界、前导零。
  • state 编码性质或自动机。
  • 位数对数，状态要小。
  • 出处：数位 DP 标准技法；自动机见 Knuth–Morris–Pratt 思想。
