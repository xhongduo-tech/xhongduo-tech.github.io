换根 DP ​

先定根做一次树形 DP，再第二次 DFS 把「来自父亲的贡献」推到每个点，使每个顶点当根的答案 $O(n)$ 齐。

—— 据树形 DP 二次扫描的标准技法；[树形 DP](/cs/tree-dp) 整理

上一课插头 DP在网格轮廓。树上一问「每个点当根时的最优/距离和」，朴素 \(n\) 次树 DP 是 \(O(n^2)\)。缺口是换根（rerooting）：一次下、一次上。不重写后序独立集。后课 LIS/LCS 换序列。

问题 ​

例：每个点到其它点的距离和。先以 \(1\) 为根算子树大小与子树内距离和；换到孩子 \(v\) 时，用 \(n-2\cdot sz[v]\) 一类公式改距离和。一般：up[v] 表示除 \(v\) 子树外的信息，由父亲的 up 与兄弟合并。

缺口是第二次 DFS，不是点分治点对。

合并要可减或可补 ​

若孩子贡献不能从总和里拆出（不可逆运算），换根要维护「去掉一个孩子」的结构，可能多 \(\log\)。可结合、可删才 \(O(n)\)。

二次扫描是树 DP 标准。与点分治：换根给每个点当根的全局量；点分治给路径计数。后课 LIS 离开树。

方法 ​

第一遍后序 down[u]。第二遍先序：用 down 与 up[u] 拼 ans[u]，再算每个孩子的 up[v]。兄弟前缀/后缀和便于 \(O(deg)\) 合计仍 \(O(n)\)。

数字实例：链 1—2—3 共 3 点，以 1 为根算出 \(down\)。换根到 2 时，距离和由 \(\sum dist(v,1)\) 平移：减去 2 号子树一侧的每个点到 1 的距离（少走边 1-2），加上另一侧每个点到 1 的距离（多走同一条边）。对 \(sz\) 相减就是 \(n-2\cdot sz[v]\) 一类公式的来历。

常见误区：初学者容易直接把 ans[u] 当成最终答案忘了方向——第一次 DFS 算的只是「以 1 为根」的子树内贡献，来自父亲的另一半必须由第二次 DFS 的 up 补齐；只交一遍扫描的结果，等于只算了「往下的亲戚」，漏了「往上的亲戚」。

换根公式先在纸上对一条边 \((u,v)\) 写清。

机制 ​

树去边成两棵，信息在边上重接。与 HLD：HLD 管路径查询数据结构；换根是一次性全体根。与重心：重心是结构点，换根是答案平移。

这张图回答的问题是「根从 \(u\) 移到相邻的 \(v\)，答案为什么能 \(O(1)\) 平移」：删边把树劈成两半，移动只改变跨越边 \(u\text{-}v\) 的路径长度——小半边各少 1、大半边各多 1，于是新答案 = 旧答案加一个只含 \(n\) 与 \(sz[v]\) 的修正项。

直觉类比：换根像全班换座位后重算「每人到所有人的平均步数」——不必重新走一遍校园，只需知道「搬近的人」和「搬远的人」各多少个，把总步数做一次加减修正。rerooting 的全部技巧就是把这次修正的账算对。

边界 ​

本课不写带修改换根。有环先缩点。后课默认：全体根上的树 DP 用二次 DFS。下一课 LIS 与 LCS。

小结 ​

  • 下 DP + 上推父亲贡献 = 全体根 \(O(n)\)。
  • 合并须能拆开一个孩子。
  • 不是 \(n\) 次独立树 DP。
  • 出处：树形 DP 二次扫描标准技法。
