## 为什么从简谐运动的回复力和能量开始

前面两节我们从「运动学」角度描述了简谐运动——位移按正弦变化。但一个振动为什么能「自己往复不停」？两种力量在起作用：**回复力**把物体拉回平衡位置，**能量**让它在动能与势能之间不断转化。从「力」与「能」这两个动力学视角再看简谐运动，你会看清它「为什么动、为什么不停」。

这一节的核心内容是：**回复力的来源（怎么判断一个系统是否做简谐运动）** 与 **能量的转化（动能、势能如何此消彼长、总量守恒）**。两者合起来，回答「简谐运动之所以是简谐运动」的根本原因——也正是这些分析，让单摆（下一节）这类「看似不是弹簧」的系统能被识别为简谐运动。<span class="marginnote">判断「是不是简谐运动」的通用方法，是本节最重要的技能：<strong>找平衡位置 → 分析该处附近的合力 → 看能否写成 $F = -kx$</strong>。弹簧振子直接满足，单摆小角度近似满足，浮在水面的木块、磁场中的粒子也各自有自己的「$k$」。学会了「凑成 $F = -kx$」这一招，任何周期系统你都能判断它是不是简谐运动、并求出它的等效周期。</span>

学这一节，请带着两个问题：**回复力从哪来？能量怎么转？** 前者的答案会给你「判断简谐运动」的通用工具，后者的答案会给你「能量视角下的振动图像」。

## 1 回复力：简谐运动的动力学特征

**回复力（restoring force）**：使振动物体回到平衡位置的力。

简谐运动的回复力满足：

$$F = -kx$$

即**回复力与位移成正比、方向相反**。这个「$F = -kx$」是简谐运动的**定义性特征**，也是判断的黄金标准。

**回复力的来源随系统不同而不同**：

- **水平弹簧振子**：回复力 = 弹簧弹力。
- **竖直弹簧振子**：回复力 = 弹力与重力的合力（不是单纯弹力！）。<span class="marginnote">竖直弹簧振子的回复力是「弹力 + 重力」的合力：设平衡时弹簧伸长 $x_0 = mg/k$，物体在平衡位置下方 $x$ 处，弹力 $k(x_0+x)$ 向上、重力 $mg$ 向下，合力 $F = k(x_0+x) - mg = kx$——恰好又是 $F = kx$（指向平衡位置）！<strong>重力与平衡时的弹力相互抵消，只留下「偏离平衡位置的部分」作回复力</strong>。所以竖直振子与水平振子动力学完全相同，只是平衡位置下移了。这个「抵消恒力、只留偏离量」的技巧在振动分析里反复使用。</span>
- **单摆（小角度）**：回复力 = 重力沿圆弧切线方向的分量，近似 $F = -\dfrac{mg}{L}x$。
- **浮在水面的木块**：回复力 = 浮力与重力的合力（偏离平衡位置时浮力改变）。

**辨析｜易错点：** 回复力不一定是「某一个力」，可以是**合力**（竖直弹簧是弹力+重力）、可以是**分力**（单摆是重力沿切线的分力）、可以是**摩擦力**。只要「指向平衡位置、与位移成正比」就是回复力。把回复力等同于「弹力」是常见的狭义理解。

## 2 如何判断一个运动是简谐运动

判断流程（万能三步）：

1. **找平衡位置**：合力为零的位置。
2. **设微小偏离**：把物体推离平衡位置一小段距离 $x$，分析受力。
3. **写合力表达式**：看合力是否满足 $F = -kx$（与偏离量成正比、指向平衡位置）。

**举例——单摆小角度**：设摆长 $L$、摆角 $\theta$（小角度），偏离平衡位置（最低点）的弧长 $x = L\theta$。回复力是重力沿切线的分量：

$$F = mg\sin\theta \approx mg\,\theta = mg\frac{x}{L} = \frac{mg}{L}x$$

负号（指向平衡位置）写成 $F = -\dfrac{mg}{L}x$——**满足 $F = -kx$ 形式，其中 $k = mg/L$**！所以小角度单摆是简谐运动，周期 $T = 2\pi\sqrt{\dfrac{m}{k}} = 2\pi\sqrt{\dfrac{L}{g}}$。<span class="marginnote">单摆的例子展示了「判断三步走」的威力：从「重力沿切线的分力」出发，用「小角度近似 $\sin\theta \approx \theta$」把回复力化成与 $x$ 成正比——就把它识别为简谐运动并求出周期 $T = 2\pi\sqrt{L/g}$。注意「小角度」三个字不是客套：角度大时 $\sin\theta \neq \theta$，回复力不再线性，单摆就不再是简谐运动。这个「线性化」技巧在物理里无处不在——平衡位置附近，几乎一切系统都近似线性。</span>

**判断的边界**：只有「回复力与位移成正比」才是简谐运动。回复力与位移不成正比（如大角度单摆、弹簧的平方力）就不是——这类叫「非简谐的周期性运动」。

## 3 简谐运动的能量

简谐运动系统的能量在**动能**与**势能**之间转化：

- **动能**：$E_k = \tfrac{1}{2}mv^2$，平衡位置最大。
- **势能**：$E_p = \tfrac{1}{2}kx^2$（弹簧振子的弹性势能），最大位移处最大。
- **总能量**（无阻尼时守恒）：

$$E = E_k + E_p = \frac{1}{2}kA^2$$

**能量的图像**：振子从最大位移处释放，势能最大、动能最小；回到平衡位置时，动能最大、势能最小；如此反复。总能量恒定，正比于振幅平方。<span class="marginnote">能量守恒是「振幅为什么不变」的答案：无阻尼时总能量 $\tfrac{1}{2}kA^2$ 恒定，所以振幅 $A$ 恒定，振动等幅。一旦有摩擦、空气阻力（阻尼），能量不断损失，振幅不断减小——这就是下一节《受迫振动 共振》里阻尼振动的由来。「振幅衰减」不是振幅的「性质」，而是「能量流失」的外在表现。</span>

**能量公式的推导**：平衡位置 $x = 0$ 处 $E_p = 0$、$v = \omega A$，所以 $E_k = \tfrac{1}{2}m(\omega A)^2 = \tfrac{1}{2}m\dfrac{k}{m}A^2 = \tfrac{1}{2}kA^2$——用 $\omega^2 = k/m$。**总能量 = 平衡位置的最大动能 = 最大位移处的最大势能 = $\tfrac{1}{2}kA^2$**。

## 4 能量与图像：x-t 与能量曲线

**能量随时间的变化**：动能与势能都按 $\sin^2$ 或 $\cos^2$ 变化，频率是振动频率的 2 倍：

- $E_k = \tfrac{1}{2}kA^2\cos^2\omega t$（设位移正弦、速度余弦）。
- $E_p = \tfrac{1}{2}kA^2\sin^2\omega t$。
- 两者之和恒为 $\tfrac{1}{2}kA^2$，但各自以**二倍频** $\omega$ 振荡（每半个振动周期，能量就完成一个「动能→势能」循环）。

**能量与位置的关系**：把 $E_p = \tfrac{1}{2}kx^2$ 画成「势能曲线」，是一条抛物线；$E_k = E - E_p$ 是「总能量减去抛物线」的剩余。振子在势能曲线「井」里来回，动能 = 总能量 − 当前势能。<span class="marginnote">「势能曲线 + 总能量水平线」的图像是理解振动（乃至量子束缚态）的利器：总能量线下的势能「井」就是振子可达的范围（$x \in [-A, A]$），井越深、能量越高，振幅越大。这个「能量井」图像在量子力学里演变成「束缚态」——粒子的能量决定它能到达的空间范围。弹簧振子的抛物线势能井，是量子谐振子（能级 $E_n = (n+\tfrac{1}{2})\hbar\omega$）的经典前身。</span>

**辨析｜易错点：** 动能与势能的振荡频率是**振动频率的 2 倍**（每个周期动能两次最大、势能两次最大），不是同频率。但总能量不变（恒定，频率为零的「常数」）。别把「能量随时间振荡」误读成「总能量在变」——变的是「动能与势能的分配」，总量守恒。

## 5 公式解析：E = ½kA² 与能量的转化

$$E = \frac{1}{2}kA^2 = \frac{1}{2}kx^2 + \frac{1}{2}mv^2$$

拆三步看：

- **第一步，三个表达式的分工**：$\tfrac{1}{2}kA^2$ 是总能量（由振幅与系统参数决定，恒定）；$\tfrac{1}{2}kx^2$ 是势能（随位移变）；$\tfrac{1}{2}mv^2$ 是动能（随速度变）。任意时刻「势能 + 动能 = 总能量」。<span class="marginnote">这三项的关系像一本「能量账」：总能量是「固定存款」$\tfrac{1}{2}kA^2$，任意时刻它被拆成「势能」$\tfrac{1}{2}kx^2$ 与「动能」$\tfrac{1}{2}mv^2$ 两份。位移大时势能占多、动能占少；平衡位置时动能全拿走。这个「总账恒定、分配流转」的结构，与机械能守恒（第八章）一脉相承。</span>
- **第二步，用能量求速度**：由 $E = \tfrac{1}{2}kx^2 + \tfrac{1}{2}mv^2$ 解出任意位置的速度：$v = \pm\omega\sqrt{A^2 - x^2}$（$\omega = \sqrt{k/m}$）。**给定总能量与当前位置，速度就定了**——这正是「能量法求速度」的通用套路，比从 $x = A\sin\omega t$ 微分更直接。
- **第三步，为什么总能量正比 $A^2$**：振幅 $A$ 是「最大位移」，此时动能 $= 0$、势能 $= \tfrac{1}{2}kA^2$，总能量就等于它。**能量与振幅平方成正比**，与「电容储能 $\tfrac{1}{2}CU^2$」「弹簧弹性势能 $\tfrac{1}{2}kx^2$」同为「线性系统储能 $\propto$ 广义坐标平方」。
- **第四步，能量与振幅的物理**：阻尼振动中能量损失 → 振幅衰减；受迫振动中外界持续输入能量 → 维持振幅（下一节）。「能量 ↔ 振幅」的对应让振动的能量语言与运动学语言完全打通。

## 6 辨析｜易错点

- **回复力可以是合力或分力**：不一定是弹力；判断看「$F = -kx$ 形式」。
- **判断简谐运动三步走**：找平衡位置 → 微小偏离分析 → 写合力看是否线性。
- **竖直弹簧振子的回复力是弹力+重力的合力**：重力与平衡弹力抵消，只剩偏离量部分。
- **总能量恒定（无阻尼），动能势能分配流转**：别把「动能势能在变」误当「总能量在变」。
- **动能与势能频率是振动频率的 2 倍**：每周期动能两次最大。
- **能量法求速度**：$v = \pm\omega\sqrt{A^2-x^2}$，知道位置就能求速度大小。

## 7 小结

- **回复力**：$F = -kx$，指向平衡位置、与位移成正比——简谐运动的动力学特征。
- 回复力来源多样：弹簧弹力、弹力+重力、重力切线分量、浮力……判断看形式不看来源。
- **判断三步**：平衡位置 → 微小偏离 → 写合力是否线性。
- **能量**：$E = \tfrac{1}{2}kA^2$ 恒定，势能 $\tfrac{1}{2}kx^2$ 与动能 $\tfrac{1}{2}mv^2$ 此消彼长。
- 能量法求速度：$v = \pm\omega\sqrt{A^2-x^2}$。
- 阻尼 → 能量流失 → 振幅衰减；能量与振幅平方挂钩。

在下一节，我们把「回复力分析」用在最经典的摆上：**单摆**。小角度单摆是简谐运动，周期 $T = 2\pi\sqrt{L/g}$ 只由摆长与重力加速度决定——这是测量 $g$、校准钟表的理论基础。
