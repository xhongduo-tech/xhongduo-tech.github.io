## 为什么从运动学开始

亚里士多德说运动「最难被理解」，是因为他把运动看成一个需要不停解释的谜。伽利略换了个问法：不追问「为什么在动」，只追问「怎么在动」——用什么量描述位置、怎样刻画快慢、位置随时间如何变化。这一换，运动学（kinematics）诞生了：**只描述运动、不过问原因**的学问。

本博客叫「从极限到大模型」。运动学是「极限」二字第一次被正式使用的舞台：瞬时速度是位移对时间的极限，瞬时加速度是速度对时间的极限。而「描述变化」这件事，恰恰也是今天机器学习处理时间序列、语言模型预测下一个 token 的起点——一切「预测未来」的能力，都建立在对「变化规律」的精确刻画上。

本篇把散落在人教版必修第一册 §1–2、必修第二册 §5 的运动学知识收拢成一条线：先立「位置—位移—速度—加速度」的词汇表，再解匀变速直线运动，然后走进抛体与相对运动。这三层正好对应「描述（什么是运动）→ 建模（最简单的变化规律）→ 合成（把直线运动拼成平面运动）」。<span class="marginnote">运动学只回答「是什么样」，动力学才回答「为什么」。这个「先描述、后解释」的顺序是整个物理学的标准流程，也是编程里「先定义数据结构、再写算法」的同构。</span>

## 1 位置、位移、时刻与时间间隔

**质点（particle）**：当物体的大小与形状对所研究的问题没有影响时，可以把它看成一个有质量的点。研究地球绕太阳公转时，地球是质点；研究地球自转时，不是。

**参考系（reference frame）**：描述运动前必须选定一个「静止」的参照物。说「火车开动」是相对地面；说「车顶乘客静止」是相对车厢——**运动是相对的，参考系的选择决定一切结论**。

四个容易混淆的量，是运动学的第一组词汇：

| 量 | 定义 | 特点 |
| --- | --- | --- |
| 位置 | 物体在参考系中的坐标 | 矢量，随时间变化 |
| 位移 | 末位置 − 初位置 | 矢量，只管起点终点，不管路径 |
| 时刻 | 一瞬间 | 对应时间轴上的一个点 |
| 时间间隔 | 两个时刻之差 | 对应时间轴上的一段 |

**位移—时间图像（$x$-$t$ 图）**是运动学第一张「看图」工具：横轴时间、纵轴位置，图线斜率就是速度。匀速直线运动对应倾斜直线（斜率恒定），静止对应水平线（斜率零），图线的弯曲反映速度的变化。读 $x$-$t$ 图只看三样——截距（初位置）、斜率（速度）、斜率变化（加速度）——这是后面 $v$-$t$ 图、频闪照片等一切图像分析的第一步。

**辨析｜易错点：** 位移是「末减初」的矢量差，路程是实际走过的轨迹长度（标量）。绕操场跑一圈回到起点，位移为零、路程 $400\ \text{m}$；竖直上抛再落回手，位移为零、路程很大。「位移 = 0」绝不意味着「没动过」。

## 2 速度与加速度：把变化讲清楚

**速度（velocity）**：位移与时间之比，$v = \dfrac{\Delta x}{\Delta t}$，矢量，描述位置变化的快慢。**平均速度**是一段时间内的快慢，几何上是 $x$-$t$ 图像割线的斜率；**瞬时速度**是 $\Delta t \to 0$ 时平均速度的极限，即 $x$-$t$ 图像切线的斜率：

$$v = \lim_{\Delta t \to 0} \frac{\Delta x}{\Delta t} = \frac{dx}{dt}$$

这一步极限，就是微积分的导数。**速率（speed）**是瞬时速度的大小，标量；**平均速率**是路程 ÷ 时间，它不等于「平均速度的大小」——只有单向直线运动时两者才相等。

**加速度（acceleration）**：速度的变化量与所用时间之比：

$$a = \frac{\Delta v}{\Delta t}$$

**速度—时间图像（$v$-$t$ 图）**：图线斜率是加速度，图线与横轴围成的面积是位移。匀变速直线运动里 $v$-$t$ 图是一条倾斜直线，直线下方的梯形面积恰好等于位移 $x = \dfrac{v_0+v}{2}t$——「面积 = 位移」这个几何解读，是微积分「积分 = 面积」思想在物理里的第二次亮相。

单位 $\text{m/s}^2$。加速度描述「速度变化的快慢」，它**与速度同向则加速、反向则减速、垂直则改变方向**。加速度大不代表速度快——火箭刚点火时加速度极大但速度还很小；巡航客机速度接近音速但加速度接近零。<span class="marginnote">「加速度大 = 速度大」是高中生第一大直觉错误。加速是「速度变化率」，与速度本身是两个独立的量——就像第二级《数学分析》里导数大不等于函数值大一样。</span>

## 3 匀变速直线运动：五条公式一条链

**匀变速直线运动**：加速度恒定（大小、方向都不变）的直线运动。它是最简单的变速运动，五条公式互相贯通：

$$v = v_0 + at, \qquad x = v_0 t + \tfrac{1}{2} a t^2, \qquad v^2 - v_0^2 = 2ax$$

$$x = \frac{v_0 + v}{2}\, t, \qquad \Delta x = aT^2$$

最后一条 $\Delta x = aT^2$ 是**相等时间间隔内位移差恒定**，它是打点计时器纸带、频闪照片判断匀变速运动、反推加速度的钥匙。

**例（刹车问题）**：汽车以 $v_0 = 20\ \text{m/s}$ 刹车，加速度 $a = -5\ \text{m/s}^2$，问刹车后 $5\ \text{s}$ 内位移多大？若直接代入 $x = v_0t + \tfrac{1}{2}at^2$ 得 $x = 20 \times 5 - \tfrac{1}{2}\times 5 \times 25 = 37.5\ \text{m}$，答案是错的——车在第 $4\ \text{s}$ 末已停下（$v = 20 - 5 \times 4 = 0$）。正确做法：先算停下时间 $t = 4\ \text{s}$，再求 $x = v_0^2 / (2|a|) = 400/10 = 40\ \text{m}$。**刹车类问题必须先确认运动是否已经停止，这是最常见的失分点。**

匀变速运动还有一组常用推论，做题直接取用：

| 推论 | 公式 | 适用情形 |
| --- | --- | --- |
| 平均速度 | $\bar{v} = \dfrac{v_0+v}{2}$ | 匀变速时某段时间的平均速度 |
| 中间时刻速度 | $v_{t/2} = \dfrac{v_0+v}{2}$ | 恰等于该段时间的平均速度 |
| 中间位置速度 | $v_{x/2} = \sqrt{\dfrac{v_0^2+v^2}{2}}$ | 位移中点的瞬时速度 |
| 连续等时位移差 | $\Delta x = aT^2$ | 纸带、频闪照片判匀变速 |
| 初速为零比例 | $x_1:x_2:x_3 = 1:3:5$ | 自由落体等初速为零情形 |

**辨析｜易错点：** 中间位置速度 $v_{x/2}$ 恒大于中间时刻速度 $v_{t/2}$。原因直观：匀加速「越走越快」，走前一半路程用时比后一半长，到达位移中点时，时间已经过了「中间时刻」，速度自然更大。这个「位置中点快于时间中点」的结论常被拿来做直觉考题。

**实验支点：打点计时器**。人教版 §2.1《实验：探究小车速度随时间变化的规律》用打点计时器在纸带上打下一串点，相邻两点时间间隔 $T$（频率 $50\ \text{Hz}$ 时 $T = 0.02\ \text{s}$）。处理纸带就是本节推论的实战：量出相邻计数点间距、算各段平均速度当作中间时刻速度、再用 $\Delta x = aT^2$ 反推加速度。**「量小段 → 取中间时刻速度 → 位移差恒定判匀变速」是贯穿高中全部纸带类实验的模板**，到验证机械能守恒、验证动量守恒还会原样复用。

## 4 抛体运动：把直线运动「投影」到两个方向

**平抛运动**：初速度水平、只受重力的运动。核心思想是**运动的合成与分解**：水平方向不受力，做匀速直线运动；竖直方向初速为零，做自由落体运动。两个方向独立、时间同步：

$$x = v_0 t, \qquad y = \tfrac{1}{2} g t^2, \qquad v_x = v_0, \qquad v_y = gt$$

**例（实际数字）**：一架飞机在离地 $h = 500\ \text{m}$ 高空以 $v_0 = 100\ \text{m/s}$ 水平匀速飞行，投下救灾物资（忽略阻力）。落地时间由竖直方向决定：$t = \sqrt{2h/g} = \sqrt{1000/9.8} \approx 10.1\ \text{s}$；水平位移 $x = v_0 t \approx 1010\ \text{m}$——所以飞机必须提前约 $1\ \text{km}$ 投下物资，才能命中目标。**两个方向时间同步**这个事实，是抛体题几乎所有「猜时间」技巧的来源。<span class="marginnote">「水平、竖直各自独立、时间同步」这个思想，到电磁场里带电粒子在电场/磁场中的偏转会原样复用——抛体是它最早的一次彩排。</span>

**斜抛运动**：把初速度分解为水平与竖直分量，最高点处竖直分速度为零、水平分速度不变，整个轨迹是抛物线。射程 $R = \dfrac{v_0^2\sin 2\theta}{g}$，在 $45°$ 时最大。

**辨析｜易错点：** 抛体运动是「匀变速曲线运动」——加速度恒为 $g$、方向竖直向下，判断标准是「只受重力 + 初速度方向任意」。竖直上抛、竖直下抛、平抛、斜抛全是一族：竖直上抛在最高点速度为零但加速度仍是 $g$，下落段就是自由落体；平抛是 $\theta = 0°$ 的斜抛特例。**「速度为零」绝不等于「加速度为零」**，这是运动学里反复出现的钉子。

## 5 相对运动：换个参考系看世界

运动是相对的，因此「观察者不同，速度不同」是常态。设物体 $A$ 相对地面速度 $\vec{v}_A$，物体 $B$ 相对地面速度 $\vec{v}_B$，则 $A$ **相对 $B$** 的速度为：

$$\vec{v}_{A/B} = \vec{v}_A - \vec{v}_B$$

**例（追赶问题）**：雨滴以 $8\ \text{m/s}$ 竖直下落，人骑着车以 $6\ \text{m/s}$ 水平前进。在人的参考系里，雨滴相对人的速度是 $\vec{v}_{\text{雨/人}} = \vec{v}_{\text{雨}} - \vec{v}_{\text{人}}$，即竖直 $8$ 与水平 $-6$ 的合成，大小为 $\sqrt{8^2+6^2} = 10\ \text{m/s}$，方向与竖直方向夹角 $\theta = \arctan(6/8) \approx 37°$——所以打伞时伞面应向前倾约 $37°$。

**例（船过河）**：船在静水中速度 $v_{\text{船}} = 4\ \text{m/s}$，河水流速 $v_{\text{水}} = 3\ \text{m/s}$，河宽 $d = 120\ \text{m}$。船头垂直对岸时过河时间最短：$t = d/v_{\text{船}} = 30\ \text{s}$，但船被水冲到下游 $x = v_{\text{水}}t = 90\ \text{m}$；要让船实际走垂直航线（最短路程），需把船头朝上游偏 $\theta = \arcsin(v_{\text{水}}/v_{\text{船}}) = \arcsin(3/4) \approx 48.6°$，过河时间随之变长。**「最短时间」和「最短路程」是两道不同的问题——这是相对运动里最经典的考点。**

参考系的选择是「解题自由的来源」：同一个问题，选地面参考系可能要对两个物体列两个方程，换到相对参考系往往一个方程就够。第 3 节的刹车、第 5 节的船，都是「把运动放到对方身上看」的示范——这种「换个角度看世界」的灵活性，到第二级《理论力学》讨论惯性力、到机器学习里做特征变换时，会一再要求你具备。<span class="marginnote">相对运动在第二级《理论力学》和第三级《相对论》里会彻底展开：参考系的变换不再只是「加减速度」，而是洛伦兹变换。但「先定参考系、再算相对量」的思维方式，从今天起就固定下来。</span>

## 6 小结

- **运动学的框架**：质点、参考系、时刻与时间间隔、位置、位移、路程——先定义语言，再谈规律。
- **速度**描述位置变化快慢（$v = \Delta x/\Delta t$，瞬时速度是极限），**加速度**描述速度变化快慢（$a = \Delta v/\Delta t$），两者是独立概念。
- **匀变速直线运动**五条公式一条链；刹车类问题务必先算停止时刻。
- **平抛/斜抛**的核心是「水平匀速 + 竖直自由落体」的合成与分解，两个方向时间同步。
- **相对速度**：$\vec{v}_{A/B} = \vec{v}_A - \vec{v}_B$，参考系的变换贯穿全部力学。
- 描述运动用的是极限（瞬时速度 = 导数）——「从极限到大模型」的物理第一课。
- 解题三问先自查：先确认是否匀变速、是否刹车已停、参考系是否选对——这三问能拦住运动学的大半失分。
