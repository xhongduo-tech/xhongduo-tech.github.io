# 牛顿第二定律

<div class="epigraph">

## 为什么牛顿第二定律是动力学的核心

前两节做了两件事：第一定律定性地说「力改变运动状态」，实验定量地归纳出「$a$ 与 $F$ 成正比、与 $m$ 成反比」。现在把它们合起来，就是整个经典力学最重要的一条方程：

$$F = ma$$

这条式子太常见，反而容易让人低估它。它是**连接运动学与动力学的桥梁**：运动学负责描述「怎么动」，而 $F = ma$ 告诉你「为什么会这么动」。从抛体到行星、从电梯到火箭，一切经典力学问题的求解路径都是同一条：**受力分析 → 写 $F = ma$ → 解出加速度 → 用运动学公式求运动**。学会它，你就拿到了分析绝大多数机械运动的万能钥匙。<span class="marginnote">牛顿在《原理》里的原始表述是「运动之变化正比于所加动力」——这里的「运动之变化」就是动量变化率 $dp/dt$。$F = ma$ 是质量恒定时 $F = dp/dt$ 的特例，到选择性必修第一册《动量》我们还会回到这个更一般的形式。</span>

## 1 内容与表达式

**牛顿第二定律（Newton's second law）**：物体加速度的大小跟它所受的**合力**成正比，跟它的**质量**成反比，加速度的方向跟**合力的方向**相同。

用公式写出来就是：

$$F = ma$$

其中 $F$ 是物体所受的**合外力**（不是某一个力），$m$ 是物体的质量，$a$ 是物体产生的加速度。三个量必须对应**同一个物体**、在**同一时刻**、相对**同一惯性参考系**。

一个公式同时封装了三个「同」，这是它最容易被误用、也最值得仔细品味的地方。<span class="marginnote">「合外力」三个字是这条定律的命门：对物体做受力分析后把各个力按矢量加法合成，得到的才是 $F$。矢量加法你已在第三章《力的合成和分解》学会——$F = ma$ 正是那章内容在动力学里的第一次大显身手。</span>

## 2 六大性质：把公式「读厚」

一条 $F = ma$ 背后站着六条性质，做题的成败往往取决于对它们的理解深度：

- **矢量性**：$F$ 与 $a$ 方向相同。$a$ 的方向不是 $v$ 的方向，而是**合外力**的方向。圆周运动里合力指向圆心，所以加速度也指向圆心（这正是第六章《向心力》的先声）。
- **瞬时性**：$F$ 与 $a$ **同时产生、同时消失、同时变化**。力变，加速度立刻变；但速度不能突变——速度是「积累」的结果，需要时间。这解释了竖直上抛最高点：那里 $v = 0$，但重力还在，所以 $a = g$ 不为零。
- **同体性**：$F$、$m$、$a$ 必须属于**同一个研究对象**。马拉车时，「马对车的力」对应「车的加速度」；「车对马的力」对应「马的加速度」——各算各的账，绝不可混用。
- **独立性**：物体受多个力时，每个力各自独立地产生对应的加速度，合加速度是各分加速度的矢量和。于是可以把力正交分解，分别对 $x$、$y$ 方向写 $F_x = ma_x$、$F_y = ma_y$。<span class="marginnote">「独立性」是解题利器：斜面上的物体，把重力分解成沿斜面和垂直斜面两个方向，就能对两个方向分别列方程。这在下一节《牛顿运动定律的应用》会反复用到。</span>
- **因果性**：**力是产生加速度的原因**，不是速度的原因。是「力 → 加速度」，不是「力 → 速度」。
- **相对性**：$F = ma$ 只在**惯性参考系**里成立。在加速的电梯里用这条定律，必须先补上惯性力——那是非惯性系的故事，本课程只点到为止。

## 3 力的单位：牛顿（N）是「造」出来的

牛顿第二定律还顺带定义了力的单位。取质量 $1\ \text{kg}$、加速度 $1\ \text{m/s}^2$，规定使这个物体产生这个加速度的力为 $1$ 牛顿：

$$1\ \text{N} = 1\ \text{kg} \cdot \text{m/s}^2$$

注意：**牛顿不是基本单位，是导出单位**。它由质量、长度、时间三个基本单位组合而成。$1\ \text{N}$ 的大小大约相当于「把约 $102\ \text{g}$（一个苹果）托在手上需要用的力」。这个单位的来龙去脉，下一节《力学单位制》会系统展开。

## 4 公式解析：F = ma 的逐步拆解

$$
F = ma
$$

拆四步看，每条都是硬知识：

- **第一步，$a = F/m$，质量是「惯性大小的量度」**：把公式改写成 $a = F/m$，同样大小的力，质量越大加速度越小——物体「越懒」，状态越难改变。这正是上一节「质量是惯性大小的量度」的定量版本。<span class="marginnote">同一外力下 $a$ 与 $m$ 成反比，可以用「推购物车」的直觉验证：满载车质量翻倍，同样的推力，加速度减半。</span>
- **第二步，量纲检查**：$F$ 的单位是 $\text{N} = \text{kg} \cdot \text{m/s}^2$，即量纲 $[F] = [M][L][T]^{-2}$。右边 $m$ 的量纲 $[M]$ 乘以 $a$ 的量纲 $[L]/[T]^2$，得到 $[M][L][T]^{-2}$，左右一致。**公式右边算出来的量纲，永远可以拿来验证左边**——这是你在考试里检查公式写没写错的最快手段。
- **第三步，矢量性落地**：$F$ 与 $a$ 同向，做题时先做受力分析，找出合力的方向，加速度方向就跟着定下来。竖直上抛全程合力向下，所以全程 $a = g$ 向下——与速度方向无关。
- **第四步，瞬时性落地**：已知某一时刻的合力，就能求该时刻的加速度；已知加速度随时间的规律，就能积分出速度、位移——这就是用 $F = ma$ 求解运动的全过程。到第二级《数学分析》与第三级《常微分方程》，$m\dfrac{d^2x}{dt^2} = F$ 会是你们反复求解的标准方程。

## 5 用 F = ma 解题的完整流程

把本节的知识拧成一股，就是解题的标准流水线：**受力分析 → 合成合力 → 写 $F = ma$ 求加速度 → 用运动学求运动**。走两道题，把流水线跑熟。

**例 1（光滑水平面，最简单情形）**：质量 $m = 2\ \text{kg}$ 的物体在光滑水平面上，受水平恒力 $F = 10\ \text{N}$，从静止开始运动。

- 受力分析：受重力、支持力、水平拉力。竖直方向合力为零，水平方向只有拉力。
- 求合力：$F_{\text{合}} = 10\ \text{N}$。
- 由 $a = F/m = 10/2 = 5\ \text{m/s}^2$，方向水平向前。
- 用运动学求 3 秒末：$v = v_0 + at = 0 + 5 \times 3 = 15\ \text{m/s}$；$x = \tfrac{1}{2}at^2 = \tfrac{1}{2} \times 5 \times 9 = 22.5\ \text{m}$。

**辨析｜易错点：$F$ 是合力，不是那个拉力。** 例 1 光滑，所以拉力恰好就是合力。只要一有摩擦，情况立刻变——看例 2。

**例 2（粗糙水平面，加入摩擦力）**：同上，但水平面粗糙，动摩擦因数 $\mu = 0.2$，取 $g = 10\ \text{m/s}^2$。

- 受力分析：重力 $G = mg = 20\ \text{N}$，支持力 $N = G = 20\ \text{N}$，拉力 $F = 10\ \text{N}$ 向前，摩擦力 $f = \mu N = 0.2 \times 20 = 4\ \text{N}$ 向后。
- **先合成**：合力 $F_{\text{合}} = F - f = 10 - 4 = 6\ \text{N}$。
- 加速度 $a = F_{\text{合}}/m = 6/2 = 3\ \text{m/s}^2$——比光滑时小，正是因为摩擦力「吃掉」了一部分拉力。<span class="marginnote">例 2 的价值在于：<strong>拉力与合力是两回事</strong>。做题最常犯的错就是把拉力直接当 $F$ 代进 $F = ma$。记住流程里的「合成」一步，就不会漏掉摩擦力。</span>

**例 3（斜面，预告下一节）**：质量为 $m$ 的物体在光滑斜面上，斜面倾角为 $\theta$。重力沿斜面的分力是 $mg\sin\theta$，垂直斜面方向合力为零，所以 $a = g\sin\theta$——**斜面越陡，下滑越快**。这是「力的分解」与 $F = ma$ 的第一次合作，下一节《牛顿运动定律的应用》里这类题会大量出现。

三道题走完，顺手做一次**单位自检**：例 1 里 $v = 15\ \text{m/s}$，单位是 $\text{m/s}$，对；$x = 22.5\ \text{m}$，单位是米，对。如果算出某个量的单位不对，多半是合力算错或代入出错——**单位是公式正确性的最低保障哨兵**。这正是下一节《力学单位制》要系统化的思想：公式不只是数字的游戏，单位自洽是它成立的前提。

## 6 一个经典辨析：马拉车问题

用「马拉车」检验你对同体性和因果性的理解。马向前拉车，车向后拉马——根据牛顿第三定律，这两个力**大小相等**。那为什么车还能向前加速？

**辨析｜易错点：作用力与反作用力不能相消，因为它们作用在两个物体上。** 车加速，看的是**车**受到的合力：车受马的拉力（向前），还有地面的摩擦力等。只要向前的力大于向后的阻力，车就向前加速。至于「车拉马的力」——它作用在**马**身上，参与决定的是**马的**加速度，跟车的运动没有直接关系。<span class="marginnote">这个辨析几乎每年都考，错因都是把「作用力与反作用力」当成了「平衡力」。平衡力作用在同一物体上、能抵消；作用力与反作用力作用在两个物体上、永不抵消。第三定律（第三章）与第二定律（本节）在这里第一次交汇。</span>

再补一个数值例子感受量级：用 $F = 10\ \text{N}$ 的水平力推一个 $m = 2\ \text{kg}$ 的物体（地面光滑），由 $a = F/m = 10/2 = 5\ \text{m/s}^2$，每过 1 秒速度增加 $5\ \text{m/s}$；若推力不变、质量加倍到 $4\ \text{kg}$，加速度减半为 $2.5\ \text{m/s}^2$。**同样的力，质量越大，加速度越小**——上一节实验图像里的反比关系，在这里变成了可以直接计算的数字。

## 7 易错点清单

把本节最容易翻车的几个点集中列一下：

- **$F$ 必须是合力**：把某个分力当 $F$ 代进公式，是最高频错误。先受力分析、先合成，再写 $F = ma$。
- **$F$ 与 $v$ 不同向很正常**：合力方向决定**加速度**方向，不是速度方向。物体可沿 $v$ 方向减速运动，此时 $F$ 与 $v$ 反向。
- **$a$ 瞬时与 $v$ 渐变的区别**：合力突变，$a$ 立刻突变；$v$ 不能突变。所以「剪断绳子瞬间」这类题，先看合力怎么变，再想速度。
- **质量不随力而变**：$F$ 增大，$a$ 增大，$m$ 不变。惯性与力无关，只由物体自身决定。
- **参考系必须是惯性系**：在加速的电梯里 $F = ma$ 不直接成立，别硬套。

## 8 小结

- **牛顿第二定律**：$F = ma$，$F$ 为合外力，$a$ 与 $F$ 同向、与 $m$ 成反比。
- **六个性质**：矢量性、瞬时性、同体性、独立性、因果性、相对性（惯性系成立）。
- **单位定义**：$1\ \text{N} = 1\ \text{kg} \cdot \text{m/s}^2$，牛顿是**导出单位**。
- **量纲**：$[F] = [M][L][T]^{-2}$，可用来验算公式。
- **马拉车辨析**：作用力与反作用力作用在两个物体上，不能相消；车的加速度取决于车受的合力。
- 求解路径：受力分析 → 合成合力 → $F = ma$ → 运动学；单位自检贯穿始终。
- 三个数例：光滑面 $a = F/m$；粗糙面合力要减去摩擦；光滑斜面 $a = g\sin\theta$。
