## 为什么从电磁感应现象及应用开始

1820 年奥斯特证明「电生磁」，人类第一次把电与磁连起来。那么反过来——**磁能生电吗？** 这个问题困扰了物理学家十余年：磁铁放在导线旁，导线里并没有电流；直到 1831 年法拉第用十年锲而不舍的实验发现，关键在于**变化**——只有磁通量**变化**时，才感应出电流。这个「磁生电」的发现，把机械能大规模转化为电能变成现实，催生了发电机、变压器与整个电气时代。

这一节是「电磁感应」的入门：**感应电流产生的条件、怎么判断有无感应电流、电磁感应在生活中的应用**。它把上一节的磁通量 $\Phi$ 变成判断的「触发器」：磁通量变，就感应；不变，就不感应。<span class="marginnote">为什么「变化」如此关键？因为静态磁场的能量「藏」在磁场里，不做事；只有磁通量变化时，磁场能量才能转化为电能、推动电荷。发电机转动的每一刻，线圈都在「扫过」变化的磁通量；而把一块磁铁静静放在线圈旁，什么也不会发生。物理学的核心动作永远是「变化」——就像运动学里的速度是「位置的变化」一样。</span>

学这一节，记住一个判断句：**产生感应电流的条件 = 穿过闭合回路的磁通量发生变化**。然后把「磁通量怎么变」的三种途径（$B$ 变、$S$ 变、$\theta$ 变）练熟，感应现象就全在掌握之中。

## 1 电磁感应现象的发现：从奥斯特到法拉第

1820 年，奥斯特在课堂上发现通电导线旁的磁针偏转——**电流产生磁场**。这一发现激起热烈反响：既然电能生磁，磁能否生电？

物理学家们做了大量尝试：把磁铁靠近导线、把导线绕成线圈再放磁铁……都失败了。**关键盲区是「静态」**：他们都以为只要磁铁放在那儿，导线里就该有电流。直到法拉第想到「变化」：

把磁铁**插入**线圈的瞬间，电流计偏转；
磁铁**停在**线圈内，电流计归零；
把磁铁**拔出**的瞬间，电流计反向偏转。

**结论**：不是磁铁「存在」产生电流，而是磁铁的**运动**（磁通量变化）产生电流。法拉第在 1831 年发现了**电磁感应现象**。<span class="marginnote">这个发现过程是科学史「顽固先入之见」的绝佳案例：前人都默认「磁生电」应当是静态的（像电池那样恒久供电），而法拉第被「变化」打开了思路。科学发现往往不是「多做了实验」，而是「换了一个提问的角度」——从「磁生电吗」到「磁的变化生电吗」。这个「找对问题」的能力，比堆实验次数更重要。</span>

电磁感应的意义：它揭示了「变化的磁场产生电场」——磁与电真正统一。法拉第之后，麦克斯韦把电磁感应写进方程组，预言电磁波，开启了整个无线时代。

## 2 产生感应电流的条件

**产生感应电流的条件**：穿过闭合回路的**磁通量发生变化**。

拆成两个必要条件：

1. **回路必须闭合**：只有闭合回路才能形成持续电流。回路断开时，磁通量变化只产生感应电动势（两端有电压），但不形成电流。
2. **磁通量必须变化**：$B$、$S$、$\theta$ 三者至少一个在变。

**常见情形判断**：

| 操作 | 磁通量是否变化 | 有无感应电流 |
| --- | --- | --- |
| 磁铁插入静止线圈 | 变（$B$ 变） | 有 |
| 磁铁静止在闭合线圈内 | 不变 | 无 |
| 线圈在匀强磁场中平移（不转、不进出） | 不变 | 无 |
| 线圈在匀强磁场中转动 | 变（$\theta$ 变） | 有 |
| 闭合回路部分切割磁感线 | 变（有效面积变） | 有 |
| 闭合回路在匀强磁场中整体平移 | 不变 | 无 |<span class="marginnote">「线圈在磁场中整体平移无感应、转动才有」是经典判断：平移时穿过线圈的磁感线条数不变（$\Phi$ 恒定），转动时 $\theta$ 连续变化（$\Phi$ 波动）。这条规律的直觉是「穿过的线数」——平移不改变「穿过的线数」，转动改变。一切电磁感应判断，都可以回到「磁感线穿过回路的条数变没变」这个直观标准。</span>

**辨析｜易错点：** 「切割磁感线」与「磁通量变化」是同一个条件的两种说法——**部分切割磁感线 ⇒ 回路磁通量变化 ⇒ 有感应电流**；而**整体在匀强磁场中平移**虽然也在「经过」磁感线，但磁通量不变，无感应电流。把「切割磁感线」误当「一定产生感应电流」是不全面的——要回到「磁通量是否变化」这个根本判据。

## 3 电磁感应的应用：发电机与变压器

电磁感应直接催生了改变世界的两大装置：

**发电机**：把机械能转化为电能。核心结构是「线圈在磁场中转动」——线圈转动使穿过它的磁通量周期性变化，产生周期性变化的感应电流（交变电流）。发电机的原理正是「磁通量变化生电」的工程实现：水流/风/蒸汽推动轮机，轮机带线圈转，线圈切割磁感线，产生电能。<span class="marginnote">发电机的本质是「用机械能改变磁通量，把机械能变成电能」。线圈转一圈，磁通量经历「最大→零→反向最大→零→最大」一个周期，感应电动势也随之周期变化。这个「转动 × 磁通量变化」的节拍，就是交变电流（选择性必修二第三章）的起源——发电机的转动频率直接决定交流电的频率（我国 50 Hz）。</span>

**变压器**：改变交流电压的大小。由铁芯 + 原线圈 + 副线圈组成。原线圈通交变电流，铁芯中产生变化的磁通量，变化的磁通量穿过副线圈，在其中感应出电动势——实现了「电能通过磁场耦合传递」且「电压按匝数比变换」。变压器不能改变直流（直流磁通量不变，无感应），这是「变压器只适用于交流」的原因。<span class="marginnote">变压器体现的「隔空传能」让远距离输电成为可能：升压变压后输电损耗大幅下降（输电损耗 $\propto 1/U^2$），降压后再供家庭使用。到选择性必修二《变压器》《电能的输送》，你会看到变压器与交变电流的完整定量关系——本节先建立「变化的磁通量在副线圈里感应电压」的图像。</span>

**其他应用**：电磁炉（交变磁场在锅底感应涡流生热）、无线充电（变化的磁场在接收线圈感应电流）、动圈式话筒与扬声器、磁卡读取——凡是「磁 ↔ 电」转换的装置，原理都是电磁感应。

把电磁感应的应用与「原理要点」对应起来：

| 装置 | 输入 | 输出 | 电磁感应角色 |
| --- | --- | --- | --- |
| 发电机 | 机械能 | 电能 | 线圈转动改变磁通量 |
| 变压器 | 交流电能 | 交流电能（变压） | 交变磁通量耦合传能 |
| 电磁炉 | 电能 | 热（烹饪） | 交变磁场感应涡流 |
| 无线充电 | 电能 | 电能（隔空） | 交变磁场在接收线圈感应 |
| 动圈话筒 | 声能 | 电能 | 线圈振动切割磁感线 |

每一行都是「磁通量变化 → 感应」的工程化身——原理相同，舞台不同。

## 4 感应电动势：回路不闭合也有「电」

严格说，电磁感应产生的不是「电流」，而是**感应电动势**——即使回路不闭合，磁通量变化也会在导体两端产生电动势（电压）。

**闭合回路**：感应电动势推动电荷，形成**感应电流**。
**不闭合回路**：只有感应电动势（两端有电压），无电流。

这个区分重要，因为它揭示了电磁感应的本质：**变化的磁通量在空间中激发出电场（感应电场），感应电场驱动电荷**。感应电动势是「变化的磁场产生电场」的直接度量——即使没有闭合回路，电场依然存在。<span class="marginnote">「变化的磁场产生电场」是麦克斯韦方程组的精髓之一：法拉第定律 $\oint \vec E\cdot d\vec l = -d\Phi/dt$ 说的正是「磁通量变化率 = 感应的电场环路积分」。到第二级电磁学你会严格学它；现在只需建立观念：<strong>电磁感应不是「电路效应」，而是「场效应」——变化的磁场在空间中激发电场</strong>。这个「场」的观念，比「电流」更本质。</span>

感应电动势的大小，定性上「磁通量变化越快，感应电动势越大」；定量关系（$E = \Delta\Phi/\Delta t$）在选择性必修二《法拉第电磁感应定律》展开。本节先抓住「有无」与「方向由楞次定律判」（下节预告）。

## 5 公式解析：感应电流的产生判据

产生感应电流的条件可写成：

$$\Phi \ \text{变化} \ \Rightarrow \ E_{\text{感}} \neq 0 \ (\text{闭合时}\ I_{\text{感}} \neq 0)$$

其中 $\Phi = BS\cos\theta$。拆三步看：

- **第一步，判据的三种形式**：$\Phi$ 变化可以是 $B$ 变（磁铁移近移远）、$S$ 变（回路收缩扩张）、$\theta$ 变（线圈转动）。任何一个是变化的，都产生感应。**判断程序：写出 $\Phi = BS\cos\theta$，逐一检查三个因子**。<span class="marginnote">这个「逐一检查 $B$、$S$、$\theta$」的流程，把抽象判断变成机械检查——就像做受力分析要「逐一画力」。熟练后你会有直觉，但初学阶段「列式逐项检查」永远是最稳的。考试里「哪种操作能产生感应电流」的题，用这个流程三秒钟出答案。</span>
- **第二步，「切割磁感线」的严格表述**：回路中部分导体切割磁感线，意味着「回路包围的磁感线数」在变——等效于 $S$ 变（对匀强磁场）或 $B$ 变（对非匀强）。所以「切割」只是「$\Phi$ 变化」在特殊情形下的通俗说法。
- **第三步，为什么回路必须闭合**：感应电动势在任何导体中都产生，但电流需要闭合路径。回路断开时，电荷无法形成持续流动，「有压无流」。这就像「两端有电压的电容器接在断开的电路里」——电压存在但无电流。
- **第四步，楞次定律预告**：感应电流的方向「阻碍磁通量的变化」——磁通量增大时，感应电流产生的磁场与原磁场反向；减小时同向。这条「阻碍」规律（楞次定律）是选择性必修二的核心内容，本节先记住结论方向。

## 6 辨析｜易错点

- **磁通量不变，无感应**：磁铁静止在线圈内、线圈整体平移，磁通量不变，无感应电流。别被「磁场里有线圈」迷惑，看「磁通量变没变」。
- **回路不闭合，无感应电流但有感应电动势**：判断「有无感应电流」看闭合 + 磁通量变；判断「有无感应电动势」只看磁通量变。
- **切割 ≠ 一定感应**：整体平移穿过磁感线不产生感应（磁通量不变）；部分切割才等效于磁通量变化。
- **直流不能通过变压器**：变压器靠变化的磁通量工作，直流磁通量恒定，副线圈无感应。
- **感应电流的大小与快慢有关**：磁通量变化越快，感应电流越大（定性）；「变化量相同但用时不同，感应不同」——快慢才是关键。

## 7 小结

- **电磁感应**：穿过闭合回路的磁通量变化，回路中产生感应电流（法拉第，1831）。
- **产生条件**：闭合回路 + 磁通量变化（$B$、$S$、$\theta$ 任一变化）。
- **发电机**：线圈转动改变磁通量，机械能 → 电能。
- **变压器**：交变磁通量耦合原副线圈，隔空传能、改变电压（只适用于交流）。
- **感应电动势**：磁通量变化即产生，回路闭合才有电流——本质是「变化的磁场激发电场」。
- **判断程序**：写 $\Phi = BS\cos\theta$，逐一检查三个因子是否变化。
- **电磁感应是「磁↔电」的总开关**：发电机、变压器、电磁炉、无线充电、话筒，同一原理。

在下一节，我们追索电磁感应与电磁波的历史与本质：**电磁波的发现及应用**。麦克斯韦预言电磁波，赫兹实验证实——光就是电磁波，无线电由此而来。
