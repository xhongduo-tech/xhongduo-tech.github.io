## 为什么从流体力学开始

前面几节研究的物体大多是「固体的质点」或「固体的刚体」。但世界上的物质多数是流体——水、空气、血液、石油。流体力学的难度在于：它没有「一个质点」的起点，而是一大群分子在流动。然而把流体看成连续介质、用「压强、速度、流量」描述它，流体就服从一套漂亮的定律，其中最著名的就是**伯努利方程**——它其实是**能量守恒在流体里的具体化**。

人教版高中物理没有独立章节讲流体力学，但初中的液体压强、必修第二册的能量守恒，都是它最直接的跳板。本篇作为第 1 篇拓展，用「能量 + 守恒」的既有武器，把流体的核心规律立起来：**连续性方程是质量守恒，伯努利方程是能量守恒**。<span class="marginnote">流体力学的两条主干方程，不过是「守恒律」换了流体这个主语——你已经在功与能、动量与碰撞里反复用过的守恒思想，在这里无缝移植。这种「守恒律才是物理学的不变量，具体方程只是它的化身」的认知，是「从极限到大模型」全站反复强化的主旋律。</span>

## 1 流体静力学：压强与浮力

**压强（pressure）**：单位面积上受到的正压力，$p = \dfrac{F}{S}$，单位帕斯卡（Pa）。流体内部的压强有两大特点：

- **向各个方向传递**：静止流体内部任一点的压强各方向相同。
- **随深度增大**：液体内部压强 $p = \rho g h$（$\rho$ 是密度，$h$ 是深度），与液体的多少无关。

**帕斯卡定律**：密闭液体任一点的压强变化，等大地传到液体的各个部分——液压千斤顶、汽车刹车、水压机都靠它：小活塞加小力，大活塞出大力，力之比等于面积之比。$F_2 = F_1 \cdot \dfrac{S_2}{S_1}$。<span class="marginnote">液压放大（力 = 面积比）与「时间换力」的缓冲、杠杆的「臂比」是同一种「以小搏大」思想的不同形态——物理的杠杆不是只有硬杆，压强传递同样是一根看不见的杠杆。</span>

**浮力（buoyancy）**：物体在流体中受到的竖直向上的力，大小等于它排开流体的重力——**阿基米德原理**：$F_{\text{浮}} = \rho_{\text{液}} g V_{\text{排}}$。传说阿基米德在浴缸里发现这一原理后光着身子跑上街高喊「Eureka（我发现了）」。判断物体浮沉：物体密度小于流体密度则漂浮，大于则下沉，等于则悬浮。

**例（液压千斤顶的数字）**：小活塞面积 $S_1 = 5\ \text{cm}^2$，大活塞面积 $S_2 = 250\ \text{cm}^2$，在小活塞上加 $F_1 = 100\ \text{N}$。由帕斯卡定律压强相等：$p = \dfrac{F_1}{S_1} = \dfrac{F_2}{S_2}$，得 $F_2 = 100 \times \dfrac{250}{5} = 5000\ \text{N}$——**50 倍的力，全靠面积比放大**。代价是：小活塞推过的距离，大活塞只移动其 $1/50$——「省力必费距离」，与杠杆、动滑轮是同一笔账。

## 2 理想流体与连续性方程：质量守恒

要描述流动，先做理想化：**理想流体**满足「不可压缩 + 无粘性 + 稳定流动（流速不随时间变）」。稳定流动中流体质点的轨迹叫**流线**，流线不相交。

**连续性方程（continuity equation）**：理想流体稳定流动时，流过任意截面的流量相等：

$$A_1 v_1 = A_2 v_2$$

$A$ 是横截面积，$v$ 是流速。它说的其实是一句大白话：**单位时间内流过每一点的流体体积相同，否则就会堆积或亏空**（质量守恒）。截面小的地方流速大，截面大的地方流速小。

**例（河水的收窄）**：河水从宽 $A_1 = 20\ \text{m}^2$ 的河道流入宽 $A_2 = 5\ \text{m}^2$ 的峡谷。若宽处流速 $v_1 = 1\ \text{m/s}$，则峡谷流速 $v_2 = A_1v_1/A_2 = 4\ \text{m/s}$——**河道变窄，水流加速**。这个「变窄加速」的直觉，正是伯努利方程下一步要处理的压强变化的关键。

**流量（volumetric flow rate）**：$Q = Av$，单位 m³/s。连续性方程 $Q_1 = Q_2$ 就是说「流量守恒」——质量守恒的流体版。工程上常用它的变形「流速 = 流量 ÷ 截面积」：知道自来水管的内径与流量，就能估流速、进而用伯努利方程估压强分布。**「管变细、流加速」**这个结论在给排水、心血管、风洞设计里无处不在。

## 3 伯努利方程：能量守恒在流体里

**伯努利方程（Bernoulli's equation）**（沿一条流线，理想流体、稳定流动）：

$$p + \tfrac{1}{2}\rho v^2 + \rho g h = \text{常数}$$

三项各有所指：$p$ 是**压强能**（单位体积流体的压力功）、$\tfrac{1}{2}\rho v^2$ 是**动能密度**、$\rho g h$ 是**重力势能密度**。整条方程就是「单位体积流体的能量沿流线守恒」——**能量守恒定律在流体力学里的化身**。<span class="marginnote">伯努利方程「每项都是一米高度」的口诀是 $p = \rho g h$：把压强项也写成「高」，方程就是「压高 + 速度头 + 位高 = 常数」。这个「把能量统一写成高度」的视角，让流动问题变成「高度守恒」问题，工程上叫水头线。</span>

**例（机翼升力）**：空气流过机翼上表面路程长、流速快（$v_{\text{上}} > v_{\text{下}}$），由伯努利方程 $p + \tfrac{1}{2}\rho v^2$ 不变，上表面压强小、下表面压强大，产生向上的净力——**升力**。民航客机巡航时升力支撑整架飞机，靠的就是「流速快 → 压强小」这一条。同一条原理还解释：为什么火车进站时人要站在黄线后（人与车之间空气流速大、压强小，把人推向车）、为什么向两纸片中间吹气纸片反而贴拢。

**例（湍流抽吸与喷雾）**：洗衣机的进水管口、喷雾器的吸液口都是「截面变窄、流速加大、压强降低」，把液体「吸」上来。这是伯努利原理在日用机械里最常见的应用——**真空不是被制造的，是被流速差「吸」出来的**。

伯努利方程的应用清单，看「流速差 → 压强差」这一个动作：

| 现象 | 流速差 | 结果 |
| --- | --- | --- |
| 机翼上表面 | 上快下慢 | 上低下高，产生升力 |
| 火车进站黄线 | 车侧快、人侧慢 | 把人和车「吸」近 |
| 向两纸片间吹气 | 纸间快、纸外慢 | 纸片反而贴拢 |
| 喷雾器吸液 | 出气口快 | 压强低，把液体吸上来 |
| 帆船逆风航行 | 帆凸面快 | 产生侧向力，靠 Z 字航线前进 |

**辨析｜易错点：** 伯努利方程只对「同一流线、理想流体、稳定流动」成立——沿流线之外不能直接套用，有粘性、有泵输入能量时须修正。判断能不能用，先问三个条件齐不齐：**「一条流线 + 无粘 + 稳流」是免检证**。

## 4 公式解析：伯努利方程从能量守恒推出

伯努利方程不是凭空猜的，它可以从能量守恒**推**出来。取一段流管，考虑单位体积的流体从位置 1 流到位置 2：

$$
p_1 + \tfrac{1}{2}\rho v_1^2 + \rho g h_1 = p_2 + \tfrac{1}{2}\rho v_2^2 + \rho g h_2
$$

- **第一步，谁在做功**：这段流体受到上游压力 $p_1 A_1$ 的推力（做正功）、下游压力 $p_2 A_2$ 的阻力（做负功）、以及重力做功。压力的净功 $W_p = p_1A_1\cdot v_1\Delta t - p_2A_2\cdot v_2\Delta t$，由连续性方程 $A_1v_1 = A_2v_2$，可写成单位体积的 $p_1 - p_2$。
- **第二步，能量怎么变**：流体动能变化（$\tfrac{1}{2}\rho v^2$ 之差）与重力势能变化（$\rho gh$ 之差）之和，等于压力做的净功。
- **第三步，移项即得**：$p_1 + \tfrac{1}{2}\rho v_1^2 + \rho g h_1 = p_2 + \tfrac{1}{2}\rho v_2^2 + \rho g h_2$——把压力功、动能、势能放一边，常数在手。**这条「从守恒律推出的方程」，就是流体力学版的动能定理。**

**例（实际数字）**：水管内水的流速 $v_1 = 1\ \text{m/s}$、压强 $p_1 = 2 \times 10^5\ \text{Pa}$，水从高处流向低处并变窄，$v_2 = 4\ \text{m/s}$、高度差 $h_1 - h_2 = 10\ \text{m}$（$\rho = 1000\ \text{kg/m}^3$）。由伯努利方程：

$$p_2 = p_1 + \tfrac{1}{2}\rho(v_1^2 - v_2^2) + \rho g(h_1 - h_2) = 2\times10^5 + 500(1 - 16) + 10000 \times 10 = 2\times10^5 - 7500 + 10^5 = 2.925 \times 10^5\ \text{Pa}$$

流速增大使压强下降 $7500\ \text{Pa}$，高度下降使压强上升 $10^5\ \text{Pa}$，净效果是压强升高——**把两个效应分开算，是伯努利题的标准动作**。

## 5 粘性流：理想流体的边界

真实流体都有**粘性（viscosity）**——内摩擦，相邻流层之间互相拖拽。粘性的直接后果是：

- **层流**：流速按抛物线分布（管中心最快、壁面为零），阻力由牛顿粘性定律 $\tau = \eta \dfrac{dv}{dy}$ 描述，$\eta$ 是动力粘度。
- **湍流**：流速超过临界值时，流动变得混乱、涡旋丛生，阻力急剧增大。
- **阻力与速度**：低雷诺数下粘性阻力与速度成正比（$F = 6\pi\eta r v$，斯托克斯定律）；高雷诺数下阻力与速度平方成正比。

**雷诺数** $Re = \dfrac{\rho v d}{\eta}$（$d$ 是特征尺度）是判断流动状态的无量纲数：$Re$ 小 → 层流，$Re$ 大 → 湍流。**雷诺数本身是量纲分析（第 1 篇）的胜利**——它把密度、速度、尺度、粘度四个量凑成一个无量纲数，让不同尺度的流动可以互相类比。<span class="marginnote">飞机与蚊子都飞，但雷诺数差七个数量级：飞机靠惯性、蚊子靠粘性（所以蚊子不怕「空气墙」，飞机怕）。量纲分析给出 $Re$ 后，风洞实验才能用缩比模型代替真机——这是「从极限到大模型」里尺度分析与建模思想的工程化身。</span>

层流与湍流的直观对比：

| 特征 | 层流 | 湍流 |
| --- | --- | --- |
| 流线 | 整齐平行 | 混乱涡旋 |
| 流速剖面 | 抛物线（中心快、壁面零） | 近壁薄边界层、主体较平坦 |
| 阻力 | 与速度一次方成正比 | 与速度平方成正比 |
| 雷诺数 | $Re$ 小 | $Re$ 大（超临界） |
| 实例 | 细小血管、蜂蜜缓流 | 大流量水龙头、江河洪水 |

**「同一个几何里，雷诺数升过临界，流动就从层流突变到湍流」**——这种「参数越界 → 状态突变」的行为，在热对流（瑞利—伯纳德）、乃至神经网络训练里的「相变式」现象，是同一个数学故事。

**例（血液流动）**：血液粘度约水的 4 倍，小动脉中 $Re \approx 1$，层流。血管变窄（动脉粥样硬化）导致流速增大、局部 $Re$ 升高，可触发湍流，产生血管杂音——医生用听诊器听到的杂音，本质是**流动状态从层流到湍流的相变信号**。

## 6 小结

- **流体静力学**：$p = \rho gh$，帕斯卡定律（液压放大）、阿基米德浮力 $F = \rho_{\text{液}}gV_{\text{排}}$。
- **连续性方程** $A_1v_1 = A_2v_2$：截面小、流速大，是质量守恒的化身。
- **伯努利方程** $p + \tfrac{1}{2}\rho v^2 + \rho gh = \text{常数}$：能量守恒的化身；流速快 → 压强小（机翼升力、火车黄线）。
- 伯努利方程可以从**压力做功 + 动能 + 势能守恒**完整推导，它就是流体版动能定理。
- **粘性流**：层流 vs 湍流由**雷诺数** $Re = \rho vd/\eta$ 判断；粘性阻力随速度一次方/二次方变化。
- 量纲分析（第 1 篇）在这里再次立功——$Re$ 本身就是量纲分析的产物。
