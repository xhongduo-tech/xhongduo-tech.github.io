## 为什么从光的干涉开始

第三章我们学过波的干涉：两列相干波叠加，形成稳定的加强区与减弱区。问题是：**光是波吗？** 如果是，光也应能干涉。但日常灯光从不产生干涉条纹——因为普通光是非相干的（频率不同、相位乱变）。1801 年，托马斯·杨用双缝实验巧妙地把一束光分成两束相干光，让它们在屏上重逢——明暗相间的条纹出现了！**光能干涉，光就是波。**

杨氏双缝实验是光学史上最重要、最优雅的实验之一：它一举证明光的波动性，还给出测量光波长的方法。牛顿的「光的粒子说」因此动摇，光的波动说从此确立，直到 20 世纪量子力学重新统一波粒二象性。<span class="marginnote">「一束光怎么分成两束相干光？」杨的答案是双缝：一束光照射到两条相距极近的狭缝，每个缝都成为新的子波源（惠更斯原理），从两个缝发出的光来自同一束光、频率相同、相位差恒定——天然相干。这就是「分波阵面法」获得相干光。普通灯光两束光不相干（来自不同原子、相位乱跳），所以不干涉；双缝把「一束光」变成「两束相干光」，干涉才发生。</span>

学这一节，请抓住：**为什么双缝能产生相干光、干涉条纹的明暗判据（波程差）、以及条纹间距公式 $\Delta x = \lambda L/d$**。

## 1 杨氏双缝实验

**杨氏双缝实验**（1801）：一束单色光照射到遮光屏上的**两条狭缝** $S_1$、$S_2$（间距 $d$ 很小），两缝后放一个接收屏（距缝 $L$）。两缝发出的光在屏上相遇叠加，形成**明暗相间的等间距条纹**。

**关键设计——获得相干光**：

用**单缝**先把光源变成「线光源」，再让光同时通过两条平行双缝——两缝发出的光来自同一波前（分波阵面法），频率相同、相位差恒定，是**相干光**。
若直接用两个独立光源（两盏灯）照亮两缝，它们不相干，屏上无稳定条纹。

**实验现象**：

屏上出现**中央亮纹**（两缝正中央对应处），两侧对称分布明暗相间的条纹。
条纹**等间距**：相邻亮纹（或暗纹）的间距相同。
条纹间距与**波长、缝屏距、双缝间距**有关（下一节公式）。<span class="marginnote">中央亮纹为什么亮？中央处到两缝的距离相等（波程差为 0），两列光「同相到达」叠加加强——这是「波程差 = 0 加强」的直接体现。从中央向两侧，波程差逐级增大：第 $n$ 级亮纹处波程差 $= n\lambda$，暗纹处波程差 $= (2n+1)\lambda/2$。整个条纹图样就是「波程差判据」的视觉化。</span>

## 2 干涉条纹的明暗判据

屏上某点到两缝的距离差（波程差）$\Delta r = r_2 - r_1$：

**亮纹条件**（振动加强）：

$$\Delta r = n\lambda, \qquad n = 0, 1, 2, \cdots$$

**暗纹条件**（振动减弱）：

$$\Delta r = (2n + 1)\frac{\lambda}{2}, \qquad n = 0, 1, 2, \cdots$$

与机械波干涉完全一致——因为光就是波，干涉的判据同源。<span class="marginnote">这套判据与第三章《波的干涉》一字不差：<strong>整数个波长加强（亮）、奇数个半波长减弱（暗）</strong>。学习光学最大的便利就是「复用机械波的干涉语言」——波程差、相位差、相干条件，全部照搬。唯一要注意的是：光波的波长极短（亚微米），所以双缝间距必须极窄（亚毫米级）、缝屏距要足够大，条纹才看得见——这也是杨氏实验当年「精巧」的原因。</span>

**辨析｜易错点：** 明暗判据的前提是两缝光「同相」（来自同一波前、相位差为 0）。若两缝反相（相位差 $\pi$），明暗条件互换。普通双缝实验中两缝同相，所以「$n\lambda$ 亮、$(2n+1)\lambda/2$ 暗」。

## 3 条纹间距公式：Δx = λL/d

相邻亮纹（或暗纹）的间距 $\Delta x$ 由波长 $\lambda$、缝屏距 $L$、双缝间距 $d$ 决定：

$$\Delta x = \frac{\lambda L}{d}$$

**推导（近似）**：屏上第 $n$ 级亮纹到中央的距离 $x_n$，满足波程差 $\Delta r \approx \dfrac{x_n d}{L} = n\lambda$（小角度近似，$L \gg d$），所以 $x_n = \dfrac{n\lambda L}{d}$，相邻亮纹间距 $\Delta x = x_{n+1} - x_n = \dfrac{\lambda L}{d}$。

**公式解读**：

- **波长越大，条纹越宽**：$\Delta x \propto \lambda$。红光的条纹间距比紫光大（红波长长）。
- **双缝间距越小，条纹越宽**：$\Delta x \propto 1/d$。缝越窄，条纹分得越开。
- **缝屏距越大，条纹越宽**：$\Delta x \propto L$。屏越远，条纹越宽。
- **测波长**：已知 $L$、$d$，测 $\Delta x$，反推 $\lambda = \dfrac{\Delta x\,d}{L}$——这就是下一节实验的原理。<span class="marginnote">「用条纹间距测光波长」是杨氏实验最直接的回报：$\lambda = \Delta x\,d/L$——量出条纹间距、双缝间距、缝屏距，光的波长就出来了。杨当年用这个方法测出可见光波长在亚微米量级，与今天的精确值吻合。这个「用宏观测量（毫米级的条纹）推微观量（亚微米波长）」的间接测量，是实验物理的经典手法。</span>

**辨析｜易错点：** 条纹间距 $\Delta x$ 是「相邻亮纹」或「相邻暗纹」的间距，不是「亮纹到暗纹」的距离（那是 $\Delta x/2$）。读题时看清问的是亮纹间距还是亮暗距离。

## 4 光的干涉在生活中的体现

除了双缝，光的干涉在日常生活中随处可见：

**薄膜干涉**：肥皂泡、水面上油膜的彩色条纹，是薄膜**上下两个表面**反射的光相互干涉的结果——膜的厚度不同，两束反射光的波程差不同，不同波长（颜色）在厚薄不同处分别加强/减弱，呈现彩虹色。<span class="marginnote">肥皂膜的彩色是「薄膜干涉」：光打到薄膜上表面反射一部分、进入薄膜再从下表面反射一部分，两束反射光来自同一束光（相干），它们的波程差取决于薄膜厚度。膜厚均匀处，某颜色光波程差为整数波长则加强，呈现该颜色；不同厚度处颜色不同。所以肥皂膜越吹越薄、颜色不断变化——这是「干涉」在日常生活中最直观的展现。</span>
- **增透膜与增反膜**：在镜片、透镜表面镀一层薄膜，控制厚度使反射光干涉减弱（增透）或增强（增反）——相机镜头的淡紫色、太阳镜的反光，都与薄膜干涉有关。
- **干涉仪**：用光干涉测微小形变、折射率——精密测量。
- **牛顿环**：平凸透镜压在平板玻璃上，空气薄膜产生的环形干涉条纹。

**辨析｜易错点：** 薄膜干涉里「两束相干光」来自**同一个入射光**被薄膜上下表面分别反射——不是来自两个光源。只要膜够薄（与波长同量级），就能观察到干涉色。厚膜（远大于波长）干涉条纹过密，肉眼看不到彩色。

## 5 公式解析：Δx = λL/d

$$\Delta x = \frac{\lambda L}{d}$$

拆三步看：

- **第一步，波程差的几何**：屏上距中央 $x$ 的点，到两缝的距离差近似 $\Delta r = \dfrac{x\,d}{L}$（小角度近似：两缝间距 $d$ 远小于缝屏距 $L$，夹角很小）。这个「几何投影」把「空间位置 $x$」与「波程差 $\Delta r$」连起来。<span class="marginnote">推导的关键近似：$\Delta r \approx xd/L$。它由「相似三角形」给出——两缝到屏上一点的光程差，近似等于「缝间距 $d$ × 位置比例 $x/L$」。小角度下这个近似极其精确，是双缝干涉一切公式的几何基础。到大学你会用「光程」概念更严格地推它。</span>
- **第二步，亮纹位置**：$\dfrac{x_nd}{L} = n\lambda$ → $x_n = \dfrac{n\lambda L}{d}$——第 $n$ 级亮纹在 $x_n$ 处，$n = 0$ 是中央亮纹，$n = 1,2,\cdots$ 是第一、第二级。
- **第三步，间距**：$\Delta x = x_{n+1} - x_n = \dfrac{\lambda L}{d}$——等间距。$d$ 越小、$\lambda$ 越大、$L$ 越大，条纹越宽。
- **第四步，数值感受**：绿光 $\lambda = 5.5\times10^{-7}\ \text{m}$，双缝间距 $d = 0.5\ \text{mm} = 5\times10^{-4}\ \text{m}$，缝屏距 $L = 1\ \text{m}$，$\Delta x = \dfrac{5.5\times10^{-7}\times1}{5\times10^{-4}} = 1.1\times10^{-3}\ \text{m} = 1.1\ \text{mm}$——毫米级条纹，肉眼可见。光的波长极短，但「放大」到米级缝屏距后就看得清了。

## 6 辨析｜易错点

- **双缝产生相干光**：分波阵面法（同源分成两束），不是两个独立光源。
- **明暗判据**：$n\lambda$ 亮、$(2n+1)\lambda/2$ 暗（同相双缝）。
- **条纹间距**：$\Delta x = \lambda L/d$；相邻亮纹间距，不是亮到暗的距离。
- **中央是亮纹**：波程差为零，同相加强。
- **薄膜干涉**：上下表面反射光干涉，膜厚决定颜色。
- **普通光不干涉**（非相干）：两盏灯无稳定条纹；双缝把一束光分成相干两束。

## 7 小结

- **杨氏双缝实验**：分波阵面获相干光，屏上明暗相间的等间距条纹——光能干涉即光波。
- **明暗判据**：波程差 $n\lambda$ 亮、$(2n+1)\lambda/2$ 暗。
- **条纹间距**：$\Delta x = \lambda L/d$；波长越长条纹越宽。
- **测波长**：$\lambda = \Delta x\,d/L$。
- **薄膜干涉**：肥皂泡、油膜彩色，增透增反膜。
- 干涉证明光的波动性，是「光即是波」的决定性实验。

在下一节，我们用双缝干涉来测量光的波长：**实验：用双缝干涉测量光的波长**。量出条纹间距、双缝间距、缝屏距，代入 $\lambda = \Delta x\,d/L$——一束光，一把尺，测出亚微米的波长。
