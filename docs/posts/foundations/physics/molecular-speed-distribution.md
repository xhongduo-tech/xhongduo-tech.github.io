## 为什么从分子运动速率分布规律开始

上一节我们认识了分子的无规则运动。但「无规则」不等于「没有规律」——单个分子的运动是随机的，**大量**分子的运动却有确定的统计规律。气体中，分子的速率不是千篇一律，而是分布在从零到很大的范围内，且分布的形状由温度唯一决定——这叫**分子速率分布**。

这一节是「统计思想」在热学里的第一次正式登场：从「单个分子的偶然」到「大量分子的必然」。正是这种统计规律，让「温度」「压强」这些宏观量有了确定的微观意义——温度决定速率分布的形状，压强由大量分子碰撞器壁的统计效果决定。<span class="marginnote">「统计规律」是热学与力学最大的观念差别：力学关心「一个物体」的确定运动，热学关心「亿万个分子」的分布规律。单个气体分子碰撞器壁的力随机而微弱，但 $10^{23}$ 个分子的碰撞合力稳定而巨大——「大量 + 平均 = 确定」。这就是统计物理的核心思想，也是「为什么宏观热学如此稳定」的原因。</span>

学这一节，请抓住：**分子速率分布的图像与特点、温度对分布的影响、气体压强的微观解释**。

## 1 分子运动速率分布图像

对一定温度下的气体，统计大量分子的速率，画出「速率分布图像」：

**图像特征**：

- **横轴**：分子速率 $v$；**纵轴**：处于该速率附近的分子数（或比例）。
- **图像形状**：中间高、两边低的「钟形」分布——速率很小和很大的分子都少，多数分子在某个「最概然速率」附近。
- **不对称**：低速率侧较陡、高速率侧拖尾（速率可以很大，但很少）。
- **分布连续**：速率分布是连续的曲线（不是离散的几条）。

**麦克斯韦速率分布**：气体分子的速率分布由麦克斯韦在 1859 年从理论上导出，实验（斯特恩实验）完全证实。速率分布曲线 $f(v)$ 描述「单位速率间隔内的分子比例」——曲线下的面积 = 分子总数（或总比例）。<span class="marginnote">「钟形分布」的三个速率值得分清：<strong>最概然速率 $v_p$（分布峰值处的速率，最多分子在此附近）、平均速率 $\bar v$、方均根速率 $\sqrt{\overline{v^2}}$</strong>。三者关系：$v_p < \bar v < \sqrt{\overline{v^2}}$（高速率侧拖尾把平均拉高）。分子平均动能看的是「方均根速率」（$\overline{E_k} = \tfrac12 m\overline{v^2}$）——所以算动能要用速度平方的平均，不是平均速率。</span>

## 2 温度与速率分布

**温度升高，速率分布如何变化**：

- **峰值（最概然速率）向高速方向移动**：温度高，分子平均速率大。
- **曲线变「矮」变「宽」**：分布更分散，高速分子比例增大。
- **曲线下面积不变**：分子总数不变，曲线下面积恒为总分子数。

**关键结论**：**温度是分子平均动能的量度**——温度越高，分子平均动能越大、平均速率越大、高速分子比例越高。<span class="marginnote">「温度 = 分子平均动能的标志」是热学最重要的定性结论：$T$ 越高，$\overline{E_k}$ 越大。注意是「平均动能」不是「平均速率」——不同分子质量不同，同样温度下平均动能相同（$\tfrac32 kT$），但轻分子平均速率大、重分子平均速率小。所以「温度相同则分子平均动能相同、平均速率不一定相同」——氢气分子比氧气分子跑得快，但平均动能一样。</span>

**辨析｜易错点：** 温度是**分子平均动能**的量度，不是「分子平均速率」的量度（不同分子质量不同）、也不是「单个分子动能」的量度（单个分子动能随机）。「温度高则每个分子都快」是错的——温度只决定「平均」，单个分子的速率仍在很大范围内随机分布。少数分子的速率即使在低温下也可能很大。

## 3 气体压强的微观解释

**气体压强**：气体对器壁的压强，是**大量气体分子频繁撞击器壁**产生的。

**微观机制**：气体分子做无规则运动，不断碰撞器壁——每个分子的撞击给器壁一个冲量；大量分子持续碰撞，宏观上表现为**持续、稳定的压力**。压强 = 单位面积器壁受到的平均撞击力。

**影响压强的两个微观因素**：

1. **分子撞击的频繁程度**（与分子数密度 $n$ 成正比）：分子越多越密，撞击越频繁，压强越大。
2. **分子撞击的强度**（与分子平均动能成正比）：温度越高，分子平均动能越大，撞击越猛，压强越大。

**定性关系**：$p \propto n \cdot \overline{E_k}$——压强与分子数密度、分子平均动能成正比。

**辨析｜易错点：** 气体压强是「大量分子碰撞」的宏观效果，不是「分子间的相互作用力」——气体分子间距大、分子力可忽略，压强完全来自碰撞。<span class="marginnote">「压强是碰撞的统计效果」可以这样感受：一个分子撞器壁的力极小、且时有时无；但 $10^{23}$ 个分子每时每刻都有大量在撞器壁，平均下来压力恒定。所以气体压强「恒定」不是「每次碰撞一样」，而是「大量碰撞的平均稳定」。真空里没有分子、没有碰撞、没有压强——「真空」就是「没有气体的空间」。</span>

## 4 从微观到宏观：温度与压强的关系

综合前几节，宏观量与微观量的对应：

| 宏观量 | 微观解释 |
| --- | --- |
| 温度 $T$ | 分子平均动能的量度（$\overline{E_k} \propto T$） |
| 压强 $p$ | 分子碰撞器壁的统计效果（$p \propto n\overline{E_k}$） |
| 体积 $V$ | 气体分子可自由活动的空间 |
| 内能 | 分子动能 + 分子势能的总和 |

**气体实验定律的微观解释**（下一章会定量展开）：

- **等温变化**（温度不变，$\overline{E_k}$ 不变）：体积增大 → 分子数密度 $n$ 减小 → 碰撞频率降低 → 压强减小。$pV = \text{常数}$（玻意耳定律）。
- **等容变化**（体积不变，$n$ 不变）：温度升高 → $\overline{E_k}$ 增大 → 碰撞更强 → 压强增大。$p/T = \text{常数}$（查理定律）。<span class="marginnote">「宏观定律的微观解释」是分子动理论的价值：玻意耳定律（$pV$ 常数）的微观图景是「温度不变 → 分子平均动能不变 → 体积增大 → 分子变稀 → 撞得少 → 压强变小」。把宏观实验定律「翻译」成微观碰撞图景，热学就「懂了」——下一章《气体》会把这些定律系统化。</span>

## 5 公式解析：平均动能与温度

分子平均动能与温度的关系（理想气体）：

$$\overline{E_k} = \frac{3}{2}kT$$

其中 $k$ 是**玻尔兹曼常量**：

$$k = 1.38\times10^{-23}\ \text{J/K}$$

拆三步看：

- **第一步，来源**：由气体动理论推导，分子平均平动动能 = $\tfrac32 kT$——温度越高，平均动能越大（线性关系）。$k$ 是「温度 → 能量」的换算常数。<span class="marginnote">「$k$ 是温度与能量的桥梁」：$k = R/N_A$（气体常量 ÷ 阿伏加德罗常数）——1 K 的温度对应每个分子约 $1.38\times10^{-23}$ J 的平均动能。玻尔兹曼常量让「温度」与「分子能量」直接挂钩：室温（约 300 K）下分子平均动能约 $6\times10^{-21}$ J，约 0.04 eV。这个「能量标尺」贯穿整个统计物理。</span>
- **第二步，为什么是 $\tfrac32$**：分子有 x、y、z 三个平动自由度，每个自由度贡献 $\tfrac12 kT$，三个方向共 $\tfrac32 kT$（能量均分定理的雏形）。$\tfrac12 kT$ 是「每个平动自由度」的平均动能。
- **第三步，与平均速率的关系**：$\overline{E_k} = \tfrac12 m\overline{v^2} = \tfrac32 kT$，所以方均根速率 $\sqrt{\overline{v^2}} = \sqrt{\dfrac{3kT}{m}}$——轻分子方均根速率大。
- **第四步，量级感受**：室温（300 K）下空气分子（质量约 $4.8\times10^{-26}$ kg）方均根速率 $\sqrt{3\times1.38\times10^{-23}\times300/4.8\times10^{-26}} \approx 500\ \text{m/s}$——空气分子平均每秒跑 500 米（但碰撞频繁、净位移很小）。

## 6 辨析｜易错点

- **速率分布是统计规律**：单个分子速率随机，大量分子分布确定。
- **温度 = 分子平均动能**：不是平均速率、不是单个分子动能。
- **压强来自碰撞**：$p \propto n\overline{E_k}$，与分子数密度和平均动能成正比。
- **温度相同平均动能相同**：不同分子平均速率不同（轻快重慢）。
- **分布曲线下面积不变**：总分子数不变；温度升高曲线变宽变矮。
- **最概然速率 < 平均速率 < 方均根速率**：拖尾把平均拉高。

## 7 小结

- **分子速率分布**：钟形分布，中间多两头少、高速端拖尾。
- **温度影响**：温度升高 → 峰值移向高速、曲线变宽变矮、高速分子增多。
- **温度 = 分子平均动能**：$\overline{E_k} = \tfrac32 kT$。
- **气体压强**：大量分子碰撞器壁的统计效果，$p \propto n\overline{E_k}$。
- **玻尔兹曼常量**：$k = 1.38\times10^{-23}\ \text{J/K}$，温度与能量的桥梁。
- 宏观热学 = 微观分子运动的统计平均——统计思想登场。

在下一节，我们研究分子的能量：**分子动能和分子势能**。内能是分子动能与势能的总和——温度决定动能、体积（分子距离）决定势能，内能的这两个来源将引出热力学的能量语言。
