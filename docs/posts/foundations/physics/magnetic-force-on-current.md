## 为什么从磁场对通电导线的作用力开始

前几章我们认识了磁场的描述（$B$、$\Phi$）与电场的能量。现在回到「力」：**磁场对通电导线有力的作用**。这个力叫**安培力（Ampère force）**，它是电动机、扬声器、电流计、电磁炮等一切「电生力」装置的基础。奥斯特 1820 年发现电生磁，安培紧接着发现磁对通电导线有力的作用——电磁学的力学时代由此开启。

这一节是电磁学与力学的又一次结合：安培力的大小 $F = BIL\sin\theta$、方向用**左手定则**判断。它把第三章的磁场（$B$）与第十二章的电流（$I$）连接成一个「力」，而「力」将驱动真实的机械运动——电动机。理解安培力，等于理解「电如何变成机械运动」。<span class="marginnote">安培力是「磁场 × 电流」的产物：电流的本质是运动电荷，磁场对运动电荷有力的作用（洛伦兹力，下一节），大量电荷的洛伦兹力宏观上就是安培力。安培力 $F = BIL$ 可以从洛伦兹力 $F = qvB$ 推导出来：$I = nqSv$，导线中所有电荷受力加起来就是 $BIL$。「微观的洛伦兹力 → 宏观的安培力」，两条公式同源。</span>

学这一节，请掌握三件事：**安培力的大小公式、左手定则判断方向、安培力做功与能量转化**。

## 1 安培力的方向：左手定则

**安培力**：通电导线在磁场中受到的力。

**安培力的方向用左手定则判断**：

伸开左手，让**磁感线穿入手心**，**四指指向电流方向**，**大拇指所指的方向就是安培力的方向**。

**关键**：安培力的方向**垂直于磁场方向与电流方向所确定的平面**——即 $F \perp B$ 且 $F \perp I$。<span class="marginnote">左手定则的要点：<strong>「磁感线穿手心、四指指电流、拇指指受力」</strong>。三个方向（$B$、$I$、$F$）两两垂直（$F$ 垂直 $B$ 与 $I$ 决定的平面）。易错点：磁场方向与电流方向平行时，安培力为零——左手定则此时「找不到力」；磁场与电流不垂直时，力仍垂直两者平面，大小为 $BIL\sin\theta$。</span>

**辨析｜易错点：** 安培力**垂直**磁场与电流所在平面——所以安培力的方向可能与电流方向、磁场方向都不相同。若电流方向与磁场方向平行（$\theta = 0$），安培力为零（左手定则的手势失效）。「安培力一定垂直电流」对，「安培力一定垂直磁场」也对——它垂直于两者决定的平面。

## 2 安培力的大小：F = BILsinθ

在匀强磁场中，长为 $L$ 的通电直导线，电流 $I$ 与磁场方向夹角 $\theta$：

$$F = BIL\sin\theta$$

**特殊情形**：

- **电流方向垂直磁场**（$\theta = 90°$）：$F = BIL$（安培力最大）。
- **电流方向平行磁场**（$\theta = 0°$ 或 $180°$）：$F = 0$（不受力）。
- **一般夹角**：$F = BIL\sin\theta$——只有「垂直磁场的电流分量」$I\sin\theta$ 或「垂直电流的磁场分量」$B\sin\theta$ 参与。

**辨析｜易错点：** 公式里 $L$ 是**有效长度**——「在磁场中的那段直导线的长度」，且是「垂直于磁场的投影」。若导线是弯曲的，$L$ 取「连接两端的直线（等效长度）」；若导线部分在磁场外，只取磁场中的部分。把「整根导线长」当 $L$ 代入是常见错误。<span class="marginnote">「有效长度」的严格定义：通电导线的安培力，等于「首尾连线（等效直导线）」在磁场中受的力。弯曲导线可用「连接两端的直线段」等效——因为安培力的合力只取决于首尾位置与磁场。这个「等效长度」技巧在求任意形状导线的安培力时非常有用：画一条从起点到终点的直线，就用它的长度与方向。</span>

## 3 安培力的应用：电动机与电流计

安培力把电能转化为机械能，最典型的是**电动机**：

**电动机原理**：通电线圈在磁场中受到安培力的力矩作用而转动。

- 线圈在磁场中，两边导体的电流方向相反，受到的安培力方向相反，形成**力矩**，使线圈转动。
- 线圈转到平衡位置（力臂为零）时，用**换向器**改变电流方向，让力矩继续同向——线圈持续转动。
- 直流电动机：换向器在每半圈换向，维持连续旋转。

**安培力与能量转化**：电动机输入电能，输出机械能——安培力做正功把电能转化为动能；同时线圈中因转动产生反电动势（电磁感应），限制电流大小（呼应第十二章电动机模型）。<span class="marginnote">电动机的本质是「安培力做功」：通电线圈在磁场中受力矩转动，安培力对线圈做正功，电能转化为机械能。但线圈转动又切割磁感线、产生反电动势——这正是「非纯电阻电路」的物理根源（第十二章电动机题）。安培力做功 + 反电动势，两条线索在电动机里汇合。扬声器也是安培力的应用：音频电流流过音圈，在磁场中受力振动，推动纸盆发声。</span>

**电流计（表头）**：灵敏电流计的原理也是安培力——通电线圈在磁场中受安培力矩偏转，偏转角与电流成正比，指针指示电流大小。它是电流表、电压表、万用表的「心脏」——你在第十一章改装电表时用的「表头」，就是安培力驱动的装置。

## 4 安培力与洛伦兹力的联系

安培力与洛伦兹力是「宏观与微观」的关系：

- **洛伦兹力**：磁场对单个运动电荷的力（下一节），$F = qvB\sin\theta$。
- **安培力**：磁场对通电导线的力，是导线中所有电荷受洛伦兹力的**宏观总和**。

**推导**：导线中电流 $I = nqSv$（$n$ 为电荷数密度、$S$ 为截面积、$v$ 为定向移动速度），导线长 $L$，则电荷总数 $N = nSL$，每个电荷受洛伦兹力 $qvB$（垂直时），总力 $F = NqvB = nSL\cdot qvB = (nqSv)LB = BIL$——**安培力 = 洛伦兹力的宏观体现**。<span class="marginnote">「微观洛伦兹力相加得宏观安培力」是电磁学最漂亮的桥梁之一：$F = BIL$ 从 $F = qvB$ 推导而来，两者本质是同一个力。这解释了为什么「电流垂直磁场」时安培力最大——电荷定向移动方向垂直磁场时洛伦兹力最大。宏观与微观的对应，让电磁学成为「微观机理可证」的学科。</span>

## 5 公式解析：F = BILsinθ

$$F = BIL\sin\theta$$

拆三步看：

- **第一步，$\sin\theta$ 的角色**：$\theta$ 是电流方向与磁场方向的夹角。$\sin\theta$ 提取「垂直分量」——只有垂直于磁场方向的电流分量才受力。$\theta = 90°$ 时 $\sin\theta = 1$，力最大；$\theta = 0°$ 时力为零。<span class="marginnote">与磁场中其他力的公式对比：洛伦兹力 $F = qvB\sin\theta$、安培力 $F = BIL\sin\theta$——同一个「$\sin\theta$ 取垂直分量」的结构。凡是「两个方向量之间的作用力」，都取「垂直分量」。这个「$\sin\theta$ 取垂直」的模式，在电磁力里反复出现，是通用判据。</span>
- **第二步，$L$ 是有效长度**：弯曲导线取首尾连线长度；只在磁场中的部分才计入。若导线部分在磁场外，$L$ 只算磁场内的等效长度。
- **第三步，单位与量纲**：$F$（N）= $B$（T）× $I$（A）× $L$（m），$1\ \text{T} = 1\ \text{N}/(\text{A·m})$——特斯拉的定义正来自 $F = BIL$（垂直时）。量纲 $[M][L][T]^{-2}$ 正确。
- **第四步，应用方向判断**：先定 $B$ 方向与 $I$ 方向，用左手定则判 $F$ 方向；大小用 $F = BIL\sin\theta$。方向与大小分开处理，是电磁力题的标准动作。

## 6 辨析｜易错点

- **左手定则 vs 右手定则**：安培力方向用**左手**；电流产生磁场用**右手**（安培定则）。「一左一右」分清用途。
- **安培力垂直 $B$ 与 $I$ 所在平面**：不是「一定沿某个方向」——用左手定则判，别猜。
- **电流平行磁场则力为零**：$\theta = 0°$ 时 $F = 0$。
- **$L$ 是有效长度**：磁场中部分、弯曲取等效直线。
- **安培力可以不做功**：若导线固定不动，安培力不做功（力作用点无位移）——安培力做功与否取决于导线是否运动。
- **电动机是安培力做功 + 反电动势**：非纯电阻，用「总功率 − 热功率」求机械功率。

## 7 小结

- **安培力**：磁场对通电导线的作用力，$F = BIL\sin\theta$。
- **方向**：左手定则（磁感线穿手心、四指指电流、拇指指受力）；$F \perp B$ 且 $F \perp I$。
- 电流垂直磁场力最大，平行磁场力为零。
- **有效长度**：磁场中部分、弯曲取等效直线。
- **微观本质**：安培力 = 大量电荷洛伦兹力的宏观总和。
- **应用**：电动机（换向器连续转动）、电流计、扬声器、电磁炮。

在下一节，我们研究磁场对单个运动电荷的力：**磁场对运动电荷的作用力**。洛伦兹力 $F = qvB$——它让带电粒子在磁场中做圆周运动，是质谱仪、回旋加速器、极光的物理基础。
