## 为什么从电路中的能量转化开始

第八章我们建立了机械能的能量守恒，第十一章我们建立了电路的电学量（电流、电压、电阻）。这一节把两者合流：**电流通过电路时，电能如何转化为热、光、机械能**。核心人物是**焦耳**——他用几十年的实验确立「电流生热」的定量规律，也为能量守恒定律提供了最后的拼图。

这一节要掌握三组公式：**电功 $W = UIt$、电功率 $P = UI$、焦耳定律 $Q = I^2Rt$**。它们看似简单，却藏着一个经典陷阱：**电功 $W = UIt$ 对一切电路成立，而 $W = I^2Rt = U^2t/R$ 只对纯电阻电路成立**。这个区别，是本节乃至整个电学最大的失分点之一。<span class="marginnote">焦耳（1818—1889）是英国自学成才的物理学家，他花二十年用精密的量热实验证明「电流生热 $Q \propto I^2R$」并测定了热功当量。他的工作与迈耶、亥姆霍兹一起确立了能量守恒定律——恩格斯称之为「19 世纪三大发现」之一。这一节学的不只是公式，更是能量守恒思想在电路里的落地。</span>

学这一节，始终带着一个问题：**电流做的功，变成了什么？** 全部变热（纯电阻），还是部分变热部分变机械能/化学能（电动机、充电电池）？答案决定用哪套公式。

## 1 电功与电功率

电流通过一段电路时，电场力对电荷做功，把电能转化为其他形式的能量。**电功**是电流做功的多少：

$$W = UIt$$

其中 $U$ 是电路两端的电压，$I$ 是电流，$t$ 是通电时间。单位焦耳（J）。**电功公式对任何用电器都成立**——只要电流流过两端电压为 $U$ 的器件，$UIt$ 就是电场力做的总功（电能转化的总量）。

**电功率**是电流做功的快慢：

$$P = \frac{W}{t} = UI$$

单位瓦特（W）。电功率同样对任何电路成立。<span class="marginnote">$W = UIt$ 的来历：电流 $I = q/t$，则 $q = It$，电场力做功 $W = qU = UIt$——「电荷量 × 电压」就是「搬运这些电荷消耗的能量」。这与第十一章 $W_{AB} = qU_{AB}$ 一脉相承：电场力做功 = 电荷量 × 电势差。电路的电压把这条静电场公式变成了「电流 × 时间」的表达。</span>

生活中电器的「额定功率」：电灯泡 60 W、电吹风 1000 W、空调 2000 W——都是在额定电压下工作的电功率。电费按「度」计：$1\ \text{度} = 1\ \text{kW·h} = 3.6\times10^6\ \text{J}$。一台 1000 W 的电器开 1 小时耗电 1 度。

## 2 焦耳定律：纯电阻电路的发热

电流通过导体时，导体发热——把电能转化为内能。**焦耳定律**给出发热量：

$$Q = I^2Rt$$

其中 $Q$ 是热量（焦耳），$I$ 是电流，$R$ 是电阻，$t$ 是时间。焦耳定律对任何导体成立（只要有电阻就有焦耳热）。

**纯电阻电路**：电能全部转化为内能（如电热器、白炽灯、电炉丝），此时电功 = 热量：

$$W = Q$$

由 $W = UIt$ 与 $Q = I^2Rt$ 联立，并利用欧姆定律 $U = IR$，可得纯电阻电路中电功的两种等价形式：

$$W = \frac{U^2}{R}t = I^2Rt, \qquad P = \frac{U^2}{R} = I^2R$$

**关键**：这三个形式（$UI$、$U^2/R$、$I^2R$）**只有在纯电阻电路中才全部成立**，因为它们用到了欧姆定律 $U = IR$。<span class="marginnote">记忆线索：纯电阻电路里 $U = IR$，所以 $UI = I^2R = U^2/R$ 三者相等。非纯电阻电路里 $U > IR$（因为还要克服反电动势），三者不相等。判断一个电路是否纯电阻，看它「电能是否只转化为热」——电热器是，电动机不是。</span>

## 3 非纯电阻电路：电动机与充电电池

**非纯电阻电路**：电能不仅转化为热，还转化为其他形式的能量——电动机（电能 → 机械能 + 热）、充电电池（电能 → 化学能 + 热）、电解槽（电能 → 化学能）。此时：

**电功** $W = UIt$：电场力做的总功（总电能消耗）。
**焦耳热** $Q = I^2Rt$：转化为内能的部分。
**其他形式的能**（机械能、化学能）：$W - Q = UIt - I^2Rt$。

对电动机：输入的电功率 $P = UI$，发热功率 $P_{\text{热}} = I^2R$，输出机械功率 $P_{\text{机}} = UI - I^2R$。<span class="marginnote">电动机模型是「反电动势 + 电阻」：转子转动时切割磁感线，产生一个与电源电压相反的电动势（反电动势 $E_{\text{反}}$），于是电流 $I = (U - E_{\text{反}})/R$，比纯电阻时小。输出功率 $P_{\text{机}} = E_{\text{反}}I$——反电动势越大，电流越小、效率越高。这正是「电动机刚启动时电流特别大」的原因：转速为零、$E_{\text{反}} = 0$，电流 $= U/R$ 巨大。</span>

**辨析｜易错点：** 非纯电阻电路里，**$U \neq IR$，$UI \neq I^2R$**。用「总功率 - 热功率」求其他功率是唯一正确的方法。常见错误：把 $P = U^2/R$ 套到电动机上求输出功率——错了，$U^2/R$ 是「若它是纯电阻」的虚拟值，不是真实的热功率。**判定流程：先问「电能是否只变热」——是，用纯电阻公式；否，用 $P = UI$ 与 $P_{\text{热}} = I^2R$ 分开算**。

举例：电动机额定电压 $U = 220\ \text{V}$，电流 $I = 10\ \text{A}$，内阻 $R = 2\ \Omega$。总功率 $P = 220\times10 = 2200\ \text{W}$；热功率 $P_{\text{热}} = 10^2\times2 = 200\ \text{W}$；机械功率 $P_{\text{机}} = 2200 - 200 = 2000\ \text{W}$；效率 $\eta = 2000/2200 \approx 91\%$。注意这里**不能**用 $U^2/R = 220^2/2 = 24200\ \text{W}$——那是个荒谬的「假功率」，因为 $U \neq IR$。

## 4 公式解析：纯电阻与非纯电阻的分野

$$W = UIt \ (\text{普适}), \qquad Q = I^2Rt \ (\text{普适}), \qquad W = I^2Rt = \dfrac{U^2}{R}t \ (\text{仅纯电阻})$$

拆三步看：

- **第一步，两条普适公式**：$W = UIt$（电场力做功，任何电路成立）、$Q = I^2Rt$（电流生热，任何导体成立）。它们不依赖欧姆定律，所以无脑成立。做题时先写这两条，永远不错。
- **第二步，什么时候 $W = Q$**：只有「电能全部变热」才成立。纯电阻电路（电热器、灯丝近似）满足；电动机、电池充电时不满足。判断依据是「电路中有没有非热形式的能量转化」。
- **第三步，$U^2/R$ 与 $I^2R$ 的来历**：在 $W = UIt$ 中代入欧姆定律 $U = IR$，得到 $W = I^2Rt$；或 $I = U/R$，得到 $W = U^2t/R$。**每一步推导都用了 $U = IR$，所以这些形式是欧姆定律的「专属特权」，只在纯电阻下合法**。<span class="marginnote">把欧姆定律看成「桥梁」：$U$、$I$、$R$ 三者知道任意两个，第三个就由欧姆定律锁定。纯电阻电路中三个量被桥连，所以 $UI$、$I^2R$、$U^2/R$ 三个功率表达式互相等价。非纯电阻电路里桥断了（$U \neq IR$），三个表达式各管一摊，不能再混用。</span>
- **第四步，效率与实际问题**：电动机效率 $\eta = P_{\text{机}}/P = 1 - IR/U$。减少内阻 $R$ 能同时减小热损耗、增大反电动势占比，是提高电机效率的根本途径。

## 5 电路中的能量守恒全景

把前几节串起来，电路的能量守恒可以写成一张「账本」：

**电源提供的电能 = 外电路消耗的电能 = 各用电器转化的能量之和**

对完整回路：电源非静电力做功 $W = Eq$（$E$ 为电动势），把化学能/机械能转化为电能；电能在外电路被电阻（内能）、电动机（机械能）、电池（化学能）、灯泡（光能+内能）分配。**能量守恒在电路里的表达式**：

$$EIt = I^2(R + r)t$$

其中 $EIt$ 是电源提供的总电能，$I^2Rt$ 是外电路电阻耗能，$I^2rt$ 是电源内阻耗能（下一节闭合电路欧姆定律会严格证明）。<span class="marginnote">这张「账本」提示了电路分析的另一种视角：不只看电流电压，还要看能量去向。能量视角的好处是「不管电路多复杂，账总能算平」——所有电能必有所归。到热力学（选择性必修三）你会看到，这种「能量有明确去向」的思想是热力学第一定律的电路版。</span>

实际电路中，灯泡把电能转化为光能（约 10%）与内能（约 90%），电动机把电能转化为机械能为主，电热器全部转化为内能——**效率最高的用电器是把能量转化为你最想要的形式的比例最高的那个**。

## 6 辨析｜易错点

- **电功与电热的区别**：电功 $W = UIt$ 是「总账」，电热 $Q = I^2Rt$ 是「热账」。纯电阻中两者相等，非纯电阻中 $W > Q$。把「电功等于电热」当普适结论，是本节最大的错误。
- **$U^2/R$ 与 $I^2R$ 只用于纯电阻**：非纯电阻电路（电动机）求热功率用 $I^2R$、求总功率用 $UI$、求机械功率用 $UI - I^2R$。绝不能用 $U^2/R$ 求任何功率。
- **额定功率 vs 实际功率**：电器标的是额定电压下的功率；实际电压不同，实际功率按 $P = U^2/R$（纯电阻）或实际工况算。「额定功率是恒定的」是错误理解——额定只是标称值。
- **千瓦时是能量不是功率**：$1\ \text{度} = 1\ \text{kW·h} = 3.6\times10^6\ \text{J}$。「度」是能量单位，不是功率单位。说「一小时用了一度电」等于说「用了一千瓦时能量」。
- **电动机启动电流大**：启动瞬间反电动势为零，$I = U/R$ 很大。正常运行后反电动势建立，电流减小。「启动电流小」是错误直觉。

## 7 小结

- **电功**：$W = UIt$，对任何电路成立；**电功率**：$P = UI$。
- **焦耳定律**：$Q = I^2Rt$，对任何导体成立。
- **纯电阻电路**：$W = Q$，$P = UI = I^2R = U^2/R$（三个表达式等价）。
- **非纯电阻电路**（电动机、充电电池）：$P = UI$，$P_{\text{热}} = I^2R$，$P_{\text{其他}} = UI - I^2R$。
- **效率**：$\eta = P_{\text{有用}}/P_{\text{总}}$；电能转化的能量形式由用电器类型决定。
- **能量守恒**：电源提供的电能 = 外电路 + 内阻消耗的电能，账必平。

在下一节，我们把电源内阻纳入电路：**闭合电路的欧姆定律**。电动势、内阻、路端电压——电源不再是「理想电压源」，而是有内阻的「真实电源」，这解释了为什么用电器多了电压会「掉」。
