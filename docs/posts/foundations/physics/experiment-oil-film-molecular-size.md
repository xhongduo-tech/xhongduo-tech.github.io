## 为什么从用油膜法估测油酸分子的大小开始

上一节我们用阿伏加德罗常数**估算**了分子大小（约 $10^{-10}$ m）。这一节用实验**直接测量**：把一滴油酸滴在水面上，油酸会**在水面自动展开成一层单分子膜**——油酸分子的亲水端扎进水里、疏水端露在外面，整齐地「肩并肩」铺成一层。测出这层膜的厚度，就是油酸分子的直径。

「油膜法」是物理实验里最优雅的测量之一：**用一个宏观可测的量（油膜面积）反推一个微观不可测的量（分子直径）**。你不需要显微镜，只需要一滴油酸、一盆水、一把刻度尺，就能量出 $10^{-10}$ 米级的分子大小。<span class="marginnote">「油酸为什么能铺成单分子膜？」因为油酸分子是「两亲」的——一端是羧基（亲水，喜欢水）、另一端是碳氢链（疏水，不喜欢水）。滴在水面上，亲水端扎进水里、疏水端翘在水面上，分子垂直水面「站」成一排。油酸不溶于水、且会扩散开——直到铺满水面成为单层分子膜（厚度恰好是一个分子）。这个「自动铺成单分子层」的性质，让分子直径 = 膜厚度。</span>

学这一节，请抓住：**实验原理（单分子膜 → 体积/面积 = 厚度 = 分子直径）、操作步骤、误差分析**。

## 1 实验原理

**油膜法原理**：把油酸滴在水面上，油酸在水面**展开成单分子油膜**。油膜是「一层分子厚」的，所以油膜的厚度 = 油酸分子的直径。

设滴入水面的油酸体积为 $V$，油膜面积为 $S$，油膜厚度（分子直径）：

$$d = \frac{V}{S}$$

**关键前提**：

1. **油膜是单分子层**：油酸在水面自动展开成一层分子（厚度 = 一个分子直径）。
2. **油膜铺满但不重叠**：油酸分子紧密排列、单层覆盖。
3. **体积 $V$ 已知、面积 $S$ 可测**：油酸体积由配制好的油酸溶液算出，面积用「数方格」测。

**辨析｜易错点：** 公式 $d = V/S$ 的 $V$ 是**纯油酸的体积**，不是「油酸溶液」的体积。实验中用的是「油酸溶于酒精的稀溶液」（油酸占一定体积分数），滴入水中的是溶液——酒精溶于水并挥发，留在水面的只有油酸。**$V$ 必须换算成纯油酸的体积**：$V_{\text{油酸}} = V_{\text{溶液}} \times \text{体积分数}$。<span class="marginnote">「为什么要用油酸酒精溶液而不是纯油酸？」纯油酸一滴太大（直接铺成多层），而把油酸按 $1/1000$ 的比例溶进酒精，滴一小滴溶液，其中油酸只有 $10^{-5}$ mL 量级，正好能铺成一层分子膜。酒精的作用是「稀释 + 铺展载体」——它溶于水、把油酸「带开」后自己消失。测出溶液中油酸的体积分数，滴入的体积 × 分数 = 纯油酸体积。</span>

## 2 实验步骤

**器材**：油酸酒精溶液（如油酸:酒精 = 1:1000）、注射器（滴管）、浅盘、水、痱子粉（撒粉）、玻璃板、坐标纸（方格纸）、刻度尺。

**步骤**：

1. **配溶液、定浓度**：配制油酸酒精溶液，记录油酸体积分数（如 1/1000）。
2. **测一滴溶液的体积**：用注射器滴出 $N$ 滴（如 50 滴）溶液，测总体积，算一滴体积 $V_{\text{滴}} = \text{总体积}/N$。
3. **撒粉**：浅盘装水，水面均匀撒一层薄薄的痱子粉（描出油膜边界）。
4. **滴油酸**：用注射器在水面中央滴一滴油酸溶液，油酸展开、酒精溶于水挥发，水面留下油膜（痱子粉被推开形成边界）。
5. **描膜**：待油膜稳定，用玻璃板盖在浅盘上，描出油膜边界。
6. **测面积**：把描好的油膜轮廓放在坐标纸上，数「完整格子 + 半格以上算一格」得面积 $S$。
7. **算直径**：$d = V_{\text{油酸}}/S$，其中 $V_{\text{油酸}} = V_{\text{滴}} \times \text{体积分数}$。

**辨析｜易错点：** 面积用「数方格」法：完整格子直接数，不足半格的舍去、超过半格的算一格——这个「半格取舍」规则决定面积测量精度。油膜边界不规则，数方格是最实用的面积测量法。<span class="marginnote">「数方格算面积」是物理测量不规则面积的标准方法：把轮廓印在坐标纸上，数格子。完整格直接算，不满半格的舍、超过半格的进——误差大约在「一个格子」量级。格子越小（坐标纸越细）误差越小。这个「以直代曲、数格子」的方法，在中学实验里反复出现（测不规则叶片面积、测压强曲线下面积）。</span>

## 3 数据处理与结果

**示例**：

油酸溶液体积分数：1/1000。
50 滴溶液总体积 1.0 mL → 一滴溶液 $V_{\text{滴}} = 0.02\ \text{mL} = 2\times10^{-8}\ \text{m}^3$。
纯油酸体积：$V = 2\times10^{-8}\times\dfrac{1}{1000} = 2\times10^{-11}\ \text{m}^3$。
油膜面积（数方格）$S = 0.06\ \text{m}^2$（约 600 cm²）。
分子直径：$d = \dfrac{V}{S} = \dfrac{2\times10^{-11}}{0.06} \approx 3.3\times10^{-10}\ \text{m}$。

**结果**：$3.3\times10^{-10}\ \text{m}$ = 0.33 nm——在 $10^{-10}$ m 量级，与已知分子大小一致。实验成功（数量级正确）。<span class="marginnote">「数量级正确即成功」是油膜法的验收标准：分子直径的测量值不必精确到小数，只要在 $10^{-10}$ m 量级（0.2–0.5 nm），实验就「成功」了。因为油膜法的误差本身就大（数格子、单分子层假设的近似），它的价值是「确定数量级」而非「精确测量」。这也是物理实验的常见态度：不同的实验目的对应不同的精度要求。</span>

## 4 误差分析

**误差来源**：

**油膜不是严格的单分子层**：油酸分子不是理想排列，可能有重叠或间隙——厚度偏大或偏小。
**酒精的影响**：酒精未完全溶于水/挥发，或油酸被酒精带走——体积偏差。
**面积测量误差**：数格子、描边界的误差（主要误差源之一）。
**一滴体积的测量**：滴管滴数、体积读数的误差。
**油膜边界不稳定**：风、振动、表面张力变化使油膜变形。

**误差方向**：若油膜有多层（重叠），面积偏小 → $d = V/S$ 偏大；若油酸损失（部分被酒精带走），$V$ 偏小 → $d$ 偏小。$d$ 的量级（$10^{-10}$ m）不受这些误差影响，但精确值有波动。

把误差来源与方向整理成表：

| 误差来源 | 对 $d = V/S$ 的影响 |
| --- | --- |
| 油膜多层（重叠） | $S$ 偏小 → $d$ 偏大 |
| 油酸损失（被酒精带走） | $V$ 偏小 → $d$ 偏小 |
| 面积数格误差 | $S$ 不准 → $d$ 不确定 |
| 一滴体积测量误差 | $V$ 不准 → $d$ 不确定 |

看表就明白：**$d$ 的数量级（$10^{-10}$ m）很稳，但精确值有波动**。所有误差都来自「单分子层假设」与「测量」的近似，实验的目标是「数量级正确」。<span class="marginnote">「主要误差是面积测量」是油膜法的特点：$d = V/S$ 中 $V$ 是已知量（溶液浓度 × 滴体积，较准），$S$ 靠数格子（人眼判断、边界模糊）误差最大。所以实验的关键是「把边界画准、把格子数对」。这再次印证「误差大的环节多用心」——面积是精度瓶颈，值得花时间。</span>

## 5 公式解析：d = V/S

$$d = \frac{V}{S}$$

拆三步看：

- **第一步，为什么厚度 = 直径**：油膜是「单分子层」——油酸分子垂直水面紧密排列，膜的厚度恰好是一个分子的长度（直径）。所以「膜的厚度」这个宏观量，数值上等于「分子直径」这个微观量。<span class="marginnote">「单分子膜假设」是整个实验的灵魂：油膜必须恰好一层分子，厚度才是分子直径。若铺成两层，厚度 = 两个分子直径，算出的 $d$ 偏大一倍。实验通过「用很稀的溶液、控制滴量」保证单层——滴多了就多层、滴少了膜不完整。找到「刚好铺满水面的量」是实验的微妙之处。</span>
- **第二步，体积的换算**：$V = V_{\text{滴}} \times \text{体积分数}$——把「溶液体积」换算成「纯油酸体积」。$V_{\text{滴}}$ 由「N 滴总体积 ÷ N」测得（累积法减小误差）。
- **第三步，面积的测量**：$S$ 用坐标纸数格子——把「不规则油膜」变成「格子的数量 × 每格面积」。$S = n_{\text{格}} \times \text{每格面积}$。
- **第四步，数量级检查**：算出的 $d$ 应在 $10^{-10}$ m 量级（0.2–0.5 nm）。若算出 $10^{-8}$ m 或 $10^{-12}$ m，说明单位换算或测量有误——先查 $V$、$S$ 的单位是否统一。

## 6 辨析｜易错点

- **$V$ 是纯油酸体积**：溶液体积 × 体积分数，别直接用溶液体积。
- **油膜是单分子层**：厚度 = 分子直径；滴太多会多层、算出的 $d$ 偏大。
- **面积数方格**：半格取舍（不足半格舍、超过算一格）。
- **单位统一**：$V$ 用 m³、$S$ 用 m²、$d$ 用 m。
- **数量级验收**：$10^{-10}$ m 量级为成功标准。
- **主要误差在面积测量**：把边界描准、格子数对是关键。

## 7 小结

- **原理**：油酸在水面铺成单分子膜，$d = V/S$（膜厚 = 分子直径）。
- **关键换算**：纯油酸体积 = 溶液体积 × 体积分数。
- **面积测量**：坐标纸数方格（半格取舍）。
- **结果**：$d \sim 10^{-10}$ m 量级（0.2–0.5 nm）。
- **误差**：主要来自面积测量；单分子层假设是近似。
- 一滴油、一池水，量出分子大小——宏观测量微观的典范。
- **宏观测微观**：$d = V/S$——用可测的油膜面积反推不可测的分子直径。

在下一节，我们研究分子热运动的统计规律：**分子运动速率分布规律**。大量分子的运动速率不是一致的，而是服从特定的分布——温度决定分布的形状，这就是「统计」思想的登场。
