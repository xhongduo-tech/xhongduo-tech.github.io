## 为什么从全反射开始

上一节折射定律留下一个「极限」：光从光密介质进入光疏介质时，折射角随入射角增大而增大，最多达到 90°。如果入射角再增大呢？答案令人意外——**光不再进入光疏介质，而是全部反射回光密介质**。这就是**全反射（total internal reflection）**。

全反射是光学里「低调但重要」的现象：光纤通信靠它在玻璃纤芯里「困住」光，让光拐着弯传到千里之外；钻石、水晶的璀璨靠它把光留在内部反复折射；水中气泡、玻璃碎片的「银亮」也是全反射。没有全反射，就没有现代通信的光纤革命。<span class="marginnote">全反射的发现很早了——牛顿就注意到水下物体的全反射，但直到 19 世纪中后期它才被系统应用。光纤的雏形出现在 1950 年代，1966 年高锟提出低损耗光纤的理论，2009 年获得诺贝尔物理学奖。今天全球互联网的信息，绝大多数时间都在光纤里以「全反射」的方式奔跑——这个「光的回头」现象，撑起了整个信息时代。</span>

学这一节，请抓住三件事：**全反射的两个条件、临界角的计算 $\sin C = 1/n$、全反射的应用（光纤、钻石、蜃景）**。

## 1 全反射的条件

**全反射**：光从光密介质射向光疏介质时，当入射角增大到某一角度，折射光线完全消失，只剩下反射光线的现象。

**全反射的两个条件**（缺一不可）：

1. **光从光密介质射向光疏介质**（$n_{\text{密}} > n_{\text{疏}}$）：光要「往外走」才可能全反射；从光疏进光密只会靠近法线，不会全反射。
2. **入射角大于等于临界角**（$\theta_1 \ge C$）：入射角要够大，折射角才会达到 90° 的极限。

**临界角 $C$**：折射角恰好为 90° 时的入射角。由折射定律（光从折射率 $n$ 的介质射向空气 $n=1$）：

$$\sin C = \frac{1}{n}$$

水 $n = 1.33$，$C \approx 48.6°$；玻璃 $n = 1.5$，$C \approx 41.8°$；钻石 $n = 2.42$，$C \approx 24.4°$。<span class="marginnote">临界角记忆：「$n$ 越大，临界角越小」。钻石折射率大、临界角小（24.4°），光线很容易超过临界角被「困」在内部反复全反射，再从多个角度折射出来——这就是钻石「火彩」璀璨、看上去亮闪闪的原因。相反，水临界角 48.6°，从水下 45° 看天空是折射，从 50° 看就是全反射——游泳时从水下往上看到「银亮的水面」，正是入射角超过临界角的全反射。</span>

**辨析｜易错点：** 全反射的两个条件**必须同时满足**——「光密进光疏」是前提、「入射角 ≥ 临界角」是触发。光从空气进水中（光疏进光密），永远不可能全反射。把「光疏进光密也能全反射」当结论是概念错误。

## 2 全反射的机理：折射角到极限

为什么入射角超过临界角后折射消失？

**几何解释**：折射角 $\theta_2$ 满足 $\sin\theta_2 = \dfrac{n_1}{n_2}\sin\theta_1$。当 $\theta_1$ 增大到使 $\dfrac{n_1}{n_2}\sin\theta_1 = 1$，$\theta_2 = 90°$（折射光沿界面掠射）——这是临界角。若 $\theta_1$ 再增大，$\dfrac{n_1}{n_2}\sin\theta_1 > 1$，**没有实数的 $\theta_2$ 能满足折射定律**——折射「无解」，光只能全部反射。

**物理图像**：入射角超过临界角后，折射定律的数学解消失——光无法「折出去」，能量全部留在反射光中。<span class="marginnote">「折射无解」这个表述很有用：折射定律 $\sin\theta_2 = (n_1/n_2)\sin\theta_1$ 右侧超过 1 时，数学上不存在折射角（正弦值不能大于 1），物理上折射光消失。全反射不是「折射光变弱」，而是「折射光彻底消失、反射光百分之百」——这是它区别于普通反射（反射光只占一部分）的关键。反射率 100%，能量全部反射回来。</span>

**辨析｜易错点：** 全反射与普通反射的区别：普通反射只反射部分能量（其余透射/折射），全反射**反射全部能量**（无透射）。所以全反射的反射光比普通反射「更亮更纯」——这正是光纤能长距离传输的原因：每一次反射都是 100%，没有能量泄漏。

把「全反射」与「普通反射」并排对照，差异一目了然：

| 对比项 | 普通反射 | 全反射 |
| --- | --- | --- |
| 发生条件 | 任何界面、任何角度 | 光密进光疏 + 入射角 ≥ 临界角 |
| 反射光能量 | 只反射一部分 | 反射全部（100%） |
| 透射光 | 有透射（折射）光 | 无透射光 |
| 典型场景 | 镜子、水面反光 | 光纤、钻石、气泡银亮 |

**「全反射反射全部能量」是它最核心的性质**——正因如此，光纤的每一次反射都不损失能量，光才能传几十公里；而普通镜子反射率再高也到不了 100%，总有一部分光透过去。

## 3 全反射的应用：光纤

**光纤（optical fiber）**是全反射最伟大的应用：用玻璃（或塑料）制成极细的纤芯，外面包一层折射率更低的包层。光从纤芯一端射入，只要在纤芯-包层界面的入射角超过临界角，就**全反射**——光被「困」在纤芯里，沿着弯曲的光纤前进而不泄漏。

**光纤的结构与原理**：

**纤芯**：折射率较高（如 $n_1 \approx 1.47$）。
**包层**：折射率较低（如 $n_2 \approx 1.45$）。
光从纤芯射向包层时，光密进光疏，入射角超过临界角即全反射。
光纤可弯曲（全反射对「弯曲」不敏感，只要弯曲半径不过分小），光沿光纤「之字形」前进。

**光纤通信的优势**：

**损耗极低**：全反射无能量泄漏 + 现代光纤低损耗，光可传数十公里不用中继。
**带宽极大**：光频率高，可承载海量信息——一根光纤的传输容量远超铜缆。
**抗干扰**：光纤是绝缘体，不受电磁干扰，信号稳定、保密性好。
全球互联网、海底光缆、医疗内窥镜（光纤束传像）全靠它。<span class="marginnote">海底光缆是光纤通信的「大动脉」：跨大西洋海底光缆里成千上万根光纤，承载着国际互联网几乎全部流量。光纤的「全反射」让光在数千公里内几乎不泄漏，加上中继放大，信息可以跨洋传输。而医疗内窥镜用光纤束把光传进体内、把图像传出来——全反射让光「拐弯」的能力，在这里变成「看得见体内」的能力。</span>

## 4 全反射的其他现象

全反射在自然界与科技里处处可见：

**钻石的闪耀**：钻石折射率大、临界角小，光线容易全反射被「困」在内部，多次反射后从顶面射出——璀璨的「火彩」。
**水中气泡的银亮**：气泡是空气（光疏）在水（光密）中，光从水射向气泡表面时容易全反射，气泡看起来银白闪亮。
**海市蜃楼**：地面热空气密度小（折射率略小），光从冷空气（光密）斜射入热空气（光疏），在一定角度全反射，形成「幻景」。
**钻石切割与光纤传感器**：利用全反射原理设计的棱镜、反射器件。
**全反射棱镜**：等腰直角棱镜利用临界角约 42° 的特性，45° 入射即可全反射——潜望镜、望远镜、单反相机的五棱镜用全反射棱镜代替镀银镜面（反射率更高、不氧化）。<span class="marginnote">「海市蜃楼」的全反射解释：沙漠/路面的热空气密度小、折射率小，光从较冷的上方空气斜射入热空气层时，可能超过临界角发生全反射，把天空的像「反射」到地面上——看起来像「水面」或「远方城市」。这个现象证明：全反射不只在玻璃光纤里，大气中处处在上演。「密度差异 → 折射率差异 → 全反射」是蜃景的物理链。</span>

## 5 公式解析：sinC = 1/n

$$\sin C = \frac{1}{n}$$

拆三步看：

- **第一步，推导**：临界角是「折射角 = 90°」的入射角。光从折射率 $n$ 的介质射向空气（$n_{\text{空}} = 1$），折射定律 $n\sin C = 1\times\sin90° = 1$，得 $\sin C = 1/n$。<span class="marginnote">推导链清晰：临界角定义（折射角 90°）→ 折射定律代入 → $\sin C = 1/n$。反过来，若光从折射率 $n_1$ 射向折射率 $n_2$（$n_1 > n_2$），临界角 $\sin C = n_2/n_1$——更一般的形式。光纤的临界角就用这个「比值形式」算。</span>
- **第二步，为什么 $n$ 大则 $C$ 小**：$\sin C = 1/n$，$n$ 越大、$\sin C$ 越小、$C$ 越小——光密介质的临界角小，更容易全反射。钻石 $C = 24.4°$，45° 入射即全反射；水 $C = 48.6°$。
- **第三步，全反射的「够不够」判断**：给出入射角与折射率，先算 $\sin C = 1/n$，再看入射角是否 ≥ $C$。例：水（$n = 1.33$），$\sin C = 1/1.33 = 0.75$，$C \approx 48.6°$。从水下以 60° 射向水面：$60° > 48.6°$，全反射；以 30° 入射：折射。
- **第四步，光纤的临界角**：纤芯 $n_1$、包层 $n_2$（$n_1 > n_2$），临界角 $\sin C = n_2/n_1$。光纤设计让「进入纤芯的光的入射角」都大于 $C$，保证全反射导光。

## 6 辨析｜易错点

- **全反射两条件**：光密 → 光疏 且 入射角 ≥ 临界角。缺一不可。
- **临界角**：$\sin C = 1/n$；$n$ 大则 $C$ 小。
- **全反射反射全部能量**：不是普通反射（只反射部分）。
- **光纤靠全反射导光**：光在纤芯与包层界面全反射，「困」在纤芯里。
- **从光疏进光密不可能全反射**：只有光密进光疏才行。
- **蜃景、气泡银亮、钻石闪耀都是全反射**：全反射在自然与科技里无处不在。

## 7 小结

- **全反射**：光密 → 光疏、入射角 ≥ 临界角时，折射消失、全部反射。
- **临界角**：$\sin C = 1/n$（射向空气），$n$ 大则 $C$ 小。
- 全反射反射全部能量，反射率 100%。
- **光纤**：纤芯（$n$ 大）+ 包层（$n$ 小），光靠全反射被「困」在芯里传输。
- **应用**：光纤通信、钻石火彩、全反射棱镜、海市蜃楼、水中气泡。
- 光纤通信：低损耗、大带宽、抗干扰——信息时代的「大动脉」。
- **全反射是「折射无解」**：入射角超过临界角时折射定律无解，能量全归反射光。
