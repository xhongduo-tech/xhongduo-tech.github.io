## 为什么从带电粒子在匀强磁场中的运动开始

上一节我们推导了洛伦兹力，知道它让垂直射入匀强磁场的粒子做匀速圆周运动，并得到半径 $r = mv/(qB)$ 与周期 $T = 2\pi m/(qB)$。这一节把这些公式变成「运动学工具」：给定粒子的速度、电荷、质量与磁场，就能算出轨道半径、周期，画出完整的运动轨迹。

这是洛伦兹力知识的第一次「实战」：从简单的「垂直射入做圆周」，到「偏转角度」「运动时间」「临界轨迹」——带电粒子在磁场中的运动是物理竞赛、高考压轴题的常客，也是质谱仪、回旋加速器（下一节）的理论基础。<span class="marginnote">「带电粒子在匀强磁场中的运动」的魅力在于：<strong>它把洛伦兹力公式变成几何问题</strong>——粒子走圆弧，圆心在哪、半径多大、转了多少角，全由 $q$、$m$、$v$、$B$ 与初始位置方向决定。解这类题的钥匙是「找圆心、定半径、算角度」，本质是几何 + 圆周运动 + 洛伦兹力的综合。掌握了这套「几何语言」，磁场题就不再是难题。</span>

学这一节，请掌握解题的「三步曲」：**画轨迹（找圆心）、算半径、求时间**。

## 1 垂直射入匀强磁场：匀速圆周运动

带电粒子以速度 $v$ **垂直**射入匀强磁场（$v \perp B$），洛伦兹力提供向心力，做**匀速圆周运动**：

**半径**：$r = \dfrac{mv}{qB}$
**周期**：$T = \dfrac{2\pi m}{qB}$（与速度、半径无关）
**动能**：不变（洛伦兹力不做功）

**运动特点**：粒子沿圆弧运动，轨迹是圆（或圆弧）。速度方向不断改变，但速度大小、动能恒定。

**辨析｜易错点：** 垂直射入时粒子做**完整的圆周运动**（若磁场范围足够大）；磁场范围有限时，粒子只走**一段圆弧**（部分圆周）。画轨迹时先确定「磁场边界」与「粒子进出磁场的点」，再判断走的是整圆还是弧。<span class="marginnote">「半径与速度成正比、周期与速度无关」在轨迹题里的体现：速度加倍，半径加倍、周期不变。所以粒子在磁场里「转一圈的时间」只看 $q/m$ 与 $B$，不看速度——回旋加速器能「固定频率」加速，正是这个性质。解题时先算 $r$ 与 $T$，再画圆弧。</span>

## 2 解题三步曲：画轨迹、算半径、求时间

**第一步，画轨迹（找圆心）**：粒子的圆弧轨迹，圆心在「洛伦兹力方向」的垂线上。方法：

- 已知粒子进出磁场的两个位置（或速度方向），圆心在「速度方向的垂线」上。
- 两个垂线的交点就是圆心；或利用「弦的垂直平分线过圆心」。

**第二步，算半径**：由 $r = \dfrac{mv}{qB}$ 算半径；或由几何关系（圆心到边的距离）求。

**第三步，求时间**：粒子在磁场中运动的时间 = 圆心角对应的弧长时间：

$$t = \frac{\theta}{2\pi}T = \frac{\theta}{2\pi}\cdot\frac{2\pi m}{qB} = \frac{\theta m}{qB}$$

其中 $\theta$ 是粒子在磁场中转过的**圆心角**（弧度）。<span class="marginnote">「时间由圆心角决定」是磁场轨迹题的核心：粒子在磁场里待多久，看它转了多少度（$\theta$）。转 90° 花四分之一周期、转 180° 花半个周期。求 $\theta$ 靠几何（轨迹圆弧与边界形成的角），求 $T$ 靠公式——$t = \dfrac{\theta}{2\pi}T$ 把两者合起来。这个「角度换时间」的思路，让磁场时间题从「动力学」变成「几何 + 周期」。</span>

**辨析｜易错点：** 求时间用**圆心角** $\theta$，不是「入射角」或「偏转角」的直接代换。偏转角（速度方向改变的角度）等于圆心角（圆弧对应的圆心角），但要注意几何关系的推导。常见错误：把入射角、出射角直接用进时间公式。

## 3 常见轨迹模型

几个高频的「磁场轨迹」模型：

**直线边界（半边磁场）**：粒子从直线边界垂直射入磁场，做半圆后从边界射出——轨迹是半圆，圆心在边界上，出射方向与入射方向相反（若垂直入射）。
**斜入射直线边界**：粒子斜射入直线边界磁场，轨迹是一段圆弧（圆心角 $2\theta$，$\theta$ 为入射角），出射角等于入射角（对称）。
**圆形边界**：粒子射入圆形磁场区域，圆弧轨迹与圆边界相交，常用「几何关系 + 半径公式」联立。
**两平行边界（有界磁场）**：粒子在两条平行边界之间做圆弧，判断能否穿出（半径与边界距离的比较）。<span class="marginnote">「直线边界对称性」是最好用的结论：粒子斜入射直线边界磁场，出射角等于入射角，轨迹是「对称圆弧」——因为洛伦兹力垂直于速度，圆弧关于入射点的法线对称。这个对称性让「进角 = 出角」，时间 = 圆心角对应周期。记住对称性，很多轨迹题不用算、直接画。</span>

## 4 临界问题：轨迹与边界

「临界」是磁场轨迹题的进阶：粒子能否穿出磁场边界、能否到达某区域，取决于**轨迹半径与边界距离的比较**：

若轨迹半径 $r$ 大于边界距离，粒子能穿出（走部分圆弧）。
若 $r$ 小于（或等于）边界距离，粒子被「困」在磁场内（走整圆或半圆）。

**临界条件**：轨迹圆弧与边界**相切**——这是「刚好能/不能」穿出的分界。

**辨析｜易错点：** 临界问题的关键是把「轨迹圆弧」画对：圆心在洛伦兹力方向垂线上、半径由公式定。画对轨迹，「能不能穿出」就看圆弧与边界是否相交/相切。**先画图、再计算**是临界题的第一纪律，凭空套公式容易出错。<span class="marginnote">「相切即临界」是临界轨迹题的统一方法：粒子轨迹圆弧与边界相切时，是「刚好穿出/刚好擦过」的边界。比较轨迹半径 $r = mv/(qB)$ 与几何距离，就能判断粒子「穿出、擦过、还是回不来」。这类题本质是「圆的几何」——把粒子轨迹看成圆，边界看成直线/圆，问相交情况。几何功底在这里直接转化为物理结论。</span>

## 5 公式解析：t = θm/(qB)

$$t = \frac{\theta m}{qB} = \frac{\theta}{2\pi}T$$

拆三步看：

- **第一步，来源**：粒子转一圈用时 $T = 2\pi m/(qB)$；转 $\theta$（弧度）用时 $\dfrac{\theta}{2\pi}T$，代入 $T$ 得 $t = \dfrac{\theta m}{qB}$。<span class="marginnote">$t = \theta m/(qB)$ 的简洁形式让人印象深刻：时间 = 圆心角 × 质量 ÷ (电荷 × 磁场)。与速度 $v$ 无关——速度只决定半径，不决定「转这么多角度要多久」（因为速度大半径大，角度对应的弧长按比例变长）。这个「时间与速度无关」的结论，是磁场时间题最常考的考点。</span>
- **第二步，$\theta$ 怎么求**：$\theta$ 是轨迹圆弧的圆心角。若轨迹是整圆，$\theta = 2\pi$（时间 = $T$）；半圆 $\theta = \pi$；直线边界斜入射 $\theta = 2\alpha$（$\alpha$ 为入射角）。几何关系求 $\theta$ 是解题核心。
- **第三步，与半径公式配合**：半径 $r = \dfrac{mv}{qB}$ 定「轨迹大小」，时间 $t = \dfrac{\theta m}{qB}$ 定「待多久」。两个公式一个管空间、一个管时间，配合使用。
- **第四步，量纲**：$\theta$（rad）× $m$（kg）÷（$q$（C）× $B$（T））= kg ÷ (C·kg/(A·s²))…单位复杂，但结果应为秒（s）。直接记 $t = \theta m/(qB)$，单位换算在具体题目里验证。

## 6 综合：电磁场中的运动

实际仪器中常「电场加速 + 磁场偏转」组合：

- **电场加速**：$qU = \tfrac{1}{2}mv^2$——粒子获得速度 $v = \sqrt{2qU/m}$。
- **磁场偏转**：$r = mv/(qB)$——粒子在磁场中偏转。

**典型流程**（质谱仪/回旋加速器的雏形）：粒子经电场加速后进入磁场，由半径反推比荷或质量：

$$r = \frac{\sqrt{2mqU}}{qB}$$

这个「加速 + 偏转」的组合，把「加速电压」与「磁场半径」相连——测出 $r$ 就知道 $q/m$，这是质谱仪的全部原理（下一节展开）。<span class="marginnote">「电场加速 + 磁场偏转」是粒子操控的基本模板：电场给能量、磁场给轨道。质谱仪、回旋加速器、速度选择器全是这个模板的变体。理解「电场管能量、磁场管方向」的分工，就抓住了粒子仪器的设计主线——下一节会具体拆解质谱仪与回旋加速器这两大代表。</span>

## 7 辨析｜易错点

- **画轨迹先找圆心**：圆心在速度方向的垂线上（洛伦兹力反向）；两个垂线交点即圆心。
- **时间用圆心角**：$t = \theta m/(qB)$，$\theta$ 是圆心角（弧度）。
- **半径 $r = mv/(qB)$**：与速度成正比。
- **周期与速度无关**：$T = 2\pi m/(qB)$，回旋加速器的同步基础。
- **临界看相切**：轨迹圆弧与边界相切是「刚好」的分界。
- **先画图再算**：磁场轨迹题的本质是圆的几何，画对图就成功一半。

## 8 小结

- **垂直射入**：匀速圆周运动，$r = \dfrac{mv}{qB}$，$T = \dfrac{2\pi m}{qB}$。
- **解题三步**：画轨迹（找圆心）→ 算半径 → 求时间（$t = \theta m/(qB)$）。
- 时间由圆心角决定，与速度无关。
- **轨迹模型**：直线边界（对称圆弧）、圆形边界、两平行边界。
- **临界问题**：轨迹与边界相切是分界。
- **电磁场组合**：电场加速 + 磁场偏转——质谱仪与回旋加速器的模板。

在下一节，我们把「加速 + 偏转」做成两台真实仪器：**质谱仪与回旋加速器**。一台分离离子、一台加速粒子——人类「称量原子」与「轰击原子」的工具，都靠洛伦兹力。
