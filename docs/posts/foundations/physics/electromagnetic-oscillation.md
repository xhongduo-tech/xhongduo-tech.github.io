## 为什么从电磁振荡开始

前几章我们学了电容（储存电场能）与电感（储存磁场能）。如果把**电容器与电感线圈连成一个回路**，会发生什么？电荷在电容与电感之间「往返流动」，电流大小方向周期性变化，电场能与磁场能反复转化——这就是**电磁振荡**。它是电磁波产生的源头：振荡的电磁场向外辐射电磁波，无线电由此而来。

电磁振荡是「LC 电路」的振荡，与机械振动（弹簧振子、单摆）惊人地同构：**电容像弹簧（储存势能），电感像质量（储存「动能」），电荷像位移，电流像速度**。理解了机械振动，就能理解电磁振荡——它们是同一个数学结构在两个物理领域的表现。<span class="marginnote">「电磁振荡 ↔ 机械振动」的同构是物理最美的对称之一：<strong>弹簧振子：位移 $x$、速度 $v$、动能 $\tfrac12mv^2$、势能 $\tfrac12kx^2$、频率 $\omega = \sqrt{k/m}$；LC 振荡：电荷 $q$、电流 $i$、磁场能 $\tfrac12Li^2$、电场能 $\tfrac12q^2/C$、频率 $\omega = 1/\sqrt{LC}$</strong>。一一对应：$x \leftrightarrow q$、$v \leftrightarrow i$、$m \leftrightarrow L$、$k \leftrightarrow 1/C$。学电磁振荡时「翻译」机械振动的公式，事半功倍。</span>

学这一节，请抓住：**LC 振荡的过程（能量往复转化）、振荡周期公式、与机械振动的类比**。

## 1 LC 振荡电路

**LC 振荡电路**：由电容器与电感线圈组成的电路。给电容器充电后（或电路中有初始电流），电路中的电荷与电流做周期性变化——电磁振荡。

**振荡过程（一个周期）**：

1. **放电阶段**：电容器带电荷，电场能最大；通过电感放电，电流增大，电感阻碍电流增大（自感），电流缓慢建立——电场能转化为磁场能。
2. **放电完成**：电容器电荷为零（电场能为零），电流最大（磁场能最大）——能量全部转化为磁场能。
3. **反向充电**：电流继续（电感维持电流，自感），给电容器反向充电——磁场能转化回电场能，电荷反向。
4. **反向放电、再充电**：如此反复，电荷与电流周期性振荡。<span class="marginnote">LC 振荡的「角色扮演」：电容是「势能库」（储存电场能），电感是「动能库」（储存磁场能）。能量在两者之间荡秋千——电场能最大时磁场能为零、磁场能最大时电场能为零。电感的作用是关键：它「阻碍电流突变」，让放电不是瞬间完成，而是「缓缓流动、来回振荡」——没有电感，电容会瞬间放电完毕；有了电感，才有振荡。</span>

**辨析｜易错点：** 电磁振荡中能量在电场能与磁场能之间转化，**总能量守恒**（理想 LC 电路无电阻损耗）。电荷、电流、电压都在变，但「电场能 + 磁场能」总量恒定。把「能量消耗完」当结论是错的——理想振荡不衰减（实际有电阻损耗而衰减）。

## 2 电磁振荡的规律

LC 振荡电路中，电荷与电流按正弦规律变化（与简谐运动同构）：

$$q = Q_m\cos\omega t, \qquad i = -I_m\sin\omega t$$

其中：

- $Q_m$ 是最大电荷量（电容器初始电荷），$I_m$ 是最大电流。
- 电荷与电流**相位差 $\tfrac{\pi}{2}$**：电荷最大时电流为零（放电瞬间），电荷为零时电流最大（放电完成）。

**振荡周期与频率**（LC 振荡电路的固有周期）：

$$T = 2\pi\sqrt{LC}, \qquad f = \frac{1}{T} = \frac{1}{2\pi\sqrt{LC}}$$

**周期只由电感 $L$ 与电容 $C$ 决定**，与初始电荷、电流无关——与弹簧振子 $T = 2\pi\sqrt{m/k}$ 完全同构（$L \to m$、$C \to 1/k$）。<span class="marginnote">「$T = 2\pi\sqrt{LC}$」与「$T = 2\pi\sqrt{m/k}$」的对应：$L$（电感，抗拒电流变化）对应 $m$（质量，抗拒速度变化），$1/C$ 对应 $k$（劲度系数）。收音机调台就是改变电容 $C$（或电感 $L$）来改变电路的固有频率，让它与某个电台频率共振——「调台 = 调 $LC$」正是谐振（共振）思想在电路里的应用。</span>

## 3 电磁振荡与机械振动的类比

| 机械振动（弹簧振子） | 电磁振荡（LC 电路） |
| --- | --- |
| 位移 $x$ | 电荷 $q$ |
| 速度 $v$ | 电流 $i$ |
| 质量 $m$ | 电感 $L$ |
| 劲度系数 $k$ | $1/C$（电容倒数） |
| 动能 $\tfrac12mv^2$ | 磁场能 $\tfrac12Li^2$ |
| 弹性势能 $\tfrac12kx^2$ | 电场能 $\tfrac12q^2/C$ |
| 周期 $T = 2\pi\sqrt{m/k}$ | 周期 $T = 2\pi\sqrt{LC}$ |
| 加速度 $a = \ddot x$ | $\dfrac{di}{dt}$（电流变化率） |

**类比的价值**：机械振动的结论可以「翻译」成电磁振荡——等幅振荡、能量守恒、周期与振幅无关（与初始条件无关），全部成立。<span class="marginnote">「一张表打通两个领域」是物理学习的最高境界：机械振动与电磁振荡共享同一个数学方程（$\ddot x + \omega^2 x = 0$），所以共享全部结论。学了弹簧振子，LC 电路只是「换皮」：把 $x$ 换成 $q$、$m$ 换成 $L$、$k$ 换成 $1/C$，公式原样照搬。「物理是同一数学在不同物质上的表现」——这个观念比任何单个公式都重要。</span>

**辨析｜易错点：** 电磁振荡的周期与**初始条件无关**（像弹簧振子与振幅无关）：充多少电、初始电流多大，不改变周期，只改变振荡的幅度（$Q_m$、$I_m$）。「初始电荷越大周期越长」是错的——周期只由 $L$、$C$ 决定。

## 4 电磁振荡与电磁波的桥梁

电磁振荡是电磁波的「源头」：**振荡的电荷（电流）产生振荡的电磁场，振荡的电磁场向外辐射电磁波**。

LC 电路中的电荷振荡 → 电场振荡 → 磁场振荡 → 相互激发、脱离电路向外传播 → 电磁波。
电磁振荡的频率 = 电磁波的频率（LC 电路调谐）。

**从电路到无线**：要让电磁波有效辐射，LC 电路要「打开」——把电容器拉开成天线、电感变成线圈，振荡的电磁场就「甩」向空间，形成无线电波。下一节《电磁场与电磁波》将系统展开。<span class="marginnote">「把 LC 电路打开成天线」是电磁振荡走向电磁波的工程动作：闭合的 LC 电路能量在电路内部振荡，辐射很弱；把电容板拉开、让电磁场「暴露」到空间，振荡的电磁场就能向外传播——这就是天线。发射塔上的天线本质上是一个「开放」的振荡电路，把振荡的能量辐射成电磁波。无线电从「电路振荡」变成「空间电磁波」，靠的正是这一步「打开」。</span>

## 5 公式解析：T = 2π√(LC)

$$T = 2\pi\sqrt{LC}, \qquad f = \frac{1}{2\pi\sqrt{LC}}$$

拆三步看：

- **第一步，推导骨架**：LC 电路中，电容电压 $u = q/C$、电感自感电动势 $e = -L\dfrac{di}{dt}$。回路电压方程 $q/C + L\dfrac{di}{dt} = 0$，即 $\dfrac{d^2q}{dt^2} + \dfrac{1}{LC}q = 0$——与简谐运动方程 $\ddot x + \dfrac{k}{m}x = 0$ 同构，角频率 $\omega = \dfrac{1}{\sqrt{LC}}$，周期 $T = 2\pi\sqrt{LC}$。<span class="marginnote">「微分方程同构」是类比的最深层证据：LC 电路的电压方程整理后正是「电荷的二阶导 + 常数 × 电荷 = 0」——与弹簧振子 $\ddot x + (k/m)x = 0$ 完全同形。同一个方程的解都是正弦/余弦，所以两者的所有结论共享。这解释了为什么「换表即可」：不是巧合，是数学结构相同。</span>
- **第二步，$L$、$C$ 的角色**：$L$ 大（电感强）→ 电流难变 → 振荡慢（周期长）；$C$ 大（电容大）→ 储存电荷多 → 充放电慢 → 周期长。两者都在「拖慢」振荡。
- **第三步，调谐的应用**：收音机用可变电容调 $C$，改变固有频率 $f = \dfrac{1}{2\pi\sqrt{LC}}$，与电台频率共振——这就是「调台」。$LC$ 越小，频率越高（调高频台）。
- **第四步，量级感受**：$L = 100\ \mu\text{H}$，$C = 100\ \text{pF}$，$T = 2\pi\sqrt{10^{-4}\times10^{-10}} = 2\pi\sqrt{10^{-14}} = 2\pi\times10^{-7} \approx 6.3\times10^{-7}\ \text{s}$，$f \approx 1.6\ \text{MHz}$——中波广播频段，正是收音机的工作范围。

**数值算例**：一个 LC 电路，$L = 1\ \text{mH}$、$C = 1\ \mu\text{F}$。周期 $T = 2\pi\sqrt{10^{-3}\times10^{-6}} = 2\pi\sqrt{10^{-9}} \approx 2\times10^{-4}\ \text{s}$，频率 $f \approx 5\ \text{kHz}$——音频范围，是扬声器电路常用的振荡频率。若要发射电磁波（中波广播约 1 MHz），需把 $LC$ 乘积减小约 200 倍：把 $L$ 减到 50 $\mu$H、$C$ 减到 500 pF，$f = 1/(2\pi\sqrt{50\times10^{-6}\times500\times10^{-12}}) \approx 1\ \text{MHz}$。「从音频到广播，只需调 $LC$」——这就是调谐的威力。

## 6 辨析｜易错点

- **电磁振荡周期只由 $L$、$C$ 决定**：与初始电荷、电流无关。
- **能量守恒（理想）**：电场能与磁场能此消彼长、总量不变。
- **电荷与电流相位差 $\tfrac{\pi}{2}$**：电荷最大时电流为零、电荷为零时电流最大。
- **$L \leftrightarrow m$、$C \leftrightarrow 1/k$**：机械振动 ↔ 电磁振荡同构。
- **振荡是电磁波的源头**：振荡电磁场辐射电磁波。
- **实际有电阻损耗**：振荡衰减；理想 LC 不衰减。
- **能量「此消彼长」**：电场能最大时磁场能为零、反之亦然——总量守恒（理想）。

## 7 小结

- **LC 振荡电路**：电容与电感组成的振荡回路，电荷电流周期性变化。
- **振荡过程**：电场能 ↔ 磁场能往复转化（电容储能、电感储「惯性」）。
- **周期公式**：$T = 2\pi\sqrt{LC}$，只由 $L$、$C$ 决定。
- **与机械振动同构**：$q \leftrightarrow x$、$i \leftrightarrow v$、$L \leftrightarrow m$、$C \leftrightarrow 1/k$。
- 能量守恒：电场能 + 磁场能总量恒定（理想）。
- 振荡的电磁场向外辐射 → 电磁波（天线开放 LC 电路）。
- **调谐的应用**：收音机调台 = 改变 $LC$ 改变固有频率，与电台频率共振。
- **LC 三要素**：电容储能、电感储惯、周期 $T = 2\pi\sqrt{LC}$——抓住它们，电磁振荡就掌握了。
- **电荷与电流差 $\tfrac{\pi}{2}$ 相位**：电荷最大时电流为零、电荷为零时电流最大。
- **周期与初始条件无关**：充多少电只改幅度（$Q_m$、$I_m$），不改周期。

- **LC 振荡电路**：电容与电感组成，电荷电流周期性变化——周期 $T = 2\pi\sqrt{LC}$。
- **能量往复转化**：电场能（电容）与磁场能（电感）此消彼长、总量守恒（理想）。
- **与机械振动同构**：$q \leftrightarrow x$、$i \leftrightarrow v$、$L \leftrightarrow m$、$C \leftrightarrow 1/k$。
- 把这个结论与上一节对照，你会发现「变化率」与「变化量」的差别贯穿物理。

在下一节，我们从振荡走向传播：**电磁场与电磁波**。变化的电场产生磁场、变化的磁场产生电场——电磁场自我维持、以光速传播，麦克斯韦预言的电磁波由此登场。
