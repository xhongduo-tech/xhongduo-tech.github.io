## 为什么从电势差开始

上一节定义了电势 $\varphi$，它像「高程」一样标出电场中每一点的「能量高度」。但真实世界里几乎没人关心「绝对高程」，大家关心的是**两点之间的落差**——水位差决定水往哪流、多快流；电势差决定电荷往哪移、电路如何工作。

**电势差（electric potential difference / voltage）**就是两点电势之差，通常叫**电压**，符号 $U$。它是整个电路理论的核心量：电池的电动势是「电源两端的电势差」，电压表测的是「两点间的电势差」，欧姆定律里 $U = IR$ 用的也是电势差。<span class="marginnote">为什么电路里「用电势差」而不是「用电势」？因为电势的绝对值依赖参考点（取无穷远或接地），而电势差是两点相减、与参考点无关，是「可测的物理量」。电压表的两根表笔正是搭在两点之间测差值——正如高程不可测、落差可测。这个「差值才有物理意义」的思想，从重力势能一路贯穿到电路。</span>

学这一节，你要掌握三件事：**电势差的定义与符号、静电力做功与电势差的关系 $W = qU$、以及电势差与电场力做功方向性的细节**。这三件事是后面所有电路计算的原子级基础。

## 1 电势差的定义

电场中两点间电势的差值，叫**电势差**（也叫电压）：

$$U_{AB} = \varphi_A - \varphi_B$$

$U_{AB}$ 表示「A 点电势减 B 点电势」。注意**下标的顺序**：

- $U_{AB} = \varphi_A - \varphi_B$：A 相对 B 的电势差。
- $U_{BA} = \varphi_B - \varphi_A$：B 相对 A 的电势差。
- 于是 $U_{AB} = -U_{BA}$：交换下标，符号相反。

电势差是**标量**，单位伏特（V），$1\ \text{V} = 1\ \text{J}/\text{C}$。它可正可负：$U_{AB} > 0$ 表示 A 点电势高于 B 点；$U_{AB} < 0$ 则相反。<span class="marginnote">电势差与参考点无关——这是它比「电势」优越的根本原因。设参考点电势为 $\varphi_0$，A、B 两点电势分别变成 $\varphi_A + \varphi_0$、$\varphi_B + \varphi_0$，相减后 $\varphi_0$ 抵消。所以「$U_{AB}$ 与零点选取无关」可以放心大胆地说。电路理论里从不说「某点电压是多少」，只说「两点间电压是多少」，正是这个道理。</span>

**辨析｜易错点：** $U_{AB}$ 与 $U_{BA}$ 千万别写反。约定俗成的读法：「$U_{AB}$ 读作 A、B 两点间的电势差」时，A 是第一个下标、默认 A 减 B。实际计算中若把下标写反，整个符号就反了。做题时建议先把 $\varphi_A$、$\varphi_B$ 的大小写清楚，再定 $U_{AB}$ 的正负。

## 2 静电力做功与电势差：W = qU

把静电力做功与电势差连接起来，是本节最重要的公式。由上一节 $W_{AB} = E_{pA} - E_{pB} = q(\varphi_A - \varphi_B)$：

$$W_{AB} = qU_{AB}$$

**电场力做的功等于电荷量乘以电势差。** 这条公式统一了「功」与「电压」两个概念，意义重大：

- 已知两点电压与电荷量，立即得到电场力做的功，无需管路径、无需管电场分布。
- 已知做功与电荷量，立即得到电势差。
- 它把能量守恒引入电路：电荷在电场中移动，电场力做的功转化为动能或其他能量形式。

**辨析｜易错点：** $W_{AB} = qU_{AB}$ 中，$q$ 与 $U_{AB}$ 都是**带符号**的量，乘积的符号自动给出功的正负：正电荷从高电势到低电势（$U_{AB} > 0$），$W > 0$，电场力做正功；负电荷同理反号。<span class="marginnote">符号规则可以用一个例子坐实：电子（$q = -e$）从电势高处（负极概念不适用，用 $\varphi_A$ 大）移动到电势低处，$U_{AB} > 0$，但 $q < 0$，所以 $W < 0$——电场力对电子做负功，电子的电势能增加？等等，电子是从高电势到低电势……<strong>不对，电子被电场力推动的方向是逆着电场线、从低电势到高电势</strong>。所以做题时别用「正电荷直觉」套负电荷，永远回到 $W = qU$ 与「电场力做正功电势能减小」两个公式。</span>

为了彻底说清符号，设 A 点电势 $\varphi_A = 10\ \text{V}$，B 点 $\varphi_B = 2\ \text{V}$，$U_{AB} = 8\ \text{V}$。

- 正电荷 $+1\ \text{C}$ 从 A 到 B：$W = 1 \times 8 = 8\ \text{J}$（正功），电势能减小 8 J。
- 负电荷 $-1\ \text{C}$ 从 A 到 B：$W = (-1) \times 8 = -8\ \text{J}$（负功），电势能增大 8 J——电场力「逆着」负电荷的自然趋势推它，所以做负功。

## 3 电势差与电场强度：初探 U = Ed

在**匀强电场**中，电势差与电场强度有一个简洁的关系。设电场强度 $E$，方向水平向右，A、B 两点沿电场线方向相距 $d$，则

$$U_{AB} = Ed$$

推导：电场力 $F = qE$，沿电场线从 A 到 B 做功 $W = Fd = qEd$；又 $W = qU_{AB}$，两式联立得 $U_{AB} = Ed$。这里 $d$ 是**沿电场线方向**的距离（下一节会严格讨论「沿场强方向的投影」）。

这个式子揭示了电压与场强的内在联系：**场强是「电势随距离的变化率」，电压是「电势差 × 距离」**。它也给出了电场强度的另一单位：$1\ \text{N}/\text{C} = 1\ \text{V}/\text{m}$——两个单位完全等价，物理上都是「每米的电势变化」或「每库仑的力」。<span class="marginnote">$U = Ed$ 的意义在下一节《电势差与电场强度的关系》会全面展开，本节先建立直觉：<strong>电场强度像「坡度」，电势像「高程」，$U = Ed$ 说「落差 = 坡度 × 水平距离」</strong>。记住这个类比，等势面疏密与场强大小的关系（等势面密 → 场强大）就一目了然。</span>

一个数字例子：平行板间距 $d = 2\ \text{cm} = 0.02\ \text{m}$，电场强度 $E = 5\times10^4\ \text{V/m}$，则板间电压 $U = 5\times10^4 \times 0.02 = 1000\ \text{V}$——一块 1 kV 的电容器，内部场强竟高达每米 5 万伏。**高压设备的危险，正来自「小距离 × 大场强」的乘积**。

## 4 电势差的应用：从静电学到电路

电势差是静电学通往电路理论的桥梁。几个重要应用方向：

**电场力做功的能量核算**：带电粒子在电场中加速，$qU = \tfrac{1}{2}mv^2$——电场力做的功全部转化为动能。这是示波器、电子枪、粒子加速器的基本原理：给带电粒子一个电压差，它就获得动能。
**电压的单位换算与量级**：常见电压量级从微伏（生物电、传感器信号）到伏（干电池 1.5 V）到千伏（高压输电）到百万伏（闪电），跨越近 12 个数量级。理解「电压」这个概念，才能安全地与电打交道。<span class="marginnote">人体的神经信号、心脏跳动（心电图）都是微伏到毫伏级的电势差；干电池 1.5 V；家庭电路 220 V；高压输电 110 kV–1000 kV；闪电可达上亿伏。电压量级的理解，是「安全用电」的第一课——「不要碰高压」不是劝告，是电势差的物理结论。</span>
- **从电势差看能量守恒**：电路中电流流过电阻，电势降低（电压降），电荷的电势能转化为热能；流过电池，电势升高，化学能转化为电势能。**整个电路就是一个电势能搬运系统**——这就是第十二章《电路中的能量转化》的思想预告。

## 5 公式解析：W = qU 的完整链条

$$W_{AB} = qU_{AB}, \qquad U_{AB} = \varphi_A - \varphi_B$$

拆三步看：

- **第一步，链式推导**：$W_{AB} = E_{pA} - E_{pB}$（电场力做功 = 电势能减少）→ 代入 $E_p = q\varphi$ → $W_{AB} = q\varphi_A - q\varphi_B = q(\varphi_A - \varphi_B) = qU_{AB}$。**三条式子环环相扣：功 → 势能 → 电势 → 电势差**。
- **第二步，为什么这个公式这么有用**：它把「电场力做功」这个需要知道电场分布才能算的量，化简为「电荷量 × 两点电压」——而电压是可直接测量的（电压表）。测量替代计算，这是工程思维的体现：与其从头算电场，不如测出电压。
- **第三步，符号的三重检查**：$q$ 的正负（正电荷 / 电子）、$U_{AB}$ 的正负（A 比 B 高还是低）、$W$ 的正负（正功 / 负功），三者乘积自动给出答案。**推荐流程：先判断物理图像（电荷从哪到哪、电场力往哪、做正功还是负功），再用公式核算符号**——物理直觉在前，符号运算是校验。
- **第四步，$U = Ed$ 的适用边界**：只在**匀强电场**中成立，且 $d$ 是沿电场线方向的距离。非匀强电场要用积分（第二级内容），或取微小距离近似。下一节会系统展开这个边界。

## 6 辨析｜易错点

- **电势差是「两点之差」，与参考点无关**：$U_{AB} = \varphi_A - \varphi_B$，任何零点选取下都一样。说「电压随接地位置而变」是错误的。
- **$U_{AB}$ 与 $U_{BA}$ 差一个符号**：顺序不能颠倒。$U_{AB} = -U_{BA}$，做题时先确认下标顺序。
- **$W = qU$ 中电荷带符号**：电子（负电荷）从高电势到低电势，电场力做负功，它的动能变化不能直接套「正电荷」直觉。负电荷问题永远回到公式与「势能最小化」原理。
- **$U = Ed$ 只对匀强电场、沿场强方向成立**：若两点连线不平行于电场线，$d$ 应取「沿场强方向的投影距离」（见下一节）。把任意两点距离直接当 $d$ 代入，是常见错误。
- **电势差为零不代表没有电场**：等势面上任意两点 $U = 0$，但场强 $E$ 不为零。电场线垂直等势面，沿等势面移动不做功，但电荷仍受电场力。
- **电压是标量，但「高低」有方向性**：说「A 点电压高于 B 点」指的是 $\varphi_A > \varphi_B$，即 $U_{AB} > 0$。描述电路里哪端电位高，始终是「相对」的说法。

## 7 小结

- **电势差**：$U_{AB} = \varphi_A - \varphi_B$，单位伏特（V），标量，与参考点无关。
- **静电力做功**：$W_{AB} = qU_{AB}$，电场力做功 = 电荷量 × 电势差。
- **匀强电场**：$U_{AB} = Ed$，$d$ 为沿电场线方向的距离；$1\ \text{N/C} = 1\ \text{V/m}$。
- 符号规则：$q$、$U$ 都带符号相乘得功的正负；先画物理图像再核算符号。
- 电势差是电路理论的核心量：电池提供电压、电阻产生电压降、电压表测电压。

在下一节，我们把 $U = Ed$ 严格化：**电势差与电场强度的关系**——场强是电势的空间变化率，等势面的疏密反映场强的大小。这一节将把「力」与「能量」两个视角彻底缝合。
