## 为什么从动量守恒定律开始

上一节动量定理告诉我们「合外力的冲量改变动量」。那么反过来——**如果系统不受外力，动量的总量会怎样？** 答案是它**不变**。这就是**动量守恒定律**：系统不受外力或所受外力的合力为零时，系统的总动量保持不变。

动量守恒与能量守恒并列为力学的两大守恒律，但它有一个能量守恒没有的优势：**碰撞、爆炸这类「力极猛、时间极短、内部能量大量转化」的过程，动量守恒依然严格成立**（因为内力冲量相互抵消、外力冲量可忽略），即使机械能损失惨重。这让动量守恒成为研究碰撞、反冲、火箭推进、粒子对撞的第一工具。<span class="marginnote">动量守恒的微观来源是牛顿第三定律：碰撞中两物体间的内力「等大反向、同时存在」，它们对系统总动量的贡献相互抵消。所以「系统不受外力（或外力可忽略）→ 总动量守恒」不是经验规则，而是牛顿第三定律的严格推论。这也让动量守恒成为检验「牛顿力学适用性」的试金石——微观粒子碰撞也遵守它。</span>

学这一节，请把「守恒条件」作为第一重点：**什么时候能用、什么时候不能用**。动量守恒不是万能的，它的适用条件（合外力为零）比能量守恒更严格、也更「容易满足于瞬时过程」。

## 1 动量守恒定律的内容与条件

**动量守恒定律**：如果一个系统不受外力，或者所受外力的矢量和为零，那么这个系统的总动量保持不变。

数学表达（两个物体系统）：

$$m_1 v_1 + m_2 v_2 = m_1 v_1' + m_2 v_2'$$

即**初态总动量 = 末态总动量**。

**适用条件**（三条，满足其一即可）：

1. **系统不受外力**（理想情况）。
2. **系统所受外力矢量和为零**（合力为零）。
3. **外力远小于内力**（外力可忽略）——碰撞、爆炸等极短过程，重力等外力的冲量可忽略，近似动量守恒。<span class="marginnote">条件 3 是「近似守恒」的关键：碰撞中内力（如撞击力）可达数千牛顿、作用时间极短，而重力可能只有几十牛顿——重力冲量 $mg\Delta t$ 相比内力冲量可以忽略。所以「碰撞瞬间动量守恒」几乎总是成立，这正是动量守恒在碰撞问题里的普适性来源。但「近似」二字提醒你：严格说总有外力，只是小到可忽略。</span>

**辨析｜易错点：** 动量守恒的「系统」要**选对**。把「一个物体」当系统，它受外力就必然动量变；把「两个相撞的物体」当系统，内力（两物之间的力）不影响总动量。**「谁和谁组成系统」决定了能不能用守恒律**——选错系统，守恒条件就不满足。这是动量守恒题最大的陷阱。

## 2 动量守恒的矢量性

动量是矢量，动量守恒是**矢量守恒**：不仅「大小」守恒，还「方向」守恒。

**一维直线运动**：先规定正方向，各速度代入正负号，等式两边代数相加。反弹、反冲的符号最容易错。
**二维运动**（斜碰、爆炸碎块分向两边）：动量守恒沿两个方向分别成立——**x 方向与 y 方向各自守恒**（动量守恒是矢量式，可正交分解）。<span class="marginnote">二维动量守恒的威力在「爆炸分裂」与「斜碰」里体现：炸弹在飞行中爆炸成两块，两块碎块的动量之和仍等于爆炸前整弹的动量（沿各方向分别守恒）。用两个方向的守恒方程联立，能求出分裂后各块的速度。这正是「反冲」与「碎片分析」的数学基础——也是天体、粒子物理里分析衰变过程的工具。</span>

**辨析｜易错点：** 动量守恒是**矢量**守恒，不能只列「大小相等」的标量方程。例如两球斜碰后，必须把初末动量分解到 x、y 方向分别守恒。**「总动量大小不变」是错的表述**——应该是「总动量（矢量）不变」。大小相同方向不同的系统，总动量可能为零。

## 3 动量守恒与能量守恒的配合

动量守恒常与能量关系联用，是力学综合题的核心套路。两类经典问题：

**碰撞**：两球碰撞，动量守恒 + 能量损失关系。设碰前速度 $v_1$、$v_2$，碰后 $v_1'$、$v_2'$：

- **弹性碰撞**：动量守恒 + 动能守恒，解得
$$v_1' = \frac{(m_1 - m_2)v_1 + 2m_2v_2}{m_1 + m_2}, \qquad v_2' = \frac{(m_2 - m_1)v_2 + 2m_1v_1}{m_1 + m_2}$$
- **完全非弹性碰撞**：动量守恒 + 「碰后一起运动」$v_1' = v_2' = v'$，解得
$$v' = \frac{m_1v_1 + m_2v_2}{m_1 + m_2}$$
动能损失最大（全部相对动能转化为内能）。<span class="marginnote">「完全非弹性碰撞」损失动能最多的证明：碰后共速时相对速度为 0，而「损失动能 = $\tfrac{1}{2}m_{\text{红}}v_{\text{相对}}^2$」型表达式——相对速度为零时损失最大。这一结论在粒子物理里对应「粒子完全吸收、融合」，在宏观里对应「子弹嵌入木块」「两车黏在一起」。弹性与完全非弹性是碰撞的两个极端，真实碰撞介于两者之间（恢复系数 $0 < e < 1$）。</span>

**爆炸与反冲**：系统总动量守恒，但能量增加（化学能/内能转化为动能）。典型：炮弹发射时炮身后坐、炸弹分裂、火箭喷气——总动量保持为零（或初动量），各部分的动量互相抵消。

## 4 反冲与火箭：动量守恒的航天应用

**反冲现象**：一个物体向某方向抛出部分质量，剩余部分向相反方向运动——整个系统动量守恒。大炮发射炮弹时炮身后坐、节日烟花四散、喷水船的喷嘴，都是反冲。

**火箭**：火箭通过向后高速喷出燃气，获得向前的动量。设火箭某时刻质量 $M$、速度 $v$，喷出燃气相对火箭速度 $u$（喷气速度），动量守恒给出推进原理。火箭的最终速度由**齐奥尔科夫斯基方程**描述：

$$v = u\ln\frac{M_0}{M}$$

其中 $M_0$ 是初始质量（含燃料），$M$ 是燃料烧完后的质量，$u$ 是喷气速度。<span class="marginnote">齐奥尔科夫斯基方程揭示了火箭设计的两个要点：<strong>喷气速度 $u$ 与质量比 $M_0/M$</strong>（都是对数与线性关系）。喷气速度由发动机决定（化学燃料约 3–4 km/s），质量比受结构限制——所以要实现高速度，用「多级火箭」逐级抛弃空燃料箱，等效于提高质量比。人类登月的三级火箭，正是这个方程的工程产物。</span>

**辨析｜易错点：** 火箭的推进「不需要外界空气」——它靠向后喷气（内力反冲）获得向前动量，在真空中照样能加速。这是「反冲」与「摩擦驱动」的本质区别，也是航天器能在太空工作的物理基础。**反冲问题的动量守恒方向**：喷出燃气向后（$-$），火箭向前（$+$），两者动量矢量和守恒（保持初动量）。

## 5 公式解析：m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′

$$m_1 v_1 + m_2 v_2 = m_1 v_1' + m_2 v_2'$$

拆三步看：

- **第一步，读符号**：$m_1$、$m_2$ 是两物体质量，$v_1$、$v_2$ 是碰前速度（带方向符号），$v_1'$、$v_2'$ 是碰后速度（带方向符号）。等式左边初态总动量、右边末态总动量，矢量相等。<span class="marginnote">一维问题里「带方向符号」意味着先设正方向：向右为正，则向左的速度取负值代入。例如 $v_1 = 3\ \text{m/s}$（向右）、$v_2 = -2\ \text{m/s}$（向左），相加时直接 $m_1\times3 + m_2\times(-2)$。符号错误是动量守恒题的头号失分点——「方向先行」永远是第一步。</span>
**第二步，为什么等式成立**：系统合外力为零（或内力冲量抵消），动量定理对系统给出总动量不变。推导：对两物体分别用动量定理 $F_{12}\Delta t = m_1\Delta v_1$、$F_{21}\Delta t = m_2\Delta v_2$，由牛顿第三定律 $F_{12} = -F_{21}$，相加得 $m_1\Delta v_1 + m_2\Delta v_2 = 0$，即 $m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$。**牛顿第三定律是动量守恒的根**。
**第三步，什么量「守恒」**：守恒的是**总动量**，不是「总动能」也不是「单个物体的动量」。碰撞中两物体各自动量都变（一个增一个减），但总和不变。判断守恒与否，看「系统总动量初末是否相等」。
**第四步，单位与方向**：各项单位都是 $\text{kg·m/s}$；矢量性要求先设正方向。二维问题把方程按 x、y 方向分别写——「矢量方程拆分量」在微积分/力学里都是通用动作。

## 6 动量守恒与机械能守恒的选用

碰到综合题，先回答「哪个守恒」：

| 条件 | 结论 |
| --- | --- |
| 系统不受外力 / 外力可忽略 | 动量守恒 |
| 只有保守力做功（无摩擦、无能量损失） | 机械能守恒 |
| 碰撞（无论是否弹性） | 动量守恒（机械能不一定守恒） |
| 弹性碰撞 | 动量守恒 + 机械能守恒 |
| 爆炸、反冲 | 动量守恒 + 能量增加 |
| 有摩擦的滑行、非弹性碰撞 | 动量守恒 + 机械能不守恒（用能量损失） |

**辨析｜易错点：** 碰撞题「动量守恒 + 动能守恒」只在**弹性碰撞**同时成立。非弹性碰撞动能不守恒，只能动量守恒 + 给恢复系数或「共速」条件。**把「动量守恒」和「机械能守恒」当成一回事，是力学里最顽固的错误之一**——记住：碰撞一律动量守恒，弹不弹性看动能守不守恒。<span class="marginnote">一句话总括：<strong>「动量守恒看外力，机械能守恒看做功」</strong>。外力为零但摩擦做功，动量守恒机械能不守恒；外力做功但非保守力为零，机械能守恒动量不守恒。两条守恒律的判断标准完全独立，各自为政。</span>

## 7 辨析｜易错点

- **守恒条件看「外力」**：系统不受外力（或合力为零、或外力远小于内力）才动量守恒。单个物体受外力，动量必变。
- **选对系统**：「谁组成系统」决定守恒是否成立。碰撞题通常把相撞的所有物体放一起当系统。
- **矢量性**：先设正方向、带符号代入；二维问题分方向列方程。
- **碰撞不等同于动量守恒的充分条件**：碰撞几乎都近似动量守恒（外力可忽略），但「动量守恒」也可能是爆炸、反冲等别的过程。
- **弹性/非弹性看动能**：动量守恒恒成立（条件满足时），动能守恒只在弹性碰撞成立。
- **爆炸与反冲的动量守恒**：总动量保持初动量（常为零），各部分动量反向等大（或按质量反比分配）。

## 8 小结

- **动量守恒定律**：系统不受外力（或合力为零/外力可忽略）时，总动量不变。
- 公式：$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$（矢量式，先设正方向）。
- **条件**：合外力为零或外力远小于内力；碰撞、爆炸、反冲近似适用。
- 弹性碰撞动量 + 动能守恒；完全非弹性碰撞动量守恒 + 共速（动能损失最大）。
- **反冲与火箭**：向后喷气获得向前动量；齐奥尔科夫斯基方程 $v = u\ln(M_0/M)$。
- 与机械能守恒独立判断：动量守恒看外力，机械能守恒看做功。

在下一节，我们把动量守恒定律付诸实验：**实验：验证动量守恒定律**。用两个滑块碰撞，测碰撞前后速度，检验总动量是否守恒——这是你亲手验证又一条自然规律的实验。
