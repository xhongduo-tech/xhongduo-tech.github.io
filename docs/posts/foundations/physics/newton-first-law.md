# 牛顿第一定律

<div class="epigraph">
<p>物体一旦开始运动，只要没有使它加速或减速的原因，就会以同一速度在同一方向上永远运动下去。</p>

## 为什么从牛顿第一定律开始

前三章的运动学回答的是「物体怎么动」：我们用位移、速度、加速度三个量把运动描述得清清楚楚。但从第四章起，我们要回答一个更根本的问题——**物体为什么会这么动？** 答案藏在「力」与「运动」的关系里，而这一关系的起点，就是**牛顿第一定律**。

这条定律的特别之处在于：它几乎不像一条「定律」，更像一句关于世界观的宣言。它否定了统治物理学两千年的亚里士多德观点，重新定义了「力」与「惯性」，还顺带规定了动力学必须在什么参考系里讨论。可以说，**整座动力学的楼，都盖在这条定律挖好的地基上**。它也第一次让我们体会到：物理学里最深刻的进展，有时不是算出新的数，而是把「大家习以为常的错误」纠正过来。

## 1 一场持续两千年的争论：力是维持运动的原因吗

亚里士多德相信：**力是维持运动的原因**。推箱子，箱子才动；不推，它就停下。日常经验仿佛处处印证——马拉车、人跑步，谁不在「用力」？这套说法统治了西方思想近两千年。<span class="marginnote">亚里士多德的错误并不愚蠢：在地面这种充满摩擦的环境里，「不推就停」确实普遍成立。他缺少的，是一个把摩擦「减到零」的思想工具。物理学最难的往往不是推导，而是想到一个能隔离干扰的理想情形。</span>

伽利略用**理想斜面实验**打破了它。设想两个斜面相对而立，小球从左侧斜面某一高度 $h$ 释放：

- 它滚下左斜面后，会冲上右侧斜面，并**几乎回到同一高度 $h$**；
- 把右侧斜面放平一些，小球为回到 $h$ 就要滚得更远；
- 再放平一些，滚得更远；
- 若把右侧斜面完全放成水平，小球**永远回不到 $h$**——于是它只能一直滚下去。

![伽利略理想斜面实验](/images/physics/newton-first-law-1.svg)

真实的斜面总有摩擦，小球会慢慢停下。但伽利略指出：摩擦越小，小球越接近「回到同一高度」；把摩擦**无限减小**、逼近零，小球就无限逼近「永不停止」。结论震撼：**运动本身不需要力来维持；力是改变运动状态的原因。**

笛卡尔随后补上了被伽利略忽略的一个细节：小球沿斜面滚到水平面后，会沿**直线**继续运动，而不是沿曲线。**不受外力的物体，将保持静止或匀速直线运动**——这就是牛顿第一定律的直接前身。<span class="marginnote">「无限减小摩擦再取极限」，正是这个博客标题「从极限到大模型」里「极限」二字的物理化身。思想实验不是猜测，而是把实验推向极限的推理，这在第二级《数学分析》里会获得严格的表述。</span>

## 2 牛顿第一定律：内容与三层含义

牛顿把伽利略、笛卡尔的成果凝练成一条定律：

**一切物体总保持匀速直线运动状态或静止状态，除非作用在它上面的力迫使它改变这种状态。**

注意它的措辞极其克制。它没有说「物体不受力时怎样」，而是说「除非有力迫使它改变」。这句话里藏着三层含义，一层比一层深：

- **第一层，惯性**：物体天然有「保持原有运动状态不变」的倾向，这个性质叫**惯性（inertia）**，下一节专门展开。
- **第二层，力的定义**：力不是「维持运动的原因」，而是「**改变运动状态的原因**」——也就是上一章说的，力产生**加速度**。一个物体速度在变，必有外力；速度不变，则合外力为零。
- **第三层，惯性参考系**：定律里「保持静止或匀速直线运动」这句话本身需要一个参考系来定义。满足牛顿第一定律的参考系，叫**惯性参考系**。地面近似是惯性系，匀速行驶的火车车厢也是；而突然加速的电梯里，物体「无缘无故」地倾斜，那里的牛顿第一定律不再成立。<span class="marginnote">「惯性参考系」是这条定律赠送给后世的隐形礼物。它到第七章《相对论时空观与牛顿力学的局限性》会再次登场：爱因斯坦正是从「惯性系之间平权」出发，建立了狭义相对论。第一定律的第三层含义，其实是为整个经典力学的框架画圈。</span>

## 3 惯性：质量是惯性大小的量度

**惯性（inertia）**：物体保持原来匀速直线运动状态或静止状态的性质。**一切物体都有惯性**，无论它是静止的石头还是飞驰的子弹——静止的石头想让它动起来「费劲」，飞驰的子弹想让它停下更「费劲」，这就是惯性在两边都起作用。

**辨析｜易错点：惯性大小只看质量，与速度无关。** 常有人以为「速度越大惯性越大」，理由是「大卡车高速时更难刹住」。这里混了两个概念：惯性是「改变运动状态的难易」的量度，只由**质量**决定；而「高速难刹」是因为速度大时，要减掉的动量 $mv$ 大，需要更长的刹车时间——这是**运动量**的问题，不是**惯性**的问题。一辆空载的小货车即使开得再快，它的惯性也小于满载的同一辆车。

衡量惯性大小的物理量就是**质量（mass）**。用同样的力推空购物车和推装满年货的购物车，前者轻松起步、轻易转弯，后者「惰性十足」——满载车的质量大，运动状态更难改变。**质量是惯性大小的量度**，这句话到下一节 $a = F/m$ 会变成精确的数学关系。

把「惯性大小看质量」落到数字上：用同样大的力推一辆 $1000\ \text{kg}$ 的小车和一辆 $10000\ \text{kg}$ 的卡车，前者的加速度是后者的 **10 倍**——质量越大的物体，「不情愿改变状态」的程度越大。这个比例关系，正是下一节实验要验证的 $a \propto 1/m$。

## 4 惯性在生活中的证据

惯性不是抽象教条，它每天在身边上演。把「物体想保持原有运动状态」这条记在心里，再看这些现象会豁然开朗：

- **公交车急刹车**：车停下来，乘客的身体却「想」保持原来向前的速度，于是集体前倾。刹车越急，前倾越猛。
- **公交车启动**：车向前开，乘客的身体「想」保持原来的静止，于是向后仰。
- **抽桌布**：快速抽走桌布，桌上的杯子几乎留在原地——桌布走了，杯子靠惯性保持静止，只要抽得足够快，餐具平安。
- **磕锤柄**：锤头松了，把锤柄往地上一磕。锤柄撞地骤停，锤头因惯性继续向下「钻」，反而被楔紧。<span class="marginnote">这四个例子的共同结构是「一个物体状态突变，另一个物体靠惯性跟不上」。做受力分析时，这类现象能帮你快速判断某个力的方向——物体「想往哪边去却被迫拐弯」，力的方向就反着来。</span>

把这些例子对照两千年的观念史，会看得更清楚：

| 观点 | 力与运动的关系 | 代表人物 |
| --- | --- | --- |
| 力是维持运动的原因 | 不受力就停 | 亚里士多德 |
| 运动不需要力维持，但沿曲线需外力 | 理想实验推理 | 伽利略 |
| 不受外力则沿直线匀速 | 惯性最早清晰表述 | 笛卡尔 |
| 力是改变运动状态（产生加速度）的原因 | 定律化总结 | 牛顿 |

从亚里士多德到牛顿，变化的不是某个数据，而是**提问的方式**：从「为什么动」转向「为什么改变运动状态」。物理学史的每一次跃迁，几乎都伴随这种提问方式的升级——到第七章《相对论时空观》，我们还会看到爱因斯坦对「绝对静止」这个概念提出同样级别的一击。

这张表值得背下来吗？不必。它真正的用途是让你看清：**每一步观念跃迁，都把「力与运动」的关系想得更精确一层**。做题时如果对一个现象的解释停在「因为它有力」或「因为它没力」，不妨对照这张表自问——你现在用的是哪一代人的逻辑？

## 5 公式解析：不受力时运动状态不变

牛顿第一定律本身没有数学公式——它是一条「边界条件」，规定动力学的起点。但我们完全可以把它翻译成前面学过的运动学语言：当物体所受合力为零时，加速度为零，于是速度不随时间改变。

$$
F_{\text{合}} = 0 \iff a = 0 \iff v = \text{常量}
$$

拆三步看这条等价链：

- **第一步，$F_{\text{合}} = 0 \Rightarrow a = 0$**：这是第一定律的动力学表述，也预告了下一节的 $F = ma$。合力为零，就没有「改变运动状态的原因」，于是加速度为零。
- **第二步，$a = 0 \Rightarrow v$ 不变**：回忆加速度的定义 $a = \dfrac{\Delta v}{\Delta t}$。若 $a = 0$，则 $\Delta v = 0$，即任意时间间隔内速度都不变。**量纲检查**：$a$ 的量纲是 $[L]/[T]^2$，为零说明分母上时间的「平方」不起作用——速度对时间的**变化率**为零，这正是「状态不变」的数学表达。
- **第三步，$v = \text{常量}$ 的两种形态**：速度不变，要么静止（$v = 0$），要么匀速直线运动（$v$ 为某个不等于零的常数）。所以第一定律才说「匀速直线运动状态**或**静止状态」——它不是两件事，而是同一件事的两种取值。

**辨析｜易错点：不受力**和**受合力为零**效果相同。** 牛顿第一定律原文只谈「除非有力迫使它改变」，但它的推论立刻适用于受平衡力的物体：静止在桌面上的书，受重力与支持力，合力为零，依然保持静止。因此「保持静止或匀速直线运动」的充分条件不是「不受力」，而是「**合外力为零**」。许多同学只记住了「不受力」，做题时一遇到「受平衡力」就犹豫，其实两者在动力学上完全等价。<span class="marginnote">把「合力为零 ⟺ 状态不变」立住，后面《共点力的平衡》（第三章）才算有了动力学意义：那里你学会了算「合力为零」，这里你才知道它意味着什么。</span>

## 6 理想实验与物理学的推理方式

伽利略的理想实验之所以伟大，不只是因为它纠正了一个错误，更因为它示范了物理学的标准动作：**把现实中的干扰因素逐个剥离，推出一个无法直接实验验证、却逻辑必然的结论**。

真实实验里摩擦永远无法完全消除，于是「永不停止」永远测不到。但逻辑链条是牢固的：倾角越小滚得越远，这条趋势单调而确定；把倾角取到零的**极限**，结论只能是不停止。物理学的很多核心结论——从理想气体到质点、从光滑平面到无摩擦滑轮——都建立在这种「理想化」之上。<span class="marginnote">理想化不是偷懒，而是「先抓住主要矛盾」。质点（第一章）把形状抹掉、理想斜面把摩擦抹掉、理想气体把分子体积抹掉，都是为了先看清本质规律，再回头修正。大模型研究里的「理想化 token」「无限上下文」同理——先把主干想清楚，再谈现实约束。</span>

这套「取极限」的推理，也是数学与物理血脉相连的证明：伽利略在这里用手势完成了后世微积分里 `Δ→0` 才敢做的事。到第二级《数学分析》，极限有了 $\varepsilon$-$\delta$ 的严格定义，但思想的种子，早在 1638 年《两种新科学的对话》里就种下了。

一点补充：理想实验与真实实验的关系，常被误读成「理想实验不需要实验」。其实两者是接力关系——**理想实验的每一个前提，都必须由真实实验来证实**。伽利略断言「摩擦越小滚得越远」，这句话本身是先有了无数真实斜面实验的支撑，才能放心地推向极限。理想实验负责「把趋势推到逻辑尽头」，真实实验负责「确认趋势真的存在」。两者合起来，才构成完整的科学方法。<span class="marginnote">这条方法论对你学任何物理都适用：图像上「外推到原点」、把斜面「推到光滑」、把质量「推到无穷大」，都是同一个动作——先确认真实趋势，再取极限。看懂了这个动作，你就看懂了半个物理学。</span>

## 7 小结

- **牛顿第一定律**：一切物体总保持匀速直线运动状态或静止状态，除非有外力迫使它改变这种状态。
- **力是改变运动状态的原因，不是维持运动的原因**——这是对亚里士多德两千年错误的一击。
- **伽利略理想实验**：用「摩擦无限减小取极限」的思想，推出运动不需要力维持。
- **惯性**：物体保持原有运动状态的性质，**一切物体都有**；惯性大小只由**质量**量度，与速度无关。
- **惯性参考系**：牛顿第一定律在其中成立的参考系，是经典力学的框架边界。
- **等价链**：$F_{\text{合}} = 0 \iff a = 0 \iff v = \text{常量}$，所以「受平衡力」与「不受力」效果相同。
- **理想实验与真实实验是接力**：真实实验确认趋势，理想实验把趋势推到极限——这是贯穿物理学的推理方式。
