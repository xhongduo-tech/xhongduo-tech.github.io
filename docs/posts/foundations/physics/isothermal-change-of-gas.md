## 为什么从气体的等温变化开始

从这一节起，我们研究气体的**实验定律**——气体状态参量（压强、体积、温度）之间满足的定量关系。第一条是**等温变化**：温度保持不变时，压强与体积的关系。

玻意耳在 1662 年通过实验发现：一定质量的气体，温度不变时，压强与体积成反比——$pV = \text{常数}$。这是人类第一条定量描述气体的定律，也是气体定律家族（等温、等压、等容、理想气体方程）的起点。<span class="marginnote">「等温」是「一个量固定、研究另外两个的关系」的控制变量法：气体有三个状态参量（$p$、$V$、$T$），先固定温度研究 $p$-$V$、再固定体积研究 $p$-$T$、固定压强研究 $V$-$T$——三个实验定律拼起来就是理想气体状态方程。这条「逐对研究」的路线，是实验科学的经典方法。</span>

学这一节，请抓住：**玻意耳定律的内容与公式、$p$-$V$ 图像、微观解释**。

## 1 玻意耳定律

**玻意耳定律**：一定质量的某种气体，在**温度不变**的情况下，压强 $p$ 与体积 $V$ 成反比。

$$pV = C \quad \text{或} \quad p_1V_1 = p_2V_2$$

其中 $C$ 是常量（由气体的质量、温度、种类决定）。

**等温变化的两个状态**：气体从状态 1（$p_1$、$V_1$）等温变化到状态 2（$p_2$、$V_2$），有

$$p_1V_1 = p_2V_2$$

**关键理解**：

- 温度不变 → 分子平均动能不变 → 分子撞击的「强度」不变。
- 体积变化 → 分子数密度变化 → 碰撞频率变化 → 压强变化。
- 体积减半 → 分子数密度加倍 → 碰撞频率加倍 → 压强加倍。<span class="marginnote">玻意耳定律的微观图像（呼应分子动理论）：温度不变（分子平均动能不变），体积 $V$ 减小则分子数密度 $n = N/V$ 增大，单位时间撞到器壁的分子数增多，压强 $p \propto n\overline{E_k}$ 增大——体积减半、密度加倍、压强加倍。所以「$p$ 与 $V$ 成反比」的微观根源是「$n$ 与 $V$ 成反比」。这个「密度变化解释压强变化」的思路，是气体定律微观解释的统一模板。</span>

## 2 p-V 图像

**等温变化的 $p$-$V$ 图像**：压强与体积成反比，图像是**双曲线**（等温线）。

**图像特征**：

每个温度对应一条等温线（双曲线）。
**温度越高，等温线离原点越远**：同体积下，温度高则压强高（$pV$ 越大）。
从一条等温线到另一条：温度变化。

**p-V 图像的应用**：给出 $p$-$V$ 图上的一条等温线，可以比较两状态的温度（同在一条等温线上温度相同）；比较两条等温线，离原点远的温度高。

**辨析｜易错点：** $p$-$V$ 图是双曲线（$p = C/V$），不是直线。判断「同温度的两状态」看「是否在同一条等温线上」。两状态在不同等温线上，温度不同——离原点远的温度高（$pV$ 值大）。<span class="marginnote">「等温线离原点越远温度越高」的判断依据：$pV = C$，而 $C \propto T$（同质量气体，温度越高 $pV$ 越大）——所以「$pV$ 值 = 温度的标志」，$pV$ 大温度高。图像题里「比较两状态温度」就看 $pV$ 乘积：在图中算 $p\times V$，大者温度高。这个「$pV$ 乘积判温度」的技巧非常实用。</span>

## 3 玻意耳定律的应用

玻意耳定律在生活与工业中有大量应用：

**打气筒**：压缩气体（体积减小、压强增大），把空气压进轮胎。
**潜水**：水下深度增加，水压增大，潜水员肺内气体体积被压缩——上升时要缓慢排气，防止减压病。
**注射器**：抽拉活塞，体积增大、压强减小，把药液吸入。
**呼吸**：肺扩张（体积增大、压强减小）吸气，肺收缩呼气。
**高压锅、气垫、测量大气压（托里拆利实验）**。<span class="marginnote">「呼吸的物理」是玻意耳定律的日常体现：膈肌下移 → 胸腔与肺体积增大 → 肺内压强降低（低于大气压）→ 空气被大气压「压」进肺里（吸气）；膈肌上移 → 体积减小 → 压强增大 → 气体排出（呼气）。「吸气」不是「肺把空气吸进来」，而是「肺变大让气压降低、大气把空气推进来」。玻意耳定律让「呼吸」这个动作变得可以定量理解。</span>

## 4 公式解析：p₁V₁ = p₂V₂

$$p_1V_1 = p_2V_2$$

拆三步看：

- **第一步，为什么是「乘积不变」**：温度不变 → 分子平均动能不变 → 压强 $\propto$ 分子数密度 $\propto 1/V$ → $p \propto 1/V$ → $pV = \text{常数}$。**「压强与密度成正比、密度与体积成反比」两链合起来就是 $pV$ 常数**。<span class="marginnote">$pV = C$ 的「三变量视角」：等温变化中 $p$、$V$ 此消彼长但乘积锁定。$pV$ 乘积的物理意义是「温度的标志」（同质量气体 $pV \propto T$）——等温就是「$pV$ 不变」。所以「等温线」也叫「等 $pV$ 线」，判断等温看 $pV$ 是否相等。</span>
**第二步，单位的一致性**：公式中 $p$、$V$ 用任意配套单位（Pa 与 m³、cmHg 与 cm³）都行，只要前后一致——因为 $p_1V_1 = p_2V_2$ 是比值关系，单位只影响常数 $C$ 的数值。
**第三步，适用条件**：一定质量、温度不变、理想气体（或低压高温的实际气体近似）。
**第四步，计算流程**：列初状态（$p_1$、$V_1$）与末状态（$p_2$、$V_2$）→ 代入 $p_1V_1 = p_2V_2$ → 解未知量。多过程问题（等温压缩后再等压膨胀）要「状态追踪」——每一步用对应的定律。

## 5 玻意耳定律的实验验证

玻意耳定律的实验（近似等温）：

**装置**：一端封闭的玻璃管，管内封入一定质量的气体，用汞柱（或活塞）改变气体的压强与体积。
**操作**：缓慢移动汞柱（让气体与外界热交换充分，保持温度不变），记录多组压强与体积。
**处理**：把 $p$-$V$ 数据画图，验证是双曲线（或画 $p$-$1/V$ 图像验证是过原点的直线）。

**关键实验条件**：**缓慢**操作——让气体有时间与外界交换热量，保持温度不变（等温）。快速压缩会升温（绝热压缩，下一章）。

**辨析｜易错点：** 玻意耳定律成立的前提是「等温」——实验必须缓慢进行。快速压缩气体时温度升高（压缩做功、来不及散热），$p$、$V$ 不满足 $pV$ 常数。做题时「缓慢」是等温的信号、「迅速」是绝热的信号。<span class="marginnote">「缓慢 = 等温、迅速 = 绝热」是气体过程题的读题关键：缓慢压缩时气体与外界充分热交换、温度不变（等温，$pV$ 常数）；快速压缩时来不及散热、温度升高（绝热，$pV^\gamma$ 常数，$\gamma > 1$）。同样压到一半体积，绝热比等温的压强升高更多（温度也升高了）。「缓慢还是迅速」决定用哪条定律——这是气体综合题的第一步判断。</span>

## 6 辨析｜易错点

- **温度不变才 $pV$ 常数**：不是任何过程都成立。
- **$p$-$V$ 图是双曲线**：同温度在同一条等温线；$pV$ 大温度高。
- **缓慢 = 等温**：快速压缩会升温，不满足玻意耳定律。
- **一定质量的气体**：质量变化（漏气、充气）不能用 $p_1V_1 = p_2V_2$ 直接算。
- **单位配套即可**：$p$、$V$ 前后用同一单位。
- **微观解释**：温度不变、密度变、碰撞频率变、压强变。

## 7 小结

- **玻意耳定律**：一定质量气体、温度不变时，$pV = \text{常数}$，$p_1V_1 = p_2V_2$。
- **微观解释**：温度不变 → 密度变 → 碰撞频率变 → 压强与体积成反比。
- **$p$-$V$ 图像**：双曲线（等温线）；离原点远温度高。
- **应用**：打气筒、呼吸、潜水、注射器。
- **实验条件**：缓慢操作保持等温。
- 「缓慢 = 等温、迅速 = 绝热」——过程性质的读题信号。

在下一节，我们研究气体的另外两条定律：**气体的等压变化和等容变化**。压强不变时体积与温度成正比（盖-吕萨克定律）、体积不变时压强与温度成正比（查理定律）。
