## 为什么从力的合成和分解开始

上一节讲的是「两个物体之间的相互作用」，这一节我们把镜头拉回**同一个物体**：当它同时受到好几个力时，能不能把这些力「打包」成一个力来研究？答案是能，但打包的方式不是简单的加减——力是有方向的，加力要按**向量的加法**来加。你同时被两个人以不同方向拉，你会往哪个方向动，正是两个力的**合力**方向。这一问题在数学里早就准备好了答案：**向量**。基础数学的平面向量教会了我们向量加法的平行四边形法则，而物理在这里第一次让它在真实世界里「干活」。

从体系看，力的合成与分解是受力分析的后半程：前几节学「认识一个力」，这里学「把一堆力变成更少、更简单的力」。下一节《共点力的平衡》将直接消费这里的成果——判断物体是否平衡，第一步就是先把所有力合成、分解。<span class="marginnote">「等效替换」是物理学里最深刻的思想之一：不关心中间细节，只要求「效果相同」。后面学电路时的「等效电阻」、学天体时把地球当「质点」、甚至深度学习里把大网络「蒸馏」成小模型，都是同一套路——找替身，用简单对象代替复杂对象。</span>

## 1 合力与分力：等效替换

**合力（resultant force）**：如果一个力 $F$ 单独作用在物体上产生的效果，与几个力（如 $F_1$、$F_2$）共同作用产生的效果**相同**，则 $F$ 叫作这几个力的合力。

**分力（component force）**：反过来，那几个力就叫作 $F$ 的分力。

「效果相同」是这里的灵魂：它指的是力的作用效果（改变运动状态、发生形变）相同，而不是说某个力「真的同时存在」。一个物体上不会同时存在「合力」和「分力」两套力——它们是同一作用效果的两种描述，二选一。<span class="marginnote">受力分析时，**合力与分力不能同时画**。画了分力 $F_1$、$F_2$，就不能再画它们的合力 $F$；画了合力，就不能再画分力。好比说一个人「身高 180 cm」和「身高 6 英尺」——两种说法，同一个人，不能叠着说。</span>

**重点：求合力不是把两个数相加，而是把两个向量相加。** 这就是为什么必须引入几何法则，而不是简单地算 $F_1 + F_2$。

## 2 平行四边形定则：合成的方法

**平行四边形定则（parallelogram law）**：求两个互成角度的共点力的合力，可以用表示这两个力的线段为邻边作平行四边形，这两条邻边之间的对角线就表示合力的大小和方向。

![两个共点力 F₁、F₂ 的合成：以 F₁、F₂ 为邻边作平行四边形，对角线 O→C 即合力 F，夹角为 θ](/images/physics/force-composition-and-resolution-1.svg)

两个力 $F_1$、$F_2$ 的夹角为 $\theta$ 时，合力大小由余弦定理给出：

$$F = \sqrt{F_1^2 + F_2^2 + 2F_1F_2\cos\theta}$$

特殊角度可以立刻代出：

- $\theta = 0^\circ$（同向）：$F = F_1 + F_2$，合力取最大值；
- $\theta = 180^\circ$（反向）：$F = |F_1 - F_2|$，合力取最小值；
- $\theta = 90^\circ$（垂直）：$F = \sqrt{F_1^2 + F_2^2}$，勾股定理直接生效。

于是有一个重要的范围结论：**合力的大小在 $|F_1 - F_2|$ 与 $F_1 + F_2$ 之间**：

$$|F_1 - F_2| \le F \le F_1 + F_2$$

**易错点：合力不一定大于分力。** 当两个分力夹角大于 $90^\circ$ 时，合力甚至可能比其中任何一个分力都小。两个等大的力反向时合力为零——这是「方向」在物理里无比重要的最直接证据。<span class="marginnote">最大值、最小值各对应一种极端夹角，画一画平行四边形就能直观看到：夹角越大，对角线越短。这条「夹角决定合力大小」的直觉，在后面万有引力、电场力的合成里会反复用到。</span>

### 三角形定则

平行四边形的一半就是**三角形定则（triangle rule）**：把 $\vec{F}_1$ 的终点与 $\vec{F}_2$ 的起点相接，则从 $\vec{F}_1$ 的起点指向 $\vec{F}_2$ 的终点的那条有向线段，就是合力 $\vec{F}$。画图时，三角形定则比平行四边形少画两条虚线，速度快、不易乱；它的本质与平行四边形完全一致——向量加法 $\vec{F} = \vec{F}_1 + \vec{F}_2$。

### 例题：算一算合力

设 $F_1 = 6\,\mathrm{N}$、$F_2 = 8\,\mathrm{N}$，代入合力公式看四种夹角：

| 夹角 $\theta$ | $\cos\theta$ | 合力 $F$ | 说明 |
| --- | --- | --- | --- |
| $0^\circ$ | 1 | $14\,\mathrm{N}$ | 同向，最大 |
| $60^\circ$ | 0.5 | $\sqrt{36+64+48} \approx 12.2\,\mathrm{N}$ | 中等 |
| $90^\circ$ | 0 | $10\,\mathrm{N}$ | 勾股定理，3-4-5 放大版 |
| $180^\circ$ | -1 | $2\,\mathrm{N}$ | 反向，最小 |

注意 $90^\circ$ 时出现了熟悉的 3-4-5 直角三角形（两边乘 2），这是勾股定理在物理里的直接「露脸」。$180^\circ$ 时合力取最小值 $|F_1 - F_2| = 2\,\mathrm{N}$——两个力几乎互相「吃掉」，只剩差。

## 3 力的分解：任意性与正交分解

**力的分解（resolution of a force）**：求一个力的分力。它是合成的逆运算，同样遵循平行四边形定则——把合力当作对角线，作平行四边形，相邻两边就是分力。

但分解比合成「自由」得多：**同一个力，可以分解成无穷多种分力组合**。任意两条「分力」只要满足平行四边形法则，就能凑出同一个合力。要让分解唯一确定，必须补充约束条件，常见的有两种：

- 已知两个分力的**方向**（按力的作用效果分解，例如把斜面上的重力分解为沿斜面与垂直斜面两个方向）；
- 已知一个分力的大小和方向。

在所有分解方式中，最常用的是**正交分解（orthogonal decomposition）**：把力分解到两个**互相垂直**的方向上。设力 $F$ 与 $x$ 轴夹角为 $\theta$，则：

$$F_x = F\cos\theta, \qquad F_y = F\sin\theta$$

正交分解之所以是「工程标配」，是因为它把**斜着的力**变成**两个沿坐标轴的力**，而沿轴的力可以直接代数加减。<span class="marginnote">正交分解是「降维」：把二维的矢量运算，降成两条一维的标量运算。这个思想与线性代数里「把向量按基分解」完全同构——坐标轴就是一组基，$F_x, F_y$ 就是坐标。到第二级《线性代数》你会看到，这是所有向量空间运算的地基。</span>

**辨析｜易错点：** 分解不是「随便拆」。两个常见错误是：其一，把分解当成「把一个力拆成两个固定大小的数」，忽略了方向；其二，在受力分析里既画合力又画分力，造成「力的个数翻倍」。记住：分解的唯一目的是**让问题更简单**——只有当你选的方向能让力直接相加时，才值得分解。

## 4 公式解析：合力大小公式

这条公式是三角函数进入物理的第一次「实战」，值得四步拆解：

$$F = \sqrt{F_1^2 + F_2^2 + 2F_1F_2\cos\theta}$$

**第一步，读懂结构。** 根号内前两项 $F_1^2 + F_2^2$ 是勾股定理的骨架，第三项 $2F_1F_2\cos\theta$ 是「夹角修正项」。夹角为零时 $\cos 0^\circ = 1$，修正项最大，合力变成 $F_1 + F_2$；夹角为 $90^\circ$ 时 $\cos 90^\circ = 0$，修正项消失，回到勾股定理。

**第二步，它从哪来。** 把 $\vec{F}_1$ 沿 $\vec{F}_2$ 方向分解：$\vec{F}_1$ 在该方向的分量是 $F_1\cos\theta$。于是沿 $F_2$ 方向的总分量是 $F_2 + F_1\cos\theta$，垂直于该方向的分量是 $F_1\sin\theta$。由勾股定理：

$$F = \sqrt{(F_2 + F_1\cos\theta)^2 + (F_1\sin\theta)^2}$$

展开平方项，利用 $\sin^2\theta + \cos^2\theta = 1$ 合并得 $F_1^2$，交叉项得 $2F_1F_2\cos\theta$，于是回到原式。<span class="marginnote">这种「先分解到坐标轴、再合并」的两步走，正是正交分解的标准动作。公式解析最好的回报，是你在后面所有「三角形 → 代数」的推导里都能认出同一个套路。</span>

**第三步，量纲检查。** 根号内每一项都是「力 × 力」，量纲为 $(\mathrm{MLT}^{-2})^2$；开根号后变回 $\mathrm{MLT}^{-2}$，与合力 $F$ 的量纲一致。平方与开根号是「量纲保底」的运算，不会改变物理量的维度。

**第四步，边界校验。** 代入两个极端：$\theta = 0^\circ$ 得 $F = F_1 + F_2$（同向最大），$\theta = 180^\circ$ 得 $F = |F_1 - F_2|$（反向最小）。公式与「常识」对上了，说明它经得起直觉检验。数学公式在物理里的作用，不是「背下来」，而是「算得对、验得回」。

## 5 受力分析实战：从合成到平衡

把合成、分解工具收进工具箱后，受力分析的标准流程变为四步：

1. **确定研究对象**，只画它受到的力；
2. **先画重力、再画弹力、最后画摩擦力**（按「易」到「难」的顺序，避免漏力）；
3. **建坐标系，正交分解**，把斜力变直力；
4. **按方向列方程**：沿某一方向合力满足的条件（下一节将给出「合力为零」这一终极条件）。

一个立刻能用的例子：物块在倾角为 $\theta$ 的粗糙斜面上匀速下滑。沿斜面建轴，重力分解为沿斜面向下的 $mg\sin\theta$ 与垂直斜面向下的 $mg\cos\theta$。垂直方向支持力 $N = mg\cos\theta$；沿斜面方向由匀速条件得 $mg\sin\theta = f$。若又知 $f = \mu N$，则 $\mu = \tan\theta$——一个简洁、可实验验证的结论。<span class="marginnote">$\mu = \tan\theta$ 是一条「测动摩擦因数」的经典方法：让物块在斜面上恰好匀速下滑，量出倾角即可。它在实验题与竞赛题里反复出现，值得会推导而不是死背。</span>

## 6 小结

- **合力与分力**是同一作用效果的两种描述，受力分析中不能同时画出。
- 合成遵循**平行四边形定则**，合力大小 $F = \sqrt{F_1^2 + F_2^2 + 2F_1F_2\cos\theta}$，范围 $|F_1 - F_2| \le F \le F_1 + F_2$。
- **合力不一定大于分力**，夹角越大合力越小。
- 分解具有**任意性**，常用**正交分解** $F_x = F\cos\theta,\ F_y = F\sin\theta$ 把斜力降维。
- 受力分析四步：定对象 → 按序画力 → 正交分解 → 列方程。

在下一节，我们把全部工具合起来回答一个问题：一个物体同时受几个共点力，究竟在什么条件下才能保持静止或匀速直线运动——这就是**共点力的平衡**。
