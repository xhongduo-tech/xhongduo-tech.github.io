## 为什么从练习使用多用电表开始

上一节我们学了电表改装——电流表并分流电阻、电压表串分压电阻。如果把所有量程的改装电阻都装进一只表，再配一个欧姆表电路，用旋转开关切换，就得到一只**多用电表（万用表，multimeter）**。它是电工、电子工程师的「瑞士军刀」：测电压、测电流、测电阻、测二极管，一只表全搞定。

这一节是动手实践课：学会正确使用多用电表，包括**读数、选挡、正确连接、欧姆调零、以及「欧姆挡不能带电测电阻」**这些关键纪律。看似是操作细节，每一条背后都是电路原理：为什么测电阻要先调零？为什么测电阻时被测电路要断电？为什么换挡要重新调零？答案都在前几节的定律里。<span class="marginnote">多用电表的本质是「一只灵敏电流表头 + 一堆改装配件」：测电压时串联不同的分压电阻（变电压表），测电流时并联不同的分流电阻（变电流表），测电阻时接入内部电池 + 可变调零电阻（变欧姆表）。旋转开关只是在切换「给表头配上哪套改装电阻」。理解了上一节电表改装，就理解了万用表的全部内部逻辑。</span>

学这一节，请在动手前先想清楚「这只表此刻测的是什么物理量、它的内部接成了什么电路」——理解了原理，操作就不会错。

## 1 多用电表的结构

多用电表的外形与挡位：

- **表盘**：有多条刻度线——测量直流电压/电流用一组刻度，测电阻用另一组刻度（欧姆挡刻度右大左小、不均匀，这是它的最大特征）。
- **挡位选择开关**：旋转选择测量对象与量程。常见挡位：直流电压挡（V）、交流电压挡（V~）、直流电流挡（A）、欧姆挡（Ω）、以及测二极管的挡位。
- **表笔**：红表笔接正极、黑表笔接负极（约定）。测量时红进黑出。
- **调零旋钮**：欧姆挡专用，测量前调节使指针指到欧姆零位（右端）。

**表盘读数要点**：直流电压/电流刻度是均匀的（线性刻度），读数按量程换算；欧姆挡刻度是不均匀的（反比刻度），且「表盘右端为 0、左端为无穷大」——与电压挡方向相反，这是欧姆表最反直觉的地方。<span class="marginnote">欧姆表刻度「右零左大」源自欧姆表原理：表头与内阻 $R$、电池串成回路，外接被测电阻 $R_x$，电流 $I = E/(R + R_x)$。$R_x = 0$ 时电流最大（指针右偏到底，刻度 0）；$R_x \to \infty$ 时电流为零（指针左端，刻度 $\infty$）。所以欧姆表刻度是「$I \propto 1/(R+R_x)$」的倒数值——不均匀、右零左无穷。理解了原理，刻度方向就不会记反。</span>

## 2 测量电压与电流：与常规电表相同

**测电压**：多用电表当电压表用——**并联**在被测电路两端，红表笔接高电势端。选量程要「大于并接近被测值」：量程太小会超量程打表，太大则读数误差大。直流挡测直流、交流挡测交流，不能混用。<span class="marginnote">选量程的原则是「宁大勿超、就近选择」：先估个量级，选比它稍大的最小挡位。指针偏转在量程中后部（约 2/3 处）读数最准，因为相对误差 = 绝对误差/读数，读数大则相对误差小。这是所有指针式仪表共通的读数智慧——「让指针尽量偏过去」。</span>

**测电流**：多用电表当电流表用——**串联**接入被测电路，红表笔接电流流入端（靠近电源正极）。测量时**必须先断开电路、把表串进去再合上**，绝不能在通电状态下把表笔直接搭在电路两点之间测电流（相当于短路，会烧表）。

**辨析｜易错点：** 电压表并联、电流表串联——这是电表使用的第一纪律。把电流挡当电压挡用（并联测电压），会因电流表内阻极小造成短路、烧毁电表；把电压挡当电流挡用（串联进电路），内阻太大几乎断流、读数错误。**接线前先确认「测什么、怎么接」**，是万用表使用的第一安全守则。

## 3 测量电阻：欧姆挡的特殊纪律

测电阻与测电压电流有本质区别：**欧姆挡内部有电池，它通过「给被测电阻供电、测电流」来测电阻**。因此有几条铁律：

1. **选挡与调零**：选好欧姆挡位后，先**红黑表笔短接**，调节调零旋钮使指针指到欧姆刻度右端零位——这叫**欧姆调零**。每换一次挡位都要重新调零（挡位不同内部电阻不同）。
2. **被测电阻要断电、独立**：测量前必须**断开被测电阻的电源**，并把它**从电路中取下来**（至少断开一端），否则并联的其他元件会改变读数。
3. **不要用手同时捏住表笔与电阻两端**：人体电阻并联进去，读数会偏小。
4. **读数乘倍率**：指针读数 × 所选倍率（如「×100」），才是电阻值。
5. **指针偏转到中间刻度附近最准**：欧姆表刻度不均匀，中值附近精度最高。偏转太靠左（读数太大）换大倍率，太靠右（读数太小）换小倍率。<span class="marginnote">欧姆表的中值电阻（刻度正中间对应的阻值）等于表头内阻加调零电阻的总内阻 $R$。指针在中值附近时，被测电阻与内阻相当，相对误差最小。所以用欧姆表要「先估一下、选个倍率让指针落中间」——表盘中间区域才是它的「舒适区」。这再次印证「选挡看量级」的原则。</span>

**为什么测电阻要断电？** 欧姆表内部有电池，若被测电阻仍接在带电电路中，外部电源会「反灌」电流进表头，轻则读数错误，重则烧表。所以「先断电、再取件、再测量」是欧姆挡的标准三步。

## 4 多用电表判断电路故障

多用电表的一个高级用途是**判断电路故障**：短路、断路、接触不良。常用方法是「测电压」与「测电阻」结合：

- **断路故障**：某处断开，电路无电流。用电压挡测各段电压，断点两端会有电压（电源电压全落在断点处），正常导线段两端电压为零——「有压处即断路点」。
- **短路故障**：用欧姆挡测各元件，短路处电阻为零，断路处电阻无穷大。
- **判断元件好坏**：测电阻挡测电阻/灯泡，阻值符合标称则正常；测二极管用二极管挡，正向导通（显示压降）、反向截止（显示无穷大）则正常。

**辨析｜易错点：** 判断故障时，**断电用欧姆挡、通电用电压挡**——别在通电状态下测电阻（会烧表），也别在断电状态下用电压挡（读不出故障）。「测电压找断路、测电阻找短路」，这两句话记住，故障判断题就稳了。<span class="marginnote">故障排查是万用表最「值钱」的应用：维修电工一天到晚在找「哪里断了、哪里短路了」。它背后的逻辑很朴素——「通电找压降（断点承担全部电压）、断电找阻值（短路为零断路无穷）」。这种「用测量缩小可疑范围」的思路，是工程诊断的通用方法，与软件调试里的二分定位异曲同工。</span>

## 5 公式解析：欧姆表原理 I = E/(R + R_x)

$$I = \frac{E}{R + R_x}$$

拆三步看：

- **第一步，电路结构**：欧姆表内部是「表头 + 调零电阻 + 电池」串联，两端接被测电阻 $R_x$。总电阻 = 内阻 $R$ + 被测电阻 $R_x$，电流 $I = E/(R + R_x)$。
- **第二步，三个特殊点**：$R_x = 0$（短接表笔）时 $I = E/R$ 最大，指针满偏——这就是「欧姆零位在右端」的原因；$R_x = R$ 时 $I = E/(2R)$ 恰为满偏一半，指针在正中——中值电阻；$R_x \to \infty$（开路）时 $I = 0$，指针不动在左端——无穷大刻度。**刻度「右零左无穷」正是由这个公式决定的**。<span class="marginnote">从 $I = E/(R+R_x)$ 还能看出欧姆表刻度为何不均匀：$I$ 与 $R_x$ 是「反比加常数」关系，不是线性关系。所以在中值附近指针变化最灵敏（$R_x$ 从 0 到 R 变化很大一段），越往两端越迟钝。这也是「用中值附近测最准」的理论根源。</span>
- **第三步，调零的本质**：短接表笔时 $R_x = 0$，若指针不在零位，说明电池电压 $E$ 或内阻 $R$ 变了（电池用久了电压下降）。旋转调零旋钮改变 $R$，让 $I = E/R$ 恰好等于满偏电流——把「内阻」校准到与当前电池匹配。**换挡后内阻 $R$ 改变，所以要重新调零**。
- **第四步，为什么不能带电测**：若被测电阻接在带电电路中，外部电源电压 $U_{\text{外}}$ 会叠加进回路，电流变成 $I = (E \pm U_{\text{外}})/(R + R_x)$——读数全乱，甚至反灌烧表。断电测电阻是原理的必然要求，不是操作洁癖。

## 6 使用多用电表的完整流程

把正确操作流程写成清单，动手前默念一遍：

1. **看挡位**：确认旋转开关在正确挡位（测什么、量程多少）。
2. **接表笔**：红笔接正端、黑笔接负端；测电阻前先短接调零。
3. **正确接线**：测电压并联、测电流串联、测电阻取下元件且断电。
4. **读数**：看清用哪条刻度线，换算倍率/量程。
5. **用毕复位**：将挡位旋到「OFF」或最高交流电压挡，避免误用烧表。

**安全守则**：电流挡绝不并联；通电时绝不测电阻；量程宁大勿小；手不触表笔金属端。这几条是万用表使用的生命线。<span class="marginnote">「用毕把挡位打到 OFF 或高压挡」是仪器保养的细节，但很有必要：如果留在欧姆挡，下次使用时表笔可能被误接在带电电路上，瞬间烧表。好习惯来自对原理的理解——欧姆挡内部有电池且内阻低，最怕外部电压「反灌」。</span>

## 7 辨析｜易错点

- **测电阻必须先断电、取元件**：带电测电阻读数必错、甚至烧表。
- **欧姆挡换挡必须重新调零**：挡位不同内阻不同，零位跟着变。
- **欧姆刻度不均匀、右零左无穷**：读欧姆表别按电压表的均匀刻度想当然。
- **指针偏到中间刻度附近最准**：选倍率让读数落在中值区，偏左换大挡、偏右换小挡。
- **测电压并联、测电流串联**：接反轻则读数错误、重则短路烧表。
- **红表笔的极性约定**：测直流时红接高电势端；测电阻时表笔极性不影响读数（内部电池方向已定）。

## 8 小结

- **多用电表** = 一只表头 + 电压/电流/欧姆三套改装配件，旋转开关切换。
- **测电压**：并联，量程就近选；**测电流**：串联，断电接入。
- **测电阻**：选挡 → 短接调零 → 取下元件断电 → 读数乘倍率；中值区最准。
- **欧姆表原理**：$I = E/(R + R_x)$，刻度右零左无穷、不均匀，中值电阻 = 内阻。
- **故障判断**：通电测电压找断路，断电测电阻找短路。
- **安全纪律**：电流挡不并联、带电不测电阻、用毕复位置 OFF。
