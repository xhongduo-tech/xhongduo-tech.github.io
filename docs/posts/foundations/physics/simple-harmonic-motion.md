## 为什么从简谐运动开始

前六节我们研究的运动都是「一去不回头」的：匀变速、圆周、碰撞。但自然界还有一类极其重要的运动——**往复的、周期性的运动**：钟摆、秋千、琴弦、弹簧、心脏跳动、分子振动、地震波……这类运动叫**振动**，其中最简单、也最根本的一种，就是**简谐运动（simple harmonic motion，SHM）**。

为什么简谐运动如此重要？因为它是「振动世界的匀速圆周」——一切复杂的振动都可以分解成若干简谐运动的叠加。它还是连接宏观与微观的桥梁：弹簧振子是宏观的简谐运动，而原子中电子、分子的振动在平衡位置附近也是简谐运动的量子版本。从钟表到激光，从声波到交流电，简谐运动无处不在。<span class="marginnote">简谐运动的地位可以从数学上看清：它对应的是「位移的二阶导数与位移成正比反向」这个最简单的二阶微分方程（$\ddot x = -\omega^2 x$）。就像匀速直线是「速度不变」的最简单运动，简谐运动是「加速度与位移成正比反向」的最简单振动。更高级的振动（阻尼振动、受迫振动）都是在它基础上加项——掌握了简谐运动，就掌握了振动的「骨架」。</span>

学这一节，请抓住两个核心量：**回复力**（把物体拉回平衡位置的力）与**位移-时间关系**（正弦函数）。理解了「为什么 $x = A\sin\omega t$ 是简谐运动的解」，整章的公式就都活了。

## 1 机械振动与平衡位置

**机械振动（mechanical vibration）**：物体在平衡位置附近所做的往复运动。

**平衡位置**：振动物体受到的合力为零的位置。注意「平衡位置」不是「静止位置」——振子在平衡位置时合力为零、加速度为零，但速度最大（它正从这里冲过去）。<span class="marginnote">「平衡位置速度最大」是振动里最反直觉的结论之一：位移为零的地方，速度反而最大；位移最大的两端，速度为零。原因：平衡位置合力为零、加速度为零，物体「惯性滑过」最快；而两端位移最大、回复力最大、加速度最大，物体被「急刹车」停住再折返。理解「位移、速度、加速度三者的相位关系」是读懂振动的关键。</span>

**辨析｜易错点：** 平衡位置是「合力为零」，不是「速度为零」。弹簧振子拉到最远处释放，最远处（最大位移处）速度为零但合力最大；平衡位置合力为零但速度最大。把「平衡位置」与「静止位置」混为一谈，是振动的第一误区。

## 2 弹簧振子与回复力

**弹簧振子**：一端固定的轻弹簧 + 连着的物体（在光滑水平面上）。它是简谐运动最标准的模型。

**回复力**：把振动物体拉回平衡位置的力。对水平弹簧振子，回复力就是弹簧弹力：

$$F = -kx$$

其中 $x$ 是相对平衡位置的位移（不是弹簧总长！），$k$ 是劲度系数，负号表示「方向与位移相反」——力总是指向平衡位置。

**回复力的两个特征**：

1. **方向**：始终指向平衡位置（与位移方向相反）。
2. **大小**：与位移大小成正比（线性关系）。<span class="marginnote">「回复力与位移成正比且反向」——$F = -kx$——就是简谐运动的定义性特征。判断一个运动是不是简谐运动，就看它的回复力能否写成 $F = -kx$ 的形式。例如单摆在小角度下，回复力近似 $F \approx -\dfrac{mg}{L}x$，也是简谐运动（下一节会严格推导）；而一般的摆动角度大时回复力与位移不成正比，就不再是简谐运动。这个「定义式」思路，比死记模型更有用。</span>

**辨析｜易错点：** $x$ 是**相对平衡位置的位移**，不是弹簧的形变量（弹簧原长两端）。若平衡位置不在弹簧原长（如竖直悬挂的弹簧，平衡时弹簧已拉伸 $mg/k$），$x$ 从平衡位置算起，$F = -kx$ 中的 $x$ 仍是「离平衡位置的位移」。**先找平衡位置，再写 $F = -kx$**，是弹簧振子题的第一步。

## 3 简谐运动的定义与位移-时间关系

**简谐运动（SHM）**：物体在平衡位置附近振动，其位移随时间按**正弦（或余弦）规律**变化。

$$x = A\sin(\omega t + \varphi_0)$$

其中：

- **振幅 $A$**：振动物体离开平衡位置的最大距离，表示振动的幅度。
- **角频率 $\omega$**：振动的快慢，$\omega = 2\pi/T = 2\pi f$（$T$ 为周期，$f$ 为频率）。
- **初相 $\varphi_0$**：$t = 0$ 时的相位，决定起始位置。
- **相位 $(\omega t + \varphi_0)$**：描述振动「进行到哪一步」的角度量。

**为什么简谐运动的位移是正弦函数？** 由回复力 $F = -kx$ 与牛顿第二定律 $F = ma = m\ddot x$ 联立：

$$m\ddot x = -kx \quad\Rightarrow\quad \ddot x = -\frac{k}{m}x$$

这个微分方程的解正是 $x = A\sin(\omega t + \varphi_0)$，且 $\omega = \sqrt{k/m}$。<span class="marginnote">「位移的正弦函数」与「回复力的线性」互为因果：$F = -kx$ 的线性回复力必然导致位移按正弦变化，而正弦函数的二阶导数仍是正弦（只是多一个 $-\omega^2$ 因子）——正弦函数是「二阶导等于自身负倍数」的函数。这个「线性回复力 ↔ 正弦解」的对应，是简谐运动全部公式的源头。</span>

**周期公式**（弹簧振子）：

$$T = 2\pi\sqrt{\frac{m}{k}}$$

**周期只由振子自身的质量与劲度系数决定**，与振幅、初相无关——这就是**等时性**（振子无论拉多远，周期相同）。

## 4 位移、速度、加速度的图像与相位

简谐运动中，位移、速度、加速度三者都是正弦函数，但相位依次相差：

- **位移**：$x = A\sin\omega t$（设初相为零）。
- **速度**：$v = \dot x = A\omega\cos\omega t = A\omega\sin(\omega t + \tfrac{\pi}{2})$——**速度相位超前位移 $\tfrac{\pi}{2}$**。
- **加速度**：$a = \ddot x = -A\omega^2\sin\omega t = A\omega^2\sin(\omega t + \pi)$——**加速度相位超前位移 $\pi$（即与位移反相）**。

三个量的对应关系：

| 位置 | 位移 $x$ | 速度 $v$ | 加速度 $a$ |
| --- | --- | --- | --- |
| 平衡位置 | 0 | 最大（±$A\omega$） | 0 |
| 最大位移处 | ±$A$ | 0 | 最大（∓$A\omega^2$） |
| 方向 | 从平衡位置向外 | 指向运动方向 | 总指向平衡位置 |<span class="marginnote">三量的相位关系用「轮转」记忆：位移最大处速度零、加速度最大（指向平衡位置）；平衡位置位移零、速度最大、加速度零。从图像看，$x$、$v$、$a$ 三条正弦曲线依次「错开」$\tfrac{\pi}{2}$ 相位——这就是「相位」概念的价值：它用一个角度统一描述「振动进行到哪一步」，三个物理量各差一个固定相位。</span>

**辨析｜易错点：** 加速度方向**始终指向平衡位置**（与位移反向），不是因为「加速度与位移成正比反向」的简谐运动定义——这是由 $F = -kx$ 决定的。但**速度方向**不一定指向平衡位置——物体向最大位移处运动时，速度与位移同向。把「加速度总指向平衡位置」与「速度总指向平衡位置」混为一谈，是振动题的常见错误。

## 5 公式解析：x = Asin(ωt + φ₀)

$$x = A\sin(\omega t + \varphi_0), \qquad \omega = \sqrt{\frac{k}{m}}, \qquad T = 2\pi\sqrt{\frac{m}{k}}$$

拆三步看：

- **第一步，为什么是正弦**：由 $F = -kx$ 与牛顿第二定律得 $\ddot x = -(k/m)x$。数学上，满足「二阶导数 = 自身负常数倍」的函数正是正弦/余弦。**物理定律（回复力线性）→ 微分方程 → 正弦解**，三步锁死。<span class="marginnote">验证一下：设 $x = A\sin(\omega t+\varphi_0)$，求二阶导得 $\ddot x = -A\omega^2\sin(\omega t+\varphi_0) = -\omega^2 x$，与 $\ddot x = -(k/m)x$ 对比得 $\omega^2 = k/m$。所以「$x$ 是正弦函数」与「$\omega = \sqrt{k/m}$」同时从微分方程得出——它们是同一条链上的两个结论。</span>
- **第二步，振幅与初相从哪来**：微分方程确定 $\omega$（由系统固有属性 $k$、$m$ 决定），但 $A$ 与 $\varphi_0$ 由**初始条件**决定——拉多远（初始位移）决定 $A$，从哪开始计时（初始位置与速度）决定 $\varphi_0$。**方程给「快慢」，初始条件给「起点」**。
- **第三步，为什么周期与振幅无关（等时性）**：$T = 2\pi\sqrt{m/k}$ 里没有 $A$——无论振幅多大，周期相同。这源于回复力的「线性」：位移大一倍，回复力也大一倍，加速度也大一倍，「按比例加速」恰好抵消了「多走的路」。摆钟的等时性、弹簧振子的稳定周期，都靠这条。
- **第四步，量级与单位**：$\omega$ 单位 $\text{rad/s}$，$T$ 单位 s，$f$ 单位 Hz；$A$ 单位 m。$\omega = 2\pi f = 2\pi/T$ 是频率的「角版本」，换算别错。

## 6 简谐运动的能量

简谐运动中，动能与弹性势能（或重力势能）不断转化，但**机械能守恒**（光滑无摩擦时）：

$$E = \frac{1}{2}kx^2 + \frac{1}{2}mv^2 = \frac{1}{2}kA^2$$

- 平衡位置：$x = 0$，动能最大 $\tfrac{1}{2}kA^2$，势能为零。
- 最大位移处：$x = A$，动能为零，势能最大 $\tfrac{1}{2}kA^2$。
- **总能量正比于振幅平方** $A^2$——振幅越大，振动能量越大（$E = \tfrac{1}{2}kA^2$）。

**辨析｜易错点：** 简谐运动的机械能守恒**只在无阻尼（光滑、无空气阻力）时成立**。真实振子总有能量损失（阻尼），振幅不断减小，这就是下一节《受迫振动 共振》里的阻尼振动。另外「机械能守恒」与「$x = A\sin\omega t$ 的等幅振动」是同一前提的两面——等幅是因为能量不损失。<span class="marginnote">能量视角给简谐运动一个新图像：振子像「能量在动能与势能之间荡秋千」，总能量恒定 $\tfrac{1}{2}kA^2$。到量子力学（下册），同一系统能量量子化后，简谐振子的能量变成 $E_n = (n+\tfrac{1}{2})hf$——经典的能量连续变成了量子的一级级台阶。弹簧振子是你第一次认识「谐振子」，而它是贯穿经典与量子的核心模型。</span>

## 7 辨析｜易错点

- **平衡位置是合力为零，不是静止**：平衡位置速度最大、加速度为零；最大位移处速度为零、加速度最大。
- **回复力与位移成正比反向**：$F = -kx$ 是简谐运动的定义特征；判断是否简谐运动就看能否写成这个形式。
- **$x$ 是相对平衡位置的位移**：不是弹簧形变量，找平衡位置是第一步。
- **周期与振幅无关**（等时性）：$T = 2\pi\sqrt{m/k}$，只由系统固有属性决定。
- **加速度总指向平衡位置，速度不总指向**：别把两者混同。
- **简谐运动机械能守恒**（无阻尼时）：总能量 $\tfrac{1}{2}kA^2$，正比于振幅平方。

## 8 小结

- **机械振动**：平衡位置附近的往复运动；平衡位置合力为零、速度最大。
- **回复力**：$F = -kx$，方向指向平衡位置、大小与位移成正比——简谐运动的定义。
- **简谐运动**：$x = A\sin(\omega t + \varphi_0)$，位移按正弦变化；$\omega = \sqrt{k/m}$。
- **周期**：$T = 2\pi\sqrt{m/k}$，与振幅无关（等时性）。
- 位移、速度、加速度相位依次差 $\tfrac{\pi}{2}$；加速度总指向平衡位置。
- **能量**：$E = \tfrac{1}{2}kA^2$，动能与势能不断转化、总量守恒（无阻尼）。

在下一节，我们把简谐运动的数学描述做全：**简谐运动的描述**。振幅、周期、频率、相位——四个物理量把一个正弦振动「定型」，也让我们能精确预言振子任意时刻的位置与速度。
