## 为什么从串联电路和并联电路开始

上一节的实验里，我们已经悄悄用到了「滑动变阻器」「电压表并联、电流表串联」——这些连接的背后就是本节的规律：**串联与并联**。任何一个实际电路，无论多复杂，都是串联与并联的组合。家庭电路、手机主板、整座电网，全都由这两种基本连接搭建。

这一节要掌握两组基本规律：**串联的分压与电阻相加，并联的分流与电阻倒数相加**。它们加上欧姆定律，就构成了电路分析的全部工具。学完之后，你会看懂「为什么家用电器并联接在 220 V 上」「为什么电压表要并联、电流表要串联」「为什么电表改装需要串并联电阻」——一切皆从这两条铁律出发。<span class="marginnote">串联与并联是「拓扑」关系：串联是「首尾相接、电流同一条路」，并联是「首首相接尾尾相接、电压相同」。判断一个电路是串联还是并联，看的是「电流有几条路可走」：只有一条路必是串联，多条路就是并联或混联。这个「数路」的判断法，比死记图形更可靠。</span>

学这一节，先建立两个直觉：**串联共享电流（处处相等）、并联共享电压（两端相等）**。一切公式都由这两个「共享」推出。

## 1 串联电路：电流相同，电压分配

把多个元件**依次首尾相连**接入电路，叫**串联**。串联电路的基本特征：

1. **电流处处相等**：$I = I_1 = I_2 = \cdots$（电荷不积累，同一条路）。
2. **总电压等于各分电压之和**：$U = U_1 + U_2 + \cdots$（电压是「落差」，逐段相加）。
3. **总电阻等于各电阻之和**：$R = R_1 + R_2 + \cdots$（推导见下）。
4. **电压分配与电阻成正比**（分压）：$\dfrac{U_1}{R_1} = \dfrac{U_2}{R_2} = \cdots = I$，即**电阻大的分得电压大**。

由欧姆定律：$U = IR$，$U_1 = IR_1$，$U_2 = IR_2$……代入 $U = U_1 + U_2 + \cdots$ 得 $IR = IR_1 + IR_2 + \cdots$，约去 $I$ 得 $R = R_1 + R_2 + \cdots$。<span class="marginnote">「串联电阻相加」的微观直觉在上一节电阻定律里已经埋下：一根长导线 = 若干段短导线串联，总电阻 = 各段之和（$R \propto L$）。串联是「把路加长」，路越长阻力越大，所以电阻相加。<strong>串联的电阻越多，总电阻越大</strong>——这是「串联分压、电阻越串越大」的记忆锚点。</span>

**分压公式**：两个电阻 $R_1$、$R_2$ 串联，加在总电压 $U$ 上，则

$$U_1 = \frac{R_1}{R_1 + R_2}U, \qquad U_2 = \frac{R_2}{R_1 + R_2}U$$

这就是**串联分压**：电压按电阻大小成比例分配。电位器（分压器）就利用这个原理，用一只可变电阻把总电压分成可调的两部分——音量旋钮调的就是这个分压比。

## 2 并联电路：电压相同，电流分配

把多个元件**首首相接、尾尾相接**接入电路，叫**并联**。并联电路的基本特征：

1. **各支路电压相等**：$U = U_1 = U_2 = \cdots$（共用一个电源两端）。
2. **总电流等于各支路电流之和**：$I = I_1 + I_2 + \cdots$（电荷守恒，分岔合流）。
3. **总电阻的倒数等于各电阻倒数之和**：$\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \cdots$。
4. **电流分配与电阻成反比**（分流）：$\dfrac{I_1}{I_2} = \dfrac{R_2}{R_1}$，即**电阻小的支路分得电流大**。

由欧姆定律：$I = U/R$，$I_1 = U/R_1$，$I_2 = U/R_2$……代入 $I = I_1 + I_2 + \cdots$ 得 $U/R = U/R_1 + U/R_2 + \cdots$，约去 $U$ 得 $\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \cdots$。<span class="marginnote">「并联电阻倒数相加」的直觉同样来自电阻定律：一根粗导线 = 若干根细导线并联，总电阻比任一根都小（$R \propto 1/S$）。并联是「把路加宽」，路越宽阻力越小，所以电阻减小。<strong>并联的电阻越多，总电阻越小</strong>——永远小于其中最小的那个，这是并联总电阻最反直觉的结论。</span>

**两个电阻并联的特例**：

$$R = \frac{R_1 R_2}{R_1 + R_2}$$

「积除以和」是两电阻并联的快捷公式，在混联电路与电表改装里反复使用。

**分流公式**：两个电阻 $R_1$、$R_2$ 并联，总电流 $I$，则

$$I_1 = \frac{R_2}{R_1 + R_2}I, \qquad I_2 = \frac{R_1}{R_1 + R_2}I$$

电流按电阻的**倒数**比例分配——电阻小的支路分到的电流大。并联的分流原理是电流表扩大量程、分流电阻设计的基础。

## 3 电表的改装：串并联定律的应用

伏安法实验里我们提到「电压表并联、电流表串联」——为什么？因为电表本身是电流表改装来的，而改装靠的正是串并联定律。

**电流表的内部结构**：一个灵敏电流计（表头）+ 一个分流电阻（并联）。表头的内阻 $R_g$、满偏电流 $I_g$ 很小（微安级）。

**改装成电流表（扩大量程）**：并联一个**分流电阻** $R_s$。表头与 $R_s$ 并联，电流按反比分配，大部分电流走 $R_s$，表头只走 $I_g$。设要扩到量程 $I$，则 $R_s = \dfrac{I_g R_g}{I - I_g}$。并联分流电阻后，电流表整体内阻**变小**。<span class="marginnote">电流表改装的核心是「分流」：把多余电流分给旁路电阻，表头始终保持满偏 $I_g$。并联的 $R_s$ 越小，分流越多，量程越大。改装后电流表内阻 $R_A = \dfrac{R_g R_s}{R_g + R_s}$——并联使内阻变小，这正是「电流表要串联、内阻要小」的原因（内阻小，分压少，对电路扰动小）。</span>

**改装成电压表（扩大量程）**：串联一个**分压电阻** $R_v$。表头与 $R_v$ 串联，电压按正比分配，大部分电压落在 $R_v$ 上，表头只承受 $I_g R_g$。设要测到量程 $U$，则 $R_v = \dfrac{U}{I_g} - R_g$。串联分压电阻后，电压表整体内阻**变大**。<span class="marginnote">电压表改装的核心是「分压」：把多余电压分给串联电阻，表头始终保持满偏 $I_g R_g$。串联的 $R_v$ 越大，量程越大。改装后电压表内阻 $R_V = R_g + R_v$——串联使内阻变大，这正是「电压表要并联、内阻要大」的原因（内阻大，分流少，对电路扰动小）。「大内小外」的口诀在这里有了根源：电压表内阻大，并联分流可忽略。</span>

**辨析｜易错点：** 电表改装的方向性：**并联分流 → 电流表（内阻变小），串联分压 → 电压表（内阻变大）**。反过来「用串联电阻扩电流表量程」就错了。记住「电流表像水管粗管（分流多、内阻小）、电压表像细管（分压多、内阻大）」的比喻。

## 4 混联电路与等效电阻

实际电路大多是**混联**——串联与并联的组合。分析混联电路的核心方法是「**逐级化简**」：先找纯串联或纯并联的部分，用等效电阻替换，一步步把复杂电路化成一个等效电阻。

例：$R_1$ 与 $R_2$ 串联，再与 $R_3$ 并联，接到电源上。化简步骤：

1. $R_1$、$R_2$ 串联 → $R_{12} = R_1 + R_2$。
2. $R_{12}$ 与 $R_3$ 并联 → $R_{\text{总}} = \dfrac{R_{12}R_3}{R_{12} + R_3}$。
3. 用总电阻求总电流 $I = U/R_{\text{总}}$，再倒回去求各支路电流、电压。

**关键技巧：电流的分配回溯**——总电流算出来后，并联处按「电阻反比」分流，串联处各处相同。每一步都在「等效化简」与「物理量回溯」两个方向交替进行。<span class="marginnote">「等效电阻」的思想是电路理论的灵魂：一个复杂网络，从外部看可以等价成一个电阻。这个「外部等价」的观点，是后来《闭合电路的欧姆定律》里「电源内阻 + 外电路电阻」统一处理的基础，也是戴维南定理（大学内容）的雏形。先学会「化简」，再学会「回溯」，混联电路就没有解不开的。</span>

**判断串联还是并联的实用方法**：从电源正极出发沿电流「走一遍」——若电流只有一条路可走，处处是串联；若在某节点分成多条路、在另一节点汇合，分叉段之间是并联。「等电势法」也行：同一根导线上（无电阻）各点电势相等，电势相等的点可以「合并」，电路往往立刻化简。

## 5 公式解析：串联分压与并联分流

$$\frac{U_1}{R_1} = \frac{U_2}{R_2} = I, \qquad I_1 R_1 = I_2 R_2 = U$$

拆三步看：

- **第一步，串联的「共享」是电流**：串联中 $I_1 = I_2$，由欧姆定律 $U_1/R_1 = U_2/R_2$，所以 $U_1/U_2 = R_1/R_2$——**电压与电阻成正比**。电阻大者分压大，这就是「串联分压」。
- **第二步，并联的「共享」是电压**：并联中 $U_1 = U_2$，由欧姆定律 $I_1R_1 = I_2R_2$，所以 $I_1/I_2 = R_2/R_1$——**电流与电阻成反比**。电阻小者分流大，这就是「并联分流」。<span class="marginnote">两个公式对称得漂亮：串联「电压比 = 电阻比」，并联「电流比 = 电阻反比」。记忆锚点：串联是「一条路，共同电流，电压按电阻分配」；并联是「一个电压，共同电压，电流按电阻反分配」。抓住「共享什么」就能推出全部。</span>
- **第三步，为什么总电阻的规律相反**：串联 $R = \sum R_i$（越串越大，大于任一分电阻）；并联 $\tfrac{1}{R} = \sum \tfrac{1}{R_i}$（越并越小，小于任一分电阻）。方向相反源于「路的长度 vs 路的宽度」——串联加长、并联加宽。
- **第四步，量纲与单位**：$U$（V）、$I$（A）、$R$（Ω）三量一致；分压分流公式里电阻比无量纲，代入时要保证 $R_1$、$R_2$ 同单位。

## 6 辨析｜易错点

- **串联电流处处相等，并联电压处处相等**：把「串联电压相等」「并联电流相等」当成结论是概念错误。共享关系是这两条规律的根基。
- **并联总电阻小于任一电阻**：$\tfrac{1}{R} = \sum \tfrac{1}{R_i}$ 保证 $R$ 比最小者还小。「并联越多电阻越大」是常见误区。
- **串联电阻越串越大，并联越并越小**：判断「往电路里加电阻，总电阻变不变」的题，先看是串联加长还是并联加宽。
- **电表改装方向**：电流表并联分流电阻（内阻变小）、电压表串联分压电阻（内阻变大）。反了就改装出错表。
- **混联要逐级化简**：先等效替换纯串、纯并部分，再回溯电流电压。跳步容易在「并联分流」处出错。
- **电压表内阻大、电流表内阻小**：理想电表是「电压表内阻无穷大、电流表内阻为零」；实际电表都近似理想，但接法不同误差不同（呼应上一节伏安法）。

## 7 小结

- **串联**：电流处处相等，$U = \sum U_i$，$R = \sum R_i$；分压与电阻成正比。
- **并联**：电压处处相等，$I = \sum I_i$，$\tfrac{1}{R} = \sum \tfrac{1}{R_i}$；分流与电阻成反比。
- **两电阻并联**：$R = R_1R_2/(R_1 + R_2)$，分流 $I_1 = \dfrac{R_2}{R_1+R_2}I$。
- **电表改装**：电流表并分流电阻、电压表串分压电阻；「大内小外」的根源在此。
- **混联分析**：逐级等效化简，再回溯电流电压；「电流一条路是串联，多条路是并联」。
- 串并联规律 + 欧姆定律 = 电路分析的完整工具集。

在下一节，我们练习一件电工必备工具：**实验：练习使用多用电表**。多用电表（万用表）把电压表、电流表、欧姆表装进一个表头，用旋转开关切换——它正是串并联定律与电表改装知识的集大成应用。
