## 为什么从带电粒子在电场中的运动开始

这一节是把前两章所有知识——电场强度、电势差、牛顿定律、能量守恒、抛体运动——汇集成一台「总装」：带电粒子（电子、质子、离子）在电场中受力、加速、偏转，飞出一条条可预测的轨迹。从示波器、电子枪，到显像管、质谱仪，再到粒子加速器，人类操控微观粒子的所有技术，都建立在这一节的模型上。

这一节最迷人的地方是「类比」：**带电粒子在匀强电场中的运动，与小球在重力场中的抛体运动完全同构**。电场力 $F = qE$ 对应重力 $mg$，电势差 $U$ 对应高度差 $h$，类平抛对应平抛。你把第五章《抛体运动》的方程「翻译」一遍，就拿到了本节的大部分结论。<span class="marginnote">为什么要「像力学的翻版」却还要专门学一节？因为微观粒子的世界里，「重力」退场、「电场力」登台：电子质量 $9.1\times10^{-31}\ \text{kg}$，重力小到可以忽略，而电场力轻松主宰它的运动。同样的抛物运动，舞台从地面换到了真空管与芯片里——这是物理定律跨尺度普适的又一证明。</span>

学这一节，请把三种场景分开：**加速（沿电场线方向）、偏转（垂直电场线进入）、示波器（加速 + 偏转的组合）**。三种场景各有其「标志公式」，掌握了流程，题目就只是套模板。

## 1 带电粒子在电场中的加速

**场景一：粒子沿电场线方向运动，只受电场力**。设粒子电荷量 $q$、质量 $m$，从静止开始，在电势差 $U$ 的两点间加速。由动能定理（电场力做功 = 动能变化）：

$$qU = \frac{1}{2}mv^2$$

于是末速度

$$v = \sqrt{\frac{2qU}{m}}$$

**关键结论：末速度只取决于加速电压 $U$ 与粒子的比荷 $q/m$，与粒子经过的路径、电场分布完全无关**。<span class="marginnote">这个结论极其重要：只要知道「被多少伏电压加速」，就能定出粒子速度，无需知道电场长什么样。电子被 1000 V 电压加速，速度 $v = \sqrt{2\times1.6\times10^{-19}\times1000/9.1\times10^{-31}} \approx 1.9\times10^7\ \text{m/s}$——约光速的 6%。这是电子枪、显像管「发射高速电子」的物理基础。</span>

若粒子初速度不为零（$v_0$），则

$$\frac{1}{2}mv^2 - \frac{1}{2}mv_0^2 = qU$$

解得 $v = \sqrt{v_0^2 + 2qU/m}$。**注意正负电荷的区别**：正电荷被「降电势」方向加速（$qU > 0$），负电荷被「升电势」方向加速。若 $qU$ 为负（逆着电场方向推进），粒子减速，可能被「挡回」——这正对应着「电势壁垒」。

**辨析｜易错点：** 用动能定理 $qU = \tfrac{1}{2}mv^2$ 时，$U$ 必须是粒子运动的**起点与终点之间的电势差**。若电场非匀强，取两点电势差仍成立（因为 $W = qU$ 对任何电场成立）——这就是动能定理比「用加速度逐段算」更省力的原因。但要注意：**这是「加速」场景，粒子从初速到末速沿的是电势差对应的能量路径**，与偏转场景不同。

## 2 带电粒子在匀强电场中的偏转：类平抛

**场景二：粒子以速度 $v_0$ 垂直射入匀强电场**（如垂直于极板的方向进入平行板电容器）。粒子受恒定的电场力 $F = qE$，方向垂直 $v_0$，于是它做**类平抛运动**——像抛体运动一样分解：

- **沿 $v_0$ 方向（垂直于电场）**：不受力，匀速直线运动，位移 $x = v_0 t$。
- **沿电场方向**：恒力 $F = qE$，匀加速，加速度 $a = \dfrac{qE}{m} = \dfrac{qU}{md}$。

粒子在电场中运动时间 $t = \dfrac{L}{v_0}$（$L$ 为极板长度），穿出时：

- **偏转量**（沿电场方向的位移）：

$$y = \frac{1}{2}at^2 = \frac{1}{2}\cdot\frac{qU}{md}\cdot\left(\frac{L}{v_0}\right)^2 = \frac{qUL^2}{2mdv_0^2}$$

- **偏转角**（速度方向与入射方向的夹角 $\theta$）：

$$\tan\theta = \frac{v_y}{v_0} = \frac{at}{v_0} = \frac{qUL}{mdv_0^2}$$

**关键结论**：偏转量 $y$ 与偏转角 $\tan\theta$ 都与 $qU/m$（比荷 × 电压）成正比、与 $v_0^2$ 成反比。<span class="marginnote">对比平抛运动：$y = \tfrac{1}{2}gt^2$，$\tan\theta = gt/v_0$——把 $g$ 换成 $qE/m$，抛体公式原封不动「翻译」成类平抛。这个「$g \to qE/m$」的翻译，就是「电学与力学同构」的最直接体现。示波器、显像管正是靠「电压控制偏转量」来绘制波形与图像的。</span>

**辨析｜易错点：** 偏转场景的两个细节。第一，粒子**飞出电场后**做匀速直线运动（不再受力），打到屏幕上时还要继续走一段直线——打到屏上的位置要考虑「飞出时已经偏转的量 + 飞出后直线延伸的量」。第二，若粒子的初速度**不垂直**电场方向，要先把初速度分解成「垂直分量（做圆周/垂直？不，是垂直电场方向的匀速分量）」与「沿电场方向的分量（匀加速）」。**先分解、再套类平抛**，是最稳妥的流程。

## 3 示波器：加速 + 偏转的经典组合

**示波器**是「带电粒子在电场中的运动」最经典的应用：它用电子枪发射电子，用两对偏转板控制电子的水平与竖直偏转，最终在荧光屏上打出光点。示波器的核心结构：

1. **电子枪**：阴极发射电子，经加速电场（电压 $U_1$）加速，获得速度 $v_0 = \sqrt{2qU_1/m}$。
2. **偏转系统**：两对偏转板——竖直偏转板（控制上下，加电压 $U_y$）与水平偏转板（控制左右，加电压 $U_x$）。电子穿过偏转板时受横向电场力，发生类平抛偏转。
3. **荧光屏**：偏转后的电子打在上面发光，光点位置反映偏转电压的大小。

示波器的关键优势：**偏转量正比于偏转电压**（$y \propto U_y$），所以它能「忠实显示」电压波形——把随时间变化的电压信号加到偏转板上，荧光屏就画出它的波形图。心电图、音频波形、电子测量的显示，都起源于这个原理。<span class="marginnote">示波器体现的「用电压控制电子位置」，是现代显示技术的老祖宗：CRT 电视、示波器都用「电子枪 + 偏转」原理。今天 LCD、OLED 替代了 CRT，但电子枪原理在电子显微镜、粒子加速器、质谱仪里依然活跃——「电场控制带电粒子」的思想从未过时。</span>

**综合分析题**：电子先加速（$U_1$）后偏转（$U_2$），偏转量最终表达式（加速后进入偏转板）：

$$y = \frac{U_2 L^2}{4U_1 d}$$

推导：$v_0^2 = 2qU_1/m$ 代入偏转公式 $y = qU_2L^2/(2mdv_0^2)$，$q$、$m$ 全部约去——**偏转量只由加速电压与偏转电压决定，与粒子种类无关**。这就是「示波器对电子、质子都给出同样的偏转」的原因。<span class="marginnote">「$q$、$m$ 全约掉」是示波器题最标志性的结论：先加速再偏转的组合，最终偏转与粒子种类无关。这解释了一个重要的工程事实：示波器不需要区分「来的是哪种带电粒子」，偏转只取决于电压。这个漂亮的对消，让「加速 + 偏转」成为可定量控制的基础模块。</span>

## 4 带电粒子运动的能量视角

处理带电粒子运动，除了牛顿定律（力 → 加速度），还有能量视角（功 → 动能），两者互补：

**能量视角**：$qU = \Delta E_k$——只要有电势差，就能直接算速度，不管路径曲直、电场是否均匀。适用于「从 A 到 B 的全程」问题。
**动力学视角**：$F = qE = ma$——要「逐点」知道加速度、轨迹形状时用。适用于「偏转轨迹、类平抛」等需要细节的问题。

一张表分清两者的分工：

| 问题类型 | 首选方法 | 理由 |
| --- | --- | --- |
| 已知电势差求末速度（加速） | 动能定理 $qU = \tfrac{1}{2}mv^2$ | 只看初末，无需电场细节 |
| 求偏转量、偏转角、轨迹 | 类平抛分解 | 需要过程细节，分解成匀速 + 匀加速 |
| 判断电势能与动能的转化 | 能量守恒 | 电场力做功与电势能变化挂钩 |
| 求某点的加速度、场强 | 牛顿定律 $a = qE/m$ | 瞬时量用力的语言 |

**辨析｜易错点：** 带电粒子在电场中运动时，**重力通常忽略不计**——但题目会明确说「忽略重力」或「不计粒子重力」。若题目没说且粒子是宏观油滴（密立根油滴实验）、尘埃，重力可能不可忽略，要受重力和电场力共同作用（平衡时 $mg = qE$）。「看到带电粒子就忽略重力」是机械的套用，**先看题目对重力的说明**才是严谨的做法。<span class="marginnote">密立根油滴实验正是「电场力平衡重力」的经典：让带电油滴在电场中悬浮，$qE = mg$，测出 $E$ 与 $m$ 反推电荷量 $q$，从而测得元电荷 $e$。这个实验我们已在《电荷》一节预告过——电场力与重力的平衡，是测量微观电荷的钥匙。</span>

## 5 公式解析：类平抛的偏转公式

$$y = \frac{1}{2}\frac{qE}{m}\left(\frac{L}{v_0}\right)^2, \qquad \tan\theta = \frac{qEL}{mv_0^2}$$

拆三步看：

- **第一步，分解运动**：粒子以 $v_0$ 垂直电场进入，沿 $v_0$ 方向匀速（$x = v_0t$），沿电场方向匀加速（$a = qE/m$）。把二维运动拆成两个一维，是类平抛的第一步，也是它与抛体「同构」的结构性原因。
- **第二步，时间由「纵向」决定**：穿出电场的时间 $t = L/v_0$ 只由极板长度与入射速度决定——与电场强弱无关。这一点常常被忽略：不管 $E$ 多大，粒子在极板间停留的时间相同（只要它不撞板）。代入 $y = \tfrac{1}{2}at^2$ 得到偏转量。
- **第三步，比荷的角色**：$a = qE/m = (q/m)E$——加速度正比于**比荷**。同一种场、同样的电压，比荷大的粒子偏转更厉害（质子比电子偏转得少得多，因为质子质量大 1836 倍）。比荷是连接「电学量（$q$）」与「力学量（$m$）」的桥梁，也是质谱仪区分不同离子的依据。
- **第四步，$E = U/d$ 的代入**：偏转板间是匀强电场，$E = U/d$，所以偏转公式可写成用电压表达的形式。把「电压」作为控制量（示波器就是改 $U$ 来控制偏转），是工程最常用的表达。

## 6 辨析｜易错点

- **加速与偏转要分清**：加速（沿电场线，用 $qU = \tfrac{1}{2}mv^2$）与偏转（垂直电场进入，用类平抛）是两个不同的场景。把「偏转的类平抛公式」用到「加速」上、或反过来，是概念混淆的高频错误。
- **重力是否忽略看题目**：微观粒子（电子、质子、离子）通常忽略重力；宏观液滴、尘埃要看题目说明。做「平衡」（$qE = mg$）类题目时重力反而是主角。
- **$q$、$m$、$U$ 的符号**：电荷量用绝对值代入大小计算，方向靠受力分析判断。负电荷受力与场强反向——类平抛中负电荷的偏转方向与正电荷相反，别默认「向下偏」。
- **飞出电场后的直线运动**：粒子穿出偏转板后不受电场力，做匀速直线运动，打到屏上的位置 = 出射点的偏转量 + 出射后直线延伸。只算「板内偏转」忘了「板外延伸」，会漏掉屏上位置的关键部分。
- **能量守恒与动能定理不冲突**：若只有电场力做功，机械能不守恒（电场力做功改变了机械能）——但动能定理 $W = qU = \Delta E_k$ 恒成立。说「带电粒子机械能守恒」是错的（电场力不是保守力？静电力是保守力！这里要注意：静电力是保守力，所以「电势能 + 动能」守恒，即「机械能 + 电势能」守恒）。**严格说：只有电场力做功时，「动能 + 电势能」总量守恒**，这等价于动能定理，但不要说成「机械能守恒」——除非你把电势能算进机械能（高中一般不这样算）。

## 7 小结

- **加速**：$qU = \tfrac{1}{2}mv^2$，末速度只由电压与比荷决定，与路径无关。
- **偏转（类平抛）**：沿入射方向匀速、沿电场方向匀加速；$y = \tfrac{1}{2}(qE/m)(L/v_0)^2$，$\tan\theta = qEL/(mv_0^2)$。
- **示波器**：电子枪加速 + 偏转板偏转；先加速后偏转时，偏转量 $y \propto U_2/(U_1 d)$，与粒子种类无关。
- **能量视角与动力学视角互补**：全程用能量，细节用动力学。
- 比荷 $q/m$ 是带电粒子的核心属性，决定加速与偏转的效果。
- 微观粒子通常忽略重力；是否忽略看题目说明。
