# 电势差与电场强度的关系

## 为什么从电势差与电场强度的关系开始

前三节我们分别建立了两个视角：**电场强度** $E$ 描述「力」（矢量），**电势** $\varphi$ 与**电势差** $U$ 描述「能量」（标量）。这两套语言描述的是同一个电场，必然存在内在联系。上一节末尾我们已经见到线索：匀强电场中 $U = Ed$。这一节把这个关系严格化、一般化，并揭示一个深刻的观念——**场强是电势的空间变化率**。

这个关系的意义怎么强调都不为过：它让「力」与「能量」两种描述合流。有了它，你可以从电势的分布推出场强（等势面疏密判断场强大小），也可以从场强推算电势差（电场强度 × 距离）。它还是我们理解「为什么电场线从高电势指向低电势、为什么场强可以用 $\text{V/m}$ 作单位」的钥匙。<span class="marginnote">$E = U/d$ 蕴含的「场强 = 电势的空间变化率」观念，在第二级《高等数学》里就是梯度：$E = -\nabla\varphi$，电场强度等于电势梯度的负值。梯度是「最陡上升方向」，负梯度就是「最陡下降方向」——电场线沿电势最快下降的方向走，这正是「电场线从高电势指向低电势」的严格数学表述。这一节是高中到大学「场论」的第一座桥。</span>

学这一节，把「坡度」的类比放心里：**电势是山的高程，场强是山的坡度，$E = U/d$ 说「坡度 = 高差 ÷ 水平距离」**。一切复杂都从这三个词展开。

## 1 匀强电场中的关系：U = Ed

先回到最简单的情形。在**匀强电场**中，电场强度 $E$ 处处相同，方向如水平向右。取电场线上 A、B 两点，相距 $d$，则两点间的电势差为

$$U_{AB} = Ed$$

推导（上一节已见过，这里补全物理图像）：沿电场线从 A 到 B，电场力做功 $W = qEd$；同时 $W = qU_{AB}$；联立得 $U_{AB} = Ed$。这个式子的物理含义非常直白：**匀强电场里，沿电场线方向每前进一米，电势下降 $E$ 伏**——$E$ 就是「电势下降的速率」。

由此得到一个更深刻的理解：**电场强度在数值上等于沿电场线方向单位距离上的电势降落**：

$$E = \frac{U_{AB}}{d}$$

注意「沿电场线方向」这个前提：$d$ 必须是**沿场强方向的投影距离**，而不是任意两点间的连线距离。若 A、B 连线与电场线夹角为 $\theta$，连线长 $L$，则

$$d = L\cos\theta, \qquad U_{AB} = EL\cos\theta$$

即：**只有沿电场线方向的分量 $L\cos\theta$ 贡献电势差**。垂直电场线的方向电势不变——这正是等势面与电场线垂直的原因。<span class="marginnote">「只有沿电场方向的分量贡献电势差」是本节最容易忽略的细节。两点在等势面上（连线垂直电场线），$U = 0$，即使它们距离很远。反过来，两点非常近、但连线几乎沿电场线方向，也能有大电势差。判断电势差大小，永远看「沿电场线方向的投影」而不是「直线距离」。</span>

## 2 非匀强电场：从 $U = Ed$ 到定性判断

匀强电场是理想模型。真实电场（点电荷、不规则电荷分布）中场强处处不同，$U = Ed$ 不能直接套用。但我们可以借用它的思想做**定性判断**：

**场强大处，等势面密集**：把 $U = Ed$ 写成 $d = U/E$，固定电势差 $U$，$E$ 大则 $d$ 小——场强大的区域，电势下降同样数值所需距离更短，等势面自然更密。<span class="marginnote">这个「等势面疏密 ↔ 场强大小的关系」是读电场图的核心技能：看到等势面，密的地方场强大、电荷受力大、加速度大；疏的地方场强小。点电荷电场的等势面（同心球面）越靠近中心越密，正是「越近场强越大」的图像。</span>
**沿电场线方向电势降低最快**：从 A 点出发向各个方向走同样距离，沿电场线方向电势下降最大。这也是「场强方向 = 电势下降最陡的方向」的直观版本。

**辨析｜易错点：** $U = Ed$ 只对匀强电场严格成立，非匀强电场里「平均场强」可以近似估算，但「逐点的 $E$」不能从「两点的 $U$ 除以距离」直接得出（因为中间的 $E$ 在变）。判断「非匀强电场能否用 $U = Ed$」——**不能**，除非题目明说近似或只求定性。把 $U = Ed$ 无条件乱用，是非匀强电场题的典型错误。

## 3 场强方向与电势变化的关系

从 $U = Ed$ 我们可以严格推出几个方向性结论：

**电场线从高电势指向低电势**：沿电场线走，$d > 0$，$U > 0$，电势下降。所以电场线永远指向电势降低的方向。<span class="marginnote">这条规则的逆命题也成立：逆着电场线走，电势升高。于是「正电荷在电场中的运动方向」「负电荷的电势能变化」都可用它判断。但要注意：电场线方向是「电势最快下降方向」，不是「唯一下降方向」——斜着走电场线夹角 60°，电势也在降，只是降得慢（$U = Ed\cos\theta$）。</span>
- **场强方向垂直等势面**：等势面上电势不变，沿等势面移动 $\Delta\varphi = 0$，所以场强沿等势面的分量必须为零——场强只能垂直等势面。这与上一节「电场线垂直等势面」互相印证。
- **等势面密的地方，电场线也密**：两者都由「场强大」驱动，于是电场线与等势面同时「疏密呼应」——电场线密处等势面也密。读图时两个疏密可以互证。

## 4 场强的两个单位与量纲

电场强度有两个常用的等价单位：

$$1\ \frac{\text{N}}{\text{C}} = 1\ \frac{\text{V}}{\text{m}}$$

推导：$1\ \text{V} = 1\ \text{J}/\text{C} = 1\ (\text{N}\cdot\text{m})/\text{C}$，所以 $1\ \text{V}/\text{m} = 1\ (\text{N}\cdot\text{m})/(\text{C}\cdot\text{m}) = 1\ \text{N}/\text{C}$。两个单位本质相同，只是「视角」不同：

- $\text{N}/\text{C}$：从「力」出发（$E = F/q$），强调电场对电荷的力的作用。
- $\text{V}/\text{m}$：从「能量」出发（$E = U/d$），强调电势随空间的变化。

物理上两者完全等价，做题时看哪个方便用哪个。<span class="marginnote">这个单位等价是「场强两种定义本质一致」的数学证据：$E = F/q$ 说它是「力的场」，$E = U/d$ 说它是「电势变化的场」。同一个物理量能用两种单位表示，说明力的描述与能量的描述没有矛盾——它们是同一对象的两张照片。这种「单位换算」往往暗示概念间的深层统一，是物理学习中值得留意的信号。</span>

## 5 公式解析：E = U/d 的投影版

$$E = \frac{U_{AB}}{d}, \qquad U_{AB} = E\,L\cos\theta$$

拆三步看：

- **第一步，$d$ 是什么**：$d$ 是 A、B 两点**沿电场线方向的距离**。若 A、B 连线长 $L$、与电场线夹角 $\theta$，则 $d = L\cos\theta$——只取沿电场方向的分量。垂直电场方向的分量 $L\sin\theta$ 不贡献电势差。<span class="marginnote">投影的思想在力学里已见过：做功 $W = Fl\cos\theta$ 取「沿位移方向的力分量」；这里 $U = EL\cos\theta$ 取「沿场强方向的距离分量」。同一个「$\cos\theta$ 投影」，一个作用在力上、一个作用在距离上。记住「谁和谁平行才贡献」，投影就不会错。</span>
**第二步，为什么垂直方向电势不变**：$\theta = 90°$ 时 $\cos\theta = 0$，$U = 0$——同一等势面上任意两点电势差为零。这也反过来证明等势面垂直电场线。
**第三步，$E = U/d$ 的双重身份**：数值上它说「场强 = 单位距离的电势降落」；单位上它给了 $\text{V}/\text{m}$。当你看到「某电场中沿某方向电势随距离线性变化」，立刻想到匀强电场与 $E = U/d$。
**第四步，计算例子**：平行板电容器板间距 $d = 5\ \text{mm} = 0.005\ \text{m}$，板间电压 $U = 500\ \text{V}$，则内部场强 $E = U/d = 500/0.005 = 10^5\ \text{V/m}$。反过来，已知场强 $2\times10^4\ \text{V/m}$、两点沿场强相距 $3\ \text{cm}$，则 $U = 2\times10^4 \times 0.03 = 600\ \text{V}$。**单位统一（都用 SI）是这类题唯一要注意的操作细节**。

## 6 综合运用：电场线与等势面的读图

把前几节的知识汇成一个「读电场图」的清单：

1. **看电场线疏密** → 判断场强大小：密处场强大。
2. **看电场线方向** → 判断电势高低：沿电场线电势降低。
3. **看等势面疏密** → 判断场强大小：等势面密处场强大。
4. **看等势面与电场线垂直** → 两者方向互相约束。
5. **等势面沿电场线方向电势降低** → 电势地形图。

**辨析｜易错点：** 一张图上有电场线又有等势面时，经常考的结论是「电场线密处等势面也密」「沿电场线方向电势降低」「同一等势面上场强大小不一定相同」（等势面是「电势相等」，与场强大小无关——例如点电荷电场的同一个球面上场强大小相同，但匀强电场的同一等势面上场强也相同，而一般电场的等势面上场强各处可以不同）。**等势面只约束电势相等，不约束场强大小**——把「等势面上场强相等」当成结论，是读图题里最常见的误区之一。<span class="marginnote">对比一个更容易混的点：等势面「上」场强可以不同，但等势面「法线方向」上场强必然垂直该面。场强大小由「等势面的疏密」反映，不是由「同一面上的值」反映。想象一座山：同一等高线上海拔相同，但坡度（场强）沿这条等高线可以时陡时缓——这就是「等势面上场强可不同」的直观图景。</span>

## 7 小结

- **匀强电场**：$U_{AB} = Ed$，$d$ 是沿电场线方向的距离；$E = U/d$ 是电势随距离的变化率。
- **投影版**：$U = EL\cos\theta$，只有沿场强方向的分量贡献电势差；垂直方向电势不变。
- **场强方向**：从高电势指向低电势，是电势下降最陡的方向；垂直等势面。
- **等势面疏密**反映场强大小：密处场强大；等势面只约束电势，不约束场强大小。
- **单位等价**：$1\ \text{N}/\text{C} = 1\ \text{V}/\text{m}$，力视角与能量视角的统一。
- 非匀强电场不能用 $U = Ed$ 严格计算，只可定性判断。

在下一节，我们研究能「储存电场能量」的元件——**电容器**。平行板电容器正是匀强电场的经典来源，而它的电容 $C$、储能公式 $\tfrac{1}{2}CU^2$，将把我们学的场、电压、能量全部串进一个实用器件。
