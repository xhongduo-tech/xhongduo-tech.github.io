## 为什么从质谱仪和回旋加速器开始

上一节我们掌握了「电场加速 + 磁场偏转」的模板。这一节把它做成两台真实的仪器：**质谱仪**（mass spectrometer）与**回旋加速器**（cyclotron）。一台用来「称量」原子的质量、分离同位素；一台用来把带电粒子加速到极高能量、轰击原子核。它们分别代表了粒子操控的两种目的：**测量**与**加速**。

质谱仪让化学、生物学、医学有了「分子天平」——测出分子的精确质量就能鉴定它是谁；回旋加速器是高能物理、医学放疗（质子治疗）、同位素生产的基石。这两台仪器把前几节的洛伦兹力、圆周运动、动能定理全部组装成真实设备，是「理论变成工具」的典范。<span class="marginnote">质谱仪的发明（1913 年，汤姆孙的学生阿斯顿）直接催生了同位素的发现——同一种元素的不同质量原子，在质谱仪里被分成不同的「跑道」。如今质谱分析是化学与生命科学的日常工具：测蛋白质分子量、鉴定污染物、医疗诊断（新生儿筛查）。「称量分子」的能力，改写了分析化学。</span>

学这一节，请抓住两台仪器的「分工」：**质谱仪用磁场半径测比荷（质量），回旋加速器用磁场回旋 + 电场加速**。

## 1 质谱仪：称量原子

**质谱仪**：利用电场加速 + 磁场偏转，测出带电粒子的比荷 $q/m$（进而测质量）的仪器。

**质谱仪的工作流程**：

1. **离子源**：让原子/分子电离成带电离子。
2. **加速电场**：离子经电压 $U$ 加速：$qU = \tfrac{1}{2}mv^2$，速度 $v = \sqrt{2qU/m}$。
3. **速度选择器（可选）**：正交电磁场，让特定速度的离子直线通过（$qvB = qE$，$v = E/B$），保证进入磁场时速度统一。
4. **偏转磁场**：离子垂直进入匀强磁场，做圆周运动，半径 $r = \dfrac{mv}{qB}$。
5. **探测器**：不同 $q/m$ 的离子落在不同位置，测出半径。

**由半径反推比荷/质量**：把 $v = \sqrt{2qU/m}$ 代入 $r = mv/(qB)$：

$$r = \frac{\sqrt{2mqU}}{qB}$$

$$q/m = \frac{2U}{B^2 r^2}$$

测出 $r$，已知 $U$、$B$，就得到离子的比荷 $q/m$；已知电荷（如 $q = +e$），就得到质量 $m$。<span class="marginnote">质谱仪的核心公式 $m = \dfrac{qB^2r^2}{2U}$：质量正比于半径平方——半径差一点，质量差很多（平方放大）。同一元素的不同同位素（如碳-12 与碳-14）质量略有差异，在质谱仪里半径分开，被探测器分别记录——这就是「同位素分离与鉴定」的原理。测出同位素的比例（碳-14/碳-12），考古学就能「碳定年」。</span>

**辨析｜易错点：** 质谱仪分离的是**比荷不同**的离子——测的是 $q/m$。若两离子比荷相同，半径相同、无法区分；比荷不同则半径不同、分道扬镳。判断「能不能分开」，看比荷是否相同。

## 2 回旋加速器：加速粒子

**回旋加速器**：利用「电场加速 + 磁场回旋」反复给带电粒子加速的装置。

**结构**：两个 D 形盒（半圆电极）面对放置，盒内是匀强磁场（垂直纸面），盒间有交变电场。

**工作原理**：

1. 粒子从 D 形盒中心附近射入，在盒内（无电场、只有磁场）做**半圆周运动**，半径 $r = mv/(qB)$。
2. 粒子运动到两盒之间的缝隙时，交变电场恰好给出加速电压——粒子被电场加速，速度增大。
3. 加速后粒子进入另一个盒，以更大的半径再做半圆。
4. 每转半圈被电场加速一次，速度越来越大、半径越来越大，轨迹是**螺旋线**。
5. 最终粒子从 D 形盒边缘射出，获得高能量。

**同步条件（关键）**：电场必须与粒子运动**同步**——每半圈粒子回到缝隙时，电场方向恰好是加速方向。由于周期 $T = 2\pi m/(qB)$ **与速度无关**，粒子转半圈的时间恒定，所以**交变电场的频率固定为 $f = 1/T = qB/(2\pi m)$** 即可始终同步——这就是「回旋加速器」能用固定频率加速的原因。<span class="marginnote">回旋加速器的「同步」全靠「周期与速度无关」：粒子速度增大、半径增大，但转一圈的时间不变，所以缝隙处的电场可以「固定节奏」加速。这是上一节 $T = 2\pi m/(qB)$ 最优雅的工程应用。但注意：粒子速度接近光速时质量按相对论增大，周期变长，固定频率不再同步——所以高能粒子要用「同步加速器」（同步调节频率或磁场）。回旋加速器只能把粒子加速到「相对论效应可忽略」的能量（约 10–20 MeV）。</span>

**最大速度与能量**：粒子从 D 形盒半径 $R$ 处射出，最大速度 $v_{\max} = \dfrac{qBR}{m}$，最大动能：

$$E_{k,\max} = \frac{q^2 B^2 R^2}{2m}$$

**关键结论：最大能量由磁场强度与 D 形盒半径决定，与加速电压无关**——电压只决定加速次数（转的圈数），不决定最终能量上限。<span class="marginnote">「最大能量与电压无关」是回旋加速器最反直觉的结论：加速电压大只是「每圈多加点」，但最终能量上限 $E_{k,\max} = q^2B^2R^2/(2m)$ 只由磁场 $B$ 与半径 $R$ 决定。因为粒子能量达到上限时，半径已经到 D 形盒边缘、必须射出。想要更高能量，只能增大 $B$ 或 $R$——这正是大型加速器越建越大的原因（LHC 周长 27 公里）。</span>

## 3 两仪器的对比

| 比较项 | 质谱仪 | 回旋加速器 |
| --- | --- | --- |
| 目的 | 测比荷/质量，分离离子 | 加速粒子到高能 |
| 核心原理 | 加速后测磁场半径 | 电场加速 + 磁场回旋 |
| 关键公式 | $q/m = 2U/(B^2r^2)$ | $E_{k,\max} = q^2B^2R^2/(2m)$ |
| 磁场的作用 | 偏转分离（按半径） | 回旋（保持轨道） |
| 电场的作用 | 加速（一次） | 加速（反复，交变同步） |
| 输出 | 半径/质量信息 | 高能粒子束 |

两台仪器都用「电场 + 磁场」，但目的不同：质谱仪「测」，回旋加速器「加」。<span class="marginnote">两台仪器共享「电场管能量、磁场管轨道」的模板，但角色完全不同：质谱仪的磁场是「分拣器」（按半径分开），回旋加速器的磁场是「环形跑道」（让粒子转圈回来再加速）。抓住「磁场干吗、电场干吗」，就能分辨任何粒子仪器的设计意图——这是「粒子仪器」这类题的通用分析方法。</span>

## 4 公式解析：E_max = q²B²R²/(2m)

$$E_{k,\max} = \frac{q^2 B^2 R^2}{2m}$$

拆三步看：

- **第一步，来源**：最大速度 $v_{\max} = \dfrac{qBR}{m}$（半径取 D 形盒半径 $R$），代入动能 $E_k = \tfrac{1}{2}mv^2$：$E_{k,\max} = \tfrac{1}{2}m\left(\dfrac{qBR}{m}\right)^2 = \dfrac{q^2B^2R^2}{2m}$。<span class="marginnote">推导链：半径公式 $r = mv/(qB)$ → 令 $r = R$（D 形盒半径）→ 解出最大速度 → 代入动能公式。最大能量与加速电压无关、只由 $B$、$R$、$q/m$ 决定——因为电压决定的只是「加速多少次」，而次数不影响「最后能到多快」（快慢只受「轨道半径上限」限制）。</span>
- **第二步，什么决定上限**：磁场 $B$ 越大、D 形盒半径 $R$ 越大、比荷越大，最大能量越高。工程上提高能量就是「加大磁场、加大尺寸」——LHC 用 8 T 超导磁体、27 km 周长，正因如此。
- **第三步，与加速电压无关的物理解释**：电压大 → 每圈加速度大 → 转的圈数少；电压小 → 每圈加得少 → 转的圈数多。但「最终半径到 $R$」决定了最终速度——电压只影响「转多少圈到达」，不影响「到达时的速度」。这个「上限由几何决定」的图像，比死记公式更本质。
- **第四步，相对论的边界**：速度接近光速时 $m$ 增大、周期变长、同步失效。所以回旋加速器有能量上限（质子约 20 MeV），更高能量需同步加速器——「适用范围」是任何理论/装置的必修课。

**数值算例**：D 形盒半径 $R = 0.5\ \text{m}$、磁场 $B = 1.5\ \text{T}$，加速质子（$q = 1.6\times10^{-19}$ C，$m = 1.67\times10^{-27}$ kg）。最大速度 $v_{\max} = qBR/m = 1.6\times10^{-19}\times1.5\times0.5/(1.67\times10^{-27}) \approx 7.2\times10^7\ \text{m/s}$（约 0.24c，相对论效应尚可忽略）；最大动能 $E_k = \tfrac12mv^2 \approx \tfrac12\times1.67\times10^{-27}\times(7.2\times10^7)^2 \approx 4.3\times10^{-12}\ \text{J} \approx 27\ \text{MeV}$。「磁场与半径决定上限」这个结论，用数字一看便知——想再快，只有增大 $B$ 或 $R$。

## 5 辨析｜易错点

- **质谱仪测比荷 $q/m$**：不是测「质量」直接——已知电荷才得质量。
- **回旋加速器同步条件**：电场频率 $f = qB/(2\pi m)$ 固定，靠「周期与速度无关」。
- **最大能量与电压无关**：$E_{\max} = q^2B^2R^2/(2m)$，由 $B$、$R$ 决定。
- **速度选择器**：$qvB = qE$，$v = E/B$——只有特定速度的粒子直线通过。
- **相对论失效**：高速时周期变长，回旋加速器有能量上限。
- 分辨两仪器：「测」用质谱仪、「加」用回旋加速器——磁场角色不同。

## 6 小结

- **质谱仪**：电场加速 + 磁场偏转，测半径定比荷 $q/m = 2U/(B^2r^2)$——分离同位素、鉴定分子。
- **回旋加速器**：D 形盒 + 匀强磁场回旋 + 交变电场同步加速，粒子螺旋加速。
- **同步条件**：$f = qB/(2\pi m)$ 固定（周期与速度无关）。
- **最大能量**：$E_{k,\max} = q^2B^2R^2/(2m)$，与电压无关，由 $B$、$R$ 决定。
- 两台仪器共享「电场管能量、磁场管轨道」模板。
- 应用：质谱分析（化学/生物/医学）、高能物理、质子治疗、同位素生产。
- **两仪器分工**：质谱仪「测」、回旋加速器「加」——磁场角色分别是「分拣」与「跑道」。
- **周期与速度无关**：$T = 2\pi m/(qB)$——回旋加速器同步的根基。
- **速度选择器的「选速」**：$v = E/B$——正交电磁场让特定速度的粒子直线通过。
- **相对论边界**：速度接近光速时周期变长、同步失效——回旋加速器有能量上限。
- **粒子操控的两大目的**：质谱仪「测量」、回旋加速器「加速」——电场管能量、磁场管轨道。

- **质谱仪定比荷**：$q/m = 2U/(B^2r^2)$——测半径反推比荷与质量。
- **回旋加速器上限**：$E_{k,\max} = q^2B^2R^2/(2m)$——由磁场与半径决定、与电压无关。
