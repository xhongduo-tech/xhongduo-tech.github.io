## 为什么从光的折射开始

这一章我们从「波」进入「光」。光有双重身份：它是电磁波（第十三章已见），也是我们每天看见世界的媒介。研究光的传播，最基础的规律就是**折射定律**（斯涅耳定律）：光从一种介质进入另一种介质时，传播方向发生偏折，偏折的程度由两种介质的折射率决定。

折射现象无处不在：筷子插进水里看起来「折断」了，池水看起来比实际浅，海市蜃楼是空气密度变化引起的折射，眼镜片、放大镜、显微镜、望远镜全靠折射成像。理解折射，是理解一切光学仪器的基础。<span class="marginnote">折射的微观本质是「光在不同介质中的速度不同」：光在介质中速度 $v = c/n$（$n$ 是折射率，真空 $n=1$、水约 1.33、玻璃约 1.5）。波速变化导致波前偏转——这与第三章「波进入异介质波速变、方向偏」的折射完全同源。光学只是把机械波的折射规律应用到了光：光速慢的介质（$n$ 大）里光「靠法线」弯。</span>

学这一节，请抓住核心公式**斯涅耳定律 $n_1\sin\theta_1 = n_2\sin\theta_2$** 与**折射率 $n = c/v$**，并建立「光速慢则偏向法线」的直觉。

## 1 光的折射与折射定律

**光的折射**：光从一种介质斜射入另一种介质时，传播方向发生改变的现象。

**光的反射与折射同界出现**：光射到两种介质界面时，一部分光反射回原介质（反射），一部分进入另一种介质并偏折（折射）。反射遵循反射定律（入射角 = 反射角），折射遵循**折射定律**。

**折射定律（斯涅耳定律）**：

$$\frac{\sin\theta_1}{\sin\theta_2} = \frac{n_2}{n_1} = n_{21}$$

其中 $\theta_1$ 是入射角（入射光线与法线的夹角）、$\theta_2$ 是折射角、$n_1$、$n_2$ 是两种介质的折射率，$n_{21}$ 是介质 2 相对介质 1 的相对折射率。也可写成：

$$n_1\sin\theta_1 = n_2\sin\theta_2$$

**结论**：

- **光从光疏介质（$n$ 小）进入光密介质（$n$ 大）**：折射角 < 入射角，光**靠近法线**。
- **光从光密进入光疏**：折射角 > 入射角，光**偏离法线**。
- **垂直入射**（$\theta_1 = 0$）：不偏折，沿原方向进入（折射角 = 0）。<span class="marginnote">「密疏判方向」的口诀：<strong>光疏进光密，折向法线靠；光密进光疏，折离法线走</strong>。光密介质 = 折射率大 = 光速慢。判断折射方向，先比 $n_1$、$n_2$ 谁大，再定「靠还是离」。这个判断比记公式本身更常考——看到「从空气进玻璃」，空气 $n=1$、玻璃 $n≈1.5$，光疏进光密，靠法线。</span>

## 2 折射率：光速的度量

**折射率（refractive index）**：光从真空射入某种介质发生折射时，入射角正弦与折射角正弦之比，等于光在真空与介质中的速度之比：

$$n = \frac{c}{v} = \frac{\sin\theta_1}{\sin\theta_2}$$

- **物理意义**：折射率反映介质「让光变慢」的程度——$n$ 越大，光在该介质中越慢，偏折越厉害。
- **真空** $n = 1$；**空气**约 $n = 1.0003$（近似取 1）；**水**约 1.33；**玻璃**约 1.5；**钻石**约 2.42（光速只有真空的一半不到，所以钻石折射率大、闪耀）。
- 折射率**无单位**，是一个纯数。
- 折射率与介质本身有关（还与光的频率有关——**色散**，白光通过棱镜分解成彩色，见下一章）。

**辨析｜易错点：** 折射率 $n = c/v$ 中 $v$ 是**光在该介质中的速度**（小于 $c$），所以 $n > 1$（除真空）。折射率不是「光速除以介质速度再减一」之类的——它就是「真空光速 ÷ 介质光速」。$n$ 越大光越慢。<span class="marginnote">用折射率比较「光速」很方便：$n$ 大则 $v$ 小。水 $n=1.33$ → $v = c/1.33$；玻璃 $n=1.5$ → $v = c/1.5$。钻石 $n=2.42$ → $v ≈ 0.41c$——光在钻石里只有真空光速的四成。这也是为什么「折射率大 → 光慢 → 偏折厉害 → 折射角小」，钻石把光「折」得特别狠，火彩璀璨。</span>

把「光疏」与「光密」并排看，方向判断就有了抓手：

| 对比项 | 光疏介质 | 光密介质 |
| --- | --- | --- |
| 折射率 $n$ | 小（接近 1） | 大 |
| 光速 $v = c/n$ | 大 | 小 |
| 典型代表 | 真空、空气（$n \approx 1$） | 水、玻璃、钻石 |
| 光进入时的偏折 | 折射角 > 入射角（离法线） | 折射角 < 入射角（靠法线） |

「疏」与「密」指的不是密度，而是「光疏 = 光快 = 折射率小、光密 = 光慢 = 折射率大」。空气与玻璃比，玻璃是光密；但玻璃与水比，水是光疏——**疏密是相对的，只取决于两者折射率谁大**。

## 3 折射定律的应用：看水里的物体

折射定律解释了许多日常现象，最重要的一类是「物体看起来的位置与真实位置不同」：

**池水看起来比实际浅**：池底某点反射的光从水（光密）进入空气（光疏），偏离法线折向水面，人眼沿折射光的反向延长线「看到」的池底位置比真实位置浅（视深 < 实深）。
**筷子在水中折断**：水中部分反射的光经折射后，人眼看到的虚像位置错开，视觉上「折断」。
**视深公式**：从正上方看，视深 $h' = \dfrac{h}{n}$（$h$ 是实深，$n$ 是水的折射率）——水 $n = 4/3$，视深只有实深的 3/4。

**辨析｜易错点：** 人眼「看到」的是折射光线的**反向延长线的交点**（虚像），不是光线的实际路径。池底的像在浅处，是折射「欺骗」了眼睛——这是折射定律最经典的应用，也是几何光学「找虚像」的思路：**顺着进入眼睛的光线的反向延长线找交点**。<span class="marginnote">「反向延长线找虚像」是光学作图的核心技能：眼睛接收到的折射光，其反向延长线会聚的点就是虚像位置。插水中的筷子、池底的硬币、鱼在水中的位置——全部用这个「反向延长线」方法判断。真正理解「虚像是折射的几何结果」，比记住「看起来浅了」的结论更重要。</span>

## 4 光的折射与全反射的边界

折射定律有一个重要的推论，预告下一节：当光从光密介质射向光疏介质时，入射角增大到某个临界值，折射角达到 90°——再增大入射角，光不再折射，全部反射。这就是**全反射**的临界条件，临界角：

$$\sin C = \frac{n_{\text{疏}}}{n_{\text{密}}} = \frac{1}{n}$$

（光从折射率 $n$ 的介质射向空气，临界角满足 $\sin C = 1/n$。）

下一节会完整展开全反射；本节先记住**折射角最大 90°** 这个「边界」——折射的极限就是全反射的开始。<span class="marginnote">折射与全反射是「一体两面」：入射角小时光部分折射、部分反射；入射角增大到临界角时折射角到 90°（掠射）；超过临界角则折射消失、只剩反射（全反射）。临界角 $\sin C = 1/n$ 由折射率唯一决定——水 $C ≈ 48.6°$、玻璃约 41.8°、钻石约 24.4°。下一节的光纤通信，就建立在这个「折射的极限」上。</span>

## 5 公式解析：n₁sinθ₁ = n₂sinθ₂

$$n_1\sin\theta_1 = n_2\sin\theta_2, \qquad n = \frac{c}{v}$$

拆三步看：

- **第一步，为什么是 $\sin$ 比值**：折射定律是实验规律（斯涅耳 1621 年发现）。$\sin\theta$ 比值的深层原因是「光程与波前」：同一波前在两种介质中传播时，沿界面方向的「相位匹配」要求 $n\sin\theta$ 在界面两侧连续——这就是「光程连续」原理。到大学用惠更斯原理或费马原理能严格推导。<span class="marginnote">「$n\sin\theta$ 在界面连续」是折射定律的现代表述，它源于「光的相位在界面上不能突变」——两种介质中光沿界面方向传播的「等效相位变化」必须相等。这个「相位匹配」思想在薄膜干涉、衍射光栅里反复出现，是光学最深刻的线索之一。</span>
- **第二步，用 $n = c/v$ 理解方向**：$n$ 大 → $v$ 小 → 光慢 → 慢的一侧「拖后腿」，波前转向、光线偏向法线。光疏进光密，$n_2 > n_1$，由 $n_1\sin\theta_1 = n_2\sin\theta_2$ 得 $\sin\theta_2 < \sin\theta_1$，$\theta_2 < \theta_1$——折射角小，靠法线。
- **第三步，垂直入射的特例**：$\theta_1 = 0$，$\sin\theta_1 = 0$，则 $\theta_2 = 0$——垂直入射不偏折。这看似与「折射改变方向」矛盾，其实垂直入射时光线沿法线，两侧速度差只影响波前的「快慢」不影响「方向」。
- **第四步，量级与计算**：光从空气（$n_1=1$）以 45° 射入水（$n_2=1.33$）：$\sin\theta_2 = \sin45°/1.33 \approx 0.532$，$\theta_2 \approx 32°$——折射角约 32°，比入射角小 13°，光明显靠法线弯折。

## 6 辨析｜易错点

- **折射定律对「光疏进光密」与「光密进光疏」方向判断不同**：先比 $n_1$、$n_2$，再判靠/离法线。
- **折射率 $n = c/v > 1$**（除真空）：折射率大 → 光慢 → 偏折厉害。
- **垂直入射不偏折**：$\theta_1 = 0$ → $\theta_2 = 0$。
- **「看到的像」是虚像**：反向延长线找交点；视深 $h' = h/n$。
- **折射的极限预告全反射**：临界角 $\sin C = 1/n$（从介质到空气）。
- **$n$ 与光的频率有关**（色散）：白光折射会分解，频率不同偏折不同（下一章）。

## 7 小结

- **折射定律**：$n_1\sin\theta_1 = n_2\sin\theta_2$；光疏进光密靠法线、光密进光疏离法线。
- **折射率**：$n = c/v$，反映介质让光变慢的程度；真空 1、水 1.33、玻璃 1.5。
- 垂直入射不偏折；光在介质中速度 $v = c/n$。
- **视深**：正上方看 $h' = h/n$——池水看起来浅是折射的「欺骗」。
- 找虚像：反向延长线交点。
- 折射的极限（折射角 90°）就是全反射的临界条件。
- **疏密是相对的**：光疏 = 折射率小 = 光快；先比两介质谁大谁小，再判方向。
- **光路可逆**：光沿折射方向射回，会沿原入射方向返回——折射的对称性。

在下一节，我们研究折射的「极端形态」：**全反射**。当光从光密介质射向光疏介质、入射角超过临界角，光全部反射——光纤通信、钻石闪耀、水中气泡的银亮，都源于全反射。
