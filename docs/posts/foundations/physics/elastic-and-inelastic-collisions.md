## 为什么从弹性碰撞和非弹性碰撞开始

上一节的实验验证了动量守恒——无论什么碰撞，动量都守恒。但碰撞还有一个「命运攸关」的分叉：**动能守不守恒**。两球相撞，可能「完美弹开」（弹性碰撞，动能不变），也可能「黏在一起」（完全非弹性碰撞，动能损失最大），中间还有无数「部分弹性」的情形。按动能是否守恒给碰撞分类，是动量守恒定律最有价值的应用之一。

为什么碰撞问题如此重要？因为它几乎是一切相互作用的「简化原型」：分子碰撞、原子碰撞、粒子对撞、子弹入木块、台球对击、汽车碰撞——微观与宏观的相互作用都归结为「碰撞」。理解碰撞的分类与能量分配，等于理解了相互作用的基本图景。<span class="marginnote">「弹性」这个词源于「弹性体」：理想弹性体碰撞时形变完全恢复、无能量损失，动能守恒；非弹性体碰撞时形变部分或完全不恢复，一部分动能转化为内能。真实物体没有完全弹性或完全非弹性的——钢球接近弹性（恢复系数近 1），橡皮泥接近完全非弹性。碰撞的分类是「理想化的两端」，真实碰撞落在中间。</span>

学这一节，请把「动量守恒恒成立 + 动能守恒看弹性」这条主线刻进脑子里，然后掌握三个典型的碰撞类型与它们的解法。

## 1 碰撞的分类

按碰撞过程中**动能是否守恒**，碰撞分为三类：

1. **弹性碰撞**：碰撞过程中**动能守恒**（动量也守恒）。形变能完全恢复，没有机械能损失。理想模型，如钢球、分子碰撞的近似。
2. **非弹性碰撞**：动能不守恒（有部分动能转化为内能）。真实碰撞大多是这种。
3. **完全非弹性碰撞**：碰后两物体**共速**（黏在一起或以同一速度运动），动能损失**最大**。如子弹嵌入木块、两车追尾粘连。

**辨析｜易错点：** 三种碰撞都**遵守动量守恒**，区别只在动能守不守恒、以及碰后是否共速。把「碰撞一定动能守恒」当结论是错的——只有弹性碰撞动能守恒。判断依据：题目是否给「弹性」「光滑碰撞无能量损失」，或者给「碰后共速」「黏在一起」等字眼。<span class="marginnote">一个容易混的点：碰撞里「动能损失」不等于「动量不守恒」。碰撞中机械能转化为内能（形变、热），但总动量依然守恒——动量守恒不因能量损失而失效。这两条守恒律的「独立性」在本节展现得淋漓尽致：动量守恒恒成立（外力忽略时），动能守恒只在弹性碰撞成立。</span>

## 2 弹性碰撞的解析解

弹性碰撞同时满足动量守恒与动能守恒，两个方程联立可解出碰撞后速度。一维、质量 $m_1$、$m_2$，碰前速度 $v_1$、$v_2$，碰后 $v_1'$、$v_2'$：

$$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$$

$$\frac{1}{2}m_1v_1^2 + \frac{1}{2}m_2v_2^2 = \frac{1}{2}m_1v_1'^2 + \frac{1}{2}m_2v_2'^2$$

解之得：

$$v_1' = \frac{(m_1 - m_2)v_1 + 2m_2v_2}{m_1 + m_2}, \qquad v_2' = \frac{(m_2 - m_1)v_2 + 2m_1v_1}{m_1 + m_2}$$

**重要特例**（$m_2$ 静止，即 $v_2 = 0$）：

$$v_1' = \frac{m_1 - m_2}{m_1 + m_2}v_1, \qquad v_2' = \frac{2m_1}{m_1 + m_2}v_1$$

从这个特例能读出丰富的物理：

- **$m_1 = m_2$**（等质量）：$v_1' = 0$，$v_2' = v_1$——**碰撞后速度完全交换**。台球对击、牛顿摆的「头球停、尾球飞」正是此理。
- **$m_1 \ll m_2$**（小球撞大球）：$v_1' \approx -v_1$（反弹），$v_2' \approx 0$——小球几乎原速弹回，大球几乎不动。乒乓球撞墙、分子撞重分子类似。
- **$m_1 \gg m_2$**（大球撞小球）：$v_1' \approx v_1$（大球几乎不变），$v_2' \approx 2v_1$——小球以近两倍速度飞出。台球杆撞球、核反应堆慢化剂（中子撞轻核减速）类似。<span class="marginnote">「大球撞小球，小球跑出近 $2v_1$」与「小球撞大球，小球原速反弹」是弹性碰撞的两个极限，非常有用。它们的微观版在核物理里：中子撞重核几乎原速反弹（难减速），撞氢核（轻）则减速显著——所以核反应堆用轻水、石墨做慢化剂给中子减速。同一套弹性碰撞公式，从台球一路用到核反应堆。</span>

## 3 完全非弹性碰撞：共速与动能损失

完全非弹性碰撞：碰后两物体以同一速度运动（共速）。由动量守恒：

$$m_1v_1 + m_2v_2 = (m_1 + m_2)v'$$

$$v' = \frac{m_1v_1 + m_2v_2}{m_1 + m_2}$$

碰撞前后动能之差（损失的最大动能）：

$$\Delta E_k = \frac{1}{2}m_1v_1^2 + \frac{1}{2}m_2v_2^2 - \frac{1}{2}(m_1+m_2)v'^2 = \frac{1}{2}\frac{m_1m_2}{m_1+m_2}(v_1 - v_2)^2$$

**关键结论**：完全非弹性碰撞的动能损失正比于**相对速度的平方** $(v_1 - v_2)^2$ 与「约化质量」$\dfrac{m_1m_2}{m_1+m_2}$。相对速度越大、两质量越接近，损失越多。<span class="marginnote">「损失动能 = $\tfrac{1}{2}\mu(v_1-v_2)^2$」式中 $\mu = \dfrac{m_1m_2}{m_1+m_2}$ 叫<strong>约化质量</strong>。把两体碰撞「翻译」成「一个约化质量相对另一个」的语言后，公式变得清爽：损失只依赖「相对运动」。这个「两体问题化为一体」的技巧，在第二级《理论力学》里会系统化——二体碰撞、二体绕转都靠它。</span>

**子弹入木块**是经典模型：子弹以 $v_0$ 射入静止木块并嵌入（完全非弹性），碰后共速 $v' = \dfrac{m_{\text{子}}}{m_{\text{子}}+m_{\text{木}}}v_0$。损失的动能大部分转化为内能（发热、形变）——这正是「子弹打木块生热」的物理来源。

## 4 中间情形：恢复系数

真实碰撞介于弹性与完全非弹性之间，用**恢复系数（coefficient of restitution）** $e$ 描述：

$$e = \frac{v_2' - v_1'}{v_1 - v_2}$$

（$v_2' - v_1'$ 是碰后相对分离速度，$v_1 - v_2$ 是碰前相对接近速度，一维正碰取绝对值比较。）

- **$e = 1$**：弹性碰撞（分离速度 = 接近速度，动能守恒）。
- **$e = 0$**：完全非弹性碰撞（分离速度为 0，共速，动能损失最大）。
- **$0 < e < 1$**：非弹性碰撞（分离速度 < 接近速度，部分动能损失）。

恢复系数描述「形变恢复的程度」：完全恢复（弹性）、完全不恢复（完全非弹性）、部分恢复。<span class="marginnote">恢复系数的实用场景是「小球落地反弹」：球从 $h$ 落下，碰地弹回的高度 $h' = e^2 h$——因为碰地前后速度比 $e = v_{\text{回}}/v_{\text{落}}$，而速度与高度关系 $v \propto \sqrt{h}$。测落地反弹高度就能测 $e$。篮球、网球、乒乓球的「弹跳性」差异，正是 $e$ 的差异。</span>

**辨析｜易错点：** 恢复系数定义中**碰后速度差（分离）除碰前速度差（接近）**——方向别弄反。且 $e$ 只对「正碰」沿碰撞方向定义。二维斜碰的恢复系数要沿法线方向投影计算，较复杂，高中以正碰为主。

## 5 公式解析：弹性碰撞等质量交换速度

$$m_1 = m_2 \ \Rightarrow \ v_1' = v_2, \ v_2' = v_1$$

拆三步看：

- **第一步，代公式**：把 $m_1 = m_2 = m$ 代入弹性碰撞解 $v_1' = \dfrac{(m_1-m_2)v_1 + 2m_2v_2}{m_1+m_2}$，得 $v_1' = \dfrac{0 + 2mv_2}{2m} = v_2$；同理 $v_2' = v_1$。**等质量弹性碰撞 = 交换速度**。<span class="marginnote">「等质量交换速度」的直观验证——牛顿摆：五个等质量钢球吊成一排，拉起最左边一个释放，碰撞后最右边一个以相同速度飞出，中间的球不动。动量守恒 + 动能守恒同时满足，只有「交换速度」这一个解。这也是「完全弹性碰撞 + 等质量」的标志性结果，台球、牛顿摆都靠它。</span>
- **第二步，为什么只有这一个解**：动量守恒给出一个方程、动能守恒给出一个方程，两个未知数 $v_1'$、$v_2'$——两个独立方程恰好定死两个解。等质量代入后，解唯一。
- **第三步，动能守恒的「检验」作用**：弹性碰撞要求动能守恒，这是「交换速度」成立的第二根支柱。若只有动量守恒，解不唯一（相对速度可以任意）；动能守恒把「分离速度 = 接近速度」锁死。
- **第四步，物理意义**：交换速度意味着「能量和动量作为一个整体全部转移给另一个物体」——这正是台球「接力」的物理本质。碰撞前后「谁的运动变成了谁的运动」在等质量弹性碰撞里一目了然。

## 6 碰撞问题解题流程

综合碰撞题的标准流程：

1. **判断是否动量守恒**：系统是否受外力？碰撞瞬间外力可忽略 → 动量守恒。
2. **判断碰撞类型**：是否弹性（动能守恒）？是否完全非弹性（共速）？
3. **列动量守恒方程**（矢量式，先设正方向）。
4. **若弹性**：再列动能守恒方程，联立求解；若完全非弹性：用共速条件 $v_1' = v_2'$；若中间情形：用恢复系数或题目给的能量损失关系。
5. **检验解的合理性**：碰后是否可能「穿过彼此」（相对速度方向应合理）、动能是否非负。<span class="marginnote">「检验合理性」是碰撞题容易被忽略的最后一步：解出的碰后速度必须满足「分离速度 ≤ 接近速度」（$e \le 1$），否则说明列式有误或碰撞不可能发生。例如算出碰后两球「速度差」比碰前还大，就违反能量约束——说明碰前数据或方程有错。物理题的答案要过「物理常识关」。</span>

**辨析｜易错点：** 碰撞题最常见的错误是「只列动量守恒」然后想当然——非弹性碰撞动能不守恒，不能套弹性公式；完全非弹性要写共速条件。**先判断类型，再选公式**，顺序不能反。

## 7 辨析｜易错点

- **三种碰撞都动量守恒**：区别只在动能守不守恒与是否共速。
- **弹性碰撞**：动量 + 动能守恒联立；等质量交换速度，大球撞小球小球约 2 倍速度飞出。
- **完全非弹性**：共速，动能损失最大 $\Delta E_k = \tfrac{1}{2}\mu(v_1-v_2)^2$。
- **恢复系数**：$e = \dfrac{v_2'-v_1'}{v_1-v_2}$，$e=1$ 弹性、$e=0$ 完全非弹性。
- **先判类型再列式**：非弹性不能用弹性公式；共速条件只用于完全非弹性。
- **解要过物理关**：碰后分离速度不能大于接近速度（$e \le 1$）。

## 8 小结

- 碰撞三分类：弹性（动能守恒）、非弹性（动能损失）、完全非弹性（共速、损失最大）。
- **弹性碰撞解**：$v_1' = \dfrac{(m_1-m_2)v_1 + 2m_2v_2}{m_1+m_2}$，$v_2' = \dfrac{(m_2-m_1)v_2 + 2m_1v_1}{m_1+m_2}$。
- 特例：等质量交换速度；大球撞小球 → 小球近 $2v_1$；小球撞大球 → 反弹。
- **完全非弹性**：共速 $v' = \dfrac{m_1v_1+m_2v_2}{m_1+m_2}$，损失 $\tfrac{1}{2}\mu(v_1-v_2)^2$。
- **恢复系数** $e$ 量化「弹性程度」，从 1（弹性）到 0（完全非弹性）。
- 解题流程：判动量守恒 → 判类型 → 列式 → 检验合理性。

在下一节，我们把动量守恒用在一个壮观的场合：**反冲现象 火箭**。炮弹后坐、火箭喷气、飞船变轨——系统动量守恒，向后喷出质量就向前获得速度，这是人类冲出地球的物理基础。
