## 为什么从利用传感器制作简单的自动控制装置开始

前两节我们认识了传感器与敏感元件。这一节把它们组装成真正的「自动控制装置」：传感器负责**感知**，控制电路负责**判断**，执行器负责**行动**——三者组成自动控制的闭环。楼道声控灯、自动恒温空调、高温报警器、光控路灯，全是这套「感知-判断-行动」结构的实例。

这一节是第五章的「动手应用」：理解自动控制系统的组成、掌握「传感器 + 比较器/开关电路 + 执行器」的搭建思路、并能分析一个具体装置（如温度报警器、光控开关）的工作原理。它是「物理 → 电路 → 工程」的综合，也是你第一次把前五册的物理量、传感器、电路知识组装成一个「有用的系统」。<span class="marginnote">「自动控制的闭环结构」：<strong>传感器（感知实际量）→ 控制电路（与设定值比较、作出判断）→ 执行器（改变被控量）→ 反馈回传感器</strong>——这个「感知-判断-执行-反馈」的闭环，是自动控制的核心。恒温空调：温度传感器测室温 → 控制电路判断「高于/低于设定值」→ 压缩机启停 → 室温变化 → 传感器再测。闭环让系统「自己保持目标值」——这就是「自动化」的本质。</span>

学这一节，请抓住：**自动控制系统的组成、典型的控制装置（光控、温控、报警）、控制电路的核心元件（比较器/继电器）**。

## 1 自动控制系统的组成

一个自动控制系统由三部分组成：

1. **传感器**：感知被控物理量，把它变成电信号——系统的「感官」。
2. **控制电路**：处理传感器的信号，与设定值比较、作出判断，输出控制信号——系统的「大脑」。
3. **执行器**：根据控制信号执行动作（开关、电机、继电器）——系统的「手脚」。

**闭环控制**：执行器改变被控量后，传感器再次感知——形成反馈，系统自动维持目标值。

**辨析｜易错点：** 自动控制的关键是「闭环」——传感器「反馈」实际值、与设定值比较、自动调整。开环系统（只感知一次、不反馈）不能自动维持目标。「自动控制必须有传感器反馈」——没有反馈就不是「自动」调节，只是「定时/手动」控制。<span class="marginnote">「闭环 vs 开环」：闭环控制有反馈——传感器持续测量、不断修正（恒温空调：温度偏了就调）；开环控制没有反馈——按预设执行（定时电饭煲：到时间就跳，不管饭熟没熟）。自动控制的核心价值在闭环——「自动」的本质是「自我调节」，而自我调节必须有反馈。理解「反馈」二字，就理解了整个自动控制。</span>

## 2 光控自动开关装置

**光控开关**（路灯/楼道灯自动控制）是传感器控制装置的代表。

**结构**：

- **传感器**：光敏电阻（光照强时电阻小、光照弱时电阻大）。
- **控制电路**：光敏电阻与固定电阻串联组成分压电路，输出端接「比较器」（或晶体管的基极）。
- **执行器**：继电器（电磁开关）控制灯的电源。

**工作原理**：

1. 白天光照强 → 光敏电阻小 → 分压输出「高/低」电平 → 比较器输出「关」→ 继电器不动作 → 灯灭。
2. 夜晚光照弱 → 光敏电阻大 → 分压输出翻转 → 比较器输出「开」→ 继电器吸合 → 灯亮。
3. 设定「阈值」：改变固定电阻或比较器的参考电压，调整「多暗才开灯」。

**辨析｜易错点：** 光控开关的「阈值」由比较器设定——分压输出超过/低于参考电压，比较器翻转。调阈值 = 调参考电压或分压电阻。「光控开关的传感器是光敏电阻」——它把「光照」变成「电阻/电压」，控制电路再判断。别把「传感器」与「执行器」混——光敏电阻是传感器，继电器/灯是执行器。<span class="marginnote">「比较器的角色」：比较器是控制电路的「判断器」——它把传感器的电压与参考电压比较，输出「开/关」信号。参考电压就是「设定值」：路灯的「多暗才亮」、报警器的「多热才响」都由参考电压决定。比较器 + 传感器 + 执行器 = 一个「有判断力的自动控制装置」。比较器可以用运算放大器实现，也可以用晶体管开关电路（更简单）。</span>

## 3 温度报警/温控装置

**温度报警器**（或恒温控制器）的典型结构：

- **传感器**：热敏电阻（NTC，温度升高电阻减小）。
- **控制电路**：热敏电阻与固定电阻分压，输出接比较器（参考电压设定报警/控温阈值）。
- **执行器**：蜂鸣器/继电器（报警时响铃、温控时启停加热器）。

**工作原理**：

1. 温度升高 → 热敏电阻（NTC）减小 → 分压电压变化 → 达到阈值 → 比较器翻转 → 报警器响（或加热器停止）。
2. 温度降低 → 热敏电阻增大 → 分压反向变化 → 比较器恢复 → 报警停止（或加热器启动）。
3. **恒温控制**：设定「上限」与「下限」，温度超过上限停止加热、低于下限启动加热——在设定区间内自动维持。

**辨析｜易错点：** 温控的关键是「设定阈值」与「反馈」——温度传感器持续测量、控制电路持续比较、执行器持续调节。分析温控装置：先确定「温度变 → 热敏电阻怎么变 → 分压怎么变 → 比较器输出怎么变 → 执行器怎么动」，一步步推导。「温控装置的传感器是热敏电阻、执行器是加热器」——分清感知、判断、行动三层。<span class="marginnote">「恒温器的滞回特性」：实际恒温器不会「到 25 ℃ 就停、到 24.9 ℃ 就开」地频繁跳动——它有「滞回」（上限与下限之间有个差值）。设上限 26 ℃、下限 24 ℃：温度升到 26 ℃ 停加热，降到 24 ℃ 才重新加热——避免「临界抖动」。这个「滞回」设计让执行器不会在阈值附近高频开关。「工程细节」藏在「自动控制」里：阈值不是单点，而是「区间」。</span>

## 4 其他典型的自动控制装置

**声控/光控楼道灯**：光敏电阻（白天光强、灯不亮）+ 声敏传感器（晚上有声音、灯亮）+ 延时电路（亮一会自动灭）——多传感器配合。

**自动消防报警**：温度传感器（过热）+ 烟雾传感器（光电）——任一触发就报警。

**自动灌溉**：土壤湿度传感器（湿度低）→ 控制电路 → 电磁阀打开浇水——湿度反馈闭环。

**电子秤**：压力传感器（压力 → 应变片电阻变化 → 电桥电压）→ 放大 → 显示重量。

**汽车胎压监测**：压力传感器测胎压，低于阈值报警。

**辨析｜易错点：** 自动控制装置的「传感器选择」取决于「被控量」——控温用温度传感器、控光用光传感器、控压用压力传感器。「一个装置可以用多个传感器」（楼道灯：光 + 声）；「一个传感器可以用于多个装置」（热敏电阻用于恒温器、报警器、过热保护）。理解「被控量 → 传感器 → 控制 → 执行」的映射，就能分析任何自动装置。<span class="marginnote">「传感器的组合应用」：复杂自动控制常「多传感器融合」——智能楼道的灯「光控 + 声控 + 红外人体感应」，白天（光强）不亮、晚上有人（声/红外）才亮。每个传感器负责「感知一个条件」，控制电路「逻辑判断」（与/或）后驱动执行器。这个「多感知 + 逻辑判断 + 执行」的结构，正是今天「智能家居」「物联网」的雏形——你的手机、智能音箱、自动窗帘，都是「传感器组合 + 智能控制」。</span>

## 5 公式解析：分压电路与阈值判断

传感器控制电路的核心是「分压 + 比较」：

$$U_{\text{出}} = \frac{R_2}{R_1 + R_2}E$$

（$R_1$ 敏感电阻、$R_2$ 固定电阻，$E$ 电源电压）

拆三步看：

- **第一步，分压原理**：敏感电阻与固定电阻串联，输出电压是「某个电阻分到的电压」$U = \dfrac{R_i}{R_1 + R_2}E$。敏感电阻变化 → 输出电压变化。<span class="marginnote">「分压公式的直觉」：串联电路电压按电阻比例分配——电阻大者分压大。敏感电阻（热敏/光敏）变化时，它分到的电压按比例变化：NTC 热敏电阻温度高 → 电阻小 → 它分到的电压小（固定电阻分到的电压大）。输出电压取哪个电阻、正比还是反比，看具体接法。做这类题先「标出哪个是敏感电阻、输出端取哪段」，再代入分压公式。</span>
- **第二步，比较器的阈值**：比较器把 $U_{\text{出}}$ 与参考电压 $U_{\text{ref}}$ 比较——$U_{\text{出}} > U_{\text{ref}}$ 输出高电平、反之低电平（或相反）。参考电压就是「设定的阈值」，由分压电阻调定。
- **第三步，完整的判断链**：物理量变化 → 敏感电阻变化 → 分压电压变化 → 越过阈值 → 比较器翻转 → 执行器动作。每一步都可推导、可计算。
- **第四步，例题式分析**：光控开关，光敏电阻 $R_G$ 与固定电阻 $R$ 串联，$U_{\text{出}}$ 取 $R$ 的电压。白天光强 $R_G$ 小 → $U_{\text{出}} = \dfrac{R}{R + R_G}E$ 大 → 比较器（$U_{\text{出}}$ 与参考比）输出关灯；夜晚 $R_G$ 大 → $U_{\text{出}}$ 小 → 翻转开灯。**先画「物理量 → 电阻 → 电压 → 输出」的链，再算阈值对应的物理量值**。

## 6 自动控制装置的设计思路

设计一个传感器自动控制装置的通用流程：

1. **明确被控量与控制目标**：控制什么（温度/光/压力）？目标是什么（保持恒温/天黑开灯）？
2. **选传感器**：被控量对应什么敏感元件（温度→热敏、光→光敏、磁场→霍尔）。
3. **设计控制电路**：分压 + 比较器，设定阈值。
4. **选执行器**：怎么执行（继电器开关、电机、蜂鸣器）。
5. **闭环检查**：执行后是否反馈回传感器（自动维持）？

**辨析｜易错点：** 设计自动控制装置要「先想清楚被控量与目标，再选器件」——不是「先有器件再想用途」。传感器选型、阈值设定、执行器选择都围绕「控制目标」。「设计」的本质是「围绕目标的器件匹配」——理解了目标，装置自然浮现。<span class="marginnote">「设计流程的工程思维」：自动控制设计是「目标导向」的工程问题——先定义「要自动维持什么」（恒温 25 ℃、天黑开灯、过热报警），再选「感知的传感器」（热敏、光敏、热敏+比较器）、「判断的电路」（比较器阈值）、「行动的器件」（加热器、灯、蜂鸣器）。这个「目标 → 感知 → 判断 → 行动」的设计法，与任何工程系统的设计思路一致——理解它，你就从「学物理」走向「做工程」。</span>

## 7 辨析｜易错点

- **自动控制三要素**：传感器（感知）、控制电路（判断）、执行器（行动）。
- **闭环才有「自动」**：反馈是自动调节的核心。
- **阈值由比较器设定**：参考电压/分压电阻决定「何时动作」。
- **分压电路**：$U = \dfrac{R_i}{R_1+R_2}E$，敏感电阻变化 → 电压变化。
- **被控量决定传感器**：温度→热敏、光→光敏、压力→压力传感。
- **多传感器融合**：复杂装置用多个传感器 + 逻辑判断。

## 8 小结

- **自动控制系统**：传感器 + 控制电路 + 执行器，闭环反馈自动调节。
- **光控开关**：光敏电阻 → 分压 → 比较器 → 继电器 → 灯。
- **温控装置**：热敏电阻 → 分压 → 比较器（阈值）→ 加热器/报警器。
- **分压电路**：$U = \dfrac{R_i}{R_1+R_2}E$，把电阻变化变电压变化。
- **比较器**：电压与参考值比较，输出开关信号——「判断」的核心。
- 设计流程：明确目标 → 选传感器 → 设阈值 → 选执行器 → 闭环检查。
