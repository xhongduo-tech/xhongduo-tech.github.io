## 为什么从应用开始

前三节我们拿到了动力学三件套：牛顿第一定律（惯性）、牛顿第二定律（$F = ma$）、力学单位制。但定律本身只是一套「语法」，会背不等于会用。**牛顿运动定律的应用**，是把它们第一次整合成完整解题流程的地方。这一节既是前面所有概念的收口，也是后面所有动力学的模板——圆周运动、天体运动、电磁场里的带电粒子运动，本质上都是「受力分析 → 牛顿第二定律 → 运动学」这条链路的变体。甚至可以说，从高中物理到大模型训练，都存在两种互补的思维路径：已知原因推后果、已知后果反推原因。这一节就是这两种路径最纯正的一次演练。

## 1 动力学的两类基本问题

牛顿第二定律 $\vec{F}_{\text{合}} = m\vec{a}$ 里站着两个角色：**受力**与**运动**。于是动力学问题天然分成两类：

- **第一类 · 已知受力求运动**：受力分析 → 求合力 → 由 $a = F_{\text{合}}/m$ 求加速度 → 用运动学公式求速度、位移。
- **第二类 · 已知运动求受力**：运动学公式 → 求加速度 → 由 $F_{\text{合}} = ma$ 求合力 → 结合受力分析解出某个未知力。

用一个具体的例子把第一类走一遍。质量 $m = 2.0\ \text{kg}$ 的物体放在水平面上，受水平拉力 $F = 10\ \text{N}$，物体与水平面的动摩擦因数 $\mu = 0.2$，求它从静止开始 $3.0\ \text{s}$ 末的速度。

- 受力分析：物体受重力 $mg$、支持力 $N$、拉力 $F$、滑动摩擦力 $f$。
- 竖直方向 $N = mg$；水平方向合外力 $F_{\text{合}} = F - f = F - \mu mg$。
- 代入数值：$F_{\text{合}} = 10 - 0.2 \times 2.0 \times 9.8 = 6.08\ \text{N}$，加速度 $a = F_{\text{合}}/m = 3.04\ \text{m/s}^2$。
- 运动学：$v = v_0 + at = 0 + 3.04 \times 3.0 \approx 9.1\ \text{m/s}$。

第二类例子：一辆汽车紧急刹车，从 $v_0 = 20\ \text{m/s}$ 匀减速到停下，滑行距离 $x = 25\ \text{m}$。由 $v^2 - v_0^2 = 2ax$ 得 $a = v_0^2/(2x) = 400/50 = 8.0\ \text{m/s}^2$，方向与运动相反。若汽车质量 $m = 1.5\times10^3\ \text{kg}$，则刹车阻力 $F_{\text{阻}} = ma = 1.2\times10^4\ \text{N}$。<span class="marginnote">注意两类问题的「输入输出」完全互换：第一类先给力、后得运动；第二类先给运动、后得力。做题时先判断属于哪一类，再决定从哪头开始。</span>

**两类问题的区别只在推理方向，骨架完全相同**：都是在「受力 ↔ 加速度 ↔ 运动」的三角关系里走一条边。第 5 节我们会专门拆开看 $F = ma$ 为何能双向行驶。

补充一句前提：牛顿第二定律只在**惯性参考系**中成立。高中阶段默认地面为近似惯性系；若在加速运动的电梯里测力，就要小心「惯性力」的假象——这正是下一节超重失重要分辨的问题。

## 2 一套可以复用的解题流程

把两类问题统一成五步流程，这也是所有动力学大题的「标准动作」：

1. **选对象**：明确研究对象，必要时把整体与部分分别作为对象。
2. **受力分析**：按「重力 → 弹力 → 摩擦力 → 其他已知外力」的顺序，画出受力图。
3. **建坐标**：通常沿加速度方向建 $x$ 轴，垂直方向建 $y$ 轴（即正交分解）。
4. **列方程**：$x$ 方向 $F_x = ma_x$；$y$ 方向若平衡则 $F_y = 0$。
5. **解与检验**：解出未知量，检查单位与量级是否合理。

<span class="marginnote">受力分析是所有动力学题的起点。很多同学式子写得飞快，受力图却画得潦草，最后一步差之毫厘、谬以千里。先画图、再列式，这个顺序不能反。</span>

这套流程的价值在于**可迁移**：物体在斜面上、在粗糙水平面上、在电梯里，变的只是受力图，骨架不变。等你学到电磁场，把「重力、弹力、摩擦力」换成「电场力、洛伦兹力」，流程依然成立。

以最常见的**斜面**为例，看看正交分解如何落地。物体沿光滑斜面下滑，把重力沿斜面方向与垂直斜面方向分解：垂直斜面方向平衡 $N = mg\cos\theta$；沿斜面方向

$$mg\sin\theta = ma \quad\Longrightarrow\quad a = g\sin\theta$$

若斜面粗糙（动摩擦因数 $\mu$），则沿斜面方向 $mg\sin\theta - \mu mg\cos\theta = ma$，即

$$a = g(\sin\theta - \mu\cos\theta)$$

斜面的价值在于：它把「倾斜」翻译成「沿斜面与垂直斜面」两个互相垂直的方向，而垂直方向恰好处于平衡态，摩擦力与弹力也随之确定——这正是正交分解最标准的教科书示范。

## 3 连接体：整体法与隔离法

当两个或多个物体相互作用、一起运动（叠放的木块、用细绳连接的小车与重物），这类问题叫**连接体问题**，它需要两种视角来回切换：

- **整体法**：把整个系统看成一个整体，只分析**外力**，求出共同的加速度。
- **隔离法**：取其中一个物体，分析它受到的全部力（**包括系统内力**），求出物体间的相互作用力。

经典模型：光滑水平面上，质量 $m_1$、$m_2$ 的两个物体用轻绳相连，在 $m_1$ 上施加水平拉力 $F$。

- 整体：$F = (m_1 + m_2)a$，得 $a = \dfrac{F}{m_1 + m_2}$。
- 隔离 $m_2$：绳的张力 $T = m_2 a = \dfrac{m_2 F}{m_1 + m_2}$。

注意一个高频易错点：**绳的张力 $T$ 并不等于 $F$**，因为 $F$ 的一部分要用来加速 $m_1$ 本身；只有 $m_1 \to 0$ 时才有 $T \to F$。<span class="marginnote">整体法求加速度、隔离法求内力，是连接体的黄金组合。能否用整体法，关键看物体间没有相对运动、加速度相同。这个「先粗后细」的思路在编程里也常见：先看整体接口，再进细节实现。</span>

## 4 临界问题：过程的「分岔点」

题目里出现「刚好」「恰好」「最大」「至少」这些词时，就是**临界问题**。临界状态通常是某个力恰好达到极值的瞬间：摩擦力达到最大静摩擦力、接触面压力刚好变为零、绳子张力刚好为零。

例子：水平面上放质量 $m_1$ 的木板，上面放质量 $m_2$ 的物块，两物体间动摩擦因数为 $\mu$。对木板施加水平力 $F$ 并逐渐增大，问 $F$ 多大时物块开始相对木板滑动。

- 临界条件：物块「恰好要滑但还没滑」，此时两者加速度相同，且物块受的摩擦力恰好达到最大静摩擦力 $\mu m_2 g$。
- 隔离物块：$\mu m_2 g = m_2 a$，得 $a = \mu g$。
- 整体：$F = (m_1 + m_2)a = (m_1 + m_2)\mu g$。

这个 $F$ 就是临界值。<span class="marginnote">临界问题的本质不是多了一条新规律，而是把「运动状态将要改变」翻译成「某个力恰好取到极值」的数学条件。抓住这层翻译，难题就降维成普通题。「恰好不相撞」「恰好通过最高点」在追及相遇与圆周运动里会反复登场。</span>

## 5 公式解析：F = ma 是「双向行驶」的方程

$$
\begin{cases}
a = \dfrac{F_{\text{合}}}{m} & (\text{已知力求运动}) \\[10pt]
F_{\text{合}} = m\,a & (\text{已知运动求受力})
\end{cases}
$$

同一个方程，两个方向都能读。拆三步理解：

- **第一步：谁是因，谁是果。** 合力是「原因」，加速度是「结果」。$\vec{a}$ 与 $\vec{F}_{\text{合}}$ 同方向，$m$ 是标量的惯性量度。这里的 $\vec{F}_{\text{合}}$ 是矢量合成的结果，必须先把几个力按平行四边形定则合成，再代入方程。
- **第二步：第一类问题的输入口。** 把 $a = F_{\text{合}}/m$ 当作运动学公式的「输入」，即 $v = v_0 + at$、$x = v_0t + \tfrac{1}{2}at^2$ 里的 $a$ 都来自这里。做一次量纲检查：$\text{N}/\text{kg} = (\text{kg}\cdot\text{m/s}^2)/\text{kg} = \text{m/s}^2$，正好是加速度单位。
- **第三步：第二类问题的反向路径。** 先用运动学公式求出 $a$，再乘 $m$ 得到合力，最后结合受力分析反解某个未知力（如支持力、摩擦力、牵引力）。量纲依然自洽：$\text{kg} \times \text{m/s}^2 = \text{N}$。

一个常被忽略的点：**单位制是这条双向桥的「车道线」**。若把质量写成「克」、长度写成「厘米」，量纲检查会当场暴露错误——这正是前面《力学单位制》一节的用武之地。

## 6 辨析｜易错点：受力分析里的三张「假力」

- **假力一：把 $ma$ 当成力。** 受力图只画性质力（重力、弹力、摩擦力、已知外力），$ma$ 是合外力的**效果**，不是独立存在的力。
- **假力二：把「惯性力」画进受力图。** 惯性力只在非惯性系里为方便而引入，高中不要求，把它当真实力是概念性错误。
- **假力三：以为「有运动方向就有力」。** 匀速直线运动的物体合力为零；物体有速度不等于一定受力。力是改变运动状态的原因，不是维持速度的原因。<span class="marginnote">这与牛顿第一定律一脉相承：不是「有力才动」，而是「有力才变」。做题时先问「运动状态变不变」，再决定是否需要非零合力。</span>

## 7 小结

- 动力学两类基本问题：**已知受力求运动**与**已知运动求受力**，是 $F = ma$ 的两个方向。
- 标准解题流程：选对象 → 受力分析 → 正交分解 → 列方程 → 求解检验。
- 连接体：**整体法求加速度，隔离法求内力**；绳张力 $T$ 通常不等于外加拉力 $F$。
- 临界问题：把「运动状态将变」翻译成「某个力恰好取极值」的条件。
- 受力分析只画性质力，$ma$、惯性力一律不入图。

在下一节，我们仍在本章框架内，把牛顿定律应用到一种奇妙的现象上——竖直方向加速运动时，人会「感觉变重或变轻」。这就是**超重和失重**。
