## 为什么从能量守恒定律开始

从第八章的机械能守恒，到上一节的热力学第一定律，能量守恒的思想贯穿了整本物理书。这一节把它提升为**最普适的自然规律**：能量既不会凭空产生、也不会凭空消失，只会从一种形式转化为另一种形式。这是物理学的「总账本」，统摄力学、热学、电磁学、光学的一切能量转化。

能量守恒定律的发现是 19 世纪物理学的伟大成就：焦耳、迈耶、亥姆霍兹几乎同时独立确立它。它统一了机械能、内能、电能、化学能、核能……所有的能量形式。它也是工程设计的最高约束：一切「永动机」都因违反它而失败。<span class="marginnote">「能量守恒定律 = 物理学的总账本」：机械能守恒（第八章）是它在力学里的特例，热力学第一定律（上一节）是它在热学里的形式，焦耳定律是它在电路里的形式——全部统一在「能量不灭」这一条下。19 世纪中叶，焦耳（热功当量）、迈耶（热力学）、亥姆霍兹（力学）从不同路径汇合到同一条定律——这是科学史上「多路殊途同归」的经典案例。</span>

学这一节，请抓住：**能量守恒定律的内容、能量转化与转移、第一类永动机的否定**。

## 1 能量守恒定律

**能量守恒定律**：能量既不会凭空产生，也不会凭空消失，它只能从一种形式转化为另一种形式，或者从一个物体转移到另一个物体，在转化和转移的过程中，能量的总量保持不变。

**能量守恒的两种「流动」**：

**转化**：能量从一种形式变成另一种形式（机械能 → 内能、电能 → 光能、化学能 → 内能……）。
**转移**：能量从一个物体传到另一个物体（热传递、做功传递）。

无论怎么转化、转移，**总能量守恒**——这是自然界的「总账本」。

**辨析｜易错点：** 能量守恒说的是「总量不变」，不是「每个物体的能量不变」。能量可以在物体之间转移、在形式之间转化——但总量恒守恒。把「能量守恒」理解成「能量不能转移」是错的——它恰恰是说「怎么转移都行，总账平衡」。<span class="marginnote">「转化 vs 转移」的区别：转化是「形式变」（动能变内能、电能变光能），转移是「位置变」（热从热水传到冷水、功从外界传给气体）。能量守恒对两种流动都成立——形式随便换、位置随便移，总量锁定。生活中的一切「用能」都是「转化 + 转移」的组合：电灯把电能（转化）变光能，灯泡同时把热能（转移）散发到房间。</span>

## 2 能量的各种形式与转化

自然界的主要能量形式与相互转化：

| 能量形式 | 微观/宏观来源 | 实例 |
| --- | --- | --- |
| 机械能 | 运动（动能）+ 位置（势能） | 运动物体、高处物体 |
| 内能 | 分子热运动动能 + 分子势能 | 温度、物态 |
| 电能 | 电荷的电场能量 | 电流、电场 |
| 化学能 | 化学键的势能 | 燃料、电池、食物 |
| 光能（辐射能） | 电磁波的能量 | 太阳光、激光 |
| 核能 | 原子核的结合能 | 核裂变、核聚变 |

**能量的转化链**（常见例子）：

**水力发电**：水的机械能 → 发电机 → 电能 → 输送到用户 → 光能/热能/机械能。
**燃烧**：化学能 → 内能 → （热机）机械能。
**光合作用**：光能 → 化学能（储存在有机物中）。
**电池放电**：化学能 → 电能 → 光能/内能。

**辨析｜易错点：** 能量转化中「效率」永远小于 100%（有能量变成低品位内能散失），但「总量」守恒——效率低不等于能量消失，是「高品质能量降级为低品质内能」。这个「守恒 + 降级」的双重性，是下一节热力学第二定律的入口。<span class="marginnote">「能量的品质降级」是理解「为什么节能」的关键：能量虽然守恒，但每一次转化都有一部分变成「低品质」的内能（散失到环境），无法再用于做功。发一度电，燃烧的化学能只有约 40% 变成电能，60% 变成废热——不是能量消失了，而是「可用能」减少了。所以「节能」的本质是「减少能量品质的降级」——这导向热力学第二定律（下一节）。</span>

## 3 能量守恒与热力学第一定律的关系

**热力学第一定律是能量守恒在热学中的具体形式**：

$$\Delta U = W + Q$$

它说「内能变化 = 做功 + 传热」——正是「能量不会凭空产生/消失」在「内能、功、热」三者间的体现。

**能量守恒比热力学第一定律更广**：

- 热力学第一定律只涉及「内能、功、热量」三种量。
- 能量守恒定律涵盖一切能量形式（机械、电、化学、核……）。

所以能量守恒是「总纲」，热力学第一定律是它在热学里的「特化」。在做涉及多种能量转化的综合题时，用「能量守恒」的总账视角，把各种能量都算进去。

**辨析｜易错点：** 机械能守恒（第八章）是能量守恒的**特例**——只在「只有保守力做功」时机械能总量不变；但即使机械能不守恒（有摩擦），总能量（机械能 + 内能）仍守恒。做题时区分「机械能守恒」（特例）与「能量守恒」（普适）。<span class="marginnote">「三个守恒的层级」：能量守恒（最普适，一切能量形式）→ 热力学第一定律（热学特化，内能+功+热）→ 机械能守恒（力学特例，只有保守力做功）。做题时先问「用哪一层」：有摩擦、生热 → 用能量守恒或热一律；光滑无阻 → 用机械能守恒。层级选对，题就顺了。</span>

## 4 第一类永动机的否定

**第一类永动机**：不消耗任何能量而能持续对外做功的机器。

**能量守恒的判决**：第一类永动机**不可能实现**——它想「凭空产生能量」，违反能量守恒定律。要对外做功，必须输入能量；能量不灭，功不能无中生有。

**辨析｜易错点：** 注意区分「第一类永动机」（凭空产生能量，被能量守恒否定）与「第二类永动机」（从单一热源吸热全部转化为功，被热力学第二定律否定）。两类永动机都被否定，但依据的定律不同。<span class="marginnote">「两类永动机」是热力学两条定律的试金石：<strong>第一类：想凭空生能（违背能量守恒/热一律）→ 不可能；第二类：想从单一热源吸热全变功（违背热力学第二定律）→ 不可能</strong>。第二类永动机并不违反能量守恒（它吸热做功，能量守恒），但它违反「热不能自发地从低温流向高温/效率有上限」。两类永动机的否定，分别确立了热力学的第一、第二定律。</span>

## 5 公式解析：能量守恒的总账

能量守恒可以写成「总账」形式：

$$E_{\text{初}} + \sum E_{\text{输入}} = E_{\text{末}} + \sum E_{\text{输出}}$$

（初始总能量 + 输入能量 = 末态总能量 + 输出能量）

拆三步看：

- **第一步，总账的写法**：把初态能量、输入能量、末态能量、输出能量（包括各种形式的能量）全部列出，守恒即「初 + 入 = 末 + 出」。<span class="marginnote">「能量总账」的实操：做能量守恒题时，把「初态各种能量」「末态各种能量」「过程中输入/输出的能量」列一张表，初 + 入 = 末 + 出。摩擦生热（机械能 → 内能）就记「内能增加」，发热散失记「输出内能」。这个「列总账」的方法，比死套公式更不容易漏项。</span>
- **第二步，与热一律的联系**：对热学系统，总账化为 $\Delta U = W + Q$（输入功、输入热量，内能增加）。能量守恒是总账、热一律是热学分账。
- **第三步，效率与损耗**：任何转化过程，输出有用能量 < 输入能量（有损耗）——但「损耗」不是消失，是变成了低品位内能（总账仍平）。
- **第四步，应用**：力学综合题（下滑 + 摩擦生热）、电学题（电能 → 机械能 + 内能）、核能题（质量亏损 → 能量），全用能量总账。

## 6 辨析｜易错点

- **能量守恒是普适的**：机械能守恒是特例（只有保守力做功时）。
- **转化 vs 转移**：形式变（转化）、位置变（转移），总量都不变。
- **效率低 ≠ 能量消失**：变成低品位内能，总量守恒。
- **两类永动机**：第一类违背能量守恒、第二类违背热力学第二定律。
- **列总账**：初 + 入 = 末 + 出，各种能量都要算。
- **节能的本质**：减少能量品质的降级。

## 7 小结

- **能量守恒定律**：能量不灭，只能转化与转移，总量不变。
- **转化 vs 转移**：形式变（转化）、位置变（转移）。
- 能量形式：机械、内、电、化学、光、核……相互转化。
- **热一律是能量守恒的热学形式**；机械能守恒是特例。
- **第一类永动机不可能**：能量守恒的判决。
- 节能 = 减少能量品质降级——通向下节的熵与第二定律。

在下一节，我们研究能量转化的「方向」：**热力学第二定律**。能量守恒没告诉我们的——为什么热不能自发从低温流向高温、为什么效率有上限——由第二定律回答。
