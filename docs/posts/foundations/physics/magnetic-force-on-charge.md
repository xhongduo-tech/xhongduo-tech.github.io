# 磁场对运动电荷的作用力

## 为什么从磁场对运动电荷的作用力开始

上一节安培力是磁场对「通电导线」的力，而电流是电荷的定向移动——那么磁场对**单个运动电荷**应该也有力。这个力叫**洛伦兹力（Lorentz force）**，是 19 世纪末荷兰物理学家洛伦兹系统研究的。它比安培力更基本：安培力只是洛伦兹力的宏观总和。

洛伦兹力看似简单（$F = qvB$），却开启了微观粒子操控的新世界：带电粒子在磁场中做圆周运动——质谱仪分离离子、回旋加速器加速粒子、显像管与电子显微镜偏转电子束、极光是太阳风粒子沿磁感线螺旋进入大气。整个粒子物理与加速器科学，都建立在洛伦兹力之上。<span class="marginnote">洛伦兹力的一个「怪」性质：<strong>它永远垂直于电荷的速度方向，所以永远不做功</strong>。这意味着磁场只能改变带电粒子的运动方向、不能改变速度大小与动能——粒子在匀强磁场中做匀速圆周运动，动能恒定。这与电场力（沿电场方向、能做功）形成鲜明对比：电场改变能量，磁场改变方向。「磁场不做功」是理解带电粒子运动与电磁场的核心。</span>

学这一节，请抓住：**洛伦兹力的大小与方向、为什么它不做功、以及它如何让粒子做圆周运动**。

## 1 洛伦兹力：大小与方向

**洛伦兹力**：磁场对运动电荷的作用力。

**大小**：

$$F = qvB\sin\theta$$

其中 $q$ 是电荷量、$v$ 是电荷速度、$B$ 是磁感应强度、$\theta$ 是 $v$ 与 $B$ 的夹角。

- 速度**垂直**磁场（$\theta = 90°$）：$F = qvB$（最大）。
- 速度**平行**磁场（$\theta = 0°$）：$F = 0$（不受力）。
- 电荷**静止**（$v = 0$）：$F = 0$——磁场对静止电荷无力（这是与电场最本质的差别，电场对静止电荷有力 $qE$）。

**方向（左手定则）**：伸开左手，磁感线穿手心、四指指向**正电荷运动方向**（负电荷方向相反）、拇指指洛伦兹力方向。洛伦兹力 $F \perp v$ 且 $F \perp B$。<span class="marginnote">负电荷的左手定则有个「负号」麻烦：四指指向正电荷运动方向，负电荷则要「反向」。更省事的办法：把负电荷的速度方向反向后当成「正电荷」用左手定则；或者直接用右手定则（负电荷四指反向）。记住「正电荷四指指速度、负电荷四指指速度的反方向」即可。</span>

**辨析｜易错点：** 洛伦兹力对**静止电荷为零**、对**平行于磁场的运动电荷为零**——「电荷在磁场中一定受力」是错的。只有「运动且速度不平行于磁场」才受力。这是洛伦兹力与库仑力（对静止电荷也有力）的根本区别。

## 2 洛伦兹力不做功

洛伦兹力最重要的性质：**洛伦兹力永远不做功**。

因为 $F \perp v$（洛伦兹力恒垂直速度），所以 $F$ 在速度方向（位移方向）的投影为零，$W = Fs\cos90° = 0$。

**推论**：

- 磁场不能改变带电粒子的**速度大小**（动能），只能改变**方向**。
- 带电粒子在磁场中运动，**动能守恒**。
- 磁场对粒子的作用像「转弯的力」，不是「加速的力」——要加速粒子，得靠电场（回旋加速器里电场加速、磁场转弯）。<span class="marginnote">「磁场不加速粒子」是个反直觉但极重要的结论：磁场只让粒子「拐弯」，不增加它的速度与能量。加速器里真正给粒子加能量的是电场（电场力做功），磁场负责「保持轨道」（让粒子转圈）——所以叫「回旋加速器」：电场每半圈加速一次，磁场让粒子转回去再加速。把「磁场能加速粒子」当结论是错误理解。</span>

**辨析｜易错点：** 洛伦兹力不做功 ≠ 洛伦兹力无作用。它改变速度方向（产生向心加速度），对粒子的**轨迹**影响巨大；只是不做功、不改变动能。把「不做功」理解成「不起作用」是概念的混淆。

## 3 带电粒子在匀强磁场中的圆周运动

当带电粒子以速度 $v$ **垂直**射入匀强磁场（$v \perp B$），洛伦兹力提供向心力，粒子做**匀速圆周运动**：

$$qvB = \frac{mv^2}{r}$$

**轨道半径**：

$$r = \frac{mv}{qB}$$

**周期**（与速度无关！）：

$$T = \frac{2\pi m}{qB}$$

**关键结论**：

- **半径与速度成正比**：$v$ 大则轨道大。
- **周期与速度无关**：只由 $m$、$q$、$B$ 决定——这是回旋加速器「同步加速」的原理（粒子速度增大、半径增大，但转一圈的时间不变）。<span class="marginnote">「回旋加速器的同步」就靠 $T = 2\pi m/(qB)$ 与速度无关：粒子每转半圈被电场加速一次，速度增大、半径增大，但周期不变——所以电场可以「固定频率」同步加速。这个「周期与速度无关」是匀强磁场中圆周运动最优雅的性质，也是回旋加速器能工作的原因。若粒子速度接近光速，质量要按相对论修正，周期变长，回旋加速器就失效了——这正是大能量加速器要用同步加速器的原因。</span>

**辨析｜易错点：** 粒子做圆周运动的**半径与周期**公式，$r = mv/(qB)$、$T = 2\pi m/(qB)$——注意 $r \propto v$、$T$ 与 $v$ 无关。把「周期随速度变」当结论是错的（$T$ 只由 $m$、$q$、$B$ 定）。

## 4 带电粒子在磁场中运动的其他情形

- **速度方向不垂直磁场**（有平行分量）：粒子沿磁场方向匀速、垂直方向圆周——合运动是**螺旋线**。地球磁场中的带电粒子（极光）就沿磁感线螺旋前进，在极区磁场强处被「反射」（磁镜效应）。<span class="marginnote">螺旋运动 = 平行磁场的匀速直线 + 垂直磁场的圆周。太阳风粒子沿地球磁感线螺旋进入两极，与大气分子碰撞发光——极光。在磁场增强的区域（两极），螺旋半径变小、粒子被「反弹」——这叫磁镜效应，地球磁场像一个「磁瓶」，困住高能粒子形成辐射带（范艾伦带）。「磁场囚禁粒子」是磁约束核聚变（托卡马克）的核心思想。</span>
- **速度与磁场平行**：$F = 0$，粒子匀速直线运动。
- **电场与磁场叠加**：电场力改变能量、磁场力改变方向——速度选择器、质谱仪、回旋加速器都靠「电磁场组合」操控粒子。

## 5 公式解析：r = mv/(qB) 与 T = 2πm/(qB)

$$r = \frac{mv}{qB}, \qquad T = \frac{2\pi m}{qB}$$

拆三步看：

- **第一步，半径的来源**：洛伦兹力提供向心力，$qvB = \dfrac{mv^2}{r}$，两边约去一个 $v$ 得 $r = \dfrac{mv}{qB}$。<span class="marginnote">推导里「约去 $v$」是关键：向心力公式里是 $v^2$，洛伦兹力里是 $v$，一比就剩 $v$——所以半径正比于速度一次方。若约不掉（比如别的力），半径与速度的关系就会不同。这个「一约」决定了「$r \propto v$」，也决定了「周期与 $v$ 无关」。</span>
- **第二步，周期的来源**：$T = \dfrac{2\pi r}{v} = \dfrac{2\pi (mv/qB)}{v} = \dfrac{2\pi m}{qB}$——$v$ 再次约掉，周期与速度无关。物理图像：速度大 → 半径大 → 转一圈的路长也成比例变长，时间恰好不变。
- **第三步，比荷的角色**：$r$ 与 $T$ 都反比于 $q/m$（比荷）。比荷大的粒子半径小、周期短——这正是质谱仪分离不同离子、回旋加速器按比荷区分粒子的依据。
- **第四步，方向判断**：$q$ 的正负决定洛伦兹力方向（偏转方向相反）——正电荷与负电荷在同样磁场中转向相反，这是区分正负粒子的实验方法。

## 6 洛伦兹力的应用

洛伦兹力是现代粒子操控技术的基石：

- **质谱仪**：带电粒子经电场加速、磁场偏转，由轨道半径测比荷——分离与鉴定同位素、分子。
- **回旋加速器**：电场加速 + 磁场回旋，把带电粒子加速到高能——高能物理实验的「前级加速器」。
- **显像管/电子显微镜**：磁场偏转电子束，控制扫描。
- **速度选择器**：正交的电场与磁场，让「特定速度」的粒子直线通过——筛选粒子速度。
- **极光与范艾伦带**：太阳风粒子在磁场中螺旋运动。
- **磁约束核聚变**：托卡马克用强磁场把高温等离子体「困」在环形磁场里——洛伦兹力让带电粒子沿磁感线转圈，不撞器壁。<span class="marginnote">质谱仪的原理是「测轨道半径定比荷」：粒子经 $qU = \tfrac{1}{2}mv^2$ 加速后进入磁场，半径 $r = \dfrac{\sqrt{2mqU}}{qB}$——不同比荷的粒子半径不同，在探测器上分离。同位素（同元素不同质量）质量差一点点，半径就分开——化学家、医学家用它分析分子量。下一节会详细展开质谱仪与回旋加速器。</span>

## 7 辨析｜易错点

- **洛伦兹力对静止电荷为零**：磁场只对运动电荷施力（且速度不平行于磁场）。
- **洛伦兹力不做功**：$F \perp v$，只改变方向、不改变动能。
- **左手定则**：四指指正电荷速度方向（负电荷反向），磁感线穿手心。
- **半径 $r = mv/(qB)$、周期 $T = 2\pi m/(qB)$**：$T$ 与速度无关。
- **磁场加速粒子是误解**：加速靠电场，磁场只转弯。
- 负电荷偏转方向与正电荷相反。

## 8 小结

- **洛伦兹力**：$F = qvB\sin\theta$，磁场对运动电荷的力；静止电荷不受力。
- **方向**：左手定则，$F \perp v$ 且 $F \perp B$。
- **不做功**：只改变方向、不改变动能——磁场不加速粒子。
- **圆周运动**：$r = \dfrac{mv}{qB}$，$T = \dfrac{2\pi m}{qB}$（与速度无关）。
- **螺旋运动**：速度不垂直磁场时沿磁感线螺旋。
- **应用**：质谱仪、回旋加速器、显像管、极光、磁约束核聚变。

在下一节，我们把洛伦兹力的圆周运动用在做功上：**带电粒子在匀强磁场中的运动**。从半径周期公式到实际轨迹分析——偏转、回旋、螺旋，粒子的舞步全由 $q$、$m$、$v$、$B$ 决定。
