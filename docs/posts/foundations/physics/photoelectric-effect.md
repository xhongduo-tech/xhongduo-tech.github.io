## 为什么从光电效应开始

上一节普朗克假设「振子的能量量子化」，爱因斯坦在 1905 年更进一步：**光本身的能量就是一份一份的**，每一份叫一个**光子**，能量 $E = hf$。他用这个「光子说」解释了**光电效应**——光照射金属表面，金属中的电子被打出来。

光电效应是量子物理的「实锤」：经典物理（光波连续能量）完全无法解释它，而光子说完美解释。爱因斯坦因此获得 1921 年诺贝尔物理学奖（这是相对论都没拿到的奖项）。光电效应也是现代科技的基石——太阳能电池、光敏二极管、数码相机、光控开关，全依赖它。<span class="marginnote">「光电效应为什么是量子物理的实锤」：经典理论（光波）预言「光越强，电子动能越大」「只要光照足够久，任何频率的光都能打出电子」——全被实验否定。实验事实是「频率低于截止频率，再强的光也打不出电子；频率够，一个光子就打出一个电子」。爱因斯坦用「光子说」一举解释：电子吸收一个光子，能量 $hf$ 够（> 逸出功）就飞出，与光的强度无关。这个「一光子一电子」的图像，只有量子理论能给。</span>

学这一节，请抓住：**光电效应的实验规律、爱因斯坦光子说与光电效应方程、截止频率的意义**。

## 1 光电效应的实验现象

**光电效应（photoelectric effect）**：光照射金属表面，金属中的电子（光电子）从表面逸出的现象。

**光电效应的实验装置**：锌板（阴极）→ 紫外线照射 → 电子逸出 → 电流计检测。

**光电效应的四个实验规律**（经典理论无法解释的关键）：

1. **存在截止频率（极限频率）**：只有入射光的频率**大于某一截止频率** $\nu_c$ 时，才能发生光电效应。频率低于截止频率，无论光多强、照射多久，都不产生光电子。
2. **光电子最大初动能与频率线性相关**：光电子的最大初动能随入射光频率增大而增大，**与光强无关**。
3. **光强决定光电子数目**：入射光越强（单位时间光子数越多），单位时间逸出的光电子数越多（饱和电流越大），与频率无关。
4. **光电效应是瞬时的**：光照射到金属，电子**立即**逸出（约 $10^{-9}$ s），不需要能量积累时间。

**辨析｜易错点：** 四个规律里，最「反经典」的是**截止频率**与**瞬时性**：经典理论认为「光越强能量越多，总能打出电子」「光照久了能量积累够了就能打出」——实验否定了两者。**频率决定能否打出（截止频率）、强度决定打出多少（饱和电流）**——这是光电效应的核心图像。<span class="marginnote">「频率管能不能、强度管有多少」是光电效应的总纲：<strong>频率太低（< 截止频率），光子能量 $hf$ 不够，打不出电子（再多光子也没用）；频率够了，一个光子打出一个电子，光强（光子数）决定打出多少</strong>。这个「一光子一电子」的颗粒性，与经典「光波能量连续」针锋相对——是量子理论的直接证据。</span>

## 2 爱因斯坦的光子说

**光子说**：光在传播和与物质作用时，是一份一份的——每一份叫**光子**，每个光子的能量：

$$E = hf$$

其中 $h$ 是普朗克常量、$f$ 是光的频率。

**光子的能量由频率决定**：

- 频率高（如紫外线、X 射线）→ 光子能量大。
- 频率低（如红外线、无线电）→ 光子能量小。
- 光的强度 = 光子数 × 每个光子的能量——**强度管光子多少，频率管光子能量大小**。

**辨析｜易错点：** 「光强」与「光子能量」的区别：光强大 = 光子数多（每个光子能量不变），不是「光子能量大」。强红光（频率低）的光子能量仍小于弱紫外光（频率高）的光子能量。光子能量只由频率决定（$E = hf$），与光强无关。<span class="marginnote">「光强 vs 光子能量」的比喻：光子像「子弹」，频率决定「每颗子弹的威力」（$hf$），光强决定「子弹的数量」。威力不够（频率低），数量再多也打不穿（打不出电子）；威力够（频率高），一颗子弹打一个洞（一个光子打一个电子）。这个「威力 vs 数量」的分工，是光电效应图像的核心。</span>

## 3 光电效应方程

**光电效应方程**（爱因斯坦）：一个光子被金属中的一个电子吸收，光子能量 $hf$ 一部分用于克服电子的束缚（逸出功 $W_0$），剩余部分成为光电子的最大初动能：

$$hf = W_0 + \frac{1}{2}mv_m^2$$

其中：

- $hf$：光子能量。
- $W_0$：**逸出功**——电子脱离金属所需的最小能量（由金属材料决定）。
- $\tfrac{1}{2}mv_m^2$：光电子的**最大初动能**。

**由光电效应方程推出的结论**：

- **截止频率**：当光子能量刚好等于逸出功（$hf = W_0$，最大初动能为零）：

$$\nu_c = \frac{W_0}{h}$$

频率低于 $\nu_c$，$hf < W_0$，光子能量不足，打不出电子——截止频率由金属的逸出功决定。

- **最大初动能与频率线性**：$\tfrac{1}{2}mv_m^2 = hf - W_0$——频率越高，初动能越大（线性关系），斜率是 $h$。

**辨析｜易错点：** 逸出功 $W_0$ 是**金属材料**的属性（不同金属逸出功不同），截止频率 $\nu_c = W_0/h$ 也由材料决定。碱金属（钠、钾）逸出功小（易打出电子）、金/铂逸出功大（需高频光）。「截止频率是光学的属性」是错的——它是金属的属性。<span class="marginnote">「逸出功 = 电子离开金属的『赎金』」：金属中的电子被原子核吸引束缚，要逃离金属表面必须「付」出最小能量 $W_0$。光子给的 $hf$ 若够付赎金（$hf \ge W_0$），电子带着剩余动能飞出来；不够则电子飞不出来。不同金属「赎金」不同：钠逸出功约 2.3 eV（黄光就能打出）、锌约 4.3 eV（要紫外光）。这就是「为什么有些金属对可见光敏感、有些要紫外光」的原因。</span>

## 4 光电效应与经典物理的对比

| 比较项 | 经典理论（光波） | 量子理论（光子） |
| --- | --- | --- |
| 光的能量 | 连续分布 | 一份一份（$E = hf$） |
| 光强作用 | 光越强能量越大，总能打出 | 光强 = 光子数，管数量 |
| 频率作用 | 无截止频率（能量可积累） | 有截止频率（$hf$ 不够打不出） |
| 初动能 | 随光强增大 | 随频率增大（$hf - W_0$） |
| 时间性 | 需要能量积累时间 | 瞬时（一光子一电子） |

**结论**：光电效应只能用光子说解释，是光「粒子性」的直接证据——但光的干涉、衍射（选择性必修一）证明了光的「波动性」。**光具有波粒二象性**（下一节）。

**辨析｜易错点：** 光电效应证明光的**粒子性**，干涉衍射证明光的**波动性**——两者不矛盾，光「既是波又是粒子」（波粒二象性）。「光电效应说明光是粒子、所以波动说错了」是错误理解——光在传播时像波（干涉衍射）、与物质作用时像粒子（光电效应），两种性质并存。<span class="marginnote">「波粒二象性：看问题的方式决定看到的面相」：光的干涉衍射（波动性，传播时）与光电效应（粒子性，与物质作用时）都是实验事实——光在传播时表现为波、在与物质交换能量时表现为粒子。这不是「光一时是波一时是粒子」，而是「光本来就是波粒二象的」——经典概念（波或粒子）都不足以完整描述光。这个深刻的观念，是量子力学的哲学基础。</span>

## 5 公式解析：hf = W₀ + ½mv_m²

$$hf = W_0 + \frac{1}{2}mv_m^2$$

拆三步看：

- **第一步，能量守恒**：光子能量 = 逸出功 + 最大初动能。一个光子把全部能量 $hf$ 交给一个电子——能量守恒在微观事件中的体现。<span class="marginnote">「一光子一电子」的微观过程：金属中一个电子吸收一个光子，获得能量 $hf$；它要逃离金属必须先「付」逸出功 $W_0$（挣脱束缚），剩余 $hf - W_0$ 成为初动能。这个「一份换一个」的颗粒性，是光电效应与经典理论分道扬镳的根源——经典理论认为能量可以连续积累，光子说认为一次只能吃一个光子。</span>
- **第二步，截止频率的推导**：最大初动能为零时 $hf = W_0$，$\nu_c = W_0/h$。频率低于 $\nu_c$，$hf < W_0$，方程无正解（初动能为负不可能）——打不出电子。
- **第三步，图像**：以频率 $f$ 为横轴、最大初动能 $\tfrac12mv_m^2$ 为纵轴，图像是斜率为 $h$ 的直线（$y = hf - W_0$）——横截距是截止频率 $\nu_c$，纵截距是 $-W_0$。**用图像可以测出普朗克常量 $h$（斜率）与逸出功 $W_0$**。
- **第四步，量级感受**：锌的逸出功约 4.3 eV，截止频率 $\nu_c = W_0/h = 4.3\times1.6\times10^{-19}/6.63\times10^{-34} \approx 1.04\times10^{15}\ \text{Hz}$——对应波长约 290 nm（紫外区），所以可见光照锌板不产生光电效应，紫外光可以。

## 6 光电效应的应用

光电效应的应用遍布现代科技：

- **太阳能电池（光伏电池）**：光照射半导体，光子打出电子形成电流——光能 → 电能。
- **光敏电阻 / 光敏二极管**：光照改变导电性——光控开关、相机测光、报警器。
- **光电倍增管**：单个光子打出电子、倍增放大——微弱光检测（天文、医学成像）。
- **数码相机 / CCD**：光子转化为电荷，记录图像。
- **光电门**：遮光/透光引起电信号变化——测速（你在实验里用过）。

**辨析｜易错点：** 太阳能电池的原理是「光子打出（激发）电子」——与光电效应的机理一致（半导体中光子激发电子-空穴对）。它把光能直接变电能，效率受「光子能量与半导体带隙匹配」的限制——频率太低的红外光光子能量不足、激发不了电子，白白浪费。<span class="marginnote">「太阳能电池的效率为什么有上限」：光伏电池的半导体有「带隙」（类似逸出功），光子能量低于带隙激发不了电子（浪费）、高于带隙的超出部分变成热（也浪费）——所以单结太阳能电池的理论效率上限（肖克利-奎伊瑟极限）约 33%。「光子能量与带隙匹配」是光伏材料设计的核心——这个微观匹配，正是光电效应方程的工程化。</span>

## 7 辨析｜易错点

- **截止频率由金属决定**：$\nu_c = W_0/h$，逸出功是材料属性。
- **频率管能否、强度管多少**：频率决定打不打得出来，强度决定打出多少。
- **光子能量只由频率决定**：$E = hf$，与光强无关。
- **光电效应方程**：$hf = W_0 + \tfrac12mv_m^2$，能量守恒。
- **光电效应证明粒子性**：干涉衍射证明波动性——波粒二象性。
- **瞬时性**：电子立即逸出，无能量积累时间。

## 8 小结

- **光电效应**：光照射金属打出电子的现象。
- **四规律**：截止频率、初动能随频率、光强管数量、瞬时性。
- **光子说**：光是一份一份的，$E = hf$。
- **光电效应方程**：$hf = W_0 + \tfrac12mv_m^2$；截止频率 $\nu_c = W_0/h$。
- **逸出功**：金属的属性，决定截止频率。
- 光电效应证明光的粒子性——与波动性并存的波粒二象性。
