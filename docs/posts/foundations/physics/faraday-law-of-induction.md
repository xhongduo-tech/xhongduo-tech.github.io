# 法拉第电磁感应定律

## 为什么从法拉第电磁感应定律开始

上一节楞次定律告诉我们感应电流的**方向**，这一节法拉第定律告诉我们感应电动势的**大小**：**感应电动势与磁通量的变化率成正比**。这是电磁感应的定量核心，也是发电机、变压器、电磁感应加热等一切电磁感应应用的理论依据。

法拉第定律的形式简洁而深刻：$E = n\dfrac{\Delta\Phi}{\Delta t}$——关键是「变化率」（$\Delta\Phi/\Delta t$），不是「变化量」（$\Delta\Phi$）。磁通量变多少不重要，**变多快**才决定感应电动势。这与速度（位置变化率）、加速度（速度变化率）一脉相承——物理学的「率」概念在电磁感应里再次登场。<span class="marginnote">「变化率 vs 变化量」的区别是法拉第定律的精髓：<strong>磁通量很大但不变，感应电动势为零；磁通量很小但急剧变化，感应电动势很大</strong>。发电机线圈转到磁场最强处（$\Phi$ 最大）时感应电动势反而是零（此刻 $\Delta\Phi/\Delta t = 0$），转到磁场为零处（$\Phi = 0$）时电动势最大——这个「峰谷错位」正是交流电的相位图像，也是「变化率思维」的经典体现。</span>

学这一节，请抓住：**法拉第定律的公式、切割磁感线的电动势公式 $E = BLv$、两者的关系**。

## 1 法拉第电磁感应定律

**法拉第电磁感应定律**：闭合电路中感应电动势的大小，跟穿过这一电路的磁通量的变化率成正比。

$$E = n\frac{\Delta\Phi}{\Delta t}$$

其中 $n$ 是线圈匝数，$\Delta\Phi$ 是磁通量的变化量，$\Delta t$ 是变化所用时间，$E$ 是感应电动势（单位 V）。

**关键理解**：

- **$E$ 与变化率成正比**：磁通量变化越快（$\Delta\Phi/\Delta t$ 越大），感应电动势越大。
- **$n$ 匝线圈**：电动势与匝数成正比——线圈绕 $n$ 匝，每匝都有感应，串联相加。
- 若 $\Delta\Phi$ 相同但用时不同，用时短的变化率大、电动势大。<span class="marginnote">「磁通量变化率」就是「磁通量变化的快慢」——类似速度是位移的变化率。法拉第定律说「电动势 = 匝数 × 磁通量变化率」，把「变化率思维」从运动学搬到电磁感应。对比：位移变化快 → 速度大；磁通量变化快 → 电动势大。这个「率」字是全公式的灵魂。</span>

**辨析｜易错点：** 是 $\dfrac{\Delta\Phi}{\Delta t}$（变化率），不是 $\Delta\Phi$（变化量）。磁通量从 0 变到 $\Phi$ 用了 1 秒，与用 0.01 秒，变化量相同但变化率差 100 倍、电动势差 100 倍。把「变化量」当「变化率」代入是法拉第定律题的头号错误。

## 2 平均电动势与瞬时电动势

法拉第定律 $E = n\Delta\Phi/\Delta t$ 给出的是**平均电动势**（在一段时间内）。

**平均电动势**：$\bar E = n\dfrac{\Delta\Phi}{\Delta t}$——一段时间内磁通量变化的平均快慢。
**瞬时电动势**：$\Delta t \to 0$ 时变化率的极限——某一瞬间磁通量变化的快慢。

与平均速度/瞬时速度的关系完全平行。实际问题中，若磁通量随时间均匀变化（$\Phi$-$t$ 图像是直线），平均 = 瞬时；若变化不均匀，用图像斜率（切线）求瞬时电动势。<span class="marginnote">「平均与瞬时」的区分与《速度》一节完全同构：$\bar v = \Delta x/\Delta t$ 是平均速度、$v = dx/dt$ 是瞬时速度；这里 $\bar E = n\Delta\Phi/\Delta t$ 是平均电动势、$E = n\,d\Phi/dt$ 是瞬时电动势。$\Phi$-$t$ 图像的斜率 = 电动势——图像法又一次成为理解「率」的工具。</span>

## 3 导线切割磁感线：E = BLv

法拉第定律的一个重要特例是**导体切割磁感线**。一段长为 $L$ 的直导线，在匀强磁场 $B$ 中以速度 $v$ 垂直切割磁感线（$v \perp B$、$v \perp L$），产生的感应电动势：

$$E = BLv$$

**推导**：导线以 $v$ 运动 $\Delta t$ 内扫过的面积 $\Delta S = Lv\Delta t$，磁通量变化 $\Delta\Phi = B\Delta S = BLv\Delta t$，法拉第定律 $E = \dfrac{\Delta\Phi}{\Delta t} = BLv$。

**关键**：$v$ 是「垂直切割磁感线」的速度分量。若 $v$ 与 $B$ 夹角为 $\theta$，$E = BLv\sin\theta$（取垂直分量）。

**辨析｜易错点：** $E = BLv$ 的条件是「$B$、$L$、$v$ 三者两两垂直」。不垂直时取 $\sin\theta$ 分量。另一个常见陷阱：$E = BLv$ 是「一段导线切割」的电动势；而法拉第定律 $E = n\Delta\Phi/\Delta t$ 是「回路磁通量变化」的电动势——两者本质一致，只是应用场景不同。<span class="marginnote">$E = BLv$ 与 $E = \Delta\Phi/\Delta t$ 是同一规律的两副面孔：<strong>回路磁通量变化（面积变/磁场变/转动）用 $E = n\Delta\Phi/\Delta t$；直导线切割磁感线用 $E = BLv$</strong>。切割公式由法拉第定律推导而来（扫过的面积 → 磁通量变化），所以结果必然一致。做题时先看「是回路变化还是单棒切割」，再选公式。</span>

## 4 电动势与电流、能量的关系

有了感应电动势，闭合回路中就有感应电流：

$$I = \frac{E}{R + r}$$

（$R$ 外电路电阻、$r$ 内阻。）感应电流在磁场中受安培力，安培力阻碍运动（楞次定律）——外力克服安培力做功，转化为电能：

$$P_{\text{外}} = P_{\text{电}} = \frac{E^2}{R + r} = \frac{(BLv)^2}{R}$$

**能量链**：外力做功（机械能）→ 克服安培力 → 转化为电能 → 电流生热（$I^2R$）。能量守恒在电磁感应里严格成立。<span class="marginnote">电磁感应的能量链是「机械能 → 电能 → 内能」的完整转化：外力拉导线切割磁感线，克服安培力做功，这部分功全部转化为电能，再通过电阻发热。发电机里「吃力」的转动、电磁阻尼里「难拉」的导体，都是这条能量链的表现。「楞次定律的阻碍」与「能量守恒」在这里定量重合：安培力做的负功恰等于产生的电能。</span>

## 5 公式解析：E = nΔΦ/Δt 与 E = BLv

$$E = n\frac{\Delta\Phi}{\Delta t}, \qquad E = BLv$$

拆三步看：

- **第一步，法拉第定律的量纲**：$\Phi$ 单位 Wb = T·m²，$\Delta\Phi/\Delta t$ 单位 Wb/s = V（1 Wb/s = 1 V）——电动势单位正确。量纲自洽。
- **第二步，$E = BLv$ 的推导还原**：导线扫过面积 $\Delta S = Lv\Delta t$ → 磁通量变化 $\Delta\Phi = B\Delta S = BLv\Delta t$ → $E = \Delta\Phi/\Delta t = BLv$。**「切割」=「磁通量变化」的几何翻译**：切得越快、扫得越多，电动势越大。<span class="marginnote">$E = BLv$ 的三个量「两两垂直」是条件，也是记忆锚点：磁场 $B$、导线长度 $L$、切割速度 $v$ 互相垂直时公式最简。不垂直时各取垂直分量——这是「$\sin\theta$ 取垂直」模式在电磁感应里的又一次应用（与安培力 $BIL\sin\theta$、洛伦兹力 $qvB\sin\theta$ 同构）。</span>
**第三步，平均与瞬时**：$\Delta\Phi/\Delta t$ 给平均电动势；瞬时电动势用 $\Phi$-$t$ 图像斜率。匀速切割（$v$ 恒定）时平均 = 瞬时。
**第四步，与楞次定律配合**：法拉第定律给大小、楞次定律给方向——「大小用变化率、方向用阻碍」，两者合起来才是一个完整的感应电动势。

**数值算例**：一个 100 匝线圈，磁通量在 0.2 s 内从 $2\times10^{-3}\ \text{Wb}$ 均匀减小到 0。磁通量变化 $\Delta\Phi = 0 - 2\times10^{-3} = -2\times10^{-3}\ \text{Wb}$，平均电动势 $\bar E = n|\Delta\Phi|/\Delta t = 100\times2\times10^{-3}/0.2 = 1\ \text{V}$。若同样的变化在 0.02 s 内完成，$\bar E = 100\times2\times10^{-3}/0.02 = 10\ \text{V}$——用时缩短 10 倍，电动势增大 10 倍。「变多快，生多强」，法拉第定律的定量验证。

## 6 法拉第定律的应用

法拉第定律是一切电磁感应技术的核心：

**发电机**：线圈转动，磁通量周期性变化，产生交变电动势——$E$ 随 $\Delta\Phi/\Delta t$ 周期性变化（下一章交变电流）。
**变压器**：原线圈通交变电流，铁芯磁通量变化，副线圈感应电动势 $E_2 = n_2\Delta\Phi/\Delta t$——按匝数比变压。
**电磁感应加热**：交变磁场在导体中感应涡流、生热（电磁炉、感应加热）。
**电磁阻尼与驱动**：感应电流受安培力阻碍运动（阻尼）或带动运动（驱动）——下一节。
**动圈式话筒/扬声器、读卡器、磁悬浮**。<span class="marginnote">发电机的电动势来源：线圈在磁场中转动，穿过线圈的磁通量 $\Phi = BS\cos\theta$ 随角度正弦变化，$\Delta\Phi/\Delta t$ 也正弦变化——所以发电机输出正弦交流电。变压器的原理：原线圈的电流变化 → 铁芯磁通量变化 → 副线圈感应出电动势——「变化的磁通量是电与电之间的桥梁」。法拉第定律把机械转动、电流变化都翻译成「磁通量变化」，从而生电——这就是电磁感应的万能身段。</span>

## 7 辨析｜易错点

- **用变化率不是变化量**：$E = n\Delta\Phi/\Delta t$，$\Delta\Phi$ 相同但用时不同，电动势不同。
- **$E = BLv$ 要两两垂直**：不垂直取 $\sin\theta$ 分量。
- **平均 vs 瞬时**：$\Delta\Phi/\Delta t$ 是平均，瞬时用 $\Phi$-$t$ 图斜率。
- **与楞次定律配合**：大小用法拉第定律、方向用楞次定律。
- **$E = BLv$ 与 $E = n\Delta\Phi/\Delta t$ 同源**：切割是磁通量变化的特例。
- **能量链**：外力做功 → 电能 → 内能，能量守恒。

## 8 小结

- **法拉第电磁感应定律**：$E = n\dfrac{\Delta\Phi}{\Delta t}$，感应电动势与磁通量变化率成正比。
- **切割公式**：$E = BLv$（$B$、$L$、$v$ 两两垂直），由法拉第定律推导。
- 平均电动势用 $\Delta\Phi/\Delta t$，瞬时电动势用 $\Phi$-$t$ 图像斜率。
- 感应电流 $I = E/(R+r)$；安培力阻碍运动、外力做功转化为电能。
- **应用**：发电机、变压器、电磁感应加热、电磁阻尼。
- 大小用法拉第定律、方向用楞次定律——电磁感应的完整图像。
- **磁通量大 ≠ 电动势大**：看变化率不看变化量——发电机峰谷错位正在于此。
- **能量链完整**：外力做功 → 克服安培力 → 电能 → 内能，能量守恒定量成立。
- **匝数的倍增**：$E = n\Delta\Phi/\Delta t$——线圈多绕一匝，电动势多一份，串联相加。
- **应用即「磁通量变化」**：发电机转动、变压器交变、感应加热涡流——同一原理不同舞台。

- **法拉第定律**：$E = n\dfrac{\Delta\Phi}{\Delta t}$——感应电动势与磁通量变化率成正比。
- **切割公式**：$E = BLv$——$B$、$L$、$v$ 两两垂直时最简。

在下一节，我们研究涡电流及其工程应用：**涡流、电磁阻尼和电磁驱动**。变化的磁场在大块导体中感应出旋涡状的电流——它既能让导体发热（电磁炉），也能让导体被制动或被带动。
