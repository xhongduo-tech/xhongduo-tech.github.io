## 为什么从闭合电路的欧姆定律开始

前面我们一直把电源当作「理想电压源」——输出电压恒定不变。但现实不是这样：电池用久了电压会「掉」，接上大功率用电器时灯光会变暗。原因是**电源本身有内阻**。把内阻纳入电路模型，就有了闭合电路的欧姆定律，它是「真实电源」的完整描述，也是理解「为什么电源电压会随负载变化」的关键。

这一节是电路理论的枢纽：**电动势、内阻、外电路电阻、电流、路端电压**五者的关系 $I = E/(R + r)$ 一出来，前几节的所有知识——欧姆定律、能量转化、串并联——全部串成一条线。而下一节的实验「电池电动势和内阻的测量」正是在此基础上设计的。<span class="marginnote">「理想电源」与「真实电源」的差别是物理建模的经典案例：理想模型（电压恒定的理想源）在分析简单问题时够用，但遇到「负载变化影响电压」就必须引入内阻。物理学里到处都是这种「先理想化、再按需加复杂项」的做法——就像力学里先光滑、再考虑摩擦。</span>

学这一节，请记住一条主线：**电动势 $E$ 是电源的「额定能力」，路端电压 $U$ 是「实际给到外电路的电压」，两者之差 $Ir$ 是「被内阻吃掉的部分」**。电流越大，内阻上掉的电压越多，路端电压越低。

## 1 内阻与闭合电路的构成

真实电源可以看成「理想电源（电动势 $E$）与一个电阻 $r$（内阻）的串联」。闭合电路由两部分组成：

- **内电路**：电源内部的电路（穿过电源本身），电阻为内阻 $r$。
- **外电路**：电源外部的电路（导线、用电器），电阻为外电阻 $R$。

电流 $I$ 同时流过内电路与外电路（串联关系），于是**总电阻 = 外电阻 + 内电阻 = $R + r$**。由欧姆定律，电流

$$I = \frac{E}{R + r}$$

这就是**闭合电路的欧姆定律**：闭合电路中的电流，跟电源的电动势成正比，跟内外电路电阻之和成反比。<span class="marginnote">为什么电源内部也有电阻？因为电源本身也是导体——电池里的电解液、极板都有电阻，发电机绕组也有电阻。电流流过这些材料同样发热（$I^2rt$），这就是「电池发烫」的原因。把内阻画成一个单独的电阻 $r$ 串联在理想电源上，是描述真实电源的标准做法。</span>

**辨析｜易错点：** 电动势 $E$ 与路端电压 $U$ 的区别在闭合电路里彻底显形：$E$ 是「空载能力」（开路时等于路端电压），$U$ 是「带载实际值」（接负载后小于 $E$）。把「电池电压 1.5 V」当成「任何时候都是 1.5 V」是错的——那是电动势，路端电压随负载变。

## 2 路端电压与外电阻的关系

闭合电路欧姆定律可改写为路端电压的表达式：

$$U = IR = E - Ir$$

**路端电压 $U$ = 电动势 $E$ − 内阻压降 $Ir$**。由此得到一组重要规律：

- **外电阻 $R$ 增大** → 电流 $I$ 减小 → 内阻压降 $Ir$ 减小 → 路端电压 $U$ **增大**（趋近 $E$）。
- **外电阻 $R$ 减小** → 电流增大 → 内阻压降增大 → 路端电压 $U$ **减小**。
- **开路**（$R \to \infty$）：$I = 0$，$U = E$——开路电压等于电动势。
- **短路**（$R = 0$）：$I = E/r$ 巨大，$U = 0$——短路电流只由电动势与内阻决定，可致电源损坏。<span class="marginnote">「灯泡变暗」现象的物理解释：家里大功率电器启动瞬间，电流猛增，内阻（线路电阻 + 电源内阻）压降增大，路端电压瞬时下降，其他灯泡因电压降低而变暗。电网的「电压跌落」也是同一原理——负载越重、电压越低。理解 $U = E - Ir$，就理解了电网调度的基本矛盾。</span>

**U-I 图像**：路端电压 $U$ 随电流 $I$ 变化的图像是一条直线：

$$U = E - Ir$$

纵截距是电动势 $E$（$I = 0$ 时），斜率的绝对值是内阻 $r$，横截距是短路电流 $I_{\text{短}} = E/r$。**这张 U-I 图是测量电动势与内阻的核心工具**（下一节实验就是测它）。

## 3 闭合电路中的功率分配

闭合电路中，能量守恒要求：电源提供的总功率 = 外电路功率 + 内阻功率。

- **总功率**：$P_{\text{总}} = EI$（电源非静电力做功的功率）。
- **外电路功率**：$P_{\text{外}} = UI = I^2R$（用电器得到的功率）。
- **内阻功率**：$P_{\text{内}} = I^2r$（内阻发热）。

由 $E = U + Ir$，两边乘 $I$：$EI = UI + I^2r$——**功率分配账自动平**。这再次印证：能量守恒是电路分析的隐形锚。<span class="marginnote">一个有趣的结论：当外电阻 $R = r$ 时，外电路功率 $P_{\text{外}}$ 取得最大值 $P_{\max} = E^2/(4r)$——这叫「最大功率传输定理」。此时效率恰好 50%（一半能量耗在内阻上）。音响系统、射频发射都想让负载匹配内阻以获得最大功率，但输电线路恰恰相反（要效率高，希望 $R$ 远大于 $r$）。「最大功率」与「最大效率」不是一回事，这个区别是工程师的基本功课。</span>

**效率**：电路效率 $\eta = P_{\text{外}}/P_{\text{总}} = U/E = R/(R + r)$。$R$ 越大，效率越高（趋近 100%）；$R$ 越小（短路趋势），效率越低。**要效率，让外电阻远大于内阻**。

## 4 含内阻的串并联综合问题

把闭合电路欧姆定律用于串并联电路，是考试的重头戏。核心流程：

1. **求总电流**：先算外电路等效电阻 $R$，用 $I = E/(R + r)$ 求总电流。
2. **回溯**：由总电流反推各支路电压、电流（串分压、并分流）。
3. **内阻参与**：电源两端的路端电压 $U = E - Ir$，就是外电路两端的总电压。

举例：电动势 $E = 6\ \text{V}$、内阻 $r = 1\ \Omega$ 的电源，接一个 $R = 5\ \Omega$ 的电阻。总电流 $I = 6/(5+1) = 1\ \text{A}$；路端电压 $U = E - Ir = 6 - 1\times1 = 5\ \text{V}$；外电路功率 $P_{\text{外}} = I^2R = 5\ \text{W}$；内阻功率 $P_{\text{内}} = I^2r = 1\ \text{W}$；效率 $\eta = 5/6 \approx 83\%$。<span class="marginnote">解题时最容易漏的步骤是「内阻不能扔」：算外电路功率用 $I^2R$、算路端电压用 $U = E - Ir$，内阻始终在账里。一句话：<strong>内阻是电源的「影子电阻」，永远与电源绑定</strong>。看清题目问的是「路端电压」还是「电动势」，就不会把 $E$ 直接当 $U$ 用。</span>

**动态电路问题**（滑动变阻器调节）：外电阻变化 → 总电流变 → 路端电压变 → 各支路分配变。分析顺序固定：**先判断外电阻怎么变，再推总电流，再推路端电压，最后回溯支路**。这个「由总到分」的链条，是动态电路题的万能流程。

## 5 公式解析：I = E/(R + r)

$$I = \frac{E}{R + r}, \qquad U = E - Ir$$

拆三步看：

- **第一步，为什么是 $R + r$**：内电路与外电路串联，串联总电阻相加。电流是「同一股」，从电源正极出发穿过外电路、又穿回电源内部，全程的电阻都算数——外电阻 + 内阻。<span class="marginnote">闭合回路的「串联观」是关键：整个回路只有一条电流路径，所有电阻（外部的、内部的）串在一起。所以总电阻 = $R + r$，电动势「推动」的是整条回路的电阻。一旦你接受「回路是一个大串联电路」，闭合电路欧姆定律就是欧姆定律本身。</span>
- **第二步，两个极限**：$R \to \infty$（开路）时 $I \to 0$，$U = E$——开路电压等于电动势；$R = 0$（短路）时 $I = E/r$，可能非常大。短路电流只由 $E$ 与 $r$ 决定，这就是「电池短路瞬间发烫烧毁」的原因。
- **第三步，路端电压的图像**：$U = E - Ir$ 是直线（$I$ 为横轴）：截距 $E$、斜率 $-r$。实验里测多组 $(I, U)$ 作图，直线的纵截距读出 $E$、斜率读出 $r$——这就是下一节实验的原理。
- **第四步，内阻不可忽略的场合**：$r$ 很小（新电池，$r$ 约零点几欧）时，$Ir$ 小，$U \approx E$，可近似为理想电源；$r$ 不可忽略（旧电池、内阻大的化学电池）时，$U$ 明显小于 $E$。**什么时候用 $E$、什么时候用 $U$，看题目问的是电源能力还是实际输出**。

## 6 辨析｜易错点

- **电动势 ≠ 路端电压**：$E$ 是电源能力（恒定），$U = E - Ir$ 是实际输出（随负载变）。开路时 $U = E$，接负载后 $U < E$。
- **内阻始终参与**：求电流用 $E/(R+r)$，算路端电压用 $E - Ir$，内阻不能丢。
- **短路电流巨大**：$I = E/r$，可能烧毁电源与导线。「短路相当于电阻为零」就能想到电流会多大。
- **$U$-$I$ 图读参**：纵截距是 $E$、斜率绝对值是 $r$、横截距是 $E/r$。读图时坐标轴别搞反。
- **最大功率 vs 最大效率**：$R = r$ 时外电路功率最大（效率 50%）；$R \gg r$ 时效率趋近 100% 但功率很小。两者不同时取到。
- **内阻压降 $Ir$ 的方向**：内电路中电流从负极到正极（逆着电动势方向），内阻上电压降方向与路端电压相反，所以 $U = E - Ir$。画图时内阻两端要标对极性。

## 7 小结

- **闭合电路欧姆定律**：$I = \dfrac{E}{R + r}$，内电路 + 外电路串联。
- **路端电压**：$U = IR = E - Ir$——外电阻增大，路端电压增大；开路 $U = E$，短路 $I = E/r$。
- **U-I 图像**：直线 $U = E - Ir$，截距 $E$、斜率 $-r$。
- **功率分配**：$EI = UI + I^2r$；$R = r$ 时外功率最大，$R \gg r$ 时效率最高。
- 内阻是电源的「影子」，永远参与计算；电动势与路端电压务必分清。
- 动态电路分析流程：外电阻 → 总电流 → 路端电压 → 各支路。

在下一节，我们动手测量真实电源的两个关键参数：**实验：电池电动势和内阻的测量**。用伏安法多组数据，画出 U-I 图，从截距与斜率读出 $E$ 与 $r$——闭合电路欧姆定律从纸面走向实测。
