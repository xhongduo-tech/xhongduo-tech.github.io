# 电场 电场强度

<div class="epigraph">
<p>电荷并不是直接与电荷相互作用，而是通过空间中的场来作用的。</p>

## 为什么从电场和电场强度开始

上一节我们学了库仑定律——两个点电荷之间的力。但有一个悬而未决的深刻问题：**一个电荷对远处的另一个电荷施力，这个力是怎么传过去的？** 是瞬间超距作用，还是通过某种中介？法拉第的回答是：通过**场**。

**电场（electric field）**是电荷周围空间存在的一种特殊物质，它对放入其中的电荷施加力的作用。电荷 A 不直接「够到」电荷 B，而是 A 在周围空间激发电场，B 感受到的其实是「A 的电场对 B 的力」。这个观念转变看似绕了弯子，却是整个电磁学乃至现代物理的基石——引力也有引力场，电磁波是变化的电磁场，大模型训练里的 GPU 显存、芯片里的电流，全都活在电磁场的语言里。<span class="marginnote">「场」的思想对物理学的重塑远超电学本身：牛顿的引力是「超距作用」——力瞬时跨越空间；法拉第和麦克斯韦把力理解为「场」的传递，而场的变化以有限速度（光速）传播。到选择性必修第二册《电磁振荡与电磁波》，你会看到变化的电场磁场互相激发、以光速传播——那就是「场」思想的巅峰成果。</span>

学这一节，你要完成一次「从力到场」的抽象升级：不再问「力多大」，而是问「空间每一点的电场强弱与方向」。为了描述这种「处处有值」的物理量，我们引入**电场强度**，并用**电场线**画出它的形象。这三件事将支撑起整个静电学。

## 1 电场：一种看不见的物质

电荷周围存在的、对放入其中的电荷产生力作用的特殊物质，叫**电场**。电场的基本性质是**对场中的电荷有力的作用**。

几个关键认识：

电场是**客观存在的物质**，虽然看不见摸不着，但它具有能量、能传递作用——电磁波就是电场磁场的传播，携带着能量跨越星际。
**电场是电荷激发的**：静止电荷激发静电场；电荷是电场的「源」。
电场对放入的**试探电荷**施力——这个力的大小与方向，就是「探测」电场的方式。<span class="marginnote">「试探电荷」是电场理论的重要工具：一个电荷量足够小、不影响原电场分布的点电荷，专用来「探测」电场。就像把一支温度计放进水里测温——温度计必须足够小、吸热足够少，才不干扰被测系统。试探电荷的引入，让「测量场」这件事有了无歧义的操作定义。</span>

为什么要引入「场」而不直接用库仑定律？因为库仑定律只能算两个点电荷，而实际中电荷是分布的、还会运动。**场把「源与受力」解耦**：先由源电荷算出空间中每一点的场，再让受力电荷「读取」它所在位置的场。这就像查表——源电荷负责「写表」，受力电荷只「查自己的位置」。当电荷运动、源在变化时，「场」的传播需要时间（光速），这种「延迟」是电磁波存在的前提。

## 2 电场强度：场的定量描述

要定量描述电场，用一个试探电荷 $q$ 放到场中某点，它受的静电力为 $F$。实验发现：$F$ 与 $q$ 成正比，比值 $F/q$ 是一个**与试探电荷无关、只由电场本身决定的量**。这个比值就是**电场强度**：

$$E = \frac{F}{q}$$

- **物理意义**：电场中某点的电场强度，等于单位正电荷在该点所受的电场力。它描述**电场的强弱与方向**。
- **矢量**：方向与正电荷在该点所受电场力方向一致。
- **单位**：牛每库（$\text{N}/\text{C}$），也可以写成伏每米（$\text{V}/\text{m}$，下一节会看到两者等价）。

**电场强度由电场本身决定，与试探电荷无关**——这是本节最重要的结论。放 $+q$ 与放 $+2q$ 进去，力分别是 $F$ 与 $2F$，但 $F/q$ 都是同一个 $E$。<span class="marginnote">强调「$E$ 与试探电荷无关」是为了防止一个常见误解：改放一个电荷，电场强度会不会变？不会——$E$ 是源电荷决定的场的属性，试探电荷只是「测量工具」。就像海拔高度是地形的属性，你带不同重量的秤上山，海拔不变。这个「场是客观的、测量不影响场」的立场，是场论的基础。</span>

由点电荷激发、在距离 $r$ 处的电场强度，把库仑定律代入定义式：

$$E = \frac{F}{q} = \frac{kQq/r^2}{q} = k\frac{Q}{r^2}$$

其中 $Q$ 是**源电荷**的电荷量。注意这里 $Q$ 只出现一次——**点电荷的场强与试探电荷无关，只取决于源电荷 $Q$ 和距离 $r$**。$Q > 0$ 时场强方向沿径向向外，$Q < 0$ 时沿径向向内。

## 3 电场强度的叠加

与静电力一样，电场强度也满足**叠加原理**：某点的电场强度等于各个点电荷单独在该点产生的电场强度的**矢量合成**。

$$E = E_1 + E_2 + \cdots + E_n$$

每个 $E_i$ 用 $E_i = kQ_i/r_i^2$ 单独计算，方向沿「源电荷指向该点」或「该点指向源电荷」的径向，然后矢量合成。<span class="marginnote">叠加原理是电场强度最强有力的工具：任意复杂的电荷分布，都可以拆成点电荷的叠加。到第二级《电磁学》，你会学到用积分把连续分布电荷的电场算出来——叠加原理就是那个积分的雏形。对称性（如带电球壳）能让积分瞬间化简，这是大学电磁学的经典技巧。</span>

举一例：两个等量同号点电荷 $+Q$、$+Q$ 相距 $2a$，求连线中点 O 的场强。两个电荷在 O 点产生的场强大小相等（都是 $kQ/a^2$）、方向相反（都指向外侧），合成后**为零**。若两电荷等量异号（$+Q$、$-Q$），中点场强方向从正电荷指向负电荷，大小 $2kQ/a^2$。<span class="marginnote">「等量同号电荷连线中点场强为零，等量异号电荷连线中点场强不为零」是高中电场的经典考点。前者叫<strong>同号相消</strong>，后者是<strong>电偶极子</strong>的电场——电偶极子是最简单的电荷系统，在化学（极性分子）、天文学（分子云谱线）中处处可见。</span>

## 4 电场线：电场的形象

电场强度是矢量场，用数学函数描述很抽象。法拉第发明了**电场线**——一组假想的曲线，用几何形象「画」出电场：

**电场线的性质**：

电场线上每点的**切线方向**，就是该点电场强度的方向。
**疏密**表示场强大小：电场线密集处场强大，稀疏处场强小。
电场线**从正电荷出发，终止于负电荷**（或延伸到无穷远），不闭合、不中断。
电场线**不相交**：若相交，交点处就有两个切线方向，场强方向不唯一。

常见电场的电场线形状：单个正电荷的电场线从它向外辐射（像刺猬）；单个负电荷的电场线指向它；两个等量同号电荷的电场线从各自发出、互相排斥；等量异号电荷的电场线从正电荷出发弯向负电荷，形成「哑铃」形。<span class="marginnote">电场线是法拉第留下的最直观的物理直觉工具，但它只是「作图」，不是真实存在的线——场是处处连续的，线只是帮助人脑把握方向与强弱。麦克斯韦把法拉第的「力线」数学化，写成了著名的麦克斯韦方程组，这是科学史上「图像直觉」转化为「严格数学」的典范。</span>

**辨析｜易错点：** 电场线不是电荷运动的轨迹！电荷沿电场线运动的**前提**是：电场线是直线、电荷初速度为零或沿切线方向。在弯曲的电场线中，电荷受的电场力沿切线方向，但速度方向未必沿切线，运动轨迹是弯的，不会贴合电场线。把「电场线」当成「电荷轨迹」，是最常见的误区之一。匀强电场中电场线是等距平行直线，电荷沿直线电场线加速，轨迹才与电场线重合。

## 5 匀强电场

**匀强电场（uniform electric field）**：电场中各点的电场强度大小相等、方向相同的电场。其电场线是**间隔相等、方向相同的平行直线**。

匀强电场怎么产生？两块靠得很近、带等量异号电荷的平行金属板之间，中间区域的电场近似匀强（边缘区域有「边缘效应」除外）。<span class="marginnote">平行板电容器内部近似匀强电场，是第十章《电容器的电容》的核心装置。正因内部场强恒定，带电粒子在里面做匀变速运动（类平抛），计算极其规整——下一节《带电粒子在电场中的运动》就是在这片匀强电场里展开的。</span>

匀强电场中，电荷 $q$ 受的力 $F = qE$ 恒定，方向不变——带电粒子在其中做**匀变速运动**。若初速度垂直场强方向，就是「类平抛运动」：沿电场方向匀加速，垂直方向匀速。这个模型是电学与力学结合的经典，也是示波器、质谱仪、显像管等仪器的物理基础。

## 6 公式解析：E = kQ/r² 与 E = F/q

$$E = \frac{F}{q} = k\frac{Q}{r^2}$$

拆三步看：

- **第一步，两条定义式的分工**：$E = F/q$ 是电场强度的**定义式**（对任何电场都成立），$E = kQ/r^2$ 是**点电荷电场的决定式**（只对点电荷成立）。定义式说明「场强怎么测」，决定式说明「点电荷的场强由什么决定」。区别「普适定义式」与「特定决定式」，是理解电场强度的关键——就像速度 $v = \Delta x/\Delta t$ 是定义，自由落体 $v = gt$ 是特定运动的规律，两者适用范围不同。<span class="marginnote">类似地，电阻 $R = U/I$ 是定义式（任何导体成立），$R = \rho L/S$ 是决定式（材料决定）。这种「定义式 vs 决定式」的二元结构在物理里反复出现，见第十一章《导体的电阻》。掌握它，物理概念就立住了。</span>
- **第二步，为什么试探电荷被约掉**：把 $F = kQq/r^2$ 代入 $E = F/q$，$q$ 在分子分母同时出现，约去。这从代数上证明了「场强与试探电荷无关」——$q$ 只是测量工具，测量结果 $E$ 里没有 $q$ 的影子。
- **第三步，方向约定**：$E$ 的方向定义为**正电荷**所受力的方向。为什么定成正电荷？因为这是约定俗成（电荷的正负号是富兰克林定的），一旦约定，负电荷受力方向与场强方向相反——$F = qE$ 中 $q < 0$ 自动给出反向。**记住「正电荷受力方向即场强方向」，负电荷则相反**。
- **第四步，叠加的使用**：空间中多个点电荷时，先对每个 $Q_i$ 算 $E_i = kQ_i/r_i^2$ 并画方向，再矢量合成。两点电荷中点场强为零的题，就是叠加原理的直接应用。

## 7 辨析｜易错点

- **$E = F/q$ 与 $E = kQ/r^2$ 不能混用**：前者任何电场都成立（定义式），后者只对点电荷成立（决定式）。匀强电场里没有「源点电荷」，只能用 $E = F/q$ 或 $E = U/d$（下一章）。
- **场强是矢量，合成必须用矢量法**：两电荷在中点产生的场强大小相等但方向可能不同，不能直接代数相加。先画方向，再合成。
- **电场线的疏密反映强弱，切向反映方向**：从图中判断场强大小看疏密，判断方向看切线。疏密与方向是两个独立的读图要素。
- **电场线不相交、不闭合**：从正电荷出发、终止于负电荷或无穷远。「电场线是闭合曲线」是常见错误（那是磁场线的性质，见第十三章《磁场 磁感线》）。
- **场强与试探电荷无关，但受力与试探电荷有关**：$F = qE$，$q$ 越大力越大；但 $E$ 不变。区分「场的属性」与「放入物体的受力」。
- **匀强电场的边缘效应**：平行板内部近似匀强，边缘处电场线弯曲、场强不再均匀。严格说匀强只存在于中间区域。

## 8 小结

- **电场**：电荷周围激发的一种特殊物质，对放入其中的电荷施力。
- **电场强度**：$E = F/q$，单位 $\text{N}/\text{C}$，矢量，方向即正电荷受力方向；由电场本身决定，与试探电荷无关。
- **点电荷场强**：$E = kQ/r^2$，方向沿径向（$Q>0$ 向外、$Q<0$ 向内）。
- **叠加原理**：某点场强等于各电荷单独产生的场强的矢量合成。
- **电场线**：切线表方向、疏密表强弱，从正电荷出发终止于负电荷，不相交。
- **匀强电场**：大小方向处处相同，电场线是等距平行直线；其中带电粒子做匀变速运动。

在下一节，我们研究电场在生活中的工程应用：**静电的防止与利用**。静电既有害（火花放电、干扰电子设备）也有益（静电除尘、静电喷涂），理解电场线如何被「屏蔽」「聚焦」，是「电场」概念落地的第一站。
