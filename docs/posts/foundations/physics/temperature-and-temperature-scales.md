## 为什么从温度和温标开始

「温度」是日常生活最熟悉、也最「说不清」的物理量：它不冷就热，但「热」到底是什么？分子动理论给了答案——**温度是分子平均动能的标志**。而要让温度可测、可比，还需要一套**温标**：规定「多少度是什么」的标尺。

这一节把温度从「感觉」变成「科学量」：认识**热平衡与温度的本质**（温度是热平衡的标志）、**摄氏温标与热力学温标**（两种标尺的换算）、以及**温度计**的工作原理。温度是热学的「第一量」，温标是热学测量的基础——没有它，气体定律、热力学定律都无从谈起。<span class="marginnote">「热平衡定律（热力学第零定律）」是温度概念的基石：<strong>如果 A 与 B 热平衡、B 与 C 热平衡，则 A 与 C 也热平衡</strong>。它保证了「温度」可以定义——一个量（温度）能同时描述 A、B、C 的冷热状态，相等则热平衡。温度计测温度的依据就是热平衡：温度计与被测物达到热平衡，读数就是被测物的温度。「第零定律」之所以叫第零，是因为它比第一、第二定律更基本、却最后被正式命名。</span>

学这一节，请抓住：**温度的本质（热平衡）、热力学温标与摄氏温标的关系**。

## 1 状态参量与平衡态

描述热学系统的状态，需要一组**状态参量**：

- **温度 $T$**：描述冷热程度。
- **体积 $V$**：描述几何大小。
- **压强 $p$**：描述力的作用。
- **物质的量 $n$**：描述粒子多少。

**平衡态**：在没有外界影响的情况下，系统的状态参量不随时间变化的状态。热学讨论的对象，通常假设处于平衡态（温度、压强、体积各处均匀）。

**辨析｜易错点：** 平衡态是「宏观状态参量不变」——微观分子仍在无规则运动（温度是平均动能，分子个体在变）。「平衡态 = 分子静止」是错的；平衡态是「宏观稳定、微观活跃」。<span class="marginnote">「宏观稳定、微观活跃」是平衡态的精髓：一壶水放凉了达到室温，宏观上温度恒定（平衡态），但微观上水分子还在剧烈热运动（温度是平均动能，不是「分子不动」）。平衡态说的是「统计平均不变」，不是「每个分子静止」。这个「宏观 vs 微观」的区别，是热学区别于力学的观念。</span>

## 2 热平衡与温度

**热平衡**：两个系统接触（传热）一段时间后，达到一个共同的「冷热状态」——不再有净热量传递，叫它们达到**热平衡**。

**热平衡定律（热力学第零定律）**：如果两个系统分别与第三个系统达到热平衡，那么这两个系统彼此也处于热平衡。

**温度的定义**：温度是**表示物体冷热程度的物理量**，也是**热平衡的标志**——两个系统热平衡，则温度相同；温度相同，则热平衡。

**辨析｜易错点：** 温度是热平衡的「判据」——判断两系统是否热平衡，看温度是否相同。温度计能测温，正因为「温度计与被测物热平衡时温度相同」——温度计显示的温度就是被测物的温度。<span class="marginnote">「热平衡 → 温度相同」是温度计的原理：把温度计放进被测物，等温度计与被测物达到热平衡（读数不再变），温度计的示数就是被测物的温度。这个「测温要等热平衡」的细节，决定了测温要「等一会儿」——体温计夹在腋下要几分钟，就是等热平衡。</span>

## 3 温标：温度计与标度

**温标**：温度的标尺——规定「温度的零点与分度」的规则。要测温度，需要：**温度计**（感温元件，如汞柱、电阻）与**温标**（刻度规则）。

**摄氏温标（℃）**：

- **定义**：在标准大气压下，冰水混合物的温度定为 0 ℃，沸水的温度定为 100 ℃，中间等分 100 份。
- 单位摄氏度，符号 ℃。
- 日常生活与物理测量常用。

**热力学温标（开尔文温标，K）**：

- **定义**：以**绝对零度**（$-273.15$ ℃）为零点，分度大小与摄氏温标相同。
- 单位开尔文，符号 K（不写「度」）。
- **热力学温度**是理论上最严格的温标，不依赖任何测温物质的特性。

**摄氏温度与热力学温度的关系**：

$$T = t + 273.15$$

其中 $T$ 是热力学温度（K）、$t$ 是摄氏温度（℃）。**两者的分度大小相同**——温度差 $\Delta T = \Delta t$（1 K 的温差 = 1 ℃ 的温差）。<span class="marginnote">「摄氏与热力学只差一个常数」：$T = t + 273.15$，分度一样、零点不同。所以「温差」两者相同（$\Delta T = \Delta t$），但「温度值」差 273.15。绝对零度 $0\ \text{K} = -273.15$ ℃——这是温度的下限，一切分子热运动停止（实际永远达不到）。热力学温标的意义：气体定律、热力学公式（如理想气体状态方程）里用的温度，都是热力学温度 $T$（K），不能直接代入摄氏温度。</span>

## 4 温度计的原理

常见温度计的工作原理（利用物质性质随温度变化）：

- **液体温度计**（汞、酒精）：利用液体**热胀冷缩**——体积随温度变化。
- **气体温度计**：利用气体压强/体积随温度变化——最准确的测温标准。
- **电阻温度计**：利用金属/半导体的**电阻**随温度变化。
- **热电偶温度计**：利用温差电动势（两种金属接触点温度差产生电动势）。
- **红外测温计**：利用物体热辐射（红外线）强度随温度变化——非接触测温。

**辨析｜易错点：** 温度计的原理是「某个物理量随温度单调变化」——温度计本身必须与被测物热平衡才能读数。红外测温不用接触（靠热辐射），但要考虑发射率修正。「温度计显示的是它自己的温度，不是被测物的」——只有达到热平衡后，两者才相等。<span class="marginnote">「测温即测热平衡」贯穿所有温度计：液体温度计等水银柱与物体热平衡（不再膨胀）才读数；电阻温度计等电阻稳定；红外测温计靠「黑体辐射公式」从热辐射反推温度（无需接触，但要求物体接近黑体）。测温的原理各异，共同点是「把温度转化成可测的物理量」（体积、电阻、辐射强度）。</span>

## 5 公式解析：T = t + 273.15

$$T = t + 273.15$$

拆三步看：

- **第一步，两个零点**：摄氏温标以冰水混合物的温度为 0 ℃，热力学温标以绝对零度（分子热运动停止的温度）为 0 K。两者的零点相差 273.15 度，分度大小相同。<span class="marginnote">「273.15 从哪来」：由理想气体实验外推——气体压强随温度线性变化，延长直线到压强为零处，对应的温度是 $-273.15$ ℃，这就是绝对零度。热力学温标把这个点定为 0 K。「绝对零度」不是「人为规定」，而是「分子热运动停止」的物理极限——一切热运动在 0 K 停止（量子力学说零点能还存在，高中按经典理解即可）。</span>
- **第二步，为什么分度相同**：摄氏温标把「冰水 0 ℃ – 沸水 100 ℃」等分 100 份，热力学温标采用同样的分度大小——所以 1 ℃ 的温差 = 1 K 的温差。$\Delta T = \Delta t$ 对任何温度差成立。
- **第三步，何时用哪个**：气体定律（查理定律 $p/T$ 常数、理想气体方程 $pV = nRT$）里温度必须用热力学温度 $T$（K）。摄氏温度用于日常与温差计算。
- **第四步，量级感受**：室温约 20 ℃ = 293 K；绝对零度 = $-273.15$ ℃ = 0 K；太阳表面约 6000 K ≈ 5700 ℃。「摄氏度数值」与「开尔文数值」差 273.15，但「温差」一样——算温差两个温标通用。

## 6 辨析｜易错点

- **热力学温度用 K，不带「度」**：不是「K 度」，直接说「开尔文」。
- **$T = t + 273.15$**：摄氏换热力学加 273.15；算温差 $\Delta T = \Delta t$。
- **气体定律用热力学温度**：代入 $T$（K），不能直接代摄氏温度。
- **平衡态是宏观稳定**：分子微观仍在运动。
- **温度计靠热平衡测温**：等读数稳定再读。
- **绝对零度达不到**：分子热运动停止的极限，只能逼近。

## 7 小结

- **温度**：表示冷热程度、热平衡的标志、分子平均动能的量度。
- **热平衡定律（第零定律）**：热平衡的传递性——温度可测可比的依据。
- **摄氏温标**：冰水 0 ℃、沸水 100 ℃，等分 100 份。
- **热力学温标**：绝对零度 0 K，分度与摄氏相同；$T = t + 273.15$。
- **温度计原理**：热平衡 + 物质性质随温度变化（热胀冷缩、电阻、辐射）。
- 气体定律用热力学温度；温差摄氏与开尔文相同。

在下一节，我们研究气体的第一条实验定律：**气体的等温变化**。温度不变时，气体压强与体积成反比——玻意耳定律 $pV = \text{常数}$。
