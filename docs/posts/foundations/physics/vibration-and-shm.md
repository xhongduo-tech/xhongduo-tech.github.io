## 为什么从振动开始

弹簧拉伸后松手，它弹回来；拨动琴弦，它往复振动；荡秋千，人来回摆荡；甚至原子的振动、电磁波的振荡、股市的周期……**往复运动**遍布宇宙。振动之所以重要，不仅因为它常见，更因为它是「波动」的源头——下一节的机械波，就是振动的传播。

本博客「从极限到大模型」里，振动是与微积分联结最深的一个主题：简谐运动的位置—时间图像就是正弦曲线，而正弦函数在数学上是**最简单的振荡函数**——它的导数还是正弦，只是相位移动。这个「自我相似」的性质，让它成为傅里叶分析（把一切信号拆成谐波叠加）的基石。大模型处理语音、图像、时间序列，第一层工具就是傅里叶变换——从振动到大模型，只有一步之遥。<span class="marginnote">简谐运动是「线性振动」：回复力与位移成正比。这个「线性」二字正是傅里叶分析能横扫一切的根源——线性系统里正弦波输入仍是正弦波输出，于是任何信号都能拆成谐波。第三级《信号与系统》、第四级《数字信号处理》会反复用到它。</span>

## 1 简谐运动：回复力与位移成正比

**机械振动**：物体在平衡位置附近做的往复运动。**简谐运动（simple harmonic motion, SHM）**是其中最简单、也最重要的一种：**回复力与位移大小成正比、方向指向平衡位置**：

$$F = -kx$$

其中 $k$ 叫**劲度系数**（对弹簧振子），负号表示力永远指向平衡位置。由牛顿第二定律 $F = ma$ 得：

$$a = -\frac{k}{m}\, x$$

**重点：简谐运动加速度与位移成正比且反向**——这是判断一个运动「是不是简谐运动」的判据，也是它区别于其他振动的本质。

**例（弹簧振子）**：水平光滑桌面上，$k = 20\ \text{N/m}$ 的弹簧系着 $m = 0.5\ \text{kg}$ 的滑块，拉离平衡位置 $x = 0.1\ \text{m}$ 后释放。回复力 $F = -20 \times 0.1 = -2\ \text{N}$（指向平衡位置），加速度 $a = -2/0.5 = -4\ \text{m/s}^2$。位移越大、力越大、加速度越大——平衡位置处加速度为零但速度最大，两端速度为零但加速度最大。<span class="marginnote">「平衡位置速度最大、两端加速度最大」的反直觉对应，来自「力 ∝ 位移」。理解这个此消彼长，简谐运动的图像（正弦/余弦）就顺理成章了——位移是正弦，速度是位移的导数（余弦），加速度是位移的二阶导（又回到正弦，但反号）。</span>

## 2 描述简谐运动：周期、频率、相位

三个核心量：

- **振幅（amplitude）$A$**：偏离平衡位置的最大距离，决定振动的强弱。
- **周期（period）$T$**：完成一次全振动的时间。弹簧振子的周期**与振幅无关**，只由系统本身决定：

$$T = 2\pi\sqrt{\frac{m}{k}}$$

- **频率（frequency）$f = 1/T$**：单位时间完成的振动次数，单位赫兹（Hz）。

位移随时间的变化：

$$x = A\cos\left(\frac{2\pi}{T}t + \varphi_0\right) = A\cos(\omega t + \varphi_0)$$

其中 $\omega = \dfrac{2\pi}{T}$ 是**角频率**，$\varphi_0$ 是**初相位**，$(\omega t + \varphi_0)$ 叫相位。<span class="marginnote">相位是振动分析里最容易被忽略却最重要的量：两个同频振动之间的相位差，决定了干涉是加强还是抵消（下一节波的干涉会用上）。到电磁学和量子力学，相位差更是干涉、衍射、量子相位的命脉。</span>

**例（周期公式的意义）**：弹簧振子周期 $T = 2\pi\sqrt{m/k}$ 告诉我们：**质量越大越慢，劲度系数越大越快**。给弹簧加上更重的载荷，振动变慢；换更硬的弹簧，振动变快。而且周期与振幅无关——把振幅拉大或缩小，周期纹丝不动，这是简谐运动「等时性」的体现。

弹簧振子与单摆是两种最典型的简谐运动，一张表对照：

| | 弹簧振子（水平） | 单摆（小角度） |
| --- | --- | --- |
| 回复力来源 | 弹簧弹力 $-kx$ | 重力切向分量 $-mg\tfrac{x}{l}$ |
| 等效劲度系数 | $k$ | $k' = \dfrac{mg}{l}$ |
| 周期 | $T = 2\pi\sqrt{\dfrac{m}{k}}$ | $T = 2\pi\sqrt{\dfrac{l}{g}}$ |
| 周期与谁无关 | 振幅、重力 | 振幅、摆球质量 |
| 应用 | 弹簧秤、减震 | 摆钟、测 $g$ |

**重点：** 单摆小角度时回复力为 $-mg\tfrac{x}{l}$，与位移 $x$ 成正比——所以它也是简谐运动，「周期只由 $l$ 和 $g$ 决定」全部由此而来。惠更斯把这条规律做进摆钟，人类从此有了稳定的计时器。

## 3 简谐运动的能量

简谐运动中动能与弹性势能互相转化、总量守恒：

$$E = \tfrac{1}{2}kx^2 + \tfrac{1}{2}mv^2 = \tfrac{1}{2}kA^2$$

- 平衡位置：$x = 0$，弹性势能最小（零）、动能最大 $\tfrac{1}{2}kA^2$。
- 最大位移处：$x = \pm A$，动能零、弹性势能最大 $\tfrac{1}{2}kA^2$。
- 总机械能 $\tfrac{1}{2}kA^2$ **与振幅的平方成正比**：振幅翻倍，能量变四倍。

**例（单摆近似）**：单摆摆角很小时做简谐运动，周期 $T = 2\pi\sqrt{l/g}$（与摆球质量、振幅无关）。惠更斯 1673 年在《摆钟论》里用摆的等时性造出了第一台摆钟——从此人类有了稳定的「秒」。伽利略早在比萨教堂数吊灯摆动时发现了等时性，但真正的机械钟是惠更斯做出来的。<span class="marginnote">单摆的等时性是「周期只由摆长和 g 决定」的直接推论。用它测 $g$：测出 $l$ 与 $T$，反解 $g = \dfrac{4\pi^2 l}{T^2}$——人教版实验《用单摆测量重力加速度》就是这么做的。这个「测可测的量、反解想知道的量」的方法，与第 1 篇量纲分析的思路一脉相承。</span>

**实验视角：用单摆测 $g$。** 人教版 §2.5《实验：用单摆测量重力加速度》的操作要点：摆长 $l$ 取「悬点到球心的距离」，测 $30\text{-}50$ 次全振动的总时间取平均得周期 $T$，多组 $l$、$T$ 后以 $l$ 为横轴、$T^2$ 为纵轴作图，直线斜率 $k = \dfrac{4\pi^2}{g}$，由 $g = \dfrac{4\pi^2}{k}$ 反解。**「量可测的量（$l, T$）、作图找斜率、反解目标量（$g$）」**——这条实验方法论，与第 1 篇量纲分析、运动学纸带实验完全同构。

## 4 阻尼振动：能量在衰减

实际的振动总有阻力——摩擦、空气阻力、内部损耗。振动系统受到阻力、能量逐渐减少、振幅逐渐减小的振动叫**阻尼振动（damped oscillation）**。

阻尼振动的特征是**振幅按指数规律衰减**，而频率略低于无阻尼固有频率。阻尼越大，衰减越快，甚至出现**过阻尼**（来不及振荡就缓慢回到平衡）和**临界阻尼**（最快回到平衡而不振荡）。

**例（汽车减震）**：汽车悬挂系统的减震器被调成**接近临界阻尼**——弹簧振动一次就基本停下来，既不反复弹跳（欠阻尼）也不迟钝到底（过阻尼）。汽车减震、弹簧门、仪表指针的阻尼设计，都在追求「一次到位、不振荡」这个甜点。<span class="marginnote">「临界阻尼 = 最快回到平衡」的工程直觉，也出现在优化算法里：梯度下降的学习率过大（欠阻尼）会震荡发散，过小（过阻尼）则收敛太慢。调学习率与调减震器，本质是同一件事。</span>

阻尼振动的定量刻画：振幅按指数衰减 $A(t) = A_0 e^{-\gamma t}$（$\gamma$ 是阻尼系数），振动方程 $x = A_0e^{-\gamma t}\cos(\omega' t)$。**品质因数** $Q = \dfrac{\omega_0}{2\gamma}$ 衡量「一个周期内能量损失的大小」：$Q$ 大则振荡持久（音叉、石英晶振），$Q$ 小则迅速衰减（减震器、仪表指针）。工程上常常刻意压低 $Q$——**「好的振荡器要 $Q$ 高，好的减震器要 $Q$ 低」**，这一对矛盾被同一个品质因数统一起来。

## 5 受迫振动与共振：把能量喂进去

**受迫振动（forced oscillation）**：在周期性外力（驱动力）作用下，系统以**驱动力的频率**振动，而不是以固有频率振动。刚开始振幅不稳定，稳定后振动频率恒等于驱动力频率，振幅由驱动力频率与固有频率的关系决定。

**共振（resonance）**：**驱动力的频率等于系统的固有频率时，振幅达到最大**。此时外力每周期都「顺着」振动方向做功，能量持续注入，振幅不断增大直到被阻尼平衡。

**例（共振的威力与灾难）**：士兵过桥要「便步走」，正是怕整齐步伐的频率与桥的固有频率接近引起共振——1840 年代英国布鲁格吊桥（Broughton Bridge）曾因士兵齐步走而坍塌；2000 年伦敦千禧桥因行人步伐频率共振而剧烈晃动，被迫关闭加固。而乐器、微波炉（水分子振动频率）、收音机选台（电谐振），则是共振被善意利用。<span class="marginnote">共振的判别很简单：驱动力频率 = 固有频率。1940 年塔科马海峡吊桥被风「吹垮」，本质是风的旋涡脱落频率与桥面扭转固有频率耦合的共振——不是风太大，是频率「对上」了。这个「频率对上就放大」的机制，也是语音识别、基因敲除等系统里「共振思想」的根源。</span>

共振的「善恶两面」，一个清单理清：

| 有害共振（要避开） | 有益共振（要利用） |
| --- | --- |
| 队伍齐步走过桥 | 乐器共鸣腔放大音量 |
| 机器转速接近固有频率 | 收音机调台（电谐振） |
| 高楼对风致振动的响应 | 微波炉加热水分子 |
| 桥梁风致扭振（塔科马） | 超声清洗、超声碎石 |

判据永远是同一条：**驱动力频率是否等于固有频率**。凡是「避免共振」的工程，手段都是错开频率——加固改变固有频率、加装减震器增大阻尼、限制速度避开激励频率。这三个手段，本质上就是「把共振点从工作频段移走」。

## 6 小结

- **简谐运动**：回复力 $F = -kx$，加速度 $a = -(k/m)x$，判断简谐运动看「加速度与位移成正比且反向」。
- **描述量**：振幅 $A$、周期 $T$、频率 $f$、相位 $\omega t + \varphi_0$；$x = A\cos(\omega t + \varphi_0)$。
- **弹簧振子周期** $T = 2\pi\sqrt{m/k}$，与振幅无关；**单摆** $T = 2\pi\sqrt{l/g}$（小角度）。
- **能量**：$E = \tfrac{1}{2}kA^2$ 与振幅平方成正比，动能与势能周期性地此消彼长。
- **阻尼振动**：振幅指数衰减；临界阻尼最快回到平衡（汽车减震、学习率调节同理）。
- **共振**：驱动力频率 = 固有频率时振幅最大——可造桥之灾（塔科马）、可造福人类（乐器、微波炉）。

在下一节，我们把振动「传出去」：一个质点的振动如何带动相邻质点，形成**机械波**？波动方程、叠加与干涉、多普勒效应——声音、地震、水波的全部秘密都在里面。下一节见。
