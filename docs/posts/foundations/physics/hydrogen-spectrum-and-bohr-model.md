## 为什么从氢原子光谱和玻尔的原子模型开始

上一节核式模型留下两个谜：**原子为什么稳定？原子发光为什么是分立的线谱？** 1913 年玻尔用量子化思想解决了它们——他提出**玻尔原子模型**：电子只能在某些特定的稳定轨道（定态）上运动，不辐射能量；电子在能级之间跃迁时，发射或吸收特定频率的光子。这个模型第一次解释了氢原子光谱的分立性，是量子理论在原子结构上的第一个成功应用。

玻尔模型是「旧量子论」的代表：它把普朗克的能量量子化、爱因斯坦的光子说应用到原子，取得了惊人成功（精确解释氢光谱），但也保留了不少经典观念（轨道、圆周运动），后来被更彻底的量子力学（波动力学）取代。它是一座承上启下的桥。<span class="marginnote">「玻尔模型的三个假设」是它的全部内容：<strong>定态假设（电子在特定轨道不辐射能量）、频率条件（跃迁时 $hf = E_n - E_m$）、量子化条件（轨道角动量 $L = n\hbar$）</strong>。前两条解释「为什么原子稳定 + 为什么发光分立」，第三条给出「哪些轨道被允许」的量子规则。玻尔把「量子化」从能量推广到轨道——原子问题第一次有了量子解答。</span>

学这一节，请抓住：**氢原子光谱的规律、玻尔的三条假设、能级跃迁与光子频率**。

## 1 氢原子光谱：分立的线谱

**原子光谱**：原子发光形成的谱——不是连续谱，而是**分立的光谱线**（线状谱）。每种元素有自己独特的谱线（指纹）。

**氢原子光谱（可见光部分，巴耳末系）**：四条明显的谱线（红、青、蓝、紫），波长满足**巴耳末公式**：

$$\frac{1}{\lambda} = R\left(\frac{1}{2^2} - \frac{1}{n^2}\right), \qquad n = 3, 4, 5, \cdots$$

其中 $R$ 是**里德伯常量**，$R = 1.097\times10^7\ \text{m}^{-1}$。

**氢光谱的其他线系**：紫外区（莱曼系，$n_1 = 1$）、可见区（巴耳末系，$n_1 = 2$）、红外区（帕邢系，$n_1 = 3$）等——都由类似的「$\tfrac{1}{n_1^2} - \tfrac{1}{n_2^2}$」公式描述。

**氢光谱的意义**：分立谱线说明原子内部能量是**分立的**——电子只能在特定能级之间跃迁，发出特定频率的光。这是「原子能量量子化」的直接证据。<span class="marginnote">「氢光谱的规律之美」：$1/\lambda = R(1/2^2 - 1/n^2)$ 是氢光谱的「密码」——所有谱线的波数都是两个「$1/n^2$」之差。这个规律在玻尔模型里得到解释：每个 $n$ 对应一个能级，$1/\lambda$ 之差对应能级之差。光谱线的「分立音符」直接反映能级的「量子台阶」。巴耳末在 1885 年凭经验凑出这个公式，玻尔在 1913 年用量子模型解释了它——「经验规律 → 理论解释」的又一范例。</span>

## 2 玻尔模型的三个假设

**假设一：定态假设（轨道量子化）**：原子只能处于一系列**不连续的能量状态（定态）**中。电子在这些定态对应的轨道上运动时，**不辐射能量**——原子是稳定的。

**假设二：频率条件（跃迁辐射）**：当电子从高能级 $E_m$ 跃迁到低能级 $E_n$ 时，辐射一个光子；反之吸收光子：

$$hf = E_m - E_n$$

（$h$ 是普朗克常量，$f$ 是辐射/吸收光的频率。）

**假设三：轨道量子化条件**：电子绕核运动的轨道半径与角动量是量子化的：

$$L = mvr = n\frac{h}{2\pi} = n\hbar, \qquad n = 1, 2, 3, \cdots$$

$n$ 是**量子数**，$\hbar = h/2\pi$。

**辨析｜易错点：** 玻尔模型的「定态」是「不辐射能量」的稳定状态——电子在定态轨道上不发光。只有**跃迁**（从一个定态跳到另一个定态）才辐射/吸收光子。「电子绕核运动会发光」是经典观念——玻尔假设「定态不发光」，只有「跃迁才发光」。<span class="marginnote">「玻尔的两步：定态 + 跃迁」：定态假设解决「原子为什么不坍缩」（电子在定态轨道上不辐射能量、稳定存在），频率条件解决「为什么发光分立」（跃迁只允许特定能量差、发出特定频率的光）。这两个假设是对经典电磁学的「硬性修改」——经典说「加速运动的电子必辐射」，玻尔说「定态轨道上的电子例外」。玻尔自己承认这些假设「看起来是疯狂的」，但实验支持它。</span>

## 3 氢原子的能级

由玻尔模型可以算出氢原子的能级：

$$E_n = -\frac{13.6\ \text{eV}}{n^2}, \qquad n = 1, 2, 3, \cdots$$

- **基态**（$n = 1$）：$E_1 = -13.6\ \text{eV}$（能量最低、最稳定）。
- **激发态**（$n = 2, 3, \cdots$）：$E_n = -13.6/n^2\ \text{eV}$（越高越接近零）。
- **电离能**：把基态电子完全移走需要 13.6 eV——氢原子的电离能。

**能级图**：用横线表示能级（高度代表能量），能级越高（越接近零）间隔越密。电子从 $E_m$ 跃迁到 $E_n$，光子能量 $hf = E_m - E_n$。

**辨析｜易错点：** 氢原子基态能量是**负的**（$-13.6\ \text{eV}$）——负号表示「束缚态」（电子被核束缚，要吸收能量才能脱离）。能级越高（$n$ 大）能量越大（越接近零）。「基态能量是负的所以没有能量」是错误理解——负号是「束缚」的标记，基态是能量最低（最束缚）的状态。<span class="marginnote">「负能量 = 束缚态」是原子物理的惯例：把「电子在无穷远处（脱离原子）」的能量定为零，束缚电子能量就为负——要给它正能量才能「爬」到零（电离）。氢原子基态 $-13.6\ \text{eV}$ 表示「把电子从基态移走需要 13.6 eV」。这个「零点在无穷远」的约定，与重力势能「零点在无穷远」一致——束缚系统的势能为负。能级图里基态在最底下（最负）、激发态在上、电离（$E = 0$）在顶。</span>

## 4 能级跃迁与光谱

**跃迁发光的频率**：电子从高能级 $E_m$ 跃迁到低能级 $E_n$，辐射光子频率：

$$f = \frac{E_m - E_n}{h}, \qquad \lambda = \frac{hc}{E_m - E_n}$$

**光谱线系与跃迁的对应**：

- **莱曼系**（紫外）：$n \ge 2 \to n = 1$（跃迁到基态）。
- **巴耳末系**（可见光）：$n \ge 3 \to n = 2$。
- **帕邢系**（红外）：$n \ge 4 \to n = 3$。

**为什么光谱是分立的**：能级是分立的，能级差（$E_m - E_n$）是分立的，光子频率 $f = \Delta E/h$ 是分立的——所以谱线是分立的。

**辨析｜易错点：** 一个氢原子一次跃迁只发出**一个**光子（一个频率）。但大量氢原子处于不同激发态、发生不同跃迁，光谱就显示出**多条**谱线。从第 $n$ 能级跃迁到基态，可能的跃迁路径有 $\tfrac{n(n-1)}{2}$ 种（能辐射的谱线数）。「一个原子发出全部谱线」是错的——一个原子一次只跳一步、只发一个光子。<span class="marginnote">「谱线数 = 跃迁方式数」：从能级 $n$ 可以跃迁到 $n-1, n-2, \cdots, 1$，每条路径对应一条谱线。从 $n = 4$ 的激发态回到基态，可能路径：$4\to1$、$4\to2\to1$、$4\to3\to1$、$4\to3\to2\to1$ 等，共 $4\times3/2 = 6$ 种——大量氢原子统计起来会发出 6 条不同谱线。这个「能级数 → 谱线数」的计数，是玻尔模型的经典考题。</span>

## 5 公式解析：hf = E_m − E_n

$$hf = E_m - E_n$$

拆三步看：

- **第一步，能量守恒**：光子能量 = 能级差。电子从高能级 $E_m$ 跳回低能级 $E_n$，多余的能量以光子形式释放；从低能级吸收光子跳上高能级，光子能量正好等于能级差。<span class="marginnote">「跃迁 = 能量守恒在原子中的体现」：电子在高能级（$E_m$）与低能级（$E_n$）之间的能量差，只能通过「发射/吸收一个光子」来转移——光子能量 $hf$ 必须精确等于 $E_m - E_n$。频率不对的光子，原子「不接招」（能量不匹配，无法跃迁）。这个「精确匹配」解释了为什么原子只吸收/发射特定频率的光——光谱指纹的来源。</span>
**第二步，与巴耳末公式的联系**：$hf = E_m - E_n$ 代入 $E_n = -13.6/n^2$ eV 与 $f = c/\lambda$，就能推出 $1/\lambda = R(1/n_1^2 - 1/n_2^2)$——玻尔模型从理论上导出了巴耳末的经验公式，里德伯常量也被算出（$R = 1.097\times10^7\ \text{m}^{-1}$）。**经验公式被理论解释**，是玻尔模型的伟大成就。
**第三步，光子能量的方向**：从高到低（辐射，发光）、从低到高（吸收）。原子发光 = 电子从高能级向低能级跃迁。
**第四步，量级感受**：氢原子巴耳末系第一条谱线（$3 \to 2$）：$E_3 - E_2 = -13.6/9 - (-13.6/4) = -1.51 + 3.40 = 1.89\ \text{eV}$，波长 $\lambda = hc/\Delta E = 1240/1.89 \approx 656\ \text{nm}$——红光，正是氢光谱的 Hα 线。

## 6 玻尔模型的成就与局限

**成就**：

成功解释氢原子光谱（分立线谱、巴耳末系等）。
解释原子的稳定性（定态假设）。
首次把量子化应用到原子结构，开启原子物理学。

**局限**：

只适用于**氢原子**（一个电子）；无法解释多电子原子（氦等）的光谱。
不能解释谱线的**精细结构**（如磁场中的分裂，塞曼效应）与相对论效应。
轨道概念被后来的量子力学取代（电子用「概率云/波函数」描述，没有确定轨道）。

**从玻尔到量子力学**：玻尔的「轨道」被薛定谔的「波函数」取代——电子不再有确定轨道，而是以概率分布存在于核外空间（电子云）。但「能级」「跃迁」「量子数」这些概念保留至今，仍是现代原子物理的语言。<span class="marginnote">「玻尔模型的半经典性」：它把经典（轨道、圆周运动）与量子（量子化条件）硬性结合，是「旧量子论」。现代量子力学（薛定谔方程）从更根本的「波函数」出发，能级与跃迁自然涌现——不需要人为假设「量子化条件」。玻尔模型的「能级图」仍被广泛使用，因为它直观、且对单电子体系（氢、类氢离子）定量正确。「旧量子论的桥」把经典物理引向量子物理，功不可没。</span>

## 7 辨析｜易错点

- **定态不发光，跃迁才发光**：电子在定态轨道上不辐射能量。
- **光子频率由能级差决定**：$hf = E_m - E_n$，能级分立 → 谱线分立。
- **基态能量是负的**：$-13.6\ \text{eV}$，负号表示束缚态。
- **一次跃迁一个光子**：一个原子一次跳一步、发一个光子。
- **玻尔模型只适用氢原子**：多电子原子需量子力学。
- **谱线数**：从能级 $n$ 到基态的谱线数为 $n(n-1)/2$。

## 8 小结

- **氢原子光谱**：分立线谱，$1/\lambda = R(1/n_1^2 - 1/n_2^2)$——能量量子化的证据。
- **玻尔三假设**：定态（不辐射）、频率条件（$hf = \Delta E$）、轨道量子化（$L = n\hbar$）。
- **氢原子能级**：$E_n = -13.6/n^2\ \text{eV}$；基态 $-13.6\ \text{eV}$、电离能 13.6 eV。
- **跃迁发光**：$f = \Delta E/h$；莱曼系（紫外）、巴耳末系（可见）、帕邢系（红外）。
- **成就**：解释氢光谱与原子稳定性；**局限**：只适用氢原子、轨道被量子力学取代。
- 玻尔模型是经典到量子物理的桥梁——能级、跃迁概念沿用至今。
