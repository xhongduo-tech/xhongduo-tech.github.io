## 为什么从磁场磁感线开始

第九章我们建立了「电场」，认识了电荷通过电场相互作用。现在轮到磁：**磁体与电流通过磁场相互作用**。磁现象古已有之——指南针、磁石——但直到 19 世纪，奥斯特发现电流能偏转磁针，才把「电」与「磁」连成一体。此后电磁学突飞猛进：发电机、电动机、变压器、无线通信，全都是「电生磁、磁生电」的产物。

这一节建立磁场的概念框架：**磁场是什么、怎么画（磁感线）、从哪来（磁体与电流）**。它与电场的框架完全平行——场、场线、源，一一对应。理解磁场的诀窍，就是借用电场那套已经熟练的「场」的思想，同时盯住两者的关键差别：**电场线始于正电荷止于负电荷，磁感线则永远闭合（无磁单极子）**。<span class="marginnote">电场与磁场的深刻对称与差异是物理学最美的话题之一：<strong>电场有「源」（正负电荷）、磁场的「源」却只有成对的磁极</strong>——你切一块磁铁，得到的是两个更小的「南北极对」，永远切不出单极。这个「磁单极子不存在」的事实，是现代物理学里一个未解的谜：如果存在磁单极子，麦克斯韦方程组将更对称。高中阶段只要记住「磁感线闭合」这个结论。</span>

学这一节，请把「电场线」的五条性质（切线表方向、疏密表强弱、不相交、从正到负、不闭合）当作模板，逐条改成磁感线版本（切线表方向、疏密表强弱、不相交、从 N 到 S 但在磁体内部从 S 到 N、闭合）——对照着记，事半功倍。

## 1 磁场：磁相互作用的媒介

**磁场（magnetic field）**：磁体或电流周围存在的一种特殊物质，它对放入其中的磁体、电流或运动电荷有力的作用。

磁场的基本性质与电场完全平行：

磁体与磁体之间的力、磁体与电流之间的力、电流与电流之间的力，都通过**磁场**传递，不是超距作用。
磁场对放入其中的磁体（小磁针）有力的作用——**小磁针的指向**可以「探测」磁场的方向。
磁场对**电流**与**运动电荷**也有力的作用（这是选择性必修二《安培力与洛伦兹力》的内容，本节先建立「磁场存在」的观念）。

**磁场的方向**：规定为**小磁针静止时 N 极所指的方向**（N 极受力方向）。这是一个约定——正如电场方向规定为正电荷受力方向。<span class="marginnote">「磁场方向 = 小磁针 N 极指向」是磁场方向判定的唯一基准。N 极指向磁场方向，S 极指向磁场反方向。所以小磁针在某处静止时，N 极指向的那端就是磁场方向。用这个约定，你可以在任何地方用一枚小磁针「读出」磁场方向——地理上，指南针 N 极指向地理北极（那里是地磁南极）。</span>

磁场从哪里来？两个来源：**磁体**与**电流**。奥斯特实验（1820 年）发现：通电导线旁的磁针会偏转——**电流产生磁场**。这第一次证明「电生磁」，把电与磁统一起来。

## 2 磁感线：磁场的形象

为了形象描述磁场，法拉第引入**磁感线（magnetic field lines）**——假想的曲线：

**磁感线的性质**：

1. 磁感线上**每点的切线方向**，就是该点磁场方向。
2. **疏密**表示磁场强弱：密处磁场强，疏处磁场弱。
3. 磁感线**从 N 极出发，进入 S 极**（外部），在磁体**内部从 S 极回到 N 极**，形成**闭合曲线**——这与电场线「不闭合」形成鲜明对比。
4. 磁感线**不相交**。
5. 磁感线是**假想的**，不是真实存在的线——就像电场线一样，是「作图工具」不是实物。<span class="marginnote">磁感线「闭合」这个性质藏着物理：电场线始于正电荷止于负电荷，因为电荷是电场的「源」；磁感线闭合、无头无尾，因为磁场没有「磁单极子」——磁极总成对出现。这是「为什么条形磁铁外部的磁感线从 N 到 S、内部从 S 到 N 连成闭合回路」的原因。磁感线闭合，是「磁单极子不存在」的几何表达。</span>

**常见磁场的磁感线**：

**条形磁铁**：外部从 N 到 S，内部从 S 到 N，闭合。
**蹄形磁铁**：外部从 N 极弯到 S 极，两极间近似匀强磁场（平行等距）。
**匀强磁场**：磁感线平行等距、方向相同，磁场强弱方向处处相同。
**直线电流的磁场**：磁感线是以导线为圆心的同心圆（用右手螺旋定则判断方向）。
**环形电流与通电螺线管**：磁感线像条形磁铁（内部近似匀强、外部闭合），通电螺线管内部磁场最强。

## 3 安培定则（右手螺旋定则）

电流产生的磁场方向，用**安培定则（右手螺旋定则）**判断。三种情形：

**直线电流**：右手握住导线，**大拇指指向电流方向**，四指弯曲的方向就是磁感线的环绕方向。
**环形电流**：右手弯曲四指**沿电流方向**，大拇指所指的方向就是环形电流中心磁场方向。
**通电螺线管**：右手弯曲四指沿电流方向，大拇指指向螺线管的 N 极（即磁感线内部方向）。

**辨析｜易错点：** 直线电流与环形/螺线管电流的安培定则**手势相反**——直线电流用「大拇指指电流」，环形电流用「四指指电流」。「谁指电流、谁指磁场」极易搞混。记忆锚点：直线电流的磁场是「绕」，所以「直导线用大拇指指电流、四指绕磁场」；环形电流的磁场是「穿」，所以「四指沿电流、大拇指穿过去指 N 极」。<span class="marginnote">三个定则的手势对比：安培定则（电流→磁场，用右手）、左手定则（磁场→力，用左手）、右手定则（运动→感应电流，用右手）。「一右生磁场、左手受安培力、右手割磁感线」——高中电磁学三大定则，先分清「谁推谁」，再用正确的手。这里先把安培定则练熟，另两个到选择性必修二再展开。</span>

安培定则的本质是「电生磁的方向性」：电流方向与它激发的磁场方向构成右手螺旋关系。这个「右手螺旋」在电磁学里反复出现，是理解电流与磁场方向的关键。

## 4 地磁场：地球的磁

地球本身是一个巨大的磁体，周围存在**地磁场**。地磁场有几个重要特征：

**磁极与地理极不重合**：地磁北极在地理南极附近，地磁南极在地理北极附近——**指南针的 N 极指向地理北方**，是因为那里是地磁南极（S 极），N 极被 S 极吸引。
**磁偏角**：地磁极与地理极之间的夹角，使指南针的指向与地理正北有一个偏差角，叫**磁偏角**。我国宋代的沈括在《梦溪笔谈》里最早记载了磁偏角。
**地磁场保护地球**：地磁场像一把「伞」，偏转来自太阳的高能带电粒子（太阳风），保护大气层与生物免受轰击。极光正是太阳风粒子沿磁感线进入两极大气、与大气分子碰撞发光的结果。<span class="marginnote">地磁场与太阳风的相互作用是空间物理的入门话题：带电粒子在磁场中受洛伦兹力偏转（选择性必修二），螺旋地沿磁感线「钻」向两极。地球磁场保护大气层不被太阳风剥离，是地球宜居性的重要保障。火星磁场弱，太阳风把大气「吹」跑了——对比两个行星，可见地磁场有多重要。</span>

**辨析｜易错点：** 地理北极附近是**地磁南极**（S 极）——这是最常考也最容易记反的结论。指南针 N 极指向地理北，意味着「地理北」的磁场方向是「指向地磁南极方向」。把「地理北极 = 地磁北极」当成结论，方向就全反了。

## 5 公式解析：直线电流磁场的磁感线

直线电流产生的磁场，其磁感线是**以导线为圆心、与导线垂直的同心圆**。方向由安培定则判断，磁场强弱随距离变化：

$$B = k'\frac{I}{r}$$

其中 $B$ 是磁感应强度（下一节的量，衡量磁场强弱），$I$ 是电流，$r$ 是到导线的垂直距离，$k'$ 是比例常数。拆三步看：

- **第一步，几何形状**：磁感线是同心圆——因为电流的磁场具有「绕导线」的圆柱对称性。导线越长的直导线，中间部分的磁场越接近这种理想圆形分布。
- **第二步，方向**：用安培定则，右手握导线、大拇指指电流，四指弯曲方向即磁感线环绕方向。换个角度说，磁感线「顺着电流的方向看是逆时针」还是「顺时针」，取决于电流流向（用右手定则定）。
- **第三步，强弱与距离**：磁场强弱随距离 $r$ 增大而**减小**（反比关系）——离导线越远磁场越弱。这与点电荷电场 $E \propto 1/r^2$ 类似但指数不同（磁场是 $1/r$），因为电流是「线源」而非「点源」：线源的辐射在圆柱面 $2\pi r$ 上扩散，所以 $\propto 1/r$。<span class="marginnote">「点源 $1/r^2$、线源 $1/r$」是「源的类型决定衰减指数」的规律：点源的能量摊在球面上（$r^2$），线源的能量摊在圆柱面上（$r$）。记住这个规律，你不仅能理解电场与磁场的强弱分布，还能预见声源、光源的强度衰减——物理学里「对称性决定分布」的例子。</span>
- **第四步，叠加**：多条导线同时存在时，磁场按矢量叠加（磁感线可以「相加」）。这正是「通电螺线管像条形磁铁」的原因：许多环电流的磁场叠加，内部同向增强、外部相互回绕。

## 6 辨析｜易错点

- **磁感线闭合，电场线不闭合**：电场线始于正电荷止于负电荷；磁感线在磁体外部从 N 到 S、内部从 S 到 N，形成闭合回路。把两者混为一谈是常见错误。
- **磁感线不相交**：若相交则交点有两个切线方向、磁场方向不唯一。这一点与电场线一致。
- **磁感线是假想的**：不是真实存在的线。铁屑在磁场中排列成的图案是「铁屑被磁化后沿磁感线排布」的显示，不是磁感线本身。
- **安培定则三种手势别混**：直线电流用拇指指电流、环形/螺线管用四指指电流。判断时先分清是「直导线」「环」还是「螺线管」。
- **地理北极 = 地磁南极**：指南针 N 极指地理北，因为那里是地磁 S 极。别记反。
- **磁场方向与磁感线切线方向一致**：读磁感线图时，某点的箭头方向或切线方向即磁场方向，疏密即强弱。

## 7 小结

- **磁场**：磁体或电流周围存在的特殊物质，对磁体、电流、运动电荷施力；方向 = 小磁针 N 极指向。
- **磁场来源**：磁体与电流（奥斯特实验证明电生磁）。
- **磁感线**：切线表方向、疏密表强弱、不相交、**闭合**（外部 N→S，内部 S→N）。
- **安培定则**：直线电流用拇指指电流；环形/螺线管电流用四指指电流、拇指指 N 极。
- **地磁场**：地理北极附近是地磁南极；磁偏角；地磁场保护大气、产生极光。
- **直线电流磁场**：磁感线为同心圆，$B \propto I/r$（线源衰减 $1/r$）。

在下一节，我们把「磁场的强弱」定量化：**磁感应强度 磁通量**。磁感应强度 $B$ 是磁场的「强度」指标，磁通量 $\Phi$ 是「穿过面的磁感线数」，两者是下一章电磁感应定律的核心量。
