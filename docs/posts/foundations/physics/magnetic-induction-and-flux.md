## 为什么从磁感应强度和磁通量开始

上一节我们认识了磁场与磁感线，但只停留在「定性」：磁场有强弱、有方向。物理学的下一步永远是定量——**磁场到底有多强？穿过一个面的磁感线有多少？** 这一节引入两个定量量：**磁感应强度 $B$**（磁场的强弱与方向）与**磁通量 $\Phi$**（穿过某面积的磁感线数）。

这两个量是电磁学的「语言基础」：$B$ 决定磁场对电流的力（安培力 $F = BIL$）、对运动电荷的力（洛伦兹力 $F = qvB$）；$\Phi$ 及其变化率决定感应电动势（法拉第电磁感应定律）。没有这两个量，选择性必修第二册的整本内容无从谈起。<span class="marginnote">注意「磁感应强度」这个名称：它是「磁」的「感应强度」，之所以叫「感应」而不是「强度」，是历史遗留——它与「电磁感应」的感应同源，但含义是「磁场强弱」。$B$ 的符号、名称都容易与电场强度 $E$ 混淆，务必分清：电场强度 $E$（单位 $\text{N}/\text{C}$ 或 $\text{V}/\text{m}$）与磁感应强度 $B$（单位特斯拉 T）是不同场的不同量。</span>

学这一节，请与电场强度 $E$ 对照着记：$E = F/q$ 用「对电荷的力」定义，$B = F/(IL)$ 用「对电流的力」定义——**场都是通过「它对放入其中的试探物施力」来定义的**。把这条主线抓住，$B$ 的定义就不难。

## 1 磁感应强度：磁场的强弱与方向

**磁感应强度（magnetic induction）**：描述磁场强弱与方向的物理量，符号 $B$，单位**特斯拉（T）**。

**方向**：磁感应强度是矢量，方向即该点磁场方向（小磁针 N 极指向，或磁感线切线方向）。

**大小**：如何测量磁场的强弱？与电场用「对试探电荷的力」类似，磁场用「对试探电流元（长为 $L$、电流 $I$ 的一小段直导线）的力」来定义。实验发现：

- 电流元与磁场方向**垂直**时，受的力最大，$F_{\max} = BIL$。
- 电流元与磁场方向**平行**时，受的力为零。
- 一般情况下，力 $F = BIL\sin\theta$（$\theta$ 为电流方向与磁场方向的夹角）。

由此定义磁感应强度的大小：

$$B = \frac{F_{\max}}{IL}$$

**物理意义**：单位电流、单位长度、与磁场垂直的导线所受的磁场力。$1\ \text{T} = 1\ \text{N}/(\text{A}\cdot\text{m})$。<span class="marginnote">特斯拉（Tesla）纪念交流电之父尼古拉·特斯拉。1 T 是相当强的磁场：地球表面地磁场约 $5\times10^{-5}\ \text{T}$，家用磁铁约 $10^{-2}$ T，MRI 医疗磁体 1.5–3 T，实验室强磁铁可达 10 T 以上。「B 的单位是特斯拉」要记住，但更要记住「$B$ 是用力定义的」——它测量的其实是磁场对电流的作用强度。</span>

**辨析｜易错点：** 磁场对**静止电荷**没有力（这点与电场不同！电场对静止电荷也有力 $F = qE$）。磁场力只作用于**运动电荷**或**电流**。所以「用试探电荷测磁场」行不通，必须用「电流元」。这正是 $B$ 用「电流 × 长度」定义、而 $E$ 用「电荷」定义的原因。

## 2 磁感应强度与电场强度的对比

$B$ 与 $E$ 的平行结构是理解电磁场的关键，一张表对照：

| 比较项 | 电场强度 $E$ | 磁感应强度 $B$ |
| --- | --- | --- |
| 定义 | $E = F/q$（对试探电荷的力） | $B = F/(IL)$（对试探电流元的力） |
| 单位 | $\text{N}/\text{C}$ 或 $\text{V}/\text{m}$ | 特斯拉 T |
| 矢量 | 方向 = 正电荷受力方向 | 方向 = 小磁针 N 极指向 |
| 对静止试探物 | 有作用力（$F = qE$） | 无作用力 |
| 源 | 电荷 | 磁体、电流 |
| 力的大小（试探物垂直场） | $F = qE$ | $F = BIL$ |

**注意 $F = BIL$ 的前提是「电流方向垂直磁场」**：不垂直时是 $F = BIL\sin\theta$。平行时力为零——这是磁场力与电场力最本质的差别：**电场力沿电场方向，磁场力垂直磁场与电流方向**（用左手定则判断方向，选择性必修二展开）。<span class="marginnote">电场力「沿场方向」（正电荷受电场力方向与 $E$ 同向），磁场力「垂直于场与电流」——这个「沿 vs 垂直」的差别决定了一切：电场可以做功（电荷沿电场线移动），磁场对电流不做功（$F$ 始终垂直 $v$）！这解释了为什么磁场能改变运动方向却永远不做功——匀速圆周运动里洛伦兹力只提供向心力。这个区别在选择性必修二会反复用到。</span>

## 3 磁通量：穿过面的磁感线数

**磁通量（magnetic flux）**：穿过某一面积的磁感线的条数，符号 $\Phi$，单位**韦伯（Wb）**。

在匀强磁场中，面积 $S$ 垂直于磁场方向放置，则

$$\Phi = BS$$

若面积 $S$ 与磁场方向不垂直，夹角为 $\theta$（$S$ 的法线方向与 $B$ 方向的夹角），则

$$\Phi = BS\cos\theta$$

即**只有「垂直于磁场方向」的有效面积 $S\cos\theta$ 贡献磁通量**——与「只有沿电场方向的分量贡献电势差」$U = EL\cos\theta$ 是同一个投影思想。<span class="marginnote">磁通量的「投影」与电势差公式 $U = Ed\cos\theta$ 的投影如出一辙：$\cos\theta$ 负责「把斜的变成直的」。记忆口诀：<strong>「穿」得越正，磁通量越大；「躺平」了（面平行于磁场），磁通量为零</strong>。一块面在磁场中「正对」磁场时磁通量最大，转 90° 后就为零——这正是一切「旋转切割磁感线」发电（发电机）的几何基础。</span>

**磁通量的含义**：直观上就是「穿过面积的磁感线条数」。磁感应强度 $B$ 大、面积 $S$ 大、面与磁场越「正对」，磁通量越大。注意 $B$ 本身就是「磁感线密度」（单位面积穿过的磁感线数），所以 $\Phi = BS$ 是「密度 × 面积」。

**单位换算**：$1\ \text{Wb} = 1\ \text{T}\cdot\text{m}^2$。

## 4 磁通量的正负与变化

磁通量是**标量**，但有正负——正负取决于面法线方向的选择：

取面的某一侧为法线正方向，磁感线从正方向穿入则 $\Phi > 0$，从反方向穿入则 $\Phi < 0$。
**穿过一个封闭面的总磁通量为零**（磁场线闭合，进多少出多少）——这是磁场「无磁单极子」的数学表达，也是高斯定理的磁场版。<span class="marginnote">「闭合面的总磁通量为零」是磁场与电场最深刻的差别之一：闭合面内若有电荷，电场线有「源」有「汇」，总电通量不为零；但磁感线永远闭合、无源无汇，穿进闭合面的磁感线必然从另一处穿出，总磁通量恒为零。这个「$\oint \vec B\cdot d\vec A = 0$」在第二级会写成麦克斯韦方程组的一条——它正是「磁单极子不存在」的数学形式。</span>

**磁通量的变化量**：$\Delta\Phi = \Phi_2 - \Phi_1$。引起磁通量变化的方式有三种：

1. **$B$ 变**：磁场强弱变化（如磁铁靠近/远离）。
2. **$S$ 变**：面积变化（如回路形状改变）。
3. **$\theta$ 变**：面与磁场的夹角变化（如线圈转动）。

**辨析｜易错点：** 磁通量是标量，正负只代表方向约定。若面翻转 180°（法线方向反了），$\Phi$ 从正变负，$\Delta\Phi = -BS - BS = -2BS$——**变化量要带符号算**。很多同学算「磁通量变化」时只算绝对值差，漏了翻转引起的符号变化，导致感应电动势方向判断错误。

## 5 公式解析：Φ = BScosθ

$$\Phi = BS\cos\theta$$

拆三步看：

- **第一步，读符号**：$B$ 是磁感应强度，$S$ 是面积，$\theta$ 是面法线与磁场的夹角。$\Phi$ 单位韦伯，$1\ \text{Wb} = 1\ \text{T·m}^2$。
- **第二步，投影的几何意义**：把面积 $S$ 投影到「垂直于磁场」的平面，投影面积 $S\cos\theta$——磁感线「实际穿过」的正是这个投影。$\theta = 0°$ 时 $\Phi = BS$（最大），$\theta = 90°$ 时 $\Phi = 0$（躺平，磁感线沿面掠过不穿过）。<span class="marginnote">「磁通量 = 磁感线穿过面的条数」是最直接的图像：想象磁感线是一束平行光线，一个框框举在光路里——框正对光（垂直）时「接住」的光最多，转个角度后「接住」的光按 $\cos\theta$ 减少。光通量与磁通量共享同一个 $\cos\theta$，因为都是「穿过的线的条数」。</span>
**第三步，为什么 $B$ 是「磁感线密度」**：$B = \Phi/S$（垂直时），即单位面积穿过的磁感线数——这正是磁感线「疏密表示强弱」的定量说法。磁感线越密，$B$ 越大。
**第四步，变化量的三来源**：$\Delta\Phi = \Delta(BS\cos\theta)$——三个因子任一变化都改变磁通量。判断「有没有磁通量变化」，就问「$B$、$S$、$\theta$ 变没变」。

## 6 磁通量与电磁感应的预告

磁通量这个量之所以重要，是因为**电磁感应的核心就是「磁通量的变化」**。下一节的电磁感应现象会揭示：闭合回路中产生感应电流的条件，正是**穿过回路的磁通量发生变化**。

于是「磁通量」成为连接「磁场」与「电」的枢纽：

磁通量**不变** → 无感应电流（磁场恒定，静磁场不产生电场）。
磁通量**变化** → 产生感应电动势（变化的磁场激发电场）。

而「磁通量变化快不快」决定感应电动势大小——这将在选择性必修二《法拉第电磁感应定律》里定量化（$E = \Delta\Phi/\Delta t$）。本节先把「磁通量」这个量本身弄扎实，它是整个电磁感应大厦的地基。<span class="marginnote">电磁感应的发现（法拉第，1831 年）是工业文明的转折点：从那时起，机械能可以大规模转化为电能。而「变化的磁通量生电」正是发电机（转动线圈切割磁感线、$\theta$ 连续变化）与变压器（交变电流让 $B$ 周期变化）的全部原理。本节学的 $\Phi = BS\cos\theta$，就是发电机的几何语言。</span>

## 7 辨析｜易错点

- **$B$ 与 $E$ 的力定义不同**：$E$ 用静止试探电荷定义，$B$ 用电流元定义。磁场对静止电荷无力。
- **$F = BIL$ 要垂直**：电流方向与磁场垂直时力最大；平行时力为零；一般 $F = BIL\sin\theta$。
- **磁通量是标量但有正负**：正负由法线方向约定；翻转面时变化量要带符号。
- **磁通量「垂直分量」才贡献**：$\Phi = BS\cos\theta$，$\theta$ 是法线与磁场的夹角。把「$S$ 正对磁场」与「$S$ 平行磁场」的磁通量搞混是常见错误。
- **闭合面的总磁通量为零**：磁感线闭合，进多少出多少。
- **磁通量变化的三途径**：$B$ 变、$S$ 变、$\theta$ 变，任一变化都能引起感应。

## 8 小结

- **磁感应强度**：$B = F_{\max}/(IL)$，单位特斯拉（T），矢量；方向 = 小磁针 N 极指向。
- **磁通量**：$\Phi = BS\cos\theta$，单位韦伯（Wb），标量（有正负）；穿过面的磁感线条数。
- **投影思想**：只有垂直于磁场的面积分量贡献磁通量。
- **闭合面总磁通量为零**：磁感线闭合，无磁单极子。
- **磁通量变化三途径**：$B$ 变、$S$ 变、$\theta$ 变——这是电磁感应的触发条件。
- 与电场强度 $E$ 平行对照：场都用「对试探物的力」定义，但磁场对静止电荷无力。

在下一节，我们见证电磁学的核心发现：**电磁感应现象及应用**。闭合回路磁通量变化，回路中就产生感应电流——「磁生电」让机械能变电能，发电机、变压器由此而来。这将是选择性必修二整章的起点。
