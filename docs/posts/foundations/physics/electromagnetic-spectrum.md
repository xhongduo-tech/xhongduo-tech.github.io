## 为什么从电磁波谱开始

前几节学了电磁波——光是电磁波、无线电是电磁波。它们频率不同，但本质相同。把所有电磁波按频率（波长）排列起来，就得到**电磁波谱（electromagnetic spectrum）**：从频率最低的无线电波到频率最高的 γ 射线，横跨约 20 个数量级。这张「谱」是电磁学的总结性地图，也是天文学、医学、通信各领域「按谱索骥」的工具。

电磁波谱的规律非常清晰：**频率越高，波长越短，光子能量越大**（$E = hf$）。频率决定了电磁波的产生方式、传播特性、与物质的相互作用——所以每种频段都有独特的应用。<span class="marginnote">「电磁波谱 = 频率（能量）的地图」：$c = \lambda f$ 让频率与波长互锁，$E = hf$ 让频率直接对应光子能量。看谱图记住三句话：<strong>频率越高 → 波长越短 → 能量越大</strong>。这「一个方向、三个递增」，是整个电磁波谱的骨架。可见光只是其中极窄的一段（400–760 nm）——人类的眼睛，只开了宇宙电磁波谱上的一条小缝。</span>

学这一节，请抓住：**电磁波谱的排列、各频段的特点与应用、频率决定能量的规律**。

## 1 电磁波谱的排列

电磁波谱按频率从低到高（波长从长到短、能量从低到高）：

| 频段 | 频率范围 | 波长范围 | 产生方式 | 主要应用 |
| --- | --- | --- | --- | --- |
| 无线电波 | $<3\times10^9\ \text{Hz}$ | $>0.1\ \text{m}$ | LC 振荡电路 | 广播、通信、雷达 |
| 微波 | $3\times10^9$–$3\times10^{11}$ Hz | 1 mm–0.1 m | 微波器件 | 微波炉、卫星通信、5G |
| 红外线 | $3\times10^{11}$–$4\times10^{14}$ Hz | 760 nm–1 mm | 热辐射 | 遥控、热成像、夜视 |
| 可见光 | $4\times10^{14}$–$8\times10^{14}$ Hz | 400–760 nm | 原子发光 | 视觉、光纤通信 |
| 紫外线 | $8\times10^{14}$–$3\times10^{16}$ Hz | 10–400 nm | 原子发光（高能） | 杀菌、验钞、医学 |
| X 射线 | $3\times10^{16}$–$3\times10^{19}$ Hz | 0.01–10 nm | 高速电子轰击 | 医学影像、安检、晶体学 |
| γ 射线 | $>3\times10^{19}$ Hz | $<0.01\ \text{nm}$ | 原子核衰变 | 放疗、探伤、天文 |<span class="marginnote">「产生方式随频率升高而升级」是电磁波谱的内在逻辑：低频（无线电、微波）由「电路振荡」产生（LC 电路、微波器件），中频（红外、可见、紫外）由「原子中电子的能级跃迁」产生，高频（X 射线）由「高速电子轰击靶」产生，最高频（γ 射线）由「原子核衰变」产生。产生机制的不同，也解释了为什么高频电磁波「更危险」——它们与物质作用更强。</span>

## 2 频率决定能量的规律

**电磁波的能量与频率的关系**（光子能量，见《能量量子化》）：

$$E = hf = h\frac{c}{\lambda}$$

- 频率越高 → 光子能量越大。
- 波长越短 → 光子能量越大。
- 能量随频率线性增长。

**这个规律决定了一切**：

- **低频（无线电、微波）**：光子能量低，与物质作用弱——适合「传信息」（不易伤害物质）。
- **高频（X 射线、γ 射线）**：光子能量高，能电离物质（破坏分子键）——用于「处理物质」但需防护。

**辨析｜易错点：** 频率越高能量越大，但「光强」不等于「能量」——强光是「光子数多」，不是「光子能量大」。弱 X 射线（光子少但每个能量高）与强可见光（光子多但每个能量低）——X 射线单个光子能量远高于可见光光子。<span class="marginnote">「单光子能量 vs 光子数量」的区别是理解电磁波谱「危险度」的关键：X 射线、γ 射线「危险」不是因为它「亮」，而是每个光子能量高——一个高能光子就能打断分子键、电离原子。可见光即使很亮（光子多），单个光子能量低，打不断化学键。「能量看频率、数量看强度」——这为下一章《光电效应》埋下伏笔（光电效应正是「单光子能量够不够」的问题）。</span>

## 3 各频段的应用与特性

**无线电波与微波**：频率低、波长长、能量低——主要做「信息传输」。中波绕射远传、微波视距中继。微波还用于加热（水分子共振）、雷达测距。

**红外线**：一切温度高于绝对零度的物体都辐射红外线（热辐射），温度越高辐射越强。应用：遥控器（红外信号）、热成像（体温检测、夜视仪）、红外测温。

**可见光**：人眼能感知的频段。应用：视觉、照明、光纤通信（光信号）、激光。

**紫外线**：能量较高，能杀菌（破坏微生物 DNA）、使荧光物质发光（验钞）、促进维生素 D 合成；过量则伤皮肤（晒伤、致癌）。<span class="marginnote">「温度越高，辐射波长越短」是热辐射的规律（维恩位移定律）：常温物体主要辐射红外线（热成像仪就是「看红外」），高温物体开始发光（烧红的铁辐射红光），极高温发出蓝白光（白炽灯丝）。这也是「红外测温」的原理——测物体辐射的红外线强度，反推温度。从体温计到天文观测，都是「靠辐射频谱测温度」。</span>

**X 射线**：能量高，能穿透软组织（被骨骼/金属吸收）——医学影像（拍片、CT）、安检（行李扫描）、X 射线晶体学（测结构）。过量伤害细胞。

**γ 射线**：能量最高，穿透力极强——癌症放疗（杀灭癌细胞）、工业探伤、γ 射线天文（伽马暴观测）。需严格防护。

## 4 电磁波谱与科学前沿

电磁波谱是天文、物理、医学的「探测窗口」：

**射电天文**：用无线电波观测宇宙（射电望远镜、FAST 中国天眼）——看见不发光的冷天体。
**红外天文**：看冷尘埃、恒星形成区。
**X 射线与 γ 射线天文**：看黑洞、中子星、伽马暴等极端天体。
**宇宙微波背景辐射**：微波段的「宇宙化石」——大爆炸的余晖，WMAP/普朗克卫星测量它揭示宇宙的年龄与组成。<span class="marginnote">「每个频段都是宇宙的一扇窗」：肉眼只看得见可见光，但天体在几乎所有频段都辐射——射电望远镜看脉冲星、X 射线望远镜看黑洞吸积盘、γ 射线望远镜看伽马暴。多频段观测（多信使天文学）是现代天文学的常态：同一个天体，在不同频段的「样子」拼出完整画像。「电磁波谱」从一张「频率表」变成「看宇宙的多彩眼镜」。</span>

**辨析｜易错点：** 电磁波谱是**连续**的——各频段之间没有「空档」，划分只是人为命名。可见光与红外之间没有「看不见的裂缝」，只是人眼对频段的敏感范围有限。「可见光以外没有电磁波」是错的——恰恰相反，可见光只是沧海一粟。

## 5 公式解析：E = hf = hc/λ

$$E = hf = h\frac{c}{\lambda}$$

拆三步看：

- **第一步，能量的频率依赖**：光子能量与频率成正比（$E = hf$，$h$ 是普朗克常量）——频率越高，单个光子能量越大。电磁波谱从低到高，就是「光子能量从低到高」的排列。<span class="marginnote">$E = hf$ 把「电磁波谱」与「能量」直接挂钩：无线电光子能量约 $10^{-24}$ J 量级（微不足道）、γ 光子能量约 $10^{-13}$ J 量级（可电离原子）。相差 11 个数量级——这就是「无线电安全、γ 射线危险」的能量根源。量子物理里电磁波谱的「位置」就是「光子能量」的大小。</span>
- **第二步，波长与能量反比**：由 $c = \lambda f$，$E = hc/\lambda$——波长越短能量越大。γ 射线波长短、能量高；无线电波波长长、能量低。
- **第三步，能量与作用的对应**：光子能量 < 化学键能 → 只能「温和」作用（加热、传信息）；光子能量 > 电离能 → 能电离物质（辐射伤害）。分界线大致在紫外线附近——紫外线及以上能电离（电离辐射），以下不能。
- **第四步，数值感受**：可见光光子约 2–3 eV（1 eV = $1.6\times10^{-19}$ J）；X 射线光子约 100 eV–100 keV；γ 光子 > 100 keV。eV 是原子物理的常用能量单位，下一章会频繁使用。

## 6 辨析｜易错点

- **频率越高 → 波长越短 → 能量越大**：一个方向三个递增，别记反。
- **电磁波谱连续**：各频段人为划分，无空档。
- **「亮」不等于「能量大」**：光子数量管强度、单光子能量管频率。
- **电离辐射分界在紫外附近**：紫外及以上能电离、有辐射危害。
- **可见光是极窄的一段**：人眼只见沧海一粟。
- **产生方式随频率升级**：电路振荡 → 原子发光 → 核衰变。

## 7 小结

- **电磁波谱**：无线电波 → 微波 → 红外 → 可见 → 紫外 → X 射线 → γ 射线。
- **规律**：频率越高、波长越短、能量越大（$E = hf$）。
- **产生方式**：电路振荡（低频）→ 原子发光（中频）→ 核衰变（高频）。
- **应用**：通信（低频）、热成像（红外）、杀菌（紫外）、医学影像（X）、放疗（γ）。
- 每个频段都是观测宇宙与改造物质的一扇窗。
- 可见光只是电磁波谱的一小段，光与无线电同本质。
