## 为什么从气体的等压变化和等容变化开始

上一节玻意耳定律研究了「温度不变时压强与体积」的关系。这一节补齐另外两种「一个量不变」的情形：**等压变化**（压强不变，体积与温度的关系，盖-吕萨克定律）与**等容变化**（体积不变，压强与温度的关系，查理定律）。

三条气体实验定律——玻意耳、查理、盖-吕萨克——把 $p$、$V$、$T$ 两两之间的关系全部厘清。它们的共同点是：**温度用热力学温度，且「某一对量成正比/反比」**。拼起来就是下一章的理想气体状态方程 $pV = nRT$。<span class="marginnote">「三条定律的控制变量」：玻意耳固定 $T$ 看 $p$-$V$（反比）、查理固定 $V$ 看 $p$-$T$（正比）、盖-吕萨克固定 $p$ 看 $V$-$T$（正比）。三条定律统一表述：<strong>气体定律都用热力学温度，且「固定一个量、另外两个成正比或反比」</strong>。查理定律的微观图像：体积不变 → 密度不变 → 温度升高 → 分子动能增大 → 撞击更猛 → 压强增大（$p \propto T$）。</span>

学这一节，请抓住：**查理定律（$p \propto T$）与盖-吕萨克定律（$V \propto T$）的内容与图像**。

## 1 查理定律：等容变化

**查理定律**：一定质量的某种气体，在**体积不变**的情况下，压强 $p$ 与热力学温度 $T$ 成正比。

$$\frac{p}{T} = C \quad \text{或} \quad \frac{p_1}{T_1} = \frac{p_2}{T_2}$$

**关键理解**：

- 体积不变 → 分子数密度不变 → 碰撞频率不变。
- 温度升高 → 分子平均动能增大 → 每次碰撞更强 → 压强增大。
- 压强与热力学温度成正比（用 $T$，不是摄氏温度 $t$）。

**辨析｜易错点：** 查理定律用的是**热力学温度** $T$（K）。若用摄氏温度，压强与温度**不是**正比（是线性但不过原点：$p \propto T = t + 273.15$）。「压强与摄氏温度成正比」是错的——必须换成热力学温度。<span class="marginnote">「为什么必须用热力学温度」：查理定律 $p/T$ 常数要求「$T = 0$ 时 $p = 0$」——用摄氏温度时 $t = 0$ ℃ 对应 $p \neq 0$，不成正比。而热力学温度的零点（绝对零度）恰好是「分子热运动停止、压强为零」处，$p$-$T$ 直线过原点——所以用热力学温度，$p \propto T$ 严格成立。这就是热力学温标在气体定律里的必要性。</span>

## 2 盖-吕萨克定律：等压变化

**盖-吕萨克定律**：一定质量的某种气体，在**压强不变**的情况下，体积 $V$ 与热力学温度 $T$ 成正比。

$$\frac{V}{T} = C \quad \text{或} \quad \frac{V_1}{T_1} = \frac{V_2}{T_2}$$

**关键理解**：

- 压强不变 → 要保持压强不变，温度升高时体积必须增大（密度减小、碰撞频率降低，恰好抵消动能增大）。
- 体积与热力学温度成正比：温度升高，体积增大（热胀冷缩的气体版）。

**微观解释**：温度升高 → 分子动能增大 → 压强趋于增大 → 要让压强不变，必须增大体积（分子变稀、碰撞变少）——体积增大「抵消」动能增大，压强维持恒定。<span class="marginnote">盖-吕萨克定律的「抵消」图像：温度升高让每个分子撞得更猛（压强↑），体积增大让分子变稀、撞得少（压强↓）——两者精确抵消，压强不变。所以「等压加热 → 体积膨胀」不是「气体自己膨胀」，而是「为了保持压强不变必须让体积跟上温度」。这个「互相抵消保持平衡」的思想，在热力学里反复出现。</span>

## 3 三条定律的图像对比

三条气体定律的图像，用「固定一个量、看另外两个」的思路：

| 定律 | 固定量 | 关系 | 图像 |
| --- | --- | --- | --- |
| 玻意耳（等温） | 温度 $T$ | $p \propto 1/V$ | $p$-$V$ 双曲线 |
| 查理（等容） | 体积 $V$ | $p \propto T$ | $p$-$T$ 过原点直线 |
| 盖-吕萨克（等压） | 压强 $p$ | $V \propto T$ | $V$-$T$ 过原点直线 |

**图像记忆**：

**$p$-$V$ 图**：等温线是双曲线。
**$p$-$T$ 图**：等容线是过原点的直线（斜率 $p/T$，体积不同斜率不同）。
**$V$-$T$ 图**：等压线是过原点的直线（压强不同斜率不同）。

**辨析｜易错点：** $p$-$T$ 与 $V$-$T$ 图是**过原点的直线**（用热力学温度）——直线不过原点说明温度用了摄氏温标或图像近似。判断「等容还是等压」看图中是哪两条线：$p$-$T$ 图上的线是等容线（每条线对应一个体积），$V$-$T$ 图上的线是等压线。<span class="marginnote">「$p$-$T$ 图斜率对应体积的倒数」：$p = (p/T)T$，斜率 $k = p/T = nR/V$（常数），所以斜率与体积成反比——斜率大的线体积小。同理 $V$-$T$ 图斜率 $k = V/T = nR/p$，与压强成反比——斜率大的线压强小。读图比较「哪条线体积大、压强大」用斜率判断。</span>

## 4 气体定律的综合应用

三条定律可以组合成复杂过程（多过程问题）：气体经历「等温 → 等容 → 等压」等多段变化，每段用对应的定律，状态参量逐步追踪。

**解题流程**：

1. 明确气体的**质量不变**（无漏气、无充气）。
2. 分段确定「每段是等温/等容/等压」。
3. 每段列出初末状态，用对应的定律列方程。
4. 把上一段的末状态作为下一段的初状态——「状态追踪」。
5. 最终用「理想气体状态方程」（下一章）可统一求解。

**例**：一定质量气体从状态 A（$p_1$、$V_1$、$T_1$）等温变化到 B（$p_2$、$V_2$），再等容变化到 C。A→B 用玻意耳（$p_1V_1 = p_2V_2$），B→C 用查理（$p_2/T_2 = p_3/T_3$），逐步求出未知量。<span class="marginnote">「多过程 = 逐段定律 + 状态衔接」是气体综合题的通用解法：把复杂过程拆成几段简单过程（等温、等容、等压），每段用一条定律，段与段之间「末状态 = 下一段初状态」。这个「拆段 + 衔接」的思路，与力学里「分段受力分析」、电学里「逐级化简」异曲同工——复杂问题化整为零。</span>

## 5 公式解析：查理定律 p₁/T₁ = p₂/T₂

$$\frac{p_1}{T_1} = \frac{p_2}{T_2}$$

拆三步看：

- **第一步，为什么 $p \propto T$**：体积不变 → 分子数密度不变 → 压强 $\propto$ 分子平均动能 $\propto T$（因为 $\overline{E_k} = \tfrac32 kT$）——$p \propto T$ 直接从「压强 ∝ 平均动能」推出。<span class="marginnote">「$p \propto T$ 的微观链条」：体积不变 → 密度不变 → 碰撞频率不变；温度升高 → 平均动能增大 → 每次碰撞更强 → 压强增大。所以压强正比于「碰撞的强度」正比于「平均动能」正比于「温度」。这个链条把查理定律归结为「温度是平均动能的标志」。</span>
- **第二步，热力学温度的必要性**：$p/T$ 常数要求「$T = 0$ 时 $p = 0$」——只有热力学温度（绝对零度处压强为零）满足。摄氏温度 $t = 0$ ℃ 时 $p \neq 0$，不成正比。
- **第三步，量纲与单位**：$T$ 用 K（热力学温度），$p$ 单位前后一致。注意「$t$ 是摄氏温度」时不能直接用 $p/t$ 常数——先换算 $T = t + 273.15$。
- **第四步，图像判断**：$p$-$T$ 图过原点的直线是等容线；不同体积对应不同斜率（体积小斜率大）。

## 6 辨析｜易错点

- **用热力学温度**：$T = t + 273.15$，别用摄氏温度代入查理/盖-吕萨克定律。
- **查理 $p \propto T$、盖-吕萨克 $V \propto T$**：都「与热力学温度成正比」，别记反固定量。
- **$p$-$T$、$V$-$T$ 图过原点**：用热力学温度才是直线过原点。
- **多过程拆段**：每段定律 + 末状态衔接下一段。
- **质量一定**：漏气/充气不能用单条定律直接算。
- **斜率判体积/压强**：$p$-$T$ 图斜率大体积小、$V$-$T$ 图斜率大压强小。

## 7 小结

- **查理定律（等容）**：$p \propto T$，$p_1/T_1 = p_2/T_2$。
- **盖-吕萨克定律（等压）**：$V \propto T$，$V_1/T_1 = V_2/T_2$。
- **微观解释**：体积不变时压强随平均动能（温度）增大；等压时体积膨胀抵消动能增大。
- **图像**：$p$-$T$ 等容线、$V$-$T$ 等压线——都过原点的直线（热力学温度）。
- **多过程**：拆段 + 状态衔接，逐段用定律。
- 三条气体定律 + 理想气体方程（下一章）构成完整的气体理论。

- **盖-吕萨克定律**：压强不变，$V/T$ = 常数——$V$ 与热力学温度 $T$ 成正比。
- **查理定律**：体积不变，$p/T$ = 常数——$p$ 与 $T$ 成正比。
- **热力学温标**：两定律中的温度必须用 K（$T = t + 273.15$），不能用摄氏温度直接代入。
- 把这个结论与上一节对照，你会发现「变化率」与「变化量」的差别贯穿物理。
- 理论的价值在应用：把本节公式代入一个数字算例，比背十遍更牢靠。

- 做题时先问「物理图像是什么」，再动笔算——直觉在前、符号在后。
