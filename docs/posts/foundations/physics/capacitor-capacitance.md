## 为什么从电容器的电容开始

前面十节我们研究「电荷在电场中受力与含能量」，主角都是「点」——点电荷、电场中的点、两点间的电势差。这一节的主角换成「面」：**电容器**，一种能储存电荷与电场能量的器件。它由两块导体（极板）隔着绝缘介质组成，是电路里三大基本无源元件之一（电阻、电容、电感）。

电容器的意义远超一个「元件」。它把本章所有概念——电场、场强、电势差、电势能、匀强电场——全部收拢进一个可以摸、可以测的器件：两板间是匀强电场（$E = U/d$），两板间的电压是电势差（$U$），储存的能量是电场能（$\tfrac{1}{2}CU^2$）。手机、电脑、相机里处处是电容：电源滤波、信号耦合、储能缓冲。<span class="marginnote">电容器的微观秘密在于「电荷的暂存」：它存储的不是电流，而是「电荷的分离」——正电荷聚集在一板、负电荷聚集在另一板，中间隔着绝缘介质，正负电荷无法中和，于是能量被「锁」在电场里。这种「存储电场能」的能力，让电容成为电路里储存与释放能量的关键器件，也是第十二章《电路中的能量转化》的重要配角。</span>

学这一节，记住三件事：**电容的定义 $C = Q/U$ 与「电容由器件本身决定」、平行板电容的公式与决定因素、电容器的充放电与储能**。这三个层次从定义到应用，缺一不可。

## 1 电容：定义与物理意义

给电容器两极板加上电压 $U$，两板分别带上等量异种电荷，电荷量 $Q$ 与电压 $U$ 成正比（实验事实）。比值 $Q/U$ 是一个**与电压无关、只由电容器本身决定**的量，定义为**电容（capacitance）**：

$$C = \frac{Q}{U}$$

- **物理意义**：电容描述电容器**储存电荷（储存电场能量）本领的大小**——电压每升高 1 伏，能多储存多少电荷。
- **单位**：法拉（F），$1\ \text{F} = 1\ \text{C}/\text{V}$。法拉单位很大，实际常用微法（$\mu\text{F}$，$10^{-6}\ \text{F}$）、皮法（pF，$10^{-12}\ \text{F}$）。<span class="marginnote">法拉（Farad）纪念英国物理学家法拉第。1 F 是巨大的电容——把两个相距一毫米、面积约一平方公里的平行板叠起来才约 1 F。所以电子电路里的电容几乎都用 $\mu\text{F}$、$\text{nF}$、$\text{pF}$ 标称。超市里 4700 $\mu\text{F}$ 的电容已经算「大水桶」，用来给电源滤波稳压。</span>

**辨析｜易错点：** $C = Q/U$ 是**定义式**，不是决定式。电容 $C$ 由电容器的**结构**决定（极板面积、间距、介质），与是否带电 $Q$、电压 $U$ 无关。把「电容随 $Q$ 增大而增大」当成结论，是本节第一误区——就像电阻 $R = U/I$ 是定义式，电阻由材料与形状决定，不随电压电流变。**「定义式 ≠ 决定式」**，这个区别在电路章节会反复考到。

## 2 平行板电容器的电容

最常见的电容器是**平行板电容器**：两块正对、平行的金属板，中间隔以绝缘介质（空气、陶瓷、云母等）。其电容由三个因素决定：

$$C = \frac{\varepsilon S}{4\pi k d}$$

其中 $\varepsilon$ 是介质相对介电常数（真空为 1），$S$ 是极板正对面积，$d$ 是极板间距，$k$ 是静电力常量。为便于记忆与解题，常写成比例式：

$$C \propto \frac{\varepsilon S}{d}$$

**电容与正对面积成正比、与极板间距成反比、与介质有关**：<span class="marginnote">这三个「决定因素」是电容题的绝对核心：<strong>面积 $S$ 大 → 电容大（能多「装」电荷）；距离 $d$ 小 → 电容大（电场更强、电势差更小）；介质介电常数 $\varepsilon$ 大 → 电容大（介质极化削弱电场，同样电压能存更多电荷）</strong>。判断「改变什么、电容怎么变」的题，都是这三个因素在考。</span>

**增大正对面积 $S$**：电容增大——更大的「电荷容量」。
**减小极板间距 $d$**：电容增大——两板间电场更集中。
**插入介电常数大的介质**：电容增大——介质极化降低了板间电场强度，相同电压下能储存更多电荷。

**辨析｜易错点：** 平行板电容的公式 $C = \varepsilon S/(4\pi kd)$ 是**决定式**，只对「平行板」成立。球形电容器、圆柱形电容器公式不同（第二级内容）。高中阶段提到「电容器的电容」，默认就是平行板，但概念上要清楚公式的适用范围。

## 3 平行板电容器的两类动态问题

电容器接在电路中，有两类经典动态问题，判断依据是「什么量不变」：

**类型一：始终接在电源上（$U$ 不变）**

电容器两极板始终与电源相连，电压 $U$ 恒等于电源电压。此时：

改变 $d$ 或 $S$ 或 $\varepsilon$ → 由 $C \propto \varepsilon S/d$ 判断 $C$ 怎么变。
由 $Q = CU$ 判断电荷量（$U$ 不变，$C$ 变则 $Q$ 变）。
由 $E = U/d$ 判断场强（$U$ 不变，$d$ 变则 $E$ 变）。<span class="marginnote">「接电源」类型的关键抓手是 $U$ 固定。比如把板间距 $d$ 增大，$C$ 减小、$Q$ 减小（电荷回流电源）、$E$ 减小——三者连锁反应全由「$U$ 不变」驱动。做题顺序永远是：先写不变的量，再用公式推变化的量。</span>

**类型二：充电后断开电源（$Q$ 不变）**

电容器充电后与电源断开，电荷无法流动，$Q$ 恒定。此时：

改变 $d$ 或 $S$ → $C$ 变，由 $U = Q/C$ 推 $U$。
场强由 $E = U/d = Q/(Cd)$ 推——**关键结论：断开电源时，只改变板间距 $d$，场强 $E$ 不变**（因为 $Q$、$S$、$\varepsilon$ 都不变时 $Q/(Cd)$ 与 $d$ 无关）。<span class="marginnote">「断开电源时场强与 $d$ 无关」是一个反直觉但高频的结论：$E = U/d$ 里 $U$ 与 $d$ 同步变化（$U = Q/C \propto d$），商 $E$ 保持恒定。推导：$C \propto 1/d$，$U = Q/C \propto d$，$E = U/d = $ 常数。记住「$Q$ 不变时，只有面积和介质变才会改变 $E$，间距变不改变 $E$」。</span>

**解题流程**：看清「$U$ 不变」还是「$Q$ 不变」→ 写三个公式 $C \propto \varepsilon S/d$、$Q = CU$、$E = U/d$ → 逐个推导。

## 4 电容器的充放电与储能

电容器的核心工作方式是**充电**与**放电**：

**充电**：电源把电荷送到两极板，正电荷堆积在一板、负电荷在另一板，板间建立电场，储存电场能。充电过程中，电流**逐渐减小**（板间电压越来越接近电源电压，推动电荷的动力减小），直至板间电压等于电源电压，电流归零。<span class="marginnote">充电电流为什么逐渐减小？可以把「充进去的电压」想象成「水库水位」，电源电压是「上游水位」，压差 = 电源电压 − 板间电压。随着板间电压逼近电源电压，压差趋零，充电电流指数衰减。这个「指数衰减」的图像在电磁振荡（选择性必修二）里还会出现——充放电的节奏由「电容 × 电阻」时间常数 $RC$ 决定。</span>
- **放电**：用导线接通两极板，板间电荷通过导线中和，电场能转化为电路中的能量（如果接电阻，转化为焦耳热；接灯泡，发光；接电机，转起来）。放电电流方向与充电相反。

**储存的能量**：电容器充电到电压 $U$、带电荷 $Q$ 时，储存的电场能为

$$W = \frac{1}{2}QU = \frac{1}{2}CU^2 = \frac{Q^2}{2C}$$

推导与弹簧势能同构：充电是「把电荷一点点搬到板上」，电压从 0 线性升到 $U$，$U$-$Q$ 图是过原点的直线，三角形面积 $\tfrac{1}{2}QU$ 就是储能。<span class="marginnote">「$\tfrac{1}{2} \times$ 刚度 $\times$ 变量平方」是线性系统储能的通用公式：弹簧弹性势能 $\tfrac{1}{2}kx^2$、电容器储能 $\tfrac{1}{2}CU^2$、电感储能 $\tfrac{1}{2}LI^2$（选择性必修二）——全是一个模式。看到 $\tfrac{1}{2} \cdot \text{刚性} \cdot \text{广义坐标}^2$，你就知道这是一个「线性存储元件」。</span>

数字例子：手机闪光灯的电容器 $C = 100\ \mu\text{F} = 10^{-4}\ \text{F}$，充电到 $U = 300\ \text{V}$，储能 $W = \tfrac{1}{2}\times10^{-4}\times(300)^2 = 4.5\ \text{J}$——足够驱动闪光管闪一次。4.5 J 看似不大，但全部在毫秒内释放，瞬时功率上千瓦，这就是「电容器能瞬间放电产生大功率」的原因。

## 5 公式解析：C = Q/U 与 W = ½CU²

$$C = \frac{Q}{U}, \qquad W = \frac{1}{2}CU^2$$

拆三步看：

- **第一步，$C = Q/U$ 是定义式的深意**：它说「在 1 伏电压下能存多少库仑电荷」。注意 $Q$ 是**一块极板**上的电荷量（两板等量异种，总量其实是 2Q，但约定取单板电量）。$C$ 的单位法拉 $1\ \text{F} = 1\ \text{C}/\text{V}$。
- **第二步，为什么 $C$ 与 $Q$、$U$ 无关**：实验与理论都表明，对固定电容器，$Q$ 与 $U$ 成正比，比值恒定。$C$ 只由几何结构与介质决定（$C \propto \varepsilon S/d$）。「$C$ 由结构决定」这句话是电学里「定义式 vs 决定式」的又一实例，与场强 $E = F/q$、电阻 $R = U/I$ 一脉相承。<span class="marginnote">这三个「定义式 vs 决定式」的对子值得一起记：$E = F/q$（定义）对 $E = kQ/r^2$（决定），$R = U/I$（定义）对 $R = \rho L/S$（决定），$C = Q/U$（定义）对 $C \propto \varepsilon S/d$（决定）。掌握这个模式，物理概念基本就立住了。</span>
- **第三步，储能公式 $\tfrac{1}{2}CU^2$ 的推导直觉**：把「充电」看成「从零开始，逐步搬运电荷」。第 $q$ 库仑被搬到电压 $U_q$ 的板上，需要能量 $U_q\,dq$。电压随电荷线性增长（$U = q/C$），把 $0$ 到 $Q$ 的所有微元相加，就是 $\int_0^Q (q/C)\,dq = Q^2/(2C) = \tfrac{1}{2}CU^2$。几何上这是直线下的三角形面积。
- **第四步，为什么「瞬间大功率」**：储能 $W$ 与体积、成本直接相关；而「多快释放」取决于放电回路的时间常数。电容能在微秒级把存储的电场能倾泻出来，瞬时功率 $P = W/t$ 极大——闪光灯、雷击防护、电焊机都靠这个「瞬间倾泻」能力。

## 6 电容器的实际应用

电容器在电路中无处不在，理解「储电荷、储能量」这个核心，就能理解它的各种用法：

- **滤波（稳压）**：电源输出有纹波（电压波动），并联一个大电容，当电压升高时电容充电「吸收」，电压降低时电容放电「补充」——把波动的电压「抹平」。这是电脑主板、手机充电器里最常见电容的用途。
- **耦合与隔直**：串联一个电容，直流过不去（电容不通直流）、交流能通过（充放电形成电流）——分离信号中的交流与直流成分。音频电路、放大器用它传递信号、隔离偏置。
- **储能**：闪光灯、电动玩具、电容储能焊机——需要短时大功率时，电容先慢慢充电、再瞬间释放。
- **调谐**：与电感配合，构成谐振电路，选频——收音机的调台就是改变电容大小来「选中」特定频率（见选择性必修二《电磁振荡》）。

**辨析｜易错点：** 电容器**不能通过稳定直流**（两极板间是绝缘介质，电荷无法穿越），但它能在「电压变化」时通过「充放电」在电路中形成电流。所以电容有「隔直流、通交流」的特性。把「电容能通过直流」当结论，是电路认知的常见错误——这要到第十一章《串联电路和并联电路》与交变电流（选择性必修二）里才能完全展开。

## 7 小结

- **电容**：$C = Q/U$，定义式，单位法拉（F），描述储存电荷的本领；由器件结构决定。
- **平行板电容决定式**：$C \propto \varepsilon S/d$——面积大、间距小、介质介电常数大，则电容大。
- **动态问题**：接电源 $U$ 不变，断开电源 $Q$ 不变；断开时只变 $d$ 则 $E$ 不变。
- **充放电**：充电电流逐渐减小至零，放电释放电场能；储能 $W = \tfrac{1}{2}CU^2$。
- **应用**：滤波、耦合隔直、储能、调谐——一切围绕「储电荷、储能量」。
- **记忆线索**：$C = Q/U$ 是定义式，$C \propto \varepsilon S/d$ 是决定式；线性系统储能都是「$\tfrac{1}{2}$ × 刚性 × 变量²」。

在下一节，我们把电容器里的匀强电场与力学结合起来：**带电粒子在电场中的运动**。电子、质子、离子在电场力作用下加速或偏转，这是示波器、电子枪、质谱仪的原理，也是「力与能量」两大主线在电学里的第一次实战。
