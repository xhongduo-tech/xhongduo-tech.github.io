## 为什么从波的描述开始

上一节我们知道了波是什么——振动在介质中的传播。但要「使用」波，必须能精确描述它：这列波多强（振幅）、多长（波长）、多快（频率、波速）、现在长什么样（波形）。这一节给波配上完整的「身份证」。

波的描述有两个核心工具：**波长、频率、波速的关系 $v = \lambda f$** 与 **波形图**。其中最容易混淆的，是「波形图（某时刻各质点位置）」与「振动图像（某质点位置随时间）」的区别——这两张图长得很像（都是正弦曲线），但横轴含义完全不同。分清它们，是波动题的第一道关。<span class="marginnote">波形图与振动图像的「双胞胎陷阱」每年都难倒一批人：<strong>波形图是「给一个时刻，看所有质点」——横轴是空间（位置）；振动图像是「给一个质点，看所有时刻」——横轴是时间</strong>。一张「全家福」、一张「个人传记」。读图第一眼先看横轴单位（m 还是 s），这是分辨二者的第一信号。</span>

学这一节，请重点攻克三件事：**四个描述量的含义、$v = \lambda f$ 的运用、波形图与振动图像的判别与互读**。

## 1 波长：相邻同相点的距离

**波长（wavelength）**：在波动中，振动相位总是相同的两个相邻质点间的距离，符号 $\lambda$，单位米。

波长也可以理解为「一个完整波形的长度」——相邻两个波峰（或波谷）之间的距离就是一个波长。

**关键结论**：

波源振动**一个周期**，波传播**一个波长**。
波长由**波速与频率共同决定**：$\lambda = v/f$。换介质时 $v$ 变、$f$ 不变，$\lambda$ 跟着变。
频率越高，波长越短（$f$ 大 → $\lambda$ 小）。

**辨析｜易错点：** 波长是「相邻**同相**点」的距离——两个波峰、两个波谷、两个同向过平衡位置的点都行。但「相邻的反相点」（波峰与波谷）之间是**半个波长**，不是波长。把「波峰到波谷」当波长是常见错误。<span class="marginnote">「半个波长」的观念在波的干涉里非常关键：波峰与波谷是反相，相距 $\lambda/2$；波峰与相邻波峰同相，相距 $\lambda$。判断「两点间是几个波长」，先看它们同相还是反相。水波两个相邻波峰的距离、声波两个相邻密部的距离，都是波长——「同相」是判据。</span>

## 2 频率、波速与波长：v = λf

三个描述量的关系（上一节已见，这里系统化）：

$$v = \lambda f = \frac{\lambda}{T}$$

**三条归属规则**（波动题的第一判断）：

1. **频率 $f$ 由波源决定**：波源怎么振，频率就多少。波传播到任何介质，频率不变。
2. **波速 $v$ 由介质决定**：同一介质中同种波，波速恒定，与频率、振幅无关。
3. **波长 $\lambda$ 由介质与波源共同决定**：$\lambda = v/f$。

**例**：声波从空气进入水中，$v$ 从 340 m/s 变到约 1500 m/s，$f$ 不变，波长变长（$\lambda = v/f$ 变大）——声音「变慢变长」。<span class="marginnote">「频率不变」是换介质问题里的锚：波源的振动频率不会因为介质改变而改变（它是「源」的属性），只有波速与波长跟着介质变。这个「谁不变、谁变」的判断，是 $v = \lambda f$ 应用的核心。电磁波进介质同理：频率不变、波速变慢、波长变短。</span>

**辨析｜易错点：** 波速 $v$ 不是质点的振动速度。波速是「波形推进」的速度（由介质决定，恒定），质点的振动速度是它自己来回运动的速度（随位置时刻变化，最快在平衡位置、最慢在最大位移处）。把「波速」当「质点速度」是最常见的概念混淆之一。

## 3 波形图与振动图像的辨析

两张图是波动描述的重中之重，用表格对照：

| 比较项 | 波形图（波动图像） | 振动图像 |
| --- | --- | --- |
| 研究对象 | 某一时刻，所有质点的位移 | 某一质点，各时刻的位移 |
| 横轴 | 位置（各质点的平衡位置） | 时间 |
| 纵轴 | 该时刻质点的位移 | 该质点各时刻的位移 |
| 物理意义 | 波在某一时刻的「快照」 | 一个质点的「传记」 |
| 读波长 | 相邻波峰间距（直接读） | 不能读波长 |
| 读周期 | 不能读周期 | 相邻波峰间距（直接读） |
| 图像形状 | 正弦（横波） | 正弦 |

**读图口诀**：看横轴——横轴是「位置」的是波形图，是「时间」的是振动图像。<span class="marginnote">波形图与振动图像的横轴单位暴露身份：<strong>m（位置）→ 波形图；s（时间）→ 振动图像</strong>。一张图能读波长（波形图）还是能读周期（振动图像），也由横轴决定。考试里常把两图并排给出，先分别标好「哪张是波形、哪张是振动」，再动手计算——顺序对了，题就顺了。</span>

**由波形图判断质点振动方向**：横波波形图里，某质点的振动方向可以用「同侧法」判断——质点的振动方向与其左方（或右方）质点的位移趋势一致；更规范的是「波形平移法」：把波形沿传播方向平移一小段，看该质点移动的方向，就是它的振动方向（下一时刻它要去的位置）。<span class="marginnote">「波形平移法」判断振动方向：把波形图沿波的传播方向平移一个小距离，质点新位置与旧位置的「上下」关系就指示了它的振动方向——波向右传，质点就向右上方/右下方「跟着波走」。这个方法的本质是「波形以波速向前推进，质点只在竖直方向振动，它现在的运动方向必须让波形保持推进」。</span>

## 4 波的图像的应用：求波长、振幅、判断方向

从一张波形图能读出：

**振幅 $A$**：波形最高（低）点离平衡位置的竖直距离。
**波长 $\lambda$**：相邻波峰（谷）的水平间距。
**某一质点的位移**：该位置对应的纵坐标。

结合振动图像（或题目给的频率/周期），能求：

波速 $v = \lambda f$ 或 $v = \lambda/T$。
某质点在某时刻的速度方向、加速度方向。
波经过多少时间传播到某位置（$t = x/v$）。

**辨析｜易错点：** 波形图只能读「波长、振幅」，振动图只能读「周期、振幅」——把周期从波形图里读、波长从振动图里读，是常见错误。两图配合时，通常「波形图给波长、振动图给周期」，两者相除得波速。<span class="marginnote">解题套路：波形图给 $\lambda$，振动图给 $T$，$v = \lambda/T$ 一步得到波速。若再给「某时刻波形」与「某质点振动」的对应关系，还能判传播方向。这种「两图对读」是波动综合题的固定题型——先标横轴、再读各量、最后 $v = \lambda f$ 串起来。</span>

## 5 公式解析：v = λf 与图像对读

$$v = \lambda f = \frac{\lambda}{T}$$

拆三步看：

- **第一步，从哪读 $\lambda$**：波形图上相邻波峰间距。若图给的是「两个波峰相隔 $n\lambda$」或「$\tfrac{3}{4}\lambda$」，先换算成 $\lambda$。
- **第二步，从哪读 $T$**：振动图像上相邻波峰间距（一个周期）。若给的是「$\tfrac{1}{4}$ 周期」「若干秒内振了若干次」，用 $f = n/t$ 求频率。<span class="marginnote">「从图像读数」的完整流程：波形图 → 读 $\lambda$ 与 $A$；振动图 → 读 $T$（或 $f$）与 $A$；$v = \lambda/T$ → 波速；再结合「某时刻波形」判断传播方向或某质点振动方向。四个量（$\lambda$、$T$、$A$、方向）齐了，波的描述就完整了。</span>
- **第三步，波速的物理**：$v = \lambda/T$ 说「波速 = 每个周期推进的距离 ÷ 周期」。它由介质决定，不随波源频率变——所以「提高频率波速变大」是错的（介质不变波速不变，变的是波长变短）。
- **第四步，单位自洽**：$\lambda$ 用 m、$T$ 用 s、$v$ 用 m/s、$f$ 用 Hz。$v$（m/s）= $\lambda$（m）× $f$（Hz）量纲正确。

## 6 辨析｜易错点

- **波形图 vs 振动图**：横轴是位置（m）还是时间（s）——先看横轴再做题。
- **波长是相邻同相点距离**：波峰到波谷是 $\lambda/2$，不是 $\lambda$。
- **波速由介质定、频率由波源定**：换介质频率不变、波长变。
- **波速 ≠ 质点振动速度**：一个是波形推进、一个是质点来回，概念不同。
- **从波形图读波长、振动图读周期**：别从波形图读周期。
- **振幅在两张图上都能读**：都是「离平衡位置的最大距离」。

## 7 小结

- **波长**：相邻同相点距离，一个周期波推进一个波长。
- **波速、频率、波长**：$v = \lambda f$；频率由波源定、波速由介质定。
- **波形图**：某一时刻全体质点的「快照」，可读波长、振幅。
- **振动图像**：某一质点的「传记」，可读周期、振幅。
- 两图对读：波形图给 $\lambda$、振动图给 $T$，$v = \lambda/T$ 得波速。
- 判断质点振动方向用「波形平移法」；先看横轴再读图。

- **波长、频率、波速**：$v = \lambda f$——波速由介质定、频率由波源定、波长由两者共同决定。
- **波形图与振动图像**：波形图是某时刻各质点位移（横轴位置），振动图像是一个质点位移随时间（横轴时间）——看轴再判图。
- 把这个结论与上一节对照，你会发现「变化率」与「变化量」的差别贯穿物理。
