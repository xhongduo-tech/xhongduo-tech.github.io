## 为什么从时间开始

上一节把「位置」变成了坐标 $x$：物体在哪儿，有了精确的「地址」。可运动是「位置随时间的变化」——这句话里藏着两个词：**位置**（已有坐标）与**时间**。物理学家讨论运动时，时间不是感觉里「过得好快」，而是刻度尺上的一个数，是可以代进公式的量。

这一节做两件事：把时间也说清（**时刻**与**时间间隔**），把「位置变化」说准（**位移**）。位置变化量 $\Delta x$ 在上一节已经见过，今天给它正式的名字——**位移**，并把它和另一个日常量**路程**严格区分开。这一步区分是整个运动学的支点：后面所有公式（速度、加速度）里出现的，都是位移，不是路程。<span class="marginnote">物理学的方法是先「测量」，再「定义」：时刻与时间间隔、位置与位移，都是把日常语言变成可测量的数。这正是本博客「从极限到大模型」主线的第一站——先把运动翻译成数学。</span>

## 1 时刻与时间间隔

画一条**时间轴（time axis）**，把时间变成几何：一个点表示**时刻**，一段表示**时间间隔**。

- **时刻（instant / moment）**：时间轴上的一个「点」，对应某个瞬间，如「8 点整」「第 3 秒末」。
- **时间间隔（time interval）**：两个时刻之间的一段「长度」，对应时间轴上的一段，如「8 点到 8 点半」「前 3 秒内」。

若时刻 $t_1$ 与时刻 $t_2$ 之间隔着一段，则这段时间间隔为

$$\Delta t = t_2 - t_1$$

**时刻是「点」，时间间隔是「段」**，两者用「第几秒」的说法最容易混淆：

- **第 3 秒末**：时刻，指时间轴上 $t = 3\ \text{s}$ 那一个点。
- **第 3 秒内**：时间间隔，指从 $t = 2\ \text{s}$ 到 $t = 3\ \text{s}$ 这一秒。
- **前 3 秒内**：时间间隔，指从 $t = 0$ 到 $t = 3\ \text{s}$ 这三秒。

「第几秒」的说法在题目里高频出现，一张表看清：

| 说法 | 类型 | 时间轴上的位置 |
| --- | --- | --- |
| 第 3 秒末 | 时刻 | $t = 3\ \text{s}$ 那一个点 |
| 第 3 秒初 | 时刻 | $t = 2\ \text{s}$ 那一个点 |
| 第 3 秒内 | 时间间隔 | 从 $t = 2\ \text{s}$ 到 $t = 3\ \text{s}$，长 $1\ \text{s}$ |
| 前 3 秒内 | 时间间隔 | 从 $t = 0$ 到 $t = 3\ \text{s}$，长 $3\ \text{s}$ |

注意「第 3 秒初」与「第 2 秒末」是**同一个时刻**，只是描述角度不同。这类「换个说法其实是同一个时刻」的题，专考时刻与时间间隔的区分；做题时先在时间轴上标出点，再判断类型，就不容易出错。

时间的国际单位是**秒（second）**，符号 $\text{s}$；常用的还有分钟（$\text{min}$）、小时（$\text{h}$）。<span class="marginnote">「秒」在 1967 年被原子钟锁定：1 秒 = 铯-133 原子基态超精细能级跃迁辐射周期的 9 192 631 770 倍。物理的每个基本单位都有严格定义，见本专题《力学单位制》一节。</span>

## 2 路程与位移：两条路，两个量

物体从 $A$ 运动到 $B$，可以走直线，也可以绕弯。于是「走了多远」就有两个答案：

**路程（path length）**：物体运动**轨迹的长度**，只有大小，是**标量**。

**位移（displacement）**：从初位置指向末位置的**有向线段**，既有大小又有方向，是**矢量**。

![路程与位移的区别：路程是实际轨迹的长度，位移是初位置指向末位置的有向线段](/images/physics/time-and-displacement-1.svg)

两者只差一个字，含义天差地别：

- **位移只问初末，不问过程**：从北京直飞上海和先飞广州再飞上海，末了都在上海——位移相同，路程不同。
- **位移大小一般小于路程**：只有沿直线**单向**运动时，位移的大小才等于路程。
- **回到原点，位移为零，路程不为零**：绕地球一圈回到家门口，路程约四万公里，位移却是零。<span class="marginnote">「环球一周回到原点」是位移与路程的终极对照：位移只认起点和终点，中间绕地球多少圈它概不负责。地图导航显示的「距离」通常是路程，而物理公式里参与计算的是位移。</span>

## 3 矢量与标量：物理量的第一次分类

位移引出了一种新量：**矢量（vector）**。

- **矢量**：既有大小又有方向的量，如位移、速度、力。矢量相加不遵循普通算术加法，而遵循**平行四边形定则**。
- **标量（scalar）**：只有大小、没有方向的量，如时间、路程、质量、温度。<span class="marginnote">矢量的运算是后面《力的合成和分解》的重头戏：两个力不能直接相加，要画成平行四边形求对角线。位移是同学们遇到的第一个矢量，先从「同一直线上的加减」起步。</span>

**辨析｜易错点：** 标量也可以是负数——温度 $-5^\circ\text{C}$ 的负号表示「零下」，不是方向；矢量的大小取绝对值，如位移 $-3\ \text{m}$ 的大小是 $3\ \text{m}$，负号只表示方向与正方向相反。**「带符号」不等于「是矢量」**，判断标准只有一个：有没有方向。

## 4 直线运动的位置和位移

物体沿直线运动时，在直线上建立一维坐标系（原点、正方向、单位长度），则：

- **位置**用坐标 $x$ 表示；
- **位移**用坐标之差表示：$\Delta x = x_2 - x_1$。

例如物体从 $x_1 = 5\ \text{m}$ 运动到 $x_2 = 2\ \text{m}$，则 $\Delta x = 2 - 5 = -3\ \text{m}$，表示**沿负方向**移动了 $3\ \text{m}$。

再算一例，让位移「活」起来：一辆小车沿 $x$ 轴运动，$t = 0$ 时在 $x = 1\ \text{m}$，$t = 2\ \text{s}$ 时在 $x = 7\ \text{m}$，$t = 5\ \text{s}$ 时在 $x = 4\ \text{m}$。

- 第 2 秒内（$0 \to 2\ \text{s}$）位移：$\Delta x = 7 - 1 = +6\ \text{m}$，沿正方向；
- 第 3 秒内（$2 \to 5\ \text{s}$）位移：$\Delta x = 4 - 7 = -3\ \text{m}$，沿负方向；
- 全程（$0 \to 5\ \text{s}$）位移：$\Delta x = 4 - 1 = +3\ \text{m}$，仍是沿正方向。

同一个物体、同一段路程，拆成不同时间段的位移方向都可能相反——这就是「位移是矢量，方向要单独说」的滋味。

画**位移—时间图像（$x$-$t$ 图像）**时，横轴是时间 $t$，纵轴是位置 $x$，曲线上的点 $(t, x)$ 表示「$t$ 时刻物体在位置 $x$」。注意：**$x$-$t$ 图像不是物体的运动轨迹**，它只是一张「位置随时间变化」的报表。<span class="marginnote">$x$-$t$ 图像是本章最重要的「报表」：直线越陡，说明同样的时间位置变化越大——这「陡不陡」的量，就是下一节的<strong>速度</strong>。请提前记住：曲线斜率这个几何量，将贯穿整个高中物理。</span>

读 $x$-$t$ 图像有固定套路：某点的纵坐标是该时刻的位置；图像越陡，位置变化越快。例如一条从原点出发向右上倾斜的直线，表示物体沿正方向做**匀速直线运动**，越陡速度越大；图像向下倾斜，则物体沿负方向运动。

## 5 公式解析：位移 Δx = x₂ − x₁ 与量纲检查

$$\Delta x = x_2 - x_1$$

这条式子是「把位移变成数」的开关，拆三步看：

- **第一步，读出方向**：位移是末位置坐标减初位置坐标，**永远末减初**。$\Delta x > 0$ 表示沿正方向，$\Delta x < 0$ 表示沿负方向，$|\Delta x|$ 是移动的距离。
- **第二步，量纲检查**：$x_1$、$x_2$ 都是长度（量纲记作 $[L]$，单位米 $\text{m}$），两个长度相减仍是长度。左边 $\Delta x$ 的量纲也是 $[L]$，两边量纲一致，式子自洽。<span class="marginnote">量纲检查是物理人的「验算快捷键」：公式对不对，先用单位对一遍。速度的量纲 $[L]/[T]$（单位 m/s）、加速度的量纲 $[L]/[T]^2$（单位 m/s²），接下来都会以同样的方式出场。</span>
- **第三步，与时间挂钩**：把位移与发生这段位移所用的时间放到一起相除，就得到下一节的**速度**——「位置变化快慢」的度量。位移是分子，时间是分母，这正是「比值定义法」的第一次登场。

把三步串成一个完整例子：一辆车从 $x_1 = 100\ \text{m}$ 处开到 $x_2 = 340\ \text{m}$ 处。位移 $\Delta x = 340 - 100 = 240\ \text{m}$（量纲是 m，方向沿正方向）；若耗时 $\Delta t = 120\ \text{s}$，则下一节的速度就是 $v = 240 / 120 = 2\ \text{m/s}$。先算位移，再算速度——链条在今天就接上了。

## 6 小结

- **时刻**是时间轴上的点，**时间间隔**是时间轴上的一段，$\Delta t = t_2 - t_1$；「第 3 秒末」是时刻，「前 3 秒内」是时间间隔。
- **路程**是运动轨迹的长度，是**标量**；**位移**是初位置指向末位置的有向线段，是**矢量**。
- 位移只与初末位置有关，与路径无关；位移大小一般小于路程，**单向直线运动**时才相等。
- **矢量**有大小有方向（位移、速度、力），**标量**只有大小（时间、路程、质量）；标量带负号不一定表示方向。
- 直线运动中 $\Delta x = x_2 - x_1$，正负表示方向；$x$-$t$ 图像是「位置随时间变化」的报表，不是运动轨迹。
- 单位是量的「身份证」：时间用秒（s），位置与位移用米（m），写答案别漏。
