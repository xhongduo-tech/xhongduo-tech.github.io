## 为什么从牛顿定律开始

运动学告诉你「物体怎么动」，却不说「为什么这样动」。牛顿三定律就是那个「为什么」：它把「运动状态的改变」与「力」绑定在一起，从此天体、落体、潮汐、炮弹被同一套法则统治。这套法则统治了世界三百年，直到 1905 年爱因斯坦用相对论修正它，2020 年之前的每一颗卫星、每一枚火箭仍用牛顿定律在算。

本博客「从极限到大模型」主线里，牛顿定律是「建模」的第一次完整示范：**把真实世界抽象成受力图，把受力图翻译成方程，把方程求解回真实世界**。这个「抽象 → 翻译 → 求解 → 回归」的闭环，今天的大模型同样在走——只不过它的「力」换成了梯度，它的「方程」换成了反向传播。<span class="marginnote">牛顿力学与机器学习共享同一句方法论：预测未来靠的是「对变化的规律建立可计算的模型」。牛顿用 F = ma，深度学习用损失函数的梯度下降——模型不同，闭环相同。</span>

## 1 力：受力分析的起点

**力（force）**：物体之间的相互作用。它是改变物体运动状态的原因，也是使物体发生形变的原因。力的三要素是**大小、方向、作用点**，力是矢量。

**受力分析**是动力学建模的第一步，口诀是「一重二弹三摩擦、其他外力再补上」：

- **重力**：$G = mg$，竖直向下，作用在重心上。
- **弹力**：由形变产生，方向与形变方向相反。支持力垂直支持面、绳子拉力沿绳指向绳、弹簧力沿弹簧。产生条件是「接触 + 形变」。
- **摩擦力**：见第 4 节。
- **其他外力**：拉力、推力、浮力、电场力等，按题目条件补上。

**辨析｜易错点：** 受力分析最怕「无中生有」与「遗漏」。物体受不受某个力，看的是「有没有别的物体施加」——**力不能脱离施力物体单独存在**，找不到施力物体的力一定是画错了。斜面上静止的物体受三个力（重力、支持力、摩擦力），支持力是「重力在垂直斜面方向的分量」的反作用，不是「重力」本身——两者方向都不同。

力的运算——**力的合成与分解**——遵循平行四边形定则：两个力 $F_1, F_2$ 的合力大小落在 $|F_1 - F_2| \le F \le F_1 + F_2$ 之间，方向由夹角决定。实际解题最常用的是**正交分解**：把每个力沿 $x$、$y$ 两个互相垂直的方向分解，分别列平衡方程或动力学方程。三角形定则是平行四边形定则的简写——三个力首尾相接围成闭合三角形则合力为零，这一条在静力平衡里极好用。

## 2 牛顿第一定律与惯性系

**牛顿第一定律（惯性定律）**：一切物体总保持匀速直线运动状态或静止状态，除非有外力迫使它改变这种状态。

这条定律的深意有三层。**第一，它定义了「惯性」**——物体保持原有运动状态的性质叫惯性，惯性只与质量有关，质量越大惯性越大。**第二，它定义了一类特殊参考系**——牛顿第一定律成立的参考系叫**惯性系（inertial frame）**，其中不受力的物体静止或匀速直线运动；相对惯性系做匀速直线运动的参考系也是惯性系，而加速运动的参考系（如急刹车的车厢）不是。<span class="marginnote">惯性系是整个经典力学的「地基」：牛顿定律只在惯性系里成立。在急刹车的车厢里，没系安全带的乘客会「向前飞」——那不是牛顿第二定律失效，而是车厢不是惯性系。伽利略相对性原理说：在任何一个惯性系内部做实验，你都无法区分自己是否在匀速运动。</span>

**第三，它是伽利略思想的遗产**：伽利略用理想斜面实验推翻了「力是维持运动的原因」这一亚里士多德教条，指出力是**改变**运动状态的原因，而不是**维持**运动的原因。这一条，是整个动力学的分水岭。

伽利略的理想实验是这段思想最漂亮的样本：让小球从斜面 A 滚下，它能几乎滚上对面倾角相同的斜面 B 的同一高度；把 B 的倾角减小，小球仍要爬到同一高度，只是走得更远；当 B 完全水平时，小球「永远达不到原来的高度」，于是永远滚下去——结论：没有外力时物体保持匀速直线运动。理想实验靠逻辑排除干扰，正是「排除干扰看本质」的科学方法在力学里的第一次完整示范。

## 3 牛顿第二定律：动力学的发动机

**牛顿第二定律**：物体加速度的大小与所受合力成正比，与质量成反比，方向与合力方向相同：

$$\vec{F}_{\text{合}} = m \vec{a}$$

**重点：这是矢量式。** 它意味着三个信息同时成立：大小关系 $F_{\text{合}} = ma$、方向关系 $\vec{a} \parallel \vec{F}_{\text{合}}$、以及「合力为零则加速度为零」（静态或匀速）。解题时通常沿两个垂直方向分解：$\sum F_x = ma_x$，$\sum F_y = ma_y$。

**例（连接体建模）**：水平桌面上，质量为 $m_1 = 1\ \text{kg}$ 的物体 A 与 $m_2 = 3\ \text{kg}$ 的物体 B 用轻绳相连，用 $F = 8\ \text{N}$ 的水平恒力拉 A（桌面光滑）。整体法：$F = (m_1+m_2)a$，得 $a = 8/4 = 2\ \text{m/s}^2$。隔离法看 B：$T = m_2 a = 3 \times 2 = 6\ \text{N}$——绳子拉力是 $6\ \text{N}$，不是 $8\ \text{N}$！**绳子拉力总是小于施加的外力**（在加速系统中），这是连接体题最经典的陷阱。<span class="marginnote">整体法求加速度、隔离法求内力，是牛顿第二定律的两板斧。机器学习里的「前向传播 + 反向传播」结构上也类似：整体看损失、逐层看梯度。</span>

## 4 摩擦力：滑动、静摩擦与临界

**滑动摩擦力**：物体相对接触面滑动时受到与相对运动方向相反的力：

$$f = \mu N$$

其中 $\mu$ 是**动摩擦因数**（取决于材料与粗糙程度），$N$ 是**正压力**（垂直接触面的压力）。注意 $f = \mu N$ 与质量无关，只与材料和正压力有关。

**静摩擦力**：物体有相对运动趋势但未滑动时受的力，方向与相对运动趋势方向相反，大小在 $0$ 到 $f_{\max} = \mu_s N$ 之间自适应。关键认知：**静摩擦力不是固定的，它是「恰好维持相对静止」的那个值**，由受力平衡反推，超过最大静摩擦后物体才开始滑动。<span class="marginnote">「最大静摩擦力 $f_{\max}$」像一道阈值：未超过时，摩擦被动地等于外力；超过后，摩擦「破防」变成滑动摩擦。这种「阈值 + 切换」行为，在神经网络激活函数（如 ReLU 的转折点）里也有类似的临界性。</span>

**例（临界分析）**：重 $20\ \text{N}$ 的箱子放在水平地面，$\mu_s = 0.4$，$\mu = 0.3$。用 $F = 5\ \text{N}$ 的水平力推：最大静摩擦 $f_{\max} = 0.4 \times 20 = 8\ \text{N} > 5\ \text{N}$，箱子不动，静摩擦恰为 $5\ \text{N}$。用 $F = 10\ \text{N}$ 推：超过 $8\ \text{N}$，箱子开始滑动，滑动摩擦 $f = 0.3 \times 20 = 6\ \text{N}$，合力 $10 - 6 = 4\ \text{N}$，加速度 $a = 4/2 = 2\ \text{m/s}^2$（质量 $m = G/g = 2\ \text{kg}$）。

**例（传送带上的摩擦力）**：物体轻放在匀速传动的传送带上，初始相对传送带向后滑，受向前的滑动摩擦力，做匀加速；速度与传送带相同后两者相对静止，摩擦力瞬间消失（水平传送带情形）。**摩擦力的方向永远与「相对运动（趋势）」方向相反，而不是与运动方向相反**——物体向前运动，摩擦力照样可以向前推它，这正是传送带能把物体「送走」、也能让刹车钳「咬住」轮盘的机制。

## 5 牛顿第三定律：力的对称性

**牛顿第三定律**：两个物体之间的作用力与反作用力总是大小相等、方向相反、作用在同一条直线上。

这一条最常见的误区是把「作用力与反作用力」和「平衡力」混为一谈：

| | 作用力与反作用力 | 平衡力 |
| --- | --- | --- |
| 施力物体 | 互为对方（A 对 B、B 对 A） | 同一物体受的两个力 |
| 受力物体 | 分别是 B 和 A | 都是同一个物体 |
| 力的性质 | 一定相同（都是弹力、都是摩擦力…） | 可以不同（重力和支持力） |
| 同时性 | 同时产生、同时消失 | 无此要求 |

**例（马能拉动车的道理）**：马对车拉力 $F$ 与车对马拉力 $F'$ 等大反向，那车怎么还能动？因为拉动车的不是 $F'$，而是**地对马的静摩擦力**——马用力蹬地，地对马的摩擦力向前，这个力超过车对马的阻力，马才前进。作用力与反作用力分别作用在不同物体上，根本不能「抵消」，这恰恰是运动得以发生的机制。

## 6 动力学建模：从受力图到答案

把前三节的工具组装成解题流程，这是本专题的第一次完整「建模」：

1. **选对象**：确定研究对象，必要时整体法 + 隔离法。
2. **画受力图**：一重二弹三摩擦，找到每个力的施力物体。
3. **选参考系**：确认是惯性系；非惯性系要引入惯性力。
4. **建立坐标系**：沿运动方向和垂直运动方向分解。
5. **写方程**：$\sum F_x = ma_x$，$\sum F_y = 0$（若沿 $y$ 无加速度），摩擦力判断静/动、是否达到临界。
6. **解方程，验答案**：符号、单位、量纲齐次性。

**例（斜面整体建模）**：质量 $m = 2\ \text{kg}$ 的物体沿倾角 $37°$ 的粗糙斜面下滑，$\mu = 0.5$。沿斜面方向：$mg\sin37° - \mu mg\cos37° = ma$。代入 $g = 10$：$a = 10(\sin37° - 0.5\cos37°) = 10(0.6 - 0.5 \times 0.8) = 2\ \text{m/s}^2$。若 $\mu = 0.75$，则 $a = 10(0.6 - 0.6) = 0$——物体恰好匀速下滑，这时的 $\mu = \tan\theta$ 是一个值得记住的临界条件。

几类高频模型的受力口诀，一张表收齐：

| 模型 | 关键受力 | 核心结论 |
| --- | --- | --- |
| 水平面拉箱子 | 重力、支持力、拉力、摩擦 | 匀速：拉力 = 摩擦；加速：$F - f = ma$ |
| 光滑斜面滑块 | 重力、支持力 | $a = g\sin\theta$，与质量无关 |
| 粗糙斜面 | 重力、支持力、摩擦 | 下滑条件 $mg\sin\theta > f$；临界 $\mu = \tan\theta$ |
| 竖直升降电梯 | 重力、支持力 | 超重 $N = m(g+a)$、失重 $N = m(g-a)$ |
| 水平连接体 | 整体 + 隔离 | 整体求 $a$、隔离求内力 $T$ |

这五行对应必修第一册第三、四章的核心模型，每一行都是「选对象 → 受力分析 → 正交分解 → 列方程」模板的产物。把这个模板练到条件反射，是动力学建模的第一阶段。

## 7 小结

- **牛顿第一定律**定义了惯性、定义了惯性系；力是改变而非维持运动状态的原因。
- **牛顿第二定律** $\vec{F} = m\vec{a}$ 是矢量式，解题要沿两个方向分解；整体法求加速度、隔离法求内力。
- **摩擦力**：滑动摩擦 $f = \mu N$；静摩擦自适应、有阈值 $f_{\max}$，超过阈值才滑动。
- **牛顿第三定律**：作用力与反作用力分属两个物体、不能抵消，与平衡力有本质区别。
- **建模流程**：选对象 → 画受力图 → 定参考系 → 建坐标 → 写方程 → 求解验证。
- 斜面临界条件 $\mu = \tan\theta$；连接体绳中拉力小于外力。

在下一节，我们将换一种「守恒」的语言重写力学：不追着力去算每一步，而是用**功、动能、势能与机械能守恒**从初态直接跳到末态——守恒律常常比力的分析更省力、更深刻。下一节见。
