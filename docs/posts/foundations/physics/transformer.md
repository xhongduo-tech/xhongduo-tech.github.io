## 为什么从变压器开始

上一节说了交流电「能变压」是它的核心优势——现在来认识实现变压的装置：**变压器（transformer）**。它由铁芯与两个线圈（原线圈、副线圈）组成，通过**互感**把电能「隔空」传递，同时按匝数比改变电压。发电厂发出的电压、输电线上的高压、家庭使用的 220 V，全靠变压器在电网里「接力」变换。

变压器是电力系统的绝对核心：升压变电站把电压升到 110–1000 kV 减少输电损耗，降压变电站再把它降回安全的等级。它还是手机充电器、电子设备电源里的「心脏」。理解变压器，等于理解「交流电为何统治电网」。<span class="marginnote">变压器的「隔离」特性很实用：原副线圈没有导线直接相连，靠铁芯中的磁通量传能——这叫电气隔离。医疗设备、电子电源用隔离变压器把危险的电网电压与人体/精密器件隔开，提高安全性与抗干扰能力。「变压 + 隔离」是变压器的两大功能。</span>

学这一节，请抓住：**变压器的变压比、能量关系（理想变压器）、以及为什么只能用于交流**。

## 1 变压器的结构

**变压器**：由**铁芯**与绕在铁芯上的**两个线圈**（原线圈、副线圈）组成。

- **原线圈（初级线圈）**：接交流电源，匝数 $n_1$。
- **副线圈（次级线圈）**：接负载，匝数 $n_2$。
- **铁芯**：闭合的导磁体，把原线圈产生的磁通量「引导」到副线圈——几乎全部磁通量穿过两个线圈（理想情况无漏磁）。

**工作原理**：原线圈通交变电流 → 铁芯中产生交变磁通量 → 磁通量同时穿过副线圈 → 副线圈中感应出电动势（互感）。能量通过「交变磁通量」从原线圈传到副线圈，无直接电气连接。<span class="marginnote">变压器的「磁路」设计：铁芯让磁通量「几乎全部」穿过原、副线圈（理想无漏磁），这样两线圈每匝的磁通量变化率相同——变压比才严格等于匝数比。铁芯用硅钢片叠成是为了减小涡流损耗。磁通量是「媒人」：它把原线圈的电压变化「翻译」给副线圈，翻译的比例由匝数决定。</span>

## 2 变压比：电压与匝数成正比

**理想变压器**（无能量损失）：原、副线圈每匝感应电动势相同（同一磁通量穿过），所以电动势与匝数成正比：

$$\frac{U_1}{U_2} = \frac{n_1}{n_2}$$

**变压器的分类**：

- **升压变压器**：$n_2 > n_1$（副线圈匝数多），$U_2 > U_1$——电压升高。
- **降压变压器**：$n_2 < n_1$，$U_2 < U_1$——电压降低。
- **隔离变压器**：$n_2 = n_1$，$U_2 = U_1$——只隔离不变压。

**辨析｜易错点：** 变压器改变**电压与电流**，不改变**频率**——原副线圈的交流电频率相同（磁通量变化频率相同）。「变压器改变频率」是错的。变压比公式的前提是理想变压器（无漏磁、无损耗）。<span class="marginnote">「频率不变」是变压器的重要性质：原线圈的电流频率由电源决定，磁通量以这个频率变化，副线圈感应出的电自然也同频率。所以变压器的匝数比只改电压电流、不改频率——这也是「电网频率恒定（50 Hz）」能贯穿全程的原因。</span>

## 3 电流关系：能量守恒的约束

理想变压器（无损耗），输入功率 = 输出功率：

$$P_1 = P_2 \quad\Rightarrow\quad U_1I_1 = U_2I_2$$

由变压比 $\dfrac{U_1}{U_2} = \dfrac{n_1}{n_2}$，得电流关系：

$$\frac{I_1}{I_2} = \frac{n_2}{n_1}$$

**电流与匝数成反比**：

- **升压变压器**（$n_2 > n_1$）：电压升、电流降——输出高压小电流。
- **降压变压器**（$n_2 < n_1$）：电压降、电流升——输出低压大电流。

**物理意义**：变压器不创造能量，只是「电压升高时电流按比例减小」，功率守恒。输电升压正是利用这个「高压小电流」——输电损耗 $P_{\text{损}} = I^2R$ 随电流平方下降。<span class="marginnote">「升压必降流」是能量守恒的直接推论：电压升 10 倍、电流降 10 倍、功率不变。输电工程利用这个：升压到 110 kV 后电流小了，输电线的焦耳损耗（$I^2R$）急剧下降——电压升 10 倍、损耗降 100 倍。这就是「为什么要高压输电」的完整答案：变压器让「高压小电流」成为可能，而小电流意味着小损耗。</span>

**辨析｜易错点：** 电流关系 $\dfrac{I_1}{I_2} = \dfrac{n_2}{n_1}$ 只在**理想变压器（无损耗）**下成立——它由功率守恒推出。若副线圈空载（不接负载，$I_2 = 0$），原线圈也只有很小的空载电流（励磁电流），不是「$I_1 = 0$」。做题时注意「副线圈是否接负载」决定原线圈电流大小。

## 4 理想变压器与实际变压器

**理想变压器**的三个假设：

1. **无漏磁**：全部磁通量穿过两个线圈。
2. **无铜损**：线圈电阻为零（无焦耳热）。
3. **无铁损**：铁芯无涡流、磁滞损耗。

在理想假设下，$U_1/U_2 = n_1/n_2$、$P_1 = P_2$ 严格成立。

**实际变压器的损耗**：

- **铜损**：线圈电阻发热 $I^2R$。
- **铁损**：铁芯涡流损耗（硅钢片减小）与磁滞损耗。
- 实际效率很高（大型变压器可达 98% 以上），但总有损耗——输出功率略小于输入功率。

**辨析｜易错点：** 理想变压器是无损耗的模型。实际变压器 $P_2 < P_1$（有损耗），$\dfrac{I_1}{I_2} = \dfrac{n_2}{n_1}$ 只是近似。考试默认「理想变压器」处理（题目会说「忽略损耗」或「理想变压器」），但概念上要知道「理想」的含义。<span class="marginnote">「理想化」是物理建模的老规矩：变压器题默认理想（无损耗），分析「为什么实际有损耗、怎么减小」是工程题。减小损耗的手段：硅钢片叠芯（减小涡流）、低电阻绕组（减小铜损）、优化铁芯材料（减小磁滞）。「理想模型 + 实际修正」是物理从理论到工程的标准路径。</span>

## 5 公式解析：U₁/U₂ = n₁/n₂

$$\frac{U_1}{U_2} = \frac{n_1}{n_2}, \qquad \frac{I_1}{I_2} = \frac{n_2}{n_1}$$

拆三步看：

- **第一步，为什么电压比 = 匝数比**：理想变压器中，原副线圈的磁通量相同（同一铁芯），每匝感应电动势相同——所以总电动势与匝数成正比。$E_1 = n_1\Delta\Phi/\Delta t$、$E_2 = n_2\Delta\Phi/\Delta t$，$E_1/E_2 = n_1/n_2$。<span class="marginnote">推导链：法拉第定律 $E = n\Delta\Phi/\Delta t$ → 两线圈 $\Delta\Phi/\Delta t$ 相同（同一磁通量）→ $E_1/E_2 = n_1/n_2$。所以变压比的根源是「同磁通 + 法拉第定律」——每匝都按法拉第定律感应，匝数多、总电动势就大。</span>
- **第二步，为什么电流比 = 匝数反比**：理想变压器功率守恒 $U_1I_1 = U_2I_2$，代入电压比得 $I_1/I_2 = n_2/n_1$。**电流关系是能量守恒的推论**，不是独立的定律。
- **第三步，等效电阻视角**：从原线圈看，副线圈接负载 $R_2$ 等效于原线圈接电阻 $R_1 = \left(\dfrac{n_1}{n_2}\right)^2 R_2$——变压器还「变换阻抗」。这个「阻抗变换」在音频功放匹配扬声器、射频电路匹配中大量应用。
- **第四步，数值例**：原线圈 1000 匝接 220 V，副线圈 50 匝，$U_2 = 220\times\dfrac{50}{1000} = 11\ \text{V}$——手机充电器的降压变压器就把 220 V 降到几伏。

## 6 辨析｜易错点

- **变压器只用于交流**：直流电流不变、磁通量不变、无互感，变压器不工作（若直流接入会烧毁线圈）。
- **电压比 = 匝数比、电流比 = 匝数反比**：方向别记反。
- **频率不变**：变压器改变电压电流，不改变频率。
- **理想变压器功率守恒**：$U_1I_1 = U_2I_2$；实际有损耗。
- **升压降压看匝数**：副线圈匝数多升压、少降压。
- **空载时原线圈有励磁电流**：不是「$I_1 = 0$」。

## 7 小结

- **变压器**：铁芯 + 原副线圈，靠互感隔空传能。
- **变压比**：$U_1/U_2 = n_1/n_2$（法拉第定律 + 同磁通）。
- **电流关系**：$I_1/I_2 = n_2/n_1$（能量守恒）。
- **理想变压器**：无损耗，$P_1 = P_2$；实际有铜损铁损。
- **只用于交流**：直流不能变压。
- **应用**：升压输电、降压供电、隔离、阻抗变换。

在下一节，我们把变压器与输电线路结合：**电能的输送**。高压输电如何减小损耗、电网如何把电能送到千家万户——变压器 + 输电线 = 现代电力系统。
