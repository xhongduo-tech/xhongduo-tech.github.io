## 为什么从机械能守恒定律开始

前三节我们分别引入了功、重力势能与动能，现在是收网时刻：把动能与势能放回同一个系统里看它们的「此消彼长」。当只有重力（或弹簧弹力）做功时，你会发现一个惊人的规律——**动能与势能互相转化，但总和保持不变**。这就是**机械能守恒定律**。

这条定律是本章的灵魂，也是整个能量守恒思想的第一次严格亮相。它把牛顿力学里需要逐点求解的问题，变成一条几乎不费力的守恒方程：**只要判断「是否只有保守力做功」，就能写下「初末机械能相等」**。<span class="marginnote">机械能守恒是「守恒律」思想的第一个实例。物理学家相信，每一个守恒量背后都对应着时空的一个对称性——能量守恒对应时间平移对称性（物理规律不随时刻而变）。这个深刻的联系在第二级《理论力学》里会揭开，高中阶段只需记住：守恒律是解题的捷径，更是物理世界秩序性的体现。</span>

学这一节的关键是**判定条件**：什么情况下机械能守恒？什么情况下不守恒？判断错了，公式就废了。而判定条件本身又是一个绝佳的例子，展示了「守恒」不是默认属性，而是**特例中的秩序**。

## 1 机械能的定义与构成

**机械能（mechanical energy）**是动能与势能的总和：

$$E = E_k + E_p$$

- **动能** $E_k = \tfrac{1}{2}mv^2$：因运动而具有。
- **重力势能** $E_p = mgh$：因高度而具有。
- **弹性势能** $E_{p弹}$：因形变而具有（弹簧被压缩或拉伸时储存的能量，$E_{p弹} = \tfrac{1}{2}kx^2$，其中 $k$ 是劲度系数、$x$ 是形变量）。<span class="marginnote">弹性势能是本节的一个重要配角。弹簧的弹力也是保守力——做功与路径无关、只与形变量有关，所以也能定义势能。$E_{p弹} = \tfrac{1}{2}kx^2$ 的推导与重力势能同源：弹簧弹力随形变线性变化，做功是 $F$-$x$ 图像下的三角形面积 $\tfrac{1}{2}kx^2$。</span>

从第三章《重力与弹力》起你就认识了弹簧，但当时只研究它的力，现在研究它储存的能量。一个被压到极限的弹簧蕴含巨大的弹性势能，放手瞬间把它全部释放成动能——弹射器、弓弩、机械表发条，都是弹性势能与动能的转化器。

## 2 机械能守恒的判定条件

机械能守恒**不是自动成立的**，需要严格条件：

**在只有重力或弹力做功的物体系统内，动能与势能可以相互转化，而总的机械能保持不变。**

判定条件可以拆成两条，只要满足其一即可：

1. **只有重力（或弹力）做功，没有其他力做功**——即系统内只有保守力参与能量转化。
2. **其他力做了功，但做功的代数和为零**——例如竖直上抛过程中空气阻力做负功、但有人工恰好补偿了等量正功（高中很少见，知道即可）。

常见守恒情形与不守恒情形的对照：

| 过程 | 判定 | 机械能 |
| --- | --- | --- |
| 自由落体、竖直上抛（忽略阻力） | 只有重力做功 | 守恒 |
| 光滑斜面/圆弧上滑动 | 重力做功，支持力不做功 | 守恒 |
| 光滑水平面上压缩弹簧 | 只有弹力做功 | 守恒 |
| 有摩擦的粗糙斜面 | 摩擦力做负功（非保守力） | **不守恒** |
| 空气阻力明显的下落 | 阻力做负功 | **不守恒** |

**辨析｜易错点：** 摩擦力做功必然导致机械能不守恒吗？**是**。因为摩擦生热，一部分机械能转化成了内能，机械能总量减少。所以「光滑」二字在守恒问题里是金钥匙——题目说「光滑」，机械能多半守恒；题目给了摩擦系数、阻力，机械能必然不守恒，要用上一节的动能定理（$W_{\text{总}} = \Delta E_k$）或整体能量守恒来解。<span class="marginnote">支持力、拉力等「非保守力」是否破坏守恒，要看它们做不做功。光滑斜面上支持力与位移垂直，做功为零，机械能仍守恒；但斜面若在运动（如传送带把物体托起来），支持力可能做功，守恒条件就要重新评估。「不做功的力不影响守恒」是判断的捷径。</span>

## 3 守恒定律的三种表达

机械能守恒可以写成三种等价的方程，各有用武之地：

**表达一：初末机械能相等**

$$E_{k1} + E_{p1} = E_{k2} + E_{p2}$$

**表达二：动能增加量等于势能减少量**

$$\Delta E_k = -\Delta E_p$$

**表达三：重力势能的减少等于动能的增加（针对单个保守力）**

$$mgh_1 - mgh_2 = \tfrac{1}{2}mv_2^2 - \tfrac{1}{2}mv_1^2$$

三种表达本质相同，选哪种看方便：系统内物体少、位置清楚，用表达一；涉及「转化了多少」的问法，用表达二更直接。<span class="marginnote">表达二的写法 $\Delta E_k = -\Delta E_p$ 是「此消彼长」的数学化：动能的增加恰等于势能的减少，一增一减对消。到选择性必修第三册《热力学第一定律》你会看到同样的结构——内能变化等于功与热量的代数和，守恒的思想一脉相承。</span>

举一个综合例子：一物体从高 $h$ 处由静止沿光滑曲面滑下，求到达最低点时的速度。机械能守恒（支持力不做功，只有重力做功）：

$$\frac{1}{2}mv^2 = mgh \Rightarrow v = \sqrt{2gh}$$

结果与自由落体完全相同——**与路径无关**。无论曲面是凹是凸、路径多长，速度只由高度差决定。这就是机械能守恒的强大：它把「过程的复杂性」压缩成「状态的简单性」。

## 4 用机械能守恒定律解题的流程

机械能守恒的解题流程比动能定理更简单，因为连「算功」都免了：

1. **选系统**：明确研究对象（通常把几个相互作用的物体放在一起考虑，如「小球 + 弹簧」）。
2. **判守恒**：检查是否只有重力/弹力做功，确认条件满足。
3. **选零势能面**：定参考平面，写出各位置的势能。
4. **列方程**：写初态与末态的机械能，令其相等，求解。

再看一个经典题：质量为 $m$ 的小球，用轻绳悬挂在 O 点，从水平位置由静止释放，求摆到最低点时速度。

只有重力做功，机械能守恒。取最低点为势能零点，初态（水平位置）：$E_{k1} = 0$，$E_{p1} = mgl$（$l$ 为绳长）；末态（最低点）：$E_{k2} = \tfrac{1}{2}mv^2$，$E_{p2} = 0$。于是 $mgl = \tfrac{1}{2}mv^2$，$v = \sqrt{2gl}$。<span class="marginnote">注意摆到最低点时<strong>绳的拉力大于重力</strong>——小球做圆周运动需要向心力，$T - mg = mv^2/l$，代入 $v^2 = 2gl$ 得 $T = 3mg$。这就是「水流星」「过山车」里物体在最低点对轨道压力三倍于重力的来源，与第六章《向心力》的知识完美衔接。</span>

对比牛顿第二定律解法：摆动的每个位置受力方向都在变，向心加速度、切向加速度都要分别处理，要列微分方程。而守恒法只用了初末两个状态。**守恒律把「过程的难度」转化为「状态的判断」**，这正是物理学家偏爱它的根本原因。

## 5 公式解析：mgh₁ + ½mv₁² = mgh₂ + ½mv₂²

$$\frac{1}{2}mv_1^2 + mgh_1 = \frac{1}{2}mv_2^2 + mgh_2$$

拆三步看：

- **第一步，等式两边的结构**：左边是初态机械能（初动能 + 初势能），右边是末态机械能（末动能 + 末势能）。每一项都有明确的物理身份：$\tfrac{1}{2}mv^2$ 是运动贡献，$mgh$ 是高度贡献。等式意味着「运动与高度的兑换」没有损耗。
- **第二步，为什么支持力不出现**：光滑斜面上支持力与位移垂直，$W_N = 0$，不做功就不改变机械能。守恒方程里只出现「参与能量兑换」的力——重力在初末位置各贡献一个势能项。**不做功的力不进守恒方程**，这是方程「干净」的原因。
- **第三步，势能零点的消去**：设参考平面升高 $H$，则 $h_1 \to h_1 + H$、$h_2 \to h_2 + H$，等式两边各加 $mgH$，恰好抵消。**零势能面的选择不影响守恒方程**——又一次印证「物理量是差不是值」。
- **第四步，能量如何转化**：小球下落时 $h$ 减小（$mgh$ 项变小），速度增大（$\tfrac{1}{2}mv^2$ 项变大），一增一减恰好平衡。机械能守恒不是说「能量不变」这个简单事实，而是说**动能与势能在内部转化，不流失到系统外**（不变成内能、不传给外界）。

## 6 辨析｜易错点

- **「只受重力和弹力」与「只有重力和弹力做功」不是一回事**：物体可以受支持力、绳拉力等，只要它们不做功（垂直速度），机械能照样守恒。判定看**做功**，不是看**受力**。<span class="marginnote">经典陷阱题：小球在光滑圆弧上运动，受重力与支持力两个力，但支持力不做功，所以机械能守恒。「受两个力 ≠ 机械能不守恒」，读题时盯住「光滑」和「不做功」。</span>
- **有摩擦一定不守恒**：摩擦力做功把机械能转成内能（生热），机械能减少。但「机械能减少」不等于「能量消失」——内能也是能量，只是不在「机械能」的账本里。总能量（机械能 + 内能 + …）仍然守恒。
- **势能零点选好后中途别换**：换了零点，两边各加常数可抵消，但中间计算容易出错。固定一个参考面算到底。
- **机械能守恒是「系统」的性质**：严格说守恒属于「物体 + 地球」系统（因为重力势能是系统的）。高中简化说「物体机械能守恒」，但心里要清楚：势能不是孤立物体能独占的。
- **不要与动能定理混淆**：动能定理对任何过程都成立，机械能守恒只在「只有保守力做功」时成立。前者是**普适定理**，后者是**特例**。判断不守恒时，退回动能定理 $W_{\text{总}} = \Delta E_k$ 一定能解。

## 7 小结

- **机械能**：动能与势能（重力势能 + 弹性势能）的总和，$E = E_k + E_p$。
- **机械能守恒条件**：只有重力或弹力做功（其他力不做功或做功代数和为零）。
- 三种表达：初末相等 $E_{k1} + E_{p1} = E_{k2} + E_{p2}$；动能增量 = 势能减少量；$mgh_1 - mgh_2 = \tfrac{1}{2}mv_2^2 - \tfrac{1}{2}mv_1^2$。
- 解题流程：选系统 → 判守恒 → 定零点 → 列方程。光滑、无阻是关键信号。
- 不守恒时用动能定理；能量不消失，只是转化形式（如摩擦生热）。

在下一节，我们把这一章的理论付诸实验：用打点计时器测下落重物的速度与高度，检验动能增加是否恰好等于势能减少——**实验：验证机械能守恒定律**，这是你亲手验证一条自然规律的机会。
