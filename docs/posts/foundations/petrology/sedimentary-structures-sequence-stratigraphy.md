## 为什么从沉积构造与层序地层学开始

前几节我们认识了一颗颗「单词」——矿物、颗粒、岩石类型。
这一节把它们连成「句子」与「篇章」：**沉积构造**是句子里的语序（读水动力），**沉积环境**是句子表达的主题（读地点），**层序地层学**则是把一页页沉积物按时间装订成书的方法（读时间轴）。
Boggs 教材的后半部分把这三层依次展开。
看懂它们，一块露头就不再是「一堆石头」，而是一份可以倒放的「沉积影片」。

## 1 沉积构造：读水动力的指纹

**沉积构造（sedimentary structure）**是沉积物在沉积时及沉积后不久留下的形体痕迹，分**原生构造**（沉积时形成）与**次生构造**（沉积后形成）。
原生构造是环境判读的主力：

- **层理（bedding）**：一切构造的基础——沉积物的界面把岩石切成层。层内细分为**纹层（laminae）**；层与层之间的面叫**层面**。
- **交错层理（cross-bedding）**：斜列的前积层组，是沙丘或水下沙波迁移留下的「剪切轨迹」——**前积层的倾角方向 = 古水流方向**。<span class="marginnote">风成砂岩的巨大交错层（如美国纳瓦霍砂岩，单组厚达 30 米以上）与河流的小型交错层截然不同——交错层理的单组厚度本身就是环境强度与介质（风 vs 水）的量纲。</span>
**粒序层理（graded bedding）**：单层内粒度自下而上变细（正粒序）。经典产出于**浊流**——水下密度流逐渐减速、颗粒按粗细先后落底。
- **波痕（ripple marks）**：对称波痕是往复的波浪留下的，不对称波痕（具陡缓两翼）是单向水流或风留下的，缓翼指向上游。
- **干裂（mudcracks）**：泥质层暴露地表失水收缩的多边形裂缝，是「曾出露水面」的直接证据。
- **底面印模（sole marks）**：如**槽模（flute casts）**——浊流在泥底冲刷出梨形凹坑后被砂充填，圆钝端指向上游，是**指向构造**里最可靠的古水流指示器。
- **风暴成因的交错层理（HCS，丘状交错层理）**：风暴浪冲刷出的穹状层理，是浅海风暴岩的标志。
- **生物扰动（bioturbation）**：虫迹、潜穴等遗迹化石。扰动越强，说明环境氧气越充足、沉积速率越慢。<span class="marginnote">遗迹化石不搬动身体、专属于沉积环境，是「原地」的环境证据；生物扰动强度（ichnofabric index）是「含氧量 × 沉积速率」的复合读卡。见《古生物学》专题的遗迹化石一节。</span>

野外读构造有一条铁律：**先看层面再看层内，先看原生再看次生**——先追索层面与粒度趋势，再辨认层内构造（交错、粒序、波痕），最后筛除后期扰动（生物扰动、构造节理、成岩压实）。
构造之间的**叠加关系**（谁切割谁）还能排出沉积事件的先后次序——这与第 10 篇变质组构的「叠印分析」是同一套逻辑。

## 2 沉积环境与相

**沉积环境（depositional environment）**是沉积作用发生地点的物理—化学—生物条件总和；
**相（facies）**则是该环境在岩石中的物质记录。
把环境按位置排一条流水线：

| 大类 | 环境 | 特征构造与产物 |
| --- | --- | --- |
| 大陆 | 冲积扇 | 角砾岩、泥石流层、分选差 |
| 大陆 | 河流（辫状/曲流） | 交错层理、边滩/心滩、河道砂岩 |
| 大陆 | 湖泊 | 细粒纹层、蒸发岩、湖相泥岩 |
| 大陆 | 风成沙漠 | 巨型交错层、风成砂丘、分选极好 |
| 大陆 | 冰川 | 冰碛岩、擦痕、杂乱分选 |
| 过渡 | 三角洲 | 顶积—前积—底积、反粒序砂体 |
| 过渡 | 海岸/潮坪 | 潮汐层理、波痕、干裂、滩坝 |
| 海洋 | 陆架 | 风暴岩、生物碎屑灰岩 |
| 海洋 | 大陆坡/海底扇 | 浊积岩（鲍马序列）、粒序层理 |
| 海洋 | 深海平原 | 远洋黏土、放射虫燧石、浊积薄层 |

每种环境的「特征构造套餐」高度特异：**正粒序 + 槽模 + 鲍马序列 = 浊流**，**巨型交错层 + 分选极好 = 风成**，**干裂 + 波痕 + 石膏 = 潮坪蒸发**。
这就是**相分析（facies analysis）**：拿观测到的构造组合去对照环境「签名」。
<span class="marginnote">鲍马序列（Bouma sequence）把一次浊流沉积自下而上分成 Ta–Te 五段（粒序段、下平行纹层段、水流波纹段、上平行纹层段、泥岩段）——它是沉积学里「一个事件 = 一段记录」的经典模板。</span>

单看一种环境容易误判，所以相分析要求**相组合（facies association）**：把同时期共生的多个相作为一个整体识别——例如「三角洲」不是某一个相，而是河道砂、天然堤粉砂、分流河口坝、前三角洲泥组成的**相组合**。
现代**相模式（facies model）**把这些组合概括成标准「模板」，野外剖面与之对照，环境判定的可信度就大大提高——这是从「认一块石头」走向「认一片沉积体系」的关键一步。

## 3 沃尔索定律：纵向剖面为何能读横向环境

相分析有一个强大的「翻译定理」——**沃尔索定律（Walther's law）**：在连续沉积、无间断的地层剖面里，**垂向上相邻的相，曾属于横向相邻的环境**。
<span class="marginnote">直觉版：如果你站在海边从海岸走向深海，依次踩过沙滩、滨面、陆架；几百万年后海水进退，同一列环境会被「折叠」成同一根钻孔里的垂向序列——垂向的相序就是横向环境带的侧向迁移记录。</span>于是，「垂向剖面上看到河流相下伏三角洲相、再下伏浅海相」，等于「河口持续向海推进」——三角洲的进积，被压缩成了剖面方向的一行相序。

**辨析｜易错点：** 沃尔索定律有一个前提——**剖面必须连续无沉积间断**。
一旦存在不整合或侵蚀面，垂向相邻的相未必横向相邻，定律失效。
判断剖面是否连续，要靠第 4 节的层序地层学方法（识别不整合面）——定律与层序分析因此是一对互相支撑的工具。

## 4 层序地层学：海平面的语法

把沉积剖面按**沉积趋势**切成有意义的单元，就是**层序地层学（sequence stratigraphy）**。
核心概念：

**层序（sequence）**：以**不整合面及其对应的整合面**为界的成因相关的沉积体组合——「一次海平面相对变化的完整记录」；
- **体系域（systems tract）**：层序内部、按海平面位置与沉积趋势划分的三段。**低位体系域（LST）**——海退、陆架暴露、河流下切，浊积扇发育；**海侵体系域（TST）**——海平面上升、岸线退却、退积，**最大海泛面（MFS）**处为海侵顶点；**高位体系域（HST）**——海平面高位稳定、岸线进积；<span class="marginnote">一次「海侵—海退」旋回就是一个层序的「呼吸」：LST 是呼气（海退）、TST 是吸气（海侵）、HST 是屏息（高位稳定）。这正对应麦克菲那句「世界已经终结过很多次」——海平面旋回在深层历史里反复轮回。</span>
**准层序（parasequence）**：以海泛面为界的小型进积单元——层序的「最小音节」；
- **海进/海退（transgression / regression）**：岸线相对移动的方向，由**相对海平面变化**（全球海平面 + 构造沉降）与**沉积物供给**赛跑决定。

层序地层学的价值在于：它把「钻孔里单调的岩性柱」翻译成**可对比的时间框架**——同一期海退在千里之外的另一个盆地同步发生，据此做区域地层对比、预测砂体（油气储层）的展布。
<span class="marginnote">严格说，海平面有「绝对海平面（eustatic，全球大洋水面）」与「相对海平面（相对盆地底面）」之分；构造沉降能让绝对海平面不变时相对海平面仍上升。这套「全球信号 vs 局部响应」的拆分逻辑，与《气候学》里「外强迫 vs 内反馈」是同一思维模型。</span>

层序地层学在石油勘探里还有一个可操作的形态：**地震层序地层**——地震剖面上，不整合面表现为削截与上超等反射终止模式，据此可在大范围无井区划分层序；钻孔里则靠测井曲线的旋回样式（退积/加积/进积）识别准层序堆叠。
**地震与钻井两套数据的互相印证**，让「层序」从一个概念变成了一张可检验的盆地地层图。

## 5 层序地层学的尺度：从层理到超大陆旋回

层序地层学的魅力在于它**跨尺度自相似**：

- **小尺度**：一次浊流事件（鲍马序列）、一个准层序（一次海泛面旋回）；
- **中尺度**：一个层序（一次三级海平面旋回，约数十万到数百万年）；
- **大尺度**：超层序与超大陆旋回——古生代以来特提斯海的闭合与青藏高原的隆升，可被视作一个「超大陆尺度的巨型层序」。

无论哪个尺度，语法都一样：**海泛面/不整合面切分、体系域排次序、堆叠样式定进退**。
这种「同一语法在多尺度复现」的结构，与《微分方程》里「同一方程在不同尺度下自相似」的直觉、以及机器学习中的层级特征表示，是同一个抽象。

最后给一个综合用例：在一次海侵—海退旋回里，自下而上看通常是「低位河道砂（LST）→ 海泛面 → 海侵滨岸砂与海相泥（TST）→ 最大海泛面 → 高位台地/三角洲（HST）」——同一根岩心，既有沃尔索定律的相序逻辑，又有层序地层学的体系域框架。
两条方法论在此合流：**构造读环境，层序读时间**。

## 6 小结

- **原生沉积构造**是水动力指纹：交错层理定古水流、粒序层理定浊流、干裂定出露、槽模定流向、生物扰动定含氧。
- **沉积环境**按大陆—过渡—海洋三带排列，每种环境有一组特征构造「签名」，相分析即签名匹配。
- **沃尔索定律**：连续剖面里垂向相邻的相 = 曾经的横向相邻环境；有沉积间断即失效。
- **层序地层学**以不整合为界切层序，分低位/海侵/高位体系域，准层序为最小单元；相对海平面 = 绝对海平面 + 构造沉降，再与沉积供给赛跑。
- 海平面旋回与层序对比，是把岩性柱变成时间柱的核心工具。
- 相组合 + 相模式：从「认一块石头」走向「认一片沉积体系」。
- 地震层序（削截/上超）与测井旋回互相印证，让层序可检验。
- 层序地层学跨尺度自相似：事件 → 准层序 → 层序 → 超大陆旋回。
- 综合用例：LST → TST → MFS → HST 一个旋回里，构造读环境、层序读时间。
- 沃尔索定律只对连续剖面成立，不整合面处失效。
