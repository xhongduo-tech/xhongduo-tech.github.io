## 为什么从基本初等函数的导数开始

上一节用定义求导，每求一个函数的导数都要走「求增量 → 平均变化率 → 取极限」三遍。太慢了。数学家已经把基本初等函数的导数全部算好，列成一张**公式表**——我们直接背下来用。这不是偷懒，而是「把一次性的推导换成永恒的结论」：公式表的每一项都从定义严格推出过，以后只需查表。<span class="marginnote">「公式表」的哲学：有限条公式，覆盖一切基本初等函数；配上下一节的四则运算法则与复合函数法则，就能对任何初等函数求导。这就像「字母表 + 拼写规则」：26 个字母（基本函数导数）加上组合规则（运算法则），就能拼出无穷多的词（任意函数的导数）。</span> 公式表是求导运算的地基，务必熟练到「脱口而出」。

## 1 基本初等函数的导数公式表

设 $C$ 为常数，$x$ 为自变量，$a>0$ 且 $a\neq1$，则：

| 函数 | 导数 |
| --- | --- |
| $f(x)=C$ | $f'(x)=0$ |
| $f(x)=x$ | $f'(x)=1$ |
| $f(x)=x^2$ | $f'(x)=2x$ |
| $f(x)=x^n$（$n\in\mathbb{N}^*$） | $f'(x)=nx^{n-1}$ |
| $f(x)=\dfrac1x$ | $f'(x)=-\dfrac{1}{x^2}$ |
| $f(x)=\sqrt{x}$ | $f'(x)=\dfrac{1}{2\sqrt{x}}$ |
| $f(x)=e^x$ | $f'(x)=e^x$ |
| $f(x)=a^x$ | $f'(x)=a^x\ln a$ |
| $f(x)=\ln x$ | $f'(x)=\dfrac1x$ |
| $f(x)=\log_a x$ | $f'(x)=\dfrac{1}{x\ln a}$ |
| $f(x)=\sin x$ | $f'(x)=\cos x$ |
| $f(x)=\cos x$ | $f'(x)=-\sin x$ |

<span class="marginnote">这张表里藏着几条「记忆线」：幂函数 $x^n$ 的导数把指数「搬下来当系数、指数减一」；指数函数 $e^x$ 的导数是自己（$e$ 是唯一「导数为自身」的数）；$\ln x$ 的导数是 $\frac1x$；正余弦互为「对方加符号」。<strong>幂、指、对、三角四族，各有一条记忆线</strong>，别把公式当孤立条目硬背。</span> 更一般地，幂函数 $f(x)=x^\alpha$（$\alpha$ 为任意实数）的导数公式是 $f'(x)=\alpha x^{\alpha-1}$——高中范围常用整数与 $\frac12$、$-1$ 等。

## 2 公式解析：由定义推导 $(x^2)'=2x$ 与 $(e^x)'=e^x$

选两个代表性公式，重温定义推导，理解「公式表不是天上掉下来的」。

**第一步，$(x^2)'$**：$\dfrac{\Delta y}{\Delta x}=\dfrac{(x+\Delta x)^2-x^2}{\Delta x}=\dfrac{2x\Delta x+(\Delta x)^2}{\Delta x}=2x+\Delta x$。令 $\Delta x\to0$，得 $2x$。**展开后约去 $\Delta x$，含 $\Delta x$ 的项消失**——这是幂函数求导的普遍模式。
**第二步，$(e^x)'$**：$\dfrac{e^{x+\Delta x}-e^x}{\Delta x}=e^x\cdot\dfrac{e^{\Delta x}-1}{\Delta x}$。关键极限 $\lim_{\Delta x\to0}\dfrac{e^{\Delta x}-1}{\Delta x}=1$（$e$ 的定义保证），所以导数为 $e^x$。
**第三步，对比**：幂函数靠「展开约分」，指数函数靠「提取 $e^x$ 后那个关键极限」——同一套三步流程，两种化简思路。

<span class="marginnote">「$e^x$ 的导数是自身」是 $e$ 存在的意义之一：在所有指数函数 $a^x$ 中，只有 $a=e$ 时导数等于自身。这个「自相似」性质让 $e$ 成为微积分里最重要的常数——它让含指数的方程、微分方程变得自洽。<strong>记住 $e^x$ 的独特地位：求导不变</strong>，这是它频繁出场的原因。</span> 这些推导现在不必每题重做，但理解「公式从定义来」，用起来才有底气。

## 3 幂函数求导的统一公式与常见变形

**幂函数求导公式**：$(x^\alpha)'=\alpha x^{\alpha-1}$ 对任意实数 $\alpha$ 成立。由此可推：

$(x^3)'=3x^2$，$(x^{-2})'=-2x^{-3}$（把 $\frac{1}{x^2}=x^{-2}$ 用公式）。
$(\sqrt{x})'=\left(x^{1/2}\right)'=\frac12x^{-1/2}=\dfrac{1}{2\sqrt{x}}$。
$\left(\dfrac1x\right)'=\left(x^{-1}\right)'=-x^{-2}=-\dfrac{1}{x^2}$。

<span class="marginnote">「把根式、分式先写成幂的形式，再用统一公式」是幂函数求导的万能手法：$\sqrt{x}=x^{1/2}$、$\frac1{x^2}=x^{-2}$。指数为分数、负数时公式照常成立。<strong>看到根号与分式，第一反应是「改写成幂」</strong>——这是幂函数求导的唯一技巧。</span> 常数函数 $f(x)=C$ 的导数为 0，可视作「$\alpha=0$」的幂函数（$Cx^0$ 的导数是 $0\cdot Cx^{-1}=0$）。

## 4 综合应用与易错辨析

**辨析｜易错点：** 一是**幂函数与指数函数搞混**——$x^n$ 底数是变量、指数是常数，导数是「指数搬系数」；$a^x$ 底数是常数、指数是变量，导数是「自身乘 $\ln a$」。两者求导规则完全不同；二是**$(a^x)'$ 忘乘 $\ln a$**——只有 $e^x$ 不用乘（$\ln e=1$），其余指数都要乘；三是**$\log_a x$ 的导数记错**——是 $\frac{1}{x\ln a}$，不是 $\frac1x$（$\frac1x$ 是 $\ln x$ 的导数）。

**应用例**：求 $f(x)=3x^2+\sin x$ 的导数（预告下节法则）。先分别求：$(3x^2)'=3\cdot2x=6x$，$(\sin x)'=\cos x$，相加得 $f'(x)=6x+\cos x$——**先认函数类型，查表求各部分，再组合**。

<span class="marginnote">「查表组合」是求导的总纲：<strong>一个复杂函数先拆成基本初等函数的组合（加减乘除、复合），各部分查表，再用运算法则拼起来</strong>。本节掌握「查表」，下节掌握「组合法则」，求导就全通了。识别函数类型是第一步：看到 $x^3$ 是幂函数、看到 $3^x$ 是指数函数、看到 $\log$ 是对数——认错类型，公式就套错。</span>

## 5 例题精讲：公式表的综合运用

求导公式的考题考「认类型 + 查表」。看一道题：求 $f(x)=\sqrt{x}+\dfrac{1}{x}+3^x$ 的导数。

**第一步，认类型**：三项分别是幂函数（$\sqrt{x}=x^{1/2}$）、幂函数（$\frac1x=x^{-1}$）、指数函数（$3^x$）——各查各的公式。
**第二步，逐项求导**：$(\sqrt{x})'=(x^{1/2})'=\frac12x^{-1/2}=\frac1{2\sqrt{x}}$；$\left(\frac1x\right)'=(x^{-1})'=-x^{-2}=-\frac1{x^2}$；$(3^x)'=3^x\ln3$。
**第三步，合并**：$f'(x)=\frac1{2\sqrt{x}}-\frac1{x^2}+3^x\ln3$——和差法则逐项相加。

<span class="marginnote">「认类型 → 查表 → 组合」是求导的总纲：<strong>$\sqrt{x}$ 与 $\frac1x$ 都先改写成幂的形式（$x^{1/2},x^{-1}$），再套幂函数公式 $(\alpha x^{\alpha-1})$</strong>。指数函数 $3^x$ 要乘 $\ln3$（只有 $e^x$ 不用乘）。三个类型三种公式，识别错了就套错。<strong>「根式、分式改写成幂」是第一动作</strong>——这个习惯让幂函数公式一网打尽所有幂的形式。</span>

**辨析｜易错点：** 一是**$\sqrt{x}$ 的导数忘 $\frac12$**——$(\sqrt{x})'=\frac1{2\sqrt{x}}$，别写成 $\frac1{\sqrt{x}}$；二是**$\frac1x$ 的导数符号**——$(x^{-1})'=-x^{-2}$，负号不能省；三是**$3^x$ 忘乘 $\ln3$**——只有 $e^x$ 的导数是自身，一般指数 $a^x$ 都要乘 $\ln a$。

## 6 对照表：三大函数族的求导规则

「认错类型 = 套错公式」，把最容易混淆的三族求导规则并排对照：

| 函数族 | 一般形式 | 导数 | 记忆要点 |
| --- | --- | --- | --- |
| 幂函数 | $x^\alpha$ | $\alpha x^{\alpha-1}$ | 指数搬系数、指数减一 |
| 指数函数 | $a^x$ | $a^x\ln a$ | 自身乘 $\ln a$（$e^x$ 例外） |
| 对数函数 | $\log_a x$ | $\frac{1}{x\ln a}$ | 分母多一个 $\ln a$ |
| 自然对数 | $\ln x$ | $\frac1x$ | $\log_a$ 中 $a=e$ 的特例 |
| 正弦 | $\sin x$ | $\cos x$ | 符号不变 |
| 余弦 | $\cos x$ | $-\sin x$ | 前面加负号 |

<span class="marginnote"><strong>判别口诀：底是变量 → 幂函数；底是常数、指数是变量 → 指数函数</strong>。$x^\pi$ 是幂函数（底变），$\pi^x$ 是指数函数（底常）。对数函数是「指数函数的逆」，导数在 $\frac1x$ 的基础上分母多一个 $\ln a$。三角函数的导数互为「对方」，余弦多一个负号——六个类型，三条记忆线。</span>

**辨析｜易错点：** 一是**把 $x^a$ 与 $a^x$ 混为一谈**——前者指数搬系数、后者乘 $\ln a$，两套规则方向完全不同；二是**$\ln x$ 与 $\log_a x$ 的导数**——$\ln x$ 是 $\frac1x$，$\log_a x$ 是 $\frac1{x\ln a}$，别把 $\ln a$ 漏掉或放错位置；三是**$\sin x$ 与 $\cos x$ 的符号**——$\sin$ 求导得 $\cos$（无负号），$\cos$ 求导得 $-\sin$（有负号），别记反。

## 7 术语速查表

| 术语 | 记号 / 公式 | 一句话释义 |
| --- | --- | --- |
| 常数函数 | $(C)'=0$ | 不变化的函数导数为 0 |
| 幂函数 | $(x^\alpha)'=\alpha x^{\alpha-1}$ | 指数搬系数、减一 |
| 指数函数 | $(a^x)'=a^x\ln a$ | 自身乘 $\ln a$ |
| 自然指数 | $(e^x)'=e^x$ | 唯一「导数为自身」 |
| 自然对数 | $(\ln x)'=\frac1x$ | 最简对数求导 |
| 一般对数 | $(\log_a x)'=\frac1{x\ln a}$ | 分母多 $\ln a$ |
| 正弦 / 余弦 | $(\sin x)'=\cos x,(\cos x)'=-\sin x$ | 互变，余弦带负号 |
| 导数公式表 | — | 由定义严格推出的「查表库」 |

**记忆线索**：求导公式表的全部秘密在三条线上——幂函数「指数搬家减一」、指数函数「乘 $\ln a$（$e$ 除外）」、对数函数「$x$ 分之一再除 $\ln a$」；配上「认类型 → 查表 → 组合」的总纲，求导不再需要临场推导。

## 8 小结

- **公式表**：常数 0、幂函数 $\alpha x^{\alpha-1}$、指数 $a^x\ln a$、对数 $\frac{1}{x\ln a}$、正余弦互变。
- **$e^x$ 的独特地位**：导数为自身；$\ln x$ 的导数是 $\frac1x$。
- 根式、分式先改写为幂再求导。
- **幂 vs 指数**：$x^n$ 指数搬系数，$a^x$ 乘 $\ln a$——两套规则别混。
- 求导总纲：**认类型 → 查表 → 组合**（组合法则下一节）。
