## 为什么从空间位置关系开始

平面几何里两条直线只有相交与平行两种关系。空间里多了一个维度，关系立刻复杂：两条直线可以不相交、不平行——它们**异面**。这个「第三种关系」是空间区别于平面的标志，也是立体几何题的核心难点。本节系统盘点空间中的全部位置关系：直线与直线、直线与平面、平面与平面，各有多少种可能、如何判定。<span class="marginnote">异面直线是空间独有的现象：它提醒我们，直觉从平面搬到空间会失效——「不相交也不平行」的直线在平面里不存在，在空间里却比比皆是（天花板上的横梁与墙面上的竖线）。培养空间想象力，就是从打破「平面直觉」开始。</span> 这份「位置关系清单」是后面平行、垂直判定的索引地图：每一节都是在某条关系上装「判据」。

## 1 空间中直线与直线的位置关系

空间中两条直线有三种位置关系：

**相交**：有且只有一个公共点。
**平行**：在同一平面内，且没有公共点。
**异面**：不同在任何一个平面内（没有公共点，也不在同一平面内）。

**重点：异面直线（skew lines）的判断标准是「不同在任何一个平面内」**——两条直线既不相交也不平行，就一定异面。平行与异面的区别在于：平行直线**总能找到**一个平面同时包含它们（过两条平行直线有唯一平面，见上节推论），而异面直线**找不到**这样的平面。<span class="marginnote">直观判异面：「一上一下、一前一后」的两条线，就像楼梯扶手与地面边线——它们既不相交也不平行，无法放进同一平面。判定异面的常用工具是「与直线相交的平面」：若一条直线在平面内，另一条直线与平面相交但交点不在第一条直线上，则两线异面。</span>

空间两条直线的公共性质：**过直线外一点有且只有一条直线与已知直线平行**（传递性也成立：若 $a\parallel b$ 且 $b\parallel c$，则 $a\parallel c$）。这条「平行的传递性」在空间依旧成立，是后续证明平行关系的基石。

## 2 直线与平面的位置关系

一条直线与一个平面的位置关系有三种：

**直线在平面内**：直线上有两点在平面内（公理 2 判定），有无数个公共点。
**直线与平面相交**：有且只有一个公共点，记作 $a\cap\alpha=A$。
**直线与平面平行**：没有公共点，记作 $a\parallel\alpha$。

三种关系合起来：「直线不在平面内」= 平行或相交。**特别地，直线与平面平行，不能与「直线在平面内」混淆**——平行的直线无限延伸也不进入平面，直线在平面内则整条线都在面里。<span class="marginnote">画图约定：直线与平面平行时，把直线画在平面外侧；相交时画一条穿过平行四边形的线，交点处点出实点。读图时看清「穿过去」还是「在侧面」，是识别相交与平行的第一眼信息。</span>

## 3 平面与平面的位置关系

两个平面之间的位置关系只有两种：

**平面与平面平行**：没有公共点，记作 $\alpha\parallel\beta$。
**平面与平面相交**：有且只有一条公共直线（公理 3 保证交线唯一），记作 $\alpha\cap\beta=\ell$。

<span class="marginnote">两个平面不会「只有一个公共点」——由公理 3，两个平面一旦有公共点，就共享整条交线。这是空间与平面直觉的又一差异：平面几何里两线相交于一点，空间里两面相交于一线。</span> 面面相交的交线可以垂直（像书页）、也可以斜交；当交角为直角时，叫**面面垂直**（后续 §8.6 详述）。面面平行的直观：像两层楼板，永远碰不到一起。

## 4 核心对比表：三类位置关系总览

> 纯概念主题：本节以位置关系的分类与判定为主，用核心对比表一次摊清全部关系。

| 对象 | 位置关系 | 公共点 | 判定要点 |
| --- | --- | --- | --- |
| 直线与直线 | 相交 | 1 个 | 交点唯一 |
| 直线与直线 | 平行 | 0 个 | 共面且无公共点 |
| 直线与直线 | 异面 | 0 个 | 不共面 |
| 直线与平面 | 在平面内 | 无数个 | 直线上两点在面内 |
| 直线与平面 | 相交 | 1 个 | 直线穿过平面 |
| 直线与平面 | 平行 | 0 个 | 无公共点 |
| 平面与平面 | 相交 | 整条交线 | 共线公共点 |
| 平面与平面 | 平行 | 0 个 | 无公共点 |

这张表是空间位置关系的「户口簿」：先问对象是「线线」「线面」还是「面面」，再逐行对照，找到对应的位置关系与判定思路。<span class="marginnote">记忆要点：公共点的个数从 0 到无数，正好区分各种关系——「0 个公共点」的三种关系（线线平行、线线异面、线面平行、面面平行）最容易混淆，判定时先看「是否共面」，再看「是否有公共点」，两步走。</span>

## 5 公式解析：异面直线所成的角

异面直线没有公共点，谈不上「夹角」，但我们仍可以定义它们之间的角——**异面直线所成的角**：

将两条异面直线 $a,b$ 平移，使它们相交于一点 $O$，则 $a,b$ 的夹角中**不大于直角**的那个角（即 $\left(0,\frac{\pi}{2}\right]$ 内的角）叫作异面直线 $a$ 与 $b$ 所成的角（或夹角）。

**第一步，为什么能平移**：由向量概念里的「向量的自由性」，直线平移不改变方向，所以平移后所成的角与原直线的「方向关系」一致。
**第二步，为什么取小角**：两条直线相交产生四个角，两两互补。取不大于 $90^\circ$ 的那个，保证异面直线所成的角**唯一且范围确定**——$\theta\in\left(0,\frac{\pi}{2}\right]$。当 $\theta=\frac{\pi}{2}$ 时，称异面直线互相垂直。
**第三步，怎么用**：求异面直线所成的角，标准做法是「**平移构造角，解三角形算角**」——选一条直线上的一点，作另一条直线的平行线，把异面角「搬」进一个三角形里，用余弦定理或三角函数求角。<span class="marginnote">「平移构造角」是异面角题的唯一套路：把两根「歪着」的线中的一条平移，直到与另一条相交，异面角就变成平面角。后续用向量法求异面角会更简单（详见《空间向量》一章），但「平移找角」依然是理解几何意义的根本。</span>

**辨析｜易错点：** 一是**忘记范围**——异面直线所成的角永远不超过 $90^\circ$，算出钝角要取它的补角；二是**误以为异面直线有交点**——异面直线永不相交，「所成的角」是定义在方向上的角，不是真实存在的几何角；三是**把「异面垂直」与「相交垂直」混淆**——两者都称垂直，但异面垂直的两条直线没有交点。

## 6 例题精讲：正方体中的位置关系

正方体是最好的「位置关系标本」。看一道题：在正方体 $ABCD$-$A'B'C'D'$ 中，（1）指出 $AB'$ 与 $CD$ 的位置关系；（2）指出 $AB'$ 与 $CC'$ 的位置关系；（3）指出 $AB'$ 与 $A'B$ 的位置关系。

**第一步，判断 $AB'$ 与 $CD$**：$AB'$ 与 $CD$ 一上一下、一斜一横——它们不相交（$CD$ 在底面 $ABCD$，$AB'$ 不在底面），也不平行（方向不同），且不能放进同一平面——**异面**。
**第二步，判断 $AB'$ 与 $CC'$**：$AB'$ 在平面 $ABB'A'$ 内，$CC'$ 与这个平面交于 $C'$，但 $C'$ 不在 $AB'$ 上——由「线在面内 + 线与面相交但交点不在该线上」的判据，两线**异面**。
**第三步，判断 $AB'$ 与 $A'B$**：两条都是正方体一个面的对角线，$AB'$ 与 $A'B$ 是矩形 $ABB'A'$ 的两条对角线，**相交**于中心。

<span class="marginnote">判断空间两直线位置关系的三步法：<strong>先看是否相交（找交点）→ 再看是否平行（比方向）→ 都不是则异面</strong>。在正方体这样的具体图形里，「同面看交、异面看错开」是快捷直觉——两条棱要么相交（共面有交点）、要么异面（既不共面也无交点）。正方体的 12 条棱与 6 个面提供了练习位置关系的全套标本。</span>

**辨析｜易错点：** 一是**把「不在同一平面」误判为「平行」**——平行要求共面且无公共点，异面是不共面，两者都要「无公共点」但共面性不同；二是**异面垂直与相交垂直混淆**——$AB'$ 与 $CC'$ 异面且可垂直（方向垂直），但无交点；三是**位置关系的判定要落实到具体图形**——画个正方体，把每条棱标出来，比空想可靠。

正方体这一课值得反复「走一遍」：从底面开始逐条棱判断与 $AB'$ 的关系——共面的看交、不共面的看异面。把 12 条棱全部归类，空间位置关系就真正长在了直觉里。

## 7 术语速查表

| 术语 | 记号 / 条件 | 一句话释义 |
| --- | --- | --- |
| 相交直线 | 一个公共点 | 共面且相交 |
| 平行直线 | 共面、无公共点 | 同一平面内的不交直线 |
| 异面直线 | 不共面 | 空间独有，既不相交也不平行 |
| 线在面内 | $a\subset\alpha$ | 无数个公共点 |
| 线面相交 | $a\cap\alpha=A$ | 一个公共点 |
| 线面平行 | $a\parallel\alpha$ | 无公共点 |
| 面面相交 | $\alpha\cap\beta=\ell$ | 公共部分是整条交线 |
| 面面平行 | $\alpha\parallel\beta$ | 无公共点 |
| 异面角 | $\theta\in(0,\frac{\pi}{2}]$ | 平移后取锐角或直角 |
| 平行传递性 | $a\parallel b,b\parallel c\Rightarrow a\parallel c$ | 空间依旧成立的传递 |
| 过直线外一点 | 唯一平行线 | 空间里的公理式结论 |
| 公理 3 | 两面相交于一线 | 交线唯一的保证 |

**记忆线索**：位置关系按「对象配对」记忆——线线三种、线面三种、面面两种；「公共点个数（0 / 1 / 无数）」与「是否共面」两个维度，足以区分全部关系。

## 8 小结

- **线线**三种关系：相交、平行、**异面**；异面是空间独有，判据是「不同在任何一个平面内」。
- **线面**三种关系：在平面内、相交、平行；「不在面内」= 平行或相交。
- **面面**两种关系：平行、相交（公共部分是交线）；两面不会「只有一个公共点」。
- **异面直线所成的角**：平移相交取锐角（或直角），范围 $\left(0,\frac{\pi}{2}\right]$；求角套路是「平移构造角，解三角形算角」。
- 判定顺序：先问线线/线面/面面，再查「是否共面」「公共点个数」。
