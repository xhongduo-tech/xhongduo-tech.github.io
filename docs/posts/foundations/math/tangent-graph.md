## 为什么从正切函数的图象与性质开始

上一节我们把正弦、余弦作为函数研究了个遍：图象、周期、奇偶、单调、最值。现在轮到第三个主角——**正切函数**。你可能会想：都是三角函数，无非再走一遍老流程。可正切会给你一场全新的刺激。<span class="marginnote">正切是三个三角函数里唯一的「分式函数」：它等于两个函数之比 $\frac{\sin x}{\cos x}$。正因为分母会取零，「比值爆炸」的现象出现了。</span>

正切函数有三个地方与正弦、余弦**截然不同**：周期只有 $\pi$（短一半）、值域是全体实数（不再被夹在 $[-1,1]$ 里）、图象上有无数条垂直渐近线（会「冲上云霄」）。这是你第一次遇见「函数值趋于无穷」——它预告了分数、极限这些更深的主题。希尔伯特说「无限」最能打动人心，而正切函数正是你在中学阶段与「无限」最近距离的一次照面。

## 1 定义域：一场「减法」

从定义出发。$\tan x = \dfrac{\sin x}{\cos x}$，分母不能为零，即 $\cos x \neq 0$。于是正切函数的定义域要把正弦、余弦定义域 $\mathbb{R}$ **扣除**使 $\cos x = 0$ 的那些点：

$$x \neq \frac{\pi}{2} + k\pi, \qquad k \in \mathbb{Z}$$

这些被扣除的点，恰好是终边落在 $y$ 轴上的角：$\pm\frac{\pi}{2}, \pm\frac{3\pi}{2}, \pm\frac{5\pi}{2}, \ldots$，每隔 $\pi$ 出现一个。<span class="marginnote">「排除法」定义域在数学里很常见：一个由比值定义的函数，天然带着「分母不为零」的附加条款。后面学分式函数、对数函数时，你会反复做同样的「排除」。</span>

**辨析｜易错点：** $\tan x$ 的定义域是 $\{x \mid x \neq \frac{\pi}{2} + k\pi\}$，而**不是**「$x \neq \frac{\pi}{2}$」。$k$ 要跑遍所有整数——$-\frac{\pi}{2}, \frac{3\pi}{2}, \frac{5\pi}{2}, \ldots$ 全都不能取。漏掉 $k \in \mathbb{Z}$ 是这类题的高频错误，因为每间隔 $\pi$ 就有一处无定义。

这些被扣除的点在单位圆上的位置很好认：**终边落在 $y$ 轴上的角**。此时交点坐标为 $(0, \pm 1)$，横坐标 $x = 0$，比值 $y/x$ 无从谈起。**「无定义」不是函数的缺陷，而是比值函数的出厂设置**——定义 $y/x$ 的那一刻，$x = 0$ 就天然被排除在外了。

## 2 周期性：为什么是 π

正弦、余弦每转一整圈（$2\pi$）回到自己，正切却**每转半圈（$\pi$）就回到自己**。直觉来自单位圆：角 $\alpha$ 转半圈到达 $\pi + \alpha$，交点坐标由 $P(x,y)$ 变成 $P(-x,-y)$，横纵坐标都变了号，可**比值** $y/x$ 却因为分子分母同变号而保持不变：

$$\tan(\pi + \alpha) = \frac{-y}{-x} = \frac{y}{x} = \tan\alpha$$

**重点：** 因此 $\pi$ 是正切函数的周期，而且是**最小正周期**——没有任何小于 $\pi$ 的正数能成为它的周期。这一点在图象上表现为：正切曲线的每个「单元」只占宽度 $\pi$，比正弦的 $2\pi$ 紧凑一半。<span class="marginnote">「转半圈比值不变」说的其实是直线方向不变：过原点的直线，反向延长后斜率相同。斜率就是正切，所以正切的周期等于「直线方向重合所需的旋转角」$\pi$，这比正弦的 $2\pi$ 更几何。</span>

与正弦对照着记：$\sin(x + \pi) = -\sin x$（变号，故周期 $2\pi$），而 $\tan(x + \pi) = \tan x$（不变号，故周期 $\pi$）。**「周期短一半」的根源，就藏在「转半圈之后正切值是否复原」这个判断里。**

## 3 正切函数的图象：渐近线登场

作正切函数的图象，可以借助**正切线**：过单位圆上 $(1, 0)$ 作圆的切线（即直线 $x = 1$），把角 $\alpha$ 的终边（或其反向延长线）与这条切线相交，交点的纵坐标就是 $\tan\alpha$。<span class="marginnote">「正切」的英文 tangent 原意就是「切线」。正切线是三角函数线家族里唯一画在圆外的成员，它告诉我们正切值可以任意大——不像正弦线、余弦线那样被限制在单位圆内。</span>

先看一个单元 $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$：

- 当 $x$ 从 $0$ 增大到 $\frac{\pi}{2}$，正切线不断变长，$\tan x$ 从 $0$ 一路**趋于正无穷**；
- 当 $x$ 从 $0$ 减小到 $-\frac{\pi}{2}$，正切线反向延伸，$\tan x$ 从 $0$ 一路**趋于负无穷**。

把这两个方向的曲线连起来，就得到正切曲线的一个「分支」。它从左下方向右上方攀升，像一条被两堵竖直的墙夹住的斜坡——那两堵墙就是**垂直渐近线（vertical asymptote）**。

$$x = \frac{\pi}{2} + k\pi, \qquad k \in \mathbb{Z}$$

**重点：** 每条渐近线两侧，函数值分别奔向 $+\infty$ 与 $-\infty$，但曲线**永远不会穿过或触碰渐近线**——因为在那条线上 $\cos x = 0$，正切无定义。渐近线是「函数在这里不存在，却把图象的走向框死」的界线。整个定义域被这些渐近线切成无穷多个互不相连的「分支」，每个分支形貌相同、错开 $\pi$ 排列。

**作图的完整策略：** 第一步，画出两条相邻渐近线 $x = -\frac{\pi}{2}$ 与 $x = \frac{\pi}{2}$；第二步，找这个分支上的两个特殊点：过原点 $(0, 0)$，以及 $\tan\frac{\pi}{4} = 1$ 对应的点 $\left(\frac{\pi}{4}, 1\right)$；第三步，从 $x$ 靠近 $-\frac{\pi}{2}$ 处自 $-\infty$ 起，穿过这两个特殊点，攀升到 $x$ 靠近 $\frac{\pi}{2}$ 处的 $+\infty$，画出一条递增曲线。最后，把这条曲线沿 $x$ 轴左右平移 $\pi$ 的整数倍，就得到完整的正切曲线——**每一个分支都长一个样，只是起点不同**。<span class="marginnote">「画一个单元，再平移铺满整个平面」是画周期函数的通用套路：画正弦是这样，画正切也是这样。图象一旦借由周期铺开，性质就尽收眼底。</span>

## 4 公式解析：tan(x + π) = tan x

这一条是整个正切「性格」的源头，把它的四步推导写清楚：

$$
\tan(x + \pi) = \tan x
$$

- **第一步，化弦**：用商数关系把正切写成弦之比，$\tan(x+\pi) = \dfrac{\sin(x+\pi)}{\cos(x+\pi)}$。这是正切问题里的标准起手式——遇到正切，先写成弦。
- **第二步，套诱导公式**：上一节学过 $\sin(x+\pi) = -\sin x$、$\cos(x+\pi) = -\cos x$。这两个变号正是「终边转半圈，坐标都变号」的代数表达。
- **第三步，作商抵消**：$\dfrac{\sin(x+\pi)}{\cos(x+\pi)} = \dfrac{-\sin x}{-\cos x} = \dfrac{\sin x}{\cos x}$。分子分母同乘 $-1$，负号约去。
- **第四步，认回正切**：$\dfrac{\sin x}{\cos x} = \tan x$，于是 $\tan(x+\pi) = \tan x$，$\pi$ 是周期。

**要点：** 整个推导的「戏眼」在第三步——分子分母**同时变号**，比值不变。对比正弦：$\sin(x+\pi) = -\sin x$，它变号了，所以正弦的周期是 $2\pi$；而正切因「同号相除」把变号抵消掉了，周期于是减半为 $\pi$。**周期长短，取决于对称操作下「比值变不变」。**

**辨析｜易错点：** 千万别写 $\tan\frac{\pi}{2} = \infty$ 之类的式子。$\frac{\pi}{2}$ 不在正切的定义域内，$\tan\frac{\pi}{2}$ **不存在**——它既不是 $+\infty$ 也不是 $-\infty$，而是「无定义」。图象上的渐近线表达的是「当 $x$ 从两侧趋近 $\frac{\pi}{2}$ 时，$\tan x$ 分别奔向 $+\infty$ 与 $-\infty$」，这是**趋近**，不是**取值**。把「趋近」写成「等于」，是把无限的过程误解成有限的结果，这是初学渐近线最常见的病句。

## 5 单调性与值域

看任何一个分支，比如 $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$：

- **单调性**：$\tan x$ 在该区间内**单调递增**——从 $x$ 靠近 $-\frac{\pi}{2}$ 时的 $-\infty$，一路增加到 $x$ 靠近 $\frac{\pi}{2}$ 时的 $+\infty$，中间没有任何回头路。
- **值域**：由「能取到任意大的正值、任意大的负值」可见，正切函数的值域是**全体实数 $\mathbb{R}$**。这是它与正弦（值域 $[-1,1]$）、余弦（值域 $[-1,1]$）最大的分水岭。

推广到每个分支：对任意整数 $k$，$\tan x$ 在开区间 $\left(-\frac{\pi}{2} + k\pi, \ \frac{\pi}{2} + k\pi\right)$ 内单调递增。<span class="marginnote">「值域是全体实数」意味着正切能覆盖整条数轴，这让它在「已知正切值求角」的问题里永远有解——反函数 $\arctan$ 也因此能定义在整个 $\mathbb{R}$ 上，这是后话。</span>

**旁白：正切就是斜率。** 过原点的直线 $y = kx$，其倾斜角为 $\alpha$，则斜率 $k = \tan\alpha$。一条直线越接近竖直，斜率越大，对应的角越接近 $\frac{\pi}{2}$——这正是正切「趋于无穷」的几何化身。斜率可以是任何实数（水平直线斜率为 $0$，竖直直线没有斜率），这也正是正切值域为 $\mathbb{R}$、且 $\frac{\pi}{2}$ 处无定义的原因。**「正切 = 斜率」这条等价关系，会在后面直线的倾斜角与斜率一节中正式登场，此处先埋下伏笔。**

**辨析｜易错点：** **不能说「正切函数在其定义域上单调递增」**。因为定义域被渐近线切成了无穷多个互不相连的开区间，相邻分支之间由渐近线隔开，函数值并不连续地增大（$x = -\frac{\pi}{4}$ 处取 $-1$，$x = \frac{\pi}{4}$ 处取 $1$，中间隔着 $x = \frac{\pi}{2}$ 这个无定义点）。正确的表述是：**在每一个开区间 $\left(-\frac{\pi}{2} + k\pi, \frac{\pi}{2} + k\pi\right)$ 内单调递增**。这也是正切与正弦、余弦在单调性表述上的本质差别。

**例（比较大小）：** 比较 $\tan 1$ 与 $\tan 2$ 的大小。注意 $1$ 与 $2$ 都是弧度制的角，且 $1, 2 \in \left(0, \frac{\pi}{2}\right) \cup \left(\frac{\pi}{2}, \pi\right)$。$1 < \frac{\pi}{2}$，$2 > \frac{\pi}{2}$，两者**不在同一个分支**内，不能直接套用单调性。事实上 $\tan 1 > 0$（第一象限），而 $\tan 2 < 0$（第二象限），故 $\tan 1 > \tan 2$。**教训：用正切的单调性比较大小，先确认两个角落在同一个开区间分支内**，否则靠符号判断。

**例（求定义域）：** 求函数 $y = \sqrt{\tan x}$ 的定义域。需 $\tan x \geq 0$。正切在 $[0, \frac{\pi}{2})$ 内从 $0$ 增到 $+\infty$，恒非负；再由周期 $\pi$ 铺开，得定义域为 $\left[k\pi, \frac{\pi}{2} + k\pi\right)$，$k \in \mathbb{Z}$。注意到区间**左闭右开**——$x = k\pi$ 处 $\tan x = 0$ 可取，$x = \frac{\pi}{2} + k\pi$ 处无定义不可取。

## 6 与正弦、余弦的三点对照

把三个函数摆在一起，差别一目了然：

| 性质 | $y = \sin x$ | $y = \cos x$ | $y = \tan x$ |
| --- | --- | --- | --- |
| 定义域 | $\mathbb{R}$ | $\mathbb{R}$ | $x \neq \frac{\pi}{2} + k\pi$ |
| 值域 | $[-1, 1]$ | $[-1, 1]$ | $\mathbb{R}$ |
| 最小正周期 | $2\pi$ | $2\pi$ | $\pi$ |
| 奇偶性 | 奇 | 偶 | 奇 |
| 最大值/最小值 | 有 | 有 | 无 |
| 渐近线 | 无 | 无 | $x = \frac{\pi}{2} + k\pi$ |

这张表值得停在最后两行想一下：正切**没有最值、没有渐近线之外的无定义点**，是因为它是「比值」。凡是由比值定义的函数（正切、分式函数、甚至后续的斜率、概率密度），都要警惕「分母为零」的时刻——那正是函数「爆开」成 $\pm\infty$、或干脆消失的地方。<span class="marginnote">「分母为零导致比值爆炸」这条直觉，会在第三级《数学分析》里正式化为「极限不存在」「有无穷间断点」等严格语言；此刻你先在正切图象上提前预演一遍。</span>

## 7 小结

- **定义域**：$x \neq \frac{\pi}{2} + k\pi$，每间隔 $\pi$ 扣除一个点；$\tan x$ 是分式函数，分母 $\cos x$ 不能为零。
- **周期性**：最小正周期是 $\pi$，由「终边转半圈、坐标同变号、比值不变」得来。
- **图象**：由正切线作出；有垂直渐近线 $x = \frac{\pi}{2} + k\pi$，曲线被切成无穷多个互不相连的分支。
- **单调性与值域**：在每个开区间 $\left(-\frac{\pi}{2}+k\pi, \frac{\pi}{2}+k\pi\right)$ 内单调递增；值域为 $\mathbb{R}$，**无最大值、最小值**。
- **易错**：不能说「在定义域上单调递增」；周期是 $\pi$ 而非 $2\pi$；定义域别漏写 $k \in \mathbb{Z}$。
- **与斜率的联系**：直线 $y = kx$ 的斜率等于其倾斜角的正切，这是正切在解析几何中的用武之地。

在下一节，我们将走出「一个角」的框架，研究**两个角**之间三角函数的关系：$\sin(\alpha + \beta)$ 能不能用 $\sin\alpha, \cos\alpha, \sin\beta, \cos\beta$ 表示？答案是——能，而且由此会展开整片三角恒等变换的森林。
