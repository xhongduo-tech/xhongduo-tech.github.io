## 为什么从解三角形的应用开始

上一节我们得到了解三角形的两把钥匙，本节把它们插进真实世界的锁里。山有多高？河有多宽？航船离岸边还有多远？古代测绘者靠步测与估算，今天一个手持测距仪的人就能答出精确数字——背后的数学，全是对两个定理的**建模应用**。本节练习的与其说是「算」，不如说是「翻译」：把一句话描述的现实情境，画成示意图，翻译成三角形，再选对定理求解。<span class="marginnote">高斯本人主持过汉诺威王国的三角测量，把测地学做成了一门精密科学。解三角形不只是课本习题，它是整个大地测量、天文测量、导航定位的数学地基——GPS 里的三角定位，原理与之同源。</span> 这种「现实 → 数学 → 现实」的回路，是「从极限到大模型」里最可迁移的一项能力。

## 1 测量中的几个标准角度

应用题里反复出现几个角度术语，先统一认全：

**仰角（angle of elevation）**：视线在水平线上方，视线与水平线的夹角。
**俯角（angle of depression）**：视线在水平线下方，视线与水平线的夹角。
**方位角（azimuth）**：从正北方向顺时针转到目标方向所转过的水平角，范围 $[0^\circ, 360^\circ)$。
**方向角**：从正北或正南方向起，偏向东或西的角，如「北偏东 $30^\circ$」。

<span class="marginnote">仰角俯角都从水平线量起，方向角从南北线量起——<strong>基准不同，别混着用</strong>。读题时先在示意图上标出这些角，再认它们所在三角形，是建模第一步，也是丢分最少的检查点。</span> 这些角定义了三角形的内角或外角，把「现实角度」装进三角形之后，解三角形的定理才有用武之地。

## 2 建模四步法

解三角形应用题有一套固定的四步流程，务必按序执行：

1. **画图**：把文字情境画成示意图，标出已知量与所求量，标出所有角度。
2. **造三角形**：在图中找（或构造）能覆盖已知与所求的三角形，必要时连接辅助线。
3. **选定理**：看已知条件匹配哪类——SAS/SSS 用余弦定理，AAS/ASA 用正弦定理，SSA 用正弦定理并讨论解数。
4. **算与验**：计算并检查结果是否符合现实（高度、距离应为正数，角度应在合理范围）。

**重点：建模失败往往不在计算，而在「找错三角形」**——已知量散落在两个三角形里，就需要先在一个三角形中算出过渡量，再转入目标三角形。这类「连环三角形」问题是应用题难度的主要来源，但流程依然是：**一步只解一个三角形**。

## 3 公式解析：测河宽

设河的一岸有两点 $A$、$B$，另一岸有目标点 $C$。测得 $AB=d$ 米，$\angle CAB=\alpha$，$\angle CBA=\beta$，求河宽（$C$ 到 $AB$ 所在直线的垂直距离）。

**第一步，认三角形**：$A,B,C$ 构成三角形，已知两角 $\alpha,\beta$ 与一边 $AB=d$，属 AAS——**用正弦定理**。
**第二步，求一条斜边**：先求 $AC$。$\angle C=180^\circ-\alpha-\beta$，由正弦定理 $\dfrac{AC}{\sin\beta}=\dfrac{d}{\sin C}$，得 $AC=\dfrac{d\sin\beta}{\sin(\alpha+\beta)}$（这里用 $\sin C=\sin(\alpha+\beta)$）。
**第三步，转直角三角形**：河宽是 $C$ 到 $AB$ 的垂距 $h$。在直角三角形 $ACD$（$D$ 为垂足）中，$h=AC\sin\alpha=\dfrac{d\sin\alpha\sin\beta}{\sin(\alpha+\beta)}$。

整个问题的骨架是「**正弦定理求出斜边，再在直角三角形里用锐角三角函数求高**」——一次定理、一次正弦，两步拼出答案。<span class="marginnote">注意到河宽 $h$ 只依赖 $d,\alpha,\beta$ 三个可测的量：在地面上量出两个角和一段基线，就能间接测出够不着的地方的距离。这就是「不可到达物体的测量」的标准套路。</span>

## 4 航海与定位：方位角的综合应用

航海问题常在两个三角形之间切换。例：一艘船从 $A$ 出发沿北偏东 $60^\circ$ 方向航行，一段时间后在 $B$ 点测得灯塔 $P$ 在北偏西 $30^\circ$，继续航行至 $C$ 点测得 $P$ 在北偏东 $45^\circ$，已知 $AB=BC=20$ 海里，求船与灯塔的最近距离。这类题的难点在**把三个方位角翻译成三角形的内角**：

$\angle PAB=60^\circ$（船行方向与正北夹角 $60^\circ$，$P$ 在航线北侧）。
$\angle PBC=30^\circ$（$P$ 在 $B$ 点北偏西 $30^\circ$，而航线方向是北偏东 $60^\circ$，夹角为 $60^\circ+30^\circ=90^\circ$……按具体图定角）。

**辨析｜易错点：** 方位角题的三个高频错误：一是**角的基准认错**——北偏东从正北量，东偏北从正东量，一字之差角就错 $90^\circ$；二是**内外角混淆**——三角形内角与外角相差 $180^\circ$ 或互为补角，标图时要把方位角「换算」成三角形内角再代入定理；三是**单位与近似**——海里、千米、米要统一，中间结果保留足够位数，避免误差累积。<span class="marginnote">「先画标准方位图，再逐角标内角」是解这类题的纪律：方位角是「外部视角」，三角形内角是「内部视角」，两者之间要过一道翻译。这道翻译错了，后面算得再准也没用。</span>

## 5 例题精讲：两次测角求高度

解三角形应用题的经典题型是「测高」，常需两个仰角。看一道题：在塔的正前方 $A$ 处测得塔顶仰角为 $30^\circ$，后退 50 米到 $B$ 处再测，仰角为 $15^\circ$，求塔高。

**第一步，画图与设元**：设塔顶 $P$、塔底 $Q$，$A$ 在 $Q$ 正前方，$B$ 在 $A$ 后方 50 米。$\angle PAQ=30^\circ$，$\angle PBQ=15^\circ$，$AB=50$，塔高 $PQ=h$，$AQ=d$。
**第二步，用两次仰角的直角三角形**：$\triangle PAQ$ 中 $\tan30^\circ=\frac hd$，$d=\frac{h}{\tan30^\circ}=\sqrt3 h$；$\triangle PBQ$ 中 $\tan15^\circ=\frac{h}{d+50}$。
**第三步，联立求解**：$d+50=\frac{h}{\tan15^\circ}$，代入 $d=\sqrt3h$：$\sqrt3h+50=\frac{h}{\tan15^\circ}$。用 $\tan15^\circ=2-\sqrt3$：$\sqrt3h+50=(2+\sqrt3)h$，$50=2h$，$h=25$ 米。

<span class="marginnote">「两次测角求高」的建模套路：<strong>两个仰角在两个直角三角形里，公共边是塔高 $h$，把水平距离 $d$ 用 $h$ 表达，再联立消 $d$</strong>。核心是「公共未知量搭桥」——$d$ 与 $h$ 在两个三角形里反复出现，用三角函数的定义建立关系。$\tan15^\circ=2-\sqrt3$ 这类特殊角的正切要会用。测高问题还能推广到「不可到达」场景——两次测角正是为了抵消「够不着塔底」的困难。</span>

**辨析｜易错点：** 一是**角的基准画错**——仰角从水平线量，$30^\circ$ 是视线与水平的夹角，不是与竖直线的夹角；二是**「后退 50 米」的方向**——$B$ 在塔的同一侧后方，$PBQ$ 的水平距离是 $d+50$，不是 $d-50$；三是**特殊角正切值用错**——$\tan15^\circ=2-\sqrt3$（不是 $\sqrt3-2$），代错则答案全错。

## 6 解三角形应用题的常见模型

解三角形的应用题可以归纳成几个固定模型，识别模型是解题的捷径。

### 模型一：测高（两次测角）

前一节的「两次测角求高」——两个仰角在两个直角三角形里，公共边是高度，联立求解。

### 模型二：测距（不可到达点）

要测河中两点 $C,D$ 的距离（岸上够不着），在岸上取基线 $AB$，测出 $\angle CAB,\angle DAB,\angle CBA,\angle DBA$ 与 $AB$——先在 $\triangle ABC$、$\triangle ABD$ 中用正弦定理求 $AC,AD$，再在 $\triangle ACD$ 中用余弦定理求 $CD$。「基线 + 两角 → 正弦定理 → 余弦定理」三步走。

### 模型三：航海方位

船在不同位置观测同一目标，把方位角翻译成三角形内角，解两个相连的三角形——「先翻译方位角，再逐三角形求解」。

### 模型四：三角形面积

$S=\frac12ab\sin C=\frac12bc\sin A=\frac12ca\sin B$——两边夹一角求面积，是正弦定理的姊妹公式。结合余弦定理可以「三边求面积」（海伦公式的简化版）：已知三边，先用余弦定理求某角余弦，再求正弦算面积。

<span class="marginnote">四大模型的共同点是「把现实图形翻译成三角形」：<strong>测高用「两个直角三角形共享高」，测距用「基线 + 正弦定理 + 余弦定理」，航海用「方位角转内角」，面积用「$\frac12 ab\sin C$」</strong>。识别模型后，解三角形就变成「选定理、代公式」的机械流程。面积公式 $S=\frac12ab\sin C$ 与正弦定理同源，务必记住——它是「两边夹角求面积」的直接工具。</span>

**辨析｜易错点（补充）：** 一是**面积公式漏 $\frac12$ 或 $\sin$**——$S=\frac12ab\sin C$，别写成 $ab\sin C$ 或 $\frac12 ab$；二是**测距模型中「不可到达」的目标**——先算过渡边（$AC,AD$）再算目标边（$CD$），跳步会缺条件；三是**方位角的基准**——北偏东从正北量、东偏北从正东量，翻译成内角前先统一基准。

## 7 对照表：四大应用模型速查

把解三角形的应用模型汇总成表，识别后直接套流程：

| 模型 | 情境 | 流程 |
| --- | --- | --- |
| 测高 | 两次测角、不可到达塔底 | 两个直角三角形共享高，联立消距离 |
| 测距 | 不可到达的河中两点 | 基线 + 正弦定理求过渡边 + 余弦定理求目标 |
| 航海方位 | 船上观测目标 | 方位角转内角，逐三角形求解 |
| 三角形面积 | 两边夹角 / 三边 | $S=\frac12ab\sin C$；三边先求角 |

**重点：四大模型的共同点是「把现实图形翻译成三角形」**——识别模型后，解题变成「选定理、代公式」的机械流程。

<span class="marginnote"><strong>「先识别模型、再套流程」是应用题的最高效策略</strong>。测高看「两个仰角 + 共享高」，测距看「基线 + 正弦余弦接力」，航海看「方位角翻译」，面积看「$\frac12 ab\sin C$」。识别对模型，剩下的就是解三角形的旧知识——<strong>应用题考的是「建模识别」而非「新计算」</strong>。</span>

**辨析｜易错点：** 一是**模型套错**——把「测距」当成「测高」，流程就错了；二是**「一步只解一个三角形」**——连环三角形别想着一步到位，过渡边先算清；三是**面积公式漏 $\frac12$ 或 $\sin$**——$S=\frac12ab\sin C$。

## 8 术语速查表

| 术语 | 定义 / 公式 | 一句话释义 |
| --- | --- | --- |
| 仰角 / 俯角 | 视线与水平线的夹角 | 从水平线量 |
| 方位角 | 正北顺时针到目标 | 范围 $[0^\circ,360^\circ)$ |
| 方向角 | 从南北线偏东西 | 「北偏东 $30^\circ$」 |
| 建模四步 | 画图 → 造三角形 → 选定理 → 算验 | 标准流程 |
| 测高 | 两个直角三角形共享高 | 联立消距离 |
| 测距 | 基线 + 正弦 + 余弦 | 不可到达的测量 |
| 面积公式 | $S=\frac12ab\sin C$ | 两边夹角求面积 |
| 连环三角形 | 过渡边转目标边 | 一步解一个 |

**记忆线索**：应用题一句话「把现实翻译成三角形」；建模四步（画图 → 造三角形 → 选定理 → 算验）；四大模型各有一套流程，识别模型是关键。角度术语基准不同——仰俯角从水平量、方位角从正北量。

## 9 小结

- 标准角度：**仰角/俯角**从水平线量，**方位角**从正北顺时针量，**方向角**从南北线偏东西量——基准不同。
- 建模四步：**画图 → 造三角形 → 选定理 → 算与验**；一步只解一个三角形。
- 不可到达测距的套路：正弦定理求斜边，直角三角形求高。
- 航海方位题：把方位角翻译成三角形内角再求解；易错在基准、内外角与单位。
