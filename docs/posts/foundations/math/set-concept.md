## 为什么从集合开始

这个网站叫「从极限到大模型」。**极限**是微积分的入口，**大模型**是当代 AI 的前沿，而把这两端串起来的那条线，正是数学的通用语言——**集合**。函数是一类特殊集合，概率论里的一次随机试验来自一个样本空间<span class="marginnote">样本空间：一次随机试验所有可能结果构成的集合，是概率论的第一块基石，见第一级《概率》与第二级《概率论与数理统计》。</span>，向量空间是满足八条运算律的集合，甚至大模型里「token 的集合」「训练数据的集合」也要先被安放进集合这个框架，才能谈后续的一切运算。学集合，是在学所有数学的第一句话怎么读。

## 1 集合的含义

康托尔在 19 世纪给集合下了一个**描述性的定义**：**把一些确定的、互不相同的对象汇合在一起，就构成一个集合（set）。** 组成集合的每个对象称为这个集合的**元素（element）**。<span class="marginnote">康托尔（1845—1918）创立了朴素集合论。他「把无穷当成可以实际研究的事物」的思想在当时备受争议，如今却成了数学的基石。我们沿用他的描述性定义，严格的公理化表述在第二级《离散数学》与《抽象代数》中展开。</span>

这个定义里有三个词构成了集合元素的**三个特征**，判断「一堆东西是不是集合」就看它：

- **确定性**：给定任意一个对象，都能明确判断它属于或不属于这个集合。<span class="marginnote">「高个子的人」不是集合，因为高矮没有明确标准；「身高 ≥ 180 cm 的人」才是集合，因为判断标准被彻底说清了。确定性把集合与模糊概念划开。</span>
- **互异性**：集合中的元素是**不重复**的，重复写只算一次。<span class="marginnote">允许重复的容器在数学里另有其名，叫「多重集」（multiset）——线性代数里的矩阵行向量组、数据结构的哈希表都更像多重集。</span>
- **无序性**：集合中元素排列顺序无关紧要，$\{a, b\}$ 与 $\{b, a\}$ 是同一个集合。<span class="marginnote">「顺序」本身若被强调，就要用有序对 $(a,b)$ 之类的结构，而不是集合——这正是后面坐标、向量的起点，也与 Python 里 tuple 与 set 的差别一一对应。</span>

## 2 元素与集合的关系

元素与集合之间只有两种关系：**属于**与**不属于**。

若 $a$ 是集合 $A$ 的元素，记作 $a \in A$，读作「$a$ 属于 $A$」；否则记作 $a \notin A$，读作「$a$ 不属于 $A$」。<span class="marginnote">符号 $\in$ 由皮亚诺（Giuseppe Peano）在 1889 年首次使用，取自希腊字母 ε（epsilon，是 esti「是」的首字母）。它是整个数学里最基本的判断动词——一切数学命题最终都要归结为「某对象属于某集合」的形式。</span>

例如，设 $A$ 是「方程 $x^2 = 4$ 的解集」，则 $2 \in A$，而 $3 \notin A$。值得注意的是，**元素与集合之间是「属于」关系，集合与集合之间才是「包含」关系**，两者符号与语义都不相同——这是初学阶段最容易混淆的地方，我们会在下一节《集合间的基本关系》专门辨析。

## 3 集合的表示

### 列举法

把集合的元素**一一列举**出来，用花括号括起来，元素之间用逗号隔开，这种表示方法叫作**列举法（roster / enumeration）**。

$$A = \{1, 2, 3\}, \qquad B = \{x, y, z\}$$

列举法直观，适合元素个数有限、且不多的情况。元素很多或无穷时，列举法力不从心，于是需要描述法。

### 描述法

用集合元素的**共同特征**来描述集合，写作 $\{x \mid x \text{ 具有的性质}\}$，竖线前是元素的一般形式，竖线后是元素须满足的条件。<span class="marginnote">竖线读作「满足」或「使得」。描述法把「外延」换成了「内涵」：不把元素逐个列出，而是给出判定规则——这与编程里「用规则而非穷举定义数据」的思想一脉相承。</span>

$$A = \{x \in \mathbb{Z} \mid x^2 < 10\}$$

这表示「所有满足 $x^2<10$ 的整数」构成的集合。相比列举法 $\{-3,-2,-1,0,1,2,3\}$，描述法在面对无穷集时是不可替代的：

$$B = \{x \mid x > 0\}, \qquad C = \{(x, y) \mid x^2 + y^2 = 1\}$$

其中 $C$ 是平面上的单位圆——**用描述法，一条几何曲线被翻译成了一个集合**。这是「数形结合」的第一次相遇，后面解析几何的全部工作都建立在这种翻译之上。

### 常用数集及其记号

高中数学里一些常用的数集有固定的记号，是国际通用的：

| 记号 | 含义 | 英文词源 |
| --- | --- | --- |
| $\mathbb{N}$ | 自然数集（含 0） | Natural |
| $\mathbb{N}^*$ 或 $\mathbb{N}_{+}$ | 正整数集 | Natural，星号表示去掉 0 |
| $\mathbb{Z}$ | 整数集 | Zahlen（德语：数） |
| $\mathbb{Q}$ | 有理数集 | Quotient（商） |
| $\mathbb{R}$ | 实数集 | Real |
| $\mathbb{R}^*$ | 非零实数集 | 去掉 0 |

记号背后的层次值得停下来想：$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$，每一次扩充都解决了一次「不够用」——自然数不够减，才有了负整数；整数不够除，才有了分数；有理数不够开方，才有了无理数与实数。<span class="marginnote">数系扩充是「先有问题，后有数」的经典叙事：方程的根不在已有数系里，就扩充数系把它装进去。高中阶段最后一次扩充是复数，见第一级《复数》一节；而每次扩充都要检查原有运算律是否仍然成立。</span>这套「数不够用就造新数」的逻辑，正是下一节讲集合关系、以及后面学复数、学抽象代数时反复出现的主旋律。

### 有限集、无限集与空集

按元素的个数，集合可分为**有限集**与**无限集**；其中元素个数为 0 的集合，叫作**空集（empty set）**，记作 $\emptyset$ 或 $\{\}$。

$$\emptyset = \{\}, \qquad \emptyset \neq \{0\} \neq \{\emptyset\}$$

空集非常重要，也最容易出误会：$\emptyset$ 是「一个元素都没有的集合」，而 $\{0\}$ 是「含一个元素 0 的集合」，$\{\emptyset\}$ 是「把空集装进一个集合」——三者的元素个数分别是 0、1、1。<span class="marginnote">空集在数学里扮演着「什么都没有」的精确表达：方程无解时解集就是空集，两条平行线没有交点，「无解」「无交点」这类日常语言都必须用空集给出无歧义的翻译。它是数学里最便宜的占位符，也是后续区间、集合运算里频繁出场的角色。</span>

## 4 公式解析：解集这样写成集合

**「解方程」与「写解集」是集合概念的第一次实战。** 它的完整链条是：先求解，再把解翻译成集合语言。

$$
A = \{x \in \mathbb{R} \mid x^2 - 3x + 2 = 0\} = \{1, 2\}
$$

对这条式子做三步拆解：

- **第一步，读懂 $\{x \in \mathbb{R} \mid \cdots\}$**：竖线前的 $x \in \mathbb{R}$ 声明了元素的范围——$x$ 从实数里取；竖线后的等式是 $x$ 必须满足的条件。
- **第二步，解方程**：$x^2 - 3x + 2 = (x-1)(x-2) = 0$，得 $x = 1$ 或 $x = 2$。
- **第三步，翻译**：符合条件的 $x$ 有两个，于是外延就是 $\{1, 2\}$。

再举一个不等式解集，它会长成「区间」，而区间本质是无限集的简写：

$$
B = \{x \in \mathbb{R} \mid x^2 > 1\} = (-\infty, -1) \cup (1, +\infty)
$$

这里出现了并集符号 $\cup$ 与无穷区间记号。**一个「>」的不等式，解集会自然分裂成两支**，因为集合 $B$ 里的元素分属两个不相交的部分——「把解集拆成几个互不相交的块的并集」，这个操作将贯穿函数、数列与概率，是本章第三节《集合的基本运算》要系统化的内容。

## 5 用集合的语言描述世界

集合的价值不在于它自身有多深奥，而在于它是**通用语言**。把之前零散接触过的数学对象用集合重写一遍：

- **方程与不等式**：解集、解集的分支，如上节。
- **函数的定义域与值域**：函数 $y = f(x)$ 的定义域与值域都是数集，函数本质上是「定义域到值域的对应」——这是第一章末《函数的概念》的预告。<span class="marginnote">先立住「定义域是集合」这一点，后面学函数时你就拥有了天然的出发点；而函数概念里「非空数集的对应」正是把集合论翻译成函数语言的第一步。</span>
- **平面点集**：直线 $l = \{(x,y) \mid y = kx + b\}$，圆 $C = \{(x,y) \mid x^2 + y^2 = r^2\}$——几何对象全部落进集合框架，解析几何由此起步。
- **程序语言**：Python 的 `set`、数据库中的无重复记录、算法里的「候选集」「解空间」——计算机科学里的「集合」概念与数学同源。<span class="marginnote">哈希集合、位图集合只是实现方式的差别，其不变量（互异性、成员判断）完全继承自数学集合。到第三级《数据结构》我们还会用集合论语言讨论它们。</span>
- **概率与统计**：随机试验的样本空间、事件，都是集合；「事件发生」就是「样本落在某个集合里」——概率论在等它的第一语言。<span class="marginnote">教材把概率放在必修第二册第十章之后，但今天你只需记住一句话：概率论 = 集合论 + 度量。把样本空间这个集合想清楚，概率的一切运算（并、交、补）都已在这个章节预习过了。</span>

## 6 小结

- 集合的**描述性定义**：确定、互异的对象汇合为集合；元素具有**确定性、互异性、无序性**。
- 元素与集合之间是**属于**关系 $a \in A$ 或 $a \notin A$。
- 表示法两种：**列举法**与**描述法** $\{x \mid x \text{ 的性质}\}$；常用的数集记号有 $\mathbb{N},\mathbb{Z},\mathbb{Q},\mathbb{R}$。
- 集合按元素个数分**有限集、无限集**；**空集** $\emptyset$ 是「没有元素的集合」，它与 $\{0\}$、$\{\emptyset\}$ 完全不同。

在下一节，我们将回答两个问题：集合之间如何比较大小、如何判定「包含」——这就是**集合间的基本关系**。
