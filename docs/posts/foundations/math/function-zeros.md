## 为什么从「零点」开始

上一节末尾我们看到，函数与 x 轴的交点决定了增长与变化的「关键节点」。现在把这件事做成一套正式工具：**方程 $f(x) = 0$ 的根、函数 $y = f(x)$ 的零点、图象与 x 轴交点的横坐标，其实是同一件事的三种说法**——这正是庞加莱那句名言的绝佳注脚。

「求零点」是数学里出现频率最高的问题之一：一元二次方程用求根公式，三次、四次有卡尔达诺公式，五次以上没有通解；矩阵的特征值满足 $\det(A - \lambda I) = 0$；可导函数的极值点满足 $f'(x) = 0$；大模型训练要找到损失函数的极小点，而极小点首先要「驻点」——梯度为零向量。这一节给出的判据，能回答所有这类问题里最基本的一个：**这个零点存不存在？大致在哪个区间？**

## 1 零点是什么

**零点（zero）**：对于函数 $y = f(x)$，使 $f(x) = 0$ 的**实数** $x$ 叫作函数的零点。

注意「实数」这个限定：$f(x) = x^2 + 1$ 在实数范围内没有零点（$x^2 = -1$ 无实解），但若允许复数，它在 $x = \pm i$ 处取零。高中阶段我们只在实数范围里讨论零点，复数视角要等第一级《复数》一节。

于是三件事完全等价：

$$f(x) = 0 \ \text{的实数根} \iff y = f(x) \ \text{的零点} \iff \text{图象与 } x \text{ 轴交点的横坐标}$$

**辨析｜易错点：零点不是「点」，是一个「数」——横坐标。** 说「函数在 $x = 2$ 处有零点」是对的；说「函数有一个零点 $(2, 0)$」是把零点和交点混为一谈了。图象与 x 轴的交点是一个坐标点 $(c, 0)$，零点则是那个横坐标 $c$。「用图象看零点」，看的正是交点处那条竖直位置，而不是交点本身。<span class="marginnote">英文里根叫 root、零点叫 zero，指的都是「使函数取 0 的自变量值」；中文「零点」二字听起来像个点，这是最容易被它误导的地方。</span>

认识了零点的定义，自然要问：零点到底怎么求？原则上有四条路——**因式分解**（解出精确根）、**求根公式**（二次、三次、四次）、**图象观察**（画 $y = f(x)$ 看交点，得到近似位置）、**数值逼近**（二分法、牛顿法）。前两条给出精确值，但只对少数「幸运」的函数适用；后两条对几乎所有连续函数都能用。本节先解决前提问题——零点存不存在、大致在哪个区间；下一节再解决「怎么逼近到想要的精度」。

## 2 零点存在性定理

只靠「有没有交点」的直观，我们还需要一个能落笔的判据：

**零点存在性定理**：如果函数 $y = f(x)$ 在区间 $[a, b]$ 上的图象是一条**连续不断**的曲线，并且 $f(a) \cdot f(b) < 0$，那么函数在区间 $(a, b)$ 内**至少有一个零点**，即存在 $c \in (a, b)$，使 $f(c) = 0$。

![零点存在性定理](/images/math/function-zeros-1.svg)

把定理的三个条件拆开讲：

**连续**：曲线不能断。从 $f(a)$ 走到 $f(b)$，不许「跳过去」。<span class="marginnote">「连续」的严格定义要用极限，属于第二级《微积分》与《实分析》；高中阶段用「图象一笔画完」来理解它就够了。值得注意的是：这个定理之所以伟大，正因为它不要求函数可导——甚至不要求有解析式，只要会取值就行。</span>
**端点异号**：$f(a)$ 与 $f(b)$ 一正一负，即乘积小于 0。
**至少一个**：定理只保证「存在」，不保证「唯一」，也不告诉你具体位置和个数。

直觉无非一句话：一条连续曲线，一头在 x 轴下方、一头在 x 轴上方，就必然在中间某个地方「穿过」x 轴——穿过去的地方，横坐标就是零点。你堵得住一次穿越，堵不住连续曲线必须完成的这次跨越。

**辨析｜易错点：定理是充分的，不是必要的。** 端点同号也完全可能有零点。例如 $f(x) = x^2$ 在 $[-1, 1]$ 上，$f(-1) = f(1) = 1 > 0$，但 $x = 0$ 是零点——曲线与 x 轴**相切**，穿过去却没有变号。反过来，若图象不连续，端点异号也可能没有零点：比如在 $[0, 2]$ 上定义「从 $(0,1)$ 一路向左到 $(1, -1)$ 再跳到 $(2, 1)$」的函数，它在 $x=1$ 处断开，$f(0) \cdot f(2) < 0$，却永远取不到 0。**「连续 + 异号」是充分的组合；少一个，定理就失效。**

## 3 零点的个数：单调性来把关

存在性解决了「有没有」，紧接着的问题是「有几个」。标准手法：**如果函数在区间上单调（严格递增或严格递减），且端点异号，那么零点唯一。**

为什么？一个严格递增的函数，图象只能「由下往上」穿过 x 轴一次：穿过一次之后，函数值继续保持增大，不可能再回到 0。严格递减同理。<span class="marginnote">判断单调性的两种工具在《函数的基本性质》里学过：定义法（任取 $x_1<x_2$ 比大小），以及「增函数之和仍为增函数」。本节的例子用的正是后者。</span>

教材的经典例子，函数 $f(x) = \ln x + 2x - 6$（$x > 0$）：

$f(2) = \ln 2 - 2 \approx -1.31 < 0$，$f(3) = \ln 3 \approx 1.10 > 0$，端点异号；
$\ln x$ 与 $2x$ 都在 $(0, +\infty)$ 上递增，故 $f$ 也递增；
由存在性定理，$f$ 在 $(2, 3)$ 内至少有一个零点；又因 $f$ 单调递增，这个零点唯一。

<span class="marginnote">为什么偏偏选 $\ln x + 2x - 6$ 当例子？因为它既不能因式分解，也没有求根公式——这恰好逼出「用定理判存在、用单调判唯一、用二分法逼近」这条处理不可解方程的标准路线。遇到这类「求不出来」的方程，这套路线就是唯一出路。</span>

## 4 公式解析：ln x + 2x − 6 的零点判定

把上面的推理写成完整链条：

$$f(x) = \ln x + 2x - 6, \qquad x \in (0, +\infty)$$

- **第一步，找变号区间**：$f(2) = \ln 2 - 2 \approx -1.31 < 0$，$f(3) = \ln 3 \approx 1.10 > 0$。两端异号，由零点存在性定理，$(2, 3)$ 内至少有一个零点。
- **第二步，证唯一**：任取 $x_1 < x_2$，$\ln x_1 < \ln x_2$ 且 $2x_1 < 2x_2$，故 $f(x_1) < f(x_2)$，$f$ 严格递增。一个严格递增的函数不可能在同一个区间内两次取到 0。
- **第三步，缩小包围圈**：$f(2.5) = \ln 2.5 - 1 \approx -0.08 < 0$，$f(2.75) = \ln 2.75 - 0.5 \approx 0.51 > 0$，于是零点被进一步夹在 $(2.5, 2.75)$ 内。每多算一步，区间就缩一半。

注意第三步的操作：我们不是「越来越接近零点」，而是**「把零点所在的区间越夹越窄」**。前两步保证了「这个区间里确实有零点」，第三步保证「区间在缩小」。这个「先存在、后唯一、再夹逼」的次序，正是下一节二分法能成立的前提——二分法的每一步都在重复第三步。

## 5 三次函数的三个零点：一个完整案例

把存在性定理与单调性合起来，可以做一件很漂亮的事：**数出一个多项式的零点个数**。看三次函数

$$f(x) = x^3 - 3x + 1$$

它在 $[-2, 2]$ 上连续。先算几个关键值：

$$f(-2) = -1 < 0, \quad f(-1) = 3 > 0, \quad f(0) = 1 > 0, \quad f(1) = -1 < 0, \quad f(2) = 3 > 0$$

按端点符号分段看：

- 区间 $(-2, -1)$：$f(-2) < 0$、$f(-1) > 0$，异号 ⟹ 至少一个零点；
- 区间 $(-1, 0)$：$f(-1) > 0$、$f(0) > 0$，同号，本区间内不能由定理直接下结论；
- 区间 $(0, 1)$：$f(0) > 0$、$f(1) < 0$，异号 ⟹ 至少一个零点；
- 区间 $(1, 2)$：$f(1) < 0$、$f(2) > 0$，异号 ⟹ 至少一个零点。

于是至少三个零点。但三次方程**至多**有三个实根（一元 $n$ 次方程至多有 $n$ 个实根，这是代数学基本结论），所以恰好三个——分别落在 $(-2,-1)$、$(0,1)$、$(1,2)$ 内。<span class="marginnote">「至多三个」来自因式分解：若三次多项式有三个不同的根 $r_1,r_2,r_3$，它就能被 $(x-r_1)(x-r_2)(x-r_3)$ 整除，次数已经用完，不可能再有第四个。这个「根个数 ≤ 次数」的结论在多项式里处处要用。</span>

这个例子展示了判定零点的完整套路：**先分组找变号区间（存在性），再与「至多几个」的上界对照（个数）。** 存在性给下界，代数定理给上界，两者一夹，个数就精确了。

## 6 零点的意义远不止「解方程」

零点判断是整座数学大厦的通用基础设施：

**多项式求根**：二次、三次、四次都有求根公式；五次以上被阿贝尔定理宣告「没有一般通解」——从此数值逼近（二分法、牛顿法）成为唯一现实出路。
**线性代数**：特征值 $\lambda$ 满足 $\det(A - \lambda I) = 0$，本质是在找一个多项式的零点；「找特征值」就是「找零点」在矩阵世界里的名字。<span class="marginnote">到第二级《线性代数》你会发现，矩阵能对角化、方程组的解的结构，全都系在「特征多项式有没有零点、有几个、重不重」这条线上。</span>
- **微积分**：可导函数的极值点必满足 $f'(x) = 0$，导数章节里「找极值」的第一步就是「找导数的零点」——到《导数与函数单调性》我们再展开。
- **机器学习**：训练大模型就是找损失函数的一个「近似极小点」，而极小点首先要满足「梯度为零向量」——这是一组多元方程的零点。你在这里学的判据，是那一整套迭代法最早的直觉原型。
- **信号与系统**：在工程数学里，传递函数的零点与极点决定系统的稳定性与响应特征；「找零点」从代数延伸到了微分方程的解空间，但「先判存在、再判个数」的思路一字未变。

## 7 小结

- **零点是「数」不是「点」**：它是使 $f(x)=0$ 的实数 $x$，即图象与 x 轴交点的横坐标。
- 方程根、零点、交点横坐标，是同一件事的三种说法（庞加莱的「同名艺术」）。
- **零点存在性定理**：连续 + 端点异号 ⟹ 至少一个零点；它**充分但不必要**。
- **唯一性靠单调**：单调递增（或递减）+ 端点异号 ⟹ 恰有一个零点。
- 对不可解的方程，策略是「先判存在、再判唯一、然后逼近」。

「每算一步，区间缩一半」这句直觉，还差一个正式的落点。在下一节，我们把它变成一条严格的算法，用它求出零点的近似值——这就是**用二分法求方程的近似解**。
