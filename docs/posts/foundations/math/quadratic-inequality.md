## 为什么从「三个二次」开始

前两节我们分别拿到两件武器：不等式的六条性质与基本不等式（解决「怎么比大小」），以及第一章的集合语言（解决「解集怎么表达」）。但至今我们只解过一次不等式——$x^2>1$ 的解集 $(-\infty,-1)\cup(1,+\infty)$，还是从图象「看」出来的。这一节要把「看」变成「算法」：给出任意一元二次不等式 $ax^2+bx+c>0$，怎样确定它的解集？

答案藏在「三个二次」的统一里：**二次函数、一元二次方程、一元二次不等式，是同一个对象的三种问法。**

- 问**图象**：抛物线 $y=ax^2+bx+c$ 长什么样？
- 问**方程**：它何时等于 0？这就是 $ax^2+bx+c=0$ 的根（等于抛物线与 x 轴交点的横坐标）。
- 问**不等式**：它何时大于 0？这就是 $ax^2+bx+c>0$ 的解集（等于抛物线在 x 轴上方时 $x$ 的全体）。

把三者装进一张图，一次解决。这与机器学习的联系也很直接：**解二次不等式就是「判断一个量何时越过阈值」**——误差大于容差、损失高于基线、神经元的加权和超过激活阈值……全是「$ax^2+bx+c>0$」这类问题的高维推广。<span class="marginnote">更一般地，「$f(x)>0$ 的解集」是函数观点下的统一问题：学完函数你会看到，几乎所有不等式都是「函数图象在哪一段位于参考线上方」的翻译。这一节是这条思路第一次完整成型。</span>

## 1 三个「二次」一家

设二次函数 $f(x)=ax^2+bx+c$（$a\neq0$），判别式 $\Delta=b^2-4ac$。方程、函数、不等式三者的关系可以浓缩成一张表：

| 对象 | 表达式 | 几何意义 |
| --- | --- | --- |
| 二次函数 | $y=ax^2+bx+c$ | 抛物线（开口方向由 $a$ 决定） |
| 二次方程 | $ax^2+bx+c=0$ | 抛物线与 x 轴交点的横坐标 |
| 二次不等式 | $ax^2+bx+c>0$ | 抛物线位于 x 轴上方时对应的 $x$ 范围 |

**核心结论：一元二次方程 $ax^2+bx+c=0$ 的根，就是二次函数 $y=ax^2+bx+c$ 的零点（zero），也就是抛物线与 x 轴交点的横坐标。** 一个对象，三个名字。

抛物线的整体形状也由「开口方向 + 位置」两部分决定。开口方向看 $a$ 的符号；位置看**顶点**：

$$\left(-\frac{b}{2a},\ \frac{4ac-b^2}{4a}\right)$$

其中 $-\dfrac{b}{2a}$ 是抛物线的**对称轴**。对称轴与判别式是描述抛物线的两把尺子：前者告诉它「左右居中在哪」，后者告诉它「与 x 轴交几次」。二次不等式解集的形状，完全由这两个量决定。

方程有几个根，完全由判别式决定：

- $\Delta>0$：两个不同的实根 $x_1,x_2$，抛物线穿过 x 轴两次；
- $\Delta=0$：两个相等的实根 $x_1=x_2$（重根），抛物线顶点恰好落在 x 轴上；
- $\Delta<0$：没有实根，抛物线不穿过 x 轴（开口向上则恒在 x 轴上方，开口向下则恒在下方）。

根与系数之间还有**韦达定理（Vieta's formulas）**：若 $x_1,x_2$ 是方程 $ax^2+bx+c=0$ 的两根，则

$$x_1+x_2=-\frac{b}{a},\qquad x_1x_2=\frac{c}{a}$$

它是「不求出根也能知道两根之和与积」的工具，也是后面二次函数对称轴、解析几何里反复使用的钥匙。<span class="marginnote">韦达定理来自 16 世纪法国数学家弗朗索瓦 · 韦达（François Viète），他第一个系统用字母表示已知数与未知数，把「具体数字的算术」提升为「一般符号的代数」。韦达定理不必死记：把 $a(x-x_1)(x-x_2)$ 展开并与 $ax^2+bx+c$ 对照，两根和、积是「必然」的。</span>

## 2 公式解析：解一元二次不等式 ax²+bx+c>0（a>0）

以具体例子走一遍：**解不等式 $x^2-3x+2>0$**。

**第一步，求根**：解方程 $x^2-3x+2=0$。因式分解得 $(x-1)(x-2)=0$，两根 $x_1=1,\ x_2=2$。

**第二步，画图**：抛物线 $y=x^2-3x+2$ 开口向上（$a=1>0$），穿过 x 轴于 $x=1,2$。于是图象被两根分成三段：两根之外在 x 轴上方（$y>0$），两根之间在 x 轴下方（$y<0$）。

**第三步，写解集**：要 $y>0$，取两根之外，用集合语言写作：
$$x^2-3x+2>0 \iff x<1\ \text{或}\ x>2 \iff x\in(-\infty,1)\cup(2,+\infty)$$

![抛物线 y=0.5(x-1)(x-3)：两根之外 y>0，两根之间 y<0](/images/math/quadratic-inequality-1.svg)

把三步上升为一般规则，就是解二次不等式的「总纲」：

**解 $ax^2+bx+c>0$（$a>0$）：先求根 $x_1\le x_2$，则解集是「两根之外」；解 $ax^2+bx+c<0$，则解集是「两根之间」。** 判别式不同，细节如下：

- $\Delta>0$：$>0$ 的解集是 $(-\infty,x_1)\cup(x_2,+\infty)$；$<0$ 的解集是 $(x_1,x_2)$。
- $\Delta=0$：$>0$ 的解集是 $\{x\mid x\neq x_1\}$（全体实数挖掉重根）；$<0$ 的解集是空集。
- $\Delta<0$：$a>0$ 时函数恒正，$>0$ 的解集是 $\mathbb{R}$，$<0$ 的解集是 $\emptyset$。

口诀「**大于取两边，小于取中间**」只对 $a>0$ 有效。<span class="marginnote">「取两边 / 取中间」指的是以两根为界，取两根外侧还是两根之间。但这条口诀的前提是「开口向上」；开口向下时图象上下翻转，结论正好互换——所以做题第一步永远是「把二次项系数化为正」。</span>

## 3 辨析｜易错点

**易错点一：开口向下忘了变号。** 解 $-x^2+2x+3>0$，不要直接套口诀。先两边同乘 $-1$（不等号反转）得 $x^2-2x-3<0$，再按「小于取中间」处理；或等价地把抛物线画成开口向下再判断。口诀「大于取两边」在开口向下时会给出恰好相反的区间。

**易错点二：端点等号。** $x^2-3x+2\ge0$ 的解集是 $(-\infty,1]\cup[2,+\infty)$，端点取等；而 $>0$ 的解集端点不取。**区间开闭由题目里的不等号是否带等号决定。**

**易错点三：判别式小于 0 不等于「无解」。** $\Delta<0$ 且 $a>0$ 时函数恒正，$ax^2+bx+c>0$ 的解集是全体实数，不是空集。<span class="marginnote">「恒成立」问题在考试里高频出现：$ax^2+bx+c>0$ 对一切 $x\in\mathbb{R}$ 恒成立 ⟺ $a>0$ 且 $\Delta<0$。注意是两个条件——「开口向上」且「与 x 轴无交点」，缺一不可；若二次项系数可能为 0，还要单独讨论 $a=0$ 的情形。</span>

**易错点四：分式不等式直接去分母。** 解 $\dfrac{x+1}{x-2}>0$，不能直接两边同乘 $x-2$，因为你不知道它的正负。正确做法：把右边化为 0 并通分，得 $\dfrac{(x+1)(x-2)}{(x-2)^2}>0$，分母恒正，等价于 $(x+1)(x-2)>0$，解集为 $(-\infty,-1)\cup(2,+\infty)$。**本质仍是「化归为整式不等式」，分母是否恒正是关键。**

## 4 应用：三个「二次」的实战

**例 1（恒成立求参数）**：若 $x^2-mx+4>0$ 对一切实数 $x$ 恒成立，求 $m$ 的范围。

$a=1>0$，要恒正只需 $\Delta<0$，即 $m^2-16<0$，得 $-4<m<4$。判别式在这里成了「参数不等式」的主角。

**例 2（用韦达定理）**：已知 $x^2-5x+6=0$ 的两根为 $x_1,x_2$，求 $x_1^2+x_2^2$。

不用求根：$x_1+x_2=5,\ x_1x_2=6$，则
$$x_1^2+x_2^2=(x_1+x_2)^2-2x_1x_2=25-12=13$$

**例 3（三个二次联手）**：若不等式 $ax^2+bx+c>0$ 的解集是 $(-1,2)$，求 $a$ 的符号。

解集是「两根之间」，说明开口向下且两根为 $-1,2$，故 $a<0$。由韦达定理 $x_1+x_2=1=-\dfrac{b}{a}$，$x_1x_2=-2=\dfrac{c}{a}$，得 $b=-a,\ c=-2a$。**关键在「解集区间」直接告诉了我们开口方向与两根**——这就是三个「二次」互相喂养信息的样子。

**例 4（含参不等式要讨论）**：解关于 $x$ 的不等式 $x^2-(a+1)x+a>0$。

因式分解得 $(x-1)(x-a)>0$，两根为 $1$ 与 $a$。但「谁在左谁在右」取决于 $a$ 与 $1$ 的大小，必须分类讨论：

- $a>1$：两根 $1<a$，开口向上取两边，解集 $(-\infty,1)\cup(a,+\infty)$；
- $a=1$：不等式化为 $(x-1)^2>0$，解集 $\{x\mid x\neq1\}$；
- $a<1$：两根 $a<1$，解集 $(-\infty,a)\cup(1,+\infty)$。

**含参二次不等式在「求根」之后多一步「比较两根大小」**——参数让两根的次序不确定，讨论的目标就是把这个次序定下来。这是从初中到高中解不等式的一个标志性飞跃。

## 5 小结

- **三个「二次」一家**：方程的根 = 函数的零点 = 抛物线与 x 轴交点的横坐标。
- **判别式** $\Delta$ 决定根的个数；**韦达定理**给出两根之和、积。
- **解二次不等式三步**：求根 → 画图 → 写解集；口诀「大于取两边，小于取中间」仅对 $a>0$ 有效。
- **恒成立** ⟺ $a>0$ 且 $\Delta<0$（若 $a$ 可能为 0 须单列讨论）；分式不等式先化整式、保分母符号。

在下一节，我们离开「二次」，进入整个高中数学的主角：**函数**。我们将用集合与对应的语言重新定义初中就认识的「函数」，学会它最正式的表达——这就是《函数的概念及其表示》。
