## 为什么从圆与圆的位置关系开始

两圆的「相处方式」比直线与圆丰富得多：**外离、外切、相交、内切、内含**五种。判断标准只需比较**圆心距 $d$** 与**两半径 $r_1$、$r_2$** 的关系——五个区间对应五种关系。两圆相交产生公共弦与公共弦方程，这是「两方程相减」的经典应用。从「从极限到大模型」的主线看，圆与圆的关系是「图形间关系的分类学」的标本，也是后续圆锥曲线相交问题与「圆系」思想的基础。

## 1 五种位置关系及其判据

设两圆半径分别为 $r_1$、$r_2$（不妨 $r_1 \ge r_2$），圆心距为 $d$：

| 位置关系 | 圆心距条件 | 公共点 | 直观 |
| --- | --- | --- | --- |
| 外离 | $d > r_1 + r_2$ | 0 | 互不接触 |
| 外切 | $d = r_1 + r_2$ | 1 | 外相碰 |
| 相交 | $r_1 - r_2 < d < r_1 + r_2$ | 2 | 交于两点 |
| 内切 | $d = r_1 - r_2$ | 1 | 内相碰 |
| 内含 | $d < r_1 - r_2$ | 0 | 一个在另一个内 |

<span class="marginnote">记忆要点：把两圆「拉开」或「靠拢」，以「外切」（$d = r_1+r_2$）与「内切」（$d = |r_1 - r_2|$）为两个临界点，夹在中间是相交，两边各是外离与内含。五个区间，五种关系，一一对应。</span>

**辨析｜易错点：** 内切的条件是 $d = r_1 - r_2$（大半径减小半径），不是 $r_2 - r_1$——用绝对值写更安全：$d = |r_1 - r_2|$。内含与「一个圆包含另一个」重合：$d < |r_1 - r_2|$。

## 2 公式解析：两圆相交的公共弦

两圆相交于两点，这两点所在的直线叫**公共弦所在的直线**。设两圆方程为

$$
C_1: x^2 + y^2 + D_1x + E_1y + F_1 = 0, \qquad
C_2: x^2 + y^2 + D_2x + E_2y + F_2 = 0
$$

两式**相减**，得到：

$$
(D_1 - D_2)x + (E_1 - E_2)y + (F_1 - F_2) = 0
$$

这正是公共弦所在直线的方程。对这条式子做三步拆解：

- **第一步，为什么相减有效**：交点同时满足两个圆方程，所以也满足「两方程之差」。交点都在直线上，而两个交点确定一条直线，这条直线就是公共弦所在直线。
- **第二步，消去二次项**：两方程相减时 $x^2 + y^2$ 恰好抵消，剩下的是一次方程——公共弦是直线，这解释了为什么「减出来是直线」。
- **第三步，推广**：两圆**相切**时，「公共弦」退化成一个切点，相减得到的直线正是**两圆的公切线在切点处**（切线方程）；两圆外离时，相减得到的直线叫**根轴**，它不在圆上，但具有「到两圆幂相等」的性质。

<span class="marginnote">「两方程相减」是解析几何处理两个图形关系的通用手法：交点同时满足两者 ⇒ 交点满足「两者之差」。这个思想在直线与圆锥曲线相交、求过交点的曲线族里反复出现。根轴（等幂线）更是通向「圆幂」与解析几何深刻理论的概念。</span>

## 3 圆系：一族圆的表示

与直线族类似，两个圆可以生成一族圆：

$$
x^2 + y^2 + D_1x + E_1y + F_1 + \lambda(x^2 + y^2 + D_2x + E_2y + F_2) = 0
$$

当 $\lambda = -1$ 时，上式退化为公共弦直线（两圆之差）；当 $\lambda \neq -1$ 时，它表示**经过两圆交点的所有圆**——过两交点 $A$、$B$ 的圆，除 $C_2$ 本身外，都可以写成这种形式。<span class="marginnote">「圆系」让我们用一个参数 $\lambda$ 描述「过两定点的所有圆」这一整族对象。这种「用参数化一族」的视角，与直线的点斜式一族、后面的圆锥曲线系一脉相承，是「无穷多个对象用一个参数管理」的典范。</span>

**重点：** 求「过两圆交点且满足某附加条件（如圆心在给定直线上）的圆」，可用圆系方程，代入附加条件定出 $\lambda$——比「解交点再求圆」更省计算。

## 4 两圆的公切线

两圆的公切线分**外公切线**与**内公切线**：

| 位置关系 | 外公切线数 | 内公切线数 | 总公切线 |
| --- | --- | --- | --- |
| 外离 | 2 | 2 | 4 |
| 外切 | 2 | 1 | 3 |
| 相交 | 2 | 0 | 2 |
| 内切 | 1 | 0 | 1 |
| 内含 | 0 | 0 | 0 |

<span class="marginnote">公切线数是个漂亮的不变量：外离 4 条、外切 3 条、相交 2 条、内切 1 条、内含 0 条，恰好与「分离程度」单调对应。求公切线方程的方法：设切线的点斜式（或一般式），令两圆心到它的距离分别等于两半径，解方程。</span>

## 5 两圆位置关系的应用

两圆位置关系不只是分类，还有大量实际应用：

**圆环与偏心**：机械里两圆位置决定配合（间隙、过盈），如轴承内圈外圈；
**交点定位**：用两圆交点确定位置（如「两个基站测距」定位，GPS 的二维版本）；
**最小覆盖圆**：求覆盖一组点的最小圆，与「两圆相切/外接」临界相关；
**圆与三角形外接圆**：三角形三顶点确定外接圆，外接圆与其它圆的关系是几何综合题常客。

<span class="marginnote">「两圆交点定位」是三角测量、卫星定位的几何原型：从两个已知中心测出距离，交点之一就是你的位置。到第四篇《解三角形应用》，这个「测距定位」的工程思想会与正余弦定理结合得更深。</span>

两圆相交还有一个「公共弦长」的计算问题，它是「两圆交点」与「弦长公式」的结合：求两圆公共弦的长，通常先「两式相减」得到公共弦所在直线方程，再用「圆心到该直线的距离 + 弦长公式 $2\sqrt{r^2 - d^2}$」求出弦长。整条链路把本节与《直线与圆的位置关系》的知识串成一道综合题。

| 两圆相交的问题 | 解法 | 用到的工具 |
| --- | --- | --- |
| 求交点坐标 | 两式相减得直线，代入圆方程 | 方程组 |
| 求公共弦长 | 相减得直线，点线距 + 弦长公式 | 点到直线距离 |
| 求公共弦所在直线 | 两圆方程相减 | 圆系 |
| 求过交点的圆 | 圆系 $C_1 + \lambda C_2 = 0$ | 圆系方程 |

这张表的共同点是：**「两圆相减」是几乎所有两圆问题入口**。因为公共点同时满足两个方程，所以它们满足「两方程之差」——这个「作差提取公共信息」的手法，在处理两个对象交集的任何问题里都通用。

<span class="marginnote">「作差提取公共信息」在数学里是一条主干道：线性方程组用「消元」（方程相减）求交集，几何用「公共弦」求两圆关系，编程里「集合求交」也是先提取公共元素。识别「公共部分 = 满足所有条件的部分」，是处理多条件问题的最强直觉。</span>

两圆位置关系的判断还可以用「向量与距离」统一理解：圆心距 $d = |\vec{OC_1} - \vec{OC_2}|$ 是一个向量的模长，而「$d$ 与 $r_1 \pm r_2$ 的比较」本质上是「两个圆心的距离与半径的关系」。这提示：**把圆看成「中心 + 半径」的数据结构，两圆关系就是「中心距与半径的组合」**——这种「以中心为代表」的观点，与后续「圆系」「圆族」问题一脉相承。

## 6 小结

- 两圆五种关系：**外离、外切、相交、内切、内含**，由 $d$ 与 $r_1 \pm r_2$ 五个区间决定。
- **公共弦方程**：两圆方程相减即得（消去二次项）；相切时退化为切线方程，外离时为根轴。
- **圆系**：$C_1 + \lambda C_2 = 0$（$\lambda \neq -1$）表示过两圆交点的所有圆。
- 公切线数：外离 4、外切 3、相交 2、内切 1、内含 0，与分离程度单调对应。
- 两圆关系应用：配合、定位、最小覆盖圆，通向测距定位与解三角形。
