## 为什么从三角比开始

前六篇研究的是「形状与位置」，而从这一篇开始，我们研究「**角与边的可计算关系**」。三角比（三角函数）回答一个朴素的问题：**给一个角，怎么用数字描述它？** 直角三角形里，这个角一确定，对边与斜边的比值、邻边与斜边的比值就完全确定——这是相似三角形（第 2 篇）的直接推论，也是「把角度翻译成数」的第一步。<span class="marginnote">三角比的思想在中国古代叫「勾股弦的关系」，《周髀算经》里已有「勾三股四弦五」与「径一周三」的测量记录；古希腊喜帕恰斯则编制了第一张弦表——测量学与天文学是三角学诞生的双胞胎摇篮。</span>

从「从极限到大模型」的主线看，三角比是整个三角函数（第四篇）的种子：把「直角三角形的角」放宽到「任意角」，就得到正弦、余弦函数；把正弦定理、余弦定理学好，三角函数才能从「一个锐角的比值」长成「定义域为全体实数的函数」——后者正是信号处理、傅里叶分析、乃至语音识别与图像压缩的数学底座。

## 1 锐角三角比：从直角三角形出发

在直角三角形 $ABC$ 中（$C$ 为直角），对锐角 $A$，定义三个基本三角比：

$$\sin A = \frac{\text{对边}}{\text{斜边}}, \qquad \cos A = \frac{\text{邻边}}{\text{斜边}}, \qquad \tan A = \frac{\text{对边}}{\text{邻边}} = \frac{\sin A}{\cos A}$$

**重点：** 这三个比值**只由角 $A$ 决定，与三角形大小无关**——因为与 $A$ 有相同锐角的直角三角形都相似（AA 相似），对应边成比例，比值不变。这正是「三角比」成立的根基：**角决定比值，比值反过来刻画角**。<span class="marginnote">「角定比值」是测量学的基石：古人测塔高，只需量出观测角与到塔脚的距离，再用三角比一算——不必爬上塔顶。今日的测距仪、卫星定位、无人机姿态控制，内核仍是「已知角求边、已知边求角」。</span>

常用特殊角的三角比需要「一眼看穿」：

| 角 | $\sin$ | $\cos$ | $\tan$ |
| --- | --- | --- | --- |
| $30°$ | $\frac{1}{2}$ | $\frac{\sqrt{3}}{2}$ | $\frac{\sqrt{3}}{3}$ |
| $45°$ | $\frac{\sqrt{2}}{2}$ | $\frac{\sqrt{2}}{2}$ | $1$ |
| $60°$ | $\frac{\sqrt{3}}{2}$ | $\frac{1}{2}$ | $\sqrt{3}$ |

记忆窍门：分子依次是 $\sqrt{1},\sqrt{2},\sqrt{3}$ 除以 $2$——正弦从 $\frac{1}{2}$ 升到 $\frac{\sqrt{3}}{2}$，余弦恰好反过来。**互补角关系**：$\sin(90° - A) = \cos A$，这也是「余角」之「余」的来历。

## 2 公式解析：正弦定理

把三角比从直角三角形推广到任意三角形，第一件武器是**正弦定理**：

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

其中 $a,b,c$ 是三角形三边，$A,B,C$ 是它们所对的角，$R$ 是三角形**外接圆半径**。

对这条公式做三步拆解：

- **第一步，从直角三角形验证**：若 $\triangle ABC$ 是直角三角形（$C = 90°$），则 $c$ 是斜边且外接圆直径就是斜边 $c = 2R$，$\frac{c}{\sin C} = \frac{c}{1} = c = 2R$，成立。
- **第二步，看它怎么来的**：过点 $A$ 作外接圆直径 $AD$，则 $\angle ABD = 90°$（直径所对圆周角为直角），且 $\angle ADB = \angle ACB = C$（同弧所对圆周角相等）。在直角三角形 $ABD$ 中 $\sin C = \frac{AB}{AD} = \frac{c}{2R}$，即 $\frac{c}{\sin C} = 2R$。三边同理。
- **第三步，掌握两个用法**：**① 已知两角一边，求边**（用「边比 = 正弦比」）；**② 已知两边与其中一边对角，求角或边**（但要小心多解，见 §4）。此外它给出一个几何惊喜——**外接圆半径可以用「$2R = \frac{a}{\sin A}$」算出来**，这在解三角形与圆结合的题目里非常有用。

**数值算例：** 在 $\triangle ABC$ 中，$A = 60°$，$B = 45°$，$a = 6$，求 $b$。由正弦定理 $\dfrac{b}{\sin B} = \dfrac{a}{\sin A}$，得 $b = a \cdot \dfrac{\sin 45°}{\sin 60°} = 6 \times \dfrac{\sqrt{2}}{\sqrt{3}} = 2\sqrt{6} \approx 4.90$。**「两角一边」最省事：比例一套，答案即出**，不用再作辅助线。

**补充：** 正弦定理在测量里的经典应用是「**测距**」：隔河测对岸两点距离，只要在河这边测得两个角与一条基线，就能用正弦定理算出河对岸的距离——这就是古代土地测量与天文测距的基本方法。

## 3 公式解析：余弦定理

第二件武器是**余弦定理**，它回答「已知两边一夹角，怎么求第三边」：

$$a^2 = b^2 + c^2 - 2bc\cos A$$

对这条公式做三步拆解：

- **第一步，验证特例**：当 $A = 90°$ 时 $\cos A = 0$，式子退化为 $a^2 = b^2 + c^2$——**勾股定理是余弦定理的特例**，余弦定理是勾股定理在「夹角不一定是直角」时的推广。
- **第二步，看它怎么来的**：作 $BC$ 边上的高，把 $a$ 边拆成两段，用勾股定理分别列出方程，再消去高即可。也可以看成「用向量数量积」：$\vec a = \vec b - \vec c$，两边取模平方 $a^2 = |\vec b - \vec c|^2 = b^2 + c^2 - 2\vec b \cdot \vec c = b^2 + c^2 - 2bc\cos A$——**余弦定理就是「差的模平方」的展开**。<span class="marginnote">向量数量积 $\vec b \cdot \vec c = bc\cos A$ 是「把长度与夹角打包成一个数」的第一次出场——它把余弦定理的几何推导翻译成了纯代数推导。这一步在第三篇《空间向量与立体几何》里会被反复使用，届时你会觉得这里最亲切。</span>
- **第三步，掌握两个用法**：**① 已知两边一夹角，求第三边**；**② 已知三边，求角**（把公式改写成 $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$，解出角的余弦再查角）。由它可以推导出「已知三边判断三角形形状」的判别法（回顾《勾股定理及其应用》）。

**数值算例：** 在 $\triangle ABC$ 中，$b = 5$，$c = 7$，$A = 60°$，求 $a$。余弦定理 $a^2 = 5^2 + 7^2 - 2 \times 5 \times 7 \times \cos 60° = 25 + 49 - 35 = 39$，故 $a = \sqrt{39} \approx 6.24$。若改用「两边一对角」的正弦路线，还要面临多解讨论——**能上余弦定理就上余弦定理**，干净利落。

**辨析｜易错点：** 用余弦定理求角时，结果唯一（三角形内角在 $0°$ 到 $180°$ 之间，余弦在 $(0°,180°)$ 内单调递减），**没有多解问题**——这一点与正弦定理求角截然不同。

## 4 解三角形的四种情形与「多解陷阱」

**解三角形（solving a triangle）**：已知三角形的部分元素（边、角），求其余元素。按「已知什么」分四类，处理方式各不相同：

| 已知条件 | 方法 | 解的个数 |
| --- | --- | --- |
| 两角一边 | 正弦定理 | 唯一 |
| 两边及夹角 | 余弦定理 | 唯一 |
| 三边 | 余弦定理求角 | 唯一 |
| 两边及其中一边对角（SSA） | 正弦定理 + 讨论 | 0、1 或 2 个 |

**重点：** SSA 是唯一的「多解雷区」。已知 $\angle A$、边 $a$、边 $b$，正弦定理给出 $\sin B = \dfrac{b\sin A}{a}$；若 $\sin B > 1$，无解（$a$ 太短够不着）；若 $\sin B = 1$，一解（$B = 90°$）；若 $\sin B < 1$，则 $B$ 有两解（锐角与钝角互补）——因为 $\sin B = \sin(180° - B)$。<span class="marginnote">回顾第 2 篇的 SSA「全等不成立」：同样是「两边及一边对角」，几何上可能画出两个三角形，代数上就是正弦的两解。这条「几何多解 ⇔ 代数两解」的对应，是「数形结合」最生动的教学案例——用「以 $C$ 为圆心、$a$ 为半径画弧，与 $B$ 的边交于几个点」就能预判解的个数。</span>

**判别方法：** 已知两边及一边对角，先画草图判断「弧与直线的交点个数」，再回到正弦定理解方程、按角的大小取舍（大边对大角）。

## 5 三角形面积公式的三角形式

正弦定理与余弦定理还有一个「帮手」——**用两边及其夹角直接写面积**：

$$S = \frac{1}{2}ab\sin C = \frac{1}{2}bc\sin A = \frac{1}{2}ca\sin B$$

**重点：** 这个公式与「$\frac{1}{2} \times$ 底 $\times$ 高」完全同源——把 $b$ 当底，$c\sin A$ 就是高（$A$ 是 $b$ 与 $c$ 的夹角），所以 $\frac{1}{2}bc\sin A$ 就是「底乘高除二」。它把「面积」与「角」联系起来，在解三角形与最值题里极常用：**当两边之积固定而夹角可变时，面积随 $\sin$ 变化；$\sin$ 最大为 1，故夹角为 $90°$ 时面积最大**——「两条边确定的三角形，直角时面积最大」，这是由三角比导出的最直观的最值结论。

**补充：** 结合正弦定理 $\frac{c}{\sin C} = 2R$，还能推出 $S = 2R^2 \sin A \sin B \sin C$ 与「已知三边」的海伦公式——正弦定理、余弦定理、面积公式、海伦公式在三角形里「一荣俱荣」，互相可以推来推去。**记住任一条，其余都能从它长出来**，这是三角公式「互相印证」的第一个样本。

## 6 应用：测高、测距与航海

正弦定理、余弦定理合在一起，能解决几乎所有「不可直接测量的量」：

**测高：** 站在距塔脚水平距离 $d$ 处，测得塔顶仰角 $\alpha$，塔高 $h = d \tan\alpha$；若塔脚不可达，则选两个观测点（距离为 $l$），测得两个仰角，用「两个直角三角形 + 方程」联立解出塔高。

**测距：** 隔河测得河宽，用「基线 + 两个角」构造三角形，正弦定理一步算出。<span class="marginnote">这些方法几乎原封不动地延续了古希腊测量学与明代《海道经》、清代《数理精蕴》里的测量手法；今天的卫星导航、车载雷达定位仍是同一套「已知部分角边、反推未知」的思想，只是测量精度与计算工具换了代。</span>

**航海与航空：** 已知两点经度纬度（即球面上两角），用球面三角推算大圆航线距离——这已经是第四篇《球面距离与旋转体》的内容。中学阶段我们先把「平面上如何解三角形」练透，再登球面这座「大船」。

## 7 小结

- **三角比** $\sin A$、$\cos A$、$\tan A$ 只由角决定，根源是相似三角形；特殊角 $30°/45°/60°$ 的比值要一眼看穿。
- **正弦定理** $\dfrac{a}{\sin A} = 2R$：已知两角一边、或两边一对角时用；「大边对大角」帮助取舍解。
- **余弦定理** $a^2 = b^2 + c^2 - 2bc\cos A$：已知两边一夹角、或三边时用；它是勾股定理的推广，也是「差的模平方」的展开。
- **解三角形四情形**：两角一边、两边一夹角、三边均唯一；**SSA 有多解**（0、1 或 2），要画弧判交点再取舍。
- **面积三角形式** $S = \frac{1}{2}ab\sin C$：把「面积」与「角」挂钩；两边固定时，夹角 $90°$ 面积最大。
- 测高、测距、航海——**解三角形就是「用可测的量推算不可测的量」**，是人类最早的定量技术之一。
- 三角比、正弦定理、余弦定理是第四篇「任意角三角函数」的入口，也是信号与傅里叶分析的种子。
