# 两条直线的位置关系

## 为什么从两条直线的位置关系开始

平面里两条直线的全部关系，只有三种：**平行、相交、重合**。在坐标系里，这三种关系分别对应斜率的相等、不同、完全一致。更进一步，「垂直」是相交的特例，它的判据「斜率之积为 $-1$」是解析几何最常用的公式之一。这一节把「几何关系」全部翻译成「斜率与方程的代数条件」——它既是直线知识的收尾，也是下一节《圆的方程》与解析几何后续内容的方法基础。

## 1 平行、重合、相交：斜率判据

设两条直线 $l_1: y = k_1 x + b_1$，$l_2: y = k_2 x + b_2$（斜率存在）：

| 位置关系 | 斜率条件 | 截距条件 |
| --- | --- | --- |
| 平行 | $k_1 = k_2$ | $b_1 \neq b_2$ |
| 重合 | $k_1 = k_2$ | $b_1 = b_2$ |
| 相交 | $k_1 \neq k_2$ | 无关 |

<span class="marginnote">记忆要点：<strong>平行与重合都要求斜率相等，区别在截距</strong>。斜率相等但截距不同 → 平行（永不相交）；斜率相等且截距相同 → 重合（是同一条直线）。斜率不同 → 必相交于一点。</span>

**辨析｜易错点：** 竖直线（斜率不存在）要单独讨论：$x = c_1$ 与 $x = c_2$，若 $c_1 = c_2$ 则重合，否则平行；竖直线与水平线 $y = b$ 总是垂直。用斜率判据时先检查「斜率是否存在」，否则结论出错。

## 2 公式解析：垂直的斜率判据

两条直线垂直，斜率满足一个极简洁的条件：

$$
l_1 \perp l_2 \;\; \Longleftrightarrow \;\; k_1 k_2 = -1
$$

即**两斜率之积为 $-1$**（互为负倒数）。对这条式子做三步拆解：

- **第一步，从倾斜角看**：若 $l_1$ 倾斜角为 $\alpha$，则 $l_2$ 倾斜角为 $\alpha + 90^\circ$，所以 $k_2 = \tan(\alpha + 90^\circ) = -\cot\alpha = -\frac{1}{\tan\alpha} = -\frac{1}{k_1}$。
- **第二步，交叉相乘**：$k_2 = -\frac{1}{k_1}$ 即 $k_1 k_2 = -1$。注意这要求两个斜率都存在——竖直线与水平线垂直是它的「退化」情形。
- **第三步，方向向量的视角**：两条直线垂直 ⇔ 它们的方向向量 $\vec{u}$、$\vec{v}$ 内积为零：$\vec{u} \cdot \vec{v} = 0$。方向向量取 $(1, k_1)$、$(1, k_2)$，内积 $1 + k_1k_2 = 0$ 同样得 $k_1k_2 = -1$。

<span class="marginnote">「垂直 ⇔ 内积为零」是比「斜率之积为 $-1$」更根本的判据——它不需要处理斜率的例外情况，也在空间向量里直接通用。到第二级《线性代数》，你会明白这是「正交」概念在坐标系的化身。</span>

## 3 公式解析：点到直线的距离

两直线的位置关系还有一个「度量」问题：如何量两条平行线之间的距离？基础是**点到直线的距离公式**：

$$
d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}
$$

其中直线为 $Ax + By + C = 0$，点 $P(x_0, y_0)$。对这条式子做三步拆解：

- **第一步，几何意义**：分子 $|Ax_0 + By_0 + C|$ 是「把 $P$ 代入直线方程得到的偏差」，分母 $\sqrt{A^2 + B^2}$ 是法向量 $(A, B)$ 的长度。
- **第二步，为什么成立**：点 $P$ 到直线的垂直距离 = $\vec{AP}$ 在法向量 $\vec{n} = (A, B)$ 方向的投影长度 = $\frac{|\vec{AP} \cdot \vec{n}|}{|\vec{n}|}$。若 $A$ 是直线上一点，$\vec{AP} \cdot \vec{n} = A(x_0-x_1) + B(y_0-y_1) = Ax_0 + By_0 + C$（因为 $Ax_1 + By_1 + C = 0$）。
- **第三步，平行线距离**：两平行直线 $Ax + By + C_1 = 0$ 与 $Ax + By + C_2 = 0$ 的距离为 $d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$——在一条线上任取一点，用点线距公式即可。

<span class="marginnote">这个公式是「向量投影」的杰作：点线距离 = 位矢在法向量上的投影长度。它与第二篇《空间向量与立体几何》里的点面距公式 $d = \frac{|\vec{AP}\cdot\vec{n}|}{|\vec{n}|}$ 结构完全一致——只是维数不同，本质同一个「投影」思想。</span>

## 4 两直线的交点与方程组的联系

两条直线相交，交点坐标就是**两个方程联立的解**：

$$
\begin{cases} A_1 x + B_1 y + C_1 = 0 \\ A_2 x + B_2 y + C_2 = 0 \end{cases}
$$

- **有唯一解**：两直线相交（$k_1 \neq k_2$）；
- **无解**：两直线平行（$k_1 = k_2$，$b_1 \neq b_2$）；
- **无穷多解**：两直线重合（两方程成比例）。

**重点：** 「几何关系 ⇔ 方程组的解」是解析几何最深刻的思想之一：**位置关系变成了线性方程组的可解性问题**。这个连接直接通向第二级《线性代数》——解方程组、秩、线性无关，全都从这里长出来。<span class="marginnote">两直线方程联立的三种解情况，对应着系数矩阵的秩：满秩 → 唯一交点，秩亏 → 平行或重合。这是线性代数「解的结构」思想在二维的完整预演。</span>

## 5 交点系与直线族

用两条相交直线还可以「生成」新的直线：设 $l_1$、$l_2$ 交于 $P$，则方程

$$
A_1 x + B_1 y + C_1 + \lambda(A_2 x + B_2 y + C_2) = 0
$$

表示**过交点 $P$ 的直线族**（除 $l_2$ 外）——$\lambda$ 每取一个值，就得到一条过 $P$ 的直线。<span class="marginnote">「直线族」是「参数化一族对象」的雏形：用一个参数 $\lambda$ 扫过一族直线。这个思想在圆的方程（圆心在一条线上移动）、圆锥曲线（离心率参数）、以及微积分的「包络线」里反复出现。</span>

两条直线的位置关系还有一个「夹角」的度量问题：两直线相交时，它们所成的角是锐角还是直角，可以用斜率直接计算。设两直线的斜率分别为 $k_1$、$k_2$，则它们的夹角 $\theta$ 满足：

$$
\tan\theta = \left|\frac{k_1 - k_2}{1 + k_1 k_2}\right| \quad (k_1 k_2 \neq -1)
$$

这个公式由「两角差的正切」得来：直线的倾斜角分别为 $\alpha_1$、$\alpha_2$，夹角为 $|\alpha_1 - \alpha_2|$，而 $\tan(\alpha_1 - \alpha_2) = \frac{\tan\alpha_1 - \tan\alpha_2}{1 + \tan\alpha_1\tan\alpha_2}$。取绝对值保证夹角取锐角（或直角）。当分母 $1 + k_1k_2 = 0$ 时，$k_1k_2 = -1$，两直线垂直，夹角为 $90^\circ$——与垂直判据自洽。

| 关系 | 代数判据 | 几何含义 |
| --- | --- | --- |
| 平行 | $k_1 = k_2$ | 方向相同 |
| 垂直 | $k_1k_2 = -1$ | 方向正交 |
| 夹角 $\theta$ | $\tan\theta = \left\|\frac{k_1-k_2}{1+k_1k_2}\right\|$ | 方向之差 |
| 重合 | $k_1 = k_2$ 且 $b_1 = b_2$ | 完全一致 |

这张表把「位置关系」与「方向关系」统一了：**平行 = 方向相同，垂直 = 方向正交，夹角 = 方向差**。两直线的几何关系，本质上全部是「方向向量之间的关系」——这是向量思想（第三篇《平面向量》）在直线世界的预演。

<span class="marginnote">「方向」这个概念会一路升级：两直线用斜率刻画方向，平面用法向量刻画，空间直线用方向向量刻画。到第二级《线性代数》，「方向」被抽象为「线性无关的向量组」——你在这里建立的「方向决定关系」直觉，是整个线性代数的种子。</span>

最后提醒一个工程背景：点在直线两侧的判别与点到直线距离，在「线性规划」里极其常用——可行域就是由若干半平面（直线一侧）的交集定义的，而「点在哪一侧」由 $Ax_0 + By_0 + C$ 的符号决定。中学的「两直线位置关系」，是线性规划、计算机图形学「裁剪算法」的基础。

## 6 小结

- 两直线关系：**平行**（$k$ 等 $b$ 不等）、**重合**（$k$、$b$ 都等）、**相交**（$k$ 不等）；竖直线单独讨论。
- **垂直判据**：$k_1 k_2 = -1$，本质是方向向量内积为零。
- **点线距公式** $d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$，是向量投影的二维版本；平行线距离为 $\frac{|C_1 - C_2|}{\sqrt{A^2+B^2}}$。
- 两直线相交 = 联立方程组有唯一解；位置关系与**方程组的解**一一对应，通向线性代数。
- 过交点的直线族 $l_1 + \lambda l_2 = 0$ 用参数化一族对象。
