# 正弦定理与余弦定理

<div class="epigraph">

## 为什么从正弦定理与余弦定理开始

直角三角形里的三角函数，怎样用到**任意三角形**？答案是两大定理：**正弦定理**把边与角的正弦挂钩，**余弦定理**把边与角的余弦挂钩。它们是把三角形「解」出来的核心工具——已知一些边角，求其余的边角。正弦定理揭示三角形与外接圆的内在联系，余弦定理则是勾股定理的任意角推广。从「从极限到大模型」的主线看，这两条定理是「用三角函数解几何」的高潮，也是测量学（测距、测高、定位）的数学引擎。

## 1 正弦定理

在 $\triangle ABC$ 中，角 $A, B, C$ 所对的边分别为 $a, b, c$，$R$ 为外接圆半径：

$$
\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R
$$

**正弦定理**：三角形各边与其对角的正弦之比相等，且等于**外接圆直径** $2R$。

<span class="marginnote">为什么等于 $2R$？因为 $a = 2R\sin A$ 的几何意义是「边 $a$ 等于外接圆直径乘以它所对角的正弦」——这与「同弧所对圆周角相等」密切相关（第一篇《圆周角与圆心角》）。正弦定理把三角形放进了它的外接圆。</span>

正弦定理的应用场景：「**已知两角一边**」或「**已知两边一对角**」时，用它求其余的边角。

## 2 余弦定理

在 $\triangle ABC$ 中，余弦定理把「夹角」与「第三边」连起来：

$$
a^2 = b^2 + c^2 - 2bc\cos A
$$

$$
b^2 = a^2 + c^2 - 2ac\cos B, \qquad
c^2 = a^2 + b^2 - 2ab\cos C
$$

**重点：** 余弦定理是**勾股定理的推广**：当 $A = 90^\circ$ 时 $\cos A = 0$，公式退化为 $a^2 = b^2 + c^2$——勾股定理正是余弦定理在直角情形下的特例。<span class="marginnote">「特例退化为已知定理」是检验新定理正确性的重要方法。余弦定理里那个 $-2bc\cos A$ 项，是「夹角不是直角」带来的修正——$A$ 越接近 $90^\circ$，修正项越接近 0。</span>

余弦定理的应用场景：「**已知两边一夹角**」（求第三边）或「**已知三边**」（求角，用变形式 $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$）。

## 3 公式解析：正弦定理的证明

证明 $\frac{a}{\sin A} = 2R$，用「外接圆 + 直径所对圆周角」三步完成：

- **第一步，作外接圆与直径**：作 $\triangle ABC$ 的外接圆，过 $B$ 作直径 $BD$，则 $\angle BCD = 90^\circ$（直径所对圆周角为直角）。
- **第二步，同弧等角**：$\angle BDC$ 与 $\angle BAC$ 都对弧 $BC$，所以 $\angle BDC = A$。
- **第三步，直角三角形**：在 $\rm{Rt}\triangle BCD$ 中，$\sin A = \sin\angle BDC = \frac{BC}{BD} = \frac{a}{2R}$，于是 $\frac{a}{\sin A} = 2R$。其余两边同理。

<span class="marginnote">这个证明把三条「孤立的边」统一到外接圆上：每一条边都等于「直径 × 对角正弦」。几何地看，三角形被它的外接圆「标准化」了——这是正弦定理最漂亮的注脚。</span>

## 4 公式解析：余弦定理的证明

证明 $a^2 = b^2 + c^2 - 2bc\cos A$，用「作高 + 勾股定理」三步完成：

- **第一步，作高建立直角三角形**：过 $B$ 作 $AC$ 边的高 $BD$，垂足为 $D$。若 $A$ 是锐角，$D$ 在 $AC$ 上，$AD = c\cos A$，$BD = c\sin A$，$CD = b - c\cos A$。
- **第二步，对 $\triangle BDC$ 用勾股定理**：$a^2 = BD^2 + CD^2 = (c\sin A)^2 + (b - c\cos A)^2$。
- **第三步，展开化简**：$a^2 = c^2\sin^2 A + b^2 - 2bc\cos A + c^2\cos^2 A = b^2 + c^2(\sin^2 A + \cos^2 A) - 2bc\cos A = b^2 + c^2 - 2bc\cos A$。

其中用到了同角关系 $\sin^2 A + \cos^2 A = 1$。<span class="marginnote">「作高 → 把斜三角形拆成直角三角形 → 用勾股与三角函数」是解任意三角形的基本功，也是「降维到直角三角形」思想的典型应用。钝角情形同理（高在延长线上，符号自动修正）。</span>

## 5 解三角形：判断解的个数

用正弦定理「已知两边一对角」求角时，会出现解的个数问题——可能 0 解、1 解或 2 解，这就是「**三角形解的判断**」。设已知 $a, b, A$：

- $a > b$：一解（大边对大角）；
- $a = b$：一解（等边对等角，若 $A < 90^\circ$）；
- $a < b$：需看 $a$ 与 $b\sin A$ 的关系——$a < b\sin A$ 无解，$a = b\sin A$ 一解（直角），$b\sin A < a < b$ 两解。

**辨析｜易错点：** 两解的情形最易漏——「已知两边一对角」可能对应两个不同的三角形（一个锐角、一个钝角，正弦值相同）。用 $\sin B = \frac{b\sin A}{a}$ 求出 $B$ 后，$B$ 与 $\pi - B$ 都可能合法，必须用「大边对大角」或内角和判断取舍。<span class="marginnote">这个「正弦值相同但角不同」的歧义，根源是「$\sin\theta$ 在 $(0, \pi)$ 上不是一一对应」——一个正弦值对应两个角。这正是解三角形最容易错的地方，也是「为什么用余弦定理求角更稳」（余弦在 $(0,\pi)$ 上一一对应）的原因。</span>

## 6 正弦定理与余弦定理的选择

| 已知条件 | 首选定理 | 备注 |
| --- | --- | --- |
| 两角一边 | 正弦定理 | 先用内角和求第三角 |
| 两边一对角 | 正弦定理 | 注意解的个数（可能两解） |
| 两边一夹角 | 余弦定理 | 直接求第三边 |
| 三边 | 余弦定理 | 用变形式求角，无歧义 |
| 求面积 | 两边一夹角用 $S = \frac{1}{2}ab\sin C$ | 正弦定理的推论 |

<span class="marginnote">选定理的原则：<strong>「角多」用正弦、「边多」用余弦</strong>。正弦定理在「给角求边」时最顺手；余弦定理在「给边求角」时无歧义（余弦一一对应）。面积公式 $S = \frac{1}{2}ab\sin C$ 是两边一夹角求面积的利器。</span>

正弦定理还有一个「统一」的形式值得留意：三条边的比值关系可以写成

$$
a : b : c = \sin A : \sin B : \sin C
$$

即**边的比等于对角正弦的比**。这个形式在「已知三边的比求角」「已知三正弦的比求边」时特别好用——不必引入外接圆半径 $R$，直接按比例设未知数。例如已知 $a : b : c = 3 : 4 : 5$，则可设 $a = 3k, b = 4k, c = 5k$，再用余弦定理求角。

| 已知 | 用正弦定理 | 用余弦定理 |
| --- | --- | --- |
| 两角一边 | 直接求另一边 | 先求角再套 |
| 两边一对角 | 求角（注意多解） | 可检验 |
| 两边一夹角 | — | 直接求第三边 |
| 三边 | 比值形式 | 直接求角 |
| 面积 | $S = \frac{1}{2}ab\sin C$ | 海伦公式 |

这张「选定理」对照表，把「角多用正弦、边多用余弦」的原则具体化了：**正弦定理擅长「边角互化」（把边换成对角正弦），余弦定理擅长「由边求角」（无歧义）**。选择的标准是「哪个方向计算量小、歧义少」。

<span class="marginnote">「边角互化」是解三角形大题的核心技巧：题目给的是「边的方程」（如 $2a\sin A = (2b+c)\sin B + \cdots$），就用正弦定理把边换成正弦；给的是「角的方程」，就反用正弦定理把正弦换回边。两种方向交替使用，直到方程变成「可解的标准形」。这个「换语言找通路」的过程，与「代数里消元、换元」是同一类操作。</span>

正弦定理与余弦定理还有「几何证明」的另一层价值：它们可以把「圆周角定理」「托勒密定理」等纯几何结论代数化。例如「圆内接四边形对角互补」与「托勒密定理 $AC \cdot BD = AB \cdot CD + AD \cdot BC$」都可以用正弦定理在圆中证明。**三角学与几何不是两套语言，而是同一套真理的两种方言**——这是「数形结合」最深刻的表达。

最后，正弦定理、余弦定理与「外接圆」的联结值得再确认一次：$\frac{a}{\sin A} = 2R$ 说明「边长由对角与外接圆半径共同决定」，而 $R$ 把三角形「放进圆里」——三角形的形状由角决定，大小由 $R$ 决定。这个「形状与大小分离」的视角，在相似三角形（形状相同、大小不同）里早已埋下伏笔。

## 7 小结

- **正弦定理** $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$：边与对角正弦成比例，等于外接圆直径。
- **余弦定理** $a^2 = b^2 + c^2 - 2bc\cos A$：勾股定理的任意角推广，$A = 90^\circ$ 时退化为勾股。
- 两个定理的证明都「降维到直角三角形」：正弦定理用外接圆直径，余弦定理用作高。
- 解三角形注意**解的个数**：两边一对角可能无解/一解/两解；求角优先用余弦（无歧义）。
- 选择原则：角多用正弦、边多用余弦；面积 $S = \frac{1}{2}ab\sin C$。
