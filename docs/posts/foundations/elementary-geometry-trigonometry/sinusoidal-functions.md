## 为什么从正弦型函数开始

$y = \sin x$ 是最简单的波形，但现实中的波——电流、声波、地震波——几乎都是「变了形」的正弦波。**正弦型函数** $y = A\sin(\omega x + \varphi) + b$ 用四个参数操控波形：$A$ 控制振幅（波的高低）、$\omega$ 控制频率（波的疏密）、$\varphi$ 控制相位（波的左右平移）、$b$ 控制上下平移。掌握了这四个旋钮，就掌握了用正弦波建模一切周期现象的能力，也是后续「由图像求解析式」与信号处理的基础。

## 1 四个参数的几何意义

**正弦型函数（sinusoidal function）**：

$$
y = A\sin(\omega x + \varphi) + b, \qquad A > 0, \ \omega > 0
$$

四个参数的几何意义：

| 参数 | 名称 | 作用 | 对图像的影响 |
| --- | --- | --- | --- |
| $A$ | 振幅 | 波的峰值 | 纵向拉伸：波峰 $b + A$、波谷 $b - A$ |
| $\omega$ | 角频率 | 波的疏密 | 横向压缩：周期 $T = \frac{2\pi}{\omega}$ |
| $\varphi$ | 初相 | 波的起点 | 左右平移 |
| $b$ | 垂直位移 | 波的基准线 | 上下平移：中线从 $0$ 移到 $b$ |

<span class="marginnote">名字的来历：$A\sin(\omega x + \varphi)$ 叫「正弦型」是因为它的图像还是正弦波，只是被四个参数「调制」过。物理里 $\omega$ 常叫角速度（角频率），$f = \frac{\omega}{2\pi}$ 叫频率（每秒几个周期），$T = \frac{1}{f}$ 是周期。</span>

**重点：** 振幅 $A$ 决定波峰波谷，**周期 $T = \frac{2\pi}{\omega}$** 决定疏密，**初相 $\varphi$ 决定「从哪开始」**。最大最小值是 $b \pm A$，函数图象的对称中心在 $y = b$ 这条中线上。

## 2 公式解析：图像变换的路径

从 $y = \sin x$ 到 $y = A\sin(\omega x + \varphi)$，可以通过**平移伸缩**实现，但顺序是关键。标准路径：

1. 相位：$y = \sin x \;\to\; y = \sin(x + \varphi)$（向左平移 $\varphi$）；
2. 频率：$y = \sin(x + \varphi) \;\to\; y = \sin(\omega x + \varphi)$（横坐标压缩为原来的 $\frac{1}{\omega}$）；
3. 振幅：$y = \sin(\omega x + \varphi) \;\to\; y = A\sin(\omega x + \varphi)$（纵坐标拉伸 $A$ 倍）。

对这条路径做三步拆解：

**第一步，先平移后压缩**：把 $\sin(x + \varphi)$ 的横坐标压缩 $\frac{1}{\omega}$ 倍，得到 $\sin(\omega x + \varphi)$——注意**先动相位再动频率**，顺序颠倒会得到不同函数。
**第二步，$\varphi$ 的平移量**：$y = \sin(\omega x + \varphi)$ 相对 $y = \sin(\omega x)$ 平移了 $\frac{\varphi}{\omega}$，不是 $\varphi$——因为 $\omega x + \varphi = \omega(x + \frac{\varphi}{\omega})$。
**第三步，振幅最后**：纵向伸缩与横向无关，最后做即可。$A$ 只改变纵坐标。

**辨析｜易错点：** 「由 $y = \sin 2x$ 平移到 $y = \sin(2x + \frac{\pi}{3})$」平移量是 $\frac{\pi/3}{2} = \frac{\pi}{6}$ 个单位，不是 $\frac{\pi}{3}$。**计算平移量永远要把 $x$ 的系数提出来**，看括号里 $x + \frac{\varphi}{\omega}$ 的形式。

## 3 由图像求解析式

「给一个正弦波形，反推出 $y = A\sin(\omega x + \varphi) + b$」是本节的核心应用，也是考试的高频题型。流程：

1. **看中线求 $b$**：波峰 $y_{\max}$ 与波谷 $y_{\min}$ 的平均值，$b = \frac{y_{\max} + y_{\min}}{2}$；
2. **看振幅求 $A$**：$A = \frac{y_{\max} - y_{\min}}{2}$；
3. **看周期求 $\omega$**：从图像量出周期 $T$，$\omega = \frac{2\pi}{T}$；
4. **代点求 $\varphi$**：把图像上一个特殊点代入，解出 $\varphi$（常用波峰、零点等「好算」的点）。

<span class="marginnote">求 $\varphi$ 时注意周期性与多解：代入一个点后 $\varphi$ 通常有无穷多解（相差 $2\pi$ 的整数倍），一般取「绝对值最小的 $\varphi$」或「符合图像位置的那个」。用「零点法」——看图像从哪个零点开始上升——常比代波峰更直观。</span>

**重点：** 「由图像求解析式」本质是**参数估计**：从数据（图像）反推模型的四个参数。这与机器学习里「从数据拟合模型参数」的思路完全同构——只是这里的数据是波形，模型是正弦型函数。

## 4 正弦型函数的应用：简谐运动

正弦型函数最著名的物理应用是**简谐运动（simple harmonic motion）**：

$$
y = A\sin(\omega t + \varphi)
$$

其中 $t$ 是时间，$y$ 是位移：

- $A$：振幅（最大位移）；
- $\omega$：角频率，$\omega = \frac{2\pi}{T}$；
- $\varphi$：初相（$t = 0$ 时刻的位置）；
- 弹簧振子、单摆（小角度）、交流电的电压电流，都是简谐运动。

<span class="marginnote">简谐运动为什么如此普遍？因为任何「偏离平衡位置的小扰动，受恢复力拉回」的系统，在平衡点附近的运动都是正弦——这是「线性化」思想（泰勒展开一阶近似）的物理化身，第二级《理论力学》《高等数学》都会深入。</span>

**辨析｜易错点：** 简谐运动里的 $\omega$ 叫「角频率」，单位是 $\mathrm{rad/s}$，不是频率 $f$（单位 $\mathrm{Hz}$）。两者关系 $\omega = 2\pi f$——每秒转过 $\omega$ 弧度，等价于每秒完成 $f$ 个周期。

## 5 从波形到频谱：傅里叶的视角

把 $y = A\sin(\omega x + \varphi)$ 放进傅里叶的框架，$A$ 与 $\omega$ 正是「频谱」的两要素：

**频谱**：把复杂波拆成一族正弦波，每个分量有一个振幅 $A$ 和一个频率 $\omega$；
**频域 vs 时域**：时域看「波形随时间怎么变」，频域看「哪些频率各占多大振幅」；
声学（音色 = 基频 + 泛音的振幅分布）、通信（调幅 = 改变 $A$，调频 = 改变 $\omega$）、图像压缩（DCT/DFT）全建立在这个视角上。

<span class="marginnote">「调幅广播改变振幅 $A$，调频广播改变频率 $\omega$」是正弦型函数最日常的应用：收音机里的「AM」「FM」就是「Amplitude Modulation」与「Frequency Modulation」。一个高中函数，撑起了整个通信工程。</span>

正弦型函数还有一个「五个关键点」的作图技巧，与五点法一脉相承：$y = A\sin(\omega x + \varphi) + b$ 在一个周期内，令 $\omega x + \varphi$ 分别取 $0, \frac{\pi}{2}, \pi, \frac{3\pi}{2}, 2\pi$，解出对应的五个 $x$ 值，再算出五个 $y$ 值（$b, b+A, b, b-A, b$），描点连线即得图像。**关键是让「内层角」取五个基准值，而不是让 $x$ 取五个等距值**。

| 内层角 $\omega x + \varphi$ | 函数值 | 对应 $x$ |
| --- | --- | --- |
| $0$ | $b$ | $-\frac{\varphi}{\omega}$ |
| $\frac{\pi}{2}$ | $b + A$ | $\frac{\pi/2 - \varphi}{\omega}$ |
| $\pi$ | $b$ | $\frac{\pi - \varphi}{\omega}$ |
| $\frac{3\pi}{2}$ | $b - A$ | $\frac{3\pi/2 - \varphi}{\omega}$ |
| $2\pi$ | $b$ | $\frac{2\pi - \varphi}{\omega}$ |

这张表把「画 $y = A\sin(\omega x + \varphi) + b$」变成了「解五个一次方程」——机械化、不易错。它比「从基本正弦一步步平移伸缩」更快，也直接暴露了 $\varphi$ 对「起始点」的影响。

<span class="marginnote">「令内层取基准值」的技巧，其实是在做「逆推」：先决定函数值（$b, b\pm A$），再反解出自变量 $x$。这种「由值反求自变量」的逆运算，在解三角方程（$\sin x = a$）、以及一般函数的「反函数」思想里，都是核心动作。</span>

正弦型函数在「建模实际问题」时的完整流程值得再梳理一遍：读题 → 提取周期（两个相邻峰值的时间差）、振幅（峰谷差的一半）、中线（峰谷的平均）→ 写出 $A, \omega, b$ → 用已知点（如起始时刻的函数值）定 $\varphi$ → 得到模型 → 代入时间求预测值。这套「从数据到模型」的流程，与机器学习「拟合」的思路同构——先定模型族，再定参数。

最后，「由图像求解析式」有一个「唯一性」的细节：同一波形可以由不同的 $\varphi$ 描述（相差 $2\pi$ 的整数倍），所以求出的 $\varphi$ 不唯一。考试中通常要求「取使解析式最简洁的那个」，或由题目的给定范围确定。**「参数不唯一」是建模的常态**——这也解释了为什么模型验证（代入多个点检验）比「求出即完」更重要。

## 6 小结

- 正弦型函数 $y = A\sin(\omega x + \varphi) + b$ 四参数：**$A$ 振幅、$\omega$ 角频率、$\varphi$ 初相、$b$ 垂直位移**。
- 周期 $T = \frac{2\pi}{\omega}$，最值 $b \pm A$；图像变换顺序「先相位再频率后振幅」，平移量是 $\frac{\varphi}{\omega}$。
- **由图像求解析式**：中线求 $b$、峰谷求 $A$、周期求 $\omega$、代点求 $\varphi$——本质是参数估计。
- 正弦型函数是**简谐运动**的数学模型：弹簧振子、交流电、单摆。
- 傅里叶视角：$A$ 与 $\omega$ 是频谱的两要素，正弦波是「一切周期信号的积木」。
