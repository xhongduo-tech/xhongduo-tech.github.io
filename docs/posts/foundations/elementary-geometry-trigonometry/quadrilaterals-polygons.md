## 为什么从四边形与多边形开始

三角形是最简单的多边形，但现实世界里的「面」大多是四边形：窗户、门板、屏幕、桌面。四边形比三角形多一个自由度——它有「不稳定性」，可以推拉变形；而三角形是「刚性」的。<span class="marginnote">这种「稳定性 vs 不稳定性」的差别在工程里被反复利用：桁架和桥梁用三角形保证刚性，而伸缩门、折叠椅、建筑工地上的活动脚手架则故意利用四边形的可变形性。</span>

从「从极限到大模型」的主线看，**平行四边形是最接近「向量」的几何对象**：它的两条对角线互相平分，这恰恰是「两个向量相加得对角线、相减得另一条对角线」的几何画面；而正多边形的旋转对称性，则是后面三角函数、傅里叶分析中「周期结构」的雏形。多边形既承接了前两篇的全等相似，又为后续的坐标几何与立体几何提供了素材。

## 1 多边形：内角和与外角和

**多边形（polygon）**：在同一平面内，由不在同一直线上的若干条线段首尾顺次相接组成的封闭图形。按边数命名：四边形、五边形、六边形……边数为 $n$ 的多边形记作 $n$ 边形。各边相等、各内角相等的多边形叫**正多边形**。

多边形有两条「角度守恒」定律，是整个多边形理论的基石：

**内角和定理：** $n$ 边形的内角和等于 $(n-2)\times 180°$。

**外角和定理：** 任意多边形的外角和（每个顶点处取一个外角）都等于 $360°$，与边数无关。

**重点：** 内角和定理的证明就是「切成三角形」：从某一个顶点出发，可以引出 $n-3$ 条对角线，把 $n$ 边形分成 $n-2$ 个三角形，每个三角形内角和 $180°$，故总内角和为 $(n-2)\times 180°$。<span class="marginnote">这个「一切多边形都可切成三角形」的思想，也顺带解释了上一篇「三角形是最小刚体单元」的说法：$n$ 边形内角和公式是三角形内角和定理的「放大版」。</span>外角和恒为 $360°$ 的直觉是「绕多边形走一圈，方向总共转了一整圈」——无论你走的是三角形、正方形还是 100 边形。

## 2 公式解析：$n$ 边形内角和

$$S_n = (n-2) \times 180°$$

对这条公式做三步拆解：

- **第一步，验证特例**：三角形 $n=3$，$S_3 = (3-2)\times 180° = 180°$，正确；四边形 $n=4$，$S_4 = 360°$，正是「四边形内角和等于 $360°$」；都符合已知结论，公式在低维端是自洽的。
- **第二步，理解「$n-2$」从哪来**：从多边形的一个顶点出发，能连出 $n-3$ 条对角线，把图形切成 $n-2$ 个互不重叠的三角形；**每个三角形的内角和贡献 $180°$，所以「$n-2$」就是三角形的个数**。
- **第三步，正向应用**：求正 $n$ 边形每个内角的度数，只需除以 $n$：$\dfrac{(n-2)\times 180°}{n}$。例如正六边形每个内角 $= \dfrac{4\times 180°}{6} = 120°$——这正是蜜蜂蜂房正六边形的角度，正六边形能无缝隙铺满平面（密铺），就是因为 $120°$ 能整除 $360°$。

**辨析｜易错点：** 「外角和」一定要在**每个顶点处只取一个外角**（一边的延长线与邻边组成的角），不要重复取。外角和恒等于 $360°$ 与边数无关，这是它和「内角和随边数增长」最本质的区别。

## 3 平行四边形：性质与判定

**平行四边形（parallelogram）**：两组对边分别平行的四边形。

它的**性质**（由定义推出）有四条，成对出现：

| 性质 | 表述 |
| --- | --- |
| 对边 | 对边平行且相等 |
| 对角 | 对角相等，邻角互补 |
| 对角线 | 对角线互相平分 |
| 对称性 | 中心对称（绕对角线交点旋转 180° 重合） |

它的**判定**（反过来，满足其一即是平行四边形）：

| 判定 | 表述 |
| --- | --- |
| 判定 1 | 两组对边分别平行 |
| 判定 2 | 两组对边分别相等 |
| 判定 3 | 一组对边平行且相等 |
| 判定 4 | 两组对角分别相等 |
| 判定 5 | 对角线互相平分 |

**重点：** 平行四边形是「向量加法」的几何模型：以 $A$ 为起点作 $\overrightarrow{AB}$ 与 $\overrightarrow{AD}$，则和向量 $\overrightarrow{AB} + \overrightarrow{AD}$ 恰是 $A$ 到对角顶点 $C$ 的向量，而 $\overrightarrow{AB} - \overrightarrow{AD}$ 是另一条对角线。**对角线互相平分**这条性质在向量语言里就是「$A$ 与 $C$ 的中点、$B$ 与 $D$ 的中点是同一个点」——这正是第三篇《空间向量与立体几何》的预告。<span class="marginnote">判定 3（一组对边平行且相等）是五个判定里最好用的：只须验证一组对边，性价比最高。实际做题时经常需要「先证明平行四边形，再利用其对边相等、对角线平分」来完成后续推理。</span>

## 4 矩形、菱形、正方形的层层递进

平行四边形家族有三员大将，它们不是并列关系，而是**层层加条件**的递进关系：

| 图形 | 在平行四边形基础上追加的条件 | 新增性质 |
| --- | --- | --- |
| 矩形 | 有一个角是直角 | 四个角都是直角；对角线相等 |
| 菱形 | 有一组邻边相等 | 四条边都相等；对角线互相垂直且平分每组对角 |
| 正方形 | 矩形 + 菱形（或：有一个直角且有一组邻边相等） | 兼具矩形与菱形的全部性质 |

**重点：** 正方形是「矩形与菱形的交集」，也是最对称的四边形——它既是中心对称（旋转 90° 重合），又有四条对称轴。<span class="marginnote">「正方形有四条对称轴」体现的是「旋转 90° 不变」——四个方向的对称都成立。而一般的矩形只有两条对称轴，菱形也是两条。对称轴的条数直接反映图形的「规则程度」。</span>判定矩形的关键是「对角线相等」或「有一个直角」；判定菱形的关键是「对角线互相垂直」或「邻边相等」；判定正方形则两个条件都要。

**辨析｜易错点：** 「对角线相等的四边形是矩形」这句话**是错的**——对角线相等的四边形可能是等腰梯形。正确的是「对角线相等且**互相平分**的四边形是矩形」（平分保证平行四边形，相等再推出矩形）。类似地，「对角线互相垂直的四边形是菱形」也错，必须加「互相平分」。

## 5 梯形与中位线

**梯形（trapezoid）**：一组对边平行而另一组对边不平行的四边形。平行的两边叫**底**，不平行的两边叫**腰**；两腰相等的叫**等腰梯形**，有一个角是直角的叫**直角梯形**。

梯形的核心定理是**梯形中位线定理**：连接两腰中点的线段叫中位线，它**平行于两底，且等于两底和的一半**：

$$\text{中位线长} = \frac{a + b}{2} \quad (\text{其中 } a, b \text{ 为两底长})$$

证明思路是把中位线「放回三角形」：作一条对角线把梯形切成两个三角形，用三角形中位线定理分别处理，再用「平行且长度相加」闭合。<span class="marginnote">等腰梯形还有一条漂亮的性质：<strong>同一底上的两个底角相等，两腰相等，两条对角线相等</strong>，且它是轴对称图形（对称轴是两底中点的连线）。这些性质都由「从一底两端向另一底作高，构造全等直角三角形」证明。</span>

## 6 正多边形：角度、对称与尺规作图

**正多边形**是各边相等、各内角相等的多边形，它的几何结构由一条性质统领：**任何一个正 $n$ 边形都内接于一个圆，也外切于一个圆**——外接圆圆心与内切圆圆心重合于正多边形的「中心」。

**重点：** 从中心向每个顶点连线，正 $n$ 边形被分成 $n$ 个全等的等腰三角形，每个三角形的顶角就是**中心角**：

$$\text{中心角} = \frac{360°}{n}$$

正多边形的三个关键角度：

- **中心角** $\dfrac{360°}{n}$：旋转对称的最小角度，正 $n$ 边形绕中心旋转 $\dfrac{360°}{n}$ 后与自身重合；
- **内角** $\dfrac{(n-2)\times 180°}{n}$：由内角和公式除以 $n$ 得到；
- **外角** $\dfrac{360°}{n}$：恰好等于中心角——「外角和 $360°$ 除以 $n$」。

<span class="marginnote">正多边形的「旋转对称」让它在自然界大量出现：正六边形的蜂房、正五边形的海星、雪花的多重对称。而「绕中心旋转 $360°/n$ 不变」这种周期性，正是第四篇三角函数里「正弦函数的图像每隔 $2\pi$ 重复一次」的几何祖先。</span>

**尺规作图：** 正 $n$ 边形能否用尺规作出，是数学史上著名的难题。正三角形、正方形、正五边形、正六边形都可作（正六边形最简便：以半径长为弦长在圆上连续截取六次）；高斯 19 岁时证明了**正 17 边形可以尺规作图**，并给出「可作的正 $n$ 边形」的完整刻画（$n$ 必须形如 $2^k \times$ 若干个费马素数之积）。这一结果让他下定决心以数学为业。<span class="marginnote">费马素数形如 $F_m = 2^{2^m} + 1$，前几个是 $3, 5, 17, 257, 65537$。可作正 $n$ 边形当且仅当 $n$ 是 $2$ 的幂乘上这些费马素数中任意多个的乘积——这是「尺规作图」从技艺升格为理论的巅峰，也是代数数论的开端。</span>

## 7 小结

- **内角和** $(n-2)\times 180°$，**外角和恒为 $360°$**；多边形都可切成 $n-2$ 个三角形。
- **平行四边形**：对边平行且相等、对角相等、对角线互相平分；五条判定里「一组对边平行且相等」最实用。
- **矩形 / 菱形 / 正方形**是逐步加条件的递进关系；「对角线相等」须配合「互相平分」才是矩形。
- **梯形中位线**等于两底和的一半；等腰梯形是轴对称图形。
- **正 $n$ 边形**中心角 $= \dfrac{360°}{n}$，旋转对称 + 轴对称；尺规可作性由高斯完整刻画。
- 平行四边形 = 向量加法，正多边形 = 旋转对称性——两族几何对象都为后续解析几何与三角铺路。
