## 为什么从圆的方程开始

圆是解析几何的第一条「曲线」——前几节研究的直线是线性对象，圆则引入了二次方程。**圆的标准方程** $(x-a)^2 + (y-b)^2 = r^2$ 是「到定点距离等于定长」这个几何定义最直接的翻译；**一般方程**则把它展开成二元二次式的标准形。研究圆方程，是从「一次（直线）」跨到「二次（曲线）」的第一步，也是圆锥曲线（椭圆、双曲线、抛物线）全部内容的方法预演。从「从极限到大模型」的主线看，圆方程是函数图像之外「隐式曲线」的第一个代表。

## 1 圆的标准方程

**圆的标准方程**：以 $C(a, b)$ 为圆心、$r$ 为半径的圆，方程为

$$
(x - a)^2 + (y - b)^2 = r^2
$$

它是「圆是到圆心距离等于半径的点的集合」的直接翻译：点 $P(x, y)$ 在圆上 ⇔ $|PC| = r$ ⇔ $\sqrt{(x-a)^2 + (y-b)^2} = r$，两边平方即得。<span class="marginnote">特别地，圆心在原点时方程是 $x^2 + y^2 = r^2$——这是最简洁的圆方程，也是单位圆 $x^2 + y^2 = 1$ 的来源（第四篇三角函数的重要舞台）。</span>

**辨析｜易错点：** 方程里的 $(x-a)^2$ 是「减圆心坐标」，不是「加」——圆心在 $(-2, 3)$ 的圆写成 $(x+2)^2 + (y-3)^2 = r^2$。判断圆心时，把方程写成「平方和 = 常数」的形式，括号内是 $(x-a)$ 则圆心横坐标为 $a$。

## 2 圆的一般方程

把标准方程展开整理，得到**圆的一般方程**：

$$
x^2 + y^2 + Dx + Ey + F = 0
$$

配方得标准形：

$$
\left(x + \frac{D}{2}\right)^2 + \left(y + \frac{E}{2}\right)^2 = \frac{D^2 + E^2 - 4F}{4}
$$

于是：

- 圆心 $\left(-\frac{D}{2}, -\frac{E}{2}\right)$，半径 $r = \frac{1}{2}\sqrt{D^2 + E^2 - 4F}$；
- 当 $D^2 + E^2 - 4F > 0$，是圆；
- 当 $D^2 + E^2 - 4F = 0$，退化成一个点；
- 当 $D^2 + E^2 - 4F < 0$，不表示任何图形。

<span class="marginnote">一般式 $x^2+y^2+Dx+Ey+F=0$ 的特征：$x^2$ 与 $y^2$ 的系数<strong>相同</strong>（这里都是 1）且<strong>没有 $xy$ 项</strong>。这是「一个二元二次方程是圆」的必要条件，判断方程表示什么图形就看它。</span>

**重点：** 一般式→标准式的方法是「配方」，标准式→一般式是「展开」。配方是解析几何的基本功，也是之后研究圆锥曲线的通用工具。

## 3 公式解析：由三个条件确定圆

一个圆由三个独立条件决定——这对应标准方程中的三个参数 $(a, b, r)$。常见「三条件」组合：

- 圆心坐标 + 半径；
- 圆心坐标 + 圆上一点（求半径）；
- 三点（利用待定系数法设一般式）。

**待定系数法求过三点的圆**：设圆的一般式 $x^2 + y^2 + Dx + Ey + F = 0$，把三点坐标分别代入，得到关于 $D, E, F$ 的三元一次方程组：

$$
\begin{cases} x_1^2 + y_1^2 + Dx_1 + Ey_1 + F = 0 \\ x_2^2 + y_2^2 + Dx_2 + Ey_2 + F = 0 \\ x_3^2 + y_3^2 + Dx_3 + Ey_3 + F = 0 \end{cases}
$$

解出 $D, E, F$ 即得圆方程。拆解三步：

- **第一步，设「通式」**：不知道圆心与半径，就先用一般式这个「通吃」的含参形式；
- **第二步，代点列方程**：每个点给一条「约束」，三点三条方程，正好解三个未知数；
- **第三步，回代得圆**：解出参数，圆方程唯一确定。「三条件确定圆」与「三条方程解三个未知数」完美对应。

<span class="marginnote">待定系数法的精神：「先把目标写成含参数的通式，再用条件列方程解参数」。这个「设 → 列 → 解 → 代」的流程，在求函数解析式、求二次曲线方程里反复出现，是代数建模的基本功。</span>

## 4 与圆有关的轨迹问题

解析几何有一类经典问题：**求动点的轨迹方程**。设动点 $P$ 满足某几何条件，求 $P$ 的轨迹方程。

典型例子：求到定点 $A(2, 0)$ 的距离等于到 $B(-2, 0)$ 的距离 $2$ 倍的点的轨迹。

**解析步骤**：设 $P(x, y)$，条件写成 $|PA| = 2|PB|$，即

$$
\sqrt{(x-2)^2 + y^2} = 2\sqrt{(x+2)^2 + y^2}
$$

平方、整理后得到 $(x + \frac{10}{3})^2 + y^2 = \frac{64}{9}$——轨迹是一个圆。<span class="marginnote">「动点轨迹」是解析几何的核心题型：把几何条件「翻译」成坐标等式，再化简出方程。这个「翻译」正是解析几何的全部精神。当比例 $|PA| : |PB| = k$（$k \neq 1$）时轨迹是阿波罗尼奥斯圆，$k = 1$ 时是垂直平分线。</span>

**重点：** 求轨迹方程的完整流程：设点 → 翻译条件 → 化简方程 → 检验（去除不符合条件的点，如分母为零处）。「检验」常被忽略，却是保证轨迹「不多不少」的关键。

## 5 圆的方程与三角函数

圆方程与三角函数有深刻的联系——单位圆的参数方程：

$$
x^2 + y^2 = 1 \quad \Longleftrightarrow \quad \begin{cases} x = \cos\theta \\ y = \sin\theta \end{cases}
$$

圆上的点 $(x, y)$ 可以用角度 $\theta$ 参数化，这正是第四篇三角函数「单位圆定义」的代数形式。<span class="marginnote">这个连接是双向的：圆的方程给三角函数的「坐标定义」提供几何舞台，而参数 $\theta$ 又给圆上的点提供「角度的编号」。到《参数方程与极坐标入门》，你会看到这个参数化推广到一般曲线。</span>

圆的标准方程与一般方程还有一个「判断」层面的问题：给定一个二元二次方程 $x^2 + y^2 + Dx + Ey + F = 0$，如何判断它是不是圆？关键看两点——**$x^2$ 与 $y^2$ 的系数相同（且不为 0）、没有 $xy$ 项**，再配方法看 $D^2 + E^2 - 4F$ 的符号。这两个「系数条件」是必要条件，第三个「判别式条件」是充分保证。

| 二元二次方程 | 图形 | 判别依据 |
| --- | --- | --- |
| $x^2 + y^2 + Dx + Ey + F = 0$ | 圆 | $D^2+E^2-4F > 0$ |
| 同上 | 点 | $D^2+E^2-4F = 0$ |
| 同上 | 无图形 | $D^2+E^2-4F < 0$ |
| $x^2 + 2y^2 + \cdots = 0$ | 椭圆（一般） | $x^2, y^2$ 系数不同 |

这张表暗示了一个更深的问题：**「方程的形状」与「系数」之间存在对应**——$x^2$、$y^2$ 系数相同时可能是圆，不同时是椭圆，含 $xy$ 项时是「倾斜的」二次曲线。这个「二次曲线分类」问题在圆锥曲线章节会系统展开，它的本质是「二次型」（第二级《线性代数》）的正定性。

<span class="marginnote">「由方程识别图形」与「由图形写出方程」是解析几何的一体两面：前者是「读」，后者是「写」。掌握两者之间的双向翻译，就掌握了解析几何的「语言能力」——这就像掌握了一门双语：图形语言与方程语言随时互译。</span>

最后，圆方程在实际中还有一个高频应用——**求动点的轨迹**：若动点 $P$ 到两定点的距离之比为定值，轨迹是一个圆（阿波罗尼奥斯圆）；到两点距离平方和为定值，轨迹也是圆。这类「轨迹方程」问题是解析几何的核心题型，而圆是最简单的「轨迹对象」。理解「轨迹 = 满足条件的点集」与集合语言 $\{P \mid \text{条件}\}$ 的对应，是学好轨迹问题的关键。

## 6 小结

- **标准方程** $(x-a)^2 + (y-b)^2 = r^2$：圆心 $(a, b)$、半径 $r$，是几何定义最直接的翻译。
- **一般方程** $x^2+y^2+Dx+Ey+F=0$：配方得圆心 $\left(-\frac{D}{2}, -\frac{E}{2}\right)$，$D^2+E^2-4F$ 的正负决定圆/点/无图形。
- **三条件定圆**：待定系数法设一般式、三点代方程、解三元一次方程组。
- **轨迹问题**：设点 → 翻译条件 → 化简 → 检验；「距离比为 $k$」的轨迹是阿波罗尼奥斯圆。
- 单位圆参数方程 $x = \cos\theta$、$y = \sin\theta$ 是圆与三角函数的桥。
