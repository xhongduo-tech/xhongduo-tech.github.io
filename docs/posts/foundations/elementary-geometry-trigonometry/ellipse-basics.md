## 为什么从椭圆开始

椭圆是圆锥曲线家族的第一位成员，也是「圆被压扁」的自然推广。它的定义不再是「到定点距离等于定长」，而是「**到两定点的距离之和等于常数**」——一个更「有弹性」的轨道。椭圆在现实中无处不在：行星轨道、卫星轨道、椭圆的反射性质（从一个焦点发出的光反射到另一个焦点）、建筑设计。从「从极限到大模型」的主线看，椭圆是二次曲线的标准样本，它的方程、焦点、离心率为后续双曲线、抛物线铺好全部词汇。

## 1 椭圆的定义与基本要素

**椭圆（ellipse）**：平面内**到两个定点 $F_1$、$F_2$ 的距离之和等于常数（大于 $|F_1F_2|$）** 的点的轨迹。

- 两个定点叫**焦点**（focus），记 $F_1$、$F_2$；
- 两焦点间的距离叫**焦距**，$|F_1F_2| = 2c$；
- 轨迹上的点满足 $|PF_1| + |PF_2| = 2a$（$2a$ 是那个常数，$a > c$）。

<span class="marginnote">椭圆的标准定义是「椭圆规」的几何：把一根绳子两端钉在两个图钉上，用笔拉紧绳子画一圈，画出的就是椭圆——绳长就是 $2a$，两图钉就是焦点。这个画法直观说明「到两焦点距离之和恒为常数」。</span>

**辨析｜易错点：** 常数必须大于焦距 $2c$，否则轨迹退化：等于 $2c$ 时是线段 $F_1F_2$，小于 $2c$ 时不存在。定义里的「之和等于常数」与圆的「距离等于常数」形成鲜明对比——一个「和」一个「等」，这是理解椭圆的关键。

## 2 椭圆的标准方程

以焦点在 $x$ 轴上、中心在原点为例，设椭圆上点 $P(x, y)$，由定义 $|PF_1| + |PF_2| = 2a$，其中 $F_1(-c, 0)$、$F_2(c, 0)$，化简得：

$$
\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1, \qquad b^2 = a^2 - c^2
$$

其中 $a$ 叫**长半轴**，$b$ 叫**短半轴**，$c$ 是半焦距。<span class="marginnote">推导的关键步骤：把 $\sqrt{(x+c)^2+y^2} + \sqrt{(x-c)^2+y^2} = 2a$ 两边平方两次，移项、合并后利用 $a^2 - c^2 = b^2$ 化简。两次平方是有技巧的「移项再平方」，值得亲手推一遍——它是「从定义到方程」的标准示范。</span>

**重点：** 标准方程是「分式 = 1」的形式，它揭示了椭圆的重要几何信息：

- 与 $x$ 轴交于 $(\pm a, 0)$，与 $y$ 轴交于 $(0, \pm b)$；
- $a > b > 0$，$a^2 = b^2 + c^2$（勾股关系，构成「特征三角形」）；
- 当 $a = b$ 时方程化为 $x^2 + y^2 = a^2$——**椭圆退化为圆**。圆是 $a = b$ 的椭圆（离心率 $e = 0$）。

## 3 公式解析：椭圆的离心率

**离心率（eccentricity）** 是刻画椭圆「扁平程度」的量：

$$
e = \frac{c}{a}, \qquad 0 < e < 1
$$

对这条式子做三步拆解：

- **第一步，定义**：离心率 = 半焦距 ÷ 长半轴。由 $c^2 = a^2 - b^2$，$e = \sqrt{1 - \frac{b^2}{a^2}}$。
- **第二步，几何含义**：$e$ 越接近 $0$，$b$ 越接近 $a$，椭圆越「圆」；$e$ 越接近 $1$，$b$ 越小，椭圆越「扁」。
- **第三步，与圆的关系**：圆可看成 $e = 0$ 的退化椭圆；$e$ 在 $(0, 1)$ 之间连续变化，就「压扁」出从圆到极扁椭圆的一切形状。

<span class="marginnote">离心率是圆锥曲线的「家族身份证」：椭圆 $0 < e < 1$、抛物线 $e = 1$、双曲线 $e > 1$。同一个 $e$ 的统一定义——「到焦点与到准线的距离之比」——让三种曲线由一个参数贯通。到后面学完三种曲线，你会看到这张「身份证」的分量。</span>

## 4 公式解析：焦点三角形与光学性质

椭圆上的点 $P$ 与两焦点构成**焦点三角形** $\triangle PF_1F_2$。若 $\angle F_1PF_2 = \theta$，由余弦定理与 $|PF_1|+|PF_2| = 2a$：

$$
S_{\triangle PF_1F_2} = b^2 \tan\frac{\theta}{2}
$$

对这条式子做三步拆解：

- **第一步，设未知**：设 $|PF_1| = m$、$|PF_2| = n$，则 $m + n = 2a$。
- **第二步，余弦定理**：$(2c)^2 = m^2 + n^2 - 2mn\cos\theta = (m+n)^2 - 2mn(1+\cos\theta)$，解出 $mn = \frac{2b^2}{1+\cos\theta}$。
- **第三步，面积公式**：$S = \frac{1}{2}mn\sin\theta = \frac{b^2\sin\theta}{1+\cos\theta} = b^2\tan\frac{\theta}{2}$。

**椭圆的光学性质**：从椭圆一个焦点发出的光（或声），经椭圆壁反射后**必经过另一个焦点**。这个性质是「回音壁」（如北京天坛的回音壁）、椭球面聚光镜的原理。<span class="marginnote">光学性质的证明仍用「到两焦点距离和为常数」：反射角相等要求「最短路径」，而椭圆上的点到两焦点的折线恰好是「最短」，于是反射自然指向另一焦点。这个「最短路径 ⇔ 反射」的思想在光学与变分法里极其深刻。</span>

## 5 椭圆与坐标、参数方程

椭圆还有一个漂亮的**参数方程**：设 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$，则

$$
\begin{cases} x = a\cos\theta \\ y = b\sin\theta \end{cases}, \qquad 0 \le \theta < 2\pi
$$

参数 $\theta$ 的几何意义：不是椭圆上的「极角」，而是「把椭圆看成单位圆在 $x$、$y$ 方向分别拉伸 $a$、$b$ 倍」时对应点的角度——从圆心看该点（辅助圆上的点）的角。<span class="marginnote">「圆被拉伸成椭圆」是理解椭圆的捷径：把单位圆 $x^2+y^2=1$ 的每个点 $(x, y)$ 变成 $(ax, by)$，就得到椭圆。这解释了为什么圆的所有「拉伸版」性质都能继承——也是第三篇《参数方程与极坐标入门》的重点。</span>

椭圆的「定义方式」其实不止一种，理解这些等价定义能让椭圆更立体：

- **轨迹定义**：到两定点距离之和为常数（本节主定义）；
- **方程定义**：$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（坐标语言）；
- **伸缩定义**：圆 $x^2 + y^2 = 1$ 按 $x$、$y$ 方向分别伸缩 $a$、$b$ 倍；
- **焦点-准线定义**：到焦点的距离与到准线的距离之比为常数 $e$（离心率定义，通用圆锥曲线）。

这四种定义在同一条椭圆曲线上完全等价，但各自突出的性质不同：轨迹定义强调「两焦点」，方程定义强调「坐标对称」，伸缩定义强调「与圆的关系」，焦点-准线定义强调「统一的离心率」。**同一个对象有多种等价定义**，是数学中常见的现象——每种定义都是一扇不同的窗。

| 定义方式 | 突出信息 | 适合的问题 |
| --- | --- | --- |
| 轨迹（两焦点） | 焦点、$2a$ | 椭圆规、几何构造 |
| 方程 | 长短轴、对称性 | 坐标计算 |
| 伸缩（圆） | 与圆的亲缘 | 参数方程、图形变换 |
| 焦点-准线 | 离心率 $e$ | 圆锥曲线统一 |

这张表提示：解题时「选定义」很重要——遇到焦点相关的问题用轨迹定义，遇到坐标计算用方程，遇到离心率统一问题用焦点-准线定义。

<span class="marginnote">「一个对象多种定义」在数学里是常态：实数可以被定义为「戴德金分割」或「柯西列的等价类」，概率可以是「测度」或「公理化」——不同定义服务不同目的。这种「多视角」能力，也是理解大模型「同一模型多种用途」的重要思维训练。</span>

最后，椭圆与圆在「几何量」上的对应值得整理：圆有圆心、半径、直径；椭圆有中心、长半轴 $a$、短半轴 $b$、半焦距 $c$，且 $a^2 = b^2 + c^2$——**椭圆是「一个被拉开的圆」，所有圆的性质在 $a = b$ 时恢复**。记住这个「退化恢复」原则，椭圆公式的记忆负担会减轻一半。

## 6 小结

- **椭圆定义**：到两焦点距离之和为常数 $2a$；$a > c$，否则退化。
- **标准方程** $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$，$b^2 = a^2 - c^2$；$a = b$ 时退化为圆。
- **离心率** $e = \frac{c}{a} \in (0, 1)$，$e$ 越接近 0 越圆、越接近 1 越扁；圆是 $e = 0$。
- 焦点三角形面积 $S = b^2\tan\frac{\theta}{2}$；椭圆的光学性质「一焦点反射到另一焦点」是回音壁原理。
- 参数方程 $x = a\cos\theta$、$y = b\sin\theta$：圆按轴拉伸即得椭圆。
