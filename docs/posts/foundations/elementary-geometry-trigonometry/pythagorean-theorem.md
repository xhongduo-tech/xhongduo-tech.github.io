## 为什么从勾股定理开始

直角三角形三边之间，藏着全数学最著名的一个等式：**两直角边的平方和等于斜边的平方**。中国称「勾股定理」，西方称「毕达哥拉斯定理」，它有数百种证法，是几何与代数第一次深情相拥的产物。它不仅是解三角形的核心工具，更直接孕育了坐标系里的距离公式、三角恒等式 $\sin^2\theta + \cos^2\theta = 1$，以及内积空间的度量结构。从「从极限到大模型」的主线看，向量、解析几何、甚至机器学习的「欧氏距离」都建立在这条定理之上——它是度量世界的第一把钥匙。

## 1 勾股定理：内容与含义

**勾股定理（Pythagorean theorem）**：直角三角形两直角边 $a$、$b$ 的平方和，等于斜边 $c$ 的平方：

$$a^2 + b^2 = c^2$$

其中 $c$ 是直角所对的边（斜边），也是直角三角形最长的边。<span class="marginnote">命名：中国古代把短直角边叫「勾」、长直角边叫「股」、斜边叫「弦」，于是「勾三股四弦五」就是 $3^2+4^2=5^2$。西方以毕达哥拉斯命名，但埃及人、巴比伦人更早就知道勾股数。</span>

**重点：** 勾股定理描述的是**直角三角形三边的长度关系**，它把一个「位置关系」（有一个直角）翻译成了一个「数量关系」（平方和）。这种「几何 ↔ 代数」的互译，是解析几何的思想雏形。

勾股数是一类有趣的整数解：$(3,4,5)$、$(5,12,13)$、$(6,8,10)$、$(8,15,17)$……所有基本勾股数都可以由参数式生成（$m^2-n^2, 2mn, m^2+n^2$，其中 $m>n$ 为正整数）。<span class="marginnote">勾股数参数式是「不定方程」的经典例子，第二级《数论》会系统地研究这类「找整数解」的问题，并给出 $x^2+y^2=z^2$ 的全部正整数解。</span>

## 2 公式解析：勾股定理的面积证明

为什么 $a^2+b^2=c^2$ 一定成立？用一个「以斜边为边的大正方形」来证明，最直观：

$$
\underbrace{(a+b)^2}_{\text{大正方形面积}} = \underbrace{c^2}_{\text{中间小正方形}} + 4 \cdot \underbrace{\frac{1}{2}ab}_{\text{四个直角三角形}}
$$

对这条式子做三步拆解：

- **第一步，构造图形**：取四个全等的直角三角形，直角边为 $a$、$b$，斜边为 $c$，把它们拼成一个大正方形，中间自然留下一个边长为 $c$ 的小正方形。大正方形的边长是 $a+b$。
- **第二步，两边算面积**：大正方形面积 = $(a+b)^2 = a^2 + 2ab + b^2$；换一种算法，它 = 小正方形 $c^2$ + 四个直角三角形 $4 \times \frac{1}{2}ab = 2ab$。
- **第三步，恒等联立**：$a^2 + 2ab + b^2 = c^2 + 2ab$，两边约去 $2ab$，得到 $a^2 + b^2 = c^2$。

这个证明的美妙在于**零计算**：两个不同的拼法给出同一个面积，等式自己从图形里长出来。<span class="marginnote">「同一个量用两种方式算，结果必须相等」是极其强大的证明策略，叫「等面积法」。物理里求质心、数学里求概率密度，都靠这个思想。到第二级《数学分析》你会看到它升级为「夹逼」。</span>

## 3 勾股定理的逆定理

勾股定理反过来也成立，这是**勾股定理的逆定理**：

**若三角形三边满足 $a^2 + b^2 = c^2$，则 $c$ 边所对的角是直角。**

这个逆定理把「数量的平方和」翻译回「位置关系（垂直）」，是判断垂直的代数工具。<span class="marginnote">逆定理的价值：要证明两条线段垂直，不一定要做几何构造，只需量出三边长度验证勾股关系——「用计算代替推理」，这是代数化几何的早期胜利。</span>

进一步地，三边关系还能判断三角形是锐角还是钝角：

- $a^2 + b^2 > c^2$（$c$ 为最大边）→ 锐角三角形；
- $a^2 + b^2 = c^2$ → 直角三角形；
- $a^2 + b^2 < c^2$ → 钝角三角形。

**辨析｜易错点：** 用勾股定理判断形状时，$c$ 必须是**最长边**。若把较短的边当斜边代入，结论会颠倒。例如三边 $3, 4, 6$：最长边是 6，$3^2 + 4^2 = 25 < 36$，所以是钝角三角形——不是锐角三角形。

## 4 勾股定理的应用：距离公式

勾股定理最重要的应用之一，是给出平面两点间的距离公式。设平面上两点 $A(x_1, y_1)$、$B(x_2, y_2)$，作辅助直角三角形：

$$
|AB| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
$$

**重点：** 这个公式把「两点距离」归结为「坐标差的平方和再开方」——它是勾股定理在坐标系里的直接化身，也是第三篇《平面直角坐标系与距离公式》的完整主题。取 $A$ 为原点，$B(x,y)$，就得到点到原点的距离 $|OB| = \sqrt{x^2+y^2}$，这正是单位圆方程 $x^2+y^2=1$ 的来源。

<span class="marginnote">距离公式向高维推广：三维空间两点距离多一个坐标 $\sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}$；$n$ 维欧氏距离则是一般化。机器学习里 K 近邻、聚类都靠它度量「相似性」。</span>

## 5 勾股定理与三角函数的第一座桥

在直角三角形中，勾股定理与三角函数直接相连。设 $\theta$ 为一个锐角，则：

$$\sin\theta = \frac{\text{对边}}{\text{斜边}}, \qquad \cos\theta = \frac{\text{邻边}}{\text{斜边}}$$

把两式平方相加：

$$\sin^2\theta + \cos^2\theta = \frac{a^2}{c^2} + \frac{b^2}{c^2} = \frac{a^2 + b^2}{c^2} = 1$$

这是三角函数里**最重要的一条恒等式**，它直接由勾股定理得来。任何时刻，角 $\theta$ 的正弦与余弦都落在单位圆上——$\cos\theta$ 与 $\sin\theta$ 正是单位圆上点的坐标。<span class="marginnote">$\sin^2\theta + \cos^2\theta = 1$ 是整个三角恒等变换的枢纽：和差角公式、二倍角公式最终都能从它导出。第四篇《同角三角函数关系》会把它系统化。</span>

勾股定理还有一个「历史上最著名」的方面——它引出了数学中最古老也最深刻的问题之一：**费马大定理**。费马在 17 世纪阅读《算术》时，在书边写道：「将一个立方数分成两个立方数之和，是办不到的……我已经发现了真正美妙的证明，可惜页边太窄写不下。」这个问题——方程 $x^n + y^n = z^n$（$n > 2$）没有正整数解——直到 1994 年才被怀尔斯（Andrew Wiles）用远超初等几何的现代数学证明。而它的起点，正是勾股定理的整数解（勾股数）。

勾股数的生成公式值得亲手验证一次：任取正整数 $m > n$，则

$$
m^2 - n^2, \quad 2mn, \quad m^2 + n^2
$$

构成一组勾股数。取 $m = 2, n = 1$：$3, 4, 5$；取 $m = 3, n = 2$：$5, 12, 13$。为什么成立？

$$
(m^2 - n^2)^2 + (2mn)^2 = m^4 - 2m^2n^2 + n^4 + 4m^2n^2 = m^4 + 2m^2n^2 + n^4 = (m^2 + n^2)^2
$$

一个恒等式的两边展开，就证明了整族勾股数的正确性——**代数恒等式在背后「批量生产」几何事实**，这是代数学最令人着迷的地方之一。

<span class="marginnote">勾股定理的逆定理在坐标几何里还有一个推论：两条直线垂直当且仅当它们斜率之积为 $-1$，其证明正是「构造直角三角形用勾股逆定理」。今天你在《直线与圆》里用的垂直判据，根子上仍是这条勾股关系。</span>

勾股定理的证明之多（据说有数百种）本身也是数学史的有趣注脚：欧几里得用面积法，爱因斯坦 12 岁时给出一个用相似三角形的证明，美国总统加菲尔德（James A. Garfield）也给出过梯形面积证法。**同一结论的多种证法，本质是不同视角看同一个事实**——这种「多角度验证」的习惯，在大模型时代同样重要：对同一个结论，用不同的推理路径交叉检验，比单一路径更可靠。

「勾股定理」还有一个「范围判断」的应用——**用三边关系判断三角形的形状**（这个主题在《三角形》一节提过，这里从勾股视角再收束一次）：设 $c$ 为最长边，则

$a^2 + b^2 > c^2$ → 锐角三角形（最大角小于直角）；
$a^2 + b^2 = c^2$ → 直角三角形；
$a^2 + b^2 < c^2$ → 钝角三角形。

「比平方和」是判断形状的代数捷径——它把「看角」变成「算数」，是「几何问题代数化」的又一个例子。

「勾股数」在工程里还有一个实用意义：**用勾股数快速画直角**。木工、瓦工用「3-4-5」法画直角——量出 3 与 4，调整位置使斜边为 5，就是一个精确直角。这个「3-4-5 法则」是勾股定理最古老的实际应用之一，比用量角器更可靠，因为「长度测量」比「角度测量」更精确。

<span class="marginnote">「3-4-5 画直角」在施工放样里沿用千年：直角不是用「量角器量 90°」得到的，而是用「三条长度构成直角三角形」保证的。这印证了「几何的可计算化」——长度关系比角度关系更「硬」。这也是「勾股定理」作为「距离的基石」的最早实践。</span>

最后，「勾股定理」与「三角恒等式」的联结值得再次强调：在单位圆里，$\sin^2\theta + \cos^2\theta = 1$ 就是「圆上点 $(x,y)$ 满足 $x^2 + y^2 = 1$」——勾股定理的代数化身。这条恒等式是整个三角恒等变换的枢纽，而它的根，在勾股定理里。**一条定理，串联几何与三角**——这正是本专题「数形结合」主线的缩影。

## 6 小结

- **勾股定理**：直角三角形中 $a^2 + b^2 = c^2$（$c$ 为斜边）；它是几何到代数的第一座桥。
- **面积证明**：用「大正方形 = 小正方形 + 四个三角形」的等面积法，零计算推出定理。
- **逆定理**：三边满足 $a^2+b^2=c^2$ 则夹角为直角；比较平方和可判断锐角/直角/钝角。
- **距离公式**：$|AB| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$，是勾股定理在坐标系中的化身，将贯穿解析几何。
- **三角恒等式**：$\sin^2\theta + \cos^2\theta = 1$ 直接由勾股定理导出，是三角学的枢纽公式。

在下一节，我们将离开单独的研究对象，研究两条直线的相处方式——**平行线**的性质与判定，它是平行四边形、相似三角形与整个坐标几何的隐含结构。
