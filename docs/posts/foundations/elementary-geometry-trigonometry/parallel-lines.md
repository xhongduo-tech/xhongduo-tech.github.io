# 平行线的性质与判定

## 为什么从平行线开始

两条直线在同一平面内不相交，就叫**平行**。这个朴素的定义看似简单，却是整个几何的结构性骨架：平行四边形、相似三角形、梯形的所有性质都从平行来；坐标几何里「斜率相等的直线平行」是代数化的平行；物理里「平行四边形法则」用平行构造向量合成。更重要的是，平行线背后的**第五公设**（平行公理）曾引发数学史上最深刻的革命——非欧几何由此诞生。从「从极限到大模型」的主线看，平行线是理解「结构不变量」的第一个窗口。

## 1 平行公理与平行线的定义

**平行线（parallel lines）**：在同一平面内，**不相交**的两条直线。记作 $a \parallel b$。

**平行公理**：经过直线外一点，**有且只有一条**直线与已知直线平行。<span class="marginnote">这条公理也叫欧几里得第五公设（等价形式）。历史上数学家们试图证明它却失败了，反而催生了罗巴切夫斯基几何与黎曼几何——「过直线外一点可以作无数条/零条平行线」。平行公理不是「显然的事实」，而是「选择的地基」。</span>

**辨析｜易错点：** 平行必须在**同一平面内**讨论。两条空间中的直线不相交，却不一定平行——它们可能是**异面直线**（不共面也不相交）。「不相交」在立体几何里不再是平行的充分条件，这是第二篇《空间点线面的位置关系》要辨析的重点。

## 2 三线八角：平行线的性质

两条平行线被第三条直线所截，产生八个角，称「三线八角」，其中几组角互为特殊关系：

- **同位角**：位置相同的一对角（如 $\angle 1$ 与 $\angle 5$）；
- **内错角**：两直线内侧、交错位置的一对角（如 $\angle 3$ 与 $\angle 6$）；
- **同旁内角**：两直线内侧、同侧的一对角（如 $\angle 3$ 与 $\angle 5$）。

**平行线的性质（由平行推角相等）**：

- 两直线平行 → **同位角相等**；
- 两直线平行 → **内错角相等**；
- 两直线平行 → **同旁内角互补**（和为 $180^\circ$）。

<span class="marginnote">「平行推角」是性质，「角推平行」是判定，方向恰好相反。记忆法：性质告诉你「因为平行，所以角怎样」；判定告诉你「因为角怎样，所以平行」。</span>

## 3 平行线的判定：从角反推平行

**判定定理（由角的关系推平行）**——它是性质定理的逆命题：

- 同位角相等 → 两直线平行；
- 内错角相等 → 两直线平行；
- 同旁内角互补 → 两直线平行。

<span class="marginnote">还有两个常用判据：平行于同一条直线的两直线平行；垂直于同一条直线的两直线平行。它们让「平行」具有了传递性与同余性——这也提示我们平行关系是一种「等价关系」（见第二级《离散数学》的等价类概念）。</span>

**重点：** 性质与判定是互逆的两套命题，初学者最大的误区是**用性质当判定**。例如「因为同位角相等，所以两直线平行」是对的（判定）；「因为两直线平行，所以同位角相等」也是对的（性质）——但「因为同位角相等，所以……」，必须先确认已知条件到底是「平行」还是「角相等」。

## 4 公式解析：平行线分线段成比例

平行线与三角形结合，产生一条极其有用的比例定理：

在 $\triangle ABC$ 中，$DE \parallel BC$（$D$ 在 $AB$ 上，$E$ 在 $AC$ 上），则：

$$
\frac{AD}{AB} = \frac{AE}{AC} = \frac{DE}{BC}
$$

对这条式子做三步拆解：

- **第一步，看结构**：$DE \parallel BC$ 在三角形里「切」出一个小的 $\triangle ADE$ 与原 $\triangle ABC$ 相似，相似比是 $\frac{AD}{AB}$。
- **第二步，为什么三个比相等**：由平行线的同位角性质，$\angle ADE = \angle ABC$、$\angle AED = \angle ACB$，两角对应相等，故 $\triangle ADE \sim \triangle ABC$，对应边成比例。
- **第三步，迁移到截线**：两条直线被一组平行线所截，所截得的**对应线段成比例**——这是「平行线分线段成比例」的一般形式，梯形、位似、坐标几何的定比分点都从这里来。

<span class="marginnote">这条定理是相似三角形章节的「工作母机」，也直接通向坐标系里的定比分点公式：点 $P$ 分 $AB$ 为 $\lambda$ 比时，$P$ 的坐标由「比例加权」给出。第二级《线性代数》里的仿射组合与之同源。</span>

## 5 平行线的证明举例

把性质与判定合起来用，是几何证明的常规操作。经典例题：已知 $AB \parallel CD$，$EF$ 交 $AB$、$CD$ 于 $E$、$F$，$\angle AEF$ 与 $\angle CFE$ 的角平分线交于 $G$，求证 $\angle EGF = 90^\circ$。

思路拆解：

- **第一步**：由 $AB \parallel CD$，同旁内角 $\angle AEF + \angle CFE = 180^\circ$。
- **第二步**：角平分线把每个角一分为二，所以 $\frac{1}{2}\angle AEF + \frac{1}{2}\angle CFE = 90^\circ$，即 $\angle GEF + \angle GFE = 90^\circ$。
- **第三步**：在 $\triangle EFG$ 中，内角和为 $180^\circ$，故 $\angle EGF = 180^\circ - 90^\circ = 90^\circ$。证毕。

<span class="marginnote">这道题的「合流」很有代表性：平行线提供角度关系，角平分线作恒等变形，三角形内角和收尾——三种工具层层递进。几何证明的节奏感，正是靠这种「每一步用哪条定理」的取舍练出来的。</span>

平行线的概念在「非欧几何」中走向了它的极限。欧几里得第五公设（平行公理）两千年来被视为「不够显然」：许多数学家试图从其它公理证明它，却一再失败。直到 19 世纪，罗巴切夫斯基（Lobachevsky）与鲍耶（Bolyai）大胆地**假设「过直线外一点可以作无数条平行线」**，黎曼（Riemann）则假设「一条也作不出」——结果不但没有矛盾，反而发展出自洽的罗氏几何与黎曼几何。原来平行公理不是「必须成立的事实」，而是「可以选择的公设」。

| 几何体系 | 过直线外一点的平行线数 | 三角形内角和 |
| --- | --- | --- |
| 欧氏几何 | 恰有一条 | $180^\circ$ |
| 罗氏（双曲）几何 | 无数条 | 小于 $180^\circ$ |
| 黎曼（椭圆）几何 | 零条 | 大于 $180^\circ$ |

这张表提示了一个深刻的转变：**「平行」不是绝对的，而是相对于几何体系而言的**。球面几何（黎曼几何的模型）里根本没有平行线——大圆总是相交。这也解释了为什么球面上「三角形内角和大于 $180^\circ$」。

<span class="marginnote">这个思想在今天的地位：爱因斯坦的广义相对论用黎曼几何描述弯曲时空——光线在引力场中「走测地线」，而我们观测到的「空间弯曲」正是黎曼几何的日常表现。从平行公理到宇宙时空，一条公理的选择塑造了整个物理图景。</span>

回到初等几何，平行线还有一个实用的「角色」：它是**平移的几何表达**。把一条直线沿某个方向移动，得到的新直线与原直线平行；反过来，两条平行线可以看作「同一方向」的直线。这个观点与向量（第三篇《平面向量》）直接接轨：方向相同的向量（共线）对应平行直线，方向是「平移」的不变量。

平行线还有一个「实际测量」的应用，它让「平行」从抽象概念变成可用的工具：**利用平行线分线段成比例来测距**。在地面上画一条基线，用平行线的性质把「无法直接量」的距离换算成「可以量」的比例。更常见的是：在地图上，「经纬线是平行线」，地图的网格就是平行线系统，利用比例尺可以在地图上量距离。

平行线在「证明」中的作用还值得再强调——它是「角相等」的制造机：

- 两直线平行 → 同位角相等、内错角相等、同旁内角互补；
- 反过来，角的关系 → 两直线平行；
- 于是「平行」与「角」之间可以来回穿梭，构成证明链的「中转站」。

| 需要什么 | 找什么 | 依据 |
| --- | --- | --- |
| 证角相等 | 找平行线 + 内错角/同位角 | 平行线性质 |
| 证线平行 | 找同位角/内错角相等 | 平行线判定 |
| 证比例 | 找平行线分线段 | 平行线比例定理 |

这张表把「平行 ⇄ 角 ⇄ 比例」的转换路径摆清楚：一个平行关系，可以同时通向角相等与比例相等，是几何证明里最「多面手」的结构。

<span class="marginnote">「平行 ⇄ 角 ⇄ 比例」的三向转换，在解三角形、相似三角形、向量共线里都会反复用到——它是「一条平行线带来一串结论」的源头。几何证明里常说「遇平行想角」，就是这个道理。</span>

最后，「平行」与「方向」的绑定值得一提：平行线是「方向相同」的几何表达，两条平行线共享同一个方向。这个「方向」视角是向量的前奏——向量「共线」就是方向相同或相反，而「平行」正是「共线」的几何名。到第三篇《平面向量》，平行与共线会完全统一。

## 6 小结

- 平行是**同一平面内不相交**；平行公理「过线外一点有且只有一条平行线」是几何的基石，也是非欧几何的起点。
- **三线八角**：同位角、内错角、同旁内角；平行线的性质由「平行」推出「角」的关系。
- **判定定理**由「角」的关系反推「平行」，与性质互为逆命题；注意区分已知是「平行」还是「角」。
- **平行线分线段成比例**：$\frac{AD}{AB} = \frac{AE}{AC} = \frac{DE}{BC}$，是相似、定比分点、梯形问题的公共工具。
