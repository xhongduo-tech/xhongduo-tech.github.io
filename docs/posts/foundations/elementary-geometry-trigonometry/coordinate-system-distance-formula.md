## 为什么从坐标系开始

解析几何的全部思想浓缩在一句话里：**给几何一个坐标系，让图形变成方程**。平面直角坐标系把「点」变成「数对 $(x, y)$」，把「直线」变成「一次方程」，把「圆」变成「二元二次方程」——几何从此可以被代数计算接管。坐标系不是「画格子」的工具，而是一种「翻译协议」：左边是图形直觉，右边是方程运算，中间是坐标。从「从极限到大模型」的主线看，坐标系是函数图像、向量、微积分共同的地基，也是机器学习里「数据点在高维空间」的起点。

## 1 平面直角坐标系：给平面命名

**平面直角坐标系**：在平面上取两条互相垂直、原点重合的数轴——水平的叫**横轴（$x$ 轴）**，竖直的叫**纵轴（$y$ 轴）**，交点叫**原点（origin）** $O$。两轴把平面分成四个**象限**，从右上起逆时针编号为第一、二、三、四象限。

平面上任意一点 $P$，可以唯一写成有序数对 $(x, y)$：$x$ 是 $P$ 到 $y$ 轴的（有向）距离，$y$ 是 $P$ 到 $x$ 轴的（有向）距离。<span class="marginnote">「有向距离」的意思是带符号：$x$ 可以为负，负号表示在 $y$ 轴左侧。正是这种「带符号」，让坐标能区分位置而不仅是距离。</span>

**重点：** 坐标系的本质是「**一一对应**」：平面上的点 ↔ 有序实数对。这个一一对应是第一级《集合》里「映射」思想的实例——平面是点集，坐标是它的另一种编号方式。由此，集合语言与图形语言首次完全打通。

## 2 数轴上点的距离与中点

从一维开始预热。数轴上两点 $A(x_1)$、$B(x_2)$：

- **距离**：$|AB| = |x_2 - x_1|$；
- **中点坐标**：$M$ 的坐标为 $\frac{x_1 + x_2}{2}$。

「减绝对值」是距离，「取平均」是中点——这两个操作是一维的基准，接下来全部推广到二维。<span class="marginnote">中点公式的直觉：$x_1$ 与 $x_2$ 的「正中间」就是它们的平均值。这个「取平均」在二维、三维、$n$ 维都照搬，是「重心」「质心」概念的源头。</span>

## 3 公式解析：两点间距离公式

平面上两点 $A(x_1, y_1)$、$B(x_2, y_2)$ 的距离，由**勾股定理**给出：

$$
|AB| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
$$

对这条核心公式做三步拆解：

- **第一步，作辅助三角形**：过 $A$ 作水平线、过 $B$ 作竖直线，交于 $C$。则 $AC = |x_2 - x_1|$，$BC = |y_2 - y_1|$，$\triangle ABC$ 是直角三角形。
- **第二步，套勾股定理**：斜边 $AB$ 的平方 = 两直角边的平方和，即 $|AB|^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2$。
- **第三步，开方取正**：距离非负，两边开平方得公式。当 $A$ 是原点时，$|AB| = \sqrt{x_2^2 + y_2^2}$——**点到原点的距离就是坐标的「长度」**。

**重点：** 距离公式是勾股定理在坐标系中的化身。它把「几何距离」变成「代数计算」，后续直线方程、圆方程、向量模长全都建立在这条公式上。<span class="marginnote">这个公式向三维推广只需加一项：$|AB| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$。向 $n$ 维推广就是欧氏距离，机器学习里衡量「两个数据点有多像」的标准度量。</span>

## 4 公式解析：中点坐标公式

两点 $A(x_1, y_1)$、$B(x_2, y_2)$ 的中点 $M$：

$$
M\!\left(\frac{x_1 + x_2}{2},\; \frac{y_1 + y_2}{2}\right)
$$

拆解三步：

- **第一步，按坐标拆开**：中点的横坐标由两点的横坐标决定，纵坐标由两点的纵坐标决定——两个方向互不干扰，这是直角坐标系的「正交分离」。
- **第二步，一维推广**：横方向上，$M$ 的横坐标就是数轴上两点 $x_1$、$x_2$ 的中点 $\frac{x_1+x_2}{2}$；纵方向同理。
- **第三步，几何意义**：中点就是「两点的重心」，也是「线段的平均位置」。线段上距 $A$ 为 $t$ 倍的点有公式 $P = (1-t)A + tB$，$t = \frac{1}{2}$ 时正是中点。

<span class="marginnote">中点公式是「向量定比分点」的特殊情形。一般地，线段 $AB$ 上满足 $\frac{AP}{PB} = \lambda$ 的点 $P$ 的坐标是 $\left(\frac{x_1+\lambda x_2}{1+\lambda}, \frac{y_1+\lambda y_2}{1+\lambda}\right)$。这个「加权平均」的思想在重心、插值、采样里无处不在。</span>

## 5 坐标法的解题范式

坐标系带来的不只是公式，而是一种新的解题方法——**坐标法（解析法）**：

1. **建系**：选择方便的位置建立直角坐标系（常让尽量多的已知点落在轴上）；
2. **翻译**：把几何条件写成坐标与方程；
3. **计算**：用代数运算（距离、斜率、联立方程）求解；
4. **还原**：把代数结果翻译回几何结论。

经典例子：证明「平行四边形对角线互相平分」。建系设 $A(0,0)$、$B(a,0)$、$D(b,c)$，则 $C(a+b, c)$。两条对角线的中点分别是 $\left(\frac{a+b}{2}, \frac{c}{2}\right)$ 与 $\left(\frac{a+b}{2}, \frac{c}{2}\right)$——完全重合，证毕。<span class="marginnote">这个证明完全没有「辅助线」——只有坐标代入。坐标法的优势正是可程序化：建系、设点、代入、化简，每一步都机械可验。它把「灵感的几何」变成「可靠的算术」。</span>

## 6 坐标与更广阔的世界

平面直角坐标系只是一个开始，它的思想会一路延伸：

- **空间直角坐标系**：加一条 $z$ 轴，点变成 $(x, y, z)$（第二篇已用）；
- **函数图像**：$y = f(x)$ 的图像就是满足方程的点的集合——函数与曲线合流；
- **向量坐标**：向量写成分量 $(x, y)$，几何运算全部代数化（第二篇《空间向量与立体几何》）；
- **数据科学**：机器学习里每个样本是一个「高维点」，特征就是坐标——「点」的语言在 $n$ 维空间继续发光。

<span class="marginnote">笛卡尔 1637 年在《几何学》中提出坐标系，被誉为「解析几何之父」。他让代数与几何合流，也奠定了现代数学「用结构统一对象」的范式。我们今天看坐标习以为常，但它是数学史上一次真正的范式革命。</span>

坐标系的建立还带来一个「坐标几何」的基本原则：**几何量应当能由坐标算出来，而不应依赖画图**。这是解析几何与综合几何的分水岭——距离、中点、斜率、夹角全部有坐标公式，「看图形猜答案」被「算坐标得答案」取代。这套「算」的语言，是笛卡尔留给数学最持久的遗产。

用坐标法可以重新「证明」一大批平面几何定理，这里举一个漂亮的例子：**用坐标证明「平行四边形的对角线互相平分」的完整过程**——

- 设 $A(0,0)$、$B(a,0)$、$D(b,c)$，则 $C(a+b, c)$（平行四边形的对边平行且相等）；
- $AC$ 的中点 $M_1 = \left(\frac{a+b}{2}, \frac{c}{2}\right)$，$BD$ 的中点 $M_2 = \left(\frac{a+b}{2}, \frac{c}{2}\right)$；
- 两中点重合，故对角线互相平分。证毕。

整个证明只有两步坐标代入，没有任何辅助线。这种「设坐标 → 代入公式 → 直接得出结论」的流程，是坐标法的标准范式。

<span class="marginnote">坐标法的代价也值得说清楚：它把「洞察」换成了「计算」——图形结构越复杂，坐标计算越繁琐，但在「找思路」层面几乎不需要灵感。现代计算机辅助几何证明（如坐标法自动证明系统）正是利用了「坐标法可程序化」这一特性。</span>

再谈坐标系的「选择自由度」：原点与坐标轴的方向可以任意选择，同一几何对象在不同坐标系下的坐标不同，但几何性质（距离、中点、平行、垂直）不变。**「坐标是相对的，几何是绝对的」**——这个观念在物理里对应「参考系的选择不影响物理规律」，是「坐标变换」「不变量」思想的源头。

最后预告一下：这套「用坐标算几何」的方法，下一步将产生直线的方程、圆的方程、圆锥曲线的方程——**几何对象全部变成方程**，这就是第三篇解析几何的完整图景，也是函数图像、乃至机器学习「数据点」空间的共同基础。

坐标系还有一个「分割」的用途，它把「连续」与「离散」连接起来：**把平面划分成网格，让几何问题变成「数格子」的问题**。计算不规则图形的面积时，可以用「网格逼近」——数完整的小方格，加上边界处近似——这是「以直代曲」的朴素版本，也是数值积分（第二级《数值分析》）的最早直觉。

「数格子」的方法在历史上有一个著名应用：**蒙特卡洛方法的思想预演**。往一个已知面积的正方形里随机撒点，统计落在目标图形内的点数比例，就能估计图形的面积——点数越多，估计越准。虽然中学阶段不学随机方法，但这个「用计数代替测量」的思路，与网格法一脉相承。

| 方法 | 原理 | 精度 | 现代对应 |
| --- | --- | --- | --- |
| 网格法 | 数完整格子 | 取决于网格粗细 | 数值积分（矩形法） |
| 割补法 | 拼成规则图形 | 精确 | 积分 |
| 蒙特卡洛 | 随机撒点计数 | 统计误差 | 随机模拟 |
| 解析法 | 定积分 | 精确 | 微积分 |

这张表展示了「求面积」从初等到高等的演进：网格法、割补法是初等武器，积分与随机方法是高等武器。它们的共同点是——**把一个复杂的「面积」问题，拆成许多简单的「单元」求和**。

<span class="marginnote">「分割 → 求和 → 取极限」正是定积分的三步。你在「数格子」里建立的直觉——格子越细越精确——就是「黎曼和」的雏形。到第二级《高等数学》，「网格无限细分」会变成极限语言，而坐标系正是这一切的舞台。</span>

最后，坐标系还赋予「位置」一种「可计算」的度量：有了坐标，「两个点有多远」「两条线是否平行」「一个图形是否对称」，全都能用坐标算出来。**「几何量的可计算化」是坐标系最深刻的贡献**——它让几何从「视觉的艺术」变成「算术的科学」，这是笛卡尔革命的核心。

## 7 小结

- 平面直角坐标系建立**点 ↔ 有序实数对**的一一对应；原点、两轴、四象限构成基本框架。
- 一维基准：距离 $|x_2-x_1|$、中点 $\frac{x_1+x_2}{2}$。
- **两点距离公式** $|AB| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$，是勾股定理在坐标系中的化身。
- **中点公式** $M(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2})$，是定比分点与「取平均」的特殊情形。
- 坐标法流程：**建系 → 翻译 → 计算 → 还原**，把几何证明变成可程序化的代数。
