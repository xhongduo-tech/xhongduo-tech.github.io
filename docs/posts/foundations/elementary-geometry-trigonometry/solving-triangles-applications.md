## 为什么从解三角形应用开始

正弦定理与余弦定理不是纸上的公式，而是测量学的引擎：**塔有多高？河有多宽？船离岸多远？** 这些问题无法直接量出答案（够不着、过不去），但可以在可及的位置测量**角度**，再用三角函数算出不可及的距离。这一节就是「实际问题 → 建三角形 → 解三角形」的完整训练，也是三角学诞生两千多年的初心——从测金字塔到 GPS 定位，原理从未改变。从「从极限到大模型」的主线看，这是「用数学建模解决现实问题」的第一次完整演练。

## 1 测量模型：仰角、俯角与方位角

把现实问题翻译成三角形，先要掌握三个「角」：

- **仰角**：视线在水平线上方时，视线与水平线的夹角；
- **俯角**：视线在水平线下方时，视线与水平线的夹角；
- **方位角**：从正北方向顺时针转到目标方向线的水平角（$0^\circ \sim 360^\circ$）。

<span class="marginnote">「仰角 = 俯角」当视线经过同一点时数值相等（内错角）。画示意图时，水平线、视线、竖直方向构成直角三角形或斜三角形，解三角形就开始了。测量问题的第一步永远是「画好图、标好角」。</span>

**辨析｜易错点：** 仰角与俯角都是以**水平线**为基准，不是以地面为基准；方位角从**正北**起顺时针量，不是正东。角度基准搞错，整个三角形就画错了——先明确基准，再动笔。

## 2 测量高度：塔高与山高

典型问题：测量塔高。在塔底正前方水平距离 $d$ 处测仰角 $\alpha$，则塔高：

$$
h = d\tan\alpha
$$

更复杂的「两次测量」模型：在塔两侧（或沿直线移动）测两个仰角 $\alpha$、$\beta$，设两次测点相距 $l$，则塔高 $h$ 满足（设塔底到较近测点距离为 $x$）：

$$
\begin{cases} h = x\tan\beta \\ h = (x + l)\tan\alpha \end{cases}
$$

解这个方程组即可得到 $h$ 与 $x$。

**重点：** 「两次测量」的核心是**建立方程组**——把未知量（塔高、距离）作为变量，把两次测得的仰角作为条件，联立求解。这是「用冗余测量消去未知中间量」的经典手法。<span class="marginnote">这个「多测一次，就能多解一个未知数」的思路，正是测量的基本逻辑：一个仰角给一条方程，两个未知数就需要两次测量。与解三角形「已知足够条件就能解」一脉相承。</span>

## 3 公式解析：测量不可及距离

河对岸有目标 $A$（不可到达），在河这边取两点 $B$、$C$，测得 $BC = l$，$\angle ABC = \alpha$，$\angle ACB = \beta$，求河宽。

- **第一步，画三角形**：$A$、$B$、$C$ 构成 $\triangle ABC$，已知 $l$（边）与 $\alpha$、$\beta$（两角），是「两角一边」情形。
- **第二步，正弦定理求 $AB$**：$\angle A = 180^\circ - \alpha - \beta$，由正弦定理 $\frac{AB}{\sin\beta} = \frac{l}{\sin A}$，得 $AB = \frac{l\sin\beta}{\sin(\alpha+\beta)}$。
- **第三步，作高求河宽**：过 $A$ 作 $BC$ 的高，河宽 $d = AB\sin\alpha = \frac{l\sin\beta\sin\alpha}{\sin(\alpha+\beta)}$。

<span class="marginnote">「两步走」的结构很清晰：先用正弦定理求斜边，再作高得垂直距离。很多测量问题都是这个套路——「先解三角形得一条边，再用三角函数得需要的量」。这与你以后用「先求参数再算目标」的建模思路完全一致。</span>

## 4 航海与定位：方位角模型

航海问题把测量搬到海面：船在 $B$ 点测灯塔 $A$ 的方位角，航行一段距离后再测，求船与灯塔的距离。

标准模型：船从 $B$ 沿正北航行 $l$ 到 $C$，在 $B$、$C$ 分别测得灯塔 $A$ 的方位角为 $\alpha$、$\beta$，则在 $\triangle ABC$ 中，$\angle ABC$ 与 $\angle ACB$ 可由方位角之差得出，再用正弦定理求 $AC$ 或 $AB$。

**重点：** 这类题的关键是**把方位角转成三角形内角**。两方位角之差常等于某个内角（平行线内错角/同位角），画图时把南北线画成平行线，角的转换一目了然。<span class="marginnote">「方位角 → 内角」的转换是航海题的灵魂：南北线互相平行，用平行线的内错角、同位角把方位角搬进三角形。这又一次用到了第一篇《平行线的性质与判定》。</span>

## 5 从测量到现代定位

解三角形应用是「测距定位」的古典形态，它的现代继承者无处不在：

- **三角测量（triangulation）**：大地测量中，从两个已知点测目标方向，交会出目标位置——原理就是「两角一边」；
- **GPS 定位**：卫星测距离（测距定位），至少四颗卫星的「测距方程」解出位置——从三角形到三维空间的推广；
- **声呐/雷达测距**：测回波时间得距离，配合方向角定位；
- **射电干涉**：天文学用多个天线测量同一天体的方向差，重建射电图像。

<span class="marginnote">GPS 的原理与本节「两次测量」同构：每颗卫星广播位置与时间，接收机算出到每颗卫星的距离，多个「距离已知」的方程联立解出自己的位置——只是从平面三角形升级到三维球面/椭球几何。从金字塔测量到卫星定位，数学的骨架从未变过。</span>

解三角形应用还有一个「误差意识」的问题值得建立：测量总是有误差的，而**角度误差对距离估计的影响随着目标变远而放大**——「差之毫厘，失之千里」。所以大地测量用「基线」方法：先量一段较短的、可达的基线，再通过精密测角，把「角度 → 距离」的换算交给正弦定理完成，尽量减少对「直接量长距离」的依赖。

| 测量手段 | 直接量 | 间接算 | 误差特点 |
| --- | --- | --- | --- |
| 测高 | 仰角 | 塔高 | 角度误差放大 |
| 测宽 | 两角 + 基线 | 河宽 | 基线越长越准 |
| 定位 | 方位角 × 2 | 位置 | 交会角太小不准 |
| 三角网 | 全测角 | 全网坐标 | 冗余校验 |

这张表揭示了一个「测量学」的核心思想：**能量短的（基线）就量短的，能测角的就测角，用几何把长距离/高高度「算」出来**。这不仅节省测量成本，也提高精度——因为「角度测量」的精度可以做得比「长度测量」更高。

<span class="marginnote">「基线 + 测角 + 三角计算」正是大地测量学（测地学）的骨架：一个国家的国土测绘，就是先布设三角网（测量全网的角），再配合少量精确的基线，用正弦定理把整个网的坐标「算」出来。今天的卫星大地测量（GNSS）虽然改用「测距」原理，但「用少量精确量推大量未知量」的思想依然不变。</span>

解三角形应用题还有一个「建模型」的通用流程，值得总结成可复制的模板：

1. **审题画图**：把文字翻译成示意图，标出已知量与未知量；
2. **构三角形**：把要算的量放进一个「可解的三角形」里（已知条件够的）；
3. **选定理**：按「角多用正弦、边多用余弦」选择正弦或余弦定理；
4. **解算**：执行计算，注意单位与角度制统一；
5. **检验**：检查结果是否符合现实（距离不为负、角在合理范围）。

这套「审题 → 构图 → 选法 → 解算 → 检验」的流程，与解任何应用题的流程一致——**数学建模的「五步法」从这里就开始了**，它会在物理、统计、机器学习里以更复杂的形式反复出现。

最后，解三角形应用的「测距」本质与「定位」思想连接：已知一个三角形的三要素（如两角夹边），就能求出全部边角——**三角形的「三要素定形」性质，让「少测多算」成为可能**。这是三角测量（triangulation）的原理，也是 GPS、雷达、声呐共用的数学底座。

解三角形应用还有一个「最值」方向的题型值得补充——**在三角形中求某条边或某个角的最值**。典型例子：在 $\triangle ABC$ 中，$\angle A$ 固定、$BC$ 边固定，求 $\triangle ABC$ 面积的最大值。解法是用正弦定理把面积写成某角的正弦函数，再用「正弦函数的值域」求最值。

完整流程演示：设 $\angle A = \alpha$ 固定，$BC = a$ 固定，由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$，面积

$$
S = \frac{1}{2}bc\sin A = \frac{a^2 \sin B \sin C}{2\sin^2 A}
$$

而 $\sin B \sin C = \frac{\cos(B-C) - \cos(B+C)}{2} = \frac{\cos(B-C) + \cos A}{2}$。要 $S$ 最大，就令 $\cos(B-C)$ 最大（取 $1$），即 $B = C$。所以「**底边固定、顶角固定时，等腰三角形面积最大**」——一个漂亮的结论，由正弦定理 + 积化和差推出来。

| 条件 | 最值结论 | 关键工具 |
| --- | --- | --- |
| 底边与顶角固定 | $B = C$ 时面积最大 | 积化和差 + 余弦有界 |
| 周长固定 | 等边三角形面积最大 | 海伦公式 / 均值不等式 |
| 两边固定 | 夹角 $90^\circ$ 时面积最大 | $S = \frac{1}{2}ab\sin C$ |

「三角形最值」问题把解三角形与「函数最值」合流：**先把目标量写成角的函数，再用三角函数的性质求最值**。这与「用导数求函数最值」是同一思路的三角版本。

<span class="marginnote">「等周效应」在这里再次出现：周长固定时等边三角形面积最大，底边顶角固定时等腰面积最大——「对称」似乎总是「最优」。这类「对称即最优」的直觉在物理（最小能量）、优化（最优控制）里反复被验证，但也需要在每个具体问题里小心求证。</span>

最后，解三角形与「向量」的联结值得一提：正弦定理、余弦定理都可以用向量内积重新证明——余弦定理 $a^2 = b^2 + c^2 - 2bc\cos A$ 正是「$\vec{a} = \vec{b} - \vec{c}$ 两边平方」的结果。到第三篇《平面向量》，你会看到解三角形的公式在向量语言里变得「不过是模长运算」。

## 6 小结

- 测量三要素：**仰角、俯角、方位角**——画图时基准要分清（水平线/正北）。
- 测高问题：一个仰角用 $h = d\tan\alpha$，两次测量用**方程组**消去未知中间量。
- 测不可及距离：两角一边 → 正弦定理求斜边 → 作高求垂直距离，两步走。
- 航海定位：把**方位角转成三角形内角**，再解三角形。
- 解三角形应用是**三角测量**的古典形态，原理延伸到 GPS、雷达与射电天文。
