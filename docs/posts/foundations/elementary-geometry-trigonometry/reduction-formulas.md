# 诱导公式

<div class="epigraph">

## 为什么从诱导公式开始

给定一个任意角，比如 $750^\circ$ 或 $-\frac{5\pi}{3}$，怎样求它的三角函数值？**诱导公式**（reduction formulas）就是答案：它把任意角的三角函数，「诱导」回锐角的三角函数——只要会算 $30^\circ$、$45^\circ$、$60^\circ$，就几乎能算一切特殊角。诱导公式一共有好几组，但它们的本质是**对称性**：单位圆的轴对称与中心对称，对应三角函数值的变号与取反。从「从极限到大模型」的主线看，诱导公式是「周期性 + 对称性」的第一次系统应用。

## 1 一组公式，一个口诀

诱导公式常用 6 组，覆盖 $-\alpha$、$\pi \pm \alpha$、$2\pi \pm \alpha$、$\frac{\pi}{2} \pm \alpha$、$\frac{3\pi}{2} \pm \alpha$。核心规则可以浓缩成口诀：

**「奇变偶不变，符号看象限」**

这句口诀是记忆诱导公式的金钥匙，拆开看：

- **奇变偶不变**：若加的是 $\frac{\pi}{2}$ 的奇数倍（如 $\frac{\pi}{2} \pm \alpha$、$\frac{3\pi}{2} \pm \alpha$），则 $\sin \leftrightarrow \cos$ 互换（名变）；若加的是 $\pi$ 的整数倍，函数名不变。
- **符号看象限**：把 $\alpha$ 看作锐角，判断原角所在象限，取原函数在该象限的符号。

<span class="marginnote">口诀的来历：诱导公式的推导靠单位圆的对称性——关于 $x$ 轴、$y$ 轴、原点对称时坐标如何变号，正是「符号看象限」；$\frac{\pi}{2}$ 倍旋转让横纵坐标互换，正是「奇变偶不变」。</span>

## 2 公式解析：几组核心诱导公式

以 $\sin$ 为例，最常用的几组诱导公式：

$$
\begin{aligned}
\sin(-\alpha) &= -\sin\alpha, & \sin(\pi - \alpha) &= \sin\alpha, \\
\sin(\pi + \alpha) &= -\sin\alpha, & \sin(2\pi - \alpha) &= -\sin\alpha
\end{aligned}
$$

对第一组 $\sin(-\alpha) = -\sin\alpha$ 做三步拆解：

- **第一步，几何含义**：$-\alpha$ 与 $\alpha$ 的终边关于 $x$ 轴对称（一个逆时针转 $\alpha$，一个顺时针转 $\alpha$），纵坐标互为相反数。
- **第二步，坐标翻译**：$\sin(-\alpha)$ 是 $- \alpha$ 终边交点的纵坐标，等于 $\alpha$ 交点纵坐标的相反数，即 $-\sin\alpha$。
- **第三步，这就是奇偶性**：$\sin$ 是奇函数。同理 $\cos(-\alpha) = \cos\alpha$（偶函数），$\tan(-\alpha) = -\tan\alpha$。

其余各组的推导完全同构：找到两个终边的对称关系（关于 $y$ 轴、原点、$x$ 轴对称），写出坐标变化，就得到公式。<span class="marginnote">与其背公式，不如<strong>画单位圆找对称</strong>：$\pi - \alpha$ 与 $\alpha$ 关于 $y$ 轴对称（横坐标变号、纵坐标不变），所以 $\sin(\pi - \alpha) = \sin\alpha$、$\cos(\pi - \alpha) = -\cos\alpha$。每次用对称性推，永远不会错。</span>

## 3 公式解析：$\frac{\pi}{2} \pm \alpha$ 的「变名」

$\frac{\pi}{2} \pm \alpha$ 这组诱导公式比较特殊——函数名要变：

$$
\sin\left(\frac{\pi}{2} - \alpha\right) = \cos\alpha, \qquad
\sin\left(\frac{\pi}{2} + \alpha\right) = \cos\alpha
$$

对第一条做三步拆解：

- **第一步，几何直觉**：$\frac{\pi}{2} - \alpha$ 是「$\frac{\pi}{2}$ 的余角」——一个角与它的余角的 $\sin$ 和 $\cos$ 互换。在直角三角形里：$\sin(\frac{\pi}{2} - \alpha) = \cos\alpha$ 是「对边变邻边」。
- **第二步，单位圆验证**：$\frac{\pi}{2} - \alpha$ 的终边与 $\alpha$ 的终边关于直线 $y = x$ 对称，横纵坐标互换：$(\cos\alpha, \sin\alpha) \to (\sin\alpha, \cos\alpha)$，所以它的纵坐标 $\sin(\frac{\pi}{2} - \alpha) = \cos\alpha$。
- **第三步，符号再看象限**：$\frac{\pi}{2} + \alpha$ 把 $\alpha$（视为锐角）转进第二象限，$\sin$ 为正，所以 $\sin(\frac{\pi}{2} + \alpha) = \cos\alpha$ 也成立。

<span class="marginnote">「关于 $y = x$ 对称 → 横纵坐标互换」是一个很优雅的事实：它说明「变名」的本质是坐标交换。这条对称轴还会在反三角函数、矩阵转置（第二级《线性代数》）里反复出现。</span>

## 4 诱导公式的应用流程

用诱导公式求任意角三角函数值的标准流程：

1. **去整周**：把角减去 $2\pi$（或 $360^\circ$）的整数倍，化为 $[0, 2\pi)$ 内的角；
2. **负角化正**：若为负角，用 $\sin(-\alpha) = -\sin\alpha$ 等去负号；
3. **化到锐角**：用 $\pi \pm \alpha$、$\frac{\pi}{2} \pm \alpha$ 等把角化到 $(0, \frac{\pi}{2})$；
4. **查表求值**：用特殊角的三角函数值直接写出。

例：求 $\sin\left(-\frac{7\pi}{6}\right)$。

先变号：$\sin\left(-\frac{7\pi}{6}\right) = -\sin\frac{7\pi}{6}$；
再化角：$\frac{7\pi}{6} = \pi + \frac{\pi}{6}$，$\sin(\pi + \frac{\pi}{6}) = -\sin\frac{\pi}{6} = -\frac{1}{2}$；
合起来：$-\sin\frac{7\pi}{6} = \frac{1}{2}$。

<span class="marginnote">流程的每一步都对应一组诱导公式，走完整条流水线，任意角就归化到锐角。这个「不断降级」的策略，与算法里的「递归化归」同构——把大问题一步步变成已知的小问题，正是计算机科学解决问题的核心范式。</span>

**辨析｜易错点：** 化角时「先变号还是先化角」要按流程来，最容易错的是符号：$\sin(\pi + \alpha) = -\sin\alpha$ 的负号不能丢。建议每次都用「把 $\alpha$ 看成锐角 → 看 $\pi + \alpha$ 在第几象限 → 决定符号」的完整判断，不要凭记忆跳步。

## 5 诱导公式与周期性、对称性

诱导公式不是孤立的 6 组公式，而是两个基本性质的展开：

**周期性**：$\sin(\theta + 2\pi) = \sin\theta$（转一圈重复）——这是「去整周」的依据；
**对称性**：$\sin(\pi - \theta) = \sin\theta$（关于 $y$ 轴对称）、$\sin(-\theta) = -\sin\theta$（关于 $x$ 轴对称）、$\sin(\pi + \theta) = -\sin\theta$（中心对称）。

<span class="marginnote">这三条对称性恰好对应圆的三个对称变换：左右翻折、上下翻折、中心旋转。诱导公式的「记忆负担」被对称性消解了——理解了圆，就理解了一整张公式表。下一节《三角函数的图像与性质》会从图像上再次看到这些对称。</span>

诱导公式的「化归」思想还有一个更广的应用——它不只是「把任意角化锐角」，而是「**把未知化已知**」的一般策略：未知的角化到已知的特殊角，未知的函数化到已知的函数，未知的象限化到第一象限。这个「化归」原则是数学解题的通用纲领，三角函数只是它的一个舞台。

| 诱导公式组 | 角度变换 | 核心作用 |
| --- | --- | --- |
| $-\alpha$ | 负角化正 | 去负号 |
| $\pi \pm \alpha$ | 化到 $(0, \pi)$ | 去平角 |
| $2\pi \pm \alpha$ | 化到 $(0, 2\pi)$ | 去整周 |
| $\frac{\pi}{2} \pm \alpha$ | 化到 $(0, \frac{\pi}{2})$ | 变名 |

这张表展示了「诱导公式」的全貌：每一组负责一种「角度操作」，合起来完成「任意角 → 锐角」的完整化归。记忆的关键不是背每一组的公式，而是理解每组公式在「化归流程」里承担的角色。

<span class="marginnote">「化归」与「递归」是同一思想的两个名字：把大问题一步步变成小问题，直到变成「已知解」的基准情形。诱导公式的「去整周 → 去负号 → 化锐角」三步，与递归里的「归约 + 基准情形」完全同构——这是数学与计算机科学共享的方法论。</span>

还有一个「实战」提醒：诱导公式最常出错的地方是「$\frac{\pi}{2} \pm \alpha$ 组的符号」——因为变名（$\sin \leftrightarrow \cos$）让人手忙脚乱。稳妥的做法是**始终把 $\alpha$ 当作锐角来判断象限**，哪怕 $\alpha$ 实际不是锐角：符号只取决于「$\alpha$ 取锐角时原角所在象限」，与 $\alpha$ 的真实大小无关。这是口诀「符号看象限」的正确打开方式。

最后，诱导公式与「对称性」的关系值得再回味：$\sin(\pi - \theta) = \sin\theta$ 对应图像关于 $y$ 轴对称，$\sin(\pi + \theta) = -\sin\theta$ 对应中心对称，$\sin(-\theta) = -\sin\theta$ 对应奇函数性质。**每一组诱导公式都是一条对称性**——理解了对称，就理解了整张公式表，甚至可以现场推导而不必背诵。

## 6 小结

- 诱导公式把任意角的三角函数化归为**锐角**三角函数，核心口诀「**奇变偶不变，符号看象限**」。
- 推导靠单位圆的**对称性**：关于 $x$ 轴、$y$ 轴、原点的对称对应变号，关于 $y = x$ 的对称对应 $\sin \leftrightarrow \cos$ 变名。
- 应用流程：**去整周 → 负角化正 → 化到锐角 → 查表求值**。
- 诱导公式 = 周期性 + 对称性的展开；画单位圆找对称，永不记错。
