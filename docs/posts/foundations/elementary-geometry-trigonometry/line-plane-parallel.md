## 为什么从直线与平面平行开始

在平面里，「两直线平行」我们已经很熟；到了空间，「直线与平面平行」成了新的基本关系。它看似抽象，却是空间结构的主角：长方体的棱与面、桌腿与地面、楼层平面与地面，处处是线面平行。这一节给出它的**判定定理**与**性质定理**——一个负责「证明线面平行」，一个负责「从线面平行推出新结论」，两者配合才能让证明闭环。从「从极限到大模型」的主线看，线面平行是「向量共面」的几何版本，也是后续空间向量解题的先声。

## 1 线面平行的判定定理

**线面平行的判定定理**：如果平面外一条直线与平面内的一条直线平行，那么这条直线与这个平面平行。

用符号语言：若 $a \not\subset \alpha$、$b \subset \alpha$ 且 $a \parallel b$，则 $a \parallel \alpha$。

<span class="marginnote">两个前提缺一不可：$a$ 必须在平面外（否则它可能在面内），$b$ 必须在平面内（否则「面内找平行线」落空）。判断时先确认这两条，再谈平行。</span>

证明思路（反证法）：假设 $a$ 与 $\alpha$ 相交于一点 $P$。由于 $a \parallel b$，直线 $a$ 与 $b$ 确定一个平面 $\beta$，且 $\alpha$ 与 $\beta$ 交于过 $P$ 的一条直线 $b'$。但 $b'$ 与 $b$ 都是过 $P$ 且在 $\alpha$ 内的……这里用「两平面交线」与「唯一性」推出矛盾，从而 $a$ 与 $\alpha$ 不可能相交。

**重点：** 判定定理的操作意义是：**要证明线面平行，只需在平面内找一条与它平行的直线**。「找线」常常需要作辅助平面或借助中位线、平行四边形等结构。

## 2 线面平行的性质定理

**线面平行的性质定理**：如果一条直线和一个平面平行，那么经过这条直线的平面与已知平面相交，交线与这条直线平行。

用符号语言：若 $a \parallel \alpha$，$a \subset \beta$，$\alpha \cap \beta = b$，则 $a \parallel b$。

<span class="marginnote">性质定理解决「已知线面平行，能得到什么新结论」：它把「线与面平行」转化为「线与交线平行」，从而可以继续用平面几何的比例、平行判定。这个「降维」操作是立体几何证明的常青技巧。</span>

**辨析｜易错点：** 由 $a \parallel \alpha$ 不能直接推出「$a$ 平行于 $\alpha$ 内的任意直线」——平面内与 $a$ 异面或相交的直线多的是。性质定理强调的「交线」，是「经过 $a$ 的平面与 $\alpha$ 的交线」，一条特定的直线，不是任意直线。

## 3 公式解析：中位线法证明线面平行

把判定定理用在具体问题上，最常见的手法之一是「构造中位线」。典型例题：在四棱锥 $P-ABCD$ 中，$M$ 是棱 $PC$ 的中点，求证 $PA \parallel$ 平面 $MBD$。

完整推理链条：

**第一步，观察目标**：要证 $PA \parallel$ 平面 $MBD$，按判定定理，需要在平面 $MBD$ 内找一条与 $PA$ 平行的直线。
**第二步，构造辅助线**：连接 $AC$ 交 $BD$ 于 $O$。在 $\triangle PAC$ 中，$O$ 是 $AC$ 的中点（平行四边形的对角线互相平分），$M$ 是 $PC$ 的中点，所以 $OM$ 是 $\triangle PAC$ 的中位线。
**第三步，结论**：由中位线定理，$OM \parallel PA$；又 $OM \subset$ 平面 $MBD$，且 $PA$ 不在该平面内，故 $PA \parallel$ 平面 $MBD$。证毕。

<span class="marginnote">这套「中点 → 中位线 → 线线平行 → 线面平行」的链式推理是考试与课本的高频套路。它的本质是：把「找平行线」的目标，转交给「三角形的中位线」，后者由中点条件自动提供。类似地，平行四边形、梯形中位线也是常见供给源。</span>

## 4 线面平行与比例、与向量

线面平行和平面几何的「平行线分线段成比例」直接呼应：若一条直线与平面平行，任何过该直线的平面与已知平面相交，交线都与之平行——于是涉及的线段比例关系可延续使用。

更进一步，用向量语言看线面平行：设直线 $a$ 的方向向量为 $\vec{u}$，平面 $\alpha$ 的法向量为 $\vec{n}$，则

$$
a \parallel \alpha \;\; \Longleftrightarrow \;\; \vec{u} \perp \vec{n} \;\; (\text{且 } a \text{ 不在 } \alpha \text{ 内})
$$

即**线面平行等价于方向向量与法向量垂直**。<span class="marginnote">这是第二篇《空间向量与立体几何》的核心预告：一旦有了向量，位置关系全部变成「内积是否为零」的代数计算。几何证明的「找线」直觉，会被「算内积」的程序化操作取代——但直觉仍然是判断辅助线、检验结果的第一助手。</span>

## 5 平行关系的传递与组合

线面平行可以与其它平行关系组合出更复杂的结构：

**线线平行 → 线面平行**：判定定理（本节）；
**线面平行 → 线线平行**：性质定理（本节）；
**面面平行 → 线面平行**：若 $\alpha \parallel \beta$，则 $\alpha$ 内任意直线都平行于 $\beta$；
**传递性**：平行于同一平面的两条直线不一定平行（它们可以相交或异面）——平行没有「平面级」的传递性。

**重点：** 注意「平行」在不同维度间的传递并不自由。线线平行的传递性成立（$a \parallel b$，$b \parallel c$ ⇒ $a \parallel c$），但线面平行之间没有直接传递性。判断能否「传递」，永远要回到定义与判据。

线面平行的判定还有一个「面面平行」的间接路径，值得预先见识：若两个平面平行，则其中一个平面内的**任意一条直线**都平行于另一个平面。所以「证明线面平行」有时候可以转化为「证明它所在的平面平行于目标平面」——虽然步骤变多，但面对复杂图形时常常更稳妥。

判定线面平行的常见「找平行线」来源，可以归纳成一张工具表：

| 平行线来源 | 判定依据 | 适用场景 |
| --- | --- | --- |
| 三角形中位线 | 中点条件 | 出现中点时 |
| 平行四边形对边 | 对边平行 | 出现平行四边形时 |
| 线面平行的性质 | 交线 | 已知一条线面平行时 |
| 面面平行的性质 | 交线平行 | 已知两个面平行时 |
| 平行线分线段成比例 | 比例相等 | 出现比例条件时 |

这张表的实用价值：拿到「证线面平行」的题，先扫一眼图形里有没有中点、平行四边形、平行面——有，就顺着对应的「平行线来源」构造辅助线。**「找平行线」不是灵感，而是模式识别**。

<span class="marginnote">「证线面平行 = 找一个平行」这个思路还可以向「证面面平行」「证线面垂直」推广：每一个位置关系都对应一个「找足够条件」的判定定理。学会「按目标找条件」而不是「看到什么证什么」，是立体几何证明能力的分水岭——它本质上是「目标导向的问题分解」。</span>

最后提一个容易混淆的细节：**「直线在平面内」与「直线与平面平行」是完全不同的位置关系**。直线在平面内时，直线上所有点都在平面内（无穷多个公共点）；直线与平面平行时，没有公共点。判定定理要求「$a$ 在平面外」，正是为了排除「在平面内」的情形——如果 $a$ 在平面内，它与 $b$ 平行也不构成「线面平行」，而是「线在面内」。

线面平行在「截面问题」里还有一种经典应用，值得单独掌握：**用一个平面去截立体，求截面的形状**。例如用平行于底面的平面截棱锥，得到的小棱锥与原棱锥相似，对应边长之比等于「截面的高度比」；用不过顶点的平面截正方体，可能得到三角形、四边形、五边形甚至六边形截面。

| 截法 | 截面形状 | 关键依据 |
| --- | --- | --- |
| 平行于底面的平面截棱锥 | 与原底面相似的图形 | 线面平行的性质 |
| 过正方体三条相邻棱的平面 | 等边三角形 | 勾股定理 |
| 平行于一条棱的平面截正方体 | 矩形 | 线面平行 |
| 过正方体中心的平面 | 可能六边形 | 对称性 |

「截面」问题把空间推理与平面图形结合：先用线面平行/垂直判定确定截面与各棱的交点，再把这些交点「摊」到一个平面里研究形状。它是「降维」思想的标准演练。

<span class="marginnote">「截面」在现实中无处不在：切面包、切木料、医学的 CT 扫描（把身体切成一层层薄片）、地质学的剖面图。理解「平面与立体相交得什么图形」，是这些应用共同的几何基础。CT 扫描的原理——从多个方向的投影重建三维结构——甚至就是「三视图」与「截面」思想的逆运算。</span>

最后强调一个「证明书写的规范」：线面平行的完整证明必须写清三件事——**① 线在平面外；② 线在平面内；③ 两线平行**。三缺一不可。很多失分不是因为「不会证」，而是因为「漏写了前提」——证明的严谨性，恰恰体现在把每个前提都说清楚。

「线面平行」在「长方体」里是最容易验证的结构：长方体中，任意一条棱都与两个面平行、与另两个面相交。例如棱 $AB$ 与平面 $DCGH$ 平行，与平面 $ABCD$ 相交。这些「标准样本」可以帮助你建立「线面平行」的直觉——遇到抽象图形，先放进长方体「找感觉」。

「线面平行」与「面面平行」还有一个「传递」关系值得明确：若 $\alpha \parallel \beta$，则 $\alpha$ 内任意直线都平行于 $\beta$（线在面内 ⇔ 线面平行）。反过来，「两条平行于同一平面的直线」却不必然互相平行（它们可以异面）。「从面面平行推线面平行」是一路通行，「从两条线面平行推线线平行」却要小心——**平行关系的传递要逐级验证**。

<span class="marginnote">「从面面平行推线面平行」与「两条线面平行推不出线线平行」的对比，是立体几何「平行传递性」最容易混淆的地方。判断能否「传递」，永远回到定义与判据：共面才谈平行，异面就不平行——「是否共面」是第一步。</span>

最后，「线面平行」在「解析几何 / 向量」里有一个干净的代数形式（预告）：直线方向向量 $\vec{u}$ 与平面法向量 $\vec{n}$ 满足 $\vec{u} \cdot \vec{n} = 0$，即线面平行 ⇔ 方向向量与法向量垂直。这个「几何关系 → 代数判据」的翻译，将在《空间向量与立体几何》一节全面展开——今天先把「几何直觉」立住。

## 6 小结

- **判定定理**：面内找一条平行线（$a \not\subset \alpha$、$b \subset \alpha$、$a \parallel b$ ⇒ $a \parallel \alpha$），用反证法证明。
- **性质定理**：线面平行 + 过线作平面 ⇒ 交线平行于该线，实现「降维」。
- **中位线法**：中点 → 中位线 → 线线平行 → 线面平行，是高频证明套路。
- 向量视角：**线面平行 ⇔ 方向向量垂直于法向量**，通往空间向量解题。
- 平行传递性要分级判断：线线有传递性，线面之间没有直接的传递性。
