## 为什么从植物生长素开始

从第1章到第4章，我们都在讲动物（尤其是人）的调节。但植物同样要适应环境：向日葵跟着太阳转头、窗台边的植物朝光生长、树顶的芽抑制侧芽……这些现象背后是一类特殊信号分子——**植物激素**。本节从第一个被发现的植物激素——**生长素**讲起，先看它如何被科学家一步步「捉到」，再看它的运输方式与作用特点。这是理解整章植物调节的钥匙，也呼应了「调节的本质是信号」这一贯穿全册的思想。

## 1 生长素的发现：一场接力式的实验

生长素的发现浓缩了近 50 年、四代科学家的接力实验。起点是达尔文父子的**向光性实验**：

**达尔文的实验**（1880）：

1. 正常胚芽鞘受单侧光照射 → 弯向光源生长。
2. 切去胚芽鞘尖端 → 不生长也不弯曲。
3. 尖端套上不透光的锡箔罩 → 不弯曲。
4. 尖端以下套上锡箔罩 → 仍弯曲。

**结论：胚芽鞘的感光部位在尖端，弯曲的部位在尖端下面**——尖端产生某种影响传递到下部，引起弯曲。<span class="marginnote">达尔文由此提出「胚芽鞘尖端产生某种影响并传递到下部的伸长区，使其弯曲」的假说。实验设计的精髓是<strong>对照</strong>：用锡箔罩分别遮住尖端与下部，把「感光」与「弯曲」两个环节分开定位。</span>

**后继者的推进**：

- **詹森**：把尖端切下，用琼脂片隔开再接回去 → 胚芽鞘仍弯曲。说明尖端的影响能**透过琼脂**（是化学物质，不是直接接触的刺激）。
- **拜尔**：把尖端切下置于胚芽鞘一侧，黑暗培养 → 胚芽鞘弯向放置尖端的一侧。说明尖端的影响**分布不均**即引起弯曲。
- **温特**：把尖端放在琼脂块上一段时间，再将琼脂块放在切去尖端的胚芽鞘一侧 → 该侧生长加快、弯曲。他由此**命名这种化学物质为生长素**。<span class="marginnote">温特实验是「分离并检验」的决定性一步：用琼脂块「收集」尖端分泌的物质，再单独施加到去尖胚芽鞘上，证明化学物质本身足以引起生长弯曲——把假说变成了可重复的实证。</span>

## 2 生长素的本质、产生与运输

1934 年，科学家从人尿、植物材料中分离鉴定出生长素的化学本质——**吲哚乙酸（IAA，indole-3-acetic acid）**。

**产生部位**：主要在**幼嫩的芽、叶和发育中的种子**等部位，由色氨酸转变而来。

**分布**：大多集中在**生长旺盛的部位**（如胚芽鞘尖端、根尖、茎尖），而趋向衰老的组织中较少。

**运输方式**——这是高频考点：

- **极性运输**：在胚芽鞘、芽、幼叶和幼根中，生长素只能**从形态学上端运向下端**，不能反向运输——这种单向运输叫极性运输。它需要载体、消耗能量（主动运输）。
- **非极性运输**：在成熟组织中，生长素可通过输导组织（韧皮部）进行非极性运输。<span class="marginnote">「形态学上端」是定义方向的基准：对茎而言是靠近顶端的方向，对根而言是靠近根尖的方向。把一段茎倒过来插，生长素仍从<strong>原来的形态学上端</strong>（现朝下）流向形态学下端——极性由形态学极性决定，不受重力方向支配。</span>

## 3 生长素的生理作用：低促高抑

生长素的作用是植物激素里最典型的「两重性」：

**生长素的作用具有两重性：既能促进生长，也能抑制生长；既能促进发芽，也能抑制发芽；既能防止落花落果，也能疏花疏果。低浓度促进，高浓度抑制。**

影响因素包括**浓度高低**与**器官种类**：

| 作用 | 低浓度 | 高浓度 |
| --- | --- | --- |
| 茎的生长 | 促进 | 抑制 |
| 芽的生长 | 促进 | 抑制 |
| 根的生长 | 促进（很敏感） | 抑制 |

**不同器官对生长素的敏感性不同：根 > 芽 > 茎。**<span class="marginnote">根对生长素最敏感——同一浓度对茎是促进、对根可能已是抑制。这就是为什么倒置的植物根仍向下（根的高浓度侧受抑制、生长慢，弯向抑制侧即向下），茎向上（茎的高浓度侧促进、生长快，弯向背光侧）——向光性、向地性都源于两重性。</span>

## 4 公式解析：生长素浓度—效应曲线

两重性可用一条「倒 U 形」曲线刻画：

$$
\text{效应} = \begin{cases} \text{促进（增强生长）} & 0 < c < c_{\text{最适}}\\ \text{促进作用减弱} & c > c_{\text{最适}}\\ \text{抑制} & c > c_{\text{阈}} \end{cases}
$$

- **第一步，看曲线形状**：横轴是生长素浓度，纵轴是促进作用（正）或抑制作用（负）。曲线先升后降，最高点对应**最适浓度**，此后随浓度升高促进作用减弱，越过某一阈值变为抑制。
- **第二步，看两条曲线的交点**：对根与茎分别画曲线——根的最适浓度远低于茎，且同一浓度下根往往处于「抑制区」而茎处于「促进区」。
- **第三步，应用举例**：**顶端优势**——顶芽产生的生长素向下运输，侧芽处浓度过高被抑制，顶芽浓度适宜旺盛生长。摘除顶芽后，侧芽浓度下降、解除抑制，侧枝萌发。<span class="marginnote">顶端优势是两重性最经典的应用：果树修剪「打顶」、棉花摘心，都是<strong>去除顶端优势</strong>让侧枝增多；园林中保持树形则保留顶芽。两重性曲线也是「植物激素类似物（生长调节剂）的应用」的理论基础。</span>

## 5 辨析｜易错点：生长素相关的常见误区

- **易错**：说「生长素促进生长就是越多越好」。生长素有**两重性**，高浓度抑制——「促进/抑制」取决于浓度与器官敏感性。
- **易错**：把「极性运输」与「重力方向」混淆。极性运输的方向由**形态学上下端**决定，重力影响的是生长素的重新分布（横向运输），两者机制不同。
- **易错**：以为向光弯曲是「背光侧长得慢」。向光侧生长素分布少、伸长慢；背光侧生长素分布多、伸长快——所以弯向**光源**。注意茎的背光侧是「促进」而非「抑制」。
- **易错**：把产生部位当成只有尖端。尖端是主要感光与产生部位，但幼芽、幼叶、发育中的种子也产生生长素。

## 6 深入理解：生长素发现实验的设计思想

生长素发现史浓缩了「控制变量」的实验智慧，逐组拆解：

- **达尔文实验**：切去尖端 vs 保留尖端 → 比较弯曲与否，证明尖端必需；尖端套罩 vs 尖端以下套罩 → 比较弯曲与否，证明「感光在尖端、弯曲在尖端以下」。两组对照把「感光部位」与「弯曲部位」分离开。
- **詹森实验**：尖端与下部之间插入琼脂片，仍弯曲 → 证明尖端的影响能**透过琼脂**（化学物质或物理刺激可扩散），排除了「必须是直接接触」的假设。
- **拜尔实验**：切下尖端置于一侧，黑暗中弯曲 → 证明弯曲由尖端物质的**分布不均**引起——黑暗中也有弯曲，说明不是光源直射效应。
- **温特实验**：尖端放在琼脂块上收集物质，再把琼脂块放去尖胚芽鞘一侧 → 该侧生长快、弯曲 → 证明确有**化学物质**（生长素）在起作用，且能离开活体组织。

**设计题套路**：证明「某部位产生某种物质」需要——切去该部位（无物质）对照、把物质转移到另一处（有物质）观察效应、设置空白琼脂对照（排除琼脂本身影响）。温特实验的空琼脂对照正是「空白对照」的典范。

**现代证实**：1934 年从人尿、植物中分离出吲哚乙酸（IAA），生长素从「假设的物质」变成「确定的分子」——假说经实验、分离、鉴定，最终成为科学事实。

## 7 本节知识网络与常见题型

**知识网络**：向光性发现史（达尔文→詹森→拜尔→温特）→ 生长素（IAA）产生与运输 → 两重性 → 顶端优势。核心概念链：尖端产生 → 极性运输 → 分布不均 → 两重性。

**常见题型与解法**：

1. **实验结论匹配**：达尔文（感光在尖端）、詹森（可透过琼脂）、拜尔（分布不均弯曲）、温特（命名生长素）——实验与结论对应。
2. **极性运输判断**：形态学上端→下端、需载体耗能（主动运输）——与重力无关；成熟组织为非极性运输。
3. **两重性应用**：低浓度促进、高浓度抑制；根>芽>茎的敏感性——顶端优势（侧芽浓度高被抑）用「摘除顶芽」解除。
4. **向光性分析**：单侧光使生长素向背光侧转移→背光侧促进伸长→弯向光源——「背光侧长得快」。

**解答要点提醒**：生长素「促进/抑制」取决于浓度与器官敏感性；向光弯曲中背光侧是「促进」不是「抑制」。产生部位：幼嫩芽叶、发育中种子；分布集中于生长旺盛处。

## 8 小结

- 生长素发现史：**达尔文（感光在尖端）→ 詹森（可透过琼脂）→ 拜尔（分布不均致弯曲）→ 温特（命名为生长素）**。
- 化学本质是**吲哚乙酸（IAA）**，在幼嫩部位合成，集中在生长旺盛处。
- 运输：幼嫩部位**极性运输**（上端→下端，主动运输），成熟组织**非极性运输**。
- 作用**两重性**：低促高抑；敏感性**根 > 芽 > 茎**。
- **顶端优势**是两重性的典型应用。

在下一节，生长素不再孤单——植物还有一组激素各司其职：赤霉素、细胞分裂素、脱落酸、乙烯，这就是**其他植物激素**。
