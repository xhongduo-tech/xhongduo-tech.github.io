## 为什么从种群遗传学开始

上一节结尾我们指出达尔文的一个局限：进化的单位到底是什么？现代生物进化理论给出了精确的回答——**种群**。本节把进化从「个体命运」提升到「种群基因库」的数学层面：用基因频率刻画种群的变化，用哈代-温伯格平衡描述「什么条件下基因频率不变」，再用突变、选择、隔离解释「什么条件下会变」。这套框架就是**现代生物进化理论（综合进化论）**，它把孟德尔遗传学与达尔文自然选择焊接在了一起。

## 1 种群与基因库

**种群（population）是生活在一定区域的同种生物全部个体的集合。** 种群是生物繁殖的基本单位，也是进化的基本单位。<span class="marginnote">「同种」是关键：同一区域内的全部个体彼此可以交配、交换基因，构成一个相对独立的基因交流单元。个体并不能「进化」，进化是种群基因组成随世代的变化。</span>

**基因库（gene pool）：一个种群中全部个体所含有的全部基因。**

**基因频率：在一个种群基因库中，某个基因占全部等位基因数的比率。** 例如，某种群有 100 个个体，基因型 AA、Aa、aa 分别为 30、60、10，则：

- A 基因数 = $30 \times 2 + 60 \times 1 = 120$，等位基因总数 = 200。
- **A 的基因频率 = 120/200 = 60%**，a 的基因频率 = 40%。

**基因型频率**则是某种基因型个体数占全部个体的比率（AA 为 30%）。

## 2 公式解析：哈代-温伯格平衡定律

设一对等位基因 A、a 的基因频率分别为 $p$ 与 $q$（$p+q=1$）。在理想条件下，随机交配一代后，各基因型频率保持恒定：

$$
(AA) = p^2, \qquad (Aa) = 2pq, \qquad (aa) = q^2
$$

- **第一步，推导配子频率**：随机交配时，配子中 A 的频率为 $p$、a 的频率为 $q$。
- **第二步，组合受精**：AA 的受精卵频率 = $p \times p = p^2$；aa 的频率 = $q^2$；Aa 的频率 = $p \times q + q \times p = 2pq$。
- **第三步，验证不变**：$p^2 + 2pq + q^2 = (p+q)^2 = 1$，且新种群中 A 的频率仍为 $p^2 + pq = p$——基因频率逐代不变。<span class="marginnote">哈代-温伯格平衡揭示了「在没有外力时，基因频率天然稳定」这一中性事实——进化不是自动发生的，需要外力打破平衡。</span>

**理想条件（哈代-温伯格成立的条件）**：种群足够大、随机交配、没有突变、没有自然选择、没有迁入迁出。只要任何一条不满足，基因频率就会改变——而现实中几乎不可能全部满足，这正是进化持续进行的数学原因。

## 3 突变、选择与基因频率的改变

**突变和基因重组**产生进化的原材料：基因突变产生新的等位基因（新基因），基因重组产生新的基因型组合。二者都是不定向的，只提供「素材」。
**自然选择**定向地改变基因频率：适应度高的基因型繁殖更多，其等位基因频率逐代上升——**自然选择决定进化的方向**。
**遗传漂变**（在较小种群中尤其显著）：随机因素造成的基因频率波动，可能使某些等位基因在种群中固定或消失，与适应性无关。<span class="marginnote">种群越小，漂变越强——这就是为什么小种群的遗传多样性往往更低。瓶效应（种群骤减）与奠基者效应（少数个体建立新种群）都是漂变的典型场景。</span>

## 4 物种的概念与隔离

**物种（species）：能够在自然状态下相互交配并产生可育后代的一群生物。**

**辨析｜易错点：物种 vs 种群。** 种群强调「同一区域」，物种强调「能交配产生可育后代」。同一物种可能分成多个种群（如不同池塘里的鲤鱼）；不同物种即使同域，也不能有效基因交流。

**隔离（isolation）是物种形成的关键环节**，分两类：

**地理隔离**：不同种群被山川、海洋等地理障碍隔开，无法交配。这是量变的积累阶段。
**生殖隔离**：即使相遇也无法交配，或交配后不能产生可育后代（如马与驴的后代骡不育）。这是质变的标志。

**物种形成的标志是产生生殖隔离。**<span class="marginnote">地理隔离不必然导致新物种——只有长期隔离中，各群体基因库独立演变，累积到不足以交配时才产生生殖隔离。所以「地理隔离是物种形成的常见途径」，而生殖隔离是形成的「完成标志」。</span>

## 5 物种形成的两种主要方式

**异地物种形成（地理隔离 → 生殖隔离）**：同一物种的不同种群被地理障碍隔开，在各自环境中独立进化，基因库渐行渐远，最终即使接触也无法交配。加拉帕戈斯群岛的地雀是经典案例。

**同域物种形成**：在同一区域内，因生态位分化、多倍化等原因直接产生生殖隔离。例如植物通过染色体加倍形成新种（新多倍体与二倍体亲本之间即存在生殖隔离）。<span class="marginnote">多倍化是植物中快速物种形成的常见机制：一次染色体加倍就使新个体与亲本无法正常杂交——这解释了为什么多倍体在植物中远比动物普遍。</span>

## 6 深入理解：哈代-温伯格平衡的计算题型

遗传平衡定律的计算是必考内容，三类典型题：

**题型一：已知基因频率求基因型频率**。若 A 频率 $p=0.6$、a 频率 $q=0.4$，则 AA = $p^2 = 0.36$、Aa = $2pq = 0.48$、aa = $q^2 = 0.16$。直接套公式即可。

**题型二：已知基因型频率求基因频率**。AA = 30%、Aa = 60%、aa = 10%，则 A = 30% + 60%/2 = 60%，a = 10% + 60%/2 = 40%。「纯合子频率 + 杂合子频率的一半」。

**题型三：已知患病率求携带者频率**。某常染色体隐性病患病率 aa = 1/10000，则 $q = \sqrt{1/10000} = 0.01$，$p = 0.99$，携带者 Aa = $2pq \approx 2 \times 0.99 \times 0.01 \approx 0.0198$（约 2%）。这是遗传咨询中估算携带者频率的基本方法。

**注意**：哈代-温伯格平衡要求理想条件（大种群、随机交配、无突变、无选择、无迁移）。若题目说明「自然选择正在发生」或「种群很小」，则不能直接套用公式——先判断是否处于平衡状态，再决定算法。

## 7 本节知识网络与常见题型

**知识网络**：种群（进化基本单位）→ 基因库/基因频率 → 哈代-温伯格平衡 → 突变选择漂变 → 隔离 → 物种形成。核心概念链：基因频率改变 → 进化 → 生殖隔离 → 新物种。

**常见题型与解法**：

1. **基因频率计算**：纯合子频率 + 杂合子频率一半；已知患病率求携带者频率（先开方得 q）。
2. **哈代-温伯格条件**：大种群、随机交配、无突变、无选择、无迁移——条件不满足则不能直接套公式。
3. **物种形成判断**：「地理隔离是常见途径、生殖隔离是完成标志」——隔离类型与作用对应。
4. **现代进化理论**：种群是基本单位、突变和基因重组是原材料、自然选择决定方向、隔离是新物种形成的必要条件。

**解答要点提醒**：基因频率改变 ≠ 一定形成新物种（量变）；生殖隔离一旦产生即新物种（质变）。马与驴产骡（不育）——骡不是新物种，因为不能产生可育后代；这体现「物种 = 可交配产生可育后代」的定义。

## 8 拓展思考：进化在身边的证据

**抗生素耐药是「正在发生的进化」**：细菌繁殖快、世代短，耐药突变不断出现；抗生素筛选下耐药菌比例快速上升——这就是「自然选择」在实验室/医院里的实时上演。看懂这一点，就理解了「滥用抗生素的进化论代价」。

**镰状细胞贫血的「平衡选择」**：镰状细胞基因纯合子（SS）患病、杂合子（AS）正常但抗疟疾——在疟疾流行区，杂合子的生存优势使该基因维持较高频率。一个有害基因因环境「有利」而保留，完美诠释了「有利/有害是环境相对的」。

**人类基因组中的进化痕迹**：乳糖耐受基因在畜牧人群中频率高（与饮奶文化协同进化）、高原人群的低氧适应基因（西藏、安第斯）——自然选择仍在塑造今天的人类。

**理解进化的时间尺度**：细菌进化以天计、人类进化以万年计——「进化」不是遥远的历史，而是持续的当下。「种群基因频率的改变」就是进化的定义，它每时每刻都在发生。

## 9 收束思考：进化的数学之美

**用数学描述进化**：基因频率、哈代-温伯格平衡、遗传漂变——进化可以用方程精确刻画。生物学与数学在此交汇：把「变化的种群」翻译成「变化的频率」，进化就变得可预测、可计算。

**平衡与打破**：哈代-温伯格平衡描述的是「无进化」的理想态——而现实中突变、选择、漂变、迁移不断打破平衡，正是这些「打破」驱动了进化。「静止是理想，变化是常态」。

**为群落学铺垫**：种群的进化（基因频率改变）与群落的变化（演替）是不同层次的时间之矢——从种群到群落，时间尺度在拉长，变化的形式在多样。带着这个视角，进入《生物与环境》。

## 10 小结

- **种群是进化的基本单位**，基因库与基因频率刻画种群的遗传组成。
- **哈代-温伯格平衡**：$p^2 + 2pq + q^2 = 1$，理想条件下基因频率不变；条件被打破即进化。
- 进化的原材料是**突变与基因重组**（不定向）；**自然选择**定向改变基因频率；漂变在小种群中作用显著。
- **物种**以「可交配产生可育后代」界定；物种形成的标志是**生殖隔离**。
- 常见途径：**地理隔离 → 生殖隔离**；多倍化可快速形成新种。

在下一节，我们把镜头拉到整个生物圈：不同物种之间、生物与环境之间如何相互影响、共同演化？这就是**协同进化与生物多样性的形成**。
