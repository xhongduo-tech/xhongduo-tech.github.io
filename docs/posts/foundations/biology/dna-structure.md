## 为什么从DNA的结构开始

上一节，我们用三个经典实验证明 DNA 是遗传物质。但「遗传物质」必须是能**复制、能突变、能编码信息**的分子——这些功能的答案，全部藏在 DNA 的三维结构里。1953 年沃森与克里克在《自然》上发表的这篇仅一页多的论文，被誉为 20 世纪生物学最重要的发现。本节要把这条双螺旋拆开看：**DNA 由什么构成、两条链如何配对、为什么这个结构恰好能满足遗传的全部要求。**

## 1 脱氧核苷酸：DNA 的基本单位

DNA 的基本组成单位是**脱氧核苷酸（deoxynucleotide）**，每个脱氧核苷酸由三部分构成：

- **一个磷酸基团**（含磷）。
- **一分子脱氧核糖**（五碳糖，比核糖少一个氧原子）。
- **一分子含氮碱基**：腺嘌呤（A）、鸟嘌呤（G）、胞嘧啶（C）、胸腺嘧啶（T）之一。<span class="marginnote">四种碱基分成两类：嘌呤（A、G，双环结构）与嘧啶（C、T，单环结构）。嘌呤比嘧啶大一圈——这个几何差异直接决定了配对规则，见下文。</span>

脱氧核苷酸通过**磷酸二酯键**连成长链：前一分子脱氧核糖的 3 号位羟基与后一分子磷酸基团脱水缩合，如此反复，形成**脱氧核苷酸链**。

## 2 沃森-克里克模型的三大基石

沃森与克里克的双螺旋模型并非凭空想象，它建立在三条证据之上：

1. **查戈夫规则（Chargaff）**：在不同物种中，A 的量总是约等于 T，G 的量总是约等于 C——即 $A = T$、$G = C$。<span class="marginnote">查戈夫 1950 年用精确的纸层析分析发现，DNA 中嘌呤总量恒等于嘧啶总量。这个「笨拙」的化学事实，是碱基互补配对的直接预言。</span>
2. **富兰克林的 X 射线衍射图**：DNA 纤维的衍射图显示螺旋特征——特定间距的反射条纹暗示分子是长而规则的螺旋，且螺旋直径约 2 nm、螺距约 3.4 nm。
3. **碱基几何**：嘌呤-嘧啶配对使双螺旋直径处处相同；若嘌呤-嘌呤配对则直径太大，嘧啶-嘧啶配对则太小。

## 3 DNA 双螺旋结构的主要特点

沃森与克里克最终给出的模型，要点可以概括为「三句话」：

**第一，DNA 由两条脱氧核苷酸链组成，两条链按反向平行方式盘旋成双螺旋结构。**<span class="marginnote">「反向平行」指一条链从 5' 端到 3' 端，另一条从 3' 端到 5' 端。这个方向性在 DNA 复制和转录中至关重要——新链只能从 5'→3' 合成。</span>

**第二，外侧是磷酸-脱氧核糖交替连接构成的骨架，内侧是碱基。** 磷酸和脱氧核糖都是亲水的、结构规则的部分，排在外侧构成两条「扶手」；碱基疏水，两两相对排在内侧，如同楼梯的「踏板」。

**第三，碱基通过氢键配对：A 与 T 配对（两个氢键），G 与 C 配对（三个氢键）。**

$$A \equiv T \quad (\text{2 个氢键}), \qquad G \equiv C \quad (\text{3 个氢键})$$

## 4 公式解析：为什么 $A+T$ 与 $G+C$ 的比例随物种而变

碱基互补配对引出一个常考的计算结论，用三步拆开：

设某 DNA 分子中 $A$ 占总碱基数的比例为 $a$，则 $T = a$，$G = C = 50\% - a$。

- **第一步，利用配对规则**：$A = T$、$G = C$，所以 $A + G = T + C = 50\%$——嘌呤恒等于嘧啶。
- **第二步，看整体**：整个双链 DNA 中，$\dfrac{A+G}{T+C} = 1$ 恒成立，无论什么物种。
- **第三步，看单链与局部**：在一条单链中，$A$ 与 $T$ 不一定相等；$A+T$ 的比例可能偏离 50%。**$(A+T)$ 的比例（或 $G+C$ 含量）是物种特异的，而 $A/T=1$、$G/C=1$ 是普适的。**<span class="marginnote">这就是「DNA 指纹」与 GC 含量测定能区分物种的化学基础：不同生物基因组中 $G+C$ 含量差异很大（如细菌从 25% 到 75%），而同物种则相对稳定。</span>

### 结构决定的功能三特性

- **稳定性**：两条链靠氢键与碱基疏水作用维系；G-C 配对三个氢键，故 GC 含量高的 DNA 更稳定（解链温度更高）。
- **多样性**：碱基对排列顺序千变万化，构成遗传信息——4 种碱基在 $n$ 对位置上有 $4^n$ 种排列，人类基因组约 30 亿碱基对，可能性近乎无穷。
- **特异性**：每个 DNA 分子的碱基排列顺序是特定的，这正是它携带特定遗传信息的根本。

## 5 辨析｜易错点：DNA 结构中的几个「位置」

- **易错**：把氢键当成化学键强度很高。氢键比共价键弱得多，DNA 复制时解旋酶就是靠拆氢键分开两条链的；共价键（磷酸二酯键）构成骨架，一般不拆。
- **易错**：嘌呤-嘌呤或嘧啶-嘧啶配对是错的。A 与 T、G 与 C 之间由氢键供体/受体匹配决定，不能任意搭配。
- **易错**：一个脱氧核苷酸的「含 N 碱基」位置。碱基连在脱氧核糖的 1 号碳上，磷酸连在 5 号碳上——方向记号 5' 与 3' 就是从碳原子编号来的。

## 6 深入理解：DNA 碱基计算的常用结论

DNA 结构题的实质是「碱基互补配对」的代数应用，五条结论直接背：

1. 双链 DNA 中，**A = T、G = C**（嘌呤 = 嘧啶），即 A + G = T + C = 50%。
2. 双链中，$\dfrac{A+T}{G+C}$ 的值随物种而异（物种特异性），但 $\dfrac{A+G}{T+C} = 1$ 恒成立。
3. 一条链中 $\dfrac{A_1+T_1}{G_1+C_1} = m$，则互补链中 $\dfrac{A_2+T_2}{G_2+C_2} = m$（相等）；而 $\dfrac{A_1+G_1}{T_1+C_1}$ 与互补链互为倒数。
4. 含 n 个碱基对的 DNA 分子，若含 m 个腺嘌呤，则含胞嘧啶 $(n-m)$ 个（因为 C = G，且 A + C = n）。
5. 复制 n 次需某种碱基数为该碱基数 × $(2^n - 1)$。

**典型题目**：某 DNA 中 A 占 20%，问 G 占多少。由 A + G = 50% 得 G = 30%。注意题目若给的是「一条链上的比例」，要先换算成整条 DNA 的比例再套结论，避免直接照搬。

**结构稳定性联想**：GC 含量越高的 DNA 热稳定性越高（三氢键多于两氢键），解链温度 $T_m$ 越高——这也是 PCR 设计中引物 GC 含量常控制在 40%～60% 的原因之一。

## 7 本节知识网络与常见题型

**知识网络**：脱氧核苷酸（磷酸+脱氧核糖+碱基）→ 磷酸二酯键连成链 → 双链反向平行 → 碱基互补配对。核心结论：A=T、G=C；嘌呤=嘧啶。

**常见题型与解法**：

1. **结构图判断**：图中给出碱基对，判断是否正确的配对（A-T、G-C 才正确）——注意氢键数目（A-T 两键、G-C 三键）。
2. **碱基比例计算**：双链中 A+G=T+C=50%；单链中 A₁/T₁ 与互补链 T₂/A₂ 对应——套用结论时先分清「双链还是单链」。
3. **数量计算**：某 DNA 含 n 个碱基对、m 个腺嘌呤 → 胞嘧啶 = n−m、氢键总数 = 2m + 3(n−m)。
4. **稳定性判断**：GC 含量越高，DNA 越稳定、解链温度越高。

**解答要点提醒**：碱基互补配对是「A 对 T、G 对 C」——不是 A 对 C 或 G 对 T；RNA 中 T 换为 U。DNA 双螺旋的「反向平行」指一条 5'→3'、另一条 3'→5'。沃森-克里克模型的三大证据：查戈夫规则、富兰克林 X 射线衍射、碱基几何。

## 8 拓展思考：双螺旋的发现方法

**富兰克林的 X 射线衍射照片**是双螺旋模型的直接线索：照片上的「十字形」衍射图案表明分子呈螺旋结构，黑色区域间距暗示螺距与直径——沃森与克里克正是靠这张照片「猜」出了正确模型。1953 年《自然》上那篇仅一页多的论文，标题是《核酸的分子结构》。

**模型建构的方法论**：用硬纸板剪出碱基与糖、磷的比例模型，反复尝试配对组合——嘌呤-嘌呤太大、嘧啶-嘧啶太小，只有嘌呤-嘧啶配对能维持直径恒定。这种「搭模型、算几何、对数据」的物理方法，是结构生物学的经典范式。

**为什么双螺旋是「合理设计」**：碱基朝内、磷酸糖骨架朝外——疏水碱基藏在内部避开水环境，亲水骨架暴露在外与水相溶；互补配对使复制只需「拆开-补全」两步。结构本身就「预告」了功能——这正是生物学「结构决定功能」的又一例证。

## 9 收束思考：结构与功能的统一

**DNA 结构是「为功能而生」的设计**：互补配对让复制有模板、碱基顺序让信息有编码、双链螺旋让分子稳定、氢键可逆让解旋可行——每一处结构特征都对应一项功能需求。「结构决定功能」在 DNA 上体现得淋漓尽致。

**从结构到信息**：DNA 的四种碱基序列是「遗传语言的字母」——正如本节公式 $4^n$ 所示，极少的字母就能组合出海量的信息。信息的存储与读取，是分子生物学永恒的主题。

**科学发现的启示**：DNA 结构不是被「看见」的，而是被「推理」出来的——X 射线数据、碱基比例、分子模型共同拼出答案。伟大的科学发现，常常是多种证据的交汇。

## 10 小结

- DNA 基本单位是**脱氧核苷酸**（磷酸 + 脱氧核糖 + A/G/C/T 碱基）。
- 双螺旋要点：**两条链反向平行**；骨架在外、碱基在内；**A-T（两氢键）、G-C（三氢键）互补配对**。
- 嘌呤数 = 嘧啶数（$A+G=T+C$）；$G+C$ 含量物种特异。
- 结构决定的三大特性：**稳定性、多样性、特异性**。

在下一节，我们将看到双螺旋最迷人的一幕——它如何自己复制自己，这就是**DNA 的复制**。
