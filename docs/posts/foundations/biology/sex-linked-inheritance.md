## 为什么从伴性遗传开始

上一节，摩尔根的果蝇实验第一次让我们看到了「跟着性别走」的基因：红白眼性状在雌雄果蝇中的分布不对称。人类同样有一批这样的基因，它们位于性染色体上，遗传规律与常染色体基因截然不同——最著名的例子是红绿色盲与血友病。**伴性遗传（sex-linked inheritance）就是研究性染色体上基因的遗传规律。**它一方面印证了基因在染色体上的结论，另一方面直接解释了现实中「为什么色盲几乎都是男性」这类现象。

## 1 性染色体与性别决定

人类的体细胞有 23 对染色体：22 对常染色体与 1 对性染色体。女性为 XX，男性为 XY。

**性别决定的关键在减数分裂产生的配子**：

- **女性**只产生一种卵细胞：均含 X 染色体。
- **男性**产生两种精子：含 X 或含 Y，各占 1/2。

受精时，若精子带 X 则子代为 XX（女性），若精子带 Y 则子代为 XY（男性）。于是：

$$XX \times XY \longrightarrow 后代性别比 \approx 1 : 1$$

**性别的决定权在精子，不在卵细胞**——这是初学者最容易忽略的一点。<span class="marginnote">X 染色体较大、含基因较多；Y 染色体较小、基因很少。所以位于 X 上的基因，在男性（XY）中往往没有对应的等位基因——这是伴性遗传诸多「怪现象」的根源。</span>

## 2 人类红绿色盲的遗传

红绿色盲是 X 染色体上的**隐性**遗传病，致病基因用 $X^b$ 表示，正常基因用 $X^B$ 表示。Y 染色体上没有相应基因。

由于男性只有一条 X，所以**只要带 $X^b$ 就患病**（基因型 $X^bY$）；女性需要两条 X 都带 $X^b$（$X^bX^b$）才患病，携带者 $X^BX^b$ 表现正常但能传病。这是「男性患者多于女性」的根本原因。

### 常见婚配组合

| 亲本基因型 | 子代患病情况 |
| --- | --- |
| $X^BX^B \times X^bY$ | 女儿全正常（携带者），儿子全正常 |
| $X^BX^b \times X^BY$ | 女儿全正常（半数为携带者），儿子半数为色盲 |
| $X^BX^b \times X^bY$ | 女儿半数色盲，儿子半数色盲 |
| $X^bX^b \times X^BY$ | 女儿全为携带者，儿子全为色盲 |

## 3 公式解析：为什么「女患者的儿子必患病」

以红绿色盲为例，推导这个在系谱图推断中极其常用的结论。

$$
X^bX^b \;(\text{女患者}) \times X^BY \;(\text{正常男}) \longrightarrow \text{儿子全为 } X^bY
$$

- **第一步，写配子**：女患者只产生含 $X^b$ 的卵细胞；正常男性的精子有两种，含 $X^B$ 或含 $Y$。
- **第二步，组合**：受精后女儿为 $X^BX^b$（正常携带者），儿子为 $X^bY$（色盲）。
- **第三步，推广**：因为儿子的 X 染色体**只能来自母亲**，所以只要母亲是色盲，儿子必定色盲；反过来，色盲男性的 X 染色体**必来自母亲**，女儿至少是携带者。<span class="marginnote">「儿子像妈」不是坊间传言，而是 X 连锁遗传的必然结果：儿子的 Y 来自父亲、X 来自母亲，X 上的基因全部由母亲单方面提供。</span>

这条「**交叉遗传**」的规律——外公患病传给母亲（携带者），再传给外孙——是判断 X 连锁隐性遗传病的重要依据。

## 4 抗维生素 D 佝偻病：X 连锁显性遗传

伴性遗传不仅有隐性形式，还有**显性形式**。抗维生素 D 佝偻病就是 X 连锁显性遗传病，致病基因 $X^D$ 为显性。它的特点是**女性患者多于男性**，因为女性只要一条 X 带 $X^D$ 即患病。

显性伴性遗传与隐性伴性遗传的关键差异在于患者分布：

- X 连锁隐性病：男患者多于女患者，常隔代遗传（交叉遗传）。
- X 连锁显性病：女患者多于男患者，往往代代相传（连续性遗传）。

| 特点 | X 连锁隐性（色盲、血友病） | X 连锁显性（抗VD佝偻病） |
| --- | --- | --- |
| 患者分布 | 男性多于女性 | 女性多于男性 |
| 遗传方式 | 隔代交叉遗传 | 连续遗传 |
| 父病传子 | 不传（儿子 Y 来自父） | 女儿全病、儿子全正常 |

## 5 辨析｜易错点：伴性遗传与常染色体遗传的区分

在遗传系谱图中，判断「基因位于常染色体还是 X 染色体」，是高考与生物竞赛的经典考点。常用步骤：

- **第一步**：若患者男女比例大致相等，且与性别无关联，优先考虑**常染色体遗传**。
- **第二步**：若女性患者的父亲或儿子**全部患病**，极可能是 **X 连锁隐性**；若男患者的母亲和女儿**全部患病**，极可能是 **X 连锁显性**。
- **第三步**：若父子均为患者且母系正常，还要考虑 **Y 连锁遗传**（限雄遗传，仅男性传递）。
- **易错**：不要仅凭「隔代」或「连续」就下结论，常染色体隐性病同样可以隔代遗传。性别分布不对称才是伴性遗传的最强信号。

## 6 深入理解：遗传系谱图的判读方法

系谱图题是伴性遗传的高频题型，判读有四步「倒查法」：

- **第一步，判显隐性**：「无中生有」为隐性（双亲正常、子女患病）；「有中生无」为显性（双亲患病、子女正常）。
- **第二步，判是否伴性**：若隐性病中**女患者的父亲或儿子必患病**，倾向 X 连锁隐性；若显性病中**男患者的母亲或女儿必患病**，倾向 X 连锁显性。
- **第三步，排除常染色体**：若存在「患病父亲生出正常女儿」或「正常母亲生出患病儿子且父系正常」，则不属于对应伴性遗传。
- **第四步，算概率**：确定基因型后，按孟德尔分离定律计算后代患病概率，注意 X 连锁时男女要分开算。

**典型实例**：血友病系谱中，若患病男孩（$X^hY$）的母亲表现正常，则其母亲基因型必为 $X^HX^h$（携带者），致病基因来自母方。这个结论直接来自「儿子的 X 只能来自母亲」。

**易错提醒**：题目说「人群中男性色盲多于女性」时，这是 X 连锁隐性的特征；若说「女性患者多于男性」则考虑 X 连锁显性。判断必须结合具体系谱，不能只凭一句话下结论。

## 7 本节知识网络与常见题型

**知识网络**：性染色体决定性别 → 性染色体上基因的遗传 → X 连锁隐性（色盲、血友病）→ X 连锁显性（抗VD佝偻病）。核心概念链：XX/XY → 交叉遗传 → 男多女少/女多男少。

**常见题型与解法**：

1. **基因型书写**：色盲基因写在 X 右上角（$X^B$、$X^b$），Y 染色体不写等位基因。
2. **概率计算**：女携带者 × 正常男 → 儿子 1/2 患病、女儿全正常；女患者 × 正常男 → 儿子全病、女儿全携带者——把男、女分开算。
3. **系谱推断**：「无中生有」隐性 → 看女患者的父/子是否患病判断是否伴 X。
4. **与常染色体区分**：男女患病比例是否对称——对称多为常染色体，不对称考虑伴性。

**解答要点提醒**：儿子的 X 染色体必来自母亲——这是 X 连锁遗传一切推论的出发点；Y 连锁遗传表现为「父传子、子传孙、全为男性」。「男性色盲多于女性」是 X 连锁隐性的直接推论。

## 8 小结

- **性别决定**：女性 XX 只产含 X 的卵细胞；男性 XY 产含 X 或 Y 的精子，后代性别比 ≈ 1∶1。
- **红绿色盲**是 X 连锁隐性病，男性只需一个致病基因即患病，故男多女少。
- **交叉遗传**：男性 X 染色体只能来自母亲并传给女儿；女患者的儿子必患病。
- **抗VD佝偻病**是 X 连锁显性病，女性患者多于男性，常连续遗传。
- 判断伴性遗传的关键是**性别分布是否不对称**。
