## 为什么从成因开始

前面几篇我们学会了「认矿物」，现在要问「矿物从哪里来」。同一种矿物可以在完全不同的环境里结晶：石英既可以是岩浆冷却的产物，也可以从热水溶液里沉淀，还可以在高温变质带里生成。**只看矿物本身永远不够，关键是把矿物放回它的成因环境**。更妙的是，矿物从不孤独地出现——一定温度、压力、成分下，能稳定共存的矿物集合是确定的，这种**共生组合（paragenesis）**本身就是环境留下的温度计与压力计。读懂成因与共生，就拿到了从「认出一种矿物」到「重建一段地质历史」的钥匙，这正是赫顿「现在是开启过去的钥匙」这句格言在矿物学里的落地。它与第一级《物理》的热力学、第一级《化学》的相平衡、以及后续《岩石学》三大岩类，直接贯通。

## 1 三大成因作用总览

矿物的形成可粗分为三大类作用，各占一方：

| 成因类型 | 环境 | 主要机理 | 典型矿物 |
| --- | --- | --- | --- |
| 内生（岩浆/火成） | 岩浆房、深部 | 熔体冷却结晶分异 | 橄榄石、辉石、长石、石英 |
| 内生（热液） | 裂隙、孔隙中的热水溶液 | 从溶液中沉淀 | 石英脉、方铅矿、闪锌矿、黄铁矿 |
| 外生（沉积/风化） | 地表、水体 | 风化搬运、蒸发结晶、生物作用 | 石膏、石盐、高岭石、菱铁矿 |
| 变质 | 高温高压地壳深处 | 固态重结晶、矿物转变 | 蓝晶石、石榴子石、硅线石 |

**辨析｜易错点：**三大成因不是互斥的「标签」，而是一条连续谱。花岗岩里的石英是岩浆成因，同一块岩石中的方解石脉却可以是后期热液充填——**同一块标本里可以有不同成因的矿物世代**，读标本时要分清先后，而不是贴一个总标签。

<span class="marginnote">赫顿那句名言的真正分量在这里：今天实验室里能做出的矿物组合，可以反推亿万年地质历史中的温压条件。实验岩石学正是「用今天的炉子，验古代的温度」。</span>

## 2 岩浆作用与鲍温反应系列

地壳深处的岩浆（硅酸盐熔体，900–1300 ℃）冷却时，矿物按一定顺序结晶。美国岩石学家鲍温（N. L. Bowen, 1928）总结了**鲍温反应系列（Bowen's reaction series）**，它是岩浆岩矿物学的「宪法」：

**不连续系列**：橄榄石 → 辉石 → 角闪石 → 黑云母。相邻矿物是「反应对」：前一矿物熔进熔体、反应生成后一矿物，**任一时刻只允许一种镁铁质矿物与熔体共存**。
- **连续系列**：钙长石 → 钠长石。斜长石的成分随温度连续地从富钙滑向富钠。
- 两系列在末端汇合为**钾长石 → 白云母 → 石英**。

这个系列有两条推论：

- 早结晶的矿物（橄榄石、钙长石）形成高温组合；晚结晶的（石英、钾长石）是低温残余熔体的产物。
- **岩浆越「基性」（镁铁越多），结晶顺序越靠前**；越「酸性」（硅氧越多），残余熔体越富石英钾长石。

**辨析｜易错点：**鲍温系列说的是「从熔体中结晶的顺序」，不是「矿物稳定性的温度顺序」。石英在高温岩浆中早就能析出，只是成分上往往到残余熔体阶段才达到过饱和——顺序与温度有关联，但不能画等号。

## 3 热液作用

**热液（hydrothermal solution）**是富水的热水溶液（50–600 ℃），含大量可溶离子。它沿岩石裂隙运移时，因温度、压力下降或化学反应，溶质过饱和而沉淀出矿物——典型产物就是**石英脉**与脉状**硫化物矿床**（方铅矿、闪锌矿、黄铜矿、黄铁矿）。

热液成矿是金属矿床的主力机制：斑岩型铜矿、脉状金矿、密西西比河谷型铅锌矿，几乎都是热液的杰作。矿物的**共生顺序（paragenetic sequence）**在这里格外清晰：早期高温矿物（磁铁矿）先沉淀，晚期低温矿物（石英、方解石）后充填——观察脉中矿物的穿插关系，就能读出成矿过程的时间轴。

<span class="marginnote">共生顺序的野外判据：谁「切过」谁、谁「包裹」谁。晚期矿物切割早期矿物的脉体，早期矿物被包裹成残晶——这正是沉积学「切割律」在热液脉里的翻版。</span>

## 4 沉积作用与成岩作用

地表环境下，矿物经历**风化 → 搬运 → 沉积 → 成岩**的旅程：

**风化**：火成岩矿物在地表不稳定。橄榄石、辉石快速水解为黏土与氧化铁；长石风化为**高岭石**（因此长石是黏土的来源）。这解释了为何沉积岩中常见稳定矿物（石英、锆石）而几乎不见橄榄石。
- **蒸发结晶**：干旱盆地水体浓缩，按溶解度递增的顺序沉淀：方解石 → 石膏 → 石盐 → 钾盐。顺序由难溶到易溶，矿物层序是古水文的记录。
- **生物作用**：生物壳体富集碳酸钙，形成石灰岩（方解石、文石）。
- **成岩作用（diagenesis）**：松散沉积物压实、胶结、重结晶，如孔隙水析出的**石英胶结物**、**方解石胶结物**把砂粒粘成砂岩。

## 5 变质作用与变质矿物组合

**变质作用（metamorphism）**指岩石在固态下经历温度、压力、流体变化而调整矿物组合。变质的关键特征：**矿物变了，但岩石大体仍是固体**——不发生大规模熔融。

以最常见的泥质岩（泥岩/页岩）为例，随温压递增，出现经典的**递增变质带**：

绿泥石带 → 黑云母带 → 石榴子石带 → 蓝晶石带 → 硅线石带

其中**蓝晶石、红柱石、硅线石**是化学成分完全相同（$\ce{Al2SiO5}$）的三种同质多象，却各自稳定于不同的温压区间，因此被尊为**指示矿物（index minerals）**——只要在区域变质带里看到蓝晶石，就能读出那片地区曾达到的温度压力档位。这与第一级《物理化学》的相图是同一套语言：**每个矿物组合都对应相图上的一个稳定域（stability field）**。

<span class="marginnote">$\ce{Al2SiO5}$ 三种变体（蓝晶石高压、红柱石低压、硅线石高温）的稳定域由实验测定，是变质岩地质温压计的中坚。一个矿物组合 = 相图上一个「点」，这就是吉布斯相律 $F = C - P + 2$ 在矿物学中的应用。</span>

### 接触变质与区域变质：两种温压档案

按温压作用方式，变质作用分两大流派：

- **接触变质**：岩浆侵入使围岩局部受热，温度高、压力低，产物以角岩、斑点板岩为主，变质带窄（几十米到几公里），环绕侵入体呈晕圈。
- **区域变质**：地壳深处大范围温压共同作用，变质带可绵延数百公里，递增变质带就是它的典型记录。
- **判别线索**：接触变质常见斑点状结构（堇青石、红柱石），区域变质常见定向片理（云母定向排列）——前者主受热、后者主受压力学作用。

## 6 共生组合与相律

**共生组合（mineral assemblage）**：同一平衡条件下共存、能相互接触的一套矿物。它由热力学控制：**体系成分、温度、压力一旦给定，能平衡共存的矿物组合就是确定的**（吉布斯相律 $F = C - P + 2$ 给出自由度）。例如基性岩浆正常结晶的「橄榄石—辉石—斜长石」组合，与高压变质形成的「榴辉岩」组合（绿辉石 + 石榴子石）截然不同——前者告诉我们岩浆房的温度，后者告诉我们大陆碰撞的深度。

**辨析｜易错点：**「共生」不等于「共存」。同一块标本里，晚期热液方解石可以「共存」于早期橄榄石旁边，但它们从未在同一平衡条件下结晶，**不是共生**。判定共生的准则是：矿物之间有接触关系、无反应边、无交代证据，才谈得上同一组合。

### 数值算例：吉布斯相律数一数自由度

以「纯水 + 冰 + 水蒸气」三相同存的简单体系（成分 $C=1$，相数 $P=3$）为例：

- **代公式**：$F = C - P + 2 = 1 - 3 + 2 = 0$，自由度为零——三相点处温度压力都被钉死（约 0.01 ℃、611 Pa），不能自由改变任何一个变量。
- **对照矿物**：若高温高压下同时稳定共存 $\ce{Al2SiO5}$ 的两种变体（如蓝晶石 + 硅线石，$C=1, P=2$），则 $F = 1 - 2 + 2 = 1$——这条反应在相图上是一条线而非一个面，沿线温度压力只留一个自由度。
- **直觉**：相数越多、自由度越少；矿物学里「数相律」就是数「还能调几个旋钮」。

## 8 小结

- 矿物有**岩浆、热液、沉积、变质**四大成因机制，同一标本可有不同成因世代。
- **鲍温反应系列**：不连续系列（橄榄石→辉石→角闪石→黑云母）+ 连续系列（斜长石），控制岩浆结晶顺序与矿物组合。
- **热液作用**沉淀石英脉与金属硫化物矿床，共生顺序由矿物穿插关系读出。
- **沉积作用**按溶解度顺序析出蒸发盐，风化把不稳定矿物改造成黏土与氧化物。
- **变质作用**固态调整矿物组合，$\ce{Al2SiO5}$ 三种变体是指示温压的**指示矿物**。
- **共生组合**由相律决定：成分 + 温压定死组合；「共生」强调同一平衡条件，不是简单共存。
