## 为什么从晶体学基础开始

本专题一直在用「晶体结构」这个词，但至今没有给出精确的数学骨架。这一节就是补上那副骨架：**用坐标、整数、矩阵与群的语言，把「原子怎么排队」彻底量化**。晶面用一组整数 $(hkl)$ 描述、晶向用 $[uvw]$ 描述、全部对称操作用点群与空间群分类——有了这套语言，前几节里「石英属六方晶系」「方解石三组解理」「XRD 峰对应哪个晶面」这些直觉性的说法，才能变成可以计算、可以验证、可以被仪器读出的严格表述。这套数学骨架还直通第二级《群论》《晶体学》与《量子力学》的固体能带理论——从一块方解石到一颗半导体芯片，对称性始终是万物秩序的源头。

## 1 晶格、晶胞与布拉维格子

**晶格（lattice）**：晶体中周期性重复的点阵。每个重复单元的最小平行六面体叫**晶胞（unit cell）**，用三个棱向量 $\mathbf{a},\mathbf{b},\mathbf{c}$ 与夹角 $\alpha,\beta,\gamma$ 描述（即轴长与轴角）。晶胞里原子的具体排布构成**基元（basis）**——晶格 + 基元 = 晶体结构。

按对称性，晶格分为 **7 个晶系**（见《矿物形态与对称》）。再考虑晶胞除了「只有顶角原子」（素晶胞）外，还可以在体心、面心、底心额外放置格点，得到 **14 种布拉维格子（Bravais lattices）**：

| 晶系 | 素格子 P | 附加格子 |
| --- | --- | --- |
| 等轴 | 简单立方 P | 体心 I、面心 F |
| 四方 | P | I |
| 正交 | P | 底心 C、体心 I、面心 F |
| 六方 | P（六方棱柱） | — |
| 三方 | R（菱面体） | — |
| 单斜 | P | 底心 C |
| 三斜 | P | — |

**辨析｜易错点：**「为什么没有底心立方、面心四方？」——因为它们可以通过重新选择晶胞而等价于更简单的格子。布拉维格子是**不重复的完备分类**，多一个少一个都会破坏「每一类对应唯一一种格子」的干净结构。这条分类的完备性证明，是第二级《群论》的经典习题。

## 2 晶面指数：Miller 指数

**晶面（lattice plane）**是一族互相平行、间距相等的原子面。给一族晶面编号，用**Miller 指数 (hkl)**：

- 写出该晶面族中距原点最近的一个晶面在 $\mathbf{a},\mathbf{b},\mathbf{c}$ 轴上的**截距**（以轴长为单位）；
- 取这三个截距的**倒数**；
- 化为**最小整数比**，写作 $(hkl)$。

例：截距为 $(1, 1, 1)$ → 倒数 $(1,1,1)$ → 晶面 (111)；截距为 $(\infty, 1, 1)$ → 倒数 $(0,1,1)$ → 晶面 (011)；截距为 $(2, 2, \infty)$ → 倒数 $(\tfrac12,\tfrac12,0)$ → 乘 2 得 (110)。<span class="marginnote">三个规律值得记住：(1) 截距越大，对应指数越小；(2) 指数含 0 表示该面平行于某个轴；(3) 负指数在数字上加横线，如 $\overline{1}00$ 表示截距在负半轴。立方晶系的 (100)、(010)、(001) 是同一个立方体家族的三组对面。</span>

Miller 指数的威力在于它是**唯一的**：一族平行晶面只对应一组 (hkl)，反过来任何一组互质整数 (hkl) 都唯一确定一族晶面。

## 3 公式解析：立方晶系晶面间距

晶面族 (hkl) 的间距 $d_{hkl}$ 是 XRD 的核心输入。立方晶系（$a=b=c$，轴角 90°）有最简洁的公式：

$$d_{hkl} = \frac{a}{\sqrt{h^2 + k^2 + l^2}}$$

- **第一步，从一维到三维**：在一维链中，间距就是晶胞长度 $a$。在三维中，(hkl) 面把 $a$ 轴方向切成 $h$ 等份、$b$ 轴切 $k$ 等份、$c$ 轴切 $l$ 等份，等价于晶面法向在三个轴上的分量比例是 $h:k:l$。
- **第二步，用勾股定理**：间距是晶胞对角方向上的投影长度，法向分量的平方和开方即 $\sqrt{h^2+k^2+l^2}$，间距 $= a/\sqrt{h^2+k^2+l^2}$。
- **第三步，代数字验证**：取 $a = 5\ \mathrm{Å}$，则 $d_{100}=5\ \mathrm{Å}$，$d_{111}=5/\sqrt3 \approx 2.89\ \mathrm{Å}$，$d_{220}=5/\sqrt8 \approx 1.77\ \mathrm{Å}$。**指数越大、间距越小**——这与《X 射线衍射》一节「大角度峰对应小 $d$」的直觉完全吻合。

对其他晶系，公式中加入轴长与轴角的修正项（正交、六方等各有表达式），但立方这一式已能培养全部直觉。**反向应用**正是 XRD 鉴定：测出 $d$，代入公式反解 $a$，再比对 PDF 卡片即可定物相。

## 4 晶向指数与晶带

**晶向（lattice direction）**用 $[uvw]$ 表示：从原点沿 $\mathbf{a},\mathbf{b},\mathbf{c}$ 分别走 $u,v,w$ 个单位（互质整数）。例如 $[100]$ 是 $\mathbf{a}$ 轴方向，$[\bar1 10]$ 是从原点到 $(-1,1,0)$ 的方向。

**晶带（zone）**：交于同一晶向（晶带轴）的一组晶面族。例如立方晶系中，(100)、(110)、(120) 都含 $\mathbf{c}$ 轴方向，属于晶带轴 $[001]$ 的晶带。晶带概念在晶体测量中有大用：晶面间的交线方向就是晶带轴。

**辨析｜易错点：**$(hkl)$ 是**晶面**、$[uvw]$ 是**晶向**——圆括号与方括号差之毫厘、谬以千里。同面族里（如立方晶系的 (100) 与 (010)）用花括号 $\{100\}$ 表示「等价面族」；同方向族（如 $[100]$ 与 $[\bar1 00]$）用尖括号 $\langle100\rangle$ 表示。符号体系务必记牢。

## 5 点群与空间群：对称的完整分类

**点群（point group）**：晶体在空间中**保持至少一个不动点**的全部对称操作（旋转、镜面、反演、旋转反伸）构成的群。晶体点群只有 **32 种**（对应对称要素的 32 种组合，归入 7 晶系）。

**空间群（space group）**：把**平移对称**也纳入后，晶体的全部对称操作（含平移、滑移面、螺旋轴）构成的群，共 **230 种**。空间群是晶体结构分类的终极坐标：每种矿物的结构，最终都要落到某一个空间群。

<span class="marginnote">国际符号（Hermann–Mauguin）如 $P2_1/c$、$Fm\bar{3}m$，直接写晶格类型（P 素、F 面心、I 体心、C 底心）+ 特征对称（2 轴、镜面 m、螺旋轴 $2_1$ 等）。如岩盐的空间群 $Fm\bar{3}m$：面心立方 + 三次旋转反伸轴 + 三个镜面，一步到位。</span>

空间群的用处不止分类：对称操作还决定**消光规律**（哪些衍射峰不出现）——这是 XRD 图谱里每条峰的来源；也决定能带简并与压电、光学等性质的对称性约束，是固体物理的出发点。

## 6 小结

- **晶格 + 基元 = 晶体结构**；晶胞用轴长轴角描述；7 晶系 × 心型组合出 **14 种布拉维格子**。
- **Miller 指数 (hkl)** 由截距取倒数化简而来，一组互质整数唯一对应一族平行晶面。
- **立方晶系晶面间距** $d = a/\sqrt{h^2+k^2+l^2}$，指数越大间距越小，是 XRD 反推结构的核心公式。
- 晶向 $[uvw]$、等价面族 $\{hkl\}$、等价方向族 $\langle uvw\rangle$，符号体系务必区分。
- **点群（32）**不含平移、**空间群（230）**含平移，是晶体对称与结构测定的终极分类坐标。

到此，《矿物学》专题的九节主线全部走完：从原子如何成键、如何对称，到如何被光与 X 射线读出，再到如何在地质历史中诞生、在工业炉中变现。下一站，把矿物放回它的母体——**岩石学**，看矿物组合如何拼出地球的三种岩类。
