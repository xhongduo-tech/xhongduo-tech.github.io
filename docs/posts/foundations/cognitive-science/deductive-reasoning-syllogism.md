## 为什么从演绎推理开始

思维研究的第一站是**推理（reasoning）**：从已知推出未知。
**演绎推理（deductive
reasoning）**是其中"保真"的一支——**前提为真则结论必真**。
它的经典形式是亚里士多德创立的三段论，以及现代心理学研究最多的条件推理。
认知科学对演绎推理的发现很反直觉：**逻辑上严密的推理，
人在心理上却经常做错**——而且错得有规律。
<span class="marginnote">
演绎推理是"逻辑学"与"心理学"交汇的领域：逻辑学规定"应该怎么推"（规范性），
心理学描述"实际怎么推"（描述性）。
两者的落差——人为何系统地偏离逻辑——是认知科学最富成果的研究主题。
本专题在逻辑学分类（第一级《逻辑学》）里讲过规范逻辑，这里看心理学证据。</span>
本文以三段论与条件推理为窗口，看人类推理的"逻辑能力"与"心理局限"。

## 1 三段论：从全称到结论

**三段论（syllogism）**由两个前提与一个结论构成，前提与结论都是"量词 +
关系"的形式：

$$\text{所有 } A \text{ 是 } B, \quad \text{所有 } B \text{ 是 } C \quad \Rightarrow \quad \text{所有 } A \text{ 是 } C$$

判断三段论是否有效，靠的是**形式逻辑**，与内容无关：只要形式对，结论就必然成立。有效的例子：

- 所有鸟是动物；所有动物是生物；因此所有鸟是生物。✓

无效的经典错误（**换位谬误**）：

- 所有 A 是 B，因此所有 B 是 A？ ✗（"所有鸟是动物"推不出"所有动物是鸟"）

**人在三段论上的表现**：错误率随内容与形式而剧变。当内容与现实知识冲突时，人们倾向按"现实合理性"而非"逻辑形式"判断：<span class="marginnote"><strong>信念偏差（belief bias）</strong>：人们倾向接受"结论与现实一致"的推理，即使逻辑无效；拒绝"结论与现实冲突"的推理，即使逻辑有效。经典例子："所有毒品都是危险的；一些药物是毒品；因此一些药物是危险的"——逻辑有效，但"药物危险"与日常经验冲突，许多人拒绝接受。</span>"所有 A 是 B；所有 C 是 B；因此所有 A 是 C"——前提全真，结论形式却无效，但很多人会接受，因为"听着像真的"。

## 2 条件推理：四种基本形式

**条件推理（conditional reasoning）**基于"如果 P，那么 Q"的条件命题，有四种基本推理形式，其中只有两种逻辑有效：

$$\text{如果 } P，\text{那么 } Q$$

| 形式 | 逻辑名称 | 有效性 | 例子 |
| --- | --- | --- | --- |
| P → Q（肯定前件） | 肯定前件（MP） | 有效 | 下雨则地湿；下雨了 ⇒ 地湿 |
| 非 Q → 非 P（否定后件） | 否定后件（MT） | 有效 | 下雨则地湿；地不湿 ⇒ 没下雨 |
| Q → P（肯定后件） | 肯定后件（AC） | **无效** | 地湿 ⇒ 下雨？（可能是洒水车） |
| 非 P → 非 Q（否定前件） | 否定前件（DA） | **无效** | 没下雨 ⇒ 地不湿？（可能洒水） |

**关键发现：人对 MP 几乎不犯错，对 MT 常犯错，对 AC 与 DA
极易犯错（把它们误当有效）**。逻辑上，只有 MP 与 MT 是有效的；心理上，
人们倾向于把"如果 P 则 Q"误解为"当且仅当"（双条件），于是认为"地湿 =
下过雨"。<span class="marginnote">
条件推理的"四种卡"实验总结出一个稳定的模式：
<strong>MP > MT > AC ≈ DA</strong>（正确率递减）。
逻辑学家与心理学家的解释分两派：逻辑规则派认为人内化了 MP/MT 规则但常常用错；
心智模型派认为人是在脑中"模拟可能世界"——"P→Q"在脑中被建模为"P 出现时 Q
也出现"，于是忽视"非 P 时 Q 也可能发生"的可能。</span>

## 3 内容与语境的影响：推理不是纯逻辑

人类推理与逻辑机器的最大差别：**内容、语境与经验强烈介入**。同样的逻辑形式，
换上不同内容，表现天差地别：

**具体 vs 抽象**：抽象的"如果 P 则 Q"错误率极高；
  换成有意义的现实规则（"如果要喝酒，就必须满 18 岁"），错误率骤降。
**社会契约（social contract）**：**"如果享受福利，
  就必须满足条件"**这类社会规则，人们几乎能完美推理——科斯米德斯与托比提出，
  人类推理能力在"社会交换/契约"领域是**进化特化**的：
  抓骗子（有人享受了福利却没满足条件）是进化压力锻造的能力。
**义务与许可（permissions）**：
  涉及"允许/必须"的规则推理尤其好——可能因为义务推理对应着社会规范的执行。

**这些证据表明：人类推理不是"冷冰冰的逻辑引擎"，
而是"内容敏感的心理机器"**——逻辑形式只是推理的一个维度，内容、知识、
进化压力都参与其中。<span class="marginnote">
科斯米德斯的"进化推理"理论最有冲击力的主张：人类的逻辑推理能力是为解决
<strong>社会交换</strong>问题（识别"欺骗者"）而进化出来的，
而非为抽象逻辑。这解释了为何同一逻辑形式，在社会契约内容上表现极佳、
在抽象内容上表现极差——推理系统"内嵌"了社会性的规则。</span>

## 4 解释人类推理的两大理论

人类为何系统性地偏离逻辑？两大理论主导：

**逻辑规则理论（mental logic theory）**：
人脑有一套**抽象的逻辑规则**（MP、MT 等），推理就是应用这些规则。
错误来自规则的应用失败（忘了用、用错规则）。预测：推理的难易取决于规则的复杂性。

**心智模型理论（mental model theory）**（约翰逊-莱尔德）：
人脑推理不是应用规则，而是**建构与操纵"心智模型"**——对"哪些可能性成立"的模拟。
人脑用尽量少的模型工作（认知经济），因此"只需一个模型"的推理容易，
"需要多个模型"的推理难。条件推理的错误，来自未能考虑"非 P 但 Q"的额外可能。
<span class="marginnote">心智模型理论能解释三段论表现：
人们只构造一个代表性模型（"所有 A 是 B"想象成"A 的每个个体都是 B"），
忽略了"可能有 A 之外的东西也是 B"——于是把"所有 A 是 B"当成"所有 B
是 A"。它把推理错误归因于"模型的完备性"，而非"规则的失用"。</span>

两派争论未决，但都承认一个共同事实：
**人类推理的默认策略是"省力"**——倾向于用最少的信息、最少的模型得出结论，
代价是系统性错误。

## 5 核心对比表：三种演绎推理形式

| 形式 | 结构 | 有效推理 | 人易犯的错误 |
| --- | --- | --- | --- |
| 三段论 | A-B, B-C ⇒ A-C | 按形式判断 | 信念偏差、换位谬误 |
| 条件推理 | P→Q | MP、MT | AC、DA 误当有效 |
| 义务推理 | 若享受则须满足 | 找"享受且未满足"者 | 抽象内容下失灵 |

**记法：三段论看"形式"，条件推理看"四种卡"，内容一换表现就变。**

## 6 小结

- **演绎推理**是保真推理：前提真则结论必真；三段论与条件推理是两大范式。
- 三段论上人犯**信念偏差**（按现实合理性而非逻辑形式判断）与换位谬误。
- 条件推理只有 **MP 与 MT 有效**，人却常把 AC、DA 误当有效。
- **内容与语境强烈影响推理**：社会契约内容表现极佳，抽象内容表现差——暗示进化特化。
- 两大理论：**逻辑规则理论**与**心智模型理论**，共同承认人类推理"默认省力"。

人又如何系统地偏向"证实"而忽略"证伪"。
