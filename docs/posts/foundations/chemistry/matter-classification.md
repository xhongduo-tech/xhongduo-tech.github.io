## 为什么从「分类」开始

化学研究的对象是物质——据估算，人类已知的化学物质已超过一亿种。面对这样一个庞大的「物质集合」，第一个动作不是逐个研究，而是**分类**：先给每一类划出清晰的边界，再为每个成员贴上标签。这套「先分类、再研究」的方法，化学上称为**分类法**；其中按某一标准把物质逐层细分、像一棵倒挂的树那样层层展开的方法，就叫**树状分类法（tree classification）**。

为什么把分类放在整个化学专题的第一课？因为**分类是化学组织世界的方式**。后续每一课——从钠、氯到有机高分子——都默认你掌握了一套坐标：这是单质还是化合物？是酸、碱还是盐？属于溶液还是胶体？没有这套坐标，一切描述都无从谈起。它之于化学，正如集合之于数学、坐标系之于几何：是「第一句话怎么读」。

## 1 树状分类法：先划边界，再贴标签

树状分类法最经典的一棵树，是对「物质」挥下的第一刀——按**组成**把物质分为**混合物**与**纯净物**。

- **混合物（mixture）**：由两种或多种物质混合而成，各组分保持各自原有的化学性质，没有固定的组成与熔、沸点。空气、海水、合金、食盐水都是混合物。
- **纯净物（pure substance）**：由一种物质组成，有固定的组成和熔、沸点。水（$\ce{H2O}$）、氧气、氯化钠都是纯净物。

**辨析｜易错点：纯净物 ≠ 「干净」的物质。「干净」是卫生概念，「纯净」是组成概念。** 蒸馏水是纯净物，矿泉水却因溶有 $\ce{Ca^{2+}}$、$\ce{Mg^{2+}}$ 等多种离子而属于混合物；一杯看起来很「干净」的自来水同样不是纯净物。反过来，**冰与水的混合物反而是纯净物**——两者都只有 $\ce{H2O}$ 一种组成，只是分子排列方式不同，所以属于纯净物。判断纯净物与混合物的唯一标准是「含几种物质」，而不是「看起来干不干净」。<span class="marginnote">「物质的分类」与第一级《基础数学》里「集合的划分」是同一件事：把全集划分成若干互不相交的子集，要求不重不漏。学集合时建立的直觉，在这里直接变成化学的第一生产力。</span>

纯净物再按**元素组成**分下去：

- **单质（element / simple substance）**：由同一种元素组成的纯净物。氧气（$\ce{O2}$）、铁（$\ce{Fe}$）、硫（$\ce{S}$）都是单质。
- **化合物（compound）**：由不同种元素组成的纯净物。水（$\ce{H2O}$）、二氧化碳（$\ce{CO2}$）、氯化钠（$\ce{NaCl}$）都是化合物。

**辨析｜易错点：由同一种元素组成的物质不一定是单质。** 单质要求「一种元素」**且**「纯净物」。把氧气与臭氧（$\ce{O3}$）混在一起，里面只有氧元素，却是两种物质——它符合「一种元素」，却不满足「纯净物」，所以不是单质，而是混合物。同理，金刚石与石墨混在一起也不是单质。判断时两个字要一起盯住：**同种元素 + 纯净物**。<span class="marginnote">氧气与臭氧、金刚石与石墨，各自互为「同素异形体」——同一元素形成的不同单质。这个概念在选择性必修 2《物质结构与性质》中还会再见。</span>

## 2 交叉分类法：同一物质的多副面孔

树状分类法有一个前提：每次只用一个标准。但同一个物质往往同时满足多个标准，只看一棵树会漏掉它的其他身份。于是有了**交叉分类法（cross classification）**：从多个角度、按多个标准对同一对象进行分类。

以碳酸钠（$\ce{Na2CO3}$）为例——它同时有多重身份：

- 从**阳离子**看，它是**钠盐**；
- 从**酸根**看，它是**碳酸盐**；
- 从是否含氧看，它是**含氧酸盐**；
- 从组成结构看，它是**正盐**。

同一瓶碳酸钠，站在不同标准下就有不同名字。再如氧化钙（$\ce{CaO}$）：既是**氧化物**，又是**金属氧化物**，还是**碱性氧化物**，也是「钙的氧化物」。这些身份互不冲突，共同构成对它的完整描述。

**分类标准不同，结论就不同。** 讨论一个物质属于哪类之前，先要说清「按什么标准分」。这正是树状分类与交叉分类的互补关系——前者把体系纵向切透，后者把对象横向看全。<span class="marginnote">树状分类是「分层展开」，交叉分类是「多维标注」——后者更像给数据打标签。大模型把词表（vocabulary）里的每个 token 标注上词性、语义、频次等多维属性，本质上就是在对「符号世界」做一场交叉分类。</span>

## 3 分散系与胶体：混合物内部的新世界

混合物并不是一盆「浑水」，它内部也有结构。把一种（或多种）物质以细小颗粒的形式**分散**到另一种物质中所得到的体系，叫作**分散系（dispersion system）**。被分散的物质叫**分散质**，容纳它的叫**分散剂**。

- 食盐分散在水中，得到食盐水；
- 泥砂分散在水中，得到悬浊液；
- 小油滴分散在水中，得到乳浊液；
- 小液滴分散在空气中，得到雾。

这些分散系长得完全不同，本质差别在哪？在**分散质粒子的直径大小**。按直径，分散系被分为三类：

| 分散系 | 分散质粒子直径 | 举例 | 是否均一、稳定 | 能否产生丁达尔效应 |
| --- | --- | --- | --- | --- |
| 溶液 | 小于 1 nm | 食盐水、蔗糖水 | 均一、稳定 | 否 |
| 胶体 | 1 ~ 100 nm | $\ce{Fe(OH)3}$ 胶体、雾、牛奶 | 均一、较稳定（介稳性） | 是 |
| 浊液 | 大于 100 nm | 泥水、油水 | 不均一、不稳定 | 否 |

其中直径介于 1 ~ 100 nm 的一类，叫作**胶体（colloid）**。胶体粒子的尺寸恰好在可见光波长的十分之一上下，于是产生了一种标志性现象——**丁达尔效应（Tyndall effect）**：当一束光透过胶体时，从侧面可以看到一条光亮的「通路」，这是胶体粒子对光发生散射造成的；而溶液粒子太小、浊液粒子太大，都不产生明显散射。因此，**用一束激光可以一秒分辨溶液与胶体**——这是鉴别两者的最简便方法。

**辨析｜易错点：丁达尔效应是胶体的「特征现象」，却不是胶体与溶液的「本质区别」。** 本质区别是**分散质粒子直径是否在 1 ~ 100 nm 之间**；丁达尔效应只是这个直径差异带来的可观测后果。考试常说「用丁达尔效应区分溶液与胶体」，这是正确做法；但若问「本质区别」，答案必须是粒子直径，而不是现象本身。

除丁达尔效应外，胶体还有**聚沉**（加入电解质或加热，胶体粒子聚成较大颗粒而沉降）与**渗析**（用半透膜把胶体粒子与溶液中更小的离子、分子分开）等性质。实验室制备 $\ce{Fe(OH)3}$ 胶体，是把饱和氯化铁溶液滴入沸水：

$$
\ce{FeCl3 + 3H2O ->[\Delta] Fe(OH)3(胶体) + 3HCl}
$$

<span class="marginnote">纳米材料的尺寸恰好落在胶体的「粒子直径」区间（1~100 nm）内，胶体化学由此成为纳米科技的基础语言之一——一次看似古老的三分类，悄悄通向了前沿。</span>

## 4 公式解析：一条转化链的四个台阶

物质的分类是「静态地看」，物质的转化则是「动态地看」：纯净物之间通过化学反应互相转变。把上一节分类得到的「单质、氧化物、碱、盐」串起来，就是一条最典型的转化链。以钙为例：

$$
\ce{Ca ->[O2] CaO ->[H2O] Ca(OH)2 ->[CO2] CaCO3 v}
$$

这条链的四个台阶，逐级拆解：

- **第一步，单质 → 氧化物**：$\ce{2Ca + O2 -> 2CaO}$。钙是活泼金属单质，与氧气化合，生成碱性氧化物。反应类型：**化合反应**（多变一）。
- **第二步，氧化物 → 碱**：$\ce{CaO + H2O -> Ca(OH)2}$。碱性氧化物与水化合生成碱。这也是生活常识——生石灰（$\ce{CaO}$）加水「熟化」，放热并生成熟石灰（$\ce{Ca(OH)2}$）。反应类型：**化合反应**。
- **第三步，碱 → 盐**：$\ce{Ca(OH)2 + CO2 -> CaCO3 v + H2O}$。碱与酸性氧化物反应生成盐和水。这一反应同时解释了「澄清石灰水遇 $\ce{CO2}$ 变浑浊」——它是检验二氧化碳的经典方法。反应类型：**复分解反应**。
- **回头看一眼整条链**：钙元素从起点到终点始终没变，变的只是它的「宿主」——从单质钙，到氧化钙，到氢氧化钙，再到碳酸钙。**元素的种类在化学反应前后保持不变**，这就是**质量守恒定律**的微观含义。正因为原子不灭，转化链才能一级一级搭上去。

最后一步的配平可以这样核对：左边 $\ce{Ca(OH)2}$ 里钙 1、氧 2、氢 2，$\ce{CO2}$ 里碳 1、氧 2；右边 $\ce{CaCO3}$ 里钙 1、碳 1、氧 3，$\ce{H2O}$ 里氢 2、氧 1。两边钙、碳、氢、氧的原子数分别为 1、1、2、4，全部相等。**配平的本质，就是让方程两边每种原子的数目一一相等**——这正是下一章「物质的量」做定量计算的前提。

## 5 物质的转化：一张「单质—化合物」的地图

单质与化合物之间、各类化合物之间的转化并非随意，而是有规律可循。把分类与转化画在同一张图上，就得到一张「物质转化关系地图」：

- **金属路线**：金属单质 → 金属氧化物 → 碱 → 盐。
- **非金属路线**：非金属单质 → 酸性氧化物 → 酸 → 盐。
- **盐的两翼**：酸 + 碱 → 盐 + 水（中和反应）；金属 + 盐溶液 → 新金属 + 新盐（置换反应）。

这张地图还对应着化学反应的**四大基本反应类型**：

| 反应类型 | 通式 | 例子 |
| --- | --- | --- |
| 化合反应 | $\ce{A + B -> AB}$ | $\ce{CaO + H2O -> Ca(OH)2}$ |
| 分解反应 | $\ce{AB -> A + B}$ | $\ce{CaCO3 ->[\Delta] CaO + CO2 ^}$ |
| 置换反应 | $\ce{A + BC -> AC + B}$ | $\ce{Fe + CuSO4 -> FeSO4 + Cu}$ |
| 复分解反应 | $\ce{AB + CD -> AD + CB}$ | $\ce{NaOH + HCl -> NaCl + H2O}$ |

注意，「四大基本反应类型」是按反应的**形式**分类，而「氧化还原 / 非氧化还原」是按反应的**实质**（有无电子转移）分类——两套标准互不从属。比如 $\ce{CaO + H2O -> Ca(OH)2}$ 既是化合反应又是非氧化还原反应，而 $\ce{Fe + CuSO4 -> FeSO4 + Cu}$ 既是置换反应又是氧化还原反应。这又是交叉分类法在化学反应上的实践。<span class="marginnote">这两套标准正是本章随后两节的主题：离子反应研究「在水溶液里实际发生了什么」，氧化还原反应研究「电子从谁转到谁」。一张分类地图，两条深入路径。</span>

<span class="marginnote">「变化中总有不变」是贯穿本博客的主旋律：物理里能量守恒，化学里质量（原子）守恒，统计里概率归一——大模型里的「不变性」（equi-variance）思想，同样在追问：哪些性质在变换之下保持不变。</span>

## 6 小结

- **物质分类**：物质分为**混合物**与**纯净物**；纯净物按元素组成分为**单质**与**化合物**。
- **两种分类法**：树状分类法按单一标准逐层细分；交叉分类法按多个标准多维标注，二者互补。
- **分散系**：按分散质粒子直径分**溶液（<1 nm）**、**胶体（1~100 nm）**、**浊液（>100 nm）**；丁达尔效应是鉴别溶液与胶体的简便方法，**本质区别是粒子直径**。
- **物质转化**：单质 → 氧化物 → 碱/酸 → 盐是典型转化路线；四大基本反应类型从形式分类，氧化还原从实质分类。
- **守恒内核**：化学反应前后**原子种类与数目不变**——每一条转化链都搭在质量守恒之上。

在下一节，我们将把物质放进水里，看看它们如何「拆开」成离子——这就是**离子反应（一）：电解质的电离**，分类法在微观世界的又一次应用。
