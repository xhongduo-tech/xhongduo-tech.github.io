# 化学平衡（三）：影响化学平衡的因素（勒夏特列原理）

## 为什么「移动平衡」需要定量与定性两套语言

上一节我们有了平衡常数 $K$ 与浓度商 $Q$ 这对定量工具。本节把「改变条件如何影响平衡」讲全：既有勒夏特列原理的定性判断，也有 $Q$ 与 $K$ 比较的定量验证，还有图像分析的直观表达。三套语言（原理、比值、图像）指向同一个结论——这才是真正掌握「平衡移动」。<span class="marginnote">勒夏特列原理（1888）是一条普适的「广义惯性」定律：体系总是试图减弱外界的改变。它在化学平衡、溶解平衡、甚至物理系统中都有体现，是「系统对扰动响应」这一思想的经典样本。</span>

## 1 浓度对平衡的影响

**规律**：增大反应物浓度（或减小生成物浓度），平衡**正移**；减小反应物浓度（或增大生成物浓度），平衡**逆移**。

**定量解释（$Q$ vs $K$）**：增大反应物浓度，$Q = \frac{c^c(C)c^d(D)}{c^a(A)c^b(B)}$ 的分母增大，$Q$ 减小，于是 $Q < K$，平衡正移。反应进行中，生成物浓度上升、反应物浓度下降，$Q$ 回升，直到 $Q$ 再次等于 $K$，建立新平衡。

**辨析｜易错点：** ①改变浓度**不改变 $K$**（$K$ 只与温度有关）——移动的结果是让 $Q$ 重新「归位」到 $K$；②**固体与纯液体的量改变不移动平衡**（其浓度视为常数）；③「增大某反应物浓度，其转化率下降、另一反应物转化率上升」——上节已述，此处呼应。

## 2 压强对平衡的影响

**规律**：增大压强，平衡向**气体分子数减少**的方向移动；减小压强，向气体分子数增加的方向移动。

**定量解释**：增大压强（缩小体积），各气体浓度同比增大，$Q$ 的分子分母按各自指数放大。若生成物气体分子总数小于反应物（$\Delta n_g < 0$），分子放大的倍数小于分母，$Q$ 减小、$Q < K$，平衡正移。<span class="marginnote">对气体反应，用「体积变化」理解更直观：加压压缩体积，体系向「占体积更小」的方向（分子数少）收缩以减弱压强。反应 $\ce{N2 + 3H2 <=> 2NH3}$ 气体分子数 4→2，加压正移。</span>

**辨析｜易错点：** ①压强只影响**有气体参与**的反应；②若反应前后气体分子数**相等**（如 $\ce{H2 + I2 <=> 2HI}$），压强改变**不移动平衡**；③「充入惰性气体」分两种：**恒温恒容**下充入，各反应气体浓度不变，平衡不动；**恒温恒压**下充入，体积增大、各反应气体浓度降低，相当于减压，平衡向分子数多方向移动。

## 3 温度对平衡的影响

**规律**：升高温度，平衡向**吸热方向**移动；降低温度，向**放热方向**移动。

**定量解释**：升温使放热反应的 $K$ 减小、吸热反应的 $K$ 增大（上节结论）。升温瞬间 $Q$ 未变，而 $K$ 变了——若反应正向吸热，升温后 $K$ 增大，$Q < K$，平衡正移。<span class="marginnote">温度是唯一同时改变「平衡位置」与「平衡常数」的因素。浓度、压强只移动 $Q$ 让 $Q$ 回归 $K$，温度直接改写 $K$ 本身——这是温度特殊性的本质。</span>

**辨析｜易错点：** ①判断温度移动方向，先看反应是吸热还是放热（由 $\Delta H$ 决定）；②升温同时加快正逆速率，但吸热方向加快更多——因此平衡向吸热方向移动；③对 $\ce{N2 + 3H2 <=> 2NH3}$（放热），升温使 $K$ 减小、氨的平衡含量下降——这正是工业合成氨「高温不利平衡、低温不利速率」矛盾的核心。

## 4 催化剂对平衡的影响

**规律**：催化剂**不移动平衡**，只缩短到达平衡的时间。

**解释**：催化剂同倍降低正逆反应的活化能，$v_{\text{正}}$ 与 $v_{\text{逆}}$ 等倍加快，平衡点（$Q = K$ 的位置）不变；只是「更快到达」。$K$ 不变、转化率不变、平衡组成不变。

**辨析｜易错点：** ①「催化剂加快反应」≠「催化剂使平衡右移」——这是高频陷阱；②催化剂不改变 $K$、不改变 $\Delta H$、不改变平衡转化率，只改变到达平衡的时间；③工业上使用催化剂是**在不动摇平衡的前提下提高产量速率**——合成氨用铁触媒就是此理。

## 5 勒夏特列原理与平衡移动的图像

**核心概念：勒夏特列原理（Le Chatelier's principle）**：改变影响平衡的一个条件，平衡将向着能够**减弱这种改变**的方向移动。

**重点：「减弱」不是「消除」**。增大压强，平衡向减压方向移动，但移动后压强仍大于原压强（只是比「不移动」时小）。「减弱」是部分抵消，不是完全恢复。

**平衡移动的图像语言**（速率—时间图）：
**浓度变化**：改变浓度瞬间，某方向速率**突变**（如增大反应物浓度，$v_{\text{正}}$ 突跳），另一方向速率不变；随后两速率重新汇合于新平衡。
**温度变化**：改变温度瞬间，**两个方向的速率同时突变**，但突变幅度不同（吸热方向幅度大）；随后再平衡。
**压强变化**：对气体分子数变化的反应，加压瞬间两速率都跳（分子数多的一侧跳得更厉害）。

**辨析｜易错点：** 读速率—时间图，先看**突变点有几处速率变化**：浓度变化只跳一个方向，温度/压强变化跳两个方向——据此可反推「条件改变的类型」，是常见考题。

## 6 平衡移动与转化率变化的综合判断

勒夏特列原理的定量应用之一是「改变条件后转化率如何变」——这是平衡移动知识的综合考题。

**核心概念：转化率变化的两类情形**。

| 条件改变 | 平衡移动 | 转化率变化 |
| --- | --- | --- |
| 增大某反应物浓度 | 正移 | 该反应物转化率**下降**、另一反应物转化率**上升** |
| 减小生成物浓度 | 正移 | 反应物转化率**上升** |
| 升温（吸热反应） | 正移 | 转化率**上升** |
| 加压（气体分子数减少） | 正移 | 转化率**上升** |

**重点：「增大某反应物」使该反应物转化率下降**——听起来反直觉，实则因为分母增大：转化率 = 转化量/起始量，起始量增大而转化量增幅有限。这个「此消彼长」规律常考。

**公式解析：判断转化率变化的步骤**

**第一步，判移动方向**：用勒夏特列或 $Q$ vs $K$ 判断平衡正移还是逆移。
**第二步，看对象**：问「哪种反应物」的转化率——不同反应物结论可能相反。
**第三步，定变化**：正移使反应物转化率上升（但被增大的那个例外）。

**结论：转化率变化 = 「移动方向 × 针对对象」联合判断**。<span class="marginnote">「增大反应物 A，A 的转化率下降、B 的转化率上升」的直觉：A 加多了，「供过于求」，A 的相对利用率（转化率）降低；B 是「稀缺方」，被更充分地利用。这个「此消彼长」与经济学中的「供需再平衡」同构——化学平衡也是「供需均衡」。</span>

**辨析｜易错点：** ①「正移」不必然「所有反应物转化率都升」——被增大的反应物是例外；②催化剂不影响转化率（不移动平衡）；③温度改变转化率的方向由吸放热决定——放热反应升温转化率下降。

**补充：平衡移动「减弱但不消除」的定量理解**。勒夏特列原理的「减弱」表述容易让人误解为「回到原状态」——定量看更清楚：改变条件后 $Q$ 偏离 $K$，平衡移动使 $Q$ 重新逼近 $K$，但新平衡的各组分浓度**不会回到**改变前的值。例如增大反应物浓度，平衡正移消耗部分反应物，但新平衡的反应物浓度仍高于原来——「减弱」是「部分抵消」而非「完全恢复」。

**补充：平衡移动与速率变化的关系**。改变条件瞬间，速率突变（平衡被打破）；随后速率「追赶」调整、重新相等（新平衡）。「平衡移动的方向 = 哪一侧速率暂时更大的方向」——增大反应物浓度，正速率瞬间增大、正快于逆，平衡正移。速率与平衡的联动是理解「突变—移动—再平衡」图像的基础。

**补充：平衡移动的综合「多条件」判断**。工业上常「多条件联合」调控平衡：合成氨「加压 + 降温 + 移氨 + 过量氮」同时用——每个条件分别移动平衡、共同提高氨产率。「多个条件改变时，分别判断每个条件对平衡的方向影响、再综合」——条件之间可能相互增强或抵消。「联合调控」是工业化学的核心方法，也是「多因素分析」思维的训练。

**补充：平衡移动与「工业条件选择」的呼应**。勒夏特列原理直接指导工业：合成氨「加压 + 降温（放热）+ 移氨」让平衡右移；接触法制硫酸「过量空气 + 移出 SO₃」。「原理是调控的总纲、具体条件看反应特征」——先判断吸放热与分子数变化，再定「加压/降温/移产物」。「平衡移动原理」是化学从实验室走向工业的「桥梁」——理论指导实践。

**补充：平衡移动的「多条件综合」再提醒**。改变多个条件时，要「分别判断、综合权衡」：每个条件对平衡的方向影响可能叠加或抵消（如加压（正移）+ 移产物（正移）叠加、加压（正移）+ 升温（放热反应逆移）抵消）。「先单条件判方向、再综合看净效果」——多条件分析是平衡的应用进阶，也是工业条件设计的思维。

**补充：勒夏特列原理的「图形记忆」**。浓度改变：一条速率线突跳（另一条不变）→ 移动后两线再汇合；温度/压强改变：两条线都跳 → 吸热方向/分子数少方向跳得更多。「看图判条件」：单线跳 = 浓度、双线跳 = 温度/压强。「速率-时间图是平衡移动的『录像』」——会读图，就掌握了平衡移动的「动态全貌」。

**补充：平衡移动的「定量方向」再确认**。平衡移动方向也可用 $Q$ vs $K$ 判断：改变条件使 $Q$ 偏离 $K$ → 平衡向「使 $Q$ 回归 $K$」的方向移动。浓度改变 → $Q$ 变（$K$ 不变）；温度改变 → $K$ 变（$Q$ 不变）。「勒夏特列是定性描述、$Q$ vs $K$ 是定量判据」——两者一致、互为印证。「会用 $Q$ vs $K$，平衡方向判断就『无死角』」。

**补充：平衡移动与「工业」的再呼应**。工业平衡调控案例：合成氨（加压、降温、移氨）、硫酸接触法（过量空气、移 SO₃）、合成甲醇（高压）、加氢反应（高压）。「每个工业反应都按『反应特征』设计条件」——先分析吸放热与分子数变化，再定「加压/降温/移产物」。「平衡移动原理是工业化的『调节阀』」——理论到应用的桥梁。

**补充：勒夏特列原理的「局限」再确认**。勒夏特列原理是「经验规律」——它判断方向、不预测程度（移动多少需 $K$）。「定性有原理、定量靠常数」——方向用勒夏特列、程度用 $Q$ vs $K$。「原理是『向导』、常数是『标尺』」——两者配合使用。「理解原理的边界，才能正确应用」——「先定性、再定量」。

**补充：平衡移动的「图像」记忆再梳理**。速率-时间图：浓度改变（单线突跳）、温度/压强改变（双线突跳）。「看图判条件」是平衡图像题的核心技能。「图像是平衡移动的动态记录」——「会读图 = 会看平衡的『动画』」。「平衡移动：条件 → 突变 → 移动 → 再平衡」——图像把整个过程「拍」下来。

**补充：平衡移动的「综合应用」再确认**。平衡移动原理的应用：工业（合成氨、硫酸）、生活（碳酸饮料开盖放气——减压 CO₂ 逸出）、人体（血红蛋白携氧——氧分压高结合、低释放）。「平衡移动解释生活与生理现象」——「条件改变 → 平衡移动 → 现象变化」。「从工业到呼吸，平衡原理无处不在」——「化学平衡是理解动态世界的工具」。

## 8 小结

- 增大反应物浓度/减小生成物浓度 → 正移；固体纯液体量的变化不移动平衡。
- 增大压强 → 向气体分子数少的方向移动；分子数不变的反应不受压强影响。
- 升高温度 → 向吸热方向移动；温度改变 $K$，浓度压强只移动 $Q$。
- 催化剂**不移动平衡**，只缩短到达平衡的时间。
- **勒夏特列原理**：「减弱」而非「消除」；图像上速率突变点判断条件类型。
