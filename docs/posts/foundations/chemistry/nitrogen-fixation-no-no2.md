## 为什么从氮气开始

空气中约 $78\%$ 是氮气，但绝大多数生物无法直接利用——植物缺氮会叶片发黄，庄稼产量骤降。矛盾就在这里：**地球上最丰富的元素之一，却是生命最紧缺的资源之一**。解开这个矛盾的关键，是把 $\ce{N2}$ 中那个极强的氮氮三键打断，这叫作「氮的固定」。本节从氮气自身的惰性讲起，再看两个不稳定的含氮氧化物——一氧化氮与二氧化氮，它们构成了氮元素在自然界的「流动」通道。<span class="marginnote">氮循环是地球化学循环的重要环节：固氮→硝化→同化→反硝化。它与第一级《生物》中的物质循环、以及第八级《生态学》中生态系统能量流动直接衔接。</span>

## 1 氮气：稳定的背后是极致的惰性

**氮气（nitrogen）**：分子式 $\ce{N2}$，空气中含量最多的气体，约占体积的 $78\%$。氮原子最外层 $5$ 个电子，两个氮原子以**三键**结合，键能高达 $946\ \mathrm{kJ/mol}$——这个数值比很多化学反应的活化能还要高。<span class="marginnote">键能是衡量共价键强度的核心参数，见选择性必修2《分子结构与性质》第二章「键参数」一节。$946\ \mathrm{kJ/mol}$ 意味着打断三键极其困难，这决定了氮气在常温下的化学惰性。</span>

**核心概念：氮气化学性质稳定，但不能说「不活泼就无用」**。常温下氮气不与氧气、水、强酸强碱反应，常用作保护气（如食品充氮保鲜、焊接保护）。但在高温或放电条件下，氮气也能参与反应：

$$
\ce{N2 + O2 ->[高温或放电] 2NO}
$$

这一反应看似简单，却开启了「氮的固定」的大门——把不可利用的空气氮，变成可以参与化学反应的含氮化合物。

**辨析｜易错点：** 「稳定」不等于「不能反应」，只是需要较高条件（高温、放电、催化剂）。高考常把「氮气化学性质稳定，故不能发生化学反应」作为陷阱表述，务必警惕。

## 2 氮的固定：把惰性转化为可用

**氮的固定（nitrogen fixation）**：将游离态的氮（$\ce{N2}$）转化为化合态的氮（含氮化合物）的过程。按照实现方式可分为三类：

| 类型 | 途径 | 代表反应 |
| --- | --- | --- |
| 自然固氮 | 雷雨放电 | $\ce{N2 + O2 ->[放电] 2NO}$ |
| 生物固氮 | 豆科植物根瘤菌 | $\ce{N2 ->[\text{固氮酶}] 含氮化合物}$ |
| 人工固氮 | 工业合成氨 | $\ce{N2 + 3H2 <=>[高温高压][催化剂] 2NH3}$ |

**重点：人工固氮——哈伯—博施法改变了人类命运**。1909 年哈伯实现合成氨，一战期间博施将其工业化。合成氨使「空气变面包」成为可能，让全球人口从氮肥紧缺中解放——今天世界上约一半的氮原子进入人体前都曾经过合成氨工厂。这个反应我们会在选择性必修1《化学反应原理》「化学反应的调控」一节，从速率、平衡、条件的角度完整剖析。

雷雨固氮的完整链条是：放电生成 $\ce{NO}$ → $\ce{NO}$ 被氧化成 $\ce{NO2}$ → $\ce{NO2}$ 溶于水生成硝酸 → 硝酸随雨水进入土壤成为氮肥。这就是「一场雷雨一场肥」的化学原理。

## 3 一氧化氮与二氧化氮：氮的两种氧化物

**一氧化氮（nitric oxide, $\ce{NO}$）**：无色、难溶于水的气体。**有毒**，但它有一个反直觉的身份——人体内一种重要的信号分子（血管舒张因子），1998 年诺贝尔生理学或医学奖正是授予一氧化氮信号通路的研究。氮在 $\ce{NO}$ 中为 $+2$ 价（中间价态），**极易被氧化**：

$$
\ce{2NO + O2 -> 2NO2}
$$

$\ce{NO}$ 遇空气迅速变成红棕色——这是实验室鉴别 $\ce{NO}$ 的简便方法（在空气中观察颜色变化）。

**二氧化氮（nitrogen dioxide, $\ce{NO2}$）**：红棕色、有刺激性气味的气体，溶于水与水反应生成硝酸，是重要的化工原料（工业制硝酸的中间体）：

$$
\ce{3NO2 + H2O -> 2HNO3 + NO}
$$

**辨析｜易错点：** $\ce{NO}$ 与 $\ce{O2}$ 混合立即反应，因此收集 $\ce{NO}$ 必须用**排水集气法**（不与水反应、难溶于水），不能用排空气法；而 $\ce{NO2}$ 溶于水，只能用**向上排空气法**收集。两种氧化物一溶于水、一难溶于水，收集方法正好相反，这是必考细节。

## 4 公式解析：二氧化氮与水的反应为什么是 3:1

$$
\ce{3NO2 + H2O -> 2HNO3 + NO}
$$

这条方程式最容易被记错系数，三步拆解：

- **第一步，定价态**：$\ce{NO2}$ 中氮为 $+4$ 价。反应后一部分升为 $+5$ 价（进入 $\ce{HNO3}$），另一部分降为 $+2$ 价（生成 $\ce{NO}$）。同一个 $\ce{NO2}$ 分子既有被氧化又有被还原的——这是**歧化反应**。
- **第二步，配电子**：升到 $+5$ 失去 $1$ 个电子，降到 $+2$ 得到 $2$ 个电子。得失相等：每 $1$ 个被还原的 $\ce{NO2}$ 得到 $2$ 个电子，对应 $2$ 个被氧化的 $\ce{NO2}$（各失 $1$ 个电子）。故氧化与还原的 $\ce{NO2}$ 数量比为 $2:1$。
- **第三步，写成系数**：被氧化的 $\ce{NO2}$ 生成 $2\ce{HNO3}$，被还原的 $1\ce{NO2}$ 生成 $\ce{NO}$，合计 $\ce{3NO2}$，再配水。

**结论：$3$ 体积 $\ce{NO2}$ 溶于水，只生成 $2$ 体积硝酸，且剩下 $\frac{1}{3}$ 的氮又变回 $\ce{NO}$**——这意味着工业上要用氧气把 $\ce{NO}$ 再次氧化成 $\ce{NO2}$ 循环利用。氧气与二氧化氮按 $4:1$ 通入水中可被完全吸收：$\ce{4NO2 + O2 + 2H2O -> 4HNO3}$。这类「尾气循环吸收」的定量问题，是氮氧化物计算题的经典模型。

## 5 氮氧化物与环境：光化学烟雾

氮氧化物不仅是工业中间体，也是重要的环境污染物——理解它们的「双面性」，是氮化学与环境的连接点。

**核心概念：光化学烟雾**。汽车尾气中的 $\ce{NO_x}$（$\ce{NO}$、$\ce{NO2}$）与碳氢化合物在阳光（紫外线）作用下发生系列光化学反应，生成臭氧、醛类等二次污染物，形成浅蓝色刺激性烟雾——洛杉矶光化学烟雾是著名案例。

**公式解析：光化学烟雾的化学链条**

- **第一步，源头**：$\ce{N2 + O2 ->[高温(发动机)] 2NO}$（高温下氮气与氧气化合）。
- **第二步，氧化**：$\ce{2NO + O2 -> 2NO2}$（一氧化氮被氧化）。
- **第三步，光解**：$\ce{NO2 ->[紫外线] NO + O}$（二氧化氮光解出活泼氧原子）→ 氧原子与 $\ce{O2}$ 生成 $\ce{O3}$（臭氧）——臭氧与醛类是烟雾的刺激成分。

**结论：光化学烟雾 = 「NOₓ + 烃 + 阳光」的光化学反应**。<span class="marginnote">光化学烟雾的治理思路是「源头削减 NOₓ」——三元催化器把尾气 NOₓ 还原成 N₂（$\ce{2NO + 2CO ->[催化剂] N2 + 2CO2}$）。这是「认识机理 → 源头治理」的环保化学样板：先搞清化学链条，才能设计治理方案。环境化学（第八级《环境工程》）中臭氧生成、自由基链式反应都是这里的光化学延伸。</span>

**辨析｜易错点：** ①光化学烟雾的元凶是 $\ce{NO_x}$（不是 $\ce{CO2}$——那是温室效应）；②「高温燃烧生成 NO」——内燃机高温是 NOₓ 的来源，「降低燃烧温度」也是减排思路；③臭氧在大气平流层（保护层）与近地面（污染物）的「两副面孔」——同一分子、不同位置、不同角色。

**补充：氮的「价态地图」与氧化还原规律**。氮元素常见价态：-3（$\ce{NH3}$）、0（$\ce{N2}$）、+2（$\ce{NO}$）、+4（$\ce{NO2}$）、+5（$\ce{HNO3}$）。最低价只有还原性（氨被氧化）、最高价只有氧化性（硝酸被还原）、中间价态双向（NO 既被氧化又被还原）。「价态决定氧化还原性格」——这张氮的价态地图，是理解氮化学的总纲，与硫的价态图（必修二）同构。

**补充：NO 的「生物学双面性」**。一氧化氮是「双面分子」：高浓度有毒（光化学烟雾、细胞毒），低浓度却是重要的生理信号——血管舒张因子（调节血压）、神经递质（学习记忆）、免疫信号（巨噬细胞杀灭病原）。1998 年诺贝尔生理学或医学奖授予 NO 信号通路研究。「同一分子、浓度决定角色」——化学物质的生物学效应常是「剂量的函数」。

**补充：氮的「固定」与「循环」再梳理**。氮循环：固氮（合成氨、根瘤菌、闪电）→ 硝化（氨 → 硝酸盐）→ 吸收（植物利用）→ 反硝化（硝酸盐 → 氮气）。「氮循环是地球化学循环的关键环节」——人类活动（化肥、燃烧）改变了氮循环（富营养化、氮沉降）。「理解氮循环 = 理解农业与环境的连接」——氮的化学在生态尺度上展开。

**补充：氮氧化物的「检验」与「收集」**。NO 无色、遇空气变红棕色（$\ce{2NO + O2 -> 2NO2}$）；NO₂ 红棕色、刺激性。收集：NO 用排水法（不与水反应、易被空气氧化）；NO₂ 用向上排空气法（溶于水）。「NO 遇空气变棕、NO₂ 本身棕」——颜色是鉴别信号。「气体的收集看溶解性与密度、鉴别看特征颜色」。

**补充：氮的「固定」与现代农业再深化**。氮肥的化学：合成氨 → 硝酸（氧化氨）→ 硝酸铵；氨 → 尿素（$\ce{2NH3 + CO2 ->[高温高压] CO(NH2)2 + H2O}$）。「氮肥是合成氨的下游产品」——「从空气到氮肥」是哈伯法的完整链条。「人工固氮养活了世界一半人口」——合成氨是「20 世纪最重要的发明之一」。「理解氮的固定，就理解了现代农业的化学根基」。

**补充：氮氧化物的「收集」与「检验」再确认**。NO 排水收集（难溶、不与水反应、易被空气氧化）；NO₂ 向上排空气（溶于水）。检验：NO 遇空气变红棕（$\ce{2NO + O2 -> 2NO2}$）、NO₂ 本身红棕。「气体收集看『溶解性 + 密度 + 反应性』」——「NO 怕氧、NO₂ 怕水」。「气体的鉴别看特征颜色」——「氮氧化物的颜色是它的名片」。

**补充：氮的「氧化物」家族再梳理**。氮氧化物家族：$\ce{N2O}$（笑气）、$\ce{NO}$（一氧化氮）、$\ce{NO2}$（二氧化氮）、$\ce{N2O4}$（四氧化二氮，NO₂ 二聚）。「氮的氧化物是『价态家族』」——+1、+2、+4 价的氮氧化物。「氮氧化物的用途：$\ce{N2O}$ 麻醉、$\ce{NO}$ 信号分子、$\ce{N2O4}$ 火箭推进剂」。「氮氧化物的化学与工业、医学、航天相连」——「一个家族、多方角色」。

**补充：氮的「固定」方式的比较再梳理**。固氮三方式：自然固氮（放电）、生物固氮（根瘤菌）、人工固氮（合成氨）。「人工固氮让氮肥大规模生产」——「哈伯法改变农业」。「生物固氮最绿色（常温常压、固氮酶）」——「酶的效率远超哈伯法」。「固氮方式的对比：自然 vs 生物 vs 工业」——「理解固氮，就理解氮循环与农业」。

## 7 小结

- 氮气含极强三键（键能 $946\ \mathrm{kJ/mol}$），**常温惰性**，但高温/放电下可与氧反应。
- **氮的固定**：游离氮→化合氮，分自然、生物、人工三类；人工固氮的核心是哈伯合成氨。
- $\ce{NO}$：无色难溶，极易被氧化成 $\ce{NO2}$；排水集气法收集。
- $\ce{NO2}$：红棕色，溶于水歧化为硝酸与 $\ce{NO}$；向上排空气法收集。
- 二氧化氮与水反应的系数 $\ce{3NO2 + H2O -> 2HNO3 + NO}$，本质是 $+4$ 价氮的**歧化**。
