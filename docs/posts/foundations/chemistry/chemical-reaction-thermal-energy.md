## 为什么化学反应总是「带能量出场」

初中我们就知道燃烧放热，但一个更深的问题是：**能量藏在哪里？** 答案是化学键。化学反应的本质是**旧键断裂、新键生成**，而这两步分别需要吸收能量与释放能量——能量差就以热能的形式表现出来。这节课是「化学反应与能量」的第一课，它既为必修第二册后面的电能（原电池）铺路，也是选择性必修1《反应热与焓变》的直观基础。<span class="marginnote">能量问题贯穿所有学科：化学用「化学键」解释反应热，物理用「能量守恒」约束一切过程，而第一级《基础物理》的热学与第三级《热力学》会给出更严格的能量语言。化学热力学是二者在「反应」上的交汇。</span>

## 1 放热反应与吸热反应

**核心概念：放热反应与吸热反应。** 化学反应中，释放热量的反应叫**放热反应**（体系能量降低，环境温度升高）；吸收热量的反应叫**吸热反应**（体系能量升高，环境温度降低）。

常见的放热反应与吸热反应要背到条件反射：

| 放热反应 | 吸热反应 |
| --- | --- |
| 所有燃烧反应 | 大多数分解反应（如 $\ce{CaCO3 ->[\Delta] CaO + CO2 ^}$） |
| 酸碱中和反应 | 碳与二氧化碳的反应 $\ce{C + CO2 ->[高温] 2CO}$ |
| 金属与酸的反应 | 氢氧化钡与氯化铵的反应 |
| 铝热反应、大多数化合反应 | 碳与水蒸气的反应 |

**辨析｜易错点：** 「放热反应」不等于「常温自发进行」。有些放热反应需要加热引发（如铝热反应需要引燃、碳燃烧需要点燃）——**加热只是提供启动所需的活化能，反应本身放热**。反过来说，吸热反应也不一定需要持续加热。判断放热还是吸热，要看反应过程中能量的净流向，而不是看是否用了酒精灯。

## 2 化学键：能量的「储蓄罐」与「释放口」

**为什么有的反应放热、有的吸热？** 关键在于**断键吸能与成键放能的差值**。

- **断键吸能**：断裂 $\ce{H-H}$、$\ce{O=O}$ 等旧键，需要吸收能量——键能越大，断键越难、吸能越多。
- **成键放能**：形成 $\ce{H-O}$ 等新键，会释放能量。

若**成键释放的总能量 > 断键吸收的总能量**，多余能量以热能形式放出，反应放热；反之则吸热。这可以写成一个朴素的关系式：

$$
\Delta E_{\text{反应}} = E_{\text{断键吸能}} - E_{\text{成键放能}}
$$

当 $E_{\text{断键}} < E_{\text{成键}}$ 时 $\Delta E$ 为负，放热；当 $E_{\text{断键}} > E_{\text{成键}}$ 时 $\Delta E$ 为正，吸热。<span class="marginnote">氢气和氯气反应放热的原因正在于此：断开 $\ce{H-H}$（436 kJ/mol）与 $\ce{Cl-Cl}$（243 kJ/mol）共吸 679 kJ，形成 2 mol $\ce{H-Cl}$（431×2=862 kJ）放 862 kJ，净放出 183 kJ。数字让你更接近「化学反应是能量交易」的感觉。</span>

## 3 公式解析：用键能估算反应热

以氢气在氯气中燃烧为例：

$$
\ce{H2 + Cl2 -> 2HCl}
$$

三步拆解：

- **第一步，列断键**：反应物 $\ce{H2}$ 含 1 mol $\ce{H-H}$，$\ce{Cl2}$ 含 1 mol $\ce{Cl-Cl}$。断键共吸 $436 + 243 = 679\ \mathrm{kJ}$。
- **第二步，列成键**：生成 $2\ \mathrm{mol}$ $\ce{H-Cl}$ 键，成键共放 $2 \times 431 = 862\ \mathrm{kJ}$。
- **第三步，求差值**：$862 - 679 = 183\ \mathrm{kJ}$，为正值意味着成键放能多于断键吸能，**反应放热 $183\ \mathrm{kJ/mol}$**。

**结论：化学反应的吸放热，本质上是一道「能量加减法」**——断键把能量存起来，成键把能量吐出来，差值就是反应热。这个「键能法」到选择性必修1会升级为更严格的焓变计算，但直观逻辑从今天就该立住。

## 4 能量变化图与生活应用

用一张「能量—反应进程」图可以直观表达吸放热：横轴是反应进程，纵轴是体系能量。放热反应中反应物能量高于生成物（能量「下坡」，多余能量散出）；吸热反应中生成物能量高于反应物（能量「上坡」）。

**重点：化学能是能量的一种形式，遵循能量守恒定律。** 反应前后的总能量（化学能 + 热能 + 其他）不变，所谓「放热」是把化学能转化为热能，「吸热」是把热能转化为化学能储存起来。<span class="marginnote">这一守恒观与第一级《基础物理》的机械能守恒、第二级《热力学第一定律》一脉相承。热化学计算就是给能量守恒配上化学方程式的记账本。</span>

生活中到处都是反应热的应用：自热火锅利用氧化钙与水的放热反应；燃料（煤、天然气）燃烧是现代社会能量的主要来源；化学暖手袋、冷敷袋也是放热/吸热反应的日常产品。

## 5 吸放热与稳定性的关系

反应是放热还是吸热，直接关系到**生成物是否更稳定**——这是「能量最低原理」在化学中的体现。

**核心概念：能量越低越稳定**。放热反应（$\Delta H < 0$）中生成物总能量低于反应物——生成物更「安稳」；吸热反应反之（生成物能量更高、更不稳定）。

**重点：稳定性判断的两步**。①看 $\Delta H$ 符号：放热 → 生成物能量低 → 更稳定；②看键能：生成物键能总和大（键更牢固）→ 更稳定。两者一致：放热反应的生成物键能总和更大。

**公式解析：比较 $\ce{H2}$ 与 $\ce{F2}$ 的稳定性**

**第一步，查键能**：$\ce{H-H}$ 436、$\ce{F-F}$ 157（kJ/mol）——$\ce{H-H}$ 键能更大。
**第二步，定稳定性**：键能越大键越难断、分子越稳定——$\ce{H2}$ 比 $\ce{F2}$ 稳定。
**第三步，联系反应**：$\ce{F2}$ 键能小 → 易断 → 氟气化学性质活泼（易反应）——「键能小 = 活泼」。

**结论：稳定性 = 能量低 = 键能大**——放热反应的产物更稳定，是能量最低原理的体现。<span class="marginnote">「能量最低、键能越大越稳定」是化学稳定性的统一判据。它解释：氮气三键键能巨大所以极稳定、氟气单键键能小所以极活泼。这个「键能—稳定性—活泼性」链条在惰性气体（全满结构最稳定）与稀有气体的发现史中都有体现。</span>

**辨析｜易错点：** ①放热反应产物「更稳定」是相对反应物而言——不代表产物绝对稳定；②「键能大 = 稳定」适用于同类型比较（气态分子），离子化合物看晶格能；③稳定性与「活性」相反：越稳定越不活泼（稀有气体稳定 → 化学惰性）。

**补充：能量变化与反应自发性的关系预告**。放热反应（$\Delta H<0$）常自发、但非必然——热效应只是「方向」的一个因素，另一个是「混乱度（熵）」。放热 + 熵增的反应任何温度都自发（燃烧）；放热 + 熵减的低温自发（氨的合成）；吸热 + 熵增的高温自发（碳酸钙分解）。「焓」与「熵」的配合，是选择性必修1《化学反应的方向》的主题——本节先立「放热是常见驱动力」的直觉。

**补充：反应热与键能、燃烧热的关系网络**。反应热有三种求法：键能法（微观）、盖斯定律（路径）、燃烧热差（数据）——三者殊途同归，互相印证。热化学是「能量守恒」在化学中的体现：化学反应中能量既不能凭空产生也不能消灭，只能从化学能转化为热能等形式——「能量守恒」是热化学的第一原理。

**补充：常见放热/吸热反应的「反直觉」辨析**。大多数放热反应仍需「启动能量」（活化能）：碳燃烧放热但要点燃、铝热反应放热但要引燃——「放热 ≠ 常温自发进行」。而吸热反应中，$\ce{C + CO2 ->[高温] 2CO}$（高温吸热）、氢氧化钡与氯化铵（常温吸热剧烈降温）——「吸热 ≠ 需要持续加热」。「放热吸热看净能量、启动与否看活化能」——两个维度分开判断。

**补充：反应热与「能源」的连接**。反应热的大小决定燃料的价值：氢气燃烧热 285.8 kJ/mol、甲烷 890.3 kJ/mol——「单位质量的能量」是燃料选择的核心指标。反应热还关联「食物的热量」（葡萄糖氧化 ~2800 kJ/mol——身体的「燃料」）。「反应热是能量的量化」——从燃料到食物，反应热是理解「化学能 → 热能 → 动能/生命活动」的计量尺。

**补充：能量变化与「化学键的断裂与形成」**。反应热 = 断键吸收的能量 − 成键释放的能量：断键吸能（破坏稳定结构）、成键放能（趋向稳定）。放热反应 = 成键释放 > 断键吸收（生成物键更强）。「反应的本质是旧键断裂、新键生成」——能量变化是「键的收支账」。「用键能理解反应热」是微观视角，与宏观的 $\Delta H$ 定义互相印证。

**补充：反应热的「工业意义」**。反应热决定工业反应的能量管理：放热反应（合成氨、硫酸）要「移热防过热」、吸热反应（裂解、炼铁）要「供热保温度」。「反应热的正负与大小 → 反应器的换热设计」——热管理是化工设计的关键。「反应热是化学过程的『能源账本』」——从实验室到工厂，反应热知识决定能量效率与安全。

**补充：放热吸热与「能量守恒」**。反应放热 = 化学能转化为热能；吸热 = 热能转化为化学能储存——总能量守恒。「化学能是能量的一种形式，与热能、电能、光能互相转化」——原电池（化学能→电能）、光合作用（光能→化学能）都是能量转化的案例。「理解能量转化，就理解了化学反应的『能量视角』」——能量守恒是化学的第一性原理。

**补充：反应热的「生活实例」再梳理**。生活处处是反应热：自热火锅（氧化钙与水放热）、暖宝宝（铁氧化放热）、冷敷袋（硝酸铵溶解吸热）、燃烧取暖（燃料放热）。「反应热不是书本概念，是日常的温度」——放热吸热时刻在身边。「用反应热解释生活现象」是化学素养的体现——「生活中的化学」从能量开始。

**补充：反应热与「化学键」的能量观再深化**。化学反应的能量本质：旧键断裂吸能、新键生成放能——反应热是「键的收支差」。「放热 = 生成物键更强、吸热 = 反应物键更强」。「从键能理解反应热」是微观解释、「从 ΔH 定义」是宏观语言——两者统一。「能量变化源于键的变化」——化学键是能量的『容器』，反应是『换容器』的过程。

**补充：吸热反应的「典型」再梳理**。常见吸热反应：大多数分解反应（$\ce{CaCO3}$ 分解）、碳与二氧化碳（$\ce{C + CO2 ->[高温] 2CO}$）、碳与水蒸气（制水煤气）、氢氧化钡与氯化铵、光合作用（光能 → 化学能）。「吸热反应把热能转化为化学能储存」——「储蓄能量的反应」。「识别吸放热：先记典型、再分析键能」——「背典型 + 懂原理」双保险。

## 8 小结

- 反应分**放热**与**吸热**两类；判断标准是能量净流向，不是是否加热。
- 反应热 = **断键吸能 − 成键放能**；断键吸、成键放。
- 常见放热：燃烧、中和、金属与酸；常见吸热：多数分解、$\ce{C + CO2}$、$\ce{Ba(OH)2 + NH4Cl}$。
- 能量变化遵循**能量守恒**，化学能与热能相互转化。
- 用键能可以估算反应热：$\ce{H2 + Cl2 -> 2HCl}$ 放热约 $183\ \mathrm{kJ}$。
