## 为什么从「电离」开始

上一节我们把物质分好了类：纯净物、化合物、酸、碱、盐……可分类只回答了「它是什么」，还没回答「它在水里会变成什么」。这一节，我们把这些化合物放进水中。

先看一个生活事实：厨房里的食盐（氯化钠）是干燥的白色晶体，它**不导电**；但把食盐溶进水里，得到的食盐水**能导电**；把食盐加热到熔融状态，熔融的食盐**也能导电**。同一种物质，为什么状态一换，导电性就完全不同？谜底藏在「离子能不能自由移动」上。

这件事值得单开一课，因为**把物质放进水里、看它如何拆成离子**，是全部溶液化学的入口。离子反应、酸碱中和、盐类水解、电化学——后续课程里最频繁出场的角色，今天全部登场。而在「从极限到大模型」的坐标系里，这一课是第一处「宏观性质 ← 微观结构」的正式演练：你用眼睛看到的是导电与否，本质却是离子在晶格与溶液之间的「被束缚」与「自由」。

## 1 电解质与非电解质

化学家把化合物按「在水溶液或熔融状态下能否导电」一分为二：

**电解质（electrolyte）**：在水溶液中或熔融状态下能够导电的化合物。
**非电解质（nonelectrolyte）**：在水溶液中和熔融状态下都不能导电的化合物。

判断一个物质属于哪类，按三步走：

- **第一步，看它是不是化合物。** 单质与混合物直接出局——它们既不是电解质也不是非电解质。<span class="marginnote">这是最容易被忽略的第一道筛子：铜、石墨能导电，但它们是单质；盐酸、食盐水能导电，但它们是混合物。「电解质」三个字的前提是「化合物」。</span>
**第二步，看它在水溶液或熔融状态下能否导电。** 二者**居其一**能导电即可。
**第三步，下结论。** 满足第一步且第二步为「能」，就是电解质；否则是非电解质。

常见物质的归类：

| 类别 | 常见例子 |
| --- | --- |
| 电解质 | 酸：$\ce{HCl}$、$\ce{H2SO4}$、$\ce{HNO3}$；碱：$\ce{NaOH}$、$\ce{KOH}$、$\ce{Ca(OH)2}$；盐：$\ce{NaCl}$、$\ce{Na2CO3}$、$\ce{CuSO4}$；活泼金属氧化物：$\ce{Na2O}$、$\ce{CaO}$；水 |
| 非电解质 | 蔗糖（$\ce{C12H22O11}$）、酒精（$\ce{C2H5OH}$）、$\ce{CO2}$、$\ce{SO2}$、$\ce{SO3}$、$\ce{NH3}$、甲烷（$\ce{CH4}$） |

**辨析｜易错点：$\ce{CO2}$、$\ce{SO2}$、$\ce{NH3}$ 的水溶液都能导电，但它们都是非电解质。** 因为导电的并不是它们自己，而是它们与水反应生成的化合物——$\ce{H2CO3}$、$\ce{H2SO3}$、$\ce{NH3.H2O}$ 才是电解质。判断「谁是电解质」，要盯住「**溶于水后直接电离出离子的那种化合物**」，而不是「谁的溶液能导电」。<span class="marginnote">同理，难溶盐如 $\ce{CaCO3}$、$\ce{BaSO4}$ 反而是电解质：它们只是「溶得少」，不是「不电离」——熔融状态下完全导电，溶于水的部分也完全电离。「溶解性」与「电解质性」是两把不同的尺子。</span>

这一区分背后的历史值得记住。1887 年，瑞典化学家**斯万特 · 阿伦尼乌斯（Svante Arrhenius）**在博士论文中提出「电解质在水溶液中自发解离成离子」的电离理论。当时的主流观点认为溶液只有在通电时才会产生离子，这个理论被评审委员会判为最低等。而正是这个「离经叛道」的观点，最终为他赢得了 1903 年的诺贝尔化学奖。<span class="marginnote">电离理论是化学史上「从现象反推微观机制」的经典范例：没有显微镜能看见离子，但导电性的数据摆在那里，理论的唯一要求是敢相信它。</span>

## 2 导电的秘密：电离

要理解导电，先问一句：电流到底是什么？**电流是电荷的定向移动。** 金属导电，靠的是内部大量**自由电子**；而电解质溶液导电，靠的是**自由移动的离子**。

把这条标准套回氯化钠：

- **干燥的氯化钠晶体不导电**——晶体里确实满是 $\ce{Na+}$ 与 $\ce{Cl-}$，但它们被晶格严格地束缚在固定位置上，只能在原地振动，不能定向移动。
- **氯化钠溶液导电**——溶于水后，离子挣脱晶格的束缚，可以在水中自由移动，通电时发生定向移动形成电流。
- **熔融氯化钠导电**——高温使晶格解体，离子重新获得自由。

离子「挣脱束缚」的这个过程，就是本课的核心概念：

**电离（ionization）**：电解质溶于水或受热熔化时，离解成自由移动的离子的过程。

溶于水与熔融，是打破晶格的两种方式。熔融靠「加热」提供能量；溶于水则靠**水分子**——水是极性分子，氧端带部分负电、氢端带部分正电，它们像一群微型「镊子」，把晶体表面的阳离子与阴离子逐个「夹走」并包裹起来，形成**水合离子**。

![氯化钠在水中的电离示意图](/images/chemistry/electrolyte-ionization-1.svg)

**辨析｜易错点：电离不需要通电，与「电解」是两回事。** 电解（electrolysis）是通电使电解质发生分解的化学变化，伴随电子得失，属于氧化还原反应；而电离是电解质溶于水或受热熔化时自发的离解过程，不需要外加电场。一字之差，机制完全不同。

## 3 电离方程式

电离的过程可以用化学语言写下来，这就是**电离方程式**。它把「电解质拆成什么离子、各多少个」一次性写清楚：

$$\ce{NaCl -> Na+ + Cl-}$$

$$\ce{H2SO4 -> 2H+ + SO4^2-}, \qquad \ce{NaOH -> Na+ + OH-}$$

$$\ce{Ca(OH)2 -> Ca^2+ + 2OH-}, \qquad \ce{Na2CO3 -> 2Na+ + CO3^2-}$$

写电离方程式有三条纪律：

- **守恒**：左边化学式里的原子，必须一个不差地出现在右边的离子里——原子种类、数目守恒。
- **电荷**：右边所有离子的正负电荷代数和必须为零，与左边电中性一致。
- **规则**：右边不能写气体箭头「↑」或沉淀箭头「↓」——电离不产生气体、不产生沉淀，只产生离子。

对多元酸与复杂盐，离子个数要跟化学式下标对齐：$\ce{Fe2(SO4)3}$ 电离成 $\ce{2Fe^3+ + 3SO4^2-}$，离子右下角的 2 与 3 正是化学式里的下标。<span class="marginnote">弱电解质如醋酸（$\ce{CH3COOH}$）、一水合氨（$\ce{NH3.H2O}$）的电离是不完全的，电离方程式要用可逆号：$\ce{CH3COOH <=> CH3COO- + H+}$。强电解质与弱电解质的完整讨论，留到选择性必修 1《化学反应原理》第三章。</span>

## 4 公式解析：电离方程式的四步

以 $\ce{H2SO4}$ 的电离为例，把「写出一个正确电离方程式」的全过程拆成四步：

$$\ce{H2SO4 -> 2H+ + SO4^2-}$$

- **第一步，识别组成**：$\ce{H2SO4}$ 由氢元素与硫酸根原子团（$\ce{SO4}$）组成。酸的特点是能电离出氢离子。
- **第二步，写出离子**：氢以 $\ce{H+}$ 形式进入溶液，硫酸根整体以 $\ce{SO4^2-}$ 形式进入溶液——原子团（根）在电离时**作为一个整体**搬移，不拆散。<span class="marginnote">「根」整体搬移是电离与离子方程式共同的关键纪律：$\ce{SO4^2-}$、$\ce{NO3-}$、$\ce{CO3^2-}$、$\ce{OH-}$ 这些原子团在中学阶段一律看作一个不可分割的整体。</span>
- **第三步，配上个数**：化学式里氢的下标是 2，所以右边写 $\ce{2H+}$；硫酸根下标是 1，写 $\ce{SO4^2-}$。
- **第四步，核对守恒**：原子数——左边 H 2、S 1、O 4，右边 H 2、S 1、O 4，相等；电荷——右边 $2\times(+1)+(-2)=0$，与左边电中性一致。

再走一个盐的例子，$\ce{Na2CO3}$：

$$\ce{Na2CO3 -> 2Na+ + CO3^2-}$$

钠下标 2 → $\ce{2Na+}$；碳酸根整体 → $\ce{CO3^2-}$；电荷 $2\times(+1)+(-2)=0$。两条式子都同时满足原子守恒与电荷守恒，它们就一定是「合法」的电离方程式。

## 5 一张易错清单

把这一节的坑集中起来，写题与考试时逐条对照：

- **电解质判断三步曲**：先问是不是化合物，再问能否导电（水溶液或熔融，二选一），最后下结论。$\ce{CO2}$、$\ce{NH3}$、$\ce{SO2}$ 的溶液能导电，但它们是非电解质。
- **单质与混合物永远不参与分类**：铜导电但不是电解质，盐酸导电但它是混合物。
- **难溶盐是电解质**：$\ce{BaSO4}$、$\ce{CaCO3}$ 溶得少，但溶解部分完全电离，熔融也导电。
- **电离不写 ↑ ↓**：电离方程式右边只有离子，没有气体与沉淀符号。
- **原子团整体搬移**：$\ce{SO4^2-}$、$\ce{NO3-}$、$\ce{CO3^2-}$ 不拆散。

## 6 小结

- **电解质**：水溶液或熔融状态下能导电的**化合物**；判断按「化合物 → 导电 → 分类」三步走。
- **非电解质陷阱**：$\ce{CO2}$、$\ce{SO2}$、$\ce{NH3}$ 的溶液能导电，但导电的是其与水反应生成的化合物，它们本身是非电解质。
- **电离**：电解质溶于水或熔融时离解成自由移动离子的过程，**不需要通电**；电离 ≠ 电解。
- **导电机制**：自由移动的离子定向移动形成电流；晶体中离子被束缚，故干燥氯化钠不导电。
- **电离方程式**：原子守恒 + 电荷守恒；弱电解质用可逆号，原子团整体搬移。

在下一节，我们将让两种电解质溶液「相遇」，观察溶液里真正发生反应的「演员」是谁、不参与的「观众」是谁——这就是**离子反应（二）：离子反应与离子方程式**。
