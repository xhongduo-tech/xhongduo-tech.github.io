## 为什么缩聚需要「两个官能团」

上一节的加聚靠双键，本节**缩聚**靠另一种机制：**官能团间的脱水缩合**。单体必须含**两个（及以上）官能团**（二元醇、二元酸、氨基酸等），像搭扣一样不断缩合，每一步脱去小分子（水、氯化氢）。尼龙、涤纶、酚醛树脂、以及天然蛋白质与淀粉，都是缩聚的产物。<span class="marginnote">缩聚反应的历史：1930 年代卡罗瑟斯（Carothers）在杜邦合成尼龙-66，1938 年实现工业化——尼龙丝袜一度风靡世界。缩聚是「官能团化学」在材料领域的延伸：酯化、酰胺化不断重复，就得到聚酯、聚酰胺。</span>

## 1 缩聚反应的概念

**核心概念：缩合聚合反应（缩聚反应）**：单体之间通过**官能团的缩合**（脱去小分子如水、$\ce{HCl}$）相互连接成高分子的反应。

**缩聚反应的特征**：
- 单体含**两个或以上官能团**（$\ce{-OH}$、$\ce{-COOH}$、$\ce{-NH2}$ 等）；
- 反应中**生成小分子副产物**（水、氯化氢等）；
- 高分子的链节组成与单体不同（少了脱去的原子）。

**核心概念：官能度**。一个单体分子所含能参与缩聚的官能团数目。缩聚要求单体**官能度 ≥ 2**（二元醇、二元酸等）。

**辨析｜易错点：** ①缩聚**产生小分子**（对比加聚无副产物）；②缩聚单体的条件：**两个官能团**——一元醇、一元酸不能缩聚成链；③缩聚产物链节的组成 ≠ 单体（脱去了水）。

## 2 常见缩聚反应

### 聚酯：涤纶（PET）

对苯二甲酸 + 乙二醇缩聚，脱去水，生成聚对苯二甲酸乙二醇酯：

$$
n\ \ce{HOOC-C6H4-COOH + n\ HOCH2CH2OH ->[\Delta] [-OC-C6H4-COO-CH2CH2O-]_{n} + 2n\ H2O}
$$

涤纶（的确良）是最重要的合成纤维，用于衣物、瓶（PET 瓶）。

### 聚酰胺：尼龙-66

己二酸 + 己二胺缩聚，生成尼龙-66（酰胺键连接）：尼龙是第一种合成纤维（强度高、耐磨）。

### 酚醛树脂

苯酚 + 甲醛缩聚（醛与酚邻对位缩合），生成酚醛树脂（电木）——第一个合成高分子，绝缘、耐热，用于电器开关。

**重点：缩聚方程式的书写**。写缩聚方程式要注意：①两端官能团「首尾相接」；②脱去的小分子数要写对（线型缩聚中 n 个单体脱 n-1 个水分子，常近似写 n 或 2n）；③链节端基要闭合。<span class="marginnote">缩聚的计量：两个双官能团单体交替缩聚，n + n 单体脱去（2n-1）个水分子（近似写 2n）。写方程式时若一端写「-O-」一端写「-H」收尾，则脱 n 个水——教材习惯不同，关键是小分子数要与产物链节匹配。</span>

**辨析｜易错点：** ①缩聚单体的官能团「互补」：酸 + 醇（酯化）、酸 + 胺（酰胺化）、酚 + 醛（酚醛缩合）；②链节中酯基/酰胺基的写法（$\ce{-COO-}$、$\ce{-CO-NH-}$）要正确；③涤纶是聚酯、尼龙是聚酰胺——「酯 vs 酰胺」是两类缩聚产物的判别。

## 3 公式解析：由缩聚产物找单体

已知缩聚产物链节 $\ce{[-CO-C6H4-COO-CH2CH2-O-]_{n}}$，找出单体：

**第一步，找断裂点**：缩聚链节中，酯基（$\ce{-COO-}$）来自酸与醇的缩合——在酯基的 $\ce{C-O}$ 处「水解」断开。
**第二步，拆出酸**：断开的 $\ce{-CO-}$ 端加 $\ce{-OH}$ → 对苯二甲酸 $\ce{HOOC-C6H4-COOH}$（二元酸）。
**第三步，拆出醇**：断开的 $\ce{-O-}$ 端加 $\ce{-H}$ → 乙二醇 $\ce{HOCH2CH2OH}$（二元醇）。

**结论：由缩聚产物找单体——在酯基/酰胺基处水解断键、两端补 H/OH**。这是逆合成思维在缩聚中的应用。<span class="marginnote">「缩聚找单体 = 把链节在水解处拆开、补上断键原子」与蛋白质水解成氨基酸、酯水解成酸和醇是同一逻辑。逆向思维（从产物拆单体）是高分子结构与合成推断题的核心方法。</span>

**辨析｜易错点：** ①拆链节在**酯基/酰胺基**处断开，不是随便断；②补原子：酸端补 $\ce{OH}$、醇/胺端补 $\ce{H}$；③缩聚单体是「双官能团小分子」——拆出的两端必须各带一个官能团（验证）。

## 4 加聚与缩聚的对比

| 对比项 | 加聚反应 | 缩聚反应 |
| --- | --- | --- |
| 单体要求 | 含不饱和键 | 含 ≥2 官能团 |
| 副产物 | 无 | 有小分子（水等） |
| 链节组成 | = 单体 | ≠ 单体 |
| 代表 | 聚乙烯、聚氯乙烯 | 涤纶、尼龙、酚醛树脂 |
| 反应本质 | 双键打开连接 | 官能团缩合 |

**重点：判断「加聚 vs 缩聚」看单体结构与副产物**。单体含双键 → 加聚；单体含两个官能团（醇/酸/胺）→ 缩聚。加聚无副产物、缩聚有水等副产物。<span class="marginnote">加聚与缩聚的分辨口诀：加聚「不丢东西」（原子 100% 进高分子）、缩聚「丢小分子」（脱水等）。这个「丢不丢」的判断，正是绿色化学原子经济性（加聚 100%、缩聚 <100%）的体现。</span>

**辨析｜易错点：** ①加聚单体含双键、缩聚单体含双官能团——看单体结构先判断类型；②天然高分子（蛋白质、淀粉、纤维素）都是**缩聚**产物（氨基酸、葡萄糖缩合）；③写方程式时加聚不写副产物、缩聚要写小分子。

## 5 缩聚的书写与计量要点

缩聚方程式的书写与计量是最易出错的地方——「端基处理」与「小分子数」是两个关键。

**核心概念：缩聚方程式的书写规范**。

单体写结构简式，官能团在两端（如 $\ce{HOOC-...-COOH}$ 与 $\ce{HO-...-OH}$）；
产物写「链节 + $n$」，链节两端闭合；
小分子副产物（水等）写在产物端并配平数量。

**公式解析：涤纶缩聚的计量**

**第一步，写单体**：对苯二甲酸（双羧基）+ 乙二醇（双羟基）。
**第二步，数官能团对**：n 个酸 + n 个醇，形成 $2n-1$ 个酯键、脱 $2n-1$ 分子水（近似写 $2n$）。
**第三步，写方程式**：$n\ce{HOOC-C6H4-COOH} + n\ce{HOCH2CH2OH} \to \ce{[-OC-C6H4-COO-CH2CH2O-]}_{n} + (2n-1)\ce{H2O}$。

**结论：缩聚计量 = 「单体数 = 链节数，小分子数按端基算」**。<span class="marginnote">线型缩聚的小分子数：n 个双官能团单体 a-a 与 b-b 缩聚，生成（2n-1）个水分子（n 对官能团缩合，最后链两端各留一个端基）。「近似写 2n 还是精确 2n-1」看教材习惯，关键是小分子数不能写成 n 或 n/2——这是书写题的失分点。</span>

**辨析｜易错点：** ①缩聚单体的官能团「互补配对」（酸配醇、酸配胺）——写错配对则链节错误；②链节中不能有「多余端基」（双官能团单体成链后两端闭合）；③缩聚产物链节比单体「少」脱去的部分（水中的 H、OH）——别把单体结构照抄进链节。

**补充：加聚与缩聚的「本质对比」再深化**。加聚是「双键打开、原子全保留」（无副产物、原子经济 100%）；缩聚是「官能团缩合、脱小分子」（有副产物、原子利用率 <100%）。这个「丢不丢原子」的差别，对应绿色化学的原子经济性——加聚更「绿色」、缩聚更「多功能」（能引入酯键、酰胺键等功能基）。两者互补，共同撑起高分子世界。

**补充：天然高分子的缩聚本质**。蛋白质（氨基酸缩聚）、淀粉/纤维素（葡萄糖缩聚）、核酸（核苷酸缩聚）——天然高分子几乎都是缩聚产物。理解缩聚，就是理解生命大分子的「制造方式」：生物体用「缩合脱水」把单体连成链、用「水解」拆链。从人工缩聚到生物合成，是「同一化学原理、不同执行主体」——合成生物学（第九级）正在用这个原理做「生物制造」。

**补充：缩聚产物的「结构与性能」**。缩聚产物的性能由「链结构 + 官能团」决定：涤纶（聚酯）强度高、耐磨、挺括（酯键 + 苯环刚链）；尼龙（聚酰胺）坚韧耐磨（酰胺键氢键增强链间作用）。「官能团 → 链间作用 → 性能」——酯键、酰胺键不仅连接链节，还通过氢键/极性赋予高分子性能。「单体选对了，性能就定了」。

**补充：缩聚的「官能度」与交联**。单体的官能度决定产物结构：官能度 2 → 线型高分子（涤纶、尼龙）；官能度 ≥ 3 → 体型（交联）高分子（酚醛树脂固化）。「官能度 2 成线、≥3 成网」——交联使高分子热固、不溶不熔。「官能度是缩聚的结构控制旋钮」——从线型到体型，全靠单体官能度的设计。

## 7 小结

- **缩聚反应**：双官能团单体缩合、脱小分子；官能度 ≥ 2。
- 常见缩聚：涤纶（聚酯）、尼龙（聚酰胺）、酚醛树脂。
- 写方程式：两端官能团首尾相接、配平小分子数。
- 由产物找单体：在酯基/酰胺基处拆、补 H/OH。
- 加聚 vs 缩聚：双键单体 vs 双官能团单体；无副产物 vs 有小分子。
