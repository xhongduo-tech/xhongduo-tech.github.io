## 为什么从「化学计算」开始

从第二章的物质的量（摩尔、气体摩尔体积、物质的量浓度），到第三章的铁三角、合金、铝的两性，我们已经攒下两套武器：一套**描述粒子多少**的语言（物质的量），一套**描述物质反应**的方程式（氧化还原、离子反应、酸碱反应）。这一节把它们焊成一把真正的尺子——**用物质的量做化学方程式的计算**。

化学计算的意义，一句话就能说清：**方程式告诉你「反应按什么比例进行」，物质的量告诉你「一份是多少」，两者合起来，就能预测「投入多少、产出多少」。** 从实验室配溶液到化工厂定原料，本质都是这一件事。<span class="marginnote">化学计算是「化学的会计学」：方程式是「账本规则」（多少对多少），物质的量是「记账单位」（每笔的多少）。会计学要求账目平衡，化学计算要求物质守恒——第2–3章学的物质的量，终于在这里变成可以算账的硬通货。</span>

## 1 化学方程式里的「比例」到底是什么

先回到一个被反复使用却很少被追问的问题：$\ce{2H2 + O2 -> 2H2O}$ 里，系数 2、1、2 表示什么？

**重点：化学方程式的系数之比，就是各物质的物质的量之比，也是微粒数之比。**

$$\frac{n(\ce{H2})}{2} = \frac{n(\ce{O2})}{1} = \frac{n(\ce{H2O})}{2}$$

为什么是物质的量之比，而不是质量之比？因为方程式描述的是**微观粒子按个数反应**：2 个氢分子与 1 个氧分子反应生成 2 个水分子。而物质的量正是「数粒子个数」的计量——1 mol 就是约 $6.02 \times 10^{23}$ 个。**系数比 = 物质的量比 = 微粒数比**，这是化学计算的总开关。

也正因如此，方程式的系数之比**不等于**质量之比：氢气的摩尔质量是 2 g/mol，氧气是 32 g/mol，$\ce{2H2 + O2}$ 的质量比是 4:32，而不是 2:1。**凡是见到「用系数直接算质量」的，都是错的。** 要先换算成物质的量，再按系数比算。<span class="marginnote">「先换成物质的量，再按系数比」是一条颠扑不破的路径：质量 → 物质的量 → 系数比 → 物质的量 → 目标单位。五个步骤，方向单向，不许抄近路。这也是为什么化学计算的解题格式总是「列比例式」——比例式的两端必须是物质的量。</span>

## 2 化学计算的标准流程

把上面那条路径固化成一套流程，高中化学方程式的计算遵循「两写两比一答」：

1. **写**：写出正确的化学方程式并配平（配平错，全盘错）。
2. **写**：在相关物质的下方，标注已知量与未知量——已知量先换算成物质的量，未知量设为 $x$（mol）。
3. **比**：列比例式。同一反应中，两种物质的物质的量之比等于其系数之比。
4. **算**：解出 $x$，再把未知量换算成题目要求的质量、体积或浓度。
5. **答**：写清单位，回看题目要求（问质量还是体积？标准状况还是任意条件？）。

**重点：已知量的第一反应，永远是「换算成物质的量」。** 题目给出质量就用 $n = m/M$，给出标况气体体积就用 $n = V/V_m$，给出溶液就用 $n = cV$——三把钥匙对号入座：

$$n = \frac{m}{M}, \qquad n = \frac{V}{V_m}, \qquad n = cV$$

这三条公式就是第二章的全部家底，现在统一派上用场。<span class="marginnote">这三把钥匙对应物质的量那三节：$n = m/M$ 是《物质的量的单位——摩尔》，$n = V/V_m$ 是《气体摩尔体积》，$n = cV$ 是《物质的量浓度》。如果哪一步卡住，回头补对应的那一节即可——化学计算是对前面知识的「总验收」。</span>

## 3 实战一：质量与物质的量的换算

**例一**：取 5.6 g 铁粉与足量稀盐酸反应，求生成 $\ce{H2}$ 的质量。

$$\ce{Fe + 2HCl -> FeCl2 + H2 ^}$$

- **第一步，换算物质的量**：$n(\ce{Fe}) = \dfrac{m}{M} = \dfrac{5.6}{56} = 0.1\ \text{mol}$。
- **第二步，列比例式**：由方程式，$n(\ce{H2}) : n(\ce{Fe}) = 1 : 1$，故 $n(\ce{H2}) = 0.1\ \text{mol}$。
- **第三步，换算回质量**：$m(\ce{H2}) = n \cdot M = 0.1 \times 2 = 0.2\ \text{g}$。

这道题的示范意义在于：**题目给的是质量，中间必须经过物质的量这座「桥」，最后再换算回质量。** 直接从 5.6 g 按系数比 1:1 算质量是错的——因为 1 mol $\ce{Fe}$（56 g）才生成 1 mol $\ce{H2}$（2 g），质量绝不等比。

**辨析｜易错点：把系数比直接当质量比，是化学计算的第一高频错误。** 记住一句口诀：「**系数比是物质的量比，不是质量比**」。凡是遇到两种物质的质量，都要先各自除以各自的摩尔质量，再谈比例。

## 4 实战二：气体体积参与的计算

**例二**：在标准状况下，将 6.5 g 锌加入足量稀硫酸中，求生成 $\ce{H2}$ 的体积（标准状况）。

$$\ce{Zn + H2SO4 -> ZnSO4 + H2 ^}$$

- **第一步**：$n(\ce{Zn}) = \dfrac{6.5}{65} = 0.1\ \text{mol}$。
- **第二步**：由方程式，$n(\ce{H2}) = 0.1\ \text{mol}$。
- **第三步**：$V(\ce{H2}) = n \cdot V_m = 0.1 \times 22.4 = 2.24\ \text{L}$。

**重点：标准状况（0 °C、101 kPa）下，1 mol 任何气体的体积都约为 22.4 L。** 这是《气体摩尔体积》的核心结论，也是「体积 ↔ 物质的量」的唯一换算桥梁。**辨析｜易错点：22.4 L/mol 只在「标准状况」下成立。** 常温常压（如 25 °C、101 kPa）下气体摩尔体积约为 24.5 L/mol；非气体（固体、液体）不能用 $V = nV_m$；题目若只说「一定条件」，须先看清条件再套数。<span class="marginnote">「标准状况」是一个有明确定义的档位：0 °C、101 kPa。记牢它的两个数字（0 和 101），就像记住「1 atm = 101 kPa」一样。后面到选择必修1学气体分压、化学平衡时，这个「状态条件决定体积」的意识还会派上用场。</span>

## 5 实战三：溶液浓度参与的计算

**例三**：取 100 mL 2 mol/L 的盐酸与过量铁粉反应，求生成 $\ce{H2}$ 的物质的量。

$$\ce{Fe + 2HCl -> FeCl2 + H2 ^}$$

- **第一步**：$n(\ce{HCl}) = cV = 2 \times 0.100 = 0.2\ \text{mol}$。
- **第二步**：由方程式，$n(\ce{H2}) = \dfrac{1}{2} n(\ce{HCl}) = 0.1\ \text{mol}$。

**辨析｜易错点：用溶液参加计算时，先乘浓度体积得到物质的量，再进比例式。** 不能拿「100 mL」直接对系数——体积不是物质的量，mL 也不是 mol。任何给定溶液的量，都要先通过 $n = cV$ 换算，体积单位记得换算成 L（100 mL = 0.100 L）。

## 6 过量问题的判断

前面几例都是「一种反应物足量」，只要把已知的那种换算成物质的量即可。但题目常给**两种反应物的量**，此时必须判断谁过量——用不足量的那种算。

**例四**：将 0.1 mol $\ce{Zn}$ 与含 0.3 mol $\ce{HCl}$ 的稀盐酸混合，求生成 $\ce{H2}$ 的物质的量。

- 由 $\ce{Zn + 2HCl -> ZnCl2 + H2 ^}$，0.1 mol $\ce{Zn}$ 需要 0.2 mol $\ce{HCl}$，实际有 0.3 mol——$\ce{HCl}$ 过量，**按 $\ce{Zn}$ 算**：$n(\ce{H2}) = 0.1\ \text{mol}$。

**重点：判断过量，看「恰好完全反应的配比」与实际量的关系。** 两种方法二选一：**方法一**，按其中一种反应物的量，算它需要另一种多少，比较是否够用；**方法二**，把两种量分别换算成物质的量，再与系数比比较。无论哪种，**计算产量只用不足量（少的那份）**。

**辨析｜易错点：过量问题里最容易错的是「拿过量的那个量去算产物」。** 生产由「短板」决定——不足量的反应物消耗完，反应就停止。这与木桶原理一模一样：**产物的量由不足量的反应物决定，而不是由过量的决定。**<span class="marginnote">「不足量决定产量」这条原则，是化学计算里最接近生活常识的一条：请客吃饭，能做多少道菜由最紧缺的那份食材决定。到了选择必修1学「化学平衡」时，这个「限制因素」的思想还会升级成「化学平衡常数决定限度」。</span>

## 7 公式解析：列比例式的规范写法

把上面所有方法浓缩成一个「公式解析」——列比例式为什么必须写成这样：

$$\frac{n(A)}{a} = \frac{n(B)}{b}$$

其中 $a$、$b$ 是化学方程式中 $A$、$B$ 两物质的系数，$n(A)$、$n(B)$ 是它们的物质的量。

- **第一步，认符号**：$a : b$ 是系数比，$n(A) : n(B)$ 是实际物质的量比；比例式让两者相等。
- **第二步，看来源**：$a : b$ 来自化学方程式的配平（微观粒子按个数反应），$n(A)$、$n(B)$ 来自已知量换算与未知量假设。
- **第三步，找直觉**：比例式说的是「每 $a$ mol 的 $A$ 需要（或生成）$b$ mol 的 $B$」——把方程式当作一条「固定汇率」，物质的量是唯一被承认的「货币」。

列比例式时，未知量统一设 $x$（mol），同一物质的两项（已知、未知）写在比例式的同一边，单位对齐。**规范写法本身就在防错：比例式两端都必须是物质的量，任何一端混入质量或体积，比例式立刻失衡。**

## 8 小结

- **系数比 = 物质的量比 = 微粒数比**，但不是质量比——这是化学计算的总开关。
- **标准流程**：写方程式 → 已知量换算成物质的量 → 列比例式 → 求未知物质的量 → 换算回题目要求的单位。
- **三把钥匙**：$n = m/M$、$n = V/V_m$（标况 22.4 L/mol）、$n = cV$——分别对应第二章的三节。
- **过量判断**：两种反应物都给量时，先判过量，**产量由不足量决定**。
- **规范比例式**：$\dfrac{n(A)}{a} = \dfrac{n(B)}{b}$，两端只能是物质的量。
