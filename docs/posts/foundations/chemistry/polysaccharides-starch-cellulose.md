## 为什么「同一种单体」造出两种命运

淀粉与纤维素都由葡萄糖单元构成（通式都是 $(\ce{C6H10O5})_n$），却命运迥异：淀粉是人体的主食、纤维素却是「膳食纤维」。差别只在一处——**葡萄糖单元间的连接方式（α-1,4 与 β-1,4 苷键）**。这个「一个羟基朝向」的差异，决定了人体酶能否水解它。多糖是「高分子化学」与「生物化学」的交汇点。<span class="marginnote">淀粉（α-葡萄糖以 α-1,4 苷键连接，支链淀粉还有 α-1,6 分支）与纤维素（β-葡萄糖以 β-1,4 苷键连接成直线链）——同分子式、不同连接，性质天差地别。这是「结构决定性质」在生物大分子中的极致体现。</span>

## 1 淀粉：α-葡萄糖的聚合物

**核心概念：淀粉（starch）**：由**葡萄糖**（α-型）以 α-1,4 苷键（及 α-1,6 分支）连接而成的多糖，通式 $(\ce{C6H10O5})_n$。

**淀粉的组成**：
- **直链淀粉**：葡萄糖以 α-1,4 苷键连接成**螺旋链**（无分支）；
- **支链淀粉**：除 α-1,4 主链外，还有 α-1,6 分支（树状）。

**淀粉的性质**：
- 白色粉末、无甜味、不溶于冷水；
- **遇碘变蓝**（直链淀粉的螺旋结构包合碘分子）；
- 在酸或酶催化下水解，最终产物是**葡萄糖**：$(\ce{C6H10O5})_n + n\ce{H2O} ->[催化剂] n\ce{C6H12O6}$。

**重点：淀粉遇碘变蓝是特征检验**。直链淀粉的螺旋空腔恰好容纳碘分子，形成蓝色包合物；加热蓝色消失、冷却复现（可逆）。<span class="marginnote">「淀粉遇碘变蓝」的灵敏性极高，用于检验淀粉与碘单质。人体消化：唾液淀粉酶把淀粉水解成麦芽糖，胰淀粉酶继续，肠麦芽糖酶分解成葡萄糖——「淀粉 → 麦芽糖 → 葡萄糖」的消化链条是必修二已学的消化化学。</span>

**辨析｜易错点：** ①淀粉是**高分子化合物**（$n$ 很大），无固定分子量、无固定熔沸点；②淀粉水解的最终产物是葡萄糖（不是麦芽糖——麦芽糖只是中间产物）；③检验淀粉水解程度：加碘看是否仍变蓝（未水解完）、用银镜看是否已有葡萄糖——「双检验」判断水解进行到哪步。

## 2 纤维素：β-葡萄糖的聚合物

**核心概念：纤维素（cellulose）**：由**葡萄糖**（β-型）以 **β-1,4 苷键**连接而成的多糖，通式 $(\ce{C6H10O5})_n$，构成植物细胞壁的主要成分。

**纤维素的结构与性质**：
- β-1,4 苷键连接成**直线链**，链间氢键使纤维坚挺；
- 不溶于水、**人体不能消化**（人缺乏水解 β-1,4 苷键的酶）；
- 是**膳食纤维**——促进肠道蠕动、帮助排便。

**重点：为什么人体不能消化纤维素**。人的消化酶（淀粉酶）只能切断 α-1,4 苷键（淀粉），不能切 β-1,4 苷键（纤维素）。反刍动物（牛、羊）靠瘤胃微生物分解纤维素——它们消化纤维素靠的是「借微生物的酶」。<span class="marginnote">纤维素是地球上最丰富的有机高分子（植物光合作用的产物）。它的应用远超「膳食纤维」：棉麻织物（天然纤维）、纸张（纸浆）、黏胶纤维（人造丝）、纤维素硝酸酯（赛璐珞/火药）。「α 可食、β 不可食」的差异还解释了白蚁——它们靠肠道共生微生物消化木质纤维素。</span>

**辨析｜易错点：** ①淀粉与纤维素**不是同分异构体**（$n$ 值不同，分子量不同）——只是通式相同；②纤维素水解的产物也是葡萄糖，但人体无法水解纤维素（酶专一性）；③「膳食纤维」不被消化但有益——「不消化」不等于「无用」；④淀粉 α-1,4 螺旋、纤维素 β-1,4 直线——结构差异决定功能差异。

## 3 公式解析：多糖水解的计算

设淀粉的聚合度为 $n$，完全水解成葡萄糖，1 mol 淀粉水解消耗多少 mol 水、生成多少 mol 葡萄糖：

- **第一步，写水解**：$(\ce{C6H10O5})_n + n\ce{H2O} -> n\ce{C6H12O6}$。
- **第二步，数水**：每个苷键水解消耗 1 分子水，$n$ 个葡萄糖单元有 $n-1$ 个苷键（直链）——但通式写 $n\ce{H2O}$（教材近似，因为末端也配平）。
- **第三步，算产物**：1 mol 淀粉（$n$ 单元）水解得 **n mol 葡萄糖**；通式方程两边原子守恒（淀粉 $\ce{C_{6n}H_{10n}O_{5n}}$ + $n\ce{H2O}$ → $n\ce{C6H12O6}$）。

**结论：多糖水解的计量——每单元葡萄糖需 1 分子水、得 1 分子葡萄糖**。用通式 $(\ce{C6H10O5})_n + n\ce{H2O} -> n\ce{C6H12O6}$ 可直接计算。<span class="marginnote">从分子式看：淀粉的单元 $\ce{C6H10O5}$ 加一分子水（$\ce{H2O}$）即得葡萄糖 $\ce{C6H12O6}$——「水解 = 每个单元补一分子水」。这个计量关系是糖类水解计算（淀粉产葡萄糖、纤维素产葡萄糖）的统一模板。</span>

## 4 淀粉与纤维素的对比与用途

| 对比 | 淀粉 | 纤维素 |
| --- | --- | --- |
| 单体 | α-葡萄糖 | β-葡萄糖 |
| 苷键 | α-1,4（+α-1,6 分支） | β-1,4 |
| 链形 | 螺旋（直链）/ 分支（支链） | 直线 |
| 人体消化 | 能（淀粉酶） | 不能 |
| 碘检验 | 变蓝 | 不变蓝 |
| 用途 | 主食、工业原料 | 织物、纸张、膳食纤维 |

**重点：淀粉与纤维素的用途**。淀粉：食物（米面）、制葡萄糖（水解）、工业（乙醇发酵、黏合剂）。纤维素：棉麻织物、纸张、人造纤维（黏胶）、纤维素衍生物（火药硝化棉）。<span class="marginnote">纤维素的衍生物应用：黏胶纤维（把纤维素碱化、二硫化碳处理再纺丝）是最早的人造纤维；醋酸纤维素用于胶片与眼镜架。植物资源的纤维素利用是「生物质化工」的方向（第八级《环境工程》与第九级《合成生物学》的交叉点）。</span>

**辨析｜易错点：** ①淀粉遇碘变蓝、纤维素遇碘不变蓝——鉴别两者；②两者都能水解成葡萄糖，但人体只能消化淀粉；③「淀粉 + 碘变蓝」用于检验淀粉，而「银镜」用于检验水解产物葡萄糖——检验对象不同。

## 5 多糖的检验与水解程度判断

淀粉的水解实验是「检验 + 程度判断」的经典综合——它同时用碘液（淀粉存在）与银镜（葡萄糖产生）两个检验。

**核心概念：淀粉水解实验**。淀粉 + 稀硫酸（催化剂）加热水解，取样检验：

| 检验 | 试剂 | 现象 | 结论 |
| --- | --- | --- | --- |
| 淀粉未水解 | 碘液 | 变蓝 | 仍有淀粉 |
| 已水解 | 银氨溶液（先中和） | 银镜 | 已有葡萄糖 |

**重点：判断水解程度的「双检验」**。

- 加碘变蓝 + 银镜无 → **未水解**（只有淀粉）；
- 加碘变蓝 + 银镜有 → **部分水解**（淀粉 + 葡萄糖）；
- 加碘不变蓝 + 银镜有 → **完全水解**（只有葡萄糖）。

**公式解析：为什么检验前要先中和硫酸**

- **第一步，看干扰**：硫酸催化水解后留在溶液中，酸性会干扰银镜（银氨溶液需碱性）。
- **第二步，中和**：先加 $\ce{NaOH}$ 至溶液显碱性（中和硫酸），再加银氨溶液。
- **第三步，检验**：碱性条件下才能发生银镜——「先中和、再检验」是操作关键。

**结论：淀粉水解程度 = 「碘液（淀粉）+ 银镜（葡萄糖）」双检验组合**。<span class="marginnote">「双检验判断水解程度」是分析化学「多指标联合判断」的雏形：两个特征反应分别盯住「反应物还剩多少」与「产物生成了多少」——组合起来就得到「反应进行到哪一步」。这个「盯住两头」的思路与工业上「过程监控」（监测反应物与产物浓度）同构，是化学过程控制的普遍方法。</span>

**辨析｜易错点：** ①检验葡萄糖前**必须加碱中和硫酸**——酸性下银镜不反应；②「加碘变蓝」说明淀粉**仍存在**——不等于「未水解」（可能部分水解）；③用「银镜」判断「已水解」——只要出现葡萄糖即已水解（哪怕还残留淀粉）。

**补充：纤维素的工业应用再扩展**。纤维素是地球上最丰富的天然高分子：棉麻（天然纤维）、纸张（纸浆纤维素）、黏胶纤维（纤维素再生——人造丝）、醋酸纤维素（胶片、眼镜架）、硝化纤维素（赛璐珞、喷漆）。「纤维素 + 化学加工 → 多种材料」——天然高分子的化学改性，是「可再生资源 → 材料」的重要路线，与生物质化工（第九级）衔接。

**补充：淀粉的「直链 vs 支链」与食物口感**。直链淀粉（螺旋、遇碘深蓝）与支链淀粉（分支多、遇碘紫红）比例决定食物口感：糯米支链淀粉多（黏软）、普通米直链多（松散）。「结构 → 口感」——淀粉的分子结构影响烹饪与营养（支链淀粉升糖快）。理解淀粉的两种结构，就从化学看到了「一碗饭」的微观世界。

**补充：多糖的「生物功能」再梳理**。多糖的功能多样：淀粉（储能）、纤维素（植物结构）、糖原（动物储能）、几丁质（昆虫外壳）、壳聚糖（生物材料）。「多糖是『结构 + 储能 + 功能』的多面手」——从植物到动物、从结构到材料。「多糖的化学连接（α/β 苷键）决定它的命运」——同一葡萄糖、不同连接、不同功能。「理解多糖，就理解了生物材料的化学基础」。

**补充：多糖的「工业应用」再梳理**。淀粉的工业应用：制葡萄糖（水解）、制乙醇（发酵）、作增稠剂、作可降解塑料（淀粉基）。纤维素的工业应用：造纸、黏胶纤维、醋酸纤维、硝化纤维、生物乙醇。「多糖是『可再生的生物质原料』」——从食物到工业原料。「生物质化工（利用淀粉、纤维素）是绿色化学的方向」——「可再生碳源替代化石碳源」。

**补充：多糖与「糖原」的对比再梳理**。动物储能多糖是**糖原**（结构与支链淀粉类似、分支更多）——「动物的淀粉」。「糖原、淀粉、纤维素都是葡萄糖聚合物」——「同一单体、三种结构、三种功能（储能/储能/结构）」。「多糖的功能由连接方式（α/β、支链）决定」——「结构决定功能在多糖中同样成立」。「理解多糖对比，就理解了生物大分子的设计逻辑」。

## 7 小结

- 淀粉 = α-葡萄糖（α-1,4 苷键）聚合物：螺旋结构、遇碘变蓝、能被人体消化。
- 纤维素 = β-葡萄糖（β-1,4 苷键）聚合物：直线链、不被人体消化、膳食纤维。
- 通式相同 $(\ce{C6H10O5})_n$，**不是同分异构体**（$n$ 不同）。
- 水解计量：$(\ce{C6H10O5})_n + n\ce{H2O} -> n\ce{C6H12O6}$。
- α vs β 的连接差异决定「能消化 vs 不能消化」——结构与功能的极致对应。
