## 为什么从「一个家族」开始

上一课认识了单质钠。但化学世界里，单质只是元素的「短暂出场」——钠在自然界里真正大量存在的是它的化合物：食盐（$\ce{NaCl}$）、纯碱（$\ce{Na2CO3}$）、小苏打（$\ce{NaHCO3}$）……同一个钠，装在不同的「宿主」里，性格迥异：有的能在呼吸面具里放出氧气，有的能治胃酸过多，有的把火焰染成黄色。这一课的任务，就是把这个「钠家族」的四位主要成员逐个看清。

学这一课有一个天然线索：**盯住氧的化合价**。上一课我们说过，钠在化合物里几乎永远是 +1 价，不会变；会变的是它身边的元素——氧可以是 −2（氧化钠、氢氧化钠、碳酸钠），也可以是 −1（过氧化钠）；碳可以是 +4（碳酸根）。**变的是别人，不变的是钠**——这正是一条用氧化还原的眼光串起整个家族的暗线。

## 1 氧化钠与过氧化钠：差一根键，多一份氧

钠有两种氧化物，名字只差一个字，性质却差出十万八千里。

| | 氧化钠 $\ce{Na2O}$ | 过氧化钠 $\ce{Na2O2}$ |
| --- | --- | --- |
| 颜色 | 白色 | 淡黄色 |
| 氧的化合价 | −2 | **−1** |
| 类别 | 碱性氧化物 | **过氧化物**（不是碱性氧化物） |
| 与水反应 | $\ce{Na2O + H2O -> 2NaOH}$（只生成碱） | $\ce{2Na2O2 + 2H2O -> 4NaOH + O2 ^}$（还放出氧气） |
| 与 $\ce{CO2}$ 反应 | $\ce{Na2O + CO2 -> Na2CO3}$ | $\ce{2Na2O2 + 2CO2 -> 2Na2CO3 + O2}$ |

关键的差别藏在那根**过氧键**里。$\ce{Na2O2}$ 中两个氧原子以 $\ce{-O-O-}$ 相连，氧的化合价是 −1。而 −1 价的氧既想变成 −2（得电子），又想变成 0（失电子）——它处在「不高不低」的中间态，于是遇到水或二氧化碳时，一部分氧升到 0 价变成氧气跑掉，另一部分降到 −2 价留在产物里。

**辨析｜易错点：$\ce{Na2O2}$ 不是碱性氧化物。** 碱性氧化物的定义是「与水反应只生成碱的氧化物」。$\ce{Na2O2}$ 与水反应除了生成 $\ce{NaOH}$ 还放出 $\ce{O2}$，不符合定义，所以它属于**过氧化物**。判断一个氧化物是酸性、碱性还是两性，唯一标准是它和水（或酸碱）反应的方式，而不是名字里带不带「碱」字。<span class="marginnote">$\ce{Na2O2}$ 也有漂白性——它的强氧化性足以漂白品红等有色物质，这一点与氯水（下一课的主角）类似。氧化性漂白是不可逆的，与 $\ce{SO2}$ 的化合性漂白（可逆）不同，这个对比到第五章学硫时再展开。</span>

正因为 $\ce{Na2O2}$ 能同时吸收 $\ce{CO2}$ 和水蒸气并放出氧气，它成了著名的**供氧剂**——呼吸面具、潜水艇里都靠它维持氧气供应。人在密闭空间里呼出二氧化碳和水蒸气，过氧化钠把它们转化成氧气，一进一出，正好循环。

## 2 公式解析：过氧化钠的供氧反应

供氧的核心反应是过氧化钠与二氧化碳的反应：

$$\ce{2Na2O2 + 2CO2 -> 2Na2CO3 + O2}$$

这个反应值得拆开看，因为它同时展示了「歧化反应」与「量关系」两个重要概念：

- **第一步，标化合价**：$\ce{Na2O2}$ 中氧为 **−1 价**；反应后，$\ce{Na2CO3}$ 中氧为 −2 价，$\ce{O2}$ 中氧为 0 价。
- **第二步，找升降**：同一反应里，一部分氧从 −1 降到 −2（**被还原**），另一部分氧从 −1 升到 0（**被氧化**）。同一个元素，既升又降——这叫**歧化反应（disproportionation）**，$\ce{Na2O2}$ 既是氧化剂又是还原剂。
- **第三步，核对守恒**：每 2 mol $\ce{Na2O2}$ 参与反应，其中有 2 个氧原子被氧化成 1 个 $\ce{O2}$（升 1，共失 2 个电子），另有 2 个氧原子被还原到 −2 价（降 1，共得 2 个电子）。得失相等，配平正确。
- **第四步，看量关系**：**每 1 mol $\ce{Na2O2}$ 与 $\ce{CO2}$ 反应，放出 0.5 mol $\ce{O2}$，标准状况下体积 11.2 L，转移 1 mol 电子。** 换句话说，78 g 过氧化钠能换来 11.2 L 氧气——这是供氧剂「性价比」的计算基础。

一个有趣的对偶：$\ce{Na2O2}$ 与水反应（$\ce{2Na2O2 + 2H2O -> 4NaOH + O2 ^}$）同样是歧化，氧的走向与和二氧化碳反应完全同构。记住一个，另一个就通了。<span class="marginnote">歧化反应是「同一元素自身发生氧化还原」：一个升、一个降，像一条河分成了两条支流。除了过氧化钠，氯气与水反应（下一课）、$\ce{Cl2}$ 与 $\ce{NaOH}$ 反应都是歧化——这是中学阶段最常见的「自己和自己打架」的反应类型。</span>

## 3 苏打与小苏打：碳酸钠与碳酸氢钠

接下来是钠家族里最贴近生活的一对——**碳酸钠（$\ce{Na2CO3}$）**与**碳酸氢钠（$\ce{NaHCO3}$）**。

**辨析｜易错点：$\ce{Na2CO3}$ 俗名「纯碱」，但它不是碱，而是盐。** 它叫「纯碱」是因为水溶液显碱性，可它由钠离子和碳酸根离子构成，属于盐。真正区分「碱」与「盐」看的是电离出的阴离子：电离出 $\ce{OH-}$ 的是碱，电离出酸根离子的是盐。$\ce{Na2CO3}$ 电离出的是 $\ce{CO3^2-}$，所以是盐——只是水溶液因水解而显碱性。<span class="marginnote">水溶液显碱性是碳酸根水解的结果：$\ce{CO3^2- + H2O <=> HCO3- + OH-}$。水解（弱离子「抢」水中的氢或氧）是选择性必修 1《盐类的水解》的核心内容，这里只需记住「纯碱不是碱」这个结论。</span>

两者的区别可以列成一张对照表：

| | 碳酸钠 $\ce{Na2CO3}$ | 碳酸氢钠 $\ce{NaHCO3}$ |
| --- | --- | --- |
| 俗名 | 纯碱、苏打 | 小苏打 |
| 溶解性（同温同量） | 较大 | 较小（同温下约是 $\ce{Na2CO3}$ 的一半） |
| 水溶液碱性 | 较强 | 较弱 |
| 热稳定性 | 稳定，受热不分解 | **受热分解**：$\ce{2NaHCO3 ->[\Delta] Na2CO3 + H2O + CO2 ^}$ |
| 与盐酸反应 | $\ce{Na2CO3 + 2HCl -> 2NaCl + H2O + CO2 ^}$ | $\ce{NaHCO3 + HCl -> NaCl + H2O + CO2 ^}$ |
| 与 $\ce{CO2}$ | $\ce{Na2CO3 + CO2 + H2O -> 2NaHCO3}$ | 不反应 |
| 与 $\ce{NaOH}$ | 不反应 | $\ce{NaHCO3 + NaOH -> Na2CO3 + H2O}$ |

这张表里有三个「不对称」，是考试的高频陷阱：

**热稳定性不对称**：$\ce{NaHCO3}$ 一加热就分解，$\ce{Na2CO3}$ 却「稳如泰山」。所以鉴别固体碳酸钠和碳酸氢钠，最可靠的办法就是**加热**：有气体生成、能让澄清石灰水变浑浊的是 $\ce{NaHCO3}$。
**与酸反应的剧烈程度不对称**：$\ce{NaHCO3}$ 与盐酸反应更剧烈，因为碳酸氢根只需一步就能放出 $\ce{CO2}$，而碳酸根要先变成碳酸氢根再放气。
**与碱反应不对称**：$\ce{NaHCO3}$ 含有 $\ce{H}$，还能与 $\ce{NaOH}$ 中和，$\ce{Na2CO3}$ 则不能。

## 4 碳酸钠与碳酸氢钠的鉴别、转化与用途

**鉴别方法一（固体）**：加热。$\ce{NaHCO3}$ 分解产生 $\ce{CO2}$，使澄清石灰水变浑浊；$\ce{Na2CO3}$ 无明显现象。

**鉴别方法二（溶液，滴加顺序）**：向两种溶液中分别**逐滴**加入盐酸，现象不同——向 $\ce{Na2CO3}$ 溶液滴加盐酸，**先无气泡**（先生成 $\ce{NaHCO3}$），后有气泡；向 $\ce{NaHCO3}$ 溶液滴加盐酸，**立即有气泡**。<span class="marginnote">向 $\ce{Na2CO3}$ 溶液滴盐酸的实质是分两步走：$\ce{Na2CO3 + HCl -> NaHCO3 + NaCl}$，然后 $\ce{NaHCO3 + HCl -> NaCl + H2O + CO2 ^}$。第一步的盐酸只把碳酸根变成碳酸氢根，不冒泡；等碳酸根全部变成碳酸氢根，第二步才开始放气。滴加顺序不同、现象不同，这是「操作顺序决定现象」的经典例子。</span>

**相互转化**：两个方向都能走通。

$$\ce{Na2CO3 ->[\text{加 CO2 和 H2O}] NaHCO3},\qquad \ce{NaHCO3 ->[\Delta] Na2CO3}$$

向饱和 $\ce{Na2CO3}$ 溶液中通入 $\ce{CO2}$，会析出 $\ce{NaHCO3}$ 晶体——因为生成的 $\ce{NaHCO3}$ 溶解度更小，饱和溶液装不下它。这是工业与实验里让 $\ce{Na2CO3}$ 转成 $\ce{NaHCO3}$ 的常用手段。

**用途**：

- $\ce{Na2CO3}$：制造玻璃、造纸、纺织、作洗涤剂。它是「三酸两碱」中的两碱之一（烧碱与纯碱），工业地位举足轻重。
- $\ce{NaHCO3}$：焙制糕点的发酵粉（受热放出 $\ce{CO2}$ 使糕点蓬松）、治疗胃酸过多的胃药（$\ce{NaHCO3 + HCl -> NaCl + H2O + CO2 ^}$）、泡沫灭火器里的反应原料。

**历史一笔：侯氏制碱法。** 纯碱在近代化学工业里曾是「卡脖子」的技术。我国化工学家**侯德榜**在 20 世纪 40 年代创立的联合制碱法，让纯碱生产既节约原料又不排放废液。他的核心反应链正是我们刚学的转化：

$$\ce{NaCl + NH3 + CO2 + H2O -> NaHCO3 v + NH4Cl}$$

先向饱和食盐水通入氨气再通入二氧化碳，析出 $\ce{NaHCO3}$，再加热分解即得纯碱。<span class="marginnote">为什么先通氨气？因为氨气极易溶于水，让溶液呈碱性，碱性环境能溶解更多 $\ce{CO2}$，碳酸根浓度足够高时 $\ce{NaHCO3}$ 才析得出来。先通氨、再通二氧化碳这个「顺序」，背后是气体溶解度的定量道理——到选择性必修 1《化学平衡》就能严格解释。</span>

## 5 焰色试验：火焰是元素的「指纹」

最后来看钠家族的一项独特检验手段——**焰色试验（flame test）**。

很多金属或其化合物在灼烧时，会使火焰呈现**特征颜色**：钠的火焰呈**黄色**，钾的火焰呈**紫色**（透过蓝色钴玻璃观察），钙呈砖红色，铜呈绿色。这种「一看火焰就知道含哪种金属」的方法，就是焰色试验。

操作要点：用盐酸洗净的铂丝（或光洁的铁丝、镍铬丝）在酒精灯外焰灼烧至无色，再蘸取试样灼烧，观察火焰颜色；每次测完再用盐酸洗净。

**辨析｜易错点：焰色试验是物理变化，不是化学变化。** 灼烧过程中没有新物质生成，只是金属原子受热后电子跃迁到高能级、再落回低能级时放出特定波长的光。所以它检验的是**元素**（金属元素的存在），而不是单质或化合物；只要是钠的化合物，火焰就都是黄色。<span class="marginnote">观察钾的火焰必须透过蓝色钴玻璃，是为了滤去钠发出的黄色光——钾的紫色很容易被一丁点钠杂质「盖住」。这是实验里的「去干扰」思想，与下一课氯离子检验里用稀硝酸排除碳酸根干扰，是同一类思维。</span>

焰色试验的物理本质是**原子光谱**：每种元素的电子在能级间跃迁时放出的光子波长是固定的，所以火焰颜色就像元素的「指纹」。这个道理到选择性必修 2《原子结构与性质》会系统展开——太阳光谱中那些神秘的暗线，正是太阳大气里的钠、氢等元素「吸收」了特定波长的光留下的，天文学家靠光谱认出了太阳的组成。<span class="marginnote">夫琅禾费在 1814 年记录太阳光谱中两条靠得很近的暗线（D 线），后来被证明是钠吸收的痕迹——钠元素的「指纹」不仅存在于我们的焰色试验里，还写在太阳的光里。同一种元素，从实验室到恒星，辨识方法完全一致。</span>

## 6 小结

- **氧化钠与过氧化钠**：$\ce{Na2O}$ 是碱性氧化物（氧 −2 价）；$\ce{Na2O2}$ 是过氧化物（氧 −1 价），与水或 $\ce{CO2}$ 反应放 $\ce{O2}$，可作**供氧剂**。
- **歧化反应**：$\ce{Na2O2}$ 中 −1 价氧一部分升到 0、一部分降到 −2，同一元素既被氧化又被还原。
- **碳酸钠与碳酸氢钠**：纯碱不是碱而是盐；$\ce{NaHCO3}$ 受热分解、与碱反应、遇盐酸立即放气，$\ce{Na2CO3}$ 则相反。
- **鉴别**：固体用加热，溶液用滴加盐酸的顺序；**相互转化**可通过加 $\ce{CO2}$ 或加热实现。
- **侯氏制碱法**：$\ce{NaCl + NH3 + CO2 + H2O -> NaHCO3 v + NH4Cl}$，$\ce{NaHCO3}$ 受热分解得纯碱。
- **焰色试验**：钠黄、钾紫（透过蓝色钴玻璃），是**物理变化**，检验的是金属元素。

在下一节，钠的故事告一段落，轮到本章的另一个主角出场。那个与钠「一生一得」、在电解槽里与钠同时诞生的黄绿色气体——**氯气**，有着比钠更霸道的氧化性。我们将看到它如何与水、与碱、与金属反应，也第一次接触「漂白」背后的化学原理：**氯及其化合物（一）：氯气的性质**。
