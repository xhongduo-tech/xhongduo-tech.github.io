## 为什么硝酸是「双重性格」的酸

氮的化合态家族从氨（$-3$ 价）出发，经过氮氧化物，最终到达最高价态 $+5$——**硝酸**。硝酸与硫酸一样，是化工三大强酸之一，但它的性格比硫酸更「烈」：它既是强酸，又是强氧化剂，而且**见光、受热就分解**。更特别的是，浓硝酸与稀硝酸的氧化产物不同，铜与它们的反应分别给出两种不同的氮氧化物——这是「浓度改变反应路径」的又一例证。<span class="marginnote">硝酸工业（氨氧化法制硝酸）与硫酸工业（接触法）并称两大无机酸工业。两者都属于「含氧酸氧化性」的集中体现，第六级《化学工程》会从反应器与工艺角度再相见。</span>

## 1 硝酸的性质：不稳定的强氧化酸

**硝酸（nitric acid）**：化学式 $\ce{HNO3}$，无色、有刺激性气味的液体，易挥发（沸点 $83^\circ\mathrm{C}$），能与水任意比互溶。市售浓硝酸的质量分数约 $69\%$，物质的量浓度约 $15\ \mathrm{mol/L}$。

**核心概念：硝酸的三重身份。** ①**强酸**：完全电离，具有酸的通性；②**强氧化性**：$+5$ 价氮易得电子，氧化产物随浓度而变；③**不稳定性**：受热或见光分解。

$$
\ce{4HNO3 ->[\Delta][光照] 4NO2 ^ + O2 ^ + 2H2O}
$$

分解产生的 $\ce{NO2}$ 溶于硝酸使浓硝酸呈**黄色**，故浓硝酸常保存在**棕色试剂瓶**中，放在阴凉处。<span class="marginnote">浓硝酸显黄色就是「溶解了 $\ce{NO2}$」：$\ce{NO2}$ 溶于硝酸生成亚硝酸，亚硝酸分解着色。棕瓶避光的细节，对应第一级《化学实验基础》里「见光易分解试剂避光保存」的通用原则，与浓盐酸（挥发出 $\ce{HCl}$）、浓氨水（挥发出 $\ce{NH3}$）并列三大易变质试剂。</span>

## 2 硝酸的强氧化性：浓稀两条路

硝酸与金属反应时，**产物与浓度直接相关**——这是本节最需要强记的对比：

**铜与浓硝酸**（剧烈反应，放出红棕色气体 $\ce{NO2}$）：

$$
\ce{Cu + 4HNO3(浓) -> Cu(NO3)2 + 2NO2 ^ + 2H2O}
$$

**铜与稀硝酸**（反应较慢，放出无色气体 $\ce{NO}$，遇空气变红棕色）：

$$
\ce{3Cu + 8HNO3(稀) -> 3Cu(NO3)2 + 2NO ^ + 4H2O}
$$

**辨析｜易错点：** 两条方程式的系数极易记混，关键在电子守恒：铜失 $2$ 电子；浓硝酸中每个 $+5$ 价氮降到 $+4$ 得 $1$ 电子，所以 $1\ce{Cu}$ 对应 $2$ 个被还原的 $\ce{HNO3}$（另 $2$ 个作酸），得 $\ce{Cu + 4HNO3}$；稀硝酸中每个氮降到 $+2$ 得 $3$ 电子，$3\ce{Cu}$ 共失 $6$ 电子对应 $2$ 个被还原的 $\ce{HNO3}$（另 $6$ 个作酸），得 $\ce{3Cu + 8HNO3}$。

**重点：无论浓稀，硝酸氧化金属都不放氢气**——这一点与稀硫酸（放 $\ce{H2}$）形成鲜明对照。活泼金属（如铝、铁）遇冷的浓硝酸也会**钝化**。而 $\ce{HNO3}$ 浓度低于某一临界值时，其氧化性主要来自 $+5$ 价氮被还原为 $\ce{NO}$ 或更低价。

## 3 公式解析：浓稀硝酸反应系数的由来

以铜与硝酸为例，提炼一条「金属 + 硝酸」的通用思考链：

$$
\ce{3Cu + 8HNO3(稀) -> 3Cu(NO3)2 + 2NO ^ + 4H2O}
$$

- **第一步，区分角色**：$8$ 个 $\ce{HNO3}$ 中，只有 $2$ 个被还原（氮降到 $+2$，作氧化剂），另 $6$ 个保持 $+5$ 价进入 $\ce{Cu(NO3)2}$（只作酸）。**硝酸身兼氧化剂与酸两职。**
- **第二步，电子守恒**：$3\ce{Cu}$ 失 $6$ 电子，$2$ 个氮得 $6$ 电子，守恒。
- **第三步，扩展规律**：若换成其他金属，先写金属变价，再按「被还原硝酸数 × 降价数 = 金属失电子数」反推系数。铁与稀硝酸、锌与稀硝酸均可套用。

更一般的结论是：**氧化还原方程式的配平，本质上就是电子守恒方程**。这个思想在第四级《氧化还原反应的配平》一节会系统化为化合价升降法，但今天的直觉是——系数不是背出来的，是「电子守恒」算出来的。

## 4 酸雨：硫与氮的「环境账单」

**酸雨（acid rain）**：pH 小于 $5.6$ 的降水。$5.6$ 这个界值来自纯水中溶解的二氧化碳达到饱和时的平衡 pH——严格说天然降水本就微酸，真正的酸雨是硫酸型与硝酸型两大类。

**两大元凶**：
- **硫酸型**：煤、石油中的硫燃烧生成 $\ce{SO2}$，$\ce{SO2}$ 被氧化并溶于水：$\ce{SO2 -> SO3 -> H2SO4}$（或 $\ce{SO2}$ 溶于水生成亚硫酸再被氧化）。这是最主要的类型，与燃煤密切相关。
- **硝酸型**：汽车尾气中的氮氧化物（$\ce{NO}$、$\ce{NO2}$）溶于水生成硝酸：$\ce{3NO2 + H2O -> 2HNO3 + NO}$。

**酸雨的危害**：腐蚀建筑物与金属（大理石、青铜雕像被侵蚀）、酸化湖泊土壤导致鱼类与植被死亡、危害人体呼吸系统。著名的「酸雨之父」瑞典科学家斯万特·奥登在 1968 年首次系统揭示这一现象。<span class="marginnote">酸雨、温室效应（二氧化碳）、臭氧层破坏（氟氯烃）并称三大全球性大气环境问题。它们分别对应「酸性氧化物排放」「温室气体排放」「卤代烃排放」，环境化学的线索详见第八级《环境科学与工程》。</span>

**防治措施**：①减少源头排放——脱硫（煤的清洁利用）、机动车尾气净化（催化转化 $\ce{2NO + 2CO ->[催化剂] N2 + 2CO2}$）；②使用清洁能源；③调整产业结构。**重点：防治的优先序永远是「源头削减 > 过程控制 > 末端治理」。**

## 5 硝酸的工业制备：氨氧化法

工业硝酸的生产是「氨 → 一氧化氮 → 二氧化氮 → 硝酸」的氧化链条——它把氨的还原性、氮氧化物的转化与吸收串成完整工艺。

**核心概念：氨氧化法制硝酸的三步**。

1. **催化氧化**：$\ce{4NH3 + 5O2 ->[Pt-Rh][高温] 4NO + 6H2O}$（氨的催化氧化）；
2. **氧化**：$\ce{2NO + O2 -> 2NO2}$（一氧化氮被氧化成二氧化氮）；
3. **吸收**：$\ce{3NO2 + H2O -> 2HNO3 + NO}$（二氧化氮溶于水）。

**重点：尾气 NO 的循环利用**。第三步产生的 $\ce{NO}$ 返回第二步再次氧化——「循环利用」提高总转化率；尾气中的氮氧化物用碱液吸收（防污染）。

**公式解析：吸收塔中加空气的意义**

- **第一步，写吸收**：$\ce{3NO2 + H2O -> 2HNO3 + NO}$——$\frac{1}{3}$ 的氮又变成 NO。
- **第二步，加氧气**：通入空气使 NO 再氧化成 $\ce{NO2}$——循环。
- **第三步，总吸收**：$\ce{4NO2 + O2 + 2H2O -> 4HNO3}$——NO₂ 与 O₂ 按 4:1 通入可被完全吸收（必修二 §氮氧化物已述）。

**结论：硝酸工业 = 「氧化链 + 循环吸收」的绿色设计**。<span class="marginnote">氨氧化法体现了化工生产的核心思想：把「副产物」（NO）循环利用、把尾气吸收处理——「原子利用 + 环境友好」。硝酸工业与硫酸工业（接触法）并称两大无机酸工业，它们的工艺设计（催化剂、循环、吸收）是第六级《化学工程》反应器与流程设计的经典案例。</span>

**辨析｜易错点：** ①硝酸工业的「源头」是氨（合成氨的延伸）——「氨→硝酸」打通了氮化工的上下游；②催化剂用铂铑合金（贵金属）——催化活性高但成本高；③尾气氮氧化物必须处理（酸雨元凶）——碱液吸收或催化还原。

**补充：硝酸的「储存与安全」**。浓硝酸见光分解（棕色瓶避光保存）、强氧化腐蚀（不可用橡胶塞——被氧化）、与有机物接触危险（强氧化剂与易燃物）。实验安全：硝酸蒸气有毒、皮肤接触腐蚀——通风操作、戴手套。硝酸的「分解、氧化、腐蚀」三重性质决定它的储存与使用规范——「性质决定操作」是实验安全的总逻辑。

**补充：酸雨的「区域与治理」再深化**。酸雨是跨境污染（污染物随大气迁移数百公里）——治理需区域合作（欧盟的「长距离跨境空气污染公约」）。中国酸雨曾集中于南方（燃煤、硫含量高）——「十一五」以来的脱硫（石灰石-石膏法）显著改善。「污染治理是系统工程」——从源头脱硫、清洁能源到区域协作，酸雨治理是「化学 + 政策 + 国际协作」的样本。

**补充：硝酸的「化学性质」再梳理**。硝酸三重性格：强酸性（完全电离）、强氧化性（+5 价氮得电子）、不稳定性（见光分解）。「浓稀硝酸氧化产物不同」（浓 → NO₂、稀 → NO）——「浓度影响反应路径」。「硝酸是少有的『既强酸又强氧化』」——它既能与金属（除贵金属）反应、又能氧化非金属。「强酸 + 强氧化」的双重身份，使硝酸在化工中不可替代。

**补充：硝酸与「金属反应」的规律再梳理**。硝酸与金属反应（除 Au、Pt）：浓硝酸 → $\ce{NO2}$（+4 价氮被还原）、稀硝酸 → $\ce{NO}$（+2 价）。「硝酸的还原产物随浓度降低而降低」——浓 → NO₂、稀 → NO、更稀 → N₂O/NH₄⁺。「金属 + 硝酸 = 金属硝酸盐 + 氮氧化物 + 水」——「不放氢气」是硝酸与稀硫酸的本质区别。「硝酸的氧化性来自 +5 价氮」。

**补充：酸雨防治的「化学原理」再梳理**。酸雨防治的化学：脱硫（石灰石-石膏法：$\ce{CaCO3 -> CaO}$ 吸收 $\ce{SO2}$）、尾气催化净化（$\ce{2NO + 2CO ->[催化剂] N2 + 2CO2}$）、清洁能源（减少排放源头）。「从源头削减（脱硫）+ 末端治理（尾气净化）」——「防治酸雨的化学工具箱」。「酸雨治理是『化学 + 工程 + 政策』的结合」——化学给原理、工程给装置、政策给约束。

**补充：硝酸的「储存」再确认**。浓硝酸见光分解（$\ce{4HNO3 ->[光照] 4NO2 + O2 + 2H2O}$）→ 棕色瓶避光保存；久置变黄（溶解 $\ce{NO2}$）。「硝酸的储存：棕瓶、避光、阴凉」——「性质决定保存方式」。「硝酸分解产生 NO₂ 使其变黄」——「黄色的硝酸提示已分解」。「化学品的保存规范 = 化学性质的对应」——「了解性质才能正确保存」。

## 7 小结

- 硝酸：不稳定的强氧化酸，见光受热分解，浓硝酸显黄色、需棕色瓶避光保存。
- 硝酸与金属反应**不放氢气**；浓硝酸产物为 $\ce{NO2}$，稀硝酸产物为 $\ce{NO}$。
- 硝酸身兼**氧化剂与酸**两职，配平靠电子守恒。
- 酸雨 pH < 5.6，硫酸型来自燃煤 $\ce{SO2}$，硝酸型来自尾气氮氧化物。
- 防治以**源头削减**为先；尾气催化转化 $\ce{2NO + 2CO -> N2 + 2CO2}$。
