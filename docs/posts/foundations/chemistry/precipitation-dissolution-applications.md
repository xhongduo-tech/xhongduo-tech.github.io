## 为什么沉淀反应能「提纯」与「检验」

上一节建立了 $K_{sp}$ 的定量框架。本节看它的用武之地：**分步沉淀**（把多种离子逐一分离）、**沉淀的溶解**（除垢、浸出）、**离子检验**（硫酸根、氯离子等）、以及生活中祛除牙垢、处理废水。沉淀溶解平衡把「溶液化学」延伸到实验台与生活现场。<span class="marginnote">沉淀法是最古老的分离提纯手段之一：从古代的「重结晶」到现代的水处理，核心都是「让目标物质以固相析出」。$K_{sp}$ 让它从经验变成可预测的精确操作。</span>

## 1 分步沉淀：把离子逐个分离

**核心概念：分步沉淀（fractional precipitation）**。当溶液中存在多种离子、加入的沉淀剂浓度逐渐增大时，**先满足 $Q_c > K_{sp}$ 的沉淀先析出**——即 $K_{sp}$ 最小的沉淀最先出现（同类型可比时）。

**公式解析：判断沉淀先后**

向含 $c(\ce{Cl-}) = c(\ce{I-}) = 0.01\ \mathrm{mol/L}$ 的溶液中逐滴加入 $\ce{AgNO3}$（$K_{sp}(\ce{AgCl}) = 1.8\times10^{-10}$，$K_{sp}(\ce{AgI}) = 8.5\times10^{-17}$）：

**第一步，求各自开始沉淀所需的 $\ce{Ag+}$**：$\ce{AgI}$ 开始沉淀需 $c(\ce{Ag+}) = K_{sp}(\ce{AgI})/c(\ce{I-}) = 8.5\times10^{-17}/0.01 = 8.5\times10^{-15}$；$\ce{AgCl}$ 需 $c(\ce{Ag+}) = 1.8\times10^{-10}/0.01 = 1.8\times10^{-8}$。
**第二步，比较阈值**：$8.5\times10^{-15} < 1.8\times10^{-8}$——加入少量 $\ce{Ag+}$ 时先达到 $\ce{AgI}$ 的 $K_{sp}$。
**第三步，下结论**：**$\ce{AgI}$ 先沉淀**（更难溶者先出）。当 $\ce{I-}$ 被沉淀到很低时，$\ce{Ag+}$ 浓度才升到 $\ce{AgCl}$ 沉淀的阈值，$\ce{AgCl}$ 开始沉淀。

**结论：同类型沉淀，$K_{sp}$ 越小越先沉淀；不同类型则按「谁的 $Q_c$ 先达 $K_{sp}$」逐一判断**。分步沉淀用于离子分离：控制沉淀剂用量，让最难溶的先析出、过滤后再沉淀下一个。<span class="marginnote">分步沉淀是「选择性沉淀」的思想：像筛子逐级过滤。它用于工业分离（如从矿石浸出液分离多种金属离子）与环境治理（分步沉淀去除不同污染物）。「阈值比较」与第四级《算法》中「贪心选择」的逻辑相通。</span>

## 2 沉淀的溶解：让固相回到溶液

沉淀溶解的本质是让 $Q_c$ 降低到小于 $K_{sp}$。三类常用手段：

| 手段 | 原理 | 例 |
| --- | --- | --- |
| 加酸 | 消耗弱酸根离子 | $\ce{CaCO3 + 2H+ -> Ca^{2+} + H2O + CO2 ^}$ |
| 加络合剂 | 络合金属离子降低其浓度 | $\ce{AgCl + 2NH3 -> [Ag(NH3)2]+ + Cl-}$ |
| 加氧化/还原剂 | 改变离子价态（溶解性改变） | $\ce{CuS}$ 用硝酸氧化溶解 |

**重点：弱酸盐沉淀溶于强酸，强酸盐沉淀不溶**。$\ce{CaCO3}$、$\ce{Mg(OH)2}$、$\ce{ZnS}$ 等弱酸盐/氢氧化物可被酸溶解；$\ce{AgCl}$、$\ce{BaSO4}$ 等强酸盐不溶于酸（沉淀检验的基本依据）。

**辨析｜易错点：** ①$\ce{AgCl}$ 不溶于酸但**可溶于氨水**（生成稳定络离子）——「溶不溶」要看具体试剂，不能一概而论；②$\ce{BaSO4}$ 既不溶于酸也不溶于水，是检验 $\ce{SO4^{2-}}$ 的理想沉淀（无干扰）；③溶解沉淀的「手段」本质都是**降低某离子浓度使 $Q_c < K_{sp}$**，记住这个统一原理就不乱。

## 3 离子检验中的沉淀应用

沉淀溶解平衡是定性检验的基础：

**检验 $\ce{SO4^{2-}}$**：加 $\ce{BaCl2}$，生成白色 $\ce{BaSO4}$ 沉淀（不溶于稀盐酸）——必修二已学，本质是 $K_{sp}(\ce{BaSO4})$ 极小；
**检验 $\ce{Cl-}$**：加 $\ce{AgNO3}$，生成白色 $\ce{AgCl}$ 沉淀（不溶于稀硝酸，溶于氨水）；
**检验 $\ce{Fe^{3+}}$**：加 $\ce{NaOH}$ 生成红褐色 $\ce{Fe(OH)3}$ 沉淀。

**重点：检验的「特征沉淀 + 确认条件」两步法**。只生成沉淀不够，还要用酸/碱确认沉淀的性质（是否溶于某试剂），排除干扰离子——这就是必修二硫酸根检验「先加盐酸、后加氯化钡」的逻辑。<span class="marginnote">沉淀检验是半微量分析的看家本领，第五级《分析化学》会把它系统化为系统分组（如硫化氢系统分组），利用沉淀溶解性的差异把阳离子分成几组逐一鉴定。</span>

## 4 生活中的沉淀平衡

**除水垢**：水垢主要成分是 $\ce{CaCO3}$ 与 $\ce{Mg(OH)2}$，用食醋（醋酸）溶解——弱酸盐沉淀遇酸溶解。但顽固的 $\ce{CaSO4}$ 部分需用碳酸钠转化为 $\ce{CaCO3}$ 再除（上节已述）。

**预防与祛除牙垢**：牙垢（牙结石）是磷酸钙、碳酸钙沉淀。含氟牙膏中的 $\ce{F-}$ 与牙釉质（羟基磷灰石）发生**沉淀转化**，生成更难溶、更耐酸的氟磷灰石，增强牙齿抗龋能力。<span class="marginnote">氟防龋的化学本质是沉淀转化：$\ce{Ca5(PO4)3OH + F- -> Ca5(PO4)3F + OH-}$，氟磷灰石的 $K_{sp}$ 更小、耐酸性更强。这个「用更稳定的沉淀保护表面」的思路，在生物矿化与材料防腐蚀中反复出现。</span>

**废水处理**：向含 $\ce{Pb^{2+}}$、$\ce{Cd^{2+}}$、$\ce{Hg^{2+}}$ 的废水中加 $\ce{Na2S}$，生成极难溶的硫化物沉淀去除重金属离子——$K_{sp}$ 越小越彻底。

**辨析｜易错点：** ①除水垢用酸要「限量」，强酸会腐蚀铝壶等容器（铝及其氧化物与酸反应）；②含氟牙膏的作用是**沉淀转化增强抗酸**，不是「氟本身杀菌」；③废水处理中 $\ce{Na2S}$ 本身有毒，过量使用会引入新的污染物——「以毒攻毒」也要控制剂量。

## 5 沉淀转化与分步沉淀的计算

沉淀溶解平衡的应用题核心是「$Q_c$ 与 $K_{sp}$ 的比较」——用定量判断沉淀生成、溶解与转化的方向。

**核心概念：沉淀转化的定量判断**。沉淀 A 能否转化为沉淀 B？——比较 $K_{sp}$：一般向 $K_{sp}$ 更小的方向自发。但「更难溶」的比较需同类型（1:1 对 1:1）。

**公式解析：分步沉淀的计算**

向含 $\ce{Cl-}$、$\ce{I-}$（浓度均为 0.01 mol/L）的溶液中滴加 $\ce{AgNO3}$，问先沉淀哪种（$K_{sp}(\ce{AgCl}) = 1.8\times10^{-10}$、$K_{sp}(\ce{AgI}) = 8.5\times10^{-17}$）：

**第一步，算各开始沉淀的 $\ce{Ag+}$**：$\ce{AgI}$ 需 $c(\ce{Ag+}) = 8.5\times10^{-17}/0.01 = 8.5\times10^{-15}$；$\ce{AgCl}$ 需 $1.8\times10^{-10}/0.01 = 1.8\times10^{-8}$。
**第二步，比阈值**：$8.5\times10^{-15} \ll 1.8\times10^{-8}$——$\ce{AgI}$ 先沉淀。
**第三步，算分离完全度**：当 $\ce{AgCl}$ 开始沉淀时（$\ce{Ag+} = 1.8\times10^{-8}$），$c(\ce{I-}) = 8.5\times10^{-17}/1.8\times10^{-8} \approx 4.7\times10^{-9}$——I⁻ 已降到极低（沉淀完全）。

**结论：分步沉淀 = 「$K_{sp}$ 小者先沉淀 + 可分离完全」**。<span class="marginnote">分步沉淀的「分离窗口」：当更难溶的离子沉淀到极低浓度（<10⁻⁵）时，较易溶的才开始沉淀——两种离子可被「分步分离」。这个「利用溶解度差异分级沉淀」的思路在化工分离（分级沉淀金属离子）、分析化学（离子分组）中广泛使用——「$K_{sp}$ 相差越大，分离越彻底」是它的定量表述。</span>

**辨析｜易错点：** ①「先沉淀」判断用「开始沉淀所需沉淀剂浓度最小者」——不是直接比 $K_{sp}$ 大小（不同类型需换算）；②沉淀「完全」的标准：离子残留 < $10^{-5}$ mol/L；③分步沉淀的前提是「同类型」沉淀可直接比 $K_{sp}$——不同类型要分别算阈值。

**补充：沉淀溶解平衡在分析化学中的作用**。沉淀反应是定量分析的基础：重量法（把待测离子沉淀、称量计算含量）、沉淀滴定（如银量法测卤离子）。沉淀的「完全性」由 $K_{sp}$ 与沉淀剂用量决定——过量沉淀剂通过同离子效应降低待测离子残留，使沉淀更完全。分析化学选沉淀反应的标准：$K_{sp}$ 小（沉淀完全）、沉淀纯净易过滤、组成确定可称量。

**补充：沉淀溶解平衡与生活应用再梳理**。除了必修二与前面的应用（除水垢、含氟牙膏、废水处理），还有：肾结石的形成（钙盐过饱和结晶——预防靠多喝水降低浓度）、珊瑚与贝壳（生物矿化的沉淀平衡）、土壤中磷的固定（磷酸盐沉淀）。「沉淀—溶解」的平衡无处不在——从人体到环境，都是 $Q_c$ 与 $K_{sp}$ 的博弈。

**补充：沉淀溶解平衡的「工程应用」再拓展**。除已述的除垢、护齿、净水外：①锅炉水处理——加磷酸盐把钙镁沉淀（防垢）；②硬水软化——沉淀法去除 $\ce{Ca^{2+}}$、$\ce{Mg^{2+}}$；③稀土分离——分步沉淀利用 $K_{sp}$ 差异；④矿冶——沉淀回收金属离子。「沉淀反应是分离与净化的基础操作」——$K_{sp}$ 越小、沉淀越彻底、应用越有效。「沉淀溶解平衡」是贯穿工业与生活的通用化学原理。

**补充：沉淀溶解平衡的「医学应用」再深化**。医学中的沉淀溶解平衡：胆结石/肾结石（钙盐结晶——多喝水降低浓度防结晶）、骨质疏松（钙磷平衡）、含氟牙膏（沉淀转化防龋）、药物（难溶药物做成盐提高溶解）。「沉淀平衡是人体矿物质的『化学管家』」——从结石到骨骼，都是「溶与沉」的平衡。「理解沉淀溶解，就理解了身体的矿物化学」。

**补充：沉淀反应在「废水处理」中的核心地位**。废水重金属处理靠沉淀：加 $\ce{Na2S}$ 把 $\ce{Pb^{2+}}$、$\ce{Cd^{2+}}$、$\ce{Hg^{2+}}$ 沉淀为硫化物、加碱把 $\ce{Fe^{3+}}$、$\ce{Al^{3+}}$ 沉淀为氢氧化物。「$K_{sp}$ 越小、沉淀越彻底、处理越干净」——「沉淀法去重金属」是水处理的基本单元。「让有毒离子『沉』下来、离开水体」——沉淀平衡是环保化学的利器。「沉淀 + 分离 + 回收」构成重金属治理的完整链条。

**补充：沉淀溶解平衡的「综合应用」再梳理**。沉淀溶解平衡的应用全景：分步沉淀（离子分离）、沉淀转化（除垢、护齿）、沉淀溶解（酸溶、络合）、离子检验（特征沉淀）、废水处理（重金属沉淀）、药物（难溶药物盐化）。「一个平衡、多种应用」——从实验室检验到工业废水、从牙齿到结石，$K_{sp}$ 与 $Q_c$ 的博弈无处不在。「掌握沉淀溶解平衡，就掌握了『固体与溶液』的化学」。

**补充：沉淀溶解平衡的「综合案例」再深化**。案例：工业废水含 $\ce{Fe^{3+}}$、$\ce{Cu^{2+}}$、$\ce{Zn^{2+}}$——加碱分步沉淀（pH 控制）→ 依次沉淀 $\ce{Fe(OH)3}$、$\ce{Cu(OH)2}$、$\ce{Zn(OH)2}$。「调节 pH 分步沉淀」——利用各氢氧化物沉淀所需 pH 不同。「沉淀分离的『pH 窗口』」——控制 pH 让目标离子先沉淀。「沉淀平衡 + pH 控制」是水处理的核心技术。

**补充：沉淀溶解平衡的「检验应用」再确认**。离子检验利用沉淀的「特征颜色 + 溶解性」：$\ce{Cl-}$（白色 $\ce{AgCl}$、不溶于硝酸）、$\ce{SO4^{2-}}$（白色 $\ce{BaSO4}$、不溶于酸）、$\ce{Fe^{3+}}$（红褐 $\ce{Fe(OH)3}$）。「沉淀是离子的『显形剂』」——「用特征沉淀认出离子」。「检验的原则：特征 + 排干扰」——「沉淀的『颜色 + 溶不溶』是双证据」。「离子检验是沉淀化学的分析应用」。

**补充：沉淀溶解平衡的「应用全景」再确认**。沉淀溶解平衡应用：分步沉淀（分离）、沉淀转化（除垢）、沉淀溶解（酸溶）、离子检验（特征沉淀）、废水处理（重金属沉淀）、生物矿化（骨骼、贝壳）。「一个平衡、多方应用」——「从实验室到工业到生物」。「沉淀溶解平衡是『固液界面』的化学」——「理解它，就理解固体在水中的行为」。「沉淀化学是分离与净化的基石」。

**补充：沉淀溶解平衡的「生活」再梳理**。生活中的沉淀溶解：水垢（钙镁沉淀——用醋溶解）、牙垢（磷酸钙——含氟牙膏沉淀转化）、结石（结晶——多喝水）、净水（明矾沉淀胶体）。「沉淀溶解平衡是生活的化学」——「从水壶到牙齿」。「理解沉淀溶解，就理解了身边的『固体与溶液』」——「生活处处有平衡」。

**补充：沉淀溶解平衡的「分步沉淀」再确认**。分步沉淀：向含多种离子的溶液逐滴加沉淀剂，$K_{sp}$ 小者先沉淀。「先达 $Q_c > K_{sp}$ 者先沉淀」——「比阈值」。「分步沉淀用于离子分离——控制沉淀剂用量逐级沉淀」。「分步沉淀是『分离化学』的重要工具」——「从混合到分离」。

**补充：沉淀溶解平衡与「水的软化」再梳理**。硬水软化（除去 $\ce{Ca^{2+}}$、$\ce{Mg^{2+}}$）：加热法（$\ce{Ca(HCO3)2 ->[加热] CaCO3 v + H2O + CO2 ^}$）、药剂法（加纯碱沉淀钙镁）、离子交换法。「硬水软化是沉淀溶解平衡的应用」——「让钙镁离子沉淀离开」。「软水的好处：省肥皂、防结垢」——「沉淀平衡改善生活品质」。「从沉淀平衡到水质改善」。

**补充：沉淀溶解平衡的「总结」**。沉淀溶解平衡贯穿分离、检验、净水、护齿、除垢——「一个平衡、多方应用」。掌握 $K_{sp}$、$Q_c$ 与平衡移动，就掌握了「固体与溶液」的化学。本节内容也是选择性必修1《水溶液中的离子平衡》的收官——从电离平衡到水解平衡再到沉淀溶解平衡，三类平衡统一在「动态平衡 + 勒夏特列」的框架下。

## 6 小结

- **分步沉淀**：$Q_c$ 先达 $K_{sp}$ 者先沉淀；同类型 $K_{sp}$ 越小越先析出。
- 沉淀溶解三手段：加酸（溶弱酸盐）、加络合剂、氧化还原；本质是降 $Q_c$。
- 弱酸盐沉淀溶于酸、强酸盐沉淀（$\ce{AgCl}$、$\ce{BaSO4}$）不溶于酸。
- 离子检验 = 特征沉淀 + 确认条件；$\ce{BaSO4}$ 是检验 $\ce{SO4^{2-}}$ 的理想沉淀。
- 应用：除水垢、含氟牙膏（沉淀转化）、重金属废水处理（硫化物沉淀）。

至此，水溶液中的离子反应与平衡全部完成。下一章，把电能与化学能双向打通——原电池与电解池。
