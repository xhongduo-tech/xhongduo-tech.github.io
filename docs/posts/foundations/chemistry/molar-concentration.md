## 为什么从「浓度」开始

前两节我们解决了两个问题：怎么数清一堆粒子（物质的量），怎么量取一团气体（气体摩尔体积）。可化学实验里最常用的舞台是**溶液**——反应在试管里进行时，试剂几乎都以溶液的形式参与。这时人们关心的不是「溶液里有多少溶质」，而是「每单位体积里有多少溶质」，也就是**浓度**。

初中化学见过一种浓度——**溶质的质量分数**，它回答「100 份溶液里溶质占几份」。可它有一个致命短板：化学反应按**粒子的物质的量**配比进行，而质量分数给出的却是质量之比，两者之间总要再费一道换算。**物质的量浓度**直接回答「每 1 L 溶液里溶质有多少 mol」，让「量取 0.1 mol 的 $\ce{NaCl}$」变成「量取 100 mL 的 1 mol/L $\ce{NaCl}$ 溶液」这么简单——它把微观计量直接刻在了量筒的刻度上。<span class="marginnote">类比一下：质量分数像「一桶饭里菜占几成」，物质的量浓度像「每 100 mL 饮料含多少克咖啡因」——后者把「量」与「体积」直接挂钩，才能谈「喝多少毫升摄入多少咖啡因」。化学反应需要的正是这种「每体积含多少物质的量」的直读量。</span>

## 1 物质的量浓度的定义

**物质的量浓度（amount-of-substance concentration）**：单位体积溶液中所含溶质 $B$ 的物质的量，符号 $c_B$，常用的单位是 $\text{mol/L}$（读作「摩尔每升」），关系式为：

$$c_B = \frac{n_B}{V}$$

其中 $n_B$ 是溶质 $B$ 的物质的量（mol），$V$ 是**溶液的体积**（L），$c_B$ 就是溶质 $B$ 的物质的量浓度（mol/L）。例如 1 mol/L 的 $\ce{NaCl}$ 溶液，表示每升溶液中含有 1 mol 的 $\ce{NaCl}$，即约 $6.02 \times 10^{23}$ 个 $\ce{NaCl}$ 的离子对。<span class="marginnote">浓度是「单位体积里的量」，这是整个化学里出现频率最高的比值之一。它和后面要学的化学反应速率（单位时间内浓度的变化）、选择必修一里的平衡常数（浓度商的极限）共享同一套「比率思维」——浓度是化学的「速度表」与「密度计」。</span>

**重点：公式中的 $V$ 是「溶液的体积」，不是「溶剂的体积」。** 把 1 mol $\ce{NaCl}$ 溶解在 1 L 水里，得到的溶液体积并不是正好 1 L——溶质会挤占体积，总体积约 1.04 L，浓度也略小于 1 mol/L。正确的做法是：先把溶质在烧杯里溶解，再**加水定容到 1 L**，此时「溶液体积 = 1 L」，浓度才是准确的 1 mol/L。体积是「配出来的终点」，不是「水的量」。

## 2 辨析：物质的量浓度 vs 质量分数

两种浓度经常被放在一起比较，它们的差别可以用一张表说清：

| 对比项 | 物质的量浓度 $c_B$ | 质量分数 $w_B$ |
| --- | --- | --- |
| 定义 | 单位体积溶液含溶质的物质的量 | 溶质质量占溶液质量的比例 |
| 公式 | $c_B = n_B / V$ | $w_B = m_B / m_{\text{溶液}}$ |
| 单位 | mol/L | 无（比值，常写作百分数） |
| 受温度影响 | **受影响**（溶液体积随温度胀缩） | 不受影响（质量不随温度变） |
| 便于 | 化学方程式计量 | 日常配制（称量即可） |

**辨析｜易错点：物质的量浓度与质量分数没有「哪个更大」的直接可比性，换算必须借助密度。** 由定义可推：

$$c_B = \frac{1000\,\rho\, w_B}{M_B}$$

其中 $\rho$ 是溶液密度（$\text{g/mL}$），$M_B$ 是溶质摩尔质量（$\text{g/mol}$）。这条换算公式的来源是量纲推演：先设 1 L 溶液，其质量是 $1000\rho$ 克，其中溶质占 $w_B$ 份，溶质物质的量再除以 1 L 即得浓度。它不要求背，但要求能推导——把「L」「g」「mol」三个单位对齐，公式自然浮出来。<span class="marginnote">推导思路与第一级《基础数学》里的单位换算同构：先选定一个基准量（1 L 溶液），把它拆成几个因子的乘积，再逐项翻译成目标单位。化学计量里的绝大多数换算公式，都是「设基准量 → 拆因子 → 对单位」这三步的产物。</span>

## 3 一定物质的量浓度溶液的配制

理论浓度要变成手中实实在在的一瓶试剂，靠一套标准的实验流程。核心仪器是**容量瓶（volumetric flask）**：一种细颈梨形的玻璃瓶，瓶颈上刻一条**刻度线**，瓶身标注温度和容积（如「100 mL 20 °C」），表示**在 20 °C 时，液体凹液面与刻度线相切时，溶液体积恰好是 100 mL**。<span class="marginnote">容量瓶是「精密定容」的专用仪器：只能用于定容，不能用来溶解固体、不能加热、不能长期存放溶液。它和量筒的根本区别是——量筒「量出」体积，容量瓶「定容到」精确体积。化学实验里凡是要精确配浓度，都要在容量瓶里收尾。</span>

以配制 100 mL 1.00 mol/L 的 $\ce{NaCl}$ 溶液为例，标准流程分六步：

1. **计算**：所需 $\ce{NaCl}$ 的质量 $m = cVM = 1.00 \times 0.100 \times 58.5 \approx 5.85\ \text{g}$。
2. **称量**：用托盘天平称取 5.9 g（初中口径保留一位小数）或分析天平称取 5.85 g $\ce{NaCl}$ 固体，倒入烧杯。
3. **溶解与冷却**：加适量蒸馏水搅拌溶解，**冷却到室温**——溶解往往放热，热的溶液体积不准，必须先冷却。
4. **转移与洗涤**：沿玻璃棒把溶液转入 100 mL 容量瓶；用蒸馏水**洗涤烧杯与玻璃棒 2–3 次**，洗涤液一并转入容量瓶——这一步是为了把黏在杯壁的溶质「全部送进瓶」，是误差控制的关键。
5. **定容**：加水至接近刻度线 1–2 cm 处，改用**胶头滴管**逐滴加水，直到凹液面最低处与刻度线**相切**；盖紧瓶塞，上下颠倒摇匀。
6. **装瓶**：把配好的溶液转入试剂瓶，贴标签注明浓度。

**重点：洗涤液必须转移、定容必须看凹液面、摇匀前不盖上瓶塞都不行——这三条是误差分析的总开关。** 每一步的操作偏差，都会以可预测的方向影响最终浓度。

## 4 误差分析：哪一步会把浓度「做偏」

实验误差是本章最经典的考点，它的总原则只有一句话：**凡是使溶质的物质的量 $n$ 偏大或溶液体积 $V$ 偏小，浓度就偏大；反之偏小。** 用 $c = n/V$ 一条公式，全部推演完毕：

| 操作失误 | 对 $n$ 或 $V$ 的影响 | 浓度 $c$ |
| --- | --- | --- |
| 定容时**俯视**刻度线 | 加水偏少，$V$ 偏小 | 偏大 |
| 定容时**仰视**刻度线 | 加水偏多，$V$ 偏大 | 偏小 |
| 烧杯与玻璃棒未洗涤 | 溶质残留，$n$ 偏小 | 偏小 |
| 溶解后未冷却就转移定容 | 热体积偏大，冷却后 $V$ 偏小 | 偏大 |
| 容量瓶内有少量水 | 不影响 $n$，也不改变最终 $V$ | 无影响 |
| 定容后摇匀发现液面低于刻度线 | 部分溶液挂壁，$n$、$V$ 未变 | 无影响 |

**辨析｜易错点：后两行最反直觉。** 「容量瓶里有水」不稀释——因为最终都要加水定容到刻度线，多出来的水只是少加了等量，$n$ 与 $V$ 都不受影响；「摇匀后液面下降」也无需再加水——那是溶液润湿瓶壁导致的暂时性液面降低，$n$ 与 $V$ 都未变，再加水反而使浓度偏小。判断误差的正道永远是回到 $c = n/V$，而不是凭直觉猜。

## 5 公式解析：$c = n/V$ 与稀释的 $c_1V_1 = c_2V_2$

先拆最基础的浓度公式：

$$c_B = \frac{n_B}{V}$$

- **第一步，认符号**：$n_B$ 是溶质的物质的量（mol），$V$ 是**溶液**体积（L），$c_B$ 是浓度（mol/L）。
- **第二步，看单位**：mol ÷ L = mol/L，单位对消，与定义一致。
- **第三步，找直觉**：浓度是「每升溶液里装了多少摩尔溶质」。它是物质的量在体积维度上的「密度」——就像人口密度是「每平方公里多少人」。

再看稀释公式。稀释的本质是**往溶液里加水，溶质一粒不少**：加水前后，溶质的物质的量守恒，即 $n_1 = n_2$，代入 $n = cV$ 得：

$$c_1V_1 = c_2V_2$$

- **第一步，认符号**：$c_1, V_1$ 是稀释前溶液的浓度与体积，$c_2, V_2$ 是稀释后溶液的浓度与体积。
- **第二步，看限制**：这个等式只在**溶质不变、只加水稀释**时成立；若混入的是另一种溶液，就要用总物质的量除以总体积，不能直接套此式。
- **第三步，找直觉**：一份浓缩液里的溶质「总量」是 $c_1V_1$，加水把它摊到更大的体积 $V_2$ 里，浓度变成 $c_2$——总量不变，只是摊薄。

走一个具体例子：要把 200 mL 的 2.0 mol/L 盐酸稀释成 0.5 mol/L，需加多少水？由 $c_1V_1 = c_2V_2$：

$$V_2 = \frac{c_1V_1}{c_2} = \frac{2.0 \times 0.200}{0.5} = 0.80\ \text{L}$$

即稀释后总体积为 0.80 L，需加水约 $0.80 - 0.20 = 0.60\ \text{L}$。<span class="marginnote">注意：$V_2$ 是稀释后的**总体积**，减去原体积才是加水量。若直接「加 0.60 L 水」在要求精确时并不严格——不同浓度的溶液体积不具可加性，只有物质的量可以相加。这个「体积不可加、物质的量可加」的原则，在配混合溶液时尤其要绷紧。</span>

## 6 实战：混合溶液与稀释的计算

浓度计算的难点，在于分清「什么时候物质的量守恒、什么时候体积可加」。两道题说透。

**例一：同种溶质的两种溶液混合。** 将 100 mL 的 0.3 mol/L $\ce{NaCl}$ 溶液与 200 mL 的 0.1 mol/L $\ce{NaCl}$ 溶液混合（忽略混合时体积变化），求混合后 $\ce{NaCl}$ 的物质的量浓度。

- 溶质总量：$n = c_1V_1 + c_2V_2 = 0.3 \times 0.100 + 0.1 \times 0.200 = 0.05\ \text{mol}$。
- 总体积：$V = 0.100 + 0.200 = 0.300\ \text{L}$（同种稀溶液混合，体积近似相加）。
- 混合后浓度：$c = \dfrac{n}{V} = \dfrac{0.05}{0.300} \approx 0.17\ \text{mol/L}$。

**例二：稀释到什么体积。** 实验室需要 500 mL 的 0.5 mol/L 盐酸，现有 2.0 mol/L 的浓盐酸，应量取多少毫升后再稀释？

- 由溶质守恒：$c_1V_1 = c_2V_2$，即 $2.0 \times V_1 = 0.5 \times 0.500$，解得 $V_1 = 0.125\ \text{L} = 125\ \text{mL}$。
- 量取 125 mL 浓盐酸，加水定容到 500 mL 即可。<span class="marginnote">「稀释到 500 mL」与「加入 500 mL 水」是两回事：前者是定容思想（总体积到刻度线），后者只是粗略近似，在精确配制里是错的——再次印证「体积不可直接相加，物质的量才可相加」这条铁律。</span>

两道题的共同结构：**先把各种来源的溶质物质的量加起来，再除以总体积；稀释问题则直接套 $c_1V_1 = c_2V_2$。** 浓度计算没有新公式，翻来覆去就是 $c = n/V$ 这一条。

## 7 小结

- **物质的量浓度（$c_B$）**：单位体积**溶液**中所含溶质的物质的量，$c_B = n_B/V$，单位 mol/L。
- **体积取溶液不取溶剂**：配制时先溶解、冷却，再定容到刻度线，$V$ 才是溶液体积。
- **与质量分数的关系**：$c_B = 1000\rho\, w_B / M_B$，换算必须经过密度；浓度受温度影响，质量分数不受。
- **配制六步**：计算 → 称量 → 溶解冷却 → 转移洗涤 → 定容 → 摇匀装瓶。
- **误差总开关**：一切回归 $c = n/V$——$n$ 偏大或 $V$ 偏小则浓度偏大，反之偏小；瓶内有水、摇匀后液面下降都不影响浓度。
- **稀释公式**：$c_1V_1 = c_2V_2$，本质是溶质物质的量守恒；体积不可加，物质的量可加。
