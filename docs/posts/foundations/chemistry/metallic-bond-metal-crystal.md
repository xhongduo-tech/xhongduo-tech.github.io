## 为什么金属能「导电、导热、可锻、有光泽」

金属的四大特征——导电性、导热性、延展性、金属光泽——用「金属键 + 自由电子」一个模型就能全部解释。金属原子「捐出」价电子，形成弥漫在整块金属中的**自由电子气**，正离子浸在电子海中靠静电吸引结合。这个模型是理解金属材料一切性质的地基。<span class="marginnote">1900 年德鲁德提出自由电子气模型、1916 年科塞尔与路易斯发展金属键概念。自由电子像「胶水」又像「润滑油」：把正离子粘在一起（金属键），又能自由移动导电导热、滑动时不断键（延展性）。</span>

## 1 金属键

**核心概念：金属键（metallic bond）**：金属原子失去部分价电子形成金属阳离子，这些阳离子沉浸在**自由电子**（离域电子）中，通过阳离子与自由电子间的静电作用结合——这种作用称为金属键。

**金属键的特点**：
- 自由电子不属于某个原子，而是「全体共享」；
- 金属键**无方向性、无饱和性**（区别于共价键）；
- 金属键强度中等，介于共价键与范德华力之间。

**重点：金属键解释金属的通性**。四个通性全部由「自由电子 + 无方向键」解释：

| 金属通性 | 解释 |
| --- | --- |
| 导电性 | 自由电子在外电场下定向移动 |
| 导热性 | 自由电子与晶格振动传递热能 |
| 延展性 | 金属键无方向性，原子层滑动不断键 |
| 金属光泽 | 自由电子吸收并反射可见光 |

**辨析｜易错点：** ①金属键与离子键不同——金属键靠「阳离子—电子」吸引（无固定阴离子），离子键靠「阴阳离子」吸引；②金属键与共价键不同——共价键有方向饱和性，金属键没有；③**自由电子**是金属导电的关键——「正离子移动」导电（离子化合物熔融态）与「自由电子」导电（金属）机制不同。

## 2 金属晶体的堆积方式

**核心概念：金属晶体**：金属原子（或阳离子 + 自由电子）通过金属键构成的晶体。金属原子尽量**紧密堆积**（球体密堆积），使空间利用率最大。

**常见堆积方式**（三维）：
- **体心立方堆积（bcp）**：如钠、钾、铁（α）；空间利用率 68%；
- **面心立方堆积（ccp / fcc）**：如铜、银、金、铝；空间利用率 74%（最密堆积之一）；
- **六方最密堆积（hcp）**：如镁、锌、钛；空间利用率 74%（最密堆积之一）。

**重点：最密堆积的空间利用率为 74%**。面心立方与六方堆积都是最密堆积（每个球与 12 个球接触，配位数 12）；体心立方配位数 8、利用率 68%。<span class="marginnote">金属的堆积方式决定密度与延展性。金、银、铜的 fcc 堆积延展性极好（可拉成细丝、锤成箔）；镁、锌的 hcp 相对脆。配位数：最密堆积 12、体心立方 8、简单立方 6。</span>

**辨析｜易错点：** ①「最密堆积」指空间利用率最高的 74%（ccp、hcp），体心立方 68% 不是最密；②配位数是「最近邻原子数」——fcc/hcp 配位数 12、bcc 配位数 8；③金属晶体可以看成「等径圆球的堆积」，离子晶体则是「不等径圆球」（阴离子大、阳离子小）——这是下一节的过渡。

## 3 公式解析：金属晶体密度的计算

某金属为体心立方堆积，晶胞边长为 $a$，摩尔质量为 $M$，求密度：

- **第一步，数晶胞原子数**：体心立方：顶点 $8\times\frac{1}{8} = 1$ + 体心 $1$ = **2 个原子**。
- **第二步，写密度公式**：$\rho = \frac{Z \times M}{N_A \times a^3}$，其中 $Z = 2$（晶胞原子数）、$N_A$ 阿伏伽德罗常数、$a^3$ 晶胞体积。
- **第三步，代入计算**：知道 $a$ 与 $M$ 即可求 $\rho$。反之，由实验密度也可反推 $a$ 与原子半径。

**结论：金属晶体密度 = 晶胞质量 ÷ 晶胞体积**。这套公式是晶体计算的标准模板，关键在于「数准晶胞原子数 Z」。<span class="marginnote">由密度可进一步推原子半径：体心立方中体对角线 $\sqrt{3}a = 4r$（两角原子 + 中心原子相切），面心立方面对角线 $\sqrt{2}a = 4r$。这些几何关系把宏观密度与微观半径连接起来，是材料科学的基础计算。</span>

## 4 金属晶体的性质与应用

**重点：金属的性质由「金属键强度」决定**。金属键越强（电荷高、半径小、自由电子多），熔点越高、硬度越大：
- 钠、钾：金属键弱，软、熔点低；
- 铁、钨：金属键强，硬、熔点高（钨熔点 3410°C，作灯丝）。

**合金**：金属中加入其他金属或非金属形成合金，金属键与晶格被改变，性能改善（硬度增大、熔点降低）——钢铁、铝合金、黄铜都是合金。<span class="marginnote">合金的「硬度增大、熔点降低」来自不同原子尺寸扭曲晶格、阻碍位错滑移。金属材料与合金设计是第六级《材料科学与工程》的核心内容，这里埋下「金属键强弱决定性能」的种子。</span>

**辨析｜易错点：** ①金属的硬度与熔点由金属键强度决定，不是由「金属活性」决定——钠（活泼）很软，钨（不活泼）极硬；②金属导电靠自由电子，电解质溶液导电靠离子——两者都导电但机制不同；③「合金是混合物」——不是化合物，金属与金属（或非金属）的熔合物。

## 5 金属晶体的性质与应用对比

把金属晶体的「金属键强弱」与「性质」对应起来，就能预测金属的性能与用途——这是「结构决定性质」在金属中的体现。

**核心概念：金属键强度与性质的关系**。

| 金属 | 金属键强弱 | 熔点/硬度 | 应用 |
| --- | --- | --- | --- |
| 钠、钾 | 弱 | 低、软 | 活泼金属、电池负极 |
| 铝 | 中 | 中 | 轻质合金（飞机） |
| 铁 | 强 | 较高 | 结构钢 |
| 钨 | 很强 | 极高（3410°C） | 灯丝 |

**重点：金属键强弱由「电荷 + 半径」决定**——阳离子电荷高、半径小、自由电子多 → 金属键强 → 熔点高硬度大。钠（+1 价、半径大）软、铝（+3 价、半径小）硬得多。

**公式解析：解释「钨作灯丝」**

- **第一步，看要求**：灯丝要耐高温（白炽灯 2700°C 以上）。
- **第二步，看熔点**：钨熔点 3410°C（金属中最高）——金属键极强（高电荷、密堆积）。
- **第三步，看应用**：钨的耐高温 + 导电性 → 灯丝与耐高温部件。

**结论：金属应用 = 「金属键强度 → 熔点/硬度 → 用途」链条**。<span class="marginnote">金属键强度的「电荷 × 半径」规律与离子键同源（都是静电作用）：高电荷小半径的金属（W、Mo）耐高温，低电荷大半径的（Na、K）软而活泼。这个「结构 → 性能 → 应用」的推理链是材料选择的通用方法——从金刚石（极硬）到金属（导电导热）到分子晶体（软低熔），材料性质全部由内部键合决定。</span>

**辨析｜易错点：** ①「金属活泼性」≠「金属键强度」——钠活泼但软（键弱）、钨不活泼但极硬（键强），两者无关；②金属导电靠自由电子（与温度有关：升温电阻增大），区别于电解质的离子导电；③合金的金属键被「杂质原子」扭曲——硬度增大、导电性下降。

**补充：金属的「电子气」模型的局限与延伸**。自由电子气模型解释导电导热延展，但解释不了「为什么有的金属是半导体、有的超导」——那需要能带理论（量子力学）。「模型有适用边界」：电子气模型是「初级近似」，能带理论是「完整图像」。从电子气到能带，是金属物理从「定性」到「定量」的深化——第二级《固体物理》与《电子科学与技术》展开。

**补充：金属晶体的「结构—性能」工程应用**。金属的晶体结构（fcc/hcp/bcc）影响性能：fcc（Cu、Al、Ni）延展性好（滑移系多）、hcp（Mg、Zn）较脆、bcc（Fe、W）强度高。工程上通过「合金化 + 热处理 + 加工」调控结构：钢的淬火（变晶相）、铝合金时效强化（析出相）。「结构控制 → 性能设计」是金属材料工程（第六级《材料科学》）的核心方法论。

**补充：金属晶体的「导电导热」再析**。金属导电靠自由电子定向移动、导热靠自由电子与晶格振动传递动能。「电子是金属的『快递员』」——既送电荷又送热量。升温时晶格振动加剧、阻碍电子移动 → 金属电阻随温度升高而增大（区别于半导体的反向）。「理解自由电子，就理解了金属的一切电热性质」——自由电子气模型虽简、解释力强。

**补充：金属晶体的「堆积」与「密度」再析**。金属的紧密堆积方式决定「空间利用率」：面心立方/六方最密（74%）、体心立方（68%）、简单立方（52%）。「堆积越密 → 空间利用率越高 → 密度相对大」。「金属的堆积方式 → 晶胞结构 → 密度计算」——晶体学的「堆积」知识从金属晶体开始。「会数晶胞粒子数，就会算金属密度」。

**补充：金属晶体与「合金」再深化**。合金是金属 + 其他元素（金属或非金属）的熔合物：钢（铁 + 碳）、黄铜（铜 + 锌）、青铜（铜 + 锡）。「合金的性能优于纯金属」——硬度增大（杂质原子阻碍位错）、熔点降低、抗腐蚀增强。「合金是『金属的改性设计』」——通过掺入元素调性能。「从纯金属到合金」，金属材料走向「按需设计」。

**补充：金属的「导热导电」应用再梳理**。金属导电应用（电线、电路）、导热应用（锅具、散热器）——「金属是电与热的『高速通道』」。「铜（导电好）、铝（轻）、银（导电最佳但贵）」——按需选金属。「理解金属的电子气模型，就理解了为什么金属是导体」——「自由电子是金属导电导热的本源」。「金属材料是电气化的基石」。

**补充：金属键的「强度」与「熔点」再确认**。金属键强度由「电荷 + 半径」决定：电荷高、半径小 → 金属键强 → 熔点高硬度大。钠（+1、半径大）软、铝（+3、半径小）硬、钨（高电荷密堆积）熔点最高。「金属键强度是金属『性格』的根源」——「从电子结构到宏观性能」。「会判金属键强弱，就会预测金属性质」。

## 7 小结

- **金属键**：阳离子 + 自由电子的静电作用；无方向性、无饱和性。
- 金属四通性（导电、导热、延展、光泽）全部由自由电子与无方向键解释。
- 堆积方式：fcc/hcp（最密，利用率 74%，配位数 12）、bcc（68%，配位数 8）。
- 密度公式：$\rho = \frac{Z \cdot M}{N_A \cdot a^3}$；数准 Z 是关键。
- 金属键越强熔点越高、硬度越大；合金改性与晶格扭曲相关。
