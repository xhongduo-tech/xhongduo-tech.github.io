## 为什么从硫开始

第四章我们建立了「结构决定性质」的理论框架，并认识了化学键。现在到了检验它的时刻：用这套框架去研究**真实的元素化学**。硫是绝佳的起点——它处在周期表第三周期第 ⅥA 族，最外层 6 个电子，意味着它的化合价非常丰富：从 $-2$ 到 $+6$，跨越了整整 8 个价态。正是这种「多价态」，让硫及其化合物演出了氧化还原化学最完整的一场戏。<span class="marginnote">硫在自然界无处不在：火山口的硫黄、化石燃料里的含硫杂质、蛋白质中的硫元素。工业上它又是硫酸工业的原料——硫酸被称为「化学工业之母」。从一种元素延伸出一整条工业链，硫是最典型的案例。</span>这一节先从单质硫讲起，再重点研究二氧化硫——一个在氧化还原与酸碱反应两个舞台上都能表演的「多面手」。

## 1 硫：从「黄金」到「硫黄」

单质硫是**淡黄色固体**，俗称**硫黄**，不溶于水、微溶于酒精、易溶于二硫化碳（$\ce{CS2}$）。它的物理性质容易记错，记住一个关键词——**疏水**：硫黄「怕水」，却「喜欢」二硫化碳这类非极性溶剂。<span class="marginnote">「相似相溶」在这里第一次现身：水是极性分子，二硫化碳是非极性分子，硫是非极性分子，所以硫溶于二硫化碳而不溶于水。到选择性必修2《分子结构与性质》讲溶解性时，这条经验会被系统化。</span>

古代人把硫黄与黄金相提并论，是因为它颜色金黄、且燃烧时发出神秘的气味与火焰。硫黄在空气中燃烧，发出**淡蓝色火焰**，生成二氧化硫：

$$\ce{S + O2 ->[点燃] SO2}$$

这一反应同时说明一件事：硫在化学性质上是个「两面派」——它既能**得电子**（作氧化剂，氧化性单质），又能**失电子**（作还原剂）。看它跟谁反应：

- **作氧化剂**（得电子，生成 $-2$ 价硫化物）：与金属、氢气反应。$\ce{Fe + S ->[\Delta] FeS}$、$\ce{2Cu + S ->[\Delta] Cu2S}$、$\ce{H2 + S ->[\Delta] H2S}$。
- **作还原剂**（失电子，生成 $+4$ 价）：与氧气反应生成 $\ce{SO2}$，与氯气、浓硝酸等强氧化剂反应可生成 $+6$ 价的硫酸。

**辨析｜易错点：** 硫与变价金属反应时，只能把金属氧化到**低价态**——铁只到 $\ce{FeS}$（$\ce{Fe}$ 为 $+2$），铜只到 $\ce{Cu2S}$（$\ce{Cu}$ 为 $+1$）。这是因为硫的氧化性比氯气、氧气弱得多。对比记忆：$\ce{2Fe + 3Cl2 -> 2FeCl3}$（氯把铁氧化到 $+3$），而 $\ce{Fe + S -> FeS}$（硫只能到 $+2$）——**氧化性强弱决定产物价态**，这条规律从卤素一直贯穿到硫。

## 2 二氧化硫：无色但有「性格」的气体

二氧化硫（$\ce{SO2}$）是硫最重要的化合物，先说它的物理性质：**无色、有刺激性气味、有毒，密度比空气大，易液化，易溶于水**（常温下 1 体积水约能溶解 40 体积的 $\ce{SO2}$）。因为易溶于水，收集 $\ce{SO2}$ 只能用**向上排空气法**，不能用排水法；因为有毒，实验必须在通风橱中进行。<span class="marginnote">「易溶于水」是 $\ce{SO2}$ 一切水溶液性质（酸性、漂白性）的前提。对比记忆：$\ce{CO2}$ 微溶于水（1:1），$\ce{SO2}$ 易溶于水（1:40），$\ce{HCl}$ 极易溶于水（1:500）——溶解度的巨大差异决定了它们在水中的行为完全不同。</span>

溶于水后，$\ce{SO2}$ 与水化合生成**亚硫酸**（$\ce{H2SO3}$）：

$$\ce{SO2 + H2O <=> H2SO3}$$

亚硫酸是弱酸，且这个反应可逆（所以亚硫酸只能存在于水溶液中，不能单独制得固体）。作为**酸性氧化物**，$\ce{SO2}$ 具备酸性氧化物的通性：能与碱反应、能与碱性氧化物反应。工业上处理尾气中的 $\ce{SO2}$，就用氢氧化钠溶液吸收：

$$\ce{SO2 + 2NaOH -> Na2SO3 + H2O}$$

**辨析｜易错点：** 酸性氧化物的「酸性」体现在与水、碱的反应上，不体现在「尝起来酸」上。$\ce{SO2}$ 溶于水后溶液显酸性、能使紫色石蕊试液变红，但这只说明它是酸性氧化物；它的漂白性、还原性、氧化性，是另外三套独立的性质，各管各的，不要混为一谈。

## 3 二氧化硫的化学性质（上）：还原性是主角

$\ce{SO2}$ 中硫的化合价是 $+4$，正处于硫价态的「中间位置」——**既可以被氧化到 $+6$（作还原剂），也可以被还原到 $0$ 或 $-2$（作氧化剂）**。但观察实验现象，$\ce{SO2}$ 的**还原性**明显是主角：

$$\ce{2SO2 + O2 ->[\text{催化剂, }\Delta] 2SO3}$$

$$\ce{SO2 + Cl2 + 2H2O -> H2SO4 + 2HCl}$$

$$\ce{SO2 + Br2 + 2H2O -> H2SO4 + 2HBr}$$

第一条是工业制硫酸的关键一步（需要催化剂与加热，可逆反应）；第二、三条则给出一个漂亮的实验现象——氯水、溴水是**黄绿色/橙黄色**的，通入 $\ce{SO2}$ 后都褪色了，因为 $\ce{Cl2}$、$\ce{Br2}$ 被 $\ce{SO2}$ 还原。品红溶液褪色、高锰酸钾溶液褪色，同样是 $\ce{SO2}$ 还原性的证据：酸性高锰酸钾（紫红色）被还原为 $\ce{Mn^{2+}}$（无色）。

$$\ce{5SO2 + 2KMnO4 + 2H2O -> K2SO4 + 2MnSO4 + 2H2SO4}$$

**易错点：** $\ce{SO2}$ 使溴水、高锰酸钾溶液褪色，**本质是氧化还原反应**，褪色不可逆（加热不能恢复）；而它使品红溶液褪色，本质是漂白反应，褪色可逆（加热恢复红色）。同样是「褪色」，机理完全不同——这是本章最重要的辨析之一，下一节专门展开。

## 4 二氧化硫的化学性质（下）：氧化性虽弱却存在

$\ce{SO2}$ 也有氧化性，只是表现场合比较少——需要更强的还原剂来「反衬」。最经典的实验是**硫化氢与二氧化硫反应**：

$$\ce{2H2S + SO2 -> 3S v + 2H2O}$$

在这个反应里，$\ce{SO2}$ 中的硫（$+4$）被还原为单质硫（$0$），$\ce{H2S}$ 中的硫（$-2$）被氧化为单质硫（$0$），生成淡黄色沉淀。两种不同价态的硫「碰头」，双双归中到 $0$ 价——这个现象叫**归中反应**。<span class="marginnote">归中反应是氧化还原的重要类型：同一元素高价态与低价态相遇，趋于生成中间价态。$\ce{SO2}$（+4）与 $\ce{H2S}$（−2）归中到 0 价，是唯一能在高中课本里反复出场的经典案例，也是判断「氧化性与还原性共存于同一元素」的活教材。</span>

由此我们看到，$\ce{SO2}$ 的氧化性、还原性都来自 $+4$ 这个「居中价态」——这为下一节《不同价态含硫物质的转化》埋下了伏笔：硫元素的 $-2、0、+4、+6$ 四个价态构成一张转化网络，化学性质就是在这张网上的移动。

**辨析｜易错点：** 「$\ce{SO2}$ 既有氧化性又有还原性」是对的，但做题时要看**具体反应对象**：遇到氧化剂（$\ce{O2}$、$\ce{Cl2}$、$\ce{KMnO4}$）它表现还原性，遇到还原剂（$\ce{H2S}$）它表现氧化性。「中间价态元素既氧化又还原」是规律，具体表现哪一面，由对手决定——这与第三周期硫的化合价分布直接对应。

## 5 二氧化硫的漂白性：可逆的「化学化妆」

$\ce{SO2}$ 最「出名」的性质是漂白性：它能使品红溶液褪色，但**加热后溶液又恢复红色**。原因是 $\ce{SO2}$ 与某些有色物质化合，生成了**不稳定的无色化合物**；加热时这些化合物分解，颜色复原。<span class="marginnote">三种常见漂白剂要分清：$\ce{SO2}$ 是「化合型漂白」，可逆；氯水、过氧化氢、臭氧是「氧化型漂白」，不可逆；活性炭是「吸附型漂白」，物理过程。判断方法很简单——加热看颜色是否回来：回来的就是 $\ce{SO2}$ 型。</span>所以 $\ce{SO2}$ 能漂白纸浆、草帽等，但**不能**用于漂白食品——它有毒，且漂白后的食品加热会「返黄」，露出本来面目。

**辨析｜易错点：** 品红溶液褪色有两种可能：$\ce{SO2}$ 的漂白（可逆）或氯气的氧化（不可逆）。区分实验就是**加热**：加热后恢复红色的是 $\ce{SO2}$，不恢复的是氯气。同时注意，$\ce{SO2}$ 使紫色石蕊试液只变红不褪色（酸性氧化物的酸性），使溴水、高锰酸钾褪色（还原性），使品红褪色（漂白性）——**三种试剂三种机理**，是选择题的经典陷阱。

## 6 公式解析：硫的「价态之舞」一张图看完

把硫的四个主要价态串起来，就是这一章的地图：

$$
\underset{-2}{\ce{H2S}} \;\xrightarrow{\text{被氧化 (失 }e^-)}\; \underset{0}{\ce{S}} \;\xrightarrow{\text{被氧化}}\; \underset{+4}{\ce{SO2}} \;\xrightarrow{\text{被氧化}}\; \underset{+6}{\ce{SO3}/\ce{H2SO4}}
$$

- **第一步，认价态**：硫在 $\ce{H2S}$ 中为 $-2$、单质硫为 $0$、$\ce{SO2}$ 中为 $+4$、$\ce{H2SO4}$ 中为 $+6$，四价态从左到右依次升高。
- **第二步，看升降**：沿箭头向右是被氧化（失电子、作还原剂），向左是被还原（得电子、作氧化剂）。
- **第三步，找中间**：$0$ 价与 $+4$ 价的硫，既有氧化性又有还原性；$-2$ 价（最低）只有还原性，$+6$ 价（最高）只有氧化性。

这张图同时解答了「为什么 $\ce{SO2}$ 是主角」：它处于中间偏高的位置，向左能降价、向右能升价，两面都能演。而**从 $+4$ 到 $+6$ 只需再失 2 个电子**，所以 $\ce{SO2}$ 的还原性才是它的「日常性格」。

**辨析｜易错点：** 「最高价只有氧化性、最低价只有还原性、中间价态两者兼有」是判断元素化合物性质的总原则，适用于所有可变价元素（如氯、氮、铁）。做题先标价态，再判断该物质表现氧化性还是还原性——**先标价、再定性**，能避开大量「想当然」的错误。

## 7 二氧化硫的用途与酸雨

$\ce{SO2}$ 并非一无是处：它是**工业制硫酸**的原料（$\ce{SO2 -> SO3 -> H2SO4}$），可作漂白剂、杀菌消毒剂，食品工业中也少量用作抗氧化剂与防腐剂（葡萄酒里的微量 $\ce{SO2}$ 就在扮演这个角色）。但它的危害同样突出——**酸雨**的主要元凶之一。含硫煤燃烧排出 $\ce{SO2}$，$\ce{SO2}$ 溶于雨水生成亚硫酸（pH 下降），再被氧化成硫酸：

$$\ce{2SO2 + O2 ->[雨水、催化剂] 2SO3},\qquad \ce{SO3 + H2O -> H2SO4}$$

雨水 pH 小于 5.6 即被称为酸雨。它腐蚀建筑、酸化湖泊、毁坏森林，是工业化必须付出代价又必须治理的典型环境问题。<span class="marginnote">治理酸雨的思路分两条：源头减硫（煤的脱硫、用低硫燃料）与末端治理（碱液吸收 $\ce{SO2}$）。这条「从元素化学到环境治理」的链条，正是《化学与可持续发展》一章（第八章）的前奏——化学不仅解释污染，也提供解决方案。</span>

**辨析｜易错点：** 正常雨水因溶有 $\ce{CO2}$ 而略显酸性（pH 约 5.6），所以「酸性降水」不等于「酸雨」——只有 pH 小于 5.6 才叫酸雨。这个 5.6 的数值是判断标准，也是常考的细节。

## 8 小结

- **单质硫**：淡黄色固体、俗名硫黄，不溶于水、易溶于 $\ce{CS2}$；既能作氧化剂（与金属、氢生成 $-2$ 价硫化物），又能作还原剂（与氧生成 $\ce{SO2}$）。
- **$\ce{SO2}$ 物理性质**：无色刺激性气味、有毒、密度大于空气、易溶于水、易液化。
- **$\ce{SO2}$ 酸性氧化物通性**：$\ce{SO2 + H2O <=> H2SO3}$，能与碱反应（尾气用 NaOH 吸收）。
- **$\ce{SO2}$ 的还原性**：与 $\ce{O2}$、$\ce{Cl2}$、$\ce{Br2}$、$\ce{KMnO4}$ 反应，均被氧化到 $+6$ 价——这是它的主要化学性格。
- **$\ce{SO2}$ 的氧化性**：与 $\ce{H2S}$ 反应归中生成硫。
- **漂白性对比**：$\ce{SO2}$ 化合型漂白、加热可逆；氯水氧化型漂白、不可逆；品红「加热看复原」是区分法。
- **价态地图**：$-2 \to 0 \to +4 \to +6$；最高价只有氧化性、最低价只有还原性、中间价态两者兼有。

**例题：** 有四瓶气体分别是 $\ce{CO2}$、$\ce{SO2}$、$\ce{Cl2}$、$\ce{HCl}$，只用一种试剂鉴别。

- **思路**：考虑各气体与品红溶液的反应差异——$\ce{SO2}$ 使品红褪色且加热恢复，$\ce{Cl2}$ 使品红褪色但加热不恢复，$\ce{CO2}$、$\ce{HCl}$ 均不使品红褪色。
- **再细分**：$\ce{CO2}$ 与 $\ce{HCl}$ 无色无味，但通入品红后，再用「能否使澄清石灰水变浑浊」区分（$\ce{CO2}$ 能使，$\ce{HCl}$ 不能——$\ce{HCl}$ 的酸性会溶解碳酸钙）。
- **结论**：只用品红溶液 + 加热，再加澄清石灰水，就能把四种气体一一鉴别。

这道题把「漂白性」「还原性」「酸性氧化物通性」三个性质压缩成一道鉴别题，是硫元素化学的经典综合。能把三种气体的「褪色差异」说清楚，本节的核心考点就掌握了。
