## 为什么「实验操作」是化学的第一课

化学是实验科学——所有规律都从实验中得来、到实验中检验。而实验的根基是**仪器**与**基本操作**：量筒读准体积、酒精灯正确加热、容量瓶精确配液……操作不规范，轻则数据错误、重则安全事故。本节把常用仪器的用途与核心操作要点系统梳理，为后面各类实验（检验、制备、方案设计）打好基础。<span class="marginnote">「规范操作」是化学实验的安全与准确底线。历史上许多事故源于操作失误：酒精灯用嘴吹灭引发火灾、稀释浓硫酸把水倒进酸里溅出烫伤。规范不是束缚，而是保护。</span>

## 1 常用仪器及用途

**核心概念：仪器分类**。化学仪器按用途分为加热、量器、容器、夹持等几类：

| 仪器 | 用途 | 使用要点 |
| --- | --- | --- |
| 试管 | 少量反应、加热 | 加热时管口朝下倾斜、液体不超过 1/3 |
| 烧杯 | 溶解、较多量反应 | 加热垫石棉网 |
| 锥形瓶 | 滴定、反应 | 摇动时防止液体溅出 |
| 圆底烧瓶 | 蒸馏、反应 | 加热垫石棉网（或水浴） |
| 量筒 | 量取液体 | **不能加热、不能配液、不能作反应容器** |
| 容量瓶 | 精确配制溶液 | 只能配液，不能久存、不能加热 |
| 滴定管 | 精确量取/滴定 | 酸式/碱式分用，读至 0.01 mL |
| 移液管 | 精确量取一定体积 | 用洗耳球吸取，读至 0.01 mL |
| 酒精灯 | 加热 | 用外焰加热、**用灯帽盖灭** |
| 蒸发皿 | 蒸发浓缩 | 加热时用玻璃棒搅拌、不能骤冷 |
| 坩埚 | 高温灼烧固体 | 与泥三角配套，灼烧后放干燥器 |
| 分液漏斗 | 萃取分液 | 下层下口放、上层上口倒 |
| 胶头滴管 | 滴加少量液体 | **不能伸入容器内、不能倒置** |
| 玻璃棒 | 搅拌、引流 | 搅拌防碰壁、引流贴壁 |

**重点：量筒与容量瓶的「三不能」**——量筒不能加热、不能配溶液、不能作反应容器；容量瓶只能用于定容配制、不能久存溶液、不能加热。精确度：量筒 0.1 mL、滴定管/移液管 0.01 mL。<span class="marginnote">「量筒粗、滴定管精」是量具选择的核心：粗略量取用烧杯/量筒、精确量取用滴定管/移液管、精确配制用容量瓶。精度的选择直接决定实验结果的可靠性——误差分析的起点。</span>

**辨析｜易错点：** ①量筒无「0 刻度」、刻度自下而上；滴定管刻度**自上而下**（0 在上）——读法不同；②酒精灯不能用嘴吹灭（用灯帽盖灭后提起再盖）、不能用燃着的灯点另一盏灯；③试管加热时管口不能对人、液体不超过容积 1/3。

## 2 基本操作（一）：加热、量取、溶解

**核心概念：加热操作**。给液体加热：试管用外焰、液体不超过 1/3、先预热再集中加热；烧杯/烧瓶要垫**石棉网**（均匀受热）；蒸发皿可直接加热、加热时搅拌防溅。给固体加热：试管口略向下倾斜（防冷凝水倒流炸裂试管）。<span class="marginnote">「试管口向下」防的是固体受热放出的水蒸气冷凝回流到热的试管底部导致炸裂。这个细节是实验操作题常考：加热固体（如制氧气用高锰酸钾）试管口必须略向下倾斜。</span>

**核心概念：液体量取**。量筒读数时**视线与凹液面最低处相平**；俯视读数偏大、仰视偏小（量筒刻度自下而上增大，俯视看高、仰视看低）。

**公式解析：量筒读数的误差**

**第一步，摆姿势**：正确读数时视线、凹液面最低点、刻度线三点一线。
**第二步，俯视**：视线从上方看，看到的刻度在真实液面**上方**——读数**偏大**（量取的实际液体偏少）。
**第三步，仰视**：读数**偏小**（实际量取的液体偏多）。

**结论：俯大仰小（读数）**——俯视读数偏大、仰视读数偏小。但在容量瓶定容时方向相反（定容是「往瓶里加水」，俯视加水偏少）。**「读数」与「定容」的俯仰误差方向不同，是常考陷阱**。<span class="marginnote">俯仰误差的记忆：量筒「俯大仰小」（读数时）；容量瓶定容「俯小仰大」（加水时，俯视看到液面已到刻度、实际没到，加水偏少）。「量筒是读数、容量瓶是加水」——动作不同、误差方向相反。</span>

## 3 基本操作（二）：过滤、蒸发、结晶

**核心概念：过滤**。分离不溶性固体与液体。操作要点「一贴二低三靠」：
**一贴**：滤纸紧贴漏斗内壁；
**二低**：滤纸边缘低于漏斗口、液面低于滤纸边缘；
**三靠**：烧杯嘴靠玻璃棒、玻璃棒靠三层滤纸处、漏斗下端管口靠烧杯内壁。

**重点：过滤的「一贴二低三靠」**是实验操作题的标准答案，也是防止滤液浑浊、液体外溅的关键。

**核心概念：蒸发结晶**。把溶液蒸发浓缩、析出晶体：
蒸发皿加热，**用玻璃棒不断搅拌**（防止局部过热飞溅）；
出现**大量晶体**时停止加热（用余热蒸干）；
不能蒸干（否则晶体可能飞溅、受热分解）。

**辨析｜易错点：** ①蒸发结晶 vs 冷却结晶：溶解度随温度变化大的用**冷却结晶**（如硝酸钾提纯）、变化不大的用**蒸发结晶**（如氯化钠）；②过滤要「先静置再倾倒」上清液，减少滤纸负担；③蒸发时「不能蒸干」——留少量溶液用余热蒸干，防止晶体飞溅。

## 4 基本操作（三）：配制一定浓度溶液

**核心概念：配制一定物质的量浓度溶液**（容量瓶法）的操作流程：**计算 → 称量/量取 → 溶解（冷却）→ 转移（洗涤）→ 定容 → 摇匀**。

关键步骤：
1. **称量**：固体用托盘天平（精确 0.1 g）、液体用量筒/移液管量取；
2. **溶解**：在烧杯中溶解（容量瓶不能直接溶解），**冷却至室温**后转移；
3. **转移与洗涤**：玻璃棒引流，**洗涤烧杯与玻璃棒 2-3 次**（洗涤液一并转入，保证溶质无损）；
4. **定容**：加水至刻度线**1-2 cm 处改用胶头滴管**，视线平视凹液面；
5. **摇匀**：盖塞倒转摇匀。

**公式解析：配液中的常见误差**

**第一步，列公式**：$c = \frac{n}{V} = \frac{m}{M \cdot V}$——浓度受溶质物质的量（$n$）与体积（$V$）影响。
**第二步，看溶质损失**：未洗涤烧杯 → 溶质减少 → $c$ **偏小**；药品潮解 → 实际溶质减少 → 偏小。
**第三步，看体积偏差**：定容俯视 → 加水偏少 → $V$ 小 → $c$ **偏大**；定容仰视 → 加水偏多 → $c$ 偏小。

**结论：配液误差用「$c = n/V$ 的两因素分析」**——先判断 $n$ 是否损失、$V$ 是否偏差，再定浓度偏大偏小。<span class="marginnote">配液误差分析是必考题型：所有操作归为「影响 n（溶质少了→偏小）」或「影响 V（水加多/少了→偏小/偏大）」。抓住「n 与 V」两个变量，任何操作都能快速判断——这是化学计算的「守恒思维」在实验中的体现。</span>

**辨析｜易错点：** ①容量瓶**不能**溶解、稀释、加热——只能在烧杯溶解冷却后转移；②洗涤液必须转入（否则溶质损失）；③定容时**液面与刻度线相切**（视线平视）；④摇匀后液面低于刻度线**不能再加水**（液体附着瓶壁属正常）。

## 5 常见实验操作的规范细节

基本操作的「细节」是实验题得分的关键——这里把最容易失分的规范点集中列出。

**核心概念：操作规范清单**。

| 操作 | 规范要点 |
| --- | --- |
| 闻气体 | 用手扇动、少量嗅闻（不能直接凑近） |
| 加热试管 | 外焰、先预热、管口不对人 |
| 取用药品 | 不摸、不尝、不凑近闻；剩余药品不放回原瓶 |
| 浓硫酸稀释 | 酸入水、沿壁倒、搅拌 |
| 酒精灯 | 灯帽盖灭、不吹不点灯 |
| 天平称量 | 左物右码、垫纸/容器 |

**重点：药品取用「三不」与剩余药品处理**。实验室规则：不直接接触（用手）、不品尝、不凑近闻；取出的多余药品**不放回原瓶**（防污染）、投入指定容器。

**公式解析：为什么剩余药品不能放回原瓶**

**第一步，看污染**：取出的药品可能被镊子、空气、手接触污染——放回会污染整瓶。
**第二步，看安全**：某些药品（如钠）遇水/空气反应，放回原瓶（煤油中）操作有风险。
**第三步，看规则**：实验室「三不」原则（不摸、不尝、不闻）+ 剩余药品「三不」——不放回、不带走、不乱倒。

**结论：实验规范的本质是「防污染 + 保安全」**。<span class="marginnote">实验规范的每一条都能用「为什么」解释：闻气体用手扇（防止大量吸入）、剩余药品不回瓶（防污染）、稀释硫酸酸入水（防暴沸）。理解「为什么」比死记「怎么做」更重要——这也是化学实验从「背操作」走向「懂操作」的分水岭。规范意识延续到工业生产就是 HSE 管理体系（安全、健康、环境）。</span>

**辨析｜易错点：** ①「闻」用扇闻法——手在瓶口轻扇、气流飘向鼻子；②加热试管先**预热**（移动加热）再集中加热——防止局部骤热炸裂；③量筒读数视线与凹液面最低点相平——俯仰都错。

## 6 小结

- 仪器分类与用途：试管、烧杯、容量瓶、量筒、滴定管、酒精灯等。
- 量筒「三不能」；量筒 0.1 mL、滴定管 0.01 mL；滴定管刻度自上而下。
- 加热：外焰、垫石棉网、试管口朝下；酒精灯用灯帽盖灭。
- 量筒读数俯大仰小；过滤「一贴二低三靠」；蒸发「不能蒸干」。
- 配液六步（计算称量溶解转移定容摇匀）；误差分析看 n 与 V。
