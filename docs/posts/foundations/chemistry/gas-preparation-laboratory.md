## 为什么气体制备是「装置设计」的样本

实验室制气（$\ce{O2}$、$\ce{CO2}$、$\ce{H2}$、$\ce{Cl2}$、$\ce{NH3}$ 等）把「反应原理、装置选择、收集方法、检验验满」串成一条完整链条。掌握制气，就是掌握实验设计的通用思路：**反应物的状态与条件决定装置类型，气体性质决定收集方法**。本节把常见气体的制备系统梳理。<span class="marginnote">气体实验的完整流程：发生装置 → 净化除杂 → 干燥 → 收集 → 尾气处理。每个环节都「看气体性质选方法」：易溶水的气体不能排水收集、有毒气体要尾气吸收、密度决定排空气方向。</span>

## 1 制气装置的选择

**核心概念：发生装置按「反应物状态 + 条件」选择**：

| 装置类型 | 适用 | 例 |
| --- | --- | --- |
| 固固加热 | 固体 + 固体加热 | 制 $\ce{O2}$（高锰酸钾） |
| 固液不加热 | 固体 + 液体常温反应 | 制 $\ce{H2}$、$\ce{CO2}$ |
| 固液加热 | 固体 + 液体加热 | 制 $\ce{Cl2}$（二氧化锰 + 浓盐酸加热） |

**重点：制气装置的选择逻辑**。先看反应物状态（固/液）、再看是否需要加热——两者组合决定装置。启普发生器适用于「块状固体 + 液体、不加热、不需持续加热」的反应（制氢气、二氧化碳）。<span class="marginnote">启普发生器靠「关闭活塞→气体压强增大→液体被压离固体」实现反应启停——「随用随停」。但它只适用于块状固体（粉末会漏下去）与放热不大的反应（电石制乙炔放热剧烈不能用）。「装置选择看反应条件」是制气设计的核心。</span>

**辨析｜易错点：** ①固固加热装置：试管口略向下倾斜（防冷凝水倒流）、试管夹夹在距口 1/3 处；②制氧气用高锰酸钾，试管口要**放棉花**（防粉末堵塞导管）；③启普发生器不能用粉末状固体（如碳酸钙粉末）——会漏。

## 2 常见气体的制备反应

| 气体 | 反应原理 | 装置 | 收集 |
| --- | --- | --- | --- |
| $\ce{O2}$ | $\ce{2KMnO4 ->[\Delta] K2MnO4 + MnO2 + O2 ^}$ 或 $\ce{2H2O2 ->[MnO2] 2H2O + O2 ^}$ | 固固加热 / 固液不加热 | 向上排空气或排水 |
| $\ce{H2}$ | $\ce{Zn + H2SO4(稀) -> ZnSO4 + H2 ^}$ | 固液不加热 | 向下排空气或排水 |
| $\ce{CO2}$ | $\ce{CaCO3 + 2HCl -> CaCl2 + H2O + CO2 ^}$ | 固液不加热 | 向上排空气 |
| $\ce{Cl2}$ | $\ce{MnO2 + 4HCl(浓) ->[\Delta] MnCl2 + Cl2 ^ + 2H2O}$ | 固液加热 | 向上排空气（或排饱和食盐水） |
| $\ce{NH3}$ | $\ce{2NH4Cl + Ca(OH)2 ->[\Delta] CaCl2 + 2NH3 ^ + 2H2O}$ | 固固加热 | **向下排空气** |

**重点：几个制气反应的「特例」**：
**制 $\ce{CO2}$ 不用稀硫酸**（生成 $\ce{CaSO4}$ 微溶、覆盖碳酸钙阻止反应）；
**制 $\ce{H2}$ 不用浓硫酸与硝酸**（氧化性酸不置换氢气）；
**制 $\ce{NH3}$ 只能用向下排空气收集**（极易溶于水，不能排水）；
**制 $\ce{Cl2}$ 的尾气用 $\ce{NaOH}$ 溶液吸收**（氯气有毒）。<span class="marginnote">制 CO₂ 不用硫酸的原因：CaSO₄ 微溶、包裹在 CaCO₃ 表面阻碍反应（生成物覆盖反应物）。这个「生成物覆盖」的教训提醒我们：选试剂要看产物是否溶解。制 H₂ 用稀硫酸不用硝酸：硝酸是氧化性酸、生成氮氧化物而非氢气。</span>

**辨析｜易错点：** ①制 $\ce{O2}$ 用高锰酸钾要**棉花**、试管口**向下**；②制 $\ce{CO2}$ 用大理石 + 稀盐酸（不用粉末、不用硫酸）；③制 $\ce{NH3}$ 用 $\ce{NH4Cl + Ca(OH)2}$（不能用 $\ce{NH4NO3}$——受热爆炸性；不能用 $\ce{NaOH}$——吸湿结块）；④制 $\ce{Cl2}$ 用 $\ce{MnO2 + 浓盐酸}$（稀盐酸不反应）。

## 3 公式解析：气体的收集方法

**核心概念：收集方法由气体性质决定**。

**排水集气法**：**难溶/微溶于水**的气体（$\ce{H2}$、$\ce{O2}$、$\ce{NO}$、$\ce{CO}$）；
**向上排空气法**：**密度大于空气**的气体（$\ce{O2}$、$\ce{CO2}$、$\ce{Cl2}$）；
**向下排空气法**：**密度小于空气**的气体（$\ce{H2}$、$\ce{NH3}$）。

判断氨气（$\ce{NH3}$）的收集方法：

**第一步，看溶解性**：氨气**极易溶于水**（1:700）→ 不能用排水法。
**第二步，看密度**：氨气相对分子质量 17 < 空气约 29 → 密度**小于空气**。
**第三步，定方法**：向下排空气法（瓶口朝下、导管伸到底部）。

**结论：收集方法 = 「溶解性 + 密度」双判断**——溶于水的用排空气、密度大的向上、密度小的向下。<span class="marginnote">易溶于水的气体（NH₃、HCl）用排空气；难溶的（H₂、O₂、NO）用排水；密度接近空气的（CO、C₂H₄）最好用排水。收集方法的本质是「让气体待在它该待的地方」——不被水吸收、不被空气稀释。</span>

**辨析｜易错点：** ①$\ce{NO}$ 只能**排水**收集（与空气反应）；$\ce{Cl2}$、$\ce{SO2}$ 可用排饱和食盐水/向上排空气；②排空气法导管**伸到瓶底**（排尽空气）、排水法导管**短进**（瓶口）；③干燥气体：$\ce{NH3}$ 用碱石灰（不能用浓硫酸——反应）、$\ce{CO2}$/$\ce{Cl2}$ 用浓硫酸、$\ce{H2}$/$\ce{O2}$ 可用浓硫酸或碱石灰。

## 4 气体的净化与尾气处理

**核心概念：净化除杂**。粗制气体常含杂质（水蒸气、酸雾、其他气体），需净化：

**除水（干燥）**：酸性气体用浓硫酸、碱性气体用碱石灰、中性气体可用氯化钙；
**除酸性杂质**：用碱液洗气（如除 $\ce{CO2}$ 中的 $\ce{HCl}$ 用饱和碳酸氢钠）；
**顺序**：先除其他杂质、再干燥（干燥通常放最后）。

**核心概念：尾气处理**。有毒气体（$\ce{Cl2}$、$\ce{SO2}$、$\ce{CO}$、$\ce{HCl}$）必须处理：

$\ce{Cl2}$、$\ce{SO2}$、$\ce{HCl}$：用 $\ce{NaOH}$ 溶液吸收；
$\ce{CO}$：点燃（燃烧成 $\ce{CO2}$）或收集；
$\ce{NH3}$：用水或稀硫酸吸收（防倒吸——用倒扣漏斗）。

**重点：防倒吸**。气体易溶于水时，尾气吸收要用**倒扣漏斗**（漏斗口贴近液面，气体吸收后液面下降、脱离漏斗，防止水倒吸进装置）。<span class="marginnote">「防倒吸」是气体制备的高频考点：氨气、氯化氢极易溶于水，直接通入水中会因压强骤降把水倒吸回反应装置。倒扣漏斗让漏斗口在水面上方——气体吸收后液面下降、漏斗脱离液面、空气进入破坏虹吸。这个「安全装置」是实验设计的典型智慧。</span>

**辨析｜易错点：** ①干燥剂选择看气体性质：碱性气体（$\ce{NH3}$）不能用酸性干燥剂、酸性气体（$\ce{CO2}$、$\ce{Cl2}$）不能用碱性干燥剂；②洗气瓶「长进短出」（气体从长管进、短管出）；③检验气体纯净：收集一小试管、点燃或试纸检验——$\ce{H2}$ 检验「纯度」（混空气点燃爆炸）。

## 5 气体制备的装置气密性检查

气体制备实验的第一步是「检查装置气密性」——这是所有气体实验的安全前提，也是常考操作。

**核心概念：气密性检查的方法**。常用「微热法」：把导管末端伸入水中，用手（或热毛巾）捂热发生装置——若导管口有气泡冒出、松手后导管内形成一段水柱且不下降，则气密性良好。

**公式解析：气密性检查的原理**

**第一步，封闭体系**：装置须「密闭」（各连接处不漏气）。
**第二步，制造压差**：加热使装置内气体膨胀（压强增大）。
**第三步，观察现象**：气体膨胀 → 导管口冒气泡；冷却 → 压强减小 → 水倒吸形成水柱。气泡 + 水柱 = 气密性良好。

**结论：气密性检查 = 「热胀冷缩制造压差 + 气泡/水柱验证」**。<span class="marginnote">气密性检查的变式：若装置本身无法用微热（如启普发生器），可用「注水法」——从长颈漏斗加水至液封，观察漏斗中液面是否稳定。不同装置的气密性检查方法不同，核心都是「制造压差、观察液面/气泡变化」——这个「设计验证」的思路与实验方案设计完全一致。</span>

**辨析｜易错点：** ①检查气密性要在**加药品之前**（装置空载检查）；②「气泡冒出」只是第一步，还要看「水柱不下降」（松手后）——两者都满足才证明不漏气；③多孔装置（有分液漏斗）要先关闭活塞、液封漏斗再检查。

**补充：气体制备的「验满与检验」区分**。验满是「收集满了没」（在收集装置检验）、检验是「是不是这种气体」（在反应后检验）：验满氧气用带火星木条伸到瓶口（复燃）、验满二氧化碳用燃着木条伸到瓶口（熄灭）；检验则把气体通入试剂（石灰水变浑 = CO₂）。「验满在瓶口、检验在试剂」——位置与方式都不同，别混淆。

**补充：气体制备的「尾气处理」原则**。有毒气体必须处理：Cl₂、SO₂、HCl 用 NaOH 吸收、CO 点燃或收集、NH₃ 用水/酸吸收（防倒吸）。「不排毒气」是实验室环保底线，也是绿色化学（§8.3）在实验中的落实。尾气处理设计要考虑「吸收剂选对 + 防倒吸」——既环保又安全。

**补充：气体收集的「排空气法」细节**。向上排空气法（收集比空气重的气体）：瓶口朝上、导管伸到瓶底、瓶口盖玻璃片（或棉花）——让空气从瓶口排出。向下排空气法（收集比空气轻的）：瓶口朝下、导管伸到底。判断方向：「重上轻下」——气体密度大于空气用向上、小于空气用向下。「导管伸到底」保证气体先沉底、把空气「顶」出。

**补充：气体制备的「装置组合」思路**。完整气体实验 = 发生 + 净化 + 干燥 + 收集 + 尾气处理——每段选对应装置：发生（固固/固液）、净化（洗气瓶）、干燥（干燥管/洗气瓶）、收集（排水/排空气）、尾气（吸收/点燃）。「分段设计、逐段匹配」——气体制备是「模块化组装」的实验，每段独立设计、整体串联。「装置的『积木化』思维」是实验设计的通用方法。

## 7 小结

- 发生装置按「固/液 + 加热/不加热」选：固固加热（$\ce{O2}$）、固液不加热（$\ce{H2}$/$\ce{CO2}$）、固液加热（$\ce{Cl2}$）。
- 制气反应特例：$\ce{CO2}$ 不用硫酸、$\ce{H2}$ 不用硝酸、$\ce{NH3}$ 用 $\ce{NH4Cl + Ca(OH)2}$。
- 收集方法看「溶解性 + 密度」：排水（难溶）、向上（密度大）、向下（密度小）。
- 净化：先除杂再干燥；干燥剂选配气体酸碱性。
- 尾气处理与**防倒吸**（倒扣漏斗）——有毒气体必须处理。
