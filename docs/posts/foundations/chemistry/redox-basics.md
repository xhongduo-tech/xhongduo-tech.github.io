## 为什么从「化合价」开始

初中化学给氧化还原的定义很朴素：**得氧的物质被氧化，失氧的物质被还原**。氢气和氧化铜共热，$\ce{H2}$ 夺取了氧被氧化，$\ce{CuO}$ 失去了氧被还原。这套说法很直观，可它有一个致命的局限——它只认「氧」。

但化学里最重要的反应，很多根本没有氧参加。金属钠在氯气中燃烧生成氯化钠，铁置换硫酸铜里的铜，原电池、电解池里的一切……这些反应里氧影子都没有，却货真价实地发生着电子的转移。所以我们需要一把更普适的尺子：**化合价**。它是「电子转移」在纸面上留下的足迹——化合价升高，说明失去了电子；化合价降低，说明得到了电子。这一节的全部任务，就是学会「读化合价、判升降」，从而一眼识别一个反应是不是氧化还原反应。

## 1 从「得氧失氧」到「化合价升降」

先看三个反应，它们同样「剧烈」，却只有第一个能用「氧」描述：

$$\ce{CuO + H2 ->[\Delta] Cu + H2O}$$

$$\ce{2Na + Cl2 -> 2NaCl}$$

$$\ce{Fe + CuSO4 -> FeSO4 + Cu}$$

初中定义对第一个反应有效，对后两个失灵。把三个反应放在一起比对，会发现一个共同点：**都有元素的化合价发生变化**。钠从 0 价升到 +1，氯从 0 价降到 −1；铁从 0 价升到 +2，铜从 +2 价降到 0。于是化学家给出更普适的定义：

**氧化还原反应（redox reaction）**：有元素化合价升降的化学反应。

**没有元素化合价升降的化学反应，称为非氧化还原反应。** 化合价，是判断氧化还原的唯一判据。

为什么化合价升降能作为判据？因为**化合价是电子转移的宏观标记**：化合价升高 ⟷ 失去电子（或电子偏离），化合价降低 ⟷ 得到电子（或电子偏向）。对于离子化合物（如 $\ce{NaCl}$）是真正转移了电子；对于共价化合物（如 $\ce{CO2}$）只是电子对发生了偏移。两条路线殊途同归，化合价都能记录它们。<span class="marginnote">化合价的升降数值，就是转移或偏移的电子数。这个「由表及里」的等价关系，是本章后半部分所有配平与计算的基石——下一节我们会把它正式落地为「电子守恒」。</span>

## 2 化合价：先会「读数」，才能判断

要判断升降，先得会标化合价。中学阶段标化合价用两条铁律加上一张常用价态表：

- **铁律一：单质中元素的化合价为 0。** $\ce{Na}$、$\ce{Cl2}$、$\ce{Fe}$、$\ce{O2}$ 中元素的化合价都是 0。
- **铁律二：化合物中，所有元素化合价的代数和等于 0。** 有了这条，只要确定一个原子团的整体价态，就能反推出其他元素。

常用化合价记成口诀（括号内是常见价态）：**一价氢氯钾钠银**（$\ce{H}$、$\ce{Cl}$、$\ce{K}$、$\ce{Na}$、$\ce{Ag}$ 为 +1 或 −1）；**二价氧钙钡镁锌**（$\ce{O}$ 通常 −2，$\ce{Ca}$、$\ce{Ba}$、$\ce{Mg}$、$\ce{Zn}$ 为 +2）；**三铝四硅五价磷**；**二三铁、二四碳、二四六硫都齐全**；**铜汞二价最常见**。

几个原子团要当作整体记住：$\ce{OH-}$（−1）、$\ce{NO3-}$（−1）、$\ce{SO4^2-}$（−2）、$\ce{CO3^2-}$（−2）、$\ce{NH4+}$（+1）。<span class="marginnote">化合价口诀是化学的「乘法表」——必须熟练到不假思索。它与元素周期律（第四章）直接相连：金属性强的元素容易失电子、化合价趋于正，非金属性强的元素容易得电子、化合价趋于负。口诀背后，是周期表的秩序。</span>

举例：$\ce{Fe2O3}$ 中氧为 −2，三个氧合计 −6，铁二合计 +6，所以每个铁为 +3；$\ce{CO2}$ 中碳为 +4；$\ce{CO}$ 中碳为 +2。同一个碳，在 $\ce{CO}$ 与 $\ce{CO2}$ 里价态不同——这正是变价元素。

同一元素在不同化合物里常常「身兼数价」：硫在 $\ce{H2S}$、$\ce{S}$、$\ce{SO2}$、$\ce{H2SO4}$ 中价态分别为 −2、0、+4、+6，从低到高排成一条「价态阶梯」。判断一个反应是不是氧化还原，最省力的办法就是**盯住这类变价元素**，看它在反应前后有没有在阶梯上移动；纹丝不动，就必非氧化还原。

## 3 氧化反应与还原反应：一对共生体

有了化合价，就能精确地给「氧化」与「还原」下定义：

**氧化反应**：元素化合价升高的过程（该元素的原子失去电子）。
**还原反应**：元素化合价降低的过程（该元素的原子得到电子）。

**辨析｜易错点：氧化反应与还原反应永远同时发生，不可能单独存在。** 因为在一个化学反应里，电子不会凭空出现或消失：一方失去的电子，必须由另一方得到。有人失电子，就有人得电子；有化合价升高的元素，就必有化合价降低的元素。所以「氧化还原反应」是一个不可分割的整体，教材上说的「氧化反应」「还原反应」只是从两个方向看同一件事。<span class="marginnote">这与中国古代「孤阴不生，独阳不长」的辩证法暗合，也像物理学里的电荷守恒：正电荷与负电荷总是成对出现。氧化与还原，是化学世界里的「阴阳」。</span>

以高炉炼铁的核心反应为例：

$$\ce{Fe2O3 + 3CO ->[\text{高温}] 2Fe + 3CO2}$$

- 铁：$+3 \rightarrow 0$，化合价**降低**，被**还原**，发生**还原反应**；
- 碳：$+2 \rightarrow +4$，化合价**升高**，被**氧化**，发生**氧化反应**。

一次高温反应里，铁被还原、碳被氧化，两个过程同时完成。

## 4 四大基本反应类型 × 氧化还原

第一课学的四大基本反应类型（化合、分解、置换、复分解）是按反应的**形式**分类；氧化还原与非氧化还原是按反应的**实质**分类。两套标准叠在一起，会得到一组非常有用的判定关系：

- **置换反应一定是氧化还原反应。** 置换的本质是「一种单质把另一种元素从化合物里替换出来」，必然伴随元素化合价升降（单质 0 价进、另一种元素价态变）。
- **复分解反应一定不是氧化还原反应。** 复分解是两种化合物互相交换成分，各元素化合价在反应前后保持不变。
- **化合反应与分解反应不一定。** 有单质参加或生成时通常是氧化还原（如 $\ce{2Na + Cl2 -> 2NaCl}$、$\ce{2H2O ->[\text{电解}] 2H2 ^ + O2 ^}$）；没有单质参与时通常不是（如 $\ce{CaO + H2O -> Ca(OH)2}$、$\ce{CaCO3 ->[\text{高温}] CaO + CO2 ^}$）。

把四个类型看作四个集合，氧化还原是一个与之相交的性质集合，用第一级《基础数学》里学过的集合语言写，就是：

$$\text{置换} \subset \text{氧化还原},\qquad \text{复分解} \cap \text{氧化还原} = \varnothing$$

$$\text{化合} \cap \text{氧化还原} \neq \varnothing,\qquad \text{分解} \cap \text{氧化还原} \neq \varnothing$$

这四行集合关系，把「反应分类」的全部逻辑压缩成了教科书里常画的一张韦恩图。<span class="marginnote">这正是「集合」这一语言的第一处化学实战：分类标准不同，结论就不同——和第一课《物质的分类》里交叉分类法的思路完全一致。学数学时建立的集合直觉，在这里直接变现。</span>

## 5 公式解析：化合价分析三步

判断一个陌生反应是不是氧化还原，用三步「化合价分析」。以 $\ce{Fe2O3 + 3CO -> 2Fe + 3CO2}$ 为例走一遍：

- **第一步，标出每个元素的化合价。** 左：$\ce{Fe}$ +3，$\ce{O}$ −2，$\ce{C}$ +2；右：$\ce{Fe}$ 0，$\ce{C}$ +4，$\ce{O}$ −2。
- **第二步，找出有变化的元素及其升降值。** 铁：$+3 \rightarrow 0$，每个铁**降 3**；碳：$+2 \rightarrow +4$，每个碳**升 2**。
- **第三步，核对升降总数是否相等。** 左边有 2 个铁，共降 $2 \times 3 = 6$；左边有 3 个碳，共升 $3 \times 2 = 6$。**升降总数相等**——电子既没凭空产生，也没凭空消失。有升有降、升降守恒，判定该反应为氧化还原反应。

再用三步法检验一个「没有氧参与」的反应——金属钠在氯气中燃烧：

$$\ce{2Na + Cl2 -> 2NaCl}$$

- **标价**：左边钠 0、氯 0；右边钠 +1、氯 −1。
- **找升降**：钠从 0 升到 +1，每个钠**升 1**；氯从 0 降到 −1，每个氯**降 1**。
- **核对**：2 个钠共升 $2 \times 1 = 2$；1 个 $\ce{Cl2}$ 含 2 个氯，共降 $2 \times 1 = 2$。升降总数相等，判定为氧化还原反应。

这个反应里根本没有氧，初中「得氧失氧」的定义完全失效，而化合价判据一视同仁——这正是把它称为「更普适的尺子」的原因。到必修第一册第二章，我们会亲眼看到这团在氯气中燃烧的白色火焰。

**辨析｜易错点：有单质参加或生成的反应，不一定是氧化还原反应。** 氧气放电变成臭氧：$\ce{3O2 ->[\text{放电}] 2O3}$。反应前后氧元素都是 0 价，化合价没有升降，所以它**不是**氧化还原反应——这是同素异形体之间的转化。判断氧化还原，只看化合价是否升降这一条，不看「有没有单质」。

## 6 小结

- **氧化还原反应的判据**：有无元素**化合价升降**；不再依赖「得氧失氧」。
- **化合价规则**：单质为 0，化合物中代数和为 0；变价元素是氧化还原的「主角」。
- **氧化与还原共生**：化合价升高（失电子）为氧化，降低（得电子）为还原，二者同时发生。
- **与四大基本反应类型的关系**：置换必是氧化还原，复分解必不是，化合与分解看有无单质参与。
- **化合价分析三步**：标价 → 找升降 → 核对升降总数相等。
- **判据的演进**：得氧失氧（拉瓦锡，18 世纪末）→ 化合价升降（19 世纪）→ 电子转移（20 世纪初），一步比一步普适；化合价升降是纸面上最方便的统一判据。
- **通向下一节**：化合价升降的数值，正是下一节「电子守恒」配平与计算的依据——得失电子总数必须相等。

在下一节，我们将给「升」与「降」两个方向配上物质角色：谁在得电子、谁在失电子，得失如何配平成一份平衡的方程式——这就是**氧化还原反应（二）：氧化剂与还原剂、氧化还原方程式的配平**。
