## 为什么从元素周期表开始

上一节我们认识了原子内部的结构，掌握了「质子数决定元素种类」。但一百多种元素要如何组织，才能既反映共性又体现递变？1869 年，门捷列夫把当时已知的 63 种元素写在卡片上，按相对原子质量排序后发现：**元素的性质每隔一段距离就出现一次相似的「重现」**。他把这种规律整理成第一张元素周期表，并大胆地给自己留出的空位预言了新元素——十几年后，镓（Ga）、钪（Sc）、锗（Ge）被一一发现，性质与预言惊人吻合。<span class="marginnote">门捷列夫预言的「类铝」即镓 Ga：他预言其相对原子质量约 68、密度约 5.9 g/cm³，实际镓的相对原子质量为 69.7、密度为 5.9 g/cm³。这种「先有理论、后有发现」的预测力，让周期表成为化学史上最伟大的组织工具，也是「模型能够指导实验」的经典范例。</span>

## 1 元素周期表的结构：横行是周期，纵列是族

现代元素周期表按**原子序数（质子数）**从小到大排列，其结构只有两套维度：

- **横行（7 个周期）**：周期序数 = 电子层数。前三周期称**短周期**（各有 2、8、8 种元素），第四、五、六周期为**长周期**（18、18、32 种），第七周期为**不完全周期**（目前排到 118 号，仍在新元素合成中）。
- **纵列（18 个纵列、16 个族）**：1—2 列与 13—18 列共 8 个**主族**，记作 ⅠA—ⅦA 与 0 族；3—12 列共 6 个**副族**（ⅠB—ⅦB）与**第Ⅷ族**（占 3 个纵列）。<span class="marginnote">18 个纵列压缩成 16 个族，是因为第Ⅷ族「一列三格」。主族序数 = 最外层电子数（对 0 族不适用），副族则与 d 轨道电子数有关——这个关系在选择性必修2里会讲清楚。</span>

主族元素有两组最重要的「坐标换算」：

$$\text{周期序数} = \text{电子层数}, \qquad \text{主族序数} = \text{最外层电子数}$$

因此，只要知道一个主族元素在周期表中的位置，就能反推它的原子结构；反之亦然。例如氯在第 3 周期第 ⅦA 族，则它有 3 个电子层、最外层 7 个电子，质子数 = 原子序数 17。<span class="marginnote">这句话是「位置—结构」双向翻译，请务必练到「秒答」。它是后面推断元素性质的第一条腿；第二条腿是同一周期、同一主族的递变规律，见《元素周期律》。</span>

**辨析｜易错点：** 周期序数对应电子层数，主族序数对应最外层电子数，但**副族元素不满足这两条**——副族的最外层电子数往往不是 2 就是 1，与族序数无关；副族化学性质由次外层 d 电子参与决定。高中阶段主族元素是主角，副族只需知道「周期表有 16 个族、其中 7 个主族 + 0 族」即可。

## 2 周期表的一格：元素的身份证

翻开周期表，每个元素占据一格，格子里常写四项信息。以钠为例：

| 位置 | 信息 | 含义 |
| --- | --- | --- |
| 左上角 | 11 | 原子序数 = 核电荷数 = 质子数 |
| 中间 | Na | 元素符号（拉丁文名缩写） |
| 上方 | 钠 | 元素名称 |
| 下方 | 22.99 | 相对原子质量（加权平均值） |

**辨析｜易错点：** 格子里的数字 22.99 是相对原子质量，不是质量数。质量数是对具体核素说的整数（如 $\ce{^{23}Na}$），而 22.99 是钠元素两种天然核素按丰度的加权平均——两者概念不同，后者数值上≈前者，但多出的小数部分恰恰来自同位素混合。

周期表中还有一些值得记住的「区域名」：第 ⅠA 族（除氢）称**碱金属**，第 ⅦA 族称**卤素**，0 族称**稀有气体**；另外有一条从硼（B）到砹（At）的锯齿形**金属与非金属分界线**，线左下方是金属、右上方是非金属，紧贴分界线的元素（如硅 Si、锗 Ge）常兼具金属性与非金属性，是典型的半导体材料——这为《元素周期律（二）》判断金属性、非金属性提供了地图。

元素周期表的「分布规律」同样值得记一笔：金属元素约占已知元素的 $\frac45$，它们分布在分界线的左下方；非金属主要集中在右上角，数量较少。副族与第Ⅷ族统称**过渡元素**，都是金属，它们的性质与主族金属不尽相同——例如铁、铜的变价现象就与 d 电子参与成键有关，这在选择性必修2会专门分析。稀有气体占据最右一列，它们的发现史（从「惰性气体」到能形成 $\ce{XeF2}$ 等化合物）恰好说明「稳定结构」也并非绝对稳定。

## 3 核素与同位素：同一元素的不同原子

上一节说「质子数决定元素种类」，但没有规定中子数必须相同。**质子数相同而中子数不同的一类原子，互称同位素（isotope）**；每种具体的「具有一定质子数和中子数的原子」称为一种**核素（nuclide）**。

三种天然的氢元素是理解同位素的最好例子：

| 核素 | 名称 | 质子数 | 中子数 | 质量数 |
| --- | --- | --- | --- | --- |
| $\ce{^1_1H}$ | 氕（piē） | 1 | 0 | 1 |
| $\ce{^2_1H}$ 或 $\ce{D}$ | 氘（dāo） | 1 | 1 | 2 |
| $\ce{^3_1H}$ 或 $\ce{T}$ | 氚（chuān） | 1 | 2 | 3 |

三者质子数相同，都是氢元素，化学性质几乎完全一样；但中子数不同，相对原子质量不同。碳的同位素有 $\ce{^{12}C}$、$\ce{^{13}C}$、$\ce{^{14}C}$，氯有 $\ce{^{35}Cl}$ 与 $\ce{^{37}Cl}$。<span class="marginnote">$\ce{^{14}C}$ 半衰期约 5730 年，生物死亡后体内碳-14 不断衰变而不再补充，据此可以测定文物年代——这就是著名的「碳-14 断代法」。同位素不仅能考古，$\ce{^{235}U}$ 与 $\ce{^{238}U}$ 的差别更是核能利用的核心。</span>

同位素的应用值得专门一提：氢的三种同位素中，氘（$\ce{^2_1H}$）与氧结合成的**重水** $\ce{D2O}$ 是核反应堆的中子减速剂；$\ce{^{235}U}$ 是核裂变的燃料；医疗诊断中常用放射性同位素示踪。<span class="marginnote">同位素化学性质几乎相同、但「质量」不同，这一「一字之差」被广泛利用——质量大的水分子蒸发更慢、扩散更慢，科学家据此可以追踪水循环。同位素是「给分子贴标签」的天然手段。</span>

**辨析｜易错点：** 同位素与同素异形体是两回事。同位素是「同一元素的不同原子」（微观，比的是质子数），同素异形体是「同一元素组成的不同单质」（宏观，如金刚石与石墨、$\ce{O2}$ 与 $\ce{O3}$）。判断口诀：**对原子谈同位素，对单质谈同素异形体**。

科学家已经发现，多数元素在自然界中都以多种同位素的混合物存在，其中丰度最大的核素称为该元素的主要核素；不同来源的同位素丰度可能略有差异（如深海与浅海水的氘含量不同），这使高精度测量中元素的相对原子质量会有极其微小的波动——所谓「原子量」是一个统计平均量，不是自然界唯一的常量。

**例题：** 已知自然界中硼有两种核素 $\ce{^{10}B}$（相对原子质量 10）与 $\ce{^{11}B}$（相对原子质量 11），硼的相对原子质量为 10.8，求 $\ce{^{10}B}$ 的丰度。

设 $\ce{^{10}B}$ 的丰度为 $x$，则 $\ce{^{11}B}$ 的丰度为 $1-x$，有 $10x + 11(1-x) = 10.8$，解得 $x = 0.2$，即丰度为 20%。这道题用的是与求氯的 35.5 完全相同的加权平均模型——只要记住「相对原子质量是加权平均」，这类题就是解一个一元一次方程，不必死记任何数字。

## 4 公式解析：元素的相对原子质量是「加权平均」

周期表里氯的相对原子质量写成 35.5，可氯的每个核素相对原子质量都是整数（35 或 37），35.5 从何而来？因为自然界里的氯是两种核素的混合物，35.5 是**按丰度加权平均**的结果：

$$M = \frac{f_1 M_1 + f_2 M_2 + \cdots}{f_1 + f_2 + \cdots} = \sum_i f_i M_i \quad (\sum_i f_i = 1)$$

- **第一步，认符号**：$M_i$ 是第 $i$ 种核素的相对原子质量，$f_i$ 是它的丰度（该核素在自然界中所占的原子数目分数，$0 \le f_i \le 1$）。
- **第二步，为什么是加权平均**：取 100 个氯原子，约 75.77 个是 $\ce{^{35}Cl}$、24.23 个是 $\ce{^{37}Cl}$，则平均每个原子质量为 $0.7577 \times 35 + 0.2423 \times 37 = 35.485 \approx 35.5$。
- **第三步，与物质的量接轨**：这正是我们在《物质的量》里学的「相对原子质量」的定义。1 mol 氯原子约 $6.02\times10^{23}$ 个，质量约 35.5 g，**相对原子质量在数值上等于摩尔质量**。加权平均的思想会反复出现在统计与概率里——本质上它是「数学期望」在化学中的应用。

同理可求元素的相对原子质量、分子的相对分子质量。**易错点：** 元素周期表上的原子量一律是加权平均值，不是某一核素的质量数。

## 5 原子序数的意义：莫塞莱的补完

门捷列夫按相对原子质量排序，但现代周期表按**原子序数**排序——两者多数时候一致，却也有「序」的例外。1913 年，莫塞莱（Henry Moseley）用 X 射线轰击不同金属，发现各元素 X 射线波长与原子序数 $Z$ 之间存在确定关系，从而证明：**真正决定元素在周期表中位置的是核电荷数（质子数），而非相对原子质量**。<span class="marginnote">镍与钴按相对原子质量应排为 Ni（58.69）在 Co（58.93）之前，但按化学性质钴应在镍之前——莫塞莱证明钴的 $Z=27$ 小于镍的 $Z=28$，问题迎刃而解。「按什么排序」是周期表史上最重要的方法论之争。</span>

这个结论还与我们的「从极限到大模型」主线呼应：**找到正确的排序变量，比排列本身更重要**。门捷列夫排表时用的是「质量」这个代理变量，莫塞莱用实验把它升级为「核电荷数」这个本质变量——科学进步常常就是把「代理」换成「本质」。

**例题：** 某主族元素位于第 3 周期第 ⅥA 族。

- **问 1**：它的原子序数是多少？第 3 周期第 ⅥA 族即硫 S，原子序数 16。
- **问 2**：它的原子结构如何？3 个电子层、最外层 6 个电子，示意图为 $\ce{+16) 2) 8) 6}$。
- **问 3**：它的最高正价与最低负价？最高正价 $+6$（主族序数），最低负价 $-2$（$8 - 6$）。

把「周期序数 = 电子层数、主族序数 = 最外层电子数」用成条件反射，是本章最重要的基本功；结合周期律后，你还能进一步预测它的金属性、非金属性与氢化物稳定性——那正是下一节《元素周期律》的内容。

## 6 小结

- 元素周期表：**7 个周期**（周期序数 = 电子层数）、**18 个纵列、16 个族**（主族序数 = 最外层电子数）。
- 主族元素满足「**位置 ⇄ 结构**」双向换算：由位置推结构、由结构定位位置。
- 一格四信息：原子序数、元素符号、元素名称、相对原子质量；后者是加权平均值，不是质量数。
- **核素**：具有一定质子数与中子数的一种原子；**同位素**：质子数相同而中子数不同的核素，化学性质几乎相同。
- 元素相对原子质量是各核素相对原子质量按**丰度加权平均**的结果，数值上等于摩尔质量（g/mol）。
- 现代周期表按**原子序数**（核电荷数）排序，这是莫塞莱用 X 射线实验确立的。
- **同位素不是另一种元素**：同位素仍属同一元素、化学性质几乎相同；只有质子数变了，才变成另一种元素。
