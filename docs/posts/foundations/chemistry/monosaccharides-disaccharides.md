## 为什么糖的化学要从「结构」重讲

必修二认识了糖的分类与葡萄糖的银镜反应，选择性必修3 要深化两点：**单糖的立体结构**（葡萄糖的环状结构与手性）与**二糖的水解细节**（蔗糖 vs 麦芽糖的还原性差异）。糖类不仅是能量物质，更是多羟基醛酮——它的化学（还原性、成苷反应）是理解多糖、核酸等生物大分子的基础。<span class="marginnote">糖类通式常写 $\ce{C_n(H2O)_m}$（「碳水化合物」的来历），但不准确——真正的定义是「多羟基醛或多羟基酮及其聚合物」。糖类化学是生物化学的起点：ATP 的能量、DNA 的脱氧核糖，都在糖化学的延长线上。</span>

## 1 单糖：多羟基醛/酮

**核心概念：单糖（monosaccharide）**：不能水解的最简单糖类，含多个羟基与一个醛基（醛糖）或酮基（酮糖）。

**葡萄糖**（$\ce{C6H12O6}$）：**己醛糖**——6 个碳、含醛基（$\ce{-CHO}$）与 5 个羟基。开链式写作 $\ce{CH2OH(CHOH)4CHO}$。

**果糖**（$\ce{C6H12O6}$）：**己酮糖**——含酮基（$\ce{-CO-}$），与葡萄糖互为**同分异构体**。

**重点：葡萄糖的环状结构**。葡萄糖在溶液中主要以**环状半缩醛**存在（开链式与环状相互转化）：醛基碳与分子内羟基加成，形成五元/六元环。环状葡萄糖含**手性碳**，存在 α、β 两种异构体（下一节多糖详述）。<span class="marginnote">葡萄糖的环状结构：5 位碳的羟基与 1 位醛基加成，生成六元环（吡喃环）。α-葡萄糖与 β-葡萄糖区别在 1 位碳上羟基的方向——淀粉连 α、纤维素连 β。这个「一个羟基的朝向」决定了淀粉可消化、纤维素不能——结构的微小差异、功能的巨大差别。</span>

**辨析｜易错点：** ①葡萄糖是**醛糖**（有醛基、能银镜），果糖是**酮糖**（无醛基，但也能银镜——果糖在碱性条件下异构化为葡萄糖）；②葡萄糖与果糖分子式相同、结构不同——**同分异构体**；③葡萄糖在溶液中环状为主，但环与开链动态平衡，开链的醛基使葡萄糖保持还原性。

## 2 单糖的化学性质

**葡萄糖的化学性质**（多羟基 + 醛基的双重体现）：

**醛基的性质**（还原性）：
- 银镜反应：葡萄糖 + 银氨溶液 → 银镜（必修二已学）；
- 与新制 $\ce{Cu(OH)2}$ 反应 → 砖红色 $\ce{Cu2O}$（检验还原糖）。

**羟基的性质**：
- 与乙酸酯化（多羟基 → 多酯）；
- 与钠反应（羟基氢被置换）；
- 成苷反应（羟基与另一分子羟基脱水，形成糖苷键——多糖连接的化学基础）。

**重点：葡萄糖的氧化供能**。葡萄糖在体内被逐步氧化：$\ce{C6H12O6 + 6O2 -> 6CO2 + 6H2O}$，释放能量供生命活动——细胞呼吸的核心底物。<span class="marginnote">葡萄糖的体内氧化是「燃烧」的缓慢版：一步放一点能量（通过 ATP 储存），而非像火焰一样瞬间释放。这个「分步降能」的策略是生命能量管理的核心，生物化学（第五级《生物化学与分子生物学》）中糖酵解、三羧酸循环都从这里展开。</span>

**辨析｜易错点：** ①葡萄糖能银镜说明含**醛基**（开链形式）；②检验葡萄糖（还原糖）用银镜或新制 $\ce{Cu(OH)2}$——斐林试剂（$\ce{NaOH}$ 过量）是标准方法；③葡萄糖的还原性来自醛基，但果糖也能使斐林试剂还原（碱性下异构）——「还原糖」不等于「含醛基的糖」。

## 3 二糖：两分子单糖缩合

**核心概念：二糖（disaccharide）**：由两分子单糖**脱水缩合**（成苷）而成，水解后生成两分子单糖。

**蔗糖**（$\ce{C12H22O11}$）：葡萄糖 + 果糖缩合。**无游离醛基**——**非还原糖**（不能银镜、不能还原斐林试剂）。

**麦芽糖**（$\ce{C12H22O11}$）：两分子葡萄糖缩合。**有游离醛基**——**还原糖**（能银镜）。

**公式解析：蔗糖与麦芽糖的水解**

- **第一步，写蔗糖水解**：$\ce{C12H22O11 + H2O ->[催化剂] C6H12O6(葡萄糖) + C6H12O6(果糖)}$。
- **第二步，写麦芽糖水解**：$\ce{C12H22O11 + H2O ->[催化剂] 2C6H12O6(葡萄糖)}$。
- **第三步，对比还原性**：蔗糖水解**前**无还原性（醛基被缩合封闭）、水解后变还原性（生成的葡萄糖、果糖有醛基/可异构）；麦芽糖水解前后都有还原性。

**结论：判断二糖是否还原性，看它是否有「游离的醛基」**——蔗糖的醛基在成苷时被封闭（1,2-苷键），麦芽糖保留一个游离醛基。<span class="marginnote">「蔗糖非还原、麦芽糖还原」的根源是成苷方式：蔗糖用葡萄糖的 1 位醛基碳与果糖的 2 位酮基碳相连——两个端基都参与成苷、没有游离醛基；麦芽糖用葡萄糖 1 位与另一葡萄糖 4 位相连——后者的醛基仍游离。这个「端基是否被封闭」的概念，下一节多糖中还要用。</span>

**辨析｜易错点：** ①蔗糖与麦芽糖分子式相同（$\ce{C12H22O11}$），互为**同分异构体**；②「水解后能银镜」不是「糖本身还原性」——蔗糖水解前不能银镜、水解后能；③检验蔗糖水解产物要先**加碱中和硫酸**（水解催化剂是酸，银镜需碱性）。

## 4 单糖二糖的用途

- 葡萄糖：医疗输液（补充能量）、食品；
- 蔗糖：食糖（甘蔗、甜菜）；
- 麦芽糖：饴糖（麦芽糖浆）、食品添加剂；
- 果糖：蜂蜜的主要成分（甜度最高）。

**重点：甜度与结构**。果糖甜度最高（约蔗糖 1.7 倍）、蔗糖次之、葡萄糖较低、麦芽糖更低——甜度由分子结构决定，与营养无关。<span class="marginnote">「果糖最甜」使高果糖玉米糖浆（HFCS）成为食品工业的主要甜味剂。但过量果糖的代谢（不经胰岛素调控、直接入肝脏合成脂肪）与肥胖、脂肪肝相关——糖化学连着公共健康议题（第五级《营养与食品卫生学》）。</span>

## 5 糖类的检验与糖尿病检测

糖类化学在医学上的一个重要应用是**血糖检测**——它直接利用了葡萄糖的还原性，把「分析化学」与「健康」连在一起。

**核心概念：血糖检测的原理**。葡萄糖含醛基（还原性），能与新制 $\ce{Cu(OH)2}$ 或银氨溶液反应——现代血糖仪用**葡萄糖氧化酶**把葡萄糖氧化，产生的信号与浓度相关（更灵敏专一）。

**重点：尿糖检测的化学**。传统尿糖检测用班氏试剂（含 $\ce{Cu^{2+}}$ 的碱性试剂）：尿中含葡萄糖（还原糖）→ 加热 → 绿色（微量）→ 黄色（少量）→ 砖红色（多量）——颜色深浅反映糖量。

**公式解析：为什么糖尿病患者的尿「甜且能还原铜」**

- **第一步，看血糖**：胰岛素不足 → 血糖升高 → 超过肾糖阈 → 尿中排出葡萄糖。
- **第二步，看化学**：尿中葡萄糖含醛基 → 能还原班氏试剂（砖红沉淀）——检验依据。
- **第三步，看临床**：「尿糖阳性 + 多饮多食多尿」→ 提示糖尿病——化学检验是诊断的一环。

**结论：血糖/尿糖检测 = 「葡萄糖还原性 + 显色反应」的应用**。<span class="marginnote">从班氏试剂的砖红色到现代血糖仪的酶电极，检测原理都建立在「葡萄糖的还原性/被氧化」之上——只是「信号转化」方式进步了。这个「化学性质 → 检测方法 → 临床诊断」的链条，是分析化学与医学的桥梁（第五级《临床检验》），也再次体现「一个性质、多个应用」。</span>

**辨析｜易错点：** ①班氏试剂检测的是「还原糖」（含葡萄糖等）——不只是葡萄糖；②尿糖阳性不一定就是糖尿病（肾糖阈个体差异）——需血糖确诊；③检测「还原糖」与「含糖量」不同——还原糖的还原能力换算糖量是定量分析的内容。

**补充：糖类的「环状结构」与苷键**。葡萄糖在溶液中以环状为主（环状与开链动态平衡）——环状葡萄糖的 1 位碳（异头碳）有两种取向（α 与 β），α/β 之间的转化叫「变旋」。两分子单糖通过「苷键」（成苷反应）连接成二糖/多糖——苷键的类型（α-1,4、β-1,4）决定多糖能否被消化（淀粉 α 可食、纤维素 β 不可食）。「环状结构 → 异头碳 → 苷键」是糖类从单糖走向多糖的桥梁。

**补充：糖类的「甜度」与热量**。甜度是糖与人味觉受体的结合强度——果糖最甜（甜度约蔗糖 1.7 倍）、蔗糖 1、葡萄糖 0.7、麦芽糖 0.4。甜度与营养无关（甜味剂糖精更甜但无热量）。「甜 ≠ 糖、糖 ≠ 都甜」——淀粉无甜味（高分子不刺激味蕾）、糖精非糖却极甜。「甜是味觉、糖是化学」——概念之辨。

**补充：单糖的「命名与结构」再梳理**。单糖按碳数分（丙糖、戊糖、己糖）、按官能团分（醛糖/酮糖）：葡萄糖是己醛糖、果糖是己酮糖、核糖是戊醛糖（RNA 成分）、脱氧核糖（DNA）。「碳数 × 官能团」的双维度命名，是糖类分类的坐标。「每个糖名 = 碳数 + 糖型」——读懂名字就懂结构。单糖的立体异构众多（葡萄糖 16 种）——手性在糖中普遍。

**补充：糖类与「生物化学」的连接**。糖类是生物化学的起点：葡萄糖是细胞呼吸的底物（糖酵解 → 三羧酸循环 → 能量）；核糖/脱氧核糖是核酸的骨架（RNA/DNA）；糖蛋白参与细胞识别。「糖的化学延伸到生命代谢」——从单糖到核酸、从供能到结构，「糖类是有机化学与生物化学的交汇点」。「学糖，是在学生命的『能量与信息分子』」。

**补充：二糖的「成苷」本质再梳理**。二糖 = 两分子单糖通过「苷键」（脱水缩合）连接：蔗糖（葡萄糖 + 果糖，α-1,2-苷键）、麦芽糖（两分子葡萄糖，α-1,4-苷键）。「苷键的形成封闭了端基碳」——蔗糖两端都封闭（非还原）、麦芽糖留一端（还原）。「苷键的类型决定二糖的还原性与水解产物」——「成苷是糖类聚合的基本方式」。

**补充：葡萄糖的「结构」再确认**。葡萄糖开链式 $\ce{CH2OH(CHOH)4CHO}$——含 1 个醛基 + 5 个羟基。溶液中以环状半缩醛为主（环与链动态平衡）。「醛基使葡萄糖具还原性（银镜）」、羟基使葡萄糖亲水、可酯化。「一个分子、两类官能团（醛基 + 羟基）」——葡萄糖的化学由此展开。「理解葡萄糖的结构，就理解了它的化学与生理功能」。

**补充：糖类的「分类」再梳理**。糖类按水解分：单糖（不水解——葡萄糖、果糖）、二糖（水解成 2 分子单糖——蔗糖、麦芽糖）、多糖（水解成多分子单糖——淀粉、纤维素）。「水解程度是糖分类的标尺」——「能不能水解、水解成几个」。「单糖是基本单元、二糖多糖是聚合形式」——「糖类家族的水解谱系」。「记住分类，就记住了糖的『族谱』」。

**补充：糖类的「生理意义」再确认**。糖类的生理意义：供能（葡萄糖是主要能源）、结构（核糖/脱氧核糖构成核酸）、储存（糖原/淀粉）。「糖是生命的第一燃料」——「细胞呼吸的底物」。「糖还参与细胞识别（糖蛋白）与信号」——「糖的生理角色远超供能」。「理解糖类，就理解了生命的能量与信息基础」。

**补充：糖类的「检验」再确认**。还原糖检验：银镜（水浴、碱性）与新制氢氧化铜（砖红沉淀）。「还原糖 = 含醛基或可异构出醛基的糖」——「单糖、麦芽糖还原、蔗糖不还原」。「检验还原糖的意义：尿糖检测（医学）」——「化学检验服务医学诊断」。「记住检验方法，就掌握了糖的『身份证』」。

## 7 小结

- 单糖 = 多羟基醛（醛糖）/酮（酮糖）；葡萄糖（醛糖）与果糖（酮糖）互为同分异构体。
- 葡萄糖以**环状半缩醛**为主，开链醛基使其具还原性（银镜、斐林）。
- 葡萄糖氧化供能：$\ce{C6H12O6 + 6O2 -> 6CO2 + 6H2O}$。
- **二糖** = 两分子单糖脱水缩合；蔗糖非还原（端基封闭）、麦芽糖还原（有游离醛基）。
- 水解：蔗糖 → 葡萄糖 + 果糖；麦芽糖 → 2 葡萄糖。
