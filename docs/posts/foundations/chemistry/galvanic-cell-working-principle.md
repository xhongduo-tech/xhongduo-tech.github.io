## 为什么必修的「铜锌原电池」要升级

必修第二册的原电池是「锌片铜片插硫酸」的单液电池——它简单，却有一个致命缺点：效率低、无法持续（锌直接与溶液反应发热损耗）。选择性必修给出真正的「化学电源」原型：**双液原电池 + 盐桥**。它把氧化还原反应彻底分隔，让电子全部走导线——这才是电池的工业级工作方式。<span class="marginnote">1836 年丹尼尔电池（Zn|ZnSO₄‖CuSO₄|Cu）首次用隔膜分隔两个半电池，获得稳定持续电流。它是现代干电池、蓄电池的始祖，也定义了「半电池」这个电极反应分析的基本单元。</span>

## 1 双液原电池的构成

**核心概念：双液原电池**：由两个**半电池**（电极 + 电解质溶液）与**盐桥**构成的电池。

- **负极半电池**：锌电极浸在 $\ce{ZnSO4}$ 溶液中；
- **正极半电池**：铜电极浸在 $\ce{CuSO4}$ 溶液中；
- **盐桥**：含饱和 KCl（或琼脂）的 U 形管，连接两个半电池。

**核心概念：盐桥的作用**——平衡电荷、构成内电路。锌失电子生成 $\ce{Zn^{2+}}$，锌半电池正电荷积聚；铜半电池 $\ce{Cu^{2+}}$ 得电子，负电荷积聚。盐桥中的离子定向迁移（$\ce{Cl-}$ 移向锌半电池、$\ce{K+}$ 移向铜半电池），维持两边电中性，反应才能持续。

**辨析｜易错点：** ①**盐桥不是导线**——它靠离子迁移导电（内电路），电子不经过盐桥；②没有盐桥，双液电池立刻断路停止；③盐桥中离子移动方向判断：**阴离子移向负极半电池**（补充负电荷）、**阳离子移向正极半电池**——做题常考，用「电荷平衡」推最稳。

## 2 电极反应与电子流向

铜锌双液电池的电极反应：

**负极（锌，被氧化）**：

$$
\ce{Zn - 2e- -> Zn^{2+}}
$$

**正极（铜，被还原）**：

$$
\ce{Cu^{2+} + 2e- -> Cu}
$$

**总反应**：

$$
\ce{Zn + Cu^{2+} -> Zn^{2+} + Cu}
$$

**重点：电子与电流的流向**。电子从**负极**（锌）经外电路流向**正极**（铜）；电流方向相反（正极→负极）。溶液中**阳离子向正极迁移**（被还原）、**阴离子向负极迁移**。<span class="marginnote">记忆口诀：电子走外线（导线）、离子走内线（溶液）；「负氧正还」——负极失电子被氧化、正极得电子被还原。电荷守恒是判断离子迁移方向的唯一标准。</span>

**辨析｜易错点：** ①电极名称按「得失电子」定：失电子为负极（氧化）、得电子为正极（还原）——不是按电极材料活泼性；②电解质溶液中离子移动与电子移动是两回事，不能混淆；③盐桥中离子移动方向与溶液中一致：都向「缺对应电荷」的一侧迁移。

## 3 公式解析：电极反应式的书写

写电极反应式的「三步法」：

- **第一步，定电极与物质**：活泼金属作负极（失电子），不活泼金属或惰性电极作正极。
- **第二步，写半反应**：先写「物质 ± 电子 → 产物」，再配平电荷与原子。负极：$\ce{Zn - 2e- -> Zn^{2+}}$（电荷守恒）；正极：$\ce{Cu^{2+} + 2e- -> Cu}$。
- **第三步，合并验总**：两式相加、电子抵消得总反应 $\ce{Zn + Cu^{2+} -> Zn^{2+} + Cu}$。

**重点：电极反应书写的通用框架**。任何原电池（包括燃料电池、锂电池）的电极反应都可按此写：①找出该电极上发生的氧化/还原；②配平电子；③用 $\ce{H2O}$、$\ce{H+}$、$\ce{OH-}$ 配平介质（酸性、碱性条件不同）；④总反应 = 两极相加。

**辨析｜易错点：** ①书写时「± 电子」的符号要正确：失电子用「$-ne^-$」、得电子用「$+ne^-$」；②介质配平：酸性溶液用 $\ce{H+}$ 与 $\ce{H2O}$，碱性溶液用 $\ce{OH-}$ 与 $\ce{H2O}$，不要混用；③电子转移数 = 失电子数 = 得电子数，合并时严格相等。

## 4 电极电势：为什么电子「愿意」流动

为什么锌失电子、铜得电子，而不是反过来？因为两种金属的**失电子能力不同**——用**电极电势**定量描述。

**核心概念：电极电势（$E$）**：金属与其盐溶液构成半电池的电势。标准电极电势 $E^\circ$ 以**标准氢电极**（$\ce{Pt|H2(100kPa)|H+(1mol/L)}$，规定 $E^\circ = 0$）为基准测定。金属的标准电极电势越低（负得越多），越易失电子、越活泼。

**重点：电动势 = 两极电势差**。电池电动势 $E_{\text{cell}} = E_{\text{正极}} - E_{\text{负极}}$。锌的 $E^\circ = -0.76\ \mathrm{V}$、铜的 $E^\circ = +0.34\ \mathrm{V}$，故铜锌电池电动势约 $1.10\ \mathrm{V}$。**电子从低电势（负极，活泼金属）流向高电势（正极），正是电势差驱动的**。<span class="marginnote">标准电极电势表是电化学的「字典」：它把所有氧化还原反应的自发性排序——$E^\circ$ 越大越易得电子（氧化性强）。判断氧化还原方向、设计电池、预测反应，都靠这张表。它与金属活动性顺序一脉相承，但更定量。</span>

**辨析｜易错点：** ①电极电势大小不等于「金属活泼性」全部——它反映的是**电极反应的倾向**，与离子浓度、温度有关（能斯特方程，第五级《电化学》深化）；②$E_{\text{cell}} > 0$ 对应自发反应（$\Delta G = -nFE_{\text{cell}} < 0$）——电动势与自由能变通过这个关系式统一；③判断正负极可用「电极电势大者为正极」。

## 5 原电池的判断与设计

判断「能否构成原电池、谁是正负极」是电化学的入门题型——掌握判断标准，就能设计简单原电池。

**核心概念：原电池的构成判断**。要构成原电池，需：①活泼性不同的两电极（或一电极一惰性）；②电解质溶液；③闭合回路；④自发的氧化还原反应。四条件缺一不可。

**重点：正负极的判断方法**。
- **看活动性**：活泼金属作负极（失电子）；
- **看反应**：发生氧化反应的一极为负极（被腐蚀）；
- **看电子流向**：电子流出的是负极；
- **看离子移动**：阴离子移向负极、阳离子移向正极。

**公式解析：判断电极反应的书写**

- **第一步，定正负极**：活泼金属负极（如 Zn）、较不活泼或惰性正极（如 Cu 或 C）。
- **第二步，写半反应**：负极失电子被氧化、正极得电子被还原——配平电荷。
- **第三步，验自发性**：总反应的 $E_{\text{cell}} > 0$（自发）——不自发不能构成原电池。

**结论：原电池设计 = 「四条件 + 正负极判断 + 半反应书写」**。<span class="marginnote">「能自发的氧化还原反应」是原电池的前提：如铜锌（自发）、但铜与稀硫酸（不反应）不能构成原电池。判断自发性可用金属活动性顺序或电极电势（$E_{\text{cell}} > 0$）。这个「自发才可发电」的原则，也是原电池与电解池的根本区别——原电池自发、电解池强迫。</span>

**辨析｜易错点：** ①两电极不能是「同种金属」（无电势差，除非电解质不同）；②电解质必须参与或接触反应——不能选与两电极都不反应的溶液；③电极材料不活泼（如碳棒）也可作正极（惰性电极，只导电）。

**补充：电极电势表与金属活动性**。电极电势（$E^\circ$）是金属失电子倾向的定量标尺：$E^\circ$ 越小（负得多）金属越活泼（如 Li、K、Na）；$E^\circ$ 越大越不活泼（如 Au、Pt）。金属活动性顺序是电极电势的定性版本——「活动性越强 = 电极电势越低 = 越易作负极」。把「背活动性」升级为「理解电势」，就能预测任意金属对的电极反应方向。

**补充：原电池的「应用思维」**。原电池原理的应用远超「电池」本身：金属防腐（牺牲阳极）、金属腐蚀的机理理解（微电池）、生物电（神经细胞膜电位）、燃料电池与储能。「自发反应 → 电」的转化思路，被放大为现代能源体系的核心（电池、燃料电池、液流电池）——理解原电池，就是理解「化学能 → 电能」这个能源转换的基本方式。

**补充：原电池的「盐桥」功能再确认**。盐桥（含 KCl 的琼脂）的两大功能：①构成内电路（离子导电，使回路闭合）；②平衡电荷（离子迁移维持电中性）。盐桥中 $\ce{K+}$ 移向正极半电池、$\ce{Cl-}$ 移向负极半电池——「阳离子向正、阴离子向负」的迁移方向常考。「没有盐桥，反应即停」——盐桥是双液电池的「生命线」。

**补充：原电池的「电池符号」表示**。电池符号（电化学语言）：负极 | 负极液 ‖ 正极液 | 正极——铜锌电池写 $\ce{Zn | Zn^{2+}(c) \| Cu^{2+}(c) | Cu}$（‖ 表示盐桥）。「电池符号是原电池的『简写地图』」——一眼看清电极、溶液与盐桥。会写电池符号，是电化学的「语言能力」——从装置图到符号、再到电极反应，原电池的表达层层抽象。

**补充：原电池与「电池设计」的工程思维**。设计一个实用电池要考虑：电压（电极材料选配）、容量（活性物质量）、内阻（电解液与结构）、寿命（可逆性）、安全（隔膜、防漏）。「实验室原电池 → 实用电池」是从原理到工程的跨越——「电压看材料、容量看结构、安全看设计」。「电化学原理 + 工程优化 = 好电池」。

## 7 小结

- **双液原电池** = 两个半电池 + 盐桥；盐桥平衡电荷、构成内电路。
- 负极失电子被氧化、正极得电子被还原；电子走外线、离子走内线。
- 电极反应三步法：定电极 → 写半反应 → 合并验总。
- 介质配平看溶液酸碱性；电子转移数两极相等。
- **电极电势**驱动电子流动；$E_{\text{cell}} = E_+ - E_-$，正数为自发。
