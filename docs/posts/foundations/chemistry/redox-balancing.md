## 为什么从「电子转移」继续

上一节我们建立了一个判据：氧化还原反应，是有元素化合价升降的反应。判据有了，但问题还悬着——**升降两端的物质该叫什么名字？升降的数量如何配平？**

比如高炉炼铁的反应，铁被还原、碳被氧化，那么「谁」是那个给出电子的「好人」、「谁」是那个夺取电子的「掠夺者」？再进一步：如果给你一个从未见过的氧化还原反应，你怎么把它配平成一条原子数、电荷数都守恒的方程式？这一节回答这两个问题。它们是把氧化还原从「定性判断」推向「定量计算」的关键一跳——此后学物质的量、学原电池、学电解，电子守恒都是贯穿始终的那条线。

## 1 氧化剂与还原剂

给化合价「升高」与「降低」两个方向，配上物质的角色：

**还原剂（reducing agent）**：在反应中失去电子的物质。它所含元素化合价**升高**，本身被**氧化**，发生**氧化反应**，生成的产物叫**氧化产物**。

**氧化剂（oxidizing agent）**：在反应中得电子的物质。它所含元素化合价**降低**，本身被**还原**，发生**还原反应**，生成的产物叫**还原产物**。

六个概念挤在一起容易乱，用一张表钉死：

| 角色 | 电子去向 | 化合价 | 本身被 | 发生反应 | 生成 |
| --- | --- | --- | --- | --- | --- |
| 还原剂 | 失去电子 | 升高 | 被氧化 | 氧化反应 | 氧化产物 |
| 氧化剂 | 得到电子 | 降低 | 被还原 | 还原反应 | 还原产物 |

记这六个概念，用一句口诀：**升失氧化还原剂，降得还原氧化剂。** 拆开读：化合价**升**高、**失**电子、被**氧化**、作**还原剂**、生成**氧化产物**；化合价**降**低、**得**电子、被**还原**、作**氧化剂**、生成**还原产物**。<span class="marginnote">这句口诀是氧化还原的「总纲」，往后所有题目都从它出发。提醒一句：「氧化剂」「还原剂」是对<strong>物质</strong>的称呼，「氧化反应」「还原反应」是对<strong>过程</strong>的称呼——问「哪个物质作氧化剂」和问「哪个过程是氧化反应」，答案对象完全不同。</span>

回到炼铁反应，逐个对号入座：

$$\ce{Fe2O3 + 3CO ->[\text{高温}] 2Fe + 3CO2}$$

- $\ce{Fe2O3}$ 中铁降价（$+3 \rightarrow 0$），$\ce{Fe2O3}$ 作**氧化剂**，被还原，生成**还原产物** $\ce{Fe}$；
- $\ce{CO}$ 中碳升价（$+2 \rightarrow +4$），$\ce{CO}$ 作**还原剂**，被氧化，生成**氧化产物** $\ce{CO2}$。

## 2 常见氧化剂与还原剂

见多才能识广，把常见的氧化剂与还原剂各记一串：

- **常见氧化剂**：氧气（$\ce{O2}$）、氯气（$\ce{Cl2}$）、浓硫酸（浓 $\ce{H2SO4}$）、硝酸（$\ce{HNO3}$）、高锰酸钾（$\ce{KMnO4}$）、氯化铁（$\ce{FeCl3}$）、过氧化氢（$\ce{H2O2}$）。
- **常见还原剂**：活泼金属（$\ce{K}$、$\ce{Na}$、$\ce{Mg}$、$\ce{Al}$、$\ce{Zn}$、$\ce{Fe}$）、碳（$\ce{C}$）、氢气（$\ce{H2}$）、一氧化碳（$\ce{CO}$）、氯化亚铁（$\ce{FeCl2}$）、碘化钾（$\ce{KI}$）、亚硫酸钠（$\ce{Na2SO3}$）。

两条规律值得记住：

- **氧化性看「得电子能力」，不看「得电子数目」。** 钠原子失 1 个电子，镁原子失 2 个电子，但钠的还原性远强于镁——还原性取决于失电子的**难易**，而不是多少。容易失电子的，失几个都容易。
- **中间价态的物质，既可能作氧化剂也可能作还原剂。** $\ce{S}$、$\ce{N}$、$\ce{Fe}$ 的中间价态化合物（如 $\ce{SO2}$、$\ce{H2O2}$、$\ce{Fe^2+}$）遇到更强氧化剂时被氧化，遇到更强还原剂时被还原，一身两役。<span class="marginnote">这与元素周期律（第四章）直接呼应：金属性越强、越靠周期表左下，还原性越强；非金属性越强、越靠右上，氧化性越强。价态与位置，两条线索最终指向同一张周期表。</span>

## 3 氧化还原方程式的配平：化合价升降法

配平一个氧化还原反应，要同时满足两条守恒：**质量守恒**（原子种类、数目不变）与**电子守恒**（氧化剂得电子总数 = 还原剂失电子总数）。后者是氧化还原配平独有的约束，也是配平的入手点。方法叫**化合价升降法**，五步走：

- **第一步，标变价**：标出反应前后有变化的元素化合价。
- **第二步，找升降**：算出每个原子升、降的数值。
- **第三步，求最小公倍数**：让升降总数相等，据此定出氧化剂、还原剂（或氧化产物、还原产物）的系数。
- **第四步，配其他**：用观察法配平其余物质的系数。
- **第五步，查守恒**：核对原子守恒；若是离子反应，还要核对电荷守恒。

## 4 公式解析：配平 Fe2O3 + CO

把五步法落在炼铁反应上。题目：配平 $\ce{Fe2O3 + CO -> Fe + CO2}$。

**第一步，标变价。**

$$\ce{\overset{+3}{Fe}2O3 + \overset{+2}{C}O -> \overset{0}{Fe} + \overset{+4}{C}O2}$$

铁从 +3 降到 0，碳从 +2 升到 +4。

**第二步，找升降。** 每个铁原子**降 3**，每个碳原子**升 2**。

**第三步，求最小公倍数。** 3 与 2 的最小公倍数是 6。$\ce{Fe2O3}$ 里有 2 个铁，若系数为 1，铁共降 $2 \times 3 = 6$；要让碳共升 6，需要 3 个碳原子，即 $\ce{CO}$ 系数为 3。

$$\ce{Fe2O3 + 3CO -> Fe + CO2}$$

**第四步，配其他。** 铁守恒：右边 $\ce{Fe}$ 系数为 2；碳守恒：3 个碳进、3 个碳出，右边 $\ce{CO2}$ 系数为 3。

**第五步，查守恒。** 氧原子：左边 $3 + 3 = 6$，右边 $3 \times 2 = 6$，守恒。配平完成：

$$\ce{Fe2O3 + 3CO ->[\text{高温}] 2Fe + 3CO2}$$

配平完成的反应，电子转移可以这样核对：铁共得 $2 \times 3 = 6$ 个电子（$\ce{Fe^3+}$ 降到 0 价），碳共失 $3 \times 2 = 6$ 个电子（$\ce{C}$ 从 +2 升到 +4），**得电子总数 = 失电子总数 = 6**。这就是双线桥法的实质——两条线，一条「得 6e⁻」标在铁上，一条「失 6e⁻」标在碳上，方向相反、数目相等。

再配一个化合反应练手：$\ce{Fe + Cl2 -> FeCl3}$。铁升 3，氯从 0 降到 −1、每个氯降 1。最小公倍数为 3：1 个铁配 3 个氯原子不够成双（氯气是双原子分子），取 2 个铁、6 个氯原子，即 $\ce{2Fe + 3Cl2 -> 2FeCl3}$。核对：铁 $2 \times 3 = 6$，氯 $6 \times 1 = 6$，守恒。<span class="marginnote">配平遇到「单质成双」时，先按最小公倍数定出电子数，再凑成单质分子的整数倍。电子守恒先行，配平就永远有方向感。</span>

## 5 电子守恒的应用（初步）

电子守恒不只是配平工具，它直接给出氧化还原的**数量关系**。用一个例子说明：铁在氯气中燃烧，$\ce{2Fe + 3Cl2 -> 2FeCl3}$，那么 1 mol 铁完全反应需要多少氯气？

每个铁失 3 个电子，1 mol 铁共失 3 mol 电子；每个氯原子得 1 个电子，需要 3 mol 氯原子，即 $3 \div 2 = 1.5$ mol 氯气分子。答案：1 mol 铁消耗 1.5 mol 氯气。

这种「得失电子数相等」的算术，是之后化学计算（第二章物质的量、原电池电量计算、电解产物计算）的通用引擎：**凡是氧化还原，先写电子守恒，再谈其他。**<span class="marginnote">电子守恒相当于化学反应里的「复式记账」：借方得电子、贷方失电子，账目永远平。开尔文那句「用数字表达才算真正了解」，正是这里的主旨——配平把氧化还原从现象变成了可计算的账本。</span>

电子守恒还能反过来判断「谁作氧化剂、谁作还原剂」。看一个把 $\ce{SO2}$ 氧化的反应：

$$\ce{SO2 + Cl2 + 2H2O -> H2SO4 + 2HCl}$$

硫从 +4 升到 +6，失去 2 个电子，$\ce{SO2}$ 作**还原剂**；氯从 0 降到 −1，每个氯得 1 个电子，$\ce{Cl2}$ 作**氧化剂**。核对数目：1 个 $\ce{SO2}$ 失 2 个电子，1 个 $\ce{Cl2}$（2 个氯原子）得 2 个电子，恰好平账。两个角色、一个等式，一眼看穿。

## 6 易错辨析

- **氧化剂与还原剂可以是同一种物质。** 氯气与氢氧化钠反应 $\ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}$ 中，氯从 0 价分别变成 −1 与 +1，既得电子又失电子——$\ce{Cl2}$ 同时作氧化剂和还原剂。这种「自我歧化」的反应叫**歧化反应**，到必修第二册学氯时会再相见。<span class="marginnote">金属单质只有还原性（金属没有负化合价）；非金属单质则可能兼具氧化性与还原性（如 $\ce{Cl2}$、$\ce{S}$），因为非金属元素存在多种价态。</span>
- **「被氧化」的对象是元素（或物质），「氧化反应」是过程，别把角色和过程混为一谈。**
- **得失电子数目 ≠ 得失电子能力。** 比较氧化性、还原性强弱，看价态变化的趋势与金属活动性，不看电子数多少。
- **配平后必须回头查一遍**：原子守恒必查，离子反应（如酸性高锰酸钾氧化亚铁离子）还要查电荷守恒——漏掉电荷守恒是离子型氧化还原配平的头号错误。

## 7 小结

- **角色表**：还原剂失电子、化合价升、被氧化、生成氧化产物；氧化剂得电子、化合价降、被还原、生成还原产物。口诀「**升失氧化还原剂，降得还原氧化剂**」。
- **常见氧化剂**：$\ce{O2}$、$\ce{Cl2}$、浓 $\ce{H2SO4}$、$\ce{HNO3}$、$\ce{KMnO4}$；**常见还原剂**：活泼金属、$\ce{C}$、$\ce{H2}$、$\ce{CO}$。
- **配平五步**：标变价 → 找升降 → 求最小公倍数定系数 → 配其他 → 查守恒。
- **两条守恒**：质量守恒 + 电子守恒（氧化剂得电子总数 = 还原剂失电子总数）。
- **应用**：电子守恒是氧化还原定量计算的通用引擎，贯穿物质的量、原电池、电解。
