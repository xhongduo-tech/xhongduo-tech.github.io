## 为什么从「离子反应」开始

上一节，我们把电解质放进了水里——它拆成离子，获得自由。这一节，我们把两种电解质溶液「倒在一起」。奇妙的事情发生了：一杯硫酸钠溶液与一杯氯化钡溶液混合，立刻出现白色沉淀，而溶液依然透明。**反应明明发生了，可它到底发生在谁和谁之间？**

答案要在离子的层面上找。溶液里的反应，往往只有「一部分离子」真正参与，其余离子只是在一旁充当「观众」。把真正的「演员」找出来、用最简的形式记录下来，就是这一节的全部工作。这套「从混合溶液的现象，反推出谁和谁结合」的能力，是分析化学与一切溶液定量计算的看家本领，也是选择性必修 1《化学反应原理》第三章「水溶液中的离子反应与平衡」的地基。

## 1 溶液里的真正演员

把 $\ce{Na2SO4}$ 溶液与 $\ce{BaCl2}$ 溶液混合，化学方程式这样写：

$$\ce{Na2SO4 + BaCl2 -> BaSO4 v + 2NaCl}$$

但如果我们先问一句「溶液里到底有什么」，就会看到更本质的画面。混合前，$\ce{Na2SO4}$ 溶液里飘着 $\ce{Na+}$ 与 $\ce{SO4^2-}$，$\ce{BaCl2}$ 溶液里飘着 $\ce{Ba^2+}$ 与 $\ce{Cl-}$——四种离子各自自由。混合后，真正结合的是 $\ce{Ba^2+}$ 与 $\ce{SO4^2-}$，它们生成难溶的 $\ce{BaSO4}$ 沉淀而脱离溶液；而 $\ce{Na+}$ 与 $\ce{Cl-}$ 什么也没做，混合前后都以游离离子形式存在。

于是化学家给出定义：

**离子反应（ionic reaction）**：电解质在溶液中发生的反应，实质上是离子之间的反应。

**离子反应的实质，是溶液中某些离子的浓度减小**——$\ce{Ba^2+}$ 与 $\ce{SO4^2-}$ 因生成沉淀而大量减少，反应才得以发生。<span class="marginnote">全程没参与的 $\ce{Na+}$ 与 $\ce{Cl-}$ 叫「旁观离子」（spectator ions）——它们只是从一个容器跟到另一个容器，从不改变自己。化学里的「旁观者」概念，与数学里「不影响结果的量」、编程里「只读不改的输入」是同一种节俭。</span>

## 2 离子方程式：写、拆、删、查

化学方程式描述「分子层面」的全貌，但我们想只看「离子层面」的精髓。于是用**离子方程式（ionic equation）**：用实际参加反应的离子的符号来表示化学反应的式子。

书写分四步，口诀是「写、拆、删、查」：

- **第一步，写**：写出反应的化学方程式。$\ce{Na2SO4 + BaCl2 -> BaSO4 v + 2NaCl}$
- **第二步，拆**：把易溶于水、易电离的物质写成离子形式；难溶物、气体、弱电解质、单质、氧化物不拆。<span class="marginnote">拆与不拆，是离子方程式唯一的技术难点，也是全部失分点。判断依据：该物质在溶液里「实际存在形式」是离子还是分子——是离子就拆，仍是分子/固体/气体就不拆。</span>
  $$\ce{2Na+ + SO4^2- + Ba^2+ + 2Cl- -> BaSO4 v + 2Na+ + 2Cl-}$$
- **第三步，删**：删去方程式两边不参加反应的离子——两边都有、数目相同的 $\ce{2Na+}$ 与 $\ce{2Cl-}$ 一并划掉。
- **第四步，查**：检查两边的原子种类、数目守恒，以及电荷守恒。

得到离子方程式：

$$\ce{Ba^2+ + SO4^2- -> BaSO4 v}$$

哪些拆、哪些不拆，用一张表定下来：

| 状态 | 处理 | 例子 |
| --- | --- | --- |
| 强酸（$\ce{HCl}$、$\ce{H2SO4}$、$\ce{HNO3}$） | 拆 | $\ce{2H+ + SO4^2-}$ |
| 强碱（$\ce{NaOH}$、$\ce{KOH}$、$\ce{Ba(OH)2}$） | 拆 | $\ce{2Na+ + 2OH-}$ |
| 可溶性盐 | 拆 | $\ce{Ba^2+ + 2Cl-}$ |
| 难溶物（沉淀） | 不拆 | $\ce{BaSO4}$、$\ce{CaCO3}$、$\ce{AgCl}$ |
| 气体、挥发性物质 | 不拆 | $\ce{CO2}$、$\ce{H2}$、$\ce{SO2}$ |
| 水等弱电解质 | 不拆 | $\ce{H2O}$、$\ce{CH3COOH}$ |
| 单质、氧化物 | 不拆 | $\ce{Fe}$、$\ce{Cu}$、$\ce{Na2O}$ |

一个离子方程式常常可以「一顶多」。例如中和反应的离子方程式：

$$\ce{H+ + OH- -> H2O}$$

它既代表 $\ce{NaOH + HCl}$，也代表 $\ce{KOH + H2SO4}$、$\ce{NaOH + HNO3}$……所有「强酸 + 强碱 → 盐 + 水」的强酸强碱中和反应，都可以浓缩成这一条。<span class="marginnote">这正是离子方程式的威力：它滤掉了无关的旁观离子，直指反应的「最小内核」。就像代码里抽出一个公共函数，所有同类调用都归它管。</span>

## 3 离子反应发生的条件

是不是随便两种电解质溶液混在一起都会反应？不是。以 $\ce{NaCl}$ 与 $\ce{KNO3}$ 混合为例：溶液里有 $\ce{Na+}$、$\ce{Cl-}$、$\ce{K+}$、$\ce{NO3-}$ 四种离子，它们两两组合要么可溶、要么是强电解质，没有任何离子浓度减小，**不反应**——混合前后只是四种离子「共同住在一杯水里」。

复分解类型的离子反应要想发生，必须满足下列条件**之一**：

- **生成沉淀**（难溶物）：如 $\ce{BaSO4}$、$\ce{AgCl}$、$\ce{CaCO3}$；
- **生成气体**（挥发性物质）：如 $\ce{CO2}$、$\ce{SO2}$、$\ce{NH3}$；
- **生成水**（难电离物质）：如酸碱中和。

**辨析｜易错点：三个条件背后是同一个本质——溶液中某些离子的浓度明显减小。** 沉淀是「离子被锁进固体」，气体是「离子变成分子逃出溶液」，水是「离子结合成难电离的分子」。表面三条路，内核一个道理。所以「生成沉淀、气体或水」只是易记的口诀，答题时说「离子浓度减小」才是触及实质。

## 4 公式解析：四步法写离子方程式

把「写拆删查」在一个完整例子上走一遍。题目：碳酸钠溶液与稀盐酸反应的离子方程式。

**第一步，写化学方程式：**

$$\ce{Na2CO3 + 2HCl -> 2NaCl + CO2 ^ + H2O}$$

**第二步，拆成离子：** $\ce{Na2CO3}$、$\ce{HCl}$、$\ce{NaCl}$ 都是易溶易电离的，拆；$\ce{CO2}$ 是气体，$\ce{H2O}$ 是弱电解质，不拆。

$$\ce{2Na+ + CO3^2- + 2H+ + 2Cl- -> 2Na+ + 2Cl- + CO2 ^ + H2O}$$

**第三步，删去两边相同的 $\ce{2Na+}$ 与 $\ce{2Cl-}$：**

$$\ce{CO3^2- + 2H+ -> CO2 ^ + H2O}$$

**第四步，检查守恒：** 原子——左 C 1、O 3、H 2，右 C 1、O 2+1=3、H 2，守恒；电荷——左 $(-2)+2\times(+1)=0$，右为电中性，守恒。结论正确。

这一条离子方程式浓缩了「碳酸盐 + 强酸」这一类反应：任何可溶性碳酸盐与强酸反应放出 $\ce{CO2}$，都归结为 $\ce{CO3^2-}$ 与 $\ce{H+}$ 的结合。实验室里用大理石（$\ce{CaCO3}$）与稀盐酸制 $\ce{CO2}$，本质也是它——只是 $\ce{CaCO3}$ 不拆，方程式写成 $\ce{CaCO3 + 2H+ -> Ca^2+ + CO2 ^ + H2O}$。

再走一个「两条腿」的例子：氢氧化钡溶液与稀硫酸恰好完全反应，生成沉淀与水，两个条件同时满足。

$$\ce{Ba(OH)2 + H2SO4 -> BaSO4 v + 2H2O}$$

拆开：$\ce{Ba(OH)2}$ 与 $\ce{H2SO4}$ 拆成离子，$\ce{BaSO4}$（沉淀）与 $\ce{H2O}$（弱电解质）不拆：

$$\ce{Ba^2+ + 2OH- + 2H+ + SO4^2- -> BaSO4 v + 2H2O}$$

这里**没有任何旁观离子**——四种离子全部参与反应，所以删无可删。核对电荷：左边 $(+2)+2\times(-1)+2\times(+1)+(-2)=0$，守恒。这个例子提醒我们：并非每个离子方程式都要「删」，删的前提是存在两边重复的离子；没有重复时，就把真正反应的离子原样写全。

## 5 易错辨析：拆与不拆的陷阱

- **沉淀、气体、水、单质、氧化物永远不拆。** 看到 $\ce{BaSO4}$、$\ce{CO2}$、$\ce{H2O}$、$\ce{Fe}$、$\ce{Na2O}$，一律保留化学式。
- **检查电荷守恒。** 铁与稀硫酸反应生成 $\ce{Fe^2+}$ 而不是 $\ce{Fe^3+}$：$\ce{Fe + 2H+ -> Fe^2+ + H2 ^}$。写完离子方程式必须数一数两边电荷是否相等——这是「写、拆、删、查」里最容易被跳过的第四步。<span class="marginnote">$\ce{Fe + 2H+ -> Fe^2+ + H2 ^}$ 左边电荷 $+2$，右边 $+2$，守恒；若误写成 $\ce{Fe^3+}$，右边是 $+6$，电荷立即失衡——电荷守恒帮你一秒识破。</span>
- **微溶物看情况。** $\ce{Ca(OH)2}$ 是微溶物：澄清石灰水（溶液）中拆成 $\ce{Ca^2+ + 2OH-}$；石灰乳（悬浊液）中不拆。写法由反应物实际状态决定。<span class="marginnote">酸式盐的拆法是一个延伸话题：$\ce{NaHSO4}$ 在水溶液中完全电离成 $\ce{Na+ + H+ + SO4^2-}$，而 $\ce{NaHCO3}$ 只电离出 $\ce{Na+ + HCO3-}$（碳酸是弱酸）。这个差别在选择性必修 1 讲弱电解质时会彻底展开。</span>
- **离子方程式表示的是一类反应**，它不唯一对应某个具体化学方程式——这正是它「简洁」的代价与价值。

## 6 小结

- **离子反应**：电解质溶液间反应的实质是离子间的反应；其实质是**某些离子浓度减小**。
- **离子方程式四步**：**写 → 拆 → 删 → 查**；拆与不拆取决于物质在溶液中的实际存在形式。
- **不拆清单**：沉淀、气体、水等弱电解质、单质、氧化物。
- **发生条件**：生成沉淀、气体或水，三选一；本质都是离子浓度减小。
- **两条守恒**：原子守恒 + 电荷守恒，是检验离子方程式的终极标准。
