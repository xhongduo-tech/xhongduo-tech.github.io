## 为什么「合成」是有机化学的终极考验

学完各类官能团的反应后，真正的挑战来了：**给你一个目标分子，如何从简单原料出发合成它？** 有机合成是「官能团转化知识」的综合应用——像拼图一样设计反应路线。它考验的不是单一反应，而是「逆向思维 + 路线规划」的全局能力。<span class="marginnote">有机合成的价值：从石油化工产品合成药物（阿司匹林、青蒿素衍生物）、材料（塑料、纤维）、农化产品。1910 年代合成氨、1930 年代合成维生素、1950 年代合成甾体激素，都是改变人类命运的合成成就。</span>

## 1 有机合成的主要任务

**核心概念：有机合成**：利用简单、易得的原料，通过有机反应，**构建目标有机分子的碳骨架**并**引入目标官能团**的过程。

**有机合成的两大任务**：
1. **碳骨架的构建**：链的增长/缩短、成环/开环、官能团的安装位置；
2. **官能团的转化**：在骨架上引入、转换或消除特定官能团。

**重点：合成 = 骨架 + 官能团双线操作**。目标分子与原料的差别，要么在碳骨架（链长、支链、环），要么在官能团（种类、位置）——合成路线就是「逐步消除这两种差别」的过程。<span class="marginnote">「碳骨架构建」与「官能团转化」是有机合成的两条主线。教材中合成的经典案例——从乙烯合成乙酸乙酯、从苯合成苯甲酸——都是先骨架后官能团（或同时）的设计范例。</span>

## 2 官能团的引入与转化

**核心概念：官能团的引入**。把官能团「装」到碳骨架上，常用方法：

| 目标官能团 | 引入方法 | 反应类型 |
| --- | --- | --- |
| $\ce{C=C}$ | 卤代烃消去、醇消去 | 消去 |
| $\ce{-OH}$ | 卤代烃水解、烯烃加水、醛酮加氢 | 取代/加成 |
| $\ce{-X}$ | 烷烃卤代、醇与 HX | 取代 |
| $\ce{-CHO}$ | 伯醇氧化 | 氧化 |
| $\ce{-COOH}$ | 醛氧化、醇氧化 | 氧化 |
| $\ce{-COOR}$ | 羧酸 + 醇酯化 | 酯化 |

**重点：官能团转化的「相邻关系」**。每个官能团都有「邻居」——醇可以氧化成醛、卤代烃可以水解成醇、烯烃可以加水成醇……合成路线的设计，就是沿着「相邻转化图」从原料走到目标。

**公式解析：官能团转化的实例**

由溴乙烷合成乙酸乙酯：

- **第一步，溴乙烷 → 乙醇**：$\ce{C2H5Br + NaOH ->[H2O] C2H5OH + NaBr}$（水解）。
- **第二步，乙醇 → 乙醛 → 乙酸**：$\ce{CH3CH2OH ->[O] CH3CHO ->[O] CH3COOH}$（两次氧化）。
- **第三步，酯化**：$\ce{CH3COOH + C2H5OH <=>[浓H2SO4][加热] CH3COOC2H5 + H2O}$。

**结论：合成路线 = 官能团转化的「接力」**——每一步用一个已知反应，把官能团变成目标需要的那个。<span class="marginnote">这个「溴乙烷 → 乙醇 → 乙醛 → 乙酸 → 乙酸乙酯」的路线是有机合成的经典入门案例：它只用卤代烃水解、醇氧化、酯化三个反应，却串联起四种官能团。理解这类「接力」，就能举一反三设计更长路线。</span>

## 3 碳骨架的构建

**核心概念：碳链的增长与缩短**。

**增长碳链**的方法：
- 卤代烃与 NaCN 反应（加一个碳）：$\ce{R-X + NaCN -> R-CN + NaX}$（腈再水解成羧酸）；
- 卤代烃与炔钠反应；
- 醛酮的加成（羟醛缩合等）。

**缩短碳链**的方法：
- 烯烃的氧化断裂（双键断裂）；
- 羧酸盐的脱羧（少一个碳）：$\ce{CH3COONa ->[NaOH/CaO] CH4}$（制甲烷）。

**重点：成环与开环**。环状化合物可通过分子内反应成环；脂环可通过氧化开环。

**辨析｜易错点：** ①增长链时注意「卤代烃 + NaCN」是经典增碳（氰基水解变羧酸）；②脱羧反应缩短碳链（醋酸钠制甲烷）；③设计路线先比较「原料与目标的碳数差」——差多少碳，决定是否需要增链/减链。

## 4 有机合成的思维方法

**核心概念：逆合成分析法（retrosynthesis）**。从**目标分子倒推**：目标 → 上一级中间体 → 再上一级……直到简单原料。这是有机合成设计的核心思维。

**步骤**：
1. **从目标出发**：目标分子 → 反推一步（酯水解回酸 + 醇）；
2. **找中间体**：把目标拆成「可合成的片段」；
3. **逐级回推**：中间体 → 再反推 → 直到原料；
4. **正写路线**：从原料正着写反应，验证每一步。

**公式解析：逆合成分析的实例**

目标：乙酸乙酯。逆推：

- **第一步，拆酯**：酯 → 羧酸 + 醇（逆酯化）：$\ce{CH3COOC2H5 <- CH3COOH + C2H5OH}$。
- **第二步，拆乙酸**：乙酸 → 乙醛（逆氧化）：$\ce{CH3COOH <- CH3CHO}$。
- **第三步，拆到原料**：乙醛 → 乙醇 → 乙烯（逆转化）：$\ce{CH3CHO <- C2H5OH <- C2H4}$。
- **第四步，正写**：乙烯 → 乙醇 → 乙醛 → 乙酸 → 乙酸乙酯。

**结论：逆合成把「目标到原料」的问题，变成一串「反推相邻官能团」的小问题**。每一步只需回答「这个官能团可以由哪个官能团转化而来」。<span class="marginnote">逆合成分析法与算法中的「目标分解」「回溯搜索」异曲同工：从目标状态反向搜索路径，直到到达初始状态。这个「从终点倒推」的思维在第九级《算法设计与分析》的动态规划、以及 AI 规划（means-ends analysis）中都是核心方法。</span>

**辨析｜易错点：** ①逆合成只「倒推」不「倒写反应」——逆推是逻辑，正写才是反应方向；②每一步逆推都要检验「这一步在正方向上可行」（反应存在、条件合理）；③多条逆推路线要比较优劣（步骤少、原料易得、产率高）——「路线评价」是有机合成的进阶能力。

## 5 官能团转化链：从烯烃到酯的完整路径

把已学的官能团转化串成一条「转化链」，是设计一切合成路线的基础——这张「地图」值得反复默写。

**核心概念：核心转化链**。

$$
\text{烯烃} \to \text{卤代烃} \to \text{醇} \to \text{醛} \to \text{羧酸} \to \text{酯}
$$

| 转化 | 反应 | 条件 |
| --- | --- | --- |
| 烯烃 → 卤代烃 | 加成 HX/卤素 | 常温 |
| 卤代烃 → 醇 | 水解 | NaOH 水溶液加热 |
| 醇 → 醛 | 氧化 | Cu 催化加热 |
| 醛 → 羧酸 | 氧化 | 银氨/高锰酸钾 |
| 羧酸 + 醇 → 酯 | 酯化 | 浓硫酸加热 |

**重点：转化链的「双向性」**。链条上的每一步几乎都能逆向：酯水解回醇 + 酸、羧酸还原回醛、醛加氢回醇、卤代烃消去回烯烃——「官能团转化是网络，不是单行道」。

**公式解析：设计「由乙烯合成乙二醇」**

- **第一步，定目标**：乙烯 $\ce{CH2=CH2}$ → 乙二醇 $\ce{HOCH2CH2OH}$。
- **第二步，选路线**：乙烯先加卤素（$\ce{Br2}$）得邻二溴乙烷、再水解得二醇。
- **第三步，写反应**：$\ce{CH2=CH2 + Br2 -> CH2BrCH2Br}$；$\ce{CH2BrCH2Br + 2NaOH ->[H2O] HOCH2CH2OH + 2NaBr}$。

**结论：设计合成 = 「在转化链上找最短路径」**。<span class="marginnote">「转化链地图」是有机合成的导航：把目标与原料放在图上、找连接路径、补全条件。这张地图从烯烃出发、经卤代/醇/醛/酸到酯，覆盖了高中有机的绝大部分转化。「转化链 + 逆向思维」就是有机合成的全部秘诀——地图越熟、路线越快。这个「路径搜索」的思维与算法中的图搜索（BFS/DFS）同构。</span>

**辨析｜易错点：** ①转化链每一步的条件要「成套记忆」（试剂 + 催化剂 + 温度）；②「两步转化」要保证中间体可分离/可直接用（如醇氧化到醛要控制不过度到酸）；③逆向设计时「从目标回推一步」——目标是什么官能团，由哪步反应可得到它。

## 6 小结

- 有机合成 = **构建碳骨架 + 转化官能团**双线操作。
- 官能团转化靠「相邻关系」接力（卤代烃→醇→醛→酸→酯）。
- 碳链增长（卤代烃 + NaCN 等）、缩短（脱羧、氧化断裂）。
- **逆合成分析**：目标 → 反推中间体 → 逐级回推 → 到原料，再正写验证。
- 路线评价：步骤少、原料易得、产率高、副反应少。
