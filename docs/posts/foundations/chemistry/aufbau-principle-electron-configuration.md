## 为什么电子的「入住顺序」有讲究

上一节确立了能层能级的框架，但还有一个关键问题：电子按什么顺序「入住」这些能级？直觉是按能层从内到外，但实际却存在**能级交错**（$4s$ 比 $3d$ 能量低），导致电子先填 $4s$ 再填 $3d$。本节给出这个顺序的系统规则——**构造原理**，并学会写电子排布式。<span class="marginnote">构造原理（Aufbau principle）来自德语 Aufbau（构建）。泡利 1925 年提出不相容原理、洪特提出同轨道优先平行占据，加上构造原理，共同构成「电子排布三定律」。它们都是经验总结后被量子力学证明的。</span>

## 1 构造原理：电子填充的能级顺序

**核心概念：构造原理**：基态原子的核外电子按**能量由低到高**依次填充各能级的顺序。这个顺序用「能级图」直观表示（能级交错）：

$$
1s \to 2s \to 2p \to 3s \to 3p \to 4s \to 3d \to 4p \to 5s \to 4d \to 5p \to 6s \to 4f \to 5d \to 6p \to 7s \to \cdots
$$

**重点：能级交错**。$4s$ 的能量低于 $3d$，$5s$ 低于 $4d$，$6s$ 低于 $4f$……所以钾（K，19 号）的最后一个电子填在 $4s$ 而非 $3d$：电子排布式是 $1s^2 2s^2 2p^6 3s^2 3p^6 4s^1$，而非 $3d^1$。这种「外层能级先于内层高能级填充」的现象，源于多电子原子中电子间的屏蔽与钻穿效应。<span class="marginnote">能级交错的根源：ns 轨道穿透到核附近的能力（钻穿效应）强，感受到更大有效核电荷、能量更低。这条「先 4s 后 3d」的顺序决定了第四周期过渡金属的排布，是元素周期表结构的微观原因。</span>

**辨析｜易错点：** ①写电子排布式要**先按构造原理顺序填充，再按能层序号排列书写**——如钾写成 $1s^2 2s^2 2p^6 3s^2 3p^6 4s^1$，不能把 $4s$ 写在 $3p$ 前（按能层排列：先 3 后 4）；②填充顺序与书写顺序不同，是「先填后整理」。

## 2 电子排布式的书写

**核心概念：电子排布式**：用能级符号与电子数表示核外电子排布的式子。如钠（11 号）：$1s^2 2s^2 2p^6 3s^1$。

**核心概念：简化电子排布式（原子实表示）**：用上一周期稀有气体的电子排布（原子实）代替内层电子，只写出外层。如钾：$[\ce{Ar}]4s^1$；铁：$[\ce{Ar}]3d^6 4s^2$。

**核心概念：价层电子排布**：决定元素化学性质的外层电子（主族是最高能层 s+p，副族是 (n-1)d + ns）。铁价电子 $3d^6 4s^2$——正是它在周期表位置与化合价的依据。

**公式解析：从原子序数推电子排布式**

写铁（Fe，26 号）的电子排布式：

**第一步，按构造原理填充**：$1s^2 2s^2 2p^6 3s^2 3p^6 4s^2 3d^6$（共 2+2+6+2+6+2+6 = 26）。
**第二步，按能层整理**：$1s^2 2s^2 2p^6 3s^2 3p^6 3d^6 4s^2$。
**第三步，写简化式**：$[\ce{Ar}]3d^6 4s^2$；价电子 $3d^6 4s^2$。

**结论：电子排布式三步——按构造原理填、按能层整理、写原子实**。注意副族元素的**价电子包括 (n-1)d 与 ns**，这是判断其常见化合价的依据。

**辨析｜易错点：** ①**轨道式（电子排布图）**与电子排布式不同：轨道式用方框（轨道）与箭头（电子）画出，体现洪特规则（下一节）；②有些元素存在**排布特例**（半充满稳定）：如铬（24 号）是 $[\ce{Ar}]3d^5 4s^1$ 而非 $3d^4 4s^2$，铜（29 号）是 $[\ce{Ar}]3d^{10} 4s^1$——**全满、半满的 d 轨道更稳定**；③写过渡金属的离子排布时，**先失 4s 电子再失 3d 电子**（$\ce{Fe^{2+}}$：$[\ce{Ar}]3d^6$，先失去两个 4s 电子）。

## 3 电子排布与元素性质的关联

**重点：电子排布决定元素在周期表中的位置与性质**。

**主族元素**：价电子 = 最外层 s+p 电子，数目 = 主族族序数；
**周期数** = 最高能层数（如 Fe 在第四周期，最高能层 n=4）；
**副族元素（过渡金属）**：价电子含 d 电子，性质多样（多种化合价、催化性、颜色）。

以铁为例：价电子 $3d^6 4s^2$ → 第四周期、VIII 族；常见 +2、+3 价（先失 4s 电子得 +2，再失 3d 电子得 +3）。<span class="marginnote">过渡金属的多变价态来自 d 轨道电子的部分失去。铁、铜、锰的多种价态使其在催化（哈伯法铁触媒）、电池（锰、钴氧化物）、配合物（血红蛋白含铁卟啉）中举足轻重。d 电子的化学是配位化学的入口。</span>

**辨析｜易错点：** ①主族元素「族序数 = 最外层电子数」成立；副族元素不看最外层，要看价电子总数——别用主族的规则套副族；②「镧系收缩」「半满稳定」等效应会造成排布与「规则」不符的特例，写排布式前先查周期表确认；③离子的电子排布与原子不同（失电子），写离子排布式要先写原子再减电子。

## 4 电子排布与元素性质的对应

电子排布式不仅是「排布记录」，更是**预测性质**的工具——最外层电子决定元素的一切化学行为。

**核心概念：电子排布 → 化合价**。主族元素的最外层电子数 = 最高正价；副族元素的价电子（(n-1)d + ns）决定多变价。例：铁价电子 $3d^6 4s^2$ → 常见 +2（失 4s 两个）与 +3（再失一个 3d）。

**公式解析：从排布推断常见化合价**

**第一步，找价电子**：主族看最外层（s+p）；副族看 (n-1)d + ns。
**第二步，定最高价**：主族最高正价 = 最外层电子数（如氯 7 → +7）。
**第三步，推多变价**：过渡金属逐步失电子 → 多个价态（锰 +2、+4、+6、+7）。

**重点：排布特例的性质意义**。铬（$3d^5 4s^1$）与铜（$3d^{10} 4s^1$）的「半满/全满」排布使它们性质稳定——铜不易失 3d 电子、常见 +1、+2 价。<span class="marginnote">「电子排布决定化合价」是把原子结构变成化学性质的桥梁。稀土元素（f 区）性质几乎相同，因为最外层电子相同、电子填在深层 f 轨道——这就是上一节「f 区元素难分离」的微观原因。电子排布是周期表与性质之间的「解释层」。</span>

**辨析｜易错点：** ①主族元素族序数 = 最外层电子数 = 最高正价（O、F 无最高正价）；②副族不看最外层——铁的 +3 价来自 3d 电子，不是最外层 4s 电子；③离子排布 = 原子排布先失最外层（4s 先于 3d 失）。

## 5 电子排布的书写检查清单

写完电子排布式，用四条规则自查一遍，能避免绝大多数错误：

1. **总数核对**：各能级电子数之和 = 原子序数；
2. **构造顺序**：按 $1s\to2s\to2p\to3s\to3p\to4s\to3d\to\cdots$ 填充；
3. **书写整理**：按能层从低到高排列（不是填充顺序）；
4. **特例检查**：Cr、Cu 等 d 区元素的半满/全满特例。

**公式解析：自查 $\ce{Fe}$ 的排布**

- **第一步，数总数**：$1s^2 2s^2 2p^6 3s^2 3p^6 3d^6 4s^2$——$2+2+6+2+6+6+2 = 26$ ✓。
- **第二步，查顺序**：4s 在 3d 前填充（先填 4s）✓。
- **第三步，查写法**：书写按 3d 在 4s 前（能层顺序）✓。

**结论：排布自查 = 「总数 + 顺序 + 写法 + 特例」四查**。多写多查，才能把「背排布」变成「会排布」。

**补充：电子排布式与「周期表结构」的对应**。电子排布直接解释周期表：周期数 = 最高能层数、族序数 = 最外层电子数（主族）、每周期元素数 = 新填能级的电子容量（2、8、8、18…）。「排布式 → 位置」是互推：给原子序数写排布、由排布定位置、由位置推性质——「结构决定位置、位置反映性质」的完整链条。「会写排布式，就会用周期表」。

**补充：电子排布式的「常见错误」**。①忘记能级交错（把钾写成 $3d^1$）；②总和不对（数错电子数）；③简化式写错原子实（$[\ce{Ar}]$ 代表 18 电子）；④价电子定义混淆（主族 vs 副族）。「自查四步：总和、顺序、写法、特例」——写排布式如同「填空 + 检查」，细节决定对错。多练几次，排布式就从「背」变成「推」。

**补充：电子排布与「原子光谱实验」的印证**。电子排布式不是「纸面推算」——它由光谱实验证实：原子的吸收/发射光谱显示能级结构，与理论排布吻合。如钠的黄色双线（3p → 3s 跃迁）正是钠原子「最外层一个电子在 3s 与 3p 间跃迁」的体现。「实验与理论互相印证」——排布式的正确性由光谱检验，这是科学「假设—验证」的范例。

**补充：价电子与「元素化学性质」的连接**。价电子（最外层 s+p 或 (n-1)d+ns）决定元素化合价与化学行为：主族价电子数 = 最高正价；副族价电子决定多变价。「电子排布 → 价电子 → 化合价 → 化学性质」——一条完整的推理链。写排布式不只是「填电子」，更是「预测性质」的第一步——「结构决定性质」从原子开始。

**补充：电子排布式的「书写练习建议」**。练习写排布式的顺序：先主族（K、Ca、Na、Cl）——规则简单；再过渡金属（Fe、Cu、Cr）——涉及 3d/4s 交错与特例；后离子（$\ce{Fe^{3+}}$、$\ce{Cu^{2+}}$）——先失 4s 再失 3d。「由简到繁、先规则后特例」——排布式的掌握靠「写」不靠「背」。「每写一个排布式，就多一分对原子结构的直觉」。

**补充：排布式的「实践意义」再确认**。电子排布式是「元素周期表」与「化学性质」的微观解释层：知道排布 → 知道位置（周期、族）→ 知道性质（价态、金属性）。「排布式是原子结构的『终极答案』」——所有原子层面的性质都能从它推导。「学排布式，是在学『化学的第一性原理』」——从电子排布出发，理解元素的一切。

**补充：电子排布与「原子光谱」的相互印证**。电子排布式由光谱实验验证：原子的发射/吸收光谱显示能级，与理论排布吻合。如钠的黄线（3p→3s 跃迁）正是「钠最外层一个电子」的跃迁。「排布式不是纸面推算，是实验的总结」——理论排布与光谱观察互相印证。「实验与理论的一致性」是科学可靠性的标志。

## 6 小结

- **构造原理**：电子按能量由低到高填充能级，存在**能级交错**（$4s < 3d$）。
- 填充顺序：$1s\to2s\to2p\to3s\to3p\to4s\to3d\to4p\to\cdots$。
- 电子排布式、简化式（原子实）、价层电子排布三层写法。
- 书写三步：按构造原理填、按能层整理、写原子实。
- 特例：$d$ 轨道**半满/全满**稳定（Cr、Cu）；过渡金属先失 4s 电子。
