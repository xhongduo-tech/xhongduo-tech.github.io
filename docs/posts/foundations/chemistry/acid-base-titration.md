## 为什么滴定是「用体积换浓度」

已知浓度的盐酸如何测出未知浓度的氢氧化钠？答案：**酸碱中和滴定**——用已知浓度的酸（标准液）逐滴加到未知浓度的碱（待测液）中，恰好完全中和时，由消耗体积计算浓度。这是化学定量分析的基本功，也是「以标准定未知」思想的源头。<span class="marginnote">容量分析（滴定分析）是定量化学最古老也最可靠的方法之一，精度可达 0.1%。从它出发，第五级《分析化学》会扩展到氧化还原滴定、络合滴定、沉淀滴定等家族。</span>

## 1 中和滴定的原理与仪器

**核心概念：酸碱中和滴定**。用已知浓度的酸（或碱）来测定未知浓度的碱（或酸）的方法。原理是恰好中和时，$n(\ce{H+}) = n(\ce{OH-})$（等当点）：

$$
\ce{H+ + OH- -> H2O}
$$

设酸浓度为 $c_A$、体积 $V_A$，碱浓度为 $c_B$、体积 $V_B$，则恰好中和时：

$$
c_A V_A = c_B V_B
$$

**仪器与试剂**：酸式滴定管、碱式滴定管、锥形瓶、滴定管夹、铁架台、指示剂（酚酞或甲基橙）。**酸式滴定管**（可盛酸与氧化性溶液，玻璃旋塞）、**碱式滴定管**（可盛碱液，橡胶管+玻璃珠）。

**重点：滴定管的使用规范**。滴定管是「先读后放」的精密量具：使用前**检漏、洗涤、润洗**（用待盛液润洗 2–3 次，防止稀释），读数时视线与凹液面最低处平齐，可估读到 0.01 mL。<span class="marginnote">滴定管与量筒的区别：滴定管刻度自上而下增大、尖端读数（先读 0 附近）、精度 0.01 mL；量筒精度 0.1 mL。选择量具看精度需求——配制一定浓度溶液与滴定的精度要求完全不同。</span>

## 2 中和滴定操作流程

**核心概念：滴定操作八步**：

1. **洗涤**：滴定管用蒸馏水洗、再用标准液润洗；
2. **装液排气**：装标准液，赶走尖嘴内气泡；
3. **初读**：记录起始读数；
4. **量取待测液**：用移液管（或碱式滴定管）量取一定体积待测液入锥形瓶；
5. **加指示剂**：滴入 2–3 滴酚酞（等当点附近变色明显）；
6. **滴定**：左手控活塞、右手摇锥形瓶，逐滴加入，近终点时半滴半滴加；
7. **终点判断**：滴入最后一滴，溶液颜色变化且 **30 秒内不褪色**，即达终点；
8. **复读**：记录终读数，重复滴定 2–3 次取平均。

**重点：终点（指示剂变色点）与等当点**。等当点是酸碱恰好完全中和的点；指示剂变色点略偏（有滴定突跃）。选择指示剂的原则是**变色范围落在滴定突跃区间内**——强酸滴定强碱选酚酞或甲基橙均可；强酸滴定弱碱选甲基橙（突跃在酸性区）；强碱滴定弱酸选酚酞（突跃在碱性区）。<span class="marginnote">滴定突跃是「最后一滴」引发 pH 的急剧变化（约 4–10 个 pH 单位），正是它让指示剂在 1-2 滴内变色、终点可精确捕捉。突跃范围取决于滴定体系，这是选择指示剂的依据。</span>

## 3 公式解析：滴定计算

用 0.1000 mol/L 盐酸滴定 20.00 mL 未知浓度的 $\ce{NaOH}$ 溶液，消耗盐酸 18.50 mL，求 $c(\ce{NaOH})$：

- **第一步，写关系**：恰好中和时 $n(\ce{H+}) = n(\ce{OH-})$，即 $c(\ce{HCl})V(\ce{HCl}) = c(\ce{NaOH})V(\ce{NaOH})$。
- **第二步，代入**：$0.1000 \times 18.50 = c(\ce{NaOH}) \times 20.00$。
- **第三步，求解**：$c(\ce{NaOH}) = \frac{0.1000 \times 18.50}{20.00} = 0.09250\ \mathrm{mol/L}$。

**结论：滴定计算就是「等当点方程」$c_1V_1 = c_2V_2$**。对多元酸碱，系数需按化学计量数调整（如 $\ce{2NaOH + H2SO4}$，则 $2c_A V_A = c_B V_B$）。

**辨析｜易错点：** ①**酸式滴定管与碱式滴定管不能混用**——酸会腐蚀碱式管橡胶，碱会腐蚀玻璃旋塞；②读数须在**滴定前后各读一次**，体积差为消耗量；③锥形瓶只需**蒸馏水洗**（不能润洗，否则待测液量改变）；④终点判断「30 秒不褪色」，不是「变了一瞬就算」——返色说明未到终点。

## 4 误差分析

**核心概念：误差来源与方向**。滴定误差分为系统误差与操作误差，用「多滴了还是少滴了标准液」判断：

| 操作 | 对 $c_B$ 的影响 |
| --- | --- |
| 滴定管未润洗（标准液被稀释） | 偏小（需多滴）→ $c_B$ 偏大 |
| 锥形瓶润洗（待测液量增） | 偏大（需多滴）→ $c_B$ 偏大 |
| 滴定管读数仰视（读数偏大） | 体积偏大 → $c_B$ 偏大 |
| 滴定前气泡未排出 | 读数差偏小 → $c_B$ 偏小 |
| 终点判断过早（颜色未稳） | 偏小 → $c_B$ 偏小 |

**重点：误差分析的总原则——「标准液用多了，结果偏大；用少了，结果偏小」**。先判断操作如何影响消耗的标准液体积，再换算对 $c_B$ 的影响，就不会乱。<span class="marginnote">这种「由操作反推测量偏差」的误差分析方法，在第五级《分析化学》中系统化为「误差传递」。学会它，就掌握了所有定量实验误差题的通用思路。</span>

**辨析｜易错点：** ①「锥形瓶中有少量蒸馏水」不影响结果——因为待测液的物质的量不变，只是浓度略变，但 $n = cV$ 不变；②「用待测液润洗锥形瓶」才使结果偏大（待测液量多了）；③滴定时振荡过度溅出液体，待测液减少，消耗标准液减少，结果偏小。

## 5 指示剂的选择与滴定曲线的终点判断

中和滴定的终点由指示剂变色判断，而指示剂的选择不是任意的——要看**滴定突跃**的范围。

**核心概念：滴定突跃**。在等当点前后约 1-2 滴内，溶液的 pH 发生急剧变化（如强酸滴强碱，突跃约 4.3–9.7）。突跃是「最后一滴引发 pH 骤变」的区间，指示剂必须在这个区间内变色。

| 滴定体系 | 突跃范围 | 可选指示剂 |
| --- | --- | --- |
| 强酸 ↔ 强碱 | 约 4–10 | 酚酞、甲基橙均可 |
| 强酸 ↔ 弱碱 | 酸性区（约 3–7） | **甲基橙** |
| 弱酸 ↔ 强碱 | 碱性区（约 7–10） | **酚酞** |

**重点：弱酸弱碱体系突跃不明显，一般不做滴定**。选择指示剂的原则：**指示剂的变色范围落在突跃区间内**——否则终点判断不准、误差大。<span class="marginnote">为什么强酸滴强碱突跃范围大？因为接近等当点时，溶液里几乎只剩「酸、碱都已接近中和」的临界状态，极少量试剂就使 H⁺ 或 OH⁻ 浓度发生数量级变化。弱酸弱碱的「缓冲」使突跃变小——所以不能精确滴定。</span>

**辨析｜易错点：** ①酚酞变色范围 8.2–10.0（无色→红），甲基橙 3.1–4.4（红→黄）——两者都适合强酸强碱；②强酸滴弱碱（如盐酸滴氨水）终点偏酸，用甲基橙；弱酸滴强碱终点偏碱，用酚酞——「指示剂与突跃匹配」是选择的铁律；③石蕊变色范围太宽（5–8）、突变不明显，不适合滴定。

**补充：中和滴定的应用与拓展**。中和滴定不只测酸碱浓度——它是「容量分析」的模板：氧化还原滴定（高锰酸钾测铁、碘量法）、沉淀滴定（银量法测卤素）、络合滴定（EDTA 测金属离子）。原理相通：用已知浓度的标准液、在等当点判断终点、按计量关系计算。掌握了中和滴定，就掌握了容量分析的「心法」。

**补充：滴定实验的「平行测定」思想**。一次滴定数据不可靠——要「平行滴定 2-3 次、取平均值」。若某次数据明显偏离（偏差 > 0.1 mL），应舍去重做。这个「重复 + 取平均 + 剔除异常」的数据处理原则，是所有定量实验的共同规范，也体现了科学测量的基本要求：可重复、可检验。

**补充：滴定管的「润洗」与「读数」细节**。滴定管使用前须用**待盛液润洗 2-3 次**（否则内壁水膜稀释标准液）；读数前赶走尖嘴气泡；读数视线与凹液面最低处平齐、估读到 0.01 mL。「润洗防稀释、排气防误差、平视防视差」——三个细节决定滴定精度。锥形瓶则「只洗不润」（蒸馏水洗即可，润洗会使待测液量偏多、结果偏大）。

**补充：中和滴定的「终点判断」技巧**。近终点时「半滴操作」：用锥形瓶内壁接触滴定管尖嘴使半滴溶液附壁、再用蒸馏水冲下——防止过量。终点判断「颜色变化且半分钟不褪」——返色说明未到终点。「半滴 + 半分钟」是滴定精确性的两个细节——滴定是「操作精度决定结果精度」的实验。

**补充：中和滴定的「计算变式」**。滴定计算不只是「$c_1V_1 = c_2V_2$」：多元酸碱要按系数折算（$\ce{2NaOH + H2SO4}$ → $2c_A V_A = c_B V_B$）；若待测液被稀释，先算「稀释前浓度」。还会结合「指示剂选择」（突跃区间）与「误差分析」综合命题。「滴定 = 等当点计量 + 终点判断 + 误差控制」三要素——掌握三要素，任何滴定变式都能应对。

**补充：中和滴定的「操作顺序」记忆**。滴定操作「洗、装、排、读、取、滴、判、复」八字诀：洗（洗涤润洗）、装（装标准液）、排（排气泡）、读（初读）、取（量取待测液）、滴（滴定）、判（判断终点）、复（复读取平均）。「顺序不乱、误差可控」——滴定是「流程决定精度」的实验，操作顺序本身就是考点。

**补充：滴定终点的「颜色变化」细节**。酚酞终点：无色 → 浅红色（半分钟不褪）；甲基橙终点：黄色 → 橙色。指示剂「变色要敏锐、终点要易判」——变色范围窄、颜色对比强的指示剂最适。「终点判读是滴定的人为误差源」——同一操作者多次读数取平均、减少主观偏差。「终点的准确判读」是滴定从「会做」到「做准」的关键。

## 7 小结

- **中和滴定**：$c_A V_A = c_B V_B$（等当点时酸碱中和）。
- 仪器：酸式滴定管（酸/氧化性液）、碱式滴定管（碱液）；滴定管需**润洗**、读至 0.01 mL。
- 操作八步：洗、装、排气、量取、加指示剂、滴定、终点判断（30 s 不褪色）、复读取平均。
- 指示剂选择看**滴定突跃区间**：强酸强碱用酚酞或甲基橙，弱酸弱碱看突跃方向。
- 误差分析原则：「标准液用多则结果偏大」。
