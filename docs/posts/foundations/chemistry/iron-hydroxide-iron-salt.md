## 为什么从「铁三角」开始

上一节我们把铁的三种价态排成一条「价态阶梯」，画出了一张铁的地图：$\ce{Fe}$、$\ce{Fe^{2+}}$、$\ce{Fe^{3+}}$ 三者之间的转化，是理解铁全部化学的主线。但那些还只是「地图上的路标」——单质在火焰里、氧化物在矿坑里，都离溶液有点远。而化学实验真正的主战场是**溶液**：铁锈怎么洗、补血剂里的铁怎么吸收、印刷电路板怎么被刻蚀，靠的都是溶液里的 $\ce{Fe^{2+}}$ 与 $\ce{Fe^{3+}}$。

本节把铁三角从「价态符号」变成「看得见的沉淀与溶液」：先用**铁的氢氧化物**给两种价态拍一张「集体照」，再用**铁盐与亚铁盐**给它们在溶液里拍「单人照」，最后用**铁三角**把六条转化路一次走完。<span class="marginnote">铁三角不仅属于铁。它是整个高中化学里「变价元素」的标准模板——第四章的氯、第五章的硫与氮，都是先画出自己的「价态阶梯」，再逐条走转化路。学会铁三角的读法，后面学氯、硫、氮时，就等于拿到了现成的剧本。</span>

## 1 铁的氢氧化物：一支「白」与一支「红褐」

把可溶性的铁盐与碱反应，就能得到铁的氢氧化物。先看比较听话的**氢氧化铁**。

**氢氧化铁（$\ce{Fe(OH)3}$）**：红褐色沉淀。在氯化铁溶液中滴加氢氧化钠溶液：

$$\ce{FeCl3 + 3NaOH -> Fe(OH)3 v + 3NaCl}$$

生成的沉淀是红褐色的、不溶于水的 $\ce{Fe(OH)3}$。<span class="marginnote">$\ce{Fe(OH)3}$ 不是两性氢氧化物，它不溶于过量氢氧化钠——这是它与下一章主角氢氧化铝（$\ce{Al(OH)3}$）的关键区别。记住「铁不两性、铝两性」，后面学铝时会有惊喜。</span>

再来看娇气的主角**氢氧化亚铁（$\ce{Fe(OH)2}$）**。在硫酸亚铁溶液中滴加氢氧化钠溶液：

$$\ce{FeSO4 + 2NaOH -> Fe(OH)2 v + Na2SO4}$$

新生成的 $\ce{Fe(OH)2}$ 是**白色**的沉淀。但这份「白」极难留住——它在空气中会被迅速氧化，沉淀的颜色按**白色 → 灰绿色 → 红褐色**快速演变，最终变成 $\ce{Fe(OH)3}$：

$$\ce{4Fe(OH)2 + O2 + 2H2O -> 4Fe(OH)3}$$

**重点：$\ce{Fe(OH)2}$ 的一生是「一出生就走向氧化」的一生——只要碰到氧气，白色就留不住。** 这正是制备 $\ce{Fe(OH)2}$ 实验的全部难点所在。

**辨析｜易错点：制备 $\ce{Fe(OH)2}$ 的成败，全在「隔绝氧气」四个字。** 标准操作有四处细节，每一处都在对抗氧气：

- **用新配制的 $\ce{FeSO4}$ 溶液**：久置的硫酸亚铁溶液中，$\ce{Fe^{2+}}$ 已被部分氧化成 $\ce{Fe^{3+}}$，会直接干扰白色的观察。
- **把蒸馏水煮沸后冷却再用**：溶解在水里的氧被赶走，配出的碱液才「干净」。
- **胶头滴管伸入液面以下再滴加**：让 $\ce{NaOH}$ 溶液直接接触 $\ce{FeSO4}$ 溶液，而不是从空中「砸」进液面，减少与空气的接触。
- **在液面上加一层煤油（或苯）**：物理隔绝空气，给白色沉淀一个「氧气的真空舱」。

这四条不是细枝末节，它们是「观察」这门手艺的教材示范——**化学实验里，颜色变化的观察，往往比计算更难。** 这也呼应着本节题记：机遇只偏爱有准备的头脑。

$\ce{Fe(OH)3}$ 还有一个重要的热稳定性。加热 $\ce{Fe(OH)3}$ 固体，它分解成氧化铁和水：

$$\ce{2Fe(OH)3 ->[\Delta] Fe2O3 + 3H2O}$$

红褐色的 $\ce{Fe(OH)3}$ 受热变回红棕色的 $\ce{Fe2O3}$——这条分解反应在后面的实验中常用，也呼应上一节「$\ce{Fe2O3}$ 是炼铁原料」的说法。

## 2 铁盐与亚铁盐：+3 与 +2 的「性格」

溶液里的 $\ce{Fe^{3+}}$ 与 $\ce{Fe^{2+}}$，是两种性格完全不同的离子。性格差异的根源，还是上一章的**氧化还原**：+3 是铁能到的最高价，只有**氧化性**；+2 处于中间，既可被氧化也可被还原。

**$\ce{Fe^{3+}}$ 的氧化性**：$\ce{Fe^{3+}}$ 能氧化金属活动性排在铁之后的金属。最经典的是与铁单质和铜的反应：

$$\ce{2FeCl3 + Fe -> 3FeCl2}$$

$$\ce{2FeCl3 + Cu -> 2FeCl2 + CuCl2}$$

第二条反应就是**印刷电路板**的刻蚀原理：铜箔被 $\ce{FeCl3}$ 溶液溶解，溶液由黄色（$\ce{Fe^{3+}}$）变为蓝绿色（$\ce{Cu^{2+}}$ 与 $\ce{Fe^{2+}}$ 混合）。一块电路板，就是一次铁三角的实战。

**$\ce{Fe^{2+}}$ 的还原性**：$\ce{Fe^{2+}}$ 遇到氯气、双氧水等氧化剂，会升到 +3 价：

$$\ce{2FeCl2 + Cl2 -> 2FeCl3}$$

这解释了保存 $\ce{FeSO4}$ 溶液时要**加入少量铁钉（铁粉）**：溶液中的 $\ce{Fe^{2+}}$ 若被氧化成 $\ce{Fe^{3+}}$，铁钉恰好把 $\ce{Fe^{3+}}$ 又还原回 $\ce{Fe^{2+}}$（$\ce{2Fe^{3+} + Fe -> 3Fe^{2+}}$）——一个「自动修复」的循环。<span class="marginnote">「加铁钉防氧化」的本质，是借助 $\ce{Fe^{3+}}$ 的氧化性反向护住 $\ce{Fe^{2+}}$。这种「用杂质反应的代价换主反应稳定」的思路，在化学实验与工业生产里到处可见——保存亚铁盐如此，冶炼钢铁时控制氧化气氛也如此。</span>

**$\ce{Fe^{3+}}$ 的检验**：向含 $\ce{Fe^{3+}}$ 的溶液中滴加**硫氰化钾（$\ce{KSCN}$）**溶液，溶液变**血红色**：

$$\ce{Fe^{3+} + 3SCN^- -> Fe(SCN)3}$$

这是检验 $\ce{Fe^{3+}}$ 最灵敏、最特异的方法。**辨析｜易错点：检验 $\ce{Fe^{2+}}$ 必须先加 $\ce{KSCN}$ 看是否变红，不变红再加氧化剂（氯水或双氧水）变红，才能说明原溶液含 $\ce{Fe^{2+}}$。** 若一开始就变红，说明有 $\ce{Fe^{3+}}$，此时无法判断是否存在 $\ce{Fe^{2+}}$——「先证伪、再证实」的次序不能颠倒。

## 3 铁三角：六条转化路一次走完

把上两节的信息汇总，铁三角的六条路是：

| 转化 | 所需试剂 | 本质 |
| --- | --- | --- |
| $\ce{Fe -> Fe^{2+}}$ | 弱氧化剂：稀盐酸、稀硫酸、$\ce{Cu^{2+}}$、$\ce{S}$ | 失 2 个电子 |
| $\ce{Fe -> Fe^{3+}}$ | 强氧化剂：$\ce{Cl2}$、$\ce{HNO3}$、浓 $\ce{H2SO4}$ | 失 3 个电子 |
| $\ce{Fe^{2+} -> Fe^{3+}}$ | 氧化剂：$\ce{Cl2}$、$\ce{O2}$、$\ce{H2O2}$ | 失 1 个电子 |
| $\ce{Fe^{3+} -> Fe^{2+}}$ | 还原剂：$\ce{Fe}$、$\ce{Cu}$、$\ce{I^-}$ | 得 1 个电子 |
| $\ce{Fe^{2+} -> Fe}$ | 强还原剂：$\ce{Zn}$、$\ce{Al}$ | 得 2 个电子 |
| $\ce{Fe^{3+} -> Fe}$ | 强还原剂：$\ce{Zn}$、$\ce{Al}$ | 得 3 个电子 |

**重点：这张表不用背，只用一条判据——「想让铁往高价走，就找氧化剂；想让铁往低价走，就找还原剂」，氧化剂或还原剂越强，铁走得越远。** 铁三角的全部学问，浓缩成一句话就是「谁强谁说了算」。

## 4 公式解析：$2\ce{Fe^{3+}} + \ce{Fe} = 3\ce{Fe^{2+}}$（归中反应）

铁三角里最值得拆解的反应，是 $\ce{Fe^{3+}}$ 与 $\ce{Fe}$ 作用生成 $\ce{Fe^{2+}}$。它同时展示了「氧化性」与「还原性」如何在一个反应里平衡。

**第一步，标化合价，找升降。** 反应前：一个 $\ce{Fe}$ 原子是 0 价，两个 $\ce{Fe^{3+}}$ 离子各 +3 价；反应后：三个铁全是 +2 价。0 → +2，是**被氧化**、失电子；+3 → +2，是**被还原**、得电子。

**第二步，配平电子得失。** 1 个 $\ce{Fe}$ 原子失 2 个电子，正好供养 2 个 $\ce{Fe^{3+}}$（各得 1 个电子）。得失电子数相等，系数 1、2、3 由此而来。

**第三步，看直觉。** 为什么 +3 的铁恰好把 0 价铁氧化到 +2，而不是停在 +3？因为**同种元素的高价态与低价态相遇，倾向于「归中」到中间价态**——+3 与 0 的中间价态正是 +2。这类反应叫**归中反应**，它是歧化反应的「反向操作」<span class="marginnote">歧化与归中是一对孪生概念：歧化是同一个价态「分裂」成高低两种价态，归中是高低两种价态「合流」到中间价态。铁三角里 $\ce{Fe}$ 与 $\ce{Fe^{3+}}$ 归中为 $\ce{Fe^{2+}}$；而氯气与水的反应 $\ce{Cl2 + H2O <=> HCl + HClO}$ 则是氯的歧化。学第四章氯、第五章硫与氮时，这对概念会反复登场。</span>。

**辨析｜易错点：$\ce{Fe^{3+}}$ 与 $\ce{Fe}$ 的反应，产物只可能是 $\ce{Fe^{2+}}$，不会是 $\ce{Fe^{2+}}$ 与 $\ce{Fe}$ 的再平衡。** 想让 $\ce{Fe^{3+}}$ 一口气变回 $\ce{Fe}$ 单质，必须借助比铁更强的还原剂（$\ce{Zn}$、$\ce{Al}$）——「氧化剂或还原剂的强度决定铁的终态」这条铁律，在这里再次生效。

## 5 小结

- **铁的氢氧化物**：$\ce{Fe(OH)3}$ 红褐色、不溶于过量碱；$\ce{Fe(OH)2}$ 白色、极不稳定，在空气中按**白 → 灰绿 → 红褐**被氧化。
- **制备 $\ce{Fe(OH)2}$**：新制 $\ce{FeSO4}$、煮沸除氧的水、滴管伸入液面、煤油液封——一切为了隔绝氧气。
- **$\ce{Fe^{3+}}$ 氧化性**：与 $\ce{Fe}$、$\ce{Cu}$ 反应得 $\ce{Fe^{2+}}$；**$\ce{Fe^{2+}}$ 还原性**：被 $\ce{Cl2}$、$\ce{H2O2}$ 氧化为 $\ce{Fe^{3+}}$。
- **检验**：$\ce{KSCN}$ 遇 $\ce{Fe^{3+}}$ 变**血红色**；检验 $\ce{Fe^{2+}}$ 须「先不变红，再加氧化剂变红」。
- **铁三角**：六条转化路由氧化剂与还原剂的强弱主导；$\ce{Fe^{3+} + Fe -> Fe^{2+}}$ 是典型的**归中反应**。

在下一节，我们离开溶液里的铁离子，来到更高一层的视野——把铁、铝、铜做成性能更好的材料，这就是**金属材料**的第一课：合金。
