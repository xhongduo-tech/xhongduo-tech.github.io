## 为什么从硫酸开始

上一节认识了单质硫与二氧化硫，二氧化硫溶于水生成亚硫酸，那只是硫元素较低价态的体现。硫的最高价态是 $+6$，代表物正是**硫酸**。硫酸被称为「化学工业之母」，因为化肥、炸药、冶金、石油炼制几乎每一个重工业部门都离不开它——全球年产量超过两亿吨，是产量最高的无机化工产品。<span class="marginnote">衡量一个国家化学工业发达程度，历史上常用「硫酸产量」作为指标；今天的「氯碱产量」也有类似地位。这个视角在第一级《化学》与第六级《化学工程》之间搭了一座桥。</span>

更重要的是，硫酸是理解「**同一元素的不同价态行为迥异**」的绝佳样本：同样是 $+6$ 价硫的体现，稀硫酸显酸性、浓硫酸却表现出吸水、脱水与强氧化三大独特性质。把「浓」与「稀」的差别看透，也就把「浓度改变反应本性」这条化学思维立住了。

## 1 两种硫酸：稀硫酸与浓硫酸

**硫酸（sulfuric acid）**：化学式 $\ce{H2SO4}$，是含硫元素最高价态 $+6$ 的含氧酸。纯净硫酸是无色、黏稠的油状液体，密度 $1.84\ \mathrm{g/cm^3}$，沸点高达 $338^\circ\mathrm{C}$，难挥发。<span class="marginnote">硫酸难挥发、沸点高这一性质有重大工程用途：实验室里制备挥发性的酸（如 $\ce{HCl}$、$\ce{HNO3}$）时，可以用浓硫酸与相应盐反应，利用「难挥发性酸制易挥发性酸」的规律。</span>

**核心概念：浓硫酸与稀硫酸的分界线**。市售浓硫酸的质量分数约为 98%（物质的量浓度约 $18.4\ \mathrm{mol/L}$）。浓与稀不仅是浓度差别，更意味着**反应行为的本质差别**——稀硫酸的电离程度接近完全，溶液中大量存在的是 $\ce{H+}$ 与 $\ce{SO4^{2-}}$，体现的是酸的通性；而浓硫酸中水极少，$\ce{H2SO4}$ 分子本身才起主要作用，由此派生出三大特性。

| 性质 | 稀硫酸 | 浓硫酸 |
| --- | --- | --- |
| 主要存在形态 | $\ce{H+}$、$\ce{SO4^{2-}}$ | $\ce{H2SO4}$ 分子 |
| 酸性 | 完全电离，强酸性 | 几乎不电离，酸的通性弱 |
| 吸水性 | 无 | 有 |
| 脱水性 | 无 | 有 |
| 氧化性 | 只有 $\ce{H+}$ 的弱氧化性 | 具有强氧化性（$\ce{S^{+6}}$） |
| 与活泼金属 | 置换出 $\ce{H2}$ | 钝化（铁、铝）或生成 $\ce{SO2}$ |

## 2 浓硫酸的特性：吸水性、脱水性与强氧化性

### 吸水性

浓硫酸能吸收游离的水分子，包括气体中的水蒸气、空气中的水分，因此常用作**干燥剂**。吸水性是物理变化——水分子被浓硫酸结合（形成一系列水合物），体系放热。常见的应用：干燥 $\ce{O2}$、$\ce{Cl2}$、$\ce{CO2}$ 等不与硫酸反应的气体。<span class="marginnote">干燥气体有两条禁忌：一是氨气不能通过浓硫酸（碱性气体与酸反应），二是还原性强的气体（如 $\ce{H2S}$）会被氧化，也不能用浓硫酸干燥。干燥剂的选择本质是「气体的性质 × 干燥剂的性质」的匹配问题。</span>

### 脱水性

把有机物中的氢、氧元素按水的组成比（$\ce{H : O = 2 : 1}$）脱去，剩余碳元素，这就是**脱水性**。典型的实验：向蔗糖（$\ce{C12H22O11}$）中加入浓硫酸，蔗糖迅速炭化变黑、体积膨胀，形成疏松多孔的黑褐色固体，并闻到刺激性气味。

$$
\ce{C12H22O11 ->[浓H2SO4] 12C + 11H2O}
$$

注意区分吸水性（吸收游离水，物理变化）与脱水性（夺取化合物内部的氢氧原子，化学变化）。这一点是考试最爱挖的坑。

### 强氧化性

浓硫酸中硫元素处于最高价态 $+6$，只具有氧化性。加热时它能氧化大多数金属（金、铂除外）与非金属，自身被还原为 $\ce{SO2}$。浓硫酸氧化金属时**不放氢气**，这与稀硫酸完全两样——稀硫酸的氧化性来自 $\ce{H+}$（产物 $\ce{H2}$），浓硫酸的氧化性来自 $+6$ 价硫（产物 $\ce{SO2}$）。

**辨析｜易错点：** 常温下，浓硫酸与铁、铝接触会使其表面迅速生成一层致密的氧化物薄膜，阻止反应继续，这叫**钝化**。注意：钝化是「常温下、发生反应但被抑制」，不是「不反应」。因此冷的浓硫酸可以装在铁罐、铝罐中运输，但热的浓硫酸会与铁、铝剧烈反应。

## 3 公式解析：浓硫酸与铜的反应（强氧化性的本质）

把「浓硫酸的强氧化性」具体化，最经典的反应是加热下浓硫酸与铜反应：

$$
\ce{Cu + 2H2SO4(浓) ->[\Delta] CuSO4 + SO2 ^ + 2H2O}
$$

分三步拆解这条方程式：

- **第一步，定变价**：反应前后铜由 $0$ 价升为 $+2$ 价（失电子，被氧化），硫由 $+6$ 价降为 $+4$ 价（得电子，被还原）。氧化剂是浓硫酸中的 $\ce{H2SO4}$，还原剂是 $\ce{Cu}$。
- **第二步，配电子**：铜失去 $2$ 个电子，每个硫得 $2$ 个电子，电子转移数为 $2$，故 $\ce{Cu}$ 与发生还原的 $\ce{H2SO4}$ 系数为 $1:1$。
- **第三步，数硫酸分子**：反应中共消耗 $2$ 个 $\ce{H2SO4}$，其中 $1$ 个被还原为 $\ce{SO2}$，另 $1$ 个硫保留 $+6$ 价、进入 $\ce{CuSO4}$——它只提供酸性。**结论：浓硫酸在氧化还原反应中身兼两职——既作氧化剂又作酸的载体，这正是含氧酸参与氧化还原的普遍模式。**

由此再推一个定量结论：用浓硫酸氧化足量铜时，被还原的硫酸占反应硫酸总数的 **一半**。这类「氧化性与酸性双重角色」的计算，是化学计算的重要题型。

## 4 硫酸根离子的检验

稀硫酸与可溶性硫酸盐在溶液中都产生 $\ce{SO4^{2-}}$。检验 $\ce{SO4^{2-}}$ 的经典方案是：向待测液中加入**稀盐酸**，若无沉淀、无明显现象，再加入**氯化钡（$\ce{BaCl2}$）溶液**，若生成**白色不溶于稀盐酸的沉淀**，则证明含 $\ce{SO4^{2-}}$。

$$
\ce{Ba^{2+} + SO4^{2-} -> BaSO4 v}
$$

**为什么要先加稀盐酸？** 因为 $\ce{Ba^{2+}}$ 还能与 $\ce{CO3^{2-}}$、$\ce{SO3^{2-}}$ 生成白色沉淀 $\ce{BaCO3}$、$\ce{BaSO3}$，它们溶于盐酸，而 $\ce{BaSO4}$ 不溶于盐酸。先酸化可以排除碳酸根、亚硫酸根等干扰离子——这是「检验要排除干扰」这一方法论的典型应用。<span class="marginnote">检验离子的通用策略在《化学实验基础》专题会系统化：先加合适试剂排除干扰，再加特征试剂产生特征现象（沉淀、气体、颜色）。后续检验 $\ce{Cl-}$ 用硝酸银加稀硝酸、检验 $\ce{NH4+}$ 用氢氧化钠加热，都是同一思路。</span>

**辨析｜易错点：** 若待测液中含有 $\ce{Ag+}$，加盐酸会产生白色 $\ce{AgCl}$ 沉淀，干扰判断。此时应改为先加稀硝酸，或用其他方案排除银离子。此外，若不加盐酸直接加 $\ce{BaCl2}$，则无法区分 $\ce{SO4^{2-}}$ 与 $\ce{CO3^{2-}}$。

## 5 硫酸的工业制备：接触法

工业上硫酸采用**接触法（contact process）**生产，三步走：

- **第一步，沸腾炉中煅烧黄铁矿**：$\ce{4FeS2 + 11O2 ->[高温] 2Fe2O3 + 8SO2}$。
- **第二步，接触室中催化氧化**：$2\ce{SO2 + O2 <=>[\Delta][V2O5] 2SO3}$，这是可逆反应，采用五氧化二钒作催化剂、约 $400\text{–}500^\circ\mathrm{C}$。
- **第三步，吸收塔中用浓硫酸吸收** $\ce{SO3}$：$\ce{SO3 + H2O -> H2SO4}$。工业上不用水直接吸收，因为会形成酸雾难以吸收，改用 $98.3\%$ 的浓硫酸吸收后再稀释。

接触法体现了「化工生产要同时考虑速率、平衡与工程成本」的思想——第二级之后的选择性必修1《化学反应原理》第二章将系统展开：为什么选 $400\text{–}500^\circ\mathrm{C}$、为什么用过量空气，都是速率与平衡权衡的经典案例。

## 6 浓硫酸与稀硫酸的鉴别与除杂

浓硫酸的三大特性常与「鉴别」「除杂」结合出题——掌握「性质差异 → 方法」的推理。

**核心概念：鉴别浓硫酸与稀硫酸的方法**。

| 方法 | 浓硫酸 | 稀硫酸 |
| --- | --- | --- |
| 滴在纸上 | 炭化变黑（脱水性） | 无 |
| 加铁片 | 常温钝化（不反应） | 放氢气 |
| 加蔗糖 | 变黑膨胀 | 无明显变化 |
| 测密度/黏度 | 大、黏稠 | 小、稀薄 |

**重点：最简便的鉴别是「脱水性」**——把待测液滴到纸屑或蔗糖上，变黑的是浓硫酸（脱水炭化）。浓硫酸「吸收水 + 脱水」两性质可综合利用。

**公式解析：干燥气体时浓硫酸的适用性**

- **第一步，看干燥原理**：浓硫酸吸收水蒸气（吸水性）——作干燥剂。
- **第二步，看限制**：浓硫酸不能干燥**碱性气体**（$\ce{NH3}$ 与酸反应）与**还原性气体**（$\ce{H2S}$、$\ce{HBr}$、$\ce{HI}$ 被氧化）。
- **第三步，选气体**：可干燥 $\ce{O2}$、$\ce{H2}$、$\ce{CO2}$、$\ce{Cl2}$、$\ce{SO2}$ 等酸性/中性气体。

**结论：浓硫酸的用途 = 「吸水（干燥）+ 脱水（鉴别/炭化）+ 强氧化（反应）」三性质的应用**。<span class="marginnote">「干燥剂的选择」本质是「气体性质 × 干燥剂性质」的匹配：碱用碱石灰、还原性气体不能用氧化性干燥剂。浓硫酸虽好，但不万能——「一物降一物」。这个「性质匹配」是化学选择试剂的通用逻辑：从干燥剂到除杂剂、从萃取剂到沉淀剂，都是「找性质互补」的过程。</span>

**辨析｜易错点：** ①浓硫酸干燥 $\ce{NH3}$ 会反应（酸碱中和）——碱性气体禁用；②干燥 $\ce{H2S}$、$\ce{HBr}$ 会被氧化（生成硫/溴）——还原性气体禁用；③「浓硫酸吸水」是物理变化、「脱水」是化学变化——两性质要分清。

## 7 小结

- 浓硫酸的**三大特性**：吸水性（物理）、脱水性（化学变化）、强氧化性（$+6$ 价硫）。
- 稀硫酸氧化性来自 $\ce{H+}$ 生成 $\ce{H2}$，浓硫酸氧化性来自 $\ce{S^{+6}}$ 生成 $\ce{SO2}$；浓硫酸与金属反应不放氢气。
- 常温下浓硫酸使铁、铝**钝化**，可用铁罐运输；加热则剧烈反应。
- 浓硫酸在氧化还原中**既作氧化剂又作酸**，被还原的硫酸占一半。
- 检验 $\ce{SO4^{2-}}$：先加稀盐酸排除干扰，再加 $\ce{BaCl2}$，白色沉淀不溶于酸即证。
- 工业接触法：沸腾炉→接触室（$\ce{V2O5}$ 催化）→吸收塔（浓硫酸吸收）。
