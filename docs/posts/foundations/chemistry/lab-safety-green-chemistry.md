## 为什么安全是实验的「第一性原则」

化学实验与火、酸碱、有毒气体为伴，安全规范不是束缚而是护身符。本节系统梳理实验安全：危险化学品的识别、常见事故的处理（火灾、灼伤、中毒）、防护用品的正确使用；并把「安全」升华到「绿色」——实验设计的环保理念（微量化、少污染、循环利用）。<span class="marginnote">实验室安全事故的教训提醒我们：浓硫酸稀释顺序、酒精灯用法、有毒气体通风，每一个「细节」都可能是「生死」的差别。安全规范背后是无数事故总结出的经验——它不是教条，是「用教训换来的规则」。</span>

## 1 危险化学品的识别与防护

**核心概念：危险化学品的标志**。常见警示标志：易燃（酒精、汽油）、易爆（硝酸铵）、腐蚀（浓硫酸、烧碱）、有毒（氯气、氰化物）、氧化剂（高锰酸钾）。

**防护用品**：护目镜（防溅入眼睛）、手套（防腐蚀）、实验服、通风橱（有毒气体实验）。<span class="marginnote">「看标志识危险」是实验室第一课：易燃品远离火源、腐蚀品戴手套护目镜、有毒品在通风橱操作。危险化学品的分级管理（储存、领用、废弃物处理）在实验室规范与工业 HSE 体系中都是制度化的——见第五级《职业卫生》与第八级《安全工程》。</span>

**重点：试剂的保存原则**。
- 见光易分解的（浓硝酸、$\ce{AgNO3}$）：**棕色瓶避光保存**；
- 易与空气反应的（钠、白磷）：钠**保存在煤油中**、白磷**保存在水中**；
- 碱性溶液（$\ce{NaOH}$）：用**橡皮塞**（不能用玻璃塞——与 $\ce{SiO2}$ 反应黏住）；
- 氢氟酸：**塑料瓶**（腐蚀玻璃）。

**辨析｜易错点：** ①钠保存在煤油（与煤油不反应、密度大于煤油）、白磷保存在水（与水不反应、隔绝空气防自燃）；②盛碱液用橡皮塞、盛 $\ce{NaOH}$ 的玻璃瓶会「黏塞」；③氢氟酸不用玻璃瓶（腐蚀玻璃）、浓硝酸用棕色瓶（见光分解）。

## 2 常见事故的处理

**核心概念：事故处理的原则——「先脱离危险，再处理」**。

| 事故 | 处理方法 |
| --- | --- |
| 酒精灯失火 | 用**湿抹布**盖灭（隔绝空气） |
| 浓硫酸溅到皮肤 | **先用大量水冲洗**，再涂 $\ce{NaHCO3}$ 溶液 |
| 浓碱溅到皮肤 | 大量水冲洗，再涂稀硼酸（或醋酸） |
| 酸/碱溅入眼睛 | 立即用大量水冲洗（眨动眼睛），送医 |
| 有毒气体泄漏 | 立即通风、撤离 |
| 少量酒精着火 | 湿抹布或沙子盖灭 |

**重点：浓硫酸处理的「先冲洗后处理」**。浓硫酸溅到皮肤，**先大量水冲洗**（稀释并带走热量——注意不能先擦，擦会扩大接触面），再涂稀 $\ce{NaHCO3}$ 中和残留酸。<span class="marginnote">「浓硫酸先冲洗再中和」与「稀释浓硫酸时酸入水」是配套的安全知识：稀释浓硫酸必须「<strong>酸入水、沿壁倒、勤搅拌</strong>」——水入酸会因局部过热暴沸溅出。这两个「顺序」是实验安全最经典的两问。</span>

**辨析｜易错点：** ①稀释浓硫酸：**把酸沿器壁缓缓倒入水中**（不能把水倒入酸中）；②眼睛溅入立即**用水冲洗**（不要揉）并就医；③油类着火不能用水浇（油浮水面、火随水扩散）——用湿布/沙子/灭火器；④酒精灯着火**不能吹**（风助火势）——用湿抹布盖灭。

## 3 实验的绿色化

**核心概念：绿色化学实验**。把绿色化学理念（必修二第八章：原子经济、源头预防）落实到实验设计中：

1. **微量化**：用微型实验（点滴板、微型试管）减少试剂用量与废物；
2. **少毒化**：用无毒/低毒试剂代替有毒试剂、密闭装置防泄漏；
3. **循环利用**：回收溶剂、催化剂（如 $\ce{MnO2}$ 回收）；废物分类处理；
4. **尾气处理**：有毒气体（$\ce{Cl2}$、$\ce{SO2}$、$\ce{CO}$）加吸收/燃烧装置。

**重点：绿色实验的「三少一好」**——试剂少、污染少、能耗少、效果好。微型实验、密闭体系、废物回收是实验室层面的绿色化路径。<span class="marginnote">绿色化学实验是「从课堂到产业」的环保延伸：实验室的微量化理念放大到工业就是「原子经济 + 清洁生产」。个人层面，实验室废液分类回收（酸液、碱液、重金属废液分开）是每个实验者的环保责任——这与第八级《环境工程》的废物管理一脉相承。</span>

**辨析｜易错点：** ①「绿色实验」不是「不做实验」，而是「更聪明地做」——用更少、更安全、更环保的方式达成实验目的；②废弃物**分类处理**（不可随意倒水槽——重金属污染水源）；③尾气吸收与防倒吸是「安全 + 环保」双重需求。

## 4 公式解析：实验安全与绿色化的综合判断

评价一个实验方案的「安全 + 绿色」程度：

- **第一步，查安全**：有无易燃易爆物（远离火源）、腐蚀性试剂（防护）、有毒气体（通风 + 尾气处理）、高压高温（防爆）。
- **第二步，查环保**：试剂用量（能否微型化）、废物产生（能否回收）、尾气排放（能否吸收）。
- **第三步，综合定级**：安全无虞 + 污染可控 = 合格方案；若能微量化 + 原子经济 = 优秀方案。

**结论：安全与绿色是实验方案的两条「底线」**——安全保证「不伤人」，绿色保证「不伤环境」。两者在「用更少、更温和、更可回收的化学」这一点上统一。

## 5 废弃物处理与实验室环保责任

实验的「最后一公里」是废弃物处理——它既是安全要求，也是绿色化学的延伸。

**核心概念：实验室废弃物的分类处理**。

| 废物类型 | 处理方法 |
| --- | --- |
| 酸/碱废液 | 中和后排放（达标） |
| 重金属废液 | 沉淀/吸附后回收，不倒入水槽 |
| 有机废液 | 分类收集、集中处理（不倒入下水道） |
| 废固（废纸、废玻璃） | 分类回收 |
| 有毒气体 | 尾气吸收后排放 |

**重点：危险废物的「三不」**——不倒入下水道（重金属污染水源）、不随意丢弃（污染土壤）、不混合存放（酸碱混合可能剧烈反应、有机物与氧化剂混合易燃）。

**公式解析：为什么废液要「分类」**

- **第一步，看反应风险**：酸与碱混合放热、有机物与氧化剂混合可能起火——分类存放防止意外反应。
- **第二步，看污染**：重金属废液倒入水槽 → 进入水循环 → 污染地下水与食物链（生物富集）——「一滴铅废液污染一大片」。
- **第三步，看回收**：分类的废液（如含银废液）可回收贵金属——「分类 = 可回收的前提」。

**结论：废弃物分类 = 「安全 + 环保 + 资源回收」三赢**。<span class="marginnote">「废物是放错位置的资源」——含银废液回收银、废催化剂回收铂、废电池回收锂钴。实验室的垃圾分类与工业的「循环经济」、城市的垃圾分类是同构的系统思维。每个人的分类投放，都是资源循环链条上的一环——这正是绿色化学「从源头到末端全周期」的理念。</span>

**辨析｜易错点：** ①废液不能「图省事」直接倒水槽——重金属与有机物污染后果严重；②酸碱废液先中和再排放（达标排放理念）；③实验室废弃物处理有专门台账与流程——安全环保的制度化。

**补充：实验室安全文化的「预防优先」**。安全事故的教训表明：几乎所有事故都可预防——「防患于未然」是安全的第一原则：进实验室先看逃生路线、熟悉灭火器位置、了解所用试剂性质、不擅自做「未规划的实验」。安全文化不是「一套规则」而是「一种习惯」——把「先想安全再做实验」内化为本能，是实验者的基本素养。

**补充：实验室事故的「应急原则」**。事故应急遵循「先人后物、先脱离再处理」：人受伤先救人不顾物、先脱离危险区再处理。具体：着火先断电源/移开易燃物、用湿布/灭火器扑灭（不用水浇油火）、烫伤冲冷水、化学灼伤大量水冲。「冷静 + 有序 + 按预案」是应急的核心——平时演练、用时不乱。

**补充：实验室的「绿色实验」案例**。微量化（点滴板代替试管、微型气体发生装置）、密闭化（微型气体实验在密闭体系内完成）、循环化（溶剂回收、催化剂回收）、替代化（用低毒试剂替代有毒试剂）。「绿色实验 = 少、密、回、替」四字诀——从源头减量、从过程防泄漏。「实验室的绿色习惯」放大到工业就是「清洁生产」——绿色化学从课堂做起。

**补充：绿色化学实验的「评估」再梳理**。评估实验的绿色度：原子利用率（产物/总原料）、E 因子（废物/产品）、溶剂安全性（水 > 有机溶剂）、能耗。「绿色评估让『环保』可量化」——从「感觉环保」到「数字环保」。「绿色化学实验 = 少毒 + 少废 + 少耗能」——用指标衡量，用设计改进。「绿色理念 + 量化评估」是化学实验的现代标准。

**补充：实验室安全的「制度」再梳理**。实验室安全靠制度保障：安全培训（进实验室前）、操作规程（SOP）、应急预案（事故处理流程）、安全检查（定期巡检）。「安全是制度化的『习惯』」——「从个人意识到制度保障」。「实验室安全文化」与工业 HSE（安全、健康、环境）一脉相承。「安全的化学 = 知识 + 规范 + 制度」三位一体。

**补充：实验室安全的「心理」再梳理**。实验室安全不只是「技术」也是「态度」：不侥幸（再小的操作也规范）、不逞能（不懂就问）、不慌不乱（事故冷静处理）。「安全的化学 = 知识 + 规范 + 态度」——「态度决定安全」。「从'会做'到'安全地做'」——化学实验的素养。「安全不是束缚，是专业」——真正的化学家把安全当第一原则。

## 7 小结

- 危险品识别：易燃、易爆、腐蚀、有毒、氧化剂标志与防护。
- 试剂保存：棕色瓶（见光分解）、煤油/水中（钠/白磷）、橡皮塞（碱液）、塑料瓶（氢氟酸）。
- 事故处理：湿布盖火、浓硫酸先冲洗、眼睛立即冲洗、通风撤离。
- **稀释浓硫酸：酸入水、沿壁倒、勤搅拌**——顺序铁律。
- 绿色实验：微量化、少毒化、循环利用、尾气处理；安全 + 环保是底线。
