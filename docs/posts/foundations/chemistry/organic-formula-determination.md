## 为什么「测定结构」是四步接力

拿到纯净的未知有机物后，如何确定它的结构？经典流程是**四步接力**：元素分析（实验式）→ 质谱（分子式）→ 红外光谱（官能团）→ 核磁共振（碳氢连接细节）。每一步解决一个问题、缩小一层范围，最终拼出完整结构。这套「层层逼近」的方法是有机结构分析的范式。<span class="marginnote">结构测定的历史：李比希 1831 年发明碳氢分析，奠定元素分析；1913 年汤姆逊质谱；1940-50 年代红外与核磁仪器化。今天的结构测定已自动化，但「元素→分子式→官能团→连接」的逻辑不变。</span>

## 1 元素分析：实验式

**核心概念：元素分析**：测定有机物中 C、H、O（及 N、S、卤素）等元素的质量分数。

**方法**：把样品完全燃烧，$\ce{C -> CO2}$、$\ce{H -> H2O}$，吸收并称量 $\ce{CO2}$、$\ce{H2O}$ 的质量，反推 C、H 质量分数；O 用差减法。

**核心概念：实验式（最简式）**：表示化合物中各元素**原子个数最简整数比**的式子。

**公式解析：由燃烧数据算实验式**

某烃样品 0.84 g 完全燃烧，生成 $\ce{CO2}$ 2.64 g、$\ce{H2O}$ 1.08 g，求实验式：

**第一步，算 C、H 质量**：$m(\ce{C}) = 2.64 \times \frac{12}{44} = 0.72\ \mathrm{g}$；$m(\ce{H}) = 1.08 \times \frac{2}{18} = 0.12\ \mathrm{g}$。$0.72 + 0.12 = 0.84$，恰好等于样品质量（无氧）。
**第二步，算物质的量比**：$n(\ce{C}) : n(\ce{H}) = \frac{0.72}{12} : \frac{0.12}{1} = 0.06 : 0.12 = 1 : 2$。
**第三步，写实验式**：实验式为 $\ce{CH2}$。

**结论：实验式 = 「质量 → 物质的量 → 最简整数比」**。实验式只给比例，不含分子量——要确定真正的分子式，还差质谱。<span class="marginnote">实验式相同的化合物可能不同（如 $\ce{CH2}$ 可以是乙烯 $\ce{C2H4}$ 或环丙烷 $\ce{C3H6}$ 的实验式）。因此实验式只是「候选集合」，分子式必须在实验式基础上乘一个整数 n。</span>

## 2 质谱：相对分子质量与分子式

**核心概念：质谱（mass spectrometry）**。把样品分子电离成离子，按质荷比（$m/z$）分离检测。**分子离子峰**（分子失去一个电子）对应的 $m/z$ 即为**相对分子质量**。

**重点：由质谱读分子量**。质谱图中**质荷比最大的峰（分子离子峰）**给出相对分子质量。结合实验式，即可确定分子式：

实验式 $\ce{CH2}$，相对分子质量 28 → $\ce{(CH2)}_n$ 中 $14n = 28$，$n = 2$ → 分子式 $\ce{C2H4}$。

**公式解析：由实验式与分子量定分子式**

某有机物实验式为 $\ce{C2H5O}$，质谱测得相对分子质量为 46，求分子式：

**第一步，算实验式量**：$M(\ce{C2H5O}) = 2\times12 + 5 + 16 = 45$。
**第二步，求倍数**：$\frac{\text{相对分子质量}}{\text{实验式量}} = \frac{46}{45} \approx 1$（实际应为整数，此例提示实验式需再核——正确实验式可能含偶数个 H 的调整。设实验式 $\ce{C2H6O}$ 量 46，正好）。
**第三步，定分子式**：分子式 = 实验式 × n。n 必须是正整数（取最接近值）。

**结论：分子式 = 实验式 × n，n 由「相对分子质量 ÷ 实验式量」确定**。质谱提供分子量、元素分析提供比例，两者配合锁定分子式。<span class="marginnote">高分辨质谱可直接给出精确分子量（如 46.0419），由此精确确定分子式（误差小于 1 ppm）。现代质谱已能直接测出元素组成，无需猜测 n。质谱还在蛋白质组学中测定生物大分子——见第五级《生物化学》。</span>

**辨析｜易错点：** ①分子离子峰是**最大 m/z 峰**，但注意同位素峰（如 $\ce{^{13}C}$）略高 1——取主峰；②「质荷比」= 质量/电荷，单电荷离子 m/z = 相对分子质量；③实验式与分子式可能相同（如 $\ce{CH4}$ 本身就是最简式），也可能不同（$\ce{C2H4}$ vs 实验式 $\ce{CH2}$）。

## 3 红外光谱：官能团的「指纹」

**核心概念：红外光谱（IR）**。分子中化学键的振动吸收特定波长的红外光，形成吸收峰。不同官能团/化学键在特征波数处有吸收，可据此判断官能团种类。

**常见红外吸收特征**（波数 $\mathrm{cm^{-1}}$）：
$\ce{O-H}$：约 3200–3600（宽峰，醇、酚、酸）；
$\ce{C=O}$：约 1700–1750（醛、酮、羧酸、酯的羰基）；
$\ce{C#N}$：约 2200（腈）；
$\ce{C=C}$：约 1600–1680（烯烃）。

**重点：红外光谱回答「有什么官能团」**。看特征吸收峰的位置与形状，判断分子含羟基、羰基、氨基等——这是结构测定的「第二层」信息。

**辨析｜易错点：** ①红外光谱看**峰的位置**（对应键振动频率），不是看峰的面积；②$\ce{O-H}$ 峰宽而强（氢键展宽），$\ce{C-H}$ 峰在约 3000 处——区分醇羟基与羧基羟基要看峰形与相邻峰；③红外不能直接给出「连接顺序」，那是核磁的任务。

## 4 核磁共振：分子结构的「定位仪」

**核心概念：核磁共振氢谱（$^1\ce{H\ NMR}$）**。不同化学环境的氢原子在磁场中产生不同的共振吸收，谱图上出现**不同位置的峰**。峰的**组数** = 氢原子环境的种类数；**峰面积比** = 各类氢原子数之比。

**核心概念：核磁共振碳谱（$^{13}\ce{C\ NMR}$）**。同理测定碳原子的化学环境种类与相对数目。

**重点：核磁氢谱的「三读」**——①读组数（几种氢环境）；②读峰面积比（氢数比）；③读化学位移（氢的环境类型，如烷基氢、烯氢、醛氢）。综合三读可推分子结构。

**公式解析：用核磁验证结构**

分子式 $\ce{C2H6O}$ 的两种异构体：

**乙醇 $\ce{CH3CH2OH}$**：三种氢环境（$\ce{CH3}$、$\ce{CH2}$、$\ce{OH}$）→ 氢谱 **3 组峰**，面积比 $3:2:1$；
**二甲醚 $\ce{CH3OCH3}$**：只有一种氢环境（六个 $\ce{CH3}$ 等价）→ 氢谱 **1 组峰**。

**结论：核磁「峰组数与面积比」可直接区分同分异构体**——乙醇 3 组峰、二甲醚 1 组峰，一测便知。<span class="marginnote">核磁共振是结构测定的终极武器：配合氢谱、碳谱、二维谱，化学家能「画出」未知分子的完整结构。它在医学影像（MRI）中也有应用（利用水的氢核共振）——同一个物理原理，跨越化学与医学，是「从原子到大模型」知识树上物理原理横向应用的典范。</span>

**辨析｜易错点：** ①氢谱「几组峰」指**等效氢**的种类数，不是氢原子总数；②峰面积比 = 各类氢数之比（3:2:1 对应 3 个、2 个、1 个氢）；③活泼氢（$\ce{-OH}$、$\ce{-NH2}$）的化学位移受浓度、温度影响，可能在谱图中移动或交换消失。

## 5 结构测定的综合案例：确定未知物的结构

把「元素分析 + 质谱 + 红外 + 核磁」四步串起来，就能完成一道「确定未知物结构」的综合题——这是本章知识的最高应用。

**公式解析：综合推断示例**

某有机物含 C、H、O，燃烧生成 $\ce{CO2}$ 与 $\ce{H2O}$ 的质量比算出实验式 $\ce{CH2O}$；质谱分子离子峰 60 → 分子式 $\ce{C2H4O2}$；红外在 1700 cm⁻¹ 有 $\ce{C=O}$ 吸收、3200 cm⁻¹ 有 $\ce{O-H}$ 宽峰；核磁氢谱 3 组峰、面积比 3:1:1。确定结构：

**第一步，分子式**：$\ce{C2H4O2}$（质谱 60）。
**第二步，官能团**：红外含 $\ce{C=O}$ 与 $\ce{O-H}$ → 羧基 $\ce{-COOH}$。
**第三步，核对核磁**：$\ce{CH3COOH}$ 的氢：$\ce{CH3}$（3 个）、$\ce{COOH}$（1 个）——但乙酸只有 2 组峰（甲基 3 个、羧基 1 个），面积比 3:1。若面积比 3:1:1 则可能是 $\ce{HCOOCH3}$（甲酸甲酯：$\ce{OCH3}$ 3 个 + $\ce{CHO}$ 1 个）——核磁区分了乙酸与甲酸甲酯两种同分异构体。

**结论：四步接力逐步锁定结构——每一步排除一部分可能**。<span class="marginnote">这个例子展示了结构测定的「信息层层递进」：实验式缩小元素比、质谱定分子式、红外定官能团种类、核磁定「氢的环境与数目」——每步增加一条约束、排除若干候选结构。这本质上是「逐步缩小搜索空间」的推理——与机器学习中「多特征联合判别」、以及刑侦中「线索拼图」是同一类逻辑。核磁的 3:1:1 与 3:1 之差，直接区分了同分异构体。</span>

**辨析｜易错点：** ①红外看「有什么官能团」、核磁看「氢怎么分布」——两者互补、缺一不可；②核磁的「峰面积比」是「氢数之比」——别当成「个数」直接读；③同分异构体（乙酸与甲酸甲酯）要靠核磁区分——分子式相同、官能团不同、氢环境不同。

## 6 分子式确定中的不饱和度检查

确定分子式后，用**不饱和度**验证结构是否合理，是避免「写出不存在结构」的保险丝。

**核心概念：不饱和度（$\Omega$）**。分子中「缺氢数」的一半：

$$
\Omega = \frac{2n_{\ce{C}} + 2 - n_{\ce{H}}}{2}\ (\text{含 O、S 无影响；N 加 1；卤素减 1})
$$

- $\Omega = 1$：一个双键或一个环；
- $\Omega = 2$：两个双键/一个三键/一个环加一个双键/两个环；
- $\Omega = 4$：苯环（三个双键 + 一个环）。

**公式解析：由分子式算不饱和度**

对 $\ce{C6H6}$（苯）：$\Omega = (2\times6 + 2 - 6)/2 = 4$——正好对应苯环（3 个 π 键 + 1 个环），说明苯是环状高度不饱和结构。

对 $\ce{C2H6O}$（乙醇/二甲醚）：$\Omega = (2\times2 + 2 - 6)/2 = 0$——无环无双键，与醇/醚（饱和）吻合。

**结论：不饱和度 = 「结构类型」的快速筛查**——算出 $\Omega$ 就知道分子含几个双键/环，与红外、核磁结果互证。<span class="marginnote">不饱和度是「结构预算」：它先告诉你「分子里该有多少不饱和键」，再与红外（C=O、C=C 的峰）对照，就能锁定官能团组合。这个「先预算、后核对」的方法，把结构推断从「猜」变成「查账」。它还与色谱质谱中的「环加双键数」（RDBE）同一概念——现代质谱软件直接报告 RDBE 帮助结构解析。</span>

**辨析｜易错点：** ①O、S 原子对 $\Omega$ 无影响（不改变缺氢数）；②N 每多一个加 1（含 N 化合物的 $\Omega$ 要修正）；③卤素按「氢」计（减 1）——$\ce{C2H5Cl}$ 的 $\Omega$ 按 $\ce{C2H6}$ 算为 0（饱和）。

## 7 小结

- 结构测定四步：**元素分析（实验式）→ 质谱（分子式）→ 红外（官能团）→ 核磁（连接）**。
- 实验式：由燃烧数据算最简整数比；分子式 = 实验式 × n。
- 质谱分子离子峰给出相对分子质量。
- 红外光谱：特征吸收峰判断官能团（$\ce{O-H}$、$\ce{C=O}$ 等）。
- 核磁氢谱：峰组数 = 氢环境种类、峰面积比 = 氢数比——区分异构体。
