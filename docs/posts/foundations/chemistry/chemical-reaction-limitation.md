## 为什么「反应进行到底」是例外而非常态

初中我们写 $\ce{CaCO3 + 2HCl -> CaCl2 + H2O + CO2 ^}$，好像反应一定把反应物用光。但请想一个反例：把 $\ce{CO2}$ 通入石灰水，既生成碳酸钙，可反过来酸又溶解碳酸钙——反应难道不能倒着走吗？实际上，**许多反应在进行的同时，逆反应也在悄悄发生**。当正逆反应速率相等时，反应「停」在了一个平衡位置——这就是化学反应的**限度**。<span class="marginnote">可逆反应是化学平衡的温床。最经典的例子：$\ce{N2 + 3H2 <=> 2NH3}$，合成氨工厂不可能把氢气、氮气全部转化，只能让它们到达一个平衡点。平衡思想也是第三级《热力学》与第二级《随机过程》中「稳态」的化学版本。</span>

## 1 可逆反应与化学平衡状态

**核心概念：可逆反应**：在同一条件下，既能向正反应方向进行、又能向逆反应方向进行的反应，用「$\ce{<=>}$」连接。绝大多数反应都有一定的可逆性，只是可逆程度不同。

**核心概念：化学平衡状态**：在一定条件下，当正反应速率与逆反应速率**相等**时，反应物与生成物的浓度**不再改变**，反应达到化学平衡。

达到平衡的标志可以这样记：

- **本质标志**：$v_{\text{正}} = v_{\text{逆}}$（同一物质的正逆反应速率相等）；
- **浓度标志**：各组分浓度保持恒定（不一定相等！）；
- **适用判断**：是「变量不变」——只要某物理量**随反应进程在变**，达到平衡时它「保持不变」即可作为标志。

**辨析｜易错点：** 「浓度不变」≠「浓度相等」。化学平衡时反应物与生成物浓度**不一定相同**，只是各自不再变化。例如 $\ce{2SO2 + O2 <=> 2SO3}$ 达到平衡时，三者的浓度可以是任意稳定值，绝不要求相等。

## 2 化学反应的限度：转化率

**化学反应的限度**：在一定条件下，反应所能达到的最大程度。用**转化率**来定量刻画：

$$
\alpha = \frac{\text{某反应物转化的浓度}}{\text{该反应物的初始浓度}} \times 100\%
$$

转化率越高，说明该条件下反应进行得越「彻底」。同一种反应，条件不同（温度、压强、浓度），限度就不同——**限度不是天生固定的，而是随条件变化的**。<span class="marginnote">这与速率形成对比：速率回答「多快」，限度回答「多远」。工业上两者必须同时考虑——只求快而转化率太低，或只求高转化率而慢得无法接受，都不是好工艺。</span>

例如合成氨反应，常温下速率极慢（几乎不反应），高温下速率快但转化率下降（反应放热，高温不利于平衡）。工业只能选一个折中条件——这是「速率与限度的权衡」的经典样本，选择性必修1第二章会完整展开。

## 3 影响平衡移动的因素：勒夏特列原理

当平衡被外部条件改变时，平衡会**移动**（正移或逆移）来削弱这种改变，直到重新建立平衡。这个规律就是**勒夏特列原理（Le Chatelier's principle）**：**改变影响平衡的一个条件，平衡将向着能够减弱这种改变的方向移动。**

- **浓度**：增大反应物浓度，平衡**正移**（向消耗反应物方向）；减小生成物浓度，平衡正移。
- **温度**：升高温度，平衡向**吸热方向**移动；降低温度，向放热方向移动。
- **压强**：增大压强，平衡向**气体分子数减少**的方向移动；减小压强反之。仅对气体参与的反应有效。
- **催化剂**：同时等倍改变正逆速率，**不引起平衡移动**，只缩短到达平衡的时间。

**辨析｜易错点：** ①「减弱」不是「抵消」——平衡移动只能部分削弱外因，不能完全消除；②催化剂**平衡不移动**，但能加快到达平衡（工业上极重要）；③固体与纯液体浓度视为常数，增减它们**不引起平衡移动**。

## 4 公式解析：用浓度商判断平衡移动方向

平衡移动的判断，可以浓缩成一个比值——**浓度商 $Q$**。对反应 $\ce{aA + bB <=> cC + dD}$：

$$
Q = \frac{c^c(\ce{C}) \cdot c^d(\ce{D})}{c^a(\ce{A}) \cdot c^b(\ce{B})}
$$

- **第一步，算 Q**：把当前各组分浓度代入上式。$Q$ 描述「现在的状态」。
- **第二步，找平衡点**：当反应平衡时，$Q$ 恰好等于一个常数——**化学平衡常数 $K$**（$K$ 只与温度有关）。
- **第三步，比较判方向**：若 $Q < K$，体系「还没到」平衡，反应**正移**；若 $Q > K$，**逆移**；若 $Q = K$，恰在平衡，不动。

**结论：平衡移动的方向 = 比较 $Q$ 与 $K$ 的大小**。这里 $K$ 是「目的地」（只由温度决定），$Q$ 是「当前位置」；勒夏特列原理描述的正是 $Q$ 被外力推开后，体系自动向 $K$ 回归的过程。<span class="marginnote">「$Q$ vs $K$」是选择性必修1第二章化学平衡常数的核心工具，今天先种下概念的种子。它与第二级《概率》中「先验—后验」的比值思想、以及机器学习里「loss 最小化」的迭代收敛，是同一类「目标比较」逻辑。</span>

## 5 化学平衡移动的图像分析

改变条件后，平衡如何「移动」、图像如何变化，是化学平衡的核心题型——掌握「先突变、再移动、后平衡」的图像逻辑。

**核心概念：速率—时间图的三种突变**。

| 条件改变 | 速率突变方式 | 平衡移动 |
| --- | --- | --- |
| 增大反应物浓度 | 仅 $v_{\text{正}}$ 突增 | 正移 |
| 升高温度 | $v_{\text{正}}$、$v_{\text{逆}}$ 都突增（吸热方向更多） | 向吸热方向 |
| 增大压强 | 气体分子数多的一侧速率突增更多 | 向分子数少方向 |

**重点：从图像反推「条件改变类型」**。看突变点：**只有一条速率曲线跳 → 浓度改变；两条都跳 → 温度或压强**；两条都跳且幅度不同 → 结合吸放热/分子数判断。

**公式解析：读速率—时间图**

- **第一步，找突变点**：图中某时刻两条曲线突然变化——即条件改变的时刻。
- **第二步，看突变方式**：单线跳（浓度）还是双线跳（温度/压强）。
- **第三步，看移动方向**：突变后两线重新汇合于新平衡——新平衡相对旧平衡的「高低」反映移动方向。

**结论：平衡图像题 = 「找突变 → 判类型 → 定方向」三步**。<span class="marginnote">图像题的进阶：催化剂使两条线「等幅」突增后保持重合（平衡不移动）；而温度变化两条线「不同幅」跳（$K$ 改变、平衡移动）。「等幅 vs 不等幅」区分催化剂与温度——催化剂不改 $K$、温度改 $K$，这是图像背后最本质的判据。</span>

**辨析｜易错点：** ①浓度改变只跳一条线（另一条不变）——因为它只影响一方速率；②温度、压强两条都跳（都影响正逆速率）；③新平衡的速率不一定回到原值（温度改变后新平衡速率不同）——「汇合」不是「回到原线」。

**补充：可逆反应与不可逆反应的「光谱」**。可逆与不可逆没有绝对界限——绝大多数反应都可逆，只是「可逆程度」不同：沉淀反应、强酸强碱中和「几乎完全」（$K$ 极大）；弱电解质电离、酯化「明显可逆」（$K$ 适中）。「不可逆」是「$K$ 大到可忽略逆反应」的近似——理解这个「连续光谱」，就不会把可逆/不可逆绝对化。

**补充：化学平衡与速率控制的工业联系**。平衡「能走多远」与速率「走多快」是工业的两把尺子：转化率低就改变条件（加压、移产物）让平衡右移；反应慢就升温、加催化剂。合成氨（§6.2 已学）、硫酸接触法都是「平衡 + 速率」双调控的案例——「限度」与「速率」是化工优化的两个维度，缺一不可。

**补充：转化率、平衡常数与「限度」的统一**。转化率（$\alpha$）是「当时进行程度」、平衡常数（$K$）是「该温度下最大程度的固有标尺」——两者关系：$\alpha$ 随起始浓度变、$K$ 不变。工业上「提高限度」的手段（加压、移产物）本质是「让平衡更靠产物」而非「改变 $K$」——「限度可调但常数恒定」是平衡思想的核心。

**补充：化学平衡与「生命体内平衡」的类比**。化学平衡的「动态相抵」思想是生命稳态的模型：体温恒定（产热 = 散热）、血糖稳定（升糖 = 降糖）、pH 稳定（缓冲）。「平衡是一种动态的稳定，而非静止」——这个观念从化学扩展到生理学、生态学（种群平衡）。「平衡思维」是理解「系统如何维持稳定」的通用语言——化学给了生命科学第一课。

**补充：勒夏特列原理的「适用范围」**。勒夏特列原理适用于「已达平衡的体系」被改变条件后的移动判断——对未达平衡的体系不适用（那是速率问题）。原理的「减弱」是「部分抵消」而非「完全恢复」；且「只减弱被改变的那个条件」——增压只向减压方向移动、不能消除全部压增。「原理有边界：平衡态 + 单一条件改变」是使用前提。

**补充：化学平衡的「图像标志」总结**。平衡图像标志：「浓度—时间」曲线变平（各浓度不变）；「速率—时间」两线重合（正逆相等）。判断「是否达平衡」用「变量不变」原则：某量随反应变化、达平衡后不变，则该量可作标志。「先问变不变、再看平不平」——平衡图像的读法核心。

**补充：化学平衡与「速率平衡图像」的配合**。读「浓度—时间」图：初始浓度、变化趋势、平衡浓度——从图可读「反应方向」（反应物降生成物升）、「平衡点」（变平处）、「转化程度」（变化量）。「图像是平衡数据的可视化」——会读图、会用图，是平衡学习的进阶技能。「图 + 数据 + 原理」三结合，平衡问题全能解。

**补充：平衡思想的「普适性」**。化学平衡的「动态相抵」思想适用于更广：溶解平衡（沉淀溶解）、电离平衡（弱电解质）、相平衡（冰水共存）、甚至生态平衡（种群动态）。「平衡是系统达到稳态的普遍方式」——正逆相抵、动态稳定。「化学平衡是『平衡思想』的第一课」——把「动态稳定」的图景带出化学，理解自然与社会的稳态。

## 7 小结

- 可逆反应用 $\ce{<=>}$；平衡时 $v_{\text{正}} = v_{\text{逆}}$、浓度不变。
- 「浓度不变」≠「浓度相等」；平衡浓度是稳定值，不要求相同。
- **转化率**刻画反应限度，随条件而变。
- **勒夏特列原理**：平衡向着减弱外因改变的方向移动；催化剂不移动平衡。
- $Q$ 与 $K$ 的比较可判断移动方向；$K$ 只与温度有关。
