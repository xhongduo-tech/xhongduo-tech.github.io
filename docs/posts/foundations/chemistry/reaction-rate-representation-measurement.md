## 为什么「平均速率」只是第一步

必修第二册我们认识了化学反应速率的基本表示。进入《化学反应原理》，速率的定义要更严格、更精细：从**平均速率**走向**瞬时速率**，并学会如何**实际测定**它。速率是化学动力学的「温度计」——测不准速率，就谈不上一系列动力学规律。<span class="marginnote">化学动力学研究反应速率与机理，与化学热力学研究方向与限度形成互补：热力学说「能不能、到哪」，动力学说「多快、怎么走」。这个「热力学 vs 动力学」的二分是整个物理化学的骨架。</span>

## 1 平均速率与瞬时速率

**核心概念：平均速率**：在一定时间间隔内，某物质浓度的变化量与时间变化量之比：

$$
v = \frac{\Delta c}{\Delta t}
$$

单位 $\mathrm{mol/(L\cdot s)}$ 或 $\mathrm{mol/(L\cdot min)}$。平均速率描述「一段时间」的平均快慢，用「割线」理解：它是浓度—时间曲线上两点间连线的斜率。

**核心概念：瞬时速率**：某一时刻的化学反应速率，是浓度—时间曲线上**该点的切线斜率**。反应进行中浓度不断变化，瞬时速率也在变化——通常随时间推移而减小（反应物浓度降低）。

**重点：平均速率与瞬时速率的关系**。时间间隔越小，平均速率越接近瞬时速率。数学上，瞬时速率是平均速率在 $\Delta t \to 0$ 时的极限——这正是微积分的思想。<span class="marginnote">「割线斜率 → 切线斜率」就是导数的定义。第二级《高等数学》的导数章节会给严格的极限语言；今天只需建立「瞬时 = 极限下的平均」这一直觉，它与后面反应速率方程的推导直接相关。</span>

**辨析｜易错点：** ①速率必须**指明物质**，且注明正负惯例——通常取浓度随时间**减少**的反应物，速率为正值（取变化量绝对值）；②平均速率不是「各时刻速率的算术平均」在计算上的直接等同，做题时直接按 $\Delta c/\Delta t$ 计算；③同一反应用不同物质表示的速率数值不同，但**之比 = 系数之比**。

## 2 反应速率的定量关系

对反应 $\ce{aA + bB -> cC + dD}$，各物质速率满足：

$$
\frac{v(\ce{A})}{a} = \frac{v(\ce{B})}{b} = \frac{v(\ce{C})}{c} = \frac{v(\ce{D})}{d}
$$

**公式解析：速率与系数的换算**

反应 $\ce{2N2O5 -> 4NO2 + O2}$，测得 $v(\ce{N2O5}) = 0.02\ \mathrm{mol/(L\cdot min)}$：

- **第一步，列系数比**：$\ce{N2O5 : NO2 : O2} = 2:4:1$。
- **第二步，算其他速率**：$v(\ce{NO2}) = \frac{4}{2} \times 0.02 = 0.04$；$v(\ce{O2}) = \frac{1}{2} \times 0.02 = 0.01$（单位相同）。
- **第三步，验证自洽**：把三个速率代入 $\frac{v}{a}$ 比较：$\frac{0.02}{2} = \frac{0.04}{4} = \frac{0.01}{1} = 0.01$——三式相等，自洽。

**结论：速率之比 = 化学计量数之比，是速率的「换算公式」**。这一关系既用于计算，也用于判断「反应是否达到平衡」（平衡时各物质速率成系数比）。<span class="marginnote">这里隐含一个前提：速率按浓度变化定义。若某物质是固体或纯液体（浓度恒定），其「浓度变化速率」无意义，不能用它表示速率——所以速率计算只适用于气体与溶液。</span>

## 3 反应速率的测定方法

怎么「看见」反应速率？本质是**测浓度随时间的变化**。常用手段：

| 测定方法 | 原理 | 适用反应 |
| --- | --- | --- |
| 气体体积法 | 测单位时间生成气体体积 | 有气体生成 |
| 颜色法 | 测溶液颜色深浅（吸光度） | 有颜色变化的溶液 |
| 浊度法 | 测沉淀产生导致的浑浊程度 | 有沉淀生成 |
| 酸碱滴定法 | 定时取样滴定测浓度 | 溶液中的酸碱反应 |
| 电导法 | 测溶液电导变化 | 离子浓度变化 |

**重点：选择测定方法的依据是「某种可观测性质与浓度单调相关」**。例如，$\ce{Zn + H2SO4 -> ZnSO4 + H2 ^}$ 可用排水集气法测氢气体积随时间的变化，绘制「体积—时间」曲线，再由曲线的切线斜率得到瞬时速率。<span class="marginnote">从「体积—时间」曲线取切线斜率求瞬时速率，就是图像处理式的动力学测量。现代实验用紫外-可见分光光度计实时测吸光度，数据更密更准——这是第五级《分析化学》的内容。</span>

**辨析｜易错点：** ①测定中必须保证**体系温度恒定**（速率对温度敏感），常用恒温槽；②用气体体积法时，读数要**同温同压**下进行（或校正），否则体积变化含温度误差；③取样滴定会**消耗反应物**（改变体系），需控制取样量小或采用连续在线监测。

## 4 实验案例：测定锌与硫酸的反应速率

设计一个简单实验：把足量锌粒投入一定浓度稀硫酸，用排水集气法记录氢气体积 $V$ 随时间 $t$ 的变化。

- **数据处理**：以 $V$ 为纵轴、$t$ 为横轴作图。曲线斜率逐渐变小——因为硫酸浓度不断降低，速率递减。
- **瞬时速率**：某时刻的斜率 = 该时刻速率。如 $t = 60\ \mathrm{s}$ 时切线斜率为 $\frac{\Delta V}{\Delta t}$，换算成 $\ce{H2}$ 的物质的量速率，再由系数比折算 $\ce{H2SO4}$ 的浓度速率。
- **曲线特征**：初始快、后期慢，最终趋平（锌耗完或酸耗尽）。

**重点：浓度—时间曲线的形状本身就是信息**。斜率递减说明速率随浓度下降而下降——这预示了下一节的「速率方程」：速率与反应物浓度存在定量关系。

## 5 速率曲线的分析与应用

「浓度—时间」与「体积—时间」曲线是速率数据的可视化——学会从曲线读信息，是动力学的重要技能。

**核心概念：速率曲线的解读**。

- **斜率 = 速率**：曲线上某点切线的斜率 = 该时刻瞬时速率；
- **斜率变化**：曲线越来越平（斜率减小）→ 速率减小（反应物浓度下降）；
- **曲线趋平**：接近反应结束（某反应物耗尽或达平衡）。

**重点：从曲线判断「一级反应」特征**。若某反应物浓度减半、速率也减半，则速率与浓度成正比（一级）——「浓度—时间」曲线呈指数衰减形（先快后慢）。

**公式解析：由曲线求平均速率**

- **第一步，取两点**：在「浓度—时间」曲线上取 $t_1$、$t_2$ 时刻的浓度。
- **第二步，算变化**：$\Delta c = c_2 - c_1$（反应物为负、取绝对值）。
- **第三步，算平均**：$v = |\Delta c|/(t_2 - t_1)$——两点间割线的斜率。

**结论：曲线 = 「点斜率（瞬时）+ 割线斜率（平均）」的双重读法**。<span class="marginnote">「切线斜率 = 瞬时速率」正是导数的几何意义（第二级《高等数学》）：把 $\Delta t$ 取极限到 0，割线变切线。化学动力学是微积分最早的用武之地之一——从「体积—时间」曲线取斜率、从「浓度—时间」关系拟合速率方程，都是「用数学读实验」。这个「数据 → 曲线 → 斜率 → 规律」的流程，是科学定量分析的通用方法。</span>

**辨析｜易错点：** ①「平均速率」用割线、「瞬时速率」用切线——别混；②曲线「变平」可能是「反应结束」也可能是「达平衡」（可逆反应）——看是否还有剩余反应物；③读曲线先看坐标轴（浓度还是体积）、单位——别被「看似相同」的曲线迷惑。

**补充：反应速率的「实验测定」细节**。测定速率要「选一个随反应进程单调变化的可测物理量」：气体体积（排水集气）、颜色（分光光度）、电导（离子浓度）、pH（酸碱反应）、压强（气体分子数变化）。现代实验用「实时监测」（分光光度计、电导仪自动记录）获得密集数据——数据越密、瞬时速率越准。测定方法的选择，本质是「找对可观测的物理量与浓度的对应关系」。

**补充：速率数据的「误差」与「平均」**。实验测速率有误差来源：温度波动（速率对温度敏感）、读数滞后（时间延迟）、副反应干扰。处理：恒温控制、多次平行取平均、剔除明显异常点。「定量实验的可靠性靠重复与统计」——单次数据不足为凭，这是科学测量的基本纪律，也是数据科学（第九级）的统计思想的雏形。

**补充：速率的「单位」与「换算」再确认**。速率单位：$\mathrm{mol/(L\cdot s)}$、$\mathrm{mol/(L\cdot min)}$——换算：$1\ \mathrm{mol/(L\cdot min)} = \frac{1}{60}\ \mathrm{mol/(L\cdot s)}$。「比较速率先统一单位」——数值随单位变。「带好单位是化学计算的基本素养」——「单位错了、结果全错」。「量纲分析」是科学计算的通用方法——从速率到反应热，单位意识贯穿。

**补充：速率的「测定」案例再梳理**。测定速率的经典实验：锌与稀硫酸（排水测氢气体积）、硫代硫酸钠与酸（测浑浊时间）、过氧化氢分解（测氧气体积/压强）。「选一个可测物理量（体积/颜色/压强）→ 记录随时间变化 → 算速率」——「速率测定的通用流程」。「测时间 = 测速率（时间短则快）」——「实验室速率的便捷测法」。

**补充：速率的「应用」再确认**。速率知识的应用：工业反应器设计（空间速率）、食品保鲜（冷藏降速）、金属防腐（减缓腐蚀）、催化剂研发（加快反应）、药物代谢（体内反应速率）。「速率是化学的『时间维度』」——「从快慢看世界」。「理解速率，就理解『化学有多快、如何控制快慢』」——「速率控制是化学工程的核心」。

## 7 小结

- **平均速率** $v = \Delta c / \Delta t$；**瞬时速率**是浓度—时间曲线的切线斜率。
- 速率之比 = 系数之比；固体、纯液体不能以浓度变化表示速率。
- 速率必须指明物质与单位；比较速率先换算到同一物质。
- 测定方法：气体体积、颜色、浊度、滴定、电导等，核心是「可观测性质随浓度单调变化」。
- 曲线斜率递减反映速率随浓度递减，是速率方程的伏笔。
