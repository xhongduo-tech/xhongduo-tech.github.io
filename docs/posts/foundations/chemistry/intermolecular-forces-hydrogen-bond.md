## 为什么「分子间」的作用力如此重要

分子内的共价键决定分子的「身份」，而**分子之间**的相互作用力（范德华力、氢键）决定物质的**聚集状态**——为什么水是液体而硫化氢是气体、为什么冰能浮在水面、为什么 DNA 双螺旋能稳定。分子间作用力比化学键弱得多，却支配着熔点、沸点、溶解性这些宏观性质。<span class="marginnote">范德华（van der Waals）1873 年修正理想气体方程时引入分子间引力概念。氢键概念则从水的反常性质（高沸点、冰浮于水）中被发现。分子间作用力是「决定物质聚集状态」的幕后之手。</span>

## 1 范德华力

**核心概念：范德华力（van der Waals forces）**：分子间普遍存在的、较弱的相互作用力，包括取向力、诱导力与色散力三种。范德华力比化学键弱得多（约 1–20 kJ/mol，化学键数百 kJ/mol）。

三种类型：

- **取向力**：极性分子之间，永久偶极的定向排列吸引；
- **诱导力**：极性分子的偶极诱导非极性分子产生瞬时偶极；
- **色散力**：分子内电子运动产生的瞬时偶极相互吸引——**所有分子间都存在**，非极性分子间主要靠它。

**重点：范德华力与熔沸点的关系**。分子间范德华力越大，物质熔沸点越高。影响范德华力大小的主要因素：

- **相对分子质量越大**，色散力越大，熔沸点越高（同系列：$\ce{F2}$ < $\ce{Cl2}$ < $\ce{Br2}$ < $\ce{I2}$ 熔沸点递增）；
- **分子极性越强**，取向力越大，熔沸点越高；
- **分子接触面积越大**，色散力越大（支链烷烃熔沸点低于直链）。<span class="marginnote">惰性气体、$\ce{H2}$、$\ce{O2}$ 等非极性物质在低温下液化，靠的正是色散力。色散力的本质是瞬时偶极的同步涨落——虽「瞬时」，却普遍存在。它也是石墨层间、石墨烯堆叠的「胶水」。</span>

**辨析｜易错点：** ①范德华力**不是化学键**——它存在于分子间，强度远小于共价键、离子键；②熔化、汽化是**破坏分子间作用力**，不破坏分子内的共价键（水汽化还是 $\ce{H2O}$ 分子）；③比较熔沸点先看「晶体类型」（分子晶体比熔沸点比范德华力），再看「分子量/极性」。

## 2 氢键

**核心概念：氢键（hydrogen bond）**：当氢原子与电负性大、半径小的原子（F、O、N）形成共价键时，该氢原子还能与另一分子（或同一分子另一部分）的电负性大原子之间形成的**较弱的相互作用**。写作 $\ce{X-H...Y}$。

**氢键的形成条件**：①有 $\ce{X-H}$ 键（X 是 F、O、N）；②有带孤对电子的 Y（F、O、N）。

**氢键的强度**：介于范德华力与化学键之间（约 20–40 kJ/mol），比化学键弱得多、比一般范德华力强。

**重点：氢键对物质性质的影响**。
- **熔沸点异常高**：水（$\ce{H2O}$）沸点远高于 $\ce{H2S}$——氧的氢键使水分子间引力大增；
- **溶解性**：能形成氢键的物质易溶于水（乙醇、氨、糖类）；
- **冰的密度小于水**：冰中氢键把水分子排成疏松的四面体骨架，体积膨胀、密度变小——所以**冰能浮在水面**，保护水生生物越冬；
- **生物大分子的稳定**：蛋白质 α 螺旋、DNA 双螺旋都靠氢键维持。<span class="marginnote">没有氢键，水的沸点约 -80°C，地球将是冰雪星球；DNA 双链靠碱基对间的氢键（A-T 两对、G-C 三对）配对——氢键既是结构支撑又允许解旋复制，是生命化学最巧妙的「弱键」设计。</span>

**辨析｜易错点：** ①氢键是**分子间（或分子内）相互作用**，不是化学键——它比共价键弱得多；②氢键的方向性：$\ce{X-H...Y}$ 三原子尽量共线（线性最稳定）；③「HF、$\ce{H2O}$、$\ce{NH3}$」是氢键的三大主角——教材说「氢键主要存在于 F、O、N」，其他原子（如 Cl、S）一般不形成强氢键；④分子内氢键（如邻羟基苯甲醛）影响熔沸点的方向与分子间氢键不同（分子内氢键降低熔沸点）。

## 3 公式解析：为什么水的沸点「反常」高

对比同族氢化物的沸点：$\ce{H2O}$（100°C）、$\ce{H2S}$（-60°C）、$\ce{H2Se}$（-41°C）、$\ce{H2Te}$（-2°C）：

- **第一步，找规律**：VIB 族氢化物，分子量增大（$\ce{H2S}<\ce{H2Se}<\ce{H2Te}$），色散力增大，沸点应单调上升——$\ce{H2S}$ 到 $\ce{H2Te}$ 确实如此。
- **第二步，看反常**：$\ce{H2O}$ 分子量最小，沸点却最高（100°C）——**范德华力无法解释**。
- **第三步，归因氢键**：水中 O 与 H 形成分子间氢键，额外引力使沸点飙升。氢键 > 范德华力 → 水沸点反常高。

**结论：凡 F、O、N 的氢化物，熔沸点都反常高于同族下一位**（$\ce{HF}$ > $\ce{HCl}$、$\ce{NH3}$ > $\ce{PH3}$）——这是「氢键效应」的标志性证据。<span class="marginnote">氨、氟化氢、水三者在同族氢化物中都是「高沸点反常者」。这类「同族递变中的突变」是识别氢键的试金石——做题时看到 $\ce{H2O}$ 比 $\ce{H2S}$ 沸点高，就要想到氢键。</span>

## 4 分子间作用力与物质性质的综合

**重点：影响熔沸点的「优先级」**。比较物质熔沸点，先看**晶体类型**（原子晶体 > 离子晶体 > 分子晶体，下一章），再看同类型内的作用力：

- 分子晶体（如卤素、烷烃）：比**范德华力**（分子量与极性）；
- 含 F、O、N 的分子：先看**氢键**（氢键压倒范德华力）。

**辨析｜易错点：** ①「分子量大沸点高」只适用于**同类型分子**（同为非极性或极性相近），若一个含氢键、一个不含，氢键优先；②汽化、熔化不破坏化学键，只破坏分子间作用力——「水蒸发是物理变化」正因如此；③对比溶解性时，「氢键 + 极性」要一起看：乙醇（有羟基、能成氢键）溶于水，而分子量更大的高级醇难溶——烷基的疏水作用逐渐压过羟基。

## 5 氢键与生命：从水到 DNA

氢键不只是「分子间的力」，它是生命化学的隐形支柱——水的反常性质、蛋白质的折叠、DNA 的双螺旋都依赖氢键。

**核心概念：氢键在生命分子中的角色**。

| 体系 | 氢键作用 |
| --- | --- |
| 水 | 分子间氢键 → 高沸点、冰浮水面、良好溶剂 |
| 蛋白质 | 肽键间氢键 → α 螺旋、β 折叠（二级结构） |
| DNA | 碱基间氢键 → 双螺旋（A-T 两对、G-C 三对） |
| 酶 | 与底物的氢键 → 分子识别、催化 |

**重点：DNA 碱基配对的氢键**。A 与 T 之间形成 2 个氢键、G 与 C 之间 3 个氢键——G-C 对更「结实」（氢键多），所以 G-C 含量高的 DNA 热稳定性更强（解链温度更高）。这个「氢键数 → 热稳定性」的对应是分子生物学的常识。

**公式解析：为什么冰能浮在水面上**

- **第一步，看结构**：冰中每个水分子以氢键连 4 个邻近分子，形成开放的四面体网络。
- **第二步，看体积**：氢键网络撑开空间，冰中分子间距大于液态水——体积更大。
- **第三步，看密度**：密度 = 质量/体积，冰体积大 → 密度小 → 浮在水面。

**结论：氢键 = 「弱键撑起生命结构」**。<span class="marginnote">氢键的「弱而多」是它的设计智慧：单根氢键弱（易断开），但大量氢键协同（如 DNA 双螺旋的数千根）足以稳定结构、又允许可逆解旋——「弱而可逆」正是生命需要动态稳定的原因。如果 DNA 用强共价键连接两条链，就无法复制解旋了。这个「弱键的力量」是生物大分子设计的核心思想。</span>

**辨析｜易错点：** ①氢键是「弱键」——它比共价键弱得多，但比普通范德华力强；②「氢键越多越稳定」适用于同类型结构（G-C 比 A-T 稳定）；③冰浮水是氢键的宏观结果——地球的湖泊结冰从水面开始，保护水下生物越冬。

**补充：氢键的「强度」与方向性**。氢键强度约 20-40 kJ/mol（介于范德华力 1-20 与共价键数百之间）；氢键有**方向性**（X-H···Y 三原子尽量共线，重叠最大最稳定）——这与范德华力（无方向）不同，使氢键能「定向」构筑结构（DNA 双螺旋、蛋白质折叠）。「比共价键弱、比范德华力强、有方向」是氢键的完整画像。

**补充：范德华力的「普遍性」与「叠加性」**。范德华力存在于所有分子间（色散力是普遍成分）——即使非极性分子（稀有气体、$\ce{H2}$）也靠它液化。它随分子量增大而增大（色散力与电子数相关）——「分子量越大、分子越『黏』」。理解范德华力的普遍性，就理解了「为什么几乎所有物质都有液态/固态」——分子间总有引力。

**补充：分子间作用力与「气体液化」**。气体液化的难易反映分子间作用力大小：易液化的气体（氯气、二氧化硫——分子量大/极性大）分子间引力强；难液化（氢气、氦气——分子量小）引力弱。「液化温度（沸点）是分子间作用力的『温度计』」——沸点越高、分子间引力越强。这个关系用于判断「气体能否轻易液化、如何分离」。

**补充：分子间作用力与「物质状态」的判断**。分子间作用力大小决定物质状态：引力强 → 高沸点（液态/固态）；引力弱 → 低沸点（气态）。「分子量小 + 非极性 + 无氢键」→ 气体（$\ce{O2}$、$\ce{N2}$、$\ce{CH4}$）；「大分子 + 极性 + 氢键」→ 液体/固体（水、乙醇、蔗糖）。「分子间作用力是物质状态的『幕后指挥』」——判断状态先看引力强弱。

**补充：分子间作用力与「溶解」的关系再梳理**。溶解是「溶质-溶质、溶剂-溶剂作用被溶质-溶剂作用替代」的过程：相似相溶的本质是「新作用 ≈ 原作用」（能量变化小）。「极性/氢键匹配 → 溶解容易」——乙醇（羟基与水氢键）溶于水、油脂（非极性）不溶于水。「溶解是分子间作用力的『重组』」——「相似相溶」的微观本质在此。

**补充：分子间作用力与「生命」的连接再深化**。生命依赖分子间作用力：DNA 双螺旋（氢键）、蛋白质折叠（氢键 + 疏水）、细胞膜（疏水组装）、酶与底物（弱作用识别）。「弱作用力是生命的『粘合剂』」——共价键搭骨架、弱作用做功能。「弱而多 → 稳定又可逆」——生命需要「可逆的结合」（结合与解离）。「分子间作用力是『生命化学』的隐形之手」。

**补充：分子间作用力与「物质状态」再确认**。判断物质状态（常温）看分子间作用力：作用力强 → 液/固态（水、乙醇、碘）；作用力弱 → 气态（$\ce{O2}$、$\ce{N2}$、$\ce{CH4}$）。「分子间作用力是物质三态的『幕后指挥』」——「引力强则聚、引力弱则散」。「判断状态先看作用力强弱」——「分子量 + 极性 + 氢键」综合判断。

## 7 小结

- **范德华力**：取向力 + 诱导力 + 色散力；比化学键弱，决定分子晶体熔沸点。
- 分子量越大、极性越强、接触面积越大 → 范德华力越大 → 熔沸点越高。
- **氢键**：$\ce{X-H...Y}$（X、Y 为 F、O、N），强度介于范德华力与化学键之间。
- 氢键致高沸点（水反常）、溶于水（乙醇）、冰浮水面、DNA/蛋白稳定。
- 比较熔沸点：先晶体类型、再氢键、后范德华力。
