## 为什么「会反应」不等于「会合成」

上一节学了逆合成分析的逻辑，本节把它落到实施：**路线怎么选、条件怎么定、怎么评价好坏**。合成的难点不只是「知道反应」，而是「在众多可能路线中选最优」——考虑步骤数、产率、原料、副反应、条件苛刻程度。这是有机化学从「知识」走向「设计」的最后一跃。<span class="marginnote">有机合成设计的评价标准：路线简短（步骤少）、产率高、原料易得廉价、条件温和安全、副反应少、原子经济性好。这些标准与工程中的「多目标优化」同构——没有唯一正确答案，只有权衡后的较优解。</span>

## 1 合成路线设计的基本原则

**核心概念：合成路线的评价标准**。

1. **步骤数**：步骤越少越好（每步都有损耗，步骤多总产率低）；
2. **产率**：每步产率高（主产物明确、副反应少）；
3. **原料**：易得、廉价、低毒；
4. **条件**：温和、安全、易操作；
5. **原子经济性**：副产物少（绿色化学理念）。

**重点：总产率 = 各步产率的乘积**。若三步各 90% 产率，总产率仅 72.9%——所以「少步骤」直接决定合成效率。设计路线先数步骤、估产率。<span class="marginnote">「总产率 = 每步产率连乘」是合成路线评价的数学基础：步骤越多、总产率越低（指数式衰减）。这也是为什么好的合成「一步能到就不绕两步」——例如能直接酯化就不先氧化再酯化（除非目标需要）。</span>

**辨析｜易错点：** ①路线评价是「多因素权衡」——步骤少但原料贵的路线未必优于步骤多但原料便宜的；②「主产物单一」很重要——选择性差的反应（产物混合物）会增加分离成本；③绿色化学视角：尽量选原子经济性高的反应（加成 > 取代 > 消除，副产物递减）。

## 2 典型合成路线示例

### 例一：由乙烯合成乙酸

- 乙烯 → 乙醇（加水）：$\ce{C2H4 + H2O ->[催化剂] C2H5OH}$；
- 乙醇 → 乙醛 → 乙酸（氧化）：$\ce{C2H5OH ->[O] CH3CHO ->[O] CH3COOH}$。

### 例二：由苯合成苯甲酸

- 苯 → 甲苯（烷基化，傅-克反应或卤代烃 + 苯）：$\ce{C6H6 + CH3Cl ->[AlCl3] C6H5CH3}$；
- 甲苯 → 苯甲酸（侧链氧化）：$\ce{C6H5CH3 ->[KMnO4(H+)] C6H5COOH}$。

### 例三：由卤代烃合成乙二醇

- 卤代烃消去成烯：$\ce{C2H5Br ->[NaOH/醇] C2H4}$；
- 乙烯与卤素加成：$\ce{C2H4 + Br2 -> CH2BrCH2Br}$；
- 二溴代物水解：$\ce{CH2BrCH2Br + 2NaOH ->[H2O] HOCH2CH2OH + 2NaBr}$。

**重点：合成路线的「官能团路线图」**。上述三例展示的核心模式：**碳骨架不变时，专注官能团逐步转化**；需要增碳或改变骨架时，用增链/成环反应。设计前先问：目标与原料的骨架相同吗？官能团差几步？<span class="marginnote">教材的合成案例常用「框图题」呈现：给出转化关系与试剂条件，让学生推断中间体结构。这类题的核心能力是「从产物反推中间体、从条件推断反应类型」——逆合成思维 + 官能团转化的综合运用。</span>

## 3 公式解析：路线设计中的条件选择

以「由 1-溴丙烷合成 1,2-二溴丙烷」为例，设计路线并选择条件：

- **第一步，认目标差别**：1-溴丙烷 $\ce{CH3CH2CH2Br}$ → 1,2-二溴丙烷 $\ce{CH3CHBrCH2Br}$——需要「在 2 号碳上再加一个溴」。
- **第二步，想反应**：直接卤代（$\ce{Br2}$/光照）会取代在 3 号或 1 号碳（选择性差、混合物）。更好的路线：先消去成烯（2 号碳产生双键），再加成溴。
- **第三步，写路线**：①$\ce{CH3CH2CH2Br ->[NaOH/醇][加热] CH3CH=CH2}$（消去）；②$\ce{CH3CH=CH2 + Br2 -> CH3CHBrCH2Br}$（加成）。

**结论：条件选择的目标是「高选择性」**——用加成（100% 定点）代替直接卤代（多位置混合物）。**「消去 + 加成」组合是把卤素「挪位」的经典策略**。<span class="marginnote">这个例子体现合成设计的核心智慧：有时「绕远路」反而更好——直接卤代看似一步，实则产物混乱；先消去再加成虽两步，却产物纯净。合成的艺术在于「用已知的高选择性反应，避免低选择性的捷径」。</span>

## 4 综合应用：设计一条完整路线

**目标：由乙烯合成乙酸乙酯**（设计并写全反应）。

- **第一步，拆目标**：乙酸乙酯 = 乙酸 + 乙醇（逆酯化）。
- **第二步，定原料路线**：乙烯 → 乙醇（加水）；乙醇 → 乙醛 → 乙酸（氧化）。
- **第三步，写完整路线**：
  1. $\ce{C2H4 + H2O ->[催化剂] C2H5OH}$（加成）；
  2. $\ce{2C2H5OH + O2 ->[Cu][加热] 2CH3CHO + 2H2O}$（氧化）；
  3. $\ce{2CH3CHO + O2 -> 2CH3COOH}$（氧化，或催化氧化）；
  4. $\ce{CH3COOH + C2H5OH <=>[浓H2SO4][加热] CH3COOC2H5 + H2O}$（酯化）。

**重点：路线书写的格式**——每一步写「反应物 → 条件 → 产物」，条件注明（试剂、催化剂、温度），产物核对官能团。完整路线的答案必须「步步清晰、条件齐全」。

**辨析｜易错点：** ①酯化需要乙醇与乙酸「两个中间体」都要由乙烯制得——别只做酸不做醇；②氧化步骤注意「乙醇先氧化成乙醛、乙醛再氧化成乙酸」，不能一步到位写错；③酯化是可逆反应，写「$\ce{<=>}$」且注明浓硫酸加热。<span class="marginnote">「由乙烯合成乙酸乙酯」是教材最经典的合成案例，串联加成、氧化、酯化三类反应。掌握它，就掌握了「从烯烃出发、经醇醛酸、到酯」的完整官能团转化链——这也是后续生物大分子（糖、脂肪）合成代谢的化学原型。</span>

## 5 有机合成的「绿色化」与原子经济

现代有机合成不仅看「能不能做成」，还看「是否绿色」——原子经济性、催化剂与溶剂选择成为路线评价的新维度。

**核心概念：原子经济性在合成中的体现**。

| 反应类型 | 副产物 | 原子利用率 |
| --- | --- | --- |
| 加成 | 无 | 100% |
| 取代 | 有（HX、水等） | <100% |
| 消除 | 有小分子 | <100% |

**重点：合成路线优先选「原子经济」反应**。加成（100%）、催化加氢、催化氧化等比「计量试剂氧化」更绿色——把「绿色化学十二原则」（必修二已学）落到合成路线设计。

**公式解析：比较两条合成路线的原子利用率**

制环氧乙烷：

- **路线一（氯醇法）**：$\ce{C2H4 + Cl2 + Ca(OH)2 -> C2H4O + CaCl2 + H2O}$——副产 $\ce{CaCl2}$、$\ce{H2O}$，原子利用率低；
- **路线二（银催化氧化）**：$\ce{2C2H4 + O2 ->[Ag][加热] 2C2H4O}$——无副产物、原子利用率 100%。

- **第一步，算利用率**：路线二全部原子进产物 → 100%；路线一大量原子浪费在 $\ce{CaCl2}$。
- **第二步，看副产物**：氯醇法产生含氯废液（污染）、银催化法干净。
- **第三步，选路线**：银催化法「原子经济 + 无污染」——绿色合成。

**结论：绿色合成 = 「原子经济 + 无污染 + 催化优先」**。<span class="marginnote">环氧乙烷的例子是「绿色合成」的教科书案例：同样产物、两条路线，一条产生废物、一条 100% 原子利用。现代化学工业的竞争力越来越依赖「绿色工艺」——不仅环保，还省原料、省处理成本。「绿色是效率的另一面」——这个观念推动着第六级《化学工程》的工艺革新与第九级《合成生物学》的生物催化路线。</span>

**辨析｜易错点：** ①原子利用率 ≠ 转化率——前者看「原子去向」、后者看「反应程度」；②「加成 > 取代 > 消除」的原子经济排序（副产物递减）；③绿色合成要考虑「全流程」——溶剂、催化剂、能耗都是评价维度，不只反应一步。

**补充：合成路线设计与「最优路径」思想**。合成路线的「步骤最少」与「总产率最高」在多数时候一致（每步产率 <100%，步骤少则总产率高），但也偶有例外——若某一步选择性差（副产物多），绕一步高选择性反应反而总产率更高。判断路线的优劣，要看「实际总产率 × 原料成本 × 操作难度」，而非单纯数步骤。这与导航软件选择路线的逻辑一致：距离短未必最快，要看路况。

## 6 小结

- 路线评价标准：步骤少、产率高、原料易得、条件温和、原子经济。
- **总产率 = 各步产率连乘**——少步骤是效率关键。
- 设计核心：骨架不变则专注官能团转化；需要增碳/改骨架用增链反应。
- 条件选择追求**高选择性**（加成 > 直接卤代）；「消去 + 加成」可挪位卤素。
- 完整路线书写：每一步「反应物 → 条件 → 产物」，条件齐全。
