## 为什么「静止的平衡」其实是「动态的平衡」

必修第二册我们学过：可逆反应达到平衡时正逆速率相等、浓度不变。进入《化学反应原理》，这个认识要深化两点：第一，平衡是**动态**的——反应并没有停止，正逆反应仍在进行，只是速度相抵；第二，平衡可以用**数据**描述——各物质浓度满足一个精确的关系式。本节立稳「化学平衡状态」的动态图景，下一节给出定量标尺（平衡常数）。<span class="marginnote">「动态平衡」是自然界的普遍图景：水在 0°C 时冰水共存，并非「静止」，而是结冰速率 = 融化速率。化学平衡、相平衡、以及第二级《热力学》中的平衡态，共享同一个「动态相抵」内核。</span>

## 1 可逆反应与化学平衡的建立

**核心概念：化学平衡状态**：在一定条件下的可逆反应中，当正反应速率与逆反应速率**相等**、反应混合物中各组分浓度**保持不变**时所处的状态。

平衡的建立是一个「自调整」过程：反应开始时，正反应速率大、逆反应速率为零；随反应进行，反应物浓度下降（正速率减小）、生成物浓度上升（逆速率增大）；当两者速率**相等**时，体系达到平衡——此后浓度不再改变，但正逆反应仍在等速进行。

**重点：平衡是「动态的」，不是「静止的」**。达到平衡 ≠ 反应停止。判断依据不是「反应停了」，而是「正速率 = 逆速率」。例如合成氨达到平衡时，$\ce{N2 + 3H2 -> 2NH3}$ 与 $\ce{2NH3 -> N2 + 3H2}$ 两个方向都在进行，只是速度相等。<span class="marginnote">如何证明平衡是动态的？用同位素示踪：向已达平衡的 $\ce{NH3 + H2O}$ 体系加入含氮-15 的氨，一段时间后发现氮-15 也出现在未标记方向——说明正逆反应都在持续进行。这个实验设计是「证明动态」的经典。</span>

## 2 平衡状态的标志

判断一个可逆反应是否达到平衡，常用标志分两类：

**本质标志（充要）**：$v_{\text{正}} = v_{\text{逆}}$，且指**同一种物质**的正逆反应速率相等（如 $v_{\text{生成 NH3}} = v_{\text{消耗 NH3}}$）。

**衍生标志（充分不必要）**：体系中某一**随反应变化的量**保持恒定。常用：

| 物理量 | 适用性 | 说明 |
| --- | --- | --- |
| 各组分浓度 | 恒成立 | 达平衡时浓度不变 |
| 各组分的百分含量 | 恒成立 | 质量分数、体积分数不变 |
| 总压强 | 仅当 $\Delta n(\text{气体}) \neq 0$ | 气体分子总数变化时才有判别意义 |
| 混合气体平均摩尔质量 | 仅当 $\Delta n(\text{气体}) \neq 0$ | 同总压强条件 |
| 恒温恒容下密度 | 一般不可用 | 密度 = 质量/体积，总质量守恒，恒容时恒不变 |

**辨析｜易错点：** ①**「变量不变」才是标志**——如果某量在反应过程中本来就不变（如恒容下的密度），它「不变」不能证明平衡；②用压强、平均摩尔质量作标志时，必须检查该反应**气体分子总数是否变化**：$\ce{N2 + 3H2 <=> 2NH3}$ 气体分子数减少（4→2），压强不变可作标志；而 $\ce{H2 + I2 <=> 2HI}$ 前后分子数相同（2→2），压强恒不变，**不能作标志**；③「浓度不变」不是「浓度相等」，平衡时各物质浓度可以是任意稳定值。

## 3 化学平衡的建立与图像

平衡建立过程可用「速率—时间」图与「浓度—时间」图表示：

- **速率—时间图**：从反应开始到平衡，$v_{\text{正}}$ 曲线下降、$v_{\text{逆}}$ 曲线上升，两线**相交处即平衡**（交点之后重合，$v_{\text{正}} = v_{\text{逆}}$）。
- **浓度—时间图**：各物质浓度先变化后趋于水平线，水平段即平衡段。

**重点：从图像读平衡状态**。做题时，看到「浓度—时间」曲线变平、或「速率—时间」两曲线重合，即可判断达到平衡。下一节改变条件后图像如何「突变—移动—再平衡」，是平衡移动专题（勒夏特列）的图像语言。

**公式解析：从正逆速率的角度判断平衡**

对 $\ce{2SO2 + O2 <=> 2SO3}$，给出：$v_{\text{正}}(SO2) = 0.4\ \mathrm{mol/(L\cdot min)}$，$v_{\text{逆}}(SO3) = 0.4\ \mathrm{mol/(L\cdot min)}$，问是否平衡？

- **第一步，统一物质**：速率比较必须针对同一物质。把 $v_{\text{逆}}(SO3)$ 换算成 $SO2$ 的消耗速率：由系数比 $SO3:SO2 = 2:2 = 1:1$，$v_{\text{逆}}(SO2 \text{ 消耗}) = v_{\text{逆}}(SO3) = 0.4$。
- **第二步，比较同物质正逆**：$v_{\text{正}}(SO2 \text{ 生成/消耗}) = 0.4$ 与 $v_{\text{逆}}(SO2 \text{ 消耗}) = 0.4$ 相等——对 $SO2$ 而言正逆速率相等。
- **第三步，下结论**：能判定达到平衡。**关键点：若不换算成同一物质直接比较（0.4 vs 0.4 碰巧相同），可能误判**——标准做法永远是「同物质的生成速率 = 消耗速率」。

**结论：判断平衡的「同一物质法」**——任选一种物质，看它的生成速率与消耗速率是否相等。<span class="marginnote">这个「换到同一把尺子再比较」的方法，与速率换算、以及第五级《分析化学》里「统一基准物」的思想一致：不同尺子不能直接比，必须先归一。</span>

## 4 平衡标志的图像判断

除了速率与浓度文字描述，平衡状态还能从「图像」上直接读出——图像分析是化学平衡的高频题型。

**核心概念：浓度—时间图**。各组分浓度随时间变化，达到平衡后曲线变平（不再变化）。图中：反应物曲线下降、生成物曲线上升，变平处即平衡点。

**核心概念：速率—时间图**。$v_{\text{正}}$ 与 $v_{\text{逆}}$ 随时间变化，两线**相交后重合**（$v_{\text{正}} = v_{\text{逆}}$）——交点即达平衡。若某时刻改变条件，速率突变、平衡移动（下一节详述）。

**公式解析：从图像判断「是否达到平衡」**

- **第一步，看浓度图**：曲线是否变平——变平说明各组分浓度不再改变（平衡）；仍在变化则未平衡。
- **第二步，看速率图**：$v_{\text{正}}$ 与 $v_{\text{逆}}$ 是否相等（两线重合）——相等即平衡。
- **第三步，看判据适用**：图像纵轴若是「总压强」「平均摩尔质量」，先判断该反应气体分子数是否变化——不变则该量恒为常数、不能作判据。

**结论：图像判断平衡 = 「变量变平或两速相等等于平衡」**。<span class="marginnote">图像题的陷阱常在「纵轴物理量是否随反应变化」：恒容下密度恒不变（总质量守恒）、气体分子数不变的反应压强恒不变——这些「天生不变」的量，曲线变平也不能证明平衡。判断「这个量该不该变」是图像题的关键——先问「这个量在反应过程中会变吗」。</span>

**辨析｜易错点：** ①浓度曲线变平 ≠ 达到「刚变平」的瞬间——需确认是长时间保持水平；②速率曲线「重合」指 $v_{\text{正}} = v_{\text{逆}}$（同物质），不同物质的速率比值要看系数；③图像只能辅助判断，最终依据还是「$v_{\text{正}} = v_{\text{逆}}$」与「变量不变」。

## 5 化学平衡中的「等效平衡」概念

「不同的起始状态能否达到同一平衡」是平衡进阶概念——等效平衡揭示了平衡的「到达方式」不唯一。

**核心概念：等效平衡**。若不同起始配比（但物质总量相当）能到达**相同的平衡状态**（各组分平衡浓度相同），称这些起始态互为等效。

**重点：恒温恒容下的等效条件**。对反应前后气体分子数变化的反应（$\ce{N2 + 3H2 <=> 2NH3}$），恒温恒容下「从正向开始」与「从逆向开始」（按计量相当的量）能达到**相同**平衡——只要「极限转化到同一侧」的物质总量相等。

**公式解析：判断等效起始**

- **第一步，定条件**：恒温恒容，$\ce{N2 + 3H2 <=> 2NH3}$。
- **第二步，换算**：起始①：1 mol $\ce{N2}$ + 3 mol $\ce{H2}$；起始②：2 mol $\ce{NH3}$（完全逆向转化 = 1 mol $\ce{N2}$ + 3 mol $\ce{H2}$）——按极限转化后总量相同。
- **第三步，判等效**：起始①与②到达**同一个平衡**——「殊途同归」。

**结论：等效平衡 = 「极限转化后物质总量相同」**。<span class="marginnote">等效平衡的「殊途同归」本质是「平衡状态由物质总量决定、与路径无关」——这与盖斯定律（焓变与路径无关）是同一哲学：状态函数的终点只取决于始态与终态。理解等效平衡，能解决「从逆向开始能否达到同一平衡」「恒温恒压下等效条件不同」等进阶题——它是平衡思想的深化。</span>

**辨析｜易错点：** ①恒温恒容与恒温恒压的等效条件不同（后者看「物质的量之比」而非「总量」）；②「等效」指「平衡状态相同」，不是「转化率相同」；③等效平衡的前提是「同一温度」——温度变则 $K$ 变、平衡不同。

**补充：平衡状态的「实验证明」**。如何证明平衡是动态的？用**同位素示踪**：向已达平衡的体系中加入含标记原子的物质，若标记原子「跑到另一边」，说明正逆反应仍在进行。例：$\ce{SO2}$ 与 $\ce{O2}$ 达平衡后加入含 $\ce{^{18}O}$ 的 $\ce{O2}$，很快发现 $\ce{SO2}$ 中也含 $\ce{^{18}O}$——证明正逆反应持续、平衡是动态。「标记原子追踪」是研究平衡动态性的实验利器。

**补充：平衡标志的「易错点」汇总**。①「浓度不变」≠「浓度相等」；②「速率相等」要同物质（不同物质速率比 = 系数比）；③压强/平均摩尔质量作标志要先看气体分子数是否变化；④「恒容下密度不变」一般不能作标志（总质量守恒）。「先判断量是否随反应变、再判断是否恒定」——「变量不变才是平衡」是核心判据。

**补充：化学平衡的「建立过程」再理解**。平衡的建立是「正逆速率追赶」的动态过程：从反应开始（正速大、逆速零）到平衡（正逆相等）。改变起始配比（纯反应物、纯生成物或混合），最终都到达「同一个平衡」（同一温度下 $K$ 相同）。「不同起点、同一终点」——平衡状态由「温度 + 物质总量」决定、与「到达路径」无关，这与盖斯定律（焓变与路径无关）是同一哲学。

**补充：平衡状态与「反应限度」的度量**。平衡时各物质「不再变化」说明反应到达「限度」——用转化率（$\alpha$）量化：$\alpha$ 越大、反应越彻底。但「限度」随条件变（温度、压强）——平衡是「条件依赖的最大程度」。「转化率 + 平衡常数」是描述限度的两把尺子：转化率看具体过程、平衡常数看温度本性。「限度不是固定值、而是条件的函数」。

**补充：化学平衡的「前提条件」**。化学平衡的前提：①可逆反应（正逆都进行）；②密闭体系（物质不逸散）；③温度不变（$K$ 不变）；④达到一定时间（正逆速率相等）。「平衡是『条件下的平衡』」——条件变则平衡动。「判断平衡先看前提是否满足」——非密闭体系（气体逸出）、非恒温，谈平衡要谨慎。「平衡是化学系统的重要范式」。

## 6 小结

- 化学平衡：$v_{\text{正}} = v_{\text{逆}}$，各组分浓度不变，是**动态平衡**。
- 本质标志：同一种物质的生成速率 = 消耗速率。
- 衍生标志：**随反应变化的量**不变；总压强、平均摩尔质量只在气体分子数改变时有效。
- 「浓度不变」≠「浓度相等」；密度（恒容）恒不变，不能作标志。
- 图像上：速率曲线相交、浓度曲线变平，即达平衡。
