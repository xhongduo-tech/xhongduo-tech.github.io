## 为什么硅能撑起信息时代

上一节的硅酸盐是硅的「化合态生活」，本节看硅的「高纯单质生活」。硅的特殊之处在于：它是**半导体**——导电性介于导体与绝缘体之间，且随温度、光照、掺杂而变化。这个「可调控」的性质，让硅成了集成电路、太阳能电池、光纤通信共同的地基。<span class="marginnote">「硅谷」之名即来自硅（silicon）。半导体物理将在第二级《电子科学与技术》与第三级《计算机组成原理》中展开——从硅原子到晶体管，再到逻辑门，正是「从原子到大模型」链条上的硬件侧。</span>

## 1 硅单质：半导体元素

**硅（silicon）**：元素符号 $\ce{Si}$，位于周期表第三周期 IVA 族，原子序数 $14$，最外层 $4$ 个电子。地壳中含量居第二，自然界以化合态存在（$\ce{SiO2}$ 与硅酸盐）。

**核心概念：硅的「类金属」本性**。$4$ 个价电子的结构使硅既不容易完全失去电子（不像金属），也不容易完全得到电子（不像典型非金属），因此表现为**半导体**：常温下导电性弱，但**掺入微量杂质（如磷、硼）或升高温度、受到光照，导电能力显著增强**。这个「掺杂可控导电」的特性，是所有电子器件的物理基础。

单质硅的制备——工业上用碳还原二氧化硅：

$$
\ce{SiO2 + 2C ->[高温] Si + 2CO ^}
$$

得到的是粗硅（纯度不高），进一步用 $\ce{HCl}$ 与氢气还原提纯，才得到高纯硅（纯度可达 $99.9999999\%$，即七个「9」以上），供芯片制造。

**辨析｜易错点：** 硅是**非金属**（元素分类），不是金属，但具有金属光泽；它不能导电到导体程度，是**半导体**。化学上硅的惰性：常温下与强酸不反应，只与氢氟酸、强碱反应。这与碳的活泼性完全不同——硅的化学性质更接近「温和的非金属」。

## 2 二氧化硅：网络共价晶体

**二氧化硅（$\ce{SiO2}$）**：天然存在为石英、水晶、砂石。与 $\ce{CO2}$ 的分子晶体不同，$\ce{SiO2}$ 是**共价晶体**：每个硅原子与 $4$ 个氧原子成键，每个氧原子连接 $2$ 个硅原子，硅氧四面体在空间无限延展成三维网状结构。<span class="marginnote">$\ce{SiO2}$ 与 $\ce{CO2}$ 同为第 IVA 族氧化物，性质却天差地别：$\ce{CO2}$ 常温是气体、$\ce{SiO2}$ 是熔点高达 1600°C 以上的坚硬固体。结构决定性质——分子晶体 vs 共价晶体的对比将在选择性必修2第三章系统化。</span>

二氧化硅的性质：
**不与水反应**（区别于 $\ce{CO2}$）。
**能与氢氟酸反应**（玻璃蚀刻的原理）：$\ce{SiO2 + 4HF -> SiF4 ^ + 2H2O}$。
**能与强碱反应**：$\ce{SiO2 + 2NaOH -> Na2SiO3 + H2O}$。因此**玻璃瓶不能长期盛装强碱溶液**（会腐蚀瓶壁）。
**能与某些盐在高温反应**：$\ce{SiO2 + Na2CO3 ->[高温] Na2SiO3 + CO2 ^}$（上一节玻璃制造的反应）。

**重点：二氧化硅的两大用途。** ①制**光导纤维**——利用二氧化硅对光的全反射传输光信号，是光纤通信的核心材料；②制**高纯硅**与光学玻璃。<span class="marginnote">注意辨析：光导纤维的主要成分是 $\ce{SiO2}$，而光电池的半导体材料是硅单质，硅芯片是硅单质——「$\ce{SiO2}$ 用光，单质硅用电」，这是常考的用途对应。</span>

**辨析｜易错点：** 玻璃的成分含 $\ce{SiO2}$，而氢氟酸能腐蚀玻璃，因此**氢氟酸不能盛放在玻璃容器中**，应盛在塑料瓶（如聚四氟乙烯）中。同理，实验室用塑料瓶装氢氟酸是常识性考点。

## 3 公式解析：二氧化硅「吃碱」与「怕酸」

二氧化硅是**酸性氧化物**，但不溶于水，其「酸性」通过碱性氧化物与碱体现：

$$
\ce{SiO2 + 2NaOH -> Na2SiO3 + H2O}
$$

- **第一步，识别身份**：$\ce{SiO2}$ 是酸性氧化物，能与碱反应生成盐与水。硅酸钠 $\ce{Na2SiO3}$ 水溶液即水玻璃。
- **第二步，推工业应用**：盛碱液的玻璃瓶长时间存放，瓶塞处 $\ce{NaOH}$ 与玻璃中的 $\ce{SiO2}$ 反应生成黏稠的 $\ce{Na2SiO3}$，可能导致**瓶塞与瓶口黏结**——所以**盛碱液必须用橡皮塞**。
- **第三步，对比推论**：既然是酸性氧化物，为什么不用水生成酸？因为 $\ce{H2SiO3}$ 难溶于水、$\ce{SiO2}$ 与水不反应，制备硅酸必须用**可溶性硅酸盐 + 强酸**：$\ce{Na2SiO3 + 2HCl -> H2SiO3 v + 2NaCl}$。

这条公式链条揭示了「物质结构决定性质、性质决定用途」的完整推理路径——它在全课程反复出现，是化学学科思想的核心。

## 4 新型无机非金属材料

传统硅酸盐材料（陶瓷、玻璃、水泥）之外，现代无机非金属材料向「高性能、多功能」发展，主要有四大家族：

| 材料类别 | 代表 | 关键性质与用途 |
| --- | --- | --- |
| 半导体材料 | 高纯硅、锗、砷化镓 | 集成电路、太阳能电池 |
| 光导纤维 | 高纯 $\ce{SiO2}$ | 光纤通信，信号损耗低 |
| 新型陶瓷 | 碳化硅、氮化硅、氧化铝陶瓷 | 耐高温、耐磨、高强度；发动机部件、切削工具 |
| 碳素材料 | 石墨烯、碳纳米管、碳纤维 | 强度高、导电导热；复合材料、储能 |

**核心概念：新型陶瓷的「新」在何处？** 与传统陶瓷相比，新型陶瓷从「天然黏土」转向「人工合成的高纯原料」（如 $\ce{Si3N4}$、$\ce{SiC}$），且性能从「日用、建筑」跃升为「结构 + 功能」——能承受极高温度与应力，还能具备导电、压电、透光等功能。例如**氮化硅陶瓷** $\ce{Si3N4}$ 是高性能发动机的理想材料。<span class="marginnote">石墨烯是碳的二维单原子层材料，2004 年由 Geim 与 Novoselov 制备并获得 2010 年诺贝尔物理学奖。从石墨到石墨烯是「维度工程」的范例，也是第六级《材料科学与工程》的重要前沿。</span>

## 5 半导体材料与芯片的化学基础

硅的半导体性质是信息时代的地基——从高纯硅到芯片，化学贯穿每一步。

**核心概念：芯片制造的关键化学**。

| 步骤 | 化学过程 | 要点 |
| --- | --- | --- |
| 提纯 | $\ce{SiO2 -> Si}$（粗硅）→ 西门子法提纯 | 纯度达 99.9999999%（7N） |
| 拉晶 | 高纯硅熔融拉单晶 | 单晶硅（晶圆） |
| 掺杂 | 掺入磷/硼 | 控制导电类型（n/p 型） |
| 刻蚀 | 含氟气体刻蚀 | 光刻电路图案 |

**重点：硅的「掺杂调控导电」**。纯硅导电弱，掺入少量磷（+5 价，多一个电子 → n 型）或硼（+3 价，缺一个电子 → p 型）——「掺杂浓度控制导电性能」是芯片设计的物理基础。

**公式解析：为什么「掺杂」能控制导电**

**第一步，看价电子**：硅四价（成键刚好），磷五价（多一个电子「自由」）——掺磷后多出的电子可导电。
**第二步，看硼**：硼三价（少一个电子）——形成「空穴」，邻近电子跳入空穴（空穴移动也导电）。
**第三步，看控制**：掺杂浓度越高、导电性越强——「按需调控」让硅成为半导体。

**结论：半导体 = 「硅 + 掺杂浓度控制」**。<span class="marginnote">半导体物理的化学根源是「价电子的多与少」：掺磷给电子（n 型）、掺硼造空穴（p 型）。n-p 结（n 型与 p 型交界）是晶体管、二极管的心脏——「从硅到芯片」是化学（提纯、掺杂）与物理（能带、结）的接力。理解「掺杂改性质」，就理解了半导体工业的一半。这条线延伸到第二级《电子科学与技术》与《计算机组成原理》。</span>

**辨析｜易错点：** ①「半导体」介于导体与绝缘体之间——不是「导电差」的导体；②掺杂量极小（ppm 级）但效果显著——「少量掺杂、大改性能」；③芯片的性能由「材料纯度 + 掺杂控制 + 工艺精度」共同决定——高纯硅是起点。

**补充：硅的「化学惰性」与用途的辩证**。硅常温下稳定（不活泼）——既让它在自然界以氧化物/硅酸盐存在，也使它成为「安全」的半导体材料（芯片在常温稳定工作）。但硅的「稳定」是相对的：高温下能与碳、氯气反应（制粗硅）；与强碱、氢氟酸反应。「稳定性是相对的、条件是关键的」——惰性元素在特定条件下同样活泼。

**补充：二氧化硅在「光通信」中的核心地位**。光导纤维（石英光纤）用高纯 $\ce{SiO2}$ 制成——光在纤芯与包层界面全反射传输。二氧化硅的「透明 + 低损耗 + 耐热」使它成为光纤首选材料。现代通信依赖光纤（互联网骨干）——「沙滩上的砂子撑起信息高速公路」。「$\ce{SiO2}$ 用光、硅单质用电」——同一元素的两种形态，支撑了信息时代的两个维度。

**补充：硅的「化学性质」再梳理**。硅的化学：常温稳定（不与 O₂、酸反应）、与强碱反应（$\ce{Si + 2NaOH + H2O -> Na2SiO3 + 2H2 ^}$）、与氢氟酸反应、高温与 Cl₂/C 反应。「硅的稳定 vs 特定条件下的反应」——「稳定性是相对的」。「硅既不像典型金属也不像典型非金属（半导体）」——「类金属的本性」。「理解硅的化学，就理解它的应用（半导体、材料）」。

**补充：二氧化硅的「结构」再确认**。二氧化硅是共价晶体：每个 Si 连 4 个 O、每个 O 连 2 个 Si，硅氧四面体三维网络。「SiO₂ 是『巨型共价分子』」——「无独立分子、整块晶体」。「Si:O = 1:2（配位数 4:2）」——「化学式的由来」。「二氧化硅的硬、高熔点、耐腐蚀源于共价网络」——「结构决定性质」。

**补充：硅与二氧化硅的「应用对应」再确认**。硅单质 → 半导体（芯片、太阳能电池）；二氧化硅 → 光纤（光通信）、石英玻璃、光学器件。「硅单质用电、二氧化硅用光」——「同一元素、两种形态、两种用途」。「芯片 vs 光纤」——「信息时代的两个支柱」。「理解硅与 SiO₂ 的应用，就理解硅在科技中的核心地位」。

## 7 小结

- 硅：IVA 族半导体元素，**掺杂可调导电性**，工业上用碳还原 $\ce{SiO2}$ 制粗硅再提纯。
- 二氧化硅：**共价晶体**，熔点高、硬度大；与 $\ce{CO2}$ 性质迥异。
- 二氧化硅**不与水反应**，但**与氢氟酸反应**、**与强碱反应**；玻璃瓶不可久盛碱液。
- 光导纤维用 $\ce{SiO2}$，半导体芯片用硅单质——用途对应是常考点。
- 新型无机非金属材料：半导体、光纤、新型陶瓷、碳素材料四大家族。
