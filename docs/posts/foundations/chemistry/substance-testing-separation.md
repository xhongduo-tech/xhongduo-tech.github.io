## 为什么「检验」讲究「特征 + 排干扰」

学过的物质性质（沉淀、气体、颜色）现在要反过来用：**检验**是利用特征反应确认物质存在；**分离提纯**是利用性质差异把目标物从混合物中取出。检验的关键是「特征现象 + 排除干扰」，分离的关键是「选对性质差异」。本节把常见的检验与分离方法系统化。<span class="marginnote">定性检验的逻辑：一个「特征现象」（特定沉淀、特定气体、特定颜色）对应一种物质的确认。但要小心干扰——比如检验 SO₄²⁻ 必须先用酸排除 CO₃²⁻。检验的可靠性来自「特征性 + 干扰排除」双重保证。</span>

## 1 常见离子的检验

**核心概念：常见离子的特征检验**。用特征反应确认离子存在：

| 离子 | 检验试剂 | 现象 |
| --- | --- | --- |
| $\ce{H+}$ | 石蕊/紫色石蕊试液 | 变红；pH < 7 |
| $\ce{OH-}$ | 酚酞/石蕊 | 酚酞变红、石蕊变蓝 |
| $\ce{Cl-}$ | $\ce{AgNO3}$ + 稀硝酸 | 白色沉淀 $\ce{AgCl}$（不溶于硝酸） |
| $\ce{SO4^{2-}}$ | $\ce{BaCl2}$ + 稀盐酸 | 白色沉淀 $\ce{BaSO4}$（不溶于盐酸） |
| $\ce{CO3^{2-}}$ | 稀盐酸 + 澄清石灰水 | 气体使石灰水变浑浊 |
| $\ce{NH4+}$ | $\ce{NaOH}$ + 加热 + 湿润红色石蕊 | 使湿润红色石蕊变蓝（氨气） |
| $\ce{Fe^{3+}}$ | $\ce{NaOH}$ 或 $\ce{KSCN}$ | 红褐色沉淀 / 溶液变血红 |
| $\ce{Fe^{2+}}$ | $\ce{NaOH}$ | 白色沉淀→灰绿→红褐（被氧化） |
| $\ce{Cu^{2+}}$ | $\ce{NaOH}$ | 蓝色沉淀 |

**重点：检验的两步法「特征试剂 + 确认条件」**。如 $\ce{SO4^{2-}}$：先加稀盐酸（排除 $\ce{CO3^{2-}}$、$\ce{SO3^{2-}}$ 干扰）、再加 $\ce{BaCl2}$（白色沉淀不溶于酸）；$\ce{Cl-}$：加硝酸银 + 稀硝酸（排除 $\ce{CO3^{2-}}$ 干扰）。<span class="marginnote">为什么检验 Cl⁻ 要加稀硝酸？因为 $\ce{Ag2CO3}$ 也是白色沉淀——加硝酸可把碳酸银溶解掉，只留不溶于酸的氯化银。同理硫酸根检验加盐酸排碳酸根。这些「排除干扰」的步骤，是检验题的核心考点。</span>

**辨析｜易错点：** ①检验 $\ce{Cl-}$ 与 $\ce{SO4^{2-}}$ 时，加酸排干扰要选对酸（$\ce{Cl-}$ 用硝酸、$\ce{SO4^{2-}}$ 用盐酸——不能用盐酸检验氯离子、不能用硫酸检验硫酸根，会引入干扰）；②$\ce{Fe^{2+}}$ 与 $\ce{Fe^{3+}}$ 的区分：加 $\ce{KSCN}$——$\ce{Fe^{3+}}$ 变血红、$\ce{Fe^{2+}}$ 不变（但 $\ce{Fe^{2+}}$ 中若含 $\ce{Fe^{3+}}$ 会干扰）；③氨气检验用**湿润的红色石蕊试纸**变蓝（碱性气体）。

## 2 常见气体的检验

**核心概念：气体的特征检验**。

| 气体 | 检验方法 | 现象 |
| --- | --- | --- |
| $\ce{O2}$ | 带火星的木条 | 复燃 |
| $\ce{H2}$ | 点燃 | 淡蓝色火焰、烧杯壁有水珠 |
| $\ce{CO2}$ | 通入澄清石灰水 | 变浑浊 |
| $\ce{NH3}$ | 湿润红色石蕊试纸 | 变蓝 |
| $\ce{Cl2}$ | 湿润淀粉碘化钾试纸 | 变蓝 |
| $\ce{SO2}$ | 品红溶液 | 褪色（加热复原） |
| $\ce{HCl}$ | 蘸浓氨水玻璃棒 | 白烟 |

**重点：气体检验的「先除杂再检验」**。多种气体混合时，先除去干扰气体再检验目标气体（如检验 CO₂ 前先除 SO₂——SO₂ 也使石灰水变浑浊）。<span class="marginnote">气体检验的组合题常考「先后顺序」：检验 CO₂ 与 SO₂ 的混合物，先用品红检验 SO₂、再用高锰酸钾除去 SO₂、最后用石灰水检验 CO₂——「检验 → 除杂 → 再检验」的流程设计是实验综合题的核心。</span>

**辨析｜易错点：** ①检验 $\ce{CO2}$ 用**澄清石灰水**变浑浊（碳酸钙）；②检验 $\ce{Cl2}$ 用湿润淀粉碘化钾试纸变蓝（氯气氧化 I⁻ 成碘、碘遇淀粉变蓝）；③检验 $\ce{SO2}$ 用**品红褪色且加热复原**——区别于氯水漂白（不可逆）。

## 3 分离与提纯的方法选择

**核心概念：分离与提纯的原则**。分离是把混合物各组分分开（都要）；提纯是除去杂质（只要目标物）。提纯的原则：**不增（不引入新杂质）、不减（不减少目标物）、易分（杂质易分离）、复原（目标物能恢复到原状态）**。

**常用方法回顾**（有机分离章节已学）：

| 方法 | 依据 | 适用 |
| --- | --- | --- |
| 过滤 | 溶解性 | 固液分离 |
| 蒸发结晶 | 溶解度随温度 | 溶解度变化小的 |
| 冷却结晶 | 溶解度随温度 | 溶解度变化大的 |
| 蒸馏 | 沸点差 | 互溶液体 |
| 分液 | 不互溶分层 | 油水等 |
| 萃取 | 溶解度分配 | 溶质在两种溶剂 |
| 洗气 | 气体性质差异 | 气体除杂 |

**重点：除杂试剂的「最后一步」**。除杂流程常有多步（必修二海水提盐的精制）：加过量试剂除掉杂质离子、再加试剂除掉过量的前一试剂、最后用盐酸调 pH——每一步的试剂选择要「不引入新的难以除去的杂质」。<span class="marginnote">除杂的「过量试剂链」：除 CO₃²⁻ 用过量 BaCl₂（除 SO₄²⁻）→ 过量 Na₂CO₃ 除 Ca²⁺ 和过量 Ba²⁺ → 最后加盐酸除过量 CO₃²⁻ 与 OH⁻。「每一步过量 + 下一步除掉它」是除杂设计的通用思路——像解线性方程一样逐级消元。</span>

**辨析｜易错点：** ①除杂不能「以坏换坏」——选试剂要避免引入难除的新杂质；②气体除杂「先除易除的、后除难除的」「干燥放在最后」（通过溶液会带出水汽）；③提纯与检验不同：检验「找证据」、提纯「除杂质」——试剂用量原则不同（检验少量、除杂过量）。

## 4 公式解析：粗盐提纯的除杂设计

粗盐（含 $\ce{Ca^{2+}}$、$\ce{Mg^{2+}}$、$\ce{SO4^{2-}}$）提纯为精制食盐：

- **第一步，除 $\ce{SO4^{2-}}$**：加过量 $\ce{BaCl2}$ → $\ce{BaSO4}$ 沉淀（滤掉）。
- **第二步，除 $\ce{Mg^{2+}}$ 与 $\ce{Ca^{2+}}$**：加过量 $\ce{NaOH}$（除 $\ce{Mg^{2+}}$）与过量 $\ce{Na2CO3}$（除 $\ce{Ca^{2+}}$ 和第一步过量的 $\ce{Ba^{2+}}$）——$\ce{Na2CO3}$ 必须在 $\ce{BaCl2}$ 之后加。
- **第三步，过滤除沉淀**：一次过滤除掉所有沉淀。
- **第四步，调 pH**：加适量盐酸，除去过量的 $\ce{OH-}$ 与 $\ce{CO3^{2-}}$。

**结论：除杂顺序的关键是「$\ce{Na2CO3}$ 必须在 $\ce{BaCl2}$ 之后」**（碳酸钠要除掉过量的钡离子）；盐酸最后加（只中和，不引入新杂质）。<span class="marginnote">粗盐提纯是「除杂顺序」的经典：Na₂CO₃ 在 BaCl₂ 之后、HCl 在最后——这两个「位置约束」是题目的核心。理解每一步「过量 + 被下一步除掉」的逻辑，就能推导顺序而不用死记。</span>

**辨析｜易错点：** ①$\ce{Na2CO3}$ 不能先于 $\ce{BaCl2}$（否则过量钡离子无法除）；②盐酸只能在过滤后加（若过滤前加，沉淀会重新溶解）；③「加适量盐酸」指调至中性（用 pH 试纸检验），不是任意量。

## 5 离子检验的综合应用与干扰排除

离子检验的高阶题目是「混合溶液中检验多种离子」——关键是「逐一检验 + 顺序设计 + 干扰排除」。

**核心概念：多离子检验的顺序设计**。检验 $\ce{SO4^{2-}}$、$\ce{Cl-}$、$\ce{CO3^{2-}}$ 的混合液：

| 顺序 | 试剂 | 检验 | 原理 |
| --- | --- | --- | --- |
| 先 | 稀硝酸 | $\ce{CO3^{2-}}$ | 放气（$\ce{CO2}$） |
| 再 | $\ce{Ba(NO3)2}$ | $\ce{SO4^{2-}}$ | 白沉淀（$\ce{BaSO4}$） |
| 后 | $\ce{AgNO3}$ | $\ce{Cl-}$ | 白沉淀（$\ce{AgCl}$） |

**重点：顺序设计的「铁律」**。①先检验「会干扰别人的离子」（$\ce{CO3^{2-}}$ 干扰 $\ce{SO4^{2-}}$、$\ce{Cl-}$ 的沉淀检验）；②检验 $\ce{SO4^{2-}}$ 用 $\ce{Ba(NO3)2}$（不能用 $\ce{BaCl2}$——引入 $\ce{Cl-}$ 干扰）；③检验 $\ce{Cl-}$ 放最后（任何沉淀都干扰）。

**公式解析：为什么 $\ce{SO4^{2-}}$ 检验不能加 $\ce{BaCl2}$**

- **第一步，写反应**：$\ce{Ba^{2+} + SO4^{2-} -> BaSO4 v}$——白沉淀。
- **第二步，看引入**：$\ce{BaCl2}$ 引入了 $\ce{Cl-}$——后续检验 $\ce{Cl-}$ 时会误判（以为原液含氯）。
- **第三步，选替代**：用 $\ce{Ba(NO3)2}$（硝酸钡）——沉淀钡离子、不引入 $\ce{Cl-}$。

**结论：检验试剂的选择要「不引入干扰离子」**。<span class="marginnote">「检验试剂自身不能带来被测离子」是离子检验的核心约束：测 $\ce{SO4^{2-}}$ 不能用 $\ce{BaCl2}$、测 $\ce{Cl-}$ 不能用盐酸。这类「自我污染」是检验题最常见的陷阱。延伸到定量分析：沉淀剂、滴定剂的选择同样要「纯净 + 不干扰」——「试剂纯度与专一性」是分析化学的第一原则。</span>

**辨析｜易错点：** ①「先放气、再沉淀、后检验」——碳酸根最先（气体跑掉不残留）；②除干扰要「彻底」——过量试剂也要被后续处理；③检验完一种离子要「分离或排除」它再检下一种——避免互相干扰。

## 6 小结

- 离子检验用**特征反应 + 排除干扰**（$\ce{Cl-}$、$\ce{SO4^{2-}}$ 先酸化、$\ce{NH4+}$ 加热）。
- 气体检验：带火星木条（$\ce{O2}$）、石灰水（$\ce{CO2}$）、品红（$\ce{SO2}$）、湿润石蕊（$\ce{NH3}$）。
- 分离提纯四原则：**不增、不减、易分、复原**；方法按性质差异选择。
- 除杂设计：每步过量 + 下一步除掉；$\ce{Na2CO3}$ 在 $\ce{BaCl2}$ 之后、盐酸最后。
- 检验与提纯试剂用量不同：检验少量、除杂过量。
