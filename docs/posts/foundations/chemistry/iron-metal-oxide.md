## 为什么从铁开始

人类文明的三个时代，有两个直接以金属命名：**青铜时代**、**铁器时代**。青铜太软、太贵，铜器也只能做礼器和装饰；是铁——便宜、坚硬、来源广泛——让农民有了铁犁、士兵有了铁剑，文明才真正大规模地「动」起来。今天地球上生产量最大的金属仍然是铁，一座跨海大桥、一列高铁、一颗火箭发动机，骨子里都是钢铁。

从化学教育的角度看，铁的意义在于它是**中学阶段第一次系统见到的变价金属**：铁单质（0 价）、亚铁离子（+2 价）、铁离子（+3 价），三种价态构成一张完整的「价态网络」。上一章《氧化还原反应》教的化合价分析，这一章要在一个真实的、常见又复杂的元素身上反复演练；第四章《物质结构》里原子结构与元素周期律的规律，也从铁身上开始具体化。<span class="marginnote">铁还在周期表的中心地带——第四周期、第Ⅷ族，是「过渡金属」的代表。过渡金属的共同特征是「价态多变、能催化、有颜色」，铁三样占全。选择必修一《化学反应原理》里催化剂的例子，就常拿铁（合成氨用铁触媒）开刀。</span>

## 1 铁单质：物理性质与化学性质

**物理性质**：铁是**银白色**的金属（铁粉因表面氧化而呈黑色），质软、有良好的导电导热性，能被磁铁吸引并**能被磁化**——这是铁区别于铜、铝的独特性质。

铁在化学反应里的「人设」是**活泼的还原剂**，但它和不同氧化剂反应，产物的价态不同。这是本节的灵魂，先记住结论：**铁与弱氧化剂反应生成 +2 价的亚铁，与强氧化剂反应生成 +3 价的铁**。逐条看：

**（1）与氧气反应。** 在纯氧中点燃，铁丝剧烈燃烧，火星四射，生成黑色的四氧化三铁：

$$\ce{3Fe + 2O2 ->[\text{点燃}] Fe3O4}$$

在潮湿空气中，铁会缓慢生锈，铁锈的主要成分是水合氧化铁 $\ce{Fe2O3 \cdot xH2O}$（红褐色）——注意生锈生成的是 +3 价，且需要水参与，不是简单的 $4\ce{Fe} + 3\ce{O2}$。

**（2）与氯气反应。** 氯气是强氧化剂，铁在氯气中燃烧生成**棕褐色**的氯化铁固体：

$$\ce{2Fe + 3Cl2 ->[\text{点燃}] 2FeCl3}$$

**（3）与硫反应。** 硫是较弱的氧化剂，铁粉与硫粉混合加热，生成黑色的硫化亚铁：

$$\ce{Fe + S ->[\Delta] FeS}$$

同样一块铁，与氯气反应显 +3 价，与硫反应显 +2 价——差别完全来自氧化剂的强弱。这个对照是本章最经典的辨析点。

**（4）与水蒸气反应。** 常温下铁与水不反应（铁在潮湿空气中生锈是氧气的作用），但在高温下，红热的铁能与水蒸气反应生成四氧化三铁和氢气：

$$\ce{3Fe + 4H2O(g) ->[\text{高温}] Fe3O4 + 4H2 ^}$$

这个反应在教材里用一套特别的装置演示（用湿棉花提供水蒸气，用肥皂液收集氢气），它是「铁 + 非氧气氧化剂」的典型例子。<span class="marginnote">注意水蒸气作氧化剂时，铁被氧化到 +3 和 +2 的混合态（$\ce{Fe3O4}$），而不是纯净的 $\ce{FeCl3}$ 式产物——$\ce{Fe3O4}$ 里同时躺着 +2 价和 +3 价的铁，这为后面理解「变价金属的混合价态化合物」埋下伏笔。</span>

**（5）与酸反应。** 铁与稀盐酸、稀硫酸反应，生成 +2 价的亚铁盐和氢气：

$$\ce{Fe + 2HCl -> FeCl2 + H2 ^}$$

但常温下，铁遇**浓硫酸、浓硝酸**会发生**钝化**——表面生成一层致密的氧化物薄膜，阻止反应继续进行，因此常温下可用铁罐车运输浓硫酸、浓硝酸。这是「强氧化性酸反而让活泼金属变『钝』」的反直觉现象。

**（6）与盐溶液反应。** 铁能把比它不活泼的金属从盐溶液中置换出来，如置换硫酸铜中的铜：

$$\ce{Fe + CuSO4 -> FeSO4 + Cu}$$

这一条在第三章金属材料、以及选择必修一的金属冶炼里反复使用。

## 2 铁的氧化物：三种价态，三张脸

铁有**三种**常见氧化物，恰好对应两种价态和一种混合价态，是「变价金属」最直观的标本：

| 氧化物 | $\ce{FeO}$（氧化亚铁） | $\ce{Fe2O3}$（氧化铁） | $\ce{Fe3O4}$（四氧化三铁） |
| --- | --- | --- | --- |
| 铁元素价态 | +2 | +3 | +2、+3 混合（可看作 $\ce{FeO \cdot Fe2O3}$） |
| 颜色与状态 | 黑色粉末 | 红棕色粉末 | 黑色晶体，有磁性 |
| 俗名 / 用途 | 不稳定，易被氧化 | 铁红，红色颜料、炼铁原料 | 磁铁矿，磁性材料 |
| 与稀盐酸反应 | $\ce{FeO + 2HCl -> FeCl2 + H2O}$ | $\ce{Fe2O3 + 6HCl -> 2FeCl3 + 3H2O}$ | $\ce{Fe3O4 + 8HCl -> 2FeCl3 + FeCl2 + 4H2O}$ |

**重点：三种氧化物与盐酸反应，产物价态各不相同。** $\ce{FeO}$ 给出 +2 价的 $\ce{FeCl2}$，$\ce{Fe2O3}$ 给出 +3 价的 $\ce{FeCl3}$，而 $\ce{Fe3O4}$ 同时给出 $\ce{FeCl3}$ 和 $\ce{FeCl2}$——因为 $\ce{Fe3O4}$ 本身就是 +2 与 +3 的「混血儿」，与酸反应时，两种价态分别原样进入溶液。<span class="marginnote">把 $\ce{Fe3O4}$ 拆成 $\ce{FeO \cdot Fe2O3}$ 是一种「想问题」的工具：凡是遇到混合价态化合物，都可以先拆成低价氧化物与高价氧化物，再分别分析——这在本节写方程式、在后面配平时都很省力。</span>

$\ce{Fe2O3}$ 还有一个著名的「生意」：与铝粉混合点燃，发生**铝热反应**，剧烈放热、生成熔融的铁，用来焊接钢轨。方程式是：

$$\ce{Fe2O3 + 2Al ->[\text{高温}] 2Fe + Al2O3}$$

这个反应里，铝把铁从 +3 价还原回 0 价——上一章学的「还原剂把金属从化合物里救出来」在这里得到最壮观的演示。

## 3 价态阶梯：一张铁的地图

把铁的三种价态排成一列，就得到化学里常说的「价态阶梯」：

$$\ce{Fe\ (0)\ \xleftrightarrow[+\ 2e^-]{-\ 2e^-}\ Fe^{2+}\ (+2)\ \xleftrightarrow[+\ e^-]{-\ e^-}\ Fe^{3+}\ (+3)}$$

这张图是理解铁全部化学性质的「地图」：**凡是能变成更高价态的方向，都意味着失电子、被氧化；凡是能变成更低价态的方向，都意味着得电子、被还原。** 铁三角（$\ce{Fe}$、$\ce{Fe^{2+}}$、$\ce{Fe^{3+}}$ 三者之间的转化）就是这张地图上的六条单向道路，下一节《铁盐与亚铁盐》会逐条走遍。

先记住两条「大路」的通行规则：

- **铁 → 亚铁**：用弱氧化剂，如稀盐酸、稀硫酸、硫、硫酸铜溶液（得到 +2 价）。
- **铁 → 铁**：用强氧化剂，如氯气、硝酸（得到 +3 价）。

而 $\ce{Fe3O4}$ 的出现说明，铁的氧化**可以停在中间态**——加热条件、氧化剂用量不同，产物价态就会不同。变价金属的「身份认同」，是本章反复强调的主线。

## 4 公式解析：同一块铁，为什么生成两种价态

这是全节最值得拆解的一个问题。把两个「铁 + 氧化剂」的反应放在一起对比：

$$\ce{Fe + 2HCl -> FeCl2 + H2 ^}\qquad \text{（稀盐酸，弱氧化剂）}$$

$$\ce{2Fe + 3Cl2 ->[\text{点燃}] 2FeCl3}\qquad \text{（氯气，强氧化剂）}$$

**第一步，标出铁元素的化合价变化。** 两个反应里铁都从 0 价出发：前一个升到 +2，后一个升到 +3。差别不在铁的「意愿」，而在氧化剂的能力。

**第二步，看氧化剂夺取电子的能力。** 稀盐酸的氧化性来自 $\ce{H+}$，它只能把铁氧化到 +2 就「没力气」了（$\ce{H+ -> H2}$ 只需要 2 个电子配对）；氯气分子 $\ce{Cl2}$ 是强氧化剂，能把铁一步氧化到最高价 +3。

**第三步，用电子守恒核对产物。** 每个铁原子从 0 到 +2 失去 2 个电子，生成 1 个 $\ce{H2}$ 需要 2 个 $\ce{H+}$ 各得 1 个电子，正好配平；从 0 到 +3 失去 3 个电子，需要氯原子得电子，配平系数 2 与 3 即由此而来。**氧化剂越强，越能「撬走」更多电子，铁就显越高价。**<span class="marginnote">这与上一章「化合价分析三步」完全接轨：标价 → 找升降 → 核对升降总数相等。铁与氯气的反应里，3 个氯分子得 6 个电子，2 个铁原子共失 6 个电子，升降守恒。配平的过程，本质就是「让得失电子数相等」的算术。</span>

再看一个「停在中间态」的例子——铁与水蒸气：

$$\ce{3Fe + 4H2O(g) ->[\text{高温}] Fe3O4 + 4H2 ^}$$

**第一步**：铁的价态从 0 变成 $\ce{Fe3O4}$ 中的混合价态。**第二步**：把 $\ce{Fe3O4}$ 拆成 $\ce{FeO \cdot Fe2O3}$，即 1 个铁 +2、2 个铁 +3。**第三步**：核对电子——3 个铁共失 $1 \times 2 + 2 \times 3 = 8$ 个电子；4 个水分子里的 8 个氢从 +1 降到 0，共得 8 个电子。得失相等，方程配平成立。这就是为什么铁的价态「一半 +2、一半 +3」也能稳定存在——只要电子账目平衡。

**辨析｜易错点：不能把「铁与酸的产物」一刀切。** 铁与稀盐酸、稀硫酸生成 +2 价的 $\ce{FeCl2}$、$\ce{FeSO4}$；但铁与**稀硝酸**（强氧化性酸）反应生成的是 +3 价的 $\ce{Fe(NO3)3}$，而且没有氢气放出（氮元素被还原成 NO）。「铁与酸反应生成亚铁和氢气」只对**非氧化性酸**成立，浓硫酸、硝酸、氯水这些强氧化剂一律把铁氧化到 +3。

## 5 小结

- **铁是过渡金属的代表**：银白色、可被磁化、化学性质活泼，是强还原剂。
- **价态由氧化剂强弱决定**：弱氧化剂（稀盐酸、硫、硫酸铜）把铁氧化到 **+2**；强氧化剂（氯气、硝酸）把铁氧化到 **+3**。
- **三种氧化物**：$\ce{FeO}$（黑色、+2）、$\ce{Fe2O3}$（红棕、+3，铁红）、$\ce{Fe3O4}$（黑色磁性，可看作 $\ce{FeO \cdot Fe2O3}$），与酸反应的产物价态各不相同。
- **铁与水蒸气**：$\ce{3Fe + 4H2O(g) ->[\text{高温}] Fe3O4 + 4H2}$，产物为混合价态。
- **钝化**：常温下铁遇浓硫酸、浓硝酸表面钝化，不继续反应。
- **价态阶梯**：$\ce{Fe \leftrightarrow Fe^{2+} \leftrightarrow Fe^{3+}}$，是理解铁全部化学的地图。

在下一节，我们把目光从「铁单质与氧化物」转向溶液里的铁：铁的**氢氧化物**如何制取，$\ce{Fe^{2+}}$ 与 $\ce{Fe^{3+}}$ 如何相互转化、如何检验——这就是**铁三角**的完整拼图。
