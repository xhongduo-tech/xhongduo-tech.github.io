## 为什么研究有机物「先分离、再分析」

自然界得到的有机物几乎都是混合物：植物提取液、石油馏分、反应产物。研究任何一个未知有机物，第一步都是**分离提纯**——拿到纯净物，才能谈定性定量。分离方法的选择依据是组分性质的差异：沸点、溶解度、密度、吸附性。本节掌握分离提纯的「工具箱」。<span class="marginnote">有机化学研究的完整流程：分离提纯 → 元素分析（实验式）→ 质谱（分子式）→ 红外/核磁（结构式）。分离是第一步，也是后续一切分析的前提——「不纯的样品，一切数据都不可信」。</span>

## 1 分离提纯的常用方法

**核心概念：分离提纯**。把混合物中目标物与杂质分开、获得纯净物的过程。选方法看「性质差异」：

| 方法 | 依据 | 适用 | 例 |
| --- | --- | --- | --- |
| 过滤 | 溶解性差异（固液分离） | 固体 + 液体 | 沉淀洗涤 |
| 结晶/重结晶 | 溶解度随温度变化 | 溶解度差异大的固体 | 提纯粗盐 |
| 蒸馏 | 沸点差异 | 沸点差异大的互溶液体 | 分离乙醇与水 |
| 分液 | 密度与互溶性差异 | 不相溶的液体分层 | 油水分离 |
| 萃取 | 溶解性差异（分配） | 溶质在两种溶剂间分配 | 碘的提取 |
| 升华 | 沸点差异（固→气） | 易升华固体 | 提纯碘 |

**重点：蒸馏与分液的区别**。蒸馏用于**互溶**液体的分离（靠沸点差）；分液用于**不互溶**液体（靠分层）。判断先看「能否分层」：分层则分液，混溶则蒸馏。<span class="marginnote">蒸馏的适用条件：沸点差较大（一般 ≥ 30°C）且热稳定。若沸点相近或形成共沸物（乙醇与水共沸），普通蒸馏分离不彻底——需加生石灰吸水或特殊精馏。共沸现象是蒸馏的「暗礁」。</span>

**辨析｜易错点：** ①萃取后还需蒸馏/蒸发才能得纯品——萃取只是「转移」不是「提纯到底」；②重结晶的关键：选择溶剂使杂质溶解度大（留在母液）或极小（先析出被过滤）；③升华要求物质**易升华且杂质不易升华**（碘中提纯）。

## 2 萃取与分液操作

**核心概念：萃取（extraction）**：利用溶质在**互不相溶的两种溶剂**中溶解度的差异，把溶质从一种溶剂转移到另一种溶剂的过程。**分液**：把分液漏斗中分层液体分离的操作。

**公式解析：萃取的选择**

用四氯化碳（$\ce{CCl4}$）从碘水中萃取碘：

**第一步，选萃取剂**：碘在 $\ce{CCl4}$ 中的溶解度远大于在水中（相似相溶——碘非极性、$\ce{CCl4}$ 非极性），且 $\ce{CCl4}$ 与水不互溶。
**第二步，振荡静置**：混合振荡后静置分层——水在上层（密度小）、$\ce{CCl4}$ 在下层（密度大），碘「跑」进 $\ce{CCl4}$ 层，下层显紫红色（碘的 $\ce{CCl4}$ 溶液）。
**第三步，分液**：打开分液漏斗活塞，先放出下层 $\ce{CCl4}$ 层，再倒出上层水层。

**结论：萃取剂三条件——溶质在其中溶解度大、与原溶剂不互溶、密度便于分层**。<span class="marginnote">分液时「下层液体从下口放出、上层液体从上口倒出」是操作要点——否则上层会被下层污染。萃取在化工（溶剂萃取）、环境（水中有机污染物提取）、制药（天然产物分离）中广泛使用，第六级《化学工程》的液-液萃取是重要单元操作。</span>

**辨析｜易错点：** ①萃取剂必须与原溶剂**不互溶**（否则混溶无法分层）；②密度大小决定上下层：$\ce{CCl4}$（1.59）比水重在下层，苯（0.88）比水轻在上层；③振荡时需放气（分液漏斗的排气），防止气压骤增。

## 3 蒸馏操作要点

**核心概念：蒸馏（distillation）**：利用互溶液体沸点差异，加热使低沸点组分先汽化、冷凝收集，从而分离提纯。

**装置与操作要点**：
蒸馏烧瓶 + 温度计（水银球在支管口处）+ 冷凝管（下进上出）+ 锥形瓶；
加**沸石**防暴沸；
冷凝水**下进上出**（逆流，冷却充分）；
温度计测的是**馏出蒸气温度**（水银球在支管口，不是液面）。

**重点：蒸馏的三个细节**——沸石防暴沸、冷凝水逆流、温度计位置。三者都是实验操作题常考。

**辨析｜易错点：** ①温度计水银球必须**在蒸馏烧瓶支管口处**，不能插入液面（测蒸气温度）；②冷凝水从**下端进、上端出**（保证冷凝管始终充满水）；③蒸馏是物理变化——分离的是混合物，不改变物质组成。

## 4 从天然产物提取有机物：案例

**青蒿素的提取**（屠呦呦团队）：用**乙醚低温萃取**青蒿——乙醚沸点低（34.6°C），低温提取避免高温破坏青蒿素的过氧桥结构。萃取 + 蒸馏回收乙醚，得到青蒿素结晶。<span class="marginnote">青蒿素提取的启示：方法选择要「匹配物质的性质」——青蒿素热不稳定，所以用低沸点溶剂低温萃取，而不是加热蒸馏。屠呦呦因此获 2015 年诺贝尔生理学或医学奖，是「分离提纯方法学」改变医学的范例。</span>

**辨析｜易错点：** ①「提取」是多步操作组合（萃取 + 蒸馏 + 重结晶等），不是单一方法；②对热不稳定的物质，优先选低温、低沸点溶剂；③结晶操作中「冷却结晶」vs「蒸发结晶」：溶解度随温度变化大的用冷却结晶，不随温度变化的用蒸发结晶。

## 5 分离提纯的原理：性质差异是依据

分离方法的本质是「利用组分性质差异」——把差异梳理成表，遇到新混合物就能选对方法。

**核心概念：分离方法与性质差异的对应**。

| 性质差异 | 分离方法 |
| --- | --- |
| 溶解性差异（固/液） | 过滤 |
| 溶解度随温度变化差异 | 结晶（重结晶） |
| 沸点差异 | 蒸馏 |
| 互溶性差异（不互溶分层） | 分液 |
| 在两种溶剂中分配差异 | 萃取 |
| 升华性差异 | 升华 |

**重点：选方法的「四步」**。①看混合物状态（固/液/气）；②找性质差异（哪个性质不同）；③选对应方法；④必要时组合（萃取 + 蒸馏 + 结晶）。

**公式解析：分离苯与水的混合物**

**第一步，看互溶性**：苯与水不互溶、分层（苯密度小在上层）。
**第二步，选方法**：分液——用分液漏斗静置分层。
**第三步，操作**：先放下层水、再倒出上层苯。

再分离乙醇与水的混合物：两者互溶、沸点差约 22°C → 蒸馏（加生石灰吸水可提高纯度）。

**结论：分离 = 「性质差异 → 方法」的匹配**。<span class="marginnote">「分离方法的核心是找到性质差异」——过滤找溶解性、蒸馏找沸点、分液找互溶性、萃取找分配系数。这个「差异 → 方法」的思维是分析化学与化工分离的共同基础（第六级《化学工程》的单元操作：蒸馏、萃取、结晶、吸附都是它的放大版）。面对陌生混合物的分离题，先问「它们的什么性质不同」。</span>

**辨析｜易错点：** ①「蒸馏」与「分液」的区分：互溶用蒸馏、不互溶用分液——先判断互溶性；②萃取后还要蒸馏/蒸发才能得纯品——萃取只是「转移」；③多种杂质要「分步除」——每次针对一个差异、逐个击破。

**补充：分离提纯与「纯度」概念**。「纯净物」在化学中指「组成均一」——但绝对的纯不存在，实验提纯追求「足够纯」（杂质不影响使用/分析）。检验纯度的方法：测固定熔点（晶体纯则熔点尖锐）、色谱（单一斑点）、光谱（无杂质峰）。「纯度标准随用途而变」——分析纯、化学纯、工业纯的规格不同。理解「纯度是相对概念」，就不纠结「绝对纯」。

**补充：分离方法选择的「综合判断」**。面对实际混合物的分离，往往「多法组合」而非单法搞定：粗盐提纯 = 溶解 + 过滤（除不溶物）+ 加试剂（除离子）+ 过滤 + 蒸发结晶；植物提取 = 萃取 + 蒸馏 + 重结晶。「先分离大类、再逐步细分」——分离是「递进式」的流程设计，类似「先粗后细」的筛选策略，与工业分离流程（第六级《化学工程》）同构。

**补充：分离提纯与「纯度检验」**。提纯后要检验纯度：测熔点（纯品熔点尖锐、杂质使熔点降低变宽）、色谱（单一斑点）、光谱（无杂质峰）。「检验纯度」是分离的「验收环节」——没有纯度检验，分离「做没做成」无法判断。「分离 + 检验」是完整流程——分离不是目的、得到「可用的纯品」才是。「实验的闭环思维：分离 → 检验 → 合格」。

**补充：分离提纯的「工业放大」**。实验室分离方法放大到工业就是「化工单元操作」：蒸馏 → 精馏塔、萃取 → 萃取塔、结晶 → 结晶器、过滤 → 过滤机。「实验室方法是工业单元操作的『原型』」——原理相同、规模不同。「从试管到精馏塔」——分离提纯是化学工程的基石。「掌握实验室分离，就理解了化工分离的『心法』」。

**补充：分离提纯与「纯度」的标准再确认**。化学品的纯度标准随用途定：试剂级（高纯，分析用）、化学纯（实验用）、工业级（生产用）。「纯度不是越高越好、而是够用就好」——「按用途选规格」。「检验纯度的方法：测熔点（纯品尖锐）、色谱（单峰）、光谱（无杂峰）」。「分离的目标是『达到所需纯度』」——「够用即合格」。

## 7 小结

- 分离提纯选方法看**性质差异**：沸点（蒸馏）、溶解度（结晶/萃取）、密度（分液）、升华性。
- 蒸馏分离互溶液体；分液分离不互溶液体——先判断是否分层。
- 萃取三条件：溶解度大、不互溶、易分层；四氯化碳萃碘（下层紫红）。
- 蒸馏操作要点：沸石防暴沸、冷凝水逆流、温度计在支管口。
- 提取流程 = 萃取 + 蒸馏 + 结晶组合；方法匹配物质稳定性。
