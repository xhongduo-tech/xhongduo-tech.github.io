## 为什么从钠开始

上一章我们建立了化学的两大坐标：**离子反应**与**氧化还原反应**。坐标有了，还需要一块「练手的金属」，把化合价升降、电子转移真正用起来。钠是最合适的选材——它是教科书里第一个被系统研究的活泼金属：最外层只有 1 个电子，反应起来「一根筋」，得失电子的路线清晰得几乎可以当作教学模型。

更重要的是，钠和它的化合物是高中化学的第一个「完整家族」：单质钠、氧化钠、过氧化钠、氢氧化钠、碳酸钠、碳酸氢钠……沿着这个家族往下走，你会看到同一个元素如何以不同的化合价、不同的离子形式出场，也会在下一节遇到著名的侯氏制碱法。而整个第二章的标题就叫《海水中的重要元素——钠和氯》：钠与氯，一个失电子、一个得电子，正好把氧化还原的原理演完一整场。这一课，从一块能被小刀切开的银白色金属说起。<span class="marginnote">钠位于元素周期表第三周期第ⅠA 族，是碱金属家族的老大。它的活泼性要到第四章《元素周期律》才被彻底解释：原子半径大、最外层电子少、原子核对最外层电子的引力弱，所以那个电子「一推就走」。</span>

## 1 切开一块钠：物理性质

钠在自然界里从不以单质形式存在，它只以化合态藏在氯化钠、硫酸钠、碳酸钠、硝酸钠等化合物里。海水中溶解着大量的 $\ce{NaCl}$——整个海洋就是一座取之不尽的钠库。<span class="marginnote">钠是地壳中含量第六的元素（约 2.7%），但因为它太活泼，自然界中没有单质钠存在。凡是活泼的金属，在自然界里都以化合态存在——这是一个普遍规律，铁、铝、钙皆然，直到《金属的冶炼》一节才被打破。</span>

实验室里见到的钠，通常是一小块存放在煤油中的银白色金属。切开一块新鲜的钠，会看到明亮的银白色光泽；但它在空气中放几秒就会变暗——那是表面迅速生成了氧化钠（$\ce{Na2O}$）。

钠的物理性质可以概括成四个「字」：

- **软**：质软，用小刀就能切开。
- **轻**：密度 0.97 g/cm³，比水（1.0）小，却比煤油（约 0.8）大。
- **低**：熔点 97.8 °C，不到 100 °C，一加热就熔。
- **良**：是电和热的良导体。

「软、轻、低、良」不是孤立事实，它们共同决定了一件要紧事——**钠必须保存在煤油中**。密度比煤油大，钠才能沉在煤油底部；煤油不含氧也不含水，把钠与空气和水彻底隔绝。反过来，若保存在水中，钠会直接与水反应；若暴露在空气中，它会被慢慢氧化。取出钠要用镊子、吸干表面的煤油、切下的剩余部分放回原瓶——这些操作细节，全部源于钠的「软、轻、低」三个物理性质。

## 2 常温与点燃：钠与氧气的两个产物

钠在空气中会慢慢变暗，这是常温下的缓慢氧化：

$$\ce{4Na + O2 -> 2Na2O}$$

生成的是**氧化钠（$\ce{Na2O}$）**，白色固体，钠为 +1 价，氧为 −2 价。这个反应进行得很慢，放热也不显著。

但一旦点燃，情况完全不同：

$$\ce{2Na + O2 ->[\text{点燃}] Na2O2}$$

生成的是**过氧化钠（$\ce{Na2O2}$）**，淡黄色固体，钠仍为 +1 价，而氧的化合价是 **−1 价**——比常见的 −2 高了一格。燃烧时火焰呈黄色，这正是钠元素焰色试验的特征颜色。

**辨析｜易错点：钠在氧气中燃烧的产物是 $\ce{Na2O2}$，不是 $\ce{Na2O}$。** 常温氧化得 $\ce{Na2O}$，点燃得 $\ce{Na2O2}$——同一个金属，温度不同，产物不同；金属的化合价没变，氧的化合价却从 −2 变成了 −1。这就是「条件决定产物」的第一次正式出场：同一个反应体系，改变条件，产物就可能换一个。<span class="marginnote">$\ce{Na2O2}$ 里那两个氧原子之间还连着一根过氧键 $\ce{-O-O-}$，所以它不是普通的碱性氧化物，而属于过氧化物。这根键的奇妙之处，下一节「供氧剂」里会详细展开。</span>

## 3 钠与水：浮、熔、游、响、红

钠与水反应，是整个高中化学最经典、也最好看的实验。把一小块钠投入滴有酚酞的水中，你会依次看到五个现象——教材用五个字概括：**浮、熔、游、响、红**。

$$\ce{2Na + 2H2O -> 2NaOH + H2 ^}$$

- **浮**：钠浮在水面上——密度比水小。
- **熔**：钠熔成闪亮的小球——反应放热，而钠熔点低，放出的热足以让它熔化。
- **游**：小球在水面上四处游动——生成的氢气推动小球运动。
- **响**：发出「嘶嘶」的响声——氢气逸出时带出的声响。
- **红**：溶液变红——生成了 $\ce{NaOH}$，酚酞遇碱变红。

这五个字不是用来背的，而是「性质决定现象」的完美注释：**每一个现象，都能追到钠的一个物理性质或化学性质。** 浮追到密度，熔追到熔点与放热，游与响追到有气体生成，红追到有碱生成。见到一组实验现象、反推出背后的性质，这是化学实验题的基本功。

钠与水的反应之所以剧烈，本质上是在和**水电离出的 $\ce{H+}$** 反应。水是很弱的电解质，溶液中 $\ce{H+}$ 浓度极低，可钠的还原性实在太强，把哪怕一点点 $\ce{H+}$ 也「抢」过来生成氢气。<span class="marginnote">水里几乎没有游离的 $\ce{H+}$，可钠照样能把氢气逼出来——因为 $\ce{H2O}$ 分子里的氢处于 +1 价，钠把电子交给它，它就变成 0 价的氢气。反应的本质是钠与「+1 价氢」之间的电子转移，与上一章氧化还原的化合价判据完全对应。</span>

## 4 钠与盐溶液：先「抢水」，再「抢盐」

如果把钠投入硫酸铜溶液，会得到什么？很多人的第一反应是置换出铜：钠比铜活泼，应该把铜从盐里赶出来。**这个直觉是错的。**

钠实在太活泼了。它一进水，首先遇到的是大量的水，于是先与水反应：

$$\ce{2Na + 2H2O -> 2NaOH + H2 ^}$$

生成的 $\ce{NaOH}$ 再与 $\ce{CuSO4}$ 反应：

$$\ce{2NaOH + CuSO4 -> Cu(OH)2 v + Na2SO4}$$

两步相加，总现象是：**有气泡、有蓝色絮状沉淀，但没有红色的铜。** 蓝色沉淀是 $\ce{Cu(OH)2}$，气泡是 $\ce{H2}$。

**辨析｜易错点：活泼金属钠投入盐溶液，不会置换出金属单质。** 钠先与溶液中的水反应生成碱和氢气，碱再与盐反应生成氢氧化物沉淀。要置换出盐中的金属，得用不如钠活泼、又比被置换金属活泼的金属（如铁置换铜）。钠的活泼性「过头」了，它的还原能力先被水消耗殆尽。<span class="marginnote">金属活动性顺序表里，钠的位置太靠前，「见水就反应」是它的宿命。这也再次解释了为什么自然界没有单质钠——它太想失去那最后一个电子了。</span>

同理，钠与酸反应比与水更剧烈——酸中 $\ce{H+}$ 浓度高得多，反应一发不可收拾，甚至可能燃烧；钠与乙醇反应则缓和得多（$\ce{2C2H5OH + 2Na -> 2C2H5ONa + H2 ^}$），因为乙醇中羟基氢的活泼性弱于水中的氢。

## 5 公式解析：钠与水反应的电子转移

把钠与水反应的电子转移拆开看，这是氧化还原知识第一次在具体物质上完整走一遍：

$$\ce{2Na + 2H2O -> 2NaOH + H2 ^}$$

- **第一步，标化合价**：反应前，钠 0 价，水中氢 +1 价；反应后，钠 +1 价，氢气中氢 0 价。
- **第二步，找升降**：钠从 0 升到 +1，每个钠原子**失 1 个电子**，2 个钠共失 2 个电子；氢从 +1 降到 0，每生成 1 个 $\ce{H2}$ 分子（含 2 个氢原子）共**得 2 个电子**。
- **第三步，核对守恒**：失 2、得 2，得失电子总数相等——这就是上一节说的**电子守恒**。钠是**还原剂**，被氧化；水是**氧化剂**，被还原。
- **第四步，看量关系**：每 2 mol 钠反应，消耗 2 mol 水，生成 2 mol $\ce{NaOH}$ 和 1 mol $\ce{H2}$。折算下来，**1 mol 钠（23 g）与水反应，生成 0.5 mol 氢气，标准状况下体积为 11.2 L，转移 1 mol 电子。**

这条量关系是本章第三节《物质的量》的预告：化学方程式的系数比，就是物质的量的比。

## 6 保存、制备与用途

**保存**：钠存放于煤油中，密封、隔绝空气与水。取用时用镊子，切剩的钠放回原瓶，绝不可丢入下水道或水池。

**制备**：钠如此活泼，自然界没有单质，那实验室和工业上的钠从哪来？答案是电解。工业上电解熔融的氯化钠：

$$\ce{2NaCl ->[\text{电解}] 2Na + Cl2 ^}$$

熔融的 $\ce{NaCl}$ 在电流作用下被拆开，阴极析出钠，阳极放出氯气——钠和氯，这一章标题里的两个主角，在同一台电解槽里同时诞生。<span class="marginnote">这正是 1807 年戴维首次分离出金属钠的思路，只是他电解的是熔融的苛性钠（$\ce{NaOH}$）。戴维用「电」这把新工具拆开了当时被认为不可再分的碱，也开启了电化学的新纪元。电解的微观细节，选择性必修 1 第四章《电解原理》会专门研究。</span>

**用途**：

- 钠钾合金（室温下呈液态）作核反应堆的导热剂——液态金属导热性能好，又不需加压。
- 高压钠灯——钠的黄色光穿透力强、透雾性好，常用于道路照明。
- 作还原剂冶炼钛、锆、铌等难熔金属，如 $\ce{TiCl4 + 4Na ->[\text{高温}] Ti + 4NaCl}$。
- 制备 $\ce{Na2O2}$ 等钠的化合物。

## 7 小结

- **物理性质**：银白、质软、密度比水小（0.97 g/cm³）、熔点低（97.8 °C），须保存在**煤油**中。
- **与氧气**：常温得 $\ce{Na2O}$（白），点燃得 $\ce{Na2O2}$（淡黄）——**条件决定产物**。
- **与水**：$\ce{2Na + 2H2O -> 2NaOH + H2 ^}$，现象「浮、熔、游、响、红」；钠为还原剂，水为氧化剂。
- **与盐溶液**：先与水反应生成碱和氢气，碱再与盐反应——**不能置换出金属**。
- **电子转移**：钠 0 → +1 失电子，水中氢 +1 → 0 得电子，得失电子守恒；1 mol 钠生成 0.5 mol 氢气、转移 1 mol 电子。
- **制备与用途**：电解熔融 $\ce{NaCl}$ 制钠；钠钾合金作导热剂、高压钠灯、作还原剂冶炼金属。
