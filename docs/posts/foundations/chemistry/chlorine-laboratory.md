## 为什么从「实验室制法」开始

上一课认识了氯气极强的氧化性、毒性和漂白性。一个「既好用又有毒」的气体，怎么在实验室里安全地拿到手？这就是本课前半段的任务：**实验室制法**。它不只是背一套装置图，而是「原理 → 装置 → 除杂 → 收集 → 尾气」一整条流水线思维——气体从哪儿来、混了什么杂质、怎么分离、怎么接住、怎么不让它跑进空气。这条流水线一旦学会，后面制取氨气、二氧化硫、氢气时都是同一套框架。

后半段是一条著名的离子检验：**氯离子的检验**。它是「离子检验」的第一课——检验一个离子，不是只看一个现象，而是先想清楚「还有谁会干扰这个现象」。这套「排除干扰」的思路，比那条离子方程式本身更重要。学完本课，第二章「钠和氯」的知识就齐了，我们会第一次把「元素化学」的完整套路走完。

## 1 反应原理：浓盐酸 + 二氧化锰

实验室制取氯气，经典原理是**浓盐酸**与**二氧化锰**共热：

$$\ce{MnO2 + 4HCl(浓) ->[\Delta] MnCl2 + Cl2 ^ + 2H2O}$$

写成离子方程式更见本质：

$$\ce{MnO2 + 4H+ + 2Cl- ->[\Delta] Mn^{2+} + Cl2 ^ + 2H2O}$$

**辨析｜易错点：必须用浓盐酸，且必须加热。** 用稀盐酸与 $\ce{MnO2}$ 反应，几乎得不到氯气。原因有二：一是 $\ce{MnO2}$ 的氧化性不算强，需要浓盐酸中高浓度的 $\ce{Cl-}$ 提供足够的还原能力；二是这个反应的活化能较高，不加热反应极慢。**「浓盐酸 + 加热」两个条件缺一不可**——这也呼应了上一课「条件决定反应」的主旋律。<span class="marginnote">历史钩子：1774 年，瑞典化学家舍勒正是用二氧化锰与浓盐酸加热第一次制得了这种黄绿色气体。他当时以为它是一种「去燃素的盐酸」（含氧的化合物），直到 1810 年戴维才确认它是单质氯。我们今天实验室里用的方法，与两百多年前的发现几乎一模一样。</span>

**替代方案**：若不想加热，可用氧化性更强的**高锰酸钾**与浓盐酸在常温下反应：

$$\ce{2KMnO4 + 16HCl(浓) -> 2KCl + 2MnCl2 + 5Cl2 ^ + 8H2O}$$

$\ce{KMnO4}$ 氧化性比 $\ce{MnO2}$ 强，所以常温就能把浓盐酸中的 $\ce{Cl-}$ 氧化成氯气。

**为什么选「固液加热」这套组合？** $\ce{MnO2}$ 是不溶于水的固体粉末，直接放在烧瓶底部；浓盐酸装在分液漏斗里，通过活塞逐滴加入，从而控制反应速率。分液漏斗在这里承担了「加液阀门」的作用——若一次性把盐酸全倒进去，反应会瞬间剧烈、气流失控。用分液漏斗逐滴滴加，是「控速」的实验智慧，与滴定管、恒压漏斗一脉相承。

## 2 装置与流程：从烧瓶到尾气

整套装置遵循「发生 → 除杂 → 干燥 → 收集 → 尾气」五步，示意图如下。

![实验室制取氯气的装置](/images/chemistry/chlorine-laboratory-1.svg)

**① 发生装置**：圆底烧瓶中加入 $\ce{MnO2}$，分液漏斗中加入浓盐酸（可通过活塞控制滴加速度），酒精灯加热。这是典型的「固 + 液 → 加热」型气体发生装置。

**② 除杂装置**：通过盛有**饱和食盐水**的洗气瓶，除去氯气中混有的 $\ce{HCl}$ 气体。<span class="marginnote">为什么用饱和食盐水而不是水？因为氯气能溶于水（1 体积水溶约 2 体积氯气），用普通水会把氯气也吸收掉一部分；而饱和食盐水中大量存在的 $\ce{Cl-}$ 会抑制反应 $\ce{Cl2 + H2O <=> HCl + HClO}$ 向右进行，使氯气在其中的溶解度大大降低。$\ce{HCl}$ 却极易溶于水，于是被「洗」掉——这就是「同离子效应」在洗气里的应用，原理到选择性必修 1《化学平衡》会严格解释。</span>

**③ 干燥装置**：通过盛有**浓硫酸**的洗气瓶，除去水蒸气。

**辨析｜易错点：除 $\ce{HCl}$ 用饱和食盐水，不能用 $\ce{NaOH}$ 溶液。** $\ce{NaOH}$ 确实能把 $\ce{HCl}$ 吸收干净，但它是「通吃」的——氯气与 $\ce{NaOH}$ 反应（$\ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}$）也会被吸收。除杂必须「只除目标杂质、不伤主产物」，这正是选择除杂剂的第一原则。干燥同样不能用碱石灰、$\ce{NaOH}$ 固体等碱性干燥剂，因为它们会与氯气反应。

**④ 收集装置**：用**向上排空气法**收集（氯气密度比空气大），导管**长进短出**——长导管伸到集气瓶底部，氯气自下而上充满瓶，空气从短导管被排出；也可以用**排饱和食盐水法**收集。

「长进短出」是有讲究的：氯气密度比空气大，先沉到集气瓶底部，自下而上把空气从瓶口的短导管赶出去；若接反成「短进长出」，氯气会贴着瓶口直接溢散，收集效率极低。排饱和食盐水法的道理相同——氯气在饱和食盐水中溶解得少，气体把食盐水排出瓶外即可集满，只是集气瓶要倒扣在盛有饱和食盐水的槽中。

**⑤ 尾气处理**：氯气有毒，不能直接排入空气。在通风处，用导管把尾气通入盛有 $\ce{NaOH}$ 溶液的烧杯中吸收：$\ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}$。

## 3 公式解析：浓盐酸里谁被氧化

制氯反应里藏着一个非常经典的定量陷阱，把它拆开：

$$\ce{MnO2 + 4HCl(浓) ->[\Delta] MnCl2 + Cl2 ^ + 2H2O}$$

- **第一步，标化合价**：反应前，锰 +4 价、氯 −1 价；反应后，锰 +2 价（$\ce{MnCl2}$），氯 0 价（$\ce{Cl2}$）和 −1 价（$\ce{MnCl2}$）。
- **第二步，找升降**：锰从 +4 降到 +2，每个锰**得 2 个电子**；部分氯从 −1 升到 0，每生成 1 个 $\ce{Cl2}$（含 2 个氯原子）**失 2 个电子**。
- **第三步，核对守恒**：1 mol $\ce{MnO2}$ 得 2 mol 电子，恰好把 2 mol $\ce{Cl-}$（生成 1 mol $\ce{Cl2}$）氧化掉。电子守恒成立。
- **第四步，看量关系——陷阱在这里**：方程式中 4 mol $\ce{HCl}$ 参加反应，但**只有 2 mol 被氧化**（变成 $\ce{Cl2}$），另外 2 mol 的氯原子进入了 $\ce{MnCl2}$，化合价没有变化，**没有被氧化**。也就是说，**被氧化的 $\ce{HCl}$ 只占总量的 1/2**。计算时：87 g $\ce{MnO2}$（1 mol）与足量浓盐酸反应，生成 1 mol $\ce{Cl2}$（标准状况下 22.4 L），转移 2 mol 电子，被氧化的 $\ce{HCl}$ 为 2 mol（73 g）。

**辨析｜易错点：「参加反应」不等于「被氧化」。** 化学方程式里的 $\ce{HCl}$ 系数是「消耗量」，其中一部分只起到提供 $\ce{Cl-}$ 组成 $\ce{MnCl2}$、提供 $\ce{H+}$ 组成水的作用，电子得失只发生在另一部分氯原子上。做题时先分清「消耗」与「被氧化」，就不会掉进这个 1/2 的陷阱。

从配平的角度再核对一遍：左边锰 1、氧 2、氢 4、氯 4；右边 $\ce{MnCl2}$ 中氯 2、$\ce{Cl2}$ 中氯 2、水中氢 2、氧 1——两边每种原子的数目都相等，配平无误。制气反应与普通反应一样，第一步永远是「配平并读懂系数比」，这正是本章第三节《物质的量》里气体定量计算的前提。

## 4 验满、收集与停止操作的顺序

**验满**：氯气在瓶口充满时，把**湿润的淀粉-碘化钾试纸**放在瓶口，若试纸**变蓝**，说明已集满。原理是氯气与 $\ce{KI}$ 反应置换出碘：$\ce{Cl2 + 2KI -> 2KCl + I2}$，碘遇淀粉变蓝。<span class="marginnote">验满试纸必须「湿润」：干燥的淀粉碘化钾试纸遇氯气不反应——氯气要先溶于试纸上的水（生成 $\ce{HClO}$ 等）才能氧化 $\ce{I-}$。这与上一课「干燥氯气不漂白」是同一个道理：氯气的很多反应都需要水的参与。</span>也可以用眼睛看：瓶口出现黄绿色气体即满。

**停止操作的顺序**：实验结束时，**先撤导管，再撤酒精灯**。若顺序颠倒，先停火，烧瓶内温度下降、气体收缩，液体会顺着导管倒吸进烧瓶，导致炸裂。这个「先撤导管后撤灯」的顺序，是所有制气实验的通用防倒吸纪律。

**防倒吸装置**：即使遵守「先撤导管」的顺序，氯气溶于 $\ce{NaOH}$ 溶液时仍可能因溶解过快造成压强骤降而倒吸。稳妥的做法是在导管末端接一个**倒扣的漏斗**，漏斗口刚好没入液面：气体从小口进入、从漏斗边缘逸出；一旦发生倒吸，液面下降、漏斗口脱离液面，倒吸随即中断。这个「倒扣漏斗」是防倒吸的标准件，以后制取氨气、氯化氢时还会反复见到。此外，整套装置应在通风橱中操作，分液漏斗要缓慢滴加盐酸，保证气流平稳、氯气被充分吸收。

**发生装置要点**：先检查装置气密性，再装药品；分液漏斗的活塞控制盐酸滴加速度，让气流平稳，避免反应过快、气体来不及收集。

## 5 氯离子的检验

氯离子的检验是「离子检验」的标准范式。

**操作**：取少量待测液于试管中，先滴加**稀硝酸**酸化，再滴加**硝酸银溶液**。若产生**白色沉淀**，且该沉淀**不溶于稀硝酸**，则证明原溶液中含有 $\ce{Cl-}$：

$$\ce{Ag+ + Cl- -> AgCl v}$$

**为什么先加稀硝酸酸化？** 这是本检验的「灵魂」。如果不酸化，溶液中若存在 $\ce{CO3^2-}$、$\ce{SO3^2-}$ 等，它们与 $\ce{Ag+}$ 也会生成白色沉淀（$\ce{Ag2CO3}$、$\ce{Ag2SO3}$），造成误判。但**碳酸银、亚硫酸银都溶于稀硝酸**（溶解时还会产生气泡），而**氯化银不溶于稀硝酸**。所以先加稀硝酸，把干扰离子生成的沉淀「消掉」，剩下的不溶白色沉淀才确定是 $\ce{AgCl}$。

**辨析｜易错点：酸化必须用稀硝酸，不能用盐酸或硫酸。** 用盐酸酸化会引入 $\ce{Cl-}$，等于自己给自己加干扰，必然产生白色沉淀、无法检验；用硫酸酸化会引入 $\ce{SO4^2-}$，而 $\ce{Ag2SO4}$ 微溶，也可能出现浑浊。**稀硝酸既不引入干扰离子，又能排除碳酸根、亚硫酸根的干扰，是唯一正确的选择。**

**检验的完整流程与推广**：以检验某未知溶液是否含 $\ce{Cl-}$ 为例——取少量溶液，先加稀硝酸，若有气泡说明可能存在碳酸根，继续加至不再冒泡、溶液呈明显酸性；再滴加硝酸银溶液，若产生白色沉淀，静置后沉淀不消失、不溶于稀硝酸，则原溶液含 $\ce{Cl-}$。若沉淀呈淡黄色或黄色，则可能是溴离子或碘离子——$\ce{AgBr}$ 淡黄色、$\ce{AgI}$ 黄色，可作初步判断的线索。**离子检验的普遍框架是「特征现象 + 排除干扰」**：先想清楚「谁会同我产生类似现象」，再设计条件把干扰者除掉，最后确认现象稳定存在。这套框架对后面检验 $\ce{SO4^2-}$（先加稀盐酸排除 $\ce{CO3^2-}$、$\ce{SO3^2-}$）、检验 $\ce{NH4+}$ 等完全适用。<span class="marginnote">氯化银（$\ce{AgCl}$）不仅是检验试剂，还曾经是照相术的感光材料——见光分解生成黑色的银微粒：$\ce{2AgCl ->[\text{光}] 2Ag + Cl2 ^}$。「硝酸银 + 稀硝酸」这套检验，还能推广到溴离子（$\ce{AgBr}$ 淡黄色沉淀）和碘离子（$\ce{AgI}$ 黄色沉淀）。</span>

**工业对照**：实验室制氯气是「小批量、求高纯」；工业上大量制氯气靠**电解饱和食盐水**（氯碱工业）：

$$\ce{2NaCl + 2H2O ->[\text{电解}] 2NaOH + H2 ^ + Cl2 ^}$$

电解槽里同时得到烧碱、氢气和氯气三种重要化工产品——这正是上一课《钠及其化合物》里电解熔融 $\ce{NaCl}$ 制钠之外的又一条工业路线。<span class="marginnote">注意区分两条电解路线：电解**熔融** $\ce{NaCl}$ 得到钠和氯气（无水的条件下），电解**饱和食盐水**得到氢氧化钠、氢气和氯气。有没有水，产物天差地别——水里的氢在阴极先被还原成氢气，钠则留在溶液中成为 $\ce{NaOH}$。</span>

## 6 小结

- **反应原理**：$\ce{MnO2 + 4HCl(浓) ->[\Delta] MnCl2 + Cl2 ^ + 2H2O}$，**必须浓盐酸 + 加热**；替代方案是 $\ce{KMnO4}$ 与浓盐酸常温反应。
- **装置五步**：发生 → 饱和食盐水除 $\ce{HCl}$ → 浓硫酸干燥 → 向上排空气法收集（长进短出）→ $\ce{NaOH}$ 溶液吸收尾气。
- **除杂原则**：只除目标杂质、不伤主产物——除 $\ce{HCl}$ 不能用 $\ce{NaOH}$，干燥不能用碱性干燥剂。
- **量关系**：4 mol $\ce{HCl}$ 参加反应，**只有 2 mol 被氧化**；1 mol $\ce{MnO2}$ 生成 1 mol $\ce{Cl2}$、转移 2 mol 电子。
- **验满与停止**：湿润淀粉-碘化钾试纸变蓝；**先撤导管，再撤酒精灯**防倒吸。
- **氯离子检验**：稀硝酸酸化 + $\ce{AgNO3}$ 溶液，白色沉淀不溶于稀硝酸即为 $\ce{AgCl}$；酸化必须用稀硝酸，排除碳酸根等干扰。
- **来源对比**：实验室 $\ce{MnO2 + 4HCl(浓)}$ 共热制氯（少量、高纯），工业电解饱和食盐水制氯（大量、廉价，副产 $\ce{NaOH}$ 与 $\ce{H2}$）。
- **两条方法论**：制气实验的「发生→除杂→干燥→收集→尾气」五步框架，与离子检验的「特征现象 + 排除干扰」框架，将在后续制气与检验中反复复用。
- **安全主线**：氯气有毒，制备全程在通风橱中进行，尾气必须吸收；「先撤导管、后撤灯」与倒扣漏斗，都是防倒吸的保险丝。

至此，「海水中的重要元素——钠和氯」两节结束：钠是还原剂的模板，氯是氧化剂的模板，它们合演了电子转移的完整剧本。在下一节，我们将从「个、堆、打」的计数困境出发，引入化学家称量原子世界的「一把尺」——**物质的量**。有了它，前面所有化学方程式的系数，才能真正换算成实验室里可称、可量、可数的量：这就是**物质的量（一）：物质的量的单位——摩尔**。
