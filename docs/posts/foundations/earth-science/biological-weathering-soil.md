## 为什么从生物风化与土壤的形成开始

前面两节讲了物理风化与化学风化——它们制造了碎屑与黏土，
但这还不是「土壤」。
**土壤（soil）**是风化产物、有机质、水与空气的复合体，
是生命参与地质作用最深刻的产物。
土壤学家多库恰耶夫说，
土壤是「岩石、气候、生物、地形、时间」五要素共同作用的结果。
<span class="marginnote">地球表面只有约 10% 的陆地被土壤覆盖，却养活了全球几乎所有人口与陆地生命。
土壤是农业的根基、碳库的仓库、水质净化的过滤器——认识土壤形成，
就是认识地球表层的「活皮肤」如何长成。
</span>

## 1 生物风化：生命对岩石的作用

**生物风化（biological weathering）**：生物活动直接或间接促进的岩石风化，
分物理与化学两条途径：

**物理途径**：植物根系伸入裂隙生长，产生**根劈作用**（把岩石撑裂）；蚯蚓、穴居动物翻动碎屑。
**化学途径**：地衣、苔藓分泌有机酸溶解矿物；植物根系与微生物呼吸产生 CO2，溶于水成碳酸加强溶解；腐殖质酸络合、淋溶矿物元素。

**生物风化的意义**：它把物理与化学风化「接力」起来，
并源源不断地为土壤补充有机质——没有生物，
风化产物永远只是「碎渣」，
而成不了能长庄稼的「土壤」。

## 2 土壤的形成：五要素的交响

俄国土壤学家多库恰耶夫提出，
土壤是**母质、气候、生物、地形、时间**五要素的函数。
逐个看：

**母质**：风化的岩石碎屑，提供矿物质的「原料库」。
**气候**：温度与降水决定风化强度、有机质分解速度与淋溶深度。
**生物**：植被提供有机质，微生物分解腐殖质，动物翻松土层。
**地形**：坡地淋溶强、土层薄；洼地堆积厚、排水差。
**时间**：成土过程以百年、千年计，土壤是「时间的作品」。

**核心逻辑：土壤 = 风化产物 × 生物作用 × 时间**。
母质决定「从什么开始」，
气候决定「风化多快」，
生物决定「有没有腐殖质」，
时间决定「长多厚」。
<span class="marginnote">黑土的秘密就藏在五要素里：中国东北的黑钙土是草原气候（温凉、半湿润）+ 草本植被（大量根系腐殖质）+ 漫长时间共同塑造的。
黑土层厚达一米，
是数千年生物累积的「绿色银行」。
</span>

## 3 土壤剖面：从上到下读成土史

把土壤垂直切开，
从上到下可见分层的**土壤剖面（soil profile）**：

| 层位 | 名称 | 特征 |
| --- | --- | --- |
| O 层 | 枯枝落叶层 | 未分解的植物残体 |
| A 层 | 淋溶层（腐殖质层） | 有机质富集、色深；水向下淋溶带走矿物 |
| B 层 | 淀积层 | 从 A 层淋溶下来的黏土、铁锰氧化物淀积 |
| C 层 | 母质层 | 风化程度低的母岩碎屑 |
| R 层 | 基岩 | 未风化的母岩 |

**淋溶与淀积**是成土的两大过程：降水把 A 层的矿物质向下淋洗（淋溶），
在 B 层沉淀富集（淀积）。
<span class="marginnote">读土壤剖面就像读「地下的历史书」：O-A 层告诉你植被与有机质状况，
B 层的铁锰淀积带告诉你淋溶强度，
C 层告诉你母岩是什么。
一条土壤剖面，
浓缩了成土五要素的全部信息。
</span>

## 4 土壤类型与气候分带

不同气候带形成不同的代表性土壤：

| 气候带 | 代表性土壤 | 特征 |
| --- | --- | --- |
| 热带雨林 | 砖红壤 | 强淋溶、铁铝富集、红色 |
| 亚热带 | 红壤、黄壤 | 中度淋溶、铁氧化物着色 |
| 温带湿润 | 棕壤、褐土 | 淋溶适中、肥力较好 |
| 温带草原 | 黑钙土、黑土 | 腐殖质厚、极肥沃 |
| 寒温带针叶林 | 灰化土 | 强淋溶、灰白色 A 层 |
| 干旱区 | 荒漠土 | 淋溶弱、富含盐类 |

**土壤分带与化学风化分带完全同源**——都是温度与降水的函数（回顾上节）。
红壤与砖红壤对应强化学风化，
灰化土对应弱分解的酸性淋溶。
<span class="marginnote">中国从南到北的土壤变迁是活教材：海南的砖红壤 → 江南的红壤 → 华北的褐土 → 东北的黑土 → 大兴安岭的灰化土，
恰好是一条完整的气候土壤带。
坐火车纵穿中国，
窗外土地颜色的变化就是气候的剖面。
</span>


土壤还是陆地碳库的重要组成部分——全球土壤有机碳储量约为大气的两倍，保护土壤既保粮食也保气候。

## 5 小结

- **生物风化**通过**根劈（物理）与有机酸、呼吸产 CO2（化学）**促进岩石风化，是岩石到土壤的「催化剂」。
- 土壤由**母质、气候、生物、地形、时间**五要素共同塑造。
- 土壤剖面分 **O（枯落物）—A（淋溶/腐殖质）—B（淀积）—C（母质）—R（基岩）**，淋溶与淀积是成土核心过程。
- 土壤类型呈**气候分带**：砖红壤→红壤→黑土→灰化土，与化学风化分带同源。
