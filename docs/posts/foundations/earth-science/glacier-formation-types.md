# 冰川的形成与类型：大陆冰川与山岳冰川

## 为什么从冰川的形成与类型开始

地球表面约 10% 的陆地被冰川覆盖，
**约 69% 的淡水资源以冰川与积雪形式储存**。
冰川不是「不动的冰堆」，
而是**能缓慢流动的冰体**——
它是地表最强大的侵蚀与搬运力量之一，
塑造了冰斗、角峰、U 形谷等独特地貌，
也记录了第四纪以来的气候历史。
<span class="marginnote">阿尔卑斯、喜马拉雅、南极与格陵兰——冰川分布在两大舞台：高山之巅与两极大陆。
它们像地球的「冷血雕刻师」，
用亿万年把山峰削尖、把峡谷改造成 U 形。
19 世纪阿加西正是靠研究阿尔卑斯冰川，
才提出了「冰期」概念。
</span>

## 1 冰川的形成：从积雪到冰流

冰川的形成不是「水结冰」那么简单，
它经历三步：

1. **积雪**：年降雪量大于消融量，雪逐年累积。
2. **压实成粒雪**：积雪自重压实，雪花晶形消失，转变成颗粒状的**粒雪（firn）**。
3. **粒雪成冰**：粒雪继续压实、排出空气，变成致密的**冰川冰**（含气泡的蓝色透明冰体）。

当冰层厚到一定程度（一般数十米），
底部冰在高压下呈塑性，
冰体开始**在重力作用下流动**——
这才成为真正的冰川。

**雪线（snow line）**：
多年积雪区与消融区的分界线，
是冰川能否形成的关键。
雪线以上积累大于消融（积累区），
以下消融大于积累（消融区）。
<span class="marginnote">雪线随纬度与海拔变化：极地雪线近海平面，
青藏高原雪线在海拔 5000 米以上，
赤道高山雪线也在 4500–5000 米。
海拔越高、纬度越高、降水越多，
雪线越低——
雪线高度本身就是气候的标尺。
</span>

## 2 山岳冰川：高山上的冰流

**山岳冰川（mountain / alpine glacier）**：
发育在高山雪线以上的冰川，
受地形控制。
按形态分：

- **冰斗冰川**：发育在雪线附近的碗状洼地（冰斗）中的小型冰川。
- **悬冰川**：贴附在陡坡上、规模小的冰川。
- **山谷冰川（valley glacier）**：沿山谷流动的冰川，像一条冰冻的河流，是山岳冰川的典型——阿尔卑斯、喜马拉雅的冰川多属此类。

## 3 大陆冰川：覆盖大陆的冰盖

**大陆冰川（continental glacier / ice sheet）**：
覆盖大面积陆地、不受地形控制的巨型冰川，
仅见于**南极与格陵兰**。

特征：

- **面积巨大**：南极冰盖面积约 1400 万 km²，平均厚约 2000 米，最厚超过 4000 米。
- **中央厚、边缘薄**：呈穹窿状，冰从中央向四周流动。
- **冰盖下的地貌**：冰层覆盖一切，只在边缘伸出冰舌、崩解成冰山。

**冰帽（ice cap）**：
介于山岳冰川与冰盖之间，
覆盖在山顶或高原上的小型冰盖，
如冰岛瓦特纳冰盖。

## 4 核心对比：山岳冰川与大陆冰川

（本主题以冰川类型对比表为核心。
）

| 对比项 | 山岳冰川 | 大陆冰川（冰盖） |
| --- | --- | --- |
| 分布 | 高山雪线以上 | 两极大陆 |
| 面积 | 小（数 km²—数千 km²） | 巨大（百万 km²级） |
| 地形控制 | 受山谷控制 | 不受地形控制 |
| 厚度 | 数十—数百米 | 可达数千米 |
| 流动 | 沿谷向下 | 自中央向四周 |
| 实例 | 阿尔卑斯、喜马拉雅冰川 | 南极、格陵兰冰盖 |
| 时代 | 现代与第四纪均有 | 现代仅两极 |

**辨析｜易错点：
** 山岳冰川与大陆冰川的差别是**规模与控制因素**，
不是「高山才有冰」——
冰盖同样可以覆盖山地（南极横贯山脉被冰盖吞没）。
划分的关键：
**冰川是否受下伏地形控制**。
受控于山谷的是山岳冰川，
不受控地覆盖一切的是冰盖。

## 5 小结

- 冰川形成三步：**积雪 → 粒雪 → 冰川冰**，冰层达一定厚度后在重力下流动。
- **雪线**是积累与消融的平衡线，其高度由**纬度、海拔、降水**决定。
- **山岳冰川**受地形控制（冰斗、悬冰川、山谷冰川）；**大陆冰川**不受地形控制，仅存于南极与格陵兰。
- 冰川储存全球约 69% 的淡水资源，南极冰盖若全融将使海平面上升约 60 米。
