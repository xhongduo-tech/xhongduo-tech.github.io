## 为什么从全球变暖的证据与归因开始

上一节我们看到：
全球在变暖。
但「变暖」不等于「人类造成的」——
要回答后者，
需要**证据**与**归因（attribution）**两步：
先证明变暖发生了，
再证明变暖主要由人类活动导致。
这是气候变化研究最核心、也最严谨的部分。
<span class="marginnote">IPCC（政府间气候变化专门委员会）第六次评估报告（AR6，2021）给出了迄今最明确的结论：人类影响使大气、海洋和陆地变暖，这一判断是「明确无疑的」（unequivocal）。
这个结论不是口号，
而是建立在观测、同位素、辐射强迫与气候模式四重证据之上。
</span>

## 1 证据一：CO2 在升，且来自化石燃料

**大气 CO2 浓度**从工业革命前的约 280 ppm 升至今天的 420 ppm 以上——
这是冰芯记录 80 万年来的最高值。

如何证明这些 CO2 来自化石燃料？
看**碳同位素**：
化石燃料含碳-13（¹³C）少、碳-12（¹²C）多。
观测显示大气 CO2 中 ¹³C 比例持续下降——
这与「燃烧化石燃料」的指纹完全吻合。
<span class="marginnote">碳同位素是 CO2 的「身份证」：火山喷发的 CO2 与化石燃料的 CO2 同位素指纹不同。
观测到的 ¹³C 持续下降，
只能由燃烧几亿年前埋藏的有机碳（煤、石油）来解释——
这是「CO2 来自人类」最硬核的证据。
</span>

## 2 证据二：变暖与温室气体辐射强迫吻合

**辐射强迫（radiative forcing）**：
温室气体增加导致的地表能量收支失衡（进入的热多于逃逸的热），
单位为 W/m²。
工业革命以来，
CO2、CH4、N2O 等温室气体的总辐射强迫约为 +3 W/m²——
相当于每平方米地表多吸收约 3 瓦特的能量，
方向与增温一致。

**观测的「指纹」也吻合**：
温室气体增暖在**对流层显著、平流层降温**——
这种「下暖上冷」的结构，
只有温室效应能产生（太阳增暖会同时加热平流层）。
<span class="marginnote">「平流层降温」是温室增暖的独特指纹：CO2 在对流层捂热地面，
在平流层却因增强辐射冷却而变冷。
太阳活动增强会同时加热所有层——
所以「变暖是太阳的锅」的说法，
被这个空间指纹直接排除。
</span>

## 3 证据三：气候模式的自然归因实验

**气候模式（climate models）**用物理方程模拟地球气候。
归因研究的经典实验是「双跑对照」：

**只含自然强迫**（太阳、火山）：模式模拟不出 1970 年以来的快速增暖。
**含自然+人为强迫**（温室气体、气溶胶等）：模式与实测温度曲线几乎重合。

**结论**：
自然因素（太阳、火山）无法解释近几十年的增暖，
必须叠加人为强迫才能复现——
**人类活动是近半个世纪全球变暖的主导原因**。
IPCC AR6 估计：
1951–2010 年观测到的增暖中，
人类活动贡献了 **全部**（范围约 100%±30%），
即自然因素贡献接近于零甚至略负。
<span class="marginnote">气候模式的「归因实验」像破案：把嫌疑人（自然因素）单独放进去，
案情对不上；
把嫌疑人（人类）加进去，
案情吻合。
太阳辐射的 11 年周期、火山降温都无法解释 0.2 ℃/十年的加速增暖——
只剩温室气体这一条路。
</span>

## 4 完整的证据链：从大气到海洋到冰

全球变暖的证据是一个**互相印证的链条**，
没有单一证据是孤立的：

| 观测事实 | 与变暖的一致性 |
| --- | --- |
| 大气 CO2 升至 420 ppm | 温室效应增强的直接原因 |
| 全球均温升约 1.1 ℃ | 变暖的主体信号 |
| 海洋吸收 90%+ 增暖热量 | 热膨胀导致海平面上升 |
| 海平面百年升约 20 cm | 热膨胀 + 冰川融水 |
| 山地冰川、两极冰盖消融 | 高温的直接后果 |
| 极端高温与强降水事件增多 | 与统计预期一致 |

**辨析｜易错点：
** 把「天气」当「气候」证据是常见误区——
一次严寒或一个暖冬，
既不能证明也不能否定变暖。
判断变暖看**长期全球平均趋势**；
归因看**模式实验与物理机制**。
科学共识不是「每个数据都完美」，
而是「所有证据都指向同一方向」。

## 5 小结

- **全球变暖的证据链**：CO2 上升 → 均温升高 → 海洋增温 → 海平面上升 → 冰川消融 → 极端事件增多，多重观测互相印证。
- **CO2 来自化石燃料**由碳同位素（¹³C 下降）证实。
- **辐射强迫 + 「对流层暖、平流层冷」的空间指纹**指向温室效应，而非太阳活动。
- **气候模式归因实验**表明：自然因素模拟不出近期增暖，人为强迫才能复现——**人类活动是近期变暖的主导原因**。
