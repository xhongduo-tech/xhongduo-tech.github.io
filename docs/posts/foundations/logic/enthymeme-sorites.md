# 省略三段论（enthymeme）与连锁三段论（sorites）

## 为什么从变体开始

标准三段论是「两条腿走路」，但真实说话的人几乎从不把话说完：他们省略前提、压缩链条。
**省略三段论（enthymeme）**就是「缺一条腿」的三段论——一个前提或结论被隐含；
**连锁三段论（sorites）**是把一串三段论首尾相接、压缩成一个多前提论证。
处理这两种变体是词项逻辑从课堂走向生活的一步：你不仅要会推，还要会**补**（把省略的前提补出来）和**拆**（把连锁论证拆回三段论）。

## 1 省略三段论：缺腿的论证

**省略三段论（enthymeme）**：省略了一个前提或结论的三段论。它不一定是错的——省略的是**说话者认为不言自明**的部分，听众自行补充。

三种省略方式：

- **省略大前提**：「苏格拉底会死，因为他是人」——省略了「所有人都会死」。
- **省略小前提**：「所有人都会死，所以苏格拉底会死」——省略了「苏格拉底是人」。
- **省略结论**：「所有人都会死，苏格拉底是人」——结论「苏格拉底会死」留给听众自己说出。

为什么人们爱省略？因为**沟通效率**——把人人皆知的大前提说出来显得啰嗦。
但这正是论证分析的陷阱：省略的前提未必成立。批判性思维的第一步，就是识别省略三段论，把缺的腿补出来，再检验它是否可靠。

**辨析｜易错点：** 省略三段论 ≠ 无效三段论。一个省略三段论只是「形式不完整」，补上省略的部分后可能完全有效。但**如果补上的前提不成立（假）或补法不当，论证就站不住**。批判的对象往往是那条被省略的前提，而不是明说的部分。

## 2 如何补出省略的前提

补前提有一套可操作的方法：

- **第一步，找出三个词项**：从明说的命题里找结论与前提，标出小项、大项、中项。
- **第二步，判断缺的是哪条腿**：若只有一条明说前提，看它含不含小项（则缺大前提）还是大项（则缺小前提）。
- **第三步，构造缺失命题**：用剩下的两个词项，按「连接中项与大小项」的方式补出。缺大前提时，用中项与大项构造；缺小前提时，用中项与小项构造。
- **第四步，选最强而不越界的补法**：补出的前提要能让论证成为**有效的三段论**——通常选「使论证最合理」的那个候选，这也正是辩论里双方争抢的「隐含前提」。

例：「张三应该被处罚，因为他违反了校规」。明说前提「张三违反了校规」（$S$ = 张三，$M$ = 违反校规的人），结论「张三应该被处罚」（$P$ = 应受处罚）。缺大前提，用 $M$ 与 $P$ 构造：**「所有违反校规的人都应被处罚」**——这条前提被补出后，论证成为第一格 AAA 有效式。可它成立吗？这正是要讨论的：校规一定等于应受处罚吗？<span class="marginnote">补隐含前提是论证重构的核心技能（第九篇《隐含前提的挖掘与补充》会专门展开）。省略三段论是它的词项逻辑版：通过形式补全，把一个「没说出口的承诺」暴露在阳光下接受检验。</span>

## 3 连锁三段论：多腿的链条

**连锁三段论（sorites）**：一串三段论首尾相接，前一个的结论充当后一个的前提，整串压缩成一个多前提论证。词项形成一个「链」：

$$
S_1 \to S_2 \to S_3 \to \cdots \to S_n
$$

最经典的例子就是「排序链」：「亚里士多德是人，人是动物，动物是生物，生物是有机物」。压缩成连锁三段论：

- 亚里士多德是人；
- 人是动物；
- 动物是生物；
- 生物是有机物；
- 所以亚里士多德是有机物。

这个论证里每个相邻命题共享一个词项，环环相扣。词项逻辑喜欢把它拆回一串第一格 AAA 三段论逐一验证——每一步都是「$x$ 属于 $A$，$A$ 属于 $B$，所以 $x$ 属于 $B$」的包含传递。<span class="marginnote">连锁三段论的名字 sorites 来自希腊语 sōros（一堆），与「堆垛悖论」同源（第七篇会讲）。那个悖论正是这种「一步一步都合理、串起来就荒谬」的链条结构的极端案例——每个相邻判断都对，累积的结果却矛盾。</span>

## 4 公式解析：连锁三段论的展开与折叠

连锁三段论可以严格地展开成一串标准三段论，也可以反向压缩。看这个四前提链条：

$$
\text{所有 } S_1 \text{ 是 } S_2, \quad \text{所有 } S_2 \text{ 是 } S_3, \quad \text{所有 } S_3 \text{ 是 } S_4, \quad \therefore \text{ 所有 } S_1 \text{ 是 } S_4
$$

- **第一步，逐环展开**：把链条拆成两个三段论。
  - 三段论一：所有 $S_1$ 是 $S_2$；所有 $S_2$ 是 $S_3$；所以所有 $S_1$ 是 $S_3$（第一格 AAA）。
  - 三段论二：所有 $S_1$ 是 $S_3$；所有 $S_3$ 是 $S_4$；所以所有 $S_1$ 是 $S_4$（第一格 AAA）。
- **第二步，中间结论**：第一个三段论的结论「所有 $S_1$ 是 $S_3$」变成第二个三段论的前提——这就是「连锁」。
- **第三步，整体有效**：每一环都有效，整体必然有效。连锁三段论的有效性 = 每一环有效性的叠加。
- **第四步，折叠回去**：反过来，任何有效的连锁论证都可以折叠成一个含 $n$ 个前提的「压缩式」——就像把一串证明连写成一行。

**连锁三段论的有效性规则**与标准三段论相同，只是多了两条形式约束：每个相邻前提必须共享一个词项，且中项的排列不能「断裂」。如果链条中间某个词项对不上（共享词项出现两次以上），整个链就断了。

## 5 例题演练

**例 1**：补全省略三段论「他应该获奖，因为他付出了最多努力」。

- 明说前提「他付出最多努力」（S=他，M=付出最多努力者），结论「他应该获奖」（P=应获奖）。缺大前提，用 M 与 P 构造：「付出最多努力的人应该获奖」。补上后为第一格 AAA——而这条隐含大前提正是可争之处。

**例 2**：连锁三段论「A 属于 B；B 属于 C；C 属于 D；所以 A 属于 D」如何展开成标准三段论？

- 三段论一：A 属于 B、B 属于 C，故 A 属于 C；三段论二：A 属于 C、C 属于 D，故 A 属于 D。中间结论 A 属于 C 成为第二三段论的前提——每环都是第一格 AAA。

**例 3**：连锁三段论与滑坡谬误结构相同，为何命运不同？

- 连锁三段论每一环都有独立证据（演绎有效）；滑坡谬误每一环都是无证据的猜测。链条本身无对错，对错在每一环是否被扣牢。

**例 4**：为什么「省略三段论」与「隐含前提」是同一件事的两面？

- 省略三段论是词项逻辑的用语，隐含前提是论证理论的用语——它们都指「为论证成立而必需、却未说出的前提」。挖出隐含前提，争论焦点才浮现。

**延伸思考**：处理省略论证的纪律是宽容原则：补上「最合理」的前提，而不是把论证补成稻草人。

**例 5**：为什么连锁三段论的「最弱一环」决定整体？

- 链条的每个结论都依赖前一环——中间任何一环不成立，后面全部崩塌。评估链式论证要逐环检查，而不是只看首尾。

**延伸思考**：连锁三段论与滑坡谬误同结构、不同命——每一环是否有独立证据是分水岭。

**本节要点自检**：省略三段论要补隐含前提再检验；连锁三段论拆成环环相扣的标准三段论，最弱一环决定整体。

## 6 小结

- **省略三段论**：缺一个前提或结论的三段论；不一定无效，但被省略的前提常是争论焦点。
- 补前提四步：**找词项 → 判缺失 → 构造缺失命题 → 选最强有效补法**。
- **连锁三段论**：一串三段论首尾相接，前一个结论充当后一个前提。
- 连锁论证的有效性 = **每一环有效性的叠加**；相邻前提必须共享词项。
- 处理两种变体的意义：**补全**（隐含前提）与**拆解**（长链论证）——这是词项逻辑应用于日常论证的两把钥匙。
