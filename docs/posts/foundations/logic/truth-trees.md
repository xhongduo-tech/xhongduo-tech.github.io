# 真值树（语义树）判定方法

## 为什么从真值树开始

真值表能判定任何命题逻辑公式，但 $n$ 个变元就要 $2^n$ 行——遇到十几个变元，手工就崩溃了。
本课介绍**真值树（truth tree）**，也叫**语义树（analytic tableau）**：一种树状的反例搜索程序，通常只需展开一部分行就能出结果。
它是《用真值表判定论证有效性》里「只找反例行」思想的形式化，也是现代逻辑教学中连接命题逻辑与一阶逻辑的桥梁——因为在一阶逻辑那里，真值树几乎是唯一可手工操作的判定工具。

## 1 树上的两种运算

真值树从「要检验的一堆公式」出发，不断用规则把公式拆成更简单的公式，直到穷尽所有可能性。
整个树的每一行都是一条「路径」，一条路径代表一种让路径上全部公式同时为真的赋值尝试。

每个逻辑联结词对应一条或两条**展开规则**：

- **合取展开（不分支）**：$P \land Q$ 同时要求 $P$ 真、$Q$ 真——在同一路径上依次写下 $P$、$Q$。
- **析取展开（分支）**：$P \lor Q$ 有两种可能——路径分成两支，一支写 $P$，另一支写 $Q$。
- **否定展开**：双重否定 $\neg\neg P$ 简化为 $P$；德摩根式（如 $\neg(P \land Q)$）按等值展开成分支的 $\neg P$ / $\neg Q$。
- **蕴涵展开（分支）**：$P \to Q$ 等价于 $\neg P \lor Q$，分支为 $\neg P$ 或 $Q$。

**辨析｜易错点：** 关键在区分「一支必须全满足」还是「两支满足其一」。合取在同一支里**串行**展开（两个都要真），析取**分支**展开（二选一）。把合取误当分支，或把析取误当串行，是建树时最常见的错误——判断标准是看这条规则是否产生了「多种可能」。

## 2 闭支与判定

一条路径上如果同时出现 $P$ 与 $\neg P$（矛盾），这条路径就**关闭（closed）**，记为 $\times$——它意味着「这条赋值尝试失败」。
所有路径都关闭时，树就是**闭树**，说明「没有任何赋值能让公式成立」。

利用闭树判定：

- 公式 $A$ 是**矛盾式** ⟺ 以 $A$ 为根建树，树闭合（无路径可满足）。
- 公式 $A$ 是**重言式** ⟺ 以 $\neg A$ 为根建树，树闭合（否定的可满足性为零）。
- 公式 $A$ 是**可满足式** ⟺ 存在一条**开放路径**（不关闭的路径），路径上出现过的原子命题及其否定给出了一个**满足赋值**。

<strong>判定论证有效性</strong>：论证「前提 $P_1,\dots,P_n$，结论 $C$」有效 ⟺ 把前提与 $\neg C$ 一起放入根，树闭合。因为「前提全真而结论假」恰是反例；反例不存在（树闭），论证即有效。<span class="marginnote">真值树把「找反例」变成了「找开放路径」：一条开放路径就是一个活生生的反例，它上面写着的原子命题赋值就是让前提为真、结论为假的赋值——比真值表的反例行更直观。</span>

## 3 一个完整的建树演示

判定「$P \to Q$ 与 $Q$ 能否推出 $P$」（即检验肯定后件是否有效）。
把前提和结论否定放入根：$P \to Q,\; Q,\; \neg P$。

- 第 1 层：写根三式。
- 第 2 层：展开 $P \to Q$，它分支为 $\neg P$（左）或 $Q$（右）。
- 左支：已有 $\neg P$（根里就有），分支又给 $\neg P$，与根一致，但这条路径同时含 $Q$ 与 $\neg P$，**没有**矛盾——开放。
- 右支：含 $Q$ 与 $Q$（根里已有），也开放。

两条路径都开放，树不闭合。于是存在赋值使前提真、结论假（如 $P$ 假、$Q$ 真），论证**无效**——与真值表第三行的反例一致。<span class="marginnote">对比一下：完整真值表要算 $P,Q$ 的 $2^2=4$ 行，而真值树只展开了一层就找到了反例。公式越复杂、反例越「浅」，真值树的优势越明显。</span>

## 4 公式解析：为什么「树闭合」等价于「不可满足」

把真值树的判定逻辑浓缩为一个等价关系：

$$
A \text{ 不可满足} \iff \text{以 } A \text{ 为根的语义树闭合}
$$

拆解它背后的每一步：

- **第一步，路径语义**：树上任意一条路径上的全部公式，代表一个「试图同时为真的赋值」；一个公式 $X$ 被展开，等于穷尽 $X$ 为真的所有方式。
- **第二步，闭合语义**：路径同时含 $P$ 与 $\neg P$，二值原则下无赋值可满足，这条路径被判死刑。
- **第三步，全闭语义**：所有路径都死亡，说明 $A$ 为真的**所有**可能方式都被排除——$A$ 不可满足。
- **第四步，判定的转化**：于是「$A$ 可满足」=「存在开放路径」；「$A$ 重言」=「$\neg A$ 树闭」；「论证有效」=「前提 + $\neg$结论 树闭」。

这套机制的关键优势是**程序化**：它没有真值表那种指数级的「全表」压力，而且到一阶逻辑仍可运行（只是可能永不终止——那是第三篇不可判定性的伏笔）。
现代定理证明器（tableau 方法、SAT 与 SMT 求解器的核心思路）都由此发展而来。

## 5 例题演练

**例 1**：用真值树判定 $P \to Q$ 与 $P \land \neg Q$ 是否一致（能否同时为真）。

- 把两式放入根。展开 $P \land \neg Q$：同支写下 $P$、$\neg Q$；展开 $P \to Q$ 分支为 $\neg P$ 或 $Q$。左支含 $\neg P$ 与 $P$——关闭；右支含 $Q$ 与 $\neg Q$——关闭。树闭合，两式不一致——因为 $P \land \neg Q$ 正是 $P \to Q$ 的否定。

**例 2**：判定「$P \lor Q,\; P \to R,\; Q \to R \therefore R$」是否有效。

- 根放前提与 $\neg R$。展开 $P \lor Q$ 分支为 $P$、$Q$；再分别用 $P \to R$、$Q \to R$ 展开。每个分支都同时含 $R$ 与 $\neg R$——全部关闭，树闭，论证有效（二难推理）。

**例 3**：开放路径如何给出反例？

- 路径上的原子命题与否定就是赋值：含 $P$ 不含 $\neg P$ 则 $P$ 真，含 $\neg P$ 则 $P$ 假。这条路径即「使根上公式全真的模型」——若根是「前提+否定结论」，它就是一个反例。

**例 4**：用真值树判定 $P \to Q$ 是否可从 $\neg(P\to Q)$ 的矛盾中逃生？

- 根放 $\neg(P\to Q)$ 与 $P\to Q$：前者展开为 $P$、$\neg Q$（否定蕴涵），后者分支为 $\neg P$ 或 $Q$。左支 $\neg P$ 与 $P$ 关，右支 $Q$ 与 $\neg Q$ 关——树闭，两式矛盾（正如预期，$\neg(P\to Q)$ 是 $P\to Q$ 的否定）。

**例 5**：为什么真值树常比真值表快？

- 真值表固定展开 $2^n$ 行；真值树只展开「与反例相关的分支」，很多公式在浅层就全部关闭。公式越复杂、反例越「浅」，真值树优势越大——它是反例搜索的剪枝版。

**延伸思考**：真值树（tableau）是现代一阶逻辑自动定理证明的基石：tableau 算法直接扩展了这套规则，是 SAT 求解与模型检查的基础技术之一。从手工画树到机器证明，走的同一条路。

**例 4**：为什么「开放路径」就是满足赋值？

- 路径上出现的原子命题（及其否定）给出一个一致的赋值——路径未关闭说明这些赋值不冲突，它们就构成让根公式为真的模型。

**延伸思考**：真值树是 SAT 求解的直观版——开放路径=可满足赋值，全闭=不可满足，反例=开放路径。

**本节要点自检**：合取串行、析取分支；全闭=不可满足；开放路径就是活生生的反例。

## 6 小结

- **真值树**：树状反例搜索程序，从公式出发按规则展开。
- 规则分两类：**合取串行**（同支展开）、**析取/蕴涵分支**（两支二选一）。
- 路径含矛盾即**关闭**；所有路径关闭即**树闭**。
- 判定：矛盾式 = 根公式树闭；重言式 = 根的否定树闭；论证有效 = 前提加结论否定树闭。
- **开放路径就是反例**，直接给出满足/无效的赋值。
- 真值树程序化程度高，向一阶逻辑扩展仍是可用的判定工具。
