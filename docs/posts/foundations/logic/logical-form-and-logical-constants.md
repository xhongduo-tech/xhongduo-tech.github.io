## 为什么从「逻辑形式」开始

上一节我们反复说「形式逻辑只问形式」，可「形式」二字一直悬着：**到底什么叫一个论证的「形式」？** 说「所有 M 是 P，s 是 M，所以 s 是 P」是形式，那「形式」是怎么从具体句子「抽」出来的？

这一节把这个手术做干净。答案是一套两步操作：**先圈定哪些词是逻辑常项，再把其余内容词换成字母。** 常项决定论证的骨架，变项是留给内容的插槽。看清了这两类词的分工，上一节的「逻辑真理」「有效性」都会从模糊的直觉变成看得见、算得出的结构——维特根斯坦说的「脚手架」也会落地成真。

## 1 逻辑形式：把句子抽成骨架

**核心概念：逻辑形式（logical form）——把一个论证中的内容词统一替换为变项后得到的结构，就是这个论证的逻辑形式。**

先看两个论证：

1. 所有人都会死；苏格拉底是人；所以苏格拉底会死。
2. 所有哲学家都是爱思考的人；苏格拉底是哲学家；所以苏格拉底是爱思考的人。

两句内容完全不同，但把「人 / 哲学家」「会死 / 爱思考」「苏格拉底」等**内容词**换成字母，两个论证都变成同一个骨架：

$$
\text{所有 } M \text{ 是 } P；\ \ s \text{ 是 } M；\ \ \therefore s \text{ 是 } P
$$

这个骨架就是它们共同的**逻辑形式**。判定论证是否有效，看的就是这个骨架，而不是填充的内容——两个论证的有效性是一样的。<span class="marginnote">「抽形」的思想最早来自亚里士多德：《前分析篇》里他把具体三段论写成「M—P、S—M，故 S—P」的字母式，这正是逻辑形式的雏形。抽形就是亚里士多德做的第一件事。</span>

**重点：逻辑形式是「替换不变」下留下的东西。** 把一个论证里的非逻辑词统一换成别的非逻辑词，论证的形式不变。形式是那个「怎么换都换不掉」的骨架，内容是每次填充进去的血肉。

## 2 逻辑常项与内容变项

抽形的关键，在于分清两类词：

**逻辑常项（logical constant）**：在替换时**保持不动**的词。它们是逻辑自己的词汇，决定推理的骨架。主要包括：

- **命题联结词**：且（$\land$）、或（$\lor$）、非（$\neg$）、如果…那么（$\to$）、当且仅当（$\leftrightarrow$）。
- **量词**：所有（$\forall$）、有的（$\exists$）。
- **等词**：等于（$=$）。（有时也把「是」的某些用法算进来。）

**内容变项（non-logical / content term）**：替换时**被字母顶替**的词。它们是内容槽，包括：

- **个体词**：苏格拉底、2、北京——换成 $a, b, c$ 或 $s$。
- **谓词词项**：会死、哲学家、爱思考——换成 $F, G, M, P$。
- **命题词**（在命题逻辑里）：一个完整句子——换成 $P, Q, R$。<span class="marginnote">分水岭不是绝对固定的：哪个系统把哪些词当常项，是逻辑学的<strong>选择</strong>。蒯因（Quine）《逻辑哲学》指出，常项范围会随理论膨胀而调整——比如把「属于（∈）」加进集合论后，它就成了该系统的逻辑常项。本专题按经典一阶逻辑的约定划分。</span>

一句话：**常项是骨架的焊点，变项是插槽。** 抽形时，焊点不动，插槽统统换成字母。

## 3 常项决定逻辑真理

上一节的「逻辑真理」，现在可以用常项与变项说清楚。

**核心概念：逻辑真理（logical truth）——一个命题是逻辑真理，当且仅当把所有非逻辑词统一替换后，句子依然为真。**

「明天要么下雨要么不下雨」之所以不可能假，是因为它依赖的只有常项「要么…要么…（$\lor$）」与「不（$\neg$）」：

$$
P \lor \neg P
$$

无论 $P$ 被换成「明天下雨」「1+1=2」还是「这个句子由五个字组成」，$P \lor \neg P$ 恒真。**常项把「真」焊死在形式上，变项怎么填都撼动不了它。**<span class="marginnote">对比事实真理：「北京是中国的首都」换成「巴黎是法国的首都」仍然真，换成「北京是法国的首都」就假——它依赖的是<strong>内容</strong>。逻辑真理与非逻辑真理的分水岭，正在于「换词不变真」这条性质。</span>

这条性质还给出了一个漂亮的推论：**所有逻辑真理共享同一个「必然性」来源——它们不是描述了世界，而是展示了一套形式规则。** 维特根斯坦说逻辑命题「描述世界的脚手架」，意思正是：逻辑真理谈论的不是世界的某一角落，而是任何可能世界都必须服从的框架。本专题第二篇要学的**重言式**，就是命题逻辑里所有逻辑真理的统称。

## 4 公式解析：抽形三步法

把「抽形」做成一套可操作的程序，共三步。以这个论证为例：

> 所有哲学家都是爱思考的人；苏格拉底是哲学家；所以，苏格拉底是爱思考的人。

- **第一步，圈出逻辑常项**：这里常项有「所有」和系词「是」。「所有…都是…」构成一个全称命题，「…是…」表达谓述关系。
- **第二步，把内容词统一换成变项**：个体词「苏格拉底」换 $s$；谓词词项「哲学家」换 $M$、「爱思考的人」换 $P$。注意**同一内容词必须换成同一变项**——「哲学家」出现两次，都得是 $M$，不能一次 $M$ 一次 $N$。
- **第三步，读出骨架**：得到

$$
\text{所有 } M \text{ 是 } P；\ \ s \text{ 是 } M；\ \ \therefore s \text{ 是 } P
$$

用一阶逻辑的语言（第三篇的预告）更精确地写成：

$$
\forall x (Mx \to Px), \quad Ms \quad \therefore \quad Ps
$$

读作：「对一切 $x$，若 $x$ 是 $M$ 则 $x$ 是 $P$；$s$ 是 $M$；所以 $s$ 是 $P$。」

**重点：抽形的正确性取决于「统一替换」。** 换变项时必须**始终如一**：同一个内容词的所有出现换同一个变项，不同内容词换不同变项。若「哲学家」一处换 $M$、一处换 $N$，骨架就被换散了，会无中生有地改变论证的有效性。<span class="marginnote">「统一替换」这条纪律在第三篇的量词规则（全称例示、存在例示）里会成为性命攸关的约束——那里有一类经典错误正是「换名换得不一致」导致的。先在抽形这里把它养成习惯。</span>

**辨析｜易错点：把「变项」误当成「省略的省略号」。** 变项不是「等等」的意思，而是「任意但固定」：$s$ 表示「任何一个你挑定的个体」，但它一旦挑定，全文都指它。「苏格拉底是哲学家」里 $s$ 指苏格拉底，就不能在下一步又当亚里士多德。变项是**同一个个体**的代称，不是随意填的占位符。

## 5 日常语言里的常项与易错点

把常项从日常汉语里识别出来，比背定义难，因为自然语言的连接词是一词多义的。

**易错点一：「或者」不一定是逻辑的「或」。** 汉语的「或者」有时是**相容**（可同时成立，$P \lor Q$），有时是**排斥**（二选一，$P \oplus Q$）。「今晚看电影或者逛街」若只能选一样，就是排斥或；逻辑课默认的「或」是相容或——$P$ 与 $Q$ 同真时「$P$ 或 $Q$」仍真。翻译成形式语言前，必须先问清楚是哪种「或」。

**易错点二：「除非」「只有…才」是反着翻译的。**「只有通过了考试，才能毕业」翻译成「毕业 $\to$ 通过考试」，不是「通过考试 $\to$ 毕业」。日常语序把后件放在前面，是初学命题逻辑最容易栽的坑，第二篇讲蕴涵时会系统训练。

**易错点三：把「并且」与「但是」当成不同的常项。**「他聪明并且勤奋」与「他聪明但是懒」在逻辑上都是合取 $\land$——「但是」只是加了一层惊讶语气，不改变真值条件。逻辑常项看的是**真值功能**，不是修辞色彩。<span class="marginnote">这条原则叫<strong>外延性（extensionality）</strong>：逻辑只关心句子的真值，不关心句子的语气、情绪或隐含意味。这也是「形式逻辑只问形式」在词汇层面的化身。</span>

这些坑的共同教训是：**自然语言是「表面语法」，逻辑形式是「深层结构」。** 翻译成形式语言，是在做一次去歧义的压缩——这正是后面用真值表、用演算检查论证的前提。

## 6 小结

- **逻辑形式**：把内容词统一替换成变项后留下的骨架；「所有 M 是 P；s 是 M；所以 s 是 P」是一个形式，无数实例共用。
- **逻辑常项**：联结词、量词、等词，抽形时不动，是骨架的焊点。
- **内容变项**：个体词、谓词词项、命题词，抽形时换成字母，是内容的插槽。
- **逻辑真理** = 换掉所有非逻辑词依旧为真的句子；它由常项焊死，如 $P \lor \neg P$。
- 抽形三步：圈常项 → 统一替换内容词 → 读出骨架；**统一替换**是正确性的命门。
- 自然语言连接词一词多义（或者、除非、但是），翻译成形式语言是去歧义的压缩。

在下一节，我们把目光从「一个论证的形式」转向「逻辑自身的宪法」：**逻辑的三大基本规律——同一律、矛盾律、排中律**，它们正是所有逻辑真理里最底层的三条。
