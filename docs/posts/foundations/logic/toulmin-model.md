# 图尔敏（Toulmin）论证模型：主张、根据、保证

## 为什么从图尔敏模型开始

古典逻辑的论证模型（三段论、演绎）擅长「从确定前提推出确定结论」，但日常论证——法律辩论、伦理争论、政策讨论——很少这么理想：前提是概率性的、推理要解释为什么、结论还常常要加限定语。<span class="marginnote">图尔敏模型把「根据→主张」的跳跃显式化为保证（warrant）——这正是隐含前提的另一种说法。</span>
1958 年，英国哲学家**斯蒂芬·图尔敏（Stephen Toulmin）**在《论证的使用》中提出一个更贴近真实论证的模型，它把论证拆成**主张、根据、保证、支援、限定、反驳**六个成分。
图尔敏模型是修辞学、法学论证、写作教学与 AI 论证挖掘的标准工具。

## 1 三个核心成分

图尔敏模型的第一层是三个核心成分：

- **主张（claim, C）**：被主张的结论——「你要论证的那个观点」。
- **根据（data / grounds, D）**：支持主张的事实或证据——「你凭什么这么说」。
- **保证（warrant, W）**：从根据到主张的**推理规则**——「为什么这些根据能推出这个主张」。

以论证「小李该升职，因为他这个季度业绩第一」为例：

- 主张 C：小李该升职。
- 根据 D：他这个季度业绩第一。
- 保证 W：业绩第一的员工应该升职（一条推理规则）。

**保证是图尔敏模型的关键创新**：古典逻辑把「根据 → 结论」的跳跃当作默认，图尔敏指出这中间有一条**推理规则**（保证）——而这条规则常常是隐含前提、也往往是争论的焦点。这正好呼应了上一课《隐含前提的挖掘》。

## 2 三个辅助成分

真实论证还会带三个辅助成分：

- **支援（backing, B）**：保证的证据——「为什么这条规则成立」。保证 W 说「业绩第一该升职」，支援 B 是「公司制度写明业绩第一者优先晋升」。
- **限定（qualifier, Q）**：结论的强度限定词——「很可能」「大概」「几乎必然」。「小李**很可能**该升职」里的「很可能」。
- **反驳（rebuttal, R）**：例外情况——「除非……」「但不包括……」。「除非小李这个季度有重大违纪」。

图尔敏模型的全貌（六个成分的关系）：

```
        保证 W（业绩第一→升职）──支援 B（公司制度）
        │
根据 D ──→ [限定 Q] 主张 C
（业绩第一）         （很可能）
        │
      反驳 R（除非重大违纪）
```

**图尔敏模型的革命性**：它把「论证」从「前提 + 结论」的两段式，升级为「根据 + 保证 + 支援 + 限定 + 反驳」的多层结构——论证不再是封闭的推演，而是**带限定、带例外、可攻防的开放结构**。这更贴近真实世界的论证形态。

## 3 图尔敏模型 vs 三段论

对照图尔敏模型与古典三段论，差异一目了然：

| 维度 | 三段论 | 图尔敏模型 |
| --- | --- | --- |
| 成分 | 前提 + 结论 | 主张、根据、保证、支援、限定、反驳 |
| 推理规则 | 隐含在大前提里 | 显式为「保证」并单独评估 |
| 结论强度 | 必然 | 允许「限定」（很可能） |
| 例外 | 不考虑 | 显式「反驳」（除非…） |
| 适用域 | 形式逻辑、数学 | 法律、伦理、政策、日常 |

**辨析｜易错点：** 图尔敏模型不是「比三段论高级」，而是**服务于不同目的**。三段论追求「演绎必然」，适合数学与形式逻辑；图尔敏模型承认「论证通常带限定与例外」，适合真实世界的论辩。把数学证明硬套图尔敏模型很别扭（数学的保证是公理，不需要「很可能」限定）；把政策辩论硬套三段论也很别扭（政策结论总是有条件、有例外的）。**选模型看场合**。

## 4 公式解析：图尔敏模型的逻辑结构

把图尔敏模型写成条件句的形式，它与经典论证的关系就清楚了：

$$
D \land W \land B \land \neg R \;\Rightarrow\; Q\,C
$$

- **D（根据）**：事实证据——条件句的前件。
- **W（保证）**：推理规则——把 D 连接到 C 的桥：$W: D \to C$。
- **B（支援）**：保证的后盾——为什么 W 成立。
- **R（反驳）**：例外条件——如果 R 成立，W 的桥断裂：$R \to \neg(W)$。
- **Q（限定）**：结论的强度——「很可能」表示结论是概率性的：$Q$ 是 C 的置信修饰。
- **整体**：在「根据 + 保证 + 支援」成立、且「无反驳」时，才推出（带限定的）主张。

逐项拆解这个公式的直觉：

- **W 是核心**：没有保证 W，D 只是孤立事实，推不出 C。「业绩第一」如果不接「业绩第一该升职」的规则，就只是陈述。
- **R 是保险**：反驳条件 R 是论证的「例外条款」——它让论证更诚实（承认边界），也让评估更全面（检查例外是否成立）。
- **Q 是诚实**：限定词承认「大多数论证不是必然的」——它把「很可能」写进结构，而不是假装绝对。

## 5 图尔敏模型的应用

图尔敏模型从哲学走向了广泛的应用：

- **法学论证**：法庭辩论的「主张—证据—法律规则（保证）—例外（反驳）」结构，几乎就是图尔敏模型的教科书示范。
- **写作与修辞**：议论文教学用图尔敏模型训练「提出主张、给出根据、解释保证、考虑反驳」。
- **AI 论证挖掘**：计算论证（computational argumentation）用图尔敏框架标注在线争论、检测论证结构——这是自然语言处理里「论证挖掘」任务的理论基础。

<span class="marginnote">图尔敏模型与「从极限到大模型」的接口很有趣：现代 LLM 的论证生成、辩论 AI、可解释性里的「推理链」都在试图重构「根据 → 保证 → 主张」的结构——图尔敏 1958 年的框架成了计算论证学的语义骨架。</span>

## 6 例题演练

**例 1**：用图尔敏六成分分析「小李该升职，因为他业绩第一」。

- 主张 C：小李该升职；根据 D：业绩第一；保证 W：业绩第一者应升职；支援 B：公司制度写明；限定 Q：很可能；反驳 R：除非有重大违纪。六成分齐备，论证完整。

**例 2**：图尔敏模型与三段论的核心差异是什么？

- 三段论：前提+结论、结论必然、无例外；图尔敏：六成分、结论带限定（很可能）、显式反驳（除非…）、保证单独评估。图尔敏更适合法律、政策等真实论证。

**例 3**：为什么保证（W）是图尔敏模型的关键？

- 古典逻辑默认「根据→结论」的跳跃，图尔敏把它显式化为推理规则 W——而 W 往往是隐含前提、也往往是争论焦点（与「隐含前提」一课呼应）。

**本节要点自检**：$D\land W\land B\land\neg R \Rightarrow Q\,C$——根据+保证+支援+无反例，推出带限定的主张。

## 7 小结

- 图尔敏模型六个成分：**主张、根据、保证、支援、限定、反驳**。
- **保证（W）**是核心创新：把「根据到主张」的推理规则显式化，往往也是争论焦点。
- 与三段论对照：**三段论求必然，图尔敏承认限定与例外**——适用域不同。
- 结构公式：$D \land W \land B \land \neg R \Rightarrow Q\,C$——根据+保证+支援+无反例，推出带限定的主张。
- 应用：法学、写作教学、AI 论证挖掘。
