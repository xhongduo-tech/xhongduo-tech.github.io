## 为什么从论证的辨识开始

前面的十一篇教了「什么样的推理有效」「什么样的推理是谬误」——但这一切的前提是：**你得先认出一个论证**。<span class="marginnote">辨识的实质是找「支持关系」——被支持的是结论，支持它的是前提；指示词只是路标。</span>
日常文本里，论证混在叙述、说明、感慨和广告里，前提与结论常常被句子结构打乱。
本课学习论证分析的第一项技能：**辨识**——判断一段话里有没有论证、论证的前提与结论分别是什么。
工具是两类指示词，以及「这段文字在支持什么主张」的判断。

## 1 什么是论证、什么不是

**论证（argument）**：一组陈述，其中一些（前提）被提出来支持另一个（结论）。论证的识别标志：**有人试图用理由支持一个主张**。

与之相对，很多文本**不是论证**：

**报告（report）**：「昨天的会议讨论了预算，最后通过了方案。」——只陈述事实，不试图证明什么。
**说明（explanation）**：「植物是绿色的，因为它们含有叶绿素。」——解释一个已知现象的原因，不争论「植物是否绿色」。说明与论证容易混淆，区分关键：**论证为「有争议的主张」找支持，说明为「已知的事实」找原因**。
**举例/描述/抒情**：「大海真美啊！」——不构成论证。

**辨析｜易错点：** 一段话里可能混着论证与非论证成分。「因为」可能是论证的指示词，也可能是说明的引导词。「植物绿因为叶绿素」是说明（没有人争「植物绿不绿」）；「该买这辆车因为它省油」是论证（「该买」是有争议的主张）。**先问「有没有一个被支持的、可争的主张」，再看「有没有理由在支持它」**。

## 2 前提指示词与结论指示词

指示词是辨识论证的「路标」。常见分类：

| 前提指示词 | 结论指示词 |
| --- | --- |
| 因为、由于、既然 | 所以、因此、因而 |
| 理由是、其依据是 | 由此可见、由此可见 |
| 考虑到、鉴于 | 故、故知、于是 |
| 由……可知 | 这表明、这说明 |
| 从……来看 | 因此可以推出 |

**前提指示词**通常引出「理由」：「**因为**下雨，所以地湿」——「下雨」是前提。
**结论指示词**通常引出「主张」：「因为下雨，**所以**地湿」——「地湿」是结论。

**用法提示**：指示词不是万无一失的。同一个「因为」有时引说明、有时引前提；有时前提和结论的顺序完全倒置（「地湿了，因为下雨」——结论在前，前提在后）。识别时以**逻辑关系**为准，指示词只是辅助线索。

<span class="marginnote">把指示词当「路标」而不是「铁律」：路标指向大致方向，最终判断要看句子的逻辑功能——「这段在支持什么？」。顺序可以颠倒（结论先说）、指示词可以省略（「天下雨。我带伞了。」——论证要重构才能看出），真正的辨识能力来自「找主张 + 找理由」的思维习惯。</span>

## 3 重构：把论证写成标准形式

辨认出论证后，下一步是**重构（reconstruction）**——把自然语言的论证改写成标准形式：

1. 找出**结论**，放在最后；
2. 找出**前提**，按序放在前面；
3. 补全**省略的成分**（隐含前提——下一课专讲）；
4. 统一**用语**，消除歧义。

以「你不该买那个包，因为太贵了，而且你已经有三个了」为例，重构：

- 前提 1：那个包太贵了。
- 前提 2：你已经有三个包了。
- （隐含前提：太贵且已有多个时不该再买。）
- 结论：你不该买那个包。

重构的价值：**只有重构后的论证才能被准确评估**。评估「前提是否可信」「推理是否有效」都要对着标准形式做——自然语言的原文常常把前提和结论混在一起。

## 4 公式解析：论证的「支持」结构

把论证的结构形式化，可以看清「辨识」的实质。一个论证可写为：

$$
P_1, P_2, \dots, P_n \;\Rightarrow\; C
$$

其中 $P_i$ 是前提，$C$ 是结论，$\Rightarrow$ 是「支持」关系。

- **第一步，读目标**：一句话里有没有「$C$」——一个被主张的、可争论的断言。
- **第二步，找理由**：有没有 $P_i$——被提出来支持 $C$ 的陈述。
- **第三步，验支持**：$P_i$ 是否真的**指向** $C$，还是只是伴随信息（背景、修辞、感叹）？「今天天气真好，不过你还是得还钱」——「天气好」不指向「还钱」，它不是前提。
- **第四步，定结论**：被「支持」的那个主张是结论；支持它的陈述是前提。

**辨识的实质**：不是找句子，而是找「**支持关系**」。一段话是论证，当且仅当存在「前提支持结论」的关系。指示词是辅助，支持关系是本质。

## 5 辨识的实战

把技能用在混合文本上。读这段：

「老张反对扩建图书馆。他觉得太费钱，而且现在的馆已经够用了。」

- 结论：老张反对扩建图书馆。
- 前提 1：扩建太费钱。
- 前提 2：现在的馆已经够用。

再看一段「非论证」：「老张反对扩建图书馆。他是本地人，在图书馆工作了二十年。
」——后半句只提供背景信息，没有理由支持「反对」这一主张——不是论证（至少不是完整论证）。

**辨析｜易错点：** 判断「有没有论证」最忌**过度解读**——把普通叙述硬读成论证。宽容原则（上一课）也适用于此：**文本没给出理由时，不要替它脑补理由**；但若文本明显省略了前提（日常说话常态），则应识别为「省略论证」（enthymeme），下一课教怎么补。

## 6 例题演练

**例 1**：区分论证与说明：「因为下雨，所以地湿」vs「因为叶绿素，所以叶子是绿的」。

- 前者是论证：「地湿」是可争的主张，用「下雨」支持；后者是说明：没人争「叶子是绿的」，「叶绿素」解释其成因。论证支持有争议的主张，说明解释已知的事实。

**例 2**：指示词失效的例子。

- 「因为」也可引说明（「植物绿因为叶绿素」）；结论可以先说（「地湿了，因为下雨」——结论在前）。指示词是路标不是铁律，最终看「有没有支持关系」。

**例 3**：重构论证的标准形式包含哪几步？

- 找结论放最后、排前提在前、补省略成分、统一用语消歧义。重构后才能准确评估——原句常把前提结论混在一起。

**本节要点自检**：辨识的实质是找「支持关系」；重构是评估的前提；宽容原则不替文本脑补理由。

## 7 小结

- **论证**：前提支持结论的陈述结构；报告、说明、描述不是论证。
- **指示词**：前提指示词（因为、由于）与结论指示词（所以、因此）是路标，不是铁律。
- **重构**：找结论 → 排前提 → 补省略 → 统一用语——评估前必先重构。
- 辨识实质：**找「支持关系」**，不是找句子——被支持的是结论，支持它的是前提。
- 宽容原则：不替文本脑补理由；省略的论证识别为省略三段论。
