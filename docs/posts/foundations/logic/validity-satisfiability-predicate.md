# 谓词逻辑的有效式与可满足性

<div class="epigraph">
<p>一个公式是逻辑真理，当且仅当它在每一个可能的解释下都为真。</p>

## 为什么从语义开始

在命题逻辑里，「有效」「可满足」靠真值表定义：穷举原子命题的真假赋值。
但谓词逻辑的原子命题有内部结构——$P(x)$ 里的 $x$ 从哪来？
$P$ 指什么性质？真值表那一套立刻失效了。本课引入谓词逻辑的语义核心：**模型（model）与解释（interpretation）**。
一个公式的「真假」必须在某个「世界」里评估——这个世界规定了论域、谓词的外延和常项的指称。
理解模型，是理解谓词逻辑一切语义概念（有效性、可满足性、后承）的前提。

## 1 模型：一个「可能世界」的完整规格

**模型（model）**：一个结构 $\mathcal{M} = \langle D, \mathcal{I}\rangle$，包含两部分：

- **论域（domain）$D$**：一个非空集合，是量词与个体词的取值范围——「这个世界里有哪些东西」。
- **解释（interpretation）$\mathcal{I}$**：一个指派，规定每个**个体常项**对应论域里的哪个对象、每个**谓词**对应论域上的哪个性质或关系、每个**函数符号**对应哪个运算。

例如一个模型可以这样规定：论域 $D = \{\text{苏格拉底}, \text{柏拉图}, \text{石头}\}$；
$s$ 指苏格拉底；谓词 $H$（是人）的解释是 $\{\text{苏格拉底}, \text{柏拉图}\}$；
谓词 $D$（会死）的解释是 $\{\text{苏格拉底}, \text{柏拉图}\}$。
在这个模型里，$H(s) \to D(s)$ 为真。

<span class="marginnote">「模型」这个词沿用数学的结构概念：一个模型就是一个装着对象和关系的「小宇宙」。给定模型 $\mathcal{M}$，任何闭公式都有确定的真值——谓词逻辑的语义就是「在某个模型里求值」的过程。这也解释了为什么叫「模型论」：一阶逻辑研究的是公式与模型之间的满足关系。</span>

## 2 在模型中求值

一个闭公式在模型 $\mathcal{M}$ 里的真值按结构递归确定：

**原子公式**：$P(a)$ 为真，当且仅当 $\mathcal{I}(a)$ 属于 $\mathcal{I}(P)$——即「$a$ 指称的对象落在 $P$ 解释的那个集合里」。
**联结词**：与命题逻辑完全一致（$\land$ 全真才真、$\neg$ 真变假等）。
**量词**：$\forall x P(x)$ 为真，当且仅当 $P$ 对论域 $D$ 中**每一个**对象都真；$\exists x P(x)$ 为真，当且仅当 $P$ 对 $D$ 中**至少一个**对象真。

量词求值的「域」是**论域**，不是全世界。这一点极其重要：「所有人都会死」在一个只装着三个人和一个石头的模型里求值，只要那三个人会死就为真——石头不影响全称句。

**辨析｜易错点：** 全称句在**空论域**上的处理是逻辑学的技术细节。经典逻辑通常**约定论域非空**，否则「所有人都…」和「有些人…」会因无对象可谈而产生奇怪的真值。数学里几乎所有讨论都在非空结构上展开，我们沿用非空论域约定。

## 3 有效性、可满足性与逻辑真理

有了模型，谓词逻辑的语义概念就能精确定义：

**可满足（satisfiable）**：存在一个模型 $\mathcal{M}$ 使公式 $A$ 为真。$\mathcal{M}$ 就叫 $A$ 的**模型**。
**逻辑有效 / 逻辑真（logically valid / tautology）**：公式 $A$ 在**每一个**模型中都为真，记作 $\models A$。
**矛盾式（contradiction）**：没有任何模型使 $A$ 为真。

与命题逻辑的关键差别：谓词逻辑的「每一个模型」不是有限的 $2^n$ 种赋值，而是**无穷多种可能世界**——论域可以任意大、谓词解释可以任意变。
因此有效性不再是查表，而是一个涉及无穷多个模型的断言。

看几个例子体会层次：

$\forall x P(x) \to \exists x P(x)$：**有效**——若所有对象都满足 $P$，且论域非空，则必有一个对象满足 $P$。
$\forall x P(x) \lor \neg\forall x P(x)$：**有效**——排中律的形式，任何模型里必有一侧为真。
$\forall x P(x) \to P(a)$：**有效**——全体都满足 $P$，则常项 $a$ 指称的对象也满足。
$\exists x P(x) \land \exists x Q(x)$：**可满足但非有效**——有些模型同时有 $P$ 对象和 $Q$ 对象，有些模型没有。

<span class="marginnote">最后一行提醒我们：谓词逻辑的判定远比命题逻辑难。命题逻辑查有限张表即可，谓词逻辑却要考察无穷多个模型。本课先立住「模型」这个语义概念，<strong>「一阶逻辑的不可判定性」</strong>那一课将说明：不存在一个通用算法能在有限时间内判定任意公式是否有效。</span>

## 4 公式解析：验证一个谓词逻辑有效式

验证「$\forall x P(x) \to \exists x P(x)$ 有效」，需要证明它对任意模型都真，而不是查表：

**第一步，任取模型**：设 $\mathcal{M} = \langle D, \mathcal{I}\rangle$ 是任意模型，$D$ 非空。
**第二步，假设前件**：若 $\forall x P(x)$ 在 $\mathcal{M}$ 中为真，则 $P$ 的解释包含论域中**每一个**对象。
**第三步，取一个对象**：因为 $D$ 非空，取 $d \in D$。由前件，$d$ 满足 $P$。
**第四步，得结论**：存在对象满足 $P$，所以 $\exists x P(x)$ 为真。前件真则后件真，公式在 $\mathcal{M}$ 中为真。
**第五步，任意化**：$\mathcal{M}$ 是任意的，故公式在所有模型中真，即有效。

注意证明的结构：**没有枚举，只有「任取模型 + 条件推理」**。这正是谓词逻辑语义论证的标准姿态——你无法一个个检查无穷模型，只能对「任意模型」作一般性推理。<span class="marginnote">这个「任取—假设—推理—任意化」的四步骨架，与数学里证明「对任意 $\varepsilon>0$…」完全相同。谓词逻辑的语义证明与数学证明用的是同一种肌肉记忆。</span>

## 5 例题演练

**例 1**：$\exists x P(x) \to \forall x P(x)$ 是否有效？

- 无效。取论域 $D=\{a,b\}$，$P$ 的解释只含 $a$：$\exists xP(x)$ 真而 $\forall xP(x)$ 假——反模型。这正是「有些是」推不出「所有都是」的模型论表达。

**例 2**：$\forall x(P(x) \lor \neg P(x))$ 是否有效？

- 有效。任取模型与论域中任一对象 $d$：$P(d)$ 与 $\neg P(d)$ 必有一真（二值），故析取恒真，全称成立。这是排中律的量词版。

**例 3**：可满足与有效的关系是什么？给一个「可满足但非有效」的例子。

- 可满足 = 至少一个模型真；有效 = 一切模型真。有效是可满足的强条件。$\exists x P(x)$ 可满足（有的模型论域非空且 $P$ 有元素）但非有效（有的模型 $P$ 空）。

**例 4**：$\exists x P(x) \to \exists x(P(x)\lor Q(x))$ 是否有效？

- 有效。若存在 $x$ 使 $P(x)$ 真，则该 $x$ 也使 $P(x)\lor Q(x)$ 真——析取引入。这是「存在量词的单调性」：加强谓词不改变存在性。

**例 5**：为什么「有效性要考察一切模型」比命题逻辑的查表难？

- 命题逻辑的赋值有限（$2^n$ 个），可穷举；一阶逻辑的模型无穷多（论域可任意大、谓词解释任意变），无法穷举。有效性成了一个关于「一切可能世界」的断言——这正是不可判定性的根源。

**延伸思考**：模型的概念把「真」相对化了——公式在不同的模型里可以取不同真值。这个相对化是模型论（model theory）的起点，也是数据库查询、程序语义「在一个结构里求值」的数学基础。

**例 4**：为什么「有效」在谓词逻辑里比命题逻辑难判定？

- 命题逻辑的有效性查 $2^n$ 张真值表即可；谓词逻辑要考察无穷多种模型（论域、解释任意变）——没有有限枚举可依赖，这是不可判定性的根源。

**延伸思考**：模型是谓词逻辑语义的核心——可满足=有模型，有效=一切模型皆真，反模型=无效的证据。

**本节要点自检**：量词在论域上求值；有效性要考察一切模型；反模型是证明无效的钥匙。

## 6 小结

- **模型** $\mathcal{M}=\langle D,\mathcal{I}\rangle$ 由**非空论域**与**解释**组成，是一个「可能世界」的完整规格。
- 量词在**论域**上求值：$\forall$ 对域中所有对象，$\exists$ 对域中某对象。
- **可满足** = 存在模型使其真；**有效** = 一切模型皆真；**矛盾** = 无模型使其真。
- 谓词逻辑的「一切模型」是无穷多种可能世界，有效性不能靠有限查表。
- 验证有效式的方法：任取模型、假设前件、推理、任意化收尾。
