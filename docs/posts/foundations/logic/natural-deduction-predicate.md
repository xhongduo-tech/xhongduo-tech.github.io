## 为什么从完整证明开始

现在积木齐了：命题逻辑的规则（MP、MT、CP、IP 等）加上量词的四条规则（UI、EI、EG、UG）。
本课把它们组合起来，进行谓词逻辑的**完整自然演绎证明**。
与命题逻辑相比，谓词逻辑的证明多了两个技术难题：**量词何时消去、何时引入**，以及**新常项与任意常项的管理**。
本课通过三个递进的例子，把「证明策略」这套手艺教给你——它不是死记规则，而是知道每一步为什么走。

## 1 策略总纲：量词处理的顺序

谓词逻辑证明的基本策略，可以总结成四句话：

- **要证全称结论，先设一个任意常项**：目标若以 $\forall x$ 开头，通常用 CP 或直接设任意 $a$，证出 $P(a)$ 后 UG 收尾。
- **要消去存在前提，先用 EI 引入新常项**：前提里有 $\exists x$，先 EI 得到 $P(c)$（$c$ 全新），再往下推。
- **要证存在结论，最后用 EG**：一旦推出了某个实例 $P(a)$，就可用 EG 得到 $\exists x P(x)$。
- **量词之前先做命题逻辑**：通常先把量词消掉，把问题转化为命题逻辑的推演，完成后再把需要的量词加回去。

这四句话几乎覆盖了所有证明。真正的技巧在于：**知道什么时候设任意常项、什么时候起新常项**——前者的目标是 UG，后者的来源是 EI。

## 2 例一：一个典型的全称结论

证明：$\forall x(P(x) \to Q(x)),\; \exists x P(x) \;\vdash\; \exists x Q(x)$。

直观：所有人都… 不，重来——所有满足 $P$ 的满足 $Q$，且存在 $P$ 对象，则存在 $Q$ 对象。

1. $\forall x(P(x) \to Q(x))$（前提）
2. $\exists x P(x)$（前提）
3. $P(c)$（由 2，EI，$c$ 新）
4. $P(c) \to Q(c)$（由 1，UI）
5. $Q(c)$（由 4、3，MP）
6. $\exists x Q(x)$（由 5，EG）

三步量词、两步命题逻辑，完成。注意 EI（第 3 行）必须**先于** UI 使用：如果先对全称句 UI 取 $c$，那 $c$ 就不再是「新」的了，EI 会失败。
**策略要点：先 EI 起名，再 UI 引用同一个名字。
**

## 3 例二：条件证明与量词相遇

证明：$\forall x(P(x) \to Q(x)) \;\vdash\; \forall x P(x) \to \forall x Q(x)$。

结论是一个蕴涵，用 CP：假设 $\forall x P(x)$，目标推出 $\forall x Q(x)$。

1. $\forall x(P(x) \to Q(x))$（前提）
2. $\forall x P(x)$（假设，CP 用）
3. $P(a)$（由 2，UI，$a$ 任意）
4. $P(a) \to Q(a)$（由 1，UI）
5. $Q(a)$（由 4、3，MP）
6. $\forall x Q(x)$（由 5，UG，$a$ 任意）
7. $\forall x P(x) \to \forall x Q(x)$（由 2—6，CP）

第 3 步取 $a$ 时它必须是**任意**的，因为第 6 步要靠 UG 收尾。为什么可以取任意 $a$？因为第 2 步的假设 $\forall x P(x)$ 对所有个体都成立，$a$ 取谁都行——这正是任意常项合法的来源。<span class="marginnote">把例一和例二对照：例一结论是 $\exists$，用 EI 起新名、EG 收尾；例二结论是 $\forall$，用「任意常项 + CP + UG」。两套模式几乎是谓词逻辑证明的全部套路——一个管「有个」，一个管「所有」。</span>

## 4 例三：反证法处理否定量词

证明：$\neg\exists x P(x) \;\vdash\; \forall x \neg P(x)$（存在否定的对偶）。

结论是 $\forall x \neg P(x)$，自然用「任意常项 + IP（间接证明）」。

1. $\neg\exists x P(x)$（前提）
2. $P(a)$（假设，IP 用；$a$ 任意）
3. $\exists x P(x)$（由 2，EG）
4. $\bot$（由 3、1，矛盾）
5. $\neg P(a)$（由 2—4，IP）
6. $\forall x \neg P(x)$（由 5，UG，$a$ 任意）

第 2 步假设 $P(a)$，推出与 $\neg\exists x P(x)$ 的矛盾，于是 $\neg P(a)$；$a$ 任意，UG 得全称。这正是量词否定律 $\neg\exists xP \equiv \forall x\neg P$ 的证明版——我们用自然演绎重新「发现」了它。<span class="marginnote">三个例子展示了谓词逻辑证明的全部技术组合：<strong>EI + EG（处理存在）、任意常项 + UG（处理全称）、CP 与 IP（处理蕴涵与否定）</strong>。掌握了这三板斧，绝大部分谓词逻辑证明都能拆解为它们的组合。</span>

## 5 公式解析：证明策略的诊断表

把「看到什么形式，就用什么招」整理成一张策略表：

| 目标/前提的形态 | 首选策略 | 注意 |
| --- | --- | --- |
| 目标以 $\forall x$ 开头 | 设任意 $a$，证 $P(a)$，UG | $a$ 必须保持任意 |
| 目标以 $\exists x$ 开头 | 证出某实例 $P(a)$，EG | 实例可来自前提或假设 |
| 前提有 $\exists x$ | 先 EI 起新常项 $c$ | 越早 EI 越好，勿用旧名 |
| 目标是蕴涵 $A \to B$ | CP 假设 $A$ | 与命题逻辑相同 |
| 目标是否定 $\neg A$ | IP 假设 $A$ 求矛盾 | 常配合量词否定律 |
| 前提是 $\forall x$ | UI 落到需要的常项 | 一般等 EI 之后再取 |

**逐项拆解要点**：全称结论的钥匙是「任意性」，存在前提的钥匙是「新颖性」，蕴涵与否定则复用命题逻辑的 CP/IP。写证明前先「读目标」：目标长什么样，决定你第一步怎么走。这是谓词逻辑证明与命题逻辑证明最大的不同——命题逻辑规则直接可用，谓词逻辑要先定策略、再动规则。<span class="marginnote">策略表里的每一行，都可以在例一、例二、例三里找到对应。写完整证明的熟练度，本质是对这张表反射弧的训练。</span>

## 6 例题演练

**例 1**：证明 $\forall x(P(x) \to Q(x)) \vdash \forall x\neg Q(x) \to \forall x\neg P(x)$。

- 用 CP 假设 $\forall x\neg Q(x)$；取任意 $a$，$\neg Q(a)$（UI）；$P(a)\to Q(a)$（UI 前提）；由否定后件得 $\neg P(a)$；$a$ 任意，UG 得 $\forall x\neg P(x)$；撤假设完成。

**例 2**：证明 $\exists x(P(x) \land Q(x)) \vdash \exists x P(x) \land \exists x Q(x)$。

- EI 得 $P(c)\land Q(c)$；合取消去分别得 $P(c)$、$Q(c)$；EG 分别得 $\exists xP(x)$、$\exists xQ(x)$；合取引入完成。注意反向不成立（两个存在未必同时由同一个对象满足）。

**例 3**：为什么「要证全称结论」通常先设任意常项？

- 因为 UG 要求常项任意，而任意性要在「引入时」就保证。先设任意 $a$ 证明 $P(a)$，最后才能用 UG 收尾——顺序错了，任意性就没了。

**本节要点自检**：先 EI 起名再 UI 引用；全称结论设任意常项、UG 收尾；存在结论找实例、EG 收尾。

## 7 小结

- 谓词逻辑证明 = 命题逻辑规则 + 四条量词规则，核心是**量词处理的时机**。
- 总策略：**先 EI 起名、再 UI 引用；全称目标设任意常项、UG 收尾；存在目标找实例、EG 收尾**。
- 先消量词、做命题逻辑推演、再按需加回量词——量词之前先把问题化简。
- CP/IP 与命题逻辑完全一致，但常与任意常项、否定量词律配合使用。
- 策略诊断表：目标/前提的形态决定首选战术。
