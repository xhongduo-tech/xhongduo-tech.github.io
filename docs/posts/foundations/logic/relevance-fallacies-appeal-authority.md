# 相干谬误：诉诸权威、诉诸大众、诉诸无知

<div class="epigraph">

## 为什么从这三种谬误开始

上一课的人身、情感、武力靠「压迫」让人屈服，本课的三位靠「借力」让人信服：**诉诸权威**（借专家之名）、**诉诸大众**（借人群之势）、**诉诸无知**（借无人能证之机）。<span class="marginnote">相关谬误的识别核心是「前提与结论的相关性」——来源（权威/大众/无知）提供的是「可信度线索」，不是「结论为真的证据」。</span>
它们的共同点是**把「来源的可靠性」错当成「结论的证据」**——专家、多数、无证据都可能是线索，但都不是结论为真的证明。
这三种谬误尤其擅长伪装成理性，识别它们需要更精细的「相关性」判断。

## 1 诉诸权威：权威有边界

**诉诸权威（appeal to authority）**：以「某权威这样说」作为结论成立的依据，而不审查论证本身。

标准的谬误形态：

**无关权威**：「著名演员说这款牙膏最好。」——演员在演技上是权威，在口腔医学上不是。
**越界权威**：「这位诺贝尔物理学家支持这种保健品。」——物理权威不覆盖营养学。
**匿名权威**：「专家研究表明……」——不指明是谁、哪项研究、怎么做的。

**但诉诸权威并非总错**：引用权威是科学和日常生活的正常部分——「按照世界卫生组织的建议接种疫苗」是完全合理的。关键在于区分：

| 合理的权威引用 | 诉诸权威谬误 |
| --- | --- |
| 权威在该领域 | 权威在无关领域 |
| 权威有共识（非孤证） | 权威孤立或被否定 |
| 引用是可核实的 | 匿名、无法核实 |
| 权威作为线索，还要看依据 | 权威本身代替了依据 |

**辨析｜易错点：** 诉诸权威的边界不是「是否提到专家」，而是「权威的可靠性是否**替代了论证**」。合理引用：权威的可信度 + 可核实的依据；谬误：权威的招牌代替了依据。真正的坏形式是「因为他说了，所以对」——而不问他说得对不对、凭什么说。

## 2 诉诸大众：人多不等于理对

**诉诸大众（appeal to the people）**，也叫**从众谬误（bandwagon fallacy）**：以「大家都这么认为/这么做」作为结论成立的依据。

「这款手机销量第一，所以它是最好的。」
「大家都用这个方案，你还犹豫什么？」

**为什么是谬误**：「多数人相信」描述的是**社会事实**，不是**真假证据**。历史上多数人相信地球是平的、相信太阳绕地球转——多数信念曾长期错误。「销量第一」最多说明「很多人选择它」，不能推出「它客观上最好」。

**辨析｜易错点：** 诉诸大众与「共识作为线索」要分开。科学研究里「同行共识」是有分量的——但它之所以有分量，是因为**共识建立在可检验的证据上**，而不是因为「人多」。谬误的判定标准：**「人多」是否被当作结论的直接理由**。如果理由只是「大家都这样」，没有独立的证据支撑，就是诉诸大众。

<span class="marginnote">诉诸大众的现代形态是「社交证明」（social proof）营销——「10 亿人都在用」「全网最火」。社会心理学（第一级《心理学基础》）早已证明从众压力的强大，但这正是它危险的原因：<strong>利用从众心理推出的结论，恰恰跳过了证据</strong>。识别它不需要心理学，只需要问「人多的证据指向结论真假了吗」。</span>

## 3 诉诸无知：没被证伪不等于真

**诉诸无知（appeal to ignorance）**：以「没有人证明 $P$ 为假（或真）」作为 $P$ 为真（或假）的依据。

- 「没有人能证明外星人不存在，所以外星人存在。」
- 「你无法证明你昨晚没偷东西，所以就是你偷的。」

**为什么是谬误**：**缺乏证据 ≠ 证据缺席的结论**。「没有证明 $P$ 假」最多说明「$P$ 未被否证」，不能推出「$P$ 真」。「没有证明 $P$ 真」也不能推出「$P$ 假」。知识的缺乏是**信息状态**，不是**事实状态**。

**辨析｜易错点：** 诉诸无知有一个正当的近亲：**举证责任**。在法庭上「无法证明有罪」→「无罪」是程序规则（无罪推定），不是「无证据即无事实」的逻辑断言。它的逻辑其实是「证据不足则按预设处理」，而不是「没证明假所以真」。区分关键：**诉诸无知把「没证明」当成「事实证据」，正当的举证责任把「没证明」当成「决策规则」**。

## 4 公式解析：三种「来源借力」的统一诊断

三种谬误可以用同一个「来源检查」框架诊断：

$$
\text{无效论证：} \quad \frac{\text{权威说 } P}{\text{所以 } P}, \quad \frac{\text{大众信 } P}{\text{所以 } P}, \quad \frac{\text{无人证明 } \neg P}{\text{所以 } P}
$$

- **第一步，找来源**：前提的信息来源是「权威」「大众」还是「无证据」——三者都不是结论本身的逻辑证据。
- **第二步，问转换**：权威/大众/无知能否**单独**决定结论真假？不能——它们只是线索，不是证明。
- **第三步，查合法性**：这些来源在什么条件下有参考价值？权威（领域相关、可核实、有共识）、大众（共识有独立证据支撑）、无知（作为举证责任规则）——**一旦越界变成「因为来源，所以结论」就是谬误**。
- **第四步，统一判据**：**前提是否提供了「为什么结论为真」的独立证据**。没有，就是相干谬误。

**核心区别**：诉诸人身、情感、武力靠「压迫」，诉诸权威、大众、无知靠「借力」——但它们破坏的都是同一个东西：**前提与结论的逻辑相关性**。

## 5 例题演练

**例 1**：什么时候「引用专家」是合理的？

- 专家在该领域、有共识而非孤证、引用可核实、权威作为线索而非替代论证。符合这四条的是合理引用，否则滑向诉诸权威谬误。

**例 2**：诉诸大众与「科学共识」的界限在哪？

- 科学共识有分量是因为它建立在可检验的证据上，不是因为它「人多」。诉诸大众把「大家都信」当作结论的直接理由——没有独立证据，只有从众。

**例 3**：「无法证明外星人不存在，所以外星人存在」错在哪？

- 诉诸无知：把「证据缺乏」当「事实证据」。没被证伪 ≠ 为真；同理没被证实 ≠ 为假。举证责任规则（无罪推定）是决策规则，不是逻辑推断。

**例 4**：为什么「AI 模型说的」不能当作诉诸权威？

- 模型不是「权威」，它的输出是统计生成、可能出错——「模型说」不构成权威引用，除非经过人工核验。评估 AI 输出更应看证据与推理，而不是「出处」。

**延伸思考**：诉诸权威、诉诸大众、诉诸无知的统一诊断——来源（权威/大众/无知）是否被当作结论的直接证据。

**例 5**：为什么「引用共识」与「诉诸大众」不同？

- 共识有价值是因为它建立在可检验证据上（可独立核实）；诉诸大众把「人多」本身当证据。判别在「有没有独立的证据支撑」，而不是「多少人认同」。

**延伸思考**：权威、大众、无知都是「来源借力」——它们可能是指标，不是结论为真的证明。

**一句话记忆**：权威、大众、无知都可能是线索，但都不是结论为真的证明——来源被当作直接证据就是谬误。

**本节要点自检**：权威/大众/无知都是「来源借力」——它们可能是指标，但不是结论为真的证据。

## 6 小结

- **诉诸权威**：权威说 ≠ 结论对——查领域相关、可核实、共识与依据。
- **诉诸大众**：人多 ≠ 理对——共识只有建立在证据上才有分量。
- **诉诸无知**：没被证伪 ≠ 为真——证据缺乏是信息状态，不是事实状态。
- 三者的统一诊断：**来源（权威/大众/无知）是否被当作结论的直接证据**。
- 边界案例：合理引权威（有依据）、共识作线索（有证据）、举证责任（是决策规则）——都不是谬误。
