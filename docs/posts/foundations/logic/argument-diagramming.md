## 为什么从图解开始

上一课能辨认并重构论证，但一个论证内部的**结构关系**——哪个前提支持哪个结论、几个前提是合作还是独立、结论能不能再当前提——用文字描述会绕晕。
本课引入**论证图解（argument diagramming）**：给每个陈述编号，用箭头画出「谁支持谁」。
图解把论证变成一张图，结构关系一目了然，也是评估论证（下一课 RSA 三角）与识别谬误的有力辅助。

## 1 论证结构的三种基本形态

按「前提如何支持结论」，论证的骨架分三种：

- **简单论证（simple argument）**：一个前提直接支持一个结论。
- **收敛论证（convergent argument）**：多个**独立**的前提分别支持同一个结论——每个前提单独就能提供支持。
- **链式论证（serial / linked argument）**：前提联合支持中间结论，中间结论再支持最终结论——一条推理链；或前提必须**合作**才能支持结论。

用图解表示（箭头从前提指向结论）：

```
简单：      1 → 2
收敛：      1 → 2 ← 3        （1、3 独立支持 2）
链式：      1 → 2 → 3        （1 支持 2，2 又支持 3）
合作（linked）：1, 2 → 3      （1 与 2 必须合起来才支持 3）
```

## 2 简单与收敛论证

**简单论证**：单个前提直接支撑结论。例：「现在下雨，所以地会湿。」编号：1「现在下雨」→ 2「地会湿」。

**收敛论证**：两个以上**互相独立**的前提，各自指向同一结论——每个前提单独就能为结论提供一定支持。例：

「我不该去那家餐厅：第一，它太贵了（1）；第二，今天有球赛我会想看（2）；
第三，朋友约了别处（3）。结论：我不该去那家餐厅（4）。
」

图解：1 → 4、2 → 4、3 → 4——三条独立的支持线，砍掉任何一条，其他仍在支持结论。
收敛论证的评估特点：**每个前提单独接受检验**，一个前提垮了不影响其他前提对结论的支持。

<span class="marginnote">收敛论证与「合作论证」的关键区别：收敛的前提<strong>各自独立成立</strong>（三个理由单独都站得住），合作的前提<strong>必须合起来才有效</strong>（像拼图，缺一块就不成立）。判别方法：<strong>把其中一个前提删掉，看剩下的是否仍支持结论</strong>——仍支持就是收敛，不再支持就是合作。</span>

## 3 链式论证：结论变前提

**链式论证（serial argument）**：一个论证的结论，充当下一个论证的前提——推理「链式」延伸。

例：「房价过高（1），所以年轻人买不起房（2）；买不起房（2），所以生育率下降（3）；
生育率下降（3），所以经济会受影响（4）。」

图解：1 → 2 → 3 → 4。每一环的结论成为下一环的前提。

链式论证与「连锁三段论」（第四篇）同构，也与「滑坡谬误」（上一课）在结构上相似——区别全在**每一环是否被有效论证**。
链式论证的评估特点：**链条的强度取决于最弱的一环**——中间任何一环的结论不成立，后面全部崩塌。

**辨析｜易错点：** 链式论证 vs 滑坡谬误：结构相同，命运相反。链式论证的每一环有独立论证（合法），滑坡谬误的每一环没有证据（谬误）。图解时特别注意：**链上的每个箭头都要单独检验**——箭头是「有效支持」还是「无证据跳跃」。

## 4 图解的操作规程

给任何文本画论证图，用统一规程：

- **第一步，编号**：给每个陈述编号（1, 2, 3, …），只给「参与论证」的陈述编号，修辞、背景、感叹不编号。
- **第二步，定结论**：找出最终结论（或每一段的结论），它是箭头汇聚的目标。
- **第三步，画箭头**：从前提指向它们支持的结论；用「编号 + 箭头」表示支持关系。
- **第四步，标结构类型**：标注每个结论是简单（单箭头）、收敛（多独立箭头）还是链式（串联）。

以一段综合文本示范：「地铁票价应该下调（1）。因为市民通勤成本太高（2），而且地铁空座很多（3）。
如果票价下调，更多人会坐地铁（4），交通拥堵就能缓解（5）。
」

图解：

```
2 → 1（独立理由）
3 → 1（独立理由）
4 → 5（链：下调→更多人→缓解）
1 → 4（链：票价下调是前提）
```

合并看：2、3 收敛支持 1；1 又作为前提支持 4；4 支持 5。整段是一个**带分支的链式 + 收敛混合结构**。<span class="marginnote">图解熟练后，论证的「形状」一眼可见：<strong>独立前提多的是「扇面结构」</strong>（收敛），<strong>前后衔接长的是「链条结构」</strong>（链式），混合论证则是扇面与链条的拼接。现代论证分析软件（如 Argument Mapping 工具）正是把这种图解搬到计算机上。</span>

## 5 公式解析：从图解到评估

图解不只是画图，它是评估的前置步骤——把「支持关系」显式化之后，评估才有靶子。把三种结构写成评估公式：

$$
\text{收敛：} \quad \text{结论强度} = \text{各独立前提强度之和（可叠加）}
$$

$$
\text{链式：} \quad \text{结论强度} \le \min(\text{各环强度})
 \quad (\text{最弱一环决定})
$$

$$
\text{合作：} \quad \text{结论强度} \le \min(\text{合作前提强度})
 \quad (\text{缺一不可})
$$

- **收敛论证**：多个独立理由，强度可叠加——一个前提弱，其他仍能撑住。
- **链式论证**：链条强度受**最弱一环**限制——正如木桶的最短板。
- **合作论证**：缺一不可——任何一个前提被推翻，整体崩溃。

这三条评估规则，是下一课「好论证的标准（RSA 三角）」的图形版：图解决了「结构对不对」，RSA 解决「前提与支持强不强」。

## 6 例题演练

**例 1**：画「该投票：候选人有经验（1）、政策合理（2）、对手不可靠（3）∴投他（4）」的图。

- 1→4、2→4、3→4：三个独立前提收敛支持同一结论——收敛论证。删掉任一前提，其他仍支持结论。

**例 2**：合作论证与收敛论证的判别方法。

- 删掉一个前提，剩下的仍支持结论→收敛；不再支持→合作。合作前提像拼图（缺一不可），收敛前提像各自独立的支撑柱。

**例 3**：链式论证为什么「最弱一环」决定整体？

- 链式论证的结论依赖每一环成立：1→2→3 中若中间结论 2 不成立，3 无从推出。强度受最短板限制——这决定了评估时要逐环检验每个箭头。

**本节要点自检**：编号→定结论→画箭头→标类型；收敛可叠加、链式看短板、合作缺一不可。

## 7 小结

- 论证结构三形态：**简单、收敛（多独立前提）、链式（结论变前提）**，外加合作前提。
- 判别收敛 vs 合作：**删掉一个前提，剩下的是否仍支持结论**。
- 链式论证：**最弱一环决定整体**——与滑坡谬误同结构、不同命。
- 图解规程：**编号 → 定结论 → 画箭头 → 标类型**。
- 图解是评估的前置：收敛可叠加、链式看短板、合作缺一不可。
