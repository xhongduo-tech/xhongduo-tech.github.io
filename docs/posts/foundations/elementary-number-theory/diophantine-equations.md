## 为什么研究丢番图方程

「方程要在整数里解」——这个朴素的约束，把代数从连续的世界拽回离散的世界。这样的方程统称**丢番图方程（Diophantine equation）**，名字来自古希腊数学家丢番图（Diophantus of Alexandria），他最早系统研究「求整数解」的问题。

丢番图方程横跨数论的每个角落：最简单的 $ax + by = c$ 在两千年前就能解；勾股方程 $x^2 + y^2 = z^2$ 蕴含了漂亮的参数化；而费马在页边写下「$x^n + y^n = z^n$ 对 $n > 2$ 无解」时，恐怕想不到这道题要等 358 年才被怀尔斯（Andrew Wiles）证明。丢番图方程是数论「最容易问出问题、最难回答问题」的领域——看似随手写下的方程，可能隐藏着最深的定理。<span class="marginnote">现代数学里丢番图方程有了更宏大的一面：希尔伯特第十问题问「能否用算法判断任意丢番图方程是否有解」，1970 年马蒂亚塞维奇（Yuri Matiyasevich）证明了这样的算法不存在——「求整数解」在算法意义上是不可判定的。这也顺便说明了数论为何如此之难：它的问句没有万能的机械化答案。</span>

## 1 线性丢番图方程

**线性丢番图方程**是最简单的一种：

$$
ax + by = c, \qquad a, b, c \in \mathbb{Z}
$$

由第一讲的 Bézout 定理，立刻得到完整的可解性准则：

**定理**：$ax + by = c$ 有整数解当且仅当 $\gcd(a, b) \mid c$。有解时，若 $(x_0, y_0)$ 是一组特解，则全部解为

$$
x = x_0 + \frac{b}{d} t, \qquad y = y_0 - \frac{a}{d} t, \qquad d = \gcd(a, b), \quad t \in \mathbb{Z}
$$

**证明**：有解「当且仅当」部分来自 Bézout：$d \mid a$ 且 $d \mid b$ 推出 $d \mid (ax + by)$，故 $d \mid c$ 必要；反之由 $ax_0' + by_0' = d$（扩展欧几里得）乘 $c/d$ 得特解。全部解的形式验证直接代入即可，而「全部」性由「两个解之差满足 $a\Delta x + b\Delta y = 0$」再除以 $d$ 得出。<span class="marginnote">求特解不必另起炉灶：第一讲的扩展欧几里得算法同时输出 $(x_0', y_0', d)$，再整体乘 $c/d$ 即得。<strong>算法与定理在这里无缝衔接</strong>——这也是为什么我们第一讲就强调 Bézout 的可构造性。</span>

**例**：解 $6x + 15y = 21$。$\gcd(6, 15) = 3 \mid 21$，有解。$6(-2) + 15(1) = 3$，乘 $7$：$6(-14) + 15(7) = 21$，特解 $(-14, 7)$。全部解：$x = -14 + 5t$，$y = 7 - 2t$。

## 2 勾股三元组

勾股方程 $x^2 + y^2 = z^2$ 是历史上最古老的丢番图方程之一（巴比伦泥板上就记有 $(3, 4, 5)$ 等解）。**勾股三元组（Pythagorean triple）**就是正整数解 $(x, y, z)$；若 $\gcd(x, y, z) = 1$，称为**本原勾股三元组（primitive Pythagorean triple）**。

**定理（勾股三元组的参数化）**：$x, y, z$ 是本原勾股三元组当且仅当存在互素的整数 $m > n > 0$（一奇一偶）使得

$$
x = m^2 - n^2, \qquad y = 2mn, \qquad z = m^2 + n^2
$$

（$x, y$ 可交换次序。）**证明思路**：设 $x$ 为偶数（或先说明 $x, y$ 一奇一偶），由 $z^2 - x^2 = y^2$ 得 $(z+x)(z-x) = y^2$。本原性迫使 $z+x$ 与 $z-x$ 互素（至多公因数 $2$，而 $y$ 为偶数时恰为 $2$），由算术基本定理，两个互素因子各自是平方数，设 $z + x = 2m^2$，$z - x = 2n^2$，解得 $x = m^2 - n^2$，$y = 2mn$，$z = m^2 + n^2$。∎

**例**：$m = 2, n = 1$ 得 $(3, 4, 5)$；$m = 3, n = 2$ 得 $(5, 12, 13)$；$m = 4, n = 1$ 得 $(15, 8, 17)$。参数 $m, n$ 走一圈，本原三元组全部出现且不重复。<span class="marginnote">参数化展示了数论的经典手法：<strong>用条件把方程「折叠」成已知结构</strong>。「$z \pm x$ 是互素的平方数」这一观察，把二次问题降维成一次问题。同样的手法在后面「两平方和定理」「四平方和定理」里会再次出现。</span>

## 3 费马大定理

**费马大定理（Fermat's last theorem）**：方程

$$
x^n + y^n = z^n, \qquad n > 2
$$

没有正整数解。费马在 1637 年研读丢番图的《算术》时，在页边写下了这段话，并声称「我发现了一个绝妙的证明，可惜页边太窄写不下」——之后三百五十年，无数数学家扑空。1995 年，**怀尔斯（Andrew Wiles）** 完成证明，其核心是将方程与椭圆曲线、模形式联系起来（Taniyama–Shimura 猜想，后称模性定理）。

对初学者，最值得看的是 $n = 4$ 的完整证明——它不需要庞然大物，用的是**无穷递降法（method of infinite descent）**。费马本人证明了 $x^4 + y^4 = z^2$ 无解，这蕴含了 $n = 4$ 的情形：

- 假设有本原解，且 $z$ 最小（良序原理保证可取）。
- 由勾股参数化，$x^2 = m^2 - n^2$，$y^2 = 2mn$，$z = m^2 + n^2$，其中 $m, n$ 一奇一偶、互素。
- 由 $x^2 + n^2 = m^2$ 再次参数化得 $m = r^2 + s^2$，$x = r^2 - s^2$，$n = 2rs$。
- 于是 $y^2 = 2mn = 4rs(r^2 + s^2)$，而 $r, s, r^2+s^2$ 两两互素，由算术基本定理它们各自是平方数：$r = u^2$，$s = v^2$，$r^2 + s^2 = w^2$。
- 得到 $u^4 + v^4 = w^2$，且 $w < z$——**找到了一个更小的反例**，矛盾。

这个「从一个反例造出一个更小的反例」的机制，是数论证明中最优雅的武器之一。<span class="marginnote">无穷递降法的精神与「最小反例」论证同出一源：先设最坏情况存在，再从它构造出更坏的情况，直到违反良序原理。它和归纳法互为表里——一个向上搭梯子，一个向下拆梯子。在《数学分析》里证明无理数、在《离散数学》里证明图论命题时，这套手法都会重逢。</span>

## 4 两平方和与四平方和

「哪些数能写成平方和？」是丢番图方程最自然的追问。

**两平方和定理（two-square theorem）**：正整数 $n$ 能写成两个整数平方之和当且仅当 $n$ 的标准分解式中，所有形如 $4k + 3$ 的素因子的指数都是偶数。特别地，**素数 $p$ 能写成 $p = a^2 + b^2$ 当且仅当 $p = 2$ 或 $p \equiv 1 \pmod 4$**。

前半由费马猜想、欧拉证明：$p \equiv 1 \pmod 4$ 时 $-1$ 是模 $p$ 的二次剩余（二次互反部分讲过 $\left(\frac{-1}{p}\right) = (-1)^{(p-1)/2}$），存在 $m$ 使 $m^2 \equiv -1 \pmod p$，再用**无穷递降**把「模 $p$ 意义下的零」提升成「真正的平方和」：反复把 $a^2 + b^2$ 的某个 $p$ 倍缩小。**例**：$5 = 1^2 + 2^2$，$13 = 2^2 + 3^2$，$17 = 1^2 + 4^2$；而 $7, 11, 19$（都是 $4k + 3$）不能写成两平方和。<span class="marginnote">「$p \equiv 1 \pmod 4 \iff p$ 能写成两平方和」是个双面线索：方向「$p$ 能写成两平方和」用到「$-1$ 是模 $p$ 的二次剩余」，方向反之则需要「有理数高斯整数的唯一分解」——两种语言，同一命题。高斯整数 $\mathbb{Z}[i]$ 的故事是《代数数论》的第一课。</span>

**四平方和定理（four-square theorem, Lagrange）**：**每个正整数都能写成四个整数的平方和**。这个定理的威力在于没有例外——$n = 7 = 4 + 1 + 1 + 1$，$n = 15 = 9 + 4 + 1 + 1$，全部都能装进四格。拉格朗日 1770 年证明，用的是欧拉的一个恒等式（把两个四平方和表示乘起来仍是四平方和表示）加上「素数是四平方和」的无穷递降。

**例**：$15 = 9 + 4 + 1 + 1 = 3^2 + 2^2 + 1^2 + 1^2$；$100 = 10^2 + 0^2 + 0^2 + 0^2$（允许 $0$）。

## 5 Pell 方程

上一节的连分数已经见过它，这里给出丢番图视角的完整叙述。**Pell 方程（Pell's equation）**

$$
x^2 - D y^2 = 1
$$

其中 $D$ 是无平方因子的正整数。它的解与 $D$ 的算术性质深刻绑定：

**定理**：$x^2 - Dy^2 = 1$ 必有非平凡整数解；所有正整数解由**基本解** $(x_1, y_1)$ 的幂生成：

$$
x_k + y_k \sqrt{D} = (x_1 + y_1 \sqrt{D})^k
$$

且基本解正是 $\sqrt{D}$ 的连分数周期末尾的渐近分数。上一节我们看到 $\sqrt2 = [1; \overline 2]$ 给出基本解 $(3, 2)$，全部解由 $(3 + 2\sqrt2)^k$ 展开。

**例**：解 $x^2 - 3y^2 = 1$。$\sqrt3 = [1; \overline{1, 2}]$，渐近分数 $\frac{1}{1}, \frac{2}{1}, \frac{5}{3}, \frac{7}{4}, \frac{19}{11}, \dots$，检验 $\frac{2}{1}$：$2^2 - 3 \times 1^2 = 1$，所以基本解是 $(2, 1)$；下一个解 $(2 + \sqrt3)^2 = 7 + 4\sqrt3$ 即 $(7, 4)$，$7^2 - 3 \times 4^2 = 49 - 48 = 1$。✓<span class="marginnote">Pell 方程在 17 世纪的欧洲被费马与拉格朗日认真研究，但解法其实早就藏在印度的<strong>chakravala 方法</strong>（婆罗摩笈多、婆什迦罗）里——这是「问题比答案流传更广」的又一例。数论的许多核心成果，东西方各自独立发现了无数次。</span>

## 6 公式解析：勾股三元组参数化

勾股三元组的参数化公式是本节最「出镜」的式子，逐项拆解：

$$
x = m^2 - n^2, \qquad y = 2mn, \qquad z = m^2 + n^2, \qquad m > n > 0, \ \gcd(m, n) = 1, \ m, n \text{ 一奇一偶}
$$

- **第一步，读懂三个表达式**：$z = m^2 + n^2$ 是半径，$x = m^2 - n^2$ 与 $y = 2mn$ 是两条直角边。验证：$(m^2 - n^2)^2 + (2mn)^2 = m^4 - 2m^2n^2 + n^4 + 4m^2n^2 = m^4 + 2m^2n^2 + n^4 = (m^2 + n^2)^2$。恒等式 $\iff$ 勾股定理。
- **第二步，为什么是 $m^2 \pm n^2$ 与 $2mn$**：这来自复数的视角——$(m + ni)^2 = (m^2 - n^2) + 2mni$，其模长平方恰为 $(m^2 + n^2)^2$。**平方一个复数，就得到一组勾股三元组**。代数与几何在此合一。
- **第三步，条件为何如此**：$\gcd(m, n) = 1$ 保证本原（边两两互素）；一奇一偶保证 $x, y$ 一奇一偶（勾股三元组必有一直角边为偶数）；$m > n$ 保证 $x > 0$。每条条件都对应「不重不漏」。
- **第四步，怎么用**：枚举 $m, n$ 即得全部本原三元组；再乘任意整数 $k$ 得到全部（非本原）三元组。**分类定理 + 平凡缩放 = 全体解**——这种「先找不可约的、再整体放大」的模式，在丢番图理论中处处可见。

## 7 小结

- **线性丢番图方程** $ax + by = c$ 可解当且仅当 $\gcd(a, b) \mid c$；全部解由一组特解加齐次项 $\left(\frac{b}{d}, -\frac{a}{d}\right)t$ 给出。
- **勾股三元组**：本原组恰为 $(m^2 - n^2, 2mn, m^2 + n^2)$，$m, n$ 互素一奇一偶。
- **费马大定理**：$x^n + y^n = z^n$（$n > 2$）无正整数解；$n = 4$ 的情形用无穷递降法可完整证明，完整定理由怀尔斯 1995 年解决。
- **平方和**：素数 $p$ 是两平方和当且仅当 $p = 2$ 或 $p \equiv 1 \pmod 4$；任何正整数都是四平方和（Lagrange）。
- **Pell 方程** $x^2 - Dy^2 = 1$：基本解来自 $\sqrt D$ 的连分数，全部解由基本解的幂生成。

在下一节，我们暂时离开「解方程」，转而给「数本身」建立一套**函数学**——研究 $n$ 的约数个数、约数和、Möbius 函数这些数论函数，以及它们的卷积与反演。
