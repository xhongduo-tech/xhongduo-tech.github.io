## 为什么从 MVT 与 SEDEX 开始

前面几篇的热液矿床都围着岩浆转，而全球相当大一部分铅锌资源，却安安静静地躺在**沉积岩**里——既没有火山，也没有侵入体。它们分两大阵营：**MVT（密西西比河谷型）**与 **SEDEX（喷流沉积型）**。这两类矿床贡献了世界铅锌储量的可观份额，也是「无岩浆成矿」的代表。<span class="marginnote">MVT 因美国密西西比河上游河谷的著名矿区得名，SEDEX 是 sedimentary exhalative（沉积喷流）的缩写。两者的共同点：都以沉积岩为容矿围岩，铅锌都靠盆地里的热卤水搬运——但它们的「出生方式」截然不同，弄清楚这组对比，就抓住了沉积成矿的核心。</span>

MVT 与 SEDEX 的对决，是矿床学里最经典的「双胞胎辨异」：看起来都是沉积岩里的铅锌矿，成因上却一个「后生」一个「同生」。这对概念直接决定找矿方向。

## 1 MVT：后生热卤水矿床

**MVT 矿床（Mississippi Valley-Type）**：产于克拉通盆地边缘的碳酸盐岩台地中，由后生热卤水沿断层、溶洞与不整合面充填交代形成的铅锌矿床。

MVT 的关键特征：

**容矿围岩**：白云岩化的石灰岩、白云岩，矿体呈脉状、鞍状（鞍状白云石）、角砾状与溶洞充填状。<span class="marginnote">MVT 矿体常与「鞍状白云石」「溶洞角砾岩」相伴——这些是碳酸盐岩被热卤水改造的标志。矿化明显晚于围岩成岩，属于<strong>后生（epigenetic）</strong>矿床，这是它与 SEDEX 最根本的差别。</span>
**成矿流体**：低温（80–150℃）、高盐度（15–30 wt%）的热卤水，来自盆地深部被蒸发浓缩的古卤水。
- **金属来源**：卤水在盆地中迁移时淋滤页岩与砂岩中的铅、锌、银。
- **硫的来源**：主要来自盆地中硫酸盐的**热化学还原（TSR）**与**细菌还原（BSR）**，常在容矿部位原位还原成硫化物。<span class="marginnote">MVT 中常出现硫同位素极负（$\delta^{34}\mathrm{S} \lt  -10‰$）的现象——这正是细菌还原硫酸盐的指纹：细菌优先利用轻硫，留下的硫化物偏负。硫同位素由此成为判别「硫来自还原作用还是岩浆」的第一判据。</span>

**分布与控矿**：MVT 矿床分布在克拉通盆地边缘的碳酸盐岩台地，常沿区域性断裂、不整合面与溶洞系统分布；北美密西西比河谷、中国川滇黔交界（会泽、天宝山）都是 MVT 的著名产区——「克拉通边缘 + 蒸发岩卤水 + 断裂系统」是 MVT 的三要素。

**重点：**MVT 是典型的**后生矿床**：矿化发生在围岩成岩之后，矿体充填在断裂、溶洞与鞍状白云石中，与岩浆活动无关——它是「盆地卤水 + 碳酸盐岩」的化学产物。

## 2 SEDEX：同生沉积喷流矿床

**SEDEX 矿床（sedimentary exhalative）**：海底热卤水沿同生断裂喷入海底，在还原的海底凹地中沉淀金属硫化物形成的层状矿床，与沉积岩层**同时（同生）**形成。

SEDEX 的关键特征：

**层状矿体**：矿体呈层状、似层状，与黑色页岩、碳酸盐岩互层，整合产出——这是它与 MVT（充填式、后生）最直观的区别。<span class="marginnote">SEDEX 的矿体「睡」在沉积岩层里，像地层一样整合；MVT 的矿体则「钻」进断裂溶洞，切割地层。一个同生、一个后生——野外看矿体与层理的关系，就能第一眼分辨两大阵营。</span>
**容矿环境**：还原的深水盆地（缺氧海底），硫化物在海底沉淀后不被氧化破坏。
**金属组合**：以锌为主、铅次之，常含银、钡，铜少——与 VMS（铜锌为主）形成对照。
**典型实例**：加拿大沙利文（Sullivan）、澳大利亚麦克阿瑟河（McArthur River）、中国甘肃厂坝与内蒙古东升庙、霍各乞。

**重点：**SEDEX 与 VMS 常被混淆，但「亲缘」不同：VMS 与海底火山作用直接相关、含铜多；SEDEX 与火山无关、由盆地卤水驱动、含锌铅多。一个是「火生」，一个是「水生」。

## 3 MVT 与 SEDEX：一对「双胞胎」的完整对比

把两个家族放进同一张表，异同立刻分明：

| 特征 | MVT | SEDEX |
| --- | --- | --- |
| 形成时代 | 后生（晚于围岩） | 同生（与沉积同时） |
| 容矿围岩 | 碳酸盐岩（白云岩、灰岩） | 细碎屑岩 + 黑色页岩 |
| 矿体形态 | 脉状、角砾状、溶洞充填 | 层状、似层状 |
| 流体 | 高盐低温卤水（80–150℃） | 高盐卤水（150–300℃） |
| 金属 | 铅锌（银） | 锌铅（银、钡） |
| 硫的来源 | 盆内硫酸盐还原 | 盆内硫酸盐还原 + 海水 |
| 实例 | 密西西比河谷、会泽 | 沙利文、麦克阿瑟河、厂坝 |

**辨析｜易错点：MVT 与 SEDEX 的「硫」和「金属」可以不同源。** 两类矿床都普遍存在「金属来自卤水、硫来自盆内还原」的分离现象——铅锌从远处淋滤而来、硫在沉淀处原位生成，二者在矿体处才「汇合」。理解了这条「异地同沉淀」，就抓住了沉积岩容矿铅锌矿的地球化学灵魂。

**共同点**：两者都**不需要岩浆**，都由**盆地卤水**搬运金属，都在**还原环境**中沉淀——「无岩浆成矿」是它们共同的身份，也是沉积成矿与内生成矿最本质的分野。

## 4 公式解析：细菌还原硫酸盐与硫化物沉淀

SEDEX 与 MVT 的核心化学，都浓缩在硫酸盐还原这条链上。细菌或热作用把硫酸盐还原为硫化物（$\ce{H2S}$）：

$$
\ce{SO4^{2-} + 2CH2O -> H2S + 2HCO3^-}
$$

对这条式子做三步拆解：

- **第一步，看反应物**：$\ce{SO4^{2-}}$ 来自盆地的海水硫酸盐或溶解石膏；$\ce{CH2O}$ 代表有机质（黑色页岩里的碳），是还原作用的「燃料」。
- **第二步，看产物 $\ce{H2S}$**：$\ce{H2S}$ 是金属的「诱饵」——它一生成，流体中的 $\ce{Pb^{2+}}$、$\ce{Zn^{2+}}$ 立即与其结合沉淀：

$$
\ce{Zn^{2+} + H2S -> ZnS + 2H+}
$$

- **第三步，看碳的意义**：**有机质丰度直接决定还原强度与硫化物产量**——黑色页岩既是 SEDEX 的容矿层，又是还原作用的燃料，这解释了为什么 SEDEX 矿体总与黑色页岩形影不离，也解释了 MVT 中硫同位素偏负的细菌指纹。

## 5 中国铅锌资源与找矿意义

把 MVT 与 SEDEX 放进中国语境，铅锌资源格局一目了然：

**中国铅锌主产区**：四川、云南、贵州交界的川滇黔地区（会泽、天宝山等 MVT 型）与甘肃、内蒙古（厂坝、东升庙等 SEDEX 型）是中国铅锌资源的两大板块。<span class="marginnote">会泽铅锌矿以「富、大、易采」著称，是川滇黔 MVT 的旗舰；厂坝、东升庙则是中国 SEDEX 的标杆。两条技术路线（后生充填 vs 同生层状）在中国都有世界级实例——矿床学课本上的分类，在这里被一一兑现。</span>

**找矿意义**：MVT 与 SEDEX 都是「无岩浆成矿」的代表，它们的找矿靶区锁定在**沉积盆地的还原相 + 断裂/同生断层系统**——化探锌铅银异常、重力与电法异常、以及黑色页岩与蒸发岩的层位组合，是圈定靶区的三把钥匙。理解了这两种矿床，就理解了为什么全球铅锌资源的答案，一半写在盆地里。

## 6 铅锌矿床家族全景

铅锌矿床不止 MVT 与 SEDEX 两种。把整个铅锌矿床家族放进一张表，才看清 MVT 与 SEDEX 的位置：

| 铅锌矿床类型 | 成矿作用 | 容矿环境 | 规模品位 | 典型实例 |
| --- | --- | --- | --- | --- |
| **MVT** | 盆地卤水充填 | 碳酸盐岩台地 | 中—大、中品位 | 密西西比河谷、会泽 |
| **SEDEX** | 海底喷流同生 | 细碎屑岩、黑色页岩 | 大、中品位 | 麦克阿瑟河、厂坝 |
| **VMS** | 海底火山热液 | 火山岩、火山沉积岩 | 中、高品位 | 见第3篇 VMS |
| **矽卡岩铅锌** | 接触交代 | 碳酸盐岩接触带 | 中、中高品位 | 见第3篇矽卡岩 |
| **热液脉型** | 断裂充填 | 各类岩石 | 小—中、高品位 | 欧洲多金属脉 |

**规律**：铅锌几乎能在所有「还原 + 硫源 + 断裂通道」的组合中成矿——硫化物的稳定性决定了铅锌对「还原环境」的绝对依赖。<span class="marginnote">铅与锌的地球化学性格（亲硫、在还原环境沉淀）贯穿全家族：无论岩浆、热液还是沉积，铅锌矿床都离不开「硫 + 还原 + 通道」三要素。这也是为什么铅锌矿床类型虽多，找矿逻辑却高度一致。</span>

**重点：**MVT 与 SEDEX 代表了「无岩浆、靠盆地卤水」的一端，与岩浆热液类（VMS、矽卡岩、脉型）形成对照——两类之间的辨析，正是本专题「沉积成矿 vs 内生成矿」这条主线的缩影，也再次呼应第1篇《元素的地球化学富集机制》里「亲硫元素握在硫手里」的判断。

## 7 小结

- **MVT**：克拉通盆地边缘的后生热卤水矿床，容矿碳酸盐岩，矿体充填断裂溶洞，铅锌 + 银，无岩浆参与。
- **SEDEX**：海底同生沉积喷流矿床，层状矿体与黑色页岩互层，锌铅 + 银钡，由盆地卤水驱动。
- 判断口诀：**矿体切割地层为 MVT（后生），矿体顺层整合为 SEDEX（同生）**。
- 金属来自卤水、硫来自盆内还原——「异地同沉淀」是两类矿床共同的地球化学机制。
- 核心反应：$\ce{SO4^{2-} + 2CH2O -> H2S + 2HCO3^-}$，有机质是还原作用的燃料。
- 中国川滇黔（MVT）与甘蒙（SEDEX）两大产区，支撑起铅锌工业的资源底盘。
