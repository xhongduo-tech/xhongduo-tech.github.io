## 为什么从视觉开始

人类获取的信息约有 80% 来自视觉。
这个数字常被引用，虽有争议，但方向不错：视觉是人脑信息量最大的入口，也是大模型最早攻克的感知通道——
图像分类、目标检测、视觉 Transformer，全是从「像素」起步。
要理解机器如何「看见」，先得理解人如何看见：从一束电磁波进入眼睛，到视网膜完成光电转换，再到枕叶皮层形成视觉，这条流水线的每一步都藏着精巧的设计。
<span class="marginnote">「80% 的信息来自视觉」是科普常见说法，彭聃龄教材引用它来说明视觉的主导地位。
精确比例虽难考证，但视觉皮层约占人类大脑皮层面积的 1/3，是神经资源投入最高的一翼。
</span>

在彭聃龄《普通心理学》的框架里，视觉是感觉章的第一大块。
本讲回答两个基础问题：**什么刺激是视觉的适宜刺激？眼睛和视网膜如何把它变成神经信号？** 下一讲谈颜色视觉，再下一讲谈视觉的空间与时间特性。

## 1 视觉的适宜刺激：一扇窄窗

光的本质是**电磁波**，但人类的眼睛只对其中极窄的一段敏感，这段波长范围大约在 **380–780 nm** 之间，称为**可见光谱（visible spectrum）**。
<span class="marginnote">380 nm 附近是紫色，780 nm 附近是红色。
波长小于 380 nm 的紫外线、大于 780 nm 的红外线，人眼一律「看不见」。
蜜蜂能看到紫外线、响尾蛇能看到红外线——
所谓「可见光」只是人类感觉道的私设，不是宇宙的客观分界。
</span>

电磁波的三个物理参数，对应着颜色知觉的三个属性：

- **波长（wavelength）** → 决定**色调**（红、橙、黄、绿、蓝、紫）。
- **强度（intensity）** → 决定**明度**（亮与暗）。
- **纯度（purity）** → 决定**饱和度**（颜色的鲜艳程度）。

记住这条对应：**物理量是波长、强度、纯度，心理量是色调、明度、饱和度。** 物理与心理的映射正是感觉研究的母题——
上一讲所说的「从物理世界到心理世界的换算」，在这里第一次有了具体的坐标。

还有一点：人眼对不同波长的敏感性并不均匀。
明亮条件下，我们对 555 nm 附近的黄绿光最敏感；
昏暗条件下，最敏感波长移向约 505 nm 的蓝绿光——
这个「明暗视觉敏感峰不同」的现象称为**浦肯野现象（Purkinje effect）**，由视锥与视杆的分工造成。
它解释了黄昏时分红色花显得发暗、蓝色花反而显得更亮：夜晚的视觉以视杆为主，而视杆对短波长更敏感。

## 2 眼睛：一套带缺陷的光学系统

光进入眼睛，先经过一套「取景 + 对焦」系统。

**角膜（cornea）**是透明的弯曲前窗，承担大部分屈光；
**虹膜（iris）**中间的**瞳孔（pupil）**像光圈一样调节进光量；
**晶状体（lens）**通过改变曲率对焦；
光线穿过玻璃体，最终成像在**视网膜（retina）**上。

一个物理常识是：**眼睛在视网膜上成的像是倒立的、左右颠倒的。** 但人「看」到的世界却是正的——
这是大脑皮层加工的结果。
视网膜只负责把光转换为神经信号，图像的正立化由后面的皮层完成。
<span class="marginnote">斯特拉顿（G. M. Stratton）做过著名的「倒视眼镜」实验：戴上把世界颠倒的棱镜眼镜几天，视觉又逐渐恢复「正立」——
说明正立是大脑习得的一种解释，不是视网膜的属性。
</span>

这套光学系统也有常见故障——
**屈光不正**：**近视（myopia）**是像落在视网膜之前（眼球过长或晶状体屈光过强），远处模糊；
**远视（hyperopia）**是像落在视网膜之后，近处模糊；
**散光（astigmatism）**是角膜曲率不对称，各方向聚焦不一。
矫正的原则只有一条：用透镜把像重新移回视网膜上。
屈光不正提醒我们，视觉的第一道关是光学问题，之后才谈得上神经加工。

瞳孔的调节也值得一提：光线强时瞳孔收缩（可小至约 2 mm），弱光时放大（可达约 8 mm），进光量相差十余倍。
但瞳孔只是「光圈」，真正的感光调节靠的是感光细胞敏感度的变化——
暗适应那 20–30 分钟的恢复，才是视觉灵敏度提升数百万倍的主力。

**辨析｜易错点：** 不少人以为「眼睛像照相机一样把世界拍下来」。
不对。
视网膜不是终点，而是一块「感光底片」，真正的「图像识别」在脑。
眼睛只提供数据，理解发生在后面几百亿神经元的加工里。
这一点对理解整个视觉章节至关重要，也解释了为什么同一张图片在不同人眼里会有不同解读。

## 3 视网膜：两类感光细胞

视网膜是视觉真正意义上的「光电转换器」，由多层细胞构成，其中直接感光的是**视锥细胞（cone）**与**视杆细胞（rod）**。

**视锥细胞（cones）**：主要在强光下工作，负责**明视觉（photopic vision）**，能分辨颜色与细节；
密度最高处是视网膜中央的**中央凹（fovea）**，中央凹只有视锥细胞、没有视杆细胞。

**视杆细胞（rods）**：对弱光极其敏感，负责**暗视觉（scotopic vision）**，但不能分辨颜色，分辨细节的能力也差；
主要分布在视网膜周边。

两类细胞的分工可以用核心对比表收拢：

| 维度 | 视锥细胞（cones） | 视杆细胞（rods） |
| --- | --- | --- |
| 功能 | 明视觉（白天） | 暗视觉（夜晚） |
| 颜色分辨 | 能（三种色素） | 不能（一种色素） |
| 细节分辨 | 高 | 低 |
| 空间分布 | 集中于中央凹 | 分布于周边 |
| 数量（约） | 650 万 | 1.2 亿 |
| 感光物质 | 视锥色素 | 视紫红质（rhodopsin） |
| 对应的视觉 | 色觉、精细视觉 | 暗视觉、粗大轮廓与运动 |

这两个数字值得品味：**视杆细胞数量是视锥的近二十倍，却几乎全部布置在周边。** 这解释了三个日常现象：夜间看星星要「斜着眼」用周边看才更清楚；
黑暗中盯住小物体反而看不清；
黄昏时分颜色变得灰暗——
因为在明暗交替的「暮光视觉」阶段，两类细胞都在工作、却都力不从心。

一个有趣的推论是：**中央凹只有视锥细胞，暗处「正眼」看物体反而看不清**，必须用余光（周边视杆）去扫。
天文学家观星时「斜着看」的姿势，正是这套生理结构的直接后果。

视网膜的感光细胞并不直接连向视神经，中间还隔着**双极细胞（bipolar cell）**与**神经节细胞（ganglion cell）**。
三层结构是：光感受器（视锥/视杆）→ 双极细胞 → 神经节细胞；
神经节细胞的轴突汇成视神经离开眼球。
一个反直觉的事实是：**光线必须先穿过神经节细胞与双极细胞，才到达最深处的感光细胞**——
视网膜是「倒装」的，感光层反而在最底层。

视网膜上还有一个特殊的点：**视神经乳头（optic disc）**是视神经纤维汇合离开眼球的出口，这里没有任何感光细胞，形成生理性的**盲点（blind spot）**。
你感觉不到它，因为大脑会用周围的信息自动补全这片空白。
<span class="marginnote">找盲点的小实验：闭上左眼，用右眼盯住下面一行字左侧的十字（＋），把页面慢慢前后移动，某一点上右侧的「·」会突然消失——
那正是它落在盲点上的时刻。
大脑的「补全」能力在《知觉》一章还会再次登场。
</span>

## 4 感光机制：视紫红质的光化学

视杆细胞里有感光物质**视紫红质（rhodopsin）**，它由一种蛋白质（视蛋白，opsin）和一种维生素 A 的衍生物（视黄醛，retinal）结合而成。
光进来时发生反应：**视黄醛吸收光能后改变形状、与视蛋白分离，视紫红质被「漂白」**，这一化学变化引起感受器电位，进而触发神经冲动。

视紫红质被漂白后需要**再合成**才能重新感光。这个「漂白—再生」循环，直接解释了两个最重要的视觉现象：

**暗适应（dark adaptation）**：从亮处进入暗处，一开始什么都看不见，随后视力逐渐恢复。
暗适应分两段：先是视锥细胞快速适应（约几分钟），再是视杆细胞慢速适应（约 20–30 分钟），视力恢复到最深。
整个过程对应视紫红质不断再合成、敏感度不断提高。

**明适应（light adaptation）**：从暗处到亮处，先是一片白亮刺眼，随后很快恢复。
明适应快得多，因为视紫红质迅速大量漂白、感受性急剧下降，几分钟内即可适应。

**夜盲症（nyctalopia）**：视紫红质再生需要维生素 A，长期缺乏维生素 A 会使人暗适应困难，这就是夜盲症的机理——
一个生化细节直接落到临床，补充维生素 A 即可缓解。

**辨析｜易错点：** 「盲点」不是「看不见某个固定的东西」。
盲点是视野中一个小缺口，因为它落在两只眼的不同位置，平时大脑用双眼信息互相填补；
即使单眼注视，大脑也会用周围背景自动补全，所以几乎无人察觉。
这与「视野缺损」（如脑损伤导致的偏盲）性质完全不同——
前者是感受器缺位，后者是皮层加工区受损。

从分子到行为，完整链条是：光 → 视紫红质漂白 → 感受器电位 → 双极细胞 → 神经节细胞产生动作电位 → 视神经传导。
值得注意的是，感光细胞对光的响应是**反向**的：光越强，感光细胞的膜电位越接近静息、输出越少。
这个反直觉的「倒相」设计，对下一讲神经节细胞「中心—周围拮抗」感受野的形成至关重要。

可以说，感受器的换能与视紫红质的再生循环，把「看见」从一句日常常识，落成了一条可测量、可解释的生化与电生理链条。
<span class="marginnote">感光机制是最能体现「心理现象有生理基础」的章节之一：一个纯化学循环（视紫红质漂白—再生）就同时解释了暗适应、明适应与夜盲症。
心理现象没有跳出生理规律，而是建立在它之上。
</span>

视锥细胞同样各含色素，但含量远低于视杆、再合成也快得多——
这正是**暗适应曲线呈两段式**的根源：第一段是视锥的快速适应（几分钟内），第二段是视杆的慢速深适应（约 20–30 分钟），两段先后启动，合成了我们观察到的完整暗适应过程。
明适应快，则是因为大量视紫红质迅速漂白、感受性骤降。

## 5 视觉传导通路：从视网膜到枕叶

感光之后，信息沿一条固定通路向皮层传递，简化的路径是：

**视网膜 → 视神经 → 视交叉 → 视束 → 外侧膝状体（LGN）→ 视放射 → 初级视觉皮层（V1，枕叶）**

这条通路里最关键的设计是**视交叉（optic chiasm）**：来自两只眼睛**鼻侧**（靠近鼻子一侧）的纤维在这里交叉到对侧，**颞侧**（靠近太阳穴一侧）的纤维不交叉。
结果是——
**左半侧视野的信息最终全部进入右半球，右半侧视野的信息全部进入左半球**。

这条通路还有一个总特点：**层级越靠上，感受野越大、加工越抽象**。
视网膜神经节细胞的感受野只是一个小圆斑，到 V1 能检测朝向与边缘，到更高层（V2、V4、颞叶梭状回）则能识别面孔与物体——
「从局部到整体、从特征到对象」的层级化加工，正是视觉系统的宏观骨架，也是卷积神经网络层层提取特征的直接原型，这部分会在第三级《计算机视觉》完整展开。
<span class="marginnote">这就是视觉的「对侧加工」。
它造成一个有趣的临床现象：右枕叶受损的病人看不见左半侧视野（偏盲），但两只眼睛本身都没有坏——
因为右枕叶接收的是来自两眼的左半侧视野信息。
</span>

![视觉传导通路示意](/images/psychology/visual-stimulus-photoreceptors-1.svg)

在视网膜与皮层之间，还有**外侧膝状体（LGN）**这个承上启下的结构。
它不只是中继站，也在做初步加工：LGN 有六层细胞，按功能分**大细胞层（magnocellular）**与**小细胞层（parvocellular）**，前者对运动敏感、后者对颜色与精细细节敏感——
视觉信号在这里就被「分路」，先分流再汇合，是视觉高效处理的又一处设计。
而视网膜神经节细胞本身已经对光斑有了**感受野（receptive field）**结构：经典的「**中心—周围拮抗**」（on-center / off-surround）——
中心被光照时兴奋、周围被光照时抑制。
这种设计让神经细胞对**明暗对比与边界**格外敏感，而不是对均匀亮光敏感。
这正为下一讲的颜色视觉、再下一讲的马赫带（侧抑制）埋下伏笔。

## 6 小结

- 视觉的适宜刺激是 **380–780 nm 的电磁波**；物理量（波长、强度、纯度）映射为心理量（色调、明度、饱和度）。
- 眼睛完成成像，**视网膜**才是真正的感光装置；**视锥细胞**管明视觉、颜色与细节（集中于中央凹），**视杆细胞**管暗视觉（分布于周边），数量约 650 万对 1.2 亿。
- 感光靠**视紫红质**的光化学「漂白—再生」循环：它同时解释了**暗适应**、**明适应**与**夜盲症**。
- 视觉通路为视网膜 → 视神经 → 视交叉 → LGN → V1；**视交叉**造成左右视野的对侧加工。
- 神经节细胞的**中心—周围拮抗**感受野，让视觉系统天生关注对比与边界——这一「边缘增强」思想在第三级《计算机视觉》的卷积边缘检测里被直接继承。

在下一节，我们给「视锥细胞负责颜色」这句话补上全部细节：颜色是如何被三色机制检测、又被拮抗机制编码的？
这就是**颜色视觉**。
