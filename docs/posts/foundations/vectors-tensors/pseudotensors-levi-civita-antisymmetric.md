## 为什么张量世界里还有「真假」之分

上一讲我们建立了「满足变换律 = 张量」的判定标准。但自然界里有一类量，变换律上**差一个正负号**——它们平时和普通张量一模一样，唯独在「镜像反射」这类翻转手性的坐标变换下多出一个负号。这类量叫**赝张量（pseudotensor）**，是张量家族里的「叛逆者」。<span class="marginnote">本讲综合 Arfken 第 2 章张量章节关于 Levi-Civita 记号、赝张量与反对称张量的内容。物理里最著名的赝向量是磁场强度 $\mathbf B$ 与角动量 $\mathbf L$——这正是「镜像世界里的物理」这一类思想实验的数学源头。</span>

想象一面镜子：镜中的世界沿镜面反射。普通向量的镜像是镜像向量，而角动量（定义于叉积 $\mathbf r\times\mathbf p$）在镜中**方向不翻转，反而更倔强地保持原方向**——它与镜中世界「不协调」。这种不协调不是误差，而是告诉我们：**手性（chirality）是真实存在的物理信息**。

## 1 Levi-Civita 记号：右手定则的数字化

**Levi-Civita 符号（Levi-Civita symbol）** $\varepsilon_{ijk}$：$(i,j,k)$ 为 $(1,2,3)$ 的偶置换时取 $+1$，奇置换取 $-1$，有重复指标时取 $0$。它有一整套精妙的恒等式，其中最重要的一条是「收缩」公式：<span class="marginnote">下标越界 $\varepsilon_{ijk}$ 三个指标全不同才非零，所以一共有 $3! = 6$ 个非零元素（三个 +1、三个 −1）。它是「有序三指标的方向」的最小编码。</span>

$$
\varepsilon_{ijk}\,\varepsilon_{ilm} = \delta_{jl}\,\delta_{km} - \delta_{jm}\,\delta_{kl}
$$

右边是 Kronecker delta 的乘积差——一个代数恒等式，却浓缩了三维空间全部的行列式与叉积运算。

这条恒等式是三维世界里几乎所有「两次叉积」运算的通用密码：左端两个 $\varepsilon$ 对指标 $i$ 求和，右边用 delta 把结果摊成两项。向量的双重叉积、行列式的乘积公式、旋度的旋度——全是它同一句台词的反复登场。由它可以推出整套行列式公式：$3\times3$ 矩阵的行列式写成 $\det A = \varepsilon_{ijk}\,A_{1i}A_{2j}A_{3k}$，叉积写成 $(\mathbf a\times\mathbf b)_i = \varepsilon_{ijk}a_jb_k$，标量三重积写成 $[abc] = \varepsilon_{ijk}a_ib_jc_k$。<span class="marginnote">$\varepsilon$ 的这些恒等式让「行列式 = 体积」「叉积 = 手性面积」这种几何直觉有了纯粹的代数表达——第一讲里埋下的 Levi-Civita 伏笔，到这里完全兑现。</span>

## 2 赝标量与赝向量：差的只是一个符号

现在看坐标变换的完整版本。设变换的 Jacobian 行列式为 $J = \det(\partial\bar{x}^i/\partial x^j)$。当坐标变换**翻转手性**（镜像、反射）时，$J = -1$。

**赝张量（pseudotensor）**：分量按张量律变换、但多乘一个 $J$ 的符号因子的量。关键实例：

**赝标量（pseudoscalar）**：标量三重积 $[abc]$ 是赝标量——镜像世界里它变号。真实标量（温度、能量）不变号。
- **赝向量（pseudovector / axial vector）**：叉积 $\mathbf a\times\mathbf b$ 是赝向量，角动量 $\mathbf L = \mathbf r\times\mathbf p$ 是赝向量，磁场 $\mathbf B$ 是赝向量。<span class="marginnote">「轴向向量（axial vector）」的旧称来自其几何来源：它沿转轴方向，而不是沿某条「指向」的直线方向。物理教科书里 axial vector 与 polar vector 的区分，就是这里赝向量与真向量的区分。</span>

**辨析｜易错点：** 注意赝向量的「多一个负号」只在**反射**类变换下显现。纯旋转（$J=+1$）下赝向量与真向量完全无法区分——所以本科初学普遍忽略它。一旦遇到镜像对称的问题（如手性分子、宇称不守恒），赝量与否立刻决定物理结论，这就是为什么李政道、杨振宁的「宇称不守恒」实验如此震撼。

把「镜像」翻译成最严格的数学：中心反演（三个坐标全变号，$J=-1$）下，真向量 $\mathbf v\to-\mathbf v$（方向反转），赝向量 $\mathbf a\to\mathbf a$（方向不动）。判据就一句话——**赝量在空间反演下不反转**。1956 年吴健雄的 β 衰变实验，测的正是「电子发射方向」与「核自旋（赝向量）」的夹角分布：若自然对左右手一视同仁，分布应左右对称；实验结果却毫不客气地打破了对称，宇称就此「沦陷」。自然界里唯一一个这样的反例，让「赝量」从课本术语变成了拿诺贝尔奖的钥匙。

把「多一个负号」再精确一点：赝量的完整变换式是 $\bar P = (\det J)\cdot(\text{张量变换})$。$\det J=+1$ 时它与真张量毫无差别，$\det J=-1$ 时才露出马脚。所以「赝」不是一个可选标签，而是一句声明——**我的手性，跟着坐标变换的符号一起走**。

## 3 反对称张量：与赝向量的一一对应

**反对称张量（antisymmetric tensor）**：交换任意两个指标变号，$A_{ij} = -A_{ji}$。二阶反对称张量在对角线上全为 0，三维里只剩 3 个独立分量——恰好与一个三维向量一样多。

这个「恰好」不是巧合而是计数规律：三维里 $n$ 阶反对称张量的独立分量数是 $\binom{3}{n}$——二阶 3 个、三阶 1 个（正是 $\varepsilon$ 本身）。于是「反对称张量的自由度与向量、标量精确对应」，这正是「对偶向量」技巧在物理里层出不穷的根源。

把「对偶」写得更显式：对任意向量 $a_i$，定义反对称张量 $A_{jk} = \varepsilon_{ijk}a_i$。于是叉积 $\mathbf a\times\mathbf b$ 可以写成 $A_{jk}b_k$——一个反对称张量作用在一个向量上。磁场写成赝向量 $\mathbf B$，还是写进反对称电磁张量 $F_{\mu\nu}$，本质是同一信息的两种编码：一种绑定于手性，一种绑定于四维时空。

这不是巧合。任何二阶反对称张量 $A_{ij}$ 都能**对偶**成一个向量：

$$
a_i = \tfrac{1}{2}\,\varepsilon_{ijk} A_{jk}, \qquad A_{jk} = \varepsilon_{ijk}\, a_i
$$

两个变换互为逆。这是「旋度」的思想根源：$\nabla\times\mathbf v$ 本质上是反对称梯度张量 $\partial v_j/\partial x_k - \partial v_k/\partial x_j$ 的向量化身。<span class="marginnote">电磁场张量 $F_{\mu\nu}$ 是四维时空里最著名的反对称张量：它的 6 个独立分量恰好打包了电场与磁场各 3 个——麦克斯韦方程用 $F_{\mu\nu}$ 可以写成两条紧凑的张量方程。</span>

## 4 公式解析：为什么叉积是赝向量

$$

(\mathbf a \times \mathbf b)_i = \varepsilon_{ijk} a_j b_k

$$

用这个式子回答「为什么叉积在镜像下多一个负号」，四步完成：

- **第一步，镜面变换 $x^1\to -x^1$**：只有 $x^1$ 变号，$J=-1$。真向量 $a_1\to -a_1$，$a_2,a_3$ 不变，$b$ 同理。
- **第二步，看 $\varepsilon$ 在新坐标里**：$\varepsilon_{ijk}$ 不是张量而是**张量密度（tensor density）**，镜像下它自身变号 $\varepsilon_{ijk}\to-\varepsilon_{ijk}$——因为它编码的是右手定则，而镜像世界换了手。
- **第三步，两项符号叠加**：$a_jb_k$ 按真向量变（两个负号在叉积里抵消成……需具体算），而 $\varepsilon$ 多出的那个负号无处抵消——最终叉积分量比「真向量应变的」多一个负号，成为赝向量。
- **第四步，物理后果**：镜像世界里角动量的方向「不跟着翻」，这正是前文镜中 $\mathbf L$ 倔强的来源。

关键教训一句话：**Levi-Civita 符号不是普通张量，它每出现一次就赠送一个手性符号**。凡是定义里含 $\varepsilon$ 的量（叉积、行列式、旋度、角动量），天然带有「赝」的血统。

## 5 张量密度：赝量的完整户口

「赝量多一个符号」看起来像特例，其实有一套完整的户口本——**张量密度（tensor density）**。定义：若对象 $T$ 的变换律在张量规则之外还乘上 Jacobian 行列式的 $w$ 次方，

$$
\bar T = (\det J)^w \cdot (\text{张量变换})
$$

则称 $T$ 为**权重 $w$ 的张量密度**。赝张量正是权重与手性符号结合的特例：$J$ 是 +1（旋转）时多出的因子是 1，$J$ 是 -1（镜像）时多出的因子是 $-1$——于是只在手性翻转时显形。

**Levi-Civita 符号就是权重 1 的张量密度**：

$$
\varepsilon'_{ijk} = (\det J)\,\varepsilon_{ijk}
$$

所以凡是用 $\varepsilon$ 定义的量（叉积、行列式、旋度）都继承了这份「密度血统」。反过来，密度乘以 $1/\sqrt{g}$（$g = \det g_{ij}$）可「去权重」变回普通张量——这正是上一讲旋度公式里 $\sqrt{g}$ 出场的真正原因。<span class="marginnote">在弯曲时空（广义相对论）里，$\sqrt{-g}\,dx^4$ 才是坐标无关的体积元——密度与权重是「测量」被几何扭曲时的标准语言。</span>

**物理应用：用赝量当「探测器」**。既然赝量在手性翻转下变号，物理规律「允不允许左手世界」，就看等式两边赝量能否互相抵消。几个一致性检查：

- 洛伦兹力 $\mathbf F = q\mathbf v\times\mathbf B$：$\mathbf v$ 是真向量，$\mathbf B$ 是赝向量，真×赝 = 真，$\mathbf F$ 是真向量 ✓——力不该是赝量，这个等式是自洽的。
- 角动量 $\mathbf L = \mathbf r\times\mathbf p$：真×真 = 赝，$\mathbf L$ 是赝向量——所以镜像世界里角动量的方向「不跟着翻」。
- 坡印廷向量 $\mathbf S = \mathbf E\times\mathbf B$：$\mathbf E$ 真、$\mathbf B$ 赝，真×赝 = 真——能量流动的方向是真实方向 ✓。

四类常见组合的判定（真×真 = 赝、真×赝 = 真、赝×赝 = 真）建议直接背下来——它是电磁学、粒子物理里快速自查的一张现成小抄。

再做一个数值微检：取 $\mathbf a = (1,0,0)$，$\mathbf b = (0,1,0)$。$(\mathbf a\times\mathbf b)_3 = \varepsilon_{312}\,a_1 b_2 = (+1)(1)(1) = 1$（因为 $(3,1,2)$ 是 $(1,2,3)$ 的偶置换），其余分量为 0。于是 $\mathbf a\times\mathbf b = (0,0,1)$，正是右手系里的 $\mathbf e_z$——**坐标手性由 $\varepsilon$ 的符号约定钉死**。

**辨析｜易错点：** 别把「手性」与「左右手定则的惯例」混为一谈。$\mathbf a\times\mathbf b$ 指向哪里**依赖**我们约定的右手系；但「$\mathbf L$ 在镜像下变号」是**客观物理事实**，与约定无关。约定的自由度可以被惯例吃掉，赝量的符号却永远留在物理里——李政道、杨振宁 1957 年凭「弱相互作用宇称不守恒」获诺奖，正是靠追踪这种「约定盖不住的符号」才找到了自然界的破绽。

## 6 小结

- **Levi-Civita 符号** $\varepsilon_{ijk}$：偶置换 +1、奇置换 −1、重复指标 0；收缩恒等式统一了行列式、叉积、三重积。
- **赝张量**：变换律多乘 Jacobian 符号因子；镜像（$J=-1$）下多一个负号，纯旋转下与真张量无异。
- **赝向量实例**：$\mathbf a\times\mathbf b$、角动量 $\mathbf L$、磁场 $\mathbf B$；赝标量实例：标量三重积。
- **反对称张量**：$A_{ij}=-A_{ji}$，二阶时 3 个独立分量，与三维向量经 $\varepsilon$ 对偶；旋度是它的化身。
- **核心教训**：$\varepsilon$ 携带手性符号，含 $\varepsilon$ 的量天然是赝量。

在下一节，我们从「张量长什么样」转向「张量能告诉我们什么」——二阶对称张量有它专属的坐标系，在该坐标系里它变成对角矩阵，物理量被彻底解耦。这就是**二阶张量的本征值与本征轴**。
