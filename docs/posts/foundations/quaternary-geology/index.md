# 第四纪地质学

第四纪地质学以最近约 260 万年以来的地层与沉积记录为研究对象，通过年代学、古气候代用指标与冰川地貌重建冰期-间冰期旋回和环境演变，是连接古气候重建、冰川演化与人类起源研究的关键学科。

## 对标教材

- 夏正楷《第四纪环境学》，北京大学出版社
- 曹伯勋《地貌学及第四纪地质学》，中国地质大学出版社
- Lowe & Walker, "Reconstructing Quaternary Environments" (3rd ed.), Routledge
