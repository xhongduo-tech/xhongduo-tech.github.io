# 生物地球化学

生物地球化学研究碳、氮、磷、硫等元素在地球表层各圈层之间的循环及其与生命活动的相互作用，是地球系统科学的核心分支，对应 AGU 生物地球科学分会。它串联大气、岩石、土壤、水体与生物圈，是理解碳氮磷循环、气候变化反馈与全球环境变化的基础学科。

## 对标教材

- Schlesinger & Bernhardt《Biogeochemistry: An Analysis of Global Change》3rd ed, Academic Press
- Jacobson, Charlson, Rodhe & Orians《Earth System Science: From Biogeochemical Cycles to Global Change》Academic Press
