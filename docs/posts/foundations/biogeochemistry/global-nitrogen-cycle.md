## 为什么从全球氮循环开始

碳循环的故事是「地球在替人类兜底」，而氮循环的故事更极端：**人类亲手改写了循环本身。** 哈伯-博施法让人类合成的活性氮超过了所有自然固氮的总和——这养活了半个地球，却也让氮从「稀缺养分」变成「过剩污染物」。理解全球氮循环，就是理解「一项伟大的化学发明如何变成一场全球生态危机」的完整链条。<span class="marginnote">活性氮（reactive nitrogen, Nr）指除惰性 N₂ 外的一切含氮形态——NH₃、NO₃⁻、NOₓ、N₂O、有机氮。人类扰动的是「活性氮的产生速率」，而不是 N₂ 本身。</span>

## 1 人为氮的崛起：翻倍的自然固氮

全球活性氮的产生通道，人为与自然各占半边：

| 来源 | 通量（Tg N yr⁻¹） | 说明 |
| --- | --- | --- |
| 自然陆地固氮 | ~110 | 土壤固氮菌、共生固氮 |
| 海洋固氮 | ~90–140 | 蓝细菌 |
| 闪电固氮 | ~5 | 放电把 N₂ 氧化成 NOₓ |
| **哈伯-博施（工业固氮）** | **~120** | 合成氮肥 |
| **化石燃料燃烧** | **~35** | 高温下 N₂ 与 O₂ 生成 NOₓ |
| **农业生物固氮（豆科种植）** | **~60** | 种植豆科作物扩大固氮 |

**重点：人为新增的活性氮（约 200+ Tg N yr⁻¹）已与自然固氮总量相当甚至超过。** 这意味着地球表层活性氮的「年产量」被人为翻了一倍——多出来的氮必须被生态过程消化，而消化不了的部分就在陆地、水体与大气里堆积成问题。<span class="marginnote">这正是「行星边界」框架里氮循环被列为「已越界」的原因（见第6节）：人类不是改变了一个参数，而是把地球活性氮的总体给改写了。</span>

## 2 氮沉降：一场看不见的「全球施肥」

工业与农业排放的活性氮（NH₃、NOₓ），随大气传输后以**干湿沉降（nitrogen deposition）** 落到地面。全球氮沉降热点分布高度不均：

**欧洲、东亚、北美东部**是三大沉降热点——正是工业化与集约农业最密集的地区。
东亚（尤其中国）是当前沉降量最大、增长最快的区域，来自化肥 NH₃ 挥发与燃煤 NOₓ。
- 氮沉降已覆盖全球约一半的自然生态系统。<span class="marginnote">氮沉降是「看不见的污染」：它不像雾霾有颜色，却在逐年改变土壤化学与植物群落。中国的氮沉降强度在 1980–2010 年间几乎翻倍，近年因减排政策首次出现拐点——这是环境治理改善全球氮循环的罕见正面案例。</span>

**核心直觉：氮沉降把「区域排放」变成「全球施肥」**——你在中国烧的煤、施的肥，氮会飘到几百上千公里外的森林、湖泊与海洋。这也是为什么氮污染必须「跨境治理」。

## 3 氮饱和：从缺氮到氮过量的反转

陆地生态系统对氮的态度会随着输入增加发生「反转」——这是理解氮沉降后果的关键概念，即**氮饱和（nitrogen saturation）**：

1. **氮限制期**：系统缺氮，输入都被生物利用，NPP 随沉降增加而升高（「施肥效应」）。
2. **饱和期**：生物与土壤「吃不下」更多氮，多余的氮开始**淋溶**——硝酸盐进入地下水、河流，造成下游富营养化。
3. **失衡期**：氮磷比失衡、土壤酸化、养分失衡，森林衰退——**氮从养分变成毒物。**<span class="marginnote">氮饱和假说由 Aber 等人在 1989 年提出，是生态学里「非线性响应」的经典范例：生态系统的响应不是随输入线性增长，而是有一个「从受益到受害」的拐点。治理氮沉降，抢的就是这个拐点之前的时间窗口。</span>

**辨析｜易错点：**「氮饱和」不等于「生态系统不需要氮」——它是说**生物对氮的需求已满，额外输入的氮开始外溢**。评估氮饱和要看「氮的输出是否随输入同步增加」，而不是看土壤氮含量高不高。

## 4 临界负荷：生态系统的「承载力」

**临界负荷（critical load）** 是政策里最常用的氮管理工具，定义是：**不造成生态系统的有害变化（按明确标准）的、最大可接受的污染沉降量**，单位是 kg N ha⁻¹ yr⁻¹。

不同生态系统的临界负荷差异很大：

| 生态系统 | 临界负荷（kg N ha⁻¹ yr⁻¹） | 主要受损害指标 |
| --- | --- | --- |
| 酸敏性湖泊 | 5–10 | 水体酸化、营养盐改变 |
| 贫营养泥炭地 | 5–10 | 植物群落改变（苔藓被取代） |
| 北方针叶林 | 10–15 | 土壤酸化、养分失衡 |
| 温带阔叶林 | 15–25 | 硝酸盐淋溶、群落变化 |
| 集约草地 | 20–40 | 高耐受 |

**核心直觉：临界负荷是一把「保护生态的尺子」**——把监测到的实际沉降与临界负荷对比，就能判断一个地区「氮是否已经超标」。它是欧洲《清洁空气公约》、中国大气污染防治的定量基础之一。<span class="marginnote">临界负荷的思路可以推广到硫（酸沉降治理用过同一套框架）。它把「生态安全」从口号翻译成「每公顷每年能承受几公斤氮」的工程语言——这背后是几十年生态监测数据与生态毒理实验的积累。</span>

## 5 公式解析：全球活性氮收支

把全球氮循环写成账，核心方程是活性氮的产生与清除：

$$
\frac{dN_r}{dt} = \left(N_{fix}^{nat} + N_{fix}^{ind}\right) - \left(N_{denit} + N_{burial}\right)
$$

其中 $N_r$ 是全球活性氮存量，$N_{fix}^{nat}$ 与 $N_{fix}^{ind}$ 是自然与人为固氮，$N_{denit}$ 与 $N_{burial}$ 是反硝化与沉积埋藏。一步步拆开：
