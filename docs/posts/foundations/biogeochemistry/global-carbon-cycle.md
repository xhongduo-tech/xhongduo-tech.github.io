## 为什么从全球碳循环开始

前 17 节我们把碳的每一段旅程拆开讲过：陆地、海洋、大气、沉积物。现在把它们**合起来算一笔全球总账**——这是生物地球化学最重要的公共议题：人类每年烧掉多少碳，地球各处又吸收多少，剩下多少让大气 CO₂ 上升？这笔「碳收支」不仅决定气候预测，也直接检验我们对整个学科的理解是否到位。<span class="marginnote">「全球碳计划（Global Carbon Project）」每年发布全球碳收支报告（Global Carbon Budget），把所有测量手段——大气观测、海洋调查、森林清查、模型反演——汇总成一张年度总账。这是地球科学里最成功的「公开账本」之一。</span>

## 1 全球碳库：分布与尺度

先看碳都「住在哪」（单位为 Pg C，1 Pg = 10¹⁵ g）：

| 库 | 碳量（Pg C） | 特征 |
| --- | --- | --- |
| 大气 CO₂ | ~880 | 增长最快，人类扰动的「显示器」 |
| 陆地植被 | ~450 | 周转快，易受砍伐影响 |
| 土壤（含冻土） | ~1700 | 巨大而缓慢 |
| 海洋溶解无机碳 | ~38,000 | 最大活动碳库 |
| 沉积岩（碳酸盐+有机碳） | ~60,000,000 | 地质尺度，几乎冻结 |

**核心直觉：把目光从「最大库」移到「变化最快的库」。** 沉积岩虽巨，百万年才动一次；大气库虽小，却在十年尺度上被人类改写——**生物地球化学关心的是「活跃库的失衡」，而不是库的大小本身。**<span class="marginnote">一个常被引用的比喻：如果沉积岩碳是一座山，大气碳只是一粒沙——但人类正在用几百年给这粒沙「灌气」，而山要到百万年尺度才响应。短期气候问题的战场在沙粒，不在山。</span>

## 2 人为碳收支：谁排了多少、谁收了多少

2020 年代的全球碳收支大致如下（Pg C yr⁻¹，数值随时间更新）：

**化石燃料燃烧与水泥**：约 9.5–10（排放源，最大项）。
**土地利用变化**（森林砍伐、农业扩张）：约 1–1.5（排放源）。
- **大气 CO₂ 增长**：约 5–5.5（留在空气中的部分）。
- **海洋吸收**：约 2.5–3（汇）。
- **陆地吸收**：约 2.5–3.5（汇——这曾是著名的「失踪碳汇」）。

**重点：人类排出的碳约一半留在大气、约四分之一进海洋、约四分之一进陆地。** 「海洋与陆地各吸收约 1/4」这两个「汇」，是地球替人类「兜底」的部分——它们不是无条件的，海洋会酸化、陆地会饱和，理解这些汇的脆弱性正是本节后半部分的主题。<span class="marginnote">把百分比记在心里：大气 45% / 海洋 25% / 陆地 30%——这是「人为碳去了哪」的现代答案。20 世纪 80 年代人们只能解释约一半的去向，剩下的是「missing sink（失踪碳汇）」，直到 90 年代才确认是北半球陆地植被在吸收。</span>

## 3 Keeling 曲线：大气 CO₂ 的「心电图」

1958 年，查尔斯·基林（Charles David Keeling）在夏威夷冒纳罗亚（Mauna Loa）开始连续测量大气 CO₂，得到今天举世闻名的**Keeling 曲线**。它的两个特征一眼可见：

**长期上升**：CO₂ 从约 315 ppm 升到今天的约 420 ppm——化石燃料排放的「指纹」。
**锯齿波动**：每年北半球春夏植被生长吸碳、秋冬腐烂放碳，CO₂ 浓度像锯齿一样季节性起伏——**这本身就是陆地生物泵存在的直接证据**，且锯齿的振幅还在逐年增大，暗示陆地碳汇在增强。<span class="marginnote">Keeling 曲线是科学观测的「样板间」：单一站点、几十年的坚持、一张不断增长的图。它还记录过核试验的放射性碳、火山爆发的扰动——一页曲线，半部地球化学史。</span>

## 4 公式解析：全球碳收支方程

全球碳循环的全部对话，浓缩成一条守恒方程：

$$
\frac{dC_{atm}}{dt} = F_{fossil} + F_{landuse} - F_{ocean} - F_{land}
$$

其中 $C_{atm}$ 是大气碳库，$F_{fossil}$ 与 $F_{landuse}$ 是人为排放，$F_{ocean}$ 与 $F_{land}$ 是海洋与陆地的净吸收。一步步拆开：

- **第一步，左边是大气的「体重秤」**：$\frac{dC_{atm}}{dt}$ 就是大气 CO₂ 的年增长率——用 Keeling 曲线的斜率直接测得（约 5 Pg C yr⁻¹）。
- **第二步，右边的正负号**：排放（fossil、landuse）是「+」，吸收（ocean、land）是「−」。**只要排放大于吸收，大气就增长——哪怕两个汇都在努力工作。**
- **第三步，每一项怎么测**：化石排放来自能源统计，大气增长来自浓度测量，海洋吸收来自船测与模式，陆地吸收是「残差」——用其他三项反推。**所以陆地汇是「算出来的」，不是「直接称出来的」，这正是它不确定性大的根源。**
- **第四步，方程的价值**：它把「人类活动—地球响应—大气后果」串成一条可检验的链。**任何声称「减少排放就不需要减排」的说法，在方程面前都会破产——因为左边只认「排放与吸收的差」。**

**这个公式的意义**：全球碳收支方程是气候谈判桌上的「总账本」——巴黎协定的「碳预算」概念，就是把它倒过来：在给定温升目标下，人类还能排放多少碳。

## 5 陆地碳汇：从「失踪」到「被确认」

陆地碳汇（约 3 Pg C yr⁻¹）的故事是科学史上一段佳话：

- **20 世纪 80 年代**：碳收支不平衡，约有 1–2 Pg C yr⁻¹ 的碳「对不上账」，被称为**失踪碳汇（missing sink）**。
- **90 年代**：通过大气 CO₂ 南北浓度差、¹³C 同位素与植被清查，确认「失踪者」是**北半球中高纬陆地植被**——它们在吸收化石燃料的碳。
- **今天的解释**：陆地汇主要来自**CO₂ 施肥效应**（大气 CO₂ 升高刺激光合）与**氮沉降施肥**（人类排放氮促进生长）、以及部分地区的森林恢复。

**辨析｜易错点：**陆地碳汇不是「免费午餐」的保证——它可能随饱和、干旱、火灾而减弱甚至反转。**「陆地是碳汇」是当前状态，不是永久属性**，这直接关系「剩余碳预算」的估计。<span class="marginnote">CO₂ 施肥效应的强度是 IPCC 评估里最大的不确定之一：实验室里 CO₂ 升高明显促进生长，但野外试验（如 FACE 试验）显示真实增益常被养分限制、水分限制打折扣——「施肥效应打几折」，决定陆地汇能撑多久。</span>

## 6 碳循环的不确定性：模型为什么各说各话

不同气候模型的碳循环预测可以相差数倍，根子在这三处：

1. **土壤碳温度敏感性**：Q₁₀ 到底是 1.5 还是 2.5（第2篇《陆地碳循环》），决定土壤释放多少。
2. **陆地汇的持久性**：CO₂ 施肥、氮沉降、火灾反馈如何随时间演变。
3. **海洋碳汇的饱和**：海洋吸收随 CO₂ 升高而效率下降（缓冲能力递减），但下降速率各家模型不同。

**核心直觉：碳循环的「汇」是活系统，不是常数。** 所有关于「1.5°C 还剩多少碳预算」的数字，都建立在「汇会如何变化」的模型之上——这正是生物地球化学从书斋走向全球决策的最后一公里。<span class="marginnote">CMIP6（第六次耦合模式比较计划）里，不同地球系统模型模拟出的 2100 年大气 CO₂ 可以相差数百 ppm——差异几乎全部来自陆地与海洋碳汇的建模分歧，而非排放假设。<strong>读懂碳循环，就是读懂气候预测的不确定性之源。</strong></span>

## 7 拓展：碳预算与气候目标——从方程到国际谈判

第4节的收支方程不只是学术账本，它是**国际气候谈判的数学基础**。理解「碳预算（carbon budget）」概念，是理解《巴黎协定》的关键。

**什么是碳预算**：要控制全球温升在某一目标（如 1.5°C）内，人类总共还能排放多少碳——这个「剩余排放额度」就是碳预算。它由两步算出来：

1. **温升目标 → 允许的 CO₂ 浓度**：给定气候敏感度（第4篇《CO₂ 与气候变化反馈》的 $G$），把 1.5°C 翻译成大气 CO₂ 的「安全上限」。
2. **浓度目标 → 允许的累计排放**：用收支方程反推——排放的碳约有 45% 留在大气，所以「累计排放」与「浓度增量」几乎成正比（这一近似正是碳预算概念成立的原因）。

**几个关键数字与争议**：

IPCC 估计：从 2020 年起，把温升控制在 1.5°C 的剩余碳预算约 **300–500 Pg C**（不同方法差异大）。
按当前全球排放（约 10 Pg C yr⁻¹），这笔预算只够烧 **几十年**——「碳预算耗尽日」的概念由此而来。
- 争议点：预算取决于**气候敏感度与碳汇持久性**（第6节）——敏感度越高、汇越弱，预算越紧。**所以「还剩多少碳预算」不是固定数，而是取决于我们对碳循环的理解。**

**为什么这是生物地球化学的功劳**：碳预算概念把「气候目标」从抽象的温升数字，变成「可管理的排放额度」——它让国际谈判有了一个共同的「算账基准」。**没有收支方程与碳汇研究，就没有今天的巴黎协定框架。**<span class="marginnote">巴黎协定的「国家自主贡献（NDC）」机制，本质上就是让各国自报「我在这笔总预算里分多少、怎么花」。碳预算因此既是科学概念，也是地缘政治工具——这也是「科学进入政策」最典型的案例。</span>

**给读者的启示**：下次看到「还剩 X 年碳预算」的新闻，你知道它的完整推导链是：**气候敏感度 → 安全浓度 → 收支方程 → 累计排放上限 → 剩余年份。** 每一步都建立在生物地球化学的方程之上。

**碳账本的「道德意味」**：全球碳收支方程不只是化学——它把「大气、海洋、陆地、人类」放进同一本账，让「谁的排放、谁在吸收、谁在兜底」一目了然。**读碳循环，读的是人类与地球之间最漫长的对账。**

**一句话记住**：排放 ≈ 大气增长 + 海洋吸收 + 陆地吸收——两边永远平衡，差别只在分配。

## 8 小结

- 全球碳库以**沉积岩最大、海洋次之、大气最小但最活跃**；生物地球化学关心活跃库的失衡。
- 人为碳收支约 **大气 45% / 海洋 25% / 陆地 30%**；两个「汇」替人类兜底，但都有代价与上限。
- **Keeling 曲线**用锯齿与上升记录着大气 CO₂ 的「心电图」，锯齿振幅增大暗示陆地汇在增强。
- 全球碳收支方程 $\frac{dC_{atm}}{dt} = F_{fossil} + F_{landuse} - F_{ocean} - F_{land}$ 把「排放-吸收-大气增长」串成一条可检验的守恒链。
- **陆地汇是「算出来的」**：用大气增长、化石排放与海洋吸收反推，不确定性最大——CO₂ 施肥、氮沉降与火灾反馈决定它能否持久。
- **碳预算**概念把温升目标翻译成「剩余排放额度」：给定敏感度与汇的持久性，就能算出「还剩多少年」。
