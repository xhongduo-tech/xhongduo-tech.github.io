## 为什么从磷硫开始

碳与氮讲了「大气参与的循环」，而**磷**把规则彻底改写：它几乎没有气相——大气里没有磷循环。这意味着磷只能在岩石、土壤、生物与水体之间「原地打转」，靠风化缓慢补充。**硫**则站在另一个极端：它有丰富的气相形态，与酸沉降、火山、海洋排放紧密相连。把磷与硫放在一起看，你就掌握了「元素有没有气相」这个决定循环形态的总开关。<span class="marginnote">金句记忆：碳和氮「有翅膀」（有气相，能飞越全球），磷「没有翅膀」（无气相，只能随水流），硫「半飞半爬」（既有气体又有固相）。这个比喻贯穿整个生物地球化学。</span>

## 1 磷循环：被岩石「锁死」的元素

磷是 DNA、ATP 与细胞膜（磷脂）的骨架元素，生命一刻也离不开它。但磷的循环路径极其受限：

**最大的库是沉积岩**：磷主要存在于**磷灰石**（apatite, $\ce{Ca5(PO4)3(OH, F, Cl)}$）等矿物里，通过**风化**缓慢释放。
**生物吸收后进入有机磷**：植物吸收可溶磷酸根，死后归还土壤。
- **吸附与沉淀**：磷酸根极易被铁铝氧化物吸附，或与钙生成难溶沉淀——土壤对磷的「固定」能力很强。
- **河流搬运入海**：大陆磷随河流流向海洋，最终埋藏在海洋沉积物里，要等地质抬升才能重回陆地。<span class="marginnote">磷循环因此被称为「地球生物地球化学中最慢、最不循环的循环」——它本质上是单向的「岩石→土壤→海洋→沉积岩」，回程靠的是千万年尺度的板块运动。</span>

**重点：磷的稀缺性取决于「土壤年龄」。** 年轻土壤（火山灰、冰川新土）富含磷，老年土壤（热带红壤）经数十万年风化淋溶，磷几乎流失殆尽——这就是为什么热带老成土是最贫磷的土壤，而磷肥是热带农业的生命线。

## 2 磷的形态与有效性

可被植物吸收的磷形态是**正磷酸根**，其形态随 pH 变化：

$$
\ce{H3PO4 \lt => H2PO4- \lt => HPO4^2- \lt => PO4^3-}
$$

- 中性土壤（pH 6–7）以 $\ce{H2PO4-}$ 与 $\ce{HPO4^2-}$ 为主，恰好都是植物可利用的形态。
- 酸性土壤里磷被铝、铁固定成难溶矿物；碱性土壤里被钙固定——**磷的有效性在 pH 两端都大打折扣**，这是「磷在中性土最幸福」的原因。<span class="marginnote">磷的另一特殊之处：它在土壤里几乎不移动（扩散距离以毫米计），所以缺磷时根系必须「追着」磷长——这引出第2篇《植物养分策略》里根际磷的获取机制。</span>

**辨析｜易错点：**「土壤全磷含量高」不等于「植物不缺磷」——大部分土壤磷以植物用不了的形态存在。测磷要看**有效磷**，就像看存款要看「可动用现金」而非「总资产」。

## 3 氮磷循环对比：一张表看懂「有无气相」

把氮与磷并排比较，是理解元素循环设计的最好练习：

| 特性 | 氮循环 | 磷循环 |
| --- | --- | --- |
| 大气库 | 有（N₂，78%） | 无 |
| 主要补充途径 | 生物固氮、工业固氮 | 岩石风化 |
| 形态变化 | 氧化还原连环变身（固氮/硝化/反硝化） | 几乎不变价，只换存在形式 |
| 主要流失途径 | 反硝化（回大气）、淋溶 | 吸附固定、河流搬运入海 |
| 典型限制场景 | 年轻土壤、北方针叶林 | 老土壤、热带雨林 |
| 人类扰动 | 哈伯-博施法倍增固氮 | 磷矿开采（资源有限） |

**核心直觉：氮有「大气阀门」自我补给，磷只能靠「岩石补给、一去不回」。** 所以磷问题本质是**资源问题**——全球磷矿储量有限，而磷一旦入海埋藏就难以回收，这是「磷危机」讨论的根源。

## 4 硫循环：气相与固相的穿梭

硫的循环横跨岩石、大气、水体与生物，且氧化还原切换剧烈：

**岩石风化**：含硫矿物（黄铁矿 $\ce{FeS2}$、石膏）风化释放硫酸根 $\ce{SO4^2-}$。
**火山排放**：SO₂ 与 H₂S 直接进入大气，是天然硫源。
- **生物排放**：海洋浮游生物释放**二甲基硫（DMS, $\ce{(CH3)2S}$）**，在大气氧化成硫酸盐气溶胶——这是影响云凝结核、进而影响气候的著名机制（CLAW 假说）。<span class="marginnote">CLAW 假说（Charlson、Lovelock、Andreae、Warren, 1987）：浮游生物释放 DMS → 氧化成硫酸盐气溶胶 → 增多云滴 → 增亮云层反射阳光 → 降温。这被设想为一个由生物驱动的气候负反馈，至今仍在争论中。</span>
- **人为排放**：燃煤燃油释放 SO₂，是**酸沉降（acid rain）** 的主要来源，曾把北半球大片森林与湖泊酸化。

**重点：硫在还原态（H₂S、有机硫）与氧化态（SO₄²⁻、SO₂）之间大幅切换**，每种切换都由特定微生物或燃烧过程驱动——这是理解硫去向的关键。

## 5 公式解析：硫的氧化还原切换

硫循环的两端，各用一个反应代表：

**还原端——硫酸盐还原**（厌氧环境，硫酸盐还原菌）：

$$
\ce{SO4^2- + 2CH2O + 2H+ -> H2S + 2CO2 + 2H2O}
$$

**氧化端——硫化氢氧化**（有氧或微生物硫氧化）：

$$
\ce{H2S + 2O2 -> H2SO4}
$$
