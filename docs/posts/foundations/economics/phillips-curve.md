# 通货膨胀与失业之间的短期权衡：菲利普斯曲线

<div class="epigraph">
<p>通胀与失业之间存在一种短期的取舍——但长期里，这种取舍会消失。</p>

## 为什么从「菲利普斯曲线」开始

第 20 章讲了通胀的长期根源（货币），第 18 章讲了失业的结构。但宏观政策最核心的「两难」在于——**通胀与失业短期此消彼长**：想降失业，可能推高通胀；想压通胀，失业可能上升。这就是**菲利普斯曲线（Phillips curve）**。

这一节做三件事：给出**短期菲利普斯曲线**（通胀与失业的负相关）；解释它与总供求模型的关系（**菲利普斯曲线 = 短期总供给的另一种画法**）；最后是 20 世纪最重要的宏观发现之一——**预期的引入**：短期菲利普斯曲线会移动，**长期菲利普斯曲线是垂直的**。**「短期有取舍、长期无取舍」**——这是理解通胀与失业的全部关键。

## 1 短期菲利普斯曲线：负相关

**菲利普斯曲线（Phillips curve）**：**描述通货膨胀与失业之间短期负相关关系的曲线。**

**经验发现**（菲利普斯，1958）：英国数据显示，**通胀率高的年份失业率低、通胀率低的年份失业率高**——**通胀与失业短期反向变动**。

**含义**：**政策制定者面临「取舍」（trade-off）**——可以用「高通胀」换「低失业」（扩张政策），或用「高失业」换「低通胀」（紧缩政策）。<span class="marginnote">菲利普斯曲线的政策含义：<strong>它像一张「菜单」——政策者可以选择「通胀换失业」的不同组合</strong>：想要低失业，接受高通胀；想要低通胀，忍受高失业。1960s 的政策制定者曾认真用这张「菜单」设计政策——后来发现菜单会移动（预期引入）。<strong>「菲利普斯曲线让宏观政策第一次有了『选择』的感觉」</strong>。</span>

**为什么短期负相关**？回顾短期总供给的机制（第 70 篇）：物价上升 → 企业增产（粘性工资下利润升）→ 产出升 → 失业降——**「高通胀伴随低失业」正是短期总供给倾斜的体现**。

## 2 菲利普斯曲线与总供求：同一枚硬币

关键洞察：**菲利普斯曲线就是短期总供给曲线的「另一种画法」**。

**对照**：
**总供求图**：纵轴物价水平、横轴真实 GDP——短期 AS 倾斜；
**菲利普斯曲线图**：纵轴通胀率、横轴失业率——短期曲线负相关。

**两个图的关系**：
真实 GDP 上升（总供求图）↔ 失业率下降（菲利普斯图）——**奥肯定律**（第 68 篇）把「产出」与「失业」连起来；
物价水平上升 ↔ 通胀率上升——同一件事的两种记法。

**所以**：**短期总供给倾斜 ⟺ 短期菲利普斯曲线负相关**——**它们是同一个「短期价格粘性」现象的两种表达。**<span class="marginnote">菲利普斯曲线与短期 AS 的等价性很重要：<strong>短期 AS 倾斜（物价升→产出增）翻译成「产出—失业」语言（奥肯定律）就成了「通胀升→失业降」的菲利普斯曲线</strong>。做这两种图时，其实是同一套逻辑换坐标轴。<strong>「菲利普斯曲线 = 短期 AS + 奥肯定律的合体」</strong>。</span>

**政策含义的统一**：扩张政策 → AD 右移 → 物价升、产出升（短期 AS）→ 通胀升、失业降（菲利普斯）——**政策在菲利普斯曲线上移动**。

## 3 预期的作用：菲利普斯曲线会移动

1960s 末，菲利普斯曲线的「菜单」失灵了——**通胀与失业同时上升（滞胀）**。弗里德曼与费尔普斯给出解释——**预期**：

**短期菲利普斯曲线不是固定的，它会随预期通胀移动**：

$$
\text{通胀率} = \text{预期通胀率} - \beta(\text{失业率} - \text{自然失业率})
$$

其中 $\beta > 0$。**预期通胀越高，整条短期菲利普斯曲线越往上移。**<span class="marginnote">菲利普斯曲线的「预期版」是 1970s 宏观革命的核心：<strong>短期菲利普斯曲线由「预期通胀」定位——预期通胀高（工人要求高工资、企业提前涨价），曲线整体上移</strong>。政策者想用「高通胀换低失业」，但一旦公众预期到通胀，曲线就上移——「换来的低失业」又被预期吃掉。<strong>「预期是菲利普斯曲线的『隐藏的移动器』」</strong>。</span>

**预期通胀的形成**：适应预期（用过去通胀推断）或理性预期（用所有可得信息预测）。**预期调整越快，短期菲利普斯曲线移动越快。**

## 4 长期菲利普斯曲线：垂直

预期移动短期菲利普斯曲线，最终的归宿是——**长期菲利普斯曲线**：

**长期菲利普斯曲线是垂直的**——**失业率在长期与通胀无关，恒等于自然失业率。**

**为什么？** 长期里**预期完全调整**：公众预期到的通胀被完全计入工资与价格 → **扩张政策只推高通胀，不降低失业**（货币中性，第 60 篇）→ **失业回到自然失业率**。<span class="marginnote">长期菲利普斯垂直 = 长期货币中性的图形表达：<strong>长期里通胀与失业没有取舍——失业被「钉」在自然失业率（第 18 篇），通胀只是名义变量的变动</strong>。政策者想长期用通胀换失业——门都没有。<strong>「长期菲利普斯曲线的垂直，是货币中性的又一次胜利」</strong>。</span>

**短长期的区别**：
- **短期**：菲利普斯曲线负相关——**通胀与失业有取舍**（预期未调整）；
- **长期**：菲利普斯曲线垂直——**没有取舍**（预期已调整）。

**「短期有取舍、长期无取舍」**——弗里德曼的总结：**政策者只能在短期「骗」经济（利用未调整的预期），长期骗不了。**

## 5 公式解析：菲利普斯曲线的完整方程

把「预期 + 短期 + 长期」统一进一个方程——**附加预期的菲利普斯曲线（expectations-augmented Phillips curve）**：

$$
\pi = \pi^e - \beta(u - u_n)
$$

其中 $\pi$ 通胀率、$\pi^e$ 预期通胀率、$u$ 失业率、$u_n$ 自然失业率、$\beta$ 衡量失业对通胀的影响强度。逐项拆解：

- **第一步，看 $\pi^e$**：预期通胀是曲线的「锚」——$\pi^e$ 高，整条曲线上移。
- **第二步，看 $-\beta(u - u_n)$**：当失业 $u$ 低于自然率 $u_n$（经济过热）→ 括号为负 → 通胀高于预期；失业高于自然率 → 通胀低于预期。
- **第三步，看长期**：长期里 $\pi = \pi^e$（预期实现）→ $-\beta(u - u_n) = 0 \Rightarrow u = u_n$——**失业恒等于自然失业率，通胀任意**——垂直的长期菲利普斯曲线。<span class="marginnote">这个方程是宏观最经典的「一条公式讲完短长期」：<strong>$\pi = \pi^e - \beta(u - u_n)$——短期（$\pi^e$ 给定）失业与通胀负相关；长期（$\pi = \pi^e$）失业钉在自然率</strong>。它把预期、通胀、失业三个宏观核心变量装进一个方程。<strong>「一个方程，讲完菲利普斯曲线的全部历史」</strong>。</span>

**用数字走一遍**：$\pi^e = 3\%$、$\beta = 0.5$、$u_n = 5\%$：
若政策把失业压到 4%（低于自然率）：$\pi = 3 - 0.5(4-5) = 3 + 0.5 = 3.5\%$——**低失业换来高通胀**（短期）；
但若公众预期调整到 3.5%，曲线移动，政策需再推……**长期里失业回到 5%，通胀越来越高**——**「用通胀买失业，越买越贵」**。

## 6 菲利普斯曲线的实战：从「1960s 菜单」到「通胀目标制」

菲利普斯曲线的历史，就是「宏观政策如何从'迷信取舍'走向'尊重预期'」的历史：

**1960s：把曲线当「菜单」**。早期政策者相信「通胀与失业的稳定取舍」——用「高通胀换低失业」被当作政策工具。结果：1970s 滞胀打脸——**通胀与失业同时恶化，曲线上的「菜单」不见了**。

**1970s：预期击穿菜单**。弗里德曼与费尔普斯指出——**曲线会随预期移动**：政策者用通胀换失业，公众学到「通胀会来」，预期上调，曲线右移——**「通胀买不到失业，只买到了更高的通胀预期」**。

**1980s 至今：锚定预期的胜利**。沃尔克（美联储）用「高利率硬压通胀」→ 公众预期转向 → 通胀下降且未引发持久高失业——**「可信的政策，改变预期；改变预期，改变曲线位置」**——通胀目标制由此诞生。<span class="marginnote">菲利普斯曲线的「驯服史」是宏观政策最成功的案例：<strong>1960s 信「取舍」→ 滞胀；1970s 悟「预期」→ 理论革命；1980s 用「可信政策」锚定预期 → 通胀被驯服</strong>。它证明：<strong>「货币政策真正管理的不是通胀本身，而是'通胀预期'」</strong>——现代央行「预期管理」的正当性，就来自这段历史。<strong>「央行最有价值的资产，是公众对它的信任」</strong>。</span>

**与大模型主线的连接**：AI 时代菲利普斯曲线的新问题——**「AI 通缩（有利供给冲击）让'低通胀 + 低失业'同时出现——打破'取舍'」**；但「AI 转型失业」又可能让自然失业率变化——**「AI 时代的菲利普斯曲线，位置在移动、形状在变形」**——宏观理论的新课题，正等着用「预期」框架去解。

**再补一个「菲利普斯曲线的读数练习」**，把「通胀—失业」的取舍变成读政策新闻的工具——看到「央行加息/降息」，用菲利普斯曲线推演：

**情景一：央行加息（紧缩）**——目标「压通胀」：
短期：利率升 → 总需求降（第 72 篇）→ 产出降 → **失业升** → 通胀降——**「在短期菲利普斯曲线上，从'高通胀低失业'移到'低通胀高失业'"**；
长期：预期调整后，**失业回到自然率、通胀降到位**——**「紧缩的长期结果：通胀降、失业不变（回自然率）」**。

**情景二：央行降息（扩张）**——目标「保就业」：
短期：总需求升 → 产出升 → **失业降** → 通胀升；
长期：预期上调，**失业回到自然率、通胀升到位**——**「扩张的长期结果：失业不变（回自然率）、通胀升」**。

**读数口诀**：**「政策只能短期移动菲利普斯曲线上的点，长期失业被钉在自然率——政策真正能长期改变的是通胀」**。<span class="marginnote">「菲利普斯曲线的读数法」是宏观政策判断的通用工具：<strong>看央行政策，先问「这是要压通胀还是保就业」——短期它能在曲线上取舍，长期它只能改变通胀预期与通胀本身</strong>。这解释了「为什么央行最终都盯通胀目标」——<strong>「既然长期只能控制通胀，不如公开承诺控制通胀——锚定预期，让短期代价更小」</strong>。</span>

**与大模型主线的连接**：AI 时代的「政策两难」变形——**「AI 通缩（有利供给冲击）让'低通胀 + 低失业'可能同时出现——短期取舍被打破」**——但「AI 转型失业」又可能抬高自然失业率——**「AI 让菲利普斯曲线的形状与位置都在变——宏观政策需要新的'预期管理'」**。

## 7 小结

- **短期菲利普斯曲线**：通胀与失业**负相关**——政策有「取舍」。
- **与总供求的关系**：菲利普斯曲线 = 短期 AS + 奥肯定律——**同一个现象的两种画法**。
- **预期移动曲线**：$\pi = \pi^e - \beta(u - u_n)$——预期通胀越高，曲线上移。
- **长期菲利普斯曲线**：**垂直**——失业恒等于自然失业率，通胀与失业无取舍（货币中性）。
- **弗里德曼总结**：**短期有取舍、长期无取舍**——政策只能短期「骗」，长期骗不了。
- **政策含义**：稳定政策的约束——**「低失业」与「低通胀」只能短期兼得，长期必须取舍**。

第 24 章收官：货币政策、财政政策、稳定政策争论、菲利普斯曲线——「总需求管理」的完整工具包。但这一切都假设一个**封闭经济**——现实世界有国际贸易与资本流动。最后一章把镜头拉向全球：《开放经济的宏观经济学》。
