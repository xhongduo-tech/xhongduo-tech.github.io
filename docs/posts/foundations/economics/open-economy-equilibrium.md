# 开放经济中的均衡：可贷资金市场与外汇市场的联系

<div class="epigraph">

## 为什么从「开放经济的均衡」开始

前两节有了 NX = NCO 的恒等式与汇率的概念，但还缺一块：**开放经济中，利率与汇率怎么同时决定？** 答案是两个市场联动：

- **可贷资金市场**（第 67 篇）：决定**利率**——储蓄与投资（国内）的均衡；
- **外汇市场（foreign-currency exchange market）**：决定**真实汇率**——资本净流出与净出口的均衡。

**两个市场通过 NCO 连接**——资本净流出既影响可贷资金市场的需求，又是外汇市场的供给。这一节把「利率—汇率」的联动讲透，下一节才能分析开放经济的政策。

## 1 两个市场的供求结构

先分别看清两个市场。

**可贷资金市场（决定利率 $r$）**：
- **供给**：国民储蓄 $S$（私人 + 公共）；
- **需求**：国内投资 $I$ + **资本净流出 NCO**——**开放经济里，储蓄不仅融通国内投资，还流向国外**（$S = I + NCO$，第 76 篇）；
- **均衡**：$S = I + NCO$ → 均衡利率。

**外汇市场（决定真实汇率 $\varepsilon$）**：
- **供给**：**资本净流出 NCO**——本国人要用本币换外币去买外国资产——**NCO 是外汇的供给**；
- **需求**：**净出口 NX**——外国人要换本币来买本国商品——**NX 是外汇的需求**；
- **均衡**：$NCO = NX$ → 均衡真实汇率。<span class="marginnote">两个市场的结构要记牢：<strong>可贷资金市场：供给 $S$、需求 $I + NCO$ → 定利率；外汇市场：供给 $NCO$、需求 $NX$ → 定真实汇率</strong>。注意 NCO 的角色：<strong>它在可贷资金市场是「需求方」，在外汇市场是「供给方」——它是连接两个市场的枢纽</strong>。这呼应第 76 篇的恒等式 $NX = NCO$。<strong>「NCO 身兼两职：借钱的（需求）和换汇的（供给）」</strong>。</span>

## 2 NCO 的桥梁作用：利率 → 汇率

NCO 为什么是桥梁？因为**利率决定 NCO 的大小**：

**NCO 与利率负相关**——利率越高，本国资产回报越高 → 外国投资者涌入、本国资本不外流 → **NCO 越小**。反之利率低 → NCO 大。

**联动链条**：
可贷资金市场均衡 → **利率 $r$**；
利率 $r$ → **决定 NCO**（负相关）；
NCO（外汇供给）与 NX（外汇需求）→ **决定真实汇率 $\varepsilon$**。

**「利率定 NCO，NCO 定汇率」**——两个市场通过 NCO 串成一条链。<span class="marginnote">两个市场的传导：<strong>可贷资金市场出清定利率 → 利率决定资本净流出 → 外汇市场出清定真实汇率</strong>。这条链让「国内储蓄政策」最终影响「汇率」——<strong>「国内的钱往哪去（NCO），决定外国的钱怎么换（汇率）」</strong>。</span>

## 3 开放经济均衡的图形

把两个市场并排画，开放经济的完整均衡就出来了：

**市场一：可贷资金市场**——供给 $S$（垂直或右上斜）、需求 $I + NCO$（右下斜，因 $I$ 与 $NCO$ 都对利率负相关）→ 均衡利率 $r_1$。

**市场二：外汇市场**——供给 $NCO(r_1)$（利率已定时 NCO 是常数，垂直线）、需求 $NX$（随真实汇率负相关）→ 均衡真实汇率 $\varepsilon_1$。

**两个均衡同时成立**：利率与真实汇率同框——**任何冲击改变其中一个市场，都会通过 NCO 传导到另一个**。<span class="marginnote">开放经济均衡的标准图形：<strong>两个并排的供求图——左边可贷资金定利率，右边外汇定汇率，中间由 NCO 传递</strong>。做题时「两步走」：先算可贷资金市场得利率，再代入外汇市场得汇率。<strong>「先定利率、再定汇率——开放经济均衡的两步法」</strong>。</span>

**例题**：某国储蓄 $S = 500$、国内投资 $I = 500 - 1000r$、资本净流出 $NCO = 400 - 2000r$、净出口 $NX = 600 - 200\varepsilon$：

**第一步，可贷资金市场**：$S = I + NCO \Rightarrow 500 = (500 - 1000r) + (400 - 2000r) \Rightarrow 500 = 900 - 3000r \Rightarrow r = 400/3000 \approx 0.133$（13.3%）。

**第二步，算 NCO**：$NCO = 400 - 2000 \times 0.133 = 400 - 267 = 133$。

**第三步，外汇市场**：$NCO = NX \Rightarrow 133 = 600 - 200\varepsilon \Rightarrow \varepsilon = (600-133)/200 = 2.34$——**均衡真实汇率 2.34**。

## 4 政策冲击一：预算赤字对开放经济的影响

把第 67 篇的「预算赤字」分析放到开放经济，看它如何同时影响利率与汇率。

**情景**：政府预算赤字增加（公共储蓄下降 → 国民储蓄 $S$ 下降）。

**第一步，可贷资金市场**：供给 $S$ 左移 → **利率上升**。

**第二步，NCO 变化**：利率上升 → 外国资本流入、本国资本不外流 → **NCO 减少**。

**第三步，外汇市场**：NCO（外汇供给）减少 → 外汇供给左移 → **真实汇率上升（本币实际升值）**。

**完整链条**：**赤字 → 储蓄降 → 利率升 → NCO 降 → 真实汇率升（本币升值）**。<span class="marginnote">开放经济里的赤字分析：<strong>赤字 → 利率升 → 吸引外资 → 本币升值 → 出口竞争力下降（NX 减少）</strong>。注意：<strong>赤字既挤出国内投资（$I$ 降），又通过汇率升值挤出净出口（$NX$ 降）——双重挤出</strong>。这也是「孪生赤字」（双赤字，twin deficits）理论的依据：财政赤字与贸易逆差常常并存。<strong>「财政赤字是贸易逆差的远亲——通过利率与汇率牵线」</strong>。</span>

**结果**：预算赤字 → 利率升、投资降、本币升值、净出口降——**「双赤字」**（财政赤字 + 贸易逆差并现）。

## 5 政策冲击二：贸易政策的影响

再看贸易政策（如关税、进口配额）对开放经济的影响。

**情景**：政府征收关税、限制进口。

**直觉**：关税让进口减少 → NX 增加（顺差扩大）。
**经济学的分析**：**贸易政策不改变 NX（恒等式 NX = NCO）！**

**第一步，可贷资金市场**：关税不改变储蓄与投资 → **利率不变**；
**第二步，NCO 不变**：利率不变 → NCO 不变；
**第三步，外汇市场**：关税让 NX 需求减少（同价下进口少了、外汇需求降）→ 外汇需求左移 → **真实汇率上升（本币升值）**——**但均衡 NX 仍等于不变的 NCO，NX 没变！**<span class="marginnote">贸易政策的「反直觉结论」：<strong>关税减少进口 → 但 NX = NCO，NCO 不变（利率没变），所以 NX 不变——关税只是让本币升值、进口「相对便宜」，抵消了关税效果</strong>。贸易政策改变的是「汇率」和「贸易结构」，而不是「贸易余额」本身。<strong>「贸易政策是汇率政策——它升值货币，但不改变总顺差」</strong>。</span>

**结论**：**贸易政策不能改变贸易余额（NX 由 NCO 决定），只能改变真实汇率**——关税让本币升值、进出口量都减少（贸易量萎缩），但顺差/逆差不变。**「限制进口」的净效果是「让贸易更少、汇率更高」，而不是「顺差更大」。**

## 6 开放经济均衡的实战：为什么「财政赤字」常伴随「贸易逆差」

两市场模型的第一个现实推论——**双赤字（孪生赤字，twin deficits）**——是理解美国等国财政与贸易关系的钥匙：

**推导链条**：财政赤字（$G > T$）→ 公共储蓄负 → 国民储蓄 $S$ 下降 → 可贷资金供给左移 → **利率上升** → 外国资本流入（NCO 下降）→ 外汇供给减少 → **本币升值** → 出口竞争力下降 → **净出口下降（贸易逆差扩大）**。

**结果**：财政赤字与贸易逆差「同时出现」——**「双赤字」**。美国 1980s、2000s 的经历都验证了这条链——**「财政扩张的'汇率通道'，把财政赤字传导成了贸易逆差」**。

**反向的案例（储蓄过剩）**：高储蓄国（中国、日本）→ 利率低 → 资本流出 → 本币贬值压力 → 出口旺 → **顺差**——**「高储蓄国天然是贸易顺差国，低储蓄国天然是逆差国」**。<span class="marginnote">「双赤字」给政策制定者的启示：<strong>想减少贸易逆差，直接的手段不是「限制进口」（贸易政策，第 78 篇证明无效），而是「减少财政赤字」（提高国民储蓄）</strong>——因为 NX 由储蓄-投资缺口决定，不由贸易政策决定。<strong>「贸易差额的根源在国内储蓄，不在关税」</strong>。</span>

**核心视角**：开放经济均衡模型把「国内财政」与「国际收支」连成一条链——**「财政赤字 → 利率 → 汇率 → 贸易逆差」——看懂这条链，就理解了宏观政策的国际传导**。这也是下一节「开放经济政策」分析的总框架。

## 7 小结

- **两个市场**：可贷资金市场（供给 $S$、需求 $I+NCO$ → 利率）；外汇市场（供给 $NCO$、需求 $NX$ → 真实汇率）。
- **NCO 的桥梁**：利率负相关决定 NCO，NCO 又作为外汇供给决定汇率——**「利率定 NCO，NCO 定汇率」**。
- **两步法**：先算可贷资金得利率 → 代入外汇市场得真实汇率。
- **预算赤字**：赤字 → 利率升 → NCO 降 → 本币升值 → 双重挤出——**双赤字**。
- **贸易政策**：关税 → NX 不变（NX=NCO）→ 只升值货币、萎缩贸易量——**「贸易政策是汇率政策」**。

开放经济的均衡讲清了：利率与汇率联动，政策通过 NCO 传导。最后一节把这些工具用于真实政策分析——《开放经济的宏观经济政策》：贸易政策、资本外逃与汇率制度。
