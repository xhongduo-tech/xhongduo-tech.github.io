# 总供给曲线：长期与短期总供给

## 为什么从「总供给曲线」开始

上一节的**总需求曲线**说「价格水平影响总支出」，但经济能生产多少，还取决于**总供给（aggregate supply）**——经济中所有企业的总产出能力。总供给曲线有一个奇妙的「两副面孔」：

- **长期总供给曲线**：**垂直**——长期产出由生产能力决定，与物价无关；
- **短期总供给曲线**：**向右上倾斜**——短期物价上升，产出会增加。

**「长期垂直、短期倾斜」**是总供给的全部秘密。这一节解释这个「两副面孔」，以及背后的核心概念——**货币中性（长期）vs 价格粘性（短期）**。它是理解经济波动（下一节）与稳定政策（第 24 章）的钥匙。

## 1 长期总供给：垂直曲线

**长期总供给曲线（long-run aggregate-supply curve）**：**长期中经济生产的物品与劳务量——它由经济中的资本、劳动、自然资源与技术决定，与物价水平无关——因此是垂直的。**

**为什么长期与物价无关？** 因为**货币中性（第 60 篇）**——长期里物价变动只是「标尺」的变化，不影响真实产出。**长期产出 = 充分就业产出（自然产出）**：经济在资本、劳动、技术给定的情况下「应该」生产的水平。<span class="marginnote">长期总供给垂直 = 古典二分法（第 60 篇）的图形表达：<strong>长期里物价水平（名义变量）不影响真实产出——总供给曲线垂直在「自然产出水平」</strong>。这个垂直线的位置由谁决定？——第 21 章的四大因素：<strong>资本、劳动、自然资源、技术——它们移动长期总供给</strong>。经济增长（第 21 章）就是这条垂直线右移的过程。</span>

**什么移动长期总供给**？——**改变生产能力的东西**：劳动增加（人口、移民）、资本积累（投资）、自然资源发现、技术进步。**长期增长 = 长期总供给右移**。

**垂直的含义**：长期里**物价水平由总需求决定，产出由总供给决定**——两者「分工」：**AD 管物价，LRAS 管产出**。

## 2 短期总供给：向右上倾斜

**短期总供给曲线（short-run aggregate-supply curve）**：**短期内经济生产的物品与劳务量——它向右上倾斜，因为短期内物价上升会刺激企业增加产量。**

**为什么短期物价升、产量增？** 因为**短期里价格有「粘性」（sticky）**——不是所有价格都立即调整。核心机制（教科书版）：

**粘性工资理论（sticky-wage theory）**：工资不能立即调整（合同锁定）。物价上升 → 企业产品的售价上升，但**工资还没涨**（合同固定）→ **企业利润上升 → 企业多雇人、多生产 → 产出增加**。**「物价升、工资未动 → 利润升 → 产量增」。**<span class="marginnote">粘性工资是短期总供给倾斜的核心机制：<strong>物价涨了、工资合同没变 → 企业的「实际工资成本」下降 → 利润变厚 → 企业增产</strong>。想清楚：工资是名义的（合同锁死），物价涨了，企业付的真实工资实际降低——多雇人更划算。短期里「名义工资粘住、物价自由」，利润就波动，产出就跟着物价动。<strong>「工资粘住，物价浮动——利润当媒介，产出随物价」</strong>。</span>

**三个粘性理论**（曼昆列三种）：
**粘性工资**：工资合同不能立即调整；
**粘性价格**：企业不能频繁改价（菜单成本，第 61 篇）——物价涨，成本没涨的企业「实际降价」、需求增多 → 增产；
**错觉理论（misperceptions theory）**：企业把「物价上升」误认为「自己产品相对涨价」→ 增产。

**共同点**：**短期里价格/工资不能完全调整，物价变动会「骗过」企业，让产出偏离自然水平。**

## 3 长期与短期的连接：为什么短期会回归长期

短期总供给倾斜、长期垂直——两者如何统一？关键概念：

**短期偏离，长期回归**。短期里产出可以偏离自然水平（物价冲击让企业增产/减产），但**长期里价格与工资调整完毕，「错觉」消失、粘性解除——产出回归自然水平**。

**用图形想**：短期总供给曲线在长期总供给曲线（垂直线）附近——**短期曲线与长期曲线交于自然产出水平**。当物价偏离预期，短期产出沿短期曲线偏离自然产出；**时间拉长，短期曲线移动到「回到自然产出」**——因为预期调整（工人要求涨工资、企业重新定价）。

**预期的作用**：短期总供给的位置取决于**预期物价水平**——若企业预期物价会涨（工资按预期上调），短期总供给左移；预期稳定，短期总供给稳定。<span class="marginnote">「短期总供给的位置随预期移动」是总供求分析的难点：<strong>短期 AS 曲线的位置由「预期物价」决定——预期通胀高，工人要求高工资，短期 AS 左移</strong>。这解释了「滞胀」（stagflation，物价涨+产出跌）的成因（下一节）：<strong>供给冲击 + 预期调整，让短期 AS 左移——物价升、产出降同时发生</strong>。<strong>「短期 AS 会跑，因为预期会动」</strong>。</span>

**回归的过程**：短期 AS 的移动（因预期调整）与 AD 的交点，最终回到长期垂直线的位置——**长期均衡 = 垂直线上的一点**。

## 4 公式解析：总供求的长期与短期均衡

把长期与短期总供给放进方程，理解均衡。

**长期均衡条件**（产出 = 自然产出）：

$$
Y = \bar{Y}
$$

其中 $\bar Y$ 是自然产出（长期总供给的位置）。**长期里，无论物价多少，产出都是 $\bar Y$。**

**短期均衡条件**（总需求 = 短期总供给）：

$$
Y = AD(P) = AS_{短期}(P)
$$

**短期里，产出由 AD 与短期 AS 的交点决定**——可以偏离 $\bar Y$。

用数字走一遍：自然产出 $\bar Y = 100$，总需求 $AD$ 移动导致短期产出变化：

**第一步，长期均衡**：$AD$ 与长期 AS（$Y = 100$）交于物价 $P = 110$——产出 100、物价 110，这是长期均衡。

**第二步，AD 意外增加（扩张）**：$AD$ 右移 → 短期均衡：物价升到 115、产出升到 105（沿短期 AS 上升）——**短期产出高于自然产出（$105 > 100$）——经济「过热」**。

**第三步，长期回归**：工资与预期调整（工人看到物价涨，要求涨工资）→ 短期 AS 左移 → 新的长期均衡：物价更高（$P = 120$）、**产出回到 100**——<span class="marginnote">这个「AD 右移 → 短期产出升 → 长期产出回、物价升」的过程，是总供求分析的标准剧情：<strong>扩张性政策短期内推高产出（繁荣），长期只推高物价（通胀）——「短期甜头、长期通胀」</strong>。它精确体现了「货币短期非中性、长期中性」（第 60 篇）：<strong>货币/总需求变动，短期影响真实产出，长期只影响物价</strong>。</span>

**总结**：**AD 移动 → 短期产出偏离自然 → 长期回归自然（物价吸收冲击）**——这是经济波动与回归的总过程。

## 5 总供给移动的原因：供给冲击

除了 AD 移动，**总供给也会移动**——这带来另一类波动：

**短期总供给移动的原因**：
**劳动市场变化**：劳动力规模、自然失业率变动；
**资本存量变化**：资本积累（投资）或损耗；
**自然资源变化**：发现新资源、石油价格冲击；
**技术变化**：技术进步（长期也移动长期 AS）；
**预期物价变化**：预期通胀上升 → 短期 AS 左移。

**供给冲击（supply shock）**：**直接改变生产成本、从而移动总供给的事件**——如石油价格暴涨（70 年代 OPEC 冲击）。**供给冲击带来「滞胀」**：短期 AS 左移 → **物价上升 + 产出下降**——两个坏消息一起来（第 71 篇展开）。<span class="marginnote">供给冲击与需求冲击的区分是第 71 篇的主题，先记住核心：<strong>需求冲击：AD 移动（物价与产出同向变动）；供给冲击：AS 移动（物价与产出反向变动——滞胀）</strong>。「石油危机 = 供给冲击 = 物价升 + 产出降」——70 年代的滞胀就是这么来的。<strong>「供给冲击是宏观的坏天气：物价和产出对着干」</strong>。</span>

## 6 总供给的实战：从「油价冲击」到「AI 供给冲击」

总供给的分析工具，在理解「冲击」时最有价值——两类冲击的对照：

**不利供给冲击（石油涨价，1970s）**：短期 AS 左移 → 物价升、产出降（滞胀）——**「坏冲击：物价产出对着干」**。

**有利供给冲击（技术革命）**：短期 AS 右移 → 物价降、产出升——**「好冲击：物价产出一起好」**——90 年代 IT 革命、2000s 全球化都带来过「低通胀 + 高增长」。

**AI 是哪种冲击**？——**AI 提高生产率（有利供给冲击）**：同样的投入产出更多 → 短期 AS 右移 → **产出升、物价降**——「AI 通缩」的宏观表现。但同时：
**转型阵痛**：被 AI 替代的行业收缩 → 结构性失业（第 56 篇）；
**预期调整**：若工人预期「AI 时代通胀高」，短期 AS 左移，抵消部分红利。

**「AI 是'好冲击 + 转型痛'的复合体」**——用总供给框架分析，比「一刀切喊好/坏」更准确。<span class="marginnote">「冲击分析」的实用价值：<strong>遇到任何「改变生产成本或生产能力」的大事件（油价、疫情、AI），第一反应是「这是供给冲击」——然后判断方向（左还是右）、读新均衡（物价产出怎么动）</strong>。供给冲击与需求冲击的区别（第 71 篇的「同向=需求、反向=供给」）在此派上用场——<strong>「读懂冲击，就读懂了经济新闻的大半」</strong>。</span>

**核心视角**：总供给曲线是「生产能力」的化身——**「长期垂直是'生产能力决定产出'，短期倾斜是'价格粘性让产出暂时偏离'」**——理解它，就理解了「为什么短期政策有效、长期政策无效」。

## 7 小结

- **长期总供给**：**垂直**——产出由生产能力（资本、劳动、资源、技术）决定，与物价无关（货币中性）。
- **短期总供给**：**向右上倾斜**——物价升、产出增（粘性工资/价格/错觉）。
- **粘性工资**：物价升、工资合同未变 → 企业实际工资降 → 利润升 → 增产。
- **长期回归**：预期调整、价格工资松动 → 短期 AS 移动 → 产出回归自然水平。
- **均衡过程**：AD 右移 → 短期产出升（繁荣）→ 长期物价升、产出回归（通胀）。
- **供给冲击**：AS 左移 → 滞胀（物价升 + 产出降）——下一节的第二类波动原因。
