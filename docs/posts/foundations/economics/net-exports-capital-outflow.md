# 物品与资本的国际流动：净出口与资本净流出

<div class="epigraph">
<p>一个国家的进出口与它的国际资本流动，是同一枚硬币的两面——卖东西给外国，必然换回外国的资产。</p>
<footer>—— 大卫 · 休谟（David Hume）</footer>
</div>

<div class="article-byline">

## 为什么从「国际流动」开始

前 24 章大多假设**封闭经济**（无国际贸易）。但现实里，中国卖手机给美国、美国卖飞机给中国、资金跨越国界流动——**开放经济（open economy）**才是常态。最后一章把宏观分析放到「全球化」的舞台上。

这一节先建立开放经济的两个核心量：**净出口（net exports, NX）**——物品的国际流动；**资本净流出（net capital outflow, NCO）**——资本的国际流动。然后揭示那个最漂亮的恒等式——**净出口 = 资本净流出（NX = NCO）**。理解这个恒等式，就理解了贸易与金融的深层联系。

## 1 净出口：物品的国际流动

**净出口（net exports, NX）**：**一国出口值减去进口值**——（第 48 篇已见过）：

$$
NX = \text{出口} - \text{进口}
$$

**NX 的符号**：
- **贸易顺差（trade surplus）**：$NX > 0$——出口 > 进口；
- **贸易逆差（trade deficit）**：$NX < 0$——出口 < 进口；
- **贸易平衡**：$NX = 0$。

**影响 NX 的因素**：本国与外国商品的相对价格、汇率、本国与外国的收入、贸易政策。**NX 衡量「本国与世界交换物品」的净余额。**<span class="marginnote">净出口的直觉：<strong>出口 = 我们把东西卖给世界（世界欠我们），进口 = 我们从世界买东西（我们欠世界）</strong>——NX 是「与世界交易的净头寸」。顺差不是简单的「好」、逆差不是简单的「坏」（第 76 篇会讲）——<strong>「顺差意味着我们卖的多、逆差意味着我们买的多——而多卖多买必有多出的资本流动」</strong>。</span>

## 2 资本净流出：资本的国际流动

**资本净流出（net capital outflow, NCO）**：**本国居民购买的外国资产减去外国人购买的本国资产。**

**NCO 的内容**：
- **本国人买外国资产**（买外国股票、在外国建厂、存款到外国银行）→ NCO 增加；
- **外国人买本国资产**（买本国股票、在本地建厂）→ NCO 减少。

**NCO 的符号**：
- **资本流出**：本国资本流向国外（NCO > 0）；
- **资本流入**：外国资本流入本国（NCO < 0）。<span class="marginnote">NCO 的概念容易混淆，记住「谁买谁」：<strong>本国人买外国资产 = 资本流出（钱流出去了）；外国人买本国资产 = 资本流入</strong>。注意「买外国资产」与「出口物品」的方向——<strong>卖物品收钱 vs 买资产花钱，正好是镜像</strong>（下一节的恒等式）。</span>

**影响 NCO 的因素**：本国与外国利率的差异（利率高 → 资本流入）、投资风险、资本管制、政府政策。

## 3 核心恒等式：NX = NCO

开放经济最重要的恒等式——**净出口 = 资本净流出**：

$$
NX = NCO
$$

**为什么必然相等？** 因为**每一笔国际交易都同时涉及物品与资产**：

- 出口物品 → 收到外汇 → 用外汇买外国资产 → **出口对应资本流出**；
- 进口物品 → 支付外汇 → 外国人用这些钱买本国资产 → **进口对应资本流入**。

**「卖出去的东西，换回来的必然是资产」**——贸易与资本流动是同一笔交易的两面。<span class="marginnote">NX = NCO 是开放经济的第一恒等式：<strong>一个国家顺差（卖的多）必然同时是资本净流出（买外国资产多）——因为它收到的外汇总要「变成」外国资产</strong>。想想中国长期顺差：卖了很多东西给世界，赚了巨额外汇，又用外汇买了美国国债等外国资产——<strong>「顺差国的钱，最终流向外国资产」</strong>。</span>

**恒等式的含义**：
- **贸易顺差国 = 资本输出国**（NX > 0 ⟺ NCO > 0）——卖得多、买外国资产多；
- **贸易逆差国 = 资本输入国**（NX < 0 ⟺ NCO < 0）——买得多、借外国钱多。

**美国是典型逆差国**：进口多（NX 负）、外国资本大量流入美国（NCO 负——外国买美国资产）——**「美国用逆差从世界借钱，世界用顺差买美国资产」。**

## 4 公式解析：从恒等式到国民核算

把 NX = NCO 嵌进国民收入恒等式，得到开放经济的完整图景。

**封闭经济**（第 66 篇）：$Y = C + I + G$，储蓄 $S = Y - C - G$，所以 $S = I$。

**开放经济**：$Y = C + I + G + NX$，储蓄 $S = Y - C - G$，移项：

$$
S = I + NX
$$

再代入 $NX = NCO$：

$$
S = I + NCO
$$

**储蓄 = 国内投资 + 资本净流出。** 逐项拆解：<span class="marginnote">「$S = I + NCO$」是开放经济储蓄的完整表达式：<strong>储蓄有两个去处——投资于国内（$I$）或投资于国外（$NCO$）</strong>。封闭经济里储蓄只能投国内（$S = I$）；开放经济里储蓄可以「出国」。<strong>「储蓄的钱，要么建国内的厂，要么买国外的资产」</strong>。</span>

- **第一步，看储蓄 $S$**：国民储蓄（私人 + 公共）；
- **第二步，看国内投资 $I$**：投入国内资本积累的部分；
- **第三步，看资本净流出 $NCO$**：流向国外的部分——**储蓄的第二个去处**。

**用数字走一遍**：某国储蓄 $S = 100$ 亿，国内投资 $I = 60$ 亿 → $NCO = S - I = 40$ 亿——**40 亿储蓄流向国外**；同时 $NX = 40$ 亿——**贸易顺差 40 亿**。**「储蓄 100 = 投资 60 + 净流出 40」——三量对账。**

**政策含义**：**预算赤字（负公共储蓄）不仅挤出国内投资，还挤出净出口**——财政赤字 → 储蓄降 → 投资与 NX 都受影响（第 79 篇的开放政策）。

## 5 恒等式的现实意义

NX = NCO 不只是记账，它有重要的政策与认知含义：

**辨析｜易错点：贸易逆差是「坏的」吗？** 不一定。贸易逆差 = 资本净流入——**逆差国在「借外国的钱」**（外国投资流入）。这可能是「好」的（外国资本促进本国投资，如发展中国家）也可能是「坏」的（本国竞争力弱、靠借债消费）——**逆差本身无好坏，看「借来的钱用在哪」。**<span class="marginnote">「贸易逆差 = 资本流入」的视角很有用：<strong>美国逆差对应的不是「美国输了」，而是「世界信任美国资产、愿意借钱给美国」</strong>——逆差与顺差是「世界储蓄如何配置」的两面。政策上「限制进口、追求顺差」其实是在「拒绝外国资本」——<strong>「逆差恐惧」常常是「资本流动」的误解</strong>。</span>

**储蓄—投资—资本流动的联动**：高储蓄国（中国、日本）→ 投资国内 + 大量资本流出 → 顺差；低储蓄国（美国）→ 资本流入 → 逆差。**「一国的储蓄率，决定它是资本输出国还是输入国」。**

## 6 恒等式的实战：从「双顺差」到「贸易战」

NX = NCO 恒等式在现实政策讨论中最有价值的应用，是看穿「贸易差额之争」：

**中国的「双顺差」现象**：经常账户顺差（NX > 0）+ 资本账户顺差（外资流入）——表面看「两项都顺」，似乎违反 NX = NCO（顺差应对应资本流出）。**实际**：中国「经常账户顺差」对应「官方储备增加」（央行买美元，等于「资本流出」的另一种形式）——**「双顺差」不是违反恒等式，而是「资本流出以官方储备形式存在」**——恒等式始终成立。

**「贸易战」的经济学解读**：某国指责另一国「贸易顺差占便宜」——但 NX = NCO 说明：**顺差国的「盈余」必然以「资本输出」形式流回世界**（买别国资产、积累储备）——**「贸易差额不是'谁赢了'，而是'储蓄流向哪'」**。用关税强行压顺差，只会改变「资本流动的形式」，不会「消灭」盈余（第 78 篇贸易政策结论）。<span class="marginnote">「NX = NCO」的政策穿透力：<strong>任何「贸易失衡」的争论，都要翻译回「储蓄—投资—资本流动」的语言——顺差 = 储蓄过剩的输出，逆差 = 储蓄不足的输入</strong>。「贸易战」表面争「出口多少」，实质争「世界的储蓄与资本流向谁」——<strong>「看懂 NX = NCO，就看清了贸易争端的宏观本质」</strong>。</span>

**核心视角**：NX = NCO 是开放经济的「总账」——**「物品流与资本流必然对账——卖出去多少，就有多少资本流出去」**——它让你在看任何「贸易顺差/逆差」新闻时，自动补上「资本流动」的另一半。

## 7 小结

- **净出口 NX**：出口 − 进口——物品的国际流动（顺差/逆差/平衡）。
- **资本净流出 NCO**：本国买外国资产 − 外国买本国资产——资本的国际流动。
- **核心恒等式**：**NX = NCO**——卖物品必然换回外国资产（贸易与资本是一体两面）。
- **储蓄恒等式**：$S = I + NCO$——**储蓄投资国内或流向国外**。
- **逆差 = 资本流入**：逆差无绝对好坏，看「借来的钱用在哪」。
- **政策含义**：财政赤字同时影响国内投资与净出口。

物品与资本的流动「对上了账」（NX = NCO），但还没有「价格」——**国际交易的价格是汇率**：名义汇率与真实汇率如何决定、如何影响贸易。下一节《国际交易的价格》。
