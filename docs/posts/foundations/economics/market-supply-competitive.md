# 竞争市场的供给曲线：短期与长期的市场供给

<div class="epigraph">
<p>短期里企业数固定，供给由每个企业增产构成；长期里企业自由进出，供给由利润信号指挥。</p>

</div>

## 为什么从「市场供给曲线」开始

前三节分析的是**单个企业**：产量决策、停止营业、进入退出。但市场供求模型（第 4 章）用的是**市场供给曲线**——全体企业的总供给。从单个企业到整个市场，中间怎么「加总」？短期和长期又有什么不同？

这一节回答这三个问题。核心结论是：**短期市场供给 = 各企业供给曲线水平相加（企业数固定）；长期市场供给由进入退出主导（企业数可变），最终停在零利润的均衡。** 更重要的是，我们将得到一个贯穿全部微观的结论：**长期竞争均衡是有效率的——价格等于最低平均成本。**

## 1 短期市场供给：水平相加

**短期**：企业数固定（来不及进入退出），每个企业按自己的 MC 曲线供给。市场供给 = 所有企业供给的**水平加总**——**在每个价格上，把各企业的供给量加起来**。

$$
Q^{S}(P) = \sum_{i=1}^{n} q_i^s(P)
$$

其中 $q_i^s(P)$ 是第 $i$ 个企业在价格 $P$ 时的供给量，$n$ 是企业总数。<span class="marginnote">「水平相加」是市场供给的标准构造：<strong>对每一个价格，问每个企业愿卖多少，然后全部加总</strong>。需求侧的「市场需求 = 个人需求水平相加」同理。画图时，市场供给曲线就是把企业供给曲线「往右推 n 份」后的结果。</span>

**短期供给曲线的特点**：向右上倾斜（每个企业 MC 递增），**企业数固定 → 短期内供给量只能靠「现有企业增减产量」调整**，不能靠新企业进入。这意味着短期需求冲击（第 4 章）主要由价格吸收——企业少、调整慢。

## 2 长期市场供给：进入与退出

**长期**：企业可以自由进出。市场供给由**企业数目**的调整主导，而数目由**利润**信号指挥：

- **$P > ATC$（经济利润为正）**：新企业涌入 → 市场供给右移 → 价格被压低；
- **$P < ATC$（经济利润为负）**：企业退出 → 市场供给左移 → 价格被推高；
- **$P = ATC$（零经济利润）**：无人进出，企业数稳定 → **长期均衡**。<span class="marginnote">这个「利润信号 → 进出 → 价格回归」的循环是竞争市场的自动稳定器：<strong>任何超额利润都会引来竞争者把它摊平，任何亏损都会逼走企业把它补回</strong>。长期均衡一定是零利润——不是没人想赚钱，而是竞争把利润压到「正常回报」水平。</span>

**长期均衡的特征**：

- 企业按 $P = MC$ 生产（利润最大化）；
- $P = ATC$（零利润）；
- 联立得 $MC = ATC$ → 企业在 **ATC 最低点（有效规模）** 生产。

**长期均衡价格 = 最低平均总成本。** 这个价格是「行业底线」：低于它企业退出、高于它企业进入，只有等于它才稳定。

## 3 长期供给曲线的形状

长期市场供给曲线的形状取决于**成本随行业规模的变化**，教科书区分三种情形：

**成本不变行业（constant-cost industry）**：新企业进入不改变投入品价格 → 长期供给曲线**水平**（在最低 ATC 处）。产量翻倍，价格不变。<span class="marginnote">这是基准情形：<strong>行业规模扩大不推高或压低成本</strong>（比如一些小商品行业，原料供给充裕）。水平长期供给意味着长期里需求冲击只改变产量、不改变价格——需求增加最终只是「更多企业按同样价格生产」。</span>

**成本递增行业（increasing-cost industry）**：行业扩张推高投入品价格（稀缺资源、熟练工）→ 长期供给曲线**向右上倾斜**。这是多数行业的常态——**为什么长期供给仍可能倾斜？因为行业整体的资源是稀缺的。**

**成本递减行业（decreasing-cost industry）**：行业扩张反而降低成本（规模经济外溢、配套产业成熟）→ 长期供给曲线**向右下倾斜**。较少见，但存在（如某些高新技术集聚区）。

**关键对比**：短期供给曲线总是向右上倾斜（MC 递增），**长期供给曲线却可能水平、上斜或下斜**——因为长期里主导力量不是「单个企业增产」，而是「企业数目的进入退出」以及「行业规模对成本的反作用」。

## 4 公式解析：长期均衡的联立求解

把长期均衡的三个条件联立，可以严格求出均衡价格与产量。竞争企业：

$$
P = MC(Q) \quad(\text{利润最大化})
$$

$$
P = ATC(Q) \quad(\text{零利润/进出均衡})
$$

联立得：

$$
MC(Q^*) = ATC(Q^*) \quad\Longrightarrow\quad Q^* = \text{有效规模}
$$

用具体数字验证。设企业 $TC(Q) = 100 + Q^2$：

**第一步，求 MC 与 ATC**：$MC = 2Q$，$ATC = 100/Q + Q$。

**第二步，令 MC = ATC**：$2Q = 100/Q + Q \Rightarrow Q = 100/Q \Rightarrow Q^2 = 100 \Rightarrow Q^* = 10$——**有效规模**。

**第三步，求长期均衡价格**：$P^* = MC(10) = 20$，或 $P^* = ATC(10) = 20$——**均衡价格 = 最低平均总成本 = 20**。<span class="marginnote">这道题的答案结构值得记住：<strong>长期均衡价格 = 最低 ATC</strong>。只要题目给出成本函数，三步就能求出均衡价格：① 令 MC=ATC 求有效规模；② 代回求最低 ATC；③ 得长期均衡价格。这个「三步模板」在竞争市场的大题里高频出现。</span>

**均衡时的利润**：$\pi = (P - ATC) \times Q = (20 - 20) \times 10 = 0$——**零经济利润**。企业在有效规模处生产，不多不少。

## 5 长期均衡的效率与福利

把长期均衡放到第 7 章的福利框架里，竞争市场的效率结论就完整了。

**长期竞争均衡的效率三连**：

- **配置效率**：$P = MC$——最后一单位的价格等于其边际成本，产量恰在「评价=成本」处（第 7 章效率条件）；
- **生产效率**：$P = \min ATC$——企业在最低平均成本处生产，没有浪费；
- **零超额利润**：所有超额利润被竞争挤掉，资源回报等于机会成本（正常利润）。

**消费者与生产者的命运**：长期均衡下总剩余最大（第 7 章的结论），且消费者以最低可能价格获得商品——**竞争是消费者的朋友**。<span class="marginnote">把「长期均衡 = 效率」连到后面的章节：<strong>第 11 章垄断打破这个均衡（$P > MC$，产量不足），第 13 章外部性打破它（价格不含社会成本），第 14 章公共物品打破它（市场不提供）</strong>——竞争市场的「效率全垒打」只发生在理想前提下，每一章市场失灵都在某个环节打出一个破洞。</span>

**辨析｜易错点：长期均衡「零利润」是否意味着企业很惨？** 恰恰相反——零经济利润意味着企业挣回了全部机会成本，包括企业家才能的正常回报。**企业不「亏」，只是「没有超额利润」。** 现实中看似「很赚钱」的企业，扣掉隐性成本（自有资本利息、企业家时间）后，经济利润往往趋近于零——这正是竞争的力量。

## 6 市场供给的实战：为什么「长期价格」是企业的底线

长期均衡价格 = 最低平均总成本，这个结论有个重要的实战含义——**它给出了一个行业「长期的合理价格锚」**。

**案例：共享单车大战。** 行业早期，各平台烧钱补贴、超低价骑行（价格低于最低 ATC）——**短期可以（为了抢市场），但不可持续**（每单都亏）。随着资本退潮、进入者减少，供给收缩，价格回升——**最终稳定在「覆盖全部成本」的水平**。**「补贴大战是短期现象，长期价格必然回归平均成本」**——这正是长期均衡价格 = 最低 ATC 的现实演绎。

**为什么长期价格不会更低？** 价格低于最低 ATC → 企业亏损 → 退出 → 供给左移 → 价格回升。**「低于成本的价格，市场会自动修复」**——这是长期供给曲线的「底线保护」。

**为什么长期价格不会更高？** 价格高于最低 ATC → 超额利润 → 新企业进入 → 供给右移 → 价格回落。**「高于成本的价格，竞争会自动抹平」**。<span class="marginnote">长期均衡的「双面钳制」：<strong>低于成本价 → 退出抬价；高于成本价 → 进入压价——价格被夹在「最低平均成本」这个均衡点上</strong>。所以做投资、做经营，盯住「行业的长期平均成本」就是盯住「长期价格的锚」。<strong>「长期价格不会偏离成本太远——这是竞争市场的自我纪律」</strong>。</span>

**政策含义**：反垄断与准入管制讨论里，「这个行业长期价格该是多少」的答案，就是最低平均成本——**任何「定价高于长期成本」的市场，都藏着进入壁垒或垄断势力**。竞争市场的长期均衡，是衡量「市场是否被扭曲」的标尺。

## 7 小结

- **短期市场供给** = 各企业供给曲线**水平相加**，企业数固定，曲线向右上倾斜。
- **长期市场供给**由**进入退出**主导：$P > ATC$ 进入、$P < ATC$ 退出、$P = ATC$ 均衡。
- **长期均衡价格 = 最低平均总成本**，企业在有效规模处生产，零经济利润。
- **长期供给曲线形状**：成本不变行业水平、成本递增行业上斜、成本递减行业下斜。
- **三步求解模板**：令 MC=ATC 求有效规模 → 代回求最低 ATC → 得均衡价格。
- **效率三连**：$P = MC$（配置效率）、$P = \min ATC$（生产效率）、零超额利润。

第 10 章落幕：从单个企业的价格接受，到整个市场的长期均衡，我们完成了竞争市场的完整画卷。下一章，我们要拿走「很多卖者」这个假设——**市场上只剩一个卖者时，会发生什么？** 这就是第 11 章《垄断》。
