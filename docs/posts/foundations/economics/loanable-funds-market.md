## 为什么从「可贷资金市场」开始

上一节的恒等式说「储蓄 = 投资」，但没解释**利率**从哪来。这一节补上这个关键拼图——**可贷资金市场（market for loanable funds）**：把「储蓄」当作资金的供给、「投资」当作资金的需求，**利率就是资金的均衡价格**。

这一节是微观供求工具在宏观的第一次完整应用：**用第 4 章的三步分析法，分析三大政策冲击——储蓄激励（税改）、投资激励（税收抵免）、政府预算赤字。** 你会看到：**微观的供求框架原封不动地搬来宏观，利率就是那个「均衡价格」。**

## 1 可贷资金市场的供求

**可贷资金市场（market for loanable funds）**：**想要储蓄的人（资金供给者）与想要借款投资的人（资金需求者）进行交易的市场。** 它的「价格」是**利率（interest rate）**。

**资金供给（储蓄）**：来自**储蓄者**——家庭存款、企业留存、政府盈余。**储蓄者对利率的反应：利率越高，储蓄的回报越高，储蓄越多——供给曲线向右上倾斜。**

**资金需求（投资）**：来自**借款者**——企业贷款投资、政府发债。**借款者对利率的反应：利率越高，借款成本越高，投资越少——需求曲线向右下倾斜。**

**均衡**：供给 = 需求 → **均衡利率**，储蓄量与投资量同时确定。<span class="marginnote">可贷资金市场的图形与第 4 章商品市场完全同构：<strong>横轴是「资金量」，纵轴是「利率」（资金的价格），供给（储蓄）向上、需求（投资）向下，交点定均衡利率</strong>。把第 4 章的「价格」换成「利率」、「数量」换成「资金量」，一切分析照搬——<strong>「可贷资金市场 = 供求分析的宏观版」</strong>。</span>

**利率的双重角色**：利率既是**储蓄的报酬**（吸引资金供给），又是**借款的成本**（抑制资金需求）——**它像市场价格的「两只手」，把储蓄与投资拉平。**

## 2 政策冲击一：税收与储蓄激励

政府的税收政策能移动**资金供给（储蓄）**。**储蓄税收优惠**（如养老金账户免税、利息税减免）让储蓄的实际回报上升：

**三步分析**：
1. **哪条曲线动**：储蓄激励影响**资金供给**（储蓄）；
2. **方向**：储蓄变多 → 供给曲线**右移**；
3. **新均衡**：需求不动，供给右移 → **均衡利率下降、均衡储蓄量/投资量上升**。<span class="marginnote">储蓄激励的结果：<strong>利率下降、投资增加</strong>——税收优惠让储蓄变便宜，资金供给增多，压低了「资金的价格」（利率），企业借钱的成本降低，投资随之扩大。这是一个「双赢」的政策结果：<strong>储蓄者得到税收优惠，投资者得到更低利率</strong>。</span>

**结论**：**储蓄税收优惠 → 供给右移 → 利率降、投资增**——这正是第 21 章「鼓励储蓄促进增长」的市场机制：**储蓄激励通过降低利率，把资金导入了投资。**

## 3 政策冲击二：投资税收抵免

**投资税收抵免（investment tax credit）** 等政策移动**资金需求（投资）**——让企业投资的实际成本下降：

**三步分析**：
1. **哪条曲线动**：投资激励影响**资金需求**（投资）；
2. **方向**：企业想投资更多 → 需求曲线**右移**；
3. **新均衡**：供给不动，需求右移 → **均衡利率上升、均衡投资量上升**。<span class="marginnote">投资激励的结果：<strong>利率上升、投资增加</strong>——企业投资需求扩大，对资金的需求推高了「资金的价格」（利率）。注意与储蓄激励的区别：<strong>储蓄激励压低利率、投资激励抬高利率——方向相反，但都增加了投资量</strong>。这是可贷资金市场两个「旋钮」的对照。</span>

**但投资激励有「副作用」**：利率上升 → 储蓄者更愿意储蓄（供给沿曲线上升）——**「投资需求增加」通过利率上升「拉动了储蓄」**——最终投资增加的幅度，取决于储蓄对利率的反应（供给弹性）。

**两个政策对照**：

| 政策 | 移动 | 利率 | 投资量 |
| --- | --- | --- | --- |
| 储蓄激励 | 供给右移 | 下降 | 增加 |
| 投资激励 | 需求右移 | 上升 | 增加 |

**都增加投资，但利率方向相反**——政策的「价格效应」不同，但「数量效应」一致。

## 4 政策冲击三：政府预算赤字

政府预算赤字（$G > T$，公共储蓄为负）会**减少资金供给**：

**三步分析**：
1. **哪条曲线动**：政府赤字 → 公共储蓄下降 → 国民储蓄下降 → **资金供给左移**；
2. **方向**：供给左移；
3. **新均衡**：需求不动，供给左移 → **均衡利率上升、均衡投资量下降**。

**这是著名的「挤出效应」（crowding out）**：**政府赤字抬高利率，挤出了私人投资。**<span class="marginnote">挤出效应是财政赤字的核心代价：<strong>政府借钱 → 资金需求不变但供给减少 → 利率上升 → 私人投资变得昂贵 → 投资减少</strong>。政府借的钱「挤占」了私人的投资空间——「今天的赤字，是明天的私人投资减少与增长放缓」（第 21 章）。<strong>「政府赤字像吸管，把私人投资的钱吸走了」</strong>。</span>

**挤出效应的完整链条**：**赤字 → 公共储蓄负 → 国民储蓄降 → 可贷资金供给左移 → 利率升 → 私人投资降 → 长期资本积累放缓。**

**赤字影响投资的量级**：取决于**储蓄供给的弹性**——若储蓄对利率高度敏感，利率小幅上升就带来大量储蓄，投资减少有限；若储蓄不敏感，利率大幅上升，投资被大量挤出。

## 5 公式解析：可贷资金市场的均衡

把可贷资金市场的均衡写成方程，做定量分析。

设资金供给（储蓄）函数 $S(r) = 500 + 1000r$，资金需求（投资）函数 $I(r) = 1200 - 1000r$（$r$ 为利率，%）。

**第一步，令供给 = 需求**：

$$
S(r) = I(r) \implies 500 + 1000r = 1200 - 1000r
$$

**第二步，解均衡利率**：$2000r = 700 \Rightarrow r^* = 0.35$（35%？这利率过高，调整系数——简化起见以 $\%$ 计，$r^* = 35\%$）。实际中把系数设得合理些：设 $S(r) = 500 + 200r$、$I(r) = 1200 - 200r$：$500 + 200r = 1200 - 200r \Rightarrow 400r = 700 \Rightarrow r^* = 1.75$（1.75%）。<span class="marginnote">做题时注意函数系数：<strong>可贷资金均衡就三步——① 令储蓄=投资；② 解利率；③ 代回求资金量</strong>。这和第 4 章「令 $Q^d = Q^s$ 解均衡」是同一个套路，只是「价格」换成了「利率」。<strong>「供求分析换个标签，就是可贷资金市场」</strong>。</span>

**第三步，代回求均衡资金量**：$S = 500 + 200 \times 1.75 = 850$（亿元）——**储蓄 850 = 投资 850**。

**第四步，模拟政策冲击**：政府赤字导致储蓄减少（供给左移 100）：$S'(r) = 400 + 200r$。令 $S' = I$：$400 + 200r = 1200 - 200r \Rightarrow r^* = 2.0\%$，资金量 $= 800$。**赤字后：利率从 1.75% 升到 2.0%，投资从 850 降到 800——挤出效应被定量算出来了。**

## 6 可贷资金市场的实战：从「房贷利率」到「国债收益率」

可贷资金市场不只是宏观模型，它直接解释你每天看到的利率新闻：

**房贷利率**：房贷利率是「可贷资金市场的价格」之一——**储蓄多（资金供给旺）→ 利率低 → 房贷便宜**；**政府发债多（资金需求旺）→ 利率高 → 房贷贵**。央行降息（增加资金供给）→ 房贷利率下行——**「房贷利率的涨跌，就是可贷资金市场供求的晴雨表」**。

**国债收益率**：政府发债是「资金需求」，买国债是「资金供给」——**国债收益率 = 政府借款的利率**——它反映「市场对政府信用 + 资金供求」的判断。**「10 年期国债收益率」是全球金融市场的「锚」**——它高，各种借贷成本都高。

**利率的「分层」**：可贷资金市场讲的「利率」是**基准利率**，现实中不同借款人利率不同（风险溢价、期限溢价）——**「基准利率是地基，风险/期限溢价是加层」**。<span class="marginnote">「利率不是单一数字，而是一族价格」：<strong>可贷资金市场定「基准」（无风险利率），现实利率 = 基准 + 风险溢价 + 期限溢价</strong>——企业债利率高（有违约风险）、长期债利率高（有期限风险）。看利率新闻，先分清「这是基准还是具体利率」——<strong>「利率是市场的分层价格，不是铁板一块」</strong>。</span>

**与大模型主线的连接**：AI 时代的「算力投资潮」——**「AI 基础设施投资」成为可贷资金需求的新主角**——大厂举债建算力中心 → 资金需求上升 → 利率压力——**「AI 投资的融资需求，正在成为可贷资金市场的新变量」**——理解可贷资金市场，就理解了「AI 烧钱为什么影响宏观利率」。

## 7 小结

- **可贷资金市场**：储蓄（供给）× 投资（需求）→ **利率是资金的均衡价格**。
- **供给与需求**：储蓄对利率正相关（右上斜）、投资对利率负相关（右下斜）。
- **储蓄激励**：供给右移 → **利率降、投资增**。
- **投资激励**：需求右移 → **利率升、投资增**。
- **预算赤字**：供给左移 → **利率升、投资降**——**挤出效应**。
- **均衡求解**：令 $S(r) = I(r)$ 解利率、代回求资金量——**供求分析的宏观版**。

可贷资金市场讲完了：利率由储蓄与投资的供求决定，政策通过移动供求改变利率与投资。但这一切都假设**经济在正常运转**——现实中经济会**波动**（繁荣、衰退、萧条）。下一章进入《经济波动与总供求》：为什么经济会起起落落。
