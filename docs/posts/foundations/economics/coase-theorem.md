# 外部性的私人解决方法：科斯定理与交易成本

## 为什么从「私人解决外部性」开始

前两节讲的是政府治外部性——管制、矫正税、许可证。但政府出手并非唯一途径：现实中，很多外部性**当事人自己就解决了**——邻居商量好谁修剪共用的树、污染工厂私下补偿受害农户、租房合同里约定噪音条款。**当交易成本低、产权清晰时，人们会自己「讨价还价」到最优结果**——这就是**科斯定理（Coase theorem）**。

这一节揭示一个改变政策观念的思想：**外部性问题的根源，常常不是「市场失灵」，而是「产权没界定清楚」**。只要产权清晰、交易成本够低，私人协商就能解决外部性，无需政府插手。但现实里交易成本往往不低——所以政府仍有存在价值。这一节用两个例子讲清科斯定理，再讲它为何在现实中常常「失效」。

## 1 科斯定理：产权清晰 + 交易成本为零

**科斯定理（Coase theorem）**：**如果产权界定清楚，并且交易成本为零，那么私人协商可以解决外部性问题，资源配置将达到有效率的结果——无论初始产权归谁。**

**科斯定理的核心主张**：外部性问题的关键，不是「谁污染了谁」，而是**「产权到底属于谁」**——只要产权归了某方，另一方愿意出钱「购买」或「赔偿」，双方就能谈成有效率的结果。<span class="marginnote">科斯定理的颠覆性在于：<strong>它把外部性从「政府必须干预的失灵」改判为「产权与交易成本问题」</strong>——如果产权清晰、谈判免费，市场（私人协商）自己就能「内化外部性」，根本不需要庇古税。这个思想 1960 年发表，让科斯拿了 1991 年的诺贝尔经济学奖。</span>

**科斯定理的两个条件缺一不可**：
- **产权清晰**：谁有权做什么，法律说清楚了；
- **交易成本为零**：谈判、签约、执行都不花钱。

**结果与初始产权无关（但有分配差异）**：无论产权归受害者还是污染者，**最终的有效率结果相同**——只是「谁付钱」不同。

## 2 科斯定理的例子：狗吠与污染

用教科书最经典的两个例子，把科斯定理「演」一遍。

**例子一：邻居的狗叫。** 迪克养了只爱叫的狗，邻居迪更被吵得睡不着。狗的叫声是负外部性（噪音）。假设迪克养狗获得 500 元的快乐，迪更的睡眠值 800 元。

- **若产权归迪克（有权养狗）**：迪更付迪克 500–800 元，请他停止养狗（或戴消音器）——迪克收钱 > 养狗的快乐，迪更付钱 < 睡眠的价值，**双方成交**，狗不叫了，效率最优。
- **若产权归迪更（有权安静）**：迪克付迪更 500–800 元，买下养狗权——迪克付出 < 养狗快乐，迪更收钱 > 睡眠价值，**双方成交**，狗继续叫，但效率同样最优（狗的价值 500 < 迪更睡觉价值 800？不——这里迪克愿意付到 500，迪更要价至少 800，迪克付不起 800！于是交易不成交，狗不叫）。<span class="marginnote">仔细推演这个例子，科斯定理的「无论初始产权如何都有效」需要一点微调：<strong>当养狗价值（500）小于睡眠价值（800）时，两种产权安排下「不养狗」都是有效率的结果</strong>——产权归迪克时迪更买断（花 600，值），产权归迪更时迪克买不起（500<800，交易破裂，结果还是不养狗）。<strong>有效率结果相同，只是谁掏钱不同</strong>。若养狗价值是 900 而睡眠值 800，则两种安排下「养狗」都是结果——科斯定理的精神依然成立。</span>

**例子二：工厂污染。** 化工厂向河里排污，下游渔场受损。工厂减排成本 200 万，渔场损失 300 万。

- **若产权归工厂（有权排污）**：渔场付工厂 200–300 万，请它安装净化设备——**成交，净化，总成本 200 万**；
- **若产权归渔场（有权干净水）**：工厂付渔场 200–300 万，买下排污权——但工厂若继续排污，渔场损失 300 万；工厂减排只要 200 万，**工厂宁可自己减排**——**成交，净化，总成本 200 万**。

**两种产权下，结果都是「净化」——效率最优，且总成本相同（200 万），只是谁掏钱不同（产权归工厂则渔场掏，反之工厂掏）。**<span class="marginnote">这个例子的妙处：<strong>科斯定理说「结果有效率」，但没说「谁出钱」</strong>——产权归谁，决定谁付钱（分配问题），但不影响最终结果（效率问题）。这呼应第 7 章「效率与分配分开」——科斯定理把外部性问题还原成「效率自动达成，分配由产权决定」。</span>

## 3 科斯定理在现实中的限制：交易成本

科斯定理的结论太美，以至于现实里常常不成立——因为它的两个条件（产权清晰、零交易成本）在现实中很难满足。教科书列出几大障碍：

**交易成本（transaction costs）**：**双方达成协议所需的成本**——信息搜集、谈判时间、签约费用、执行监督。交易成本 > 0 时，私人协商可能无法达成有效率的结果。

**现实中的交易成本来源**：

- **谈判成本**：涉及方太多，谈判旷日持久。空气污染影响几百万人，让几百万人坐一起谈判？不现实。<span class="marginnote">科斯定理的「隐形前提」是当事人少——<strong>污染影响的人越多，谈判成本越高，科斯定理越不适用</strong>。这解释了为什么「邻居噪声」能私下解决（涉及两家人），而「空气污染」需要政府出手（涉及几百万人）。<strong>外部性的「人数规模」决定它需要哪种解决机制。</strong></span>
- **信息不对称**：双方不知道对方的真实成本/收益，谈判无法定价。
- **搭便车**：涉及多人时，每个人都想让别人付钱、自己受益——集体行动失败（第 14 章公共物品的伏笔）。
- **产权模糊**：污染者是谁、受害范围多大、法律没说清——产权不清，无从谈判。

**科斯定理的教训**：**它不是一个「政府无需干预」的结论，而是一个「交易成本很高时政府为何需要干预」的框架**——交易成本低，私人解决；交易成本高，政府介入。

## 4 公式解析：科斯谈判的收益分配

把科斯谈判写成「收益分配」的公式，能更精确地看它如何达成效率。

设污染工厂的减排成本为 $C$（工厂减排的花费），受害者损失为 $L$（继续污染时受害者的损失）。社会最优：**减排当且仅当 $C < L$**（减排的成本低于损失）。

**第一步，判断有效率结果**：若 $C < L$，减排划算——社会最优是「减排」；若 $C > L$，不减排划算——社会最优是「继续排污 + 赔偿」。

**第二步，看谈判能否达成**（以 $C < L$ 为例）：
- **产权归受害者**：工厂减排自己花 $C$，或者继续排污赔 $L$——工厂选便宜的：减排（$C < L$）。**结果：减排，效率最优。**
- **产权归工厂**：受害者付工厂 $C$（请他减排）或承受损失 $L$——受害者选便宜的：付钱（$C < L$）。**结果：减排，效率最优。**

**第三步，读谈判区间**：只要存在「双方都比现状好」的价格区间 $[C, L]$，谈判就能成交——**成交价落在区间内任一点，双方都获益，效率达成**。<span class="marginnote">这个「$[C, L]$ 区间」与第 3 章贸易价格区间 $[2, 4]$ 是同构的：<strong>交易可能发生的充要条件是「买方最高愿付 ≥ 卖方最低要价」</strong>。科斯谈判、贸易、任何自愿交易，都在「双方保留价格区间」里成交——<strong>这个「区间非空即成交」的原理，是微观经济学最通用的定理之一</strong>。</span>

**第四步，读分配**：成交价落在区间哪一点，由**议价能力**决定——靠近 $C$ 则工厂吃亏、受害者占优；靠近 $L$ 反之。**效率与分配再次分离：谈判保证「有效率」，议价决定「谁得利」。**

## 5 科斯定理与政策：什么时候该信它

科斯定理对政策设计有重要启示，但也有明确边界：

**该信科斯定理的时候**：当事人少、产权可界定、谈判成本低——**私人物品的小范围外部性**。邻居纠纷、厂商与农户的局部污染、相邻产业的水权——这些可以靠协商与法律（侵权诉讼）解决，无需政府直接管制。

**不该信的时候**：涉及大量人口、产权模糊、谈判成本极高——**公共物品型的外部性**。空气污染、气候变暖、海洋捕捞——这些是「几百万人的谈判」，科斯条件完全不成立，**必须靠政府（管制、税、许可证）或国际协议**。<span class="marginnote">科斯定理给政府的「分诊」建议：<strong>先看能否界定产权、能否降低交易成本——能，就让私人解决（政府只负责「界定产权 + 降低交易成本」）；不能，政府才直接干预</strong>。很多环境政策的「最佳设计」其实是科斯式的——比如排污许可证制度（第 37 篇），本质就是政府「界定污染权 + 建立交易市场」来降低交易成本。</span>

**辨析｜易错点：科斯定理是不是「证明政府无用」？** 不是。科斯自己也不这么认为——他的意思是：**外部性问题的第一问，应该是「交易成本高不高」**。交易成本低，市场能自理；交易成本高，市场失灵，政府该出手。**科斯定理是「政府干预边界」的探测器，不是「政府无用论」的论证。**

## 6 科斯定理的实战：从水权到数据产权

科斯定理最有价值的应用，是它给出的**「先界定产权、再让市场协商」**的政策思路——几个现实案例：

**水权交易**：水资源紧缺时，政府把「用水权」界定清楚、允许水权买卖——**农场主可以把水卖给城市（高价值用途）**，双方谈判成交——**水被配置到最值钱的地方，且无需政府指挥**。这是科斯式「界定产权 + 市场交易」的成功实践。

**污染权交易**：可交易排污许可证（第 37 篇）本质是科斯式——**政府界定「排污权」（总量）、市场决定「谁排多少」**——**产权化 + 市场分配，比「命令式管制」更高效**。

**数据产权之争**：AI 时代的数据——**数据算谁的？** 界定「数据产权」让个人拥有自己的数据、平台获取需付费/授权——**科斯定理预言：只要产权清晰 + 交易成本低，数据就能通过市场谈判配置到最有价值处**（训练 AI vs 个人隐私，让市场去谈）。<span class="marginnote">科斯定理给政策制定者的「标准答案」：<strong>面对资源冲突（水、污染、数据、频谱），先问「能不能界定产权」——能，就让市场协商（政府只负责降低交易成本）；不能，才轮到直接管制</strong>。频谱拍卖、排污权交易、水权市场都是这条思路的成功——<strong>「界定产权，往往比命令管制更便宜、更有效」</strong>。</span>

**科斯式思维的边界**（复习第 38 篇）：**当事人多、谈判成本高时，科斯定理失效**——空气污染（几百万人）不能靠谈判、只能靠管制。**「科斯定理是个探测器：能界定产权且交易成本低，私人解决；否则政府介入」**——记住这个分诊逻辑，你对「该不该政府干预」的判断就有了准星。

**再补一个「科斯定理的常见误读」辨析清单**，把最容易错的三点钉死：

**误读一：「科斯定理证明政府无用」。** 错——科斯定理说的是「交易成本为零时政府无用」；现实交易成本几乎总为正，所以**政府（界定产权、降低交易成本、直接干预）仍有大量用武之地**——「科斯定理是'政府干预的边界探测器'，不是'政府无用论'」。

**误读二：「产权归谁都一样，所以不用管归谁」。** 错——科斯定理说「效率结果相同」，但**分配结果完全不同**（谁付钱、谁受益）——产权归受害者 → 污染者赔偿；产权归污染者 → 受害者付钱——**「效率一样，公平不一样」——产权的初始分配仍是重大政策问题**。

**误读三：「只要有谈判，就有效率」。** 错——谈判要有效率，需要**完全信息 + 零交易成本 + 无策略性行为**（漫天要价、僵持不下都可能让谈判破裂）——**「谈判可能失败，科斯定理是'理想情形'的结论」**。<span class="marginnote">三个误读的根源：<strong>科斯定理是「条件句」（若产权清晰 + 交易成本为零，则私人解决有效率）——把「若」当「总是」，就会误读</strong>。经济学里凡「定理」，都要问「前提是什么」——<strong>「科斯定理的前提越严格，它的现实适用面越窄；但它揭示的'产权与交易成本'视角，永远有价值」</strong>。</span>

**核心视角**：科斯定理的价值不在「结论」而在「视角」——**它把外部性问题从「政府必须管」转向「先看产权与交易成本」**——这个视角转换，是第 13 章最有思想深度的贡献。

## 7 小结

- **科斯定理**：产权清晰 + 交易成本为零 → **私人协商自动解决外部性，结果有效率，与初始产权无关（只影响分配）**。
- **例子**：狗吠与污染——无论产权归谁，效率结果相同，只是「谁掏钱」不同。
- **交易成本**：谈判、信息、执行、搭便车——**交易成本 > 0 时科斯定理失效，政府干预有理**。
- **谈判区间**：成交发生在双方保留价格区间 $[C, L]$ 内——与贸易价格区间同构，效率与分配分离。
- **应用边界**：当事人少 → 私人解决；涉及面广 → 政府介入——**科斯定理是「要不要干预」的分诊器**。
- **政策启示**：政府的最佳角色常是「界定产权、降低交易成本」，而非直接命令。

第 13 章收官：外部性的诊断、政府药方、私人解方。外部性问题的另一面是——**有些「好东西」市场根本不愿提供**（因为受益者太多、没人愿意付费）。这就进入第 14 章《公共物品和公共资源》。
