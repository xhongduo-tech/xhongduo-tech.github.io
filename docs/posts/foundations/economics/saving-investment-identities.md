# 国民收入账户中的储蓄与投资：一些重要的恒等式

## 为什么从「储蓄与投资的恒等式」开始

上一节介绍了金融体系的「管道」，这一节要回答：**管子里「流多少」由什么决定？** 这需要给「储蓄」与「投资」两个词先「对账」——**在一个封闭经济体里，储蓄必然等于投资。** 这个「必然」不是理论假设，而是**国民收入恒等式**的记账结果。

这一节的核心是几个**重要恒等式**：**储蓄 = 投资、国民储蓄 = 私人储蓄 + 公共储蓄、储蓄 = (Y−T−C) + (T−G)。** 这些等式看似只是「记记账」，但它们是理解「可贷资金市场」（下一节）的骨架——**知道「钱从哪来、到哪去」，才能分析利率如何被决定。**

## 1 恒等式一：储蓄 = 投资

先回到最根本的恒等式。在**封闭经济**（无国际贸易）中，GDP 恒等式（第 47 篇）简化为：

$$
Y = C + I + G
$$

其中 $Y$ GDP、$C$ 消费、$I$ 投资、$G$ 政府购买。移项：

$$
Y - C - G = I
$$

**左边是「国民储蓄」**（$Y - C - G$），右边是投资——于是：

$$
S = I
$$

**在封闭经济中，储蓄必然等于投资。**<span class="marginnote">「储蓄=投资」是宏观最基础的恒等式：<strong>封闭经济里，没花掉的钱（储蓄）必然被用于投资——因为「没被消费掉」的产出只能是「投资品」</strong>。想清楚：一国一年生产 $Y$，消费掉 $C$，政府用 $G$，剩下的 $Y - C - G$ 若不是投资，还能去哪？<strong>「储蓄与投资是同一笔产出的两面」</strong>——这是记账，不是理论。</span>

**为什么这个恒等式重要？** 因为它把「储蓄」（资金供给）与「投资」（资金需求）连成一体——**下一节可贷资金市场的起点**：储蓄多 → 可贷资金供给多；投资多 → 可贷资金需求多。

## 2 国民储蓄的两半：私人储蓄 + 公共储蓄

把国民储蓄拆成两块，政策含义立刻显现。设 $T$ 是政府税收（净税收 = 税收 − 转移支付）：

**私人储蓄（private saving）**：**家庭在支付税收和消费之后剩下的收入。**

$$
S_{私人} = Y - T - C
$$

**公共储蓄（public saving）**：**政府在税收和支出之后剩下的收入。**

$$
S_{公共} = T - G
$$

**国民储蓄 = 私人储蓄 + 公共储蓄**：

$$
S = (Y - T - C) + (T - G) = Y - C - G
$$

**验证**：两项相加，$T$ 抵消，回到 $Y - C - G$。<span class="marginnote">国民储蓄的「两半」结构非常有用：<strong>私人储蓄 $Y - T - C$（家庭剩的）、公共储蓄 $T - G$（政府剩的）</strong>——两者相加就是总储蓄。政策对储蓄的影响可以从两半分别看：减税 → 私人储蓄增、公共储蓄减；政府支出增 → 公共储蓄减。<strong>「政府储蓄可以抵消或放大私人储蓄」——预算赤字就是在「吃」公共储蓄。</strong></span>

**公共储蓄的三个状态**：
- $T > G$：**预算盈余（budget surplus）**——公共储蓄为正，政府「存钱」；
- $T < G$：**预算赤字（budget deficit）**——公共储蓄为负，政府「花钱超过收入」；
- $T = G$：**预算平衡**——公共储蓄为零。

**赤字 = 负的公共储蓄**——**政府赤字会「吃掉」一部分国民储蓄，减少可用于投资的资金。**

## 3 公式解析：储蓄恒等式的完整推导

把「储蓄 = 投资」从 GDP 恒等式一步步推出来，并解释每一项。

**封闭经济，GDP 恒等式**：

$$
Y = C + I + G
$$

**第一步，移项**：把 $C$、$G$ 移到右边：$Y - C - G = I$。

**第二步，拆 $Y - C - G$**：插入净税收 $T$（加一项再减一项，等式不变）：

$$
Y - C - G = (Y - T - C) + (T - G)
$$

**第三步，识别两个储蓄**：$(Y - T - C)$ 是私人储蓄、$(T - G)$ 是公共储蓄——于是：

$$
S_{私人} + S_{公共} = I
$$

**第四步，读结论**：**私人储蓄 + 公共储蓄 = 投资**——国民储蓄恒等于投资。<span class="marginnote">这个推导的「关键技巧」是「插入 $T$」：<strong>加一项减一项，等式不变，但把储蓄拆成了「私人的」与「公共的」两半</strong>。做题时只要记得「$Y - C - G$」可以写成「$(Y-T-C) + (T-G)$」，储蓄恒等式就自己长出来了。<strong>「恒等式不是记忆，而是变换」——掌握变换，恒等式全是推导。</strong></span>

**用数字走一遍**：$Y = 100$、$C = 60$、$G = 20$、$T = 25$：
私人储蓄 = $Y - T - C = 100 - 25 - 60 = 15$；
公共储蓄 = $T - G = 25 - 20 = 5$；
国民储蓄 = $15 + 5 = 20$，投资 $I = Y - C - G = 100 - 60 - 20 = 20$——**储蓄 20 = 投资 20，恒等。**

## 4 预算赤字对储蓄的影响

恒等式最有用的应用，是分析**政府预算赤字对投资的影响**。

**预算赤字（$G > T$）→ 公共储蓄为负 → 国民储蓄下降**（若私人储蓄不变）→ 储蓄 = 投资 → **投资下降**。

**机制**：政府花得比收得多，缺口要靠**借债**补——政府借债「吸走」了市场上的资金，留给私人投资的资金就少了。**「政府赤字挤出私人投资」——这就是下一节「挤出效应」（crowding out）的伏笔。**<span class="marginnote">预算赤字与投资：<strong>政府赤字 = 负的公共储蓄 → 国民储蓄下降 → 可贷资金供给减少 → 利率上升 → 私人投资被挤出</strong>。这条链是「财政赤字有害增长」的核心机制——它通过「挤占储蓄」降低了投资，进而降低了资本积累与长期增长（第 21 章）。<strong>「今天的赤字，是明天的利率上升与投资减少」</strong>。</span>

**但赤字不总「坏」**：若政府借债用于**生产性投资**（基础设施、教育）——借来的钱变成资本积累——则「挤出的私人投资」被「公共投资」替代，净效果未必差。**「赤字好坏，取决于钱花在哪」——用于消费的赤字挤投资，用于投资的赤字可能不挤。**

## 5 从恒等式到市场：可贷资金的预告

储蓄与投资的恒等式告诉我们「总量相等」，但没回答「**利率怎么定**」——这需要引入**可贷资金市场（market for loanable funds）**：

**资金供给**：储蓄（私人 + 公共）——**愿意把闲置资金借出的人**；
**资金需求**：投资（企业借款、政府借款）——**需要资金的人**；
**价格**：**利率**——资金的「租金」。

**利率是「资金的均衡价格」**：储蓄多（供给多）→ 利率降；投资旺（需求大）→ 利率升。**下一节把「储蓄=投资」的恒等式变成「可贷资金市场的均衡」，利率浮出水面。**<span class="marginnote">「恒等式」与「市场」的关系要分清：<strong>恒等式是记账（储蓄必然=投资，无需解释），可贷资金市场是行为（利率让供给与需求平衡）</strong>。恒等式告诉我们「总会相等」，市场告诉我们「凭什么相等——因为利率会调整」。<strong>「记账告诉你相等，市场告诉你利率如何让它们相等」</strong>。</span>

**封闭 vs 开放**：本节假设封闭经济（$S = I$）。开放经济里储蓄不必等于本国投资（可以借给外国）——第 25 章开放经济会放宽这个假设。

## 6 储蓄恒等式的实战：为什么「个人多存钱」未必「国家多储蓄」

储蓄恒等式最反直觉的应用，是「节俭悖论」（paradox of thrift）——**个人多储蓄，国民储蓄可能不增反降**：

**个人层面**：你多存 1000 元——你的私人储蓄增加 1000 元——「储蓄是好事」。

**宏观层面**：你多存 1000 元意味着你少消费 1000 元 → 商家的收入减少 1000 元 → 商家少雇人、少生产 → **别人的收入也下降** → 别人也减少储蓄……——**「人人多储蓄，总需求下降，收入下降，国民储蓄反而可能下降」**。

**这就是节俭悖论**：**「个人节俭是美德，全民节俭可能是灾难」**——储蓄恒等式（$S = I$）在短期被「收入变动」改写：**储蓄意愿上升 → 消费降 → 收入降 → 储蓄（收入×储蓄率）未必上升**。<span class="marginnote">「节俭悖论」的宏观逻辑：<strong>个人储蓄是「从消费里省下来」，但一个人的消费是另一个人的收入——全民多省 → 全民收入降 → 可储蓄的总量反而缩水</strong>。这解释了为什么经济衰退时政府常「鼓励消费」而非「鼓励储蓄」——<strong>「短期看需求（消费是增长引擎），长期看供给（储蓄是资本来源）——悖论只在短期成立」</strong>。</span>

**长短期之分**：短期（需求不足时），储蓄意愿过高抑制经济；长期（资本积累时），高储蓄支撑增长——**「同一个储蓄，短期是'勒紧腰带'，长期是'播种未来'"**。这正是第 64 篇「储蓄与投资」增长政策与第 24 章「消费刺激」政策的张力所在——**「理解节俭悖论，就理解了宏观政策的两难」。**

## 7 小结

- **储蓄 = 投资（封闭经济）**：$Y - C - G = I$——**记账的必然，不是假设**。
- **私人储蓄**：$Y - T - C$；**公共储蓄**：$T - G$——**国民储蓄 = 两者之和**。
- **预算赤字 = 负的公共储蓄**——**赤字减少国民储蓄、减少投资（挤出效应伏笔）**。
- **推导技巧**：$Y - C - G = (Y-T-C) + (T-G)$——**插入 $T$ 拆出两半**。
- **恒等式 vs 市场**：恒等式说「必然相等」，市场说「利率让它们相等」。
- **预告**：可贷资金市场——利率是资金的均衡价格（下一节）。

储蓄与投资「对上了账」，但「利率怎么定」还没回答——**利率是储蓄与投资的均衡价格，而它由可贷资金市场的供求决定。** 下一节《可贷资金市场》：储蓄激励、投资激励与政府预算赤字如何作用于利率。
