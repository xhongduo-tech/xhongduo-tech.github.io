## 为什么从地磁要素开始

从极限到大模型，我们最终要理解的是「地球如何被一层看不见的场保护着」。但在讨论发电机、倒转、漂移之前，必须先有一把**丈量这个场的尺子**——那就是**地磁要素（geomagnetic elements）**。它是整个地磁学与古地磁学的第一语言：测磁仪器读出的是要素的数值，岩石记下的也是要素的函数，地磁场的球谐模型输入输出的还是要素。这一篇把「地球磁场长什么样、怎么描述、几个要素如何互相换算」讲清楚，下一篇就可以把全场写成球谐函数的级数，再往后才谈得上让岩石开口说话。

## 1 地磁场：从一根指南针说起

地磁场最朴素的表现是一根自由悬挂的磁针。把它支起来，它会绕竖直轴转，最终指向一个水平方向——这个方向**不是地理正北**，而是磁北。这一偏转就被记作地磁要素里的第一个成员：**磁偏角（declination，记作 $D$）**。<span class="marginnote">磁偏角的历史几乎等于地磁学的历史：中国人早在 11 世纪就发现罗盘不完全指南，沈括在《梦溪笔谈》里写「然常微偏东，不全南也」。欧洲的磁偏角观测则催生了哥伦布时代以后的全球磁场测绘。</span>

再让磁针能在竖直面里自由转动（如测斜仪），它会倾斜一个角度，在北半球针尖向下指，在南半球针尖向上翘。这个与水平面的夹角叫**磁倾角（inclination，记作 $I$）**。磁倾角在赤道附近接近 0°，在磁极附近接近 ±90°。<span class="marginnote">磁倾角是古地磁的命根子：它直接反映岩石形成时的地磁纬度。一块含铁岩石若记录了 60° 的倾角，就说明它形成在纬度约 48° 处——这个换算公式我们后面用球谐模型严格导出。</span>

把这两件事合起来，地磁场在任意一点其实是一个**三维矢量**：有大小、有方向。描述它需要一组相互关联的量，这一组量合起来就是**地磁要素**。

## 2 七个要素与一张关系图

在某一观测点，地磁要素共有七个，习惯上按下述方式定义：

- **磁偏角 $D$**：水平面内，地理北与磁北方向的夹角，向东偏为正。
- **磁倾角 $I$**：磁矢方向与水平面的夹角，向下为正。
- **水平分量 $H$**：磁矢在水平面的投影，即水平磁力强度。
- **北向分量 $X$**：$H$ 在地理北方向的分量。
- **东向分量 $Y$**：$H$ 在地理东方向的分量。
- **垂直分量 $Z$**：磁矢在竖直方向的分量，向下为正。
- **总强度 $F$**（也叫 $T$）：磁矢本身的模，是水平分量与垂直分量的合矢量长度。

这七个量并不独立，它们由三个自由度完全决定。最常用的一组独立变量是 $(D, I, F)$，其余四个都能从它们推出。它们之间的几何关系是：$X, Y, H$ 位于水平面内，$Z$ 竖直向下，$F$ 是 $H$ 与 $Z$ 的合矢量；$D$ 是 $X$ 与 $H$ 的夹角，$I$ 是 $F$ 与 $H$ 的夹角。

**地磁要素的次序，就是把一个三维矢量拆成「水平面内两个角 + 长度」三个自由度的过程。** 之所以不直接给直角坐标 $(X, Y, Z)$，是因为罗盘天然给出方向角，古地磁测量也天然记录偏角与倾角——要素是「测量语言」，直角坐标是「计算语言」，两者之间必须反复互译。

## 3 公式解析：要素之间的换算

要素换算的核心是一连串直角三角形关系，下面这条总式把七个量串在一起：

$$
F = \sqrt{H^2 + Z^2}, \qquad
H = F\cos I, \qquad
Z = F\sin I, \qquad
X = H\cos D, \qquad
Y = H\sin D, \qquad
\tan I = \frac{Z}{H}
$$

对这套公式做四步拆解：

- **第一步，$H$ 与 $Z$ 合成 $F$**：$H$、$Z$ 互相垂直，合成矢量 $F$ 的模由勾股定理给出 $F = \sqrt{H^2+Z^2}$，方向由 $\tan I = Z/H$ 决定。<span class="marginnote">这一条物理上把「水平力」与「竖直力」合成了「磁力的真实方向」。测量垂直分量用磁秤，测量水平分量用偏角仪，分开测、再合成，是经典地磁台的日常操作。</span>
**第二步，由 $F$ 与 $I$ 回推 $H, Z$**：把 $H = F\cos I$、$Z = F\sin I$ 代入勾股式，得到 $F\cos I$ 与 $F\sin I$ 是两个直角边，恰好等于水平与垂直投影——这是球坐标到直角坐标的投影，与天文上把天体位置投影到地平坐标完全同理。
**第三步，$H$ 分解为 $X, Y$**：水平分量在偏角 $D$ 的坐标系里再分解一次，$X = H\cos D$、$Y = H\sin D$，于是东向分量 $Y$ 正是「偏角不为零」的直接度量。
- **第四步，用途反过来说明**：已知某点 $(D, I, F) = (10°, 60°, 50000\,\mathrm{nT})$，立刻得 $H = 50000\cos 60° = 25000\,\mathrm{nT}$，$Z = 50000\sin 60° \approx 43301\,\mathrm{nT}$，$X = 25000\cos 10° \approx 24620\,\mathrm{nT}$，$Y = 25000\sin 10° \approx 4341\,\mathrm{nT}$。七要素一次算全。

**辨析｜易错点：** 初学者最容易把「磁偏角 $D$」与「磁倾角 $I$」记反——记住：偏角是「偏了几度」，在水平面内衡量罗盘偏离地理北；倾角是「倾斜了几度」，在竖直面内衡量磁力线插入地面的陡度。另一个易错点是垂直分量 $Z$ 的正负约定：北半球 $Z > 0$（向下），南半球 $Z \lt  0$（向上），不同教科书符号约定可能相反，读文献务必先看作者约定。

## 4 地磁场的基本特征：偶极场、磁极与量级

把全球的地磁要素画到地图上，第一眼印象是：磁场像一个放在地心、略微倾斜的**磁偶极子**产生的场。偶极轴与地球自转轴夹角约 **11°**，偶极磁北极位于地理南极附近、偶极磁南极位于地理北极附近——这正是指南针指南的原因。<span class="marginnote">「磁北极在地理南极附近」这句话常把人绕晕。物理惯例：磁力线从磁北极出发、进入磁南极；罗盘 N 极指向地理北，意味着地理北极附近的场点是磁力线的汇入点，即磁南极。把「磁南极/北极」与「地理南北」分开记，是避免一切混乱的关键。</span>

磁场的量级与结构有四个值得记住的特征：

**强度**：总强度 $F$ 在全球从赤道的约 $25000\,\mathrm{nT}$ 到磁极附近的约 $65000\,\mathrm{nT}$ 之间变化，单位 **nT（纳特斯拉）**，$1\,\mathrm{nT} = 10^{-9}\,\mathrm{T}$。<span class="marginnote">nT 也叫 γ（伽马），是地磁界历史遗留的单位；现代文献已统一用 nT。作为参照，地球磁场只有实验室电磁铁磁场的几万分之一，却足以在数百万年里给岩石「印上」稳定的记录。</span>
**偶极占比**：全球磁场的约 90% 可用中心偶极子描述，剩余约 10% 是**非偶极部分**（四极子、八极子等高阶项），它们构成长期变化的来源。
**磁极位置**：实测的（非偶极的）地磁极与现代的偶极磁极并不重合，且随时间漂移；日常导航用的「磁北」是当地实际磁场方向，不是偶极磁极方向。
- **场源分层**：地表观测到的场绝大部分来自**地球内部**（地核发电机），少量来自地壳岩石与高空电离层、磁层——这为后面「主磁场 + 地壳磁异常」的分解埋下伏笔。

## 5 地磁要素与古地磁的接口

要素不是只供导航的摆设，它是古地磁学的**数据出口**。一块定向岩心测出的天然剩磁，第一步就是整理成偏角 $D$、倾角 $I$；古地磁学家后续所有的统计与重建——计算虚拟地磁极（VGP）、拟合 Fisher 分布、画视极移曲线——全部从 $(D, I)$ 出发。<span class="marginnote">所以本篇看似只是「地磁学常识」，实际是古地磁全套流程的入口。后面《虚拟地磁极（VGP）与 Fisher 统计》一篇会把 $(D, I)$ 换算成地磁极位置，公式里处处用得上本篇的三角函数骨架。</span>

还有一个值得建立的心理模型：**倾角 $I$ 与纬度之间存在单调关系**。在中心偶极子假设下，$I$ 从赤道的 0° 增长到磁极的 90°，赤道附近每往两极走约 1° 纬度，$I$ 约增大 1.7°。于是「测出倾角 → 反推古纬度」成为古地磁最古老也最有力的工具：一块在低纬度形成的岩石若今天处于高纬度，就证明它所在的地块发生过纬向漂移——这是大陆漂移说最早的地磁证据之一，我们到《视极移曲线与大陆重建》再展开。

## 6 地磁台：连续观测的哨站

地磁要素不止是书本上的定义，它们每天被全球数百个**地磁台站（geomagnetic observatory）** 逐分钟、逐小时地记录着。一座标准地磁台做的事，是把这一篇的全部要素「实测化」：

**相对记录**：用磁通门磁力仪连续记录 $H, D, Z$（或 $X, Y, Z$）随时间的变化，采样率常达每秒一次；
**绝对标定**：定期用质子旋进磁力仪与偏角/倾角仪做绝对测量，把连续记录「钉」到绝对标尺上；
- **日变与长期变化分离**：逐日平均得到日变化，逐月/逐年平均得到长期变化——两种信号在地磁台数据里被清楚地区分开来。<span class="marginnote">地磁台数据是地球物理学的基础设施：IGRF 模型的构建、空间天气的监测、导航用的磁偏角图，全都依赖地磁台的连续观测。一个台站几十年的记录，就是一篇「要素如何随时间演化」的活教材。</span>

地磁台数据的整理有一个专门的规范流程：先扣基线漂移、再做日变校正，最后按国际规范发布「地磁台年报」。读一篇地磁长期变化论文时，数据来源往往就是某台站几十年的月均值序列——要素的七个符号，在这条序列里获得了生命。

**把要素放进台站的语境，能纠正一个常见误解**：七个要素看似只是「换算」，但实际测量各有各的仪器与误差源——$H$ 用石英水平磁力仪或质子仪、$D$ 用偏角仪、$Z$ 用垂直磁秤。**每个要素的误差特征不同**，换算公式传播误差的方式也不同，这是实测数据处理里的一个重要细节。

## 7 思考与进阶：要素如何通向整个学科

地磁要素是这门学科最小的一环，但把它「放大」看，整个知识树都从这套记号长出来：

**要素 → 球谐模型**：七个要素只是局部的描述，要把它变成全球图景，需要球谐展开（下一篇）——要素是「测量语言」，球谐系数是「模型语言」。
**要素 → 长期变化**：地磁台年复一年记录要素，几十年序列就是长期变化（第 3 篇主题）的第一手资料。
- **要素 → 导航与工程**：磁偏角修正海图、磁航向，要素是导航的底层数据，也是 IGRF 的输入输出。
- **要素 → 行星磁学**：火星、月球也有「要素」——只是那里的场极弱、无全球偶极，测量与解释的思路由此延伸。

**自查清单**：

- [ ] 能否不看公式，说出 $D, I, F, H, X, Y, Z$ 各自的几何含义？
- [ ] 已知 $(D, I, F)$，能否一步步算出 $X, Y, Z$？
- [ ] 能否解释「磁北极在地理南极附近」这句话的物理来源？
- [ ] 能否区分偏角 $D$（水平）与倾角 $I$（竖直）的测量对象？

**一个开放问题**：全球磁场约 90% 是偶极，剩下 10% 的非偶极部分为什么长期存在？它来自核幔边界哪些特定的流动结构——这个问题要到《发电机理论》与《地核动力学》两篇才能展开。<span class="marginnote">学这一篇时最值得养成的习惯，是把每个要素都想象成「一块磁铁在空间中的姿态」：偏角是它在水平面转的角度，倾角是它在竖直面俯仰的角度，总强度是它的大小——七个要素，就是一块空间磁铁的三个姿态自由度加一个大小的不同投影。</span>

## 8 小结

- 地磁要素共七个：$D, I, H, X, Y, Z, F$，由 $(D, I, F)$ 三个自由度完全决定。
- 换算核心是两轮直角投影：$F = \sqrt{H^2+Z^2}$、$\tan I = Z/H$、$X = H\cos D$、$Y = H\sin D$。
- 主磁场近似为**地心倾斜偶极子**，偶极轴与自转轴夹角约 11°，偶极场占总场的约 90%。
- 磁极与地理极不重合，「磁北极在地理南极附近」的表述源于磁力线方向约定。
- 强度量级 $25000\text{–}65000\,\mathrm{nT}$，单位 nT 即 $10^{-9}\,\mathrm{T}$。
- 偏角 $D$（水平偏离）与倾角 $I$
