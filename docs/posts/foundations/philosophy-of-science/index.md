# 科学史与科学哲学

从泰勒斯仰望星空到量子力学的奠基，科学史记录了人类理解自然方式的每一次跃迁；科学哲学则追问科学何以可能、如何进步、是否逼近真理。本分类覆盖从古代自然哲学到当代科学论战（Science Wars）的通识全景，章目对标丹皮尔《科学史》、科恩《科学中的革命》、库恩《科学革命的结构》与罗森堡《科学哲学》等经典著作。
