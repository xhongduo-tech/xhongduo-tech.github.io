## 为什么从美德伦理开始

前面几篇提供了原则（第 3 篇）与机制（第 5、6 篇），但都绕开了一个朴素的事实：**最终执行道德的，是活生生的人**。原则再漂亮，若设计者、监管者、使用者本身缺乏判断力与品格，一切都会落空。香农 · 瓦洛（Shannon Vallor）的《技术与美德》正是冲着这个缺口而来——她要复兴亚里士多德的美德伦理，让它成为技术时代的第一伦理语言。<span class="marginnote">瓦洛的立场一句话可概括：我们不应只问「这项技术是否合规」，更应问「这项技术会把我塑造成什么样的人、把社会塑造成什么样」。她在 2016 年出版此书时，正值 AI 伦理「原则潮」前夜，此书成了后来「美德进路」的必引之作。</span>

美德进路的复兴还有一个现实背景：**规则在「原则潮」里爆炸，而行动者没有同步变好**。几百份 AI 伦理宣言（第 3 篇提过）可以被任何一个企业随手引用，但「引用规则」与「具备判断力」之间隔着一整条品格的养成之路——这正是美德伦理要补的那一段。

## 1 伦理学的三大传统

要理解美德伦理，先看它与另外两大传统的分工。两千多年来，西方伦理学给出过三种回答「我该如何行动」的进路：

| 传统 | 核心问题 | 判断标准 | 代表 |
| --- | --- | --- | --- |
| 后果论 | 哪种做法后果最好？ | 结果（效益、幸福） | 边沁、密尔 |
| 义务论 | 我的义务/规则是什么？ | 规则（理性、普遍化） | 康德 |
| 美德伦理 | 我该成为什么样的人？ | 品格（德性、健全） | 亚里士多德 |

后果论盯结果，义务论盯规则，美德伦理盯**行动者**。<span class="marginnote">三个问题并不是三选一，而是三种视角：本专题第 3 篇的五原则大体是义务论（规则式的），风险分析大体是后果论式的；瓦洛要补的，正是第三块拼图——光有规则与结果，还缺「造就好人」这条线。</span>它们的经典分歧点在于：当规则与结果冲突时（比如「向说谎就能救人的情境」），美德伦理不急着给出裁决程序，而是问「一个智慧而勇敢的人会怎么权衡」。

## 2 美德是什么：品格的习性

亚里士多德把**美德（virtue, aretē）**定义为：**一种稳定的、通过习惯养成的品格倾向，使人倾向于以恰当的方式去感受与行动**。

它有四个特征，值得逐一记住：

**美德是习性（hexis）而非偶然行为**：偶尔帮一次忙不是助人，养成习惯才是。它被「练」出来，不是被「想」出来。
- **美德是中道（golden mean）**：在过度与不及之间取恰当点——勇敢是怯懦与鲁莽的中道，节制是放纵与麻木的中道。<span class="marginnote">注意「中道」不是数学平均值，而是情境化的恰当：对新手勇敢的标准与对老兵不同。这与本专题第 4 篇「公平要情境化」的结论结构完全一致——「恰当」永远依赖语境。</span>
**美德通向繁荣（eudaimonia）**：美德不是自我牺牲，而是人获得美好生活（繁荣、幸福）的方式。
- **美德需要实践智慧（phronesis）**：知道「什么时候、对谁、用多大力度」行事——这是统摄性能力，把各种美德在具体情境里调配起来。

把亚里士多德翻译进技术时代，瓦洛给**技术美德（technomoral virtues）**下了一个定义：**在技术社会（technosocial environment）中使人得以繁荣所需的道德品质**。<span class="marginnote">「技术社会」是瓦洛的关键词：我们与技术共同演化，技术改变我们是谁。所以美德不再是「通用人性」的静态清单，而必须针对技术环境重新刻画。</span>

举个「中道」在技术时代的例子：对算法的态度，怯懦者不敢用、鲁莽者全盘交出去，而审慎者是「知道什么时候该信任、什么时候该保留判断」——美德不是站队，而是在诱惑的两端之间找到那个恰当点。

## 3 技术美德：十二种技术道德美德

瓦洛在《技术与美德》中列出了一张**十二种技术美德**的清单，每一味都对应一种技术时代的诱惑或匮乏：

| 美德 | 针对的诱惑 / 缺失 |
| --- | --- |
| 诚实 Honesty | 数字身份与假新闻中的欺骗 |
| 自制 Self-control | 算法驱动的成瘾与冲动 |
| 谦逊 Humility | 技术全能感的傲慢 |
| 公正 Justice | 算法偏私与数字鸿沟 |
| 勇气 Courage | 面对技术风险的懦弱或鲁莽 |
| 共情 Empathy | 屏幕对面的他者被抽象成数据 |
| 关怀 Care | 技术服务的冷漠化、非人性化 |
| 文明 Civility | 匿名网络中的言语暴力 |
| 灵活 Flexibility | 技术剧变中的僵化 |
| 洞察 Perspective | 沉迷局部而失去整体图景 |
| 宽宏 Magnanimity | 技术胜利后的忘本与自大 |
| 技术道德智慧 Technomoral wisdom | 统摄以上全部，见下节 |

这些美德不是「新发明的道德」，而是**旧美德在新技术条件下的重新规定**。<span class="marginnote">例如「自制」在印刷时代主要指节制饮食与欲望，在算法时代则具体化为「抵抗无限滚动与个性化成瘾」；「共情」在面对面时代靠表情与语气，在数字时代要靠主动想象不在场的他者。</span>

读这张表要抓住一个要领：**每一行美德，都是一次「技术诱惑」的克星**。算法时代最稀缺的不是新的德目，而是把这些旧德目重新翻译进新情境的耐心——「诚实」在深度伪造时代意味着主动标注来源，「关怀」在远程服务时代意味着主动追问屏幕那头的感受。翻译，就是这条清单真正的练习场。

**重点**：这张清单的用处不在「背下来」，而在**把抽象原则变成可培养的品质**——本专题第 3 篇的「不作恶」「可解释」是规则，而「自制」「诚实」是让这些规则真正被落实的人格基础。

## 4 技术道德智慧：统摄性美德

十二种美德之上，还有第十二种、也是统摄性的——**技术道德智慧（technomoral wisdom）**。瓦洛把它定义为：**在技术日益渗透生活的世界里，正确地判断「何时、如何、为什么」运用技术的能力**。<span class="marginnote">对应亚里士多德的 phronesis：不是「知道所有美德」，而是在具体情境里恰当地调配它们——有时要大胆创新，有时要克制等待，有时要果断放弃。</span>

它为什么在技术时代格外稀缺？因为技术环境的三个特征不断挤压人的判断空间：

**速度**：决策被系统提速到人类来不及反思。
- **复杂性**：因果链条太长，后果无法在当下看清。
- **驯化**：技术改变我们的欲望结构，让人「想要的东西」本身被塑造。<span class="marginnote">「驯化」是最深层的问题：推荐算法不只是满足偏好，而是在训练偏好。当人被技术反向塑造，连「我真正想要什么」都需要重新审查——这正是技术道德智慧要保卫的阵地。</span>

技术道德智慧的价值在于：它不提供万能公式，而是培养一种**在不确定中仍然审慎、负责地判断**的能力。这正好弥补本专题第 3 篇指出的「原则无法裁决冲突」的缺口。

技术道德智慧并不是少数「伦理专家」的专利。它更像一种**公民能力**：普通人在看到一条 AI 生成的新闻时，能停下来问一句「这是谁、基于什么、为了什么」；在购买一件「智能」产品时，能分辨它是在服务我还是在塑造我。智慧始于这种随时可用的怀疑。

## 5 辨析：美德进路能做什么、不能做什么

**辨析｜易错点一：** **美德伦理不是决策程序**。它不给你「在两种罪行中选较小者」的算法；它给你的是判断者本人的品格。批评者说这「太含糊」，支持者说这正是它的优点——复杂情境本就没有机械答案。**辨析的要点**：美德进路与规则进路是互补的——规则给出底线，美德给出上限。

**辨析｜易错点二：** **美德不是「让机器有美德」**。瓦洛的美德伦理学对象始终是**人**——设计者、监管者、使用者。说「算法要有同理心」只是隐喻；真正要问的是「用算法的人有没有共情的习惯与能力」。把美德误当成机器的属性，是初学者最常见的错位。<span class="marginnote">这与本专题第 6 篇的辨析遥相呼应：机器可以有「可问责性」的设计属性，但「美德」要求拥有者能反思、能成长——那是人的能力。</span>

**辨析｜易错点三：** **美德清单 ≠ 价值观清单**。把「诚实、关怀」印成海报贴在墙上，不产生任何美德。美德是**经由练习形成的第二本性**，需要组织里的榜样、制度与反复实践——这又回到第 5 篇「警惕伦理洗涤」的告诫。

## 6 小结

- 伦理学三传统：**后果论**看结果、**义务论**看规则、**美德伦理**看行动者；瓦洛为技术时代补上第三块拼图。
- 美德是**通过习惯养成的品格倾向**：有习性、讲中道、通向繁荣、需要实践智慧。
- **十二种技术美德**：诚实、自制、谦逊、公正、勇气、共情、关怀、文明、灵活、洞察、宽宏，外加统摄性的**技术道德智慧**。
- 技术道德智慧是在**速度、复杂性、驯化**三重重压下仍能审慎判断的能力。
- **实践起点**：把技术道德智慧当作公民能力来练习——对每一个「智能」判断保持一次追问。
- **辨析**：美德伦理不是决策程序、对象是人而非机器、美德清单不是标语。

在下一节，我们把美德伦理放进最考验它的战场——**自动化**。当决策越来越多地交给系统，「人的自主性」本身正成为需要保卫的对象。这就是《自动化伦理与自主性》。
