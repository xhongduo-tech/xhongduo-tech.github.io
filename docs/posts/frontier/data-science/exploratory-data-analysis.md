## 为什么从 EDA 开始

数据清洗完毕，很多人急着上模型。但**在拟合任何方程之前，先要认识你的数据**。探索性数据分析（Exploratory Data Analysis，EDA）就是这个过程：用统计量加可视化，快速摸清数据的分布、关系、异常与结构。<span class="marginnote">「EDA」一词由统计学家约翰 · 图基（John Tukey）在 1977 年那本同名著作中系统提出。他主张分析应该先「探索」再「证实」：探索阶段不设严格假设，用灵活的图形与统计量发现线索，再交给正式的假设检验去确认。</span>跳过 EDA 直接建模，就像不看地形就开跑——模型可能在错误的道路上精确地迷路。

## 1 单变量：认识每一列的「长相」

EDA 的第一步是逐个字段检查，称为**单变量分析（univariate analysis）**。对每个变量，我们要回答三类问题。

**第一类：这是什么类型？** 数值型（连续/离散）还是类别型（有序/无序）？类型决定后面用哪些工具——数值型看分布，类别型看频数。<span class="marginnote">类型划分直接影响建模：类别型变量不能直接送进多数模型，需要编码（第16篇《特征工程》）；数值型变量的尺度差异则会影响距离类算法。EDA 阶段把类型记清楚，建模阶段就少踩坑。</span>

**第二类：分布长什么样？** 数值型用直方图、箱线图看集中趋势、离散程度与偏态；类别型用柱状图看各类占比。

**第三类：值域与缺值如何？** 有没有超出常识的值？缺失比例是多少？与清洗阶段的数据质量报告呼应。

核心描述统计量在这一步集中出场：

| 统计量 | 含义 | 对形状的判断 |
| --- | --- | --- |
| 均值 $\bar{x}$ | 算术平均，对极端值敏感 | 均值 > 中位数 → 右偏 |
| 中位数 | 排序后中间的值，稳健 | 与均值差异大 → 有异常值或偏态 |
| 标准差 $\sigma$ | 围绕均值的离散程度 | 大 → 数据分散 |
| 四分位数 $Q_1, Q_3$ | 四等分点的位置 | 用于箱线图与 IQR |
| 众数 | 出现最频繁的值 | 类别型最常用 |

## 2 双变量：看两列之间的「关系」

单变量看「每一列」，双变量分析看「两列之间」。常见组合与工具：

- **数值 × 数值**：散点图 + 相关系数。先画图，再算数——**相关性只捕捉线性关系**，两个变量可能强相关但曲线相关（相关系数却接近 0），图能立刻暴露这一点。
- **类别 × 数值**：分组箱线图或小提琴图，比较各组的分布差异（如「男/女」两组的身高分布）。
- **类别 × 类别**：交叉表（列联表）与堆叠柱状图，看组合频数。

相关系数是我们第一个要算的「关系数值」。对两列数值 $x, y$，样本皮尔逊相关系数定义为：

$$
r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2}\sqrt{\sum_{i=1}^{n}(y_i - \bar{y})^2}}
$$

**辨析｜易错点：** 皮尔逊相关系数有三个经典陷阱。其一，**它只度量线性相关**：$y = x^2$ 在 $x \in [-1,1]$ 上两个变量完全相关，$r$ 却可能接近 0。其二，**它受异常值影响大**：一个离群点可以把 $r$ 从 0.9 拉到 0.2。其三，**相关不等于因果**：冰淇淋销量与溺水人数高度相关，是因为共同受「夏天」驱动——这是第1篇就立下的认识论底线。EDA 阶段看到的「关系」，只适合当作线索，不适合当作结论。

## 3 多变量：相关矩阵与分组洞见

当字段变多，单张散点图不够用了。常用武器是**相关矩阵热力图**：把任意两列的相关系数排成矩阵，用颜色深浅表达强度，一眼扫出哪些字段高度相关（可能是冗余，也可能是值得深挖的信号）。<span class="marginnote">相关矩阵热力图是 EDA 阶段最高性价比的一张图：一个数据集的「关系地图」尽收眼底。高度相关的两列（$|r|>0.9$）在建模时可能造成多重共线性，是特征工程要去重或合并的对象。</span>

多变量 EDA 还有一个强大技巧：**分组透视**。按业务上有意义的类别分组，再比较各组的分布与统计量。例如按「是否流失」分组，比较两组在各特征上的分布差异——这往往直接指向建模时最有区分力的特征。

**重点：EDA 的输出不是一张图，而是一份「发现清单」。** 专业的 EDA 文档会记录：哪些变量分布异常、哪些字段高度相关、哪个异常值需要回去核实、哪条关系值得建模验证。这份清单是建模阶段的作战地图。

## 4 EDA 的纪律：假设不设防，判断不轻率

图基给 EDA 定的纪律值得时刻提醒自己：

1. **先探索，后证实**：EDA 阶段允许大胆看、快速试；发现线索后，再交给正式的统计推断（第8篇《描述统计与推断统计》）去证实。
2. **图形优先于数字**：数字告诉你「有多强」，图形告诉你「像什么」。图基的名言——一张图胜过千个 p 值。<span class="marginnote">图形优先还有一个务实的理由：人能一眼识别形状、集群、离群点，而靠数字枚举要遍历成千上万个组合。EDA 本质上是把「机器算得动、人看得懂」两件事接起来。</span>
3. **警惕过度解读**：看过的图越多，越容易在噪声里「发现」模式。对 EDA 阶段发现的每个关系，都带着「这可能是巧合」的怀疑进入证实阶段。

## 5 一个完整的 EDA 示例：用户付费数据

用一个很小的例子把 EDA 流程串起来。假设拿到一张「用户付费表」，字段有 `user_id`、`signup_month`、`total_spend`、`active_days`、`churned`（是否流失）。

**第一步，先看形状与类型**：

```python
import pandas as pd
print(df.shape)                 # (5000, 5)
print(df.dtypes)                # 各列类型
print(df.isnull().sum())        # 每列缺失数
```

发现 `signup_month` 有 3 条缺失，`total_spend` 有 1 条——缺失率极低，可以删行或填充。

**第二步，单变量分布**：

```python
df["total_spend"].describe()    # 均值、分位数
df["total_spend"].hist(bins=30) # 直方图
```

`total_spend` 右偏严重（均值远大于中位数），提示后续建模要做对数变换（第16篇）。

**第三步，双变量关系**：

```python
df.plot.scatter("active_days", "total_spend", alpha=0.3)
df.groupby("churned")["total_spend"].mean()
```

散点图显示正相关，但有个「active_days 很高、total_spend 却接近 0」的离群点——可能是「只看不买」的爬虫或测试账号，回源头核实后决定保留还是剔除。

**第四步，多变量与分组透视**：

```python
df.corr()["total_spend"].sort_values()
df.pivot_table(index="signup_month", columns="churned", values="total_spend")
```

发现 `active_days` 与 `total_spend` 相关最强（r ≈ 0.7），早期注册的用户流失率更低——这些线索直接指引建模时的特征权重与分组分析。

**辨析｜易错点：** EDA 示例里最常犯的错是「跳过可视化直接看相关系数」——相关矩阵告诉你「有多强」，散点图告诉你「长什么样」。上面那个离群点，相关系数只会让它稍微变小，只有散点图能让你**看见**它。EDA 的「探索」二字，靠的就是「先图后数」。

**重点：EDA 的产出要「写成发现清单」。** 这个例子的清单是：① `total_spend` 右偏需变换；② 存在一个可疑离群点待核实；③ `active_days` 是最强相关特征；④ 早期用户流失率更低值得深挖。带着这四条进入建模，你就不再是「盲目跑模型」，而是「验证已知的猜想」。

## 6 小结

- EDA 是建模前的**摸底侦察**：用统计量 + 图形快速认识数据的分布、关系与异常。
- **单变量**分析回答「每一列长什么样」：类型、分布、值域、缺值。
- **双变量**分析回答「两列什么关系」：数值×数值看散点图与相关系数，类别×数值看分组箱线图。
- **多变量**分析用相关矩阵热力图与分组透视，给出整张「关系地图」。
- 三大纪律：**先探索后证实、图形优先、警惕过度解读**。

在下一节，我们把 EDA 里反复用到的「看图」升级为一项正式技能——图怎么画才能准确又不骗人，这就是**数据可视化原理**。
