## 为什么从可视化原理开始

上一篇 EDA 里，我们不停「看图」。但「看图」和「会画图」是两码事：**同一批数据，画法不同，读者会得出完全不同的结论。**<span class="marginnote">可视化不是装饰，而是「编码-解码」的过程：作图者把数值编码成图形元素（位置、长度、颜色、面积），读者再把图形解码回数值印象。理解这套编码规则，才知道为什么某些画法会骗人，也才能画出不骗人的图。这与第三级《计算机图形学》的渲染管线视角互补。</span>这一篇讲原理，下一篇讲实践工具。

## 1 视觉编码：人眼如何读图

可视化理论的根基是**视觉编码（visual encoding）**：用图形的视觉属性来表达数据属性。人类视觉对不同的编码通道，感知精度差异极大。按从精确到模糊的顺序，常用的编码通道大致是：

1. **位置（position）**：点放哪里——最精确的通道，人眼对位置的分辨率极高。
2. **长度（length）**：条形图高度——非常精确，对比长度很容易。
3. **角度与斜率**：饼图扇区、线图斜率——中等精确。
4. **面积**：气泡大小——**不精确**，人眼对面积的感知远差于对长度。
5. **颜色明度** 与 **颜色色相**：区分组别用色相、表达强弱用明度——只适合表达分类或强度，不适合精确读数。

**重点：编码通道的选择有优先级，别用「面积」表达本应用「长度」表达的量。** 条形图（长度）与饼图（面积/角度）之争就是典型：人眼对比两个条形的高度误差很小，对比两块扇区面积误差很大。<span class="marginnote">这是为什么统计学家普遍建议「能用条形图就别用饼图」。饼图只有在「占比差异很大、只需定性」时才合适。凡是需要精确对比的场合，长度编码总是更可靠。</span>

## 2 坐标与几何：诚实的地图才能导航

除了编码通道，图表的**几何骨架**（坐标轴、标度、缩放）同样决定信息是否失真。三类最常见的「几何失真」：

**截断坐标轴**：把条形图的纵轴从 20 而不是 0 开始，会让 22 与 24 的差距看起来翻了好几倍。**条形图必须从 0 开始**，否则长度比例失真。<span class="marginnote">例外是折线图与散点图：它们的纵轴截断是为了放大细节，且读者不会按「高度比例」解读，所以截断可接受——但必须明确标注轴断口。</span>

**线性坐标与对数坐标**：跨越多个数量级的数据（如收入从几千到几亿），线性坐标会把大多数点压扁，对数坐标则能同时展示小值与大值。**对数坐标下相等的高度差代表相等的倍数差**，而非相等的绝对差。

**比例陷阱**：在统计图里，把「增长率」与「增长量」混在一张图上，或在柱状图上叠加趋势线但单位不同，都会误导。任何一张图，**坐标轴单位与含义必须标注清楚**。

## 3 常见图表类型与适用场景

图表选择有章可循。把常见类型按「你想表达什么」归类：

| 表达意图 | 推荐图表 | 关键注意 |
| --- | --- | --- |
| 数值分布 | 直方图、箱线图 | 直方图 bin 宽度影响形状 |
| 数值比较 | 条形图 | 纵轴从 0 开始 |
| 时间趋势 | 折线图 | x 轴用时间，注意缺失点 |
| 两变量关系 | 散点图 | 加透明度避免重叠遮蔽 |
| 占比构成 | 堆叠条形图（优于饼图） | 类别 ≤ 6 类，色彩易区分 |
| 高维概览 | 热力图（相关矩阵） | 用统一颜色映射 |
| 地理分布 | 地图/气泡地图 | 注意投影失真 |

**辨析｜易错点：** 新手最常犯的图表错误有三类。其一，**用折线图连接无序类别**——折线隐含「前后连续」语义，类别之间没有顺序就不该连线。其二，**过多颜色**——一张图超过 8 种色相，读者就无法区分，改用分组或明度。其三，**图例与数据分离**——图例放在远处，读者要在图例与图形之间来回跳，视线成本极高，应把标注直接放在图形附近。

## 4 可视化中的诚实原则

可视化不仅是技术，也是**责任**。数据科学家画出的图，会被拿去支撑决策。三条诚实原则必须内化：

1. **不歪曲尺度**：坐标轴起点、刻度、单位都要诚实，不靠「裁剪视图」放大或掩盖差异。
2. **如实标注不确定性**：样本估计值应画置信区间或误差棒，平均值不画区间就暗示「数据完全确定」。
3. **交代上下文**：给出基数与背景。只说「事故率上升 100%」而不说「从 1 起上升到 2 起」，是典型的数字误导。<span class="marginnote">「从 1 到 2」的 100% 增长与「从 1000 到 2000」的 100% 增长，对人类决策的意义完全不同。可视化同样如此：无基线的比例图会放大恐慌或兴奋。交代上下文是可视化伦理的核心。</span>

**重点：图表的第一个读者是作图者自己。** 如果一个图你自己都读不出明确结论，它对别人就更是噪音。画图不是为了「好看」，而是为了「看清」——这个判断标准，能帮你过滤掉绝大多数花哨而无用的图表设计。

## 5 一张图的解剖：从数据到视图中转站

把「原理」落到「一张图怎么做出来」，这里解剖一个「各区域季度营收对比」的条形图，展示每一步背后的原理。

**第一步，确定编码通道**。要精确对比各区域营收 → 选择「长度」通道（条形图），而不是面积（气泡图）或角度（饼图）。这一步的依据正是第1节的感知精度排序。

**第二步，确定坐标与标度**。条形图纵轴从 0 开始——否则 900 万与 1000 万的差距会被视觉放大（第2节截断轴陷阱）。

**第三步，选择颜色**。区域是**无序类别**，用色相区分（青色系一组、深浅区分），不用连续色带——连续色带暗示「有序、可排序」，会误导读者以为区域之间有等级。

**第四步，标注上下文**。图题写「各区域 2026 年第二季度营收（单位：万元）」，标注数据来源与样本说明。让读者一看便知「这是什么、量纲是什么、数据从哪来」。

**辨析｜易错点：** 这张图最容易出的错，是把「数值标签」直接标在柱子上。柱子高度本身已经是长度编码，再标一遍数字并非不对，但**如果数值标签成了主角，说明长度编码没选好**——读者需要数字才能读出差异，就意味着图形本身没把差异讲清。好的图形应当「不读数字也能读出结论」。

**重点：作图前先回答「读者要被说服什么」，再选图。** 原理的最终用途不是「画得漂亮」，而是「让结论被准确看见」。把「想传达的结论」写在纸上，再逆推编码与图形选择——这是原理进入肌肉记忆的练习法。

### 经典误导图三例：看懂别人怎么骗你

把「不诚实」的图表类型列成清单，你既能识破别人的误导，也能避免自己犯错：

**误导一：截断纵轴**。把条形图纵轴从「接近最大值处」而不是 0 开始，5% 的差异被画成 10 倍差距。新闻里「A 党支持率 52%，B 党 48%」配上从 45 开始的纵轴，视觉冲击力惊人——**破解法：看纵轴起点是否标注清楚，条形图必须从 0 开始**。

**误导二：面积骗局**。用气泡大小、饼图扇区表达「本应看长度」的量。人眼对比面积的误差远大于长度——两个看起来「差一倍」的圆，实际数值可能只差 30%。**破解法：凡是要精确对比的量，改用条形图；看 3D 饼图时要特别警惕——立体透视会让近处扇区显得更大**。

**误导三：双轴诱导**。左轴放 A 序列、右轴放 B 序列，两条线交叉出「戏剧性对比」——但两轴刻度比例是人为选的，调整刻度就能制造任意「趋势反超」的假象。**破解法：双轴图必须说明两轴单位，警惕「单位不可比却放一起」的对比**。

**重点：识图能力与作图能力同样重要。** 数据科学家的责任不只是「画对图」，还包括「不被图骗」——你在汇报里引用的每一张外部图表，都要经得起「坐标、单位、基数、面积 vs 长度」四问。学会读图，是学会作图的一半。

### 配色可访问性：别让色觉障碍者看不见你的图

约 8% 的男性和 0.5% 的女性有色觉障碍（红绿色弱最常见）。一张「红=涨、绿=跌」的图，对红绿色弱读者几乎是废纸——**配色不只是美学，是可访问性（accessibility）**。

三条配色纪律：

1. **不要只用颜色区分**：同一信息同时用「颜色 + 形状/图案/标注」表达。比如在「红/绿」之外，叠加「▲/▼」或直接标「涨/跌」文字——色觉障碍读者靠形状也能读图。
2. **用色盲安全的调色板**：seaborn 的 `colorblind`、Tableau 10、`viridis` 等调色板在红绿色弱下仍可区分。避免「红-绿」这对最危险的组合，改用「蓝-橙」。
3. **关键信息不靠「深浅」单一维度**：颜色明度叠加在另一个编码（长度、位置）之上，而不是单独承担「区分」职责。

**辨析｜易错点：** 最容易被忽视的是「**颜色作为唯一区分手段**」——饼图扇区只有颜色不同、折线图多条线只有颜色不同。这类图对约 8% 的读者失效。**检验法：把图转成灰度再看一遍**——如果转灰度后信息就分不清，说明你过度依赖颜色了。

**重点：可访问性不是「额外要求」，而是「好图的基本功」。** 一张「大多数人能看、少数人看不清」的图，远不如一张「所有人都能读」的图。把配色可访问性写进习惯，你的图会覆盖更广的读者——这也是数据科学「让数据被看见」的题中之义。

### 一张图的最后一步：读它

原理讲完，最后补一条最容易被忽视的实践：**图画完之后，退一步认真读它一遍**——假装你是第一次看到这张图的读者，问三个问题：我能在一秒内说出这张图在讲什么吗？图的结论和我预想的一致吗？有没有任何误导我的元素（截断轴、面积陷阱、双轴）？

读不出结论，图就没完成任务；读出错误结论，图就在误导人。**把「读图」放进「画图」的流程**，是可视化原理内化成习惯的最后一环。

## 6 小结

- 可视化本质是**视觉编码**：用图形属性编码数据属性，编码通道按感知精度排序，位置与长度最优。
- 图表几何要**诚实**：条形图纵轴从 0 开始，对数坐标用于跨数量级数据，坐标轴含义必须标注。
- 图表类型按**表达意图**选择：分布、比较、趋势、关系、占比各有其适配图形。
- 三大常见错误：**无序类别用折线、颜色过多、图例与数据分离**。
- 三条诚实原则：**不歪曲尺度、标注不确定性、交代上下文**。
