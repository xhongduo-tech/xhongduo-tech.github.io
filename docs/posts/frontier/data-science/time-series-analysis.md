## 为什么从时间序列开始

前面分析的样本都是「横截面」的：同一时刻观测的多个个体。但真实世界大量数据是**时间序列（time series）**——按时间顺序记录的同一对象的一系列观测：每日股价、每分钟流量、每小时气温。<span class="marginnote">时间序列与第二级《随机过程》直接接壤：时间序列观测 $\{X_t\}$ 就是随机过程的一条样本轨道。但数据科学视角更偏预测与分解：不追求严格的理论，而追求「能不能用它预测明天」。这也解释了为什么时间序列常独立于普通机器学习单独成课。</span>时间序列的特殊性在于：**观测之间不独立**，昨天的股价影响今天——这让普通回归「样本独立」的假设全线失效。

## 1 时间序列的三大成分

几乎所有时间序列都可以分解为三类成分的叠加（加法模型）：

$$
X_t = T_t + S_t + R_t
$$

其中 $T_t$ 是**趋势（trend）**，$S_t$ 是**季节性（seasonality）**，$R_t$ 是**残差（剩余波动）**。

- **趋势**：长期的、缓慢的方向性变化，如某城市房价十年缓慢爬升。
- **季节性**：固定周期（日、周、年）的重复波动，如冰淇淋销量每年夏季见顶。
- **残差**：去掉趋势与季节后剩下的随机波动，应近似「白噪声」——无规律、不可预测。

**重点：分解不是花架子，它是预测的前置步骤。** 预测 $X_{t+1}$ 时，先拟合趋势与季节，再对残差建模——把「有规律的部分」与「随机部分」分开处理，预测才可能准。用 `statsmodels` 的 `seasonal_decompose` 可以一键完成分解。<span class="marginnote">分解是加法还是乘法？乘法模型 $X_t = T_t \times S_t \times R_t$ 适合「季节波动随趋势放大」的数据（如收入翻倍后季节性差异也翻倍）。判断口诀：若波动幅度随水平变化，用乘法；若恒定，用加法。实际中常取对数把乘法变加法。</span>

## 2 平稳性与差分

时间序列建模的核心概念是**平稳性（stationarity）**：一个序列是平稳的，大致要求它的均值与方差不随时间变化、自相关结构稳定。<span class="marginnote">直观理解平稳性：取任意两段不重叠的时间窗，它们的统计特征（均值、方差、相关结构）看起来一样。平稳性如此重要，是因为大多数时序模型（如 ARIMA）的数学性质都建立在「规律不随时间漂移」的假设上——不平稳的序列必须先转平稳再建模。</span>

现实中多数序列不平稳（有趋势）。最常用的转化手段是**差分（differencing）**：用相邻观测的差替代原始值：

$$
\nabla X_t = X_t - X_{t-1}
$$

一阶差分抹掉线性趋势；二阶差分抹掉抛物线趋势。差分后的序列若平稳，就可以进入 **ARIMA** 模型（自回归积分滑动平均）——「I」正是积分，意思是「差分多少次，预测完再加回去」。

**辨析｜易错点：** 一个经典误区是「对非平稳序列直接做回归」。非平稳序列之间可能因为**共同的时间趋势**而出现**伪回归（spurious regression）**：$R^2$ 高达 0.9，但两个序列毫无因果联系——比如「某国巧克力消费量」与「某市新生儿数」都随年份增长，回归出来高度显著，纯属时间趋势造成的假象。**处理趋势后再分析，是时序建模的纪律。**

## 3 公式解析：AR(1) 与自相关

最简单的时序模型是**一阶自回归 AR(1)**：

$$
X_t = c + \phi X_{t-1} + \varepsilon_t
$$

其中 $c$ 是常数，$\phi$ 是自回归系数，$\varepsilon_t$ 是白噪声（均值 0、方差 $\sigma^2$、与过去无关）。

拆解三步：

- **第一步，模型结构**：今天的值由昨天的值乘以 $\phi$ 再加噪声决定。$|\phi| < 1$ 时序列平稳；$|\phi| \geq 1$ 时序列爆炸或随机游走。
- **第二步，自相关**：$X_t$ 与 $X_{t-k}$ 的相关系数（自相关函数 ACF）在 AR(1) 下为 $\rho_k = \phi^k$——以 $\phi$ 的幂指数衰减。**ACF 是识别模型阶数的侦察工具**：拖尾衰减提示 AR，在某个滞后处截断提示 MA。<span class="marginnote">识别 ARIMA 阶数的标准流程是看两个图：自相关函数（ACF）与偏自相关函数（PACF）。PACF 在滞后 $p$ 处截断提示 AR($p$)，ACF 在滞后 $q$ 处截断提示 MA($q$)。经验法则之外，现代实践更常用信息准则（AIC/BIC）自动定阶。</span>
- **第三步，预测**：$\hat{X}_{t+1} = c + \phi X_t$。注意预测的是「条件期望」，不确定性随预测步数增大而增大——长期预测会收敛到序列的无条件均值。

## 4 现代时间序列：从经典到深度学习

经典 ARIMA 处理的是单变量、线性、平稳化的序列。现实需求远超于此，三个方向把它推向现代：

- **多变量与外部变量**：**VAR**（向量自回归）处理多条序列的相互影响；带外生变量的 **ARIMAX** 把「促销活动、节假日」等事件纳入模型。
- **波动率建模**：金融收益率序列方差时变，**GARCH** 族模型专门刻画「波动聚集」——大波动后常跟大波动。
- **深度时序**：LSTM、Transformer 类模型（如 Informer、PatchTST）端到端学习长程依赖，适合数据量大、非线性强的场景。<span class="marginnote">深度学习时序模型的好处是少做手工分解与定阶，坏处是需要大量数据、可解释性差。经验规则：样本几千条以下先用经典方法（分解 + ARIMA），几十万条以上再考虑深度模型。这条「由简入繁」的顺序，与第四级《机器学习》里「先基线后复杂」的工程纪律一致。</span>

**重点：时间序列预测必须先做「时间感知」的数据划分。** 训练集必须早于验证集、验证集早于测试集——随机打乱样本会让模型「偷看未来」。这个泄漏形式之隐蔽，连老手都会翻车，务必按时间顺序切分。

## 5 一个完整的小型预测流程

把前面的工具串成一个「从数据到预测」的 30 行流程：**预测某门店未来 7 天日销售额**。

**第一步，分解看结构**。用 `seasonal_decompose` 把序列拆成趋势、季节（周期为 7 天）、残差。若残差近似白噪声（均值 0、无自相关），说明分解已经把规律抓干净。

**第二步，判断平稳性并差分**。用 ADF 检验看原始序列是否平稳；若不平稳，一阶差分后重测。平稳后进入建模。

**第三步，定阶并拟合 ARIMA**。用 `auto_arima` 或 ACF/PACF 目测定阶，拟合 ARIMA 模型，输出 AIC 比较候选阶数。

```python
from statsmodels.tsa.arima.model import ARIMA
model = ARIMA(train, order=(1, 1, 1), seasonal_order=(1, 0, 1, 7))
fit = model.fit()
print(fit.summary())            # 看系数显著性、AIC
```

**第四步，回测与预测**。在留出的「最后 7 天」上回测，比较预测与真实；确认误差合理后，再滚动预测未来 7 天。

**第五步，始终按时间切分**。训练集是「前段」，测试集是「末段」，**绝不随机打乱**（第14篇红线在时序里的体现）。

**辨析｜易错点：** 这个小流程最容易翻车的不是模型，而是「**季节周期定错**」。日销售额的周期是 7 天（周内波动），不是 365 天——把 `seasonal_order` 的周期写错，模型会把「周一 vs 周二」的差异当噪声，预测自然失真。**定周期要靠领域知识**（日数据→周周期、月数据→年周期），不能拍脑袋。

**重点：时序项目的流程感比模型更值钱。** 分解 → 平稳化 → 定阶 → 回测 → 按时间切分，这套流程走顺了，换任何模型（ARIMA、Prophet、LSTM）都只是换第 3 步。**流程可靠，模型才可比较**——这正是数据科学「工程化」在时序里的意义。

### 平稳性检验的注意点

第2节说「先检验平稳、再建模」，但检验本身有几个坑：

**ADF 检验（Augmented Dickey-Fuller）** 是最常用的平稳性检验。零假设是「序列有单位根、不平稳」——p 值小（< 0.05）则拒绝「不平稳」，认为序列平稳。

三个注意点：

1. **滞后阶数的选择**：ADF 需要指定滞后阶数（自动按 AIC 选），不同阶数可能给出不同结论——**跑检验时用自动选择，并报告用的阶数**。
2. **「趋势平稳」≠「平稳」**：一个「有确定线性趋势、但去掉趋势后平稳」的序列，ADF 可能判为不平稳——这不奇怪，因为趋势本身就是非平稳的来源。**区分「确定性趋势」（可去）与「随机游走」（不可去）**，是时序建模的分水岭。
3. **检验是「拒绝/不拒绝」，不是「证明」**：p > 0.05 只能说「没有足够证据认为它平稳」，不一定是「它就平稳」——样本少时检验功效低。

**辨析｜易错点：** 一个常见操作错误是「对已经平稳的序列过度差分」。比如序列本来只是「水平平稳、但有季节性」，你差分一次转平稳，再差分一次——**过度差分会破坏信号、引入不必要的移动平均结构**。判据：差分后看「方差有没有变大、自相关有没有更复杂」——**能不差分就不差分，这是时序建模的克制原则**。

**重点：平稳性检验是「工具」，不是「仪式」。** 它的真正用途是帮你判断「该用什么模型结构」：平稳序列用 ARMA（无差分），非平稳用 ARIMA（差分阶数按需），有趋势先「去趋势」再检验。**理解「为什么差分」比「会调用检验函数」更重要**——当你看到一条序列，能判断「它有趋势还是有随机游走」，就掌握了时序建模的第一直觉。

## 6 小结

- 时间序列分解为**趋势 + 季节 + 残差**，预测前先分解。
- **平稳性**是建模前提，**差分**是把非平稳序列转平稳的标准手段。
- 非平稳序列直接回归会产生**伪回归**，趋势项是隐蔽的欺骗者。
- **AR(1)**：$X_t = c + \phi X_{t-1} + \varepsilon_t$，自相关 $\rho_k = \phi^k$ 指数衰减；ACF/PACF 用于定阶。
- 现代扩展：**VAR/ARIMAX/GARCH** 与**深度时序模型**；所有时序建模都必须**按时间顺序切分数据**，严禁随机打乱。

在下一节，我们换一种哲学立场：不再只依赖频率主义，而是把「先验 + 数据 → 后验」的贝叶斯机器开动起来——这就是**贝叶斯方法**。
