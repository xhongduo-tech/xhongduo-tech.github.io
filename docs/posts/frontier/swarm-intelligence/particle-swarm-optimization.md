## 为什么 PSO 是群体智能的「最短代码」

蚁群要维护信息素矩阵、蚂蚁要构造完整路径——ACO 是优雅而复杂的。而**粒子群优化（Particle Swarm Optimization, PSO）**把群体智能压缩到了极致：**每个「粒子」只有两个量——位置和速度**，更新规则一句话就写完，几十行代码就能跑。<span class="marginnote">Kennedy 与 Eberhart 在 1995 年 IEEE 神经网络会议上发表 PSO 时，论文正文只有寥寥数页——它的简洁到了「半天就能实现」的程度，这大概是它在工程界流传最广的原因之一。</span>

但简洁不意味着简单。PSO 的两条更新公式浓缩了群体智能的全部精华：**个体记忆（认知）+ 群体经验（社会）+ 惯性**，三者加权合成每个粒子的下一步飞行。它在神经网络权重训练、参数调优、图像配准、电力系统调度里遍地开花，是「群体智能应用最广的算法」几乎没有争议。本节把这两条公式拆到底。

## 1 从 boids 到粒子群：一次关键的思维替换

回忆第二节的 boids：鸟靠「分离、对齐、聚合」三条力维持队形，但不朝任何目标飞。Kennedy 做了一个**精神层面的大改**：

- 把每个 boid 看成解空间里的一个点——**粒子（particle）**，它的坐标 $\mathbf{x}_i$ 就是优化问题的一个候选解。
- 把「对齐邻居的平均方向」换成「飞向自己历史最优 $p_i$」——**个体记忆（cognitive）**。
- 把「飞向邻居中心」换成「飞向全局最优 $p_g$」——**社会学习（social）**。
- 去掉「分离力」（因为解空间里粒子不会物理碰撞），保留惯性让粒子继续飞。

于是，**一群鸟从「维持队形」变成了「协同搜索最优解」**：每个粒子记住自己见过的最好位置，也偷看群体见过的最好位置，在两个吸引子之间折中飞行。队形让位给了搜索，但「局部交互、全局涌现」的内核原封不动。

## 2 公式解析：速度更新与位置更新

PSO 的全部动力来自两条式子。每个粒子 $i$ 在第 $d$ 维上按如下方式更新：

$$
v_{i,d}(t+1) = w\, v_{i,d}(t) + c_1 r_1 \big(p_{i,d} - x_{i,d}(t)\big) + c_2 r_2 \big(p_{g,d} - x_{i,d}(t)\big)
$$

$$
x_{i,d}(t+1) = x_{i,d}(t) + v_{i,d}(t+1)
$$

![粒子群速度更新示意图](/images/swarm-intelligence/particle-swarm-optimization-update.svg)

- **第一步，看惯性项 $w v_{i,d}(t)$**：$w$ 是**惯性权重**，控制粒子沿原方向飞行的分量。$w$ 大 → 探索强、收敛慢；$w$ 小 → 收敛快、易早熟。Shi 与 Eberhart 在 1998 年加入这一项，让 PSO 从「没有惯性」的初版进化成今天的标准形式。<span class="marginnote">最常用的工程技巧是<strong>线性递减惯性权重</strong>：迭代初期 $w \approx 0.9$ 大幅探索，后期降到 $w \approx 0.4$ 精细收敛——把「先探索后利用」写进一个参数里。</span>
**第二步，看认知项 $c_1 r_1 (p_{i,d} - x_{i,d}(t))$**：$(p_{i,d} - x_{i,d})$ 是「个体最好位置减当前位置」的**方向向量**——飞向自己的成功。$c_1$ 是认知系数，$r_1 \in [0,1]$ 是随机数，给「飞向自己」加抖动。
- **第三步，看社会项 $c_2 r_2 (p_{g,d} - x_{i,d}(t))$**：$(p_{g,d} - x_{i,d})$ 是「群体最好位置减当前位置」——飞向群体的成功。$c_2$ 是社会系数，$r_2$ 同样提供随机性。
- **第四步，合成**：新速度 = 惯性（保持）+ 认知（飞向自己）+ 社会（飞向群体）。位置则简单地把新速度累加上去。$c_1 r_1(p_i - x) + c_2 r_2(p_g - x)$ 本质上是一个**带随机缩放的加权质心牵引**——粒子在「自己走过的路」与「大家发现的路」之间折中。
- **第五步，直觉**：整条公式没有一个梯度。粒子不知道目标函数的导数，只知道自己和同伴的「坐标好坏」——这正是 PSO 能优化**黑箱、不连续、不可微**目标的原因，也解释了为什么它在深度学习的梯度不可用场景里依然吃香。

整个 PSO 的迭代，一句话就能写完，也是它「代码最短」的由来：

```
初始化：随机撒 N 个粒子位置 x_i，随机速度 v_i，p_i = x_i，p_g = 全体最优
循环 T 代：
    for 每个粒子 i：
        评估 f(x_i)，更新 p_i（自己历史最优）与 p_g（全局最优）
        按速度公式更新 v_i，按位置公式更新 x_i
        （可选）速度钳制 v_i 到 [-Vmax, Vmax]
输出：p_g
```

注意循环体里没有任何求导、没有矩阵分解、没有复杂的初始化——**唯一「昂贵」的操作是评估目标函数 $f$**。这意味着 PSO 的算力瓶颈不在算法本身，而在「一次评估有多贵」：评估便宜（比如低维函数）时 PSO 飞快；评估昂贵（比如一次完整神经网络训练）时，省评估次数就成了第一优先级，这也引出了 §3 的邻域拓扑与早熟问题。

## 3 参数、拓扑与早熟

**辨析｜易错点：** 新手最常犯的三个 PSO 错误——其一，**把所有维度共用一个随机数 $r$**，会破坏各维的独立探索；其二，**忘了速度上限 $V_{max}$**，粒子可能一步飞出太空，解直接爆掉；其三，**把 $c_1, c_2, w$ 设成「经验值外」的激进组合**，系统剧烈震荡永不收敛。教科书级经验值：$c_1 = c_2 \approx 2.0$，$w$ 线性从 0.9 降到 0.4。

另一个关键设计是**邻域拓扑（topology）**：

- **全局版（gbest）**：每个粒子都看全体最好的 $p_g$——收敛快，但易被一匹黑马带偏，早熟风险高。
- **局部版（lbest）**：每个粒子只看自己邻域（环状邻域里的邻居）的最好——信息传播慢，但探索更强，更抗早熟。<span class="marginnote">拓扑与收敛速度的关系在文献中是一个著名的实验结论：gbest 收敛快而脆，lbest 慢而稳，环形拓扑几乎是「免费」的稳健性提升——这是群体智能里「信息流通方式决定行为」的又一例证。</span>

**早熟（premature convergence）**是 PSO 的宿敌：当所有粒子都聚到同一个局部最优附近时，认知项与社会项都变成「原地打转」，群体失去多样性。对抗手段有：**速度重启、随机重置部分粒子、拥挤距离多样性保持**——本质上都是给系统重新注入「随机波动」这个自组织要素。

**用一组具体的数观察粒子怎么动**：设一维目标 $f(x) = (x-3)^2$ 的最小值在 $x=3$，粒子当前在 $x=1$，速度 $v=0.5$，它的个体最优 $p_i=1.5$，全局最优 $p_g=2.5$。取 $w=0.7, c_1=c_2=2, r_1=0.6, r_2=0.8$，则新速度

$$v = 0.7\times0.5 + 2\times0.6\times(1.5-1) + 2\times0.8\times(2.5-1) = 0.35 + 0.6 + 2.4 = 3.35$$

粒子位置变为 $1 + 3.35 = 4.35$——它**冲过了** $x=3$！这正是 PSO 的典型行为：惯性让它过冲，认知/社会把它拉回；下一轮它会从 4.35 折返。**过冲-回拉-逼近**的振荡收敛，是 PSO 在光滑目标上的标配轨迹——如果振荡迟迟不衰减，就该怀疑参数是否过激（$c_1,c_2$ 太大或 $w$ 太大）。

## 4 PSO 与 ACO：群体算法的两种极致

把 PSO 与 ACO 放在一起对照，是理解整个群体智能算法的捷径：

| 维度 | ACO | PSO |
| --- | --- | --- |
| 解的表示 | 路径/组合（离散结构） | 连续坐标点 |
| 记忆载体 | 环境（信息素矩阵） | 个体内部（$p_i, p_g$） |
| 通信方式 | 间接（stigmergy） | 直接（观察群体最优） |
| 正反馈 | 信息素沉积 | 社会项牵引 |
| 负反馈 | 信息素蒸发 | 惯性权重衰减 |
| 典型战场 | TSP、调度、路由 | 连续优化、参数调优 |

一句话：**ACO 把记忆写在环境里，PSO 把记忆装在心里**。前者适合组合优化，后者适合连续优化——选错舞台，再好的算法也事倍功半。<span class="marginnote">这不是硬性边界：ACO 也有连续版（ACO-R），PSO 也有离散版（二进制 PSO、PSO 求解 TSP），但「主场」意识是应用群体算法的第一课。</span>

## 5 PSO 在现代机器学习中的位置

PSO 与深度学习的纠葛很深，值得单独说一段：

**黑箱目标优化**：训练策略模型时，如果目标不可导（如延迟、吞吐、真人对齐），PSO 直接把它当黑箱——这在强化学习与自动机器学习（AutoML）里是常用招数。
- **超参数搜索**：神经网络的学习率、批大小、正则系数，是低维连续空间，PSO 对它的搜索往往比随机网格更高效，且无需梯度。
- **与梯度结合**：PSO 可以当作「迁移前的初始化器」——先用粒子群在权重空间粗搜一个立足点，再交给梯度下降精修。这与「群体探索 + 局部精修」的混合策略（如 ACO+局部搜索）一脉相承。

**值得警惕**：当问题可微、样本充足时，梯度法通常胜过 PSO。群体算法的价值在于「梯度用不了」的场景与「计算预算里没有 GPU」的场景——它是机器学习的瑞士军刀，不是瑞士军刀的替代品。<span class="marginnote">关于深度学习的优化，请对照《深度学习》专题的「优化器」一节：Adam 与 PSO 都在做「方向 + 动量」的事，只是前者靠梯度、后者靠群体投票——殊途同归的有趣证据。</span>

最后补一个 PSO 的**工程心态**：它跑得快、代码短，是「第一个值得尝试的元启发式」。但正因为它好上手，人们容易对它期待过高——面对高维强多峰问题，裸 PSO 常常卡在局部；面对离散问题，原版 PSO 并不自然。成熟的用法是把 PSO 当作**探索引擎**：配合局部搜索（梯度下降/爬山）做精修，配合多样性保持处理多峰，配合二进制/离散变体处理组合问题。**把 PSO 当「引擎」而非「答案」**，才能发挥它真正的主场价值。

## 6 小结

- PSO 由 boids 改造而来：**去掉分离、加入目标**，把鸟群队形变成协同搜索。
- 两条核心公式：**速度 = 惯性 + 认知 + 社会**，位置 = 位置 + 速度；没有梯度，可优化黑箱。
- 参数三宝：**惯性权重 $w$（探索）、认知 $c_1$、社会 $c_2$**；$V_{max}$ 与各维独立随机数不可省。
- 拓扑决定信息流通：gbest 快而脆、lbest 慢而稳；**早熟**是 PSO 的头号敌人，靠重启与多样性对抗。
- 与 ACO 对照：环境记忆 vs 内心记忆、组合 vs 连续——**选对主场**是应用第一课。
