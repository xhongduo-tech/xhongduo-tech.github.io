# 价值表征与选择

<div class="epigraph">
<p>大脑面临的问题是经济学中的老问题：不同的选项，如何折算成同一把尺子去比较？答案似乎就藏在眶额叶皮层的放电模式里。</p>

## 为什么从价值表征开始

第2篇解决了「价值如何被学习」，这一篇解决「价值如何被读出、如何被比较」。神经经济学有一条著名的**共同货币假说（common currency hypothesis）**：大脑在比较不同选项时（比如「一个苹果」vs「一杯果汁」vs「一百块钱」），必须把它们折算进同一种神经信号——否则两把不同单位的尺子根本无法比大小。<span class="marginnote">这个假说的源头可以追溯到神经科学家关于「神经元如何统一编码不同奖赏」的争论，而它一旦成立，就等于给经济学经典的「效用函数」找到了神经实现：效用不是什么玄学，它就是大脑内部的共同货币。</span>

这一篇还会介绍神经经济学最强大的行为模型之一——**漂移扩散模型（drift diffusion model, DDM）**。它不仅拟合「选了哪个」，还拟合「用了多久做出选择」，把「决策」从「一个结果」还原成「一个时间过程」。理解 DDM，是理解后面风险决策、跨期选择里所有「反应时数据」的钥匙。

这一篇在整条学习路线上的位置也很关键：第1篇立了「机制可识别性」的原则，第2篇给了「价值如何学习」的误差信号，本篇则把「价值」与「选择」焊在一起——告诉你价值在哪里、怎么比、比多久。从下一篇起，风险、时间、社会因素将逐个登场，为这台「价值比较机器」施加越来越复杂的边界条件。

## 1 价值编码的发现：从猴子到人

价值编码的第一批硬证据来自单细胞记录。帕多阿-斯基奥帕与阿萨德 2006 年在《科学》发表实验：让猕猴在两个选项（比如 1 杯葡萄汁 vs 2 杯苹果汁）之间选择，同时记录**眶额叶皮层（OFC）**神经元的放电。结果令人震撼：部分神经元只在「眼前两个选项的相对价值」变化时改变放电频率，而且这种放电直接预测了猴子最终的选择——选左，左边对应的神经元先「点火」；选右，右边先「点火」。

这个实验还有一个精致的细节：当研究者系统变化「选项 A 的量」时，神经元放电与「A 相对 B 的价值比」几乎成单调关系，而且猴子「偶尔犯错」时——选了价值更低的选项——神经元的放电也「跟着错」：在犯错的试次里，它先为「被选中的低价值选项」点火。这说明这些神经元不是事后「报告答案」，而是在**实时执行比较**。<span class="marginnote">这类神经元被称作「选项价值神经元」（offer value neurons）。它们编码的不是某个选项的绝对奖赏量，而是「当下比较语境里」的价值——这正是共同货币假说的单细胞证据。</span>

人脑的对应证据来自 fMRI。凯布尔与格利姆彻 2007 年的经典实验让被试在「今天的钱」与「将来的钱」之间选择，发现**腹内侧前额叶皮层（vmPFC）**的 BOLD 信号随「选项的主观价值」平滑变化——不随客观金额，只随主观价值。普鲁斯曼等 2007 年的品酒实验更进一步：同样的酒，标注「贵」时 vmPFC 活动显著更高，被试也报告更好喝。**主观价值不是抽象概念，它有可测量的神经信号**，而且这个信号会被价格锚定、被标签扭曲。

**重点：** 价值编码有一个重要属性——它编码的是**当下比较语境**里的价值，而不是「绝对客观价值」。同样一杯水，在你极度口渴时 vmPFC 编码的价值比刚喝完水时高得多；同一件商品，在奢侈品店里与在打折超市里，神经价值也不同。这把第2篇「价值是被学出来的」推进了一步：价值不仅被学，还被**实时重构**。

## 2 共同货币假说：效用函数的神经实现

把这些观察收拢起来，就是**共同货币假说**：**大脑把性质迥异的选项（食物、金钱、社会认可）编码进统一的、可比较的神经价值信号。** 这个信号大致位于内侧前额叶—纹状体环路：vmPFC 负责「算价值」，纹状体负责「接奖赏」，两者合作输出一个「行动值」。

| 维度 | 经典经济学的效用 | 神经共同货币 |
| --- | --- | --- |
| 存在位置 | 抽象偏好关系 | vmPFC / 纹状体放电率 |
| 度量单位 | 序数（只比大小） | 基数（可测幅度） |
| 跨域可比性 | 假设可比 | 实证可测（跨域换算） |
| 随情境变化 | 假设稳定 | 实测会漂移（锚定、框架） |
| 对选择预测力 | 预测行为 | 预测行为 + 反应时 + 神经信号 |

共同货币假说对经济学理论的影响是结构性的：它把「效用函数存在吗」从哲学问题变成实证问题。如果大脑内部真的存在一个统一的「价值标度」，那么**效用就不是一种方便的假设，而是一种可测的神经量**。格利姆彻在《神经经济分析的基础》中把这一结论推得很远：他主张，神经经济学可以给出「可测的基数效用」，从而复活那些被序数革命赶出经济学主流的福利分析。

支持共同货币的间接证据还来自**跨域换算**实验：给被试「现在付钱 A 元」或「做 B 分钟无聊任务」两个选项，研究者可以用行为数据「兑换」出 A 元在神经上与 B 分钟的等价关系；而当这种兑换发生在 vmPFC 里时，神经信号恰好在「钱」与「时间」两个维度上落在同一条价值曲线上。**同一把尺子量不同的东西**——这正是共同货币的日常工作方式。<span class="marginnote">所谓「序数革命」，指 20 世纪上半叶经济学家认定效用只能比大小、不能量数值，于是把基数效用赶出主流。共同货币假说若成立，基数效用就以「神经量」的身份回来了——这是神经经济学最具野心的一步。</span>

## 3 公式解析：漂移扩散模型

共同货币告诉你「大脑在比什么」，漂移扩散模型告诉你「大脑怎么比」。DDM 假设决策是一个**噪声中累积证据、触及阈值即做选择**的过程：

$$
dx = v\,dt + \sigma\,dW, \qquad \text{当 } x \text{ 首次达到 } +a \text{ 或 } -a \text{ 时选择对应选项}
$$

- **$x$**：证据累积量（decision variable），初值一般为 0。
- **$v$**：漂移率（drift rate），反映「选项 A 相对选项 B 的平均优势」——价值差越大，$v$ 越大。
- **$\sigma$**：噪声幅度，反映决策的随机性；$\sigma\,dW$ 是维纳过程的随机扰动项。
- **$a$**：决策阈值（boundary），代表「证据充足到可下结论」的尺度。
- **选择**：$x$ 首次碰到上阈值 $+a$ 选 A，碰到下阈值 $-a$ 选 B。

DDM 特别适合神经经济学，还因为它的参数有直觉对应：漂移率 $v$ 可以写成「价值差」的函数，阈值 $a$ 反映「谨慎程度」，初值 $x_0$ 反映「先验偏向」——比如品牌先验、首因效应。每一个行为现象，都能在 DDM 的参数空间里找到一个「住所」，这让模型在解释「为什么选、为什么快、为什么有偏向」时格外有力。

DDM 的核心洞见在于**正确率与反应时的关系**。直觉地看：$v$ 大 → 证据累积快 → 反应快且正确率高；$\sigma$ 大 → 噪声大 → 反应慢且更容易出错；$a$ 大 → 要求更多证据 → 反应变慢但更准。由此，DDM 能同时预测三个量——**选谁、用多久、有多自信**——而经典期望效用只能预测「选谁」。<span class="marginnote">数学上，首次通过时间服从逆高斯分布，其中位反应时约为 $a/v$（无噪声极限）。这正是 DDM 与「累加—上限模型」「竞争累积模型」等一起被统称为「序贯采样模型」的原因。</span>

## 4 神经证据：大脑是累积器

DDM 不只是行为模型，它还有直接的神经对应。猕猴研究长期发现，顶内沟（LIP）的神经元在做方向判别任务时，放电频率随时间单调上升，逼近阈值后触发眼动——这就是「证据累积」在神经层面的样子。经济选择任务中，内侧前额叶与纹状体的活动同样呈现「累积后撞阈值」的模式。

值得一提的是，神经累积的证据并不只存在于「感觉判别」任务。当被试在两笔金额之间选择时，脑磁图（MEG）与颅内记录都能捕捉到类似的「上升—达峰—锁定」波形，只是累积的「证据」变成了价值差。**同一个序贯采样算法，既处理「光点在左还是右」，也处理「苹果还是果汁」**——这是共同货币在算法层面的又一次体现。

更关键的是，DDM 的神经预测是**可量化检验**的：研究者可以从神经信号的斜率估计出 $v$，从阈值高度估计出 $a$，再用这些参数去预测未见过试次的反应时分布。当「神经估计」与「行为拟合」的参数对得上时，我们说「行为模型获得了神经锚点」——这正是第1篇提出的双向锁定标准。

一个经典的对照实验是「速度—准确率权衡」：实验者口头要求被试「快点选」或「认真选」。行为上，后者反应更慢但更准；神经上，后者对应的阈值 $a$ 显著更高。研究者能用一个参数的变化同时解释行为与脑活动两边的数据——这种「一个参数，两处验证」的格局，正是神经经济学方法论上最令人信服的部分。

**辨析｜易错点：** DDM 的「噪声」不是「情绪干扰」的同义词。噪声是模型里的随机游走项，反映的是「证据进入的变异性」；情绪、注意力、疲劳都会改变 $v$ 与 $a$，但那是「参数变化」，不是「噪声本身」。把两者混同，会把 DDM 误读成「决策 = 理性 + 随机错误」。

DDM 在应用层面的影响力横跨多个领域：它被用来解释感知判别（光点在左还是右）、记忆再认（见过还是没见）、以及经济选择（A 还是 B）。在神经经济学里，它尤其擅长拟合**反应时分布**——同一个被试在同一个选择上反复出现的「快慢起伏」是噪声的直接读数，而这在经典行为经济学里被当作误差丢弃了。这也是 DDM 被称为「把噪声变成数据」的模型的原因。

## 5 从价值到选择：一条完整的决策链

把前三节的成果串起来，就得到神经经济学对「一次选择」的完整描述：

1. **编码**：眶额叶 / vmPFC 为每个选项生成「当下语境的神经价值」。
2. **累积**：价值差进入漂移扩散过程，以 $v$ 的速率在噪声中累积。
3. **阈值**：累积触及阈值 $a$ 时，「该选项胜出」被固定下来。
4. **执行**：运动系统读取胜出结果，做出反应（眼动、按键、真实行动）。

这条链的价值在于：**它把「选择」拆成了可分别操纵的环节。** 让阈值升高（先想清楚）可以压住冲动，让漂移率提高（讲清楚收益）可以加快决策，而这些在经典行为经济学里都被笼统地称为「偏好」或「冲动」——神经经济学第一次让「干预决策」有了具体靶点。这一思想会一直贯穿到第9篇的助推设计。

**辨析｜易错点：** 「共同货币」不等于「所有选项最终都折算成钱」。大脑折算的是「主观价值」，不是「客观金额」——社会认可、荣誉、风险都可能压过金钱。把共同货币误读成「金钱中枢」，是对这个假说最常见的曲解。

## 6 价值编码如何解释行为经济学的经典偏差

把「价值实时重构」与「共同货币」两个结论接在一起，就能对行为经济学里最著名的几个偏差给出机制层面的解释候选：

**锚定效应**：给出一个不相关的数字（锚），vmPFC 对后续选项的编码会向锚滑动。神经上，锚改变了「参照点」，而参照点是价值编码的零点——零点移动，整个标尺跟着移。

**框架效应**：同一选项用「收益」还是「损失」框架呈现，改变的是价值信号的正负编码，而非「信息内容」。神经上，损失框架激活的杏仁核—岛叶通路比收益框架更强，价值信号随之偏移。

**禀赋效应**：出售价格高于购买价格，部分因为「放弃」触发的负向价值信号大于「获得」的正向信号——这呼应了第2篇预测误差与第7篇损失厌恶的讨论。<span class="marginnote">注意：这些「机制解释」目前多属于「神经数据与偏差一致」的层次，尚未全部达到「唯一机制」的强度。第10篇会系统评估这类证据的可重复性。</span>

这段对接的意义在于：**神经经济学不是另起炉灶，而是给既有行为发现补上「机制坐标」。** 行为经济学告诉你「有这个偏差」，神经经济学告诉你「这个偏差住在哪个脑区、由哪个参数造成、可以被什么干预改变」。第9篇的助推，正是靠这一层信息才能设计得精准。

## 7 小结

- **共同货币假说**主张大脑把异质选项折算进统一的神经价值信号，主战场在 vmPFC 与纹状体。
- 单细胞与 fMRI 证据表明：主观价值有可测的神经信号，且会被价格、标签等情境因素扭曲。
- **漂移扩散模型**把决策建模为噪声中累积证据、触及阈值即选择的过程，同时预测选择、反应时与信心。
- DDM 的三大参数是漂移率 $v$、噪声 $\sigma$、阈值 $a$，各有清晰的神经对应。
- 共同货币 + DDM 构成「价值 → 选择」的完整链条，把决策拆成可分别干预的环节。
- 这一章让「效用」从抽象假设变成可测神经量，是强纲领路线的核心成果。
- 行为经济学的锚定、框架、禀赋效应，都能在「价值实时重构 + 共同货币」的框架下获得机制坐标。

**一句话复盘**：价值不是被「知道」的，而是被「实时算出来、在噪声中比出来的」——共同货币给了它单位，DDM 给了它过程。带着这把「价值—时间」的标尺，我们即将面对决策中最棘手的变量：不确定性。

在下一节，我们将给这套「价值比较机器」加一层复杂性：当结果不再确定、当概率本身令人不安，大脑如何决策——这就是**风险与不确定性决策**。
