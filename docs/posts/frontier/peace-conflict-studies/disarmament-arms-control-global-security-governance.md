## 为什么从裁军与军控开始

第四篇的理查森方程告诉我们：**军备会自我升级，除非有外部约束**。历史上最大的「外部约束」，不是道德劝告，而是一整套国际制度——**裁军、军控与防扩散条约**。冷战核武库峰值约 7 万枚弹头，今天约 1.2 万枚，这个下降不是人类突然变善良，而是军控条约的成果。<span class="marginnote">SIPRI（斯德哥尔摩国际和平研究所）自 1966 年起持续追踪全球军备——它的年度数据是本节所有数字的权威来源。</span>本篇讲三件事：区分「裁军/军控/防扩散」三个概念、核武器与人道主义裁军的历史、以及联合国这套全球安全治理机器的成与败。

## 1 三个概念，三种逻辑

先说清术语，避免「凡是有核弹就叫军备竞赛」的模糊：

- **裁军（disarmament）**：**减少或消除武器本身**——尤其核武器。目标是「少造、少存、甚至销毁」。
- **军控（arms control）**：**管理武器的发展、部署与使用规则**，而非消灭武器——通过限制数量、限制部署地、建立信任措施，降低冲突风险与军备竞赛的失稳。
- **防扩散（non-proliferation）**：**防止武器（尤其核武器）向更多国家扩散**——把「核俱乐部」的成员数冻住，甚至收缩。

**核心概念**：三者目标不同——裁军要「减量」，军控要「维稳」，防扩散要「封口」。实践中常交织：NPT 既是防扩散条约，也含裁军义务；START 系列是军控条约，但把弹头削减到数千枚已接近「准裁军」。看清三者逻辑，才能理解为什么有的谈判成功、有的永远谈不成。

## 2 核武器：从数字看核裁军的真实轨迹

核军控的硬数据最有说服力。冷战高峰（约 1986 年），全球核弹头存量接近 **7 万枚**；到 2020 年代初，已降到 **约 1.2 万枚**——其中美俄两国占约 90%。这条下降曲线背后的制度阶梯：

- **《不扩散核武器条约》（NPT，1968 年签署、1970 年生效）**：全球防扩散的基石。承认五国为核武国（美俄中英法），其余 180 余个缔约国承诺不寻求核武；核武国承诺「最终全面核裁军」。1995 年被无限期延长。
- **美俄双边军控**：1972 年《第一阶段限制战略武器条约》（SALT I）、《中导条约》（INF，1987，禁止陆基中程导弹）、1991 年 START I、2010 年 **《新削减战略武器条约》（New START）**——把双方部署的核弹头限制在 **约 1550 枚**、运载工具 800 件以下。<span class="marginnote">New START 的核查条款（现场检查、卫星通报）是「可验证军控」的黄金标准——没有验证，条约只是废纸。</span>
- **《禁止核武器条约》（TPNW）**：2017 年通过、2021 年生效，是首个**直接禁止核武器本身**的条约——但美俄中等所有核武国均未加入。它是「人道主义裁军」路线的宣言式成果，象征意义大于实际约束。

防扩散的「第二战场」是**伊朗核问题**：2015 年《伊核协议》（JCPOA）以「解除制裁」换取「伊朗限制浓缩铀活动、接受 IAEA 核查」，被视为多边核外交的高光时刻；2018 年美国单方退出后协议濒于瓦解。它示范了核不扩散的真实面貌——**不是一次立法，而是一场依赖大国承诺的反复拉锯**，而这正是下一节「全球安全治理」要处理的难题。

**辨析｜易错点**：不要以为「核武国没签 TPNW，核裁军就是假的」。真实的削减主要发生在 NPT + 美俄双边框架里——**军控的成就不在「宣言」，而在「可验证的存量下降」**。TPNW 的价值是设定规范，NPT/New START 的价值是落地削减，两者作用不同、不可互相替代。

## 3 核威慑与相互确保摧毁：军控的理论地基

要理解核军控为何是今天这个样子，必须先懂它要管住的**理论怪兽**——**核威慑（nuclear deterrence）**与**相互确保摧毁（Mutual Assured Destruction, MAD）**。

**核心概念**：核威慑的逻辑是「**我确保能毁掉你，所以你不敢先动手**」。当美苏双方都拥有「二次打击能力」（即使挨第一轮核打击，仍能发动足以毁灭对方的报复），就进入 MAD 状态：**任何一方先发核战争，都等于自杀**。MAD 令人恐惧，却提供了冷战的一种「稳定」——超级大国之间没有爆发直接战争。

MAD 对军控有三层推论：

- **军备竞赛仍然发生**：威慑需要「可信的报复能力」，于是双方不断升级弹头数量、导弹精度、潜艇与洲际弹道导弹——理查森方程在这里真实上演。
- **军控因此必要**：军备竞赛极易因误判（预警系统误报）、升级失控而引爆。军控条约（限制数量、限制部署、热线电话、核查通报）的作用是**降低失稳与误判风险**——它不是「反核的乌托邦」，而是「核威慑下的风险管理」。
- **核武器数量其实是「军控的成果」**：没有条约，双方会按竞速逻辑越造越多；有了条约，双方才能把资源从「军备竞赛」转向「相互核实」，于是出现 7 万 → 1.2 万的下降。

**辨析｜易错点**：不要以为「MAD 稳定」=「核武无害」。MAD 只是「相对不炸」，它把全人类绑在毁灭边缘；且它对**小国与恐怖组织无效**（他们没国土可报复）。理解 MAD，是为了理解军控为什么是「明知不完美、仍必须做」的风险管理，而非为核武器辩护。

## 4 常规武器与人道主义裁军：从地雷到军火贸易

核武之外，国际社会在「更常见、更杀平民」的武器上建立了**人道主义裁军**传统：

- **《渥太华公约》（1997，禁止杀伤人员地雷）**：地雷在战后长年杀伤平民、阻断耕作。公约得到 160 余国批准，全球地雷产量与使用量大幅下降——由戴安娜王妃参与推动的这场运动，被视为「以人道为先的裁军」典范。<span class="marginnote">值得对比：杀伤人员地雷被禁，但中俄美等国仍保留使用——条约的「半覆盖」是裁军的常态。</span>
- **《集束弹药公约》（2008 年通过、2010 年生效）**：禁止集束弹药（子母弹）这种「未爆率高、误伤平民严重」的武器。
- **《武器贸易条约》（ATT，2013 年通过、2014 年生效）**：首次对**常规武器国际转让**（坦克、战机、军舰、小武器）设定共同标准——禁止转让给「会用于种族灭绝、战争罪或危害人类罪」的买方。

**要点**：人道主义裁军的共同逻辑是**「平民保护优先于国家武器自由」**——它把军控从「大国安全」扩展到了「人的安全」。这是和平研究「人的安全」概念在制度层面的落地，也呼应了第二篇「结构暴力」的视角。

人道主义裁军的经验还有一个重要副产品：**它为「被大国排斥的议题」开辟了多边通道**。当裁军谈判会议被五常僵局锁死时，禁雷、禁集束弹药运动绕开它，通过「核心组国家 + 公民社会」的联盟快速立法。这提示军控的另一条路：**当制度天花板太高，就从天花板下绕过去**——TPNW 正是这条路的延续。

## 5 核查难题：条约如何被验证

军控里有一句行话：**「条约的效力取决于验证（verification），验证的效力取决于信任」**。任何军控条约都面临同一个难题——**怎么确认对方真的履约、没藏一手？**

核查工具箱包括：

- **现场检查**：New START 允许双方对对方核基地进行限次数现场核查，清点弹头与运载工具；
- **卫星侦察**：通过遥感影像监控导弹发射井、地下隧道与武器试验场——冷战双方靠间谍卫星相互数导弹；
- **技术监测**：地震监测站（CTBTO 的全球地震监测网）捕捉地下核试验的信号，国际原子能机构（IAEA）对民用核设施进行保障监督（safeguards）以发现秘密武器化；
- **通报与热线**：双方定期通报军备数据，建立危机热线（如美苏 1963 年热线）降低误判。

**辨析｜易错点**：核查不是万能的。历史上著名的「核查漏洞」包括：伊拉克在 1990 年代一度用隐蔽设施规避 IAEA 检查；而「核查过严」又会因侵犯主权而难以通过。**核查是「够用即可」的工程权衡，不是「绝对透明」的乌托邦**——这也是为什么军控谈判总在「可验证的诚意」与「保密的必要」之间拉锯。

## 6 全球安全治理：联合国这套机器

裁军条约之上，是更大的**全球安全治理**体系——以联合国为中枢：

- **裁军机制**：联合国大会第一委员会审议裁军议题，日内瓦**裁军谈判会议（Conference on Disarmament）**是唯一多边裁军谈判论坛——但它自 1990 年代以来已**僵局十余年**，核裁军多边谈判名存实亡。<span class="marginnote">僵局的原因很直白：五常（P5）是安理会常任理事国且都拥核，多边机制要约束的恰恰是机制的掌控者。</span>
- **安理会与维和**：安理会（五常一票否决）是唯一可授权动用武力的机构；维持和平行动（第八篇详述）是其最具体的日常功能，目前部署十余项任务、覆盖非洲与中东多国。
- **大国博弈的阴影**：乌克兰战争（2022）后，五常中俄冲突公开化，裁军谈判进一步冻结。**全球安全治理的「全球性」始终受制于大国的「主权让渡意愿」**——这是体系的结构性天花板。

**重点**：理解这套体系要同时看两面——**它的制度成果是真实的**（军备下降、维和行动、武器条约），**它的政治天花板也是真实的**（五常垄断、多边僵局）。和平研究者既不能全盘否定，也不能天真乐观。

具体到维和：目前全球十余项维和行动分布在非洲（如刚果（金）的 MONUSCO、南苏丹的 UNMISS）与中东（如黎巴嫩的 UNIFIL），高峰时兵力超十万人，年预算数十亿美元。它们的角色已从「看停火」扩展到「保护平民」——但兵源、装备与授权都依赖五常的默许，**大国的分歧直接决定维和行动能否部署与续期**。

## 7 核心对比表：裁军 / 军控 / 防扩散

| 维度 | 裁军 | 军控 | 防扩散 |
| --- | --- | --- | --- |
| 目标 | 减少/消除武器 | 管理武器与部署规则 | 阻止武器扩散 |
| 核武器对应 | 全面核裁军、TPNW | New START 限制数量 | NPT 冻结成员 |
| 常规对应 | 禁雷、禁集束弹药 | 军费与部署透明度 | 武器出口管制 |
| 可验证性 | 最难（销毁难核验） | 中等（配额核查） | 较易（能否核身份） |
| 政治阻力 | 最大 | 中等 | 中等 |
| 当代状态 | 规范推进、实体滞缓 | 美俄双边仍在运转 | 多边框架承压 |

**辨析｜易错点**：三者在现实中不是三选一，而是**三管齐下**。而且「没有条约就能放任」是错误的——许多国家（含中国）自 1990 年代以来曾实际扩大核武库，防扩散体系正因大国重新武装而承压。**军控是动态博弈，不是一次性立法**。

## M 小结

- **裁军**（减武器）、**军控**（管规则）、**防扩散**（封成员）是三个不同逻辑的概念，实践中三管齐下。
- 核弹头从冷战峰值约 7 万枚降至约 1.2 万枚，主因是 **NPT + 美俄双边军控（New START 限 1550 枚）**；TPNW 象征规范、核武国均未加入。
- **核威慑与 MAD** 解释了军控的逻辑：威慑需要可信报复能力，军控是「核威慑下的风险管理」。
- **人道主义裁军**（禁地雷、禁集束弹药、武器贸易条约）把「人的安全」置于国家武器自由之上。
- 伊朗核问题的反复拉锯证明：防扩散是依赖大国承诺的动态博弈，而非一劳永逸的立法。
- 全球安全治理以联合国为中枢，但受制于**五常垄断与多边僵局**——制度成果与政治天花板并存。
- 军控是动态博弈：可验证性决定条约效力，大国重新武装让防扩散体系承压。
- **核查工具箱**（现场检查、卫星、地震监测、IAEA 保障监督）是条约效力的生命线，核查是「够用即可」的权衡。
- 当多边制度天花板太高，「核心组国家 + 公民社会」联盟可从制度缝隙绕道立法（禁雷、TPNW）。
- 军控的终极目标是「让武器少到足够可控」——这与和平研究始终追求的「结构上不生产暴力」一脉相承。

在下一节，我们把目光投向和平研究正在争论的前沿：**前沿议题**——气候变化与冲突、网络冲突、AI 与自主武器、以及性别与和平（WPS 议程）。这一篇也是整个专题的收束篇：它把前面所有概念——暴力三角、冲突动力学、制度与规范——放到 21 世纪的新战场上检验，并为「从极限到大模型」这条主线收一个面向未来的尾。
