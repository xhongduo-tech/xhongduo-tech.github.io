## 为什么从量子比特开始

经典信息学的一切都建立在**比特（bit）**之上：一个比特取值 0 或 1，无论存于磁盘还是内存，它的状态永远是二者之一。<span class="marginnote">经典比特的两种状态构成一个「确定性二态系统」；无论你读它多少次，它都给出同样的结果——这正是布尔代数、图灵机、一切经典算法的地基。</span>但量子世界的规则不同：微观粒子在被「看」之前，并不住在某一个确定状态里，而是住在所有可能状态的**叠加**中。于是量子信息学把信息的最小单元替换为**量子比特（qubit）**，一切量子的计算、通信与密码由此展开。<span class="marginnote">这是本专题的第一课，对应 Nielsen & Chuang §2.1–2.2。你在本专题学到的每个后续概念——纠缠、量子门、算法、纠错——都在为这个「量子比特」的数学对象补充新的性质。</span>

为什么要关心它？因为叠加带来的是**状态空间的指数膨胀**：经典比特只能存一个数，而 n 个量子比特可以同时承载 $2^n$ 个系数。费曼在 1981 年敏锐地指出：既然自然本质上是量子的，那经典计算机模拟量子系统就要指数代价，而量子计算机模拟它却是「顺路」。理解量子比特与态空间，就是给这条主线铺第一块砖。

## 1 从经典比特到量子比特

经典比特只有两个状态，记为 0 与 1。量子比特也有两个「基态」，但用的记号是狄拉克符号：**右矢（ket）** $|0\rangle$ 与 $|1\rangle$。<span class="marginnote">狄拉克（Paul Dirac）在 1939 年前后引入 bra–ket 记号：$|v\rangle$ 叫右矢（ket），$\langle v|$ 叫左矢（bra）。「bra」取自 bracket（括号）的前半，是物理学家用量子语言重写线性代数的第一件武器。</span>

一个量子比特的状态是这两个基态的**归一化线性组合**：

$$
|\psi\rangle = \alpha |0\rangle + \beta |1\rangle, \qquad |\alpha|^2 + |\beta|^2 = 1
$$

其中 $\alpha, \beta$ 是复数。这是量子信息与经典信息**最本质的分野**：经典比特是「非 0 即 1」，量子比特则是「0 与 1 的某种叠加」。叠加既不是「一半是 0」，也不是「不确定是哪个」，而是信息论意义上同时处在两种基态的相干叠加。

**核心概念：叠加态（superposition）**：量子比特状态 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ 是基态 $|0\rangle$ 与 $|1\rangle$ 的线性组合，组合系数称为**概率幅（probability amplitude）**。

叠加与「经典概率混合」在数学上完全不同：经典混合里粒子**真的**处于某个确定状态、只是我们不知道；叠加态里粒子**同时**处于两种状态的相干组合。区别在测量时会暴露出来——这正是本专题后续《量子测量与不可克隆》《量子纠缠》等篇反复强调的线索。

## 2 态空间：二维复希尔伯特空间

把量子比特的状态看成一个数学对象：所有形如 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ 的态构成一个**二维复向量空间**，基矢为 $|0\rangle, |1\rangle$。<span class="marginnote">这里你已经在使用第一级《线性代数》的全部工具：基、线性组合、内积、算符。量子信息学的口号是「线性代数 + 概率 + 一点点物理」，复杂度的爬升全靠线性结构托底。</span>

这个向量空间带有内积 $\langle \varphi | \psi \rangle$，使得它可以谈正交、谈范数、谈投影。这样的空间叫**希尔伯特空间（Hilbert space）**；量子比特的态空间是二维复希尔伯特空间，记作 $\mathbb{C}^2$。

两条基本规则构成了量子力学的运算法则：

**归一化**：状态必须满足 $\langle \psi | \psi \rangle = |\alpha|^2 + |\beta|^2 = 1$。这保证了把它解释为概率时「总概率为 1」。
**叠加原理**：任何归一化的复线性组合都仍是合法状态。量子比特态空间因此是**连通的**——从任意态都可以连续地走到任意其他态，中间走过的全是合法状态。

还有一个微妙之处必须现在讲清楚：**全局相位不可观测**。态 $|\psi\rangle$ 与 $e^{i\theta}|\psi\rangle$ 在物理上完全相同，因为测量概率只取决于 $|\alpha|^2, |\beta|^2$，而公因子 $e^{i\theta}$ 会被内积的模方消掉。<span class="marginnote">「全局相位」无意义，但「相对相位」有物理意义：$\frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)$ 与 $\frac{1}{\sqrt{2}}(|0\rangle-|1\rangle)$ 是两个不同的态（相对相位差 $\pi$），干涉实验能区分它们。这是量子计算里相位门能起作用的根源。</span>

## 3 布洛赫球与测量

二维复空间看似简单，但量子比特的全部信息可以画在一个球上：**布洛赫球（Bloch sphere）**。

任何单量子比特态都可以写成

$$
|\psi\rangle = \cos\frac{\theta}{2}|0\rangle + e^{i\varphi}\sin\frac{\theta}{2}|1\rangle, \qquad 0 \le \theta \le \pi,\; 0 \le \varphi < 2\pi
$$

参数 $(\theta, \varphi)$ 恰好是单位球面上的球坐标，球面上的每个点对应一个量子比特态（全局相位已被约掉，所以一对点会合并，这正是球面而不是球体的原因）。<span class="marginnote">布洛赫球不是「态空间本身」的直观图（严格说它画的是单量子比特的约化状态），但它给了我们宝贵的几何直觉：量子门就是球面上的旋转，测量就是把点「拍」到某个轴的两极上。布洛赫球在 Nielsen & Chuang 中是贯穿全书的第一张直观图。</span>

测量规则是连接量子态与经典结果的桥：在计算基 $\{|0\rangle, |1\rangle\}$ 下测量 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$，结果为 0 的概率是 $|\alpha|^2$，结果为 1 的概率是 $|\beta|^2$；测得之后，状态**塌缩**为对应的基态。<span class="marginnote">测量概率只依赖概率幅的模方，相位信息在测量后丢失——这就是为什么量子计算必须在测量前做完所有运算，也是「不可克隆」「量子信道容量有限」等一切限制的共同根源。</span>注意这里出现了本专题第一个**辨析｜易错点：**——测量概率 $|\alpha|^2$ 与「经典随机变量取 0 的概率」看起来一样，但叠加态在测量前承载着相位信息，这不是经典概率能描述的；把叠加误当成经典混合，是初学量子信息最常见的错误。

## 4 公式解析：叠加态的测量

**测量是量子信息里唯一「从量子到经典」的不可逆步骤。** 我们拆解一条最基本的测量概率公式：

$$
p(m=0) = |\langle 0 | \psi \rangle|^2 = |\alpha|^2
$$

- **第一步，投影**：$\langle 0 | \psi \rangle$ 把态 $|\psi\rangle$ 投影到基矢 $|0\rangle$ 上。代入 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$，利用基的正交归一性 $\langle 0|0\rangle = 1,\ \langle 0|1\rangle = 0$，得到 $\alpha$。
- **第二步，取模方**：测量结果为 0 的概率等于投影系数模的平方 $|\alpha|^2$。这一步叫 Born 规则，是量子力学的公设之一，不能从更基本的原理推出——它是「量子概率」的字典。
- **第三步，归一化校验**：两个结果互斥且穷尽，$|\alpha|^2 + |\beta|^2 = 1$，所以 $p(0) + p(1) = 1$。归一化条件与概率公理在此合二为一。

再看一个稍复杂的例子，它能立刻暴露出「叠加 vs 经典混合」的差别。态 $|+\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$ 在计算基下测量，两种结果各占一半——这看起来与「随机选 0 或 1」的经典硬币无异。但若先把 $|+\rangle$ 经过一个哈达玛门再测，经典硬币仍五五开，量子叠加却会确定性给出 0，因为相位信息在干涉中显露。**测量概率相等，并不代表两个物理过程等价**——这是量子信息学的第一课。

## 5 多量子比特与张量积

真正的量子计算需要多个量子比特。n 个量子比特的态空间是每个单比特空间的**张量积（tensor product）**：

$$
\mathbb{C}^2 \otimes \mathbb{C}^2 \otimes \cdots \otimes \mathbb{C}^2 = \mathbb{C}^{2^n}
$$

基态写作 $|00\rangle, |01\rangle, |10\rangle, |11\rangle$，其中 $|01\rangle = |0\rangle \otimes |1\rangle$，一般状态是所有 $2^n$ 个基态的叠加：

$$
|\psi\rangle = \sum_{x \in \{0,1\}^n} c_x |x\rangle, \qquad \sum_{x} |c_x|^2 = 1
$$

<span class="marginnote">维度从 n 跳到 $2^n$——这是量子计算的「指数优势」的数学来源：经典计算机描述这个态需要 $2^n$ 个复数，而 n 个量子比特物理上就装在 n 个粒子里。费曼说的「模拟自然」指的正是这件事。</span>

**辨析｜易错点：**并非所有多比特态都能写成各比特态的乘积。$|00\rangle + |01\rangle = |0\rangle(|0\rangle + |1\rangle)$ 可以分解，但 $\frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$ 就不能分解成任何两个单比特态的乘积——不可分解的态就是下一节的主角**纠缠态**。<span class="marginnote">张量积空间里「乘积态」只是冰山一角，「纠缠态」占了绝大多数量级。用线性代数的语言说：两比特态空间是 4 维的，乘积态不过是其中一张低维「曲面」。</span>

## 6 经典比特与量子比特的一次对照

把本节的收获放进一张对照表，信息论的味道立刻出来：

| 维度 | 经典比特 | 量子比特 |
| --- | --- | --- |
| 状态 | 0 或 1（二选一） | $\alpha|0\rangle + \beta|1\rangle$（叠加） |
| 状态空间 | 2 个点 | 球面（无穷多个点） |
| 存储 | 一个数 | 两个复数（归一化后剩两个自由度） |
| 读取 | 读多少次都一样 | 测量塌缩，只取一次 |
| 复制 | 随便复制 | 不可克隆（第五篇） |
| n 个的状态空间 | $2^n$ 个点 | $\mathbb{C}^{2^n}$（连续） |

这张表埋着本专题全部主题的种子：测量、不可克隆、指数维态空间——每一条都将在后面的文章里展开。先记住一句总纲：**经典比特是「离散的两个点」，量子比特是「连续的一个球」；连续给了它相位与干涉，也给了它脆弱与不可复制。**

再做一个具体的手算练习，让抽象落地。设 $|\psi\rangle = \frac{1}{\sqrt{5}}|0\rangle + \frac{2}{\sqrt{5}}|1\rangle$：归一化成立，因为 $\frac15 + \frac45 = 1$；测量结果为 0 的概率是 $|\frac{1}{\sqrt{5}}|^2 = \frac15 = 20\%$，结果为 1 的概率是 80%。若把系数改成 $\frac{1}{\sqrt{5}}|0\rangle - \frac{2}{\sqrt{5}}|1\rangle$，概率**完全不变**——但相对相位翻了个符号，这就是「概率相同、相位不同」的两个态，它们在干涉实验里会给出截然不同的答案。<span class="marginnote">这个练习是理解「概率幅 vs 概率」的入门：概率幅是复数、能相加（干涉），概率是模方、只能为正相加。量子计算的引擎「干涉」正是发生在概率幅层面。</span>

## 7 小结

- 量子比特状态是**归一化的复线性组合** $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$，$|\alpha|^2+|\beta|^2=1$；概率幅是复数，携带相位。
- 单比特态空间是**二维复希尔伯特空间** $\mathbb{C}^2$；**全局相位不可观测**，**相对相位**才是物理量。
- 测量遵循 **Born 规则**：结果为 $m$ 的概率是投影系数模方 $|\langle m|\psi\rangle|^2$，测量后态**塌缩**到基态；叠加态不同于经典混合。
- n 量子比特态空间是**张量积空间** $\mathbb{C}^{2^n}$，维度指数膨胀，这是量子优势的几何根源。
- 存在**不可分解**的多比特态——它们就是量子纠缠。

在下一节，我们将进入多比特态中最奇特的一类：连爱因斯坦都称之为「幽灵般的超距作用」的**量子纠缠**，并认识本专题最重要的四个两比特态——Bell 态。
