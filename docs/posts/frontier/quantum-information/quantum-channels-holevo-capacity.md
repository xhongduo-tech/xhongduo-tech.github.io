## 为什么从信道开始

上一节我们有了量子熵的语言，现在该把它接到「传输」上：现实里量子态要经过光纤、波导、大气，噪声不可避免。**量子信道（quantum channel）** 描述量子态在传输中的演化，**容量（capacity）** 回答「这条信道最多可靠地传多少信息」。本节对应 Wilde §13 与 Preskill Part II 的核心内容。

<span class="marginnote">1973 年苏联数学家霍尔沃证明的 <strong>Holevo 界</strong>是量子信息论的第一个里程碑定理：n 个量子比特能承载的经典信息量被 $\log_2 d$ 之类线性界钉死——「叠加态里藏无穷信息」的幻想被数学地终结。本节我们把经典信道论（第二级《信息论》）的框架整体平移进量子世界，并看清多出来的那些层次。</span>

## 1 量子信道：CPTP 映射

从输入密度算子 $\rho$ 到输出 $\mathcal{N}(\rho)$ 的合法量子演化，必须满足两个条件：**保迹**（$\mathrm{Tr}\,\mathcal{N}(\rho) = 1$，概率不漏）与**完全正性**（completely positive，即使系统与环境耦合也保持正定）。这样的映射称为 **CPTP 映射（quantum channel）**。

任何量子信道都可以写成 **Kraus 表示**：

$$
\mathcal{N}(\rho) = \sum_k E_k \rho E_k^\dagger, \qquad \sum_k E_k^\dagger E_k = I
$$

Kraus 算子 $\{E_k\}$ 编码了信道的全部「动作」。<span class="marginnote">Kraus 表示是量子信道理论的通用语言，Nielsen & Chuang §8.2 有完整推导：任何信道 = 「系统 + 环境整体酉演化后对环境求迹」。噪声、退相干、甚至纠错的每个操作都能用这组算子描述。</span>

**核心概念：Kraus 表示**：量子信道 $\mathcal{N}(\rho) = \sum_k E_k \rho E_k^\dagger$，其中 $\sum_k E_k^\dagger E_k = I$。它是「环境求迹」的等价数学形式，是量子噪声的统一记法。

几个最常碰到的噪声信道：

**退极化信道（depolarizing）**：以概率 $p$ 把态随机替换为 $I/d$，$\mathcal{N}(\rho) = (1-p)\rho + p\,\frac{I}{d}$。
- **退相位信道（dephasing）**：只破坏相干项（抹去密度矩阵非对角元），不改变对角线概率——它是「经典信息能传、量子信息丢失」的最简例子。
- **振幅阻尼（amplitude damping）**：模拟能量耗散（激发态衰减到基态），是量子比特物理实现的底色。

## 2 Holevo 界：量子载体的经典信息上限

现在考虑一个自然的问题：Alice 想通过**量子态**传**经典信息**。她选一组消息 $x$，以概率 $p_x$ 制备编码态 $\rho_x$，Bob 用测量读出 $x$。<span class="marginnote">注意这里 Bob 只能做<strong>测量</strong>——测量是非酉的、有信息损失的。Alice 可以任意选择「编码」，Bob 可以任意选择「测量」，Holevo 界说的是：无论怎么选，Bob 能恢复的经典信息都有上限。</span>

定义 **Holevo 量**：

$$
\chi = S\!\Big(\sum_x p_x \rho_x\Big) - \sum_x p_x S(\rho_x)
$$

Holevo 界断言：Bob 的测量能恢复的经典信息（即可达信息 $I_{\mathrm{acc}}$）满足

$$
I_{\mathrm{acc}} \le \chi
$$

更惊人的是，对无纠缠辅助的情形，$\chi$ 不仅上界，还**可渐进达到**——它就是经典容量。

**辨析｜易错点：**初学者常以为「叠加态 = 无穷信息」或「量子比特 = 模拟连续信号」。Holevo 界否决了这一切：一个量子比特的 $\chi$ 最多是 1 比特，n 个量子比特最多经典传 n 比特（若用正交编码）。量子计算机的威力不来自「比特里塞更多信息」，而来自**酉演化的并行处理**——测量是瓶颈，运算才是引擎。<span class="marginnote">把两句话连起来读：n 量子比特含 $2^n$ 个概率幅（指数内存），但 Bob 一次只能读到其中 n 比特（Holevo 界）。中间的巨大落差就是量子算法（Shor/Grover）要靠干涉去跨越的空间——算法本质上是把「藏在相位里的答案」搬到「测量能读到的概率上」。</span>

## 3 信道容量的三个层次

把经典信道论（香农容量 C）推广到量子，同一个物理信道 $\mathcal{N}$ 有多个容量，它们是不同「任务」的最优速率：

**经典容量 $C(\mathcal{N})$**：用非纠缠编码，可靠传经典比特的最大速率 = 正则极限 $\lim_{n} \frac{1}{n}\chi(\mathcal{N}^{\otimes n})$。
- **量子容量 $Q(\mathcal{N})$**：可靠传量子态的最大速率，用上一节的 coherent information 定义。
- **纠缠辅助容量 $C_E(\mathcal{N})$**：发送方与接收方**预先共享纠缠**时能获得的最大速率，其公式出奇地简单：$C_E(\mathcal{N}) = \max_\rho \big[S(\rho) + I(A\rangle B)_{\mathcal{N}(\rho)}\big]$。<span class="marginnote">纠缠辅助容量的公式无需正则化极限——它一次就能算出来，这是信道容量理论里难得的「单字母公式」。直觉：发送方可以边传态边用共享纠缠做超密编码，两条腿同时跑。</span>

这些容量满足嵌套关系 $Q \le C \le C_E$，并且**它们一般不相等**——同一个信道在不同任务里「胃口」不同。<span class="marginnote">经典容量 > 量子容量很常见（退相位信道 C > 0 而 Q = 0）；纠缠辅助容量可以严格大于两者之和，这来自超密编码的加成。到《量子隐形传态与超密编码》我们还会回头解释这种「纠缠入股」的机制。</span>

## 4 公式解析：Holevo 量的三项拆解

Holevo 量 $\chi = S\!\left(\sum_x p_x \rho_x\right) - \sum_x p_x S(\rho_x)$ 拆开看：

**第一项 $S(\sum_x p_x \rho_x)$**：整个「混合编码集合」的熵，度量 Alice 若不被告知具体消息时的整体不确定性。注意这是把 $\rho_x$ 以概率 $p_x$ 混合后的**平均态**的熵，而不是「平均熵」。
- **第二项 $\sum_x p_x S(\rho_x)$**：各编码态熵的加权平均——「预先知道是哪个 $\rho_x$」时的平均不确定性。
- **两者之差**：知道了「用哪个编码」带来的不确定性下降，这正是「编码态集合能承载的信息量」。若编码态**互相正交**，$\chi = \log d$（达到最大）；若所有 $\rho_x$ 相同，$\chi = 0$（没传任何东西）。

再看一个具体例子：Alice 以 $p = \frac12$ 发送 $|0\rangle$、$\frac12$ 发送 $|1\rangle$。平均态是 $I/2$，所以 $S(I/2) = 1$；而 $S(|0\rangle) = S(|1\rangle) = 0$，故 $\chi = 1$ 比特。如果 Alice 发送的是 $|+\rangle, |-\rangle$（非正交），Bob 用计算基测量只能以 $3/4$ 的正确率猜对，可恢复信息 $< 1$——测量把非正交编码的信息读丢了一部分。Holevo 界正是把「正交编码达到上限、非正交编码打折」这条直觉钉成了定理。

## 5 容量地图：把经典地图量子化

把第二级信息论的经典地图摊开，量子侧每一条都有对应：

| 经典（香农） | 量子（Holevo / 相干信息） |
| --- | --- |
| 离散无记忆信道 $\{p(y|x)\}$ | CPTP 信道 $\mathcal{N}$ |
| 互信息 $I(X;Y)$ | Holevo 量 $\chi$（经典编码） |
| 信道容量 $C = \max I$ | 经典容量 $C$、量子容量 $Q$ |
| 编码定理（可达性） | Holevo–Schumacher–Westmoreland 定理 |
| 无纠缠辅助 | 纠缠辅助容量 $C_E$（超密编码加成） |

<span class="marginnote">值得记住的里程碑名字：Holevo（1973，上界）、Schumacher–Westmoreland（1997，经典容量编码定理）、Lloyd 与 Shor/Devetak（1997，量子容量编码定理）。量子信息论不是经典信息论的简单搬移，而是「经典 + 纠缠」的完整架构。</span>

**辨析｜易错点：**经典信道的容量只有**一个**；量子信道有**多个**容量（C、Q、$C_E$、私密容量等），对应不同任务。写结论时若只说「量子信道容量」，必须问清是哪种任务——这是量子信息论文献中最常见的歧义之一。

还有一个常被忽略的区分：**单次使用容量 vs 正则容量**。许多信道的容量需要多拷贝联合编码才能达到，单次编码往往达不到极限；只有「正则化」——让 n 个拷贝共享一次编码、取 n 趋于无穷的速率——才给出真正的容量。这是量子信道容量理论比经典版更硬核的原因：**经典信道通常单字母即可，量子信道常常必须正则化，而且有些容量的正则极限至今没有闭式**。

## 6 三个容量不等的活例子

「同一个信道有多个容量」这句话需要用例子钉住。**退相位信道**（第九篇的主角）是最好的试金石：它只杀相干、不杀经典概率。于是

**经典容量** $C(\mathcal{N}) = 1$：以 Z 基编码、Z 基解码，相位噪声根本不碰经典比特——信息安然通过。
- **量子容量** $Q(\mathcal{N}) = 0$：任何输入叠加的相干都被抹平，无法量子传态——纠缠一滴都过不去。
- **纠缠辅助容量** $C_E = 2$：预共享纠缠 + 超密编码（第十三篇），每个发出的 qubit 携带 2 个经典比特。

于是同一个「几乎无害」的退相位信道，在不同任务里分别给出 $0, 1, 2$ 三个数值。<span class="marginnote">这个例子把「容量是对任务的承诺，不是信道的固有数字」这句话讲透了。很多科普说「量子信道容量有限」容易误导——准确说法是：每个任务（量子传态、经典通信、纠缠辅助通信）各有各的容量，而且可能差出好几倍。</span>

**辨析｜易错点：**「经典容量 ≥ 量子容量」是一般事实（经典编码可以取量子编码的一个特例），但「纠缠辅助容量」为什么能超过它们？因为双方共享的纠缠**不是**通过信道送的——它是「提前存在的资源」。计算容量时必须问清：纠缠是不是免费的？信道本身传输的只有 qubit，这是 Holevo 界管住的部分；纠缠是额外的第二条管道。<span class="marginnote">这个辨析与第十三篇的结论呼应：超密编码之所以「一比特传两比特」，不是信道变快了，而是「纠缠 + 信道」的总资源比单独的信道更宽。容量理论最终回答的是「怎么分配资源才能最省」。</span>

## 7 小结

- 量子信道 = **CPTP 映射** = **Kraus 表示** $\mathcal{N}(\rho) = \sum_k E_k \rho E_k^\dagger$；常见噪声：退极化、退相位、振幅阻尼。
- **Holevo 界**：编码态集合的可达信息 $\le \chi = S(\sum p_x\rho_x) - \sum p_x S(\rho_x)$；n 个量子比特最多传 n 比特经典信息。
- 同一个量子信道有**多个容量**：经典容量 C、量子容量 Q、纠缠辅助容量 $C_E$；它们一般不相等。
- 量子计算机的威力不在「比特装更多信息」，而在**酉并行 + 干涉**，测量是瓶颈。
- 量子容量由 coherent information 的正则极限定义，纠缠辅助容量有单字母公式。

在下一节，我们将从「信道能传多少」转向「信道从哪来」——量子比特的**物理实现**：离子阱、超导、光子与拓扑，看看这些抽象定理落到实验室里是什么样子。
