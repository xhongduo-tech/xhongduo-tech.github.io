## 为什么从纠缠度量开始

第二篇我们把纠缠称作「量子信息的基本货币」，但一直没回答一个硬问题：**怎么给纠缠定价？** 本节对应 Nielsen & Chuang §12，把纠缠从定性概念升级为可量化资源：什么样的态「更纠缠」？纠缠在局域操作下怎么变化？怎样把劣质纠缠「蒸馏」成高质量 EPR 对？<span class="marginnote">这背后是一门年轻的数学分支——<strong>量子资源理论（resource theory）</strong>。它把纠缠看作一种稀缺资源，配上一套操作规则（LOCC）、一组资源度量（entanglement measures）和一个转换框架（蒸馏/稀释）。2000 年前后 Bennett、Vidal、Horodecki 们把它系统化，如今已扩展到「热力学资源」「相干性资源」等更广的场景。</span>

度量纠缠的动机很实际：量子隐形传态每次要消耗一个 Bell 态；纠缠越多的态能办越多的事，但「多一点纠缠」到底值多少 Bell 对？答案藏在理论里，也在实验中（比如 Bell 不等式违背量本身就是一种度量）。

## 1 纯态纠缠：熵就是答案

对**纯态** $|\psi\rangle_{AB}$，纠缠度量有一个干净而唯一的选择——**纠缠熵**：

$$
E(|\psi\rangle) = S(\rho_A) = -\mathrm{Tr}(\rho_A \log_2 \rho_A)
$$

其中 $\rho_A = \mathrm{Tr}_B |\psi\rangle\langle\psi|$ 是约化密度算子。由于整体纯，$S(\rho_A) = S(\rho_B)$，两边对称，定义无歧义。<span class="marginnote">回忆第六篇：纠缠熵就是单侧约化态的 von Neumann 熵。Bell 态 $|\Phi^+\rangle$ 的 $\rho_A = I/2$，所以 $E = 1$ ebit（纠缠比特）。「ebit」是纠缠的标准单位：一个 Bell 对的纠缠量。</span>

**核心概念：纠缠熵（entanglement entropy）**：纯态纠缠的度量，等于单侧约化态的 von Neumann 熵。它满足两条好性质：乘积态熵为 0（无纠缠），Bell 态熵为 1（一 ebit）。

为什么「部分系统的熵」能度量「整体系统的纠缠」？直觉：纠缠越强，丢掉 B 后 A 留下的不确定性越大——A 越是「残缺不全」，越说明它与 B 缠得紧。极端的 Bell 态里，$\rho_A = I/2$，A 独自完全不携带任何信息，信息全在关联里。<span class="marginnote">这条直觉呼应第二篇的「整体大于部分之和」：整体纯态总熵 0，部分熵却达最大值——负条件熵的另一种面孔。</span>

**辨析｜易错点：**纠缠熵只对**纯态**成立。对混合态，「约化态熵」不再等于「纠缠量」——一个经典混合的 $I/4$ 也有非零熵，但它毫无纠缠。混合态纠缠的度量要困难得多，见第 4 节。

## 2 LOCC：局域操作不能创造纠缠

要给「资源」定价，先要界定「合法的自由操作」——**LOCC（局域操作与经典通信）**：每方只能对自己的子系统做任意量子操作和测量，彼此只能通过经典信道交谈。

LOCC 的两条铁律构成资源理论的地基：

1. **LOCC 不能增加纠缠**（单调性）：$E(\Lambda(\rho)) \le E(\rho)$ 对任何 LOCC 映射 $\Lambda$ 与任何好度量 $E$ 成立。
2. **LOCC 不能从零造出纠缠**：乘积态经 LOCC 仍是乘积态（可分态经 LOCC 仍可分）。

这意味着纠缠像「负熵」或「免费物质」——你无法凭空创造，只能消耗、转化、提纯。<span class="marginnote">这正是资源理论的骨架：定义「自由操作」（LOCC，免费的）、定义「资源」（纠缠，稀缺的）、要求度量在自由操作下单调。经典类比：热力学里自由操作是「绝热过程」，资源是「自由能」。量子资源理论是这类「广义热力学」中最成熟的一支。</span>

**辨析｜易错点：**「LOCC 不能增加纠缠」常被误读成「不能增加任何量子关联」。LOCC 完全能制造经典关联（互相发消息即可），只是不能制造**纠缠**。纠缠 = 无法用 LOCC 创造的关联，这才是它的定义性特征。

LOCC 还顺带解释了「为什么共享纠缠这么难得」：两个素不相识的量子系统要建立纠缠，必须通过**物理相互作用**（光子交换、粒子碰撞、量子信道发送），而这些都要付出真实的物理代价；一旦建立，纠缠就成为双方可反复使用的「存款」——只要不测量、不扰动。这正是隐形传态（第十三篇）里 Bell 对被当作「预先存好的资源」来消耗的原因：**纠缠可以提前制备、事后兑现**，这是它与普通通信最不同的经济属性。

## 3 蒸馏与稀释：纠缠的提纯

两个相距遥远的 Alice 与 Bob 各有一些「劣质纠缠」（混合纠缠态），想要高质量 Bell 对。**纠缠蒸馏（entanglement distillation）**：用 LOCC 把 $m$ 个劣质态变成 $n$ 个（$n < m$）高质量 Bell 对。**纠缠稀释（entanglement dilution）**：反过来用 LOCC 把 Bell 对「稀释」成更多劣质态。<span class="marginnote">蒸馏的存在本身不是显然的：混合态纠缠可能「藏得很深」，但 Bennett 等 1996 年证明任意非可分态都能被蒸馏（对充分多的拷贝，纯化协议有效）。蒸馏协议常利用「纯化 + 纠错码」的思路，与第十篇《量子纠错码》的稳定子工具直接相通。</span>

对纯态，蒸馏与稀释在**渐近极限**下速率相同——都等于纠缠熵 $E(|\psi\rangle)$。也就是说，纯态纠缠在「无穷多拷贝」的意义上是**可逆资源**：$E$ 个 Bell 对能造出 $E$ ebit 的任何纯态，反之亦然。这让「ebit 是纠缠的通货」这句话有了精确意义。<span class="marginnote">但混合态不是这样：蒸馏率 $E_D$ 一般严格小于稀释率 $E_C$（纠缠花费），不可逆性是混合态纠缠的深刻特征——就像热力学里自由能转化有不可逆损失。Nielsen & Chuang §12.5 用「mixing 使可逆性破裂」解释了这一点。</span>

纯态蒸馏还藏着一个美丽的数学定理（Nielsen 1999）：$|\psi\rangle \to |\phi\rangle$ 的**单拷贝** LOCC 转化存在当且仅当 $|\psi\rangle$ 的 Schmidt 系数向量**被 $|\phi\rangle$ 的以某个顺序控制（majorization）**。纠缠的转化问题由此变成线性代数的排序问题——资源理论在这里与第一级线性代数深情相拥。

## 4 公式解析：从 Bell 态到 Werner 态

把纯态与混合态的纠缠度量对照算一遍。先看 **Bell 态** $|\Phi^-\rangle = \frac{|01\rangle - |10\rangle}{\sqrt{2}}$：

**第一步，求约化态**：$\rho_A = \mathrm{Tr}_B(|\Phi^-\rangle\langle\Phi^-|) = \frac{I}{2}$。
- **第二步，求熵**：$E = S(I/2) = \log_2 2 = 1$ ebit。最大纠缠 = 1 ebit。

再看混合态的典型代表 **Werner 态** $\rho_W = p|\Phi^-\rangle\langle\Phi^-| + (1-p)\frac{I}{4}$（以概率 $p$ 是 Bell 态、以概率 $1-p$ 是最大混合）：

- **第三步，判可分**：用 **PPT 判据**（部分转置判据）——$d = 2 \times 2$ 情形下，$\rho$ 可分当且仅当部分转置 $\rho^{T_B}$ 仍半正定。计算得 $\rho_W$ 纠缠当且仅当 $p > \frac13$。
- **第四步，解读阈值**：$p \le \frac13$ 时，Werner 态虽是 Bell 态与噪声的「混合」，却完全可分——**噪声把纠缠稀释没了**；$p > \frac13$ 才有可蒸馏的纠缠。这个 $\frac13$ 阈值是混合态纠缠最经典的定量案例。

注意 Werner 态揭示了纯态直觉的失灵：$p=1/2$ 的 Werner 态显然「含着」不少 Bell 成分，但可蒸馏纠缠 $E_D$ 远小于「混合概率」——混合态纠缠不是简单加权。<span class="marginnote">其它常用度量还有：纠缠构成（entanglement of formation，制备所需的最小 ebit）、concurrence（2×2 情形有闭式）、负性（negativity，由部分转置的负本征值定义，易于计算）。量子信息学里「算得了的」与「有意义」的度量常常不同，这是一个仍在活跃的研究主题。</span>

## 5 纠缠度量应该满足什么

一个「好」的纠缠度量 $E$ 应当满足一组公理，其中最核心的是：

**单调性**：LOCC 下不增加，$E(\Lambda(\rho)) \le E(\rho)$。
- **零值条件**：可分态 $E = 0$；纯态则满足 $E(\rho_A) = S(\rho_A)$。
- **凸性 / 正则性**：$E(\sum p_i \rho_i) \le \sum p_i E(\rho_i)$；对 $n$ 拷贝有合理的渐近行为。

不同的度量在这些公理下各有取舍——有的易算（负性、concurrence），有的更有物理意义（蒸馏率、纠缠构成），有的可加（纠缠熵）有的不可加（蒸馏率）。**没有单一度量适合一切场景**，这正是「纠缠是多维资源」的数学体现。<span class="marginnote">把本节连回主线：纠缠度量是传态（消耗 Bell 态）的成本核算、是 QKD（需要纠缠保证安全）的安全度量、也是纠错码（把信息藏进纠缠）的理论语言。读懂「纠缠有价」，就理解了量子信息学作为「纠缠经济」的那一面。</span>

## 6 纠缠的单配性：一夫一妻定律

资源理论里有一个令人过目不忘的性质：**纠缠单配性（monogamy of entanglement）**——两个量子比特纠缠得越深，它们各自的纠缠就越不可能再分给第三者。<span class="marginnote">「monogamy」来自拉丁文 monogamia，即一夫一妻。Bell 态 $|\Phi^+\rangle_{AB}$ 是完美的单配：A 与 B 共享了全部纠缠，A 与任何第三方 C 的纠缠熵严格为 0。Coffman–Kundu–Wootters（2000）把「两两纠缠之和 ≤ 整体纠缠」写成了不等式，从此单配性有了精确的数学形式。</span>

单配性远不只是数学趣味，它是量子密码的定海神针：在 QKD（第十二篇）里，Alice 与 Bob 的共享纠缠越接近 Bell 态，Eve 能「分走」的纠缠就越少——**窃听者想分一杯羹，必然以双方纠缠减少为代价**。这个「此消彼长」正是量子密钥分发安全性的另一根支柱（与不可克隆并列）。<span class="marginnote">对比经典关联：经典相关完全可以「多方共享」——一个共同原因可以同时影响无数观察者。只有量子纠缠被单配性锁死，这也是「纠缠 ≠ 经典相关」最物理、最直观的证据之一。从第二篇到现在，我们终于集齐了纠缠的全部身份证明：不可分解、Bell 不等式违背、负条件熵、LOCC 单调、单配性。</span>

## 7 两个易算的度量

混合态纠缠的度量很多，挑两个最常见的「可计算」代表：

**concurrence（并发度）**：对 2×2 两比特态 $\rho$ 有闭式公式 $C(\rho) = \max(0, \lambda_1 - \lambda_2 - \lambda_3 - \lambda_4)$，其中 $\lambda_i$ 是矩阵 $R = \sqrt{\sqrt{\rho}\,\tilde\rho\sqrt{\rho}}$ 本征值的降序排列（$\tilde\rho = (\sigma_y \otimes \sigma_y)\rho^*(\sigma_y \otimes \sigma_y)$）。它难看不难算，且与纠缠构成有单调关系，是两比特纠缠的「标准尺」。

**negativity（负性）**：$N(\rho) = \frac{\|\rho^{T_B}\|_1 - 1}{2}$，即部分转置后负本征值的绝对值之和的一半。它可以直接计算（任何维度都可以），且是 PPT 判据的「连续化」——Werner 态里 $p > 1/3$ 的纠缠阈值，在负性上表现为 $N$ 从 0 变为正值。<span class="marginnote">值得辨析：负性与 PPT 判据是同一条线。对 2×2 与 2×3 系统，负性为 0 ⟺ 可分（判据完备）；对更高维系统，负性为 0 只说明「PPT」，可能有更隐蔽的纠缠（束缚纠缠）逃过负性法眼。<strong>易算与完备不可兼得</strong>，是纠缠度量世界的第一现实。</span>

这些度量与热力学有着漂亮的类比：纠缠构成像「焓」（制备成本）、蒸馏率像「可做功的自由能」、负性像「一种易测的探针」——量子资源理论把这些数字安排进了一张「纠缠热力学」的地图，见本书第九篇到第十一篇的逐步展开。

在离开纠缠度量之前，把「纠缠 = 负条件熵」这层窗户纸也点破：对纯态，$E(|\psi\rangle) = S(A) = -S(A|B)$，纠缠量恰是负条件熵的绝对值。<span class="marginnote">这正是第六篇《von Neumann 熵》里那个 $-1$ 的现形：Bell 态的条件熵 $-1$，不是数学怪癖，而是「1 ebit 纠缠」的另一种写法。纠缠度量、量子熵、条件熵、coherent information 在本专题里是同一条大河的不同支流。</span>

## 8 动手练习

1. **纠缠熵计算**：对 $|\psi\rangle = \sqrt{\frac13}|00\rangle + \sqrt{\frac23}|11\rangle$，求 $\rho_A$、它的本征值，再算 $S(\rho_A)$——体会「Schmidt 系数决定纠缠量」。
2. **LOCC 单调性验证**：假设 Bob 对自己的比特做一次随机酉并丢弃结果，检查 $\rho$ 变为混合态后纠缠熵是升是降——猜一猜「平均只会减少」。
3. **Werner 态阈值**：对 $p = 0.4$ 的 Werner 态写出部分转置矩阵，验证存在负本征值（纠缠）；再对 $p = 0.3$ 验证全部非负（可分）——亲手确认 $1/3$ 阈值。

做完这三题，你就能对任意给定的两比特态说一句「它有多少纠缠、可否蒸馏」，而不只是感受纠缠。

## 9 小结

- **纯态纠缠熵** $E = S(\rho_A) = S(\rho_B)$；Bell 态 = 1 ebit，最大混合 = 0 纠缠。
- **LOCC 是自由操作**：不能增加纠缠、不能无中生有；纠缠 = LOCC 不可创造的关联。
- **蒸馏 / 稀释**：劣质态提纯成 Bell 对（蒸馏），或反向稀释；纯态渐近可逆，混合态不可逆。
- **PPT 判据**：$2\times2$ 情形下可分 ⟺ 部分转置半正定；Werner 态的纠缠阈值是 $p > 1/3$。
- 好度量的公理：**单调性、零值条件、凸性**；不同度量各有取舍，纠缠是多维资源。

在下一节，我们把纠缠资源投入到最实际的应用——**量子密钥分发（QKD）**：用量子力学的不可克隆与测量塌缩，把「不可破译」从密码学的理想变成物理定律的结论。
