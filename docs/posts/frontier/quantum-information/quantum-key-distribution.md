# 量子密钥分发 QKD

## 为什么从 QKD 开始

第四篇我们见识了 Shor 算法对 RSA 的威胁：**计算安全性**（「破解它需要不可行的时间」）会随着算法进步而崩塌。量子密钥分发（QKD）提供另一条路：把安全建立在**物理定律**之上——不可克隆定理与测量塌缩——而不是任何计算复杂性假设。本节对应 Preskill 讲义 §4，介绍最著名的两个协议：**BB84**（Bennett–Brassard 1984）与 **E91**（Ekert 1991）。<span class="marginnote">QKD 不是「量子加密整个通信」，而是「安全地分发一把随机密钥」。分发完成后，通信双方用一次性密码本（Vernam 密码）加密正文——那才是无条件安全的部分。QKD 只解决「如何安全送钥匙」，不解决「如何用钥匙」。</span>

QKD 的直觉可以一句话讲完：**任何窃听都会留下痕迹**。经典信息可以复制后送走原样，窃听无痕；量子态不可克隆，窃听必然扰动，双方一对照就能发现。这就是「物理安全」的全部秘密。

## 1 经典密码的三层困境

经典密码学里，「安全密钥」问题始终没有完美答案：

**对称密码（AES）**：双方必须先共享密钥——但密钥怎么安全地传给对方？这就是**密钥分发问题**。
- **公钥密码（RSA/ECC）**：用数学难题分发密钥，但只提供计算安全；Shor 算法把它击穿（第四篇）。
- **量子计算机落地之前**：RSA 还能撑一阵；但「长期秘密今天可能被窃取、明天再破译」的存储-现在-解密-延迟攻击，让计算安全愈发不可靠。

QKD 的价值不在「更快的密码」，而在**换了安全定义**：从「对手算力不够」换成「对手违反了量子力学」。<span class="marginnote">经典密码（RSA）的安全性依赖未证明的复杂性猜想；QKD 的安全性可由信息论定理证明（在理想器件下）。「可证明安全」四个字的分量，是量子密码区别于一切经典方案的真正资本。</span>

## 2 BB84：两个基的游戏

BB84 协议用**两组互相共轭的基**来编码密钥比特：Z 基 $\{|0\rangle, |1\rangle\}$ 与 X 基 $\{|+\rangle, |-\rangle\}$，其中 $|+\rangle = (|0\rangle+|1\rangle)/\sqrt2$，$|-\rangle = (|0\rangle-|1\rangle)/\sqrt2$。<span class="marginnote">为什么用两个基？因为「不兼容的基」是量子不可克隆的实用化：Eve 不可能同时知道一个光子处于 Z 基还是 X 基下的哪个态。BB84 的安全核心就是「基的不可兼得」。</span>

协议的步骤：

1. **制备**：Alice 为每个比特随机选基（Z 或 X）与比特值（0 或 1），据此制备光子态并发送。
2. **测量**：Bob 对每个光子随机选基测量。
3. **公开对基（sifting）**：通过经典公开信道，双方公布各自用的基——**只公布基，不公布比特**。基相同的那些位留下，成为「筛后密钥」；基不同的丢弃。Z 基与 X 基的态互相不干扰吗？相同基的位两边一致，约占一半。
4. **误码检测**：从筛后密钥里抽一部分公开比对，若误码率低于阈值则相信没有窃听，保留其余作为密钥；否则丢弃。<span class="marginnote">公开对基这一步看似泄露信息，实际安全：公布「我用了哪个基」并不泄露「我测到 0 还是 1」。经典信道完全可以被窃听，因为公开信息是双方共享的、不再保密的部分——这正是 QKD 协议设计的精妙：经典信道只用于公开校验，保密全靠量子态。</span>

用一个具体回合把 BB84 走一遍，把「基」与「比特」分开看：Alice 想传的第 3 个比特是 1，她随机选了 X 基，于是制备 $|-\rangle$；Bob 随机用 Z 基测量，得到 0 或 1 的概率各半——他拿到一个可能不对的比特，但**此刻他还不知道**。公开对基后，双方发现基不同，这个位被丢弃；如果基相同（比如都用 X 基），Bob 的测量结果就与 Alice 一致，成为候选密钥。Eve 若想偷看，她的「随机选基」会以 1/4 概率把这个位弄错——而错误是藏不住的，会在误码检测里暴露。

## 3 公式解析：Eve 窃听必留 25% 误码

QKD 的安全性有一个漂亮的定量体现：**Eve 逐光子拦截测量时，必然在筛后密钥里留下 25% 的误码率**。推导如下：

**第一步，Eve 的处境**：Eve 截获一个光子，不知道 Alice 用的是 Z 基还是 X 基，只能随机猜一个基去测量。猜中的概率是 $\frac12$。
- **第二步，猜中基时**：测量不扰动态，Bob 之后测得与 Alice 一致——Eve 没被抓到，但也没引入错误。
- **第三步，猜错基时**（概率 $\frac12$）：Eve 在错误基上测量会把态**塌缩**到错误基上。比如 Alice 发 $|0\rangle$，Eve 用 X 基测量，随机得到 $|+\rangle$ 或 $|-\rangle$；Bob 之后用正确的 Z 基测量这个被污染的态，结果有一半概率翻错。引入错误的概率是 $\frac12 \times \frac12 = \frac14 = 25\%$。
- **第四步，结论**：若 Eve 碰过每个光子，双方误码率必达 25%。协议设定阈值（如 11%），超过即判存在窃听。**关键：Eve 无法绕开，因为不可克隆定理（第五篇）堵死了「复制一份再测」的旁路。**

$\frac14$ 这个数字的推导只用了线性代数与概率——没有任何计算复杂性假设。这正是「物理安全」的全部含义。<span class="marginnote">进阶版本（如纠缠辅助的 Devetak–Winter 安全性证明）给出更精细的密钥速率公式：可提取密钥速率 $r \ge I(A:B) - I(A:E)$——Alice–Bob 的互信息减去 Alice–Eve 的互信息。这与第七篇 Holevo 界的语言一脉相承。</span>

## 4 E91：用纠缠做密码

BB84 用「单光子 + 随机基」；**E91 协议**（Ekert 1991）走另一条路——共享纠缠。Alice 与 Bob 共享若干 Bell 对 $|\Phi^-\rangle$，各自随机选基测量自己的那个光子。

若双方选了**相同的基**，测量结果**完美反相关**（$|\Phi^-\rangle$ 的特性）——可以筛出密钥。
- 若选了**不同的基**，结果可用于检测：按特定组合验证 **Bell 不等式是否被违背**。经典局域隐变量理论给出的界（$|S| \le 2$）会被量子纠缠超过（$S = 2\sqrt2$），一旦违背，就证明双方共享的确实是纠缠态、没有第三者参与。<span class="marginnote">E91 的安全检测不靠「算误码率」而靠「测 Bell 不等式」——理论上更根本：它直接验证「没有经典复制品能解释我们的关联」。E91 也是「基于纠缠的量子网络」的原型，与量子隐形传态天然对接。</span>

**辨析｜易错点：**E91 里的 Bell 不等式检测与第二篇「纠缠不能超光速通信」并不矛盾——Bell 不等式验证的是「关联不是经典模拟的」，而任何测量结果仍是随机序列，不含任何信息传输。安全的密钥来自「纠缠 + 经典对基」，不是来自超光速。

## 5 从协议到现实

QKD 早已走出黑板：光纤 QKD 已在数百公里城域网络运行（中国「京沪干线」、欧洲、美国多家厂商商用设备），卫星 QKD 由墨子号（2016）实现千公里级密钥分发。现实器件（光子损耗、探测器暗计数、单光子源不完美）会引入额外误码，于是有一整套「设备无关 QKD」「测量设备无关 QKD」的工程与理论演进。<span class="marginnote">对照第四篇的密码威胁全景：对称密码被 Grover 减半密钥、公钥密码被 Shor 击穿、而 QKD + 一次性密码本提供「不依赖计算假设」的对称密钥方案。2020 年代业界已把 QKD 与后量子密码（PQC）并列为量子时代的两个密码支柱。</span>

把 QKD 放进本专题的因果链：**不可克隆定理**（第五篇）让窃听必留痕，**测量塌缩**（第五篇）让「看一眼」必然扰动，**纠缠与 Bell 不等式**（第二篇）支撑 E91 的安全证明，**Holevo 界**（第七篇）给出密钥速率的理论限。QKD 不是孤立的协议，而是本专题前面所有概念的一次大会师。

## 6 密钥后处理与信息论安全

BB84 筛出的原始密钥远不能直接当密码用——它还有误码、还有可能被 Eve 窥到**部分**信息。真正的 QKD 流程还要两步「后处理」：

**误码估计与纠错**：公开比对部分比特算出误码率，用经典纠错码把 Alice 与 Bob 的密钥对齐（信息论里叫 reconciliation）。
- **隐私放大（privacy amplification）**：用哈希等函数把较长的密钥压缩成较短的一把，把 Eve 已知的部分信息「挤出」——理论上 Eve 对最终密钥的信息趋近于零。<span class="marginnote">隐私放大是 QKD 的临门一脚：即使 Eve 窃听到部分原始比特，经过哈希压缩后，她对最终密钥的互信息指数地衰减到 0。这一步与第二级《信息论》的「随机性抽取」、以及密码学的「随机哈希」一脉相承。</span>

经过这两步，QKD 提供的安全是**信息论意义**的：它不依赖任何计算复杂性假设，只依赖量子力学定理与通信双方的能力假设。这与 RSA 的「计算安全」是两种不同层次的安全——QKD 的安全性证明甚至能容忍设备不完全理想（虽然后续「设备无关」版本还在工程化路上）。<span class="marginnote">把整个链条收拢：单光子源（第八篇物理实现）→ BB84/E91（本篇）→ 纠错与隐私放大（第二级信息论）→ 一次性密码本（经典密码）。量子与经典在这里不是对立而是接力：量子负责「安全送钥匙」，经典负责「用钥匙」，各司其职。</span>

**辨析｜易错点：**QKD 不等于「量子加密传输」。它只分发密钥，明文仍用经典加密（且需一次性密码本才无条件安全）。新闻里「量子通信绝对安全」的说法要打折：它安全的是「密钥分发环节」，不是整条链路的每个环节（比如端点的设备、密钥存储仍是经典风险）。

现实器件的漏洞催生了两个「更硬」的版本，值得记住名字：

**测量设备无关 QKD（MDI-QKD）**：把「测量」交给一个可能被黑客控制的第三方（measurement device），双方只各自发送量子态；安全性证明不再信任测量设备，只信任发送源。这让「不信任的中间节点也能安全组网」成为可能。

**设备无关 QKD（DI-QKD）**：更进一步，用 **CHSH 不等式的违背**（见《量子纠缠与 Bell 态》的 CHSH 一节）来检测纠缠质量与窃听：只要违背量够大，就证明双方共享的确实是纠缠态，任何实现细节都不必信任。<span class="marginnote">DI-QKD 是安全性的「黄金标准」——它只依赖量子力学本身，不依赖任何器件实现。代价是苛刻的实验条件（高效率单光子探测、低噪声），目前还难以大规模部署。这条「从信任设备到信任物理」的演进路线，正是量子密码学从实用走向严谨的缩影。</span>

总结 QKD 的核心竞争力：它把「密钥安全」从「算法复杂度假设」搬到了「物理定理」。只要量子力学正确——不可克隆、测量塌缩、纠缠单配性（第十一篇）——窃听就必然被发现。这份安全不随算力进步而贬值，这是它与 RSA 最根本的分野。<span class="marginnote">把这句话记牢：RSA 的安全是「暂时的」（随算法/算力演化），QKD 的安全是「永恒的」（随物理定律而定）。这就是为什么后量子密码（PQC）与 QKD 被并列为量子时代两大防线——前者仍依赖数学假设，后者依赖物理。</span>

从信息论再看一眼 BB84，会多一层理解：它的「安全」本质上是**不可克隆定理 + Holevo 界**的联合运作——Eve 若想「复制一份慢慢研究」，不可克隆定理禁止；若想「读完再放回」，测量塌缩让她必留痕。量子密码没有发明新的物理，只是把量子力学已知的「做不到」，用协议重新组织成了「敌人进不来」。

## 7 动手练习

把 BB84 的细节亲手走一遍，胜过读十遍：

1. **对基统计**：Alice 与 Bob 各随机选基，两人选到同基的概率是 $1/2$；传 $n$ 个光子，筛后约剩 $n/2$ 个候选比特。算一算：发 1000 个光子、全被 Eve 拦截的情况下，筛后误码率的期望是多少个比特？（提示：每个被拦截位以 $1/4$ 概率出错。）
2. **状态识别**：说明为什么 Bob 用 X 基测量 $|0\rangle$ 得到的 0/1 各半——这正是不公开基就无法保证正确性的根源。
3. **攻防推演**：若 Eve 只拦截「她猜中基」的那些光子（概率 $1/2$），剩余光子不加干扰——筛后误码率会低于 25%，但她拿到的密钥位也少；设想双方如何用「误码阈值 + 隐私放大」补偿这种部分窃听。

做完这三题，你对「为什么公开基不泄露信息」「为什么误码率是安全的温度计」会有手感上的把握。<span class="marginnote">练习题的参考答案都在本节正文里：对基概率在第二节、误码率在第三节、后处理在第六节。把三节串成一条线，就是完整的 BB84 安全论证。</span>

如果只能用一句话总结 QKD 与经典密码的差别，那就是：**经典密码防的是「不知道」，量子密码防的是「知道就暴露」**。前者假设敌人算不动，后者让敌人算之前就败露。随着量子硬件进步，前者越来越危险、后者越来越现实——这正是本专题值得被认真读下去的时代理由。

再往深走，QKD 还在与「量子网络」结合：城域 QKD 网络把密钥当作「数字黄金」在节点间路由，卫星 QKD 把服务延伸到洲际。随着 MDI-QKD、DI-QKD 等「少信任设备」版本成熟，量子密码正从「点对点演示」走向「可大规模组网的基础设施」。量子时代的密码图景，已经不只是理论家的推演。

而这一切都建立在同一个地基上：**量子力学的概率与纠缠，是被验证了半个世纪以上的物理事实**。基于物理的安全，在「量子时代」反而比任何算法假设更恒久——这正是 QKD 值得我们认真理解的理由。

## 8 小结

- QKD 把安全从**计算假设**换成**物理定律**：不可克隆 + 测量塌缩，窃听必留痕。
- **BB84**：两个共轭基（Z/X）制备、测量、公开对基筛出密钥、误码检测；Eve 逐光子窃听必留 **25% 误码**。
- **E91**：共享 Bell 对 + Bell 不等式检测，用纠缠验证安全性。
- QKD 只安全分发密钥，正文用**一次性密码本**加密；与 **PQC** 并列为量子时代密码支柱。
- 已有光纤与卫星级 QKD 部署，工程挑战在单光子源、损耗与设备不完美。

在下一节，我们用前十一篇攒下的全部工具，走向量子信息学的「期末考试」——**量子隐形传态与超密编码**：看两个看似魔术、实则数学的协议，如何把纠缠变成通信的超能力。
