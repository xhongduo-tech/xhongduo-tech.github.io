# 深度学习可解释性

<div class="epigraph">

## 为什么从深度学习讲起

本专题前八篇，方法几乎都假设「模型可被当黑箱询问」。
但深度学习是 XAI 舞台的中心，原因恰恰是**它最难**：动辄几十上百层、上亿参数、高度分布式的内部表示，让「可读」在字面意义上失去了坐标。<span class="marginnote">这一篇与第九级《深度学习》主线正面交汇：那边教你「怎么把网络训出来」，这边回答「网络训出来之后，怎么理解它」。没有深度学习的基础（卷积、注意力、嵌入），本篇的判断就悬空。</span>而大模型正是深度学习的极端形态——注意力叠加成百上千层，参数以千亿计。
理解深度可解释性，就是为理解大模型时代「为什么这样输出」铺路。
这一篇讲清三件事：深度网络为什么难解释、XAI 能为它提供哪些策略（设计侧与事后侧）、以及「注意力作为解释」这场著名的争论。

## 1 为什么深度网络是“最难解释的黑箱”

深度网络难解释，不只是因为它大，而是**大 + 分布式 + 层级非线性**三者的乘积：

**分布式表示（distributed representations）**：一个概念分散在成千上万个神经元的激活里，单个神经元几乎永远不对应单一语义——「看到眼睛」不体现在某个神经元的开与关，而体现在高维向量里某片区域的模式。第7篇说示例解释可复验，可到了深度网络，「示例」自己也难以解读——对抗样本就是证据：人类概念与模型特征词典完全错位。
- **层级非线性**：每一层都做非线性变换，输出对输入的依赖呈指数级复杂化。第4篇 PDP 那条「让一个特征变、其余冻结」的实验，在高维图像输入下连「一个特征」都定义不了——像素不是语义。
- **参数规模**：即使理论允许逐层分析，实践上亿参数的审查也无人力可及。<span class="marginnote">数学上，输入输出映射可以被分层展开成链式求导——梯度是可得的；但「梯度」与「语义」之间隔着整个表示空间。这就是为什么深度解释方法几乎全是「启发式可视化 + 统计验证」而非「结构可读」。</span>

于是深度可解释性被分成两条互补的路线：**设计侧**让网络天生更可解释，**事后侧**给已训练网络补解释。前者是工程，后者是本专题第10篇的主角。

## 2 设计侧：让网络天生“白”一点

「事后补解释」永远是在追债，另一派选择**在训练时就把可解释性砌进结构**：

**注意力作为解释**：Transformer 与各类注意力机制天然产出「权重矩阵」——模型在生成第 $t$ 个词时，注意力分配了多大的权重给前面的哪些词。
这看起来像现成的解释材料：注意力越高 = 越相关。
这条直觉带来了「Attention is Explanation」时代，也带来了第4节要讨论的争论。<span class="marginnote">注意力在解释学上的诱惑在于它是「免费」的：训练一次就有，不需要额外解释器。但它是不是一个可信的解释，是 XAI 领域最激烈的论战之一。</span>

**概念瓶颈模型（Concept Bottleneck Models, CBM）**：在「输入特征 → 概念 → 目标」之间插入一层**人工定义的概念向量**，模型先预测「有没有眼睛、有没有皮毛」，再由概念决定目标分类。
解释退化成读概念层的激活——「因为它识别出了皮毛和獠牙，所以判为狼」。
代价是：概念词典是人工构造的，覆盖不全时模型性能受损，这是「可解释性税」最直白的体现。

**解耦表示学习（disentangled representation）**：用变分自编码器（VAE）等结构，强迫隐空间的每个维度尽量只编码一个生成因子（形状、颜色、角度）。
如果成功，隐向量的每个坐标都自带语义——网络的一部分就「翻译」成了人话。<span class="marginnote">注意解耦是「尽力而为」：现实数据的生成因子往往纠缠不清，解耦成功的判据本身也仍是开放问题。别把「论文里漂亮的解耦图」当成生产模型的普遍现状。</span>

**知识蒸馏（knowledge distillation）**：把大网络的知识蒸馏进一个小的、可读的模型（浅树、规则、小网络）——这是「把深度模型的判断逻辑提炼成可检查的东西」的最务实路线。
第3篇的全局替代模型，在深度场景下就叫蒸馏，两者的哲学完全相同：**用可读对象近似黑箱**。

## 3 事后侧：给已训练网络“补档案”

设计侧是理想，现实里大量网络已经训练完毕、无法重来。事后侧提供四类手段：

**归因 / 可视化（attribution & visualization）**：梯度类（saliency、SmoothGrad、Integrated Gradients）、CAM 类（Grad-CAM、Score-CAM）——在像素/超像素上标出「模型的注意力区域」。
这是用户最常遇到的一类深度解释，第10篇将整篇展开。

**激活分析（activation analysis）**：把一个测试样本塞进网络，看各层神经元如何激活；进一步做**特征可视化（feature visualization）**——用梯度上升找出「让某个神经元最兴奋的图像」，直观展示该神经元「在找什么」（条纹、眼睛、车轮）。

**探针（probing）**：在某一层隐表示之上训练一个小的线性分类器，看「这一层是否编码了某种语义」——例如「BERT 第 6 层已经编码了词性」。
探针把「隐表示里有什么信息」变成可检验的统计问题，是语言模型可解释性的主力工具之一。

**示例归因（influence / prototypes）**：第7篇的原型、对抗样本在深度网络里同样适用，且因为深度模型对微扰敏感，对抗样本在此格外刺眼——它是「网络依赖了什么线索」的最直接证据。

## 4 公式解析：注意力到底能不能当解释

「注意力是解释」这句口号值得用一个公式把它钉死，再给出它的反面：

$$
\alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k} \exp(e_{ik})}, \qquad
\text{注意力越高} \;\stackrel{\text{？}}{\Longrightarrow}\; \text{与决策越相关}
$$

- **第一步，$e_{ij}$ 是相关性打分**：在 self-attention 里，$e_{ij}$ 是 query 与 key 的点积（缩放后），衡量「第 $i$ 个位置与第 $j$ 个位置的相关强度」。$\text{softmax}$ 把它归一化成 $\alpha_{ij}$，全部位置加起来等于 1。
- **第二步，注意力作为输出的权重**：第 $i$ 个位置的输出是对所有位置按 $\alpha_{ij}$ 加权求和。权重越大，第 $j$ 个位置对第 $i$ 个位置输出贡献越大——这层因果链是真的：**输出确实主要由高注意力位置决定**。
- **第三步，翻译成解释**：于是「高注意力 = 对决策重要」看起来水到渠成：输出由权重决定，权重高就是主导者。
- **第四步，反驳**：Jain 与 Wallace（2019）的著名论文用一套巧妙的实验拆穿了这个推理——**对抗注意力（adversarial attention）**：把训练好的注意力权重换成随机值，再重新微调，结果模型性能几乎不下降。这说明**注意力权重不是决策的充分编码**：同一决策可以由很多组不同的注意力权重实现，注意力高不代表「模型离不开它」。注意力只是「与决策相关」的弱证据，不是「决策原因的忠实档案」。<span class="sidenote-number"></span><span class="sidenote">Jain &amp; Wallace, "Attention is not Explanation"（NAACL 2019），与 Wiegreffe &amp; Pinter 的回应 "Attention is not not Explanation" 构成 XAI 领域最经典的攻防之一。最终共识接近：注意力可用作「提示」，不可当作「证明」。</span>

这个公式解析的教训是通用的：**模型里任何一个可读的数值，都不自动等于一个诚实的解释**。
第10篇的 saliency、Grad-CAM 也共享同一个命运——它们都提供「模型注意什么」的弱证据，诚实的使用者必须验证（用什么标准验证，第11篇再讲）。

## 5 深度可解释性的三件套：什么时候用什么

把深度场景按「审查深度」分类，可解释性的答案层次分明：

| 审查深度 | 手段 | 回答的问题 | 篇章 |
| --- | --- | --- | --- |
| 行为级 | 示例、反事实、对抗 | 模型在哪些输入上怎么表现 | 第7、8篇 |
| 归因级 | Grad-CAM、saliency、注意力 | 模型的注意力落在这张图的哪里 | 第10篇 |
| 表示级 | 特征可视化、探针、解耦 | 网络各层在编码什么概念 | 本篇 |

**辨析｜易错点：** 三层手段不能互相替代：行为级解释「说了不算」（只描述行为），归因级解释「弱证据」（注意力相关不等于因果），表示级解释「最接近真相但也最贵」（要访问内部，且结果仍是统计推断）。**深度可解释性没有银弹，三件套叠起来用、互相交叉验证，才是工程上的诚实做法。**

## 6 大模型时代的深度可解释性

从 CNN 到大语言模型，可解释性的重心发生了一次迁移：CNN 时代的主角是「输入空间里的可视化」（第10篇的 Grad-CAM），而 LLM 时代的核心问题变成了「**这个 token 是怎么生成的、知识存在哪里、为什么要这么答**」。

**注意力仍然是入口**：生成每个词时模型在看哪些上文——它在翻译、摘要、RAG 检索里给出最便宜的「关注点」证据。**探针（probing）升级**：除了「某一层是否编码了词性」，还出现了**激活修复 / 因果追踪（causal tracing）**——用「把某层激活替换掉、看输出怎么变」的办法定位「知识到底存在哪一层、哪个 MLP 参数里」。
这类方法把第9节的「事后侧」从「看」推进到「干预」：不再是描述网络在看什么，而是**测试网络离开了哪部分就会崩溃**，从而回答「哪部分真正承载了这项能力」。<span class="marginnote">这些方法与第九级《大模型原理》《大模型对齐》专题直接接壤：对齐问题（模型为什么拒绝/迎合、为什么撒谎）在很大程度上就是「把模型的内部决策机制摸清楚」的问题——可解释性是对齐研究的底层工具箱。RLHF 之后模型行为剧变，只有理解了内部机制才能判断它的拒绝是真的「懂」还是「装」。</span>

**大模型不可解释的结论要缓一缓**。
是的，千亿参数的网络没有一个「人可读的答案」，但「不可解释」不应被当成静止的事实，而应被当成一张任务清单：**行为级**（示例、反事实）在 LLM 上依然可用且廉价；**归因级**（注意力、梯度）给出弱证据；**表示级**（探针、因果追踪）才真正深入。
本专题建立的「三层证据 + 交叉验证」纪律，在大模型时代不是失效，而是更加必要。

## 7 小结

- 深度网络难解释 = **大 + 分布式表示 + 层级非线性**三者叠加，「一个特征」在像素输入下失去定义。
- **设计侧**：注意力、概念瓶颈（CBM）、解耦表示、知识蒸馏——把可解释性砌进结构，但要付「可解释性税」。
- **事后侧**：归因/可视化、激活分析、探针、示例归因——给已训练网络补档案，各有用处。
- **注意力之争**：注意力是「与决策相关的弱证据」，不是「决策原因的忠实证明」（对抗注意力实验）。
- 深度解释分**行为级、归因级、表示级**三层，互不替代，应交叉验证。

在下一节，我们扎进归因级的最深处：**saliency、Grad-CAM 与注意力可视化**——梯度与热力图如何把「模型在看哪里」翻译成一张人眼可读的图，以及它们各自的数学与陷阱。
