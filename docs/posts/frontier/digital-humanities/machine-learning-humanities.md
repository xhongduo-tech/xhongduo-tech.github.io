## 为什么数字人文要学机器学习

前几节的工具——词频、主题建模、网络、GIS——大多属于「描述性」分析：它们把已有数据组织成可见的结构。而**机器学习（machine learning，ML）**带来一个质的跃迁：**让模型从带标签的例子里自动学习规律，然后用规律去预测或分类新的对象。** 人文研究中这样的任务到处都是：这件佚名作品的作者是谁（作者归属）、这部年代不明的碑刻属于哪个时期（断代）、这篇小说属于哪个文类（分类）。机器学习之所以放在方法篇中段，是因为它**整合了前面全部工具**——文本要变成特征、结构要建网络、结果要可视化——同时第一次向人文学者抛出「信还是不信机器」的问题。本节讲清 ML 在人文研究里的典型任务、关键流程、评估指标，以及一个必须坚守的边界：**机器学习给人文学者的是「候选与线索」，不是「判决」**。

## 1 两类任务：分类与聚类

机器学习按「有无标签」分成两大族，人文应用各有经典场景：

- **监督学习（supervised learning）**：训练数据带标签（这部作品已知作者是 A/B），模型学习「特征→标签」的映射，然后预测新样本。人文任务包括：
  - **作者归属（authorship attribution）**：用风格特征判别佚名文本的作者；
  - **断代（dating）**：从语言特征推断文本/碑刻的年代区间；
  - **文类/情感分类**：自动判定文本属于哪一文体、传达何种态度。
- **无监督学习（unsupervised learning）**：无标签，让模型自己发现结构——主题建模（LDA）就是其一，聚类（clustering）把人/文本按相似度自动分组，常用于「先看有哪些派别，再检验假设」。

监督学习的典型流程：**语料 → 特征提取 → 划分训练/测试集 → 训练模型 → 评估 → 部署到未标注数据**。人文学者最常参与也最该盯紧的，是「特征提取」与「评估」两步——它们决定了模型的视野与可信度。

## 2 特征：风格测量学给机器喂什么

机器学习不直接吃文本，吃的是**特征（features）**——一组从文本里抽出的数值。人文任务的经典特征源是**风格测量学（stylometry）**，可归为四类：

| 特征族 | 例子 | 能揭示什么 |
| --- | --- | --- |
| 词汇特征 | 平均句长、词长分布、词频 | 行文的繁简与流畅度 |
| 功能词特征 | 「之、其、以、而」的频率 | 几乎无意识的功能词是最稳定的「指纹」 |
| 句法特征 | 虚词序列、句式模式 | 语法习惯的时代与个人差异 |
| 内容无关特征 | 标点密度、篇章结构 | 规避主题差异的干扰 |

**功能词是作者归属的秘密武器**：作者很难有意识控制「之」字的出现频率，因此功能词频率的向量就像笔迹——不同作者可分、同一作者稳定。而**内容词要小心**：两篇同写战争的文本，内容词自然相近，会把「主题相近」误判成「作者相同」。选特征就是选「你允许机器从哪个角度看文本」。

## 3 评估：一个模型好不好，不能靠感觉

监督学习的核心纪律是**评估**：模型在训练数据上再准也不算数，必须在**没见过的测试集**上检验。最常用指标是**精确率、召回率与 F1**：

$$
P = \frac{TP}{TP + FP}, \quad R = \frac{TP}{TP + FN}, \quad F_1 = \frac{2PR}{P + R}
$$

其中 $TP$（真正例）是「判为甲作者且真是甲作者」的样本数，$FP$（假正例）是「判为甲但不是甲」的数，$FN$（假负例）是「是甲但没判出」的数。

- **第一步，查全/查准的权衡**：$P$ 回答「模型说这是甲，可信吗」；$R$ 回答「甲的作品，模型找全了吗」。两者天然此消彼长——模型「宁可错杀」时 P 高 R 低，「宁可放过」时反是。
- **第二步，F1 调和平均**：单看 P 或 R 都易被「偷懒策略」钻空子，$F_1$ 作为两者的调和平均，惩罚「偏科」——F1 = 0.9 意味着查全查准都不差。
- **第三步，语境化解读**：作者归属任务中，**错误样本比正确率更值得研究**——模型把某篇佚名文判给 B 而非 A，这个「误判」本身就是风格学证据，值得回到原文细读。

**过拟合（overfitting）**是人文 ML 的头号陷阱：特征太多、样本太少时，模型会「背下」训练集而非「学会」规律——测试集上立刻现形。用交叉验证 + 控制特征数量，是防线。<span class="marginnote">交叉验证把数据切分成多份、轮流做训练与测试，让每个样本都有机会当「没见过的数据」——是小样本人文语料的标配评估方式。</span>

## 4 解释性：人文研究凭什么相信黑箱

机器学习模型常被批评为**黑箱**：给一个分数，却不给理由。人文学者的立场应当是一种「受控的信任」：

- **用线性/可解释模型**：逻辑回归、朴素贝叶斯、决策树，权重可以直接读出「哪个特征起了多大作用」——「『之』字频率高，导致被归入明代文本」是可以陈述的结论。
- **对黑箱模型做事后再解释**：深度学习做特征重要性分析、注意力权重可视化，让模型「说出它看了哪里」。
- **把模型当假设生成器**：最稳妥的姿势是——模型输出一组候选（作者、年代、文类），**人回去读原文验证**。模型定位可疑样本，人做最终裁判。

<span class="marginnote">「人机分工」是数字人文 ML 的共识范式：机器处理它擅长的规模与一致性，人处理它不擅长的语境与意义。这与第四级《机器学习》的工程问题不同——这里的问题不是「如何把准确率再提 0.1%」，而是「这个分类结论意味着什么、可不可信、对谁负责」。</span>一个不能解释的模型，在人文语境里等于没有证据。

## 5 机器学习的人文边界：偏见与伪精确

机器学习一旦用于人文，就必须直面三个根本性保留：

1. **训练数据即权力**：标签是谁打的？「杰作」vs「平庸之作」的分类，早已内含文学史家的判断——模型只是把既有偏见**放大并永久化**。用模型证明「某文类是杰作」是循环论证。
2. **历史不可反事实**：模型从 1900 年报刊学到的规律，不能外推到 1800 年——历史语境不可迁移，预测的是「模式相似」而非「真实因果」。
3. **概率不等于真理**：一个 92% 置信度的归属判断，可能只是特征空间里的巧合；置信度高≠正确，尤其当测试分布与真实分布不一致时。

**一条底线**：机器学习在人文学科的价值不是「得出最终答案」，而是**把印象变成可审计的假设**——它放大人的提问能力，不替代人的判断能力。用机器的强项（规模、复现、一致性）补人的弱项，是唯一正当的使用方式。

## 6 一个作者归属实验的完整设计

用机器学习做作者归属，是数字人文 ML 最经典的入门实验。以「判断一篇无名文言文属于甲还是乙」为例：

| 环节 | 设计 | 常见错误 |
| --- | --- | --- |
| 语料 | 甲乙各自 20 篇同时期作品 | 两作者时代不同，风格差被误当身份差 |
| 特征 | 20 个高频功能词频率 | 内容词混入，主题差被误当作者差 |
| 训练/测试 | 留出 20% 作测试集 | 在训练集上评估（过拟合） |
| 评估 | F1 + 错误样本分析 | 只看正确率，不看谁被分错 |
| 解释 | 读特征权重 | 黑箱直接下结论 |

### 特征权重的阅读法

线性模型（如逻辑回归）的权重可以直读，但要按「三步」读：

1. **看方向**：哪个特征把样本推向甲？「之」字频率高 → 归甲，方向是否可解释？
2. **看幅度**：权重最大的几个特征是否稳健？换掉一个特征结论是否改变？
3. **看内容**：权重大的词是功能词还是内容词？若内容词主导，说明模型学的是「主题」而非「风格」。

**作者归属结论的发表标准**：必须报告特征清单、模型超参、测试集划分方式与错误样本——否则同行无法判断你的 F1 是「风格学证据」还是「过拟合表演」。

### 人文学者与机器学习的关系定位

三种常见的错位认知需要纠正：

- **「我只要会调库就行」**：理解损失函数与评估口径，才能判断模型在替你说什么。
- **「模型结果就是答案」**：模型给出的是候选假设，不是历史/文学结论。
- **「可解释的模型一定更差」**：在人文任务里，可解释性优先于一点点准确率提升。

**正确姿势**：人文学者当「提问者与裁判」，模型当「规模化的助研」——让机器跑完你不可能手做的部分，你负责它替你说的每一句话。

## 7 小结

- 机器学习分**监督（分类/预测）**与**无监督（聚类/发现）**；人文经典任务是作者归属、断代、文类判定。
- 特征工程是人文 ML 的胜负手；**功能词特征是稳定的风格指纹**，内容词需防主题干扰。
- 评估用 $P$、$R$、$F_1$：精确率问「判得对不对」，召回率问「找得全不全」，F1 取调和平均防偏科；过拟合靠交叉验证防。
- **可解释性是人文前提**：能用可解释模型就用，黑箱必须事后解释，模型输出当假设不当判决。
- 三大边界：**训练数据即偏见、历史不可反事实、概率不等于真理**。
