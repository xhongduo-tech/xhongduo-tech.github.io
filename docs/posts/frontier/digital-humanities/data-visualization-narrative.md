## 为什么可视化是数字人文的「最后一公里」

前面五节产出了词频、主题、网络、地图、模型——一堆数字与结构。但数字不会自己说话，**可视化（visualization）**是把分析结果交还给读者的通道：一张历时词频曲线，能让人一眼看见「科学」一词在 1915 年前后的跃升；一张人物关系图，能让隐藏的派系浮出水面。可视化之所以值得单独一节，是因为在数字人文里它**不是装饰，而是论证**：图的坐标选择、色彩分配、裁切范围，都在替你发表观点。塔夫特的名言「图形化是让数据为自己辩护」常被误读——其实好的图不是「数据自己辩护」，而是**作者精心布置的一场让数据发言的法庭**。本节讲清可视化的类型学、叙事结构、误导陷阱与设计伦理。

## 1 探索性可视化 vs 解释性可视化

按用途，人文可视化分两大阵营，目的与读者都不同：

| 维度 | 探索性可视化 | 解释性可视化 |
| --- | --- | --- |
| 目的 | 研究者自己发现问题 | 向读者传达结论 |
| 读者 | 本人/同行 | 公众/审稿人 |
| 特征 | 快速、临时、允许杂乱 | 精心裁剪、标注完整 |
| 典型形态 | 散点矩阵、交互过滤面板 | 一张图讲清一个论点 |
| 反面教材 | 把草稿图直接投稿 | 过度修饰掩盖数据 |

两者是同一份数据的两副面孔：先靠探索图**发现**「某时期词频异常」，再用解释图**论证**「该异常对应某事件」。数字人文项目的图册里，两类图往往并存，但**投稿与公众传播的图必须是解释性**——承载完整的图例、坐标说明与来源。

## 2 图与人文问题的配对

不同类型的图适合回答不同类型的人文问题，选错图型就是选错语言：

| 问题类型 | 适合的图 | 人文案例 |
| --- | --- | --- |
| 随时间变化 | 折线图、小多图、时间轴 | 「科学」词频历时曲线 |
| 类别比较 | 条形图（按长度排序） | 各文类作品产量对比 |
| 分布 | 直方图、核密度图 | 诗人籍贯的经纬分布 |
| 部分—整体 | 堆叠面积图（慎用饼图） | 期刊各栏目版面占比 |
| 关系结构 | 网络图、力导向图 | 师承与合著网络 |
| 空间分布 | 地图、热力面 | 灾害记录的地理集聚 |
| 多变量对应 | 平行坐标、散点矩阵 | 风格特征多维对照 |

一个常被忽视的细节：**饼图几乎不该用**——人眼对角度与面积的判断极差，堆叠条形或分列条形更诚实。另有一个小技巧：**小多图（small multiples）**——同一坐标刻度下并排多个小图，比一张塞满变量的巨图更利于比较，是塔夫特推崇的经典手法。

## 3 叙事：让图成为论证的一环

解释性可视化的终极形态是**数据叙事（data storytelling）**——把图嵌入一个「问题—证据—结论」的故事流。数字人文项目常采用三幕结构：

1. **设问**：用一句反常的观察开场——「晚清『科学』一词的词频在十年间暴增 40 倍」。反常制造好奇。
2. **证据**：多张图递进展开——先全局曲线，再放大关键年份，再叠加该年份的报刊事件标注，最后引用一段原文。**图与原文互证**，是数字人文叙事区别于纯数据新闻的关键。
3. **收束与保留**：给出结论，同时诚实交代不确定处——样本范围、OCR 误差、替代解释。**保留让论证可信**，全知口吻反而招疑。

交互式可视化（悬停显示原文、滑块切换年代）进一步把「读者」变成「共同探索者」：叙事不是单向灌输，而是邀请读者亲手验证路径。但交互要克制——**交互是给读者留的，不是给作者炫耀的**。

## 4 可视化最常犯的谎言

塔夫特最著名的概念之一是**数据墨水比（data-ink ratio）**：图上「承载信息」的墨水，应占「全部墨水」的绝大多数。装饰、阴影、三维效果、冗余刻度，都是降低比值的噪音。<span class="marginnote">塔夫特的《定量信息的可视化展示》（The Visual Display of Quantitative Information，1983）是现代数据可视化设计的奠基之作；「数据墨水比」是他最常被引用的概念之一。</span>由此出发，人文可视化的常见谎言清单：

- **截断坐标轴**：纵轴不从 0 开始，会戏剧性放大微小差异——对比图的轴必须标注清晰。
- **三维变形**：3D 柱状图扭曲高度与体积的感知，2D 永远更诚实。
- **色盲陷阱**：红绿对比对约 8% 的男性读者不可读，需用色盲安全配色。
- **图例缺失**：没有来源、没有样本量、没有时间范围的图，等于没有出处。
- **相关图暗示因果**：两曲线同涨同落只说明共变，图上必须声明「这不等同因果」。
- **过度平滑**：曲线平滑掉离群点，可能正好抹掉了最有价值的异常年份。

<span class="marginnote">「让数据自己辩护」的真相是：数据不会辩护，<strong>是人替它选择辩护的姿势</strong>。因此可视化设计是一种修辞——它不是掩盖，而是选择性地照亮。诚实的设计照亮真实的形状，并写明「我裁掉了什么」。</span>一张图若不能回答「你的数据哪来的、少了什么、为什么这么画」，它就不该发表。

## 5 可视化的可访问性：面向所有读者

好的可视化还要过**可访问性（accessibility）**这一关：

- **不只靠颜色**：用形状、线型、标签补充颜色通道，色盲读者与印刷黑白版都能读。
- **不只靠图**：为每张图配 alt 文本与文字性结论摘要，屏幕阅读器用户也能获得信息。
- **多模态呈现**：重要结论同时用图、表、文字三轨表达——读者各取所需，也便于校对。

在数字人文里，可访问性不单是公益，更是**学科规范**：你的图是给别人读的，而别人读图的方式比你想象的更多样。一张只对自己友好的图，在学术传播上是失败的。

## 6 一个可视化叙事的成型过程

把一个研究结果做成「能发表的一张图」，需要经历多轮迭代。以「晚清『科学』词频曲线」为例：

| 版本 | 形态 | 问题 |
| --- | --- | --- |
| v1 草稿 | 折线图 + 年份 | 曲线突兀，无上下文 |
| v2 加标注 | 叠加关键事件标记 | 读者不知标记依据 |
| v3 加对比 | 并排对照另一词（如「格致」） | 开始有论证力 |
| v4 定稿 | 加图例、来源、误差带 | 可发表、可复核 |

### 颜色与字体的纪律

- **配色三原则**：色盲安全、语义一致（红=强调、蓝=中性）、一图一主题色系。
- **字体两要求**：中文用无衬线（思源黑体等）、字号不小于 10px、与正文可区分。
- **图例一规矩**：图例放图内，说明放图注，来源放页脚——读者不用翻正文就能读图。

**可视化定稿的试金石**：把图打印成灰度、缩小到手机屏幕、遮住图例——三种情况下若读者仍能抓住主要结论，这张图才算合格。

### 从图到图景

一张图回答一个问题，一组图讲述一段历史。把若干单图编成「图景」有三条技巧：

- **同轴对齐**：多图共用时间轴，便于横向对比。
- **渐进放大**：先全局再局部，引导视线从概貌进入细节。
- **图间互引**：图 A 的标注区指向图 B，让读者在图中漫游。

**好的图景像好的论文**：有起承转合，有主次详略——可视化的终极目标，是让读者看完图景后，自己得出你希望他得出的结论。

## 7 小结

- 可视化分**探索性（自己发现问题）**与**解释性（向读者论证）**；传播与发表必须用解释性图。
- 图型选择取决于问题：时间用折线、比较用条形、关系用网络、空间用地图、多变量用小多图；**饼图基本不用**。
- 数据叙事三幕：**设问—证据—收束**；图与原文互证、保留不确定处，是数字人文叙事的特色。
- 数据墨水比是设计标尺；谎言清单包括**截断轴、3D、色盲配色、无图例、暗示因果、过度平滑**。
- 可访问性：不只靠颜色、不只靠图、多模态呈现。
