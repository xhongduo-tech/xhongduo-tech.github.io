## 为什么从认知架构开始

上一篇我们定义了认知计算：要造一台能理解、推理、学习、交互的机器。可「能力清单」只是愿望，「怎么搭」才是工程。**认知架构（cognitive architecture）**就是那个「怎么搭」——它把心智拆成一组固定的模块（工作记忆、长期记忆、目标、感知与行动接口），并规定这些模块之间如何通信、如何竞争、如何同步。它回答一个朴素的问题：如果思考是可计算的，那么「思考的程序」长什么样？

从「从极限到大模型」的视角看，大模型是一整块权重构成的隐式推理器，而认知架构是**显式地画出大脑的电路图**。两者代表人工智能史上最重要的两种路线，这一篇我们深入其中最有生命力的两支：**SOAR** 与 **ACT-R**。

## 1 SOAR：统一认知理论的实践者

**SOAR**（State, Operator, And Result，由纽厄尔、莱尔德与罗森布卢姆在 1983 年起持续开发）是「智能体在问题空间中搜索，直到找到解法」这一思想的机器化。它的世界模型很简单：系统总处于一个**状态（state）**，为了达到目标要施加**算子（operator）**，施加算子的结果把状态推进到新状态。

SOAR 的全部行为由一条**决策循环**驱动：如果当前状态已经知道该干什么，就执行；如果不知道，就触发**僵局（impasse）**，系统转而把「如何走出僵局」本身当作新的子问题来求解——求解出来后，把解法固化为一条**规则（rule）**存进长期记忆，下次再遇到就直接用。<span class="marginnote">「遇到不会的就现场学，学完存下来」——SOAR 把学习（chunking）内建在决策循环里，而不是像神经网络那样单独开一个训练阶段。这是它和联结主义最本质的分野。</span>

SOAR 由此获得三个特性：**离散的符号状态**、**目标是显式的一等公民**、**学习发生在循环内部**。它擅长规划与问题求解，在军事仿真、战术决策等需要「想清楚再做」的领域服役至今。

## 2 ACT-R：认知心理学的可运行理论

与 SOAR 的工程气质不同，**ACT-R**（Adaptive Control of Thought—Rational，安德森与莱博尔）的野心更「科学」：它要把认知心理学实验中测到的反应时间、错误率、学习曲线，精确地拟合出来。ACT-R 假设心智由一组**模块（module）**组成，模块之间通过**缓冲器（buffer）**交换信息：

- **知觉-运动模块**：视觉、听觉、手部动作，负责与外部世界打交道；
- **记忆模块**：声明性记忆（事实），存储为**块（chunk）**；
- **程序性记忆**：把「条件-动作」对写成**产生式规则（production rule）**；
- **目标模块**：记住当前目标与意图。

ACT-R 的每条产生式规则形如：**若 缓冲器中出现某条件，则 执行某动作并更新缓冲器**。规则之间有激活强度与匹配度，系统在每次循环里选择最「划算」的一条执行。安德森把这种选择解释为**理性分析（rational analysis）**的产物——人脑倾向于选择预期代价最小的那条行动路径。<span class="marginnote">「理性分析」意味着 ACT-R 里没有玄学：行为的统计规律（如遗忘曲线）被解释成贝叶斯最优决策的结果。这个「理性 = 贝叶斯」的设定，让 ACT-R 与《不确定性推理》一篇天然衔接。</span>

## 3 核心对比：SOAR 与 ACT-R

两者同属**产生式系统（production system）**家族，却走出两条路。下表是理解认知架构的关键对照：

| 维度 | SOAR | ACT-R |
| --- | --- | --- |
| 核心循环 | 问题空间搜索 + 僵局驱动 | 缓冲器驱动的产生式匹配 |
| 学习机制 | 组块化（chunking） | 声明性激活增强 / 产生式效用调整 |
| 与实验对齐 | 弱，重在工程任务 | 强，拟合人类反应时间与误差 |
| 记忆结构 | 工作记忆 + 长期程序记忆 | 声明性 / 程序性 / 目标多模块 |
| 擅长场景 | 规划、战术决策、游戏 AI | 认知心理学实验建模、人因工程 |
| 目标地位 | 显式一等公民 | 目标模块缓冲器 |

**辨析｜易错点：** 初读 SOAR/ACT-R 最容易误以为「认知架构 = 专家系统」。两者共享产生式规则的外壳，但专家系统的规则由领域专家手工填写、数量有限；认知架构的规则是**心智本身的组织原则**，目标在于解释或复现通用认知，而非局限于某个领域。另一处易错：ACT-R 的「模块」不是神经网络的层，模块之间没有梯度回传——它们交换的是符号化的块，而非连续张量。

## 4 公式解析：产生式规则的选择机制

认知架构的行为层是规则，规则层之下还压着一个选择问题：多条规则同时匹配时，执行哪一条？ACT-R 用**效用（utility）**量化每条规则的价值，规则 $i$ 的效用 $U_i$ 近似为：

$$
U_i = P_i \cdot G - C_i
$$

- **第一步，看结构**：效用 = 「成功的收益」减去「执行的代价」。$P_i$ 是规则 $i$ 导致成功的估计概率，$C_i$ 是执行它的期望代价（通常以时间为单位），$G$ 是达成目标带来的收益常数。
- **第二步，理解权衡**：一条规则即使成功率高，若代价太大，效用也会被压低；反之，代价小的规则即便概率平平，也可能胜出。**选择 = 对「收益/代价」的实时权衡**，这正是「理性分析」的落点。
- **第三步，连接学习**：系统执行某条规则后，根据实际是否成功**更新 $P_i$**（增强或衰减）——于是「学习」被归结为对效用参数的一步步修正，产生式系统由此获得了与神经网络相似的「越用越准」特性，只是更新对象从权重换成了效用。
- **第四步，与主线对话**：把这个效用公式与强化学习中的 Q 值 $Q(s,a) = \mathbb{E}[r \mid s,a]$ 对照着看——它们都是「行动的价值」的估计器，一个服务符号规则，一个服务连续策略。认知架构与深度强化学习在本专题《认知机器人》一篇将正式相遇。

<span class="marginnote">SOAR 也面临同样的选择问题，它用偏好与匹配程度的多维比较解决；ACT-R 则直接用数值效用。工程上「给候选排序」这件事，从认知架构到搜索引擎的 learning to rank，本质是同一个问题——排序依据不同而已。</span>

## 5 认知架构为什么还没有成为主流

既然 SOAR/ACT-R 如此优雅，为何今天的 AI 主角是大模型而不是它们？两个诚实的理由。其一，**符号产生式规则的表达力上限**：感知层的原始信号（像素、声波）难以优雅地落进离散规则，而联结主义网络天然擅长连续感知。其二，**手工设计成本**：把领域知识编码成规则需要大量人力，而深度学习从原始数据自动学特征。<span class="marginnote">但认知架构并未死去：它提供了大模型没有的东西——可审计的目标、可解释的决策链、以及把「学习」和「推理」统一进同一个循环的视角。今天的「智能体（agent）+ 工具调用 + 规划器」架构，某种意义上就是 SOAR 精神在神经网络时代还魂，见第四级《AI 智能体》。</span>

## 6 案例拆解：用 SOAR 走一遍「取水灭火」

把决策循环放进一个具体任务。设想一台 SOAR 驱动的消防机器人接到指令「把火扑灭」，初始状态里只有「火在 A 屋」这条知识，而它的算子库里只有「移动」「取水」「喷洒」三个算子。

**第一拍，匹配**：当前目标 `灭火`，当前状态 `火在A屋`。SOAR 在算子库里匹配——「移动」「取水」「喷洒」都不能直接作用于「火在A屋」，匹配失败，进入**僵局（impasse）**。僵局不是故障，而是 SOAR 的「好奇时刻」：它把「如何灭火」升级为一个新的子问题。

**第二拍，子问题求解**：系统在问题空间里搜索「灭火」的解法，找到一条链：`移动到水源 → 取水 → 移动到A屋 → 喷洒`。这条链通过后，SOAR 执行一个关键动作——**组块化（chunking）**：把「火在X屋 ⇒ 去水源取水再喷洒」固化成一条新算子，存进长期记忆。

**第三拍，直接用**：下次再遇到「火在 B 屋」，系统不再搜索——它直接从长期记忆里调出上次组块化的规则，「经验」第一次生效。这就是 SOAR 的学习：**不靠改权重，靠把解法编译成规则**。

**第四拍，失败与再搜索**：如果「喷洒」后发现火没灭（可能是油火，水反而助燃），当前算子失效，系统再次进入僵局，重新搜索并组块化一条「油火要用干粉」的修正规则。注意，旧规则没有被删除——它只是在新状态（油火）下不再被匹配，这正是符号系统「不灾难性遗忘」的来源。

**辨析｜易错点：** 别把 SOAR 的「组块化」与深度学习的「训练」画等号。组块化是**把一条已经找到的解法原样存起来**，学习发生在「搜索成功的那一瞬间」，一次就够；深度学习是**反复调整连续参数**，需要成千上万次梯度更新。两者的时间尺度与机制完全不同——这决定了 SOAR 擅长「可符号化的任务」，而联结主义擅长「不可言说的技能」。

把同一个任务交给 ACT-R，观察差异：ACT-R 不会出现「僵局—搜索—组块」的显式结构，而是每一条产生式规则按效用竞争，「取水」「喷洒」这些候选动作各自带一个效用值，系统按效用与代价排序执行，并通过多次尝试调整效用——它更像「反复试错中学」，SOAR 更像「一次想通后记住」。两种学习风格可用一张表并排：

| 维度 | SOAR | ACT-R |
| --- | --- | --- |
| 学习的触发 | 僵局产生时 | 每次规则执行后 |
| 学习的产物 | 新产生式规则（组块） | 效用参数增减 |
| 一次学习的信息量 | 整条解法链 | 单个行动的价值修正 |
| 对应的心理现象 | 顿悟、灵光一现 | 渐悟、熟能生巧 |
| 遗忘方式 | 规则失配（无灾难性遗忘） | 效用衰减（带遗忘曲线） |

<span class="marginnote">这两种学习风格的差异，恰好对应心理学里「顿悟（insight）」与「渐悟（gradual learning）」的经验之别。认知架构不是互相竞争的真假理论，而是「人类学习的不同侧面」的机器模型——这正是它们能共存的理由，也是下一节《符号主义与联结主义》正面对撞前的完整铺垫。</span>

最后，给认知架构一个「站在今天回头看」的坐标。SOAR 与 ACT-R 都诞生于 1980 年代，是「认知科学 × 计算」的第一批结晶；今天它们不再占据新闻头条，但它们的遗产正以更隐蔽的方式活在每个智能系统里：

- **目标分解**：SOAR 的「目标栈」演化成了今天智能体（agent）的「任务规划器」——大模型智能体也在把大目标拆成子目标、遇到失败重新规划。
- **产生式规则**：ACT-R 的「若条件则动作」演化成了今天的「规则引擎」「工具调用协议」「ReAct 模式」——「条件」是上下文匹配，「动作」是函数调用。
- **效用权衡**：ACT-R 的效用公式演化成了强化学习里的 Q 值——「做哪个动作更划算」这个决策骨架，五十年没变。
- **模块化心智**：SOAR/ACT-R 的「多模块 + 缓冲器」演化成了今天「记忆 / 规划 / 工具」分离的 agent 架构——认知科学的模块划分，比任何时髦框架都活得久。

这段遗产史说明一件事：**认知架构从没消失，它只是改名为「工程惯例」**。当你今天写一个带记忆、会规划、能解释的智能体时，你实际上是在重新实现 SOAR——只是没用它的名字。理解这一点，你会对本专题以及整个「从极限到大模型」主线里的智能体技术有更深一层的眼光。

最后补一个判断标准，帮你把「认知架构」与「普通软件框架」区分开：认知架构的关键不在于「有模块」，而在于**模块的划分依据的是认知科学理论，而非工程方便**——SOAR 的目标栈来自「问题求解」的理论，ACT-R 的缓冲器来自「人类反应时间」的实验。当你看到一个自称「认知架构」的系统时，问一句「它的模块划分有什么认知科学依据？」——答不上来的，多半只是普通软件披了件认知外衣。这个判据，能帮你在「认知架构」的营销热词里保持清醒。

## 7 小结

- **认知架构**把心智组织成固定模块与交互规则，是「思考程序」的显式电路图。
- **SOAR** 以问题空间搜索为核心，僵局触发学习，擅长规划与战术决策。
- **ACT-R** 以多模块 + 缓冲器 + 产生式规则拟合人类认知实验，追求与实验数据的定量吻合。
- 二者的规则选择机制可统一为**效用权衡**：成功的收益减去执行的代价。
- 认知架构的短板在感知层与工程成本，但这不妨碍它成为理解「符号 vs 连接」之争的最佳标本。

在下一节，我们将正面展开那场持续了半个世纪的思想战争：**符号主义与联结主义**——它们各自信什么、吵什么，以及为什么认知计算需要同时拥抱两者。
