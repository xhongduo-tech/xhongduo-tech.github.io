## 为什么从记忆讲起

一个只能「学一次、用一次」的系统不是认知系统。认知计算要像人一样：今天记住一条事实，下周还记得；练过一百遍的技能越用越顺；旧知识不被新知识冲垮。这一篇的**学习与记忆建模（learning and memory modeling）**回答三个问题：记忆分成哪几类、每类如何存储与检索、学习如何在记忆之上发生。它把认知心理学一个多世纪的实验积累，翻译成可计算的模型。

「从极限到大模型」的读者会想起大模型「见过」万亿 token 却记不住事实的荒诞：它把一切压进权重，没有「逐条存储、按需检索」的仓库。认知计算的记忆模型恰好是另一极——**显式的、分型的、带遗忘曲线的记忆**。理解它，就理解了认知系统「越用越聪明、且不遗忘」的工程秘密。

## 1 记忆的多重分型

认知心理学不把记忆当一块铁板，而把它分成**类型不同、存储位置不同、遗忘规律不同**的几个系统：

- **工作记忆（working memory）**：当前正在「思考」的那一小块信息，容量极小（经典说法是 7±2 个组块，现代实验更保守），几秒钟内刷新。
- **情景记忆（episodic memory）**：关于「具体事件」的记忆——「上周三我在咖啡店见到老王」。有时间、地点、人物，是一次性发生的事。
- **语义记忆（semantic memory）**：关于「世界事实」的记忆——「北京是中国的首都」。脱离了具体场景，是抽象的知识。
- **程序性记忆（procedural memory）**：关于「怎么做」的记忆——骑自行车、打字、解方程。难以言说，靠练习获得。

<span class="marginnote">这套分型是认知计算的<strong>存储规划蓝图</strong>：工作记忆对应推理过程中的瞬时缓冲区，情景记忆对应「这条经验发生过」的日志，语义记忆对应知识图谱，程序性记忆对应产生式规则与技能参数。一种认知架构要「像人」，至少要同时装备这四类存储。</span>

## 2 工作记忆：认知的「白板」

巴德利（Baddeley）的多成分模型是工作记忆的经典理论：**中央执行系统（central executive）**负责调度，下面挂着两个从属子系统——**语音环路（phonological loop）**存「心里默念」的声音信息，**视空间画板（visuospatial sketchpad）**存「在脑海里比划」的图形信息。你默背一个电话号码、在脑中旋转一个魔方，靠的正是这两个子系统。

对计算建模而言，工作记忆的启示是**容量与时限**：它一次性只能容纳少数符号结构，而且会快速衰退。认知系统必须像人一样「及时把重要的工作记忆内容固化进长期记忆」，否则信息就丢了。<span class="marginnote">现代「上下文窗口」就是工作记忆的机器版，但两者有本质差别：大模型的上下文窗口是「一次性全部塞给模型」，而人/认知架构的工作记忆是<strong>一个小而动态更新的缓冲区，与长期记忆实时交互</strong>——这正是 RAG（检索增强）要模拟的动作：窗口装不下就从仓库里取。</span>

## 3 长期记忆的检索：激活与遗忘

长期记忆怎么「想起」一条知识？ACT-R 给出一个漂亮的计算理论：每条记忆块（chunk）有一个**激活值（activation）**，激活值越高，越容易被检索到；激活值随时间衰减、随重复使用回升。检索不是「全库扫描」，而是「取激活值最高的那个块」。

这直接解释了**遗忘曲线**：艾宾浩斯（Ebbinghaus）1885 年测出，记忆留存随时间指数式衰减，且**复习能重置并抬升留存曲线**。间隔重复（spaced repetition）的全部威力，就在于赶在曲线跌穿之前复习一次，把记忆一次次推回高位——今天 Anki、SuperMemo 等记忆软件，都是这条曲线与这条激活规则的工程化。

## 4 公式解析：ACT-R 的激活方程——遗忘的数学

ACT-R 把「一条记忆的当前强度」写成基级激活（base-level activation）：

$$
A_i = \ln\!\left( \sum_{j=1}^{n} t_j^{\,-d} \right)
$$

- **第一步，认符号**：$A_i$ 是记忆块 $i$ 的激活值；$n$ 是这条记忆被使用的总次数；$t_j$ 是第 $j$ 次使用距离现在的**时间间隔**；$d$ 是**衰减率**（通常取 0.5 左右），控制遗忘速度。
- **第二步，读结构**：求和号里每一项 $t_j^{-d}$ 都是「那次使用的残留强度」——越近的使用贡献越大，越久远贡献越接近零。激活值 = 所有历史使用的残留强度之和，再取对数压回一个可控尺度。
- **第三步，看遗忘与复习**：若 $n$ 不变而时间流逝，每一项 $t_j^{-d}$ 都变小，$A_i$ 下降——这是**遗忘**。若再复习一次（新增一项 $t_{\text{new}}^{-d} = 1$），激活立刻跳升——这是**复习的收益**。于是「什么时候该复习」有了精确判据：当 $A_i$ 低于某个检索阈值，这条记忆就「想不起来」了。
- **第四步，连主线**：把这个激活方程与神经网络的参数对比——神经网络把「记忆」存进权重，永久固化、很难逐条修改；ACT-R 的激活是可变的**元数据**，让「记住什么、忘掉什么」成为可调策略。这正是认知系统做**终身学习（lifelong learning）**的抓手，也预告了下一节的灾难性遗忘问题。

<span class="marginnote">激活方程还解释了「提示效应」：检索一条记忆时，与其关联的块会被<strong>扩展激活（spreading activation）</strong>波及——想起「咖啡店」会顺带拉高「老王」的激活。这就是联想的机制，也是 ACT-R 与《神经认知模型》里赫布规则的精神对应：符号层的「扩展激活」就是权重层的「连接强度」。</span>

## 5 学习、巩固与灾难性遗忘

记忆不是「存入即永存」，而是一个**巩固（consolidation）**过程：新记忆先在短期系统里不稳定地存在，再通过睡眠中的重放（replay）逐步固化到长期系统。对认知系统，巩固意味着两件事：**重放**（把重要经验反复激活，等价于离线复习）与**结构化**（把新经验融入既有知识图，而非孤岛式存储）。

深度学习在这里有个著名困境：**灾难性遗忘（catastrophic forgetting）**——神经网络学新任务时，会剧烈破坏对旧任务的记忆，因为权重是共享的。认知架构的记忆模型天然免疫：不同任务的记忆块各占各的激活槽位，旧知识不会因为新知识写入而被覆盖。<span class="marginnote">现代「持续学习」（continual learning）研究正是要把认知架构的这套免疫机制搬进神经网络：弹性权重巩固（EWC）用重要度矩阵保护关键权重、重放缓冲区（replay buffer）模拟情景记忆回放、参数隔离为不同任务分派独立子网络——每一种都对应着一种认知记忆类型的工程移植。</span>

## 6 学习与记忆在认知计算中的整合

回到整座大厦：感知层产出的符号结构先进**工作记忆**；重要的被固化进**情景记忆**（记录事件）与**语义记忆**（抽象为事实，写入知识图谱）；反复成功的行为被编译成**程序性记忆**（产生式规则或技能参数）；记忆检索靠**激活 + 扩展激活**；遗忘由激活衰减与巩固策略共同管理。<span class="marginnote">这五条合起来，就是一篇「如何给认知系统装记忆」的完整规格书。SOAR 的组块化把「刚学会的解法」即时编译为长期规则，ACT-R 的激活方程管理语义检索——两套架构各管一类记忆，正好互补。</span>

## 7 案例拆解：给一个背单词软件装上记忆模型

把本文的组件装进一个你大概用过的产品：背单词软件。大多数背单词软件只是「今天推 20 个新词」，而装了认知记忆模型的版本，行为完全不同。看它背后的三块引擎。

**引擎一：遗忘曲线调度（spacing）**。软件为每个单词维护一个「下次复习时间」，依据就是遗忘曲线与 ACT-R 激活方程：一个词背对后，激活 $A_i$ 上升，随后随时间按 $t^{-d}$ 衰减。软件不按固定间隔推复习，而是**掐着点**推——当某个词的激活跌近「想不起来」的阈值时，它正好出现在你的复习列表里。你背得越熟，它推得越稀；越生疏，推得越密。这就是「间隔效应」的机器执行。

**引擎二：错因分诊（error diagnosis）**。同一个词答错，原因不同，处理不同。「拼写错」——说明词形记忆弱，软件接下来重点练拼写；「意思混」（把 abandon 和 absence 搞混）——说明两个词形成了错误的联想，软件用「交错练习」把这对混淆词打乱着一起练。它用的正是《教育与个性化学习》里 BKT 的「猜测/失误」分解：区分「不会」与「粗心」。

**引擎三：记忆巩固（consolidation）**。每天睡前，软件把当天高频错词重放一遍——模拟睡眠中的记忆重放。这不是噱头：研究表明，间隔一夜的复习比当天重复更牢固，因为巩固发生在睡眠里。认知系统把「复习」从「纯重复」升级为「掐点 + 分诊 + 重放」的三段式。

**辨析｜易错点：** 这套引擎最大的陷阱是「为复习而复习」：如果一个词你已经连续七天轻松记住，激活很高，继续推它纯粹浪费学习时间；反之如果一个词总是推不对，死磕「明天再来」也不对——应该换策略（换例句、换记法），而不是换频率。**认知记忆模型的正确目标是「以最少的总复习次数达到长期掌握」，而不是「每天完成复习配额」**——优化目标错了，再好的模型也白搭。<span class="marginnote">把「背单词」换成「复习微积分」「练钢琴指法」「背法律条文」，这套三引擎结构完全通用——遗忘曲线调度、错因分诊、记忆巩固，是认知系统给所有「技能习得」任务的统一配方。它与《教育与个性化学习》共享 BKT，与《认知机器人》共享「在恰当时刻干预」，与《认知助手》共享「记住用户」。</span>

这套三引擎之所以可行，前提是记忆被**显式地、逐条地**建模——每个词一条记录、一个激活值、一个下次复习时间。这恰恰是神经网络做不到的：把「单词」压进权重后，你既不知道它记住了哪个词，也无法单独给某个词排复习时间。**认知计算选显式记忆，不是怀旧，而是因为「逐条干预」这个能力本身需要「逐条存储」**——这是《认知计算与深度学习》里神经符号融合的重要动机。

回到「记忆」这个主题本身，值得把四类记忆在认知架构里的「分工边界」再压一张速查表，因为它是后续所有应用（教育、助手、机器人）都会用到的底层地图：

| 记忆类型 | 存什么 | 如何写入 | 如何检索 | 机器对应 |
| --- | --- | --- | --- | --- |
| 工作记忆 | 当前任务信息 | 感知/检索流入 | 实时刷新 | 上下文窗口 |
| 情景记忆 | 具体事件 | 一次记录 | 按时间线索 | 交互日志 |
| 语义记忆 | 世界事实 | 抽象与固化 | 激活检索 | 知识图谱 |
| 程序性记忆 | 怎么做 | 反复练习 | 自动触发 | 产生式规则 / 技能 |

这张表揭示了认知记忆工程的三个常见错误：**把情景当语义存**（记住「上周三吃了火锅」却当成了「火锅=周三才吃」的规律）、**把工作记忆当长期记忆用**（指望上下文窗口装下一切，结果装不下也检索不了）、**把程序性记忆当语义存**（试图用「讲道理」教会骑自行车——程序性记忆只能靠练）。三类错误在真实产品里每天都在发生，而它们的解药，都在这张表的「分型」里。

本节留三个练习，让「记忆建模」从抽象方程变成你的设计工具：

1. **手算 ACT-R 激活的「复习收益」**：设一条记忆被使用过 3 次，时间间隔分别为 $t_1=100,\ t_2=50,\ t_3=10$（单位：天），衰减率 $d=0.5$。算出当前激活 $A = \ln(100^{-0.5} + 50^{-0.5} + 10^{-0.5})$。然后假设现在复习一次，$t_{\text{new}}=0$，重算激活——对比前后，你会直观看到「复习把激活拉回多高」。

2. **设计一个「该不该现在复习」的判定器**：给一个闪卡系统写一条判定规则：什么时候该把某张卡推给用户复习？（提示：当它的激活低于某个阈值、且距离上次复习超过某间隔。）再写一条「该不该不再推」的规则——你会被迫思考「掌握到什么程度算记住」，这正是激活模型相对「固定间隔」的优势。

3. **把四类记忆映射到你的生活**：各举一个你自己的例子填入四类记忆（工作、情景、语义、程序），并说明「如果机器想替你记住这件事，该用哪类存储」。这个练习会立刻暴露一个事实：**多数「记忆产品」只做了情景记忆（日志），而最有价值的语义记忆与程序性记忆反而没人做**——这就是认知记忆建模的市场空白。

三题做完，你会明白记忆建模不是「一个方程」，而是一套「什么时候存、怎么检索、何时复习、如何遗忘」的完整策略——它同时回答了人的记忆之谜与机器的记忆工程。

最后，把记忆建模与「知识表示」的关系点明，因为它们共享「存储」这个词却分属两层：知识表示存的是「世界的事实」（语义记忆的载体，见《知识表示与推理》《语义网与知识图谱》），记忆建模管的是「这些事实何时被想起、何时被遗忘」（记忆的动力学）。**一个管「有什么」，一个管「何时能用」**——认知系统要两者兼备：图谱告诉你「北京是首都」，激活方程告诉你「此刻要不要把这条事实调进工作记忆」。想清楚这个分工，记忆建模就不是孤立的一篇，而是贯穿所有应用篇的「检索调度器」。

最后用一句话把记忆建模的「地位」抬到它该在的位置：记忆不是认知系统的一个配件，而是**所有认知能力的后台**——理解要调用语义记忆，推理要占用工作记忆，学习要写入长期记忆，连「信任用户」都需要跨会话记住用户。认知计算的每一篇应用（医疗、金融、教育、助手），本质上都是在「记忆之上做决策」。理解了记忆的分型、检索与遗忘，你就握住了认知系统最底层的数据库——这个数据库的架构，决定了一切上层的可能。

一句话收束：记忆建模的终极追问是「什么值得记、什么时候忘」——认知系统与人的区别之一，就在于它能更精确地回答这个问题，而不是用「遗忘」来逃避。

## 8 小结

- 记忆分**工作、情景、语义、程序**四类，认知架构应同时装备，各司其职。
- **工作记忆**容量小、刷新快，与长期记忆实时交互——RAG 是它的机器版雏形。
- **激活 + 遗忘**是长期记忆的检索引擎：激活值高则易取，随使用上升、随时间衰减。
- **ACT-R 激活方程**（$A_i = \ln\sum_j t_j^{-d}$）把遗忘与复习的收益精确量化，是间隔重复的原理。
- 记忆需要**巩固**（重放 + 结构化）；神经网络有**灾难性遗忘**，认知架构天然免疫，持续学习研究正在向它取经。
- 学习 = 在四类记忆之间流动与固化的过程，不是单独一个「训练阶段」。

在下一节，我们回到认知计算的数学心脏：**不确定性推理（贝叶斯）**——系统在证据不全时如何定量地「猜」，以及为什么「置信度」是认知系统最珍贵的资产。
