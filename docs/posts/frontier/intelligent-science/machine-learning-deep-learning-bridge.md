## 为什么从机器学习与深度学习衔接开始

前两章的专家系统靠「人写规则」，这一章开始靠「机器学规则」。
**机器学习（machine learning, ML）**是从数据中自动归纳规律的技术，**深度学习（deep learning, DL）**是机器学习里以多层神经网络为核心、自动学习特征表示的一支。
智能科学的技术体系里，ML/DL 是最重要的一根承重梁——本网站从「极限到大模型」的另一条主线也正汇聚于此：微积分给了梯度，概率给了损失，线性代数给了高维表示。

## 1 从规则到学习：范式的转移

专家系统把知识写成 IF–THEN 规则，人负责把经验翻译成规则。
机器学习反转了方向：**人提供「输入—输出」样例与目标函数，机器自己找出从输入到输出的规律**。
这张对照表是两代技术的分水岭：

| 维度 | 专家系统 | 机器学习 |
| --- | --- | --- |
| 知识来源 | 专家访谈、手工编码 | 数据中自动归纳 |
| 主要成本 | 知识获取 | 数据采集与标注 |
| 边界行为 | 越界即崩溃 | 越界后性能平滑下降 |
| 可解释性 | 高（规则可读） | 低（参数不可读） |
| 适用领域 | 窄、稳定、规则清晰 | 广、多变、模式难言说 |

关键的分界点是**泛化（generalization）**：机器学习关心的不是记住训练样例，而是对**没见过的数据**做出正确预测。
<span class="marginnote">「背答案」不是学习，「会做题」才是。机器学习的全部学问，本质上是「在有限的训练数据上，学出对新数据有效的规律」——这与第一级《概率论》里的「用样本估计总体」是同一件事的两个名字。</span>

## 2 机器学习的三大类型与基本流程

按「反馈信号」的不同，机器学习分三大类型：

**监督学习（supervised learning）**：给定输入与标签对，学输入→标签的映射。
  分类（垃圾邮件识别）与回归（房价预测）都在此列。
**无监督学习（unsupervised learning）**：只有输入，无标签。目标是从数据里发现结构——聚类、降维、密度估计。
**强化学习（reinforcement learning）**：没有现成答案，只有奖惩信号。
智能体在试错中学会「什么动作带来长期回报」，与第 1 章「智能 = 长期回报最大化」直接呼应。
<span class="marginnote">三者的信号强度递减：监督学习给答案，无监督学习给方向，强化学习只给评分。信号越弱，学习越难，也越接近真实世界的「智能」——毕竟没人给人生每个选择标注正确答案。</span>

基本流程是固定的五步：**收集数据 → 特征提取 → 选择模型 → 训练（优化参数） → 评估（测试泛化）**。

## 3 深度学习：从特征工程到表示学习

传统机器学习的一个巨大瓶颈是**特征工程**：输入不能直接喂给模型，必须由人精心设计「特征」——图像的颜色直方图、文本的词频向量。
特征的优劣直接决定模型上限，而特征设计全靠人的领域经验。

**深度学习（deep learning）**彻底改变了这一分工：**特征不再由人设计，而由网络自动学习**。深度网络由多层非线性变换堆叠而成，第一层学低层特征（边缘、音素），深层学高层语义（部件、语义概念），端到端地从原始数据直达目标。<span class="marginnote">「表示学习（representation learning）」是深度学习的口号：让机器自己学出对任务有利的数据表示。正是这一点，让深度学习从「需要特征工程师的算法」变成「能规模化利用海量数据的引擎」。</span>

**辨析｜易错点：**深度学习不是「更深的机器学习」这么简单。传统 ML 模型（决策树、SVM、线性回归）用**人工特征 + 浅层模型**；DL 用**原始数据 + 深层模型 + 自动特征**。两者可以在同一任务上共存，但哲学不同：ML 优化「在给定表示下的预测」，DL 同时优化「表示本身」与「表示上的预测」。

## 4 为什么「深」有效

深度学习在图像、语音、语言上取得远超传统 ML 的成绩，原因可归结为三条：

**层级抽象与数据量匹配**：深度网络的结构天然适合「层层抽象」——就像感知智能里讲的层级管线，浅层到深层对应简单到复杂。
  数据越多，深层网络越能发挥结构优势。
**端到端优化**：整条「输入→输出」链路联合优化，误差从末端逐层回传，任何一层都能为整体目标调整——不存在「特征工程与模型脱节」的问题。
**规模效应**：现代深度学习的突破与**算力、数据、算法**的三重规模效应绑定：GPU 算力、互联网数据、可扩展的训练框架，三者每十年量级跃升，深度学习就上一个台阶。
<span class="marginnote">一个关键实证：传统 ML 的性能在数据增多时很快饱和（模型容量不够），而深度网络的性能随数据量持续上升——「大数据 + 大模型」的组合是深度学习时代的核心配方，也是大模型能出现的根本原因。</span>

## 5 公式解析：梯度下降的更新规则

机器学习和深度学习共享同一个优化引擎：**梯度下降（gradient descent）**。
它的更新规则是：

$$
\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}(\theta)
$$

- **第一步，$\mathcal{L}(\theta)$**：损失函数——模型参数 $\theta$ 下的整体误差，第 2 章研究范式里见过它。
- **第二步，$\nabla_\theta \mathcal{L}(\theta)$**：损失关于参数的梯度——一个向量，指向「损失增长最快」的方向。
- **第三步，$-\eta \nabla_\theta \mathcal{L}(\theta)$**：往梯度的反方向（损失下降方向）迈一步，步长由学习率 $\eta$ 控制。
- **第四步，$\theta \leftarrow \cdots$**：参数更新，然后重复——直到损失不再下降，模型「学会」了。

直觉：**梯度下降是蒙着眼走下坡路的算法**——只感受脚下最陡的方向，一步步蹭到谷底。
传统 ML 用这个规则优化浅层模型；
深度学习让它作用于千万级参数的深度网络，并靠**反向传播**高效算出每一层的梯度。
$\eta$ 太小收敛慢，太大震荡甚至发散——调学习率是两代技术共同的必修课。

## 6 衔接的要点：何时用 ML，何时用 DL

衔接不是「DL 取代 ML」，而是**按问题选择**：

| 场景 | 推荐 | 理由 |
| --- | --- | --- |
| 数据量小（千级） | 传统 ML | 深度网络易过拟合，线性/树模型更稳 |
| 数据量大（百万级） | 深度学习 | 容量优势释放，性能持续上升 |
| 特征明确可解释 | 传统 ML | 可解释、部署轻、调试快 |
| 原始数据（图像/文本/语音） | 深度学习 | 免特征工程，自动学表示 |
| 强实时、受限硬件 | 传统 ML | 计算开销低一个量级 |

**辨析｜易错点：**「深度学习能自动学特征」不等于「不需要领域知识」。数据清洗、问题建模、损失设计、数据增强仍然依赖领域经验——DL 把特征工程的重担从「模型前」搬到了「模型外」。衔接的智慧是：**让 ML 处理小而稳的问题，让 DL 攻克大而复杂的问题，让领域知识决定两者边界**。

## 7 训练的常见失败与数据为中心的方法

机器学习的工程实践里，模型的「翻车」很少是「算法不行」，而是「数据与流程」出了问题。
三类最常见的失败模式：

**过拟合（overfitting）**：模型把训练集「背」下来，在新数据上表现暴跌。经典症状：训练集准确率接近满分、验证集却不高。对策是正则化（限制模型复杂度）、数据增强（增加训练变体）、早停（验证集不再改善就停止训练）。「背答案」与「会做题」的分界，正是过拟合与否的分界。

**数据泄露（data leakage）**：训练集与测试集之间「悄悄共享了信息」——例如把测试集的一部分当训练数据、或在时间序列里「用未来预测过去」。数据泄露让评估分数虚高，上线即崩。<span class="marginnote">数据泄露是「最难发现的错误」：模型没有错，流程错了——数据切分、特征构造、预处理步骤里的任何一个「信息穿越」，都会让「验证集分数」变成谎言。它提醒我们：机器学习的评估分数只有在「数据流程正确」时才有意义。</span>

**分布漂移（distribution shift）**：训练数据与线上数据分布不同——用户变了、季节变了、环境变了，模型在「没见过的新分布」上性能骤降。这解释了「模型上线后变笨」的现象。

针对这些失败，「**以数据为中心（data-centric AI）**」的方法论兴起：与其执着于换更强的模型，不如系统性改善数据——清理噪声标签、补齐长尾样本、修正数据偏差。
吴恩达的论断常被引用：「模型进步的红利正在耗尽，而数据改进的红利远未挖尽。
」<span class="marginnote">「数据质量 > 模型复杂度」是 data-centric 运动的核心主张，但需辩证看：<strong>高质量数据与强模型不是二选一，而是乘法关系</strong>——数据决定了性能天花板，模型决定逼近天花板的效率。数据为中心不是「轻视模型」，而是「先保证地板扎实」。</span>

**辨析｜易错点：**「提升模型」与「提升数据」经常被误当成同一件事。改模型（加层、调参）只改变「对同一份数据的利用效率」；改数据（清洗、增强、补样）改变「模型能学到什么」。一个经验法则：**先诊断数据，再折腾模型**——如果错误模式集中在某些样本类型，问题多半在数据；如果错误分布均匀，才是模型容量的问题。

## 8 小结

- 机器学习把「人写规则」反转成「机器从数据学规律」，核心命题是**泛化**。
- 三大类型：**监督、无监督、强化**，按反馈信号的强弱排序。
- 深度学习的本质是**表示学习**：特征从人工设计转为网络自动学习，端到端优化。
- 「深」有效的三条原因：**层级抽象、端到端、规模效应**。
- 两者共享梯度下降引擎：$\theta \leftarrow \theta - \eta\nabla_\theta\mathcal{L}(\theta)$，按数据量、可解释性、实时性选择用谁。
