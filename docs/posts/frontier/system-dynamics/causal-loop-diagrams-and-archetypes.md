## 为什么从因果回路图开始

上一节我们建立了「反馈回路」的概念，但光在脑子里想回路是不够的——**模型必须画出来，才能被讨论、被检验、被分享**。因果回路图（Causal Loop Diagram，CLD）就是系统动力学最轻量的一张「系统地图」：它用箭头与极性记号，把盘根错节的因果链压缩成一目了然的回路结构。<span class="marginnote">CLD 的哲学是「一张图胜过千言万语」：1980 年代美国电话电报公司（AT&T）重组时，顾问用一张 CLD 让全体高管在几小时内就「为什么调整价格会引火烧身」达成共识——这在没有共同语言之前需要数月。</span>而在这些回路中反复出现的经典结构，被称为**基模（archetypes）**。学会画 CLD、认基模，就是学会「用系统的语法说话」。

## 1 因果回路图的语法

一张 CLD 由三样东西组成。

**变量（variable）**：系统里的要素，用名词短语表示，如「产品价格」「顾客数量」。**因果链（causal link）**：用箭头 $A \to B$ 表示「A 影响 B」。链上标注极性：**正号（+）**表示「A 增加，B 也增加；A 减少，B 也减少」，**负号（−）**表示「A 增加，B 减少」——注意极性描述的是**同向 / 反向**，不是「好 / 坏」。<span class="marginnote">正号链要读作「A 与 B 同向变化」，负号链读作「A 与 B 反向变化」。日常语言里的「价格上涨 → 需求下降」就是一条负号链；「价格上涨 → 利润上升」则是正号链。</span>

**回路极性（loop polarity）**：把回路里所有链的极性相乘。偶数个负号（含 0 个）→ **增强回路（R）**；奇数个负号 → **平衡回路（B）**。<span class="marginnote">这个「数负号」的规则在第一篇介绍过，现在它落地成了一种制图规范：识别出回路后在回路中央标一个 R 或 B，读者一眼就能看出「这个回路在放大还是在校正」。</span>此外，图上可标注**延迟（delay）**符号 `∥`，表示因果链上存在时间滞后——延迟是振荡的来源，第六篇将专门处理它。

绘制 CLD 的常见错误：把「库存」「销量」这种**存量**与「进货」「卖出」这种**流量**混在同一个图里。CLD 是定性工具，允许混写，但一旦进入定量建模就必须分开——这是第三篇《存量流量图》的伏笔。

把「数负号判极性」练成条件反射，三个示例就够了：

- **存款 → 利息 → 存款**：全正链，0 个负号（偶数），增强回路 R——滚雪球。
- **库存 → 缺货 → 订货 → 库存**：库存上升 → 缺货下降（负号）、缺货上升 → 订货上升（正号）、订货上升 → 库存上升（正号），共 1 个负号（奇数），平衡回路 B——自我校正。
- **价格 → 需求 → 价格**：价格上升 → 需求下降（负号）、需求下降 → 价格回落（负号），共 2 个负号（偶数），增强回路 R——价格螺旋。

练熟后会发现一个捷径：**回路里负号个数为奇数 ⇔ 平衡回路 ⇔ 系统里有「刹车」**。抓住「刹车在哪」，就抓住了系统的稳定性来源。

## 2 十一个经典基模

系统思考者在成百上千个 CLD 中总结出反复出现的结构，称为**基模（system archetypes）**。掌握它们等于获得一套「模式识别」的模板。下表列出最常用的十一个：

| 基模 | 回路结构 | 典型症状 |
| --- | --- | --- |
| 增长上限（Limits to Growth） | R 增长 + B 上限 | 越做越难，后劲不足 |
| 转移负担（Shifting the Burden） | B 缓解 + R 依赖 | 治标不治本，依赖成瘾 |
| 目标侵蚀（Eroding Goals） | 目标随表现下滑 | 标准越降越低 |
| 恶性竞争（Escalation） | 两个 R 对顶 | 军备竞赛、价格战 |
| 富者愈富（Success to the Successful） | 两个 R 竞争资源 | 赢家通吃 |
| 公地悲剧（Tragedy of the Commons） | 多个 R 共享有限资源 | 资源耗尽 |
| 成长与投资不足（Growth and Underinvestment） | R 增长 + 投资延迟 | 产能跟不上需求 |
| 意外之敌（Accidental Adversaries） | 两个 R 互相伤害 | 盟友变对手 |
| 上瘾结构（Addiction） | 转移负担 + 副作用 | 戒断困难 |
| 共同愿景稀释（Drifting Goals） | 目标侵蚀复合体 | 愿景褪色 |
| 规则陷阱（Fixes That Fail） | 短期 B + 长期 R 反噬 | 按下葫芦浮起瓢 |

**辨析｜易错点：** 基模不是「菜谱」，不是说「识别出公地悲剧就能一键解决」。基模的价值是**指出干预的杠杆点**——例如「增长上限」的杠杆不在「加速增长」而在「解除或推迟上限」；「转移负担」的杠杆在于处理根本问题而非长期依赖解。把基模当标签贴，是最常见的误用。

## 3 公式解析：三个基模的回路方程

基模的数学内核并不神秘，它们只是若干标准方程的组合。取三个高频基模拆解。

**增长上限**：一个增强回路被一个平衡回路压制。

$$
\frac{dX}{dt} = g\,X\left(1 - \frac{X}{K}\right)
$$

- **第一步，看结构**：$gX$ 来自增强回路（增长），$(1 - X/K)$ 来自平衡回路（资源上限）。$K$ 是环境容量。
- **第二步，解方程**：这是 Logistic 方程，解为 $X(t) = \dfrac{K}{1 + \left(\frac{K}{X_0}-1\right)e^{-gt}}$——初始近似指数，接近 $K$ 时趋缓，最终停在 $K$。
- **第三步，读行为**：曲线呈 S 形。**「感觉越走越顺，实际越走越顶」**——增长上限的数学根源就在这里。

**转移负担**：症状缓解回路（B）与根本解回路（R）并行，且症状解削弱根本解。设症状为 $S$，根本治本投入为 $I$，则缓解速率为 $a\,S$，而治本投入随时间衰减 $\frac{dI}{dt} = -b\,S$——因为症状缓解后，解决根本问题的压力也减小了。

**目标侵蚀**：实际表现 $P$ 低于目标 $T$ 产生压力，压力推动 $T$ 下调：

$$
\frac{dT}{dt} = -k\,(T - P)
$$

- **第一步，读结构**：偏差 $(T - P)$ 越大，目标下调越快；$k$ 是下调速率。注意方向——目标是「追着」实际表现往下走，不是往上修。
- **第二步，看机制**：目标下滑后，偏差 $(T - P)$ 随之缩小，压力减小，下滑放缓——一条「目标自我让位」的平衡回路。**目标在这里不是固定常数，而是可被侵蚀的存量**。
- **第三步，读教训**：目标侵蚀与增长上限不同——前者是「目标自己放弃」，后者是「增长被资源顶住」。识别出目标侵蚀，就找到了「标准滑坡」的病根：不修复实际表现，只反复下调目标。

三个基模方程放在一起对照：**增长上限 = 增强项 × 平衡项；转移负担 = 症状解削弱根本解；目标侵蚀 = 目标随偏差衰减**。基模的数学内核就这么简单——几条标准方程的组合，配上不同的回路拓扑，就生成了整本「行为词典」。

## 4 因果回路图的进阶语法

识别回路只是第一步，把 CLD 画得**无歧义、可复用**还需要四条纪律。

**延迟要标位置**：延迟记号 `∥` 标在「决策依据」与「行动生效」之间，而非任意一条链上——标错了位置，振荡的因果就讲错了。**变量用名词短语**：CLD 里的变量是「量」不是「动作」——写「进货」不如写「进货量」，「库存下降」是流量，不该作为节点出现在 CLD 上。<span class="marginnote">变量命名的名词化原则来自 Sterman：节点必须是「可以在某一时刻取值的量」。动词短语（如「增加产量」）隐含了方向，会把极性讨论搅浑——一个节点只能是一个量，方向留给箭头去表达。</span>**合并同义变量**：同一个量在不同人口中可能叫「库存」与「存货」，画图前先统一术语，否则回路会在改名处「断链」。**极性沿链一周检查**：每条回路画完后，绕链走一圈数负号——奇数个负号是平衡回路、偶数个是增强，这是最容易自查也最常被跳过的动作。

## 5 从基模到干预：把标签变成杠杆

基模不是终点，识别它的目的是**找到干预点**。同一个基模，本能反应与杠杆式干预的效果天差地别：

| 基模 | 本能反应（低效） | 杠杆式干预（高效） |
| --- | --- | --- |
| 增长上限 | 加大马力猛推 R | 解除或推迟上限 $K$ |
| 转移负担 | 加强症状缓解 | 提高根本解的可得性 |
| 目标侵蚀 | 接受新的低目标 | 修复目标与实际表现的锚定 |
| 恶性竞争 | 跟进加码 | 单方面降级、改变博弈规则 |
| 公地悲剧 | 各扫门前雪 | 共有资源私有化 / 配额管制 |
| 富者愈富 | 补贴落后者 | 拆分资源分配结构 |

这张表的共同规律：**本能反应都在「增强回路」上使劲，高效干预都在「平衡回路」或「规则层」上动手**——这直接预告第十一篇的杠杆点理论。基模的价值，正在于把「该往哪使劲」从口号变成可讨论的结构问题。

## 6 辨析：基模的三个常见误用

**误用一：把基模当「罪名」**。说「这是公地悲剧」不等于诊断完成——真正要做的是指出哪条资源、哪群使用者、哪条反馈在耗尽它。**误用二：在一张 CLD 上强行套单个基模**。一张真实系统的 CLD 往往同时含有两三个基模，套一个标签反而掩盖了多重结构。**误用三：只识别、不落地**。识别出基模却不回落到具体干预，等于医生会诊完却不开处方——上一节那张「基模 → 杠杆」对照表，就是让识别落地的处方签。

## 7 动手练习（把 CLD 画进肌肉记忆）

- 把你所在组织的一个「按下葫芦浮起瓢」问题画成 CLD，标出每条链的极性。
- 在图上找出至少一个基模，用第五节的表格给它配一个杠杆式干预。
- 给「增长上限」画一张带延迟记号的 CLD，指出延迟在哪个环节制造超调。
- 用「名词化」原则检查你的 CLD：有没有把流量或动作写成了节点？
- 找一位同事，让 TA 仅凭你的图复述系统的行为——检验 CLD 是否无歧义。

## 8 小结

- **CLD 语法**：变量（名词）+ 因果链（带极性）+ 回路（数负号判 R/B）+ 延迟记号 `∥`。
- **十一个基模**是反复出现的回路模板；基模的价值在指出杠杆点，不在贴标签。
- 三个基模方程：增长上限（Logistic）、转移负担（症状解削弱根本解）、目标侵蚀（目标随偏差衰减）。
- 基模误用三连：当罪名、硬套单标签、只识别不落地。
- 本能反应在增强回路上使劲，高效干预在平衡回路或规则层动手。

在下一节，我们将把 CLD 升级成能算数的**存量流量图（SFD）**——给每个回路配上存量、流量与信息弧，让「画得出的地图」变成「算得出的模型」。
