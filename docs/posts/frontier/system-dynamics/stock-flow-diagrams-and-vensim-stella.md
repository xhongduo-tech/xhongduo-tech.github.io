## 为什么从存量流量图开始

上一节的因果回路图（CLD）能讲清结构，却算不出数量。要回答「地铁提价 1 元乘客减少几成」「疫情下需要多少张病床」，必须把系统翻译成**存量流量图（Stock and Flow Diagram，SFD）**——系统动力学的「定量母语」。<span class="marginnote">存量流量图的思想源头是水库与管道：水（物质/信息）在管道里流动，蓄水池积攒水量。这一类比直接来自流体力学，让「积分」「导数」有了肉眼可见的几何。</span>这一节我们先把存量与流量这对概念钉死，再学 SFD 的制图规范，最后用 Vensim / Stella 走出第一次完整的建模流程。

## 1 存量与流量：一对不可混淆的概念

**存量（stock，又称 level）**：在某一时刻点可以被「数得清、看得见」的量——水库里的水量、仓库里的库存、人口数量、账户余额。**流量（flow，又称 rate）**：单位时间内进出存量的速率——注水速率、进货速率、出生率、存款利率。<span class="marginnote">记忆口诀：存量是「某时刻有多少」，流量是「单位时间变化多少」。数学上存量是时间的函数 $S(t)$，流量是它的导数 $dS/dt$——一个是量，一个是速率，物理量纲完全不同。</span>

为什么这组区分如此关键？因为存量**决定系统的记忆与惯性**：存量不会瞬间跳变，只能通过流量缓慢累积。物价可以一夜暴涨（存量跳变？不——物价本身不是存量；但人口、库存、水位一定是存量，它们**不可能**跳变）。<span class="marginnote">「存量不能跳变」是一条物理铁律，也是理解系统惯性的钥匙：为什么政策总是「慢半拍」？因为政策的效应要经过存量的累积才能显现，而累积需要时间。</span>反过来说，存量也是系统**对扰动的缓冲**——水库蓄水让下游河流不至于骤涨骤落，正是存量的缓冲功能。

**辨析｜易错点：** 初学者常把「库存」与「销量」混为一谈。库存是存量（时刻量），销量是流量（速率）。「库存减少」是流量为负，不是库存「变小了却还是存量」——一个名词是存量还是流量，取决于它描述的是「时刻的状态」还是「单位时间的变化」，与词义无关。

把高频对象归归类，一眼看清存量与流量：

| 领域 | 存量 | 流量 |
| --- | --- | --- |
| 水库 | 蓄水量 | 注水 / 放水 |
| 仓库 | 库存量 | 进货 / 出货 |
| 人口 | 人口数 | 出生 / 死亡 |
| 银行 | 账户余额 | 存入 / 取出 |
| 疫情 | 现存感染者 | 新增感染 / 康复 |
| 员工 | 在职人数 | 招聘 / 离职 |

这个清单的价值在建立「条件反射」：看到一个词，先问它是存量还是流量。判别对了，SFD 就画对了一半。

## 2 存量流量图的语法

SFD 的制图规范比 CLD 严格，因为每一部分都要能对应到方程。四种基本元件：

**存量**：画成矩形（水箱），如「库存」「人口」。**流量**：画成箭头上的「阀」符号，如「进货」「出生」。**信息弧（information link）**：用细箭头连接，表示「决策依据」，不消耗物质。**源与汇（source/sink）**：用云朵表示系统边界外的无限供给或吸收处，如「外部市场」。<span class="marginnote">云朵不是「没有」，而是「边界之外我们不去建模的部分」——它是建模者自觉划定边界的形式化表达，对应第一篇讲的「边界」概念。</span>

一个最小模型包含一个存量、一条流入、一条流出：

$$
\text{库存}(t) = \text{库存}(0) + \int_0^t \left[\text{进货}(s) - \text{出货}(s)\right]\,ds
$$

读作：库存等于初始库存加上「进货减出货」从 0 到 t 的累积。**流量作用于存量，存量反馈给流量**——进货速率可能取决于库存（库存低 → 多进货），这就闭合了一条平衡回路。信息弧正是用来画这种「存量影响流量」的反馈。

## 3 Vensim / Stella 建模流程

工具不是重点，流程才是。用 Vensim 或 Stella 建一个模型的完整流程有五步。

**第一步，明确问题**：写下「我要解释什么行为」。模型为问题服务，不为现实服务——「我要模拟城市人口」不如「我要解释 2010 年后人口增速为何放缓」聚焦。**第二步，画 SFD**：把存量、流量、信息弧按语法画出来，每个流量都要写清楚它由哪些变量决定。**第三步，写方程**：给每个流量指定数学形式，例如「出生 = 人口 × 出生率」。**第四步，赋参数与初值**：填上初始库存、各常数。**第五步，模拟与检验**：跑出行为曲线，与历史数据对照，再回头修改结构。<span class="marginnote">这条「问题 → 结构 → 方程 → 参数 → 检验」的流程，是系统动力学的标准方法论，也是第七篇《模型检验与真实性验证》的预告：模型的价值不在「像不像现实」，而在「能否解释并改善行为」。</span>

以「温水浴缸」为例走一遍：存量是水温，流入是加热器功率（受「水温 − 目标」驱动），流出是散热（受「水温 − 室温」驱动）。两条流量把水温拉向两个目标，模拟结果是一条收敛曲线——一个简单的平衡回路模型就建成了。

关于工具，Vensim 与 Stella 各有所长：Vensim 的方程语言更贴近教材、自带丰富的检验工具（第七篇会用到）；Stella 的图形拖拽更直观、在教育与系统图沟通上更顺手。两者共享同一套 SFD 语义，**学会其一，另一个半天就能上手**——这印证了本节的核心立场：建模能力在结构思维，不在软件按键。另外两点工程经验：模型文件里第一件事是统一**时间单位与模拟步长**（月/年/周要写进方程）；每个变量**必须写单位**，Vensim 会用它做量纲检查——这是最便宜的查错手段。

## 4 公式解析：流量如何决定存量

在 SFD 里，一切动态最终归结为一条方程：**存量是流量的积分**。写完整形式：

$$
S(t) = S_0 + \int_{t_0}^{t} \left( \text{inflow}(\tau) - \text{outflow}(\tau) \right) d\tau
$$

- **第一步，认识每个符号**：$S(t)$ 是 t 时刻存量，$S_0$ 是初始存量，$\text{inflow}$ 与 $\text{outflow}$ 是两条流量，积分下限 $t_0$ 是起始时刻。
- **第二步，理解积分**：积分号 $\int$ 表示「把每一瞬间的净流入加总」。即使 inflow 与 outflow 都在剧烈波动，存量也只记得它们的**累积差**——这解释了系统的记忆。
- **第三步，离散化**：计算机不会做连续积分，它用时间步长 $\Delta t$ 近似：$S(t+\Delta t) = S(t) + (\text{inflow} - \text{outflow})\cdot\Delta t$。**这就是 Vensim / Stella 内部真正在做的运算**：一步一步向前推。<span class="marginnote">数值积分在数学上是第二级《数值分析》的内容，但这里只需记住直觉：仿真器用足够小的步长把积分「切成薄片」逐片累加，步长越小越精确、代价是更慢。</span>

这一条方程同时是理解系统惯性的钥匙：**因为存量只能被流量缓慢改变，任何直接作用于存量的政策（如「把库存清零」）若不改变流量，只是暂时扰动，系统会弹回原状**——这就是为什么许多治标政策短期有效、长期失效。

## 5 建模实践中的四个坑

SFD 建模是手艺活，初学者的坑集中在四处。

**流量单位错配**：把「每年」与「每月」混在一起，积分结果直接爆炸。建模第一步必须统一时间单位。**漏掉信息弧**：只画了物质流、忘了「决策依赖什么信息」，模型就变成开环，无法产生反馈。**存量当流量用**：例如把「员工数」写成「员工 = 招聘 + 离职」——正确写法是「员工」是存量，「招聘」「离职」是流量。<span class="marginnote">一个快速的自我检查：如果一个量在某一时刻「跳变」而物理上不可能，那它多半不是存量——例如「销售额」每月可以骤变，但「累计销售额」只能缓慢增长，前者是流量，后者是存量。</span>**四舍五入不当**：Vensim 里参数若设成整数而流量是小数，长期模拟会累积漂移，务必用浮点数。

把这四个坑记住，你的第一个模型就不会在第一天就发散。更系统的检验方法，我们在第七篇展开。

还有一个心态问题值得提前说破：**模型刚建好的那一刻，最像「真的」，也最危险**。新手看到一条漂亮的模拟曲线，很容易产生「我掌握了现实」的错觉。系统动力学的纪律是：曲线越漂亮，越要追问「它凭什么可信」——参数从哪来？边界划对了吗？换个初始值它还成立吗？这种「对模型的怀疑」不是自信不足，而是专业素养。第七章的整套检验方法，就是把这句怀疑变成一套可执行的程序。

给本节收一个可带走的口诀：**「存量是水池，流量是管道，信息弧是仪表，云朵是『我们不管的地方』」**。把这四句话背熟，SFD 的画法与读法就都握在手心——它是后面所有模型（库存、人口、供应链、World3）共同的地基。

## 6 从 CLD 到 SFD：翻译对照表

CLD 与 SFD 描述同一套系统，语法却不同。把两者对照翻译，是系统动力学建模的基本功：

| CLD 元素 | 对应 SFD 元素 | 翻译要点 |
| --- | --- | --- |
| 变量（名词） | 存量或流量 | 量「值」的用矩形，量「速率」的用阀 |
| 因果链 A → B | 信息弧或物质流 | 物质流动用双线，信息传递用细线 |
| 平衡回路 B | 一个存量 + 两条反向流量 | 目标值写进流量的方程 |
| 增强回路 R | 存量把自身放进流量方程 | 如「存量 × 增长率」 |
| 延迟 ∥ | 在途存量（pipeline） | 延迟 = 一个隐形的中间存量 |
| 目标变量 | 流量方程里的常数 | 如「期望库存 $S^*$」 |
| 云朵（源/汇） | 系统边界外的供给/吸收 | 不建模的部分，画云 |

翻译时最容易犯的错：把 CLD 的「变量」一股脑全画成存量。判别标准只有一条——**这个量是否在某时刻「有值」且只能被流量改变**。是 → 存量；否 → 流量、常数或辅助变量。

给本节再补一个「建模入门者最值钱」的习惯：**每次跑完模拟，都把「结果曲线 + 对应方程」截图存档**。模型迭代几十次后，你会发现自己早已忘记「上一版为什么会振荡」——存档让每一次修改都有据可查，也让「试错」真正变成「学习」。这套「结构—方程—行为」三件套的归档习惯，是系统动力学建模区别于「写代码调参数」的专业门槛，也是第七篇「可复现性」纪律的雏形。

**动手练习（把 SFD 画进肌肉记忆）**：

- 把「超市库存」画成 SFD：识别存量、流量、信息弧与源/汇。
- 给「人口」画 SFD，并写出出生、死亡两条流量的方程雏形。
- 打开 Vensim 或 Stella，把浴缸模型从头搭一遍，观察收敛曲线。
- 故意把一条流量的单位写错，运行模型，看量纲检查如何报错。
- 用「存量不能跳变」的检验，判断「价格」「销售额」里谁是存量。

## 7 小结

- **存量**是时刻量（水位、库存、人口），**流量**是速率（注水、进货、出生）；存量不能跳变，只能被流量累积改变。
- SFD 四元件：**存量（矩形）、流量（阀）、信息弧（细线）、源/汇（云朵）**。
- 核心方程：$S(t) = S_0 + \int_{t_0}^t (\text{inflow} - \text{outflow})\,d\tau$
