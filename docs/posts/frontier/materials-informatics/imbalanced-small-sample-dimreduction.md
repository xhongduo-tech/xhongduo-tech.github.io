## 为什么从数据不均衡与小样本开始

材料信息学有一个与「大数据」时代格格不入的处境：**样本通常很少，正样本尤其稀少**。做超导、热电、催化剂筛选时，「好材料」在候选空间里可能是十万分之一——这就是**类不均衡（class imbalance）**；而带实验标签的高质量样本常常只有几十到几百条——这就是**小样本（small sample）**。

想想第 1 章：材料「基因组」是开放无穷的空间，而高质量标签是稀缺的。数据库里的 DFT 数据数以万计，但**实验验证过的**性质数据往往只有数百条。<span class="marginnote">因此材料建模的核心矛盾，从来不是「数据太多」，而是「标签太少、信号太稀」。这一章教的不是「炫技的算法」，而是「在数据拮据时怎么活下来」——这不只是材料的问题，凡是昂贵标注的科学领域（药筛、气候、临床）都有同样的处境。</span>

「小样本」在材料里有多普遍？以实验带隙数据为例，经过清洗、去重、对齐之后，公开可用的带标签样本通常只有几百到几千条——而成分-结构空间的候选是百万量级的。这个数量级差距意味着：**材料 ML 的主要矛盾，是把几百条真值样本的每一分信息都榨干**，而不是像图像识别那样靠海量数据堆规模。这也是为什么本专题对 GPR、主动学习、迁移学习这些「数据节俭」的方法格外重视。

这一节讲三件应对它的工具：处理不均衡的重采样、把「少」变成「可以学」的降维、以及评估时不均衡-aware 的指标。

## 1 类不均衡：当「好材料」是万里挑一

二分类场景（如「是否超导」「是否拓扑绝缘体」）里，正样本可能只占 0.1%。此时朴素地最大化准确率会得到一个「永远猜负类」的废模型——准确率 99.9% 却毫无用处。三条主流的应对路线：

**重采样（resampling）**：把数据分布掰正。**欠采样**删除多数类样本、**过采样**复制少数类样本，两者都改变分布，各有信息损失/过拟合的风险。更现代的是 **SMOTE**：在少数类样本的 $k$ 近邻连线之间**插值合成新样本**，而不是简单复制——合成样本更「像真的」。
**代价敏感学习（cost-sensitive learning）**：给少数类样本更高的误分代价。实现上等价于在损失函数里加权，如给正样本权重 $w_+ = \frac{N}{2N_+}$（$N$ 为总样本数）。不需要动数据分布，且保持信息完整。
- **异常检测视角**：当正样本极少（<1%）时，干脆把问题翻转成**异常检测**——用多数类数据训练「正常模型」，把偏离者判为异常（如 one-class SVM、孤立森林）。

<span class="marginnote">把「找稀有新材料」建模成异常检测有个额外好处：不再需要人工标注的正样本，多数类（已知平凡材料）的负数据多得是。这个方法在药筛（化合物活性）里已经成熟，材料领域正快速跟进。它把「找宝」的困境，转化成「找离群」的富矿。</span>

具体到实现，异常检测视角在材料里常用 **one-class SVM**：只拿「已知平凡材料」的描述符训练一个「正常区域」边界，候选落在边界外即判为「异常」（潜在新超导/新拓扑体）。它的参数（核、$\nu$）决定边界松紧，$\nu$ 越小越严格、检出越少但更精。<span class="marginnote">one-class 方法对「正样本完全没标签」的场景尤其好用——你甚至不需要标注「哪些是超导」，只需要大量「已知不是」的平凡材料。这在实验标签稀缺时是巨大的优势。</span>

### 辨析｜易错点：重采样不是免费的

SMOTE 合成样本「像真的」，但**合成不等于实测**——模型可能对合成样本的模式过度自信。材料领域尤其危险：合成样本之间插值，可能跨越真实的相边界，生成「物理上不存在」的中间体。代价敏感加权（不改数据分布）通常比 SMOTE 更稳，是材料场景的推荐优先项。

## 2 小样本：先降维，再建模

样本少而特征多（145 维 Magpie × 300 个样本）时，模型会过拟合——学到的「规律」是噪音的巧合。**降维（dimensionality reduction）**把小样本问题变成「用更少的自由度去拟合」。

最经典的是**主成分分析（PCA）**。给定数据矩阵 $\mathbf{X}$（$n$ 个样本 × $p$ 个特征，已中心化），PCA 寻找一组正交方向，使数据投影后方差最大。数学上归结为协方差矩阵的特征分解：

$$\mathbf{C} = \frac{1}{n}\,\mathbf{X}^\top\mathbf{X}, \qquad \mathbf{C}\,\mathbf{v}_k = \lambda_k\,\mathbf{v}_k$$

### 公式解析：PCA 的特征方程

- **第一步，协方差矩阵 $\mathbf{C}$**：$p\times p$ 矩阵，$\mathbf{C}_{ij}$ 刻画特征 $i$ 与 $j$ 的线性共变程度。中心化保证了 $\mathbf{C}$ 的统计意义。
- **第二步，特征方程 $\mathbf{C}\mathbf{v}_k = \lambda_k \mathbf{v}_k$**：第 $k$ 个主成分方向是 $\mathbf{v}_k$，其方差是 $\lambda_k$。$\lambda$ 按从大到小排序，**前几个主成分就捕获了数据的大部分方差**。
- **第三步，降维投影**：取前 $K$ 个主成分，把每个样本投影到 $\mathbf{v}_1,\dots,\mathbf{v}_K$ 张成的子空间，得到 $K$ 维新特征。材料特征高度相关（电负性、电离能彼此相关），$K$ 常常远小于 $p$ 就能解释 90% 以上方差。

PCA 是**线性**降维，适合特征相关性强的结构化数据。当材料数据结构复杂（如多种结构类型的混合数据），非线性方法更能揭示流形——**t-SNE 与 UMAP** 把高维点嵌入二维/三维，擅长**可视化**聚类结构，但注意它们不保留全局距离，不能当作严谨的距离度量用于建模。<span class="marginnote">PCA 与 t-SNE/UMAP 的分工要分清：PCA 是「可逆的压缩」，常用于建模前的降噪；t-SNE/UMAP 是「为了看」的嵌入，常用于探索性分析——材料组分空间里哪些体系聚成一族、哪里是未开发的空白，一张 UMAP 图往往比十张散点图更直观。</span>

在材料探索里，UMAP 最经典的用法是把 145 维 Magpie 特征压到二维，每个点是一种候选材料、颜色标记其结构族——一张图上，你立刻能看到「哪些体系拥挤（已被充分研究）、哪些区域稀疏（尚未开发的成分空白）」。这份「空白地图」直接指导下一轮候选生成，是降维超越「建模前处理」、直接参与发现决策的体现。

## 3 评估指标：在不均衡里说实话

不均衡数据下，准确率是骗人的。四个指标必须分清：

| 指标 | 定义 | 在不均衡下的表现 |
| --- | --- | --- |
| 准确率 | $\frac{TP+TN}{N}$ | 被多数类支配，虚高 |
| 精确率 Precision | $\frac{TP}{TP+FP}$ | 查出的「好材料」里有几个是真的——**审阅成本** |
| 召回率 Recall | $\frac{TP}{TP+FN}$ | 真「好材料」被找回几个——**漏网成本** |
| F1 | 精确率与召回率的调和平均 | 两者折中，比准确率诚实得多 |

在「筛材料」场景里，精确率与召回率的权衡尤其微妙：精确率低意味着**浪费实验机时**去验证假阳性；召回率低意味着**错过真正的新材料**。材料筛选一般偏好**高召回 + 可接受精确率**（宁多验几个，也别漏掉真材）。

对排序类评估，**PR 曲线（精确率-召回率）比 ROC 曲线更合适**：ROC 的横轴是假阳性率，被海量负样本稀释；PR 曲线直接展示「筛出来的候选里好材料占比」，更贴近材料筛选者的真实问题。

一个具体的数值对比：正样本 50 条、负样本 5000 条时，一个把所有负样本都判对的模型，ROC-AUC 可能高达 0.98，因为 ROC 的分母（假阳性率）被 5000 条负样本稀释；但它的 PR-AUC 可能只有 0.1，因为查出的候选里几乎没有真材。**ROC 看着很美、PR 一照原形**——这正是材料筛选必须看 PR 的原因。<span class="marginnote">一句话记牢：负样本极多时看 PR 曲线、不用 ROC；比较模型时看 PR-AUC 而不是 ROC-AUC。这是医学影像与异常检测界早已确立、材料筛选还常犯的错误。</span>

### 辨析｜易错点：F1 也要看应用场景

F1 把精确率与召回率等权平均，但对「筛材料」而言两者并不等权——漏掉一个新材料（召回率低）的代价，通常远高于多验一个假阳性（精确率低）。更贴合的折中是 F2（召回率权重更高）或直接给两个指标定约束。指标的选择应该跟着「失败代价」走，而不是机械取 F1。

### 案例：超导材料的罕见正样本

超导材料是类不均衡的教科书案例：候选空间里超导体的比例约在 0.1% 量级，且超导转变温度（$T_c$）跨越几个量级。数据驱动的工作常分两步走：

1. **分类筛选**：先训练一个「是否超导」的二分类器（正样本极稀），用 SMOTE + 代价敏感加权缓解不均衡；
2. **回归预测**：在筛出的超导候选里，训练「成分-结构 → $T_c$」的回归模型，预测临界温度高低。

两阶段共用同一批描述符，但目标不同、评估指标也不同——分类阶段看 PR-AUC，回归阶段看 $T_c$ 的 RMSE。<span class="marginnote">这两步的衔接有个微妙点：分类阶段的假阳性（不是超导却判成超导）会作为「真超导」进入回归训练集，污染 $T_c$ 模型。工程对策是给回归阶段加一层质量门槛——只保留分类置信度高的样本。</span>

## 4 把三件工具组合起来：小样本建模的完整姿势

数据不均衡、小样本、高维，三个问题常同时出现，孤立处理都不够。一套成熟的组合姿势：

1. **降维先行**：用 PCA 把 145 维 Magpie 压到能解释 90% 方差的十几维，先降低「维度诅咒」；
2. **重采样/加权**：对分类任务做 SMOTE 或代价敏感加权，让少数类不再被淹没；
3. **强正则化建模**：在小样本上选「数据节俭」的模型——GPR、带正则的核方法、强正则的浅层网络；
4. **评估不均衡-aware 指标**：PR-AUC、F2、类别加权误差，而不是准确率；
5. **主动学习接力**：样本太少时，用模型的不确定性引导补样（见第 4 篇贝叶斯优化）。

这条链路的哲学是：**小样本问题的解法不是「找一个更聪明的模型」，而是「把每一分信息榨干」**——降维去掉噪音、重采样平衡信号、正则防过拟合、不确定性驱动补样。

### 辨析｜易错点：降维不是「越多越好」

降维目标不是「压到越低越好」，而是「在保留信息的前提下压到够用」。压过头会丢掉区分超导/非超导的微妙成分特征；压不够则维度诅咒依旧。经验：用「累计解释方差 ≥ 90%」或「PCA 后交叉验证不再明显变差」来定 $K$，比拍脑袋定维度可靠。

### 一个工作流实例：热电材料的小样本筛选

热电优值 $ZT$ 的实验数据稀少，典型工作流：

1. 用 DFT 高通量数据（几万条）预训练性质模型，作为「便宜标签」的表示来源；
2. 在少量实验 $ZT$ 数据上用迁移/微调校准（呼应《迁移学习》）；
3. 用 PCA 压缩成分特征，缓解「样本少、特征多」；
4. 用 GPR 给出 $ZT$ 预测与不确定性，主动采样补算实验。

每一步都在应对「少」：DFT 预训练补结构多样性、迁移校准补真值、降维防过拟合、主动学习省实验。**单靠任何一步都不够，组合起来才是小样本材料的生存之道**。

## 5 小结

- **核心矛盾**：材料数据「标签太少、信号太稀」——好材料可能是十万分之一，实验标签只有几百条。
- **类不均衡三路线**：重采样（SMOTE 插值）、代价敏感加权、异常检测翻转；正样本 <1% 时翻转成异常检测最省事。
- **降维两兄弟**：PCA（线性、可逆、建模前降噪）与 t-SNE/UMAP（非线性、可视化用，不保全局距离）。
- **评估要诚实**：不均衡数据用 PR-AUC 而非 ROC-AUC；精确率是审阅成本、召回率是漏网成本。
- **组合姿势**：降维 + 重采样 + 强正则 + 不均衡指标 + 主动学习，五步把每一分信息榨干。
- **辨析提醒**：SMOTE 合成样本可能跨相边界造出「物理不存在」的中间体；降维不是越低越好。
- **两阶段案例**：超导「先分类筛 + 再回归预测 $T_c$」，回归阶段要过滤分类假阳性。

在下一节，我们终于进入机器学习本体——用监督学习把「描述符 → 性质」的映射学出来，这就是**监督学习基础与材料性质回归**。
