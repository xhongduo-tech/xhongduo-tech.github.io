## 为什么从人工神经网络开始

前面两节用的都是**手工设计特征 + 浅层模型**：描述符是人设计的，模型只负责在描述符上回归。**人工神经网络（artificial neural network，ANN）**换了一个更野的承诺：**特征和预测一起学**。

对材料信息学，这有一个直接后果：不再需要绞尽脑汁设计「完美的描述符」。只要给网络足够原始、足够信息的输入（比如直接给晶体结构图或成分向量），网络能在训练中自动发现合适的内部表示。<span class="marginnote">当然，「自动学表示」也意味着可解释性下降、数据需求上升——这盘棋怎么下，正是本章要权衡的。材料领域最常见的权衡路线是「浅层 MLP + 描述符」：既保留手工特征的可解释性，又享受网络的非线性拟合能力。</span>

这一节从最朴素的多层感知机讲起，拆开反向传播的数学，再讲让深度模型在小样本材料数据上「活下来」的实战纪律。

## 1 多层感知机：从神经元到前向传播

**神经元（neuron）**是基本计算单元：对输入加权求和、加偏置、再过非线性激活：

$$h = \sigma\left(\mathbf{w}^\top \mathbf{x} + b\right)$$

把很多神经元分层堆叠，前一层的输出作为后一层的输入，就得到**多层感知机（MLP）**。以一层隐藏层为例，第 $l$ 层的输出是：

$$\mathbf{h}^{(l)} = \sigma\left(\mathbf{W}^{(l)}\mathbf{h}^{(l-1)} + \mathbf{b}^{(l)}\right)$$

### 公式解析：前向传播

- **第一步，仿射变换 $\mathbf{W}^{(l)}\mathbf{h}^{(l-1)} + \mathbf{b}^{(l)}$**：权重矩阵 $\mathbf{W}$ 把上一层的 $d_{l-1}$ 维特征线性组合成 $d_l$ 维，偏置 $\mathbf{b}$ 提供平移。这是全部「信息混合」发生的地方。
- **第二步，激活函数 $\sigma(\cdot)$**：非线性。没有它，多层线性变换合并起来还是线性——网络就退化成一个线性模型。现代标配是 **ReLU** $\sigma(z)=\max(0,z)$：计算简单、梯度不消失；$\sigma$ 也可选 tanh 或 sigmoid，视任务而定。
- **第三步，逐层堆叠**：每一层学到的 $\mathbf{h}^{(l)}$ 是越来越抽象的内部表示——低层像「元素统计」，高层像「结构模式」，最后一层直接接输出（回归任务通常是线性输出）。

<span class="marginnote">激活函数是网络的「语义开关」：ReLU 让网络天然保持稀疏——很多神经元的输出恰为 0，等价于网络学会了「这些输入直接忽略」。这种隐式稀疏性，与材料的局域性直觉（某些成分对某性质无关紧要）出奇地合拍。</span>

一个具体的材料例子：输入是 Magpie 的 145 维描述符，第一层隐藏层的某个神经元可能学会「电负性差异大的二元化合物」这个组合模式——它的权重对电负性相关特征为正、对其他为负。这样的「特征探测器」在深层网络里层层组合，最后形成「带隙大小」的判断。这正是「表示学习」在材料上的字面含义：**网络自己长出了「物理组合特征」**，而不是等人去设计。

### 辨析｜易错点：网络「深」不等于「好」

层数越深，能表达的函数越复杂，但训练难度与过拟合风险同步上升。材料小数据（几百到几千条）下，**1—3 层的浅层 MLP 常常优于深网络**——深网络的数据需求是浅层的十倍以上。先浅后深、用验证集决定深度，是材料 MLP 的纪律。

## 2 反向传播：梯度怎么算出来

网络有几十万权重，怎么调整？答案是**梯度下降**：沿损失对权重的梯度反方向更新。误差对每层权重的梯度由**反向传播（backpropagation）**高效算出——它是链式法则的工程化。

损失（如均方误差）$L = \frac{1}{n}\sum_i (y_i - \hat{y}_i)^2$，权重更新规则：

$$\mathbf{W}^{(l)} \leftarrow \mathbf{W}^{(l)} - \eta \,\frac{\partial L}{\partial \mathbf{W}^{(l)}}$$

### 公式解析：梯度下降更新

- **第一步，学习率 $\eta$**：每步迈多远。$\eta$ 过大发散、过小龟速，是深度学习中仅次于架构的调参旋钮。
- **第二步，梯度 $\frac{\partial L}{\partial \mathbf{W}^{(l)}}$**：损失对第 $l$ 层权重的偏导。反向传播从输出层倒着算：先算最后一层的误差，再逐层往回传，每层只用上一层的误差与本地导数——这正是「反向」二字的来历，总成本与一次前向相当。
- **第三步，批量与优化器**：实际更新常用**小批量（mini-batch）随机梯度下降**（每批几十个样本算一次平均梯度），配合 **Adam** 等自适应优化器——Adam 自动调每个参数的学习率，在材料小数据上几乎是默认选择。

<span class="marginnote">误差反向传播的意义再强调一次：<strong>网络不再需要人告诉它「哪个特征重要」——梯度自动告诉每个权重该怎么调</strong>。这就是「特征学习」的数学机制：网络每层都在学「从原始输入到目标性质的最佳中间表示」。</span>

## 3 过拟合的四个刹车：让深度模型在小数据上活下来

深度模型参数多，材料数据动辄几百条，过拟合是头号杀手。四个「刹车」缺一不可：

**Dropout**：训练时随机「关掉」一部分神经元（输出置 0）。每个小批量都在用不同的稀疏子网络训练，等效于集成了指数多个网络，测试时全部打开。
**权重衰减（weight decay / L2 正则）**：在损失上加 $\lambda\sum \|\mathbf{W}\|^2$，惩罚大权重，与 Ridge 同源。
- **早停（early stopping）**：每轮训练后在验证集上测误差，**验证误差开始回升就停止**。材料数据小，早停几乎总是最优的「正则器」。
- **数据增强（data augmentation）**：材料特有的增强是「对称性增强」——同一个晶体结构，做所有等价的空间群对称操作，产生多个等价的训练样本。

<span class="marginnote">对称性增强是材料深度学习的「免费午餐」：$P4/mmm$ 空间群的对称操作能从一个结构变出 8 个等价结构，训练集凭空放大一个数量级，且不引入任何人为偏差。这在图神经网络（下一节）里尤其常用，因为图的对称性与晶体空间群天然匹配。</span>

### 辨析｜易错点：早停不是「偷懒」，是正则

有人觉得早停「没把模型训完」，其实它是最廉价的正则器：验证误差曲线的最低点，恰是「刚好学到规律、还没记住噪音」的时刻。配合「先训到过拟合、再回退到最低点」的操作，早停能精确地卡在偏差-方差平衡点上。

## 4 深度 vs 浅层：什么时候值得

深度学习在材料里不是万能钥匙。一张决策表：

| 场景 | 推荐 |
| --- | --- |
| 样本 < 500，特征已设计好（Magpie） | 随机森林 / GPR，别上深度模型 |
| 样本 1k–10k，手工描述符 | MLP 浅层（1—3 层）可与 RF 竞争 |
| 样本 > 10k，或输入是原始结构/图 | 深度模型（CGCNN 等）显优势 |
| 需要不确定性做主动学习 | GPR（深度模型的不确定性另说） |

核心权衡：**深度模型的资本是数据，材料模型的资本是物理先验**。<span class="marginnote">当数据不足以撑起「自动学表示」，把手动描述符 + 正则化浅层 + 交叉验证的组合用好，往往胜过硬上大模型。材料学界常见的「深度迷信」——一上来就搭几十层网络——在小数据上几乎总是翻车。先用 RF 建基线，再决定值不值得上深度，是永远不会错的开局。</span>

## 5 案例：用浅层 MLP 预测聚合物玻璃化转变温度

一个典型的材料 MLP 应用：预测聚合物的玻璃化转变温度（$T_g$），数据约 3000 条。流程：

1. **特征**：聚合物结构片段描述符（类似分子的指纹）；
2. **架构**：3 层隐藏层（256-128-64）+ ReLU + dropout(0.2)；
3. **训练**：Adam + 早停（验证集 $T_g$ 的 MAE 停止下降时停）；
4. **评估**：分组 CV（按聚合物家族分组）报 RMSE；
5. **对比**：与随机森林基线对比——若 MLP 未显著胜出，就用 RF 的结论。

第 5 步是最重要的一步：**深度模型必须用「能否击败强基线」来证明自己值得**，而不是因为「看起来更高级」就被采用。

## 6 小结

- **MLP** = 神经元加权求和 + 非线性激活逐层堆叠；前向传播 $h^{(l)}=\sigma(\mathbf{W}^{(l)}\mathbf{h}^{(l-1)}+\mathbf{b}^{(l)})$ 让每一层自动学越来越抽象的内部表示。
- **反向传播**用链式法则高效算梯度，配合小批量 SGD + Adam 完成「特征学习」——不再需要人设计特征。
- **过拟合四刹车**：dropout、权重衰减、早停、对称性数据增强；早停对材料小数据尤其有效。
- **深度 vs 浅层**看数据量：小样本用 RF/GPR，中样本用浅层 MLP，大样本或原始结构输入才值得上深度模型。
- **材料特有的杠杆**是物理先验（对称性增强、约束），数据不足时用物理补。
- **辨析提醒**：深 ≠ 好，先浅后深；深度模型必须击败强基线才值得用。
- **案例**：聚合物 $T_g$
