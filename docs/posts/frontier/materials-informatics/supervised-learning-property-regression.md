## 为什么从监督学习开始

前面六节铺好了数据侧的一切：描述符、预处理、小样本应对。现在进入机器学习本体。**监督学习（supervised learning）**的任务最直白：给定一组「输入—输出」样本 $\{(\mathbf{x}_i, y_i)\}$，学一个函数 $f(\mathbf{x})$ 逼近 $y$。

材料信息学里，输入 $\mathbf{x}$ 是描述符（成分统计或结构指纹），输出 $y$ 是某个性质——形成能、带隙、弹性模量、熔点。**性质预测几乎都是回归问题**；「是否超导」这类才是分类。<span class="marginnote">本专题第 3 篇整篇都在做回归，这篇的线性模型是它们共同的起点。把回归学扎实，后面的 GPR、随机森林、神经网络本质上都是「回归」这个动作的变体。</span>

这一节用「形成能预测」当主线，讲清监督学习的完整骨架：目标函数、正则化、评估与交叉验证，以及最容易被材料学者忽略的偏差-方差权衡。

## 1 线性回归：从最小二乘开始

材料性质与特征之间，先假设是线性关系：

$$y = \mathbf{w}^\top\mathbf{x} + b = \sum_{j=1}^{p} w_j x_j + b$$

目标是找到权重 $\mathbf{w}$ 与偏置 $b$，使预测与真实值的平方误差和最小——这就是**最小二乘（least squares）**：

$$\hat{\mathbf{w}} = \arg\min_{\mathbf{w}} \sum_{i=1}^{n}\left(y_i - \mathbf{w}^\top\mathbf{x}_i - b\right)^2$$

### 公式解析：最小二乘

- **第一步，逐样本误差 $y_i - \mathbf{w}^\top\mathbf{x}_i - b$**：第 $i$ 个样本的预测残差，正负都可能。
- **第二步，平方求和**：平方让正负误差都算、放大大的残差（对离群点敏感），求和把所有样本的偏离汇总成标量损失。
- **第三步，对 $\mathbf{w}$ 求最小**：最小二乘有闭式解 $\hat{\mathbf{w}} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y}$，一步算完，不需要迭代——这是线性模型最大的工程优势。

线性模型的意义不仅是「简单可用」，更是**可解释**：权重 $w_j$ 直接告诉你「特征 $j$ 每变一单位，性质平均变多少」。<span class="marginnote">材料学家能从回归系数里读出物理——比如「平均电负性每升 0.1，形成能下降 X eV」。这是黑箱模型给不了的东西，也是为什么线性模型在材料领域从不退场：它既是基线，也是「可解释性」的黄金标准。</span>

## 2 过拟合与正则化：当 $p > n$

材料数据常出现特征数 $p$ 大于样本数 $n$ 的极端情况。此时 $\mathbf{X}^\top\mathbf{X}$ 不可逆，最小二乘无解或解出巨大的权重——模型把训练集的每个点都「记住」，对新材料外推却一塌糊涂。解法是**正则化（regularization）**：给损失加上对权重规模的惩罚。

最常用的两种：

$$\text{Ridge: } \min_{\mathbf{w}}\sum_i\left(y_i-\mathbf{w}^\top\mathbf{x}_i-b\right)^2 + \lambda\sum_j w_j^2 \qquad \text{Lasso: } \min_{\mathbf{w}}\sum_i\left(y_i-\mathbf{w}^\top\mathbf{x}_i-b\right)^2 + \lambda\sum_j |w_j|$$

- **Ridge（L2）**：惩罚权重平方，让权重**整体变小但不归零**，适合特征间相关性强的场景。
- **Lasso（L1）**：惩罚权重绝对值，会把不重要的特征权重**压到精确为 0**——自带特征选择（呼应《特征工程》一章）。

<span class="marginnote">正则化系数 $\lambda$ 控制惩罚强度：$\lambda \to 0$ 回到最小二乘，$\lambda \to \infty$ 所有权重归零。$\lambda$ 怎么选？交给交叉验证——把候选 $\lambda$ 逐个在验证集上试，选误差最小的那个。这背后正是「用数据选超参数」的通用思想，后面每一章都会遇到。</span>

材料信息学里 Lasso 特别受欢迎：它把 145 维描述符自动筛到十来个，同时给出一个可解释的线性公式——「性质 = 系数 × 几个物理量的线性组合」，这在工程上常被当作经验公式使用。

在实际操作中，特征间高度相关时 Lasso 的选择会「抖动」——两个相关特征可能被随机二选一。**弹性网（Elastic Net）**把 L1 与 L2 罚线性组合，既做选择又稳权重，是材料场景的稳妥升级：$\lambda_1\sum_j |w_j| + \lambda_2\sum_j w_j^2$。当你的 Magpie 特征里存在成组相关的元素属性（如电负性与电离能强相关）时，优先考虑弹性网。

### 辨析｜易错点：正则化 ≠ 特征选择

Ridge 也会「压小」不相关特征的权重，但**不会压到 0**——它做的是「收缩」，不是「选择」。只有 Lasso 因为 L1 罚的几何形状（尖角在坐标轴上），才真正把某些权重置 0。如果你的目标是要「选出一小撮特征」，用 Lasso；如果只是「防止过拟合」，Ridge 往往更稳。

## 3 评估与交叉验证：分数要经得起检验

模型建好，怎么知道它好不好？不能看训练集误差——那几乎必然虚低。正确的评估框架分两层。

**评价指标**：回归常用三个。**RMSE**（均方根误差）$\sqrt{\frac{1}{n}\sum(y_i-\hat{y}_i)^2}$，与性质同量纲、对大误差敏感；**MAE**（平均绝对误差）$\frac{1}{n}\sum|y_i-\hat{y}_i|$，更稳健；**$R^2$**（决定系数）衡量模型解释的方差比例，越接近 1 越好。

<span class="marginnote">材料论文里 RMSE 常配「每原子 eV」或「GPa」单位，$R^2$ 则常被误用——注意 $R^2$ 在测试集上可以取负值（模型比「猜均值」还差），看到负 $R^2$ 说明模型根本没有泛化能力。这三个指标要一起看：RMSE 告诉你「平均错多少」，MAE 告诉你「稳健的错多少」，$R^2$ 告诉你「解释了多少方差」。</span>

**交叉验证（cross-validation）**：把数据划成 $k$ 折，轮流用 $k-1$ 折训练、1 折验证，把 $k$ 次的验证误差平均。$k$ 通常取 5 或 10。材料数据小，**留一法（LOO，$k=n$）**也常用，但注意结合第 5 节的教训——要用**按成分分组**的划分，否则同族的「亲戚样本」会让验证分数虚高。

### 交叉验证的两条铁律

铁律一：**划分必须先于一切预处理**（标准化、特征选择都在训练折内做）；
铁律二：**分组划分优先于随机划分**——材料样本按成分聚类，随机划分的高分是幻觉。

## 4 偏差-方差权衡：模型「偏」还是「抖」

所有监督学习都要在两种病之间找平衡：

- **欠拟合（偏差大）**：模型太简单，连训练集的规律都学不完整，训练误差与验证误差都高。
- **过拟合（方差大）**：模型太复杂，把训练集的噪音也背了下来，训练误差极低、验证误差高。

**偏差（bias）**衡量模型对真实规律的逼近能力，**方差（variance）**衡量模型对训练集变化的敏感程度。两者此消彼长：线性模型偏差大、方差小；深度模型偏差小、方差大；正则化系数 $\lambda$、特征选择、交叉验证，本质上都是在调这个天平。<span class="marginnote">用「学习曲线」诊断最直观：横轴是训练集大小，纵轴是误差。训练误差与验证误差都高且几乎重合 → 欠拟合；训练误差低、验证误差高、两条线张开 → 过拟合。材料数据从几百条开始扩样时，曲线形状会明确告诉你「加数据」还是「加复杂度」哪个有用。</span>

### 辨析｜易错点：误差「低」不等于「可外推」

材料学者最需要警惕的，是「在训练域内误差很低、出了训练域就崩」的模型。回归模型只保证在训练数据覆盖的空间里有意义——训练集里没有含氟化合物，模型对含氟体系的预测就是「外推」，误差毫无保证。判断外推风险的方法：看预测点的特征是否落在训练集的凸包附近。

## 5 案例：一次形成能回归的完整流程

把本章工具串成一个完整案例——预测 500 个二元氧化物的形成能：

1. **数据**：从 Materials Project 拉 500 条形成能记录；
2. **特征**：Magpie 145 维成分描述符；
3. **预处理**：训练集内 z-score，Lasso 筛出 12 个核心特征；
4. **划分**：按成分分组 5 折 CV；
5. **建模**：岭回归与 Lasso 各跑一遍，比较 RMSE 与 $R^2$；
6. **诊断**：画学习曲线，确认是「数据不够」还是「模型太弱」；
7. **解读**：把 Lasso 留下的非零系数特征做成「物理规律表」——例如「电负性差异是形成能第一驱动因素」。

这 7 步几乎就是本专题所有性质预测的模板——后续每一篇（带隙、弹性、吸附能）只是换了目标 $y$ 与描述符，骨架完全相同。

## 6 小结

- **监督回归** = 从「描述符 → 性质」样本中学函数 $f(\mathbf{x})$；最小二乘是起点，有闭式解且可解释。
- **$p > n$ 时必须正则化**：Ridge 收缩权重、Lasso 同时做特征选择；$\lambda$ 用交叉验证选定。
- **评估要诚实**：RMSE/MAE/$R^2$
