## 为什么从图神经网络开始

描述符路线要人工设计特征，深度 MLP 路线要手工铺平结构——两者都把晶体的**拓扑信息**（谁和谁相连、以什么键长相连）打散了。**图神经网络（graph neural network，GNN）**让模型直接在「原子图」上工作：把晶体表示为节点（原子）与边（化学键）构成的图，用**消息传递（message passing）**在图上逐层聚合邻居信息。

2018 年，Xie 与 Grossman 提出的 **CGCNN（Crystal Graph Convolutional Neural Network）**是材料领域 GNN 的里程碑：仅用晶体结构做输入，就在形成能、带隙、弹性模量等多项性质上超过了精心设计描述符的模型。<span class="marginnote">从此「端到端 + 图表示」成为材料深度学习的标准范式。CGCNN 的意义不止于性能——它示范了「结构信息应该以什么形式进入模型」：不是铺平成向量，而是保留原子间的连接关系。</span>

这一节讲清楚三件事：晶体图怎么建、消息传递怎么算、以及 GNN 凭什么能天然满足《描述符》一章的三大不变量。

## 1 晶体图：把周期结构变成一张有限图

晶体的核心困难是**周期性**——原子在三个方向无限重复。图表示的处理办法是**截断到有限邻域**：

**节点**：每个原子是一个节点，特征取该元素的物理属性（原子序数、电负性、共价半径、价电子数等）。
**边**：对每个原子，按**周期距离**找它的 $k$ 个最近邻居，两点间连边，边的特征编码键长（并可加键角等几何量）。

<span class="marginnote">「找邻居要按周期距离」是材料 GNN 最容易踩的坑：如果只算原始晶胞内的距离，边界原子会丢失与自己镜像原子的连接，同一结构旋转或平移后图的拓扑就变了。正确实现是用「周期内最近镜像」距离（minimum image convention），这也是 `pymatgen` 的 `CrystalGraph` 默认做的事。</span>

于是，一个含 $N$ 个原子的原胞就变成了一张有 $N$ 个节点、每个节点最多 $k$ 条边的有限图。**同一种材料无论怎么平移、旋转、换原胞起点，得到的图都同构**——这为下面的不变量打好了地基。

节点特征还有一个细节：元素属性是「专家设计」的，但 GNN 通常把每个元素映射成**可学习的嵌入向量**——元素 $\ce{Fe}$ 不再用固定的电负性数值，而是用一个由数据训练出来的向量表示。嵌入向量让网络自动发现元素之间的相似关系（如 $\ce{Fe}$ 与 $\ce{Co}$ 在嵌入空间里靠近），与第 4 节成分嵌入的思路一致。

### 辨析｜易错点：截断半径 vs 最近邻居数

「按 $k$ 个最近邻居连边」与「按半径 $R_c$ 连边」是两种常见构图法。$k$ 固定保证每个节点度一致（计算均匀），$R_c$ 固定保证几何意义一致（物理截断）。两者各有取舍：$k$ 太小漏掉长键相互作用，$R_c$ 太小在稀疏结构里会孤立原子。CGCNN 默认用 $k=12$ 附近，实践中应做敏感性测试。

## 2 消息传递：邻居怎么「聊」出特征

GNN 的每一层，都让每个节点聚合邻居的信息并更新自己的表示。CGCNN 的更新规则可概括为：

$$\mathbf{h}_i^{(t+1)} = \sigma\left(\mathbf{h}_i^{(t)} + \sum_{j \in \mathcal{N}(i)} \mathbf{W}\left[\mathbf{h}_j^{(t)} \oplus \mathbf{e}_{ij}\right]\right)$$

### 公式解析：消息传递更新

- **第一步，邻居集合 $\mathcal{N}(i)$**：第 $i$ 个原子的邻居。$\oplus$ 是拼接（concatenation）——把邻居表示 $\mathbf{h}_j$ 与边特征 $\mathbf{e}_{ij}$（键长编码）拼成一个更长向量。
- **第二步，线性变换 $\mathbf{W}[\cdot]$**：把「邻居是谁 + 你们之间键多长」这个拼接向量映射成一条「消息」。这是可学习的，等价于「学会每种邻居组合对当前原子意味着什么」。
- **第三步，求和聚合 $\sum_{j\in\mathcal{N}(i)}$**：把第 $i$ 个原子收到的所有消息加起来。**求和（以及最大、均值）是排列不变的**——邻居顺序打乱，结果不变，这从构造上满足了排列不变量。
- **第四步，残差连接 + 激活 $\sigma\left(\mathbf{h}_i^{(t)} + \cdots\right)$**：保留自身旧表示再叠加上邻居消息，让信息在层间平稳流动，也帮助深层训练。

<span class="marginnote">每多一层消息传递，节点就多「看」一层邻域：一层看最近邻居，两层看次近邻居……类比人类：第一层看「这个原子周围是谁」，第二层看「这个原子在什么局域结构里」，第三层看「这个结构在整个骨架里的位置」。层的深度对应感知范围，这正是 GNN 能自动学到「局域→介观→整体」特征的原因。</span>

消息传递重复 $L$ 层后，每个节点带着 $L$ 层邻域信息。最后用**读出（readout）**把整张图的节点表示汇总成晶体级表示：常见的做法是求和/均值池化，更先进的是**注意力池化**（给每个节点一个学习出的权重）。这个图级表示再接到全连接层，输出目标性质。

## 3 GNN 凭什么记住对称性：三种不变量的工程实现

回到《材料描述符》一节的三大不变量，看 GNN 如何逐一满足——这解释了它为什么是「结构表示」的天然选择：

| 不变量 | 问题 | GNN 的解法 |
| --- | --- | --- |
| 平移不变 | 整体平移晶体 | 消息传递只用相对距离（键长、邻居结构），节点坐标只用于构图，不进入特征运算 |
| 旋转不变 | 整体转动晶体 | 图结构与边特征由**距离/键长**决定，旋转不改距离，故图与特征都不变 |
| 排列不变 | 原子标号打乱 | 消息聚合用交换对称的求和；图同构对应相同表示 |

<span class="marginnote">需要说明的是，上述「不变量」针对的是<strong>不携带方向信息的图</strong>。若某性质（如压电极化、光学各向异性）依赖方向，就必须升级成<strong>等变（equivariant）GNN</strong>——节点特征随空间旋转协同变换。材料社区近年流行的 MACE、NequIP 等正是等变模型，能在保留对称性的同时编码方向信息，是机器学习势函数（第 3 篇）的核心组件。</span>

### 辨析｜易错点：图同构 ≠ 数值相同

「同一种材料得到相同的图」是**拓扑层面**的说法。实际输入还包含**数值特征**（键长的具体数值、元素属性值）——同一拓扑下数值特征不同，输出自然不同。GNN 保证的是「对称操作不改结果」（拓扑 + 数值都等价时），而不是「所有同构结构给出相同预测」。这个区别在评估「GNN 是否真的记住了对称性」时很关键。

## 4 GNN 的材料实战：为什么端到端能赢

与描述符方法相比，GNN 的取舍一目了然：

- **优势**：端到端（结构进、性质出），不依赖人设计描述符；天然处理结构信息；训练好的模型**可迁移**到未见过的结构类型；对称性增强数据免费。
- **代价**：需要大量数据（通常 ≥ 万级计算数据才能发挥）；训练慢、调参多；可解释性弱于线性模型。
- **数据匹配**：GNN 的用武之地恰是 **DFT 高通量数据**——几十万条带结构的计算样本，训练 CGCNN 类模型正合适；而实验小样本上，GNN 反而容易过拟合，此时 GPR/RF 更稳。

一条经验法则是：**让表示复杂度与数据量匹配**——结构信息丰富但标签稀缺时，用「结构感知的描述符 + 浅模型」；标签充足（DFT 库）时，才让 GNN 的深度表示放手去学。

### 案例：CGCNN 的典型训练流程

1. 从 Materials Project 拉 5 万条形成能记录（含结构）；
2. 用 `pymatgen` 把每个结构转成晶体图（节点 + 边特征）；
3. 训练 CGCNN：3 层消息传递 + 注意力读出 + Adam + 早停；
4. 按空间群分组划分训练/测试，检验对**新结构类型**的泛化；
5. 与 Magpie+RF 基线对比，确认 GNN 的增益来自结构信息。

### GNN 家族的三种读出方式

读出（readout）把节点表示汇总成图表示，三种主流方案：

- **求和/均值池化**：最朴素，把全部节点表示相加或平均，牺牲了「哪些原子更重要」的信息；
- **注意力读出**：给每个节点学一个权重（如 CGCNN），重要原子对图表示的贡献更大——常带来明显增益；
- **层级池化**：逐层合并节点（如把相邻原子聚成超节点），保留多尺度结构信息，更先进但更重。

选择读出的经验法则：先试注意力读出（性价比最高），需要多尺度信息时再升级层级池化。

### 辨析｜易错点：GNN 的「端到端」不等于「免调参」

端到端省去了手工特征设计，但把调参复杂度转移到了架构上：层数、隐藏维度、读出方式、学习率、dropout……每一项都要调。材料团队上手 GNN 的常见失败模式，不是「模型不好」，而是「超参数没调、数据没分组划分、基线没建」。**先把 RF 基线建好、把分组 CV 流程跑通，再让 GNN 上场**——否则你根本不知道 GNN 到底赢在哪。

## 5 小结

- **晶体图**：原子为节点、周期最近邻为边，节点特征取元素属性、边特征取键长；周期性靠 minimum image convention 处理。
- **消息传递**：每层让节点聚合邻居消息 $h_i^{(t+1)}=\sigma(h_i^{(t)} + \sum_{j\in\mathcal{N}(i)}\mathbf{W}[h_j^{(t)}\oplus e_{ij}])$，层数对应感知邻域半径；读出把图汇总成性质预测。
- **GNN 天然满足三大不变量**：平移/旋转被「只用距离构图」消解，排列被「交换对称聚合」消解；依赖方向的性质需升级为等变模型。
- **CGCNN 范式**：结构进、性质出，端到端学特征，适合 DFT 大数据；实验小样本上不如 GPR/RF 稳。
