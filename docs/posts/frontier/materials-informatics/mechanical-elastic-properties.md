## 为什么从力学与弹性性质开始

稳定性决定了材料「能不能存在」，力学性能决定了它「能不能用」——梁要抗弯、装甲要抗冲击、涂层要抗剥落。**弹性性质**（弹性模量、剪切模量、泊松比）是力学行为的基石，几乎所有结构设计与失效分析都从它们出发。

弹性性质的机器学习预测在工程上有一个直接卖点：**硬度、强度做实验要破坏试样，而弹性常数可以纯算**。<span class="marginnote">一旦把「结构 → 弹性张量」的模型训练好，就能在合成前预判「这块材料硬不硬、脆不脆」，把材料设计从「做出来再测」变成「算完再决定做不做」。这也是为什么弹性预测是「先筛稳定、再挑性能」流水线里，紧跟在稳定性之后的第二个环节。</span>

这一节讲三件事：弹性常数张量怎么定义、从张量到工程模量的「Voigt-Reuss-Hill」平均、以及机器学习预测弹性的方法与注意点。

## 1 弹性常数：胡克定律的张量化

各向异性材料里，应力 $\sigma_{ij}$ 与应变 $\epsilon_{kl}$ 的关系由**弹性刚度张量 $C_{ijkl}$** 给出——广义胡克定律：

$$\sigma_{ij} = \sum_{kl} C_{ijkl}\,\epsilon_{kl}$$

张量 $C$ 有 $3\times3\times3\times3 = 81$ 个分量，但由对称性约简到最多 **21 个独立弹性常数**。晶系对称性越高，独立常数越少：立方晶系只剩 3 个（$C_{11}, C_{12}, C_{44}$），各向同性只剩 2 个（$C_{11}, C_{12}$ 或 $E, \nu$）。<span class="marginnote">对称性在这里是免费的维度削减器：立方晶系的 $C_{11},C_{12},C_{44}$ 三个数就决定了它的全部弹性行为，这也是为什么「用少量弹性常数做描述符/目标」是可行的——数据维度天然不高。DFT 算弹性常数的方法是给晶胞施加小应变、测应力响应，取响应的斜率；高通量库（如 Materials Project 的 elastic 任务）已批量提供这些值。</span>

### 公式解析：广义胡克定律

- **第一步，应力张量 $\sigma_{ij}$**：第 $i$ 面、$j$ 方向的受力分量，9 个分量（对称后 6 个独立）。
- **第二步，应变张量 $\epsilon_{kl}$**：材料在载荷下的变形，同样 9 分量、对称后 6 个独立。
- **第三步，刚度张量 $C_{ijkl}$**：把「怎么应」映射到「怎么受」的桥梁。**$C$ 的分量越大，材料越「硬」**——要产生同样的应变，需要更大的应力。用工程记号（Voigt 记法），6×6 的 $C_{ij}$ 矩阵常被直接用作训练标签。

### 辨析｜易错点：$C_{ij}$ 不是「模量」

弹性刚度张量的分量 $C_{ij}$ 有量纲、有方向，**不等于工程师口中的「弹性模量」**——后者是标量（如杨氏模量 $E$），由张量平均而来。初学者常把 $C_{11}$ 当杨氏模量，其实对单晶，沿晶轴方向的杨氏模量是柔度矩阵的倒数 $1/s_{11}$，并不简单等于 $C_{11}$。训练与评估时，务必分清「张量分量」与「工程标量」。

## 2 工程模量：Voigt-Reuss-Hill 平均

工程师关心的不是张量的 21 个分量，而是几个标量模量。对多晶材料，不同晶粒取向混杂，宏观上近似**各向同性**，需要把单晶的 $C_{ij}$ 平均成三个标量：

$$K = \frac{E}{3(1-2\nu)}, \qquad G = \frac{E}{2(1+\nu)}$$

### 公式解析：模量间的桥

- **第一步，体积模量 $K$**：抵抗体积变化的能力，分母 $1-2\nu$ 让泊松比趋近 0.5（不可压缩材料）时 $K\to\infty$。
- **第二步，剪切模量 $G$**：抵抗形状变化的能力，分母 $2(1+\nu)$。
- **第三步，解耦**：给定 $E$ 与 $\nu$ 就能得 $K,G$——但反过来，$E,\nu$ 从 $C_{ij}$ 得到需要**平均**。

平均的经典方案是 **Voigt-Reuss-Hill（VRH）**：Voigt 假设均匀应变（给出模量上界 $K_V$，对立方系 $K_V=(C_{11}+2C_{12})/3$），Reuss 假设均匀应力（给出下界 $K_R$，用柔度张量的逆），Hill 取两者算术平均：

$$K_H = \frac{K_V + K_R}{2}, \qquad G_H = \frac{G_V + G_R}{2}$$

**$K_H$、$G_H$ 是最常用的多晶模量估计**，再由 $E = \frac{9KG}{3K+G}$ 反推杨氏模量。

弹性各向异性还有一个实用的量化指标：**Zener 各向异性比** $A = 2C_{44}/(C_{11}-C_{12})$，$A=1$ 表示各向同性。$A$ 偏离 1 越远，材料各方向弹性差异越大——对多晶材料，这意味着晶界处应力集中，容易诱发微裂纹。筛选工程材料时，$A$ 常常和模量一样重要：又硬又各向同性，才是理想的受力材料。<span class="marginnote">VRH 平均的两个工程用途：一是<strong>硬度粗判</strong>——经验公式硬度 $\propto G^3/K^2$（Pugh 模量比 $G/K$ 判别材料的延/脆，$G/K > 0.57$ 偏脆），这些「模量 → 工程性质」的经验桥把弹性张量翻译成设计师能用的语言。二是<strong>弹性各向异性</strong>——$C_{11}$ 与 $C_{44}$ 的差异过大说明材料各方向弹性差异大，微观上常与位错运动、裂纹扩展方向有关。</span>

### 辨析｜易错点：VRH 平均是「估计」，不是「定律」

Voigt 与 Reuss 给的是上下界，Hill 取平均是经验折中——真实多晶模量落在两者之间，但具体位置取决于晶粒形貌与织构。对高度各向异性的材料（如层状石墨），上下界可能差出 30% 以上，Hill 平均只是「最不坏的单点估计」。需要精确值时，用取向平均（自洽模型）或直接注明「本报告用 VRH 平均」。

## 3 机器学习预测弹性：方法与陷阱

机器学习预测弹性性质的目标设定有两类：**预测 $C_{ij}$ 张量本身**（信息全，但多输出、需物理约束如对称性）与**预测标量模量**（$K,G,E,\nu$，简洁好用，是大多数筛选任务的最终需求）。

**方法**：描述符路线（成分统计 + 结构描述符 → 随机森林/GPR）与结构路线（晶体图 → CGCNN 类 GNN）都有成熟工作。弹性对**键合与几何细节**极其敏感，纯成分描述符往往不够，结构信息（尤其是键长、配位、空间群）能显著提升精度。

**三个必须警惕的陷阱**：

1. **力学稳定性检验**：物理上，弹性张量必须满足**Born 稳定性判据**（如立方晶系的 $C_{11}-C_{12}>0$、$C_{44}>0$、$C_{11}+2C_{12}>0$）才可能是稳定结构。预测出负弹性常数的样本，要么是数据错误、要么是结构本就不稳定——建模前先过滤。
2. **量纲与尺度**：弹性模量从 GPa 到 TPa 横跨三个量级，训练前做对数变换或标准化；不同数据库的计算方案（应变量、应变幅度）会影响数值，混合来源时按来源处理。
3. **外推边界**：弹性对成分空间高度非线性，模型在训练域外的预测极易失真——筛选时给预测附加不确定性（GPR）或只信任训练域附近的候选。

<span class="marginnote">Born 判据的直觉：$C_{11}-C_{12}>0$ 意味着「剪切这种变形方向」材料有恢复力；不满足时材料在相应形变下自发失稳。把违反 Born 判据的样本剔除或标记，是弹性预测数据清洗的关键一步——数据库里这类「假弹性常数」并不少见。</span>

## 4 应用：从超硬材料到合金设计

弹性预测的典型应用：

**超硬材料筛选**：以 $K,G$（进而硬度经验式）为目标，在含硼、氮、碳的候选空间里批量预测，挑出硬度有望超越现有材料的候选——这是「弹性预测 + 成分空间搜索」结合的最经典案例。
**轻质高强合金**：以模量/密度比为目标，筛选结构轻而刚的体系（航天结构件的核心指标）。
- **柔性器件与储能**：对电池电极材料预测体积模量，评估充放电膨胀——弹性性质与服役可靠性直接挂钩。

<span class="marginnote">弹性预测与热力学筛选通常是<strong>接力关系</strong>：先凸包筛稳定（上一节），再在稳定者里按弹性模量排序——「稳定 + 够硬」两条标准叠加，候选数量从百万级压到个位数，才值得实验合成。这种多目标接力正是第 4 篇《多目标优化》的主题。</span>

### 辨析｜易错点：弹性「高」不等于「硬」

弹性模量衡量的是「弹性变形阶段的刚度」，硬度衡量的是「抵抗局部塑性变形的能力」——两者相关但不同。超硬材料（如金刚石）两者都高，但有些材料模量高、硬度却低（容易位错滑移）。经验式 $\text{硬度} \propto G^3/K^2$ 只是近似桥，筛选时若硬度是目标，最好直接用硬度数据训练，而不是只依赖模量的间接代理。

### 案例：超硬材料虚拟筛选流程

1. 候选生成：含 B/C/N 的三元化合物组合，数万个；
2. 稳定性粗筛：凸包筛选掉不稳定的（上一节的工具）；
3. 弹性预测：GPR/RF 预测 $K$、$G$，由 $G^3/K^2$ 估硬度；
4. 排序：按预测硬度排序，取 Top 20；
5. 复核：DFT 精算弹性张量，验 Born 判据，确认无虚高。

### 弹性数据从哪来

弹性预测的数据源有两个层次：**Materials Project 的 elastic 任务**提供批量计算的 $C_{ij}$（数十万条），适合做 ML 训练集；**实验手册**（如 Landolt-Börnstein 的弹性常数表）提供实测值，适合做校准与验证。两个层次都要注意：计算值来自不同的应变方案与泛函，跨库比较要统一协议；实验值常是单晶方向依赖的，与 VRH 平均的多晶模量要对齐语义。**「数据从哪来、语义是什么」决定弹性模型的可靠性**——这和《材料数据库》一章的教训一脉相承。

## 5 小结

- **弹性张量** $C_{ijkl}$ 是广义胡克定律的桥梁，对称性把 81 个分量压到 ≤21 个（立方系仅 3 个），张量分量本身可作训练标签。
- **工程模量**：体积模量 $K$、剪切模量 $G$、杨氏模量 $E$、泊松比 $\nu$ 由 VRH 平均从单晶常数得到——Voigt 上界 + Reuss 下界 + Hill 平均。
- **经验桥**：$G/K$ 判别延脆、硬度 $\propto G^3/K^2$，把张量翻译成设计语言。
- **三大陷阱**：Born 稳定性判据过滤、量纲/来源处理、外推边界控制。
- **辨析提醒**：$C_{ij}$ 不是模量；VRH 平均是估计不是定律，各向异性强时上下界差很大。
- **应用接力**：稳定筛选 → 弹性排序 → 实验验证，弹性预测是结构材料设计的引擎。
- **案例**：超硬材料 = 凸包粗筛 + 弹性预测 + DFT 复核 + Born 判据。
- **各向异性**：Zener 比 $A=2C_{44}/(C_{11}-C_{12})$，$A=1$ 各向同性；偏离越远应力集中越易诱发微裂纹——又硬又各向同性才是理想受力材料。
- **三大陷阱**：Born 稳定性判据过滤「假弹性常数」、量纲/来源处理（GPa 到 TPa 三个量级）、外推边界控制。
- **辨析提醒**：$C_{ij}$ 不是模量（张量分量 vs 工程标量）；弹性「高」不等于「硬」（模量是弹性变形刚度，硬度是抗塑性变形能力）。
- **应用接力**：稳定筛选 → 弹性排序 → 实验验证；超硬材料 = 凸包粗筛 + 弹性预测 + DFT 复核 + Born 判据。
- **VRH 平均**：Voigt 上界 + Reuss 下界 + Hill 平均给出多晶模量，$E=9KG/(3K+G)$ 反推杨氏模量；各向异性强时上下界差大，注明「用 VRH 平均」。
