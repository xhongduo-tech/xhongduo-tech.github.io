## 为什么从迁移学习开始

材料信息学最大的数据矛盾是：**DFT 计算数据多而偏，实验数据少而准**。第 3 章说过，高通量 DFT 一晚上生成几十万条数据，但实验验证的标签只有几百条。**迁移学习（transfer learning）**是化解这个矛盾的标准武器：先在**源域**（DFT 大数据）上训练一个通用模型，再在**目标域**（实验小数据）上微调。

「迁移」在物理上是常识：研究铁基合金的专家转做镍基合金，会带着铁的成键直觉出发，而不是把自己当白板。<span class="marginnote">深度学习一样——预训练学到的「原子如何成键、结构如何影响性质」的通用表示，正是要迁移到新任务上的资产。这套范式与当代大模型的「预训练-微调」同构（见第二级《深度学习》与第四级《大模型原理》）。</span>

这一节讲清迁移学习怎么做、多任务学习怎么共享表示、以及材料场景里特有的「计算到实验」迁移陷阱。

## 1 迁移学习：预训练 + 微调

迁移学习的标准流程分两步：

1. **预训练（pretraining）**：在大而便宜的源域数据上训练模型。对材料，源域通常是几十万条 DFT 计算数据——形成能、带隙等性质批量算出的「合成标签」。模型在这阶段学到的是**通用的结构-性质表示**：原子怎么排布、哪些结构模式对应哪些能量趋势。
2. **微调（fine-tuning）**：把预训练好的模型参数作为初始值，在目标域（几百条实验数据）上继续训练。微调时可以**全量更新**，也可以**冻结前几层**（只更新输出层附近的参数）。

**关键前提**：源域与目标域的**输入表示必须一致**。预训练用 CGCNN 结构输入，微调时也必须给同样格式的晶体图——好在晶体图表示对 DFT 与实验结构是通用的，这使「计算预训练 → 实验微调」成为可能。<span class="marginnote">微调在材料小数据上几乎总是优于从零训练，原因藏在统计里：模型在预训练时已把「通用结构特征」的权重学好，微调只需调整「从特征到性质」的最后几层——参数量小、需要的样本就少。这相当于<strong>用几十万条 DFT 数据做了一次免费的表示学习</strong>，实验数据只负责校准最后的映射。</span>

冻结多少层？经验法则：从「只冻结输入层」开始，逐层放开，用目标域验证集选最优冻结点。冻结越深，可训练参数量越小、过拟合风险越低，但表达力也越低。材料小数据下「冻结大半 + 只训输出层」常是甜点——它把微调问题退化成「在预训练表示上做线性回归」，几乎不可能过拟合。

### 辨析｜易错点：微调 ≠ 从头训练

「微调」与「从零训练」的区别不只是「用预训练初始化」——微调通常配**更小的学习率**（预训练权重已经接近不错，大步长会把它打乱）、更短的训练轮数、以及可选的特征冻结。直接把预训练模型当随机初始化用大步长训练，等于放弃预训练的全部价值。

## 2 多任务学习：让性质互相「补课」

**多任务学习（multi-task learning）**与迁移学习同源但结构不同：**同时训练多个相关任务，共享底层表示**。材料里天然有一群相关任务——同一批晶体，同时预测形成能、带隙、弹性模量、熔点。联合训练时共享隐藏层、各任务独享输出头，总损失是各任务损失的加权和：

$$\mathcal{L} = \sum_{t=1}^{T} w_t \,\mathcal{L}_t\left(y_t, \hat{y}_t(\mathbf{x};\theta_{\text{shared}},\theta_t)\right)$$

### 公式解析：多任务损失

- **第一步，共享参数 $\theta_{\text{shared}}$ 与任务参数 $\theta_t$**：底层表示由所有任务共用，每个任务只在顶部加自己的输出层。
- **第二步，任务损失 $\mathcal{L}_t$**：第 $t$ 个性质自己的回归损失（如 MSE）。
- **第三步，加权求和**：权重 $w_t$ 平衡各任务的重要性与量纲差异——带隙（eV）和熔点（K）数值差三个量级，直接相加会让大量纲任务霸占梯度，所以各任务损失通常先各自标准化（除以自身基准误差）再加权。
- **第四步，动态权重**：固定 $w_t$ 是最朴素的方案；更稳的是让权重随训练动态变化——例如「不确定性加权」（用各任务的可学习噪声参数自动决定权重）或「梯度归一化」，让难任务不拖累易任务的学习。

多任务学习在材料里的好处很实在：**共享表示让相关任务互相「补课」**——形成能与带隙都依赖「成键强度」，模型学到一个，另一个就少走弯路；当某个任务数据稀缺时，其他任务的梯度仍会带着它前进。这相当于「用大数据任务给弱数据任务做免费的表示学习」。

### 辨析｜易错点：多任务 ≠ 任务越多越好

任务若彼此无关（如带隙与离子电导），共享表示反而互相干扰——这就是「负迁移（negative transfer）」。材料里判断任务是否该共享，看物理上是否同源：形成能/带隙/弹性模量同源于「成键」，适合共享；带隙与扩散势垒（动力学量）就不宜硬塞进同一个共享层。任务冲突时，宁可分开建模。

## 3 迁移学习的三个工程问题

预训练-微调落到材料数据上，有三个必须亲手处理的工程问题：

**问题一：微调时的学习率**。预训练权重已经接近不错，微调若用大步长会把学好的表示打乱。经验：微调学习率取预训练的 1/10 甚至 1/100，配更短的训练轮数。<span class="marginnote">这个「小学习率」的直觉：预训练权重像「一个有经验的老手」，微调只需要小幅调整它的判断，而不是让它重新学一遍。材料小数据下，微调学习率过大几乎必然导致过拟合或灾难性遗忘。</span>

**问题二：该冻结几层**。冻结的层越多，可训练参数越少、过拟合风险越低，但表达力也越低。材料实验数据常只有几百条，此时「冻结大部分 + 只训输出层」退化成「在预训练表示上做线性回归」，几乎不会过拟合——是数据极小时的默认选择。

**问题三：分布漂移（distribution shift）**。预训练用的是 DFT 数据，微调目标是实验数据——两者的「成分-性质」关系有系统偏差（DFT 低估带隙等）。迁移学习能学到「DFT 特征 → 实验性质」的映射，但前提是源域与目标域的**输入空间一致、偏差有规律**。若偏差本身无规律（如不同数据库的协议混乱），迁移也会失效。

### 案例：用 DFT 预训练模型预测实验带隙

一个具体的迁移流程：源域是 Materials Project 的 5 万条 PBE 带隙，目标域是 300 条实验带隙。

1. 用 CGCNN 在 5 万条 DFT 数据上预训练，学「结构 → DFT 带隙」的通用表示；
2. 取预训练权重，替换输出层为「预测实验带隙」的输出头；
3. 用 300 条实验数据微调，学习率取预训练的 1/100，只训练最后两层 + 输出层；
4. 在留出的实验数据上评估，与「从零训练 300 条」的基线对比。

结果通常：微调模型的误差显著低于从零训练——因为模型在预训练阶段已经学会了「什么结构对应什么带隙量级」，300 条实验数据只负责校准「DFT 带隙 → 实验带隙」的偏差。这正是「计算数据提供结构多样性、实验数据校准绝对数值」的分工。

## 4 从计算到实验：材料特有的迁移陷阱

材料场景的迁移有一个其他领域少见的特殊陷阱：**源域（DFT）与目标域（实验）之间隔着「计算与实验的系统差异」**。

陷阱一：**标签语义不同**。DFT 算的是 0 K 静态性质，实验测的是有限温度、含缺陷的真实材料。把「DFT 形成能」当预训练标签、微调到「实验形成能」，等于要模型学会「0 K → 300 K」的温度修正——这需要目标域数据本身覆盖这个修正，否则模型学不到。

陷阱二：**数据分布偏差**。DFT 高通量库偏爱稳定、好算的体系，实验库偏爱有应用价值的体系——两个域的样本分布天然不同。微调时若目标域数据太少，模型可能「忘记」预训练的多样结构，退化成只见过实验域局部。

陷阱三：**评价要分域**。迁移模型的价值在于「把 DFT 域的泛化能力带进实验域」，所以评估必须用**目标域（实验）的测试集**——在 DFT 域上测得好不代表迁移成功。<span class="marginnote">工程上最实用的检查：把微调前后的模型同时在「目标域留出集」上测一遍。微调后目标域误差显著下降，才算真正的正迁移；若只降源域误差，说明模型在「迁回老本行」，没有学会新域。</span>

### 辨析｜易错点：迁移学习 ≠ 万能药

迁移学习不能凭空造数据：目标域若与源域物理完全脱节（如用金属数据预训练、预测高分子玻璃化转变温度），共享的「结构-性质」表示并不存在，迁移毫无增益甚至有害。判断迁移值不值得的先验问题：**源域与目标域是否共享物理规律？**共享则迁，不共享则别迁。

## 5 选型：什么时候用哪个

迁移、多任务、以及「老老实实从零训练」，三条路各有适用场景。一张决策表：

| 场景 | 推荐 | 理由 |
| --- | --- | --- |
| 有大量便宜 DFT 数据 + 少量实验数据 | 迁移学习 | 用 DFT 做免费表示学习，实验校准绝对数值 |
| 多个相关性质都要预测、共享物理 | 多任务学习 | 共享表示让弱数据任务搭强数据任务的便车 |
| 任务不相关、数据充足 | 各自从零训练 | 避免负迁移，各模型各司其职 |
| 目标域数据极少（<100 条） | 冻结大半 + 只训输出层 | 退化成「预训练表示上做线性回归」 |

选型的本质是「信息从哪来」：**从别的任务来用迁移，从别的性质来用多任务，从自己的数据来就从零训练**。材料项目里三者常组合使用——先用多任务共享物理相关的性质，再用迁移把 DFT 域的能力带进实验域。

### 一个组合实例：多任务 + 迁移的带隙工程

真实项目的常见组合：预训练一个 CGCNN 同时预测 DFT 形成能、带隙、体积模量（多任务，共享表示），再用实验带隙微调（迁移）。这条「多任务预训练 + 单任务微调」的路线，比「单任务预训练 + 微调」往往更强——因为多任务预训练让共享表示同时具备「成键」「电子结构」「力学」三类信息，微调时有更丰富的先验可借。这也是当下材料基础模型（foundation model）的思路雏形：先在大而多样的任务上预训练一个通用表示，再快速适配到具体任务。

## 6 小结

- **迁移学习** = 源域预训练 + 目标域微调，把「计算到实验」的结构多样性变成免费的表示学习；微调用更小的学习率、更短的轮数。
- **多任务学习** = 同时训练多个相关任务、共享底层表示，各任务独享输出头；相关任务（同源于成键的性质）共享有效，无关任务会负迁移。
- **多任务损失** $\mathcal{L}=\sum_t w_t \mathcal{L}_t$：加权要平衡量纲与难度，动态权重（不确定性加权）比固定权重更稳。
- **三大工程问题**：学习率（取 1/10—1/100）、冻结策略（数据越少冻结越多）、分布漂移（源域与目标域偏差要有规律）。
- **计算到实验的陷阱**：标签语义不同、数据分布偏差、评价要分域——三条都要在设计流程时前置考虑。
- **辨析提醒**：迁移不是万能药，先问「源域与目标域是否共享物理规律」。
- **选型口诀**：信息从别的任务来用迁移，从别的性质来用多任务，从自己的数据来就从零训练——三者可组合（多任务预训练 + 单任务微调）。
