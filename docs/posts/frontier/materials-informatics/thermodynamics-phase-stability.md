## 为什么从热力学与相稳定性开始

第 3 篇要预测各类材料性质，**热力学稳定性是第一道门槛**——一个化合物若在热力学上不稳定，带隙再漂亮、弹性再理想也白搭，它根本无法稳定合成。

稳定性是「能不能存在」的问题，其他性质是「存在之后好不好」的问题。<span class="marginnote">材料筛选的正确顺序是：先筛稳定的，再在稳定者里挑性能最优的。若顺序颠倒，你可能在为一个永远无法合成的「幽灵材料」设计应用——这正是本专题反复强调「先凸包、后性能」的原因。</span>

上一节第 3 章引入的形成能只是第一块砖；把「稳定/不稳定」变成工程上可操作的判据，需要**凸包（convex hull）**分析。这一节讲：能量上凸包怎么定义稳定性、机器学习如何批量预测稳定相、以及从 0 K 能量到真实温度的鸿沟在哪。

## 1 凸包：稳定相的「最低信封」

考虑二元系 $\ce{A_xB_{1-x}}$。横轴是成分 $x$，纵轴是每原子形成能 $E_f$。把数据库里所有 $\ce{A_xB_{1-x}}$ 化合物的形成能点画上去，**取这些点的下凸包（lower convex hull）**——也就是「兜住所有点」的最低折线：

$$E_{\text{hull}}(\text{化合物}) = E_f(\text{化合物}) - E_{\text{hull}}(\text{该成分})$$

### 公式解析：能量上凸包距离

- **第一步，下凸包曲线 $E_{\text{hull}}(\text{该成分})$**：在同一成分处，凸包给出的最低可能形成能——由最稳定的相邻相线性插值决定。
- **第二步，做差**：化合物自身形成能减去凸包值。这个差叫**分解能（decomposition energy）**，也叫 **energy above hull，$E_{hull}$**。
- **第三步，判据**：**$E_{\text{hull}} = 0$ 的化合物恰在凸包上，是热力学稳定的**；$E_{\text{hull}} > 0$ 的化合物可以分解成凸包上的两相混合物，数值越大越不稳定。

<span class="marginnote">工程经验：$E_{\text{hull}} \lt  25$–$50$ meV/atom 的化合物常被称为「接近稳定」——它们虽然在 0 K 严格意义上会分解，但分解驱动力小，实验上往往能通过动力学手段合成并保持。Materials Project 网站就把 $E_{\text{hull}}$ 作为筛选稳定化合物的核心指标展示。</span>

一个常见误解需要纠正：**$E_{\text{hull}} = 0$ 说的是「0 K 热力学稳定」，不等于「一定能合成」**。合成还要翻越动力学势垒、克服成核困难；反之，$E_{\text{hull}}$ 略大于 0 的材料（亚稳相）恰恰是功能材料的大户——金刚石相对于石墨就是亚稳的，但它是动力学的钻石。

### 辨析｜易错点：凸包是「构型空间的」，不是「成分轴的一维线」

凸包严格说是多维的（每个元素一个轴）。为可视化常投影到二元成分轴上，但真实凸包要考虑所有共存相的组合。二维投影方便理解，**真正判断稳定性要回到完整的高维凸包**——数据库（如 Materials Project 的 Phase Diagram 模块）正是这样算的。只沿单一成分轴看凸包，可能把「在三元相图中不稳定」的化合物误判为稳定。

## 2 机器学习如何批量预测稳定性

对单个成分，算 $E_{\text{hull}}$ 需要知道凸包上所有相邻相的能量，成本不低；要在几十万候选里筛稳定相，就要机器学习出马。两条主流路线：

**路线一：预测形成能，再算凸包**。训练模型预测任意化合物的 $E_f$（输入是描述符或晶体图，见第 2 篇），然后对候选成分空间**穷举生成 + 批量预测**，用预测的形成能重建凸包、计算每个候选的 $E_{\text{hull}}$。<span class="marginnote">这条路线的精度瓶颈是形成能预测的误差——$E_f$ 有 30 meV/atom 的模型误差，$E_{\text{hull}}$ 判据就相应模糊。因此「ML 算出的稳定」必须当作<strong>粗筛</strong>：只把预测稳定且 $E_{\text{hull}}$ 富余量大的候选送入高精度 DFT 复核。</span>

**路线二：直接预测「离凸包多远」**。把「能量上凸包」本身当作学习目标，用数据库里已标注 $E_{\text{hull}}$ 的样本训练回归模型。这绕开了「先预测每个相、再重建凸包」的级联误差，但需要训练数据里天然含凸包信息（Materials Project 等库正好提供）。

两条路线的共同点：**机器学习在这里是「通量放大器」**——它不能替代热力学，但能把热力学筛选从「逐个 DFT」放大到「百万级预筛 + 精选复核」。

## 3 从 0 K 到使用温度：Gibbs 自由能的修正

0 K 的凸包忽略了温度。真实过程发生在有限温度，判断稳定性的量是**吉布斯自由能 $G(T) = H(T) - TS(T)$**，其中 $H$ 是焓、$S$ 是熵。温度修正来自三个来源：

**振动贡献**：原子在平衡位置附近振动，声子（phonon）谱给出振动自由能——对软材料、轻元素体系尤其重要。
**构型熵**：固溶体中原子排列的混合熵，$S_{\text{mix}} = -k_B\sum_i x_i\ln x_i$，在高温使无序相更稳。
- **相变**：某个相在高温可能失稳（如铁从 bcc 转 fcc），凸包在温度轴上会「移动」。

对绝大多数 ML 筛选，处理温度的标准做法是**分层**：0 K 凸包粗筛排除掉明显不稳定的，对进入短名单的候选再算声子（振动自由能）与高温相图——昂贵的温度修正只施加给少数胜出者，成本可控。

既然温度这么重要，为什么材料筛选仍默认从 0 K 凸包出发？一是**成本**——算声子（振动自由能）比算静态能量贵一到两个数量级，不可能对百万候选做；二是**趋势的稳健性**——0 K 形成的相对稳定性排序，在多数体系里与室温排序一致（温度修正量级相近，相对差异不变）。温度复核只改判「势均力敌」的短名单，不改判「明显稳定 vs 明显不稳定」的大局。这个「先粗后精」的分层，是整个稳定性预测工程的核心。<span class="marginnote">一个直觉锚点：振动自由能在室温下通常在几十 meV/原子量级，与 $E_{\text{hull}}$ 的「接近稳定」阈值同量级。也就是说，温度效应能把 0 K 时 $E_{\text{hull}}\sim 30$ meV 的亚稳相「扶正」为稳定相——这正是材料计算里「0 K 判据 + 温度复核」必须两级把关的原因。</span>

### 辨析｜易错点：熵不是「细节」，是稳定性的半边天

初学者常把熵修正当成「锦上添花」，但对高温相（如耐火材料、固态电解质的工作温度），构型熵与振动熵可能彻底翻转相稳定性的结论。判断「要不要算熵」的标准是：**你关心的温度有多高、体系有多软、有多少原子占位**——温度越高、越软、占位越多样，熵越不可忽略。

## 4 应用：从预测到新材料

热力学稳定性预测最著名的应用之一是**发现新型稳定的无机化合物**。典型流程：

1. **候选生成**：用元素替换、晶体结构预测（见第 4 篇生成模型）批量制造候选结构；
2. **ML 粗筛**：预测 $E_f$ 与 $E_{\text{hull}}$，保留「预测稳定且余量足」的少数；
3. **DFT 复核**：对幸存者做高精度 DFT，重算凸包，确认稳定性；
4. **实验验证**：合成并表征。

<span class="marginnote">这个「生成 → 粗筛 → 复核 → 验证」流水线，是材料信息学把「筛选成本」从实验转移到计算的核心机制——计算筛掉 99% 的不稳定候选，实验只碰剩下的 1%。第 4 篇的贝叶斯优化与主动学习，就是把第 3 步到第 4 步的「选谁去复核」做得更聪明的机制。</span>

这条流水线已产出一批里程碑成果：从数据库驱动的高温合金、新型拓扑材料，到 2023 年之后大规模 ML + DFT 全自动发现新化合物的项目。它的共同叙事是——**热力学稳定性是可预测的、可批量筛选的，而机器学习让「批量」的规模从千跳到百万**。

### 案例：在一个二元体系里找新稳定相

对 $\ce{Fe-O}$ 体系，已知稳定相只有少数几种。用机器学习预测的 $E_f$ 重建凸包后，某几个「预测落在凸包上」的候选成分从未被实验合成过——DFT 复核确认它们的确稳定，实验随后合成了其中一种新的铁氧化物相。这类「凸包预测 → 实验证实」的闭环，就是热力学稳定性预测的招牌成果。

### 实操：从数据库「读取」凸包信息

不会自己算凸包也能用——Materials Project 等库的 Phase Diagram 模块直接给出：

- **凸包图**：把某个元素对的稳定相与亚稳相画在下凸包上；
- **$E_{\text{hull}}$ 字段**：每个化合物距凸包的距离，直接可作为筛选标签；
- **分解反应**：给每个亚稳相标注「它会分解成哪两相」。

用这些现成字段做训练的注意点：**$E_{\text{hull}}$ 是「全局量」**——它依赖整个数据库中已知的相，库更新了、$E_{\text{hull}}$ 就变了。所以拿 $E_{\text{hull}}$ 当标签时，要固定数据库版本，并在论文里注明「$E_{\text{hull}}$ 基于 X 版 Materials Project 计算」。

### 稳定性筛选的工程清单

- 先定「稳定线」：$E_{\text{hull}} \lt  25$ meV/atom（可合成）还是 < 5 meV/atom（严格稳定）；
- ML 粗筛时留富余：把阈值放宽 2 倍，给 DFT 复核留余地；
- 复核必须重算凸包，不能复用 ML 的凸包——复核的凸包才是结论。

这份清单把「稳定不稳定」从模糊判断变成可复现的工程流程。

### 与全课程体系的连接

凸包与相稳定性不只是材料信息学的方法，它把多个层级的知识连成一张网：热力学自由能（第一级《化学》与《物理》的相变概念）给出判据的物理来源；线性规划式的凸包构造（第三级《线性代数》与《优化》）给出实现；而「先筛稳定、再挑性能」的分层哲学，正是本专题第 4 篇多目标优化「先把绝对淘汰的剔除，再谈权衡」的同款思路。学稳定性预测，等于同时复习了「自由能最低」这条贯穿物理与化学的第一性原理。

## 5 小结

- **凸包判稳**：$E_{\text{hull}} = E_f - E_{\text{hull 曲线}}$，凸包上的相（$E_{\text{hull}}=0$）热力学稳定；接近稳定（<25–50 meV/atom）工程上可合成。
- **稳定 ≠ 可合成**：亚稳相（金刚石！）常是关键功能材料；动力学决定最终能否得到。
- **ML 的两条路线**：预测形成能再重建凸包，或直接回归 $E_{\text{hull}}$；ML 是通量放大器，稳定候选需 DFT 复核。
- **温度修正**：0 K 凸包 + 声子/构型熵/相变的两级把关；振动自由能与「接近稳定」阈值同量级。
- **流水线范式**：生成 → ML 粗筛 → DFT 复核 → 实验验证，把筛选成本从实验转移到计算。
- **辨析提醒**：凸包是高维的，别只看成分轴投影；熵不是细节，高温高占位必算。
- **案例**：ML 重建凸包 → 发现新稳定相 → 实验证实，是稳定性预测的招牌闭环。
- **实操**：数据库 Phase Diagram 模块直接给凸包图与 $E_{\text{hull}}$ 字段——但 $E_{\text{hull}}$ 是全局量、依赖库版本，取数要固定版本并注明。
- **与后续衔接**：稳定性是「先筛」的第一道门槛——带隙、弹性、吸附能都要在稳定相上谈，否则是在为「幽灵材料」设计应用；凸包复核也是第 4 篇生成模型的标准把关。
