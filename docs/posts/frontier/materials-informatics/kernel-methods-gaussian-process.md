## 为什么从核方法与高斯过程开始

上一节的线性回归假设「性质 = 特征的线性组合」，但真实材料性质几乎都是非线性的——带隙随成分的变化曲线布满拐点，弹性常数与键长呈幂律关系。**核方法（kernel methods）**是第一条非线性之路：不显式构造非线性特征，而是用一个**核函数**隐式地在高维空间里做线性回归。

材料数据通常只有几百到几千个样本，而深度学习需要的数据量大得多——在这样的「小数据 + 中等非线性」区间，核方法常比深度模型更稳、更省。<span class="marginnote">高斯过程回归（GPR）尤其特别：它不只给预测值，还给<strong>不确定性</strong>，这正是第 4 篇主动学习（active learning）依赖的「我不知道哪里该补实验」信号。可以说，GPR 是材料信息学里「预测 + 决策」双肩挑的模型。</span>

先建立一个思想锚点：**核方法的所有力量都来自「相似度」这个单一概念**——RBF 核说「距离近则相似」，SVM 说「分界面附近的点更重要」，GPR 说「相似的点共享函数值」。一旦你习惯了用「相似度」思考，核方法的整个家族就变得非常统一：它们都在回答同一个问题——「新样本跟谁像，就该跟谁取一样的性质」。

这一节讲透两件事：核技巧怎么把线性模型升级成非线性，以及高斯过程如何同时给出「预测 + 置信区间」。

## 1 核技巧：隐式升维

线性模型解决不了 $y = x_1^2 + x_2^3$ 这类问题，但如果我们先把特征映射到高维 $\phi(\mathbf{x}) = (x_1^2, x_2^3, x_1x_2, \dots)$，再在映射后的空间里做线性回归，就能学到非线性。问题在于 $\phi$ 的维度可能爆炸。**核技巧（kernel trick）**绕开了它：

**核函数（kernel）**定义为两个样本映射后的内积，$k(\mathbf{x}, \mathbf{x}') = \langle\phi(\mathbf{x}), \phi(\mathbf{x}')\rangle$。神奇之处在于：许多算法的解只依赖样本内积，而内积可以直接用核函数算——**根本不需要显式写出 $\phi$**。

最常用的**径向基核（RBF / 高斯核）**：

$$k(\mathbf{x}, \mathbf{x}') = \sigma_f^2 \exp\left(-\frac{\|\mathbf{x} - \mathbf{x}'\|^2}{2\ell^2}\right)$$

### 公式解析：RBF 核

- **第一步，距离 $\|\mathbf{x}-\mathbf{x}'\|$**：核的输入是两样本的欧氏距离，距离越近，核值越大。它编码的直觉是：**性质在特征空间里是「光滑」的——相似的描述符对应相似的性质**。
- **第二步，长度尺度 $\ell$（lengthscale）**：控制「多近算近」。$\ell$ 小，核值随距离快速衰减，模型只能看到很局部的相似；$\ell$ 大，影响范围广、函数更平滑。$\ell$ 是核方法最重要的超参数，通常用交叉验证或边际似然优化选出。
- **第三步，幅度 $\sigma_f^2$**：控制函数值整体的波动幅度，决定先验「有多响」。

<span class="marginnote">$\ell$ 有物理解读：它大约是「描述符变化一单位、性质相关性衰减到一半」的特征尺度。拟合出的 $\ell$ 若与某个物理量的自然尺度吻合，常能反推性质背后的主导相互作用——核方法不只是预测工具，也是探针。</span>

核方法家族包括**核岭回归（KRR）**、**支持向量机/回归（SVM/SVR）**。它们都是「核 + 正则化」的组合，区别在损失函数与正则形式。对材料性质预测，KRR 简单可靠，SVR 对离群点更鲁棒，两者都是小样本任务的常青树。

核的选择还有一层「物理先验」的考量：如果你的描述符里既有成分量（电负性）又有几何量（键长），直接用欧氏距离会让不同物理量的尺度混在一起。一个实用技巧是**按物理量分组加权**——给每一类描述符一个独立长度尺度（ARD 核），让数据自动决定「哪个物理量对性质影响多大」。这等价于给不同特征分别调 $\ell$，常常能显著提升精度与可解释性。

## 2 高斯过程：从「一个函数」到「函数的分布」

高斯过程回归（GPR）换了个世界观：**不再学一个函数，而是学所有可能函数的分布**。高斯过程是一个随机过程，任意有限个点上的函数值服从联合高斯分布，由**均值函数 $m(\mathbf{x})$** 与**协方差核 $k(\mathbf{x},\mathbf{x}')$** 完全刻画：

$$f(\mathbf{x}) \sim \mathcal{GP}(m(\mathbf{x}),\, k(\mathbf{x},\mathbf{x}'))$$

观测含噪声 $\epsilon \sim \mathcal{N}(0,\sigma_n^2)$，即 $y = f(\mathbf{x}) + \epsilon$。

### 公式解析：GPR 的预测

给定训练集 $\{(\mathbf{x}_i, y_i)\}_{i=1}^n$，对测试点 $\mathbf{x}_*$ 做预测。令 $\mathbf{K}$ 为训练样本间的核矩阵（$\mathbf{K}_{ij}=k(\mathbf{x}_i,\mathbf{x}_j)$），$\mathbf{k}_*$ 为测试点与训练样本的核向量，$k_{**} = k(\mathbf{x}_*,\mathbf{x}_*)$。预测分布是高斯分布，均值为：

$$\mu_* = \mathbf{k}_*^{\top}\left(\mathbf{K} + \sigma_n^2 \mathbf{I}\right)^{-1}\mathbf{y}$$

方差为：

$$\sigma_*^2 = k_{**} - \mathbf{k}_*^{\top}\left(\mathbf{K} + \sigma_n^2 \mathbf{I}\right)^{-1}\mathbf{k}_*$$

- **第一步，核矩阵 $\mathbf{K} + \sigma_n^2\mathbf{I}$**：编码「训练样本彼此多相似」外加噪声。求逆这一步是 GPR 的主成本，复杂度 $O(n^3)$，所以 GPR 处理几千样本就吃力了。
- **第二步，预测均值 $\mu_*$**：形式与核岭回归一致——预测是训练标签 $\mathbf{y}$ 的**加权和**，权重由测试点与训练点的相似度 $\mathbf{k}_*$ 决定。离测试点越近的训练点，权重越大。
- **第三步，预测方差 $\sigma_*^2$**：第一项 $k_{**}$ 是先验在测试点的方差；第二项是训练数据「见过的程度」。**数据没覆盖到的地方，第二项接近 0，方差回到先验水平；数据稠密的地方，方差被压低到噪声水平**——这就是不确定性估计的直觉来源。

<span class="marginnote">预测方差不只是「误差棒」：它是主动学习的发动机。筛选实验候选时，选「预测最优但方差大」还是「预测一般但方差小」是个策略问题——最大熵、置信上界（UCB）等采集函数（acquisition function）都建立在 $\mu_*,\sigma_*$ 之上，详见《贝叶斯优化与主动学习》。</span>

GPR 的美丽之处是**边际似然可解析**：对超参数（$\ell,\sigma_f,\sigma_n$）的边缘概率可以直接计算并优化——换句话说，**超参数由数据自动确定**，不需要单独交叉验证，这在小数据下尤其珍贵。

边际似然为什么能自动选超参数？直觉：一个「太抖」的模型（$\ell$ 太小）让训练点之间几乎独立，每个点都被当成孤立的异常，整体似然很低；一个「太平」的模型（$\ell$ 太大）则把不同的训练点强压成同一条曲线，拟合残差大，似然也低。**最优的 $\ell$ 恰好落在「既能解释数据、又不至于过拟合」的中间**——边际似然在参数空间里天然惩罚过拟合，这正是它免交叉验证的数学根源。

## 3 核方法在材料中的实践要点

**先标准化，再核化**：RBF 核基于欧氏距离，特征量纲不一致时距离被大尺度特征主导——这是核方法最容易被忽视的前提，务必沿用《特征工程》的 z-score 流程。
**样本量匹配**：核方法靠样本间相似度工作，适合 $10^2$–$10^4$ 样本。上万样本后矩阵求逆变贵，树集成或深度模型更划算。
- **不确定性要验证**：GPR 给的方差是否可信，要检查**校准（calibration）**——比如预测区间是否真的覆盖了约 95% 的实测点。未校准的方差在主动学习里会误导采样。

<span class="marginnote">一个材料领域的典型坑：把 DFT 数据与实验数据混在一起训 GPR，噪声水平 $\sigma_n$ 会被大噪声的实验点抬高，导致模型在干净的 DFT 区域给出过大的方差。解决思路是分来源建模或给不同来源的样本不同噪声，这与《材料数据库》一章「按来源分层」的建议同源。</span>

什么时候别用 GPR？一是数据量大（> 几万条）时 $O(n^3)$ 扛不住；二是标签噪声重尾（实验数据常有离群）时，高斯噪声假设会被个别离群点带偏；三是纯分类问题——GPR 做分类需套一层 sigmoid，不如直接用核 SVM 或树集成。

### 辨析｜易错点：RBF 核 ≠ 万金油

RBF 核假设「相似描述符 → 相似性质」，但这个假设对某些性质不成立：一阶相变附近，微小的成分/结构变化会导致性质突变（如超导临界温度随掺杂的跳变）。此时「光滑性假设」天然失效，RBF 核学不好——可以考虑非平稳核（如学习长度尺度随位置变化）或改用树模型。

## 4 案例：带 GPR 的带隙预测与不确定性驱动补样

一个典型的 GPR 应用：预测氧化物的带隙，数据只有 200 条 DFT 标签。流程是：

1. **训练**：Magpie 描述符 + RBF 核 GPR，边际似然自动选超参数；
2. **评估**：分组 CV 报 RMSE；同时检查预测区间覆盖率；
3. **不确定性驱动的补样**：把预测方差最大的 20 个候选拿去算 DFT，回填训练集；
4. **迭代**：三轮回填后，模型在「没去过」的成分区域明显变准。

第 3 步是 GPR 区别于其他回归的杀手锏——**它告诉你「哪里最值得花钱补数据」**。这正是第 4 篇主动学习循环的核心零件。

但第 3 步的可行性建立在「方差可信」之上：如果 GPR 的方差被系统性低估，补样会集中在已研究区域，白花钱；如果被高估，补样会漫无目的地乱撒。因此启动补样循环前，先做一次**校准测试**：把训练集随机留出 10%，看 GPR 的 95% 区间是否真的罩住了约 95% 的留出点。校准合格，才启动循环。

## 5 小结

- **核技巧**用内积函数 $k(\mathbf{x},\mathbf{x}')$ 隐式升维，让线性模型学到非线性；RBF 核「距离近则相似」的直觉正对应材料性质的光滑性。
- **RBF 核**的关键超参数是长度尺度 $\ell$ 与幅度 $\sigma_f^2$，$\ell$ 常有物理解读。
- **高斯过程回归**学的是函数的分布：预测均值 $\mu_*$ 是训练标签的相似度加权和，预测方差 $\sigma_*^2$ 度量「这块数据我熟不熟」。
- **GPR 自带不确定性**，是主动学习的基础；边际似然可解析优化超参数，小数据下省去额外调参。
- **实践三要点**：先标准化、量力而行（$O(n^3)$）、验证方差校准；混合来源数据要按来源处理噪声。
- **辨析提醒**：RBF 的光滑性假设在一阶相变附近失效，光滑性不是免费的物理前提。
- **案例**：带隙 GPR + 方差驱动补样，是「预测 + 决策」双肩挑的教科书用法。
- **适用范围**：GPR 怕大数据（$O(n^3)$
