## 为什么从输入数据开始

仿真的规矩是「垃圾进，垃圾出」（garbage in, garbage out）。前两篇解决了「随机数怎么造」，这一篇解决「**照着什么分布造**」——这取决于真实系统喂进来的数据。<span class="marginnote">输入分布选错，再精致的引擎、再充分的运行次数，产出的结论也建立在错误的地基上。业界统计过，许多仿真项目「失败」并非算法或代码出错，而是输入建模这一步偷了懒。</span>这一篇把输入建模的完整流程走一遍：收集数据 → 识别分布形态 → 估计参数 → 拟合优度检验。它承接第二级《概率论与数理统计》的极大似然估计与假设检验，也是第一篇五步流程里「收集数据与假设」一步的展开。

## 1 输入建模的四步流程

把原始数据变成仿真输入分布，是四个环节的接力：

1. **收集与整理数据**：从现场或日志采集原始观测，处理缺失值与异常值。
2. **识别分布形态**：用直方图、概率图判断数据「长得像」哪种分布。
3. **估计参数**：用极大似然或矩估计，把分布的参数定下来。
4. **拟合优度检验**：用卡方或 K-S 检验审判「这个分布配不配得上这些数据」。

一步都不能省，且每一步都有坑：数据不足时直方图形状抖动、离群值扭曲参数估计、检验对样本量敏感……下面逐节拆解。

## 2 识别分布形态：先画图，再猜

参数估计之前，先回答「数据大致是什么形状」。三个工具层层递进：

**直方图（histogram）**：把数据分桶，看频率分布的「轮廓」。左偏还是右偏？单峰还是多峰？峰是否在 0 附近截断？轮廓直接指向候选分布族。<span class="marginnote"><strong>右偏</strong>（长尾朝右、多数值靠近 0）常见于服务时长、修理时间，指向指数、对数正态或伽马分布；<strong>左偏</strong>（长尾朝左）常见于完成时间，指向贝塔分布；<strong>对称钟形</strong>指向正态或 t 分布。直方图是分布识别的第一双眼睛。</span>

**概率图（probability plot）**：把数据的分位数画在某种分布的「概率纸上」，若点近似落在一条直线上，就说明数据服从该分布。这是比直方图更敏锐的「验尸工具」——直方图只能猜，概率图能确认或否决。

概率图的坐标轴经过分布特有的**尺度变换**：指数分布用对数纵轴、正态分布用分位数刻度。点落直线上→数据适配该分布；两端翘起→分布族不对（通常是尾部行为不同），比看直方图「胖瘦」可靠得多。

**散点/时序图**：若数据带时间标签，先看是否**独立同分布**。顾客到达间隔若表现出「早高峰密、午间疏」，就不是一个稳定分布能描述的——需要按时段分段建模。

## 3 极大似然估计：把参数交给数据说话

分布族定下来后，参数怎么取？黄金标准是**极大似然估计（MLE）**：在所有可能的参数里，选一个让「这批数据出现的概率」最大的。

设观测样本 $x_1, \dots, x_n$ 独立同分布，密度为 $f(x;\theta)$，则**似然函数**为：

$$
L(\theta) = \prod_{i=1}^{n} f(x_i;\theta)
$$

MLE 就是最大化 $L(\theta)$ 的那个 $\hat\theta$。实践中取对数，把乘积变求和：

$$
\ell(\theta) = \ln L(\theta) = \sum_{i=1}^{n} \ln f(x_i;\theta)
$$

**公式解析：指数分布参数的 MLE**

指数分布 $f(x;\lambda) = \lambda e^{-\lambda x}$ 的对数似然为：

$$
\ell(\lambda) = \sum_{i=1}^{n}\left(\ln\lambda - \lambda x_i\right) = n\ln\lambda - \lambda \sum_{i=1}^{n} x_i
$$

- **第一步，写出对数似然**：把每个样本的 $\ln f(x_i)$ 累加。
- **第二步，求导置零**：对 $\lambda$ 求导得 $\frac{n}{\lambda} - \sum x_i = 0$。
- **第三步，解出参数**：$\hat\lambda = n / \sum x_i = 1/\bar x$——**指数分布的 MLE 就是样本均值的倒数**，直觉是「平均间隔短，则到达率必然高」。

**辨析｜易错点：** MLE 给出的是**点估计**，它本身也是随机变量，有方差。样本量小的时候，$\hat\lambda$ 可能偏离真值很远——所以大样本是 MLE 可靠的前提。矩估计（让样本矩等于理论矩）是更简单的替代，但对尾部分布不如 MLE 有效。

矩估计尤其要注意**重尾陷阱**：若分布连一阶矩都不存在（如某些帕累托分布），矩估计会给出荒谬的参数——这时只能靠 MLE 或分位数法。

## 4 拟合优度检验：审判分布

参数定好了，最后一个问题：这个分布真的「够格」吗？两类检验登场。

**卡方检验（chi-square）**：把数据分桶，比较每桶观测频数与拟合分布的理论频数，统计量沿用前一篇的卡方公式。它灵活，但**分桶方式影响结论**，且需要足够样本保证每桶期望频数不太小。

**K-S 检验（Kolmogorov–Smirnov）**：比较经验分布函数 $F_n(x)$ 与拟合分布 $F(x)$ 的最大偏差 $D = \max_x |F_n(x) - F(x)|$。它不依赖分桶、对中样本更灵敏，是分布拟合检验的首选。<span class="marginnote">用拟合参数再做 K-S 检验时，拒绝域要打折扣（即「显著性水平被抬高」），因为参数本身就来自这批数据——这叫 <strong>Lilliefors 修正</strong>。经验不足者常忽略这点，导致错误地高估拟合质量。</span>

**辨析｜易错点：** 检验「通过」只说「**没有证据拒绝**」，不等于「数据真服从这个分布」。且样本量越大，检验越容易揪出微小偏离——大样本下几乎任何现实分布都会被判「不服从某简单分布」。这时实用主义上场：**分布只要够用即可**，关键性能指标（均值、方差）拟合准了，就可以接受。

## 5 数据不足与经验分布

数据量不够拟合参数时，两条出路：

**经验分布（empirical distribution）**：直接把观测数据本身当分布——每个观测以 $1/n$ 概率被抽样。仿真时就是「洗牌后逐个重放历史数据」。优点：零假设、忠实于数据；缺点：只能覆盖已观测范围，无法外推。

**参数化分布 + 专家判断**：用行业标准值或历史经验给参数，再配灵敏度分析——看结论对参数取值敏不敏感。

经验分布也可以「平滑」：对观测做核密度估计（KDE），得到一个连续的经验密度，再结合逆变换法采样——兼顾「忠于数据」与「连续外推」。<span class="marginnote">仿真里有个被反复验证的规律：<strong>输出性能（如平均队长、等待时间）往往对「输入分布的形状」不敏感，而对「输入分布的均值与变异性」敏感</strong>。所以数据不足时，把均值与方差估准，比纠结「正态还是伽马」更关键。</span>

**辨析｜易错点：** 把「数据里没出现过」当「不可能发生」。经验分布在小样本下会系统性低估尾部事件的概率——服务时长若偶尔出现超长值，用经验分布重放时永远碰不到它，队列积压的极端场景就被漏掉了。

## 6 输入建模清单

给一个可检查的清单，写仿真前逐条过：

| 检查项 | 做法 | 常见失误 |
| --- | --- | --- |
| 独立性 | 画时序图、算自相关 | 忽略早晚高峰的分段差异 |
| 分布形态 | 直方图 + 概率图 | 只看直方图就拍板 |
| 参数估计 | MLE / 矩估计 | 小样本硬拟合 |
| 拟合优度 | K-S（含 Lilliefors 修正） | 忘了参数来自同批数据 |
| 敏感性 | 换参数重跑对比 | 对输入错误零容忍到不切实际 |

清单过完，输入建模就到了收官处。<span class="marginnote">清单的目的不是苛求「分布绝对真实」，而是<strong>让每个建模决定都显式、可复核</strong>。仿真报告里写清「到达间隔取 Exp(0.8/分钟)，依据是 300 条观测的 MLE 与 K-S 检验 p 值 > 0.05」——这份透明度比任何一行代码都重要。</span>

## 7 小结

- 输入建模四步：**收集数据 → 识别形态 → 估计参数 → 拟合检验**。
- 形态识别先画图：**直方图**猜族（右偏→指数/对数正态，钟形→正态），**概率图**确认。
- 参数用**极大似然估计**；指数分布参数的 MLE 是样本均值的倒数 $\hat\lambda = 1/\bar x$。
- 拟合优度用**卡方检验**与 **K-S 检验**审判；拟合参数须配 **Lilliefors 修正**。
- 数据不足时退回**经验分布**，同时记住：输出往往对「均值与方差」敏感、对「分布形状」不敏感。

在下一节，输入数据定了、随机数也齐了，我们把它们组装进第一个完整系统：进入 **排队系统仿真**，把前三篇的工具全部跑起来。
