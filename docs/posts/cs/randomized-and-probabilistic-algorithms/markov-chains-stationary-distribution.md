## 为什么从马尔可夫链开始

随机算法不只是「抛硬币然后执行」，很多算法的随机过程是**有状态的演化**：随机游走在图上游荡、洗牌算法的置换在更新、MCMC 从分布里采样。它们共同的心脏是**马尔可夫链（Markov chain）**——一个「未来只依赖现在、不依赖过去」的随机过程。这一节建立马尔可夫链的基本框架：转移矩阵、状态分布演化、不可约与常返、以及最核心的**平稳分布（stationary distribution）**——链「跑足够久之后稳定下来」的分布。它为下一节的混合时间、随机游走与 MCMC 铺路，也是从「一次性随机」走向「演化随机」的关键一步。

## 1 马尔可夫性质与转移矩阵

**马尔可夫链**：状态空间 $\Omega$ 上的随机过程 $X_0, X_1, X_2, \dots$，满足**马尔可夫性质**：

$$\Pr[X_{t+1} = j \mid X_t = i, X_{t-1}, \dots, X_0] = \Pr[X_{t+1} = j \mid X_t = i]$$

未来只通过**当前状态**与过去藕断丝连。<span class="marginnote">「无记忆性」是马尔可夫链的全部本质：给定现在，未来与过去独立。这不是对现实的近似，而是一种建模选择——它让分析只需一张「转移表」，而这张表编码了系统的一切随机动力学。</span>

**转移概率（transition probability）** $P_{ij} = \Pr[X_{t+1} = j \mid X_t = i]$，全体排成**转移矩阵** $P$（行随机：每行和为 1）。若转移不随时间变，称**齐次（homogeneous）** 链。设 $v_t$ 为 $t$ 时刻的状态分布向量（$v_t(i) = \Pr[X_t = i]$），则分布演化是简单的矩阵乘法：

$$v_{t+1} = v_t \, P, \qquad v_t = v_0\, P^t$$

这是马尔可夫链可分析性的根源：**概率演化 = 线性代数**。<span class="marginnote">于是马尔可夫链理论可以借力特征值、谱分解等线性代数工具——这是「概率 + 代数」的第一次深度联姻，也是后一节混合时间分析（用第二大特征值）的地基。</span>

## 2 平稳分布：链的「不动点」

**平稳分布（stationary distribution）** $\pi$：满足

$$\pi = \pi\, P, \qquad \pi(i) \geq 0, \quad \sum_i \pi(i) = 1$$

即「从这个分布出发，演化一步后还是这个分布」——它是转移算子 $P$（左乘）的特征值 1 对应的特征向量，且是概率分布。<span class="marginnote">平稳分布可以理解为「链跑无限久之后的占位比例」：若链从 $\pi$ 出发，它永远停留在 $\pi$。而链是否从任意初态<strong>收敛</strong>到 $\pi$，是下一节混合时间要回答的问题；本节先讨论「平稳分布何时存在、是否唯一」。</span>

**细致平衡（detailed balance）**：若存在概率分布 $\pi$ 使

$$\pi(i)\,P_{ij} = \pi(j)\,P_{ji}, \qquad \forall i, j$$

则称链对 $\pi$ **可逆（reversible）**，且 $\pi$ 必是平稳分布。细致平衡比 $\pi = \pi P$ 更强：它要求「从 $i$ 到 $j$ 的流」与「从 $j$ 到 $i$ 的流」逐对相等——是「全局不动」的充分条件。<span class="marginnote">细致平衡是构造平稳分布的瑞士军刀：设计转移矩阵时，只要让「每对状态之间的正反向流相等」，平稳分布就自动正确。MCMC 的 Metropolis 算法正是围绕它构建的（见本节后文），这也是为什么它值得单独标记。</span>

## 3 不可约、常返与周期的结构分类

平稳分布的存在唯一性，由链的结构性质决定：

**不可约（irreducible）**：从任何状态出发都能到达任何其他状态（有限步内）。没有「孤岛」。
**常返（recurrent）**：从某状态出发，回来的概率为 1。有限状态链的不可约链自动常返。
- **非周期（aperiodic）**：回到某状态的所有步数集合的最大公约数为 1（无「冻结节拍」）。

**基本定理**：若链**不可约且非周期**，则存在唯一的平稳分布 $\pi$，且从任何初态出发，$v_t \to \pi$（在合适的距离下）。若只不可约（可周期），平稳分布仍唯一但收敛不保证。<span class="marginnote">把这三条串成一句话：不可约保证「处处可达」，非周期保证「没有节拍」，两者齐备则「任意起点都流向唯一平稳分布」。工程上判断一个链「有没有稳态」就查这三条，比算特征值快得多。</span>

**例（无偏随机游走于 $n$-环）**：状态 $0,1,\dots,n-1$，每步 $\pm 1$。链不可约、周期 2（步数奇偶冻结）。平稳分布唯一：$\pi(i) = 1/n$ 处处均匀。细致平衡检查：$\pi(i)P_{i,i+1} = (1/n)(1/2) = \pi(i+1)P_{i+1,i}$，成立。

## 4 公式解析：细致平衡推出平稳性

$$
\pi(i)\,P_{ij} = \pi(j)\,P_{ji}, \; \forall i,j \;\Rightarrow\; \pi = \pi P
$$

- **第一步，写成分量**：$(\pi P)(j) = \sum_i \pi(i)P_{ij}$，即「从任意 $i$ 流入 $j$」的总概率流。
- **第二步，代入细致平衡**：$\pi(i)P_{ij} = \pi(j)P_{ji}$，于是 $(\pi P)(j) = \sum_i \pi(j)P_{ji} = \pi(j)\sum_i P_{ji}$。
- **第三步，行随机性**：$\sum_i P_{ji} = 1$（每行概率和为 1），故 $(\pi P)(j) = \pi(j)$——正是平稳性定义。
- **第四步，为什么要逐对**：细致平衡比「总流入 = 总流出」更强，它要求每对状态间的流平衡。更强的条件是构造时的便利：只要按「对称流」设计 $P$，平稳分布自动正确。

**直觉**：细致平衡是「微观可逆性」——正向流量与反向流量逐对相等，净流量为零。它是物理里「细致平衡原理」的数学形式，在 MCMC 里成了「设计出指定平稳分布」的最实用工具。

## 5 与前面各节的连接

马尔可夫链不是孤岛，它与本专题前面所有工具紧密相连：

- **期望与线性**：$v_{t+1} = v_t P$ 是期望线性在「分布演化」上的体现。
- **集中不等式**：链上遍历量的尾界，由混合时间 + 鞅给出（第 27 节）。
- **随机游走**：图上随机游走是状态空间为顶点的马尔可夫链（第 25 节）。
- **MCMC**：以目标分布为平稳分布构造链，从链的稳态采样（第 26 节）。
- **负载均衡 / 洗牌**：从一次到多次的随机操作，都是链的演化。<span class="marginnote">记住这个位置：马尔可夫链是「随机算法从单步到多步、从静态到动态」的桥梁。前 22 节分析的是「一次性随机性」；从本节起，随机性在时间上展开，分析工具也随之升级为「谱、混合时间、鞅」。</span>

**辨析｜易错点：** 平稳分布**不唯一**的常见原因是没有不可约性：若有多个互不相通的连通块，每个块有各自的局部平稳分布。分析链之前先检查状态空间是否「处处可达」，否则「收敛到 $\pi$」无从谈起。

## 6 转移矩阵的线性代数视角

马尔可夫链的分布演化 $v_{t+1} = v_t P$ 是一个线性动力系统，用特征值看它，能获得一整套「冻结画面」。

**平稳分布是左特征向量**：$\pi = \pi P$ 意味着 $\pi$ 是 $P$ 的特征值 1 对应的**左特征向量**。右特征向量 $\mathbf{1}$（全 1 向量）满足 $P\mathbf{1} = \mathbf{1}$（行随机性），它是「常数函数」——矩阵的谱里，1 永远是一个特征值，且对应左右特征向量恰好就是平稳分布与常数。

**分布演化的谱分解**：若 $P$ 可对角化，$v_0$ 在特征基下展开，$v_t = v_0 P^t$ 的分量按 $\lambda_i^t$ 演化。$\lambda_1 = 1$ 的分量不动（留在 $\pi$），其余分量指数衰减——**第二大特征值 $\lambda_2$ 决定「向 $\pi$ 收敛的速度」**。<span class="marginnote">这个谱视角把「链的收敛」变成「矩阵幂的收敛」：$\lambda_2$ 越接近 1，非稳态分量衰减越慢。它也是下一节混合时间的数学核心——谱隙 $1-\lambda_2$ 直接进入混合时间公式。对可逆链（细致平衡），$P$ 相似于对称矩阵，特征值都是实数且可对角化——这就是「可逆」在代数上的意义。</span>

**周期与谱的关系**：链有周期 $> 1$ 时，$P$ 会有模长为 1 的其他特征值（如二部图的 $-1$），它们对应的分量不衰减——这就是「非周期」保证收敛的谱学解释：只有谱中恰有一个模长 1 的特征值，所有其他特征值的模都严格小于 1，链才会收敛。

## 7 马尔可夫链建模的常见陷阱

把真实问题建成马尔可夫链时，几个经典错误几乎人人会踩：

**错误一：忘了「状态必须含全部决策信息」**。若状态只含部分信息，马尔可夫性质失效。例：赌徒的「追损策略」——本金 + 已亏金额才能决定下一注，若状态只记本金，链就不是马尔可夫的。**补救**：扩大状态空间，把影响未来的全部信息纳入状态。<span class="marginnote">判断一个过程是否马尔可夫的测试：给定现在的状态，未来是否与过去的路径独立？若「从哪里来」还会影响未来分布，状态就漏了信息。这是「状态工程」的核心——状态太粗失忆性，太细算不动。</span>

**错误二：把「平稳分布」当「收敛分布」**。平稳分布是「不动点」，收敛需要额外条件（不可约 + 非周期）。若不连通，链可能困在某个连通块，永远到不了全局平稳分布。

**错误三：混淆「转移概率」与「条件概率方向」**。$P_{ij} = \Pr[X_{t+1} = j | X_t = i]$ 是「从 $i$ 到 $j」的向右转移；贝叶斯公式里的「从后验反推」方向相反。行列记错，整个谱分析全错。

**错误四：连续时间与离散时间混用**。本专题处理离散时间链（$X_0, X_1, \dots$）；连续时间马尔可夫链（如排队论的 M/M/1）有独立的生成元理论，转移矩阵的概念要换成速率矩阵。不要把两套记号混着用。

**数值视角的补充**：实际求平稳分布时，直接解线性方程 $\pi(I - P) = 0$ 往往比「跑很久」更快——对中小规模状态空间，这是首选。只有状态空间极大（$>10^6$）或转移矩阵有特殊结构时，才用「幂迭代」：反复乘 $P$ 让分布收敛到 $\pi$，每次乘是 $O(|\Omega|^2)$ 的矩阵-向量积。幂迭代的价值不在精确，而在于它同时给出收敛轨迹——可以直接观察「混合得够不够快」，与下一节混合时间衔接。

平稳分布是「链条的身份证」，而「收敛到它」是「链条的归宿」——两者缺一不可。本节建立了身份，下一节就回答归宿的速率：要跑多少步才足够接近平稳分布。

## 8 小结

- **马尔可夫性质**：未来只依赖现在；转移矩阵 $P$ 编码全部动力学。
- 分布演化是线性代数：$v_&#123;t+1&#125; = v_t P$。
- **平稳分布** $\pi = \pi P$；**细致平衡**（逐对流量相等）是其充分条件，也是构造利器。
- **不可约 + 非周期** ⇒ 唯一平稳分布且从任意初态收敛。
- 马尔可夫链是「从单步随机到演化随机」的桥梁，连接谱方法、鞅与 MCMC。

在下一节，我们问一个尖锐的问题：平稳分布存在，但链要**跑多久**才「足够接近」它？这就是**马尔可夫链的收敛与混合时间**——用第二大特征值刻画的收敛速率。
