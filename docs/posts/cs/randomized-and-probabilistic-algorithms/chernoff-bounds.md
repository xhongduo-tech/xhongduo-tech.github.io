## 为什么从切尔诺夫界开始

马尔可夫给出 $1/a$ 的尾巴，切比雪夫给出 $1/a^2$ 的尾巴——对随机算法来说这常常不够。当我们需要「失败概率小于 $2^{-100}$」这种保证时（密码学、拉斯维加斯算法的重复运行、负载均衡的最坏箱），必须把尾巴压到**指数衰减**。**切尔诺夫界（Chernoff bound）** 正是为此而生：它针对独立随机变量之和，利用矩母函数把尾巴从多项式提速到指数。它是本专题第一个「真正锋利」的集中不等式，也是后续霍夫丁、掷球入箱、随机图分析的核心引擎。

## 1 切尔诺夫界的两种形式

设 $X_1, \dots, X_n$ 为独立随机变量，$X_i \in \{0,1\}$，$\Pr[X_i = 1] = p_i$，令 $X = \sum_i X_i$，$\mu = \mathbb{E}[X] = \sum_i p_i$。这类 $X$ 称为**泊松试验和（Poisson trials）**。切尔诺夫界给出**乘法形式**的尾界：

$$\Pr\left[X \geq (1 + \delta)\mu\right] \leq \left(\frac{e^{\delta}}{(1+\delta)^{1+\delta}}\right)^{\mu}, \qquad \delta > 0$$

$$\Pr\left[X \leq (1 - \delta)\mu\right] \leq \left(\frac{e^{-\delta}}{(1-\delta)^{1-\delta}}\right)^{\mu}, \qquad 0 \lt  \delta \lt  1$$

左边的界对称性较差，工程上几乎总是用下面的**简化形式**，它牺牲少量精度换来一目了然：

$$\Pr\left[X \geq (1+\delta)\mu\right] \leq e^{-\delta^2 \mu / 3}, \qquad 0 \lt  \delta \leq 1$$

$$\Pr\left[X \leq (1-\delta)\mu\right] \leq e^{-\delta^2 \mu / 2}, \qquad 0 \lt  \delta \leq 1$$

<span class="marginnote">简化形式的记忆锚点：$\delta$ 越接近 1、$\mu$ 越大，指数越小（概率越小）。上界用 $1/3$，下界用 $1/2$，这只是来自泰勒展开的取舍，不必深究常数。</span>

**直觉**：切尔诺夫界说「独立泊松试验的和，以高概率停留在均值附近的一个乘性区间 $((1-\delta)\mu, (1+\delta)\mu)$ 内」，偏离越远概率指数下降。**指数中的 $\delta^2 \mu$** 是整条式子的灵魂：$\mu$ 越大，相对偏差被压得越紧。

## 2 证明的引擎：矩母函数 + 马尔可夫

为什么切尔诺夫界能拿到指数衰减？秘密在于它不像切比雪夫那样只用二阶矩，而是用矩母函数**一次性打包全部矩**。推导分三步：

1. **引入指数**：对任意 $t > 0$，事件 $\{X \geq (1+\delta)\mu\}$ 等价于 $\{e^{tX} \geq e^{t(1+\delta)\mu}\}$。因为 $e^{tx}$ 严格递增，事件不变。
2. **套马尔可夫**：$e^{tX}$ 非负，于是
$$\Pr[X \geq (1+\delta)\mu] = \Pr\left[e^{tX} \geq e^{t(1+\delta)\mu}\right] \leq \frac{\mathbb{E}[e^{tX}]}{e^{t(1+\delta)\mu}}$$
3. **拆独立性**：独立变量的和的 MGF 是 MGF 之积，
$$\mathbb{E}[e^{tX}] = \prod_i \mathbb{E}[e^{tX_i}] = \prod_i \left(p_i e^t + 1 - p_i\right) \leq \prod_i e^{p_i (e^t - 1)} = e^{(e^t - 1)\mu}$$
最后一步用了 $1 + x \leq e^x$。

合并后 $\Pr[X \geq (1+\delta)\mu] \leq e^{(e^t - 1)\mu - t(1+\delta)\mu}$，再对 $t$ 自由取值优化（取 $t = \ln(1+\delta)$），就得到最紧的那条界。<span class="marginnote">「优化 $t$」这一步是切尔诺夫界的点睛之笔：$t$ 越大，马尔可夫那边的阈值越陡，但 $e^{tX_i}$ 的期望也越大——两者对 $t$ 的权衡恰好给出最优指数。</span>

## 3 一个具体例子：判断硬币是否公平

设有一枚未知硬币，抛 $n$ 次，$X$ 为正面的次数。若硬币公平（$\Pr[\text{正}] = 1/2$），则 $\mu = n/2$。我们想验证：$X$ 落在区间 $[n/2 - \epsilon n, n/2 + \epsilon n]$ 之外的概率。

用切尔诺夫下界（$\delta = 2\epsilon$）与上界（$\delta = 2\epsilon$）：

$$\Pr\left[X \leq \tfrac{n}{2} - \epsilon n\right] \leq e^{-(2\epsilon)^2 (n/2)/2} = e^{-\epsilon^2 n}$$

两边合计，偏离区间之外的概率至多 $2e^{-\epsilon^2 n}$。<span class="marginnote">这就是统计里「估计精度随样本量指数改善」的量化：想达到 $2^{-100}$ 的置信度，只需 $\epsilon^2 n \approx 100 \ln 2$，即 $n = O(1/\epsilon^2)$——蒙特卡洛模拟的样本量公式正是从这里来。</span>

## 4 公式解析：简化上界为什么是 $e^{-\delta^2\mu/3}$

把最常用的简化形式从精确形式「推」出来，你会明白 $1/3$ 不是魔法：

$$
\left(\frac{e^{\delta}}{(1+\delta)^{1+\delta}}\right)^{\mu} \;\Rightarrow\; e^{-\delta^2\mu/3} \quad (0 \lt  \delta \leq 1)
$$

- **第一步，取对数**：$\mu\left[\delta - (1+\delta)\ln(1+\delta)\right]$。
- **第二步，泰勒展开**：$\ln(1+\delta) = \delta - \delta^2/2 + \delta^3/3 - \dots$，代入括号内得 $\delta - (1+\delta)(\delta - \delta^2/2 + \delta^3/3 - \dots)$。
- **第三步，化简到二阶**：展开后主导项是 $-\delta^2/2 + \delta^3/6 + \dots$。对 $0 \lt  \delta \leq 1$，这一串的绝对值至少是 $\delta^2/3$，于是
$$\ln(\text{界}) \leq -\mu \cdot \frac{\delta^2}{3} \quad\Rightarrow\quad \text{界} \leq e^{-\delta^2\mu/3}$$
- **第四步，为什么能丢高阶项**：我们只关心上界，把「比 $-\delta^2/2$ 小（更负）」的部分近似成 $-\delta^2/3$ 是一个保守的放缩，方向正确。

**直觉**：精确界是一串无穷级数，简化界是取「前几阶的保守估计」。丢掉的高阶项在 $\delta$ 小时无关紧要，在 $\delta$ 接近 1 时也只会让界略松——用一个小小的常数损失，换来可读性。

## 5 切尔诺夫界的使用清单

在随机算法里套用切尔诺夫界，有一个标准流程：

1. **确认独立**：$X_i$ 必须独立（或至少是负相关），否则 MGF 之积这步失效。若只证「上界」且变量正相关，有时可改用霍夫丁或马尔可夫。
2. **确认取值在 $\{0,1\}$ 或 $[0,1]$**：切尔诺夫的矩母函数估计依赖有界性；推广到 $[0,1]$ 取值的变量同样成立。
3. **选定方向**：要「超过上界」用 $\Pr[X \geq (1+\delta)\mu]$，要「跌破下界」用另一条。
4. **选精确形式还是简化形式**：证明里需要最优常数用精确式，需要可读性用简化式。

**辨析｜易错点：** 把 $\mu$ 当成「最坏情形」而非「期望」。切尔诺夫界衡量的是**相对偏差**：同样的 $\delta$，$\mu$ 越大界越紧。当 $\mu$ 很小时（比如 $\mu = 1$），界几乎不提供信息——此时常先做「缩放/重复」把 $\mu$ 抬高。

## 6 切尔诺夫界的加法形式

乘性形式刻画「相对偏差」，但有时我们更关心**绝对偏差**：$X$ 偏离期望 $\mu$ 达到 $t$ 的概率。把乘性界里的 $\delta$ 换成 $t/\mu$，可以得到加法形式：

$$\Pr\left[|X - \mu| \geq t\right] \leq 2e^{-t^2/(3\mu)}, \qquad 0 \leq t \leq \mu$$

当偏差 $t \le \mu$（不偏离期望太多）时，这个形式最有用；当 $t > \mu$ 时，直接用乘性界（$\delta = t/\mu > 1$）更紧。<span class="marginnote">记忆法：加法形式把「相对偏差 $\delta$」换成「绝对偏差 $t$」，分母从 $\mu$ 变 $3\mu$——本质是 $\delta^2 \mu = t^2/\mu$ 的代换。它与霍夫丁的加法形式 $e^{-2t^2/S^2}$ 形似而神异：切尔诺夫看 $\mu$，霍夫丁看区间宽度平方和，两个分母各有其适用范围。</span>

**泊松逼近**：当 $n$ 很大而 $p$ 很小（$\mu = np$ 为常数），二项分布 $\mathrm{Bin}(n,p)$ 逼近泊松 $\mathrm{Pois}(\mu)$。此时切尔诺夫界的指数与泊松的真实尾巴几乎一致——「稀有事件之和」的集中性由 $\mu$ 单独决定。这是生日碰撞、哈希冲突等「稀疏随机性」场景用切尔诺夫最顺手的理由。

## 7 切尔诺夫界在算法设计中的典型用法

切尔诺夫界不只是一条不等式，它是随机算法「放大 + 高概率保证」的标准生产线。三条高频用法：

**用法一：RP 算法的成功概率放大**。一个 Monte Carlo 算法单次成功概率 $1/2$，独立重复 $k$ 次取「任一次成功」。设 $X$ = 成功次数，$\mu = k/2$，则「全部失败」即 $X = 0$。切尔诺夫下界给出

$$\Pr[X = 0] \le \Pr[X \le \mu/2] \le e^{-\mu/8} = e^{-k/16}$$

重复 $k = 16\ln(1/\delta)$ 次，失败概率压到 $\delta$。<span class="marginnote">这是切尔诺夫界在「放大」上最直接的用法：把常数概率变成指数小。任何「以 $1/2$ 概率成功」的随机算法，都能靠 $O(\log(1/\delta))$ 次重复升级成「以 $1-\delta$ 概率成功」——本专题 Las Vegas/Monte Carlo 一节的放大论证，背后正是这条切尔诺夫下界。</span>

**用法二：负载/数量的高概率上界**。掷球入箱、哈希链长、随机子集大小，都是独立 $\{0,1\}$ 之和，直接用上界形式给「超过期望常数倍」的指数概率。

**用法三：证明「几乎必然」**。配合 Borel-Cantelli 引理：若 $\sum_n \Pr[E_n] \lt  \infty$，则无穷多个 $E_n$ 发生的概率为 0。切尔诺夫给出可求和的上界后，就能把「对每个 $n$ 以高概率成立」升级为「对几乎一切 $n$ 成立」——这是从「概率论证」走向「几乎必然论证」的最后一公里。

## 8 小结

- **切尔诺夫界**对独立 $\{0,1\}$ 变量之和给出**指数衰减**的乘性尾界。
- 上界 $\Pr[X \geq (1+\delta)\mu] \leq e^{-\delta^2\mu/3}$，下界用 $-\delta^2\mu/2$。
- 证明三件套：指数化事件 → 马尔可夫 → 独立性拆 MGF 之积。
- 精确形式可优化 $t$ 得到最紧界，简化形式用 $1/3$、$1/2$ 换可读性。
- 使用前提：独立 + 有界取值；$\mu$ 太小则界失效。
