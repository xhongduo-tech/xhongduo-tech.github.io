## 为什么广播协议长不大

[[cache-coherence-snooping]] 的监听协议靠**总线广播**——每个请求都要通知所有核。核数 $N$ 增长时，每个核的每个请求都产生 $O(N)$ 的流量，总量 $O(N^2)$——**到几十核就爆了**。DSM/NUMA 没有共享总线，广播连「物理载体」都没有。<span class="marginnote">目录协议（[[directory-based-coherence]]）换一种思路：<strong>别广播，先查目录——只通知真正持有该块的核</strong>。这把单次请求的代价从 $O(N)$ 降到 $O(k)$（$k$ 是共享者数）。</span>

## 1 目录：谁持有、什么状态

**核心概念**：**目录（directory）**：一份集中的（或分布式）记录，为每个内存块跟踪「**哪些核缓存了它 + 处于什么状态**」。

目录条目的典型形态：

```
块地址 X 的目录项：
  状态：unowned / shared / modified（基本协议，类似 MSI）
  presence bits：一个位向量，第 i 位 = 核 i 是否有 X 的副本
  若 modified：记录「哪个核是唯一脏持有者（owner）」
```

目录放在**内存的归属节点（home node）**——每个内存块有一个 home，谁访问它都要先找 home。由于内存物理分布（DSM），目录也**分布在各节点**（本地内存的块归本地目录管）。

## 2 读与写的目录流程

**读缺失**（核 0 读 X）：

1. 核 0 向 X 的 **home 节点**发读请求。
2. home 查目录：若无人持有 → 回数据，标记 shared + presence[0]=1。
3. 若某核有 M 态 → home 让该核**写回并提供数据**，核 0 加入 sharer。

**写缺失**（核 0 写 X）：

1. 核 0 向 home 发**写请求（读-独占）**。
2. home 查 presence bits：给**所有持副本的核**发**失效消息**（只发给有副本的）。
3. 各核失效并确认 → home 标记「独占 + owner=核 0」→ 核 0 开始写。

**关键**：失效消息**只发给共享者**，不是全广播——这就是目录省流量的根源。

## 3 三个状态的基础协议

目录协议通常用三态（类似 **MSI**）：**unowned（无人缓存）、shared（多核共享、干净）、modified（唯一脏持有）**。相比监听协议的 MESI，目录版少了 E（独占），因为「是否唯一」由 presence bits 精确知道，不需要用 E 态去猜。<span class="marginnote">目录协议与 MESI 的关系：<strong>目录只是「换掉广播通道」，状态机仍可带 M/E/S/I 或 MOESI 语义</strong>。现代多核 SoC 的 L3 目录往往还是 MOESI 语义的目录实现。</span>

## 4 代价与优化

目录的代价：

- **目录内存开销**：每个块都要 presence bits——位数 = 核数。核越多，目录越大。
- **首跳延迟**：请求要先到 home，多一跳（vs 总线直连）。
- **home 节点热点**：频繁访问的块让 home 成为瓶颈。

常见优化：

- **目录+缓存**：把热门目录项缓存到请求节点附近。
- **有限指针目录**：presence bits 换成「最多放 4 个指针」，超限再广播——省内存。
- **所有者转发**：home 一旦知道 owner，就只把请求转发给 owner，少走弯路的「加速」。

## 5 公式解析：广播 vs 目录的流量

$$
Q_{\text{监听}} = O(N^2), \qquad Q_{\text{目录}} = O(N \cdot k)
$$

（$N$ = 核数，$k$ = 每次请求实际涉及的共享者数，通常 $k \ll N$）

- **第一步，看监听**：每个核的每个一致性请求都要广播给全部 $N$ 个核 → 单次 $O(N)$、全体 $O(N^2)$。
- **第二步，看目录**：单次请求只通知 $k$ 个共享者 → 全体 $O(N \cdot k)$。
- **第三步，理解量级**：$N=256$ 时，监听是 $65536$ 量级、目录若 $k=8$ 只是 $2048$——**差 30 倍**。这就是目录协议能撑到上千核而监听不行的数学原因。

## 6 小结

- **目录协议**记录「谁持有每个块」，请求**点对点**通知共享者，替代广播。
- 目录项 = **状态 + presence bits + owner**，放在块的 home 节点，天然分布。
- 读/写缺失都要先问 home，再定向通知——**流量从 $O(N^2)$ 降到 $O(Nk)$**。
- 代价：目录内存、首跳延迟、home 热点；优化有目录缓存、有限指针、owner 转发。
- 一致性协议家族：**监听适合小规模，目录适合大规模**——现代系统两者按规模分工。
