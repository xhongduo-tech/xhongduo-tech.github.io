## 为什么既要相联又要直接映射

上一节告诉我们：**相联度越高缺失率越低，但命中时间越长**。能不能两者兼得——大相联度的高命中率 + 直接映射的快命中时间？**路预测（way prediction）** 与 **伪相联（pseudo-associative）** 就是两个经典答案。<span class="marginnote">它们的思路与分支预测一脉相承（[[branch-prediction-1bit-2bit]]）：<strong>先猜，猜错了补查</strong>。在缓存命中的高频路径上「赌一把」，把比较从「N 路并行」减到「1 路优先」。</span>

## 1 路预测：先只比一路

**核心概念**：**路预测（way prediction）**：组相联 Cache 在访问时，不是并行比较所有 $N$ 路的标签，而是**先按预测选出一路**，只比较这一路的标签；若命中，代价与直接映射相同；若猜错，再回头比较其余各路——**多付一次「补查」的代价**。

典型实现是 **MRU 预测**：每个 Cache 组记住「上一次命中的是第几路」（Most Recently Used way），下次优先查这一路——因为局部性保证，**同一组被反复访问时，往往都落在同一路**。

以 2 路组相联为例：

```
地址 → 组索引 → 查 MRU 位（记着上次命中哪路）
    → 只比较那一路的标签
        命中 → 走人（1 次比较）
        猜错 → 比较另一路（多花 1 次比较 + 选通）
```

MIPS R10000 就用 MRU 路预测把 4 路 L1 的命中时间压到接近直接映射——**预测正确率通常 90% 以上**，猜错时补查的额外代价远小于「每访问都并行比 4 路」的固定开销。

## 2 伪相联：直接映射也能有「第二路」

**核心概念**：**伪相联（pseudo-associative / column-associative）Cache**：在**直接映射**的框架上，把同一索引的「另一个候选位置」伪装成第二路。

做法：直接映射 Cache 把地址索引成唯一位置；命中判失败时，**把索引的某一位取反**，去查「另一个位置」——相当于把这个集合扩大成 2 路：

```
第一次查询：索引 = A（直接映射位置）
  命中 → 完事
  缺失 → 索引取反 → 查索引 = ¬A 的位置（第二路）
```

这样，**命中时的速度是直接映射**（只有命中那一路参与判断），**缺失时才去查第二路**——而缺失时多付的代价相对较小。<span class="marginnote">伪相联的微妙之处：它把「相联的缺失率收益」放在<strong>缺失路径</strong>上实现，把「直接映射的速度」放在<strong>命中路径</strong>上实现——用「第二路只在缺失时启用」换取两全。代价是第二路的索引规则约束了替换策略，实际收益不如真相联。</span>

## 3 预测正确率与代价的权衡

路预测是否划算，取决于两个数：

- **预测正确率 $p$**：命中时猜对的比例。
- **猜错代价 $\Delta$**：多一次标签比较的额外周期。

平均命中时间 $\approx T_{\text{单路}} + (1-p) \times \Delta$。若 $p = 0.95$、$\Delta = 1$，则平均命中时间 $= T_{\text{单路}} + 0.05$——**几乎白赚直接映射的速度**。若程序「每组乱跳」（$p$ 降到 0.6），平均命中时间变差，路预测失效——这就是为什么路预测适合**工作集稳定的负载**。

**辨析｜易错点：** 路预测**不改变缺失率**，它只优化命中时间。说「路预测降低了缺失率」是错的——它降低的是「命中判断的成本」，缺失率由容量与相联度决定，与预测无关。

## 4 核心对比表

> 本节为纯概念主题，以核心对比表替代公式解析。

| 维度 | 直接映射 | 组相联 | 路预测（组相联） | 伪相联 |
| --- | --- | --- | --- | --- |
| 命中比较 | 1 路 | N 路并行 | 1 路优先，错则补查 | 1 路，错则查反位 |
| 命中时间 | 最快 | 慢 | 近直接映射 | 近直接映射 |
| 缺失率 | 高 | 低 | 低（不变） | 介于之间 |
| 猜错代价 | 无 | 无 | 小（+比较） | 小（+第二路访问） |
| 复杂度 | 低 | 中 | 中（预测位） | 低（取反位） |

## 5 小结

- **路预测**：先猜一路再比较，命中时间接近直接映射、缺失率保持组相联。
- **MRU 预测**：每组记「上次命中路」，正确率通常 90%+。
- **伪相联**：直接映射 + 索引位取反的「第二路」，命中快、缺失时补查。
- 预测正确率决定收益：工作集稳定的负载最划算。
- 路预测只优化**命中时间**，不改变缺失率——别把两者混为一谈。
