## 为什么最底层的存储值得「深入」

存储层次的底部是磁盘/SSD——它们是 Cache 缺失链的终点。但闪存（Flash）远不是「慢一点的磁盘」：它**不能原地改写、寿命有限、读写不对称**，一堆怪癖塑造了整个存储软件栈。而新一代**非易失存储（NVM）**又在把「掉电不丢」和「近内存速度」合流——这是存储层次正在发生的一场重构。<span class="marginnote">闪存与 NVM 决定了 [[server-memory-hierarchy-case]] 里的每一层怎么排、[[raid-ecc-reliability]] 里的可靠性怎么算。理解底层物理，才能理解上层设计。</span>

## 1 NAND 闪存的结构：块、页与擦除

**核心概念**：NAND 闪存的存储单元是**浮栅晶体管**（靠电荷存位）。它的组织与 DRAM 完全不同：

- **页（page）**：读写的最小单位（如 4 KB）。
- **块（block）**：擦除的最小单位（含几十到几百个页，如 1 MB）。
- **只读/只写/擦除分离**：可以读/写一个页，但**改写前必须先擦除整个块**——不能原地覆盖。

所以闪存的「写」其实是「擦除整块 + 写新块」。这个不对称直接催生了 SSD 内部的复杂软件。

## 2 SSD 与 FTL：把怪癖藏起来的软件

**核心概念**：**FTL（Flash Translation Layer，闪存转换层）**是 SSD 控制器里的固件，它把「逻辑块地址」翻译成「闪存物理页 + 版本」，从而对上层**伪装成一块普通磁盘**。

FTL 干的三件大事：

- **映射与写时复制**：写一个逻辑页 → 写到新的物理页，映射表更新；旧页标记失效。**逻辑地址从不「覆盖」物理页**。
- **磨损均衡（wear leveling）**：闪存块有擦写寿命（SLC 约 10 万次，TLC 约千次），FTL 把擦写**均摊**到所有块，避免热点块先死。
- **垃圾回收（garbage collection）**：失效页积累后，把存活页搬走、整块擦除回收。<span class="marginnote">SSD 还有一个隐藏空间：<strong>预留空间（over-provisioning）</strong>——出厂就留一些空白块给垃圾回收用。预留越多，写放大幅度越小、寿命越长。<strong>「写放大」</strong>指逻辑写 1 倍数据，物理实际写 2–4 倍——这是 SSD 性能之谜的核心。</span>

## 3 新型非易失存储：PCM 与 3D XPoint

闪存虽然快于磁盘，但仍**不是字节寻址**（页/块粒度）。新一代 NVM 的目标是**字节寻址 + 非易失 + 比闪存快**：

| 技术 | 存储原理 | 特点 |
| --- | --- | --- |
| **PCM（相变存储）** | 硫系材料在晶态/非晶态间切换 | 字节寻址、可原位改写、寿命中 |
| **3D XPoint / Optane** | 相变 + 选通管 | Intel 商用，介于 DRAM 与 SSD 间 |
| **MRAM** | 磁隧道结 | 快、寿命高，容量有限 |
| **ReRAM** | 电阻开关 | 低功耗，[[reram-computing-in-memory]] 的主角 |

**核心概念**：这类 NVM 的共同点是：**可字节寻址（像内存）、掉电不丢（像存储）、读快写慢、寿命有限**。它们试图填补 DRAM 与 SSD 之间巨大的延迟鸿沟。

## 4 存储级内存（SCM）与持久内存编程

**核心概念**：**存储级内存（Storage-Class Memory, SCM）**把 NVM 放进内存总线的位置，让 CPU 直接**字节寻址地读写持久数据**——不再需要「先读进 DRAM 再算」：

```c
// 传统：文件要 mmap 后还要 flush 到磁盘
// SCM：直接对持久内存指针读写
pmem[42] = value;          // 写入即持久（配合 clflush/屏障）
```

代价与风险：

- **崩溃一致性**：写了一半断电怎么办？需要事务、日志（如 Intel 的 PMDK、Linux DAX 机制）保证一致性。
- **持久化指令**：要显式 **`clflush`/`sfence`** 把写刷出 CPU 缓存，否则「掉电」时新值还在缓存里——**缓存成为持久性的敌人**。<span class="marginnote">SCM 把「[[precise-exceptions-speculation-recovery]] 式的精确性」从异常扩展到断电：<strong>掉电也要精确</strong>。这是持久内存编程与普通内存编程最大的不同。</span>

## 5 核心对比表

> 本节为纯概念主题，以核心对比表替代公式解析。

| 维度 | DRAM | NVM（PCM/Optane） | NAND SSD | HDD |
| --- | --- | --- | --- | --- |
| 字节寻址 | 是 | 是 | 否（页/块） | 否 |
| 非易失 | 否 | 是 | 是 | 是 |
| 延迟 | ~80 ns | ~0.3–10 μs | ~0.1 ms | ~5 ms |
| 写入方式 | 覆盖 | 原位（有限寿命） | 擦除+写 | 覆盖 |
| 寿命 | 近乎无限 | 有限（数百万次写） | 有限（千~十万次擦写） | 有限 |
| 位置 | 主存 | SCM | 块存储 | 块存储 |

## 6 小结

- **NAND 闪存**按块擦除、按页读写，不能原地覆盖——怪癖由 **FTL** 软件掩盖。
- FTL 三件事：**映射/写时复制、磨损均衡、垃圾回收**；写放大与预留空间决定 SSD 性能与寿命。
- 新型 NVM（**PCM/3D XPoint/MRAM/ReRAM**）：字节寻址 + 非易失，填 DRAM 与 SSD 的鸿沟。
- **SCM** 让 CPU 直接字节寻址持久数据，但引入**崩溃一致性**与**缓存刷新**问题。
- 存储层次正从「DRAM + SSD」二元结构，走向「DRAM + SCM + SSD」三元结构。
