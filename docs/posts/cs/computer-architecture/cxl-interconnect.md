## 为什么「设备访问内存」要重新设计

传统加速器（GPU/NIC）通过 PCIe 访问内存——但要先**拷到自己的显存**、没有缓存一致性、IO 语义慢。**CXL（Compute Express Link）**把主机与设备之间的连接升级为**缓存一致性**的连接：设备可以直接读主机的内存、和 CPU 共享一致视图，还能**把内存挂到主机上供整个系统使用**。<span class="marginnote">这是 [[virtual-machines-memory-virtualization]] 里「地址空间共享」的硬件化延伸：<strong>把 CPU 内部的一致性协议（[[cache-coherence-snooping]]）扩展到板卡级设备</strong>。</span>

## 1 CXL 的三种协议

| 协议 | 语义 | 用途 |
| --- | --- | --- |
| **CXL.io** | PCIe 兼容的 I/O | 枚举、配置、常规 I/O |
| **CXL.cache** | 缓存一致性 | 加速器访问并缓存主机内存 |
| **CXL.mem** | 内存语义 | 设备/扩展内存作为系统内存 |

**核心概念**：CXL 物理层复用 PCIe，但**协议层把 I/O 升级成「缓存一致性 + 内存语义」**——设备不再是「外设」，而是「系统内存体系的一部分」。

## 2 三种设备类型

| 类型 | 行为 | 代表 |
| --- | --- | --- |
| **Type 1** | 只缓存主机内存（CXL.cache） | 智能网卡 |
| **Type 2** | 有自己的内存 + 缓存主机内存（.cache + .mem） | GPU、加速器 |
| **Type 3** | 只提供内存（.mem） | **内存扩展器** |

**核心概念**：**Type 3 是 CXL 的重头戏**——一根「内存条 + 控制器」的设备，插到 CXL 槽位就**变成主机的系统内存**，让一台服务器**挂上远超本地插槽的容量与带宽**。

## 3 内存池化：把内存拆出服务器

**核心概念**：**内存池化（memory pooling）**：把内存从「每台服务器私有」变成「机架/集群共享池」，多台主机**按需动态分配**内存。

```
传统：每台服务器 N GB 私有内存（各用各的，浪费）
CXL 池化：一个内存池，多台主机按需认领
  → 内存利用率从 30% 提到 80%+（统计复用）
```

**收益**：内存是云服务器最贵的资源之一，**池化让「内存利用率」追上「CPU 利用率」**——这正是 [[cloud-economics-wsc]] 里统计复用在内存上的翻版。<span class="marginnote">内存池化呼应 [[wsc-architecture]] 的「存算分离」趋势：<strong>计算与内存解耦，按需弹性配比</strong>——像「把内存条做成云服务」。</span>

## 4 挑战：CXL 的现实账

- **延迟**：CXL 内存访问比本地 DIMM 慢（多了互连与控制器）——通常本地 ~80 ns、CXL 200–300 ns。**内存分层**（热数据在本地、冷数据在 CXL）是软件要解决的问题。
- **一致性**：多主机/多设备共享缓存一致内存，**一致性协议负载与复杂度上升**（[[directory-based-coherence]] 的目录思路要延伸到板卡级）。
- **软件栈**：操作系统要把「CXL 内存」当「可热插拔的 NUMA 节点」管理（[[server-memory-hierarchy-case]] 的 NUMA 经验复用）。

**辨析｜易错点：** CXL 内存**不是**「普通内存条」——它的延迟和带宽低于本地内存。**它扩展的是「容量」与「共享」，不是「速度」**。把热数据放 CXL、冷数据放本地，顺序反了就得不偿失。

## 5 核心对比表：CXL vs 传统互连

> 本节为纯概念主题，以核心对比表替代公式解析。

| 维度 | PCIe 设备 | CXL 设备 | 本地内存 |
| --- | --- | --- | --- |
| 缓存一致性 | 无 | **有** | 有 |
| 内存语义 | 无 | **有（.mem）** | 原生 |
| 延迟 | 高 | 中（200–300 ns） | 低（~80 ns） |
| 容量扩展 | 无 | **大（池化）** | 受插槽限制 |
| 软件模型 | 驱动/拷贝 | **系统内存** | 系统内存 |

## 6 小结

- **CXL** = PCIe 物理 + **缓存一致性/内存语义**协议，连接主机与设备。
- 三种协议：**.io（I/O）、.cache（一致性缓存）、.mem（内存）**。
- 三种设备：**Type 1（纯缓存）、Type 2（加速器）、Type 3（内存扩展）**。
- **内存池化**：内存从「私有」变「共享池」，利用率与弹性大增。
- 挑战：**延迟高于本地、一致性复杂度、内存分层软件**。
- CXL 让「内存」成为可弹性伸缩的互连资源——**存算分离的关键一步**。
