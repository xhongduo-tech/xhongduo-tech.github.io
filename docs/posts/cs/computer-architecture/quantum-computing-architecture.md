## 为什么体系结构要谈量子

量子计算（见「量子计算」专题）用**量子比特（qubit）**做计算，理论上能破解 RSA、加速搜索与模拟。但**造一台有用的量子计算机，九成是体系结构问题**：量子比特极易出错、相干时间极短、可连接性受限——**把这些物理限制组织成可编程的「计算机」**，正是体系结构的任务。<span class="marginnote">对照经典计算机：经典体系结构解决「快」，量子体系结构先解决「<strong>活着且对</strong>」。<strong>错误率、可靠性、抽象层次</strong>——这些经典体系结构的老主题，在量子领域全部以极端形式重现。</span>

## 1 量子计算机的体系结构栈

| 层 | 职责 | 类比经典 |
| --- | --- | --- |
| **算法层** | 量子算法（Shor、Grover） | 应用程序 |
| **编译器/映射层** | 门分解、量子比特路由 | 编译器 + 指令调度 |
| **纠错层（QEC）** | 逻辑量子比特的容错 | 内存 ECC/RAID |
| **物理层** | 量子比特 + 控制电子学 | 晶体管 + 微架构 |

**核心概念**：量子体系结构栈与经典惊人相似——**同样的「算法 → 编译 → 容错 → 物理」分层**，只是每一层都要面对「量子比特会错、会衰减、连不上去」三座大山。

## 2 物理量子比特 vs 逻辑量子比特

**核心概念**：物理量子比特（硬件上的 qubit）错误率高（每门 10⁻²–10⁻³），无法直接用于长计算。**量子纠错（QEC）**把**多个物理 qubit 编码成一个逻辑 qubit**——逻辑 qubit 才可靠。

**编码开销**：一个逻辑 qubit 需要 **100–1000 个物理 qubit**（取决于错误率与码型）。
**后果**：跑有用算法要数百万逻辑 qubit ≈ **数十亿物理 qubit**——今天最好的量子处理器只有 **数百到上千物理 qubit**。
**教训**：量子计算的可扩展性 = **纠错开销 + 硬件规模**的问题，与经典 [[raid-ecc-reliability]] 里「冗余换可靠」同一哲学，只是开销大几个数量级。<span class="marginnote">经典世界里 ECC 用 8 位校验保 64 位数据（约 12% 开销）；量子世界里纠错要 100–1000 倍开销——<strong>「可靠」在量子尺度的代价是天文数字</strong>。</span>

## 3 映射与路由：量子编译器

物理 qubit 的**连接拓扑**受限（如网格），不是任意两比特都能直接作用（两比特门需要「相邻」）。于是量子编译器做两件事：

- **门分解**：把任意门翻译成硬件支持的原生门集（如 $\{H, T, CNOT\}$）。
- **路由（routing）**：通过 **SWAP 门**把量子比特「搬」到相邻位置——**每次 SWAP 都是额外噪声**，路由优化直接决定程序能否跑完。

**核心概念**：这像经典编译器的寄存器分配 + 指令调度，但约束更硬：**连接图固定、每步都出错、移动也出错**。量子编译 = 在「有限的邻接图」上最小化「移动 + 错误」。

## 4 物理实现：几种量子比特

| 技术 | 代表 | 特点 |
| --- | --- | --- |
| 超导量子比特 | IBM、Google | 成熟、可扩展，需极低温 |
| 离子阱 | IonQ、Quantinuum | 高保真、连接灵活，速度慢 |
| 光量子 | 光子 | 室温、不易纠错 |
| 中性原子 | Pasqal | 可重组、规模潜力 |

## 5 NISQ 时代与规模挑战

**核心概念**：**NISQ（Noisy Intermediate-Scale Quantum）**——今天几十到几千 qubit、带噪声、无纠错的「中间时代」。NISQ 机器的策略是**在退相干前跑完**（短程序、浅电路），靠「变分算法」让经典与量子协作（如 VQE）。

- **今天**：几百 qubit，演示性质。
- **明天**：逻辑 qubit 出现，需百万物理 qubit——**还有两个数量级的工程鸿沟**。
- **体系结构的角色**：让错误率下降、连接性提升、编译更聪明——**每一分提升都换算成「能跑的算法复杂度」**。

**辨析｜易错点：** 量子计算机**不是「更快地做经典计算」**——它擅长的是**特定问题**（因式分解、量子模拟、搜索），而通用计算它可能更慢。**量子是「专用加速器」的极致形态**，与 [[dsa-rise-background]] 的「领域专用」思想遥相呼应。

## 6 核心对比表：经典 vs 量子体系结构

> 本节为纯概念主题，以核心对比表替代公式解析。

| 维度 | 经典 | 量子 |
| --- | --- | --- |
| 基本单元 | 比特 | 量子比特 |
| 错误率 | 极低 | 高（需 QEC） |
| 容错开销 | ECC/RAID（10%级） | **100–1000 倍** |
| 连接 | 任意（总线/NoC） | 受限（邻接图） |
| 编译器 | 指令调度 | 门分解 + 路由 |
| 现状 | 成熟 | **NISQ 起步** |

## 7 小结

- 量子体系结构栈：**算法 → 编译/路由 → 纠错 → 物理**，与经典分层同构。
- **物理 qubit 不可靠**，逻辑 qubit 靠纠错，**开销 100–1000 倍**——规模是最大挑战。
- 量子编译器干两件事：**门分解 + 路由（SWAP）**，每步都在与噪声赛跑。
- **NISQ 时代**：几百 qubit、带噪声、靠变分算法；距离有用容错机还有两个数量级。
- 量子是「专用计算」的极致，与经典通用计算互补而非替代。
