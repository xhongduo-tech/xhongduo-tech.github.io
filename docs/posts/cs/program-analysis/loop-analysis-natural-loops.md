## 为什么循环是优化的主战场

程序运行时间的 90% 往往集中在 10% 的代码上，而这 10% 几乎都是循环。因此编译器把绝大部分优化火力对准循环。但循环在 CFG 上怎么**定义**？不是所有「看起来像循环」的图结构都是循环——程序的循环对应一种特殊的图结构：**自然循环（natural loop）**。识别它，需要上一节的支配关系。<span class="marginnote">「80/20 法则」在编译器里有个更精确的版本：循环嵌套越深，越值得优化。所以优化器会专门维护循环嵌套结构（循环森林/循环树），把强度削减、外提、向量化按深度排序地应用。</span>

**回边（back edge）**：一条从节点 $a$ 指向 $b$ 的边，其中 $b$ 支配 $a$。**自然循环（natural loop）**：由一条回边 $a \to b$ 确定的、包含 $b$ 与所有「能到达 $a$ 且不被 $b$ 支配的节点排除」的节点集合，形成一个结构良好的循环。

## 1 回边：循环的信号

循环在 CFG 上的本质是「路径绕回」：存在一条路径从某个节点出发又回到它自己。用支配的语言说：

**回边（back edge）**：$a \to b$ 是回边，若 $b$ 支配 $a$。含义：从入口到 $a$ 的每条路径都经过 $b$，而 $a \to b$ 又把控制送回 $b$——控制流在 $b$ 和 $a$ 之间打转。

为什么「$b$ 支配 $a$」是回边的判据？因为回边意味着「循环回到的节点能管住出发的节点」——$b$ 是循环的必经入口，$a$ 是绕回来之前的最后一站。<span class="marginnote">注意回边判据用的是支配而非「$a$ 能到达 $b$」。$a$ 能到达 $b$ 只是说明存在路径，$b$ 支配 $a$ 才说明「回到 $b$ 是唯一的出路」——后者才是循环头「说了算」的语义。</span>

**易错点：** 无向图上「有环」不等于 CFG 上有自然循环。CFG 的「环」必须由回边产生；两个互相跳转但互不支配的节点（如 `if/else` 的合流再分叉），在无向图上有环，在支配意义下不是自然循环。**自然循环是「由回边确定、有唯一入口」的强结构化循环。**

## 2 自然循环：回边 + 支配的节点闭包

给定回边 $a \to b$，**自然循环（natural loop）** 是节点集合：

$$
\mathrm{Loop}(a \to b) = \{b\} \cup \mathrm{NodesOnPaths}(b, a)
$$

其中 $\mathrm{NodesOnPaths}(b, a)$ 是所有「从 $b$ 出发、能到达 $a$ 且不经过 $b$」的路径上的节点集合。构造算法：

1. 从回边 $a \to b$ 出发，把 $a$ 加入循环集。
2. 反复把「能到达循环集中任意节点的前驱」加入，直到不再变化，但要**跳过 $b$**（防止把循环头之外的区域卷进来）。
3. 循环集 = $\{b\} \cup$ 上一步得到的集合。

自然循环的性质，使它成为优化的理想单位：

**单入口（header）**：$b$ 是唯一的入口——任何进入循环的执行必先到 $b$。这保证「在 $b$ 之前做的优化假设」对整条路径有效。

**连通且封闭**：循环内任意节点到 $a$ 再到 $b$ 都在循环内；从循环外进入循环必经过 $b$。

**嵌套结构**：循环可以嵌套（一个循环的 header 在另一个循环内），也可以共享 header（两个回边同指向 $b$，合并为一个循环）。

**可约性（reducibility）**：若一个 CFG 的每个循环都是自然循环（即所有环都由回边产生），称该图是**可约的（reducible）**。结构化编程（只用 if/while/for）产生的 CFG 恒可约；`goto` 可能产生不可约图。**可约性是可读性的图论化身**：它保证循环结构能层层剥离。<span class="marginnote">经典程序语言（C、Java、Python 的 while/for）都产生可约 CFG。不可约图需要专门的「节点分裂」预处理才能套用循环优化。龙书里对可约性的定义、判定（无「两个互相可达但不互支配」的节点对）值得专门记忆。</span>

## 3 循环结构信息：从自然循环到优化清单

识别出循环后，编译器为每个自然循环计算一组结构信息，它们是循环优化的输入：

**header**：循环唯一入口。
**preheader**：优化器人工加的一个空基本块，插在 header 之前，专门收纳「循环不变量外提」的目标与循环入口处的初始化。它让「循环前只执行一次」的代码有安放处。

**body**：循环内全部节点。
**back edge 集合**：$a \to b$ 的回边清单。
**循环不变量（loop-invariant）**：循环内「值在循环期间不变」的表达式——每个操作数的定值都来自循环外，或来自本循环内不变的定值。这是循环不变量外提（LICM）的候选。
**归纳变量（induction variable）**：在循环内每次迭代按固定步长变化的变量，如 `i = i + 1`。这是强度削减与归纳变量消除的候选。

计算循环不变量的迭代规则：表达式 $e$ 在循环 $L$ 中不变量，若其所有操作数要么是常量、要么其定值在循环外、要么其定值也是不变量表达式。这又是一个不动点计算——沿循环体的依赖关系扩散。<span class="marginnote">归纳变量的典型例：`for (i=0;i<n;i++) a[4*i] = ...` 里的 `4*i` 是归纳变量 `i` 的线性函数，强度削减把它换成每次加 4 的新归纳变量 `j`。下一节专门展开。</span>

### 循环嵌套与循环树

真实程序里循环不是孤立的，而是**嵌套**的。编译器把全部自然循环组织成一棵**循环树（loop tree）**：

树的根是「整个函数」（看作最外层的容器）。
每个自然循环是树上的一个节点，其子节点是「直接嵌套在它内部」的循环。
- 嵌套关系由循环体的包含关系决定：若循环 $L_1$ 的 header 与体都包含在循环 $L_2$ 的体内，则 $L_1$ 是 $L_2$ 的后代。

**为什么循环树重要**：

**优化的优先级**：内层循环每次迭代最频繁，收益最大。优化器按「从内向外」的顺序处理——先优化最深层的循环，再逐层向外。**内层循环的一条指令优化，抵得上外层循环的十条。**

**不变量外提的层次**：循环不变量「相对哪层循环不变」是有区分的。对双层循环：

```
for (i...) for (j...) { c = a + b; ... }
```

`a + b` 在 $j$ 循环内不变，也在 $i$ 循环内不变——可以提到最外层，只算一次。判断「外提到第几层」需要沿循环树逐层确认不变性。

**易错点：** 共享 header 的循环（两个回边指向同一个 header）合并成一个自然循环，其 header 唯一；但循环树的结构仍要正确处理这种「共享头」情况——它们不会变成两个并列子树，而是共享 header 的单节点。<span class="marginnote">循环树与支配树的结构关系值得留意：循环的嵌套关系可以由支配树辅助判定——内层循环的 header 支配外层循环的 header。所以循环分析、支配分析、SSA 三者共享同一套「图结构」基建。</span>

### 自然循环与 do-while / for 的对应

把自然循环的图论定义翻译回三种常见语言构造，建立直觉：

**`while (b) S`**：header 是循环入口（测试 $b$ 的位置），回边从循环体末尾跳回 header。header 同时是「测试」与「入口」——这是最简单的自然循环。

**`do { S } while (b)`**：header 是循环体入口，回边从「末尾的测试」跳回入口。**注意**：do-while 的 header 不测试条件，条件在回边上——这影响不变量外提的合法性（循环体至少执行一次）。

**`for (i = 0; i < n; i++) S`**：header 是「测试 $i \lt  n$」的位置；初始化 `i = 0` 在 preheader，增量 `i++` 在回边上。for 循环被规范化成「初始化块 + 测试头 + 体 + 增量回边」的结构，是最「教科书」的自然循环形态。

**为什么要做这个对应**：真实程序源码千变万化，但落到 CFG 上只有这几种循环形态。**识别循环 = 识别回边 + 划定循环体**，与源码写的是 while 还是 for 无关。这个「源码多样、图统一」的视角，是程序分析抽象层次优势的最好例证——**分析器看到的是图，不是语法。**

## 4 公式解析：自然循环的闭包定义

把自然循环的构造写成集合不动点。设回边为 $a \to b$，从种子集 $\{a\}$ 出发，定义：

$$
L \leftarrow \text{lfp}_{\ \subseteq}\ \Big( \{a\} \cup \big\{ p \mid p \in \mathrm{pred}(n),\ n \in L,\ p \ne b \big\} \Big)
$$

对这条式子做三步拆解：

- **第一步，看种子**：$\{a\}$ 是回边的源端——绕回来那一站必在循环内。
- **第二步，看扩张规则**：若 $p$ 是循环内某节点 $n$ 的前驱，且 $p \ne b$，则 $p$ 也进循环。$\mathrm{pred}$ 反向扩展，$p \ne b$ 是「护栏」——$b$ 是循环头，它之外的世界不被卷入。
- **第三步，看不动点**：$\text{lfp}$ 表示扩张到不能再扩张。最终 $L \cup \{b\}$ 就是自然循环：所有「能绕到 $a$ 再回 $b$」的路径节点都被收进来了，且不多不少。

## 5 小结

- **回边**：$a \to b$ 且 $b$ 支配 $a$
