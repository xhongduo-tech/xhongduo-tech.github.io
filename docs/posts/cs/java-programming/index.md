# Java 编程

Java 是一门面向对象、平台无关的通用编程语言，凭借"一次编写、处处运行"的 JVM 生态与数十年积累的开源库，长期占据后端服务、大数据与企业级软件开发的主流地位。系统掌握 Java 语言机制与高效编程范式，是进入后端开发、分布式系统与云原生技术栈的基础能力。

## 对标教材

- 《Java核心技术》（第1卷：基础知识 / 第2卷：高级特性，Cay S. Horstmann）
- 《Effective Java》（第3版，Joshua Bloch）
