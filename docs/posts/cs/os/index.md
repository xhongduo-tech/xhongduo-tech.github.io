# 操作系统

硬件之上的第一层抽象，理解进程、内存与 I/O 的管理之道。

## 主题规划

- [ ] 操作系统概述：内核、系统调用与中断
- [ ] 进程与线程：状态转换与上下文切换
- [ ] CPU 调度算法：FCFS、SJF、RR 与多级反馈队列
- [ ] 进程同步：信号量、管程与经典同步问题
- [ ] 死锁：产生条件、预防、避免与检测
- [ ] 内存管理：分区、分页与分段
- [ ] 虚拟内存：页面置换算法与工作集
- [ ] 文件系统：inode、目录结构与日志文件系统
- [ ] 磁盘调度与 I/O 管理
- [ ] Linux 实践：进程、信号与 IPC
- [ ] Linux 实践：epoll 与高并发 I/O 模型
- [ ] 虚拟化技术：Hypervisor 与 KVM
- [ ] 容器原理：Namespace 与 Cgroup
