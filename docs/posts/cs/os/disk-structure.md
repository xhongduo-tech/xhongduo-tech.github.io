## 为什么从磁盘结构开始

虚拟内存、文件系统、数据库——这些全都依赖**持久存储**，而传统持久存储的主角是**机械硬盘（HDD）**。理解磁盘的物理结构（盘片、磁头、柱面、扇区），才能理解磁盘调度、RAID 和文件系统为什么要这样设计。**磁盘的物理特性决定了「随机访问很慢、顺序访问很快」**，这一句话是存储子系统设计的全部出发点。<span class="marginnote">回顾《内存映射文件》：mmap 让文件访问像内存。但内存是纳秒级，磁盘是毫秒级——这 5~6 个数量级的鸿沟，决定了文件系统一切「为减少 I/O 而设计」的技巧。磁盘结构是理解这道鸿沟的第一课。</span>

## 1 磁盘的物理结构

**磁盘（hard disk drive, HDD）**由以下部分组成：

- **盘片（platter）**：圆形磁性盘片，数据存在其表面。一个磁盘有多片盘片叠放。
- **磁头（read/write head）**：每片盘片的每个表面一个磁头，悬浮在盘面上读写数据。
- **主轴（spindle）**：驱动盘片旋转，转速如 7200 RPM（每分钟转数）。
- **磁道（track）**：盘片表面的同心圆环，数据沿磁道存放。
- **扇区（sector）**：磁道被分成的最小存储单元，传统大小 512 字节（现代 4K 扇区）。**扇区是磁盘读写的最小单位**。
- **柱面（cylinder）**：所有盘片上**相同半径**的磁道集合。

```
俯视盘片：
  ┌──────────────────┐
  │    ╭────────╮    │
  │   ╭┤  磁道  ├╮   │
  │  ╭┤ │       │├╮  │
  │  ││ │ ◎主轴 ││ │  │
  │  ╰┤ │       │├╯  │
  │   ╰┤       ├╯    │
  │    ╰────────╯     │
  └──────────────────┘
  扇区：磁道上的一小段弧
```

**数据定位**：要读写某个扇区，磁头臂要把磁头移动到对应**磁道**（寻道），然后等盘片旋转到对应**扇区**（旋转），最后才读写。

## 2 磁记录原理：数据怎么存进磁场

**磁记录（magnetic recording）**：盘片表面涂有磁性材料，每个微小区域（磁畴）可被磁化。**磁头写入时改变该区域的磁化方向，读出时感应磁场变化**。

- **一位数据**：磁化方向朝一个方向（0）或反方向（1）。
- **写入**：磁头产生磁场，定向磁化磁畴。
- **读出**：磁头感应磁化方向的变化。

**记录方式（编码）**：直接存 0/1 不够可靠（长串相同位无法读出「变化」），需要**编码**（如游程长度受限编码 RLL）保证磁场有足够变化——这是磁盘控制器的事，对 OS 透明。

**扇区与 ECC**：每个扇区除了数据，还存**校验码（ECC）**——读写时校验错误并纠正。扇区是「数据 + 冗余」的完整单元。

**辨析｜易错点：** 「磁盘读最小的单位是字节」是误解。**磁盘的最小读写单位是扇区（512B 或 4KB）**——你不能只读一个字节，必须整扇区读入，再在内存里取所需字节。这也解释了为什么文件系统用「块」（通常等于或倍于扇区）作为存储单位（见第十二篇《文件系统实现》）。

## 3 磁盘的三种访问时间

一次磁盘 I/O 的总时间：

$$\text{访问时间} = \text{寻道时间} + \text{旋转延迟} + \text{传输时间}$$

- **寻道时间（seek time）**：磁头臂移到目标磁道的时间——**最耗时**（毫秒级，且与移动距离成正比）。
- **旋转延迟（rotational latency）**：盘片转到目标扇区的时间——平均为半圈旋转时间（7200 RPM 下约 4.17ms）。
- **传输时间（transfer time）**：数据从磁盘传出的时间——通常最小。

**公式解析：平均旋转延迟**

$$T_{rot\_avg} = \frac{1}{2} \times \frac{1}{\text{RPM}} \times 60\text{s}$$

- **RPM**：转速（转/分）。
- $\frac{1}{\text{RPM}}\times60$：转一圈的秒数。
- 平均等半圈，故乘 $\frac12$。
- 7200 RPM：$T = \frac12 \times \frac{60}{7200} = 4.17\text{ms}$。

**核心结论**：**寻道与旋转占磁盘访问时间的绝大部分（毫秒级），传输只占小头。随机访问（每个请求都寻道+旋转）远慢于顺序访问（连续读同一磁道，几乎不寻道）。** 这就是「顺序 I/O 快、随机 I/O 慢」的物理根源。<span class="marginnote">这个差距量化一下：7200RPM 磁盘随机访问约 10ms，顺序读可达 100~200 MB/s（约每 512B 扇区微秒级）。<strong>随机 vs 顺序差 3~4 个数量级</strong>——数据库、文件系统、日志系统一切「顺序化」设计，都在填这个鸿沟。</span>

## 4 核心对比表：三种访问时间

| 时间 | 典型值（7200RPM） | 决定因素 |
| --- | --- | --- |
| 寻道时间 | 4~10 ms | 磁头移动距离 |
| 旋转延迟 | 平均 4.17 ms | 转速 |
| 传输时间 | 0.05~0.2 ms/扇区 | 转速与记录密度 |

## 5 小结

- **磁盘结构**：盘片 + 磁头 + 主轴；磁道 → 柱面 → 扇区（最小读写单位）。
- **磁记录**：磁畴磁化方向表示 0/1；扇区带 ECC 校验。
- **访问时间** = 寻道 + 旋转 + 传输；**寻道与旋转占大头（毫秒级）**。
- 平均旋转延迟 $= \frac12 \times \frac{60}{\text{RPM}}$，7200RPM 约 4.17ms。
- **顺序访问 vs 随机访问差 3~4 个数量级**——存储系统一切设计的出发点。
