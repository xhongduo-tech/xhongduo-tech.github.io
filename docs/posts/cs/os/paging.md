## 为什么从分页开始

连续分配绕不开碎片：要么内部空、要么外部碎、要么靠紧凑搬来搬去。**分页（paging）**从根本上釜底抽薪——**进程不再需要连续内存**：把进程切成固定大小的「页」，散装到内存中任意空闲的「页框」，用页表记录映射。碎片问题烟消云散，分页也因此成为现代操作系统内存管理的绝对主流。<span class="marginnote">回顾碎片之争：内部碎片（块内空）与外部碎片（块间碎）都是「连续分配」的病。分页把「块」换成「等大小的页框」，任何空闲页框都能装任何页——<strong>外部碎片消失，内部碎片只剩每页最后一小块</strong>（平均半页）。</span>

## 1 基本概念：页、页框、页表

- **页（page）**：进程的逻辑地址空间切成等大的块，每块叫一页。典型大小 4KB。
- **页框（frame）**：物理内存切成等大的块，每块叫一页框。页与页框**大小相同**。
- **页表（page table）**：每个进程一张，记录「我的第几页 → 物理内存的哪个页框」。

**页表是进程私有的**——每个进程有自己的页表，这就是进程地址空间隔离的物理基础：进程 A 的页表把页映射到页框 5，进程 B 的页表把页映射到页框 100，互不相干。

例如，进程 A 有 4 页，页表项依次为 `[5, 100, 23, 47]`——它的第 0、1、2、3 页分别存放在页框 5、100、23、47。页框 5 与页框 100 之间隔着别的进程的页，但 A 完全感觉不到：它只看到自己「连续」的 0~3 号逻辑页。

**进程的页可以不连续**——这正是分页解决外部碎片的本质：不需要连续块，任意空闲页框都行。

## 2 地址转换：页号 + 偏移

分页系统的逻辑地址被硬件拆成两部分：

$$\text{逻辑地址} = \underbrace{\text{页号 } p}_{\text{高位移}} + \underbrace{\text{页内偏移 } d}_{\text{低位移}}$$

若页大小 = $2^k$，则逻辑地址的低 $k$ 位是偏移 $d$，高位移是页号 $p$。

**地址转换流程**：

1. 从逻辑地址拆出**页号 p** 与**偏移 d**。
2. 查**页表**：页号 p 对应的表项得到**页框号 f**。
3. 物理地址 = **页框号 f × 页大小 + 偏移 d**。

**公式解析：物理地址的组成**

$$\text{物理地址} = f \times 2^k + d$$

- **$f$**：页框号（从页表取出的映射）。
- **$2^k$**：页大小（$k$ 是页大小以 2 为底的对数）。
- **$d$**：页内偏移（逻辑地址低 $k$ 位，原样保留——页内偏移在物理页框内不变）。

**直觉**：地址转换就是把「高位移（页号）」换成「另一个高位移（页框号）」，低 $k$ 位偏移**原封不动**——因为页与页框等大，页内第 d 字节仍落在页框内第 d 字节。**转换 = 换「块号」，不换「块内位置」。**

## 3 示例：一次具体的转换

设页大小 4KB（$k=12$），逻辑地址 0x3058：

1. 拆位：$0x3058 = 0000\ 0011\ 0000\ 0101\ 1000_2$，低 12 位 $= 0x058$ 是偏移，高位移 $= 0x3$ 是页号。
2. 查页表：假设页 3 → 页框 7（$f=7$）。
3. 物理地址 $= 7 \times 4096 + 0x058 = 0x7058$。

**页内偏移 0x058 完全没变，只有高位移从 3 变成 7**——这就是分页转换的全部奥妙。

## 4 分页的优缺点

**优点**：

- **无外部碎片**：任意空闲页框都能装，不再需要连续块。
- **内部碎片极小**：只剩每页末尾平均半页的浪费（4KB 页平均浪费 2KB/进程，可忽略）。
- **共享方便**：代码页、公共库可以映射到多个进程的页表，物理上只有一份。

**缺点**：

- **页表开销**：每个进程一张页表，进程大则页表大（见《页表结构》）。
- **两次访存**：一次查页表、一次访数据——需要 TLB 加速（见《快表 TLB》）。
- **页内碎片**：虽小但存在。

**辨析｜易错点：** 「分页完全没有碎片」是夸大。**分页消灭了外部碎片，内部碎片只是变小（每页平均半页），没有彻底消失。** 页大小越大，内部碎片越多（页越小碎片越少但页表越大）；页大小越小，页表越大、TLB 命中率越差。**页大小是碎片与开销的权衡点。**

另一个易错点：**页表是进程私有、存于内存**——内核管页表，进程自己无法篡改（否则就能映射到别人的页框，突破隔离）。**页表既是「翻译工具」也是「保护工具」**：不在页表中的页就是不可访问的页。

## 5 小结

- **分页**：进程切页、内存切页框、页表记映射——进程无需连续内存。
- 逻辑地址 = **页号 + 页内偏移**；物理地址 = **页框号 × 页大小 + 偏移**。
- 地址转换 = 换高位移（页号→页框号），低 k 位偏移原样保留。
- 分页消灭**外部碎片**、内部碎片只剩平均半页；代价是页表开销与两次访存。
- 页表是「翻译 + 保护」双重工具，进程私有无权篡改。
