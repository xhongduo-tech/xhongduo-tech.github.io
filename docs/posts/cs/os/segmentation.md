## 为什么从分段开始

分页解决了碎片，但它的页是**机械等分**的——程序根本不在乎「第 5000 页在哪」，分页纯粹是内存管理的便利。**分段（segmentation）**换一个视角：**按程序员的逻辑单位切**——代码段、数据段、栈段各是一段，每段有名字、有语义。分段更符合程序结构，但也带来了外部碎片。最后，**段页式**把两者的优点合二为一。这一节是分页到虚拟内存之间的桥梁。<span class="marginnote">回顾分页的动机：它切的是「等大小的页」，为了消除碎片。分段切的是「不等大小的逻辑段」，为了符合程序结构——两者的动机根本不同，这正是「为什么会有两种方案」的答案。</span>

## 1 分段的基本思想

**分段（segmentation）**：把进程的逻辑地址空间按逻辑单元分成若干**段（segment）**——每段是一个完整的逻辑单位：主程序、函数库、全局变量、栈、堆。每段大小**不同**，从 0 开始编号。

分段系统的逻辑地址是**二维的**：

$$\text{逻辑地址} = \text{段号 } s + \text{段内偏移 } d$$

段表（segment table）记录每段的：

- **基址（base）**：该段在物理内存的起始位置。
- **段长（limit）**：该段的长度。

**物理地址 = 段表[s].base + d**，前提是 $d < $ 段表[s].limit（段内偏移不越界）。

**分段的优势（对程序员友好）**：

- **段有语义**：代码段可共享、可只读；数据段可写；栈段动态增长——保护与共享都按段为单位，天然合理。
- **段可独立编译/链接/增长**：编译器按段组织，不需要为「页」操心。
- **段间不连续**：段可装在任意位置，无需进程整体连续。

## 2 分段的代价：外部碎片回来了

分段按需分配、段大小不等——**这是动态分区！** 分段本质上就是「把进程按逻辑切块后的动态分区」，所以它继承了动态分区的毛病：

- **外部碎片**：段与段之间的空闲块碎得用不上（回顾《动态分区》）。
- 需要紧凑或靠分配算法缓解。

**辨析｜易错点：** 「分段比分页好，因为符合逻辑」是理想；**分段在内存利用上有「倒退」——它把连续分配的碎片问题带回来了。** 分页消除碎片靠「等大小」，分段保留语义靠「不等大小」——**等大小 vs 语义，正是分页与分段不可兼得的根源**。所以才有了段页式：外层按语义分段，段内按等大小分页，两全其美。

## 3 段页式存储管理：合二为一

**段页式存储管理（segmentation with paging）**：**段内再分页**——地址空间先按逻辑分成段，每段再切成固定大小的页，段表记录「段 → 页表」，页表记录「页 → 页框」。

地址转换（三段式）：

$$\text{逻辑地址} = \text{段号 } s + \text{页号 } p + \text{页内偏移 } d$$

1. 查**段表**：段号 s → 得到该段的页表基址与段长（检查段内偏移 < 段长）。
2. 查**页表**：页号 p → 得到页框号 f。
3. **物理地址** = f × 页大小 + d。

**段页式的双重收益**：

- **分页解决碎片**：段内分页，页框等大小，外部碎片消失。
- **分段保留语义**：段是逻辑单位，按段共享、按段保护。

**代价**：**三次访存**（段表 + 页表 + 数据），需两级缓存加速（TLB 缓存「s+p → f」的组合）。

## 4 核心对比表：分页 vs 分段 vs 段页式

| 维度 | 分页 | 分段 | 段页式 |
| --- | --- | --- | --- |
| 划分依据 | 机械等分 | 逻辑单位 | 段内再分页 |
| 用户可见性 | 不可见 | 可见（程序员按段组织） | 段可见、页不可见 |
| 外部碎片 | 无 | **有** | 无 |
| 内部碎片 | 有（半页） | 无 | 有（半页） |
| 地址结构 | 页号+偏移 | 段号+偏移 | 段号+页号+偏移 |
| 保护/共享 | 按页，粒度粗 | **按段，天然合理** | 按段共享 + 按页分配 |
| 访存次数 | 2（TLB 后 1） | 2 | 3（缓存后近 1） |

**辨析｜易错点：** 「段页式 = 分页 + 分段叠加，地址拆三段」听起来简单，但要注意**顺序**：先段号、再页号、再偏移——段表是**外层**，页表是**内层**。另一个易错点：**段页式的段长检查仍要保留**（段长对应「该段用了多少页」），不能因为分页就丢了对段边界的保护。

## 5 小结

- **分段**按逻辑单位切（代码/数据/栈），地址 = 段号 + 段内偏移，物理地址 = 段表.base + d。
- 分段保留语义、便于共享与保护，但**外部碎片回归**（本质是动态分区）。
- **段页式**段内分页：地址 = 段号 + 页号 + 偏移，段表→页表→页框三级转换。
- 段页式**兼得分页无碎片与分段有语义**，代价是三次访存（需缓存加速）。
- 三种方案是「等分 vs 语义」的取舍光谱，现代系统以分页为基、以段页式实现保护。
