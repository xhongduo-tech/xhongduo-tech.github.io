## 为什么从逻辑地址与物理地址开始

从死锁回到主线。操作系统管理资源，而**内存是最重要的资源**——所有进程的代码与数据都装在内存里。内存管理的起点是两个看似相近却天差地别的概念：**逻辑地址**（进程看到的）与**物理地址**（硬件看到的）。这两个地址之间的「翻译」机制，就是内存管理的全部技术演化史。<span class="marginnote">回顾进程概念：进程有独立地址空间。为什么能独立？因为每个进程用的是「自己的逻辑地址」，经翻译后才落到物理内存——互不打架。逻辑地址是进程的「幻觉空间」，物理地址是机器的「真实空间」。</span>

## 1 两个地址的定义

**物理地址（physical address）**：内存单元的硬件地址——从 0 到物理内存总量-1 的真实编号。CPU 通过物理地址访问物理内存。

**逻辑地址（logical address）**：程序生成的地址，是进程视角下的地址——从 0 开始，与物理地址**无关**。程序里的指针、变量地址都是逻辑地址。

**关键区别**：

- 同一个逻辑地址（如 0x1000）在不同的进程里，翻译后可能是**不同的物理地址**。
- 程序的链接、编译、跳转都基于逻辑地址——**程序从不知道、也不必知道物理地址**。

**逻辑地址有时也叫虚拟地址（virtual address）**，但严格说二者有细微差别（虚拟地址在分页/虚拟内存体系里，逻辑地址更泛指 CPU 生成的地址）。大多数教材把「逻辑地址」与「虚拟地址」混用。

## 2 地址翻译：MMU 的活

进程访问逻辑地址时，硬件**内存管理单元（MMU, Memory Management Unit）**负责把逻辑地址翻译成物理地址，再送去访存：

```
进程 CPU
  │ 生成逻辑地址 LA
  ▼
[MMU 地址翻译]
  │ 基址寄存器（relocation register）等
  ▼
物理地址 PA = LA + 基址
  ▼
物理内存
```

**最简单的翻译（重定位）**：物理地址 = 逻辑地址 + **重定位寄存器（relocation register）**中的基址。进程被装入物理内存的基址，例如基址 = 14000，则逻辑地址 346 翻译成物理地址 14346。

**辨析｜易错点：** 「逻辑地址是假的，物理地址是真的，翻译只是加法」——加法只是最简模型。**现代系统用分页/分段做翻译（见后续几篇），不是简单加基址**。简单加法模型（连续分配）的问题是：进程必须装在连续的内存块里，内存碎片严重。**翻译机制的复杂度，决定了内存管理的精致程度。**

## 3 为什么要翻译：三个好处

- **进程隔离**：每个进程从逻辑 0 开始，互不干扰——进程 A 的逻辑 100 与进程 B 的逻辑 100 翻译到不同物理区，天然隔离。
- **重定位（relocation）**：进程可以装在物理内存的任何位置——只要把基址告诉 MMU，逻辑地址不变。程序「搬家」无需修改代码。
- **保护**：MMU 可检查访问是否越界（超出该进程的物理范围），配合「界地址寄存器」实现保护（见《内存保护机制》）。

**重定位的好处尤其重要**：编译链接时程序不知道会装到哪，运行前才决定——这就是「从源码到运行」的最后一步（链接与装入），是下一节的主题。<span class="marginnote">「程序能装在任何位置」是重定位的核心价值：多道程序环境下，内存里有几十个进程，每个都从自己的物理基址开始，但逻辑地址都从 0 开始。<strong>逻辑地址让「写程序」与「装程序」彻底解耦</strong>——这是内存管理送给编程的礼物。</span>

## 4 核心对比表：逻辑地址 vs 物理地址

| 维度 | 逻辑地址 | 物理地址 |
| --- | --- | --- |
| 谁生成 | 程序/CPU（编译期与运行期） | MMU 翻译后的地址 |
| 空间 | 0 到逻辑空间上限 | 0 到物理内存上限 |
| 是否唯一 | 不唯一（多进程共用同一逻辑空间） | 唯一（每个物理单元一个地址） |
| 谁看见 | 进程（指针、跳转） | 硬件（访存） |
| 翻译 | — | 由 MMU 完成 |

**记忆主线**：**逻辑地址是「进程的世界」，物理地址是「机器的世界」，MMU 是翻译官。** 后面几篇的分页、分段、段页式，都是「翻译官」的不同任职方式。

## 5 小结

- **逻辑地址**：进程视角、从 0 开始、与物理位置无关；**物理地址**：硬件真实地址、唯一。
- **MMU** 负责翻译，最简单的模型是「物理 = 逻辑 + 重定位基址」。
- 翻译带来**隔离、重定位、保护**三大好处。
- 「逻辑地址与物理地址解耦」让程序与装位置无关，是多道程序的前提。
- 现代翻译用分页/分段，连续分配 + 基址只是最简起点。
