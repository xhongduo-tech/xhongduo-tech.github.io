## 为什么从交换开始

动态分区解决了「怎么分块」，但没解决「内存总不够」。进程越来越多、越来越大，物理内存就是不够用。**交换（swapping）**给出最朴素的方案：**把暂时不跑的进程整体搬去磁盘，腾出内存给要跑的进程。** 它是虚拟内存的前奏——虽然「整个进程搬」很粗，但「内存与磁盘之间搬移数据」的思想，正是请求分页的雏形。<span class="marginnote">回顾《进程状态》的七状态模型：挂起（suspend）状态就是把进程换到磁盘。交换技术是七状态模型的物理实现——就绪挂起、等待挂起都是「被换出的进程」。</span>

## 1 交换的机制：换出与换入

**交换（swapping）**：把进程从内存**换出（swap out）**到磁盘的交换区（backing store），或从磁盘**换入（swap in）**到内存。

基本流程：

1. 某进程被挂起（或新进程到达但内存不足）。
2. 把内存里的一个进程（通常是最久没用、优先级最低、或阻塞中的）**换出**到交换区，腾出空间。
3. 把需要的进程**换入**到腾出的空间。

**交换区（backing store）**：磁盘上划出的一块专门区域，用于存放被换出的进程映像。它的访问速度决定了交换的性能。

**换出 vs 换入的触发**：

**换出**：新进程到达但内存不足；或调度器决定降低某个进程的内存占用。
**换入**：被换出的进程被调度（要运行了），且内存有空位。

**交换与调度配合**：被换出的进程不在就绪队列（在挂起队列），调度器只调度内存中的进程——**换入换出与调度的联动**，是操作系统吞吐的关键（减少换入换出频率，否则系统忙于搬进程）。<span class="marginnote">交换时代的经典权衡：<strong>交换粒度 vs 上下文切换</strong>。如果每次都交换整个进程，系统大部分时间花在磁盘 I/O 上。现代 Linux 的「整页交换」已经是换出页面而非进程——交换技术从「整进程」演化为「整页」，演化的线索就是：搬得越细，浪费越少。</span>

## 2 交换的代价：为什么现在很少整进程交换

整进程交换的致命弱点：

**换出/换入的是整个进程映像**——哪怕进程只用了很少内存，也要搬全部地址空间，I/O 量巨大。
**交换开销与进程大小成正比**——进程越大，交换越慢；大进程换入换出一次可能是秒级。
**不能解决「进程本身大于内存」**：进程若比物理内存还大，交换也救不了（进程在内存里放不下）。

因此经典「整进程交换」在现代通用 OS 中几乎绝迹，取而代之的是**请求分页（demand paging）**——只换出进程**用到的那些页**，粒度细、效率高（见第九篇《虚拟内存》）。

**辨析｜易错点：** 「交换 = 虚拟内存」是常见混淆。**交换是「整个进程搬走」，虚拟内存（请求分页）是「按页搬」**。交换是整进程级别，虚拟内存是页级别——后者的粒度细得多，所以效率高得多。可以说交换是虚拟内存的「粗糙前身」，但二者机制不同。

## 3 交换的改进：现代变体

虽然整进程交换退场，但交换思想在现代系统中仍有大量化身：

**进程级 swap（Linux）**：Linux 仍在用 `swap` 分区/文件，换出的是**不常用的页面**，粒度是页而非整个进程——这是「页级交换」。
**移动设备的内存压缩（memory compression / zram）**：把不常用的内存页**压缩后**放在内存里，而不是搬到磁盘——用 CPU 换 I/O。
**休眠（hibernation）**：整机睡眠时把全部内存写到磁盘，唤醒时再读回——这是「整机交换」，粒度最大。

**设计启示**：交换的演化史就是「粒度变细」的历史——从整进程 → 整页 → 压缩页。**搬移的粒度越细，浪费越少，代价越小。** 这个「细粒度化」的方向，在缓存、分布式系统的数据迁移里反复出现。<span class="marginnote">zram 是个有趣的现代例子：与其把页搬到磁盘（慢 I/O），不如压缩后留在内存（快 CPU）。它把「换出」从「搬去哪」变成「怎么省空间」——空间优化没有唯一答案，只有当前硬件约束下的权衡。</span>

## 4 核心对比表：交换 vs 请求分页

| 维度 | 交换 | 请求分页 |
| --- | --- | --- |
| 搬移单位 | 整个进程 | 单个页 |
| I/O 量 | 大（全地址空间） | 小（按需） |
| 内存不足处理 | 换出进程 | 换出页面 |
| 进程大于内存 | 无法处理 | 可以（只装当前页） |
| 现代地位 | 退化为页级 swap | 虚拟内存核心 |

## 5 小结

- **交换**：内存不足时把进程整体搬到磁盘交换区，需要时再换回。
- 交换区是磁盘上的专用区域；换入换出与调度联动。
- 整进程交换的代价：I/O 量大、与进程大小成正比、救不了「进程大于内存」。
- 现代演化：**页级交换（Linux swap）**、内存压缩（zram）、休眠——粒度越来越细。
- 交换是虚拟内存的粗糙前身，「搬移粒度变细」是它的演化主线。
