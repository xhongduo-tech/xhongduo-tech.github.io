## 为什么从磁盘性能参数开始

上一节认识了磁盘结构，这一节把它量化为**可测的参数**——寻道时间、旋转延迟、传输率。这三个参数共同决定磁盘的 **I/O 吞吐与延迟**，也是后续磁盘调度算法（FCFS、SSTF、SCAN）要优化的对象。看懂这些参数，你就能读懂任何一块机械硬盘的规格表。<span class="marginnote">回顾上一节的访问时间公式：寻道 + 旋转 + 传输。这一节把三个分量分别展开，并讨论「随机访问 vs 顺序访问」如何被它们决定——磁盘调度的目标就是「减少寻道与旋转」。 </span>

## 1 三个核心参数

**寻道时间（seek time）**：磁头从当前磁道移动到目标磁道的时间。

- 取决于移动距离：跨越的磁道数越多越慢。
- 包含启动加速与停止减速（不是匀速）。
- 典型值：相邻磁道 0.5~2ms，全盘扫描 15~20ms，**平均约 5~10ms**。

**旋转延迟（rotational latency）**：目标扇区转到磁头下方的时间。

- 平均 = 半圈：$T_{rot\_avg} = \frac{60}{2 \times \text{RPM}}$。
- 7200 RPM → 4.17ms；15000 RPM → 2ms（转速越高延迟越低）。

**传输时间（transfer time）**：数据从盘面读出/写入的时间。

- 与数据量成正比，与记录密度和转速相关。
- **传输率（transfer rate）**：如 200 MB/s（现代 HDD 的顺序传输率）。

## 2 磁盘 I/O 时间的计算

**磁盘 I/O 时间 = 寻道 + 旋转延迟 + 传输时间**。实际规格里的「平均访问时间」通常是「平均寻道 + 平均旋转延迟」，不包含传输。

**示例计算**：访问一个 4KB 块，寻道 6ms，7200RPM，传输率 200MB/s。

- 平均旋转延迟 $= \frac{60}{2\times7200} = 4.17\text{ms}$。
- 传输时间 $= \frac{4\text{KB}}{200\text{MB/s}} = 0.02\text{ms}$。
- **总时间 $= 6 + 4.17 + 0.02 \approx 10.19\text{ms}$**——传输只占 0.2%，寻道+旋转占 99.8%。

**这个例子是存储系统设计的核心事实**：**一次随机访问的时间几乎全部花在「找位置」（寻道+旋转）上，真正传数据只占极小比例。** 于是：

- **随机 I/O 的吞吐 ≈ 1 / 访问时间**：10ms 一次随机访问，每秒最多约 100 次随机 I/O（IOPS）。
- **顺序 I/O 的吞吐 ≈ 传输率**：连续读几乎没有寻道与旋转等待，吞吐接近 200MB/s。

**随机 vs 顺序的吞吐差距可达百倍以上**——这是所有存储系统（文件系统、数据库、日志）追求「顺序化」的物理动机。<span class="marginnote">这解释了为什么数据库的 B+ 树、日志系统（LSM-tree、WAL）都拼命把随机写转成顺序写：<strong>一次随机写 ≈ 10ms，一次顺序追加 ≈ 微秒级</strong>。你会在数据库篇、分布式系统篇反复见到「顺序化」这个词——它的一切收益都源于本节这道算术题。</span>

## 3 影响磁盘性能的其他因素

- **转速（RPM）**：转速越高，旋转延迟越低、传输率越高（同样密度）。7200 家用、10000/15000 企业级。
- **记录密度**：密度越高，每圈存的数据越多，传输率越高。
- **磁道缓存（track cache）**：磁盘内置缓存，预读相邻数据，提升顺序访问与局部访问性能。
- **NCQ（原生命令队列）**：磁盘控制器重排等待的 I/O 请求，优化寻道顺序（硬件级磁盘调度）。
- **碎片化**：文件碎片化导致随机访问增加，`defrag`（碎片整理）把文件变连续，恢复顺序访问。

**辨析｜易错点：** 「传输率高的硬盘一定快」是常见误解。**规格表里的「传输率」是顺序传输率（理论峰值）；真实随机负载下的性能由寻道+旋转决定**——一块顺序 200MB/s 的硬盘，随机 4KB 读写可能只有 ~1MB/s 的有效吞吐。**看磁盘性能，先看 IOPS 与随机延迟，再看顺序传输率。**

## 4 核心对比表：三个参数的作用

| 参数 | 影响什么 | 受谁决定 | 优化手段 |
| --- | --- | --- | --- |
| 寻道时间 | 随机访问延迟 | 磁头移动距离 | 磁盘调度算法 |
| 旋转延迟 | 随机访问延迟 | 转速 | 提高 RPM |
| 传输率 | 顺序吞吐 | 转速 + 密度 | 提高 RPM/密度 |

## 5 小结

- 三大参数：**寻道时间**（磁头移动）、**旋转延迟**（半圈等待）、**传输率**（顺序吞吐）。
- 一次随机访问 ≈ 寻道 + 旋转 + 传输，**传输只占 <1%，寻道+旋转占 >99%**。
- **随机 I/O 的吞吐 ≈ 1/访问时间（IOPS）**，顺序 I/O 的吞吐 ≈ 传输率——差百倍以上。
- 存储系统「顺序化」设计的物理动机：**把随机访问转成顺序访问，绕开寻道+旋转**。
- 看磁盘性能先看 **IOPS 与随机延迟**，顺序传输率只是峰值参考。
