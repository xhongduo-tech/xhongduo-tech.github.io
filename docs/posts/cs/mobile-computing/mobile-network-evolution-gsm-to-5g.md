## 为什么从演进讲起

蜂窝系统原理回答了「小区怎么切、频率怎么复用」，但没有回答「网络到底由哪些设备组成、语音和短信是怎么跑起来的」。从 1980 年代的 1G 到今天 5G，移动通信经历了从模拟到数字、从电路到分组、从手机到万物互联的多次跃迁。每一次「代际」的跃迁，都伴随着一次**频谱效率、时延与业务形态**的根本改变。<span class="marginnote">看懂这条演进线，你就拿到了一张地图：后面讲移动 IP、TCP over wireless、MEC、传感器网络时，都能把具体技术对号入座到某一代网络里。</span>这一篇把 2G 到 5G 的主干讲清楚，重点落在 GSM 的架构、3G/4G 的关键变革与 5G 的新范式上。

## 1 从 1G 到 2G：模拟落幕，数字登场

**1G（第一代）**是模拟蜂窝系统，以 1980 年代美国的 AMPS 为代表。语音以连续波形式传送，保密性差、易被窃听、频谱效率低，且各国标准不一、无法漫游。

**2G（第二代）**以 **GSM（Global System for Mobile Communications）** 为全球标杆，实现了两个根本转变：**语音数字化**与**蜂窝标准统一**。GSM 把语音用 13 kbit/s 的 RPE-LTP 编码器压缩成数字比特，再经调制后发射；同时引入了 SIM 卡，把用户身份从手机硬件中分离出来——换机不换号成为可能。<span class="marginnote">GSM 全称里的「Global」当时是个雄心：让用户在全世界漫游。后来它真的成了事实标准，全球超过 80% 的移动用户一度在 GSM 家族内漫游。数字化的另一大红利是纠错：比特错误可以检测和纠正，通话质量不再随距离急剧劣化。</span>

GSM 采用 **FDMA/TDMA 混合多址**：900 MHz 频段被切成 124 个 200 kHz 的载频（FDMA），每个载频再按时隙切成 8 个信道（TDMA）。一个时隙就是一路用户连接，时隙 0 常被用作控制信道。

语音之外，GSM 还有一套完整的**信令（signaling）**体系：专用控制信道承载呼叫建立、位置更新、鉴权等控制消息，与用户数据信道严格分离。这套「数据与控制分路」的设计让网络可以精确定位用户、加密通信，也奠定了后续所有移动网络的公共框架。无线资源管理（RR）、移动性管理（MM）、连接管理（CM）三层的划分，今天仍能在 4G/5G 的信令协议栈里看到对应物。

## 2 GSM 的网络架构

GSM 的网络结构是理解移动网络的标准模板，值得拆开来看。它由三大部分组成：

**移动台（MS）**：手机本身，由移动设备（ME）与 SIM 卡构成。
**基站子系统（BSS）**：包括**基站收发台（BTS）**——覆盖一个小区的无线电收发设备；以及**基站控制器（BSC）**——管理几十个 BTS，分配无线信道、处理切换。
**网络与交换子系统（NSS）**：核心是**移动交换中心（MSC）**，负责呼叫接续、移动性管理；配套**归属位置寄存器（HLR）**与**访问位置寄存器（VLR）**记录用户的位置与业务信息。<span class="marginnote">HLR 是「用户户籍」：存用户签约信息与当前所在的 MSC/VLR 地址；VLR 是「暂住登记」：存当前在本区漫游的用户。位置更新就是 VLR/HLR 之间的登记同步——这个「户籍/暂住」二分法在《移动 IP 与移动性管理》一篇还会以更抽象的形式出现。</span>

**位置管理**是 GSM 的一个核心机制：把覆盖区划分成若干**位置区（LA）**，手机只在跨区时才向网络报告位置（位置更新），网络据此在寻呼时只在该位置区内广播寻呼消息，避免全网广播。这里有一个经典权衡：**位置区越大，位置更新越少但寻呼开销越大；位置区越小则相反**。<span class="marginnote">位置更新与寻呼是一对「省电/省信令」的矛盾：频繁更新耗手机电与信令，太少更新则寻呼要撒大网。这个权衡在移动 IP 里叫「update vs. search」的根本张力，是移动性管理的普适主题。</span>

## 3 2.5G 与 3G：分组数据与宽带码分

GSM 只擅长语音，传数据按电路计费且速度只有 9.6 kbit/s。**GPRS（2.5G）**引入**分组交换**：数据按 IP 分组传送，仅在传输时才占信道，理论速率升到约 171 kbit/s，并引入了 SGSN（服务 GPRS 支持节点）与 GGSN（网关 GPRS 支持节点）两类新网元，把移动网接到 IP 世界——这是「always on」概念的第一次落地。<span class="marginnote">GPRS 的分组核心网（SGSN/GGSN）是 4G/5G 核心网的直接祖先：GGSN 相当于今天的 PGW/UPF，负责与外部 IP 网络接轨。可以说「把移动网 IP 化」的工程从 GPRS 就开始了。</span>

**3G（第三代）**以 **WCDMA**（以及 CDMA2000、TD-SCDMA）为代表，采用宽带码分多址。相比 GSM 的窄带 TDMA，WCDMA 用 5 MHz 宽载波承载码分信道，理论下行速率达 2 Mbit/s（后经 HSDPA 演进到十几 Mbit/s）。WCDMA 首次大规模商用**软切换**与**快速功率控制**，语音质量与频谱效率大幅提升。这一代还首次把「移动宽带上网」做成了主流体验——手机从电话变成了多媒体终端。

3G 的中期升级 **HSPA**（HSDPA/HSUPA）值得单独留意：它引入**自适应调制编码（AMC）**与**快速调度**——信道好就上 16-QAM、一次多调度，信道差就退回 QPSK——把「信道随时变」从敌人变成了可以榨取的信息。这套「信道越好越快」的自适应思想，后来原封不动地进入了 LTE 与 5G 的调度器，是理解 4G 速率可变性的钥匙。<span class="marginnote">HSPA 的高速率本质上来自「多用户分集」：三个用户轮流用最好信道的那个，叠加起来吞吐远高于单用户。4G 的频选调度（把每个子载波分给信道最好的人）正是这套思想的精细化。</span>

## 4 4G LTE：全 IP 与 OFDMA

4G 以 **LTE（Long Term Evolution）**为代表，做了一次彻底的架构革命：**全 IP 化**——语音也从电路域搬进分组域（VoLTE），网络里只剩一张 IP 包交换网。LTE 的空中接口改用 **OFDMA（正交频分多址）**：把宽带信道切分成大量窄带正交子载波，用户按需分配子载波块。<span class="marginnote">OFDM 的窄子载波使每个子信道近似平坦衰落，配合循环前缀抵抗符号间干扰，抗多径能力远胜 CDMA——这是 4G 能在同样带宽里跑出更高速率的关键物理基础。它其实脱胎于几十年前的军用与广播技术，工程史上并不罕见。</span>

LTE 核心网叫 **EPC（演进分组核心）**，网元包括 MME（移动性管理实体）、S-GW（服务网关）、P-GW（分组数据网关）。相比 GSM 的网元罗列，EPC 把控制面（MME）与用户面（S-GW/P-GW）分离——这一「控制与转发分离」的设计，是后来 5G 与 SDN 思想的直接伏笔。

全 IP 化的一个直接后果是**语音必须找到新载体**。LTE 用 **VoLTE（Voice over LTE）**解决：语音作为 IP 分组走 IMS（IP 多媒体子系统）承载，端到端走 QoS 优先队列，时延与音质反而优于 2G/3G。**LTE 还引入了 QCI 承载等级**——同一部手机可以同时跑语音（高优先级）与下载（尽力而为），网络按等级调度，互不拖累。这种「一张网里多级服务」的能力，正是 5G 网络切片的小规模预演。

## 5 5G NR：新空口与新范式

5G 的空中接口叫 **NR（New Radio）**，它在三个方向同时突破：

**三大场景**：增强移动宽带（eMBB，峰值 10 Gbit/s 量级）、超可靠低时延（URLLC，时延 1 ms 量级）、海量机器类通信（mMTC，每平方公里百万级连接）。<span class="marginnote">5G 的野心不只是「更快的手机」，而是「连接万物」：URLLC 服务工业控制与自动驾驶，mMTC 服务大规模物联网——这正是《无线传感器网络基础》一篇的前置铺垫。</span>
**灵活参数集（numerology）**：子载波间隔可按 15 kHz 的整数倍缩放（15/30/60/120 kHz），配以可变的帧结构，同一套物理层同时适配低频大覆盖与高频大带宽。
**毫米波与大规模 MIMO**：在 24 GHz 以上频段使用数百天线阵做波束成形，用空间维度弥补路径损耗；大规模 MIMO 让频谱效率再上一个台阶。

5G 的**双工方式**也做了细分：**FDD（频分双工）**用两个频率分别收发，适合对称业务与大覆盖；**TDD（时分双工）**用一个频率分时收发，上下行资源可灵活配比，更适合非对称的移动互联网流量，且无需成对频谱。中国主流 5G 频段多为 TDD，这背后是「业务不对称、频谱稀缺」两个现实共同推动的结果。<span class="marginnote">TDD 与 FDD 之争在 Wi-Fi 里也有对应：Wi-Fi 本质上是半双工（同一信道分时收发），靠退避避免碰撞。理解「对称业务用 FDD、非对称用 TDD」这条原则，就能看懂运营商频谱规划的很多选择。</span>

5G 核心网 **5GC** 采用**服务化架构（SBA）**：网元拆成微服务式的网络功能（NF），用 RESTful 接口互相调用，支持网络切片——在同一张物理网络上切出多个逻辑网络，分别服务手机、车联网与工业互联网。**这就是「软件定义一切」在移动网里的最终形态**。配合**MEC（移动边缘计算）**，5GC 还能把计算下沉到基站侧，让低时延应用不必绕行核心网——这正是《移动边缘计算》一篇要展开的主题，也是「从极限到大模型」主线里「把算力放到数据旁边」这一思想的通信侧表达。

把各代核心网并列，能看到一条清晰的「去集中化 + IP 化」主线：

| 代际 | 核心网 | 关键网元 | 主要特性 |
| --- | --- | --- | --- |
| 2G GSM | NSS | MSC / HLR / VLR | 电路交换，语音优先 |
| 2.5G GPRS | 分组域新增 | SGSN / GGSN | 引入 IP 分组交换 |
| 3G WCDMA | 电路+分组并存 | MSC / SGSN / GGSN | 移动宽带起步 |
| 4G LTE | EPC | MME / S-GW / P-GW | 全 IP，控制转发分离 |
| 5G | 5GC | AMF / SMF / UPF | 服务化架构，网络切片 |

这张表里的每个网元名称不必死记，但**「网元从专用交换机走向通用 IP 网元、再走向云原生微服务」的轨迹**值得记住——它与云计算里「从物理机到虚拟机到容器」的演化如出一辙，两条主线在同一本教材里相遇。

## 6 公式解析：从 1G 到 5G 的频谱效率跃迁

把各代际放到同一把尺子上比较，最好的指标是**频谱效率**——每赫兹每小区能传的比特数：

$$\eta = \frac{C}{B \cdot N_{\text{cells}}} \quad (\text{bit/s/Hz/cell})$$

以单小区单用户、无扇区的理想化口径估算：

| 代际 | 关键技术 | 典型下行速率 | 每扇区带宽 | 频谱效率量级 |
| --- | --- | --- | --- | --- |
| 2G GSM | TDMA/FDMA | 约 10 kbit/s | 200 kHz | 约 0.05 bit/s/Hz |
| 3G WCDMA | CDMA + 软切换 | 约 2 Mbit/s | 5 MHz | 约 0.4 bit/s/Hz |
| 4G LTE | OFDMA + MIMO | 约 100 Mbit/s | 20 MHz | 约 5 bit/s/Hz |
| 5G NR | OFDMA + 大规模 MIMO | 约 1 Gbit/s | 100 MHz | 约 10 bit/s/Hz |

把第四行套进公式：$\eta = 1\ \text{Gbit/s} / (100\ \text{MHz} \times 1) = 10$ bit/s/Hz——比 2G 高出两个数量级。
