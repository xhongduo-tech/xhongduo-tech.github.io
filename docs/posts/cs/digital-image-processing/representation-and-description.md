## 为什么从表示与描述开始

分割把目标从背景里「切」了出来，但切出来的是一堆像素。要让机器说「这是个圆」「这块布是棉的」「这个零件的形状符合公差」，必须先把像素块**表示**成紧凑的形式，再从中提取**描述子**（特征）。这就是本专题的收尾章节：**表示（representation）**解决「用什么结构去近似目标」（边界还是区域？），**描述（description）**解决「用什么数字去刻画目标」（长度、形状、纹理、矩？）。它上承分割、下接识别与检索——字符识别里的骨架、工业质检里的几何公差、图像检索里的纹理向量，都从这里起步。走到这里，数字图像处理的经典主线「获取 → 增强 → 复原 → 彩色 → 压缩 → 形态学 → 分割 → 描述」正好闭环。

## 1 从分割到描述：先表示，后描述

目标一旦被分割出来，第一步是决定**表示**策略——它取决于目标是「重形状」还是「重内部」：

- **边界表示（boundary representation）**：只关心目标的**轮廓**。适合形状识别：字符、零件轮廓、细胞膜。上一节形态学的边界提取正是入口。
- **区域表示（region representation）**：关心目标的**内部填充**。适合纹理、质地区分：布料、皮肤、木材纹理。

边界表示的经典方法：**链码（chain code）**沿边界行走，每一步记一个方向编号（4-方向或 8-方向）。<span class="marginnote"><strong>辨析｜易错点：</strong> 链码对起点与旋转敏感——同一个圆从不同像素开始走，码串完全不同。解决是<strong>归一化</strong>：把码串循环移位到「字典序最小」以消去起点依赖；把相邻方向码做差得到<strong>差分链码</strong>以消去旋转依赖。表示到描述之间，处处是对「不变性」的追求。</span>

区域表示的经典方法：把区域用它的**骨架**（形态学章节的剥洋葱结果）或一组**中轴**描述，也可用区域的**外接矩形、凸包、包围圆**等外包络近似。

## 2 公式解析：傅里叶描述子

把边界看成复数平面上的点序列 $s(k) = x(k) + j\,y(k)$，$k = 0, 1, \dots, K-1$。对 $s$ 做离散傅里叶变换：

$$a(u) = \sum_{k=0}^{K-1} s(k)\, e^{-j2\pi uk / K}, \qquad u = 0, 1, \dots, K-1$$

系数 $a(u)$ 称为**傅里叶描述子（Fourier descriptor）**。逐项拆解：

- **把边界翻译成复数**：$x$ 坐标作实部、$y$ 坐标作虚部，一条二维闭合曲线变成一维复数序列——傅里叶的现成对象。
- **低频系数 $a(0), a(1), \dots$**：决定边界的大致形状；**高频系数**决定边界的细节毛刺。
- **用前 $P$ 个系数重建**：$P$ 远小于 $K$ 时得到一条「去毛刺」的平滑边界；$P$ 越小越模糊——傅里叶描述子天然支持形状的「精度旋钮」。
- **不变性**：$a(0)$ 是边界质心（平移量），其余系数与旋转、尺度、起点相关，但可以标准化——取模消去旋转、除以 $|a(1)|$ 消去尺度，得到平移旋转尺度不变的形状签名。

直觉上，傅里叶描述子把「边界的形状」压缩成「少数几个低频系数」——这就是上一节频率域思想在形状分析上的直接回响。<span class="marginnote"><strong>与全局特征呼应</strong>：傅里叶描述子是「形状的频率签名」，和图像本身的傅里叶频谱一样遵守「低频=概貌、高频=细节」的谱系逻辑。一个闭曲线无论多复杂，前 10 个系数已能锁定它的大形。</span>

## 3 区域描述：矩与形状度量

区域描述用**统计量**刻画内部填充。最通用的是**矩（moment）**。二维图像 $f(x,y)$ 的 $(p+q)$ 阶矩与中心矩：

$$m_{pq} = \sum_x \sum_y x^p y^q f(x, y), \qquad \mu_{pq} = \sum_x \sum_y (x - \bar{x})^p (y - \bar{y})^q f(x, y)$$

其中 $\bar{x} = m_{10}/m_{00}$、$\bar{y} = m_{01}/m_{00}$ 是区域的质心。<span class="marginnote"><strong>矩的语义</strong>：$m_{00}$ 是区域面积；$\mu_{20}, \mu_{02}$ 度量水平与垂直方向的散布；$\mu_{11}$ 度量倾斜。把中心矩归一化到尺度不变，再组合出<strong>七个 Hu 矩</strong>，得到平移、旋转、尺度不变的形状特征——它们是模板匹配、形状检索里「不看具体像素、只看形状数值」的经典武器。</span>

派生的形状度量：

**紧致度（compactness）**：$(\text{周长})^2 / (4\pi \cdot \text{面积})$，圆取最小值 1，越细长的形状越大。
**圆形度（circularity）**：$4\pi \cdot \text{面积} / (\text{周长})^2$，紧致度的倒数形式。
**离心率（eccentricity）**：区域二阶矩导出的主轴长短之比，刻画「偏椭」程度。
- **凸性（convexity）**：区域面积 / 凸包面积，度量「有多接近凸」。

## 4 纹理描述：统计、结构与频谱

**纹理（texture）**描述区域内部的重复性结构。三大流派：

**统计方法**：用灰度直方图的统计量描述纹理——**灰度共生矩阵（GLCM）**统计「相距 $(\Delta x, \Delta y)$ 的两像素灰度对 $(i, j)$ 出现的频率」。从 GLCM 导出**对比度、能量、熵、相关性**四个经典特征：能量大说明纹理均匀，熵大说明纹理杂乱。<span class="marginnote"><strong>辨析｜易错点：</strong> 灰度直方图（一阶统计）与 GLCM（二阶统计）的能力差一个维度——直方图只能描述「有哪些灰度」，GLCM 才能描述「灰度怎么相邻分布」。砂纸与纸张的灰度直方图可能几乎相同，但 GLCM 的对比度会截然不同。</span>

**结构方法**：把纹理看作基本纹理元的规则排列。适合规则纹理（砖墙、蜂巢），描述「纹理元 + 排列规则」。

**频谱方法**：纹理在频域有指纹——用傅里叶谱的**径向分布**（距中心的环带能量）与**角向分布**（沿方向的能量）描述纹理的粗细与方向性。粗纹理能量集中在低频，细纹理能量扩散到高频。<span class="marginnote">频谱纹理与傅里叶描述子共用同一套频率语言：一个描述「形状」的频率签名，一个描述「纹理」的频率签名。至此，频率域的思想在形状、纹理、压缩、配准四个方向上分别落了地。</span>

## 5 描述子与识别：收束到分类

描述子最终要供**分类**使用——把描述向量喂给分类器（第三级《机器学习》里的最近邻、贝叶斯、SVM）判断目标类别。描述子的选择决定特征空间的好坏：好的描述子让同类目标聚成一簇、异类分开，分类器只需一条简单分界线；差的描述子则让分类器在重叠的数据里挣扎。这正是在深度学习之前，图像识别「手工特征 + 分类器」范式的完整一环——直到卷积网络把「特征」本身也学了出来（第四级《深度学习》）。<span class="marginnote"><strong>为什么学经典描述子仍有价值</strong>：今天的深度特征虽然更强，但理解「什么量应当不变（平移/旋转/尺度）、什么统计能区分纹理」，仍是设计数据增强、理解网络学到什么的底层直觉。经典描述子是这层直觉最浓缩的教科书。</span>

## 6 描述子：从形状到识别的工作流

把本节的全部描述子串成一条「从分割到识别」的完整流水线：

1. **分割**：得到目标的二值掩膜（上一节）。
2. **表示**：选择边界链码或区域掩膜，视「重形状还是重内部」而定。
3. **初级描述**：面积、周长、紧致度、离心率等标量——先得到几个「手感」数字。
4. **进阶描述**：傅里叶描述子（形状）、GLCM 统计（纹理）、Hu 矩（不变矩）。
5. **分类**：把描述向量喂给分类器，输出类别。

**描述子的选择直接影响识别上限**——描述得好，最近邻分类器就够用；描述得差，再强的分类器也无力回天。这是特征工程里「数据决定上限」的又一次体现。

| 描述目标 | 推荐描述子 | 为什么 |
| --- | --- | --- |
| 字符形状 | 骨架 + 结构特征 | 笔画拓扑对字体粗细不敏感 |
| 零件轮廓 | 傅里叶描述子 | 自动去毛刺、可控精度 |
| 布料/皮肤 | GLCM 纹理 | 捕获灰度相邻关系 |
| 树叶/细胞 | Hu 矩 | 平移旋转尺度不变 |
| 指纹 | 细节点（分叉/端点） | 拓扑结构唯一性强 |

**傅里叶描述子的归一化再辨析**：取模消旋转、除以 $|a(1)|$ 消尺度——但注意这只对「闭合、无自交」的边界严格成立；自交边界会让系数语义混乱。使用前检查边界的「良态性」，是容易被忽略的前提。

**GLCM 的工程参数**：偏移 $(\Delta x, \Delta y)$ 常用 $(1,0)$、$(0,1)$、$(1,1)$ 三个方向各取一个，取平均增强鲁棒性；灰度级常量化到 8 或 16 级（而不是 256）以压缩矩阵规模——量化到多少级，本身就是一个权衡。

**矩与主成分的联系**：区域的二阶中心矩构成协方差矩阵，其特征向量给出区域的主轴方向——这正是离心率的来源，也是「用二阶统计量描述形状」与「PCA 描述数据散布」（第三级《机器学习》）的同构关系。

**为什么「形状 + 纹理」常常一起用**：单独用形状描述分不清「同样的形状、不同的纹理」（两种面料同款剪裁）；单独用纹理描述分不清「同样的纹理、不同的形状」（同一面料的两种版型）。把两者拼接成联合描述向量，是检索系统「以图搜图」的常见做法。

**描述的「尺度意识」**：同一目标在近景与远景中，面积、周长都变，但紧致度、离心率这类归一化描述子不变——这就是「尺度不变」的价值。设计描述子时，先问「什么量应当不变」，再决定用什么统计量，是描述子设计的第一性问题。

**纹理描述的一个直觉**：粗糙的沙子放大后仍是一团颗粒，光滑的丝绸放大后仍是一条平滑——「放大后看起来像什么」，决定了该用统计还是结构还是频谱描述。先看纹理的「尺度行为」，再选方法。

**经典描述子与现代识别**：深度学习把「手工设计特征」变成了「自动学习特征」，但「表示 → 描述 → 分类」的流水线结构从未改变——CNN 的每一层都在做「表示」，最后的全连接层在「分类」。学经典描述子，是在学这条流水线的「第一性原理」。

**描述的「信息量」权衡**：标量描述（面积、周长）信息量低但极稳健，向量描述（傅里叶系数、GLCM 特征）信息量高但对噪声更敏感。工程上的常见策略是先用力矩等稳健标量粗筛，再用向量描述细分类——由粗到细，兼顾稳健与区分力。

## 7 小结

- **表示先行，描述后随**：边界表示适合形状，区域表示适合纹理；链码要差分 + 循环归一化消去起点与旋转依赖。
- **傅里叶描述子**：把边界写成复序列做 DFT，前 $P$ 个系数重建即得去毛刺形状；标准化后平移/旋转/尺度不变。
- **矩**：$m_{00}$
