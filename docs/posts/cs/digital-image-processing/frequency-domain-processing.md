## 为什么从频率域开始

空间域滤波处理的是「像素」，但有一类现象在空间域里解释困难：周期性的纹理噪声、缓慢变化的光照不均、需要精确裁切的频带。把这些现象放进**频率域**，一切豁然开朗——傅里叶变换把图像从「每个点有多亮」翻译成「每个频率有多强」。低频对应平缓区域，高频对应边缘与噪声。**频域滤波**因此有了空间域不具备的优势：一次变换之后，所有的滤波都变成「乘一个滤波器」这样直白的事。傅里叶变换在第二级《复变函数与积分变换》里是理论工具，在这里则变成了图像处理的生产工具；它与第六级《数字信号处理》的 DFT/FFT 完全同源，只是搬到了二维。

## 1 另一种视角：把图像当作波

空间域里，图像是 $f(x, y)$ 的灰度值；频率域里，图像被看成**无数个不同频率的正弦波叠加**。低频正弦波对应灰度的缓慢变化（天空、墙壁），高频正弦波对应剧烈变化（边缘、噪声、纹理）。

**傅里叶变换（Fourier transform）**就是把「空间坐标 → 频率」的翻译机。一维情形下，任意信号可展开为不同频率 $u$ 的分量之和；二维图像则是空间频率 $(u, v)$ 的二维铺展。变换后的系数 $F(u, v)$ 的幅度 $|F(u, v)|$ 叫**频谱（spectrum）**，它告诉我们在频率 $(u, v)$ 处有「多强的波」。

一个直觉实验：一块纯灰色区域，空间域是一整片常数；变换到频率域，能量全部集中在**直流分量** $F(0, 0)$（频率为零的波），其他频率几乎为零。而一块棋盘格，空间域是黑白相间的周期图案；频率域在对应周期的频率处出现两个尖峰。<span class="marginnote"><strong>辨析｜易错点：</strong> 频谱图的中心并不是「原点的像素」——$F(0,0)$ 是直流分量，对应图像的平均亮度，通常要把频谱做中心化（fftshift）后才把直流挪到画面中央。初学者看到频谱图中央一团亮，那多半是平均亮度，不是某个真实的结构频率。</span>

## 2 二维离散傅里叶变换（2D DFT）

数字图像是离散的，所以用**离散傅里叶变换**。设图像尺寸 $M \times N$：

$$F(u, v) = \sum_{x=0}^{M-1} \sum_{y=0}^{N-1} f(x, y)\, e^{-j2\pi \left( \frac{ux}{M} + \frac{vy}{N} \right)}$$

逆变换恢复原图：

$$f(x, y) = \frac{1}{MN} \sum_{u=0}^{M-1} \sum_{v=0}^{N-1} F(u, v)\, e^{j2\pi \left( \frac{ux}{M} + \frac{vy}{N} \right)}$$

两个关键性质必须立住：<span class="marginnote"><strong>可分离性</strong>：二维 DFT 可以拆成「先对每行做一维 DFT、再对每列做一维 DFT」，于是二维变换的成本由 $O(M^2 N^2)$ 降到两次一维的 $O(MN(M+N))$；再配合快速傅里叶变换（FFT），一幅 $1024 \times 1024$ 图像的 DFT 从天文数字降到毫秒级。这是「频率域处理能落地」的根本原因。</span>

**对称性与共轭**：实值图像的频谱关于原点共轭对称，$F(u, v) = F^*(-u, -v)$，所以频谱有一半是冗余的——这是压缩章节会再利用的性质。

## 3 频域滤波的标准流程

频域滤波的全部过程浓缩为四步：

1. 计算原图 $f$ 的 DFT，得 $F$；
2. 构造**滤波器传递函数** $H(u, v)$（低通、高通、带通……）；
3. 逐频率相乘 $G(u, v) = H(u, v) \cdot F(u, v)$；
4. 逆变换回空间域 $g = \mathcal{F}^{-1}(G)$。

为什么乘一个 $H$ 就能滤波？因为 $H$ 是一个「频率的闸门」：$H$ 在低频处为 1、高频处为 0，就放行低频、拦下高频——这正是低通。空间域里要设计一套模板系数，频域里只需画一条频率响应曲线。<span class="marginnote"><strong>卷积定理</strong>是这一切的保证：空间域卷积 $\Leftrightarrow$ 频率域相乘。上一节空间域滤波是「直接卷积」，这一节的频域滤波是「变换 → 相乘 → 逆变换」，两者在数学上等价。代价是一次 DFT + 一次 IDFT，收益是滤波器的设计自由度（可精确切出任意频带）。</span>

## 4 公式解析：二维 DFT 的读法

对 $M = N = 8$ 的简单图像，取 $u=1, v=0$ 的分量：

$$F(1, 0) = \sum_{x=0}^{7} \sum_{y=0}^{7} f(x, y)\, e^{-j2\pi \frac{x}{8}}$$

- **$\sum_{x=0}^{7}\sum_{y=0}^{7}$**：对全部 $8 \times 8 = 64$ 个像素求和——每个输出频率都要「看遍整幅图」，这正是傅里叶变换的非局部性。
- **$e^{-j2\pi \frac{x}{8}}$**：单位模长的复指数，绕单位圆转圈。它按行坐标 $x$ 构造一个「横向波」：$x$ 每增 1，相位前进 $2\pi/8$，$x$ 走完 8 格正好绕一圈，即频率 $u=1$ 的基波。
- **$(u,v) = (1,0)$**：波只在 $x$ 方向振动、$y$ 方向恒定——所以 $v$ 项的指数为 0。$u$、$v$ 一个管横向、一个管纵向，两个方向的频率正交叠加。
- **求和的结果**：64 个像素对这个「单位频率横波」的相关值。若图像本身在横向就是 $u=1$ 的周期图案，各像素与基波同相叠加，$|F(1,0)|$ 很大；否则相互抵消，接近零。

对每个 $(u, v)$ 重复这套求和，就得到整幅频谱。**谱图的可视化**需要先取对数（$|F|$ 的动态范围动辄跨越 6 个数量级，不取对数几乎全黑），再中心化——上一节学的对数变换在这里派上了用场。

## 5 频域滤波器家族

**低通滤波器**（理想、巴特沃斯、高斯）：保留低频、平滑图像。高斯低通 $H(u,v) = e^{-D^2(u,v)/2D_0^2}$ 没有振铃（ripple）现象，是最温和的选择；理想低通在截止频率处陡峭截断，逆变换后在边缘处出现振铃——这是「频域陡峭」的代价。

**高通滤波器**：$H_{HP} = 1 - H_{LP}$，保留高频、锐化图像。高通同时放大了噪声，因此实践中常用**高频提升滤波** $H = a + b \cdot H_{HP}$，保留一部分低频做底，避免锐化过度。

**带阻 / 带通与陷波**：拦掉（或只留）特定频带。**陷波滤波**针对频谱上对称的两个尖峰，专门压制周期性噪声——比如扫描照片上叠加的莫尔条纹，在频域就是一对刺眼的亮点，陷波把它们挖掉，周期性噪声便消失。<span class="marginnote">这就是频率域相对空间域最「无可替代」的场景：周期性噪声在空间域弥散全图、无从下手，在频域却浓缩成几个孤立尖峰。读得懂频谱，就找得到病灶。</span>

## 6 频域 vs 空间域：两条路线的对照

频域滤波与空间域滤波在数学上等价，但工程上各有适用面。用一张对照表把差异固定下来：

| 维度 | 空间域滤波 | 频域滤波 |
| --- | --- | --- |
| 操作 | 模板与邻域卷积 | 变换后逐频率相乘 |
| 直观性 | 直接，逐像素 | 需要频谱想象 |
| 大模板 | 计算量随模板尺寸平方增长 | 一次 FFT 后成本固定 |
| 精确切频带 | 困难，模板近似 | 精确，传递函数直接画 |
| 周期性噪声 | 几乎无解 | 陷波滤波一招制敌 |
| 局部处理 | 天然局部 | 全局，局部要开窗 |

**一个关键结论**：滤波器**尺寸大**时选频域划算（FFT 总成本基本固定），**尺寸小**时选空间域划算（$3 \times 3$ 模板每像素 9 次乘加，比 FFT 便宜得多）。工程上，$3 \times 3$、$5 \times 5$ 的滤波几乎都用空间域实现；而大尺寸高斯模糊、去模糊（维纳滤波）、周期性噪声抑制，才值得进频域。

**为什么要学两种表示**：因为「频域设计、空间域实现」是滤波器设计的标准工作流——在频域里画一个理想低通（几分钟），反变换得到空间域核（可能很大），再截断成有限模板。这样既有频域的设计自由度，又有空间域的局部性。

**频率域的边界效应**：DFT 假设图像是周期延拓的，图像左右边缘在频域里是「相邻」的——这会在边界制造虚假的高频。解决是零填充（padding）或边缘延拓后再变换，处理完裁掉填充区。

**再谈一次可视化**：频谱图中心是直流、向外频率递增。要判断一幅图「哪里是周期性噪声」，先看频谱里有没有成对的孤立亮点；要判断「图像是否清晰」，看高频能量是否丰富——这两条是频率域阅读的最基本体检。

**实际频谱长什么样**：自然图像绝大多数能量集中在低频（DC 附近的尖峰），频谱能量随频率快速衰减——这解释了为什么 DCT/小波压缩能把大部分系数量化成零（见本篇《图像压缩》）。「自然图像 ≈ 低频为主 + 少量高频细节」，是频率域一切经验的出发点。

**如何挑选低通截止频率 $D_0$**：$D_0$ 越小越模糊。经验起点是取频谱尺寸的 1/10 到 1/5（对 $1024 \times 1024$ 即约 100–200），再根据目测微调。振铃是否明显，是判断「是否用理想低通过度了」的直接信号。

**一段自检流程**（理解思路）：

```
1. 对原图做 FFT，看中心化后的频谱形态；
2. 构造 H(u,v)，与 F 逐点相乘；
3. 逆变换，比较平滑/锐化程度与振铃；
4. 若出现振铃，改用高斯型 H 并减小 D_0。
```

**高通滤波的视觉陷阱**：单纯高通滤波后图像会发灰——因为直流被滤掉了，平均亮度归零。必须用高频提升 $H = a + bH_{HP}$ 保留一部分直流，这也是「高通 = 1 − 低通」公式在实际中总要配一个 $a$ 的原因。

**频谱的相位其实比幅度更关键**：把图像 A 的幅度谱与图像 B 的相位谱组合后逆变换，看到的几乎全是 B 的内容——说明视觉结构主要由相位携带，幅度谱主要决定「能量分布」。这也是为什么压缩、去噪在幅度上动手脚，而对相位要格外小心。

## 7 小结

- **傅里叶变换**把图像从空间坐标翻译成频率：低频 = 平缓，高频 = 边缘/噪声。
- **2D DFT** $F(u,v) = \sum_x \sum_y f e^{-j2\pi(ux/M + vy/N)}$ 把图像翻译成频率；可分离性 + FFT 让它可落地。
- **频域滤波四步**：DFT → 构造 $H(u,v)$ → 相乘 → 逆变换；卷积定理是「频域相乘 = 空间域卷积」的保证。
- **选型**：大模板、周期性噪声、精确切频带进频域；小模板留在空间域。频谱可视化需取对数 + 中心化。
- **关键性质**：实值图像频谱共轭对称（一半冗余可再利用）；自然图像能量集中于低频，是压缩与去噪的经验起点。

在下一节，我们面对「图像已经坏了」的现实——**图像复原与重建**将基于退化模型把原图算回来，并首次接触「求逆会放大噪声」这一反问题的核心矛盾。
