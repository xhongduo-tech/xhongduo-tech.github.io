## 为什么从小波开始

傅里叶变换有一个根本局限：它的基函数是覆盖整个时域/空域的正弦波，**一个频率分量属于全局，却没有「位置」信息**。图像里一个 5 px 的小噪点，在频谱上只是一丝高频涟漪，你无法从频谱读出「它在哪里」。**小波（wavelet）**用一簇局部化的、可伸缩平移的小波函数代替无限延伸的正弦波，让「频率」与「位置」同时被记录。多分辨率分析（MRA）则给图像搭了一座尺度金字塔：先看概貌，再看细节，逐层逼近。小波变换正是 JPEG2000 压缩的核心引擎，也是去噪、融合、纹理分析的标准工具——学完它，上一节傅里叶的「盲区」才被补齐。

## 1 从傅里叶到小波：时频定位之困

傅里叶变换把信号分解成正弦波的叠加，正弦波**只有频率、没有位置**。对一段含有个别尖峰的信号，频谱能告诉你「有高频」，却指不出「尖峰在第几个样本」——这就是**全局基的局限**。

短时傅里叶变换（STFT）曾试图补救：用窗函数把信号切成小段，逐段做傅里叶。但窗一旦选定，时频分辨率就被钉死——窗短则频率分辨率差，窗长则时间定位差，无法两全。这就是著名的**不确定性原理**（测不准关系在信号分析中的体现）。<span class="marginnote"><strong>辨析｜易错点：</strong> 不确定性是数学内禀的，不是算法不够好——时间分辨率与频率分辨率的乘积有下界。小波并没有「破解」不确定性，而是用「高频段用窄窗、低频段用宽窗」的自适应策略，把有限的分辨率预算花在最需要的地方。这正对应着人耳对声音的处理：高音需要精确定位时刻，低音需要精确判断音高。</span>

小波变换的基函数是小波母函数 $\psi(x)$ 的伸缩和平移族：

$$\psi_{a,b}(x) = \frac{1}{\sqrt{a}}\, \psi\!\left( \frac{x - b}{a} \right)$$

$a$ 控制伸缩（尺度），$b$ 控制平移（位置）。**尺度 $a$ 越大，小波越宽，看低频概貌；$a$ 越小，小波越窄，看高频细节**——一套函数，通吃所有尺度。

## 2 多分辨率分析：图像的尺度金字塔

**多分辨率分析（multi-resolution analysis, MRA）**的核心思想：图像的内容分属不同尺度，应该逐层展开。最基本的实现是**图像金字塔**：

- **高斯金字塔（Gaussian pyramid）**：逐层低通滤波 + 降采样。第 $j$ 层是第 $j-1$ 层尺寸减半的模糊版本——从精到粗，一层一层「只看轮廓」。
- **拉普拉斯金字塔（Laplacian pyramid）**：每层记录「上一层高斯金字塔与该层的差值」，即**被金字塔丢掉的细节**。原图 = 最粗层 + 逐层细节的累加，可无损重建。

$$\text{Laplacian}_j = \text{Gaussian}_j - \text{expand}(\text{Gaussian}_{j+1})$$

<span class="marginnote">拉普拉斯金字塔是「分解 → 压缩 → 重建」的天然框架：细节层能量少、可大幅量化，概貌层能量集中但尺寸小。<strong>辨析｜易错点：</strong> 降采样前必须先低通滤波，否则产生<strong>混叠（aliasing）</strong>——高分辨率里的小纹理会被「折」成低分辨率里的假纹样。这个「先滤波后抽样」的顺序在金字塔、小波、JPEG2000 里处处是铁律。</span>

## 3 小波变换：连续到离散

**连续小波变换（CWT）**对连续尺度 $a$ 和平移 $b$ 计算内积 $W(a, b) = \langle f, \psi_{a,b}\rangle$，信息冗余大、无法工程实现。实用的**离散小波变换（DWT）**把 $a, b$ 都取成 2 的幂的网格：$a = 2^j$、$b = k\,2^j$。此时 $\psi_{j,k}(x) = 2^{-j/2}\psi(2^{-j}x - k)$ 构成一组正交基。

二维 DWT 用**可分离滤波器**实现：先对每行做一次低通/高通滤波并降采样（得到 L 与 H），再对每列做同样操作。一次二维分解把图像分成四个子带：

**LL**（横竖都低通）：概貌，尺寸 1/4；
**LH**（竖低横高）：水平边缘细节；
**HL**（竖高横低）：垂直边缘细节；
- **HH**（横竖都高通）：对角细节。

下一次分解只对 LL 继续递归——于是有了「左上角一个缩小的概貌，周围三面环绕不同方向细节」的经典小波图。<span class="marginnote">这个「LL 递归、细节旁置」的结构正是 JPEG2000 的骨架：概貌层是低分辨率预览，细节层按重要性排序供渐进式传输。图像压缩章节我们还会回来。</span>

## 4 公式解析：哈尔小波与滤波器组

最朴素也最能说明原理的是**哈尔（Haar）小波**。它的尺度函数与母小波分别取「两段平」与「一高一低」的矩形：

$$\varphi(x) = \begin{cases} 1, & 0 \le x \lt  1 \\ 0, & \text{其他} \end{cases}, \qquad \psi(x) = \begin{cases} 1, & 0 \le x \lt  0.5 \\ -1, & 0.5 \le x \lt  1 \\ 0, & \text{其他} \end{cases}$$

对一个长度为 2 的信号对 $(x_0, x_1)$，一次哈尔分解输出两个系数：

$$\text{近似：} a = \frac{x_0 + x_1}{\sqrt{2}}, \qquad \text{细节：} d = \frac{x_0 - x_1}{\sqrt{2}}$$

- **近似系数 $a$**：两项之和，反映局部均值——低频概貌。
- **细节系数 $d$**：两项之差，反映局部起伏——高频细节。
- **$\sqrt{2}$ 归一化**：保证变换是正交的（能量守恒），$x_0^2 + x_1^2 = a^2 + d^2$。
- **重建**：$x_0 = (a + d)/\sqrt{2}$，$x_1 = (a - d)/\sqrt{2}$——和与差互逆，无损往返。

对整幅图像反复作用这个「和/差」运算，就得到多级小波分解。**辨析｜易错点：** 哈尔小波简洁但不平滑，重建图像会有「砖块感」；工程上更常用 Daubechies 系（db2、db4）等具有更多消失矩的小波，边缘更光滑、压缩效率更高，但滤波器系数不再是简单的 ±1。

## 5 小波的应用

**去噪**：小波分解后，噪声能量均匀散布在大量小系数上，而真实结构的能量集中在少数大系数上。对细节系数做**软阈值 / 硬阈值**处理（把绝对值小于阈值的系数置零，或向零收缩），再逆变换，噪声被「扣」掉而结构基本保留——这比空间域均值滤波精细得多。

**压缩**：小波域里大量系数接近零，量化 + 熵编码可高效压缩。JPEG2000 用「小波 + 嵌入式编码」，支持渐进传输与 ROI（感兴趣区域）高保真，比 JPEG 的 DCT 方案抗块效应更强。

**图像融合**：把多聚焦、多传感器的图像分别小波分解，在每层子带里按「能量更大、细节更清晰」的原则挑选系数，再逆变换合成——得到比任何单幅输入都清晰的融合结果。<span class="marginnote">医学影像（CT 骨窗 + MRI 软组织）、遥感多光谱融合、手机夜景多帧合成，都是这套「分解-选择-重建」在工程里的变体。小波不是唯一的工具，但它是把「尺度」这个概念用得最系统的一个。</span>

## 6 小波、傅里叶与图像的尺度观

小波不是来「取代」傅里叶的，而是补它的盲区。两者的对照是理解整个多分辨率思想的钥匙：

| 维度 | 傅里叶变换 | 小波变换 |
| --- | --- | --- |
| 基函数 | 全局正弦波 | 局部化、可伸缩的小波 |
| 频率 | 精确 | 按尺度分带 |
| 位置 | 无 | 有（平移参数 $b$） |
| 分辨率 | 全频带一致 | 高频窄窗、低频宽窗 |
| 典型应用 | 频谱分析、滤波 | 去噪、压缩、融合 |

**一条贯穿全章的主线**：图像里的结构有尺度之分——一个文字是「小尺度」（局部笔画），一栋楼是「中尺度」，一座城市是「大尺度」。多分辨率分析的价值，正是让不同尺度的结构「各归其位」：概貌层管大结构，细节层管小结构。这个「按尺度拆解」的思路，也直接对应着计算机视觉里图像金字塔（多尺度检测）、深度学习里卷积的感受野分层。

**金字塔在工程里的广泛使用**：目标检测里的多尺度检测（在不同金字塔层上跑同一个检测器）、模板匹配里的由粗到细搜索（先在最粗层定位、再逐层细化）、以及 SIFT 的尺度空间，全部建立在「图像金字塔」这个基础设施上——理解多分辨率分析，是理解这些现代算法的一把钥匙。

**小波去噪的阈值选择**：对小波系数做阈值时，阈值越大去噪越彻底、细节损失也越多。一个经验起点是取「通用阈值」$\lambda = \sigma\sqrt{2\ln N}$（$\sigma$ 是噪声标准差，$N$ 是像素数）——它来源于高斯噪声的极值统计，是软硬阈值的常用基准。

**离散小波的实现直觉**：一次二维小波分解 = 行方向低通/高通 + 列方向低通/高通，各降采样一半。若把「低通」想成「取平均」、把「高通」想成「取差值」，就得到了最朴素的哈尔小波——图像压缩里的「概貌 + 细节」两股信息流，从这个最简单的运算开始。

**小波分析的一个隐藏收获**：因为小波系数天然区分「概貌」与「细节」，它在「渐进式传输」里的价值是傅里叶给不了的——先传概貌系数，用户立即看到低分辨率全图；再传细节系数，图像逐步变清晰。这正是「先粗后细」的用户体验。

**为什么 JPEG2000 没普及**：除了计算成本，另一个原因是许可证与专利纠纷。技术最优不等于商业成功，JPEG2000 至今主要活跃在医学影像（DICOM 支持）与专业摄影（RAW 中间格式）等特定领域。

**小波系数图怎么读**：分解结果里，左上角是层层缩小的概貌，右侧与下侧是不同方向、不同尺度的细节系数。亮像素表示该处该尺度有显著结构，暗像素表示接近零。扫一眼系数图，就能判断「图像在哪个尺度最丰富」。

**为什么叫「小波」**：wavelet 即「小波」——母小波是一个快速衰减的短波（非零区间有限或迅速趋零），与无限延伸的正弦波形成对照。这个「局部化」特征是它能定位时空事件的根源。

**与卷积网络的一次对话**：小波分解与 CNN 的每层结构惊人相似——都做「滤波 + 降采样」，都在不同尺度提取特征。区别是小波的滤波器是手写的、可逆的，CNN 的滤波器是学出来的、通常不可逆。理解小波，是理解「多尺度表示」如何被机器自动发现的一座桥梁。

## 7 小结

- **傅里叶的局限**：全局基函数没有位置信息；STFT 用窗换取定位，却受不确定性原理制约。
- **小波** $\psi_{a,b}(x) = a^{-1/2}\psi((x-b)/a)$
