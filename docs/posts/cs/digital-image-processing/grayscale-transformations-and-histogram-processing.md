## 为什么从灰度变换开始

上一节我们拿到了数字图像——一个 $M \times N$ 的灰度矩阵。绝大多数时候，这张图不是「拿来就能用」的：夜晚的照片暗得看不清细节，扫描件灰蒙蒙一片，X 光片对比度不足。**灰度变换与直方图处理**是图像处理里最廉价、最直白的一类操作：不动像素的空间结构，只改写每个像素的灰度值。它是「先给直觉再上工具」的最佳示范——没有卷积、没有变换域，一套映射函数加一张统计直方图，就能解决大量实际问题。这些操作在后续每个章节（滤波、复原、分割）的预处理阶段都会反复出现，也是理解深度学习之前图像增强的经典底座。

## 1 灰度变换：逐像素映射

设输入图像在 $(x, y)$ 处的灰度为 $r$，输出为 $s$。**灰度变换**用一个函数把每个像素独立映射：

$$s = T(r)$$

其中 $T$ 是映射函数。因为每个像素只依赖自身、与邻居无关，这类操作又叫**点运算（point operation）**。<span class="marginnote">点运算有三个用途层次：<strong>对比度拉伸</strong>（把窄灰度区间展宽）、<strong>灰度级切片</strong>（把某段灰度单独高亮，常用于突出感兴趣区域）、<strong>比特平面分层</strong>（把 8 bit 的每个位平面拆出来看）。三者都是同一函数形式的不同设计。</span>

灰度变换的实现天然就是查表：图像只有 $L$ 种灰度，把 $T$ 对 $0,1,\dots,L-1$ 各算一次，得到一张 $L$ 长度的查找表（LUT），此后每个像素只需一次取表。$L = 256$ 时这张表只有 256 个条目，成本可以忽略——这是「小函数撬动大矩阵」的典型例子。

## 2 三类基本变换

### 反转变换

$$s = L - 1 - r$$

把黑变白、白变黑。常用于处理白底黑字的医学影像：乳腺 X 光片中原本黑背景上的白色钙化点，反转后更符合「亮点即病灶」的阅读习惯。

### 对数变换

$$s = c \log(1 + r)$$

对数曲线在低灰度段陡、在高灰度段平缓，因此**把窄的低灰度范围展宽、把高的宽范围压缩**。<span class="marginnote">对数变换的典型应用是傅里叶谱的可视化：频谱动态范围极大（直流分量可能是其他分量的几十万倍），直接显示几乎全黑；取 $\log$ 之后才能看到中高频的丰富结构。这个技巧在频率域章节会反复用到。</span>

### 幂律（伽马）变换

$$s = c r^{\gamma}$$

$\gamma$ 是核心参数。$\gamma \lt  1$ 时作用类似对数（把暗部提亮），$\gamma > 1$ 时相反（把亮部压暗）。<span class="marginnote"><strong>伽马校正</strong>之名由此而来：CRT 显示器对输入电压的响应近似 $r^{2.5}$，为抵消这种非线性，图像在被送出前要预先乘 $r^{1/\gamma}$。今天所有显示器的色彩管理里都还留着这个痕迹——手机相册里「调节亮度」的直觉，本质是调 $\gamma$。</span> 与对数变换相比，伽马变换多一个可调参数，控制力更强，是工程中最常用的灰度映射。

## 3 直方图：图像的统计画像

**直方图（histogram）**统计每个灰度级出现的像素个数：

$$h(r_k) = n_k, \qquad k = 0, 1, \dots, L-1$$

其中 $r_k$ 是第 $k$ 级灰度，$n_k$ 是灰度等于 $r_k$ 的像素数。归一化后 $p(r_k) = n_k / MN$ 近似灰度分布的概率密度，且 $\sum_k p(r_k) = 1$。

直方图是一张「统计快照」，能一眼看出一幅图的质量：

- **暗图像**：直方图集中在低灰度一侧；**亮图像**：集中在高灰度一侧。
- **低对比度**：直方图收窄成一条细柱，占据的灰度范围很窄。
- **高对比度**：直方图铺满整个灰度范围且分布均匀——这通常是「理想图像」的特征。

读直方图的能力，是后面一切增强、分割、阈值选择的基础。你不需要知道图像内容，单看直方图形状就能判断「要不要做增强、往哪个方向增强」。

## 4 公式解析：直方图均衡化

**直方图均衡化（histogram equalization）**的目标是把灰度分布拉平：让每个灰度级的像素数尽量接近，从而把图像原本稀疏使用的灰度范围充分铺开。它的核心是变换

$$s_k = T(r_k) = (L-1) \sum_{j=0}^{k} p(r_j)$$

逐项拆解：

- **$p(r_j) = n_j / MN$**：灰度 $r_j$ 的归一化频率，也就是「灰度 $j$ 的像素占比」。
- **$\sum_{j=0}^{k}$**：从 0 到 $k$ 的累加——这使 $T$ 成为**累积分布函数（CDF）**，单调不减。
- **$s_k$**：原灰度 $r_k$ 映射到的新灰度。因为 CDF 单调，排序关系被保持，不会出现「原来亮的变暗」的倒置。
- **$(L-1)$**：把 CDF 值域（$[0,1]$）缩放回 $[0, L-1]$ 的灰度范围。

直觉上，均衡化是在「搬移」直方图的柱子：把密集的灰度区间拉伸、把稀疏的区间压缩。<span class="marginnote"><strong>辨析｜易错点：</strong> 均衡化并不保证输出直方图绝对平坦——因为灰度级是离散的、像素个数是整数，均衡化只是「近似均匀」。少数灰度级会被合并（多个输入灰度映射到同一输出），信息在这一步是有损失的。</span>

## 5 直方图匹配与局部增强

均衡化是自动的，但有时我们需要输出具有指定形状的直方图——比如希望图像偏暗以保留夜景氛围。这时用**直方图匹配（规定化，histogram matching / specification）**：先对输入做均衡化变换 $s = T(r)$，再对目标直方图求它的均衡化变换 $G(z)$，最后反解 $z = G^{-1}(s)$，把两步复合起来。这就是「通过均衡化作中间桥梁」的两段式映射。

直方图还有**局部（邻域）版本**：全局均衡化用整幅图的统计，而**局部直方图均衡化**在一个滑动窗口内计算直方图并只对中心像素应用变换。窗口滑动到哪，统计就重算到哪——计算量大一个数量级，但能同时增强图像中明暗差异悬殊的区域，是全局方法做不到的。<span class="marginnote">局部增强是「空间域滤波」的先行者：以邻域为处理单元、逐像素滑动，这个模式下一节的空间滤波将全面采用。区别只在滤波器里的「窗口内操作」从直方图变成了卷积。</span>

## 6 灰度变换的工程工具箱

把三类变换与直方图工具放在一起，正好构成一张「按需取用」的对照表：

| 需求 | 首选工具 | 为什么 | 参数参考 |
| --- | --- | --- | --- |
| 提亮暗部 | 伽马变换 $\gamma \lt  1$ | 曲线在低灰度段更陡，暗部被拉伸 | $\gamma \approx 0.4$–0.7 |
| 压暗过曝 | 伽马变换 $\gamma > 1$ | 高灰度段被压缩 | $\gamma \approx 1.5$–2.5 |
| 扩展窄动态范围 | 对比度拉伸 | 灰度区间线性映射到全范围 | 映射端点 |
| 自动增强 | 直方图均衡化 | 无需调参，CDF 直接拉开分布 | 无 |
| 指定风格 | 直方图匹配 | 输出直方图形状可控 | 目标直方图 |
| 局部光照不均 | 局部直方图均衡化 | 按窗口统计，明暗分治 | 窗口大小 |

伽马变换与对数变换的适用边界值得再辨析一次：两者都在低灰度段更陡，但**对数变换无参数、形状固定**，适合「不管怎样先压动态范围」的场景（如频谱可视化）；**伽马变换多一个 $\gamma$，可精细调形**，适合需要定量控制明暗的场景（如显示校正）。实践里先给一张图试 $\gamma$，再决定要不要换对数，是效率最高的路径。

直方图工具还有一个常被忽略的作用：**质量诊断**。扫描件发灰、显示器偏暗、夜间照片过黑——先看直方图形状再决定处理方向，能避免「盲目均衡化把本来就正常的图调得发灰」。均衡化适合「灰度分布挤在中间」的图，对已经高对比度的图反而有害。

**一组数字直觉**：均衡化后的理想直方图接近均匀，但离散图像的灰度级有限，被合并的灰度级数目与图像内容有关——平坦区域多的图，合并更剧烈。因此均衡化效果「目测最明显」的，恰恰是那些原本直方图最集中的图。

还有一类更稳健的变体——**对比度受限的自适应直方图均衡化（CLAHE）**：它把图像分成小块分别均衡化，并对局部直方图做限幅，防止平坦区域的噪声被过度放大，是医学影像增强的默认选择。这已经是「全局工具」向「局部工具」过渡的桥头堡，下一节的空间滤波会系统地走上这条局部化之路。

这一整套「先看直方图、再选变换、最后验证」的工作流，正是灰度处理从「试参数」走向「有方法」的分水岭——它也是后续所有增强章节反复出现的方法论骨架。

**人眼的对数感知**：人眼对亮度的感知近似对数——暗处的绝对亮度差比亮处更「显眼」。这解释了为什么伽马变换（形状类似对数）在暗部拉伸最有效：它顺应了人眼的感知曲线。理解这一点，灰度变换就不再是「试参数」，而是「顺着感知调曲线」。

## 7 小结

- **灰度变换** $s = T(r)$ 是点运算：反转、对数、伽马三类基本映射，伽马变换参数最灵活。
- **直方图** $h(r_k) = n_k$ 是灰度分布的统计画像，形状直接反映图像明暗与对比度。
- **直方图均衡化** $s_k = (L-1)\sum_{j=0}^k p(r_j)$ 用 CDF 拉伸灰度分布，输出接近均匀但非严格平坦。
- **直方图匹配**与**局部均衡化**（含 CLAHE）在「指定输出风格」与「光照不均」时各有所长。
- **工程工作流**：先看直方图形状诊断，再选变换工具，最后验证——这是后续一切增强的方法论骨架。

在下一节，我们让每个像素不再「只看自己」，而是与邻居协作——进入**空间域滤波（平滑/锐化）**，用模板与邻域加权运算处理整片结构。
