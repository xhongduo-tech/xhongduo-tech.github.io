## 为什么从工作负载特征化开始

前两篇回答了「测什么」和「怎么测」，但还缺最关键的一块拼图：**拿什么去测**。一台新服务器要验证是否够用，随便跑一个程序得出的数字毫无意义——**负载必须有代表性**。真实系统承受的请求千差万别：有的是短小高频的查询，有的是耗时长的大事务，有的一天 24 小时平稳，有的在晚高峰暴涨。<span class="marginnote">工作负载特征化（workload characterization）是性能评估的「食材采购」：测量工具只是锅碗，负载才是下锅的菜。菜选错了，厨艺再好端出来的也是错味。</span>

这一篇讲清楚：**如何把一个复杂的真实使用场景，浓缩成一组可复现、有代表性的测试条件**。

## 1 什么是工作负载

**工作负载（workload）**：系统在运行期间实际承受的全部输入，包括请求的类型、频率、大小、到达时间与资源消耗。对一个 Web 服务器，工作负载是「每秒到达多少请求、每请求读多少字节、CPU 密集还是 I/O 密集」；对一个数据库，是「读多还是写多、事务多长、热点数据在哪」。

工作负载在三个粒度上被描述：

**指令混合（instruction mix）**：各类指令（整数、浮点、访存、分支）占总指令的比例，描述 CPU 级别的行为。<span class="marginnote">指令混合是《计算机组成原理》与《计算机体系结构》评测 CPU 的经典语言——SPECint、SPECfp 的本质就是一组精心配比好的指令级负载。</span>

**内核行为（kernel behavior）**：CPU 密集、I/O 密集还是内存密集，决定瓶颈在哪个子系统。

**应用行为（application behavior）**：具体业务层面的模式，如「读多写少」「冷热数据分明」。

## 2 特征化的维度

特征化就是把负载拆成可测的维度，常用的几根轴：

**频率与大小**：请求多久来一个（到达率）、每个请求多大（请求大小分布）。大小分布常是长尾的——大多数请求很小、少数请求极大，这直接决定缓存策略与容量余量。

**资源需求**：每个请求对 CPU、内存、磁盘、网络的消耗比例。一个请求占多少资源，决定系统能不能扛住给定并发。

**时间特性**：到达是平稳的还是突发的？交互式用户的到达常被建模为**泊松过程**——每瞬间到达一个请求的概率只与到达率相关，与过去无关。<span class="marginnote">泊松过程是《概率论与数理统计》与《随机过程》的经典模型；它的「无记忆性」让排队论的计算成为可能，但要注意：现代网络流量往往比泊松更「聚集」。</span>

**辨析｜易错点：** 许多性能测试只用一个「平均请求」打天下。但真实负载的方差往往比均值更重要——**90% 的小请求 + 10% 的大请求，与 100% 的中等请求，均值相同、系统表现天差地别**。特征化必须记录分布，而非只记均值。

## 3 到达模式：泊松与自相似

请求到达的模式，是排队论与容量规划的核心输入。最经典的模型是**泊松到达**：到达间隔服从指数分布，均值为 $\frac{1}{\lambda}$。它的数学性质极好——无记忆、可叠加、稳态分析简单，是 M/M/1 排队模型（第 8 篇）的前提。

但真实的计算机网络流量常呈现**自相似（self-similar）**特性：在任何时间尺度上放大看，突发模式都长得一样——小的突发套着大的突发。<span class="marginnote">自相似流量由 Leland、Taqqu 等人 1993 年在以太网流量的实测中揭示，它颠覆了「流量可被泊松近似」的假设：长相关让排队积压比泊松预测的大得多。</span>

这对工程的意义是双重的：一方面，**基于泊松假设的容量估计会低估突发场景的需求**；另一方面，自相似负载的模拟需要能产生长相关序列的生成器（第 7 篇《模拟与仿真方法》会涉及）。

## 4 公式解析：三种均值的正确选择

工作负载特征化绕不开一个看似简单、实则充满陷阱的问题：**多个负载值，取什么平均？** 处理时间取算术平均，速率取调和平均，比率取几何平均——选错平均值，结论就反了。

**算术均值（arithmetic mean）**，用于同一量纲的「时间」类数据：

$$\bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n}$$

**几何均值（geometric mean）**，用于「比率」类数据（如相对于基准的加速比）：

$$G = \left(\prod_{i=1}^{n} x_i\right)^{\frac{1}{n}}$$

**调和均值（harmonic mean）**，用于「速率」类数据（如每秒处理多少任务）：

$$H = \frac{n}{\frac{1}{x_1} + \frac{1}{x_2} + \cdots + \frac{1}{x_n}}$$
