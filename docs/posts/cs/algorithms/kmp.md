## 为什么从 KMP 开始

有限自动机匹配线性但构造 $O(m^3|\Sigma|)$ 且依赖字符集；**KMP** 用**前缀函数（prefix function）**在 $O(m)$ 内获得全部「回退信息」，匹配 $O(n)$——**严格线性、与字符集无关**。<span class="marginnote">KMP 是字符串匹配的「黄金标准」：三作者分别独立发现（Knuth-Pratt 与 Morris），1977 年发表。它回答了朴素算法的核心浪费——「已匹配的前缀信息被丢弃」——通过预先计算「模式自己与自己匹配」的表格，失配时知道「回退多少恰好还能继续」。</span>

这一课讲前缀函数的定义、KMP 匹配、以及那个反直觉的 $O(m)$ 构造分析。

## 1 前缀函数：模式的自匹配信息

**前缀函数（prefix function）** $\pi[q]$：对 $q \ge 1$，$\pi[q]$ = 模式 $P$ 的**真前缀**同时是 $P[1..q]$ 的**真后缀**的最大长度。

$$\pi[q] = \max\{ k : k < q \text{ 且 } P[1..k] \text{ 是 } P[1..q] \text{ 的后缀} \}$$

例：$P = ababaca$，$\pi = [0, 0, 1, 2, 3, 0, 1]$。$\pi[4] = 2$（$P[1..4] = abab$ 的最长真前缀-后缀是 $ab$，长 2）。<span class="marginnote">前缀函数是自动机 $\delta$ 的「压缩版」：$\delta(q,a)$ 问「读 $a$ 后回退到哪」，而 $\pi[q]$ 问「模式自己失配时回退到哪」。KMP 的洞察是：匹配阶段只关心「$a = P[q+1]$ 成功」与「否则回退 $\pi$」两种情况，$\pi$ 足够完成全部「回退」任务，无需字符集大小的表。</span>

## 2 KMP 匹配算法

```
KMP-MATCHER(T, P)
1  n = T.length
2  m = P.length
3  π = COMPUTE-PREFIX-FUNCTION(P)
4  q = 0                                // 已匹配的字符数
5  for i = 1 to n                       // 扫描文本，i 从不回退
6      while q > 0 and P[q+1] ≠ T[i]
7          q = π[q]                     // 安全回退到 π[q]
8      if P[q+1] == T[i]
9          q = q + 1
10     if q == m                         // 找到一处完整匹配
11         print "Pattern occurs with shift" i − m
12         q = π[q]
```

**思想**：文本指针 $i$ **从不回退**；只有模式指针 $q$ 在失配时回退到 $\pi[q]$——而 $\pi[q]$ 保证「回退后，已匹配的前缀仍与文本对齐」。<span class="marginnote">「$i$ 不回退、$q$ 回退到 $\pi[q]$」是 KMP 的全部。回退到 $\pi[q]$ 的安全性：$P[1..q]$ 是文本后缀，而 $\pi[q]$ 是「$P[1..q]$ 的最长真前缀-后缀」——所以 $P[1..\pi[q]]$ 也匹配文本，不必重比。这个「安全回退」把朴素算法的重复比较全部省掉。</span>

## 3 公式解析：前缀函数构造为什么是 $O(m)$

```
COMPUTE-PREFIX-FUNCTION(P)
1  m = P.length
2  let π[1..m] be a new array
3  π[1] = 0
4  k = 0                                // 当前最长匹配前缀长度
5  for q = 2 to m                       // P 匹配 P 自己
6      while k > 0 and P[k+1] ≠ P[q]
7          k = π[k]
8      if P[k+1] == P[q]
9          k = k + 1
10     π[q] = k
11 return π
```

与匹配循环同构（$P$ 匹配 $P$ 自己）。**复杂度 $O(m)$**——为什么 while 循环总次数是线性的？

**第一步，$k$ 的变化**：每次匹配成功 $k$ 加 1；while 里 $k = \pi[k]$ 严格减小。
**第二步，摊销论证**：$k$ 最多加到 $m-1$ 次（每轮至多 +1），而每次 while 循环把 $k$ 减至少 1——**总减少次数 ≤ 总增加次数 ≤ $m$**。
**第三步，结论**：while 总执行 $O(m)$ 次，外层 $O(m)$，总 $O(m)$。

**要点**：$k$ 的「先加后减」被摊销——**增加有限，减少也有限**。这是摊还分析在 KMP 的又一次应用。<span class="marginnote">同样的摊销论证适用于匹配阶段：$q$ 每字符至多 +1（共 $n$ 次），while 里 $q = \pi[q]$ 严格减小——总回退 ≤ 总前进 ≤ $n$。所以匹配阶段也是 $O(n)$。KMP 的双重线性（构造 $O(m)$ + 匹配 $O(n)$）都靠这个「单调回退」证明。</span>

**辨析｜易错点：** while 条件里的 $q = m$ 不能省——$q = 0$ 时没有「可回退的前缀」，直接尝试匹配 $P[1]$。$P[m+1]$ 的索引也要小心：$q = m$ 时 $P[m+1]$ 越界，所以匹配到 $m$ 后先 $m$ 再继续。

## 4 KMP 复杂度与自动机的关系

| 算法 | 预处理 | 匹配 | 依赖字符集 |
| --- | --- | --- | --- |
| 朴素 | 无 | $O(nm)$ | 否 |
| Rabin-Karp | $O(m)$ | 期望 $O(n+m)$ | 否（哈希） |
| 自动机 | $O(m^3\|\Sigma\|)$ | $O(n)$ | **是**（表大小） |
| KMP | $O(m)$ | $O(n)$ | **否** |

KMP 同时拿下「线性预处理」与「线性匹配」，且不依赖字符集——它是「实用最优」的经典。<span class="marginnote">理论上最优的字符串匹配算法（如 Z-algorithm、Two-Way）常数更小；KMP 的价值在于<strong>思想清晰</strong>——前缀函数是「自匹配」这一概念的化身，也是后缀自动机、AC 自动机、周期检测的理论基础。理解了 $\pi$，理解了一族算法。</span>

## 5 数值算例：算 π 并匹配一段文本

**构造前缀函数**：$P = \text{ababaca}$（$m = 7$）。逐 $q$ 算（$k$ 是「当前最长匹配前缀长度」）：

| $q$ | $P[q]$ | 动作 | $k$ | $\pi[q]$ |
| --- | --- | --- | --- | --- |
| 1 | a | 初始化 | 0 | 0 |
| 2 | b | $P[1]{=}a \ne b$ | 0 | 0 |
| 3 | a | $P[1]{=}a = a$，$k{+}1$ | 1 | 1 |
| 4 | b | $P[2]{=}b = b$，$k{+}1$ | 2 | 2 |
| 5 | a | $P[3]{=}a = a$，$k{+}1$ | 3 | 3 |
| 6 | c | $P[4]{=}b \ne c$，回退 $k=\pi[3]=1$，$P[2]{=}b \ne c$，回退 $k=0$，$P[1]{=}a\ne c$ | 0 | 0 |
| 7 | a | $P[1]{=}a = a$，$k{+}1$ | 1 | 1 |

得 $\pi = [0,0,1,2,3,0,1]$。<span class="marginnote">第 6 步的「两级回退」是前缀函数构造最精彩的一笔：$q=6$ 读到 c 时，前缀匹配从 $k=3$ 一路回退到 0——因为 $\text{aba}$ 后接 c 构不成任何「前缀-后缀」，只能从头再试。这轮回退 $k: 3\to1\to0$ 正是「while 循环总回退 ≤ 总前进」摊销论证的微观实例。</span>

**跑匹配**：文本 $T = \text{ababacababaca}$。

| $i$ | $T[i]$ | 匹配动作 | $q$ |
| --- | --- | --- | --- |
| 1–6 | a b a b a c | 全匹配 $P[1..6]$ | 6 |
| 7 | a | $P[7]{=}a$ 匹配 → $q = 7 = m$ | **匹配（位移 0）**，$q=\pi[7]=1$ |
| 8–12 | b a b a c | 从 $q=1$ 续接 | 6 |
| 13 | a | $q = 7 = m$ | **匹配（位移 6）** |

文本中 `ababaca` 出现在位移 0 与 6 两处，全部命中。<span class="marginnote">注意位移 0 匹配后 $q$ 回退到 $\pi[7] = 1$——因为文本接下来是 `babacababaca`，其前缀 `b` 恰好与 $P$ 的 `ab` 对齐，所以<strong>不必回到 0，直接续 $q=1$</strong>。这就是「回退到 $\pi$」省掉重复比较的现场：13 个字符、13 次主循环，$i$ 从未回退。</span>

## 6 小结

- **前缀函数** $\pi[q]$：$P[1..q]$ 的最长真前缀-后缀长度——「失配后能安全续接的长度」。
- **KMP 匹配**：文本指针不回退，失配时模式回退到 $\pi[q]$——$O(n)$。
- **构造**：$P$ 匹配 $P$ 自己，$O(m)$（$k$ 的摊销：增加 ≤ 减少）。
- 数值算例：$P=\text{ababaca}$ 得 $\pi=[0,0,1,2,3,0,1]$，在 $\text{ababacababaca}$ 中命中位移 0 与 6。
- 与自动机的关系：$\pi$ 是 $\delta$ 的压缩，免去字符集大小的表。
- 双线性 $O(m) + O(n)$，不依赖字符集——实用最优的经典。
