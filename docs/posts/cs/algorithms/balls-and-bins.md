## 为什么从球与箱子开始

我们随机化了输入，但这只是第一步——随机性带来的**量化收益**需要一个能精确计算的模型来体现。球与箱子（balls and bins）就是这样的模型：把 $n$ 个球独立均匀地投入 $n$ 个箱子，问**负载最大的箱子装了多少个球**。<span class="marginnote">这个模型是「哈希表」「负载均衡」「路由」的抽象原型。理解了它，就理解了为什么哈希表摊还 O(1)、为什么 Web 服务器随机分发请求时单台压力不会爆炸——因为最大负载只有 $O(\log n / \log\log n)$。</span>

上一课的指示器随机变量足够算期望，但**本课需要的是「上界」**：不仅要知道平均负载是 1，还要以高概率保证「没有箱子超过某个界」。这引出了随机分析的另一件武器——**布尔不等式与切尔诺夫界**。

## 1 问题设定与直觉

设 $n$ 个球逐一独立均匀地投入 $n$ 个箱子。对每个箱子 $b$ 和每个球 $i$，定义指示器

$$X_{ib} = I\{\text{球 } i \text{ 落入箱子 } b\},\qquad \Pr[X_{ib}=1] = \frac{1}{n}$$

箱子 $b$ 的负载 $X_b = \sum_{i=1}^n X_{ib}$，其期望为 $\mathbb{E}[X_b] = n \cdot (1/n) = 1$。**平均负载是 1**——但「平均是 1」完全不等于「每个箱子最多 1 个」：许多箱子为空，同时某些箱子堆积多个球。<span class="marginnote">这是概率论给算法设计的第一个警醒：期望只是均值，我们真正关心的是「以高概率不发生坏事」。平均分析与高概率界的差距，正是从「朴素概率」走向「尾不等式」的地方。</span>

直觉上，某个箱子有 $k$ 个球的概率是 $\binom{n}{k}(1/n)^k(1-1/n)^{n-k}$，二项分布。但 $n$ 个箱子里**最大的那个**怎么算？这需要比单个箱子的分布更精细的联合论证。

## 2 两个基本概率工具

### 布尔不等式（Boole's Inequality）

对任意事件族 $\mathcal{A}_1, \dots, \mathcal{A}_m$：

$$\Pr\left[\bigcup_{i=1}^{m} \mathcal{A}_i\right] \le \sum_{i=1}^{m} \Pr[\mathcal{A}_i]$$

也叫**并集界（union bound）**。它把「至少一件事发生」上界化为「各件事概率之和」——虽然粗糙，但在处理「任何箱子超载」这类「存在型」事件时极其有用。

### 切尔诺夫界（Chernoff Bound）

对独立伯努利变量之和 $X = X_1 + \cdots + X_n$（$\mathbb{E}[X] = \mu$），有

$$\Pr[X \ge (1+\delta)\mu] \le \left(\frac{e^{\delta}}{(1+\delta)^{1+\delta}}\right)^{\mu},\qquad \forall \delta > 0$$

它的直觉：二项分布的尾部以**指数速率**衰减。对「有 $\ge k$ 个球落入同一箱子」这种事件，切界给出指数上界——这是得到 $O(\log n / \log\log n)$ 的关键。

## 3 公式解析：最大负载为什么是 $O(\log n / \log \log n)$

我们推导「任意箱子负载 $\ge 3 \ln n / \ln \ln n$ 的概率很小」。设 $k^* = 3\ln n / \ln\ln n$，用切尔诺夫界的简化形式：

$$\Pr[X_b \ge k^*] \le \frac{e^{k^*-1}}{(k^*)^{k^*}}$$

对这条式子做三步拆解：

- **第一步，代入简化界**：把 $(1+\delta)\mu = k^*$、$\mu = 1$ 代入切界的等价形式 $\Pr[X \ge k] \le e^{k-1}/k^k$。这一步是把「球落进箱子」的二项分布尾部换成可计算的上界。
- **第二步，估算 $k^k$ 的量级**：$k^* = 3\ln n/\ln\ln n$，则 $k^* \ln k^* = (3\ln n/\ln\ln n)(\ln\ln n - \ln\ln\ln n + O(1)) \approx 3\ln n$。于是 $(k^*)^{k^*} = e^{k^* \ln k^*} \approx e^{3\ln n} = n^3$。
- **第三步，套并集界**：$\Pr[\text{存在箱子负载} \ge k^*] \le n \cdot \Pr[X_1 \ge k^*] \le n \cdot e^{k^*}/n^3 = O(e^{k^*}/n^2) = o(1/n)$。

结论：**以至少 $1 - o(1/n)$ 的概率，最大负载不超过 $k^* = O(\ln n/\ln\ln n)$**。<span class="marginnote">反直觉之处正在这里：平均负载只有 1，但「最大负载」的对数量级远大于 1。随机分散的数学事实是：均匀独立投放时，负载上限只以对数增长——这让哈希与随机负载均衡成为可行策略。</span>

**辨析｜易错点：** 不要试图用「单个箱子负载 $\le k^*$」直接下结论——你要的是「所有箱子」同时安全，必须把单箱子的失败概率乘上箱子数（并集界）。反过来，并集界往往过于保守：若把系数从 3 换成 2，结论会变成「以高概率最大负载 $O(\ln n/\ln\ln n)$」，这更接近精确的答案（真正的极值约为 $\ln n/\ln\ln n \cdot (1+o(1))$）。

## 4 两个重要的引申结论

### 空箱子的期望数

每个箱子为空的概率 $(1-1/n)^n \to 1/e$。由期望线性性，空箱子期望数约为 $n/e \approx 0.37n$。**即使均匀投放，也有近四成的箱子空着**——这对「均匀哈希是否真的用满了空间」给出一个清醒的答案。<span class="marginnote">这个 $1/e$ 常数在《数据结构》开放寻址哈希里还会出现：装填因子接近 $1$ 时，探测序列长度的分析同样依赖这类指数衰减。</span>

### 生日悖论预告

「至少两个球落入同一箱子」在 $n^2$ 个球、$n$ 个箱子时就高概率发生——这正是下一课生日悖论的原型。它们共享同一个数学内核：**碰撞问题的阈值在 $\sqrt{n}$ 量级**。

## 5 数值算例：最大负载到底有多小

先看小规模精确值，再看大规模渐近值——两头夹出直觉。

**小规模精确计算**：$n = 2$ 时，两个球落两个箱：最大负载为 2 的概率 $1/2$、为 1 的概率 $1/2$，期望最大负载 $1.5$。$n = 3$ 时（共 $3^3 = 27$ 种等可能投法）：最大负载恰为 3 的投法有 3 种（三球同箱），概率 $1/9$；恰为 2 的有 18 种，概率 $2/3$；恰为 1 的 6 种（全排列），概率 $2/9$——期望最大负载 $3\times\frac19 + 2\times\frac23 + 1\times\frac29 = \frac{17}{9} \approx 1.89$。**平均负载明明是 1，最大负载却总在 1.5–1.9 附近**，这就是「均值与极值不同」的最小实例。

**大规模渐近值**：把上界 $k^* = 3\ln n / \ln\ln n$ 代入实际数字：

| 箱子数 $n$ | $k^* = 3\ln n/\ln\ln n$ | 含义 |
| --- | --- | --- |
| $10^2$ | $\approx 9.0$ | 百个箱子，最大负载约个位数 |
| $10^6$ | $\approx 15.8$ | 百万箱子，最大负载不到 16 |
| $10^9$ | $\approx 20.5$ | 十亿箱子，最大负载约 21 |
| $10^{12}$ | $\approx 25.0$ | 万亿箱子，最大负载仍只有 25 |

这个表的震撼在于：$n$ 从 $10^2$ 涨到 $10^{12}$（扩大 $10^{10}$ 倍），最大负载只从 9 涨到 25。<span class="marginnote">这正是「$O(\ln n / \ln\ln n)$ 几乎像常数」的字面意义——二重对数把指数级增长压得几乎平直。哈希表把海量键均匀散列后，<strong>任何桶都不会塞进多少元素</strong>，这就是摊还 O(1) 查找的底气。把这个表讲给「担心哈希冲突」的人听，就是最好的镇定剂。</span>

**对照验证**：$n = 10^6$ 时并集界给出「以高概率最大负载 ≤ 15.8」；空箱期望数约 $n/e \approx 0.37n$——一边是「最满的箱只有十几个」，一边是「近四成箱空着」。均匀随机投放的「不均匀」恰恰是它「不会过载」的原因。

## 6 小结

- **球与箱子**：$n$ 球投入 $n$ 箱，平均负载 1，但**最大负载以高概率只有 $O(\ln n/\ln\ln n)$**。
- **布尔不等式**：处理「存在型」坏事件，把概率和并集界化。
- **切尔诺夫界**：二项分布尾部指数衰减，是导出高概率上界的标准工具。
- 数值算例：$n$ 从 $10^2$ 到 $10^{12}$，最大负载上界只从 9 涨到 25；$n=3$ 时精确期望 $\approx 1.89$。
- 空箱子的期望数 $\approx n/e$，提醒「均匀分散」不等于「空间用满」。
- 随机负载均衡的 $O(\log n)$ 级上界，是哈希表与随机路由可行性的理论基石。


**速查表**：

| 工具 | 用途 | 形式 |
| --- | --- | --- |
| 期望线性性 | 算平均负载 | $\mathbb{E}[X_b] = 1$ |
| 并集界 | 处理「存在某箱超载」 | $\Pr[\cup] \le \sum \Pr$ |
| 切尔诺夫界 | 二项尾部指数衰减 | $\Pr[X \ge k] \le e^{k-1}/k^k$ |
| $O(\ln n/\ln\ln n)$ | 最大负载上界 | 由「$k^*\ln k^* \approx 3\ln n$」导出 |

**辨析｜易错点：** 别拿「单个箱子的尾部界」直接当结论——要的是「所有箱子同时安全」，必须乘上箱子数（并集界）。反之并集界偏保守：系数 2 已足够，真正的极值约 $\ln n/\ln\ln n\cdot(1+o(1))$。

**数值快照**：$n$ 从 $10^2$ 到 $10^{12}$，最大负载上界只从 9 涨到 25——二重对数把指数级增长压得几乎平直，这是哈希表摊还 O(1) 的底气。


- 负载均衡的实际含义：把任务随机派发给 $n$ 台服务器，最忙的机器负载只有 $O(\\ln n/\\ln\\ln n)$——比「均匀」更令人安心的随机性红利。
