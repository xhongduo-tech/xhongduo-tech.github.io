## 为什么从最近点对开始

聚类、碰撞检测、地图配准、图像匹配——「最近点对」是这些问题的几何基石。朴素做法两两算距离 $O(n^2)$；**分治法**把最近点对在 $O(n\log n)$ 内找出。<span class="marginnote">最近点对是「分治」与「计算几何」的交叉点：递归把点集分成两半，关键在「合并」——跨中线的最近点对只需检查中线附近 $2\delta$ 宽窄条内的点。这个「窄条 + 常数邻域」的论证，把看似 $O(n^2)$ 的合并压成线性。</span>

这一课讲算法、那个关键的「$\delta$ 窄条」论证、以及 $T(n) = 2T(n/2) + O(n) = O(n\log n)$ 的推导。

## 1 算法：分治三件套

**CLOSEST-PAIR**（按 $x$ 坐标排序后的点集）：

```text
CLOSEST-PAIR(P)                    // P 已按 x 坐标升序排序
if |P| ≤ 3
    两两计算距离，返回最小距离        // 基本情况：O(1)
mid = ⌊|P| / 2⌋
PL = P[1..mid]；PR = P[mid+1..|P|]
dL = CLOSEST-PAIR(PL)              // 左半内部最近距离
dR = CLOSEST-PAIR(PR)              // 右半内部最近距离
δ = min(dL, dR)
S = { p ∈ P : |p.x − P[mid].x| < δ }        // 中线 δ 窄条
按 y 坐标对 S 排序
for i = 1 to |S|
    for j = i+1 to min(i+7, |S|)            // 只需查至多 7 个后继
        if dist(S[i], S[j]) < δ
            δ = dist(S[i], S[j])
return δ
```

**分解**：按 $x$ 坐标中位数切成左右两半；**递归**：各求最近对 $d_L, d_R$；**合并**：检查跨中线的对，更新 $\delta$。<span class="marginnote">「递归只求两半内部」+「合并时检查跨线对」是最近点对的分治骨架。朴素合并要检查左右各 $n/2$ 个点的所有组合（$O(n^2)$）；关键优化是「只用看中线两侧各 $\delta$ 内的点」，因为<strong>任何跨线对若距离 < δ，两点的 $x$ 都必须在 $x_{mid}$ 两侧 $\delta$ 内</strong>——更远的点对距离必然 ≥ δ，无需检查。</span>

## 2 核心论证：为什么窄条内每点只需查常数个邻居

**关键引理**：在 $\delta$ 窄条内，按 $y$ 排序后，对每个点 $p$，只需检查它**后面至多 7 个点**——因为窄条内不可能有 8 个点两两距离 ≥ δ 却都距离 $p$ < δ。

**论证**：把 $\delta \times 2\delta$ 的窄条（中线两侧各 $\delta$）划分成 $\delta/2 \times \delta/2$ 的格子。**每个格子至多一个点**（否则格内两点的距离 $\le \sqrt{2}(\delta/2) < \delta$，矛盾于「δ 已是两半内部的最近距离」）。$p$ 后面 $y$ 距离 < $\delta$ 的点只能落在「以 $p$ 为底、高 δ」的范围，覆盖至多 $2 \times 3 + 1$ 个格子 → 至多 7 个点。<span class="marginnote">「$\delta/2$ 格子至多一个点」是整场论证的支点：它用「δ 是左右内部最近距离」这个递归假设，排除了「窄条内拥挤」的可能。于是合并阶段对每个点只需查常数个邻居——线性合并。这个「格子论证」是计算几何「常数邻域」技巧的经典，最近点对是它的出生地。</span>

## 3 公式解析：$T(n) = 2T(n/2) + O(n) = O(n\log n)$

合并阶段：筛选窄条（扫一遍 $O(n)$）+ 按 $y$ 排序（若预排序则 $O(n)$ 归并）+ 每点查常数个邻居（$O(n)$）：

$$T(n) = 2T\left(\frac{n}{2}\right) + O(n) = O(n\log n)$$

- **第一步，递归项**：两半各 $T(n/2)$。
- **第二步，合并项**：窄条筛选 $O(n)$ + 每点常数检查 $O(n)$——线性。（按 $y$ 排序若每次重排是 $O(n\log n)$，则总 $T(n) = 2T(n/2) + O(n\log n) = O(n\log^2 n)$；**预排序 + 归并**把合并压回 $O(n)$。）
- **第三步，主定理**：$T(n) = 2T(n/2) + \Theta(n)$ 是 Case 2，解 $O(n\log n)$。

**要点**：**合并必须是 $O(n)$** 才能拿到 $n\log n$。按 $y$ 排序是合并里最容易「变贵」的环节——用「预排序 + 归并」保持线性。<span class="marginnote">若合并阶段每次都重新按 $y$ 排序，复杂度退化为 $O(n\log^2 n)$——仍不错但非最优。预排序技巧（先按 y 排好，合并时用归并保持有序）把排序成本摊进分治结构，是「排序 + 分治」组合的经典优化。这个「归并保持有序」的思路与归并排序同源。</span>

**辨析｜易错点：** 窄条范围是「$|x - x_{mid}| < \delta$」——**严格小于**还是「≤」要看实现一致性，但别用成「±2δ」（多查无妨但常数变大）或漏查（会漏掉最优对）。最稳妥：先筛窄条、再按 y 排序、对每个点只查「y 差 < δ」的后继。

## 4 最近点对的应用与延伸

**聚类**：最近邻图的构建（K 近邻、DBSCAN 的邻域查询）。
**碰撞检测**：先找最近点对作为「可能碰撞」的候选。
**数值计算**：三角剖分的预处理（Delaunay 的最近邻结构）。
**变体**：最近点对的「最远点对」（直径）可用旋转卡壳；高维最近邻则转向 KD 树、哈希（LSH）。<span class="marginnote">最近点对是「分治在几何上的表演」：它证明了「看似必须 $O(n^2)$ 的两两问题」可以因「几何局部性」降为 $O(n\log n)$。类似的「局部性 + 常数邻域」论证出现在扫描线、最近邻、网格哈希里。理解最近点对，就理解了「几何问题为什么往往比组合问题便宜」。</span>

## 5 数值算例：把整个分治走一遍

取六个点（已按 $x$ 升序）：

$$p_1(0,0),\ p_2(1,2),\ p_3(2,0.1),\ p_4(2.5,0.5),\ p_5(4,1),\ p_6(5,3)$$

**分解**：$n=6$，$mid = 3$，左半 $P_L = \{p_1,p_2,p_3\}$，右半 $P_R = \{p_4,p_5,p_6\}$。

**左半递归** $d_L$：三对距离为 $\sqrt{5}\approx 2.236$（$p_1p_2$）、$\sqrt{4.01}\approx 2.002$（$p_1p_3$）、$\sqrt{4.61}\approx 2.147$（$p_2p_3$），取 $d_L \approx 2.002$。

**右半递归** $d_R$：$p_4p_5 = \sqrt{2.5}\approx 1.581$，$p_4p_6 = \sqrt{12.5}\approx 3.536$，$p_5p_6 = \sqrt{5}\approx 2.236$，取 $d_R \approx 1.581$。

**合并**：$\delta = \min(d_L, d_R) \approx 1.581$。中线 $x_{mid} = (2+2.5)/2 = 2.25$。窄条 $|x - 2.25| < 1.581$ 内的点是 $p_2, p_3, p_4$——注意 **$p_1$（$x=0$）和 $p_5, p_6$ 被排除**，因为与中线的距离已超过 $\delta$。按 $y$ 排序得 $p_3(2,0.1), p_4(2.5,0.5), p_2(1,2)$。

**逐对检查**：$p_3p_4$ 的距离 $\sqrt{0.41}\approx 0.640 < \delta$，更新 $\delta = 0.640$；后续 $p_4p_2$ 的 $y$ 差 $1.5 > \delta$，按「只需查 $y$ 差 $< \delta$ 的后继」提前终止。<span class="marginnote">注意最优对 $p_3p_4$ 恰好横跨中线——如果合并阶段只算两半内部，就会漏掉它。这正是「窄条检查」存在的意义：跨线对的 $x$ 都贴在中线两侧，必落在窄条内。本例还展示了提前终止：$y$ 差超过 $\delta$ 后，更后面的点 $y$ 差更大，不必再查。</span>

**答案**：最近点对是 $p_3(2,0.1)$ 与 $p_4(2.5,0.5)$，距离 $\sqrt{0.41}\approx 0.640$。全程每一步都是 $O(n)$ 或更少，验证了线性合并。

## 6 小结

- **最近点对分治**：按 $x$ 分两半递归，合并时检查「中线 $\delta$ 窄条」内的跨线对。
- **关键引理**：$\delta/2$ 格子至多一个点 ⟹ 每点只需查 ≤ 7 个 $y$ 邻居。
- **复杂度**：$T(n) = 2T(n/2) + O(n) = O(n\log n)$；合并必须线性（预排序 + 归并）。
- 若合并每次重排 y，退化为 $O(n\log^2 n)$。
- 数值算例证实：最优对可以横跨中线，窄条检查必不可少；$y$ 差超过 $\delta$ 即可提前终止。
- 应用：聚类、碰撞检测、最近邻；「常数邻域」论证是几何局部性的通用武器。


**速查表**：

| 术语 | 含义 | 作用 |
| --- | --- | --- |
| $\delta$ 窄条 | 中线两侧 $|x - x_{mid}| < \delta$ 的点带 | 跨线最近对必在其中 |
| $\delta/2$ 格子 | 把窄条切成 $\frac{\delta}{2}\times\frac{\delta}{2}$ | 每格至多一个点 ⟹ 每点查 ≤ 7 邻居 |
| 预排序 + 归并 | $y$ 坐标预先排好、合并时归并保持 | 把合并压回 $O(n)$ |
| 常数邻域 | 每个点只查常数个后继 | 几何局部性的通用论证 |

**辨析｜易错点：** 窄条宽度严格取「$< \delta$」还是「$\le \delta$」需与实现一致；漏查会漏掉最优对、宽查只是常数变大。最稳的是「先筛窄条、按 y 排序、每点只查 y 差 < $\delta$ 的后继」。

**数值快照**：$n=10^6$ 个点时朴素两两距离 $\approx 5\times10^{11}$ 对、分治约 $2\times10^6\log_2(10^6) \approx 4\times10^7$ 次基本操作——「只查常数邻居」把平方代价压成拟线性，这是几何局部性的量化收益。


- 工程注意：浮点坐标可用「平方距离」比较避免开方；退化情形（重复点、共线多点）需先预处理。
- 变体：求「第 k 近点对」或「最大空圆」时，同一套「窄条 + 常数邻域」框架可复用。
- 与扫描线的关系：最近点对也可用「按 x 排序 + 平衡树维护 y 序」的扫描线解法，同样是 $O(n\\log n)$。
