# 最优二叉搜索树（Optimal BST）：期望搜索代价最小化

<div class="epigraph">
<p>有些键被搜索一百次，有些键只被搜索一次——把它们放在合适的高度，期望代价就最小。</p>
<footer>—— 唐纳德 · 克努斯（Donald E. Knuth）</footer>

## 为什么从最优 BST 开始

普通的二叉搜索树假设所有键等概率被搜索；现实中并非如此——字典里「the」比「xylophone」被查得多得多。**最优二叉搜索树（optimal BST）**：给定每个键的搜索概率，构造一棵 BST，使**期望搜索代价最小**。<span class="marginnote">这又是区间 DP 的舞台：问题要求「整个键集合的最优树」，而它必然由「某子区间的键组成的最优子树」拼接而成——和矩阵链乘法如出一辙。不同点在于：矩阵链的「最后一步」是分割点 $k$，最优 BST 的「根」就是分割点。</span>

这一课展示区间 DP 的第三个实例，并首次引入「**虚拟键**」的概念——搜索失败也占概率。

## 1 问题定义与虚拟键

给定 $n$ 个排序后的键 $k_1 < k_2 < \cdots < k_n$，各键搜索概率 $p_i$；搜索失败也可能发生——落在 $k_i$ 与 $k_{i+1}$ 之间（或首尾之外）的概率为 $q_i$。于是共有 $n$ 个成功概率与 $n+1$ 个失败概率，满足

$$\sum_{i=1}^{n} p_i + \sum_{i=0}^{n} q_i = 1$$

其中 $q_0$ 是「小于 $k_1$」的概率，$q_i$ 是「在 $k_i$ 与 $k_{i+1}$ 之间」的概率，$q_n$ 是「大于 $k_n$」的概率。<span class="marginnote">失败概率 $q_i$ 不可或缺：搜索一个不在树里的键也是花时间的。每个「空隙」$q_i$ 对应一个虚拟键（dummy key）$d_i$——它是搜索失败的「叶子位置」。把 $q_i$ 放进概率和，期望代价才算完整。</span>

**期望搜索代价**：设键 $k_i$ 在树中的深度为 $depth(k_i)$（根深度 1），虚拟键 $d_i$ 深度为 $depth(d_i)$，则

$$E[\text{cost}] = \sum_{i=1}^{n} p_i \cdot depth(k_i) + \sum_{i=0}^{n} q_i \cdot (depth(d_i) - 1)$$

**目标**：构造 BST 使 $E[\text{cost}]$ 最小。

## 2 最优子结构与递推式

设 $e[i][j]$ = 由键 $k_i, \dots, k_j$ 与虚拟键 $d_{i-1}, \dots, d_j$ 构成的最优 BST 的期望搜索代价（$i \le j$；$e[i][i-1] = q_{i-1}$ 表示空树只含虚拟键）。

若最优树的**根**是 $k_r$（$i \le r \le j$），则左子树由 $k_i..k_{r-1}$ 构成（最优），右子树由 $k_{r+1}..k_j$ 构成（最优）。整棵树的期望代价 = 根的一层代价 + 两棵子树代价各**下移一层**。下移一层让每个节点深度 +1，代价增加「该子树内所有概率之和」。设

$$w[i][j] = \sum_{t=i}^{j} p_t + \sum_{t=i-1}^{j} q_t$$

为键 $k_i..k_j$（含相关虚拟键）的概率总和，则递推式：

$$e[i][j] = \begin{cases} q_{i-1}, & j = i-1 \\ \min_{i \le r \le j} \left\{ e[i][r-1] + e[r+1][j] + w[i][j] \right\}, & i \le j \end{cases}$$

<span class="marginnote">「$+w[i][j]$」这一步是精髓：把 $k_r$ 提为根后，两棵子树整体下移一层，每个键和虚拟键的深度都 +1，累计增加恰好 $w[i][j]$。所以递推式 = 「左最优 + 右最优 + 全概率下移一层」。这正是「最优子结构 + 根作分割点」的区间 DP 模板。</span>

**辨析｜易错点：** 矩阵链乘法的递推是 $m[i][k]+m[k+1][j]+p_{i-1}p_kp_j$，没有「下移」；最优 BST 是 $e[i][r-1]+e[r+1][j]+w[i][j]$，多一个 $w[i][j]$。**别把两者混淆**——BST 的每个节点深度都要算进代价，根的选择改变所有深度。

## 3 算法：区间 DP 填表

```
OPTIMAL-BST(p, q, n)
1  let e[1..n+1][0..n], w[1..n+1][0..n], root[1..n][1..n] be new tables
2  for i = 1 to n+1
3      e[i][i−1] = q[i−1]                       // 空树边界：只有虚拟键
4      w[i][i−1] = q[i−1]
5  for l = 1 to n                                // 区间长度
6      for i = 1 to n−l+1                        // 区间起点
7          j = i+l−1                             // 区间终点
8          e[i][j] = ∞
9          w[i][j] = w[i][j−1] + p[j] + q[j]     // 概率和递推
10         for r = i to j                        // 枚举根
11             t = e[i][r−1] + e[r+1][j] + w[i][j]
12             if t < e[i][j]
13                 e[i][j] = t
14                 root[i][j] = r
15 return e and root
```

$root[i][j]$ 可递推计算：$w[i][j] = w[i][j-1] + p_j + q_j$。$root[i][j-1] \le root[i][j] \le root[i+1][j]$ 记录最优根，供构造树。<span class="marginnote">三重循环结构与矩阵链完全相同（外层长度、中层起点、内层根位置）。Knuth 还发现一个加速：最优根 $root[i][j]$ 满足单调性 $root[i][j-1] \le root[i][j] \le root[i+1][j]$，利用它可把内层循环从 $O(n)$ 摊到 $O(1)$ 平均，总时间降到 $O(n^2)$——这是「四边形不等式」优化区间 DP 的著名例子。</span>

## 4 公式解析：复杂度与期望代价的直觉

三重循环：

$$T(n) = \sum_{l=1}^{n}\sum_{i=1}^{n-l+1}\sum_{r=i}^{j} O(1) = \Theta(n^3)$$

- **第一步，状态数**：$O(n^2)$ 个区间 $[i,j]$。
- **第二步，每状态转移**：枚举 $O(n)$ 个根候选 $r$。
- **第三步，相乘**：$\Theta(n^3)$；空间 $O(n^2)$（$e$ 与 $root$ 两表）。用 Knuth 单调性优化可降至 $O(n^2)$ 时间。

**期望代价的直觉**：高频键放得越浅（靠近根），期望代价越小；低频键可以沉到深处。最优 BST 的形态「看起来」像一个偏斜的树——但偏斜的方向由概率决定，而非固定。<span class="marginnote">对照：普通 BST（按等概率）高 $O(\log n)$；最优 BST 在分布极不均匀时可以是「几乎一条链」的形状——高频键在链顶，低频键垂到底。这就是「概率驱动结构」的直观体现。</span>

**辨析｜易错点：** $e[i][i-1] = q_{i-1}$ 的边界不能漏——它表示「只有虚拟键 $d_{i-1}$ 的空树」，期望代价就是搜索失败概率 $q_{i-1}$。若把边界设成 0，所有递推都会系统性偏小，构造的树不是最优。

## 5 应用与延伸

最优 BST 的经典应用是**静态字典**：查词频率已知、建树一次、查询海量——例如编译器关键字表、编码表、数据库索引的静态版本。<span class="marginnote">当查询频率已知且稳定，「建一次最优树」的 $O(n^3)$ 前期成本完全值得。若频率动态变化，就该用更复杂的动态树（如伸展树、替罪羊树）；那是《数据结构》专题的内容。最优 BST 与 Huffman 编码（贪心课）都是「频率驱动的结构」，但一个最小化查找代价、一个最小化编码长度——对比着学最有味道。</span>

## 6 数值算例：两个键的最优 BST

取两个键：$p_1 = 0.6$、$p_2 = 0.3$，失败概率 $q_0 = 0.03$、$q_1 = 0.04$、$q_2 = 0.03$（总和 $1.0$）。算 $e$ 表：

**长度 1**：
- $e[1][1]$：唯一根 $k_1$，$e[1][0] + e[2][1] + w[1][1] = q_0 + q_1 + (p_1+q_0+q_1) = 0.03 + 0.04 + 0.67 = 0.74$。
- $e[2][2]$：唯一根 $k_2$，$e[2][1] + e[3][2] + w[2][2] = q_1 + q_2 + (p_2+q_1+q_2) = 0.04 + 0.03 + 0.37 = 0.44$。

**长度 2**（$w[1][2] = p_1+p_2+q_0+q_1+q_2 = 1.0$）：
- 根 $k_1$：$e[1][0] + e[2][2] + w[1][2] = 0.03 + 0.44 + 1.0 = 1.47$。
- 根 $k_2$：$e[1][1] + e[3][2] + w[1][2] = 0.74 + 0.03 + 1.0 = 1.77$。

**最优**：$e[1][2] = \min(1.47, 1.77) = 1.47$，根 $root[1][2] = k_1$——$k_1$ 作根、$k_2$ 作其右孩子。<span class="marginnote">验证 1.47：树中 $k_1$ 深度 1、$k_2$ 深度 2，虚拟键 $d_0$（左子 $k_1$）深度 2、$d_1,d_2$（$k_2$ 的孩子）深度 3。期望代价 $= 0.6{\cdot}1 + 0.3{\cdot}2 + 0.03{\cdot}2 + 0.04{\cdot}3 + 0.03{\cdot}3 = 0.6+0.6+0.06+0.12+0.09 = 1.47$——与 DP 完全一致。若把 $k_2$ 作根，代价 1.77 更差：高频键 $k_1$（0.6）被压到深层，得不偿失。<strong>「$+w[i][j]$」正是把「$k_1$ 作根使所有节点深一层」的成本算进去的那一步</strong>——$k_1$ 作根时右子树整体下移，比 $k_2$ 作根少付一层 0.3 的高频代价。</span>

**结构对照**：$k_1$ 频率 0.6 是 $k_2$ 的两倍，最优树自然把 $k_1$ 放浅层——「概率驱动结构」在一个最小例子里就清晰可见。

## 7 小结

- **最优 BST**：给定键与虚拟键的搜索概率，构造期望搜索代价最小的 BST。
- 虚拟键 $d_i$ 对应搜索失败，$q_i$ 是失败概率；$\sum p_i + \sum q_i = 1$。
- 数值算例：两键最优根为 $k_1$，期望代价 1.47（$k_2$ 作根则 1.77）。
- 递推式 $e[i][j] = \min_r(e[i][r-1] + e[r+1][j] + w[i][j])$，「$+w$」是子树整体下移一层的代价。
- 区间 DP 三重循环 $\Theta(n^3)$；Knuth 单调性优化可降至 $O(n^2)$。
- 应用：静态字典、编译器关键字表；与 Huffman 编码形成「频率驱动结构」的对照。


**速查表**：

| 概念 | 含义 |
| --- | --- |
| 虚拟键 $d_i$ | 搜索失败的叶子位置 |
| $w[i][j]$ | 区间内所有概率之和 |
| 「$+w$」 | 子树整体下移一层的代价 |
| Knuth 单调性 | $root[i][j-1] \le root[i][j] \le root[i+1][j]$ |

**辨析｜易错点：** $e[i][i-1] = q_{i-1}$ 的边界不能漏——它表示「只有虚拟键 $d_{i-1}$ 的空树」，期望代价就是失败概率。若设成 0，所有递推系统性偏小，构造的树不是最优。

**数值快照**：两键 $p_1=0.6$、$p_2=0.3$ 最优根为 $k_1$、期望代价 1.47（$k_2$ 作根则 1.77）——高频键 $k_1$ 被压到深层时，0.6 的高频代价乘上「多一层」，得不偿失。
