## 为什么从分数背包开始

0-1 背包「每件要么全拿要么不拿」，需要 DP；但**分数背包**允许取物品的一部分（如切黄金、舀糖、装水），问题骤然变简单——**按性价比从高到低装，装满即止**。<span class="marginnote">这个对比是「贪心 vs 动态规划」的最佳教材：同一个背包问题，只改一个约束（能否切割），解法的复杂度和性质就完全不同。0-1 需要 $O(nW)$ DP 且是 NP 完全；分数背包 $O(n\log n)$ 排序贪心即可，且必然最优。</span>

这一课回答：为什么分数背包贪心正确、0-1 背包贪心错误，以及「能不能切分」到底改变了什么。

## 1 分数背包：贪心算法

**分数背包（fractional knapsack）**：物品可切分，取任意比例 $x_i \in [0,1]$ 使 $\sum w_i x_i \le W$ 且 $\sum v_i x_i$ 最大。

贪心策略：**按单位重量价值（性价比）$v_i/w_i$ 从大到小排序，依次尽量多装**。

```text
FRACTIONAL-KNAPSACK(W, w[], v[]):
    按性价比 v[i]/w[i] 降序排序物品
    value ← 0
    for 每个物品 i（按性价比从高到低）:
        if w[i] ≤ W:                       // 能整件装下
            W ← W − w[i];  value ← value + v[i]
        else:                              // 只能装一部分
            value ← value + (v[i]/w[i]) × W
            break                          // 背包已满
    return value
```

直觉：在「可切分」的世界里，单位价值最高的物品永远值得优先——因为它每单位重量的「回报」最高，没有理由先装便宜的。

## 2 为什么贪心最优：交换论证

**交换论证（exchange argument）**是证明贪心最优的标准武器。设贪心解为 $G$，任意最优解为 $O$。若 $G \ne O$，找到「第一个不同」的物品——贪心在某个位置装了性价比更高（或相同）的物品 $g$，而 $O$ 装了性价比更低（或相同）的物品 $o$（或留着空位）。把 $O$ 中 $o$ 的部分替换成 $g$：

替换后总重量不变（$g$ 与 $o$ 占同样多的重量）；
总价值**不降**（$g$ 的性价比 $\ge$ $o$ 的性价比）；
替换后 $O$ 仍是可行解，且与贪心在更多位置一致。

反复替换，最终 $O$ 变成 $G$ 且价值不降——故**贪心解的价值 ≥ 任意最优解的价值**，贪心最优。<span class="marginnote">交换论证的核心动作：把最优解里「不符合贪心规则」的部分，换成「符合贪心规则」的部分，证明价值不降。它直接依赖「可切分」——替换的只是比例，不必扔掉整件物品。0-1 背包里替换会破坏「整件」约束，交换论证失效。</span>

## 3 0-1 背包为什么贪心失败

把同样的贪心用到 0-1 背包上，会失败：物品不能切分，装了高性价比物品后可能剩下一块「塞不进任何整件」的零头，而两个低性价比整件反而能拼出更高总价值。

**反例**：$W = 4$。物品 A（$w=3, v=6$，性价比 2）、B（$w=2, v=4$，性价比 2）、C（$w=2, v=4$，性价比 2）。贪心取性价比最高的 A → 剩容量 1，塞不下任何物品，总价值 6；最优是 B+C = 8。<span class="marginnote">注意这里三件性价比都是 2，所以「先装谁」由排序细节决定——但无论先装 A 还是 B，贪心都会剩下 1 或 2 的零头装不满，最多 6；DP 则发现 B+C 恰好装满。零头（剩余容量）是 0-1 贪心失败的根源。</span>

**辨析｜易错点：** 别以为「性价比一样就不分先后」。0-1 背包的正确解是 **$O(nW)$ 的 DP**（上一课），它枚举所有「装/不装」组合，不依赖性价比排序。**分数背包靠排序，0-1 背包靠状态枚举**——两者的本质差异在于「能否把剩余容量用好」。

## 4 公式解析：两类背包的数学对比

分数背包的贪心解 $\text{OPT}_{\text{frac}}$ 与 0-1 背包最优解 $\text{OPT}_{\text{01}}$ 满足

$$\text{OPT}_{\text{frac}} \ge \text{OPT}_{\text{01}} \ge \text{OPT}_{\text{frac}} - v_{\max}$$

- **第一步，$\text{OPT}_{\text{frac}} \ge \text{OPT}_{\text{01}}$**：分数背包的可行解集合 ⊇ 0-1 的可行解集合（0-1 是分数取整的特例），所以分数背包最优值 ≥ 0-1 最优值——**放宽约束只会让最优值不降**。
- **第二步，$\text{OPT}_{\text{01}} \ge \text{OPT}_{\text{frac}} - v_{\max}$**：0-1 最优至少是「分数贪心把最后一件物品扔掉」的解；分数贪心只有最后一件是「部分取」，其余都是整件。去掉它，剩余全是整件、且是可行 0-1 解，损失 ≤ 一件物品的最大价值 $v_{\max}$。
- **第三步，结论**：分数最优是 0-1 最优的**上界**，且差距至多 $v_{\max}$——若所有物品价值都不超过 1，分数最优与 0-1 最优只差小于 1。<span class="marginnote">这个不等式是「分数背包作为 0-1 背包的上界」的量化表达。它也是第十二篇近似算法里「分数背包近似 0-1」的种子：当所有 $v_i$ 有界，分数贪心几乎就是 0-1 的好近似。FPTAS 正是靠「缩放价值 + 分数上界」构造的。</span>

**要点**：约束的松紧改变问题本质。切分自由度给了贪心「每单位都最优」的杠杆；整数约束则引入了「组合」的难度。

## 5 数值算例：两类背包同台对比

同一组物品，先跑分数背包，再跑 0-1 背包，看差值从哪来。背包容量 $W = 10$：

| 物品 | 重量 $w$ | 价值 $v$ | 性价比 $v/w$ |
| --- | --- | --- | --- |
| A | 5 | 25 | 5 |
| B | 4 | 16 | 4 |
| C | 4 | 12 | 3 |
| D | 3 | 3 | 1 |

**分数背包贪心**：按性价比排序 A、B、C、D。

- 装 A 整件：容量剩 5，价值 25；
- 装 B 整件：容量剩 1，价值 41；
- C 重 4 > 剩 1，只能切 $1/4$：价值再加 $12 \times \tfrac14 = 3$，总价值 **44**。<span class="marginnote">注意 C 的切片价值 3 与 D 整件价值 3 相同——但先装性价比 3 的 C 切角而非性价比 1 的 D，是因为每单位容量回报不同。若贪心先装 D（性价比 1），会用掉 3 单位容量只换 3 价值，明显吃亏。</span>

**0-1 背包同一实例**：不能切 C。可选手枚举：A+B = 41（重量 9）；A+C = 37；A+B 后再无余地（D 重 3 塞不下）；B+C+D = 31。最优 **41**。

**对比**：$\text{OPT}_{\text{frac}} = 44 \ge \text{OPT}_{\text{01}} = 41$，差值 $44 - 41 = 3 \le v_{\max} = 25$——正好兑现第 4 节的不等式。差值的来源就是「最后那 1 单位容量只能装 $1/4$ 个 C」，而 0-1 背包对这点零头无能为力。若把 $v_i$ 全部缩放到不超过 1，这个差值就小于 1——这正是第十二篇 FPTAS 的构造灵感。

**辨析｜易错点：** 分数背包里「先切性价比高的」和「先装满容量」不是一回事——本例若先把容量装给 D（先填满再谈性价比），会得到 $3 + 16 + 12 = 31$，远差于 44。**贪心的排序键必须是性价比 $v_i/w_i$，不是重量也不是价值本身。**

## 6 小结

- **分数背包**：物品可切分，按性价比 $v_i/w_i$ 降序贪心，$O(n\log n)$ 排序即可最优。
- **交换论证**：把最优解中不符贪心的部分替换成贪心物品，价值不降——证明贪心最优。
- **0-1 背包贪心失败**：整数约束产生「零头」，两个低性价比整件可胜过高性价比单件；需 $O(nW)$ DP。
- **关系**：$\text{OPT}_{\text{frac}} \ge \text{OPT}_{\text{01}} \ge \text{OPT}_{\text{frac}} - v_{\max}$，分数最优是 0-1 的上界。
- 数值算例（$W=10$，四物品）显示差距来自「零头容量」；性价比是唯一正确的排序键。
- 「能否切分」是贪心与 DP 的分水岭：连续 ⇒ 贪心，离散 ⇒ 组合搜索。


**速查表**：

| 概念 | 含义 |
| --- | --- |
| 性价比 $v_i/w_i$ | 每单位重量的价值，贪心排序键 |
| 交换论证 | 把最优解的物品换成贪心物品，价值不降 |
| 零头 | 整数约束下剩余容量无法利用 |
| 分数上界 | 分数最优是 0-1 最优的上界，差距 ≤ $v_{\max}$ |

**辨析｜易错点：** 贪心的排序键必须是性价比 $v_i/w_i$，不是重量也不是价值本身——「先装满容量」或「先拿最贵」都会错。分数背包的「先切性价比最高」与「先填满」不是一回事。

**数值快照**：$W=10$ 四物品，分数贪心得 44、0-1 最优 41，差值 3 ≤ $v_{\max}=25$——差距来自「最后 1 单位容量只能装 1/4 个 C」，0-1 背包对这点零头无能为力。
