## 为什么从线段相交开始

线段相交是计算几何最基本的判定问题：地图上的道路、版图边界的重叠、图形的碰撞检测，都要回答「这两段是否相交」。<span class="marginnote">叉积的方向判定在这里第一次实战：<strong>跨立实验（straddling test）</strong>用「一个线段的两个端点是否在另一线段的两侧」来判定相交。它的正确性、以及「共线特例」的处理，是计算几何「精确判定」的示范。</span>

这一课讲跨立实验、它的四种情形、以及「端点落在对方线段上」的边界处理。

## 1 跨立实验：一般情形

**判定两条线段 $p_1p_2$ 与 $p_3p_4$ 是否相交**：

**跨立条件**：$p_3$ 与 $p_4$ 分别落在 $p_1p_2$ 的**两侧**，且 $p_1$ 与 $p_2$ 分别落在 $p_3p_4$ 的**两侧**。用 DIRECTION 表达：

$$d_1 = \text{DIRECTION}(p_1, p_2, p_3), \qquad d_2 = \text{DIRECTION}(p_1, p_2, p_4)$$
$$d_3 = \text{DIRECTION}(p_3, p_4, p_1), \qquad d_4 = \text{DIRECTION}(p_3, p_4, p_2)$$

**一般相交**（无共线端点）：$(d_1 \cdot d_2 < 0) \text{ 且 } (d_3 \cdot d_4 < 0)$——两线段**互相跨立**。<span class="marginnote">「互相跨立」是相交的充要条件（端点不落在对方线段上时）：$p_3, p_4$ 分居 $p_1p_2$ 两侧（$d_1, d_2$ 异号），同时 $p_1, p_2$ 分居 $p_3p_4$ 两侧（$d_3, d_4$ 异号）。为什么需要两个方向都跨立？因为「只在一个方向跨立」可能两线段呈「T 形」分离——它们都斜穿对方的延长线但不接触。</span>

## 2 边界情形：共线端点

当某个 $d_i = 0$（端点共线），需用 **ON-SEGMENT** 补判：

```
SEGMENTS-INTERSECT(p1, p2, p3, p4)
  d1 = DIRECTION(p1,p2,p3);  d2 = DIRECTION(p1,p2,p4)
  d3 = DIRECTION(p3,p4,p1);  d4 = DIRECTION(p3,p4,p2)
  if ((d1>0 and d2<0) or (d1<0 and d2>0)) and
     ((d3>0 and d4<0) or (d3<0 and d4>0))
    return TRUE                       // 一般情形：互相跨立
  else if d1 == 0 and ON-SEGMENT(p1,p2,p3)  return TRUE
  else if d2 == 0 and ON-SEGMENT(p1,p2,p4)  return TRUE
  else if d3 == 0 and ON-SEGMENT(p3,p4,p1)  return TRUE
  else if d4 == 0 and ON-SEGMENT(p3,p4,p2)  return TRUE
  else return FALSE
```

**边界情形**：某个端点在另一条线段上（$d_i = 0$ 且该点在线段内）——也算相交。<span class="marginnote">共线时「方向判定」失效（$d_i = 0$ 不提供左右信息），必须回到 ON-SEGMENT（边界框检查）。例如 $p_3$ 恰好在 $p_1p_2$ 上但 $p_4$ 在另一侧——这是「端点接触」，线段相交。漏掉这些分支，端点接触的相交会被误判为不相交。</span>

## 3 公式解析：为什么「互相跨立」等价于相交

把「相交」分解成「$p_3$ 在 $p_1p_2$ 上」或「$p_3, p_4$ 分居 $p_1p_2$」且「$p_1, p_2$ 分居 $p_3p_4$」：

$$\text{相交} \iff (d_1 d_2 < 0 \wedge d_3 d_4 < 0) \vee (\exists i: d_i = 0 \wedge \text{ON-SEGMENT})$$

- **第一步，一般情形**：$d_1 d_2 < 0$ 表示 $p_3, p_4$ 在 $p_1p_2$ 两侧；$d_3 d_4 < 0$ 表示反向也跨立。两条件合取 = 「互相跨立」。
- **第二步，跨立的几何含义**：$p_3, p_4$ 分居 $p_1p_2$ 两侧意味着「线段 $p_3p_4$ 穿过直线 $p_1p_2$」；同理 $p_1p_2$ 穿过直线 $p_3p_4$——两线段都穿过对方的直线，且交点落在两线段内部。
- **第三步，边界情形**：共线端点用 ON-SEGMENT 补上「交点恰在端点」的场合。

**要点**：跨立实验把「几何相交」翻译成「四个方向判定的符号组合」——**纯整数运算、精确无浮点误差**。<span class="marginnote">对比代数解法（求直线交点坐标再检查）：求交点涉及除法与浮点，既慢又不精确。跨立实验完全避开交点计算——只要符号判定。这体现了计算几何「能判符号就不算数值」的设计哲学。</span>

**辨析｜易错点：** 叉积结果可能溢出（坐标大时）——实现用 64 位整数。且「>0/<0」的严格不等不能写成「≥/≤」——共线分支要单独走 ON-SEGMENT，否则端点接触会被「严格异号」误判。

## 4 复杂度与应用

单次判定：4 个 DIRECTION + 至多 4 次 ON-SEGMENT，**$O(1)$**。它是最便宜的几何原语之一。

- **碰撞检测**：图形学、机器人运动规划的「线段是否相交」。
- **多边形自交**：判断多边形边是否相交（判断多边形是否简单）。
- **扫描线算法**（下一课）的每个「事件」都要用跨立判定。
- **地图与 GIS**：道路、边界线的拓扑关系。<span class="marginnote">「$O(1)$ 的线段相交判定」是无数几何算法的原子操作。下一课会把 $n$ 条线段两两判交的 $O(n^2)$ 优化成 $O((n+k)\log n)$（$k$ = 相交对数）——但那个优化内部，每次「候选对」仍然调用这个 $O(1)$ 跨立判定。先把这个原子操作吃透，上层算法才有可靠的砖块。</span>

## 5 小结

- **跨立实验**：$d_1d_2 < 0$ 且 $d_3d_4 < 0$ ⟹ 一般相交。
- **边界情形**：$d_i = 0$ 时用 ON-SEGMENT 补判「端点在线段上」。
- 四个 DIRECTION + 至多四次 ON-SEGMENT，$O(1)$，纯整数精确。
- 严格异号 vs 共线分支要分清；64 位防溢出。
- 应用：碰撞检测、多边形自交、GIS、扫描线算法的原子操作。

在下一课，我们解决「一堆线段里有哪些相交」——**扫描线算法**：用 $O((n+k)\log n)$ 代替 $O(n^2)$ 两两检查。
