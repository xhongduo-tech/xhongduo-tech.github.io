# 随机排列算法：按优先级排序与原地洗牌（Fisher–Yates）

<div class="epigraph">
<p>洗牌的本质，是让每一种排列以相同概率出现——这是随机算法正确性的试金石。</p>

## 为什么从随机排列开始

上一课我们说要「主动把输入打乱」来实现真正的随机化，但还没回答一个关键问题：**如何公平地洗牌？** 直觉上「随便交换几下」是不够的——有些排列会出现得更频繁。这一课给出两个可证明均匀的洗牌方法，并揭示一个深刻道理：**均匀性不能靠直觉保证，只能靠概率论证**。<span class="marginnote">洗牌算法无处不在：在线学习里打乱训练数据、推荐系统里打乱曝光顺序、Monte Carlo 模拟里采样置换。一个不均匀的洗牌器会把统计推断悄悄带偏——代价看不见，却最致命。</span>

我们将学习两种方法：**按优先级排序**（思想简单，但期望时间 $O(n \log n)$）与 **Fisher–Yates 原地洗牌**（$O(n)$，工业标准）。两者都以「均匀分布」为目标，但证明路径不同。

## 1 按优先级排序：随机键法

**方法**：给每个元素 $A[i]$ 附一个独立均匀取自 $[1, n^3]$ 的随机优先级 $P[i]$，然后**按优先级从小到大排序**，得到排列。伪代码：

```text
PERMUTE-BY-SORTING(A)
    n = A.length
    for i = 1 to n
        P[i] = RANDOM(1, n³)    // 给每个元素独立随机优先级
    按 P 的升序对 A 排序          // 得到随机排列
    return A
```

为什么优先级取到 $n^3$？因为要保证**所有优先级互不相同的概率极高**。<span class="marginnote">若两个元素拿到相同优先级，排序结果依赖具体排序算法的并列处理，均匀性就可能被破坏。取 $n^3$ 后，出现并列的概率上界约为 $1/n$——随着 $n$ 增大，这几乎不会发生。</span>具体论证：对任意一对元素，它们优先级相等的概率是 $1/n^3$；$\binom{n}{2}$ 对中至少一对相等的概率，由布尔不等式不超过 $\binom{n}{2}/n^3 = (n-1)/(2n^2) < 1/n$。

**均匀性证明（思路）**：若所有优先级互异，排序后得到的排列完全由优先级的大小序决定。由于优先级独立同分布，任何一对优先级的相对大小等可能——由此可归纳证明：**每种排列都以 $1/n!$ 的概率出现**。CLRS 用「第 $k$ 小优先级出现在某特定位置的概率」做严格论证，核心是一个计算：对固定排列，其出现概率恰为 $\prod_{i=1}^{n} 1/i = 1/n!$。

## 2 Fisher–Yates：原地洗牌

**方法**：从后往前扫描，对每个位置 $i$，在 $A[1..i]$ 中均匀随机取一个位置 $j$，交换 $A[i]$ 与 $A[j]$。伪代码：

```text
RANDOMIZE-IN-PLACE(A)
    n = A.length
    for i = n downto 2
        j = RANDOM(1, i)        // 注意范围是 1..i（含 i）
        exchange A[i] with A[j]
```

注意随机范围是 $1$ 到 $i$（含当前位），**不是**每次都在整个数组上取。<span class="marginnote">一个常见的错误版本是「每次在 $1..n$ 均匀取 $j$ 交换」——它看似更随机，实则产生的排列并非均匀。这个反例值得自己算一次：$n=3$ 时该版本能到达的排列概率并不相等。</span>

**均匀性证明（归纳法）**：

- **基础**：$i = n$ 时，第一步把 $A[n]$ 与 $A[1..n]$ 中任一位交换，故 $A[n]$ 等可能地成为任意原始元素。
- **归纳**：假设前 $n-i$ 步已让 $A[i+1..n]$ 等可能地成为任意 $n-i$ 个元素的某种排列。第 $i$ 步从剩余的 $i$ 个元素中均匀取一个放到 $A[i]$。于是每个元素以 $1/i$ 的概率成为 $A[i]$，且剩余元素与已固定部分互斥。

合起来，任意特定排列 $\pi_1, \pi_2, \dots, \pi_n$ 出现的概率为

$$\frac{1}{n} \cdot \frac{1}{n-1} \cdots \frac{1}{2} \cdot 1 = \frac{1}{n!}$$

这就是均匀分布的定义。<span class="marginnote">归纳法在这里的妙处：不是去数所有排列，而是按「从后往前逐位固定」的顺序证明每一层的条件概率都正确。这是分析随机算法的标准套路。</span>

## 3 公式解析：概率链 $\frac{1}{n} \cdot \frac{1}{n-1} \cdots \frac{1}{2} = \frac{1}{n!}$

这条链是 Fisher–Yates 均匀性的数学核心，拆成三步：

**第一步，$\frac{1}{n}$**：第一步从 $n$ 个元素中均匀取一个放到末位，任意指定元素落入末位的概率是 $1/n$。
**第二步，$\frac{1}{n-1}$**：已固定末位后，第二步在剩余 $n-1$ 个元素中均匀取一个放到 $n-1$ 位，**条件概率**是 $1/(n-1)$。
**第三步，连乘**：各步互不影响（每步只在自己那层的剩余集合里取），条件概率连乘得到目标排列出现的总概率 $1/n!$。

**辨析｜易错点：** 最容易犯的错误是洗牌范围写错。Fisher–Yates 第 $i$ 步的随机范围是 $1..i$（含 $i$）；若写成 $1..n$，排列概率会偏向「末位元素更可能是后来者」——虽然 $n$ 个位置的边缘分布看似均匀，但**联合分布**不再均匀，很多基于置换的随机化就会失效。判断一个洗牌器是否均匀，别只看边缘概率，要检验排列本身的分布。

## 4 复杂度与选择

两种方法对比：

| 方法 | 时间 | 空间 | 随机数个数 | 特点 |
| --- | --- | --- | --- | --- |
| 按优先级排序 | $O(n \log n)$ | $O(n)$ | $n$ | 思路直观，证明稍繁 |
| Fisher–Yates | $O(n)$ | $O(1)$ | $n-1$ | 原地、最优、工业标准 |

**工程上的选择几乎总是 Fisher–Yates**：它一次遍历、原地交换、常数空间，且只产生 $n-1$ 个随机数。<span class="marginnote">许多标准库的洗牌函数（如 Python 的 `random.shuffle`、C++ 的 `std::shuffle`）就是 Fisher–Yates 的变体。反过来，C++ 早期版本的 `std::random_shuffle` 曾因随机数发生器质量不足而备受诟病——这提醒我们，算法均匀还要求随机源本身均匀。</span>

**辨析｜易错点：** 随机数源的质量直接影响洗牌质量。即使 Fisher–Yates 证明「若随机数均匀则排列均匀」，若底层 PRNG 的周期小于 $n!$，某些排列根本不可能出现。对 $n \ge 20$ 的场景，$n!$ 已超过 64 位整数范围——**用 `rand()` 这类弱随机源洗大数组，均匀性只是纸面承诺**。

## 5 小结

- **按优先级排序**：给每个元素独立均匀的随机键，按键排序；键取到 $n^3$ 以保证互异概率极高。
- **Fisher–Yates**：从后往前，第 $i$ 步在 $1..i$ 中均匀取 $j$ 交换——$O(n)$ 时间、$O(1)$ 空间。
- 均匀性证明的关键是**概率链连乘** $\prod 1/i = 1/n!$，这是「每种排列等概率」的定义。
- 判断洗牌器是否均匀要看**联合分布**而非边缘分布；随机数源的质量同样关键。
- 有了随机排列，上一课的雇佣问题才能真正「随机化」；它也是随机化快速排序（下下篇）的基石。
