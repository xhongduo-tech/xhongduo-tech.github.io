# 基数排序（Radix Sort）：低位优先与正确性归纳

<div class="epigraph">

## 为什么从基数排序开始

计数排序把「值域小」变成了线性时间；基数排序再进一步：**当值域大时，把每个数拆成 $d$ 位数字，逐位排序**。<span class="marginnote">基数排序的历史比电子计算机还早：打孔卡时代就用「按位分发」给普查数据排序。今天它仍是后缀数组、字符串排序、GPU 排序库的底层组件。它证明了一件事：比较排序的下界不是排序的全部。</span>

这一课的核心是**低位优先（least significant digit, LSD）**策略与它的正确性归纳证明——为什么先排低位、再排高位，最终得到的是全局有序？

## 1 算法：逐位稳定排序

输入：$n$ 个 $d$ 位的整数（每位取值 $[0, k-1]$）。算法对每一位从**低位到高位**依次做一次稳定排序：

```
RADIX-SORT(A, d)
  for i = 1 to d          // i 从最低位到最高位
    use a stable sort to sort array A on digit i
```

**为什么是「低位优先」而不是「高位优先」？** 高位优先（MSD）需要递归处理每个高位的分组，且不稳定排序会毁掉已排好的低序；LSD 配合稳定排序，每次只排一位，但**稳定排序保证：高位相同的元素，其相对顺序由已排好的低位决定**——于是逐位推进，最终有序。<span class="marginnote">直觉：第 $i$ 轮排完后，所有元素的「末 $i$ 位」已经有序（按末 $i$ 位的大小）。稳定排序处理第 $i+1$ 位时，把「第 $i+1$ 位更大」的排到后面；第 $i+1$ 位相同的，保持「末 $i$ 位有序」的顺序——合起来就是「末 $i+1$ 位有序」。</span>

## 2 正确性：归纳证明

**定理**：对 $d$ 位整数，LSD 基数排序（每轮用稳定排序）输出全局有序。

**归纳证明**：

- **基础（$i=0$）**：排完 0 位，空序列显然「按末 0 位有序」。
- **归纳步**：假设排完第 $i$ 位后，数组按「末 $i$ 位」有序。现在稳定排序第 $i+1$ 位。任取两个元素 $a, b$：
  - 若 $a$ 与 $b$ 的第 $i+1$ 位不同，稳定排序直接按该位排好；
  - 若第 $i+1$ 位相同，稳定排序**保持它们之前（按末 $i$ 位）的相对顺序**，而归纳假设该顺序已是按末 $i$ 位有序。

  两种情形都保证「按末 $i+1$ 位」正确。归纳完成。

- **终止（$i=d$）**：按「末 $d$ 位」有序 = 按完整整数有序。<span class="marginnote">这个证明的精髓在于：<strong>稳定性把「高位的相等」交给「低位的已排好序」去处理</strong>。没有稳定性，归纳步里「第 $i+1$ 位相同时保持顺序」就不成立——所以基数排序必须绑定稳定子排序。</span>

**辨析｜易错点：** 若用不稳定的子排序（如堆排序），基数排序失效。很多实现错误地「优化」掉稳定性，结果只有前几位排对了。**子排序必须稳定**是基数排序不可妥协的前提。

## 3 复杂度与参数权衡

设 $d$ 位、每位取值 $[0, k-1]$，子排序用计数排序（$O(n+k)$）。总时间：

$$T(n) = \Theta(d(n + k))$$

实际中 $k$ 通常取常数（如 10 进制、256 进制），于是 $T = \Theta(dn)$。对 $b$ 位二进制整数，可以拆成 $\lceil b/r \rceil$ 位、每位 $2^r$ 个取值，总时间

$$T(n) = \Theta\left(\frac{b}{r}(n + 2^r)\right)$$

**关键权衡**：$r$ 越大（每位取更多位），位数越少，但每轮计数排序的 $k = 2^r$ 指数增长。选择 $r$ 让 $n + 2^r$ 最小——通常取 $r \approx \lg n$。<span class="marginnote">这个「$b/r$ 对 $2^r$」的权衡是基数排序工程调优的核心：GPU 基数排序常用 $r = 8$ 或 $r = 11$，在「轮数」与「每轮桶数」之间找平衡点。它也是「算法参数化设计」的活例子。</span>

**辨析｜易错点：** 基数排序的「线性」有一个隐藏前提：**位数 $d$ 是常数或 $O(\log n)$ 级**。若 $b$ 固定（如 32 位整数），$d$ 是常数，则确实 $O(n)$；但若数的值域随 $n$ 增长（$b = \log n$），则 $T = O(n\log n)$——与比较排序下界一致。**「线性」是针对固定位宽说的，不是无条件的。**

## 4 公式解析：为什么 $O(d(n+k))$ 里藏着「空间换时间」

以 4 位十进制数（$d=4$）、$n$ 个元素为例：

$$T = 4 \cdot (n + 10) = \Theta(4n) = \Theta(n)$$

- **第一步，看子排序**：每位用计数排序，$O(n+k)$，其中 $k=10$ 是每位取值个数。
- **第二步，看轮数**：共 $d=4$ 轮，每轮独立，线性相加。
- **第三步，看总时间**：$d$ 是常数时 $T = \Theta(n)$——**线性时间排序，且不依赖值域大小**，只依赖位数。

**要点**：基数排序把「大值域」问题转化成「多轮小值域」问题。每轮的小值域用计数排序线性解决，轮数由位数决定。**它不违反比较排序下界，因为它根本不是比较排序**——它读的是数字的位，是算术信息。

## 5 小结

- **LSD 基数排序**：从低位到高位逐位稳定排序，$d$ 轮完成。
- **正确性**：归纳证明「排完第 $i$ 位后按末 $i$ 位有序」；稳定子排序是归纳步的命门。
- **复杂度** $O(d(n+k))$；固定位宽下是线性，$b$ 随 $n$ 增长时回到 $O(n\log n)$。
- **参数权衡**：每位位数 $r$ 增大则轮数减少但桶数 $2^r$ 指数增长，通常取 $r \approx \lg n$。
- 基数排序靠「位的算术信息」绕过比较下界，是「用结构换速度」的经典。

在下一课，我们把「桶」的思想推向概率——**桶排序**：当输入均匀分布时，把值域切成 $n$ 个桶，每个桶内排序后拼接，期望 $O(n)$；但要先弄清它依赖什么分布假设。
