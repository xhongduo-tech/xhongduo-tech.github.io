## 为什么从二分图最大匹配开始

岗位匹配、任务指派、婚姻稳定模型、赛车排位——二分图最大匹配是组合优化里应用最广的问题之一。<span class="marginnote">最大流的价值在这里完全绽放：只需把二分图「翻译」成一个流网络，最大匹配数就等于最大流值——<strong>归约（reduction）</strong>让已有算法一鱼多吃。这也是第十一篇「NP 完全性」里归约概念的先声：把新问题翻译成熟知问题，是一种核心的算法设计思想。</span>

这一课构建归约、证明「匹配 ⟺ 流」的一一对应，并讨论用 Edmonds-Karp 求解的复杂度。

## 1 问题与归约构造

**二分图** $G=(L \cup R, E)$：顶点分成 $L$（左部）与 $R$（右部），所有边都连接左右。**匹配（matching）**：互不相交的边集（每个顶点至多一条匹配边）。**最大匹配**：边数最多的匹配。

**归约成最大流**：

```text
构造流网络 G′ = (V′, E′)：
    V′ ← L ∪ R ∪ {s, t}                // 增加源 s 与汇 t
    E′ ← ∅
    for 每个 l ∈ L:   E′ ← E′ ∪ {s → l}        // 容量 1
    for 每条 (l, r) ∈ E: E′ ← E′ ∪ {l → r}     // 容量 1
    for 每个 r ∈ R:   E′ ← E′ ∪ {r → t}        // 容量 1
    return G′
```

所有边容量都是 1。<span class="marginnote">容量全 1 是归约的关键设计：从 $s$ 到某个 $l$ 的边容量 1，强制「每个 $l$ 至多送出 1 单位流」——正好对应「每个左顶点至多匹配一条边」；从 $r$ 到 $t$ 容量 1 同理约束右顶点。流在 $l \to r$ 边上走 1 单位 ⟺ 匹配里含该边。</span>

**辨析｜易错点：** 归约方向别搞反。我们想把匹配**归约到**最大流（用流算法解匹配），所以要构造「匹配的解 = 流的解」的对应。归约的正确性必须证明「匹配 ↔ 流」双向保真——单向只够给出上界/下界之一，双向才是等价。这是所有归约的通用纪律。

## 2 数值算例：小二分图跑一遍

用一个小二分图验证。$L = \{l_1, l_2, l_3\}$、$R = \{r_1, r_2\}$，边：$l_1$–$r_1$、$l_1$–$r_2$、$l_2$–$r_1$、$l_3$–$r_2$。

- 构造流网络：$s\to l_1, l_2, l_3$（容量 1），四条匹配边（容量 1），$r_1, r_2 \to t$（容量 1）。
- **找最大匹配**：直观上 $r_1$ 只能被 $l_1$ 或 $l_2$ 匹配，$r_2$ 只能被 $l_1$ 或 $l_3$ 匹配——最优取 2 条（如 $l_2$–$r_1$ 与 $l_3$–$r_2$）。$l_1$ 闲置。
- **流算法**：增广路 $s\to l_2\to r_1\to t$（送 1）、$s\to l_3\to r_2\to t$（送 1）——流值 2，$s\to l_1$ 无法增广（两个汇边都满了）。最大流 = 最大匹配 = 2。

关键观察：$l_1$ 有两条候选边但只能贡献 1 个匹配（$s\to l_1$ 容量 1）——「每个左顶点至多一条」的约束被容量 1 精确编码。<span class="marginnote">若把 $s\to l_1$ 容量改成 2，$l_1$ 就能「同时匹配两条边」——那不是匹配了。归约的精确性正是靠「每个约束翻译成一个容量」，一个都不能少，也一个都不能多。</span>

## 3 匹配 ⟺ 流：双向对应

**匹配 → 流**：给定匹配 $M$，令流 $f$ 为：对每条匹配边 $(l, r)$，让 $s \to l \to r \to t$ 各走 1 单位流。容量约束与守恒都满足（每个 $l, r$ 至多 1 单位进出），故 $f$ 是合法流，$|f| = |M|$。

**流 → 匹配**：给定整数流 $f$，收集所有「流 $= 1$ 的 $l \to r$ 边」构成 $M$。因为 $s \to l$ 容量 1，每个 $l$ 至多一条这样的边；$r \to t$ 容量 1，每个 $r$ 至多一条——$M$ 是合法匹配，$|M| = |f|$。<span class="marginnote">这里用到「整数流可被分解」的性质：容量全为整数时，最大流算法（Ford-Fulkerson）产生整数流。于是「流值 1 的 $l\to r$ 边」恰好对应匹配边——一一对应成立。这个「整数性」是归约正确的隐含前提。</span>

**结论**：最大匹配 = 最大流值。算法：构造 $G'$，跑 Edmonds-Karp，取流值。

**辨析｜易错点：** 「流值 1 的边」是指 $f(l,r) = 1$，不是「残量网络上存在」。若某个 $l\to r$ 边的流为 0 但残量里还有反向边，它不算匹配边。实现时收集的是「当前流的赋值」，而不是「残量图的边集」——这两者易混。

## 4 公式解析：复杂度为什么是 $O(VE)$

归约后的网络有 $|V'| = |L| + |R| + 2$ 个顶点、$|E'| = |E| + |L| + |R|$ 条边。用 Edmonds-Karp：

$$T = O(V'E'^2) \quad\text{但更紧：}\quad T = O(V' \cdot E')$$

- **第一步，一般上界**：Edmonds-Karp 是 $O(VE^2)$——归约后 $O(V' E'^2)$。
- **第二步，容量全 1 的改进**：因为最大流值 ≤ $|L| = O(V)$，且每次增广至少 +1，增广次数 ≤ $O(V)$。每次 BFS $O(E')$，总 $O(V E') = O(VE)$。
- **第三步，代入**：$T = O(V E)$（更紧），其中 $V = |L|+|R|$、$E$ 是原二分图边数。

**要点**：**容量为 1 的网络让增广次数有上界 $O(V)$**——这是「单位容量网络」给最大流算法的免费加速。<span class="marginnote">经典替代：Hopcroft-Karp 算法用「增广路分层 + 多路同时增广」把二分匹配做到 $O(E\sqrt{V})$，比 $O(VE)$ 更快（尤其稠密图）。但归约到最大流的 $O(VE)$ 已经足够清晰且通用——先理解归约，再看更快的专用算法。</span>

## 5 延伸：从匹配到更多问题

**完美匹配判定**：二分图有完美匹配（覆盖所有顶点）⟺ 最大流值 = $\min(|L|,|R|)$。
**带权匹配**：给边加权重，求最大权匹配——归约成**最小费用最大流**（每条边带费用，流单位计费）。<span class="marginnote">最小费用最大流是最大流的「加权版」：在最大流基础上最小化总费用。它把带权匹配、最优运输、调度成本等一大批问题都收进来。归约思想到这里已经形成体系——把新问题「翻译」进一个熟悉的算法框架。</span>
**最大独立集/最小顶点覆盖**（二分图）：用 König 定理与最大匹配关联（二分图的最小顶点覆盖 = 最大匹配）。<span class="marginnote">König 定理（二分图最小点覆盖 = 最大匹配）是最大流最小割定理的直接推论：点覆盖对应割，匹配对应流。这展示了「归约链条」——匹配 → 流 → 割 → 点覆盖，一个定理串起一串问题。</span>

## 6 术语速查与相关概念对照

| 术语 | 含义 |
| --- | --- |
| 二分图 | 顶点分左右、边只连左右 |
| 匹配 | 互不相交的边集 |
| 最大匹配 | 边数最多的匹配 |
| 归约 | 把新问题翻译成熟知问题 |
| 最小费用最大流 | 最大流的加权版 |
| König 定理 | 二分图最小点覆盖 = 最大匹配 |

**辨析｜易错点：** 不是所有匹配问题都能用「容量 1 的普通最大流」解决。**带权匹配**需要最小费用流；**一般图匹配**（非二分图）不能这样归约——那需要 Edmonds 开花算法。归约的适用范围是「二分图 + 无权」，超出就要换工具。

## 7 常见疑问快速答疑

**问：为什么不能直接贪心匹配？** 贪心（随便挑边）可能过早占用某个右顶点，导致「全局最优」被错过——匹配需要「换匹配」的能力，最大流算法的增广路正是这种「换」的体现：沿残量反向边走等于「撤销」一条已匹配边、重新配对。没有反悔的贪心解不了最大匹配。

**问：最大匹配一定唯一吗？** 不一定。同一张图可能有多个大小相同的最大匹配——只要边数相同都叫最大匹配。流算法输出的是「某个」最大匹配，取决于增广路的选择顺序。需要特定性质（如字典序最小）时，要加额外约束。

**问：$|L|$ 和 $|R|$ 不等时最大匹配多少？** 最大匹配 ≤ $\min(|L|, |R|)$——因为每个顶点至多匹配一条边。完美匹配要求 $|L| = |R|$ 且能全部配对；否则「完美匹配」不存在，最大匹配只是「尽可能多」。

**问：把容量都设 1，会不会限制解的多样性？** 不会。容量 1 约束的是「每个顶点至多一条匹配边」，这正是匹配的定义；解的多样性由「选哪些 $l\to r$ 边」体现，与容量无关。若想表达「允许重复匹配」，那是另一类问题，不该用匹配模型。

**问：二分图匹配还能归约到其他问题吗？** 能。反过来，「二分图匹配」本身也是很多问题的归约目标：课程分配、排班、网络流建模的检验。归约是双向的工具——学匹配，既可以用最大流解它，也可以用它检验其他模型。

## 8 小结

- **二分图最大匹配**：互不相交的最大边集。
- **归约**：源 $s$→左部（容量 1）、左部→右部（容量 1）、右部→汇 $t$（容量 1）。
- **对应**：匹配 ⟺ 单位容量流，一一对应；最大匹配 = 最大流。
- **复杂度**：容量全 1 使增广 ≤ $O(V)$ 次，Edmonds-Karp 为 $O(VE)$。
- 延伸：完美匹配判定、带权匹配（最小费用流）、König 定理（匹配 = 点覆盖）。
- 归约纪律：双向保真才是等价；带权匹配与一般图匹配需要其他工具。
- 归约是双向工具：既用流解匹配，也把其他问题翻译进匹配/流框架。
- 完美匹配 ⟺ 最大流值 = $\min(|L|, |R|)$；用流值核对「能否全配对」。
- 直觉锚点：容量全 1 把「每个顶点至多匹配一次」精确编码，是归约的点睛之笔。
- 整数值保证一一对应：容量整数 ⟹ 流可分解为「每单位一条增广路」，流值 1 的边恰是匹配边。
- Hopcroft-Karp 用分层多路增广把复杂度压到 $O(E\sqrt{V})$——归约版是理解它的跳板。

在下一课，我们看一个与增广路思路不同的最大流算法——**推送-重贴标签（Push-Relabel）**：不找整条路径，而是逐顶点「推流」，另辟蹊径地把复杂度降到 $O(V^2E)$。匹配归约给我们的启示——「容量 1 的约束可以表达组合约束」——会在推送算法里继续发光。
