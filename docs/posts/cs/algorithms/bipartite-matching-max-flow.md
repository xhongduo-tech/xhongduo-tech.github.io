## 为什么从二分图最大匹配开始

岗位匹配、任务指派、婚姻稳定模型、赛车排位——二分图最大匹配是组合优化里应用最广的问题之一。<span class="marginnote">最大流的价值在这里完全绽放：只需把二分图「翻译」成一个流网络，最大匹配数就等于最大流值——<strong>归约（reduction）</strong>让已有算法一鱼多吃。这也是第十一篇「NP 完全性」里归约概念的先声：把新问题翻译成熟知问题，是一种核心的算法设计思想。</span>

这一课构建归约、证明「匹配 ⟺ 流」的一一对应，并讨论用 Edmonds-Karp 求解的复杂度。

## 1 问题与归约构造

**二分图** $G=(L \cup R, E)$：顶点分成 $L$（左部）与 $R$（右部），所有边都连接左右。**匹配（matching）**：互不相交的边集（每个顶点至多一条匹配边）。**最大匹配**：边数最多的匹配。

**归约成最大流**：

```text
构造流网络 G′ = (V′, E′)：
    V′ ← L ∪ R ∪ {s, t}                // 增加源 s 与汇 t
    E′ ← ∅
    for 每个 l ∈ L:   E′ ← E′ ∪ {s → l}        // 容量 1
    for 每条 (l, r) ∈ E: E′ ← E′ ∪ {l → r}     // 容量 1
    for 每个 r ∈ R:   E′ ← E′ ∪ {r → t}        // 容量 1
    return G′
```

所有边容量都是 1。<span class="marginnote">容量全 1 是归约的关键设计：从 $s$ 到某个 $l$ 的边容量 1，强制「每个 $l$ 至多送出 1 单位流」——正好对应「每个左顶点至多匹配一条边」；从 $r$ 到 $t$ 容量 1 同理约束右顶点。流在 $l \to r$ 边上走 1 单位 ⟺ 匹配里含该边。</span>

## 2 匹配 ⟺ 流：双向对应

**匹配 → 流**：给定匹配 $M$，令流 $f$ 为：对每条匹配边 $(l, r)$，让 $s \to l \to r \to t$ 各走 1 单位流。容量约束与守恒都满足（每个 $l, r$ 至多 1 单位进出），故 $f$ 是合法流，$|f| = |M|$。

**流 → 匹配**：给定整数流 $f$，收集所有「流 $= 1$ 的 $l \to r$ 边」构成 $M$。因为 $s \to l$ 容量 1，每个 $l$ 至多一条这样的边；$r \to t$ 容量 1，每个 $r$ 至多一条——$M$ 是合法匹配，$|M| = |f|$。<span class="marginnote">这里用到「整数流可被分解」的性质：容量全为整数时，最大流算法（Ford-Fulkerson）产生整数流。于是「流值 1 的 $l\to r$ 边」恰好对应匹配边——一一对应成立。这个「整数性」是归约正确的隐含前提。</span>

**结论**：最大匹配 = 最大流值。算法：构造 $G'$，跑 Edmonds-Karp，取流值。

## 3 公式解析：复杂度为什么是 $O(VE)$

归约后的网络有 $|V'| = |L| + |R| + 2$ 个顶点、$|E'| = |E| + |L| + |R|$ 条边。用 Edmonds-Karp：

$$T = O(V'E'^2) \quad\text{但更紧：}\quad T = O(V' \cdot E')$$

- **第一步，一般上界**：Edmonds-Karp 是 $O(VE^2)$——归约后 $O(V' E'^2)$。
- **第二步，容量全 1 的改进**：因为最大流值 ≤ $|L| = O(V)$，且每次增广至少 +1，增广次数 ≤ $O(V)$。每次 BFS $O(E')$，总 $O(V E') = O(VE)$。
- **第三步，代入**：$T = O(V E)$（更紧），其中 $V = |L|+|R|$、$E$ 是原二分图边数。

**要点**：**容量为 1 的网络让增广次数有上界 $O(V)$**——这是「单位容量网络」给最大流算法的免费加速。<span class="marginnote">经典替代：Hopcroft-Karp 算法用「增广路分层 + 多路同时增广」把二分匹配做到 $O(E\sqrt{V})$，比 $O(VE)$ 更快（尤其稠密图）。但归约到最大流的 $O(VE)$ 已经足够清晰且通用——先理解归约，再看更快的专用算法。</span>

**辨析｜易错点：** 归约方向别搞反。我们想把匹配**归约到**最大流（用流算法解匹配），所以要构造「匹配的解 = 流的解」的对应。归约的正确性必须证明「匹配 ↔ 流」双向保真——单向只够给出上界/下界之一，双向才是等价。

## 4 延伸：从匹配到更多问题

**完美匹配判定**：二分图有完美匹配（覆盖所有顶点）⟺ 最大流值 = $\min(|L|,|R|)$。
**带权匹配**：给边加权重，求最大权匹配——归约成**最小费用最大流**（每条边带费用，流单位计费）。<span class="marginnote">最小费用最大流是最大流的「加权版」：在最大流基础上最小化总费用。它把带权匹配、最优运输、调度成本等一大批问题都收进来。归约思想到这里已经形成体系——把新问题「翻译」进一个熟悉的算法框架。</span>
**最大独立集/最小顶点覆盖**（二分图）：用 König 定理与最大匹配关联（二分图的最小顶点覆盖 = 最大匹配）。<span class="marginnote">König 定理（二分图最小点覆盖 = 最大匹配）是最大流最小割定理的直接推论：点覆盖对应割，匹配对应流。这展示了「归约链条」——匹配 → 流 → 割 → 点覆盖，一个定理串起一串问题。</span>

## 5 小结

- **二分图最大匹配**：互不相交的最大边集。
- **归约**：源 $s$→左部（容量 1）、左部→右部（容量 1）、右部→汇 $t$（容量 1）。
- **对应**：匹配 ⟺ 单位容量流，一一对应；最大匹配 = 最大流。
- **复杂度**：容量全 1 使增广 ≤ $O(V)$ 次，Edmonds-Karp 为 $O(VE)$。
- 延伸：完美匹配判定、带权匹配（最小费用流）、König 定理（匹配 = 点覆盖）。

在下一课，我们看一个与增广路思路不同的最大流算法——**推送-重贴标签（Push-Relabel）**：不找整条路径，而是逐顶点「推流」，另辟蹊径地把复杂度降到 $O(V^2E)$。
