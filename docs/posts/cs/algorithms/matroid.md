## 为什么从拟阵开始

活动选择与哈夫曼编码的贪心证明各写各的，但背后是否有统一规律？**拟阵（matroid）**给出了答案：一个抽象结构，只要满足三条公理，**贪心算法就必然给出最大权独立集**。<span class="marginnote">拟阵由惠特尼在 1935 年为统一「线性相关的抽象性质」而提出，后来被证明是「贪心可解问题」的数学刻画。学它不是为了算题，而是为了理解「贪心何时正确」的边界——这是算法理论最有深度的部分之一。</span>

这一课定义拟阵、看两个核心例子（图拟阵、矩阵拟阵），并证明那条中心定理：**贪心在拟阵上最优**。

## 1 拟阵的定义：三条公理

**拟阵（matroid）** 是一个有序对 $(S, \mathcal{I})$，其中 $S$ 是有限集合，$\mathcal{I}$ 是 $S$ 的某些子集的集合（称为**独立集**），满足：

**(M1) 空集独立**：$\emptyset \in \mathcal{I}$。
**(M2) 遗传性（heredity）**：若 $B \in \mathcal{I}$ 且 $A \subseteq B$，则 $A \in \mathcal{I}$。独立集的子集仍独立。
**(M3) 交换性（exchange property）**：若 $A, B \in \mathcal{I}$ 且 $|A| < |B|$，则存在 $x \in B \setminus A$ 使 $A \cup \{x\} \in \mathcal{I}$。<span class="marginnote">交换性是最核心也最抽象的公理：两个独立集，小的那个总能「借」大的那个里的一个元素而保持独立。它正是「贪心每一步都能把集合做大」的数学保证——没有 M3，贪心可能卡在「局部极大」无法到「全局最大」。</span>

## 2 两个关键例子

**图拟阵（graphic matroid）**：$S$ = 无向图 $G=(V,E)$ 的边集，$\mathcal{I}$ = **森林**（无环边集）的集合。

(M1) 空边集无环，独立。
(M2) 森林的子集仍是森林（删边不会造出环）。
(M3) 若 $A, B$ 都是森林且 $|A|<|B|$：$B$ 有更多边，其连通分量更少（森林边数 = 顶点数 − 分量数）。$A$ 的某两个分量必然被 $B$ 的一条边连接——加入该边不产生环。交换性成立。

**最大权独立集**：给每条边赋权，求最大总权森林——**这就是最大生成树**（或最小生成树取负权）。<span class="marginnote">图拟阵把「最小生成树」翻译成「图拟阵上的最大权独立集」——Kruskal 算法的正确性因此由拟阵定理免费给出。这是拟阵「一统贪心」最漂亮的例子：Kruskal 按边权排序贪心，正是「拟阵上贪心」的特例。</span>

**矩阵拟阵（vector matroid）**：$S$ = 一组向量，$\mathcal{I}$ = **线性无关**的子集族。三条公理对应线性代数的基本性质（空集无关、子集仍无关、Steinitz 交换引理）。「最大权无关子集」即「选最大权的一组基」。

## 3 公式解析：为什么贪心在拟阵上最优

**定理（拟阵贪心定理）**：设 $M = (S, \mathcal{I})$ 是拟阵，$w: S \to \mathbb{R}^+$ 是权函数。按权降序扫描元素，能加就加（保持独立），得到的独立集 $G$ 是**最大权独立集**。

证明分两步。

**第一步（贪心选择性质）**：设 $x$ 是 $S$ 中权最大的元素，且 $\{x\} \in \mathcal{I}$。则存在最大权独立集含 $x$。<span class="marginnote">证明：任取最大权独立集 $B$。若 $x \notin B$，由交换性（M3），把 $x$ 加入 $B$ 的某个可交换位置 $A$（若 $B$ 的某些子集也独立）……严格论证是：若 $\{x\}$ 独立，$B \cup \{x\}$ 可能含环，但 M3 保证可从 $B \setminus A$ 找一个元素替换。核心是「$x$ 权最大，替换不会降权」。</span>

**第二步（最优子结构）**：选定 $x$ 后，剩余问题是在「与 $x$ 相容的独立集」上求最大权——仍是同一拟阵的「收缩」结构，可递归贪心。

**合起来**：贪心在拟阵上每一步都「不失最优」且「剩余问题同构」——递归贪心即最优。这就是拟阵作为「贪心正确性框架」的全部内容。<span class="marginnote">反方向也成立：若一个结构满足 M1、M2 但贪心总能最优，它未必是拟阵（M3 是充分性的关键）。教材会给出「贪心最优 ⟺ 拟阵」在特定形式下的对应，M3 正是那道门槛。</span>

## 4 贪心伪代码与时间复杂度

```
GREEDY(M, w)
1  sort S by decreasing weight w            // 按权降序
2  A = ∅                                    // 贪心解，初始为空
3  for each x ∈ S in that order
4      if A ∪ {x} ∈ 𝓘                       // 能加就加（保持独立）
5          A = A ∪ {x}
6  return A
```

对图拟阵 + 降权，这就是 **Kruskal 算法**：按边权升序（= 降权取负）扫描，用并查集判断「加边是否成环」。时间复杂度 $O(|E|\log|E|)$（排序主导）——与《数据结构》里 Kruskal 的实现一致。<span class="marginnote">拟阵的价值不在给出新算法，而在「把已熟知的贪心统一到一条定理下」：Kruskal、Prim、活动选择的加权版、最大权独立集……只要验证结构是拟阵，贪心正确性自动成立，不必每题重写交换论证。</span>

## 5 拟阵的边界：什么不是拟阵

并非所有「能贪心」的问题都是拟阵——活动选择是「贪心可解」但**不是**拟阵（其独立集族不满足交换性）。拟阵是「贪心正确」的**充分条件**，不是必要条件。<span class="marginnote">还有更一般的结构：<strong>拟阵交（matroid intersection）</strong>、<strong>带权拟阵</strong>等扩展。两个拟阵的交不一定是拟阵，但其最大权交集可在多项式时间求解（Edmonds）。拟阵是组合优化里「既有深度又有广度」的少数主题之一——从线性代数到图论到贪心理论，它把三条路拧成一股。</span>

**辨析｜易错点：** 别把「贪心能解」与「是拟阵」划等号。活动选择贪心正确但非拟阵；0-1 背包连贪心都不正确。**拟阵给出的是一条「够用的充分条件」**：验证 M1–M3 成立，贪心必对；不成立，贪心可能对也可能错，需另证。

## 6 小结

- **拟阵** = $(S, \mathcal{I})$，三条公理：空集独立、遗传性、交换性。
- **图拟阵**：森林作独立集 → 最大权森林 = 最大生成树，Kruskal 是拟阵贪心的实例。
- **矩阵拟阵**：线性无关组作独立集 → 最大权基。
- **拟阵贪心定理**：按权降序「能加就加」，得到的独立集必是最大权——贪心选择性质 + 最优子结构两步证明。
- 拟阵是「贪心正确」的充分条件（非必要）；活动选择贪心正确但非拟阵。
