## 为什么从全源最短路开始

单源最短路算「一个源点到所有点」；**全源最短路径**算「所有点对」。朴素做法是「每个顶点跑一次单源算法」——但 Floyd-Warshall 用一个漂亮的 DP 一网打尽，Johnson 算法则在稀疏图上更胜一筹。<span class="marginnote">全源最短路应用极广：地图导航的距离矩阵、社会网络的紧密度中心度、路由表的预计算、蛋白质相互作用网络的图论指标。Floyd-Warshall 的「中间点集合」视角更是一个可迁移到许多图 DP 问题的框架。</span>

这一课讲两个算法：**Floyd-Warshall**（$O(V^3)$ 动态规划，允许负权）与 **Johnson**（稀疏图 $O(VE\log V)$，用「重赋权」技巧兼容 Dijkstra）。

## 1 Floyd-Warshall：以「中间点集合」为阶段

设顶点编号 1..n，定义 $d^{(k)}[i][j]$ = **只允许经过 $\{1,2,\dots,k\}$ 作为中间点**时，$i$ 到 $j$ 的最短距离。

**递推**：看是否经过第 $k$ 个点。

$$d^{(k)}[i][j] = \min\left(d^{(k-1)}[i][j],\; d^{(k-1)}[i][k] + d^{(k-1)}[k][j]\right)$$

- 不经过 $k$：路径的中间点都在 $\{1..k-1\}$ 里，$d^{(k-1)}[i][j]$。
- 经过 $k$：路径拆成「$i \to k$」与「$k \to j$」两段，各自由 $\{1..k-1\}$ 里的中间点组成，$d^{(k-1)}[i][k] + d^{(k-1)}[k][j]$。<span class="marginnote">这个 DP 的精髓是「<strong>逐步开放中间点集合</strong>」：从「不许经过任何中间点」到「允许经过点 1」「允许经过点 1,2」……每步只多放一个点进来。三维状态 $d^{(k)}[i][j]$ 是「区间 DP」的另一种形态——不是按长度，而是按「可用的中间点前缀」推进。</span>

**实现**：滚动掉 $k$ 维，直接用二维矩阵原地更新：

```
FLOYD-WARSHALL(W)
  n = W.rows;  D = W
  for k = 1 to n
    for i = 1 to n
      for j = 1 to n
        D[i][j] = min(D[i][j], D[i][k] + D[k][j])
  return D
```

**复杂度**：三重循环 $O(n^3)$，空间 $O(n^2)$。允许负权边，但**不允许负环**（负环会让「最短路」无定义）。

## 2 公式解析：$d^{(k)}[i][j]$ 递推的复杂度与正确性

三重循环：

$$T(n) = \sum_{k=1}^{n}\sum_{i=1}^{n}\sum_{j=1}^{n} O(1) = \Theta(n^3)$$

- **第一步，外层 $k$**：中间点集合逐步扩大，$n$ 个阶段。
- **第二步，中层 $i$、内层 $j$**：每个阶段更新 $n^2$ 个点对。
- **第三步，相乘**：$n^3$。空间只需 $O(n^2)$ 的矩阵（原地滚动 $k$ 维）。

**正确性（归纳）**：$d^{(k)}[i][j]$ 是「中间点限于 $\{1..k\}$」的最短距离。第 $k$ 步把「经过 $k$ 与否」两分支取 $\min$，即把集合扩大一个点；$k=n$ 时中间点不受限，得到全局最短路。<span class="marginnote">负权处理：Floyd-Warshall 在无负环时对所有负权边仍正确——因为 DP 不依赖「非负性」（不像 Dijkstra），只要最终「最短路径」存在即可。检测负环：跑完后检查对角线 $D[i][i]$，若 $<0$ 则存在负环。</span>

**辨析｜易错点：** 三条线中 $k$ 必须在**最外层**。若把 $k$ 放内层，$d^{(k)}$ 的「逐步开放」语义被破坏，结果错乱。**「中间点集合」的顺序是 Floyd-Warshall 的实现命门**——很多抄写错误都出在循环顺序上。

## 3 Johnson 算法：重赋权 + Dijkstra

Floyd-Warshall 对稠密图好；**稀疏图**上，Johnson 用「把负权变成非负」的技巧，让 Dijkstra（更快）在每一点跑一次：

```
JOHNSON(G, w)
  1. 加一个新顶点 s，与所有顶点连权 0 的边
  2. 用 Bellman-Ford 从 s 求 h[v] = 最短距离
     （若有负环，返回 FALSE）
  3. 对每条边 (u,v): w'(u,v) = w(u,v) + h[u] - h[v]   // 重赋权
  4. 对每个顶点 u: 用 Dijkstra 从 u 求 w' 意义下的最短路
  5. 还原真实距离: d(u,v) = d'(u,v) - h[u] + h[v]
```

**重赋权（reweighting）**：$w'(u,v) = w(u,v) + h[u] - h[v]$，其中 $h$ 是「从超级源 $s$ 出发的最短距离」。三个性质：<span class="marginnote">重赋权的直觉：$h[v]$ 是「$s$ 到 $v$ 的参考高度」。$w'$ 把每条边的权「按两端高度差调整」——因为 $h$ 满足三角形不等式 $h[v] \le h[u] + w(u,v)$（最短路性质），所以 $w' = w + h[u]-h[v] \ge 0$——负权被抹平，Dijkstra 可用。</span>

- **非负性**：$w'(u,v) \ge 0$（由 $h$ 的三角不等式）；
- **路径总长不变差**：对任何路径 $p$，$w'(p) = w(p) + h[s'] - h[t']$——常数偏移，最短路径关系不变；
- **正确性**：最短路径在 $w'$ 与 $w$ 下一致，跑 Dijkstra 后还原。

**复杂度**：Bellman-Ford $O(VE)$ + $V$ 次 Dijkstra $O(V E \log V)$ = 稀疏图 $O(VE\log V)$，优于 Floyd-Warshall 的 $O(V^3)$。

## 4 公式解析：重赋权为什么保持最短路径不变

对任意路径 $p = v_0 \to v_1 \to \cdots \to v_k$，重赋权后的路径长为

$$w'(p) = \sum_{t=1}^{k} w'(v_{t-1}, v_t) = \sum_{t=1}^{k} \left(w(v_{t-1},v_t) + h[v_{t-1}] - h[v_t]\right) = w(p) + h[v_0] - h[v_k]$$

- **第一步，逐边展开**：每条边加 $h[u] - h[v]$，路径上相邻项**抵消**（望远镜求和）。
- **第二步，只剩首尾**：中间 $h$ 全部消掉，剩 $w(p) + h[v_0] - h[v_k]$。
- **第三步，比较两条路径**：对固定的 $u, v$，$h[v_0] - h[v_k]$ 是常数——所以「$w'$ 下谁最短」与「$w$ 下谁最短」完全一致。

**要点**：重赋权是「保持最优解、抹平负权」的通用技巧——望远镜求和让 $h$ 只影响常数。**Johnson 因此把「负权全源最短路」降维成「非负权 Dijkstra 多次」**。<span class="marginnote">这个「加势函数保持最短路径」的技巧与物理里的「势能」概念暗合：$h$ 就像势场，边的权重差是「势差」，路径总代价不变。类似的技巧在最小费用流、差分约束里也会出现。</span>

## 5 两个算法怎么选

| 算法 | 时间 | 空间 | 负权 | 适合 |
| --- | --- | --- | --- | --- |
| Floyd-Warshall | $O(V^3)$ | $O(V^2)$ | 允许（无负环） | 稠密图、需矩阵 |
| Johnson | $O(VE\log V)$ | $O(V^2)$ | 允许（无负环） | 稀疏图 |
| 重复 Dijkstra | $O(V E\log V)$ | $O(V^2)$ | 否 | 稀疏、无负权 |

**辨析｜易错点：** Johnson 的「超级源 $s$」不能与图中任何顶点冲突；Bellman-Ford 检测到负环时，全源最短路无定义，必须返回错误。**先验负环、再重赋权**，顺序不能颠倒。<span class="marginnote">工程速查：n 在几百以内用 Floyd（实现极简、常数小）；n 上万且稀疏用 Johnson；无负权时直接 $V$ 次 Dijkstra 也行。地图类应用（数亿节点）则用更高级的多级 Dijkstra/收缩层级——那是《数据结构》与数据库索引课的范畴。</span>

## 6 小结

- **全源最短路**：求所有点对距离；Floyd-Warshall 用 DP，Johnson 用重赋权 + 多次 Dijkstra。
- **Floyd-Warshall**：$d^{(k)}[i][j]$ = 中间点限于 $\{1..k\}$ 的最短路，$O(V^3)$、$O(V^2)$ 空间；$k$ 在最外层。
- **Johnson**：超级源 + Bellman-Ford 求 $h$，重赋权 $w' = w + h[u]-h[v]$ 抹平负权，再跑 $V$ 次 Dijkstra。
- 重赋权靠**望远镜求和**保持最短路径不变，$h$ 只影响常数。
- 选择：稠密图 Floyd、稀疏图 Johnson；负环检测是两者的前置。
