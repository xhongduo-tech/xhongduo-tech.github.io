## 为什么从贪心的理论基础开始

分数背包的贪心成功了，0-1 背包的贪心失败了——同一个「按性价比装」的动作，结果天差地别。为什么？**贪心算法没有万能的正确性保证，它只在满足特定结构时成立**。<span class="marginnote">这一课把「贪心」从手艺升华为理论：两个性质——贪心选择性质与最优子结构——是贪心正确性的充分条件。学完它，你就有了一台「贪心正确性检测器」：先验证这两个性质，再放心地贪。</span>

这也解释了贪心与动态规划的关系：贪心是 DP 的「激进版本」——DP 探索所有选择，贪心只做一个选择。

## 1 贪心策略的直觉与风险

**贪心算法（greedy algorithm）**：每一步做出当前看起来最优的选择（局部最优），从不回头调整。它不枚举、不回溯、不填表——一次遍历就出答案。

风险是显而易见的：**局部最优未必导向全局最优**。0-1 背包、TSP（第十一篇）、图着色都是贪心的坟场。<span class="marginnote">「贪心是危险的直觉」——它太符合人类直觉，以至于错误用例往往不容易一眼看穿。判断一个贪心是否正确，必须用性质验证，不能靠「试几个例子都对」。</span>

## 2 两个核心性质

**贪心选择性质（greedy-choice property）**：通过**局部最优选择**（不依赖任何子问题的解）就能得到全局最优解。即：存在一个全局最优解，它以贪心的第一步选择为起点。<span class="marginnote">关键区分：DP 的选择依赖子问题（先解子问题再组合）；贪心的选择「先做」，子问题随之变小。顺序反过来——贪心是「先选再做子问题」，DP 是「先做子问题再选」。这个顺序差异是理解两者的钥匙。</span>

**最优子结构（optimal substructure）**：做了贪心选择后，剩余问题的最优解由「原问题的最优解」与「子问题的最优解」组合而成（与 DP 的最优子结构定义一致）。

**两者合起来**：贪心选择性质保证「第一步贪心不丢最优」，最优子结构保证「剩下的可以递归地贪心」——于是整个贪心过程正确。

## 3 验证方法：交换论证与剪贴论证

两个性质各有对应的证明工具：

**贪心选择性质 → 交换论证（exchange argument）**：设贪心第一步选择了 $g$，任意最优解含元素集合 $O$。若 $g \notin O$，证明可以把 $O$ 里某个「占着 $g$ 位置」的元素换成 $g$，不破坏可行性且不降最优性——于是存在「以 $g$ 开头」的最优解。<span class="marginnote">分数背包的证明就是这样：把最优解中性价比低的物品换成贪心物品，重量不变、价值不降。交换论证的关键是找到一个「可交换不损优」的替换对。</span>

**最优子结构 → 剪贴论证（cut-and-paste）**：若全局最优解含非最优子问题，把该子问题替换成它的最优解，全局不会变差——矛盾。（与 DP 课的剪贴论证同源。）

**辨析｜易错点：** 只证最优子结构不够。0-1 背包满足最优子结构（它的 DP 就依赖它），但**不满足贪心选择性质**——所以 0-1 背包贪心失败、DP 成功。**两个性质缺一不可**，贪心选择性质才是贪心与 DP 的分水岭。

## 4 公式解析：贪心 vs DP 的选择顺序

用「选择-子问题」的先后关系看两种范式。设原问题 $P$，贪心选择 $g$ 后剩子问题 $P'$：

$$\text{贪心}:\quad \underbrace{g}_{\text{先选}} \to \text{解 } P' \qquad \text{DP}:\quad \underbrace{\text{解所有 } P_i'}_{\text{先解子问题}} \to \text{选 } \max_i$$

- **第一步，贪心顺序**：先做「局部最优」选择 $g$，再用同样方法解剩余 $P'$——每个选择 $O(1)$，总时间由「选择次数」主导。
- **第二步，DP 顺序**：先解所有子问题（填表），再从多个候选中取最优——时间由「状态数 × 每状态枚举」主导。
- **第三步，本质差异**：贪心把「选择」提前、把「探索」砍掉；DP 保留全部探索。**贪心正确的前提是「有一个最优解以贪心选择开头」**——这是贪心选择性质。

**要点**：若贪心选择性质成立，DP 表里的「max/min」其实只有一个候选会胜出——贪心就是「早知道自己会赢」的 DP。<span class="marginnote">这就是为什么教材常说「贪心是动态规划的特例」。当且仅当「每个状态的转移只有唯一最优选择」时，DP 退化成一连串贪心。检验一个优化问题：画出它的 DP 转移，若每个状态的最优选择「一眼可判」，贪心多半可行。</span>

## 5 何时怀疑贪心：危险信号

几个「贪心可能错」的信号：

- **零头问题**：选择后留下无法被后续利用的剩余（0-1 背包）。
- **跨选择耦合**：当前选择影响未来多个选择的可行性（TSP）。
- **无交换对称性**：找不到「可替换不损优」的对（图着色）。

对应地，贪心通常可靠的信号：

- **可交换**：选择之间可以「替换」而不破坏结构（分数背包、活动选择）。
- **可排序**：存在一个全序，按序贪心就是最优（性价比序、结束时间序）。
- **每步独立**：选择后剩余问题与原问题同构（贪心选择的递归不变性）。

## 6 小结

- **贪心算法**：每步做局部最优选择，从不回溯；不是总正确，必须验证。
- **贪心选择性质**：存在以贪心第一步为起点的全局最优解——用交换论证证明。
- **最优子结构**：贪心后剩余问题仍可递归最优——用剪贴论证证明。
- 两性质缺一不可：0-1 背包有最优子结构但无贪心选择性质，故贪心失败。
- 贪心是 DP 的特例加速：「每个状态只有一个最优选择」时 DP 退化为贪心。

在下一课，我们用活动选择问题落地这套理论——按结束时间排序的贪心为什么必然最优，并给出完整的交换论证。
