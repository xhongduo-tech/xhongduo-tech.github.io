## 为什么从带权中位数开始

前几课我们学了「找第 $k$ 小」的技术，这一课看它的**应用**。问题是：一条街道上有 $n$ 户人家，每户每天出行次数（权重）不同，邮局建在哪里，能让所有人到邮局的**加权总距离最小**？<span class="marginnote">这不是巧合的趣味题——它是「一维设施选址（1-median）」的经典模型。它出现在聚类（k-median 的一维特例）、线性回归的鲁棒中心、供应链选址、甚至均衡负载分配里。而这个问题的答案惊人地简单：<strong>建在带权中位数处</strong>。</span>

这一课揭示带权中位数与普通中位数的联系、如何用顺序统计量在 $O(n)$ 内找到它，以及它与均值的本质区别。

## 1 问题定义与两个候选答案

**带权中位数（weighted median）**：给定 $n$ 个不同元素 $x_1 < x_2 < \cdots < x_n$，权重 $w_1, \dots, w_n > 0$ 且 $\sum w_i = 1$。**带权中位数**是满足「左边权重和 ≤ 1/2 且右边权重和 ≤ 1/2」的那个元素 $x_k$：

$$\sum_{i<k} w_i \le \frac{1}{2} \quad \text{且} \quad \sum_{i>k} w_i \le \frac{1}{2}$$

**最近邮局问题（post-office location problem）**：求 $x$ 使 $f(x) = \sum_{i=1}^n w_i |x - x_i|$ 最小。直觉给两个候选：

- **均值** $\bar x = \sum w_i x_i$：最小化的是加权**平方**距离 $\sum w_i (x-x_i)^2$——把偏远的住户「平方放大」，均值会被大权重拉偏。
- **带权中位数**：最小化的是加权**绝对**距离 $\sum w_i |x-x_i|$。

结论：**对绝对距离，最优解是带权中位数**（不唯一时取区间内的任意点）。<span class="marginnote">「均值 vs 中位数」的选择在统计学里是经典二选一：平方损失选均值（回归），绝对损失选中位数（鲁棒估计，对离群点不敏感）。带权中位数就是「绝对损失 + 权重」的解——离群点只会被「翻倍计权」，不会被平方放大。</span>

## 2 为什么带权中位数最优：边际分析

直观论证「往左挪一点还是往右挪一点」：设在位置 $x$，把所有住户按位置排序。**把 $x$ 向右移动无穷小量 $dx$**：

- 左边（$x_i < x$）的住户，距离增加 $dx$，代价增加 $\sum_{x_i < x} w_i \cdot dx$；
- 右边（$x_i > x$）的住户，距离减少 $dx$，代价减少 $\sum_{x_i > x} w_i \cdot dx$。

净变化 $= \left(\sum_{x_i<x} w_i - \sum_{x_i>x} w_i\right) dx$。当左边权重和 < 1/2 时净变化为负——**往右挪更优**；当左边权重和 > 1/2 时净变化为正——**往左挪更优**。平衡点正是「左右权重各约 1/2」的位置，即带权中位数。<span class="marginnote">这个「挪动一点点看边际变化」的论证是优化里「一阶条件」的朴素版：凸函数的极小点处，左右导数必须「夹住 0」。$f(x)$ 是凸的分段线性函数，其极小点恰是「左侧斜率从负转正」的地方。</span>

**辨析｜易错点：** 若「左边 ≤ 1/2 且右边 ≤ 1/2」同时被两个相邻元素满足（中间整段都是最优），答案不唯一。工程上取「第一个左边权重 > 1/2 的元素」或「最后一个左边权重 ≤ 1/2 的元素」都正确——关键是别把「唯一中位数」误当成必然存在。

## 3 算法：用顺序统计量在 $O(n)$ 内找带权中位数

朴素做法：先排序（$O(n\log n)$）再累加权重找分界点。但顺序统计量给出 $O(n)$ 方案——**分治 + 剪枝**：

```
WEIGHTED-MEDIAN(x[1..n], w[1..n], totalW)
  if n == 1  return x[1]
  find the median element x[k] of the current set   // 用 SELECT，O(n)
  leftW  = sum of weights of elements < x[k]
  rightW = sum of weights of elements > x[k]
  if leftW <= 1/2 and rightW <= 1/2
    return x[k]                        // 它就是带权中位数
  else if leftW > 1/2
    recurse on elements < x[k]          // 答案在左边，右边剔除
  else
    recurse on elements > x[k]          // 答案在右边，左边剔除
```

每次用 SELECT 找当前集合的中位数 $O(n)$，然后按左右权重决定递归方向，**只走一边**。$T(n) = T(n/2) + O(n) = O(n)$。<span class="marginnote">与 RANDOMIZED-SELECT 的「单臂递归」同构：每层线性工作 + 单侧递归 = 线性总时间。这里 SELECT 可用随机化版本（期望线性）或最坏线性版本——应用的灵活之处在于可以按需选底层的顺序统计量子程序。</span>

**辨析｜易错点：** 递归条件别写反。`leftW > 1/2` 说明左边太重，答案（让左右均衡的点）在**左边**，必须递归左半；若误判方向，分治会越走越偏。**「权重在哪边失衡，答案就在哪边」**——权重像质量，带权中位数是「质量中心」。

## 4 公式解析：为什么是「权重和 ≤ 1/2」而非「个数 ≤ n/2」

普通中位数是带权中位数的特例（$w_i = 1/n$）。此时左右权重和 ≤ 1/2 ⟺ 左右元素个数 ≤ n/2——普通中位数条件自动浮现。拆解：

$$\sum_{i<k} w_i \le \frac{1}{2} \quad \Longleftrightarrow \quad (\text{当 } w_i = 1/n) \quad \frac{k-1}{n} \le \frac{1}{2} \Longleftrightarrow k \le \frac{n}{2}+1$$

- **第一步，看普通情形**：均匀权重下，条件退化为「中位数左边至多一半」——这就是我们熟悉的「第 $\lceil n/2 \rceil$ 个元素」。
- **第二步，看权重偏移**：非均匀权重时，「质量中心」从「位置中间」被拉向「权重集中的地方」——一个权重 0.9 的点会把带权中位数吸到它附近。
- **第三步，看最优性**：带权中位数使 $\sum w_i|x-x_i|$ 最小；若目标是 $\sum w_i(x-x_i)^2$，则最优解是加权均值 $\bar x$——**目标函数决定「中心」的定义**。

**要点**：带权中位数把「中位数」从「第几个」升级为「权重在哪平衡」。同一个顺序统计量框架，套上不同权重就是不同问题的解——这是「算法 + 建模」的分工。<span class="marginnote">把权重换成概率，带权中位数就是「使期望绝对偏差最小的估计量」；这在鲁棒统计与量化投资（绝对风险的最小化）里都是标准工具。与第二级《概率论》里「期望」的联系在这里闭合。</span>

## 5 小结

- **带权中位数**：左边权重和 ≤ 1/2 且右边权重和 ≤ 1/2 的元素；普通中位数是其 $w_i = 1/n$ 特例。
- **最近邮局问题**：$\min \sum w_i|x-x_i|$ 的最优解是带权中位数；最小化平方距离则用加权均值。
- 最优性靠**边际分析**：左右导数在带权中位数处「夹住 0」（凸函数一阶条件）。
- 算法：SELECT 找中位数 + 按左右权重单侧递归，$O(n)$。
- 「均值 vs 中位数」取决于目标函数：平方损失 vs 绝对损失。
