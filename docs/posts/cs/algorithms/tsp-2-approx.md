## 为什么从 TSP 近似开始

TSP 是 NPC，而且比顶点覆盖更「难近似」——一般 TSP（无额外假设）**没有任何**常数近似比（除非 P=NP）。但现实世界的距离（欧氏、测地、网络延迟）几乎都满足**三角不等式**：$c(u,v) \le c(u,w) + c(w,v)$（捷径不绕远）。在三角不等式下，TSP 有漂亮的 2-近似，甚至 1.5-近似的 Christofides 算法。<span class="marginnote">三角不等式是 TSP 近似的「开关」：没有它，问题太任意（可以用权值编码任意结构）；有了它，MST 与回路之间建立了可量化的关系——「删掉回路的一条边得到一棵树」这个朴素事实成为近似的支点。这解释了「近似能做多好」如何被结构假设决定。</span>

这一课讲 MST 双倍遍历的 2-近似算法与它的证明。

## 1 算法：最小生成树 + 深度优先

**APPROX-TSP-TOUR**：

```
APPROX-TSP-TOUR(G, c)
  1. 求 G 的最小生成树 T（Prim 或 Kruskal）
  2. 对 T 做一次深度优先遍历，列出访问顶点的顺序
  3. 返回该顺序构成的哈密顿回路（跳过重复顶点）
```

直觉：MST 是「连接所有城市的最便宜骨架」；沿 MST 的边「走一圈」（每条边正反各一次）是一条访问所有顶点的闭合路径，总代价 = $2 \times w(T)$；把它「短路」（跳过重复访问）成哈密顿回路，由三角不等式，代价只会更小。<span class="marginnote">「先绕树走一圈，再短路成回路」是这个算法的灵魂。绕树一周每条边被走两次（$2w(T)$）；跳过已访问顶点时，三角不等式保证「走捷径」不会比「沿原路径绕」贵。于是回路代价 ≤ $2w(T)$。MST 与 TSP 的联系就这样建立。</span>

## 2 公式解析：为什么回路 ≤ 2 × MST

设 $T$ 是 MST，$H$ 是算法的回路。

**核心不等式链**：

$$c(H) \le 2 \cdot w(T) \le 2 \cdot C^*$$

- **第一步，$c(H) \le 2w(T)$**：沿 $T$ 深度优先遍历，每条树边正反各一次，得到闭合游走代价 $2w(T)$；短路成 $H$ 后，由三角不等式每次「跳跃」≤ 沿原路径绕的代价——$c(H) \le 2w(T)$。
- **第二步，$w(T) \le C^*$**：从最优回路 $C^*$ 中删掉一条边，得到一棵**生成树**，其权 ≤ $C^*$。$T$ 是最小生成树，所以 $w(T) \le$ 这棵树的权 ≤ $C^*$。
- **第三步，合并**：$c(H) \le 2w(T) \le 2C^*$——**2-近似**。<span class="marginnote">第二步是最关键也最容易被忽略的一笔：任何回路删一边就是生成树，所以「最优回路 ≥ MST 权」。这个「回路 ⊃ 树」的朴素关系，把 TSP 的最优值用 MST 锚定。近似算法证明里「找一个最优解的子结构当锚点」是通用套路——这里锚点是 MST。</span>

**要点**：2-近似的两个不等式分别是「三角不等式（上界）」与「回路删边成树（下界）」的合体——结构假设与最优值锚定，缺一不可。

## 3 为什么要三角不等式：反例

若没有三角不等式，上述证明的第一步失效：跳过重复顶点时的「捷径」可能比原路贵得多。事实上，**一般 TSP 不存在任何常数近似**（除非 P=NP）。<span class="marginnote">证明思路：若一般 TSP 有 $\rho$-近似，用它就能解哈密顿回路——把「边权 1（原边）与 2（非边）」的构造塞给它，近似解能区分「有回路」与「无回路」，从而多项式解 NPC——矛盾。所以「三角不等式」不是可有可无的假设，而是「近似可行性」的门槛。</span>

**辨析｜易错点：** 三角不等式要求**完全图**上任意三点满足 $c(u,v) \le c(u,w)+c(w,v)$。若图本身缺边（非完全），要先补全（补上的边权 = 原图最短路径距离），再跑近似——补全后的距离满足三角不等式。

## 4 提升：Christofides 的 1.5-近似

2-近似可以改进：**Christofides 算法**（1976）把比值降到 1.5——用「MST + 最小权完美匹配」修补奇度顶点。

```
CHRISTOFIDES(G, c)
  1. 求 MST T
  2. 令 O = T 中奇数度的顶点集
  3. 在 O 上求最小权完美匹配 M（|O| 是偶数）
  4. 求 T ∪ M 的欧拉回路，再短路成哈密顿回路 H
```

**比值**：$c(H) \le w(T) + w(M) \le C^* + \frac{1}{2}C^* = 1.5 C^*$（匹配权 ≤ 最优回路的一半，由「最优回路在 O 上交替取边」论证）。<span class="marginnote">Christofides 的 1.5 保持了 40 余年的纪录（TSP 近似比的上界），近年才有微小改进（1.5 - 极小常数）。它展示了近似算法的进阶套路：MST 打底 + 匹配修奇点 + 欧拉回路衔接。理解 2-近似是理解 Christofides 的必经之路。</span>

## 5 小结

- **TSP 2-近似**：MST + 深度优先遍历 + 短路成回路。
- **证明**：$c(H) \le 2w(T)$（三角不等式）+ $w(T) \le C^*$（回路删边成树）⟹ 2-近似。
- **三角不等式是命门**：一般 TSP 无常数近似（否则可解哈密顿回路）。
- 非完全图先补全（最短路径距离）再近似。
- **Christofides**：MST + 奇度顶点最小匹配 + 欧拉回路，1.5-近似。
