## 为什么从矩阵链乘法开始

三个矩阵相乘 $A_1 A_2 A_3$，可以先算 $A_1A_2$ 再乘 $A_3$，也可以先算 $A_2A_3$ 再乘 $A_1$——结果相同，但**标量乘法次数可能相差巨大**。<span class="marginnote">例：$A_1$ 是 $10\times30$，$A_2$ 是 $30\times5$，$A_3$ 是 $5\times60$。方案 $((A_1A_2)A_3)$ 需要 $10\cdot30\cdot5 + 10\cdot5\cdot60 = 4500$ 次；方案 $(A_1(A_2A_3))$ 需要 $30\cdot5\cdot60 + 10\cdot30\cdot60 = 27000$ 次——相差 6 倍。</span>

这是**区间型（区间 DP）**的第一次登场：状态是「子矩阵链 $A_i..A_j$」，不是前缀而是任意区间。它引入了一个新维度——**子问题依赖多个、且嵌套的区间**，比钢条切割的一维状态复杂一个台阶。

## 1 问题定义与穷举的灾难

给定矩阵链 $A_1 A_2 \cdots A_n$，其中 $A_i$ 的维数为 $p_{i-1} \times p_i$（相邻矩阵维数兼容）。**目标**：找一个括号化方式，使标量乘法总次数最少。

穷举所有括号化方案：设 $P(n)$ 是 $n$ 个矩阵的括号化方案数，它满足卡特兰数递推

$$P(n) = \begin{cases} 1, & n=1 \\ \sum_{k=1}^{n-1} P(k)P(n-k), & n \ge 2 \end{cases}$$

解为卡特兰数 $P(n) = \Omega(4^n/n^{3/2})$——**指数爆炸**。$n = 30$ 时方案数已超过 $10^{16}$，穷举不可行。<span class="marginnote">卡特兰数在《组合数学》（第二级）里会系统学习。这里只需知道：括号化的方案数是指数级的，所以必须找结构化方法——而「最后的分割点 $k$」恰好给了 DP 的递归入口。</span>

## 2 最优子结构与递归定义

**关键观察**：考虑链 $A_i..A_j$（$i \le j$）的最优括号化。它最后一步必然是「在某处 $k$ 处劈开」，先算 $A_i..A_k$ 与 $A_{k+1}..A_j$，再把两个结果相乘。设 $m[i][j]$ = 计算 $A_i..A_j$ 的最少标量乘法次数，则

$$m[i][j] = \begin{cases} 0, & i = j \\ \min_{i \le k < j} \left\{ m[i][k] + m[k+1][j] + p_{i-1} p_k p_j \right\}, & i < j \end{cases}$$

其中 $p_{i-1} p_k p_j$ 是「两个子链结果相乘」的代价：$(p_{i-1}\times p_k)$ 与 $(p_k \times p_j)$ 相乘需要 $p_{i-1} p_k p_j$ 次标量乘法。<span class="marginnote">「最后的分割点」是区间 DP 的核心技巧：不关心内部怎么切，只枚举「最后一步切在哪」。最优子结构由「最后一步」反推：最优解的最后一步劈在 $k$，则两段各自必是最优。</span>

**辨析｜易错点：** $m[i][j]$ 的索引是**区间** $[i,j]$，不是前缀。填表时**必须按区间长度从小到大**：先算所有长度为 1 的（0 次），再长度为 2、3……因为 $m[i][j]$ 依赖更短区间 $m[i][k]$ 与 $m[k+1][j]$。若按 $i$ 从小到大填，会用到尚未计算的区间。

## 3 自底向上填表

```text
MATRIX-CHAIN-ORDER(p):
    n ← p.length − 1
    令 m[1..n][1..n] 与 s[1..n−1][2..n] 初始化为 0
    for l ← 2 to n:                     // 区间长度从小到大
        for i ← 1 to n − l + 1:
            j ← i + l − 1
            m[i][j] ← ∞
            for k ← i to j − 1:
                q ← m[i][k] + m[k+1][j] + p[i−1]·p[k]·p[j]
                if q < m[i][j]:
                    m[i][j] ← q
                    s[i][j] ← k         // 记录最优分割点
    return m 和 s
```

外层按区间长度 $l$ 从 2 到 $n$，内层枚举起点 $i$ 与分割点 $k$。$i$ 记录「使 $m[i][j]$ 最优的分割点」，供回溯构造括号化方案。<span class="marginnote">三重循环的结构是区间 DP 的标准模板：外层长度、中层起点、内层分割点。无数区间问题（最优 BST、石子合并、括号匹配、凸多边形三角剖分）都是这个模板换转移式。</span>

## 4 公式解析：$m[i][j] = \min_{k}(m[i][k] + m[k+1][j] + p_{i-1}p_kp_j)$ 的时间复杂度

算法时间由三重循环决定：

$$T(n) = \sum_{l=2}^{n}\sum_{i=1}^{n-l+1}\sum_{k=i}^{j-1} O(1) = \Theta(n^3)$$

- **第一步，外层长度 $l$**：从 2 到 $n$，共 $n-1$ 种。
- **第二步，中层起点 $i$**：给定 $l$，$i$ 有 $n-l+1$ 个选择，$j = i+l-1$。
- **第三步，内层分割 $k$**：$k$ 从 $i$ 到 $j-1$，共 $l-1$ 个选择。

三重循环总量 $\sum_l (n-l+1)(l-1) = n^3/6 + O(n^2) = \Theta(n^3)$。**空间**：$m$ 与 $s$ 都是 $n\times n$，$O(n^2)$。<span class="marginnote">$n^3$ 对「指数穷举」是巨大改进：$n=30$ 时约 27000 次操作（穷举要 $10^{16}$）。虽不是多项式最优（有 $O(n^2)$ 的 Hu-Shing 算法），但 $n^3$ 的清晰模板已足够绝大多数场景。</span>

**要点**：区间 DP 的复杂度通常是「区间数 × 分割点数」= $O(n^3)$。看到「区间 $[i,j]$ + 枚举 $k$」的三重循环，心里就要有 $\Theta(n^3)$ 的预期。

## 5 构造最优括号化方案

记录在 $s$ 表里的分割点，通过递归回溯还原括号化：

```text
PRINT-OPTIMAL-PARENS(s, i, j):
    if i = j:
        输出 "A" 与 i                   // 单个矩阵
    else:
        输出 "("
        PRINT-OPTIMAL-PARENS(s, i, s[i][j])
        PRINT-OPTIMAL-PARENS(s, s[i][j] + 1, j)
        输出 ")"
```

例如 $n=6$、$s[1][6]=3$，则整链先劈在 3：$A_1..A_3$ 与 $A_4..A_6$，再分别递归。**四步法的第 4 步在此落地**：最优值在 $m$ 表，最优方案靠 $s$ 表的决策回溯。<span class="marginnote">「值表 + 决策表」是 DP 构造方案的通用搭配：值表回答「多少」，决策表回答「怎么做」。凡是需要输出方案的问题（不只是最优值），都要额外存决策。</span>

## 6 小结

- **矩阵链乘法**：不同括号化方案计算量差可达指数倍；目标是最少标量乘法。
- 穷举方案数是卡特兰数，指数爆炸；**区间 DP** 用「最后分割点 $k$」建模。
- 转移式 $m[i][j] = \min_k(m[i][k] + m[k+1][j] + p_{i-1}p_kp_j)$，$m[i][i]=0$。
- 填表按**区间长度从小到大**；三重循环模板 $\Theta(n^3)$，空间 $O(n^2)$。
- $s$ 表存分割点，递归回溯构造括号化方案。
