# RSA 公钥密码体制：密钥生成、加密与正确性

## 为什么从 RSA 开始

前面几课的数论工具——欧几里得、扩展欧几里得、快速幂、CRT——在这里汇成一座大厦：**RSA**，第一个实用公钥密码体制。<span class="marginnote">RSA 的安全基础是「大整数分解很难」：公钥公开（$n, e$），私钥秘密（$d$），而 $d$ 的计算需要 $\varphi(n)$——需要分解 $n$。只要分解困难，私钥就安全。这一课是把「数论算法」用于「信息安全」的巅峰，也是《密码学与信息安全》专题的前置。</span>

这一课讲密钥生成、加解密、正确性证明（费马小定理）与安全性论证。

RSA 值得单独一课的另一个原因是它把「算法分析」的视野带进了真实世界：别的算法课我们关心「最快」，密码学里我们关心「最难」。RSA 的存在本身就是一个实验——**一个公认「难」的数学问题（大整数分解），被工程化地用作安全地基**。看懂 RSA，等于看懂「难度假设如何变成产品」。这条思路会一直延续到本专题后面的素性测试与 Pollard rho——它们分别从「怎么安全造素数」和「分解到底多难」两个方向补全 RSA 的故事。

## 1 密钥生成

**RSA 密钥生成**：

```text
1. 随机选两个大素数 p, q（约 1024 位）
2. n = p × q；φ(n) = (p − 1)(q − 1)
3. 选整数 e，满足 1 < e < φ(n) 且 gcd(e, φ(n)) = 1
4. 计算 d ≡ e⁻¹ (mod φ(n))          // 扩展欧几里得求逆
5. 公钥 = (n, e)；私钥 = d；销毁 p, q, φ(n)
```

**公钥** = $(n, e)$，**私钥** = $d$。<span class="marginnote">关键点：$\varphi(n) = (p-1)(q-1)$ 只在「知道 $p, q$」时能算；外人只知道 $n$，算 $\varphi(n)$ 等价于分解 $n$。所以「私钥 $d = e^{-1} \bmod \varphi(n)$」对攻击者不可得——除非能分解 $n$。这个「陷门」是 RSA 安全的全部。</span>

**生成时的两条工程纪律**：第一，$p, q$ 必须是**随机独立**的大素数（靠下一课的 Miller-Rabin 概率测试筛选），否则两把不同私钥可能撞出公共因子。第二，生成完成后**必须销毁 $p, q$ 与 $\varphi(n)$**——它们留在内存里就是后门；实际实现里往往用「强素数」并在密钥使用后立刻清空相关缓冲区。**密钥生成的安全性，一半在数学，一半在卫生习惯**。

## 2 加密与解密

**加密**：把明文 $M$（$0 \le M < n$）用公钥 $(n, e)$ 加密：

$$C = M^e \bmod n$$

**解密**：用私钥 $d$ 解密：

$$M = C^d \bmod n$$

两个模幂都用**快速幂**（$O(\log e)$ / $O(\log d)$ 次模乘）完成。<span class="marginnote">加密只用到「幂」——任何人用公钥都能加密；解密需要私钥 $d$——只有知道 $\varphi(n)$ 的人能算出 $d$。这个「公钥加密、私钥解密」的不对称性，就是「公钥密码」名字的由来。实际系统里 RSA 常只加密「会话密钥」（混合加密），因为 RSA 对大明文慢。</span>

**加密为什么可以公开做**：加密方不需要任何秘密——他只知道 $(n, e)$。这带来一个现代密码学的基本要求：**公钥密码必须抗「选择明文攻击」**——攻击者能拿到任意明文的密文，也不许他推出其他密文的明文。裸 RSA（教科书版）不满足这个要求，所以实战要加**填充（padding）**（如 OAEP），把确定性加密变成概率性加密——同一个明文每次密文都不同，攻击者无法利用「相同明文相同密文」的性质。**「教科书 RSA」与「安全 RSA」之间的全部距离，就是一层填充**。

## 3 正确性：为什么解密能还原

**定理**：若 $ed \equiv 1 \pmod{\varphi(n)}$，则 $M^{ed} \equiv M \pmod n$。

**证明**（费马小定理 + 中国剩余定理）：

$$M^{ed} \equiv M^{1 + k\varphi(n)} \equiv M \cdot (M^{\varphi(n)})^k \pmod n$$

- **第一步，指数关系**：$ed = 1 + k\varphi(n)$（$d$ 是 $e$ 模 $\varphi(n)$ 的逆元）。
- **第二步，费马小定理**：若 $\gcd(M, p) = 1$，则 $M^{p-1} \equiv 1 \pmod p$；又 $\varphi(n) = (p-1)(q-1)$ 是 $p-1$ 的倍数，故 $M^{\varphi(n)} \equiv 1 \pmod p$——于是 $M^{ed} \equiv M \pmod p$。若 $\gcd(M,p) \ne 1$（$M$ 是 $p$ 的倍数），两边也 ≡ 0，仍成立。
- **第三步，CRT 拼回**：同理 $M^{ed} \equiv M \pmod q$；由 CRT（$p, q$ 互素），$M^{ed} \equiv M \pmod{pq} = \pmod n$——解密还原。<span class="marginnote">证明的最后一步依赖 CRT：分别证明「模 $p$ 还原」与「模 $q$ 还原」，因 $p,q$ 互素，CRT 保证「模 $pq$ 也还原」。这个「分开证再拼回」是 RSA 正确性证明的标准结构——又一次「分治拼回」。费马小定理是整个证明的引擎，它在本专题与《数论》专题都是核心定理。</span>

**为什么可以只验 $M^{ed} \equiv M$ 而不验别的**：解密是 $C^d = (M^e)^d = M^{ed}$，正确性只需要模 $n$ 下 $M^{ed}$ 还原为 $M$ 这一件事。它之所以不平凡，是因为 $ed$ 并不是 $1$，而是 $1 + k\varphi(n)$——**还原靠的是费马小定理让「指数减 $\varphi(n)$ 等价于指数减 1」**。把「指数空间里 $\varphi(n)$ 像 0 一样」这个观察记住，RSA 正确性就再也忘不掉。

## 4 公式解析：安全性论证——为什么难破解

攻击者已知 $n, e, C$，想求 $M$ 或 $d$。两条路都卡在分解：

$$d \equiv e^{-1} \pmod{\varphi(n)}, \qquad \varphi(n) = (p-1)(q-1), \qquad n = pq$$

- **第一步，目标**：解密需 $d$；$d$ 由 $\varphi(n)$ 决定；$\varphi(n)$ 由 $p, q$ 决定。
- **第二步，困难点**：只知道 $n$，求 $p, q$（分解 $n$）——**目前无多项式算法**（第十五篇的 Pollard rho 只是启发式，对 2048 位 $n$ 不可行）。
- **第三步，等价性**：已知 $n, e, d$ 可多项式地分解 $n$（构造算法），所以「求 $d$」与「分解 $n$」难度相当——**RSA 的安全性不弱于整数分解**。

**要点**：RSA 安全建立在「分解 $n$ 难」之上；而分解难是「没有已知多项式算法」的经验事实，**不是证明**。<span class="marginnote">「安全性」与「难度」的微妙处：RSA 依赖「分解难」这一<strong>假设</strong>（许多人认为分解是 NP 中间态，但未证明）。量子计算出现后，Shor 算法能多项式分解——RSA 在量子时代不安全，这就是「后量子密码」研究的动因。理解「安全 = 依赖一个未证明但广泛相信的假设」是密码学的第一课。</span>

**分解的实际难度曲线**：对 $\approx 10^2$ 位的小 $n$，普通台式机几秒分解；512 位在 1999 年由 RSA-512 挑战赛分解（动用数百台机器）；1024 位至今仍被视为「勉强安全、正在退役」；2048 位与 3072 位是目前主流。这个「位数翻倍、难度暴涨」的经验曲线，正是密钥长度选择的依据——**安全不是「绝对不可能」，而是「代价远大于收益」**。密码学里的「安全」，永远是经济学问题。

## 5 数值算例：用小素数完整跑一遍 RSA

理论全通，用手算规模（CLRS 31.7 节的经典数字）把密钥生成、加密、解密、验正确性完整走一遍。

**第一步，密钥生成**：取 $p = 61,\ q = 53$。则 $n = 61 \times 53 = 3233$，$\varphi(n) = 60 \times 52 = 3120$。选 $e = 17$（与 3120 互素）。用扩展欧几里得求 $d = 17^{-1} \bmod 3120$：$17 \times 2753 = 46801 = 15 \times 3120 + 1$，故 $d = 2753$。公钥 $(3233, 17)$，私钥 $2753$。

**第二步，加密**：设明文 $M = 65$（一个英文字母的 ASCII）。则

$$C = 65^{17} \bmod 3233 = 2790$$

**第三步，解密**：用私钥还原 $M = 2790^{2753} \bmod 3233 = 65$。✓

**第四步，验证正确性链条**：$ed = 17 \times 2753 = 46801 = 1 + 15 \times 3120$，即 $ed = 1 + k\varphi(n)$ 且 $k = 15$。按正确性证明，$M^{ed} = M^{1 + 15\varphi(3233)} \equiv M$ 同时模 $p=61$ 与模 $q=53$，CRT 拼回模 $3233$——数字对上了。

这个算例的价值：**每个步骤都是手工可验的**。公钥任何人能拿到（$n, e$ 公开），但要解出 $M$ 需要 $d$；而 $d$ 依赖 $\varphi(n) = 3120$——外人只能看到 $n = 3233$，要分解成 $61 \times 53$ 才算得出 $\varphi(n)$。**「公钥容易加密、私钥藏住陷门」在这里得到最直观的演示**。<span class="marginnote">这个例子用的素数太小，几秒就能暴力分解——实战要 2048 位（约 600 位十进制）的 $n$。但「小例子能把机制走通，大参数只是把同一个机制放大」——理解 RSA 只需这个 4 位数规模的版本。</span>

## 6 术语速查

| 术语 | 含义 | 一句话记忆 |
| --- | --- | --- |
| 公钥 $(n, e)$ | 公开，用于加密 | 锁，人人都能锁 |
| 私钥 $d$ | 秘密，用于解密 | 钥匙，只有你有 |
| $\varphi(n)$ | $(p-1)(q-1)$，只有知道 $p,q$ 才可算 | 私钥的源头 |
| 陷门 | 公钥公开但反算私钥需分解 $n$ | 单向门 |
| 混合加密 | RSA 只加密对称会话密钥 | 快与安全兼得 |
| CRT 加速 | 解密拆到模 $p$、模 $q$ 分别算 | 快 4 倍 |

**辨析｜易错点：** $p$ 与 $q$ 不能太接近（否则 $n$ 的平方根附近就能撞出因子）；$e$ 通常取 $65537 = 2^{16}+1$（二进制只有两个 1，快速幂极快）；**消息 $M$ 必须满足 $0 \le M < n$**，更大消息要分块。另外「$ed \equiv 1 \pmod{\varphi(n)}$」里的模数是 $\varphi(n)$ 不是 $n$——这是初学最常抄错的一处。

## 7 小结

- **密钥生成**：选 $p,q$ → $n, \varphi(n)$ → 选 $e$ → 算 $d = e^{-1}$（扩展欧几里得）。
- **加解密**：$C = M^e \bmod n$，$M = C^d \bmod n$——都靠快速幂。
- **正确性**：$ed \equiv 1 \pmod{\varphi(n)}$ + 费马小定理 + CRT ⟹ $M^{ed} \equiv M$。
- **安全性**：求 $d$ 等价于分解 $n$；依赖「分解难」假设。
- 实践：混合加密（RSA 加密会话密钥）、CRT 加速解密、后量子威胁（Shor 算法）。

在下一课，我们回到数论的核心判定问题——**素性测试**：费马小定理给启发、Miller-Rabin 给出多项式时间的概率测试。
