## 为什么从素性测试开始

RSA 需要生成大素数（2048 位）——但「怎么知道一个大数是素数」？试除法对 $10^{600}$ 量级的数完全不可行。**素性测试**回答这个问题，而主角是 **Miller-Rabin**：一个**概率性**多项式算法，错误率可降到任意小。<span class="marginnote">素性测试与「因子分解」是镜像关系：判定「是否素数」容易（概率多项式），找出「怎么分解」难（无多项式算法）。这个「判定易、分解难」的不对称正是 RSA 安全的根基——Miller-Rabin 保证「你选到的是素数」，而分解难题保证「别人破不了你的 RSA」。</span>

这一课讲费马小定理的朴素测试、它的反例（Carmichael 数）、以及 Miller-Rabin 如何修复。

## 1 费马小定理与朴素测试

**费马小定理（Fermat's little theorem）**：若 $p$ 是素数且 $\gcd(a, p) = 1$，则

$$a^{p-1} \equiv 1 \pmod p$$

**朴素费马测试**：对候选 $n$，随机取 $a$，检查 $a^{n-1} \equiv 1 \pmod n$。若不等，$n$ 必是合数（费马小定理的逆否）；若等，$n$「可能是素数」。<span class="marginnote">费马测试是「必要但不充分」：素数必通过，但<strong>合数也可能通过</strong>。通过费马测试的合数叫「伪素数」；更麻烦的是 <strong>Carmichael 数</strong>——对<strong>所有</strong>与 $n$ 互素的 $a$ 都通过测试的合数（如 561 = 3·11·17）。对 Carmichael 数，随机选 $a$ 的费马测试几乎总是误判——朴素测试不可靠。</span>

## 2 Miller-Rabin：把「可能素数」钉死

**Miller-Rabin** 加强费马测试：把 $n-1$ 写成 $n - 1 = 2^t u$（$u$ 奇数），然后沿「平方链」检查。

**定理（关键）**：若 $n$ 是素数，则对任何 $a$（$\gcd(a,n)=1$），数列

$$a^u, a^{2u}, a^{4u}, \dots, a^{2^t u} = a^{n-1}$$

要么**第一项 ≡ 1**，要么**在某处出现 ≡ -1**（否则从「≡1 的平方根」矛盾）。若两者都不出现，$n$ 必是合数。

```text
MILLER-RABIN(n, s):                 // 返回「n 是素数」的概率判定
    if n == 2: return TRUE
    if n < 2 或 n 为偶数: return FALSE
    将 n-1 写成 n - 1 = 2^t * u，其中 u 为奇数
    repeat s 次:
        随机选取 a ∈ {2, 3, ..., n-2}
        x = a^u mod n
        if x == 1 or x == n - 1: continue      // 这一轮通过
        for j = 1 to t - 1:
            x = x^2 mod n
            if x == n - 1: break               // 中途出现 ≡ -1，通过
        if x != n - 1: return FALSE            // 平方链未出现 -1，n 为合数
    return TRUE
```

**判定逻辑**：若 $n$ 是素数，定理保证任何 $a$ 都通过；若 $n$ 是合数，**至少 3/4 的 $a$ 会让测试暴露它**。<span class="marginnote">「合数时至少 3/4 的 $a$ 能暴露」是 Miller-Rabin 的核心性质（比费马测试强得多——没有 Carmichael 数式的漏洞）。所以做 $s$ 次独立随机测试，合数被误判的概率 ≤ $1/4^s$——取 $s = 50$ 时错误率 $< 10^{-30}$，比硬件故障率还低。这就是「概率几乎等于确定」。</span>

## 3 公式解析：错误率 $1/4^s$

设 $n$ 是合数，单次随机 $a$ 误判（$a$ 通过测试）的概率 ≤ $1/4$。$s$ 次独立测试全误判：

$$\Pr[\text{合数被误判为素数}] \le \left(\frac{1}{4}\right)^s$$

- **第一步，单次错误界**：对合数 $n$，「$a$ 通过 Miller-Rabin」的 $a$ 占比 ≤ $1/4$（CLRS 引理 31.38）。
- **第二步，独立重复**：$s$ 次独立随机 $a$ 全部误判的概率 ≤ $(1/4)^s$。
- **第三步，选择 $s$**：$s = 50$ 时 $(1/4)^{50} \approx 8 \times 10^{-31}$——「概率素数」实际上就是素数。

**要点**：Miller-Rabin 是 **Monte Carlo 算法**——结果有极小的错误概率，但运行时间严格多项式（$O(s \log^3 n)$）。「几乎总是对 + 多项式快」的组合，使它成为密码学的工业标准。<span class="marginnote">对比：<strong>AKS 算法</strong>（2002）是<strong>确定性</strong>多项式素性测试——但它常数大，实践中仍用 Miller-Rabin（快、错误率可忽略）。「概率算法实践胜出」的原因是：$10^{-30}$ 的错误率在物理上比「计算机随机故障」还低，确定性保证在实际意义下没有优势。这是「概率 vs 确定」最生动的现实案例。</span>

**辨析｜易错点：** Miller-Rabin 的判定要检查「$x == 1$ 或 $x == n-1$」作为通过条件，且平方链中「出现 $n-1$」即通过。**不能只检查最终 $x$**——平方链中途的「≡ -1」也是素数的重要特征。漏掉中途检查会把素数误判为合数。

## 4 素性测试在密码学中的应用

**RSA 密钥生成**：随机选奇数 → Miller-Rabin 测素性 → 通过即用（两个大素数拼 $n$）。
**Diffie-Hellman**：需要安全素数（$2p+1$ 形式）——素性测试是生成器选择的前置。
**同态加密/数字签名**：底层模数都是素数，素性测试保证结构正确。<span class="marginnote">密钥生成的流程：随机挑一个 $k$ 位奇数，先用「试除小素数」快速排除大部分合数（绝大多数奇数被 3、5、7 整除），再对幸存的跑 Miller-Rabin。这个「小筛子 + 概率测试」的组合把「生成大素数」从不可行变成毫秒级。理解它，就理解了密码系统如何量产「素数」。</span>

## 5 小结

- **费马小定理**：$a^{p-1} \equiv 1 \pmod p$（$p$ 素数）——必要不充分，有 Carmichael 数漏洞。
- **Miller-Rabin**：$n-1 = 2^t u$，沿平方链检查「首项 1 或出现 -1」；否则必为合数。
- **错误率** ≤ $1/4^s$：$s$ 次独立测试，$s=50$ 时 < $10^{-30}$。
- **Monte Carlo**：概率正确 + 多项式时间 $O(s\log^3 n)$——密码学工业标准。
- 应用：RSA/DH 密钥生成；「小筛子 + Miller-Rabin」让大素数生成毫秒级完成。
