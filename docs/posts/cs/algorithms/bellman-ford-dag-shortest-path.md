# 单源最短路径：Bellman-Ford 与 DAG 上的最短路径

## 为什么从 Bellman-Ford 开始

Dijkstra 算法（《数据结构》已学）很快，但**不能处理负权边**。现实里负权很常见：货币套利（汇率 log）、含「退款」的路径、差分约束系统。**Bellman-Ford 算法**是处理负权的标准武器，还能**检测负环**。<span class="marginnote">Bellman-Ford 的核心是「松弛」：对每条边反复尝试「能不能让起点到终点的距离更短」。它比 Dijkstra 慢（$O(VE)$），但适用范围广得多，而且它的「松弛思想」是整篇最短路课的共同语言——Dijkstra、DAG、Floyd-Warshall 全是松弛的变体。</span>

这一课讲 Bellman-Ford 的松弛框架、为什么 $|V|-1$ 轮就够，以及 DAG 上借助拓扑序的线性时间算法。

## 1 松弛与最短路径的结构

**松弛（relax）**：对边 $(u,v)$，若 $d[u] + w(u,v) < d[v]$，则更新 $d[v] = d[u] + w(u,v)$（「经过 $u$ 更近」）。$d[v]$ 是当前对「源点到 $v$ 的最短距离」的估计。

**最短路径的简单性**：若无负环，最短路径**至多含 $|V|-1$ 条边**（多于 $|V|-1$ 条边必有重复顶点 → 去掉环更短）。这是「$|V|-1$ 轮松弛」的根据。<span class="marginnote">「最短路径简单（无环）」是最短路理论的基石：任何含环的路径都可以删掉环（除非负环，但负环意味着「最短」无定义）使距离不增。于是只需考虑边数 ≤ $V-1$ 的路径——这决定了 Bellman-Ford 的轮数。</span>

## 2 Bellman-Ford 算法

```text
BELLMAN-FORD(G, w, s)
    INITIALIZE-SINGLE-SOURCE(G, s)          // 所有 d = ∞，d[s] = 0
    for i = 1 to |V| - 1:
        for each edge (u, v) in G.E:
            RELAX(u, v, w)                  // 第 i 轮松弛所有边
    for each edge (u, v) in G.E:
        if d[v] > d[u] + w(u, v)
            return FALSE                    // 存在负环
    return TRUE
```

**两阶段**：

**阶段一（$|V|-1$ 轮松弛）**：每轮对所有边松弛一次。第 $i$ 轮后，$d[v]$ 是「至多含 $i$ 条边」的最短路径长度。因为最短路径至多 $V-1$ 条边，$V-1$ 轮后 $d[v]$ 即真实最短距离。
**阶段二（负环检测）**：若还能松弛某条边，说明存在「可以无限变短」的负环——最短距离无定义，返回 FALSE。<span class="marginnote">为什么第 $V$ 轮还能松弛就说明有负环？第 $V$ 轮松弛若能改进 $d$，必然是因为某条最短路径需要 ≥ $V$ 条边——而简单路径最多 $V-1$ 条边，多出来的「边」只能是负环带来的「转圈更短」。负环检测就藏在这一轮。</span>

**复杂度**：$|V|-1$ 轮 × 每轮 $|E|$ 条边 = $O(VE)$。

## 3 DAG 上的最短路：拓扑序 + 一趟松弛

DAG 有拓扑排序，这让最短路变得极其简单：**按拓扑序逐个处理顶点，松弛它的所有出边**——每个顶点只需松弛一次。

```text
DAG-SHORTEST-PATHS(G, w, s)
    拓扑排序 G，得到顶点序
    INITIALIZE-SINGLE-SOURCE(G, s)          // 所有 d = ∞，d[s] = 0
    for 按拓扑序的每个顶点 u:
        for each edge (u, v) in G.Adj[u]:
            RELAX(u, v, w)                  // 每个顶点只需松弛一次
```

**正确性**：按拓扑序处理时，处理到 $u$ 时，所有能到达 $u$ 的顶点都已处理完毕，$d[u]$ 已是真实最短距离；松弛出边把 $d[u]$ 传播给后继。**每个顶点只被处理一次**，无负环问题（DAG 天然无环）。<span class="marginnote">为什么 DAG 版不需要 $V-1$ 轮？因为 Bellman-Ford 的「轮次」本质是「路径边数的逐层推进」；拓扑序一次就把所有「依赖」按序排好了——每个顶点松弛一次，等价于 Bellman-Ford 的所有轮。这是「拓扑序 = 一次性完成所有松弛」的洞察。</span>

**复杂度**：拓扑排序 $O(V+E)$ + 每边松弛一次 $O(E)$ = **$O(V+E)$ 线性时间**。

## 4 公式解析：为什么 $V-1$ 轮就够了

第 $i$ 轮松弛后，$d[v]$ ≤「从 $s$ 到 $v$ 的至多含 $i$ 条边的最短路径长度」。用归纳证明：

$$d^{(i)}[v] = \min_{\text{路径 } s \rightsquigarrow v,\; \text{边数} \le i} \text{len}(路径)$$

- **第一步，归纳基础（$i=0$）**：$d^{(0)}[s] = 0$（0 条边的路径），其余 $d = \infty$。
- **第二步，归纳步**：第 $i$ 轮对每条边 $(u,v)$ 松弛，若最优 $i$ 边路径的最后一条边是 $(u,v)$，其前缀是 $s\rightsquigarrow u$ 的 $i-1$ 边最优路径——松弛使 $d[v]$ 达到「$i$ 边最优」。
- **第三步，收尾**：任何简单路径边数 ≤ $V-1$，故 $i = V-1$ 轮后 $d[v]$ = 真实最短距离。

**要点**：**轮数 = 最短路径的最大边数 = $V-1$**。这是「松弛轮数与路径结构」的精确对应——Bellman-Ford 的 $O(VE)$ 直接由此而来。<span class="marginnote">一个实用的观察：如果图比较稀疏且「最坏路径」通常很短，实际往往只需很少几轮就收敛（可以提前检测：某轮无任何松弛就终止）。但最坏情形（长链路径）确实需要 $V-1$ 轮。</span>

**辨析｜易错点：** 负环检测必须在**所有 $V-1$ 轮之后**做——若提前检查，会把「还在收敛中」误判为负环。**先跑满 $V-1$ 轮，再扫一遍边看是否还能松弛**，顺序不能错。

## 5 应用

**货币套利**：汇率 $r_{ab}$ 满足 $w(a,b) = -\log r_{ab}$，则「套利环」= 负环。Bellman-Ford 检测负环即发现套利机会。
**差分约束系统**：约束 $x_j - x_i \le b_k$ 转成边 $i \to j$ 权 $b_k$，可行解 = 无负环的最短路距离。
**路由协议**：RIP 等距离向量协议与 Bellman-Ford 思想一致（分布式版本）。<span class="marginnote">差分约束是 Bellman-Ford 最精彩的间接应用：把一组线性不等式翻译成图的最短路问题，用「负环检测」判断可行性——这是「算法归约」的典范，把代数问题变成图问题。第十一篇的「归约」课会系统化这个思想。</span>

## 6 数值算例：带负权跑满三轮

图：$s \to a$（权 4）、$s \to b$（1）、$b \to a$（$-3$）、$a \to t$（2）、$b \to t$（5）。$V = 4$，需 $V-1 = 3$ 轮。

**初始化**：$d[s]=0$，其余 $\infty$。

| 轮 | 松弛顺序 | $d[a]$ | $d[b]$ | $d[t]$ |
| --- | --- | --- | --- | --- |
| 0 | 初始化 | $\infty$ | $\infty$ | $\infty$ |
| 1 | s→a, s→b, b→a, a→t, b→t | $-2$ | 1 | 0 |
| 2 | 同上 | $-2$ | 1 | 0 |
| 3 | 同上 | $-2$ | 1 | 0 |

第 1 轮内：s→a 使 $d[a]=4$，s→b 使 $d[b]=1$，随后 **b→a 的负权边把 $d[a]$ 从 4 改写成 $-2$**——这就是「松弛能走回头路」的体现；a→t 把 $d[t]$ 设为 0。第 2、3 轮无任何改进（表中数值不变）。<span class="marginnote">看负权边的威力：$s\to a$ 直达是 4，但 $s\to b\to a$ 是 $1 + (-3) = -2$——负权让「绕远路反而更近」。若用 Dijkstra，贪心会先锁定 $d[a]=4$ 不再更新，永远发现不了 $-2$ 的更优路径——这正是 Dijkstra 不能处理负权的根源，也是 Bellman-Ford 的价值。本例中 $s\to t$ 最短路径 $s\to b\to a\to t$ 总长 0，在「一轮」内就松弛到位，说明实际往往比 $V-1$ 轮更快收敛。</span>

**负环检测**：第 3 轮后扫一遍边——所有 $d[v] \le d[u]+w(u,v)$ 成立（如 $d[a] = -2 \le d[b] + (-3) = -2$），无负环，返回 TRUE。

**DAG 对照**：若把图改成 DAG（去掉会成环的边），拓扑序排列后每个顶点松弛出边一次，同样得到 $d[t]=0$——但只需 $O(V+E)$，无需三轮全扫。

## 7 小结

- **松弛**：尝试「经过 $u$ 更近」更新 $d[v]$——最短路课的共同语言。
- **Bellman-Ford**：$V-1$ 轮全边松弛 + 一轮负环检测，$O(VE)$；处理负权、检测负环。
- 数值算例：$s\to b\to a\to t$ 长 0，负权边在首轮就把 $d[a]$ 从 4 改写成 $-2$。
- 最短路径至多 $V-1$ 条边（无负环时），这决定轮数。
- **DAG 最短路**：拓扑序 + 一趟松弛，$O(V+E)$ 线性。
- 应用：货币套利、差分约束系统、距离向量路由。


**速查表**：

| 概念 | 含义 |
| --- | --- |
| 松弛 RELAX | $d[v] > d[u]+w(u,v)$ 则更新 |
| 最短路径简单性 | 无负环时最短路径 ≤ $V-1$ 条边 |
| 负环检测 | 第 $V$ 轮还能松弛 ⟹ 存在负环 |
| 拓扑序一趟松弛 | DAG 上每个顶点只处理一次 |

**辨析｜易错点：** 负环检测必须在**所有 $V-1$ 轮之后**做——若提前检查，会把「还在收敛中」误判为负环。先跑满 $V-1$ 轮，再扫一遍边看能否松弛，顺序不能错。

**数值快照**：$s\to b\to a\to t$ 长 0，负权边在首轮就把 $d[a]$ 从 4 改写成 $-2$——若用 Dijkstra，贪心会先锁定 $d[a]=4$ 不再更新，永远发现不了更优路径，这正是 Dijkstra 不能处理负权的根源。
