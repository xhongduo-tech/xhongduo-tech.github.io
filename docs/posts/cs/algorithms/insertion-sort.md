## 为什么从正确性证明开始

上一课我们认识了插入排序：它像整理扑克牌一样，把新抓的牌插进已排好的部分。代码能跑通、样例能通过，但「几个样例跑对了」距离「对一切输入都正确」还有一道深沟——迪杰斯特拉的这句话正是深沟的写照：**测试只能证明错误的存在，永远不能证明错误的不存在**。

这道深沟要靠**证明**来填。本课的核心其实不是插入排序本身（它只是载具），而是一把贯穿整个算法设计领域的钥匙——**循环不变式（loop invariant）**，用它来证明循环类算法的正确性。它将在归并排序、快速排序、Dijkstra 最短路、图算法里反复出现；今天先在最小的舞台上把它练熟。

从「从极限到大模型」的全课程看，这里也是「证明文化」第一次进入计算机专题：第一级基础数学里你用数学归纳法证明恒等式，今天你会看到归纳法在代码里的化身。

## 1 循环不变式：循环的「宪法」

**循环不变式（loop invariant）**：一条**在循环的每次迭代开始之前都成立的逻辑命题**。它像国家的宪法，不因循环体的执行而改变——循环体可以在宪法框架内任意修改数据，但一旦进入下一次迭代，宪法规定的性质必须依旧成立。

插入排序的那条不变式（上一课末尾已经预告）是：

> **在每次 for 循环迭代开始时，子数组 $A[1..j-1]$ 已经有序，并且它恰好包含原数组的前 $j-1$ 个元素。**

这条性质不是凭空冒出来的，它刻画的是「已排序的前缀」——循环每推进一轮，这个前缀就变长一格。循环的使命就是把这条「宪法」从 $j=2$ 一路维持到 $j = n+1$，那时整个数组都在前缀里，排序完成。

<span class="marginnote">「不变式」在中文里有时也叫「循环不变量」。它并不是循环条件本身——循环条件决定「何时停下来」，不变式描述「循环过程中始终成立的事实」，两者职责完全不同，见下一节辨析。</span>

## 2 证明的三板斧：初始化、保持、终止

要用不变式证明循环正确，需要验证三条性质，CLRS §2.1 把它总结成：

**初始化（initialization）**：在第一次迭代之前，不变式成立。
**保持（maintenance）**：如果在某次迭代之前不变式成立，那么在这次迭代之后、下一次迭代之前，它依然成立。
**终止（termination）**：循环终止，并且终止时不变式能推出一个有用的性质——正是它证明了算法的正确性。

这三板斧与数学归纳法的对应关系一目了然：**初始化是归纳基础，保持是归纳步骤，终止则把「对每个前缀成立」收束成「对整个数组成立」**。区别只在于：数学归纳法通常证明「对所有 $n$ 成立」，而循环不变式要把结论收敛到「循环结束时」这个具体时刻。<span class="marginnote">为什么必须单独检查<strong>终止</strong>？因为「保持」只说了「只要还在循环，性质就不变」，它无法保证循环会结束——一个死循环也可能满足初始化与保持。终止性让证明真正闭环。</span>

**辨析｜易错点：** 初学者最常犯的错误是把「循环条件」当成不变式。循环条件是「$j \le A.\text{length}$」这种控制语句，它随迭代变化、最终为假；不变式是「$A[1..j-1]$ 有序」这种数据性质，它始终为真。一个描述「循环要不要继续」，一个描述「循环进行中世界是什么样」，请务必分清。

## 3 插入排序：把三斧头抡起来

先把要证明的对象写全（下标从 1 开始，与 CLRS 一致）：

```
INSERTION-SORT(A)
1  for j = 2 to A.length
2      key = A[j]
3      // 把 A[j] 插入已排序的 A[1..j−1]
4      i = j − 1
5      while i > 0 and A[i] > key
6          A[i+1] = A[i]        // 大于 key 的元素右移一位
7          i = i − 1
8      A[i+1] = key             // key 归位
```

**不变式**：在每次 for 迭代开始时，$A[1..j-1]$ 已按非降序排列，且恰含原数组 $A[1..j-1]$ 的元素。

**初始化**：$j = 2$ 时，$A[1]$ 是单元素数组，平凡有序，也「恰含原数组第 1 个元素」。✔
**保持**：假设迭代开始时 $A[1..j-1]$ 有序。第 2 行把 $A[j]$ 存入 key；第 4–6 行从 $A[j-1]$ 起向左扫描，把所有大于 key 的元素逐个右移一位，为 key 腾出空位；第 7 行把 key 放入空位。因为 $A[1..j-1]$ 有序，右移不破坏 $A[1..i]$ 与 $A[i+2..j-1]$ 各自的有序性，而 key 恰好落在二者之间——于是 $A[1..j]$ 有序，且元素集合没变。下一次迭代（$j+1$）开始时不变式依旧成立。✔
**终止**：for 循环的终止条件是 $j = n+1$（超过数组长度）。此时不变式说「$A[1..n]$ 有序且含全部 $n$ 个原元素」，这正是排序问题的解。✔

三步走完，插入排序对**一切输入**都是正确的——不是「测了很多样例都通过」，而是「证明它不可能出错」。

正确性证明的回报是**可组合性**：一旦证明插入排序正确，别处调用它时就不必再为它操心——它变成一块值得信赖的积木。后续所有算法都会以这种方式被证明一次，然后被反复当作子程序使用，这正是系统化的算法书与零散代码段最本质的区别。

## 4 一次演练：不变式在数组上推进

证明抽象，落个具体的例子就清楚。拿上一课那只数组 $\langle 5, 2, 4, 6, 1, 3 \rangle$ 走一遍，每轮开始时记下不变式所说的「已排序前缀 $A[1..j-1]$」，迭代后再记下 $A[1..j]$：

| 轮次 | 迭代前不变式 $A[1..j-1]$ | key | 迭代后 $A[1..j]$ |
| --- | --- | --- | --- |
| $j=2$ | $\langle 5 \rangle$ | 2 | $\langle 2, 5 \rangle$ |
| $j=3$ | $\langle 2, 5 \rangle$ | 4 | $\langle 2, 4, 5 \rangle$ |
| $j=4$ | $\langle 2, 4, 5 \rangle$ | 6 | $\langle 2, 4, 5, 6 \rangle$ |
| $j=5$ | $\langle 2, 4, 5, 6 \rangle$ | 1 | $\langle 1, 2, 4, 5, 6 \rangle$ |
| $j=6$ | $\langle 1, 2, 4, 5, 6 \rangle$ | 3 | $\langle 1, 2, 3, 4, 5, 6 \rangle$ |
| 终止 $j=7$ | 整个数组 | — | 排序完成 |

注意 $j=5$ 那一行最有戏剧性：key 是 1，比前面**所有**元素都小，while 一路扫到 $i=0$ 才停，把 5 个元素全部右移——但迭代结束时 $A[1..5]$ 依旧有序，而且元素一个没丢。这正是不变式最扎实的体现：**循环体可以翻天覆地，但不变量纹丝不动**。<span class="marginnote">这张表也是「保持」的直接证据：每一行都从「有序前缀」出发、又落在「更长的有序前缀」上。若某个时刻前缀乱序，表格就会在这一行断掉——而证明保证了它永远断不了。</span>

## 5 公式解析：不变式 $P(j)$ 的建立与保持

把不变式写成一阶逻辑命题，能让「证明」变得更机械。定义命题

$$
P(j) :\quad A[1..j-1]\ \text{有序}\ \wedge\ \operatorname{sort}(A[1..j-1]) = \operatorname{sort}(A^{\mathrm{orig}}[1..j-1])
$$

其中 $\operatorname{sort}(\cdot)$ 表示把子数组中的元素重排为有序；等式右边 $A^{\mathrm{orig}}$ 是输入时的原数组。两个合取项各有分工：第一项管「序」，第二项管「元素没丢没换」。

要验证「保持」，只需盯住一轮迭代 $j \to j+1$，拆成四步：

- **第一步，取出 key**：第 2 行把 $A[j]$ 暂存到 key，$A[j]$ 的位置从此可以安全覆写。
- **第二步，找到插入点**：while 循环用条件 $i=0$ 持续左移，循环结束时 $A[i] \le key$（或 $i=0$ 走到头）。此时 $i+1$ 就是 key 该待的位置。
- **第三步，右移保序**：第 5 行把所有大于 key 的元素向右挪一格。移动的是「值」而非「顺序」，所以 $A[1..i]$ 与 $A[i+2..j-1]$ 仍分别有序，且二者之间空出 $A[i+1]$。
- **第四步，归位**：第 7 行把 key 写入 $A[i+1]$。由第二步知 $A[i] \le key$，而右移前 $A[i+1..j-1]$ 中的元素原本都大于 key，故 $A[1..j]$ 整体有序；元素集合仍是原数组的前 $j$ 个。于是 $P(j+1)$ 成立。✔

这四步合起来，就是归纳法里「从 $P(j)$ 推出 $P(j+1)$」的那一步。把它与第一级数学里证明「$1+2+\cdots+n = \tfrac{n(n+1)}{2}$」的归纳步骤对照：那里的核心是「把 $n$ 加到等式左边」，这里的核心是「把 key 插进有序前缀」——结构完全同构，只是舞台从纸面换成了内存。

## 6 复杂度的一句预告

正确性解决「对不对」，代价解决「快不快」——后者是下一课《算法分析框架》的主角，这里只给结论，以免喧宾夺主：插入排序最坏情况下 $t_j = j$，运行时间 $\sum_{j=2}^{n} j = \tfrac{n(n+1)}{2} - 1 = \Theta(n^2)$；最佳情况（输入已有序）是 $\Theta(n)$。一条「越接近有序越快」的算法，特别适合做其它排序的收尾步骤——这个性质以后在《快速排序的工程优化》里会被用到。

## 7 小结

- **循环不变式**：循环每次迭代开始前都成立的性质，是证明循环正确性的核心工具。
- 证明三板斧：**初始化、保持、终止**；与数学归纳法的**归纳基础、归纳步骤、结论收敛**一一对应。
- 插入排序的不变式：「$A[1..j-1]$ 有序且元素不变」；终止时 $j = n+1$ 推出整个数组有序。
- 测试与证明的分工：测试找反例，证明给保证——迪杰斯特拉的话是全文的注脚。
- 复杂度与正确性分离：本课只管「对」，代价的度量交给下一课。

在下一节，我们把目光从「算法对不对」转向「算法有多快」——建立一套**算法分析框架**：用 RAM 模型给每一步定价，用输入规模把成本变成函数，再比较最坏、平均、最好三种情形。
