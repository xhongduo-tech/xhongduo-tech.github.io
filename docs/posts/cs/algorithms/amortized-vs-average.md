# 摊还分析与平均情况分析的区别

<div class="epigraph">
<p>两种「平均」说的是两件事：一个对操作序列取平均，一个对输入分布取平均。</p>
<footer>—— 高德纳（Donald E. Knuth）</footer>
</div>

<div class="article-byline">

## 为什么从概念辨析开始

摊还分析、平均情况分析——都含「平均」二字，极易混淆。但它们是**两种本质不同的断言**：摊还分析对「任意操作序列」给出确定性的总代价上界；平均情况分析对「随机输入」给出期望代价。<span class="marginnote">混淆的后果很实际：面试/考试里「均摊 O(1)」与「平均 O(1)」是两句话。前者是「无论序列多坏，n 次操作总额有界」，后者是「假设输入随机，期望代价有界」。把它们混为一谈，会得出错误的性能承诺。</span>

这一课把两种分析放在解剖台上：各自的前提、结论、适用场景，以及三组「看起来一样、其实不同」的例子。

## 1 定义对照

| 维度 | 摊还分析 | 平均情况分析 |
| --- | --- | --- |
| 对象 | 数据结构上的一串操作 | 一次算法执行 |
| 输入 | 任意（对手可控） | 服从某概率分布 |
| 随机性来源 | 无（确定性论证） | 输入分布 |
| 结论 | 最坏总代价 / 次数 | 期望代价 |
| 示例 | 动态表、splay 树 | 快排（均匀排列）、哈希 |

**摊还分析（amortized）**：对**固定的最坏序列**求总代价上界，再除以操作数。「摊还 $O(1)$」=「任何 $n$ 次操作总代价 $O(n)$」。

**平均情况分析（average-case）**：对**随机输入**求期望运行时间。「平均 $O(n\log n)$」=「若输入均匀随机，期望是 $n\log n$，但某个特定输入可能很慢」。<span class="marginnote">最容易混淆的一点：两者都可能得出「$O(1)$」或「$O(n\log n)$」，但<strong>语义完全不同</strong>。摊还的 $O(1)$ 是「确定性、无条件」的；平均的 $O(1)$ 是「在分布假设下、期望意义」的。前者无需随机源，后者依赖分布假设。</span>

## 2 三个「看起来一样」的案例

### 案例一：动态表插入

**摊还**：$n$ 次插入总代价 $O(n)$，无论插入序列怎样——确定性上界。
**平均**：若假设「插入位置随机」……但插入代价根本不依赖位置，所以这里平均分析没意义。

结论：**动态表的 $O(1)$ 是摊还结论**，不靠任何分布假设。

### 案例二：快速排序

**摊还**：快排**没有**摊还 $O(n\log n)$ 保证——它的 $n\log n$ 是「期望」或「平均」，最坏仍是 $O(n^2)$。
**平均**：输入均匀排列时，期望比较次数 $2n\ln n$。

结论：**快排的 $O(n\log n)$ 是平均/期望结论**，不是摊还。随机化快排的「期望」来自算法内部掷骰子，与「平均情况」的输入分布假设略有不同——但都不是「摊还」。<span class="marginnote">这里的区分很精微：随机化快排的期望是「随机化算法」的期望（概率在算法内部），平均情况分析是「确定性算法的输入平均」。两者用同一套概率工具，但来源不同——一个随机源在算法里，一个在输入里。</span>

### 案例三：哈希表

- **摊还**：动态扩容的哈希表，$n$ 次插入摊还 $O(1)$（同动态表）。
- **平均**：单个查找的期望 $O(1)$ 依赖「哈希函数均匀」（均匀哈希假设）。

结论：**两者都对哈希表重要**，但回答不同问题——「总体插入的确定性上界」vs「单次查找的期望」。

## 3 公式解析：两种「平均」的数学差异

摊还分析的「平均」是除法：

$$\text{摊还代价} = \frac{\max_{\text{序列}} \sum_{i} c_i}{n}$$

平均情况分析的「平均」是期望：

$$\mathbb{E}[T] = \sum_{\text{输入 } I} \Pr[I] \cdot T(I)$$

- **第一步，摊还的 max**：先取「最坏序列」的总代价，再除以 $n$——**顺序是先最坏、后平均**。
- **第二步，平均的期望**：先对输入分布取期望——**没有 max**，坏输入被概率摊薄。
- **第三步，本质差异**：摊还不关心输入分布，只保证「总代价有界」；平均关心分布，坏输入可能以正概率出现且代价极高。

**结论**：摊还比平均**更强**（对任何序列成立）但也**更弱**（只能回答「总代价」，单次仍可能贵）。**平均比摊还更适合描述「典型行为」，摊还更适合承诺「总额不超预算」**。<span class="marginnote">一个形象的类比：摊还是「每月还贷总额确定」——无论这个月多花多少，总额有上限；平均是「预期花费」——平均看便宜，但某一笔可能贵到失控。设计实时系统（需要硬实时保证）用摊还，设计吞吐评估（看典型表现）用平均。</span>

## 4 什么时候用哪个

**用摊还分析**：

数据结构有「偶尔很贵的操作」但总量可控（动态表、splay 树、并查集）。
需要**确定性**的性能承诺（实时系统、安全关键系统）。
操作序列由程序控制、无法假设分布。

**用平均/期望分析**：

输入天然随机或可假设均匀（快排、哈希、随机算法）。
需要「典型性能」而非「总额上限」。
概率工具能给出更紧的界（如随机算法的期望）。

**辨析｜易错点：** 「摊还分析用了概率吗？」——**不**。聚合、核算、势能三种方法都是确定性论证，不掷骰子。<span class="marginnote">有些教材把「随机化算法的期望」与「摊还」并列，容易误导。正确的区分轴是：<strong>随机性来源</strong>——摊还没有随机性，平均/期望有（要么在输入、要么在算法）。一句话：摊还 = 最坏序列的平均；平均/期望 = 分布的期望。</span>

## 5 小结

- **摊还分析**：对任意操作序列，确定性证明总代价上界，再除以次数。
- **平均情况分析**：对输入分布（或算法内随机源）取期望。
- 摊还无需概率、对任何序列成立；平均依赖分布、坏输入仍可能。
- 快排的 $n\log n$ 是期望/平均（非摊还）；动态表的 $O(1)$ 是摊还（非平均）。
- 选择标准：需要确定性总额上限用摊还，需要典型性能描述用平均/期望。
