## 为什么从 Pollard rho 开始

素性测试解决了「是不是素数」；**因子分解**解决「不是素数时，怎么拆」。试除法 $O(\sqrt{n})$ 对大数不可行。**Pollard 的 rho 启发式**用「生日悖论 + 伪随机游走」在 $O(n^{1/4})$ 期望内找到小因子。<span class="marginnote">「判定易、分解难」的不对称是 RSA 安全的全部基础。但「难」不等于「不可解」——Pollard rho 对<strong>中小型因子</strong>（如几十位的因子）相当有效，是「先筛小素数、再 rho、再更重武器」分解管线的第一梯队。它也是「生日悖论在算法里的第二次大显身手」（第一次在第三篇）。</span>

这一课讲 rho 的核心思想、生日悖论如何保证「碰撞」，以及复杂度 $O(n^{1/4})$ 的直觉。

## 1 核心思想：用伪随机序列找碰撞

**问题**：找合数 $n$ 的一个非平凡因子 $d$（$1 < d < n$）。

**Pollard rho 思路**：选一个伪随机函数 $f(x) = (x^2 + c) \bmod n$，从 $x_0$ 出发迭代：

$$x_0, x_1 = f(x_0), x_2 = f(x_1), \dots$$

这个序列**模 $n$ 时看似随机**，但如果考虑「模某个真因子 $d$」，序列 $x_i \bmod d$ 的周期比模 $n$ 短得多。当两个 $x_i \bmod d$ 相等（碰撞）时，$\gcd(x_i - x_j, n)$ 很可能就是 $d$。<span class="marginnote">直觉：$x_i \bmod n$ 的序列值域是 $\{0..n-1\}$（$n$ 种可能）；$x_i \bmod d$ 的值域只有 $\{0..d-1\}$（$d$ 种可能）。生日悖论说：大约 $\sqrt{d}$ 步后，$x_i \bmod d$ 就会碰撞——而碰撞时 $\gcd$ 暴露因子。因子越小，暴露越快——这就是「找到小因子是 $O(\sqrt{d})$ 而不是 $O(\sqrt{n})$」的来源。</span>

## 2 算法：Floyd 判圈

直接「两两比 $x_i$」是 $O(n)$ 个点两两比——太贵。**Floyd 判圈（龟兔赛跑）**只存两个值：

```text
POLLARD-RHO(n):
    c ← 随机常数（1 ≤ c ≤ n−1）        // f(x) = (x² + c) mod n
    x ← y ← 随机起点（2 ≤ x ≤ n−1）
    d ← 1
    while d = 1:
        x ← f(x)                       // 乌龟走一步
        y ← f(f(y))                    // 兔子走两步
        d ← gcd(|x − y|, n)
    return d                           // 若 d = n 说明失败，换 c 重来
```

**为什么能撞上**：$x$ 与 $y$ 以不同速度在序列上前进，当 $x_i \bmod d$ 进入周期后，「龟兔」最终会「同余模 $d$」——此时 $\gcd(|x-y|, n)$ 给出 $d$（或其倍数）。<span class="marginnote">Floyd 判圈是「空间 $O(1)$」找周期碰撞的经典：不用存整个序列，只要两个指针不同速度走，必在周期内相遇。这里「相遇」被 $\gcd$ 捕获——碰撞发生时 $x \equiv y \pmod d$，$d | (x-y)$，$\gcd$ 取到 $d$。若 $\gcd = n$（全撞到 $n$ 上），换 $c$ 重来。</span>

## 3 公式解析：期望复杂度 $O(\sqrt{d}) \approx O(n^{1/4})$

由生日悖论，$x_i \bmod d$ 在约 $\sqrt{d}$ 步内碰撞。每次迭代 $O(\log n)$（gcd），总期望：

$$T(n) = O(\sqrt{d}) \cdot O(\log n) \approx O(n^{1/4} \log n)$$

- **第一步，碰撞步数**：$x_i \bmod d$ 的序列在 $\sqrt{d}$ 步内高概率碰撞（生日悖论：$\sqrt{d}$ 个「球」落入 $d$ 个「箱」）。
- **第二步，每步代价**：一次 $f$ 求值 $O(1)$ + 一次 $\gcd$ $O(\log n)$。
- **第三步，期望总时间**：$O(\sqrt{d}\log n)$——$d$ 越小越快。最坏（$d$ 接近 $n$）时 $O(n^{1/4}\log n)$，仍远好于试除的 $O(\sqrt{n})$。

**要点**：rho 的期望是 $n^{1/4}$——**因为它在「因子 $d$」的尺度上找碰撞，而不是在 $n$ 的尺度上**。因子小则快，这是「输出敏感」的又一例。<span class="marginnote">对比试除法 $O(\sqrt{n})$：试除对每个候选 $k$ 检查「$k | n$」，要在 $n$ 的尺度上扫。rho 只在「$d$ 的尺度」上等碰撞——$\sqrt{d}$ 对 $\sqrt{n}$，差了一个 $d$ 的平方根。这就是生日悖论给分解的「加速」：用概率碰撞代替确定性枚举。</span>

**辨析｜易错点：** rho 是**启发式**，不是有保证的算法——它可能失败（$\gcd = n$）或很慢（$d$ 大）。**实际分解管线是「分层」的**：先试除小素数（排除小因子），再跑 rho（找中等因子），最后才上椭圆曲线法（ECM）或数域筛（NFS）。别指望 rho 单独搞定 RSA 的大素数因子——它处理的是「中小因子」。

## 4 因子分解的生态

| 方法 | 复杂度 | 适用规模 |
| --- | --- | --- |
| 试除法 | $O(\sqrt{n})$ | 小因子（< $10^9$） |
| Pollard rho | $O(n^{1/4})$ | 中等因子（< $10^{12}$ 量级） |
| ECM | 亚指数 | 中大规模因子 |
| 数域筛（NFS） | 亚指数 | RSA 规模的合数（$10^{200}$+） |

RSA 之所以安全，是因为 **2048 位（约 $10^{616}$）的合数对 NFS 都不可行**——但**实现不当**（$p, q$ 太接近、太小、或共因子）会让 rho/ECM 有机可乘。<span class="marginnote">「分解生态」的层次结构说明：密码安全不是「分解完全不可行」，而是「分解在目标规模下不切实际」。攻击者总有更快的方法，只是代价远超收益。理解「哪一层算法能攻破多大」，是密码强度评估的实质——这也是《密码学与信息安全》专题深入展开的地方。</span>

## 5 数值算例：小因子怎么被撞出来的

拿 $n = 91$（$= 7 \times 13$）跑一遍。取 $f(x) = x^2 + 1 \bmod 91$，起点 $x_0 = 2$：

| 步 $i$ | $x_i = (x_{i-1}^2 + 1) \bmod 91$ | $x_i \bmod 7$ |
| --- | --- | --- |
| 0 | 2 | 2 |
| 1 | 5 | 5 |
| 2 | 26 | 5 |
| 3 | 40 | 5 |
| 4 | 54 | 5 |
| 5 | 5 | 5 |

**看中间两行**：$x_1 = 5$ 与 $x_2 = 26$ 都满足 $x \equiv 5 \pmod 7$——**模真因子 7 发生碰撞**，而模 $n = 91$ 它们完全不同。于是 $\gcd(|26 - 5|, 91) = \gcd(21, 91) = 7$，因子 7 暴露。<span class="marginnote">对比「模 $n$」与「模 $d$」两列：$x_i \bmod n$ 在 5 步后进入周期，但碰撞发生在更早、且只对 $d$ 而言——这就是「在 $d$ 的尺度上找碰撞」的字面意义。因子 7 一步就被龟兔找到：$\gcd(|f(f(2)) - f(2)|, 91) = \gcd(26 - 5, 91) = 7$。</span>

**用龟兔跑**：$x_0 = y_0 = 2$。第一轮 $x \leftarrow f(2) = 5$，$y \leftarrow f(f(2)) = 26$，$d \leftarrow \gcd(|5-26|, 91) = 7$——一次迭代即得因子。期望碰撞步数 $\sqrt{d} = \sqrt{7} \approx 2.6$，本例恰好更快。

**复杂度对照**：$n = 91$ 时试除法要在 $\sqrt{91} \approx 9.5$ 个候选里扫；rho 期望 $\sqrt{7} \approx 2.6$ 步——因子越小，差距越大。这就是「输出敏感」在因子分解里的表现：**撞上的是因子 $d$ 的生日，不是 $n$ 的生日**。

## 6 小结

- **Pollard rho**：伪随机游走 + 生日悖论找「模因子 $d$」的碰撞，$\gcd$ 暴露因子。
- **Floyd 判圈**：龟兔双指针 $O(1)$ 空间找周期碰撞。
- **期望 $O(n^{1/4})$**：在 $d$ 的尺度（$\sqrt{d}$）而非 $n$ 的尺度上找——因子小则快。
- 数值算例：$91 = 7 \times 13$，一次龟兔迭代即用 $\gcd(21, 91)$ 拿到因子 7。
- **启发式**：可能失败（$\gcd=n$ 重试）；用于「试除后、ECM/NFS 前」的中小因子。
- 分解生态分层：试除 → rho → ECM → NFS；RSA 安全靠「2048 位对 NFS 不切实际」。


**速查表**：

| 术语 | 含义 |
| --- | --- |
| 伪随机游走 $f(x)=(x^2+c)\bmod n$ | 生成看似随机的序列 |
| 碰撞 | 两个 $x_i \bmod d$ 相等 → $\gcd(x_i-x_j,n)$ 暴露因子 |
| 生日悖论 | $\sqrt{d}$ 步内高概率碰撞 |
| 分层分解 | 试除（小）→ rho（中）→ ECM/NFS（大） |

**辨析｜易错点：** rho 是启发式不是有保证的算法——可能失败或很慢。实际分解管线必须「分层」：先试除小素数、再 rho、最后才上重武器。别指望 rho 单独搞定 RSA 的大素数因子。

**数值快照**：$n=91=7\times13$ 时，一次龟兔迭代即用 $\gcd(21,91)=7$ 拿到因子；试除法要在 $\sqrt{91}\approx9.5$ 个候选里扫，rho 期望 $\sqrt{7}\approx2.6$ 步——因子越小，差距越大。


- 应用场景：质因数分解的「第一梯队」——先试除小素数、再 rho 找中等因子，最后才上 ECM/NFS；分解 30 位左右的小因子时 rho 是首选。
