## 为什么从主定理开始

前两课把「猜」和「证」都练熟了，但每解一道递归式都要画树、归纳，终究太累。现实中分治算法的递归式几乎都长同一个形状——**规模除以常数、递归若干份、外加一个函数**：

$$
T(n) = a\,T(n/b) + f(n), \qquad a \ge 1,\ b > 1
$$

**主定理（master theorem）**把这类递归式的解直接写成一张查表：比较 $f(n)$ 与 $n^{\log_b a}$ 的大小关系，三句话出答案。它是递归树分析的「背诵版」——上一课画的每一棵树，都是主定理某个情形的实例。学会它，等于把整类递归式的求解时间从「半小时推导」压到「十秒读表」。

## 1 主定理的标准形式与临界指数

**主定理（master theorem）**：设 $a \ge 1$、$b > 1$ 为常数，$f(n)$ 为渐近正函数，$T(n)$ 由 $T(n) = aT(n/b) + f(n)$ 定义（$n/b$ 可写作 $\lfloor n/b \rfloor$ 或 $\lceil n/b \rceil$，不影响结论）。记**临界指数** $\log_b a$，比较 $f(n)$ 与 $n^{\log_b a}$：

- **情形一（叶子主导）**：若存在常数 $\varepsilon > 0$，$f(n) = O\!\left(n^{\log_b a - \varepsilon}\right)$，则 $T(n) = \Theta\!\left(n^{\log_b a}\right)$。
- **情形二（势均力敌）**：若存在常数 $k \ge 0$，$f(n) = \Theta\!\left(n^{\log_b a}\,\lg^k n\right)$，则 $T(n) = \Theta\!\left(n^{\log_b a}\,\lg^{k+1} n\right)$。
- **情形三（根主导）**：若存在常数 $\varepsilon > 0$，$f(n) = \Omega\!\left(n^{\log_b a + \varepsilon}\right)$，且**正则条件**成立——存在常数 $c < 1$ 使 $a\,f(n/b) \le c\,f(n)$ 对充分大的 $n$ 恒成立——则 $T(n) = \Theta(f(n))$。

<span class="marginnote">临界指数 $\log_b a$ 有个直观身份：递归树的<strong>叶子数</strong>是 $a^{\log_b n} = n^{\log_b a}$，所以 $n^{\log_b a}$ 就是「最底层那些 $T(1)$ 的总代价」的规模。它把递归深度（$\log_b n$）与分支因子（$a$）打包成一个数，是整张表的锚点。</span>

**核心口诀**：递归式 $T(n) = aT(n/b) + f(n)$ 的解，由**「叶子总代价」$n^{\log_b a}$ 与「根代价」$f(n)$ 谁大**决定——谁大谁主导，势均力敌就乘个 $\lg n$。

把三情形缩成一张随身携带的对照表：

| 情形 | 条件（与临界指数比） | 结论 | 主导方 |
| --- | --- | --- | --- |
| 一 | $f(n) = O(n^{\log_b a - \varepsilon})$ | $\Theta(n^{\log_b a})$ | 叶子 |
| 二 | $f(n) = \Theta(n^{\log_b a}\lg^k n)$ | $\Theta(n^{\log_b a}\lg^{k+1} n)$ | 平手 × 层数 |
| 三 | $f(n) = \Omega(n^{\log_b a+\varepsilon})$ 且正则 | $\Theta(f(n))$ | 根 |

这张表值得贴在案头：做题时先填 $a, b, f(n)$，算出 $\log_b a$，再对号入座。表格三行之间谁都不覆盖谁——**每一行都要求一个「多项式」级别的差距或精确同阶**，这正是下一节间隙讨论的伏笔。

## 2 三种情形的直觉：从递归树看

把主定理翻译回上一课的树，三情形就活了。递归树的总代价由三块构成：**从根往下内部节点的工作 $f(n) + a f(n/b) + a^2 f(n/b^2) + \cdots$**，以及**底层叶子 $n^{\log_b a}$ 个 $\Theta(1)$**。

- **情形一，$f(n)$ 多项式地小于 $n^{\log_b a}$**：内部各级层代价几何**衰减**，等比级数被首项常数倍吸收，主导权落在叶子——$T(n) = \Theta(n^{\log_b a})$。这正是上一课例一（$3T(n/4)+cn^2$）的镜像：那里是 $f(n)$ 主导，这里反过来了。
- **情形二，两者同阶**：每层层代价**恒为常数倍**的 $f(n)$（如同 $2T(n/2)+n$ 每层都 $cn$），于是层数 $\log_b n$ 与 $f(n)$ 相乘，再乘上 $\lg^k n$ 提供的余量——$T(n) = \Theta(n^{\log_b a}\lg^{k+1} n)$。
- **情形三，$f(n)$ 多项式地大于 $n^{\log_b a}$**：层代价几何**增长**，越往下越大，但正则条件保证不会「每层都比上一层多」，于是总和被最底层（根）的常数倍钉住——$T(n) = \Theta(f(n))$。

一句话：**叶大归叶，根大归根，平手乘对数**。树的三种求和模式，就是主定理的三张脸。

顺着这条线还能给出**证明梗概**（CLRS §4.6 的完整证明也沿同一路线）：把递归树展开，内部各级总代价为

$$
\sum_{i=0}^{\log_b n - 1} a^i\,f(n/b^i)
$$

叶子层合计 $\Theta(n^{\log_b a})$。三情形说的其实是**这个级数从哪一头收敛**：情形一中各项几何衰减、和由最后一项（叶子侧）主导；情形二中各项同阶、和约等于项数 $\log_b n$ 乘每项；情形三中各项几何增长、和由第一项（根侧）主导。而**正则条件** $a\,f(n/b) \le c\,f(n)$（$c < 1$）正是在情形三里保证「每层确实比上一层多一个小于 1 的倍数、但总和不至于失控」——它是情形三成立的关键前提，不是装饰。

## 3 公式解析：为什么锚点是 n^{log_b a}

主定理最神秘的符号是 $n^{\log_b a}$，值得单独拆一次。

$$
n^{\log_b a} = b^{\log_b n \cdot \log_b a} = a^{\log_b n}
$$

- **第一式**：$n = b^{\log_b n}$，于是 $n^{\log_b a} = (b^{\log_b n})^{\log_b a} = b^{\log_b n \cdot \log_b a}$。
- **第二式**：交换指数，$b^{\log_b n \cdot \log_b a} = b^{\log_b a \cdot \log_b n} = (b^{\log_b a})^{\log_b n} = a^{\log_b n}$。
- **含义**：$a^{\log_b n}$ 正是「叶子数」——递归树把规模从 $n$ 一路除以 $b$，深度 $\log_b n$，每层分支因子 $a$，底层共有 $a^{\log_b n}$ 片叶子。**临界指数 $\log_b a$ 因此同时编码了「递归多深」与「每层分多少叉」**。
- **三种情形都在问同一个问题**：$f(n)$ 与这 $a^{\log_b n}$ 片叶子相比，是多项式地小（情形一）、同阶（情形二）、还是多项式地大（情形三）？

把递归式的参数 $a,b$ 代进 $\log_b a$，得到临界指数，然后拿它和 $f(n)$ 比——这就是用主定理的全部动作。

## 4 三个工作例：代入数值

**例一（情形一）**：$T(n) = 9T(n/3) + n$。$a = 9,\ b = 3$，临界指数 $\log_3 9 = 2$；$f(n) = n = O(n^{2-\varepsilon})$（取 $\varepsilon = 1$）。叶子主导，故 $T(n) = \Theta(n^2)$。✔

**例二（情形二）**：$T(n) = T(2n/3) + 1$。$a = 1,\ b = 3/2$，$\log_{3/2} 1 = 0$；$f(n) = 1 = \Theta(n^0 \lg^0 n)$（$k = 0$）。势均力敌，故 $T(n) = \Theta(\lg n)$。✔

**例三（情形三）**：$T(n) = 3T(n/4) + n\lg n$。$a = 3,\ b = 4$，$\log_4 3 \approx 0.793$；$f(n) = n\lg n = \Omega(n^{0.793+\varepsilon})$（取 $\varepsilon = 0.2$），且正则条件：$3 \cdot (n/4)\lg(n/4) \le \tfrac{3}{4} n \lg n = c\,f(n)$，$c = 3/4 < 1$。根主导，故 $T(n) = \Theta(n\lg n)$。✔

**例四（情形二，$k = 0$）**：$T(n) = 4T(n/2) + n^2$。$a = 4,\ b = 2$，$\log_2 4 = 2$；$f(n) = n^2 = \Theta(n^2 \lg^0 n)$，与临界指数精确同阶。势均力敌，故 $T(n) = \Theta(n^2 \lg n)$。✔——这个例子说明：**同阶时多乘一个 $\lg n$**，根与叶子谁也没赢，层数 $\log_b n$ 出来摘了果子。

<span class="marginnote">例三是情形一（上一课例一 $3T(n/4)+cn^2$，$\Theta(n^2)$）的近亲：把 $cn^2$ 换成 $n\lg n$，临界指数 $0.793$ 压不过 $n\lg n$，主导权从叶子换到根——一个参数的改动，整个树的主宰就易主了。</span>

## 5 间隙讨论：主定理不适用的时候

主定理不是万能的：三情形之间有**两道间隙（gap）**，落在里面的递归式查表失效，必须回到递归树。

**辨析｜易错点：** 情形之间的比较要求「**多项式地**」（poly）大或小——差一个 $\lg n$ 不算数。具体说：

- **间隙一（情形一与情形二之间）**：$f(n)$ 小于 $n^{\log_b a}$，但只差一个对数因子，达不到 $O(n^{\log_b a - \varepsilon})$。典型如 $T(n) = 2T(n/2) + n/\lg n$：$f(n) = n/\lg n$ 比 $n$ 小，但 $n/\lg n$ 与 $n^{1-\varepsilon}$ 之比 $n^{\varepsilon}/\lg n \to \infty$，不满足情形一的 $\varepsilon$ 条件。递归树可验证：第 $i$ 层总代价为 $n/(\lg n - i)$，从 $i=0$ 加到 $\lg n-1$ 得 $n\sum_{j=1}^{\lg n} 1/j = n\,H_{\lg n} = \Theta(n\lg\lg n)$——没有主定理，树自己给出答案。
- **间隙二（情形二与情形三之间）**：$f(n)$ 大于 $n^{\log_b a}$，但只大一个对数因子。最著名的陷阱是 $T(n) = 2T(n/2) + n\lg n$：$f(n)$ 与 $n$ 之比是 $\lg n$，不是 $n^{\varepsilon}$，**不是**多项式地大——但它在推广版情形二里（$f(n) = \Theta(n\lg^1 n)$，$k=1$）被精确覆盖，得 $T(n) = \Theta(n\lg^2 n)$。若再用 $T(n) = 2T(n/2) + n\lg n\lg\lg n$，连情形二也套不上（$f(n)$ 不是 $n\lg^k n$ 的形状），只能递归树求 $\Theta(n\lg^2 n\lg\lg n)$。

**核心警示**：看见 $f(n)$ 含 $\lg$ 因子时，先问一句「这个对数会不会破坏多项式比较」。$n\lg n$ 与 $n$ 之差，是「亚多项式」之差——这正是把 $n\lg n$ 误判进情形三、得出错误答案 $\Theta(n\lg n)$ 的最常见事故，务必警惕。

## 6 主定理使用手册：三条纪律

- **先算临界指数 $\log_b a$**，再拿 $f(n)$ 与之比较——一切判断从这两个数开始。
- **情形三必须先验正则条件** $a\,f(n/b) \le c\,f(n)$；缺了它，即使 $f(n) = \Omega(n^{\log_b a + \varepsilon})$ 也不能下结论。
- **分清「同阶」与「多项式大/小」**：差 $\lg^k n$ 是情形二，差 $n^{\varepsilon}$ 才是情形一或三；对数因子不构成多项式差距。
- **实战提示**：拿不准该进哪一行时，把递归树前两层画出来——层代价在缩水、持平还是膨胀，一眼就能看出该进情形一、二还是三。

## 7 小结

- **主定理**：$T(n) = aT(n/b) + f(n)$ 的解由 $f(n)$ 与临界指数 $n^{\log_b a}$ 的相对大小决定。
- **三情形**：$f(n)$ 多项式地小 → $\Theta(n^{\log_b a})$；同阶 → $\Theta(n^{\log_b a}\lg^{k+1} n)$；多项式地大（且正则）→ $\Theta(f(n))$。
- **临界指数 $\log_b a$ = 叶子数的对数**，把递归深度与分支因子打包成锚点。
- **两道间隙**：只差对数因子、不差 $n^{\varepsilon}$ 时主定理失效，须回退递归树；$T(n) = 2T(n/2) + n\lg n$ 是高频陷阱。
- 情形三的**正则条件**不可省。

在下一节，我们离开「通用的方法」，进入分治的**实战案例**——**最大子数组问题（Maximum Subarray）**：用 $T(n) = 2T(n/2) + \Theta(n)$ 的递归式与主定理，在 $\Theta(n\lg n)$ 内找到跨越中点的最大和子数组，并引出「分治未必最快」的伏笔。
