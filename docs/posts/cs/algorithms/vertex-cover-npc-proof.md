## 为什么从顶点覆盖开始

上一课给了 NPC 证明的两步范式；这一课完整走一遍：**顶点覆盖（Vertex Cover）** 如何被证明是 NPC。它是最经典的「从 3-SAT 归约」案例，展示了归约构造的**构件思维**——把公式的变量、子句翻译成图的结构。<span class="marginnote">顶点覆盖：给定图 $G$ 与整数 $k$，是否存在 ≤ $k$ 个顶点「覆盖」所有边（每条边至少一个端点被选）？它看着像「图着色」那类问题，实际是 NPC——且它的<strong>近似</strong>版（2-近似）在第十二篇是标准案例。先理解「为什么难」，再看「近似怎么救」。</span>

这一课走完整证明：$\in NP$ 验证、从 3-SAT 的归约构造、以及两个方向的等价性论证。

## 1 问题定义与 NP 成员验证

**顶点覆盖（VERTEX-COVER）**：输入图 $G=(V,E)$ 与整数 $k$。问：是否存在 $V' \subseteq V$，$|V'| \le k$，且每条边 $(u,v) \in E$ 至少有一个端点在 $V'$ 中？

**$X \in NP$**：证书 = 顶点子集 $V'$。验证器检查：$|V'| \le k$，且遍历所有边确认每条边都被覆盖——$O(|E|)$ 时间，多项式。<span class="marginnote">验证部分总是最简单的：给候选解，检查约束。这一步几乎对所有「存在性组合问题」都是「给出解、查约束」——关键是确认检查是多项式的。很多初学 NPC 证明的人跳过这步，但它是 NPC 定义的必要一半。</span>

## 2 归约：从 3-SAT 构造图

要证 VERTEX-COVER 是 NPC，构造归约 3-SAT $\le_P$ VERTEX-COVER。给定 3-CNF 公式 $\phi$（$n$ 个变量、$m$ 个子句），构造图 $G$ 与整数 $k$：

**构件一（变量 gadget）**：每个变量 $x_i$ 对应一条边 $(x_i, \bar{x}_i)$——两个顶点（真/假）。覆盖这条边至少要选一个端点。

**构件二（子句 gadget）**：每个子句 $C_j$（三个文字，如 $(l_1 \vee l_2 \vee l_3)$）对应一个三角形（三个顶点连成三角），顶点标记为该子句的三个文字。

**连边（文字到变量）**：子句三角形的每个文字顶点，连到对应变量的「文字顶点」（$l = x_i$ 连到 $x_i$，$l = \bar{x}_i$ 连到 $\bar{x}_i$）。

设 $k = n + 2m$。<span class="marginnote">构件思维：变量边强制「每个变量二选一（真/假）」，子句三角形强制「每个子句至少一个文字被选中」——而选中恰意味着「该文字为真」。连接边把「文字选中」与「变量赋值」绑定。$k = n + 2m$ 是「配额」：每个变量边用 1 个顶点，每个三角形用 2 个顶点（留 1 个由连接边逼出来）。这个「配额定构造」是归约的经典手法。</span>

## 3 归约正确性：两个方向

**$(\Rightarrow)$ 公式可满足 ⟹ 有 ≤ $k$ 的顶点覆盖**：取满足赋值。每个变量边选「为真的那个文字顶点」；每个子句三角形中，选「为真的文字」所对应的两个顶点（该文字顶点 + 与连接边相邻的另两个中任两个……确切说是选「两个未被连接边覆盖要求的顶点」）。验证：每条变量边被覆盖（选了端点）、每条三角形边被覆盖（选了 3 个中 2 个）、每条连接边被覆盖（真文字端点被选）。总数 = $n + 2m = k$。

**$(\Leftarrow)$ 有 ≤ $k$ 的顶点覆盖 ⟹ 公式可满足**：顶点覆盖中，每个变量边至少选一个端点（变量 gadget 决定赋值：选了 $x_i$ 则 $x_i = true$，选了 $\bar x_i$ 则 false）。每个三角形至少选 2 个顶点（否则三角形边漏覆盖），又因为总配额 $k = n+2m$ 且变量边已用 $n$，三角形恰各用 2——**没给「连接边」单独留顶点**，所以每个三角形「漏选的那个顶点」必靠连接边被覆盖——即该文字端点被选，该文字为真。每个子句至少一个文字为真——公式可满足。<span class="marginnote">$(\Leftarrow)$ 方向是归约证明里最容易写错的部分：要利用「配额恰好用完」推导出每个三角形的「缺角」必须由连接边补上。配额是「紧」的——$k$ 若设大一点，三角形就可以全选 3 个而无需连接边补角，等价性就断了。归约构造里「配额紧」是命门。</span>

## 4 公式解析：配额 $k = n + 2m$ 为什么「恰好」

$$k = n + 2m$$

- **第一步，$n$ 给变量边**：每条变量边至少 1 个顶点，共 $n$ 条。
- **第二步，$2m$ 给子句三角形**：每个三角形至少要 2 个顶点（覆盖三角形三条边），共 $2m$。
- **第三步，紧配额**：总数 $n + 2m$ 恰好 = 「各构件的最小必需」之和——没有任何余量。所以「$≤ k$ 的覆盖」必须「每个构件都取最小」：每个变量边取 1 个、每个三角形取 2 个。这个「每个构件都逼近下界」的强制，正是归约把「子句必须有一个真文字」逼出来的杠杆。

**要点**：归约构造的核心是「用配额制造约束」——让图结构 + 配额编码公式的语义。**看懂 $k$ 怎么设，就看懂了整个归约**。<span class="marginnote">这类「构件 + 配额」归约是 NPC 证明的主流形态：变量构件、子句构件、连接边、紧配额。理解了顶点覆盖这一例，哈密顿回路、TSP、子集和的归约构造都能「举一反三」——只是构件换花样（子图代替三角形）、配额换算法（路径覆盖代替点选）。</span>

## 5 小结

- **顶点覆盖**：≤ $k$ 个顶点覆盖所有边；证书 = 顶点子集，验证 $O(E)$——$\in NP$。
- **归约**：3-SAT → 顶点覆盖；变量构件（真/假边）+ 子句构件（三角形）+ 连接边 + 配额 $k = n+2m$。
- **两个方向**：满足赋值 ⟹ 覆盖；覆盖 + 紧配额 ⟹ 每个子句有真文字。
- **紧配额**是归约构造的命门：每个构件都逼近最小必需，约束才被逼出。
- 顶点覆盖是「构件 + 配额」归约的模板，其 2-近似（第十二篇）是近似算法的开山案例。
