## 为什么从活动选择开始

会议室的档期、CPU 的任务调度、选课的冲突避免——这些都能抽象成**活动选择问题**：$n$ 个活动，各占时间段 $[s_i, f_i)$，两两不能重叠，最多能安排几个？<span class="marginnote">它是贪心理论的最佳落地案例：贪心规则简单到一句话（「按结束时间排序，能排就排」），但它的正确性需要完整的交换论证——恰好把上一课的性质验证走一遍。学完它，你就有了「贪心正确性」的标准范文。</span>

这一课给出贪心算法、它如何从 DP 自然「退化」出来，以及那个经典的交换证明。

## 1 问题与贪心算法

**活动选择（activity selection）**：活动 $a_i$ 用半开区间 $[s_i, f_i)$ 表示（$s_i$ 开始、$f_i$ 结束，半开保证「一个结束时另一个可开始」）。两个活动兼容当且仅当区间不重叠：$f_i \le s_j$ 或 $f_j \le s_i$。求兼容活动的最大集合。

**贪心策略**：按结束时间 $f_i$ 升序排序，依次扫描，**只要当前活动与前一个已选活动兼容就选**。

```
GREEDY-ACTIVITY-SELECTOR(s, f)
  n = s.length
  sort activities by f ascending
  A = {a_1}                     // 结束最早的必选
  k = 1
  for m = 2 to n
    if s[m] >= f[k]
      A = A ∪ {a_m};  k = m
  return A
```

「选结束最早的」让剩余时间最长，给后续活动留下最大余地——这是整个贪心的直觉。<span class="marginnote">为什么不是「开始最早的」或「持续时间最短的」？反例：开始最早的会议可能持续一整天，把后续全堵死；最短的会议可能横在正中，把两侧各切一段。只有「结束最早」同时保证「早点腾出时间」。结束时间排序是活动选择的标准答案。</span>

## 2 贪心选择性质：交换论证

**定理**：设 $a_1$ 是结束时间最早的活动，则存在一个最优解以 $a_1$ 开头。

**交换论证**：设 $O$ 是任一最优解，其中结束最早的活动是 $a_j$（$j \ne 1$）。把 $O$ 里的 $a_j$ **替换成 $a_1$**：

- **可行性**：$a_1$ 的结束时间不晚于 $a_j$（$f_1 \le f_j$），而 $O$ 中 $a_j$ 之后的活动都满足「开始时间 $\ge f_j$」，自然 $\ge f_1$——所以替换后所有活动仍两两兼容。
- **最优性**：替换只换了一个活动，集合大小不变，仍是 $|O|$ 个活动。

故存在包含 $a_1$ 的最优解——贪心第一步不失最优。<span class="marginnote">这个交换论证的关键是「$f_1 \le f_j$」：$a_1$ 结束不晚于任何活动的开始可行性前提。替换 $a_j$ 为 $a_1$ 后，$a_1$ 只会更早结束，给后面的活动留的余地只增不减——这就是「结束最早」的性质红利。</span>

## 3 最优子结构与递归贪心

选了 $a_1$ 后，剩余问题变成：在**开始时间 $\ge f_1$** 的活动里选最大兼容集——与原问题同构。设 $S_{ij}$ = 在「结束 $\le f_i$、开始 $\ge s_j$」约束下的活动子集，则

$$\text{OPT}(S_{ij}) = \max\left(1 + \text{OPT}(S_{a_k j'}),\; \text{OPT}(S_{i k})\right)$$

其中 $a_k$ 是 $S_{ij}$ 中结束最早的活动。**最优子结构**成立：原问题最优 = 选 $a_k$ + 剩余问题最优。

**辨析｜易错点：** 活动选择问题**也能用 DP** 解（$O(n^2)$ 或 $O(n\log n)$）——它完全满足 DP 的两个条件。贪心只是「发现每个状态的转移只有一个候选胜出」而简化。**不要把「贪心能解」误解成「DP 不能解」**——贪心是 DP 的优化，不是替代。

## 4 公式解析：贪心 vs DP 在活动选择上的对比

设按结束时间排序，$c[i][j]$ = 活动 $i$ 到 $j$ 之间最大兼容数，DP 转移为

$$c[i][j] = \max_{k: \text{兼容}} \left(c[i][k] + c[k][j] + 1\right)$$

- **第一步，DP 视角**：对每个「空隙」枚举中间活动 $k$ 作为分割——$O(n^2)$ 状态 × $O(n)$ 枚举。
- **第二步，贪心洞察**：最优解必含「空隙内结束最早的活动 $a_k$」——这个 $k$ 是**唯一**的胜出者，不用枚举。
- **第三步，退化**：把「枚举 $k$」换成「直接取 $a_k$」，DP 变成单链贪心，$O(n\log n)$（排序主导）。

**要点**：活动选择的贪心正确性 = 「最优解里结束最早的活动必然入选」这一结构事实。它让 DP 的 $\max$ 退化成唯一选择——这正是上一课说的「贪心是 DP 的特例」的实例化。<span class="marginnote">这个「空隙里取结束最早」的模式可迁移：区间调度、最小点覆盖区间、会议室安排等「最大化不相交区间」问题都用同一个贪心骨架。</span>

## 5 变体与延伸

- **加权活动选择**：每个活动带权重，求最大**权重**兼容集——贪心失效（结束最早但可能价值最低），需 $O(n\log n)$ DP（按结束时间排序 + 二分前驱）。<span class="marginnote">加权版是「贪心与 DP 的分界线」的活教材：没有权重时贪心最优，一加权重贪心就错。理由：交换论证依赖「所有活动等价值」——替换 $a_j$ 为 $a_1$ 不损价值；有权重时替换可能降低总权重。</span>
- **最少会议室**：区间调度变体，贪心扫时间轴维护「当前占用数」。
- **最大化不相交区间**：与活动选择同构。

**辨析｜易错点：** 半开区间 $[s_i, f_i)$ 的约定很关键——它允许「$f_i = s_j$ 时两活动兼容」。若用闭区间，边界重叠会被误判为冲突，结果偏小。**写代码前先确认区间开闭约定**。

## 6 小结

- **活动选择**：最大化兼容活动集；贪心按**结束时间升序**，能排就排。
- **贪心选择性质**：结束最早的活动 $a_1$ 必在某个最优解中——交换论证（$f_1 \le f_j$ 保可行性）。
- **最优子结构**：选 $a_1$ 后剩余问题同构，递归贪心。
- 贪心是 DP 的特例：最优解中「结束最早必选」让 DP 的 $\max$ 退化为唯一选择。
- 加权活动选择贪心失效，需 DP——权重破坏交换论证。
