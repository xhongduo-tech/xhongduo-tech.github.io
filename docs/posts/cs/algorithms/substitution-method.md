## 为什么从代入法开始

上一课我们用递归树「看到」了 $T(n) = 2T(n/2) + \Theta(n) = \Theta(n\lg n)$。但看到不等于证明：递归树默认 $n$ 是 2 的幂、忽略取整、还假设所有叶子等高。从工程直觉到数学保证，中间差一个严格的证明步骤。

**代入法（substitution method）**就是填补这道沟的工具。它只需要两样东西：一个**猜测**（guess），一次**数学归纳**（induction）。它也因此承担了整个分治篇里「证」的职责：递归树负责猜，代入法负责证，两者配合无间。学会了它，你手里就多了一把能对付**任何**递归式的通用钥匙——主定理不过是它的「背诵版」。

## 1 代入法的三步：猜、证、解常数

**代入法（substitution method）**：先猜出解的形式（如 $T(n) = O(n\lg n)$），再用数学归纳法证明猜测成立，最后把归纳证明中出现的未定常数解出来。它分三步：

1. **猜测解的形式**。递归树的求和、或者对递归式结构的直觉，都指向一个候选，比如 $T(n) = O(n\lg n)$。
2. **用数学归纳法验证**。假设猜测对「更小的规模」成立（归纳假设），代入递归式右侧，推出它对规模 $n$ 也成立。
3. **求出常数**。归纳证明里会引入常数 $c$（如 $T(n) \le c\,n\lg n$），需要证明存在某个 $c$ 使整个不等式链成立，同时满足基本情况。

<span class="marginnote">CLRS 用符号 $\lg$ 表示以 2 为底的对数，$\ln$ 才是自然对数。渐进记号（第一课）说过常数底数不影响结果，但 CLRS 全文默认 $\lg = \log_2$，阅读时保持一致最省心。</span>

第 2 步是正文，第 3 步是容易翻车的地方——因为归纳步骤里常常「差一个常数」，猜对了形式却证不出来，未必是猜测错了，而可能只是需要**加强归纳假设**（见第 4 节）。

## 2 一个完整证明：T(n) = 2T(⌊n/2⌋) + n

我们证明归并排序的递归式，这次带取整、写全：

$$
T(n) = 2\,T(\lfloor n/2 \rfloor) + n, \qquad T(1) = 1
$$

**猜测** $T(n) = O(n\lg n)$，即证明存在常数 $c > 0$，使 $T(n) \le c\,n\lg n$ 对所有 $n \ge n_0$ 成立。

先做**归纳假设**：对一切 $m < n$，$T(m) \le c\,m\lg m$。把 $m = \lfloor n/2 \rfloor$ 代入，得 $T(\lfloor n/2 \rfloor) \le c\,\lfloor n/2 \rfloor \lg\lfloor n/2 \rfloor$。代入递归式：

$$
T(n) \le 2c\,\lfloor n/2 \rfloor \lg\lfloor n/2 \rfloor + n
$$

注意 $\lfloor n/2 \rfloor \le n/2$ 且 $\lg\lfloor n/2 \rfloor \le \lg(n/2)$，所以

$$
T(n) \le 2c \cdot \frac{n}{2}\cdot\lg\frac{n}{2} + n = cn\,\lg\frac{n}{2} + n = cn\lg n - cn + n
$$

最后一步用了对数性质 $\lg(n/2) = \lg n - \lg 2 = \lg n - 1$。要让 $T(n) \le cn\lg n$ 成立，只需 $-cn + n \le 0$，即 $c \ge 1$。取任意 $c \ge 1$ 即可（稍大也无妨，下面基本情况的常数要求会覆盖它）。✔

**基本情况**：$n = 1$ 时 $T(1) = 1 \le c \cdot 1 \cdot \lg 1 = 0$ 不成立——这正是归纳法经典的**基本情况选择**问题。解决办法是不从 $n=1$ 起步，而是把 $n = 2, 3$ 这类「紧邻基本情况」直接算出来当归纳基础（$T(2) = 2T(1) + 2 = 4 \le 2c\lg 2 = 2c$，取 $c \ge 2$ 即满足；$T(3)$ 同理）。**归纳法允许把基础建立在几个小规模上，然后用 $n \ge n_0$ 的归纳步覆盖更大的 $n$。**

## 3 公式解析：一条不等式链的每一步

上一节的证明可以浓缩成一条不等式链，值得逐项拆解——它是代入法的「最小单位」：

$$
T(n) \;\le\; 2c\,\lfloor n/2 \rfloor \lg\lfloor n/2 \rfloor + n \;\le\; 2c \cdot \tfrac{n}{2} \cdot \lg\tfrac{n}{2} + n \;=\; cn\lg n - cn + n
$$

- **第一个 $\le$**：归纳假设代入。把 $m = \lfloor n/2 \rfloor$ 的界 $cm\lg m$ 塞进递归式的 $2T(\lfloor n/2 \rfloor)$ 项。
- **第二个 $\le$**：放宽取整。$\lfloor n/2 \rfloor \le n/2$，而对数 $\lg$ 单调不减，故 $\lg\lfloor n/2 \rfloor \le \lg(n/2)$。取整的麻烦在这里被一个不等式消化掉。
- **等号**：对数展开。$\lg(n/2) = \lg n - 1$，于是 $2c \cdot \tfrac{n}{2} \cdot (\lg n - 1) = cn\lg n - cn$。
- **最后的不等式**：要求 $cn\lg n - cn + n \le cn\lg n$，即 $n - cn \le 0$，也就是 $c \ge 1$。

这条链的精髓是**「留出余量」**：我们不直接证 $T(n) \le cn\lg n$，而是证出一个**比目标多出 $(-cn + n)$ 的中间形式**，再靠选常数把它消掉。$cn\lg n$ 里那个 $c$ 既是目标也是工具——这正是代入法「猜常数」的妙处。

## 4 直觉与技巧：为什么常常要猜得「更强」

**辨析｜易错点：** 新手最常见的失败是——猜 $T(n) = O(n)$ 想证明 $T(n) = 2T(\lfloor n/2 \rfloor) + n$。代入归纳假设 $T(\lfloor n/2 \rfloor) \le c\lfloor n/2 \rfloor$，得到

$$
T(n) \le 2c\lfloor n/2 \rfloor + n \le cn + n = (c+1)n
$$

得到的是 $(c+1)n$ 而不是 $cn$——**常数消不掉**，证明失败。这个失败不是运气问题：$O(n)$ 这个猜测本身是错的（解确实是 $n\lg n$），但也可能**猜对了形式、却因为假设不够强而证不出来**。经典补救是**加强归纳假设**：如果差一个 $-d\,n$（某个低阶项）才能消掉，就改猜

$$
T(n) \le c\,n\lg n - d\,n
$$

代入后得到 $cn\lg n - cn - dn + n$，只要 $c \ge 1 + d$ 就能压回 $cn\lg n - dn$。**猜得比需要的更强，往往反而更好证**——因为多出来的低阶项给了归纳步骤「消耗」的余粮。这个反直觉的技巧，是代入法的招牌动作。

## 5 改变变量：换一个世界求解

递归式的规模不一定是 $n \to n/2$。比如

$$
T(n) = 2\,T(\lfloor \sqrt{n} \rfloor) + \lg n
$$

规模是开方而非减半，直接归纳很别扭。**改变变量（change of variables）**是标准解法：令 $m = \lg n$，即 $n = 2^m$，则 $\lfloor \sqrt{n} \rfloor \approx 2^{m/2}$。定义 $S(m) = T(2^m)$，代入得

$$
S(m) = 2\,S(m/2) + m
$$

这就是第 2 节那副熟面孔！我们已经知道 $S(m) = \Theta(m\lg m)$。把 $m = \lg n$ 换回去：

$$
T(n) = S(\lg n) = \Theta(\lg n \cdot \lg\lg n)
$$

<span class="marginnote">「改变变量」的思想在数学里比比皆是：积分里的换元、傅里叶变换把卷积变成乘积。算法里遇到奇怪的规模变化（开方、对数、指数），先试试有没有一个变量能把递归式拉回标准形状——$m = \lg n$ 是最高频的候选。</span>

这个例子也顺带预告了主定理的边界：$T(n) = 2T(\sqrt{n}) + \lg n$ 的规模变化不是「除以常数 $b$」，标准主定理直接套不上，改换变量后主定理（第 4.5 节）才上场。

## 6 代入法使用手册：四条纪律

把零散经验收拢成四条纪律，写作业时逐条自查：

- **第一条，别从 $n=1$ 起步**。基本情况常在 $n = 2, 3$ 或更大的常数处验证，然后用归纳步覆盖更大规模；执拗于 $n=1$ 常会得到「$1 \le 0$」这种自取其辱的结论。
- **第二条，取整用不等式消化**。$\lfloor n/2 \rfloor \le n/2$ 配合单调性，一步放掉取整，别在取整里纠缠。
- **第三条，猜不准就加强**。差一个低阶项消不掉时，改猜 $c\,n\lg n - d\,n$，给归纳步骤留余量。
- **第四条，大 $\Theta$ 与 $\Omega$ 分开证**。$T(n) = \Theta(n\lg n)$ 要分别证 $O(n\lg n)$ 与 $\Omega(n\lg n)$；$\Omega$ 侧把 $\le$ 换成 $\ge$、把「最大」换成「最小」重走一遍流程，常数可能不同。

## 7 小结

- **代入法**三步：猜测解的形式、归纳验证、求解常数；它是递归树猜测的「证明搭档」。
- 关键动作：**假设对更小规模成立，代入递归式，用不等式放宽取整，用对数展开留出 $-cn$ 余量，最后选常数消余量**。
- 常见翻车：猜 $O(n)$ 证不动；补救是**加强归纳假设**，猜 $cn\lg n - dn$。
- 基本情况选 $n = 2, 3$ 等小规模即可，不必从 $n=1$ 起步。
- 奇怪的规模变化（开方、对数）用**改变变量** $S(m) = T(2^m)$ 拉回标准形状。

在下一节，我们把「猜」这个环节也机械化——**递归树方法（recursion tree）**：不靠灵感，而是把递归式展开成一棵树，逐层求和，系统地产出猜测。主定理的三个情形，正是从这棵树里总结出来的。
