## 为什么从钢条切割开始

上一课的原理需要一个完整的落地案例。**钢条切割（rod cutting）**是 CLRS 动态规划的第一个例子：给定长度为 $n$ 的钢条与价格表 $p_i$（长度 $i$ 的价格），问如何切割使总收益最大。<span class="marginnote">这个问题小到可以手工画递归树，又完整包含 DP 的所有元素：最优子结构、重叠子问题、自顶向下/自底向上、决策回溯。学透它，等于学会了所有「一维切割型」DP 的模板——后面 LIS、背包都会回响它的结构。</span>

更妙的是：它有一个朴素递归是 $\Theta(2^n)$ 的指数算法，而 DP 把它压到 $O(n^2)$——**这是「记忆化消除指数爆炸」最直观的演示**。

## 1 问题与朴素的指数递归

给定长度 $n$ 与价格表 $p_1, \dots, p_n$。**最优切割收益** $r_n$：把钢条切成若干段 $i_1 + i_2 + \cdots = n$，使 $\sum p_{i_k}$ 最大。例如 $p = [1, 5, 8, 9, 10, 17, 17, 20, 24, 30]$，$n = 4$ 时最优是切成 $2 + 2$，收益 $5+5 = 10$（不切 $p_4 = 9$，切成 $2+2$ 更好）。

**第一层洞察**：最优切割可以描述为「切下长度为 $i$ 的第一段 + 剩下 $n-i$ 段的最优切割」。于是：

$$r_n = \max_{1 \le i \le n} (p_i + r_{n-i}), \qquad r_0 = 0$$

直接按此递归是**指数级**的：$T(n) = 1 + \sum_{i=1}^{n-1}T(i)$，解得 $T(n) = \Theta(2^n)$。<span class="marginnote">为什么指数？因为每种「第一刀切在哪」都对应一整棵子问题树，且子问题严重重叠——$r_{n-2}$ 既出现在「先切 2」的路径里，也出现在「先切 1 再切 1」的路径里。重叠子问题正是 DP 出手的理由。</span>

## 2 另一种视角：等价的递推

CLRS 还给出一个更紧凑的形式。把「切与不切」统一：$r_n = \max(p_n, \max_{1\le i<n}(r_i + r_{n-i}))$。再进一步化简，可以写成一个更「单侧」的递推——**只考虑第一段长度为 $i$，且 $i$ 从 1 到 $n$**：

$$r_n = \max_{1 \le i \le n}(p_i + r_{n-i})$$

它已经蕴含最优子结构：最优解的第一段是某个 $i$，剩下的是规模 $n-i$ 的子问题的最优解。<span class="marginnote">这个「第一段 + 剩余子问题」的拆法，把二维的「切在哪些位置」压成一维的「第一段选多长」——最优子结构的价值正在于：不用枚举所有切割方案，只需枚举「第一刀」这个选择。</span>

## 3 自顶向下：备忘录法

朴素递归浪费在重复计算。**备忘录法（memoization）**给每个 $r_i$ 一个缓存，算过就存、再要直接取：

```
MEMOIZED-CUT-ROD(p, n)
  let r[0..n] be a new array filled with -infinity
  return MEMOIZED-CUT-ROD-AUX(p, n, r)

MEMOIZED-CUT-ROD-AUX(p, n, r)
  if r[n] >= 0  return r[n]          // 已算过，直接返回
  if n == 0  q = 0
  else  q = max over i in 1..n of (p[i] + MEMOIZED-CUT-ROD-AUX(p, n-i, r))
  r[n] = q
  return q
```

**关键**：每个 $r_i$ **只被真正计算一次**。递归调用看起来还是「每个 $n$ 都枚举 $i$」，但每次 $n-i$ 的调用是 O(1) 查表（若已缓存）。总共 $n$ 个状态，每个状态枚举 $O(n)$ 个 $i$，总时间 $O(n^2)$。<span class="marginnote">备忘录法保留了「递归」的思考方式（想清楚子问题结构即可），只是加了一层缓存。对「不擅长从底往上想」的新手特别友好——先写递归，再加缓存，就是 DP。</span>

## 4 自底向上：填表法

自底向上按规模从小到大计算，先算 $r_0, r_1, \dots$，每个 $r_j$ 用已算好的 $r_1..r_{j-1}$：

```
BOTTOM-UP-CUT-ROD(p, n)
  let r[0..n] be a new array
  r[0] = 0
  for j = 1 to n
    q = -infinity
    for i = 1 to j
      q = max(q, p[i] + r[j-i])
    r[j] = q
  return r[n]
```

两层循环：外层 $j$ 从 1 到 $n$，内层 $i$ 从 1 到 $j$，总比较次数 $\sum_{j=1}^n j = n(n+1)/2 = \Theta(n^2)$。<span class="marginnote">自底向上的好处：无递归栈开销、无缓存查找、状态依赖关系一目了然（$r[j]$ 只依赖更小的 $r[j-i]$）。CLRS 强调「子问题图是 DAG」，自底向上就是按拓扑序填表——这一观点在第十篇图算法里会再次出现。</span>

## 5 公式解析：$r_n = \max_{1\le i\le n}(p_i + r_{n-i})$ 的复杂度与正确性

**正确性**（归纳）：假设 $r_1..r_{j-1}$ 已是最优值。对 $r_j$，枚举第一段长度 $i$：$p_i + r_{j-i}$ 表示「切 $i$ + 剩余最优」，这是 $j$ 的一个合法切割收益；取所有 $i$ 的最大，就是 $j$ 的所有切割方式的上界与可达值——故 $r_j$ 最优。

**复杂度**：$T(n) = \sum_{j=1}^{n}\sum_{i=1}^{j}O(1) = \Theta(n^2)$。

三步拆解：

- **第一步，状态数**：$n+1$ 个状态 $r_0..r_n$。
- **第二步，每状态转移**：每个 $r_j$ 枚举 $j$ 个 $i$，每个转移 $O(1)$。
- **第三步，求和**：$\sum_{j=1}^n j = \Theta(n^2)$——**比指数递归的 $2^n$ 是天壤之别**。

**辨析｜易错点：** 若想**构造切割方案**（不只是收益），需要额外记录 `s[j]` = 使 $r_j$ 最优的 $i$。这是四步法的第 4 步「回溯构造」——只填 `r[]` 表只能得到最优值，得不到方案。**凡是 DP，问「最优是多少」与「怎么得到」是两件事**，后者必须存决策。

## 6 小结

- **钢条切割**：$r_n = \max_{1\le i\le n}(p_i + r_{n-i})$，朴素递归 $\Theta(2^n)$，DP $O(n^2)$。
- **最优子结构**：最优解 = 第一段 + 剩余子问题最优；只枚举「第一刀」一个选择。
- **备忘录法**：递归 + 缓存，保留思考顺序，每状态算一次。
- **自底向上**：按规模填表，$O(n^2)$，无递归开销；状态图是 DAG，按拓扑序计算。
- 回溯构造方案需额外存 `s[j]` 决策表。
