## 为什么从桶排序开始

计数排序与基数排序都要求「整数」，桶排序把线性排序扩展到**实数**——代价是引入一个概率假设：**输入均匀分布**。<span class="marginnote">桶排序是「分而治之 + 概率」的混合体：把 $[0,1)$ 区间切成 $n$ 个桶，每个元素按值落入一个桶，桶内排序后再拼接。它的期望 $O(n)$ 依赖「每桶元素不多」——而「每桶元素不多」正是均匀分布给的承诺。</span>

这一课有两个看点：算法的结构与直觉，以及那个经典的**期望时间分析**——它再次使用指示器随机变量，但这次每个「指示器」是一个「桶内元素对」。

## 1 算法：切桶、入桶、排桶、拼接

输入：$n$ 个 $[0, 1)$ 内的实数，**独立均匀分布**。算法：

```text
BUCKET-SORT(A):
    n ← A.length
    令 B[0..n−1] 为 n 个空桶
    for i ← 1 to n:
        把 A[i] 放入桶 B[⌊n · A[i]⌋]       // 值越大桶号越大
    for i ← 0 to n−1:
        INSERTION-SORT(B[i])               // 桶内排序
    按桶号顺序拼接 B[0], B[1], …, B[n−1]
```

关键设计：元素 $A[i]$ 落入第 $\lfloor n \cdot A[i] \rfloor$ 个桶——因为 $A[i] \in [0,1)$，桶号在 $[0, n-1]$，且**值越大桶号越大**，于是拼接时自然有序。<span class="marginnote">均匀分布的妙处：$n$ 个元素落入 $n$ 个桶，每个桶的期望元素数恰好是 1。「每桶大约 1 个元素」正是桶排序的甜蜜点——桶内用插入排序（对近于空或近于有序的小列表极快），总代价近线性。</span>

**辨析｜易错点：** 桶号映射必须**保序**：$A[i] < A[j] \Rightarrow \text{桶}(A[i]) \le \text{桶}(A[j])$。否则拼接时低值可能跑到高桶之后。CLRS 用 $\lfloor n \cdot A[i] \rfloor$ 恰因它是保序映射。若用不保序的哈希式散列，桶排序就退化成「排完还要全局再排」，失去意义。

## 2 期望时间分析：指示器算桶内对数

总时间 = 入桶（$O(n)$）+ 每桶排序之和 + 拼接（$O(n)$）。关键项是**各桶插入排序的时间总和**。设随机变量 $n_i$ = 第 $i$ 个桶中的元素个数，插入排序对大小为 $n_i$ 的列表花 $O(n_i^2)$，故总时间

$$T(n) = \Theta(n) + \sum_{i=0}^{n-1} O(n_i^2)$$

由期望线性性：

$$\mathbb{E}[T(n)] = \Theta(n) + \sum_{i=0}^{n-1} O(\mathbb{E}[n_i^2])$$

**核心是算 $\mathbb{E}[n_i^2]$**。用指示器 $X_{ij} = I\{\text{元素 } j \text{ 落入桶 } i\}$，则 $n_i = \sum_{j=1}^n X_{ij}$，于是

$$\mathbb{E}[n_i^2] = \mathbb{E}\left[\left(\sum_{j=1}^n X_{ij}\right)^2\right] = \sum_{j=1}^n \mathbb{E}[X_{ij}^2] + 2\sum_{j<k} \mathbb{E}[X_{ij}X_{ik}]$$

每个 $X_{ij} = 1$ 的概率是 $1/n$（均匀分布），故第一项 $\sum \mathbb{E}[X_{ij}^2] = \sum \Pr[X_{ij}=1] = 1$；对 $j \ne k$，$X_{ij}X_{ik}=1$ 当且仅当两个元素都落入桶 $i$，概率 $(1/n)^2 = 1/n^2$，共 $\binom{n}{2}$ 对，故第二项 $= 2\binom{n}{2}(1/n^2) = 1 - 1/n$。于是

$$\mathbb{E}[n_i^2] = 1 + \left(1 - \frac{1}{n}\right) = 2 - \frac{1}{n} < 2$$

代入得 $\mathbb{E}[T(n)] = \Theta(n) + O(n) = \Theta(n)$。<span class="marginnote">注意这里必须算 $\mathbb{E}[n_i^2]$ 而不是 $(\mathbb{E}[n_i])^2$——插入排序是 $n_i^2$ 的代价，期望里的平方与平方的期望差着一个方差。指示器展开恰恰把 $n_i^2$ 的期望算了出来，全程只用到 $1/n$ 与 $1/n^2$ 两个概率。</span>

## 3 公式解析：$\mathbb{E}[n_i^2] = 2 - 1/n$ 的直觉

$$\mathbb{E}[n_i^2] = 1 + 2\binom{n}{2}\frac{1}{n^2} = 2 - \frac{1}{n}$$

三步拆解：

- **第一步，对角项 $j=k$**：$X_{ij}^2 = X_{ij}$（0/1 变量的平方不变），期望 $= \Pr[X_{ij}=1] = 1/n$，$n$ 项合计 $1$。
- **第二步，交叉项 $j<k$**：两元素同入桶 $i$ 的概率 $(1/n)^2$，配对数 $\binom{n}{2}$，系数 2，合计 $2 \cdot \frac{n(n-1)}{2} \cdot \frac{1}{n^2} = 1 - 1/n$。
- **第三步，相加**：$\mathbb{E}[n_i^2] = 1 + (1 - 1/n) = 2 - 1/n$——**有界常数，不随 $n$ 增长**。

**要点**：$n_i^2$ 的期望是常数，意味着「每个桶内插入排序的期望代价是 $O(1)$」，$n$ 个桶合计 $O(n)$。均匀分布是这一切的源头：它让「两个元素同桶」的概率低到 $1/n^2$。

**辨析｜易错点：** 均匀分布假设**不可省略**。若输入集中在某小区间（如所有元素都落在 $[0.1, 0.2]$），几乎所有元素进同一个桶，桶内插入排序退化到 $O(n^2)$。桶排序的最坏情况（所有元素同桶）正是 $O(n^2)$——它只保证「期望」线性，不保证最坏。

## 4 适用条件与工程变体

桶排序的适用条件可以放宽：**不要求 $[0,1)$ 均匀，只要知道元素分布能「预分桶」使每桶期望负载 $\le 1$**。<span class="marginnote">工程上常见的变体：对浮点数按「指数位」分桶（IEEE 754 的指数天然把数按数量级分组）、对直方图数据按频率分桶、对地理位置按格子分桶。核心不变——<strong>让每桶负载小</strong>，桶内排序就便宜。</span>

对比三种线性排序：

| 算法 | 输入假设 | 时间 | 空间 |
| --- | --- | --- | --- |
| 计数排序 | 小范围整数 | $\Theta(n+k)$ | $O(k)$ |
| 基数排序 | 固定位宽整数 | $\Theta(d(n+k))$ | $O(n+k)$ |
| 桶排序 | 均匀分布实数 | 期望 $\Theta(n)$ | $O(n)$ |

## 5 数值算例：十个随机数入桶

取 $A = [0.78, 0.17, 0.39, 0.26, 0.72, 0.94, 0.21, 0.12, 0.23, 0.68]$（$n = 10$，$[0,1)$ 内）。按 $\lfloor 10 \cdot A[i] \rfloor$ 分桶：

| 桶 | 落入的元素 | 桶内排序后 |
| --- | --- | --- |
| B[1] | 0.17, 0.12 | 0.12, 0.17 |
| B[2] | 0.26, 0.21, 0.23 | 0.21, 0.23, 0.26 |
| B[3] | 0.39 | 0.39 |
| B[6] | 0.68 | 0.68 |
| B[7] | 0.78, 0.72 | 0.72, 0.78 |
| B[9] | 0.94 | 0.94 |
| 其余 | 空 | — |

按桶号拼接：$0.12, 0.17, 0.21, 0.23, 0.26, 0.39, 0.68, 0.72, 0.78, 0.94$——**全局有序**。<span class="marginnote">看桶内规模的「稀疏性」：6 个非空桶里，最大桶（B[2]）只有 3 个元素——插入排序对 3 个元素几乎免费。若输入均匀，每个桶期望只有 1 个元素（$\mathbb{E}[n_i] = 1$），桶内排序是 $O(1)$ 级别的；本例 10 个元素落入 10 桶，实测平均每桶 1 个，与理论吻合。若所有元素挤进同一个桶（如都在 $[0.1,0.2]$），桶内排序就会退化到 $O(n^2)$——分布假设的破坏代价清晰可见。</span>

**核对 $\mathbb{E}[n_i^2]$**：$n = 10$ 时 $\mathbb{E}[n_i^2] = 2 - 1/10 = 1.9$——每个桶的期望平方规模 < 2，于是 $n$ 个桶的插入排序总代价期望 $\sum O(1.9) = O(n)$。平方的期望与期望的平方（$1^2 = 1$）差着方差，而指示器展开正好补上了这一块。

## 6 小结

- **桶排序**：$[0,1)$ 均匀实数按值分入 $n$ 桶，桶内插入排序，拼接即有序。
- **期望分析**：总代价 $O(\sum n_i^2)$，用指示器算 $\mathbb{E}[n_i^2] = 2 - 1/n$，得期望 $\Theta(n)$。
- 数值算例：十个随机数入桶后逐桶排序拼接即有序，最大桶仅 3 个元素。
- **均匀分布是命门**：分布假设破坏则退化为 $O(n^2)$ 最坏。
- 分桶映射必须**保序**；每桶期望负载 $\le 1$ 是线性成立的充分条件。
- 桶排序把「排序」变成「分桶 + 小规模排序」，是分布已知时最快的排序策略之一。


**速查表**：

| 概念 | 含义 |
| --- | --- |
| 保序映射 $\lfloor n\cdot A[i]\rfloor$ | 值越大桶号越大，拼接自然有序 |
| 负载 $n_i$ | 第 $i$ 桶元素个数，期望 1 |
| $\mathbb{E}[n_i^2] = 2 - 1/n$ | 桶内插入排序代价的期望 |
| 分布假设 | 输入 $[0,1)$ 均匀，否则退化 $O(n^2)$ |

**辨析｜易错点：** 分桶映射必须保序：$A[i] < A[j] \Rightarrow \text{桶}(A[i]) \le \text{桶}(A[j])$。若用不保序的哈希散列，拼接时低值可能跑到高桶之后，桶排序就失去意义。

**数值快照**：$n=10$ 个随机数入桶，最大桶 B[2] 仅 3 个元素——均匀分布让每桶期望 1 个元素，桶内插入排序几乎免费；若全挤进一个桶则退化 $O(n^2)$。
