## 为什么从图的遍历开始

图算法是算法设计的皇冠，而**遍历**是它的第一块基石。这一课把《数据结构》里已学过的 BFS 与 DFS 升级到「算法分析」的视角：不仅会写，还要**理解它们的性质**——BFS 的最短路性质、DFS 的时间戳与括号定理、边的四种分类。<span class="marginnote">这些性质是后续所有图算法的地基：拓扑排序靠 DFS 完成时间，强连通分量靠 DFS 的二次遍历，DAG 最短路靠拓扑序，无向图连通性靠 DFS 树。不把这些性质吃透，后面十课都会悬空。</span>

这一课是「复习 + 深化」：表示法、BFS 的复杂度与最短路性质、DFS 的时间戳系统。

## 1 图的表示：邻接表与邻接矩阵

**邻接表（adjacency list）**：$G=(V,E)$ 用 $|V|$ 个链表表示，每个顶点 $u$ 的链表存它的所有邻接点。**空间** $O(V+E)$。**邻接矩阵**：$V\times V$ 布尔矩阵，$A[u][v]=1$ 当且仅当 $(u,v)\in E$。**空间** $O(V^2)$。

| 表示 | 空间 | 判断边(u,v) | 遍历 u 的邻居 | 适用 |
| --- | --- | --- | --- | --- |
| 邻接表 | $O(V+E)$ | $O(\deg(u))$ | $O(\deg(u))$ | 稀疏图 |
| 邻接矩阵 | $O(V^2)$ | $O(1)$ | $O(V)$ | 稠密图 |

**辨析｜易错点：** 判断「$(u,v)$ 是否是边」，邻接矩阵是 $O(1)$、邻接表要扫 $u$ 的邻居列表（$O(\deg(u))$）。**稠密图用矩阵、稀疏图用邻接表**——图算法的时间复杂度常以 $O(V+E)$ 表示，正是默认邻接表。<span class="marginnote">《数据结构》专题里邻接表/矩阵是重点；这里的区别在于「分析视角」——之后几乎所有图算法的复杂度都以 $V+E$ 计，选错表示会直接把复杂度升到 $O(V^2)$。</span>

## 2 BFS：最短路径与广度优先树

**广度优先搜索（BFS）**：从源点 $s$ 出发，用队列逐层向外扩展，访问所有可达顶点，并记录**最短距离** $d[v]$（边数为 1 的路径）。

```
BFS(G, s)
1  for each vertex u ∈ G.V − {s}
2      u.color = WHITE
3      u.d = ∞
4      u.π = NIL
5  s.color = GRAY
6  s.d = 0
7  s.π = NIL
8  Q = ∅
9  ENQUEUE(Q, s)
10 while Q ≠ ∅
11     u = DEQUEUE(Q)
12     for each v ∈ G.Adj[u]
13         if v.color == WHITE
14             v.color = GRAY
15             v.d = u.d + 1
16             v.π = u
17             ENQUEUE(Q, v)
18     u.color = BLACK
```

**复杂度**：每个顶点入队出队一次，每条边被检查两次（无向）或一次（有向），$O(V+E)$。

**最短路性质**：BFS 结束后，对每个可达 $v$，$d[v]$ 是从 $s$ 到 $v$ 的**最短距离**（按边数）。这是 BFS 最核心的性质——它来自「队列的逐层推进」：顶点按距离升序入队，先入队的距离更近。<span class="marginnote">BFS 的「逐层」性质让它成为无权图最短路的解法。它的最短路性质用「队列中顶点的距离单调不减」归纳证明——这个论证在《数据结构》里学过，这里只需记住结论并会用。</span>

## 3 DFS：时间戳与括号定理

**深度优先搜索（DFS）**：从每个未访问顶点出发递归深入，记录每个顶点的**发现时间** $d[v]$ 与**完成时间** $f[v]$（都是 1..2|V| 的整数时间戳）。

```
DFS(G)
1  for each vertex u ∈ G.V
2      u.color = WHITE
3      u.π = NIL
4  time = 0
5  for each vertex u ∈ G.V
6      if u.color == WHITE
7          DFS-VISIT(G, u)

DFS-VISIT(G, u)
1  time = time + 1            // 发现 u
2  u.d = time
3  u.color = GRAY
4  for each v ∈ G.Adj[u]
5      if v.color == WHITE
6          v.π = u
7          DFS-VISIT(G, v)
8  u.color = BLACK            // u 变黑
9  time = time + 1
10 u.f = time
```

**括号定理（parenthesis theorem）**：对任意两顶点 $u, v$，区间 $[d[u], f[u]]$ 与 $[d[v], f[v]]$ 要么**互不相交**（$u, v$ 在不同的 DFS 子树中），要么**完全嵌套**（一个在另一个的子树内）。**不会部分重叠**。<span class="marginnote">「区间要么套住要么分开」是 DFS 的结构基石：它意味着 DFS 树中的祖先-后代关系 = 时间戳区间的包含关系。判断「$u$ 是否是 $v$ 的祖先」只需检查 $d[u] < d[v] < f[v] < f[u]$。</span>

**边的四种分类**：按 DFS 树，边可分为

**树边**：DFS 树中的边（发现新顶点）；
**后向边**：连到祖先（在白/灰时遇到）；
**前向边**：连到后代（非树边）；
**横向边**：连到其他子树。

**关键性质**：**无向图只有树边与后向边**（无前向/横向）；有向图四类都可能有。<span class="marginnote">「无向图无横向边」直接推出「无向图无环 ⟺ DFS 无后向边」——这是环检测的标准工具。有向图的环检测则看「是否有后向边」，拓扑排序会用到。</span>

## 4 公式解析：为什么 BFS 是 $O(V+E)$

总时间 = 初始化 + 队列处理：

$$T_{\text{BFS}} = O(V) + \sum_{u \in V} O(\deg(u)) = O(V + E)$$

- **第一步，初始化**：给所有顶点上色、设距离，$O(V)$。
- **第二步，扫描边**：每个顶点出队时扫描其邻接表，顶点 $u$ 贡献 $O(\deg(u))$。
- **第三步，握手引理**：$\sum_{u\in V}\deg(u) = 2|E|$（无向）或 $|E|$（有向）——所有顶点的度数之和等于边数的两倍。

**要点**：遍历复杂度 $O(V+E)$ 的「+E」来自握手引理——每条边恰好被它的两个端点各看一次。**「$O(V+E)$」是图算法的标配复杂度**，后续所有图算法都以此为基础。

**辨析｜易错点：** BFS 的 $O(V+E)$ 与「遍历了每个顶点」不是一回事——队列里只入队**可达**顶点，但初始化仍扫描全部顶点。稀疏图（$E \ll V^2$）时 $O(V+E) \ll O(V^2)$，这正是邻接表的意义。

## 5 小结

- **图的表示**：邻接表 $O(V+E)$ 空间（稀疏图）、邻接矩阵 $O(V^2)$（稠密图/判断边）。
- **BFS**：队列逐层扩展，$O(V+E)$；对无权图给出最短距离，顶点按距离升序入队。
- **DFS**：递归深入 + 发现/完成时间戳 $d[v], f[v]$；括号定理（区间套住或分开）。
- **边分类**：树边、后向、前向、横向；无向图只有树边与后向边。
- 握手引理 $\sum\deg(u) = 2E$ 是「$O(V+E)$」复杂度的来源。

在下一课，我们用 DFS 完成时间做**拓扑排序**——为什么「完成时间逆序」就是合法的拓扑序？那个「DAG 必有拓扑序」的证明是怎样的。
