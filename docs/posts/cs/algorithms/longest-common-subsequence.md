# 最长公共子序列（Longest Common Subsequence）：递推式与回溯构造

## 为什么从最长公共子序列开始

在基因组比对、diff 工具、拼写纠错、抄袭检测里，一个核心问题是：**两个序列有多「像」？** 最长公共子序列（LCS）给出一种朴素而强大的相似度定义——不要求连续，只要求「按序出现」即可。<span class="marginnote">「ABCBDAB」与「BDCABA」的最长公共子序列是「BCBA」，长度 4。注意它是<strong>子序列</strong>不是<strong>子串</strong>：字符不必连续（B-C-B-A 在原串里隔着别的字符），但相对顺序必须保持。这个「可以不连续」是它与「子串」的本质分界。</span>

这一课是**双序列 DP** 的第一次完整演示：二维状态表、四种递推分支、以及回溯构造。理解它，编辑距离、最优 BST 的二维表就都通了。

## 1 最优子结构与递推式

设 $X = \langle x_1, \dots, x_m \rangle$，$Y = \langle y_1, \dots, y_n \rangle$，$c[i][j]$ = $X$ 的前 $i$ 个字符与 $Y$ 的前 $j$ 个字符的 LCS 长度。

**核心观察**看最后两个字符 $x_i$ 与 $y_j$：

- 若 $x_i = y_j$，它们可以配对进 LCS：$c[i][j] = c[i-1][j-1] + 1$。
- 若 $x_i \ne y_j$，LCS 不包含「两者同用」——它要么在「$X$ 少一个」里，要么在「$Y$ 少一个」里：$c[i][j] = \max(c[i-1][j], c[i][j-1])$。

$$c[i][j] = \begin{cases} 0, & i=0 \text{ 或 } j=0 \\ c[i-1][j-1] + 1, & x_i = y_j \\ \max(c[i-1][j],\; c[i][j-1]), & x_i \ne y_j \end{cases}$$

<span class="marginnote">这个递推式的正确性依赖最优子结构：$X$ 与 $Y$ 的 LCS 必然由「去掉尾部后的更短序列」的 LCS 延伸而来。剪贴论证：若 $x_i=y_j$ 且 $x_i$ 不在某最优 LCS 里，则把它替换进去还能再长 1，矛盾。</span>

**辨析｜易错点：** 「$x_i = y_j$ 时一定取 $c[i-1][j-1]+1$」需要前提：**$x_i$ 和 $y_j$ 配成一对**。若 $x_i = y_j$ 但跳过它们（例如后面有更划算的配对），$c[i-1][j-1]+1$ 仍是下界吗？是的——因为若跳过，LCS 至多 $\max(c[i-1][j], c[i][j-1]) \le c[i-1][j-1]+1$（由于两个更短序列的 LCS 至多让其中一个序列多一个匹配）。所以「相等就配」不失最优。

## 2 填表：按行推进

自底向上按 $i$ 从 1 到 $m$、$j$ 从 1 到 $n$ 填二维表。每格 $c[i][j]$ 依赖 $c[i-1][j-1]$、$c[i-1][j]$、$c[i][j-1]$——都在「上一行或本行左侧」，已先算好：

```text
for i = 1 to m:
    for j = 1 to n:
        if x_i == y_j:
            c[i][j] = c[i-1][j-1] + 1;   b[i][j] = "↖"
        elif c[i-1][j] >= c[i][j-1]:
            c[i][j] = c[i-1][j];         b[i][j] = "↑"
        else:
            c[i][j] = c[i][j-1];         b[i][j] = "←"
```

$b$ 表记录每格的「来源方向」，是回溯构造 LCS 的决策表。<span class="marginnote">填表顺序只需保证「依赖格先算」。按行从左上到右下即可，因为 $c[i][j]$ 的三个依赖分别来自正上方、正左方、左上方——都先于 $(i,j)$ 填好。</span>

## 3 公式解析：为什么是 $O(mn)$ 时间

每格 $c[i][j]$ 用常数时间计算（一次比较 + 至多两次查表），共 $m\times n$ 格：

$$T(m,n) = \sum_{i=1}^{m}\sum_{j=1}^{n} O(1) = \Theta(mn)$$

- **第一步，状态数**：$(m+1)(n+1)$ 个格，即 $mn$ 量级。
- **第二步，每格转移**：$O(1)$——三种来源各一次常数判断。
- **第三步，总时间**：$\Theta(mn)$，空间也是 $\Theta(mn)$（$c$ 与 $b$ 两表）。

**要点**：双序列 DP 的复杂度是「两个长度之积」。$m = n = 10^3$ 时 $10^6$ 格完全可行；$10^5$ 长度就会爆内存——这时需要降维技巧（只保留两行）或改用其他算法（如 Myers 的 $O(ND)$ 算法，diff 工具的实现）。<span class="marginnote">空间可以压到 $O(\min(m,n))$：算 $c[i][j]$ 只用上一行，故只需保留两行；但要<strong>输出 LCS 本身</strong>还是得存整张决策表 $b$。这是「只要长度」与「要序列」的又一次分工。</span>

## 4 回溯构造 LCS

从 $b[m][n]$ 出发，沿决策表反向走：

```text
PRINT-LCS(b, X, i, j):
    if i == 0 or j == 0:
        return
    if b[i][j] == "↖":                   // 配对：x_i 进入 LCS
        PRINT-LCS(b, X, i-1, j-1)
        输出 x_i
    elif b[i][j] == "↑":                 // 抛弃 x_i
        PRINT-LCS(b, X, i-1, j)
    else:                                // "←"，抛弃 y_j
        PRINT-LCS(b, X, i, j-1)
```

只有「↖」格打印字符，其余格只是「穿越」——回溯路径上的每个「↖」对应 LCS 中的一个字符，自后向前收集即为 LCS。<span class="marginnote">「↖」的语义：$x_i$ 与 $y_j$ 配成一对，字符 $x_i$ 进入 LCS；「↑」表示「抛弃 $x_i$」，「←」表示「抛弃 $y_j$」。回溯路径描述了一个「删除某些字符后匹配其余」的对齐方式。</span>

**辨析｜易错点：** 当 $c[i-1][j] = c[i][j-1]$ 时取「↑」是任意的——LCS **可能不唯一**。不同实现可能输出不同但同长度的 LCS；判断正确性看**长度**是否等于 $c[m][n]$，而非要求唯一序列。

## 5 LCS 的应用与变体

**文本 diff**：按行求 LCS，未匹配的行即「新增/删除」。
**基因组比对**：DNA 序列的相似度；配合编辑距离选择最合理的变异解释。
**版本控制与克隆检测**：代码相似度评分。
**最长回文子序列**：$X$ 与其反转的 LCS。<span class="marginnote">下一个变体（编辑距离）更贴近真实应用：它给「插入、删除、替换」各自定价，把「相似度」升级为「最小编辑代价」。LCS 是「只允许删除」的特例（两个串删到相同）。</span>

## 6 小结

- **LCS**：不要求连续的公共子序列；$c[i][j]$ = 前 $i$ 与前 $j$ 字符的 LCS 长度。
- **递推式**：相等取「↖ +1」，不等取「↑/← 的 max」；$O(mn)$ 时间与空间。
- 最优子结构：尾部配对与否决定递推分支；剪贴论证保证「相等就配」不失最优。
- $b$ 决策表回溯输出 LCS；LCS 可能不唯一。
- 空间可压到两行（只要长度），要输出序列则需整张决策表。

在下一课，我们给 LCS 加权——**编辑距离**：插入、删除、替换各付代价，求最小编辑代价；Levenshtein 距离是它的著名特例。
