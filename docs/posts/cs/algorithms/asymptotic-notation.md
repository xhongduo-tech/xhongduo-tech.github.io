## 为什么需要一套记号的「公理化」

上一课我们反复说「增长阶」：插入排序是 $n^2$ 阶，归并排序是 $n\lg n$ 阶。「阶」这个词听起来很直觉，却还没有精确的定义——$n^2 + n$ 是不是 $n^2$ 阶？$2n^2$ 呢？$n^2/1000$ 呢？直觉上都是，但我们需要一套**可以证明、可以比较**的记号，把「大约是这个量级」说成一条无可辩驳的数学命题。

CLRS §3.1 给出的答案是五个渐进记号：$\Theta$、$O$、$\Omega$、$o$、$\omega$。它们像五把不同精度的尺子：$\Theta$ 量「正好这个量级」，$O$ 量「最多这个量级」，$\Omega$ 量「至少这个量级」，$o$ 与 $\omega$ 量「严格更慢 / 严格更快」。本课把五把尺子的刻度都校准一遍。

## 1 Θ：渐进紧确界

**渐进记号（asymptotic notation）**的定义方式很特别：每个记号是一个**函数的集合**，我们说 $f$ 属于它，其实是说 $f$ 属于某个集合。例如 $\Theta(g(n))$ 定义为：

$$
\Theta(g(n)) = \{\, f(n) : \text{存在正常数 } c_1, c_2 \text{ 与 } n_0,\ \text{使对所有 } n \ge n_0 \text{ 有 } 0 \le c_1 g(n) \le f(n) \le c_2 g(n) \,\}
$$

读作「$f$ 是 $g$ 的渐进紧确界」或「$f$ 与 $g$ 同阶」。直觉是：**当 $n$ 足够大，$f(n)$ 被夹在 $c_1 g(n)$ 与 $c_2 g(n)$ 之间**——$g(n)$ 乘上一个「不那么小的常数」和「不那么大的常数」，正好把 $f(n)$ 包住。<span class="marginnote">$n_0$ 的存在是「足够大」的形式化：前有限项可以乱跳，我们只在乎 $n$ 趋于无穷后的长期行为。这与第一级《数列的极限》里「$n$ 充分大后 $|a_n - L| < \varepsilon$」的 $\varepsilon$-$N$ 语言是同一个思想。</span>

条件里那个 $0 \le c_1 g(n)$ 不是废话：它保证 $f$ 取非负值（运行时间天然非负），也让 $g$ 不会被「负的界」蒙混过去。

## 2 O 与 Ω：上界与下界

$\Theta$ 要求「夹住」，$O$ 只要「上面封顶」，$\Omega$ 只要「下面托底」：

$$
O(g(n)) = \{\, f(n) : \text{存在正常数 } c, n_0,\ \text{使对所有 } n \ge n_0 \text{ 有 } 0 \le f(n) \le c\,g(n) \,\}
$$

$$
\Omega(g(n)) = \{\, f(n) : \text{存在正常数 } c, n_0,\ \text{使对所有 } n \ge n_0 \text{ 有 } 0 \le c\,g(n) \le f(n) \,\}
$$

于是显然有 $\Theta(g(n)) = O(g(n)) \cap \Omega(g(n))$——「既是上界又是下界」就是「紧确界」。<span class="marginnote">这条恒等式是理解整套记号的门钥匙：$O$ 与 $\Omega$ 各管一头，$\Theta$ 是它们之交。判断一个函数是否 $\Theta(g)$，往往拆成「先证 $O$、再证 $\Omega$」两步，比一次找两组常数容易得多。</span>

**辨析｜易错点：** $O$ 只是上界，**不要求紧**。$2n = O(n^2)$ 完全正确——因为 $2n \le 2n^2$ 对 $n \ge 1$ 成立；但 $2n \ne \Theta(n^2)$，因为不存在 $c_1 > 0$ 使 $c_1 n^2 \le 2n$ 对足够大的 $n$ 成立（比值 $2n/n^2 = 2/n$ 趋于 0）。工程里说「快排平均是 $O(n\log n)$」通常指紧确界，但数学上那只是上界——教材区分这个细节，是为了让你读证明时不踩坑。

## 3 o 与 ω：非紧确界

$O$ 与 $\Omega$ 允许「相等量级」，$o$ 与 $\omega$ 要求**严格**落后或领先。$f(n) = o(g(n))$ 定义为：对**任意**常数 $c > 0$，存在 $n_0 > 0$，使对所有 $n \ge n_0$ 有 $0 \le f(n) < c\,g(n)$。

注意「任意 $c$」：不管你给的乘法常数多小，从某处开始 $f$ 还是被 $g$ 甩开。等价地说，若 $\lim_{n\to\infty} f(n)/g(n) = 0$，则 $f = o(g)$。$\omega$ 反过来，对应极限为 $+\infty$。

**辨析｜易错点：** $f = O(g)$ 且 $f \ne \Theta(g)$，并不能推出 $f = o(g)$。反例：$f(n) = n(1 + \sin n)$ 满足 $f = O(n)$（因为 $f \le 2n$），但比值 $f/n = 1 + \sin n$ 不收敛——它既不是 $o(n)$ 也不是 $\Theta(n)$。渐进记号只管长期行为，振荡函数会让「非此即彼」失效。

## 4 公式解析：用定义证明 $3n^2 + 2n \in \Theta(n^2)$

空谈定义不如动手一次。证明 $f(n) = 3n^2 + 2n$ 与 $g(n) = n^2$ 同阶，核心是**找出那一组常数 $c_1, c_2, n_0$**：

- **第一步，找上界 $c_2$**：对 $n \ge 1$，有 $2n \le 2n^2$，所以 $f(n) = 3n^2 + 2n \le 3n^2 + 2n^2 = 5n^2$。取 $c_2 = 5$、$n_0 = 1$，即满足 $f(n) \le 5n^2$。
- **第二步，找下界 $c_1$**：$2n \ge 0$，所以 $f(n) = 3n^2 + 2n \ge 3n^2$。取 $c_1 = 3$、$n_0 = 1$，即满足 $f(n) \ge 3n^2$。
- **第三步，合并**：$3n^2 \le 3n^2 + 2n \le 5n^2$ 对所有 $n \ge 1$ 成立，按定义 $f \in \Theta(n^2)$。∎

这道题的技巧在于「把低阶项 $2n$ 放大成 $n^2$ 的常数倍」：只要 $2n = O(n^2)$，就能把它并进 $c_2$。再练一道更隐蔽的：**证明 $g(n) = \tfrac{n^2}{2} - 3n \in \Omega(n^2)$**。<span class="marginnote">减法让下界变难：$\tfrac{n^2}{2} - 3n$ 在 $n$ 小时可能为负，必须先「等 $n$ 长大」。这类「先取足够大的 $n_0$，再谈界」的手法，是渐进证明的日常。</span>

- **第四步，等 $n$ 长大**：$g(n) = n^2(\tfrac12 - \tfrac{3}{n})$。当 $n \ge 12$ 时 $\tfrac{3}{n} \le \tfrac14$，于是 $\tfrac12 - \tfrac3n \ge \tfrac14$，即 $g(n) \ge \tfrac14 n^2$。取 $c = \tfrac14$、$n_0 = 12$，按定义 $g \in \Omega(n^2)$。∎

注意我们**没有**证明 $g \in \Theta(n^2)$——事实上它确实是，因为上界 $g(n) \le \tfrac12 n^2$ 对 $n \ge 1$ 显然成立，读者可以自行补上。

## 5 公式解析：如何否定一个 Θ 断言

证明「属于」要找常数，证明「不属于」要找矛盾。第 2 节我们断言 $2n \ne \Theta(n^2)$，这里用定义彻底证一遍。假如 $2n \in \Theta(n^2)$，则存在正常数 $c_1, c_2, n_0$，使对所有 $n \ge n_0$ 有

$$
c_1 n^2 \le 2n \le c_2 n^2
$$

- **上界那半边** $2n \le c_2 n^2$ 没问题：取 $c_2 = 2$、$n_0 = 1$ 即可。坏在下界。
- **下界那半边**要求 $c_1 n^2 \le 2n$，即 $c_1 n \le 2$ 对所有 $n \ge n_0$ 成立。可一旦 $n > 2/c_1$，这个不等式立刻被破坏。
- **于是矛盾**：无论 $c_1$ 取得多小，$n$ 总会长到超过 $2/c_1$。故不存在这样的 $c_1$，$2n \notin \Theta(n^2)$。∎

四步拆解：

- **第一步，把断言翻成不等式**：$\Theta$ 的定义要求「夹住」，否定它只需说明「夹不住」——通常是下界或上界有一头永远无法满足。
- **第二步，找罪魁祸首**：这里下界失效，因为 $2n / n^2 = 2/n \to 0$。比值趋于 0，意味着 $2n$ 相对 $n^2$「越来越矮」，任何 $c_1 n^2$ 都会在足够大的 $n$ 面前压过它。
- **第三步，用矛盾收尾**：$c_1 n \le 2$ 对所有 $n \ge n_0$ 成立是不可能的——固定 $c_1$ 后，$n$ 是无界的。这就是「不存在常数」的严格证明。
- **第四步，推广成口诀**：**判断「不属于」，就看比值 $f/g$ 是否趋于 0 或 $\infty$**——这在直觉层面与「找 $n_0$」的严格证明互为表里。同样的手法可以证 $6n^3 \notin \Theta(n^2)$（比值 $6n \to \infty$），读者可自行仿写。<span class="marginnote">「否定一个 $\Theta$ 断言」在算法书里无处不在：证明「$n^{1.5} \ne O(n \lg n)$」这类下界不可能结论，靠的都是同一招——假设存在、推出矛盾。</span>

## 6 五记号的运算律

有了定义，可以证明一套漂亮的性质。设 $f, g, h$ 为渐近非负函数：

- **传递性**：$f = \Theta(g) \wedge g = \Theta(h) \Rightarrow f = \Theta(h)$；对 $O, \Omega, o, \omega$ 同样成立。
- **自反性**：$f = \Theta(f)$、$f = O(f)$、$f = \Omega(f)$；但 $f = o(f)$ 与 $f = \omega(f)$ 恒假。
- **对称性**：$f = \Theta(g) \Leftrightarrow g = \Theta(f)$。
- **转置对称性**：$f = O(g) \Leftrightarrow g = \Omega(f)$；$f = o(g) \Leftrightarrow g = \omega(f)$。

CLRS §3.1 把它们总结成一张与实数比较的对照表：

| 记号 | 类比 | 记号 | 类比 |
| --- | --- | --- | --- |
| $f = O(g)$ | $f \le g$ | $f = \Omega(g)$ | $f \ge g$ |
| $f = \Theta(g)$ | $f = g$ | $f = o(g)$ | $f < g$ |
| $f = \omega(g)$ | $f > g$ | | |

这张表是记忆锚点，但**仅止于类比**：$O$ 与「$\le$」最关键的差别是，$O$ 不构成**全序**——存在函数（如 $n$ 与 $n^{1+\sin n}$）之间既没有 $O$ 关系也没有 $\Omega$ 关系。真正的定义才是裁判。

## 7 常见陷阱

- **指数底数**：$2^{n+1} = O(2^n)$（因为 $2^{n+1} = 2 \cdot 2^n$）；但 $2^{2n} \ne O(2^n)$（比值 $2^{2n}/2^n = 2^n \to \infty$）。**判断指数阶，看的是底数幂次，不是系数**。
- **对数底数**：$\log_2 n$ 与 $\ln n$ 只差常数 $\ln 2$，同阶；**但对数与多项式、指数之间没有这种宽容**。
- **等号是单向的**：$f = O(g)$ 应读作「$f$ 属于 $O(g)$ 这个集合」，$O(g) = f$ 没有意义。教材用 $=$ 只是习惯，心里要装着 $\in$。
- **$o$ 与「不是 $\Theta$」**：$f = o(g)$ 蕴含 $f = O(g)$ 且 $f \ne \Theta(g)$，但反过来不成立（见第 3 节辨析）。

## 8 小结

- 五个记号都是**函数集合**：$\Theta$ 紧确、$O$ 上界、$\Omega$ 下界、$o$ 严格更慢、$\omega$ 严格更快；$\Theta = O \cap \Omega$。
- 证明套路：**找常数 $c_1, c_2, n_0$**，把低阶项并入常数；减法项先等 $n$ 长大。
- 运算律：五记号都**传递**；$\Theta$ 对称、$O/\Omega$ 与 $o/\omega$ 转置对称；$o, \omega$ 不自反。
- 对照实数表只是记忆锚：$O$ 不是全序，振荡函数可以让记号关系失效。

在下一节，我们手里有了记号，还差一张「地图」：**常用函数的增长速率排序**，以及求和技巧——毕竟算法运行时间常常是一串和，不会求和就没法分析。
