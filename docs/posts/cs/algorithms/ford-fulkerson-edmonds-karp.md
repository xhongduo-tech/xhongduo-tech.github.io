# Ford-Fulkerson 方法及其变体：Edmonds-Karp 算法

<div class="epigraph">
<p>反复找一条可增广的路，直到无路可走——最简单的循环，收敛到最大值。</p>

## 为什么从 Ford-Fulkerson 开始

最大流最小割定理保证了「无增广路 ⟹ 最大流」，于是算法思路自然浮现：**反复找增广路并增广，直到残量网络无路可走**。这就是 **Ford-Fulkerson 方法**——它不是一个具体算法，而是一族「按不同策略找增广路」的算法。<span class="marginnote">Ford-Fulkerson 的朴素版在<strong>整数容量</strong>下是多项式吗？不是——若每次增广只 +1，且路径选择很差，可能增广 $|f^*|$ 次，而 $|f^*|$ 可以是指数级（甚至依赖容量值）。Edmonds-Karp 的修复极其简单：<strong>用 BFS 找最短（边数最少）的增广路</strong>，复杂度立刻变成 $O(VE^2)$——与容量无关的纯多项式。</span>

这一课讲方法框架、朴素版的陷阱、Edmonds-Karp 的 BFS 选择与它的复杂度分析。

## 1 Ford-Fulkerson 方法框架

```text
FORD-FULKERSON(G, s, t):
    for each 边 (u, v) in G.E:
        f(u, v) = 0                      // 初始零流
    while 残量网络 G_f 中存在增广路 p:
        c_f(p) = min{ c_f(u, v) : (u, v) ∈ p }   // 路径上的瓶颈残量
        for each 边 (u, v) in p:
            if (u, v) ∈ G.E:
                f(u, v) = f(u, v) + c_f(p)       // 正向边加流
            else:
                f(v, u) = f(v, u) - c_f(p)       // 反向边退流
```

循环不变式：$f$ 始终是**合法流**（每次增广沿残量网络，保持容量约束与守恒）。终止时无增广路，由最大流最小割定理，$f$ 是最大流。<span class="marginnote">「方法」而非「算法」：它只规定「找增广路」这个循环，不规定怎么找。不同的「找路策略」产生不同复杂度的具体算法——这是「算法族」设计模式的典范。正确性由最大流最小割定理免费给出，复杂度全看找路策略。</span>

## 2 朴素版的陷阱：为什么可能指数级

考虑「贪心坏路径」的反例：初始沿 $s \to a \to b \to t$ 增广 1 单位（把 $a\to b$ 用满），之后最优解需要 $a \to b$ 的容量走另一条路——但残量网络里反向边 $b \to a$ 允许「退回来」。如果找路策略总挑「先把 $a\to b$ 填满」的路径，每次增广 1、需要反向再增广……**在最坏构造下需要 $2^k$ 次增广**（容量 $2^k$ 的对称图），时间随容量指数增长。<span class="marginnote">这个反例说明：Ford-Fulkerson 的朴素版（任意找路）不是多项式算法。问题不在「增广」本身，而在「找路顺序」——坏顺序会反复在两条路径间来回倒腾。Edmonds-Karp 的 BFS 选择正是为了打破这种「来回震荡」。</span>

**辨析｜易错点：** 反例依赖**非整数容量**或**很大的容量值**。若容量全是「够小」的整数，朴素版仍可能多项式；但理论上没有保证。**「任意找路」的正确性没错，复杂度没谱**——这正是「需要更聪明找路策略」的理由。

## 3 Edmonds-Karp：BFS 找最短增广路

**Edmonds-Karp 算法**：在残量网络中用 **BFS** 找「边数最少」的增广路。

```text
EDMONDS-KARP(G, s, t):
    for each 边 (u, v) in G.E:
        f(u, v) = 0
    while TRUE:
        p = BFS 在残量网络 G_f 中找「边数最少」的 s → t 增广路
        if p 不存在:
            break                        // 无增广路，f 已是最大流
        c_f(p) = min{ c_f(u, v) : (u, v) ∈ p }
        for each 边 (u, v) in p:
            if (u, v) ∈ G.E:
                f(u, v) = f(u, v) + c_f(p)
            else:
                f(v, u) = f(v, u) - c_f(p)
```

**为什么 BFS 有效**：边数最短的增广路让「某条边被用作瓶颈」的次数受限——每增广一次，至少一条边变成「满流瓶颈」；而这条边在下次增广前必须先被「反向清空」。Edmonds-Karp 的核心引理是：**从 $s$ 到任何顶点的最短路径距离（边数）随增广单调不降**。<span class="marginnote">引理的直觉：增广可能引入反向边，反向边「往回走」不会让任何顶点更近。于是每条边被选为瓶颈的次数 ≤ 它在「最短路级别」上被清空重用的次数，总量 $O(E)$ 次。这个「单调不降」的论证是 Edmonds-Karp 复杂度分析的心脏。</span>

## 4 公式解析：Edmonds-Karp 为什么是 $O(VE^2)$

设每次增广使至少一条边成为「临界边」（残量为 0 的瓶颈）。关键引理：每条边成为临界边**至多 $O(V)$ 次**。于是增广次数 ≤ $O(VE)$，每次增广找 BFS 花 $O(E)$：

$$T(n) = O(E) \times O(VE) = O(VE^2)$$

- **第一步，增广次数**：每条边至多成为瓶颈 $O(V)$ 次（由最短距离单调不降证明），总瓶颈事件 $O(VE)$。
- **第二步，单次代价**：BFS 找最短增广路 $O(E)$。
- **第三步，相乘**：$O(VE^2)$——与容量值无关，纯顶点/边数的多项式。

**要点**：$O(VE^2)$ 是「容量无关」的关键卖点——容量再大也不影响上界。对稠密图 $V^2 \approx E$ 时约 $O(V^4)$，仍是实用范围。<span class="marginnote">更快的最大流算法族：Dinic 的 $O(V^2E)$、push-relabel 的 $O(V^2E)$（下一课）、以及现代的近线性算法。Edmonds-Karp 的价值在于「第一个多项式界 + 实现简单」，至今仍是教学与不少工程的首选。</span>

## 5 数值算例：一个五顶点网络跑三轮

网络：$s \to a$（容量 3）、$s \to b$（2）、$a \to b$（1）、$a \to t$（2）、$b \to t$（3）。先看最小割：$\{s\}$ 割容量 $3+2=5$，$\{s,a\}$ 割容量 $2+1+2=5$，$\{s,a,b\}$ 割容量 $2+3=5$——最小割 5，所以最大流应为 5。

**Edmonds-Karp 三轮增广**：

| 轮 | BFS 找到的最短增广路（边数） | 瓶颈 $c_f$ | 增广量 | 累计流 |
| --- | --- | --- | --- | --- |
| 1 | $s \to a \to t$（2 条边） | $\min(3, 2) = 2$ | 2 | 2 |
| 2 | $s \to b \to t$（2 条边） | $\min(2, 3) = 2$ | 2 | 4 |
| 3 | $s \to a \to b \to t$（3 条边） | $\min(1, 1, 1) = 1$ | 1 | 5 |

第 3 轮的路径用到残量：$s\to a$ 剩 1、$a\to b$ 全 1、$b\to t$ 剩 1——增广后 $s\to a$ 满 3、$a\to b$ 满 1、$b\to t$ 满 3。第 4 轮 BFS 找不到任何 $s\to t$ 路径（$s$ 的两条出边都满流），算法终止，流 = 5 = 最小割。<span class="marginnote">看点一：第 3 轮不是「最短的两条边路径」，而是唯一剩余的三边路径——Edmonds-Karp 每轮都严格取<strong>当前残量网络里的最短路径</strong>，路径长度单调不降（2, 2, 3）。看点二：若某轮 BFS 先撞到 $s \to b \to t$ 而非 $s \to a \to t$，结果不变（流值唯一）——只是找路顺序不同。这个「顺序不影响终点、只影响步数」正是多项式界的宽容度来源。</span>

**对照朴素版**：若第 1 轮有人「贪心地」先沿 $s \to a \to b \to t$ 增广 1，把 $a\to b$ 填满，后续还要靠反向边 $b\to a$ 把流退回去才能到 $t$——在小图上还看不出灾难，但对称构造下这种「来回倒腾」能让增广次数指数级膨胀。**BFS 的「最短优先」保证了每轮至少清掉一条边、且距离不降**，指数膨胀被结构性排除。

## 6 小结

- **Ford-Fulkerson 方法**：反复找增广路并增广，直到无路；正确性靠最大流最小割定理。
- **朴素版陷阱**：任意找路可能指数级增广（坏顺序来回震荡），非多项式。
- **Edmonds-Karp**：用 BFS 找**边数最短**的增广路，打破震荡。
- **复杂度** $O(VE^2)$：每条边至多成为瓶颈 $O(V)$ 次（最短距离单调不降），与容量无关。
- 数值算例：五顶点网络三轮（2, 2, 3 条边的路径）增广到最大流 5，与最小割吻合。
- 后续：Dinic、push-relabel 进一步提速；Edmonds-Karp 是理解整个流算法族的起点。


**速查表**：

| 概念 | 含义 |
| --- | --- |
| 残量网络 $G_f$ | 记录每条边还能增广多少、能否退流 |
| 增广路 | $s$ 到 $t$ 的残量正边路径 |
| 瓶颈容量 $c_f(p)$ | 路径上最小残量 |
| 反向边 | 允许「退流」，是算法正确性的关键 |

**辨析｜易错点：** 朴素 Ford-Fulkerson 的坏例子依赖「非整数或很大的容量」——若容量够小，朴素版可能多项式；但理论上无保证。Edmonds-Karp 的 BFS「最短优先」正是为了排除「来回倒腾」的指数震荡。

**数值快照**：五顶点网络三轮（路径长 2、2、3 条边）增广到最大流 5，与最小割吻合；每轮 BFS 取最短增广路，路径长度单调不降——这就是「距离单调」保证多项式界的微观机制。


- 实践选型：$|V|$ 数百内 Edmonds-Karp 足够；更大规模再上 Dinic 或 push-relabel。
