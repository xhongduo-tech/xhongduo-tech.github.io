## 为什么从 Graham 扫描开始

给一组点，**凸包（convex hull）**是「包含所有点的最小凸多边形」。它在碰撞检测、图像识别、最远点对、数据聚类里都是第一步。<span class="marginnote">凸包的「橡皮筋」直觉：把所有点钉在平面上，拉一根橡皮筋套住它们，松手后橡皮筋绷成的形状就是凸包——它的顶点是「最外侧」的点，边是「支撑线」。Graham 扫描把「找凸包」变成「按极角排序 + 一趟左转检查」，$O(n\log n)$。</span>

这一课讲 Graham 扫描的算法、它如何用叉积判断「左转/右转」、以及正确性的核心论证。

## 1 算法：排序 + 单调栈

**GRAHAM-SCAN**：

```
GRAHAM-SCAN(Q)
  let p0 be the point with minimum y-coordinate (tie: min x)
  sort the other points by polar angle with respect to p0
  let S be an empty stack;  PUSH(p0);  PUSH(p1);  PUSH(p2)
  for i = 3 to n-1
    while DIRECTION(TOP-NEXT(S), TOP(S), p_i) <= 0   // 非左转 → 弹出
      POP(S)
    PUSH(p_i)
  return S
```

**关键步骤**：

1. 选最低点 $p_0$（y 最小、同 y 取最左）作为「锚点」。
2. 其余点按相对 $p_0$ 的**极角**排序。
3. 用栈维护「当前候选凸包顶点」；新点来时，若栈顶的两个点与新点构成**非左转**（右转或共线），弹出栈顶——它不可能是凸包顶点。<span class="marginnote">「非左转就弹出」是 Graham 的全部逻辑：凸多边形沿逆时针方向走，每个转角必须是<strong>左转</strong>（内部角度 < 180°）。若出现右转或平角（DIRECTION ≤ 0），说明栈顶顶点「凹进去」了——它在凸包内部，被弹出。这个「单调栈 + 左转检查」是计算几何最优雅的模式之一。</span>

## 2 正确性：为什么弹出「非左转」不丢顶点

**直觉**：凸包的边界沿逆时针方向每个转角都 < 180°（严格左转）。当栈顶 $S[top]$、次顶 $S[top-1]$ 与新点 $p_i$ 构成非左转时，$S[top]$ 处于「凹角」——它不可能在凸包上（凸包顶点必须都是凸角）。

**严格论证**（CLRS）：按极角顺序处理时，栈维护「已处理点的凸包」。新点 $p_i$ 加入时，若构成右转，则栈顶顶点被「包在」$p_i$ 与新边的内侧——它不是凸包顶点，弹出。反复弹出直到左转，然后压入 $p_i$。由归纳，处理完所有点后栈恰好是全部点的凸包。<span class="marginnote">「按极角排序」是正确性的前提：极角顺序保证处理到 $p_i$ 时，$p_i$ 之前的所有点都位于「$p_0 \to p_i$ 的同一侧」——这使「非左转弹出」不破坏尚未处理的点。若顺序乱，弹出可能误删真正的凸包顶点。排序是 Graham 的灵魂。</span>

## 3 公式解析：复杂度 $O(n\log n)$

$$T(n) = \underbrace{O(n\log n)}_{\text{极角排序}} + \underbrace{O(n)}_{\text{扫描（每个点至多进出栈一次）}} = O(n\log n)$$

- **第一步，排序**：按极角排序 $n-1$ 个点，$O(n\log n)$（比较用叉积判定极角大小）。
- **第二步，扫描**：每个点入栈一次、至多出栈一次——栈操作总 $O(n)$。
- **第三步，总时间**：$O(n\log n)$ 由排序主导。空间 $O(n)$（栈）。

**要点**：每个点「至多进出栈一次」是摊还论证——弹出总次数 ≤ 压入总次数 = $n$。**排序是唯一超线性的部分**，凸包扫描本身线性。<span class="marginnote">比较极角需要「以 $p_0$ 为原点比较两个点的方向」——用叉积：$p_0 p_a \times p_0 p_b > 0$ 表示 $a$ 的极角小于 $b$。这个比较器避免了浮点角度计算，保持整数精确性。共线点（相同极角）要按距离排序，便于「只保留最远点」。</span>

**辨析｜易错点：** `DIRECTION <= 0` 的共线处理要看需求——若要求「凸包不含共线边上的点」，用 `<= 0`（共线即弹出）；若允许共线边，用 `< 0`。**共线策略影响凸包的顶点集**，实现前先约定。另外最低点 $p_0$ 的选取（y 最小、同 y 最左）必须唯一——若有并列会破坏排序基准。

## 4 Graham vs 其他凸包算法

| 算法 | 时间 | 特点 |
| --- | --- | --- |
| Graham 扫描 | $O(n\log n)$ | 排序 + 单调栈，实现简洁 |
| Jarvis 步进 | $O(nh)$ | 逐点「礼品包装」，$h$ = 凸包顶点数 |
| 分治凸包 | $O(n\log n)$ | 递归合并 |
| Andrew 单调链 | $O(n\log n)$ | 按 x 排序代替极角，不需锚点 |

Graham 是「排序后一趟扫描」的典范；Andrew 单调链（按 x 排序、上下两次扫描）在许多实现里常数更小。<span class="marginnote">选择依据：$h$ 很小时 Jarvis 可能更快（$O(nh)$ 优于 $n\log n$）；一般情况 Graham/Andrew 最稳。理解 Graham 的「排序 + 左转检查」骨架，其他凸包算法都是同思想的不同排序/扫描方式——先吃透一个，其余自然贯通。</span>

## 5 小结

- **凸包**：包含所有点的最小凸多边形；Graham 用「极角排序 + 单调栈」。
- **核心动作**：新点与栈顶两点构成非左转（DIRECTION ≤ 0）→ 弹出栈顶。
- **正确性**：凸包顶点都是凸角；按极角顺序 + 左转检查不丢顶点。
- **复杂度** $O(n\log n)$（排序主导），扫描线性（每点进出栈至多一次）。
- 共线策略（≤0 vs <0）影响顶点集；Andrew 单调链是常数更小的同类变体。
