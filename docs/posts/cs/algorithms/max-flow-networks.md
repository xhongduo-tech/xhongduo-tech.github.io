## 为什么从最大流开始

输水管网、交通路网、电路、匹配问题——凡是「从 A 运到 B 且每条通道有容量上限」的问题，都抽象成**流网络**。<span class="marginnote">最大流问题（max-flow）：给定源点 $s$、汇点 $t$、边容量，求从 $s$ 到 $t$ 能输送的最大流量。它不仅是运输问题本身，还是一个强大的「归约工具」——二分图匹配、项目选择、棒球淘汰判定都能归约到它。学完这一课，你就拿到了一把可开很多锁的万能钥匙。</span>

这一课建立基础概念：流网络、流的三条性质、残量网络与增广路——它们是 Ford-Fulkerson 方法（下下下课）的原料。

## 1 流网络与流

**流网络（flow network）** $G=(V,E)$：有向图，每条边 $(u,v)$ 有**容量** $c(u,v) \ge 0$；指定**源点** $s$ 与**汇点** $t$。若 $(u,v) \notin E$ 则 $c(u,v) = 0$。

**流（flow）**：函数 $f: V\times V \to \mathbb{R}$，满足三条性质：

1. **容量约束**：$0 \le f(u,v) \le c(u,v)$——每条边上的流不超过容量。
2. **反对称性**：$f(u,v) = -f(v,u)$——反向流为负（建模「净流」）。
3. **流量守恒**：除 $s, t$ 外，每个顶点的**净流入为 0**：$\sum_{u} f(u,v) = 0, \; \forall v \ne s,t$。<span class="marginnote">守恒律是流的核心：中间节点不产生也不储存流量，进多少出多少。这是「物质不灭」在流网络里的化身——也是之后所有证明的支点。反对称性让「净流」的表述统一，是数学上优雅但实现时容易糊涂的一点。</span>

**流的值** $|f|$ = 从源点净流出的总量 = $\sum_{v} f(s,v) = \sum_{v} f(v,t)$。目标：找 $|f|$ 最大的流。

**辨析｜易错点：** 流定义里「容量约束」针对的是每条有向边 $(u,v)$，而「反对称性」说的是 $f(u,v) = -f(v,u)$——注意 $f(v,u)$ 可以是负值，但原图中未必存在反向边。实现时常用「残量容量」而非直接存负流，避免数组索引混乱。**先想清楚「流」与「边的原始方向」的关系，再写代码。**

## 2 残量网络：给「反悔」留余地

**残量网络（residual network）** $G_f$：与 $G$ 同顶点集，每条边 $(u,v)$ 的**残量容量**

$$c_f(u,v) = c(u,v) - f(u,v)$$

即「还能再流多少」。残量网络包含两类边：原边剩余容量 + **反向边**（$c_f(v,u) = f(u,v)$，表示「可以退回的流」）。<span class="marginnote">反向边是最大流算法最反直觉也最关键的设计：它让算法能「撤销」之前不优的流。没有反向边，Ford-Fulkerson 会被「贪心选了一条坏路」卡死；有了反向边，增广路径可以通过「反向流」重新路由，纠正错误。残量网络就是「当前状态下的可行调整空间」。</span>

**增广路径（augmenting path）**：残量网络中从 $s$ 到 $t$ 的一条路径。沿着它，可以把路径上每条边的流增加「瓶颈值」

$$c_f(p) = \min_{(u,v) \in p} c_f(u,v)$$

> 0。**增广** = 沿路径把流增加 $c_f(p)$。

**辨析｜易错点：** 增广路径上的边可以是「反向边」——这意味着「撤销」一段已送出的流。新手常以为「增广只能顺着原边走」，忽略了反向边恰恰是算法的灵魂。沿反向边增广 = 把之前多送的流退回来，再改走别的路。这个「退路」机制让贪心不至于困死在局部最优。

## 3 数值算例：从零流到增广

用一个小网络走一遍增广。顶点 $s, a, b, t$，边容量：$s\to a = 3$、$s\to b = 2$、$a\to b = 1$、$a\to t = 2$、$b\to t = 3$。

- **初始零流**：残量网络 = 原网络。
- **第一次增广**：选路径 $s\to a\to t$，瓶颈 $\min(3, 2) = 2$。送 2：$f(s,a)=2$、$f(a,t)=2$。残量更新：$c_f(s,a) = 1$、$c_f(a,s) = 2$（反向）、$c_f(a,t) = 0$、$c_f(t,a) = 2$。
- **第二次增广**：选路径 $s\to b\to t$，瓶颈 $\min(2, 3) = 2$。送 2：$f(s,b)=2$、$f(b,t)=2$。残量：$c_f(s,b)=0$、$c_f(b,t)=1$。
- **第三次增广**：选路径 $s\to a\to b\to t$——注意它经过了 $a\to b$ 这条「未用过的原边」。瓶颈 $\min(1, 1, 1) = 1$。送 1：总流 $= 5$。

现在 $s\to a$ 满、$s\to b$ 满、$a\to t$ 满、$b\to t$ 满，残量网络中 $s$ 无可达 $t$ 的路径——增广终止，最大流 $= 5$。<span class="marginnote">第三步的关键是「$a\to b$ 这条边被启用」：最优流不是「各走各的直路」，而是可能交叉改道。若当初第一次增广选了别的路径，后续增广会用反向边把流重新分配——这正是「当前状态 + 可调整空间」框架的威力。</span>

## 4 公式解析：流量守恒与流的值

流量守恒的数学形式是：对任意非 $s,t$ 顶点 $v$，

$$\sum_{u \in V} f(u,v) = 0 \quad\Longleftrightarrow\quad \sum_{u} f(u,v) = \sum_{w} f(v,w)$$

- **第一步，反对称性**：$\sum_u f(u,v)$ 是「净流入」（正的进、负的出），守恒要求它为 0。
- **第二步，等价形式**：净流入 0 ⟺ 流入 = 流出——这是「进多少出多少」的算术写法。
- **第三步，流的值**：$|f| = \sum_v f(s,v)$。用守恒律可证它也等于 $\sum_v f(v,t)$——源点流出的总量 = 汇点流入的总量，中间全部守恒。

**要点**：流的值不依赖「从源点数还是从汇点数」——守恒律保证了两个方向一致。<span class="marginnote">这个「守恒 ⇒ 源=汇」的论证是理解流的基础：中间节点只是「管道中转站」，流量守恒保证「源流出多少，汇就流入多少」。任何「看起来多出来或消失」的流，都违反了守恒——算法正确性靠它把关。</span>

## 5 增广的直观：为什么能提高流

初始零流：残量网络 = 原网络。找到一条 $s \to t$ 路径（如 $s \to a \to t$），瓶颈容量为路径上最小剩余容量，把流加上去。之后残量网络更新：原边剩余减少，反向边增加（等于刚送的流）。

**反例驱动**：若先增广了一条「占住 $b \to t$ 容量」的路径，而最优解需要 $b$ 的容量走别的方向——反向边允许算法「把已送出的流退回来」，重新路由。<span class="marginnote">对比普通贪心：没有反向边的「只增不减」会被局部最优困死。残量网络的妙处是它把「当前的流 + 可调整空间」合成一张图——找增广路就是在「可调整空间」里找新的改进方向。这个「当前状态 + 可达改进」的框架，也是很多优化算法的通用形态。</span>

## 6 常见疑问快速答疑

**问：流一定存在吗？** 零流（处处为 0）满足全部三条性质，所以至少有一个可行流。最大流问题因此总有一个最优解——「空运」就是退路。

**问：容量是小数怎么办？** 可以。流网络允许实数容量，理论定义不要求整数。但整数容量带来「整数流」的保证（Ford-Fulkerson 增广每次推整数），在归约到匹配等离散问题时至关重要。

**问：多源多汇怎么处理？** 加一个超级源点连到所有源点（容量 ∞）、所有汇点连到超级汇点（容量 ∞）——化多源多汇为单源单汇，一次最大流求解完成。

**问：为什么要有反对称性这条性质？** 它让「净流」的数学表述简洁：$f(u,v) = -f(v,u)$ 把双向流量合并成一条带符号的净流。实际建模时可以不显式存负值，但所有守恒推导都依赖这条约定。

**问：增广到何时停止？** 当残量网络中不存在 $s\to t$ 的路径时停止——这正是下一课最大流最小割定理的第二个等价命题。停止时的流值就是最大流，且能构造出容量相等的割。

**问：为什么最大流能被多项式时间解决，而很多图问题不行？** 因为流有「守恒 + 容量」两个线性约束，残量网络的结构让「找改进路」变得可计算。相比之下，哈密顿回路等「存在性」问题没有这种可改进的局部结构。可近似改进的结构 = 多项式算法的沃土。

**问：最大流与最短路径有什么相似？** 都是「沿可行路径推进」的迭代：最短路每次选最省的一段，最大流每次选一条增广路。区别在于最短路无需「撤销」，而流需要反向边反悔。理解这种「改进型迭代」的家族，比孤立背算法更有用。

**问：增广会不会破坏之前的流？** 增广总是沿着残量网络的边走，而残量边要么是「原边剩余」要么是「反向可退」——沿它们增广都不会违反容量约束。增广后的流仍是合法流，这是算法「不变量」的核心。

## 7 流网络的应用与直觉

最大流模型的「归约力」体现在它能把看似不相关的现实问题统一起来：

**运输与物流**：边 = 航线/公路，容量 = 班次/车次，源 = 产地，汇 = 销地——求最大运输量。
**网络路由**：边 = 链路，容量 = 带宽，源 = 发送端，汇 = 接收端——求最大吞吐。
**任务分配**：源 → 任务（容量 1）、任务 → 机器（若可做，容量 1）、机器 → 汇（容量 1）——最大流 = 最大匹配数。
**棒球淘汰判定**：建「比赛-球队」网络，判断某队是否已被数学淘汰——最大流给出「还能不能夺冠」的答案。

**直觉总结**：凡是「从 A 到 B、经过带容量限制的通道」的问题，都值得先想一想「能不能建成流网络」。学完最大流，等于拿到了把一堆现实问题归约成同一个可解问题的模板。

## 8 小结

- **流网络**：有向图 + 边容量 + 源/汇；流满足容量约束、反对称性、流量守恒。
- **流的值** = 源点净流出 = 汇点净流入；守恒律保证两者一致。
- **残量网络**：原边剩余容量 + 反向边（可撤销的流）——「当前状态的调整空间」。
- **增广路径**：残量网络中 $s \to t$ 路径，瓶颈容量 $c_f(p)$ 是可增加的流量。
- 反向边是最大流「可反悔」的关键，也是 Ford-Fulkerson 家族的理论基础。
- 零流保证可行解存在；整数容量保证整数流；多源多汇可加超源/超汇化归。
- 应用：运输规划、网络路由、任务分配、二分图匹配——都归约到最大流。
- 增广是「可反悔的贪心」：反向边让错误路由能被纠正，最终收敛最优。
