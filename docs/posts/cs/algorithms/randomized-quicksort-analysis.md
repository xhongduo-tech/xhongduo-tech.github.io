## 为什么从随机化快排开始

快速排序是实践中最快的排序算法之一，但它的经典版本有一个致命弱点：**输入已经有序时，性能退化到 $O(n^2)$**。为什么？因为每次选到的「主元」都是最大或最小元素，划分完全失衡。随机化的回答直截了当：**主元不再取固定位置，而是从区间里随机挑**。<span class="marginnote">这一改动的意义远超「碰运气」：它把「对输入分布做假设」换成「自己制造随机性」。无论输入有多坏，随机化之后面对的都是一样的随机过程——对手无法再构造最坏输入。</span>

这一课的主题是**证明期望 $O(n \log n)$**。我们将在随机分析的框架下走完一条完整路径：随机变量建模 → 指示器分解 → 期望线性性 → 求和估算。

## 1 算法回顾与随机化改造

经典快速排序的划分过程 `PARTITION(A, p, r)` 取 $A[r]$ 为主元，把数组分为「$\le$ 主元」和「$>$ 主元」两段，返回主元的最终位置 $q$。随机化版本只改一处：

```
RANDOMIZED-PARTITION(A, p, r)
  i = RANDOM(p, r)
  exchange A[r] with A[i]
  return PARTITION(A, p, r)
```

**RANDOMIZED-QUICKSORT(A, p, r)** 递归调用随机划分，然后对两段分别递归。每个元素被选为主元的概率均等——这就是随机化快排与雇佣问题的联结：**我们重新随机化了输入顺序，相当于 Fisher–Yates 洗牌的运行时版本**。<span class="marginnote">事实上，先洗牌再跑普通快排，与随机化快排的分布完全相同——两者都让每个元素等概率成为任意位置的主元。理解这个等价关系，就理解了「随机化 = 给输入均匀分布」。</span>

## 2 期望时间的指示器建模

设数组含 $n$ 个**互异**元素 $z_1 < z_2 < \cdots < z_n$。快速排序的运行时间正比于划分过程执行的总次数，而每次划分比较主元与区间内每个其他元素一次。所以**总比较次数就是运行时间的代理**。

定义指示器

$$X_{ij} = I\{z_i \text{ 与 } z_j \text{ 在某一划分中被比较}\},\qquad i < j$$

总比较次数 $X = \sum_{i=1}^{n-1}\sum_{j=i+1}^{n} X_{ij}$，由期望线性性

$$\mathbb{E}[X] = \sum_{i=1}^{n-1}\sum_{j=i+1}^{n} \Pr[X_{ij} = 1]$$

**核心问题转化为算 $\Pr[X_{ij} = 1]$**——两个元素在整个排序过程中「被比较过」的概率。

## 3 关键引理：$\Pr[X_{ij}=1] = \frac{2}{j-i+1}$

设 $Z_{ij} = \{z_i, z_{i+1}, \dots, z_j\}$ 是值介于两者之间的元素集合，共 $j-i+1$ 个元素。观察：

- 在 $Z_{ij}$ 中**最先被选为主元**的元素 $z$ 会把 $Z_{ij}$ 分成左右两段，且 $z$ 会与 $Z_{ij}$ 中除自己外的每个元素比较一次。
- 若 $z$ 是 $z_i$ 或 $z_j$，则 $z_i$ 与 $z_j$ 在这一次划分中**被直接比较**，此后分别进入不同子区间，不再相遇——比较恰好发生一次。
- 若 $z$ 是中间的某个元素，则 $z_i$ 与 $z_j$ 被分到 $z$ 的两侧，**永远不会再被比较**。

所以 $X_{ij} = 1$ 当且仅当 $Z_{ij}$ 中第一个被选为主元的元素恰是 $z_i$ 或 $z_j$。由于 $Z_{ij}$ 中每个元素被选为主元的概率相等：

$$\Pr[X_{ij} = 1] = \frac{2}{j - i + 1}$$

**这个引理是整场证明的心脏**：概率不是由全局「任意两个元素」决定，而是由**它们之间间隔的元素个数** $j-i+1$ 决定。<span class="marginnote">把「跨越大间隔的两个元素」与「紧挨着的两个元素」对比：$j-i+1$ 越大，两者被第一个主元拆开的概率越大，被比较的概率越小。间隔小的元素对几乎必然被比较。</span>

## 4 公式解析：从 $\frac{2}{j-i+1}$ 到 $\Theta(n \log n)$

现在把引理代入期望和：

$$\mathbb{E}[X] = \sum_{i=1}^{n-1}\sum_{j=i+1}^{n} \frac{2}{j-i+1}$$

对这条式子做三步拆解：

- **第一步，按间隔分组**：设 $k = j - i + 1$。对每个固定的 $k$（$2 \le k \le n$），有多少对 $(i,j)$ 满足 $j-i+1 = k$？恰好 $n - k + 1$ 对。于是内层求和按 $k$ 重排。
- **第二步，化成调和数**：$\mathbb{E}[X] = \sum_{k=2}^{n} \frac{2}{k} \cdot (n-k+1) \le \sum_{k=2}^{n} \frac{2n}{k} = 2n \sum_{k=2}^{n} \frac{1}{k} = 2n(H_n - 1)$。
- **第三步，调和数近似**：$H_n = \ln n + O(1)$，故 $\mathbb{E}[X] \le 2n \ln n + O(n) = \Theta(n \log n)$。

**结论：随机化快速排序的期望运行时间是 $\Theta(n \log n)$**，其中隐含常数约 $2\ln n$（约 $1.39 \log_2 n$），与归并排序相当。<span class="marginnote">注意这个证明没有使用「每次划分都均衡」这类乐观假设——它精确地处理了所有可能的失衡，并把失衡的可能性折算进期望。这比「平均情况」强得多，因为随机化之后没有「坏输入」可言。</span>

**辨析｜易错点：** 期望 $O(n \log n)$ 不意味着「最坏不会发生 $O(n^2)$」。随机化快排依然可能倒霉地连续选中坏主元，最坏情况仍是 $\Theta(n^2)$；只是这种情况的概率随 $n$ 指数衰减。**期望分析与最坏分析是两个不同的断言，不要混为一谈**——前者关于「平均下来」，后者关于「有没有可能」。

## 5 从期望到高概率：切比雪夫与尾界

单有期望还不够令人安心：万一方差极大，「期望好」可能只是美好想象。CLRS 用切比雪夫不等式补上这一环：可以证明 $\operatorname{Var}[X] = O(n^2)$，于是

$$\Pr\left[|X - \mathbb{E}[X]| \ge cn \log n\right] \le \frac{\operatorname{Var}[X]}{c^2 n^2 \log^2 n} = O\left(\frac{1}{\log^2 n}\right)$$

即：**以高概率，随机化快排的运行时间就是 $\Theta(n \log n)$**——不仅期望如此，偏离到 $n^2$ 的概率被压到 $O(1/\log^2 n)$。<span class="marginnote">更精细的尾界（切尔诺夫/霍夫丁）还能给出 $e^{-c n}$ 量级的指数衰减。这告诉我们：随机化快排不仅「平均快」，而且「几乎总是快」。这也是为什么它成为工业排序库（如 C 库的 `qsort`、C++ `std::sort` 的混合策略）的骨干。</span>

## 6 小结

- 随机化改造：主元从区间内**均匀随机选取**，对手无法构造最坏输入。
- 建模：比较次数 $X = \sum X_{ij}$，用指示器与期望线性性把问题归约为「单对元素被比较的概率」。
- **关键引理**：$\Pr[X_{ij}=1] = 2/(j-i+1)$，由「区间内最先被选为主元的元素」决定。
- 求和重排成调和数：$\mathbb{E}[X] = O(n \log n)$，这是随机化快排的期望运行时间。
- 期望与最坏的区别要分清；高概率界（切比雪夫）进一步保证「几乎总是快」。

在下一课，我们将正式进入**堆排序**的专题：先学习二叉堆这种优雅的数据结构——它在 $O(\log n)$ 内支持取最大元素，而建堆居然只要 $O(n)$。
