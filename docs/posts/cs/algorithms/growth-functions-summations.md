## 为什么需要一张增长速率地图

上一课我们有了精确的记号——$\Theta$ 告诉我们两个函数「同阶」，$O$ 告诉我们「不超过」。但记号本身不回答另一个更基本的问题：**$\lg n$、$\sqrt{n}$、$n$、$n\lg n$、$n^2$、$2^n$、$n!$，到底谁快谁慢？** 没有这张地图，记号只能告诉我们「同不同阶」，却指不出「谁是赢家」。

更实际的是，算法分析最终会落到一长串**求和**上：插入排序的 $\sum_{j=2}^n j$、归并排序递归展开后的 $\sum_k n$、快速排序平均情况里的调和级数。不会算这些和，很多复杂度结论就只能靠背。本课把「增长率比较」与「求和技巧」这两件工具一次配齐。

## 1 常客函数与它们的层级

CLRS §3.2 的标准函数有：**多项式**、**对数**、**指数**、**阶乘**，以及它们的组合。先记住主干顺序（$a>1$、$b>1$ 为常数）：

$$
1 \ \prec\ \lg\lg n \ \prec\ \lg n \ \prec\ \sqrt{n} \ \prec\ n \ \prec\ n\lg n \ \prec\ n^2 \ \prec\ n^3 \ \prec\ 2^n \ \prec\ n! \ \prec\ n^n
$$

这里的「$\prec$」读作「渐进慢于」，即左边的函数是右边函数的 $o$。有三条「断裂」值得单独标注：<span class="marginnote">$n\lg n$ 夹在 $n$ 与 $n^2$ 之间，它正是比较排序的最优边界——第五篇《比较排序下界》会证明：任何基于比较的排序算法至少要做 $\Omega(n\lg n)$ 次比较，而 $\Theta(n\lg n)$ 的归并排序恰好达到。</span>

- 任何**对数**增长慢于任何**多项式**：$\lg^b n = o(n^a)$ 对任意 $a>0, b>0$。
- 任何**多项式**增长慢于任何**指数**：$n^a = o(2^n)$ 对任意固定 $a>0$。
- **阶乘**增长快于任何指数：$c^n = o(n!)$ 对任意固定 $c>0$；$n!$ 又慢于 $n^n$。

这些「任意」与「任何」是渐进比较的硬骨头——它们说明层级之间是**断裂**的：$n^{0.0001}$ 与 $2^n$ 之间隔着不可逾越的鸿沟。

## 2 用极限比较两个函数

光背顺序不够，遇到陌生函数还得会当场判断。**极限法**是一把万能尺：若极限

$$
\lim_{n\to\infty} \frac{f(n)}{g(n)} = 0,\quad +\infty,\quad c>0
$$

则分别有 $f = o(g)$、$f = \omega(g)$、$f = \Theta(g)$。（极限不存在时记号未必失效，但极限法是最好用的充分条件。）

计算极限常用两件工具：**洛必达法则**与**取对数**。

- **洛必达**：判断 $\lg n$ 与 $\sqrt{n}$，反复求导得 $\lim \frac{\lg n}{\sqrt{n}} = \lim \frac{(1/n)/\ln 2}{(1/2)n^{-1/2}} = \lim \frac{2}{\ln 2}\,\frac{1}{\sqrt{n}} = 0$，故 $\lg n = o(\sqrt{n})$。
- **取对数**：比较 $n^{\lg n}$ 与 $2^n$，两边取 $\lg$：$\lg(n^{\lg n}) = (\lg n)^2$，而 $\lg(2^n) = n$。因为 $(\lg n)^2 = o(n)$（对数慢于多项式），故 $n^{\lg n} = o(2^n)$。<span class="marginnote">取对数把「指数对指数」的难题降维成「对数对多项式」的简单比较——$n^{\lg n}$ 的对数是 $(\lg n)^2$，阶一下子降下来了。这是处理「幂指函数」的标准手法。</span>

**辨析｜易错点：** 不要靠「直觉」比 $n^{100}$ 与 $2^{\sqrt{n}}$。$n^{100}$ 的常数很大，但取对数后是 $100\lg n$，而 $2^{\sqrt{n}}$ 的对数是 $\sqrt{n}$；$\sqrt{n}$ 最终压过 $100\lg n$，所以 $n^{100} = o(2^{\sqrt{n}})$。**指数上哪怕只有根号，也终将战胜任何固定次多项式。**

## 3 三把求和扳手

算法的代价大多是一串和。三把最常用的扳手：

**① 算术级数（等差求和）**

$$
\sum_{k=1}^{n} k = \frac{n(n+1)}{2} = \Theta(n^2)
$$

这是插入排序最坏情况 $\sum_{j=2}^n j$ 的来源。低阶项 $n/2$ 与 $1/2$ 在渐进意义上都是灰尘。

**② 几何级数（等比求和）**

$$
\sum_{k=0}^{n} x^k = \frac{x^{n+1} - 1}{x - 1},\qquad x \neq 1
$$

两个极端行为：当 $x > 1$，和由**末项**主宰，$\sum_{k=0}^n x^k = \Theta(x^n)$；当 $0 < x < 1$，和由**首项**主宰，收敛到常数 $\frac{1}{1-x}$。<span class="marginnote">几何级数是「被末项或首项主宰」的典型：公比大于 1，增长爆炸在最后一格；公比小于 1，增长饱和在第一格。二分查找、二叉堆的代价摊还，处处是它的影子。</span>

**③ 调和级数**

$$
H_n = \sum_{k=1}^{n} \frac{1}{k} = \ln n + \Theta(1)
$$

$H_n$ 出奇地常见：快速排序平均情况、哈希表分析、二叉搜索树的期望高度都有它。它增长**极其缓慢**——$H_{10^6} \approx 14.4$——但它是无界的（发散），且与 $\ln n$ 只差一个常数。

## 4 公式解析：用积分近似 $H_n$

「$H_n = \ln n + \Theta(1)$」这个结论怎么来的？一个漂亮的工具叫**积分近似（integral approximation）**：对单调函数，和可以夹在两次积分之间。

因为 $f(x) = 1/x$ 在 $[1, \infty)$ 上单调递减，每个单位区间上「左端点值 ≥ 区间内函数值 ≥ 右端点值」：

- **下界**：对任意 $k$，在 $[k, k+1]$ 上 $1/x \le 1/k$，故 $\int_k^{k+1} \frac{dx}{x} \le \frac1k$；对 $k = 1..n$ 求和得 $\int_1^{n+1} \frac{dx}{x} \le H_n$，即 $\ln(n+1) \le H_n$。
- **上界**：在 $[k-1, k]$ 上 $1/x \ge 1/k$，故 $\frac1k \le \int_{k-1}^{k} \frac{dx}{x}$；对 $k = 2..n$ 求和并补上 $k=1$ 的项，得 $H_n \le 1 + \ln n$。

把两个界夹起来：

$$
\ln(n+1) \le H_n \le 1 + \ln n
$$

四步拆解：

- **第一步，为什么要单调**：只有单调递减，才能保证「小区间右端函数值 ≤ 左端值」，从而积分与求和可以互相夹逼。若函数振荡，这套夹逼立刻失效。
- **第二步，为什么是积分**：$\int dx/x = \ln x$ 是微积分基本功，它把「求和对数」翻译成「积分的对数」——求和难，积分容易。
- **第三步，夹逼的结论**：两侧都是 $\ln n + O(1)$，故 $H_n = \ln n + \Theta(1)$。更精细的欧拉-马歇罗尼版本是 $H_n = \ln n + \gamma + O(\tfrac1n)$，其中 $\gamma \approx 0.57721$。<span class="marginnote">欧拉常数 $\gamma$ 是数学里最神秘的数字之一：至今没人证明它是否无理数。在渐进分析里你只需知道它是「常数」——它和 $0.5$、$1$ 一样，都只是 $\Theta(1)$ 的不同写法。</span>
- **第四步，通用套路**：把「$\sum_{k=1}^n f(k)$」换成「$\int_1^n f(x)\,dx$」，对单调的 $f$ 总是只差常数——**积分近似法**以后在摊还分析、主定理的证明里会反复出现。

## 5 求和工具的首次实战

把三把扳手用到一个即将登场的算法上，提前感受威力。**归并排序**（下一篇的主角）把规模 $n$ 的问题拆成两个 $n/2$，代价函数是

$$
T(n) = 2T(n/2) + n
$$

逐层展开：第 $k$ 层有 $2^k$ 个子问题，每个代价 $n/2^k$，整层代价 $2^k \cdot n/2^k = n$。递归树共 $\lg n$ 层，于是

$$
T(n) = n \cdot \lg n = \Theta(n\lg n)
$$

这里用到的正是「每一层加起来都是同一个 $n$」的直觉——求和技巧不只是课本习题，它就是主定理（后面那一课）背后「展开 → 求和 → 读主导项」这台机器的零件。

## 6 小结

- 增长层级：$1 \prec \lg n \prec \sqrt{n} \prec n \prec n\lg n \prec n^2 \prec n^3 \prec 2^n \prec n! \prec n^n$；对数输给多项式、多项式输给指数、指数输给阶乘。
- 比较工具：**极限法** + 洛必达 + 取对数；指数上哪怕只有 $\sqrt{n}$，也终将战胜任何固定次多项式。
- 三把求和扳手：**算术** $\sum k = \Theta(n^2)$、**几何** $x>1$ 时 $\Theta(x^n)$ / $x<1$ 时 $\Theta(1)$、**调和** $H_n = \ln n + \Theta(1)$。
- **积分近似**：对单调函数，和与积分只差常数；$H_n$ 的界正是这样夹出来的。

在下一节，我们带着这两件工具进入**第二篇：分治与递归**——用归并排序看分治范式如何把 $O(n^2)$ 的排序压到 $O(n\lg n)$，以及如何用递归树解出 $T(n) = 2T(n/2) + n$ 这类式子。
