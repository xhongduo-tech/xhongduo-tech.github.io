## 为什么从「证明」开始

上一课我们从划分质量的角度理解了快排「平均好」；但「平均好」需要一个**无可辩驳的严格证明**，而不是直觉。随机化快排的期望时间 $O(n \log n)$ 的证明，是 CLRS 全书的经典篇章——它把「随机算法的时间」翻译成「若干随机变量的期望之和」，再用积分与调和数算出结果。<span class="marginnote">这一证明的价值远超快排本身：它示范了「用指示器随机变量把算法运行时间变成概率问题」这一通用技术。后续球与箱子、生日悖论、哈希表分析全都是同一招。学会它，等于学会了随机算法分析的一半。</span>

与第三篇的「期望时间分析」侧重概念不同，本篇专注**证明的技术细节**：如何建立递归式、如何用积分近似求和解、如何给方差一个上界。

## 1 随机变量建模：比较次数即运行时间

沿用互异元素 $z_1 < z_2 < \cdots < z_n$ 的设定。快排的每次比较都发生在 PARTITION 内部，而**任意两个元素在整个算法中至多被比较一次**——一旦它们被某个主元分到两侧，就永远不再相遇。因此总比较次数 $X$ 是运行时间的忠实代理。

定义指示器

$$X_{ij} = I\{z_i \text{ 与 } z_j \text{ 被比较}\},\qquad 1 \le i < j \le n$$

则 $X = \sum_{i=1}^{n-1} \sum_{j=i+1}^{n} X_{ij}$。由期望线性性，问题归结为 $\Pr[X_{ij}=1]$。

**关键引理（复习）**：设 $Z_{ij} = \{z_i, z_{i+1}, \dots, z_j\}$。$z_i$ 与 $z_j$ 被比较，当且仅当 $Z_{ij}$ 中第一个被选为主元的元素是 $z_i$ 或 $z_j$，因此

$$\Pr[X_{ij} = 1] = \frac{2}{j-i+1}$$

这个概率的推导完全依赖「随机主元」：$Z_{ij}$ 中每个元素成为「第一个主元」的概率相等。**若主元取固定位置（如末尾），这个对称性就失效了**——这正是随机化在证明中的关键作用。<span class="marginnote">对照：确定性快排无法给出这样的概率式，因为「第一个被选中的主元」不是随机变量。随机化把「对手能精确预测的主元序列」变成「均匀随机的序列」，概率论证才得以展开。</span>

## 2 建立期望的递归式

把指示器和代入：

$$\mathbb{E}[X] = \sum_{i=1}^{n-1}\sum_{j=i+1}^{n}\frac{2}{j-i+1}$$

换元 $k = j - i + 1$。对固定的 $k$（$2 \le k \le n$），满足 $j - i + 1 = k$ 的 $(i,j)$ 对数为 $n - k + 1$。于是

$$\mathbb{E}[X] = \sum_{k=2}^{n}\frac{2}{k}\cdot (n - k + 1) \le \sum_{k=2}^{n}\frac{2n}{k} = 2n\left(\sum_{k=1}^{n}\frac{1}{k} - 1\right) = 2n(H_n - 1)$$

其中 $H_n = \sum_{k=1}^n 1/k$ 是调和数。<span class="marginnote">这个「按间隔 $k$ 重排求和」是证明中最巧妙的一步：内层 $j$ 的求和本来是二维的，换元后变成一维的调和数求和。二维结构 → 一维级数，期望分析里常见的手法。</span>

## 3 公式解析：调和数为什么等于 $\ln n + \Theta(1)$

我们用积分近似严格证明 $H_n = \ln n + O(1)$。核心是**把求和夹在两个积分之间**：

$$\int_1^{n} \frac{1}{x}\,dx \le \sum_{k=1}^{n}\frac{1}{k} \le 1 + \int_1^{n} \frac{1}{x}\,dx$$

对这条式子做三步拆解：

- **第一步，看下界**：$\frac{1}{k} \ge \int_k^{k+1}\frac{1}{x}dx$（因为 $\frac{1}{x}$ 在 $[k, k+1]$ 上递减，其值 $\ge \frac{1}{k+1}$，等等——严格说法是 $1/k \ge \int_k^{k+1} dx/x$ 因为被积函数在区间内 $\le 1/k$）。求和得 $\sum_{k=1}^n 1/k \ge \int_1^{n+1} dx/x = \ln(n+1)$。
- **第二步，看上界**：$1/k \le \int_{k-1}^{k} dx/x$（被积函数在 $[k-1,k]$ 上 $\ge 1/k$）。第 1 项单独处理为 1，其余求和 $\le 1 + \ln n$。
- **第三步，夹逼**：$\ln(n+1) \le H_n \le 1 + \ln n$，两边同除以 $\ln n$ 后都趋于 1，故 $H_n = \Theta(\ln n)$。更精确地，$H_n = \ln n + \gamma + O(1/n)$，$\gamma \approx 0.577$ 是欧拉常数。

**结论**：$\mathbb{E}[X] \le 2n H_n = 2n\ln n + O(n) = \Theta(n\log n)$。<span class="marginnote">积分夹逼是「用微积分处理离散和」的标准工具。它不精确但够用——算法分析里我们只在乎 $\Theta$ 量级，而积分近似恰好给出量级。</span>

## 4 精确常数：期望其实是 $2n\ln n$

注意上界推导用了 $\le \sum 2n/k$，丢弃了 $-(k-1)/k$ 的负项，因此是**上界而非精确值**。CLRS 展示了另一种精确算法：把递归式写全

$$\mathbb{E}[X] = \sum_{k=2}^{n}\frac{2(n-k+1)}{k} = 2\sum_{k=2}^{n}\frac{n+1}{k} - 2\sum_{k=2}^{n}1 = 2(n+1)(H_n - 1) - 2(n-1)$$

化简得 $\mathbb{E}[X] = 2(n+1)H_n - 4n$，即

$$\mathbb{E}[X] = 2n\ln n + O(n)$$

**常数恰为 2**：期望比较次数约 $2n\ln n \approx 1.39 n \log_2 n$。<span class="marginnote">对比归并排序的精确比较次数 $\lceil n\log_2 n\rceil - 2^{\lceil\log_2 n\rceil} + 1$（约 $n\log_2 n$），快排的期望比较次数约 1.39 倍——常数略大，但快排的常数在工程上仍胜出，因为它的比较非常便宜（一次分区内连续访问，缓存友好）。</span>

**辨析｜易错点：** 期望比较次数是 $2n\ln n$ 并不意味着「运行时间就是比较次数 × 常数」。比较次数是运行时间的主导项，但交换、递归调用等也占常数比例。分析时把它当「比较次数代理」即可，不必苛求到每条指令。

## 5 方差不失控：切比雪夫补上「几乎总是」

期望好还不够，还需证明**方差不大**，否则「期望 $n\log n$」可能掩盖「常常 $n^2$」。CLRS 证明 $\operatorname{Var}[X] = O(n^2)$。由切比雪夫不等式：

$$\Pr\left[|X - \mathbb{E}[X]| \ge c\cdot n\log n\right] \le \frac{\operatorname{Var}[X]}{c^2 n^2 \log^2 n} = O\left(\frac{1}{\log^2 n}\right)$$

即随机化快排的运行时间**以高概率落在 $\Theta(n\log n)$ 附近**，退化为 $n^2$ 的概率被压到 $O(1/\log^2 n)$。<span class="marginnote">方差的推导：$\operatorname{Var}[X] = \sum \operatorname{Var}[X_{ij}] + 2\sum \operatorname{Cov}(X_{ij}, X_{kl})$。指示器间虽然不独立（区间重叠时耦合），但协方差上界仍可控，合计 $O(n^2)$。这是「期望线性性省事，方差必须算相关性」的典型示范。</span>

## 6 小结

- 运行时间建模为比较次数 $X = \sum X_{ij}$，利用**期望线性性**归约为单对元素概率。
- **关键概率** $\Pr[X_{ij}=1] = 2/(j-i+1)$，依赖「$Z_{ij}$ 中第一个主元均匀随机」。
- 换元 $k = j-i+1$ 把二维求和化为一维**调和数**求和：$\mathbb{E}[X] \le 2n(H_n-1)$。
- **积分夹逼**证明 $H_n = \ln n + O(1)$，从而 $\mathbb{E}[X] = \Theta(n\log n)$，精确常数 $2n\ln n$。
- **方差界** $\operatorname{Var}[X] = O(n^2)$ 配合切比雪夫，保证运行时间「几乎总是」$\Theta(n\log n)$。

在下一课，我们离开理论证明，进入工程实践——**快速排序的优化**：三数取中、三向划分、小数组切换插入排序，让快排在真实数据上又快又稳。
