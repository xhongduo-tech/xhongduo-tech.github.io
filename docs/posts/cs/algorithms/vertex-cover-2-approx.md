## 为什么从顶点覆盖 2-近似开始

顶点覆盖在第十一篇被证明是 NPC；但这一课告诉我们：**虽然找不到精确多项式算法，但找到一个「保证不比最优差两倍」的多项式算法却很简单**。<span class="marginnote">这则「简单到可疑」的算法（选未覆盖边的两个端点）是近似算法入门第一课：算法三行，证明也是三行。它的意义在于展示「近似比」不是纸面概念——一个平凡的贪心就能给出严格保证。理解它，就理解了「NPC ≠ 放弃」。</span>

这一课给算法、2-近似的完整证明，以及「为什么 2 是能拿到的（匹配下界）」。

## 1 算法：最大匹配驱动的覆盖

**APPROX-VERTEX-COVER**：

```
APPROX-VERTEX-COVER(G)
1  C = ∅
2  E' = G.E
3  while E' ≠ ∅
4      let (u, v) be an arbitrary edge of E'    // 任意选一条未覆盖边
5      C = C ∪ {u, v}                           // 两个端点都入覆盖
6      remove from E' every edge incident on u or v
7  return C
```

每次选一条**未覆盖边**，把两端点都加入覆盖，删除所有被它们覆盖的边——直到无边可删。<span class="marginnote">算法选择边时「任意」——任何选择都行，近似比都一样。这是因为证明只依赖「选出的边互不相交」这一结构事实，不依赖具体选哪条。这种「任意选择仍保证比值」的性质，让算法实现完全自由（队列、随机、贪心皆可）。</span>

**复杂度**：$O(V+E)$——扫描边并标记覆盖，线性时间。

## 2 2-近似的证明：匹配下界

设算法返回 $C$，最优顶点覆盖为 $C^*$。证明 $\frac{|C|}{|C^*|} \le 2$。

**关键观察**：算法在循环中选出的所有边 $(u,v)$ 构成集合 $M$，且**互不相交**（选了 $(u,v)$ 后删掉所有关联边，后续选的都是不关联的边）——$M$ 是图的**匹配**。

**第一步，$|C| = 2|M|$**：每选一条边加两个顶点，边互不相交所以顶点不重复。
**第二步，$|C^*| \ge |M|$**：最优覆盖必须覆盖 $M$ 中每条边（它们是图的边）；而 $M$ 的边互不相交，**一个顶点至多覆盖 $M$ 中的一条边**——要覆盖 $|M|$ 条边至少 $|M|$ 个顶点。
**第三步，相除**：$\frac{|C|}{|C^*|} \le \frac{2|M|}{|M|} = 2$。<span class="marginnote">「匹配大小是顶点覆盖的下界」这一事实是整个证明的支点：任意匹配的每条边都需要一个专属顶点，所以 $C^* \ge \text{匹配大小}$。算法构造的匹配 $M$ 恰好给出「算法解 = $2 \times$ 匹配下界」——比值 2 由此而来。这个「用匹配当下界」的技巧在近似算法里反复出现。</span>

## 3 公式解析：为什么「选两个端点」恰好是 2 倍

$$|C| = 2|M|, \qquad |C^*| \ge |M| \quad\Longrightarrow\quad \frac{|C|}{|C^*|} \le 2$$

- **第一步，算法侧**：每选一条未覆盖边，加两个端点——$|C|$ 恰为选边数的两倍。
- **第二步，最优侧**：最优覆盖至少匹配大小——每条匹配边「占」一个顶点。
- **第三步，比值**：$2|M| / |M| = 2$。**因子 2 来自「一条边两个端点」**——算法为每条匹配边付出 2 个顶点，而最优至少要 1 个。

**要点**：近似比的证明常常是「算法付出的 / 最优至少要付出的」。算法每单位「结构」付 2，最优付 1——比值就是 2。<span class="marginnote">严格说 2 是<strong>上界</strong>；真正的最坏比值可以更差吗？存在图（如完整二分图 $K_{n,n}$ 的变体）让近似算法恰好选到 2 倍——所以 2 是「紧」的（最坏情况下达到）。不过证明「紧性」需要构造坏例，通常比证明上界更难。</span>

## 4 顶点覆盖近似为什么「到此为止」

顶点覆盖有 2-近似，但**没有更好的**（除非 P=NP）：任何 $(2-\varepsilon)$-近似都会违反已知的下界结论。<span class="marginnote">「为什么卡在 2」有深刻原因：顶点覆盖与「唯一猜想（UGC）」相关——在特定猜想下，$(2-\varepsilon)$-近似是 NP-hard。这里点到为止即可：知道「2 是顶点覆盖的近似极限」就够了，它展示了近似理论里「每类问题有自己的近似阈值」。</span>

**辨析｜易错点：** 别把「2-近似」当成「通常输出 2 倍」——近似比是最坏保证，多数输入可能远好于 2 倍。**「近似比 2」= 「任何输入上解 ≤ 2× 最优」**，不是「解总是恰好 2 倍」。

## 5 数值算例：在一张具体的图上跑一遍

拿一条四顶点的路径图 $P_4$（顶点 1—2—3—4，边 $(1,2)、(2,3)、(3,4)$）试跑 APPROX-VERTEX-COVER：

- 若算法先选边 $(1,2)$：加入 $\{1,2\}$，删去 $(1,2)、(2,3)$；剩下边 $(3,4)$，再加入 $\{3,4\}$ 并删除。得 $C = \{1,2,3,4\}$，$|C| = 4$。
- 最优覆盖是 $\{2,3\}$（中间两个顶点就覆盖了全部三条边），$|C^*| = 2$。
- 比值 $4/2 = 2$——**恰好踩到上界**。路径图 $P_4$ 就是逼出 2 倍的坏例之一，证明这个近似比是「紧」的。

再看一个算法表现好得多的例子：三角形 $K_3$，三条边两两相连。最优覆盖是任意两个顶点（如 $\{1,2\}$），大小 2；算法选第一条边 $(1,2)$ 就覆盖了全部三条边，$C = \{1,2\}$，比值恰好 1。<span class="marginnote">两个算例合起来看：近似比 2 是<strong>最坏情况保证</strong>，不是典型行为。星图、稠密图、多数随机图上算法远优于 2 倍；只有刻意构造的路径式图才逼出最坏情况。理解「近似比是最坏承诺」比记住 2 这个数字更重要。</span>

| 图 | 算法输出 $|C|$ | 最优 $|C^*|$ | 比值 |
| --- | --- | --- | --- |
| 路径图 $P_4$ | 4 | 2 | 2（紧） |
| 三角形 $K_3$ | 2 | 2 | 1 |
| 星图 $K_{1,4}$（中心 0 连四叶） | 2 | 1 | 2 |

星图 $K_{1,4}$ 的推演：算法选边 $(0,1)$ 加入 $\{0,1\}$，中心 0 一入覆盖，所有边（都关联 0）全被删除，$C = \{0,1\}$ 大小 2；而最优只需中心 $\{0\}$，大小 1。这也是达到 2 倍的一例——**每条被选的边都让算法付出 2 个顶点，而匹配下界只保证最优至少 1 个**。

## 6 延伸与小结

- **延伸一：加权顶点覆盖**。顶点带权 $w(v)$ 时，「任选边两个端点」失效（两个重端点可能很贵）。标准的 2-近似改为**线性规划舍入**：解顶点覆盖的 LP 松弛，把取到 $\ge 1/2$ 的变量舍入为 1，仍保证 2-近似。这是「LP 对偶 + 舍入」在近似算法里的第一个经典课例。
- **延伸二：匹配的推广**。一般图最小边覆盖、顶点覆盖与最大匹配满足经典恒等式：无孤立点图上，**最小顶点覆盖 + 最大匹配 = 顶点数**（对二分图成立，Kőnig 定理）——这正是「匹配下界」的正式化。
- **对比 NPC 证明**：同一问题——第十一篇证它 NPC（无精确多项式），本课证它有 2-近似（多项式近似）——两者共存不矛盾，这正是近似算法存在的意义。

小结：

- **算法**：反复选未覆盖边，两端点入覆盖，删关联边——$O(V+E)$。
- **证明**：选出的边是匹配 $M$；$|C| = 2|M|$、$|C^*| \ge |M|$ ⟹ 比值 ≤ 2。
- **2 是紧的**：路径图 $P_4$、星图 $K_{1,4}$ 都是坏例；$(2-\varepsilon)$-近似在特定猜想下不可能。
- 近似比的证明套路：算法付出 / 最优下界（此处是匹配）。
- 顶点覆盖是「NPC 证明 + 2-近似」双主角，贯穿第十一篇与第十二篇。
- 加权版本的进阶武器是 LP 舍入——后续 Set Cover、MAX-SAT 的近似都离不开它。


**速查表**：

| 概念 | 含义 |
| --- | --- |
| 匹配（matching） | 两两不相邻的边集；匹配大小是顶点覆盖的下界 |
| 紧性（tightness） | 存在坏例让近似比恰好达到上界 |
| UGC 关联 | 特定猜想下 $(2-\varepsilon)$-近似是 NP-hard |
| LP 舍入 | 加权顶点覆盖的 2-近似：解 LP 松弛再舍入 |

**辨析｜易错点：** 「2-近似」不等于「输出总为最优的 2 倍」——它是最坏情况保证。多数输入（星图、稠密图）上算法远优于 2 倍；只有刻意构造的图才逼出最坏。判断近似算法好坏看最坏比值，不看典型表现。

**数值快照**：$P_4$ 路径图算法输出 4、最优 2，比值恰 2（紧）；$K_3$ 三角形算法输出恰为最优、比值 1——同一个算法在不同图上表现天差地别。


**延伸｜更多 2-近似**：加权顶点覆盖的 LP 舍入、最小割的「贪心对偶」都给出 2；而 Set Cover 只能 $\\ln n$、TSP 无常数近似——**近似比上限由问题结构决定**。理解顶点覆盖「为什么能到 2」，就理解了「匹配下界」这类「最优解的下界」在近似证明里的支点作用。


- 记忆锚点：「匹配大小 ≤ 任意顶点覆盖」一句话同时给出下界与 2-近似的构造。
