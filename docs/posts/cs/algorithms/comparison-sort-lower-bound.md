# 比较排序下界：决策树模型与 Ω(n log n) 证明

## 为什么从下界开始

前三篇的排序算法都在比「谁更快」：插入排序 $O(n^2)$、归并排序 $O(n\log n)$、快排期望 $O(n\log n)$。一个自然的问题悬而未决：**比较排序能不能比 $n\log n$ 更快？** 这一课给出否定的回答——不是「还没人想到更快的」，而是 **$\Omega(n\log n)$ 是信息论意义上的铁律**。<span class="marginnote">这个结论意义重大：它划清了「基于比较的排序」的能力边界。但注意定语——「比较排序」。下一课我们将看到，一旦允许对元素做算术（计数、基数、桶），线性时间排序就成为可能。下界只对「靠比较获取信息」的算法成立。</span>

证明工具是**决策树（decision tree）**——把任何比较排序算法抽象成一颗二叉决策树，然后用「叶子数 ≥ 排列数」与「树高 ≥ 叶子数对数」两步推出下界。

## 1 决策树模型：算法即二叉树

任何**比较排序**算法都可以抽象为一棵决策树：

每个**内部节点**是一次比较（如「$a_i \le a_j$ 吗？」），它的两个分支对应两种比较结果。
每条从根到叶的路径对应算法对某个输入的一次完整执行。
每个**叶子**对应一种输入可能得到的最终排列（排序结果）。

关键观察：一个有 $n$ 个元素的输入，其正确排序结果**共有 $n!$ 种可能**（$n$ 个互异元素的全排列）。算法要能正确排序任意输入，决策树**至少要有 $n!$ 个叶子**——否则两个不同的排列会落在同一个叶子上，算法无法区分它们。<span class="marginnote">「叶子数 ≥ $n!$」来自一个朴素但决定性的事实：如果 $n!$ 个排列中有两个走到同一个叶子，那算法在这两种输入上产生相同输出，必然至少错一个。正确性要求「每个排列各占一个叶子」。</span>

例如 $n = 3$ 时 $n! = 6$，任何比较排序的决策树至少要 6 片叶子；一个 3 元素的比较排序决策树高度至少是 $\lceil \lg 6 \rceil = 3$。

## 2 从叶子数到树高：信息量论证

二叉树的高度与叶子数之间有一个硬约束：**高度为 $h$ 的二叉树至多有 $2^h$ 片叶子**。因此叶子数 $n!$ 要求

$$2^h \ge n! \quad\Longrightarrow\quad h \ge \lg(n!)$$

而算法的运行时间（在最坏情况下）**至少与决策树的高度成正比**——最坏输入要走过最长的那条路径。于是

$$T(n) \ge h \ge \lg(n!) = \Theta(n\log n)$$

最后一个等号用斯特林近似：$\lg(n!) = n\lg n - n\lg e + O(\lg n) = \Theta(n\lg n)$。<span class="marginnote">斯特林公式 $n! \sim \sqrt{2\pi n}(n/e)^n$ 告诉我们 $n!$ 不仅大，而且「以 $n/e$ 的 $n$ 次幂」增长。取对数后 $n\log n$ 项就跳出来了——这是「排列数爆炸」最常用的量化表达。</span>

## 3 公式解析：斯特林近似如何给出 $n\log n$

展开 $\lg(n!)$：

$$\lg(n!) = \lg\left(\sqrt{2\pi n}\left(\frac{n}{e}\right)^n\right) = \frac{1}{2}\lg(2\pi n) + n\lg n - n\lg e = n\lg n - O(n)$$

三步拆解：

- **第一步，代入斯特林**：$n! \approx \sqrt{2\pi n}\cdot (n/e)^n$。这是阶乘最著名的渐近式，误差相对值 $O(1/n)$。
- **第二步，取对数**：对乘积取对数变成求和：$\lg\sqrt{2\pi n} = O(\lg n)$，$\lg(n/e)^n = n(\lg n - \lg e)$。
- **第三步，看主项**：$n\lg n$ 是主项，$O(n)$ 与 $O(\lg n)$ 都是低阶——所以 $\lg(n!) = \Theta(n\log n)$。

**结论**：任何比较排序的最坏情况至少需要 $\Omega(n\log n)$ 次比较。<span class="marginnote">这个下界是「紧」的——归并排序与堆排序正好达到它。它回答了一个深刻问题：为什么归并排序无法通过常数优化突破 $n\log n$。答案：不是工程问题，是信息论问题。</span>

## 4 下界的边界与反例直觉

**辨析｜易错点：** 决策树下界只适用于**比较排序**。下面的「反直觉事实」容易造成混淆：

| 方法 | 是否比较 | 复杂度 | 前提 |
| --- | --- | --- | --- |
| 归并/堆/快排 | 只比较 | $\Omega(n\log n)$ | 无额外假设 |
| 计数排序 | 否（统计频次） | $O(n+k)$ | 元素是 $[0,k]$ 内整数 |
| 基数排序 | 否（按位） | $O(d(n+k))$ | 元素是 $d$ 位整数 |
| 桶排序 | 否（分配入桶） | 期望 $O(n)$ | 输入均匀分布 |

**比较排序的 $\Omega(n\log n)$ 不适用于上述「非比较」算法**——它们利用元素值的额外结构（整数范围、位数、分布）来绕过「仅靠比较获取信息」的限制。<span class="marginnote">这揭示了算法设计的一条主线：<strong>信息的获取方式决定能力边界</strong>。只靠「大小比较」只能获取全序信息，区分 $n!$ 个排列需要 $\lg(n!) \approx n\log n$ 比特信息；允许算术运算后，信息渠道变宽，下界随之消失。</span>

另一个边界：**平均情况**下界同样是 $\Omega(n\log n)$——对所有叶子深度求和求平均，由凸性可得平均高度也 ≥ $\lg(n!)$。所以「平均比最坏快」在比较排序里也是奢望（顶多常数）。

## 5 小结

- **决策树模型**：比较排序 = 二叉树，内部节点是比较，叶子是结果排列。
- **叶子数下界**：正确性要求叶子数 ≥ $n!$（每个排列至少一个叶子）。
- **树高下界**：高度 $h$ 的二叉树至多 $2^h$ 叶子，故 $h \ge \lg(n!)$。
- **斯特林近似**：$\lg(n!) = \Theta(n\log n)$，从而最坏与平均都比较排序的 $\Omega(n\log n)$ 下界。
- 下界**只对比较排序成立**——计数/基数/桶排序借元素值的额外结构突破它。

在下一课，我们第一次见到**不靠比较的排序**——计数排序：当元素是 $[0,k]$ 内的整数时，如何用频次统计做到 $O(n+k)$，以及「稳定」这个性质为何如此关键。
