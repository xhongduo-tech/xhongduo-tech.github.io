## 为什么从欧几里得算法开始

RSA、Diffie-Hellman、ElGamal——现代密码学的一切都建立在初等数论上，而初等数论的第一块砖是**最大公约数（GCD）**。**欧几里得算法**以「辗转相除」求 GCD，是全世界最古老的算法，也是「递归优雅性」的终极典范。<span class="marginnote">《几何原本》第七卷记载的算法至今未被超越：$O(\log n)$ 的极致效率。这一课的数论概念（整除、素数、同余）不仅是《数论》专题（第二级）的衔接，也是后面扩展欧几里得、RSA、Miller-Rabin 的全部基础。学数论算法，等于给密码学打地基。</span>

这一课建立整除与 GCD 的概念、欧几里得算法及其复杂度证明。

## 1 整除性与基本概念

**整除（divisibility）**：$a | b$（$a$ 整除 $b$）当且仅当存在整数 $k$ 使 $b = ak$。

**素数（prime）**：大于 1 且只有 1 与自己两个正因数的整数。**合数**：非素数的大于 1 的整数。

**基本性质**（CLRS 引理 31.1）：

若 $a | b$ 且 $a | c$，则 $a | (b + c)$；
若 $a | b$，则 $a | bc$（对任意整数 $c$）；
若 $a | b$ 且 $b | c$，则 $a | c$（传递性）。

**算术基本定理**：每个大于 1 的整数可唯一分解为素数的乘积（不考虑顺序）。<span class="marginnote">算术基本定理是数论的分水岭：素数是最小的「积木」，一切整数由它们唯一拼成。它也是后面「素性测试」「因子分解」问题的动机——知道「必须分解」和「分解很难」之间的张力，正是密码学安全的来源。与第二级《数论》专题的整除性章节衔接。</span>

**辨析｜易错点：** 整除符号的方向别写反——$a | b$ 读作「$a$ 整除 $b$」，即「$b$ 是 $a$ 的倍数」。$2 | 6$ 成立、$6 | 2$ 不成立。与分数符号 $a / b$ 的方向正好相反，初学时极容易混。

**辨析｜易错点：** 「$a | b$」里的 $a$ 可以是 0 吗？$0 | b$ 当且仅当 $b = 0$（因为需 $b = 0 \cdot k$）。通常讨论都默认 $a \neq 0$——零整除是退化情形，别在正式证明里用「$0 | b$」当一般事实。CLRS 的 $\gcd$ 递归正是靠「$b = 0$ 终止」避开这一点。

## 2 数值算例：手算几个 GCD

用几组数练熟「辗转相除」的过程。

- $\gcd(30, 21)$：$30 \bmod 21 = 9$，$21 \bmod 9 = 3$，$9 \bmod 3 = 0$ → $\gcd = 3$。
- $\gcd(17, 5)$：$17 \bmod 5 = 2$，$5 \bmod 2 = 1$，$2 \bmod 1 = 0$ → $\gcd = 1$（互素）。
- $\gcd(100, 64)$：$100 \bmod 64 = 36$，$64 \bmod 36 = 28$，$36 \bmod 28 = 8$，$28 \bmod 8 = 4$，$8 \bmod 4 = 0$ → $\gcd = 4$。

**观察**：每一步 $b$ 都换成一个比它小的 $a \bmod b$，数字迅速收缩——这就是「递归次数 $O(\log n)$」的直觉来源。<span class="marginnote">对比「逐个试因数」：求 $\gcd(100, 64)$ 要试 1, 2, 4, ... 直到 4，大约 $\sqrt{\min}$ 次；辗转相除只用了 5 步。数字越大差距越明显——$10^{300}$ 量级的密码学数字，试除法完全不可行，辗转相除几十步完成。这就是「用结构而非穷举」的力量。</span>

## 3 最大公约数与欧几里得算法

**最大公约数（greatest common divisor）** $\gcd(a,b)$：同时整除 $a$ 与 $b$ 的最大正整数。约定 $\gcd(0, 0) = 0$、$\gcd(0, b) = |b|$。

**欧几里得算法（Euclidean algorithm）**：

$$\gcd(a, b) = \gcd(b, a \bmod b), \qquad \text{递归直到 } b = 0$$

```text
EUCLID(a, b):
    if b = 0:
        return a
    else:
        return EUCLID(b, a mod b)
```

**正确性**：由「$a \bmod b = a - \lfloor a/b \rfloor b$」，$\gcd(a,b) = \gcd(b, a \bmod b)$（任何同时整除 $a, b$ 的数也整除 $a - qb$，反之亦然）——公约数集合不变，故最大公约数不变。<span class="marginnote">「$a \bmod b$ 让数字迅速变小」是算法收敛的原因：$b$ 换成 $a \bmod b < b$，规模单调下降直到 0。这个「余数替换」比「逐个试因数」快得多——它是「用结构而非穷举」的古老证明。例：$\gcd(30, 21)$：$30 \bmod 21 = 9$，$21 \bmod 9 = 3$，$9 \bmod 3 = 0$ → $\gcd = 3$。</span>

## 4 公式解析：复杂度 $O(\log n)$

**定理**：若 $a > b \ge 1$ 且 $b < F_{k+1}$（$F_k$ 是斐波那契数），则 EUCLID 的递归调用次数 $< k$。于是递归次数 ≤ $\log_\phi b$（$\phi$ = 黄金比例）。

$$T(n) = O(\log n)$$

- **第一步，最坏输入**：斐波那契对（如 $F_{k+1}, F_k$）——每次 $a \bmod b$ 恰好让「余数 = 更小的斐波那契数」，递归最慢。$F_k = \Theta(\phi^k)$。
- **第二步，次数对规模**：$F_k \approx \phi^k$，故递归 $k$ 次对应 $b \approx \phi^k$，$k = O(\log_\phi b) = O(\log b)$。
- **第三步，结论**：$O(\log b)$ 次取模运算——**指数级快于逐个试因数**。

**要点**：欧几里得算法的最坏情形是斐波那契数对——**「最坏输入」的刻画是分析优雅算法的关键**。$O(\log n)$ 让它能在超大数（密码学里的 $10^{300}$ 量级）上快速运行。<span class="marginnote">实践里「取模」对超大的数不是 $O(1)$——但数论算法通常按「算术运算次数」计（字长固定假设），工程实现用高精度整数库，每次取模是「大数除法」。分析习惯上仍按 $O(\log n)$ 次运算计，密码学应用里这个复杂度完全可行。</span>

**辨析｜易错点：** $\gcd(a, b)$ 与 $\gcd(b, a \bmod b)$ 的递归**不要求 $a > b$**——若 $a < b$，第一步自动交换（$a \bmod b = a$，递归变 $\gcd(b, a)$）。**别写错「谁取模谁」**：参数顺序是 $\gcd(b, a \bmod b)$，不是 $a > b$。

**数值对照**：把「最坏输入」与「普通输入」的递归步数摆在一起：

| 输入对 | 递归步数 | 步数上限 $\lceil \log_\phi b \rceil$ |
| --- | --- | --- |
| $\gcd(34, 21)$（斐波那契对 $F_9, F_8$） | 7 | $\log_{1.618} 21 \approx 6.3 \to 7$ |
| $\gcd(55, 34)$（$F_{10}, F_9$） | 8 | $\approx 7.6 \to 8$ |
| $\gcd(100, 64)$（第 2 节普通例） | 5 | $\approx 10$（上界宽松） |
| $\gcd(10^{300}, 3\times10^{300}-1)$（密码学规模） | 数十步 | 约 $O(\log 10^{300}) \approx 1400$ |

斐波那契对每步恰好「余数 = 下一个更小的斐波那契数」，递归最慢、且**精确达到** $\log_\phi b$ 的上界；普通输入远快于上界。<span class="marginnote">$10^{300}$ 量级是 RSA 素数的常见规模——试除法对这么大的数完全不可行，欧几里得算法却只需约 1400 次取模（每次大数除法）。「最坏输入被精确刻画 + 仍是对数复杂度」是它成为密码学地基的原因：<strong>对手找不到让它变慢的输入</strong>。</span>

## 5 从 GCD 到密码学

GCD 是「互素」判定的工具：$\gcd(a, b) = 1$ ⟺ $a, b$ **互素（coprime）**。互素是模运算里「可逆元」的存在条件——$a$ 在模 $m$ 下有乘法逆元 ⟺ $\gcd(a, m) = 1$。这正是 RSA 密钥生成（下一课）与扩展欧几里得（下下课）的支点。<span class="marginnote">「互素 ⟺ 有逆元」是模运算与密码学的核心桥梁：加密/解密需要「乘性逆元」，而逆元存在性由 GCD 判定。欧几里得算法不仅求 GCD，扩展版本（下一课）还能<strong>同时求出逆元</strong>——把「判定」升级成「求解」。这条线一路通向 RSA。</span>

## 6 常见疑问快速答疑

**问：$\gcd(0, 0)$ 为什么约定为 0？** 因为「同时整除 0 和 0 的最大正整数」是无穷大，没有意义。约定为 0 是为了让「欧几里得递归的终止情形」自洽：$b = 0$ 时返回 $a$，若 $a$ 也是 0 就返回 0。这个约定只影响边界，不影响正常输入。

**问：负数怎么办？** $\gcd$ 只定义在非负整数上，负数取其绝对值：$\gcd(-a, b) = \gcd(a, b)$。实现时先取绝对值再跑算法即可——公约数是正的概念，符号无关。

**问：除了辗转相除，还有别的 GCD 算法吗？** 有——Stein 算法（二进制 GCD）只用移位和减法，避开除法，在计算机上常数更小（尤其大数）；以及「扩展欧几里得」（下一课）除 GCD 外还求出贝祖系数。辗转相除最优雅、扩展版本最通用。

**问：GCD 和 LCM 的关系？** $\gcd(a,b) \times \text{lcm}(a,b) = |ab|$——知道 GCD 就能直接得最小公倍数。这个关系在分数通分、周期问题里常用；工程里常「先算 GCD 再导出 LCM」避免大数相乘。

**问：为什么数论算法在密码学里这么重要？** 因为现代公钥密码（RSA、DH、ECC）的安全性建立在「素数、大数运算、取模」上。数论算法提供「快速判定互素」「快速求逆元」「快速模幂」这些「正操作」——而「反向操作」（分解大整数）没有快速算法，这个不对称就是安全性的来源。

## 7 小结

- **整除与素数**：$a|b$ 的定义、整除性质、算术基本定理。
- **GCD**：最大公约数；欧几里得算法 $\gcd(a,b) = \gcd(b, a \bmod b)$。
- **复杂度** $O(\log n)$：斐波那契对是最坏输入，$k = O(\log_\phi b)$。
- 正确性靠「公约数集合不变」；递归天然处理 $a < b$。
- **互素** $\gcd=1$ ⟺ 模 $m$ 下有逆元——通往 RSA 与密码学的桥梁。
- 负数取绝对值、$\gcd(0,0)=0$、GCD × LCM = $|ab|$——边界与派生公式一表收齐。
- 逐次余数迅速收缩是收敛的直觉；斐波那契对是最坏情形的定量刻画。

在下一课，我们升级欧几里得——**扩展欧几里得算法**：不只求 GCD，还求出「贝祖系数」与模逆元，为线性同余方程与 RSA 提供计算工具。
