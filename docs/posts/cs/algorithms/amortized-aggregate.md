# 摊还分析导论：聚合分析（Aggregate Analysis）与栈操作

## 为什么从摊还分析开始

动态表（vector、ArrayList）偶尔要扩容拷贝整个数组——那一次操作很贵。但**平均到每一次插入**，代价只是 $O(1)$。**摊还分析（amortized analysis）**就是回答「一连串操作的总代价」的方法：不求单次最坏，而求**平均每次操作**的界。<span class="marginnote">摊还分析是「数据结构性能」的第一理论工具：哈希表的扩容、斐波那契堆、并查集、splay 树，全靠它分析。它与「平均情况分析」不同——摊还是不假设概率分布，而是「最坏情况下的一串操作总代价 / 操作次数」，这是确定性上界，不是期望。</span>

这一课从最简单的方法——**聚合分析（aggregate analysis）**开始，用栈操作与二进制计数器两个经典例子立住概念。

## 1 摊还分析三问

**摊还分析（amortized analysis）**：对 $n$ 次操作序列，分析**最坏总代价** $T(n)$，然后定义**每次操作的摊还代价**为 $T(n)/n$。它回答三个问题：

- **单次最坏**是多少？（可能很贵）
- **$n$ 次总代价**的上界是多少？
- **平均每次**（摊还代价）是多少？

注意：摊还代价是**确定性上界**——对任何 $n$ 次操作序列都成立，不是期望。<span class="marginnote">「摊还」一词来自会计：把一次性的大额支出（扩容）分摊到受益的多次小操作上。它保证的是「总额有限」，不是「每次都便宜」——单次仍可能贵，但贵的次数受控。</span>

## 2 聚合分析：先算总账再求平均

**聚合分析**的思路最朴素：直接算 $n$ 次操作的总代价 $T(n)$，摊还代价 = $T(n)/n$。它不区分操作类型，只关心总和。

### 例子：栈的多重操作

一个栈支持三种操作：

- `PUSH(x)`：压栈，代价 1；
- `POP()`：弹栈，代价 1；
- `MULTIPOP(k)`：连续弹出 $k$ 个元素，代价 $\min(k, \text{栈大小})$（若栈空则停）。

**单次最坏**：`MULTIPOP` 可一次弹出整个栈，$O(n)$。**但 $n$ 次操作总代价呢？** 关键观察：**每个元素被压入一次，至多被弹出一次**。所以「弹出」的总次数 ≤ 压入的总次数 ≤ $n$。于是 $n$ 次操作中所有 PUSH/POP/MULTIPOP 的总代价 ≤ $2n$。

$$T(n) = O(n) \quad\Longrightarrow\quad \text{摊还代价} = \frac{T(n)}{n} = O(1)$$

即使存在单个 $O(n)$ 的 MULTIPOP，平均每次操作仍是 $O(1)$。<span class="marginnote">聚合分析的精髓是「找全局守恒量」：这里栈里的元素总量就是守恒量——被压入一次、被弹出至多一次。「总弹出数 ≤ 总压入数」这一句话，就把看似随意的 MULTIPOP 代价牢牢钉住。找守恒量，是聚合分析的核心手艺。</span>

## 3 聚合分析的经典例子：二进制计数器

一个 $k$ 位二进制计数器，初始为 0，支持 `INCREMENT`（加 1）。每次加 1 会翻转若干位：从最低位开始，连续的 1 变 0，直到遇到 0 变 1。

**单次最坏**：从 `0111...11` 加 1 变成 `1000...00`，翻转 $k$ 位，$O(k)$。

**$n$ 次总代价**：数一数每一位翻转了多少次。

- 第 0 位（最低位）：每次 INCREMENT 都翻，$n$ 次；
- 第 1 位：每 2 次翻 1 次，$\lfloor n/2 \rfloor$ 次；
- 第 $i$ 位：每 $2^i$ 次翻 1 次，$\lfloor n/2^i \rfloor$ 次。

总翻转次数

$$T(n) = \sum_{i=0}^{k-1} \left\lfloor \frac{n}{2^i} \right\rfloor < n \sum_{i=0}^{\infty} \frac{1}{2^i} = 2n$$

故 $T(n) = O(n)$，**摊还代价 $O(1)$**。<span class="marginnote">每一位独立统计翻转次数，然后按位求和——这是聚合分析的另一种形态：「把总代价拆成若干独立部分的贡献之和」。第 $i$ 位的翻转频率按 $1/2^i$ 衰减，几何级数收敛到 2，所以总代价线性。</span>

## 4 公式解析：$T(n) = \sum \lfloor n/2^i \rfloor = O(n)$

以二进制计数器为例，拆解总代价公式：

$$T(n) = \sum_{i=0}^{\lfloor \lg n \rfloor} \left\lfloor \frac{n}{2^i} \right\rfloor \le n \sum_{i=0}^{\infty} \frac{1}{2^i} = 2n$$

- **第一步，按位分解**：第 $i$ 位（权值 $2^i$）在 $n$ 次加 1 中翻转的次数是 $\lfloor n/2^i \rfloor$——因为每 $2^i$ 次加 1 才进位到它一次。
- **第二步，放大为几何级数**：$\lfloor n/2^i \rfloor \le n/2^i$，求和 $\le n \sum 1/2^i$。
- **第三步，几何级数收敛**：$\sum_{i\ge 0} 1/2^i = 2$，故 $T(n) \le 2n = O(n)$，摊还 $O(1)$。

**要点**：聚合分析常常需要「把难直接算的总代价拆成可统计的独立贡献」。每位翻转次数是指数衰减的，总和被几何级数钉死——这是摊还分析里反复出现的求和模式。<span class="marginnote">对比直接思维：不看位、只盯「最坏单次」，会以为 $n$ 次操作是 $O(nk)$；聚合分析给出真正紧的 $O(n)$。它也预告了下一课核算法：给每个位「存一笔钱」，正好覆盖它未来可能的翻转。</span>

## 5 聚合分析的方法论与局限

**方法**：找「总代价的守恒表达式」或「可独立统计的贡献分解」——然后求总和的紧上界。

**局限**：聚合分析给出**总代价界**，但不区分「哪种操作摊还多少」。它无法回答「PUSH 摊还多少、MULTIPOP 摊还多少」——如果需要**每类操作的摊还代价**（比如给不同操作配不同预算），就要用核算法（下一课）。<span class="marginnote">聚合分析与核算法/势能法的关系：聚合只看「总和」，核算法与势能法「给每个操作分配一个摊还代价」从而能分类型地分析。三种方法殊途同归——得到同一组摊还界，但适用场景和直觉各有不同。</span>

**辨析｜易错点：** 摊还界 ≠ 平均情况。摊还是对**任何**操作序列的最坏总代价做平均，不涉及概率；平均情况分析则假设输入服从某分布。**「摊还 $O(1)$」的意思是「无论序列多坏，$n$ 次总代价 $O(n)$」**——它比「平均 $O(1)$」强得多，也比「单次最坏 $O(1)$」弱。

## 6 小结

- **摊还分析**：$n$ 次操作最坏总代价 $T(n)$，摊还代价 $= T(n)/n$；确定性上界，非期望。
- **聚合分析**：直接算总代价再平均，靠「守恒量」或「贡献分解」。
- **栈 MULTIPOP**：每元素至多压一次、弹一次，总代价 $O(n)$，摊还 $O(1)$。
- **二进制计数器**：第 $i$ 位翻转 $\lfloor n/2^i\rfloor$ 次，几何级数 $\sum 1/2^i = 2$，摊还 $O(1)$。
- 局限：聚合只给总界，不给「每类操作的摊还代价」——那是核算法的任务。

在下一课，我们给操作「存钱」——**核算法**：为每个操作分配一个摊还代价，用「信用」解释为什么二进制计数器平均便宜。
