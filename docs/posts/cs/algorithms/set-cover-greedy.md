## 为什么从集合覆盖开始

监控摄像头覆盖所有路口、选址使每个居民点都有服务、测试用例覆盖所有分支——**集合覆盖**是这些问题的抽象：给定全集 $U$（$n$ 个元素）与若干子集（各带代价），选代价最小的子集族覆盖所有元素。<span class="marginnote">集合覆盖是「覆盖类」问题的代表，也是近似算法里第一个<strong>对数近似比</strong>的经典案例：贪心算法的比值是 $\ln n$——比常数差、但比「无界」好得多。更重要的是：$\ln n$ 是<strong>紧</strong>的（除非 P=NP，没有 $(1-\varepsilon)\ln n$ 近似）——它展示了一类「近似比随输入规模增长」的问题。</span>

这一课讲贪心算法、$\ln n$ 近似比的证明（摊还分析风格）、以及「为什么对数是最优」。

集合覆盖还承担着承上启下的角色：在第十一篇我们见到「问题多难」（NPC），在上一课见到「常数近似」（顶点覆盖 2-近似），这一课则是「近似比会随规模增长」的第一例。**近似比不是常数而是一个函数**——这个观念的转变，为下一课的 FPTAS（用 $1/\varepsilon$ 换任意精度）埋下伏笔：常数近似、对数近似、任意精度近似，构成了近似算法的一整条谱系。学集合覆盖，就是给这条谱系画上「对数」这一格。

## 1 贪心算法：性价比最高的子集

**SET-COVER 贪心**：每次选「性价比最高」的子集——每覆盖一个元素代价最小的那个。

```text
GREEDY-SET-COVER(U, ℱ):
    U′ ← U                                // 尚未覆盖的元素
    C ← ∅                                 // 已选集合族
    while U′ ≠ ∅:
        选 S ∈ ℱ 使 |S ∩ U′| / cost(S) 最大   // 性价比最高的子集
        C ← C ∪ {S}
        U′ ← U′ ∖ S                       // 删除新覆盖的元素
    return C
```

每轮选「每元覆盖代价最小」的子集（未覆盖元素按性价比计），删掉它覆盖的元素，继续。<span class="marginnote">「性价比贪心」把问题从「选哪些集」变成「每轮选最划算的」——它不保证最优，但保证一个对数界的次优。注意性价比的分母是<strong>该子集的原始代价</strong>，分子是<strong>新覆盖的元素数</strong>（已覆盖的不算）——「新增覆盖」而非「总覆盖」才是收益。</span>

## 2 $\ln n$ 近似比证明：摊还计数

设最优覆盖用 $k$ 个集合（代价归一化为 1，即每个集合代价 1）。贪心每轮选「新增覆盖最多」的集合。

**关键论证**：设第 $j$ 轮贪心覆盖了 $c_j$ 个新元素。因为最优用 $k$ 个集合覆盖全部 $n$ 个元素，**在贪心第 $j$ 轮开始时**，剩余未覆盖元素 $R_j$ 一定能被最优的 $k$ 个集合覆盖——所以「每元平均覆盖」至少 $|R_j|/k$，即**存在某个集合至少新增覆盖 $|R_j|/k$ 个元素**。贪心选的是最大值，所以 $c_j \ge |R_j|/k$。于是

$$|R_{j+1}| \le |R_j| - \frac{|R_j|}{k} = |R_j|\left(1 - \frac{1}{k}\right)$$

递推得 $|R_j| \le n(1 - 1/k)^j \le n e^{-j/k}$。<span class="marginnote">「每轮至少覆盖剩余的 $1/k$」是证明的心脏：它把「贪心不比最优差太多」翻译成「剩余元素按 $(1-1/k)$ 收缩」。$1-1/k \le e^{-1/k}$ 是指数衰减的抓手——于是经过 $k \ln n$ 轮后剩余 $< 1$，贪心停止。</span>

要求 $|R_j| < 1$：$n e^{-j/k} < 1 \Rightarrow j > k\ln n$。故贪心在至多 $\lceil k\ln n \rceil$ 轮内覆盖全部。贪心使用的集合数 ≤ $k\ln n$，而最优用 $k$ 个：

$$\text{近似比} \le \ln n$$

## 3 公式解析：$n e^{-j/k}$ 从哪里来

$$|R_{j+1}| \le |R_j|\left(1 - \frac{1}{k}\right) \quad\Longrightarrow\quad |R_j| \le n\left(1-\frac{1}{k}\right)^j \le n e^{-j/k}$$

- **第一步，每轮收缩**：$|R_{j+1}| \le |R_j|(1 - 1/k)$——因为至少覆盖剩余 $1/k$。
- **第二步，迭代**：$j$ 轮后剩余 ≤ $n(1-1/k)^j$。
- **第三步，指数化**：$1 - 1/k \le e^{-1/k}$（$e^x \ge 1+x$ 的反向），故剩余 ≤ $n e^{-j/k}$。
- **第四步，解 $j$**：令 $n e^{-j/k} < 1$，得 $j > k\ln n$——贪心至多 $k\ln n$ 轮。

**要点**：近似比 $\ln n$ 由「$k\ln n$ 轮覆盖完」推出——**贪心集合数 ≤ 最优的 $\ln n$ 倍**。<span class="marginnote">对比 2-近似（顶点覆盖）：那里的比值是常数 2，因为「每单位结构的最优下界」是常数；集合覆盖的下界是「最优 $k$ 个集每轮最多保证 $1/k$」，对数自然出现。「下界的衰减速度」决定近似比的量级——常数衰减给常数比值，$1/k$ 衰减给对数比值。</span>

**辨析｜易错点：** 证明假设「每个集合代价为 1」。带不同代价时，性价比公式用 $|S \cap U| / cost(S)$，近似比不变（$\ln n$）——但证明的「存在某个集合新增 ≥ $|R_j|/k$」要换成「按代价归一化的平均」论证。**别把代价不同的情况直接套等代价证明**。

## 4 为什么 $\ln n$ 是紧的

**下界结论**：若 $P \ne NP$，则不存在 $(1-\varepsilon)\ln n$-近似算法（对任何 $\varepsilon > 0$）。集合覆盖的近似比**本质上是 $\ln n$**——不能再好。<span class="marginnote">这个下界由 Feige 1998 年证明（在 P≠NP 假设下）。直觉来源：集合覆盖能编码「3-SAT 变体」的难度，且这种编码使「更好于 $\ln n$」的近似会瓦解归约。它是「近似比下界」的教科书案例——证明一个近似算法<strong>不可能更好</strong>，与证明它「多好」同样重要。</span>

**实践含义**：集合覆盖类问题（设施选址、传感器覆盖）的贪心 $\ln n$ 是「理论上最优性价比」——工程上不必追求更好（不可能），只需实现贪心。

**为什么「证明不可能更好」如此重要**：近似算法研究有两个方向——「造出好算法」和「证明更好的不存在」。集合覆盖是后者的教科书：因为 $P \ne NP$ 下 $(1-\varepsilon)\ln n$-近似不可能，**工程上任何「改进集合覆盖近似」的尝试都是白费力气**，除非同时推翻 P≠NP。理解这一点，就能看懂为什么文献里集合覆盖的后续工作转向「特殊情形」（单位圆盘、亚模函数）而不是通用改进——**通用问题是封闭的，突破口都在加约束**。

## 5 数值算例：把贪心一轮一轮跑出来

教科书证明抽象，动手跑一遍才看得见「性价比」的计算过程。取 $U = \{1,2,\dots,8\}$，五个子集各带代价：

| 子集 | 元素 | 代价 |
| --- | --- | --- |
| $S_1$ | $\{1,2,3,4,5\}$ | 2 |
| $S_2$ | $\{5,6,7,8\}$ | 2 |
| $S_3$ | $\{1,2,6\}$ | 1 |
| $S_4$ | $\{3,4,7,8\}$ | 1 |
| $S_5$ | $\{2,5,8\}$ | 1 |

**第 1 轮**：$U' = U$，每个子集按「代价 / 覆盖元素数」比较：$S_1$ 为 $2/5 = 0.4$、$S_2$ 为 $0.5$、$S_3$ 为 $1/3 \approx 0.33$、$S_4$ 为 $0.25$、$S_5$ 为 $0.33$。**性价比最高是 $S_4$**（每元 0.25），选中。覆盖 $\{3,4,7,8\}$，剩余 $\{1,2,5,6\}$。

**第 2 轮**：分母换成「**新**覆盖数」。$S_3$ 新覆盖 $\{1,2,6\}$ 共 3 个、代价 1 → 每新元 0.33，胜出。覆盖后剩余 $\{5\}$。

**第 3 轮**：$S_2$ 新覆盖 $\{5\}$、代价 2 → 2.0；$S_5$ 新覆盖 $\{5\}$、代价 1 → 1.0。选 $S_5$。总代价 $1 + 1 + 1 = 3$。

**对照最优**：$S_1 \cup S_2$ 也覆盖全集，代价 $2 + 2 = 4$——贪心（3）反而更好。这个实例不能展示 $\ln n$ 的紧性（那需要精心构造的「阶梯」实例，见上节），但它把三件事演示清楚：**性价比要逐轮重算**、**已覆盖的元素不再计入收益**、**「先选便宜的」不等于「先选覆盖多的」**。<span class="marginnote">注意 $S_4$ 在第 1 轮胜出靠的是「覆盖多且便宜」，而 $S_3$ 第 2 轮胜出靠的是「剩下的活便宜」——<strong>贪心每一轮都在为「尚未覆盖的部分」定价</strong>。这正是它与「一次性按性价比排序选满」的区别。</span>

## 6 术语速查

| 术语 | 含义 | 一句话记忆 |
| --- | --- | --- |
| 集合覆盖 | 选最小代价子集族覆盖全集 | 摄像头覆盖问题 |
| 近似比 | 算法解 / 最优解的比值上界 | 最坏倍率 |
| 性价比 | 代价 / 新覆盖元素数 | 每元买到几个元素 |
| 剩余收缩 | 每轮剩余乘以 $(1 - 1/k)$ | 指数衰减的抓手 |
| 紧性 | 不存在更好的近似比（在 P≠NP 下） | 已到极限 |
| $e^{-1/k}$ | 用 $1 - x \le e^{-x}$ 放缩 | 把乘法变指数 |

**辨析｜易错点：** 集合覆盖与顶点覆盖的 2-近似看似相似，本质不同——顶点覆盖的「边」是离散结构，匹配下界给常数；集合覆盖的「元素覆盖」是连续累积，只能保证 $1/k$ 衰减。**别把「顶点覆盖 2-近似」的直觉套到集合覆盖上**；对数比值的出现不是技巧问题，而是问题结构使然。

## 7 小结

- **集合覆盖**：选代价最小的子集族覆盖全集；贪心每轮选「每元覆盖代价最小」的子集。
- **$\ln n$ 近似比**：每轮至少覆盖剩余的 $1/k$，剩余按 $n e^{-j/k}$ 指数收缩，至多 $k\ln n$ 轮。
- 证明三件套：剩余收缩 + 指数化（$1-1/k \le e^{-1/k}$）+ 解轮数。
- **$\ln n$ 是紧的**：$(1-\varepsilon)\ln n$-近似在 P≠NP 下不可能（Feige）。
- 常数衰减给常数比值、$1/k$ 衰减给对数比值——衰减速度决定近似比量级。

**数值快照**：$k$ 个子集、$n$ 个元素，第 $j$ 轮后剩余未覆盖元素至多 $n e^{-j/k}$。取 $n = 10^6$、$k = 1000$：$e^{-1} \approx 0.37$ 意味着每轮剩余乘 $0.37$，$6$ 轮后剩约 $10^6 \times 0.37^6 \approx 2500$ 个——指数收缩把「还剩多少」压得极快。但要「覆盖到零」，仍需 $k \ln n \approx 1000 \times 13.8 \approx 13800$ 轮的上界——这就是 $\ln n$ 近似比的直观来源。
