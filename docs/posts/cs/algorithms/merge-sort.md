## 为什么从归并排序开始

上一课我们证明了插入排序的正确性，代价却是 $\Theta(n^2)$：对一万个数要执行上亿次基本操作。输入规模翻一倍，时间要翻四倍——这条曲线在「从极限到大模型」的主线上是致命的，因为真实世界的输入规模从来只增不减。我们需要更快的排序。

**归并排序（merge sort）**就是答案：它把时间压到 $\Theta(n \lg n)$，而这已经逼近比较排序的理论极限（第五篇《比较排序下界》会证明 $n\lg n$ 就是天花板）。但本课的价值远不止「快了一点」：它是**分治范式（divide-and-conquer paradigm）**的第一次完整登场，也是全专题第一处冒出的**递归式（recurrence）**。从归并排序开始，分治三步骤、递归树、代入法、主定理——第二篇的整条主线都由它牵引。它还是冯·诺依曼在 1945 年提出的算法，是计算机科学史上最古老的排序算法之一。

## 1 分治范式：分解、解决、合并

**分治（divide-and-conquer）**是一种把问题拆小的通用策略，分三步走：

- **分解（divide）**：把原问题拆成若干规模更小、结构相同的子问题。
- **解决（conquer）**：递归地解决各子问题；子问题小到可直接求解（**基本情况**，base case）时就停止递归。
- **合并（combine）**：把各子问题的解拼回原问题的解。

<span class="marginnote">「分而治之」（divide et impera）原是古罗马的政治格言：把敌人拆散，再逐个击破。算法借用了同样的哲学——把一个难问题拆成几个好解的小问题，难度的来源（规模）被稀释了。</span>

三步里最容易被低估的是**合并**：分解和解决几乎是机械地递归，真正的智力往往藏在「把两半拼起来」这一步。归并排序的合并步骤值得单独写一节。

## 2 归并排序：两段有序的舞蹈

归并排序在数组上这样落地：把数组从中间劈成两半，分别排序，再把两个有序半段**合并**成一个有序整段。核心子程序是 MERGE，它假设子数组 $A[p..q]$ 与 $A[q+1..r]$ 都已有序，把两者归并进 $A[p..r]$：

```text
MERGE(A, p, q, r)                // 输入：A[p..q] 与 A[q+1..r] 均有序
n1 = q − p + 1
n2 = r − q
L[1..n1+1], R[1..n2+1] 为新数组     // 辅助数组，末尾各留一个哨兵位
for i = 1 to n1
    L[i] = A[p + i − 1]
for j = 1 to n2
    R[j] = A[q + j]
L[n1+1] = ∞
R[n2+1] = ∞
i = 1, j = 1
for k = p to r
    if L[i] ≤ R[j]
        A[k] = L[i]; i = i + 1
    else
        A[k] = R[j]; j = j + 1
```

这里的哨兵 $\infty$ 是 CLRS 的经典手法：把「一个数组先用完」的边界判断藏进哨兵里，循环体内就不必再写越界检查。MERGE-SORT 则是一棵递归的骨架：

```text
MERGE-SORT(A, p, r)
if p < r
    q = ⌊(p + r) / 2⌋
    MERGE-SORT(A, p, q)       // 排序左半
    MERGE-SORT(A, q + 1, r)   // 排序右半
    MERGE(A, p, q, r)         // 合并两个有序半段
```

整个排序只需一次顶层调用 MERGE-SORT(A, 1, A.length)。

**辨析｜易错点：** 三个细节初学者最容易栽跟头。其一，**边界划分**：左半是 $A[p..q]$、右半是 $A[q+1..r]$，$q$ 取 $\lfloor (p+r)/2 \rfloor$，两半不重不漏；写成 $A[p..q-1]$ 和 $A[q..r]$ 混用会漏元素或死递归。其二，**哨兵值必须保证「两半永不同时耗尽」**：这正是 $L[n_1+1]$、$R[n_2+1]$ 位置放 $\infty$ 的原因——若两边同时到哨兵，比较 $L[i] \le R[j]$ 仍会选左边，行为依然正确。其三，**归并必须从 $A[p]$ 写回 $A[r]$**，别把起始下标写成 1。

## 3 用循环不变式证明 MERGE 正确

插入排序那节课我们把循环不变式的三板斧练熟了，这里再抡一次（这次的舞台是 MERGE 的 for 循环）：

> **不变式**：每次迭代开始时，$A[p..k-1]$ 按非降序排列，且恰好包含 $L[1..n1+1]$ 与 $R[1..n2+1]$ 中前 $k-p$ 个最小的元素；$L[i]$ 与 $R[j]$ 分别是各自数组中尚未被复制回 $A$ 的最小元素。

- **初始化**：$k = p$ 时 $A[p..p-1]$ 为空，平凡有序；$L[1]$ 与 $R[1]$ 正是各自最小的未复制元素。✔
- **保持**：设迭代前不变式成立。若 $L[i] \le R[j]$，则 $L[i]$ 是两数组中未复制的全部元素里最小的，把它写入 $A[k]$ 后，$A[p..k]$ 有序且恰好是最小的 $k-p+1$ 个元素；$i$ 前进一位，下一轮不变式恢复。反之同理。✔
- **终止**：$k = r+1$ 时 $A[p..r]$ 按非降序含 $L$ 与 $R$ 的全部元素——而归并完成。✔

由 MERGE 正确、且两边递归调用 MERGE-SORT 各自正确，归纳可得 MERGE-SORT 对任意输入都正确。**正确性就这样被「一次证明、处处复用」**：我们为一块积木担保，整座塔就稳了。

## 4 公式解析：归并排序的递归式

MERGE-SORT 的运行时间写成关于输入规模 $n$ 的函数，就得到一个**递归式（recurrence）**——一个「用自身定义自身」的方程，这也是本专题第一种全新的数学对象：

$$
T(n) = \begin{cases} \Theta(1) & n = 1 \\[2mm] 2\,T(n/2) + \Theta(n) & n > 1 \end{cases}
$$

逐项拆解：

- **$T(n)$**：排序 $n$ 个元素所需的最坏时间，是我们要求解的对象。
- **$2T(n/2)$**：分解后得到两个规模各为 $n/2$ 的子数组，对每个子数组递归调用 MERGE-SORT。递归发生在两处，所以系数是 2；每个子问题规模减半，所以自变量是 $n/2$。
- **$+\Theta(n)$**：合并步骤 MERGE 的代价。把两段共 $n$ 个元素扫一遍，每次迭代确定一个最终位置，共 $n$ 次——线性时间。
- **基本情况 $T(1) = \Theta(1)$**：单元素数组已经有序，直接返回。

这条递归式是第二篇的「母题」：代入法、递归树、主定理三大求解工具都将围绕 $T(n) = 2T(n/2) + \Theta(n)$ 及其变体展开。先把直觉立住：**每个「合并」都花线性时间，而整个递归要做 $\lg n$ 层合并**，于是总量 $n \times \lg n$。

## 5 递归树：把递归式画成一棵树

光有直觉不够，我们用一个可视化工具把上面的直觉变成算式：**递归树（recursion tree）**。把递归式 $T(n) = 2T(n/2) + cn$（把 $\Theta(n)$ 具体写成 $cn$）展开成树——根节点是原始规模 $n$ 的代价 $cn$，它的两个孩子各是 $cn/2$，再往下每个节点 $cn/4$，直到叶子 $T(1) = \Theta(1)$：

![归并排序的递归树：每层总代价恒为 cn](/images/algorithms/merge-sort-recursion-tree.svg)

看图说话，把总代价算出来：

- **每层总代价恒为 $cn$**。第 $i$ 层有 $2^i$ 个节点，每个代价 $c\,(n/2^i)$，相乘得 $2^i \cdot c n / 2^i = cn$，与 $i$ 无关。
- **树高是 $\lg n + 1$**。从 $n$ 一路除以 2 到 1，共 $\lg n + 1$ 层（0 到 $\lg n$）。
- **总代价**：

$$
\sum_{i=0}^{\lg n} cn = cn(\lg n + 1) = \Theta(n \lg n)
$$

<span class="marginnote">严格说叶子层（第 $\lg n$ 层）有 $n$ 个 $T(1)$，合计 $\Theta(n)$；而 $cn(\lg n+1)$ 中的 $cn$ 项恰好吸收了这个 $\Theta(n)$，不影响渐近结果——这是递归树分析里常见的「一个常数项被吃掉」的小把戏。</span>

于是归并排序的运行时间是 $\Theta(n\lg n)$。注意**我们还没有严格证明**：递归树是「先求猜测」的手段，它假设了 $n$ 是 2 的幂、忽略了取整、还默认所有叶子在同一层。严谨的证明要交给下一课——代入法。这一课先享受视觉直觉带来的确定性。

## 6 递归树分析的两个边界

递归树好用，但有两个边界必须点破。

**辨析｜易错点：** 其一，**$n$ 未必是 2 的幂**。真实输入任意长，递归式实际是 $T(n) = 2T(\lfloor n/2 \rfloor) + \Theta(n)$，带取整符号。可以证明（CLRS 的惯例）取整至多改变常数因子，**渐近结论不变**——但这一步要单独说，不能一笔带过。其二，**递归树给出的是猜测，不是证明**。树画到「每一层都 $cn$」时，眼睛会替我们完成求和，可求和依赖「所有分支等高」这一理想化假设。严谨路线永远是：递归树猜 $\Theta(n\lg n)$，代入法验证。

这个「先猜后证」的两段式，是整个分治篇的固定节拍。理解了它，你就不会在考场里把递归树当证明交上去。

## 7 小结

- **分治范式**三步走：分解、解决、合并；归并排序是它的原型，**合并步骤**是智力所在。
- **MERGE** 用**哨兵 $\infty$** 简化边界；**MERGE-SORT** 递归两半再合并。
- **MERGE** 的正确性用**循环不变式**证明，归并排序的正确性由递归归纳建立。
- 归并排序的时间写成**递归式** $T(n) = 2T(n/2) + \Theta(n)$。
- **递归树**：每层代价恒为 $cn$，共 $\lg n+1$ 层，总和 $\Theta(n\lg n)$；它给出猜测而非证明。
- 递归树还将在外部排序的多路归并（第十七篇）与并行归并（第十六篇）里以更丰富的形式回归。

在下一节，我们把「先猜后证」里的**证**补齐——学会**代入法（substitution method）**：先猜解的形式，再用数学归纳法严格验证，并顺带解决 $T(n) = 2T(\lfloor n/2 \rfloor) + n$ 这类带取整的递归式。
