## 为什么从 vim 开始

在图形界面里编辑文件，人人都会；但当你 `ssh` 到一台没有图形界面的服务器上、半夜修复一份配置时，你手里几乎只剩一个选择：**vim**。它预装在几乎所有 Linux 发行版里，是运维与开发共用的最低公分母。vim 最让新手崩溃的是「**模式**」：同样的按键在普通模式下是命令、在插入模式下是文字。一旦理解模式，vim 的每一次击键都从「打字」变成「指挥」——这正是它与现代编辑器最本质的差别，也解释了为什么老手在 vim 里改文件比鼠标还快。

## 1 模式：vim 的第一性原理

**vim 是一个模式化编辑器（modal editor）**：同一批按键在不同模式下含义完全不同。三个核心模式：

**普通模式（Normal）**：启动后默认所在。此时按键是**命令**而非文字：`h`/`j`/`k`/`l` 移动光标，`dd` 删行，`yy` 复制行，`u` 撤销。不进入插入模式就永远打不了字，这是新手第一道坎。

**插入模式（Insert）**：按 `i` 进入，此时和普通编辑器一样输入文字。按 `Esc` 回到普通模式。

**命令模式（Command-line）**：普通模式下按 `:` 进入，屏幕底部出现命令行，用于保存、退出、搜索替换等整条操作：`:w` 保存、`:q` 退出、`:wq` 保存并退出。

**核心对比表：三种模式怎么切**

| 模式 | 进入方式 | 按键含义 | 退出方式 |
| --- | --- | --- | --- |
| 普通模式 | 启动默认 / 按 `Esc` | 命令与移动 | 按 `:` 或 `i` 等 |
| 插入模式 | 按 `i`/`a`/`o` | 输入文字 | 按 `Esc` |
| 命令模式 | 普通模式下按 `:` | 文件级操作 | 回车执行 / `Esc` 取消 |

<span class="marginnote">`i` 在光标<strong>前</strong>插入，`a` 在光标<strong>后</strong>插入，`o` 在下方<strong>新建一行</strong>再插入，`O` 在上方新建一行。这几个进入插入模式的姿势是最高频的肌肉记忆。</span>

**易错点**：不知道自己在哪个模式是新手最痛的体验——按了 `i` 以为打不出字，或者按 `Esc` 结果退出了整个文件。记住一个口诀：**「Esc 永远回家」**，按 `Esc` 一定会回到普通模式，`dd` 试一下、能删行就是普通模式，能打字母就是插入模式。

## 2 移动与编辑：普通模式的操作语

vim 普通模式的效率秘密是**「动词 + 目标」**的组合语法。移动光标的原子操作：

```text
h j k l     左 下 上 右（不必用方向键）
w / b       按单词前进 / 后退
0 / $       行首 / 行尾
gg / G      文件开头 / 文件末尾
:n          跳到第 n 行
ctrl-d / u  向下 / 向上翻半屏
```

编辑操作同样组合：**`d`（删除）+ 移动目标 = 删除到那里**。

```text
dd          删除当前行
dw          删除到下一个单词开头
d$          删除到行尾
yy          复制当前行
p           粘贴到光标下方
u           undo 撤销
ctrl-r      redo 重做
```

<span class="marginnote">把 `d` 看成「动词」、把移动命令看成「宾语」，`d2w` 就是「删两个单词」、`3dd` 就是「删三行」。这个「次数 + 动词 + 目标」的语法是 vim 区别于一切普通编辑器的核心，花十分钟刻意练它，回报远超十分钟。</span>

**易错点**：普通模式下按字母就是命令，所以**不要用方向键**——方向键可用但打断流畅度。想要文本选择，进入**可视模式（Visual）**：按 `v` 进入字符选择、`V` 进入行选择、`ctrl-v` 进入列选择，配合移动命令选中后再按 `y`（复制）或 `d`（删除）。

## 3 查找与替换：从命令行走向文件深处

**`/关键字`** 在普通模式下向后搜索，按 `n` 跳到下一个匹配、`N` 回上一个。搜索匹配到的单词时，光标停在词上按 `*` 可直接跳转到下一个相同单词——阅读日志、对齐代码时极高频。

**替换**是命令模式的经典操作，语法是：

```bash
:范围s/旧/新/标志
```

四个最常见用法：

```text
:s/foo/bar/          替换当前行第一个 foo
:s/foo/bar/g         替换当前行所有 foo
:%s/foo/bar/g        替换整个文件所有 foo
:%s/foo/bar/gc       替换前逐个确认（安全）
```

**公式解析：替换命令的三个部分**

$$
:s / \text{pattern} / \text{replacement} / g
$$

- **第一部分 `:%s`**：冒号进入命令模式，`%` 表示「整个文件」（等价于 `1,$`，即第一行到最后一行），`s` 是 substitute（替换）。
- **第二部分 `/pattern/replacement`**：把每个 pattern 换成 replacement，pattern 支持正则表达式。
- **第三部分 `/g`**：global 标志，替换**每行所有**匹配；不带 `g` 只替换每行第一个。

**易错点**：替换内容是正则表达式时，`/` 会被当作分隔符。要替换 URL 或路径这类含 `/` 的文本，改用 `#` 或 `+` 做分隔符：`:s#/usr/bin#/usr/local/bin#g`。<span class="marginnote">vim 的 `:s` 与 `sed` 的 `s` 命令是同源的正则替换语法——这一章在第 4 篇《初识 sed》会原样重逢。提前熟悉 `:s///g` 等于提前预习 sed。</span>

## 4 配置与实战：vimrc 与 vimtutor

**vim 默认配置很朴素**，但它的可配置性极强。用户级配置文件是 `~/.vimrc`，每次启动自动加载。新手建议先配这几行：

```vim
set number          " 显示行号
set showmatch       " 括号自动配对高亮
set expandtab       " 用空格代替 Tab
set shiftwidth=4    " 缩进 4 格
syntax on           " 语法高亮
```

**练习方法**：终端里敲 `vimtutor`，它会打开一份约 30 分钟的交互式教程，从移动到替换循序渐进——这是全世界公认的 vim 入门第一课。别急着背全部命令，先掌握「移动 + 删除 + 复制粘贴 + 保存退出 + 搜索替换」这五组，就已经覆盖日常编辑的九成场景。

**易错点**：vim 依赖 `~/.vimrc` 生效前要确认文件路径写对；而「退出」的四个写法最容易记混——`:wq` 保存退出、`:q!` 不保存强制退出、`:wq!` 只读文件也保存退出、`ZZ` 等价于 `:wq`。<span class="marginnote">断电或 ssh 断连时 vim 会留下交换文件 `.filename.swp`，下次打开会提示恢复。看到「Swap file exists」时，用 `vim -r filename` 恢复上次未保存的内容。</span>

## 5 小结

- **vim 是模式化编辑器**：普通模式发命令、插入模式打文字、命令模式做文件级操作，`Esc` 永远回普通模式。
- **操作语法是「动词 + 目标」**：`d`/`y` 配移动命令，`dd`、`d2w`、`yy`、`3yy` 都能自然推出。
- **搜索 `/` 与替换 `:%s/old/new/g`** 是文本处理的主力，replacement 支持正则、`#` 可换分隔符。
- **配置写在 `~/.vimrc`**：行号、缩进、语法高亮三件套起步，`vimtutor` 是入门第一课。
- **退出四写法**：`:wq`、`:q!`、`:wq!`、`ZZ`，记混前先想清楚要不要保存。
