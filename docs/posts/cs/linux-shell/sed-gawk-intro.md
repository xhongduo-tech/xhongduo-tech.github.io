## 为什么从 sed 与 gawk 开始

前文我们已用 grep 过滤行、用 cut/tr 格式化列，但还缺两个重武器：**`sed`** 能**流式编辑**文本（替换、删除、插入，不改原文件、直接处理流），**`gawk`**（awk 的 GNU 版本）能把文本**当数据算**（按字段拆分、求和、计数、出报表）。它们与 grep 合称「文本处理三剑客」，几乎是 Unix 世界里一切日志分析、配置批量改写的引擎。本章首次正面接触两者的核心模型：**sed 的「行处理命令式」**与 **awk 的「字段处理编程式」**。

## 1 sed：流编辑器的心智模型

**`sed`**（stream editor）是**逐行读入、逐行处理、逐行输出**的编辑器：它不打开文件、不依赖交互，而是像一个流水线工人，每拿到一行就按脚本指令加工，再放走。最常见的两种用法：

```bash
sed 's/old/new/' file            # 把每行第一个 old 换成 new
sed 's/old/new/g' file           # 每行所有 old 换成 new
sed -i 's/old/new/g' file        # -i 直接改原文件（慎用！）
```

**`s`**（substitute）是 sed 的核心命令，结构与 vim 的替换如出一辙：`s/模式/替换/标志`。<span class="marginnote">`sed` 默认<strong>只输出到屏幕、不改文件</strong>——`sed 's/a/b/' file` 原文件纹丝不动。想真改文件加 `-i`，但 `-i` 是破坏性的，生产环境先备份：`sed -i.bak 's/a/b/' file` 会自动留一个 `.bak`。</span>

**易错点**：sed 的「行」以换行为界，`s` 默认只处理每行第一个匹配，`g` 才处理全部——与 vim 替换、与 grep 的语义要对齐，别混。替换内容含 `/` 时改用其他分隔符：`sed 's#/usr/bin#/usr/local/bin#g'`。

## 2 sed 的寻址：只处理指定行

sed 的威力在于**按地址挑选行**再操作。地址可以是行号、范围或正则：

```bash
sed '3d' file                    # 删除第 3 行
sed '1,5d' file                  # 删除第 1-5 行
sed '/^#/d' file                 # 删除注释行（正则匹配）
sed '/ERROR/,+2p' file           # 匹配 ERROR 的行及其后 2 行
sed -n '10,20p' file             # 只打印 10-20 行（-n 关闭默认输出）
```

**`d`**（delete）删行、**`p`**（print）打印、**`a`/`i`**（append/insert）追加/插入。`-n` 配合 `p` 是「只看我想要的行」的黄金组合——默认 sed 会输出所有行，`-n` 关掉默认输出后，只有被 `p` 标记的行出现。<span class="marginnote">sed 支持多个命令用分号串在一起：`sed 's/a/b/; /^#/d' file`。也可以写进脚本文件用 `sed -f script.sed`。`sed` 与 `vim` 的 `:s` 语法同源——先学 sed 等于复习 vim，反之亦然。</span>

**易错点**：`sed -n '10,20p'` 与 `sed '10,20p'` 天差地别——后者除了 10-20 行还会把**所有行**再打印一遍（因为默认输出 + p 重复打印）。`-n` 忘了写是 sed 新手最经典的「输出重复」事故。

## 3 gawk：字段驱动的数据处理语言

**`gawk`**（GNU awk）是一个微型编程语言：把每行**按分隔符拆成字段**，再用类 C 语法逐字段计算。基本结构是「三段式」：

```bash
gawk 'BEGIN { print "开始" }
      { print $1, $2 }
      END { print "结束" }' data.txt
```

- **`BEGIN` 块**：读第一行前执行一次（初始化、打印表头）。
- **主体块**：对**每一行**执行（`$1`、`$2` 是第 1、2 个字段，`$0` 是整行）。
- **`END` 块**：处理完所有行后执行一次（汇总、打印结论）。

**公式解析：awk 的字段与分隔符**

$$
\text{一行} = \underbrace{\$1}_{第1字段} \;\; \text{FS} \;\; \underbrace{\$2}_{第2字段} \;\; \text{FS} \;\; \underbrace{\$3}_{第3字段} \;\; \cdots \qquad \text{FS = 字段分隔符，默认空白}
$$

拆解：

- **第一步**：awk 按 **FS（field separator，默认连续空白）** 把 `$0`（整行）切开。
- **第二步**：`$1`、`$2` 依次对应切出的字段；`NF` 是字段总数、`NR` 是当前行号。
- **第三步**：改分隔符用 `-F`：`gawk -F: '{print $1}' /etc/passwd` 按冒号切、取用户名。
- **第四步**：字段值可参与运算、比较、printf 格式化——这就是「算文本」。

一个「统计每行字段数并求和」的例子：

```bash
gawk '{ total += NF } END { print "字段总数:", total }' file.txt
```

主体块对每行累加字段数，END 块打印合计——**awk 天生适合做报表**。<span class="marginnote">`awk` 里变量无需声明、直接用（`total` 初值是 0）；`+=`、`if`、`for`、`printf` 都是 C 语法。`gawk` 是 GNU 的实现，现代 Linux 的 `awk` 基本都指向 gawk——用 `gawk` 或 `awk` 皆可。</span>

## 4 核心对比表：sed 与 gawk 的分工

两者都是逐行处理，但关注点截然不同——选错工具是新手最常犯的选择题：

| 维度 | sed | gawk |
| --- | --- | --- |
| 本质 | 流式**编辑器** | 数据处理**语言** |
| 擅长 | 替换、删除、插入文本 | 拆分字段、运算、出报表 |
| 处理单位 | 行（正则寻址） | 行内字段（`$1`/`$2`） |
| 状态 | 无状态 | 有变量、可累加 |
| 典型场景 | 批量改配置、删日志行 | 日志统计、列运算、汇总 |

**判断口诀**：**「改文本找 sed，算数据找 awk」**。把配置里的端口 80 改成 8080 → sed；统计每个 IP 的访问次数 → awk。当然两者都支持正则、都能做替换，只是「擅长的事」不同。<span class="marginnote">sed 与 gawk 都可以处理<strong>管道输入</strong>：`tail -f log | sed 's/^/[LOG] /'` 给每行加前缀，`ps aux | gawk '{print $2}'` 取 PID 列——它们是管道链里最顺手的两个齿轮。</span>

**易错点**：gawk 程序里的 `$2` 是字段变量，**不是 shell 变量**——在 shell 里写 `gawk '{print $2}'`，`$2` 由 gawk 解释，别用 shell 的 `$2` 去套。而 sed 里 `$` 表示行尾（`s/foo$/bar/`），语义又不同——三个工具对 `$` 的解释各有一套，写之前先想清楚当前在哪个「语言」里。

## 5 组合实战：sed + gawk 的管道

把两者串起来看一个真实任务：**统计 access.log 中每个 IP 的请求次数，按次数从高到低排**。

```bash
cat access.log \
  | gawk '{print $1}' \
  | sort \
  | uniq -c \
  | sort -rn \
  | head -10
```

这条管道的每一步各管一段：

- **第一步**：`gawk '{print $1}'`——日志行格式是 `IP - - [时间] "GET ..." 状态 大小`，`$1` 正好是 IP 列，awk 把整行削成只剩 IP。
- **第二步**：`sort` 把相同 IP 聚拢——uniq 只认相邻重复行，这一步不可省。
- **第三步**：`uniq -c` 逐段计数，输出 `次数 IP`。
- **第四步**：`sort -rn` 按次数逆序数值排序，`head -10` 取 Top 10。

想在结果里附加「请求失败数」，gawk 进一步加工：`gawk '{print $1, $9}'` 取出 IP 与状态码，再用第二个 awk 统计。**sed 负责「洗」、awk 负责「算」、sort/uniq 负责「排」**——每个工具只做一件事，管道把它们接成一条自动生产线。这条思路与大数据里的 MapReduce 在精神上完全同构：先按 key 分组，再在组内聚合。

## 6 小结

- **sed 是流式编辑器**：`s/old/new/g` 替换、`3d` 删行、`-n '10,20p'` 挑行打印；默认不改原文件。
- **sed 寻址靠行号与正则**：`/^#/d` 删注释行，`-i.bak` 原地修改并备份。
- **awk 是字段编程语言**：`BEGIN` 初始化、主体逐行、`END` 汇总，`$1`/`NF`/`NR` 是字段三件套。
- **`-F:` 改分隔符**：`gawk -F: '{print $1}'` 是处理 passwd 这类文件的标准姿势。
- **选型口诀**：改文本用 sed、算数据用 awk；两个都是管道的好齿轮。
