## 为什么从变量开始

上一节我们把环境搭好、跑通了 `print`。但只会打印字面量还不够——真实程序要先**记住数据**：把用户的名字存起来、把价格算出来、把状态标记出来。这种「用名字装住数据」的机制，就是**变量（variable）**。

本节回答三个问题：变量怎么用、Python 有哪些**简单数据类型**、以及不同类型之间如何**转换**。它们是后续一切语法（列表、字典、类）的最小砖块。

## 1 变量：名字与值的绑定

在 Python 中，赋值用等号：右边先被求值，再把结果**绑定**到左边的名字。

```python
message = "Hello, world!"   # 字符串
age = 42                     # 整数
pi = 3.14159                 # 浮点数
is_ok = True                 # 布尔值
```

**重点：变量是「名字」，不是「盒子」。** 在 Python 里，变量名只是贴在对象上的标签；同一个对象可以被多个名字引用。这与你之后在 C 语言里见到的「内存位置」模型有微妙差别，但在入门阶段，把它想成「给值贴标签」就已足够。<span class="marginnote">「贴标签」模型能解释一个经典现象：`a = b` 之后，`a` 与 `b` 指向同一个对象。`b = b + 1` 会让 `b` 换一个新标签，而 `a` 仍指向旧对象——这在后面的可变对象（列表）一节会变得格外重要。</span>

**命名规则**：名字只能由字母、数字、下划线组成，且不能以数字开头；不能与 `if`、`for`、`class` 等**关键字**重名。风格上遵循 PEP 8，用小写加下划线：`user_name` 而非 `userName`。

PEP 8 对常量还有一个约定：**常量名用全大写加下划线**，如 `MAX_ATTEMPTS = 5`。Python 没有真正的「常量」——这是给读者的约定，全大写意为「请勿修改」。另注意**多变量赋值**可一行完成：`a, b = 1, 2` 同时给两个名字赋值，这是解包语法的雏形（元组解包会在《列表、元组与序列操作》一节展开）。

## 2 字符串：不可变的有序字符序列

**字符串（string）**：由字符构成的有序序列，用单引号或双引号括起。它是文本处理的基本单位。

字符串是**不可变**的：任何「修改」其实都是创建新字符串。

字符串还支持**索引与切片**：`name[0]` 取第一个字符、`name[-1]` 取最后一个、`name[1:3]` 取子串——这些操作与列表完全一致，因为二者同属「序列」家族（细节见《列表、元组与序列操作》）。

```python
name = "python"
print(name.title())     # 'Python'：首字母大写
print(name.upper())     # 'PYTHON'
print(name.replace("p", "P"))  # 'Python'
```

**f-string（格式化字符串）**：在字符串前加 `f`，用花括号嵌入表达式，是 Python 3.6 起的推荐做法：

```python
name = "ada"
age = 41
print(f"{name.title()} 出生于 {age} 岁之前的整整 50 年")
```

f-string 把「拼字符串」从 `+` 的连缀变成了「模板填空」，可读性大幅提升。它还支持格式说明符（如 `{age:.2f}` 保留两位小数），这在本专题《字符串处理与格式化》一节会系统展开。

## 3 数字与布尔：整数、浮点数与真值

Python 的数值类型主要有**整数（int）** 与**浮点数（float）**。

```python
a = 2 ** 10        # 1024，** 是乘方
b = 7 / 2          # 3.5，/ 永远返回浮点数
c = 7 // 2         # 3，// 是整除
d = 7 % 2          # 1，% 是取余
```

**辨析｜易错点：** 浮点数不是精确小数。`0.1 + 0.2` 在 Python 里等于 `0.30000000000000004`，因为二进制无法精确表示十进制小数。这不是 bug，而是 IEEE 754 的固有属性，财务计算要用 `decimal` 模块——我们在第三级《数值分析》与第二级《数值计算》中会专门处理这类误差。

**布尔（bool）** 只有两个值 `True` 与 `False`，本质上对应整数 1 与 0，因此 `True + True == 2`。布尔是后面 `if` 语句的心脏。

数值运算还有一组**复合赋值**运算符：`+=`、`-=`、`*=`、`/=`。`count += 1` 等价于 `count = count + 1`——在《用户输入与 while 循环》的计数循环里它们无处不在。记住一条经验：**整数运算精确、浮点运算才有误差**，所以计数的 `+= 1` 永远安全，累加小数时才要留意精度。

字符串的**不可变性**同样值得注意：`s += "!"` 并不是「改长原字符串」，而是创建新字符串再让 `s` 指向它。大量拼接时用 `''.join(...)` 更高效，日常写作 `+` 或 f-string 完全够用。

## 4 核心对比表：四种内置标量类型

| 类型 | 关键字 | 示例 | 可变性 | 典型用途 |
| --- | --- | --- | --- | --- |
| 整数 | `int` | `42`、`-7` | 不可变 | 计数、索引 |
| 浮点数 | `float` | `3.14`、`1e5` | 不可变 | 测量、科学计算 |
| 字符串 | `str` | `"hello"` | 不可变 | 文本处理 |
| 布尔 | `bool` | `True`、`False` | 不可变 | 分支判断、开关标志 |

**核心观察：四种简单类型全部不可变。** 这与后续列表、字典（可变）形成鲜明对比——「不可变对象按值参与运算、可变对象按引用共享状态」，是理解 Python 内存模型的钥匙。<span class="marginnote">`type(x)` 查看任意对象的类型，`isinstance(x, int)` 判断类型。在交互式 REPL 里多敲几遍 `type(1)`、`type(1.0)`、`type("1")`，比读十遍书都直观。</span>

## 5 类型转换：在类型之间安全迁移

不同数据类型不能直接混用：`"10" + 5` 会报错。**转换**就是显式地在类型间迁移：

```python
age_str = "29"
age = int(age_str)      # 字符串 → 整数
ratio = float("0.618")  # 字符串 → 浮点数
print(float(1))         # 1.0，整数 → 浮点数
print(str(3.14))        # "3.14"，浮点数 → 字符串
```

最常见的是把 `input()` 返回的字符串转成数字——下一节《用户输入与 while 循环》里，`int(input(...))` 将是最频繁出现的组合。转换有规则：`int("hello")` 会抛 `ValueError`，因为内容根本无法解析成整数；「先转换、再运算、并对可能失败之处做准备」，是稳健代码的第一步。

`bool()` 也能显式转换：`bool(0)` 为 `False`、`bool("")` 为 `False`、其余大多为 `True`——这与前面提到的「真值」规则完全一致。写 `if not user_input:` 判断「空输入」时，用的正是这套规则。

## 6 小结

- 变量是**名字与对象的绑定**，命名遵循「字母数字下划线、不以数字开头」与 PEP 8。
- 四种简单类型 `int`、`float`、`str`、`bool` **全部不可变**。
- 字符串支持 `title()`、`upper()`、`replace()` 等方法，f-string 是推荐的拼接方式。
- 浮点数存在**二进制表示误差**（`0.1 + 0.2` 问题），高精度场景用 `decimal`。
- 用 `int()`、`float()`、`str()` 显式转换类型；非法转换会抛 `ValueError`。
- 复合赋值 `+=`、`*=` 是缩写；整数运算精确、浮点运算才有误差。
