## 为什么从列表开始

变量一节里，每个名字只装一个值。但真实世界几乎总是「一群值」：一份成绩单、一条购物清单、一张扑克牌。**列表（list）** 就是 Python 用来装「一组有序数据」的容器，也是全书第二早出场的核心数据结构。

本节学习列表的三种能力：**按下标取元素、切出一段子列表、用方法增删改**；再对比它与**元组（tuple）**——一个不可变的孪生兄弟。

## 1 列表：可变的有序容器

**列表（list）**：用方括号括起、逗号分隔的一组元素的有序集合。

```python
bicycles = ["trek", "cannondale", "redline", "specialized"]
print(bicycles[0].title())   # 'Trek'，下标从 0 开始
print(bicycles[-1])          # 'specialized'，负数从尾部数
```

**重点：下标从 0 开始。** 第 1 个元素是 `[0]`，最后一个元素是 `[-1]`——负下标是 Python 的贴心设计，让「取最后一个」不用先数长度。<span class="marginnote">下标从 0 开始是 C 语言遗风，也符合「偏移量」的直觉：`a[0]` 是「偏移 0 个位置」。数学里我们记第 1 项为 $a_1$，编程里它却是 `a[0]`，初学者最容易在这里摔一跤。</span>

**可变性**：列表与字符串的最大差别——列表**可变**，可原地增删改：

```python
bicycles.append("giant")        # 尾部追加
bicycles.insert(1, "merida")    # 指定位置插入
bicycles.remove("trek")         # 按值删除第一个匹配
last = bicycles.pop()           # 弹出末尾元素
del bicycles[0]                 # 按下标删除
```

`len(bicycles)` 返回长度，`"trek" in bicycles` 判断成员——这两个函数在几乎所有语言里都叫 `len` 与 `in` 的近亲。

列表还支持一组**运算**：`+` 拼接、`*` 重复、`count()` 计数、`index()` 定位：

```python
print([1, 2] + [3])         # [1, 2, 3]
print([0] * 3)              # [0, 0, 0]
print([1, 2, 2].count(2))   # 2
print([1, 2, 3].index(2))   # 1，第一次出现的位置
```

`[0] * 3` 这个「重复」写法在初始化固定长度的列表时极常用；`index()` 在找不到元素时会抛 `ValueError`——用它之前先确认元素存在，或用 `if x in lst` 先判断。

## 2 切片：序列的「段落复制」

**切片（slice）**：用 `[start:stop:step]` 一次性取出一段子序列。它不修改原列表，而是返回一个**新列表**。

```python
numbers = [0, 1, 2, 3, 4, 5]
print(numbers[1:4])    # [1, 2, 3]，从 1 到 4 之前
print(numbers[:3])     # [0, 1, 2]，从头到 3 之前
print(numbers[2:])     # [2, 3, 4, 5]，从 2 到尾
print(numbers[::2])    # [0, 2, 4]，隔一个取一个
print(numbers[::-1])   # [5, 4, 3, 2, 1, 0]，反转
```

切片在复制时有个大坑：`copy = numbers` 只是给同一列表贴了个新标签，改 `copy` 会同步改 `numbers`；真正复制要用 `numbers[:]` 或 `list(numbers)`。<span class="marginnote">`list1 = list2` 是「别名」，`list1 = list2[:]` 才是「副本」。别名问题在嵌套列表与类属性里还会再次出现——记住口诀：可变对象用切片复制，不可变对象无所谓。</span>

## 3 元组：不可变的序列

**元组（tuple）**：用圆括号括起、逗号分隔的元素序列，与列表语法几乎相同，但**不可变**。

```python
dimensions = (200, 50)
print(dimensions[0])     # 200
# dimensions[0] = 100    # TypeError：元组不支持元素赋值
```

元组能做的，是「打包」与「解包（unpacking）」：

```python
x, y = dimensions        # 一行解包成两个变量
point = (3, 4)
```

**为什么需要元组？** 因为「不可变」意味着安全：把一个元组传给函数，函数没法偷偷改坏它。数据科学里，坐标、RGB 颜色、日期都可以用元组表达「一组不允许被改动的值」。<span class="marginnote">Python 里很多「看起来像元组」的东西其实是元组：`for x, y in points` 中的 `x, y`、函数多返回值、字典的 `items()` 结果，解包语法无处不在。</span>

元组有两个值得注意的「语法陷阱」。第一，**单元素元组要加逗号**：`(5)` 只是普通括号，`(5,)` 才是元组。第二，列表与元组可以相互转换——`tuple(lst)` 冻结、`list(tup)` 解冻：

```python
single = (5,)               # 单元素元组，别忘了逗号
frozen = tuple([1, 2, 3])   # 列表 → 元组
mutable = list((1, 2, 3))   # 元组 → 列表
```

**切片不止对列表有效。** 字符串、元组都支持同样的切片语法——`"python"[1:4]` 得到 `"yth"`。它们共享**序列（sequence）**这一共同祖先，索引、切片、`len`、`in`、`+` 都是序列协议的一部分。这也解释了本节标题为何叫「列表、元组与序列操作」——学一次，处处通用。

## 4 公式解析：切片的区间语义

**切片的 `[start:stop:step]` 本质上是一个半开区间公式。** 数学里的闭区间 $[a,b]$ 含两端点，而 Python 切片只取 `stop` **之前**的元素：

$$
\text{numbers}[start:stop] = \{\text{numbers}[i] \mid start \le i < stop\}
$$

对这条规则做三步拆解：

- **第一步，读符号**：冒号把 `start`、`stop`、`step` 三个参数隔开；省略哪个就取默认（`start=0`、`stop=len`、`step=1`）。
- **第二步，理解半开**：`stop` 是**排除**的端点。`numbers[1:4]` 取下标 1、2、3 共 3 个元素，因为 $1 \le i < 4$。这保证了 `a[:k] + a[k:] == a` 恒成立——两段无缝拼接。
- **第三步，理解步长**：`step` 是下标间距。`[::2]` 取 $\{i \mid i = 0, 2, 4, \dots\}$，`[::-1]` 用负步长实现倒序。

**为何半开区间更优雅？** 它让「切割」变得无歧义：两个相邻切片 `a[:k]` 与 `a[k:]` 正好拼回原列表，不存在「多取一个」或「漏取一个」的边界争吵。这一设计与 `range(start, stop)` 完全一致，也与数学里的区间记号 $[start, stop)$ 对应——如果你在第二级《离散数学》学过区间，这里就是同一思想在编程里的落地。

## 5 小结

- 列表用 `[]` 定义、**可变**，下标从 0 起，`-1` 指最后一个元素。
- `append`、`insert`、`remove`、`pop`、`del` 是增删改的五种主力操作。
- 切片 `[start:stop:step]` 返回**新列表**，遵循半开区间 $[start, stop)$ 语义。
- `list2 = list1` 是别名，`list2 = list1[:]` 才是副本。
- 元组 `()` **不可变**，擅长打包与解包，适合表达「不允许修改的值」。
