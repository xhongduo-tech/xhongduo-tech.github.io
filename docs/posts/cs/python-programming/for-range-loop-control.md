## 为什么把流程控制讲深一层

前面两节分别学了 `for` 与 `while`，但流程控制的细节远不止「会写一个循环」。真实代码里的循环往往嵌套、带提前退出、需要同时遍历多个序列——这些进阶形态，官方 Python 教程第 4 章做了系统梳理，也正是本节的内容。

把循环从「会写」提升到「写得准」，关键在四个点：`range` 的惰性本质、`break/continue/else` 三个控制语句的精确语义、嵌套循环的节奏、以及 `zip`/`enumerate` 这类「同时遍历」的利器。

## 1 range 的惰性本质与步进

`range()` 在遍历数值序列时几乎无处不在，但它的真实身份常被误解。

**`range` 返回的是「可迭代对象」，不是列表。** 它按需生成数字，不一次性占用内存。看一个证据：

```python
big = range(10 ** 9)      # 十亿个数，但内存几乎为零
print(10 ** 9 in big)     # 很快判断出 True，而不是真的生成十亿个数
```

**重点：`range` 是惰性（lazy）的。** 它只存储起点、终点、步长三个参数，每次迭代才算出下一个值。这一设计让 `range(10**9)` 这种「天文数字的序列」也能安全创建。<span class="marginnote">惰性求值是大数据与流式处理的核心思想：能按需生成就不提前生成。本专题《迭代器与生成器》会把它推广到任意自定义序列；第二级《数值分析》里「向量不整块分配、按索引访问」也是同一哲学。</span>

**步长的三种典型用法**：

```python
list(range(5))            # [0, 1, 2, 3, 4]          默认从 0、步长 1
list(range(2, 8))         # [2, 3, 4, 5, 6, 7]       指定起点
list(range(0, 10, 2))     # [0, 2, 4, 6, 8]          步长 2
list(range(5, 0, -1))     # [5, 4, 3, 2, 1]          负步长倒序
```

## 2 循环控制三兄弟：break / continue / else

**`break`**：立即终止整个循环，程序跳到循环之后的语句。

```python
for n in range(2, 100):
    if n * n > 50:
        break            # 找到第一个平方超过 50 的数就停
    print(n)             # 打印 2..7
```

**`continue`**：跳过本次迭代剩余语句，进入下一轮。

```python
for n in range(10):
    if n % 3 == 0:
        continue         # 跳过 3 的倍数
    print(n, end=" ")    # 1 2 4 5 7 8
```

**`else` 子句**：这是 Python 循环的独门武器——**循环正常结束（没被 break 打断）时才执行 `else` 块**。

```python
for n in range(2, 10):
    for d in range(2, n):
        if n % d == 0:
            break        # 找到因子，n 不是质数
    else:                # 内层没 break，说明 n 是质数
        print(n, end=" ")   # 2 3 5 7
```

**重点：`for...else` 的语义是「循环没被 break 就执行 else」。** 上面的质数判定是经典示范——用 `break` 标记「找到了」，用 `else` 标记「没找到」。这个写法在需要「搜索是否存在」的场景非常优雅。

**辨析｜易错点：** `else` 不是在「循环结束后」执行，而是在「循环未被 break 中断而自然结束」时执行。如果循环被 `break` 打断，`else` 会被跳过。搞混这一点，是 `for-else` 最常见的误用。

## 3 嵌套循环：外层换一次，内层跑一圈

循环体内再套循环，就是**嵌套循环（nested loop）**。外层每执行一次，内层完整跑一遍。

```python
for i in range(3):
    for j in range(2):
        print(f"({i}, {j})", end=" ")
    print()
```

输出：

```
(0, 0) (0, 1) 
(1, 0) (1, 1) 
(2, 0) (2, 1) 
```

**重点：嵌套循环的总执行次数 = 外层次数 × 内层次数。** 用 `range` 嵌套生成的 `(i, j)` 对，正是「笛卡尔积」的编程表达——遍历二维表格、枚举坐标、生成全排列的起点都在这里。<span class="marginnote">笛卡尔积在数学里是集合运算：$A \times B = \{(a,b) \mid a \in A, b \in B\}$，嵌套循环就是它的枚举实现。这一联系在第二级《离散数学》的集合论与《算法》的复杂度分析里还会再次相遇。</span>

**辨析｜易错点：** `break` 只跳出**最内层**循环。若想从多层嵌套中一次性退出，惯用手法是设置一个「标志」在外层判断，或把嵌套逻辑抽成函数、用 `return` 提前返回——后一种更清晰，也更接近函数式思想。

## 4 zip 与 enumerate：同时遍历多个序列

两个并列的列表，如何「按位置配对」遍历？`zip` 是标准答案：

```python
names = ["alice", "bob", "carol"]
scores = [88, 92, 79]
for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

`zip` 把多个序列按位置「拉链」式地配对，每次迭代吐出对应元素组成的元组。**重点：`zip` 以最短序列为准**——`zip([1,2,3], ["a","b"])` 只产生两对。

**`enumerate`** 则解决「既要元素、又要下标」的遍历：

```python
for index, name in enumerate(names, start=1):
    print(f"第 {index} 位：{name}")
```

`enumerate(seq, start=0)` 每次产出一个 `(下标, 元素)` 元组，配合解包语法 `for i, x in ...`，比手动 `range(len(seq))` 更简洁、也更安全（不会越界）。<span class="marginnote">`zip` 与 `enumerate` 都是<strong>惰性</strong>的——它们返回迭代器，按需产出，不会把整组配对提前存进内存。这与《迭代器与生成器》一节的惰性求值哲学一脉相承；官方教程第 4 章正是在「循环技术」处介绍它们。</span>

## 5 公式解析：嵌套循环的执行次数

**嵌套循环的总迭代次数可以精确计算。**

设外层循环执行 $n_1$ 次、内层循环执行 $n_2$ 次，则循环体执行总次数为：

$$
N = n_1 \times n_2
$$

推广到 $k$ 层嵌套，设各层次数为 $n_1, n_2, \dots, n_k$：

$$
N = n_1 \times n_2 \times \cdots \times n_k
$$

对这条式子做三步拆解：

- **第一步，读「乘法原理」**：外层每走一步，内层要完整跑一遍。`for i in range(3): for j in range(2):` 中，内层体执行 $3 \times 2 = 6$ 次——每次外层迭代都「复制」内层的完整循环，这正是乘法原理（独立步骤数相乘）在编程里的体现。
- **第二步，看不等长嵌套**：各层次数可以不同，乘积公式依然成立。三层 `10 × 20 × 30` 的循环体执行 $6000$ 次——用这个公式可以**先算清代价再写代码**。
- **第三步，警惕复杂度爆炸**：若每层次数都是 $n$，则 $N = n^k$。当 $k=2$ 是 $O(n^2)$，$k=3$ 是 $O(n^3)$——输入规模翻倍，时间可能变成八倍。这就是第二级《算法与复杂度》里「循环嵌套决定复杂度量级」的直觉来源，也是为什么大量算法优化的本质是「减少一层循环」。

**为何要精确计算？** 因为它把「这个循环会不会太慢」从感觉变成了算术：跑 100 万次以内，Python 通常眨眼即过；一旦上了亿次，就要警惕。用乘积公式预估规模，是性能意识的第一步。

## 6 小结

- `range` 是**惰性**可迭代对象，只存三参数，`range(start, stop, step)` 三参数控制步进。
- `break` 立即终止循环，`continue` 跳过本次迭代；`for...else` 只在循环**未被 break** 时执行。
- 嵌套循环总次数 $N = n_1 \times n_2 \times \cdots \times n_k$，警惕 $O(n^k)$ 复杂度爆炸。
- `zip(seq1, seq2)` 按位置配对（以最短为准），`enumerate(seq, start)` 同时给下标与元素。
- `break` 只跳出最内层；多嵌套退出用标志或函数 `return`。

在下一节，我们将把循环里积累的「对每个元素做什么」的思考正式化——函数：定义、参数与返回值，把逻辑封装成可复用的积木。
