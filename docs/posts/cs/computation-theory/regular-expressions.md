## 为什么需要正则表达式

前两课我们有了两台机器：DFA 与 NFA。
机器擅长「运行」，却不擅长「描述」——让你用状态图画「所有不含 `00` 的二进制串」，你要费不少功夫。
**正则表达式（regular expression）** 给出另一种视角：用一串紧凑的符号直接写出语言的「配方」。
它既是数学对象（描述一类语言），也是工程工具（grep、`sed`、各种编程语言里的 pattern），是计算理论里少见的「学完立刻能用」的概念。
<span class="marginnote">正则表达式由 Kleene 在 1956 年提出，本意是描述「神经网中的事件」；
1968 年 Ken Thompson 把它实现进编辑器 QED 与 Unix 的 grep，从此成为每个程序员的日常工具。
</span>

在课程主线里，这一课补齐了「正则语言」的第三种等价刻画：**DFA 能识别的 = NFA 能识别的 = 正则表达式能描述的**。
三者指向同一个对象，只是从「运行」「猜测」「描述」三个角度看它。

## 1 正则表达式的语法

**正则表达式（regular expression, regex）**：按如下规则递归地定义的表达式，每个表达式 $R$ 描述一个语言 $L(R)$：

**基例 1**：$\varnothing$ 是正则表达式，$L(\varnothing) = \varnothing$（空语言——不含任何串）。
**基例 2**：$\varepsilon$ 是正则表达式，$L(\varepsilon) = \{\varepsilon\}$（只含空串）。
- **基例 3**：对任意 $a \in \Sigma$，$a$ 是正则表达式，$L(a) = \{a\}$。<span class="marginnote">注意 $\varnothing$ 与 $\varepsilon$ 的区别：$\varnothing$ 描述的语言一个串都没有；$\varepsilon$ 描述的语言含有恰好一个串——空串。二者的正则表达式写法也不同：`∅` 与 `ε`。</span>

- **归纳 1（并）**：若 $R_1$、$R_2$ 是正则表达式，则 $R_1 \cup R_2$ 是，且 $L(R_1 \cup R_2) = L(R_1) \cup L(R_2)$。
- **归纳 2（连接）**：若 $R_1$、$R_2$ 是正则表达式，则 $R_1 R_2$ 是，且 $L(R_1 R_2) = L(R_1) \circ L(R_2)$——把两个语言里的串**首尾相接**：$\{ab \mid a \in L(R_1), b \in L(R_2)\}$。
- **归纳 3（星号）**：若 $R$ 是正则表达式，则 $R^*$ 是，且 $L(R^*) = L(R)^0 \cup L(R)^1 \cup L(R)^2 \cup \cdots$——**零个或多个** $R$ 的串连接起来。

工程里的写法略有不同：并常写作 `a|b` 或 `a+b`，连接就是并排（`ab`），星号是 `*`，还有派生记号 `+`（一个或多个）、`?`（零个或一个）等。
它们的语义都能用上面三种基本运算定义出来。

**重点：正则表达式是「最小描述语言」的典范。**
 三种基例加三种运算，就足够表达一切正则语言——不多也不少。

## 2 三个例子读懂语法

**例 1**：$R = (0 \cup 1)^*$。
描述「由 0 和 1 任意拼接的串」，即全体二进制串 $\{0,1\}^*$。
星号套在括号外，意思是「任意多个（0 或 1）」——注意是任意多个**整体**，每个整体可以独立选择 0 或 1。

**例 2**：$R = 0^*10^*$。
描述「恰有一个 1 的二进制串」：$1$ 左边可以有任意个 0，右边也可以有任意个 0。
这个描述比画状态图简洁得多。

**例 3**：$R = (0 \cup 1)^* 011$。
描述「以 `011` 结尾的二进制串」。
这个语言用 DFA 也能画，但正则表达式几乎是「看着题目写出来的」——这正是表达力所在。

**辨析｜易错点：** `(0|1)*` 与 `0*1*` 完全不同。
前者允许 0 与 1 任意交错（`0101` 属于它）；
后者要求「先一堆 0、再一堆 1」（`0101` 不属于它）。
星号作用于括号内整体时，才获得「每个位置自由选择」的威力。
写正则时先问自己：**这个星号作用在哪个单元上？**

## 3 公式解析：正则表达式描述的语言

把「正则表达式如何生成语言」写成一条干净的递推定义，是理解一切例子的关键：

$$
L(R_1 R_2) = \{ uv \mid u \in L(R_1),\, v \in L(R_2) \}, \qquad L(R^*) = \bigcup_{k \ge 0} L(R)^k
$$

拆成三步看：

- **第一步，读连接**：$L(R_1 R_2)$ 的每个串由两段拼成——**前段来自 $R_1$，后段来自 $R_2$**。这里出现的是「存在一个切分点」：$uv$ 表示 $u$ 接上 $v$，切在哪里由 $u,v$ 共同决定，一个串可能有多种切分。
- **第二步，读星号**：$L(R)^k$ 表示「$k$ 个来自 $L(R)$ 的串依次连接」。$L(R)^0 = \{\varepsilon\}$，这是 $k=0$ 的约定——所以**空串总在 $R^*$ 里**，与 $R$ 是否能描述空串无关。
- **第三步，读出语义**：星号 = **任意多次拼接的并**。这就是「`*` 表示零个或多个」的严格定义，也是正则语言为什么对星号封闭的根。

## 4 核心定理：正则表达式 ≡ 有限自动机

**定理（Kleene）：** 一个语言是正则的，当且仅当它能被某个正则表达式描述。

这一定理把「机器世界」与「符号世界」连成闭环。
证明的机械方向（正则表达式 → NFA）用的是**汤普森构造（Thompson construction）**，思路是跟着正则表达式的递归结构走：

- **基例**：$\varnothing$ 对应「无路可走的单状态机」；$\varepsilon$ 对应「从起始直接到接受的单状态机」；$a$ 对应「读一个 $a$ 就到接受态」的两状态机。
- **并 $R_1 \cup R_2$**：造一个新的起始状态，用 $\varepsilon$-转移同时连到两台子机器的起始；再把两台子机器的接受态汇到一个新的接受状态——**「或」就是分叉，分叉就用 $\varepsilon$-转移**。
- **连接 $R_1 R_2$**：把 $R_1$ 的接受态与 $R_2$ 的起始态用 $\varepsilon$-转移接起来，首尾相接——「然后」就是串行。
- **星号 $R^*$**：从接受态加一条 $\varepsilon$-转移绕回起始态，再让起始态能直接白嫖到接受态——「重复」就是绕圈。

每一步构造都保持一个不变量：**最终 NFA 的状态数是各个子机器状态数的常数倍**，因此这个构造是**线性规模**的——正因如此，工程里「正则 → NFA」从不担心爆炸，爆炸发生在 NFA → DFA。
<span class="marginnote">反方向的证明（自动机 → 正则表达式）也不难：把每个 DFA 状态编号，用动态规划式的「路径语言」归纳出正则表达式——这叫 Arden 引理或「消除状态法」，直观做法就是反复删状态、把路径并成并运算。
</span>

## 5 正则语言的代数

正则表达式还自带一套**代数运算律**，让表达式可以化简、等价变换。
几条最常用的：

| 恒等式 | 含义 |
| --- | --- |
| $R \cup \varnothing = R$ | 并上空语言等于自身（$\varnothing$ 是并的单位元） |
| $R \varepsilon = \varepsilon R = R$ | 连接上空串等于自身（$\varepsilon$ 是连接的单位元） |
| $R \varnothing = \varnothing$ | 连接上空语言得到空语言（没有串可拼） |
| $(R^*)^* = R^*$ | 星号是幂等的：重复重复还是重复 |
| $R(R \cup S)^* = (R \cup S)^* R$ | 星号里的内容前后挪动不改变语言 |

这些律看起来平凡，却是**正则语言判定与最小化**的地基。
比如「$R \varnothing = \varnothing$」这条，很多人初看会愣一下——因为它对应一个重要的直觉：**语言是串的集合，集合的连接是「任意配对」，一个集合为空，配对就无从谈起。**

**辨析｜易错点：** 不要把连接想成「顺序拼接每个串」。
「$R \varnothing$」不是「$R$ 的串后面跟个空的」，而是「$R$ 的任意串与空集的任意串相接」——空集没有串可选，所以结果是空语言，不是 $R$。

## 6 小结

- **正则表达式**由三种基例（$\varnothing$、$\varepsilon$、$a$）与三种运算（**并、连接、星号**）递归生成，每个表达式描述一个语言。
- 星号 $R^*$ = **零个或多个** $R$ 的串的连接；空串总在 $R^*$ 里。
- **Kleene 定理**：正则语言 = 正则表达式可描述的语言；正则表达式 ↔ NFA 互相转换。
- 正则 → NFA 用**汤普森构造**，规模线性；NFA → DFA 用**子集构造**，可能指数爆炸。
- 正则表达式满足一套**代数恒等式**（单位元、幂等律等），是化简与判定的工具。
