## 为什么要给语言分类

有了图灵机这把「万能钥匙」，第一个元问题浮出水面：**哪些语言能被机器判定，哪些只能被识别，哪些根本不可算？**
 这一课把答案的骨架立起来：先看一批**可判定**的具体例子（关于自动机与文法的判定问题），再严格区分「可判定」与「图灵可识别」，最后用一个漂亮的刻画把它们缝在一起。
<span class="marginnote">可判定语言在文献里也叫「递归语言」（recursive languages），图灵可识别语言也叫「递归可枚举语言」（recursively enumerable, r.e.）。
「递归」是 1930 年代递归函数论留下的叫法，指「能用有限步算出成员关系」。
</span>

从课程主线看，这一课是「可计算性的正面版图」：先看什么**能**算，下一课再看什么**不能**算。
认识「可判定」的边界，是理解停机问题、以及后续一切不可判定性证明的必要前提。

## 1 可判定的语言：三个代表性例子

**可判定语言（decidable language）**：存在一台**判定器**（对所有输入停机）识别它的语言。

先看三个关于「机器/文法的元问题」，它们全是可判定的——因为这些问题的答案可以由另一台机器**有限步模拟**得到：

**例 1：$A_{DFA}$ = $\{\langle B, w \rangle \mid B \text{ 是 DFA，且 } B \text{ 接受 } w\}$。**
 判定器 `M` 拿到 $\langle B, w \rangle$，直接**模拟** $B$ 在 $w$ 上的运行：每读一个字符走一步，$w$ 读完看停在不在接受态。
模拟至多 $|w|$ 步必然结束，所以 `M` 是判定器。
<span class="marginnote">$\langle B, w \rangle$ 是「把机器 $B$ 和串 $w$ 打包成一个串」的编码。
判定器的输入是编码后的串，而不是「活的机器」——机器在纸上只是数据，这正是通用机思想的体现。
</span>

**例 2：$A_{NFA}$** = $\{\langle B, w \rangle \mid B \text{ 是 NFA，且 } B \text{ 接受 } w\}$。
做法：先用子集构造把 NFA 转 DFA，再模拟。
**可判定**——因为 NFA 转 DFA 是有限算法，转完就回到例 1。

**例 3：$A_{CFG}$** = $\{\langle G, w \rangle \mid G \text{ 是 CFG，且 } w \in L(G)\}$。
做法：把 $G$ 转成 CNF，用 **CYK 算法** $O(|w|^3)$ 判定成员性。
**可判定**——虽然 CFG 比 DFA 强，但「给定文法和串问是否生成」仍然有算法。

**重点：三个例子共同说明——「模拟 + 已知算法」就够判定。**
 只要另一台已知机器跑有限步能给答案，这个元问题就可判定。

## 2 可判定的更多例子：关于机器的性质

把判定对象从「输入是否被接受」推广到「机器本身的属性」：

**$E_{DFA}$** = $\{\langle B \rangle \mid B \text{ 是 DFA，且 } L(B) = \varnothing\}$：**可判定**。标记算法——从起始状态 BFS 可达状态，检查是否有接受态可达。没有 → 空；有 → 非空。
**$EQ_{DFA}$** = $\{\langle B, C \rangle \mid B, C \text{ 是 DFA，且 } L(B) = L(C)\}$：**可判定**。用积构造造出「接受 $L(B) \triangle L(C)$（对称差）」的 DFA，再判其是否为空。

这两个例子的模式值得记住：**把「属性判定」翻译成「另一台自动机的语言判定」**。
等价性 = 对称差为空；
空性 = 无可达接受态。
<span class="marginnote">这种「把性质塞进语言」的手法，是自动机理论里最常用的归约思路。
到第5课我们会看到它的反面——把「不可判定问题」归约到「另一个不可判定问题」，用的是同一种翻译思想，方向却相反。
</span>

## 3 图灵可识别的语言：A_TM

**图灵可识别语言（Turing-recognizable）**：存在一台识别器（对 $L$ 内串接受，对 $L$ 外串**可能不停机**）识别它的语言。

最典型的图灵可识别语言是：

$$A_{TM} = \{ \langle M, w \rangle \mid M \text{ 是图灵机，且 } M \text{ 接受 } w \}$$

**识别器 `U`（通用图灵机）**：输入 $\langle M, w \rangle$，模拟 $M$ 在 $w$ 上的运行；$M$ 接受就接受，$M$ 拒绝就拒绝。问题在于：**若 $M$ 在 $w$ 上永不停机，`U` 也跟着永不停机**——所以 `U` 是识别器，但**不能**保证是判定器。

**辨析｜易错点：** $A_{DFA}$ 可判定而 $A_{TM}$ 只可识别，差别在哪里？模拟 DFA 至多 $|w|$ 步必然结束（DFA 无环可跑无限步），而模拟图灵机**没有步数上界**——机器可能永远跑下去。**「模拟」要成为「判定」，前提是被模拟对象必然停机。**

**一个细化的直觉**：识别器「跑」一个输入时，你永远不知道它是「还在算」还是「永远算不完」。判定器消灭了这个不确定性：它承诺在有限步内给出答案。正是这个「承诺」的存在与否，把可判定语言从可识别语言里分了出来——而 $A_{TM}$ 恰好是「可识别、不可判定」的活标本。

## 4 公式解析：可判定与可识别的刻画

可判定语言与图灵可识别语言之间，有一条极其优美的等价刻画：

$$
L \text{ 可判定} \iff L \text{ 图灵可识别} \ \wedge\ \overline{L} \text{ 图灵可识别}
$$

拆成三步看：

- **第一步，正方向（可判定 ⟹ 双侧可识别）**：若 $L$ 有判定器 $D$，则 $L$ 显然可识别（$D$ 本身就是识别器）；把 $D$ 的接受/拒绝态对调，得到 $\overline{L}$ 的判定器，故 $\overline{L}$ 也可识别。判定器取补：**只需交换 $q_{accept}$ 与 $q_{reject}$**。
- **第二步，反方向（双侧可识别 ⟹ 可判定）**：设 $M_1$ 识别 $L$、$M_2$ 识别 $\overline{L}$。造判定器 `N`：输入 $w$，**交替**运行 $M_1$ 与 $M_2$（各跑一步）：$M_1$ 接受则 `N` 接受，$M_2$ 接受则 `N` 拒绝。因为 $w \in L \cup \overline{L}$ 恒成立，$M_1$、$M_2$ 中恰有一个最终接受——`N` 必停机。
- **第三步，读出意义**：**「不可判定」的本质是「机器和它的补，最多只能识别一个」。** 下一课会证明 $A_{TM}$ 的补 $\overline{A_{TM}}$ 甚至不可识别——于是 $A_{TM}$ 不可判定。

**重点：这条刻画把「判定」翻译成「自己与补都能被机器接受」。** 它是证明「某语言不可判定」的黄金路径：先证该语言可识别，再证它的补不可识别，合起来推出不可判定。

## 5 封闭性质对照

| 运算 | 可判定语言 | 图灵可识别语言 |
| --- | --- | --- |
| 并 | 封闭 | 封闭 |
| 交 | 封闭 | 封闭 |
| 补 | 封闭 | **不封闭** |
| 连接 | 封闭 | 封闭 |
| 星号 | 封闭 | 封闭 |

**重点：可判定语言对补封闭，可识别语言对补不封闭。** 这正是上节刻画的一个推论：若可识别语言都对补封闭，可判定与可识别就重合了——但 $A_{TM}$ 只可识别不可判定，说明补运算是两类语言的分水岭。<span class="marginnote">为什么可识别语言对补不封闭？直觉：识别 $L$ 的机器对 $w \notin L$ 可能「一直跑」，换成补的机器后，这些「永不停机」的串反而成了「应该接受」的串——但我们无法判断一台机器到底在「继续算」还是「永远不算」。这个「无法判断停不停」正是不可判定性的种子。</span>

**一个值得对比的边界案例：** $A_{TM}$ 的补 $\overline{A_{TM}}$ 甚至不可识别，而 $A_{DFA}$ 的补 $\overline{A_{DFA}}$ 显然可判定——只需交换接受与非接受状态。
同为「补」，自动机世界与图灵机世界的待遇天差地别。
这个对比直观地展示了「判定」的边界：**可判定语言对补封闭，而可识别语言不一定**——补运算正是两类语言的分水岭。

这条刻画也给出一个实用的判定技巧：若你能为 $L$ 与其补各造一台识别器，就自动得到 $L$ 的判定器——构造上只需让两台机器交替运行。

## 6 小结

- **可判定语言**存在判定器（对所有输入停机）；**图灵可识别语言**只要求识别器（可对语言外串不停机）。
- $A_{DFA}$、$A_{NFA}$、$A_{CFG}$、$E_{DFA}$、$EQ_{DFA}$ 全部**可判定**——靠「模拟 + 已知算法」。
- $A_{TM}$ 由通用机识别，但**目前只知道它可识别**（是否可判定，下节课揭晓）。
- **刻画定理**：$L$ 可判定 ⟺ $L$ 与 $\overline{L}$ 都可识别。
- 可判定语言对**补封闭**；可识别语言对补**不封闭**。

在下一节，我们将回答那个悬而未决的问题：$A_{TM}$ 是否可判定——答案是否定的，而那正是《停机问题与不可判定性》的主角：对角线的力量将第一次在机器世界露出它的獠牙。
