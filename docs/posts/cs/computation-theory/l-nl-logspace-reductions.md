## 为什么研究「最小的空间」

PSPACE 是「多项式空间」，可现实里更珍贵的是**常数级内存**——嵌入式设备、流式算法、数据库游标，往往只允许你「记住几个数」。
**对数空间**正是「能记住几个数」的数学版本：要用 $O(\log n)$ 位去记住一个「位置」或「计数器」，因为 $n$ 个可能值需要 $\log n$ 位来编号。
于是 **L**（对数空间）与 **NL**（非确定对数空间）成为刻画「极省内存」的类。
<span class="marginnote">为什么 $\log n$ 空间有意义而不是 $O(1)$？
输入长度 $n$ 可变，要在输入上「指位置」就要 $\log n$ 位来存下标；
要在输入上计数也要 $\log n$ 位。
所以 $\log n$ 是「与输入相关的最小工作空间」，它容纳了指针、计数器、栈深等最基本的操作。
</span>

在课程主线上，L 与 NL 是空间谱系的底层，也是「归约」概念最精致的舞台——这里用的**对数空间归约**比多项式归约更严格，因为它要求归约函数本身也极省空间。

## 1 L 与 NL 的定义

**L（对数空间）** = 用 $O(\log n)$ 空间可判定的语言。
**NL（非确定对数空间）** = 用 $O(\log n)$ 空间的 NTM 可判定的语言。

$$
L = SPACE(\log n), \qquad NL = NSPACE(\log n)
$$

**重点：L 里的机器「读输入是只读的，工作区只有 $\log n$ 位」。**
 它不能把输入复制一份（那要 $O(n)$ 空间），只能靠指针在输入上「巡游」，外加几个计数器。
<span class="marginnote">典型的 L 算法例子：判断「输入里第 $i$ 个符号与第 $j$ 个符号是否相同」——用 $\log n$ 位存 $i, j$ 两个下标，指针扫两遍即可。
回文判断的「两头指针向中间扫」也是 L。
</span>

**例：所有正则语言都在 L 中。**
 模拟 DFA：只需一个变量存当前状态（$|Q|$ 种可能，常数位），外加一个指针扫输入。
整个工作区是 $O(1) = O(\log n)$。

## 2 PATH ∈ NL：非确定对数空间的力量

**PATH / STCONN**（s-t 连通性）= $\{\langle G, s, t \rangle \mid G \text{ 有从 } s \text{ 到 } t \text{ 的路径}\}$。

**PATH 在 NL 中。**
 非确定机器怎么做？
它**不存整条路径**（那要线性空间），只存「当前在哪个顶点」：

- 用 $\log n$ 位存当前顶点 $v$，初始 $v = s$。
- 重复：非确定地**猜**下一条边 $(v, u)$，更新 $v = u$。
- 若某步 $v = t$，接受；步数超过 $n$ 还没到，拒绝。

**公式解析：** 这台机器的「聪明」在于用非确定性换来空间：

$$
\text{PATH 的 NL 算法}:\quad v \leftarrow s;\ \text{while } v \ne t:\ v \leftarrow \text{guess}( \{u \mid (v,u) \in E \} )
$$

- **第一步，读「猜邻居」**：$\text{guess}$ 从当前顶点的邻居里非确定地挑一个——不需要记住为什么选它，只需要「存在一条路」。
- **第二步，读空间账本**：全程只存一个顶点 $v$（$\log n$ 位）与一个步数计数器。**路径本身被遗忘，只保留「当前位置」。**
- **第三步，读出为什么是 NL 而非 L**：确定性地找路（BFS）需要队列（可能 $O(n)$），而「猜」让机器免于记住已访问集合——这是非确定性直接兑换成空间节约的经典一幕。

## 3 NL 完全性与对数空间归约

要谈论「NL 中最难的问题」，归约必须**足够廉价**，否则归约本身就把空间烧光了。

**对数空间归约（logspace reduction）$A \le_l B$**：存在可计算函数 $f$（其计算只用 $O(\log n)$ 空间），使 $w \in A \iff f(w) \in B$。

**定理：PATH 是 NL 完全的**（在 $\le_l$ 下）。
任何 NL 语言都能对数空间归约到 PATH。
<span class="marginnote">证明思路：给定 NL 机器 $M$ 与输入 $w$，构造「格局图」$G$——节点是 $M$ 在 $w$ 上的所有格局（对数空间机器只有 $2^{O(\log n)}$ 个格局），边是格局间一步转移。
「$M$ 接受 $w$」就等价于「格局图中从起始格局可达接受格局」，即 PATH。
归约函数建图只用对数空间。
</span>

**推论：$NL \subseteq P$。**
 因为 PATH ∈ P（BFS 多项式时间），而一切 NL 问题归约到 PATH，归约本身多项式时间——于是 NL ⊆ P。

**包含链收束：**

$$
L \subseteq NL \subseteq P \subseteq NP \subseteq PSPACE
$$

**辨析｜易错点：** 对数空间归约比多项式归约**更严格**——任何 $\le_l$ 归约自动是 $\le_p$ 归约（$\log n$ 空间 ⇒ 多项式时间，由空间-时间关系）。
所以 NL 完全性的「难度声明」比 NP 完全性更精细：它把「至少这么难」的标尺压到了极小。

## 4 公式解析：Savitch 与 NL ⊆ SPACE(log²n)

应用 Savitch 定理于 $f(n) = \log n$：

$$
NL = NSPACE(\log n) \subseteq SPACE(\log^2 n)
$$

拆解含义：

- **第一步，读常数基例**：格局图有 $2^{O(\log n)} = n^{O(1)}$ 个节点，步数上界 $t = n^{O(1)}$，$\log t = O(\log n)$。
- **第二步，读递归深度**：Savitch 的 $CANREACH$ 递归深度是 $\log t = O(\log n)$ 层。
- **第三步，读每层空间**：每层存一个格局——$\log n$ 空间。总空间 $O(\log n) \times O(\log n) = O(\log^2 n)$。**非确定性对数空间，确定化后只需对数平方空间。**

所以 $L \subseteq NL \subseteq SPACE(\log^2 n) \subseteq \cdots$，且 $L \stackrel{?}{=} NL$ 是开放的——而它**等价于**「PATH 是否 ∈ L」这一问题。

## 5 惊艳定理：NL = coNL

空间世界最惊人的结果之一来自 Immerman 与 Szelepcsényi（1988，两人分别独立证明）：

$$
\boxed{\;NL = coNL\;}
$$

**非确定性对数空间对补运算封闭。**
 这之所以惊艳，是因为在时间世界，$NP \stackrel{?}{=} coNP$ 至今未决；
而在空间世界，答案竟是「相等」。

证明的核心是给 PATH 的补（「不存在从 $s$ 到 $t$ 的路径」）设计一个 NL 算法。
难点：如何**非确定地**验证「没有路径」？
思路是**计数**——非确定地猜「从 $s$ 出发 $i$ 步内可达的顶点数」，再验证这个数，从而排除「$t$ 可达」的可能。
<span class="marginnote">这是「验证不存在性」的范式：<strong>先猜一个数量，再验证数量本身</strong>——如果猜的数量等于真实的可达数，且 $t$ 不在可达集里，就没有路径。
Immerman 的计数技巧至今仍是去随机化与描述复杂性的重要工具。
</span>

**重点：NL = coNL 说明「非确定性 + 对数空间」这个组合足够强壮，对补免疫。**
 这为后来的「NL 是自身的补」以及广义空间层次的封闭性质铺平了道路。

## 6 L 与 NL 的实践风味

**流式算法**：在只允许 $O(\log n)$ 内存的流上统计、判定——这就是 L 的工程化身。数据库与网络设备里的「一趟算法」本质上在 L/NL 附近工作。
**与数据库查询**：一阶逻辑可定义、可在一趟扫描中判定的查询，与对数空间类有深刻联系——这预告了描述复杂性（以逻辑刻画复杂性类）的方向。<span class="marginnote">描述复杂性理论（Fagin 开创）把「复杂度类」重新定义为「逻辑语言可定义的查询集合」。比如 NP 恰是「存在量词逻辑（SO∃）可定义」的类。用逻辑而非机器描述计算，是理解「复杂性类为什么长这样」的另一扇窗。</span>

## 7 小结

- **L** = $SPACE(\log n)$，**NL** = $NSPACE(\log n)$——极省内存的类，工作区只够存指针与计数器。
- **PATH ∈ NL**：只存当前顶点、非确定地猜下一条边——用非确定性兑换空间。
- **PATH 是 NL 完全的**（对数空间归约下）；**NL ⊆ P**。
- **Savitch** 给出 $NL \subseteq SPACE(\log^2 n)$；**Immerman-Szelepcsényi** 给出 **NL = coNL**。
- 包含链：$L \subseteq NL \subseteq P \subseteq NP \subseteq PSPACE$；$L \stackrel{?}{=} NL$
