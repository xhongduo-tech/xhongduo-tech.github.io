## 为什么需要下推自动机

上节课我们说 CFG 能生成任意深嵌套，但「能生成」不等于「有机器识别」。
要给 CFL 配一台执行模型，需要在 DFA 的基础上加一样东西：**栈（stack）**。
**下推自动机（pushdown automaton, PDA）** 就是「有限自动机 + 一个栈」——栈给了它**无界的记忆**，但只用**后进先出（LIFO）**这一种方式读写。
<span class="marginnote">栈的「后进先出」约束非常关键：它让 PDA 只能「回溯最近打开的括号」，而不能随意跳回任意位置。
正是这种「有限 + 一条栈」的组合，让 PDA 恰好识别上下文无关语言——比正则强、比图灵机弱。
</span>

在课程脉络里，PDA 是「识别 CFL 的机器」，与 CFG（生成 CFL 的语法）配对。
**语法与机器的等价**——正则表达式↔DFA、CFG↔PDA、图灵机↔可计算函数——是计算理论反复奏响的同一主题：同一个语言类，总有一半是「描述」、一半是「识别」。

## 1 下推自动机的定义

**下推自动机（PDA）**：一个六元组

$$P = (Q, \Sigma, \Gamma, \delta, q_0, F)$$

与 DFA 相比，新增了两个成分：

- $\Gamma$：**栈字母表（stack alphabet）**——可以写进栈的符号。
- $\delta: Q \times \Sigma_\varepsilon \times \Gamma_\varepsilon \to \mathcal{P}(Q \times \Gamma_\varepsilon)$：**转移函数**，输入三元组（当前状态、读到的输入符号、栈顶符号），输出一组「（新状态、写到栈顶的符号）」——后者为空串 $\varepsilon$ 表示**弹出**栈顶。

一条转移 $(q, a, b) \to (r, c)$ 的含义：在状态 $q$，读到输入 $a$，栈顶是 $b$；弹出 $b$，进入状态 $r$，把 $c$ 压入栈顶。若 $c = b$ 则是「读一下不改」；若 $c = \varepsilon$ 则是「弹出」；若 $b = \varepsilon$ 则是「不关心栈顶（但压入 $c$）」。<span class="marginnote">$a$ 也可为 $\varepsilon$——表示「不读输入也能转移」。所以 PDA 在每一步可以：只动栈不动输入（$a = \varepsilon$），或只读输入不动栈（$b = \varepsilon$ 且 $c = b$），或两者都做。</span>

**重点：PDA 的记忆不是「状态」而是「栈的内容」。** 状态仍是有限的，但栈可以长到任意高——记忆的「量」无限，「形」却只能是一条栈。

## 2 用 PDA 识别 &#123;0ⁿ1ⁿ&#125;

为 $\{0^n 1^n \mid n \ge 1\}$ 造一台 PDA。思路：读到 $0$ 就压栈，读到 $1$ 就弹栈，最后检查栈是否恰好弹空。

三状态机器（$q_0$ 读 0 压栈、$q_1$ 读 1 弹栈、$q_2$ 接受）：

$\delta(q_0, 0, \varepsilon) = \{(q_0, X)\}$：读到 0，压一个记号 $X$ 进栈。
$\delta(q_0, 1, X) = \{(q_1, \varepsilon)\}$：第一次读到 1，弹掉一个 $X$，进入 $q_1$。
- $\delta(q_1, 1, X) = \{(q_1, \varepsilon)\}$：继续读 1，继续弹 $X$。
- $\delta(q_1, \varepsilon, \varepsilon) = \{(q_2, \varepsilon)\}$：输入读完且栈空（栈底记号已露），进入接受态。

运行 `0011`：压 $X,X$；读到第一个 1 弹一个 $X$；第二个 1 再弹一个；此时栈空、输入读尽 → 接受。运行 `001`：弹了两个 $X$ 后栈空，可输入还剩一个 1，无处可走 → 拒绝。<span class="marginnote">注意「栈空」如何表达：通常栈底先压一个记号 `$`（栈底标记），$q_1$ 时用 $\varepsilon$-转移探底。这里简化为「弹尽即入接受态」，形式细节以 Sipser 定义为准。</span>

## 3 公式解析：PDA 一步转移的签名

PDA 的转移函数是最容易让人晕的地方，它的输入输出都带「可空」选项：

$$
\delta(q,\, a,\, b) \ni (r,\, c), \qquad q, r \in Q,\ a \in \Sigma \cup \{\varepsilon\},\ b, c \in \Gamma \cup \{\varepsilon\}
$$

拆成四步看：

- **第一步，读输入坐标 $a$**：$a \in \Sigma \cup \{\varepsilon\}$。$a$ 是真符号则必须读掉一个输入；$a = \varepsilon$ 则本次转移不消耗输入。
- **第二步，读栈顶坐标 $b$**：$b$ 是当前栈顶必须匹配的符号；$b = \varepsilon$ 表示「不查栈顶」，任何栈顶都能走这条转移。
- **第三步，读输出栈符号 $c$**：$c$ 是转移到新状态时压入栈顶的符号；$c = \varepsilon$ 表示只弹不压；$c = b$ 表示栈不变。
- **第四步，读出非确定性**：$\delta$ 的返回值是一个**集合** $\{(r,c), (r', c'), \dots\}$——同一步可以有多条路，与 NFA 的非确定性同源。只要有**一条**路走到接受态，PDA 就接受。

## 4 核心定理：PDA 与 CFG 等价

**定理：** 一个语言是上下文无关语言，当且仅当它被某个 PDA 识别。

**CFG → PDA（自上而下）**：让 PDA 用栈模拟「派生过程的未完成部分」。开始时栈顶是起始变元 $S$；遇到变元就弹出来、压入它的某个规则的右端（倒序）；遇到终结符就与输入比对，匹配则弹出、推进输入；栈空时接受。**栈里的东西 = 派生树里还没长出来的叶子**——这就是「栈跟踪树的生长」的具体化。

**PDA → CFG**：反向构造较复杂（Sipser 第2章末的定理 2.20），思路是把「从状态 $p$ 出发、栈顶为空、最终状态 $q$、栈回到空」的整段计算，编码成变元 $A_{pq}$，再把每条转移翻译成产生式。**语法与机器的桥梁由此建立。**

**辨析｜易错点：** 与正则语言不同，PDA 的**确定性版本（DPDA）严格弱于非确定版本**。存在上下文无关语言（如 $\{ww^R\}$——回文串）能被非确定 PDA 识别，却没有任何 DPDA 能识别。原因：识别回文需要「猜中点」，而 DPDA 每一步都唯一，猜不了。**非确定性在正则世界不增力，在上下文无关世界增力**——这是两类模型的重要分水岭。

## 5 两种接受方式

PDA 的接受有两种习惯，定理保证二者等价：

- **按接受状态接受**：读完整输入后停在某个 $F$ 状态。
- **按空栈接受**：读完整输入后栈恰好为空（用 $\varepsilon$-转移进入空栈状态）。

**重点：两种接受方式的等价可以互相翻译。** 空栈接受 → 状态接受：给机器加一个栈底标记，最后让「栈空」转移到新接受态。状态接受 → 空栈接受：加一个「清栈」过程，读到输入结束时把所有栈内容弹出。这条「翻译」技术，是证明 PDA 与 CFG 等价时的常用零件。

| 模型 | 记忆 | 能识别的语言类 |
| --- | --- | --- |
| DFA | 无（纯有限状态） | 正则语言 |
| NFA | 无（纯有限状态） | 正则语言（同 DFA） |
| DPDA | 一条栈，确定性 | 确定上下文无关语言（⊊ CFL） |
| PDA（非确定） | 一条栈，可猜 | 上下文无关语言 |

这张表值得记住：**从左到右，记忆与不确定性同时增加；只有 PDA 一步，「非确定性」从免费变成了付费。**

**DPDA 与编译器的关系值得单独一提：** 大多数程序设计语言的语法由 DPDA 可解析（LL、LR 文法），这是编译器语法分析的工程基础。
但「所有 CFL 都能用 DPDA 解析」是错误的——需要非确定性的语言（如回文 $\{ww^R\}$）只能用通用 CFG 解析算法（如 CYK、Earley）处理，代价是更高阶的时间复杂度。
这再次说明：**非确定性不是免费的**——它在 PDA 这里第一次收下了「多算能力」的账单。

给一个动手建议：把 $\{0^n1^n\}$ 的 PDA 与正则版 DFA 并排画出来，你会发现差别只在「那条栈」——去掉栈，PDA 就退化成一台 DFA。
**栈是唯一的分水岭**，也是理解一切自动机强弱关系的钥匙。

与正则语言的对照值得记牢：**NFA 之于 DFA 不增力，PDA 之于 DPDA 却增力**——这个不对称来自栈的「不可回看」特性，让「猜」第一次有了真正的价值。

这条「记忆形态决定语言类」的线索，到第2篇图灵机将走到终点——无限可读写纸带把语言类推到极限，而极限之外是不可判定。

## 6 小结

- **PDA** = 有限自动机 + 一条栈，六元组 $(Q, \Sigma, \Gamma, \delta, q_0, F)$。
- 转移 $\delta(q,a,b) \ni (r,c)$ 的含义：读 $a$、查栈顶 $b$、弹 $b$、进 $r$、压 $c$；三者各自可空。
- PDA 的**记忆在栈里**：无限长度、但只有 LIFO 一种读写方式。
- **核心定理**：CFL ⇔ 被某 PDA 识别；CFG 的派生树 = PDA 栈里「未完成的树」。
- 与正则语言不同：**非确定性让 PDA 变强**（DPDA ⊊ PDA）。
- 接受可用**接受状态**或**空栈**定义，二者等价。

在下一节，我们将像正则语言那样，为 CFL 建立**泵引理**——把「数不深」的界限推广到带栈的世界，并系统研究 CFL 的封闭性质。
