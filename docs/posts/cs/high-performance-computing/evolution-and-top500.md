## 为什么从高性能计算开始

从单核 CPU 到万亿次、亿亿次的超级计算机，「快」从来不是免费的。

它背后有一整条因果链：

芯片越做越快，功耗就越高；

功耗高到散热跟不上，主频就撞墙；

主频撞墙，厂商就转向「多核」与「并行」。

<span class="marginnote">摩尔定律的减速（2004 年前后主频撞上功耗墙）直接催生了「多核 + 并行」这条主线，这是本专题全部内容的出发点。</span>

这一篇回答三个问题：

高性能计算（HPC）是怎么来的？

今天哪些机器跑在最前面？

用什么尺子来衡量一台超算的快慢？

它是整个专题的序章。

后面讲并行机结构、并行编程模型、并行算法，都是在这条历史与度量轴上展开。

## 1 从串行到并行：性能墙的出现

早期计算机是**串行（sequential）**的：

一条指令接一条指令，一个进程独占所有资源。

1950 年代的 ENIAC 每秒只能做几千次加法，1970 年代的 Cray-1 用向量处理把浮点性能推到亿次。

这条路上真正的主角是**频率**——主频越高，单核越快。

<span class="marginnote">Cray-1（1976）开创了「让计算机牺牲一切换取浮点峰值」的设计哲学，至今仍是超算文化的一部分。</span>

但 2004 年前后，物理定律拦住了这条路。

**功耗与热密度**随频率呈超线性上升，散热跟不上了。

业界把这次危机称为**功耗墙（power wall）**。

既然单核难以为继，厂商掉头转向：

在一个芯片上放多个核。

于是：

单核主频停滞在 3–5 GHz 附近；
核心数开始翻倍：双核、四核、几十核；
每一代新机器换来的算力增量，不再来自「更快」，而来自「更多、更并行」。

**并行（parallelism）**由此从学术实验变成工业常态。

一台今天的顶级超算里有上百万个计算核，它们同时工作、交换数据、协同求解同一个问题——这就是高性能计算的全部底色。

## 2 并行计算机的四十年演进

把「很多核放一起」这件事做到极致，就出现了**超级计算机（supercomputer）**。

其演进大体可分四代：

**第一代（向量机时代，1970s–1980s）**：以 Cray-1 为代表，靠流水线让一条指令同时处理一串数据。并行藏在处理器内部，程序员几乎无感。
**第二代（大规模并行处理 MPP，1980s–1990s）**：用几千个普通微处理器通过高速网络连成一台机器，代表是 Thinking Machines 的 CM-5。并行第一次暴露给程序员，MPI 应运而生。
**第三代（集群与商品化，1990s–2000s）**：网络和 PC 太便宜了，把大量服务器用以太网连起来就是集群（cluster）。1990 年代的 Beowulf 项目证明，集群能拿下传统超算的活。
**第四代（异构与能效时代，2000s 至今）**：GPU 作为加速器大规模进场，Top500 榜首机器几乎全部依赖 CPU+GPU 异构架构。

<span class="marginnote">2018 年起，「百亿亿次」（exascale）成为新的赛点，代表机器有美国的 Frontier、日本的 Fugaku 与中国曙光、神威系列。</span>

这条演进路径暗含一个判断：

**单机性能到头了，性能增量只能来自并行度与能效。**

也正因如此，学 HPC 的入口不是某一台机器，而是「并行」这两个字。

## 3 Top500：用基准说话

光说「我的机器很快」没用，得有一个公认的尺子。

1993 年起，每年发布两次的 **Top500 榜单**就成了 HPC 世界的奥运会。

<span class="marginnote">Top500 每半年更新一次（6 月与 11 月），网址 top500.org，数据完全公开。</span>

它的核心基准是 **LINPACK**：

求解一个稠密线性方程组 $Ax = b$，测出机器实际达到的浮点运算速度，单位是 **FLOPS**（每秒浮点运算次数）。

| 量级 | 名称 | 每秒运算次数 |
| --- | --- | --- |
| $10^6$ | 兆（mega）FLOPS | 一百万次 |
| $10^9$ | 吉（giga）FLOPS | 十亿次 |
| $10^{12}$ | 太（tera）FLOPS | 万亿次 |
| $10^{15}$ | 拍（peta）FLOPS | 千万亿次 |
| $10^{18}$ | 艾（exa）FLOPS | 百亿亿次 |

2017 年前后人类跨过百亿亿次门槛的前夜，2022 年美国橡树岭的 Frontier 成为首台公开宣称突破 1 exaFLOPS 的机器。

中国在 2010 年天河一号、2013 年天河二号两度登顶，神威·太湖之光在 2016 年凭**全自主国产处理器**拿下第一。

## 4 核心对比：串行世界与并行世界

这是一个偏概念的主题，用一张表把两种范式的差别钉死：

| 维度 | 串行计算 | 并行计算 |
| --- | --- | --- |
| 硬件前提 | 单核单处理器 | 多核 / 多机 / 加速器 |
| 时间来源 | 处理器本身变快 | 多处理器「同时」工作 |
| 增长瓶颈 | 主频（功耗墙） | 通信、同步、负载不均 |
| 度量指标 | 单条指令时间 | 加速比、效率、规模 |
| 编程方式 | 顺序执行天然正确 | 必须显式管理分解与通信 |
| 主要失效模式 | 性能慢 | 正确性难、加速比上不去 |

**辨析｜易错点：** 并行计算 ≠ 多线程编程。

多线程只是并行的**一种实现形态**（共享内存），而本专题还覆盖多机（分布式内存）、GPU 等更宽的谱系。

另一方面，**并行（parallel）是同时执行，并发（concurrent）只是交替执行**——两个概念在操作系统课程里要反复区分。

## 5 小结

- **功耗墙**终结了「主频快 = 机器快」的时代，并行成为唯一出路。
- 超算演进四代：**向量机 → MPP → 集群 → 异构加速**，GPU 是当下主流。
- **Top500** 每半年发布，核心基准 **LINPACK**，度量单位是 **FLOPS**。
- 当前量级是 **exaFLOPS（$10^{18}$）**，能效与国产化是两条重要线索。
- 并行世界的三个核心代价：**通信、同步、负载不均**——它们将贯穿全专题。
