## 为什么 SSD 快但不简单

机械硬盘靠盘片旋转与磁头移动，SSD 靠**闪存（Flash）**电子存储——没有机械运动，所以快得惊人。但闪存的「先擦后写、按块擦除、寿命有限」特性，让 SSD 内部藏着一个复杂的 **FTL（闪存转换层）** 固件。本课讲 SSD 的结构（闪存芯片 + FTL + 接口）、读写特性（页/块、写放大、磨损均衡）与性能特点。<span class="marginnote">「SSD 是披着硬盘外衣的闪存系统」：对外是标准块设备接口（SATA/NVMe），对内是闪存 + 复杂的 FTL 固件。FTL 把闪存的「别扭」隐藏起来，让操作系统以为它是普通磁盘——这层「翻译」是 SSD 设计的核心。</span>

## 1 SSD 的物理结构SSD = 闪存芯片阵列 + 控制器（含 FTL）+ DRAM 缓存 + 接口（SATA/NVMe）。

闪存的分层：

- **页（page）**：读写单位，通常 4–16KB。
- **块（block）**：擦除单位，通常 128–512 页（几 MB）。

$$\text{读/写以页为单位，擦除以块为单位}$$

**核心概念：SSD 的读写粒度不对称**——读/写按页（快），擦除按块（慢）。<span class="marginnote">对比磁盘：读写都是扇区（512B/4KB）为单位，对称。SSD 的「读写页、擦除块」不对称是它一切设计（FTL、写放大、垃圾回收）的根源——数据不能直接覆盖，要先整块擦除。</span>

## 2 闪存的三态与「先擦后写」闪存单元的状态：

- **写（编程）**：把 1 变成 0（注入电荷）。
- **读**：检测电荷状态。
- **擦除**：把整块恢复成全 1（放掉电荷）。

**关键限制：只能把 1 写成 0，要把 0 变回 1 必须整块擦除**——所以「覆盖写」要先擦块。

**核心概念：闪存不能「原地覆盖」**——写一个页，若该页已有数据，必须先擦除整块或写到新位置。<span class="marginnote">「不能原地覆盖」导致 SSD 的写入策略是「写新弃旧」：新数据写到空页，旧页标记为「失效」，等垃圾回收再擦——这与《ROM 与闪存》一课的「只能 1→0、整块擦」一脉相承。</span>

## 3 FTL：闪存转换层**FTL（Flash Translation Layer）** 是 SSD 固件的核心，提供三块能力：

### 逻辑-物理地址映射

操作系统看到的是「逻辑块地址（LBA）」，闪存实际用「物理页地址」——FTL 维护映射表，把逻辑地址翻译到物理页。

### 垃圾回收（GC）

失效页累积后，FTL 在后台**搬移有效页、擦除整块**，腾出空块——叫垃圾回收。

### 磨损均衡（Wear Leveling）

每块擦写次数有限（TLC 约 1000–3000 次）——FTL 均匀分配擦写，避免热块早死。

**核心概念：FTL 让 SSD「看起来像普通磁盘」，同时隐藏了写放大、磨损、GC 的所有复杂性**。<span class="marginnote">FTL 是 SSD 的「操作系统」：映射（像页表）、GC（像内存回收）、磨损均衡（像负载均衡）。它让闪存从「别扭的硬件」变成「好用的磁盘」——也是 SSD 比 HDD 贵、且不同 SSD 性能差异巨大的原因（FTL 固件质量决定一切）。</span>

## 4 公式解析：写放大**写放大（write amplification, WA）**：主机写入的数据量与实际闪存写入量的比值。

$$\text{WA} = \frac{\text{实际写入闪存的量}}{\text{主机请求写入的量}}$$

例：主机写 4KB，FTL 为腾块要搬移 8KB 有效页 + 写 4KB 新数据 = 12KB 实际写：

$$\text{WA} = \frac{12}{4} = 3$$

逐项拆解：

- **第一步，随机小块写**：逻辑上写 4KB，物理上要「搬旧页 + 写新页」。
- **第二步，垃圾回收放大**：GC 时搬移有效页也算写入。
- **第三步，WA>1 的代价**：写寿命缩短（闪存写入次数是有限的）、性能下降。

**核心结论：写放大把「有限寿命」进一步消耗——降低 WA 是 SSD 固件优化的头号目标**。<span class="marginnote">「降低写放大」的手段：增大预留空间（OP）、写合并（把相邻小写合并成大写）、后台 GC 错峰、日志式写入。数据库的「顺序写优先」也大幅降低 WA——所以 SSD 上的数据库依然讲究顺序 I/O，虽然寻道已不是问题，但「写放大」接替了「寻道」成为新的瓶颈。</span>

## 5 辨析｜易错点：SSD 概念**辨析｜易错点：**

- **SSD 随机读比 HDD 快得多（无寻道），但随机写也有代价**：写放大 + GC 让随机写变慢——「SSD 随机写也快」要打折扣。
- **「读不磨损、写磨损」**：SSD 的寿命与写入量成正比，与读无关——「读太多伤 SSD」是误解。
- **SSD 不用磁盘调度（无寻道）**：但 FTL 的 GC 调度、磨损均衡仍是「调度」——只是对象不同。
- **掉电安全**：SSD 的写缓冲（DRAM 缓存）掉电丢数据，需要「掉电保护」——「SSD 不怕掉电」不准确。

## 6 拓展：SSD 的「顺序 vs 随机」为何重要SSD 没有寻道，但「顺序 vs 随机」仍然重要——因为**写放大**：

- 顺序写：数据连续落到空块，几乎不触发垃圾回收，写放大≈1。
- 随机写：每次写一个 4KB 页，FTL 为腾块要搬移整个块的有效页，写放大可达 3–10。

**核心概念：SSD 的性能关键词从「寻道」变成了「写放大 + GC」**——随机写的代价藏在固件层，不是「磁头移动」而是「搬移有效页」。

**辨析｜易错点：**「SSD 随机读快、随机写也快」要打折扣——随机读确实快（无寻道），随机写受写放大拖累。所以数据库在 SSD 上依然讲究「顺序写日志」（WAL）——把随机写变成顺序写，降写放大。

## 7 补充：SSD 速记- 结构：闪存 + 控制器（FTL）+ 缓存 + 接口。
- 读写页、擦除块；只能 1→0，覆盖要先擦块。
- FTL：地址映射 + 垃圾回收 + 磨损均衡。
- 写放大 = 实际写/逻辑写，>1 消耗寿命。
- SSD 快在无机械、慢在写放大+GC；寿命与写量挂钩。

## 8 一句话回顾- SSD 快在无机械、慢在写放大 + GC。
- 读写页、擦除块；FTL 做映射、GC、磨损均衡。
- 顺序写降写放大，随机写消耗寿命。

> 记住：SSD 的性能关键词是「写放大」而非「寻道」。

## 9 核心要点
- 读写以页（4-16KB）为单位，擦除以块为单位。
- 写放大 WA = 实际写入 / 主机请求写入。
- 磨损均衡让所有块擦写均匀。
- FTL 三能力：地址映射、垃圾回收、磨损均衡。
- 随机写触发 GC，写放大 3-10；顺序写 ≈1。

## 10 小结- SSD 结构：闪存芯片 + 控制器（FTL）+ 缓存 + 接口。
- **读写页、擦除块**：粒度不对称；只能 1→0，覆盖要先擦块。
- **FTL**：地址映射 + 垃圾回收 + 磨损均衡，把别扭的闪存伪装成磁盘。
- **写放大**：实际写 / 逻辑写，>1 消耗寿命、拖慢性能。
- SSD 快在「无机械」，慢在「写放大 + GC」；寿命与写量挂钩。
