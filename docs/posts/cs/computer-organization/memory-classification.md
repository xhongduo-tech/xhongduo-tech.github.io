## 为什么存储器要先「分类」

从 CPU 里的寄存器到云端的数据库，存储设备的容量差了十多个数量级，速度差了百万倍。把它们放在同一张图里讨论，必须有一套分类框架。这一课用三种视角给存储器分类：**按介质**（物理原理）、**按存取方式**（读写机制）、**按作用**（在系统里的角色）。这套分类是理解「存储器层次结构」的前提——层次结构正是「把不同类的存储器按速度与容量组织成一个整体」的工程答案。<span class="marginnote">「没有一种存储技术能同时做到快、大、便宜」是存储领域的铁律。这个矛盾催生了整个存储器层次结构，也催生了缓存、虚拟内存等一切技术。</span>

## 1 按存储介质分类**存储介质**：用来记录 0/1 的物理材料，分两大类：

**半导体存储器**：用晶体管电路存储，速度快，用作主存与缓存。
**易失性（volatile）**：断电丢数据——SRAM、DRAM。
**非易失性（non-volatile）**：断电不丢——ROM、闪存（Flash）。
**磁表面存储器**：用磁化方向记录，非易失、容量大、速度慢——磁盘、磁带。
**光存储器**：用凹凸坑记录激光反射差异——CD、DVD、蓝光。

| 介质 | 易失性 | 速度 | 容量 | 典型用途 |
| --- | --- | --- | --- | --- |
| SRAM | 易失 | 最快 | 小 | Cache |
| DRAM | 易失 | 快 | 大 | 主存 |
| 闪存 Flash | 非易失 | 中 | 大 | SSD、U 盘 |
| 磁盘 | 非易失 | 慢 | 极大 | 辅存、机械硬盘 |
| 光盘 | 非易失 | 慢 | 大 | 分发、归档 |

<span class="marginnote">「易失性」是断电数据是否保留的属性，与速度无关。ROM 虽然叫「只读」，但闪存等现代非易失芯片已支持写入——「ROM」这个叫法是历史遗留，详见《只读存储器 ROM》一课。</span>

## 2 按存取方式分类存取方式决定「怎么找到数据」：

**随机存取（Random Access）**：按地址直接访问任意单元，访问时间与地址无关。SRAM、DRAM 都是随机存取。
**顺序存取（Sequential Access）**：只能从起点顺序读，访问时间与位置有关。磁带是典型——找中间的记录要倒带。
**直接存取（Direct Access）**：先随机定位到「磁道」，再顺序找「扇区」。磁盘介于随机与顺序之间。
**按内容存取（Content-Addressable）**：不按地址，按「内容」查找。相联存储器（CAM）就是——TLB 快表的硬件基础。

**重点：随机存取 vs 顺序存取是区分「内存思维」与「外存思维」的钥匙**。内存地址就是「第几个单元」，O(1) 访问；外存则要先寻道再扫描。<span class="marginnote">这个区别直接影响算法设计：数组在内存里是随机存取，在磁盘上却退化为顺序扫描——所以数据库用 B+ 树把随机 I/O 变成顺序 I/O，见《数据库》专题。</span>

## 3 按作用分类（在系统中的地位）按在计算机中的作用，存储器分为三大类：

**主存储器（main memory）**：CPU 直接访问，存正在运行的程序与数据。通常是 DRAM，按地址随机存取。容量以 GB 计。
**辅助存储器（secondary storage）**：CPU 不能直接访问，先读入主存才能用。磁盘、SSD。容量以 TB 计，非易失。
**高速缓冲存储器（cache）**：夹在 CPU 与主存之间，用 SRAM 存主存的副本，利用局部性加速访问。

外加**控制存储器（control store）**：存微程序（微程序控制器的指令），是 CPU 内部专用的「小内存」。<span class="marginnote">「辅存不能被 CPU 直接访问」是常考结论：CPU 访问磁盘上数据，必须通过 DMA/中断先把块读入主存，再按地址访问。这个「主存是唯一接口」的结构，到第八篇《输入输出系统》会展开。</span>

## 4 公式解析：存储器的核心指标衡量一个存储器有四组指标：

$$C = \text{容量} = \text{存储字数} \times \text{字长}, \qquad T_A = T_{\text{寻址}} + T_{\text{读出}}$$

$$\text{带宽} = \frac{\text{一次读写的数据量}}{\text{一次存取时间}}$$

逐项拆解：

- **容量 $C$**：如「64K × 16」表示 64K 个字、每字 16 位，容量 = $64\text{K}\times16$ bit = 128 KiB。
- **存取时间 $T_A$**：从发出访问请求到数据稳定的时间，含寻址（选行选列）与读出。
- **存取周期 $T_M$**：连续两次独立访问的最小间隔，比 $T_A$ 略大（含恢复时间）。
- **带宽**：单位时间的传输量，是吞吐视角。

**辨析｜易错点：**「存取时间」与「存取周期」是两个概念：周期 ≥ 时间，因为一次访问后电路要恢复。考试常考这两个词的区别。<span class="marginnote">带宽的工程意义：现代 GPU 需要几百 GB/s 的显存带宽，普通 DDR4 主存约 20–50 GB/s，SSD 约 1–7 GB/s——差一到两个数量级。这就是「存储墙」（memory wall）问题的量化来源。</span>

## 5 辨析｜易错点：三个易混分类维度**辨析｜易错点：**

- **易失 ≠ 慢、非易失 ≠ 快**：DRAM 易失但比非易失的闪存快；闪存非易失但比 DRAM 慢。分类维度彼此独立。
- **「随机存取」指时间均匀，不是「随机选」**：RAM 的名字 Random Access 强调「任意地址等时间」，与「顺序存取」相对。
- **ROM 不一定只读**：EPROM、EEPROM、闪存都能改写，只是写入方式特殊（整块擦除、写寿命有限）。「ROM」是「只读型」的统称，详见《只读存储器 ROM》一课。
- **主存 ≠ 内存**：口语「内存」通常指主存；严格说寄存器、缓存也在「内存」的大范畴内。考试用词以教材定义为准。

## 6 拓展：存储器分类的「一句话速记」把三种分类维度各用一句话钉死：- **按介质**：半导体（SRAM/DRAM/ROM/Flash）、磁表面（磁盘）、光（光盘）——物理记录原理。
- **按存取**：随机（RAM，等时间）、顺序（磁带，从头找）、直接（磁盘，先寻道后顺序）、按内容（CAM）——找数据的方式。
- **按作用**：主存（CPU 直接访问）、辅存（要调主存才能用）、Cache（加速）、控制存储器（存微程序）——在系统里的角色。

**核心概念：三个分类维度互相独立**——DRAM 是「半导体 + 随机 + 主存」，磁盘是「磁表面 + 直接 + 辅存」，SRAM 是「半导体 + 随机 + Cache」。一个设备同时属于三个维度的某个值。

**辨析｜易错点：**「易失性」与「存取方式」无关——DRAM 易失但随机存取，闪存非易失也是随机存取。别把「断电丢不丢」和「怎么找数据」混为一谈。
