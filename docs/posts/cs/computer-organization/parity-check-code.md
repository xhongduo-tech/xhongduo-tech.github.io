## 为什么需要校验码

内存读出、磁盘传输、网络通信——比特在物理世界里旅行，随时可能被噪声翻转。校验码（error-detecting/correcting code）就是给数据「上保险」：加几个冗余位，让接收方能够**发现**甚至**纠正**错误。本课从最简单的**奇偶校验（parity check）**讲起：它只加 1 位，只能发现奇数个错误，但却是理解海明码、CRC 的起点。<span class="marginnote">奇偶校验至今仍活跃：内存条的 ECC 是其升级版、串口通信的校验位、RAID 5 的奇偶盘——都是「加一位冗余换错误检测」的思想。</span>

## 1 奇偶校验的定义**核心概念：奇偶校验码**：在有效信息位后增加一位**校验位**，使整个码字中「1」的个数满足约定。

- **偶校验（even parity）**：码字中 1 的个数为偶数。
- **奇校验（odd parity）**：码字中 1 的个数为奇数。

设信息位为 $D = d_{n-1}\cdots d_1 d_0$，校验位 $P$ 由信息位异或得到：

$$P_{\text{偶}} = d_{n-1} \oplus d_{n-2} \oplus \cdots \oplus d_0$$

$$P_{\text{奇}} = \overline{d_{n-1} \oplus d_{n-2} \oplus \cdots \oplus d_0}$$

例：信息位 `1011`，1 的个数为 3（奇数）。偶校验需要补一个 `1` 使总数变 4（偶数），码字为 `10111`（信息 `1011` + 校验 `1`）。<span class="marginnote">校验位放在最前或最后都有约定，关键是在收发双方约定一致。教材里常把校验位放最左或最右，考试看题目标注。</span>

## 2 奇偶校验的检错能力奇偶校验能发现**奇数个**比特错误，发现不了**偶数个**：

1 个错误：1 的奇偶性翻转 → 检出。
2 个错误：两个 1 同时翻转（或 0→1 与 1→0 配对），奇偶性不变 → **漏检**。
3 个错误：翻转 3 次，奇偶性变 → 检出。

用「码距」语言表达：奇偶校验码的**最小码距为 2**（任意两个合法码字至少差 2 位），而码距 2 的检错能力就是「检 1 位错」。

**核心概念：码距（Hamming distance）**：两个等长码字中对应位不同的个数。校验码的检错/纠错能力完全由最小码距决定：

码距 $d$ 能检测 $d-1$ 位错误，能纠正 $\lfloor (d-1)/2 \rfloor$ 位错误。<span class="marginnote">这是编码理论的「第一定理」：海明距离 $d$ 的码，检错能力 $e$ 与纠错能力 $t$ 满足 $e + t \le d-1$。奇偶码 $d=2$，只能检 1 位错、不能纠错。</span>

## 3 公式解析：奇偶校验为什么「检不出偶数个错」

设码字 $C = D \parallel P$，偶校验满足：

$$\bigoplus_{i} C_i = P \oplus d_{n-1} \oplus \cdots \oplus d_0 = 0$$

逐项拆解：

- **第一步，生成**：校验位使全体异或为 0（偶数个 1）。
- **第二步，传输**：比特流经过信道，其中某些位翻转。
- **第三步，检测**：接收方重新计算全体异或。若结果为 0，认为无错；非 0 则报错。
- **第四步，偶数个错**：两个翻转位贡献了两次「改变 1 的个数」——一增一减，总和不变，异或仍为 0 → 漏检。

**结论**：奇偶校验的检错率不是 100%，而是「奇数个错必检、偶数个错漏检」。对独立随机噪声，1 位错误最常见，所以它性价比很高。<span class="marginnote">在存储设备里，错误多为「一位翻转」（如宇宙射线击中 DRAM 单元），奇偶校验因此够用；但 RAID 磁盘阵列里的整块坏盘是「系统性错误」，需要更强的编码——那就是《RAID》一课的话题。</span>

## 3 纵向奇偶校验与二维奇偶校验单个校验位太弱，工程上常做扩展：- **纵向奇偶校验（LRC）**：把数据按块组织，每行一个奇偶位，能定位错误在哪一行。
**二维奇偶校验**：行列都加奇偶位（方块校验）。行列交叉能**定位**单个错误的位置，从而**纠正**它。

```
信息位（3×3）     行校验位
1  0  1   →      0     （101 有 2 个 1，补 0）
0  1  0   →      1     （010 有 1 个 1，补 1）
1  1  0   →      0     （110 有 2 个 1，补 0）
──────────────────────────────
列校验位  0  0  1       1
```

若某位出错，其所在行与所在列的校验都失败，交叉点即错误位置——**用 $O(\sqrt n)$ 个冗余位换来了 1 位纠错能力**。<span class="marginnote">二维奇偶是「纠错」的启蒙：它说明只要冗余足够、组织得当，就能从「检测」升级为「纠正」。海明码就是把这一思想系统化的产物。</span>

## 4 辨析｜易错点：奇偶校验的边界**辨析｜易错点：**- **奇偶位本身也可能出错**：校验位被翻转时，检测同样会失败——所以「校验失败」只能说明「有奇数个错」，不能确定错在信息位还是校验位。
- **不能纠错**：奇偶校验只能「知道错了」，不知道错在哪一位（1 位校验位提供的信息量不足）。
- **不能检偶数个错**：这是它最常被考到的局限。
- **奇校验 vs 偶校验**：没有本质优劣，选择是协议约定；但奇校验能保证「全 0 码字」也合法码（因为 0 个 1 是偶数，奇校验要求至少奇数个 1）——少数系统因此偏好奇校验。

## 5 考点速记：奇偶校验三句话**一句话：** 奇偶校验加 1 位，让码字 1 的个数为奇（奇校验）或偶（偶校验）。

**二句话：** 能检**奇数个**错误，检不出**偶数个**错误——因为偶数个翻转不改变 1 的个数奇偶性。

**三句话：** 校验位本身也可能出错，所以「校验失败」只能说明「有奇数个错」，不能定位错误位置。

**五条必记**：

- 硬件实现：一个异或树，$P = d_0 \oplus d_1 \oplus \cdots$。
- 最小码距 2 → 检 1 位错、不能纠错（码距 d 检 d−1、纠 ⌊(d−1)/2⌋）。
- 二维奇偶（行+列）能定位单个错误位置 → 可纠 1 位。
- 应用：串口校验位、早期内存、RAID 奇偶盘。
- 与 CRC/海明的对比：奇偶最便宜但能力最弱。

**辨析｜易错点：**「校验失败」不代表「错在信息位」——校验位翻转同样导致失败。奇校验 vs 偶校验是协议约定，无本质优劣。

## 6 一句话回顾- 奇偶校验检奇数个错、漏偶数个错。
- 码距 2 → 检 1 纠 0。
- 二维奇偶能定位单个错误。

> 一句话：奇偶检奇数个错、漏偶数个错。
> 一句话：二维奇偶能定位单个错误。

## 7 小结- **奇偶校验**：加 1 位使码字 1 的个数为奇/偶，实现简单，硬件是一个异或树。
- **码距**：检错能力 = 最小码距减 1；奇偶码码距 2，检 1 位错。
- **局限性**：检不出偶数个错误，不能定位错误。
- **升级路线**：二维奇偶 → 定位并纠正；海明码 → 系统化纠错。
- 应用：串口校验、内存 ECC 的低层思想、RAID 奇偶盘。
