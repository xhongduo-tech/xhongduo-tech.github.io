## 为什么 CPU 是「一台机器里的机器」

前四篇讲了数据怎么表示、指令长什么样、存储器怎么组织——现在把它们组装起来。**CPU（Central Processing Unit，中央处理器）** 是全系统的指挥中心，本课先从宏观把握它的**功能**（它要干什么）与**组成**（用哪些部件干）。CPU 的内部结构——运算器、控制器、寄存器组——是后十几课的骨架，先立起这张地图，后面的数据通路、控制器设计才有挂靠点。<span class="marginnote">本课的组成框架就是整个第五篇的目录：运算器（ALU 与数据通路）、控制器（硬布线/微程序）、寄存器组（PC/IR/MAR/MDR/PSW）。理解了「三部件」的分工，第五篇的每一课都只是往里填细节。</span>

## 1 CPU 的功能CPU 要完成的四大功能：

1. **取指令（instruction fetch）**：从内存取出指令放入 IR。
2. **分析指令（decode）**：译出操作码与操作数地址。
3. **执行指令（execute）**：按操作码执行算术逻辑运算或控制转移。
4. **控制时序（timing）**：发出控制信号，协调各部件按节拍工作。

外加**处理异常与中断**、**响应 I/O 请求**。

**核心概念：CPU 的工作循环**——取指 → 译码 → 执行 → （中断检查）→ 取下一条，周而复始。这个循环就是《指令周期》一课的主题。<span class="marginnote">把 CPU 想成「一台每周期读一条指令的小机器」：它不「理解」程序，只是机械地重复「取一条、做一条」。所有高级语言的复杂性，都被编译成这条机械循环能吃的指令序列。</span>

## 2 CPU 的组成：三大部件**CPU 由运算器、控制器、寄存器组（以及内部总线）组成**：

### 运算器（ALU + 寄存器）

**运算器**负责算术逻辑运算与数据的暂存：

- **ALU**：执行加、减、与、或、移位等操作（见《ALU 的基本结构》）。
- **累加器 ACC、暂存寄存器、状态寄存器**：暂存操作数与结果。

### 控制器（CU）

**控制器**是 CPU 的「发令官」：

- 生成控制信号，指挥运算器、存储器、I/O 按序工作。
- 核心部件：指令寄存器 IR（存当前指令）、程序计数器 PC（存下一条指令地址）、指令译码器、时序产生器。
- 实现方式：**硬布线**或**微程序**（见后续各课）。

### 寄存器组

寄存器是 CPU 内部的「超高速暂存」：PC、IR、MAR、MDR、PSW、通用寄存器——下一课专讲。

<span class="marginnote">「运算器 + 控制器」是经典的 CPU 二分法；现代 CPU 里还有 Cache、TLB、流水线逻辑、分支预测器——但「算 + 控 + 存」的骨架不变。理解这个骨架，再看现代微架构就有坐标系了。</span>

## 3 CPU 内部的连接：数据通路三大部件之间靠**内部总线**与**数据通路（datapath）**连接：

- **内部总线**：CPU 内部传输数据/地址/控制的公共通路（单总线/多总线，见《数据通路》一课）。
- **数据通路**：数据从寄存器到 ALU、再回到寄存器的流动路径。

**核心概念：一次「执行指令」在数据通路上的样子**——操作数从寄存器 → ALU → 结果写回寄存器，控制器在一旁按节拍发控制信号（何时取、何时算、何时写回）。

**重点：控制信号 = 数据通路的「红绿灯」**——同样的数据通路，靠不同的控制信号完成不同指令。这就是「控制器指挥数据通路」的关系。<span class="marginnote">「数据通路 + 控制器」是现代 CPU 的两半：数据通路是「肌肉」（算路），控制器是「神经」（发令）。RISC 的哲学之一就是让数据通路简单规整，把复杂性留给控制器。</span>

## 4 公式解析：CPU 的功能实现模型把 CPU 的功能模型化为「状态 + 循环」：

$$\text{CPU 状态} = (\text{PC}, \text{IR}, \text{寄存器组}, \text{标志位}, \text{存储器状态})$$

$$\text{循环}:\ \text{取指} \to \text{译码} \to \text{执行} \to \text{写回} \to \text{更新 PC}$$

逐项拆解：

- **第一步，状态**：CPU 的一切工作围绕一组状态（寄存器、标志、PC）展开。
- **第二步，取指**：`MAR ← PC; 读内存; IR ← 读出内容; PC ← PC + 指令长`。
- **第三步，译码**：控制器分析 IR 的操作码，决定要发哪些控制信号。
- **第四步，执行**：数据通路按控制信号完成运算或访存。
- **第五步，更新 PC**：顺序（PC+步长）或跳跃（转移指令改 PC）——回到第一步。

**核心结论：CPU 的一切功能都实现为这个「取指-译码-执行-更新 PC」的循环**，每循环一次执行一条指令。<span class="marginnote">这个循环在《指令周期》一课会被细化成取指、间址、执行、中断四个子周期；在流水线篇会被重叠执行（多条指令同时在不同阶段）。先记住「单条循环」，再学「循环重叠」。</span>

## 5 辨析｜易错点：CPU 组成概念**辨析｜易错点：**

- **控制器 ≠ 控制信号发生器**：控制器含 IR、译码器、时序器，控制信号是它的输出；别把「控制器」与「控制单元（CU）」割裂。
- **运算器 ≠ ALU**：运算器含 ALU 以及配套的暂存寄存器、累加器；ALU 只是它的核心运算电路。
- **寄存器组属于 CPU 但不全在运算器里**：PC/IR 在控制器侧，通用寄存器在运算器侧，MAR/MDR 是访存接口寄存器。
- **CPU 不含主存**：主存是独立部件，CPU 通过 MAR/MDR 与总线访问它——「CPU 包含内存」是常见误解。

## 6 考点速记：CPU 功能与组成**四大功能**：取指令、分析指令、执行指令、控制时序，外加中断/异常处理。

**三大部件**：运算器（ALU+暂存）、控制器（IR/PC/译码/时序）、寄存器组。

**五条必记**：
- CPU 工作循环：取指 → 译码 → 执行 → 更新 PC。
- 数据通路是「肌肉」、控制器是「神经」、控制信号是「红绿灯」。
- ALU ⊂ 运算器、CU 是控制器主体、CPU 不含主存。
- 寄存器组里 PC/IR 在控制器侧，通用寄存器在运算器侧。
- 现代 CPU 还有 Cache/TLB/流水线/分支预测，但「算+控+存」骨架不变。

**辨析｜易错点**：运算器 ≠ ALU——运算器含 ALU 及配套暂存寄存器。

## 7 一句话回顾- CPU 四大功能：取指、译码、执行、控制时序。
- 三大部件：运算器、控制器、寄存器组。
- 循环：取指→译码→执行→更新 PC。

## 8 小结- CPU 四大功能：**取指、译码、执行、控制时序**，外加中断/异常处理。
- 组成三大部件：**运算器**（ALU + 暂存）、**控制器**（IR/PC/译码/时序）、**寄存器组**。
- 数据通路是「肌肉」，控制器是「神经」，控制信号指挥数据流动。
- 工作模型：取指 → 译码 → 执行 → 更新 PC 的循环。
- 边界辨析：ALU ⊂ 运算器、CU 是控制器主体、CPU 不含主存。
