## 为什么移位是算术的原子操作

乘法可以用移位加加法实现，除法可以用移位加减法实现，这听起来不可思议，但正是早期 CPU 的设计现实：**一个移位器比一个乘法器便宜得多**。补码的移位运算还有一个天然优势——**算术右移天然保持符号**。这一课讲透三种移位（逻辑、算术、循环）的区别，以及一个程序员天天遇到却不自知的操作：**符号扩展**。理解它，你就看懂了为什么 char 转 int 不会出错，也看懂了为什么某些按位操作会「越移越错」。<span class="marginnote">乘法指令在 486 之前都是微码实现的多周期操作，编译器遇到「乘以 2 的幂」会直接换成左移：x\*8 编译成 `x<<3`。这种优化至今仍是编译器的基础技能。</span>

## 1 三种移位运算以 8 位为例，定义三种移位：

**逻辑左移（LSL）**：各位左移一位，最低位补 0，最高位移入标志位。
**逻辑右移（LSR）**：各位右移一位，最高位补 0。
**算术右移（ASR）**：各位右移一位，最高位**保持符号不变**（补符号位）。
**算术左移**：与逻辑左移等价（左移低位自然补 0），所以一般只说「左移」。

看一组具体的例子：

| 运算 | 例（8 位） | 结果 | 十进制 |
| --- | --- | --- | --- |
| 逻辑左移 1 位 | 0000 0101（5） | 0000 1010 | 10 |
| 逻辑右移 1 位 | 1000 0000（128） | 0100 0000 | 64 |
| 算术右移 1 位 | 1111 1101（-3） | 1111 1110 | -2 |
| 算术右移 1 位 | 0111 1111（127） | 0011 1111 | 63 |

**核心概念：算术右移相当于除以 2（向负无穷方向取整）**，逻辑右移只是「把位往右挪」<span class="marginnote">算术右移 -3 在 C 语言里结果是多少？多数平台是 -2，因为 -3 的补码 1111 1101 右移补符号位得 1111 1110，即 $-2$，而 $-3/2 = -1.5$ 向下取整恰好是 $-2$。</span>，而逻辑右移则是无符号视角的除二。同一个右移硬件电路，由「是否补符号位」决定它是算术还是逻辑——编译器按操作数类型选择。

## 2 移位与乘除的等价关系算术右移与乘除的关系（前提：不溢出、不丢精度）：

$$x \ll k \;\Longleftrightarrow\; x \times 2^k$$

$$x \gg_a k \;\Longleftrightarrow\; \left\lfloor \frac{x}{2^k} \right\rfloor$$

其中 $\gg_a$ 表示算术右移，$\lfloor \cdot \rfloor$ 是向下取整。

**辨析｜易错点：**右移与「除以 $2^k$ 的整数除法」并不总相等。C 语言里右移（>>）与除法（/）：

- 对非负数，两者相同。
- 对负数，算术右移（>>）是向下取整，而 C 的整数除法（/）是向零取整。例如 -3 >> 1 = -2（向下），-3 / 2 = -1（向零）。**二者差 1**，这是面试必考陷阱。<span class="marginnote">这个差异的工程后果：右移（>>）不能无条件替代除法（/）。编译器若已知 $x$ 非负（如 size_t），才会做这种替换；对有符号可能为负的数必须保留除法指令。</span>

## 3 符号扩展：短变长而不变值**符号扩展（sign extension）**：把较短的有符号数扩展成较长的位数，同时保持数值不变——方法是将符号位复制到新增的高位。

例：把 8 位补码 1111 1100（即 $-4$）扩展成 16 位：

$$\underbrace{1111\ 1111}_{\text{新高位填符号位 1}}\ \ 1111\ 1100 = \text{-4}$$

为什么填符号位能保持值不变？因为补码最高位权重为负，复制符号位相当于把「$-2^7$ 的负贡献」扩展成「$-2^{15} + (2^{15}-2^8)$」——代数上恰好抵消。<span class="marginnote">直觉：补码的符号位像一排「负权重的永动机」，复制再多份负权重，总额不变。这也解释了为什么负数补码前面填 1、正数填 0 都叫符号扩展。</span>

**无符号数扩展**则简单得多：高位一律填 0，叫**零扩展（zero extension）**。

## 4 公式解析：符号扩展为何保值的代数证明设 $n$ 位补码 $x$，符号位为 $x_{n-1}$，扩展成 $m$ 位（$m > n$），新高位全填 $x_{n-1}$：

$$x' = -x_{n-1}2^{m-1} + \sum_{i=n-1}^{m-2} x_{n-1}2^i + \sum_{i=0}^{n-2} x_i 2^i$$

逐项拆解：

- **第一步，看新符号位**：新增最高位的贡献是 $-x_{n-1}2^{m-1}$。
- **第二步，看中间填充位**：从第 $n-1$ 位到第 $m-2$ 位全是符号位的副本，贡献 $x_{n-1}\sum_{i=n-1}^{m-2}2^i = x_{n-1}(2^{m-1} - 2^{n-1})$。
- **第三步，抵消**：把第一步与第二步合并，$x_{n-1}$ 的系数是 $-2^{m-1} + 2^{m-1} - 2^{n-1} = -2^{n-1}$——恰好是原符号位的权重！
- **结论**：新增的 $m-n$ 位对值零贡献，$x' = x$，保值成立。

**辨析｜易错点：**C 语言中 char 转 int 会自动做符号扩展；unsigned char 转 unsigned int 则做零扩展。若先截断成无符号类型再做符号扩展，负数会变成巨大的正数——「先截断再扩展」与「先扩展再截断」结果不同，混合类型运算时必须心里有数。

## 5 移位与符号扩展的工程应用- **取绝对值的快路径**：mask = x >> 31 用算术右移生成掩码，(x ^ mask) - mask 一条指令序列完成绝对值，避免分支。
- **字节序处理**：读网络字节流时，把 4 个字节拼成 int（或 unsigned int），若涉及有符号就要区分符号扩展与零扩展。
- **归一化处理**：浮点尾数的规格化要靠移位，见《浮点数的表示》一课。
- **掩码提取**：`(x >> k) & 1` 提取第 $k$ 位——逻辑右移 + 与运算，是位操作的日常。<span class="marginnote">在《C 语言中的整数与浮点数》一课我们会回到这些位操作的实战细节，并用 printf 验证移位与乘除的差异。</span>

## 6 拓展：用位操作写「无分支绝对值」算术右移的一个经典应用是「无分支绝对值」：

```c
int abs(int x) {
    int mask = x >> 31;        // 全 0（x≥0）或全 1（x<0）
    return (x ^ mask) - mask;  // x≥0 得 x；x<0 得 ~x+1 = -x
}
```

- 若 $x \ge 0$：mask=0，(x ^ mask) - mask = x。
- 若 $x < 0$：mask=-1（全 1），(x ^ mask) - mask = ~x + 1 = -x（按位取反 + 补数）。

**核心概念：算术右移生成「符号掩码」——负数得到全 1、非负得到全 0**，这个掩码可以参与算术而不引入分支。现代编译器会自动做这类优化（gcc -O2 下绝对值表达式常常编译成无分支）。

**辨析｜易错点：**x >> 31 只有在「算术右移」语义下才对有符号数生成符号掩码——若编译器把右移当成逻辑右移，就错了。C 标准规定有符号负数的右移是「实现定义」，多数平台是算术右移——跨平台代码要小心。

## 7 补充：移位与符号扩展速记- 逻辑左移（补 0）、逻辑右移（补 0）、算术右移（补符号位）。
- 算术右移 = 向下取整的除二；负数 >> 与 / 差 1。
- 左移 k 位 ⇔ 乘 2^k（不溢出时）。
- 符号扩展复制符号位保值；无符号用零扩展。
- 移位可做无分支绝对值、掩码提取等位操作。

> 一句话：算术右移补符号位，负数 >> 与 / 差 1。
> 一句话：符号扩展复制符号位保值。

## 8 小结- 三种移位：**逻辑左移**（低位补 0）、**逻辑右移**（高位补 0）、**算术右移**（高位补符号位）。
- **算术右移 = 向下取整的除二**；对负数，右移（>>）与除法（/）差 1。
- 左移 $k$ 位 $\Leftrightarrow$ 乘 $2^k$（不溢出时）。
- **符号扩展**：复制符号位到新高位，保值不变；无符号用**零扩展**。
- 符号扩展保值有严格代数证明：新增高位贡献恰好互相抵消。
