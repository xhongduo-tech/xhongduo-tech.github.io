## 为什么需要定点数

上一课我们有了原码、补码这些「怎么表示正负」的工具，但还有一个关键问题没解决：**小数点放在哪里？** 数字电路里没有物理上的小数点——它只是二进制位之间一个**约定好的位置**。定点数就是「小数点位置固定不变」的数，它分两种：**定点整数**（小数点固定在最低位之后）与**定点小数**（小数点固定在符号位之后）。这一课把这些约定讲清楚，因为浮点数正是「定点数 + 一个可移动的小数点」，先理解定点，浮点才有支点。<span class="marginnote">很多嵌入式系统至今还在用定点数做控制算法（如 PID），因为定点运算没有舍入问题、速度快、功耗低。理解定点数不是怀旧，而是工程现实。</span>

## 1 定点数的数学定义**核心概念：定点数（fixed-point number）**：约定小数点位置固定不变的机器数。

设字长为 $n$，其中数值位为 $n-1$ 位（含符号位共 $n$ 位）：

- **定点整数**：小数点固定在数值位最低位 $x_0$ 的右边，表示范围（补码）为 $-2^{n-1} \sim +2^{n-1}-1$。它其实就是整数补码。
- **定点小数**：小数点固定在符号位 $x_{n-1}$ 与最高数值位 $x_{n-2}$ 之间，表示范围（补码）为 $-1 \sim +(1-2^{-(n-1)})$。

定点小数的一个关键性质：**它表示的数绝对值永远小于 1**（除 $-1$ 外）。<span class="marginnote">定点小数的补码 `1000...0` 表示 $-1$，这是唯一的例外——它是规格化浮点数的「尾数」最常用到的形态，后文浮点表示里你会反复见到它。</span>

## 2 定点小数的补码表示设定点小数为 $n$ 位，位模式 $x = x_{n-1}x_{n-2}\cdots x_0$，其补码真值公式为：

$$x = -x_{n-1} + \sum_{i=1}^{n-1} x_{n-1-i}\cdot 2^{-i}$$

注意与整数的差别：这里符号位的权重是 $-1$（即 $-2^0$），第 $i$ 位小数权重是 $2^{-i}$。<span class="marginnote">对比整数补码的符号位权重 $-2^{n-1}$，定点小数补码的符号位权重是 $-1$——因为小数点紧挨符号位，符号位代表的整数部分是 $0$ 或 $-1$。这种「权重的平移」是理解两种定点数的钥匙。</span>

例如 8 位定点小数 `1101 0000` 的真值：

$$x = -1 + 1\times2^{-1} + 0\times2^{-2} + 1\times2^{-3} = -1 + 0.5 + 0.125 = -0.375$$

## 3 定点小数的模 2 加减法定点小数的加减法与整数完全一样——因为补码都基于「取模」思想。定点小数 $n$ 位，模为 2：

$$x \pm y \pmod{2}$$

只要结果落在 $-1 \sim 1-2^{-(n-1)}$ 范围内，丢弃溢出进位即正确。

**辨析｜易错点：**定点小数的模是 2，定点整数的模是 $2^n$，两者不同。它们的共同点是**加法器完全一样**，只是对结果的解释不同——这就是「同样的硬件，不同的定点约定」的含义。考试中常见题型：给你一个位模式，分别按定点整数与定点小数求值，答案完全不同。

| 8 位位模式 | 按定点整数（补码） | 按定点小数（补码） |
| --- | --- | --- |
| `1101 0000` | $-48$ | $-0.375$ |
| `0110 0100` | $+100$ | $+0.78125$ |
| `1000 0000` | $-128$ | $-1$ |

## 4 公式解析：定点数的表示范围推导以 $n$ 位定点整数补码为例，推导范围。

$$-2^{n-1} \;\le\; x \;\le\; 2^{n-1} - 1$$

逐项拆解：

- **第一步，最小负数**：符号位为 1，其余全 0，即 `1000...0`，真值 $= -2^{n-1}$。因为它只贡献符号位的负权重。
- **第二步，最大正数**：符号位为 0，其余全 1，即 `0111...1`，真值 $= 2^{n-2}+2^{n-3}+\cdots+1 = 2^{n-1}-1$（等比数列求和）。
- **第三步，总个数**：$n$ 位共有 $2^n$ 个位型，恰好等于范围覆盖的整数个数：$(2^{n-1}-1) - (-2^{n-1}) + 1 = 2^n$。不多不少，无双零浪费。

对定点小数做同样推导，得到 $-1 \le x \le 1 - 2^{-(n-1)}$，个数同样正好 $2^n$。<span class="marginnote">「位型总数 = 可表示数值总数」是补码区别于原码反码的优美性质：原码因为双零，$2^n$ 个位型只表示 $2^n-1$ 个不同的数。</span>

## 5 定点数在现实中的坐标定点数不是课本玩具，它有一个「现代化身」：**定点算术在 DSP 与 AI 推理里的回归**。

- 早期 DSP 芯片（如 TI 的 C5000 系列）只支持定点运算，程序员要手工管理 Q 格式（如 Q15 表示 $-1\sim1$ 的 16 位定点小数）。
- 现代大模型推理的**量化**（INT8、INT4）本质是「用定点近似浮点」——把浮点权重缩放到定点整数，以换取速度与内存。这与你正在学的定点表示直接相关。<span class="marginnote">大模型部署里的 INT8 量化、AWQ、GPTQ 等技巧，底层都要理解「定点数的范围与精度如何权衡」。这条线一直通到第四级《大模型部署》专题。</span>

**核心要点**（定点数主题偏概念性，用表格总结设计权衡）：

| 问题 | 定点数答案 |
| --- | --- |
| 小数点在哪 | 约定固定位置，硬件不存小数点的位置 |
| 精度如何 | 均匀、确定，无舍入误差 |
| 范围如何 | 有限且固定，溢出直接出错 |
| 速度功耗 | 极快、极省，一个加法器搞定 |
| 现代用途 | DSP、嵌入式控制、AI 量化推理 |

## 6 拓展：定点数的现代应用——AI 量化定点数不是古董，大模型推理的 **INT8 量化**就是它的现代应用：

- 浮点权重 $W$ 缩放成定点整数：$W_q = \text{round}(W / s)$，$s$ 是缩放因子。
- 推理用 INT8 定点乘加（快、省内存），结果再乘回 $s$ 还原。
- 精度损失可控（8 位有 256 级），速度与内存收益巨大。

**核心概念：量化 = 用「定点近似浮点」**——把浮点运算换成定点运算，牺牲少量精度换大量速度。Q 格式（Q15 等）是传统定点，现代量化是「动态缩放定点」，思想同源。

**辨析｜易错点：**定点数「无舍入误差」指「运算在表示范围内的误差为零」，但**范围有限**——超出范围就溢出，这恰恰是定点的软肋。浮点用「阶码换范围」，定点只能「设计好 Q 格式保证不溢出」。

## 7 补充：定点数速记- 定点整数：小数点在最右，范围 -2^(n-1)~2^(n-1)-1。
- 定点小数：小数点在符号位后，范围 -1~1-2^-(n-1)。
- 符号位权重：整数 -2^(n-1)，小数 -1——权重平移是钥匙。
- 同一位置型按不同定点约定读，值完全不同。
- 现代应用：DSP Q 格式、AI INT 量化。

## 8 一句话回顾- 定点整数小数点在右，定点小数在符号位后。
- 符号位权重不同：-2^(n-1) vs -1。
- 现代回归：DSP Q 格式、AI INT 量化。

## 9 核心公式
- 定点整数：-2^(n-1) ~ 2^(n-1)-1。
- 定点小数：-1 ~ 1-2^-(n-1)。
- 小数符号位权重 -1、整数 -2^(n-1)。
- 位型总数 = 2^n 个，无双零。

## 10 小结- **定点数**是小数点位置固定的机器数，分**定点整数**（小数点在最右）与**定点小数**（小数点在符号位后）。
- 定点整数补码范围 $-2^{n-1} \sim 2^{n-1}-1$；定点小数补码范围 $-1 \sim 1-2^{-(n-1)}$。
- 定点小数的符号位权重是 $-1$，整数的是 $-2^{n-1}$，加法器可共用。
- 同一个位模式按不同定点约定读，值完全不同。
- 定点思想在现代的回归：DSP Q 格式与大模型 INT 量化。

- 定点整数小数点在右、定点小数在符号位后
- 整数范围 -2^(n-1)~2^(n-1)-1
- 小数范围 -1~1-2^-(n-1)
- 符号位权重不同
- 位型总数 = 2^n
- Q15 是传统定点
- INT 量化是定点现代应用
- 范围有限是定点软肋
