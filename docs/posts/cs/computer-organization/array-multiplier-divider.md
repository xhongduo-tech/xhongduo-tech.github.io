## 为什么从「一位乘」走向「阵列乘」

上一课的恢复余数法、一位乘都是**时序**思路：用一套硬件，循环 n 次。而**阵列乘法器**走的是另一条路——**空间换时间**：把 n 轮循环「摊开」成 n 层组合逻辑，一次时钟内并行完成全部部分积相加。这是组合逻辑的乘法、除法电路，是理解「乘法器为什么可以这么快」的关键，也是后续学习 Wallace 树、浮点乘法的垫脚石。<span class="marginnote">「时序 vs 组合」是组成原理的一对核心矛盾：时序电路省硬件费时间，组合电路费硬件省时间。阵列乘法器是后者的教科书代表。</span>

## 1 阵列乘法器的结构：部分积的网状加法n 位 × n 位乘法，本质是生成 $n$ 个部分积（每个是被乘数 × 一位乘数），再把它们按位权错位相加。阵列乘法器把这些加法**排成一个二维网格**：

每一行是一个部分积，由「被乘数 与 一位乘数」做与运算生成。
各行的错位相加由**全加器阵列**完成，进位沿对角方向传递。

以 4 位乘法 1011 × 1101 为例，部分积网格：

```
被乘数 X = 1011（11），乘数 Y = 1101（13）

每行 = 被乘数 × 乘数的一位，错位排列：
PP0 = 1 0 1 1  × y0 = 1
PP1 = 0 0 0 0  × y1 = 0
PP2 = 1 0 1 1  × y2 = 1
PP3 = 1 0 1 1  × y3 = 1

错位相加 → 乘积 = 1000 1111（143）
```

网格的每一格是一个「与门 + 全加器」单元，进位向右下传递。<span class="marginnote">乘法器阵列的经典版叫 Braun 乘法器（无符号）；补码版在每行端头加符号扩展与修正项，叫 Baugh-Wooley 乘法器。它们都由「与门 + 全加器」的规则网格构成，非常适合 VLSI 布局。</span>

## 2 阵列乘法器的时间代价：关键路径阵列乘法器虽然是组合逻辑，但**进位传播**决定了它的延迟。n 位乘法器的最坏路径从「最左上角」斜穿到「最右下角」，要经过约 $2n$ 个全加器。

延迟估计：

$$T_{\text{mult}} \approx (2n - 2) \cdot t_{\text{FA}} + t_{\text{AND}}$$

其中 $t_{\text{FA}}$ 是一个全加器的进位延迟。<span class="marginnote">8 位乘法器关键路径约穿过 14 个全加器；32 位则约 62 个——延迟随位宽线性增长，这正是 Wallace 树想解决的痛点（它把关键路径压到 $O(\log n)$）。</span>

**重点**：阵列乘法器把「n 个时钟周期的时序乘法」压缩成「1 个时钟周期（但较长的组合路径）」。代价是硬件面积随 $n^2$ 增长：n 位需要约 $n^2$ 个全加器。

## 3 阵列除法器：恢复余数法的组合化阵列除法器的思想同样是把「恢复余数法」的循环摊开成网格。它由一排排「可控加减单元（CAS, controlled add/subtract）」组成，每一排对应一位商：

每排 CAS 根据上一排的余数符号，决定本排做「减除数」还是「加除数」。
商位由该排最终余数的符号决定（够减商 1，不够减商 0）。
余数沿对角线向下传递，最终余数在底层输出。

每个 CAS 单元：一个全加器 + 一个受控反相器（控制位决定是加 Y 还是加 Y 的反码）。<span class="marginnote">阵列除法器本质是「加减交替法」的组合展开：每排 CAS 恰好对应交替法的一轮，商的位在每排末尾直接定出。它比时序除法器快，但面积更大，且最高位还要处理符号与溢出判断。</span>

## 4 公式解析：CAS 单元的行为阵列除法器的基本单元是可控加减单元，其行为可写成：

$$S = A \oplus (B \oplus C) \oplus C_{\text{in}}, \qquad C_{\text{out}} = (A \wedge (B\oplus C)) \vee (C_{\text{in}} \wedge ((B \oplus C) \vee A))$$

这看起来复杂，但拆开只有三件事：

- **第一步，控制位 $C$**：$C=0$ 时 $B \oplus 0 = B$，单元做加法（$A+B$）；$C=1$ 时 $B \oplus 1 = \bar B$，单元做减法（$A - B$，靠 $C_{\text{in}}=1$ 完成加一）。
- **第二步，求和**：$S$ 是全加器标准求和，只是第二个输入被控制位「可能取反」。
- **第三步，进位**：$C_{\text{out}}$ 是标准进位逻辑，全加器四输入的真值表即可推导。

**核心直觉**：一个 CAS 单元 = 全加器 + 一个 XOR 门。阵列除法器就是 n² 个这样的单元排成对角线网格。<span class="marginnote">这正是「硬件复用」的妙处：加法器稍微加点控制，就能同时服务加、减、乘、除四种运算。这种「用控制位扩展基本单元」的思想，在 ALU 设计与流水线控制中反复出现。</span>

## 5 辨析｜易错点：时序 vs 阵列| 维度 | 一位乘（时序） | 阵列乘法器（组合） |

| --- | --- | --- |
| 执行方式 | n 个时钟周期循环 | 1 个时钟周期组合延迟 |
| 硬件量 | 约 1 个加法器 + 寄存器 | 约 $n^2$ 个全加器 |
| 速度 | 慢 | 快 |
| 面积 | 小 | 大（随 n² 增长） |
| 关键路径 | n 轮移位 | $2n$ 个全加器进位 |

**辨析｜易错点：**（1）阵列乘法器没有「循环」，也没有「状态」，它是纯组合逻辑——答案在一拍内稳定输出；（2）「关键路径」≠「时钟周期数」：组合电路用延迟衡量，时序电路用周期数衡量；（3）n 位阵列乘法器面积约 $O(n^2)$，这是它不能无限加宽的原因，现代大位宽乘法用 Wallace 树降低高度（进位压缩），再配合快速加法器。

## 6 考点速记：阵列运算器三要点**要点一：阵列乘法器** = 与门 + 全加器的规则网格，部分积并行相加，一拍完成。n 位乘法器约 $n^2$ 个全加器，关键路径约 $2n$ 个全加器延迟。

**要点二：阵列除法器** = 可控加减单元（CAS）排成对角网格，每排对应一位商——加减交替法的组合化。

**要点三：CAS 单元** = 全加器 + 一个异或门，控制位决定加/减（$B \oplus C$）。

**五条必记**：

- 时序（一位乘）用循环省硬件，阵列（组合）用面积换速度。
- Braun 乘法器（无符号）、Baugh-Wooley（补码）是两种经典阵列。
- 阵列除法器的商位由每排最终余数符号决定。
- 面积随位宽 O(n²) 增长，是阵列乘法器不能无限加宽的原因。
- 现代大位宽乘法用 Wallace 树压缩部分积高度 + 快速加法器。

**辨析｜易错点：**「阵列乘法器有 n 个时钟周期」是错的——它是纯组合逻辑，一拍稳定输出；用「关键路径延迟」衡量，不是「周期数」。

- 自测 3：Wallace 树解决什么问题？

## 7 一句话回顾- 阵列乘法器 = 与门 + 全加器网格，一拍完成。
- 阵列除法器 = CAS 网格，加减交替法组合化。
- 用 O(n²) 面积换 O(1) 周期。

## 8 核心公式
- 阵列乘法：约 n² 全加器、关键路径 2n。
- CAS = 全加器 + 异或门。
- 用 O(n²) 面积换 O(1) 周期。

## 9 小结- **阵列乘法器**：把部分积加法排成二维网格，与门 + 全加器阵列，一拍完成。
- **关键路径**约 $2n$ 个全加器，延迟随位宽线性增长。
- **阵列除法器**：可控加减单元（CAS = 全加器 + XOR）排成对角网格，摊开恢复余数法。
- **CAS 单元**用控制位决定加减，一套硬件两种运算。
- 阵列方案用 **$O(n^2)$ 面积换 $O(1)$ 周期**，是「空间换时间」的教科书案例。
