## 为什么 ALU 是 CPU 的「计算心脏」

前几课我们学了加、减、乘、除、移位、比较——它们都住在同一个部件里：**ALU（Arithmetic Logic Unit，算术逻辑单元）**。ALU 是组合逻辑电路，输入两个操作数和一条「功能选择」信号，输出结果和若干标志位（零、符号、进位、溢出）。本课把 ALU 的组成、功能集、标志位生成与控制方式讲清楚。理解 ALU 的结构，就理解了「一条指令如何在硬件里被翻译成一次运算」——这是第五篇控制器设计的必要前置。<span class="marginnote">ALU 是全组合电路：没有寄存器、没有时钟，给定输入，经过一段传播延迟后输出稳定。它内部的加法器就是《加法器设计》一课的主角。</span>

## 1 ALU 的功能集一个典型 ALU 提供以下功能，按类别：

- **算术**：加、减（加取反）、加 1、减 1、乘（可选，乘常在独立单元）。
- **逻辑**：与、或、非、异或、同或。
- **移位**：逻辑左/右移、算术右移、循环移位（可独立于 ALU）。
- **比较**：产生相等、大于、小于标志，常通过减法+标志位实现。

ALU 通过**操作控制信号（ALU op）**选择具体功能：控制信号是几位二进制编码，译码后选通对应的功能电路。<span class="marginnote">经典教材里 ALU 的「1 位单元」是基础积木：1 个全加器 + 一组逻辑门 + 多路选择器，控制信号选择输出哪种运算。n 个 1 位单元级联即 n 位 ALU。</span>

## 2 ALU 的结构框图一个 n 位 ALU 的三个界面：

- **数据输入**：操作数 $A$（n 位）、$B$（n 位）。
- **控制输入**：功能选择信号 $S$（如 4 位编码 16 种功能）、进位输入 $C_{\text{in}}$（减法时置 1）。
- **数据输出**：结果 $F$（n 位）、标志位（Zero、Sign、Carry、Overflow）。

```
   A ──┬─────┐
   B ──┼─► ALU ──► F (n 位结果)
   S ──┘  │
          ├──► Zero / Sign / Carry / Overflow
```

ALU 的**核心电路**是加法器（减法靠取反+进位复用），逻辑运算用与或非门阵列并行生成，最后用多路选择器挑一条输出。<span class="marginnote">这种「各功能电路并行算、最后选路」的设计叫「共享数据通路」：不是为每种运算单独建一条路，而是全部并排放好，控制信号决定哪条被选中。这是硬件复用思想的集中体现。</span>

## 3 标志位的生成ALU 输出的标志位不是「算出来的额外东西」，而是**结果的属性**，供后续指令判断：

| 标志位 | 生成条件 | 用途 |
| --- | --- | --- |
| Zero（ZF） | 结果全 0 | `if (a==b)` 比较、循环判断 |
| Sign（SF） | 结果符号位 | 有符号比较 |
| Carry（CF） | 最高位进位/借位 | 无符号比较、多精度算术 |
| Overflow（OF） | $C_n \oplus C_{n-1}$ | 有符号溢出检测 |

**Zero 与比较**：`a < b` 的实现就是算 $a-b$，看符号位与溢出标志的组合（有符号：`SF != OF`；无符号：`CF == 1`）。<span class="marginnote">「减法即比较」是 ALU 的经典技巧：一条减法同时产出结果、符号、进位、溢出四个信息，比较指令（`cmp`）实际上就是一次「不写回结果的减法」。</span>

## 4 公式解析：有符号与无符号比较的判据设 ALU 计算 $a - b$，用标志位组合判断大小：

$$\text{无符号：} a < b \iff CF = 1$$

$$\text{有符号：} a < b \iff SF \oplus OF = 1$$

逐项拆解：

- **第一步，无符号**：$a < b$ 意味着 $a - b$ 有借位，即最高位有进位取反，$CF=1$。
- **第二步，有符号**：$a < b$ 时结果符号可能为负（$SF=1$），但若发生溢出，符号位会反——所以要看 $SF$ 与 $OF$ 是否不同：不同则为真。
- **第三步，直觉**：`SF XOR OF` 相当于「结果符号正确的情况下为负，或者溢出导致符号反转仍为负」——把两种可能统一成一个表达式。

这套判据直接决定 CPU 里 `JA/JB`（无符号跳转）与 `JG/JL`（有符号跳转）的硬件逻辑。<span class="marginnote">这就是为什么汇编里有两套比较跳转指令：`JB` 看 CF，`JL` 看 SF^OF。写汇编时选错指令，负数会被当成巨大正数——与《无符号数与有符号数》一课的陷阱一脉相承。</span>

## 5 辨析｜易错点：ALU 设计要点**辨析｜易错点：**

- **ALU 是组合逻辑**：没有时钟、没有状态，输入变了输出跟着变；说「ALU 用寄存器保存结果」是混淆了 ALU 与它旁边的结果寄存器。
- **减法 = 加反 + 进位 1**：`A - B` 实现为 `A + ~B + 1`，靠 `Cin=1` 完成加一，所以减法不需要独立电路。
- **标志位由最后一步运算更新**：指令顺序会影响标志位的读法，编译器和汇编程序员必须时刻追踪「上一条指令更新了哪些标志」。
- **乘法不在 ALU 里的历史**：早期 CPU 乘法用循环移位实现，现代 CPU 有独立乘法器（MUL 单元），ALU 只处理加减逻辑。

## 6 拓展：ALU 的一个完整功能表一个典型 4 位 ALU 的「功能选择信号 → 操作」对应：

| S3 S2 S1 S0 | 操作 |
| --- | --- |
| 0000 | A AND B |
| 0001 | A OR B |
| 0010 | A + B |
| 0011 | A − B（A + ~B + 1） |
| 0110 | 左移 |
| 0111 | 右移 |
| ... | ... |

**核心概念：ALU 是「组合逻辑 + 多路选择」**——所有功能电路并行算好，控制信号（S）通过多路选择器挑一条输出。这与微指令的「直接编码/字段编码」思想同构。

**辨析｜易错点：**「减法 = 取反加一」复用加法器——`A - B` 实现为 `A + (~B) + 1`，靠进位输入 $C_{in}=1$ 完成加一。所以 ALU 没有独立的减法电路，减法只是「加法器的控制变体」。

## 7 补充：ALU 速记- 三界面：两个操作数 + 功能选择信号 + 结果与四个标志位。
- 功能集：算术、逻辑、移位、比较。
- 标志位：Zero/Sign/Carry/Overflow，供条件分支使用。
- 减法 = 取反加一复用加法器；比较复用减法。
- 无符号比较看 CF，有符号看 SF^OF——两套跳转指令。

## 8 一句话回顾- ALU = 组合逻辑 + 多路选择，功能表选路。
- 减法复用加法器（取反+进位1）。
- 无符号看 CF、有符号看 SF^OF。

> 一句话：减法复用加法器（取反 + 进位 1）。

## 9 小结- ALU 三界面：**两个操作数、功能选择信号、结果 + 四个标志位**。
- 功能集：算术（加/减/加一）、逻辑（与/或/非/异或）、移位、比较。
- **标志位**：Zero/Sign/Carry/Overflow，由结果属性生成，供条件分支使用。
- 减法复用加法器（取反 + $C_{\text{in}}=1$）；比较复用减法（看标志）。
- 无符号比较看 CF，有符号比较看 SF^OF，两套跳转指令由此而来。

- ALU = 组合逻辑+多路选择

- 标志位 Zero/Sign/Carry/Overflow
