## 为什么舍入值得专门研究

每次浮点运算都会产生一个「无限精度」的中间结果，而寄存器只有有限位——所以**每一次运算都要舍入**。单个舍入误差微乎其微，但在一亿次迭代后可能变成灾难。这一课把舍入的方式、误差的量级、以及几个著名的精度灾难（消去误差、累积误差、病态问题）讲透。它们是「为什么科学计算要分析误差」的起点，也是你在面试里谈「为什么不能用浮点做金额」时的弹药。<span class="marginnote">IEEE 754 的舍入规则保证了「每次运算的误差不超过半个 ulp」（ulp 是最低有效位单位）。这个有界的单步误差，是整座浮点大厦的地基承诺。</span>

## 1 舍入方式的完整解剖IEEE 754 四种舍入模式，重点是默认的**就近舍入（round to nearest, ties to even）**：

- 被舍入位的值小于一半 → 直接舍弃（向下取）。
- 大于一半 → 进位（向上取）。
- **恰等于一半（ties）** → 取「最低有效位为偶数」的那个候选。

例（二进制，保留 4 位尾数）：

| 精确结果 | 4 位尾数舍入后 | 说明 |
| --- | --- | --- |
| `1.00110` | `1.0011` | 丢弃位 `0` < 一半 |
| `1.00111` | `1.0100` | 丢弃位 `1` > 一半，进位 |
| `1.001101` | `1.0011` | 中间值，候选 `1.0011`（奇）与 `1.0100`（偶），取偶 `1.0100`？ |

第三个例子的取偶逻辑要小心：`1.001101` 的精确值在 `1.00110` 与 `1.00111` 正中间，两个候选是 `...110`（末位 0，偶）与 `...111`（末位 1，奇）——取偶得 `1.00110`。<span class="marginnote">「取偶」消除的是系统性偏差：如果每次都向上取，一万次运算平均偏大；取偶让一半向上、一半向下，统计上无偏。这是金融统计里银行家舍入被选中的根本原因。</span>

## 2 误差的度量：ulp 与相对误差**ulp（unit in the last place）**：两个相邻可表示数之间的距离，即最低有效位的权。

- 单精度：$2^{-23} \approx 1.2\times10^{-7}$；双精度：$2^{-52} \approx 2.2\times10^{-16}$。
- 每次舍入的绝对误差 $< \frac{1}{2}\,\text{ulp}$。
- **相对误差**：$\epsilon = |x - \text{fl}(x)|/|x|$，机器精度（machine epsilon）$\epsilon_m$ 约为半个 ulp 的上界（单精度 $\approx 1.2\times10^{-7}$，双精度 $\approx 2.2\times10^{-16}$）。<span class="marginnote">注意：ulp 随数值大小变化（大数的间隔大），相对误差才是描述精度的不变量。`16777216.0f` 之后单精度连整数 1 都表示不了，因为此时 ulp = 2——这正是《IEEE 754》一课「大数加小数被吃掉」的量化解释。</span>

## 3 公式解析：消去误差为何危险两个相近的大数相减是浮点误差的头号杀手。设 $x$ 与 $y$ 都近似相等，它们的浮点表示误差为 $\epsilon_x, \epsilon_y$：

$$\text{fl}(x) - \text{fl}(y) = (x-y) + (\epsilon_x - \epsilon_y)$$

逐项拆解：

- **第一步，看真值差**：$x - y$ 很小（两者相近）。
- **第二步，看误差差**：$\epsilon_x - \epsilon_y$ 是原误差之差，量级不变。
- **第三步，比大小**：误差的相对占比 = $\frac{|\epsilon_x - \epsilon_y|}{|x-y|}$，当 $x \approx y$ 时分母趋近 0，相对误差被**无限放大**。

**结论**：减法把「绝对误差」保留、把「真值」消掉，于是相对误差爆炸。这就是为什么 `1e16 + 1 - 1e16` 在双精度里可能得到 `0` 而不是 `1`。<span class="marginnote">工程对策：重写公式避免减法，如 $x^2-y^2 \to (x-y)(x+y)$，$\sqrt{x+1}-\sqrt{x} \to \frac{1}{\sqrt{x+1}+\sqrt{x}}$。这种「代数变形降误差」是数值算法的经典技艺。</span>

## 4 精度问题的经典场景### 累积误差

求和 $S = \sum_{i=1}^{n} a_i$ 时，误差随 $n$ 增长。**Kahan 求和算法**通过记录每次舍入丢失的「补偿项」，把 $O(n)$ 的误差降为 $O(1)$：

```c
double kahan_sum(double a[], int n) {
    double sum = 0.0, c = 0.0;
    for (int i = 0; i < n; i++) {
        double y = a[i] - c;
        double t = sum + y;
        c = (t - sum) - y;   // 捕获这次舍入丢掉的部分
        sum = t;
    }
    return sum;
}
```

### 条件数与病态问题

**条件数（condition number）**衡量一个问题的输出对输入的敏感程度：条件数大说明输入的小扰动会被放大成输出的大误差。矩阵求逆、解线性方程组的稳定性都用它刻画——这是数值分析与机器学习数值优化的共同话题。<span class="marginnote">在深度学习训练里，梯度范数、损失数值的波动常与浮点误差纠缠：BF16 的 8 位尾数放大了相对误差，所以训练要用损失缩放（loss scaling）保精度。这条线通往第四级《大模型部署》的混合精度训练专题。</span>

## 5 辨析｜易错点：舍入相关的常见误区**辨析｜易错点：**

- **截断 ≠ 舍入**：直接丢弃低位（向 0）误差最大且有偏，默认舍入是就近取偶。
- **浮点比较**：`a == b` 应替换为 `fabs(a - b) < eps`，但 eps 的选择要看数值量级（绝对阈值 vs 相对阈值）。
- **`float` 精度只有约 7 位十进制**，别把 `double` 的直觉用在 `float` 上。
- **误差是乘法传播的**：两次舍入误差叠加，不是简单相加，但相对误差近似相加。
- **NaN 与 Inf 参与运算**会「安静污染」，不会报错，调试时要用 `isnan`/`isinf` 显式检查。

## 6 考点速记：舍入与精度**四种舍入**：就近舍入（默认，ties-to-even）、向+∞、向-∞、向 0（截断）。

**核心指标**：ulp = 相邻可表示数间距；单精度 2⁻²³≈1.2e-7，双精度 2⁻⁵²≈2.2e-16。

**头号陷阱**：消去误差——两个相近大数相减，真值消掉、误差保留，相对误差爆炸。

**五条必记**：

- ties-to-even 消除系统性偏差：一半向上、一半向下，统计无偏。
- 单步误差 < ½ ulp——IEEE 754 的地基承诺。
- Kahan 求和把累积误差从 O(n) 降到 O(1)。
- 条件数刻画问题对扰动的敏感度；病态问题再好的算法也算不准。
- 金融不用浮点：0.1 的误差在千万笔交易上累积，用十进制定点。

**辨析｜易错点：**截断（向 0）≠ 舍入——截断误差最大且有偏；默认舍入是就近取偶。

## 8 小结- 默认舍入是**就近舍入（ties to even）**，保证单步误差 $< \frac12$ ulp。
- **ulp** 是相邻可表示数间距；**相对误差**才是精度不变量。
- **消去误差**：相近大数相减使相对误差爆炸，是浮点头号陷阱。
