## 为什么先从 SRAM 讲起

存储器层次结构的金字塔尖，除了寄存器就是 Cache，而 Cache 的物理载体正是 **SRAM（Static Random Access Memory，静态随机存取存储器）**。它的「静态」指只要供电，数据就稳定保存，不需要像 DRAM 那样周期刷新。理解 SRAM 的单元结构——一个双稳态触发器——就理解了为什么它快而贵、为什么它只能做小容量的 Cache。这一课从晶体管级解剖 SRAM，是后续 DRAM 对比的最佳参照。<span class="marginnote">SRAM 的「随机存取」与 DRAM 一样：按地址访问任意单元，时间与地址无关。区别在「静态 vs 动态」：静态靠电路状态锁存，动态靠电容电荷暂存。一个字母之差，决定了两种器件的命运。</span>

## 1 SRAM 存储单元：六管结构**核心概念：SRAM 单元**：典型的 6 管 SRAM（6T SRAM）由一个 **SR 锁存器**（两个交叉耦合的反相器）加两个**门控管**构成。

```
         Vdd
          │
       ┌──┴──┐
       │     │
      Q       Q̄        （交叉耦合反相器）
      │     │
   ┌──┤     ├──┐
   │  │     │  │
  WL─┤  M5  M6 ├─WL   （两个门控管，字线控制）
   │  │     │  │
  BL─┴─────┴──BL̄    （位线对）
```

- **锁存器**：两个反相器交叉反馈，状态稳定在「Q=1/Q̄=0」或「Q=0/Q̄=1」，只要供电就一直保持——这是 SRAM 的「静态」。
- **门控管（M5、M6）**：由**字线（word line, WL）**控制，读写时打开，把存储单元与**位线（bit line, BL/BL̄）**连通。<span class="marginnote">六管的具体排布（上拉 PMOS、下拉 NMOS、门控 NMOS）是 CMOS 工艺的细节，考试只需掌握「锁存器 + 门控管」的功能结构：字线选中、位线读写。真正背电路图是《数字逻辑》与《微电子》专题的功课。</span>

## 2 SRAM 的读写操作- **读**：字线拉高，位线对 BL/BL̄ 预充到高电平，单元的两个反相器通过门控管「拉」位线，位线对出现电压差，灵敏放大器检测差值输出数据。
- **写**：字线拉高，位线对被强行驱动到目标值（写入 1 就把 BL 拉高、BL̄ 拉低），锁存器被迫翻转进入新状态。
- **保持**：字线拉低，门控管关断，位线与单元隔离，锁存器靠电源保持数据。

**关键点：SRAM 是「双稳态」**——它不依赖电荷暂存，所以**无需刷新**，读出后数据仍在（读不破坏）。这带来两个后果：速度快、功耗随访问活跃。<span class="marginnote">读操作不破坏数据（非破坏性读出）是 SRAM 与 DRAM 的本质差异之一：DRAM 读出会破坏电荷，必须读后重写。因此 SRAM 的读周期可以更短，电路也更简单。</span>

## 3 为什么 SRAM 快但贵

从单元结构直接推导出 SRAM 的工程属性：

- **快**：双稳态切换在几纳秒内完成，且无刷新等待、无读后重写。
- **贵**：每个单元 6 个晶体管，集成度低——同样面积下容量远小于 DRAM（1 管 1 电容）。
- **功耗**：静态时锁存器持续耗电（PMOS 上拉一直导通），待机功耗高于 DRAM。
- **容量小**：所以只用在需要「极快」的地方：Cache、寄存器堆、TLB。<span class="marginnote">CPU 芯片里 L1/L2/L3 Cache 都是 SRAM，占芯片面积的相当一部分。现代 CPU 的 3 级 Cache 加起来几十 MB 的 SRAM，面积甚至超过计算核心——这就是「快是有代价的」最直观体现。</span>

## 3 公式解析：SRAM 的容量与组织
一个 SRAM 芯片的容量记作「字×位」，如「64K × 8」表示 64K 个字、每字 8 位：
$$C = 2^{a} \times b \quad \text{bit}$$

其中 $a$ 是地址线数（$2^a$ 个存储单元行），$b$ 是数据线数（每行位数）。

**芯片引脚**：地址线 $a$ 根、数据线 $b$ 根、控制线（片选 $\overline{CS}$、读写 $\overline{WE}$、输出使能 $\overline{OE}$）。

逐项拆解：

- **第一步，地址**：$a$ 根地址线可寻址 $2^a$ 个字，如 16 根地址线 = 64K 个字。
- **第二步，数据**：$b$ 根数据线决定每次读写的字长，8 根即每次 1 字节。
- **第三步，内部组织**：芯片内部是二维存储阵列（行×列），地址被译码器拆成「行地址」与「列地址」，选中行列交叉点。

**重点：芯片「容量 = 地址线定深度 × 数据线定宽度」**，这个公式贯穿主存设计、位扩展与字扩展。<span class="marginnote">「64K×8」这类记号是芯片接口的语言：字容量与位宽分开写，方便做存储器扩展——把几片并排接一起就能加宽数据线（位扩展），把几组串联就能加深地址（字扩展）。详见《存储器容量扩展》一课。</span>

## 4 辨析｜易错点：SRAM vs DRAM| 维度 | SRAM | DRAM |

| --- | --- | --- |
| 存储原理 | 双稳态触发器 | 电容电荷 |
| 每单元晶体管 | 6 个 | 1 个 + 电容 |
| 需要刷新 | 否 | 是（约每 64ms） |
| 读出是否破坏 | 否 | 是（需重写） |
| 速度 | 快（ns 级） | 慢（数十 ns） |
| 集成度 | 低 | 高 |
| 用途 | Cache | 主存 |

**辨析｜易错点：**（1）「静态」指不需要刷新，不是说「不能写」——SRAM 完全可写；（2）SRAM 的功耗集中在「待机也耗电」与「每次访问都让位线充放电」，所以 SRAM 芯片不适合做大容量待机存储；（3）CPU 里的寄存器堆（register file）也常用 SRAM 实现，但多端口设计让每个寄存器堆单元更复杂。

## 5 拓展：SRAM 与寄存器堆的差别
CPU 里的寄存器堆（register file）常用 SRAM 结构，但要求更高：
- **多端口**：寄存器堆要同时读 2 个、写 1 个（三总线结构）——SRAM 单元要加端口，面积上升。
- **更快的访问**：寄存器访问要求 1 个周期内完成——SRAM 的选址 + 读出延迟要压到最低。

**核心概念：SRAM 是「可寻址的高速存储」的通用方案**——Cache、寄存器堆、TLB 全是 SRAM 结构，差别在容量、端口、速度的取舍。

**辨析｜易错点：**「SRAM 静态 = 不需要时钟」是误解——SRAM 阵列的读写需要时钟/时序控制，只是「数据保持」不依赖刷新（双稳态），与 DRAM 的「要刷新」相对。静态指「数据保持静态」，不是「电路无时钟」。

## 6 补充：SRAM 速记- 单元 = 锁存器（双稳态）+ 门控管，字线选通、位线读写。
- 读不破坏、无需刷新——快且电路简单。
- 每单元 6 管，集成度低、价格高——只能做 Cache。
- 芯片容量 = 地址深度 × 数据宽度。
- 寄存器堆是三端口 SRAM，Cache/TLB 也是 SRAM 结构。

## 7 一句话回顾- SRAM = 锁存器 + 门控管，双稳态无需刷新。
- 每单元 6 管，快但贵、集成度低。
- 只用于 Cache/寄存器堆/TLB 等小容量高速场景。

## 8 小结- SRAM 单元 = **锁存器（双稳态）+ 门控管**，字线选通、位线读写。
- 读不破坏、**无需刷新**，所以快且电路简单。
- 每单元 6 管，集成度低、价格高、待机耗电——只能做小容量高速存储（Cache、寄存器堆）。
- 芯片容量 = 地址线深度 × 数据线宽度，如「64K × 8」。
- SRAM 与 DRAM 的对比是「快而贵」vs「慢而便宜」的第一课。
