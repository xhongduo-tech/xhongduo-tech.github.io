# 计算机组成原理

从晶体管到程序运行，理解计算机硬件如何执行软件。

## 主题规划

- [ ] 计算机系统层次结构与冯·诺依曼体系
- [ ] 数据的表示：原码、补码与 IEEE 754 浮点数
- [ ] 算术逻辑单元（ALU）与运算电路
- [ ] 指令系统：指令格式与寻址方式
- [ ] RISC 与 CISC：以 RISC-V 为例
- [ ] CPU 数据通路与控制器设计
- [ ] 指令流水线：加速比与三类冒险
- [ ] 分支预测与乱序执行初步
- [ ] 存储层次结构：寄存器、Cache、主存与磁盘
- [ ] Cache 映射策略与一致性协议（MESI）
- [ ] 虚拟存储器：页表、TLB 与缺页
- [ ] 总线与 I/O 系统：中断与 DMA
- [ ] 多核与并行体系结构初步
