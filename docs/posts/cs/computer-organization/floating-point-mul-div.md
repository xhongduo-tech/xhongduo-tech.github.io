## 为什么浮点乘除反而比加减简单

加减法要对阶、要右移丢位，每一步都小心翼翼；乘除法却简单得多——**尾数相乘除、阶码相加减，两部分独立完成**。原因在于科学计数法的代数性质：$(M_1 \times 2^{E_1}) \times (M_2 \times 2^{E_2}) = (M_1 M_2) \times 2^{E_1 + E_2}$。这一课把浮点乘除的流程、阶码的移码技巧与溢出处理讲清楚，并指出一个隐藏的坑：**规格化后的尾数乘法，可能把精度窗口「挤出」可用范围**。<span class="marginnote">浮点乘法的硬件代价主要在「尾数乘法器」上——这正是上一课《阵列乘法器》里那些大阵列的用武之地。所以现代 CPU 的浮点乘法延迟接近定点乘法，而浮点加法反而因对阶/规格化更慢。</span>

## 1 浮点乘法的流程两个浮点数相乘，按四步走：

$$N_1 \times N_2 = (M_1 \times M_2) \times 2^{E_1 + E_2}$$

1. **阶码相加**：$E = E_1 + E_2$（注意两者都是移码，直接相加需要减去一个 bias 修正，见公式解析）。
2. **尾数相乘**：$M = M_1 \times M_2$（用定点乘法器，乘积位宽翻倍）。
3. **规格化**：两个规格化尾数都在 $[1, 2)$，乘积在 $[1, 4)$，可能需右规一次（结果 $\ge 2$ 时）。
4. **舍入**：乘积位宽是尾数的两倍，必须舍入回原精度。

例：$(1.5 \times 2^3) \times (1.25 \times 2^{-1})$：

- 阶码：$3 + (-1) = 2$。
- 尾数：$1.5 \times 1.25 = 1.875$，在 $[1,2)$ 内，无需右规。
- 结果：$1.875 \times 2^2 = 7.5$。<span class="marginnote">尾数乘积可能恰好是 $2$（如 $1.5\times 1.333...\approx2$），此时右规一次、阶码加一。乘法最多右规一次，因为两个 $[1,2)$ 的数相乘最大不超过 4，右规后仍在 $[1,2)$。</span>

## 2 浮点除法的流程除法是乘法的镜像：

$$N_1 \div N_2 = (M_1 \div M_2) \times 2^{E_1 - E_2}$$

1. **阶码相减**：$E = E_1 - E_2$（同样要修正 bias）。
2. **尾数相除**：用定点除法器。
3. **规格化**：$M_1/M_2$ 在 $[1/2, 2)$ 之间，小于 1 时需**左规一次**、阶码减一。
4. **舍入**。

**辨析｜易错点：**除法常被设计成「先对尾数做保护性处理」：为使商的精度更高，有的实现先把被除数尾数左移一位（保证商在 $[1,2)$ 内，减少左规），代价是阶码相应减一。不同教材的「预处理」步骤不同，考试以唐朔飞教材流程为准。

## 3 公式解析：移码阶码相加减的 bias 修正移码的好处是「可比大小」，但**直接做算术却要修正偏置**。设阶码真值为 $e_1, e_2$，移码为 $E_1 = e_1 + b$、$E_2 = e_2 + b$（$b$ 为 bias）。

- 乘法需要 $e_1 + e_2$，而 $E_1 + E_2 = e_1 + e_2 + 2b$，多了 $2b$，修正为：

$$E = E_1 + E_2 - b$$

- 除法需要 $e_1 - e_2$，而 $E_1 - E_2 = e_1 - e_2$，**恰好无需修正**。

逐项拆解：

- **第一步，乘法**：两个移码各含一个 bias，相加后共两个 bias，所以要减去一个。
- **第二步，除法**：两个 bias 相减抵消，直接相减即得真值阶差。
- **第三步，修正溢出**：修正后仍可能超出阶码范围，触发上溢/下溢判断。

**核心结论：浮点乘法器里「阶码加法器」多接一个「减 bias」操作，这是浮点单元设计的小细节，也是考试爱考的「为什么不能直接相加」。<span class="marginnote">用非规格化数参与乘除时，尾数不再有隐藏的 1，直接相乘得到的是「伪规格化」结果，需要额外处理，IEEE 754 的硬件通常先检测再走特殊路径。</span>

## 4 乘除法的精度与误差传播- **乘法误差**：两个近似数相乘，相对误差相加。若 $x$ 的相对误差为 $\epsilon_x$、$y$ 为 $\epsilon_y$，则 $xy$ 的相对误差约为 $\epsilon_x + \epsilon_y$。
**除法误差**：同理，商的相对误差约为 $\epsilon_x + \epsilon_y$。
**消去误差（catastrophic cancellation）**：两个接近相等的数相减，会把「高位有效数字」消掉，剩下的只有噪声——这是加减法的危险区，乘除法没有这个问题。<span class="marginnote">这是数值分析的核心结论：乘法除法是「误差温和放大」，减法才是「误差灾难性放大」。所以算法设计要尽量避免「两个相近的大数相减」，例如计算 $x^2 - 1$ 在 $x\approx1$ 时应改写为 $(x-1)(x+1)$。</span>

## 5 特殊值与边界情况浮点乘除遇到特殊值时有既定规则：

- 任何数 × $\pm\infty$ = $\pm\infty$（0 × ∞ = NaN）。
- 任何数 ÷ $\pm\infty$ = $\pm 0$。
- 0 ÷ 0 = NaN，$x \div 0 = \pm\infty$（$x\ne0$）。
- 阶码运算后若超出范围，按就近舍入变成 $\infty$ 或非规格化数。

**核心要点**（乘除主题的边界用表格收束）：

| 操作 | 结果 |
| --- | --- |
| 尾数相乘 | 用定点乘法器，位宽翻倍，最多右规一次 |
| 阶码相加 | 移码相加需减 bias |
| 尾数相除 | 用定点除法器，可能左规一次 |
| 阶码相减 | 移码相减 bias 自动抵消 |
| 上溢 | 变 $\pm\infty$ |
| 下溢 | 逐渐下溢到非规格化或 0 |

## 6 考点速记：浮点乘除四步**乘法**：阶码相加（移码要减 bias）+ 尾数相乘 + 规格化（最多右规一次）+ 舍入。

**除法**：阶码相减（bias 自动抵消）+ 尾数相除 + 规格化（可能左规一次）+ 舍入。

**五条必记**：
- 移码相加含两个 bias，要减一个；移码相减 bias 抵消、直接减。
- 尾数乘积在 [1,4)，最多右规一次；商在 [1/2,2)，可能左规一次。
- 相对误差在乘除中相加传播：ε_xy ≈ ε_x + ε_y。
- 消去误差是减法的专利，乘除没有——减法才是误差大敌。
- 特殊值：0×∞=NaN、x/0=±∞、x/±∞=±0。

**辨析｜易错点**：浮点乘法器里「阶码加法器」要多接一个「减 bias」——这是考试爱问的细节，也是设计的坑。

- 自测 1：为什么移码相加要减 bias？
- 自测 2：尾数相乘后可能右规几次？
- 自测 3：为什么除法商在 [1/2,2)？

## 7 一句话回顾- 乘法：尾数乘、阶码加（减 bias）；除法：尾数除、阶码减。
- 乘除误差温和相加，减法才是灾难。
- 特殊值规则固定：0×∞=NaN。

## 8 小结- 浮点乘法：**尾数乘、阶码加**，最多右规一次，最后舍入。
- 浮点除法：**尾数除、阶码减**，可能左规一次，最后舍入。
- **移码相加需减 bias**，移码相减 bias 自动抵消——这是乘除单元的设计细节。
- 相对误差在乘除中**相加**传播；**消去误差**才是减法的大敌。
- 特殊值运算规则固定：$0\times\infty$=NaN、$x/0=\pm\infty$ 等。

- 乘法：尾数乘、阶码加（减 bias）
- 除法：尾数除、阶码减（bias 抵消）
- 乘除误差温和相加，减法才灾难
- 特殊值：0×∞=NaN、x/0=±∞
- 右规最多一次、左规可能多次
- 乘法阶码相加减 bias、除法直接减
- 尾数乘积 [1,4) 右规一次
- 商 [1/2,2) 可能左规一次
- 相对误差相加传播
- 0×∞=NaN、x/0=±∞
- FMA 精度速度双赢
- 浮点乘除比加减简单
