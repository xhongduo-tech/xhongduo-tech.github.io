## 为什么二叉树是树的「主角」

树可以有任意多个孩子，但真正统治数据结构的，是**每个结点至多两个孩子**的**二叉树（binary tree）**。原因有三：第一，二叉树的结构最简单，存储与算法都最规整；第二，**任何一般的树都能转换成二叉树**（孩子兄弟表示法），所以「会二叉树」就「会一切树」；第三，二叉树的形态与搜索、排序、编码深度绑定——二叉排序树、堆、赫夫曼树、表达式树全是它的子孙。本节推导二叉树的五条经典性质，它们是后续一切二叉树算法的效率依据。

## 1 二叉树的定义

**二叉树（binary tree）**：$n$（$n \ge 0$）个结点的有限集合，它或是空集，或由一个**根结点**加上**两棵互不相交的**、分别称为**左子树**与**右子树**的二叉树组成。

注意两个措辞的分量：

- **「至多两个孩子」**：每个结点度 $\le 2$；
- **左、右子树有次序**：二叉树是有序的——交换左右子树得到的是不同的二叉树。这是二叉树与「普通树」的本质区别：普通树不分左右，二叉树分。<span class="marginnote">「有序性」是二叉树的关键特征：同样两个孩子，谁在左谁在右是有意义的。这也是为什么二叉树能表示表达式（加减乘除的左右顺序不能乱）而普通树不能。</span>

## 2 满二叉树与完全二叉树

两个重要的特殊形态：

**满二叉树（full binary tree）**：深度为 $k$，含 $2^k - 1$ 个结点——每一层都恰好塞满。
**完全二叉树（complete binary tree）**：深度为 $k$ 的二叉树，前 $k-1$ 层是满的，最后一层的结点**集中在最左边**。满二叉树是完全二叉树的特例。

**重点：完全二叉树的结点可以「从 1 开始逐层从左到右连续编号」**——这个编号性质让它可以**用数组存储而不浪费空间**（编号 $i$ 对应数组下标 $i$），这正是堆的实现基础。<span class="marginnote">完全二叉树与数组的完美契合，是二叉堆「用数组装树」的全部前提。到专题篇《二叉堆的上浮与下沉》时，你会看到：<strong>父节点 $i$ 的孩子是 $2i$ 与 $2i+1$</strong>——这个编号性质被用到了极致。</span>

## 3 公式解析：二叉树的五条性质

二叉树的核心性质可以浓缩成五条公式：

$$
\begin{aligned}
&\text{性质1：第 } i \text{ 层至多有 } 2^{i-1} \text{ 个结点} \ (i \ge 1) \\
&\text{性质2：深度为 } k \text{ 的二叉树至多有 } 2^{k} - 1 \text{ 个结点} \\
&\text{性质3：} n_0 = n_2 + 1 \qquad (\text{叶子数 = 度为 2 的结点数} + 1) \\
&\text{性质4：含 } n \text{ 个结点的完全二叉树深度为 } \lfloor \log_2 n \rfloor + 1 \\
&\text{性质5：完全二叉树编号 } i \text{ 的结点，双亲为 } \lfloor i/2 \rfloor \text{，左孩子 } 2i \text{，右孩子 } 2i+1
\end{aligned}
$$

- **第一步，读性质 1、2**：第 $i$ 层最多 $2^{i-1}$ 个结点（每一层至多是上一层两倍）；各层加起来 $1 + 2 + \cdots + 2^{k-1} = 2^k - 1$。这是「每结点两个孩子」的结构上限。
- **第二步，读性质 3**：设 $n_0, n_1, n_2$ 分别为度为 0、1、2 的结点数。从「边」的角度数两次：总边数 $= n - 1$（连通无环），又 $= n_1 + 2n_2$（每个结点贡献的边数 = 其孩子数）。于是 $n_0 + n_1 + n_2 - 1 = n_1 + 2n_2$，化简得 $n_0 = n_2 + 1$。<span class="marginnote">性质 3 的证明是「<strong>用两种方式数同一件事</strong>」的经典——组合数学里的双计数法（double counting）。它能直接导出：空树、单结点之外，<strong>叶子数总是比「有二子的结点数」多 1</strong>。
<strong>第三步，读性质 4、5</strong>：完全二叉树结点编号「紧凑连续」，故深度由结点数唯一决定；编号 $i$ 的结点，其双亲与孩子的位置都能用整数除法定出——<strong>这是「数组存储二叉树」的地基</strong>。</span>

## 4 二叉树与满二叉树、完全二叉树的关系

三个概念的关系需要厘清：

**满二叉树** ⊂ **完全二叉树** ⊂ **二叉树**；
满二叉树是「最密」的二叉树：所有叶子都在最后一层，且都在最底层；
完全二叉树是「编号连续」的二叉树：允许最后一层不满，但必须靠左。

**辨析｜易错点：完全二叉树 ≠ 满二叉树的删节。** 完全二叉树「最后一行靠左」这一约束，不是「随便缺几个结点」——若中间缺一个结点导致编号不连续，就不再是完全二叉树，也无法享受「数组紧凑存储」的编号性质。<span class="marginnote">判断一棵二叉树是否完全，最可靠的办法是「<strong>按编号逐层检查是否连续</strong>」：编号 1..n 无缺号即完全。层序遍历时一旦出现空位，其后就不允许再出现结点——这个规则也是层序遍历题目的常考点。</span>

## 5 二叉树形态的计数

由性质 3 可以推出一类计数问题：**含 $n$ 个结点、形态不同的二叉树有多少棵？** 设 $n$ 个结点的不同二叉树形态数为 $b_n$，把根固定后，左子树有 $k$ 个结点、右子树有 $n-1-k$ 个结点，枚举 $k$ 得递推：

$$
b_0 = 1, \qquad b_n = \sum_{k=0}^{n-1} b_k\, b_{n-1-k}
$$

这个递推正是**卡特兰数**：$b_n = \frac{1}{n+1}\binom{2n}{n}$。$n=3$ 时 $b_3 = 5$——三结点的二叉树恰有 5 种形态。<span class="marginnote">这与《双端队列》一节里「出栈序列的计数」是同一个数列。卡特兰数在二叉树、括号配对、多边形剖分之间反复出现——<strong>不同问题的计数殊途同归</strong>。第六篇末尾的《树的计数》会专门展开。</span>

## 6 小结

- 二叉树：每结点**至多两子树，且分左右**；递归定义（左子树 + 右子树）。
- 满二叉树：$2^k - 1$ 个结点全填满；完全二叉树：编号连续、末行靠左。
- 性质 1、2：第 $i$ 层至多 $2^{i-1}$ 个，深度 $k$ 至多 $2^k-1$ 个。
- 性质 3：$n_0 = n_2 + 1$，用双计数法证明。
- 性质 4、5：完全二叉树深度 $\lfloor \log_2 n \rfloor + 1$，编号 $i$ 的双亲/孩子可由整数除法定出。
- $n$ 个结点二叉树形态数为**卡特兰数**。
