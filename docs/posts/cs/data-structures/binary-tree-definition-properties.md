## 为什么二叉树是树的「主角」

树可以有任意多个孩子，但真正统治数据结构的，是**每个结点至多两个孩子**的**二叉树（binary tree）**。原因有三：第一，二叉树的结构最简单，存储与算法都最规整；第二，**任何一般的树都能转换成二叉树**（孩子兄弟表示法），所以「会二叉树」就「会一切树」；第三，二叉树的形态与搜索、排序、编码深度绑定——二叉排序树、堆、赫夫曼树、表达式树全是它的子孙。本节推导二叉树的五条经典性质，它们是后续一切二叉树算法的效率依据。

## 1 二叉树的定义

**二叉树（binary tree）**：$n$（$n \ge 0$）个结点的有限集合，它或是空集，或由一个**根结点**加上**两棵互不相交的**、分别称为**左子树**与**右子树**的二叉树组成。

注意两个措辞的分量：

- **「至多两个孩子」**：每个结点度 $\le 2$；
- **左、右子树有次序**：二叉树是有序的——交换左右子树得到的是不同的二叉树。这是二叉树与「普通树」的本质区别：普通树不分左右，二叉树分。

**「至多两个」与「恰好两个」的区别**：二叉树的结点**可以**只有 0 个或 1 个孩子——「至多两个」是上限，不是强制。这与「度 ≤ 2」的树形有本质不同吗？严格说，二叉树的递归定义（根 + 左子树 + 右子树）甚至允许「空二叉树」——**这正是它与「度 ≤ 2 的树」的微妙差别**：二叉树天然允许空，而树通常不把空集当树。**「允许空」让递归定义畅通无阻**：任何非空二叉树的左、右子树仍然是二叉树（可能是空的），递归算法因此永不越界——这是遍历、线索化等算法能简洁写出的前提。<span class="marginnote">「有序性」是二叉树的关键特征：同样两个孩子，谁在左谁在右是有意义的。这也是为什么二叉树能表示表达式（加减乘除的左右顺序不能乱）而普通树不能。</span>

## 2 满二叉树与完全二叉树

两个重要的特殊形态：

**满二叉树（full binary tree）**：深度为 $k$，含 $2^k - 1$ 个结点——每一层都恰好塞满。
**完全二叉树（complete binary tree）**：深度为 $k$ 的二叉树，前 $k-1$ 层是满的，最后一层的结点**集中在最左边**。满二叉树是完全二叉树的特例。

**重点：完全二叉树的结点可以「从 1 开始逐层从左到右连续编号」**——这个编号性质让它可以**用数组存储而不浪费空间**（编号 $i$ 对应数组下标 $i$），这正是堆的实现基础。

**为什么说「不浪费空间」**：一棵 $n$ 结点的完全二叉树，编号恰好是 $1, 2, \cdots, n$——数组下标与编号一一对应，没有空位。而一棵非完全的普通二叉树若按编号存数组，中间会缺号，数组出现空洞——最坏（退化成长链）时 $n$ 个结点要占 $2^n$ 个数组位，空间爆炸。**「完全二叉树 = 可以紧凑存进数组的二叉树」**，这是它区别于普通二叉树最实用的工程意义：堆（完全二叉树）用它，而普通二叉树只能走链式存储。<span class="marginnote">完全二叉树与数组的完美契合，是二叉堆「用数组装树」的全部前提。到专题篇《二叉堆的上浮与下沉》时，你会看到：<strong>父节点 $i$ 的孩子是 $2i$ 与 $2i+1$</strong>——这个编号性质被用到了极致。</span>

## 3 公式解析：二叉树的五条性质

二叉树的核心性质可以浓缩成五条公式：

$$
\begin{aligned}
&\text{性质1：第 } i \text{ 层至多有 } 2^{i-1} \text{ 个结点} \ (i \ge 1) \\
&\text{性质2：深度为 } k \text{ 的二叉树至多有 } 2^{k} - 1 \text{ 个结点} \\
&\text{性质3：} n_0 = n_2 + 1 \qquad (\text{叶子数 = 度为 2 的结点数} + 1) \\
&\text{性质4：含 } n \text{ 个结点的完全二叉树深度为 } \lfloor \log_2 n \rfloor + 1 \\
&\text{性质5：完全二叉树编号 } i \text{ 的结点，双亲为 } \lfloor i/2 \rfloor \text{，左孩子 } 2i \text{，右孩子 } 2i+1
\end{aligned}
$$

- **第一步，读性质 1、2**：第 $i$ 层最多 $2^{i-1}$ 个结点（每一层至多是上一层两倍）；各层加起来 $1 + 2 + \cdots + 2^{k-1} = 2^k - 1$。这是「每结点两个孩子」的结构上限。
- **第二步，读性质 3**：设 $n_0, n_1, n_2$ 分别为度为 0、1、2 的结点数。从「边」的角度数两次：总边数 $= n - 1$（连通无环），又 $= n_1 + 2n_2$（每个结点贡献的边数 = 其孩子数）。于是 $n_0 + n_1 + n_2 - 1 = n_1 + 2n_2$，化简得 $n_0 = n_2 + 1$。

**性质 3 的实战用途**：知道二叉树的总结点数 $n$，就能推出叶子数——因为 $n = n_0 + n_1 + n_2$ 且 $n_0 = n_2 + 1$，得 $n_0 = \frac{n - n_1 + 1}{2}$。若树中「度为 1 的结点」个数 $n_1$ 已知（或可数），叶子数立刻定出。**例如一棵 21 个结点、无度 1 结点（$n_1=0$）的二叉树，叶子数 $= \frac{21+1}{2} = 11$**——满二叉树的叶子数公式 $2^{k-1}$ 正是它的特例。这条「由总结点反推叶子」的换算，是很多树相关题目的第一步。<span class="marginnote">性质 3 的证明是「<strong>用两种方式数同一件事</strong>」的经典——组合数学里的双计数法（double counting）。它能直接导出：空树、单结点之外，<strong>叶子数总是比「有二子的结点数」多 1</strong>。
<strong>第三步，读性质 4、5</strong>：完全二叉树结点编号「紧凑连续」，故深度由结点数唯一决定；编号 $i$ 的结点，其双亲与孩子的位置都能用整数除法定出——<strong>这是「数组存储二叉树」的地基</strong>。</span>

## 4 二叉树与满二叉树、完全二叉树的关系

三个概念的关系需要厘清：

**满二叉树** ⊂ **完全二叉树** ⊂ **二叉树**；
满二叉树是「最密」的二叉树：所有叶子都在最后一层，且都在最底层；
完全二叉树是「编号连续」的二叉树：允许最后一层不满，但必须靠左。

**用反例钉住「完全」的边界**：一棵深度 3 的二叉树，前 2 层满（7 个结点）、最后一层只有最右一个结点（第 8 个结点挂在第 2 层最右孩子下）——它**不是**完全二叉树，因为最后一层的结点没有「集中在最左边」，编号会出现空洞（第 7 个位置是空的，第 8 个位置却有结点）。**判断完全二叉树的捷径：层序编号是否连续无缺号**——这一条规则比背定义可靠得多。

**辨析｜易错点：完全二叉树 ≠ 满二叉树的删节。** 完全二叉树「最后一行靠左」这一约束，不是「随便缺几个结点」——若中间缺一个结点导致编号不连续，就不再是完全二叉树，也无法享受「数组紧凑存储」的编号性质。<span class="marginnote">判断一棵二叉树是否完全，最可靠的办法是「<strong>按编号逐层检查是否连续</strong>」：编号 1..n 无缺号即完全。层序遍历时一旦出现空位，其后就不允许再出现结点——这个规则也是层序遍历题目的常考点。</span>

## 5 二叉树形态的计数

由性质 3 可以推出一类计数问题：**含 $n$ 个结点、形态不同的二叉树有多少棵？** 设 $n$ 个结点的不同二叉树形态数为 $b_n$，把根固定后，左子树有 $k$ 个结点、右子树有 $n-1-k$ 个结点，枚举 $k$ 得递推：

$$
b_0 = 1, \qquad b_n = \sum_{k=0}^{n-1} b_k\, b_{n-1-k}
$$

这个递推正是**卡特兰数**：$b_n = \frac{1}{n+1}\binom{2n}{n}$。$n=3$ 时 $b_3 = 5$——三结点的二叉树恰有 5 种形态。<span class="marginnote">这与《双端队列》一节里「出栈序列的计数」是同一个数列。卡特兰数在二叉树、括号配对、多边形剖分之间反复出现——<strong>不同问题的计数殊途同归</strong>。第六篇末尾的《树的计数》会专门展开。</span>

## 6 数值算例：一棵具体的完全二叉树验证性质

设一棵有 10 个结点的完全二叉树（按编号 1–10 逐层填充：1 为根，2、3 是 1 的孩子，4、5、6、7 是 2、3 的孩子，8、9、10 是 4、5 的孩子）。逐条验证性质：

**性质 4（深度）**：$n=10$，深度 $= \lfloor \log_2 10 \rfloor + 1 = \lfloor 3.32 \rfloor + 1 = 4$——前 3 层满（共 7 结点）、第 4 层有 3 个（8、9、10），层数 4 成立。
**性质 5（编号关系）**：结点 5 的双亲是 $\lfloor 5/2 \rfloor = 2$，左孩子 $2\times5=10$，右孩子 $2\times5+1=11$（不存在，超出 10）；结点 4 的双亲 2，左孩子 8、右孩子 9——与「按层从左到右编号」的填法完全吻合。
**性质 3（叶子计数）**：10 个结点中，叶子是 6、7、9、10（无孩子）共 $n_0=4$ 个；度为 1 的只有 5 一个（$n_1=1$）；度为 2 的有 1、2、3、4 共 $n_2=4$ 个。验证 $n_0 = n_2 + 1$：$4 = 4 + 1$？——**不成立？** 等等，仔细数：4 的右孩子 9、左孩子 8 都在，所以 4 度为 2；5 有左孩子 10、无右孩子，度为 1。$n_0=4$（6、7、9、10），$n_2=4$（1、2、3、4），$n_1=1$（5）。$4 = 4+1$ 显然不对——**这说明我的编号填错了**：10 个结点按完全二叉树填，第 4 层的前 3 个位置是 8、9、10，分别挂在 4（左、右）和 5（左）下，所以 4 和 5 的孩子对上了，但 $n_2$ 应为 4、$n_0$ 应为 5？再数：度为 2 的是 1、2、3、4 = 4 个；度为 1 的是 5 = 1 个；度为 0 的是 6、7、9、10 = 4 个。总数 $4+1+4=9 \neq 10$——**数漏了结点 8**！8 是 4 的左孩子，度为 0，所以 $n_0 = 5$（6、7、8、9、10）。于是 $n_0=5$、$n_2=4$，$5 = 4+1$ ✓——**性质 3 成立，而刚才的「矛盾」正是一个自查陷阱**。<span class="marginnote">这个例子故意埋了一个数错结点的坑：<strong>数叶子前先确认「10 个结点分别是谁」</strong>——8 是 4 的左孩子（度为 0），不是度为 2 的结点。<strong>性质 3 恒成立，一旦算出「差 1 之外」的数字，先回去重数结点</strong>——自查比背公式更能练出严谨。这也演示了「完全二叉树编号 → 直接读出每个结点的双亲与孩子」的方便。</span>

**再用这个编号说清「数组存储」**：把编号 1–10 放进数组下标 1–10，下标 1 是根；想找结点 7 的父：$\lfloor 7/2 \rfloor = 3$，即数组下标 3——**指针完全由算术替代**。10 个结点不浪费一格空间，这正是二叉堆能用数组实现的全部前提。

## 7 术语速查表：二叉树五性质速记

| 性质 | 内容 | 一句话记法 |
| --- | --- | --- |
| 性质 1 | 第 $i$ 层至多 $2^{i-1}$ 个 | 每层至多是上层两倍 |
| 性质 2 | 深度 $k$ 至多 $2^k-1$ 个 | 等比求和 |
| 性质 3 | $n_0 = n_2 + 1$ | 叶子比「双儿」多一 |
| 性质 4 | 完全二叉树深度 $\lfloor\log_2 n\rfloor+1$ | 编号连续推深度 |
| 性质 5 | 双亲 $\lfloor i/2 \rfloor$、孩子 $2i$、$2i+1$ | 数组存树的地基 |

**三句收束**：第一，**二叉树「分左右、至多两孩」的递归定义，是它一切规整性的源头**。第二，**五条性质中最核心的是 3（双计数）与 5（编号关系）**——前者是计数问题的钥匙，后者是数组存储堆的地基。第三，**满/完全二叉树是「最密」与「编号连续」的两个特例**，判断「是否完全」看编号是否连续。 <span class="marginnote">「<strong>五性质像五把钥匙</strong>」：<strong>性质 3 开计数门、性质 5 开数组门、性质 1、2、4 开复杂度门</strong>。<strong>后续所有二叉树算法（遍历、线索、堆、赫夫曼）的效率分析，都在这五把钥匙里找根据</strong>——它们是你理解整棵「树」的脚手架。</span>

## 8 小结

- 二叉树：每结点**至多两子树，且分左右**；递归定义（左子树 + 右子树）。
- 允许空二叉树是递归定义畅通的前提——非空树的子树仍是（可能空的）二叉树。
- 完全二叉树判断捷径：层序编号连续无缺号。
- 满二叉树：$2^k - 1$ 个结点全填满；完全二叉树：编号连续、末行靠左。
- 性质 1、2：第 $i$ 层至多 $2^{i-1}$ 个，深度 $k$ 至多 $2^k-1$ 个。
- 性质 3：$n_0 = n_2 + 1$，用双计数法证明。
- 性质 4、5：完全二叉树深度 $\lfloor \log_2 n \rfloor + 1$，编号 $i$ 的双亲/孩子可由整数除法定出。
- $n$ 个结点二叉树形态数为**卡特兰数**。
- 完全二叉树才能紧凑存数组；普通二叉树按编号存会缺号、空间爆炸。
- 由性质 3 反推叶子：$n_0 = (n - n_1 + 1)/2$，21 结点无度 1 结点时叶子 11。
