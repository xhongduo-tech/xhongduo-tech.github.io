## 为什么编码要「变长」

等长编码（ASCII 每个字符 8 位）简单但浪费：英文里 `e` 比 `z` 出现频繁得多，却占一样的位数。**赫夫曼编码（Huffman coding）**是变长编码：**出现频率高的字符用短码，频率低的用长码**。它由赫夫曼树直接生成，并保证两个关键性质——**前缀性**（没有哪个编码是另一个编码的前缀，可无歧义解码）与**最优性**（在给定频率下平均码长最短）。从 ZIP 到 JPEG 到现代压缩器，赫夫曼编码是数据压缩的基石，也用它自己的方式诠释了信息论「信息量 = 负对数概率」的先见之明。

## 1 前缀编码：解码无歧义的关键

**前缀编码（prefix code）**：任何字符的编码都**不是**其他字符编码的**前缀**。

为什么必需？设 `a`、`b`、`c` 三个字符——`a` 的编码 `0` 是 `c` 的编码 `01` 的前缀。收到 `01` 时，无法判断是 `0` 后跟 `1`（`a` `b`）还是 `01`（`c`）——**解码歧义**。前缀编码保证：从码流起点开始，每读入一位，若构成某字符的编码，即可唯一确定；因为不可能存在「更长编码以此开头」。<span class="marginnote">前缀编码等价于「编码构成一棵二叉树的叶子」。把编码当作「根到叶子的路径」，0 走左、1 走右：前缀性 ⇔ 编码都在叶子、没有任何编码是另一编码路径的中间结点。<strong>编码集就是叶子集</strong>——这正是赫夫曼树的结构。</span>

## 2 赫夫曼编码的生成

用字符频率构造赫夫曼树（上一节的构造算法），然后**从根到每个叶子走一条路径，左分支记 0、右分支记 1**，路径上的 0/1 序列就是该叶子对应字符的编码。

```c
/* 从叶子回溯到根，再逆序得到编码 */
void getCode(int leaf) {
    int bits[MAX]; int n = 0;
    for (int c = leaf; c != root; c = parent[c])
        bits[n++] = (c == left[parent[c]]) ? 0 : 1;  /* 左分支记 0、右分支记 1 */
    for (int i = n - 1; i >= 0; i--) printf("%d", bits[i]);  /* 逆序输出 */
}
```

**重点：编码是从叶子回溯到根「逆序」得到的。** 从根到叶是「0/1 一路向下」，从叶到根是反方向，因此要把回溯途中记下的位**倒过来**才是正确编码。<span class="marginnote">注意编码方向：走左是 0 还是走右是 0，纯属约定；<strong>关键是一棵赫夫曼树 + 一种左右约定，就确定一套前缀编码</strong>。不同左右约定得到「镜像」的编码，平均码长相同。</span>

## 3 公式解析：平均码长与 WPL 的关系

设字符 $c_i$ 出现概率 $p_i$，编码长度 $l_i$，则平均码长：

$$
\bar{L} = \sum_{i=1}^{n} p_i \, l_i
$$

若权值取「出现次数」$w_i$，则总码长 $= \sum w_i l_i = WPL$。于是：

- **第一步，读等价**：总码长恰好就是赫夫曼树的带权路径长度 $WPL$——因为每个叶子被访问（编码）的路径长度就是它的码长。
- **第二步，读最优性**：赫夫曼树使 $WPL$ 最小 ⇒ 总码长最小 ⇒ **平均码长最短**。这就是「赫夫曼编码最优」的全部含义。
- **第三步，与信息论对照**：最优前缀编码的理论下界是香农熵 $H = -\sum p_i \log_2 p_i$ 位/符号。赫夫曼编码的平均码长满足 $H \le \bar{L} < H + 1$——**它逼近、但不一定达到熵界**（当概率恰为 $2^{-k}$ 时达到）。<span class="marginnote">「$H \le \bar{L} < H+1$」是赫夫曼编码与信息论的交汇点。到第二级《信息论》学熵与信源编码定理时，你会发现：<strong>赫夫曼编码就是「无损信源编码」在离散符号上的最优实现之一</strong>——压缩的极限是熵。</span>

## 4 赫夫曼译码：沿树下行

译码是编码的逆过程：从根出发，读到 0 走左、读到 1 走右；走到叶子就输出该叶子字符，然后回到根继续读。

```c
/* 译码：沿树下行，到叶子输出后回到根 */
void decode(const char* s) {
    int p = root;
    for (int i = 0; s[i]; i++) {
        p = (s[i] == '0') ? left[p] : right[p];   /* 读到 0 走左、读到 1 走右 */
        if (isLeaf(p)) { putchar(ch[p]); p = root; } /* 到叶输出，回到根 */
    }
}
```

**辨析｜易错点：译码错误 = 从错误的根出发。** 前缀编码保证了「不会把两个字符的编码切错」，但前提是**译码必须严格从根开始、到叶子结束**。若某位读错或从中间某结点出发，后续全部错位——这也是压缩数据里「一位错误可能破坏整个块」的原因。<span class="marginnote">「一位错误 → 整块错乱」催生了压缩格式里的<strong>错误检测与块结构</strong>：把数据分成独立压缩的块，每块自带校验。这让单个比特翻转的破坏局限于一块——工程上「隔离故障域」的思路。</span>

## 5 赫夫曼编码的现代形态

经典的赫夫曼编码有几个「升级版」工程形态：

**静态 vs 动态**：静态编码统计一遍频率、建树、编码（两趟）；动态编码一边读一边更新树（一趟，适合流式数据）。
**规范赫夫曼编码（canonical Huffman）**：约定一种「按码长排序」的规则，让编解码双方只共享码长表而非整棵树——大幅缩小**编码表**的体积，是现代压缩器（DEFLATE）采用的形式。
**与 LZ 系组合**：ZIP、gzip 先用 LZ77 去冗余，再用赫夫曼压缩——「字典匹配 + 熵编码」是现代无损压缩的标准流水线。<span class="marginnote">规范赫夫曼编码的价值是「<strong>减少元数据</strong>」：传一棵树很贵，传一份码长列表很便宜。这个「元数据与数据本身竞争空间」的矛盾，在文件压缩、网络协议、序列化格式里处处存在——<strong>能省的元数据，绝不多传</strong>。</span>

## 6 数值算例：从频率到编码表

用一组字符与频率构造赫夫曼编码：`a:0.40, b:0.20, c:0.15, d:0.10, e:0.15`（和为 1）。先合并两个最小频率 `d(0.10)` 与 `e(0.15)` 得 `0.25`，再与 `c(0.15)` 合并得 `0.40`……按构造算法逐步合并，约定左分支 0、右分支 1，得到编码表：

| 字符 | 频率 | 编码 |
| --- | --- | --- |
| a | 0.40 | `0` |
| b | 0.20 | `10` |
| c | 0.15 | `110` |
| d | 0.10 | `1110` |
| e | 0.15 | `1111` |

验算前缀性：`0` 之后没有别的编码以 `0` 开头；`10` 出现后，`11` 开头的编码不再含 `10` 前缀——**解码无歧义成立**。

平均码长 $\bar{L} = 0.40\times 1 + 0.20\times 2 + 0.15\times 3 + 0.10\times 4 + 0.15\times 4 = 2.25$ 位/符号。若改用等长编码，5 个字符需 $\lceil \log_2 5 \rceil = 3$ 位——赫夫曼省下 $0.75$ 位/符号。对照熵 $H = -\sum p_i\log_2 p_i \approx 2.15$ 位，满足 $H \le \bar{L} < H+1$：**逼近熵界但不到达**（因为概率不是 $2^{-k}$ 的精确幂）。

**重点：编码长度与频率严格负相关——频率越高、码越短，这就是「把最常用的话说得最短」。**<span class="marginnote">这张表同时验证了三件事：<strong>前缀性（解码无歧义）、最优性（平均码长 2.25 位贴近熵 2.15 位）、以及等长 vs 变长的差距（3 位 vs 2.25 位）</strong>。数据压缩的每一分收益，都来自「按频率重新分配码长」。</span>

**辨析｜易错点：赫夫曼编码不唯一，但平均码长唯一。** 合并频率相同的结点时，选择不同的合并顺序会得到**不同的赫夫曼树**，从而有不同的编码表（甚至某些字符的码长可能不同）——但**平均码长（$WPL/n$）始终最小且相同**。所以「赫夫曼编码」是一族最优编码，不是唯一的一个。

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| 前缀编码 | 无编码是另一编码的前缀 |
| 变长编码 | 高频短码、低频长码 |
| WPL | 带权路径长度 = 总码长 |
| 平均码长 | $\sum p_i l_i$，贴近熵界 |
| 规范赫夫曼 | 只传码长表、不传整棵树的工程形态 |

**延伸对照**：赫夫曼树与《最佳归并树》同构——「每次合并两个最小」的贪心，在压缩（赫夫曼编码）与外部排序（最佳归并树）里是同一把尺子。

## 7 小结

- 变长编码：高频字符短码、低频字符长码，平均码长更短。
- **前缀编码**：任何编码不是其他编码的前缀，解码无歧义。
- 赫夫曼编码：由赫夫曼树生成，0/1 走左右分支，叶子到根**逆序**得码。
- 总码长 = $WPL$，故赫夫曼编码平均码长最短（最优性）。
- 平均码长满足 $H \le \bar{L} < H+1$，逼近信息论熵界。
- 译码沿树下行、到叶输出；现代形态有动态赫夫曼、规范赫夫曼（DEFLATE）。
