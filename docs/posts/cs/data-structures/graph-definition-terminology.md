## 为什么从图的定义开始

线性结构讲「前后」，树讲「层次」，但现实是**多对多**的：社交网络里任何两人都可能成为朋友，公路网里任意两个城市都可能相连，互联网里任何网页都可能链接到任何网页。**图（graph）**是描述「多对多」关系的最一般结构，也是数据结构课程的「最终形态」——线性与树都是它的特例。图的应用覆盖网络路由、路径规划、任务调度、推荐系统，甚至大模型里的知识图谱与计算图。本节先把图的定义与全套术语钉死，为后面存储、遍历、最短路、最小生成树铺路。

## 1 图的定义

**图（graph）**：$G = (V, E)$，其中 $V$ 是**非空**的顶点集合，$E$ 是顶点之间关系的集合。

- 若边 $e$ 无序——$(v_i, v_j)$ 与 $(v_j, v_i)$ 是同一条边，称为**无向边**，图为**无向图（undirected graph）**；
- 若边有方向——记作 $<v_i, v_j>$，称为**弧（arc）**，$v_i$ 是**弧尾（tail）**、$v_j$ 是**弧头（head）**，图为**有向图（directed graph）**。

**重点：图的边集可以是「无序对」或「有序对」，这是区分无向图与有向图的唯一标准。**<span class="marginnote">记法上：无向边用圆括号 $(u,v)$，有向弧用尖括号 $<u,v>$。一个有向图的「无向化」（忽略方向）会得到它的基础无向图，但原始方向信息会丢失——很多图算法（如强连通分量）恰恰不能丢方向。</span>

## 2 基本术语：度、路径、连通

图有自己的「成员语言」，全部围绕顶点与边的计数：

**顶点的度（degree）**：与该顶点相关联的边的条数。无向图中，度 = 出边数 + 入边数；有向图中拆成**入度（in-degree）**与**出度（out-degree）**。
**路径（path）**：顶点序列 $v_{p1}, v_{p2}, \cdots, v_{pm}$，相邻顶点之间有边。路径上的边数叫**路径长度**。
**回路/环（cycle）**：起点与终点相同的路径。不含重复边的回路叫**简单回路**。
**连通（connected）**：无向图中，两顶点间存在路径则称连通。
**子图（subgraph）**：顶点集与边集分别是原图的子集。

**重点：无向图中「度之和 = 2 倍边数」，有向图中「入度之和 = 出度之和 = 边数」。** 这两条「握手定理」是图论里一切计数证明的起点。

**从握手定理立刻推出的结论**：无向图中，**度数为奇数的顶点个数一定是偶数**——因为度之和是偶数（$2|E|$），而偶数个奇数和才可能为偶。这个「奇数度顶点数为偶数」的推论，是「哥尼斯堡七桥问题」无解的核心：七桥对应一个含 4 个奇数度顶点的图，而要一笔画（欧拉回路）所有顶点度数必须为偶。**一个教科书级的例子证明：最抽象的图论定理，直接判定了两百年前那道经典问题的答案**——图论不是纸上谈兵，它判定的正是现实世界的可行与不可行。<span class="marginnote">握手定理（handshaking lemma）：无向图所有顶点的度之和等于边数的两倍，因为每条边贡献两个「端点度」。这个「<strong>每条边数两次</strong>」的观察，与树的性质 3（$n_0 = n_2+1$）的双计数法是同一手法。</span>

## 3 连通性家族：连通图、连通分量、强连通

连通性是图论最重要的分类维度：

**连通图（connected graph）**：无向图中任意两个顶点之间都连通。
**连通分量（connected component）**：无向图的**极大连通子图**。「极大」= 再多加一个顶点就不连通。
**强连通图（strongly connected graph）**：有向图中任意两顶点 $u, v$ 都**互相**可达（$u$ 可达 $v$ 且 $v$ 可达 $u$）。
**强连通分量（SCC）**：有向图的极大强连通子图。

**「极大」二字的精确含义**：连通分量不是「随便一个连通的子图」，而是「不能再大的连通子图」——往它里面再加任何一个顶点，整个子图就不再连通。这个「极大」让分量成为唯一的「划分」：每个顶点恰好属于一个连通分量（无向），所有分量把顶点集**无重叠地瓜分**。**「无重叠地划分」是连通分量最重要的结构性质**——它让「有多少个连通分量」「哪些点同属一块」成为可以精确回答的问题，这正是后面 DFS 求连通分量、Kruskal 用并查集判连通的前提。<span class="marginnote">有向图与无向图的连通性差别很大：无向图只要「双向通路」就连通；有向图要求「两个方向都可达」才算强连通。一个「单向环」的图——如 $1 \to 2 \to 1$ 加 $2 \to 3$——并不强连通，因为 3 无法回到 1。<strong>方向让连通性问题变难</strong>，这也是后面 Tarjan 算法（专题篇）存在的理由。</span>

## 4 公式解析：完全图的边数

**完全图**：无向图中每对顶点之间恰有一条边（记为 $K_n$）；有向图中每对顶点之间有两条弧。

$$
E_{\text{无向完全}} = \binom{n}{2} = \frac{n(n-1)}{2}, \qquad E_{\text{有向完全}} = n(n-1)
$$

- **第一步，读无向完全图**：从 $n$ 个顶点中选 2 个构成一条边，即组合数 $\binom{n}{2}$。
- **第二步，读有向完全图**：每对顶点有两条方向相反的弧，故是无向的两倍 $n(n-1)$。
- **第三步，读「稠密 vs 稀疏」的阈值**：完全图的边数 $\Theta(n^2)$ 是「稠密」的极端；边数 $O(n)$ 的是「稀疏」图（如树、公路网、社交网络实际图）。**边数是否接近 $n^2$，决定了选邻接矩阵还是邻接表**——这是下一节存储结构选择的依据。

**用数字体感「稠密 vs 稀疏」**：$n = 10^4$ 个顶点的完全图有约 $5\times10^7$ 条边；而一张真实的社交网络图，$10^4$ 个顶点的边数可能只有 $10^4 \sim 10^5$ 条——比完全图少 2~3 个数量级。**「稀疏」是绝大多数真实图的常态**：公路、社交、网页链接、电路，全是边数远小于 $n^2$ 的稀疏图。这也是为什么工程里邻接表（只存存在的边）远比邻接矩阵（存 $n^2$ 个位置）常用——**结构的选择由「真实的数据形态」而非「理论上的最坏」决定**。<span class="marginnote">「$\frac{n(n-1)}{2}$」是图论里的出场率之王：它既是最坏边数，也是「任意两点连一条边」的组合计数。<strong>判断一个结构是否稀疏，就看它与 $n^2$ 的相对差距</strong>——差距大，就该用只存「存在的边」的存储。</span>

## 5 核心对比表：线性、树、图

三种逻辑结构的全景对比：

| 维度 | 线性结构 | 树 | 图 |
| --- | --- | --- | --- |
| 关系 | 一对一 | 一对多 | 多对多 |
| 前驱 | 至多一个 | 至多一个 | 任意 |
| 后继 | 至多一个 | 至多多个 | 任意 |
| 环 | 无 | 无 | 可有 |
| 路径唯一性 | 唯一 | 唯一 | 不唯一 |
| 典型问题 | 查找、排序 | 层次、编码 | 最短路、连通、流 |

三条规律：第一，**图是「关系的完全释放」**——前驱后继都不受限，环也允许，因此问题复杂度陡增。第二，**树是图的特例**（无环连通图），线性是树的特例——图算法的最短路径、最小生成树，在树上退化成了平凡问题。第三，**图算法是数据结构课程的「终局」**：最短路、拓扑排序、关键路径、最大流，每一个都是「图 + 某种数据结构（栈、队列、堆、并查集）」的合奏。

## 6 数值算例：用握手定理反推边数

空讲「度之和 = 2 倍边数」不如算一道。设一个无向图有 8 个顶点，度序列为 $3, 3, 2, 2, 1, 1, 1, 1$——先验证它可能吗？

**度之和**：$3+3+2+2+1+1+1+1 = 14$。握手定理说「度之和 $= 2|E|$」，所以 $|E| = 14/2 = 7$ 条边——**是整数，且能画出来**（比如一条路径加几根弦）。

**再做一道反例**：度序列 $3, 3, 3, 1$，度之和 $= 10$，$|E| = 5$——看起来可以？但**有向图里**「入度之和 = 出度之和 = $|E|$」，若某人给出「入度 $2,2,2,2$、出度 $2,2,2,2$」则 $|E|=8$ 且各顶点入出相等——合法。而「入度 $3,1,3,1$、出度 $3,1,3,1$」也合法（各顶点入出相等）。**握手定理不只是「数一遍」**：它还是「判定一个度序列是否可能存在」的第一道检验——**度之和必须为偶数（无向）**。<span class="marginnote">握手定理的用处比想象中大：<strong>它立刻排除「度之和为奇数的无向图」这类不可能存在的输入</strong>。<strong>很多图论证明（树的性质 3、欧拉路径存在性）的第一步就是「数度之和」</strong>——<strong>把「每条边数两次」这个动作练熟，图论大门就进了一半</strong>。</span>

## 7 术语速查表：图的基本术语

| 术语 | 含义 | 一句话记法 |
| --- | --- | --- |
| 无向边 / 有向弧 | $(u,v)$ 无序 / $<u,v>$ 有序 | 圆括号 / 尖括号 |
| 度 / 入度 / 出度 | 关联边数 / 进入 / 离开 | 有向拆两半 |
| 路径 / 回路 | 顶点序列 / 闭合路径 | 回路起点=终点 |
| 连通 / 连通分量 | 可达 / 极大连通子图 | 无向的概念 |
| 强连通分量 | 互相可达的极大子图 | 有向的概念 |
| 完全图 | 每对顶点都相连 | 无向 $\binom{n}{2}$ 条边 |
| 稠密 / 稀疏 | 边数 $\sim n^2$ / $\sim n$ | 决定存储选型 |

**三句收束**：第一，**图是「多对多」关系的最一般结构**——线性与树都是它的特例。第二，**握手定理（度之和 $=2|E|$）是一切计数证明的起点**——「每条边数两次」这个手法贯穿图论。第三，**无向看连通、有向看强连通**——方向让连通性问题变难，这是后面强连通分量算法存在的理由。<span class="marginnote">「<strong>图的术语是一套精确的语言</strong>」：<strong>顶点、边、度、路径、连通</strong>——每个词都对应一个可检验的定义。<strong>学图的第一步不是记算法，而是先把这套语言说准</strong>——术语不清，后面的遍历、最短路全都寸步难行。本节把这些词钉死，就是给整章打地基。</span>

## 8 小结

- 图 $G = (V, E)$：顶点集 + 边集；无向边用圆括号，有向弧用尖括号。
- 术语：度、入度/出度、路径、回路、子图、连通、连通分量、强连通分量。
- 握手定理：无向图度之和 $= 2|E|$；有向图入度之和 $=$ 出度之和 $= |E|$。
- 连通分量 = 极大连通子图，无重叠地把顶点集瓜分。
- 真实图几乎都是稀疏图——工程上邻接表比邻接矩阵常用。
- 完全图：无向 $n(n-1)/2$ 条边，有向 $n(n-1)$ 条。
- 「极大连通子图」= 不能再大的连通子图，是唯一划分。
- 稠密（$\sim n^2$ 条边）与稀疏（$\sim n$ 条边）决定存储选型。
- 图是线性与树的「多对多」推广，图算法是数据结构课程的终局。
- 数值算例：度序列 3,3,2,2,1,1,1,1 → 7 条边，握手定理先验可画。
- 推论：奇数度顶点个数为偶数——七桥问题的判决依据。
