## Trie 不止存单词

上一节的 Trie 存字符串。本节展示它的两个「换皮」应用：**前缀统计**（单词计数 + 前缀计数）与**异或最大对**（把二进制位当「字符」塞进 Trie）。第二个尤其精彩——**把每个数拆成二进制位，建成一棵「二进制 Trie」**，然后「沿着与当前位相反的位走」，贪心找出异或最大值。这展示了 Trie 的本质：**它存的是「有序序列的共享前缀」——序列可以是单词的字符，也可以是数字的比特**。换一种「字符集」，Trie 就换一个战场。

## 1 应用一：前缀统计与词频

在 Trie 上每个结点加一个 `sum`（子树单词总数）或直接用 `cnt`（结尾计数）：

- **统计某前缀出现次数**：走到前缀末尾结点，返回它的子树总和（或该结点计数）；
- **词频排序 / Top 前缀**：DFS 遍历 Trie，按 `cnt`/`sum` 排序。

**重点：前缀统计 = 「走到前缀结点 + 读子树信息」**——Trie 把「前缀」变成「一个结点」，统计就是一次定位 + 一次读取。<span class="marginnote">「<strong>前缀即结点</strong>」让统计变成读结点：<strong>「以 app 开头的词有几个」= 走到 app 结点，读它的 sum</strong>。<strong>这个「把查询对象固化成结点」的思想，是 Trie 一切应用的共同模式</strong>。</span>

## 2 应用二：异或最大对

**问题**：给 $n$ 个数，求两个数使 $a[i] \oplus a[j]$ 最大（$\oplus$ 是异或）。

**思路**：把每个数写成二进制（如 31 位），建成一棵**二进制 Trie**（每位 0/1 一个孩子）：

1. 把所有数插入二进制 Trie；
2. 对每个 $a[i]$，在 Trie 里**沿着「与当前位相反」的位走**（贪心：异或想要 1，就找相反位）：
   - 相反位存在 → 走它，该位异或得 1；
   - 不存在 → 走同向位，该位异或得 0；
3. 从高位到低位贪心，得到与 $a[i]$ 异或最大的配对。

```cpp
int query(int x) {                    /* 在二进制 Trie 里找与 x 异或最大的数 */
    int p = 0, ans = 0;
    for (int b = 30; b >= 0; b--) {   /* 从高位到低位贪心 */
        int bit = (x >> b) & 1;
        int want = bit ^ 1;           /* 想要相反位，使该位异或得 1 */
        if (ch[p][want]) {            /* 相反位存在 → 走它 */
            p = ch[p][want];
            ans |= (1 << b);
        } else {
            p = ch[p][bit];           /* 不存在 → 走同向位 */
        }
    }
    return ans;
}
```

**公式解析：异或最大对的复杂度**

$$
T = O(n \cdot B) \quad \text{（$B$ 为位数，$n$ 个数插入 + 查询）}
$$

- **第一步，读「贪心」**：从最高位开始，每一位都想要异或结果 = 1——沿相反位走。高位优先，贪心正确。
- **第二步，读「$O(nB)$」**：每个数插一次 $O(B)$、查一次 $O(B)$——$n$ 个 $O(nB)$。
- **第三步，读「为什么 Trie 合适」**：数太大不能开数组，但 Trie 只建「用到的前缀」——空间 $O(nB)$ 可控。<span class="marginnote">「<strong>二进制 Trie = 异或的贪心导航</strong>」：<strong>从最高位开始「想要相反位」，Trie 恰好回答「相反位有没有」</strong>。<strong>这个「沿位贪心」把最大异或从 $O(n^2)$ 降到 $O(nB)$</strong>——数据结构把暴力枚举变成了导航。</span>

## 3 变体：异或最小值、区间异或

**异或最小值**：反向贪心——每一步尽量走同向位（异或结果尽量 0）；
**区间异或最大值**：利用异或性质 $a[l..r]$ 的异或 = 前缀异或 $p[r] \oplus p[l-1]$——问题变成「在 $p$ 数组里找最大异或对」，用二进制 Trie + 滑动/分治。

**重点：异或类问题的通用套路是「前缀异或 + 二进制 Trie」**——把「区间异或」转成「两个前缀异或的异或」，再用 Trie 找最大对。<span class="marginnote">「<strong>区间异或 → 前缀异或 → 二进制 Trie</strong>`」是一条万能链：<strong>$a[l..r]$ 的异或 = $p[r] \oplus p[l-1]$</strong>——<strong>区间问题化成「点对问题」，点对问题交给 Trie</strong>`。这串翻译在 LeetCode 高频题里反复出现。</span>

## 4 Trie 应用总览

| 应用 | 「字符集」 | 关键技巧 |
| --- | --- | --- |
| 字典 / 拼写检查 | 字母 | 结尾标记 |
| 前缀统计 / 自动补全 | 字母 | 结点存 sum/cnt |
| 词频排序 | 字母 | DFS 遍历 |
| 异或最大对 | 二进制位 | 沿相反位贪心 |
| 区间异或 | 二进制位 | 前缀异或 + 二进制 Trie |
| 最长公共前缀 | 字母 | 找最深「分叉前」结点 |

**重点：Trie 的「字符集」可以任意替换——字母、数字、比特——只要序列有「前缀结构」**。换字符集，Trie 就换一类问题。<span class="marginnote">「<strong>Trie = 序列的共享前缀树</strong>」是它的统一抽象：<strong>单词是「字母序列」，数字是「比特序列」——只要是序列，就有前缀，就能建 Trie</strong>。<strong>「识别出序列结构」是套用 Trie 的第一步</strong>。</span>

## 5 从 Trie 到更复杂的字符串结构

**AC 自动机（Aho-Corasick）**：Trie + 失配指针——多模式串同时匹配，是 Trie 的进阶；
**可持久化 Trie**：每个版本一棵树——支持「历史查询」「区间内找最大异或」；
**后缀 Trie / 后缀树**：把后缀建进 Trie——字符串匹配与子串问题的高级结构。

**重点：Trie 是「字符串数据结构的起点」**——AC 自动机、后缀树、可持久化 Trie 都在它的基础上加料。学好 Trie，是通向字符串算法王国的门票。<span class="marginnote">「<strong>Trie 是字符串算法族的地基</strong>」：<strong>AC 自动机 = Trie + 失配指针（多模式匹配），后缀树 = 所有后缀的压缩 Trie</strong>。<strong>把 Trie 的「沿字符走」学到家，再学这些进阶结构就是「加一个机制」的事</strong>。</span>

**辨析｜易错点：二进制 Trie 的「位数」要统一。** 异或最大对通常从最高位（如第 30 位）开始贪心——若两个数位数不一致，高位的「0」也要参与（不足位补 0）。插入与查询必须用**相同的位数范围**，否则「相反位导航」会错位。统一 `for (b = 30; b >= 0; b--)` 是这类题的固定写法。

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| 前缀统计 | 走到前缀结点 + 读 sum |
| 二进制 Trie | 把数按比特位建 Trie |
| 沿相反位贪心 | 异或想要 1 就走相反位 |
| 前缀异或 | $a[l..r]$ = $p[r] \oplus p[l-1]$ |
| AC 自动机 | Trie + 失配指针（多模式匹配） |

**辨析｜易错点：二进制 Trie 的「异或最大」是「高位贪心」，前提是前缀性质成立。** 从最高位开始，每一位都想要异或结果 1——高位决定了数的大小量级，先保高位一定最优。这个「高位优先」是异或贪心正确性的根基。

**一句话**：Trie 的字符集可以任意替换——字母、数字、比特，有前缀结构的序列都能建树。

## 6 小结

- 前缀统计：走到前缀结点 + 读 sum/cnt——「前缀即结点」。
- 异或最大对：二进制 Trie + 沿相反位贪心，$O(nB)$。
- 区间异或：前缀异或 + 二进制 Trie 的通用套路。
- 字符集可换：字母、数字、比特——有前缀结构的序列都能建 Trie。
- 变体：AC 自动机、可持久化 Trie、后缀树。
- Trie = 序列的共享前缀树——识别序列结构是套用第一步。
