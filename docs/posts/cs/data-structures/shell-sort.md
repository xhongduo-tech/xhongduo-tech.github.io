## 为什么插入排序要「大步走」

插入排序每次把元素移动一格，逆序时一个元素要挪 $O(n)$ 次。**希尔排序（Shell sort）**看穿了这一点：**先让元素大步跨越（移动多个位置），把序列「基本有序」，再用插入排序收尾**。它的做法是「**缩小增量**」：按增量 $d$ 把序列分成若干子序列，分别做插入排序；增量逐渐缩小，最后 $d=1$ 就是完整插入排序。因为经过大步交换，序列已经「大致有序」，最后的插入排序几乎线性。希尔排序是插入排序的「大规模远程打击」升级版，复杂度介于 $O(n)$ 与 $O(n^2)$ 之间。

## 1 希尔排序的思想

设增量序列 $d_1 > d_2 > \cdots > d_t = 1$。对每个 $d$：

- 把序列分成 $d$ 组，每组是「相隔 $d$ 个位置」的元素；
- 对每组做**直接插入排序**（此时元素移动跨度为 $d$，大步前进）；
- $d$ 缩小，重复，直到 $d=1$ 做一次完整插入排序。

```cpp
// 希尔排序：缩小增量，每趟对「相隔 d」的元素做插入排序
void shellSort(int a[], int n) {
    for (int d = n / 2; d >= 1; d /= 2) {      // 增量从 n/2 递减到 1
        for (int i = d; i < n; ++i) {          // 对每组子序列做插入排序
            int tmp = a[i], j;
            for (j = i; j >= d && a[j - d] > tmp; j -= d)
                a[j] = a[j - d];               // 元素按跨度 d 大步移动
            a[j] = tmp;
        }
    }
}
```

**重点：希尔排序的移动是「按增量 d 跳跃」的——一趟就能把元素移动很远，这是它快于普通插入排序的根源。**<span class="marginnote">为什么「先大步后小步」有效？因为<strong>逆序元素经过大步交换后，距离目标位置已经不远</strong>——最后 $d=1$ 的插入排序只需少量移动。<strong>「大步逼近 + 小步收敛」是排序里的「分阶段」策略</strong>，希尔排序是最早的超越 $O(n^2)$ 的比较排序。</span>

## 2 增量序列的选择

增量序列是希尔排序的灵魂——不同的 $d$ 序列，复杂度天差地别：

**Shell 原始序列**：$n/2, n/4, \cdots, 1$——最坏 $O(n^2)$；
**Hibbard 序列**：$2^k - 1$——最坏 $O(n^{3/2})$；
**Sedgewick 序列**：$9\cdot4^k - 9\cdot2^k + 1$ 等——最坏 $O(n^{4/3})$，经验极佳。

**重点：增量序列要「互不整除、末尾为 1」**——互质能让各趟子序列充分交错，避免「上一趟的努力被下一趟破坏」。<span class="marginnote">增量序列问题至今没有最优解——它是排序理论里少数「工程经验领先理论」的例子。<strong>「什么样的 $d$ 序列最好」仍是开放问题</strong>，但经验序列（Sedgewick）已在实践中做到接近 $O(n^{4/3})$。</span>

## 3 公式解析：希尔排序的复杂度

$$
T_{\text{希尔}} = \begin{cases} O(n^2) & \text{Shell 原始序列} \\ O(n^{3/2}) & \text{Hibbard 序列} \\ O(n^{4/3}) & \text{Sedgewick 序列} \end{cases}
$$

- **第一步，读「介于 $O(n)$ 与 $O(n^2)$ 之间」**：希尔排序打破了插入排序的 $O(n^2)$ 天花板，却达不到 $O(n\log n)$——它是不完全分治的产物。
- **第二步，读「为什么能突破」**：每趟子序列的插入排序都让序列更有序；「基本有序」是插入排序的甜蜜区——**先花小代价制造有序，再花线性代价完成排序**。
- **第三步，读稳定性**：希尔排序**不稳定**——大步跳跃破坏了相等元素的相对顺序。<span class="marginnote">「不稳定」是希尔排序的代价：<strong>增量跳跃让元素越过相等的元素，相对顺序无法保持</strong>。所有「跳跃式」排序（希尔、快排、选择）几乎都不稳定；而「相邻式」排序（插入、起泡、归并）保持稳定——<strong>稳定性与「移动的局部性」绑定</strong>。</span>

## 4 辨析｜易错点：希尔排序的几个要点

**子序列是「间隔 d」的不是「连续段」**：$d$ 组子序列分别插排，不是把数组切成 $d$ 段。
**$d=1$ 是必经的最后一趟**：前面的趟次只是「预排序」，最终必须做完整插入排序——但此时数据已基本有序，代价小。
**排序「基本有序」后的插入排序接近 $O(n)$**：这正是希尔排序设计的总目标。<span class="marginnote">「最后一趟 $d=1$」常被误以为多余——其实它是收尾的关键。<strong>预排序把「乱序」变「近似有序」，最后的插入排序把「近似」变「精确」</strong>。这个「先粗排再细排」的模式，也出现在快速排序的「先划分递归、规模小时切插入排序」里。</span>

## 5 希尔排序的地位与启示

**历史地位**：1959 年由 Donald Shell 提出，是**第一个突破 $O(n^2)$ 的通用排序算法**——在快速排序普及前，它是最快的排序。
**工程应用**：嵌入式、对稳定性要求不高的场景；`sort` 命令在小数组的某些实现；某些数据库中间结果排序。
**启示**：**「先大步制造有序，再小步收敛」** 是比「一次到位」更普适的优化哲学——网络拥塞控制（慢启动）、数值优化（粗搜→精搜）都是同一思路。

**重点：希尔排序教会我们「用阶段的思路突破复杂度天花板」。** 一个看似简单的「增量 + 插入」，就把 $O(n^2)$ 拉到了 $O(n^{4/3})$。<span class="marginnote">「分阶段排序」的哲学：<strong>不要试图一步到位，先用粗粒度手段快速降低「混乱度」，再精修</strong>。这个思想在后续的快速排序（划分 + 递归）、归并排序（分治 + 合并）、甚至大模型的「先粗对齐再精调」里，都以不同形态反复出现。</span>

## 6 小结

- 希尔排序：按增量 $d$ 分组的插入排序，增量递减到 1。
- 大步移动让序列「基本有序」，最后的插入排序近线性。
- 增量序列决定复杂度：Shell $O(n^2)$、Hibbard $O(n^{3/2})$、Sedgewick $O(n^{4/3})$。
- **不稳定**：跳跃移动破坏等值元素的相对顺序。
- 历史地位：第一个突破 $O(n^2)$ 的通用排序。
- 启示：「先大步制造有序，再小步收敛」的分阶段哲学。
