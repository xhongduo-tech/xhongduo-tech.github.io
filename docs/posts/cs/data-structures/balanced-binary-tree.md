## 为什么 BST 要加「平衡约束」

BST 的形状由插入顺序决定，有序输入会把它拉成长链。**平衡二叉树（AVL 树）**在 BST 的基础上加一条硬约束：**任何结点的左右子树高度之差（平衡因子）不超过 1**。这条约束保证树高恒为 $O(\log n)$，查找永远不退化为线性。代价是插入、删除后可能「失衡」，需要用**旋转（rotation）**把树扳回平衡。AVL 树是「用旋转换高度」的完美示范，也是 `std::map` 之前的经典平衡结构；专题篇的红黑树则是它「放宽约束、减少旋转」的后继。

## 1 AVL 树与平衡因子

**平衡二叉树（AVL 树）**：既是 BST，又满足**任何结点的平衡因子 $BF$ 满足 $|BF| \le 1$**。其中：

$$
BF(\text{结点}) = \text{左子树高度} - \text{右子树高度}
$$

**重点：$|BF| \le 1$ 的约束保证树高 $h \le \log_2(n+1) + \text{常数}$，查找 $O(\log n)$ 有保证。** 只要每次插入/删除后把失衡的结点旋转回来，整棵树就一直「矮而胖」。<span class="marginnote">为什么 $|BF|\le 1$ 就能保证 $O(\log n)$？设最少结点数 $N(h)$ 满足 $N(h) = N(h-1) + N(h-2) + 1$——这是<strong>斐波那契式递推</strong>，解出 $N(h) \approx \varphi^h$，故 $h \approx \log_\varphi n$。<strong>平衡因子的约束，把树高钉在对数量级</strong>。</span>

## 2 插入后的四种失衡：LL、RR、LR、RL

插入一个结点可能让某些祖先失衡（$|BF|=2$）。失衡形态按「插入位置相对失衡点」分四种，每种对应一种旋转：

| 失衡类型 | 插入位置 | 旋转方式 |
| --- | --- | --- |
| LL | 失衡点左孩子的左子树 | 右旋（单旋） |
| RR | 失衡点右孩子的右子树 | 左旋（单旋） |
| LR | 失衡点左孩子的右子树 | 先左旋再右旋（双旋） |
| RL | 失衡点右孩子的左子树 | 先右旋再左旋（双旋） |

**记忆要点：LL 与 RR 对称、LR 与 RL 对称——单旋管「一条直线」，双旋管「一个折线」。**<span class="marginnote">识别旋转类型的口诀：看「失衡点 → 失衡的孩子 → 再往下」三步，方向一致（LL 全左、RR 全右）就单旋，方向相反（LR、RL）就双旋。<strong>单旋解决「同向」，双旋解决「反向」</strong>——这是旋转世界最干净的分界。</span>

## 3 公式解析：右旋（LL 型）

以 LL 型失衡为例。失衡点 $A$ 的左孩子 $B$ 的左子树插入，导致 $A$ 的 $BF=2$。右旋操作：

```
        A                 B
       / \               / \
      B   T3    ==右旋=> T1  A
     / \                   / \
    T1  T2               T2  T3
```

- **第一步，读旋转的三步**：① $B$ 成为新根；② $B$ 的右子树 $T2$ 改挂到 $A$ 的左孩子；③ $A$ 成为 $B$ 的右孩子。
- **第二步，读 BST 性质不变**：$T1 < B < T2 < A < T3$ 的序关系在旋转后依旧成立——$T2$ 移到 $A$ 的左子树，仍然「小于 $A$、大于 $B$」。
- **第三步，读高度**：旋转后 $A$、$B$ 的平衡因子都归 0，子树高度降 1——**失衡被一步修复，且只影响局部**。<span class="marginnote">旋转是「<strong>保持 BST 有序性的局部重排</strong>」：只动 $A$、$B$ 及一棵子树 $T2$ 的父子关系，其余结点纹丝不动。这就是旋转比「重建子树」便宜的原因——<strong>一次旋转 $O(1)$，最多沿路径做 $O(\log n)$ 次</strong>。</span>

## 4 双旋（LR 型）

LR 型：失衡点 $A$ 的左孩子 $B$ 的**右子树**插入，导致 $A$ 失衡。单次右旋无效（会转错），必须先左旋再右旋：

```
    A          A           C
   /          /           / \
  B    ==L=> C      ==R=> B   A
   \        /
    C      B
```

- **第一步，先左旋**：把「折线」压成「直线」——以 $B$ 为轴左旋，让 $C$ 上位；
- **第二步，再右旋**：以 $A$ 为轴右旋，$C$ 成为新根，$B$、$A$ 分列左右。

**辨析｜易错点：LR 不能直接右旋。** 若对 LR 型直接右旋，会得到「右子树上翻」的错误结构，仍不满足 BST 序。**必须「先转直再转平」**——双旋的本质是把「折线」先拉直成「直线」（LL 或 RR），再套单旋。<span class="marginnote">「双旋 = 先拉直再单旋」是个可迁移的套路：<strong>凡是「方向不一致」的失衡，先做一次旋转让它变成「方向一致」，再用单旋修复</strong>。这条规则同样适用于红黑树插入后的调整、以及各种平衡结构的修补。</span>

## 5 公式解析：AVL 树的复杂度与删除

$$
\begin{aligned}
T_{\text{查找}} &= O(\log n) \ \text{（树高被平衡约束钉死）} \\
T_{\text{插入}} &= O(\log n) \ \text{（沿路径找位 + 至多 $O(\log n)$ 次旋转）} \\
T_{\text{删除}} &= O(\log n) \ \text{（删除 + 可能沿路径逐层旋转）}
\end{aligned}
$$

- **第一步，读插入**：先按 BST 插入 $O(\log n)$，再从插入点向上检查平衡因子，遇到 $|BF|=2$ 就旋转——最坏要沿路径修多个失衡点，仍 $O(\log n)$。
- **第二步，读删除**：删除后可能一路失衡到根，每层一次旋转，最坏 $O(\log n)$——**删除比插入更麻烦，因为要连锁修复**。
- **第三步，读「为什么值」**：AVL 保证最坏 $O(\log n)$，而普通 BST 最坏 $O(n)$——**确定性优于随机性**，这是它不可替代的理由。<span class="marginnote">AVL 的插入删除代码比 BST 复杂不少，换来的是「<strong>最坏情况也有保证</strong>」。这个「用实现复杂度换性能下限」的取舍，是数据结构设计的核心命题——<strong>红黑树（专题篇）正是「放宽平衡、简化删除」的 AVL 变体</strong>。</span>

## 6 从 AVL 到平衡树家族

- **AVL 树**：平衡因子严格 $|BF|\le 1$，查找最快，但旋转频繁；
- **红黑树**：用「黑高」约束代替严格平衡，旋转更少，插入删除常数更好（`std::map` 的选择）；
- **B 树**：多路平衡树，把「矮」推向极致，适配磁盘块（§9.6）。

**重点：AVL 是「严格平衡」的极端**——它把树高压得最低、查找最快，但为维护严格平衡付出的旋转成本也最高。**「平衡越严，查找越稳，维护越贵」**，这个三角权衡贯穿整个平衡树家族。<span class="marginnote">在「查找快」与「维护便宜」之间，AVL 偏向前者、红黑树偏向后者。<strong>没有绝对最优，只有适合负载</strong>——查询远多于插入的场景选 AVL，插入删除频繁的场景选红黑树。数据结构选型，永远是「读/写比例」的函数。</span>

## 7 小结

- AVL：BST + 平衡因子 $|BF| \le 1$，树高 $O(\log n)$ 有保证。
- 四种失衡：LL/RR 单旋，LR/RL 双旋；单旋管同向、双旋管反向。
- 旋转保持 BST 有序性、只影响局部，$O(1)$ 每次。
- 查找/插入/删除均 $O(\log n)$；删除的连锁旋转最麻烦。
- 平衡越严、查找越稳、维护越贵——AVL 是「严格平衡」的极端。
- 红黑树、B 树是同一目标下的不同平衡哲学。
