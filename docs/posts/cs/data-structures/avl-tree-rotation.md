## 为什么 AVL 是「平衡树的起点」

§9.5 讲了 AVL 的定义与四种失衡。本节把「旋转」这门外功练到纯熟：**LL、RR、LR、RL 四种失衡各自的旋转手势，以及「插入后如何沿路径回溯修复」的完整流程**。旋转是平衡树家族的「通用语言」——红黑树的调整也建立在旋转之上。学 AVL 的旋转，等于给后面红黑树、B 树的「再平衡」预习了基本动作。本节配一个简单的示意图式推演，把「失衡点 → 旋转 → 平衡因子复原」讲透。

## 1 失衡的定位：从插入点向上找

插入一个结点后，**只有从插入点向上到根的祖先**可能失衡（其他子树不受影响）。所以修复流程是：

1. 从插入结点出发，沿父链**向上回溯**；
2. 找到第一个 $|BF| = 2$ 的结点（失衡点 $A$）；
3. 观察「失衡点 → 插入方向的孩子 → 再往下」三步，判定 LL/RR/LR/RL；
4. 对 $A$ 做对应旋转，修复后**整棵子树平衡因子归位**——**且子树高度恢复原状，祖先无需再调**。

**重点：一次旋转就能修复全部失衡——因为旋转把子树高度恢复到插入前的水平。** 这使 AVL 插入的「再平衡」至多一次旋转。<span class="marginnote">「<strong>一次旋转修好整条链</strong>」是 AVL 插入的关键性质：<strong>旋转后的子树高度与插入前相同，所以所有祖先的平衡因子自动恢复</strong>。这也是 AVL 插入比删除简单的根源——<strong>删除后高度可能变矮，需要沿链多次旋转；插入只需一次</strong>。</span>

## 2 单旋转：LL 与 RR

**LL 型**（在失衡点左孩子的左子树插入）：对失衡点 $A$ 做**右旋**。

```
      A                  B
     / \                / \
    B   T3  右旋        T1  A
   / \                    / \
  T1  T2                T2  T3
```

步骤：① B 上位；② B 的右子树 T2 改挂为 A 的左子树；③ A 变成 B 的右孩子。旋转后 A、B 的平衡因子都归 0。

**RR 型**（在失衡点右孩子的右子树插入）：与 LL 镜像，对 $A$ 做**左旋**。

**重点：单旋转解决「同向」失衡——LL 右旋、RR 左旋，方向与失衡方向相反。** 记忆：**「哪个方向重，就往反方向转」**。<span class="marginnote">「<strong>重哪边、转反向</strong>」是单旋转的记忆锚点：<strong>LL 左边重 → 右旋；RR 右边重 → 左旋</strong>。旋转后，被「压下去」的失衡点平衡因子归 0，新根平衡因子归 0——<strong>一次旋转，整棵子树恢复平衡</strong>。</span>

## 3 双旋转：LR 与 RL

**LR 型**（在失衡点左孩子的右子树插入）：**先左旋（把折线拉直），再右旋（把直线转平）**。

```
    A            A            C
   /            /            / \
  B    --左旋-> C   --右旋-> B   A
   \          /
    C        B
```

**RL 型**（在失衡点右孩子的左子树插入）：先右旋再左旋，与 LR 镜像。

**重点：双旋转 = 「先转直 + 再转平」——本质是把「折线」先变成「直线」（LL/RR），再套单旋转。** 为什么 LR 不能直接右旋？因为直接右旋后，C 会跑到错误的位置，仍不满足 BST 序。<span class="marginnote">「<strong>LR/RL 不能直接单旋</strong>」是初学者最大的坑：<strong>直接右旋 LL 型有效，对 LR 型直接右旋会把「右子树的左孩子」转到错误一侧</strong>。记住：<strong>方向相反（折线）→ 双旋转；方向相同（直线）→ 单旋转</strong>。</span>

## 4 公式解析：旋转的复杂度与平衡因子

设失衡点为 $A$：

$$
T_{\text{旋转}} = O(1) \qquad \text{（只改 3 个指针 + 更新平衡因子）}
$$

- **第一步，读「旋转是 O(1)」**：无论 LL/RR/LR/RL，都只涉及「失衡点、孩子、孙」三个结点的指针重排——常数时间。
- **第二步，读「插入总代价」**：定位插入点 $O(\log n)$ + 至多一次旋转 $O(1)$ = **$O(\log n)$**。
- **第三步，读「平衡因子的更新」**：旋转后要重新计算相关结点的平衡因子——LL/RR 后 A、B 归 0；LR/RL 后需按「C 的哪边高」分三种情形更新。<span class="marginnote">「旋转 $O(1)$ + 插入 $O(\log n)$」让 AVL 的一切操作保持 $O(\log n)$：<strong>查找无旋转、插入至多 1 次、删除至多 $O(\log n)$ 次</strong>。这个「<strong>旋转次数封顶</strong>」的性质，正是 AVL「最坏 $O(\log n)$」的保证来源。</span>

## 5 从 AVL 到红黑树：旋转的复用

AVL 的旋转在红黑树里原样复用，但「触发条件」从「平衡因子 ±2」换成「颜色冲突」：

- **AVL**：旋转修「高度差」——严格平衡，旋转多；
- **红黑树**：旋转修「红黑性质」——宽松平衡，旋转少、插入至多 2 次旋转、删除至多 3 次。

**重点：旋转是平衡树家族的「公共原语」**——AVL 用它保「严格平衡」，红黑树用它保「近似平衡」。学会了 AVL 的旋转手势，红黑树的插入/删除调整就是「换一套触发规则」而已。<span class="marginnote">「<strong>旋转是语言，平衡规则是语法</strong>」：<strong>AVL 用平衡因子驱动旋转，红黑树用颜色驱动旋转，B 树用分裂合并（树的旋转推广）</strong>——<strong>旋转作为「局部重排、保持有序」的基本动作，被所有平衡结构复用</strong>。数据结构学到最后，你会发现「旋转」无处不在。</span>

## 6 小结

- 失衡定位：从插入点沿父链向上找第一个 $|BF|=2$ 的失衡点。
- 单旋转：LL 右旋、RR 左旋——「重哪边转反向」，转后平衡因子归 0。
- 双旋转：LR 先左后右、RL 先右后左——「先转直再转平」。
- 一次旋转修复整条链：旋转后子树高度复原，祖先无需再调。
- 旋转 $O(1)$：插入 $O(\log n)$，删除至多 $O(\log n)$ 次旋转。
- 旋转是平衡树家族的公共原语——红黑树、B 树都建立在它之上。
