## 为什么 DP 要「数据结构加速」

很多 DP 的转移形如 $dp[i] = \max_{j \in [i-k, i-1]}(dp[j]) + \text{cost}$——**内层的「区间 max」每算一次 $O(k)$，总 $O(nk)$**。上一节的单调队列正是「滑动窗口最大值」的 $O(1)$ 递推器——于是**内层 max 变成 $O(1)$，DP 从 $O(nk)$ 降到 $O(n)$**。本节讲清「形如区间最值的 DP 怎么被单调队列优化」——这是「数据结构 × 动态规划」的经典交叉，也是《算法》课程「优化 DP 状态转移」的第一课。

## 1 可优化的 DP 形态

**适用单调队列的 DP 特征**：状态 $i$ 的转移，来自**一个长度固定的滑动区间**里的最值：

$$
dp[i] = \max_{j \in [i-k, i-1]} \{ dp[j] \} + c_i
$$

或更一般的 $dp[i] = \max_{j < i} \{ dp[j] + w(j) \}$ 且「候选 $j$ 随 $i$ 滑动窗口」——**候选集是一个随 $i$ 平移的窗口**。

**重点：识别「转移来源是滑动窗口」是第一步**——看到 $\max_{j \in [i-k, i-1]}$ 这类「窗口内最值」，就想到单调队列。<span class="marginnote">「<strong>DP 优化的第一步是看出转移的『窗口结构』</strong>」：<strong>如果 $dp[i]$ 依赖的 $dp[j]$ 们恰好构成一个随 $i$ 滑动的区间，那这个「区间 max」就能用单调队列 $O(1)$ 递推</strong>。<strong>「结构识别」先于「算法套用」</strong>。</span>

## 2 经典例题：跳跃取最大

**问题**：在数组上走，从 $i$ 可以跳到 $[i+1, i+k]$，求路径上取到的最大值（或最小步数等）。转移：

$$
dp[i] = a[i] + \max_{j \in [i-k, i-1]} dp[j]
$$

朴素：每个 $i$ 扫 $k$ 个前驱，$O(nk)$。优化：维护一个「$dp$ 值的单调递减队列」——队列里是「最近 $k$ 个 $i$ 的候选」，队头是最大 $k$：

```cpp
deque<int> q;                         // 存下标，队列内 dp 值单调递减
for (int i = 1; i <= n; i++) {
    while (!q.empty() && q.front() < i - k) q.pop_front(); // ① 过期淘汰
    dp[i] = a[i] + (q.empty() ? 0 : dp[q.front()]);        // ② 取队头（窗口最大）
    while (!q.empty() && dp[q.back()] <= dp[i]) q.pop_back(); // ③ 实力淘汰入队
    q.push_back(i);
}
```

**重点：三个动作的顺序是「过期淘汰 → 取答案 → 实力淘汰入队」**——先清过期，再取队头（当前最优），再入队并维持单调。<span class="marginnote">「<strong>先清时间、再取答案、后比实力</strong>」是 DP 单调队列的固定节奏：<strong>窗口先滑（淘汰过期），答案现成（队头），新状态入队（维护单调）</strong>。<strong>顺序错一个，取到的可能不是合法窗口内的最大值</strong>。</span>

## 3 公式解析：从 O(nk) 到 O(n)

设 $n$ 个状态、窗口 $k$：

$$
\begin{aligned}
T_{\text{朴素}} &= O(nk) \quad \text{（每状态扫 } k \text{ 个前驱）} \\
T_{\text{单调队列}} &= O(n) \quad \text{（每状态入队/出队一次）}
\end{aligned}
$$

- **第一步，读「朴素慢在哪」**：$n$ 个状态 × 每状态 $O(k)$ 的窗口 max——$O(nk)$。
- **第二步，读「优化换掉了什么」**：窗口 max 从「每状态 $O(k)$」变成「单调队列 $O(1)$ 摊还」——**总 $O(n)$**。
- **第三步，读「均摊」**：每个 $dp$ 值入队一次、出队一次——$O(n)$ 的严格上界。<span class="marginnote">「<strong>一个数据结构，砍掉 DP 的一个维度</strong>」：<strong>把「窗口 max」从 $O(k)$ 摊到 $O(1)$，DP 的复杂度就从 $n \times k$ 变成 $n \times 1$</strong>。<strong>「状态数 × 转移代价」里的「转移代价」被数据结构压平</strong>——这是所有 DP 优化的统一目标。</span>

## 4 单调队列 DP 优化的适用条件

**转移是「区间最值」**：$dp[i]$ 依赖的候选是一个滑动窗口，且取 max/min；
**窗口是「固定或单调移动」的**：左界、右界随 $i$ 单调不减；
**代价可分离**：$c_i$ 只依赖 $i$（或与 $j$ 可分离）。

**辨析｜易错点：不是所有「区间 DP」都能用单调队列。** 若窗口不是「单调滑动」（如任意区间）、或转移含「非线性组合」（如 $dp[j] + dp[i-j]$），单调队列不适用——那是「斜率优化」或「四边形不等式」的领地。<span class="marginnote">「<strong>单调队列管『滑动窗口最值』，不管『任意区间』</strong>」：<strong>窗口必须随 $i$ 单调平移，候选才能「排队淘汰」</strong>。<strong>一旦窗口乱跳，队列的单调性就崩溃</strong>——<strong>「适用条件」先于「套模板」</strong>，别硬套。</span>

## 5 从单调队列到 DP 优化家族

**单调队列优化**：窗口最值类转移——$O(nk) \to O(n)$；
**斜率优化（凸包）**：转移含 $dp[j] + a_j \cdot b_i$ 的「点积」——用凸包维护；是单调队列优化的推广；
**四边形不等式**：区间 DP 的决策单调性——$O(n^3) \to O(n^2)$。

**重点：单调队列优化是「DP 优化家族」的入门**——它的思想（维护候选集、淘汰失去资格的）延伸到斜率优化、决策单调性。学会它，就是学会「用数据结构给 DP 减维」的思维方式。<span class="marginnote">「<strong>DP 优化 = 给转移找结构</strong>」：<strong>窗口最值 → 单调队列，点积结构 → 斜率优化，决策单调 → 四边形不等式</strong>——<strong>每种优化都是「发现了转移里隐藏的结构」</strong>。<strong>单调队列是这家族的第一课，也是最好懂的一课</strong>。</span>

**一个具体的数值算例。** 设 $a = [3, 1, 4, 2, 8, 5, 2, 7]$、$k = 3$，转移 $dp[i] = a[i] + \max_{j \in [i-3, i-1]} dp[j]$，$dp[0] = 0$。

- $i=1$：窗口内 $dp[0]=0$，$dp[1] = 3+0 = 3$，队内 $[dp_0=0, dp_1=3]$；
- $i=2$：窗口 $\{dp_0, dp_1\}$ 最大 3，$dp[2] = 1+3 = 4$，队尾弹出更小的 $dp_0$，队内 $[dp_1=3, dp_2=4]$；
- $i=3$：窗口 $\{dp_1, dp_2\}$ 最大 4，$dp[3] = 4+4 = 8$，队尾弹出 $dp_1$，队内 $[dp_2=4, dp_3=8]$；
- $i=4$：窗口 $\{dp_2, dp_3\}$ 最大 8，$dp[4] = 2+8 = 10$，队内 $[dp_3=8, dp_4=10]$；
- $i=5$：窗口 $\{dp_3, dp_4\}$ 最大 10，$dp[5] = 8+10 = 18$。

每一步的「队头」就是窗口最大值——没有扫一遍 $k$ 个元素，而是 $O(1)$ 从队头取。<span class="marginnote">注意第 $i=5$ 步：$dp_1$ 已滑出窗口（$i-k=2$），若它还在队里，第一步「过期淘汰」就会把它弹出——<strong>「先淘汰过期」保证取到的队头永远在合法窗口内</strong>，这也是三动作顺序不能乱的原因。</span>

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| 滑动窗口 | 随 $i$ 平移的候选区间 |
| 过期淘汰 | 队头下标 $< i-k$ 时弹出 |
| 实力淘汰 | 队尾 dp 值不大于新值时弹出 |
| 摊还 $O(1)$ | 每元素入队、出队各一次 |
| 斜率优化 | 转移含点积时的凸包优化 |

**辨析｜易错点：「窗口长度 $k$ 固定」与「左右界单调」都要满足。** 单调队列优化的前提是窗口「整体平移」——左界右界都随 $i$ 单调不减。若窗口会「乱跳」，队头淘汰就不可靠。识别「窗口结构」时，先确认窗口是「滑动」而非「跳变」。

**一句话**：能用单调队列的 DP，都长着「$\max_{j \in [i-k, i-1]}$」这张脸——看到窗口内取最值，先想到单调队列。

**补充**：从 $O(nk)$ 到 $O(n)$ 的收益在 $k$ 接近 $n$ 时最明显——窗口越大，省得越多；$k$ 很小（如 2）时朴素也不慢，别过度优化。

## 6 小结

- 适用形态：$dp[i] = \max_{j \in [i-k,i-1]} dp[j] + c_i$——转移来源是滑动窗口。
- 三步节奏：队头淘汰过期 → 取队头答案 → 队尾淘汰弱者入队。
- 复杂度：$O(nk) \to O(n)$，每状态入/出队一次。
- 适用条件：窗口单调滑动、代价可分离。
- 不适用：任意区间、非线性组合——那是斜率优化/四边形不等式。
- 单调队列优化是 DP 优化家族的入门，思想延伸到斜率优化。
