## 最大流：一张图能输送多少

**网络流**把「运输/分配/匹配」抽象成带容量边的有向图：**源点（source）**产流、**汇点（sink）**收流，中间是带**容量（capacity）**的管道。**最大流** = 从源到汇能通过的最大流量。直觉答案「最窄的割决定流量」被形式化为**最大流-最小割定理**。**Ford-Fulkerson 方法**是求最大流的经典框架：**反复找一条「增广路」并推流，直到没有**——它靠**残余网络（residual graph）**支持「反悔」，即把已分配的流量「退回来」重新规划。朴素版 $O(E \cdot f)$（$f$ 为最大流量），工程用 BFS 的 Edmonds-Karp 或 Dinic（下节）。

## 1 网络流的基本概念

- **容量 $c(u,v)$**：边 $(u,v)$ 能通过的最大流量；
- **流量 $f(u,v)$**：实际通过的流量，满足 $0 \le f \le c$；
- **守恒**：除源点与汇点外，每个顶点的「流入 = 流出」；
- **最大流**：满足约束下，源点总流出（= 汇点总流入）的最大值。

**重点：网络流的核心约束是「容量上限 + 流量守恒」**——每条边不超过容量、每个中间点不积压不亏空。<span class="marginnote">「<strong>容量是上限，守恒是纪律</strong>」：<strong>边不能超载（容量），点不能积压（守恒）</strong>。<strong>网络流的全部理论，都在这两条约束上建立</strong>——<strong>它把「运输问题」翻译成「带约束的优化」</strong>。</span>

## 2 残余网络与增广路

**残余网络（residual graph）**：对每条边 $(u,v)$ 记录两条「残余」：

- **正向残余**：`c(u,v) - f(u,v)`——还能多流多少；
- **反向残余**：`f(u,v)`——能「退回」多少（反悔边）。

**增广路**：残余网络中从源到汇的一条通路（沿残余 > 0 的边走）。沿它推流 `min(路径上最小残余)`，流量增加——这就是「一次增广」。

**重点：反向残余边是「反悔机制」**——它允许把流量退回，从而修正之前的次优决策。这是 Ford-Fulkerson 正确的关键：**增广路不只在「没用过的管道」上找，也能在「已用过的管道」上反向找。**<span class="marginnote">「<strong>反向边 = 后悔药</strong>」：<strong>给已分配的流量留一条「退路」，让算法能推翻次优分配</strong>。<strong>没有反向边，Ford-Fulkerson 可能卡在局部最优</strong>——<strong>残余网络是「可反悔贪心」的图论形态</strong>。</span>

## 3 Ford-Fulkerson 主流程

```c
int MaxFlow(Graph G, int s, int t) {
    int flow = 0;
    while (存在增广路 P：残余网络中 s 到 t 的路径) {
        int add = min(P 上所有边的残余容量);
        for (每条边 (u,v) in P) {
            f[u][v] += add;        /* 正向推流 */
            f[v][u] -= add;        /* 反向记账（残余+add） */
        }
        flow += add;
    }
    return flow;
}
```

**重点：算法循环「找增广路 → 推流 → 更新残余」，直到无增广路——此时即最大流。** 找增广路用 BFS（Edmonds-Karp，保证 $O(VE^2)$）或 DFS（朴素，$O(E \cdot f)$）。<span class="marginnote">「<strong>没有增广路 = 已达最大流</strong>」是最大流-最小割定理的直接推论：<strong>无增广路 ⇔ 存在一个割（割的容量 = 当前流）⇔ 当前流是最大流</strong>。<strong>「反复增广直到没有」的终止判据，与匈牙利算法的增广路定理如出一辙</strong>。</span>

## 4 公式解析：复杂度与最大流-最小割定理

$$
\begin{aligned}
T_{\text{Ford-Fulkerson (DFS)}} &= O(E \cdot f) \quad \text{（$f$ 为最大流量，可能很大）} \\
T_{\text{Edmonds-Karp (BFS)}} &= O(V E^2)
\end{aligned}
$$

**最大流-最小割定理**：最大流的值 = **最小割**（把图切成「源侧/汇侧」的两组边的最小容量和）的容量。

- **第一步，读「DFS 的隐患」**：DFS 可能找「绕路」增广路，增广次数可多达 $f$——流量大时爆炸。
- **第二步，读「BFS 的保证」**：Edmonds-Karp 每次找「最短增广路」（BFS），增广次数 $O(VE)$，总 $O(VE^2)$——**多项式有界**。
- **第三步，读「割定理」**：最大流 = 最小割，像「最窄瓶颈决定最大流量」——它让「最大流」问题与「最便宜切断」问题互为镜像。<span class="marginnote">「<strong>最大流 = 最小割</strong>」是网络流最深刻的定理：<strong>「能送多少」等于「最少要切断多少」</strong>——<strong>运输能力的上限，由最窄的截面决定</strong>。<strong>这个定理让网络流能解决「最便宜切断」（割）类问题</strong>，应用面翻倍。</span>

## 5 网络流的建模应用

- **二分图最大匹配**：加源连左部、右部连汇、边容量 1——最大流 = 最大匹配；
- **任务分配 / 课程安排**：带容量与偏好的分配；
- **多源多汇**：加超级源、超级汇；
- **最小割应用**：图像分割（前景/背景）、项目选择、密铺问题——「最小割 = 最省钱的分隔」。

**重点：网络流是「资源分配」的万能模型**——只要问题能翻译成「源 → 中间 → 汇」的容量图，最大流/最小割就给出答案。二分图匹配只是它的第一个应用。<span class="marginnote">「<strong>会建模，网络流就什么都能解</strong>」：<strong>匹配、分配、调度、分割——全都能翻译成「带容量的图 + 最大流」</strong>。<strong>「先建模、再套算法」是网络流题的固定流程</strong>——学会建模，比学会算法更重要。</span>

## 6 小结

- 网络流：容量约束 + 流量守恒；最大流 = 源到汇的最大输送量。
- 残余网络：正向残余（还能流）+ 反向残余（反悔边）。
- Ford-Fulkerson：反复找增广路、推流，直到无增广路。
- 复杂度：DFS 版 $O(E\cdot f)$；Edmonds-Karp（BFS）$O(VE^2)$。
- 最大流-最小割定理：最大流 = 最小割——「最窄截面决定流量」。
- 应用：二分图匹配、任务分配、图像分割、最便宜切断。
