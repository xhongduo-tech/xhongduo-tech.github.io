# 数据结构

程序 = 数据结构 + 算法。本模块覆盖从线性结构到高级数据结构的完整路线。

## 主题规划

- [ ] 时间复杂度与空间复杂度分析
- [ ] 数组与链表：原理、对比与应用
- [ ] 栈与队列：单调栈、单调队列
- [ ] 哈希表：哈希函数、冲突处理与扩容
- [ ] 二叉树：遍历、性质与重建
- [ ] 二叉搜索树与平衡树（AVL、红黑树）
- [ ] 堆与优先队列
- [ ] 并查集：路径压缩与按秩合并
- [ ] 图的表示与遍历（BFS/DFS）
- [ ] 最短路径：Dijkstra、Bellman-Ford、Floyd
- [ ] 最小生成树：Prim 与 Kruskal
- [ ] 拓扑排序与关键路径
- [ ] 经典排序算法及其稳定性分析
- [ ] 字符串结构：Trie、KMP 与后缀数组
- [ ] 高级数据结构：跳表、B/B+ 树、线段树与树状数组
