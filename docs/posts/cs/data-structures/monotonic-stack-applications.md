## 两个「看起来像分治」的题，单调栈一行解

**柱状图最大矩形**与**接雨水**是单调栈的两大招牌题——朴素思路都是「对每个位置向两边扩展」，$O(n^2)$。它们的共同结构是：**每个元素的有效范围，由「左右第一个更矮（或更高）的元素」决定**——这正是单调栈的一问。本节把两题的「单调栈解法」完整推演：怎么把「找边界」翻译成「单调栈弹出」，以及为什么「弹出时结算答案」是正确时机。

## 1 柱状图最大矩形

**问题**：$n$ 个柱子高度 $h[1..n]$，找「以某区间为底、最矮柱高为高」的最大矩形面积。

**关键观察**：以第 $i$ 根柱为「最矮柱」的矩形 = $h[i] \times (\text{左右第一个更矮柱之间的宽度})$。

用**单调递增栈**（栈底到栈顶递增）：

- 从左到右扫，遇到比栈顶矮的柱子 → **弹出栈顶并结算**：它的右边界就是当前柱子、左边界就是弹出后新的栈顶；
- 弹出时计算矩形面积，更新最大。

```cpp
// 柱状图最大矩形：单调递增栈
int largestRectangleArea(vector<int>& h) {
    h.push_back(0);                       // 哨兵：强制弹出所有剩余柱子
    stack<int> st;                        // 存下标，栈底到栈顶递增
    int ans = 0;
    for (int i = 0; i < (int)h.size(); ++i) {
        while (!st.empty() && h[st.top()] > h[i]) {
            int t = st.top(); st.pop();   // 弹出并结算
            int left = st.empty() ? -1 : st.top();   // 左边界：弹出后的栈顶
            int width = i - left - 1;     // 右边界：当前柱子 i
            ans = max(ans, h[t] * width);
        }
        st.push(i);
    }
    return ans;
}
```

**重点：单调栈在「弹出时结算」——被弹柱子的矩形，左右边界此刻都已知。** 弹出的柱子 $t$：右边界 = 当前 $i$（第一个比它矮的），左边界 = 弹出后栈顶（左边第一个比它矮的）。<span class="marginnote">「<strong>弹出时，边界才齐全</strong>」是结算时机的关键：<strong>柱子 $t$ 的「左右第一个更矮」在它被弹出那一刻同时确定</strong>——<strong>右边界是当前柱子，左边界是新的栈顶</strong>。<strong>「该结算的时候结算」——单调栈的答案计算总是发生在 pop 时</strong>。</span>

## 2 公式解析：柱状图矩形的复杂度与正确性

$$
T = O(n) \quad \text{（每根柱子入栈/出栈各一次）}
$$

- **第一步，读「每个柱子被结算一次」**：每根柱子恰好被弹出一次、结算一次——它的最大「以它为高」的矩形不会漏。
- **第二步，读「正确性」**：以柱子 $t$ 为最矮柱的矩形，左右边界恰是「第一个更矮柱」，单调栈在弹出时精确给出这两根——宽度正确。
- **第三步，读「哨兵」**：末尾加一根高度 0 的柱子，强制弹出所有剩余——不遗漏任何结算。<span class="marginnote">「<strong>哨兵柱子 = 强制收尾</strong>」：<strong>扫描结束时栈里还有递增的柱子没结算，加一根高度 0 的哨兵把它们全部弹出</strong>。<strong>「哨兵」这个技巧在单调栈/单调队列里反复出现</strong>——省去「结束后再单独处理栈」的代码分支。</span>

## 3 接雨水

**问题**：柱子间能接多少雨水——每列的储水量 = max(0, min(左墙高, 右墙高) − h[i])（非负）。

**单调栈解法**（按「凹槽」结算）：

维护单调递减栈；
遇到比栈顶高的柱子 → 弹出栈顶（这是凹槽的底），**两侧夹出水量**：宽 = 左右边界距离，高 = min(两边界高) - 底高；
累加所有凹槽水量。

```cpp
// 接雨水：单调递减栈，按「凹槽」结算
int trap(vector<int>& h) {
    stack<int> st;                        // 存下标，栈底到栈顶递减
    int ans = 0;
    for (int i = 0; i < (int)h.size(); ++i) {
        while (!st.empty() && h[i] > h[st.top()]) {
            int bottom = st.top(); st.pop();  // 凹槽的底
            if (st.empty()) break;            // 没有左墙，接不住水
            int left = st.top();              // 左墙：新的栈顶
            int width = i - left - 1;
            int height = min(h[left], h[i]) - h[bottom];  // 水高
            ans += width * height;
        }
        st.push(i);
    }
    return ans;
}
```

**重点：接雨水是「按凹槽分层结算」——每个被弹出的「底」，其水量由两侧更高的柱子夹出。** 这是单调栈在「三维 → 两墙一底」上的应用。<span class="marginnote">「<strong>每个凹槽 = 两墙一底</strong>」：<strong>单调递减栈里，被弹出的底，其左墙是栈顶、右墙是当前柱子——两墙夹出一层水</strong>。<strong>「分层结算」把「整体积水」拆成「每层凹槽」</strong>——单调栈天然适合这种「左右夹逼」的几何。</span>

## 4 两题的共同模式

| 维度 | 柱状图最大矩形 | 接雨水 |
| --- | --- | --- |
| 栈的单调性 | 递增 | 递减 |
| 弹出触发 | 遇到更矮 | 遇到更高 |
| 弹出时算什么 | 面积（高 × 宽） | 水量（宽 × 水高） |
| 左右边界 | 第一个更矮 | 第一个更高 |
| 复杂度 | $O(n)$ | $O(n)$ |

**重点：两题是同一枚硬币的两面——一个找「更矮边界」（矩形），一个找「更高边界」（雨水），栈的单调方向相反。** 学懂一个，另一个是「镜像」。<span class="marginnote">「<strong>矩形找矮、雨水找高</strong>」是两题的镜像关系：<strong>矩形要「左右更矮」定宽度，雨水要「左右更高」定水高</strong>——<strong>单调方向相反、骨架完全相同</strong>。<strong>「一个模板的正反两面」——这是最好记的一对题</strong>。</span>

## 5 单调栈的工程直觉

**识别信号**：「找离元素最近的大/小值」「以元素为界的最大区间」→ 单调栈；
**通用模板**：维护单调栈 + 扫描 + 弹出时结算；
**复杂度保证**：每元素入出栈一次，$O(n)$ 摊还。

**重点：单调栈是「在线维护候选 + 及时淘汰」的思维模板**——它不只解这两题，任何「每个元素的答案由『邻近的极值』决定」的问题，都能套。<span class="marginnote">「<strong>单调栈 = 候选淘汰的艺术</strong>」：<strong>栈里永远只留「可能成为答案」的元素，失去资格就立刻弹出</strong>。<strong>这个「淘汰」思路，和单调队列、滑动窗口里的「过期弹出」完全同构</strong>——<strong>「维护一个单调的候选集」是这类 O(n) 算法的统一思想</strong>。</span>

## 6 小结

- 柱状图最大矩形：单调递增栈，弹出时以「左右更矮」结算面积，$O(n)$。
- 接雨水：单调递减栈，弹出时以「两墙夹底」结算水量，$O(n)$。
- 弹出时结算：被弹元素的边界在弹出那一刻齐全。
- 哨兵技巧：末尾补高度 0 柱子，强制收尾结算。
- 两题镜像：矩形找矮、雨水找高，单调方向相反。
- 识别信号：「邻近极值定边界」→ 单调栈；每元素入出栈一次。
