## 树状数组还能干什么

上一节的基础树状数组管「单点改 + 区间查」。本节两个进阶：**区间修改**（给一段同时加一个数）——用**差分**把它化回「单点改 + 区间查」；**逆序对计数**——用树状数组在线统计「前面有多少个比它大」。这两个应用展示了树状数组的真正威力：**它是一个「动态前缀工具」，只要问题能化成「前缀和/单点更新」，就能套上去**。逆序对计数尤其经典——$O(n\log n)$ 时间、十几行代码，是竞赛与面试的常客。

## 1 区间修改：差分化单点

**问题**：给 `a[l..r]` 整体加上 $v$，并支持查询。

**差分思想**：设差分数组 $d[i] = a[i] - a[i-1]$。则：

- **区间修改** `a[l..r] += v` ⇒ **差分上两个单点改**：`d[l] += v`、`d[r+1] -= v`；
- **单点查询** `a[x]` ⇒ **差分前缀和**：$a[x] = \sum_{j=1}^{x} d[j]$。

**公式解析：差分化**

$$
a[l..r] \mathrel{+}= v \quad \Longleftrightarrow \quad d[l] \mathrel{+}= v, \quad d[r+1] \mathrel{-}= v
$$

- **第一步，读「区间改 → 两个单点改」**：差分数组上，区间加变成「左端点 +v、右端点后一个 -v」。
- **第二步，读「单点查 → 前缀和」**：原数组的值 = 差分数组的前缀和。
- **第三步，读「交给树状数组」**：差分数组的单点改 = 树状数组的 `Add`（$O(\log n)$）；差分前缀和 = 树状数组的 `PrefixSum`（$O(\log n)$）。**区间修改 + 单点查询，双双 $O(\log n)$**。<span class="marginnote">「<strong>区间问题化差分，差分交给树状数组</strong>」是经典的两步翻译：<strong>先把「区间改」翻译成「两个单点改」，再把「单点查」翻译成「前缀和」</strong>——两个都落在树状数组的看家本领上。<strong>「翻译问题到已知结构」永远是第一生产力</strong>。</span>

## 2 区间修改 + 区间查询：两个树状数组

若要「区间修改 + 区间查询」都支持，差分 + 前缀和还不够——因为区间查询要 $\sum a[i]$。推导可得：

$$
\sum_{i=1}^{x} a[i] = \sum_{i=1}^{x} \sum_{j=1}^{i} d[j] = (x+1)\sum_{i=1}^{x} d[i] - \sum_{i=1}^{x} i \cdot d[i]
$$

**重点：维护两个树状数组——一个存 $d[i]$、一个存 $i \cdot d[i]$——就能 $O(\log n)$ 完成区间修改与区间查询。**<span class="marginnote">「<strong>区间查 = 两个树状数组的线性组合</strong>」：<strong>$\sum a[i]$ 展开成 $(x+1)\sum d[i] - \sum i\cdot d[i]$</strong>——<strong>两个前缀和，各配一个树状数组维护</strong>。<strong>「不够就多开一个数组」是树状数组扩展的标准姿势</strong>。</span>

## 3 逆序对计数：树状数组的经典应用

**逆序对（inversion）**：$i < j$ 且 $a[i] > a[j]$ 的 $(i,j)$ 对数。

**用树状数组在线计数**：

1. 把数组**离散化**（值域压缩到 $1..m$，$m \le n$）；
2. 从左到右扫：对每个 $a[i]$，查询「已出现且大于 $a[i]$」的个数 = `总数 - PrefixSum(a[i])`；
3. 把 $a[i]$ 加入树状数组（`Add(a[i], 1)`）。

```c
long long CountInversions(int *a, int n) {
    /* 离散化：a 的值域压缩到 1..m */
    long long inv = 0;
    for (i = 0; i < n; i++) {
        inv += i - PrefixSum(a[i]);     /* 前面比 a[i] 大的个数 */
        Add(a[i], 1);                   /* a[i] 出现次数 +1 */
    }
    return inv;
}
```

**公式解析：逆序对的复杂度**

$$
T = O(n \log n) \quad \text{（每元素一次查询 + 一次更新，均 } O(\log n) \text{）}
$$

- **第一步，读「在线统计」**：边扫边统计，`PrefixSum(a[i])` = 前面「≤ a[i]」的个数，`i - 它` = 前面「> a[i]」的个数——即与 $a[i]$ 构成的逆序对。
- **第二步，读「为什么离散化」**：值域可能 $10^9$，树状数组下标要 $1..n$——离散化把值映射到 $1..m$。
- **第三步，读「$O(n\log n)$」**：$n$ 个元素、每步 $O(\log n)$——比朴素 $O(n^2)$ 快一个量级。<span class="marginnote">「<strong>逆序对 = 顺序遍历 + 动态计数</strong>」：<strong>树状数组在这里当「出现次数的动态桶」——按值域维护「这个值出现过几个」</strong>。<strong>「值域树状数组」= 桶 + 前缀和，是树状数组最常用的变身</strong>——它把「统计比某值大/小的个数」变成 $O(\log n)$ 查询。</span>

## 4 逆序对的应用与变体

- **归并排序也能数逆序对**：分治合并时统计跨组逆序——与树状数组 $O(n\log n)$ 同阶；
- **冒泡排序的交换次数** = 逆序对数；
- **变体**：统计「三元逆序」（$i<j<k$ 且 $a[i]>a[j]>a[k]$）——用两个树状数组，先正扫一遍统计「左边比它大的」，再倒扫一遍统计「右边比它小的」，相乘累加。

**重点：逆序对问题的「树状数组版」是「值域 + 前缀和」套路的模板**——凡是「统计序列中满足大小关系的位置对数」，都可以用「值域树状数组在线扫」。<span class="marginnote">「<strong>值域树状数组 = 动态桶 + 前缀和</strong>」的应用面极广：<strong>逆序对、小于当前数、排名、前 K 小（配合二分）</strong>——<strong>凡是「按值域做前缀统计」，树状数组都是首选</strong>。它是「桶排序思想」的动态化。</span>

## 5 树状数组 vs 线段树的取舍

| 维度 | 树状数组 | 线段树 |
| --- | --- | --- |
| 支持操作 | 单点/差分区间 + 前缀统计 | 任意区间操作（sum/max/min/…） |
| 代码量 | 十几行 | 五十行+ |
| 常数 | 极小 | 较大（递归） |
| 区间最值 | **不支持** | 支持 |
| 通用性 | 局限 | 全面 |

**重点：树状数组「快而专」，线段树「慢而全」**——能树状数组解决的问题，它永远比线段树快、短、稳；线段树专治树状数组搞不定的（区间最值、区间任意合并）。<span class="marginnote">「<strong>先想树状数组，不行再线段树</strong>」：<strong>单点改 + 前缀统计、差分区间 → 树状数组；区间最值、任意区间合并 → 线段树</strong>。<strong>选型的第一问是「操作能不能化成前缀和/单点更新」</strong>——能，就用最锋利的工具。</span>

## 6 小结

- 区间修改化差分：`d[l]+=v`、`d[r+1]-=v` → 两个单点改。
- 区间修改 + 区间查询：两个树状数组（$d[i]$ 与 $i\cdot d[i]$）。
- 逆序对：值域树状数组在线扫，$O(n\log n)$。
- 离散化：把大值域压缩到 $1..m$，适配树状数组下标。
- 值域树状数组 = 动态桶 + 前缀和，统计「比某值大/小」的万能工具。
- 树状数组快而专、线段树慢而全——先想树状数组。
