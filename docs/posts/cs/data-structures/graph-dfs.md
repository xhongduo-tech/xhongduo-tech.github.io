## 为什么图的遍历要新讲

树的遍历天然从根开始、无环可绕。图没有「根」，还可能有环——从某顶点出发，可能回到已经访问过的顶点。于是图的遍历多了两件事：**从任意顶点出发**，以及**记录哪些顶点已访问**（否则会死循环）。**深度优先搜索（DFS, Depth-First Search）**是树的先序遍历在任意图上的推广：一条路走到黑，走不动就回溯换路。它不仅是遍历，更是连通分量、拓扑排序、强连通分量、割点等一大族图算法的基础。

## 1 DFS 的思想

从顶点 $v$ 出发的 DFS：访问 $v$ 并标记，然后**依次对 $v$ 的每个未访问的邻接点递归 DFS**。若一次 DFS 后仍有未访问顶点，则从其中任选一个重新开始——「外层循环」保证覆盖全图。

```cpp
// 从顶点 v 出发的 DFS：一条路走到黑，走不动就回溯
void dfs(int v) {
    visited[v] = true;                    // 访问并标记
    printf("%d ", v);
    for (int w : adj[v])                  // 依次处理 v 的每个邻接点
        if (!visited[w])
            dfs(w);                       // 未访问则递归深入
}

// 外层循环：保证覆盖全图（处理不连通的情况）
for (int v = 0; v < n; ++v)
    if (!visited[v])
        dfs(v);
```

**重点：visited 数组是 DFS 的「记忆」——没有它，图遍历就变成死循环。** 树不用标记是因为树无环；图有环，必须靠标记防止重复进入。<span class="marginnote">DFS 的递归调用与《栈与递归（汉诺塔）》一脉相承：每次递归压一层栈，栈深就是当前搜索深度。图很大时，<strong>显式栈 + 循环</strong>可以替代递归，避免系统栈溢出——与二叉树非递归遍历同理。</span>

## 2 DFS 的非递归写法

DFS 的本质是「后进先出」地扩展，所以显式栈版本很自然：

```cpp
// 非递归 DFS：显式栈
void dfsIter(int start) {
    stack<int> st;
    st.push(start);
    visited[start] = true;                // 入栈即标记，防止重复入栈
    while (!st.empty()) {
        int v = st.top();                 // 看栈顶，不急着弹
        bool hasUnvisited = false;
        for (int w : adj[v]) {            // 找下一个未访问的邻接点
            if (!visited[w]) {
                visited[w] = true;
                st.push(w);               // 有路 → 深入
                hasUnvisited = true;
                break;
            }
        }
        if (!hasUnvisited) st.pop();      // 无路 → 弹出（回溯）
    }
}
```

**重点：栈顶「有路则深入、无路则弹出」——这就是 DFS 的全部。** 弹出的时机是「该顶点的所有邻接点都已访问」，即真正走到底才回头。<span class="marginnote">注意递归版与显式栈版的微妙差异：递归版对每个邻接点立即深入；显式栈版先压入再逐个处理。<strong>两者访问顺序可能不同，但「访问集合」与「路径结构」一致</strong>——DFS 的本质是「栈」，不是「某一种特定输出顺序」。</span>

## 3 公式解析：DFS 的复杂度

设图有 $n$ 个顶点、$e$ 条边。DFS 的总复杂度：

$$
T_{\text{DFS}} = \begin{cases} O(n + e) & \text{邻接表} \\ O(n^2) & \text{邻接矩阵} \end{cases}
$$

- **第一步，读邻接表版**：每个顶点被访问一次（$n$），每条边被检查一次（$e$，因为邻接表遍历邻居的总和是 $2e$ 或 $e$）——故 $O(n+e)$。
- **第二步，读矩阵版**：每个顶点访问时，要扫描整行（$n$ 个位置）找邻居——$n$ 个顶点共 $O(n^2)$，与边数无关。
- **第三步，读「与边数无关」的陷阱**：矩阵版即使图很稀疏（$e=O(n)$），DFS 也固定 $O(n^2)$。<strong>稀疏大图用邻接表，DFS 才是线性的</strong>——这再次印证「先定存储，再谈复杂度」。<span class="marginnote">DFS 的 $O(n+e)$ 是图算法复杂度的「黄金标准」——拓扑排序、连通分量、双连通分量都能做到线性。凡是比 $O(n+e)$ 差的图算法，一定多付了「找邻居」或「重复扫描」的代价。</span>

## 4 DFS 生成树与生成森林

DFS 从某顶点出发访问到的所有边中，**「首次发现新顶点」的那些边**构成一棵以出发顶点为根的**深度优先生成树**；若图不连通，各连通分量的 DFS 生成树合成**深度优先生成森林**。

**辨析｜易错点：DFS 树上的「回边」才是环的证物。** 无向图的 DFS 树上，若某条边连接的两个顶点「一个在树上、一个已访问但不是双亲」，则这条边是**回边（back edge）**——它正好圈出一个环。**无向图无环 ⇔ DFS 无回边。** 这一观察是「检测图中是否有环」的最快方法（$O(n+e)$）。<span class="marginnote">「DFS 树 + 回边」的框架是图论算法的地基：<strong>有向图的强连通分量（Tarjan）、无向图的割点与桥、拓扑排序的环检测</strong>，全都围绕「树边、回边、前向边、横叉边」这四类边展开。专题篇的 Tarjan 算法就是在这棵 DFS 树上做文章。</span>

## 5 DFS 的应用全景

DFS 是图算法中使用最广的「引擎」：

**连通分量**：visited 标记下外层循环启动 DFS 的次数 = 连通分量个数；
**环检测**：DFS 中遇到「已访问且非双亲」的邻接点即有环；
**拓扑排序**：DFS 完成的逆序就是拓扑序（对有向无环图）；
**强连通分量 / 割点 / 桥**：Tarjan 算法（专题篇）；
**二分图判定**：DFS 染色，相邻不同色。

**重点：学会 DFS，就解锁了图算法的半壁江山。** 后续的拓扑排序、关键路径、强连通分量，全是 DFS 的「加料」版本。<span class="marginnote">DFS 的另一重身份是「<strong>隐式图的搜索</strong>」——八皇后、迷宫、状态空间搜索都显式或隐式地组织成图，DFS（及其兄弟 BFS）是走迷宫、解谜题、状态搜索的统一引擎。回溯法（六篇）正是 DFS 在约束满足问题上的特化。</span>

**一个 DFS 的算例。** 图顶点 $\{1,2,3,4,5\}$，邻接 $1$—$\{2,3\}$、$2$—$\{4\}$、$3$—$\{5\}$。从 1 出发：访问 1 → 深入 2 → 深入 4（无未访问邻居，回溯）→ 回到 2（无其他邻居，回溯）→ 回到 1 → 深入 3 → 深入 5 → 回溯到 1，结束。访问序 $1,2,4,3,5$；DFS 生成树的边为 $1\!-\!2, 2\!-\!4, 1\!-\!3, 3\!-\!5$。

若图再加一条边 $4\!-\!5$，DFS 遍历到 5 时会发现 4「已访问且非双亲」——**回边 $4\!-\!5$ 圈出一个环**，环检测由此成立。<span class="marginnote">「$4\!-\!5$ 连接两个已访问结点 = 有环」是最直接的环检测直觉：<strong>无向图中一条边连接「已访问的两个结点」，这条边必圈出环</strong>。<strong>DFS 只需 $O(n+e)$ 就能回答「图有没有环」</strong>——比任何其他方法都快。</span>

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| visited 数组 | 图的「记忆」，防环防重复 |
| DFS 树 / 森林 | 首访新顶点的边构成 |
| 回边 | 连到已访问非双亲的边 = 环的证物 |
| 递归栈 / 显式栈 | 递归实现与栈实现等价 |
| 邻接表 $O(n+e)$ | 稀疏图 DFS 的线性复杂度 |

## 6 小结

- DFS = 树的先序遍历推广到任意图；visited 数组防环、防重复访问。
- 递归版 + 显式栈版等价；栈顶「有路深入、无路弹出」。
- 复杂度：邻接表 $O(n+e)$，邻接矩阵 $O(n^2)$。
- DFS 生成树/森林：「首访新顶点」的边构成；无环 ⇔ 无回边。
- 应用：连通分量、环检测、拓扑排序、SCC、割点桥、二分图判定。
