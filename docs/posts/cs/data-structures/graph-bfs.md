## 为什么还需要 BFS

DFS 一路走到底，适合「找一条路」「判断可达」；但许多问题需要**按距离逐层推进**——无权图的最短路径、社交网络的「几度人脉」、网络广播的传播层数。这些恰好是 DFS 的盲区：DFS 找到的路径不保证最短，因为它一路狂奔到底。**广度优先搜索（BFS, Breadth-First Search）**用**队列**逐层扩展：从起点出发，先访问所有「距离 1」的顶点，再访问所有「距离 2」的顶点……于是**BFS 首次到达某顶点的路径，就是最短路径**。BFS 与层序遍历同源，是「队列」这座结构的头号大客户。

## 1 BFS 的思想

从顶点 $v$ 出发的 BFS：访问 $v$ 并入队；循环出队一个顶点，访问它所有未访问的邻接点并入队——直到队列空。

```c
void BFS(Graph G, int v) {
    int w;
    Queue Q;                 /* 队列 */
    InitQueue(Q);
    visited[v] = TRUE;       /* 访问起点并标记 */
    EnQueue(Q, v);
    while (!QueueEmpty(Q)) {
        DeQueue(Q, v);                       /* 出队一个顶点 */
        for (w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w))
            if (!visited[w]) {               /* 未访问的邻接点 */
                visited[w] = TRUE;
                EnQueue(Q, w);               /* 入队 */
            }
    }
}
```

**重点：BFS 与树的层序遍历是同一段代码**——只是把「左右孩子」换成「所有邻接点」，加一个 `visited` 标记。队列 FIFO 保证「先发现的顶点先扩展」，这正是「按距离分层」的机制来源。<span class="marginnote">对照记忆：<strong>DFS 用栈（递归）、BFS 用队列</strong>——一个后进先出、一个先进先出。栈/队列的选择直接决定搜索顺序：栈走到底再回头，队列逐层推进。数据结构的选择，就是搜索策略的选择。</span>

## 2 BFS 的生成树与最短路径

BFS 首次发现每个顶点的「父边」构成一棵**广度优先生成树**。它的核心性质：

**在无权图上，BFS 树从根到任意顶点的路径长度 = 该顶点到根的最短距离。**

因为 BFS 严格按「距离层」扩展——第 $k$ 层全部访问完，才进入第 $k+1$ 层；首次入队的顶点，其路径一定是最短的。<span class="marginnote">「首次到达即最短」是 BFS 的招牌。它的正确性依赖「<strong>层序单调</strong>」：先入队的一定不比后入队的更远。若边有权（长度不都是 1），这个性质立刻失效——那就要等 Dijkstra（§7.6）登场。<strong>BFS = 无权最短路，Dijkstra = 带权最短路</strong>。</span>

## 3 公式解析：BFS 求无权最短路

设起点为 $s$，$d[v]$ 记录 $s$ 到 $v$ 的距离。BFS 的层序性质给出：

$$
d[v] = \begin{cases} 0 & v = s \\ d[\text{父}(v)] + 1 & v \neq s \ (\text{由 BFS 树决定}) \end{cases}
$$

- **第一步，读「父」**：BFS 首次发现 $v$ 的那个顶点叫父顶点（parent），它比 $v$ 先入队、距离小 1。
- **第二步，读递推**：每访问一个新顶点，距离 = 父距离 + 1——因为父到子恰一条边。
- **第三步，读「最短性」**：层序单调保证「首个父」的距离就是最小距离；若还有更短的路径，那路径上的中间顶点会更早被发现，矛盾。<span class="marginnote">「最短性」的证明是一个典型的「<strong>反证 + 层序单调</strong>」论证，也是 BFS 正确性证明的骨架。到第二级《算法》学最短路时，你会看到 Dijkstra 的证明用了同样的「贪心 + 不变量」结构。</span>

## 4 辨析｜易错点：BFS 与 DFS 的访问顺序

两者常被混淆，关键差异：

**顺序**：DFS 先深入再回头（一条分支到底）；BFS 先铺开再深入（一层访问完再下一层）。
**空间**：DFS 栈深 $O(\text{图深度})$；BFS 队列长 $O(\text{最大层宽度})$——**最坏都是 $O(n)$**，但分布不同：窄高图 DFS 省、宽矮图 BFS 省。
**最短路径**：无权图上 BFS 首次到达即最短；DFS 不保证。
**应用**：DFS 适合「可达性、环、拓扑、连通」；BFS 适合「最短步数、分层、广播」。<span class="marginnote">空间上有个反直觉的点：<strong>稠密图里 BFS 队列可能接近 $O(n)$，而 DFS 递归栈也 $O(n)$，两者同阶</strong>。真正差异在「哪个更贴合你的搜索目标」——不是空间谁省，而是语义谁对。</span>

## 5 BFS 的应用

**无权最短路**：迷宫最短步数、网络跳数（六度分隔）；
**分层遍历**：按层输出树/图、社交网络的「距离圈」；
**连通分量**：BFS 同样可数连通分量；
**二分图判定**：BFS 染色（同一层同色、相邻异色），出现同色冲突即非二分图；
**搜索引擎的爬虫策略**：按链接层级抓取。

**重点：BFS 与 DFS 只是「用哪种容器控制扩展顺序」，其余框架几乎相同。** 学会一个，另一个是镜像修改。<span class="marginnote">在大模型与知识图谱语境里，BFS 式的「多跳推理」很常见：从一个实体出发，沿关系逐层扩展邻居。区别只是图更大、边有语义——<strong>但「按层扩展、先近后远」的核心不变</strong>。</span>

## 6 小结

- BFS 用队列逐层扩展，访问顺序按「距离层」推进。
- 首次到达即最短：无权图上 BFS 树路径 = 最短路径。
- 复杂度：邻接表 $O(n+e)$，邻接矩阵 $O(n^2)$（同 DFS）。
- DFS 栈、BFS 队列——容器决定搜索策略。
- 应用：无权最短路、分层遍历、连通分量、二分图判定。
- 与 DFS 同框架，仅「扩展顺序」不同。
