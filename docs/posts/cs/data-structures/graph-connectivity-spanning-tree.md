## 为什么连通性值得单列一节

一个图是不是「连成一片」，是许多现实问题的先决条件：网络是否断点？电路是否连通？一个社交图谱里是否有孤岛？**连通性**直接由 DFS/BFS 判定——启动遍历的次数就是连通分量个数。而**生成树**把「连通」翻译成「最省的连通骨架」：$n$ 个顶点用 $n-1$ 条边连起来且无环。当边有权，还要找总权最小的骨架——**最小生成树（MST）**，这正是下一节 Prim、Kruskal 的目标。本节先立起「连通分量 + 生成树」两个概念，为 MST 铺路。

## 1 用遍历求连通分量

**连通分量**：无向图的极大连通子图。判定方法出奇简单——**DFS 或 BFS 从某顶点出发，能到达的全部顶点恰是一个连通分量**：

```c
// 连通分量：启动 DFS/BFS 的次数 = 分量个数
int countComponents(Graph G) {
    int count = 0;
    for (int v = 0; v < G.n; v++) visited[v] = false;
    for (int v = 0; v < G.n; v++)
        if (!visited[v]) {          // 从未访问顶点启动一次遍历
            DFS(G, v);              // 恰好覆盖一个连通分量
            count++;
        }
    return count;
}
```

**重点：主程序中外层循环启动 DFS 的次数，恰好等于连通分量个数。** 因为每次从一个未访问顶点启动，恰能覆盖一个极大连通子图。<span class="marginnote">这个「<strong>启动次数 = 分量数</strong>」的结论是图遍历的隐藏福利——不额外建任何结构，就得到连通分量的数量与划分。它也是「并查集（专题篇）求连通分量」的对照：<strong>遍历法在线、并查集法支持动态加边</strong>，各擅胜场。</span>

## 2 生成树与生成森林

**生成树（spanning tree）**：连通图的**极小连通子图**——包含全部 $n$ 个顶点，恰有 $n-1$ 条边，且连通无环。

由定义立即可得三条性质（都与「无环连通图」等价）：

生成树含 $n$ 个顶点、$n-1$ 条边；
删除任意一条边，生成树不再连通；
任意加一条边，生成树必然出现环（且只多出一个环）。

**重点：$n$ 个顶点的连通图，至少 $n-1$ 条边；恰好 $n-1$ 条边时它就是一棵生成树。** 这条「下界」是图论里最常用的手算结论。<span class="marginnote">「$n-1$ 条边无环必连通」是树的等价刻画之一：任何无环图，若边数 $= n-1$，则必连通。<strong>树 = 无环 + 连通 + 边数 $n-1$，三条任取其二即可推出第三</strong>——这个三选二法则在证明时能救命。</span>

## 3 DFS 生成树、BFS 生成树与最小生成树

遍历图时，「首次发现新顶点的边」组成一棵生成树：

**DFS 生成树**：沿 DFS 的「树边」构成；
**BFS 生成树**：沿 BFS 的「首次到达边」构成；
不同遍历起点、不同邻居顺序，会得到**不同的生成树**。

当边带权，我们关心的不只是「任意一棵生成树」，而是**总权值最小的生成树——最小生成树（MST）**。MST 不唯一，但最小总权值唯一。

**辨析｜易错点：MST 不是「最短路径之和」。** 最小生成树考虑的是「连通所有顶点的总边权最小」，而最短路径考虑「两点之间路径权最小」——**两者目标不同，选边逻辑完全不同**。最小生成树的边是「桥接不同簇的最便宜边」，不是「某个点连到源点的最短路」。<span class="marginnote">MST 的直觉：把 $n$ 个城市连成一张网，让「总铺设成本」最小，而不是让「任意两城之间路径最短」。这正对应「<strong>网络铺设（省总成本）</strong>与「<strong>路径导航（省单程时间）</strong>」两种工程目标的差别。</span>

## 4 公式解析：生成树的边数与割边

设连通图有 $n$ 个顶点，任意生成树的边数为：

$$
m_{\text{生成树}} = n - 1
$$

- **第一步，读「为什么是 $n-1$」**：树是无环连通图。无环 ⇒ 边数 ≤ $n-1$（每加一条边至多连通一个新顶点）；连通 ⇒ 边数 ≥ $n-1$（至少要 $n-1$ 条边把所有顶点串起来）。夹逼得恰为 $n-1$。
- **第二步，读「删除边的后果」**：生成树删一条边必断开（分成两个连通分量）；原连通图删一条「**割边/桥**」也断开——但普通边不一定。找「哪些边是桥」需要专门算法（专题篇 Tarjan）。
- **第三步，读「加边的后果」**：生成树加任意一条原图边，恰好产生一个环——**生成树 + 一条回边 = 一个基本环**。这个「基本环」概念是后续很多图论推导（如生成树的计数、差分约束）的零件。<span class="marginnote">「$n-1$ 条边」也是<strong>最小生成树算法的终止判据</strong>：Prim/Kruskal 都选到 $n-1$ 条边即停。<strong>为什么不是别的数？因为 $n-1$ 是无环连通所需边数的下界与上界重合点</strong>——记住这个数，就记住了 MST 的终点。</span>

## 5 从连通性到最小生成树

连通分量为「判连通」，生成树为「最省连通」，MST 为「最省 + 有权」。两个经典算法：

**Prim**：从一个顶点出发，每次选「已连集合到未连集合的最短边」加入——适合稠密图，$O(n^2)$ 朴素版 / 堆优化 $O((n+e)\log n)$；
**Kruskal**：把所有边按权排序，从小到大选「不产生环」的边——适合稀疏图，$O(e\log e)$，配并查集判环。

两者都基于同一条**切割性质**：对任一顶点集合划分，连接两半的「最轻边」必在某棵 MST 中。这一性质是 MST 贪心正确的根基。<span class="marginnote">「切割性质」是 MST 的元定理：<strong>任何一条「跨过某个割」的最小边，都在某棵最小生成树里</strong>。Prim 每次沿「已连/未连」的割取最轻边，Kruskal 沿「森林各树间」的割取最轻边——<strong>两个算法是同一性质的两个视角</strong>。下两节分别展开。</span>

**一个具体的算例：手数连通分量。** 设无向图有 6 个顶点、边集 $\{1\!-\!2, 2\!-\!3, 4\!-\!5\}$。从顶点 1 启动 DFS，覆盖 $1,2,3$——第一个分量；顶点 4 启动 DFS，覆盖 $4,5$——第二个分量；顶点 6 未访问，单独启动，覆盖 $6$——第三个分量。共 3 个连通分量——**孤立点本身就是一个连通分量**，这是手算时最易漏掉的。

生成树方面，设连通图 $n=5$、$m=6$ 条边：任取一棵生成树恰有 $4$ 条边；任意生成树加一条原图边必出一个环——这环就是「基本环」，「独立环数」$= m - (n-1) = 6 - 4 = 2$。<span class="marginnote">「独立环数 = $m - n + 1$」是个有用的手算公式：<strong>连通图的边数比生成树多几条，就多几个「独立环」</strong>。它也是电路分析里「基本回路数」、网络流里「回边数」的先声。</span>

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| 连通分量 | 极大连通子图 |
| 生成树 | $n$ 顶点、$n-1$ 条边的连通无环子图 |
| 生成森林 | 非连通图的各分量生成树之并 |
| 割边 / 桥 | 删除后图断开的边 |
| MST | 总权最小的生成树 |
| 独立环数 | $m - n + 1$ |

**辨析｜易错点：DFS/BFS 求连通分量，与「并查集求连通分量」是两种路线。** 遍历法一次扫完静态图，$O(n+e)$；并查集支持「边不断到来」的动态加边（专题篇）。静态图用遍历、动态图用并查集——别在「图会不会变」上选错。

**一句话**：连通性三个层次——分量（遍历次数）、生成树（树边数）、独立环（$m-n+1$）——一次 DFS 全部得到。

**延伸对照**：生成树的「$n-1$ 条边」与《B 树》的「叶子同层」一样，都是「结构性质直接给出算法边界」的例子——记住 $n-1$，就记住了 MST 的终点与环路计数的起点。

**核心对比表：三层度量**

| 层次 | 度量 | 求解 |
| --- | --- | --- |
| 连通分量 | 极大连通子图数 | DFS/BFS 启动次数 |
| 生成树 | $n-1$ 条树边 | 首次访问的边 |
| 独立环 | $m - n + 1$ | 非树边数 |

## 6 小结

- 连通分量 = 极大连通子图；DFS/BFS 启动次数即分量数。
- 生成树：$n$ 顶点、$n-1$ 条边、连通无环——树的等价刻画「三选二」。
- DFS/BFS 生成树随遍历策略不同而不同。
- MST = 总权最小的生成树；目标与最短路不同，别混淆。
- 切割性质是 MST 贪心的根基；Prim/Kruskal 是它的两个视角。
- 「$n-1$」既是生成树边数，也是 MST 算法的终止判据。
