## 为什么快速排序「快」

**快速排序（quick sort）**是应用最广的排序算法：平均 $O(n\log n)$、常数小、原地排序。它的核心是**划分（partition）**——选一个**枢轴（pivot）**，一趟把序列分成「比枢轴小」与「比枢轴大」两半，枢轴落到最终位置；然后对两半递归。快排是「分治」的教科书：**划分是分解，递归是求解，无需合并**（枢轴已就位）。但快排有个著名弱点：**最坏 $O(n^2)$**——当枢轴总是极端值（如已有序输入配固定枢轴）。工程实现靠「随机选枢轴」或「三数取中」驯服最坏。

## 1 划分（partition）的思想

以「第一个元素作枢轴」为例的划分过程（严蔚敏教材的经典写法）：

1. 取枢轴 `pivot`（第一个元素）存入临时变量，low 位置空出；
2. 从右往左找「比枢轴小的」，放到左边空位；
3. 从左往右找「比枢轴大的」，放到右边空位；
4. 交替进行，直到左右指针相遇——相遇处即枢轴的最终位置。

```c
// 一趟划分：以第一个元素为枢轴，返回枢轴最终位置（严蔚敏教材写法）
int Partition(int A[], int low, int high) {
    int pivot = A[low];                  // 取枢轴（第一个元素），low 空出
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;  // 从右找比枢轴小的
        A[low] = A[high];                // 放到左边空位
        while (low < high && A[low] <= pivot) low++;    // 从左找比枢轴大的
        A[high] = A[low];                // 放到右边空位
    }
    A[low] = pivot;                      // 枢轴归位
    return low;
}
```

**重点：划分一趟让「枢轴左边全小、右边全大」——枢轴从此再不动，两半互不干扰。** 这种「枢轴定位」让快排不需要合并步骤，递归分解到底即排序完成。<span class="marginnote">「枢轴最终归位」是快排与归并的本质区别：<strong>归并先分后合（合并要额外空间），快排先分就「分完了」</strong>。快排的「分」是「按值划分」（枢轴居中），归并的「分」是「按位置对半」——<strong>一个重划分、一个重合并</strong>。</span>

## 2 快速排序的递归框架

```c
// 快速排序：划分（枢轴归位）+ 递归两半，无需合并
void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int p = Partition(A, low, high);   // 划分：枢轴落到最终位置
        QuickSort(A, low, p - 1);          // 递归排序左半
        QuickSort(A, p + 1, high);         // 递归排序右半
    }
}
```

**重点：快排的递归深度 = 划分的层数，理想 $O(\log n)$、最坏 $O(n)$。** 递归深度直接对应系统栈占用——这是快排「退化」时栈溢出的根源。<span class="marginnote">递归深度与枢轴质量直接挂钩：<strong>枢轴每次把序列对半劈 → 深度 $\log_2 n$；枢轴每次偏到一端 → 深度 $n$</strong>。工程上「随机选枢轴」让偏到一端的概率指数级降低——<strong>随机化把「最坏输入」的概率摊没</strong>。</span>

## 3 公式解析：快速排序的复杂度

$$
\begin{aligned}
T_{\text{平均}} &= O(n\log n) \qquad \text{（每次划分把问题约减半，深度 }\log n\text{）} \\
T_{\text{最坏}} &= O(n^2) \qquad \text{（枢轴每次都偏到一端：已有序输入 + 固定枢轴）} \\
T_{\text{最好}} &= O(n\log n) \qquad \text{（每次完美对半）}
\end{aligned}
$$

- **第一步，读平均 $O(n\log n)$**：每层划分总代价 $O(n)$（每个元素被比较常数次），层数期望 $O(\log n)$——乘起来 $O(n\log n)$。
- **第二步，读最坏 $O(n^2)$**：有序输入配「第一个元素作枢轴」，每趟划分只分出「1 个 + n-1 个」，退化成 $O(n)$ 层、每层 $O(n)$——总 $O(n^2)$。
- **第三步，读「为什么平均仍快」**：即使划分不是完美对半（如 1:9），层数也是 $\log n$ 级别——**快排对「不完美的划分」非常宽容**，这是它平均性能强的深层原因。<span class="marginnote">「1:9 划分也能 $O(n\log n)$」是个反直觉的结论：<strong>只要划分是「常数比例的偏」，递归深度就是 $O(\log n)$</strong>。这解释了为什么快排对随机输入表现稳定——<strong>几乎任何随机枢轴都足够好</strong>。</span>

## 4 稳定性与空间

**稳定性**：**不稳定**。划分时的大范围跳跃交换会打乱相等元素的相对顺序。
**空间**：$O(\log n)$ 期望（递归栈），最坏 $O(n)$。原地划分不占额外数组。

**辨析｜易错点：快排「不是不稳定就不行」。** 稳定性只在「需要保持等值元素原顺序」时重要。快排的不稳定性是「跳跃交换」的必然代价，但它换来了**原地 + 小常数 + 平均极快**。多数场景（数值排序、去重前排序）不需要稳定——这就是快排能当「排序之王」的原因。<span class="marginnote">「稳定 vs 快」的权衡：<strong>需要稳定选归并（$O(n)$ 空间），追求速度选快排（不稳）</strong>。C 的 `qsort`、Java 的 `Arrays.sort`（基本类型）都用快排——它们宁愿放弃稳定，也要速度与原地。</span>

## 5 工程优化：驯服最坏

现代快排实现的四个标准优化：

1. **随机选枢轴**（或三数取中）：避免有序输入的退化；
2. **递归到小规模切插入排序**：$n$ 小时插入排序常数更小；
3. **三路划分**：处理大量相等元素，避免「全等输入」退化为 $O(n^2)$；
4. **尾递归 / 迭代**：压栈小的一侧，递归深度降为 $O(\log n)$。

**重点：工业快排（C++ `std::sort` 的 introsort）是「快排 + 插入 + 堆排」的组合**——快排为主，退化时切堆排序兜底（保证 $O(n\log n)$），小规模切插入排序。<span class="marginnote">introsort 是「<strong>用组合消灭单一算法的死角</strong>」的典范：<strong>快排负责平均快、堆排负责最坏兜底、插入负责小规模常数</strong>。<strong>没有万能的单一算法，但有万能的组合</strong>——这是工程算法的第一课。</span>

**一个划分的完整算例。** 序列 `[5, 3, 8, 1, 4]`，取第一个元素 5 作枢轴：

1. pivot=5，low 指向左端（空位），high 指向右端 4；
2. 从右找比 5 小的：high 停在 4，把 4 放到左边空位 → `[4, 3, 8, 1, 4]`；
3. 从左找比 5 大的：low 停在 8，把 8 放到右边空位 → `[4, 3, 8, 1, 8]`；
4. 从右找比 5 小的：high 停在 1，放到左边空位 → `[4, 3, 1, 1, 8]`；
5. 左右指针相遇于下标 2，枢轴 5 归位 → `[4, 3, 1, 5, 8]`。

划分结果：左边 `[4, 3, 1]` 全比 5 小、右边 `[8]` 比 5 大——枢轴 5 已就位，对两半递归即完成排序。<span class="marginnote">注意「空位」的交接：<strong>枢轴取走后留下的空位被「从另一端搬来的元素」填补，空位在两端间来回移动</strong>——<strong>最终空位回到中间，枢轴填入即归位</strong>。<strong>「挖坑填数」是严蔚敏版划分的直观记忆</strong>。</span>

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| 枢轴（pivot） | 划分的基准元素 |
| 划分（partition） | 一趟把序列按枢轴分成两半 |
| 挖坑填数 | 空位在两端间移动、枢轴最后归位 |
| 递归深度 | 划分层数，理想 $O(\log n)$、最坏 $O(n)$ |
| introsort | 快排 + 堆排 + 插入的组合排序 |

## 6 小结

- 快排 = 划分（枢轴归位）+ 递归两半，无需合并。
- 平均 $O(n\log n)$、最好 $O(n\log n)$、最坏 $O(n^2)$。
- 划分 1:9 也足够好——快排对不完美划分宽容。
- **不稳定**（跳跃交换）、原地、空间 $O(\log n)$。
- 退化根源：固定枢轴 + 已有序输入；随机/三数取中可驯服。
- 工程形态：introsort = 快排 + 堆排 + 插入排序组合。
