## 为什么选择排序是「最省移动」的排序

插入排序靠「移动」，交换排序靠「交换」；**简单选择排序（simple selection sort）**走第三条路：**每趟从未排序区挑出最小元素，与未排序区第一个元素交换**——一趟确定一个「最终位置」，共 $n-1$ 趟。它的特点是**移动次数极少**（每趟至多交换 1 次，共 $\le n-1$ 次），但**比较次数恒定**（$O(n^2)$，与输入有序与否无关）。简单选择排序是「选择思想」的起点——下一节「堆排序」用堆把「挑最小」从 $O(n)$ 加速到 $O(\log n)$，正是它的进化。

## 1 简单选择排序的算法

```c
// 简单选择排序：每趟挑出未排序区的最小元素，与第一个交换
void SelectSort(int A[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min = i;                      // 假设 A[i] 最小
        for (int j = i + 1; j < n; j++)   // 扫描未排序区找最小
            if (A[j] < A[min]) min = j;
        if (min != i) swap(A[i], A[min]); // 与未排序区第一个交换
    }
}
```

**重点：每趟只做「一次扫描 + 至多一次交换」——移动次数被压到最少，但比较次数是硬性的 $O(n^2)$。**<span class="marginnote">选择排序的「不变式」：<strong>第 $i$ 趟结束时，前 $i$ 个元素是全局最小的 $i$ 个，且已有序</strong>。它与起泡排序的不变式对称——起泡是「末尾固定最大」，选择是「开头固定最小」。</span>

## 2 公式解析：简单选择排序的复杂度

$$
\begin{aligned}
T_{\text{比较}} &= O(n^2) \ \text{（固定：第 } i \text{ 趟比较 } n-i \text{ 次，} \sum = n(n-1)/2 \text{）} \\
T_{\text{移动}} &= O(n) \ \text{（至多 } n-1 \text{ 次交换）} \\
T_{\text{总}} &= O(n^2)
\end{aligned}
$$

- **第一步，读「比较固定」**：无论数据有序与否，每趟都要扫完整个未排序区找最小——**比较次数与输入无关**，最坏=最好=平均。
- **第二步，读「移动极少」**：每趟至多一次交换，总移动 $O(n)$——**在所有 $O(n^2)$ 排序里移动最少**。
- **第三步，读「输入不敏感」**：插入排序「越有序越快」，选择排序「有序无序一个样」——它不会从数据的有序性里占便宜，也不会被逆序坑。<span class="marginnote">「输入不敏感」是一把双刃剑：<strong>选择排序没有最好情况（已有序也 $O(n^2)$ 比较），但也没有最坏退化</strong>。若数据「几乎有序」，插入排序 $O(n)$ 完胜；若数据完全随机，选择排序的移动优势才开始显现。</span>

## 3 稳定性与空间

**稳定性**：**不稳定**。例：序列 `5, 5, 1`，第一趟挑出最小 1 与第一个 5 交换，两个 5 的相对顺序颠倒。
**空间**：$O(1)$，原地排序。

**辨析｜易错点：选择排序的不稳定来自「远距离交换」。** 把最小元素交换到前面时，可能「越过」与其相等的元素——等值元素的相对顺序被破坏。这与起泡排序「相邻交换」保持稳定形成对比：**「跳着换」破坏稳定，「挨着换」保持稳定**。<span class="marginnote">「稳定性 ⇔ 交换的局部性」这条规律再次应验：<strong>起泡（相邻）稳定，选择（跨越）不稳，快排（跨越）不稳</strong>。若必须稳定，要在选择排序里「插入式移位」而非「交换」——但那会牺牲它的「移动最少」优势。</span>

## 4 简单选择 vs 直接插入 vs 起泡

三个 $O(n^2)$ 排序的全面对比：

| 维度 | 简单选择 | 直接插入 | 起泡 |
| --- | --- | --- | --- |
| 比较次数 | $O(n^2)$ 固定 | 最好 $O(n)$ | 最好 $O(n)$ |
| 移动/交换 | 最少（$O(n)$） | 移动多 | 交换多 |
| 稳定性 | 不稳定 | 稳定 | 稳定 |
| 输入敏感 | 否 | 是（有序快） | 是（有序快） |
| 实战 | 移动少时好 | 有序时好 | 垫底 |

**重点：三个 $O(n^2)$ 排序各有胜场——选择「移动少」、插入「有序快」、起泡「教学用」。** 工程上按数据特征挑：近有序用插入，移动昂贵（大对象）用选择，其余常用插入的变体。<span class="marginnote">「移动代价 vs 比较代价」是选 $O(n^2)$ 排序的标尺：<strong>对象大（拷贝贵）选选择排序（移动少），对象小且近有序选插入排序（比较少）</strong>。当元素是「几百字节的大结构体」，一次交换/移动的成本就能决定胜负。</span>

## 5 数值算例：一趟趟「挑最小」的完整轨迹

以序列 `[64, 25, 12, 22, 11]` 走一遍简单选择排序：

- **第 1 趟**：未排序区为全部 5 个，最小是 11（下标 4），与 64 交换 → `[11, 25, 12, 22, 64]`；
- **第 2 趟**：未排序区 `[25, 12, 22, 64]`，最小 12，与 25 交换 → `[11, 12, 25, 22, 64]`；
- **第 3 趟**：未排序区 `[25, 22, 64]`，最小 22，与 25 交换 → `[11, 12, 22, 25, 64]`；
- **第 4 趟**：未排序区 `[25, 64]`，最小 25，位置已正确 → 不交换；
- 排序完成：共 3 次交换、$4 + 3 + 2 + 1 = 10$ 次比较。

**对比插入排序**：同样的 `[11, 12, 22, 25, 64]` 若已有序，插入排序每趟只需 1 次比较即可确认就位，共约 4 次；而选择排序无论数据如何都要扫满 10 次——**这就是「输入不敏感」付出的代价**。<span class="marginnote">算例直观呈现选择排序的两面性：<strong>交换极少（大对象友好）、比较恒定（不占有序的便宜）</strong>。工程判断由此干脆：<strong>元素拷贝昂贵 → 选择排序；数据近有序 → 插入排序</strong>。</span>

## 6 从选择排序到堆排序

简单选择排序的瓶颈一眼可见：**每趟挑最小要扫 $O(n)$，$n$ 趟就是 $O(n^2)$**。堆排序的改进正是针对这里——**用二叉堆维护「未排序区的最小值」，挑最小从 $O(n)$ 降到 $O(\log n)$**：

建堆 $O(n)$；
每趟取堆顶（最小/最大）$O(\log n)$，$n$ 趟 $O(n\log n)$。

**重点：堆排序 = 简单选择排序 + 数据结构加速。** 选择排序的「每趟全扫描」被堆的「上浮下沉」替代，复杂度从 $O(n^2)$ 跃到 $O(n\log n)$——**这是「用数据结构优化朴素算法」的教科书案例**。<span class="marginnote">「朴素算法慢在哪，就用数据结构加速哪」是一条通用工程思路：<strong>选择排序慢在「找最小」，堆就是「找最小的数据结构」</strong>；同理，Dijkstra 慢在「找最小 dist」，堆加速后 $O((n+e)\log n)$。<strong>同一个加速模式，贯穿排序与图算法</strong>——下一节堆排序正式登场。</span>

**辨析｜易错点：选择排序的「移动最少」只算交换，不算临时变量。** 一次 `swap` 通常要 3 次赋值（借助临时变量），所以「至多 $n-1$ 次交换」实际是「至多 $3(n-1)$ 次赋值」。真正意义上的「移动最少」指「记录级移动」——每个元素最多移动一次进最终位置。对大对象（结构体、长字符串）排序时，「每元素至多移动一次」的优势是压倒性的。

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| 未排序区 / 已排序区 | 趟次划分的两段 |
| 一趟确定一个位置 | 每趟固定一个元素的最终位置 |
| 输入不敏感 | 比较次数与数据有序性无关 |
| 不稳定 | 远距离交换破坏等值顺序 |
| 堆排序 | 用堆把「挑最小」加速到 $O(\log n)$ |

**延伸对照**：选择排序的「反复挑最小」与《树形选择排序》的败者树一脉相承——「如何更快找最小」从全扫描、到锦标赛树、再到堆，是一条完整的技术路线。

**辨析｜易错点：选择排序的「比较恒定」既是优点也是缺点。** 它不占有序的便宜（已有序也 $O(n^2)$ 比较），但也不被逆序坑（最坏也是 $O(n^2)$）——「输入不敏感」让它的性能可预测。若数据几乎有序，插入排序完胜；数据随机、元素拷贝贵，选择排序更稳。

**一句话**：选择排序的舞台是「大对象 + 移动昂贵」——每元素至多移动一次进最终位置，这个承诺它兑现得最彻底。

**补充**：选择排序与堆排序是「找最小」的两种实现——一个全表扫、一个用堆加速，复杂度差一个 $\log$ 因子。

## 7 小结

- 简单选择：每趟挑最小交换到最前，共 $n-1$ 趟。
- 比较固定 $O(n^2)$，移动最少 $O(n)$——输入不敏感。
- **不稳定**：远距离交换破坏等值顺序。
- 三 $O(n^2)$ 排序对比：选择移动少、插入有序快、起泡教学用。
- 大对象（拷贝贵）选选择排序。
- 堆排序 = 选择排序 + 堆加速「找最小」到 $O(\log n)$。
