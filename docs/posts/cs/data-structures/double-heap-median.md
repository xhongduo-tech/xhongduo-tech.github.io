## 为什么「动态中位数」难

静态中位数排序后取中间即可 $O(n\log n)$。但**动态中位数**——元素不断插入，每次都要当前中位数——静态排序每次都重来就是 $O(n^2)$。**对顶堆（two heaps）**给出优雅解：**一个大根堆放「较小的半边」，一个小根堆放「较大的半边」**，两堆大小差 ≤ 1，中位数就是「较大那堆的堆顶」或「两堆顶的平均」。插入 $O(\log n)$、取中位数 $O(1)$。它把「动态集合的中位数」变成「两个堆顶的协调」——是「堆管极值」思想的双倍应用。

## 1 对顶堆的结构

用两个堆维护一个动态集合：

- **大根堆 maxHeap**：存**较小的一半**元素，堆顶是「较小半边的最大值」；
- **小根堆 minHeap**：存**较大的一半**元素，堆顶是「较大半边的最小值」；

**不变量**：两堆大小相等或差 1，且小半边最大值 ≤ 大半边最小值——即**所有小半边的元素都不大于所有大半边的元素**。<span class="marginnote">「<strong>小半边全 ≤ 大半边全</strong>」是对顶堆的黄金不变量：<strong>它保证中位数就在两个堆顶之间</strong>。维护这个不变量的动作只有两个——「插到哪边」与「两边大小失衡时搬顶」。<strong>两个堆 + 一条不变量 = 动态中位数</strong>。</span>

## 2 插入与平衡

插入一个元素 $x$：

1. 若 $x \le$ `maxHeap.top()`（或堆空）→ 入大根堆（小半边）；否则入小根堆（大半边）；
2. **再平衡**：若 `maxHeap` 比 `minHeap` 大 2 个，把 `maxHeap` 顶搬到 `minHeap`；反之亦然——保持两堆大小差 ≤ 1。

```c
void Insert(int x) {
    if (maxHeap.empty() || x <= maxHeap.top())
        maxHeap.push(x);                    /* 归类到小半边 */
    else
        minHeap.push(x);                    /* 归类到大半边 */

    /* 再平衡：保持两堆大小差 ≤ 1 */
    if (maxHeap.size() > minHeap.size() + 1) {
        minHeap.push(maxHeap.top());        /* 大根堆顶搬到小根堆 */
        maxHeap.pop();
    } else if (minHeap.size() > maxHeap.size() + 1) {
        maxHeap.push(minHeap.top());        /* 小根堆顶搬到大根堆 */
        minHeap.pop();
    }
}
```

**重点：插入 = 「归类入堆」 + 「搬顶平衡」，两个动作都是 $O(\log n)$。** 归类的判据是「与较小半边最大值的比较」，平衡的判据是「两边大小差」。<span class="marginnote">「<strong>归类看值、平衡看大小</strong>」是插入的两步口诀：<strong>值比小半边最大值小 → 小半边；大小失衡 → 把堆顶搬到另一边</strong>。每次插入最多搬一个顶，所以插入严格 $O(\log n)$——<strong>两个堆各 $O(\log n)$，一次搬顶 $O(\log n)$</strong>。</span>

## 3 公式解析：取中位数

取当前中位数：

$$
\text{中位数} = \begin{cases} \maxHeap.top() & \text{若 } |\text{max}| > |\text{min}| \\ \dfrac{\maxHeap.top() + \minHeap.top()}{2} & \text{若两堆等大} \end{cases}
$$

- **第一步，读「奇数个」**：总数奇数时，较大那堆多 1 个，其堆顶就是中位数——它恰好在「分界线」上。
- **第二步，读「偶数个」**：总数偶数时，中位数是「两个堆顶的平均」——分界线两侧的「中间两数」。
- **第三步，读「$O(1)$ 取中位数」**：两个堆顶都是 $O(1)$ 可读——取中位数不花时间。<span class="marginnote">「<strong>两堆顶夹着中位数</strong>」是对顶堆最直观的图景：<strong>大根堆顶 = 较小半边的最大，小根堆顶 = 较大半边的最小</strong>，中位数就夹在这两数之间。奇偶两种情形，分别取「靠多的一边的顶」或「两顶平均」——<strong>一个 if 分支，搞定奇偶</strong>。</span>

## 4 对顶堆 vs 其他求中位数的方法

| 方法 | 插入 | 取中位数 | 适用 |
| --- | --- | --- | --- |
| 排序后取中间 | 每插一次 $O(n\log n)$ | — | 静态 |
| 平衡树（BST） | $O(\log n)$ | $O(\log n)$ 找第 K 大 | 通用但实现重 |
| **对顶堆** | **$O(\log n)$** | **$O(1)$** | 中位数专用、实现简单 |
| 计数/分段统计 | $O(1)$ 更新 | $O(\sqrt{n})$ 或 $O(\log V)$ | 值域小的场景 |

**重点：对顶堆是「中位数专用」的最优解**——插入 $O(\log n)$、取中位数 $O(1)$，实现只需两个堆。<span class="marginnote">「<strong>专用结构 > 通用结构</strong>」是对顶堆给我们的启示：<strong>平衡树能求中位数，但对顶堆专为中位数而造，取中位数 $O(1)$、实现更短</strong>。<strong>「按需定制数据结构」往往比「套用万能结构」更优</strong>——就像「最小生成树有专用算法，不必用最短路硬凑」。</span>

## 5 对顶堆的扩展与变体

**滑动窗口中的中位数**：对顶堆 + 延迟删除（标记删除）——窗口滑出元素时惰性移除；
**第 K 大/小**：把「两堆」换成「K 堆 + 剩余堆」——大根堆存「前 K-1 大」、小根堆存其余，堆顶即第 K 大；
**分位数/百分位**：同理推广到任意分位。

**辨析｜易错点：滑动窗口的删除要「延迟」。** 堆不支持「删任意元素」（要 $O(n)$ 找），所以窗口滑出时**不立即删**，而是记一个「待删除」计数，取中位数时把堆顶的「已删除元素」惰性弹出。这个「延迟删除」是对顶堆在滑动窗口场景的关键技巧。<span class="marginnote">「<strong>堆不会删任意元素 → 用延迟删除</strong>」是堆类应用的通病解药：<strong>先把「要删的」标记起来，等它飘到堆顶时再真正弹出</strong>。这个技巧在「堆 + 窗口」「堆 + 在线 Top K」里反复出现——<strong>「惰性」是补偿「堆不能任意删」的标准姿势</strong>。</span>

**一个逐步插入的算例。** 依次插入 $5, 3, 8, 1, 7$：

1. 插 5：入 maxHeap，堆内 $[5]$；
2. 插 3：$3 \le 5$ 入 maxHeap，堆内 $[5,3]$（顶 5），大小差 2 → 把顶 5 搬入 minHeap，得 max=$[3]$、min=$[5]$，奇数取多的一边，中位数 $=3$；
3. 插 8：$8 > 3$ 入 minHeap，得 max=$[3]$、min=$[5,8]$，中位数 $=5$；
4. 插 1：$1 \le 3$ 入 maxHeap，得 max=$[3,1]$、min=$[5,8]$，两堆等大，中位数 $=(3+5)/2 = 4$；
5. 插 7：$7 > 3$ 入 minHeap，得 max=$[3,1]$、min=$[5,7,8]$，min 多 1 个，中位数 $=5$。

每一步的中位数都来自「两个堆顶的协调」——没有排序，没有 $O(n)$ 扫描。<span class="marginnote">注意第 4 步：等大时中位数是「两堆顶的平均」$4$——它甚至不是任何已插入元素。<strong>「两顶平均」是偶数个元素时中位数的标准定义</strong>，也是面试题的常考细节。</span>

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| 对顶堆 | 大根堆（小半边）+ 小根堆（大半边） |
| 黄金不变量 | 小半边全 ≤ 大半边全，且大小差 ≤ 1 |
| 归类 | 按值与较小半边最大值的比较入堆 |
| 再平衡 | 大小失衡时把堆顶搬到另一边 |
| 延迟删除 | 堆不能任意删，先标记待删、飘到顶再弹出 |

**辨析｜易错点：对顶堆的「归类」看值、「平衡」看大小——两步别混。** 归类：新元素 ≤ maxHeap 顶 → 小半边；平衡：两堆大小差 ≤ 1 的维护。若用「大小」去归类、用「值」去平衡，堆序与中位数都会错。

**一句话**：对顶堆把「动态中位数」变成「两个堆顶的协调」——插入 $O(\log n)$、取中位数 $O(1)$。

## 6 小结

- 对顶堆：大根堆放小半边 + 小根堆放大半边，两堆顶夹中位数。
- 插入：按值归类 + 大小失衡搬顶，$O(\log n)$。
- 取中位数：奇数取较大堆顶、偶数取两顶平均，$O(1)$。
- 不变量：小半边全 ≤ 大半天全，且大小差 ≤ 1。
- 对比：中位数专用最优，实现短于平衡树。
- 扩展：滑动窗口（延迟删除）、第 K 大、分位数。
