## 线段树不止会求和

线段树的「聚合值」只需满足**可结合**——所以它既能求和，也能求**最大值、最小值、最大子段和、gcd**。本节看三个经典应用：**区间最值**（`RMQ` 动态版）、**最大子段和**（聚合三个量的经典题）、以及**扫描线**（用线段树求矩形并的面积——「离散化 + 线段树 + 事件排序」的组合拳）。这三个例子说明：**线段树的价值不在「求和」，而在「任何可合并的区间统计」**——换一种聚合，就换一类问题。

## 1 应用一：区间最值（RMQ）

把「聚合」从「和」换成「max」：线段树的每个结点存「该区间最大值」。建树、单点改、区间查的骨架一字不改，只把 `tree[node] = left + right` 换成 `tree[node] = max(left, right)`。

**重点：线段树支持「可结合」的任何聚合**——`max`、`min`、`gcd`、`最大子段和`，全都能 $O(\log n)$ 区间查询。这是它比树状数组强的地方（树状数组只适合「可逆」的聚合如加法）。<span class="marginnote">「<strong>聚合只要可结合，线段树就能管</strong>」：<strong>求和、最大、最小、gcd——全是「结合律」的住户</strong>。<strong>树状数组要求「可逆」（有减法），线段树只要求「可结合」</strong>——所以 max 这类「不可逆」操作是线段树的专属领地。</span>

## 2 应用二：最大子段和

「区间最大连续子段和」无法简单合并——两个子段的最大子段和，拼接后可能横跨中间。解法是每个结点存**三个量**：

- `sum`：区间和；
- `lmax`：以区间左端开始的最大前缀和；
- `rmax`：以区间右端结束的最大后缀和；
- `best`：区间内最大子段和。

合并公式：

$$
\begin{aligned}
\text{best} &= \max(\text{左.best}, \ \text{右.best}, \ \text{左.rmax} + \text{右.lmax}) \\
\text{lmax} &= \max(\text{左.lmax}, \ \text{左.sum} + \text{右.lmax}) \\
\text{rmax} &= \max(\text{右.rmax}, \ \text{右.sum} + \text{左.rmax})
\end{aligned}
$$

**重点：最大子段和靠「三个量 + 合并公式」把「跨中段」也考虑进去**——它展示了「聚合值可以是结构体」的思想，是线段树聚合设计的代表作。<span class="marginnote">「<strong>一个聚合不够，就存三个</strong>」：<strong>最大子段和要「跨中间」，就得知道每段的 sum、lmax、rmax</strong>——<strong>把「聚合」从标量升级为结构体，是线段树进阶的第一课</strong>。合并公式的推导，本质是「枚举最大子段可能在的位置」。</span>

## 3 应用三：扫描线求矩形并面积

**问题**：给 $n$ 个矩形（可能有重叠），求覆盖的总面积。

**扫描线（sweep line）**三步走：

1. **事件排序**：把每个矩形的「左竖边」记为 +1 事件、「右竖边」记为 -1 事件，按 x 坐标排序；
2. **离散化 y**：把所有矩形的 y 坐标离散化成若干区间；
3. **线段树维护覆盖长度**：沿 x 从左到右扫，处理事件时「区间 +1/-1」更新线段树，`覆盖长度 × Δx` 累加进面积。

```text
面积 = Σ (当前 y 被覆盖长度) × (下一事件的 x - 当前 x)
```

**公式解析：扫描线的复杂度**

$$
T = O(n \log n) \quad \text{（$2n$ 个事件排序 $O(n\log n)$ + $2n$ 次线段树区间更新 $O(\log n)$）}
$$

- **第一步，读「事件化」**：矩形并面积被拆成「沿 x 的若干薄条」，每条的宽度 = 相邻事件的 Δx、高度 = 当前被覆盖的 y 长度。
- **第二步，读「线段树的作用」**：维护「y 方向被覆盖的长度」——支持区间加（+1/-1）与查「总覆盖长」。这正是上一节「懒惰标记 + 区间修改」的用武之地。
- **第三步，读「复杂度」**：事件排序 + 每事件一次区间更新，$O(n\log n)$。<span class="marginnote">「<strong>扫描线 = 把二维问题降成一维线段树</strong>」：<strong>沿一个方向扫，另一方向用线段树维护「覆盖状态」</strong>——二维变一维，复杂度从 $O(n^2)$ 降到 $O(n\log n)$。<strong>「扫一维、树一维」是几何问题的标准降维术</strong>，矩形并、矩形交、周长都能这么干。</span>

## 4 扫描线的细节与变体

- **y 离散化**：y 坐标太多/太大，压缩成「单位区间」的编号——线段树建在离散后的区间上；
- **+1/-1 是「覆盖计数」**：线段树的聚合从「和」换成「覆盖长度」（覆盖计数 > 0 的长度）——聚合又换了一种；
- **变体**：求矩形并的周长、求矩形交面积、多边形面积（转扫描线）。

**重点：扫描线把「覆盖计数」这个聚合塞进线段树**——再次证明「聚合可换」：求和、最值、覆盖长度、最大子段，全都能塞进同一棵线段树。<span class="marginnote">「<strong>线段树的聚合是插件</strong>」：<strong>同一个骨架，插「和」就是求和树、插「覆盖长度」就是扫描线树、插「三量结构体」就是最大子段树</strong>。<strong>「掌握骨架 + 会写聚合」就是掌握了线段树的全部</strong>——这是「数据结构的复用」最生动的例证。</span>

## 5 线段树应用总览

| 应用 | 聚合值 | 关键技巧 |
| --- | --- | --- |
| 区间最值 RMQ | `max` | 可结合即可 |
| 区间和 | `sum` | 最基础 |
| 最大子段和 | `{sum, lmax, rmax, best}` | 结构体聚合 |
| 覆盖长度（扫描线） | 覆盖计数 → 长度 | 离散化 + 事件排序 |
| gcd / 位运算 | `gcd` / `and, or` | 不可逆聚合 |

**重点：线段树是「区间聚合」的万能容器——选对聚合，就能解一类题。** 它的学习曲线在「聚合设计」，不在「树本身」。<span class="marginnote">「<strong>会设计聚合 = 会解区间题</strong>」：<strong>拿到区间问题先想「要聚合什么、怎么合并」，再想「要不要懒惰标记」</strong>。<strong>线段树的骨架是固定的，可变的是「每个结点存什么」</strong>——把聚合想清楚，代码自然就写出来了。</span>

## 6 小结

- 线段树支持任何「可结合」聚合——求和、最值、gcd、覆盖长度。
- 最大子段和：聚合升级为结构体 `{sum, lmax, rmax, best}`。
- 扫描线：事件排序 + 离散化 + 线段树维护覆盖长度。
- 矩形并面积 $O(n\log n)$：扫一维、树一维的降维术。
- 聚合是插件：换聚合 = 换一类问题。
- 线段树学习的核心在「聚合设计」，骨架是固定的。
