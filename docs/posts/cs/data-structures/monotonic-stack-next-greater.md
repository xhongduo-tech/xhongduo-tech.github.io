## 为什么「下一个更大元素」要专门结构

朴素做法：对每个元素向右扫描找第一个更大的——$O(n^2)$。**单调栈（monotonic stack）**把它压到 $O(n)$：**维护一个「从栈底到栈顶单调递减（或递增）」的栈**，扫描时「该弹出的元素，其下一个更大元素就是当前元素」。单调栈的威力来自一个观察：**已经被弹出栈的元素，永远不会再是后续任何元素的「下一个更大元素」**——所以它们可以安全丢弃。理解单调栈 = 理解「维护候选集 + 及时淘汰」的在线优化思想。

## 1 单调栈的核心思想

**单调栈**：栈内元素按「从栈底到栈顶」保持单调（增或减）。以「下一个更大元素」为例：

- 从右往左扫（或从左往右），维护一个**栈底到栈顶单调递减**的栈；
- 栈里存的是「还没确定答案的元素的候选」；
- 当前元素入栈前，**把所有比它小的元素弹出**——那些被弹的元素，其「下一个更大元素」就是当前元素。

```cpp
vector<int> nextGreater(vector<int>& a) {
    int n = a.size();
    vector<int> ans(n, -1);
    stack<int> st;                    // 栈底到栈顶单调递减，存下标
    for (int i = 0; i < n; i++) {
        while (!st.empty() && a[st.top()] < a[i]) {
            ans[st.top()] = a[i];     // 弹出即了断：下一个更大 = 当前元素
            st.pop();
        }
        st.push(i);
    }
    return ans;                       // 留在栈里的没有更大者，记 -1
}
```

**重点：每个元素「入栈一次、出栈一次」——总代价 $O(n)$。** 被弹出即答案确定，弹出后永不回头。<span class="marginnote">「<strong>弹出即了断</strong>」是单调栈的灵魂：<strong>一个元素被弹出，意味着「找到了它的下一个更大元素」，此后它不再参与任何判断</strong>。<strong>「入栈一次、出栈一次」→ $O(n)$</strong>——这个「每个元素只处理常数次」的保证，是单调栈高效的全部来源。</span>

## 2 为什么「弹出即正确答案」

设当前元素 $a[i]$ 弹出栈顶 $t$（$a[t] \le a[i]$）：

$t$ 右边的元素中，比 $t$ 大的**最小位置**……等等——为什么 $a[i]$ 就是 $t$ 的「下一个更大元素」？
**栈内单调递减**：栈里 $t$ 下方（栈底方向）的元素都比 $a[t]$ 大，但它们都在 $t$ 的**左边**；
$t$ 右边的、比 $t$ 大的、且位置最靠前的，恰是**从左往右扫时第一个「大到能弹出 $t$」的元素**——即当前 $a[i]$。

**重点：单调递减栈保证「栈顶是被弹元素右边最近的更大者」**——因为任何「在 $t$ 右边、比 $t$ 大」的元素，都会在扫描到它时把 $t$ 弹出。<span class="marginnote">「<strong>谁弹出你，谁就是你的答案</strong>」：<strong>单调栈里的淘汰顺序天然按「最近的更大者」排列</strong>——<strong>先被更大的元素弹出 = 答案更近</strong>。<strong>栈这个「后进先出」正好匹配「从左到右的邻近关系」</strong>，所以它成了「下一个更大」的天然容器。</span>

## 3 公式解析：复杂度 O(n)

设 $n$ 个元素：

$$
T_{\text{单调栈}} = O(n) \quad \text{（每个元素恰好入栈一次、出栈一次）}
$$

- **第一步，读「两次」**：每个元素入栈一次（push）、出栈至多一次（pop）——共 $O(n)$ 次栈操作。
- **第二步，读「while 的总量」**：虽然每步有 $O(1)$ 循环，但**总弹出次数 ≤ 总入栈次数 = $n$**——摊还 $O(1)$/元素。
- **第三步，读「与朴素对比」**：朴素「对每个元素向右找」$O(n^2)$；单调栈每个元素只被「看」常数次——**$O(n)$，且是最优**。<span class="marginnote">「<strong>while 不叠加 = 摊还线性</strong>」是单调栈/单调队列共用的复杂度论证：<strong>每个元素只会被弹出一次，所以「弹」的总次数有上界</strong>。<strong>「看起来有内层循环，实际总量受限」</strong>——这是「摊还」在数据结构里的经典套路。</span>

## 4 变体：下一个更小、左右边界

单调栈的「单调方向」与「扫描方向」一变，就能解不同问题：

| 问题 | 栈的单调性 | 扫描方向 |
| --- | --- | --- |
| 下一个更大 | 栈底到栈顶递减 | 从右往左（或从左） |
| 下一个更小 | 栈底到栈顶递增 | 从右往左 |
| 左边第一个更小 | 递增 | 从左往右 |
| 左边第一个更大 | 递减 | 从左往右 |

**重点：同一套单调栈，换「单调方向」与「扫描方向」，就得到「下一个/上一个 × 更大/更小」四类问题**——模板不变，参数变。<span class="marginnote">「<strong>一个模板、四类问题</strong>」是单调栈的可迁移性：<strong>「更大/更小」决定栈的单调方向，「下一个/上一个」决定扫描方向</strong>——<strong>背熟一套，四类题自动会写</strong>。这也是为什么单调栈是「模板题」之王。</span>

## 5 单调栈与「柱状图最大矩形」

最经典的单调栈应用（下一节展开）：**柱状图最大矩形**。

对每个柱子，要找「以它为高的最大矩形」= 它的**左右第一个更矮的柱子**之间的宽度；
「左右第一个更矮」正是单调栈的两问——用一次单调递增栈，同时求出左右边界。

**重点：单调栈的核心识别词是「左右第一个更大/更小」**——凡问题里出现「找离它最近的、比它大/小的元素」，单调栈就是第一选择。<span class="marginnote">「<strong>识别词：最近 + 更大/更小</strong>」是单调栈的触发条件：<strong>柱状图矩形（左右更矮）、接雨水（左右更高）、温度（下一个更大）、股票跨度</strong>——全是这个模式。<strong>看到「最近的一个比它…」就想到单调栈</strong>。</span>

**一个逐步演算的算例。** 数组 $a = [4, 2, 5, 1, 3]$，从左往右扫，维护单调递减栈（存下标）：

- $i=0$：栈空，入栈下标 0（值 4）；
- $i=1$：$a[0]=4 > 2$，不弹，入栈下标 1，栈 $[0, 1]$；
- $i=2$：$a[1]=2 < 5$，弹 1，`ans[1]=5`；$a[0]=4 < 5$，弹 0，`ans[0]=5`；入栈下标 2，栈 $[2]$；
- $i=3$：$a[2]=5 > 1$，不弹，入栈下标 3，栈 $[2, 3]$；
- $i=4$：$a[3]=1 < 3$，弹 3，`ans[3]=3`；$a[2]=5 > 3$，不弹；入栈下标 4，栈 $[2, 4]$。

结果 `ans = [5, 5, -1, 3, -1]`——栈里残留的下标 2、4 没有更大元素，记 -1。每个元素恰好入栈一次、出栈一次，共 $O(n)$ 次操作。<span class="marginnote">注意下标 2（值 5）全程没被弹出——它右边没有更大的元素。<strong>「留在栈里 = 没有答案」</strong>，这些元素的答案是默认值 -1。<strong>「弹与不弹」完全由「谁比我大且在我右边」决定</strong>——这正是单调栈「候选集」的取舍逻辑。</span>

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| 单调栈 | 栈内自底到顶单调（增/减） |
| 弹出即了断 | 被弹元素的答案 = 当前元素 |
| 摊还 $O(1)$ | 每元素入栈、出栈各一次 |
| 候选集 | 栈里「还没确定答案」的元素 |
| 识别词 | 「左右第一个更大/更小」→ 单调栈 |

## 6 小结

- 单调栈：栈内单调（增/减），维护「还有希望当答案」的候选。
- 弹出即了断：被弹元素的下一个更大（小）就是当前元素。
- 复杂度 $O(n)$：每元素入栈/出栈各一次，摊还线性。
- 四类变体：更大/更小 × 下一个/上一个——换方向与单调性。
- 识别词：「左右第一个更大/更小」→ 单调栈。
- 柱状图最大矩形、接雨水、每日温度都是它的经典舞台。
