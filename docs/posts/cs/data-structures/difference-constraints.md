## 为什么不等式组能化成最短路

**差分约束系统（system of difference constraints）**：一组形如 $x_j - x_i \le c$ 的不等式，求一组满足全部不等式的解（或判定无解）。表面是代数问题，内核却是**图论问题**——把每个变量 $x_i$ 当顶点，把不等式 $x_j - x_i \le c$ 画成**有向边 $i \to j$，权 $c$**，则「满足所有不等式」等价于「图中不存在负权回路」，一组解可由**最短路（或最长路）**给出。这是「问题到图」建模的经典——学会它，你就掌握了把约束系统翻译成图的通用能力。

## 1 从不等式到图

对每个不等式 $x_j - x_i \le c$：

- **建边**：$i \to j$，权值 $c$；
- 若给定了变量的取值范围（如 $x_i \le C$），加**虚拟源点** $x_0 = 0$，连 $0 \to i$ 权 $C$。

**重点：$x_j \le x_i + c$ 恰是「最短路三角不等式」的形态**——「沿边 $i\to j$ 走，$x_j$ 至多 $x_i + c$」。于是「找一组满足全部约束的 $x$」=「从虚拟源点求到各点的最短路」。<span class="marginnote">「<strong>$x_j - x_i \le c$ 就是边 $i\to j$</strong>」是差分约束的全部魔法：<strong>最短路算法里「$dist[v] \le dist[u] + w$」正是同一条不等式</strong>。<strong>「求最短路」自动保证「沿每条边都满足三角不等式」</strong>——<strong>算法天然产出合法解</strong>。</span>

## 2 无解 ⇔ 负权回路

**判定无解**：若差分约束图存在**负权回路**，则不等式组无解——因为沿负环累加，会推出 $0 \le \text{负数}$ 的矛盾（绕环一圈 $x_i \le x_i + \text{负}$）。

**判定方法**：用 **Bellman-Ford**（或 SPFA）从虚拟源点跑最短路——**第 $n$ 轮还能松弛（或入队 ≥ n 次）即有负环 = 无解**。

**重点：差分约束的「无解判定」就是「负环检测」——两个概念在此合二为一。** 这正是上一节 Bellman-Ford「检测负环」能力的用武之地。

**辨析｜易错点：负环判定的实现细节。** Bellman-Ford 跑 $n$ 轮，若第 $n$ 轮仍能松弛，说明存在负环；SPFA 则看「某点入队次数是否 ≥ n」。两种写法都要注意：**判负环必须把第 $n$ 轮跑完，不能提前退出**——否则稀疏图上负环可能藏在最后几条边里。另一个细节是「负权边 ≠ 负环」：单条负边不构成无解，只有「绕一圈总和为负」的回路才判无解。<span class="marginnote">「<strong>无解 ⇔ 负环</strong>」是差分约束的核心定理：<strong>沿负环转一圈，$x_i \le x_i + (负数)$，只能推出矛盾</strong>。<strong>所以「判断约束有无解」=「判断图有无负环」</strong>——<strong>不等式系统的可解性，交给最短路算法裁决</strong>。</span>

## 3 公式解析：最短路即解

设从虚拟源点 $x_0$ 出发求最短路 $dist[v]$，则一组可行解：

$$
x_v = dist[v]
$$

- **第一步，读「为什么满足」**：最短路满足三角不等式 $dist[j] \le dist[i] + w(i,j)$——即 $x_j \le x_i + c$，恰是约束 $x_j - x_i \le c$。
- **第二步，读「虚拟源点」**：加 $x_0 = 0$ 与边 $0 \to v$ 权 0（或不加，初始化 $dist=0$ 的「超级源」技巧），保证每个变量都被覆盖。
- **第三步，读「取最值」**：最短路给的是「满足约束的**最大**解」（都 ≤ 某上界）；若求「最小解」，把不等式转成 $x_i - x_j \le -c$ 或求最长路。<span class="marginnote">「<strong>最短路给最大解、最长路给最小解</strong>」：<strong>约束 $x_j \le x_i + c$ 天然是「上界」，最短路把每个 $x$ 压到「不超过任何约束的最小上界」</strong>。<strong>「解不唯一、最短路取一边」</strong>——这是差分约束的微妙之处。</span>

## 4 差分约束的典型问题

**不等式组求解**：直接建模；
**时间 / 距离约束**：「任务 $j$ 不早于任务 $i$ 后 $c$ 天」→ $x_j - x_i \ge c$（转成 $-x_i + x_j \ge c$，再变号成 $\le$）；
**区间约束 / 选点问题**：前缀和变量差分建模；
**图论转化**：任何「$A$ 与 $B$ 之差 ≤ 常数」的约束族。

**辨析｜易错点：不等式方向与建边方向。** $x_j - x_i \le c$ 建边 $i \to j$ 权 $c$；若给的是 $\ge$，先变号成 $\le$（两边乘 -1）再建边。**方向建反，答案全错。**<span class="marginnote">「<strong>方向错了，负环就变正环</strong>」：<strong>$\ge$ 约束必须先变号成 $\le$ 再建边</strong>——<strong>这是差分约束最常见的坑</strong>。<strong>一个口诀：「$\le$ 直接建、$\ge$ 先取反」</strong>——方向永远朝「$\le$ 的箭头方向」。</span>

**区间选点问题**：给定若干区间 $[l_i, r_i]$，要求「每个区间内至少选一个点」。令前缀和 $S_k$ 表示「$1..k$ 中选的点数」，则「区间 $[l, r]$ 内至少选一个点」写成 $S_r - S_{l-1} \ge 1$，「相邻位置最多选一个」写成 $S_i - S_{i-1} \le 1$，「点数非负」写成 $S_i - S_{i-1} \ge 0$。全部是差分约束，一次 Bellman-Ford 就得到最少选点数——**经典区间贪心问题，用差分约束也能无脑解出**。

**差分约束的编码细节**：邻接表建图时注意边权可为负，不能直接用 Dijkstra，必须用 Bellman-Ford 或 SPFA；判无解要「多跑一轮」而不是只看一轮收敛；求具体方案时给每个 $x_i$ 一个足够大的初值（如 $0$ 的超级源）可以免去显式虚拟源点。

## 5 从差分约束到最短路体系

差分约束是「最短路算法」的建模应用，它与前面的知识链：

**Bellman-Ford / SPFA**：求解与负环检测的引擎；
**最长路变体**：求「最小值」时把图反过来求最长路（或全部取负求最短路）；
**拓扑序特例**：若图是 DAG，可用 DP 求最短路（$O(n+m)$），不必 Bellman-Ford。

**重点：差分约束把「代数的约束系统」翻译成「图的最短路」**——它示范了「建模」这一高级能力：**拿到一个抽象问题，能画成图、套上已知算法**。<span class="marginnote">「<strong>建模 = 把陌生问题翻译成熟知结构</strong>」：<strong>不等式 → 图、约束 → 边、可解性 → 负环</strong>——<strong>一次成功的建模，就把新问题变成了旧算法</strong>。<strong>差分约束是「图建模」的最佳入门课</strong>，学会它，再看线性规划、网络流建模就都有了直觉。</span>

## 6 数值算例：把三个不等式组解出来

空谈「最短路即解」，不如手算一个完整例子。设变量 $x_1, x_2, x_3$，约束系统为

$$
\begin{aligned}
x_2 - x_1 &\le 3 \\
x_3 - x_2 &\le -2 \\
x_3 - x_1 &\le 1
\end{aligned}
$$

**第一步，建图**：三条不等式对应三条边 $1 \to 2$（权 3）、$2 \to 3$（权 $-2$）、$1 \to 3$（权 1）。再加虚拟源点 $0$，连 $0 \to 1$、$0 \to 2$、$0 \to 3$ 权均为 0。

**第二步，从 $0$ 跑 Bellman-Ford 求最短路**：初始 $dist[1]=dist[2]=dist[3]=0$。第一轮松弛：边 $1\to2$ 权 3，$dist[2] \le dist[1]+3 = 3$，不更新（0 更小）；边 $2\to3$ 权 $-2$，$dist[3] \le dist[2]-2 = -2$，更新 $dist[3]=-2$；边 $1\to3$ 权 1，$dist[3] \le 0+1=1$，$-2$ 更小，不更新。第二轮无更新，收敛。

**第三步，读解**：$x_1=0,\ x_2=0,\ x_3=-2$。回代验证：$x_2-x_1 = 0 \le 3$ ✓；$x_3-x_2 = -2 \le -2$ ✓；$x_3-x_1 = -2 \le 1$ ✓。三式全部满足。

注意这个解不是唯一的——$x_1=1, x_2=1, x_3=-1$ 同样满足（整体加常数）。**最短路给出的只是「让每个变量尽量小」的那一组特解**，这正是「最大解/最小解」语境的来源。<span class="marginnote">自己动手把「三不等式 → 三边 → 最短路」走一遍，比背十遍定理都管用。<strong>建图、松弛、回代，三步循环往复</strong>，差分约束就从「神奇变身术」变成常规手艺。</span>

## 7 核心对比表：差分约束与它的表亲

| 问题 | 形态 | 求解引擎 | 解的性质 |
| --- | --- | --- | --- |
| 差分约束 | $x_j - x_i \le c$ | Bellman-Ford / SPFA | 最短路 = 最大解 |
| 普通最短路 | 已知图，求 $dist$ | Dijkstra / Bellman-Ford | 无「解」概念，直接求值 |
| 线性规划（LP） | $Ax \le b$ | 单纯形 / 内点法 | 有目标函数，求极值 |
| 差分约束求最小解 | 变号成 $\le$ 或求最长路 | Bellman-Ford 变体 | 最长路 = 最小解 |

三句总结：**第一**，差分约束是「只有两两差、无目标函数」的 LP 特例，因此可以用最短路这种图算法解，而不用通用的单纯形。**第二**，判断无解的唯一标准是负环，它对应 LP 的「可行域为空」。**第三**，工程里「时间窗口」「距离下限」「频率差约束」都能塞进这个框架，SQL 的谓词约束与调度系统的时序约束尤其常见。<span class="marginnote">把差分约束放进 LP 谱系，是为了让你在更高的视角看它：<strong>它只是「稀疏、纯差、无目标」的线性系统</strong>，图算法是它趁手的专用工具。<strong>学数据结构最终要能反哺算法与系统设计</strong>，这张表就是桥梁。</span>

## 8 小结

- 差分约束：$x_j - x_i \le c$ → 建边 $i\to j$ 权 $c$。
- 解 = 从虚拟源点的最短路 $x_v = dist[v]$——最短路三角不等式天然满足约束。
- 无解 ⇔ 负权回路——用 Bellman-Ford 第 n 轮松弛 / SPFA 计数检测。
- 判负环要跑满第 n 轮，负单边不是负环。
- 最短路给最大解、最长路给最小解。
- $\ge$ 约束先变号成 $\le$ 再建边——方向是最大坑。
- 差分约束是「问题 → 图」建模的经典，覆盖时间/距离/区间约束。
- 边权为负 → 不能用 Dijkstra，必须 Bellman-Ford/SPFA。
- 数值流程：建边 → 松弛 → 回代验证，手算一遍胜过背定理。
- 与 LP 的关系：稀疏纯差无目标的线性系统，图算法是其专用引擎。
- 数值流程复盘：建边（含虚拟源点）→ 松弛至收敛 → 回代验证三条不等式。

在下一节，我们从最短路进入路径计数——**次短路与第K短路**。差分约束给我们的最大财富不是某个模板，而是「**把陌生约束翻译成熟悉算法**」的建模直觉——下一节的第 K 短路，依然要用到这条思路。
