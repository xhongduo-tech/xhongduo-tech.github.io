## 为什么 B 树的插入是「分裂」

§9.6 讲了 B 树的定义与「叶子同层」。本节把 B 树的**插入操作**做透：**分裂（split）**是它的核心动作——结点满了，就一分为二，把中间关键字**上提到父结点**；父结点若也满，继续向上分裂，可能一直裂到根（树长高一层）。这套「分裂上提」让 B 树**永远保持叶子同层、树高只增不减**——它与二叉树的「旋转」不同，是「向上长」的平衡。理解分裂，就理解了 B 树「矮而稳」的根源。

## 1 B 树的结点结构与满的条件

$m$ 阶 B 树的每个结点：**最多 $m-1$ 个关键字、$m$ 个孩子指针**（非叶）。结点「满」即关键字数达到 $m-1$。

**重点：$m$ 阶 B 树的「满」= 有 $m-1$ 个关键字。** 这是分裂的触发条件，也是 B 树一切操作的边界。<span class="marginnote">「<strong>满 = $m-1$ 个关键字</strong>」是 B 树的第一标尺：<strong>小于它随便插，等于它就裂，小于一半（$\lceil m/2 \rceil - 1$）就要借或并</strong>。<strong>「满、半、空」三档边界，定义了 B 树的全部再平衡</strong>。</span>

## 2 插入流程：定位 + 分裂上提

插入一个关键字 $k$：

1. **查找定位**：从根出发，找 $k$ 应插入的**叶子结点**；
2. **直接插入**：叶子未满（关键字 < $m-1$），直接插到位；
3. **分裂**：叶子满，把结点分裂成左右两半，**中间关键字上提到父结点**；父结点若因此满，继续向上分裂；
4. **根分裂**：根满了就分裂，产生**新根**——树高 +1。

```
// B 树插入：定位叶子 → 直接插 → 满则分裂上提（可能一直裂到根）
Insert(T, k):
  1. 从根出发查找 k：记录路径，定位到叶子结点 leaf
  2. 若 leaf 未满（keynum < m-1）：把 k 插到 leaf 的有序位置，返回
  3. 否则：分裂 leaf
     - 把 k 加入后共 m 个关键字，取中键 k_mid（第 ⌈m/2⌉ 个）
     - 左半键留在 leaf，右半键移到新结点 sibling
     - 中键 k_mid 上提到父结点，插入到 leaf 与 sibling 之间
  4. 若父结点因上提而满，重复第 3 步，继续向上分裂
  5. 若根也被分裂：新建根结点只含 k_mid，树高 +1
```

**重点：插入永远发生在叶子；分裂把「满结点」一分为二、中键上提——「满则裂、裂则提」沿路径向上。**<span class="marginnote">「<strong>分裂是 B 树唯一的生长方式</strong>」：<strong>二叉树靠「旋转」长高（局部重排），B 树靠「分裂」长高（中间值上提）</strong>。分裂让「叶子同层」这个性质永远成立——<strong>B 树没有「不平衡」的概念，只有「裂没裂」</strong>。</span>

## 3 公式解析：分裂的细节

设结点 $N$ 有 $m-1$ 个关键字 $k_1 < k_2 < \cdots < k_{m-1}$，要插入第 $m$ 个。分裂：

$$
N \ \xrightarrow{\text{裂}} \ N_L \ (\text{前 } \lceil m/2 \rceil - 1 \text{ 键}) \quad + \quad \text{中键 } k_{\lceil m/2 \rceil} \ \xrightarrow{\text{上提}} \quad + \quad N_R \ (\text{后 } m - \lceil m/2 \rceil \text{ 键})
$$

- **第一步，读「中键的位置」**：第 $\lceil m/2 \rceil$ 个关键字被上提，左右各分一半——**保证分裂后每半都不少于 $\lceil m/2 \rceil - 1$ 个关键字**（B 树的最小占用）。
- **第二步，读「孩子指针」**：$N_L$ 带前一半孩子、$N_R$ 带后一半孩子，中键在父里隔开两半。
- **第三步，读「为什么中键上提」**：中键在父结点里充当「分隔符」——左子树全小于它、右子树全大于它，B 树的有序性在分裂后依然成立。<span class="marginnote">「<strong>分裂 = 保序切半 + 中键上提</strong>」：<strong>中键的位置恰是「一半与一半」的分界，上提后它既正确分隔、又保持了「所有叶子同层」</strong>。<strong>分裂不破坏任何 B 树性质</strong>——这是它作为「唯一生长动作」能被反复执行的原因。</span>

## 4 辨析｜易错点：根分裂的特殊性

**根分裂是 B 树唯一「长高」的方式**——新根只有 1 个关键字（中键），树高 +1；
**非根分裂不改变树高**——只是把「满」的结点换成「半 + 半」，中键上移到父；
**分裂是「向上传递」的**：一个结点分裂，可能引发父分裂、祖父分裂……直到某个父不满或到根。

**重点：B 树的高度只会在「根分裂」时增加 1——这是它与二叉平衡树最不同的生长模式。** 二叉平衡树靠旋转局部平衡，B 树靠「从下往上裂」，两者殊途同归：树高都 $O(\log n)$。<span class="marginnote">「<strong>根裂才长高</strong>」让 B 树的高度变化「低频而全局」：<strong>平时插来插去树高不变，偶尔根裂一次高度 +1</strong>。<strong>这种「稳定高度」正是数据库索引需要的——页结构不会频繁重建</strong>。</span>

## 5 B 树插入的复杂度

设树高 $h = O(\log_m n)$：

$$
T_{\text{插入}} = O(h) = O(\log_m n) \quad \text{（沿路径下行 + 至多 $h$ 次分裂）}
$$

- **第一步，读「下行」**：从根到叶子，每层结点内找位置（顺序或二分），$O(h)$ 层。
- **第二步，读「分裂次数」**：一次插入最多沿整条路径分裂（每层一次），仍 $O(h)$。
- **第三步，读「为什么很少真裂」**：只有「恰好满」的结点才裂，平均每个结点用到一半以上才裂——**实际分裂远少于理论上限**。<span class="marginnote">「<strong>满才裂、裂了变半满</strong>」让 B 树的结点利用率至少 50%（$m$ 大时接近 $\lceil m/2 \rceil/m$）：<strong>插入很多次才需要一次分裂</strong>。这也是 B 树适合磁盘的原因——<strong>结点大、分裂少、I/O 次数少</strong>。</span>

## 6 数值算例：一棵 $m=3$ 树的两次分裂

用 $m=3$ 阶 B 树（每个结点至多 2 个关键字）把「分裂上提」落到具体动作。依次插入 10、20、30、40、50：

- **插入 10、20**：根结点依次收下，得 `[10, 20]`——不满，直接插。
- **插入 30**：`[10, 20, 30]` 达满（3 键），按第 3 节的规则分裂：取中键 20（第 $\lceil 3/2 \rceil = 2$ 个）上提为新根，左 `[10]`、右 `[30]`。**树高从 1 变 2，根裂了一次。**
- **插入 40**：沿中键 20 向右下行到叶子 `[30]`，得 `[30, 40]`——不满，直接插。
- **插入 50**：叶子 `[30, 40, 50]` 达满，中键 40 上提到根，根 `[20]` 变 `[20, 40]`，左 `[30]`、右 `[50]`。**这次分裂发生在叶子层，树高没变。**

最终结构：根 `[20, 40]`，三个叶子 `[10]`、`[30]`、`[50]`——所有叶子同层、每结点关键字有序。全部 5 个插入里只发生了 2 次分裂，**「满才裂、裂了变半满」让分裂频率远低于插入频率**。

**重点：根分裂改变树高（20 上提那次），叶子分裂只改变局部（40 上提那次）——「向上裂」是 B 树唯一的生长方式。**<span class="marginnote">这个例子还说明 B 树为何磁盘友好：<strong>5 次插入只有 2 次结点分裂，平均 2.5 次插入才重排一次</strong>。若用二叉搜索树，几乎每个插入都要旋转；而 B 树靠「攒满再裂」把再平衡成本摊薄——<strong>结点越大（$m$ 越大），分裂越稀，I/O 越省</strong>。</span>

**辨析｜易错点：分裂的「中键上提」会让父结点「多一个孩子」。** 一个结点从「$m-1$ 键、$m$ 孩子」裂成「左右各半 + 父里多一个中键」——父结点的孩子数也 +1。若父本来就有 $m$ 个孩子，上提后变 $m+1$ 个，父就「超满」——这正是父继续分裂的触发。**「孩子数 = 键数 + 1」的守恒，贯穿整条分裂链。**

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| 满结点 | 键数 = $m-1$ |
| 分裂 | 切半 + 中键上提 |
| 中键 | 第 $\lceil m/2 \rceil$ 个关键字 |
| 根分裂 | 唯一让树长高的动作 |
| 最小占用 | $\lceil m/2 \rceil - 1$ 个键 |

**辨析｜易错点：分裂的「中键」是「新插入后的第 $\lceil m/2 \rceil$ 个」，不是原结点的中位。** 先把新键插入（共 $m$ 个键），再取第 $\lceil m/2 \rceil$ 个上提——顺序不可反。取错中键，左右半的「最小占用」就保证不了。

**一句话**：B 树的再平衡只有一个动作——「满则裂、裂则提」，向根生长。

## 7 小结

- B 树结点：至多 $m-1$ 键、$m$ 个孩子；「满」= 键数到 $m-1$。
- 插入：定位叶子 → 直接插；满则分裂、中键上提。
- 分裂：切半 + 中键上提，保持有序与叶子同层。
- 根分裂是唯一「长高」的方式——新根单键、树高 +1。
- 复杂度 $O(\log_m n)$；满才裂、结点利用率 ≥ 50%。
- 分裂是 B 树唯一的平衡动作——「向上长」而非「旋转」。
