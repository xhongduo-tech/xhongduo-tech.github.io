## 为什么还要 Floyd

Dijkstra 求「一个源点到所有点」，要全源最短路就得跑 $n$ 次。**Floyd 算法**用一个漂亮的动态规划直接求出**任意两点之间的最短路**：$O(n^3)$ 一次搞定，代码只有三行核心循环。它不挑图（可含负权边，只是不能有负权回路），实现极简，尤其适合**稠密图**与「需要查任意点对距离」的场景。Floyd 是「动态规划」思想在数据结构课里的第一次完整亮相——状态、转移、初始化三件套，一应俱全。

## 1 Floyd 的思想：以「中间点」递推

设 $dist[i][j]$ 为从 $i$ 到 $j$ 的当前最短路，初始为邻接矩阵（不直接相邻为 $\infty$）。核心递推：

**允许前 $k$ 个顶点作为中间点时，$i$ 到 $j$ 的最短路 = 要么不用第 $k$ 个顶点（保持 $k-1$ 时的结果），要么经过第 $k$ 个顶点（$i \to k$ 的最短路 + $k \to j$ 的最短路）。**

$$
dist_k[i][j] = \min\{ dist_{k-1}[i][j],\ dist_{k-1}[i][k] + dist_{k-1}[k][j] \}
$$

三重循环，外层是 $k$（中间点）、内两层是 $i, j$：

```c
/* Floyd：三重循环，外层 k 是「允许作为中间点的最大顶点编号」 */
for (int k = 0; k < n; k++)                  /* 第 k 阶段：放开顶点 k */
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (dist[i][k] + dist[k][j] < dist[i][j]) {
                dist[i][j] = dist[i][k] + dist[k][j];   /* 松弛 */
                path[i][j] = path[k][j];                /* 记录路径 */
            }
```

**重点：外层 $k$ 必须放在最外面。** 递推的正确性依赖「$dist_{k}$ 由 $dist_{k-1}$ 推出」——若 $k$ 不在最外层，会用到「本轮已被 $k$ 更新」的值，破坏 DP 的阶段结构。<span class="marginnote">「外层 $k$」不是实现细节，而是 DP 的阶段划分：<strong>第 $k$ 阶段只允许前 $k$ 个顶点当中间人</strong>。这个「逐步放开中间点集合」的设计，是 Floyd 能收敛到全源最短路的原因，也是它区别于「乱序松弛」的根本。</span>

## 2 公式解析：Floyd 的状态与复杂度

状态 $dist_k[i][j]$ 的含义与递推已在上面给出。复杂度一目了然：

$$
T_{\text{Floyd}} = O(n^3), \qquad S_{\text{Floyd}} = O(n^2)
$$

- **第一步，读时间**：三重循环各 $n$ 次，共 $n^3$ 次松弛。$n=1000$ 时是 $10^9$ 次——所以 Floyd 只适合中等规模的稠密图。
- **第二步，读空间**：一张 $n \times n$ 的距离矩阵（加一张可选的路径矩阵）。
- **第三步，与「跑 $n$ 次 Dijkstra」对比**：Dijkstra 朴素 $n$ 次是 $O(n^3)$ 同级，但堆优化是 $O(n(n+e)\log n)$——稀疏大图用「$n$ 次堆 Dijkstra」更快，稠密图用 Floyd 更简单直接。<span class="marginnote">「Floyd 还是 $n$ 次 Dijkstra」的选型：<strong>稠密图、代码要短、允许 $O(n^3)$ → Floyd；稀疏大图、要最优单源 → 堆优化 Dijkstra × n</strong>。工程里两者并存，按图的规模与形态挑选。</span>

## 3 负权边与负权回路的检测

Floyd 能处理**负权边**（Dijkstra 不行），前提是**没有负权回路**（一圈下来总权为负的环）。

负权边没问题：Floyd 的松弛能「绕路变便宜」；
**负权回路会毁了所有最短路**：在环上绕圈，距离无限减小，$dist[i][i]$ 会被更新成负数——这本身就是检测信号。

**辨析｜易错点：检测负权回路看对角线。** Floyd 结束后检查 $dist[i][i] < 0$ 的对角元：若有，说明存在负权回路，最短路无定义。**对角线本应全为 0（$i$ 到 $i$ 距离 0）**，被更新成负值即「绕圈越绕越短」的铁证。<span class="marginnote">「$dist[i][i]$ 变负 = 有负环」是 Floyd 白送的检测器。<strong>凡含负环的图，最短路问题本身无解</strong>——因为可以无限绕圈。Bellman-Ford（专题篇）用「第 $n$ 轮还能松弛」检测负环，与此异曲同工。</span>

## 4 记录路径：path 矩阵

Floyd 同样可以记录路径。维护 $j$ = 「从 $i$ 到 $j$ 最短路中，$j$ 的前驱」（或「第一个中间点」）。松弛成功时更新。重建路径时递归/循环沿 $j$ 走：

$$
\text{path}[i][j] = \begin{cases} \text{path}[i][k] & \text{若经过 } k \text{ 更短} \\ \text{path}[i][j] & \text{保持原样} \end{cases}
$$

**重点：path 矩阵让「任意点对的最短路」都能 $O(n)$ 重建。** 这是 Floyd 相比「$n$ 次 Dijkstra」的另一便利——所有点对路径一次性存好。<span class="marginnote">「矩阵存答案 + 矩阵存路径」是<strong>全源最短路</strong>的标准形态：查任意两点，先查距离、再沿 path 展开路径。<strong>一次计算、任意查询</strong>——这是「预计算索引」思想在路径问题上的体现，与数据库「建索引换查询快」同构。</span>

## 5 Floyd 的应用

**传递闭包**：把「距离」换成「是否可达」，$dist[i][j]$ 用「或」运算递推——Floyd 变体求**传递闭包**（$O(n^3)$），用于判「任意两点是否间接可达」；
**全源最短路查询**：交通网络、地图服务的「任意两点距离表」；
**带权图的闭包分析**：社交图谱的「影响力传播路径」；
**DP 的入门案例**：Floyd 是「区间/阶段 DP」的最简范例，也是后续《算法》课程 DP 的引子。

**重点：Floyd 是「动态规划」的第一次完整演出**——状态（$dist_k[i][j]$）、阶段（$k$）、转移（min 合并）、初始化（邻接矩阵）四件套齐全。<span class="marginnote">Floyd 与《算法》课的「区间 DP」同族：<strong>「允许前 k 个」与「区间长度」都是对 DP 状态做「阶段化」</strong>。先理解 Floyd 的「阶段-状态-转移」，后面学矩阵链乘、最优二叉搜索树时就有了现成的思维框架。</span>

**一个具体的算例。** 三顶点 $1,2,3$，初始 $dist[1][2]=4$、$dist[1][3]=9$、$dist[2][3]=1$，其余为 $\infty$、对角线 0。第 1 阶段（中间点 1）：无更新。第 2 阶段（中间点 2）：

- $dist[1][3]$ 现为 9，$dist[1][2]+dist[2][3]=4+1=5 < 9$，更新为 5，path 记 $1 \to 2 \to 3$；
- 其余组合无更新。第 3 阶段（中间点 3）：无更新。

最终 $dist[1][3]=5$——**一条「绕道」的路径打败了直达边**，这正是「允许中间点」递推的威力：$1$ 到 $3$ 的最短路不是直边 $9$，而是经 $2$ 的 $4+1=5$。<span class="marginnote">这个例子浓缩了 Floyd 的全部直觉：<strong>最短路往往藏在「绕路」里</strong>。因为外层 $k$ 逐个放开中间点，$k=2$ 之后「允许 $2$ 当中间人」就顺带修正了 $1$ 到 $3$ 的距离——DP 的「阶段」在此体现得淋漓尽致。</span>

**辨析｜Floyd vs 跑 $n$ 次 Dijkstra**

| 维度 | Floyd | $n$ 次 Dijkstra |
| --- | --- | --- |
| 复杂度 | $O(n^3)$ | 堆优化 $O(n(n+e)\log n)$ |
| 负权边 | 支持 | 不支持 |
| 代码量 | 三行核心循环 | 需复写 $n$ 遍 |
| 路径重建 | path 矩阵一次搞定 | 各源点分别存 |
| 适用 | 稠密图、实现要短 | 稀疏大图、单源优先 |

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| 全源最短路 | 任意两点之间的最短路集合 |
| 松弛（relax） | 用 $dist[i][k]+dist[k][j]$ 更新 $dist[i][j]$ |
| 负权回路 | 总权为负的环，最短路无定义 |
| 传递闭包 | 判「任意两点是否间接可达」的变体 |
| path 矩阵 | 记录最短路前驱，供重建路径 |

## 6 小结

- Floyd 求**全源最短路**：三重循环 $O(n^3)$、空间 $O(n^2)$。
- 状态：允许前 $k$ 个顶点作中间点的最短路；外层 $k$ 是 DP 阶段。
- 支持负权边，不支持负权回路；$dist[i][i]<0$ 即负环信号。
- path 矩阵记录路径，任意点对 $O(n)$ 重建。
- 变体：传递闭包（距离换可达）。
- 与「$n$ 次 Dijkstra」对比：稠密图用 Floyd，稀疏大图用堆 Dijkstra。
