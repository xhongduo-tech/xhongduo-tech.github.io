## 为什么先学起泡排序

**起泡排序（bubble sort）**是最直观的交换排序：**相邻比较，逆序就交换**，一趟下来最大元素「冒」到末尾；重复 $n-1$ 趟，序列有序。它的教学价值不在效率（$O(n^2)$），而在两点：一是**稳定**——相邻交换不破坏等值元素的相对顺序；二是**可优化**——「一趟无交换即可提前结束」让它对有序输入达到 $O(n)$。起泡排序是「交换排序」的入门，快速排序将在它之后登场。

## 1 起泡排序的算法

```cpp
void BubbleSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        bool swapped = false;
        for (int j = 0; j < n - i; j++) {
            if (a[j] > a[j + 1]) {       /* 逆序才交换（严格大于，保稳定） */
                swap(a[j], a[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;             /* 一趟无交换 → 已有序，提前结束 */
    }
}
```

**重点：起泡排序每趟把「当前范围内最大元素」送到末尾——第 $i$ 趟后，末尾 $i$ 个元素已就位，下一趟只需比较前 $n-i$ 对。**<span class="marginnote">「每趟固定一个最大值到尾部」是起泡排序的核心循环不变式：<strong>第 $i$ 趟结束时，最后 $i$ 个元素是全局最大的 $i$ 个，且有序</strong>。这个不变式保证了 $n-1$ 趟后全体有序。</span>

## 2 公式解析：起泡排序的复杂度

$$
\begin{aligned}
T_{\text{最好}} &= O(n) \qquad \text{（已有序：第一趟无交换，提前结束）} \\
T_{\text{最坏}} &= O(n^2) \qquad \text{（逆序：每趟都做满，比较 + 交换约 } \frac{n^2}{2} \text{ 次）} \\
T_{\text{平均}} &= O(n^2) \qquad \text{（约一半的交换）}
\end{aligned}
$$

- **第一步，读最好 $O(n)$**：第一趟扫描发现无交换，$n-1$ 直接结束——只比较 $n-1$ 次。**这是「可提前终止」带来的最好情况**。
- **第二步，读最坏 $O(n^2)$**：逆序时第 $i$ 趟比较 $n-i$ 次，累加 $\sum (n-i) = n(n-1)/2$，且每次都交换。
- **第三步，读「交换多」**：起泡的交换次数接近比较次数（逆序时），而**交换比比较贵**（三次赋值）——这使它在同阶算法里常数偏大，实际常慢于插入排序。<span class="marginnote">「交换比比较贵」常被忽视：<strong>一次交换 = 三次赋值，而一次比较只是读+判</strong>。起泡排序交换频繁，常数大——这就是为什么它「理论 $O(n^2)$、实战垫底」，也解释了为何工程排序几乎不用纯起泡。</span>

## 3 稳定性与空间

**稳定性**：稳定。相邻交换只在 `a[j] > a[j+1]`（逆序）时发生，相等元素不会被交换——相对顺序保持。
**空间**：$O(1)$，原地排序。

**辨析｜易错点：起泡排序「不比较相等的元素」。** 条件写 `>` 而不是 `>=`——这是稳定性的关键。若写 `>=`，相等的元素也会被交换，稳定就丢了。**「是否稳定」往往就藏在一个 `>` 与 `>=` 之差里。**<span class="marginnote">「$>$ vs $\ge$ 决定稳定性」是一条可推广的规律：<strong>插入、起泡、归并等相邻比较算法，只要条件用「严格大于」就稳定</strong>；快排的划分若用「<=」也可能破坏稳定。<strong>写排序时，稳定性的开关就在比较运算符里</strong>。</span>

## 4 起泡排序 vs 直接插入排序

两个「相邻式」$O(n^2)$ 排序的对比：

| 维度 | 起泡排序 | 直接插入 |
| --- | --- | --- |
| 操作 | 比较后交换 | 比较后移动 |
| 最好情况 | $O(n)$（无交换早停） | $O(n)$（有序） |
| 交换/移动次数 | 多（逆序时近 $n^2/2$） | 少（移动优于交换） |
| 常数 | 偏大 | 偏小 |
| 实战速度 | 垫底 | 快于起泡 |

**重点：插入排序通常快于起泡——因为「移动」比「交换」省。** 插入排序每趟移动的元素个数与起泡交换次数相近，但移动（一次赋值）比交换（三次赋值）便宜。<span class="marginnote">「移动 vs 交换」是选择排序与交换排序的分野：<strong>一次交换 = 三次移动</strong>。所以「能移动就别交换」——插入、选择、归并都靠移动，起泡、快排才用交换。这个「赋值次数」的视角，让排序的常数对比变得清晰。</span>

## 5 起泡排序的优化与地位

**优化一（已用）**：无交换早停——对近乎有序输入 $O(n)$；
**优化二**：记录「最后交换位置」，下趟只比较到该位置——尾部有序段不再比较；
**鸡尾酒排序（双向起泡）**：一趟从左、一趟从右交替冒泡，对「中段乱序、两端有序」的数据更快。

**重点：起泡排序的教学价值远超其实战价值**——它的「相邻比较 + 交换 + 早停」是理解「交换排序」「稳定性」「最好情况分析」的完美载体。<span class="marginnote">工程上为什么不用起泡？因为<strong>它同时输给插入排序（常数）与快速排序（阶数）</strong>。但作为「算法分析的活教材」，它的最好/最坏/平均、稳定/不稳定、可优化点，几乎覆盖了评价一个排序的全部维度——<strong>学会分析起泡，就学会分析一切排序</strong>。</span>

## 6 小结

- 起泡排序：相邻比较、逆序交换，每趟把最大元素冒到末尾。
- 复杂度：最好 $O(n)$（无交换早停）、最坏/平均 $O(n^2)$。
- **稳定**：`>` 而非 `>=`，相等元素不动。
- 交换比移动贵：起泡常数大，实战常垫底。
- 插入通常快于起泡（移动 < 交换）。
- 优化：早停、记录最后交换位置、双向起泡。
