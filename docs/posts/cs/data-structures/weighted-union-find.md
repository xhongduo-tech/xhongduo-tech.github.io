## 为什么并查集还要「带权」

基础并查集只回答「是否同一集合」。但很多问题要「**同一集合内元素间的关系**」：数值上「x 比 y 重多少」、逻辑上「x 与 y 是同类还是天敌」。**带权并查集（weighted union-find）**给每个结点到父结点挂一个**权值**，Find 时累计路径权，Union 时推导新关系——让「关系」随集合一起维护。**种类并查集（type union-find）**是它的特例：权值取模「种类数」，用于「食物链」「敌人朋友」这类**关系取模**的问题。本节讲清「权怎么存、路径怎么累加、合并怎么推」，并配食物链问题示范。

## 1 带权并查集：边带关系

每个结点多存一个 `weight[x]`（权值），表示「x 到父结点的关系值」：

```c
int parent[MAXN];   /* 父指针，根指向自己 */
int weight[MAXN];   /* weight[x] = x 到 parent[x] 的关系权值 */
```

- **Find 带路径压缩**：沿路径走时，把「x 到根的距离」逐段累加，并把 x 直接挂到根下、权值更新为「x 到根的距离」；
- **Union**：已知 x、y 及其根 rx、ry，以及「x 与 y 的关系」，推导出「rx 与 ry 的关系」，把 rx 挂到 ry（或反之）并赋权。

```c
int find(int x) {                      /* 带权 Find：先递归、再累加、最后挂根 */
    if (parent[x] == x) return x;
    int root = find(parent[x]);        /* 先求出父结点到根的距离 */
    weight[x] += weight[parent[x]];    /* 再累加得到「x 到根」的权值 */
    return parent[x] = root;           /* 最后把 x 直接挂到根下 */
}
```

**重点：Find 的路径压缩要「先递归、再累加、最后挂根」**——先求出父到根的距离，才能更新「x 到根的距离」。顺序错，权值就错。<span class="marginnote">「<strong>先递归后累加</strong>」是带权 Find 的纪律：<strong>parent[x] 的权值要在它自己 Find 完之后才有效</strong>。这个「先算父、再算子」的递归顺序，与树的「后根遍历」同构——<strong>自底向上的信息流动</strong>。</span>

## 2 带权 Union：从已知关系到根的关系

设已知「x 与 y 的关系为 $d$」（如 $val[x] - val[y] = d$，取模语义时 $d$ 在 $[0, k)$）。要合并 rx、ry：

1. Find(x) 得 rx 与 `wx`（x 到 rx 的距离）、Find(y) 得 ry 与 `wy`；
2. 把 rx 挂到 ry 下，令 `weight[rx] = d + wy - wx`——使「x 到 ry 的距离」恰好满足已知关系。

$$
\text{weight}[rx] = d + wy - wx
$$

- **第一步，读推导**：要求 $val[x] - val[y] = d$。挂 rx 到 ry 后：$val[x] = val[rx] + wx$，$val[y] = val[ry] + wy$，$val[rx] = val[ry] + weight[rx]$。代入展开即得。
- **第二步，读「模语义」**：种类并查集里所有运算对 $k$ 取模，$d \in [0, k)$。
- **第三步，读「同一集合内的查询」**：若 Find(x) == Find(y)，则 rel(x, y) = (weight[x] - weight[y]) mod k（取模）。<span class="marginnote">「带权 Union 的公式」看起来吓人，本质就是「<strong>解一个线性方程</strong>」：<strong>已知 val[x]、val[y] 与根的关系、以及 val[x] - val[y]，求两个根的关系</strong>。把它当「代数方程」而非「背公式」，任何题型的权值推导都能现场解。</span>

## 3 种类并查集：关系取模

**种类并查集**把关系限制为「若干种类」的取模等价类。经典例题**食物链**：A 吃 B、B 吃 C、C 吃 A，三种关系循环。令关系值 $d$ 表示「x 与 y 的关系」：

$d = 0$：同类；
$d = 1$：x 吃 y；
$d = 2$：x 被 y 吃（y 吃 x）。

于是「关系」构成模 3 的循环群：**x 吃 y、y 吃 z ⇒ x 与 z 的关系 = 1 + 1 = 2（z 吃 x）**——关系值的加法取模 3。整套带权并查集在模 3 下运行。

**重点：种类并查集 = 带权并查集 + 关系取模 $k$。** 它把「关系」抽象成「模 $k$ 加法群」，让「关系的复合」变成「权值的模加法」——同一个框架，换 $k$ 就换问题。<span class="marginnote">「<strong>关系取模 = 关系是循环群</strong>」是种类并查集的数学本质：<strong>食物链（模 3）、敌人朋友（模 2）、猫狗性别（模 2）</strong>，全是「$k$ 种关系循环往复」。这个「把关系代数化」的视角，让看似不同的题共用同一套代码——<strong>抽象的力量</strong>。</span>

## 4 公式解析：食物链的查询与合并

在模 3 语义下，$val[x]$ 表示「x 的物种」（0、1、2）。两条关键规则：

$$
\text{查询：} rel(x, y) = (val[x] - val[y]) \bmod 3
$$
$$
\text{合并：} val[rx] = (d + val[y] - val[x]) \bmod 3
$$

- **第一步，读查询**：同集合内，x 与 y 的关系 = 物种差取模 3；为 0 同类、1 被 y 吃、2 吃 y。
- **第二步，读合并**：已知「x 与 y 的关系为 d」，解出根 rx 的物种，挂根并赋权。
- **第三步，读「矛盾检测」**：若 Find(x) == Find(y) 但算出的关系与题目陈述矛盾，则这是假话。<span class="marginnote">「种类并查集 = 边带权的图染色」——<strong>每个结点染「种类色」，边的权是两端的色差</strong>。合并 = 确定两块染色的相对偏移；矛盾 = 已确定的关系与新关系冲突。这个「<strong>带偏移的图着色</strong>」视角，能统一食物链、团伙、性别推断等一大类「关系推理」题。</span>

## 5 带权并查集的应用

**食物链 / 生态关系**：模 3 循环关系（经典）；
**敌人与朋友**：模 2——「敌人的敌人是朋友」（种类并查集的入门）；
**区间和 / 差值约束**：权 = 数值差，Find 时解线性方程；
**并查集上的数学关系推理**：竞赛题「带偏移的连通块」。

**重点：带权并查集把「集合的合并」升级为「关系的合并」**——从「谁和谁一伙」进化到「谁和谁什么关系」，能覆盖的问题面宽了一个量级。<span class="marginnote">「基础并查集管『连通』，带权并查集管『关系』」：<strong>连通是关系的特例（只有同类/不同类），关系是连通的推广（任意权值语义）</strong>。理解了带权版，再回头看基础版，就像「从黑白到彩色」——<strong>同一个数据结构，语义丰富了，能解的题就多了</strong>。</span>

**一个食物链的具体推演。** 三种动物 A、B、C（模 3，0 同类、1 吃、2 被吃）。陈述「A 吃 B」：Find 得 $val[A]=0, val[B]=0$，合并 $rx$ 挂到 $ry$：$val[rx] = (1 + val[B] - val[A]) \bmod 3 = 1$——A 的根物种设为 1、B 的根物种 0，恰表示「A 吃 B」。

再查「B 与 C」：若 $val[C]=2$（相对同一根），则 $rel(B,C) = (val[B]-val[C]) \bmod 3 = (0-2) \bmod 3 = 1$——B 吃 C。而「A 吃 B」+「B 吃 C」按模 3 复合：A 与 C 关系 $= (1+1) \bmod 3 = 2$，即 C 吃 A——与食物链「A 吃 B、B 吃 C、C 吃 A」完全吻合。<span class="marginnote">「关系复合 = 模加法」在例子里看得最清楚：<strong>吃的关系循环（A→B→C→A）对应模 3 加法的循环（1+1=2，再 +1=0）</strong>。<strong>把「吃与被吃」翻译成「$0,1,2$ 的模加法」，种类并查集就能自动推出任何两动物的关系</strong>——这是「关系代数化」的魔力。</span>

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| 带权并查集 | 边带关系值的并查集 |
| weight[x] | x 到父结点的关系权值 |
| 路径压缩累加 | Find 时逐段累加 x 到根的距离 |
| 种类并查集 | 关系取模 $k$ 的带权并查集 |
| 矛盾检测 | 已确定关系与新陈述冲突即假话 |

**辨析｜易错点：带权并查集的「权值方向」要全篇统一。** weight[x] 表示「x 到父的关系」，Find 累加、Union 推导都用同一方向；方向一乱，查出的关系差一个符号或取模偏移。写之前先定「权值指父」还是「父指子」。

**一句话**：带权并查集把「集合合并」升级为「关系合并」——食物链、差值约束都能解。

## 6 小结

- 带权并查集：`weight[x]` = x 到父的关系值；Find 路径压缩时累加、挂根。
- Find 顺序：先递归父、再累加权、最后挂根。
- 带权 Union：`weight[rx] = d + wy - wx`——解线性方程得根关系。
- 种类并查集：关系取模 $k$（食物链模 3），关系复合 = 模加法。
- 查询：rel(x, y) = (weight[x] - weight[y]) mod k；矛盾检测 = 已确定关系与新陈述冲突。
- 应用：食物链、敌人朋友、差值约束、关系推理。
