## 为什么从顺序表转向链表

上一节我们看到了顺序表的局限：**中间插入要搬动 $n/2$ 个元素**。问题出在哪？出在「逻辑相邻 = 物理相邻」这条铁律——顺序表为了维持它，每次插入都得给新元素腾出一整段连续位置。这一节我们松开这条铁律：**逻辑相邻，物理上可以随便放**，用一根「指针」把元素之间的关系显式穿起来。这种结构就是**链表（linked list）**。

这是数据结构里第一次「用空间换时间」的经典交易：为了插入删除从 $O(n)$ 降到 $O(1)$，我们付出的代价是每个结点多存一个指针（空间），以及放弃随机存取（取第 $i$ 个元素变回 $O(n)$）。霍尔的「数十亿美元失误」正好点题：**指针是自由的源泉，也是错误的高发地**——空指针、悬垂指针、断链，链表里每一个坑都通向这里。<span class="marginnote">霍尔 1965 年在 ALGOL W 中发明了 null 引用。他后来公开道歉，说这是「数十亿美元的错误」——因为空指针导致的崩溃、漏洞与修复成本难以估量。链表把指针暴露给程序员，也把这份危险带到了台前。</span>

## 1 单链表的结点与存储结构

**单链表（singly linked list）**：用一组**任意的存储单元**存放线性表的元素，逻辑上相邻的元素在物理上不一定相邻。每个存储单元称为一个**结点（node）**，它由两部分组成：

**数据域（data）**：存放元素值；
**指针域（next）**：存放直接后继结点的地址。

C 语言的定义如下：

```c
typedef struct LNode {
    ElemType data;          /* 数据域 */
    struct LNode *next;     /* 指针域：指向直接后继 */
} LNode, *LinkList;
```

注意 `next` 指向的是**同类结构体**——这是 C 语言里「自引用结构」的典型写法：结点里存着下一个结点的地址，下一个结点里又存着它的下一个……如此一环扣一环，把零散的内存串成一条链。

整个表用**头指针（head pointer）** `L` 指向第一个结点；最后一个结点的 `next` 为空，记为 `NULL`，表示「链到此为止」。判断空表，就看头指针是否为空：

```c
/* 不带头结点：头指针为空即空表 */
if (L == NULL) { /* 空表 */ }

/* 带头结点：头结点无后继即空表 */
if (L->next == NULL) { /* 空表 */ }
```

## 2 头结点：一个容易被误解的「哨兵」

严蔚敏教材里，单链表有两种形态，区别只在一个结点：

**带头结点**：在第一个元素结点之前，额外挂一个**头结点（head node）**。头结点的数据域可以不用（或存表长），其指针域指向第一个元素结点。
**不带头结点**：头指针直接指向第一个元素结点。

**辨析｜易错点：**「头指针」与「头结点」是两回事。**头指针**是链表的名字，指向链表第一个结点，任何链表都有头指针；**头结点**是带头结点的链表里，位于第一个元素结点之前的一个**实际存在**的结点，可有可无。二者的名字只差一个字，含义完全不同。

带头结点有什么好处？最直接的一条：**在表头插入、删除时，代码不用特判「是不是第一个」**。不带头结点时，在位置 1 插入要改的是头指针本身；带头结点后，头指针永远指向头结点、永远不变，插入删除统一按「在某结点之后操作」处理。这份「用哨兵统一边界」的思想，在后面的循环链表、双向链表、乃至操作系统与数据库的工程实现里反复出现。<span class="marginnote">哨兵思想不只在链表里：数组里给循环队列留一个空位、字符串末尾的 `'\0'`、二分查找里的左右开区间，都是「用哨兵/边界约定消除特判」。这是程序员「减少分支」的重要心法。</span>

## 3 插入与删除：指针操作的两步与三步

链表最核心的功夫是**改指针**。先看最简单的情形：在结点 `p` 的**后面**插入一个新结点 `s`。只要两条语句：

```c
s->next = p->next;   /* ① 先连：s 接上 p 原来的后继 */
p->next = s;         /* ② 后断：p 的后继改为 s */
```

**注意顺序：必须先①后②。** 如果先执行②，那 `p` 原来的后继（`s` 要接的那一段）就「丢」了，无法再找回。<span class="marginnote">先连后断：先把新结点与后继接上（s 的 next 保存了那一段链），再切断 p 指向新结点。断链之后链上没有任何结点丢失——这是所有指针操作必须遵守的纪律。</span>

删除结点 `p` 的后继 `q` 更简单，一条语句绕过它：

```c
q = p->next;        /* 暂存待删结点 */
p->next = q->next;  /* 绕过 q，把 q 摘出链 */
free(q);            /* 释放 q */
```

**辨析｜易错点：** `free(q)` 之后，`q` 成了一个**悬垂指针（dangling pointer）**——它仍保存着那块已被释放的地址，但内容已不可用。若之后误用 `q` 或重复 `free(q)`，轻则读到脏数据，重则段错误。**先断开，再释放；释放后不再碰它**，是链表内存管理的铁律。

## 4 按位插入：为何要「找前驱」

真正的按位插入要插在**位序 $i$** 之前，而不是某个已知结点之后。麻烦在于：单链表只存了「后继」的指针，没有「前驱」——想在第 $i$ 个位置之前插入，就必须找到第 $i-1$ 个结点。因此整个操作分两步：**先找，再插**。

```c
Status ListInsert(LinkList &L, int i, ElemType e) {
    LNode *p = L;  int j = 0;
    while (p && j < i - 1) { p = p->next; j++; }   /* 找第 i-1 个结点 */
    if (!p || j > i - 1) return ERROR;             /* i 越界 */
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;  p->next = s;               /* 在第 i-1 个结点后插入 */
    return OK;
}
```

**找**要 $O(i)$——从表头一路 `p = p->next` 走过来；**插**本身只要 $O(1)$——两句指针赋值。若插入位置等概率取 $1 \sim n+1$，平均查找次数为 $\dfrac{n}{2}$，所以按位插入的整体复杂度仍是 $O(n)$。

这里藏着链表与顺序表最微妙的差别：**给定「指针位置」的操作是 $O(1)$ 的，给定「位序」的操作是 $O(n)$ 的。** 顺序表恰恰相反——给定位序它 $O(1)$ 定位，但改值要 $O(n)$ 搬移。数据结构没有绝对优劣，只有「你的应用以哪种访问为主」。<span class="marginnote">这正是后文「线性表的应用」里反复权衡的主题：频繁在<strong>已知位置</strong>增删（如文本编辑器、LRU 缓存）选链表；频繁<strong>按下标</strong>读取（如二分查找、矩阵运算）选顺序表。工程上没有银弹，只有匹配。</span>

## 5 公式解析：为什么「已知位置」与「给定位序」差一个量级

把上一节的关键结论写成一条公式，它会非常醒目。设表长为 $n$：

$$
\begin{aligned}
\text{已知结点 } p \text{，在其后插入：} & \quad T = O(1) \\[2pt]
\text{给定位序 } i \text{，在其前插入：} & \quad T = O(i) + O(1) = O(n)
\end{aligned}
$$

三步拆解：

- **第一步，看第一个 $O(1)$**：插入本身是两句赋值（`s->next = p->next; p->next = s`），不随表长变化——这就是「指针的自由」：只要拿到了前驱，插入在哪都只需要两步。
- **第二步，看 $O(i)$ 从哪来**：`p = p->next` 每循环一次前进一个结点，共 $i-1$ 步。单链表只有一个方向的指针，**找前驱必须从头走**。
- **第三步，看量级的跳跃**：$O(1)$ 与 $O(n)$ 是跨量级的天壤之别。链表把「操作」变便宜了，却把「定位」变贵了——它把顺序表的代价从「搬」转移到了「走」。

这条公式是理解一切「指针结构」的钥匙：**链式结构赢在改结构（增删）只要局部操作，输在找位置（查询）要全局遍历。** 后面学双向链表时你会发现，加一根「前驱指针」正是为了把「找前驱」也变成 $O(1)$。

## 6 小结

- **单链表**：结点 = 数据域 + 指针域，逻辑相邻 ≠ 物理相邻；用头指针定位整表，`NULL` 标记链尾。
- **头指针 vs 头结点**：头指针是链表的标识，头结点是表头前的哨兵结点；带头结点可统一插入删除的边界特判。
- **插入两步走**：先 `s->next = p->next` 再 `p->next = s`，**先连后断**，顺序不能反。
- **删除要防悬垂**：先断开再 `free(q)`，释放后不再碰 `q`。
- **复杂度镜像**：已知位置增删 $O(1)$，给定位序增删 $O(n)$（主要花在找前驱）；与顺序表「读快写慢」正好互补。
- 链表是「用空间换时间」的第一次系统实践：每个结点多存一个指针，换来局部修改的自由。
