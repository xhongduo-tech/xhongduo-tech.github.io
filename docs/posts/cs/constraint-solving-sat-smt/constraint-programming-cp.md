## 为什么在 SAT/SMT 之后讲 CP

前七篇我们一直在「逻辑求解」的谱系里打转：把问题编码成布尔公式或理论约束，交给 CDCL 或 DPLL(T)。但工程世界还有另一大求解传统——**约束规划（Constraint Programming，CP）**：它不把问题编码成布尔，而是**直接用「变量 + 值域 + 约束」的语言建模**，用「传播」与「搜索」来求解。<span class="marginnote">CP 与 SAT/SMT 共享同一个祖先：回溯搜索与传播。区别在粒度——SAT 的传播对象是「子句」，CP 的传播对象是「全局约束」；SAT 以完备的 CNF 语义取胜，CP 以丰富的领域建模能力见长。两者自 2010 年代起迅速融合，OR-Tools 的 CP-SAT 求解器正是融合的产物。</span>

CP 的语言很贴近问题本身：排课就是「每节课安排时间与教室」、调度就是「每个任务安排开始时间」。这种「贴近自然建模」的能力，是 CP 在排程、排课、排班、布局等工业场景经久不衰的根本原因。

## 1 约束满足问题与回溯搜索

CP 求解的问题叫**约束满足问题（Constraint Satisfaction Problem，CSP）**，由三部分组成：

- **变量集**：如 $\{X_1, X_2, \dots, X_n\}$。
- **值域**：每个变量 $X_i$ 的可取集合 $D_i$。
- **约束集**：变量间必须满足的关系，如 $X_1 + X_2 \le 5$、$X_1 \neq X_2$、`alldifferent`。

**CSP 求解**就是找一个对每个变量的赋值，使所有约束成立。基础算法是**回溯搜索**——依次给变量赋值、检查约束、冲突则回溯——这与 DPLL 如出一辙，只是变量域可能是整数、枚举而非布尔。<span class="marginnote">正是这个「回溯 + 传播」的共同骨架，让 CP 与 SAT 在理论上可以互相归约：布尔 CSP 就是 SAT；有限值域 CSP 总能编码成 SAT。Kroening & Strichman 第 2 章专门讨论了 SAT 与 CSP 的这种联系。</span>

## 2 传播器与弧一致性

CP 区别于朴素回溯的威力，在于**传播（propagation）**：每个约束都配一个**传播器（propagator）**，它不断从值域中删除「不可能出现在任何解中的值」，缩小搜索空间。

最强的传播强度是**弧一致性（arc consistency）**：对约束 $C$，若值域中某个值 $a$ 无论其它变量怎么取都无法与 $C$ 兼容，就删掉它。最经典的算法是 **AC-3**（Mackworth 1977）：

```
队列 ← 所有约束
while 队列非空:
  取约束 C，检查并删除 C 中变量的不兼容值
  若某变量值域变小，则把所有涉及该变量的约束重新入队
```

AC-3 以多项式时间达到弧一致性，是 CP 传播的理论基准。实践中传播器会针对具体约束做专用推理——这引向 CP 最有特色的发明：**全局约束**。

## 3 全局约束：把领域知识装进约束

**全局约束（global constraint）** 是一族「表达整类关系」的高级约束，最著名的是 `alldifferent`：

$$
\text{alldifferent}(X_1, X_2, \dots, X_n) \iff \forall i \neq j:\; X_i \neq X_j
$$

`alldifferent` 的传播器不必对 $\binom{n}{2}$ 对变量两两做不等式传播——它可以用**图论**（二分图匹配 / Hall 定理）一次性推出：若某些变量的并集值域小于变量个数，则必有无解子集，可立刻剪枝。<span class="marginnote">`alldifferent` 只是冰山一角：`cumulative`（累计资源调度）、`global cardinality`、`regular`（正则语言约束）、`table`（元组表约束）等全局约束构成了 CP 的「领域知识库」。一个排课问题用 `alldifferent` + `cumulative` 建出的模型，比手写布尔编码紧凑几个数量级。</span>

正是这种「把数学结构封装进约束、让传播器做专用推理」的思路，让 CP 在组合优化问题（尤其调度、排程、布局）上拥有超过朴素 SAT 编码的建模优势。

## 4 公式解析：alldifferent 的匹配式传播

看 `alldifferent` 传播器如何用图论剪枝。设三个变量值域为：

$$
X_1 \in \{1,2\},\quad X_2 \in \{1,2\},\quad X_3 \in \{1,2,3\}
$$

**逐步拆解**：第一步，构造二分图：左节点是变量，右节点是值，连边表示「该值在该变量值域中」。第二步，检查 Hall 条件：变量子集 $\{X_1, X_2\}$ 的邻居值集是 $\{1,2\}$，大小恰为 2，可匹配。第三步，观察整体：3 个变量要取互不相同的值，至少需要 3 个不同的值，而值域 $\{1,2\}$ 只有 2 个——但 $X_3$ 还有值 3。第四步，关键传播：若 $X_1, X_2$ 占用了 1 和 2，则 $X_3$ 唯一可取 3；更妙的是，若将来 $X_1$ 被赋为 1，传播器立即知道 $X_2$ 只能取 2、$X_3$ 只能取 3——整套推理通过一次匹配完成，无需逐对枚举。

这正是 CP 与「把约束摊平编码」的本质区别：`alldifferent` 用一个匹配算法表达了 $\binom{n}{2}$ 个二元不等式的联合语义。

## 5 CP 与 SAT/SMT 的融合时代

2010 年代起，CP 与 SAT/SMT 的边界迅速模糊，出现「杂交求解器」：

| 融合方向 | 代表 | 思路 |
| --- | --- | --- |
| CP 引擎引入 SAT 技术 | OR-Tools CP-SAT | 用 CDCL 的冲突学习替换朴素回溯 |
| SAT 编码全局约束 | `table` → 编码 | 用位向量编码全局约束，交给 CDCL |
| 惰性分解 | CP → SAT on demand | 先传播，必要时才把约束编译成子句 |
| SMT 与 CP 结合 | CP-SMT | 传播器充当理论求解器，融入 DPLL(T) |

其中最著名的当属 Google 的 **OR-Tools CP-SAT**：它名义上叫 CP，内核却是 CDCL + 位向量编码 + 惰性子句生成——本质上是「SAT 求解器 + 全局约束库」的合体，并在 2018 年后成为组合优化领域的超级明星。这证明了一个判断：**「传播」与「冲突学习」并非竞争范式，而是可以相互增益的两件武器**。<span class="marginnote">对想深入源码的读者，OR-Tools 的 CP-SAT 求解器与 Z3 各代表了「融合」的两种方向：前者从 CP 出发拥抱 SAT 技术，后者从 SAT 出发拥抱理论推理。二者殊途同归，正是本专题全部内容的当代交汇。</span>

## 6 小结

- **CP** 用「变量 + 值域 + 约束」直接建模，靠**回溯搜索 + 传播**求解，贴近工程问题的自然表述。
- **传播器**不断删除值域中不可能的值；**弧一致性（AC-3）** 是传播强度的理论基准。
- **全局约束**（`alldifferent`、`cumulative`）把领域知识封装进约束，用专用推理实现指数级剪枝。
- CP 与 SAT/SMT 共享「回溯 + 传播」的祖先，2010 年代后迅速融合。
- **OR-Tools CP-SAT** 证明「传播」与「冲突学习」可以互相增益，是当代融合的标杆。
