## 为什么从交互范式与 3D UI 开始

《跟踪与位姿估计》解决了「系统知道你在哪」，这一节解决「你怎么命令系统」。在 GUI 里，交互是成熟的（点击、拖拽、菜单）；但到了 VR，**一切熟悉的东西都要推倒重来**——没有鼠标光标，没有二维窗口，你的手、眼、身体本身就是输入设备。<span class="marginnote">《人机交互》专题里 Norman 的「心智模型 / 反馈 / 约束」原则在这里依然成立，但载体从「屏幕上的控件」变成了「空间里的动作」。3D UI 不是把菜单浮在空气里就算完，而是重新发明「点击」这件事。</span>这一节讲清 3D 交互的两大流派、三类输入通道，以及那条统治着「指向有多快」的著名定律——Fitts 定律。

这一节也是理解「为什么有些 VR 应用好玩、有些是体力活」的分水岭：交互设计得好，用户忘记设备的存在、只沉浸在任务里；设计得差，用户被姿势、误触、找不到入口反复打断。**交互是存在感的最后一块拼图**——显示与跟踪解决了「世界像不像」，交互解决「世界好不好相处」。

## 1 直接操纵与间接操纵

3D 交互的第一分叉，是**谁在驱动交互**：

**直接操纵（direct manipulation）**：用你的手直接「碰到」虚拟物体——伸手抓住、握住、旋转。它的存在感最强，因为与本体的感觉（《人类感知系统》的视觉主导）完全一致：你看到手在动，手也真的在动。<span class="marginnote">直接操纵的代价是<strong>可达性</strong>：虚拟世界里的物体可能在 20 米外，你不可能走过去摸。这引出了「拉伸手臂」的奇技淫巧——Go-Go 技术让虚拟手臂按「真实距离的平方」伸长，够到远处物体。</span>

**间接操纵（indirect manipulation）**：通过射线、光标、控制器等中介去「遥控」物体。典型是**射线指向（raycasting）**——从手柄射出一条激光，末端光圈落在目标上，扳机选中。<span class="marginnote">间接操纵与 GUI 的鼠标哲学同构：用「指示器 + 确认」代替「伸手」。它的存在感弱，但精确、不费力——在 Fitts 定律一节我们会看到，它对远目标的效率甚至反超直接操纵。</span>

两者的分界并不绝对：**HOMER 技术**先用射线锁定目标，再把手「瞬移」到目标旁边完成后续抓握——把两种范式的优点拼在一起。设计者真正要权衡的，是「存在感」与「效率」这对矛盾在具体任务里谁更重要。

**操纵（manipulation）**还包括物体的旋转与缩放。真实世界里「拿起来转一转看看背面」是一个连续动作，VR 里却常常要拆成「抓握 + 双手比划 + 缩放命令」几段。研究者的经验是：**旋转最好用「双手」完成**——两只手柄各抓一端，像转动一个真实物体，双手动作最符合人对三维物体的直觉；单手柄的旋转命令（如按键转向）则效率低且容易误触。这一切都在验证一个朴素原则：**交互保真度越高，认知负担越低**。

## 2 三类输入通道：手、眼、语音

**手**是最自然的通道。2020 年前后，inside-out 头显（Quest）用视觉手部跟踪把「裸手交互」变成默认选项：手势张开/捏合对应抓取与释放。手部交互的瓶颈在**疲劳**——手臂悬空保持动作会迅速酸疼，这就是著名的**大猩猩手臂问题（gorilla arm）**：交互设计师必须让常用操作落在「自然垂下/微举」的舒适区内，否则用户五分钟就累了。<span class="marginnote">Jerald《The VR Book》把「beware of sickness and fatigue」列为交互概念的一条铁律：再好的交互设计，只要让用户累或晕，就是失败的。舒适的交互区大约在手肘以下、肩膀前方的「易到达半球」内。</span>

**眼**是第二通道。**注视点选择（gaze selection）**让用户「看着目标，停留片刻（dwell）」即可触发——免手、极快，但有两个问题：眼动不可控（无意的一瞥可能误触）与「注视 + 确认」的延迟感。2024 年后，**眼动 + 手势捏合**（Vision Pro 的「看一眼 + 捏一下」）成为主流：眼睛负责指向，手负责确认，两个最快的人体器官分工协作。

**语音**是第三通道。命令式（「打开设置」）、查询式（「天气如何」）与多轮对话式（大语言模型驱动的 AI 助手）逐渐进入 XR。语音的优势是免手免眼，但受环境噪声、口音、公共场合羞耻感限制——它最适合作为「快捷命令」的补充，而不是主通道。

**多模态（multimodal）交互**的价值在于：把三条通道**组合**起来，让每个动作都挑最合适的器官完成。Jerald《The VR Book》把这叫「multimodal interaction」原则：例如「看着一个物体（眼）+ 说『放大』（语音）+ 手势捏合（手）」——眼睛负责指认，语音负责命令，手负责精修。多模态不是「三个通道各做一个动作」，而是「一个动作由三个通道协同完成」，这让交互既快又不累，也是《人类感知系统》里「多模态一致」原则在交互侧的回声。

**参照系（reference frame）**也决定了交互的成败：**以身体为中心（egocentric）**的交互（「把物体移到我自己面前」）符合人的直觉，但要占用真实空间；**以世界为中心（exocentric）**的交互（「把物体移到房间东墙」）更适合大场景布置，却需要用户脑内做一次坐标换算。Jerald 提醒：**同一应用内不要混用太多参照系**——用户每次「坐标系切换」都要重新建立空间心智模型，比点错按钮更伤。

## 3 指向与选择：3D 的「点击」

把「选中一个目标」这件 GUI 里最简单的事搬到 3D，会出现一个独特的难题：**目标在三维空间里层层叠叠**——近处的箱子挡住远处的箱子，你「点」的到底是谁？于是产生了多种选择策略：

**射线（raycast）**：沿手柄方向发射射线，取「第一个碰到的物体」。简单直观，但有著名的**射程抖动**问题：射线越长，末端的光标抖动越剧烈，远目标越难稳定选中。

射程抖动其实是一个几何现象：手柄角度上的一个微小抖动 $\delta\theta$，在距离 $D$ 处表现为 $\delta\theta \times D$ 的线性位移——**距离翻倍，抖动翻倍**。对策有两条：一是「角度锁定」辅助——当射线末端接近目标时，系统降低灵敏度（像磁性吸附）；二是改用**锥形光圈**，让命中判定不再依赖「射线的终点精确落点」。

**锥形光圈（aperture）**：把射线换成「从手柄发出的锥形光束」，命中「锥内所有物体里最近的那个」——比纯射线更容易击中小目标，但会牺牲精确。

**虚拟手（virtual hand）**：直接把手伸进场景摸到目标，等价于 1:1 的直接操纵——存在感最高，但受手臂长度限制。

**图像平面（image-plane）**：把 3D 场景「拍扁」成屏幕上的 2D 图像，在 2D 上选点再反投影回 3D——相当于给 3D 套了一层「屏幕选择」，适合密集小目标（如一排按钮）。

LaValle《Virtual Reality》第 10 章把这些统一收进「选择与操纵」的框架，并强调一个残酷事实：**没有任何单一策略在所有任务上都最优**——远距离选大目标用射线，近距离抓取用虚拟手，密集小目标用图像平面。好的 VR 产品，通常是几种策略的「按需切换」。

| 策略 | 原理 | 优势 | 劣势 |
| --- | --- | --- | --- |
| 射线（raycast） | 手柄方向射线命中最近物 | 远距、直观 | 远目标抖动 |
| 锥形光圈（aperture） | 锥形光束选「锥内最近」 | 易击小目标 | 精度略降 |
| 虚拟手（virtual hand） | 手 1:1 触碰 | 存在感强 | 受臂长限制 |
| 图像平面（image-plane） | 2D 投影选点反投影 | 密集小目标 | 抽象、需校准 |

**注视点选择（gaze）**虽不在上表，却是「免手」场景的主力：盯住目标停留（dwell）或配合语音确认。它的极端形态是**眼动 + 捏合**——眼睛定位、手指确认，成为 2024 年后 MR 设备（Vision Pro）的招牌交互。

还有一个常被忽略的细节：**头显的姿态跟踪精度，直接影响选择手感**。射线指向的末端抖动、虚拟手的抓握判定，全都建立在《跟踪与位姿估计》输出的位姿之上——跟踪的毫米级抖动，经过射线的距离放大，就是选择时的「瞄不准」。交互设计者永远要记得：你的输入质量，被上游的跟踪质量锁死了。

## 4 公式解析：Fitts 定律

Fitts 定律（1954）是人与计算机交互里少数几条「定量」定律，它预测**移动到目标的时间**：

$$
MT = a + b \cdot \log_2\!\left(\frac{A}{W} + 1\right)
$$

$MT$（movement time）是移动到目标所需时间，$A$（amplitude）是移动距离，$W$（width）是目标宽度，$a,b$ 是经验常数。拆解三步：

- **第一步，读懂核心比例**：$\log_2(A/W+1)$ 叫**难度指数（index of difficulty, ID）**——目标越远（$A$ 大）、越小（$W$ 小），ID 越大，操作越难。
- **第二步，为什么是对数**：距离翻倍只让时间增加一个常数，目标缩小一半同样只加一个常数——这反映人眼的「对数式」运动控制。把 $A$ 换成**角距离**、$W$ 换成**角宽度**，就得到 **3D 中的 Fitts 定律**，用来预测「用射线指向多远的目标要多快」。
- **第三步，VR 的推论**：想让选择更快，要么让目标更大（增大 $W$）、要么把目标「放近」用户的交互区（减小 $A$）。这就是为什么**射线指向在大屏幕上比实际伸手更快**——它的 $A$ 是「手的一个小角度」，而 $W$ 被放大成屏幕上的大目标。Mine、Brooks 与 Séquin 在 1997 年的研究中测出：在同等条件下，**射线指向通常显著快于虚拟手直接操纵**——因为它压缩了移动距离。

Fitts 定律还给 3D UI 一个明确的度量工具：**把「选中时间」当指标，对比不同交互方案**，比主观「感觉好不好用」可靠得多——这与《人机交互》里用任务完成时间测可用性的思路一脉相承。

算例能让人立刻get到「对数」的威力。设经验常数 $a=0.1\text{s}$、$b=0.2\text{s}$，目标宽 $W=0.2$ 米。目标在 1 米外（$A=1$）：$MT = 0.1 + 0.2\log_2(1/0.2+1) \approx 0.1+0.2\times2.58 \approx 0.62\text{s}$；目标移到 4 米外（$A=4$）：$MT \approx 0.1+0.2\times4.39 \approx 0.98\text{s}$。距离变成 4 倍，时间只增约 0.36 秒——这就是对数曲线的「边际递减」。反过来，把目标宽度从 0.2 米缩到 0.05 米，$MT$ 从 0.62 秒跳到约 1.02 秒——**目标缩小远比目标远离更伤效率**，所以「把虚拟按钮做得大一点」几乎是性价比最高的优化。

## 5 3D UI 设计原则：从交互到界面

把交互通道与选择策略组合成界面，还需要几条经验原则：

**保持一致性**：抓取、旋转、缩放的映射必须跨场景统一，否则用户的心智模型反复重建——这正是 Jerald 强调的「interaction fidelity」（交互保真度）与参考系一致性。

**避免疲劳与晕动**：大猩猩手臂、不必要的头动、强制旋转都要避免；界面元素尽量固定在用户视野中心附近的舒适区。<span class="marginnote">「界面跟着头走」（把菜单钉在视野角落、转头即见）是消费级 VR 的默认做法，但它也会削弱空间沉浸感——「世界固定 vs 界面跟手」是需要权衡的一对矛盾。</span>

**反馈要即时且多模态**：点击的视觉高亮、抓取的力反馈、捏合的手势确认——反馈越早、越立体，用户越安心。GUI 的「按钮按下变灰」在 VR 里要变成「物体微微发光 + 手柄震动 + 声音轻响」的合成反馈。

**界面要「空间化」而非「贴图化」**：把 2D 菜单硬塞进 3D 世界（「3D 里贴一张网页」）是最常见的偷懒，也是最常见的失败——用户必须转头、伸手、对焦才能看菜单。优秀的 3D UI 让菜单融入场景（全息面板、桌面投影），让交互发生在「物体身上」而不是「屏幕里」。

**模式与流程（modes and flow）**：3D 世界没有「窗口失焦」这回事，模式切换必须显式且可逆。例如「编辑模式 / 浏览模式」用长按手柄键切换，切换时给出明确的视觉状态（物体边缘高亮 = 可编辑）。Jerald 提醒：**每次「猜错了模式」都是一次心智打击**——用户会反复确认「我到底在什么模式」，比 2D 界面的「模态困境」更伤体验，因为 VR 里没有菜单栏可以瞄一眼。

**反馈的「距离」也很重要**：选择反馈应在**手指按下那一刻**给出（视觉高亮 + 音效 + 震动），而不是等「松开确认」——人的手在悬停时就开始预期结果，反馈晚了 100 毫秒都会感觉「粘」。把反馈拆成「预反馈（hover highlight）→ 激活反馈（按下闪光）→ 完成反馈（动画收尾）」三拍，是 3D UI 设计的成熟套路。

## 6 小结

- 3D 交互分**直接操纵**（伸手摸）与**间接操纵**（射线遥控），HOMER 等混合技术兼取两者。
- 三类输入通道：**手**（自然但易疲劳）、**眼**（快但不可控）、**语音**（免手但受环境限制）。
- 选择策略各有适用域：**射线 / 锥形光圈 / 虚拟手 / 图像平面**，好产品按需切换。
- **Fitts 定律** $MT = a + b\log_2(A/W+1)$ 定量预测指向时间，射线指向靠「压缩距离、放大目标」赢过直接操纵。
- 3D UI 五原则：**一致性、防疲劳、即时多模态反馈、空间化而非贴图化**。
- 射程抖动随距离线性放大，可用**角度锁定 / 锥形光圈**缓解；目标大小对效率的影响远超目标距离。
- **多模态**让眼/手/语音协同完成一个动作；**参照系**与**模式切换**要少而明确，避免心智模型反复重建。
- 反馈要拆成**预反馈 → 激活反馈 → 完成反馈**三拍，任何一拍迟到都会让交互「发粘」。
- 交互手感被上游**跟踪精度**锁死——射线的抖动是跟踪抖动的距离放大。

在下一节，我们将处理 3D 交互最大的敌人——**移动与导航技术**：瞬移、重定向行走与晕动症，看人如何在虚拟世界里「走过去」而不晕倒。
