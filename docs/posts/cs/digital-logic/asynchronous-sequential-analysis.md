## 为什么从异步时序分析开始

同步电路有统一时钟，「所有触发器一起走」；异步电路没有统一时钟，状态靠**事件触发逐级传播**——一个触发器的输出变化，可能触发下一个触发器。异步电路速度快、结构灵活，但分析复杂、易出竞争问题。<span class="marginnote">典型的异步时序电路就是<strong>异步计数器（行波计数器）</strong>：最低位触发器直接接时钟，高位的时钟来自低位的输出——进位信号像「多米诺骨牌」一样逐级倒下。分析它必须「逐级跟踪边沿」。</span>这一节讲异步电路的分析要点，并以异步二进制计数器为例。

## 1 异步电路的特点与分析难点

与同步相比，异步时序电路有四个显著特点：

1. **触发器时钟不同源**：各触发器的 $CP$ 由不同信号驱动（如低位输出）。
2. **状态传播逐级**：输入变化像「涟漪」一样沿触发器链传播，需要时间。
3. **时序依赖实际延迟**：分析必须考虑触发器的传输延迟，不能假设「同时更新」。
4. **易产生竞争与毛刺**：逐级传播中，中间状态可能出现短暂错误。

**分析难点**：不能用「统一时钟」的简化，必须**逐个触发器跟踪时钟边沿**——先看谁先变，再看谁被它触发。<span class="marginnote">异步分析的本质是<strong>「因果链分析」</strong>：一次外部事件 → 第一个触发器翻转 → 其输出沿触发第二个 → 依次传播。分析时要沿着这条因果链逐级推进，每一步都问「谁的时钟沿到了、此刻它的输入是什么」。</span>

**辨析｜易错点：** 异步电路分析最易犯的错是「假设同步」——把高位的更新时间算成与低位同时。实际上高位要**晚**低位一个传输延迟（$t_{pd}$）才翻转。做题或看波形时，高位边沿永远比低位「迟到」一点。

## 2 例题：异步二进制加法计数器

分析一个 3 位异步二进制加法计数器：$Q_0$ 的时钟直接接外部 $CP$，$Q_1$ 的时钟接 $\overline{Q_0}$，$Q_2$ 的时钟接 $\overline{Q_1}$，三个触发器都是 T'（每沿翻转）或 JK 接 $J=K=1$。

**计数机制**：

$Q_0$：每个外部 $CP$ 上升沿翻转一次——频率二分频。
$Q_1$：在 $\overline{Q_0}$ 的上升沿（即 $Q_0$ 的**下降沿**）翻转——当 $Q_0$ 从 1 变 0（进位）时翻转。
$Q_2$：在 $Q_1$ 的下降沿翻转——$Q_1$ 进位时。

**验证计数序列**（初态 000）：

| 序号 | $Q_2Q_1Q_0$ |
|---|---|
| 0 | 000 |
| 1 | 001 |
| 2 | 010 |
| 3 | 011 |
| 4 | 100 |
| 5 | 101 |
| 6 | 110 |
| 7 | 111 |
| 8 | 000 |

$000\to001\to\dots\to111\to000$，正是 3 位二进制加计数。<span class="marginnote">关键机制：<strong>「低位下降沿 = 进位」</strong>。$Q_0$ 从 1 变 0 意味着「9 变成 0、要向高位进 1」，用 $\overline{Q_0}$ 的上升沿恰好捕获这个进位。二进制计数的「逢二进一」，被硬件实现成「下降沿触发高位」。</span>

## 3 异步电路的竞争与毛刺

异步电路的**最大风险**是竞争与毛刺，典型例子是异步置数/清零：

计数到某值时用**译码器**检测并产生清零脉冲，但译码器输出可能有毛刺（组合竞争冒险），导致**错误清零**。
逐级传播使各触发器翻转时间不同，中间状态（如 111 转 000 时的中间 011）会短暂出现，若被其他逻辑采样会出错。

**工程对策**：

**同步化**：把异步信号先用同步器（双触发器）同步到本地时钟域。
**同步清零/置数**：计数器清零信号与时钟同步，避免异步毛刺。
**格雷码计数**：在跨时钟域传输计数状态时用格雷码（每次只变一位），把「多位同时变化」变成「单 bit 变化」，规避竞争。<span class="marginnote">格雷码在此大放异彩：<strong>异步 FIFO 的读写指针、多时钟域间的计数状态，都用格雷码编码</strong>——因为「每次只变一位」天然免疫多位竞争。第一篇学的格雷码，在这里兑现了它的价值。</span>

## 4 公式解析：异步计数器的时间关系

异步计数器有明确的时序代价。设每个触发器传输延迟为 $t_{pd}$，3 位计数器：

**第一步，看第一级**：$Q_0$ 在外部 $CP$ 沿后 $t_{pd}$ 翻转。

**第二步，看第二级**：$Q_1$ 要在 $Q_0$ 翻转（其输出沿）后再过 $t_{pd}$ 才翻转——相对外部 $CP$ 延迟 $2t_{pd}$。

**第三步，看第 $n$ 级**：$Q_n$ 相对外部 $CP$ 延迟 $n \cdot t_{pd}$。3 位计数器最高位延迟 $3t_{pd}$。

**第四步，读结论**：**异步计数器的总延迟随位数线性增长**，位数越多越慢。所以：

$$t_{settle} \approx n \cdot t_{pd}$$

- 若要「计数到 $N$ 后立刻采样」，必须等 $n\cdot t_{pd}$ 后信号才稳定。
- 高频应用因此**不用异步计数器**——高位的滞后可能让采样读到「旧值」。<span class="marginnote">这就是为什么现代芯片几乎只用同步计数器：<strong>同步计数器的所有位在同一时钟沿更新，总延迟固定（一位触发器的 $t_{pd}$ 加组合逻辑），与位数无关</strong>。异步计数器只剩低功耗、简单等有限优势。</span>

## 5 异步分析的一般方法

对更一般的异步电路，分析步骤与同步类似但更小心：

1. **确定各触发器的时钟源**：谁接外部时钟，谁接其他触发器的输出。
2. **对每个触发器写状态方程**：但注意，**只有在「自己的时钟边沿到来」的那一瞬**，状态方程才生效；时钟没来，输出保持。
3. **从外部输入出发，沿因果链逐级推进**：每次外部变化，跟踪第一个触发器的翻转，再看它触发谁。
4. **列状态表**：标注「哪个沿触发、什么条件」。
5. **画时序图**：波形图是异步分析的必需工具——逐级画出各触发器，标注传播延迟造成的边沿错位。

<span class="marginnote">异步分析口诀：<strong>「谁的沿来了，谁才动；沿没来，保持不动」</strong>。每个触发器像一扇独立的小门，被自己的时钟沿敲响时才开门。这正是异步与同步最本质的差别——同步是「一起走」，异步是「推着走」。</span>

## 6 异步时序的现代应用：异步 FIFO 与跨时钟域

「异步时序」在现代设计中并未消失，它以更精确的形式存在于跨时钟域（CDC）场景。

**异步 FIFO**：两个时钟域（如读时钟与写时钟不同）之间的数据缓冲。核心难点：

- 读写指针分别在自己的时钟域递增。
- 判断「满/空」要比较两个时钟域的指针——直接比较会因采样不同步而误判。

**格雷码指针**：异步 FIFO 的指针用**格雷码**编码——相邻计数只变一位，采样时最多一位不确定，配合两级同步器把误判概率压到极低。这是「每次只变一位」思想（约翰逊计数器、格雷码）的经典应用。

**两级同步器**：跨时钟域的单个信号，先经过两级触发器同步——第一级可能亚稳态，第二级「重新采样」让亚稳态概率指数下降。这是应对亚稳态（第五篇）的标准电路。

**同步器与亚稳态概率**：两级同步器的亚稳态失效率 ≈（第一级失效率）×（建立时间裕量比例）——指数级下降。工程上用「两级起步，必要时三级」。

**为什么现代设计避不开 CDC**：SoC 里多个时钟域（CPU、外设、总线）必然交汇——跨时钟信号的处理是「异步时序思想」最活跃的现代应用。理解异步分析的「逐级传播」，就理解了 CDC 的难点（采样不确定）与对策（同步器 + 格雷码）。

**辨析｜易错点：** 异步 FIFO 的「满/空」判断有「保守性」——宁可「假满」不可「真满漏判」。设计时用「格雷码 + 同步 + 安全裕量」，而不是追求「精确满空」——安全优先于精确，是 CDC 设计的原则。

## 7 小结

- 异步时序电路无统一时钟，状态靠**事件逐级传播**；典型代表是异步计数器。
- 异步二进制加计数：低位下降沿触发高位，实现「逢二进一」。
- 异步电路易出**竞争与毛刺**：译码毛刺、中间状态、多位竞争，需同步化、同步清零、格雷码应对。
- 异步计数器总延迟 $n\cdot t_{pd}$ 随位数线性增长，高速场合不如同步。
- 分析口诀：谁的沿来谁才动，逐级跟踪因果链。
