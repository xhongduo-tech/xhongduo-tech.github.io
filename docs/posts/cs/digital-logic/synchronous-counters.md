## 为什么从同步计数器开始

计数器是时序电路里应用最广的模块：计时、分频、寻址、状态编号，处处需要「数数」。上一节我们见过异步计数器，但它的延迟随位数增长；**同步计数器**让所有触发器在同一时钟沿更新，速度快、时序干净，是现代设计的标准。<span class="marginnote">同步计数器的核心洞察：<strong>每个触发器「何时翻转」由组合逻辑统一算出，而不是靠低位输出触发</strong>。用 T 触发器的语言说——「该翻转的位，这一拍全部翻」。</span>这一节从同步二进制加法计数器讲起，再讲减法与加减可逆计数器。

## 1 同步二进制加法计数器的设计

**同步二进制加法计数器**：每个时钟沿，计数值加 1。以 3 位为例，状态序列 $000\to001\to\dots\to111\to000$。

**关键问题：每位何时翻转？** 观察二进制计数：

| 位 | 翻转条件 |
|---|---|
| $Q_0$（最低位） | 每拍都翻 |
| $Q_1$ | $Q_0=1$ 时翻（低位满 1 就进位） |
| $Q_2$ | $Q_1Q_0=11$ 时翻（低两位满 11 进位） |

**规律**：第 $i$ 位在**所有低位都为 1** 时翻转。用 T 触发器实现，T 端输入：

$$T_0 = 1, \qquad T_1 = Q_0, \qquad T_2 = Q_1 Q_0$$

每个触发器只在 $T_i=1$ 时翻转，否则保持。这个「$T$ = 低位全 1」的逻辑就是同步计数器的设计核心。<span class="marginnote">对比异步：异步靠「低位下降沿触发高位」，同步靠「低位全 1 的门控信号让高位同时翻转」。<strong>同步省去了逐级传播的延迟，但多了一组与门</strong>——用面积换速度，正是工程权衡的典型。</span>

## 2 状态方程与实现

用 D 触发器实现同步计数器，需要把「何时翻转」翻译成 D 输入。对 T 触发器 $Q^{n+1} = T\oplus Q^n$，D 触发器实现时：

$$D_i = Q_i^{n+1} = T_i \oplus Q_i$$

即 $D_0 = \overline{Q_0}$（每拍翻），$D_1 = Q_0\oplus Q_1$，$D_2 = Q_1Q_0\oplus Q_2$。电路由异或门与与门组成，全部触发器共享时钟。<span class="marginnote">对比两种实现：<strong>用 T 触发器最直观（$T$=低位全1），用 D 触发器最贴合现代工艺（$D$=次态）</strong>。Verilog 综合器会自动选最优实现，但手工设计时 T 的思路最好懂。</span>

**辨析｜易错点：** 同步计数器的进位**不是**「低位输出接高位时钟」——那是异步。同步的进位是**逻辑信号**（$Q_1Q_0$ 等），参与高位的 $T$ 或 $D$ 输入计算，与时钟无关。看电路图时，认准「所有触发器时钟连同一根线」就是同步。

## 3 同步二进制减法计数器

**减法计数器**：每个时钟沿计数值减 1，序列 $000\to111\to110\to\dots\to001\to000$。

翻转条件对称：第 $i$ 位在**所有低位都为 0** 时翻转（减法的「借位」当低位全 0 时发生）。T 端输入：

$$T_0 = 1, \qquad T_1 = \overline{Q_0}, \qquad T_2 = \overline{Q_1}\,\overline{Q_0}$$

**对比加法**：加法用「低位全 1」，减法用「低位全 0」——进位与借位的对称性，在计数器的门控逻辑里一目了然。<span class="marginnote">加减计数器可以用一个方向控制信号 $U/D$ 选择门控逻辑：$U/D=1$ 时按加法（全 1），$U/D=0$ 时按减法（全 0）。这个「方向信号切换门控」的思路，就是可逆计数器（74LS191/193）的原理。</span>

## 4 公式解析：同步计数器的最高频率

同步计数器的优势在速度上可量化。设每个触发器的 $t_{pd}$ 与每个与门的 $t_{gate}$：

**同步计数器的时钟周期下限**：

$$T_{clk,min} = t_{pd} + t_{gate} + t_{su}$$

**第一步，看路径**：时钟沿触发所有触发器，最慢的 $T_i$ 由「低位全 1」的与门链产生（$n$ 个与门级联），再经过触发器的 $t_{pd}$ 才更新输出。

**第二步，算组合延迟**：$n$ 位计数器的进位门控是 $n$ 级与门，$t_{comb} = (n-1)\cdot t_{gate}$。

**第三步，加建立时间**：与同步分析公式一致，$T_{clk,min} = t_{su} + t_{pd} + (n-1)t_{gate}$。

**第四步，对比异步**：异步计数器 $T_{clk,min} \approx n\cdot t_{pd}$。当 $n$ 大时，同步因 $t_{gate} \ll t_{pd}$ 而显著更快，且可预测。<span class="marginnote">不过同步的进位与门链随位数变长，仍会拖慢速度——于是有了<strong>进位增强技术（carry-lookahead counter）</strong>：像超前进位加法器一样，预计算「低位全 1」，把 $O(n)$ 的与门链压成 $O(\log n)$。这是「进位传播」问题在计数器里的又一次显现。</span>

## 5 计数器与分频

同步计数器最常见的用途之一是**分频**：

3 位计数器从 000 数到 111 需要 8 个时钟，最高位 $Q_2$ 每 8 拍循环一次——**$Q_2$ 是 8 分频**。
一般地，$n$ 位计数器最高位输出频率 $= f_{clk}/2^n$。
而「模 N 计数器」（数到 $N-1$ 就清零）能实现任意整数分频——这正是下一节「任意进制计数器」的内容。

<span class="marginnote">分频器无处不在：<strong>时钟树里把 100 MHz 主频分成 1 MHz 外设时钟、看门狗定时器、心跳计时器</strong>，全是计数器分频。一个「数到 N 就翻转」的计数器，就是最可靠的分频电路。</span>

## 6 可逆计数器与集成计数器

工程上很少从零搭计数器，多用**集成计数器**（如 74LS161）或 IP 核。但理解同步原理，才能用好它们。

**可逆计数器（加/减可控）**：增加方向控制信号 $U/D$：

- $U/D=1$：按加法计数（$T_i = \prod Q_{\\lt i}$）。
- $U/D=0$：按减法计数（$T_i = \prod \overline{Q_{\\lt i}}$）。

**实现**：每个触发器的 $T$ 端用「$U/D$ 选择加/减门控」——这就是 74LS191/193 可逆计数器的内部结构。

**集成计数器的典型功能**（以 74LS161 为例，第十一篇第 6 节已见，这里从计数器视角回顾）：

| 信号 | 功能 |
| --- | --- |
| $\overline{R}$ | 异步清零，立即回 0 |
| $\overline{LD}$ | 同步置数，边沿载入预置值 |
| $ENP, ENT$ | 计数使能，都有效才计数 |
| $TC$ | 计数到 1111 的进位输出 |

**为什么这些功能重要**：清零/置数实现任意模数（置零法/置数法），使能实现「走走停停」，进位实现级联——集成计数器把同步计数的全部要点封装成几个引脚，工程师直接接信号即可。

**Verilog 视角**：在 HDL 里计数器就一行：

```verilog
always @(posedge clk) count <= count + 1'b1;
```

综合器自动生成带进位的同步计数结构——原理仍是「低位全 1 触发翻转」，只是交给了工具。

**辨析｜易错点：** 同步计数器的「同步」指所有位在同一时钟沿更新，与「用不用集成芯片」无关。集成计数器内部若是同步结构，级联时也共享时钟；若是异步（如 74LS90 的部分结构），级联时序就要小心。

## 7 小结

- **同步计数器**：所有触发器共享时钟，翻转条件由组合逻辑统一算出。
- 加法计数翻转条件 = **低位全 1**（$T_i=\prod Q_{\\lt i}$）；减法 = **低位全 0**。
- 用 T 触发器实现最直观，用 D 触发器实现最贴合现代工艺。
- 同步计数器的 $T_{clk,min}=t_{su}+t_{pd}+(n-1)t_{gate}$，优于异步的 $n\cdot t_{pd}$。
- 计数器 = 分频器；$n$ 位计数器最高位输出 $f_{clk}/2^n$。
