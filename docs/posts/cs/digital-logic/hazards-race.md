## 为什么从竞争-冒险开始

前面所有设计都假设「信号瞬间到达、瞬间稳定」——但真实电路有传输延迟，多条路径的延迟不一样。当输入变化时，输出可能在稳定到正确值之前，先冒出几个不该有的**毛刺（glitch）**。这就是**竞争-冒险**。<span class="marginnote">毛刺的危害：如果它被采进触发器（第五篇），就会把「错误瞬间」永久保存下来——<strong>这是数字系统最难排查的「幽灵 bug」之一</strong>：仿真波形上明明正确，实际板子上偶发错误。理解并消除冒险，是可靠数字系统的必修课。</span>这一节讲清竞争与冒险的含义、如何判断、以及三种消除方法。

## 1 竞争与冒险：两个相关概念

**竞争（race）**：当一个门的多个输入同时变化（或一个输入经不同路径、以不同延迟到达）时，各输入到达该门的**时间有先有后**，这种现象叫竞争。

**冒险（hazard）**：由于竞争，电路输出出现了**不符合逻辑功能的瞬时错误**（毛刺）。冒险有静态与动态之分：

**静态冒险**：输出本应保持不变，却瞬时跳到另一值又跳回。**静态 1 冒险**：输出本应为 1，却瞬时跌到 0；**静态 0 冒险**：输出本应为 0，却瞬时冲到 1。
**动态冒险**：输出本应从 0 变 1（或 1 变 0），却在过渡中来回振荡多次。

最常见、最需要消除的是**静态冒险**，尤其是静态 1 冒险（与-或结构电路中常见）。<span class="marginnote">竞争是「原因」（延迟不一致），冒险是「结果」（毛刺）。<strong>有竞争不一定有冒险，冒险必源于竞争</strong>——判断时看输出是否真的出现毛刺。</span>

## 2 典型例：与-或电路的静态 1 冒险

考虑电路 $Y = AB + \overline{A}C$。当 $B=C=1$ 时：

$$Y = A\cdot 1 + \overline{A}\cdot 1 = A + \overline{A} = 1$$

**逻辑上 $Y$ 恒为 1**。但物理上，当 $A$ 从 1 变 0 时：

- $AB$ 路径：$A$ 经与门延迟后变 0，$AB$ 从 1 变 0。
- $\overline{A}C$ 路径：$A$ 要先经过反相器（多一级延迟）再与 $C$ 相与，$\overline{A}C$ 从 0 变 1 会**晚一些**到达。
- 在「$AB$ 已变 0、$\overline{A}C$ 尚未变 1」的瞬间，输出 $Y = 0 + 0 = 0$——**毛刺出现了**。

这就是静态 1 冒险：逻辑上应保持 1 的输出，瞬时跌到了 0。<span class="marginnote">冒险的根源在于 <strong>$A$ 与 $\overline{A}$ 两条路径的延迟不相等</strong>——反相器比普通门多一级延迟，使 $\overline{A}$ 到得比 $A$ 晚。「$A + \overline{A}$」在逻辑上恒 1，在时间上却可能「断档」。</span>

## 3 判断冒险：代数法与卡诺图法

**代数法判断**：把逻辑式写成「出现 $A$ 与 $\overline{A}$ 互补项」的形式，看能否化简出「恒 1 或恒 0 的项」。具体地：

静态 1 冒险判据：$Y$ 在某个输入组合下能化为 $A + \overline{A}$ 形式，则存在静态 1 冒险。
静态 0 冒险判据（或-与结构）：$Y$ 能化为 $A\cdot\overline{A}$ 形式，则存在静态 0 冒险。

**卡诺图法判断**（更直观）：画出 $Y$ 的卡诺图，若存在**两个相邻的 1 格不在同一个圈内**，则当输入在它们之间切换时会产生静态 1 冒险。<span class="marginnote">直觉：相邻 1 格对应「只差一个变量的两个最小项」，它们之间切换时，若没有圈同时覆盖两者，输出就要「临时经过 0 区」，于是冒毛刺。<strong>卡诺图里相邻 1 格之间必须有圈相连</strong>——这是判断冒险的「看图法」。</span>

**辨析｜易错点：** 卡诺图判据只适用于「两个 1 格相邻且未被同一圈覆盖」的情形。若相邻 1 格已在同一圈内，切换时输出有「平滑路径」经过 1 区，不冒险。判断时先检查所有相邻 1 格对，再下结论。

## 4 公式解析：消除冒险的冗余项法

消除静态冒险最经典的方法是**增加冗余圈（冗余项）**，从逻辑上「架一座桥」，让输出在切换期间有路径保持 1。

仍以 $Y = AB + \overline{A}C$ 为例：

**第一步，识别危险相邻对**：卡诺图上，$ABC=111$（$AB$ 圈的格）与 $ABC=011$（$\overline{A}C$ 圈的格）相邻，但不在同一圈——危险对。

**第二步，补冗余项**：这两个格对应的最小项是 $ABC$ 与 $\overline{A}BC$，它们的公共因子是 $BC$。加入冗余项 $BC$：

$$Y = AB + \overline{A}C + BC$$

**第三步，验证**：当 $B=C=1$ 时，$BC=1$，$Y$ 由 $BC$ 一路撑住，不再依赖 $A+\overline{A}$ 的瞬时配合——毛刺消除。

**第四步，逻辑不变性检查**：$AB + \overline{A}C + BC = AB + \overline{A}C$（冗余项 $BC$ 是原式的吸收项，用公式 $AB+\overline{A}C+BC = AB+\overline{A}C$ 反向理解）——功能完全不变。<span class="marginnote">通用方法：<strong>在卡诺图上，凡「相邻 1 格不在同一圈」就补一个圈盖住它们</strong>。每个补圈对应一个冗余项。代价是多用一个与门，但换来毛刺消除——在时序电路里，这个代价几乎总是值得的。</span>

## 5 消除冒险的三种方法对比

| 方法 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| **冗余项法** | 卡诺图补圈 | 纯组合逻辑解决 | 多耗门 |
| **输出滤波（加电容）** | 低通滤掉窄毛刺 | 简单 | 拖慢边沿，只对慢速电路有效 |
| **采样法（时序）** | 用时钟在稳定后采样 | 最彻底 | 需时序设计（第五篇） |

工程上最彻底的方案其实是**第三种**：让毛刺发生在「没人看的时候」——用时钟边沿在信号稳定后才采样，毛刺即使存在也不被采到。这正是时序电路「克服组合冒险」的方式，也是为什么真实系统几乎都是「组合逻辑 + 寄存器」的结构。<span class="marginnote">现代 FPGA 设计里，工具会提示你「组合逻辑过长、时序违例」，但纯组合毛刺很少成为问题——因为寄存器采样天然免疫毛刺。<strong>冗余项法主要在「无时钟的纯组合接口」或「异步信号」场合仍在使用</strong>。</span>

## 6 竞争冒险的仿真观察与工程实践

毛刺在仿真里怎么看到？工程上怎么处理？这里给出实操层面的认识。

**仿真观察毛刺**：组合逻辑的功能仿真（零延迟）看不到毛刺——因为所有信号「同时」变化。要看毛刺，必须用**带延迟的仿真**（门级仿真或时序仿真）。综合后的门级网表仿真里，反相器比与门多一级延迟，$A$ 与 $\overline{A}$ 的到达时间差就显现出来，毛刺在波形上清晰可见。

**消除毛刺的工程顺序**：

1. **首选：寄存器采样**（时序设计）——毛刺发生在边沿前的组合段，触发器只在边沿采样，毛刺被天然忽略。这是现代同步设计的「默认免疫」。
2. **次选：冗余项法**——纯组合接口、无时钟可采样时，在卡诺图上补圈消除冒险。
3. **末选：滤波电容**——只能用于慢速、对边沿不敏感的场合，且会拖慢信号。

**冗余项法的一个代价**：补的冗余项增加了门数与延迟，可能让关键路径变长——所以「先采样、后冗余、再滤波」的顺序是工程经验之谈，不是理论推导。

**真实系统的视角**：现代 ASIC/FPGA 设计中，纯组合毛刺很少成为主要矛盾——因为寄存器采样 + 静态时序分析（STA）已经把时序问题系统性解决了。冗余项法主要存在于：无时钟的异步接口、老式 TTL 电路、以及考试题里。

**辨析｜易错点：** 不要看到任何毛刺就「补冗余项」。先判断毛刺会不会被采进触发器：不会 → 忽略；会 → 先考虑加寄存器/调整采样时机，再考虑冗余项。盲目补圈只会增加面积与延迟。

## 7 竞争冒险的考试与工程要点回顾

竞争冒险是高频考点，也是工程敏感点，把要点收束一遍。

**三类必考题型**：

1. **判断有无冒险**：给逻辑式，找 $A+\overline{A}$ 或 $A\overline{A}$ 结构（代数法），或画卡诺图找「相邻 1 格不在同圈」（图法）。
2. **指出冒险类型**：静态 1（应 1 变 0）、静态 0（应 0 变 1）、动态（翻转中振荡）。
3. **消除冒险**：补冗余项（卡诺图补圈）、加滤波、时钟采样。

**判断步骤口诀**：「**找互补，看相邻，补圈消**」——找互补变量对（$A$ 与 $\overline{A}$），看卡诺图上相邻格是否同圈，不同圈就补冗余项消除。

**工程要点回顾**：

- 纯组合接口的毛刺靠冗余项消除；
- 同步系统靠寄存器采样「天然免疫」；
- 高速设计中毛刺影响通过 STA 与仿真评估，不盲目补圈。

**为什么「冗余项」不是万能**：冗余项只消除「因路径延迟不等」的静态冒险；若毛刺来自更复杂的多变量竞争或动态冒险，冗余项未必够。工程上「采样优先」正是因为它在机制上更彻底。

**从竞争冒险看「逻辑 vs 时序」**：竞争冒险是「逻辑正确但时序不对」的典型——它提醒你：**数字电路的正确性 = 逻辑正确 + 时序正确**。两个维度都过关，电路才可靠。这是全书反复出现的主题。

**辨析｜易错点：** 「有竞争」≠「有冒险」——竞争是普遍现象（路径延迟不可能全等），冒险是「竞争造成可见毛刺」的结果。不要对每个竞争都「补圈」，只处理会造成错误采样的冒险。

## 8 小结

- **竞争** = 信号经不同延迟路径到达，**冒险** = 竞争导致的瞬时毛刺。
- 静态 1 冒险 / 静态 0 冒险按「本应保持 1/0 却瞬时跳变」区分。
- 判断：代数法看 $A+\overline{A}$（或 $A\overline{A}$），卡诺图法看「相邻 1 格不在同一圈」。
- 消除：**冗余项法**（补圈）、输出滤波、时钟采样；时序采样最彻底。
- 冗余项法代价是多一个与门，换来无毛刺的可靠输出。
