## 为什么从同步时序分析开始

组合电路的分析是「从电路到真值表」，时序电路的分析则是「从电路到状态图」——看它的记忆如何演化、输出如何变化。这是读懂计数器、状态机、CPU 控制器的基本功。<span class="marginnote">同步时序分析的产出是一张<strong>状态转换表（次态表）</strong>和一张<strong>状态图</strong>：列出每个状态在每种输入下的次态与输出。有了它们，电路「到底在干什么」就一目了然。</span>这一节把分析流程走一遍，用经典例题（如模计数器）示范。

## 1 分析步骤：六步法

同步时序逻辑电路的分析有标准流程：

1. **写方程**：根据电路写出每个触发器的**驱动方程（激励方程）**（触发器输入端的逻辑式）、**状态方程**（代入特征方程后的次态式）、以及**输出方程**。
2. **列状态表**：把所有状态与输入组合代入状态方程，算出次态与输出，列成状态转换表。
3. **画状态图**：把状态转换表画成状态图（圆圈 = 状态，箭头 = 转移，标注输入/输出）。
4. **画时序图（波形图）**：给定初始状态与输入序列，画出各触发器与输出的波形。
5. **说明功能**：根据状态图与波形，归纳电路的逻辑功能。

<span class="marginnote">第 1 步是分析的「源头」：<strong>驱动方程写错，后面全错</strong>。写驱动方程时顺着信号流：从触发器输入端往回看，逐级推导到外部输入与其他触发器输出。建议写完先代入触发器特征方程化简，再进状态表。</span>

## 2 例题：一个模 4 计数器

分析一个由两个 D 触发器构成的同步电路：设触发器 $Q_1$、$Q_0$，驱动方程 $D_1 = Q_0$、$D_0 = \overline{Q_1}\,\overline{Q_0}$，时钟同步驱动。

**第一步，写状态方程**：D 触发器 $Q^{n+1}=D$，代入得

$$Q_1^{n+1} = Q_0, \qquad Q_0^{n+1} = \overline{Q_1}\overline{Q_0}$$

**第二步，列状态表**：设状态 $Q_1Q_0$，初态 00：

| $Q_1Q_0$ | $Q_1^{n+1}Q_0^{n+1}$ |
|---|---|
| 00 | 01 |
| 01 | 10 |
| 10 | 00 |
| 11 | 00 |

**第三步，画状态图**：$00\to01\to10\to00$，状态 11 也回到 00——**这是一个模 3 计数器**（三个有效状态循环），11 是过渡态（自启动可回到循环）。

**第四步，归纳功能**：电路每 3 个时钟脉冲循环一次，输出 $Q_1Q_0$ 依次为 $00,01,10$——模 3 计数器。<span class="marginnote">注意一个细节：状态 11 虽然不在主循环里，但它能自动回到 00——这就是「<strong>自启动</strong>」性质。设计时序电路时希望所有非法状态都能回到主循环，否则电路可能「卡死」在某个非法状态（第六篇设计方法会专门处理）。</span>

## 3 带输入与输出的电路：完整三方程

再分析一个带外部输入 $X$ 和输出 $Z$ 的电路。设驱动方程：

$$J_1 = X, \quad K_1 = \overline{Q_0}, \quad J_0 = X\overline{Q_1}, \quad K_0 = X, \quad Z = Q_1 Q_0$$

**第一步，写状态方程**（JK：$Q^{n+1}=J\overline{Q^n}+\overline{K}Q^n$）：

$$Q_1^{n+1} = X\overline{Q_1} + Q_0 Q_1, \qquad Q_0^{n+1} = X\overline{Q_1}\overline{Q_0} + \overline{X}Q_0$$

**第二步，列状态表**：对每个状态 $Q_1Q_0$ 与每个输入 $X$，代入算次态与输出 $Z$。

**第三步，画状态图**：把转移标在箭头上（Mealy 型，$X/Z$），或标在圈内（Moore 型，$Z$）。

**第四步，说明功能**：观察状态图，判断是检测器、计数器还是控制器。<span class="marginnote">这一步是「模式识别」：<strong>如果状态按 00→01→10→11 循环且每个时钟加 1，就是计数器；如果输出只在特定输入序列时拉高，就是序列检测器</strong>。练习时多对照状态图与波形图，把「状态循环」和「输出拉高」对应起来。</span>

## 4 公式解析：从驱动方程到状态方程的推导

以 JK 触发器为例演示「驱动 → 状态」的完整推导。设驱动方程 $J=X$、$K=\overline{Q_1}$，求 $Q^{n+1}$：

**第一步，代入 JK 特征方程**：

$$Q^{n+1} = J\overline{Q^n} + \overline{K}Q^n = X\overline{Q^n} + \overline{\overline{Q_1}}\,Q^n$$

**第二步，化简反号**：$\overline{\overline{Q_1}} = Q_1$，得

$$Q^{n+1} = X\overline{Q^n} + Q_1 Q^n$$

**第三步，整理**：把 $Q^n$（即 $Q$）视为变量，$X$、$Q_1$ 是参数，得到次态关于 $Q$ 的表达式。

**第四步，代入验证**：若 $X=1,Q_1=0$，则 $Q^{n+1} = \overline{Q^n}$——翻转；若 $X=0$，则 $Q^{n+1}=Q_1Q^n$——由 $Q_1$ 决定。<span class="marginnote">关键习惯：<strong>状态方程必须显式写出「次态 = 现态的函数」</strong>。分析时先在草稿上把每个触发器的驱动方程抄成「$X$ 和 $Q$ 的函数」，再代入特征方程，不要跳步。</span>

## 5 分析的产物：状态图与波形图

状态图是时序电路分析的「精华交付物」，画法要点：

- **圆圈**表示状态，圈内写状态编码（如 $Q_1Q_0$）与 Moore 输出。
- **箭头**表示转移，箭头上标注「输入/输出」（Mealy）或只标输入（Moore）。
- 每个状态必须有箭头指出（完备性），也要有箭头指入（可达性）。

波形图则展示**时间行为**：从初始状态开始，逐拍画出 $Q_1,Q_0$ 与输出的波形。波形图能直观验证状态表是否正确，也是仿真验证的对照基准。<span class="marginnote">现代视角：<strong>EDA 仿真器输出的就是波形图</strong>——Vivado、ModelSim 里跑时序仿真，看到的正是这些波形。手工分析的状态表，就是「预期波形」的模板。</span>

## 6 时序电路分析的工程意义

手工分析是考试题，但它的能力在工程里同样重要：

**读懂别人设计的电路**：拿到一份 RTL（或原理图），通过「写驱动方程 → 列状态表 → 画状态图」的方法，能快速弄清它在干什么——这是 code review、bug 排查的基本功。

**对照综合结果**：综合器把 HDL 变成门级网表，网表里触发器与组合逻辑交错——用「状态方程分析」的方法，能验证综合结果是否与设计意图一致。

**状态图作为文档**：把一段复杂的时序逻辑画成状态图，比看代码直观得多——状态图是时序设计的「沟通语言」，团队成员靠它对齐设计意图。

**故障定位**：电路不工作时，从输出波形反推状态序列，用状态图对照「该在哪个状态、实际在哪个状态」——快速定位是状态转移错、还是输出逻辑错。

**从分析到设计**：分析是「电路 → 状态图」，设计是「状态图 → 电路」——两者互逆。掌握了分析，设计的一半就学会了（第六篇第 6 节的设计方法就是分析的逆过程）。

**现代工具的视角**：EDA 工具自动做「状态机提取」（从 RTL 提取状态图）与「等价性检查」（综合前后功能一致）——但理解手工方法，才能读懂工具报告、排查工具遗漏的边界情况。

**辨析｜易错点：** 分析时序电路时「状态表」要穷举「状态 × 输入」的所有组合，缺一个输入组合就漏一种转移。列表时按「每个状态、逐个输入」枚举，别跳步——遗漏输入是分析最常见的错误。

## 7 小结

- 同步时序分析**六步法**：写方程 → 列状态表 → 画状态图 → 画波形 → 说明功能。
- 核心方程：**驱动方程 → 状态方程 → 输出方程**，是分析的源头。
- 状态表列出「每个状态 × 每个输入 → 次态 + 输出」；状态图是其图形化。
- **自启动**：非法状态能否回到主循环，是设计质量的重要指标。
- 功能归纳靠模式识别：循环计数 = 计数器，特定序列输出 = 检测器。
