## 为什么从电平触发开始

上一节的 SR 锁存器「随时响应」，这在多级系统中会乱套——多个触发器各自随时变，系统无法协调。解决办法是给锁存器加一扇**时钟门**：只有时钟有效期间才允许输入进入。这就是**电平触发的触发器（锁存器）**。<span class="marginnote">加时钟的本质是「<strong>在输入通路上加一道闸门</strong>」：时钟 $CP=1$ 时闸门开、输入直通（透明）；$CP=0$ 时闸门关、输出锁住。这种「有效电平期间透明」的器件，工程上称为 <strong>锁存器（latch）</strong>，以区别于边沿触发的触发器（flip-flop）。</span>这一节分析同步 SR 触发器与 D 锁存器，并讨论电平触发的致命缺陷——空翻。

## 1 同步 SR 触发器：给 SR 锁存器装时钟门

**同步 SR 触发器（clocked SR flip-flop）**在 SR 锁存器的输入端前加两个与门，时钟 $CP$ 同时控制两个与门：

- $CP=0$：两个与门输出都为 0，等效于给锁存器输入「无效」，输出保持。
- $CP=1$：与门放行，$S$、$R$ 的输入进入锁存器，表现如基本 SR 锁存器。

功能表与基本 SR 锁存器相同，但所有动作被 $CP$ 门控：

| $CP$ | $S$ | $R$ | $Q^{n+1}$ |
|---|---|---|---|
| 0 | × | × | $Q^n$（保持） |
| 1 | 0 | 0 | $Q^n$ |
| 1 | 0 | 1 | 0 |
| 1 | 1 | 0 | 1 |
| 1 | 1 | 1 | 不定（禁止） |

<span class="marginnote">同步的意义：<strong>所有触发器的「动作窗口」被统一到时钟高电平期间</strong>，系统有了共同的时间基准。但注意——仍是电平触发，$CP=1$ 的整个期间都「透明」，输入一变输出就变。</span>

## 2 D 锁存器：解决禁止态

同步 SR 触发器还带着「$S=R=1$ 禁止」的老毛病。**D 锁存器（D latch）**用一个反相器把 $D$ 分成 $S=D$、$R=\overline{D}$，使两个输入永远互补，禁止态天然消失：

- $CP=1$：输出 $Q$ 跟随输入 $D$（透明），$Q^{n+1}=D$。
- $CP=0$：输出保持。

**D 锁存器的特征方程**：

$$Q^{n+1} = D \quad (\text{当 } CP=1)$$

这就是「输入什么、存什么」——D 的来源（Data/Data）。D 锁存器的优点：无禁止态、只有一个数据输入、行为直观。<span class="marginnote">D 锁存器是数据通路的基本元件：<strong>CPU 里的「透明锁存器」在使能期间让数据流过，关闭时锁住当前值</strong>。它在总线暂存、流水线寄存里大量使用。但「透明」也是一把双刃剑——正是它带来了下一节的空翻问题。</span>

## 3 空翻：电平触发的致命缺陷

**空翻（racing / toggling）**：在时钟有效电平期间，若输入多次变化，输出跟着多次翻转，最终状态由最后一次输入决定——触发器在「该保持的时候」没有保持住。

为什么空翻是问题？设想一个计数器：D 锁存器在 $CP=1$ 期间输入 $D$ 因为别的原因抖动了三次，输出就跟着变了三次——但设计者以为它只在时钟边沿更新一次。**输出「失去约束」地乱跳，就破坏了时序纪律**。

空翻的本质：**电平触发把「采样窗口」拉得太长**（整个高电平期间），任何期间内的输入扰动都会被采到。<span class="marginnote">注意「空翻」一词有时特指主从 JK 触发器的竞争现象，但广义上，<strong>一切「电平期间输出失控翻转」都属于空翻家族</strong>。它的消除办法只有一种——把采样窗口压缩成「一瞬间」，即边沿触发。</span>

**辨析｜易错点：** 锁存器（latch）与触发器（flip-flop）在中文教材里常混用，但严格区分是：**锁存器 = 电平触发（透明）；触发器 = 边沿触发（边沿采样）**。看英文数据手册时，`latch` 与 `flip-flop` 的差别一望即知。面试题常问「latch vs flip-flop」的区别，答案就在触发方式上。

## 4 公式解析：D 锁存器为什么能消除禁止态

对比同步 SR 与 D 锁存器的输入逻辑：

**同步 SR 的输入方程**：$S$、$R$ 独立，可以同时为 1 → 禁止态。

**D 锁存器的输入方程**：

$$S = D, \qquad R = \overline{D}$$

**第一步，代回 SR 特征方程**：$Q^{n+1} = S + \overline{R}Q^n = D + \overline{\overline{D}}\,Q^n = D + D Q^n$。

**第二步，化简**：$D + D Q^n = D(1 + Q^n) = D$。

**第三步，验证约束**：$SR = D\cdot\overline{D} = 0$——永远满足 SR 约束，禁止态不可能出现。

**第四步，物理意义**：$D=1$ 时置位（$S=1,R=0$），$D=0$ 时复位（$S=0,R=1$），二者互补永不同时。一个反相器解决了 SR 的全部麻烦。<span class="marginnote">这个「用反相器把两个输入变成互补」的技巧是数字设计的基本功：<strong>只要两个信号必须互斥，就用一个反相器从同一信号派生</strong>。D 锁存器的简洁性正是它统治数据通路的原因。</span>

## 5 D 锁存器与 D 触发器的区别

先预告下一节的主角，用表格把两者的边界划清：

| 对比 | D 锁存器（电平触发） | D 触发器（边沿触发） |
|---|---|---|
| 响应时刻 | $CP=1$ 全程透明 | 只在时钟边沿瞬间 |
| 采样窗口 | 整个高电平 | 边沿前后极短时间 |
| 空翻问题 | 有 | 无 |
| 英文名 | Latch | Flip-Flop |
| 典型用途 | 总线暂存、透明寄存 | 寄存器堆、计数器、状态机 |

<span class="marginnote">一句话：<strong>锁存器「跟着输入走」，触发器「只在边沿取一次」</strong>。现代同步设计几乎只用边沿触发器，因为它的时序可由时钟精确控制——空翻、竞争都被关在「边沿」这扇门外。</span>

## 6 锁存器在工程中的正反两面

锁存器（电平触发）在现代设计里「名声不好」，但它在特定场合仍不可替代——两面都要看清。

**锁存器的「坏名声」**：电平触发期间透明，时序不可控；空翻风险；ASIC 静态时序分析（STA）对锁存器处理复杂。因此现代同步设计**默认禁用锁存器**，Verilog 综合器还把「意外推断锁存器」当警告。

**锁存器仍被使用的场合**：

1. **高速数据暂存**：锁存器比触发器少一个时钟边沿的开销，某些超高速流水线用它「借用时间」（time borrowing）。
2. **异步接口**：跨时钟域握手、异步 FIFO 里，锁存器的透明性反而有用。
3. **模拟采样保持**：S/H 电路的取样开关本质就是锁存行为。
4. **时钟门控**：某些低功耗设计用锁存器做时钟门控，避免毛刺。

**锁存器 vs 触发器的工程取舍**：

| 对比 | 锁存器（电平） | 触发器（边沿） |
| --- | --- | --- |
| 时序可控性 | 差 | 好 |
| 面积/速度 | 小/快 | 大/略慢 |
| STA 友好度 | 差 | 好 |
| 默认选用 | 否 | 是 |

**为什么「默认禁用、特定启用」**：同步设计的纪律性是可靠性的基石——触发器把采样时刻钉死在边沿，一切分析都建立在「边沿同步」上。锁存器是「特例」，只在明确需要它的场合（高速、异步）才用，且要加注释说明。

**辨析｜易错点：** 综合器「推断出锁存器」的警告，99% 是「组合 always 分支不完整」的笔误（第十一篇），不是有意设计。看到警告先修分支，别默认「反正锁存器也能用」。

## 7 小结

- **同步 SR 触发器** = SR 锁存器 + 时钟门；$CP=1$ 时工作、$CP=0$ 时保持。
- **D 锁存器**用反相器把 $S=D$、$R=\overline{D}$ 互补化，消除禁止态；$Q^{n+1}=D$。
- **空翻**：电平触发期间输入多次变化导致输出失控，破坏时序纪律。
- 锁存器（latch）与触发器（flip-flop）的界限 = 电平触发 vs 边沿触发。
- 消除空翻的方向：把采样窗口压缩成边沿——下一节的主从与边沿触发器。

在下一节，我们将看到「边沿」是如何被制造出来的——脉冲触发（主从结构）与边沿触发，让触发器只在瞬间采样。
