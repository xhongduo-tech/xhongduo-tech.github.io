## 为什么从编码器开始

从这一节起，我们进入组合逻辑的「标准零件库」。第一个零件是**编码器**：把 $2^n$ 个输入信号压缩成 $n$ 位二进制输出，完成「很多条线 → 少数几条线」的信息浓缩。<span class="marginnote">编码器的直觉：<strong>键盘上 100 多个键，CPU 不可能接 100 多根线，于是先用编码器压缩成 7~8 位按键码</strong>。信息论里这是最朴素的信源编码——每条输入线携带 1 bit，输出 $n$ 位编码最多区分 $2^n$ 个输入。</span>编码器有两个版本：普通编码器与优先编码器，后者解决了「多个输入同时有效」的歧义，是实际系统的主力。

## 1 普通编码器：二进制的压缩

**普通编码器（encoder）**：有 $2^n$ 个输入、$n$ 个输出，输入是「独热」（one-hot，只有一位为 1），输出是该位的二进制编号。以 8 线-3 线编码器为例：输入 $I_0\sim I_7$，输出 $Y_2Y_1Y_0$。

| 有效输入 | $Y_2$ | $Y_1$ | $Y_0$ |
|---|---|---|---|
| $I_0$ | 0 | 0 | 0 |
| $I_1$ | 0 | 0 | 1 |
| $I_2$ | 0 | 1 | 0 |
| $I_3$ | 0 | 1 | 1 |
| $I_4$ | 1 | 0 | 0 |
| $I_5$ | 1 | 0 | 1 |
| $I_6$ | 1 | 1 | 0 |
| $I_7$ | 1 | 1 | 1 |

输出方程很简单——**哪一位输出为 1，取决于哪些输入的编号在该位含 1**：

$$Y_0 = I_1 + I_3 + I_5 + I_7, \quad Y_1 = I_2 + I_3 + I_6 + I_7, \quad Y_2 = I_4 + I_5 + I_6 + I_7$$

<span class="marginnote">观察规律：$Y_0$ 是「编号最低位为 1 的所有输入之和」，即所有奇数编号输入；$Y_1$ 是编号第二低位为 1 的输入之和。编码器的逻辑式就是「按输出位分组求或」——这是编码器设计的通式。</span>

**辨析｜易错点：** 普通编码器有个隐含假设：**同一时刻只有一个输入有效**。若两个输入同时为 1（比如 $I_3$ 和 $I_5$），输出 $010 + 101$ 会「打架」，产生无意义的混合码。这个缺陷由优先编码器解决。

## 2 优先编码器：谁优先谁说了算

**优先编码器（priority encoder）**：允许多个输入同时有效，但输出**只取编号最大的那一个**——因为给每个输入设定了优先级，高优先级的输入「压制」低优先级输入。

以 74LS148（8 线-3 线优先编码器）为例，它的附加设计值得注意：

- **输入低电平有效**：$I_0\sim I_7$ 中 $I_7$ 优先级最高，$I_0$ 最低。
- **输出也是低电平有效**：$Y_2Y_1Y_0$。
- 附加输出 $Y_S$（片选）与 $Y_{EX}$（扩展端），用于级联多片编码器扩展输入位宽。

**输出方程**（以编号最大有效输入为准）：

$$Y_2 = \overline{I_4 + I_5 + I_6 + I_7}, \quad Y_1 = \overline{I_2\overline{I_4} + I_3\overline{I_4} + I_6 + I_7}, \quad \dots$$

它的本质是：高优先级的输入「使能屏蔽」低优先级输入——$I_4$ 有效时，$I_0\sim I_3$ 全部被忽略。<span class="marginnote">优先编码器在计算机里无处不在：<strong>CPU 的中断控制器（如 8259A）就是按优先级处理多个中断请求</strong>，键盘矩阵扫描、多设备总线仲裁也用它。</span>

## 3 公式解析：优先编码器的「屏蔽」逻辑

以 4 线-2 线优先编码器为例，输入 $I_0$（最低优先级）到 $I_3$（最高优先级），输出 $Y_1Y_0$：

$$Y_1 = I_3 + I_2, \qquad Y_0 = I_3 + \overline{I_2}\,I_1$$

**第一步，看 $Y_1$**：只要 $I_3$ 或 $I_2$ 有效，编号的次高位就是 1——$I_1$、$I_0$ 被完全忽略，因为它们优先级低。

**第二步，看 $Y_0$**：$I_3$ 有效时输出 1；否则若 $I_2$ 有效，输出 0（编号 10）；若 $I_2$ 无效而 $I_1$ 有效，输出 1（编号 01）。所以 $Y_0 = I_3 + \overline{I_2}I_1$——**$\overline{I_2}$ 就是「屏蔽 $I_2$」的开关**。

**第三步，验证**：输入 $I_2=1, I_1=1$（同时有效）时，$Y_1=1$、$Y_0 = 0 + \overline{1}\cdot 1 = 0$，输出 $10_2 = 2$——正是优先的 $I_2$ 编号。$I_1$ 被正确屏蔽。<span class="marginnote">这个「$\overline{I_j}$ 屏蔽低优先级」的项，是优先编码器逻辑式的标志性结构。<strong>级联多片优先编码器时，低优先级的输出还要被高优先级的有效信号整体屏蔽</strong>，正是这个思想的延伸。</span>

## 4 编码器的应用

编码器的应用远超「键盘」：

- **键盘编码**：键盘矩阵通过编码器把按键位置变成扫描码。
- **中断优先级管理**：多中断源经优先编码器选出最高优先级，形成中断号。
- **指令操作码生成**：CPU 的译码器输入端常由编码器把「控制信号」压缩成操作码。
- **状态表示**：独热码到二进制码的转换，用于状态机（第六篇）的编码表示。

**辨析｜易错点：** 编码器与译码器方向相反，极易搞混。**编码器：多条输入线 → 少数输出线（压缩）；译码器：少数输入线 → 多条输出线（展开）**。一个是「找编号」，一个是「译码」。记忆锚点：编码器把「一长串信号」变成「一个码」，译码器把「一个码」变成「一长串信号」。

## 5 编码器的级联与扩展

单个优先编码器（如 8-3）输入不够时，可以级联扩展。用两片 8-3 优先编码器构成 16-4：

**思路**：把 16 个输入分成高 8 位与低 8 位两组，各接一片 74LS148；再用附加逻辑合成：

1. **组内编码**：高组片与低组片各自输出 3 位编码。
2. **组间优先**：若高组有任意输入有效，则整体最高优先级在高组——输出 = 高组编码 + 高位标志；否则输出 = 低组编码。
3. **级联端**：74LS148 的 $Y_{EX}$（扩展端）指示「本片有无输入有效」，正好用来做组间选择。

**通用规律**：优先编码器级联后，**高优先级的片「屏蔽」低优先级的片**——与单片的「高优先级输入屏蔽低优先级输入」完全同构。这个「逐级屏蔽」的结构，在中断控制器、总线仲裁器里反复出现。

**中断控制器的实例**：CPU 的中断系统常用多级优先编码——多个中断源（定时器、串口、键盘）各自有优先级，优先编码器选出最高优先级中断号，CPU 据此跳转到对应中断服务程序。你键盘上按下一个键，键盘编码器 + 中断控制器就完成了一次「哪个键、按了没」的判定。

**辨析｜易错点：** 级联时注意各片输出的**有效电平**。74LS148 输入输出都是低有效，级联时「最高有效输入」的判定要考虑低有效语义——先把每片输出「翻译」成正常逻辑再合成，避免正负逻辑混乱。

## 6 编码器的 Verilog 描述

编码器在现代设计里用 HDL 描述，理解原理后写起来很直接。

**普通编码器（独热输入）**：

```verilog
always @(*) begin
    case (1'b1)
        y0:       code = 3'd0;
        y1:       code = 3'd1;
        y2:       code = 3'd2;
        // ...
        default:  code = 3'd0;
    endcase
end
```

`case (1'b1)` 是独热编码器的经典写法——匹配第一个为 1 的位，天然实现「唯一有效」。

**优先编码器（多个有效取最高）**：

```verilog
always @(*) begin
    if (y7)      code = 3'd7;   // 最高优先级
    else if (y6) code = 3'd6;
    else if (y5) code = 3'd5;
    // ...
    else if (y0) code = 3'd0;
    else         code = 3'd0;
end
```

`if-else if` 链天然实现优先级——先判高优先级，命中即止。这与硬件的「屏蔽」逻辑（前面推导的 $\overline{I_j}$ 项）完全等价。

**为什么优先编码器用 if-else 链**：硬件上 if-else 链综合成「逐级使能/屏蔽」结构——每级判断自己的输入、屏蔽低优先级——正是优先编码器的硬件本质。理解原理，写代码就有把握；读综合报告也能看懂结构。

**编码器的测试要点**：Testbench 要覆盖「单输入有效」与「多输入有效（验证优先级）」两类情况——只测单输入的 Testbench 测不出优先级逻辑的对错。

**辨析｜易错点：** `case (1'b1)` 匹配第一个为 1 的位，隐含「只有一个 1」假设；`if-else if` 处理「多个 1 取最高」。普通编码器与优先编码器的差别，在 HDL 里就是这两种写法的差别——写错就换了个功能。

## 7 小结

- **编码器**：$2^n$ 输入 → $n$ 输出，输入独热，输出为有效输入的二进制编号。
- 输出方程通式：每一位输出 = 「该位为 1 的所有编号输入」之和。
- 普通编码器要求**输入互斥**；**优先编码器**按优先级处理同时有效，用 $\overline{I_j}$ 屏蔽低优先级输入。
- 74LS148 是经典 8-3 优先编码器，带低有效输入输出与级联端。
- 编码器（压缩）与译码器（展开）方向相反，勿混淆。

在下一节，我们将见到编码器的「孪生兄弟」——译码器，它把二进制代码展开成唯一的输出线，是地址译码与显示驱动的核心。
