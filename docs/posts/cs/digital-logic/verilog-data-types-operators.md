## 为什么从数据类型与运算符开始

上一节搭好了模块骨架，这一节填充「血肉」——**数据类型**（怎么描述数值）与**运算符**（怎么组合逻辑）。它们是 Verilog 表达硬件行为的词汇表。理解四值逻辑、位宽与各类运算符，才能写出正确的 HDL。<span class="marginnote">Verilog 与 C 最大的不同之一：<strong>它是四值逻辑</strong>——除了 0 和 1，还有 x（未知）与 z（高阻）。这四个值对应硬件的真实状态，仿真时尤其重要。忘了这一点，就会写出「只对 0/1 正确」的错误代码。</span>这一节系统讲清数据类型与运算符。

## 1 四值逻辑：0、1、x、z

Verilog 的每个 bit 可以有四个值：

| 值 | 含义 | 硬件对应 |
|---|---|---|
| 0 | 逻辑 0 | 低电平 |
| 1 | 逻辑 1 | 高电平 |
| x（X） | 未知/不确定 | 未初始化、冲突 |
| z（Z） | 高阻 | 三态输出断开 |

**x 与 z 的作用**：

**仿真时**：未初始化的 reg 是 x；两个驱动器冲突是 x；未连接的引脚是 z。
**综合时**：x 常用于表达「无关项」（don't care），给综合器化简空间。

**辨析｜易错点：** x 与 z 不是「两个电压」，而是「不知道/没连接」的抽象。比较 <code>4'b1x == 4'b1x</code> 结果是 x（未知不等于未知）——这与 C 语言完全不同。写代码时尽量避免让 x 传播，否则仿真结果一片红。<span class="marginnote">四值逻辑的价值在仿真：<strong>「仿真出 x 就说明电路有 bug」</strong>——未初始化、冲突、悬空都会显示为 x。学会读 x 出现的源头，就是学会找硬件 bug。综合时 x 则是有意为之的无关项声明。</span>

## 2 数值表示：位宽、进制与常量

Verilog 常量的格式：**位宽'进制值**：

```verilog
8'd255        // 8 位十进制数 255
8'hFF         // 8 位十六进制 0xFF
4'b1010       // 4 位二进制 1010
12'o777       // 12 位八进制 0o777
16'hC0DE_5A   // 下划线提高可读性
```

**位宽**：常量占几位，缺省按使用场景推断。
**进制**：<code>'b</code>`（二进制）、<code>'o</code>`（八进制）、<code>'d</code>`（十进制）、<code>'h</code>`（十六进制）。
**下划线**：提高可读性。

**位宽不匹配是常见 bug**：8 位常量（如 <code>8'hA5</code>）赋给 4 位信号会**截断高 4 位**。

```verilog
reg [3:0] low;          // 4 位信号
initial low = 8'hA5;    // 8 位值赋给 4 位 → 截断高 4 位，low = 4'h5
```

**辨析｜易错点：** 位宽是 Verilog 的头号陷阱：**赋值按位宽截断/扩展，不是按数值大小**。<code>4'b1111 + 4'b0001</code>` 结果是 <code>4'b0000</code>`（溢出截断，无进位提示）。用拼接 <code>{cout, s}</code> 显式保留进位，是处理溢出的标准手法。

## 3 运算符总览：逻辑、位、算术

Verilog 的运算符分几大类：

**逻辑运算符**（结果 0/1/x，用于条件判断）：

| 运算符 | 含义 | 示例 |
|---|---|---|
| `!` | 逻辑非 | `!a` |
| `&&` | 逻辑与 | `a && b` |
| `\|\|` | 逻辑或 | `a \|\| b` |

**位运算符**（逐位运算，用于逻辑设计）：

| 运算符 | 含义 | 示例 |
|---|---|---|
| `~` | 按位取反 | `~a` |
| `&` | 按位与 | `a & b` |
| `\|` | 按位或 | `a \| b` |
| `^` | 按位异或 | `a ^ b` |
| `~^` / `^~` | 按位同或 | `~(a ^ b)` |

**算术运算符**（综合成算术电路）：

| 运算符 | 含义 | 示例 |
|---|---|---|
| `+` | 加 | `a + b` |
| `-` | 减 | `a - b` |
| `*` | 乘 | `a * b` |
| `/` | 除（慎用） | `a / b` |
| `%` | 取模 | `a % b` |

<span class="marginnote">逻辑运算符与位运算符的差别必须分清：<strong>逻辑运算符看整体真假，位运算符逐位操作</strong>。<code>4'b1010 & 4'b1100 = 4'b1000</code>`（位与），而 <code>4'b1010 && 4'b1100 = 1'b1</code>`（两者非零为真）。条件判断用逻辑运算符，逻辑设计用位运算符——混用是初学者高频错误。</span>

## 4 公式解析：运算符的优先级与实战

组合运算符写表达式时，优先级容易出错。从高到低关键几个：

```
!  ~            （最高，单目）
*  /  %
+  -
<<  >>
<  <=  >  >=
==  !=  ===  !==
&
^  ^~
|
&&
||              （最低）
```

**例题**：写 $Y = (A \cdot B) \oplus C + D$ 的 Verilog：

**第一步，分析优先级**：先猜「位与（&）先于异或（^）先于加法（+）」。

**第二步，直接写**：

```verilog
assign Y = A & B ^ C + D;   // 先按默认优先级写
```

**第三步，检查优先级**：`&` 优先于 `+`？不对——`&` 在 `+` 之后（低优先级）。`C + D` 先算，再异或。若想表达 $(AB)\oplus C + D$，实际是 $(AB)\oplus(C+D)$——**与意图不符**。

**第四步，加括号明确**：

```verilog
assign Y = ((A & B) ^ C) + D;   // 括号明确意图：先 (A&B)^C，再加 D
```

**结论**：**算术/位运算混用时，务必加括号**——Verilog 的优先级不是直觉，括号是消除歧义的唯一可靠手段。<span class="marginnote">工程铁律：<strong>Verilog 表达式里的括号宁多勿少</strong>。综合工具不会抱怨多余括号，但错误的优先级会生成错误的电路。写表达式时按硬件逻辑「分组」加括号，读的人和你自己都不会错。</span>

## 5 其他常用运算符

**关系与相等**：

关系：`>` `>=` `<` `<=`（结果 0/1/x）。
相等：`==` `!=`（含 x/z 比较为 x）、`===` `!==`（全等比较，x/z 也逐位比）。

**移位**：

<<` 左移（乘 2）、`>>` 右移（除 2）、<<<` `>>>` 算术移位。

**缩减运算（归约）**：单目，对总线逐位归约：

```verilog
wire [7:0] bus;
wire all_ones = &bus;        // 归约与：全部为 1 才为 1（全 1 检测）
wire any_one  = |bus;        // 归约或：任一为 1 即 1
wire parity   = ^bus;        // 归约异或：奇偶校验
```

**条件运算（三目）**：

```verilog
wire sel;
wire [7:0] a, b, y;
assign y = sel ? a : b;      // sel=1 选 a，否则选 b → MUX
```

**拼接**：

```verilog
wire a, b, c;
wire [2:0] y;
assign y = {a, b, c};        // 拼接成 3 位
assign c  = {y[2:1], a};     // 位选与拼接组合
```

<span class="marginnote">几个实用直觉：<strong>三目 <code>? :</code> 直接对应 MUX、归约与 <code>&</code> 对应「全 1 检测」、归约异或 <code>^</code> 对应奇偶校验、移位对应乘除 2</strong>。这些「一行代码 = 一个标准模块」的对应，正是 HDL 高效的原因——想清楚硬件，再挑运算符。</span>

## 6 小结

- **四值逻辑**：0、1、x（未知）、z（高阻）；x 是 bug 的信号，也是无关项的声明。
- 常量格式：<code>位宽'进制值</code>（如 <code>8'hFF</code>）；位宽不匹配会截断/扩展。
- 运算符五大类：逻辑、位、算术、关系、其他；**逻辑运算符 vs 位运算符** 必须分清。
- 优先级易错：混用算术与位运算时**务必加括号**。
- 常用对应：三目 <code>? :</code> → MUX、归约 <code>&</code> → 全 1 检测、归约 <code>^</code> → 奇偶校验、左移 <code><<</code> → 乘 2。
