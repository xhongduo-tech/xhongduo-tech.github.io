## 为什么从触发器转换开始

实际系统里库存的触发器往往只有一种（现代 FPGA/ASIC 里几乎只有 D 触发器），但设计时可能想要 JK 的翻转、T 的计数。**触发器间的相互转换**就是回答：「用手中的 D 触发器，怎么实现 JK 的行为？」<span class="marginnote">转换的本质是<strong>组合逻辑变换</strong>：在既有触发器的输入端加一个「转换网络」，把目标触发器的输入翻译成既有触发器能理解的输入。这在现代 EDA 里由综合器自动完成，但手工推导是理解「触发器 = 记忆 + 输入逻辑」的关键练习。</span>这一节建立分类框架，并重点推演 D→JK、JK→T 等经典转换。

## 1 触发器的逻辑功能分类

按**逻辑功能**（特征方程决定），触发器分为四大类：

| 类型 | 特征方程 | 核心能力 |
|---|---|---|
| SR | $Q^{n+1}=S+\overline{R}Q^n$（$SR=0$） | 置位/复位/保持，有禁止态 |
| D | $Q^{n+1}=D$ | 存数（输入即次态） |
| JK | $Q^{n+1}=J\overline{Q^n}+\overline{K}Q^n$ | 功能最全（保持/置/复/翻） |
| T | $Q^{n+1}=T\oplus Q^n$ | 可控翻转 |

四种功能不是独立的：**JK 功能最全，能实现其余一切**（把 J、K 适当接法即得 D、T、SR）；D 次之（能实现 T、SR 等）；SR 最弱。<span class="marginnote">能力排序：<strong>JK ⊇ D ⊇ SR；T 是 JK 的特例</strong>。工程上「最弱够用」——现代芯片只用 D，因为 D 的实现最省、行为最简，能力差一点没关系。</span>

**辨析｜易错点：** 分类角度别混淆：**逻辑功能**（SR/D/JK/T）与**触发方式**（电平/脉冲/边沿）是两回事。例如「边沿 JK」与「主从 JK」触发方式不同但逻辑功能都是 JK。一套功能可以由多种触发方式实现。

## 2 转换的通用方法：比较特征方程

触发器转换的通用套路是**特征方程比较法**：

1. 写出**目标触发器**（想得到的）的特征方程。
2. 写出**已有触发器**（手中的）的特征方程，把次态 $Q^{n+1}$ 用同样的 $Q^n$ 表达。
3. 令两者相等，解出**已有触发器的输入信号**关于目标输入与 $Q^n$ 的函数。
4. 用组合逻辑实现该函数，接到已有触发器的输入。

以 **D 触发器实现 T 触发器**为例：

目标：$Q^{n+1} = T\oplus Q^n$。
已有 D：$Q^{n+1} = D$。
令 $D = T\oplus Q^n$：D 触发器的输入 D 接「$T$ 异或 $Q$」——一个异或门即可。

于是「D + 异或门」就构成了 T 触发器。<span class="marginnote">这个例子的要点：<strong>D 触发器的输入完全由「目标次态」决定</strong>——因为 $D=Q^{n+1}$。因此「用 D 实现任何触发器」只需把目标特征方程整个搬给 D 输入：$D = f(\text{目标输入}, Q^n)$。</span>

## 3 经典转换：D → JK

用 D 触发器实现 JK 触发器：

**第一步，写目标方程**：$Q^{n+1} = J\overline{Q^n} + \overline{K}Q^n$。

**第二步，D 的输入**：因为 $D = Q^{n+1}$，直接得

$$D = J\overline{Q^n} + \overline{K}Q^n$$

**第三步，验证四组 J,K**：
- $J=0,K=0$：$D = 0 + \overline{0}\cdot Q^n = Q^n$ → 次态 $=Q^n$，保持 ✓
- $J=0,K=1$：$D = 0 + 0\cdot Q^n = 0$ → 次态 0，复位 ✓
- $J=1,K=0$：$D = 1\cdot\overline{Q^n} + 0 = \overline{Q^n}$ → 次态 1，置位 ✓
- $J=1,K=1$：$D = \overline{Q^n} + 0 = \overline{Q^n}$ → 次态取反，翻转 ✓

四种行为全部吻合。<span class="marginnote">D→JK 的结论：<strong>一个 D 触发器加两个与门、一个或门（实现 $D=J\overline{Q}+\overline{K}Q$）就变成 JK</strong>。这个转换网络里用到 $Q$ 与 $\overline{Q}$，正是触发器互补输出端的用途之一。</span>

## 4 公式解析：JK → T 的化简

用 JK 触发器实现 T 触发器，体会「×」带来的化简空间：

**第一步，写目标方程**：$Q^{n+1} = T\oplus Q^n$。

**第二步，列 JK 激励表**（按 $Q^n\to Q^{n+1}$ 查）：

| $Q^n$ | $Q^{n+1}=T\oplus Q^n$ | J | K |
|---|---|---|---|
| 0 | T | T | × |
| 1 | $\overline{T}$ | × | T |

**第三步，写 J、K 的方程**：由表可得

$$J = T, \qquad K = T$$

**第四步，验证**：$J=K=T$ 时，JK 特征方程化为 $Q^{n+1}=T\overline{Q^n}+\overline{T}Q^n=T\oplus Q^n$，与目标一致——**JK 短接就是 T**。<span class="marginnote">JK→T 为什么这么简单？因为 JK 的激励表里 × 多，化简后 $J=T、K=T$ 各占一行。<strong>激励表 + 卡诺图是触发器转换的标准工具链</strong>：列出激励表→对 J、K 分别化简→得到转换网络。</span>

## 5 转换小结：一张全览表

| 目标 | 用 D 实现 | 用 JK 实现 | 用 T 实现 |
|---|---|---|---|
| T | $D=T\oplus Q^n$ | $J=K=T$ | — |
| JK | $D=J\overline{Q^n}+\overline{K}Q^n$ | — | $T=J\overline{Q^n}+\overline{K}Q^n$ |
| SR | $D=S+\overline{R}Q^n$ | 略 | 略 |
| D | — | $J=D,K=\overline{D}$ | $T=D\oplus Q^n$ |

**工程现实**：这些转换在现代综合器里自动完成，但理解它们让你能**读懂综合后的网表**、诊断手工设计问题，也是面试中「触发器基础」的经典考题。<span class="marginnote">更重要的思维：<strong>「用简单器件+组合逻辑实现复杂功能」是数字设计的第一性原理</strong>——从触发器转换到 CPU 指令集设计，全都是「用现有积木拼出目标行为」。</span>

## 6 转换的工程意义与综合器视角

触发器转换不只是考试题，它揭示了数字设计的深层规律：

**「最小积木」的统一**：现代 FPGA/ASIC 里，硬件触发器几乎只有 D 一种。设计者想用 JK、T 的行为，全靠「D + 转换逻辑」实现——综合器自动把 JK/T 行为（如 `q <= (j & ~q) | (~k & q)`）这类代码映射成 D 触发器 + 门逻辑。

**转换网络的代价**：转换不是免费的——D→JK 要加组合网络（延迟 + 面积）。所以「功能转换」只在「非用不可」时做：库存只有 D 触发器、或综合器强制。设计时优先「直接用目标触发器」，转换是兜底。

**转换揭示的统一性**：所有触发器（SR/D/JK/T）都能互相转换，说明它们共享同一个「记忆内核」——都是「带输入的边沿存储单元」，区别只在输入组合逻辑。这个「内核统一、输入各异」的视角，是理解触发器家族的最高层抽象。

**从触发器到状态机**：触发器转换的本质是「输入逻辑设计」——设计「给什么输入能实现目标行为」。时序电路设计（第六篇）里的「激励方程」就是触发器转换的规模化应用：对每个状态转移，算触发器该收什么输入。

**综合器怎么做**：综合器收到 `q <= d` 就映射 D 触发器，收到 `q <= t ? ~q : q` 就映射 D + MUX。设计者写「行为」，综合器挑「实现」——但理解手工转换，才能预判综合结果、优化关键路径。

**辨析｜易错点：** 转换得到的电路「功能等价」，但**时序不同**——转换网络有额外延迟。高频率设计里，多余的转换网络可能成为关键路径。所以「能不用转换就不用」，直接选原生触发器。

## 7 小结

- 触发器按逻辑功能分 SR、D、JK、T 四类；能力排序 JK ⊇ D ⊇ SR。
- 分类的两个维度：逻辑功能 × 触发方式，勿混。
- 转换方法：**特征方程比较法**——令目标次态 = 已有触发器次态，解出输入端函数。
- D 触发器最易转换（$D=Q^{n+1}$）；JK→T 只需短接 $J=K=T$。
- 激励表 + 卡诺图是转换的标准工具链。

在下一节，我们将离开「功能」，进入触发器的「物理」——建立时间、保持时间与传输延迟这些动态参数，它们决定电路能跑多快。
