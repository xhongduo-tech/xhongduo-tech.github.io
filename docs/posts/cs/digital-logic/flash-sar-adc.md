## 为什么从并联与逐次逼近 ADC 开始

ADC 家族里，**并联比较型（flash）**以「快」著称，**逐次逼近型（SAR）**以「均衡」著称——它们是速度与成本权衡的两个代表。理解它们的原理，就能理解 ADC 的多样性：不同应用（视频 vs 传感器 vs 音频）需要不同速度/精度的 ADC。<span class="marginnote">两种 ADC 的策略对比：<strong>flash 用「人海战术」（一堆比较器同时比），SAR 用「二分查找」（一个比较器反复比）</strong>。一个以面积换速度，一个以时间换面积——这正是硬件设计里最经典的权衡。</span>这一节把两种 ADC 的结构、原理与取舍讲透。

## 1 并联比较型 ADC：一锤定音的快

**并联比较型 ADC（flash ADC）**：$n$ 位 ADC 用 $2^n - 1$ 个比较器**同时**把输入与各级阈值比较，一次比较出全部位数。

**结构**：

电阻分压链产生 $2^n-1$ 个阈值（$V_{REF}/2^n, 2V_{REF}/2^n, \dots$）。
$2^n-1$ 个比较器同时把输入 $v_I$ 与各阈值比较。
优先编码器把「最高位的比较结果」编码成 $n$ 位数字码。

**工作原理**：$v_I$ 落在哪个台阶，对应的所有低阈值比较器输出 1、高阈值输出 0——编码器根据「1 的最高位置」输出数字码。

**优点**：**极快**——一次比较完成转换，转换时间只受比较器延迟限制，可达 GSPS（每秒几十亿次）。无需 S/H 严格保持。

**缺点**：**面积爆炸**——$n$ 位需要 $2^n-1$ 个比较器。10 位就要 1023 个比较器，12 位要 4095 个——**位数每加 1，比较器翻倍**。<span class="marginnote">flash ADC 的「贵」在于比较器数量指数增长：<strong>6 位 63 个、8 位 255 个、10 位 1023 个</strong>。所以 flash ADC 多用于 6~8 位的超高速场合（示波器前端、高速 SerDes 接收）。更高位数靠「多级 flash」（流水线 ADC）解决。</span>

## 2 逐次逼近型 ADC：二分查找的准

**逐次逼近型 ADC（SAR ADC, Successive Approximation Register）**：用一个比较器 + 一个 DAC + 逐次逼近寄存器（SAR），通过**二分查找**逐位确定数字码。

**工作原理**（以 8 位为例）：

1. SAR 置最高位（MSB）为 1，其余为 0：$D = 10000000$。
2. DAC 输出 $V_{REF}/2$，与输入 $v_I$ 比较。
3. 若 $v_I > V_{REF}/2$：MSB 保留 1；否则 MSB 清 0。
4. 下一位置 1，重复比较……直到最低位。

**转换过程**：8 位需要 8 次比较（每个时钟一次）。每次比较把范围「对半」，逼近输入值——这就是**二分查找**的硬件实现。

**特点**：

**比较器只有一个**，面积小。
**速度适中**：$n$ 位需 $n$ 次比较，转换时间 $= n \times t_{cycle}$。
**精度高**：精度取决于内部 DAC 与比较器精度，可达 16~20 位。
**需要 S/H**：比较期间输入必须稳定（保持电路在逐次逼近期间锁定输入）。

<span class="marginnote">SAR 是「<strong>用时间换面积</strong>」的典型：一个比较器反复用 $n$ 次，换来 flash 需要 $2^n$ 个比较器的面积。它在精度、速度、功耗、面积上最均衡，是数据采集、仪器、音频的最主流 ADC 架构。</span>

## 3 公式解析：逐次逼近的收敛过程

用例子看 SAR 的二分查找如何收敛。设 4 位 SAR，$V_{REF} = 16$（归一化），输入 $v_I = 10.5$：

**第一步，置 MSB**：$D = 1000$，DAC 输出 8。$10.5 > 8$，MSB 保留 1。

**第二步，置次高位**：$D = 1100$，DAC 输出 12。$10.5 < 12$，该位清 0 → $D = 1000$。

**第三步，置第 3 位**：$D = 1010$，DAC 输出 10。$10.5 > 10$，保留 → $D = 1010$。

**第四步，置 LSB**：$D = 1011$，DAC 输出 11。$10.5 < 11$，清 0 → $D = 1010$。

**结果**：$D = 1010_2 = 10$，量化误差 $|10.5 - 10| = 0.5$（≤ 半个 LSB，符合理论）。<span class="marginnote">观察收敛过程：<strong>每次比较把搜索区间减半，$n$ 次比较后误差 ≤ 半个 LSB</strong>。这正对应量化误差的理论极限——SAR 的精度由「二分查找能收敛到多细」决定，即位数 $n$。</span>

## 4 两种 ADC 的对比与选型

| 对比 | Flash ADC | SAR ADC |
|---|---|---|
| 比较器数 | $2^n - 1$ | 1 |
| 转换时间 | 1 次比较 | $n$ 次比较 |
| 速度 | 极快（GSPS） | 中（MSPS~百 MSPS） |
| 分辨率 | 低（6~8 位实用） | 高（可达 20 位） |
| 面积/功耗 | 大/高 | 小/低 |
| S/H 需求 | 不强 | 必须 |
| 典型应用 | 示波器、SerDes | 数据采集、仪器、音频 |

**选型逻辑**：

要**极快**（视频、高速采样）→ flash/流水线。
要**高精度 + 适中速度**（传感器、音频、仪器）→ SAR。
要**高精度 + 慢速**（精密测量、称重）→ 双积分型（下一节）。

<span class="marginnote">现代 ADC 格局：<strong>flash 用于超高速低位数，SAR 统治中速中高精度，Σ-Δ 统治高精度低速，流水线统治高速中高精度</strong>。每种架构都是「速度×精度×面积×功耗」折线上的一点——选型就是找需求在折线上的投影。</span>

## 5 从 SAR 看 ADC 的通用框架

SAR ADC 体现了 ADC 的通用框架：**比较器 + 基准 DAC + 逻辑控制**。

- 比较器：判断「输入大还是 DAC 大」。
- DAC：产生候选阈值。
- 逻辑：决定下一次比较试哪个码。

这个「**用 DAC 逼近输入**」的框架，是 SAR 与双积分、以及许多 ADC 变体的共同内核。理解了 SAR，再学其他 ADC 就有抓手了。

## 6 ADC 选型的完整框架

把 ADC 选型做成一个可复用的决策流程：

**① 定速度需求**：信号最高频率 $f_{max}$ → 采样率 $f_s \ge 2f_{max}$（取样定理 + 裕量）。再换算成「转换时间」需求。

**② 定分辨率需求**：信号动态范围 / 需要分辨的最小幅度 → 位数 $n$。

**③ 定精度需求**：总误差预算 → ENOB（有效位数）。**ENOB 比标称位数更关键**——标称 16 位但 ENOB 12 位，实际按 12 位用。

**④ 定架构**：

| 需求组合 | 架构 |
| --- | --- |
| 极快 + 低位数 | Flash / 流水线 |
| 中速 + 中高精度 | SAR |
| 慢 + 高精度 + 抗噪 | 双积分 / Σ-Δ |
| 高精度 + 中速 | 流水线 / Σ-Δ（高带宽版） |

**⑤ 定外围**：基准电压精度、时钟抖动、驱动放大器（运放）——ADC 的精度上限常被「前面」的模拟电路限制，不只是 ADC 本身。

**为什么「ADC 精度」是系统问题**：ADC 只是数据链的一环——传感器噪声、放大器失调、基准漂移、时钟抖动、PCB 噪声，全都叠加进结果。ADC 选得再好，前端不干净也白搭。这就是「系统级精度预算」的概念。

**一个易错提醒**：采样率不是越高越好——数据量、功耗、成本都随采样率上升。够用（满足取样定理 + 裕量）即可，过度采样是浪费。

**辨析｜易错点：** 「位数越高 ADC 越好」是误区——不同架构的「高位数」含义不同：Σ-Δ 的 24 位靠过采样换取，速度慢；SAR 的 16 位是真实逐次逼近，速度中等；flash 的 8 位是物理比较，速度极快。位数脱离架构谈没有意义。

## 7 小结

- **Flash ADC**：$2^n-1$ 个比较器同时比较，一次转换、极快，但面积指数增长、位数低。
- **SAR ADC**：一个比较器 + DAC 二分查找，$n$ 次比较，面积小、精度高、速度适中。
- SAR 收敛过程：逐位置位/清位，$n$ 次后误差 ≤ 半个 LSB。
- 选型：极快用 flash/流水线，中速高精度用 SAR，慢速高精度用双积分/Σ-Δ。
- SAR 的「比较器 + DAC + 逻辑」框架是理解多种 ADC 的通用钥匙。
