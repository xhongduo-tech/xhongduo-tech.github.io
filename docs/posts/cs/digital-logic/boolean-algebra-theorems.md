## 为什么从三个定理开始

上一节的公式表是「武器」，三个定理则是「锻造武器的规则」。代入定理告诉我们：公式里的变量可以替换成更复杂的式子；反演定理与对偶定理则像两面镜子，让我们从一个恒等式立刻得到它的「孪生兄弟」。有了它们，一张小小的公式表就能覆盖无穷多种情形。<span class="marginnote">反演定理在求职面试和期末考试里几乎必考：求 $\overline{F}$ 的「翻号」操作有一套严格口诀，稍不注意就会在「先与后或」的顺序上翻车。</span>这一节的目标，是把这三面镜子磨亮。

## 1 代入定理：把变量替换成任意逻辑式

**代入定理（substitution theorem）**：在任何一个含变量 $A$ 的等式两边，将 $A$ 都替换为同一个逻辑函数式 $G$，等式仍然成立。

例如，德·摩根定律 $\overline{A\cdot B} = \overline{A}+\overline{B}$ 对两个变量成立；若令 $A = X+Y$，则得

$$\overline{(X+Y)\cdot B} = \overline{X+Y} + \overline{B} = \overline{X}\cdot\overline{Y} + \overline{B}$$

代入定理的威力在于**公式的推广**：它让「二变量的德·摩根定律」自动升级为「任意多个变量的德·摩根定律」。反复代入，可得

$$\overline{A_1 A_2 \cdots A_n} = \overline{A_1} + \overline{A_2} + \cdots + \overline{A_n}$$

这一推广是计算机里对「一整个总线取反」做正确性验证的理论依据。<span class="marginnote">代入定理的逻辑基础很朴素：等式恒真，把其中一个符号换成任意有定义的表达式，恒真性不会改变——就像方程两边同时「换元」仍相等。</span>

**辨析｜易错点：** 代入必须是**两侧同时、全部位置**替换。只替换一边、或只替换部分出现位置，得到的式子就不再是恒等式。这跟解方程时「两边同乘一个数」的道理完全一样。

## 2 反演定理：求反函数的万能公式

**反演定理（inversion theorem）**：已知函数 $F$，对 $F$ 中所有「·」换成「+」、「+」换成「·」、0 换成 1、1 换成 0、每个原变量换成反变量、每个反变量换成原变量，所得的新函数就是 $\overline{F}$。

这个操作有个响亮的记法——**反演（取反）**，操作口诀是「**与或互换、01 互换、变量取反**」。

**例子：** 设 $F = A \cdot (B + \overline{C}) + \overline{D}$，求 $\overline{F}$。

- 与或互换：$A + (B \cdot C) \cdot D$
- 变量取反：$\overline{A} \cdot (\overline{B} + C) + D$

注意顺序：原式中 $\overline{C}$ 取反后变为 $C$，$\overline{D}$ 变为 $D$。最终

$$\overline{F} = \overline{A}\cdot(\overline{B} + C) + D$$

反演定理最常见的用途是把「与或式」变成「或与式」，以及化简时求反函数。它本质上就是**多次嵌套的德·摩根定律**：$\overline{F}$ 就是把 $F$ 整个用德·摩根展开。

**辨析｜易错点：** 反演时**必须保持原式的运算优先级不变**。比如 $F = A + BC$ 的反演是 $\overline{F} = \overline{A}\cdot(\overline{B}+\overline{C})$，**括号不能省略**——很多人漏括号写成 $\overline{A}\cdot\overline{B}+\overline{C}$，那是 $\overline{A+BC}$ 以外的另一个函数。求反演时先补全隐含括号，再逐层「翻号」。

## 3 对偶定理：让一个公式变成两个

**对偶定理（duality theorem）**：设 $F$ 是一个逻辑函数式，把 $F$ 中所有「·」与「+」互换、0 与 1 互换（**变量不取反**），得到的新式称为 $F$ 的**对偶式** $F^*$。若两个函数 $F$ 与 $G$ 相等，则它们的对偶式 $F^*$ 与 $G^*$ 也相等。

上一节的「双分配律」就是对偶定理的直接产物：

$$A(B+C) = AB + AC \;\xrightarrow{\;\text{取对偶}\;}\; A + BC = (A+B)(A+C)$$

对偶与反演的区别是本题的**高频考点**：

| 对比项 | 反演（求 $\overline{F}$） | 对偶（求 $F^*$） |
|---|---|---|
| 与、或互换 | ✓ | ✓ |
| 0、1 互换 | ✓ | ✓ |
| 变量取反 | ✓ | ✗ 变量保持原样 |
| 结果 | 原函数的非 | 另一恒等式的左侧/右侧 |

<span class="marginnote">关系式：$\overline{F}$ 与 $F^*$ 只差在「变量取反」这一步——事实上 $\overline{F}$ 等于把 $F^*$ 中所有变量取反。于是掌握对偶，反演也就顺带掌握了。</span>

## 4 公式解析：一个例子同时走完两个定理

用同一道题把两个定理串起来。设 $F = \overline{A} \cdot B + C$。

**第一步，取对偶**：与或互换（+ 与 · 互换），01 互换（这里无常数，跳过），变量不取反：

$$F^* = (\overline{A} + B)\cdot C$$

**第二步，取反演**：在 $F^*$ 的基础上把所有变量取反（$\overline{A}\to A$、$B\to\overline{B}$、$C\to\overline{C}$），就得到 $\overline{F}$：

$$\overline{F} = (A + \overline{B})\cdot\overline{C}$$

**第三步，直接验证**：用真值表或德·摩根逐层展开 $F$ 的非——$\overline{F} = \overline{\overline{A}B + C} = (\overline{\overline{A}B})\cdot\overline{C} = (A + \overline{B})\cdot\overline{C}$，与反演结果一致。<span class="marginnote">这条「先对偶再取变量反 = 反演」的捷径能显著降低翻车率：先把 01/与或翻完，最后才动变量，思路更清晰。</span>

## 5 三个定理的实战演练

把代入、反演、对偶三个定理放在一组题里综合运用，检验熟练度。

**题目**：设 $F = \overline{A}B + \overline{C}D$，求 $F$ 的对偶式 $F^*$ 与反演式 $\overline{F}$。

**① 求对偶 $F^*$**：只互换与或、01，变量不取反：

$$F^* = (\overline{A} + B)\cdot(\overline{C} + D)$$

**② 求反演 $\overline{F}$**：对偶的基础上再变量取反，或直接按反演定理：

$$\overline{F} = (A + \overline{B})\cdot(C + \overline{D})$$

**③ 验证一致性**：直接用德·摩根展开 $\overline{F} = \overline{\overline{A}B + \overline{C}D} = \overline{\overline{A}B}\cdot\overline{\overline{C}D} = (A+\overline{B})(C+\overline{D})$——与②一致。

**④ 检验「先对偶再取反 = 反演」**：$F^* = (\overline{A}+B)(\overline{C}+D)$ 的所有变量取反，得 $(A+\overline{B})(C+\overline{D})$——正是 $\overline{F}$。捷径成立。

**三个定理的分工记忆**：

- **代入**：让公式「升级」——单个变量的恒等式推广到任意表达式。
- **反演**：求反函数——「翻号」操作，保持括号顺序。
- **对偶**：生成新恒等式——「镜像」操作，变量不动。

**工程用途**：反演用于求补电路、与或式 ↔ 或与式转换；对偶用于验证恒等式、发现对称结构。三者是逻辑代数「变形语法」的全部工具。

**辨析｜易错点：** 求反演时若式子有括号，括号本身**保留**、内部整体翻号；对偶则完全不碰括号结构与变量。分清「反演动变量、对偶不动变量」这两个字，就抓住了全部区别。

## 6 小结

- **代入定理**：等式中的变量可整体替换为任意逻辑式，两侧同时、全部位置替换。
- **反演定理**：与或互换、01 互换、变量取反；**括号顺序必须保留**，求 $\overline{F}$ 的一键操作。
- **对偶定理**：只互换与或和 01，变量不动；恒等式取对偶仍恒等。
- 三者关系：对偶比反演少「变量取反」一步；$\overline{F}$ = 对 $F^*$ 的变量全部取反。
