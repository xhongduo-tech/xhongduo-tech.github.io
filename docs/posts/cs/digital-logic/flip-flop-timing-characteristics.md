## 为什么从动态特性开始

前几节看的是触发器「干什么」，这一节看「多快、多稳」——**建立时间、保持时间、传输延迟**这三个时间参数，决定了一个同步系统能跑多快的时钟。它们也是现代芯片设计里「时序收敛」这门硬功夫的物理根基。<span class="marginnote">真实世界没有「瞬间」：<strong>数据必须在时钟边沿前准备好（建立时间）、在边沿后维持住（保持时间），触发器才能可靠采样</strong>。这两个窗口若被违反，输出进入亚稳态——既不是 0 也不是 1，完全不可预测。</span>这一节把这三个参数讲透，并给出它们如何约束时钟频率。

## 1 三个时间参数的定义

以边沿 D 触发器（上升沿触发）为例，定义三个关键时间：

**建立时间 $t_{su}$（setup time）**：数据 $D$ 必须在时钟上升沿**之前**保持稳定的一段时间。若 $D$ 在 $t_{su}$ 内变化，采样结果不确定。
**保持时间 $t_h$（hold time）**：数据 $D$ 必须在时钟上升沿**之后**继续稳定的一段时间。若 $D$ 过早变化，采样同样失败。
**传输延迟 $t_{pd}$（propagation delay）**：从时钟上升沿到输出 $Q$ 稳定为新值之间的时间。也分 $t_{pd}^{0}$（输出变 0）与 $t_{pd}^{1}$（输出变 1）。

三个参数的数量级（CMOS 工艺）：$t_{su}$ 约几十皮秒到几百皮秒，$t_h$ 约几皮秒到几十皮秒，$t_{pd}$ 与 $t_{su}$ 同量级。<span class="marginnote">直觉比喻：<strong>建立时间 = 「拍照前要摆好姿势」，保持时间 = 「快门落下后不能马上动」，传输延迟 = 「照片洗出来要的时间」</strong>。三个参数合起来定义了「一次可靠的拍照（采样）」的完整窗口。</span>

## 2 时序图与约束的含义

用波形图理解：时钟上升沿是「采样时刻」，$D$ 必须在它前后各留出一段稳定区。

```text
      ┌─────┐     ┌─────┐     ┌─────┐
clk ──┘     └─────┘     └─────┘     └─────
      ┌───────────┐   ┌───────────┐
D  ───┘           └───┘           └─────────
      │←─ t_su ──→│←─ t_h ─→│
      ↑                   ↑
   采样边沿           D 可变化
```

**违反建立时间**：$D$ 在边沿前太晚才稳定，触发器「来不及看清」——采样到旧值或亚稳态。
**违反保持时间**：$D$ 在边沿后立刻变化，触发器「还没锁牢」——同样出错。

为什么 $D$ 会变？因为 $D$ 通常来自**上一级触发器的输出**，而上一级输出有自己的传输延迟。两级之间的时序关系，正是约束时钟频率的核心。<span class="marginnote">建立/保持时间在现代 EDA 里由静态时序分析（STA）自动检查，违反会报 <strong>setup/hold violation</strong>。<strong>建立时间违反通常靠降频或优化逻辑路径解决，保持时间违反常靠加缓冲（延迟数据）解决</strong>——这两条经验是所有数字后端工程师的常识。</span>

## 3 公式解析：最大时钟频率的约束

两个触发器级联（前级的 $Q_1$ 经组合逻辑 $T_{comb}$ 送到后级的 $D_2$），后级要可靠采样，必须满足：

$$T_{clk} \ge t_{su} + t_{pd} + t_{comb,max}$$

**第一步，看路径延迟**：时钟上升沿触发前级，前级输出经过 $t_{pd}$ 才稳定，再经过组合逻辑 $t_{comb}$ 才到后级输入 $D_2$。这整条路径的延迟是 $t_{pd} + t_{comb}$。

**第二步，加建立时间**：$D_2$ 必须在该路径延迟完成后、下一个边沿之前再稳定 $t_{su}$ 的时间。于是「边沿到边沿」的时间 $T_{clk}$ 至少为 $t_{pd}+t_{comb}+t_{su}$。

**第三步，求最大频率**：

$$f_{max} = \frac{1}{T_{clk,min}} = \frac{1}{t_{su} + t_{pd} + t_{comb,max}}$$

**第四步，读结论**：**组合逻辑越深（$t_{comb}$ 越大），能跑的时钟越慢**。这就是为什么 CPU 要流水线——把长组合路径切开，每段 $t_{comb}$ 变短，$f_{max}$ 提高。<span class="marginnote">这条公式是整个数字时序设计的核心不等式，也是为什么「<strong>关键路径（critical path）</strong>」决定芯片主频——芯片能跑多快，取决于最慢的那条组合路径。流水线、逻辑优化、寄存器重定时，全都在缩短关键路径。</span>

## 4 保持时间：一个被忽略的约束

建立时间约束大家记得牢，**保持时间**却常被忽略。它的约束与时钟频率**无关**：

$$t_h \le t_{pd,min} + t_{comb,min}$$

**解读**：后级 $D_2$ 必须在边沿后保持 $t_h$ 稳定；但前级输出可能在 $t_{pd,min} + t_{comb,min}$ 之后就开始变化（最小延迟路径）。若最小延迟太短（比如前级到后级只是一根导线），新数据可能**提前**冲到 $D_2$，破坏保持时间。

**关键推论**：**保持时间违反不能靠降频解决**——因为它是「数据变太快」，不是「时钟太快」。解法只能是**加延迟**（在数据路径上串缓冲器）或保证寄存器间最小延迟足够。<span class="marginnote">这就是为什么数字后端有个专门步骤叫「<strong>保持时间修复（hold fixing）</strong>」——在快速路径上插缓冲器。它靠加延迟而非降频，与建立时间违反的处理完全不同。</span>

**辨析｜易错点：** 建立时间与保持时间的约束方向相反：建立时间要求「数据别太晚」，保持时间要求「数据别太早」。前者限制了 $f_{max}$，后者与频率无关。考试/面试必考这组对比。

## 5 亚稳态：违反时序的后果

当建立/保持时间被违反，触发器可能进入**亚稳态（metastability）**：输出卡在 0 与 1 之间的中间电平，持续一段不确定的时间后才落到某个稳态——**且落向哪个稳态不可预测**。

亚稳态的危害：

输出既不是 0 也不是 1，后级电路可能各自读出不同值，系统逻辑混乱。
亚稳态持续的时间可能超过一个时钟周期，错误被传播。
无法通过「多等一会儿」彻底避免——它本质上是一个随机过程。

**工程对策**：

**同步器（synchronizer）**：对异步输入用两级（或更多级）触发器串联，第一级亚稳态、第二级在下一个边沿「重新采样」，极大降低亚稳态传播概率。
**保证建立/保持时间**：所有同步路径通过 STA 检查，确保时序收敛。<span class="marginnote">亚稳态是跨时钟域（CDC）设计的头号公敌：<strong>不同时钟域的信号直接采样，几乎必然触发亚稳态</strong>。同步器、FIFO、握手协议都是 CDC 的经典对策——这在分布式系统、多时钟 SoC 里是必修课。</span>

## 6 时序分析的工程框架：从参数到收敛

三个时间参数怎么在真实设计中用起来？把工程框架搭一遍。

**建立时间检查（setup check）**：时序分析工具对每条「寄存器 → 组合 → 寄存器」路径做检查：

$$t_{arrival} \le t_{required} \quad \Rightarrow \quad t_{pd} + t_{comb} + t_{su} \le T_{clk}$$

不满足 → **setup violation**。常见解法：降频（放大 $T_{clk}$）、缩短组合路径（逻辑优化）、流水线切段。

**保持时间检查（hold check）**：

$$t_{pd,min} + t_{comb,min} \ge t_h$$

不满足 → **hold violation**。解法：数据路径加缓冲（增大最小延迟）。**注意：hold 违反与频率无关，降频无效**——这是它最迷惑人的地方。

**静态时序分析（STA）**：工具遍历所有路径，逐条做 setup/hold 检查，报告「最差路径（关键路径）」与「时序裕量（slack）」。slack 为正 = 满足，为负 = 违例。

**时序收敛的工程流程**：

1. 综合后做 STA，看哪些路径 slack 为负。
2. 优化逻辑（缩短关键路径）或调整约束。
3. 布局布线后重做 STA（布线延迟加入）。
4. 迭代直到全部路径 slack > 0。

**为什么理解这三个参数**：没有它们，你只能「凭感觉」判断电路快慢；有了它们，你能精确回答「这个设计能不能跑到 500 MHz」——答案是算出来的，不是猜出来的。现代 FPGA/ASIC 工程师的日常，就是跟这三个参数打交道。

**辨析｜易错点：** setup 与 hold 的检查方向相反、解法相反——setup 靠「缩短数据路径/降频」，hold 靠「加长数据路径」。把两者混淆是时序分析的第一大错误。

## 7 小结

- **建立时间 $t_{su}$**：边沿前数据需稳定；**保持时间 $t_h$**：边沿后数据需稳定；**传输延迟 $t_{pd}$**：边沿到输出的延迟。
- 最大时钟频率 $f_{max} = 1/(t_{su}+t_{pd}+t_{comb,max})$——组合路径越深，主频越低。
- 保持时间约束 $t_h \le t_{pd,min}+t_{comb,min}$，**与频率无关**，违反靠加延迟修复。
- 违反时序 → **亚稳态**：输出不确定且可能传播；用同步器（双级触发器）等对策缓解。
- 关键路径决定芯片主频，流水线通过缩短关键路径提升 $f_{max}$。
