## 为什么从组合逻辑电路开始

单个门电路是「词」，组合逻辑电路是「句子」——把若干个门连起来，实现一个完整功能（加法、译码、选择），这就是数字系统的第一层建筑。与后面要学的时序电路不同，**组合逻辑电路没有记忆**：输出只取决于当前输入，与电路的历史无关。<span class="marginnote">「无记忆」是组合逻辑的分水岭：<strong>它对应逻辑代数里纯粹的布尔函数</strong>，可以完全用真值表描述，不需要时钟、不需要状态。相比之下，时序电路（第五、六篇）才有「记忆」能力。</span>这一节先建立组合电路的整体框架：它长什么样、用什么描述、有哪些分类。

## 1 组合逻辑电路的定义

**组合逻辑电路（combinational logic circuit）**：任一时刻的输出稳定值，仅由该时刻的输入决定，与电路过去的状态无关。它的三个结构特征是：

1. **由逻辑门组成，不含记忆元件**（无触发器、无电容存储节点）。
2. **输入到输出是单向的**：信号从输入流向输出，没有反馈回路。
3. **输出是输入的纯布尔函数**：$Y_i = F_i(X_1, X_2, \dots, X_n)$。

**辨析｜易错点：** 判断一个电路是不是组合逻辑，关键是看两条：**有没有反馈回路**、**有没有记忆元件**。哪怕电路中含非门形成「看似循环」的结构（如两个交叉耦合的非门），只要存在反馈，它就不是组合电路而是时序电路——这正是第五篇触发器的基础。实际电路即使有延迟，只要无反馈、无存储，逻辑上仍是组合电路。

## 2 组合逻辑的功能描述

组合逻辑的功能可以用四种方式描述，与逻辑函数表示方法一一对应：

| 描述方式 | 内容 | 适用场景 |
|---|---|---|
| 逻辑函数式 | $Y = AB + \overline{A}C$ | 代数化简、实现 |
| 真值表 | 列出 $2^n$ 种输入组合的输出 | 功能定义、验证 |
| 逻辑图 | 门级连线图 | 物理实现 |
| 波形图/卡诺图 | 时序行为 / 几何化简 | 调试、化简 |

设计流程的经典闭环：**需求 → 真值表 → 逻辑式（化简）→ 逻辑图 → 验证**。这也是下一节「分析方法」与下下节「设计方法」要系统化的主线。<span class="marginnote">在工业界，这个流程的前半段（真值表→逻辑式→化简）已被 EDA 综合工具接管：你写 Verilog 逻辑表达式，综合器自动完成化简与映射。但理解底层手工流程，仍是读懂综合报告、排查问题的前提。</span>

## 3 组合逻辑的分类

从功能与规模两个维度，组合电路可以有多种分类：

**按功能**：编码器、译码器、数据选择器、数据分配器、加法器、数值比较器、奇偶校验电路、算术逻辑单元（ALU）等——它们是大规模组合电路的标准「零件库」。

**按集成度（SSI → LSI）**：

| 集成度 | 门的数量级 | 典型器件 |
|---|---|---|
| SSI（小规模） | 1~10 门 | 基本门、触发器 |
| MSI（中规模） | 10~100 门 | 译码器、选择器、加法器 |
| LSI（大规模） | 100~万门 | ROM、PLA、存储器 |

<span class="marginnote">MSI 是个关键的分界线：<strong>中规模器件（74LS138 译码器、74LS151 选择器等）是模块化设计的积木</strong>，第四篇后段会专门讲「用 MSI 设计组合逻辑」——不追求用最小门数，而是用现成的标准模块快速拼出系统，这在工程上往往比纯化简更高效。</span>

## 4 公式解析：从真值表到逻辑式的标准翻译

组合电路设计的起点是真值表，翻译成逻辑式的规则我们已经熟悉，但值得用组合电路的视角再走一遍。设一个三输入组合电路，输出为 1 的行是 $m_1,m_3,m_5,m_7$：

$$
Y = \sum m(1,3,5,7) = \overline{A}\overline{B}C + \overline{A}BC + A\overline{B}C + ABC
$$

**第一步，逐行翻译**：每一行输出 1 的最小项写成与项（取 1 写原变量、取 0 写反变量）。

**第二步，并项化简**：四对相邻最小项两两并项：
$$\overline{A}\overline{B}C + \overline{A}BC = \overline{A}C, \qquad A\overline{B}C + ABC = AC$$

**第三步，提出公因子**：
$$Y = \overline{A}C + AC = C(\overline{A} + A) = C$$

**第四步，物理意义**：化简后 $Y=C$ 意味着——这个电路的实际行为就是「$Y$ 恒等于 $C$」，前面三个输入中 $A$、$B$ 对输出毫无影响。<span class="marginnote">这提示一个组合电路设计的重要经验：<strong>写完逻辑式务必化简</strong>——不化简可能做出三四个门，化简后可能只剩一根导线。化简不仅是省元件，更是「看懂函数本质」的过程。</span>

## 5 组合逻辑与后续篇章的接口

组合逻辑不是孤立的一章，它与全书处处相连：

**卡诺图**（第二篇）是组合逻辑化简的武器；
**门电路**（第三篇）是组合逻辑的物理载体；
**触发器与时序电路**（第五、六篇）里，组合逻辑仍以「次态方程」「输出方程」的形式存在——时序电路 = 组合逻辑 + 记忆元件；
**Verilog**（第十一篇）里 assign 语句描述的正是组合逻辑；
**ALU**（第十二篇）是组合逻辑电路的最高成就之一：一个能算加、减、与、或的模块。

<span class="marginnote">可以说，组合逻辑是数字系统的「纯计算」部分，而时序逻辑是「记忆+控制」部分。一台 CPU 的运算器几乎全是组合逻辑，控制器则大量使用时序逻辑。</span>

## 6 组合逻辑的延迟与关键路径

组合逻辑不只是「真值表」，它的**延迟**在真实系统里同样关键：

**传输延迟的累积**：信号每经过一级门就有一次延迟。一个 $n$ 级组合逻辑的总延迟约 $n \times t_{pd}$——门越深，延迟越大。这就是为什么化简（减少级数）不仅是省元件，更是提速度。

**关键路径（critical path）**：组合电路中**最长**的延迟路径决定整个模块能跑多快。优化组合逻辑 = 缩短关键路径——要么减少级数，要么用更快门的替换关键路径上的慢门。

**延迟与功耗的权衡**：减少级数通常省延迟，但可能增加扇出（一个门带更多负载）、增加功耗。组合逻辑设计处处是「延迟 × 面积 × 功耗」的三角权衡。

**组合延迟与时钟**：在时序系统里，组合逻辑的延迟必须小于时钟周期减去建立时间（第五篇的公式）——否则触发器采不到稳定值。**「组合逻辑能多长」由时钟频率决定**，这是组合逻辑与时序逻辑衔接的桥梁。

**工程度量**：EDA 工具会报告「关键路径延迟」，综合器以它为目标优化。设计者通过化简、流水线、逻辑复制等手段压低关键路径——这些手段的数学基础，正是组合逻辑的延迟模型。

**辨析｜易错点：** 「逻辑正确」不等于「速度达标」——一个正确但关键路径超长的组合电路，在时序系统里无法工作。设计组合逻辑时，「正确性」与「速度」要同时考虑，缺一不可。

## 7 组合逻辑设计的完整流程回顾

把组合逻辑从需求到实现的完整流程串一遍，作为本章的总纲：

```text
需求分析 → 逻辑抽象 → 真值表 → 逻辑式（化简）→ 选器件 → 验证
```

**每一步的关键**：

1. **需求分析**：搞清输入输出、逻辑语义。
2. **逻辑抽象**：定变量、定正负逻辑、标无关项。
3. **真值表**：穷举全部组合，无遗漏。
4. **逻辑式**：从真值表翻译（或直接写卡诺图）。
5. **化简**：公式法/卡诺图法，利用无关项。
6. **选器件**：门电路 / MSI（译码器/MUX）/ 存储器 / PLD。
7. **验证**：真值表核对、仿真。

**流程的「分叉点」在「选器件」**：

- 简单函数 → 门电路。
- 标准功能（译码/选择/加法）→ MSI。
- 复杂/多输出 → 存储器或 PLD。

**为什么「先化简再选器件」**：化简让函数形式清晰，选器件才有的放矢——化简后的与-或式适合门电路，最小项形式适合译码器，真值表形式适合 ROM。**化简是「翻译」成目标器件语言的前置步骤**。

**现代流程**：EDA 工具把「需求 → HDL → 综合 → 实现」自动化——但理解手工流程，才能读懂工具行为、排查综合问题。这一篇的「手算流程」是理解「工具流程」的地基。

**辨析｜易错点：** 「验证」不是最后一步的奢侈品，而是贯穿全程的习惯——每写一步（真值表、逻辑式、化简）都该回头验证。等全部做完再验证，出错时难以定位到哪一步。逐步验证比一次验证高效得多。

## 8 小结

- 组合逻辑：输出仅由当前输入决定，**无记忆、无反馈、纯布尔函数**。
- 描述方式：逻辑式、真值表、逻辑图、波形图；设计主线为「真值表→逻辑式→逻辑图」。
- 按功能分有编码器、译码器、选择器、加法器、比较器等；按集成度分 SSI/MSI/LSI。
- 从真值表翻译逻辑式并化简，是设计的第一步，也是「看懂电路」的必经之路。
- 组合逻辑 + 记忆元件 = 时序逻辑；ALU 是组合逻辑的集大成者。

在下一节，我们将学习「读电路」的本领——给定一个组合逻辑电路，如何一步步分析出它的逻辑功能，这就是组合逻辑电路的分析方法。
