## 为什么从 ROM 开始

ROM 是「出厂就定好内容」的只读存储器，它的本质是一个**巨大的查找表**：给定地址（输入），输出固定的数据（内容）。这层「查找表」本质让它不仅能存数据，还能**实现组合逻辑函数**——这是第八篇最后的重要应用。<span class="marginnote">ROM 的数学本质：<strong>地址 → 数据的固定映射，就是真值表</strong>。$n$ 位地址、$m$ 位数据，就是一个 $2^n \times m$ 的真值表。所以「用 ROM 实现逻辑函数」在数学上是顺理成章的——它把函数表直接做成存储器。</span>这一节讲 ROM 的结构、分类与工作原理。

## 1 ROM 的结构：地址译码 + 存储阵列 + 输出

一个 ROM 芯片的内部由三部分组成：

1. **地址译码器**：把 $n$ 位地址译成 $2^n$ 条字线（选择存储行）。
2. **存储阵列**：$2^n \times m$ 的存储单元矩阵，每个单元存 0 或 1。
3. **输出缓冲**：把选中行的 $m$ 位数据送到数据线 $D_{m-1}\sim D_0$。

结构示意：地址 $A_{n-1}\dots A_0$ → 译码器 → 选中一行 → 该行的 $m$ 位内容 → 输出。

**容量表示**：$2^n \times m$ bit。例如 8 位地址、8 位数据 = $256 \times 8 = 2\,\text{Kbit}$。<span class="marginnote">容量记法：<strong>$2^n \times m$ 中 $2^n$ 是地址数（字数）、$m$ 是每字位数</strong>。如「32K×8」表示 $32\times1024$ 个字、每字 8 位，共 256 Kbit。读容量时要看清「字数 × 位数」两项。</span>

## 2 固定 ROM（掩膜 ROM）

**固定 ROM（mask ROM）**：数据在**制造时**用掩膜固定，出厂后**不能修改**。

制造工艺：存储单元的「有/无晶体管」由掩膜决定，代表 1/0。
优点：成本最低（大批量时）、可靠性高。
缺点：一次性定型，改内容要改掩膜，周期长、只适合大批量定型产品。

典型应用：大批量的字符库、固件、微码。<span class="marginnote">掩膜 ROM 是「<strong>用工艺当笔</strong>」：光刻掩膜上的图案直接决定每个单元是 1 还是 0。它的成本结构是「一次掩膜费高、单片复制费极低」——所以只有百万级出货才划算。</span>

## 3 PROM：一次可编程 ROM

**PROM（Programmable ROM，可编程只读存储器）**：出厂时内容全为 1（或全 0），用户用**编程器**一次性写入，写后不能再改。

编程原理：每个单元串一个**熔丝（fuse）**或**反熔丝**。编程时对要写 0 的单元通大电流烧断熔丝（或击穿反熔丝）。
一次编程、不可恢复：烧断的熔丝不能接回。
优点：用户可自定义内容，适合中小批量、需要特定内容的场合。
缺点：只能写一次，写错就报废。

**辨析｜易错点：** PROM 与掩膜 ROM 的区别在「谁决定内容」——掩膜 ROM 由工厂决定，PROM 由用户决定。但两者都「只能写一次」。要「可擦除重写」，需要下一节的 EPROM 与 E²PROM。

## 4 公式解析：ROM 作为查找表实现逻辑

ROM 最漂亮的数学性质：**用 $2^n \times m$ ROM 可实现 $m$ 个 $n$ 变量逻辑函数**。因为 ROM 的地址译码输出全部最小项，存储阵列记录每个最小项对应的输出。

**例题**：用 ROM 实现 $Y_1 = \sum m(1,3,5)$、$Y_2 = \sum m(0,2,6)$（三变量）。

**第一步，定地址与数据位**：地址 $A_2A_1A_0$，数据 $D_1D_0$ 对应 $Y_1Y_2$。

**第二步，填 ROM 内容表**：

| 地址 $A_2A_1A_0$ | $D_1 = Y_1$ | $D_0 = Y_2$ |
|---|---|---|
| 000 | 0 | 1 |
| 001 | 1 | 0 |
| 010 | 0 | 1 |
| 011 | 1 | 0 |
| 100 | 0 | 0 |
| 101 | 1 | 0 |
| 110 | 0 | 1 |
| 111 | 0 | 0 |

**第三步，编程**：把这张表烧进 PROM（或写入 ROM），地址输入变量，数据输出即函数值。

**第四步，结论**：**ROM 免化简、免画门**——真值表直接变成存储内容。这是「用存储器实现组合逻辑」的基本原理（8.6 会系统讲）。<span class="marginnote">ROM 实现逻辑 vs 门电路：<strong>ROM 把「逻辑」变成「查表」，速度由存取时间决定、与函数复杂度无关</strong>。代价是面积大（$2^n \times m$ 个单元全要造）。这就是「用容量换逻辑」——PLD/FPGA 里的查找表（LUT）正是同一思想的现代实现。</span>

## 5 ROM 的选择与工程注意

**选型**：大批量定型 → 掩膜 ROM；小批量自定义 → PROM 或可擦写 ROM（下节）。
**时序**：ROM 是组合性的——地址稳定后经过**存取时间**，数据输出稳定。没有时钟，像组合逻辑一样「地址进、数据出」。
**应用**：查表（正弦表、对数表）、字符发生器、微码存储、启动代码。

**辨析｜易错点：** ROM 没有「写」时序（正常工作时），但它**不是触发器**——它的输出是地址的组合函数（带存取延迟），本质上是大规模组合电路。把它当「真值表存储器」理解，最不容易错。<span class="marginnote">一句话：<strong>ROM = 被固化的真值表</strong>。地址是输入，数据是输出，内容是出厂/编程时写死的。这层「真值表」心智模型，到 8.6「用存储器实现组合逻辑」会完全兑现。</span>

## 6 ROM 的读取时序与应用实例

ROM 是组合性器件，它的使用关键是读懂读取时序。

**读取时序**：地址稳定后，经过**存取时间 $t_{acc}$**，数据才稳定输出。这期间数据线先处于高阻（或旧值），$t_{acc}$ 后变成地址对应的内容。与 RAM 不同，ROM **没有写时序**（正常工作），只有读时序。

**应用实例：正弦查表**。用 ROM 实现正弦函数：把 $0\sim90^\circ$ 的正弦值量化成 8 位，按角度地址存入 ROM。

- 地址 = 角度编码（如 256 个点 → 8 位地址）。
- 数据 = 正弦值（8 位）。
- 输入角度 → 查表 → 输出正弦值。

**优点**：一个 ROM + 一个计数器，就能生成正弦波——数字频率合成（DDS）的雏形。改变步进（每拍地址加几），就改变输出频率。查表代替计算，速度快、无浮点。

**其他查表应用**：对数表（乘除变加减）、伽马校正表（图像处理）、编码转换表（格雷码 ↔ 二进制）。凡「函数值可预计算」的地方，ROM 都能把计算变成查表。

**辨析｜易错点：** ROM 查表的精度受两个限制——地址位数（角度分辨率）与数据位数（幅度分辨率）。要更高精度就加大 ROM（更多地址位 × 更多数据位），这是「用容量换精度」。工程上需在精度与 ROM 容量之间权衡，必要时用「查表 + 插值」折中。

## 7 ROM 与 RAM 的全面对比

ROM 与 RAM 常被并列提及，理清它们的边界很重要：

| 对比 | ROM | RAM |
| --- | --- | --- |
| 读写能力 | 以读为主（可编程写） | 可读可写 |
| 易失性 | 非易失（断电保留） | 易失（断电丢失） |
| 用途 | 固件、查表、启动 | 运行数据、程序 |
| 写入方式 | 出厂/编程器/擦写 | 随时读写 |
| 速度 | 较快（读） | 快（读）快（写） |
| 典型 | 掩膜 ROM、PROM、Flash | SRAM、DRAM |

**「ROM 是 RAM 的一部分」吗**：不——两者是「只读为主」与「可读可写」的分类，不是包含关系。ROM 能读也能（特定方式）写，RAM 能读写——区分标准是「正常工作时能否随意写」与「断电是否保留」。

**现代边界的模糊**：Flash 既能读又能写、还非易失——它模糊了 ROM/RAM 的边界。这也是为什么现代用「非易失存储」取代「ROM」的叫法（8.3 讲过）。

**从系统看**：一台设备的存储分工——启动代码在 Flash（非易失、上电即读）、运行程序在 DRAM（大容量、可读写）、热点数据在 SRAM 缓存（高速）——ROM 与 RAM 各司其职，共同构成存储层次（8.1）。

**为什么 ROM 仍在「随机存取」行列**：ROM 也是随机存取（读任何地址一样快）——「随机存取」与「只读」是两个正交维度。理解这点，就不会被「ROM 也是 RAM（随机存取存储器）」绕晕——R 的含义是 Random 而非 Read。

**辨析｜易错点：** 「RAM = 可读写」是通俗理解，严格定义「随机存取」指「访问时间与地址无关」——ROM 也满足。真正区分 ROM/RAM 的是「易失性 + 可写性」，不是「随机」二字。这个抠字眼是经典考点。

## 8 小结

- ROM 结构：地址译码器 + 存储阵列 + 输出缓冲，$2^n \times m$ bit。
- **掩膜 ROM**：制造时定型，成本低只适大批量，不可改。
- **PROM**：熔丝/反熔丝，用户一次编程，写后不可改。
- ROM 是**固化的真值表**，可实现任意 $n$ 变量组合逻辑（免化简、查表实现）。
- ROM 是组合性器件，输出 = 地址的函数（带存取延迟）。

在下一节，我们将认识「能擦」的 ROM——EPROM、E²PROM 与 Flash Memory，它们让「固件更新」成为可能。
