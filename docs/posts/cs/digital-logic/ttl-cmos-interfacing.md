## 为什么从接口与注意事项开始

TTL 与 CMOS 各有拥趸，但真实系统从来不是单一逻辑家族的天下：一块板上可能同时有 5 V 的 TTL 芯片、3.3 V 的 CMOS 芯片，它们的电平标准、驱动能力、输入结构各不相同。**接口（interface）**要解决的就是：两种家族（或不同电源电压）的器件直接相连时，能否可靠传输逻辑电平。<span class="marginnote">接口设计失败的典型症状：输出高电平不够高、接收门误判、电流超限烧管子、电平转换后信号畸变。<strong>每一对「驱动门→接收门」都要做一次电平核对</strong>，这是硬件工程师的日常纪律。</span>这一节给出接口判据、几种经典接法，以及 TTL/CMOS 使用时的红绿灯清单。

## 1 接口判据：电压对齐与电流对齐

两个门能否直接相连，看两件事——**电压匹配**与**电流匹配**：

**电压判据**（驱动门输出必须落在接收门判定区间内）：

$$\text{驱动 } V_{OH} \ge \text{接收 } V_{IH}, \qquad \text{驱动 } V_{OL} \le \text{接收 } V_{IL}$$

**电流判据**（驱动门输出能力必须大于接收门需求）：

$$\text{驱动 } I_{OH} \ge \sum \text{接收 } I_{IH}, \qquad \text{驱动 } I_{OL} \ge \sum \text{接收 } I_{IL}$$

两条判据都满足，接口才可靠。其中电压判据是前提，电流判据决定扇出。<span class="marginnote">这套判据是普适的：无论是 TTL→CMOS、CMOS→TTL，还是 5 V→3.3 V 跨电压接口，判断方法都是查数据手册、套这两组不等式。表格：</span>

| 判据 | 含义 | 失效后果 |
|---|---|---|
| $V_{OH} \ge V_{IH}$ | 高电平够高 | 接收门把 1 误判成 0 |
| $V_{OL} \le V_{IL}$ | 低电平够低 | 接收门把 0 误判成 1 |
| $I_{OH}$、$I_{OL}$ 充足 | 电流能力够 | 电平被拉偏、甚至损坏 |

## 2 典型接口：TTL 驱动 CMOS 与 CMOS 驱动 TTL

**① TTL 驱动 CMOS（同电源电压 $5\,\text{V}$）**——直接相连有问题：

- 74TTL 的 $V_{OH(min)} = 2.4\,\text{V}$，而 74HC CMOS 的 $V_{IH(min)} \approx 3.5\,\text{V}$（约 0.7$V_{DD}$）。**电压判据失败**：TTL 的高电平不够高，CMOS 可能识别不了 1。

解决办法有三：

- **接上拉电阻到 $V_{DD}$**：把 TTL 高电平拉到接近 5 V，这是最常用的补丁（电阻取 $1\sim10\,\text{k}\Omega$）。
- **换用带电平转换的接口门**：如缓冲器/电平转换芯片。
- **用 TTL 的 OC 门 + 上拉**：OC 门上拉电阻直接接 $V_{DD}$，把高电平彻底拉到 5 V。

**② CMOS 驱动 TTL（同电源 $5\,\text{V}$）**——直接相连基本可以：

- CMOS 输出满摆幅（$V_{OH}\approx 5\,\text{V}$、$V_{OL}\approx 0\,\text{V}$），电压判据轻松满足。
- 但 TTL 输入低电平时灌电流大（$I_{IL}\approx 1.6\,\text{mA}$），而早期 4000 系列 CMOS 的输出能力弱，可能带不动。此时需用**CMOS 缓冲器**增强驱动，或改用驱动能力强的 HC/HCT 系列。

**③ 5 V TTL 驱动 3.3 V CMOS（跨电压）**——绝对不能直接连：

- 5 V 的高电平会**超过 3.3 V CMOS 的电源电压与输入耐压**，可能损坏器件。必须用**电平转换芯片**或**分压/钳位**（如电阻分压、二极管钳位、OC/OD 门加上拉电阻到 3.3 V）。<span class="marginnote">「跨电压接口」在今天的板卡上无处不在：CPU/FPGA 的 IO 是 1.8/3.3 V，外设可能是 5 V。电平转换不仅是电压问题，还有 <strong>耐压与闩锁（latch-up）风险</strong>——输入电压高于 $V_{DD}$ 可能触发寄生可控硅，烧毁芯片。</span>

## 3 使用注意事项：TTL 与 CMOS 的红绿灯

**TTL 使用要点：**

- **输入端悬空等效于接高电平**（多发射极输入级），因此**悬空输入 = 逻辑 1**。但悬空易受干扰，工程上应把不用的输入端**接高电平或接地**（直接接 $V_{CC}$ 或经电阻），不要留空。
- **电源去耦**：TTL 翻转时电流尖峰大，每个芯片的电源脚旁要放 0.1 µF 去耦电容。
- **扇出限制**：低电平灌电流 1.6 mA/门，注意总负载不超过 $I_{OL}$。

**CMOS 使用要点：**

- **输入端绝不允许悬空**——CMOS 栅极阻抗极高，悬空时栅极电压漂移，可能使 NMOS/PMOS 同时导通、甚至损坏。**不用的输入必须接 $V_{DD}$ 或地**（不能悬空），这是 CMOS 与 TTL 最大的使用差异。<span class="marginnote">CMOS 悬空输入还可能因静电积累击穿栅氧化层——CMOS 器件对静电（ESD）尤其敏感，拿取时要注意防静电手环、避免手直接摸引脚。</span>
- **电源极性**：$V_{DD}$ 与地不能接反，否则寄生二极管导通烧毁芯片。
- **闩锁效应**：输入/输出电压超过电源范围时可能触发闩锁，导致芯片「锁死」并烧毁——设计接口时注意钳位保护。

## 4 公式解析：上拉电阻修复 TTL→CMOS 接口

TTL 驱动 CMOS 最常用的补救是上拉电阻，它的取值要满足两个条件。设 $V_{CC}=V_{DD}=5\,\text{V}$，TTL 输出漏电流 $I_{OH(漏)}=250\,\mu\text{A}$，CMOS 输入漏电流 $I_{IH}=1\,\mu\text{A}$，要求高电平 $\ge 3.5\,\text{V}$：

**第一步，算上限（保证高电平够高）**：TTL 截止时输出靠 $R$ 拉高，最坏情形是 TTL 漏电流加 CMOS 输入漏电流全流过 $R$，压降不能超过 $5-3.5=1.5\,\text{V}$：

$$R_{max} = \frac{5 - 3.5}{250\,\mu\text{A} + 1\,\mu\text{A}} \approx 6\,\text{k}\Omega$$

**第二步，算下限（保证低电平够低）**：TTL 导通输出低电平时，$R$ 会向 TTL 灌入额外电流，此电流加上 CMOS 输入漏电流不能使 TTL 输出超过 $V_{OL(max)}=0.4\,\text{V}$。一般取 $R \ge 300\,\Omega$ 左右即可，故下限远小于上限。

**第三步，取折中**：工程上取 $R \approx 1\sim3.3\,\text{k}\Omega$，既保证高电平拉得足够高，又不过度增加低电平电流。<span class="marginnote">这条计算与 OC/OD 门上拉电阻的计算同源——<strong>「高电平靠电阻拉、低电平靠管子灌」的统一模型</strong>。吃透这一个模型，TTL→CMOS、OC 门、OD 门、I²C 总线的上拉电阻就都会选了。</span>

## 5 电平转换的完整方案对比

跨电压接口（5V ↔ 3.3V、3.3V ↔ 1.8V）是今天的常态，几种方案对比：

| 方案 | 原理 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 专用电平转换芯片 | 双向缓冲器（如 TXS0108） | 可靠、自动双向 | 贵、占面积 |
| 分压电阻 | 电阻分压降压 | 简单、便宜 | 单向、慢、有静态功耗 |
| 二极管钳位 | 二极管限制高压 | 简单 | 单向、速度受限 |
| OC/OD 门 + 上拉 | 开路输出接目标电源 | 干净、电平由上拉决定 | 只适合开路输出 |
| MOSFET 双向转换 | 单管双向（如 BSS138） | 双向、低成本 | 速度受 RC 限制 |

**选型原则**：

- **频率低、单向**：分压电阻或二极管钳位即可。
- **双向、中速**：专用转换芯片或 MOSFET 双向电路。
- **总线型（I²C 等）**：OC/OD 门 + 上拉天然适配（开漏本来就是线与）。

**为什么不能简单串联电阻**：电阻分压会降低驱动能力、且高阻节点易受干扰；对双向信号，分压还破坏方向性。所以跨电平「看起来简单」，实际要靠专用电路。

**闩锁防护的补充**：跨电压接口除电平问题外，还要防**闩锁**——输入电压高于 $V_{DD}$ 会触发寄生可控硅导通，短路电源。防护手段：输入串电阻限流、加钳位二极管、选择带闩锁保护的器件。这是跨电压设计的「隐形雷区」。

**辨析｜易错点：** 电平转换 ≠ 电平匹配。匹配是「同电压不同逻辑族」的对齐（如 TTL 5V → CMOS 5V），转换是「不同电压」的搬移（如 5V → 3.3V）。两者都要电压对齐判据，但转换还涉及耐压与闩锁，更复杂。

## 6 小结

- 接口判据两条：**电压对齐**（$V_{OH}\ge V_{IH}$、$V_{OL}\le V_{IL}$）与**电流对齐**（扇出充足）。
- **TTL→CMOS** 常需上拉电阻抬高电平；**CMOS→TTL** 注意驱动能力；**跨电压**必须电平转换并防闩锁。
- TTL 输入悬空当 1，可用但易受扰；CMOS 输入**严禁悬空**，必须接电源或地。
- CMOS 对 ESD 敏感、怕电源接反、怕闩锁；TTL 要重视电源去耦与扇出。
- 上拉电阻的「高电平靠电阻、低电平靠管子」模型贯穿所有开路输出接口设计。
