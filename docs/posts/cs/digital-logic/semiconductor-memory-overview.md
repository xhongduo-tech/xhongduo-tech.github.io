## 为什么从半导体存储器开始

数字系统的三大件是「算、控、存」——前面讲完了算（组合逻辑）与控（时序逻辑），这一篇讲**存**。半导体存储器是所有程序的安身之所：没有它，CPU 再快也只能算一遍。理解存储器的分类、结构与工作原理，是理解计算机存储体系（内存、缓存、固件）的第一站。<span class="marginnote">存储器的核心指标是「<strong>能不能写、掉电保不保、快不快、贵不贵</strong>」。这四个问题构成了存储器的分类学——ROM vs RAM、SRAM vs DRAM、易失 vs 非易失。这一节先搭好这张分类地图，后面几节逐个深入。</span>

## 1 存储器的基本概念与指标

**存储器**按层次可分为：

- **半导体存储器**（本章）：用集成电路工艺做在芯片上的存储，速度快、容量适中，用于内存、缓存、固件。
- **磁存储**（硬盘、磁带）：容量大、速度慢，非易失。
- **光存储**（光盘）与 **Flash/固态**：介于两者之间。

衡量存储器性能的四项指标：

| 指标 | 含义 |
|---|---|
| 存储容量 | 能存多少位，如 $2^n \times m$ bit |
| 存取时间 | 读/写一次的时间 |
| 功耗 | 运行时耗电 |
| 价格/位 | 单位存储成本 |

<span class="marginnote">存储器的经典矛盾：<strong>越快越贵、越贵容量越小</strong>。计算机用「存储层次」化解这个矛盾：寄存器（最快最小）→ 缓存 → 内存 → 硬盘（最慢最大）——用「快的小的缓存慢的大」的局部性原理逼近「又大又快」。这是《计算机组成原理》的核心内容。</span>

## 2 按存储功能分类：ROM 与 RAM

半导体存储器按读写能力分两大类：

**RAM（随机存取存储器，Random Access Memory）**：
- **可读可写**：运行中既读又写。
- **易失性**：断电后数据丢失。
- 用途：程序运行时的数据与代码（内存）。

**ROM（只读存储器，Read Only Memory）**：
- **以读为主**：正常工作时只能读（可编程写入但次数/条件受限）。
- **非易失性**：断电后数据保留。
- 用途：固件、启动代码、查表数据。

**辨析｜易错点：** 「随机存取」指的是**存取时间与地址无关**（任何地址读写一样快），而不是「随机读写都行」。ROM 也是随机存取的（读任意地址一样快），只是不能写。RAM 的「R」指 Random 而非 Read——这是初学者最常犯的概念错误。

## 3 RAM 的内部两大分支：SRAM 与 DRAM

RAM 又按存储单元的工作原理分两类：

**SRAM（静态随机存储器，Static RAM）**：
- 存储单元用**触发器**（交叉耦合反相器）保存数据。
- **不需要刷新**（只要供电就一直保持）。
- 速度快、功耗相对高、集成度低（一个单元 6 个晶体管）。
- 用途：CPU 缓存、寄存器堆。

**DRAM（动态随机存储器，Dynamic RAM）**：
- 存储单元用**电容**保存电荷。
- **需要周期性刷新**（电容会漏电，几毫秒要重写一次）。
- 速度慢、功耗低、集成度高（一个单元 1 管 1 容）。
- 用途：计算机主内存。

| 对比 | SRAM | DRAM |
|---|---|---|
| 存储原理 | 触发器（6 管） | 电容（1 管 1 容） |
| 需要刷新 | 否 | 是 |
| 速度 | 快 | 慢 |
| 集成度 | 低 | 高 |
| 成本/位 | 高 | 低 |
| 典型用途 | 缓存 | 主内存 |

<span class="marginnote">SRAM vs DRAM 的选择本质是「<strong>速度换容量</strong>」：SRAM 快但贵、面积大，只够做小容量的缓存；DRAM 便宜、密度高，能做大容量的主存。现代 CPU 的 L1/L2/L3 缓存全是 SRAM，而几 GB 的内存全是 DRAM。</span>

## 4 按数据存储方式分类：易失与非易失

从「断电保不保数据」角度，半导体存储器分两类：

**易失性存储器（volatile）**：断电数据丢失——RAM（SRAM/DRAM）都是易失的。

**非易失性存储器（non-volatile）**：断电数据保留——ROM 家族（掩膜 ROM、PROM、EPROM、E²PROM、Flash）都是非易失的。

Flash（闪存）的特殊地位：它介于 ROM 与 RAM 之间——**非易失但可擦写**。严格说 Flash 属于 E²PROM 的变种，但它今天几乎独立成类（U 盘、SSD、手机存储全是 Flash）。

**辨析｜易错点：** 「RAM 一定是易失的、ROM 一定是非易失的」——这句基本成立，但要注意 Flash 这类「可擦写非易失」器件既不像 RAM（不可频繁快写）也不像传统 ROM（可多次擦写）。现代设备里「ROM」往往指「存固件的 Flash」——名字是历史遗留，别被字面骗了。<span class="marginnote">存储世界的演进：<strong>「ROM」这个叫法正在被「非易失存储」取代</strong>——因为现代 ROM 几乎都是可擦写的 Flash，不再是「真的只能读」。</span>

## 5 半导体存储器在系统中的地位

存储器的选择是系统设计的关键决策：

- **固件/启动**：非易失 ROM/Flash——开机第一条指令从这里取。
- **运行内存**：DRAM——程序与数据的主战场。
- **缓存**：SRAM——弥合 CPU 与 DRAM 的速度差。
- **配置/参数**：EEPROM/Flash——掉电保存设置。

它们的配合构成完整存储体系。这一篇会依次深入：ROM 家族（8.2、8.3）→ RAM（8.4）→ 容量扩展（8.5）→ 用存储器实现逻辑（8.6）。<span class="marginnote">从「从极限到大模型」的视角：大模型推理时，权重存在显存（DRAM 类）、被缓存在 SRAM、由 Flash/SSD 做模型分发——<strong>同一个存储层次体系，从单片机到大模型服务器都在用</strong>。理解本章，就理解了 AI 硬件的存储底座。</span>

## 6 存储层次与局部性原理

半导体存储器不是孤立存在的，它嵌入整个**存储层次**（memory hierarchy）中，靠**局部性原理**发挥最大效率。

**存储层次**：寄存器 → SRAM 缓存（L1/L2/L3）→ DRAM 主存 → Flash/SSD → 硬盘。从快到慢、从贵到便宜、从小到大。

**为什么层次能工作**：程序访问内存有**局部性**：

- **时间局部性**：刚访问的数据很快会再访问（循环变量）。
- **空间局部性**：刚访问数据附近的地址很快会访问（数组、连续指令）。

**缓存（Cache）**：把最近用的数据从慢的 DRAM 复制到快的 SRAM——命中则快，未命中才访慢层。靠局部性，命中率高，平均访问时间接近缓存速度。

**两个关键换算**：

- 平均访问时间 $= t_{cache} + \text{未命中率} \times t_{miss}$。
- 未命中率由局部性决定，好程序命中率 90%+。

**为什么理解存储层次**：数字逻辑的存储单元（SRAM/DRAM）是层次的「砖」，局部性与缓存是「架构」。从「从极限到大模型」的视角：大模型的权重访问高度依赖缓存与 DRAM 带宽——理解存储层次，就理解了 AI 硬件性能的瓶颈在哪。

**辨析｜易错点：** 「缓存是存储器」与「缓存是层次」是两回事——SRAM 是器件（第八篇 8.4），Cache 是「用 SRAM 搭的层次结构」。同一块 SRAM 既可以当寄存器堆，也可以当缓存——「器件」与「结构」是两个概念。

## 7 小结

- 存储指标：容量、存取时间、功耗、价格/位；「快、贵、小」与「慢、便宜、大」的矛盾靠存储层次化解。
- **RAM**（可读写、易失）vs **ROM**（只读、非易失）——「随机存取」指地址无关，与可写性无关。
- **SRAM**（触发器、免刷新、快而贵）vs **DRAM**（电容、需刷新、慢而密）。
- **易失 vs 非易失**：RAM 易失、ROM 家族非易失；Flash 是可擦写非易失的「新贵」。
- 系统分工：固件用 Flash、内存用 DRAM、缓存用 SRAM。
