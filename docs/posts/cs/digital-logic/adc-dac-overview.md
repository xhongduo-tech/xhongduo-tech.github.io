## 为什么从 D/A 与 A/D 转换开始

数字电路处理 0/1，但真实世界是连续变化的——温度、声音、图像都是模拟量。**D/A 转换器（DAC）**把数字变成模拟（输出），**A/D 转换器（ADC）**把模拟变成数字（输入）。它们是数字系统与物理世界之间的接口，也是「从极限到大模型」里感知（传感器→ADC→计算）与执行（计算→DAC→执行器）的必经之路。<span class="marginnote">一部智能手机的完整链路：<strong>麦克风（模拟声波）→ ADC（变成数字）→ DSP 处理 → DAC（还原模拟）→ 扬声器（声波）</strong>。ADC/DAC 是这条链的两端。这一节先搭好 D/A 与 A/D 的整体框架与关键概念。</span>

## 1 为什么需要转换：两个世界的对接

**数字世界**：离散、精确、抗干扰，但「不连续」。

**模拟世界**：连续、真实、贴近物理，但「易受干扰」。

两者各有优势，需要桥接：

- **D/A（Digital to Analog）**：把二进制码变成对应的电压/电流。
- **A/D（Analog to Digital）**：把电压/电流量化成二进制码。

**应用**：音频（CD 播放器 DAC、录音 ADC）、视频（显示 DAC）、测量（传感器 ADC）、控制（电机驱动 DAC）、通信（调制解调）。

<span class="marginnote">转换器的根本作用：<strong>「翻译」——把一种表示换成另一种等价表示</strong>。翻译的质量由分辨率、精度、速度决定——这三者是贯穿全章的指标。理想转换器是精确的线性翻译，现实转换器有量化误差与非理想性。</span>

## 2 基本概念：分辨率、LSB、满量程

转换器的核心概念先从一组定义开始：

- **满量程（Full Scale, FS）**：输出（或输入）的最大模拟值，记为 $V_{FS}$ 或 $V_{REF}$。
- **分辨率（Resolution）**：$n$ 位转换器能把范围分成 $2^n$ 份，分辨率即 $1/2^n$。习惯上用位数说：「8 位 DAC」「12 位 ADC」。
- **LSB（Least Significant Bit，最低有效位）**：一个 LSB 对应的模拟量大小：

$$\text{LSB} = \frac{V_{FS}}{2^n}$$

**直觉**：8 位 ADC、满量程 5 V，则 1 LSB = $5/256 \approx 19.5\,\text{mV}$——ADC 能分辨的最小电压差。

**辨析｜易错点：** 分辨率（位数）与精度（accuracy）不是一回事：**分辨率是「能分出多细」，精度是「分得准不准」**。一个 12 位 ADC 分辨率很高，但如果基准电压漂移、非线性大，精度可能很差。位数高 ≠ 测准，这是初学常犯的概念错误。<span class="marginnote">「分辨率 vs 精度」的类比：<strong>分辨率是尺子的刻度细不细，精度是尺子本身准不准</strong>。一把刻度 1 mm 但本身偏了 1 cm 的尺子，分辨率高而精度差。工程里两个指标都要看。</span>

## 3 D/A 与 A/D 的总体架构

**DAC**：数字输入 → 模拟输出。内部核心是**权电阻/电流开关网络**：把各位的「权重」叠加成总模拟量。主要类型：权电阻 DAC、倒 T 型电阻网络 DAC、电流源 DAC 等。

**ADC**：模拟输入 → 数字输出。内部核心是**取样、量化、编码**三步：先按时间采样、再按幅度量化、最后编码成二进制。主要类型：并联比较型（快）、逐次逼近型（均衡）、双积分型（慢而准）等。

**两者的关系**：ADC 的量化过程常内部包含一个 DAC（比较基准）——逐次逼近型 ADC 就是「用 DAC 猜输入」。

<span class="marginnote">架构预览：<strong>DAC 靠「叠加权重」，ADC 靠「取样 + 比较」</strong>。DAC 是 ADC 的基石（比较器需要一个已知基准），所以教材先讲 DAC 再讲 ADC——下一节就从权电阻 DAC 开始。</span>

## 4 公式解析：LSB 与量化台阶

用公式把「数字 ↔ 模拟」的对应关系写清。$n$ 位 DAC，满量程 $V_{REF}$，数字码 $D = d_{n-1}\dots d_0$：

$$V_{out} = V_{REF} \sum_{i=0}^{n-1} \frac{d_i}{2^{n-i}} = V_{REF} \cdot \frac{D}{2^n}$$

**第一步，看每一位权重**：最高位（$d_{n-1}$）权重 $1/2$，次高位 $1/4$，最低位 $1/2^n$——二进制权的等比关系。

**第二步，看整体映射**：$D$ 从 0 到 $2^n-1$，$V_{out}$ 从 0 到 $V_{REF}(2^n-1)/2^n$——线性映射。

**第三步，看一个 LSB**：$D$ 加 1，$V_{out}$ 增加 $V_{REF}/2^n = \text{LSB}$——量化台阶。

**第四步，代入例值**：8 位、$V_{REF}=5\,\text{V}$，$D=128$ 时 $V_{out} = 5 \times 128/256 = 2.5\,\text{V}$；1 LSB $= 19.5\,\text{mV}$。<span class="marginnote">这条映射公式是 D/A 的「宪法」：<strong>模拟输出 = 满量程 × 数字码 / $2^n$</strong>。所有 DAC 结构（权电阻、倒 T 型）都在物理上实现这个加权求和。A/D 则是它的逆——找数字码 $D$ 使 $V_{REF}D/2^n$ 最接近输入。</span>

## 5 转换器在现代系统中的地位

- **感知**：传感器输出 → 放大器 → ADC → 数字处理器。
- **执行**：数字处理器 → DAC → 驱动器 → 电机/扬声器/显示。
- **通信**：调制解调器的 I/Q 数据经 DAC 发、ADC 收。
- **大模型时代**：语音输入（麦克风 ADC）、音频输出（DAC）、图像传感器（像素 ADC）——**AI 与物理世界交互的每一环都有转换器**。

这一篇后面几节会深入：DAC 的权电阻与倒 T 型网络（10.2）、DAC 指标（10.3）、ADC 原理（10.4）、取样保持（10.5）、并联与逐次逼近 ADC（10.6）、双积分 ADC（10.7）。<span class="marginnote">从「从极限到大模型」的视角：大模型要「看到」世界，靠的是摄像头里每个像素的 ADC；要「说话」，靠的是 DAC 驱动扬声器。<strong>转换器是 AI 的「感官」与「声带」</strong>——理解它们，就理解了 AI 硬件的输入输出边界。</span>

## 6 转换器的关键参数总览

除了分辨率与 LSB，转换器还有一组常被一起考量的参数，先整体建立框架：

| 参数 | 含义 | 对应章节 |
| --- | --- | --- |
| 分辨率 | 位数 / LSB | 本节 |
| 转换精度 | 实际偏离理想的误差 | 10.3（DAC）/ 10.4（ADC） |
| 建立时间 | 输出稳定到误差带内的时间 | 10.3 |
| 转换速率 | 每秒转换次数 | 10.3 |
| 取样率 | ADC 每秒取样次数 | 10.4 |
| 量化误差 | ADC 的固有台阶误差 | 10.4 |
| 有效位数（ENOB） | 综合噪声后的真实位数 | 10.4 |

**为什么这些参数总是一起出现**：因为「选一个转换器」是一个多维决策——位数定分辨率，精度定误差，速率定速度，三者互相牵制：位数高往往慢、精度高往往贵。没有一个参数能单独决定「好不好」。

**换算速查**：

- 1 LSB = $V_{FS}/2^n$。
- 量化信噪比 ≈ $6.02n + 1.76$ dB。
- 位数每加 1，动态范围 × 2（电压）、× 4（功率）。

**选型心智模型**：拿到一个转换需求，先问三个问题——**要分多细（分辨率）？要分多准（精度）？要多快（速率）？** 三个答案落到数据手册上，选型就完成了。这套「三维选型」的思路，后续每一节都会用到。

## 7 转换器的两大发展方向

D/A 与 A/D 转换器的技术演化，可以用两条主线概括：

**方向一：速度与分辨率的提升**。

- 速度：flash → 流水线 → 时间交织（多个 ADC 轮流采样，等效采样率成倍提升）。
- 分辨率：SAR → Σ-Δ（过采样 + 噪声整形，把量化噪声推出带内）。

**方向二：功耗与集成的优化**。

- 低压低功耗：便携设备的 ADC/DAC 在毫瓦甚至微瓦级工作。
- 片内集成：ADC/DAC 集成进 MCU、SoC——外部转换器用于高性能场合。

**为什么转换器研究如此活跃**：万物数字化——通信、音频、图像、传感器、AI——都需要「模拟↔数字」的翻译。转换器的性能（速度/精度/功耗）直接决定系统上限。

**转换器与数字逻辑的关系**：转换器内部大量使用数字逻辑——SAR 的逐次逼近寄存器、Σ-Δ 的数字滤波器、DAC 的编码器——「模拟电路 + 数字逻辑」的融合是现代转换器的常态。学完数字逻辑再学转换器，是「数字为模拟服务」的完整图景。

**从「从极限到大模型」的视角**：AI 芯片的「感知侧」（传感器 ADC）与「执行侧」（音频 DAC、显示驱动）都依赖转换器；大模型的模拟前端（语音唤醒、图像采集）也是转换器的主场。理解转换器，就是理解 AI 与物理世界的接口。

**辨析｜易错点：** 转换器的「性能三角」——速度、精度、功耗——三者互相牵制，没有「全都要」的转换器。选型时明确「哪个优先」，其余让步。想「又快又准又省电」是不现实的，工程是权衡的艺术。

## 8 小结

- **DAC** 把数字码变模拟量，**ADC** 把模拟量变数字码——数字与模拟世界之间的桥。
- 核心概念：满量程、分辨率（位数）、LSB = $V_{FS}/2^n$。
- **分辨率 ≠ 精度**：位数管「细」，精度管「准」。
- DAC 靠「权重叠加」，ADC 靠「取样 + 量化 + 编码」；DAC 常内嵌于 ADC。
- 映射公式：$V_{out} = V_{REF} \cdot D/2^n$；应用覆盖感知、执行、通信、AI 硬件。
