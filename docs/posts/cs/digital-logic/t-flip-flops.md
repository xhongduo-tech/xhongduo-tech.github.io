## 为什么从 T 触发器开始

计数器的核心是「每来一个脉冲翻转一次」，而有一类触发器天生就是为翻转而生的——**T 触发器（Toggle Flip-Flop）**与它的极限形态 **T' 触发器**。<span class="marginnote">T 取自 Toggle（翻转）。<strong>T 触发器可以看成 JK 触发器把 J、K 短接的产物</strong>——$J=K=T$ 时 JK 的四种功能退化成「T=0 保持、T=1 翻转」。它是理解计数器结构的最短路径。</span>这一节讲清 T 触发器的由来、特征方程，以及 T' 触发器在分频器中的应用。

## 1 T 触发器：可控翻转

**T 触发器（T flip-flop）**：单个输入 $T$，两个功能——$T=0$ 时保持，$T=1$ 时翻转。

| T | $Q^{n+1}$ | 功能 |
|---|---|---|
| 0 | $Q^n$ | 保持 |
| 1 | $\overline{Q^n}$ | 翻转 |

特征方程：

$$Q^{n+1} = T\oplus Q^n$$

**从 JK 派生**：把 JK 触发器的 $J=K=T$ 短接，代入 JK 特征方程：

$$Q^{n+1} = J\overline{Q^n} + \overline{K}Q^n = T\overline{Q^n} + \overline{T}Q^n = T\oplus Q^n$$

这正是异或——T 触发器的本质是「**输入 T 与当前状态异或**」：$T=1$ 时输出取反，$T=0$ 时保持不变。<span class="marginnote">异或又一次登场：<strong>「翻转」这个动作的数学形式就是异或</strong>——$Q^{n+1} = 1\oplus Q^n$ 是翻，$Q^{n+1}=0\oplus Q^n$ 是不翻。加法器里求和用异或，计数器里翻转也用异或，异或是数字电路里最「万能」的运算。</span>

**辨析｜易错点：** T 触发器没有标准的独立型号（不像 74LS74 就是 D、74LS76 就是 JK），它通常是 JK 触发器短接而成，或由综合器自动生成。做题时认准特征方程 $Q^{n+1}=T\oplus Q^n$ 即可。

## 2 T' 触发器：无条件翻转

**T' 触发器（T' flip-flop）**是 T 触发器的退化：输入 $T$ 恒为 1，**每个时钟边沿必然翻转一次**。

$$Q^{n+1} = \overline{Q^n}$$

T' 触发器没有数据输入，只有一个时钟输入——它的唯一功能就是「分频」：**每两个时钟脉冲输出翻转一次，输出频率是时钟频率的一半**。

为什么是分频？看时间轴：

- 时钟：$\underline{1}\ \overline{1}\ \underline{1}\ \overline{1}\ \dots$（每个上升沿触发一次）
- 输出：$0 \to 1 \to 0 \to 1 \to \dots$

输出在每两个时钟边沿之间保持一个电平，于是**输出周期 = 2×时钟周期**，频率减半。<span class="marginnote">T' 触发器就是最朴素的<strong>二分频器</strong>：一个触发器把频率除以 2，两个串联除以 4，$n$ 个串联除以 $2^n$——这是所有时钟树分频、计时器、分频链的底层积木。</span>

## 3 T 触发器与计数器的关系

T 触发器与计数器的联系极其直接。把多个 T 触发器连成链：

**每个触发器翻一次 = 计一个数**。$n$ 个 T' 触发器串联，输出构成 $n$ 位二进制计数器（每位在低位翻转时进位）。

以 2 位为例：最低位 $Q_0$ 每拍翻转；$Q_1$ 在 $Q_0$ 从 1 变 0（下降沿）时翻转——这正好实现了「低位进位」：

| 时钟序号 | $Q_1Q_0$ |
|---|---|
| 0 | 00 |
| 1 | 01 |
| 2 | 10 |
| 3 | 11 |
| 4 | 00 |

$00\to01\to10\to11$ 正是 2 位二进制加法计数。<span class="marginnote">这就是第六篇计数器的雏形：<strong>「最低位每拍翻、高位在低位下降沿翻」= 异步二进制加法计数</strong>。T 触发器把「计数」这个复杂行为还原成最简单的「翻转」，是理解计数器的钥匙。</span>

## 4 公式解析：分频链的定量推导

用 T' 触发器构成的 $n$ 级分频链，推导输出频率。设时钟频率 $f_{clk}$，第 $i$ 级输出 $f_i$：

$$f_0 = \frac{f_{clk}}{2}, \qquad f_1 = \frac{f_{clk}}{2^2}, \qquad \dots, \qquad f_{n-1} = \frac{f_{clk}}{2^n}$$

**第一步，看第一级**：一个 T' 触发器每两个时钟脉冲翻转一次，输出一个完整周期占两个时钟周期，$f_0 = f_{clk}/2$。

**第二步，看第二级**：第二级的输入是 $f_0$（来自第一级的输出），它又把 $f_0$ 除以 2，$f_1 = f_0/2 = f_{clk}/4$。

**第三步，归纳 $n$ 级**：每加一级就除以 2，$n$ 级分频链的输出频率 $f = f_{clk}/2^n$。

**第四步，应用**：若系统时钟 $1\,\text{GHz}$，经过 5 级分频链得到 $1\,\text{GHz}/32 = 31.25\,\text{MHz}$——分频链广泛用于生成慢速外设时钟、看门狗定时、计时基准。<span class="marginnote">分频链的现代应用：<strong>CPU 里的 PLL（锁相环）先倍频、再用分频链分频出各种外设时钟</strong>。T' 触发器是其中最朴素的一环——虽然现代分频用可编程计数器实现，但「每级除 2」的原理不变。</span>

## 5 T 触发器的其他应用

- **可编程分频**：给 T 触发器加使能（$T$ 可控），就得到「有时翻转、有时保持」的可控分频器——计数器计数到某值时停、到另一值时开，实现任意模数计数（第六篇）。
- **时序波形生成**：T 触发器翻转产生方波，配合其他逻辑生成脉冲序列。
- **教学抽象**：T 触发器是分析「翻转行为」的纯净模型，帮助理解 JK 的翻转模式。

**辨析｜易错点：** T' 触发器没有使能，只要有时钟就一直翻转；T 触发器有使能 $T$。工程上「可控 T」更常用——通过控制 $T$ 的 0/1，就能让计数器「走走停停」，这正是可编程计数器的原理。

## 6 从 T 触发器到可编程计数器

T 触发器的「使能」思想，可以直接升级成可编程计数器。

**使能 T 触发器的功能**：T 触发器加使能 $EN$——$EN=1$ 时翻转（计数），$EN=0$ 时保持（暂停）：

$$Q^{n+1} = EN \oplus Q^n \quad (\text{或 } Q^{n+1} = (EN \cdot T) \oplus Q^n)$$

**可编程分频**：多个使能 T 触发器串联，用控制信号决定各级「翻不翻」：

- 全部使能：$2^n$ 分频。
- 某些级禁止：跳过部分状态，模数变化。

**计数器到定时器的升级**：计数器 + 比较器 = 定时器——计数值与预设值相等时输出脉冲，然后清零重计。这就是 MCU 定时器/看门狗的基本结构：**计数（T 翻转）+ 比较（判断到达）+ 清零（重来）**。

**T 触发器的 Verilog 实现**：

```verilog
module t_ff (
    input      clk,
    input      t,
    input      rst_n,
    output reg q
);
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            q <= 1'b0;
        else if (t)
            q <= ~q;
    end
endmodule
```

综合器把 `if (t) q <= ~q`（使能控制）识别为 T 触发器行为，生成相应电路。

**为什么 T 触发器重要**：它把「计数」这个最普遍的需求抽象成「使能即翻转」——所有计数器、定时器、分频器的底层都是它。虽然现代设计用计数器（如 `cnt <= cnt + 1'b1`），但综合后的硬件仍是「翻转 + 进位」的组合——T 触发器是理解一切的钥匙。

**辨析｜易错点：** T 触发器与 T' 触发器在 Verilog 里都写成 `q <= ~q`，区别在「有没有 en 控制」：有使能是 T，无条件翻转是 T'。写代码时用 `if (en) q <= ~q` 表达 T，直接 `q <= ~q` 是 T'。

## 7 小结

- **T 触发器**：$Q^{n+1}=T\oplus Q^n$，T=1 翻转、T=0 保持；由 JK 短接而来。
- **T' 触发器**：$Q^{n+1}=\overline{Q^n}$，每拍必翻，是最简二分频器。
- $n$ 级 T' 链 = $2^n$ 分频 = $n$ 位异步计数器。
- 计数器的本质是「翻转 + 进位」；T 触发器把计数还原成翻转。
- 可控 T 触发器（加使能）是可编程计数器的基础。
