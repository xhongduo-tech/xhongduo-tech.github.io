## 为什么从移位寄存器型计数器开始

普通计数器靠「翻转」计数，还有一种计数器靠「移位」计数——**移位寄存器型计数器**。它把移位寄存器的末位反馈回首位，让数据在环中循环，从而产生一组顺序脉冲。它的两大代表是**环形计数器**与**扭环形计数器（约翰逊计数器）**。<span class="marginnote">为什么用移位而非翻转来计数？因为某些场合需要的是「<strong>顺序脉冲</strong>」——同一时刻只有一个输出为高（或低），像一圈灯依次点亮。环形计数器天然就是独热码输出，译码逻辑几乎为零，这是它最大的价值。</span>这一节分析这两种计数器，以及它们的自启动问题。

## 1 环形计数器：独热码的循环

**环形计数器（ring counter）**：把移位寄存器的最末位 $Q_{n-1}$ 反馈到最首位 $Q_0$ 的输入，构成一个环。

初始状态置为「1000」（独热码，只有一个 1），每来一个时钟，这个 1 在环中右移一位：

$$1000 \to 0100 \to 0010 \to 0001 \to 1000$$

每个状态都是**独热码**（恰好一个 1），$n$ 位移位寄存器形成**模 $n$ 计数器**（$n$ 个状态循环）。

**输出性质**：$Q_0\sim Q_{n-1}$ 依次变高，天然就是顺序脉冲——**无需译码器**就能直接用于顺序控制（如多路选通的轮流扫描）。<span class="marginnote">环形计数器的杀手锏：<strong>独热码输出 + 零译码 = 极低的组合逻辑延迟</strong>。在「状态多但不需要编码」的场合（如状态机的一位热编码），环形计数器让控制逻辑几乎消失——这就是 FPGA 状态机里独热码受宠的原因。</span>

**辨析｜易错点：** 环形计数器共有 $2^n$ 种可能状态，但**有效状态只有 $n$ 个**（独热的那 $n$ 个）——其余 $2^n - n$ 个是非法状态。若不处理，电路可能「跑进」非法环，永远回不来——这就是**自启动**问题。

## 2 扭环形计数器：约翰逊计数器

**扭环形计数器（twisted ring counter）**，也叫**约翰逊计数器（Johnson counter）**：把末位的**反**反馈回首位，$D_0 = \overline{Q_{n-1}}$。

以 4 位为例，初态 0000：

$$0000 \to 1000 \to 1100 \to 1110 \to 1111 \to 0111 \to 0011 \to 0001 \to 0000$$

**规律**：状态由「一串 0 + 一串 1」构成，共有 $2n$ 个状态（8 个），因此 4 位约翰逊计数器是**模 8** 计数器。

**特点**：比环形计数器多一倍的计数能力（$2n$ vs $n$），且状态转移**每次只变一位**（相邻状态汉明距离为 1），无毛刺风险。<span class="marginnote">「每次只变一位」是约翰逊计数器的隐藏优点：<strong>相邻状态间没有多位同时翻转，天然免疫竞争冒险</strong>。这个性质让它在需要「状态平滑过渡」的场合（如频率合成器的分频、三相波形生成）很受青睐。</span>

## 3 自启动问题与解决

**自启动（self-starting）**：电路从任意初始状态（含非法状态）出发，能否自动进入有效循环？

环形计数器的问题：若初态不是独热码（如 1010），它可能跑进一个**非法环**，永远回不到独热环。比如 4 位环形的非法环 $1010\to0101\to1010$ 就是一个死循环。

**解决自启动**：修改反馈逻辑，让非法状态能跳回有效环。经典做法是「**检测是否有 1，无 1 或多余 1 时强制置入一个 1**」——例如反馈输入改为：

$$D_0 = Q_3 + \overline{Q_0}\overline{Q_1}\overline{Q_2}\overline{Q_3}$$

即「末位移出，若无 1 则补 1」。这样任何含多个 1 的状态会逐步「吐出」多余的 1，直到回到独热环。<span class="marginnote">自启动设计的通用思想：<strong>检查非法状态的转移图，凡不能回到有效环的，用修改反馈/复位逻辑「纠正」它</strong>。这在状态机设计中是硬性要求——「卡死」在非法状态的控制电路是灾难。第六篇的设计方法会把自启动检查列为标准步骤。</span>

## 4 公式解析：约翰逊计数器为什么是模 2n

用状态方程推导约翰逊计数器的模数。4 位约翰逊计数器，反馈 $D_0 = \overline{Q_3}$：

$$
\begin{aligned}
Q_0^{n+1} &= \overline{Q_3} \\
Q_1^{n+1} &= Q_0 \\
Q_2^{n+1} &= Q_1 \\
Q_3^{n+1} &= Q_2
\end{aligned}
$$

**第一步，看移位**：$Q_1,Q_2,Q_3$ 逐级继承左邻，数据右移。

**第二步，看反馈**：$Q_0$ 接收 $\overline{Q_3}$——末位为 0 时首位变 1，末位为 1 时首位变 0。

**第三步，推状态序列**：从 0000 出发：$Q_3=0 \Rightarrow Q_0=1$（下一拍 1000）；$Q_3=0 \Rightarrow Q_0=1$（1100）；$Q_3=0\Rightarrow Q_0=1$（1110）；$Q_3=0\Rightarrow Q_0=1$（1111）；$Q_3=1\Rightarrow Q_0=0$（0111）……共 8 个状态。

**第四步，归纳**：状态由「0 串 + 1 串」组成，0 的个数从 4 递减到 0、1 的个数从 0 递增到 4，共 $2\times4=8$ 个状态——**模 $2n$**。<span class="marginnote">直觉总结：<strong>反相反馈让「边界」在环里移动——先是 0 越来越多，再是 1 越来越多，边界扫一圈用了 $2n$ 拍</strong>。环形是「一个 1 走一圈」（$n$ 拍），约翰逊是「边界走一圈」（$2n$ 拍）。</span>

## 5 移位寄存器型计数器的应用

**环形计数器 → 顺序脉冲发生器**：独热码直接驱动多路轮流选通，译码为零（下一节「顺序脉冲发生器」就是它）。
**约翰逊计数器 → 分频器**：模 $2n$ 分频，且每级输出是相位均匀的方波，可用于多相时钟。
**约翰逊计数器 → 无毛刺状态机**：每次只变一位，状态转移平滑。
**LFSR（线性反馈移位寄存器）**：用异或反馈取代简单反馈，生成伪随机序列（前面提过）——它是移位寄存器型计数器的「远亲」，但周期性最长（$2^n-1$）。

<span class="marginnote">从环形到 LFSR 是一条「反馈逻辑进化」的线：<strong>直通反馈 → 反相反馈 → 异或反馈</strong>，环的状态数从 $n$ 增长到 $2n$，再到 $2^n-1$——反馈越「聪明」，循环越长。这条线把「简单计数」推向了「伪随机」的领域。</span>

## 6 移位寄存器型计数器的实际应用对比

三种移位寄存器型计数器（环形、扭环形、LFSR）在实际中各有定位：

| 类型 | 周期 | 输出特点 | 典型用途 |
| --- | --- | --- | --- |
| 环形计数器 | $n$ | 独热码，零译码 | 顺序脉冲、状态机独热编码 |
| 扭环形（约翰逊） | $2n$ | 每次只变一位 | 无毛刺分频、多相时钟 |
| LFSR | $2^n-1$ | 伪随机序列 | 测试图案、CRC、加扰 |

**选型逻辑**：

- 要「顺序选通、译码最少」→ 环形计数器（独热输出直接驱动）。
- 要「分频且输出平滑」→ 约翰逊计数器（每次变一位，边沿干净）。
- 要「长周期伪随机」→ LFSR（周期指数增长）。

**环形计数器的状态机价值**：FPGA 状态机常用独热码——每个状态一个触发器，输出即状态，省译码逻辑。一个独热码状态机本质上就是一个带「预设初态」的环形计数器。这是移位寄存器型计数器在现代设计中最活跃的应用。

**约翰逊计数器的多相输出**：4 位约翰逊计数器各输出是相位依次移位的方波，可生成 8 相时钟——用于三相电机驱动、开关电源的多相 PWM。输出的均匀相位分布是它的独门优势。

**辨析｜易错点：** 环形计数器与约翰逊计数器的「反馈」一字之差（直通 vs 反相），周期却差一倍（$n$ vs $2n$）。做题时先看反馈是 $Q_{n-1}$ 还是 $\overline{Q_{n-1}}$，再定模数——这是最快、最不易错的方法。

## 7 移位寄存器型计数器的 Verilog 实现

用 Verilog 实现这三种计数器，看 HDL 如何表达「移位 + 反馈」。

**环形计数器**：

```verilog
module ring_counter #(parameter N = 4) (
    input  clk, rst_n,
    output reg [N-1:0] q
);
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) q <= 4'b1000;          // 预置独热码
        else        q <= {q[0], q[N-1:1]}; // 右移，末位直通反馈首位
    end
endmodule
```

**约翰逊计数器**：

```verilog
module johnson_counter #(parameter N = 4) (
    input  clk, rst_n,
    output reg [N-1:0] q
);
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) q <= 4'b0000;           // 初态全 0
        else        q <= {~q[0], q[N-1:1]}; // 右移，末位反相反馈首位
    end
endmodule
```

**LFSR**：

```verilog
module lfsr #(parameter N = 4) (
    input  clk, rst_n,
    output reg [N-1:0] q
);
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) q <= 4'b0001;              // 非全零初态（全 0 会卡死）
        else        q <= {q[0] ^ q[N-1], q[N-1:1]}; // 异或反馈（4 位取本原多项式 x^4+x+1 的抽头 q0⊕q3）
    end
endmodule
```

**三种实现的对比**：直通反馈（环形）、反相反馈（约翰逊）、异或反馈（LFSR）——HDL 里的差别只是「首位怎么接」，一行代码的差异带来周期从 $n$ 到 $2n$ 到 $2^n-1$ 的巨大不同。

**综合视角**：这些代码综合后就是「移位寄存器 + 反馈 MUX/异或门」——与手工设计完全等价。写「行为」（Verilog），综合器生成「结构」（移位 + 反馈）。

**为什么用 HDL 描述**：比手工画图简洁、可仿真、可参数化（位宽用 `parameter`）。但理解「反馈决定周期」的原理，才能预判综合结果、调试异常。

**辨析｜易错点：** LFSR 的异或反馈抽头不是随便选的——选错抽头周期会缩短。对应「本原多项式」的抽头才能达到 $2^n-1$ 最长周期。HDL 里写 LFSR 时，反馈抽头要按标准查表，别自创。

## 8 小结

- **环形计数器**：末位直通反馈首位，独热码循环，模 $n$，零译码顺序脉冲。
- **扭环形（约翰逊）计数器**：末位反相反馈，状态「0 串+1 串」，模 $2n$，每次只变一位。
- **自启动**：非法状态须能回到有效环；修改反馈逻辑纠正非法环。
- 环形适合顺序脉冲，约翰逊适合无毛刺分频；LFSR 用异或反馈生成最长循环。
- 反馈逻辑决定循环长度：直通 $n$、反相 $2n$、异或 $2^n-1$。
