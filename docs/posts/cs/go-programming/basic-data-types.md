## 为什么从数据类型开始

程序处理的一切都是**数据**，而数据必须先有**类型**才能谈运算。Go 的静态类型系统特别「硬」：没有隐式转换，每个数值都有明确的位宽，溢出与截断都有确定行为。这一章看似琐碎，实则是后续一切运算的安全网——搞懂 `int` 与 `int32` 的区别、浮点数的舍入、字符串的字节本质，你写出的代码才不会在边界处翻车。<span class="marginnote">本专题第一级《基础数学》讲了数的扩张：自然数→整数→有理数→实数→复数。Go 的数值类型恰好把这套数系在机器里落了一遍地——每种类型对应固定的位宽与范围，这是「数学的数」到「机器的数」的第一次全面对照。</span>

## 1 整数类型：位宽决定一切

Go 的整数类型分为**定宽类型**与**架构相关类型**两族：

| 类型 | 位宽 | 范围 | 用途 |
| --- | --- | --- | --- |
| `int8`/`uint8` | 8 位 | $-128$~$127$ / $0$~$255$ | 小数值、字节 |
| `int16`/`uint16` | 16 位 | $-2^{15}$~$2^{15}-1$ / 无符号对应 | 中数值 |
| `int32`（`rune`） | 32 位 | $-2^{31}$~$2^{31}-1$ | Unicode 码点 |
| `int64` | 64 位 | $-2^{63}$~$2^{63}-1$ | 大数值、时间戳 |
| `int`/`uint` | 架构相关 | 平台字长（64 位平台即 64 位） | 通用整数 |

`int` 是**架构相关**类型：在 64 位平台上是 64 位，在 32 位平台上是 32 位。<span class="marginnote">`int` 的位宽随平台变化，是「顺手够用」的选择；需要精确定宽（如协议解析、文件格式）时必须用定宽类型 `int32`/`int64`。`rune` 是 `int32` 的别名，表示一个 Unicode 码点——它是 Go 处理中文等非 ASCII 字符的关键。</span>

**重点：** `int` 与 `int32` 在 64 位平台上**位宽相同（都是 64 位）但类型不同**——`int` 与 `int32` 不能互相赋值，必须显式转换 `int32(x)`。这与《程序结构》篇「禁止隐式转换」一脉相承：类型是编译期安全边界，位宽相同也不代表类型相同。

**辨析｜易错点：** 整数溢出不会报错，而是**静默回绕（wrap around）**。`math.MaxInt8 + 1` 会变成 `math.MinInt8`。Go 规范保证无符号整数的回绕是「模 $2^n$」运算，有符号整数也以补码形式回绕——但你的**逻辑**往往不允许回绕，所以要在边界检查。

## 2 浮点类型：IEEE 754

Go 的浮点类型 `float32`、`float64` 遵循 **IEEE 754 标准**——与《基础数学》篇「实数是无限精度的理想数」形成对照：<span class="marginnote">IEEE 754 是浮点数的国际标准：`float64` 用 1 位符号 + 11 位指数 + 52 位尾数表示，`float32` 用 1+8+23。它规定了舍入规则、特殊值（`+Inf`、`NaN`）与「0 的符号」，是所有现代 CPU 与语言共同遵循的规范。</span>

| 类型 | 指数位 | 尾数位 | 约精度 | 范围 |
| --- | --- | --- | --- | --- |
| `float32` | 8 位 | 23 位 | 约 7 位十进制 | $\pm 3.4 \times 10^{38}$ |
| `float64` | 11 位 | 52 位 | 约 16 位十进制 | $\pm 1.8 \times 10^{308}$ |

**重点：** 浮点数**不能精确表示所有小数**。`0.1` 在二进制里是无限循环小数，`float64(0.1) + float64(0.2)` 不等于 `0.3`，而是 `0.30000000000000004`。这是 IEEE 754 的固有特性，不是 Go 的 bug。

**辨析｜易错点：** 永远**不要用 `==` 比较浮点数**。正确做法是比较差的绝对值：`math.Abs(a-b) < 1e-9`。涉及金额的精确计算要用整数（分）或 `math/big`，而不是浮点。

## 3 复数与字符串

**复数** `complex64`、`complex128` 由实部与虚部组成，Go 原生支持：

```go
var x complex128 = complex(1, 2)   // 1+2i
y := 3 + 4i                        // 复合字面量
fmt.Println(x + y)                 // 4+6i
```

**字符串（string）** 是 Go 最重要的数据类型之一，其核心特性是**不可变**与 **UTF-8**：<span class="marginnote">Go 源码默认 UTF-8，字符串就是「字节序列」，`len(s)` 返回<strong>字节数</strong>而非字符数。要按「字符」（码点）遍历用 `for _, r := range s`，它自动解码 UTF-8。这个「字符串=字节」的设计让 Go 处理多语言文本极其干净，代价是中文等字符占 3 字节。</span>

```go
s := "hello, 世界"
fmt.Println(len(s))      // 13：5+1+1+3+3（"世界"各 3 字节）
fmt.Println(len([]rune(s)))  // 8：5 个 ASCII + 1 逗号 + 2 汉字
```

**核心对比：字符串的常见操作**

| 操作 | 写法 |
| --- | --- |
| 拼接 | `s1 + s2`（或用 `strings.Builder` 高效拼接） |
| 长度（字节） | `len(s)` |
| 字符数 | `len([]rune(s))` |
| 子串 | `s[0:5]`（按字节切片） |
| 遍历字符 | `for i, r := range s` |
| 查找 | `strings.Contains`、`strings.Index` |

**辨析｜易错点：** 按字节切片 `s[0:5]` 若切在**多字节字符中间**会产生「非法 UTF-8」的碎片。处理中文时优先用 `[]rune` 或 `range`，不要盲目按字节索引。字符串**不可变**——`s[0] = 'x'` 编译错误；要修改用 `[]byte(s)` 转换后再写回（`string([]byte)`）。

## 4 公式解析：整数范围与位宽

**整数能表示的范围由位宽决定**。有符号 $n$ 位整数的范围

$$
[-2^{n-1},\ 2^{n-1}-1]
$$

无符号 $n$ 位整数的范围

$$
[0,\ 2^{n}-1]
$$

以 `int8`（$n=8$）逐步验证：

- **第一步，算下界**：$-2^{7} = -128$。
- **第二步，算上界**：$2^{7}-1 = 127$。
- **第三步，总数核对**：$128 + 128 = 256 = 2^8$ 个值，正好占满 8 位。
- **第四步，与浮点对照**：整数的范围**精确**、可列举；浮点的范围巨大但**有间隙**（精度有限）。这是「离散的数」与「近似的数」的数学本质差异。

这条公式解释了一切整数边界的来源：溢出回绕、`math.MaxInt8` 等常量、以及「为什么 `rune` 能表示全部 Unicode 码点」（$2^{31}-1 \approx 21$ 亿，大于 Unicode 的约 110 万个码点）。

## 5 核心对比：Go 数值类型的取舍

| 维度 | 整数 | 浮点 | 复数 |
| --- | --- | --- | --- |
| 精确性 | 精确 | 有限精度 | 精确（分量用浮点） |
| 表示对象 | 离散量 | 连续量近似 | 二维数 |
| 溢出行为 | 回绕 | 上溢为 `+Inf` | 分量回绕 |
| 比较 | 可 `==` | 用差值 | 实虚部各自比较 |
| 典型用途 | 计数、索引 | 科学计算、测量 | 信号处理、傅里叶 |

这张表提示选型：**计数用整数、测量用浮点、振荡用复数**。整数是「离散世界的数」，浮点是「连续世界的近似」，复数把实数轴扩展成平面——三者各司其职，Go 让它们各有明确位宽，杜绝了 C 里「int 到底多大」的暧昧。

**补充｜实践提示：** 常量用无类型常量（untyped constant），它在运算时才确定类型；`const MaxInt = 1<<63 - 1` 可以赋给任何足够宽的整数类型。`math` 包提供 `MaxInt`、`MaxFloat64` 等边界常量，`strconv.Atoi` 把字符串转 `int`，`fmt.Sprintf("%x", n)` 输出十六进制——这些工具在实际编程中天天用。

## 6 小结

- **整数**分定宽（`int8`~`int64`）与架构相关（`int`/`uint`）；`rune` 是 `int32`，表示 Unicode 码点。
- `int` 与 `int32` 位宽可能相同但**类型不同**，不能互相赋值。
- 整数溢出**静默回绕**；浮点遵循 IEEE 754，`0.1+0.2 ≠ 0.3`，比较用差值而非 `==`。
- **字符串**是「字节序列」：`len` 数字节、`range` 数字符；不可变，改需 `[]byte` 转换。
- 复数 `complex64`/`complex128` 原生支持，实部虚部由 `complex()` 或字面量 `3+4i` 构造。
- 整数范围 $[-2^{n-1},2^{n-1}-1]$ 由位宽决定，是一切边界行为的数学根源。
