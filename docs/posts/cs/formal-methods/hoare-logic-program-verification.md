## 为什么程序本身也可以被证明

上一篇我们学会了用证明助手证明数学命题。但形式化方法最大的目标不是证明数学，而是证明**程序**——「这个排序算法真的排序了吗」「这段并发代码真的不会死锁吗」。把程序的执行行为放进逻辑，就是**霍尔逻辑（Hoare logic）**：1969 年霍尔在《An Axiomatic Basis for Computer Programming》中把弗洛伊德（Robert Floyd）1967 年关于程序流程图的断言思想，做成了一套关于命令式程序的公理与推理规则。<span class="marginnote">弗洛伊德 1967 年提出「用断言语义给流程图标注中间状态」，霍尔将其改造成「前置/后置条件 + 推理规则」的优美形式，迪克斯特拉（Dijkstra）随后补上「最弱前置条件」。三人的工作构成程序验证的理论基座，也直接支撑了第 5 篇的 Isabelle/HOL 验证和今天的静态分析工具。</span>

霍尔逻辑的美在于「**程序的结构决定证明的结构**」：程序的每条语法构造（赋值、顺序、条件、循环）都对应一条推理规则，于是验证程序就变成「沿着语法树自底向上套规则」——一种可以机械执行的证明方法。<span class="marginnote">这也正是 Nipkow《Concrete Semantics》第 7 章的路线：先给命令式小语言定义操作语义（程序怎么跑），再证明霍尔逻辑规则的可靠性——「被规则证明的都真的成立」。有了这层保证，霍尔逻辑才不是好看的纸面推理，而是关于真实程序的真命题。</span>

## 1 霍尔三元组：把规格写成逻辑

**霍尔三元组（Hoare triple）**是霍尔逻辑的基本单位，形如：

$$
\{P\}\; c \;\{Q\}
$$

读作「**若程序 $c$ 在满足前置条件 $P$ 的状态下开始执行，且 $c$ 终止，则执行结束后 $Q$ 成立**」。$P$ 叫**前置条件（precondition）**，$Q$ 叫**后置条件（postcondition）**，两者都是关于程序变量的一阶断言（如 $x > 0$、$\mathrm{result} = n!$）。

**辨析｜易错点：部分正确性 vs 总正确性。** 上面的读法只承诺「若终止则满足后置条件」，这叫**部分正确性（partial correctness）**。**总正确性（total correctness）**进一步要求「$c$ 必然终止」，写作 $\langle P \rangle\; c \;\langle Q \rangle$。两者差一个「终止性」。对「$P$ 成立时 while 循环是否停得下来」这种问题，部分正确性完全不管——这是初学者最容易误会的语义边界。<span class="marginnote">工程上大部分「正确性」其实都是部分正确性 + 单独的终止性证明。终止性常用「良基排序函数 + 每次迭代严格减小」证明，这与第 5 篇的归纳原理一脉相承；Isabelle/HOL 里每个递归函数都要配一个终止性证明，正是这道闸门。</span>

## 2 霍尔逻辑的五条核心规则

程序由五类构造组成，霍尔逻辑就给五条规则：

$$
\frac{\{Q[x := e]\}\; x := e \;\{Q\}}{\,} \quad \text{（赋值公理）}
$$

$$
\frac{\{P\}\; c_1 \;\{R\} \qquad \{R\}\; c_2 \;\{Q\}}{\{P\}\; c_1;\; c_2 \;\{Q\}} \quad \text{（顺序复合）}
$$

$$
\frac{\{P \land B\}\; c_1 \;\{Q\} \qquad \{P \land \neg B\}\; c_2 \;\{Q\}}{\{P\}\; \textbf{if}\; B \;\textbf{then}\; c_1 \;\textbf{else}\; c_2 \;\{Q\}} \quad \text{（条件）}
$$

$$
\frac{\{P \land B\}\; c \;\{P\}}{\{P\}\; \textbf{while}\; B \;\textbf{do}\; c \;\{P \land \neg B\}} \quad \text{（循环）}
$$

$$
\frac{P' \Rightarrow P \qquad \{P\}\; c \;\{Q\} \qquad Q \Rightarrow Q'}{\{P'\}\; c \;\{Q'\}} \quad \text{（前提强化 / 结论弱化）}
$$

**重点：循环规则里的 $P$ 叫循环不变量（loop invariant）**——一个「每轮循环体执行前后都成立」的断言，它连接「循环开始前的状态」和「循环结束后的状态」。写对不变量，是霍尔逻辑证明的**全部难点与全部艺术**。<span class="marginnote">寻找不变量的直觉：循环是「重复做同一件事」，能撑过每一轮重复的，只能是「每一轮开始都成立的规律」。例如累加求和的循环，不变量往往是「$s$ 等于已处理部分的和」这种「部分结果不变量」。第 7 篇《抽象解释与不变量》会从另一个方向机械化地找它们。</span>

五条规则可以压缩成一张「规则速查表」，做证明时对照着用：

| 构造 | 规则要点 |
| --- | --- |
| 赋值 | 前置 = 后置做替换 $Q[x:=e]$ |
| 顺序 | 用中间断言 $R$ 衔接 $c_1; c_2$ |
| 条件 | 两分支分别证，前提各带 $B$ 与 $\neg B$ |
| 循环 | 不变量 $P$ 循环体保真 + 退出得 $P \land \neg B$ |
| 强化 / 弱化 | 前提可加强、结论可减弱 |

## 3 从后往前推导：最弱前置条件

「给定程序与后置条件，反推前置条件」比「正着验证」更机械。**最弱前置条件（weakest precondition）** $\mathrm{wp}(c, Q)$ 定义为：使「$\{P\}\; c \;\{Q\}$ 为总正确性三元组」的所有 $P$ 中最弱（最容易被满足）的那个——也就是「保证 $c$ 执行后满足 $Q$ 的全部前置状态」构成的集合。<span class="marginnote">「最弱」指逻辑上最宽容：只要状态落到 $\mathrm{wp}(c,Q)$ 里，执行 $c$ 后 $Q$ 必成；任何更严格的前置条件都是它的子集。迪克斯特拉用它把「验证程序」变成「逐步反推并化简断言」——这就是第 10 篇《精化演算》的发动机。</span>关键计算规则：

$$
\mathrm{wp}(x := e,\; Q) = Q[x := e], \qquad \mathrm{wp}(c_1; c_2,\; Q) = \mathrm{wp}(c_1, \mathrm{wp}(c_2, Q))
$$

赋值的最弱前置条件是「把 $Q$ 里的 $x$ 替换成 $e$」——**倒着算，赋值变成替换**。于是验证「$\{P\}\; c \;\{Q\}$」可机械地归结为：从后往前反复套 $\mathrm{wp}$，最后检查「$P \Rightarrow \mathrm{wp}(c,Q)$」这条纯逻辑蕴含是否成立（这一步就交给第 5 篇的证明助手或第 9 篇的 SMT）。

## 4 实战：证明一个累加程序的正确性

用霍尔逻辑验证经典例子「求 $1$ 到 $n$ 的和」，程序为 `i := 0; s := 0; while i < n do (i := i+1; s := s+i)`。目标：

$$
\{ n \geq 0 \}\; \text{上述程序} \;\{ s = \frac{n(n+1)}{2} \}
$$

证明骨架（部分正确性）：

- **选定不变量** $P \equiv (s = \frac{i(i+1)}{2} \land 0 \leq i \leq n)$——「$s$ 恰好是 $1$ 到 $i$ 的和，且 $i$ 没有越界」。
- **初始化**：执行赋值前 $i=0, s=0$，则 $s = \frac{0 \cdot 1}{2} = 0$ 成立，$0 \leq i \leq n$ 由 $n \geq 0$ 推出——**不变量在循环前成立**。
- **循环体保真**：假设进入循环体时 $P \land (i < n)$ 成立，执行 `i := i+1; s := s+i` 后，新的 $s = \text{旧} s + (i+1) = \frac{i(i+1)}{2} + (i+1) = \frac{(i+1)(i+2)}{2}$，且 $i+1 \leq n$——**不变量依然成立**。
- **退出时刻**：循环结束时有 $P \land \neg(i < n)$，即 $i = n$（因 $i \leq n$ 且 $\neg(i<n)$），代入 $P$ 得 $s = \frac{n(n+1)}{2}$——**后置条件成立**。

**这个例子的关键一眼**是「$s = \frac{i(i+1)}{2}$」这个不变量选得恰好：它既描述了「部分和」的进展，又在 $i=n$ 时自动变成目标结论。霍尔逻辑证明的所有工夫，都花在「写出那个让循环体保真的断言」上。<span class="marginnote">你或许已注意到：上面的代数化简「$\frac{i(i+1)}{2} + (i+1) = \frac{(i+1)(i+2)}{2}$」正是第 5 篇证明助手里 `simp` 命令自动完成的代数。Nipkow 第 7 章用 Isabelle/HOL 实现了整套霍尔逻辑，验证这样的程序往往只有十几行证明脚本。</span>

同样的骨架可以照搬到别的程序上——只要换一个不变量。**再看阶乘程序** `i := 0; r := 1; while i < n do (i := i+1; r := r*i)`，目标 $\{ n \geq 1 \}$ 程序 $\{ r = n! \}$，选不变量 $P \equiv (r = i! \land 0 \leq i \leq n)$：

- **初始化**：$i=0, r=1=0!$，且 $0 \le i \le n$ 由 $n \ge 1$ 推出；
- **循环体保真**：进入循环体时 $r = i!$，执行 `i := i+1; r := r*i` 后新 $r = i! \cdot (i+1) = (i+1)!$——恰好是「新 $i$ 的阶乘」；
- **退出时刻**：$i=n$ 时 $r = n!$，后置条件成立。

这个例子和累加例子几乎是同一个证明模板换了个不变量——**「已处理部分的累积量」是寻找不变量最通用的直觉**：累加时是「部分和」，阶乘时是「部分积」，在数组上则是「前缀已排序 / 已求和」。掌握了这个模板，霍尔逻辑就只剩代数化简的体力活了。

## 5 公式解析：循环规则为什么需要不变量

把循环规则拆到骨头里：

$$
\frac{\{P \land B\}\; c \;\{P\}}{\{P\}\; \textbf{while}\; B \;\textbf{do}\; c \;\{P \land \neg B\}}
$$

- **第一步，读前提**：前提是「若 $P \land B$ 成立时执行一次循环体 $c$，$P$ 仍成立」——这正是不变量的定义：**一次循环体执行不破坏 $P$**。
- **第二步，看前提够不够**：循环体可能执行 $0$ 次或 $k$ 次。若 $0$ 次（$B$ 初始为假），则前提从未启用，$P$ 从循环前直接保留到循环后，再叠加 $\neg B$，结论成立。若 $k$ 次，则 $P \land B$ 沿每轮执行逐轮传递——**相当于对循环次数做归纳**：基例是「$0$ 轮」,归纳步正是前提。所以结论对任意有限轮数都成立。
- **第三步，看结论**：$P \land \neg B$ 说「循环结束后，不变量还在，且退出条件已满足」。$P$ 既被循环前状态验证、又被循环体保真，于是成功地从「循环之前」桥接到「循环之后」。
- **第四步，看出它缺什么**：前提只说「若 $B$ 成立则执行一次后 $P$ 还在」，**没说循环一定终止**——所以这是部分正确性的规则。要总正确性，需另证「某个良基度量每轮严格减小」（如 $n - i$），这就是 $\mathrm{wp}$ 里「保证终止」那半边。

## 6 小结

- **霍尔三元组** $\{P\}\; c \;\{Q\}$ 把「程序行为」写成「前置条件 → 程序 → 后置条件」；**部分正确性**不承诺终止，**总正确性**额外要求终止。
- 五条规则（赋值、顺序、条件、循环、强化/弱化）**与语法结构一一对应**，程序结构即证明结构。
- **循环不变量** $P$ 是循环规则的心脏：它连接循环前后，写对它几乎就是证明的全部艺术。
- **最弱前置条件** $\mathrm{wp}$ 把验证变成「从后往前反推 + 检查蕴含」的机械过程，赋值对应替换 $Q[x:=e]$。
- 累加求和例示范了完整骨架：初始化、循环体保真、退出时得结论三步。

在下一节，霍尔逻辑留给我们的最大难点是「不变量从哪来」。**抽象解释（abstract interpretation）**用「把具体状态投影到抽象域 + 不动点」的方式自动算出一批不变量——这是《抽象解释与不变量》的内容，也是静态分析工具的数学心脏。
