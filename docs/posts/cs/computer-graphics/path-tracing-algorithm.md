## 为什么 Whitted 式光追「不够真」

Whitted-Style 只追镜面反射/折射的「单条路径」，对漫反射表面之间的光照无能为力——两个粗糙表面互相反射产生的「颜色渗透」（如红墙把红光映到白沙发上）它算不出来。**路径追踪（path tracing）** 用蒙特卡洛采样解决这个问题：对**所有**表面（包括漫反射），随机采样反射方向，用平均值逼近真实光照。<span class="marginnote">路径追踪由 Kajiya 在 1986 年的渲染方程论文中同时提出：<strong>它不是「追几条光路」，而是「对光路空间做蒙特卡洛积分」</strong>——每个像素发多条光线，每条光线在表面随机反射，最后所有光路贡献的平均就是渲染方程的无偏估计。今天影视渲染的标准就是路径追踪。</span>

本节把「渲染方程 + 蒙特卡洛」的完整落地讲清楚：从方程到估计器、从估计器到递归采样算法。

## 1 路径追踪的估计器：每个方向采一个样本

对渲染方程做蒙特卡洛估计：在每个反射点，从半球里按分布 $p(\omega_i)$ **只采一个方向**，用单样本估计积分：

$$
L_o(p, \omega_o) \approx L_e(p, \omega_o) + \frac{f_r(p, \omega_i, \omega_o)\, L_i(p, \omega_i)\, \cos\theta_i}{p(\omega_i)}
$$

- $\omega_i$ 是从 $p(\omega_i)$ 随机采的一个入射方向。
- 用「单样本」替代「对半球积分」——蒙特卡洛的威力：**一个样本的加权值就是积分的无偏估计**（期望正确，方差大些）。
- $L_i(p, \omega_i)$ 是沿 $\omega_i$ 看过去的入射光——它本身又是「别处的 $L_o$」，递归地追下去。

**为什么「每个方向只采一个样本」也够？** 因为我们对**每个像素发多条光线**，每条光线在每层只采一个方向——最终所有光线的平均值收敛。这就是「路径」的含义：每条光线是**一条**从眼睛出发、逐层随机反射的路径。<span class="marginnote">「一层一个方向，一条一条路径」是路径追踪与 Whitted 的本质区别：Whitted 在镜面处<b>确定性</b>分裂（一条反射 + 一条折射），路径追踪在<b>所有</b>表面<b>随机</b>选一个方向（包括漫反射）。随机 = 能覆盖漫反射的无数方向；每层一个 = 路径是一条「线」而不是一棵「树」，成本可控。</span>

## 2 递归的路径：光线的随机漫步

一条路径从相机出发的旅程：

1. 从相机穿过像素发光线，命中表面点 $p_0$。
2. 在 $p_0$ 处：直接光照（从 $p_0$ 向光源发阴影光线）+ 采样一个反射方向 $\omega_i$，沿它继续追。
3. 命中 $p_1$：同样「直接光照 + 采样反射方向」递归。
4. 直到光线射出场景、或达到最大深度（或用俄罗斯轮盘赌随机终止，下一节）。

每条路径的颜色 = 沿途各点「直接光照」的乘积累积：

$$
L = \sum_{k} \left(\prod_{j<k} \frac{f_r \cos\theta_j}{p_j}\right) L_e(\text{path 上第 } k \text{ 个点的光源贡献})
$$

路径越长，乘积项越多，贡献越小——但必须追够深度才能得到完整全局光照。<span class="marginnote">「路径 = 直接光照链的累积」：每段路径上的反射概率密度相乘，把「这条路有多可能被走到」折算进最终颜色。路径越长，被「俄罗斯轮盘赌」提前终止或乘数衰减的概率越大——所以多数贡献来自短路径，长路径稀疏但重要（间接光）。</span>

## 3 公式解析：单样本估计器为什么无偏

把「为什么采一个方向就能估计整个积分」用期望算一遍：

$$
\mathbb{E}\left[\frac{f_r(\omega_i)\, L_i(\omega_i)\, \cos\theta_i}{p(\omega_i)}\right] = \int_{H^2} \frac{f_r(\omega_i)L_i(\omega_i)\cos\theta_i}{p(\omega_i)}\, p(\omega_i)\, d\omega_i = \int_{H^2} f_r L_i \cos\theta_i\, d\omega_i
$$

- **第一步，期望定义**：随机变量 $g(X)$ 的期望 = $\int g(x) p(x) dx$。
- **第二步，代入**：$g(\omega_i) = f_r L_i \cos\theta_i / p(\omega_i)$，期望 = $\int (f_r L_i \cos\theta / p) \cdot p\, d\omega = \int f_r L_i \cos\theta\, d\omega$。
- **第三步，结果**：单样本估计器的期望恰好等于渲染方程的积分——**无偏**。$p$ 在分子分母消掉，采样分布的选择不影响「正确性」，只影响「方差」。

**辨析｜易错点：** 单样本估计无偏，但**方差极大**——单个样本可能采到「很暗的方向」（$f_r$ 小）导致某条路径贡献很小或很大。方差要靠「多个像素样本平均」来压：每像素 1000+ 条光线（samples per pixel, spp）才有干净图像。另一个坑：**$p$ 必须在 $f_r L_i \cos\theta$ 非零处也非零**——若 $p$ 在某些方向为 0 而那里 $f_r > 0$，那部分贡献被系统性地丢掉，估计器不再无偏（这是「采样覆盖不足」问题）。

## 4 路径追踪的算法骨架

一条完整路径的伪代码：

```
function trace(ray):
    hit = intersect(ray)
    if not hit: return background(ray)

    # 直接光照：向光源发阴影光线
    L = 0
    for light in lights:
        x_light = sample_light(light)            # 在光源上采一点
        if not occluded(hit.p, x_light):         # 阴影测试
            L += BRDF(hit, ω_o, ω_light) * L_light * cosθ / p_light

    # 间接光照：采样一个反射方向继续追
    ω_i = sample_brdf(hit.material, hit.n, ω_o)  # 按 BRDF 采样
    L += BRDF(hit, ω_o, ω_i) * cosθ / p_brdf * trace(ray_from(hit.p, ω_i))

    return L

pixel_color = average(trace(pixel_ray) for spp 条光线)
```

结构清晰：**直接光照（发阴影光线）+ 间接光照（采样方向递归）**，递归终止靠「光线射出场景」或「轮盘赌」。<span class="marginnote">路径追踪的两难在这里显现：<strong>直接光照用「对光源采样」（$p$ 指光源）方差小，间接光照用「对 BRDF 采样」（$p$ 贴合高光锥）更合理</strong>——但直接光照采光源时可能采到 BRDF 很小的方向、间接光采样方向时可能错过光源。两个分布各有所长，于是有了「多重重要性采样」（MIS）把它们混合——那是《采样理论》一节的主角。</span>

## 5 路径追踪的输出：噪声与收敛

路径追踪的图像特点：

- **低 spp 时充满噪声**：每条路径是随机的，噪声方差 $∝ 1/\text{spp}$。
- **收敛到无噪声**：spp → ∞，平均 → 渲染方程的精确解。
- **噪声分布不均匀**：暗处（间接光弱）与高光边缘噪声最大——需要更多样本。

降噪的工程手段：**提高 spp**（贵）、**重要性采样**（让 $p$ 贴合 $f$，降方差）、**降噪器（denoiser）**（用深度学习/双边滤波在后处理消除残留噪声）。影视渲染里，降噪器 + 适量 spp 是标准组合。<span class="marginnote">「噪声是路径追踪的身份证」：一张满是颗粒的图说明它「正在收敛」。实时路径追踪（RTX 的路径追踪、UE 5 的 Lumen）用「每像素 1-2 条光线 + 强降噪器」把噪声压到可用——<strong>光线的「量」与降噪器的「智」是现代路径追踪的两个杠杆</strong>。</span>

## 6 从 Whitted 到路径追踪：一次思想升级

| | Whitted-Style | 路径追踪 |
| --- | --- | --- |
| 反射方向 | 确定性（镜面分裂） | 随机采样（含漫反射） |
| 覆盖 | 镜面/折射路径 | 所有光路（含漫反射间光照） |
| 正确性 | 近似（无全局漫反射） | **渲染方程的无偏解** |
| 代价 | 有限树 | 需要大量样本压方差 |

路径追踪的代价是「每个像素要很多光线」，但换来的是「物理正确的全局光照」——颜色渗透、软阴影、焦散全部自然涌现，不需要任何 hack。<span class="marginnote">路径追踪的意义：它把「渲染」从「一堆近似技巧」变成「求解一个方程」。影视渲染（RenderMan、Arnold、Octane）已全面转向路径追踪；实时渲染正在追赶。理解路径追踪 = 理解「物理正确的光」是怎么算出来的——这是整个渲染学科的终点与起点。</span>

## 7 小结

- **路径追踪 = 渲染方程的蒙特卡洛求解**：每个表面随机采一个反射方向，形成一条「路径」。
- 单样本估计器无偏：$\mathbb{E}[f_r L_i \cos\theta/p] = \int f_r L_i \cos\theta\, d\omega$。
- 算法骨架：**直接光照（阴影光线）+ 间接光照（BRDF 采样递归）**。
- 噪声 $∝ 1/\sqrt{\text{spp}}$，靠提样本、重要性采样、降噪器压制。
- 相比 Whitted，路径追踪覆盖漫反射间光照，是渲染方程的无偏解——影视渲染的标准。
