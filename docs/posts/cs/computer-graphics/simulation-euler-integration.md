## 为什么动画要「物理」？

关键帧动画是「设计好的」，但真实世界的行为——布料飘动、水流、碰撞、爆炸——无法预先设计，只能**模拟**：给定初始状态与物理定律，让系统自己演化。**物理模拟（simulation）** 是图形学的另一条动画路线，它把「牛顿力学」离散化成「每一帧算一步」。<span class="marginnote">模拟与动画的区别：<strong>动画是「预先写剧本」，模拟是「现场算结果」</strong>——布料在风里怎么飘、水撞到石头怎么溅，预先无法穷举，只能靠模拟推演。模拟的数学本质是「对常微分方程（ODE）做数值积分」——给定初始状态与力，推演下一时刻的状态。</span>

本节从最简单的模拟对象——**单粒子**——开始，讲模拟的基本框架：状态、力、以及最基础的数值积分方法——**显式欧拉（explicit / forward Euler）**。

## 1 模拟的状态与动力学

一个粒子的状态由**位置**与**速度**描述：

$$
\mathbf{X}(t) = \begin{pmatrix} \mathbf{x}(t) \\ \mathbf{v}(t) \end{pmatrix}, \qquad \mathbf{v} = \dot{\mathbf{x}}
$$

由牛顿第二定律，加速度由合力决定：

$$
\ddot{\mathbf{x}} = \mathbf{a} = \frac{\mathbf{F}}{m}
$$

力 $\mathbf{F}$ 可以是重力、弹簧力、阻力等。模拟的目标：**给定初始状态 $\mathbf{X}(0)$，求出任意时刻 $t$ 的状态 $\mathbf{X}(t)$**——这是常微分方程的初值问题。<span class="marginnote">「状态 + 力 + 时间演化」是模拟的三要素：<strong>状态是「现在在哪、多快」，力是「现在受什么推动」，积分是「怎么从现在推到下一步」</strong>。几乎所有模拟（粒子、布料、刚体、流体）都复用这个框架——只是状态与力越来越复杂。</span>

## 2 显式欧拉：最朴素的积分

**显式欧拉（forward Euler）** 用「当前时刻的斜率」外推一步：

$$
\mathbf{x}_{t+1} = \mathbf{x}_t + \Delta t\, \mathbf{v}_t
$$

$$
\mathbf{v}_{t+1} = \mathbf{v}_t + \Delta t\, \mathbf{a}_t = \mathbf{v}_t + \Delta t\, \frac{\mathbf{F}_t}{m}
$$

- $\Delta t$：时间步长（每帧的时间间隔）。
- 用**当前**的速度、加速度更新位置与速度——「向前看一步」。

**直觉**：假设在 $\Delta t$ 内速度/加速度不变，用当前值直线外推。步长越小越准，步长越大越粗糙。<span class="marginnote">显式欧拉的哲学是「<strong>用过去的外推未来</strong>」：当前时刻的力决定了下一步的速度，当前的速度决定了下一步的位置——全程只用「现在」的信息，实现简单、一帧一算。它是所有数值积分里最简单的一个，也是理解更复杂积分方法的起点。</span>

## 3 公式解析：一帧的欧拉步进

跟踪一个自由落体粒子一帧的演化：

$$
\begin{aligned}
\mathbf{v}_{t+1} &= \mathbf{v}_t + \Delta t\, \mathbf{g} \\
\mathbf{x}_{t+1} &= \mathbf{x}_t + \Delta t\, \mathbf{v}_t
\end{aligned}
$$

- **第一步，速度更新**：加速度是重力 $\mathbf{g}$（常数），速度加上 $\Delta t \cdot \mathbf{g}$——「每帧速度增重一个 $\Delta t \cdot g$」。
- **第二步，位置更新**：位置加上 $\Delta t \cdot \mathbf{v}_t$——「按当前速度走 $\Delta t$ 时间」。
- **第三步，反复迭代**：每帧重复这两步，粒子在时间上「走」下去。

**辨析｜易错点：** 显式欧拉有两个著名缺陷：

1. **位置更新用了「旧速度」**：$\mathbf{x}_{t+1} = \mathbf{x}_t + \Delta t \mathbf{v}_t$ 用的是更新前速度——如果把 $\mathbf{v}_{t+1}$ 代入（先更新速度再用），会变成「半隐式」，结果大不同（见数值稳定性一节）。
2. **能量不守恒**：显式欧拉系统性地**增加**能量（振荡越振越强）——弹簧会越弹越猛，最终爆炸。这是显式欧拉「不稳定」的根源。

## 4 显式欧拉的稳定性问题：为什么系统会爆炸

显式欧拉最严重的缺陷是**数值不稳定**。以简谐运动（弹簧/圆周）为例，显式欧拉会让振幅**单调增长**——轨道越画越大，最终「爆炸」到无穷。

原因：显式欧拉是「显式」的——**每一步都在「当前状态」处做外推**，而外推的误差会累积。当 $\Delta t$ 超过系统的特征时间尺度时，误差每步放大，系统失稳。

**稳定性判据（直觉版）**：$\Delta t$ 必须足够小——小于系统最快动力学的时间尺度（如弹簧振动的周期）。$\Delta t$ 太大，显式欧拉必然爆炸。<span class="marginnote">「显式欧拉的稳定步长受限于系统最快尺度」是模拟工程的第一条铁律：<strong>布料、流体里的「硬弹簧」或「快振动」会强迫你把 $\Delta t$ 压到极小，否则显式欧拉直接爆掉</strong>。这就是为什么实际模拟几乎不用纯显式欧拉——下一节的「半隐式欧拉」与「隐式方法」都是为了让大步长稳定而生的。</span>

## 5 单粒子模拟的完整实现

一个单粒子模拟的框架（伪代码）：

```
state = (x0, v0)          # 初始状态
for frame in frames:
    a = compute_force(state) / m    # 计算合力加速度
    v_new = v + dt * a              # 更新速度
    x_new = x + dt * v              # 更新位置
    state = (x_new, v_new)          # 推进状态
    render(x_new)
```

「**算力 → 更新速度 → 更新位置 → 渲染**」是模拟的每帧循环。从单粒子到布料、流体，循环不变，只是「力」和「状态」变复杂。<span class="marginnote">「每帧循环 = 算力 + 积分 + 渲染」是所有模拟引擎的骨架：<strong>单粒子的力是重力，布料的力是弹簧 + 重力，流体的力是压强 + 黏性 + 重力</strong>——力越来越复杂，但「算力 → 积分 → 更新」的循环结构始终如一。掌握单粒子，就掌握了模拟的「循环骨架」。</span>

## 6 从单粒子到复杂系统

单粒子是模拟的「hello world」，往上扩展的路径：

- **多粒子**：粒子系统（烟火、雨雪），粒子之间独立或弱交互。
- **质点弹簧**：粒子 + 弹簧连接 = 布料、绳子（下一节）。
- **刚体**：粒子的状态换成「质心位置 + 角向」，加碰撞。
- **流体**：粒子或网格的连续场（最后两节）。

每走一步，状态维度增加、力更复杂、积分更讲究——但「单粒子的欧拉循环」是共同的地基。<span class="marginnote">「模拟的世界从单粒子长出来」：<strong>粒子系统是离散个体的集合，质点弹簧把个体连成结构，刚体把个体换成刚性的整体，流体把个体换成连续场</strong>——单粒子的「状态 + 力 + 积分」框架是这一切的起点。理解单粒子，你就拿到了理解所有模拟的钥匙。</span>

## 7 模拟基础的一页速查

- **框架**：状态（位置 + 速度）+ 力 + 积分——「算力 → 更新 → 渲染」每帧循环。
- **显式欧拉**：用当前速度/加速度外推——简单但不稳定（振荡爆炸）。
- **位置更新用旧速度**——这是显式欧拉的定义特征。
- **稳定步长**：受限于系统最快尺度（弹簧越硬步长越小）。
- **升级路径**：半隐式欧拉（默认）、RK4（精确）、隐式（稳定）。

**一句话记忆**：「显式快但爆、半隐式稳、隐式贵」——积分器的三档，按「刚度」选。

## 8 小结

- **模拟 = 对 ODE 做数值积分**：状态（位置 + 速度）+ 力 + 时间步进。
- **显式欧拉**：用当前速度/加速度外推一步，$\mathbf{v}_{t+1} = \mathbf{v}_t + \Delta t\, \mathbf{a}_t$、$\mathbf{x}_{t+1} = \mathbf{x}_t + \Delta t\, \mathbf{v}_t$。
- 每帧循环：**算力 → 更新速度 → 更新位置 → 渲染**。
- 显式欧拉**不稳定**：振荡系统能量越积越多，步长超阈值就爆炸。
- 位置更新必须用旧速度（否则变成另一种方法）；稳定步长受限于系统最快尺度。
