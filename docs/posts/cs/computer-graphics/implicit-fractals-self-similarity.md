## 为什么分形是隐式表示

前两节的距离函数、水平集是「正经」的隐式几何。而**分形（fractal）** 是隐式家族里最狂野的一支：它用一条**迭代规则**生成无限复杂的形状，而非一个闭式方程。<span class="marginnote">分形（fractal）一词来自拉丁语 fractus（碎裂的），由曼德博在 1975 年造出。核心特征是<b>自相似</b>：形状的任意局部放大后看起来与整体相似——海岸线、山脉、蕨叶、血管都呈现这种「局部复制整体」的结构。</span>

为什么把分形归入隐式表示？因为分形也遵循「条件判定」而非「点枚举」：判断一个点是否在分形里，靠的是**迭代一个函数直到收敛或发散**——它的定义是过程式的，但判定方式是隐式的。分形与 SDF 结合（分形 SDF）正是现代程序化地形的核心工具。

## 1 从自相似到迭代规则

自相似的数学表达是「同一规则反复作用于自身」。以经典的**科赫雪花（Koch snowflake）** 为例：把一条线段中间三分之一换成凸起的折线，然后对每条新线段重复这个操作——无限迭代下去，得到周长无限、面积有限的雪花。<span class="marginnote">科赫雪花的反直觉之处：每一步周长变为原来的 $\frac{4}{3}$，$n$ 步后周长 $(4/3)^n \to \infty$，但面积收敛于有限值。这是「无穷细节塞进有限空间」的最早实例，也让数学家意识到：<strong>分形的维度不是整数</strong>。</span>

分形维度（Hausdorff 维度）可以是非整数：科赫雪花的维度是 $\log 4 / \log 3 \approx 1.26$——它比一条线（1 维）「多」，比一个面（2 维）「少」。维度成为「复杂性度量」，这正是分形与普通几何的分野。

## 2 分形几何的生成机制

图形学里生成分形主要有三条路线：

**迭代函数系统（IFS）**：一组仿射变换（缩放、旋转、平移），随机选一个应用到当前点，反复迭代。Barnsley 蕨就是用 4 个仿射变换生成的经典例子。
**L-系统（L-system）**：一套「重写规则」，用符号串的反复替换生成植物结构。规则「$F \to F[+F]F[-F]F$」反复应用，长出一棵树。
**逃逸时间算法**：对每个点迭代一个复函数，看它是否发散。Mandelbrot 集与 Julia 集都是这样定义的——点属于集合当且仅当迭代不逃逸到无穷。<span class="marginnote">Mandelbrot 集的定义极简：$z_{n+1} = z_n^2 + c$，从 $z_0 = 0$ 出发。$c$ 属于集合当且仅当 $|z_n|$ 永远不趋于无穷。一条二次迭代规则，渲染出世界上最复杂的几何——它是「简单规则 → 复杂结构」的极致示范。</span>

三种机制的共性：**有限规则 + 无限迭代 = 无限细节**。这正是分形作为「数据压缩」的本质——用几行规则存储「无限复杂」的形状。

## 3 分形与噪声：程序化自然

上一节程序纹理里的**噪声**，其实是「软分形」：它不自相似到「数学分形」的程度，但用**分形布朗运动（fBm）** 叠加多层噪声，就能逼近自然的分形结构：

$$
\text{fBm}(p) = \sum_{i=0}^{n-1} \text{amplitude}_i \cdot \text{noise}(\text{frequency}_i \cdot p)
$$

每层噪声频率翻倍（$2^i$）、幅度减半（$\frac{1}{2^i}$）——这就是「自相似」在噪声上的落点：高频层添加细节，低频层决定形状。<span class="marginnote">fBm（fractal Brownian motion）是程序化地形的发动机：把噪声的幅度-频率关系设为「每倍频幅度减半」，叠加 8–16 层，就得到起伏自然的地形高度场。山体的自相似性（近看有石头、远看有峰峦）正是分形叠加的结果。</span>

从 fBm 出发，地形生成管线是：fBm 高度场 → 位移网格 → 根据高度与坡度着色 → 程序化植被。整座山由几行噪声代码生成，而不是几十 GB 的手工模型。

## 4 公式解析：Mandelbrot 集怎么判定一个点

$$
z_{n+1} = z_n^2 + c, \qquad z_0 = 0, \qquad c \in \mathbb{C}
$$

- **第一步，初始化**：取复数 $c = x + iy$（对应平面上一个点），$z_0 = 0$。
- **第二步，迭代**：反复计算 $z_{n+1} = z_n^2 + c$。每步把 $z$ 平方再平移 $c$。
- **第三步，判据**：若 $|z_n|$ 在若干步内超过 2（一旦超过 2 必发散），则该点不属于 Mandelbrot 集；若 $|z_n|$ 始终被限制在 2 以内，属于集合。
- **第四步，上色**：按「第几步逃逸」给点染色——逃逸越慢，颜色越靠近集合边界，渲染出经典的「分形火焰」边界。

**辨析｜易错点：** 分形渲染的常见坑是**迭代次数不够**：逃逸时间算法是「截断的无限」——迭代次数设得太少，边界附近（逃逸很慢的区域）会被误判为集合内，出现生硬的色带。另一个坑是溢出：$z$ 的模会快速爆炸，浮点精度不足时提前发散，需要 `double`（双精度）甚至任意精度计算。

## 5 分形 SDF：可渲染的分形隐式几何

把分形与上一节的 SDF 结合，得到**分形 SDF**——用「距离估算」逼近分形的到表面距离：

- 对迭代式分形（如 Mandelbrot 逃逸时间），用 **距离估算（distance estimation）**：从点的迭代偏导数推一个保守的距离上界。
- 这个估算距离可以喂给球追踪（ray marching），让分形像普通 SDF 一样被光线渲染。

于是分形世界（Mandelbulb、迭代树、分形山脉）可以直接被光线追踪，无需任何网格——**纯隐式渲染**。<span class="marginnote">分形 SDF 让「无法建模的几何」变得可渲染：Mandelbulb（三维 Mandelbrot）没有网格、没有显式表面，只有一条迭代规则，却能被实时光追。这展示了隐式表示的终极形态：<strong>规则即几何，函数即形状</strong>。</span>

## 6 分形的两面：美丽与昂贵

分形的价值与代价都来自同一件事——无限细节：

**价值**：数据压缩（几行规则 = 无限几何）、自然真实（山脉/云/植物的自相似结构）、无缝合（程序化、无需边界处理）。
**代价**：判定昂贵（每次迭代是计算）、渲染成本随细节要求上升、难以「精确控制形状」（规则好写，形状难预测）。<span class="marginnote">分形是「程序化生成」的鼻祖：今天的地形、植被、云层、布料磨损，都继承着「用规则生成无限细节」的思想。从纯数学分形到 fBm 噪声再到引擎里的程序化材质，分形不是「奇技淫巧」，而是程序化内容的数学根基。</span>

在实际工程里，分形通常不是终点，而是「种子」：用 fBm 生成地形高度、用噪声扰动材质，再转成网格或直接用隐式渲染——「规则生成 + 显式渲染」的混合是主流。

## 7 分形 SDF 与渲染实例：从 Mandelbulb 到程序化山脉

把「分形 + SDF」的组合落到两个经典实例，看「规则即几何」怎么变成可渲染的画面。

**实例一：Mandelbulb（三维 Mandelbrot）**。把复平面迭代 $z \to z^2 + c$ 推广到三维，用「球坐标的幂」做三维版本：

$$
z \to r^n \left(\sin(n\theta)\cos(n\phi),\; \sin(n\theta)\sin(n\phi),\; \cos(n\theta)\right) + c
$$

- $r, \theta, \phi$：$z$ 的球坐标，$n$ 是「幂次」（通常是 8，产生花瓣状结构）。
- 距离估算（distance estimation）给出「到集合边界的距离」，喂给球追踪。

**实例二：程序化山脉**。用 fBm（分形布朗运动，见《程序纹理》）生成高度场，山体自相似：

```glsl
// 程序化山脉：fBm 高度场（片元着色器伪代码）
float fbm(vec2 p) {
    float h = 0.0, amp = 0.5, freq = 1.0;
    for (int i = 0; i < 8; i++) {
        h += amp * noise(p * freq);   // 每层频率翻倍、幅度减半
        amp *= 0.5;
        freq *= 2.0;
    }
    return h;
}

// 高度场既做位移（几何）又做颜色（外观）
float h = fbm(world_pos.xz);
color = mix(snow, rock, smoothstep(0.6, 0.8, h));   // 雪线以上变白
```

- 近看有岩石纹理（高频层），远看有峰峦起伏（低频层）。
- 高度场既做位移（几何）又做颜色（雪线以上变白）——「一个函数驱动几何与外观」。

**为什么这些「能渲染」**：它们都提供「距离查询」——Mandelbulb 用距离估算、山脉用高度场——球追踪只需要「每步前进的距离」，不管形状是「解析曲面」还是「迭代规则」。**分形把「几何」变成了「算法」，渲染把「算法」变成了「图像」**——这是程序化内容的本质。

**辨析｜易错点：** 分形渲染的代价常被低估——**每条光线要迭代几十次距离估算**，比普通 SDF 贵一个量级；远处细节爆炸时，迭代步数不够会出现「噪点」。工程对策：限制迭代深度、用「细节等级」（远处少迭代）。另一个坑：**距离估算的「保守性」**——估算过大会「跳过表面」（漏几何），过小会「慢步前进」（慢）——「安全步长」是分形渲染调优的核心。

## 8 分形的一页速查

把分形的关键点压成速查：

- **本质**：迭代规则生成的自相似结构——局部放大后与整体相似。
- **维度**：非整数（如科赫雪花 $\approx 1.26$）——复杂性的度量。
- **生成机制**：IFS（仿射变换迭代）、L-系统（重写规则）、逃逸时间（复迭代）。
- **与图形学**：fBm 噪声是程序化地形/纹理的引擎；分形 SDF + 球追踪实现「规则即几何」。
- **代价**：无限细节 = 无限计算——迭代深度/距离估算要控制。

**一句话记忆**：「有限规则 + 无限迭代 = 无限细节」——分形是「数据压缩」的极致。

## 9 小结

- **分形 = 迭代规则生成的自相似结构**，任意局部放大后与整体相似。
- 分形维度可以是非整数，是「复杂性」的度量。
- 三大生成机制：**IFS、L-系统、逃逸时间**；共性是无限制迭代 + 有限规则。
- **fBm = 多层噪声叠加**，是程序化地形与自然纹理的发动机。
- 分形 SDF + 球追踪让「规则即几何」的纯隐式渲染成为可能。
