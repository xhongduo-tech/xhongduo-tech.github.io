## 为什么需要 Catmull-Clark 细分

Loop 细分只处理三角形网格。但动画与工业设计的角色模型几乎都是**四边形网格**——四边拓扑便于 UV 展开、雕刻与再拓扑。四边网格的细分标准是 **Catmull-Clark 细分**（Edwin Catmull 与 Jim Clark，1978 年提出），它在规则区域（顶点度数 $n=4$）收敛到 **C² 光滑**的极限曲面。<span class="marginnote">Catmull-Clark 细分的地位：Pixar 从《玩具总动员》时代起就用它做角色模型——<strong>「粗控制网格 + Catmull-Clark 细分」是三维动画角色的标准生产流程</strong>。它在规则四边形区域达到 C² 光滑，比 Loop 的 C¹ 更平滑，适合需要「极致顺滑」的曲面。</span>

Catmull-Clark 的另一大优势：**它能处理任意拓扑**——五边面、三角面、极点（顶点周围面数不为 4）都能迭代收敛，这让它成为「通用细分」的首选。

## 1 Catmull-Clark 的三类顶点更新

一次 Catmull-Clark 细分把每个四边形分裂成 4 个，顶点分三类更新：

1. **面点（face point）**：每个面的新中心点 = 该面所有顶点的平均。
2. **边点（edge point）**：每条边的新点 = 边两端点与两个邻接面点取平均。
3. **顶点（vertex point）**：原有顶点更新 = 自身、邻接面点、邻接边点的加权组合。

分裂后每个面产生 4 个新四边形：面点 + 四个边点 + 四个角顶点组合而成。<span class="marginnote">Catmull-Clark 的「面点、边点、顶点」三套公式，是 Loop 细分的四边版。它比 Loop 多一层「面中心」信息——正是这层信息让极限曲面达到 C²（四边网格的规则结构更「丰满」）。</span>

## 2 三类顶点的权重公式

设面 $F$ 有 $n$ 个顶点，顶点 $v$ 的邻接面点平均为 $F$、邻接边点平均为 $R$、自身为 $v$。

**面点**（面 $f$ 的中心）：

$$
v_f = \frac{1}{n}\sum_{i=1}^{n} v_i
$$

**边点**（边 $e = (v_a, v_b)$，邻接两面的面点为 $v_{f1}, v_{f2}$）：

$$
v_e = \frac{v_a + v_b + v_{f1} + v_{f2}}{4}
$$

**顶点**（原有顶点更新）：

$$
v' = \frac{F}{n} + \frac{2R}{n} + \frac{(n-3)v}{n}
$$

其中 $F$ 是邻接面点平均、$R$ 是邻接边点平均、$n$ 是顶点度数。<span class="marginnote">顶点更新公式的权重分配耐人寻味：面点权重 $\frac{1}{n}$、边点权重 $\frac{2}{n}$、自身权重 $\frac{n-3}{n}$，三者相加 $= 1$。$n=4$ 时自身权重 $\frac{1}{4}$——规则顶点主要被「面点 + 边点」拉向局部平均；$n$ 越大自身权重越高（越「顽固」），这正是极点的行为特征。</span>

## 3 公式解析：规则网格（n=4）的极限

对规则四边形网格（所有顶点度数 $n=4$），Catmull-Clark 的极限曲面是**双三次 B 样条曲面**——这是它光滑性的数学根基。

以顶点更新公式为例拆解 $n=4$ 的情形：

**第一步，代入 $n=4$**：$v' = \frac{F}{4} + \frac{2R}{4} + \frac{(4-3)v}{4} = \frac{F + 2R + v}{4}$。
**第二步，读出权重**：面点、边点、自身权重分别是 $1/4, 2/4, 1/4$——边点权重是面点/自身的两倍。
**第三步，与 B 样条对照**：这个加权结构恰好对应双三次 B 样条曲面的离散化——所以规则区域收敛到 C² 的 B 样条曲面，这就是「规则处 C²」的理论来源。

**辨析｜易错点：** C² 光滑只在**规则顶点**（$n=4$）处成立；**奇异顶点**（$n\neq 4$，如极点）处极限曲面通常只有 C¹，且曲率会轻微皱缩（偏转）。实际渲染里极点很难完全避免，视觉上 C¹ 已足够——但设计控制网格时应尽量减少极点，它们会让高光在极点处出现「星芒」瑕疵。

## 4 Catmull-Clark 处理任意拓扑

Catmull-Clark 最强大的性质：**初始网格可以是混合拓扑**（三角、四边、多边形混合），迭代后：

所有面逐渐变成四边形（一次细分后，非四边面变成四边）。
非四边面产生的新顶点成为新的奇异点，但奇异点**数量不再增加**（每次细分只在原奇异点处产生奇异点）。
曲面持续收敛到光滑极限，即使初始网格「很不规整」。

这让 Catmull-Clark 成为「通用细分」——任何多边形网格（包括三角网格）都能用它细分，且自动「四边形化」。<span class="marginnote">Catmull-Clark 的「自适应四边形化」是工程便利：艺术家可以自由地混合三角与四边面建模，细分后统一成四边拓扑。对比 Loop（只能吃三角形），Catmull-Clark 是更宽容的算法——这也是动画管线偏爱它的另一原因。</span>

## 5 Catmull-Clark 在动画工业的形态

Pixar 与主流动画软件（Maya、Blender）里的细分曲面工作流：

1. **控制网格**：艺术家雕刻低分辨率四边网格，塑造角色的「大形」。
2. **预览细分**：渲染时迭代 Catmull-Clark 细分，得到光滑表面。
3. **极限求值**：不真正迭代，直接用极限曲面理论算出光滑位置与法线（Pixar 的极限求值技术）。
4. **置换贴图**：细分后的密集网格承接置换贴图（见《位移贴图》），把细节「烧」进表面。

这个流程把「控制网格 + 细分 + 置换」组合成完整的角色生产管线——一个网格、无限细节。<span class="marginnote">Catmull-Clark 与细分极限求值的组合，让动画师「所见即所得」：编辑控制网格时，屏幕上的光滑曲面即时响应。这正是动画管线「粗模可控、细模可用」的平衡——控制网格是接口，细分曲面是产品。</span>

## 6 Catmull-Clark 与 Loop 的对比总结

| | Loop 细分 | Catmull-Clark 细分 |
| --- | --- | --- |
| 输入网格 | 三角形 | 任意多边形（尤其四边） |
| 面分裂 | 1→4 三角形 | 1→4 四边形 |
| 规则度 | $n=6$ | $n=4$ |
| 规则区光滑度 | C¹ | C² |
| 奇异点行为 | 保留奇异点 | 奇异点数量不增 |
| 应用 | 三角网格处理 | 动画角色、CAD |

两者是互补的细分家族成员——三角网格用 Loop，通用/四边网格用 Catmull-Clark。它们共享「分裂 + 更新 + 收敛」的算法骨架，只是规则参数不同。<span class="marginnote">细分算法的统一视角：所有细分都是「局部线性更新」（每步用邻接顶点加权平均），收敛性由「细分矩阵」的谱决定。Loop 与 Catmull-Clark 只是同一数学框架下的两个实例——理解了谱分析，任何新细分算法都只是换个权重矩阵。</span>

## 6 Catmull-Clark 的工程实现与局限

把 Catmull-Clark 跑起来的工程细节，以及它的边界，值得展开。

**实现要点**：

- **面点、边点、顶点的数据组织**：三类顶点要「分开算、再合并」——原地更新会「污染」（面点算完边点要用面点，顺序错乱）。
- **边界处理**：边界边/边界顶点没有「另一侧邻居」——权重公式要用边界版本（如边界边点取中点）——漏了边界处理，边界「塌陷」。
- **顶点度数 n 的散列**：顶点更新公式里的 $1/n$ 要对「每个顶点」算——度数不同，权重不同——「预处理顶点度数」避免重复计算。

**局限**：

- **奇异点（$n \neq 4$）处 C¹ 而非 C²**——极点处曲率不连续，高光有「星芒」——「减少奇异点」是控制网格设计的原则。
- **极限曲面的求值**：不真迭代，用「极限公式」算极限位置/法线——Pixar 的「极限求值」是标准做法。
- **控制网格的拓扑要求**：Catmull-Clark 对「任意拓扑」健壮，但「极度退化的输入」（共线面、零面积面）会让细分「炸」——输入要清理。

**辨析｜易错点：** 两个工程坑：

1. **「细分次数与视觉」**——3 次细分通常足够（面数 ×64），再多视觉差异微小、成本暴涨——「3 次是甜点」。
2. **「细分改变体积」**——细分曲面的极限通常比控制网格「小一点」（角被磨圆）——「需要精确体积」的场景要「极限体积修正」。

**「Catmull-Clark 的工程 = 分步更新 + 边界处理 + 极限求值」**——理解了实现与局限，你就知道「为什么动画软件里角色模型要『控制网格 + 细分』一起用」。

## 7 小结

- **Catmull-Clark 细分**处理任意多边形网格，面点、边点、顶点三套更新公式。
- 面点 = 面顶点平均；边点 = 两端点 + 两邻接面点平均；顶点 = $\frac{F}{n}+\frac{2R}{n}+\frac{(n-3)v}{n}$。
- 规则顶点（$n=4$）收敛到 **C² 的双三次 B 样条曲面**；奇异点处降至 C¹。
- 任意拓扑可用，迭代后自动四边形化，奇异点数量不增——动画工业的标准。
- Loop（三角、C¹）与 Catmull-Clark（四边/通用、C²）互补，共享细分数学框架。
