## 为什么曲线如此重要

网格是离散的，但真实世界的形状是连续的：字体的笔画、汽车的车身、动画的轨迹。用网格去表达连续曲线需要海量顶点；用**参数曲线**表达则只需几个控制点。贝塞尔曲线（Bézier curve）是最经典的参数曲线，也是字体（TrueType）、矢量图形、动画路径、曲面（贝塞尔曲面）的共同基石。<span class="marginnote">贝塞尔曲线由法国工程师 Pierre Bézier（雷诺）与 Paul de Casteljau（雪铁龙）在 1960 年代独立发明，用于汽车车身设计。其核心思想：<strong>曲线完全由一组控制点决定，不通过（多数）控制点，而是被它们「牵拉」</strong>。</span>

理解贝塞尔曲线，等于掌握了「用参数表达连续几何」的第一门语言——下一节的曲线性质、B 样条、NURBS、贝塞尔曲面全都从这里生长。

## 1 从线性插值到二次贝塞尔

一切的起点是**线性插值（lerp）**：两点 $b_0, b_1$ 之间的直线，参数 $t \in [0,1]$ 处的点：

$$
b_0^1(t) = (1-t)\, b_0 + t\, b_1
$$

$t=0$ 时在 $b_0$，$t=1$ 时在 $b_1$，$t$ 均匀扫过整条线段。

**二次贝塞尔曲线**用三个控制点 $b_0, b_1, b_2$。核心思想是**递归插值**：

1. 在线段 $b_0b_1$ 上取插值点 $b_0^1$，在线段 $b_1b_2$ 上取插值点 $b_1^1$。
2. 在两点 $b_0^1, b_1^1$ 之间再取插值点 $b_0^2$。
3. 当 $t$ 从 0 扫到 1，$b_0^2$ 的轨迹就是二次贝塞尔曲线。

**关键：曲线上的每个点都是「对插值再插值」的结果**——这就是 de Casteljau 算法的雏形：每一层都在上一层的中点之间插值。<span class="marginnote">为什么「递归插值」能得到漂亮的曲线？因为每一层插值都是线性的（直的），但「对直线插值出来的点再插值」引入了二次项，产生了弯曲。控制点离得越远，中间那一层插值点偏离得越厉害，曲线弯得越明显——控制点就是这样「牵拉」曲线的。</span>

## 2 de Casteljau 算法：通用的递归插值

把递归推广到 $n+1$ 个控制点 $b_0, b_1, \ldots, b_n$，**de Casteljau 算法** 用三角形表格逐层插值：

$$
b_i^k(t) = (1-t)\, b_i^{k-1}(t) + t\, b_{i+1}^{k-1}(t), \qquad k = 1, \ldots, n,\; i = 0, \ldots, n-k
$$

其中 $b_i^0 = b_i$（第 0 层是控制点本身）。迭代 $n$ 层后，$b_0^n(t)$ 就是参数 $t$ 处的曲线点。

以三次（4 个控制点）为例，$t$ 固定时：

$$
b_0^1, b_1^1, b_2^1 \xrightarrow{\text{插值}} b_0^2, b_1^2 \xrightarrow{\text{插值}} b_0^3
$$

$b_0^3$ 即曲线在 $t$ 处的点。**这棵「插值树」就是 de Casteljau 算法的全部**：简单、稳定、与维度无关（控制点可以是二维或三维）。<span class="marginnote">de Casteljau 算法的实用性：它只用加法和乘法（没有平方、开方），数值稳定，且给出了「切向量」的副产品——最后一步插值 $b_0^2 \to b_1^2$ 的方向就是曲线在该点的切线方向。因此它既是求点算法，也是求导算法。</span>

## 3 公式解析：二次贝塞尔曲线的展开

把 de Casteljau 的两层插值展开，看二次贝塞尔的解析式：

$$
\begin{aligned}
b_0^1(t) &= (1-t)b_0 + t b_1 \\
b_1^1(t) &= (1-t)b_1 + t b_2 \\
b_0^2(t) &= (1-t)b_0^1 + t b_1^1
\end{aligned}
$$

- **第一步，代入**：$b_0^2 = (1-t)\big[(1-t)b_0 + t b_1\big] + t\big[(1-t)b_1 + t b_2\big]$。
- **第二步，展开合并**：$= (1-t)^2 b_0 + 2(1-t)t\, b_1 + t^2 b_2$。
- **第三步，读出权重**：三个控制点的系数分别是 $(1-t)^2,\; 2(1-t)t,\; t^2$——这是**伯恩斯坦多项式** $B_0^2, B_1^2, B_2^2$。**二次贝塞尔 = 控制点以伯恩斯坦基做凸组合**。

**辨析｜易错点：** 伯恩斯坦权重和为 1（$(1-t)^2 + 2(1-t)t + t^2 = 1$），所以曲线**位于控制点的凸包内**——这是贝塞尔曲线的核心几何性质。另一个易错点：控制点**多数不在曲线上**（只有 $b_0$ 和 $b_n$ 在端点上），「曲线经过控制点」是常见误解——控制点只是在「拉扯」曲线。

## 4 贝塞尔曲线的三个关键性质

- **端点插值**：曲线起点在 $b_0$、终点在 $b_n$（$t=0,1$ 时权重退化）。
- **凸包性质**：曲线完全落在控制点的凸包内——设计曲线时能预估曲线的「活动范围」。
- **仿射不变性**：对控制点做仿射变换（旋转/平移/缩放），等价于对曲线做同一变换——建模时变换曲线只需变换控制点。
- **切向量**：端点的切向量方向 = 首末两条控制边的方向，即 $b_0 \to b_1$ 和 $b_{n-1} \to b_n$——这让两条曲线拼接时可以精确控制连续性。<span class="marginnote">「仿射不变性」是参数曲线最重要的工程性质：旋转一个物体，只需旋转它的控制点，曲线自动跟着转——不需要重新采样曲线。这也解释了为什么建模软件里变换曲线就是变换控制点手柄。</span>

## 5 贝塞尔曲线在图形学中的位置

贝塞尔曲线是「参数曲线家族」的起点，它直接通向：

**贝塞尔曲面**：对两族贝塞尔曲线做张量积，得到曲面（见《贝塞尔曲面》）。
**B 样条 / NURBS**：克服贝塞尔「全局牵拉」的缺点——移动一个控制点影响整条曲线，而 B 样条只影响局部。
**字体与矢量图**：TrueType 用二次贝塞尔，PostScript/SVG 用三次贝塞尔——你看到的每个字、每张矢量图都是贝塞尔曲线拼接。

一个常见的疑问：既然有 B 样条更好，为什么还学贝塞尔？因为 **B 样条在数学上是「分段贝塞尔」的推广**——每条 B 样条段都能写成贝塞尔形式。贝塞尔是积木，B 样条是建筑。<span class="marginnote">「贝塞尔是积木，B 样条是建筑」：B 样条通过「节点向量」把多项式段拼接起来，每段在数学上等价于一条贝塞尔。所以学透贝塞尔的插值、凸包、端点性质，B 样条只是「把多段贝塞尔按连续条件拼起来」——下一节《贝塞尔曲线的性质与分段构造》正是这个过渡。</span>

## 6 贝塞尔曲线的求值与实现细节

把 de Casteljau 算法落成代码，几个实现要点决定「效率与正确性」。

**三角形求值的实现**：一维数组原地迭代——$b$ 数组存放当前层，每次迭代长度减一：

```cpp
// 输入：控制点数组 b（长度 n+1），参数 t；返回：曲线上的点
Point deCasteljau(Point b[], int n, float t) {
    for (int k = 1; k <= n; ++k)
        for (int i = 0; i <= n - k; ++i)
            b[i] = (1 - t) * b[i] + t * b[i + 1];  // 相邻两点插值
    return b[0];
}
```

- 每层「相邻两点插值」，长度减一，最后一层只剩一个点——即曲线点。
- 复杂度 O(n²)（n 个控制点），数值稳定（只用加乘）。

**求切向量**：最后一步插值的「方向」就是曲线在该点的切线：

$$
\vec{T} = b_1^{n-1} - b_0^{n-1}
$$

- de Casteljau 的中间层「免费」给出切向——无需额外求导。
- 二次曲线的切线：$b_0^1 \to b_1^1$ 方向；三次的：$b_0^2 \to b_1^2$ 方向。

**求值频率的工程权衡**：曲线要渲染成「折线」——沿 $t$ 采样 $N$ 个点连直线。$N$ 太小「棱角」（不像曲线），太大浪费（点比像素密）——**「按曲线的弧长与曲率自适应采样」**（平坦处少采、弯曲处多采）是高效渲染曲线的关键。

**辨析｜易错点：** 三个实现坑：

1. **$t$ 越界**——$t < 0$ 或 $t > 1$ 时曲线外推，行为未定义——调用前钳制 $t$。
2. **原地更新的顺序**——内层循环必须「从前往后」更新（$b[i]$ 用了 $b[i+1]$ 的旧值）——顺序反了会「污染」。
3. **浮点累积**——深层迭代（高次曲线）累积误差——「用 de Casteljau（加乘）而非展开多项式（乘方）」能显著降低误差。

**「de Casteljau 是贝塞尔曲线的『原子操作』」**——理解它的实现，你就知道「曲线求值、求切、渲染」三步怎么在代码里完成。

## 7 小结

- **贝塞尔曲线 = 控制点通过伯恩斯坦基的凸组合**，多数控制点不在曲线上。
- **de Casteljau 算法**：递归插值求曲线点，稳定、通用、附带切线。
- 二次展开 $b_0^2 = (1-t)^2 b_0 + 2(1-t)t\, b_1 + t^2 b_2$，权重和恒为 1。
- 核心性质：**端点插值、凸包、仿射不变性、端点切线方向**。
- 贝塞尔是积木：贝塞尔曲面、B 样条、NURBS、字体矢量图全部建立在它之上。
