## 为什么需要纹理映射

Blinn-Phong 给了物体明暗，但每个物体还是「一个颜色」——红苹果、白球、灰墙。真实世界充满了**图案**：墙上的砖纹、地板的木纹、球衣的队标。逐像素程序化生成这些图案不现实，图形学用**纹理映射（texture mapping）**解决：把一张二维图像「贴」到三维表面，用表面的局部坐标去查这张图。<span class="marginnote">纹理映射的本质是「<b>用二维坐标索引颜色</b>」：每个三角形顶点带一个纹理坐标 $(u,v) \in [0,1]^2$，像素处插值得到自己的 $(u,v)$，再用 $(u,v)$ 去纹理图上取色。$(u,v)$ 是「这个点在纹理图上的位置」。</span>

上节我们说过，光栅化把顶点属性插值到每个片元。纹理坐标就是最重要的顶点属性之一——本节把它落实：**重心坐标怎么插值纹理坐标，插值后怎么采样纹理**。

## 1 纹理坐标：把表面参数化到 [0,1]²

每个顶点除了位置、法线，还带一个**纹理坐标（texture coordinate / UV coordinate）**：

$$
\text{vertex} = (x, y, z, u, v)
$$

$(u, v)$ 约定在 $[0,1]^2$ 内，$(0,0)$ 通常在纹理图的左下角（或左上角，取决于 API 约定）。<span class="marginnote">$(u,v)$ 的取值范围与方向约定随 API 而不同：OpenGL 传统上原点在左下，DirectX 在左上。建模软件导出的模型已经把这些约定「烤」进顶点的 UV 数据里，引擎只需原样传递。UV 展开（unwrap）本身是建模里的一门手艺——把球面摊平成一张地图。</span>

把纹理贴到球体上：球体被 UV 展开成一张矩形图（像世界地图投影），球面上的每个点对应图上唯一一个 $(u,v)$。纹理映射的质量，取决于 UV 展开是否平滑、无撕裂、无过度拉伸。

## 2 重心坐标插值：从顶点 UV 到片元 UV

三角形三个顶点的纹理坐标 $(u_A, v_A), (u_B, v_B), (u_C, v_C)$，片元 $p$ 处的纹理坐标用**重心坐标** $(\alpha, \beta, \gamma)$ 线性插值：

$$
u = \alpha u_A + \beta u_B + \gamma u_C, \qquad v = \alpha v_A + \beta v_B + \gamma v_C
$$

$(\alpha,\beta,\gamma)$ 正是光栅化阶段已经算好的面积比（见《三角形遍历》）。**同一组重心坐标插值所有顶点属性**——深度、法线、颜色、UV——这是图形管线的统一机制。<span class="marginnote">重心坐标是「一权多用」的典型：只要知道像素在三角形里的 $(\alpha,\beta,\gamma)$，任何顶点属性都能用同一组权重混合。GPU 光栅化器对每个片元算一次重心坐标，然后对所有属性各做一次加权和。</span>

**辨析｜易错点：** 屏幕空间的重心坐标**不能直接用于透视投影下的 UV 插值**。因为投影是非线性的，屏幕上的等距与三维空间中的等距不一致——直接线性插值 $u,v$ 会让远处纹理「漂移」（消失点附近的纹理呈波浪状）。正确做法是**透视校正插值**（见下节公式解析）。

## 3 采样纹理：最近邻与双线性

片元有了 $(u,v)$，就可以去纹理图上取颜色。纹理图是一张像素网格，$(u,v)$ 是连续坐标，落在像素之间的哪个位置？两种标准采样方式：

**最近邻（nearest neighbor）**：取最近的纹素（texel）颜色。速度快，但放大时出现块状马赛克。
**双线性（bilinear）**：取周围 4 个纹素，按距离加权平均。平滑，放大时过渡自然，是默认选择。<span class="marginnote">双线性插值：先对两对水平相邻纹素做线性插值，再对两个结果做一次垂直插值——「双线性」因此得名。它把离散的纹素网格变成一个连续的颜色函数，代价是三次插值、约 4 次纹理采样。</span>

**纹素（texel）** 是纹理的像素。纹理映射里的分辨率不匹配问题（放大/缩小）引出走样——正是下一节《纹理采样问题》的主题。

## 4 公式解析：透视校正插值

为什么直接插值 $u,v$ 会错？追到底层，插值应该发生在**三维空间**里，但光栅化是在**屏幕空间**插值。两个空间之间隔着透视除法（除以 $w$）。正确公式：

$$
u_{\text{correct}} = \frac{\frac{\alpha u_A}{w_A} + \frac{\beta u_B}{w_B} + \frac{\gamma u_C}{w_C}}{\frac{\alpha}{w_A} + \frac{\beta}{w_B} + \frac{\gamma}{w_C}}
$$

- **第一步，问题**：屏幕空间重心坐标 $(\alpha,\beta,\gamma)$ 描述的是「屏幕上的权重」，而 UV 应在三维空间线性插值。
- **第二步，除以 w 再插值**：把每个顶点的 $u$ 先除以该顶点的齐次 $w$，对 $\frac{u_i}{w_i}$ 做线性插值——因为 $\frac{u}{w}$ 与屏幕坐标是线性相关的。
- **第三步，除以分母**：对权重 $\frac{\alpha}{w_A} + \cdots$ 做同样插值（它正是 $\frac{1}{w}$ 的插值），相除抵消透视的影响。

**辨析｜易错点：** 现代 GPU 在光栅化阶段自动做透视校正，程序员几乎感知不到。但在软件光栅化器、自定义插值、以及「把 UV 用于非颜色目的」（如程序纹理、视差映射）时，忘记透视校正会得到偏移的纹理与错误的深度。**「插值对象要选对空间」是一条普适规律**——所有顶点属性在透视下都应先除以 $w$ 再插值。

## 5 纹理映射在管线的位置与扩展

纹理映射在片元阶段执行：片元着色器用插值 UV 采样纹理，得到漫反射颜色 $k_d$（作为 Blinn-Phong 的漫反射项输入）。但纹理不只是「颜色贴图」：

- **漫反射贴图（albedo）**：物体的底色。
- **法线贴图（normal map）**：存法线方向，扰动光照。
- **高光贴图（specular map）**：存 $k_s$ 与粗糙度。
- **环境贴图（environment map）**：存周围环境的颜色，用于反射与 IBL。

这些「用纹理存非颜色数据」的技巧，把纹理从「图片」升级为「表面属性的通用容器」——后面《凹凸贴图》《法线贴图》《位移贴图》都是这条思路的展开。<span class="marginnote">纹理的通用化是渲染史的里程碑：一旦「纹理 = 表面属性的查找表」，任何随表面变化的数据（粗糙度、金属度、AO、发光）都可以用一张图表达。PBR 的材质系统正是围绕多张纹理（base color、roughness、metallic、normal、AO）搭建的。</span>

## 6 纹理映射的工程实践：UV 展开与采样设置

理论讲完了「怎么插值、怎么采样」，工程上还有一层「怎么把纹理贴对」——这层决定了纹理映射的质量上限。

**UV 展开（unwrap）** 是把三维表面摊平成二维平面（类似地球仪展开成地图）的过程，几个要点：

- **接缝（seam）**：摊平必然有「切开」的地方——球面无法无拉伸地摊成矩形，一定存在接缝。接缝要放在「不显眼」的位置（背后、底部）。
- **拉伸（stretch）**：摊平时的面积/角度变形——拉伸大的区域纹理「糊」或「歪」。建模工具的「棋盘格预览」就是检查拉伸。
- **UV 岛（island）**：通常把表面切成若干「岛」分别展开（脸、四肢各一岛），岛之间用接缝分开。

**采样设置（sampler state）** 决定「超出 UV 范围」与「缩放」的行为：

- **Wrap 模式**：$[0,1]$（平铺）、`CLAMP_TO_EDGE`（拉伸边缘）、`MIRRORED_REPEAT`（镜像）——决定了 $u,v$ 超出 $[0,1]$ 时取什么。
- **Filter 模式**：`NEAREST`（最近邻）、`LINEAR`（双线性）、`TRILINEAR`（三线性） + Mipmap——决定了缩放时的插值（见《纹理采样问题》）。
- **Anisotropic**：各向异性过滤的倍数（见《各向异性过滤》）。

**辨析｜易错点：** 三个高频工程坑：

1. **UV 翻转/镜像**——UV 岛的方向不一致（一个岛 $v$ 轴反了），贴图在该岛「镜像」——烘焙法线贴图时尤其致命。
2. **接缝处的双线性出血**——接缝两侧纹素插值时「采到对面」——要加「UV 填充」（padding）或调整接缝。
3. **Mipmap 层级在 UV 撕裂处错乱**——UV 不连续处，屏幕差分突变，Mipmap 选层错误——需要「UV 缝合」或手动层级修正。

纹理映射的「工程 80%」都在 UV 与采样设置——理解插值与采样的数学，才能诊断这些「贴图贴不对」的工程问题。

## 7 纹理映射与着色器的配合：一个片元着色器的解剖

把「纹理映射」放进一个真实的片元着色器，看它怎么与光照、法线配合：

```glsl
in vec2 vUV;                 // 光栅化插值后的纹理坐标
uniform sampler2D uAlbedo;
uniform sampler2D uNormalMap;
uniform vec3 uLightDir;

void main() {
    vec3 albedo = texture(uAlbedo, vUV).rgb;
    vec3 n = texture(uNormalMap, vUV).xyz * 2.0 - 1.0;  // 法线贴图解码
    float diff = max(dot(n, normalize(uLightDir)), 0.0);
    fragColor = vec4(albedo * diff, 1.0);
}
```

- **UV 是「一切纹理采样的入口」**——漫反射、法线、粗糙度、金属度全是同一个 UV 采样——「UV 是材质系统的坐标轴」。
- **一张 UV 对齐所有贴图**——建模时 UV 展开一次，所有贴图都按它采样——「贴图之间要对齐」是资产规范。

**为什么「一个 UV 采多张贴图」**：材质 = 多张属性贴图（albedo、normal、roughness…），它们共享同一套 UV——「一张 UV 定义表面参数化，所有属性贴图挂在这套参数化上」——这是 PBR 材质系统的数据组织。

**辨析｜易错点：** 一个工程坑——「UV 的翻转/镜像会让所有贴图一起错」——UV 是「全局坐标」，一处翻转，所有贴图在该处镜像——「UV 是材质系统的地基，地基错则全错」。

## 8 小结

- **纹理映射 = 用二维纹理坐标 $(u,v)$ 查颜色**，顶点带 UV、片元插值 UV、纹理提供颜色。
- 片元 UV 用**重心坐标**从顶点 UV 插值得到，同一组权重插值所有属性。
- 采样方式：最近邻（块状）与双线性（平滑），双线性是默认。
- 透视投影下必须用**透视校正插值**（除 $w$ 再插值再除），否则纹理漂移。
- 纹理不只是颜色图，更是「表面属性的通用容器」，是 PBR 材质的基座。
