## 为什么高斯泼溅是「实时」的答案

NeRF 的训练与渲染都慢——体渲染的「每像素积分」与实时管线冲突。2023 年的 **3D Gaussian Splatting（3DGS，3D 高斯泼溅）** 换了一条路：**把场景表示成大量「3D 高斯基元」，用可微光栅化直接「泼」到屏幕**——训练只要几分钟、渲染实时（数百 FPS）。<span class="marginnote">3DGS 的洞见：<strong>把场景拆成「一团团有颜色、有形状的高斯云」——每个高斯是一个椭球光斑（位置、协方差、颜色、不透明度）</strong>。渲染时把高斯投影到屏幕、按深度排序、像「泼颜料」一样叠涂到像素上——这是「可微光栅化」替代「体渲染积分」，把神经渲染拉回 GPU 最擅长的光栅化轨道。结果：训练分钟级、渲染实时、质量匹敌 NeRF。</span>

本节讲 3DGS 的表示、渲染、训练，以及它为什么是当前「新视角合成」的主流。

## 1 3D 高斯基元：场景的基本粒子

场景由 $N$ 个**3D 高斯**组成，每个高斯是一个「椭球光斑」，携带参数：

- **位置** $\mu$：高斯中心。
- **协方差** $\Sigma$：椭球的形状（由旋转矩阵 $\mathbf{R}$ 与缩放 $\mathbf{S}$ 参数化）。
- **颜色** $\mathbf{c}$：球谐系数（视角相关颜色）。
- **不透明度** $\alpha$：该光斑的透光程度。

每个高斯的「空间分布」：

$$
G(\mathbf{x}) = e^{-\frac{1}{2}(\mathbf{x}-\mu)^\top \Sigma^{-1} (\mathbf{x}-\mu)}
$$

场景 = 「一团团椭球光斑的集合」——像点云，但每个点有「大小、形状、颜色、透明度」。<span class="marginnote">「高斯 = 有体积的点」：<strong>点云的点是『零维』的（一个位置），高斯是『三维』的（位置 + 椭球形状）——一簇高斯能表达一片连续的表面，就像『糊在三维空间的柔焦光斑』</strong>」——协方差决定光斑的胖瘦、方向（椭球），颜色球谐让高光随视角变化。数量从几千（简单物体）到几百万（大场景），训练时从「随机撒点」长出「贴合场景的分布」。</span>

## 2 渲染：把高斯「泼」到屏幕

3DGS 的渲染是「可微光栅化」——比体渲染快得多：

1. **投影**：每个 3D 高斯投影到屏幕，变成「2D 高斯」（屏幕空间的光斑）。
2. **排序**：按深度（离相机远近）排序所有高斯。
3. **泼溅（splatting）**：从远到近，把每个 2D 高斯「泼」到覆盖的像素——颜色按高斯权重 + 不透明度 α 混合。

像素颜色 = 沿深度排序的高斯 α 混合：

$$
C = \sum_{i=1}^{N} c_i\, \alpha_i\, T_i, \qquad T_i = \prod_{j<i}(1 - \alpha_j)
$$

- 每个像素只被「覆盖它的高斯」影响——不像体渲染要沿视线采样数百点。
- 排序 + α 混合 = 「传统管线」的透明混合（画家算法），GPU 硬件天然擅长。<span class="marginnote">「泼溅 = 传统透明混合」：<strong>渲染不是『积分』而是『排序 + 混合』——把高斯按深度排好，从远到近用 α 混合叠涂，这正是图形管线里透明物体的标准做法</strong>」——所以 3DGS 能直接吃 GPU 的光栅化硬件，每像素只需处理「覆盖它的少量高斯」而非「数百个采样点」。这就是它实时（数百 FPS）的硬件基础。</span>

## 3 训练：从照片长出高斯

3DGS 的训练与 NeRF 同为「逆向渲染」（可微渲染 + 梯度优化）：

1. **初始化**：从 SfM 点云初始化高斯（或用随机点）。
2. **渲染**：可微光栅化渲染当前视角。
3. **损失**：渲染图 vs 照片的误差（L2 + SSIM），反向传播。
4. **更新参数**：梯度下降更新高斯的 μ、Σ、颜色、α。
5. **自适应密度化**：**克隆/分裂/修剪高斯**——哪里细节不足就克隆（复制高斯细化）、哪里高斯太大就分裂、哪里透明无用就删除——让高斯数量与分布「生长」成贴合场景的形态。

「梯度优化参数 + 自适应生长高斯」——场景从「随机点云」长成「精确的椭球集合」。<span class="marginnote">「训练 = 让高斯『长大成人』」：<strong>一开始是一堆随机高斯，渲染图糊成一片；梯度告诉每个高斯『该往哪挪、该多大、该什么色』，配合『哪里细节不足就克隆、哪里透明就删除』的密度化，几万次迭代后高斯『排布』成精确的场景</strong>」——这套「参数优化 + 结构生长」让 3DGS 在几分钟内达到 NeRF 数小时的质量——可微渲染 + 显式表示的速度优势。</span>

## 4 公式解析：高斯的屏幕投影

把「3D 高斯怎么变成 2D 光斑」拆开：

$$
\Sigma' = \mathbf{J}\, \mathbf{W}\, \Sigma\, \mathbf{W}^\top \mathbf{J}^\top
$$

- **第一步，视图变换**：3D 高斯的协方差 $\Sigma$ 经视图矩阵 $\mathbf{W}$ 变换到相机空间。
- **第二步，投影线性化**：透视投影是非线性的，但「局部」可线性化——用投影的雅可比矩阵 $\mathbf{J}$ 近似。
- **第三步，2D 协方差**：$\Sigma'$ 是变换后的 2D 高斯协方差——决定光斑在屏幕上的形状（椭圆）。
- **第四步，光斑值**：屏幕上每个像素的「高斯贡献」由这个 2D 高斯计算——椭圆内权重高、外为零（裁剪）。

**辨析｜易错点：** 投影线性化的**雅可比近似**在「相机离高斯很近」或「大高斯」时误差大（光斑扭曲）。另一个坑：**协方差必须保持正定**（半正定的 Σ 才合法）——参数化用旋转 + 缩放（$\Sigma = \mathbf{R}\mathbf{S}\mathbf{S}^\top\mathbf{R}^\top$）保证正定，直接优化 Σ 会退化。

## 5 3DGS vs NeRF：对比与选型

| | NeRF | 3D Gaussian Splatting |
| --- | --- | --- |
| 场景表示 | MLP（隐式函数） | 显式高斯基元 |
| 渲染 | 体渲染积分（慢） | 可微光栅化 + α 混合（快） |
| 训练时间 | 小时级 | **分钟级** |
| 渲染速度 | 秒级/帧 | **实时（数百 FPS）** |
| 可编辑 | 难（权重里的场景） | 较易（高斯可删改） |
| 内存 | 小（MLP 权重） | 大（百万高斯） |

**选型**：追求质量与紧凑 → NeRF 家族；追求实时与可编辑 → 3DGS。当前「新视角合成」的工业主流是 3DGS——它把神经渲染拉回了「可实时、可交互、可编辑」的轨道。<span class="marginnote">「3DGS 是『显式表示对隐式表示的胜利』（在实时场景）」：<strong>NeRF 的隐式函数紧凑但慢、不可编辑；3DGS 的显式高斯占显存但快、可编辑（删一个高斯就是删一块场景）、可实时</strong>」——这正是《几何表示》篇「显式 vs 隐式」的现代重演：表示方式的选择决定算法的「能力与边界」。3DGS 的『可编辑』让它成为游戏、影视、数字人等领域的新宠。</span>

## 6 3DGS 的局限与未来

3DGS 并非终点：

- **显存占用大**：百万高斯 × 每高斯参数，大场景内存压力大。
- **高斯「糊」与「飞溅伪影」**：远处细节不足、高光处有「光斑」伪影。
- **拓扑/编辑**：删除高斯会「露洞」，编辑仍不如网格直观。
- **与管线的融合**：3DGS 与光栅化/光追管线的深度融合仍在演进。

3DGS 的后续：**多分辨率高斯、高斯 + 网格混合、高斯与物理模拟结合**（可变形高斯）、以及被游戏引擎集成（实时渲染的神经场景）——它是「神经渲染融入传统管线」的桥梁，也是下一节《神经渲染与传统管线的融合》的起点。<span class="marginnote">「3DGS 的『不完美』正是研究前沿」：<strong>显存（压缩高斯）、清晰度（多分辨率）、可编辑性（与网格融合）、物理性（可变形高斯做动画）——每个局限都是一个活跃研究方向</strong>」——而它在实时渲染的成功证明了一件事：神经渲染终于「配得上」GPU 的光栅化硬件。下一节我们把这个趋势放大——看神经渲染如何与传统渲染管线真正融合。</span>

## 7 3DGS 的一页速查

- **表示**：大量 3D 高斯基元（位置、协方差、颜色球谐、不透明度）——「有体积的点」。
- **渲染**：投影高斯 → 按深度排序 → α 混合泼溅——可微光栅化，实时。
- **训练**：逆向渲染 + 自适应密度化（克隆/分裂/修剪）——分钟级。
- **优势**：实时渲染、可编辑、细节好；**劣势**：显存大、远处糊。
- **vs NeRF**：显式 vs 隐式、光栅化 vs 体渲染、实时 vs 慢——当前新视角合成主流。

**一句话记忆**：「高斯当点、泼溅当渲染、密度化当训练」——3DGS 的三根支柱。

## 8 小结

- **3DGS** = 场景表示成「3D 高斯基元」（位置、协方差、颜色、不透明度），可微光栅化渲染。
- **渲染 = 排序 + α 混合**：投影高斯 → 按深度排序 → 泼溅叠涂——GPU 光栅化硬件天然擅长，实时数百 FPS。
- **训练 = 逆向渲染 + 自适应密度化**：梯度优化高斯参数，克隆/分裂/修剪让高斯「生长」贴合场景。
- 协方差用旋转 + 缩放参数化保证正定；投影用雅可比线性化近似。
- vs NeRF：训练分钟级、渲染实时、可编辑，但显存大——当前新视角合成的主流。
- 局限（显存、清晰度、编辑）是研究前沿——通向神经渲染与传统管线的融合。
