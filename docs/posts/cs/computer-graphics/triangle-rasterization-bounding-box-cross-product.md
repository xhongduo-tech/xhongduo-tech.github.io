## 为什么需要三角形遍历

上一节我们确立了「三角形是基本图元」「点是否在三角形内可用叉积判定」。但一个三角形只占屏幕的一小块——屏幕有上百万像素，逐像素跑全部三角形是天文数字。**三角形遍历（triangle traversal）**要回答：给定一个屏幕空间三角形，高效地找出它覆盖的所有像素。<span class="marginnote">光栅化的最朴素思路是「对每个像素、对每个三角形」都做一次内外判定——复杂度是 像素数 × 三角形数，完全不可行。三角形遍历的核心是<b>剪枝</b>：先排除绝大多数「显然不相交」的像素，再对候选像素做精确判定。</span>

本节讲光栅化的标准两步法：**先用包围盒圈出候选区域，再对盒内像素逐一做叉积内外判定**。它简单、可并行，是 GPU 光栅化器的教学原型。

## 1 包围盒：把候选像素圈出来

给定三角形顶点 $v_0, v_1, v_2$，它的**轴对齐包围盒（axis-aligned bounding box, AABB）**是能包住三角形的最小矩形：

$$
x_{\min} = \lfloor \min(v_{0x}, v_{1x}, v_{2x}) \rfloor, \quad x_{\max} = \lceil \max(v_{0x}, v_{1x}, v_{2x}) \rceil
$$

$y$ 方向同理。取整是让包围盒覆盖到整像素边界。<span class="marginnote">AABB 的计算只需三次比较取极值，O(1) 成本，却能砍掉屏幕上 99% 的无关像素——三角形通常只占画面的一小部分。</span>

遍历时只扫描盒内像素：

```text
for (y = ymin; y <= ymax; y++)
    for (x = xmin; x <= xmax; x++) {
        p = (x + 0.5, y + 0.5);          // 像素中心作采样点
        if (inside_triangle(p))          // 叉积判定：三条边同侧
            draw_pixel(x, y, interpolate(p));
    }
```

像素中心 $(x+0.5, y+0.5)$ 作为采样点——「像素是否被覆盖」以它的中心为准，这正是上一节视口变换里 0.5 偏移在光栅化中的延续。

## 2 叉积判定法：点与三角形的内外关系

对三角形顶点 $v_0, v_1, v_2$（逆时针排列）和点 $p$，依次计算三条有向边的叉积 $z$ 分量：

$$
e_i = \text{cross}(v_{i+1} - v_i,\; p - v_i) \Big|_z = (v_{i+1} - v_i)_x (p - v_i)_y - (v_{i+1} - v_i)_y (p - v_i)_x
$$

若三个 $e_i$ **全部同号**（全正或全负），则 $p$ 在三角形内；否则在外。对逆时针三角形，$p$ 当且仅当 $e_0 > 0 \wedge e_1 > 0 \wedge e_2 > 0$。<span class="marginnote">直觉：沿每条边行进时，三角形内部始终在行进方向的<b>同一侧</b>（逆时针时在左侧）。点若满足三条边的同侧性，就同时被三条边「围住」——正是「内」的定义。叉积符号就是「侧」的代数判据。</span>

这条判定的另一个名字是**边缘函数（edge function）**：$e_i(p)$ 的符号即点 $p$ 相对边 $i$ 的左右侧，它同时给出重心坐标的原料（面积比），与《三角形：基本图元》一节的重心坐标天然衔接。

## 3 公式解析：边缘函数的逐点求值

以一条边 $v_0 \to v_1$ 为例，追踪 $e_0(p)$ 的完整求值：

$$
e_0(p) = (v_{1x} - v_{0x})(p_y - v_{0y}) - (v_{1y} - v_{0y})(p_x - v_{0x})
$$

- **第一步，构造边向量**：$\vec{d} = v_1 - v_0 = (v_{1x}-v_{0x},\, v_{1y}-v_{0y})$，即这条边的方向。
- **第二步，构造点到顶点的向量**：$\vec{w} = p - v_0$，从边的起点指向采样点。
- **第三步，叉积 $z$ 分量**：$e_0 = d_x w_y - d_y w_x$。若 $e_0 > 0$，则 $\vec{w}$ 在 $\vec{d}$ 的逆时针侧（三角形内部一侧）。
- **第四步，逐边判定**：对 $e_1, e_2$ 重复，三者全正才返回「内部」。

**辨析｜易错点：** 顶点顺序决定符号约定——**逆时针三角形**用「全正」判内，**顺时针三角形**用「全负」判内。若顶点顺序不统一（有的逆时针有的顺时针），判定会时而取反。工程上的做法是：预处理时统一顶点绕序，或把「同号」放宽为「不全异号」。另一个坑是边界情形：$p$ 恰好在边上时 $e_i = 0$，属于「内部还是外部」的灰色地带——多数实现约定「$0$ 算内部」（top-left rule），避免相邻三角形共享边时产生裂缝。

## 4 包围盒 + 叉积的完整流程

把两步拼成完整的光栅化一个三角形的算法：

1. **计算包围盒**：由三顶点坐标取 min/max，得到像素扫描范围。
2. **遍历盒内像素**：对每个像素中心 $(x+0.5, y+0.5)$。
3. **叉积判定**：计算 $e_0, e_1, e_2$，若全正则像素被覆盖。
4. **写颜色**：被覆盖的像素写入帧缓冲（颜色、深度、纹理坐标由重心插值得到——见《纹理映射》一节）。

这套流程每个像素的计算量是固定的（6 次乘减），与三角形数量无关——因此它天然适合并行。GPU 的着色器单元正是在这种「对每个像素执行相同指令」的模型上组织起来的。<span class="marginnote">现代 GPU 不会真的逐像素跑 CPU 循环，而是把三角形划分成像素块（tile/warp），用硬件单元<b>并行求值</b>同一组边缘函数。但数学内核与本节完全一致：包围盒剪枝 + 边缘函数判定 + 重心插值。</span>

## 5 进一步剪枝：扫描线、增量与提前退出

包围盒已经很快，但还能再省：

**增量求值（incremental evaluation）**：边缘函数 $e_i$ 关于 $x, y$ 是线性的，遍历一行像素时相邻像素的 $e_i$ 只差一个常数增量——用加法替代乘减，省掉大半浮点运算。
**行级剪枝**：某一行若最左最右像素都在三角形外，整行跳过。
**提前退出**：三角形面积过小（如退化三角形）时，直接不渲染。<span class="marginnote">增量求值是经典图形学优化，今天的 GPU 仍以「每像素一次加法」的方式求边缘函数——它把「叉积判定」从乘法级优化到加法级，是光栅化器性能的重要来源。</span>

这些优化都不改变判定的正确性，只降低判定次数——理解「包围盒 + 叉积」的基线，再叠加优化，就能读懂真实光栅化器的大部分逻辑。

## 6 边界规则与像素覆盖的一致性

三角形遍历的「最后一块拼图」是**边界一致性**——相邻三角形共享一条边时，边界上的像素该算谁的？

**问题**：两个三角形 $ABC$ 与 $ABD$ 共享边 $AB$。边上的一个像素中心，叉积判定里 $e_{AB} = 0$（恰在边上）——若两个三角形都「不包含边界」，边上的像素没人画（裂缝）；若都「包含」，画两次（重叠）。

**约定：top-left rule**（左上规则）——边界像素归属「上边或左边」的三角形：

- 若边的方向是「朝上」（$\Delta y < 0$）或「水平且朝右」（$\Delta y = 0, \Delta x > 0$），该边属于「左侧」三角形。
- 判定时：**边界像素归属「上边或左边」的三角形**——边界像素被「恰好一个」三角形接收。

**为什么是这个规则**：D3D11 用 top-left，OpenGL 有类似约定——规则不重要，**「所有三角形用同一规则」才重要**。规则不一致，共享边处出现「点状裂缝」（相邻三角形都不画边界像素）。

**辨析｜易错点：** 三个工程坑：

1. **顶点顺序翻转改变边方向**——顺时针/逆时针翻转，边方向变，top-left 归属变——同一网格内顶点顺序必须一致。
2. **浮点下的「恰在边上」**——浮点误差让「本应在边上」的像素判成「略在两侧」——两个三角形可能都判「内部」，重叠一次。**一致性规则只能处理「精确共边」，浮点重叠要额外容忍**。
3. **MSAA 子采样点也受边界规则影响**——MSAA 的每个子采样点独立判定，边界规则不一致会让「子采样点在两个三角形间闪烁」。

**边界一致性是「三角形遍历正确性」的最后细节**——理解了它，你就知道「为什么像素不会漏、不会重」。

## 7 三角形遍历的一页速查

- **流程**：包围盒剪枝 → 盒内像素叉积判定 → 重心插值 → 写颜色。
- **包围盒**：顶点 min/max 的 AABB——O(1) 剪掉 99% 像素。
- **叉积判定**：三条有向边符号一致 = 内部——顶点顺序决定全正/全负。
- **边界规则**：top-left rule 保证共享边像素不重不漏。
- **优化**：增量求值（加法替代乘法）、像素块并行（GPU）。

**一句话记忆**：「先圈后判、逐像素测、增量优化」——光栅化一个三角形的全部套路。

## 8 小结

- **三角形遍历 = 包围盒剪枝 + 像素级内外判定**，把复杂度从「像素 × 三角形」降到「盒内像素」。
- 包围盒 AABB 由顶点 min/max 得出，O(1) 剪掉 99% 像素。
- **边缘函数（叉积）判定**：三条有向边符号一致即内部；顶点顺序决定全正/全负约定。
- 增量求值把判定优化到加法级，GPU 用像素块并行执行同一套边缘函数。
