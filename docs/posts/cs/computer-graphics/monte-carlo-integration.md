## 为什么渲染方程要靠蒙特卡洛

渲染方程里的积分 $\int_{H^2} f_r L_i \cos\theta_i\, d\omega_i$ 没法解析求解——被积函数复杂（BRDF、递归的入射光、复杂的场景），维数高（每条反射路径都是一个新的积分维度）。**蒙特卡洛积分（Monte Carlo integration）** 用「随机采样 + 平均」估计积分值，是路径追踪的数学引擎。<span class="marginnote">蒙特卡洛的名字来自赌城蒙特卡洛——它靠「掷骰子」求积分。思想极朴素：<strong>要估计积分，就在积分域上随机采样，取被积函数的平均值</strong>。只要采样点足够多，平均值收敛到真实积分——「大数定律」保证这一点。</span>

本节讲蒙特卡洛积分的基本框架：无偏估计、期望、方差、以及它与「确定性求积」的区别。这是路径追踪采样的理论地基。

## 1 定积分与期望：一个核心等式

先建立一个关键直觉：**定积分可以看成期望**。设 $X$ 是区间 $[a, b]$ 上均匀分布的随机变量，其概率密度 $p(x) = 1/(b-a)$，则：

$$
\int_a^b f(x)\, dx = (b-a)\, \mathbb{E}[f(X)]
$$

右边的期望 $\mathbb{E}[f(X)]$ 可以用样本均值估计。于是「求积分」变成「求期望」，而期望可以用随机样本近似。

**蒙特卡洛积分**：采样 $N$ 个独立样本 $x_i \sim p$（服从概率密度 $p$），估计为：

$$
F_N = \frac{1}{N} \sum_{i=1}^{N} \frac{f(x_i)}{p(x_i)}
$$

$p(x)$ 是采样用的概率密度（PDF）。<span class="marginnote">分母里的 $p(x_i)$ 是蒙特卡洛估计的「关键零件」：它把「用非均匀分布采样」的偏差修正回来。直觉：<strong>如果某个方向采得密（$p$ 大），它被多采到的次数就要「打折」（除以 $p$），否则平均值会被高密区带偏</strong>。$p$ 选得越接近 $f$ 的形状，估计方差越小——这就是下一节「重要性采样」的伏笔。</span>

## 2 无偏性与收敛：为什么平均值会逼近积分

蒙特卡洛估计的两个基本性质：

- **无偏性**：$F_N$ 的期望等于真实积分 $\int f(x)\,dx$。平均意义下不系统性地偏高或偏低：

$$
\mathbb{E}[F_N] = \frac{1}{N}\sum_i \mathbb{E}\left[\frac{f(X_i)}{p(X_i)}\right] = \int_a^b f(x)\, dx
$$

- **收敛性**：随 $N$ 增大，$F_N$ 以概率收敛到真值（大数定律）。误差的收敛速度是 $O(1/\sqrt{N})$——误差减半需要 4 倍样本。

**辨析｜易错点：** $O(1/\sqrt{N})$ 的收敛速度**与维数无关**——这是蒙特卡洛 vs 确定性求积的决定性优势。确定性求积（梯形法、辛普森）的误差随维数 $d$ 指数恶化（$O(N^{-1/d})$），而蒙特卡洛在任意维数都是 $O(1/\sqrt{N})$。渲染方程是「无穷维」的，蒙特卡洛几乎是唯一现实的选择。<span class="marginnote">「维数无关的收敛」是蒙特卡洛统治渲染的根本原因：确定性求积的误差随维数 $d$ 呈 $N^{-1/d}$——每加一维，要维持精度得指数级多采样。渲染的积分维度是「反射次数」（每次反射加两维方向），蒙特卡洛 $1/\sqrt{N}$ 的收敛率对任意维数成立，于是它成了唯一「维度免疫」的方法。</span>

## 3 公式解析：蒙特卡洛估计器为什么除 p

把一个均匀分布的蒙特卡洛估计拆开，看分母 $p$ 的必要性：

$$
F_N = \frac{1}{N}\sum_{i=1}^{N} \frac{f(x_i)}{p(x_i)}, \qquad x_i \sim p
$$

- **第一步，均匀特例**：$p(x) = 1/(b-a)$ 时，$\frac{f(x_i)}{p(x_i)} = f(x_i)(b-a)$，估计器 $F_N = \frac{b-a}{N}\sum f(x_i)$——就是「样本平均值 × 区间长度」。
- **第二步，为什么对**：样本平均值 $\to \mathbb{E}[f]$，乘 $(b-a)$ 得 $(b-a)\mathbb{E}[f] = \int f$——正好回到积分。
- **第三步，一般 $p$**：$x_i$ 从 $p$ 采，样本频率 $∝ p$，所以每个样本要「除以 $p$」来抵消「采得密的地方权重虚高」——这保证 $\mathbb{E}[f(X)/p(X)] = \int f$ 对任意合法的 $p$ 都成立。

## 4 方差：为什么有的采样好、有的采样差

蒙特卡洛估计的**方差**决定收敛快慢：

$$
\text{Var}(F_N) = \frac{1}{N}\,\text{Var}\left(\frac{f(X)}{p(X)}\right)
$$

- 若 $p$ 与 $f$ 的形状接近（$f$ 大的地方 $p$ 也大），$f(X)/p(X)$ 近似常数，方差小——收敛快。
- 若 $p$ 与 $f$ 严重不匹配，$f(X)/p(X)$ 忽大忽小，方差大——需要海量样本才收敛。

**关键洞察：$p$ 的选择决定方差**。这就是「重要性采样」的名字由来——让 $p$ 「重要」（匹配 $f$ 的形状）的地方多采样。随机均匀采样（$p$ 常数）在 $f$ 峰值处经常采不到，方差巨大；$p$ 贴合 $f$ 则方差骤降。<span class="marginnote">「$p$ 越贴合 $f$，方差越小」是蒙特卡洛的全部艺术：路径追踪里「对光源采样」（$p$ 指向光源，那里 $L_i$ 大）与「对 BRDF 采样」（$p$ 贴合高光锥）都是「让 $p$ 匹配 $f$ 的形状」。最理想是 $p \propto f$，方差为 0——但通常做不到，只能近似。</span>

## 5 蒙特卡洛积分的实现骨架

一个蒙特卡洛积分的典型实现：

```text
F_N = 0
for i = 1 to N:
    x = sample(p)          // 采样：从概率密度 p 抽一个 x
    F_N += f(x) / p(x)     // 加权：f(x)/p(x) 修正采样偏差
F_N /= N                   // 平均：得到积分的蒙特卡洛估计
```

三步：**采样**（从 $p$ 抽 $x$）→ **加权**（$f(x)/p(x)$）→ **平均**（除以 $N$）。路径追踪就是这个骨架的递归版本——每次反射采样一个方向，把反射方程里的 $f_r L_i \cos\theta / p$ 累加。<span class="marginnote">路径追踪 = 「递归的蒙特卡洛积分」：外层对像素积分（多条光线取平均），内层对反射方向积分（每步随机采样一个方向）。整棵光线树的颜色贡献，就是一个「递归的加权平均」——蒙特卡洛骨架贯穿始终。</span>

## 6 从蒙特卡洛到路径追踪

蒙特卡洛积分为路径追踪提供了「怎么求积分」的答案：

渲染方程的积分 → 用蒙特卡洛估计器逼近。
采样方向 → 用「对 BRDF 采样」或「对光源采样」（重要性采样）。
递归 → 每条光线是「一次弹射路径」，像素颜色 = 多条路径的平均。

下一节我们把两者正式结合——**路径追踪：从渲染方程到采样算法**。<span class="marginnote">蒙特卡洛与路径追踪的关系是「工具与方法」：蒙特卡洛给出「怎么估计积分」，路径追踪给出「渲染方程的积分具体怎么拆成可采样的路径」。理解了蒙特卡洛的无偏性、方差、重要性采样，路径追踪的每一个设计选择（为什么采这个分布、为什么除 $p$、为什么方差会大）都有了答案。</span>

## 7 蒙特卡洛积分的「直觉速查」

把蒙特卡洛积分的核心直觉压成速查，方便「写采样器时一眼找到」：

- **核心公式**：$F_N = \frac{1}{N}\sum \frac{f(x_i)}{p(x_i)}$——样本的「加权平均」估计积分。
- **无偏条件**：$p$ 在 $f$ 非零处也非零（$p$ 覆盖 $f$ 的支撑）。
- **方差来源**：$\text{Var}(f/p)$——$p$ 与 $f$ 形状越接近，方差越小。
- **收敛**：$O(1/\sqrt{N})$，与维数无关——维度免疫是它统治渲染的原因。
- **降方差三板斧**：重要性采样（$p$ 贴合 $f$）、分层采样（均匀覆盖）、控制变量（减相关项）。

**一条直觉**：「采样密的地方要打折（除 $p$），采样疏的地方要保值（$f/p$ 大）」——估计器靠「打折」修正采样偏差，$p$ 选对则折扣均匀、方差小。

**为什么路径追踪离不开它**：渲染方程的积分「维度无限、被积函数复杂」——只有蒙特卡洛「与维度无关」的收敛率扛得住——**「蒙特卡洛是渲染方程的数值引擎」**。

## 8 小结

- **蒙特卡洛积分**用随机样本估计积分：$F_N = \frac{1}{N}\sum f(x_i)/p(x_i)$。
- **无偏**（期望 = 真积分）+ **收敛 $O(1/\sqrt{N})$**，且收敛率与维数无关。
- 分母 $p$ 修正采样分布的偏差；$p$ 与 $f$ 形状越接近，方差越小。
- 方差 $\propto \frac{1}{N}\text{Var}(f/p)$——$p$ 的选择是蒙特卡洛的全部艺术。
- 实现骨架 = 采样 + 加权 + 平均；路径追踪是它的递归版本。
