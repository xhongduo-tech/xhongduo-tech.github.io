## 为什么阴影映射需要「补丁」

上一节的阴影映射有三大硬伤：边缘锯齿、大场景分辨率不足、偏移两难。本节逐一拆解三个最重要的改进——**PCF**（软化边缘）、**CSM**（大场景分层）、**VSM**（可滤波的深度）——它们构成了现代实时阴影的完整工具箱。<span class="marginnote">阴影改进的三条线：<strong>PCF 管「边缘软不软」（采样滤波），CSM 管「场景大不大」（分辨率分层），VSM 管「能不能直接滤波」（深度重编码）</strong>——三条线解决三个不同维度的问题，现代引擎通常把它们组合使用（CSM + PCF 是标配，VSM 用于特殊场景）。</span>

## 1 PCF 的深化：从固定邻域到泊松圆盘

上一节的 PCF 用固定 $3\times3$ 邻域平均。它的改进空间在「采样模式」：

**固定网格采样**：邻域是规则的，产生规则的「网格状」软阴影伪影。
**随机旋转 / 泊松圆盘采样**：用不规则分布采样，消除网格伪影，阴影更自然。
**动态核大小**：阴影离接触点越远（半影越宽），采样半径越大。

PCF 的代价是「$N$ 次阴影贴图采样」——采样数越高越软但越贵。现代实现用「PCSS」（Percentage Closer Soft Shadows）根据遮挡物距离动态调整 PCF 核大小，产生物理合理的半影宽度。<span class="marginnote">「PCF 的采样模式决定软阴影的质量」：<strong>固定网格采样留下「棋盘格」伪影，随机采样（泊松圆盘/抖动）把伪影打散成噪声，肉眼更舒服</strong>。PCSS 更进一步——它根据「遮挡物离得多远」动态算半影宽度，让近处阴影硬、远处阴影软——这是「物理合理软阴影」的低成本近似。</span>

## 2 CSM：级联阴影映射

**CSM（Cascaded Shadow Maps，级联阴影映射）** 解决「大场景 + 单张阴影贴图分辨率不足」：

把视锥体沿深度切成**多个级联（cascade）**，每段分配一张独立的阴影贴图：

近处的级联：贴图覆盖小范围 → 分辨率高 → 近处阴影锐利。
远处的级联：贴图覆盖大范围 → 分辨率低 → 远处阴影模糊（可接受）。

渲染时，片元按深度选择**所属级联**的阴影贴图采样。近处高分辨率、远处低分辨率——分辨率按「视觉重要性」分配。<span class="marginnote">CSM 的哲学是「<strong>把分辨率花在看得到的地方</strong>」：<strong>近处阴影占屏幕像素多、值得高分辨率；远处阴影占像素少、低分辨率也看不出</strong>——用 3-4 张不同范围的贴图，替代「一张贴全场景」的糊。代价是多 pass 渲染（每级联一次光视角）、以及「级联边界」处的接缝（不同级联分辨率不同，过渡要处理）。</span>

**级联边界伪影**：片元在级联交界处切换贴图，分辨率突变产生接缝——用「级联间交叉过渡」缓解。

## 3 VSM：方差阴影映射

PCF 的痛点：软阴影要多次采样（贵），且硬阴影区域无法平滑滤波。**VSM（Variance Shadow Maps）** 用「可滤波的深度统计」解决：

不存「深度」，而存**深度与其平方的均值**（前两阶矩）：

$$
M_1 = \mathbb{E}[z], \qquad M_2 = \mathbb{E}[z^2]
$$

然后由切比雪夫不等式估计「深度大于某阈值的概率」：

$$
P(z_p > z_{\text{shadow}}) \le \frac{M_2 - M_1^2}{M_2 - M_1^2 + (z_p - M_1)^2}
$$

**关键优势**：$M_1, M_2$ 是**可线性滤波**的（均值可以卷积/模糊），所以阴影贴图可以被模糊成软阴影——一次滤波即可，不用多次采样。<span class="marginnote">VSM 的「切比雪夫上界」：<strong>存前两阶矩，用概率不等式估计「被遮挡的概率」——遮挡概率作为阴影浓度，天然软、天然可滤波</strong>。因为矩是线性量，可以把阴影贴图像普通纹理一样模糊（生成软阴影只需一次模糊 pass），比 PCF 的多次采样便宜得多。代价：概率上界是「估计」，在深度分布多峰（多个遮挡层）时会产生「漏光」伪影。</span>

**VSM 的漏光（light leaking）**：深度分布多峰时切比雪夫估计偏大，阴影「透光」——修正用「多层矩」或「深度 clamping」。

## 4 公式解析：切比雪夫不等式如何给概率

把 VSM 的「概率上界」公式拆开，看它在估计什么：

$$
P(z > t) \le \frac{M_2 - M_1^2}{M_2 - M_1^2 + (t - M_1)^2}
$$

- **第一步，方差**：$M_2 - M_1^2 = \text{Var}(z)$——深度的方差（遮挡物深度的分散程度）。
- **第二步，分子**：方差越大，「深度离均值远」的可能性越大——概率上界越高。
- **第三步，分母**：方差 + 阈值与均值的偏差平方——阈值 $t$ 离均值越远，上界越低（更确定地在均值之上）。
- **第四步，作为阴影浓度**：$P$ 越大，该点越可能被遮挡——阴影越浓。

**辨析｜易错点：** 切比雪夫给出的是**上界**，不是精确概率——当遮挡深度分布「多峰」（多层遮挡物）时，上界严重高估，产生漏光。VSM 的实现坑还有：$M_2$ 在浮点下溢出（深度值平方很大），需要归一化存储。

## 5 三种改进的对比与组合

| | PCF | CSM | VSM |
| --- | --- | --- | --- |
| 解决的问题 | 边缘锯齿/硬边 | 大场景分辨率 | 软阴影滤波成本 |
| 原理 | 深度比较的邻域平均 | 视锥分层多贴图 | 矩 + 切比雪夫概率 |
| 软阴影 | 多次采样 | 配合 PCF | 一次模糊即可 |
| 代价 | N 次采样 | 多 pass 渲染 | 漏光风险 |
| 硬件 | 无特殊需求 | 多渲染目标 | 可滤波贴图 |

**工程组合**：CSM + PCF 是现代引擎默认（方向光的大场景软阴影）；VSM 用于「需要任意模糊/动态场景」的场景；PCSS 是 PCF 的物理升级版。<span class="marginnote">「CSM 管远近平滑、PCF 管软边、VSM 管可滤波」——现代阴影系统几乎总是组合：<strong>UE 的 Cascaded Shadow Maps + 级联内 PCF、Unity 的 CSM + PCF、影视风格的 PCSS</strong>。没有「银弹」阴影方案，只有「按场景选组合」——理解每个方法的代价，才能选对组合。</span>

## 6 从阴影到实时渲染的全局视角

阴影映射及其改进是「实时渲染工程思维」的缩影：**每个技术都是「成本-质量」的交易**：

阴影映射：多一次 pass 换阴影（便宜但有走样）。
PCF：多次采样换软边（贵一点换自然）。
CSM：多 pass 换大场景清晰（分辨率预算分配）。
VSM：矩存储换可滤波软阴影（赌概率估计的准确）。

理解了这些交易，就理解了实时渲染的工程师思维——**没有免费的真实，只有「在预算内最值的真实」**。<span class="marginnote">「实时渲染 = 一系列『预算内交易』」是贯穿本册的主题：<strong>每个技术回答「我花掉什么（pass、采样、内存）换回什么（真实感）」，工程师的工作是在 16ms 预算内做出最优的『交易组合』</strong>。阴影映射的整个改进史，就是这个思维的最清晰例证——从「一张贴图」到「级联 + 概率 + 软边」，每一步都在优化「性价比」。</span>

## 6 阴影改进的选型：一个工程决策表

把 PCF、CSM、VSM 放进「工程决策表」，你就知道「什么场景用什么组合」。

| 场景 | 推荐方案 | 理由 |
| --- | --- | --- |
| 方向光 + 大场景（开放世界） | **CSM + PCF** | 分层保近清晰，PCF 软化边缘 |
| 点光源 + 局部（室内灯具） | 立方体贴图 + PCF | 六面阴影图，PCF 软化 |
| 动态场景 + 需要软阴影 | VSM / PCSS | 可滤波软阴影，动态更新 |
| 移动端（性能敏感） | 单张阴影图 + 简单 bias | 少 pass、少采样 |
| 影视离线 | 光线追踪阴影 | 物理正确的软阴影 |

**CSM 的参数**：级联数（3–4）、每级的距离范围、阴影图分辨率（1024–4096）——「级联越密越清晰但越贵」——「级联边界」的接缝处理是 CSM 的调优重点。

**PCF 与 CSM 的组合**：CSM 提供「分层的高分辨率阴影图」，每级内用 PCF 软化——「分层管清晰、PCF 管柔和」——现代引擎方向光阴影的标准组合。

**VSM 的使用场景**：需要「任意模糊」的软阴影（体积光配合）、或「阴影图可以像普通纹理一样滤波」的后期——「VSM 的漏光」要配合「多层矩/深度 clamp」修正。

**辨析｜易错点：** 两个选型坑：

1. **「一个方案打天下」**——开放世界用 CSM + PCF、室内点光用 cubemap、特殊效果用 VSM——「按光源类型与场景规模组合」。
2. **「阴影质量只看分辨率」**——偏移、PCF 采样模式、级联分配同等重要——「调阴影不只看分辨率一个旋钮」。

**「阴影方案 = 场景类型 × 平台预算的组合」**——理解了决策表，你就知道「为什么引擎的阴影设置有那么多个开关」。

## 7 小结

- **PCF**：深度比较的邻域滤波 → 软边；随机/泊松采样消除网格伪影；PCSS 动态半影。
- **CSM**：视锥分层多贴图 → 近清晰远模糊；级联边界要处理接缝。
- **VSM**：存深度均值 + 方差，切比雪夫估计遮挡概率 → 可滤波软阴影；多峰时漏光。
- 切比雪夫上界：$P \le \frac{\text{Var}}{\text{Var} + (t-\mu)^2}$，是估计不是精确值。
- 工程组合：CSM + PCF 是方向光默认；VSM 用于可滤波场景；PCSS 是 PCF 升级。
