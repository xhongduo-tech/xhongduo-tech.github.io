## 为什么从矢量场开始

标量场每个位置只有一个数，
**矢量场（vector field）**每个位置则是一个**带方向的向量**——

风速、洋流、磁场、血流、流体力学的速度场。

矢量场可视化要回答两个问题：
**流体往哪流？速度有多快？**

这比标量场难得多：方向 + 大小两个信息都要表达，
且「流」的本质是**沿场的积分轨迹**，不是单个位置的属性。

Telea 第 6 章给出从**箭头**到**流线**再到**流面/流体积**
的完整阶梯：

从「局部点采样」到「全局轨迹追踪」，
表达能力逐级增强，计算成本也逐级上升。

<span class="marginnote">矢量场可视化与《流体力学》的耦合极深：
流线就是流场中「每个点都相切于速度方向」的曲线，
物理上对应无质量粒子的运动路径（定常流）。
理解速度场的散度、旋度、涡量，
是读懂流线形态的前提——
本博客《流体力学》专题会提供这些物理概念。</span>

## 1 矢量场：方向 + 大小

**矢量场（vector field）**：定义在区域上的向量函数
$\mathbf{v}: \mathbb{R}^3 \to \mathbb{R}^3$，
每个点 $\mathbf{x}$ 对应一个向量
$\mathbf{v}(\mathbf{x}) = (u, v, w)^\top$
（三维的三个分量；二维即 $(u, v)^\top$）。

存储与标量场一样靠网格采样，
但每个采样点有多个分量。

矢量场可视化的两大挑战：

其一，**数据量翻倍**（3 个分量 vs 1 个），绘制成本高；

其二，**方向没有天然的颜色编码**——
颜色有顺序感，但方向是「圆上的角度」，
用色相环勉强可表达角度但丢大小。

因此矢量场可视化几乎都用**几何手法**（箭头、轨迹），
颜色只作辅助。

<span class="marginnote">方向用颜色编码的尝试
（HSV 色相 = 角度）一直存在，
但效果受「色相不连续」与「色觉缺陷」双重拖累。
更稳健的做法是「流线 + 颜色编码速度大小」：
几何管方向、颜色管大小，各司其职。</span>

## 2 箭头图：局部采样的直接表达

最直接的矢量场可视化是**箭头图（glyph / hedgehog）**：
在采样点上放置小箭头（或锥体），
箭头方向 = 场方向，箭头长度/颜色 = 场大小。

它几乎不费计算，一眼就能看出「哪里快、哪里往哪拐」。

箭头图的致命缺点是**采样矛盾**：
箭头放得太密，互相重叠，一片乱麻；
放得太稀，又漏掉了重要的局部结构。

箭头图适合「看全局概貌」，不适合「追踪流的具体路径」。

另一个工程细节是**箭头归一化**：
若箭头长度正比于速度，
慢速区箭头几乎看不见、快速区箭头互相交叉——

折中是「长度 = 方向提示 + 颜色 = 速度大小」，
让长度保持大致一致。

<span class="marginnote">「箭头长度 vs 颜色」的双通道分工
是矢量场可视化的经典妥协：
几何通道（长度）受画布与密度限制，
颜色通道（速度）则不受重叠影响。
这与第 2 篇《标记与通道》的「幅度通道精度排序」对应——
把「快慢」交给色相/亮度后，重叠问题就缓解了。</span>

## 3 流线：沿着场的轨迹

**流线（streamline）**：场中一条处处与 $\mathbf{v}$ 相切的曲线。

物理直觉：把一粒无质量的种子放入流场，
它沿速度方向流动的路径就是流线（定常流下）。

流线把「矢量场」压缩成了「一维曲线族」，
是矢量场可视化最常用的手法。

生成流线要解决三个问题：

1. **播种（seeding）**：从哪些点出发生成流线？
   种子的分布决定了哪些结构被看到。
   均匀撒种会漏掉关键特征；
   按特征撒种（如临界点附近加密）则效率高。
   播种策略是流线可视化的研究热点。

   <span class="marginnote">播种的经典两难：
   种得密→流线互相缠绕，读不出每条线的走向；
   种得稀→关键区域（涡旋、分离线）没有线经过。
   现代方法用「重要性采样」：先算场的关键特征
   （临界点、涡量高区域），在这些区域加密种子，
   其余区域稀疏——这就是下一节「矢量场拓扑」的动机之一。</span>

2. **积分**：从种子出发，沿速度方向数值积分 $\mathbf{x}(t)$，
   用欧拉法或龙格—库塔法（见第 5 节公式）。
3. **终止**：流线在什么条件下停止？
   通常三个条件：到达场边界、
   到达临界点（速度为 0，无法继续）、
   积分步数达到上限。

## 4 流面与流体积：从线到面的推广

单条流线只展示一条路径，
流线族能展示一片路径，但「一片线」容易纠缠。
更完整的表达是：

- **流面（stream surface）**：由一族相邻流线张成的曲面。
  种子不在点上而在一条**曲线**上，
  沿场推进生成一个面。
  流面适合展示「一个截面上的流束」——
  如从某个圆形种子环发出的气流，流面呈现出「管状」结构。
- **流体积（stream volume）**：更进一步，用体积表达流。
  流体积适合展示「整团流体如何运动」，
  但计算量巨大，实际可视化中较少用，
  更多用「流线 + 流面的混合」。

流线与流面的选择口诀：

**流线看「路径」，流面看「束形」，流体积看「整体输送」**。

它们共享同一套积分骨架，
只是种子的维度不同（点 → 曲线 → 区域）。

## 5 公式解析：流线 = 常微分方程

流线是「求解一个常微分方程」的结果。
设粒子位置为 $\mathbf{x}(t)$，速度场为 $\mathbf{v}$：

$$
\frac{\mathrm{d}\mathbf{x}}{\mathrm{d}t} = \mathbf{v}(\mathbf{x}(t)),\qquad
\mathbf{x}(0) = \mathbf{x}_0
$$

- **第一步，看 $\mathrm{d}\mathbf{x}/\mathrm{d}t = \mathbf{v}(\mathbf{x})$**：
  这是「速度 = 位置变化率」的物理解释。
  $\mathbf{x}(t)$ 是粒子轨迹，
  它在每一点的切线方向就是该点的场方向——
  这正是「流线处处与场相切」的定义。
- **第二步，看初值 $\mathbf{x}(0) = \mathbf{x}_0$**：
  流线是一条初值问题（IVP）的解，
  **不同的种子 $\mathbf{x}_0$ 得到不同的流线**。
  播种策略的本质就是「选择一组初值」。
- **第三步，数值积分**：场只有离散采样，积分必须数值化。
  最简单的**欧拉法**：$\mathbf{x}_{k+1} = \mathbf{x}_k + h\,\mathbf{v}(\mathbf{x}_k)$，
  步长 $h$ 越大越快但越容易「飞离」真实轨迹；
  **龙格—库塔法（RK4）**用中间点的斜率做加权平均，
  同样步长下精度高得多，是流线积分的实际标配。

  <span class="marginnote">欧拉法 vs RK4 的取舍与《数值分析》里的
  ODE 求解器完全一致：欧拉是一阶方法、RK4 是四阶方法。
  流线积分的一个特殊坑是「步长与网格尺度不匹配」——
  步长太大会跳过细小的涡旋结构，
  让流线看起来是平滑直线，实则在数值上漏掉了真实物理。</span>

- **第四步，临界点与终止**：在临界点处 $\mathbf{v} = \mathbf{0}$，
  微分方程右端为零，积分无法继续——流线在此终止。
  这引出了下一节的主题：**矢量场拓扑**，
  研究临界点与它们之间的「骨架」。

## 6 辨析｜易错点

**辨析｜易错点 1：箭头长度正比于速度**。
慢速区箭头消失、快速区箭头互相交叉。
改用「长度 = 方向 + 颜色 = 速度」的分工，
或做归一化。

**辨析｜易错点 2：播种不均匀漏结构**。
均匀撒种会漏掉涡旋、分离线等关键区域。
按特征播种（临界点、高涡量区加密），
让种子密度跟随信息密度。

**辨析｜易错点 3：积分步长与网格不匹配**。
步长太大会「跳过」细小涡旋，
流线看似平滑实则漏物理。
步长应与最小网格尺度匹配，
并优先用 RK4。

## 7 小结

- **矢量场** $\mathbf{v}: \mathbb{R}^3 \to \mathbb{R}^3$，
  每个位置一个向量；数据量翻倍、方向难用颜色编码。
- **箭头图**局部采样直接表达，看概貌；
  箭头长度 + 颜色双通道可缓解重叠。
- **流线**是处处与场相切的轨迹，
  靠「播种 + 数值积分 + 终止条件」生成。
- **流面/流体积**把种子从点推广到曲线/区域，
  看「束形」与「整体输送」。
- 流线 = 常微分方程 $\mathrm{d}\mathbf{x}/\mathrm{d}t = \mathbf{v}(\mathbf{x})$
