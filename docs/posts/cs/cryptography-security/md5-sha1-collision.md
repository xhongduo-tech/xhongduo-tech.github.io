## 为什么从 MD5 与 SHA-1 的碰撞攻击开始

哈希的历史是一部「碰撞攻防」史：MD5（1992）与 SHA-1（1995）曾是使用最广的哈希，却在碰撞攻击面前逐一倒下。MD5 的碰撞在 2004 年被王小云团队攻破（手工构造）；SHA-1 的碰撞在 2017 年被 Google/CWI 用大规模 GPU 集群攻破（**SHAttered**）。理解这些攻击如何从「理论可行性」变成「现实工具」，是理解哈希选型与密码退役机制的关键。<span class="marginnote">王小云 2004 年在 CRYPTO 上当场宣布 MD5、SHA-0、SHA-1 的碰撞攻击，<strong>一举终结了 MD5 的密码学寿命</strong>——她用手算级别的符号分析加少量计算就构造出碰撞，震惊了整个密码学界。这是中国密码学家改写现代密码史的标志性时刻。</span>

## 1 为什么碰撞攻击如此致命

抗碰撞是哈希的底线性质。一旦碰撞可行，依赖「同摘要 = 同内容」的所有应用全部失效：

**数字签名**：签名的是 $H(m)$。找到 $m \neq m'$ 且 $H(m) = H(m')$，则 $m'$ 就继承了 $m$ 的合法签名——**伪造签名**。
**口令散列**：数据库存的是 $H(\text{口令})$。若两条不同口令散列相同，登录校验就会被绕过或碰撞到他人账户。
**证书**：让恶意证书与合法证书同摘要，可让恶意证书被信任。
**软件校验**：恶意程序伪装成与合法程序同摘要的版本。

碰撞攻击的可怕在于**攻击者完全自由**：他不需要针对某个特定文件，只需要**制造一对**同摘要文件，然后设法让其中一个被信任、另一个被使用。更有威力的变体是**选择前缀碰撞（chosen-prefix collision）**：攻击者分别指定两个文件的前缀（例如一个合法合同与一个恶意合同），然后计算后缀使两者摘要相同——这比「自由找一对」更难，却也更贴近真实伪造场景。<span class="marginnote">一个直观的类比：生日悖论让「找一对同生日的人」只需要 23 人；而「找到一个与你同生日的人」需要 183 人。自由碰撞对应前者（$2^{n/2}$），选择前缀碰撞接近后者（$2^{n}$），所以选择前缀碰撞的工程成本远高于普通碰撞。</span>

## 2 MD5：从王小云到「两个 PDF 同指纹」

MD5 输出 128 位，理论碰撞成本 $2^{64}$（生日攻击）。但 2004 年王小云团队的攻击把成本降到**几乎即时**——他们找到的碰撞构造甚至不需要穷举。到 2007 年，Stevens 等人把攻击工程化：能构造「两个内容不同但 MD5 相同」的合法 PDF 文档。

**攻击思路（差分类）**：MD5 的压缩函数与 SHA-1 一样基于 Merkle-Damgård。差分攻击寻找两条「消息差分路径」——在两条消息上注入精心构造的字节差，使压缩函数内部的状态差在每轮都被「抵消」，最终殊途同归到同一状态。<span class="marginnote">MD5 的教训：<strong>「128 位输出」在今天连「名义上的 $2^{64}$」都保不住</strong>。攻击不是停留在理论上——2008 年就有攻击者用 MD5 碰撞伪造了 CA 证书（Flame 恶意软件）。一旦碰撞可构造，任何「信任摘要」的系统都是靶子。</span>

| 参数 | MD5 | SHA-1 |
| --- | --- | --- |
| 输出长度 | 128 位 | 160 位 |
| 理论碰撞成本（生日） | $2^{64}$ | $2^{80}$ |
| 实际碰撞成本 | 秒级（2004 后） | $2^{63}$（SHAttered，2017） |
| 首次公开攻破 | 2004 王小云 | 2005 王小云（理论），2017 实践 |
| 当前状态 | 完全失守 | 全面禁用 |

## 3 SHA-1：SHAttered 的 GPU 战争

SHA-1 输出 160 位，理论碰撞成本 $2^{80}$——曾被认为「永久安全」。但 2017 年，Google 与 CWI 用 **SHAttered** 攻击真正造出了第一对 SHA-1 碰撞：

成本：约 **$2^{63.1}$** 次 SHA-1 计算（比理论 $2^{80}$ 低得多，因为差分攻击找到了更优路径）。
资源：**110 块 GPU** + 数百万美元电费，运行数月。
产出：两个不同但 SHA-1 相同的 PDF 文件。

**攻击方法**：利用 SHA-1 压缩函数中一种叫 **SHAdisturbance / boomerang 差分** 的结构特性，把碰撞搜索的复杂度从 $2^{80}$ 压到 $2^{63}$。这是「理论差分」与「工程资源」结合的里程碑——它证明**只要资源够，SHA-1 的碰撞可实际制造**。<span class="marginnote">SHAttered 的意义不在「破解了加密」，而在<strong>把「$2^{63}$ 次运算」从理论带进现实</strong>。随着算力按摩尔定律增长，$2^{63}$ 从「不可能」变成「数月的 GPU 集群」——密码学参数必须留足未来余量，这正是「淘汰 80 位级强度」的决策逻辑。</span>

## 4 公式解析：碰撞攻击的复杂度对比

$$
\text{MD5 实际碰撞} \ll 2^{64}, \qquad \text{SHA-1 实际碰撞} \approx 2^{63}
$$

三步拆解这条「理论 vs 实际」的对比：

- **第一步，理论基准**：抗碰撞的通用下界是 $2^{n/2}$（生日）。MD5 为 $2^{64}$，SHA-1 为 $2^{80}$。
- **第二步，差分攻击压低**：利用压缩函数的结构，找到「高概率差分路径」——状态差按预期路径演化，碰撞搜索从「随机碰撞」降级为「沿路径找碰撞」。MD5 的路径几乎免费，SHA-1 需要 $2^{63}$ 次。
- **第三步，读出结论**：MD5 完全失守（秒级），SHA-1 勉强守到 2017（GPU 数月）——**「理论可行」到「工程可行」之间的距离，取决于攻击者愿意花多少电费**。

这里的量级关系值得反复体会：$2^{64}$ 与 $2^{63}$ 只差一倍，却是「几秒钟」与「几个月」的天壤之别。因为每差一位指数，工作量就翻倍；而**从理论界到实际攻击的压缩幅度，取决于算法的结构弱点而非位数**。MD5 结构弱点极深，位数再多也救不回。

## 5 退役：生态如何淘汰哈希

被攻破的哈希不会立即消失，而是经历「警告 → 禁用 → 移除」的缓慢退役：

- **MD5**：2008 年起 TLS 弃用 MD5 签名；2011 年 RFC 6151 明确「MD5 不得用于安全」；今天仅用于非安全校验（下载完整性提示）。
- **SHA-1**：2014 年 Chrome 开始标注 SHA-1 证书；2016 年证书机构停止签发；**2017 年 SHAttered 后全面禁用**；Git 仍在内部使用 SHA-1（有 hash-function-transition 计划）。
- **教训**：密码退役有**巨大的生态惯性**——就算算法被攻破，迁移仍需数年。所以**选型要选有未来余量的算法**（如 SHA-256/SHA-3），并提前规划迁移路径。<span class="marginnote">Git 的 SHA-1 案例最能说明迁移之难：Git 对象名基于 SHA-1，全世界的仓库都依赖它。<strong>即使 SHA-1 碰撞可构造（2017），Git 也只能「逐渐迁移」而非「立即切换」</strong>——迁移成本往往是密码升级真正的瓶颈。</span>

| 时间点 | 事件 |
| --- | --- |
| 1992 / 1995 | MD5 / SHA-1 发布 |
| 2004 | 王小云攻破 MD5，发布实际碰撞 |
| 2005 | 王小云给出 SHA-1 理论碰撞（$2^{69}$ 级） |
| 2008 | Flame 利用 MD5 碰撞伪造 CA 证书 |
| 2016 | 主流 CA 停止签发 SHA-1 证书 |
| 2017 | SHAttered：第一对实际 SHA-1 碰撞 |

## 6 面对「待退役」哈希：工程上的应对清单

当某个哈希进入「警告」状态，工程团队要按以下顺序行动，而不是立刻大规模替换：

1. **盘点依赖**：找出所有用到该哈希的协议、证书、签名、存储格式——Grep 代码库、审计配置文件、梳理第三方依赖。
2. **评估暴露面**：判断该哈希是否参与「安全判定」（签名、认证、信任链）——只有安全判定场景必须立刻迁移；纯完整性校验（如下载 MD5）可缓办。
3. **分层迁移**：先迁移高风险的证书与签名路径，再迁移存储格式；新代码一律使用 SHA-256 或 SHA-3。
4. **保留过渡机制**：在迁移窗口内同时支持新旧两种哈希（例如「双摘要」），保证旧数据可被读取，直到存量耗尽。

**重点：迁移的核心不是「换一个函数」，而是「打破所有『同摘要=同内容』的假设」。** 只要还有一处信任链在使用待退役哈希，碰撞攻击就仍有一击致命的空间。

## 7 术语速查

| 术语 | 含义 |
| --- | --- |
| 碰撞（collision） | 两个不同消息 $m \neq m'$ 满足 $H(m) = H(m')$ |
| 差分路径 | 注入字节差使压缩函数状态差逐轮抵消的攻击工具 |
| 选择前缀碰撞 | 攻击者分别指定两个前缀，再补后缀使摘要相同 |
| 生日攻击 | 通用碰撞下界 $2^{n/2}$ 的搜索方法 |
| SHAttered | 2017 年第一对实际 SHA-1 碰撞 |
| 密码退役 | 算法被攻破后的「警告→禁用→移除」生态过程 |

## 8 小结

- **碰撞攻击的威力**：签名伪造、证书欺骗、软件伪装——「同摘要 = 同内容」的信任链崩塌。
- **MD5**：128 位，2004 年王小云攻破，2007 年可构造 PDF 碰撞——完全失守。
- **SHA-1**：160 位，2017 年 SHAttered（110 块 GPU + 数月）造出真实碰撞——$2^{63}$ 级攻击。
- 攻击方法：**差分路径**——构造状态差抵消，把碰撞从 $2^{n/2}$ 压到可工程化。
- **退役教训**：被攻破 ≠ 立即消失，生态迁移以年计；选型要留未来余量（SHA-256/SHA-3）。
- 一位指数的差距可能是「秒」与「月」的天壤之别——算法结构弱点比位数更能决定生死。
- 面对待退役哈希，工程应对是「盘点 → 评估暴露面 → 分层迁移 → 保留过渡机制」。
- 现代选型基线：SHA-256 或 SHA-3；旧摘要仅用于非安全校验。
