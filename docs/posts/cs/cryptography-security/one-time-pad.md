# 一次一密（One-Time Pad）及其安全性证明

<div class="epigraph">

## 为什么从一次一密开始

上一节我们得到一个令人生畏的结论：完善保密要求 $|K| \ge |M|$，密钥不能比消息短。一次一密（One-Time Pad, OTP）是这个界被**精确取到等号**的唯一方案：密钥和消息一样长、每个密钥位只使用一次、密钥完全随机。它在 1917 年被美国电话电报公司的工程师 Gilbert Vernam 发明，1949 年被香农证明达到了完善保密——这份证明直到今天仍是密码学中最优雅的结果之一。<span class="marginnote">Vernam 最初的实现是「维吉尼亚密码的二进制版」：把字母换成 5 位博多码，用同样长度的密钥纸带逐位异或。香农后来才把「随机密钥、一次使用」上升为一般理论。</span> 理解一次一密，是理解「信息论意义上的完美」到底长什么样的最直接入口。

## 1 定义：异或的二元运算视角

一次一密把明文 $M$、密钥 $K$、密文 $C$ 都看成比特串，用**逐位异或**运算加密：

$$
C = M \oplus K
$$

解密同样是异或——因为 $K \oplus K = 0$，所以

$$
M = C \oplus K = (M \oplus K) \oplus K = M
$$

三个使用前提缺一不可：**密钥必须与消息等长**、**密钥必须完全随机**（每一位独立等概）、**密钥绝不重用**。「一次一密」这个名字本身就是这三个条件的浓缩。只要任一条被违反，安全性立即崩塌——第 4 节会展示重用密钥的灾难性后果。

<span class="marginnote">为什么是异或而不是别的运算？因为异或的逆运算就是它自己（自逆），且当 $K$ 等概随机时，$M \oplus K$ 对任意 $M$ 都均匀分布。这两个性质让它成为「把密钥混进消息」的最小、最干净的载体。</span>

## 2 正确性：为什么解密一定能还原

**一次一密的解密正确性**是逐位成立的：每一位上 $c_i = m_i \oplus k_i$，于是 $c_i \oplus k_i = m_i \oplus k_i \oplus k_i = m_i$。这里用到异或的两条基本性质：

**自逆**：$a \oplus a = 0$，任何数与自身异或得 0。
**结合律**：$(a \oplus b) \oplus c = a \oplus (b \oplus c)$，异或的先后顺序不影响结果。

这两条性质保证了「加密与解密用同一个操作、同一个密钥」，不需要任何密钥派生或转换。这也是异或在流密码、以及后续 AES 的轮函数里被反复使用的原因——硬件上就是一个 XOR 门，成本极低。<span class="marginnote">对比一下：凯撒密码的解密是「移回相同位移」，一次一密的解密是「再异或一次」——后者把加密与解密彻底对称化了，这是香农之前没人系统意识到的好处。</span>

## 3 安全性证明：密文对 Eve 完全无意义

现在证明一次一密满足完善保密性，即对任意明文 $m$、任意密文 $c$，都有 $P(M = m \mid C = c) = P(M = m)$。

证明分三步：

- **第一步，固定密文 $c$，看它可能来自哪些明文**。由于 $m = c \oplus k$，对每一条明文 $m$ 恰好对应**唯一**的密钥 $k = m \oplus c$。也就是说，给定 $c$，明文的集合和密钥的集合是一一对应的。
- **第二步，利用密钥的随机性**。密钥每一位独立等概，所以所有密钥等概率出现，$P(K = k) = 2^{-n}$。由一一对应，对任意 $m$，$P(C = c \mid M = m) = P(K = m \oplus c) = 2^{-n}$——**任意明文产生这条密文的概率完全一样**。
- **第三步，贝叶斯公式收尾**。由贝叶斯定理，$P(M=m \mid C=c) = \dfrac{P(C=c \mid M=m)\,P(M=m)}{P(C=c)}$。分子里的条件概率 $2^{-n}$ 与 $m$ 无关，可以在求和时消去，最后得到 $P(M=m \mid C=c) = P(M=m)$。证毕。

**一次一密达到了完善保密性**：Eve 即使拥有无限算力、截获任意长的密文，她对明文的判断也和没截获时完全一样。

## 4 公式解析：$P(C=c \mid M=m) = 2^{-n}$ 的含义

$$
P(C = c \mid M = m) = P(K = m \oplus c) = 2^{-n}
$$

这条式子是整个证明的心脏，拆成三步：

- **第一步，把密文概率翻译成密钥概率**：给定明文 $m$，密文 $c$ 出现当且仅当密钥取 $k = m \oplus c$——密文的不确定性完全来自密钥的不确定性。
- **第二步，代入密钥分布**：密钥随机等概，$n$ 位密钥共有 $2^n$ 种，每种概率 $2^{-n}$。
- **第三步，读出直觉**：对**同一条**密文 $c$，从**每一条**可能的明文 $m$ 出发，产生它的概率都是同一个常数 $2^{-n}$。于是密文 $c$ 不偏向任何明文——这就是「密文不含明文信息」的精确含义。

## 5 反例：密钥重用等于自杀

一次一密的前提是「一次一换」。一旦密钥被重用，攻击者立刻可以获得两个明文之间的约束关系：

$$
C_1 \oplus C_2 = (M_1 \oplus K) \oplus (M_2 \oplus K) = M_1 \oplus M_2
$$

$K$ 被消掉了！两个密文异或直接等于两个明文异或。Eve 不需要知道密钥，就能得到两条明文之间的差异模式——英文文本里有大量空格（0x20），通过这种「crib-dragging」技巧可以逐步还原两条明文。历史上最著名的案例是美苏「Venona 项目」：苏联长期重用一次性密钥本，美国情报机构据此在 1940 年代破译了大量电报。<span class="marginnote">Venona 是密码学史上「数学上完美、工程上翻车」的经典样本：密钥本被复制、重用，完美方案在现实中轰然倒塌。它反复提醒后人：<strong>安全不是算法的属性，而是使用方式的属性</strong>。</span>

## 6 一次一密是极限，不是日常

一次一密把「绝对安全」的全部代价摊在明面上：等长的随机密钥、密钥只能使用一次、安全的密钥分发。这些代价使得它在普通通信中几乎不可行——这正是现代密码学转向「短密钥 + 计算安全」的根本动力。但它的思想并没有消失：流密码的密钥流生成器、AES 的密钥扩展、TLS 的会话密钥，都是在「用伪随机生成器模拟一次一密的效果」，代价是从完美降级为「计算上安全」。

## 7 小结

- **一次一密**：$C = M \oplus K$，等长随机密钥、逐位异或、一次使用。
- 正确性来自异或的**自逆**与**结合律**：解密就是再异或一次。
- 完善保密证明的核心：给定密文，明文与密钥一一对应，且 $P(C=c \mid M=m)=2^{-n}$ 与 $m$ 无关。
- **密钥重用即毁灭**：$C_1 \oplus C_2 = M_1 \oplus M_2$，密钥被消去。
- 一次一密是**无条件安全**的极限样本，工程上以**伪随机密钥流**替代，转入计算安全。

在下一节，我们将直面一次一密的工程现实：密钥分发、密钥存储、同步问题——这些局限如何把密码学从「理论完美」推向「计算可行」，也正是**无条件安全与计算安全分野**的由来。
