## 为什么从组合生成与非线性滤波开始

上一节的结论是：纯 LFSR 会被 Berlekamp-Massey 秒杀，必须引入非线性。这一节看两条最经典的非线性化路线：**非线性组合**（多个 LFSR 输出过一个非线性函数）与**非线性滤波**（一个 LFSR 的多个抽头过非线性函数）。它们把「长周期线性序列」与「非线性函数」结合起来，看似解决了问题——直到 1980 年代西根塔勒提出**相关攻击**，揭示了一个微妙陷阱：组合函数只要与某个 LFSR 的输出「相关」，攻击者就能逐个体攻破。<span class="marginnote">这段历史是密码学「补丁工程」的缩影：线性→非线性组合→相关攻击→加记忆元件→…每一次修复都引入新的攻击面。它告诉我们：<strong>安全不能靠修补，要靠一开始就满足完整的设计准则</strong>。</span>

## 1 非线性组合生成器

**非线性组合生成器（nonlinear combination generator）** 把 $m$ 个 LFSR 的输出 $x^{(1)}_t, \ldots, x^{(m)}_t$ 同时喂给一个**非线性布尔函数** $f$，输出密钥流：

$$
z_t = f\big(x^{(1)}_t, x^{(2)}_t, \ldots, x^{(m)}_t\big)
$$

每个 LFSR 的周期独立，组合后的总体周期是所有 LFSR 周期的**最小公倍数**——只要各周期互素，总周期能撑得极大。同时 $f$ 的非线性让密钥流不再是单个 LFSR 的线性函数，Berlekamp-Massey 直接攻击失效。

但这引出关键问题：**$f$ 到底够不够非线性？** 如果一个 LFSR 的输出 $x^{(1)}_t$ 与最终输出 $z_t$ 的相关系数显著偏离 0，攻击者就能单独盯住这个 LFSR。<span class="marginnote">经典例子是 Geffe 生成器：$z_t = x^{(1)}_t x^{(2)}_t \oplus x^{(2)}_t x^{(3)}_t \oplus x^{(3)}_t$。它曾被广泛使用，但 $z_t$ 与 $x^{(1)}_t$ 的相关概率是 3/4——远超 1/2，留下明显后门。</span>

**补充：Geffe 生成器的相关泄露，逐行算一遍。** 对 $z_t = x_1 x_2 \oplus x_2 x_3 \oplus x_3$，枚举 $x_1, x_2, x_3$ 的 8 种取值，统计 $z = x_1$ 的成立次数：

| $x_1$ | $x_2$ | $x_3$ | $z$ | $z = x_1$? |
| --- | --- | --- | --- | --- |
| 0 | 0 | 0 | 0 | 是 |
| 0 | 0 | 1 | 1 | 否 |
| 0 | 1 | 0 | 0 | 是 |
| 0 | 1 | 1 | 0 | 是 |
| 1 | 0 | 0 | 0 | 否 |
| 1 | 0 | 1 | 1 | 是 |
| 1 | 1 | 0 | 1 | 是 |
| 1 | 1 | 1 | 0 | 否 |

8 种情况里 $z = x_1$ 成立 6 次，相关概率 $= 6/8 = 3/4$。每输出 1 比特就泄露 $x_1$ 约 0.42 比特信息，足以支持攻击。

## 2 相关系数攻击：逐个击破 LFSR

**相关系数攻击（correlation attack）** 由 Siegenthaler 于 1984 年提出。思路分两步：

**第一步，找相关**：对组合函数 $f$，计算每个输入变量 $x^{(i)}$ 与输出 $z$ 的相关系数 $p_i = P(z = x^{(i)})$。若某个 $p_i$ 显著偏离 1/2（如 3/4），说明 $z$ 泄露了 $x^{(i)}$ 的信息。
**第二步，逐体恢复**：把密钥流 $z_t$ 当作「带噪的 $x^{(i)}_t$ 观测」，用**最大似然 / 纠错解码**（如维特比算法）恢复第 $i$ 个 LFSR 的内部状态。恢复一个 LFSR 后，把它从 $f$ 里消去，继续攻下一个。

攻击的复杂度取决于相关系数与 LFSR 长度：$p_i$ 越偏离 1/2，每个密钥流比特泄露的信息越多，恢复 $n$ 级 LFSR 所需的观测越少。**相关性是「信噪比」**——密码学里的相关性分析，本质上就是通信理论里的信道解码。<span class="marginnote">相关性攻击的深刻之处：<strong>它把「组合函数的设计问题」变成了「纠错码的信道容量问题」</strong>。$z$ 与 $x^{(i)}$ 的相关概率 $p$，等价于一条二元对称信道的误码率——信道解码算法直接变成密码分析工具。</span>

**辨析｜易错点：** 有人以为「只要用了非线性函数就安全」。请记住 Geffe 的教训：**非线性函数可以整体非线性、却对某个输入变量高度线性相关**。真正的判据不是「整体是否非线性」，而是「是否对所有输入变量、所有输入变量子集都近乎独立」。

## 3 非线性滤波生成器：同一陷阱的变体

**非线性滤波生成器（nonlinear filter generator）** 只有一个 LFSR，但它不是取单个输出比特，而是取 LFSR 内部**多个抽头**（不同位置的寄存器值），通过非线性函数 $f$ 输出：

$$
z_t = f(s_t, s_{t+1}, \ldots, s_{t+d})
$$

好处：只用一个 LFSR，状态空间小、实现省；抽头组合提供扩散。但相关攻击照样适用：如果 $f$ 与某个**线性抽头组合**（$s$ 的某几个位置的异或）相关，攻击者就能把滤波器问题规约回 LFSR 攻击。滤波生成器的安全性取决于 $f$ 是否对所有可能的线性组合都「不相关」——这比组合生成器的要求更高。

| 特性 | 组合生成器 | 滤波生成器 |
| --- | --- | --- |
| LFSR 数量 | 多个 | 单个 |
| 抽头 | 每个 LFSR 的输出 | 同一 LFSR 的多位置 |
| 周期来源 | 各 LFSR 周期的最小公倍数 | 单个 LFSR 的周期 |
| 硬件成本 | 较高 | 较低 |
| 相关攻击目标 | 某个 LFSR 的输出 | 某条线性抽头组合 |

## 4 公式解析：相关概率如何变成攻击参数

$$
p_i = P\big(f(x^{(1)}, \ldots, x^{(m)}) = x^{(i)}\big)
$$

三步拆解这个「相关概率」为何是安全参数：

- **第一步，算概率**：随机输入下，$f$ 输出与第 $i$ 个输入相等的概率 $p_i$。若 $f$ 完全独立于 $x^{(i)}$，$p_i = 1/2$——安全；$p_i$ 偏离 1/2 越远，泄露越强。
- **第二步，换算信息**：每个密钥流比特对第 $i$ 个 LFSR 状态的信息量约 $|p_i - 1/2|$（比特）。要恢复 $n$ 级 LFSR（$n$ 比特状态），约需 $n / |p_i - 1/2|^2$ 量级的观测比特。
- **第三步，读出设计准则**：组合函数必须对每个输入变量、每个输入变量子集都「几乎不相关」——这叫**相关免疫性（correlation immunity）**。但相关免疫与非线性度存在**此消彼长**（西根塔勒不等式），设计者必须在两者间找平衡点。

用数字体会复杂度：设 $n = 64$ 级 LFSR、相关偏差 $|p_i - 1/2| = 0.25$，则攻击约需 $64 / 0.25^2 = 1024$ 比特观测即可恢复状态——微不足道。要让攻击不可行，必须把偏差压到 $|p_i - 1/2| \ll 1/\sqrt{n}$ 量级，例如 $n = 64$ 时偏差要小于约 $2^{-3}$，这极难做到。**相关免疫与非线性度的权衡，是流密码设计真正的「刀刃」。**

## 5 现代对策：从「补丁」到「证明」

组合与滤波路线在 1980–90 年代发展出一大套「平衡性、相关免疫性、非线性度、代数免疫度」的设计准则，但始终没有根本摆脱「LFSR + 非线性函数」的脆弱体质。现代流密码设计转向了两条更彻底的路：

- **带记忆的组合生成器**：在组合函数里引入内部状态（记忆），让输出依赖**历史输入**——相关攻击的静态概率分析失效（如 A5/1、Trivium）。
- **ARX 结构**：彻底抛弃 LFSR，用「加-旋转-异或」（Addition-Rotation-XOR）构造密钥流，靠整数加法的进位传播提供非线性——代表是 **ChaCha20**，它同时获得软件实现快、结构简单、易于证明的优势。<span class="marginnote">对照锚点：<strong>LFSR 是「硬件时代的流密码引擎」，ChaCha20 是「软件时代的流密码引擎」</strong>。前者几个触发器和异或门就能跑，后者靠 CPU 的 32 位加法与旋转指令。时代换了引擎，但「长周期 + 不可预测」的目标没变。</span>

## 6 术语速查

| 术语 | 含义 |
| --- | --- |
| 非线性组合生成器 | 多 LFSR 输出过非线性布尔函数 $f$ 的密钥流生成器 |
| 非线性滤波生成器 | 单 LFSR 多抽头过 $f$ 的密钥流生成器 |
| 相关概率 $p_i$ | $P(f = x^{(i)})$，偏离 1/2 即泄露 |
| 相关攻击 | 把密钥流当带噪观测，用纠错解码恢复 LFSR 状态 |
| 相关免疫性 | $f$ 对输入变量（子集）统计独立的性质 |
| Geffe 生成器 | 经典组合生成器，因相关概率 3/4 而被攻破 |
| 西根塔勒不等式 | 相关免疫与非线性度此消彼长的量化关系 |

## 7 小结

- **非线性组合生成器**：多 LFSR + 非线性布尔函数 $f$；周期为各周期的最小公倍数。
- **非线性滤波生成器**：单 LFSR 多抽头 + $f$；省硬件但要求对所有线性组合不相关。
- **相关系数攻击**（Siegenthaler）：$p_i = P(f = x^{(i)})$ 偏离 1/2 就泄露——把密码分析变成纠错解码。
- Geffe 生成器：整体非线性却与 $x_1$ 相关概率 3/4——「整体非线性 ≠ 安全」。
- 设计准则：**平衡性、相关免疫性、非线性度、代数免疫度**，且它们彼此此消彼长。
- 现代路线：带记忆生成器（Trivium）与 **ARX 结构（ChaCha20）**，彻底告别 LFSR。
- 攻击成本估算：$n$ 级 LFSR、偏差 $\epsilon$，约需 $n/\epsilon^2$ 比特观测即可恢复。
