## 为什么从破解维吉尼亚密码开始

上一节我们建起了一座看起来很坚固的堡垒：维吉尼亚密码用密钥周期驱动 26 张凯撒表，抹掉了单字母频率，把单表替换时代的一切攻击挡在门外整整三个世纪。但我们也留下了一句话——**密钥会循环，周期就是软肋**。这一节，我们就来兑现这句话。

破解维吉尼亚密码的标准流程分两步，对应两个经典工具：先用**卡西斯基试验（Kasiski test）**或**重合指数（index of coincidence）**测出密钥长度 $m$，再把密文按「每隔 $m$ 个字符取一个」拆成 $m$ 条子串——每条子串都是一条独立的凯撒密文，于是回到上一章已经学会的字母频率攻击。<span class="marginnote">破解思路之所以成立，是因为维吉尼亚密码是「周期替换」：第 $i$ 个字符只依赖 $i \bmod m$ 这一位。所以按周期拆出来的每条子串，内部用的是同一张替换表——一条普通到可以直接用频率分析的单表替换。</span>

这套方法的数学内核有两个量：卡西斯基试验靠「重复片段之间的距离」找周期，重合指数靠「字母分布偏离均匀的程度」验证周期。一个给出候选，一个确认取舍，配合起来几乎无往不利。而它的统计思想——**从观察值反推隐藏参数**——正是香农信息论即将登场的序曲。

## 1 破解思路总览：先测密钥长度，再还原密钥内容

维吉尼亚密码的加密公式是 $C_i = (P_i + K_i) \bmod 26$，密钥长度 $m$ 未知。攻击者面对一大段密文，不知道 $m$，更不知道 $K_1, \dots, K_m$。破解分两个阶段：

**阶段一：测 $m$。** 若能确定密钥长度 $m$，就把密文按下标对 $m$ 取模分成 $m$ 组：

$$G_j = \{\, C_i \mid i \equiv j \ (\mathrm{mod}\ m) \,\}, \qquad j = 0, 1, \dots, m-1$$

每组 $G_j$ 恰好对应密钥的第 $j$ 个字符：组内所有字符都被同一个移位量 $K_j$ 加密，所以每组都是一条**凯撒密文**。

**阶段二：逐组还原。** 对每组 $G_j$ 做字母频率分析（上一章的老手艺）：出现最多的密文字母，大概率是明文 $E$ 的像，于是 $K_j = (\text{该密文字母} - E) \bmod 26$。逐组解出 $K_0, K_1, \dots, K_{m-1}$，密钥单词就出来了。

所以整场战役的关键，全在阶段一的 $m$。卡西斯基试验和重合指数是测量 $m$ 的两把尺子。

## 2 卡西斯基试验：让重复片段自己招供

卡西斯基试验的思路非常朴素，它盯着密文里**重复出现的片段**看。前提是一条语言事实：任何自然语言文本里都有高频常见词，比如英文的 `the`、`and`、`tion`。假设某个常见词在明文里出现了两次，且两次出现的位置之差恰好是密钥长度的整数倍——那么这两次出现会被**同一张替换表**加密（因为位置差是 $m$ 的倍数，密钥位完全相同），加密结果必然是一模一样的密文片段。

反过来，攻击者就在密文里找重复片段：**重复片段两次出现之间的距离，往往就是密钥长度的倍数。** 把多个重复片段的距离放在一起，取最大公约数（gcd），就得到一个大概率等于 $m$ 的候选值。<span class="marginnote">卡西斯基 1863 年在《秘密写作与破译艺术》中发表此法。它的洞察可以浓缩成一句：<strong>相同的密文片段 ⇒ 大概率是同一明文片段被同一密钥位加密 ⇒ 两次出现的位置差是周期的倍数</strong>。当然这只是一个「概率线索」——巧合的重复也会出现，所以要求 gcd、要求多个证据交叉，而不是靠单次重复下结论。</span>

来看一个微缩例子。设密钥长度为 $m=3$，明文某处出现两次 `the`，位置分别在 $i$ 与 $i+6$（差 6，是 3 的倍数）。加密时 `t`、`h`、`e` 分别用第 1、2、3 张替换表，两处完全相同，所以密文会出现两段一模一样的 3 字符片段，距离恰好 6。攻击者测得距离 6，它的约数 2、3 都是候选 $m$。若再发现另一处重复的距离是 9，则 $\gcd(6, 9) = 3$——密钥长度 3 浮出水面。

**辨析｜易错点：** 卡西斯基试验给出的是「倍数」，不是「精确值」。重复片段间的距离 $d$ 满足 $d \equiv 0 \pmod m$，所以 $m$ 是 $d$ 的约数；而巧合重复（比如不同明文词组恰好拼出相同密文）会引入「杂质距离」。正确的做法是收集一批距离、逐个取约数、统计出现最多的公约数——**要用多数证据投票，而不是拿单条距离断言**。此外，密文越短、语言越单调，重复越少，试验越不可靠；这也是为什么需要重合指数来交叉验证。

## 3 重合指数：用「分布有多不均匀」验证密钥长度

卡西斯基试验靠「重复片段」说话，但短密文里重复片段可能少得可怜。重合指数（index of coincidence，简称 IC）换了一把尺子：它直接测量**密文字母分布的均匀程度**。

定义如下。设密文总长度 $N$，字母表中第 $i$ 个字母出现 $n_i$ 次（$i = 0,\dots,25$），从密文里随机抽取两个字符，它们**相同**的概率就是重合指数：

$$
\mathrm{IC} = \frac{\sum_{i=0}^{25} n_i (n_i - 1)}{N (N - 1)}
$$

这个量对「分布长什么样」极其敏感：

- 若密文是**均匀分布**的随机字母，每个字母约占 $1/26$，则抽到两相同字母的概率约为 $1/26 \approx 0.0385$。
- 若密文是**英文原文**（或任何单表替换密文），频率并不均匀——最高的 $E$ 占 12.7%——则抽到两相同字母的概率显著更高，英文长文本的 IC 约为 **0.065**。

维吉尼亚密文处在两者之间：密钥长度 $m$ 越大，频率被摊得越平，IC 越接近 0.0385；$m$ 越小（尤其 $m=1$，退化为单表替换），IC 越接近 0.065。于是**IC 成了一台「周期探测器」**：试遍 $m=1,2,3,\dots$，把密文按周期拆组、对每组分别算 IC 再取平均，平均 IC 最高的那个 $m$，就是最可能的密钥长度。<span class="marginnote">弗里德曼 1920 年发表《重合指数及其在密码学中的应用》，用这份统计工具让维吉尼亚密码的攻击完全量化。后来它还被推广成更通用的「估计文本语言 / 猜测密钥长度」工具，是统计密码分析的奠基作之一。</span>

## 4 公式解析：重合指数与弗里德曼的密钥长度公式

先拆 IC 的定义式，再把它改写成密钥长度的估计器。

**第一步，看分子 $\sum n_i(n_i-1)$。** 若字母 $i$ 出现 $n_i$ 次，则「在 $i$ 内部抽一对」有 $\binom{n_i}{2} = n_i(n_i-1)/2$ 种方式；所有字母加起来，抽到「相同字母对」的总数是 $\sum_i n_i(n_i-1)/2$。

**第二步，看分母 $N(N-1)$。** 从 $N$ 个字符里有序抽两个，总共有 $N(N-1)$ 种方式。两者相除，正是「随机抽一对相同」的概率：

$$
\mathrm{IC} = \frac{\sum_i \binom{n_i}{2}}{\binom{N}{2}}
= \frac{\sum_i n_i(n_i-1)}{N(N-1)}
$$

**第三步，连接英语统计。** 对英文原文，$E$ 以概率 $p_E \approx 0.127$ 出现，随机抽一对相同的概率近似 $\sum_i p_i^2 \approx 0.065$；对均匀随机字母，$\sum_i p_i^2 = 26 \times (1/26)^2 = 1/26 \approx 0.0385$。把这两个数记住：**0.065 与 0.0385 是 IC 的两个天然参照点。**

**第四步，反推密钥长度。** 对维吉尼亚密文，任取一对密文字符，它们落入同一条子串（即下标同余 $\bmod\ m$）的概率约为 $1/m$；落入同一条子串时，字符服从英语频率，配对的 IC 约为 0.065；落入不同子串时，近似均匀独立，IC 约为 $1/26$。因此期望 IC 约为

$$
\mathbb{E}[\mathrm{IC}] \approx \frac{1}{m} \cdot 0.065 + \left(1 - \frac{1}{m}\right) \cdot \frac{1}{26}
$$

解出 $m$，得到弗里德曼的估计式：

$$
m \approx \frac{0.0265}{\mathrm{IC} - 0.0385}
$$

**第五步，验证直觉。** 当 $m=1$ 时，$\mathbb{E}[\mathrm{IC}] = 0.065$（纯英语）；当 $m\to\infty$ 时，$\mathbb{E}[\mathrm{IC}] \to 0.0385$（趋于均匀）。把观测到的 IC 代入上式，四舍五入就得到密钥长度。短文本下公式会有偏差，所以工程上通常用它给出候选范围，再与卡西斯基试验的结果互相印证。

## 5 Python 实战：两把尺子一起上

把卡西斯基试验与重合指数写成代码，就能对任意维吉尼亚密文自动测出密钥长度：

```python
import math
from collections import Counter

ALPHABET = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"

def ic(text):
    """重合指数 IC = Σ n_i(n_i-1) / (N(N-1))；英文约 0.065，均匀约 0.0385。"""
    n = len(text)
    cnt = Counter(c for c in text.upper() if c in ALPHABET)
    return sum(v * (v - 1) for v in cnt.values()) / (n * (n - 1))

def kasiski(ciphertext):
    """卡西斯基试验：收集重复 3 字符片段的距离，返回出现最多的约数（候选 m）。"""
    dists, seen = [], {}
    for i in range(len(ciphertext) - 3):
        chunk = ciphertext[i:i + 3]
        if chunk in seen:
            dists.append(i - seen[chunk])
        else:
            seen[chunk] = i
    divs = []
    for dist in dists:
        for d in range(1, int(math.sqrt(dist)) + 1):
            if dist % d == 0:
                divs.append(d)
                if d * d != dist:
                    divs.append(dist // d)
    return Counter(divs).most_common(1)[0][0]

def split_by_period(text, m):
    """按周期拆组：text[i::m] 归为一组，共 m 组——多表替换打回 m 条单表替换。"""
    return [text[i::m] for i in range(m)]

def guess_key_length(ciphertext):
    """用 IC 探测密钥长度：试遍 m=1..20，平均 IC 最高者胜出。"""
    best_m, best_score = 1, 0.0
    for m in range(1, 21):
        score = sum(ic(g) for g in split_by_period(ciphertext, m)) / m
        if score > best_score:
            best_m, best_score = m, score
    return best_m
```

代码里的 `split_by_period` 就是按周期拆组——**这一步把多表替换打回了 m 条单表替换**。算出 $m$ 后，对每组做上一章的频率分析即可还原密钥字母；把多组结果拼起来，密钥单词就完整现形。<span class="marginnote">把「按周期拆组再逐组分析」抽象一层，就是密码学里反复出现的<strong>「divide and conquer」</strong>：多表替换的复杂性被拆成 m 个并行的单表子问题，复杂度从指数级降到多项式级。这种「找到隐藏结构，把难问题分解」的思路，在第三篇的线性/差分密码分析里会再次登场。</span>

## 6 历史回响：从卡西斯基到香农

卡西斯基（1863）用重复片段破开了维吉尼亚密码的周期，弗里德曼（1920）用重合指数把它彻底量化。这条「加密者抹统计 ↔ 分析者找统计」的战线，至此走完了古典时代的最后一程。维吉尼亚密码的退场留下一个深刻的教训，也是通向下一篇章的门票：**一个密码的强度不是看「看起来多乱」，而是看「密钥到底提供了多少不确定性」。** 密钥长度 $m$ 就是那点不确定性的全部来源——只要密钥短到会循环，统计就总能把它揪出来。

这个教训由香农在 1949 年的《保密系统的通信理论》中升华为一般理论：他用**熵**度量密钥、明文与密文各自的不确定性，用**疑义度**（条件熵）度量「给定密文后还剩多少不确定」，并证明了一条冷酷的边界——要真正彻底保密，密钥的熵至少要赶上明文的熵。换句话说，**维吉尼亚密码「密钥太短」的宿命，不是某个具体算法的失误，而是信息论意义上的必然**。下一节我们就进入这篇奠基之作：用熵这把尺子，丈量一切保密系统。

## 7 小结

- 破解维吉尼亚密码分两步：**先测密钥长度 $m$，再按周期拆组、对每组做频率分析**还原密钥。
- **卡西斯基试验**：密文重复片段两次出现的位置差多为 $m$ 的倍数，取 gcd 得候选 $m$。
- **重合指数 IC**：$\mathrm{IC} = \dfrac{\sum n_i(n_i-1)}{N(N-1)}$；英文约 0.065，均匀约 0.0385，维吉尼亚密文介于其间。
- **弗里德曼公式**：$m \approx \dfrac{0.0265}{\mathrm{IC} - 0.0385}$，把观测 IC 反推成密钥长度。
- 两把尺子互为印证：**卡西斯基给候选，IC 给确认**；短文本时 IC 更稳，长文本时两者都好用。
- 深层教训：多表替换的周期结构使「divide and conquer」得以把难问题拆成若干单表子问题。

在下一节，我们将离开替换的世界，转向古典密码的另一大支柱——**不换字母、只换位置**的置换密码，并看到它如何与替换联手，成为现代分组密码的胚胎。
