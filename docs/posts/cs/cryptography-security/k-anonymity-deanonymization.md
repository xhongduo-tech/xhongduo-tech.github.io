# 匿名化与 k-匿名：去匿名化攻击

## 为什么从匿名化与 k-匿名开始

大数据时代，机构发布脱敏数据用于研究——但**「去掉姓名」不等于「匿名」**。1997 年，Latanya Sweeney 用一个著名实验证明：只要知道出生日期、性别、邮编三项（准标识符），就能唯一指认美国大多数公民——即使数据「去除了姓名」。**k-匿名（k-anonymity）** 就是她提出的防御：让每条记录至少与 $k-1$ 条其他记录不可区分。理解匿名化与去匿名化，是理解「隐私为什么难」的第一课。<span class="marginnote">Sweeney 的著名实验：<strong>1997 年，她用「出生日期 + 邮编 + 性别」三个准标识符，在公开的「马萨诸塞州雇员医保数据」里指认出了当时的州长</strong>——数据已经「去掉了姓名」，但三项组合足以唯一锁定。这个实验宣告了「去标识 ≠ 匿名」。</span>

## 1 为什么去标识不够：准标识符与链接攻击

**标识符（identifier）**：能直接指认个人的字段——姓名、身份证号、手机号。

**准标识符（quasi-identifier, QI）**：单独不指认个人，但**组合起来**能唯一/接近唯一地指认——出生日期、性别、邮编、职业。

**链接攻击（linkage attack）**：攻击者把**发布的数据**与**外部公开数据**（选民登记、社交媒体）按准标识符**链接**，把「匿名记录」指认回个人。

发布数据：`{出生日期, 性别, 邮编, 诊断}`（医院发布的「已去标识」医疗记录）
外部数据：`{姓名, 出生日期, 性别, 邮编}`（选民登记表）
链接：按三项准标识符匹配 → 得到「谁得了什么病」。<span class="marginnote">去匿名化的普遍性：<strong>几乎任何「组合足够多属性」的数据都能指认个人</strong>——研究显示约 87% 的美国人可用「邮编+性别+出生日期」唯一识别。匿名化的真正敌人不是「姓名」，而是「准标识符的组合粒度过细」。</span>

**辨析｜易错点：** 「去标识」常被误当成「已经匿名」。其实去标识只是**移除直接标识符**（姓名、ID），而准标识符（出生日期、邮编等）仍留在数据里。攻击者只要有一条外部数据源，就能用准标识符做链接攻击——**去标识是「减少标识」，匿名是「消除可指认性」**，两者天差地别。

## 2 k-匿名：让记录「淹没」在同类里

**k-匿名** 的防御思路：**让每条记录在「准标识符组合」上至少与 $k-1$ 条其他记录完全相同**——这样攻击者最多把目标缩小到「一组 $k$ 条记录」，无法唯一指认。

**实现方式——泛化（generalization）与抑制（suppression）**：

**泛化**：把准标识符的粒度变粗——出生日期 `1985-03-14` → `1985`；邮编 `100081` → `100`。
**抑制**：删除无法安全泛化的记录/值。

**k=3 的例子**：把出生日期泛化到「年」、邮编泛化到「前 3 位」，使每组至少 3 条记录共享同一 QI 组合——攻击者只能确定「目标在这 3 人里」。

**k-匿名的意义**：它把「唯一指认」变成「至少 $k$ 选 1」——$k$ 越大，隐私越好，但数据效用越低（泛化损失信息）。<span class="marginnote">k-匿名的权衡：<strong>$k$ 越大越安全，但数据越「糊」</strong>——出生日期到年、邮编到前三位的泛化，让「研究某病的年龄相关性」还能做，但「精确到个人的统计」就做不了了。k-匿名是「隐私-效用」天平上的第一个正式刻度。</span>

| k 值 | 攻击者能确定 | 数据效用 |
| --- | --- | --- |
| k=1 | 唯一指认 | 最高（未泛化） |
| k=5 | 目标在 5 人中 | 中等 |
| k=20 | 目标在 20 人中 | 较低（泛化严重） |

## 3 k-匿名的失败模式：它不防什么

k-匿名不是万能药，它有多个已知弱点：

**同质攻击（homogeneity attack）**：一组 $k$ 条记录里，敏感属性**全部相同**——虽然不能指认「是谁」，但能确定「这 $k$ 人都有艾滋病」。
**背景知识攻击**：攻击者知道目标的一些背景（如「目标不住养老院」），可以排除组内的部分记录，缩小范围。
**合成数据/重识别**：k-匿名没有数学保证——它只保证「组内 $k$ 条」，不保证「攻击者无法用其他知识进一步区分」。

**k-匿名的本质局限**：它是**启发式**（基于泛化），不是**数学定义**——它不量化「攻击者知道多少」，因此无法给出「绝对的隐私保证」。这正是差分隐私（下一节）登场的原因。<span class="marginnote">k-匿名 vs 差分隐私：<strong>k-匿名是「启发式」（泛化后分组），差分隐私是「数学定义」（对查询结果加噪）</strong>——差分隐私不依赖「攻击者不知道什么」的假设，它保证「无论攻击者知道多少，输出都不泄露单个人的信息」。这是隐私技术从「经验」到「可证明」的跃迁。</span>

## 4 公式解析：k-匿名的形式定义

$$
\forall \text{QI 组合 } q: \quad |\{r \in D : QI(r) = q\}| \ge k
$$

三步拆解这条「k-匿名定义」：

- **第一步，QI 组合**：把所有准标识符（如出生日期、邮编、性别）看成一个组合 $q$。
- **第二步，分组计数**：统计数据集中「QI 组合 = q」的记录条数。
- **第三步，约束**：对**每个** QI 组合，记录数都 ≥ $k$——任何一组都至少有 $k$ 条，攻击者最多缩小到 $k$ 选 1。

**重点：k-匿名防的是「按准标识符直接指认」，不是「一切指认」。** 它把「唯一指认」挡在门外，但挡不住「用敏感属性的同质性」或「用外部背景知识」的间接指认——这正是它需要被 l-多样性、差分隐私补强的根本原因。

## 5 从 k-匿名到 l-多样性到差分隐私

隐私技术的演进是「不断堵住前一种的漏洞」：

- **k-匿名**（1998）：组内 ≥ k 条——防「唯一指认」，但不防「组内同质」。
- **l-多样性**（2006）：组内敏感属性至少有 l 个不同值——补同质攻击。
- **t-紧密度**（2007）：敏感属性分布接近整体分布——补背景知识攻击。
- **差分隐私**（2006）：用数学噪声给出**可证明的隐私保证**——不再依赖「攻击者假设」。

**趋势**：从「启发式的匿名化」到「数学化的差分隐私」——现代隐私保护以差分隐私为理论核心，k-匿名仍是「简单场景」的实用手段。<span class="marginnote">一条演进主线：<strong>k-匿名 → l-多样性 → t-紧密度 → 差分隐私——每一步都在回答「前一种还漏什么」</strong>。差分隐私之所以成为终点，是因为它不再「隐藏个体」，而是「让任何个体的存在与否对输出影响可忽略」——这是信息论层面的保证，不是启发式。</span>

## 6 术语速查

| 术语 | 含义 |
| --- | --- |
| 标识符 | 直接指认个人的字段（姓名、ID） |
| 准标识符（QI） | 组合起来可指认个人的字段（日期/邮编/性别） |
| 链接攻击 | 用外部数据按 QI 匹配的指认攻击 |
| k-匿名 | 每组 QI 至少 k 条记录 |
| 泛化 / 抑制 | 变粗粒度 / 删除记录，实现 k-匿名的工具 |
| 同质攻击 | 组内敏感属性全部相同的攻击 |
| l-多样性 | 组内敏感属性至少 l 个不同值 |

## 7 小结

- **去标识 ≠ 匿名**：准标识符组合（出生日期+邮编+性别）能唯一指认个人——链接攻击。
- **k-匿名**：每条记录与 ≥ k-1 条记录在 QI 上不可区分——泛化 + 抑制实现。
- **局限**：不防同质攻击、背景知识攻击——启发式、无数学保证。
- **演进**：k-匿名 → l-多样性 → t-紧密度 → **差分隐私**——从经验到可证明。
- 现实：简单场景用 k-匿名，严格隐私用差分隐私——「隐私-效用」天平需要显式权衡。
- 一个直觉：k-匿名防「唯一指认」，不防「间接指认」——它的每一处短板，都是后一个技术登场的原因。
- 记住 Sweeney 实验：87% 的美国人可用「邮编+性别+出生日期」唯一识别——去标识从来不够。
- 一个实用自查：发布数据集前，先做「最坏情况」的链接攻击演练——用外部公开数据试着把几条记录指认回个人。
- k-匿名不是「要不要用」而是「用在哪」：简单统计场景够用，严格隐私场景交给差分隐私。

- 一个对比记忆：k-匿名问「这条记录和谁一样」，差分隐私问「这个人还在不在数据里」——前者启发式、后者可证明。
- 一句话收尾：匿名化的第一课是「别信去标识」——准标识符组合是隐私最大的敌人，泛化是它最朴素的盾。

- 一个工程动作：泛化之前先想「这组准标识符能不能被外部数据源撞上」——撞得上就该泛化或抑制。
- 记住演进终点：差分隐私是「不再假设攻击者」的数学保证——k-匿名是它的前传，不是替代。

- 一句话总结：去标识是「减少标识」，k-匿名是「分组淹没」，差分隐私是「数学保证」——三者难度递增、保证递增。
