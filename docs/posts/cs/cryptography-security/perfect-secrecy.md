# 完善保密性（Perfect Secrecy）：定义与判定

## 为什么从完善保密性开始

上一节我们用香农熵定义了疑义度 $H(M \mid C)$：密文带给明文的「残余不确定性」。沿着这条思路往前走，一个自然的问题浮现：**最好能有多安全？** 香农在 1949 年给出了一个历史上第一个、也是唯一一个「绝对安全」的数学定义——**完善保密性（perfect secrecy）**。它不依赖任何计算假设、不依赖攻击者的算力，只依赖概率本身。理解它是理解「安全到底意味着什么」的起点，也是下一节一次一密安全证明的直接铺垫。<span class="marginnote">信息安全的两条路线在此分野：<strong>无条件安全</strong>（本节的完善保密性）与<strong>计算安全</strong>（后面 RSA、AES 走的路线）。前者靠概率定义说话，后者靠「攻击者的工作量」说话。</span>

## 1 直觉：截获密文不该改变你对明文的看法

设想一位密码分析者 Eve 在信道上截获了一段密文 $C$。在截获之前，她心中对「明文 $M$ 是什么」有一个先验概率 $P(M)$——这来自她对消息内容的常识推断，比如电报的开头多半是「先生/女士」。截获密文 $C=c$ 之后，她的判断会更新为后验概率 $P(M \mid C=c)$。

**完善保密性的直觉表述**：无论 Eve 截获到哪一段密文，她的后验判断都回到先验判断——密文没有给她任何新的信息。

用公式写出来就是：对任意明文 $m$ 与任意密文 $c$，

$$
P(M = m \mid C = c) = P(M = m)
$$

这个等式看起来简单，力量却极大：它要求**密文与明文在统计上独立**。Eve 观察到的密文无论长什么样，都无法让任何一条明文的可能性增加或减少——她截获密文前后的知识完全一样。

<span class="marginnote">注意这个定义的苛刻程度：它要求对<strong>任意</strong>密文 $c$ 都成立，包括「概率极低的密文」。一个密码体制只要有一个密文可能泄露信息，就不满足完善保密性。这意味着不存在「差一点点完善」——要么完美，要么不完美。</span>

## 2 用条件熵重写：疑义度不减少

上一节的工具在这里派上用场。把上面的定义翻译成信息论语言：$P(M \mid C) = P(M)$ 等价于**给定密文后明文的熵不减少**：

$$
H(M \mid C) = H(M)
$$

- 若 $H(M \mid C) < H(M)$，说明看到密文后明文的熵变小了——密文**泄露**了关于明文的信息，攻击者的疑义度下降，不安全。
- 若 $H(M \mid C) = H(M)$，说明密文没有提供任何关于明文的信息——完美安全。

这个等价关系是把「概率意义上的独立」翻译成「信息论意义上的独立」。两种语言描述的是同一件事，但条件熵版本更便于我们推导下一节的必要条件，也更贴合「疑义度」这套已有的词汇体系。<span class="marginnote">条件熵的链式法则 $H(M,C) = H(M) + H(C \mid M) = H(C) + H(M \mid C)$ 在此处反复出现——它把「明文的熵」「密钥的熵」「密文的熵」三者的关系锁定在一起。</span>

## 3 判定：密钥空间必须至少和明文空间一样大

香农不仅给出了定义，还给出了一个极其重要的**必要条件**：一个完善保密的密码体制，其密钥熵必须不少于明文熵，即

$$
H(K) \ge H(M)
$$

特别地，若密钥等概分布且明文空间是有限集，则有 $|K| \ge |M|$——**密钥至少与消息一样长**。

证明思路只有四步，但每一步都值得回味：

- **第一步**，密文的熵不超过密钥与明文的联合熵：$H(C) \le H(K, M)$。
- **第二步**，密钥与明文在现实中相互独立（发送者选明文时不知道密钥），所以 $H(K, M) = H(K) + H(M)$。
- **第三步**，完善保密要求 $H(M \mid C) = H(M)$，等价于 $H(M \mid C) = H(M)$ 与 $H(C \mid M) = H(C)$ 同时成立（密文与明文相互独立，方向对称）。
- **第四步**，把链式法则代入：$H(M \mid C) = H(M, C) - H(C)$，而 $H(M, C) = H(M, C, K) - H(K \mid M, C) \le H(M) + H(K)$。整理后得到 $H(K) \ge H(M)$。

## 4 公式解析：为什么 $|K| \ge |M|$ 是硬约束

$$
|K| \ge |M| \quad \text{（完善保密的前提）}
$$

三步拆解这条最实用的推论：

- **第一步，理解符号**：$|K|$ 是密钥空间的大小（密钥的种数），$|M|$ 是明文空间的大小（可能消息的条数）。一次一密里两者都是 $2^n$（$n$ 位），所以等式恰好成立——这是它能完善保密的根本原因。
- **第二步，理解为什么必须「密钥至少和消息一样长」**：直觉上，每一段密文都必须能被「不同的密钥」解释成「不同的明文」。若密钥比消息少（$|K| < |M|$），则固定一段密文，用全部密钥去解密只能覆盖少于 $|M|$ 种明文——攻击者至少能排除掉一条明文，信息就泄露了。
- **第三步，理解推论**：密钥不能复用、不能缩短、必须一次一换。这解释了为什么「安全」和「方便」在此处不可兼得——后文 AES 用短密钥实现「计算安全」，付出的代价就是放弃「完善安全」。

## 5 用凯撒密码做反例：为什么它差得远

把理论落到具体密码上。凯撒密码密钥空间只有 26 种位移，明文空间远大于 26，$|K| \ll |M|$，必然不满足完善保密。更具体地看：截获密文 $|K| \ll |M|$（明文 $|K| \ll |M|$ 位移 3），Eve 用 26 个密钥逐一试解，会得到 26 种「合法英文」——但原文 $|K| \ll |M|$ 在语义上显然更可能，后验概率不等于先验，信息泄露。

维吉尼亚密码同样不满足，原因更微妙：它不是密钥太短，而是**密钥周期性复用**。只要密文长度超过密钥周期，同一密钥片段对应的多个密文位之间就出现统计关联，字母频率的峰谷被保留下来，后验分布就不再等于先验分布。上一节的卡西斯基试验正是利用这一点找到周期。<span class="marginnote">一个值得记住的对照：<strong>完善保密性要求密钥与消息等长且不重用</strong>；古典密码要么密钥太短（凯撒、仿射），要么密钥重用（维吉尼亚、重复密钥流），统统撞上同一堵墙。</span>

## 6 完善保密性不是终点，而是分水岭

完善保密性在现代密码学里的角色更像一把「量尺」而不是「日常工具」：它告诉我们绝对安全长什么样、代价是什么。代价（$|K| \ge |M|$、密钥一次性、等概随机）在绝大多数应用场景里不可承受，于是密码学在 1970 年代转向了另一条路线——用「攻击者计算能力有限」换取「密钥可以很短」的计算安全。这个分野是密码学思想史上最重要的一次转向。

## 7 小结

- **完善保密性**：$P(M=m \mid C=c) = P(M=m)$，密文与明文统计独立。
- 等价的信息论刻画：**疑义度不减少** $H(M \mid C) = H(M)$。
- 香农必要条件：$H(K) \ge H(M)$，等概有限情形下即 **$|K| \ge |M|$**——密钥不能比消息短。
- 凯撒、仿射、维吉尼亚全部不满足；不满足的原因分别是**密钥空间过小**与**密钥周期复用**。
- 完善保密是**无条件安全**的代表；代价不可承受，才催生了计算安全路线。

在下一节，我们将看到一个把 $|K| \ge |M|$ 推到等号成立的密码体制——**一次一密（One-Time Pad）**，并证明它确实达到完善保密性。
