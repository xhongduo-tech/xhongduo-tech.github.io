## 为什么从香农开始

前几节我们在古典密码的战场上摸爬滚打：单表替换被频率攻击击穿，维吉尼亚密码靠周期勉强续命、又被卡西斯基与重合指数拆解。这一路我们反复遇到同一个问题，却一直没给它一个精确的答案——**一个保密系统到底需要多少密钥才算安全？** 直觉说「密钥越长越安全」，但「长」到多少？为什么维吉尼亚密码「密钥会循环」就必死？能不能有一个统一的理论，一次性回答所有这些问题？

能。这就是香农在 1949 年给出的答案。克劳德 · 香农（Claude E. Shannon）1948 年刚发表划时代的《通信的数学理论》创立信息论，第二年就把这套工具用到了密码学上，写下《保密系统的通信理论》。他的洞察是革命性的：**保密问题本质上是一个信息问题。加密就是一场「信息对抗」——发送方想让密文携带尽量少的关于明文与密钥的信息，攻击者想从密文里榨取尽量多的信息。** 而「信息量」恰好有一把精确的尺子：熵。

香农用三个概念重构了整个密码学：**熵（entropy）**度量不确定性，**条件熵（conditional entropy）**度量「在知道一部分信息之后还剩多少不确定性」，而它作用在密码学对象上就有了专门的名字——**疑义度（equivocation）**：给定密文后，关于明文（或密钥）还剩下的不确定性。<span class="marginnote">信息论的熵在第二级《信息论》中已系统讲过（对标 Cover & Thomas《Elements of Information Theory》）。本节是它的密码学应用：同一把尺子，从「压缩编码」的场景换到「保密系统」的场景。若你还没学过信息论，本节也会把熵的定义自包含地讲清楚。</span>

## 1 香农的公理化转向：把密码学变成数学

在香农之前，密码学是一门手艺：每个密码都有自己的一套说法，安全性靠「多年实战未破」来背书，谈不上理论。香农做的第一件事，是把「密码系统」抽象成一个可以形式化的对象。

他定义：一个**保密系统（secrecy system）**由三部分组成——**明文消息空间** $M$、**密钥空间** $K$、**密文空间** $C$，外加一套加密规则 $E_K: M \to C$ 与解密规则 $D_K$，满足 $D_K(E_K(m)) = m$。这与我们在《密码学的基本概念》里学的五元组一脉相承，但香农的侧重点完全不同：他不再问「这个具体的替换表长什么样」，而是问——**在 $M$、$K$、$C$ 上各有一个概率分布，它们之间的信息如何流动？**

这套「概率化」的眼光是决定性的。攻击者知道的不是「某一份具体明文」，而是「明文服从某个分布」（语言统计就是这种分布）。加密过程把明文的分布、密钥的分布，加工成密文的分布。密码分析就是：**给定密文的观测值，反向推断明文与密钥的后验分布。** 于是「保密系统安全吗」变成了一个可以精确计算的量——这正是熵出场的地方。

**辨析｜易错点：** 香农的模型要求**密钥是随机选取的**——密钥必须服从一个分布（通常假设均匀分布）。初学者常忽略这一条，以为「密钥只要长就行」。但香农理论说的从来不是「密钥有多长」，而是「密钥有多少**熵**」。一个长度 100 的密钥若由可预测的日期组成，它的熵可能比一个随机的 8 位密钥还低。**长度 ≠ 熵**，这是理解后续一切结论的前提。

## 2 熵：不确定性的度量

香农把「信息量」定义成「消除的不确定性」，而「不确定性」本身用熵来度量。设随机变量 $X$ 取值于集合 $\{x_1, \dots, x_n\}$，取 $x_i$ 的概率为 $p(x_i)$，则 $X$ 的**熵**为

$$
H(X) = -\sum_{i=1}^{n} p(x_i) \log_2 p(x_i)
$$

单位是**比特（bit）**。这个定义有两处值得停下来品味：

- **$\log_2$ 让「不确定性」可叠加**：如果 $X$ 等价于两个独立二选一的叠加，那么它的熵等于两个二选一熵之和。$H(X)$ 的比特数，恰好是「最省的平均编码长度」——这与第二级《信息论》中信源编码定理同源。
- **等概率时熵最大**：若 $n$ 个取值等概率，$p(x_i) = 1/n$，则 $H(X) = \log_2 n$。均匀分布的不确定性最高；分布越偏斜，不确定性越低。一个「几乎总是 A」的变量，熵趋近 0——因为它的取值几乎可预测。

对密码学而言，熵回答了一个尖锐的问题：**密钥有多少「真正的不确定性」？** 若密钥等概率取自 $|K|$ 个可能值，则 $H(K) = \log_2 |K|$ 比特。$|K|$ 是密钥空间大小，而 $H(K)$ 才是密钥真正提供的不确定性——攻击者平均要试 $2^{H(K)}$ 次才能穷尽。这就是为什么我们前面总说「密钥空间大不等于安全」：**决定强度的不是密钥的位数，而是密钥的熵。**<span class="marginnote">一个常被引用的对照：DES 有 $2^{56}$ 个可能密钥，$H(K) = 56$ 比特；而一个由英语单词拼接的「密码短语」，每个单词约 11 比特熵，4 个单词也只有约 44 比特——常常不如随机 56 比特密钥。</span>

## 3 联合熵、条件熵与疑义度

单个变量的熵还不够，保密系统关心的是变量之间的依赖。香农定义了三个「多变量」工具。

**联合熵（joint entropy）**度量一对变量的总不确定性：

$$
H(X, Y) = -\sum_{x}\sum_{y} p(x, y) \log_2 p(x, y)
$$

**条件熵（conditional entropy）**度量「已知 $Y$ 之后，$X$ 还剩下多少不确定性」：

$$
H(X \mid Y) = -\sum_{x}\sum_{y} p(x, y) \log_2 p(x \mid y)
$$

条件熵的性质极其直观：**知道 $Y$ 只会减少或保持 $X$ 的不确定性，绝不会增加**，即 $H(X \mid Y) \le H(X)$。当且仅当 $X$ 与 $Y$ 独立时取等号——知道 $Y$ 对 $X$ 毫无帮助。

把条件熵用到密码学三件套上，就得到香农起名**疑义度（equivocation）**的两个核心量：

- **明文疑义度** $H(M \mid C)$：已知密文 $C$ 后，关于明文 $M$ 还剩下的不确定性。
- **密钥疑义度** $H(K \mid C)$：已知密文 $C$ 后，关于密钥 $K$ 还剩下的不确定性。

它们的含义一句话就能说透：**$H(M \mid C)$ 越接近 $H(M)$，说明密文泄露的明文信息越少；$H(M \mid C) = H(M)$ 意味着密文对明文毫无贡献——这就是完善保密性。** 而 $H(K \mid C)$ 告诉我们，拿到一份密文后，攻击者关于密钥还剩多少不确定性——它直接度量「破译有多难」。<span class="marginnote">注意疑义度是「条件熵」在密码学里的专门叫法，数学上就是 $H(M \mid C)$ 与 $H(K \mid C)$。教材里「疑义度」三个字常让初学者发怵，其实它只是换了个名字的条件熵——这个对应关系记牢，后面一切定理都好读。</span>

## 4 公式解析：用链式法则计算疑义度

疑义度本身很少直接算，人们通常用**链式法则（chain rule）**把它化成更好处理的形式。核心公式是

$$
H(X, Y) = H(Y) + H(X \mid Y)
$$

移项即得

$$
H(X \mid Y) = H(X, Y) - H(Y)
$$

把它套在明文与密文上，得到本节最关键的一条：

$$
H(M \mid C) = H(M, C) - H(C)
$$

逐项拆解：

- **第一步，先读链式法则 $H(X, Y) = H(Y) + H(X \mid Y)$**：联合不确定性，等于「先确定 $Y$ 的不确定性」加上「在 $Y$ 已知时 $X$ 的不确定性」。这与直觉吻合：你知道两个人一起干的事的信息量，等于先弄清其中一人，再看另一人还剩多少。这个等式是信息论的公理级结果，香农证明它不需要任何额外假设。
- **第二步，套到 $H(M, C)$ 上**：把 $X = M$、$Y = C$ 代入，$H(M, C) = H(C) + H(M \mid C)$。联合不确定性由「密文的不确定性」与「知道密文后明文的不确定性」拼接而成。
- **第三步，移项得 $H(M \mid C) = H(M, C) - H(C)$**：明文疑义度 = 联合熵 − 密文熵。直觉是：知道密文后明文剩多少不确定，就是「两者联合的信息量」减去「密文单独已经提供的信息量」。
- **第四步，代入密码学对象算边界**：密钥 $K$ 与明文 $M$ 合起来决定了密文 $C$（因为 $C = E_K(M)$），所以 $H(M, C) = H(M, K)$——密文不含超出「明文 + 密钥」的信息。又因为 $H(K) \ge H(K, M) - H(M)$ 且密钥与明文通常独立（$H(K, M) = H(K) + H(M)$），整理可得

$$
H(M \mid C) \ge H(M) - H(C) + H(K) \;\Rightarrow\; H(M \mid C) \ge H(M) + H(K) - H(C)
$$

这条不等式揭示了一个深刻的权衡：**密钥的熵 $H(K)$ 是对抗「密文泄露 $H(C)$」的弹药。** 若 $H(K)$ 很大而 $H(C)$ 相对小，明文疑义度就能逼近甚至达到 $H(M)$——保密性越好。若 $H(K)$ 很小（密钥熵不足），$H(M \mid C)$ 就会显著低于 $H(M)$，攻击者从密文里获得了大量明文信息。**维吉尼亚密码的密钥熵太小，正是它被卡西斯基攻破的信息论解释。**

## 5 完善保密性的雏形：当 H(M|C) = H(M)

有了疑义度，「彻底保密」第一次有了严格定义。香农说：一个保密系统是**完善保密（perfect secrecy）**的，当且仅当

$$
H(M \mid C) = H(M)
$$

即：**给定密文后，关于明文的不确定性保持不变——密文没有泄露任何关于明文的信息。** 这是「无条件安全」的数学表述：无论攻击者有多强的计算能力，都从密文里学不到明文的任何信息。

从这个定义出发，香农证明了一条令整个密码学界肃然起敬的定理：

$$
\boxed{\text{完善保密性} \Rightarrow H(K) \ge H(M)}
$$

也就是说，**要做到完美保密，密钥的熵至少要达到明文的熵**；若密钥等概率分布，则等价于密钥长度不小于明文长度 $|K| \ge |M|$。这条定理的证明思路简洁而深刻：若 $H(K) < H(M)$，则密钥无法「覆盖」明文的全部不确定性，必然存在某些密文能让攻击者排除掉一批明文——$H(M \mid C) < H(M)$，完善保密性被破坏。<span class="marginnote">换个角度想：密文 $C$ 的熵至多等于 $H(M, K)$；若 $H(K) < H(M)$，那么 $H(M, C) = H(M) + H(K) < 2H(M)$，再结合 $H(M \mid C) = H(M, C) - H(C) \le H(M, C) - H(M)$ 可推出 $H(M \mid C) < H(M)$，与完善保密矛盾。这条「熵的边界」是下一节一次一密安全性证明的序章。</span>

**辨析｜易错点：** 「完善保密」与「计算安全」是两个层次不同的概念，初学者极易混淆。**完善保密**是香农意义上的**无条件安全**：不假设攻击者的算力，只要求 $H(M \mid C) = H(M)$。**计算安全**则不同：它承认密文会泄露信息，但声称「在合理算力下，把这些信息变成明文需要不可行的时间」（比如 RSA、AES 的安全都建立在这个假设上）。完善保密听起来更美，代价却极其昂贵——上面那条定理已经预告：**它要求密钥至少和明文一样长，且只能一次性使用**。这个代价直接导向下一节的一次一密。

## 6 Python 实战：亲手量一量熵与疑义度

把熵、条件熵和疑义度写成代码，你就能对一个具体密码测量它的信息泄漏：

```python
import math

def entropy(probs):
    """熵：H = -Σ p·log2 p（比特）。"""
    return -sum(p * math.log2(p) for p in probs if p > 0)

def cond_entropy(joint):
    """条件熵 H(M|C) = -Σ p(m,c)·log2 p(m|c)，joint 是 {(m, c): p} 的字典。"""
    pc = {}
    for (m, c), p in joint.items():
        pc[c] = pc.get(c, 0.0) + p
    return sum(p * math.log2(pc[c] / p)
               for (m, c), p in joint.items() if p > 0)

# 1) 均匀 26 字母的熵：每个字母 1/26
print("H(均匀26字母) =", round(entropy([1/26] * 26), 2), "比特")      # ≈ 4.70

# 2) 单表替换的密钥熵：密钥是 26! 个置换之一
print("H(单表替换密钥) =", round(math.log2(math.factorial(26)), 2), "比特")  # ≈ 88.4

# 3) 疑义度 H(M|C)：极简例子——密钥决定后，密文唯一确定明文
joint = {("a", "0"): 0.5, ("b", "1"): 0.5}
print("H(M|C) =", round(cond_entropy(joint), 2), "比特")             # 0：知道密文即知明文
```

第一组输出会展示那把尺子的威力：均匀 26 键的熵只有约 4.70 比特，而**单表替换的密钥空间虽是 $26!$，其熵 $H(K) = \log_2 26! \approx 88.4$ 比特**——这个数字印证了《单表替换密码》里「密钥空间巨大却仍被攻破」的悖论：密钥熵很大，但密文 $H(C)$ 也保留了明文的全部统计结构，$H(M \mid C)$ 照样被频率攻击压到接近 0。<span class="marginnote">这正是香农理论的清醒之处：<strong>大密钥空间只是必要条件，不是充分条件</strong>。单表替换的 $H(K)$ 高达 88 比特，完善保密性要求却不满足（因为密文分布保留了明文的统计冗余），所以它连「接近完善保密」都谈不上。</span>

## 7 历史与前瞻：从熵到一次一密

香农 1949 年的这篇论文，被公认为现代密码学的奠基之作。它一次性贡献了三件影响深远的东西：**用熵为信息与不确定性立尺**，**用疑义度定义并刻画完善保密性**，以及——常被低估的——**混淆与扩散（confusion and diffusion）原则**与「乘积密码」思想。后者直接催生了 Feistel 网络与现代分组密码，我们将在第三篇分组密码里反复用到；前者则把「密码要多少密钥」彻底说清：**完善保密需要 $H(K) \ge H(M)$，而任何有限长度的密钥都无法满足——除非密钥不短于明文且只用一个明文。**

顺着香农的边界走下去，只剩两条路。一条是「接受不完美，靠计算安全过日子」——今天世界上 99% 的加密都走这条路：用短得多的密钥（如 256 位），换取「算力上不可行」的保密。另一条是「追求完美，付信息论的代价」——这就是**一次一密（One-Time Pad）**：密钥与明文等长、完全随机、只用一个明文，从而精确达到 $H(M \mid C) = H(M)$。它是人类已知唯一被数学证明无条件安全的密码，也恰恰是香农定理的正面例证。

## 8 小结

- **熵**：$H(X) = -\sum p(x) \log_2 p(x)$，度量不确定性；等概率时熵最大，分布越偏斜熵越低。
- **条件熵 / 疑义度**：$H(X \mid Y)$ 是「已知 $Y$ 后 $X$ 还剩的不确定性」；用在密码学上就是明文疑义度 $H(M \mid C)$ 与密钥疑义度 $H(K \mid C)$。
- **链式法则**：$H(X \mid Y) = H(X, Y) - H(Y)$，是把疑义度化成可计算量的一把钥匙。
- **完善保密性**：$H(M \mid C) = H(M)$，即密文不泄露任何明文信息，是无条件安全的数学定义。
- **香农定理**：完善保密性 $\Rightarrow H(K) \ge H(M)$（密钥熵不小于明文熵），预告了一次一密「等长密钥、一次性使用」的必然性。
- 香农的另一份遗产——**混淆与扩散**、乘积密码——为第三篇分组密码的轮结构埋下了伏笔。

在下一节，我们将把「完善保密性」的定义与判定推到底：**它到底是不是一个可操作的标准？什么样的密码能证明自己完善保密？** 然后，就是那枚传说中的「完美密码」——一次一密。
