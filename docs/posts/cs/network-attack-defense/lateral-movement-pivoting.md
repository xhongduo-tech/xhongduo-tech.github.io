## 为什么从横向移动开始

单机提权之后，攻击者站在「一台内网机器」上。但**一台机器的价值有限，整个内网才是目标**——数据库、文件服务器、域控，全都藏在攻击者面前这片「不可直接访问」的网络里。

**横向移动（lateral movement）**：从已控制的机器出发，以它为跳板，访问内网中其他机器、搜集更多凭证、逐步逼近核心资产（尤其是**域控制器**）。而要「看见并打到」内网深处，还需要**内网穿透（pivoting）**——利用已控机器把攻击者的流量转进内网。

本节拆解横向移动与内网穿透两大主题：从**凭证窃取与哈希传递**到**代理与隧道**，再到**域渗透**这条内网攻防的主线。这也是后渗透阶段的「收网」环节。

<span class="marginnote">横向移动与提权的区别：提权是「在同一台机器上提高权限」，横向是「从一台机器跳到另一台机器」。内网渗透的核心矛盾是<strong>「隔离」</strong>——DMZ、网段隔离、防火墙让外网攻击者够不到核心资产，而横向移动就是「借已控机器越过隔离」的路线图。红队经典叙事「边界突破 → 横向移动 → 拿下域控」正对应本专题第15、17、18篇。</span>

## 1 横向移动的第一步：凭证为王

横向移动几乎总是围绕**凭证（credential）**展开——因为「从这台跳到那台」，最朴素的方式就是「用拿到的账号口令/哈希直接登录那台」。

**凭证来源**：内存里的口令与哈希（`mimikatz sekurlsa::logonpasswords` 抓内存中登录凭证）、`SAM` 与 `NTDS.dit`（本地与域控的哈希库）、配置文件里的明文口令、历史命令。

**核心要点｜凭证在横向移动中的用法：**

| 凭证类型 | 怎么用 | 工具 |
| --- | --- | --- |
| 明文口令 | 远程登录复用 | psexec、ssh、rdp |
| NTLM 哈希 | 哈希传递（PtH） | crackmapexec、impacket |
| Kerberos 票据 | 票据传递（PtT） | mimikatz、Rubeus |
| 域凭证 | 批量扫内网 | crackmapexec 批量 |

**哈希传递（Pass-the-Hash，PtH）**是内网横向的王牌：Windows 认证接受 **NTLM 哈希**而非明文口令——抓到哈希就能直接用它登录其他机器（`crackmapexec smb 192.168.1.0/24 -u admin -H <哈希>` 批量尝试网段内所有主机）。

**意味着一个管理员的哈希 = 内网里能登录的一大批机器**。

<span class="marginnote">为什么 PtH 能成立？因为 Windows 的 NTLM 挑战-响应机制里，「正确响应」由哈希直接算出——<strong>哈希本身就是一种可用的「口令等价物」</strong>。这带来一个残酷现实：只要域内一台机器上抓到管理员哈希，攻击者就能横向登录其他机器，而不用破解任何一个明文口令。蓝队对策：限制本地管理员在不同机器间的口令复用、启用 Credential Guard、监控异常的 PtH 登录（第27篇蓝队防御）。</span>

## 2 内网穿透：代理与隧道

攻击者的机器在**外网**，而目标内网是**隔离网络**——攻击者无法直接访问内网中的机器，于是用已控的内网机器做「中转站」，把攻击者的流量转进内网，这就是**内网穿透（pivoting）**。

**端口转发（port forwarding）**：把已控机器上的某个端口转到一个内网目标端口。`ssh -L` 本地转发、`ssh -R` 远程转发，或 `chisel`/`frp` 等工具。最简单也最常用。

**SOCKS 代理（SOCKS proxy）**：在已控机器上开一个 SOCKS 代理，攻击者**整个工具链（Nmap、浏览器、Burp）都通过这个代理访问内网**——一次建立，全工具可用。工具：`ssh -D 1080`、`chisel`、`proxychains`（把任意工具强制走代理）。

**隧道（tunnel）**：把流量封装进「看似正常」的协议里穿过防火墙——**HTTP 隧道**、**DNS 隧道**（把数据编码进 DNS 查询）、**ICMP 隧道**。用于防火墙只放行某些协议的场景，隐蔽性优先。

**核心对比表｜三类穿透方式：**

| 方式 | 原理 | 适用 | 工具 |
| --- | --- | --- | --- |
| 端口转发 | 单端口转内网 | 访问单个服务 | ssh、chisel |
| SOCKS 代理 | 全流量走代理 | 多工具访问内网 | proxychains、chisel |
| 隧道 | 协议封装穿越 | 穿防火墙 | dns2tcp、icmpsh |

<span class="marginnote">`proxychains` 的用法：先在一台已控内网机器上 `ssh -D 1080` 建 SOCKS 代理，再 `proxychains nmap -sT 10.10.10.0/24` 让 Nmap 透过代理扫内网——攻击者的流量先到已控机器、再进内网。<strong>注意：通过代理的扫描必须用 `-sT`（连接扫描），SYN 扫描的原始包无法穿过代理</strong>，这也是「扫描经代理」的常识。</span>

## 3 域渗透：横向移动的终点

**域（domain）**是 Windows 内网的组织形式：一台**域控制器（DC）**集中管理所有成员的账号与策略。内网渗透的最高目标几乎都是**拿下域控制器**——拿到 DC 就等于拿到整个域的账户数据库（`NTDS.dit`）。域渗透的经典链路：

**侦察域**：`whoami /all`、`net user`、`net group "Domain Admins"` 摸清域结构；`BloodHound` 把域内的权限关系画成图，找出攻击路径。

**攻击路径**：横向移动中积累的凭证，配合**Kerberoasting**（破解域内服务账户的 SPN 哈希）、**AS-REP Roasting**（破解未预认证用户的哈希）、**黄金票据/白银票据**（伪造域控签发的 Kerberos 票据），逐步逼近域管权限。

**拿下 DC**：域管权限到手，`secretsdump -ntds` 导出整个域的用户哈希，横向移动「毕业」。

**核心要点｜域渗透的关键概念：**

| 概念 | 含义 | 攻击意义 |
| --- | --- | --- |
| 域控制器 DC | 集中管理账户 | 拿下即拿全域 |
| NTDS.dit | 域账户哈希库 | 导出即全域哈希 |
| Kerberoasting | 破解 SPN 哈希 | 借服务账户提权 |
| 黄金票据 | 伪造 TGT 票据 | 长期全域权限 |

<span class="marginnote">`BloodHound`（配合 SharpHound 采集）是域渗透的「地图神器」：它把域内用户、组、机器、ACL、会话关系构建成图数据库，用查询找出「从当前用户到域管」的最短攻击路径。红队用它规划路线，蓝队（第27篇）反过来用它加固——<strong>图论思维在攻防里成了共同的通用语言</strong>。</span>

## 4 横向移动的检测与防护

横向移动是内网攻防对抗最激烈的一环——蓝队的大部分检测规则都针对它。理解了红队怎么打，就理解了蓝队怎么防。

**检测信号**：Windows 安全日志里，**4624（登录成功）与 4625（登录失败）**的批量异常、**4688（进程创建）**里的远程工具特征、同一账号在短时间内登录多台机器的「跳跃」模式——这些就是 PtH 与横向移动的脚印。EDR 与 SIEM（第27篇）把这些信号关联成告警。

**防护手段**：**网络分段**（把高价值网段隔离）、**本地管理员口令去重**（LAPS 让每台机器口令不同，断了 PtH 的「一把钥匙开多把锁」）、**最小权限**（普通用户不挂管理员组）、**Credential Guard**（隔离内存中的凭证，呼应第17篇 mimikatz）。

**核心对比表｜横向移动手法与检测：**

| 手法 | 检测信号 | 防护 |
| --- | --- | --- |
| 哈希传递 | 异常 4624/4625 | LAPS、Credential Guard |
| 远程登录 | 批量 4624 | 日志关联分析 |
| C2 隧道 | 异常外连 | 出站流量管控 |
| 凭证抓取 | 内存访问异常 | 凭据隔离 |

<span class="marginnote">红蓝的攻防循环在这里最清晰：红队用 PtH 横向（第17篇），蓝队就部署 LAPS 与 Credential Guard 让哈希「用不了、抓不到」；红队改打 WMI/计划任务横向，蓝队又给这些异常进程加规则。<strong>攻防没有终点，只有不断的迭代</strong>——这也正是红蓝对抗（第26篇）存在的意义。</span>

## 5 小结

- **横向移动**从已控机器出发，借凭证跳到内网其他机器，逐步逼近核心资产。
- **凭证为王**：明文口令、NTLM 哈希、Kerberos 票据都是横向的通行证；**哈希传递**让哈希直接当口令用。
- **内网穿透**解决「够不到内网」：端口转发、SOCKS 代理（proxychains）、协议隧道各司其职。
- **域渗透**是内网攻防的终点：侦察域结构（BloodHound）→ Kerberoasting/票据伪造 → 拿下 DC 导出全域哈希。
- 红队经典链路：**边界突破 → 提权 → 横向移动 → 拿下域控**。
- 横向移动是攻防对抗最激烈的一环——蓝队的横向移动检测（第27篇）正是针对这些手法。
