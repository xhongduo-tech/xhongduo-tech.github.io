## 为什么从蓝队防御开始

上一节我们建立了红蓝对抗的框架：红队攻击、蓝队防守，而蓝队的核心是**可见性**——本节的 **SIEM（Security Information and Event Management，安全信息与事件管理）**就是把「可见性」落地的工程体系。为什么单独成篇？

因为「发现攻击」是蓝队的第一要务，而它的实现依赖一整套「收集 → 分析 → 告警 → 响应」的基础设施：**日志分析**是素材，**SIEM** 是平台，**安全加固**是前置的「少留口子」。

本节讲清这三块：日志里看什么、SIEM 怎么工作、加固从哪些方面做——这是蓝队从「有想法」到「能干活」的关键一步。

<span class="marginnote">蓝队与红队（第15–19篇）的关系：红队研究的每一种攻击，蓝队都要在日志里「认得出来」。本专题前篇讲的所有技术（横向移动、持久化、隧道、WebShell），在本节都变成蓝队要检测的「告警特征」——<strong>把攻防知识翻个面，就是蓝队知识</strong>。这也是本专题「攻防一体」设计的用意。</span>

## 1 日志分析：安全运营的第一手素材

**日志（log）**是系统、应用、网络设备记录的事件流水。蓝队的安全分析**建立在日志之上**——没有日志，一切检测都是空谈。**收集哪些日志**决定你能看到什么：

**操作系统日志**。Windows 的**安全日志**（4624 登录成功、4625 登录失败、4688 进程创建、4672 特权分配）、Linux 的 `auth.log`/`secure`（登录、sudo）、`syslog`（系统事件）。

**登录事件与进程创建**是检测横向移动、提权、持久化的主力。

**应用与 Web 日志**。Web 服务器访问日志（`access.log`——看异常 URL、目录爆破、SQL 注入特征）、应用日志（业务异常、认证失败）。**Web 日志**是检测 WebShell、SQLi、扫描的首选。

**网络与安全设备日志**。防火墙、IDS/IPS、路由器的连接与告警记录——看端口扫描、异常连接、外带流量。

**核心要点｜必看的安全日志清单：**

| 日志 | 平台 | 检测什么 |
| --- | --- | --- |
| 登录事件 | Windows/Linux | 撞库、横向移动 |
| 进程创建 | Windows | 恶意程序、提权 |
| Web 访问 | 服务器 | 扫描、注入、WebShell |
| 防火墙 | 网络设备 | 扫描、外带 |

<span class="marginnote">日志分析的第一原则是<strong>「先有基线，才有异常」</strong>：不了解「正常的长什么样」，就无法判断「什么算异常」。所以蓝队要定期收集<strong>正常时期的日志基线</strong>（常见 IP、登录时段、进程列表）。另一个常识：<strong>本地日志可被攻击者清理（第19篇痕迹清理），所以日志必须「异地留存 + 防篡改」</strong>——这也是 SIEM 存在的理由之一。</span>

## 2 SIEM：把日志变成告警

**SIEM（安全信息与事件管理）**是把分散在各处的日志**集中收集、关联分析、实时告警**的平台。它把蓝队从「一台台机器翻日志」升级为「一个平台看全局」。

**SIEM 的四大功能**：

**日志收集（Log Management）**。通过 Agent 或 Syslog 把全网的日志汇集到中央——解决「日志在哪」。

**标准化与关联（Correlation）**。把不同格式的日志统一成标准字段，再按规则做**关联分析**——「A 机登录失败 100 次 + 5 分钟后 B 机登录成功」这条跨机器关联，正是横向移动的特征。

**告警（Alerting）**。命中规则即产生告警，推送给安全人员。

**检索与报表**。事后调查时全文检索、溯源还原。

**核心要点｜SIEM 检测规则的本质：**
$$
\text{告警} = \text{日志} \land \text{关联规则} \land \text{时间窗口}
$$
一条关联规则就是「在某个时间窗口内，若干条日志同时满足某些条件」。例如「同源 IP 在 5 分钟内登录失败超过 50 次」→ 撞库告警；「非管理员账号创建新服务」→ 持久化告警（呼应第19篇）。**规则写得好不好，直接决定 SIEM 的价值**——规则太松则噪音淹没告警，太紧则漏报。

**核心要点｜主流 SIEM：**

| SIEM | 授权 | 特点 |
| --- | --- | --- |
| Splunk | 商业 | 检索强、生态全 |
| Elastic Stack（ELK） | 开源 | 灵活、社区大 |
| Wazuh | 开源 | 与 EDR 一体 |
| 奇安信/绿盟等 | 国产商业 | 本地化合规 |

<span class="marginnote">SIEM 的现实挑战是<strong>告警疲劳（alert fatigue）</strong>：海量规则产生海量告警，安全人员被噪音淹没，真正的攻击反而被漏过。应对思路：<strong>先建基础规则（登录、进程、Web 异常），逐步精简</strong>；配合威胁情报、白名单与优先级分级。现代进阶方向是 <strong>SOAR（安全编排自动化响应）</strong>——把告警后的处置动作自动化，进一步压缩 MTTR（呼应第26篇的指标）。</span>

## 3 安全加固：让攻击无路可走

检测很重要，但**防御加固（hardening）**是把攻击面做小的前置工作——攻击者无处下手，检测压力也小。安全加固按「纵深防御」分层展开：

**系统加固**。最小化安装（删多余服务）、补丁管理（及时打补丁）、最小权限（普通用户而非 root）、加固基线（CIS Benchmarks 是权威基线标准）、SSH 禁 root 登录、禁用危险服务（如 SMBv1）。

**网络加固**。网络分段（内网隔离、DMZ）、防火墙最小放行（默认拒绝）、**关键端口最小暴露**（把 SSH/RDP 藏进 VPN 后面）、监控关键网段。

**应用加固**。WAF（Web 应用防火墙）拦截注入与扫描、代码层面的输入校验（呼应第7–14篇的正确防线）、安全配置（禁用目录列表、隐藏版本号）。

**核心对比表｜三层加固：**

| 层次 | 手段 | 对抗的攻击 |
| --- | --- | --- |
| 系统加固 | 补丁、最小权限、基线 | 漏洞利用、提权 |
| 网络加固 | 分段、防火墙、VPN | 扫描、横向移动 |
| 应用加固 | WAF、输入校验 | 注入、WebShell |

**辨析｜易错点：** 初学者常把「加固」等同于「装个防火墙/杀毒软件」。真正的加固是**「减少攻击面 + 提升检测可见性」的组合**——补丁让漏洞消失、最小权限让提权困难、日志与 SIEM 让攻击可见。单靠一个工具是「点防御」，配合层层加固才是「纵深防御」。

这正呼应第26篇「检测 > 预防」的理念：加固是预防，SIEM 是检测，两者缺一不可。

<span class="marginnote">加固的行业参照：<strong>CIS Benchmarks</strong> 给出各系统/应用的加固基线清单，是蓝队做系统加固的标准参考；<strong>等保 2.0</strong>（中国网络安全等级保护）把加固要求制度化。蓝队做加固时，<strong>「最小权限 + 默认拒绝 + 全面审计」</strong>是三条总原则——攻击面小了、权限低了、动作都有记录，攻击自然无处遁形。</span>

## 4 蓝队实战：一条检测规则从写到告警

用一个完整示例，把「日志 → 规则 → 告警」的链路走通：

**场景**：检测「同源 IP 的横向移动尝试」——攻击者在短时间内用同一组口令尝试登录内网多台机器（呼应第18篇）。

**写规则**：在 SIEM 里配置关联规则——`5 分钟内，同一来源 IP 对不同目标机的登录失败（4625）次数 ≥ 10`，命中即告警。这条规则把一个「尝试性攻击」变成一条可操作的告警。

**调优**：规则上线后要观察误报——办公网里域控批量验证可能误触发，通过白名单（合法 IP）、调阈值、加「目标含敏感服务器」条件来收敛。

**核心要点｜一条检测规则的要素：**

| 要素 | 本示例 |
| --- | --- |
| 事件源 | Windows 安全日志 4625 |
| 关联维度 | 源 IP × 目标机 |
| 时间窗 | 5 分钟 |
| 阈值 | 10 次以上 |
| 动作 | 告警 + 通知 |

<span class="marginnote">「写规则」是蓝队最日常也最见功力的活：<strong>规则太粗则告警噪音淹没一切，太细则漏报真实攻击</strong>。成熟的蓝队会建立「规则生命周期」——上线、观察误报率、调优、退役。这个过程与红队「试漏洞」的过程一样，是攻防双方每天都在迭代的核心技能。</span>

## 5 小结

- **蓝队防御**的核心是可见性：**日志**是素材、**SIEM** 是平台、**加固**是前置。
- **日志分析**看四类：登录事件、进程创建、Web 访问、防火墙——先有基线，才有异常。
- **SIEM** 把全网日志集中收集并关联分析，用**关联规则**把攻击特征变成告警（`日志 ∧ 规则 ∧ 时间窗口`）。
- 告警的敌人是**告警疲劳**：规则要精简、分级、配威胁情报；进阶方向是 SOAR 自动化响应。
- **安全加固**按纵深分层：系统（补丁/最小权限/基线）、网络（分段/防火墙/VPN）、应用（WAF/输入校验）。
- 攻防一体：红队的每招，蓝队都应有对应的告警特征——把前篇的攻防知识翻个面就是蓝队知识。
