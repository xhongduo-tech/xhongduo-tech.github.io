## 为什么从二叉树开始

链表只有一条路，树则有了分岔。**二叉树（binary tree）** 是每个节点最多两个孩子的结构，它既是数据组织方式（堆、BST、哈夫曼树都是二叉树），也是**递归思想的最佳练习场**——每个子树都是「更小的同构问题」，恰好命中我们上一章学的递归。<span class="marginnote">树在后续图论里也是主角：树是「无环连通图」，很多图算法（如最小生成树）的结论都从树的性质出发。先在地基上把二叉树练透，图论会轻松一大截。</span>这一章，我们掌握四种遍历、递归分治的套路，以及「由遍历重建二叉树」这类经典问题。

## 1 二叉树的定义与表示

**二叉树（binary tree）**：一棵空树，或由一个根节点和左右两棵不相交的二叉树组成——注意这个定义本身就是递归的。每个节点用结构体表示：

```cpp
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
```

几个关键概念：**根节点（root）**、**叶子节点（leaf）**（无孩子）、**高度（height）**（从根到最深叶子的边数）、**深度（depth）**（从根到某节点的边数）。

**重点：满二叉树与完全二叉树。** 满二叉树每层都满；完全二叉树除最后一层外都满、最后一层靠左。完全二叉树「用数组就能存」的性质，我们在优先队列的堆里已经见过——下标 $i$ 的孩子是 $2i+1$、$2i+2$。

## 2 四种遍历：先序、中序、后序、层序

遍历是二叉树的第一基本功。递归实现时，**访问根的位置**决定了遍历顺序：

**先序遍历（preorder）**：根 → 左 → 右。**中序遍历（inorder）**：左 → 根 → 右。**后序遍历（postorder）**：左 → 右 → 根。

```cpp
void preorder(TreeNode* p) {
    if (!p) return;
    visit(p);          // 访问根
    preorder(p->left); // 再左
    preorder(p->right); // 再右
}
```

三种遍历递归实现只差一行 `visit` 的位置，却是三种完全不同的顺序。<span class="marginnote">记忆口诀：名字里「先/中/后」说的是<strong>根</strong>在什么时候被访问。「先序」根最先，「中序」根在中间，「后序」根最后。BST 的中序遍历结果恰好是升序序列——这是《排序应用》和后续 BST 专题的重要性质。</span>

**层序遍历（level order）** 则是「一层一层从上到下、从左到右」访问，天然用队列实现：根入队，出队时把孩子入队，循环到队列为空。这正是 BFS 在树上的形态。

**辨析｜易错点：** 层序遍历返回的常常是「按层分组的二维数组」，需要每层开始时记录当前队列长度，只处理这么多个节点——否则会串层。

## 3 递归分治：树上的统一套路

几乎所有「树上计算」问题，都能套同一个递归分治模板：**向左右子树要答案，再在根上合并**。

以「最大深度」为例：

```cpp
int maxDepth(TreeNode* p) {
    if (!p) return 0;                                  // 基线：空树深度 0
    int L = maxDepth(p->left);                         // 左子树深度
    int R = maxDepth(p->right);                        // 右子树深度
    return max(L, R) + 1;                              // 合并：本层 +1
}
```

**核心概念：递归三问。** 每个树上的递归问题都可以问自己三句话：**这个函数返回什么？** 基线条件是什么？** 根节点如何利用左右子树的结果？三问答完，代码基本成型。这个模板覆盖了最大深度、节点个数、对称判断、路径和等一大片题目。

**辨析｜易错点：** 「最大深度」里每个节点只算一次，复杂度 $O(n)$；但「求某节点路径和」若对每个节点都递归遍历整棵子树，会变成 $O(n^2)$。树题最容易踩的坑就是「递归套递归」导致复杂度爆炸——能用一次后序遍历完成的，就不要对每个节点再开一次遍历。

## 4 由遍历序列重建二叉树

知道先序 + 中序（或后序 + 中序），就能唯一重建一棵二叉树。原理是：**先序第一个是根，中序用根把左右子树切开**，再递归处理两侧。

```cpp
TreeNode* build(vector<int>& pre, int pl, int pr,
                vector<int>& in,  int il, int ir) {
    if (pl > pr) return nullptr;
    TreeNode* root = new TreeNode(pre[pl]);
    int pos = il;
    while (in[pos] != pre[pl]) pos++;      // 在中序里找根
    int lsz = pos - il;                     // 左子树大小
    root->left  = build(pre, pl+1, pl+lsz, in, il, pos-1);
    root->right = build(pre, pl+lsz+1, pr, in, pos+1, ir);
    return root;
}
```

**重点：为什么必须有中序？** 只有先序 + 后序时，若某节点只有一个孩子，无法确定是左还是右——重建会不唯一。中序的「根在中间、左子树在左、右子树在右」提供了这种区分力。<span class="marginnote">上面的代码里，`while` 在中序里线性找根，总复杂度 $O(n^2)$；改用「值 → 下标」的哈希表预存后，变成 $O(n)$。凡是「查位置」的地方，都可以考虑哈希表加速——这是《数组与哈希表基础》思想的复用。</span>

## 5 公式解析：满二叉树的高度与节点数

二叉树的很多结论可以「算出来」。高度为 $h$ 的**满二叉树**，各层节点数构成等比数列：

$$
1 + 2 + 4 + \cdots + 2^{h} = 2^{h+1} - 1
$$

- **第一步，层数到节点数**：第 $k$ 层（根为第 0 层）有 $2^k$ 个节点。
- **第二步，等比求和**：$S = \sum_{k=0}^{h} 2^k = 2^{h+1} - 1$。
- **第三步，反推高度**：反之，$n$ 个节点的完全二叉树高度约为 $\lfloor \log_2 n \rfloor$——这就是堆、BST 等平衡结构操作 $O(\log n)$ 的根源。

**重点：对数高度是树结构的红利。** 只要树是平衡的（高度 $\approx \log n$），沿着树走一步就排除掉一半节点，查询、插入都是 $O(\log n)$。反之，一棵退化成链的树，高度 $= n$，所有操作退化为 $O(n)$——这正是后续要追求「平衡」的原因。

## 6 小结

- 二叉树是递归定义的结构：空树或根 + 左右子树；每个节点两个孩子。
- 先序/中序/后序的区别只在「根何时访问」，递归实现只差一行。
- 层序遍历用队列，是 BFS 在树上的形态。
- 树上的递归分治三问：返回什么、基线、如何合并；警惕递归套递归的复杂度爆炸。
- 先序（后序）+ 中序可重建二叉树，中序提供左右划分；哈希表加速查找。
- 满二叉树节点数 $2^{h+1}-1$，平衡树高度 $O(\log n)$
