## 为什么从图的表示与遍历开始

上一章的树只有「上下级」，真实世界的关系要复杂得多——朋友网络、地铁线路、网页链接，任何「谁与谁相连」的问题都是一张**图（graph）**。图论是算法竞赛里最大的一块版图，而一切图算法的起点都是两件事：**怎么把图存进计算机**（表示），**怎么把图走遍**（遍历）。DFS 与 BFS 是遍历的两种基本策略，也是后续最短路、拓扑排序、连通分量等一切图算法的骨架。这一章，我们把地基打牢。

## 1 图的基本概念

**图（graph）** 由**顶点（vertex）** 集合 $V$ 和**边（edge）** 集合 $E$ 组成，记作 $G = (V, E)$。边可以有权重（带权图）也可以没有；边有方向的叫**有向图**，没有的叫**无向图**。<span class="marginnote">竞赛里习惯用 $n$ 表示顶点数、$m$ 表示边数。数据范围里出现的「$n \le 10^5$，$m \le 2\times10^5$」就是在告诉你图的规模——它直接决定该用 $O(n^2)$ 还是 $O(n+m)$ 的算法。</span>

**度（degree）** 是顶点的邻边数。无向图里所有顶点的度之和等于 $2m$（每条边贡献两个度），这个「握手定理」是很多证明的出发点。有向图还分**入度**与**出度**。

## 2 图的两种表示：邻接矩阵与邻接表

把图存进计算机，主流有两种方式：

**邻接矩阵（adjacency matrix）**：开一个 $n \times n$ 的数组 `g[i][j]`，`g[i][j] = 1` 表示 $i$ 到 $j$ 有边。查询任意两点是否相邻是 $O(1)$，但空间是 $O(n^2)$——$n$ 到 $10^5$ 时就存不下了。

**邻接表（adjacency list）**：每个顶点开一个列表，存它的邻居。空间 $O(n+m)$，遍历一个顶点的所有邻居只需扫它的列表，但判断两点是否相邻要扫描列表。

```cpp
vector<vector<int>> g(n);     // 邻接表
for (int i = 0; i < m; i++) {
    int u, v; cin >> u >> v;
    g[u].push_back(v);
    g[v].push_back(u);        // 无向图要加两条
}
```

![图的三视图：原图、邻接矩阵与邻接表](/images/competitive-programming/graph-representation-dfs-bfs-1.svg)

**重点：竞赛几乎都用邻接表。** $n$ 动辄 $10^5$，邻接矩阵 $10^{10}$ 的内存直接爆掉；邻接表只存真实存在的边，空间线性。判断「稠密图用矩阵，稀疏图用链表」——竞赛数据几乎都是稀疏图，所以邻接表是默认选项。<span class="marginnote">带权图只需把邻接表里的元素从「邻居编号」变成「邻居编号 + 边权」的结构体，或存进 `pair<int,int>`。`vector<vector<pair<int,int>>>` 是带权图的竞赛标配写法。</span>

## 3 深度优先搜索 DFS

**深度优先搜索（DFS，Depth-First Search）** 像走迷宫时「一条路走到黑，走不通就回头」——用递归（或显式栈）实现。从起点出发，访问一个顶点后立刻深入它的第一个邻居，递归地走到底再回溯。

```cpp
vector<int> vis(n, 0);   // 访问标记
void dfs(int u) {
    vis[u] = 1;                          // 标记已访问
    for (int v : g[u]) {
        if (!vis[v]) dfs(v);             // 深入未访问的邻居
    }
}
```

**核心概念：visited 数组防死循环。** 图可能有环，不加访问标记，DFS 会在环里无限打转。`vis` 数组是图遍历的铁律——每个顶点只处理一次。

**辨析｜易错点：** 递归 DFS 在 $n$ 很大（如 $10^5$）时可能**栈溢出**，因为每层递归都压栈。解决方法是换成**显式栈**模拟，或用 C++ 的 `std::stack` 手写迭代版。竞赛里「递归爆栈换迭代」是高频操作，值得提前练熟。

## 4 广度优先搜索 BFS

**广度优先搜索（BFS，Breadth-First Search）** 则像水面泛起的涟漪——从起点出发，先访问所有一步可达的顶点，再访问两步可达的……逐层推进。它用**队列**实现：

```cpp
queue<int> q;
vector<int> dist(n, -1);   // -1 表示未访问
dist[s] = 0; q.push(s);
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) {
        if (dist[v] == -1) {
            dist[v] = dist[u] + 1;   // 记录层数（最短步数）
            q.push(v);
        }
    }
}
```

**重点：BFS 首次访问即最短路。** 在**无权图**里，BFS 按层扩展，第一次到达某顶点时走的步数就是最短距离——`dist` 数组天然记录了这个信息。这正是 BFS 在「迷宫最短步数」「社交网络最少几度人脉」里无可替代的原因。

## 5 公式解析：遍历的复杂度 O(n + m)

DFS 与 BFS 的复杂度可以精确算出。设图有 $n$ 个顶点、$m$ 条边：

$$
T(n, m) = \underbrace{n}_{\text{每个顶点访问一次}} + \underbrace{m}_{\text{每条边看一次}}
= O(n + m)
$$

- **第一步，访问顶点**：`vis`/`dist` 标记保证每个顶点至多被「发现」一次，总代价 $O(n)$。
- **第二步，扫描边**：对每个顶点，要遍历它的邻接表，全部加起来恰好是 $2m$（无向图每条边在两端各出现一次），总代价 $O(m)$。
- **第三步，相加**：两笔账加起来，就是 $O(n + m)$——它只与图的真实规模成正比，是最理想的「线性」遍历。

**重点：`O(n+m)` 是图算法的黄金复杂度。** 判断一个图算法快不快，就看它是不是 $O(n+m)$：是，说明「每个顶点每条边都只被摸一遍」，基本到极限了。<span class="marginnote">对比邻接矩阵实现：访问顶点仍 $O(n)$，但「看邻居」要扫整行，总代价变成 $O(n^2)$。同样的算法，换一种表示，复杂度差了一个量级——选对数据结构常常比优化算法本身更关键。</span>

## 6 遍历的应用：连通分量与二分图

两个最经典的遍历应用：

**连通分量（connected component）**：反复调用 DFS/BFS，每启动一次就「点亮」一个连通块，启动次数就是连通分量数。扩展到「找环」「判断图是否连通」，都是同一套路。

**二分图判定（bipartite check）**：给顶点染两种颜色，要求相邻顶点颜色不同。DFS 时相邻顶点若颜色相同则不是二分图——整个判定一次遍历完成，$O(n+m)$。

```cpp
bool ok = true;
void color(int u, int c) {
    col[u] = c;
    for (int v : g[u]) {
        if (col[v] == -1) color(v, c ^ 1);
        else if (col[v] == c) ok = false;  // 相邻同色，非二分图
    }
}
```

**核心概念：染色即分类。** 二分图的判定本质是「能不能把顶点分成两堆，使得所有边都在两堆之间」——后续的匹配问题、网络流问题都以它为基础，先在这里种下概念。

## 7 小结

- 图 = 顶点 + 边；$n$ 个顶点、$m$ 条边；有向/无向、带权/不带权。
- 邻接矩阵查询 $O(1)$ 但空间 $O(n^2)$；邻接表空间 $O(n+m)$，竞赛默认选它。
- DFS 用递归或栈，「一条路走到底」；`vis` 数组防止环内死循环。
- BFS 用队列逐层推进，无权图里首次到达即最短路。
- 遍历复杂度 $O(n+m)$
