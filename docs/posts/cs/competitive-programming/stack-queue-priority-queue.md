## 为什么从线性受限容器开始

数组让我们能随意访问任何位置，但这种「自由」有时反而是负担——很多问题的访问模式天然受限：处理嵌套结构要**后进先出**，处理排队要**先进先出**，处理「总想取最值」要**优先队列**。这三种容器约束了访问方式，却因此获得了更高的语义清晰度与效率。更重要的是，它们是一整类算法（DFS、BFS、Dijkstra、哈夫曼）的直接载体。这一章，我们把三种容器的「性格」和它们的经典应用一次讲透。

## 1 栈：后进先出的处理器

**栈（stack）** 只允许在**栈顶**插入和删除——最后进去的先出来，缩写 **LIFO**（Last In, First Out）。像一摞盘子，后放的先取。<span class="marginnote">程序的调用栈就是最著名的栈：每次函数调用压一帧，返回时弹出。前面《函数与递归》里递归一层层压栈、逐层返回，物理结构就是栈——这也是为什么递归常配栈思考。</span>

栈的三个操作都只碰栈顶：`push` 入栈、`pop` 出栈、`top` 看栈顶，都是 $O(1)$。

**经典应用一：括号匹配。** 判断 `([{}])` 是否合法，用一个栈扫描：遇到左括号入栈，遇到右括号就与栈顶比对，匹配则弹出。扫描结束时栈必须为空：

```cpp
bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') st.push(c);
        else {
            if (st.empty()) return false;
            if (c == ')' && st.top() != '(') return false;
            if (c == ']' && st.top() != '[') return false;
            if (c == '}' && st.top() != '{') return false;
            st.pop();
        }
    }
    return st.empty();
}
```

**经典应用二：表达式求值。** 中缀表达式 `3 + 5 * 2` 里 `*` 的优先级高于 `+`，处理器需要「看到后面的运算符才能决定前面怎么算」——这正是栈能处理的「延迟决策」。

## 2 队列：先进先出的调度器

**队列（queue）** 只允许在**队尾**插入、在**队头**删除——先进来的先出去，缩写 **FIFO**（First In, First Out）。像排队买票，先到先服务。<span class="marginnote">队列的两个操作叫 `push`（入队）与 `pop`（出队），队头用 `front` 看。注意 C++ 里 `queue` 没有 `top`——栈叫 `top`，队列叫 `front`，写混了编译器会直接报错，属于「看着像但就是不对」的一类。</span>

队列是**广度优先搜索（BFS）** 的天然载体：按层扩展，先被发现的节点先被处理。BFS 在《图的表示与 DFS/BFS 遍历》里会系统展开，这里先记住一条：**凡是「按层推进」「求最短步数」的问题，先想到队列**。

**经典应用：约瑟夫问题。** $n$ 个人围成一圈，从 1 开始报数，报到 $k$ 的出局，问最后剩下谁。用队列模拟「转圈」十分直观：每次把队头出队，不是第 $k$ 个就重新入队（模拟「继续转」），是第 $k$ 个就淘汰：

```cpp
queue<int> q;
for (int i = 1; i <= n; i++) q.push(i);
int cnt = 0;
while (q.size() > 1) {
    int x = q.front(); q.pop();
    if (++cnt == k) cnt = 0;  // 第 k 个出局
    else q.push(x);           // 否则回到队尾继续转
}
```

## 3 优先队列：总会给出最值的堆

**优先队列（priority_queue）** 每次弹出的都是当前**最大**（或最小）的元素。它底层是一个**堆（heap）**——一种完全二叉树结构，保证插入与弹出都是 $O(\log n)$。

**核心概念：堆的两个性质。** 结构上，堆是**完全二叉树**；值上，堆序性（大顶堆）要求每个父节点不小于其子节点。于是堆顶必是全局最大，而调整（上浮/下沉）只需沿着一条路径走，代价是树高 $O(\log n)$。<span class="marginnote">堆用数组就能实现：下标 $i$ 的左右孩子在 `2*i+1`、`2*i+2`，父节点在 `(i-1)/2`——完全二叉树天然适合数组存储，这是「逻辑上是树、物理上是数组」的第一次正式亮相。</span>

**经典应用：哈夫曼编码（Huffman coding）**。把字符按频率合并成带权路径最短的二叉树，每次取两个最小频率合并——「反复取最值」正是优先队列的主场，整体复杂度 $O(n\log n)$。

**辨析｜易错点：** `priority_queue` 只能看堆顶，不能直接看第二大的元素。想「取走最大后取次大」，必须先 `pop` 再 `top`。另外，默认是大顶堆，取最小用 `greater<int>`（见《C++ 与 STL 容器入门》）。

## 4 三种容器横向对比

| 容器 | 访问规则 | 插入 | 取出 | 适合的问题 |
| --- | --- | --- | --- | --- |
| `stack` | 后进先出 | $O(1)$ | $O(1)$ | 括号、表达式、DFS、单调栈 |
| `queue` | 先进先出 | $O(1)$ | $O(1)$ | BFS、层序、约瑟夫、滑动窗口 |
| `priority_queue` | 按优先级 | $O(\log n)$ | $O(\log n)$ | Dijkstra、哈夫曼、Top-K |

**重点：选容器的判断顺序**——先问「我要按什么顺序取元素」：最后放的先取就用栈，先放的先取就用队列，永远取最值就用优先队列。顺序想清楚，容器自然浮出水面。

## 5 公式解析：n 对括号的合法排列数

栈与括号匹配引出一个著名的计数问题：$n$ 对括号能组成多少种合法序列？答案就是**卡特兰数（Catalan number）**：

$$
C_n = \frac{1}{n+1}\binom{2n}{n}
$$

- **第一步，理解问题**：$2n$ 个位置里放 $n$ 个左括号，任意前缀里左括号数不少于右括号数，即为合法。
- **第二步，递推视角**：考虑第一个左括号匹配的右括号位置，把序列切成独立的两段，得递推式 $C_n = \sum_{i=0}^{n-1} C_i C_{n-1-i}$。
- **第三步，闭式解**：解这个递推得到 $C_n = \frac{1}{n+1}\binom{2n}{n}$，前几项为 $1, 1, 2, 5, 14, 42$。

**重点：卡特兰数是栈的「指纹」**。凡是「进出栈的合法顺序」「合法括号序列」「二叉树形态数」这类问题，答案几乎都是卡特兰数——它连接了栈、括号、二叉树三条看似无关的线，是竞赛数学里一个值得记住的常数序列。

### 表达式求值：中缀转后缀

栈处理表达式最经典的形态是**中缀转后缀（逆波兰表示法）**。中缀 `3 + 5 * 2` 里，`*` 优先级高，但读到时后面的 `2` 还没来，处理器需要「延迟决策」。栈正好做这件事：扫描表达式，数字直接输出，运算符与栈顶比较优先级——栈顶优先级不低于当前就弹出，最后当前运算符入栈。括号则「左括号入栈，遇到右括号弹到左括号」。

```cpp
int precedence(char c) {
    if (c == '+' || c == '-') return 1;
    if (c == '*' || c == '/') return 2;
    return 0;
}

string infixToPostfix(string s) {
    string res; stack<char> st;
    for (char c : s) {
        if (isdigit(c)) res += c;          // 操作数直接输出
        else if (c == '(') st.push(c);
        else if (c == ')') {
            while (st.top() != '(') { res += st.top(); st.pop(); }
            st.pop();                       // 弹出左括号
        } else {
            while (!st.empty() && precedence(st.top()) >= precedence(c)) {
                res += st.top(); st.pop();  // 栈顶优先级更高/相等，先出栈
            }
            st.push(c);
        }
    }
    while (!st.empty()) { res += st.top(); st.pop(); }
    return res;
}
```

**核心概念：优先级比较是「延迟决策」的开关。** `while` 里 `>=` 保证相同优先级的运算符**从左到右**结合（如 `3-2-1` 不会算成 `3-(2-1)`）；若改成 `>` 则是右结合。后缀表达式求值只需一个栈：遇数字入栈，遇运算符弹出两个数、算完压回——极其简单。

**辨析｜易错点：** 求值时弹出的是「右操作数在前、左操作数在后」，减法与除法要特别注意顺序：`a - b` 是先弹 `b` 再弹 `a`，写反就是 `b - a`。这个「弹栈顺序」错误是表达式求值题的头号 bug 来源。

## 6 小结

- 栈 = 后进先出，处理嵌套与延迟决策；括号匹配、表达式求值是标配应用。
- 队列 = 先进先出，按层推进；约瑟夫问题的「转圈」用队列模拟最直观。
- 优先队列 = 永远取最值，底层堆 $O(\log n)$；哈夫曼、Dijkstra 都靠它。
- 选容器先问取出顺序：栈/队列/优先队列三选一。
- 卡特兰数 $C_n = \frac{1}{n+1}\binom{2n}{n}$
