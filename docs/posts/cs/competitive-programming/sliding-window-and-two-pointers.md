## 为什么从滑动窗口与双指针开始

有一大类问题是「子数组」「子串」问题：最长无重复子串、最小覆盖子串、和为某个值的子数组……暴力做法对每个起点都向后扩展，$O(n^2)$。但这些问题的共性是——**子数组是连续的，随着起点右移，终点只增不减**。这个单调性让「维护一个窗口」成为可能：窗口的两个边界都是指针，只向前移动，于是每个元素最多被加入一次、移出一次，总复杂度摊还 $O(n)$。**滑动窗口（sliding window）** 与双指针，是 LeetCode 上性价比最高的一组技巧——套路固定、应用极广。

## 1 固定窗口与可变窗口

滑动窗口分两种基本形态。

**固定大小窗口**：窗口长度固定为 $k$，整体向右滑动，每次只变一个头尾。典型问题「大小为 k 的子数组最大平均值」——先算出第一个窗口的和，之后每次「加新去旧」，$O(n)$ 完成：

```cpp
double findMaxAverage(vector<int>& nums, int k) {
    int sum = 0;
    for (int i = 0; i < k; i++) sum += nums[i];
    int best = sum;
    for (int i = k; i < nums.size(); i++) {
        sum += nums[i] - nums[i - k];   // 进一个出一个
        best = max(best, sum);
    }
    return (double)best / k;
}
```

**可变窗口**：左右边界都在动，窗口保持一个「性质」。这是滑动窗口的精华，也是面试最爱考的部分。

## 2 可变窗口模板：最长无重复子串

「最长不含重复字符的子串」是可变窗口的教科书题。窗口用 `[l, r)` 表示，维护一个字符计数表，右指针不断扩展，一旦出现重复就收缩左边界：

```cpp
int lengthOfLongestSubstring(string s) {
    int cnt[128] = {0};
    int l = 0, ans = 0;
    for (int r = 0; r < s.size(); r++) {
        cnt[s[r]]++;
        while (cnt[s[r]] > 1) {      // 窗口里有重复，收缩左端
            cnt[s[l]]--;
            l++;
        }
        ans = max(ans, r - l + 1);   // 当前窗口长度
    }
    return ans;
}
```

**核心概念：窗口不变量。** 这个算法能成立，靠的是一个不变量——**循环体结束时，窗口 `[l, r]` 内没有重复字符**。右指针扩展破坏不变量，`while` 收缩左边界恢复不变量，每一步都让窗口保持合法。<span class="marginnote">这个「扩展破坏 → 收缩恢复」的节奏，就是可变窗口的通用骨架：`for` 右边界前进，内层 `while` 收缩左边界。模板背熟后，改改「合法性判断」就能套到最小覆盖子串、替换后的最长重复字符等一大片题。</span>

## 3 公式解析：为什么滑动窗口是 O(n)

滑动窗口最漂亮的地方是它的复杂度。设数组长为 $n$，两个指针都只向前移动：

$$
\text{总移动次数} = (\text{右指针前进次数}) + (\text{左指针前进次数}) \le n + n = 2n
$$

- **第一步，右指针**：外层 `for` 让右指针从 0 走到 $n$，恰好 $n$ 步，每步 $O(1)$ 维护窗口。
- **第二步，左指针**：内层 `while` 让左指针也只会从 0 走到 $n$——每个元素至多被移出窗口一次，总计 $n$ 步。
- **第三步，相加**：两个指针合计 $2n$ 次操作，总复杂度 $O(n)$。

**重点：摊还分析（amortized analysis）的直觉。** 虽然内层有 `while`，可能某一步连着收缩好多次，但这些收缩的总次数被「每个元素至多出一次窗口」限死了。这就是为什么看着像「双层循环」，实际却是线性——**把每一笔「贷款」都摊回每一次移动上**，是分析这类算法的通用手法。

## 4 双指针的另一副面孔：同向与相向

滑动窗口是**同向双指针**（两个指针都往右）。双指针还有**相向**的形态——两个指针从两端往中间走，靠有序性排除区域。

**相向指针的经典题：三数之和。** 先排序，固定一个数 $a_i$，剩下的区间用左右指针找两数之和为 $-a_i$：

```cpp
vector<vector<int>> threeSum(vector<int>& a) {
    sort(a.begin(), a.end());
    vector<vector<int>> res;
    int n = a.size();
    for (int i = 0; i + 2 < n; i++) {
        if (i > 0 && a[i] == a[i-1]) continue;   // 去重
        int l = i + 1, r = n - 1;
        while (l < r) {
            int s = a[i] + a[l] + a[r];
            if (s == 0) { res.push_back({a[i], a[l], a[r]}); while (l<r && a[l]==a[l+1]) l++; while (l<r && a[r]==a[r-1]) r--; l++; r--; }
            else if (s < 0) l++;
            else r--;
        }
    }
    return res;
}
```

**核心概念：相向指针的剪枝原理。** 排序后，左指针右移让和变大，右指针左移让和变小，每一步都排除「一整段不可能」——这与《链表与双指针》里「有序数组两数之和」是同一个思想，只是多了一层枚举。

**辨析｜易错点：** 三数之和的去重要在**三个层面**各做一次：外层枚举的 `a[i]` 跳过重复值，内层找到一组答案后跳过重复的 `a[l]` 与 `a[r]`。漏掉任何一层，结果里就会出现重复三元组。

## 5 从窗口到前缀：子数组求和问题

「和为 k 的子数组个数」这类问题，滑动窗口并不能直接套（因为数组有正有负时窗口不满足单调性）。这时换个视角：**子数组和 = 前缀和之差**。

$$
\text{sum}(i..j) = S[j] - S[i-1]
$$

要求 `sum == k`，即 `S[j] - S[i-1] == k`，等价于「在 $j$ 之前找前缀和等于 $S[j] - k$ 的个数」——用哈希表记录每个前缀和出现的次数：

```cpp
int subarraySum(vector<int>& nums, int k) {
    unordered_map<int,int> mp; mp[0] = 1;
    int sum = 0, ans = 0;
    for (int x : nums) {
        sum += x;
        ans += mp[sum - k];   // 之前有多少个前缀和 == sum-k
        mp[sum]++;
    }
    return ans;
}
```

**重点：单调性决定工具选择。** 数组全非负时，窗口随右端扩展「和单调不减」，滑动窗口可用；有负数时单调性破，改用前缀和 + 哈希。<span class="marginnote">「前缀和 + 哈希」是《前缀和、差分与离散化》的前置预览：凡是「子数组满足某条件」的计数题，先想「前缀和之差」，再用哈希表把「找差值」变成 $O(1)$ 查询——这个组合的威力在后面的题目里会反复验证。</span>

## 6 小结

- 滑动窗口分固定窗口（加新去旧）与可变窗口（扩展 + 收缩）。
- 可变窗口模板：右指针 `for` 扩展，内层 `while` 收缩，维护窗口不变量。
- 复杂度 $O(n)$ 的根据是摊还：两指针各至多前进 $n$ 次，共 $2n$
