## 为什么从前缀和、差分与离散化开始

有一类问题在竞赛里高频到令人麻木：**区间求和**（算 `[l, r]` 内元素之和）、**区间加值**（把 `[l, r]` 内每个元素都加 x）、以及**值域过大**（坐标是 $10^9$ 但数量只有 $10^5$）。朴素做法是每次查询都扫一遍区间，$O(n)$ 一次——查询一多就超时。**前缀和（prefix sum）** 用一次 $O(n)$ 预处理，把区间求和变成两次 $O(1)$ 查询；**差分（difference）** 则是它的「逆运算」，把区间加值变成两次 $O(1)$ 修改；**离散化（coordinate compression）** 把巨大的值域映射到紧凑的排名。这三个技巧几乎总是配套出现，是区间问题的最强基本功。

## 1 前缀和：把区间和变成两次减法

**前缀和数组**：`pre[i]` 表示原数组前 i 个元素之和。一次 $O(n)$ 预处理后，任意区间和 `[l, r]` 都能用两次查表算出来：

$$
pre[i] = pre[i-1] + a[i], \qquad \text{sum}(l, r) = pre[r] - pre[l-1]
$$

```cpp
vector<long long> pre(n + 1, 0);
for (int i = 1; i <= n; i++) pre[i] = pre[i-1] + a[i];
// 查询 [l, r] 的和（l, r 均为 1 起）：
long long ans = pre[r] - pre[l - 1];
```

- **第一步，看预处理**：`pre[i]` 从 `pre[i-1]` 递推而来，`pre[0] = 0`。
- **第二步，看查询**：区间 `[l, r]` 的和 = 「前 r 个的和」减去「前 l-1 个的和」。
- **第三步，看复杂度**：预处理 $O(n)$，之后每次查询 $O(1)$。

**核心概念：前缀和是「差」的艺术。** 它把「一段区间」的信息压缩进两个端点的前缀信息里——区间和是两端前缀和的差。<span class="marginnote">下标从 1 开始、`pre[0] = 0` 是前缀和的默认约定，让 `sum(l,r) = pre[r] - pre[l-1]` 无需特判。若用 0 起下标，`l = 0` 时 `pre[-1]` 越界，就得额外分支——所以竞赛里宁可浪费一格也要从 1 起。</span>

## 2 二维前缀和：矩形区域求和

二维前缀和把「区间」推广到「矩形」。`pre[i][j]` 表示以 `(1,1)` 为左上角、`(i,j)` 为右下角的子矩阵和，用**容斥原理**递推：

$$
pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j]
$$

任意矩形 `(x1,y1)..(x2,y2)` 的和同样用容斥：

$$
S = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1]
$$

**核心概念：容斥——加两片减一片。** 求 `pre[i][j]` 时，把上方矩形与左方矩形相加，左上角那块被加了两次，要减去一次，再加上自身 `a[i][j]`。<span class="marginnote">二维前缀和是「图像积分图」（integral image）的数学前身——图像处理里的快速框式滤波就靠它。同样，`n` 维前缀和只需容斥 $2^n$ 项，但竞赛里二维就到顶了，三维以上少见。</span>

**辨析｜易错点：** 二维前缀和的容斥式有 4 项，任何一项的坐标写错（漏减、多减、下标越界）都会得到错误结果。写完对着一个小矩阵（如 $2\times2$）手算验证一遍，比调试十次都省时间。

## 3 差分：区间加值的逆操作

**差分数组（difference array）**：`diff[i] = a[i] - a[i-1]`，它记录「原数组相邻位置的差」。前缀和是「从差分还原原数组」，差分是「从前缀和求相邻差」——两者互为逆运算。

**核心用途：区间加值变两次修改。** 要给 `[l, r]` 内每个元素加 x，只需：

$$
diff[l] += x, \qquad diff[r+1] -= x
$$

因为差分只记录「相邻差值」：在 `l` 处开始加 x（`a[l]` 与 `a[l-1]` 的差变大 x），在 `r+1` 处抵消（`a[r+1]` 与 `a[r]` 的差变小 x），中间全部自然继承。全部修改做完后，**对差分数组做一次前缀和就还原出原数组**。

```cpp
vector<long long> diff(n + 2, 0);      // 多开两个防越界
// 做 m 次区间加
for (auto &[l, r, x] : ops) {
    diff[l] += x;
    diff[r + 1] -= x;
}
// 还原并求最终数组
for (int i = 1; i <= n; i++) a[i] = a[i-1] + diff[i];
```

**重点：差分把「$O(mn)$ 的区间修改」变成「$O(n+m)$」。** 朴素做法每次区间加都扫一遍区间，$m$ 次修改 $O(mn)$；差分让每次修改 $O(1)$，最后一次性还原 $O(n)$。<span class="marginnote">「航班预订统计」「打家劫舍变体」这类题就是差分的直接应用：把多个区间修改的叠加，先全部记录到差分里，再一次前缀和求出最终状态——这是「离线批量处理」思想的雏形。</span>

## 4 离散化：把大值域压进小数组

**离散化（coordinate compression）**：当坐标值域巨大（如 $10^9$）但实际出现的不同值很少（如 $10^5$）时，把所有出现过的值排序、去重，映射成紧凑的排名 0、1、2……：

```cpp
vector<int> vals = a;
sort(vals.begin(), vals.end());
vals.erase(unique(vals.begin(), vals.end()), vals.end());
// 用排名代替原值
for (int &x : a) x = lower_bound(vals.begin(), vals.end(), x) - vals.begin();
```

**核心概念：只关心相对大小。** 离散化保序——原值的大小关系在排名里原样保留。于是凡是「只比较大小、不关心绝对坐标」的问题（扫描线、树状数组、坐标 DP），都能把值域从 $10^9$ 压到 $n \le 10^5$，让数组、树状数组存得下。<span class="marginnote">`sort + unique + lower_bound` 是离散化的三件套：排序拿到有序值，`unique` 去重（要配合 `erase` 真的删掉），`lower_bound` 把原值换成排名。离散化几乎总是与树状数组、线段树配套出现——它让这些数据结构从「值域受限」走向「任意值域通用」。</span>

**辨析｜易错点：** `unique` 只把重复元素移到末尾，不会真的删除——必须配合 `erase` 收缩容器。另外，离散化前先想清楚「需不需要保留重复值」：做频率统计时需要区分原值，做「只比较大小」时去重即可。

## 5 三者合奏：一个综合问题

假设要解决：坐标轴上 $m$ 次「给区间 `[l, r]` 加 x」的操作，最后回答某点最终值。数据坐标可达 $10^9$，但区间端点总共只有 $2m$ 个不同值。三件套流水线：

1. **离散化**：收集所有 `l` 与 `r+1`，排序去重得到排名。
2. **差分**：在排名上做区间加，`diff[rank(l)] += x`，`diff[rank(r+1)] -= x`。
3. **前缀和还原**：一趟前缀和，得到每个关键位置的最终值。

**重点：三件套是区间问题的标准流水线。** 前缀和回答「静态区间查询」，差分回答「批量区间修改」，离散化让两者在任意值域上可用。三者可以自由组合，覆盖了区间问题的一大半场景。

## 6 小结

- 前缀和：`pre[i] = pre[i-1] + a[i]`，区间和 = 两次前缀相减，查询 $O(1)$。
- 二维前缀和用容斥：加两块减一块再加自身，矩形查询 4 项容斥。
- 差分：`diff[i] = a[i] - a[i-1]`，区间加值 = `diff[l]+=x, diff[r+1]-=x`，还原靠前缀和。
- 差分把 $O(mn)$ 的区间修改降到 $O(n+m)$。
- 离散化三件套：`sort + unique + lower_bound`，把 $10^9$ 值域压到 $n$。
- 三件套组合：离散化让差分与前缀和在任意值域可用，是区间问题的标准流水线。

在下一节，我们将进入**位运算与状态压缩**——前缀和的「差分还原」思想将在位级世界重现。
而离散化维护的相对大小，正是状态压缩要编码的集合关系——数据规模与数值范围，是贯穿整条主线的两把尺。
