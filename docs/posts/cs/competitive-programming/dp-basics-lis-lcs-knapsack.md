## 为什么从动态规划初步开始

我们在《函数与递归》里见过朴素递归的灾难：斐波那契递归会重复计算同一个子问题几千次。**动态规划（dynamic programming, DP）** 的治疗方案朴素而深刻——**把子问题的答案记下来**，需要时直接查表，不再重算。这个「记」字，把指数级降成多项式级。DP 是竞赛算法中最重要、也最需要练习的一类：它的难点不在代码，而在**识别问题能不能 DP、把问题翻译成状态转移方程**。这一章我们用三个最经典的模型——LIS、LCS、背包——把「状态、转移、初始化、答案」四步法走通。

## 1 DP 的两个前提：最优子结构与重叠子问题

**核心概念：DP 的两个成立条件。** 一个问题能用 DP 解决，需要同时满足：

**最优子结构（optimal substructure）**：大问题的最优解包含子问题的最优解。**重叠子问题（overlapping subproblems）**：不同的父问题共享同一个子问题，所以「记下来」才有意义。

判断方法：写一个朴素递归，若递归树里**同一个参数反复出现**，就说明有重叠子问题，值得用 DP 记表；若每个子问题只出现一次，递归就够了。

**重点：DP 的两种实现。** **自顶向下（top-down）** = 递归 + 记忆化数组，顺着递归思考，返程时查表；**自底向上（bottom-up）** = 递推填表，从小到大逐个计算。两者等价的，自底向上没有递归开销，是竞赛主流；自顶向下在「转移顺序不明显」时更好写。先把自底向上的填表练熟。

## 2 最长上升子序列 LIS

**LIS（Longest Increasing Subsequence）**：在序列里找一条最长的「严格递增」子序列（不必连续）。定义状态 `dp[i]` = **以第 i 个元素结尾的 LIS 长度**：

$$
dp[i] = 1 + \max\{dp[j] \mid j \lt  i \text{ 且 } a[j] \lt  a[i]\}, \qquad dp[i] \ge 1
$$

```cpp
vector<int> dp(n, 1);          // 每个元素自己就是一个长度为 1 的 LIS
for (int i = 0; i < n; i++)
    for (int j = 0; j < i; j++)
        if (a[j] < a[i])
            dp[i] = max(dp[i], dp[j] + 1);
int ans = *max_element(dp.begin(), dp.end());
```

- **第一步，定义状态**：`dp[i]` 强制第 $i$ 个元素作为 LIS 的最后一个元素。
- **第二步，写转移**：在 $i$ 之前找所有「值小于 $a[i]$」的位置 $j$，把「以 $j$ 结尾的 LIS」接上 $a[i]$。
- **第三步，初始化**：每个位置自己是一个 LIS，所以 `dp` 全初始化为 1。
- **第四步，取答案**：全局最大值 = max 所有 `dp[i]`（LIS 不一定在末尾结束）。

**重点：LIS 的朴素 DP 是 $O(n^2)$。** $n \le 10^5$ 时会超时，此时用「维护各长度末尾最小值」的贪心 + 二分优化到 $O(n\log n)$——这是 LIS 的进阶形态，先掌握朴素 DP 理解本质。

## 3 最长公共子序列 LCS

**LCS（Longest Common Subsequence）**：两个字符串的最长公共子序列。状态定义 `dp[i][j]` = **`a` 前 i 个字符与 `b` 前 j 个字符的 LCS 长度**，转移分两种情况：

$$
dp[i][j] = \begin{cases} dp[i-1][j-1] + 1 & a_i = b_j \\ \max(dp[i-1][j],\ dp[i][j-1]) & a_i \ne b_j \end{cases}
$$

```cpp
vector<vector<int>> dp(n+1, vector<int>(m+1, 0));
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++) {
        if (a[i-1] == b[j-1]) dp[i][j] = dp[i-1][j-1] + 1;
        else dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
    }
// 答案 dp[n][m]
```

**核心概念：匹配则前进，不匹配则取舍。** 当 `a[i] == b[j]`，这两个字符可以配对，答案由前一个状态 +1 而来；不等时，要么跳过 `a[i]`、要么跳过 `b[j]`，取两者更大。<span class="marginnote">注意下标从 1 开始填、用 0 行 0 列做「空串」基线——`dp[0][j] = 0` 表示空串与任何串的 LCS 是 0。这个「多加一圈 0」的技巧在二维 DP 里非常常见，能省去大量边界特判。</span>

## 4 0/1 背包与完全背包

**0/1 背包**：$n$ 个物品，每个有重量 $w_i$ 与价值 $v_i$，背包容量 $C$，每个物品**最多选一次**，求最大总价值。状态 `dp[i][j]` = **前 i 个物品、容量 j 时的最大价值**：

$$
dp[i][j] = \max(dp[i-1][j],\ dp[i-1][j - w_i] + v_i)
$$

```cpp
vector<int> dp(C + 1, 0);
for (int i = 0; i < n; i++)
    for (int j = C; j >= w[i]; j--)        // 逆序！保证每个物品只用一次
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

**重点：为什么内层要逆序？** 一维滚动数组里，若正序遍历 `j`，`dp[j - w[i]]` 可能已经被**本轮**更新过——等于同一个物品被用了多次。逆序遍历保证 `dp[j - w[i]]` 仍是「上一轮」的值，物品只能用一次。<span class="marginnote"><strong>完全背包</strong>（每个物品无限次）恰好反过来：内层正序遍历，`dp[j]` 就可以反复叠加同一个物品。一个「逆序」之差，两种背包模型由此分野——这是背包专题里最经典的细节，也常是面试官的第一道追问。</span>

**公式解析：背包状态如何由「选/不选」决定。** 把 0/1 背包的转移拆开看：

- **不选第 i 个**：容量 j 直接继承前 i-1 个物品的结果，`dp[i-1][j]`。
- **选第 i 个**：先给第 i 个物品留出容量 `w[i]`，剩余容量 `j - w[i]` 交给前 i-1 个物品最优，再加 `v[i]`。
- **取最大**：两种决策都合法，取价值更大者——这就是「每个物品只有选与不选两种状态」的数学表达。

## 5 动态规划的四步法

把三个模型抽象出来，DP 的做题流程高度固定：

**第一步，定义状态**：想清楚 `dp` 的下标代表什么、`dp[i][j]` 存什么值。状态定义决定一切，定义错方向，后面全错。
**第二步，写转移方程**：想清楚当前状态能从哪些「更小」的状态到达。这步是核心，也是最难的一步。
**第三步，定初始化与边界**：最「小」的状态值是多少？下标从 1 还是 0 开始？越界怎么处理？
**第四步，找答案**：答案在哪个状态？是 `dp[n][m]`，还是要对 dp 取 max？

**辨析｜易错点：** 四步里最容易错的是**状态定义含糊**。「以 i 结尾」「前 i 个」「第 i 个是否选」三种口径对应完全不同的转移——动手前先写一句话把 `dp[i]` 说清楚。另一点是**初始化遗漏**：`dp[0]`、`dp[0][0]` 这类基线若不设置，转移会用到垃圾值。

**补充：滚动数组的空间优化。** 0/1 背包的二维 `dp[i][j]` 只依赖 `dp[i-1][...]` 上一行，于是可以只用一维数组滚动——代码里那个 `vector<int> dp(C+1)` 就是滚动数组的结果。凡是「状态只依赖前一行」的 DP，都能做滚动压缩，空间从 $O(nC)$ 降到 $O(C)$。判断能否滚动，看转移方程里 `dp[i]` 是否只用 `dp[i-1]`（或更早的固定几行）。

## 6 小结

- DP 两前提：最优子结构 + 重叠子问题；记忆化把指数级降到多项式级。
- 自顶向下 = 递归 + 记忆化；自底向上 = 递推填表，竞赛主流。
- LIS：`dp[i] = max(dp[j]+1)`，$O(n^2)$；进阶用贪心 + 二分优化到 $O(n\log n)$。
- LCS：`dp[i][j]` 匹配则 `dp[i-1][j-1]+1`、不匹配取 `max`，答案 `dp[n][m]`。
- 0/1 背包内层逆序遍历保证物品只用一次；完全背包正序遍历即可重复取。
- 滚动数组：状态只依赖上一行就能压成一维，空间从 $O(nC)$ 降到 $O(C)$。

在下一节，我们将进入**区间 DP 与记忆化搜索**——当子问题从「前缀」变成「一段连续区间」，状态的定义与填表顺序都要换一套思路。
而记忆化会把「递归 + 缓存」用到极致，让分割点的枚举顺着递归自然流淌。
