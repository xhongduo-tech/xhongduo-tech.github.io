## 为什么从排序与复杂度开始

算法竞赛里最常被问到的一句话是：「你的算法复杂度是多少？」答案是「能不能过」的判据——$O(n^2)$ 的算法在 $n = 10^5$ 时可能要几十秒，$O(n\log n)$ 却瞬间完成。**排序**是理解复杂度最好的窗口：它的朴素版本（冒泡、选择）是 $O(n^2)$ 的典型，高效版本（归并、快排）是 $O(n\log n)$ 的典型，两者对比，你会直观地感受到「同一个问题，算法差多远」。这一章我们建立复杂度的度量语言，并借排序把五种经典算法一次讲透。

## 1 大 O 记号：给算法定级

**大 O 记号（Big-O notation）** 描述算法运行时间随输入规模 $n$ 增长的**量级**，忽略常数与低阶项。$O(n^2)$ 的意思是：当 $n$ 足够大时，运行时间大致不超过 $c \cdot n^2$ 的某个常数倍。

| 记号 | 名称 | 直觉 | $n=10^5$ 时的量级感受 |
| --- | --- | --- | --- |
| $O(1)$ | 常数 | 一次操作 | 眨眼 |
| $O(\log n)$ | 对数 | 每步砍一半 | 17 步 |
| $O(n)$ | 线性 | 扫一遍 | 微秒级 |
| $O(n\log n)$ | 线性对数 | 分而治之 | 毫秒级 |
| $O(n^2)$ | 平方 | 双重循环 | 秒级到分钟级 |
| $O(2^n)$ | 指数 | 枚举全部子集 | 宇宙毁灭级 |

<span class="marginnote">竞赛的经验法则：现代评测机每秒约能执行 $10^8$ 次简单运算。于是 $n = 10^5$ 时，$O(n^2)$ 的 $10^{10}$ 次运算必超时，$O(n\log n)$ 稳稳通过——拿到数据范围先算复杂度，是读题的第一步。</span>

**重点：复杂度看的是增长趋势，不是具体时间**。$O(n)$ 里常数再大也只是「慢」，$O(n^2)$ 里常数再小也救不了 $n$ 增大时的灾难。

## 2 朴素排序：冒泡、选择与插入

三个 $O(n^2)$ 的排序，都基于直观的「比较—交换」，是理解排序本质的起点。

**冒泡排序（bubble sort）**：每轮把相邻逆序的元素交换，最大的元素像气泡一样浮到末尾。

**选择排序（selection sort）**：每轮从未排序部分挑出最小元素，放到已排序部分末尾——交换次数少，但比较次数仍是 $O(n^2)$。

**插入排序（insertion sort）**：像整理扑克牌，把新元素插入到已排序序列的正确位置。它在**数据近乎有序**时接近 $O(n)$，这是另外两个没有的优势。

```cpp
// 插入排序
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i], j = i - 1;
        while (j >= 0 && a[j] > key) { a[j+1] = a[j]; j--; }
        a[j+1] = key;
    }
}
```

**辨析｜易错点：** 插入排序的 while 循环里，`j >= 0` 必须先判断——`a[j]` 在 `j = -1` 时会越界。数组下标访问在前，条件判断在后，这是 C 系 `&&` 短路求值的经典用例，也最容易写反。

## 3 高效排序：归并与快排

当 $n$ 到 $10^5$ 以上，$O(n^2)$ 就撑不住了，需要 $O(n\log n)$ 的排序。

**归并排序（merge sort）**：分治思想的标准教材。把数组对半拆，各自排好，再**合并**两个有序段。合并操作是「双指针比较，小的先出」，正确且稳定。

```cpp
void merge(int a[], int l, int m, int r) {
    vector<int> t(r - l + 1);
    int i = l, j = m + 1, k = 0;
    while (i <= m && j <= r)
        t[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i <= m) t[k++] = a[i++];
    while (j <= r)  t[k++] = a[j++];
    for (int p = 0; p < t.size(); p++) a[l + p] = t[p];
}
```

**快速排序（quick sort）**：选一个**基准（pivot）**，把小于它的放左边、大于它的放右边，再对两侧递归。平均 $O(n\log n)$，但最坏（每次基准都是极值）退化为 $O(n^2)$——工程实现用「三点取中 + 内省切换」来防御。<span class="marginnote">C++ 的 `std::sort` 是内省排序：快排为主，检测到递归过深就切换成堆排序保证 $O(n\log n)$，小段用插入排序降低常数——工程上「三个算法协同」的典范。</span>

## 4 公式解析：归并排序的时间复杂度

归并排序的运行时间满足一个**递推关系（recurrence）**：

$$
T(n) = 2T\left(\frac{n}{2}\right) + O(n)
$$

- **第一步，拆解**：规模 $n$ 的问题被拆成两个规模 $n/2$ 的子问题，加上合并的 $O(n)$ 代价。
- **第二步，展开**：$T(n) = 2T(n/2) + cn = 4T(n/4) + 2cn = \cdots$
- **第三步，归纳**：拆到第 $k$ 层时，$T(n) = 2^k T(n/2^k) + kcn$。当 $n/2^k = 1$，即 $k = \log_2 n$，得到 $T(n) = n \cdot O(1) + cn\log_2 n = O(n\log n)$。

**重点：递归树的直觉**——归并排序把问题切成 $\log n$ 层，每层合计处理 $O(n)$ 个元素，于是总代价是「层数 × 每层代价」=$O(n\log n)$。这个「递归树」视角在后面分治、快排、二分里会反复出现。

## 5 排序的工程选择与进阶工具

竞赛里几乎不需要手写排序——`std::sort` 足够快。真正要练的是**「排序 + 处理」的组合题**：

**合并区间**：按起点排序后，一趟扫描合并重叠区间——排序把「乱序的区间重叠判断」变成「相邻区间的比较」。

**第 K 大元素**：可以用快排的 partition 思想做到平均 $O(n)$——只递归一边，这是「快速选择（quickselect）」。

**自定义排序规则**：C++ 用 lambda 传比较器，见《C++ 与 STL 容器入门》。

| 排序 | 最好 | 平均 | 最坏 | 空间 | 稳定 |
| --- | --- | --- | --- | --- | --- |
| 冒泡 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 是 |
| 插入 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 是 |
| 选择 | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 否 |
| 归并 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | 是 |
| 快排 | $O(n\log n)$ | $O(n\log n)$ | $O(n^2)$ | $O(\log n)$ | 否 |

**辨析｜易错点：** **稳定性（stability）** 指相等元素的相对顺序在排序后是否保持不变。归并稳定，快排不稳定。当「先按主键排，再按次键排」时，第二趟排序的稳定性决定了第一趟的顺序是否被保留——经典的多级排序陷阱。

## 6 小结

- 大 O 记号衡量增长量级；$10^8$ 次/秒是估算能否通过的标尺。
- 冒泡、选择、插入是 $O(n^2)$ 的基础课；插入排序对近似有序数据近乎 $O(n)$。
- 归并、快排是 $O(n\log n)$ 的分治典范；快排最坏 $O(n^2)$，需防御。
- 归并递推式 $T(n) = 2T(n/2) + O(n)$ 解得 $O(n\log n)$
