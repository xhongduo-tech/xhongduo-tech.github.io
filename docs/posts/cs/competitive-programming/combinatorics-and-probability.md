## 为什么从组合数学与概率期望开始

竞赛里有一类题「看不出算法」，其实它在考**数学建模**：把问题翻译成「数有多少种方案」「期望要走多少步」。**组合数学（combinatorics）** 是「数数」的科学——排列、组合、容斥、递推；**概率期望（probability & expectation）** 则给「不确定性」一个确定的数值。两者是竞赛数学题的两大支柱：从「抛骰子几次」到「随机游走期望步数」，再到概率 DP 的递推，全部建立在这套语言上。这一章，我们掌握计数的基本功与期望的两大利器——**线性性**与**期望 DP**。

## 1 计数的两个基本原理

计数的地基是两条几乎显然、却威力无穷的原理。

**加法原理**：做一件事有 $k$ 类互斥的方法，分别有 $n_1, n_2, \ldots, n_k$ 种，则总方法数 = $n_1 + \cdots + n_k$。<span class="marginnote">「互斥」是关键——两类方法不能重叠，否则重复计数。判断互斥是加法原理最常见的坑：分情况讨论时，情况之间绝不能有交集。</span>

**乘法原理**：做一件事分 $k$ 步，第 $i$ 步有 $n_i$ 种选择，则总方法数 = $n_1 \times n_2 \times \cdots \times n_k$。

**核心概念：排列与组合是两原理的封神应用。**

- **排列（permutation）**：$n$ 个里选 $k$ 个并排顺序，$P(n, k) = \frac{n!}{(n-k)!}$。
- **组合（combination）**：$n$ 个里选 $k$ 个不管顺序，$\binom{n}{k} = \frac{n!}{k!(n-k)!}$。

区别只有一句话：**要不要排序**。排序用排列，不排序用组合。判断标准是「选出的结果是否区分先后」。

## 2 组合数的计算与容斥原理

**组合数取模** 是竞赛的常客。$n$ 大、$M$ 为素数时，预处理阶乘与逆元，$O(1)$ 查询：

```cpp
const int MOD = 1e9 + 7;
vector<long long> fact(N), inv(N);
fact[0] = 1;
for (int i = 1; i < N; i++) fact[i] = fact[i-1] * i % MOD;
inv[N-1] = qpow(fact[N-1], MOD-2, MOD);        // 费马小定理求逆元
for (int i = N-2; i >= 0; i--) inv[i] = inv[i+1] * (i+1) % MOD;
long long C(int n, int k) {                     // 组合数 O(1)
    if (k < 0 || k > n) return 0;
    return fact[n] * inv[k] % MOD * inv[n-k] % MOD;
}
```

**容斥原理（inclusion-exclusion principle）** 处理「至少满足一个条件」的计数。两个集合的情形：

$$
|A \cup B| = |A| + |B| - |A \cap B|
$$

- **第一步，相加**：先数满足 A 的、满足 B 的。
- **第二步，减重叠**：两个都满足的被加了两次，减去一次。
- **第三步，推广**：三个集合就「加三减三加一」，$k$ 个集合按符号交替——这就是容斥的「奇加偶减」规则。

**辨析｜易错点：** 容斥最容易错在「重叠部分算没算」。画韦恩图核对是最可靠的办法；推广到多集合时，每个「交集」的系数由集合数目的奇偶决定，写错一个符号全盘皆错。

## 3 公式解析：期望的线性性

**数学期望（expected value）** 是「平均结果」的严格定义。它的最大武器是**线性性（linearity of expectation）**——对任意随机变量 $X, Y$（哪怕相关）：

$$
E[X + Y] = E[X] + E[Y], \qquad E[cX] = c\,E[X]
$$

- **第一步，读定理**：和的期望 = 期望的和，**不需要任何独立性假设**——这是期望区别于概率的最强性质。
- **第二步，应用套路**：把复杂随机变量拆成若干「指示变量」之和。指示变量 $I_i$ 表示「事件 i 是否发生」（取 1 或 0），$E[I_i] = P(\text{事件 } i \text{ 发生})$。
- **第三步，实战例子**：「$n$ 张牌随机排列，期望有几张位置正确？」设 $I_i$ 表示第 $i$ 张在正确位置，$P(I_i=1) = 1/n$，于是 $E[\sum I_i] = n \times 1/n = 1$——**永远恰好期望 1 个**，与 $n$ 无关。这个反直觉结论全靠线性性得出。

**重点：线性性让「相关变量」也能拆。** 朴素求期望需要完整分布；线性性只需逐个算「单点的概率」再求和——复杂度从指数级降到线性。<span class="marginnote">「随机排列的固定点数期望为 1」是经典面试题：几乎所有第一次见的人都猜「约 $n/2$」或「$n/e$」，正确答案是常数 1。线性性把看似复杂的整体问题拆成 $n$ 个独立的一问一答，这就是它被称为「期望题第一武器」的原因。</span>

## 4 概率 DP：用递推算期望

当问题有「状态」与「转移」时，期望可以用 **DP** 来算——这是概率期望与动态规划的合体。

**经典问题：期望步数。** 一个随机过程（如掷骰子走格子、随机图上的游走），问「从起点到终点期望要几步」。设 `dp[i]` = **从状态 i 到终点的期望步数**，按「一步能到哪些状态」列递推：

$$
dp[i] = 1 + \sum_{j} p_{i \to j} \cdot dp[j]
$$

其中 $p_{i \to j}$ 是从 $i$ 转移到 $j$ 的概率，`1` 是走这一步的代价。<span class="marginnote">注意方向：`dp[i]` 表示「从 i 出发还要几步」，所以是<strong>从终点反向递推</strong>还是正向递推，取决于转移图的形态。若存在「回退」（如失败重来），`dp[i]` 的式子右边可能包含 `dp[i]` 自己——这时要解方程，用「移项」把 `dp[i]` 系数化为 1。概率 DP 里「自己转移到自己」的解方程技巧是分水岭。</span>

**核心概念：期望 DP 的三要素**——定义状态（`dp[i]` 是从 i 到终点的期望）、写转移（枚举一步的所有可能结果）、找边界（终点状态 `dp[终点]=0`）。它与普通 DP 的唯一区别是「转移要乘概率求和」。

## 5 常用计数模型速览

| 模型 | 计数/公式 | 关键点 |
| --- | --- | --- |
| 排列 | $P(n,k) = \frac{n!}{(n-k)!}$ | 讲顺序 |
| 组合 | $\binom{n}{k}$ | 不讲顺序 |
| 多重集排列 | $\frac{n!}{n_1! n_2! \cdots}$ | 同类内部交换不算新 |
| 鸽巢原理 | 超过 $kn$ 个进 $n$ 个盒子必有盒 $\ge k+1$ | 存在性证明 |
| 容斥 | $\|\cup A_i\|$ 奇加偶减 | 避免重复计数 |
| 卡特兰数 | $C_n = \frac{1}{n+1}\binom{2n}{n}$ | 括号、栈、二叉树 |

**辨析｜易错点：** 计数题做完一定要**验算小数据**。$n=1$、$n=2$ 时手算答案对上了，公式才大概率正确。组合数的模运算还要检查 `k > n` 与 `k < 0` 的越界分支——漏了会访问到未初始化的数组。

### 概率的基本运算法则

期望的线性性之外，概率本身有几条基础法则，是建模的第一步。**对立事件**：$P(\bar{A}) = 1 - P(A)$，常把「至少发生一次」转成「一次都不发生」。**加法法则**：$P(A \cup B) = P(A) + P(B) - P(A \cap B)$，与容斥同构。**乘法法则**：$P(A \cap B) = P(A) \cdot P(B \mid A)$。

**辨析｜易错点：独立与互斥是两个概念。** 互斥是「不能同时发生」，独立是「一个发生不影响另一个的概率」。互斥事件若概率都不为 0，就不可能是独立的——两件只能发生一件的事，知道一件发生了，另一件的概率直接变 0。把「互斥」当成「独立」是概率题最常见的错误。

**核心概念：条件概率是期望 DP 的底层语言。** `dp[i]` 里的转移概率 `p(i→j)` 就是条件概率；期望 DP 之所以成立，本质是把全概率公式 `P(B) = Σ P(A_i) P(B|A_i)` 的加权平均思想搬进了状态转移。

## 6 小结

- 计数地基：加法原理（互斥才相加）、乘法原理（分步才相乘）。
- 排列讲顺序 $P(n,k)$，组合不讲顺序 $\binom{n}{k}$。
- 组合数取模：预处理阶乘 + 逆元，$O(1)$ 查询；容斥原理「奇加偶减」。
- 期望线性性 $E[X+Y]=E[X]+E[Y]$
