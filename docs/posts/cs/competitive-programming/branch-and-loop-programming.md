## 为什么从分支与循环开始

上一章我们学会了「读进数据、输出结果」，但程序还只是一条笔直的路：从头走到尾，不做任何判断。真实的问题不是这样——"如果输入是负数怎么办""对每一个测试数都要算一遍"。**分支**让程序有了抉择，**循环**让程序有了重复，两者合起来，程序才真正获得了「用少量代码处理海量数据」的能力。这一章是结构化程序设计的核心，也是后面一切算法（枚举、搜索、动态规划）的地基。

## 1 分支结构：if 与 switch

程序要按条件决定走哪条路，用的是 **分支（branch）** 语句。最基本的形态是 `if`：

```c
if (n % 2 == 0) {
    printf("even\n");
} else {
    printf("odd\n");
}
```

**核心概念——关系与逻辑运算**：判断条件由关系运算符与逻辑运算符组成。`==`（等于）、`!=`（不等于）、`>`、`<`、`>=`、`<=` 六种关系运算符，加上 `&&`（与）、`||`（或）、`!`（非）三种逻辑运算符，足以表达任何条件。<span class="marginnote">`&&` 与 `||` 都有<strong>短路（short-circuit）</strong>行为：`a && b` 若 `a` 为假，`b` 根本不会执行；`a || b` 若 `a` 为真同理。利用短路可以安全地写 `n != 0 && x / n > 1` 这种条件，避免除零。</span>

多个互斥分支可以级联 `else if`，也可以用 `switch` 语句做「值匹配」。`switch` 适合对同一个变量做多分支分发：

```c
switch (op) {
    case '+': printf("%d\n", a + b); break;
    case '-': printf("%d\n", a - b); break;
    default:  printf("?\n");
}
```

**辨析｜易错点：** 忘记 `break;` 是 `switch` 最经典的坑——它不会自动退出，会「穿透（fall through）」到下一个 `case` 继续执行。而 `if (n = 1)` 这种「赋值写成相等」的错，编译器通常只给警告，却会把条件永远置真——把常量写在左边 `1 == n` 可让编译器帮你抓出来。

## 2 循环结构：while 与 for

循环让一段代码反复执行，直到条件不成立。C 语言有三种循环，但本质相同：

**`while` 循环**：先判断条件，再决定是否进入循环体。
**`for` 循环**：把「初始化—条件—更新」三件事写在一行，是计数循环的标配。
**`do-while` 循环**：先执行一次循环体再判断条件，保证至少执行一次。

```c
// 三种写法求 1 到 n 的和
int i = 1, s = 0;
while (i <= n) { s += i; i++; }

int s2 = 0;
for (int j = 1; j <= n; j++) s2 += j;

int k = 1, s3 = 0;
do { s3 += k; k++; } while (k <= n);
```

**重点：循环三要素**——每个循环都要问自己三件事：**从哪里开始**（初始化）、**什么时候停**（条件）、**每一步怎么变**（更新）。三要素缺一，循环不是死循环就是少算一轮。

**辨析｜易错点：** 循环里的「差一错误（off-by-one）」占了竞赛报错的大头。`for (int i = 1; i <= n; i++)` 恰好跑 $n$ 次；若写成 `i < n` 就少一次。想清楚「闭区间还是开区间」再动笔，比事后调试快得多。

## 3 循环控制：break 与 continue

循环体内有两把「指挥棒」。**`break`** 立即终止整个循环，跳到循环之后；**`continue`** 跳过本次迭代的剩余语句，直接进入下一次。

```c
// 找 2 到 n 之间第一个能被 7 整除的数
for (int i = 2; i <= n; i++) {
    if (i % 7 != 0) continue;
    printf("%d\n", i);
    break;
}
```

<span class="marginnote">`break` 只跳出<strong>最近一层</strong>循环。嵌套循环里想一次性跳出两层，需要借助标记变量或 `goto`——竞赛里常见「检查到不合法就置 flag，外层 `break` 两次」的写法。</span>continue` 则要小心它不会跳过更新语句：`for` 循环的更新写在头部，`continue` 后仍会执行；但 `while` 循环里如果把更新放在循环体末尾，`continue` 会跳过它——这也是 `while` 与 `for` 最容易出差异的地方。

## 4 循环与分支的经典组合

循环和分支一旦组合，就能表达几乎一切「搜索 + 决策」的逻辑。三个竞赛起步期必练的经典模式：

**累加器与计数器**：在循环里维护一个累加变量，用于求和、计数、求平均值。先初始化，再在循环体内更新，最后输出——顺序不能乱。

**嵌套循环**：循环套循环，常用于二维表格、排列组合、矩阵遍历。时间复杂度是两个循环次数的乘积，$n$ 次外层乘 $n$ 次内层就是 $O(n^2)$——这个记法下一章《排序基础与时间复杂度分析》会正式引入。

**标记法（flag）**：用一个布尔变量记录「是否发生了某件事」，常用于素数判断、重复检查：

```c
int is_prime(int n) {
    if (n < 2) return 0;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return 0;
    return 1;
}
```

## 5 公式解析：求和的循环不变量

循环写得多了，会需要一个「为什么它是对的」的判断依据。最有力的工具是**循环不变量（loop invariant）**——一个在循环每次迭代前后都保持为真的性质。

以 $1 + 2 + \cdots + n$ 的求和为例，设第 $k$ 次迭代开始时，累加器 $s = 1 + 2 + \cdots + (k-1)$：

$$
s_k = s_{k-1} + k, \qquad s_0 = 0
$$

- **第一步，初始化**：$k = 1$ 时 $s = 0$，不变量「$s$ 等于前 $0$ 项之和」成立。
- **第二步，保持**：假设第 $k$ 步前 $s = 1 + \cdots + (k-1)$，执行 `s += k` 后 $s = 1 + \cdots + k$，不变量继续成立。
- **第三步，终止**：循环在 $k = n+1$ 时结束，此时 $s = 1 + \cdots + n$——不变量在每一步都成立，循环结束时恰好给出答案，循环的正确性就此证明。

**重点：循环不变量是「证明循环」的数学工具。** 初始化成立 → 保持时仍成立 → 终止时给出答案，「三步证明法」与归纳法一脉相承。竞赛里不必每题都写完整证明，但养成「我的循环每一步满足什么」这个追问，能抓出一大半差一错误。

## 6 小结

- 分支：`if/else if/else` 与 `switch`；`switch` 忘记 `break` 会「穿透」到下一个 case。
- 循环三要素：初始化、条件、更新；差一错误靠「闭区间还是开区间」想清再动笔。
- `break` 跳出一层、`continue` 跳过本轮；`while` 里 `continue` 会跳过循环体末尾的更新。
- 经典组合：累加器与计数器、嵌套循环、标记法 flag。
- 循环不变量三步证明：初始化 → 保持 → 终止。
