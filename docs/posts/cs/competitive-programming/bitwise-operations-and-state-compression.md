## 为什么从位运算与状态压缩开始

计算机底层只有 0 和 1，一切运算最终都是**位运算（bitwise operations）**。但位运算在竞赛里不只是「底层细节」——它是**最快的运算**（一条机器指令），自带优雅的数学性质（异或的自反性），更是**状态压缩（state compression）** 的基石：把「选了哪几个元素」这样的集合状态，压进一个整数的二进制位里。$n$ 个元素的所有子集用一个 `int` 就能表示，配合 DP 就能在指数级状态空间里高效转移。这一章，我们把这些「位级武器」一次补齐。

## 1 六种基本位运算

C/C++ 提供六种位运算符，作用在整数的每一个二进制位上：

| 运算符 | 名称 | 规则 | 示例 |
| --- | --- | --- | --- |
| `&` | 按位与 | 同 1 才 1 | `6 & 3 == 2` |
| `\|` | 按位或 | 有 1 就 1 | `6 \| 3 == 7` |
| `^` | 按位异或 | 相同为 0，相异为 1 | `6 ^ 3 == 5` |
| `~` | 按位取反 | 0 变 1，1 变 0 | `~0 == -1` |
| `<<` | 左移 | 整体左移，低位补 0 | `1 << 3 == 8` |
| `>>` | 右移 | 整体右移 | `8 >> 2 == 2` |

**核心概念：左移一位等于乘 2，右移一位等于整除 2。** `1 << k` 的值是 $2^k$，这是状态压缩里最常用的一条式子。<span class="marginnote">右移 `>>` 对<strong>无符号数</strong>是逻辑右移（高位补 0），对<strong>有符号负数</strong>是算术右移（高位补符号位）。竞赛里用右移做「取二进制位」时，建议配合无符号类型或先转正，避免负数右移的符号位干扰。</span>

## 2 异或的自反性：位运算的「和」

**异或（XOR）** 拥有一个其他位运算没有的优雅性质——**自反性**：`x ^ x == 0`，`x ^ 0 == x`。由此得到：

$$
a \oplus a = 0, \qquad a \oplus 0 = a, \qquad (a \oplus b) \oplus b = a
$$

**经典应用一：找唯一出现奇数次的数。** 数组中除一个数外都出现两次，找出它——把所有数异或起来，出现两次的成对抵消，剩下的就是答案。一次遍历 $O(n)$，空间 $O(1)$，比哈希表更省。

**经典应用二：交换两个数，不用临时变量。**

```cpp
a ^= b; b ^= a; a ^= b;   // a、b 交换（不推荐生产用，但理解异或的绝佳例子）
```

**辨析｜易错点：** 自反性依赖「每个数恰好出现偶数次」的前提。若某数出现三次，异或就不灵了——那时要回到逐位计数或哈希。异或的性质强大但挑剔，用之前先确认出现次数的奇偶结构。

## 3 公式解析：lowbit 与位操作技巧

**lowbit** 是一个高频位运算工具：提取一个数**最低位的 1**（及其后的 0）。

$$
\text{lowbit}(x) = x \ \& \ (-x)
$$

- **第一步，看 -x 的补码**：在补码表示里，`-x = ~x + 1`。`~x` 把 `x` 的每一位取反，`+1` 使得「最低位的 1 及其右边」在 `-x` 里仍是 1（其余位与 `x` 相反）。
- **第二步，逐位与**：`x & (-x)` 中，`x` 的 `1` 位与 `-x` 对应位：最低位那个 1 处两边都是 1，其余位置至少一边是 0。
- **第三步，得结果**：结果恰好是 `x` 的二进制里最低位 1 单独抽出，如 `lowbit(12) = lowbit(1100₂) = 100₂ = 4`。

**重点：lowbit 是树状数组的灵魂。** 树状数组（Fenwick Tree）靠 `x & (-x)` 找到「当前节点向上跳的区间长度」，也是《数论基础》里计算 `__builtin_ctz`（末尾零个数）的等价表达。<span class="marginnote">GCC 内置了一批位运算函数：`__builtin_popcount(x)` 数 1 的个数、`__builtin_ctz(x)` 数末尾零、`__builtin_clz(x)` 数前导零。这些都是一条指令，比手写循环快得多——竞赛里直接调用即可。</span>

## 4 状态压缩：用一个整数表示一个集合

**状态压缩（bitmask / state compression）**：用一个整数的第 $i$ 位表示「第 $i$ 个元素是否被选」。这样，一个**子集**就是一个整数 `mask`，集合运算变成位运算：

- 判断第 $i$ 个元素是否在集合里：`mask >> i & 1`。
- 加入第 $i$ 个元素：`mask |= (1 << i)`。
- 删除第 $i$ 个元素：`mask &= ~(1 << i)`。
- 集合大小：`__builtin_popcount(mask)`。

**经典应用：状态压缩 DP（旅行商问题 TSP）。** 求从起点出发、访问所有城市恰好一次、回到起点的最短路。状态定义 `dp[mask][u]` = **已访问城市集合为 mask、当前在 u 的最小路程**：

$$
dp[mask][u] = \min_{v \in mask, v \ne u} \big( dp[mask \setminus \{u\}][v] + dist(v, u) \big)
$$

```cpp
vector<vector<int>> dp(1 << n, vector<int>(n, INF));
dp[1 << 0][0] = 0;                       // 起点 0 已访问
for (int mask = 1; mask < (1 << n); mask++)
    for (int u = 0; u < n; u++) if (mask >> u & 1)
        for (int v = 0; v < n; v++) if (mask >> v & 1 && v != u)
            dp[mask][u] = min(dp[mask][u], dp[mask ^ (1 << u)][v] + dist[v][u]);
// 答案：访问完全部城市后回到起点
```

**重点：状态数是 $2^n \times n$，转移 $O(n)$，总复杂度 $O(n^2 2^n)$。** 这是 TSP 的最优已知精确解法，而它之所以可行，正是因为 `mask` 把「哪几个城市访问过了」压缩成了一个整数——`1 << n` 个状态用数组存得下（$n \le 20$ 时约 $10^6$ 个状态）。<span class="marginnote">去掉 `v != u` 的限制并把 `dp[mask ^ (1<<u)][v]` 理解成「从去掉 u 的状态走来」，是这题的转移核心。状态压缩 DP 的通用写法是：枚举 mask 从小到大，再枚举「最后加入/最后到达」的元素——`mask ^ (1<<u)` 是「把 u 从集合里去掉」的位运算表达。</span>

## 5 枚举子集的位运算技巧

状态压缩里还有一个高频技巧——**枚举一个集合的所有子集**：

```cpp
for (int sub = mask; sub; sub = (sub - 1) & mask) {
    // sub 是 mask 的一个非空子集
}
```

**核心概念：`(sub - 1) & mask` 跳到下一个子集。** 从 `mask` 本身开始，每次减一并与 `mask` 取交，会**按字典序从大到小**枚举出 mask 的全部子集，且中间不遗漏、不重复。<span class="marginnote">这个枚举所有子集的循环，总迭代次数是 $3^n$（每个元素有三种状态：在子集、在父集不在子集、都不在）而不是 $2^{2n}$。配合「子集 DP」能解决「划分集合」类问题——比如把集合分成两组使代价最小。</span>

**辨析｜易错点：** 子集枚举循环里，`sub` 会走到 0 结束——如果 `mask` 本身就是 0，循环一次也不执行。需要处理空子集时，要单独把 `sub = 0` 的情况补上。

**辨析｜易错点：** `mask` 枚举的顺序很重要。状态压缩 DP 要求「小的状态先算」，而 `mask` 的数值大小并不总是与「包含元素多少」一致——幸好任何子集的数值都小于包含它的超集，所以 `for mask = 1..(1<<n)-1` 从小到大枚举恰好满足拓扑序，这是状态压缩 DP 能直接用整数循环的原因。

## 6 小结

- 六种位运算：`&`、`|`、`^`、`~`、`<<`、`>>`；`1 << k == 2^k`。
- 异或自反性 `a^a=0, a^0=a`：找唯一出现奇数次、无临时变量交换。
- lowbit：`x & (-x)` 提取最低位 1，是树状数组的基石。
- 状态压缩：一个整数 `mask` 表示集合，第 i 位表示第 i 个元素是否被选。
- TSP 状态压缩 DP：`dp[mask][u]`，状态数 $2^n$，复杂度 $O(n^2 2^n)$。
- 枚举子集 `(sub-1) & mask`：$3^n$
