# 算法竞赛与编程实践

算法竞赛以高效算法设计与系统化题型训练为核心，是锤炼编程能力、数据结构功底与算法思维的最有效路径之一。以刘汝佳《算法竞赛入门经典》为纲，配合 LeetCode 实战题单，从语言基础、数据结构、高效算法到图论与数学方法，系统重建算法竞赛的完整知识体系。

## 对标教材

- 刘汝佳《算法竞赛入门经典》（第2版，2014）
- LeetCode 力扣题库（算法与数据结构专题）
