## 为什么从函数开始

到目前为止，程序还是一长条自上而下执行的语句。要写真正的软件，必须把逻辑拆成**函数（function）**：一个「输入参数 + 返回类型 + 函数体」的命名单元。函数是 C++ 三种范式（过程式、面向对象、泛型）的最小公共单元——类的成员是函数，模板实例化出来的是函数，甚至运算符重载底层也是函数。第6章把函数讲透：**参数如何传递**（值、引用、const 引用）、**返回值**的三种形态、**重载**如何决议、**默认实参**与 **inline** 的取舍。<span class="marginnote">「把一段逻辑命名、封装、复用」是人类组织大规模软件的最基本手段。C++ 的函数在 C 的基础上加了重载、默认实参、inline、constexpr、lambda 五件装备，理解它们各自的适用场景，是写出可读、可维护代码的起点。</span>

## 1 函数声明与定义

**函数定义（definition）**包含返回类型、名字、形参列表与函数体；**函数声明（declaration）**只有前三者、以分号结尾，不写函数体：

```cpp
int factorial(int n);        // 声明：只告诉编译器签名
int factorial(int n) {       // 定义：带函数体
    return n <= 1 ? 1 : n * factorial(n - 1);
}
```

**重点：** C++ 要求「**先声明、后使用**」——函数被调用前必须至少出现一次声明。多文件程序里，函数声明放在**头文件**，定义放在**源文件**，每个调用它的翻译单元只需 include 头文件。这和第2章 `extern` 的「声明不定义」逻辑一脉相承。<span class="marginnote">头文件只放声明、不放定义，是为了避免「同一函数被重复定义」的链接错误。这也是第4篇 Effective C++ 第31条「最小化编译期依赖」的基础：头文件变化会让所有 include 它的文件重新编译。</span>

## 2 参数传递：值、引用与 const 引用

**按值传递（pass by value）**：形参是实参的**拷贝**，函数内修改不影响调用者。对 `int`、`double` 这类小类型，这是默认且高效的选择。

**按引用传递（pass by reference）**：形参是实参的**别名**，不拷贝、可修改实参。代价是函数与调用者共享同一对象——**想改实参就用它**。

**按 const 引用传递**：`const T &` 既不拷贝、也不允许修改。**这是「读大对象」的标准姿势**——传 `std::string`、`std::vector`、类对象时，按值拷贝整个容器的开销远高于绑定一个引用。<span class="marginnote">C++ Primer 第6章的建议非常明确：<strong>读大对象用 `const &`，写大对象用 `&`，只有小内置类型才按值</strong>。Effective C++ 第20条把这条扩写成一条铁律——「尽量以 pass-by-reference-to-const 取代 pass-by-value」，我们到第五篇再展开。</span>

```cpp
void f(int x);                    // 按值：x 是拷贝
void g(int &x);                   // 按引用：可改实参
void h(const std::string &s);     // const 引用：只读不拷贝
```

**数组参数**是个老坑：数组名会退化为指针，`void f(int a[10])` 与 `void f(int *a)` 是同一个函数——数组长度信息在参数传递时丢失。C++11 后推荐用 `void f(const std::vector<int> &)` 或 `std::array` 承载定长数组。

## 3 返回值：值、引用与初始化的位置

**返回值（return value）**最常用的是**按值返回**——返回临时对象，安全直观。**返回引用**意味着把「某个已存在对象的别名」交出去，调用者可以修改它；**但绝不能返回对局部变量的引用**——函数结束后局部变量已销毁，留下的悬空引用是未定义行为。<span class="marginnote">「返回局部对象的引用」是最常见的悬垂引用来源之一，Effective C++ 第21条专门警告「别返回局部对象的引用」。检查方法很朴素：返回的东西在函数结束后还活着吗？活着才能用引用返回。</span>

**返回值优化（RVO，return value optimization）**：`return 表达式;` 构造的临时对象，编译器可以**直接构造到调用者目标位置**，省去一次拷贝。这是「零开销抽象」在函数返回值上的体现，第13章拷贝控制还会见到它。

## 4 重载：同名函数，不同签名

**重载（overload）**：同一作用域内，**多个函数同名、但形参列表不同**（数量或类型不同）。调用时编译器按实参选择最匹配的版本：

```cpp
void print(const char *s);
void print(const std::string &s);
void print(int n);
void print(double d);

print("hello");        // → print(const char*)
print(42);             // → print(int)
print(3.14);           // → print(double)
```

**重载决议（overload resolution）**按「精确匹配 > 提升 > 标准转换」的次序挑最优者；**仅返回类型不同不算重载**（无法决议），**仅形参名不同也不算**。重载让「同一操作、不同类型」的调用统一——这是 C++ 面向对象与泛型之间的桥。<span class="marginnote">重载的本质是「用名字表达语义，让编译器替你把类型分发出去」。它与第16章的模板各占一席：重载针对「有限的已知类型」，模板针对「未知的任意类型」。二者叠加时（模板重载）规则更微妙，第16章再谈。</span>

## 5 默认实参、inline 与 constexpr 函数

**默认实参（default argument）**给形参预置值，调用时可省略：

```cpp
void greet(const std::string &name, const std::string &greeting = "你好");
greet("张三");                          // greeting 取默认值
greet("李四", "早上好");
```

规则：**默认实参必须从右边连续给出**（`int f(int a, int b = 0, int c = 1);`），不能「中间缺省、右边不省」。<span class="marginnote">默认实参只在<strong>声明处</strong>填写，且「声明与定义分开时，默认实参写在声明里」。一旦某个参数有默认值，它右边所有的参数都必须有默认值——这是「从右向左缺省」的原因。</span>

**inline 函数**：把函数体在调用点**内联展开**，省去函数调用开销：

```cpp
inline int max(int a, int b) { return a > b ? a : b; }
```

`inline` 是对编译器的**建议**而非命令，且**对每个翻译单元可见**（通常写在头文件里）。它对「小而热」的函数有用；对几十行的大函数，内联反而让代码膨胀。

**constexpr 函数**：**能在编译期求值**的函数，返回类型与形参必须是字面量类型，函数体可含一条 `return`（C++11）或多条语句（C++14）：

```cpp
constexpr int square(int x) { return x * x; }
constexpr int k = square(5);   // 编译期算出 25
```

**函数指针**：函数也有「地址」，可以存进变量、传参、作为回调。`int (*fp)(int, int)` 声明一个「指向『两个 int、返回 int』函数的指针」，`fp = add;` 赋值、`fp(3, 4)` 调用。函数指针与重载的配合点是：**拿重载函数名赋值给指针时，编译器按指针的签名挑选匹配的重载**。现代 C++ 里函数指针多被 `std::function` 与 lambda 取代（第10章），但它仍是理解回调机制的起点。

## 6 核心对比表：三种传递方式

| 维度 | 按值 `T` | 按引用 `T&` | 按 const 引用 `const T&` |
| --- | --- | --- | --- |
| 是否拷贝 | 拷贝 | 不拷贝 | 不拷贝 |
| 能否改实参 | 否 | **能** | 否 |
| 大对象开销 | 高（整块拷贝） | 低 | 低 |
| 适用 | 小内置类型 | 需要改实参 | **读大对象（首选）** |
| 悬空风险 | 无 | 低 | 低 |

## 7 小结

- 函数**先声明后使用**；声明放头文件、定义放源文件。
- **按值**传小类型、**按 const 引用**读大对象、**按引用**改实参；数组参数会退化指针。
- **别返回局部变量的引用**；RVO 让「按值返回」零开销。
- **重载**靠「同名不同形参列表」实现类型分发；仅返回类型不同不算重载。
- **默认实参**从右往左缺省、写声明不写定义；**inline** 是内联建议；**constexpr** 函数编译期可求值。
- 函数是三种范式的公共单元——这一章的所有规则在成员函数、模板、lambda 里都会复现。
