# C++ 编程

C++ 是一门同时支持过程式、面向对象与泛型三种范式的系统编程语言，广泛用于操作系统、游戏引擎、高性能计算与嵌入式等领域。它让你既能贴近硬件掌握内存与资源管理的细节，又能借助模板与 RAII 写出安全、可复用的抽象，是深入理解计算机系统与写出高性能代码的必修语言。

## 对标教材

- Stanley B. Lippman、Josée Lajoie & Barbara E. Moo, "C++ Primer"（第5版, 2013）
- Scott Meyers, "Effective C++: 55 Specific Ways to Improve Your Programs and Designs"（第3版, 2005）
