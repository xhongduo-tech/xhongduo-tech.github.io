## 为什么从程序结构开始

任何语言的第一课都是「让机器跑起来」，而 C++ 的第一课特别值得慢下来：它要你同时看清三件事——**源码如何被组织**、**文本如何变成可执行文件**、**程序如何与外界通信**。这三件事在 Python、JavaScript 里被刻意隐藏了，在 C++ 里却写在明面上。看懂一个最小的 `main` 函数，等于拿到了理解整个 C++（以及后面的操作系统、编译器、程序分析）的钥匙。<span class="marginnote">C++ 由斯特劳斯特鲁普于 1979 年起在贝尔实验室开发，最初叫「带类的 C」（C with Classes），1983 年更名 C++。它承接 C 的过程式内核，又叠加了类、模板与异常三大体系，是本专题后面的全部主线。</span>本专题后续所有博文都以本章的编译模型为前提，所以先用一篇把地基打牢。

## 1 一个最小的 C++ 程序

打开任何一本 C++ 教材，第一段代码几乎都是向标准输出打印一行问候。C++ Primer 的版本长这样：

```cpp
#include <iostream>

int main()
{
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

这 8 行里已经塞满了 C++ 的核心语法，逐行看：

**`#include <iostream>`** 是**预处理指令**：在编译开始前，把标准输入输出流的声明「粘贴」进源文件。`<iostream>` 是一个**头文件**，它声明了 `std::cin`、`std::cout`、`std::endl` 等名字。
**`int main()`** 定义**主函数**：`main` 是程序的入口点，操作系统加载程序后第一个调用的就是它。`int` 是返回值类型，`()` 表示它不接受参数（也可以写 `int main(int argc, char *argv[])` 接收命令行参数）。
- **函数体**由一对花括号 `{ }` 括起来，里面是函数要执行的语句。
- **`std::cout << "..." << std::endl;`** 是**输出语句**：`<<` 是**输出运算符**，把右侧的内容送入左侧的**输出流** `std::cout`。`std::endl` 表示换行并冲刷缓冲区。
- **`return 0;`** 向操作系统返回退出码：返回 0 表示程序正常结束，非零值表示出错。<span class="marginnote">`main` 是唯一允许省略 `return` 的函数——C++ 规定控制流走到 `main` 末尾时，相当于隐式执行 `return 0;`。但显式写出返回值是一种更清晰的习惯。</span>

**`std::` 前缀**是本章最容易被忽略、却最重要的记号：它表示名字 `cout` 位于**命名空间 `std`** 中。命名空间是 C++ 用来避免名字冲突的机制——标准库所有名字都被放进 `std`，这样你的变量叫 `cout` 也不会撞车。完整的命名空间体系要到第18章才展开，但从第一天起就要习惯带着 `std::` 前缀。

## 2 输入、输出与流

程序与外界的通信靠**流（stream）**完成。**流**是一条「字节的水管」：程序向流中写数据、从流中读数据，不需要关心数据最终落在哪里——是屏幕、文件还是网络。

标准库提供四个预定义流对象，都声明在 `<iostream>` 里：

| 对象 | 方向 | 默认连接 | 用途 |
| --- | --- | --- | --- |
| `std::cin` | 输入 | 标准输入（键盘） | 读入数据 |
| `std::cout` | 输出 | 标准输出（屏幕） | 输出普通数据 |
| `std::cerr` | 输出 | 标准错误 | 输出错误信息（不缓冲） |
| `std::clog` | 输出 | 标准错误 | 输出日志信息（缓冲） |

一次完整的「读进来、算一算、写出去」循环用 `cin` 与 `cout` 配合完成：

```cpp
#include <iostream>

int main()
{
    int a, b;
    std::cout << "请输入两个整数：";
    std::cin >> a >> b;
    std::cout << "它们的和是 " << a + b << std::endl;
    return 0;
}
```

这里出现了输入运算符 `>>`：它从 `std::cin` 中**依次提取**一个值存入变量。`std::cin >> a >> b` 等价于 `(std::cin >> a) >> b`——输入运算符也是**返回流本身**的，所以可以链式书写。<span class="marginnote">链式调用的设计根源于运算符的返回类型：`<<` 与 `>>` 都返回左操作数的引用，因此 `a << b << c` 才能从左到右逐段展开。这个「返回自身以便继续链式」的模式，在后面的插入器、赋值链与重载运算符里反复出现。</span>若用户输入的不是整数，`cin` 会进入**错误状态**，后续读取全部失效——这种**流状态（stream state）**机制，是第8章 IO 库的正式主题。

## 3 编译与链接：从源码到可执行文件

Python 是**解释执行**：源码被解释器一边读一边跑。C++ 是**编译执行**：源码要经过两个阶段才能成为可运行的程序——**编译（compile）**与**链接（link）**。

```text
hello.cpp ──编译器──> hello.o ──链接器──> hello（可执行文件）
            (编译)              (链接)
```

**编译**：编译器把每个 `.cpp` 源文件单独翻译成**目标文件（object file）**（Unix 下后缀 `.o`）。目标文件里的指令还不能运行——它调用外部函数时只记下一个「未解析的引用」，不知道函数在哪。
**链接**：链接器把多个目标文件与**库**合并，把每个「未解析的引用」解析成真实的地址，最终产出一个可执行文件。你写的函数可能在另一个 `.cpp` 里，你用的标准库函数可能在 `libstdc++` 里——**链接器负责把它们拼成一个整体**。

为什么把编译和链接分开？因为它们是两种不同的**依赖关系**。假设你改了 `foo.cpp` 里一个函数的内部实现，但没动它的接口：编译器只需重新编译 `foo.cpp`，其余 `.o` 文件原样复用，最后再链接一次——大型项目（比如游戏引擎）动辄几百万行，这种**增量编译**能省下数十分钟的构建时间。

一个常见误区是把「预处理、编译、链接」混为一谈。完整的流水线其实是四步：**预处理**（处理 `#include`、`#define` 等指令）→ **编译**（C++ 源码 → 汇编）→ **汇编**（汇编 → 机器码目标文件）→ **链接**（目标文件 + 库 → 可执行文件）。<span class="marginnote">在命令行里，`g++ hello.cpp -o hello` 一条命令就把四步全包办了；加 `-c` 只编译不链接，产出 `.o` 文件。调试用的 `-g`、优化用的 `-O2` 都作用在编译阶段——这些标志在第三级《Linux 命令行》与《编译原理》里会展开细讲。</span>本专题不深入编译器实现，但你必须建立起「源文件是文本、可执行文件是机器码、中间隔着链接」这张地图，否则后面遇到的「链接错误」（undefined reference）会显得毫无头绪。

## 4 代码解析：主函数逐行拆解

理解 C++ 程序，就是把每一条语句拆回它的语法成分。我们选上面求和程序的 `main` 函数做逐行解析：

```cpp
int main() {
    int a, b;                        // ① 声明
    std::cout << "请输入：";          // ② 提示
    std::cin >> a >> b;              // ③ 读取
    std::cout << "和是 " << a + b
              << std::endl;          // ④ 输出
    return 0;                        // ⑤ 返回
}
```

- **① 声明（declaration）**：`int a, b;` 定义两个 `int` 类型的变量。C++ 规定**变量必须先声明后使用**——这行之后，`a` 与 `b` 才在作用域内可见。声明与定义的区别、初始化与赋值的区别，是第2章《变量与基本类型》的开场。
- **② 提示输出**：`std::cout << "请输入："` 把字符串字面量 `"请输入："` 送入输出流。注意字符串用双引号，字符常量用单引号，二者不可互换。
- **③ 链式读取**：`std::cin >> a >> b` 展开为 `((std::cin >> a) >> b)`。第一个 `>>` 读到 `a`，返回 `std::cin`；第二个 `>>` 再读到 `b`。输入运算符会自动跳过开头的空白字符（空格、换行、Tab）。
- **④ 链式输出**：`a + b` 先被求值，得到整数结果，再被 `<<` 依次送入流；两个 `<<` 之间换了行，说明 C++ 语句可以跨行，**分号才是语句的结束标记**。
- **⑤ 返回退出码**：`return 0;` 结束 `main` 并把 0 交还操作系统。壳程序里可以用 `echo $?`（Linux/macOS）看到这个值。

这段解析里隐藏着 C++ 两条最重要的直觉：**一切皆表达式**（`a + b` 是表达式，`std::cin >> a` 也是表达式，它们都有值），以及**运算符的求值顺序由结合律决定**。这两点将在第4章《表达式与运算符》里被彻底讲透。

## 5 小结

- 一个 C++ 程序至少有一个 `main` 函数，它是操作系统调用的**入口点**，返回 0 表示成功。
- **头文件**用 `#include` 引入，`std::` 前缀表示名字位于**命名空间 `std`**，避免命名冲突。
- **流（stream）**是程序与外界的字节通道：`cin` 读入、`cout` 输出、`cerr` 报告错误，`<<` 与 `>>` 都是链式运算符。
- C++ 是**编译执行**的语言：源码经预处理、编译、汇编、**链接**四步成为可执行文件；链接负责把各目标文件中的未解析引用拼成整体。
- 变量先声明后使用，语句以**分号**结尾，函数体由花括号包裹。

在下一节，我们将从 `int a;` 这句最简单的声明出发，把 C++ 的类型系统彻底拆开——从内置类型、变量初始化，到 `const`、引用与 `auto`，这就是**变量与基本类型**。
