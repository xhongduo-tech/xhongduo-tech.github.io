## 为什么从复合语句与条件语句开始

控制结构的两个基础构件是**复合语句（compound statement）**与**条件语句（conditional statement）**。复合语句把多条语句「捆」成一个逻辑单元（C 系的 `{ ... }`），是「顺序」原语的语法载体；条件语句实现「选择」原语——`if/else` 是最古老也最普遍的决策构造。两者合起来构成了几乎所有程序的主体骨架。这一节先把这两个「地基构造」讲透，特别是条件语句在各语言里的语义差异：悬挂 else 如何解决、条件分支是语句还是表达式、`elif`/`else if` 的嵌套形态。<span class="marginnote">复合语句是「块」的语法形态（第六篇已从作用域角度看过），条件语句是「选择」的控制形态。两者的结合点：`if` 的每个分支都放一个复合语句，从而让「单入口单出口」在每个分支内部也成立。</span>

## 1 复合语句：把多条语句捆成一条

**复合语句（compound statement）**：用定界符括起来的一组语句，语法上视为一条语句。C 系用 `{ ... }`，Python 用缩进，Ada 用 `begin ... end`。

```c
{
    int tmp = a;
    a = b;
    b = tmp;
}
```

复合语句的价值：

- **需要多条语句的位置**：`if` 分支、`while` 体、函数体都要求「一条语句」，复合语句让多条语句伪装成一条。
- **引入块作用域**：复合语句内的声明不外泄（第六篇讲过）。
- **可嵌套**：复合语句内可以再有复合语句，形成层次结构。<span class="marginnote">注意「复合语句」与「块」的关系：C 里它们重合（`{}` 既捆语句又建作用域）；但 Ada 的 `begin ... end` 与声明区是分开的，Python 的缩进块建作用域而 `for` 体不建。不同语言对「捆」与「作用域」的绑定程度不同。</span>

## 2 条件语句：if/else 的基本形态

**条件语句（conditional statement）**：根据布尔条件选择执行分支。

```c
if (score >= 60) {
    printf("pass");
} else {
    printf("fail");
}
```

基本语义：条件为真执行 `then` 分支，为假执行 `else` 分支（若存在）。语言间的差异集中在语法细节：

- **条件是否必须布尔**：C 接受任意值（非零为真）；Java/Rust/Python 必须布尔。
- **括号**：C 系必须 `if (cond)`；Python 无括号 `if cond:`。
- **else-if 链**：`else if` 实现多级条件，Python 用 `elif` 关键字。

## 3 悬挂 else：经典文法歧义

**悬挂 else（dangling else）**：当 `if` 没有 else，且嵌套另一层 if 时，`else` 到底属于哪个 `if`？

```c
if (a)
    if (b)
        x = 1;
    else        /* 这个 else 属于哪个 if？ */
        x = 2;
```

C 的规则：**else 与最近的未匹配 if 结合**——上述 `else` 属于 `if (b)`。这是所有主流语言的约定（就近匹配）。<span class="marginnote">「就近匹配」是 C 系、Java、Python 的默认。但文法上这个问题来自二义性——第二篇讲过，语法分析器通过「优先匹配内层 if」的规则消解。写代码时用花括号显式分组，可以完全避免误解。</span>

**辨析｜易错点：** 悬挂 else 的本质是文法二义性，不是「else 的行为怪」。两种消除方式：① 语言规定「就近匹配」（大多数）；② 用 `elif` 避免嵌套（Python 的 `elif` 让 else-if 链扁平化，从源头上不产生悬挂）。**悬挂 else 提醒我们：语法细节可以决定语义**。

## 4 条件表达式：if 的表达式形态

许多现代语言提供「if 的表达式形态」——`if` 作为一个**产生值**的表达式，而非仅执行分支的语句。

**三元运算符（ternary operator）**：

```c
int max = (a > b) ? a : b;   /* C/Java/JS：条件 ? 真值 : 假值 */
```

**if 表达式**（Rust、Kotlin、Python 的条件表达式）：

```rust
let max = if a > b { a } else { b };   // Rust：if 是表达式
```

```python
max = a if a > b else b                # Python 条件表达式
```

**辨析｜易错点：** 语句 if 与表达式 if 的区别：语句 if **不产生值**（只执行副作用），表达式 if **必须产生值**（每个分支都要有结果）。Rust 的 `let x = if ...` 要求分支类型一致，否则编译错误。**「if 是不是表达式」是现代语言提升表达力的一步**——少写临时变量，让逻辑更声明式。

## 5 公式解析：条件语句的语义

条件语句的语义（操作语义风格）可以用分支规则刻画：

$$
\frac{\mathcal{B}(B)(\sigma) = \text{true} \quad \langle S_1, \sigma \rangle \Rightarrow \sigma'}{\langle \text{if}\ B\ \text{then}\ S_1\ \text{else}\ S_2, \ \sigma \rangle \Rightarrow \sigma'}
$$

$$
\frac{\mathcal{B}(B)(\sigma) = \text{false} \quad \langle S_2, \sigma \rangle \Rightarrow \sigma'}{\langle \text{if}\ B\ \text{then}\ S_1\ \text{else}\ S_2, \ \sigma \rangle \Rightarrow \sigma'}
$$

三步拆解：

- **第一步，两条规则**：条件为真走规则一（执行 $S_1$），为假走规则二（执行 $S_2$）——**每条路径都是一次「求值条件 + 执行分支」的顺序组合**。
- **第二步，看存储**：$\sigma$ 是执行前状态，$\sigma'$ 是分支执行后的状态。**只走一个分支**——未选中的分支不执行，其副作用不发生。这是「选择」的语义核心。
- **第三步，看单出口**：两条规则的结论都以 $\sigma'$ 结束——无论走哪条分支，控制都汇合到结构出口。**「分支分裂、出口汇合」正是单入口单出口的形式化**。

**辨析｜易错点：** 条件里放**副作用表达式**的语义要注意：`if (x = 1)` 在 C 里是先赋值再判真（永真）；Python/Rust 直接编译错误。**「条件必须是纯布尔」让 if 语义更可预测**——现代语言普遍收紧这一点。

## 6 小结

- **复合语句**把多条语句捆成一条，同时常引入块作用域。
- **条件语句**实现选择：`if/else` 的基本语义是「真走 S1、假走 S2，只走一支」。
- **悬挂 else** 由「就近匹配」消解；`elif` 扁平化 else-if 链，从源头避免歧义。
- **条件表达式**（三元/if 表达式）让 if 产生值，是现代语言的表达力升级。
- 条件语义：条件求值 + 分支执行 + 出口汇合，形式化即「两条分支规则」。
