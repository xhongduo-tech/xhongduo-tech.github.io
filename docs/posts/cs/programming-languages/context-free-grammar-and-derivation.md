## 为什么从上下文无关文法开始

上一节我们立住了「语法、语义、文法、语言」四个概念，并把它们串成公式 $L(G) = \{ w \in \Sigma^{*} \mid S \overset{*}{\Rightarrow} w \}$。但那个公式里还欠一个精确的对象：**文法 $G$ 到底长什么样？** 这一节回答这个问题。

答案是一类特殊的文法——**上下文无关文法（context-free grammar, CFG）**。它是描述程序设计语言语法的标准工具：一门语言的表达式、语句、声明，几乎都能用 CFG 写下来。理解 CFG，是理解 BNF（下一节）、理解编译器如何解析（第四级《编译原理》专题）、甚至理解语言设计（为什么某些语言的结构「天生」难解析）的共同前提。

## 1 文法的形式定义：四个部件

**上下文无关文法（context-free grammar）**：一个四元组 $G = (V, T, P, S)$，其中：

- **非终结符（nonterminal）集合 $V$**：出现在推导过程中、还会被继续替换的符号，通常用大写字母或尖括号表示。
- **终结符（terminal）集合 $T$**：构成句子的基本符号，不再被替换，如 `+`、`*`、`id`、`(`。
- **产生式（production）集合 $P$**：形如 $A \to \alpha$ 的规则，读作「$A$ 可以改写成 $\alpha$」，其中 $A$ 是非终结符，$\alpha$ 是终结符与非终结符组成的串。
- **开始符号（start symbol）$S$**：推导的起点，$S \in V$。

用一个描述算术表达式的文法来落地：

```
E -> E + T | E - T | T
T -> T * F | T / F | F
F -> ( E ) | id
```

这里 $V = \{E, T, F\}$，$T = \{+, -, *, /, (, ), id\}$，$S = E$。竖线 `|` 表示「或」：`E -> E + T | E - T | T` 是三条产生式的缩写。<span class="marginnote">非终结符对应自然语言里的「短语类别」（名词短语、动词短语），终结符对应「词」本身；产生式就像改写规则——「名词短语」可以被改写成「形容词 + 名词短语」或直接是一个「名词」。语法就是一组改写规则。</span>这套三层结构 `E（表达式）→ T（项）→ F（因子）` 不是随意的：每一层把一类运算夹在下一层之间，正是下一篇文章《二义性、运算符优先级与结合性》要展开的关键设计。

**核心要点**：文法用「有限条产生式」递归地刻画「无限个句子」。递归——产生式的右部可以再次出现该非终结符——是文法表达力的源泉。

## 2 推导（derivation）：一步一步替换

**推导（derivation）**：从开始符号 $S$ 出发，反复用产生式把某个非终结符替换成它的右部，直到得到一个只含终结符的串。每做一次替换，就前进「一步」。

以 `id + id * id` 为例，做一次**最左推导（leftmost derivation）**——每次都替换最左边的非终结符：

```
E
=> E + T          用 E -> E + T
=> T + T          用 E -> T
=> F + T          用 T -> F
=> id + T         用 F -> id
=> id + T * F     用 T -> T * F
=> id + F * F     用 T -> F
=> id + id * F    用 F -> id
=> id + id * id   用 F -> id
```

箭头 $\Rightarrow$ 表示一步替换，右边标注了所用到的产生式。第八步之后，串里只剩终结符，推导结束。<span class="marginnote">「最左推导」与「最右推导」对称存在：最右推导每次都替换最右边的非终结符。两条路线最终得到同一个句子，只是替换的先后不同。自上而下的语法分析器（top-down parser）模拟最左推导，自下而上的语法分析器（bottom-up parser）做最右推导的逆过程——这是第四级《编译原理》专题的核心内容。</span>

**辨析｜易错点：** 推导的方向不能反着理解。文法规定的是「$A$ 能改写成 $\alpha$」（从 $A$ 到 $\alpha$），所以推导是「从开始符号往下长」的过程；「把 `id + id * id` 归约回 $E$」叫**归约（reduction）**，是推导的逆过程，别把两者混为一谈。

## 3 句子、句型与语言

推导中途产生的串，和最终得到的串，名称不同：

- **句型（sentential form）**：推导过程中任何一步得到的串，可以仍含非终结符。上面八步里的每一步都是一个句型。
- **句子（sentence）**：不含任何非终结符的句型，即只由终结符组成的串。`id + id * id` 是句子，`E + T` 不是。

于是语言的精确定义可以重写为：**文法 $G$ 的语言 $L(G)$，是 $G$ 的全部句子的集合**。

$$
L(G) = \{\, w \in T^{*} \mid S \overset{*}{\Rightarrow} w \,\}
$$

注意这里的字符表是终结符集 $T$（而非上一节笼统的 $\Sigma$）。<span class="marginnote">一个文法生成的语言可能无限：比如文法 `E -> E + E | id` 能生成 `id`、`id + id`、`id + id + id`、……无穷多个句子，而文法本身只有两条产生式。「有限规则 ↔ 无限语言」是形式语言理论最迷人的一点。</span>

## 4 语法分析树（parse tree）

推导是「过程」，而**语法分析树（parse tree）**把同一结构画成「图」：每个内部结点是一个非终结符，叶结点是终结符，从根到叶的分支对应产生式的展开。`id + id * id` 在上一节文法下的语法分析树如下。

![表达式 id + id * id 的语法分析树](/images/programming-languages/context-free-grammar-and-derivation-1.svg)

读这棵树有三条要点：

- **叶子从左到右拼起来，就是句子**：`id + id * id`。所以语法树是「句子如何由文法生成」的静态快照。
- **树的形状编码了结构**：`*` 所在的子树比 `+` 所在的子树更「深」，叶结点 `id` 被先并入 `F`、再并入 `T`、最后并入 `E`——这就是表达式里乘法先于加法的结构性来源。
- **一棵树 ≠ 一种推导**：同一个句子可以有不同的推导顺序（最左、最右……），但它们可能对应同一棵语法树。语法树消除的是「顺序」，保留的是「结构」。<span class="marginnote">这正是语法树的价值：它比推导更「本质」。编译器要的不是「如何一步步推」，而是「最终长成什么结构」——语法树就是那个结构，也是后续语义分析、代码生成的输入。</span>

**辨析｜易错点：** 最左推导与最右推导得到的是**同一棵**语法树（对无二义文法而言），不是两棵。「推导不同」不等于「结构不同」；只有**两棵结构不同的语法树**才说明问题——这就是下一篇文章《二义性》的伏笔。

## 5 公式解析：推导的一步

把「一步推导」单独拎出来，它是整个文法理论里最小的动作：

$$
\alpha\, A\, \beta \;\Rightarrow\; \alpha\, \gamma\, \beta, \qquad A \to \gamma \in P
$$

逐项拆解：

- **第一步，认识 $\alpha$ 与 $\beta$**：它们是 $A$ 两边的**上下文（context）**——当前句型里位于被替换非终结符前、后的两段串，可能是空串。
- **第二步，认识 $A$**：被替换的非终结符。这一步选哪个非终结符，由推导策略决定（最左 / 最右 / 任意）。
- **第三步，认识 $\gamma$**：产生式 $A \to \gamma$ 的右部，替换后 $A$ 的位置变成 $\gamma$。
- **第四步，读懂「上下文无关」**：产生式 $A \to \gamma$ 的**右部不依赖于 $\alpha$、$\beta$**——无论 $A$ 出现在什么上下文里，替换规则都一样。这正是「上下文无关」四个字的含义，也是它区别于上下文有关文法的本质。

举个例子：句型 `id + T * F` 中，若取 $A = T$、$\alpha = \text{id + }$、$\beta = \text{ * F}$，用产生式 $T \to F$ 替换，就得到 `id + F * F`——与第 2 节推导的第六步完全一致。**「上下文无关」是 CFG 可高效解析的根源**：解析器不需要回头检查替换发生时周围是什么，规则是局部的、确定的。

## 6 小结

- **上下文无关文法**是四元组 $G = (V, T, P, S)$：非终结符、终结符、产生式、开始符号。
- **推导**是从 $S$ 出发、反复用产生式替换非终结符的过程；**最左 / 最右推导**是两种规范策略。
- **句型**可含非终结符，**句子**只含终结符；**语言** $L(G)$ 是全部句子的集合。
- **语法分析树**把推导画成树：内部结点是非终结符，叶结点从左到右拼成句子；一棵树代表一种结构，可对应多种推导顺序。
- 一步推导 $\alpha A \beta \Rightarrow \alpha \gamma \beta$ 的右部与上下文无关，这是「上下文无关」得名之处，也是 CFG 可高效解析的根源。
- 有限文法生成无限语言，「有限规则 ↔ 无限句子」是形式语言的核心张力。
