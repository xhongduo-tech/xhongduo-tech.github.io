## 为什么从码分复用开始

复用家族里，FDM 按频率分、TDM 按时间分、WDM 按波长分——它们都是把资源「切碎分给众人」。但 **码分复用（CDM，Code Division Multiplexing）** 换了一条完全不同的路：**所有用户同时、同频地发送，靠各不相同的「码序列」来区分彼此。**<span class="marginnote">CDMA（Code Division Multiple Access，码分多址）是 CDM 在无线多址场景的落地——2G/3G 时代的 IS-95、CDMA2000、WCDMA 都基于它。理解 CDMA 的关键，是一套小小的向量代数：每个用户分到一条「正交码」，谁跟谁的码正交，谁就听不到谁。</span>

这一节是物理层少有的「线性代数上场」的地方：一组码序列构成一组**正交向量**，通信双方靠内积来「解锁」信号。它也是连接「线性代数」与「网络」的绝佳桥梁。

## 1 CDM 的思想：正交码当「暗号」

CDM 的核心设定：**每个用户被分配一个唯一的码片序列（chip sequence）**，各用户的码片序列**两两正交**。发送数据时，用户用自己的码片序列去「扩展」数据比特；接收端用同样的码片序列做内积，就能从混在一起的所有信号中，把属于自己那一份「提取」出来。

具体规则（设码片长度为 8）：

- 每个比特用 8 个码片（chip）表示，记为向量。例如用户 A 的码片 $S = (1, -1, -1, 1, -1, 1, 1, -1)$。
- 发送比特 1 时，发送码片 $S$；发送比特 0 时，发送码片的**反码 $-S$**。<span class="marginnote">把「1 发原码、0 发反码」记牢，这是 CDMA 编码的第一条规则。芯片速率（chip rate）是数据速率的 8 倍，所以 CDMA 以「扩频」为代价换取多址能力——这正是「扩频通信」的由来。</span>
- 所有用户的信号在信道上**叠加**成一条总和信号，接收端各取所需。

**辨析｜易错点：** 码片不是「密码」——它不加密数据，而是「扩频」。**CDMA 的安全性来自正交性，不是保密性**：任何用户都能收到总和信号，但只有持匹配码片的接收端能解出数据。把 CDMA 理解成「加密」，是常见的误解。

## 2 公式解析：正交码怎么「过滤」出自己

CDMA 能工作的数学根基是**码片的正交性**。设两个用户 A、B 的码片分别为 $S$ 和 $T$，码片长度为 $m$，则要求：

$$
S \cdot T = \frac{1}{m} \sum_{i=1}^{m} s_i t_i = 0, \qquad S \cdot S = 1
$$

- **第一步，看内积的定义**：$S \cdot T$ 是两个码片向量逐位相乘后求平均（归一化内积）。它衡量两个向量「有多像」。
- **第二步，$S \cdot T = 0$ 意味着正交**：A 与 B 的码片完全不同（平均来看点积为 0），所以 B 的信号对 A 来说「听不见」。
- **第三步，$S \cdot S = 1$ 意味着自相关为 1**：码片与自己内积为 1，表示「我认得自己的暗号」。

接收端恢复数据的完整过程：设 A 收到叠加信号 $R$（所有用户信号之和），其中 $R = S + T + \cdots$，A 用码片 $S$ 做内积：

$$
S \cdot R = S \cdot (S + T + \cdots) = S \cdot S + S \cdot T + \cdots = 1 + 0 + \cdots = 1
$$

内积结果为 **1 说明 A 发出的比特是 1**；若 A 发的是 0，则 $R$ 里对应的是 $-S$，内积得 $-1$。<span class="marginnote">这个推导是 CDMA 的灵魂：<strong>正交性让「别人的信号在我这里自动清零」</strong>。中间那些用户的信号与 S 不正交（内积 0）就不干扰；与 S 正交的所有用户被完全滤除。噪声也能被大幅抵消——因为噪声与任何码片的内积平均接近 0。</span>

**辨析｜易错点：** 内积结果为正值（1）代表比特 1、负值（-1）代表比特 0，**取值是「正负」而不是「0/1」**。另外注意：码片序列的选取必须**两两正交**，而且每个码片必须是「平衡」的（1 与 -1 的个数大致相等），否则叠加信号会出现直流偏置。

## 3 举例：两个用户的 CDMA 通信

设用户 A 码片 $S = (1, 1, 1, -1, 1, -1, -1, -1)$，用户 B 码片 $T = (1, -1, 1, 1, 1, -1, 1, 1)$。可以验证 $S \cdot T = 0$（正交）。

- A 要发比特 1：发送 $S = (1, 1, 1, -1, 1, -1, -1, -1)$
- B 要发比特 0：发送 $-T = (-1, 1, -1, -1, -1, 1, -1, -1)$
- 信道叠加：$R = S + (-T) = (0, 2, 0, -2, 0, 0, -2, -2)$

接收端 A 用 $S$ 解：
$$
S \cdot R = \tfrac{1}{8}[(1)(0) + (1)(2) + (1)(0) + (-1)(-2) + (1)(0) + (-1)(0) + (-1)(-2) + (-1)(-2)]
$$
$$
= \tfrac{1}{8}(0 + 2 + 0 + 2 + 0 + 0 + 2 + 2) = \tfrac{8}{8} = 1
$$

内积为 +1，A 正确解出「1」；同时 B 的信号在 A 的眼里被完全滤除。<span class="marginnote">亲手算一遍这个例子，CDMA 就从「玄学」变成「算术」了。注意叠加信号里每位的数值，正是多个码片逐位相加的结果——这正是「同时同频发送」的物理现实。</span>

## 4 CDMA 与 CDM：多址与复用的一字之差

**CDM（复用）与 CDMA（多址）** 常被混用，但严格说有区别：

| 对比维度 | CDM | CDMA |
| --- | --- | --- |
| 全称 | 码分复用 | 码分多址 |
| 语境 | 一条信道上多路复用 | 无线蜂窝网里多用户接入 |
| 关注点 | 信道资源的共享方式 | 多用户如何同时接入基站 |
| 关系 | 技术机制 | CDM 机制在无线多址场景的落地 |

**辨析｜易错点：** 这一组「复用 vs 多址」的对照，同样适用于 FDM/FDMA、TDM/TDMA——**复用（MUX）讲的是「一条信道怎么被共享」，多址（Multiple Access）讲的是「多个用户怎么接入一个共享介质」。** CDMA 用「码」这个维度实现多址，是 2G/3G 时代的关键技术；到了 4G/5G，多址方式演化为 OFDMA（正交频分多址），但 CDMA 的思想仍在码分场景中延续。

## 5 小结

- **CDM/CDMA 思想**：所有用户同时同频发送，靠两两正交的码片序列区分彼此。
- **编码规则**：比特 1 发码片 $S$，比特 0 发反码 $-S$；芯片速率是数据速率的 m 倍。
- **正交性公式**：$S \cdot T = 0$（别人的信号清零）、$S \cdot S = 1$（认自己的暗号）。
- **解调方法**：接收端用 $S$ 与叠加信号 $R$ 做内积，正值=1、负值=0。
- **CDM vs CDMA**：复用讲信道共享，多址讲用户接入；类似 FDM/FDMA、TDM/TDMA。
- **不是加密**：CDMA 靠正交性而非保密性，任何接收端都能收到叠加信号。
