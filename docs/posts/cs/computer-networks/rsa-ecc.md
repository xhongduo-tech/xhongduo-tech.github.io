## 为什么从 RSA 与 ECC 开始

上一节说了公钥密码的思想（公钥加密、私钥解密），这一节看它的「数学发动机」——两个统治级公钥算法：**RSA** 与 **ECC**。它们的共同点：**安全建立在「数学上容易做、反向极难做」的单项函数上。**<span class="marginnote">公钥密码的安全基石是<strong>数学难题</strong>：<strong>RSA</strong> 靠「两个大素数相乘容易，但已知乘积分解回素数极难」（大整数分解难题）；<strong>ECC</strong> 靠「椭圆曲线上点乘容易，但已知结果反求倍数极难」（椭圆曲线离散对数难题）。<strong>「正着算容易、倒着算难」的单项函数</strong>是公钥密码的数学基础。</span>

这一节讲：**RSA 的原理与加解密、ECC 的优势、两者的对比。**

## 1 RSA 的原理：大数分解难题

**RSA（Rivest-Shamir-Adleman）**：1977 年提出的第一个实用的公钥密码算法。它的安全性基于**大整数分解难题**：<span class="marginnote">RSA 的密钥生成：<strong>选两个大素数 p、q，计算 n = p·q，公钥是 (e, n)，私钥是 (d, n)</strong>。其中 e 与 d 满足 $e \cdot d \equiv 1 \pmod{\varphi(n)}$（$\varphi(n)=(p-1)(q-1)$ 是欧拉函数）。加密 $C = M^e \bmod n$，解密 $M = C^d \bmod n$。<strong>安全性：知道 n 很容易（公钥公开），但从 n 分解出 p、q 极难</strong>——只要分解不出 p、q，就无法算出私钥 d。</span>

- **密钥生成**：选大素数 p、q，$n = pq$，公钥 $(e, n)$、私钥 $(d, n)$。
- **加密/解密**：$C = M^e \bmod n$，$M = C^d \bmod n$。
- **安全性**：从 n 分解出 p、q 在计算上不可行（n 越大越难）。

**公式解析：RSA 加解密的完整流程**

1. **生成密钥**：$p=61, q=53$，则 $n = 61 \times 53 = 3233$，$\varphi(n) = 60 \times 52 = 3120$。取 $e=17$（与 3120 互素），算出 $d$ 使 $17d \equiv 1 \pmod{3120}$，得 $d=2753$。
2. **加密**：明文 $M=65$，密文 $C = 65^{17} \bmod 3233 = 2790$。
3. **解密**：$M = 2790^{2753} \bmod 3233 = 65$。<span class="marginnote">这里的数值都是教学用的小数；真实 RSA 的 n 是 2048 位甚至 4096 位的巨数。<strong>「模幂运算」是 RSA 计算的核心</strong>——快速模幂算法让加密解密在毫秒级完成，而反向的「分解 n」却要数万年。这种「<strong>不对称的计算成本</strong>」正是公钥密码的精华。</span>

**辨析｜易错点：** **RSA 的安全性依赖「n 足够大」**——现代标准要求 n ≥ 2048 位，1024 位已被认为不安全。另一个易错点：**RSA 加密的是「数」不是任意字节**——实际应用中要把数据编码成小于 n 的数、分块处理。<strong>「n 越大越安全、但越慢」</strong>是 RSA 的永恒权衡。

## 2 ECC：用更短的钥匙，达到同样的安全

**ECC（Elliptic Curve Cryptography，椭圆曲线密码）**：基于**椭圆曲线离散对数问题**的公钥密码。它的核心优势：<span class="marginnote"><strong>同等安全下，ECC 的密钥更短</strong>：256 位 ECC 的安全性 ≈ 3072 位 RSA。为什么？因为针对 RSA 的大数分解有相对高效的算法，而针对椭圆曲线离散对数目前没有——所以 ECC 用更短的密钥就能达到同样难度。短密钥 = 更快的计算、更省存储带宽，这让 ECC 成为移动设备、TLS 握手的首选。<strong>「ECC 用更短的钥匙撬开同样坚固的锁」</strong>是它最核心的优势。</span>

- **256 位 ECC ≈ 3072 位 RSA**：同样安全、密钥短得多。
- **好处**：计算快、省存储带宽，适合移动与握手场景。
- **基础**：椭圆曲线离散对数问题（没有高效攻击算法）。

**辨析｜易错点：** ECC 不是「更强的加密」，而是「**同样强度的加密、用更短的钥匙**」。**「更短 ≠ 更弱，是更高效」**——把「短密钥」误解为「弱安全」是常见误区。对比：**256 位 ECC 与 3072 位 RSA 的安全性相当**，但 ECC 的密钥短、运算快。

## 3 RSA vs ECC：一张表

| 对比维度 | RSA | ECC |
| --- | --- | --- |
| 数学基础 | 大整数分解 | 椭圆曲线离散对数 |
| 同等安全的密钥长度 | 3072 位 | 256 位 |
| 运算速度 | 慢 | 快 |
| 存储/带宽 | 大 | 小 |
| 适用场景 | 传统系统、数字签名 | 移动端、TLS 现代部署 |
| 抗量子风险 | 高（Shor 算法可破） | 高（同样可破） |

**辨析｜易错点：** 一个常被忽略的事实：**RSA 与 ECC 在「量子计算」面前都脆弱**——Shor 算法能同时攻破大数分解与离散对数（后量子密码学是另一个战场）。**「RSA 与 ECC 是经典时代的主力，量子时代都需要替换」**是对两者长远命运的正确认识。

## 4 公钥密码与「从极限到大模型」主线

公钥密码的数学，处处与数学基础课相通：<span class="marginnote"><strong>模运算与欧拉函数</strong>（数论）、<strong>大数分解的复杂度</strong>（算法与计算复杂性）、<strong>椭圆曲线上的群结构</strong>（抽象代数）——公钥密码是把「数学难题」变成「安全基石」的极致应用。你在一级《数论》、二级《抽象代数》《计算复杂性》里学的「难题」「群」「模算术」，在这里都有了「用武之地」。<strong>「学数学时不知为何学，到密码学里全用上了」</strong>——这是学科交叉的典型回响。</span>

- **数论**：模运算、欧拉定理 → RSA 的数学基础。
- **抽象代数**：有限域、群 → ECC 的数学基础。
- **计算复杂性**：难题的难解性 → 安全强度的理论依据。

**辨析｜易错点：** 密码学不是「发明一个谁都算不出的函数」，而是「**把安全建立在公认的数学难题上**」——难题一旦被攻破（或量子算法出现），密码就得换代。**「安全是相对的，数学难题是它的锚」**是理解密码学演进的哲学。

## 5 小结

- **RSA**：基于大数分解，$C = M^e \bmod n$、$M = C^d \bmod n$；n 越大越安全越慢。
- **ECC**：基于椭圆曲线离散对数，256 位 ≈ 3072 位 RSA，更短更快。
- **单项函数**：正着算容易、倒着算极难——公钥密码的数学基石。
- **黄金对比**：RSA 传统、ECC 高效；同等安全 ECC 密钥短得多。
- **量子风险**：两者都被 Shor 算法威胁，后量子密码是未来战场。
- **数学渊源**：数论、抽象代数、计算复杂性在密码学里「会师」。
