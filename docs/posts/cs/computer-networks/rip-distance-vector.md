## 为什么从 RIP 开始

路由协议分两大流派：距离向量与链路状态。**RIP（Routing Information Protocol，路由信息协议）** 是**距离向量算法**的经典代表，也是所有 IGP 里最简单的一个。<span class="marginnote">距离向量（distance vector）的思想极其朴素：<strong>每台路由器只维护「到各网络的距离」，周期性地把自己的「距离表」告诉邻居，同时从邻居那里「听」来更新的距离</strong>。它的著名别名是「传闻路由（routing by rumor）」——因为信息是「听邻居说的」，一传十、十传百。</span>

这一节讲：**距离向量算法的更新规则、RIP 的具体参数、以及它最著名的缺陷——坏消息传得慢。**

## 1 距离向量算法：听邻居说，取最小

每台路由器维护一张**路由表**，每条含「目的网络、距离（跳数）、下一跳」。初始时，只知道自己直连的网络（距离 1）。然后周期性地（RIP 每 30 秒）与邻居交换整张表。

**更新规则**（设收到邻居 X 的表）：<span class="marginnote">对 X 表里的每个目的网络 N：<strong>新距离 = X 到 N 的距离 + 1（加上到 X 的这一跳）</strong>。若 N 不在自己的表里，直接加入；若新距离小于自己的旧距离，更新（下一跳指向 X）；若自己的旧路径下一跳就是 X，无论新距离大小都更新（因为旧的这条路径可能已变）。</span>

**公式解析：距离向量的更新**

$$
D_{u}(N) = \min\left(D_{u}(N),\ D_{x}(N) + 1\right)
$$

- **第一步，看符号**：$D_u(N)$ 是路由器 u 到网络 N 的距离，$D_x(N)$ 是邻居 x 到 N 的距离。
- **第二步，算候选**：从 x 那里「学」到的到 N 的候选距离是 $D_x(N)+1$（x 到 N 再加 u 到 x 的一跳）。
- **第三步，取最小**：u 保留「自己已有的」与「从 x 学来的」中较小的一个。<span class="marginnote">这个「min」是距离向量算法的全部数学：<strong>每条路由都是「经某邻居 + 该邻居到目的」的最小值</strong>。它依赖 Bellman-Ford 方程的分布式迭代——第二级《算法设计与分析》里会见到它的集中式版本。</span>

**辨析｜易错点：** 三条更新规则别漏：① 目的不在表中→直接加入；② 更短路径→更新；③ **下一跳仍是该邻居时→无条件更新**（哪怕距离变大）。第三条最容易忘，但它正是让路由能「跟着链路变坏而变」的关键——没有它，链路断了路由也不会改。

## 2 RIP 的具体参数：简单到极致

RIP 把一切做到最简：

| 参数 | 值 | 含义 |
| --- | --- | --- |
| 度量 | 跳数（hop count） | 每过一个路由器 +1 |
| 最大距离 | 16 | 距离 16 = 不可达 |
| 更新周期 | 30 秒 | 周期性广播路由表 |
| 路由失效 | 180 秒 | 超时未更新则标记失效 |
| 端口 | UDP 520 | RIP 报文用 UDP 传输 |
| 适用规模 | 小型网络 | 最大 15 跳 |

**辨析｜易错点：** **RIP 的最大跳数是 15**——超过 15 跳视为不可达。这直接限制了 RIP 只能用于小型网络（一个 AS 直径小于 15 跳）。另外注意 **RIP 用的是 UDP（端口 520）**——它是个「应用层之上的路由协议」，这点与 OSPF（直接用 IP 协议号 89）不同。<span class="marginnote">「16 跳 = 不可达」是 RIP 对「计数到无穷」问题的硬性截断：<strong>它不允许距离无上限地增长，超过 16 就宣告不可达</strong>。这个「数字封顶」既是保护，也是 RIP 只能小规模使用的根本原因。</span>

## 3 RIP 的著名缺陷：坏消息传得慢

距离向量算法的经典问题是**收敛慢**，尤其是「坏消息（链路断开）」。著名的 **「计数到无穷（count to infinity）」** 问题：<span class="marginnote">当某条链路断开，邻居之间可能「互相把对方当作路径」地无限递增距离——A 听 B 说「去 N 要 3 跳」，B 听 A 说「去 N 要 4 跳」……距离不断 +1，要很久才能涨到 16（不可达）。这就是「坏消息传得慢」：<strong>好消息（链路恢复）传播快，坏消息（链路断开）传播慢</strong>。</span>

**缓解手段**：**水平分割（split horizon）**——「我从你学来的路由，不再告诉你」；**毒性逆转（poison reverse）**——「我从你学来的路由，告诉你距离为无穷」。

**辨析｜易错点：** 「坏消息传得慢」不是 RIP 的 bug，而是**距离向量算法的结构性缺陷**——因为信息「逐跳传播」，断开的信息要一跳一跳地传遍网络。而下一节的 OSPF（链路状态）由于「全网广播拓扑 + 各自计算」，能同时看到全局，收敛就快得多。**「距离向量慢、链路状态快」**是两大算法最本质的性能分水岭。

## 4 RIP 的定位：教学价值大于实战

RIP 在真实网络中已很少使用（被 OSPF、IS-IS 取代），但它的价值不减：<span class="marginnote">RIP 是「<strong>分布式算法 + 路由协议</strong>」的最佳教学样本：算法极简（min 更新）、参数清晰（30 秒/15 跳）、缺陷典型（计数到无穷）。学懂 RIP 的优缺点，再学 OSPF、BGP 时就有了对照物——<strong>每一个新协议都是在修 RIP 的某一个缺陷</strong>：OSPF 修「收敛慢」，BGP 修「无策略」。学协议的最高效姿势，是「带着 RIP 的缺陷去学下一个」。</span>

**辨析｜易错点：** 别因为 RIP「过时」就轻视它——面试与考试里，**距离向量算法、水平分割、计数到无穷**都是高频考点。**RIP 的价值在「算法思想」，不在「工程部署」**。理解它，你就理解了「分布式迭代求最短路径」这一整类算法。

## 5 算例：一次 RIP 更新推演

设三个路由器 A、B、C 连成一线，网络 N 直连在 C 上。

1. **初始**：C 的路由表有「N，距离 1，直连」；A 有「N，距离 16（不可达）」；B 有「N，距离 16」。
2. **第一个周期**：C 把「N，1」广播给 B。B 更新为「N，2，下一跳 C」。
3. **第二个周期**：B 把「N，2」广播给 A 和 C。A 更新为「N，3，下一跳 B」；C 已直连（1 < 2），不更新。
4. **收敛完成**：A→N 距离 3、B→N 距离 2、C→N 距离 1。三个周期后全网收敛。

**再演算坏消息**：假设 C 与 N 的链路断了。C 把 N 的距离改为 16 并广播。但若 B 先把自己的「N，2」广播给 C，C 会以为「经 B 可达 N」→ C 更新为 3，B 又从 C 学到 4……**距离在 A、B、C 之间互相递增**——这就是「计数到无穷」的现场。

**辨析｜易错点：** 好消息传播快（每周期 +1 向前传）、坏消息传播慢（可能要几十个周期才到 16）——**「对称的算法，不对称的收敛」**正是距离向量的宿命。

## 6 RIP 报文与 OSPF 的对照

RIP 报文很简单（UDP 520）：每个条目含「目的网络 + 距离」两个字段，一条 RIP 报文最多 25 个路由条目。它的「表交换」是**整表周期性广播**——网络一大，带宽浪费明显。

与 OSPF 对比看 RIP 的定位：

| 对比维度 | RIP | OSPF |
| --- | --- | --- |
| 算法 | 距离向量 | 链路状态 |
| 度量 | 跳数 | 代价（带宽/时延等） |
| 交换什么 | 距离表 | 链路状态（全网拓扑） |
| 收敛 | 慢 | 快 |
| 最大规模 | 15 跳 | 大（无 15 跳限制） |
| 传输 | UDP 520 | IP 协议号 89 |

**辨析｜易错点：** RIP 的「整表广播」是它的带宽开销来源——网络每大一点，周期性广播就越重。**「RIP 适合小而稳，OSPF 适合大而变」**是选型的经验法则。

## 7 RIP 的实践细节：版本与触发更新

- **RIPv1 vs RIPv2**：v2 支持子网掩码、认证、组播更新（比 v1 的广播更省带宽）。
- **触发更新**：链路状态变化时，RIP 会立即发送更新（不等 30 秒周期）——「变化优先于周期」。
- **抑制时间**：为避免路由抖动，RIP 有「抑制（holddown）」机制——链路变化后先冻结一段时间，再接受新路由。

**辨析｜易错点：** RIPv2 的「触发更新」缓解了收敛慢，但没根治——「计数到无穷」在链路震荡时仍可能出现。**「触发更新是打补丁，换算法才是治本」**（所以有 OSPF）。

## 8 术语速查

| 术语 | 含义 |
| --- | --- |
| 距离向量 | 只与邻居交换距离表的算法 |
| RIP | 路由信息协议 |
| 跳数 | 经过的路由器数，RIP 的度量 |
| 最大跳数 | 15（16 = 不可达） |
| 更新周期 | 30 秒 |
| 计数到无穷 | 链路断开后距离互相递增 |
| 水平分割 | 从你学来的不再告诉你 |
| 毒性逆转 | 从你学来的告诉你是无穷 |
| 收敛 | 全网路由一致所需的时间 |
| Bellman-Ford | 距离向量的数学基础 |

## 9 小结

- **距离向量思想**：路由器维护「到各网络的距离表」，周期与邻居交换，min 更新。
- **更新规则**：目的不在表→加入；更短→更新；下一跳不变→无条件更新。
- **RIP 参数**：跳数为度量、最大 15 跳（16 不可达）、30 秒更新、UDP 520。
- **计数到无穷**：链路断开时距离可能互相递增，收敛极慢——「坏消息传得慢」。
- **缓解手段**：水平分割、毒性逆转。
- **教学价值**：RIP 是路由协议的「基准样本」，新协议都在修它的缺陷。
- **算例结论**：好消息每周期 +1 快传，坏消息几十周期才到 16，收敛不对称。
- **OSPF 对照**：距离向量慢而省、链路状态快而全，RIP 适合小而稳。
- **实践细节**：RIPv2 加认证与组播、触发更新是打补丁，换算法才是治本。
