## 为什么从移动性管理开始

移动通信的本质是「**边移动边通信**」——你开车、坐地铁、出差跨省，手机不能断线、来电还得找到你。**移动性管理（mobility management）** 解决两个核心问题：**切换**（你移动时连接怎么不断）与**漫游**（你离开归属地时怎么被找到）。<span class="marginnote"><strong>移动性管理的两大任务</strong>：<strong>① 切换（handoff）</strong>——终端从一个基站小区移动到另一个时，连接如何「无缝交接」；<strong>② 位置管理</strong>——终端不在归属地时，网络怎么知道「你此刻在哪」，让来电能找到你。<strong>「切换管连接不断，位置管理管找你到人」</strong>是移动性管理的两条线。</span>

这一节讲：**切换的类型与过程、位置管理与漫游、以及移动 IP 的思想。**

## 1 切换（Handoff）：连接的无缝交接

**切换（handoff / handover）**：移动设备从一个小区的基站范围进入另一个时，把通信连接**从一个基站交接给另一个基站**的过程。<span class="marginnote"><strong>切换的时机</strong>：基站持续监测终端的信号强度，当信号弱到阈值、且相邻基站信号更好时，触发切换。<strong>硬切换 vs 软切换</strong>：<strong>硬切换</strong>——先断开旧基站、再连新基站（2G 时代，「先断后连」，可能短暂掉话）；<strong>软切换</strong>——先连上新基站、再断开旧基站（3G 时代，「先连后断」，无缝）。<strong>「硬切先断后连，软切先连后断」</strong>是两种切换的关键差异。</span>

- **硬切换**：先断开旧基站 → 再连新基站（可能短暂断线）。
- **软切换**：先连上新基站 → 再断开旧基站（无缝）。
- **触发**：信号强度监测 + 阈值判断。

**辨析｜易错点：** **硬切换与软切换的「断连顺序」正好相反**——这是考试必考点。**「硬切先断后连、软切先连后断」**。另一个易错点：**切换由网络侧（基站/控制器）管理，不是手机主动操作**——手机只负责上报信号，网络决定何时切、切到哪。**「切换是网络替手机做的决定」**。

## 2 位置管理：网络怎么「找到你」

移动设备的位置是动态的，网络必须追踪：<span class="marginnote"><strong>位置管理的核心</strong>：靠 <strong>HLR（归属位置寄存器）</strong>与 <strong>VLR（拜访位置寄存器）</strong>。<strong>HLR 记录「你登记在哪个网络」</strong>——你的「籍贯」；<strong>VLR 记录「你当前在哪个小区/哪个拜访网络」</strong>——你的「现居」。你移动时，网络更新 VLR；你漫游到外地时，外地网络的 VLR 通知你归属的 HLR「你在这」——于是来电先问 HLR「你在哪」，HLR 指向 VLR，VLR 定位到小区。<strong>「HLR 是总台账，VLR 是临时住宿登记」</strong>。</span>

- **HLR**：归属位置寄存器——你的「籍贯」数据库。
- **VLR**：拜访位置寄存器——你的「现居」数据库。
- **位置更新**：你移动/漫游时，VLR 更新、并通知 HLR。

**辨析｜易错点：** **来电找人的链路是「HLR → VLR → 小区」**：先问 HLR「你在哪个网络」，HLR 指向当前拜访的 VLR，VLR 再定位到具体小区。**「HLR 指方向，VLR 定位置」**是对两者协作的准确描述。

## 3 漫游：离开归属地的「异地接入」

**漫游（roaming）**：移动设备离开**归属网络（home network）**，进入另一个运营商/地区的网络使用时，仍能获得服务。<span class="marginnote"><strong>漫游的机制</strong>：你到外地，手机接入当地网络（拜访网络）。拜访网络通过你的身份（SIM 卡）识别你是「来访用户」，向你的归属网络（HLR）核实身份与权限。核实通过后，拜访网络给你提供服务，账单记回归属网络。<strong>「漫游 = 拜访网络替归属网络服务、费用记回归属方」</strong>——这就是为什么国际漫游能「带着号走」。</span>

- **归属网络**：你签约的网络（SIM 卡登记处）。
- **拜访网络**：你当前所在地的网络。
- **漫游流程**：拜访网络核实身份（问 HLR）→ 提供服务 → 费用记回归属网络。

**辨析｜易错点：** **漫游的信任链是「拜访网络信归属网络」**——拜访网络不知道你是谁，但它信你的归属网络（HLR 的核实）。**「漫游是网络间的信任协作」**。另一个易错点：**漫游不改变你的号码**——号码始终是归属网络的，拜访网络只是「借网」。**「号码跟着你走，网络临时借用」**。

## 4 移动 IP：网络层的「随身地址」

蜂窝网络管好了「语音移动」，但**数据（IP）的移动**是另一回事——IP 地址与网络位置绑定，换个网络 IP 就变，正在进行的连接会断。**移动 IP（Mobile IP）** 解决这个问题：<span class="marginnote"><strong>移动 IP 的思想</strong>：给设备两个地址——<strong>归属地址（home address，固定不变）</strong>与<strong>转交地址（care-of address，当前网络的临时地址）</strong>。设备离开归属网时，向归属网络的<strong>归属代理（home agent）</strong>登记「我在哪」。发给归属地址的数据，被归属代理「隧道」转发到转交地址。<strong>「归属地址是身份证号，转交地址是临时住址；归属代理负责转信」</strong>——上层连接看到的是不变的归属地址，移动对上层透明。</span>

- **归属地址**：设备固定的 IP（身份）。
- **转交地址**：当前网络的临时 IP（位置）。
- **归属代理**：把发给归属地址的数据隧道转发到转交地址。

**辨析｜易错点：** **移动 IP 的核心是「地址分离」**——把「身份（归属地址）」与「位置（转交地址）」分开，靠归属代理转信。**「身份与位置分离」**是移动性管理的通用思想，也贯穿在 IPv6 的移动支持与未来网络架构里。<span class="marginnote">从「从极限到大模型」主线的角度看，移动 IP 的「<strong>身份与位置分离</strong>」思想非常重要——它同样出现在 CDN（内容与服务器解耦）、命名数据网络（NDN）等前沿里。<strong>「把『你是谁』和『你在哪』分开，是分布式系统解耦的经典手法」</strong>。</span>

## 5 小结

- **切换（handoff）**：基站间连接交接——硬切先断后连、软切先连后断。
- **位置管理**：HLR（籍贯）+ VLR（现居），来电链路 HLR → VLR → 小区。
- **漫游**：拜访网络借网、归属网络核实计费——「号码跟着你走」。
- **移动 IP**：归属地址（身份）+ 转交地址（位置）+ 归属代理转信。
- **核心思想**：身份与位置分离——移动对上层透明。
- **延伸**：身份-位置分离是分布式系统解耦的通用手法。
