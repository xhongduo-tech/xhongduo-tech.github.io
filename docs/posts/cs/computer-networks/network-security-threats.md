# 网络安全问题概述：威胁模型与攻击类型

<div class="epigraph">
<p>网络安全的本质不是「造一堵墙」，而是「明确谁可信、谁不可信，并为每一种恶意行为做好准备」。</p>

## 为什么从网络安全概述开始

前面的章节假设网络「友善」——大家都按协议办事。但现实中存在恶意攻击者：窃听、篡改、伪造、拒绝服务……**网络安全**要回答：**数据在网络里传输，如何保证它的机密性、完整性与可用性？**<span class="marginnote">学习网络安全的第一步，是建立「<strong>威胁模型（threat model）</strong>」：明确<strong>攻击者是谁、能做什么、攻击什么目标</strong>。没有威胁模型的安全讨论都是空谈——安全设计的前提是「先知道要防什么」。这一节把威胁模型与攻击类型立起来，后面各节（加密、签名、TLS、防火墙）都是「针对某类攻击的解药」。</span>

这一节讲：**安全的三目标（CIA）、攻击的两种分类、常见攻击手段。**

## 1 网络安全的三目标：CIA

网络安全的三大目标，合称 **CIA**：<span class="marginnote"><strong>C - Confidentiality（机密性）</strong>：数据不被未授权者窃看。<strong>I - Integrity（完整性）</strong>：数据不被篡改。<strong>A - Availability（可用性）</strong>：服务一直可用、不被拒绝。三者的英文首字母合起来是 CIA——这不是巧合，是教材的经典记号。<strong>「机密防偷看、完整防篡改、可用防瘫痪」</strong>是三大目标的通俗版。</span>

| 目标 | 英文 | 防什么 |
| --- | --- | --- |
| 机密性 | Confidentiality | 防窃听（偷看数据） |
| 完整性 | Integrity | 防篡改（改数据） |
| 可用性 | Availability | 防拒绝服务（瘫痪） |

**辨析｜易错点：** 安全的三目标不是「可选项」而是「同时要满足」——一个系统机密性做得再好，如果被 DDoS 打瘫（可用性崩），依然不安全。**「CIA 三目标要同时守」**是安全评估的基本框架。很多教材还会加两个延伸目标：**真实性（Authenticity）**——数据确实来自声称的来源；**不可抵赖性（Non-repudiation）**——发送方无法否认发过数据。

## 2 威胁模型：攻击者的「能力画像」

**威胁模型（threat model）**：对攻击者能力与目标的假设。没有它，安全设计无从谈起。常见的攻击者分类：<span class="marginnote"><strong>被动攻击者（passive）</strong>：只监听、不干预——能窃听（威胁机密性），但无法发现（因为没改任何东西）。<strong>主动攻击者（active）</strong>：干预通信——篡改、伪造、重放、注入（威胁完整性、可用性）。另一个维度是「位置」：攻击者可能在<strong>链路中间</strong>（窃听者）、在<strong>网络内部</strong>（内鬼）、或<strong>远程主机</strong>上。<strong>「先假设攻击者能做什么，再设计防线」</strong>是威胁建模的核心。</span>

- **被动攻击**：只窃听（读），不干预——难发现、威胁机密性。
- **主动攻击**：篡改、伪造、重放——易发现但破坏大、威胁完整性与可用性。

**辨析｜易错点：** **被动攻击最难防范也最难发现**——因为它「不碰数据」，加密是唯一有效的防线。而主动攻击虽然破坏大，但**可被发现**（完整性校验能查出来）。**「被动靠加密防，主动靠校验防」**是两类攻击对应解药的骨架。

## 3 常见攻击类型：从窃听到拒绝服务

把常见攻击手段按 CIA 分类：<span class="marginnote">常见攻击的「威胁-解药」对照：<strong>窃听 → 加密；篡改 → 完整性校验（哈希、MAC）；伪造 → 数字签名与认证；重放 → 随机数/时间戳；拒绝服务 → 流量清洗与冗余</strong>。每个解药都对应本章后面的一节——<strong>「先看攻击，再看解药」是学习网络安全的最优路径</strong>。</span>

| 攻击 | 威胁目标 | 典型手法 | 解药（本章后续） |
| --- | --- | --- | --- |
| 窃听 | 机密性 | 抓包、中间人 | 加密（§7.2-7.4） |
| 篡改 | 完整性 | 修改数据 | 散列/消息鉴别（§7.6） |
| 伪造/伪装 | 真实性 | 冒充身份 | 数字签名、证书（§7.5-7.8） |
| 重放 | 完整性/真实性 | 重复发送旧报文 | 时间戳、随机数 |
| 拒绝服务（DoS） | 可用性 | 洪泛、SYN 洪水 | 防火墙、流量清洗（§7.10） |

**辨析｜易错点：** **很多攻击是「组合拳」**——中间人攻击 = 窃听 + 篡改 + 伪装（上一节 ARP 欺骗就是中间人的实现手段）。别把攻击类型当成「单选」——真实攻击常常同时威胁多个 CIA 目标。**「中间人是窃听、篡改、伪装的合集」**是最典型的组合攻击。

## 4 纵深防御：不止一层防线

面对复杂的威胁，安全的正确姿势是**纵深防御（defense in depth）**：<span class="marginnote"><strong>纵深防御</strong>：不依赖单层防线，而是<strong>层层设防</strong>——加密保护数据、认证确认身份、完整性校验防止篡改、防火墙过滤流量、入侵检测发现异常。即使某一层被攻破，其他层仍然兜底。这就像城堡的多重防线：护城河、城墙、内城、塔楼。<strong>「没有银弹，只有层层设防」</strong>是网络安全的现实主义。</span>

- 加密（数据层面）→ 认证（身份层面）→ 校验（完整性层面）→ 防火墙/IDS（边界层面）。
- 任何单点失败都不至于全线崩溃。

**辨析｜易错点：** **纵深防御 ≠ 堆砌多种技术**——它的要点是「各层防不同的东西、互为备份」。如果加密和认证都只解决「机密性」，那不算纵深。**「纵深 = 不同层防不同威胁」**才是它的正确理解。

## 5 小结

- **CIA 三目标**：机密性（防偷看）、完整性（防篡改）、可用性（防瘫痪）。
- **威胁模型**：明确攻击者能力与目标——被动（窃听）vs 主动（篡改/伪造）。
- **攻击-解药对照**：窃听→加密、篡改→校验、伪造→签名认证、DoS→防火墙。
- **组合攻击**：中间人 = 窃听 + 篡改 + 伪装。
- **纵深防御**：层层设防、各防不同威胁，无银弹、只有兜底。
- **学习路径**：先看攻击，再看解药——本章后面各节都是「解药」。
