## 为什么从蜂窝移动通信网开始

蓝牙管「身边」，Wi-Fi 管「室内」，而手机要覆盖的是**整个城市、整个国家**——这是**蜂窝移动通信网（cellular network）** 的领地。它用「蜂窝」结构解决了「有限频谱如何服务无限移动用户」的难题。<span class="marginnote">蜂窝网络的核心洞察：<strong>不是用一个巨型基站覆盖全城，而是把区域切成无数个「小区（cell）」，每个小区一个基站、用不同的频率子集</strong>——这样频率可以在不相邻的小区间<strong>复用（frequency reuse）</strong>。蜂窝结构是移动通信从「一对多广播」走向「广域个人通信」的基石。</span>

这一节讲：**蜂窝概念与频率复用、从 GSM 到 5G 的代际演进。**

## 1 蜂窝概念：六边形的小区与频率复用

**蜂窝（cell）**：把覆盖区域划分成许多个**小区**（理论上是六边形），每个小区由**一个基站（base station）** 服务。<span class="marginnote"><strong>频率复用</strong>：相邻小区用<strong>不同的频率组</strong>，相隔足够远的小区可以<strong>用相同的频率组</strong>（如 7 个小区一组，第 8 个小区复用第 1 组的频率）。<strong>复用因子</strong>决定「多少个小区一组」。<strong>为什么用六边形</strong>？六边形能无缝隙覆盖平面且面积最大——小区越小，频率复用越密，容量越高。<strong>「蜂窝 = 把频谱切碎、按小区复用」</strong>。</span>

**小区（cell）**：一个基站覆盖的区域（理想六边形）。
**频率复用**：不相邻小区可复用相同频率，相邻小区用不同频率。
**越区切换**：移动设备从一个小区进入另一个，基站间交接（§8.5 详讲）。

**辨析｜易错点：** **蜂窝的「六边形」是理论模型，实际小区的形状取决于地形与基站覆盖**。**「六边形是理想化的等高线，不是现实的地图」**。另一个易错点：**频率复用不是「所有人都用同一频率」**——它是在「保证小区间不互相干扰」的前提下，让频率「隔空复用」——**「复用的是频率，隔离的是距离」**。

## 2 从 GSM 到 5G：四代演进

移动通信的世代演进，每代解决一个核心问题：<span class="marginnote"><strong>1G</strong>`（模拟语音）：大哥大，模拟信号。<strong>2G</strong>`（GSM，数字）：数字语音 + 短信 + 低速数据（GPRS/EDGE）。<strong>3G</strong>`（WCDMA/CDMA2000）：宽带数据，首次让「手机上网」成为现实。<strong>4G</strong>`（LTE）：全 IP 网络，高速数据（百兆级），语音也走 IP（VoLTE）。<strong>5G</strong>`：三大场景——<strong>eMBB</strong>`（增强移动宽带，10Gbps）、<strong>uRLLC</strong>`（超低时延高可靠，自动驾驶）、<strong>mMTC</strong>`（海量物联）。<strong>「每代都在『提速 + 扩展应用场景』」</strong>。</span>

| 代际 | 代表技术 | 核心能力 |
| --- | --- | --- |
| 1G | 模拟 | 模拟语音 |
| 2G | GSM | 数字语音 + 短信 + 低速数据 |
| 3G | WCDMA | 宽带数据（手机上网） |
| 4G | LTE | 全 IP、高速数据（百兆级） |
| 5G | NR | 高速 + 低时延 + 海量物联 |

**辨析｜易错点：** **「G」代表「Generation（代）」，不是「GHz」**——5G 的 G 是第五代。另一个易错点：**5G 不只是「更快」**——它的 uRLLC（超低时延）与 mMTC（海量物联）扩展了「移动通信能做什么」，**「5G 从『人连人』走向『万物互联』」**是它的代际意义。

## 3 GSM 的典型结构：一个蜂窝网络的「解剖」

以 2G 的 GSM 为例，看蜂窝网络的组成：<span class="marginnote"><strong>GSM 的核心结构</strong>：<strong>MS（移动台）</strong>——手机；<strong>BTS（基站收发信台）</strong>——小区里的无线电收发设备（铁塔上的设备）；<strong>BSC（基站控制器）</strong>——管理多个 BTS（分配信道、切换）；<strong>MSC（移动交换中心）</strong>——核心的交换与呼叫管理；<strong>HLR/VLR（归属/拜访位置寄存器）</strong>——记录用户位置与身份的数据库。<strong>「终端、基站、控制器、交换中心、位置数据库」</strong>是蜂窝网络的五层骨架。</span>

**MS（移动台）**：手机终端。
**BTS（基站收发信台）**：小区里的无线电设备。
**BSC（基站控制器）**：管理多个 BTS。
**MSC（移动交换中心）**：核心交换与呼叫管理。
**HLR/VLR**：用户位置与身份数据库。

**辨析｜易错点：** **「基站」与「小区」不是一回事**——一个 BTS 管一个小区，一个 BSC 管多个 BTS。**「小区是地理概念，BTS/BSC 是设备概念」**。另一个易错点：**HLR 是「归属」数据库（用户登记的地方），VLR 是「拜访」数据库（用户当前所在的地方）**——漫游时，用户的信息从 HLR 同步到所访网络的 VLR。**「HLR 管籍贯，VLR 管现居」**是两者的分工。

## 4 LTE 与 5G：从「电路」到「全 IP」

4G 与 5G 相比 2G/3G 有一个根本转变——**从「电路交换思维」走向「全 IP 思维」**：<span class="marginnote"><strong>2G/3G</strong>`：语音走「电路交换」（电话思维），数据走「分组交换」——两套系统并存。<strong>4G LTE</strong>`：<strong>全 IP</strong>`——语音也变成 IP 数据（VoLTE），一切皆分组。这让核心网大幅简化（不再有两套交换系统）。<strong>5G</strong>`：进一步把核心网「服务化」，支持网络切片（把同一物理网络切成多个虚拟网络，分别服务不同场景）。<strong>「从两套交换到全 IP，从一张网到网络切片」</strong>是核心网的演进主线。</span>

- **2G/3G**：语音走电路交换、数据走分组交换（两套系统）。
- **4G LTE**：全 IP——语音也 IP 化（VoLTE）。
- **5G**：核心网服务化、网络切片。

**辨析｜易错点：** **4G 的「全 IP」是革命性的**——它消灭了「电路交换」这个从电话时代继承的系统。**「4G 让移动通信彻底变成计算机网络」**是它的历史地位。另一个易错点：**5G 的网络切片不是「多个物理网」，是「一张物理网上的多个虚拟网」**——类似云计算里的虚拟化。**「切片 = 虚拟化在移动网络的应用」**。

## 5 小结

- **蜂窝概念**：把区域切成六边形小区，频率在不相邻小区间复用。
- **代际演进**：1G 模拟 → 2G 数字 → 3G 宽带数据 → 4G 全 IP → 5G 万物互联。
- **GSM 结构**：MS → BTS → BSC → MSC + HLR/VLR。
- **HLR vs VLR**：归属数据库 vs 拜访数据库，漫游时同步。
- **4G 全 IP**：消灭电路交换，语音也走 IP。
- **5G 三大场景**：eMBB（高速）、uRLLC（低时延）、mMTC（海量物联）。
