## 为什么从常量传播与常量折叠开始

程序里藏着大量「编译期就知道的值」：字面常量、循环不变的值、只被赋了一次的值。把这些值在编译期算完、把结果贴进代码，运行时就少了乘法、少了访存、少了分支。**常量折叠（constant folding）** 在编译期计算常量表达式，**常量传播（constant propagation）** 把「x 一定等于常量 c」的知识沿程序传播，让更多折叠成为可能。<span class="marginnote">「折叠 + 传播」是优化器里最直接的「数学在编译期做」：`2 × 3` 编译成 `6`，`x` 若恒等于 1 则 `x + 1` 编译成 `2`。看似简单，却是一切优化的「底层燃料」——不折叠常量，后面的 CSE、外提都无从谈起。</span>

## 1 常量折叠：编译期算数

**常量折叠（constant folding）**：对**所有操作数都是常量**的表达式，在编译期直接算出结果：

$`$2` \times 3 \Rightarrow 6, \qquad 10 \div 2 \Rightarrow 5, \qquad 2^{10} \Rightarrow 1024$$

翻译成 IR 时，`2 × 3` 直接被替换为 `6`——不生成乘法指令。折叠在表达式翻译、局部优化、窥孔优化里都会做，是「重复出现」的廉价优化。

**安全前提**：折叠必须保持语义。整数运算的**溢出**、**除零**、**浮点舍入**都可能改变行为——编译器通常只对「无副作用、无异常」的常量运算折叠，或按语言语义明确处理。<span class="marginnote">常量折叠的坑全在边界：C 里 `INT_MAX + 1` 是有符号溢出（未定义行为），编译器折叠它需谨慎；`x / 0` 是除零（会崩还是折叠成「未知」要看语言）。「折叠正确」不只是算出数字，还要算「该不该算」。</span>

## 2 常量传播：把常量知识传下去

**常量传播（constant propagation）**：若某个点**保证**变量 `x` 等于常量 `c`，则后续读取 `x` 的地方可替换为 `c`：

$$x = 1; \quad y = x + 2 \quad \Rightarrow \quad y = 1 + 2 \quad \Rightarrow \quad y = 3$$

关键在「保证」二字：必须沿**所有**到达路径都确认 `x = c`，才能替换。若某条路径给 `x` 赋了别的值，传播就不安全。

- **单一定值**：若 `x` 只有一个到达定值且其为常量，可传播（这是到达定值分析的直接应用）。
- **全路径一致**：多个定值但**全部**是同一常量 `c`，也可传播。

**辨析｜易错点：** 常量传播的「一定」语义对应用了「到达定值」的「可能」——到达定值说「可能到达」，常量传播要的是「**所有**到达的定值都是同一个常量」。这个「可能 vs 一定」的升格，正是传播的安全性所在。<span class="marginnote">一个经典反例：`if (c) x = 1; else x = 2;`——`x` 的两个定值是 1 和 2，路径不同，所以汇合点处 `x` 不是常量，不能传播。编译器必须「所有路径一致」才敢动，这条保守原则保护了语义。</span>

## 3 数据流框架下的常量传播

常量传播可以放进数据流框架：每个变量的「信息」是三值格的元素——**常量 c / 非常量（未知的任意值）/ 未定义**。

$$x: \begin{cases} \text{未定义} & \text{还没有任何定值到达} \\ c & \text{所有到达定值都是常量 } c \\ \text{非常量} & \text{至少一个到达定值不是常量（或 c 不一致）} \end{cases}$$

转移函数：定值 `x = c` 把 `const(x)` 设为该常量；`y = a \text{ op } b`（操作数非常量）把 `const(y)` 设为「非常量」；多个路径汇合时，若各路径给 `x` 的值一致则取该值，不一致则「非常量」。

这个「三值格」是**抽象解释**的雏形——用一个抽象值（未定义/常量/非常量）代替所有具体值，在格上做单调传播。<span class="marginnote">「抽象解释」是常量传播的理论底座：把「所有可能的整数值」抽象成「未定义/常量 c/非常量」三档，运算在抽象值上近似进行。它是格论在编译器里的经典应用，也是「静态分析 = 格上不动点」这个宏大框架的起点。</span>

## 4 公式解析：传播规则的格

设 $\text{const}(x)$ 表示 `x` 当前的抽象值，定值 `x = a \text{ op } b` 的转移为：

$$\text{const}(x) = \begin{cases} c_a \ \text{op}\ c_b & \text{若 } a = c_a \text{ 且 } b = c_b \text{（折叠）} \\ \top \ (\text{非常量}) & \text{否则} \end{cases}$$

- **第一步，双常量折叠**：两个操作数都是已知常量，则结果也是常量——算出具体值，折叠发生。
- **第二步，遇非常量**：任一操作数是非常量（或未定义却按非常量处理），结果就是非常量——无法静态确定。
- **第三步，汇合规则**：多路径给 `x` 的值，全同才取那个值，否则非常量——「所有路径一致」被编码进格运算。

**「格 + 转移 + 汇合」把常量传播变成不动点计算**：迭代到收敛，每点的常量知识精确可信。

## 5 条件常量传播：让分支也参与

**条件常量传播（conditional constant propagation）** 是增强版：不仅传播常量，还**同时追踪控制流可达性**——若 `x = 5` 且 `x` 恒为 5，则只有真分支可达，假分支的代码变成不可达，可删除。

$$x = 5; \quad \text{if } (x < 3)\ S_1; \quad \text{else}\ S_2 \quad \Rightarrow \quad S_1 \text{ 不可达，只保留 } S_2$$

它把「常量知识」与「不可达分析」结合，一次传播同时化简了数据与控制流——是现代优化器（SSA 上的 SCCP）的核心。<span class="marginnote">条件常量传播是「常量传播 + 死代码消除」的联合不动点：常量知识判定分支可达性，可达性反过来约束哪些代码还能传播。这个「两个分析互相喂」的模式，在 SSA 形式（第十一篇）上尤其优雅，是 LLVM `SCCP` pass 的基础。</span>

## 7 思考与练习

**练习 1 手算传播**：对程序 `x = 1; if (p) y = 2; else y = 3; z = x + y;`，用「三值格」（未定义/常量/非常量）逐语句传播，标出 `y` 在汇合点「所有路径一致才取常量」的判定。

**练习 2 折叠安全**：`INT_MAX + 1` 在 C 里是有符号溢出（未定义行为）——编译器折叠它安全吗？`1 / 0` 呢？各讨论「折叠正确」需要哪些语言语义信息。<span class="marginnote">常量折叠的「安全」不是「算得对」，而是「语义允许」：`INT_MAX + 1` 折叠成什么？若折叠成某个值，就「替未定义行为定了性」——C 编译器可以（把 UB 当任意值），但会谨慎；`1 / 0` 折叠成「除零」会改变程序行为，多数编译器保守不折。理解「折叠要尊重语言语义」，就避开了优化器最常见的坑。</span>

**练习 3 全路径一致**：构造一个 `x` 的「到达定值都不同」的例子（`x = 1` 与 `x = 2`），说明为什么汇合点不能传播——对比「所有定值都是同一常量」的传播条件。

**练习 4 格运算**：把三值格的「汇合」写成运算表（未定义 ⊓ 常量 = ?，常量 c1 ⊓ 常量 c2 = ?，非常量 ⊓ 任何 = ?）——验证「单调性」与「幂等性」。

**练习 5 条件传播**：对 `x = 5; if (x > 3) S1; else S2`，用条件常量传播指出 `S2` 不可达——把「常量知识」与「可达性」如何互相喂给对方写清楚。

**练习 6 工程观察**：写一段含常量传播机会的 C 程序，用 `gcc -O2`（或 `clang -O2`）观察优化前后，找「全常量折叠」类的折叠结果——把第七十五节的手法用在这里。

**常见误区**：

- **误区一**：把「到达定值」的「可能」当成传播的「一定」——传播要求所有到达定值一致，不是「有一个是常量」。
- **误区二**：折叠时忽略溢出/除零——「能算」不等于「允许算」。
- **误区三**：忘记传播与折叠的接力——传播制造「全常量表达式」，折叠才算——两者是「开路」与「收割」的配对。

**延伸**：三值格是「抽象解释」的最简实例——把「所有整数值」抽象成三档。到第二级《数理逻辑》与第三级《形式化方法》里找「抽象解释」的完整定义，把「格上不动点」这套数学与编译器优化接通。

## 8 小结

- **常量折叠**在编译期计算「全常量表达式」：`2 × 3` → `6`；前提是无副作用、语义不变。
- **常量传播**把「x 一定等于 c」沿程序传递，让更多折叠发生；安全性靠「所有路径一致」。
- 数据流框架：三值格（未定义/常量/非常量）+ 转移 + 汇合，不动点求解。
- 汇合规则：多路径值**全同才取**，否则非常量——「可能」与「一定」的升格是安全核心。
- **条件常量传播**同时追踪常量与可达性，让分支化简参与进来（LLVM SCCP 的雏形）。
