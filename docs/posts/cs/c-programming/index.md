# C 语言编程

C 语言是现代操作系统、嵌入式系统与高性能程序的事实标准语言，也是理解计算机内存模型与指针语义的基石。学完这些章节，就系统掌握了从语法、指针、内存管理到系统编程接口的完整 C 语言功底。

## 对标教材

- Brian W. Kernighan & Dennis M. Ritchie, "The C Programming Language" (2nd, 1988)
- Stephen Prata, "C Primer Plus" (6th, 2014)
