## 为什么从函数讲起

到目前为止，我们的程序都挤在 `main` 里。真实程序动辄上万行，若全塞在一个函数里，没人能读懂。**函数（function）** 是把一段逻辑打包、命名、可反复调用的机制——它是 C 程序组织的第一级单元，也是模块化与抽象的开端。<span class="marginnote">函数在数学里是「输入到输出的映射」，在 C 里则是「一段有名字的代码块」。K&R 把函数比作「黑盒」：调用者只关心输入输出契约，不关心内部实现——这正是「抽象」的最小形态，后续结构体、指针、链表全部建立在这套抽象之上。</span>这一节讲清函数的三个环节：**定义**（怎么写）、**声明**（怎么预告）、**调用**（怎么用），并重点辨析 C 的「值传递」语义。

## 1 函数定义：三件套

一个函数定义由**返回类型、函数名、参数列表**（合称函数头）与**函数体**组成：

```c
int add(int a, int b)      /* 函数头：返回 int，接收两个 int */
{                          /* 函数体开始 */
    int sum = a + b;
    return sum;            /* 返回 int 类型的值 */
}                          /* 函数体结束 */
```

**返回类型（return type）**：函数返回值的类型。不需要返回值时用 `void`：`void greet(void) { ... }`。
**参数列表（parameter list）**：形如 `int a, int b`，声明了函数接收哪些输入。`void` 表示不接收参数。
- **`return` 语句**：把值送回调用处，并立刻结束函数。返回类型为 `void` 的函数可以没有 `return`，也可以写 `return;` 提前结束。

调用它：

```c
#include <stdio.h>

int add(int a, int b);   /* 函数原型（声明）：告诉编译器 add 长什么样 */

int main(void)
{
    int result = add(3, 4);    /* 函数调用：3、4 是实参 */
    printf("%d\n", result);    /* 输出 7 */
    return 0;
}

int add(int a, int b)     /* 函数定义 */
{
    return a + b;
}
```

这里出现了 **`int add(int a, int b);` 这一行「函数原型」（prototype）**——它只声明签名、不写函数体。它的作用是：让 `main` 在定义 `add` 之前就能调用它。<span class="marginnote">若没有原型，编译器遇到 `add(3, 4)` 时只能猜它的参数与返回类型，可能猜错而引发未定义行为。C99 起，函数必须先声明或定义才能调用，否则编译报错。工程惯例是把原型放在头文件里，多个源文件共享。</span>

## 2 值传递：函数拿到的是副本

**C 函数的参数按值传递（pass by value）**：调用时，实参的值被**复制**一份给形参，函数内部修改形参**不会影响**实参：

```c
#include <stdio.h>

void change(int x)
{
    x = 100;               /* 改的是形参 x 的副本 */
}

int main(void)
{
    int n = 5;
    change(n);
    printf("%d\n", n);     /* 还是 5！n 没被改变 */
    return 0;
}
```

这是 C 新手最容易困惑的一点。若想让函数**修改外部变量**，必须把变量的**地址**传进去——这正是指针的用武之地：

```c
void set_to_hundred(int *p)   /* 接收 int*，即地址 */
{
    *p = 100;                 /* 通过解引用修改 p 指向的变量 */
}

int main(void)
{
    int n = 5;
    set_to_hundred(&n);       /* 传地址 &n */
    printf("%d\n", n);        /* 输出 100 */
    return 0;
}
```

**「传值」与「传地址」的差别，是理解 C 的钥匙之一**：值传递保证函数不会意外改动调用者的数据（安全），代价是无法回传结果；指针参数能直接改外部变量（高效），但要用得小心。<span class="marginnote">严格说，指针本身也是按值传递的——`set_to_hundred` 拿到的是「地址的副本」。但因为副本指向的对象是同一个，所以通过指针仍能改到外部变量。这个「按值传指针，却改了外部数据」的双层结构，在《指针基础与指针运算》一节会彻底展开。</span>

## 3 return：把结果带回调用处

`return` 语句两件事：**确定返回值**、**结束函数**。调用者可以把返回值赋给变量、作为实参再传给别的函数、或直接用于表达式：

```c
int max(int a, int b)
{
    if (a > b)
        return a;
    return b;
}

int main(void)
{
    int m = max(3, 7);                 /* 赋给变量 */
    printf("%d\n", max(m, 10));        /* 作为实参再传 */
    printf("%d\n", max(1, 2) + max(3, 4));  /* 参与运算 */
    return 0;
}
```

注意返回类型必须与 `return` 表达式的类型兼容：返回 `int` 的函数却写 `return "hi";` 是类型错误；`return 3.99;` 会被隐式截断为 `3`（返回 `int` 时）。

`void` 函数不返回值，直接用 `return;` 提前退出：

```c
void print_if_positive(int x)
{
    if (x <= 0)
        return;            /* 提前结束 */
    printf("%d\n", x);
}
```

## 4 参数太多怎么办：作用域与局部变量

函数体内的变量（包括形参）默认是**局部变量（local variable）**：它们在函数**每次调用时**才创建、调用结束就销毁，外部无法访问：

```c
int counter(void)
{
    int local = 0;     /* 每次调用都从 0 开始 */
    local++;
    return local;      /* 总是返回 1 */
}
```

若想记住「上一次调用的状态」，用 `static` 局部变量（存储类别见下一节《作用域、存储类别与链接》）：

```c
int counter(void)
{
    static int count = 0;   /* 只初始化一次，跨调用存活 */
    count++;
    return count;           /* 第一次 1，第二次 2，…… */
}
```

**参数过多时**，C 没有默认参数与重载，常见对策是「结构体打包参数」或「可变参数函数」——前者需要结构体（第 3 篇），后者见《可变参数与函数指针》。
