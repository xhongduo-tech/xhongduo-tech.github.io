## 为什么从位运算讲起

第 2 篇介绍运算符时，位运算只是表格里的一行。但它在嵌入式、底层协议、性能敏感代码里是**主力工具**：一个字节的 8 个开关、一组权限位、一个网络报文头，都靠位运算来读写。<span class="marginnote">高级语言里你几乎不用碰位，但 C 给你完全的控制权：一个 `int` 的 32 个位，每一位都可以单独置位、清零、翻转、查询。文件权限 `0755`、Unix 的 `open` 标志位、TCP 头里的标志字段，全是位运算的日常。这一节把位运算练成「条件反射」。</span>这一节讲透六个位运算符、位掩码的经典手法，以及 C 的**位字段（bit field）** 语法。

## 1 六个位运算符

位运算在整数的**每一位**上独立操作：

| 运算符 | 名称 | 行为 |
| --- | --- | --- |
| `&` | 按位与 | 两个位都是 1 结果才为 1 |
| `\|` | 按位或 | 任一位是 1 结果就为 1 |
| `^` | 按位异或 | 两个位不同结果为 1 |
| `~` | 按位取反 | 1 变 0，0 变 1 |
| `<<` | 左移 | 各位左移，低位补 0 |
| `>>` | 右移 | 各位右移，低位丢弃 |

举例（8 位示意）：

```c
unsigned char a = 0b11001100;
unsigned char b = 0b10101010;

a & b   /* 0b10001000  两个都是 1 的位置 */
a | b   /* 0b11101110  任一为 1 的位置 */
a ^ b   /* 0b01100110  相异的位置 */
~a      /* 0b00110011  全部取反 */
a << 1  /* 0b10011000  左移一位，高位丢弃 */
a >> 2  /* 0b00110011  右移两位，低位丢弃 */
```

**位移即乘除**：`x << n` 等价于乘以 $2^n$（在无溢出时），`x >> n` 等价于整除 $2^n$（对无符号数）。`1 << k` 得到「只有第 k 位为 1」的掩码，这是位操作的基石。<span class="marginnote">对有符号负整数，右移是「算术右移」（补符号位）还是「逻辑右移」（补 0）由实现决定——跨平台代码若依赖右移填充位，应使用无符号类型。`unsigned` 的右移永远是逻辑右移，行为明确。</span>

## 2 位掩码的经典手法

**掩码（mask）** 是一个「只关心某些位」的位模式。设 `flags` 是一个字节的开关集合，`0b00000100` 是第 2 位（值 4）：

```c
#define FLAG_A (1 << 0)   /* 0b00000001 */
#define FLAG_B (1 << 1)   /* 0b00000010 */
#define FLAG_C (1 << 2)   /* 0b00000100 */

unsigned char flags = 0;

flags |= FLAG_B;             /* 置位：打开 FLAG_B */
flags &= ~FLAG_C;            /* 清零：关闭 FLAG_C */
flags ^= FLAG_A;             /* 翻转：FLAG_A 取反 */
if (flags & FLAG_B)          /* 测试：FLAG_B 是否打开 */
    printf("B 已打开\n");
```

四种操作各有明确语义，可总结成口诀：

| 操作 | 写法 | 效果 |
| --- | --- | --- |
| 置位（打开） | `flags |= mask;` | 指定位置 1，其余不变 |
| 清零（关闭） | `flags &= ~mask;` | 指定位置 0，其余不变 |
| 翻转（切换） | `flags ^= mask;` | 指定位取反，其余不变 |
| 测试（查询） | `if (flags & mask)` | 指定位是否位 1 |

**`flags &= ~mask` 里的 `~mask` 是关键**：`~FLAG_C` 是「除了 C 位其余全 1」，与它按位与，C 位被清零、其余位保持。这比直接写 `flags = 0` 精细得多——**只动指定的位**。

## 3 位运算的经典应用

**判断奇偶**：`x & 1` 为 1 则 `x` 是奇数——比 `x % 2` 更贴近硬件。

```c
if (n & 1) printf("奇数\n"); else printf("偶数\n");
```

**交换两个数（不用临时变量）**：三次异或，`a^=b; b^=a; a^=b;` 可交换——是经典的位运算面试题，也是 XOR 性质「自反」的直接体现。

**计数置位数（popcount）**：

```c
int count_bits(unsigned int x)
{
    int cnt = 0;
    while (x) {
        x &= (x - 1);   /* 清除最低位的 1 */
        cnt++;
    }
    return cnt;
}
```

`x &= (x - 1)` 每次消掉最右边的 1，循环次数就是 1 的个数——比逐位测试高效。

**检查某位是否为 1（提取位）**：`(x >> k) & 1` 取出第 k 位。

**颜色通道拆分**：一个 32 位像素 `0xAARRGGBB`，取出红分量：`(pixel >> 16) & 0xFF`。<span class="marginnote">位运算在图像处理、协议解析、哈希散列里无处不在。`hash = hash * 31 + c` 这类乘法可以用 `hash = (hash << 5) - hash` 替代——左移 5 位是乘 32，减自己就是乘 31。编译器常自动做这类优化。</span>

## 4 位字段：在结构体里按位分配

**位字段（bit field）** 允许在结构体里以「位」为单位声明成员，非常适合紧凑存储硬件寄存器、协议头：

```c
struct Flags {
    unsigned int read  : 1;   /* 占 1 位 */
    unsigned int write : 1;
    unsigned int exec  : 1;
    unsigned int : 5;         /* 匿名位：跳过 5 位（填充） */
};
```

每个成员用 `:` 指定位数。访问与普通结构体成员一样：

```c
struct Flags f;
f.read = 1;        /* 只改这一位 */
f.write = 0;
if (f.exec) printf("可执行\n");
```

**位字段的优点**：紧凑（8 个 1 位标志只需 1 字节，而不是 8 个 `unsigned int`）、语义清晰（成员有名字）。**局限**：可移植性差（字段布局、跨越字节边界的方式由实现定义）、不能取地址（`&f.read` 非法）、不能声明数组。工程上，**数据持久化或网络传输结构不要用位字段**（布局不可控），只在单机内存结构里用。<span class="marginnote">位字段是实现「设备寄存器」最常见的 C 手法——嵌入式里一个寄存器常常 32 位里塞了多个字段（使能、模式、中断标志）。但它的内存布局是「实现定义」的：不同编译器可能把小端/大端、位顺序弄出差别。驱动代码里常改用显式掩码 + 位移来保证可控。</span>

## 5 公式解析：`(x >> k) & 1` 提取第 k 位

提取位是位运算的原子操作，拆解它：

$$
\text{bit}_k(x) = \left( x \gg k \right) \mathbin{\&} 1
$$

以提取 `x = 0b10110110` 的第 4 位（从右数，最低位是第 0 位）为例：

- **第一步，右移 k 位**：`x >> 4` 把第 4 位搬到最低位。$0b10110110 \gg 4 = 0b00001011$
