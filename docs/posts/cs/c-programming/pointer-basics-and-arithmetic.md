## 为什么从指针讲起

指针（pointer）是 C 语言**最具标志性、也最劝退**的特性。它让 C 能直接操作内存地址，从而成为系统级语言的基石——操作系统、嵌入式、性能敏感程序都离不开它。<span class="marginnote">Python 里 `x = [1,2,3]` 时 `x` 其实就是个「引用」，与 C 指针同源；但 Python 帮你管理一切，C 让你亲手掌控。学会指针，你就同时理解了「一切现代语言底层都在做的事」。</span>这一节从「地址」这个朴素概念出发，建立指针的完整心智模型，再讲透指针运算的规则——这也是后续数组、字符串、链表全部内容的地基。

## 1 地址：每个变量都有门牌号

内存可以想象成一条巨大的字节走廊，每个字节都有一个**地址（address）**。变量占据若干字节，它的地址就是首字节的编号。取地址运算符 `&` 能拿到这个门牌号：

```c
int x = 42;
printf("x 的值：%d\n", x);      /* 42 */
printf("x 的地址：%p\n", (void*)&x);  /* 形如 0x7ffee4a1a8a4 */
```

**指针（pointer）就是保存地址的变量**。声明指针时，`*` 表示「这是一个指针」，类型说明它指向什么类型的对象：

```c
int *p;        /* p 是指向 int 的指针 */
double *q;     /* q 是指向 double 的指针 */
char *s;       /* s 是指向 char 的指针 */
```

`int *p` 的读法是「`*p` 是一个 `int`」——**声明里 `*` 是「所指向的类型」的标记**，理解这一点，后面读复杂声明就有抓手。

## 2 解引用：顺着地址找到东西

**解引用（dereference）** 运算符 `*` 顺着指针保存的地址，访问它指向的变量：

```c
int x = 42;
int *p = &x;      /* p 保存 x 的地址 */
*p = 100;         /* 通过 p 修改 x：x 变成 100 */
printf("%d\n", x);  /* 100 */
```

一句话串起 `&` 与 `*`：**`&` 是「取地址」，`*` 是「沿地址取值」；`*&x` 等价于 `x`**。两者互为逆运算。

再回看第 2 篇《函数》里的值传递：函数要改外部变量，传地址即可——`set_to_hundred(&n)` 里 `&n` 是地址，形参 `int *p` 接收它，`*p = 100` 修改 `n`。

**空指针（NULL pointer）**：`NULL`（通常是 `0`）表示「不指向任何对象」。解引用空指针是**未定义行为**，绝大多数实现直接崩溃（段错误）。安全惯例：用指针前检查它是否为 `NULL`：

```c
int *p = NULL;
if (p != NULL)
    *p = 10;      /* 安全：先检查再用 */
else
    printf("p 是空指针\n");
```

## 3 指针与类型：指针的「量级」

一个关键事实：**指针是有类型的，而且类型决定了它运算时的步长**。`int *p` 指向一个 `int`（通常 4 字节），`char *q` 指向一个 `char`（1 字节）。类型不同，`p + 1` 与 `q + 1` 前进的字节数就不同。

指针的类型必须与指向的对象匹配：`int *p = &x;` 里 `x` 必须是 `int`。把不同类型的地址强行赋给指针（如 `double *q = &x;`）编译器会警告，因为 `*q` 会按错误的步长解读内存。唯一的例外是 **`void *`**——不指定指向类型的通用指针，常用于「先存地址、后按需转换」（动态内存与 `qsort` 里大量使用）。

## 4 指针运算：前进后退的步长

指针不只是存地址，还可以做算术运算。**指针运算的步长以「所指向类型的大小」为单位**：

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = &arr[0];      /* p 指向第一个元素 */
p + 1;                 /* 指向 arr[1]，地址比 p 大 sizeof(int) 字节 */
p + 3;                 /* 指向 arr[3] */
p - 1;                 /* 若 p 指向 arr[1]，则回退到 arr[0] */
```

**`p + n`**：指针前进 n 个元素，地址实际增加 $n \times \text{sizeof}(*p)$ 字节。
**`p - n`**：后退 n 个元素。
- **`p - q`**：两个指针相减，得到它们**之间的元素个数**（仅当指向同一数组时合法）。

```c
int *p = &arr[1];     /* 指向 20 */
int *q = &arr[4];     /* 指向 50 */
printf("%ld\n", q - p);   /* 3：中间隔了 3 个元素 */
```

**指针的比较**：`p < q` 比较地址大小，同样要求指向同一数组。<span class="marginnote">比较两个无关的指针（不指向同一数组）是未定义行为——只有指向同一数组（或数组尾部之后一个位置）的指针才能安全地比较或相减。这个约束在《内存模型、对齐与未定义行为》一节会归入未定义行为的清单统一处理。</span>指针运算越界是未定义行为——`p + 100` 指向数组外的未知内存，但**不会立刻报错**，等解引用时才可能爆炸，这是指针 bug 难以调试的原因。

## 5 公式解析：`p + n` 到底移动了多少字节

指针加法是 C 里「优雅又容易算错」的运算，拆开看：

$$
\text{addr}(p + n) = \text{addr}(p) + n \times \text{sizeof}(\text{*p})
$$

以 64 位系统、`int` 占 4 字节为例，设 `p` 的地址是 `0x1000`：

- **第一步，确定 `*p` 的类型**：`p` 是 `int *`，所以 `*p` 是 `int`，`sizeof(*p) = 4`。
- **第二步，乘以 n**：`p + 3` 中 $n=3$，前进 $3 \times 4 = 12$ 字节。
- **第三步，加到底址**：`0x1000 + 12 = 0x100C`。`p + 3` 指向地址 `0x100C`。

若换成 `char *q` 且地址同为 `0x1000`，`sizeof(*q) = 1`，`q + 3` 只前进 3 字节到 `0x1003`。**同样的 `+ 3`，不同指针类型走不同的距离**——这就是「指针类型决定步长」的数学表达，也是数组遍历能通过 `p++` 逐元素推进的根本原因。

## 6 核心对比表：`&` 与 `*`，指针与变量

| 维度 | 普通变量 `int x` | 指针变量 `int *p` |
| --- | --- | --- |
| 存放内容 | 值（如 `42`） | 地址（如 `0x1000`） |
| 取它自己的地址 | `&x` | `&p`（指针的指针） |
| 访问它指的东西 | 无 | `*p` |
| 大小 | `sizeof(x)` 字节 | `sizeof(p)` 字节（64 位下 8） |
| 主要用途 | 存数据 | 间接访问、共享数据、遍历数组 |

这张表回答初学者最迷茫的问题「指针到底是什么」：**指针是一个普通的变量，只是它的值是地址**。它有自己的地址（`&p`）、自己的大小（8 字节），只不过多了一项别人没有的能力——解引用去访问它「指」的变量。

## 7 小结

- 内存里的每个变量都有**地址**；`&` 取地址，`*` 解引用，`*&x` 等价于 `x`。
- 指针 = 保存地址的变量；声明 `int *p` 读作「`*p` 是 `int`」。
- 指针类型决定运算步长：`p + n` 前进 $n \times \text{sizeof}(*p)$
