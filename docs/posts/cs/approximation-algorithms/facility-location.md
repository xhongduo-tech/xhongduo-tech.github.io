## 为什么从设施选址开始

前面所有问题的「动作」都是选边、连点。
**设施选址（uncapacitated facility location, UFL）**把目标升级成两笔开销的权衡：开设施要**建设费**，客户连设施要**服务费**——开得越多服务费越低，可建设费越高。这是供应链、物流、云计算机房布局的原型问题，也是本专题「选址 + 分配」问题族（k-中位数、k-中心）的第一站。

UFL 在近似算法史上有特殊地位：
它逼出了**原始对偶方法最精妙的一次应用**（Jain–Vazirani 3-近似），也催生了**对偶拟合 + 贪心**的 1.52-近似纪录。理解 UFL，等于同时掌握「客户出钱、设施喊价」的对偶直觉和「修剪初解」的雕琢技术。

## 1 问题与 LP

**无容量设施选址**：给定客户集合 $D$ 与潜在设施集合 $F$，设施 $i$ 有建设费 $f_i$，客户 $j$ 连到设施 $i$ 需服务费 $c_{ij}$（满足三角不等式）。求设施子集 $S \subseteq F$ 与客户到 $S$ 的分配，使

$$
\min_{S} \Big[ \sum_{i \in S} f_i + \sum_{j} \min_{i \in S} c_{ij} \Big]
$$

LP 松弛用两类变量：$y_i$（设施是否开）、$x_{ij}$（客户 $j$ 是否连到设施 $i$）：

$$
\min \sum_i f_i y_i + \sum_{ij} c_{ij} x_{ij} \quad \text{s.t.} \quad \sum_i x_{ij} = 1\ \forall j, \quad x_{ij} \le y_i\ \forall i,j, \quad x,y \ge 0
$$

第二个约束「客户只能连到已开的设施」是选址问题的精髓。<span class="marginnote">这个 LP 与调度、覆盖的 LP 有一个微妙差别：它有 $x_{ij} \le y_i$ 的「耦合约束」，让变量之间互相牵扯。这使它的对偶不再只是「元素价格」，而变成「客户出价」与「设施费用」的联合博弈——对偶的新玩法由此展开。</span>

**重点：** 目标函数是「建设 + 服务」两笔开销，这是 UFL 一切复杂性的来源。如果只开一个设施，它就是平凡的「全连最近点」；难在「几个设施一起开、客户共享」的权衡。

## 2 对偶：客户出价、设施喊价

写出 UFL 的对偶，引入对偶变量 $v_j$（客户 $j$ 的「出价」）。经过化简，对偶问题可写成：

$$
\max \sum_j v_j \quad \text{s.t.} \quad \sum_j \max\big(0,\ v_j - c_{ij}\big) \ \le\ f_i \ \forall i, \quad v_j \ge 0
$$

直觉极为生动：**客户 $j$ 愿意为服务出价 $v_j$**；
它若连到设施 $i$，服务费 $c_{ij}$ 从出价里扣掉，剩下的 $\max(0, v_j - c_{ij})$ 是「贡献给建设费的份子」。一个设施的**建设费必须被它的客户们的份子凑满**，这是约束；所有客户出价之和最大化，这是目标。<span class="marginnote">这个对偶把 UFL 翻译成「拍卖」：客户是买家（每人愿意出 $v_j$ 买服务），设施是商品（建设费是底价）。约束说「任何设施的份子总和 ≤ 建设费」，弱对偶说「总出价 ≤ 最优总开销」。原始对偶算法的全程，就是让这场拍卖自行出清。</span>

**重点：** 对偶约束里有个 $\max(0, \cdot)$——客户对「太远的设施」不出份子。这看似小细节，却是算法能工作的关键：它让设施「只从愿意为它掏钱的客户那里筹建设费」。

## 3 公式解析：原始对偶算法与 3-近似

算法（Jain–Vazirani）分两阶段：

**阶段一（上升与试探性开店）：**
1. 所有客户以速率 1 同步提高出价 $v_j$。
2. 当 $v_j$ 首次达到某个 $c_{ij}$ 时，把边 $(i,j)$ 加入「连接」集合。
3. 一旦设施 $i$ 的份子总和 $\sum_j \max(0, v_j - c_{ij})$ 达到 $f_i$，就**试探性开店** $i$，并把连到 $i$ 的客户标记「已连接」（停止涨价）。
4. 已连接客户与已开店设施之间若有连接边，冻结。

**阶段二（修剪与最终分配）：**
5. 对试探性开的设施做**聚类**：按某种顺序挑选，若一个新设施 $i$ 与已选设施 $i'$ 的某个已连接客户「太近」（$c_{ii'} \le 2c_{i'j}$ 之类），就丢弃 $i$。
6. 每个客户分配到**最近的已开设施**。

**为什么是 3-近似？** 记客户 $j$ 停涨时的出价为 $\tau_j$。对每个客户 $j$：

- **分配费**：设 $j$ 最终连到已开设施 $i^*$。修剪保证存在一个试探性开的设施 $i'$ 使 $c_{i^*j}$ 有界。组合三角不等式可得 $c_{i^*j} \le 3\tau_j$（细节见下）。
- **建设费**：已开设施 $i$ 的建设费 $f_i$ 恰等于其份子总和，而聚类保证每个客户的份子至多被「一份」建设费吸收。

于是

$$
\mathrm{cost}(S) \ =\ \sum_{i \in S} f_i + \sum_j c_{i^*j} \ \le\ 3 \sum_j \tau_j \ \le\ 3\,\mathrm{OPT}
$$

最后一步用弱对偶：$\sum_j \tau_j$ 是某个可行对偶解的值。

**分配费的 3 倍论证**：客户 $j$ 停涨时 $v_j = \tau_j$。它要么在阶段一已连到某设施 $i$（此时 $c_{ij} \le \tau_j$），要么未连（此时最近的试探性设施也满足某种界）。对已连客户的修剪论证：设 $j$ 已连到试探性设施 $i'$，最终分配给了 $i^*$。聚类条件保证 $c_{i^*,i'} \le c_{i'j} + c_{i^*j}$ 的组合，而最终「最近分配」给出 $c_{i^*j} \le c_{i'j}$，于是 $c_{i^*j} \le 2c_{i'j} \le 2\tau_j + \tau_j = 3\tau_j$——三个 $\tau_j$ 分别来自「连接时的服务费」「修剪的聚类半径」「分配时最近的设施」。<span class="marginnote">这个「3 = 1 + 1 + 1」的拆解是 UFL 原始对偶的精髓：连接时贡献一个 $\tau_j$，聚类半径再贡献一个，最终分配又贡献一个。后来的改进（Mahdian 等的 1.52）本质上是在这「三个 $\tau$」上做文章——用更好的聚类规则把某个因子压下去。理解「比值怎么被拆成若干可独立优化的项」，你就握住了改进算法的钥匙。</span>

**重点：** 阶段二的**修剪**是整个算法的点睛之笔。没有修剪，试探性开的设施会过多、建设费爆表；修剪后，设施数量被聚类半径约束，建设费与服务费得到平衡。**「先贪婪地多开，再修剪到合理」** 是近似算法里反复出现的两段式设计。

**辨析｜易错点：** 聚类条件必须用**已连接客户**作中介（$c_{ii'}$ 与 $c_{i'j}$ 的比较），而不是设施间的原始距离——因为设施间距离无上界，而「经客户中转」才能用三角不等式把它控在 $\tau$ 量级。很多初写者直接拿设施距离聚类，导致论证断裂。

## 4 从 3 到 1.52：对偶拟合的第二次登场

Jain–Vazirani 的 3-近似开启了 UFL 的改进竞赛。Mahdian, Ye 与 Zhang 用**对偶拟合 + 贪心**把比值压到 1.52：算法仍是「按性价比贪心」，但分析改为**构造一个缩放的对偶解**——把客户出价按某个因子缩小后验证对偶可行性，从而把比值直接写成缩放因子。

UFL 也成为「近似比下界」的重要样本：
已知不能近似到 1.463 以内（除非 P=NP），因此 1.52 与下界之间只差约 0.06 的缝隙。<span class="marginnote">UFL 的近似比史是「逼近下界」的精彩案例：3 → 1.61 → 1.52 → 1.5（弱结果）……每一步都把「三个 $\tau$」的拆解再优化一格。它提醒我们：近似算法不是「找到就结束」，而常常是「找到 + 反复打磨」的长跑；而下界告诉我们长跑的终点在哪。</span>

**重点：** 对偶拟合在 UFL 上的成功，说明它不止适用于集合覆盖的 $H_n$——它是一套「把算法输出翻译成（近）可行对偶」的通用分析框架。算法可以不依赖 LP，但**证明一定要经过对偶**。

**延伸：** UFL 的「客户出价」对偶还有一个工程启示：
它给出了一个「分布式」的选址算法——每个客户独立涨价、每个设施自行判断是否被凑满，
无需全局 LP 求解器。
这种「局部信息驱动的近似」思想，正是分布式与联邦场景下组合优化的重要方向。
理解 UFL 的原始对偶，等于拿到这类「自组织近似算法」的第一把钥匙。

**补充：** 若把客户换成「请求」、设施换成「服务器集群」，
UFL 的 LP 与对偶几乎原封不动地描述了 CDN 节点选址问题——
只是 $c_{ij}$ 换成网络延迟、$f_i$ 换成机房建设成本。
这解释了为什么 UFL 是算法课程里「离工业最近」的问题之一。

## 5 小结

- **UFL**：开设施建设费 + 客户服务费的两笔权衡；LP 用 $x_{ij} \le y_i$ 耦合变量。
- **对偶 = 拍卖**：客户出价 $v_j$，贡献 $\max(0, v_j-c_{ij})$ 凑设施建设费；总出价 ≤ 最优。
- **原始对偶 3-近似**：同步涨价 → 份子凑满则试探性开店 → 聚类修剪 → 最近分配。
- **3 = 三个 $\tau$**：连接服务费 + 聚类半径 + 最终分配，各自贡献一个出价上界。
- **修剪**是两段式设计的核心：先多开、再修剪，平衡建设费与服务费。
- **1.52 纪录**来自对偶拟合 + 贪心；下界 1.463，缝隙很小。

在下一节，我们给设施选址加上「预算帽」——**k-中位数问题**：
只能开恰好 $k$ 个中心，只最小化客户到最近中心的距离之和。
而这条「恰好 k」的基数约束，将逼出拉格朗日松弛这件处理基数约束的标准武器——
把问题退回已经会解的设施选址，再用二分搜索逼近「恰好 k」。
读者若能在此预判出「约束换罚金、罚金再二分」的套路，就掌握了处理一切基数约束问题的钥匙。
