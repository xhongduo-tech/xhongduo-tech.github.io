# PCP 定理与 Max-3SAT 的不可近似性

<div class="epigraph">

## 为什么从 PCP 定理开始

上一篇的缺口归约是「手工制造」不可近似的机器：每个问题都要专门设计归约。
1992 年，Arora 等人证明的 **PCP 定理**把这件事**工业化**了：
它等价于「Max-3SAT 有一个常数不可近似下界」，而由于 Max-3SAT 能编码一切 NP 问题，**一次证明、处处生效**——几乎每个 NP 优化问题都自动获得了常数下界。这是二十世纪计算复杂性最深刻的定理之一，也是「近似算法」这门学科真正成形的地基。

这一篇讲清 PCP 定理是什么、它与 Max-3SAT 不可近似如何互相翻译，以及 Håstad 如何把常数下界推到 7/8 的绝对极限。MAX-3SAT 的 7/8 在 MAX-SAT 篇已作为「焊死的上界」预告——现在补上「焊死」的那一半证明。

## 1 概率可验证证明：改写的证明观

传统 NP 的验证器拿到一个完整证明，从头到尾读完，确认是「yes」才接受。
**PCP（probabilistically checkable proof）验证器**换一种玩法：
允许随机数，只抽查证明的**少数位置**，以高概率接受正确证明、拒绝错误证明。

一个语言 $L$ 属于 $\mathrm{PCP}[r(n), q(n)]$，若存在多项式时间验证器 $V$：

- **完备性（completeness）**：若 $x \in L$，存在证明 $\pi$ 使 $V$ 用 $r(n)$ 个随机位、查 $q(n)$ 个位置后**以概率 1（或 ≥ c）接受**。
- **可靠性（soundness）**：若 $x \notin L$，对任意证明 $\pi$，$V$ **以概率 ≤ s（< c）接受**。

随机位与查询数是关键资源：
随机位越少、查询越少，验证器越「吝啬」，定理越强。<span class="marginnote">经典 NP 是「读完整个证明」：$\mathrm{NP} = \mathrm{PCP}[0, \text{多}]$。PCP 定理的震撼在于把「读完」换成「只查常数个位置」，代价只是一点点随机性——但可靠性只能保证「以概率拒绝」，这正是「概率可验证」的含义。想象审稿人不再通读论文，只随机抽查三个公式——却仍能以高概率抓住伪造，这就是 PCP 的思想。</span>

## 2 PCP 定理：NP 的一口价证明

**PCP 定理（Arora–Safra 1992；Arora–Lund–Motwani–Sudan–Szegedy 1992）：**

$$
\mathrm{NP} \ =\ \mathrm{PCP}[O(\log n),\ O(1)]
$$

即：每个 NP 语言都有验证器，只用 $O(\log n)$ 个随机位、查 $O(1)$ 个位置。

**为什么随机位 $O(\log n)$？** 因为 $O(\log n)$ 个随机位只产生 $n^{O(1)}$ 种随机串，验证器对每种随机串查常数个位置，于是「哪些位置一起被查」的约束总数是多项式——这套约束可以编码成 Max-3SAT 实例。<span class="marginnote">这个观察是 PCP → 近似下界的桥梁：把「验证器的查询」翻译成「子句」，把「证明」翻译成「赋值」，完备性（接受）对应「可满足」，可靠性（拒绝）对应「几乎不可满足」——中间被拉开的概率差就是缺口。PCP 的随机位数决定子句规模（多项式），查询数决定子句大小（常数个文字），因此编码出来的是 Max-3SAT（每个子句 3 个文字）级别的实例。</span>

**证明脉络（了解级）**：PCP 定理的证明是一台巨大的**缺口放大机**（Dinur 2007 的证明更简洁）：从某个常数缺口出发，反复「并行复合 + 一致性放大」，每轮把缺口乘上常数因子，同时控制规模，$O(\log n)$ 轮后缺口到常数。<span class="marginnote">Dinur 的缺口放大证明值得一提：她把「把缺口从小常数放大到大常数」设计成「对约束图反复做『幂 + 一致性检验』」的组合操作——每一轮规模小幅增长、缺口翻倍。这个「重复放大」的思路，后来成为「局部到全局」论证的模板。理解缺口放大，就理解了 PCP 定理「为什么会存在」而不只是「它说什么」。</span>

**重点：** PCP 定理的威力在于**等价性**：它不是「NP 有一个奇怪证明系统」的孤立事实，而是「NP 问题的可近似性下界」的通用来源。给任意 NP 优化问题 $\Pi$，只要能把 PCP 验证器编码成 $\Pi$ 的实例，就自动得到 $\Pi$ 的常数不可近似下界。

## 3 公式解析：从 PCP 到 Max-3SAT 的 7/8

以 Max-3SAT 为终端，走通「PCP → 缺口实例」的翻译：

1. **取 NP 完全判定问题 $L$**（比如 3-SAT）。PCP 定理给 $L$ 一个验证器：$O(\log n)$ 随机位、$O(1)$ 查询。
2. **编码成 Max-3SAT**：对每个随机串，验证器查询的 $O(1)$ 个位置对应 $O(1)$ 个布尔变量；「验证器接受」这个逻辑条件写成几个 3-子句。所有随机串产生的子句拼成一个 Max-3SAT 实例 $f(x)$，规模多项式。
3. **完备性 → 可满足**：$x \in L$ ⇒ 存在证明使验证器全接受 ⇒ 对应赋值满足**全部**子句，$\mathrm{OPT} = m$。
4. **可靠性 → 缺口**：$x \notin L$ ⇒ 任意证明最多以概率 $s$ 被接受 ⇒ 任意赋值最多满足 $s' \cdot m$ 个子句（$s' \lt  1$，具体由 PCP 参数决定），$\mathrm{OPT} \le s'm$。

于是判定 $L$ 变成「分辨 $\mathrm{OPT}=m$ 与 $\mathrm{OPT}\le s'm$」——**任何比值 $> s'$ 的近似算法都能区分**，所以 Max-3SAT 不可近似到 $s'$ 以内。<span class="marginnote">这里的 $s'$ 一开始是个「某个小于 1 的常数」。Håstad 的天才在于把可靠性压到极致：他的 PCP 参数化让 $s'$ 逼近 7/8，并同时证明「任何 $> 7/8$ 都不可行」。上篇已见过 Karloff–Zwick 的 7/8 算法，于是 7/8 两端合拢——这是「上界算法 + 下界 PCP」完美对接的典范。</span>

**第一步（PCP 参数化）**：选择随机位 $O(\log n)$、查询数 $O(1)$ 的验证器。
**第二步（子句编码）**：把「验证器接受」写成 3-子句，得到多项式规模的 Max-3SAT 实例。
- **第三步（完备/可靠 → 满/空）**：接受概率差变成最优值差（缺口）。
- **第四步（近似判定）**：缺口 > 近似比 ⇒ 矛盾 ⇒ 不可近似。

**Håstad 定理**：对任意 $\varepsilon > 0$，不存在多项式算法近似 Max-3SAT 到 $> \frac78 + \varepsilon$（除非 P = NP）。配套的还有 **3-LIN**（$\mathbb{Z}_2$ 线性方程系统）——它不可近似到 $> \frac12 + \varepsilon$，且 Max-3SAT 的 7/8 正是由 3-LIN 的 1/2 经「锯齿化」归约而来。

**重点：** 7/8 不是凑巧，而是 PCP 参数的**最优选择**：验证器用「3 个查询、二值变量」达到最佳可靠性，正好对应 3-子句与 7/8。**每一个「好看的不可近似常数」背后，都有一个精心调过的 PCP 验证器**——这是 PCP 时代近似下界的通用语法。

## 4 PCP 时代的收获：下界的工业化

PCP 定理之后，近似下界从「手工缺口归约」变成「流水线生产」：

- **顶点覆盖**：不可近似到 1.36 以内（Dinur–Safra）；在 UGC 下到 1.5。
- **集合覆盖**：不可近似到 $(1-\varepsilon)\ln n$（Feige），与贪心 $H_n$ 对齐。
- **Max-Cut**：不可近似到 0.941（Håstad）；UGC 下到 0.878（与 GW 对齐）。
- **多割 / 稀疏割**：获得 $\Omega(\log\log n)$ 或更强的下界。

每条结果都是同一台机器（PCP）的不同输出。<span class="marginnote">PCP 定理还有「配得上复杂性定理」的深刻后果：它与「NP 有交互式证明」「非逼近的间隙刻画」等结果同源，是「概率与证明」这条研究线的高峰。它的证明技术（一致性检验、平行复合、代数化）本身成了复杂性理论的通用语言——读懂 PCP 定理，等于拿到阅读近二十年复杂性文献的通行证。</span>

**辨析｜易错点：** PCP 给出的下界是「**常数**」还是「**函数**」，取决于验证器的查询数能否随问题变化。对 Max-3SAT，查询数恒为 3（常数），所以下界是常数 7/8；对集合覆盖，需要查询数随输入增长的 PCP 变体，下界变成 $\ln n$。**别把「PCP 给常数下界」当成普适结论**——常数只来自「常数查询」。

**延伸：** PCP 定理还有一个容易被低估的推论：
它把「证明」本身变成了一个可定量研究的对象——
「证明要多长、要抽查几处、能以多高概率放心」。
这套「证明的复杂性」语言后来渗透到密码学（交互式证明、零知识）、
机器学习（稳健验证）、乃至区块链（简洁验证 SNARKs）。
一个看似纯理论的结果，最终在密码协议里找到了工程生命。
这也是为什么 PCP 常被誉为「二十世纪计算复杂性最深刻的定理」之一。

**补充：** 从「上界/下界对账」的角度，7/8 的故事还有一层方法论启示：
当算法的常数与下界的常数精确重合（如 Max-3SAT 的 7/8），
说明我们对这个问题的理解「封顶」了——之后的工作只能转向
「更强假设下的版本」（如 UGC）或「更细粒度的问题变体」。
判断一个领域是否成熟，就看它的常数还有没有缝：
7/8 无缝，0.878 有缝（0.941 那端）——后者因此仍是活的问题。
读到这里，你已站在「上界与下界会合」这一近三十年核心叙事的地基上；
接下来标签覆盖会把「为什么会合在 7/8」这个问题的答案彻底揭开，
而平行复合与投影性质就是那把钥匙。
在那之前，先把「7/8 来自 3 查询、二值变量」这个对应记牢——
它是所有后续讨论的锚点。
下一站，标签覆盖将把这个锚点锻造成通用的归约引擎。

**补充（直觉）：** 用「审稿人抽查」感受 PCP 的可靠性。
- 传统验证 = 审稿人通读全文；PCP 验证 = 审稿人只随机抽查 3 个公式，却仍能以概率 $> \frac78$ 抓住伪造。
- 这个「概率」就是可靠性参数 $s$：对错误证明，任意抽查组合下接受概率 ≤ $s$。
- 随机位 $O(\log n)$ 保证抽查组合总数是多项式——于是「抽查哪些位置」能被编码成多项式规模的 Max-3SAT 实例。

## 5 小结

- **PCP**：验证器用 $O(\log n)$ 随机位、查 $O(1)$ 个位置，以概率区分接受/拒绝。
- **PCP 定理**：$\mathrm{NP} = \mathrm{PCP}[O(\log n), O(1)]$；等价于 Max-3SAT 有常数不可近似下界。
- **翻译链**：验证器 → 子句编码 → 完备/可靠概率差 → 最优值缺口 → 不可近似。
- **Håstad 7/8**：Max-3SAT 不可近似到 $> 7/8+\varepsilon$；3-LIN 的 1/2 是原始素材。
- 下界工业化：顶点覆盖 1.36、集合覆盖 $(1-\varepsilon)\ln n$、Max-Cut 0.941——同一台 PCP 机器的不同输出。
- **查询数决定下界形状**：常数查询给常数下界（7/8），查询随输入增长给函数下界（$\ln n$）；别把「PCP 给常数下界」当成普适结论。
- **7/8 的锚点**：验证器用 3 个查询、二值变量达到最佳可靠性——对应 3-子句与 7/8，这是后续一切讨论的起点。

在下一节，我们把 PCP 验证器翻译成一个「标准问题」——**标签覆盖问题与硬度归约**：双证明者游戏、投影性质与平行复合，让下界从 PCP 出发、经标签覆盖再抵达具体问题。
