## 为什么从集合覆盖的 schema 与局部比率开始

上一篇我们看到了原始对偶方法的骨架。这一篇把它在集合覆盖上做「彻底」，并引出两条延伸：
其一，原始对偶 schema 对**带权**集合覆盖（$c_j$ 任意）的直接应用及其 $f$-近似；
其二，一个看起来完全不同、实则等价的技术——**局部比率法（local ratio）**。

局部比率法的出发点朴素得惊人：
**如果能把权重 $c$ 拆成两份 $c^1 + c^2$，且同一个解对两份都分别是 $\alpha$-近似，那么它对原问题也是 $\alpha$-近似。** 这个「拆权重」的递归框架，与原始对偶的「同步涨价」表面毫无共同点，却能在集合覆盖上证明同一件事。理解它们的等价性，是本期最重要的认知收获：**近似算法的「技术」常常只是同一枚硬币的两面。**

## 1 原始对偶 Schema 在集合覆盖上的完整论证

把上一篇的算法写成正式 schema，并补上带权情形。设 $c_j > 0$ 任意：

1. 初始 $x = 0$，$y = 0$，所有元素未覆盖。
2. 只要还有未覆盖元素，就**同步提高**所有未覆盖元素的价格 $y_e$。
3. 一旦某个集合 $S_j$ 满足 $\sum_{e\in S_j} y_e = c_j$（**变紧**），就把 $x_j$ 置 1，并把 $S_j$ 覆盖的所有元素标记为已覆盖。
4. 重复。

结束时 $y$ 可行（任何集合要么未变紧、要么被选中，都不会超过 $c_j$）；
$x$ 可行（所有元素都被某个被选中集合覆盖）。比值 $f$ 的证明在上一篇已给出：
**每个选中集合都紧，元素频率 ≤ $f$，弱对偶收尾**。<span class="marginnote">这里有个值得注意的对称性：对偶拟合里是「先定价、后缩放」；原始对偶 schema 是「边涨边触发、天然可行」。同一个集合覆盖，同一个 $H_n$（对偶拟合）或 $f$（原始对偶）——两个比值哪个更小取决于实例，没有一个是普适最优。这个「一个问题的多个等价框架」正是本期主题。</span>

**重点：** 原始对偶 schema 还有一处精修——**「最违反约束」优先**。当多个集合同时变紧时，选择覆盖未覆盖元素**最多**的那个，可以显著改善实际表现，而比值仍被 $f$ 保证。这种「保证内优化」是近似算法工程的常态：理论比值是安全网，具体选择策略决定常数。

## 2 公式解析：局部比率引理

**局部比率引理：** 设权重 $w = w_1 + w_2$（分量权重），若可行解 $F$ 对 $(w_1)$ 与 $(w_2)$ 都是 $\alpha$-近似，则 $F$ 对 $w$ 也是 $\alpha$-近似。

**证明（最大化问题形式）：** 设 $\mathrm{OPT}_1, \mathrm{OPT}_2, \mathrm{OPT}$ 分别是三个权重下的最优值。对任意可行解 $F$：

$$
w(F) = w_1(F) + w_2(F) \ \ge\ \frac{\mathrm{OPT}_1}{\alpha} + \frac{\mathrm{OPT}_2}{\alpha}
$$

而 $\mathrm{OPT}_1 + \mathrm{OPT}_2 \ge \mathrm{OPT}$（把原问题最优解分别代入两个分量的定义——每个分量最优至少不差于取 $F^*$）。于是

$$
w(F) \ \ge\ \frac{\mathrm{OPT}_1 + \mathrm{OPT}_2}{\alpha} \ \ge\ \frac{\mathrm{OPT}}{\alpha}
$$

- **第一步（拆权重）**：$w(F) = w_1(F)+w_2(F)$，把解在总权重下的值拆成两个分量下的值。
- **第二步（代入分近似）**：对每个分量，$F$ 是 $\alpha$-近似，所以值 $\ge$ 该分量最优的 $1/\alpha$。
- **第三步（分量最优之和）**：$\mathrm{OPT}_1+\mathrm{OPT}_2 \ge \mathrm{OPT}$，因为原问题最优解是某分量可行解。
- **第四步（合并）**：得到 $w(F) \ge \mathrm{OPT}/\alpha$。<span class="marginnote">这个引理的价值在递归：把难权重拆成「简单分量（可直接解）+ 残余分量」，对简单分量直接给出最优（$\alpha=1$），对残余递归调用同一算法。只要递归的深度可控，就能用「组合局部近似」得到全局近似。它像归纳法的「拆第一项」——证明的关键是设计一个好的分解。</span>

对最小化问题，引理方向翻转：
$w(F) \le \alpha(w_1(F)+w_2(F)) \le \alpha(\mathrm{OPT}_1 + \mathrm{OPT}_2)$，再由 $\mathrm{OPT}_1 + \mathrm{OPT}_2 \le \alpha \cdot$…需要小心——最小化版本的证明是 $w(F) \le \alpha w_1(F^*) + \alpha w_2(F^*) = \alpha(w_1(F^*)+w_2(F^*)) = \alpha w(F^*) = \alpha \mathrm{OPT}$，其中 $F^*$ 是原问题最优解。这版更干净。

**辨析｜易错点：** 最小化与最大化版本的局部比率引理证明**不对称**：最大化靠「分量最优之和 ≥ 原最优」，最小化靠「直接把原最优代进两个分近似」。初学者常把两版混淆，推导时方向写反。**先定最大化/最小化，再选对应的引理形式。**

## 3 局部比率法设计集合覆盖：拆权重的艺术

用局部比率法重新设计集合覆盖，展示「拆权重」如何工作。对带权集合覆盖，递归地：

1. **选择**：若存在元素 $e$ 只被一个集合覆盖（孤元素），好办；否则任意挑一个未覆盖元素 $e$，设它所在的集合为 $S_1, \dots, S_k$。
2. **分解**：定义分量权重 $w_1$：对 $S_1,\dots,S_k$ 中**每个**集合，把 $w_1$ 设成「只靠 $e$ 计价」——$w_1(S_j) = \min_i w(S_i)$（取最小代价作为 $e$ 的单价，赋给每个含 $e$ 的集合），$w_1$ 在其他集合上为 0。剩余权重 $w_2 = w - w_1$。
3. **递归**：对 $w_2$ 递归求 $\alpha$-近似解 $F$，再检查是否需要补上某个含 $e$ 的集合。

关键在于：
$w_1$ 足够简单（只有一个非零「刻度」），对它任意可行解都有 $w_1(F) = w_1(\text{最优})$ 的接近性；$w_2$ 中 $e$ 的「需求」被移除，递归规模缩小。<span class="marginnote">这个分解的直觉：给「最难缠的元素 $e$」单独设一个计价分量，其余权重不含 $e$ 的约束，于是递归时 $e$ 不再碍事。局部比率法把「谁先被覆盖」的决策从算法里拿出来，放进<strong>权重分解</strong>里——选择被编码进权重，而不是算法步骤。这种「把决策转移到权重上」的设计自由度，正是局部比率法相对贪心的独特优势。</span>

**重点：** 对集合覆盖，这个局部比率递归等价于原始对偶 schema——**两者挑选同一组集合**。这不是巧合：瓦齐拉尼证明了**每个局部比率算法都可以翻译成原始对偶算法，反之亦然**。局部比率法于是成为理解原始对偶的「几何视图」：权重分解是对偶涨价的另一种画法。

## 4 局部比率的应用版图

局部比率法的名声来自它能干净地处理那些「原始对偶表达式很笨拙」的问题：

**顶点覆盖**：把边的权重分解给端点，得到 2-近似，证明比阈值舍入更直观。
**反馈顶点集**（feedback vertex set）：把环的权重递归拆给环上的顶点，得到近似解——原始对偶视角下这是「对偶变量挂在环上」。
- **集合覆盖的推广**：带元素权重的变体、多层覆盖问题，局部比率法都能自然延伸。

它还与**目标函数可加分解**的问题天然契合：
只要目标能拆成「好解的部分 + 好递归的部分」，局部比率就接管。<span class="marginnote">在算法教科书里，局部比率法常被归为「把近似比证明变成归纳法」的技术——它把「难证明的全局近似」还原成「好证明的逐步近似」。对想自己设计近似算法的人来说，它是比原始对偶更「好上手」的思维起点，因为拆权重比管理对偶价格更直观。</span>

**延伸：** 局部比率法还有一个优雅的递归视角：
它对「分量权重 $w_1$ 直接给最优」、对「残余 $w_2$ 递归」——
这本质上是在对偶变量上做「分解」。
瓦齐拉尼证明了这种分解与原始对偶的「同步上升」逐点对应，
因此「拆权重」的直觉可以移植到任何「目标可加分解」的问题上。
学完这一篇，你会获得两个工具箱：
一个用对偶价格（原始对偶），一个用权重分解（局部比率），而它们说的是同一件事。

**补充：** 理解两者等价性的一个直观抓手是「谁在涨」：
原始对偶里对偶价格在涨，触发条件是对偶约束变紧；
局部比率里权重分解在变，触发条件是「剩余权重下某个元素被孤立」。
两个视角观测同一个过程，一个看价格、一个看权重——
这种「同一算法的两种语言」现象在近似算法里比想象中普遍，
是训练「从不同角度理解算法」的好材料。
带着这面镜子去读后续的 Steiner 森林、设施选址，
你会发现自己能更快地抓住每个算法「在对偶里到底在做什么」。
这种「换一种语言看同一算法」的能力，正是近似算法进阶的分水岭。
下一节的 Steiner 树与 TSP 里，你会再次看到这种「换语言」带来的豁然开朗。

**补充（数值算例）：** 用两个集合感受拆权重。
- 设元素 $e$ 被 $S_1,S_2$ 覆盖，代价 $c(S_1)=3,\ c(S_2)=5$：取单价 $m=\min(3,5)=3$。
- 分量 $w_1$：$w_1(S_1)=3,\ w_1(S_2)=3$，其余为 0；残余 $w_2$：$w_2(S_1)=0,\ w_2(S_2)=2$。
- 对 $w_1$ 任意解都「等价」（覆盖 $e$ 恒付 3），对 $w_2$ 递归——$e$ 从递归里消失，规模缩小。
- 这正是「最难缠的元素单设计价、其余递归」的分解直觉：选择被编码进权重而非算法步骤。

## 5 小结

- **原始对偶 schema（带权集合覆盖）**：同步涨价、变紧触发、$f$-近似；对偶全程可行。
- **局部比率引理**：$w = w_1 + w_2$ 且 $F$ 对两者都 $\alpha$-近似，则对 $w$ 也 $\alpha$-近似；最小化与最大化版本证明不对称，方向不能写反。
- **局部比率设计集合覆盖**：给最难缠的元素单设计价分量，剩余权重递归；选择被编码进权重而不是算法步骤。
- **等价性**：每个局部比率算法可翻译成原始对偶算法，反之亦然——「拆权重」与「同步涨价」是同一枚硬币的两面。
