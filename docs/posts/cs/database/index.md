# 数据库

## 主题规划

- [ ] 关系模型与关系代数

- [ ] 规范化理论：函数依赖与范式
- [ ] 存储引擎：堆表、聚簇索引与页结构

- [ ] 查询处理：解析、重写与执行算子

- [ ] 事务与 ACID 的实现机制
- [ ] 并发控制：锁、MVCC 与隔离级别
- [ ] 日志与故障恢复：WAL 与 ARIES
- [ ] 复制与高可用：主从、半同步与 Paxos/Raft
- [ ] 分库分表与分布式事务（2PC、TCC、Saga）
- [ ] CAP、BASE 与一致性模型
- [ ] NoSQL 与 NewSQL：KV、文档、列存与 TiDB/Spanner
