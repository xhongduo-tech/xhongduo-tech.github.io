## 为什么从多值依赖开始

BCNF 消灭了函数依赖带来的所有冗余，但还有一种冗余它管不到。考虑一张「课程-教师-教材」表：一门课由多位教师授课、也使用多本教材，**教师与教材彼此独立**——课程 A 的两位教师必须和两本教材**做笛卡儿积**，产生 4 行。这不是函数依赖造成的（教师与教材之间没有函数决定关系），而是**多值依赖（multivalued dependency, MVD）**造成的。**第四范式（4NF）**正是为消灭这类冗余而设。这一节把多值依赖的定义、判定与 4NF 分解讲清楚。

## 1 多值依赖的定义

**多值依赖（multivalued dependency）** $\alpha \twoheadrightarrow \beta$：给定 $\alpha$ 的值，$\beta$ 有一组独立的值与之对应，且 $\beta$ 的取值**不依赖** $\alpha\beta$ 之外的属性。

形式化：关系 $r$ 满足 $\alpha \twoheadrightarrow \beta$，当且仅当对任意两行 $t_1, t_2 \in r$ 且 $t_1[\alpha] = t_2[\alpha]$，都存在行 $t_3, t_4 \in r$ 使得：

$$
t_3[\alpha] = t_4[\alpha] = t_1[\alpha], \quad
t_3[\beta] = t_1[\beta], \quad t_4[\beta] = t_2[\beta], \quad
t_3[R-\alpha-\beta] = t_2[R-\alpha-\beta], \quad t_4[R-\alpha-\beta] = t_1[R-\alpha-\beta]
$$

**直觉**：$t_1, t_2$ 在 $\alpha$ 上相同，则「$\beta$ 值与其余属性的所有组合」都必须出现——这正是笛卡儿积。

**核心要点：函数依赖是多值依赖的特例。** 若 $\alpha \to \beta$，则必然 $\alpha \twoheadrightarrow \beta$（函数决定时，$\beta$ 集合退化为单元素）。反之不然——多值依赖描述「一对多、且互不干扰」的独立关系。

## 2 一个直观例子

考虑关系模式 (course_name, teacher_name, book_name)：一门课有多位教师、也多本教材，且教师与教材相互独立变化。

数据（课程「数据库」）：

| course_name | teacher_name | book_name |
| --- | --- | --- |
| 数据库 | 张三 | 数据库概念 |
| 数据库 | 张三 | SQL 教程 |
| 数据库 | 李四 | 数据库概念 |
| 数据库 | 李四 | SQL 教程 |

课程决定多值：$course\_name \twoheadrightarrow teacher\_name$（张三、李四）、$course\_name \twoheadrightarrow book\_name$（两本教材）。但**函数依赖不存在**：$course\_name$ 不决定单个教师、不决定单本教材。冗余来自教师与教材的**独立性**：4 行里信息只有「2 位教师 + 2 本书」，却存成 4 行。

**辨析｜易错点：** 这样的表满足 BCNF 吗？候选码是 (course_name, teacher_name, book_name) 全三列，没有非平凡函数依赖，**满足 BCNF**。可见 BCNF 管不了这种冗余——必须靠 4NF。

## 3 第四范式（4NF）

**第四范式**：模式 $R$ 满足 4NF，当且仅当对每个非平凡多值依赖 $\alpha \twoheadrightarrow \beta$，$\alpha$ 都是 $R$ 的超码。

**4NF 与 BCNF 的关系**：因为函数依赖是特殊的多值依赖，**4NF ⊆ BCNF**。4NF 是「把 BCNF 的『左侧超码』要求推广到多值依赖」。

**4NF 分解算法**：与 BCNF 分解算法几乎一样，只是把「违反 BCNF 的函数依赖」换成「违反 4NF 的多值依赖」：

```text
result = {R}
while result 中某个模式 Rᵢ 违反 4NF:
    找到 Rᵢ 中非平凡的多值依赖 α ↠ β
    result = (result − {Rᵢ}) ∪ {Rᵢ − (β − α), α ∪ β}
```

每步仍无损（公共属性 α，且 α 决定 αβ 的多值版本）。<span class="marginnote">4NF 分解的直觉与 BCNF 完全平行：发现「独立变化」的 β，就把它单独拆成一张表，让 α 在子模式里成为超码。上面的课程-教师-教材表拆成 <strong>course_teacher(course, teacher)</strong> 与 <strong>course_book(course, book)</strong> 两张，各 2 行，冗余消失。</span>

## 4 公式解析：多值依赖与无损分解

多值依赖与无损分解之间有一条深刻联系：**多值依赖 $\alpha \twoheadrightarrow \beta$ 存在，当且仅当把 $R$ 分解为 $R_1 = \alpha\beta$ 与 $R_2 = \alpha(R-\beta)$ 是无损的**。

- **第一步，看等价性**：$R_1 \cap R_2 = \alpha$，$R_1 - R_2 = \beta$。多值依赖恰好断言「$\beta$ 与 $R-\alpha-\beta$ 独立变化」。
- **第二步，无损即独立**：$R_1 \bowtie R_2$ 精确还原 $R$ ⇔ 每个 $\alpha$ 值下的 $\beta$ 集合与 $R-\alpha-\beta$ 集合**任意组合都存在**——这正是 $\alpha \twoheadrightarrow \beta$ 的定义。
- **第三步，与函数依赖对比**：函数依赖下的二元无损条件是「$\alpha$ 决定一侧」；多值依赖放宽为「$\alpha$ 与两侧相互独立」。
- **第四步，指导实践**：发现「独立变化」的两组属性，就大胆拆表——无损性由多值依赖自动保证。

## 5 一个综合判断流程

给定模式与依赖集，规范化到 4NF 的流程：

1. **找候选码**（闭包算法）。
2. **检查函数依赖**：是否有非超码左侧的 FD？有则按 BCNF 拆。
3. **检查多值依赖**：是否有非超码左侧的 MVD？有则按 4NF 拆。
4. **验证**：每一步用 Chase 或二元判据验证无损；4NF 分解可能丢依赖（与 BCNF 同病）。

**核心要点（范式对照表）：**

| 范式 | 消灭的冗余 | 判据 |
| --- | --- | --- |
| BCNF | 函数依赖冗余 | 每个非平凡 FD 左侧是超码 |
| 4NF | 多值依赖冗余 | 每个非平凡 MVD 左侧是超码 |
| （5NF） | 连接依赖冗余 | 每个连接依赖可由候选码推出 |

## 6 多值依赖的数值算例与术语速查

**把 4NF 分解的收益算到具体数字。** 设课程-教师-教材表：5 门课、每门课 3 位教师、3 本教材。

- **分解前（3NF/BCNF 满足）**：每门课教师 × 教材笛卡儿积 = $5 \times 3 \times 3 = 45$ 行——实际信息只有「5 门课 × 3 教师 = 15」+「5 门课 × 3 教材 = 15」= 30 条。
- **分解后**：course_teacher（15 行）+ course_book（15 行）= 30 行——**冗余消失，省 15 行**。
- **查询代价**：查「某课的教师与教材」从 1 次读 9 行变 2 次读（3 + 3）——**用连接换空间**，与规范化一贯的权衡一致。

**数值算例：多值依赖的判定** 设 $r(A, B, C)$，观察数据「A=1 时 B 取 {x,y}、C 取 {p,q}」。

- 若 4 行全出现（x,p / x,q / y,p / y,q）——$A \twoheadrightarrow B$ 且 $A \twoheadrightarrow C$ 成立（独立变化）。
- 若只出现 (x,p) 与 (y,q)——B 与 C 绑定变化——**无多值依赖**（$A$ 到 $B$、$A$ 到 $C$ 都是函数依赖关系或普通一对多）。
- **启示**：判断 MVD 要看「组合是否全出现」——**数据里「缺失的组合」是 MVD 不成立的证据**。

**辨析｜易错点：** 多值依赖是**模式语义**，不是「当前数据碰巧成立」——与函数依赖同理。**一组数据里「组合全出现」只能说明「可能」有多值依赖**，是否真是约束要靠业务语义确认（如「教师与教材确实相互独立」）。

<span class="marginnote">把 4NF 与第 7 章「多值属性拆子表」连起来：<strong>第 7 章说「多值属性要拆子表」，第 8 章的多值依赖给出了「为什么拆」的数学理由</strong>——一个学生的多个电话 + 多个地址若不拆，就是多值依赖冗余。概念设计的直觉，在这里被形式化成定理。</span>

### 术语速查

| 术语 | 含义 |
| --- | --- |
| 多值依赖 | α ↠ β，β 与其余属性独立 |
| 4NF | 非平凡 MVD 左侧是超码 |
| 笛卡儿积冗余 | 独立变化组相乘 |
| 4NF 分解 | 把独立 β 拆成独立表 |
| BCNF | 只处理函数依赖 |
| 5NF | 处理连接依赖（更一般） |

## 7 小结

- **多值依赖** $\alpha \twoheadrightarrow \beta$：$\beta$ 与其余属性独立变化，产生笛卡儿积式冗余；函数依赖是其特例。
- 「课程-教师-教材」满足 BCNF 却仍冗余——**BCNF 管不到多值依赖**。
- **4NF**：每个非平凡 MVD 左侧是超码；4NF ⊆ BCNF；分解算法与 BCNF 平行。
- 多值依赖 ⇔ 二元分解无损，这是 4NF 分解无损性的根源。
- 独立变化的属性组应拆成独立表，让 $\alpha$ 在子模式里成为超码。
