# 黑盒测试：等价类划分与边界值分析

## 为什么从等价类划分开始

白盒测试看内部结构，**黑盒测试（black-box testing）**只看**输入输出**——把软件当作黑箱，不关心内部实现。但"只测输入输出"有个难题：输入空间是无穷的，怎么选一组"代表性输入"？这一节讲黑盒测试两大基石：**等价类划分**（怎么分组）与**边界值分析**（重点测哪里）。

## 1 等价类划分：以类代点

**等价类划分（equivalence partitioning）**：把输入数据按"对程序行为的影响"分成若干**等价类**，同一等价类中任意一个数据在测试中"等价"——测一个代表即可，不必全测。

核心思想：**行为相同的输入归为一类**。每个等价类取一个代表数据，即可代表整类。

- **有效等价类**：合理的、程序应接受的输入。
- **无效等价类**：不合理的、程序应拒绝的输入。

以"年龄输入（1–120 的整数）"为例：

| 等价类 | 代表值 |
| --- | --- |
| 有效：1–120 的整数 | 25 |
| 无效：< 1 的整数 | 0、-5 |
| 无效：> 120 的整数 | 150 |
| 无效：非整数 | 25.5 |
| 无效：非数字 | "abc" |

**辨析｜易错点：** 等价类划分最容易被忽视的是**无效等价类**——测试者常只测"合法输入"，忘了测"非法输入应该被优雅拒绝"。而现实中大量缺陷恰恰在非法输入的处理上（崩溃、报错不友好、SQL 注入入口）。**无效等价类与有效等价类同等重要**——每个无效类都应至少设计一条用例。

## 2 边界值分析：bug 的聚集地

**边界值分析（boundary value analysis）**基于一个经验事实：**缺陷往往聚集在输入的边界附近**——把 `<` 写成了 `<=`、数组越界、恰好差一位。因此测试要**重点覆盖边界及其附近**。

对范围 `[1, 120]`，边界值分析法要测：

- 边界本身：1、120
- 边界内外侧：0、121（相邻值）
- 通常还包含 2、119 等次边界

**辨析｜易错点：** 边界值分析 ≠ 等价类划分。等价类测"类内代表"，边界值测"**类的边界与边界两侧**"。两者互补：等价类保证"覆盖面"，边界值保证"险要处"。实践中常结合——先划分等价类，再在每类边界处加强测试。

## 3 边界值分析作为"公式"

Pressman 给出的边界值分析方法可以形式化。对两个输入 $a \in [1, 10]$、$b \in [1, 20]$，边界值分析要求测试：

- 每个边界本身（1、10、20 等）
- 边界的相邻值（0、2、11、21 等）
- 略超过边界的值（–1、11、21 等）
- 正常值（作为"基准"用例）

**公式解析**：对 $n$ 个输入变量，每个变量的有效范围 $[L, U]$，边界值分析生成约 $4n + 1$ 条用例：$4n$ 条是"每个变量取边界与近边界值、其余变量取正常值"，加 1 条"所有变量都取正常值"。它把"无穷输入"压缩成了"与输入变量个数线性相关"的测试集——这是黑盒测试"聪明抽样"的定量体现。

## 4 两种技术的配合

| 维度 | 等价类划分 | 边界值分析 |
| --- | --- | --- |
| 回答 | 输入怎么分组 | 边界测哪里 |
| 选择 | 每类取代表 | 边界及相邻值 |
| 覆盖 | 类级覆盖 | 边界级覆盖 |
| 侧重 | 有效/无效类 | 边界内外侧 |
| 关系 | 先划分 | 在边界处加强 |

**辨析｜易错点：** 两种技术都适用于**所有输入维度**——不仅数值范围，还有集合（空集、全集、单元素）、字符串（空串、单字符、超长）、枚举（每个枚举值）。测试设计者的成熟度，体现在"对每种输入都自觉做等价类 + 边界值"——而不是只对"年龄"这种明显数值做。<span class="marginnote">一个真实的教训：某系统的密码强度校验，用 `len >= 7` 判断"至少 7 位"，测试只测了 7 位与 8 位（等价类内）就通过，上线后用户发现 6 位密码能注册——正是边界值（6 位）漏测。边界值分析抓的不是"大 bug"，而是"恰好差一位"的 bug，而这类 bug 最伤信任。</span>

## 5 小结

- **黑盒测试**只看输入输出，不关心内部实现。
- **等价类划分**把输入按行为分组成等价类，每类取一个代表；**有效与无效类同等重要**。
- **边界值分析**重点测边界与相邻值，因为缺陷聚集在边界。
- 对 $n$ 个输入，边界值分析约生成 $4n+1$ 条用例，把无穷输入压缩成线性规模。
- 两者互补：等价类保覆盖、边界值保险要，通常先划分、后加强边界。
- 两种技术适用于所有输入维度，不只数值。
