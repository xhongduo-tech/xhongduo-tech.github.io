# 期望Sarsa

<div class="epigraph">

## 为什么 Sarsa 可以更聪明

Sarsa 的更新目标里，下一步动作价值 $Q(S_{t+1}, A_{t+1})$ 依赖一个随机采样：$A_{t+1}$ 是从策略里抽出来的，同一次转移可以因为「恰好抽到次优动作」而给出偏低的目标。**期望 Sarsa（Expected Sarsa）** 把这一步采样换成对下一个状态上**所有动作价值按策略概率取期望**，从而把随机性从目标里抹掉。这是「用计算量换方差」的经典权衡：多算一次期望，少抖一个随机源。<span class="marginnote">「对随机量取期望以消方差」正是第5章重要性采样方差削减、以及第7章每决策方法背后的同一哲学——随机性只该保留在无法消除的地方。</span>

这个「以计算换方差」的思想并不只属于 TD：它在统计里叫**控制变量（control variate）**，在蒙特卡洛里叫**方差削减**。把「从策略里抽一个动作」这种无害却吵闹的随机源消灭掉，剩下的随机性就只剩环境本身——那才是真正无法消除的部分。学期望 Sarsa，其实是在学「如何判断一个随机源是否值得留下」。

## 1 期望 Sarsa 更新：期望取代采样

期望 Sarsa 的更新是：

$$
Q(S_t, A_t) \;\leftarrow\; Q(S_t, A_t) + \alpha \Big[\,R_{t+1} + \gamma \sum_a \pi(a \mid S_{t+1})\, Q(S_{t+1}, a) - Q(S_t, A_t)\,\Big]
$$

目标里第二项从 $Q(S_{t+1}, A_{t+1})$ 换成了

$$
\mathbb{E}_\pi\big[Q(S_{t+1}, \cdot)\big] \;=\; \sum_a \pi(a \mid S_{t+1})\, Q(S_{t+1}, a)
$$

与 Sarsa 相比，目标去掉了采样噪声——同一个 $(S_t, A_t)$ 无论随机抽到哪个 $A_{t+1}$，期望 Sarsa 给出的目标都相同，更新的方差因此严格更低。代价是：**需要遍历 $S_{t+1}$ 的所有动作**。动作空间小（表格型）时这个代价微不足道；动作连续或巨大时（深度 RL），求和变成不可行的遍历——那正是第13篇以后策略梯度方法登场的理由。<span class="marginnote">在风变网格世界这样的表格环境里，期望 Sarsa 通常比 Sarsa 更快更稳；而它的「额外计算」只是乘加，几乎可以忽略。</span>

### 数值算例：期望怎么抹掉抽签运

设状态 $S_{t+1}$ 下有两个动作，$Q(S_{t+1},a_1)=1.0$、$Q(S_{t+1},a_2)=0.5$；行为策略是 $\varepsilon$-贪心（$\varepsilon=0.2$），$\gamma=0.9$，$R=0$，$\alpha=0.1$，$Q(S_t,A_t)=0$。

- **Sarsa 的两种命运**：抽到 $a_1$，目标 $=0.9 \times 1.0 = 0.9$，$Q$ 单步推到 $0.09$；抽到 $a_2$，目标 $=0.9 \times 0.5 = 0.45$，$Q$ 只推到 $0.045$。**同一转移，目标在 $0.45$ 与 $0.9$ 之间随抽签波动**。
- **期望 Sarsa 的确定性**：$\pi(a_1 \mid S_{t+1}) = 0.9$、$\pi(a_2 \mid S_{t+1}) = 0.1$，期望目标 $= 0.9 \times 0.9 \times 1.0 + 0.1 \times 0.9 \times 0.5 = 0.81 + 0.045 = 0.855$，$Q$ 稳定推到 $0.0855$。

无论接下来怎么抽，这一步的目标都是 $0.855$——抽签的随机性被期望运算吸收了，剩下的只有环境自身的随机。

## 2 同策略还是离策略？它两栖

期望 Sarsa 的一个独特之处在于**策略 $\pi$ 写进了目标里**，因此它的学习/行为关系完全由 $\pi$ 的选取决定：

取 $\pi$ 为**当前行为策略**（如 $\varepsilon$-贪心）：目标估计的就是行为策略的价值，这是**同策略**的期望 Sarsa，行为与目标一致，性质类同 Sarsa 但方差更小。
取 $\pi$ 为**贪心策略**：此时 $\sum_a \pi(a|S_{t+1})Q(S_{t+1},a) = \max_a Q(S_{t+1},a)$——**期望 Sarsa 退化为 Q-learning**。<span class="marginnote">这个退化关系很值得记：Q-learning 是「目标策略为贪心」的期望 Sarsa 特例。教材正是这样组织的——先讲期望 Sarsa，再把它当作 Q-learning 的统一视角。</span>
取 $\pi$ 为**任意目标策略** $b$：构成一般意义上的离策略期望 Sarsa，用行为策略数据学习任意目标策略的价值。

因此教材称它是「介于 Sarsa 与 Q-learning 之间的统一体」。**当 $\varepsilon>0$ 时，期望 Sarsa 的误差可以严格小于 Q-learning**：因为 Q-learning 的 $\max$ 会对估计噪声取极大（抬高估计），而期望 Sarsa 的期望运算天然对噪声做了平滑。<span class="marginnote">这一结论是 van Seijen 等人的经典分析：对 $\varepsilon$-贪心策略，期望 Sarsa 的稳态期望误差通常低于 Q-learning，尤其在 $\varepsilon$ 较大时优势更明显。</span>

把三个算法并排放进一张对照表，家族谱系就清晰了：

| 对比维度 | Sarsa | 期望 Sarsa | Q-learning |
| --- | --- | --- | --- |
| 目标里的下一步价值 | $Q(S',A')$（采样） | 按 $\pi$ 加权平均 | $\max_a Q(S',a)$ |
| 单步更新方差 | 高 | 低 | 中 |
| 同 / 离策略 | 同策略 | 可同可离 | 离策略 |
| 是否需遍历动作 | 否 | 是 | 是 |
| 误差倾向 | 贴近行为策略 | 平滑、稳健 | $\max$ 会高估 |

**读表的要点：三者的差别全在「目标里第二项怎么写」**——采样、期望、最大值，分别对应「看运气、看平均、看最好」。理解这一列，就抓住了 TD 控制家族的全部变体。

## 3 公式解析：期望怎么消掉一个随机源

$$
Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha\big[\,R_{t+1} + \gamma \underbrace{\sum_a \pi(a|S_{t+1}) Q(S_{t+1},a)}_{\text{动作价值的策略加权平均}} - Q(S_t, A_t)\,\big]
$$

- **第一步，认加权**：$\sum_a \pi(a|S_{t+1}) Q(S_{t+1},a)$ 是把 $S_{t+1}$ 下所有动作的价值，按策略 $\pi$ 的动作概率加权求和。若 $\pi$ 把 90% 概率给动作 $a_1$、10% 给 $a_2$，目标就取 $0.9 Q(S_{t+1},a_1) + 0.1 Q(S_{t+1},a_2)$。
- **第二步，看它取代了什么**：Sarsa 的目标是「抽一次 $A_{t+1}$ 得到的 $Q(S_{t+1},A_{t+1})$」，这是个随机变量；期望 Sarsa 的目标是它的期望。**随机变量被常数替代，方差归零**（在该状态下）。
- **第三步，算账**：期望 Sarsa 每步多算一次「概率 × 价值」的求和，换来目标方差下降；代价只在动作空间巨大时变得不可承受。这是教科书里「方差与计算量的第一笔交易」，也是第7章 n步方法的预告——n步也是把「采样更多步」与「期望」做折中。

### 三个算法在同一转移上的三种目标

把同一份经验 $(S_t,A_t,R_{t+1},S_{t+1})$ 喂给三个算法，目标会各走各路。设 $S_{t+1}$ 下 $Q=(1.0,0.5)$、行为策略 $\varepsilon$-贪心且 $\varepsilon=0.2$、$\gamma=0.9$：

| 算法 | 目标第二项 | 本转移的目标值 |
| --- | --- | --- |
| Sarsa | $0.9 \times Q(S_{t+1}, A_{t+1})$ | $0.45$ 或 $0.9$（看抽签） |
| 期望 Sarsa | $0.9 \times (0.9 \times 1.0 + 0.1 \times 0.5)$ | $0.855$（恒定） |
| Q-learning | $0.9 \times \max(1.0, 0.5)$ | $0.9$（恒定，偏高） |

同一个转移，Sarsa 给了个会抖的目标，Q-learning 给了个偏高（对噪声取极大）的目标，期望 Sarsa 给了个居中且稳定的目标。**三者不是「谁对谁错」，而是方差、偏差、计算量三组指标上各取所长的取舍**——这就是表格型 TD 控制选型时真正要权衡的东西。

## 4 易错点辨析

**辨析｜易错点：** 以为期望 Sarsa 一定离策略。**它本身不规定策略来源**——同策略或离策略取决于你给目标里的 $\pi$ 喂什么。最容易的记法：目标里显式出现 $\pi$ 的，策略关系由外部指定；目标里出现 $\max$ 或采样 $A_{t+1}$ 的，策略关系内嵌在更新规则里。

**另一个易错点**：混淆「期望 Sarsa 的期望」与「贝尔曼期望算子」。期望 Sarsa 的目标 $\mathbb{E}_\pi[Q(S_{t+1},\cdot)]$ 是对**下一状态动作价值**取期望；而贝尔曼期望算子是对**转移概率与奖励**取期望。前者在数据里可用、免模型，后者需要模型——两个「期望」作用于不同的随机源。<span class="marginnote">把「对什么取期望」说清楚，就能避免把免模型的 TD 方法与需模型的 DP 方法搅在一起——这是贯穿全书的一个概念分界线。</span>

**第三个易错点**：以为期望 Sarsa 的「期望」需要知道策略的精确概率。表格型里 $\pi(a|S_{t+1})$ 确实要显式算出（$\varepsilon$-贪心的概率是 $1-\varepsilon+\varepsilon/|\mathcal{A}|$）；但若策略是从 $Q$ 软导出（如 softmax），权重 $\pi(a \mid S_{t+1})$ 就得随 $Q$ 每次变化重新计算——这是「多算一次期望」里真正不便宜的部分。期望运算把随机性换成确定性，代价不是白来的。

### 为什么「遍历动作」会成为分水岭

期望 Sarsa 每步要遍历 $S_{t+1}$ 的所有动作：动作数 $|\mathcal{A}|=4$ 的网格世界只是 4 次乘加，可动作一旦变成连续空间（如机器人关节角的无穷集合），这个求和就失去了意义。这条**计算可行性边界**正是第13篇策略梯度方法登场的根本原因——当「对动作加权求和」不可行时，只能改为「沿梯度方向移动动作分布」。

也正因如此，期望 Sarsa 在表格型教材里是「理论上的优雅」，而 Q-learning 的 `max` 因只做一次比较、天然可配函数逼近，反而成为深度 RL 的主流入口。**优雅与实用之间的张力，从这里开始显现**——它是后面「表格方法如何过渡到函数逼近」这条主线的第一个路标。

## 5 小结

- **期望 Sarsa**：把 Sarsa 目标里的采样动作换成策略加权期望，方差更低，代价是多算一次求和。
- **两栖性**：目标里显式含 $\pi$，取行为策略即同策略、取贪心即退化为 Q-learning、取任意目标策略即离策略。
- 与 Q-learning 相比，期望 Sarsa 的期望运算平滑了噪声，**误差通常更小**（$\varepsilon$-贪心分析）。
- 计算代价随动作空间增长；动作巨大或连续时，这个求和不可行——导向策略梯度方法。
- 核心思想「以计算换方差」将在第7章的 n步方法里再次出现。
- 家族谱系：采样 → 期望 → 最大值，对应 Sarsa / 期望 Sarsa / Q-learning——目标里第二项的写法决定了全部性格。
- 在 GPI 框架里，期望 Sarsa 把「对策略求期望」这一步做成显式算子，让「评估什么策略」一目了然。
- 控制变量思想：凡能用确定性期望替换的随机源，都应替换——这是方差削减的通用配方。
- 数值感受：同一个转移，Sarsa 的目标可能在 $0.45$ 与 $0.9$ 之间波动，期望 Sarsa 恒定取 $0.855$——期望运算就是把「抽签」换成「加权平均」。
- 实践取舍：表格型环境里「多算一次期望」几乎免费，无脑选期望 Sarsa；动作巨大或连续时，期望求和失效，才轮到 Q-learning 的 `max` 与策略梯度出场。
- 与贝尔曼期望算子之别：前者对「动作价值」取期望（数据里可用、免模型），后者对「转移概率」取期望（需要模型）——两个期望指向不同的随机源。
- 一句话判据：**目标里出现的采样，若不给环境新信息就应替换成期望**——这条判据贯穿 n步方法、半梯度与 TD(λ) 的全程。
- 与第5章的联系：重要性采样消的是「策略不匹配」的方差，期望 Sarsa 消的是「策略内部抽签」的方差——同一种哲学的两个变奏。

把「以计算换方差」的配方再抽象一层：**任何出现在更新目标里的随机采样，只要它不携带环境的新信息，就可以（也应该）用期望替换**。Sarsa 抽 $A_{t+1}$ 不携带新信息（价值表已知），所以能换成期望；而 $S_{t+1}$ 的转移来自环境，无法用当前知识替换。这条「哪些随机源可消除」的判据，是理解第7章 n步方法、第9章半梯度方法的一条暗线——每一步采样都要先问一句「这个随机是必要的吗」。

在下一节，我们要直面 Q-learning 那枚隐藏的雷：**最大化偏差**——「对估计取最大值」会系统性高估，Double Learning 正是为拆除这颗雷而生。
