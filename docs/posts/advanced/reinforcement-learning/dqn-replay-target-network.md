## 为什么 Q-learning 配上深度网络会「碎」

前几章反复警告：Q-learning + 函数逼近 + 自举三要素齐备（致命三要素）容易发散。DQN 的贡献不是发明新公式，而是用**两份工程稳定剂**把这个「会碎」的组合硬生生压住：**经验回放（experience replay）**打散时序相关的数据，**目标网络（target network）**冻结自举目标、断开「目标随参数漂移」的正反馈。2015 年它在 49 个 Atari 游戏上达到人类水平，宣告深度强化学习的诞生。<span class="marginnote">DQN 的两个技巧恰好对应致命三要素的两个「开关」：回放把「离策略 + 相关数据」变成「近独立分布」，目标网络把「自举目标的即时漂移」变成「周期性冻结」。它们不是理论补丁，而是「知道会碎、所以小心捧着」的工程智慧。</span>

## 1 DQN 的更新：Q-learning 的「双网络」版

DQN 用深度网络 $Q(s,a;\boldsymbol{\theta})$ 近似动作价值，更新沿用 Q-learning 目标，但**目标里的价值用另一份参数 $\boldsymbol{\theta}^-$**：

$$
\boldsymbol{\theta} \;\leftarrow\; \boldsymbol{\theta} + \alpha\Big[\,r + \gamma \max_{a'} Q(s', a'; \boldsymbol{\theta}^-) - Q(s, a; \boldsymbol{\theta})\,\Big]\nabla Q(s, a; \boldsymbol{\theta})
$$

$\boldsymbol{\theta}$ 是**在线网络**（每步更新），$\boldsymbol{\theta}^-$ 是**目标网络**（固定不动，每 $C$ 步从 $\boldsymbol{\theta}$ 复制一次）。**目标网络切断「目标里含 $\boldsymbol{\theta}$」的即时反馈**：在 $C$ 步内，目标 $\max Q(\cdot;\boldsymbol{\theta}^-)$ 是常数，更新退化为「对一个固定目标做监督回归」——这正是致命三要素里「自举的即时性」被人工关掉的机制。<span class="marginnote">直觉：目标网络让「追的目标」慢半拍。半梯度的问题在于「目标随着你的参数一起动」，追着移动靶容易过冲；目标网络把靶子冻住 C 步，让网络「先追到冻结的靶，再移动靶子」——收敛因此稳得多。</span>

## 2 经验回放：打散时序，复用数据

**经验回放（experience replay）** 把经历的转移 $(s,a,r,s')$ 存进一个**回放缓冲区（replay buffer）**，训练时**均匀随机抽样**小批量来更新。它的三重收益：

1. **打破时序相关**：相邻经验强相关（一步之差），直接按序喂网络会破坏「独立同分布」假设、训练震荡；随机抽样让批次近似独立。
2. **数据复用**：一条经验被反复抽样、反复学习——样本效率大幅提升（这在样本昂贵的环境里是生死攸关）。
3. **平滑分布**：回放里的数据来自**历史所有策略**，让训练分布更平稳，避免「当前策略的偏科数据」把网络带偏。<span class="marginnote">回放是「离策略学习」的天然应用——正因为 Q-learning 能学「与行为策略不同的目标」，回放缓冲区的旧数据才能被反复使用。这也让 DQN 的数据效率远超 on-policy 方法（如策略梯度），但代价是「旧数据 + 新目标」的离策略偏差（第11章的隐患仍在，只是被工程压住）。</span>

## 3 DQN 的算法骨架与 Atari 成就

DQN 算法框的骨架：

1. 初始化在线网络 $\boldsymbol{\theta}$ 与目标网络 $\boldsymbol{\theta}^-=\boldsymbol{\theta}$，清空回放缓冲区。
2. 每步：以 $\varepsilon$-贪心在 $Q(\cdot;\boldsymbol{\theta})$ 上选动作，执行存 $(s,a,r,s')$ 进回放。
3. 每若干步：从回放**均匀抽样**一个小批量，用目标网络算 $\max$ 目标，对 $\boldsymbol{\theta}$ 做一步梯度更新。
4. 每 $C$ 步：$\boldsymbol{\theta}^- \leftarrow \boldsymbol{\theta}$。

**关键超参**：回放大小（常 1e6）、批量大小（32）、目标网络更新频率 $C$（如 10000）、$\varepsilon$ 退火（从 1.0 降到 0.1）。输入是游戏画面的**原始像素**（84×84×4 帧堆叠），输出是每个离散动作的 $Q$ 值——**特征从像素到价值，全部端到端学出**。<span class="marginnote">Atari 结果的震撼点不在「赢了多少分」，而在「只用像素输入 + 奖励信号，一个通用算法就能玩转几十个规则迥异的游戏」——这是「通用智能」在强化学习里的第一次大规模展示，也是深度学习 + RL 组合的里程碑验证。</span>

## 4 公式解析：目标网络如何稳住自举

$$
\mathcal{L}(\boldsymbol{\theta}) \;=\; \mathbb{E}_{(s,a,r,s')\sim\text{Replay}}\Big[\underbrace{\big(r + \gamma \max_{a'} Q(s',a';\boldsymbol{\theta}^-)}_{\text{冻结目标}} - Q(s,a;\boldsymbol{\theta})\big)^2\Big]
$$

- **第一步，认损失**：对回放样本求「TD 误差平方」的期望——标准的监督回归损失，目标由目标网络给出。
- **第二步，认冻结**：$\boldsymbol{\theta}^-$ 在 $C$ 步内是常数——**目标不随 $\boldsymbol{\theta}$ 变**。于是这是「真」监督学习：目标固定、只优化 $\boldsymbol{\theta}$，梯度下降的收敛性恢复（对固定目标）。
- **第三步，认代价**：目标冻结意味着「价值信号滞后 $C$ 步」——学习速度略降，但换来了稳定。**这是「慢一点但稳」的经典交易**：半梯度的不稳定来自「目标追着参数跑」，目标网络把「追」的幅度限制成「每 C 步跳一次」。<span class="marginnote">目标网络更新频率 $C$ 是一个「稳定性-速度」旋钮：$C$ 太小（目标跟得太近）≈ 半梯度、可能震荡；$C$ 太大（目标太久不变）学习迟钝。实践中 $C$ 取几千到几万步。Double DQN（下一课）会进一步消掉 $\max$ 带来的高估，和这里的目标网络是「两味互补的药」。</span>

## 5 易错点辨析

**辨析｜易错点：** 以为「回放缓冲区的数据应该优先用新数据」。经典 DQN 用**均匀抽样**——新旧经验一视同仁。优先抽「价值高的经验」（如优先经验回放）是后话，但均匀回放本身就是 DQN 稳定性的基础；把「最新数据」的权重调高会重新引入时序相关，动摇回放的意义。

**另一个易错点**：混淆「目标网络」与「冻结梯度」。目标网络是「**参数复制 + 周期性同步**」，不是「梯度截断/冻结」——$\boldsymbol{\theta}^-$ 完全不被更新，只在 $C$ 步时整体复制。别把它当成「对 $\boldsymbol{\theta}$ 加正则」。

**第三个易错点**：在 on-policy 算法（如策略梯度）里硬套经验回放。回放依赖「Q-learning 式离策略」才能合法使用旧数据；纯 on-policy 方法用回放会引入「旧策略数据 + 新策略目标」的偏差。**回放是离策略方法的资产，不是万能补丁**——这解释了为什么 A2C/PPO 用「并行环境」而非回放。

## 6 小结

- **DQN**：深度 Q-learning，更新目标用**目标网络** $\boldsymbol{\theta}^-$ 冻结、训练用**经验回放**打散数据。
- **目标网络**：每 $C$ 步复制在线参数，断开自举目标的即时漂移——「慢一点但稳」。
- **经验回放**：均匀抽样历史转移，破时序相关、复用数据、平滑分布。
- **算法骨架**：$\varepsilon$-贪心采集 → 存回放 → 抽样批量 → 对冻结目标做监督回归。
- Atari 上的成功验证了「深度网络 + RL + 稳定技巧」的组合，开启深度强化学习时代。

在下一节，我们拆掉 DQN 里 $\max$ 的隐患：**Double DQN** 用「双估计」削减高估，**Dueling Network** 把价值拆成「状态价值 + 优势」。
