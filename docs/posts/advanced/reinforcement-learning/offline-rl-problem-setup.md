## 为什么「用旧数据学新策略」这么难

在线 RL 边学边采——数据永远匹配当前策略。但很多场景**无法交互**：医疗处方不能乱试、自动驾驶不能拿人命探索、推荐系统收集一次用户反馈代价高昂。**离线强化学习（offline RL，又称 batch RL）** 的任务是：**只给一批固定的历史数据（行为策略采的），学出一个新策略**。听起来像「监督学习用数据集」，但 RL 的「自举」让这件事远比想象难——**分布偏移（distribution shift）与外推误差（extrapolation error）** 会让最朴素的 Q-learning 在离线数据上彻底失败。<span class="marginnote">离线 RL 与「模仿学习」的区别：模仿学习只学「照着行为策略做」（行为克隆）；离线 RL 要学「比行为策略更好」——它必须从数据里<strong>推断</strong>「哪些没做过的动作可能更好」，这正是难度所在，也是价值所在。</span>

## 1 问题设定：固定数据 + 学更好策略

**离线 RL** 的正式设定：给定一个**固定的转移数据集** $\mathcal{D} = \{(s, a, r, s')\}$（由某个未知/已知的行为策略 $b$ 收集），目标是学一个策略 $\pi$，使得「部署后」的性能优于行为策略 $b$ 本身。

与在线 RL 的对照：

| 维度 | 在线 RL | 离线 RL |
| --- | --- | --- |
| 数据 | 边学边采、匹配当前策略 | 固定数据集、来自旧策略 |
| 探索 | 主动探索未知 | 无法探索、只能利用已有 |
| 安全 | 可试错 | 部署前必须可靠 |
| 关键难题 | 探索-利用 | **分布偏移** |

**应用场景**（数据贵/危险/稀缺）：医疗（历史病历）、机器人（离线示教数据）、推荐、对话系统。**「先离线学个能用的，再上线微调」**是离线 RL 最现实的用法。<span class="marginnote">离线 RL 的「数据利用率」比「样本效率」更贴切：它不新增任何样本，只把<strong>已有的</strong>数据榨到极致。它也是「从人类数据/日志数据里学」——这直接通向 RLHF 的早期形态（用人类反馈数据学奖励/策略）。</span>

## 2 核心障碍一：分布偏移

**分布偏移**：训练时价值/策略被「数据里的状态动作分布」喂着，部署时策略遇到的分布不同。具体地：

- 数据由 $b$ 生成，覆盖「$b$ 常走」的区域；
- 学出的 $\pi$ 可能偏爱「数据里少见」的动作/状态；
- 一旦 $\pi$ 走到数据稀疏区，**没有数据纠正**——价值估计在那里完全靠猜。

在线 RL 里，这种偏移会被「新数据」自动纠正；离线 RL 里**没有任何纠错机制**，偏移只会越滚越大——**策略被自己带向数据盲区**。<span class="marginnote">分布偏移的数学本质：Q-learning 的更新期望来自「行为分布」，而收敛目标属于「目标分布」——两者错位正是第11章「致命三要素」里「离策略」的极端形态（数据彻底不更新）。离线 RL 的一切方法，本质上都在治「分布偏移」这个病。</span>

## 3 核心障碍二：外推误差

**外推误差（extrapolation error）** 是 Fujimoto 等 2019 年命名并分析的核心机制：**Q 函数对「没在数据里见过的动作」的估计是不准的，且系统性地高估**。

Q-learning 的目标 $\max_{a'} Q(s',a')$ 会**主动去寻找「Q 最大的动作」**——而这个动作往往不在数据集里（否则行为策略早就选了它）。对 OOD（out-of-distribution，分布外）动作，$Q$ 的估计是「外推」出来的，噪声大且**偏向高估**（最大化偏差的离线版）：

$$
Q(s,a)_{\text{OOD}} \;\gg\; \text{真实价值}
$$

于是策略学到「去选那个被虚高的 OOD 动作」——**越学越差，甚至完全崩溃**。<span class="marginnote">为什么「系统性地高估」？因为 $\max$ 对噪声取极大（第6章最大化偏差）——数据稀疏区里 $Q$ 的噪声被 $\max$ 选中放大。在线 RL 会被真实反馈「打脸」纠正；离线 RL 没有真实反馈，高估永远不被打脸——<strong>「没有批评者的谎言越说越真」</strong>。这就是离线 RL 的魔鬼。</span>

## 4 公式解析：外推误差如何摧毁 Q-learning

$$
\underbrace{Q(s,a) \leftarrow Q(s,a) + \alpha\Big[r + \gamma \max_{a'} Q(s',a') - Q(s,a)\Big]}_{\text{标准 Q-learning}} \qquad \text{当 } (s', a')\notin \mathcal{D}
$$

- **第一步，认查询**：$a' = \arg\max_{a'}Q(s',a')$ 是「当前 Q 认为最好的动作」。在线时它大概率被采到、有数据；离线时它**大概率不在数据集里**（否则行为策略早选了）。
- **第二步，认外推**：对 $(s', a') \notin \mathcal{D}$，$Q(s',a')$ 只能靠「特征相似的动作」外推——网络在数据稀疏区给出一个**不可靠且偏高**的估计。
- **第三步，认传播**：这个虚高的 $\max$ 被写回 $Q(s,a)$——**虚高沿贝尔曼方程扩散**。整张 Q 表被「虚构的高价值」污染，策略去追虚高动作——**离线 Q-learning 系统性失败**。<span class="marginnote">Fujimoto 等人的实验给出了震撼的对照：同样的离线数据，标准 Q-learning 学的策略<strong>远差于行为克隆</strong>（BC）——「自以为在学更好的策略，结果连照着做都不如」。这解释了为什么离线 RL 必须<strong>主动设计</strong>「防外推」机制（约束、保守、悲观），而不是祈祷数据够多。</span>

## 5 防外推的三大策略群

理解了病根，离线 RL 的方法可以归为三大策略群：

1. **约束（constraint）**：把策略**限制在数据分布附近**——BCQ 用「只选数据里出现过的动作」、策略正则化让 $\pi$ 靠近行为策略。
2. **保守/悲观（conservatism/pessimism）**：**压低 OOD 动作的价值估计**——CQL 显式惩罚「没见过的动作」的 Q 值，让策略不敢碰数据盲区。
3. **隐式约束/期望回归（implicit/expectile）**：绕开「$\max$ 查询 OOD」——IQL 用分位/期望回归只拟合「数据内」的价值，不主动外推。

三者的共同点：**「别相信你从没见过的东西」**——离线 RL 的智慧是「在已知的数据里找到更好的策略，而不是幻想数据之外的世界」。<span class="marginnote">把离线 RL 的三大策略对照第6章：约束≈「别走出数据」的探索抑制；保守≈「把未知标成低价值」的悲观主义；期望回归≈「不取 max、只取数据内期望」的自举抑制。<strong>它们全是「致命三要素」里「离策略」这一要素的防御工事</strong>。</span>

## 6 易错点辨析

**辨析｜易错点：** 以为离线 RL 的难点是「数据不够」。**数据量不是关键，数据覆盖才是**——就算数据很多，若行为策略从不访问某区域，那区域依然是「外推区」。离线 RL 的方法论是「在覆盖范围内做最优」，不是「靠更多数据填满空间」。

**另一个易错点**：混淆「离线 RL」与「经验回放」。DQN 的经验回放是「在线训练过程中复用历史数据」——数据会持续补充、且与当前策略相关；离线 RL 的**数据集固定、不再补充**。**「训练中回放」≠「纯离线学习」**——前者有纠错机会，后者没有。

**第三个易错点**：把「行为克隆」当离线 RL 的下限或基线混淆。行为克隆（模仿数据里的动作）是离线 RL 的**重要基线**——很多离线 RL 方法的目标是「比 BC 好」；若数据质量差，BC 反而最稳。**「比 BC 好」是离线 RL 的及格线**，衡量方法好坏常以 BC 为参照。

## 7 小结

- **离线 RL**：固定数据集、学比行为策略更好的策略——数据贵/危险场景的必然选择。
- **分布偏移**：策略走向数据盲区、无纠错——离线学习的头号敌人。
- **外推误差**：OOD 动作的 Q 被系统性高估，$\max$ 放大噪声、虚高沿贝尔曼扩散——标准 Q-learning 离线即崩。
- **三大策略群**：约束（BCQ）、保守（CQL）、隐式期望（IQL）——「别信没见过的东西」。
- 及格线是「比行为克隆好」；关键在覆盖度而非数据量。
