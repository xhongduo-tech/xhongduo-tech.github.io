## 为什么从「离策略」开始

上一节的探索起点假设给了我们一个能证明收敛的无模型控制算法，但它有一个刺眼的硬伤：**真实智能体无法任意选择回合的起点。** 让一个机器人从「每个 (状态, 动作)」出发一次，比让它在每个状态都做一次完美的贪心还难。于是我们面临两条出路：要么在策略内部塞进持续的小探索（ε-软策略，只能得到近似最优），要么干脆**换一种数据来源**——让别人去探索，自己只负责学习。

这第二种思路就是 **离策略（off-policy）学习**：**数据由行为策略（behavior policy）$b$ 采集，而学习的目标是另一个策略——目标策略（target policy）$\pi$ 的价值与最优策略。** 听起来很理想：经验可以来自任意来源（旧日志、别的智能体、甚至人类），学完一种目标还能换一种目标继续学。但它立刻带来一个数学难题：**用 $b$ 采的数据，怎么去估 $\pi$ 的价值？** 两者连「每条轨迹出现的概率」都不同。

答案是本节的主角——**重要性采样（importance sampling）**。它给每段经验乘以一个「修正因子」$\rho$，把「来自 $b$ 的数据」换算成「仿佛来自 $\pi$」的样子。这个工具今天看起来是配角，但它是整条离策略谱系的地基：第六篇的 Q-learning、第十四篇的经验回放与离线 RL、第十九篇的 RLHF，全是它的子孙。<span class="marginnote">离策略的价值怎么强调都不为过：它让「数据」与「算法」解耦——经验回放（第十四篇）把旧数据存起来反复学、离线 RL（第十六篇）只拿固定数据集学、RLHF（第十九篇）用人类偏好数据训练语言模型，全是「行为策略 ≠ 目标策略」这条路的直接延伸。</span>

## 1 行为策略与目标策略：数据与价值的分家

先给两个角色起名。**行为策略 $b$**：真正与环境交互、产生数据的策略，它负责探索，通常是某个软策略；**目标策略 $\pi$**：我们真正想要评估或改进的策略，通常更接近贪心。同策略（on-policy）学习是两者的特例：$b = \pi$。

**重点：离策略的核心在于「数据的来源」与「价值的所有者」可以不同。** 这带来三个现实红利：

- **数据复用**：一份由旧策略或他人采的经验，可以被反复用来评估不同目标策略，不用重新采样。
- **学习解耦于行为**：探索归 $b$ 管，学习归 $\pi$ 管——不必像 ε-贪心那样让「最优」被探索策略本身污染。
- **从人类/日志学习**：离线数据集往往来自一个与最终部署策略完全不同的行为策略，RLHF 正是先有「人类行为数据」，再学「模型策略」。

但红利的背面是代价：$b$ 与 $\pi$ 不同，经验里的**分布**就错了位。设我们想估

$$v_\pi(s) = \mathbb{E}_\pi\left[G_t \mid S_t = s\right]$$

可手里只有「按 $b$ 行动的回报」$G_t$，它的期望是 $\mathbb{E}_b\left[G_t \mid S_t = s\right] \neq v_\pi(s)$。直接平均，估的是 $v_b$ 而不是 $v_\pi$。要修正这个错位，需要引入**重要性采样**。

## 2 重要性采样比率：给经验乘以「概率之比」

重要性采样的思想来自蒙特卡洛积分：要算「目标分布下的期望」，却只有「提议分布下的样本」，那就按**两个分布的概率之比**给每个样本加权。

对一条从时刻 $t$ 跑到终止 $T$ 的轨迹，定义**重要性采样比率（importance sampling ratio）**：

$$\rho_t^{T-1} \doteq \prod_{k=t}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}$$

它是「这条轨迹在目标策略 $\pi$ 下出现的相对概率」与「在行为策略 $b$ 下出现的相对概率」之比。如果 $\pi$ 在某个 $S_k$ 更可能选 $A_k$，比值大于 $1$，该回报被**放大**；更不可能，则被**缩小**。于是

$$\mathbb{E}_b\left[\rho_t^{T-1} G_t \mid S_t = s\right] = v_\pi(s)$$

**把 $b$ 的期望修正成了 $\pi$ 的期望。** 这个「加权再平均」就是离策略预测的全部秘密——样本还是那些样本，只是每份回报按「它更该属于谁」打了折。

**辨析｜易错点：同策略时 $\rho$ 恒等于 $1$。** 若 $b = \pi$，分子分母逐项相同，$\rho \equiv 1$，修正因子自动失效——所以同策略是离策略的特例，重要性采样方法在同策略下自然退化成上一节的普通 MC。初学常犯的错是「给同策略数据也强行加权」，那除了引入无谓的方差外毫无意义。

## 3 普通 IS 与加权 IS：两种平均

有了 $\rho$，剩下的问题只是「怎么平均」。两条路线在教材里并列为普通 IS 与加权 IS：

- **普通重要性采样（ordinary importance sampling）**：

$$V(s) = \frac{1}{|\mathcal{T}(s)|}\sum_{t \in \mathcal{T}(s)} \rho_t^{T-1} G_t$$

其中 $\mathcal{T}(s)$ 是所有「访问过 $s$」的时刻集合。它是样本 $\rho G$ 的**算术平均**，数学上**无偏**：$\mathbb{E}[V(s)] = v_\pi(s)$。但它的方差可能大得离谱——理论上甚至可以是无穷大。<span class="marginnote">方差爆炸的直觉：$\rho$ 是若干个小概率的倒数之积。只要行为策略在某个动作上概率极低，一旦它恰好选到，$\rho$ 就暴涨成天文数字，一个样本就把平均搅翻天。这在统计里是典型的「无偏但重尾」估计——均值正确，中位数却很可怜。</span>

- **加权重要性采样（weighted importance sampling）**：

$$V(s) = \frac{\sum_{t \in \mathcal{T}(s)} \rho_t^{T-1} G_t}{\sum_{t \in \mathcal{T}(s)} \rho_t^{T-1}}$$

分子分母都加 $\rho$，相当于对 $\rho G$ 做**归一化的加权平均**。它**有偏**（除非 $\mathcal{T}(s) \to \infty$），但方差被分母的归一化压住了，重尾问题大幅缓解。

**重点：普通 IS 无偏但方差爆炸，加权 IS 有偏但方差温和——这是整条离策略方法谱系的第一对矛盾，往后我们还会反复遇见它。** 实践中几乎总是选加权 IS；只有在需要「无偏」这个理论性质时才用普通 IS。

## 4 公式解析：ρ 里为什么只剩策略概率

重要性采样比率能写成 $\prod \pi/b$ 这种「不含环境」的形式，并不是理所当然的——轨迹概率里明明还有转移概率 $p$。拆四步看清它是怎么被约掉的。

- **第一步，写出目标策略下整条轨迹的概率。** 一条轨迹 $S_t, A_t, R_{t+1}, S_{t+1}, \dots, S_T$ 在 $\pi$ 下出现的概率，是每一步「选动作概率 × 转移概率」的连乘：

$$\Pr_\pi\left(A_t, S_{t+1}, \dots, S_T \mid S_t\right) = \prod_{k=t}^{T-1} \pi(A_k \mid S_k)\; p(S_{k+1}, R_{k+1} \mid S_k, A_k)$$

（奖励被并进了 $p(S', R \mid S, A)$；终止状态 $S_T$ 之后不再有动作。）

- **第二步，同样写下行为策略 $b$ 下的概率。** 把上式的 $\pi$ 换成 $b$，其它一项不动——因为**环境动力 $p$ 与谁在选择动作无关**。

$$\Pr_b\left(A_t, S_{t+1}, \dots, S_T \mid S_t\right) = \prod_{k=t}^{T-1} b(A_k \mid S_k)\; p(S_{k+1}, R_{k+1} \mid S_k, A_k)$$

- **第三步，两者相除，$p$ 项逐对约分。** 每个 $p(S_{k+1}, R_{k+1} \mid S_k, A_k)$ 同时出现在分子分母、且取值相同，逐一抵消，剩下：

$$\rho_t^{T-1} = \frac{\Pr_\pi(\text{轨迹})}{\Pr_b(\text{轨迹})} = \prod_{k=t}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}$$

**这就是关键：$\rho$ 只含策略的概率，不含任何环境模型。** 无模型方法不用知道 $p$ 就能算 $\rho$，因为 $p$ 在比值里自己消掉了。

- **第四步，为什么加权后期望正确。** 对任意函数 $G$（比如回报），把「按 $\pi$ 取期望」展开成「按 $b$ 取期望」：

$$\mathbb{E}_\pi\left[G_t \mid S_t = s\right] = \sum_{\text{轨迹}} \Pr_\pi(\text{轨迹})\, G_t = \sum_{\text{轨迹}} \Pr_b(\text{轨迹})\, \rho_t^{T-1} G_t = \mathbb{E}_b\left[\rho_t^{T-1} G_t \mid S_t = s\right]$$

中间的等号就是「乘 $1 = \frac{\Pr_\pi}{\Pr_b}$」。于是 $v_\pi(s) = \mathbb{E}_b[\rho G]$，普通 IS 的无偏性由此而来。

## 5 一个能手算的例子

一个单状态、两动作的 MDP：动作 $A$ 得奖励 $+1$ 立即终止，动作 $B$ 得 $0$ 终止。目标策略 $\pi$ 永远选 $A$（所以 $v_\pi = 1$）；行为策略 $b$ 以 $0.5/0.5$ 等概率选 $A$ 或 $B$。用 $b$ 采一批回合，估计 $v_\pi$。

每个回合的修正因子：

| 行为动作 | $\rho = \pi/b$ | 回报 $G$ | $\rho G$ |
| --- | --- | --- | --- |
| $A$（概率 0.5） | $1 / 0.5 = 2$ | $1$ | $2$ |
| $B$（概率 0.5） | $0 / 0.5 = 0$ | $0$ | $0$ |

普通 IS 估计 $= 0.5 \times 2 + 0.5 \times 0 = 1 = v_\pi$。**选 $A$ 的经验被放大两倍（因为它本属于更稀罕的目标策略），选 $B$ 的经验被清零（因为目标策略根本不选 $B$）。** 这个 $1$ 不是 $b$ 的回报均值 $0.5$，而是被 $\rho$ 修正后的 $\pi$ 的价值——修正因子干的正是这份「翻译」的活。

## 6 实现：两种估计器与增量式加权 IS

把两种估计器写成函数，输入是「若干条回合」的扁平化样本 `(s, G, rho)`：

```python
def ordinary_is(samples, state):
    """普通重要性采样：无偏，但可能高方差。"""
    n, total = 0, 0.0
    for s, G, rho in samples:
        if s == state:
            n += 1
            total += rho * G
    return total / n if n else 0.0

def weighted_is(samples, state):
    """加权重要性采样：有偏，但方差小。"""
    num = den = 0.0
    for s, G, rho in samples:
        if s == state:
            num += rho * G
            den += rho
    return num / den if den else 0.0
```

加权 IS 还可以写成**增量式**，不必保存全部样本。记 $C(s)$ 为累积的权重，则每来一个样本就更新一次：

$$V(s) \leftarrow V(s) + \frac{\rho}{C(s)}\left(G - V(s)\right), \qquad C(s) \leftarrow C(s) + \rho$$

对照上一节 MC 的增量式 $V \leftarrow V + \frac{1}{N}(G - V)$，差别只在「权重从 $1/N$ 换成 $\rho/C$」——**普通平均换成了加权平均，骨架不变。** 这条增量式是下一节离策略控制算法的心脏，先在这里打好地基。<span class="marginnote">教材 Example 5.4 用黑杰克演示过两者的差距：行为策略随机出牌，目标策略「20 点或 21 点就停牌」。加权 IS 的估计紧贴着同策略值一路收敛，普通 IS 却剧烈抖动、甚至给出超过合理范围的离谱值——「无偏」在方差面前常常只是理论安慰。</span>

## 7 辨析：无偏 vs 方差，什么时候用哪个

普通 IS 与加权 IS 的取舍，值得单独摆一张对照表：

| | 普通 IS | 加权 IS |
| --- | --- | --- |
| 偏差 | **无偏**（任意有限样本） | 有偏，样本越多偏差越小 |
| 方差 | 可能为无穷大 | 有界，重尾被归一化压制 |
| 典型用途 | 需要无偏性的理论分析 | 几乎所有实践 |
| 同策略退化 | $\rho \equiv 1$，退化为普通平均 | $\rho \equiv 1$，退化为普通平均 |

**辨析｜易错点：加权 IS 的「有偏」不是 bug。** 它的偏差是「用归一化换方差」的必然代价，且随样本增多趋于零；而普通 IS 的「无偏」在 $\rho$ 重尾时几乎派不上用场——一个天文数字的样本就能让估计偏离十万八千里。**判断用哪个，先问「我缺样本还是缺稳定性」。**

还有一个易混点：**离策略 ≠ 一定要用重要性采样。** 本章的 MC 离策略靠 $\rho$，但第六篇的 Q-learning 离策略却几乎不用 $\rho$——因为它的目标策略是贪心的 `max`，更新式里直接写「目标 = $r + \gamma \max_{a'} q(s', a')$」，压根不需要按策略概率加权。**重要性采样是「目标策略是随机策略」时的修正工具，而不是离策略的定义。**

## 8 小结

- **离策略设定**：行为策略 $b$ 采数据、目标策略 $\pi$ 学价值；数据与价值分家，带来数据复用、学习解耦、从日志学习三大红利。
- **重要性采样比率**：$\rho_t^{T-1} = \prod_{k=t}^{T-1} \frac{\pi(A_k\mid S_k)}{b(A_k\mid S_k)}$，它把「$b$ 的期望」修正成「$\pi$ 的期望」：$\mathbb{E}_b[\rho G] = v_\pi(s)$。
- **ρ 不含模型**：轨迹概率之比中，环境转移项 $p(S',R\mid S,A)$ 逐对约分——无模型方法也能算 $\rho$。
- **两种平均**：普通 IS 无偏但方差可爆（重尾），加权 IS 有偏但方差温和；实践多用加权。
- **增量式**：$V(s) \leftarrow V(s) + \frac{\rho}{C(s)}(G - V(s))$，$C \leftarrow C + \rho$，是离策略控制的算法心脏。
- **辨析**：同策略时 $\rho \equiv 1$；离策略 ≠ 必须重要性采样（Q-learning 用 `max` 免掉了 $\rho$）。

在下一节，我们把这套「修正因子」装进控制算法：让行为策略 $b$ 去探索、目标策略 $\pi$ 当贪心——但它将撞上一个更棘手的退化问题：当 $\pi$ 是确定性贪心时，$\rho$ 会变得非零即无，离策略 MC 控制将迎来它最艰难的时刻。
