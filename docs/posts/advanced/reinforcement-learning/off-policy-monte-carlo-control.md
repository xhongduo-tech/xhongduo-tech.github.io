## 为什么从「离策略控制」开始

上一节我们把重要性采样装进了预测：用行为策略 $b$ 采的数据，去估目标策略 $\pi$ 的价值，靠修正因子 $\rho$ 翻译两套概率。这一节把它升级成**控制**——不只估 $\pi$ 的价值，还要直接改进它，直到找到最优策略。这听起来只是「预测 + 改进」的机械拼接，但拼接出来的算法撞上了一个决定性的困难：**当目标策略 $\pi$ 是确定性的贪心时，修正因子 $\rho$ 会变得「非零即无」**——要么大得离谱，要么直接归零。

为什么执着于离策略控制？回顾前两节：探索起点需要「能控制回合起点」，现实中做不到；ε-软策略是同策略，只能找到 ε-最优。**离策略控制提供第三条路：让一个爱探索的行为策略负责采数据，让一个纯贪心的目标策略负责当最优**——数据与野心彻底分家。这正是现实世界的样子：我们学到的策略不必和产生数据的策略相同。这条路的成败，就看 $\rho$ 能不能扛住「目标贪心」的压力。

这一节先看清 $\rho$ 的退化，再给出能转起来的加权 IS 控制算法，最后解释为什么蒙特卡洛在这个问题上注定吃力，而时序差分（下一篇）才是离策略的归宿。

## 1 设定：行为策略负责探索，目标策略当贪心

离策略控制里有两个角色，各司其职：

- **行为策略 $b$**：真正与环境交互，负责**探索**。通常取一个 $\varepsilon$-软策略（每个动作都有正概率），保证「覆盖」所有动作——否则有些 $(s, a)$ 永远采不到样本。
- **目标策略 $\pi$**：真正要被学会的策略，负责**最优**。通常取当前 $Q$ 的贪心：

$$\pi(s) = \arg\max_a Q(s, a)$$

它随 $Q$ 的更新而动态变化——注意，这里 $\pi$ 不是固定的，而是「跟着 $Q$ 走的贪心策略」。

**重点：离策略控制的核心循环是「用 $b$ 采一个回合 → 用加权 IS 更新 $Q$ → 令 $\pi$ 重新贪心于 $Q$」。** 与上一节预测的唯一差别，是多了「每步更新后改进 $\pi$」这一步；但正是这个「贪心目标」，把后面的 $\rho$ 逼到了墙角。

直觉上这很美：$b$ 像一位爱到处乱逛的向导，把所有岔路都踩过；$\pi$ 像一位只看地图的决策者，专挑当前最好的路。向导的经验被修正因子翻译成决策者的语言。问题是——翻译在「目标策略是贪心」时彻底失灵。

## 2 确定性贪心目标，把 ρ 推向两个极端

回到修正因子的定义（上一节推导过，环境项 $p$ 已约分）：

$$\rho_t^{T-1} = \prod_{k=t}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}$$

当 $\pi$ 是**确定性贪心**时，每个 $\pi(A_k \mid S_k)$ 都只有两种取值：贪心动作取 $1$，其余取 $0$。于是一个完整回合的 $\rho$ 呈现两个极端：

- **若回合里 $b$ 在任何一步选了非贪心动作**：乘积里出现因子 $0$，整段 $\rho = 0$。这个回合对估计**零贡献**——目标策略根本不会走这条路，它的经验被彻底作废。
- **若回合全程与贪心一致**：所有 $\pi$ 因子都是 $1$，于是 $\rho = \prod \frac{1}{b(A_k \mid S_k)}$。$b$ 是探索策略，单步概率往往不大，几项倒数连乘下来，$\rho$ 可以涨到天文数字。

**重点：贪婪的目标把「修正因子」从「温和的加权」变成了「要么归零、要么爆炸」的两极开关。** 这不是实现粗糙，而是结构性困难：目标策略越接近确定性（越贪心），$\rho$ 的分布越病态。教材在 §5.7 明确指出这是离策略蒙特卡洛方法的**根本困难（fundamental difficulty）**。<span class="marginnote">这与上一节普通 IS「无偏但可能无穷方差」是同一病灶的放大：现在不只方差爆炸，连「有效样本」都几乎消失——绝大多数回合因为某一小步偏离贪心而整个作废。后面的每决策重要性采样（§5.9）正是针对这个浪费开刀。</span>

## 3 公式解析：当 π 是确定性贪心时 ρ 如何退化

把「非零即无」用三步数学钉死，并把它翻译成算法的「提前终止」。

- **第一步，写全 $\rho$ 的两种命运。** 设回合从 $t$ 到 $T-1$。确定性贪心 $\pi$ 下，

$$\rho_t^{T-1} = \begin{cases} \prod_{k=t}^{T-1} \frac{1}{b(A_k \mid S_k)}, & \text{若 } A_k = \pi(S_k),\; \forall k \\[4pt] 0, & \text{若存在 } k \text{ 使 } A_k \neq \pi(S_k) \end{cases}$$

「所有动作都跟贪心一致」这个事件本身是稀有事件：若 $b$ 是 $\varepsilon$-贪心，每一步一致的概率是 $1 - \varepsilon$，长度为 $L$ 的回合全程一致的概率是 $(1-\varepsilon)^L$，随长度**几何衰减**。

- **第二步，看「一致」时 $\rho$ 的大小。** 一致回合的 $\rho = \prod 1/b(A_k \mid S_k)$，$b$ 的单步概率每项都 $\le 1$，倒数每项都 $\ge 1$，连乘随长度**几何增长**。一缩一涨，撞出重尾：**大多数回合贡献 $0$，极少数「幸运」回合贡献一个巨无霸样本。** 普通 IS 的方差在这种分布下可以趋于无穷。<span class="marginnote">重尾直觉：想象一个「买彩票」分布——$99\%$ 概率得 $0$，$1\%$ 概率得 $10^6$。均值是 $10^4$ 没错，但你要采很多样本才碰得到那个大奖，估计在样本有限时七上八下。普通 IS 在离策略控制里就是这样一只彩票机。</span>

- **第三步，翻译成算法：反向遍历 + 提前终止。** 加权 IS 控制从回合末尾向前更新。记 $W$ 为「从当前时刻到末尾这一段与贪心一致的累计权重」。每处理一步：

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \frac{W}{C(S_t, A_t)}\left(G - Q(S_t, A_t)\right), \qquad C(S_t, A_t) \leftarrow C(S_t, A_t) + W$$

然后检查：若 $A_t \neq \pi(S_t)$（非贪心），则更早的所有步骤 $\rho$ 都会乘上 $0$，**直接终止反向循环**；否则令 $W \leftarrow W \cdot \frac{1}{b(A_t \mid S_t)}$，继续向前。

**重点：反向遍历让「提前终止」变得廉价——一旦发现偏离贪心，就立刻停手，不必把前面所有步骤的权重都清零。** 这个 $W$ 的增量更新，正是上一节结尾埋下的增量式加权 IS 在控制场景的完整形态。

## 4 一个例子：方差为什么会爆炸

用一个极端简化的单状态两动作 MDP 看清「爆炸」的机制。动作 $A$ 得 $+1$ 终止，动作 $B$ 得 $0$ 终止；目标策略 $\pi$ 永远选 $A$，所以 $v_\pi = 1$。行为策略 $b$ 选 $A$ 的概率是 $p$（很小），选 $B$ 的概率 $1-p$。回合长度为 $1$。

对普通 IS，样本是 $\rho G$：

- 选 $B$ 的回合：$\rho = \pi(B)/b(B) = 0$，贡献 $0$。
- 选 $A$ 的回合：$\rho = 1/p$，$G = 1$，贡献 $1/p$，出现概率 $p$。

期望是 $p \cdot \frac{1}{p} = 1$，无偏，正确。但**二阶矩**是 $p \cdot \frac{1}{p^2} = \frac{1}{p}$：当探索越稀少（$p \to 0$），二阶矩 $\to \infty$，方差发散。**你需要的样本数随 $\frac{1}{p}$ 增长——行为策略越不爱走贪心路，估计越难收敛。** 这个例子是教材「无限方差」示例的精神简化版：普通 IS 无偏，但方差在「稀有事件放大」面前可以无限坏。

加权 IS 在这个例子里反而从容：分母 $\sum \rho$ 也把 $1/p$ 的因子包含进来，归一化后估计恰好是 $1$。**这正是加权 IS 存在的理由——它用「有偏」换掉了普通 IS 的重尾。** 但代价我们上一节说过：有效样本只剩「与贪心一致」的那些，样本效率很低。

## 5 加权 IS 控制：能转，但很慢

把第三节的算法写成可运行代码。环境沿用四格走廊（状态 $1$–$4$，左右两动作，到 $0$ 或 $5$ 终止，每步 $-1$）。行为策略 $b$ 取均匀随机（$0.5/0.5$，保证覆盖一切动作），目标策略 $\pi$ 是随 $Q$ 更新的贪心。

```python
import random
from collections import defaultdict

STATES = [1, 2, 3, 4]
ACTIONS = ["L", "R"]
B = {"L": 0.5, "R": 0.5}                 # 行为策略 b：均匀随机，保证覆盖

def mc_off_policy_control(num_episodes, gamma=1.0):
    Q = defaultdict(float)               # q(s, a)，初值 0
    C = defaultdict(float)               # 累计权重
    pi = {s: random.choice(ACTIONS) for s in STATES}
    for _ in range(num_episodes):
        # 1) 用行为策略 b 生成一个完整回合
        s = random.choice(STATES)
        traj = []                        # (s, a, r)
        while True:
            a = random.choice(ACTIONS)   # b(s)
            s2 = s + (1 if a == "R" else -1)
            traj.append((s, a, -1))
            if s2 in (0, 5):
                break
            s = s2
        # 2) 从后往前做加权 IS 更新
        G, W = 0.0, 1.0
        for s, a, r in reversed(traj):
            G = r + gamma * G
            C[s, a] += W
            Q[s, a] += (W / C[s, a]) * (G - Q[s, a])
            pi[s] = max(ACTIONS, key=lambda act: Q[s, act])   # 目标策略重新贪心
            if a != pi[s]:               # 非贪心 → 更早步骤的权重全为 0，终止
                break
            W *= 1.0 / B[a]              # 本步一致 → W 乘上 π/b = 1/b
    return pi, dict(Q)

pi, Q = mc_off_policy_control(100_000)
print("目标策略:", pi)
```

算法正确转起来了，但注意两处「吃力」：

- **`break` 频繁触发**：均匀随机的行为策略每步只有 $1/2$ 概率撞上贪心，回合稍长，`break` 几乎立刻发生。于是只有回合末端的少数 $(s, a)$ 被更新，靠前状态的 $Q$ 长期拿不到样本。
- **W 几何膨胀**：真撑到「全程一致」的回合，$W$ 是 $2^{\text{长度}}$ 量级，一个回合的权重就能主导一整段估计，方差随之拉高。

**辨析｜易错点：别把「收敛」误以为「快」。** 这个算法理论上收敛（加权 IS 保证），但有效样本被 `break` 砍得所剩无几，实际收敛慢得难以接受。教材明确评价：离策略 MC 控制在原则上可行，却「因这些困难而很少被使用」——它在理论史上的价值，是证明了「离策略 + 贪心目标」这条路**能走通**，而不是「好走」。

## 6 辨析：为什么 TD 才是离策略的解药

蒙特卡洛在这道题上吃亏，根子在**完整回合**：$\rho$ 要连乘整段轨迹，一旦中途有一步偏离贪心，整段作废。下一章要登场的时序差分（TD）方法，恰好把「整段回报」换成「一步自举」，于是离策略立刻变得温顺。

- **TD 只需要一步的修正因子。** TD 更新 $Q(S, A)$ 时，目标只用到 $R + \gamma \cdot \text{(自举值)}$，而非完整回报；因此需要修正的只是「当前这一步动作」的概率比 $\rho_t = \pi(A_t \mid S_t) / b(A_t \mid S_t)$，而不是整段轨迹的连乘。**一步的偏离只作废一步，不连坐整回合。**
- **Q-learning 干脆不用 ρ。** 第六篇的 Q-learning 是离策略 TD 控制，它的目标里直接写 $\max_{a'} Q(S', a')$——「按目标策略（贪心）取值」被 `max` 一步算完，行为策略只在采样时出现，修正因子根本不需要。

$$Q(S, A) \leftarrow Q(S, A) + \alpha\left[ R + \gamma \max_{a'} Q(S', a') - Q(S, A) \right]$$

**重点：离策略 ≠ 必须重要性采样。** MC 需要 $\rho$，是因为它的目标策略 $\pi$ 是「按概率取期望」的随机策略；Q-learning 不需要，是因为它的目标策略是「取最大值」的贪心。**理解这一条，你才算真正看懂了「为什么深度学习里的 DQN 遍地都是，而离策略 MC 几乎无人问津」。**<span class="marginnote">这条线索一路延伸到后面：第十四篇 DQN 用经验回放（离策略 + 无 $\rho$）训练深度网络，第十六篇离线 RL 完全依赖离策略数据——它们全都站在 Q-learning 这条「贪心目标免修正」的支线上，而非 MC 的 $\rho$ 支线。真正保留 $\rho$ 的地方，是策略梯度里的重要性采样（第十三篇）与第十一篇的离策略函数逼近。</span>

**辨析｜易错点：TD 的「离策略」不会遇上一章的方差爆炸吗？** 不会完全免疫——TD 目标含 $\max$，本身有最大化偏差（第六篇会专门讲 Double Learning）；但 TD 的离策略修正只跨一步，权重不会像 MC 那样几何级数连乘整段，重尾被结构性地掐断。**这就是「自举」给离策略送来的礼物：误差只传一步，权重只修一步。**

## 7 小结

- **离策略控制的设定**：行为策略 $b$ 负责探索（$\varepsilon$-软、覆盖全部动作），目标策略 $\pi$ 是随 $Q$ 更新的确定性贪心。
- **ρ 的两极退化**：确定性贪心使 $\rho$ 要么归零（回合偏离贪心，整段作废）、要么爆炸（全程一致时是 $1/b$ 的连乘）——这是离策略 MC 的**根本困难**。
- **加权 IS 控制**：反向遍历回合，$Q \leftarrow Q + \frac{W}{C}(G - Q)$，$C \leftarrow C + W$，遇到非贪心步骤提前终止；能收敛，但有效样本稀少、收敛极慢。
- **方差爆炸机制**：一致事件概率 $(1-\varepsilon)^L$ 几何衰减，$\rho$ 大小 $\prod 1/b$ 几何增长——重尾分布让普通 IS 的二阶矩发散。
- **TD 是解药**：自举使修正因子只需覆盖一步，Q-learning 用 $\max$ 甚至完全免掉 $\rho$——这是 DQN、经验回放、离线 RL 共同的支线。
- **辨析**：离策略 ≠ 必须重要性采样；MC 的 $\rho$ 连乘整段，TD 只修一步。

在下一节，我们把「整段回报 × 整段 $\rho$」的粗糙搭配打磨得更精细：用**折扣感知**与**每决策重要性采样**，把每个奖励只乘以它真正需要的修正因子，把离策略 MC 的方差再往下压——那是第五篇对 $\rho$ 的最后一轮手术。
