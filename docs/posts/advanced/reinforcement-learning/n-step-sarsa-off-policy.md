## 为什么 n步预测要升级成 n步控制

上一课的 n步回报停留在状态价值预测。这一课把它装进动作价值，得到 **n步 Sarsa**——以及更重要的，把离策略学习与 n步回报拼在一起：当数据来自行为策略 $b$、要学目标策略 $\pi$ 时，n步回报里「多余的几步」必须用重要性采样比修正。离策略 n步方法因此比单步 TD 更微妙：**步数越多，需要乘上的采样比越多，方差也随之膨胀**——这为下一课的树回溯（完全不用采样比）埋下了动机。<span class="marginnote">n步回报的离线学习是 TD(λ) 在离策略情形下遭遇「致命三要素」的第一个前奏：自举 + 离策略 + 函数逼近，三缺一都安全，三合一就发散——这个伏笔在第11章引爆。</span>

## 1 n步 Sarsa：把谱系搬上动作价值

n步 Sarsa 的更新几乎可以照着 n步 TD 抄，只是把状态价值换成动作价值：

$$
Q(S_t, A_t) \;\leftarrow\; Q(S_t, A_t) + \alpha\big[\,G_{t:t+n} - Q(S_t, A_t)\,\big]
$$

其中 **n步动作回报**为：

$$
G_{t:t+n} \;=\; R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^n Q(S_{t+n}, A_{t+n})
$$

与预测版的唯一区别在自举项：预测版用 $V(S_{t+n})$，控制版用 $Q(S_{t+n}, A_{t+n})$，其中 $A_{t+n}$ 按当前策略采样。因此**每次更新需要向前多等一步动作**——预测需要保存 $n$ 个状态，控制需要保存 $n+1$ 个状态动作对。<span class="marginnote">实现上的时间对齐：时刻 $t$ 更新 $Q(S_t,A_t)$ 时，用到的自举项 $Q(S_{t+n},A_{t+n})$ 是「刚采样到」的动作价值，因此要等 $n$ 步后回头更新。第7章的「延迟更新」在控制里变成了「延迟 n+1 步」。</span>

**n步期望 Sarsa** 照例把自举项换成期望：

$$
G_{t:t+n} \;=\; R_{t+1} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^n \sum_a \pi(a \mid S_{t+n})\, Q(S_{t+n}, a)
$$

方差更低，代价是动作空间大时求和不可行——与单步期望 Sarsa 一模一样的权衡，只是搬到了 n步。

### 数值算例：三步 Sarsa 的回报怎么算

拿一条极短的轨迹演示 n=2 的机制。设 $\gamma = 0.9$，行为序列为 $S_0 A_0 \to S_1 A_1 \to S_2 A_2$，奖励 $R_1 = 1$、$R_2 = -5$，估计值 $Q(S_2, A_2) = 10$。则：

$$
G_{0:2} = R_1 + \gamma R_2 + \gamma^2 Q(S_2, A_2) = 1 + 0.9 \times (-5) + 0.9^2 \times 10 = 1 - 4.5 + 8.1 = 4.6
$$

若 $Q(S_0, A_0)$ 当前是 2，步长 $\alpha = 0.5$，则一次更新后：

$$
Q(S_0, A_0) \leftarrow 2 + 0.5 \times (4.6 - 2) = 2 + 1.3 = 3.3
$$

注意三点：第一，$R_2 = -5$ 是**已经真实发生的**奖励，不是猜测；第二，$\gamma^2 Q(S_2, A_2) = 8.1$ 是**猜测**（自举），它占了回报的绝大部分——这正是 n 小时「自举早、偏差大」的体现；第三，若把 n 换成 1，回报只剩 $R_1 + \gamma Q(S_1, A_1)$，完全不看 $R_2$，轨迹里更远的信息就被丢掉了。

## 2 离策略 n步：给回报乘采样比

当数据来自行为策略 $b$，目标策略是 $\pi$，n步回报 $G_{t:t+n}$ 是按 $\pi$ 的意义定义的——可实际走的动作来自 $b$。修正是把整个回报乘上**从 $t+1$ 到 $t+n-1$** 的重要性采样比：

$$
\rho_{t+1:t+n-1} \;=\; \prod_{k=t+1}^{t+n-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}
$$

于是离策略 n步 Sarsa 的更新为：

$$
Q(S_t, A_t) \;\leftarrow\; Q(S_t, A_t) + \alpha\, \rho_{t+1:t+n-1}\big[\,G_{t:t+n} - Q(S_t, A_t)\,\big]
$$

**为什么从 $t+1$ 而不是 $t$ 开始、到 $t+n-1$ 而不是 $t+n$ 结束？** 因为被更新的正是 $Q(S_t,A_t)$——动作 $A_t$ 的价值我们要「按目标策略」学，不必自我修正；而 $A_{t+n}$ 只出现在自举项里，n步 Sarsa 约定它按行为策略取（也算一种采样），于是剩下需要修正的是中间的 $A_{t+1},\dots,A_{t+n-1}$ 共 $n-1$ 个动作。<span class="marginnote">若把 $A_{t+n}$ 也纳入修正（乘 $\rho_{t+1:t+n}$），会得到另一个合法但方差更大的估计器；教材的标准形式停在 $t+n-1$，是为了让自举项留在「行为采样」一侧，减小权重爆炸。</span>当 $t+n \ge T$（越过幕末），$\rho$ 只乘到 $T-1$，且 $G_{t:t+n}=G_t$。

**离策略 n步期望 Sarsa** 用期望替换 $Q(S_{t+n},A_{t+n})$ 后，同样的采样比仍然适用，但方差更受控。

## 3 n与采样比的博弈：为什么 n 越大越难

把离策略 n步方法的方差摊开看：

$$
\rho_{t+1:t+n-1} = \prod_{k=t+1}^{t+n-1} \frac{\pi(A_k|S_k)}{b(A_k|S_k)}
$$

**n 每增加 1，就多乘一个 $\pi/b$ 因子**。若 $\pi$ 与 $b$ 偏离大（比如 $\pi$ 几乎不选 $b$ 常选的动作），比值可能巨大，乘积更是指数级膨胀。于是离策略 n步学习面临一个两难：

- **n 小**（如 n=1）：采样比只有一个因子，方差可控，但自举早、偏差大。
- **n 大**：偏差小，但采样比乘积的方差爆炸，更新被少数「权重尖峰」主导。<span class="marginnote">这正是上一课 U 形结论的离策略版本：最优 n 由「偏差-方差」与「重要性权重-方差」两座天平共同决定。实践中常用每决策或折扣感知 IS（第5章）来压缩乘积方差。</span>

这个张力在表格型里尚能忍受，在函数逼近 + 离策略 + 自举三者叠加时则彻底失控——那就是第11章的「致命三要素」。**n步方法之所以在深度 RL 里常常「n=1 或 n=小常数」够用，正是因为采样比乘积随 n 的方差爆炸**。

把同一族方法并排比较，取舍一目了然：

| 方法 | 自举项 | 采样比 | 权重方差 | 典型偏差 |
| --- | --- | --- | --- | --- |
| n步 Sarsa（同策略） | $\gamma^n Q(S_{t+n},A_{t+n})$ | 无 | 无 | 随 n 增大而减小 |
| n步期望 Sarsa | $\gamma^n \sum_a \pi(a\mid S_{t+n})Q(S_{t+n},a)$ | 无 | 低 | 随 n 增大而减小 |
| 离策略 n步 Sarsa | $\gamma^n Q(S_{t+n},A_{t+n})$ | $\rho_{t+1:t+n-1}$ | 随 n 指数涨 | 随 n 增大而减小 |
| Q-learning（n=1 特例） | $\gamma \max_a Q(S_{t+1},a)$ | 无 | 无 | 高（单步自举） |

读这张表要抓住一个不对称：**同策略一族可以自由地把 n 调大来压偏差，离策略一族却不敢——n 越大采样比乘积越爆炸**。这正是为什么表格型讲义里 n 是超参数，而深度 RL 里离策略算法（DQN、SAC 之类）几乎一律退回 n=1。

## 4 公式解析：离策略 n步回报的权重从哪来

$$
\underbrace{Q(S_t,A_t)}_{\text{被更新}} \;\leftarrow\; Q(S_t,A_t) + \alpha \overbrace{\prod_{k=t+1}^{t+n-1}\frac{\pi(A_k|S_k)}{b(A_k|S_k)}}^{\rho_{t+1:t+n-1}}\Big[\,\underbrace{R_{t+1}+\cdots+\gamma^{n-1}R_{t+n}+\gamma^n Q(S_{t+n},A_{t+n})}_{G_{t:t+n}} - Q(S_t,A_t)\,\Big]
$$

- **第一步，数因子**：$\rho$ 的连乘从 $k=t+1$ 到 $k=t+n-1$，共 $n-1$ 项。每一项把「数据里实际走的动作 $A_k$」从行为概率下「翻译」回目标概率下——概率之比恰是「这条轨迹在目标策略下更可能还是更不可能」。
- **第二步，看作用对象**：$\rho$ 乘在整个括弧 $[G_{t:t+n} - Q]$ 上，而不是只乘 $G$。因为 $Q(S_t,A_t)$ 的期望更新量必须是「目标策略下的 n步回报误差」的无偏估计，乘以 $\rho$ 恰好完成这一重加权。
- **第三步，看边界**：$A_t$ 不参与（正在学的动作无需修正）；$A_{t+n}$ 不参与（自举项按行为采样处理）；$t+n \ge T$ 时乘积截断到 $T-1$。**边界规则只有一条：只修正在「被估计的回报」里额外出现、又非自举对象的动作**。<span class="marginnote">若把边界记错，比如把 $A_t$ 也乘进去，等价于给目标策略下的 $Q(S_t,A_t)$ 又加了一层与自身无关的权重，期望不变但方差徒增——很多离策略 n步实现 bug 就出在这里。</span>

## 5 易错点辨析

**辨析｜易错点：** 以为离策略 n步 Sarsa 的采样比与 n 无关。**它随 n 增长**：n=1 时 $\rho_{t+1:t}$ 是空乘积（$=1$，这正是单步 Q-learning 无需采样比的原因——自举动作被 $\max$ 或期望吸收），n=2 时乘 1 个因子，n 越大因子越多。**Q-learning 之所以能免于采样比，是因为它只自举一步**。

**另一个易错点**：把「n步回报的期望」与「重要性采样的重加权」混在一起。n步回报 $G_{t:t+n}$ 的目标是估计 $q_\pi$（目标策略），而采样产生的动作来自 $b$；$\rho$ 负责把分布从 $b$ 对齐到 $\pi$。一个是时间尺度（n），一个是策略对齐（$\rho$），两个维度正交，可自由组合。

## 6 术语速查

| 术语 | 一句话含义 | 在本课的记号 |
| --- | --- | --- |
| n步回报 | 前 $n$ 个真实奖励 + 第 $n$ 步的价值自举 | $G_{t:t+n}$ |
| 行为策略 | 实际产生数据的策略 | $b$ |
| 目标策略 | 想要学习/评估的策略 | $\pi$ |
| 重要性采样比 | 目标概率与行为概率之比，把轨迹从 $b$ 重加权到 $\pi$ | $\rho_{t+1:t+n-1}$ |
| n步期望回报 | 自举项换成按 $\pi$ 加权求和 | $\sum_a \pi(a\mid S_{t+n})Q(S_{t+n},a)$ |

## 7 小结

- **n步 Sarsa**：$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[G_{t:t+n}-Q(S_t,A_t)]$，自举项为 $\gamma^n Q(S_{t+n},A_{t+n})$。
- **n步期望 Sarsa**：自举项换成 $\sum_a \pi(a|S_{t+n})Q(S_{t+n},a)$，方差更低。
- **离策略 n步**：更新乘 $\rho_{t+1:t+n-1}$，只修正「回报里额外、非自举对象」的动作。
- **n 与权重方差博弈**：n 越大采样比因子越多，方差越易爆炸；最优 n 是两座天平的折中。
- 边界规则：$A_t$ 不修正、$A_{t+n}$ 不修正、越过幕末截断——记牢这三点就不会写错。

在下一节，我们绕过采样比这个麻烦：**带控制变量的每决策方法** 与 **树回溯** 用「期望」替代「重加权」，让离策略 n步学习不再背负 $\rho$ 的方差。
