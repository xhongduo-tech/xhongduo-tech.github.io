## 为什么「梯度下降」在 RL 里要打折扣

上一课确立了目标：最小化均方价值误差 $\overline{\text{VE}}(\mathbf{w})$。监督学习顺手就是梯度下降——但强化学习有两个拦路虎：**真值 $v_\pi$ 未知**，只能拿采样目标顶替；**目标自身含参数**，对它求梯度会把问题搅浑。**随机梯度下降（stochastic gradient descent，SGD）** 处理第一个难题（用样本目标估计真梯度方向）；**半梯度（semi-gradient）** 处理第二个难题（把目标当常数，只对「当前项」求导）。这一课是函数逼近预测方法的理论心脏：**半梯度不收敛到 $\overline{\text{VE}}$ 的最小点，却稳定收敛到一个「TD 不动点」**——这个「次优但稳定」的取舍，定义了 RL 逼近方法的全部气质。<span class="marginnote">「半」字的分寸：完整梯度需要对「目标」也求导，但目标里的 $\hat v(S_{t+1},\mathbf w)$ 随 $\mathbf w$ 变化，把它的梯度也算进去会让更新不稳定（第11章讲离策略发散时还会再遇）。半梯度只保留「当前项」的梯度——丢了收敛到全局最小，换来稳定。</span>

这一课是第9章的「引擎课」：上一课定义了「要优化什么」（$\overline{\text{VE}}$），这一课回答「怎么优化」——SGD 提供方向、半梯度提供稳定性。而「半梯度收敛到 TD 不动点」这个结论，正是整本教材对「函数逼近 TD 为什么能跑」的理论承诺：**它不是最优解，却是最稳的可行解**。

## 1 随机梯度下降：用样本估计梯度

对 $\overline{\text{VE}}$ 的梯度，逐状态展开：

$$
\nabla \overline{\text{VE}}(\mathbf{w}) \;=\; \sum_s \mu(s)\,\big(\hat{v}(s,\mathbf{w}) - v_\pi(s)\big)\,\nabla \hat{v}(s,\mathbf{w})
$$

真值 $v_\pi$ 未知，但若我们能对每个状态拿到一个**无偏的回报样本** $U_t$（如 MC 回报 $G_t$），那么 $\big(\hat{v}(S_t,\mathbf{w}) - U_t\big)\nabla\hat{v}(S_t,\mathbf{w})$ 就是该梯度的无偏估计——它的期望等于上面的梯度（差一个符号与权重常数）。于是 **SGD 更新**：

$$
\mathbf{w}_{t+1} \;=\; \mathbf{w}_t - \tfrac{1}{2}\alpha\,\nabla\big[U_t - \hat{v}(S_t,\mathbf{w}_t)\big]^2 \;=\; \mathbf{w}_t + \alpha\big[U_t - \hat{v}(S_t,\mathbf{w}_t)\big]\nabla \hat{v}(S_t,\mathbf{w}_t)
$$

**只要目标 $U_t$ 是 $v_\pi(S_t)$ 的无偏估计、且步长满足 Robbins–Monro 条件，SGD 就收敛到 $\overline{\text{VE}}$ 的（局部）最小值**——这是函数逼近预测里少数「干净」的结论之一。<span class="marginnote">关键条件在「无偏」二字：MC 回报 $G_t$ 无偏（方差大）；TD 目标 $R+\gamma\hat v(S_{t+1},\mathbf w)$ 有偏（因为用了不准确的 $\hat v$）。无偏 → 标准 SGD 收敛；有偏 → 必须降级为半梯度。</span>

**一个「SGD 如何朝梯度走」的数字小例**：设单特征 $\hat v(s)=\theta x$，当前 $\theta=1$、$x=2$（即 $\hat v=2$），真值 $v_\pi=5$，MC 样本 $G_t=4.8$（无偏，略带噪声）。梯度 $\nabla\hat v = x = 2$，误差 $U-\hat v = 4.8-2=2.8$，取 $\alpha=0.1$ 则 $\theta \leftarrow 1 + 0.1\times2.8\times2 = 1.56$。**每次样本都「朝减少 $\overline{\text{VE}}$」的方向挪一点**——虽然单个样本只含噪声，但大量样本的期望方向正是全局梯度方向，这就是「随机」二字的意义：单步抖，期望不抖。

## 2 半梯度 TD(0)：把目标当常数

如果目标 $U_t$ 里含参数（TD 目标、n步目标都是如此），还拿它对 $\mathbf{w}$ 求导，就会把「目标随参数移动」也计进梯度——通常导致发散或振荡。**半梯度方法**干脆规定：**对 $U_t$ 不求导**。半梯度 TD(0) 的更新是：

$$
\mathbf{w}_{t+1} \;=\; \mathbf{w}_t + \alpha\big[\underbrace{R_{t+1} + \gamma\,\hat{v}(S_{t+1},\mathbf{w}_t)}_{\text{目标：视为常数}} - \hat{v}(S_t,\mathbf{w}_t)\big]\nabla \hat{v}(S_t,\mathbf{w}_t)
$$

对比完整梯度，缺的是「对 $\gamma\hat{v}(S_{t+1},\mathbf{w}_t)$ 关于 $\mathbf{w}$ 的导数项」。<span class="marginnote">这个「缺失项」在 on-policy 表格/线性情形下无害（第6章照常收敛），但在「离策略 + 自举 + 函数逼近」三要素齐备时成为发散之源（第11章贝尔德反例）。所以「缺的那一项」不是可省的小尾巴，而是「稳定性边界的开关」。</span>它的行为特征：

- **不收敛到 $\overline{\text{VE}}$ 最小值**，而是收敛到**TD 不动点（TD fixed point）**——一个由「当前目标自洽」决定的折中解。
- 但在**线性参数化**下，半梯度 TD(0) 的收敛性是**可靠**的（步长衰减时收敛到不动点），且收敛解通常误差不大。
- **表格型里半梯度 TD(0) 退化为标准 TD(0)**——所以你在第6章学的一切都没有白费，只是被包进了更大的框架。<span class="marginnote">半梯度的「妥协」换来两个实际好处：方差小（目标是自举的）、可在线更新。教材的观点很务实：在函数逼近里，TD 的半梯度不动点「虽不是全局最优，却是稳定可得的最优」——工程上先要稳，再谈优。</span>

**一个「半」字的具体对照**：设单参数线性 $\hat v(s,\theta)=\theta x$，$\gamma=0.9$，$S$ 的 $x=1$、$S'$ 的 $x'=0.5$，$\theta=1.0$，$R=0$，$\alpha=0.1$。先算 $\hat v(S)=1.0$、$\hat v(S')=0.5$，TD 误差 $\delta=0+0.9\times0.5-1.0=-0.55$：

- **半梯度**：$\theta \leftarrow 1.0 + 0.1\times(-0.55)\times 1 = 0.945$——只沿 $\nabla\hat v(S)=x=1$ 走。
- **完整梯度**：再多出「对 $\gamma\hat v(S')$ 的导数」$\gamma x'=0.45$，$\theta \leftarrow 1.0 + 0.1\times(-0.55)\times(1+0.45)=0.920$——步子更大、方向被「未来」修正。

半梯度少走的那 $0.025$，正是「$S'$ 的估计也会随 $\theta$ 变」这一项——**它让每一步更新更保守，代价是收敛点不再是全局最小**。这就是「缺项 = 稳定性开关」的数字落地。

**「TD 不动点长什么样」一句话**：它是「$\hat v$ 满足『下一步价值用当前 $\hat v$ 自洽』」的那个参数——即「把贝尔曼方程投影到特征空间后，最接近成立」的点。第11章的贝尔德反例里，这个不动点虽然在，但半梯度的更新路径会先发散再撞回来；而第11章后半的梯度 TD 等方法，正是「直接朝这个不动点走」的修正。**「半梯度收敛到不动点」这件事，既解释了 TD 为什么能跑，也预告了第11章「怎么在离策略下也让它跑到」的全部故事**。

**SGD 与半梯度的边界一表看清**：

| 维度 | 随机梯度下降（SGD） | 半梯度 |
| --- | --- | --- |
| 目标 | $U_t$（无偏样本） | TD/n步目标（有偏、含参数） |
| 是否对目标求导 | 是（目标不含参数） | 否（目标当常数） |
| 收敛点 | $\overline{\text{VE}}$ 局部最小 | TD 不动点 |
| 适用目标 | MC 回报 | TD、n步、资格迹目标 |
| 稳定性 | 需无偏目标才稳 | 有偏但线性下稳定 |

**一句话**：SGD 是「对明确目标走梯度」，半梯度是「对移动目标做稳定追随」——前者求优、后者求稳，工程上绝大多数 RL 逼近用的是后者。

## 3 n步半梯度：把 n 步回报当目标

同样的半梯度思想直接搬到 n步。目标换成 **n步回报** $G_{t:t+n}$（视为常数）：

$$
\mathbf{w}_{t+1} \;=\; \mathbf{w}_t + \alpha\big[G_{t:t+n} - \hat{v}(S_t,\mathbf{w}_t)\big]\nabla \hat{v}(S_t,\mathbf{w}_t)
$$

这里的 $G_{t:t+n}$ 含 $\gamma^n \hat{v}(S_{t+n},\mathbf{w})$——仍然有参数，仍然不求导（半梯度）。n步半梯度在**线性情形**下也是稳定收敛的，且 n 越大、收敛解越接近 $\overline{\text{VE}}$ 最小值（因为自举成分被推迟），代价是方差增大——**第7章的 U 形权衡在函数逼近里原样重演**。<span class="marginnote">第7章学的「n 是偏差-方差旋钮」在这里没有过时，只是旋钮的作用对象从「表格里的值」变成「参数化的值」。这也暗示了第12章 TD(λ)：用 λ 把所有 n 的回报加权平均，一次性收获「n 的多样性」。</span>

**「n 越大越接近全局最小」值得强调**：MC（$n\to\infty$）用无偏回报，其 SGD 更新就是标准 SGD，收敛到 $\overline{\text{VE}}$ 的局部最小；TD(0)（$n=1$）用自举目标，收敛到 TD 不动点。**所以「半梯度的收敛点」随 n 从不动点滑向全局最小**——n 不仅是偏差-方差旋钮，还是「收敛目标」的连续旋钮。工程师在 n 上的选择，本质上是在「要最稳的不动点」与「要最优但抖的全局最小」之间权衡。

## 4 公式解析：一条更新里的「梯度」与「非梯度」

$$
\mathbf{w}_{t+1} = \mathbf{w}_t + \alpha\,\underbrace{\big[\,R_{t+1} + \gamma\,\hat{v}(S_{t+1},\mathbf{w}_t) - \hat{v}(S_t,\mathbf{w}_t)\,\big]}_{\text{TD 误差 } \delta_t}\underbrace{\nabla \hat{v}(S_t,\mathbf{w}_t)}_{\text{当前项的梯度}}
$$

- **第一步，认误差**：$\delta_t = R_{t+1} + \gamma\hat{v}(S_{t+1},\mathbf{w}_t) - \hat{v}(S_t,\mathbf{w}_t)$——和第6章的 TD 误差一模一样的量，只是 $\hat{v}$ 现在带参数。它告诉更新「往哪个方向调」。<span class="marginnote">「量一样、参数化不一样」是理解全章的关键：第6章的 $\delta$ 直接改表格格子，这里的 $\delta$ 作为「误差标量」乘梯度——误差大则步子大、梯度方向决定朝哪调。表格型只是「梯度 = one-hot 向量」的特殊情形。</span>
- **第二步，认梯度**：$\nabla\hat{v}(S_t,\mathbf{w}_t)$ 是当前状态的梯度，指示「$\mathbf{w}$ 朝哪个方向调，能最快改变 $\hat{v}(S_t)$」。两项相乘：误差大 → 步子大；梯度陡 → 调得猛。
- **第三步，认缺失**：$\gamma\hat{v}(S_{t+1},\mathbf{w}_t)$ 里的 $\mathbf{w}_t$ **没有被求导**——这就是「半」。若把它也求导，梯度里会多出 $\gamma\nabla\hat v(S_{t+1})$ 项，正是这一项在离策略+自举+函数逼近下引发发散（第11章）。<span class="marginnote">一个记忆锚点：完整梯度是「追着当前样本的最小化」，半梯度是「追着一个移动目标的稳定追随」。前者可能追空，后者总追得着——虽然追到的不是全局最优。</span>

## 5 易错点辨析

**辨析｜易错点：** 以为「半梯度只是 SGD 的一个实现细节」。它们的目标根本不同：SGD 最小化 $\overline{\text{VE}}$（需无偏目标），半梯度收敛到 TD 不动点（容忍有偏目标）。**把 MC 目标换成 TD 目标，不只是「换了个目标函数」，而是整个收敛点都变了**——这也是教材坚持把二者分开讲的深层原因。<span class="marginnote">这个区别还有个实用的推论：若你用一个「无偏的 MC 回报」当目标，你跑的就是标准 SGD，可以放心追求全局最小；一旦换成「自举的 TD 目标」，你就自动进入了半梯度的框架——「先想清楚目标无偏与否，再决定该用哪套收敛理论」。</span>

**另一个易错点**：混淆「步长 $\alpha$ 是否要衰减」。半梯度 TD(0) 在线性情形，**即使 $\alpha$ 固定也能收敛到不动点附近的界内**（不会无界漂移）；但若要收敛到精确不动点，仍需 $\sum\alpha=\infty,\sum\alpha^2<\infty$。工程上常见「固定小 $\alpha$」，学到的不是严格收敛点而是「准稳态」——知道这点，看论文曲线就不会被「没衰减也稳了」误导。<span class="marginnote">工程上「固定小 α」的理由不只是省事：α 太小则收敛慢、α 太小又怕越过不动点；「衰减 α」在 RL 里常被「自适应优化器」（Adam 等）隐式替代——它逐参数缩放步长，等于「每个坐标各配一个 α」，这在深度 RL 里比手工衰减更省心。</span>

**第三个易错点**：把非线性参数化（神经网络）当线性一样分析。**半梯度 TD 的收敛性证明只对线性情形成立**；神经网络（非线性）下连「收敛到不动点」都未必保证——第14篇深度 RL 的种种工程技巧，大半是为了在非线性下「假装它是线性」地稳住训练。

**第四个易错点**：把「半梯度」当「只是实现细节的省略」。它不是「偷懒少算一项」，而是**主动选择的优化目标**——半梯度在「每一步更新量」上精确对应「最小化 TD 误差的平方」这种「半目标」，而非全局 $\overline{\text{VE}}$。**「对哪半个求导」是方法学问题，不是工程近似**——理解了这一点，才理解为什么第11章会把「该不该把 $\gamma\hat v(S_{t+1})$ 也求导」当成离策略发散的核心争论。

## 6 小结

- **SGD**：用无偏样本目标 $U_t$ 估计 $\overline{\text{VE}}$ 梯度；无偏目标 → 收敛到（局部）最小。
- 数字例：$\theta\leftarrow1+0.1\times2.8\times2=1.56$——单步含噪声，期望方向正是全局梯度。
- 半梯度是「主动选择的目标」，不是「偷懒省略」——对哪半个求导是方法学问题。
- **半梯度**：对含参数的目标不求导；有偏但稳定，收敛到**TD 不动点**而非全局最小。
- 半梯度 TD(0)：$\mathbf{w} \leftarrow \mathbf{w} + \alpha\delta_t\nabla\hat v(S_t,\mathbf{w})$；表格型下退化为标准 TD(0)。
- SGD 求优、半梯度求稳：前者「对明确目标走梯度」，后者「对移动目标做稳定追随」。
- **n步半梯度**：目标换 n步回报，n 仍是偏差-方差旋钮。
- n 还是「收敛目标」的连续旋钮：$n\to\infty$ 滑向全局最小，$n=1$ 停在 TD 不动点。
- 自适应优化器（Adam 等）在深度 RL 里隐式替代「手工衰减 α」——逐参数缩放步长更省心。
- 线性参数化下收敛性可靠；非线性下只是工程性稳定，理论保证薄弱。
- 缺的那项（对 $\gamma\hat v(S_{t+1})$ 求导）是「稳定性边界的开关」——on-policy 无害，离策略+自举+逼近下引发放散。
- 第6章 $\delta$ 直接改格子、这里 $\delta$ 乘梯度——「量一样、参数化不一样」是函数逼近的起点。
- 「半梯度收敛到 TD 不动点」既解释 TD 为什么能跑，也预告第11章「离策略下怎么修正」的全部故事。
