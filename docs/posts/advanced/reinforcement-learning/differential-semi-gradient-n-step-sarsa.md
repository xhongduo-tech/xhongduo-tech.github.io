## 为什么要把「差分」与「n步」拼起来

上一课给出了平均奖励设定的单步差分 TD。这一课把它升级成完整的控制算法：**差分半梯度 n步 Sarsa（differential semi-gradient n-step Sarsa）**——平均奖励设定（差分回报）+ 多步自举（n步）+ 函数逼近（半梯度）三件套合体。三者各自解决一个问题：差分回报让**持续性任务**的目标诚实，n步让**自举与采样的比例可调**，半梯度让**参数化价值在目标漂移下还能站住**。这也是本书表格型章节里「最终形态」级别的算法——它把第6、7、9、10章的主线全部拧成一股绳。<span class="marginnote">教材用「接入控制排队任务（access-control queuing）」演示它：一个有优先级的服务队列，系统要决定「是否接入新任务」。这是典型的持续性决策——没有终局，只有永远在线的取舍，平均奖励设定正是它的主场。</span>

## 1 差分 n步回报：每步都减平均

平均奖励设定下的 **n步差分回报（n-step differential return）** 是：

$$
G_{t:t+n} \;=\; R_{t+1} - \bar r + R_{t+2} - \bar r + \cdots + R_{t+n} - \bar r + \hat q(S_{t+n}, A_{t+n}, \mathbf{w})
$$

对比折扣 n步回报，三处变化：

- 每步真实奖励都被**中心化**（减 $\bar r$）；
- 自举项**不再有 $\gamma^n$ 折扣**（持续任务里没有 $\gamma$）；
- 自举对象仍是动作价值 $\hat q(S_{t+n},A_{t+n},\mathbf w)$——**注意没有减 $\bar r$**，因为动作价值本身就是「相对平均」的度量。<span class="marginnote">为什么自举项不减 $\bar r$？因为 $\hat q$ 已经按「相对平均」标定：$q>0$ 意味着「比平均好」。若自举项也减 $\bar r$，会双重扣减、把价值整体压偏——「奖励减 $\bar r$、价值不减」是差分回报在动作价值上的统一约定。</span>

## 2 差分半梯度 n步 Sarsa：更新与 $\bar r$ 的在线估计

差分半梯度 n步 Sarsa 的更新是：

$$
\mathbf{w}_{t+1} \;=\; \mathbf{w}_t + \alpha\big[\,G_{t:t+n} - \hat q(S_t, A_t, \mathbf{w}_t)\,\big]\nabla \hat q(S_t, A_t, \mathbf{w}_t)
$$

与折扣版唯一的差别在 $G_{t:t+n}$ 的定义——其余照搬。而 **$\bar r$ 本身也要在线学习**，常见的做法是与一步 TD 误差耦合：

$$
\bar r \;\leftarrow\; \bar r + \beta\,\delta_t, \qquad \delta_t = R_{t+1} - \bar r + \hat q(S_{t+1}, A_{t+1}, \mathbf{w}) - \hat q(S_t, A_t, \mathbf{w})
$$

这里出现了两个步长：$\alpha$（价值参数）与 $\beta$（平均奖励估计）。**$\beta$ 决定 $\bar r$ 追踪环境平均奖励的速度**——$\beta$ 太小，$\bar r$ 滞后、价值基准漂移；$\beta$ 太大，$\bar r$ 被噪声扰动。教材建议 $\beta$ 常取与 $\alpha$ 相近或稍小的值。

### 数值算例：差分 n步回报怎么「扣基准」

设平均奖励估计 $\bar r = 1$，取 n=3。观察到奖励 $R_1 = 3$、$R_2 = 0$、$R_3 = 2$，自举价值 $\hat q(S_3, A_3) = 5$。则：

$$
G_{0:3} = (3-1) + (0-1) + (2-1) + 5 = 2 - 1 + 1 + 5 = 7
$$

**逐项读**：三步真实奖励中心化后分别贡献 $+2$、$-1$、$+1$，净相对收益是 $+2$；自举价值 $5$ 表示「从 $S_3$ 出发的长期相对优势」。整体 $G_{0:3}=7$ 意味着「这段轨迹整体比平均高出 7 个单位」。

若 $\bar r$ 估计错误（比如 $\bar r = 3$），则 $G_{0:3} = 0 + (-3) + (-1) + 5 = 1$——**基准偏了就整体压偏**，这正是为什么 $\bar r$ 的在线估计要跟上环境真实平均。对比折扣版（若 $\gamma = 0.9$）：$G_{0:3} = 3 + 0.9 \times 0 + 0.9^2 \times 2 + 0.9^3 \times 5 = 3 + 0 + 1.62 + 3.645 = 8.265$——数值不同，但「真实奖励 + 自举」的结构完全同构。<span class="marginnote">两个步长的存在是平均奖励设定的「税」：折扣设定只有 $\alpha$ 一个步长要调，平均奖励设定多一个 $\beta$。这也是工程上「折扣设定更受欢迎」的又一条理由——少一个超参。但 $\bar r$ 的引入换来的是持续性任务下目标的诚实。</span>

## 3 接入控制任务：差分 n步的实战

**接入控制（access control）** 任务（教材 Example 10.2）是一个 10 优先级的服务系统：每个时隙有概率到达一个新任务，系统决定「接入」（赚取与优先级成正比的高收益，但占用服务器 n 步）或「拒绝」（收益 0，服务器空闲）。目标是最大化长期平均收益。

这个任务的特性让它成为差分 n步的完美试金石：

**持续无终局**：系统永不停止，折扣设定无法直接套用（没有幕末）。
**收益依赖长期权衡**：接太多任务 → 高优先级任务被占住时只能拒绝 → 收益不升反降；接太少 → 浪费服务器。最优策略是「优先接入高优先级任务、低优先级排队看情况」。
**最优平均收益可算**：教材给出最优策略能达的平均回报，作为对照基准。

**差分半梯度 n步 Sarsa**（配瓦片编码）在此任务上**收敛到接近最优的平均收益**，且 n 取中间值（如 $n=4$）时收敛又快又稳——再次验证「n 是偏差-方差旋钮」在平均奖励设定下依然成立。<span class="marginnote">这个例子的教学价值在于：它展示了「平均奖励」不是理论玩具——排队系统、网络路由、供应链控制都是它的真实应用场景。而差分 n步 Sarsa 是这类「永远在线决策」问题的开箱算法。</span>

把折扣 n步回报与差分 n步回报并排对照：

| 维度 | 折扣 n步回报 | 差分 n步回报 |
| --- | --- | --- |
| 真实奖励项 | $R_{t+1} + \gamma R_{t+2} + \cdots$ | $(R_{t+1}-\bar r) + (R_{t+2}-\bar r) + \cdots$ |
| 折扣因子 | $\gamma^n$ | 无 |
| 自举项 | $\gamma^n \hat q(S_{t+n})$ | $\hat q(S_{t+n})$，不减 $\bar r$ |
| 适用任务 | 幕式（有终局） | 持续性（无终局） |
| 步长个数 | 1 个（$\alpha$） | 2 个（$\alpha$ 与 $\beta$） |
| n 的语义 | 向前看 n 步再打折扣 | 向前看 n 步真实相对收益 |

**读表要点**：差分版不是「折扣版的变形」，而是「把 γ 与幕结构整个换成中心化奖励」——数学结构平行，工程手感完全不同（多一个步长、没有幕末对齐）。

## 4 公式解析：差分 n步回报如何「扣基准、留自举」

$$
G_{t:t+n} \;=\; \underbrace{(R_{t+1}-\bar r) + (R_{t+2}-\bar r) + \cdots + (R_{t+n}-\bar r)}_{\text{n 步中心化奖励}} + \underbrace{\hat q(S_{t+n}, A_{t+n}, \mathbf w)}_{\text{自举动作价值（不减 }\bar r\text{）}}
$$

- **第一步，认中心化**：前 n 个真实奖励每步减 $\bar r$，得到「相对平均」的 n 步增益——它们衡量「这 n 步比平均多赚（或少赚）了多少」。
- **第二步，认自举**：$\hat q(S_{t+n},A_{t+n},\mathbf w)$ 不减 $\bar r$，因为动作价值已经是「相对平均」的标度；用它顶替「第 n 步之后的全部相对收益」。
- **第三步，认整体**：整个 $G_{t:t+n}$ 是「n 步真实相对收益 + 一步自举相对收益」——与折扣版的唯一区别是「折扣因子消失、中心化奖励出现」。**当 n 增大，自举成分后移、真实成分增多，方差增大、偏差减小；当 n 减小，反之**——第7章的 U 形权衡在平均奖励设定下原样复现。<span class="marginnote">实现要点：因为无折扣，$G_{t:t+n}$ 里各项没有 $\gamma^{i}$ 的指数衰减——n 步的长度直接就是「向前看多少步真实奖励」，语义比折扣版更直白。这也让「n 的选择」在差分设定下更接近「决策时往前想几步」的本意。</span>

## 5 易错点辨析

**辨析｜易错点：** 把差分 n步回报的「中心化奖励」误用到自举项上。**奖励减 $\bar r$，自举动作价值不减**——若自举项也减 $\bar r$，价值被双重扣减、整体偏移。记忆口诀：**「$\bar r$ 只扣真实奖励，不扣自举价值」**。

**另一个易错点**：忘记 $\bar r$ 的估计要与价值更新解耦好。$\bar r$ 若用「整段 n步回报的平均差」更新，会与价值估计耦合过深、振荡；标准做法是**用单步 TD 误差**驱动 $\bar r$ 的滑动更新，让两个估计各有各的时间尺度。

**第三个易错点**：以为「平均奖励设定不需要 $\gamma$ 就没有超参了」。它只是把 $\gamma$ 换成了 $\beta$（$\bar r$ 的学习率）——**超参没有消失，只是换了个名字**。而且 $\beta$ 的取值更微妙，因为它同时影响「基准」与「价值」两个估计。

## 6 术语速查

| 术语 | 一句话含义 |
| --- | --- |
| 平均奖励设定 | 用 $R - \bar r$ 中心化奖励，面向持续性任务 |
| 平均奖励 $\bar r$ | 长期平均每步奖励，须在线估计 |
| 差分回报 | n 步中心化奖励之和 + 自举动作价值（不减 $\bar r$） |
| 差分半梯度更新 | 以差分回报为目标、对当前估计求梯度的更新 |
| 接入控制任务 | 10 优先级排队系统，持续决策的经典试金石 |
| 折扣设定 | 用 $\gamma$ 折扣未来奖励，面向幕式任务 |

## 7 小结

- **差分 n步回报**：n 步中心化奖励（减 $\bar r$）+ 自举动作价值（不减 $\bar r$），无折扣因子。
- **差分半梯度 n步 Sarsa**：$G_{t:t+n}$ 作目标 + 半梯度更新，$\bar r$ 由单步 TD 误差在线估计。
- **两个步长**：$\alpha$（价值）、$\beta$（平均奖励），$\beta$ 是平均奖励设定的「税」。
- **接入控制**：持续无终局任务的经典案例，差分 n步 Sarsa 收敛到近最优平均收益。
- n 仍是偏差-方差旋钮；$\bar r$ 只扣奖励、不扣自举价值。
