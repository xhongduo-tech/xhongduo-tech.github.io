## 为什么从「探索起点」开始

上一节我们有了无模型的价值估计——首次访问 MC 预测。但预测只是开胃菜，这一节要动真格：**控制**，即不给定策略、直接找出最优策略 $\pi_*$。思路顺理成章：套用第四篇的广义策略迭代（GPI）——评估与改进交替进行——只是把「评估」部件从 DP 的贝尔曼迭代换成 MC 的回报平均。骨架不变，血肉更新。

然而 MC 评估动作价值时有一个天生的窟窿，上一节结尾我们已经撞上：**确定性的策略只会光顾被它选中的动作，其余动作的价值永远估不到。** 没有样本，贪心（$\arg\max_a$）就成了在「垃圾估计」里选秀。要堵上这个窟窿，第五篇请出了它的招牌假设——**探索起点（exploring starts）**：把探索从学习过程里抽出来，直接塞进回合的开头。

这一节回答三件事：MC 控制长什么样、为什么绕不开探索、以及探索起点如何把 GPI 的轮子转起来。

## 1 控制 = 把 GPI 的评估换成 MC

回顾第四篇的广义策略迭代：任何「评估让价值贴近当前策略、改进让策略贴近当前价值」的交替过程，都收敛。策略迭代是「评估到底再改进」的极端，值迭代是「评估一步就改进」的极端。MC 控制只是把评估手段换成「平均回报」，其余机械照搬。

**MC 探索起点算法（Monte Carlo ES）**：

1. 对每个 $(s, a)$，任意初始化 $q(s, a)$；对每个状态任意初始化 $\pi(s)$。
2. 循环：
   - **采集回合**：从每个 $(s, a)$ 都以非零概率出发，用当前策略 $\pi$ 跑一个完整回合。
   - **评估**：用首次访问 MC 更新每个 $(s, a)$ 的估计——把回合里首次出现 $(s, a)$ 处的回报 $G_t$ 平均进 $q(s, a)$。
   - **改进**：对每个状态，令 $\pi(s) \leftarrow \arg\max_a q(s, a)$。

![探索起点假设：Q 表的每一格都要成为回合起点](/images/reinforcement-learning/monte-carlo-control-exploring-starts-1.svg)

**重点：MC 控制与第四篇的策略迭代在结构上完全同构，唯一差别是评估算子。** 策略迭代用贝尔曼迭代把 $v_\pi$ 算到收敛，MC ES 用回合回报把 $q_\pi$ 平均出来；改进都是同一个贪心规则。第四篇那个「评估拉向 $v_\pi$、改进拉向贪心」的 GPI 螺旋，在这里原封不动地复活，只是评估的口粮从「模型」换成了「经验」。<span class="marginnote">第四篇 §4.6 的 GPI 图（图 4.7）在这里依然成立：MC 控制的评估不再是「全体状态同步扫描」，而是「来了哪个 (s,a) 就更新哪个」，这正是异步思想的又一次体现——评估的调度完全由经验驱动。</span>

## 2 探索死结：确定性的策略喂不饱 Q 表

改进规则 $\pi(s) \leftarrow \arg\max_a q(s, a)$ 有一个致命副作用：**它把策略变成了确定性的**。一旦某个动作在某状态胜出，下一轮该状态就只选它。

于是第二轮 MC 评估立刻挨饿：每个状态只采到「被选中动作」那一个 $(s, a)$ 的样本，其它动作的 $q$ 停留在一开始的初值。第三轮改进在这个残缺的 $q$ 上取 $\arg\max$——如果某个真正优秀的动作因为没被采到而保持低初值，它可能**永远**被埋没。

这并非实现细节，而是控制问题的**结构性困难**：贪心改进需要全部动作价值，而贪心行为只产生部分动作的样本。二者天然冲突。

**重点：无模型控制必须回答「如何保证每个动作都被尝试」——这是从第二篇多臂老虎机就认识的探索-利用困境，在控制问题里第一次变得不可回避。** 老虎机里至少每轮还能摇任何一只手臂；MC 控制里，确定性策略会彻底饿死「非贪心动作」的估计。<span class="marginnote">回想第二篇 k 臂老虎机：ε-贪心、UCB、乐观初值，全部是在同一个「探索-利用」天平上做文章。MC 控制把这个问题从「一只手臂」放大到「一张 Q 表」，但解药本质上仍是那几味。</span>

## 3 探索起点：把探索挪到回合的开头

解药是 **探索起点（exploring starts，ES）**：**假设每个回合都以非零概率从每一个「状态-动作」对 $(s, a)$ 出发**。也就是说，环境（或实验设计）保证：无论 $(s, a)$ 多冷门，总有一天会有一个回合从它开始。

这个假设优雅地把问题一刀切开：

**探索归起点管**：所有 $(s, a)$ 都会在「回合开头」被尝到，估计不会饿死。
**学习归策略管**：回合一旦开始，就放心地走贪心策略——不必再在每一步兼顾探索。

**重点：ES 的价值在于把「探索」与「策略学习」解耦。** 它用一个「每个角落都去过」的外部保证，换来了学习过程内部的全然贪心。这就像探险队不必在行进时处处兜圈子，而是派出小队从每个岔路口分别出发，把地图画全之后再放心走最短路。

**辨析｜易错点：ES 是「环境或实验者」的属性，不是算法的属性。** 算法本身没有「保证探索」的机制；ES 是写在假设里的外部承诺。真实世界里你几乎无法从任意状态、摆出任意动作开始一个回合——这正是 ES 被多数实践抛弃的原因，但作为第一个能证明收敛的无模型控制算法，它是第五篇理论叙事的必经站。<span class="marginnote">现实中 ES 并非毫无影子：自对弈棋类里「从不同局面开始训练」、机器人「从不同初始姿态尝试」都近似 ES。下一节我们还要面对它的替代品——ε-软策略，与更彻底的离策略路线。</span>

## 4 公式解析：贪心改进为什么必须看 q 而不是 v

MC ES 的改进步骤是 $\pi(s) \leftarrow \arg\max_a q(s, a)$。为什么这个「看着 $q$ 贪心」的行为一定改进策略？这需要第四篇的策略改进定理，拆三步看。

- **第一步，写出改进后的策略。** 定义 $\pi'$ 为对当前动作价值 $q_\pi$ 的贪心：

$$\pi'(s) = \arg\max_a q_\pi(s, a)$$

它把每个状态的动作「换挡」到当前估计最好的那个。$\arg\max$ 是「看表换挡」：比较同一行（同一状态）所有动作列，取最大者。

- **第二步，代入改进定理的条件。** 策略改进定理（§4.2）说：若对所有 $s$ 有 $q_\pi\!\left(s, \pi'(s)\right) \ge v_\pi(s)$，则 $\pi'$ 不劣于 $\pi$。对贪心构造的 $\pi'$，左侧恰好是最大值：

$$q_\pi\!\left(s, \pi'(s)\right) = \max_a q_\pi(s, a) \;\ge\; \sum_a \pi(a \mid s)\, q_\pi(s, a) = v_\pi(s)$$

中间的不等号是显然的：**最大值不可能小于加权平均**。右边把 $v_\pi$ 展开成 $q_\pi$ 的加权和，正是第三篇动作价值与状态价值的关系式。

- **第三步，得出单调改进。** 于是 $\pi'$ 处处不劣于 $\pi$；等号成立当且仅当 $v_\pi$ 已是 $v_*$。因此「评估 $q_\pi$ → 贪心改进」每一轮都让策略朝最优单调推进——与 DP 的策略迭代收敛论证完全同构，只是这里的 $q_\pi$ 来自 MC 平均而非贝尔曼求解。

**辨析｜易错点：为什么必须估 $q$，估 $v$ 不行？** 因为改进要用 $\arg\max_a$，它需要比较「同一状态下每个动作」的好坏；而 $v_\pi(s) = \sum_a \pi(a\mid s) q_\pi(s,a)$ 只是一个加权平均，从平均里解不出单个动作的排序。上一节我们说「控制必须估动作价值」，这一节的公式解析就是这句话的数学兑现——**没有 $q$，就写不出那个 $\arg\max$，策略就改不动。**

## 5 实现：走廊上的 MC 探索起点控制

把算法落到代码。环境与上节相同：四格走廊，状态 $1$–$4$，左右两个动作，到 $0$ 或 $5$ 终止，每步奖励 $-1$。ES 用「随机抽取起始 $(s, a)$」实现。

```python
import random

Q = {(s, a): 0.0 for s in range(1, 5) for a in (-1, 1)}   # 动作价值
N = {(s, a): 0 for s in range(1, 5) for a in (-1, 1)}     # 首次访问计数

def greedy(s):                         # 贪心策略：取 Q 最大的动作
    return max((-1, 1), key=lambda a: Q[s, a])

for _ in range(200_000):
    s = random.choice([1, 2, 3, 4])    # 探索起点：随机起始状态
    a = random.choice([-1, 1])         # 探索起点：随机起始动作
    traj = []
    while s not in (0, 5):
        traj.append((s, a))            # 记录 (s, a)
        s += a
        if s in (0, 5):
            break
        a = greedy(s)                  # 回合开始后一路贪心

    G = 0
    seen = set()
    for s, a in reversed(traj):        # 首次访问 MC 更新
        G += -1                        # 每步奖励 -1
        if (s, a) in seen:
            continue
        seen.add((s, a))               # 每回合每个 (s, a) 只更新一次
        N[s, a] += 1
        Q[s, a] += (G - Q[s, a]) / N[s, a]

print({s: greedy(s) for s in range(1, 5)})   # {1: -1, 2: -1, 3: 1, 4: 1}
```

收敛后策略应是「永远往近的一端走」：状态 $1$、$2$ 向左（更快到 $0$），状态 $3$、$4$ 向右（更快到 $5$）。注意代码里「探索」完全由 $0$ 的起始点承担，回合开始后策略一路贪心——**这就是 ES 的兑现：探索只存在于开头。**<span class="marginnote">这段代码的回报计算与上一节完全相同（从后往前累加）；MC ES 的唯一新增是「控制起点」与「每回合结束后立即贪心改进」。把 $3$ 里 $4$ 换成某个软策略、并去掉探索起点，它就退化成同策略（ε-贪心）MC 控制。</span>

## 6 辨析：探索起点 vs ε-软策略，两条探索路线

ES 不是唯一的探索解药。Sutton & Barto 在同一章紧接着给出另一条更实用的路线——**ε-软策略（ε-soft）**：让策略在每个状态以至少 $\frac{\varepsilon}{|\mathcal{A}|}$ 的概率选择每个动作（ε-贪心是它的特例）。两条路线对照：

- **探索起点**：探索集中在回合开头；学习过程全贪心。理论上保证收敛到 $\pi_*$，但要求「能控制起点」，实践中几乎做不到。
- **ε-软策略**：每步都以小概率随机，是**同策略（on-policy）**控制——估的是「ε-贪心策略本身」的价值，因此只能保证收敛到**ε-最优**，而非真最优。优点是无需控制起点，通用。

**辨析｜易错点：别把「探索」误当成「学习到的行为」。** ε-贪心最终学到的策略**包含**随机动作，所以它的「最优」是被 ε 拖累过的近似最优；ES 学到的策略则是纯净的贪心。若你看到某个无模型算法声称「找到最优策略」，先问一句：它的探索是塞在开头（ES）还是缠在策略里（ε-软）？答案决定了「最优」二字的纯度。

**重点：ES 与 ε-软都还在「同策略」的地盘——学什么策略，就用什么策略采数据。** 下一节我们要跳出这个地盘：让**行为策略**负责探索、**目标策略**负责学习，两者分家——这就是离策略（off-policy）方法，而它需要一件新工具：重要性采样。

## 7 小结

- **MC 控制**：把 GPI 的评估部件换成「平均回报」，改进仍是 $\pi(s) \leftarrow \arg\max_a q(s,a)$；与 DP 策略迭代同构，只是口粮从模型换成经验。
- **探索死结**：贪心改进需要全部动作价值，贪心行为只产生部分动作的样本——无模型控制必须正面解决探索。
- **探索起点（ES）**：每个 $(s, a)$ 都以非零概率成为回合起点，把探索与策略学习解耦；它保证所有动作价值都能被采样，但要求能控制起点，现实难用。
- **改进的数学**：$\pi'(s) = \arg\max_a q_\pi(s,a)$ 使 $q_\pi(s,\pi'(s)) = \max_a q_\pi(s,a) \ge v_\pi(s)$，由策略改进定理得单调改进——必须估 $q$ 而非 $v$，因为 $\arg\max$ 需要动作级的比较。
- **两条探索路线**：ES（收敛到真最优，理论干净）vs ε-软策略（收敛到 ε-最优，实践常用）。
- **承前启后**：ES 与 ε-软都是同策略；下一节转向离策略，用行为策略采数据、目标策略学习。

在下一节，我们将拆掉「学什么策略就用什么策略采样」的墙：让一个爱探索的行为策略去采集经验，去估计一个完全不同的目标策略的价值——这就是离策略预测，它的第一件武器是**重要性采样**。
