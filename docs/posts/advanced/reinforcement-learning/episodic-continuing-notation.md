## 为什么从「记号」开始

上一节我们分别定义了回合式与持续性两类任务的回报，得到两条公式外加一条「排他」约束。但两套记号用起来很别扭：回合式要写 $\sum_{k=0}^{T-t-1}$，持续性要写 $\sum_{k=0}^{\infty}$；同一套算法往往要为两类任务各写一遍，代码里也得开两个分支。Sutton & Barto 用一个极其简洁的装置——**终止吸收状态（absorbing state）**——把两套记号合并成一套。

这一节表面上是「记账」，实际上解决的是全书的写作成本：往后每一章（动态规划、蒙特卡洛、时序差分、策略梯度）都只需要写一遍公式，同时覆盖两类任务。<span class="marginnote">这种「用记号统一 + 用边界条件约束」的做法，在数学里遍地都是：第二级《复变函数》里把实积分统一进围道积分、把幂级数统一进洛朗级数，都是同一件事——先承认两种情形，再找一个足够宽的容器把两者都装进去。RL 的统一容器，就是那个吸收状态。</span>读懂了这一节，后面读算法与代码时会少绕很多弯。

## 1 两类任务的对照

先把两类任务摆在一起，看清差别到底在哪里：

| 维度 | 回合式任务（episodic） | 持续性任务（continuing） |
| --- | --- | --- |
| 是否有天然终点 | 有：终止状态 | 无 |
| 地平线 $T$ | 有限 | $T = \infty$ |
| 折扣 $\gamma$ | 可用 $1$（和有限） | 必须 $< 1$（否则发散） |
| 典型例子 | 下棋、走迷宫、打游戏 | 护理机器人、生产线、长期交易 |

关键差别其实只有一行：**地平线 $T$ 是有限还是无穷**。回合式任务在终止状态画了句号，持续性任务永远续写。至于「折扣是否必须小于 1」，只是「地平线无穷时和是否收敛」的推论，不是任务的本质属性。

## 2 吸收状态：把「结束」变成「永远停在原地」

统一记号的机关，是把「结束」也变成一种「不结束」——只不过是不再产生任何东西的结束。定义一个特殊的**终止吸收状态（absorbing state / terminal state）$S_+$**：

- 进入 $S_+$ 后，智能体永远停留其中，不再离开；
- 在 $S_+$ 里，任何「动作」都只会从 $S_+$ 转到 $S_+$ 自己，并且奖励恒为 $0$。

于是，一个本来在 $S_T$ 处终止的回合，可以**当作一条永不结束的轨迹**来看：从 $S_T$ 开始，后面跟着无穷多个 $S_+, S_+, S_+, \ldots$，奖励全是 $0$。这样一来：

**重点：回合式任务 = 一条在吸收状态上永远打转的持续性轨迹。** 由于吸收状态之后的奖励全部为 $0$，「总回报」完全不变——无论你把和截断在 $T$，还是把它延长到无穷，求和结果一模一样。于是我们可以在扩大的状态集

$$\mathcal{S}^+ = \mathcal{S} \cup \{S_+\}$$

上，把两类任务统一成一种：**所有任务都是在 $\mathcal{S}^+$ 上的一条（可能无穷长的）轨迹，回报都是那个统一的求和公式。**<span class="marginnote">把「结束」建模成「停在吸收态」，与第三级《概率论与数理统计》里马尔可夫链的「吸收态」概念完全一致——不可约、常返、吸收，这些马尔可夫链的词汇可以直接搬过来分析 RL 的终止行为。这套词汇在第八篇讲模型与规划时还会用到。</span>

用一个两位数例让「总和不变」落地。设一回合只有两步：$S_0 \xrightarrow{A_0} S_1$（得 $R_1 = 2$）$\xrightarrow{A_1} S_2$（得 $R_2 = 3$，$S_2$ 是终止状态），取 $\gamma = 1$。回合式有限和给出 $G_0 = R_1 + R_2 = 5$。若把 $S_2$ 看作吸收态、把和延长到无穷：$G_0 = R_1 + \gamma R_2 + \gamma^2 R_3 + \cdots = 2 + 3 + 0 + 0 + \cdots = 5$——延长出来的项全是 $0$，总和纹丝不动。

| 写法 | $G_0$ 的展开 |
| --- | --- |
| 回合式有限和（$T = 2$） | $R_1 + R_2 = 5$ |
| 吸收态无限和 | $R_1 + R_2 + 0 + 0 + \cdots = 5$ |
| 统一公式 | $\sum_{k=1}^{2} \gamma^{k-1} R_k = 5$ |

**吸收态的「零奖励自环」让两种写法自动相等**——这就是统一记号的全部底气：你可以自由选择「把和截断在 $T$」还是「让它在吸收态里无限打转」，结果不变，记号却归一了。

## 3 记号约定：时间索引与回合索引

统一了「是否结束」，还差最后两块拼图：**回合之间的区分**与**奖励的标号**。

第一块，回合索引。理论上，第 $i$ 个回合的第 $t$ 步应写成 $S_{t,i}$——状态、动作、奖励都要带上回合号，因为每个回合是独立的一段经历。但实践中，几乎所有的推导都发生在「单个回合内部」，回合号只是拖累。Sutton & Barto 的约定是：**形式上保留 $S_{t,i}$ 的定义，行文中一律简写成 $S_t$**。<span class="marginnote">这不是偷懒，而是有意识的「记号卫生」：把信息冗余的部分藏进定义，把推导真正需要的信息留在台面上。写代码时同理——尽量让「数据结构的形状」自动携带信息，别在每一步都手动维护全局状态。这个品味贯穿第四级《大模型》的工程实践。</span>

第二块，奖励标号。整本书的轨迹写成

$$S_0, A_0, R_1, S_1, A_1, R_2, S_2, A_2, R_3, \ldots$$

其中 $R_t$ 是「从 $S_{t-1}$ 出发、执行 $A_{t-1}$、进入 $S_t$」时拿到的奖励——**奖励的下标对齐「到达的状态」，而不是「出发的状态」**。$R_{t+1}$ 就是「在状态 $S_t$ 执行 $A_t$ 之后」收到的奖励。这一约定让下面的统一公式读起来最顺：回报从 $R_{t+1}$ 开始加。

这套标号落到代码里也很直白：存一条转移 `(s, a, r, s_next)` 时，`r` 对应的正是 $R_{t+1}$；一回合结束时从后往前累加，恰好就是在算统一公式：

```python
# rewards 是这一回合的奖励序列 [R_1, R_2, ..., R_T]
G = 0
for r in reversed(rewards):
    G = r + gamma * G        # 等价于 G_t = R_{t+1} + γ G_{t+1}
```

同一段 `for` 循环，回合式任务照跑、持续性任务照跑——**统一记号在公式层省掉的复杂度，会在实现层原样省回来。** 这也是为什么「记号」值得专门花一整节：它是理论与工程之间的翻译协议。

## 4 公式解析：统一后的回报公式

有了吸收状态与奖励标号约定，两类任务的回报被合成一条公式：

$$G_t \doteq \sum_{k=t+1}^{T} \gamma^{k-t-1} R_k$$

其中，回合式任务取有限 $T$（$S_T$ 为终止状态）；持续性任务取 $T = \infty$。三步拆解这条公式为什么「通吃」：

- **第一步，看求和起点**：下标从 $k = t+1$ 开始，第一个加进去的是 $R_{t+1}$——即「从 $S_t$ 出发执行动作后」的第一笔奖励，与 $G_t$ 的直觉「从当下往后累积」完全吻合。
- **第二步，看权重**：第 $k$ 项 $R_k$ 的权重是 $\gamma^{k-t-1}$。它到 $t$ 的间隔是 $k - t$，权重里的指数却要再减 $1$——因为第一项（$k = t+1$）的权重是 $\gamma^{0} = 1$，即当下邻近的奖励不打折。逐项展开就是上一节的 $G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots$。
- **第三步，看 $T$ 的两个取值**：回合式任务里，$S_T$ 之后全是吸收状态、奖励恒为 $0$，所以把和截断在 $T$ 与延长到无穷结果一致；持续性任务里没有终止，直接把 $T$ 设成 $\infty$，让这条公式自动退化成无穷折扣和。**一条公式，两个设定，两类任务全覆盖。**

为什么「$T = \infty$ 与 $\gamma = 1$ 不能同时成立」这条约束会浮出水面？因为当 $T = \infty$ 且 $\gamma = 1$ 时，求和 $\sum_{k} R_k$ 是「无穷项、不打折」的无限和，在一般有界奖励下可能没有有限值。回合式任务能安全地用 $\gamma = 1$，靠的正是「$T$ 有限」这个前提。**统一不是免费午餐：它用「吸收状态」把回合式并入持续性，同时用「排他约束」把不收敛的角落剔了出去。**

**辨析｜易错点：终止状态 $S_T$ 到底是「状态的最后一个」还是「结束后的第一个」？** 不同教材口径不一，务必认准这本书的约定：回合在**时刻 $T$** 结束，$S_T$ 是终止状态本身，$G_T = 0$，之后不存在动作 $A_T$；$R_T$ 是「走进 $S_T$」那一刻的奖励，是回合的最后一笔收入。代码实现里，这个「$T$ 到底指哪里」的偏差，会导致目标值偏一位（off-by-one）——经典的调试陷阱，记住 $R_{t+1}$ 对齐「到达的状态」就不会错。

## 5 一个例子：统一记号如何同时算两类任务

把两个看似不相关的任务并排放在一起看。**任务甲（回合式）**：一局井字棋，最多 $T = 9$ 手见分晓，终局 $+1$（赢）或 $-1$（输），可令 $\gamma = 1$。**任务乙（持续性）**：昼夜不歇的室温控制器，没有「终局」，每步的电费以负奖励计入，$T = \infty$，取 $\gamma = 0.95$。

两个任务的回报都用同一条公式 $G_t = \sum_{k=t+1}^{T} \gamma^{k-t-1} R_k$：甲取有限 $T$、$\gamma = 1$；乙取 $T = \infty$、$\gamma = 0.95$。**同一个函数、同一段代码，两类任务都能算**——这正是统一记号的工程回报。

| | 井字棋（回合式） | 室温控制（持续性） |
| --- | --- | --- |
| 地平线 $T$ | $9$（有限） | $\infty$ |
| 折扣 $\gamma$ | $1$ | $0.95$ |
| 终止状态 | 有（吸收态） | 无 |
| 统一公式 | ✓ | ✓ |

这种「不分任务类型」的红利会在后面每一章兑现：学到第四篇的动态规划、第六篇的时序差分时你会看到，**所有的更新公式都以 $G_t$（或它的一步展开）为原料，而 $G_t$ 已经与任务类型无关**——统一记号把「回合式还是持续性」这层复杂性提前消化在了第3章，算法层从此可以只写一遍。

## 6 小结

- **两类任务**：回合式（有限 $T$、可用 $\gamma = 1$）与持续性（$T = \infty$、必须 $\gamma < 1$），差别只有地平线。
- **吸收状态 $S_+$**：自环、奖励恒为 $0$，把「结束」变成「永远停在原地」，回合式任务由此并入持续性框架。
- **统一公式**：$G_t = \sum_{k=t+1}^{T} \gamma^{k-t-1} R_k$，回合式取有限 $T$，持续性取 $T = \infty$；首项权重 $\gamma^0 = 1$。
- **记号约定**：$S_{t,i}$ 简写为 $S_t$；奖励 $R_t$ 对齐「到达的状态」$S_t$，轨迹为 $S_0, A_0, R_1, S_1, A_1, R_2, \ldots$。
- **排他约束**：$T = \infty$ 与 $\gamma = 1$ 不同时成立，否则无限无折扣和可能发散。

在下一节，我们把回报——这条轨迹上的随机变量——放进期望里，得到**价值函数**；再对回报的递归恒等式取期望，得到价值函数必须满足的**贝尔曼方程**。记号已经铺平，接下来是本书真正的第一道主菜。
