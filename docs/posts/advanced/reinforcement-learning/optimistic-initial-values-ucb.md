## 为什么从「把不确定性当朋友」开始

上一节的 ε-贪心用「固定概率 ε 乱试」守住探索。它简单、稳健，但有个明显的浪费：**探索是「无差别」的**——好动作和坏动作被随机试探的概率一样大。可直觉告诉我们，探索应该「有针对性」：一个被试过 100 次、估计很准的动作，没必要再乱试；而一个从没试过的动作，才值得优先去看看。

这一节的两个方法都把这条直觉变成算法。第一个办法近乎「作弊」：**乐观初始值**——干脆让算法一开始就以为每个动作都很棒，逼着它挨个去验证。第二个办法更「科学」：**置信度上界（UCB）**——把「不确定性」本身算成一条加分项，加到价值估计上，再按加完分的大小做选择。它们共享同一个世界观：**未知不是要被回避的风险，而是值得被收集的信息。**

这套思想会一路长成更庞大的东西：第八篇决策时规划的蒙特卡洛树搜索（MCTS）用的正是 UCB 的一个变体，AlphaGo 的前几手落子也由它驱动。<span class="marginnote">「乐观面对不确定性」（optimism in the face of uncertainty）是 RL 里反复出现的元原则：第八章的探索性奖励、第九章的乐观价值函数初始化，都是同一句哲学的化身。你会在后续很多算法里再次认出它的面孔。</span>

## 1 乐观初始值：给未知一个「偏高」的起点

回忆上一节的增量式更新：

$$Q_{n+1} = Q_n + \alpha(R_n - Q_n)$$

它的初始条件 $Q_1(a)$ 一直没被讨论。默认设 0 很自然，但如果我们**故意把初值设得很大**——比如真值服从 $\mathcal{N}(0,1)$，却把所有 $Q_1(a)$ 设成 $+5$——会发生什么？

- 一开始，每个动作的估计值都是 $+5$，「看起来都是最优」。贪心策略（甚至 ε 可以设为 0）会**逐个尝试所有动作**。
- 一旦某个动作被尝试，估计值就被真实奖励拉低；表现差的动作估计值迅速跌落，之后被选中的次数越来越少。
- 最终，好的动作被「验证」了出来——而这一切**不需要任何显式的随机探索**。

**重点：乐观初始值把「探索」伪装成了「利用」。** 算法自以为在选最优动作，实际上因为所有初值都虚高，它被迫把每个动作都验证一遍——探索不是靠随机数，而是靠「程序化的乐观」驱动。Sutton & Barto 的 10 臂测试台显示，把 $\varepsilon$ 设为 0 的贪心算法配上 $+5$ 的乐观初值，探索效果竟然能和 $\varepsilon = 0.1$ 的 ε-贪心媲美。<span class="marginnote">注意：这个技巧的前提是问题<strong>平稳</strong>。在非平稳环境里，探索的需求是持续存在的，乐观初值只在前几步起作用——「初值的乐观」是一次性的，用完就没了。</span>

**辨析｜易错点：乐观偏差是「永久」还是「暂时」？** 这取决于步长。若用样本平均（$\alpha = 1/n$），每个动作被访问过一次后，乐观偏差就彻底消失——初值只影响「先试谁」的顺序；若用常数 $\alpha$（如 0.1），偏差会随更新**指数衰减但永不归零**——初值的影子一直留在估计里。乐观初始值是有意的「永久乐观」，这正是它与「估计不准」的区别：**它把偏差当作探索的燃料，而不是需要消除的误差。**

### 一个手算：乐观初值如何逼出探索

设两台老虎机，真值 $q_*(1) = 0.2$、$q_*(2) = 0.8$。我们故意把初始估计都设成乐观值 $Q_1(1) = Q_1(2) = 5$，用常数步长 $\alpha = 0.1$ 更新 $Q \leftarrow Q + \alpha(R - Q)$。逐步追踪：

| 时刻 $t$ | 选的动作 | 奖励 $R$ | 更新后 $Q(1)$ | 更新后 $Q(2)$ |
| --- | --- | --- | --- | --- |
| 1 | 1（两个都虚高，随机） | 0 | $5 + 0.1(0-5) = 4.5$ | 5 |
| 2 | 2（仍是最大） | 1 | 4.5 | $5 + 0.1(1-5) = 4.6$ |
| 3 | 2（仍最大） | 0 | 4.5 | $4.6 + 0.1(0-4.6) = 4.14$ |
| 4 | 2（仍最大） | 1 | 4.5 | $4.14 + 0.1(1-4.14) = 3.83$ |

头几步两个动作都被试过——因为初值虚高，**没有一个动作「看起来不值得试」**。随着更新，臂 2 的估计被真实奖励（围绕 0.8）拉低，而臂 1 因为「运气不好」先被拉到了 4.5，还会继续被选中若干次，直到它的估计也跌下来。最终两个估计都向真值收敛，但**探索已经在那之前自动完成了**——这就是乐观初值「不设 ε 也能探索」的机理。

## 2 UCB：把不确定性翻译成加分项

乐观初始值的缺点是它只「在开头」工作。UCB 则把不确定性**持续地**编码进选择，每一时刻都问：哪个动作最可能其实是最优的？

**UCB 动作选择（upper-confidence-bound action selection）**：不再选估计值最大的动作，而是选「估计值 + 不确定性加分」最大的动作：

$$A_t \doteq \underset{a}{\arg\max} \left[ Q_t(a) + c \sqrt{\frac{\ln t}{N_t(a)}} \right]$$

其中：

- $t$ 是当前的步数（总选择次数）；
- $N_t(a)$ 是到时刻 $t$ 为止动作 $a$ 被选过的次数；
- $\ln t$ 是自然对数；
- $c > 0$ 是控制探索强度的参数；
- 分母为零（动作 $a$ 从未被选过）时，规定该动作直接视为最大化动作——保证每个动作都被尝试一遍。

**重点：平方根项是一个「不确定性红利」。** 动作被试得越少（$N_t(a)$ 越小），红利越大；被试得越多，红利越小。而 $\ln t$ 虽然随 $t$ 增长，却增长得极其缓慢——它的作用是给「被冷落的动作」缓慢地累积怀疑：每当你选择了其他动作，$t$ 增加而 $N_t(a)$ 不变，这个动作的不确定性就悄悄变大一点。于是所有动作最终都会被无限次尝试，但好动作被选得越来越频繁。<span class="marginnote">$\ln t$ 只是「增长缓慢且无界」的函数的一个选择。换成 $\sqrt{t}$ 也可以，但增长越快，探索越分散；对数增长保证探索「前期集中、后期收敛」——这是 UCB 遗憾界能压低的关键。</span>

## 3 公式解析：UCB 的置信上界从哪来

为什么平方根项正好长成 $c\sqrt{\ln t / N_t(a)}$？这背后是一条概率论不等式——**集中不等式（concentration inequality）**。

先给出直觉：设 $q_*(a)$ 是动作 $a$ 的真实期望，$Q_t(a)$ 是它的样本均值。样本量越大，$Q_t(a)$ 离 $q_*(a)$ 越近；但「有多近」要用概率语言说。Hoeffding 型的集中不等式告诉我们，对任意 $\delta > 0$：

$$\Pr\left\{ \left| Q_t(a) - q_*(a) \right| \geq \delta \right\} \leq 2 \exp\left(-2\, N_t(a)\, \delta^2\right)$$

偏离超过 $\delta$ 的概率，随 $N_t(a)$ 的增大指数式衰减。现在做三步拆解：

- **第一步，反解出「置信半径」**：想让「偏差超过半径」的概率随 $t$ 衰减（约 $\le 1/t$），令 $2\exp(-2N\delta^2) \approx 1/t$，解得 $\delta = \sqrt{\ln t / (2N)}$。取 $c$ 吸收常数，半径就是 $c\sqrt{\ln t / N_t(a)}$——**这个半径随样本量 $N$ 增大而收缩，随拖久了的 $t$ 增大而扩张**，两个方向都合理。
- **第二步，构造「上界」**：既然真值以高概率落在 $Q_t(a) \pm \text{半径}$ 之内，那么 $Q_t(a) + \text{半径}$ 就是真值的「高概率上界」——这就是 **upper confidence bound** 名字的来历：一个对真值的乐观估计，把不确定性变成了容错余量。
- **第三步，按上界选动作**：选「上界最大」的动作，等于在说——「如果真值恰如其分地高，哪个动作最划算？」这是一种**对未来最有利可能性的下注**，与「按当前估计值选」的利用、与「随机乱试」的探索都不同，它把两者折进同一个式子。

**辨析｜易错点：UCB 不做分布假设，但要精确计数。** UCB 不需要知道奖励服从什么分布，只需要 $N_t(a)$（计数）和 $Q_t(a)$（均值）。代价是它必须**为每个动作维护这两个量**——这在表格型老虎机里轻而易举，但动作空间一旦巨大、或者价值估计由函数逼近给出，逐动作的计数就做不到了。这正是深度 RL 里 UCB 难以直接上阵的原因，也是后续方法（如探索奖励、熵正则）要另想办法的动机。

## 4 UCB 的边界与「乐观」的哲学

UCB 在老虎机里通常碾压 ε-贪心：它把「探索多少」从一个拍脑袋的超参数 $\varepsilon$，变成了有理论依据的量（遗憾界可以做到 $O(K\ln T)$ 量级）。但它有两个明确的边界：

- **非平稳问题**：$\ln t$ 与 $N_t(a)$ 是「从零累积」的计数器，隐含假设「历史数据越多越好」。环境一旦漂移，累积计数反而会拖累决策——这与上一节「常数 $\alpha$ 才适合非平稳」的结论一致。
- **不可分解的规模**：需要逐动作维护 $Q$ 与 $N$，遇到连续或组合爆炸的动作空间就失效。

但把这两个「不行」放一边，UCB 留下的哲学遗产影响深远：**面对未知，与其回避，不如把它折算成「可能的上限」去下注。** 这条原则在本书的蒙特卡洛树搜索（第八篇）、以及在多臂老虎机理论（bandit theory）的整个后续发展中，都是主角。<span class="marginnote">老虎机研究的「遗憾界」思路会渗透到在线学习与推荐系统：一个算法的好坏，用「与全知最优相比少拿了多少」来度量——这也是理解「探索投入该花多少」的最干净框架。</span>

### 代码实现：一个 UCB 老虎机

把上面所有思想合成一段可运行的 Python。UCB 的核心就两行：维护计数 $N$ 与均值 $Q$，选择时按上界打分：

```python
class UCB:
    def __init__(self, k, c=2.0):
        self.k = k
        self.c = c                # 探索系数：置 0 退化为纯贪心
        self.Q = [0.0] * k        # 每个动作的平均奖励估计
        self.N = [0] * k          # 每个动作被选择的次数
        self.t = 0                # 总步数

    def select(self):
        self.t += 1
        ucb = [q + self.c * (np.log(self.t) / (n + 1e-9)) ** 0.5
               for q, n in zip(self.Q, self.N)]
        return argmax(ucb)        # 按「估计值 + 不确定性红利」选动作

    def update(self, a, r):
        self.N[a] += 1
        self.Q[a] += (r - self.Q[a]) / self.N[a]   # 样本平均（α = 1/N）
```

与上一节的 ε-贪心类对照着看：**UCB 类**里那行上界公式 $Q_t(a) + c\sqrt{\ln t / N_t(a)}$ 就是「不确定性红利」，它取代了「随机乱试」；把 **$c$** 设成 0，UCB 退化成纯贪心。**这个类几乎可以直接平移到第八篇的蒙特卡洛树搜索里——那里用的 UCB 只是把「动作计数」换成了「节点访问计数」。**<span class="marginnote">注意这里用的是样本平均（$\alpha = 1/N$）而非常数步长——与 ε-贪心不同，UCB 的经典形式假定平稳问题，用递减步长换取「最终精确收敛」。</span>

## 5 小结

- **乐观初始值**：把 $Q_1(a)$ 设得虚高，逼贪心算法逐个验证所有动作；省掉了显式随机探索。仅对平稳问题有效。
- **步长决定乐观的寿命**：样本平均下一次访问即消除偏差，常数 $\alpha$ 下偏差指数衰减但永不归零。
- **UCB 选择**：$A_t = \arg\max_a \left[ Q_t(a) + c\sqrt{\ln t / N_t(a)} \right]$，在估计值上加「不确定性红利」。
- **红利的两半**：$N_t(a)$ 越小红利越大（试得少→值得试），$\ln t$ 缓慢增长（拖得久→怀疑累积），两者合力保证所有动作最终都被无限次尝试。
- **来源**：平方根项来自集中不等式——真值以高概率落在均值 ± 半径内，$Q_t(a)+$半径即「置信上界」。
- **局限**：需要逐动作精确计数，难以推广到非平稳与大规模动作空间；但「乐观面对未知」的原则在 MCTS 与探索奖励中延续。

在下一节，我们把视角从「估计价值」转向「直接学偏好」：不再问「动作值多少钱」，而是问「该给每个动作多高的权重」——这就是**梯度老虎机算法**，一条通往第十三篇策略梯度定理的小路。
