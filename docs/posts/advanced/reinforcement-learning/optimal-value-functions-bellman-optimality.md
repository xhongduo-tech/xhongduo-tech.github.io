# 最优价值函数、贝尔曼最优方程与最优策略

<div class="epigraph">

## 为什么从「最优」开始

上一节我们定义了价值函数与贝尔曼方程：给定一个策略 $\pi$，就能算出每个状态的价值 $v_\pi(s)$。但强化学习的目标不是「评估一个策略」，而是**找到一个最优策略**——在所有可能的行动手册里，挑出最值得信赖的那一本。这一节把「最好」三个字变成精确的数学对象，并给出最优策略必须满足的方程：**贝尔曼最优方程（Bellman optimality equation）**。

这一节是整个第3章的高潮，也是全书的一个战略拐点：**贝尔曼方程是「描述」——给定策略，价值是什么；贝尔曼最优方程是「求解」——最优价值长什么样。** 前者线性、好解；后者非线性、难解，但它指明了「最优」这个靶心。第四篇的动态规划，做的就是「朝靶心迭代」。读懂了这一节，你就握住了从「理解 RL」到「设计 RL 算法」的钥匙。

## 1 策略的偏序：什么算「更好」

先解决一个看起来像废话的问题：**两个策略，凭什么说一个比另一个好？** 直觉是「哪个赢得多哪个好」，但赢是随机的，得先定义「多」指什么。

Sutton & Barto 用价值函数定义了一种**偏序（partial order）**：

**策略 $\pi \geq \pi'$，当且仅当对所有的状态 $s$，都有 $v_\pi(s) \geq v_{\pi'}(s)$。** 也就是说：**一个策略「处处不劣于」另一个，才算「更好」——它必须在每个状态下的期望回报都不输给对方。**

这个定义看似严苛，却恰好避开了「两个策略在不同状态上各有胜负」的纠结：RL 的优化目标要求一个策略「全局不输」，而不是「某个状态很猛、另一些状态很菜」。对有限 MDP，Sutton & Barto 给出了一个漂亮的结论：

**重点：对任意有限 MDP，至少存在一个最优策略 $\pi_*$，它对所有状态都「不劣于」任何其他策略。** 换句话说，偏序里存在「最高点」——最优策略不是可望不可及的理想，而是确定存在、只是还没找到的东西。寻找它，就是第3章之后全部内容的任务。<span class="marginnote">「有限状态 + 有限动作」是这条存在性定理的前提。一旦状态空间变成连续（第九篇函数逼近），「最优策略存在」就不再自动成立，只能退而求其次找「尽量好」——这是深度 RL 里各种近似技巧的思想根源。</span>

## 2 最优价值函数：把「最好」标在图上

有了最优策略，最优价值函数就顺理成章了。**最优状态价值函数（optimal state-value function）**：在所有策略里取最大的那个期望回报

$$v_*(s) \doteq \max_{\pi} v_\pi(s), \qquad \forall s \in \mathcal{S}$$

**最优动作价值函数（optimal action-value function）** 同理，把「策略可变」放进条件里：

$$q_*(s, a) \doteq \max_{\pi} q_\pi(s, a), \qquad \forall s \in \mathcal{S},\ a \in \mathcal{A}$$

两个最优价值函数之间有一条极其好用的关系：

$$v_*(s) = \max_{a \in \mathcal{A}(s)} q_*(s, a)$$

**在最优状态下，状态的价值就等于「最好的那个动作」的价值。** 这不是巧合，而是「最优策略会选最好的动作」的直接翻译：$v_*$ 是站在状态 $s$ 的终极收益，$q_*$ 是「先做 $a$ 再做到最好」的终极收益，两者之差就是「动作选得好不好」——最好自然是 $0$。

这里浮现出一个关于「知道多少才够」的洞见。**如果你知道 $q_*$，做决策不需要任何模型**：直接在每个状态挑 $q_*(s, a)$ 最大的动作即可，环境会替你兑现后续。**如果你只知道 $v_*$，则需要模型做一步搜索**：对每个候选动作 $a$，用 $p(s', r \mid s, a)$ 算出「$r + \gamma v_*(s')$ 的期望」，再挑最大的。前者是「无模型」的底气，后者是「基于模型」的起点——这个差别在后面第八、九篇会反复出场。<span class="marginnote">这也解释了为什么动作价值 $q_*$ 在算法里比状态价值 $v_*$ 更「吃香」：Q-learning、DQN 学的是 $q$，因为 $q$ 直接给出动作排序，免去模型搜索。第3章的这一句关系，是深度 RL 遍地是「Q」的原因。</span>

## 3 贝尔曼最优方程：把「最优」写进递归

上一节的价值函数满足贝尔曼方程；最优价值函数也不例外，只是方程里的「按策略加权平均」被替换成了「取最大」。**贝尔曼最优方程**把「站在最优状态的价值」递归地定义为「选最好的动作后，一步奖励 + 折现的最优未来」：

$$v_*(s) = \max_{a} \sum_{s', r} p(s', r \mid s, a)\left[ r + \gamma\, v_*(s') \right]$$

动作价值版本则把「取最大」挪到了内层（因为动作 $a$ 已被条件钉死，下一步才要选最优动作）：

$$q_*(s, a) = \sum_{s', r} p(s', r \mid s, a)\left[ r + \gamma \max_{a'} q_*(s', a') \right]$$

对照上一节的贝尔曼方程，唯一的区别就是：**对固定的 $\pi$，方程里的 $\sum_a \pi(a \mid s)$ 是「平均」；对最优，$\max_a$ 是「挑最好」。** 这个「平均 → 最大」的替换，就是「从评估到求解」的全部数学代价——也是麻烦的根源（见第4节）。

**重点：贝尔曼最优方程没有显式出现任何策略，它只关于 $v_*$ 与 $q_*$ 本身。** 它是一组独立的方程，解出来直接就是最优价值，不需要先指定策略。换句话说，**「找最优策略」和「解这组方程」是同一件事。**

## 4 公式解析：贝尔曼最优方程的逐步推导

最优方程不是新发明的公式，而是「最优策略 + 贝尔曼方程」的必然推论。四步推导，看清「最大」是怎么进来的：

- **第一步，选定一个最优策略**：设 $\pi_*$ 是最优策略之一。它当然也满足贝尔曼方程，且 $v_{\pi_*}(s) = v_*(s)$：

$$v_*(s) = \sum_{a} \pi_*(a \mid s) \sum_{s', r} p(s', r \mid s, a)\left[ r + \gamma\, v_*(s') \right]$$

- **第二步，认出「最优策略在 $s$ 上只押注最好的动作」**：因为 $\pi_*$ 是贪心的，它在状态 $s$ 只选 $q_*(s, a)$ 最大的动作（其余动作概率为 $0$），所以「按 $\pi_*$ 加权平均」坍缩成「取最大」：

$$\sum_{a} \pi_*(a \mid s)\, q_*(s, a) = \max_{a} q_*(s, a)$$

- **第三步，把 $q_*$ 展开**：$q_*(s, a)$ 满足它自己的递归——一步奖励加折现的最优未来：

$$q_*(s, a) = \sum_{s', r} p(s', r \mid s, a)\left[ r + \gamma\, v_*(s') \right]$$

- **第四步，合并**：把第三步代回第二步的右边，得到

$$v_*(s) = \max_{a} \sum_{s', r} p(s', r \mid s, a)\left[ r + \gamma\, v_*(s') \right]$$

——**贝尔曼最优方程原样浮现。** 这条推导的「杠杆点」在第二步：贪心策略让「概率加权」退化成「最大值」，这正是第3章「最优」二字全部的数学含义。

反过来，方程的**反方向**同样重要：**如果已知 $v_*$，任何在每一步都选择「使 $\sum_{s',r} p(s',r\mid s,a)[r + \gamma v_*(s')]$ 最大」的动作的贪心策略，都是最优策略。** 最优方程的解自动「兑现」出最优策略——这就是为什么解出 $v_*$（或 $q_*$）就等价于找到最优行为。

**辨析｜易错点：$\max$ 与 $\arg\max$，以及「对 $v_*$ 贪心」与「对 $v_\pi$ 贪心」，是两对必须分清的概念。** 贝尔曼最优方程里出现的是 $\max$（最大的那个值，方程的解）；而构造最优策略用的是 $\arg\max$（取到最大的那个动作）。更微妙的是：**对任意非最优策略 $\pi$ 的价值 $v_\pi$ 做贪心选择，得到的策略会「改进」但不一定最优**（这是第四篇「策略改进定理」的预告）；只有对 $v_*$ 做贪心，才一步到位得到最优策略。把这两对概念混在一起，是学完第3章最常见的认知事故。

用一个两状态小例把这些关系钉死。设状态集 $\{s_1, s_2\}$，每状态两个动作 $a, b$，折扣 $\gamma = 0.9$；假设经过某种手段我们已经算出了最优动作价值：$q_*(s_1, a) = 3.0$、$q_*(s_1, b) = 1.5$、$q_*(s_2, a) = 2.0$、$q_*(s_2, b) = 2.5$。则由 $v_*(s) = \max_a q_*(s, a)$：

$$v_*(s_1) = \max(3.0, 1.5) = 3.0, \qquad v_*(s_2) = \max(2.0, 2.5) = 2.5$$

最优策略在 $s_1$ 选 $a$、在 $s_2$ 选 $b$——它正是逐状态取 $\arg\max$ 的贪心策略。注意看：**最优策略不是「某个全局动作」，而是「每个状态各选各的最好」**。这恰好与第1节「偏序要求处处不劣」的定义咬合：最优不是赢在某一处，而是处处都不输。

## 5 为什么最优方程「能写不能解」

贝尔曼最优方程简洁、漂亮、非策略——但它有个致命的问题：**它几乎从来不能直接解出来。** 原因有三层：

- **非线性**：$\max$ 运算符破坏了线性。普通贝尔曼方程是 $v$ 的线性方程组（有闭式求解法）；一旦换成 $\max$，未知量 $v_*$ 以「最大值的参数」身份出现，方程变成非线性、分段结构，没有解析解。
- **三重穷举**：即使数值求解，也要面对「所有状态 × 所有动作 × 所有后继」的三重组合。状态一多（围棋的 $10^{170}$ 种局面），直接求解彻底不可能。
- **模型未必可得**：方程需要 $p(s', r \mid s, a)$ 全程在手，而现实问题（机器人、对话、游戏对手）往往没有精确模型。

不过有一点值得先说清楚，免得误以为「不能直接解」等于「没有唯一答案」：**贝尔曼最优方程在 $\gamma < 1$ 或「任何策略下都能保证终止」的条件下，有且仅有一个解 $v_*$。**「唯一」是「定靶」能成立的前提——如果解不唯一，算法就不知道该收敛到哪里去。真正的问题不是「解不存在」，而是「解没有闭式表达式、只能靠迭代逼近」。第四篇的动态规划、第六篇的 Q-learning，都在用不同的迭代格式逼近这同一个唯一解，殊途同归。

**重点：贝尔曼最优方程的真正价值不是「用来解」，而是「用来定靶」。** 它告诉我们最优价值长什么样、最优策略必须满足什么条件，从而为所有近似算法（动态规划、蒙特卡洛、时序差分、Q-learning、深度 RL）提供了统一的「收敛目的地」。第四篇的动态规划正是这条路的第一步：不直接解非线性方程，而是反复套用贝尔曼（最优）方程做迭代，让价值估计一步步逼近 $v_*$。<span class="marginnote">这种「写得出、解不了、只能逼近」的处境，在数学里一点都不陌生：第一级学过的「$x = \cos x$ 这样的不动点方程」、第二级《数值分析》里的牛顿迭代，都是同一套路——方程本身给出迭代格式，收敛性由条件保证。RL 的价值迭代与它们同源。</span>

## 6 小结

- **策略偏序**：$\pi \geq \pi' \iff v_\pi(s) \geq v_{\pi'}(s)\ \forall s$；有限 MDP 至少存在一个最优策略 $\pi_*$。
- **最优价值函数**：$v_*(s) = \max_\pi v_\pi(s)$、$q_*(s, a) = \max_\pi q_\pi(s, a)$，且 $v_*(s) = \max_a q_*(s, a)$；知道 $q_*$ 可无模型贪心，只知道 $v_*$ 需模型一步搜索。
- **贝尔曼最优方程**：$v_*(s) = \max_a \sum_{s',r} p(s',r\mid s,a)[r + \gamma v_*(s')]$；与普通贝尔曼方程的唯一差别是「平均 $\to$ 最大」。
- **推导路径**：最优策略满足贝尔曼方程 + 贪心使概率加权坍缩为 $\max$ + $q_*$ 递归展开 → 最优方程。
- **能写不能解**：$\max$ 带来非线性，三重穷举与模型依赖让它无法直接求解；它的角色是「定靶」，逼近它的迭代算法从第四篇动态规划开始。
- **易错点**：$\max$（解）与 $\arg\max$（动作）别混；对 $v_\pi$ 贪心只保证改进，对 $v_*$ 贪心才保证最优。

在下一节，我们终于要动手求解了——第四篇《动态规划》的第一课：**策略评估**。既然最优方程难解，就先用贝尔曼方程把「给定策略的价值」算准，再一步步改进策略，朝最优价值那面靶心爬上去。
