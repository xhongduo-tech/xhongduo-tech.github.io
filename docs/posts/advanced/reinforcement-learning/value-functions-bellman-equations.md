## 为什么从「价值函数」开始

前面两节我们备齐了原料：动态函数 $p(s', r \mid s, a)$ 描述世界怎么变，回报 $G_t$ 与递归恒等式 $G_t = R_{t+1} + \gamma G_{t+1}$ 描述「一条轨迹上能拿多少」。但智能体做决策时并不知道自己会走哪条轨迹——未来是随机的。于是它需要一个更稳的量：**把「未来能拿多少」的期望**算出来，作为「此刻站在这个状态有多好」的判断。这个量就是**价值函数**。

价值函数是全书出现频率最高的角色。动态规划、蒙特卡洛、时序差分（TD）、Q-learning——几乎所有经典算法都在回答同一个问题：**如何估计 $v_\pi(s)$ 或 $q_\pi(s, a)$。** 而价值函数之所以可以被估计，全因为一条结构性的等式——**贝尔曼方程（Bellman equation）**。它把「一个状态的价值」写成「下一状态价值的函数」，让「无限长未来」变成「一步递归」。今天这一节，就是给全书的心脏做开胸手术。

## 1 策略与价值函数：把回报放进期望

先补上上一节欠下的定义。**策略（policy）$\pi$**：从状态到「选动作概率」的映射，$\pi(a \mid s)$ 表示在状态 $s$ 下选动作 $a$ 的概率——它是智能体的行动手册，也是我们最终要学习的东西。

在策略 $\pi$ 的控制下，从状态 $s$ 出发的期望回报，定义**状态价值函数（state-value function）**：

$$v_\pi(s) \doteq \mathbb{E}_\pi\left[G_t \mid S_t = s\right] = \mathbb{E}_\pi\left[\sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \;\middle|\; S_t = s\right]$$

读作：**「站在状态 $s$，如果从此以后都按策略 $\pi$ 行动，平均能拿多少折扣回报。」** 注意两个关键词：

- **条件 $S_t = s$**：价值是「关于状态」的函数——状态不同，期望回报不同。下棋时「将军死局」与「大优局面」的价值天差地别。
- **下标 $\pi$**：期望是在「策略 $\pi$ 生成的随机轨迹」上取的。换个策略，同一状态的价值就变了——这正是「策略决定价值」的数学形式。

**重点：价值是策略的函数，不是环境的函数。** 同一张棋盘，莽撞棋手看到的价值与国手看到的价值完全不同。后面几乎所有算法的目标，都可以概括为一句话：**找一个好策略，让每个状态的价值都尽可能高。**

与状态价值孪生的是**动作价值函数（action-value function）**：

$$q_\pi(s, a) \doteq \mathbb{E}_\pi\left[G_t \mid S_t = s, A_t = a\right]$$

区别只有条件的最后一位：`在 $s$ 上**先执行动作 $a$**，之后再按 $\pi$ 行动`。它回答的是「在 $s$ 上这个动作划不划算」——做决策最直接需要的正是它。两者由一条恒等式相连：

$$v_\pi(s) = \sum_{a} \pi(a \mid s)\, q_\pi(s, a)$$

**状态的价值，是它可能采取的各动作价值的「按策略加权平均」。** 策略把概率压在哪，状态的价值就被哪个动作主导。

## 2 贝尔曼方程：价值的递归结构

价值函数定义里那个无穷和，看起来没法算。但上一节的递归恒等式 $G_t = R_{t+1} + \gamma G_{t+1}$ 给了我们一把钥匙：把 $G_t$ 换成 $R_{t+1} + \gamma G_{t+1}$，再对两边取期望——无穷和就会坍缩成「一步奖励 + 下一状态的价值」。

$$v_\pi(s) = \sum_{a} \pi(a \mid s) \sum_{s', r} p(s', r \mid s, a)\left[ r + \gamma\, v_\pi(s') \right]$$

这就是状态价值函数的**贝尔曼方程（Bellman equation）**。它说的是一句大白话：**状态 $s$ 的价值 = 「这一下的平均奖励」+「折现后的、下一状态的平均价值」。**

**重点：贝尔曼方程把一个状态的价值，写成了它全部可能后继状态价值的加权和。** 未来的链条无限长，但方程只往前看一步——因为下一步的状态价值 $v_\pi(s')$ 自己又满足同样的方程，递归会自动「接力」下去。这就是「动态规划」四个字里「动态」二字的由来：问题被分解成同构的子问题，一环扣一环。

![状态价值函数的回溯图](/images/reinforcement-learning/value-functions-bellman-equations-1.svg)

回溯图（backup diagram）从状态 $s$ 出发：先按策略 $\pi$ 分支到各动作 $a$（空心节点），再从每个动作按动态 $p$ 分支到各后继状态 $s'$ 与奖励 $r$（实心节点）。**价值的信号从树叶沿树根向上「回传」**：每个 $s'$ 带一个 $v_\pi(s')$，按概率加权，一路乘上 $\gamma$，最终汇聚成 $v_\pi(s)$。<span class="marginnote">这张图里藏着一个贯穿全书的「信条」：把价值的计算画成一棵向后看的树。蒙特卡洛画完整的树（一路走到叶子、不回头），TD 只画一步就回头（第六篇），n 步自举画 n 步（第七篇）——三大家族算法全在这棵树上做「走多深」的取舍。</span>

## 3 动作价值函数的贝尔曼方程

同样的递归结构也适用于 $q_\pi$。动作 $a$ 在状态 $s$ 的价值，等于「这一步拿到的平均奖励 + 折现后的、下一状态按策略加权的动作价值」：

$$q_\pi(s, a) = \sum_{s', r} p(s', r \mid s, a)\left[ r + \gamma \sum_{a'} \pi(a' \mid s')\, q_\pi(s', a') \right]$$

对照两条方程，结构一模一样，只是求和的对象不同：$v_\pi$ 的方程里多了一层「按 $\pi$ 对动作加权」（因为策略负责选动作），$q_\pi$ 的方程里没有外层动作求和（因为动作 $a$ 已经被条件钉死了）。<span class="marginnote">一个记忆技巧：把 $v_\pi$ 的方程看作「$q_\pi$ 方程外面再套一层 $\sum_a \pi(a|s)$」——两个方程互为对方的展开。写程序时你会惊讶于这两条式子能互相推来推去、永不卡壳。</span>

## 4 公式解析：从回报恒等式到贝尔曼方程

把「取期望」这一下做扎实，贝尔曼方程就「长」出来了。我们顺着三步推一遍 $v_\pi$：

- **第一步，代入递归恒等式**：把定义里的 $G_t$ 换成 $R_{t+1} + \gamma G_{t+1}$：

$$v_\pi(s) = \mathbb{E}_\pi\left[R_{t+1} + \gamma G_{t+1} \mid S_t = s\right]$$

期望是线性的，和的期望等于期望的和，于是拆成两块：

$$v_\pi(s) = \mathbb{E}_\pi\left[R_{t+1} \mid S_t = s\right] + \gamma\, \mathbb{E}_\pi\left[G_{t+1} \mid S_t = s\right]$$

- **第二步，分别处理两块**。第一块「这一步的平均奖励」：先按策略选动作，再按动态取（$s', r$）的联合期望：

$$\mathbb{E}_\pi\left[R_{t+1} \mid S_t = s\right] = \sum_a \pi(a \mid s) \sum_{s', r} p(s', r \mid s, a)\, r$$

第二块「折现后的未来」：$G_{t+1}$ 依赖的是下一状态 $S_{t+1}$，把它拆成「先到哪个 $s'$、再从 $s'$ 往后看」。由条件期望的塔性质，条件 $S_t = s$ 下到达 $s'$ 的「概率 × 从 $s'$ 起的期望」再求和：

$$\mathbb{E}_\pi\left[G_{t+1} \mid S_t = s\right] = \sum_a \pi(a \mid s) \sum_{s'} p(s' \mid s, a)\; v_\pi(s')$$

其中 $p(s' \mid s, a) = \sum_r p(s', r \mid s, a)$，而 $v_\pi(s')$ 的定义恰好就是「从 $s'$ 起按 $\pi$ 的期望回报」——定义被原样用上。

- **第三步，合回一块**：两块都带着 $\sum_a \pi(a|s)$，把它们并进同一个双重求和，注意 $p(s' \mid s, a) = \sum_r p(s', r \mid s, a)$，于是

$$v_\pi(s) = \sum_a \pi(a \mid s) \sum_{s', r} p(s', r \mid s, a)\left[ r + \gamma v_\pi(s') \right]$$

——**贝尔曼方程原样浮现。** 这一步最值得咂摸的是第二步的「塔性质」：未来价值不用你一路算下去，只需「到达下一状态、再用 $v_\pi(s')$ 接力」。这正是第三级《概率论与数理统计》里条件期望性质的直接应用，也是全书所有「自举（bootstrap）」算法的数学依据。

**辨析｜易错点：$v_\pi$ 与 $q_\pi$，别用混。** $v_\pi(s)$ 是「状态的价值」，隐含了「策略会替我挑动作」；$q_\pi(s, a)$ 是「(状态, 动作) 的价值」，把动作钉死、策略只负责之后。做选择要用 $q_\pi$（否则没法在动作间比较），做评估常用 $v_\pi$。还有一个经典误区：**对固定的 $\pi$，贝尔曼方程是 $v_\pi$ 的「线性」方程组**——未知量是各状态的价值，等式两边都是 $v$ 的一次式。线性方程组的求解理论（存在唯一解）保证：只要 $\gamma < 1$ 或任务能保证终止，$v_\pi$ 就有唯一解，这才让「迭代逼近」有意义（第四篇动态规划正是干这个的）。

## 5 价值函数的意义：从「一串奖励」到「一张地图」

有了价值函数，智能体手里就有了一张「地图」：每个状态标着一个数，代表「从这儿出发平均能拿多少」。这张地图让三个长期困扰的问题都有了落点：

- **延迟奖励**：某个动作当下没奖励，但它把智能体送进了高价值状态——价值函数会把这份功劳「追溯」回来（这就是信用分配问题，第六篇的 TD 算法正式接棒）。
- **决策**：在 $s$ 上该选哪个动作？看 $q_\pi(s, \cdot)$，挑价值最高的那个。
- **比较策略**：策略 $\pi$ 与 $\pi'$ 谁更好？比它们的价值函数——这正是下一节「最优策略」的入口。

在大模型时代，这张「地图」也有直接对应物：RLHF 里奖励模型输出的「这段话值几分」，本质上就是对「终局好坏的未来期望」做估计——语言模型的对齐训练，正踩在价值函数的延长线上（第十九篇会详述）。

## 6 小结

- **价值函数**：$v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$（状态价值）、$q_\pi(s, a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a]$（动作价值）；价值是策略的函数，$v_\pi(s) = \sum_a \pi(a \mid s) q_\pi(s, a)$。
- **贝尔曼方程**：$v_\pi(s) = \sum_a \pi(a \mid s) \sum_{s', r} p(s', r \mid s, a)\left[r + \gamma v_\pi(s')\right]$，把「一个状态的价值」递归成「后继状态价值的加权和」。
- **回溯图**：从 $s$ 经 $\pi$ 到 $a$、经 $p$ 到 $s'$ 的树形结构，价值信号自叶向根回传；MC、TD、n 步自举都是在这棵树上选「走多深」。
- **推导核心**：回报递归恒等式 + 期望线性 + 条件期望塔性质 → 贝尔曼方程；对固定 $\pi$ 它是线性方程组，$\gamma<1$ 或可终止保证唯一解。
- **易错点**：做选择看 $q_\pi$、做评估常用 $v_\pi$；$v_\pi$ 方程 = $q_\pi$ 方程外层套 $\sum_a \pi(a|s)$。

在下一节，我们把「在给定策略下评估价值」升级为终极问题：**在所有策略里挑最好的**——最优价值函数、贝尔曼最优方程与最优策略。价值地图画好了，下一节要找的是地图上的最高峰。
