## 为什么从贪心的失败开始

上一节我们看到了贪心选择的致命伤：一步坏运气就能把最优动作永远埋没。直观的补救是——**偶尔别听估计的，去乱试一把**。这就是 ε-贪心（ε-greedy）的全部思想：用一个小概率 ε 保持探索，其余时间专注利用。

这个算法简单到一句话能说完，却构成了 RL 里探索策略的基线：后起的 UCB、梯度老虎机、乃至深度 RL 里的各种探索机制，都要先跟它比一比。<span class="marginnote">「没有免费午餐定理」说：没有任何算法在所有问题上都最优——ε-贪心也不例外。它把探索与利用的权衡压缩进一个参数 ε，简单，但不可能在每个任务上都胜过专门设计的方法。理解它的优势与边界，正是走向更精细探索方法的第一步。</span>

而在工程实现上，本节还有一个所有 RL 算法共用的公式：**增量式更新（incremental update）**——它让「用样本均值估计价值」不必存下所有历史奖励，一行就能在线更新。这个公式的形态会在时序差分（第六篇）、资格迹（第十二篇）里以同一个灵魂反复出现，甚至在第四级《大模型微调》的 PPO 里，步长与更新的节奏依然是同一个骨架。

## 1 ε-贪心：用小概率守住探索

**ε-贪心策略**：在每一步，以概率 $1 - \varepsilon$ 选择当前价值估计最大的动作（贪心），以概率 $\varepsilon$ 在所有动作中均匀随机选一个（探索）。

$$A_t = \begin{cases} \arg\max_a Q_t(a), & \text{以概率 } 1-\varepsilon \\ \text{均匀随机选一个动作}, & \text{以概率 } \varepsilon \end{cases}$$

两个要点值得停下来想：

- **每个动作都会被无限次地尝试。** 因为以概率 $\varepsilon$ 随机选，所以无论某个动作多么「看起来差」，它被选中的次数 $N_t(a)$ 都会随 $t \to \infty$ 趋于无穷——于是大数定律保证 $Q_t(a) \to q_*(a)$，**所有动作的估计最终都会收敛到真值**。这恰好治好了贪心「永远不回头」的病。
- **代价是长期次优。** 若 $\varepsilon$ 固定不变，算法在极限下以概率 $\varepsilon$ 仍在乱选——收敛到的价值会比最优低 $\varepsilon$ 的比例。若让 $\varepsilon$ 随时间递减（比如 $\varepsilon_t = 1/t$），则可以同时保证「无限探索」与「最终完全收敛」——但**探索概率递减的时机是个超参数**：减快了会重蹈贪心覆辙，减慢了会长期次优。<span class="marginnote">Sutton & Barto 的经典 10 臂测试台上，固定 $\varepsilon = 0.1$ 通常明显好于 $\varepsilon = 0.01$，也远好于纯贪心——因为 10 台机器奖励分布重叠，纯贪心经常被「一次差运气」骗走。这解释了为什么「常数 ε 虽非最优却稳健」。</span>

如果奖励是**确定性的**（每台机器每次给同样的数），情况则完全不同：只要每个动作被访问过一次，它的价值就精确已知，贪心立刻成为最优策略，探索纯属浪费。ε-贪心的价值恰恰出现在**随机奖励**的环境里——噪声让单次观测不可信，才需要靠反复访问去逼近期望。**环境的确定性越低，探索的回报越高**，这条直觉在全书（以及大模型训练的随机梯度里）都会反复用到。这个「确定性环境下贪心最优、随机环境下需要探索」的对照，也是理解「为什么 RL 需要随机性」的第一课。

## 2 公式解析：从样本均值到增量式更新

样本均值估计需要记下「选的次数」和「奖励总和」两个数就够了，但更优雅的是把它改写成**增量式（递归）**的形式——每次来一个新奖励，只更新一行。

设 $Q_n$ 是某个动作被选了 $n-1$ 次后的价值估计，第 $n$ 次该动作得到的奖励是 $R_n$。用上一节的样本均值定义：

$$Q_{n+1} = \frac{1}{n} \sum_{i=1}^{n} R_i$$

把它拆成递推，三步推导：

- **第一步，把「第 $n$ 次的奖励」从求和里单拎出来**：
$$Q_{n+1} = \frac{1}{n}\left( \sum_{i=1}^{n-1} R_i + R_n \right)$$

- **第二步，把前 $n-1$ 项的和换成 $(n-1) Q_n$**（因为 $Q_n$ 正是前 $n-1$ 次的平均）：
$$Q_{n+1} = \frac{1}{n}\left( (n-1)Q_n + R_n \right)$$

- **第三步，展开并整理成「旧估计 + 修正」的形式**：
$$Q_{n+1} = Q_n + \frac{1}{n}\left( R_n - Q_n \right)$$

于是我们得到一个**通用更新范式**：

$$\text{新估计} \leftarrow \text{旧估计} + \alpha \times (\text{目标} - \text{旧估计})$$

其中 $\alpha = 1/n$ 是**步长（step size）**，$R_n - Q_n$ 是**误差（error）**——「这次的观测告诉你：你原来偏了多少」。这个范式在全书反复出现：时序差分的更新、资格迹的更新，全是它的变形——第六篇你会再见到「$Q \leftarrow Q + \alpha [R + \gamma Q' - Q]$」这样一模一样的骨架。

### 数值算例：三个奖励，三步逼近均值

某个动作依次给出奖励 $1, 2, 6$，用增量式更新 $Q_{n+1} = Q_n + \frac{1}{n}(R_n - Q_n)$ 追踪其样本均值：

| 步骤 | 旧估计 $Q_n$ | 新奖励 $R_n$ | 误差 $R_n - Q_n$ | 新估计 $Q_{n+1}$ |
| --- | --- | --- | --- | --- |
| 1 | $0$ | $1$ | $1$ | $0 + 1 = 1$ |
| 2 | $1$ | $2$ | $1$ | $1 + \frac{1}{2}\times1 = 1.5$ |
| 3 | $1.5$ | $6$ | $4.5$ | $1.5 + \frac{1}{3}\times4.5 = 3$ |

**验证**：$(1+2+6)/3 = 3$，完全一致。**看这个表**：每步都只用「一个旧估计 + 一个观测」，没有存下 1、2、6 三个数——这就是增量式更新的全部魔法。步长 $\frac{1}{n}$ 让「第 $n$ 个样本」的权重恰好是 $\frac{1}{n}$，误差越大修得越猛。<span class="marginnote">增量式更新的意义：你不需要存下某个动作的全部历史奖励，只需一个 $Q_n$ 和计数器 $n$。在强化学习里，价值估计要在线随经验更新——这种「来了一个观测就修正一点」的节奏，正是所有学习算法的核心律动。</span>

## 3 步长的选择：收敛与跟踪的两难

上式的心脏是步长 $\alpha$。两种典型选择：

**$\alpha_n = 1/n$（递减步长）**：满足罗宾斯-门罗条件 $\sum_n \alpha_n = \infty$ 且 $\sum_n \alpha_n^2 < \infty$——前者保证「走了无限远」（不会被起点困住），后者保证「最终停得下来」（噪声不累积）。它对**平稳问题**保证收敛到真值 $q_*(a)$，但代价是**不再能跟踪环境的变化**——后期步长太小，环境若漂移就追不上。
**常数 $\alpha$（如 0.1）**：不满足收敛条件，估计不会真正收敛（会在真值附近浮动），但能**持续跟踪非平稳分布**——旧数据被指数遗忘，最近的数据权重更大。这就是**指数滑动平均**：$Q_{n+1} = Q_n + \alpha (R_n - Q_n)$ 展开后，$k$ 步前的奖励只占 $\alpha(1-\alpha)^k$ 的权重。

**辨析｜易错点：平稳与不平稳，用的步长策略相反。** 真实世界几乎总是不平稳的——用户的偏好会变、对手的策略会变、环境本身在漂移。所以在实践里「常数小步长」往往比「$1/n$ 递减」更稳健。判断一个算法该不该「收敛到精确值」，先问：**这个问题本身是静止的吗？** 这个「收敛 vs 跟踪」的两难，会在全书反复出现，也是调参时最值得记在心里的一个权衡。实践中，当奖励的尺度在不同问题间差别很大时，还会对步长做归一化处理，但无论怎么调，骨架始终是「旧估计 + 步长 × 误差」这一行。

## 4 代码实现：一个可运行的 ε-贪心老虎机

把上面所有思想合成一段可运行的 Python，你会看到增量式更新只有几行：

```python
class EpsilonGreedy:
    def __init__(self, k, eps=0.1):
        self.k = k
        self.eps = eps
        self.Q = [0.0] * k          # 价值估计（增量式更新）
        self.N = [0] * k            # 每个动作的选择次数

    def select(self):
        if random.random() < self.eps:      # 以概率 ε 均匀探索
            return randint(self.k)
        return argmax(self.Q)               # 其余时间贪心利用

    def update(self, a, r):
        self.N[a] += 1
        self.Q[a] += (r - self.Q[a]) / self.N[a]   # 旧估计 + 1/N × 误差
```

运行这段代码你会发现，多数时候 $Q_0$（对应真值 1.0）会被估得比 $Q_1$ 高——ε-贪心用 10% 的随机尝试守住了对较差动作的探索，同时把 90% 的力气花在最优动作上。<span class="marginnote">把 $\varepsilon$ 设成 0，这段代码就退化成纯贪心——在随机环境下它常常被一次坏运气带偏；把 $\alpha$ 换成 $1/n$，它就变成「平稳问题严格收敛」的版本。这个类的两个参数，正好对应本节的全部讨论。</span>

若想把 $N_t(a)$ 用起来（比如后面 UCB 需要它），只需在**更新公式**里把步长换成 $1/N_t(a)$——这行改动，就是「递减步长」与「常数步长」两种世界观的分界。而把 **ε-贪心** 里的探索从「均匀随机」换成「按某种优先级」，就得到了下一节 UCB 的雏形——**ε-贪心是探索策略的地基，而不是终点。**

## 5 探索策略对照与术语速查

把本节与接下来的探索策略并排，各自的「不确定性来源」一目了然：

| 探索策略 | 机制 | 显式建模不确定性 | 适用场景 |
| --- | --- | --- | --- |
| ε-贪心 | 以概率 ε 均匀乱试 | 无 | 通用基线、简单稳健 |
| 乐观初始值 | 把初始 Q 设高 | 隐含（乐观偏差） | 早期探索充分 |
| UCB | 选「均值 + 置信上界」最大的 | 显式（用访问次数） | 平稳、有 $N(a)$ 可用 |
| 梯度老虎机 | 按数值偏好更新选择概率 | 无 | 偏好型任务 |

**读表要点**：ε-贪心把所有探索「一刀切」成固定概率，不区分「哪个动作更不确定」；UCB 则把不确定性算进选择分数里——后者更聪明，但需要每个动作的访问计数。理解 ε-贪心的「均匀乱试」局限，正是走向 UCB 的动机。

## 6 术语速查

| 术语 | 一句话含义 |
| --- | --- |
| ε-贪心 | 以概率 ε 随机探索、$1-\varepsilon$ 贪心利用 |
| 增量式更新 | $Q \leftarrow Q + \alpha(\text{目标}-Q)$，无需存储历史 |
| 步长 $\alpha$ | 控制旧估计向新观测靠拢的幅度 |
| 指数滑动平均 | 常数 $\alpha$ 展开后旧数据按指数衰减 |
| 罗宾斯-门罗条件 | $\sum\alpha_n=\infty$ 且 $\sum\alpha_n^2<\infty$ 的收敛条件 |
| 非平稳分布 | 分布随时间漂移，需要常数步长持续跟踪 |

## 7 小结

- **ε-贪心**：以概率 $\varepsilon$ 随机探索、$1-\varepsilon$ 贪心利用，是最简单的「探索 + 利用」折衷；固定 $\varepsilon$ 保证无限探索但长期次优，$\varepsilon$ 递减可兼顾最终收敛。
- **增量式更新**：$Q_{n+1} = Q_n + \alpha (R_n - Q_n)$，通用范式是「新估计 ← 旧估计 + 步长 × 误差」，无需存储全部历史。
- **步长两难**：$1/n$ 收敛但不跟踪，常数 $\alpha$ 不收敛但能跟踪非平稳；真实问题多是不平稳，常数小步长更稳健。
- 记住三个数就够了：**ε 管探索、α 管步长、误差 $R - Q$ 管方向**。
- 时序差分（第六篇）与资格迹（第十二篇）的更新，都是同一更新范式的变身。

在下一节，我们进入探索策略的「更聪明」阵营：与其让探索概率固定为 ε，不如把「不确定性」本身编码进选择——这就是**乐观初始值与置信度上界（UCB）**。它会把本节那句「环境的确定性越低，探索的回报越高」，变成一条可以精确计算的数学不等式。
