## 为什么从「回报」开始

上一节我们把放大镜对准了「智能体—环境」接口：状态、动作、奖励、一步转移 $p(s', r \mid s, a)$，还有那条把「目标」翻译成「标量奖励累积和期望」的奖励假设。但仔细想想，奖励假设只说了半句话——它说目标等价于「累积和的期望」，却没定义**这个累积和到底是什么**。
$R_{t+1}$ 是当下的一步奖励，可智能体在意的不是这一下，而是从这一下开始的整条未来。把「未来的一长串奖励」折叠成一个数，这个数就叫**回报（return）**；怎么折、折多少，取决于智能体有多少耐心——这正是**折扣（discounting）**的用武之地。

这一节是全书第一次正式出现记号 $G_t$ 的地方。$G_t$ 的递归形式

$$G_t = R_{t+1} + \gamma G_{t+1}$$

将直接导出下一节的价值函数与贝尔曼方程，而贝尔曼方程又是后续所有算法（动态规划、蒙特卡洛、时序差分）共同的心脏。可以说，**回报的记号定得清不清楚，决定了你能不能读懂整本书**。

## 1 目标如何翻译成奖励

回到奖励假设：一切目标都可表述为「最大化标量奖励累积和的期望」。这句口号落到工程上，立刻逼出一个尖锐问题：**奖励函数到底该怎么给？** Sutton & Barto 的答案非常直接——只给「想要的结果」，不给「怎么达成」。

**重点：奖励信号不是用来向智能体传授「如何达成目标」的先验知识的地方，它只负责声明「目标是什么」。** 国际象棋的标准做法是只有终局给奖励：赢 $+1$、输 $-1$、其余每步全部 $0$。
吃子、占中心这些「好棋」不配任何中间奖励——智能体应该自己在对局中发现「吃子有助于赢棋」，而不是被我们直接塞进奖励里。<span class="marginnote">反过来，如果你忍不住在每个「好棋」上都发一点进度奖励，就可能喂出奖励欺骗（reward hacking）：智能体发现吃一串子就能刷分，于是专心刷分、却把整盘棋下输。
这个话题在《强化学习的要素》一篇里已经埋了伏笔，第十九篇讲 RLHF 时它会以更危险的面貌卷土重来。</span>

这条原则听起来朴素，做起来却是 RL 工程里最难的判断之一：**什么该编码进奖励，什么该留给智能体去学**。而想真正理解「奖励为什么不能乱给」，前提是先搞清楚**回报**长什么样。

## 2 回报：把一串奖励折叠成一个数

**回报（return）$G_t$**：从时刻 $t$ 起，把未来收到的全部奖励累加而成的总和。它是一个**随机变量**——因为轨迹本身是随机的，同样的起点每次走出来的奖励串都可能不同。

先看最简单的设定：**回合式任务（episodic task）**。它天然地分成一个个**回合（episode）**，每回合在**终止状态（terminal state）**结束。下完一盘棋、走出一次迷宫、打完一局游戏，都是一回合。
设回合在时刻 $T$ 结束（即 $S_T$ 是终止状态，$G_T = 0$），回合式回报就是一个有限和：

$$G_t = R_{t+1} + R_{t+2} + \cdots + R_T$$

注意 $R_{t+1}$ 之后的所有奖励都写在里面，最后一项 $R_T$ 是「走进终止状态」那一刻拿到的奖励；$T$ 之后轨迹终止，不再有奖励。

举个具体的数。一个寻宝机器人的一回合是：$R_1 = 0$（出门）、$R_2 = +10$（踩到金币）、$R_3 = 0$（穿过走廊）、$R_4 = +1$（走进终点），于是 $T = 4$。
从 $t = 0$ 出发的回报：

$$G_0 = R_1 + R_2 + R_3 + R_4 = 0 + 10 + 0 + 1 = 11$$

从 $t = 2$ 出发则是 $G_2 = R_3 + R_4 = 1$。<span class="marginnote">注意：同一个回合，不同的起点，回报完全不同。回报永远是「从当下往后看」的量——这一性质决定了价值函数必然是「关于状态」的函数，也解释了为什么强化学习总在追问「此刻我站在哪、往前能看到多少」。
</span>「只看当下之后」这种截断视角，正是价值函数需要的。

奖励是**标量**这一点，值得单独停下来想一想。环境对智能体的反馈被压缩成一个数——这个「压缩」本身就是奖励假设的承诺：**任何目标都必须能折叠成一个标量的累积和。** 可现实里的目标往往是多维的：既要快、又要稳、还要省电。
工程师必须自己决定如何把这三个目标加权成一个数，而这一步「定权重」本质上已经是人在替智能体做价值判断。权重一旦定错，智能体就会钻空子——过度追求速度、把稳定性甩在脑后。第十八篇的逆强化学习，正是对「我凭什么替你定权重」的反击：与其人肉指定，不如从专家的行为里把奖励函数反推出来。
<span class="marginnote">「多维目标 → 单个标量」的压缩在经济学里也有对应物：效用函数。第二级《经济学》里讨论「效用能否跨人比较」的那些争论，和这里「奖励权重该由谁定」的争论，是同一个哲学问题的两个分身。
</span>

还有一个容易被忽略的点：**回报不仅看「总共多少」，还看「先到后到」。** 两串奖励 $0, 10, 0, 0$ 与 $0, 0, 0, 10$ 在 $\gamma = 1$ 下回报相同（都是 $10$），但在 $\gamma = 0.9$ 下截然不同：前者 $G_t = 0 + 9 + 0 + 0 = 9$，后者 $G_t = 0 + 0 + 0 + 6.561 \approx 6.56$。
**早来的奖励比晚来的更值钱**——这是「时间就是金钱」在强化学习里的精确表达，也是为什么智能体天生倾向「尽快兑现」的策略。<span class="marginnote">这一性质让折扣回报天然偏好「短平快」的解法；
而在医疗、金融这类「慢变量」领域，工程师常被迫把 $\gamma$ 调到非常接近 $1$，甚至改用平均奖励（第十篇）来淡化「早到偏好」。</span>

## 3 折扣：为什么未来要打折扣

但回合式只是强化学习的一半天地。另一半是**持续性任务（continuing task）**：没有天然的回合终点——照料病人一生的护理机器人、持续运转的生产线、长期自动交易的量化策略。
这类任务 $T = \infty$，上面的有限和会一直加下去，很可能发散：如果每一步都拿 $+1$，累积和直接爆炸，智能体无从比较「哪个动作更好」。

**折扣（discounting）** 解决的就是这件事。引入**折扣率（discount rate）$\gamma \in [0, 1]$**，给未来的奖励逐一打上「时间折扣」，折扣回报写成：

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

$\gamma$ 刻画了智能体的**耐心**：

- $\gamma = 0$：**极度短视**，只在乎下一步 $R_{t+1}$，之后的奖励全部被乘成 $0$；
- $\gamma$ 趋近 $1$：**高瞻远瞩**，越接近 $1$，未来奖励被打的折扣越小；$\gamma = 1$ 时完全不打折（只在回合式、有限和的场合安全）。

为什么加一个小于 $1$ 的系数就能保证有限？因为若每步奖励都被某个界 $R_{\max}$ 约束，整串和的绝对值就不超过

$$R_{\max}\left(1 + \gamma + \gamma^2 + \cdots\right) = \frac{R_{\max}}{1 - \gamma}$$

——等比级数的求和公式，只要求 $|\gamma| < 1$。这条等比级数在第二级《数列》与《无穷级数》里有完整推导，这里记住结论即可：**折扣同时买来了「远见」与「收敛」两样东西。**

折扣还有一个更微妙的解读：它隐式地把**不确定性**也折了进去。未来的奖励之所以要打折，不只是「钱越晚越不值钱」，更因为环境常常是随机的——越远的未来越不可靠。下棋时提前三十步看出的「大优局面」，随时可能被对手一手好棋抹平，所以三十步后的奖励就该被打上大折扣。

用一组数把「远见」的粒度看清楚。设一条奖励串 $R_{t+1} = 0$、$R_{t+2} = 0$、$R_{t+3} = 0$、$R_{t+4} = 10$——前三步空手，第四步一笔大的。
看不同 $\gamma$ 下的折扣回报：

| $\gamma$ | $G_t$ | 四步后的 $10$ 实际折算 |
| --- | --- | --- |
| $0$ | $0$ | 完全看不见 |
| $0.5$ | $1.25$ | $10 \times 0.125$ |
| $0.9$ | $7.29$ | $10 \times 0.729$ |
| $0.99$ | $9.70$ | $10 \times 0.970$ |

同样一笔奖励，$\gamma$ 从 $0.5$ 涨到 $0.99$，它在你心里的分量从「聊胜于无」跳到「近乎全额」。**$\gamma$ 因此是一个关键超参数：定得太小，智能体只顾眼前、看不见长期后果；
定得太大，远期估计的方差大、学得慢。** 实践中电子游戏常用 $0.99$，机器人控制常用 $0.95$ 上下；而大模型对齐（RLHF）因为整段对话都要被纳入评价，$\gamma$ 常取非常接近 $1$ 的值（第十九篇会展开）。
<span class="marginnote">「折扣率怎么定」，本质是在「看得远」与「估得准」之间做权衡——这是偏差—方差权衡在时间维度上的翻版，第二级《数理统计》与第九篇《函数逼近》都会回到它。
</span>

## 4 公式解析：折扣回报的递归恒等式

折扣回报里藏着全书最重要的一个恒等式：

$$G_t = R_{t+1} + \gamma G_{t+1}$$

它没有引入任何新量，只是把「求和」换了个写法——但正是这一换，让价值函数变成了可以递归求解的对象。三步拆解：

- **第一步，把第一项单独拿出来**：从 $G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \gamma^3 R_{t+4} + \cdots$ 出发，把 $R_{t+1}$ 留在括号外，其余各项提出公因子 $\gamma$：

$$G_t = R_{t+1} + \gamma\left(R_{t+2} + \gamma R_{t+3} + \gamma^2 R_{t+4} + \cdots\right)$$

- **第二步，认出括号里就是 $G_{t+1}$**：括号内是从「$t+1$ 时刻」看出去的折扣回报，逐项比对 $G_t$ 的定义可知它正是 $G_{t+1}$。于是那条无限长的求和，坍缩成了两步。
- **第三步，读出递归的含义**：**当下的回报 = 当下的一步奖励 + 折现后的「未来回报」**。无穷求和变成了「一步奖励 + 一个回头递归」——这是后面动态规划与时序差分能够迭代求解的数学前提。下一节的价值函数与贝尔曼方程，本质上就是对这条恒等式取期望。

再用数字验证一遍：设 $R_{t+1} = 2$、$R_{t+2} = 3$、$R_{t+3} = 4$、$\gamma = 0.5$。直接求和：$G_t = 2 + 0.5 \times 3 + 0.25 \times 4 = 4.5$。
递归地算：$G_{t+2} = R_{t+3} = 4$，于是 $G_{t+1} = R_{t+2} + \gamma G_{t+2} = 3 + 0.5 \times 4 = 5$，再 $G_t = R_{t+1} + \gamma G_{t+1} = 2 + 0.5 \times 5 = 4.5$。
两条路殊途同归——递归不是另一套算法，它只是同一笔账的另一种算法。

**辨析｜易错点：回报与折扣是两个独立的选择，别绑死。** 回合式任务完全可以不用折扣（$\gamma = 1$ 的有限和依然收敛）；持续性任务则必须 $\gamma < 1$ 才保证收敛。
Sutton & Barto 在统一记号里给出了一条「排他」约束：**$T = \infty$ 与 $\gamma = 1$ 不能同时成立**——否则「无穷长 + 不打折」的和可能发散。
记号上还有一个常被忽视的坑：$0^0$ 这类边界情形，约定 $\gamma^0 = 1$ 恒成立，无论 $\gamma$ 是多少，以免首项 $R_{t+1}$ 被错误地乘上 $0$。<span class="marginnote">这套「有限和 → 打折无限和 → 统一记号」的演进路线，与第一级《数列》里「有限数列 → 无穷级数 → 幂级数」的路线惊人地同构：都是先用手头的有限量定义清楚，再靠收敛条件把边界推过去。
数学的推进方式在 RL 里原样重演了一遍。</span>

## 5 小结

- **奖励假设**落地为一条设计原则：奖励只声明「目标是什么」，不传授「怎么达成」；乱给中间奖励会诱发奖励欺骗。
- **回报 $G_t$** 是从时刻 $t$ 起累积奖励的总和，是随机变量；回合式任务是有限和 $R_{t+1} + \cdots + R_T$。
- **折扣**用 $\gamma \in [0, 1]$ 给未来打折，同时买来「远见」与「收敛」（等比级数 $\sum_k \gamma^k = \tfrac{1}{1-\gamma}$）；$\gamma = 0$ 短视，$\gamma \to 1$ 远见。
- **递归恒等式** $G_t = R_{t+1} + \gamma G_{t+1}$ 把无限求和变成一步递归，是贝尔曼方程的直接前身。
- **易错点**：回报与折扣独立选择；持续性任务必须 $\gamma < 1$；约定 $\gamma^0 \equiv 1$。

在下一节，我们把「回报」从「一条轨迹上的随机变量」提升为「一个状态的期望」——这就是**价值函数**，以及它满足的**贝尔曼方程**。回报是梯子，价值是站在梯子上看到的风景；顺着递归恒等式往上爬，就进入了强化学习的心脏地带。
