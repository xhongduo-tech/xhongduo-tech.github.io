## 为什么单步与整幕之间需要一个刻度

TD(0) 只回望一步真实奖励就自举；蒙特卡洛要等整幕结束才敢更新。前者的偏差来自「过早自举」——下一步价值还是旧估计，误差会被复制；后者的方差来自「等太久」——整幕随机性全部累积进一个回报。**n步TD（n-step TD）** 把两者放进一条谱系：向前看 $n$ 步真实奖励，第 $n$ 步之后才自举。$n$ 是从 1 到无穷的一格刻度尺——$n=1$ 是 TD(0)，$n=\infty$（到幕末）就是 MC。<span class="marginnote">n步方法的重要性常被低估：它的价值不止是「介于 TD 与 MC 之间」，更在于它把「自举点」做成可调节的超参数，并在第12章的资格迹里以 λ 形式无限逼近真正的灵活实现。</span>

这条谱系是第6章 TD 学习的自然延伸：第6章里 TD(0) 与 MC 各执一端，第7章则给了「中间态」一个正式的位置。理解 n步回报，等于理解了全书所有「自举点」旋钮的通用机制——第12章把整数 n 换成连续 λ，靠的就是同一个思想。

## 1 n步回报：一半真实，一半自举

定义从时刻 $t$ 出发、向前看 $n$ 步的 **n步回报（n-step return）**：

$$
G_{t:t+n} \;\equiv\; R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^n V(S_{t+n})
$$

它由三部分拼成：前 $n$ 个**真实奖励**（折扣后的和），加上**第 $n$ 步之后的自举**——用当前估计 $V(S_{t+n})$ 顶替剩下的所有未来。若 $t+n \ge T$（超过了幕末），则 $G_{t:t+n} = G_t$（整幕回报），因为 $V$ 在终止状态定义为 0。

**n步TD预测**的更新就是把 TD(0) 的目标换成 n步回报：

$$
V(S_t) \;\leftarrow\; V(S_t) + \alpha\big[\,G_{t:t+n} - V(S_t)\,\big]
$$

**关键约束**：$V(S_{t+n})$ 必须是**在 $S_{t+n}$ 被首次访问时**的估计——更新发生在时刻 $t+n$，且用「尚未被 $t$ 以后更新污染过」的旧值。实现上需要保存过去 n 步的状态、奖励与时间，这是 n步方法唯一的工程代价。<span class="marginnote">实现细节：用循环数组保存最近 $n$ 个 $(S_t, A_t, R_{t+1})$，每到达一个新的 $S_{t+n}$ 才回头更新 $S_t$。这个「延迟 n 步再更新」的缓冲，是 n步实现里最常见的 bug 来源。</span>

**一个数字小例**：设 $\gamma = 0.9$、$n=3$，从时刻 $t$ 出发的三步奖励为 $R_{t+1}=2$、$R_{t+2}=-1$、$R_{t+3}=4$，且 $S_{t+3}$ 处的价值估计为 $V(S_{t+3})=5$。则

$$
G_{t:t+3} = 2 + 0.9\times(-1) + 0.9^2\times 4 + 0.9^3\times 5 = 2 - 0.9 + 3.24 + 3.645 = 7.985
$$

若把 $n$ 改成 1，则 $G_{t:t+1}=2+0.9\times V(S_{t+1})$——自举点更近，真实奖励更少；若 $n$ 一直拉到幕末，$G_{t:T}$ 就是整幕真实回报的折扣和。**同一个状态序列，n 不同得到的目标值就不同**——这个「同一幕、多个目标」的视角，正是后面资格迹「几何加权平均所有 n」的前提。

**工程上的代价要算清楚**：n步方法每前进一步，都要额外保存 n 个「状态—奖励」对。n 很小（如 3–5）时开销可忽略；但若 n 大到数百（在长视界任务里），内存与延迟都会抬头。**这也是资格迹在实践里常被偏爱的原因**——它用一套「资格」的指数衰减，近似等价于「所有 n 的加权平均」，却几乎不增加存储。

## 2 n是超参数：随机游走实验的结论

教材的经典随机游走实验（19 个非终止状态）给出了一个可复现的结论：**n 过小，学习慢且偏；n 过大，方差大且也慢——存在一个最优中间值**。

实验数据（每批 10 次，做 100 批后测均方误差）大致呈现「U 形」曲线：$n=1$（TD(0)）与 $n=32$（接近 MC）的误差都高于 $n=4\sim 8$ 的中间地带。<span class="marginnote">不同 $\alpha$ 下最优 n 会移动，但「中等 n 最优」这一形状是稳健的。直觉：n=1 时自举过早，误差主要来自旧估计的偏差；n 大时自举点远去，方差回升。折中处偏差与方差之和最小。</span>

教材报告的具体数值值得记住：$\alpha=0.2$ 时，$n=4$ 附近的均方误差约为 TD(0) 的一半；$\alpha=0.4$ 时最优 n 前移到 $n=3$ 左右。**n 与 α 存在联动**——α 大（步子猛）时，自举点过早会把误差放大，所以要往前看更多真实步数来补偿；α 小时则可承受更早的自举。工程师调参的顺序，往往是先定 n 再配 α，就是这个联动的直接应用。

这个「U 形」是全书反复出现的主题：**TD 家族里，自举点（n 或 λ）是一个真正的偏差-方差旋钮**。工程师调它，比调学习率更立竿见影。<span class="marginnote">值得注意的是，这个「中等 n 最优」的结论在<strong>固定学习率</strong>下成立；若引入合适的自适应步长（如 RMSProp 式的逐参数缩放），MC 也能达到接近 TD 的效果——但那是第9章函数逼近以后的话题。表格型世界先把「n 是旋钮」这件事立住。</span>

## 3 谱系视角：TD(n) 如何统一 TD(0) 与 MC

把 n步回报的式子两端分别取极限：

$n=1$：$G_{t:t+1} = R_{t+1} + \gamma V(S_{t+1})$——就是 TD(0) 目标，完全自举。
$n \to T-t$（直到幕末）：$G_{t:T} = G_t$——就是 MC 回报，完全采样，零自举。

于是 **TD(0) 与 MC 是同一条谱系的两个端点，n步方法是中间插值**。这条谱系的价值在于：它让「多相信数据、少相信估计」变成连续可调的。行为策略下，n步方法对错误初始估计的敏感度随 n 增大而下降——这正是「自举是偏差来源」的直接体现。<span class="marginnote">这也解释了为什么「n 越大越像 MC」在<strong>控制</strong>问题里通常更稳：探索行为（ε-贪心）注入的噪声会被 n 步采样平滑，而不是被一步自举立即放大。</span>

还要注意 **n步回报的期望性质**：对任意 $n$，在目标策略下，$\mathbb{E}[G_{t:t+n} \mid S_t = s]$ 是 $v_\pi(s)$ 的估计，其偏差随 $V$ 的误差衰减（$n$ 越大偏差越小），方差随 $n$ 增大而增大。<span class="marginnote">数学上，n步回报是「部分期望+部分采样」的混合估计量。它的偏差来自最后一项 $\gamma^n V(S_{t+n})$ 若 $V \neq v_\pi$，而这一项随 $\gamma^n$ 指数衰减——这就是「n 越大越无偏」的定量含义。</span>

这个「期望里夹着采样」的结构值得再读一遍：前 n 步的奖励是**已实现的样本**，第 n 步以后被 $V$ 的**期望**顶替。所以 n 越小，「期望的成分」越多、自举越重；n 越大，「样本的成分」越多、自举越轻。**自举与采样的比例，被 n 这一个整数完整控制**——这是 n步方法与资格迹能够统一的最本质原因。

**TD(0)、n步TD 与 MC 三者的并排对照**，把「自举刻度」一次看透：

| 维度 | TD(0)（$n=1$） | n步TD（$1<n<\infty$） | MC（$n\to\infty$） |
| --- | --- | --- | --- |
| 自举点 | 第 1 步后 | 第 n 步后 | 幕末，无自举 |
| 偏差 | 最大（过早自举） | 中等 | 最小（无偏） |
| 方差 | 最小 | 中等 | 最大（整幕随机） |
| 更新时间 | 每步 | 延迟 n 步 | 幕末 |
| 需要缓冲 | 否 | 循环数组存 n 步 | 存整幕 |
| 误差传播 | 快（会被复制） | 受 $\gamma^n$ 控制 | 不传播 |

这张表的本质是一条**偏差-方差交换曲线**：自举点越靠前，方差越小但偏差越大；自举点越靠后，偏差越小但方差越大。工程师的活，就是在这条曲线上找一个 n，让两者之和最小。

## 4 公式解析：n步回报的三个部件

$$
G_{t:t+n} \;=\; \underbrace{R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n}}_{\text{真实奖励：n步}} \;+\; \underbrace{\gamma^{n} V(S_{t+n})}_{\text{自举：剩余一切}}
$$

- **第一步，数步数**：前面的真实奖励恰好 $n$ 项，第 $i$ 项乘 $\gamma^{i}$（$i=0$ 到 $n-1$）。这是「采样」部分，方差随 n 增长。
- **第二步，看自举项**：$\gamma^{n} V(S_{t+n})$ 把「第 n 步之后的所有未来」压缩成一个估计值。当 $V$ 是准确的，它就是条件期望的正确补全；当 $V$ 有误差，这部分就引入偏差，但误差被 $\gamma^n$ 打折。
- **第三步，辨端点**：$n=1$ 时自举项是 $\gamma V(S_{t+1})$，几乎全靠估计；$n$ 增到幕末时自举项消失，$G_{t:t+n}=G_t$。**自举份额随 n 指数下降**，这就是为什么中等 n 能取得「偏小、方差也小」的平衡。<span class="marginnote">把 n 换成随机变量（如 λ-几何分布），就能从 n步方法推导出资格迹——这是第12章 TD(λ) 的路线图，本节先埋好种子。</span>

**再看折扣 γ 的角色**：γ 本身也在调「未来多远该被当真」。γ 接近 1 时，远处的奖励权重几乎不减，自举误差能传到很远；γ 小（如 0.9）时，$\gamma^n$ 项快速衰减，第 n 步以后的自举误差被天然压住。**n 与 γ 一个管「自举点在哪」，一个管「未来有多真」**——两者联合起来，才完整刻画一条 n步回报曲线的形状。

## 5 易错点辨析

**辨析｜易错点：** 实现 n步 TD 时直接用「当前」$V$ 值做自举，而忘了保存访问 $S_{t+n}$ 时的旧估计。若用最新估计，更新对象与目标互相污染，n步方法退化成一种不稳定的混合。**标准做法是：$V(S_{t+n})$ 取首次访问该状态时的快照**。

**另一个易错点**：认为「n 越大一定越好」。随机游走实验明确打脸：**最优 n 在中间**。原因是偏差-方差权衡是真实的，没有免费的午餐——MC（$n=\infty$）在有限数据下并不比 $n=8$ 好，反而更差。

**第三个易错点**：忘记终止状态的约定 $V(T)=0$。当 $t+n$ 越过幕末，回报直接取 $G_t$（整幕回报），此时自举项为 0。把终止状态价值当非零处理，会让 n步回报多一项错误的自举。

**第四个易错点**：在**持续性任务**里也用 n步回报的式子。上述 $G_{t:t+n}$ 是**回合式任务**的记号；持续性任务里 $t+n$ 永不越过幕末，回报形式要换成「n步差分回报」（第7章 §7.4 的处理），否则会引入对终止的虚构依赖。**先分清回合/持续两种设定，再谈 n 的取值**——这是 n步方法从预测走向控制前必须跨过的一关。

## 6 小结

- **n步回报**：$G_{t:t+n} = \sum_{i=1}^{n}\gamma^{i-1}R_{t+i} + \gamma^n V(S_{t+n})$，前 n 步真实、之后自举。
- **n步TD**：$V(S_t) \leftarrow V(S_t) + \alpha[G_{t:t+n} - V(S_t)]$，自举点由 n 控制。
- **谱系**：$n=1$ 即 TD(0)，$n\to\infty$ 即 MC；n 是偏差-方差旋钮。
- 随机游走实验呈 **U 形**：中等 n 最优，n 过小偏、过大抖。
- 实现需保存过去 n 步的缓冲，自举值用「首次访问时」的旧估计。
- 数字例：$\gamma=0.9$、$n=3$ 时，$G_{t:t+3}=2-0.9+3.24+3.645=7.985$——同一幕、多个 n 目标并存。
- n步回报是「同一幕可同时构造 $n$ 个目标」的视角，这是第12章资格迹做几何加权平均的前提。
- 自举与采样的比例由 n 唯一控制：n 小则期望成分多，n 大则样本成分多——「自举刻度尺」的最终含义。
