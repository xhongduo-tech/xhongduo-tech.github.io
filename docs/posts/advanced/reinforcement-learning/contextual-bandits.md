## 为什么从「情境」开始

走到这里，我们处理的所有老虎机都是**非关联（nonassociative）**的：不管外部世界是什么样子，动作的好坏评价标准都一成不变。这显然离真实世界很远——给一位刚打开手机的用户推运动鞋可能正中下怀，给一位正在赶论文的用户推同一款鞋，只会被一键关闭。**同样的动作，在不同的情境下价值不同。**

这一节引入老虎机的最后一块拼图：**情境（context）**。每一步，智能体先观察到一个情境，再据此选动作；奖励同时取决于情境与动作。学习的目标从「选一个动作」升级为「学一张情境 → 动作的映射」——也就是**策略**。这个升级虽小，却是质的：它是「状态」概念第一次出场，也是通往第3章马尔可夫决策过程的最后一级台阶。<span class="marginnote">科日布斯基那句「地图并非疆域」常被用来提醒：我们对世界的表示（状态、情境）不等于世界本身。强化学习里，状态表示是否足够好，直接决定学出来的策略好不好——这个话题在马尔可夫性质一节会正面展开。</span>

## 1 关联搜索：给老虎机加上情境

**关联搜索（associative search）任务，也叫上下文老虎机（contextual bandit）**：每一步 $t$，智能体观察到一个情境 $S_t$（也叫上下文），据此选择一个动作 $A_t$，环境返回奖励 $R_{t+1}$，然后进入下一步——**情境会变，但情境的演变与动作无关**。

它与前面所有老虎机（k 臂、ε-贪心、UCB、梯度老虎机）的本质区别，Sutton & Barto 用一句话点明：**关联搜索任务既需要「试错搜索」，又需要「把动作与它最合适的情境关联起来」**。纯老虎机只要求前者；关联搜索在它之上加了「记忆与关联」。

**重点：关联搜索第一次要求学习一张策略（policy）。** 策略是一个映射——看到情境 $s$ 就选动作 $a$。前面我们虽然偶尔用「策略」这个词，但那里的策略退化成了一个固定动作或一套固定概率；这里是真正的「情境 → 动作」表格。这也是「学习」从「数值估计」走向「关系学习」的第一步。

现实例子俯拾皆是：

- **个性化推荐**：情境是用户画像与页面信息，动作是候选商品，奖励是点击/购买。
- **医疗用药**：情境是病人的症状与检查指标，动作是备选药物，奖励是疗效指标。
- **广告竞价**：情境是访客与广告位，动作是素材选择，奖励是转化。

这些场景都满足一个关键假设：**这一步的动作不会改变下一个情境**——你给用户推了鞋，用户不会因此「变成另一种画像」。正是这个假设把它们与完整 RL 划开。

## 2 与非关联任务的对照：别把不同情境混为一谈

**辨析｜易错点：把上下文老虎机当非关联老虎机处理，会得到次优策略。** 如果你只维护一套 $Q(a)$，学到的是「跨情境平均」的价值——它对每个具体情境都不是最优的。举个极端的例子：情境 $s_1$ 里动作 A 好、动作 B 坏；情境 $s_2$ 里恰好反过来，且两个情境出现频率相当。跨情境平均下来 A、B 打平，非关联算法无从区分；而关联算法能分别记住「$s_1$ 选 A、$s_2$ 选 B」，两个情境都做对。

反过来也成立：如果任务其实是非关联的（情境不提供任何信息），却强行按情境拆分成多个老虎机，每个子问题数据变少、估计更差。**「要不要关联」本身是个建模选择**，选错了方向都会吃亏。

朴素的做法是**每个情境独立跑一个老虎机**（每个 $s$ 维护一套 $Q(s, \cdot)$）。它一定比不区分情境好，但代价是**不共享数据**：两个相似情境的样本无法互相借力，情境一多，数据立刻捉襟见肘。<span class="marginnote">出路是**函数逼近**：用情境的特征（而不是离散编号）作输入，让相似情境共享统计强度。这条线在第九篇《函数逼近》会全面展开；「用特征而非编号表示情境」正是价值函数逼近的起点。</span>

## 3 公式解析：情境价值、策略与「分开学」的代价

把记号正式化。设情境集 $\mathcal{S}$、动作集 $\mathcal{A}$，三者关系如下：

$$\pi(a \mid s) = \Pr\{A_t = a \mid S_t = s\}, \qquad q_*(s, a) = \mathbb{E}\left[R_t \mid S_t = s, A_t = a\right]$$

- $\pi(a \mid s)$ 是**策略**：在情境 $s$ 下选动作 $a$ 的概率；
- $q_*(s, a)$ 是**情境-动作真值**：在情境 $s$ 下选动作 $a$ 的期望奖励。

最优策略就是在每个情境里取最大值：

$$\pi_*(s) = \underset{a}{\arg\max}\, q_*(s, a)$$

拆三步看这张图景：

- **第一步，真值表膨胀了**：从非关联老虎机的 $k$ 个数（$q_*(a)$），变成 $|\mathcal{S}| \times k$ 个数（$q_*(s,a)$）。若情境有 $n$ 个、动作 $k$ 个，独立学习需要维护 $n \times k$ 个参数——这就是「分开学」的**数据代价**：每个格子都需要足够的样本来估计。
- **第二步，策略从「一个动作」变成「一张表」**：$\pi_*$ 不再是单个最优动作，而是「每个情境各配一个动作」的映射。这张表正是「知识」的所在——记住「什么情境下该做什么」。
- **第三步，特征表示可以压缩这张表**：若情境可表示成特征向量 $\phi(s)$，那么 $q_*(s,a) \approx \theta_a^\top \phi(s)$ 之类的线性近似，能把参数从 $n \times k$ 压到「特征维度 $\times k$」。相似情境共享 $\theta_a$，统计强度得以互通——这是从「查表」走向「泛化」的关键一跃，也是下一大篇（第3章之后）的主题。

用一个两情境、两动作的数值例子收束本节：情境 $s_1$ 中 $q_*(s_1, A) = 1,\ q_*(s_1, B) = 0$；情境 $s_2$ 中 $q_*(s_2, A) = 0,\ q_*(s_2, B) = 1$。平均价值 A、B 各为 0.5，非关联算法只能二选一并长期错一半；关联策略 $\pi_*(s_1)=A,\ \pi_*(s_2)=B$ 则两全其美。**「情境」的价值，正在于它把「该选谁」这个问题从一刀切变成了「看情况」。**

## 4 上下文老虎机为何是通往 MDP 的桥

把前面三节的积累放到地图上看，脉络一下子清晰起来：

| 设定 | 情境/状态 | 动作影响奖励 | 动作影响下一状态 |
| --- | --- | --- | --- |
| k 臂老虎机 | 无 | 是 | 无状态 |
| 上下文老虎机 | 有，但演变与动作无关 | 是 | **否** |
| 完整 RL（MDP） | 有 | 是 | **是** |

**重点：上下文老虎机 = 完整 RL 减去「动作改变状态」这一环。** 它把「在情境下学策略」这件事，从「处理延迟奖励与信用分配」里剥离出来单独研究——你已经能看清：策略 $\pi(a \mid s)$、情境价值 $q_*(s,a)$ 这些概念会一字不差地进入第3章；届时唯一的新东西，是状态转移 $p(s', r \mid s, a)$，以及它带来的回报、折扣与贝尔曼方程。<span class="marginnote">在推荐系统与在线广告的文献里，「上下文老虎机」本身就是一个繁荣的研究方向（线性 UCB、汤普森采样等），并不只是教材里的过渡章节——它把「情境化决策」做到了工程可用的程度。</span>

从多臂老虎机到上下文老虎机，再到 MDP，是「在什么层面上做决策」的不断深化：没有情境 → 有情境但无动态 → 有情境且有动态。每一步都往模型里加一层「世界对动作的回应」。理解了这条进化链，你就能预判第3章为何值得投入全部注意力——那里将出现全书的心脏：**贝尔曼方程**。

## 5 小结

- **关联搜索 / 上下文老虎机**：每一步先观察情境 $S_t$，再选动作，奖励取决于（情境，动作）；情境的演变与动作无关。
- **首次要求学习策略**：一张「情境 → 动作」的映射 $\pi(a \mid s)$，区别于纯老虎机的固定动作或固定概率。
- **易错点**：把上下文老虎机当非关联老虎机处理，学到的是跨情境平均的次优策略；反之过度拆分会损失统计强度。
- **公式化**：$q_*(s,a)$ 是真值表，最优策略 $\pi_*(s) = \arg\max_a q_*(s,a)$；独立学习需 $|\mathcal{S}| \times k$ 个参数，特征表示能把参数压到特征维度。
- **它是通往 MDP 的桥**：与完整 RL 的唯一差别是「动作不影响下一状态」。
- 策略、情境价值等概念将原样进入第3章，那时新增的是状态转移 $p(s', r \mid s, a)$ 与延迟奖励。

在下一节，我们正式离开「一步决策」的世界，进入第3章。第一站是全书最基本的构件：**智能体-环境交互接口与马尔可夫性质**——回答「状态、动作、奖励到底如何构成一个决策问题」。
