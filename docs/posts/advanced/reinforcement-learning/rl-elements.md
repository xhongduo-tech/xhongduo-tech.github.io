## 为什么从「要素」开始

上一节我们建立了强化学习的整体图景：试错、延迟奖励、与环境交互，以及「智能体—环境」这条交互回路。但你会发现，那里把「智能体」当成了一个黑箱——它收到状态，吐出动作，可**箱子里面到底装了什么？**

Sutton & Barto 的答案是：几乎所有强化学习系统都由四个要素构成——**策略、奖励信号、价值函数、环境模型**。前三个是任何 RL 系统都必需的，第四个是可选的。理解这四个要素的分工，是读懂全书每一个算法的前提：动态规划、蒙特卡洛、时序差分估计的是**价值函数**；策略梯度直接优化的是**策略**；Dyna 与 AlphaZero 用到的则是**环境模型**。<span class="marginnote">四要素不是教材的摆设：全书的结构几乎就是按要素展开——第二、三篇建记号，第四至十二篇学价值函数的估计，第十三篇学策略的直接优化，第八、十五篇讲模型的规划。看懂这张分工图，你就握住了全书的目录。</span>

更重要的是，四个要素内部藏着一个全 RL 最深刻也最容易混淆的区分：**奖励信号定义「发生了什么」，价值函数定义「接下来会发生什么」。** 今天把这条线划清，后面读任何公式都会顺得多。

## 1 策略：智能体的行动手册

**策略（policy）**：从状态到动作选择的映射，是智能体的「行动手册」。它回答的问题是：在状态 $s$ 下，我应该怎么动。

策略可以是**确定性的**：$\mu(s) = a$，一个状态对应一个固定动作；也可以是**随机性的**，记作

$$\pi(a \mid s) \doteq \Pr\{A_t = a \mid S_t = s\}$$

即在状态 $s$ 下选择动作 $a$ 的概率。随机策略不是「犹豫不决」，而是一种理性设计：在石头剪刀布这类博弈里，确定性策略必然被对手摸透；在探索与利用的平衡里，随机性保证了「还没验证过的动作」有被尝试的机会。

**策略是 RL 学习的最终对象。** 价值函数、环境模型都只是手段——你最终想要的是一个好策略：一个在每一步都能告诉你「该选哪个动作」的规则。这也解释了为什么亚里士多德的「习惯」之说如此贴切：RL 学的不是一条条孤立的正确动作，而是一整套**在各类处境下稳定采取的应对方式**。

## 2 奖励信号：定义「好」的唯一标尺

**奖励信号（reward signal）**：环境在每个时间步给智能体的即时标量反馈 $R_t$，它定义了「什么是好的」。注意两个关键词：

- **由环境给出，不由智能体决定**。智能体无法直接修改奖励，只能通过改变自己的动作去「挣得」更多奖励。
- **即时（immediate）**：$R_t$ 只描述「这一步」的好坏，不承诺未来。

上一节的**奖励假说**在这里再次出场：任何目标都可以表述为「最大化期望累积回报」。正因为有了奖励信号，强化学习才不需要像监督学习那样有一位「老师」在每个样本上指出正确动作——环境用一把尺子度量一切，智能体自己摸索怎么把这把尺子的读数变大。<span class="marginnote">心理学里有一个同源的对应物：操作性条件反射中的「强化物」——斯金纳箱里的鸽子按啄杆获得食丸，正是在一个极简环境里「用行动挣奖励」。第一级《心理学》的这节内容，就是奖励信号在人脑中的原始版本。</span>

奖励设计本身是一门艺术。最经典的例子是国际象棋：人类下棋并不会在每一步都拿到分数，只有终局才见胜负——这是极稀疏的奖励。工程师常忍不住给中间过程加一些「进度奖励」（比如吃掉对方一个子 $+0.5$），这叫**奖励塑造（reward shaping）**。它的风险是智能体可能学会「刷分」而不是「取胜」——绕过真正的目标，去反复赚取中间奖励，这就是著名的**奖励欺骗（reward hacking）**现象，在 RLHF 的奖励模型训练中尤其要防。设计奖励的一条原则是：**奖励应该忠实反映你真正想要的结果，而不是你猜测的「通向结果的捷径」。**

## 3 价值函数：奖励的「远见」版本

如果说奖励回答「这一步做得好不好」，那么**价值函数（value function）**回答的是「**从这里出发，未来累计能拿多少**」——它是奖励的远见版本。

**价值函数 $V_\pi(s)$**：在策略 $\pi$ 下，从状态 $s$ 出发所能获得的**期望回报（expected return）**，即从此刻起到未来全部折现奖励的期望总和。它度量「长远好坏」，而奖励只度量「当下好坏」。

为什么做决策要用价值而不是奖励？因为延迟奖励的存在：某一步动作的收益可能要在很多步之后才兑现。只比较单步奖励是短视的——它忽略了一个动作如何改变你进入的未来。<span class="marginnote">这里浮现出 RL 最著名的难题——信用分配（credit assignment）：一盘棋赢了，功劳该记给 37 步前那次弃子，还是最后一步绝杀？价值函数把「终局的成败」逐步分摊到每一个状态上，正是回答这个问题的数学工具。第六篇的时序差分、第十二篇的资格迹都在为此而战。</span>

在大模型时代，价值函数的思想直接长进了 RLHF：奖励模型要学的就是「这段话值多少分」——它本质上就是一个把「终局好不好」摊到每一句回复上的价值估计，这在第四级《大模型微调》里会有专门的展开。

## 4 公式解析：价值函数这样定义

把「远见」写成公式，就是我们最常遇到的价值函数定义：

$$V_\pi(s) \doteq \mathbb{E}_\pi\left[ G_t \mid S_t = s \right] = \mathbb{E}_\pi\left[ R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots \mid S_t = s \right]$$

对这条公式做四步拆解：

- **第一步，读出 $\mathbb{E}_\pi[\cdot]$**：期望是关于「在策略 $\pi$ 控制下随机产生的整条轨迹」取的。起点固定在 $s$，但接下来每一步的动作由 $\pi$ 的概率决定，状态转移由环境的动力学决定——这两重随机性共同生成一条轨迹，价值的期望就摊在这无数条轨迹之上。这正是第三级《概率论与数理统计》里「条件期望」的直接应用。
- **第二步，读懂条件 $\mid S_t = s$**：竖线后面是「此刻我在状态 $s$」。这个条件把价值函数定义成**关于状态的函数**：状态不同，期望回报不同。同一盘棋，「优势局面」与「败局」的价值天差地别。
- **第三步，展开回报 $G_t$**：$R_{t+1}$ 是下一步的即时奖励，$\gamma^k R_{t+k+1}$ 是 $k$ 步之后奖励的折现值。整串求和就是把「未来的全部折现奖励」加起来——价值就是「这笔钱」在状态 $s$ 处的期望值。
- **第四步，它为什么不等于奖励**：奖励是环境给的单步标量，价值是智能体**估计**出来的期望。奖励「发生了就是发生了」，价值则需要从经验中学习——这正是全书所有预测方法（DP、MC、TD）要解决的问题：如何让 $V_\pi(s)$ 的估计逼近真值。

价值函数还有一对「动作版」：**动作价值函数** $Q_\pi(s,a) \doteq \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a]$，表示「在 $s$ 上先做动作 $a$、之后遵循 $\pi$」的期望回报。两者由一条恒等式相连：

$$V_\pi(s) = \sum_{a} \pi(a \mid s)\, Q_\pi(s, a)$$

**状态的价值，是它可能采取的各动作价值的按策略加权平均。** 第三篇我们会顺着这条链导出贝尔曼方程——价值函数的递归定义，也是全书一切算法的心脏。

这条式子还暗示了价值学习的入口：如果我们能估计出 $Q_\pi(s,a)$，就可以通过对动作价值排序来做选择——这正是第二篇老虎机里「动作价值方法」的种子，也是第三篇「动作价值函数」要全面展开的对象。

## 5 环境模型：要不要「算命」

第四个要素是可选的：**环境模型（model of the environment）**——对环境的动力学做模拟，预测「在状态 $s$ 做动作 $a$，接下来会到什么状态、拿到什么奖励」：

$$\hat{p}(s', r \mid s, a) \approx p(s', r \mid s, a)$$

有了模型，智能体就可以在**想象中**推演未来的轨迹，提前规划而不必真的去环境里试错——这叫**规划（planning）**。不用模型、只靠真实交互反馈来学习的叫**无模型（model-free）**方法；用模型提前推演的叫**基于模型（model-based）**方法。<span class="marginnote">「要不要模型」是 RL 的设计抉择：模型给了你「想象」的能力，代价是模型可能不准——模型与现实不符时，规划会系统地跑偏。Sutton & Barto 把「学习 + 规划」统合进 Dyna 框架（第八篇）；AlphaZero 则是「完美模型（规则）+ 深度规划」的极致（第十五篇）。</span>

注意「模型」不是「策略」：模型回答「世界会怎么变」，策略回答「我该怎么做」。有了模型，智能体可以把两者组合起来做**前瞻式规划（look-ahead planning）**——在想象里走一步看一步，挑一条最可能通往高回报的路。机器学习里常说的 **world model（世界模型）**，就是环境模型在深度学习时代的名字；第十五篇会看到它如何支撑 AlphaGo 这类「在脑中推演」的系统。

**辨析｜易错点：奖励、回报与价值是三样东西。** 初学者常把三者混为一谈。分清它们：**奖励 $R_t$** 是环境给的、当步的、已知标量；**回报 $G_t$** 是「从当下到未来」全部折现奖励的**总和**（一个随机变量）；**价值 $V_\pi(s)$** 是回报的**期望**（一个关于状态的函数）。奖励与价值的关系，就像「一次考试成绩」与「你真实的学科水平」——前者是一次观测，后者是要估计的期望。三者混用，后面的 TD 误差就会读不懂。

## 6 用四要素看一个真实系统：以 AlphaGo 为例

抽象的四要素放回真实系统，立刻变得具体。2016 年的 AlphaGo 几乎把四要素占全了：

- **策略**：策略网络 $\pi_\theta(a \mid s)$——给定棋盘局面，给出每个落子位置的概率，告诉智能体「这一步大概该往哪下」。
- **奖励信号**：极简——赢了 $+1$，输了 $-1$，中间所有步子的奖励都是 $0$。真正的胜负信号只在终局出现，这正是一道极端的延迟奖励问题。
- **价值函数**：价值网络 $V_\theta(s)$——评估「当前局面（在当前执子方视角下）大概值多少」，用来给搜索树里的中间节点打分，判断「走到这步划不划算」。
- **环境模型**：围棋规则本身就是一个完美模型——AlphaGo 在蒙特卡洛树搜索里用规则**在想象中推演**未来的对局，而不必真的去棋盘上落子（第十五篇会详述）。

这个例子把四要素的分工一次性说清了：**策略负责「怎么走」，奖励定义「为什么赢」，价值估计「走到这里划不划算」，模型提供「想象推演」的舞台。** 读完本篇再回头想 AlphaGo，你会发现它不是一个黑箱，而是一台由四个分工明确的部件组成的机器。

## 7 小结

- 强化学习系统的**四要素**：策略、奖励信号、价值函数、环境模型（可选）。
- **策略 $\pi(a \mid s)$** 是最终的学习对象；确定性 $\mu(s)$ 与随机性 $\pi(a \mid s)$ 各有用途。
- **奖励信号**由环境给出、定义「当下好坏」，是一切目标的标尺（奖励假说）。
- **价值函数** $V_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$ 定义「长远好坏」，需要从经验中估计；它与奖励是「观测」与「期望」之别。
- **环境模型**允许想象与规划，构成模型内 / 模型外方法的分水岭。

在下一节，我们把放大镜对准「强化学习与监督学习、无监督学习的异同」——看 RL 为什么在机器学习三范式里独树一帜，这也正是理解四要素各自角色的捷径。
