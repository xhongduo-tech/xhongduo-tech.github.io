## 为什么从「偏好」开始

到目前为止，ε-贪心和 UCB 走的是同一条路线：**先估计动作价值 $Q(a)$，再按价值选动作**。这一节换一种世界观：根本不估计价值，而是直接学习每个动作的**偏好（preference）**——一个只决定「被选概率大小」的数。动作之间谁更优，由它们的偏好相对大小决定，而不是由绝对数值决定。

这条路有两个重要理由。其一，它把「选择」这件事做成了**概率分布**：动作被选中的概率与偏好的指数成正比，探索是「渐进的」而非「一刀切的」。其二，也是更重要的——**偏好 + 指数分布 + 梯度上升**这个组合，正是第十三篇策略梯度方法的雏形。今天你在两只手臂的老虎机上看到的更新规则，将来会原封不动地长成 REINFORCE、Actor-Critic 乃至 PPO 的骨架。<span class="marginnote">Softmax 并不陌生：第三级《深度学习基础》里多分类输出的就是它，配合交叉熵损失做梯度下降；本节只是把它当作「策略」来用——输出是动作概率，训练目标是让期望奖励最大。</span>

## 1 动作偏好与 Softmax 策略

给每个动作 $a$ 维护一个偏好 $H_t(a)$，$t$ 时刻按 **softmax 分布（也叫 Gibbs 分布 / Boltzmann 分布）** 选动作：

$$\Pr\{A_t = a\} \doteq \frac{e^{H_t(a)}}{\sum_{b=1}^k e^{H_t(b)}} = \pi_t(a)$$

这里 $\pi_t(a)$ 读作「时刻 $t$ 的策略选择动作 $a$ 的概率」。两个关键性质：

- **只有相对偏好有意义**。给所有 $H_t(a)$ 同时加 1000，分子分母同乘 $e^{1000}$，概率分布一个数都不变。<span class="marginnote">这有点像神经网络的 logits：预测只关心各类别得分的高低差，而不关心它们的绝对大小。所以偏好本身没有「单位」，它的尺度与步长 $\alpha$ 是绑在一起被调出来的。</span>
- **分布随偏好差「平滑地」变化**。若两个动作偏好相等，各占一半；若一个远超另一个，分布趋于把概率全给胜者。控制的不是「要不要探索」的开关，而是「概率如何倾斜」的程度。

**重点：softmax 与 ε-贪心的差别是「连续 vs 离散」。** ε-贪心在「贪心」与「均匀随机」之间硬切换；softmax 给每个动作一个介于 0 和 1 之间的概率，偏好越高概率越大——探索被「分摊」到所有动作上，而不是一次只给一个随机动作。

## 2 随机梯度上升：更新规则与直觉

偏好怎么学？Sutton & Barto 给出的更新规则是：在第 $t$ 步选了动作 $A_t$、拿到奖励 $R_t$ 之后，

$$H_{t+1}(A_t) = H_t(A_t) + \alpha\left(R_t - \bar{R}_t\right)\left(1 - \pi_t(A_t)\right)$$

$$H_{t+1}(a) = H_t(a) - \alpha\left(R_t - \bar{R}_t\right)\pi_t(a), \qquad \forall a \neq A_t$$

其中 $\alpha > 0$ 是步长，$\bar{R}_t$ 是到时刻 $t$ 为止**所有奖励的平均值**（用增量式更新在线计算），充当**基线（baseline）**。

把直觉翻译成一句话：**「这次拿到的奖励，比平时好还是坏？」** 若 $R_t - \bar{R}_t > 0$（高于平均），就奖励被选中的动作——提高 $H_t(A_t)$、压低其他动作；若低于平均，则反过来惩罚它。注意两个式子加起来总和为零：提高被选动作的量 $\alpha\delta(1-\pi)$，恰好等于压低其他动作的总量 $\alpha\delta\pi$——**偏好总和守恒**，softmax 分布也因此自动保持归一化，不需要额外处理。<span class="marginnote">「与平均比」这个动作极端重要：奖励是 +1 还是 +1000，绝对尺度千差万别，但「高于基线多少」是相对的。基线把奖励从「绝对数值」翻译成「相对好坏」，让同一组步长在不同任务里都能工作。</span>

## 3 公式解析：为什么这是「梯度」上升

方法的名字里有「梯度」，它真的是在做梯度上升。目标函数是期望奖励：

$$\mathbb{E}[R_t] = \sum_{x} \pi_t(x)\, q_*(x)$$

即「按当前策略分布，对每个动作的真实价值加权平均」。我们想知道：**把某个偏好 $H_t(a)$ 拨大一点，期望奖励会上升还是下降？** 也就是求梯度 $\dfrac{\partial \mathbb{E}[R_t]}{\partial H_t(a)}$。三步拆解：

- **第一步，softmax 的求导恒等式**。对 $\pi_t(x) = e^{H_t(x)} / \sum_b e^{H_t(b)}$ 关于 $H_t(a)$ 求导，得到一个漂亮的结果：

$$\frac{\partial \pi_t(x)}{\partial H_t(a)} = \pi_t(x)\left(\mathbf{1}_{x=a} - \pi_t(a)\right)$$

它说：偏好 $H_t(a)$ 变化对概率 $\pi_t(x)$ 的影响，正比于「$x$ 是不是 $a$」减去「$a$ 当前的概率」——自己受益、对手受损，且整体总和为零（这正是上一节「总和守恒」的微积分版本）。

- **第二步，把梯度写成一个期望**。把恒等式代入 $\partial\mathbb{E}[R_t]/\partial H_t(a)$，整理后：

$$\frac{\partial \mathbb{E}[R_t]}{\partial H_t(a)} = \mathbb{E}\left[\left(R_t - \bar{R}_t\right)\left(\mathbf{1}_{A_t = a} - \pi_t(a)\right)\right]$$

注意这里 $\bar{R}_t$ 出现了——**任何与动作无关的常数 $b$ 都可以当基线**，因为 $\mathbb{E}[\mathbf{1}_{A_t=a} - \pi_t(a)] = 0$，乘上常数 $b$ 后期望贡献为零，不改变梯度方向。

- **第三步，用单次样本代替期望：随机梯度上升**。期望没有解析表达式（$q_*$ 未知），但我们可以用「这一步真实发生的 $(A_t, R_t)$」当作无偏样本，于是得到：

$$H_{t+1}(a) = H_t(a) + \alpha\left(R_t - \bar{R}_t\right)\left(\mathbf{1}_{A_t = a} - \pi_t(a)\right)$$

把它拆回 $\mathbf{1}_{A_t=a}$ 取 1 或 0 两种情形，恰好就是上一节的 (2.12)(2.13) 两个式子。**这就是随机梯度上升（stochastic gradient ascent）：每步朝「真实样本」给出的梯度方向迈一小步。**

**重点：这条推导是第十三篇策略梯度定理的微缩版。** 这里我们恰好知道 $q_*$（老虎机的真值），所以梯度是干净的；在完整 RL 里 $q_*$ 未知，只能估计，于是策略梯度定理要用「价值估计」代替 $q_*$、并沿整条轨迹累积——但骨架一模一样：**性能对策略参数求梯度，再用随机样本近似，沿梯度上升。**

## 4 基线的作用与易错辨析

**辨析｜易错点：基线改变「期望更新方向」吗？** 不改变。由上面第二步，任何常数 $b$ 都满足 $\mathbb{E}[(\mathbf{1}_{A_t=a} - \pi_t(a)) b] = 0$，所以期望意义上的梯度与 $b$ 无关。那基线有什么用？**方差。** 奖励可能是 $+1$ 或 $+1000$，不减去基线，更新的随机波动量级天差地别，一个步长很难同时适配；减去基线后，更新只随「高于/低于平均」而正负变化，方差被大幅压缩，步长才稳定。

- 没有基线（$\bar{R}_t = 0$）：期望方向不变，但方差巨大、步长难调——尤其当所有奖励都是正数时，更新会「只加不减」，偏好被推向极端。
- 用常数基线 $b$（比如固定 5）：依然无偏，但方差压缩效果不如「随经验更新的平均奖励」好。经验平均 $\bar{R}_t$ 是最常用的选择。

**辨析｜易错点：softmax 的「温度」去哪了？** 统计力学里的 Boltzmann 分布常写成 $e^{H/\tau}$，$\tau$ 是温度。本节把它并进了偏好与步长的尺度：偏好整体放大 $\Leftrightarrow$ 温度降低、分布变尖。所以**不要试图在偏好上额外套温度参数**——那会与 $\alpha$ 和 $H$ 的初始尺度纠缠不清。

举个手算例子定个性：两臂老虎机，某时刻 $\pi_t(A_t) = 0.6$，奖励高于基线（$\delta = R_t - \bar{R}_t > 0$）。则 $H_t(A_t)$ 增加 $0.4\alpha\delta$，另一个动作 $H_t$ 减少 $0.6\alpha\delta$——被选动作与其余动作此消彼长，总量守恒。若奖励低于基线，则方向相反，被选动作被「泼冷水」。

与 ε-贪心、UCB 相比，梯度老虎机在动作偏好差异很大的问题上常表现更好，因为它把「概率的倾斜程度」本身也纳入了学习——而在非平稳环境下，用常数 $\alpha$ 持续追踪即可，与上一节结论一致。

## 5 小结

- **梯度老虎机**：不估计价值，直接学习动作偏好 $H_t(a)$，按 softmax 分布 $\pi_t(a) = e^{H_t(a)}/\sum_b e^{H_t(b)}$ 选动作。
- **更新规则**：被选动作 $H \mathrel{+}= \alpha(R_t-\bar{R}_t)(1-\pi_t(A_t))$，其余动作等量反向扣减——总和守恒，分布自动归一化。
- **本质是随机梯度上升**：目标 $\mathbb{E}[R_t]$ 对偏好求梯度，用单次样本替代期望；softmax 的求导恒等式 $\partial\pi_t(x)/\partial H_t(a) = \pi_t(x)(\mathbf{1}_{x=a}-\pi_t(a))$ 是推导的心脏。
- **基线只压方差，不偏方向**：任何常数基线在期望意义上不改变梯度方向，但把奖励从绝对尺度翻译成「相对好坏」，方差大减。
- **它通往策略梯度**：第十三篇的策略梯度定理是本节「梯度 + 随机样本」在完整 RL 上的推广。
- 探索是「连续的」：偏好差大则分布尖，差小则分布平，没有 ε 那样的硬开关。

在下一节，我们给老虎机补上最后一个缺失的维度：**情境**。同一个动作在不同情境下好坏不同，于是学习目标第一次从「选一个动作」变成「学一张情境→动作的映射」——这是通往第3章马尔可夫决策过程的关键一步。
