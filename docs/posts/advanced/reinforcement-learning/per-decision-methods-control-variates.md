## 为什么采样比乘积是个「粗糙的锤子」

上一课的离策略 n步学习把整段回报乘上采样比乘积 $\rho_{t+1:t+n-1}$。这能保证期望正确，但它有个笨拙之处：**如果 $\rho_t = 0$（目标策略永远不会选这个动作），整段回报被乘成 0，这次经验被彻底浪费**；而 $\rho_t$ 很小时，回报被压成一小撮，更新近乎无意义。更糟的是，$\rho_t$ 与回报相乘的方差远大于两者各自方差的直觉之和。**每决策方法（per-decision method）** 把「整段乘比」拆成「每一步各乘各的比」，再配上**控制变量（control variate）**——一个期望为零、却能把方差削平的量——让离策略 n步学习在 $\rho$ 极端时也保持稳定。<span class="marginnote">控制变量的思想来自蒙特卡洛方差削减：若 $\mathbb{E}[C]=0$，则 $X + C$ 与 $X$ 同期望、可方差更小。这里把「$-\rho$ 乘估计值」配一个「$+\rho$ 乘估计值」的相反项，让极端权重被中和。</span>

## 1 每决策的递归回报：一次一个 ρ

先回顾 n步回报的递归形式（对 $t < h < T$）：

$$
G_{t:h} \;=\; R_{t+1} + \gamma\, G_{t+1:h}, \qquad G_{h:h} = V_{h-1}(S_h)
$$

在离策略情形，朴素的做法是「每一步递归都乘 $\rho_t$」，于是当 $\rho_t$ 为 0 时整段归零。**每决策方法用当前估计做「替补」**，把更新改为：

$$
G_{t:h} \;=\; \rho_t\big(R_{t+1} + \gamma\, G_{t+1:h}\big) + (1 - \rho_t)\, V_{h-1}(S_t)
$$

理解这一式子的关键是「替补」语义：$\rho_t$ 是「这段轨迹在目标策略下是否该被信」的开关。$\rho_t=1$ 时式子退回普通的递归回报；$\rho_t=0$ 时目标恰好等于当前估计 $V(S_t)$，更新量为零——**目标策略从不会走这条路，那就维持原判，而不是把价值往下拽**。<span class="marginnote">这与朴素加权的天壤之别：朴素版在 $\rho=0$ 时把回报归零、朝 0 猛拉一步（灾难性的错误更新）；控制变量版把目标设定为「维持不变」，完全不扰动估计。</span>由于 $\mathbb{E}[\rho_t] = 1$，项 $(1-\rho_t)V_{h-1}(S_t)$ 的期望为零，它不改变目标的无偏性。

## 2 动作价值形式：第一个动作不参与加权

预测（状态价值）的每决策方法里，$\rho_t$ 从第一步就乘上了。但控制（动作价值）有特殊约定：**被学习的动作 $A_t$ 本身不参与重要性加权**——奖励 $R_{t+1}$ 与下一状态 $S_{t+1}$ 是「跟着 $A_t$ 走的」，必须全额计入。于是动作价值版本的递归是：

$$
G_{t:h} \;=\; R_{t+1} + \gamma\Big(\rho_{t+1}\, G_{t+1:h} \;+\; \bar{V}_{h-1}(S_{t+1}) - \rho_{t+1}\, Q_{h-1}(S_{t+1}, A_{t+1})\Big)
$$

其中 $\bar{V}_{h-1}(S_{t+1}) = \sum_a \pi(a \mid S_{t+1}) Q_{h-1}(S_{t+1}, a)$ 是**目标策略**在 $S_{t+1}$ 的期望价值，递归底 $G_{h:h} = \bar{V}_{h-1}(S_h)$。<span class="marginnote">这一形式的内核是「用 $\bar{V}$ 做控制变量」：当 $\rho_{t+1}=1$，括号里变成 $\bar{V} + (G - Q)$，是普通递归；当 $\rho_{t+1}=0$，括号变成 $\bar{V}(S_{t+1})$——目标策略的期望值，完全合理的替身。$\rho$ 被「夹」在 $G$ 与 $Q$ 之间，不再能毁掉整段回报。</span>

## 3 公式解析：控制变量如何既不偏又不抖

$$
\underbrace{\rho_t\,(R_{t+1} + \gamma G_{t+1:h})}_{\text{原估计量}} \;+\; \underbrace{(1 - \rho_t)\, V_{h-1}(S_t)}_{\text{控制变量}}
$$

- **第一步，认主角**：第一项是朴素的重要性加权回报。它无偏，但方差被 $\rho_t$ 的极端值放大。
- **第二步，认控制变量**：第二项 $(1-\rho_t)V_{h-1}(S_t)$ 里，$V_{h-1}(S_t)$ 是**已知的、低方差的量**（当前估计），$(1-\rho_t)$ 的期望为零。整体期望为零，不引入偏差。
- **第三步，看方差**：当 $\rho_t$ 大时，第一项大、第二项负向大，两者抵消出温和的目标；当 $\rho_t=0$，第一项为零、第二项等于 $V(S_t)$，目标即「维持原判」。**控制变量把 $\rho$ 的极端波动从「目标」里剥离出来，放进一个期望为零的校正项里，方差被压平**。<span class="marginnote">对比「加零项不改变期望」这一统计事实：控制变量的全部功夫就是选好那个「期望为零、却与噪声强相关」的项，让它吸收方差。这里 $V(S_t)$ 与回报强相关，于是能高效吸走 $\rho_t$ 引入的抖动。</span>

这套递归的价值不只是方差：**它是第8章树回溯（tree backup）、以及第12章资格迹统一视角的数学骨架**。树回溯把「$\rho$ 与 $Q$ 的夹心」换成「目标策略的期望 $\bar{V}$」，把离策略学习彻底变成无重要性采样的形式。

## 4 易错点辨析

**辨析｜易错点：** 把「控制变量」与「基线（baseline）」混为一谈。控制变量加在**目标（回报）**上、期望为零、目的是降低目标本身的方差；基线减在**梯度**上、期望为零、目的是降低策略梯度更新的方差。两者同属「加期望为零项」的家族，但作用对象与出现的章节不同——基线要到第13章 REINFORCE 才登场。

**另一个易错点**：在动作价值版本里把 $\rho_t$ 也乘到 $R_{t+1}$ 上。**$R_{t+1}$ 永远不乘 $\rho_t$**——它是被学习动作 $A_t$ 的直接结果，属「全额计入」部分。重要性采样只作用于 $A_{t+1}, A_{t+2}, \dots$ 这些「额外」动作。

**第三个易错点**：忘记 $\mathbb{E}[\rho_t] = 1$ 这个关键前提。它成立是因为 $b$ 与 $\pi$ 都定义在同一状态空间且 $\rho_t = \pi(A_t|S_t)/b(A_t|S_t)$ 在 $b$ 下取期望。若行为策略在某状态与目标策略的支撑集不一致（$b$ 的概率为零而 $\pi$ 非零），期望性质破裂——这正是第11章离策略函数逼近发散的引信。

## 5 小结

- **每决策方法**：把「整段乘 $\rho$」拆成「每步各乘各的 $\rho$」，配合当前估计做替补。
- **控制变量**：$(1-\rho_t)V(S_t)$ 期望为零、方差相关，把 $\rho$ 的极端波动从目标中剥离，不改变无偏性。
- **状态值形式**：$G_{t:h} = \rho_t(R_{t+1}+\gamma G_{t+1:h}) + (1-\rho_t)V_{h-1}(S_t)$。
- **动作值形式**：$R_{t+1}$ 不乘 $\rho$，$\rho$ 被夹在 $G$ 与 $Q$ 之间，配 $\bar{V}$ 做控制变量。
- 这是**树回溯**与**统一算法 n步 Q(σ)** 的数学骨架——下一课两者登场。

在下一节，我们用「控制变量」的终点站去换一棵**树**：n步树回溯算法把重要性采样比彻底请出离策略学习，而 n步 Q(σ) 用一个开关把 Sarsa、期望 Sarsa 与树回溯统一成一条谱系。
