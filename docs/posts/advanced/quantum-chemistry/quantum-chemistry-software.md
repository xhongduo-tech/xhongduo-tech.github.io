## 为什么从程序与软件开始

二十篇方法讲完了——但方法的最终归宿是**程序**。量子化学从纸面推导走向实际应用，靠的是 Gaussian、ORCA、Pyscf 这些软件把每一条方程变成可运行的代码。这一篇作为专题收官，讲**主流量子化学软件的生态**：它们各自擅长什么、一份输入文件的结构是什么、以及如何避免实际计算中最常见的坑。

这一篇不讲具体菜单操作（那些看手册），而讲**软件世界的「地图」**：哪个程序解决哪类问题、如何设计一次可靠的计算流程、以及怎么读懂输出文件里的关键量。

## 1 主流软件生态：选程序看什么

| 程序 | 授权 | 强项 | 常用场景 |
| --- | --- | --- | --- |
| Gaussian | 商业 | 有机化学全能、复合方法（G4/CBS）、QM/MM 友好 | 有机反应、光谱、热化学 |
| ORCA | 学术免费 | 开壳层、过渡金属、EOM-CC、RI 加速 | 无机/金属、激发态、高精度 |
| Psi4 | 开源 | 高精度波函数方法、Python API | 方法开发、教学 |
| Pyscf | 开源 | Python 灵活、方法开发、机器学习集成 | 研究型、DFT/CC 原型 |
| Q-Chem | 商业 | 大规模 DFT、ADC/RI、生物大分子 | 大体系、激发态 |
| VASP/Quantum ESPRESSO | 商业/学术 | 周期体系、能带、表面催化 | 材料、表面 |
| CP2K | 开源 | 从头 MD、QM/MM、大体系 | 液态、生物、界面 |

<span class="marginnote">选择逻辑：<strong>有机分子 + 常规性质 → Gaussian/ORCA；金属/开壳层 → ORCA（对开壳层 DFT 的稳健性更好）；方法开发 → Psi4/Pyscf；周期材料 → VASP/QE/CP2K</strong>。学术界的趋势是 ORCA 与 Pyscf 增长最快——免费 + 功能全 + 可编程是主因。</span>

**辨析｜易错点：** 不同程序对同一方法的实现细节（积分精度、SCF 收敛判据、基组定义）有差异，**跨程序比较结果要谨慎**。引用计算必须注明「程序 + 方法 + 基组 + 版本」，如「Gaussian 16 Rev.C.01, ωB97X-D/def2-TZVP」——这是计算化学论文的硬规范。

## 2 输入文件的结构：一次计算的解剖

一份典型量子化学输入文件（以 Gaussian 为例），是「关键词 + 分子结构 + 任务」三明治：

```text
#p ωB97X-D/def2-TZVP opt freq  temperature=298.15

title line: water optimization

0 1
O     0.000000    0.000000    0.117300
H     0.000000    0.757200   -0.469200
H     0.000000   -0.757200   -0.469200
```

逐段拆解：

- **第 1 行 `#p` 关键词行**：指定**方法（ωB97X-D）/基组（def2-TZVP）/任务（opt 优化、freq 频率）**。`#p` 表示打印完整输出。
- **标题行**：自由文本，说明这次算什么。
- **电荷与多重度**：`0 1` 表示**总电荷 0、多重度 1**（单重态）。这是最容易写错的地方——多重度算错，结果全错。
- **坐标块**：原子种类 + 坐标（内坐标、直角坐标或 Z 矩阵）。

<span class="marginnote">多重度 = 未配对电子数 × 2 + 1。闭壳层单重态是 1；一个自由基是 2；三重态是 3。<strong>写输入前先画 Lewis 结构数电子</strong>——多重度写错是新手最高频的错误，而程序常常「照算不误」给出一堆没意义的数。</span>

**ORCA 的输入风格**类似但语法不同（用 `!` 引导方法关键词、`%` 块配置细节），底层引擎是自主的；Pyscf 则是**纯 Python**——方法、基组、积分全是对象，脚本式驱动，特别适合「批处理 + 分析」。

## 3 一个可靠计算流程的模板

把前二十篇的知识落成操作流程，一套「不会错」的模板：

1. **结构准备**：从数据库/文献取初始几何，或用手画草图粗优化（MM）；
2. **方法选择**：按体系定（有机→ωB97X-D/PBE0-D3；金属→ORCA 开壳层；高精度→CCSD(T)）；
3. **几何优化**：`opt`，检查收敛（四重判据）；若虚频 → 扰动重优化；
4. **频率分析**：`freq`，确认无虚频（极小）或恰一个虚频（过渡态）；
5. **单点/高精度**：在优化结构上做 CCSD(T) 单点 + 基组外推；
6. **性质计算**：NMR（`nmr`）、UV-Vis（`td`）、IRC（反应路径）、溶剂化（`scrf`）按需加；
7. **数据报告**：注明方法/基组/溶剂/温度，报告能量要**统一单位**（Hartree、kcal/mol、eV 换算清楚）。

<span class="marginnote"><strong>单位换算陷阱</strong>：1 Hartree = 627.5095 kcal/mol = 27.2114 eV。能量差（势垒、反应能）通常用 kcal/mol 报告，单点能用 Hartree，激发能用 eV。<strong>跨单位直接相减是论文里的低级错误</strong>——换算清楚再比较。还要注意 Gaussian 输出的能量默认不含核动能修正，与实验值比较时要加 ZPE 与热校正。</span>

## 4 公式解析：SCF 收敛与加速的「工程学」

软件背后的工程细节，决定了一次计算能否收敛。SCF 迭代的收敛判据与加速是每份输入都会遇到的：

$$\left| E^{(n+1)} - E^{(n)} \right| < \tau_E, \qquad \left\| \mathbf{P}^{(n+1)} - \mathbf{P}^{(n)} \right\| < \tau_P$$

- **$\tau_E, \tau_P$**：能量与密度矩阵的收敛阈值（默认约 $10^{-8}$ 与 $10^{-6}$）；
- **DIIS（直接反演迭代子空间）**：用最近几次的误差向量外推新 Fock/密度——**SCF 加速的标准武器**；
- **阻尼（damping）**：新密度与旧密度混合，抑制振荡；
- **二阶 SCF（SOSCF）**：对难收敛体系（开壳层、金属）用牛顿型更新。

**SCF 不收敛怎么办**：从易到难依次尝试——换初猜（如用上一构型的密度作为初猜）、加强阻尼、开 DIIS、用混合占位（smearing）、检查是否多重度写错、或者体系本身有简并（此时要换方法而非硬算）。<span class="marginnote">对过渡金属/开壳层体系，<strong>SCF 难收敛是常态而非异常</strong>。常用「独门绝技」：用<strong>非限制</strong>（unrestricted）而非限制方法、用金属离子的低自旋态初猜、或先算一个闭壳层阴离子再改回来。ORCA 对这类体系的稳健性口碑好，正源于它在初猜与收敛控制上更精细。</span>

**双电子积分的工程**：前面说过 $O(K^4)$ 的双电子积分是瓶颈。软件用**积分筛选**（远距离积分近似为零）、**密度拟合/RI**（把四中心积分拆成三中心）、**对称性**（利用分子点群）大幅加速。**RI 近似（resolution of identity）**是现代 DFT/MP2 里几乎必开的选项：`RIJCOSX`（ORCA）、`IOp`（Gaussian）——精度损失极小，速度提升显著。

## 5 读懂输出：三个必须看的关键量

程序输出几万行，但重要的量就那么几个：

1. **SCF 收敛信息**：看 `converged` 标志；不收敛警告必须处理，不能无视。
2. **能量**：`SCF Done: E(RωB97X-D) = -76.xxx Hartree`——记下方法、能量值与单位。
3. **频率/虚频**：`Frequencies -- 120.5, 352.1, 3685.4`；**有负值即虚频**，判断极值性质。

<span class="marginnote">除了能量，<strong>偶极矩、HOMO/LUMO 能级、Mulliken/ESP 电荷、自旋密度</strong>也是常读的量。开壳层体系还要看 <strong>$\langle S^2 \rangle$</strong>（自旋平方期望值）：非限制方法里它若明显偏离理论值（如单重态应接近 0、三重态应接近 2），说明存在<strong>自旋污染</strong>，结果不可信——需换方法（如用投影自旋方法或 ROHF）。</span>

**辨析｜易错点：** 新手最常犯的三个「程序错误」——(1) 多重度写错；(2) 基组拼写错误（`def2-TZVP` vs `def2tzvp`，程序对大小写敏感）；(3) 忽略了**基组重叠误差（BSSE）**：小基组下两个片段会互相「借用」对方的基函数，导致结合能虚高。算弱相互作用务必做 BSSE 校正（counterpoise）或直接用弥散基组。

一个实用的「提交前检查清单」：确认电荷与多重度、确认方法/基组拼写、确认是几何优化还是单点、确认溶剂模型是否开启、确认是否需要色散校正（D3）、最后看一眼内存与磁盘配额——一次认真核对，能省去一整夜的无效计算。

## 6 小结

- 软件生态按问题分：**Gaussian/ORCA 分子计算、VASP/QE 材料计算、Psi4/Pyscf 方法开发**。
- 输入文件 = **关键词行 + 标题 + 电荷/多重度 + 坐标**；多重度写错是最常见错误。
- 可靠流程：**结构 → 方法/基组 → 优化 → 频率验证 → 高精度单点 → 性质**，全程注明规范。
- SCF 收敛问题用 **DIIS/阻尼/SOSCF** 应对；难收敛体系先查多重度与初猜。
- **RI/积分筛选**是提速关键；读输出认准 **SCF 收敛、总能量、虚频、$\langle S^2\rangle$** 四个量。
- 单位换算（Hartree/kcal/mol/eV）与 BSSE 校正是严谨性的基本要求。

## 7 小结（专题收束）

本专题从量子力学的公设出发，走到软件的实操——二十一节的路径正是「学完量子化学」的完整轨迹：**公理 → 近似方法 → 电子相关 → 势能面 → 应用 → 工具**。回头再看第一节那句「量子化学 = 用量子力学解分子」，此刻你已经知道：解的过程是 BO 近似、HF/DFT 与相关方法的三层接力，解的落点是一个个可计算的量——能量、结构、光谱、速率。

在下一站，你的知识将不再限于「算一个分子」：**计算化学（advanced/computational-chemistry）**会把这里学到的方法学推向算法与程序实现——从数值积分、几何优化算法，到量子化学的机器学习加速，那是量子化学「如何被真正算出来」的另一半故事。
