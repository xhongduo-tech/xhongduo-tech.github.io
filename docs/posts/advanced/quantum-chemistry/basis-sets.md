## 为什么从基组理论开始

HF 方程落到计算机上，全靠 LCAO 展开：把轨道 $\phi_i$ 写成一堆基函数 $\chi_\mu$ 的线性组合。但「一堆基函数」具体选什么？基函数越多，精度越高，但计算量也越大——**基组（basis set）就是在精度与成本之间的工程取舍**。这一篇要讲清楚：为什么有的基组叫 STO-3G、6-31G、cc-pVDZ？这些名字背后的物理和约定是什么？选基组时有哪些坑？

基组不只影响 HF，它定义了所有电子结构计算的「分辨率」：**任何方法的精度上限，都是「在该基组下的完备极限」**。基组选小了，再好的方法（CCSD(T)）也算不出正确结果——「基组完备性」是量子化学里反复出现的一条底线。

## 1 理想的单电子基：Slater 与 Gaussian

氢原子精确解给出的 1s 轨道形如 $e^{-\zeta r}$——指数衰减，在原子核处有一个「尖点」。这种函数叫 **Slater 型轨道（STO）**：

$$\chi^{\text{STO}}_{\zeta n l m}(r, \theta, \phi) = N r^{n-1} e^{-\zeta r} Y_{lm}(\theta, \phi)$$

STO 在物理上很「对」，但在数学上很麻烦：涉及三中心、四中心的**双电子积分**无法解析计算。<span class="marginnote">Slater 轨道指数衰减 $e^{-\zeta r}$ 与氢原子波函数一致，但其双电子积分 $\int\int \chi_a\chi_b \frac{1}{r_{12}} \chi_c\chi_d \, d\tau$ 在含多个原子核的分子里几乎无法解析求值——这是 1950 年代量子化学「卡壳」的直接原因。</span>

**Gaussian 型轨道（GTO）** 拯救了这一切：

$$\chi^{\text{GTO}}_{\alpha l m} = N x^a y^b z^c e^{-\alpha r^2}$$

高斯函数的奇妙性质是：**两个高斯的乘积还是高斯**。高斯函数可分离为 $e^{-\alpha x^2}e^{-\alpha y^2}e^{-\alpha z^2}$，任意两个（哪怕中心不同）高斯的乘积都能化简为中心在中间某点的高斯。这使得多中心双电子积分可以**解析计算**——量子化学由此真正可计算化。

## 2 从 GTO 到收缩基组

一个高斯在原点处没有尖点、衰减又太快，单个高斯模拟原子的 1s 轨道效果很差。解法是**把多个高斯「收缩」成一个基函数**（contraction）：

$$\chi^{\text{CGTO}}(\mathbf{r}) = \sum_{k} d_k \, g_k(\mathbf{r})$$

其中 $g_k$ 是**原始高斯**（primitive Gaussian，指数 $\alpha_k$），$d_k$ 是**收缩系数**。这样既保留高斯的可计算性，又模拟 STO 的形状。<span class="marginnote">固定收缩系数后，整个收缩函数在计算中被当作<strong>一个</strong>基函数对待，从而把「用多个高斯表达一个轨道」的成本从「每个高斯独立」降为「一个基函数」。这是 Pople 基组族（如 6-31G）的设计核心。</span>

基组名称里的数字是**收缩方案的编码**。以 6-31G 为例：

- **6**：内层（core）轨道用 6 个原始高斯收缩成 1 个基函数；
- **31**：价层轨道用「3 个高斯的收缩」+「1 个高斯」两条基函数，形成**双 ζ（double-zeta）**——价层有「一大一小」两条，允许轨道伸缩。

## 3 极化函数、弥散函数与基组的层次

基组要灵活地描述电子云形变，光有「大小」不够，还要补两类特殊函数：

- **极化函数（polarization）**：角动量比价层高一级的函数（如氢的 p 函数、碳的 d 函数），允许轨道在化学环境里「变形」。记法：6-31G(d,p) 或 6-31G**，d 加在重原子上、p 加在氢上。
- **弥散函数（diffuse）**：指数 $\alpha$ 很小的函数，延展到远离核的区域。记法：6-31+G(d)，+ 表示加重原子上的弥散 s、p 函数；++ 则连氢也加。

| 基组 | 层次 | 用途 |
| --- | --- | --- |
| STO-3G | 极小基（minimal） | 定性、大体系粗筛 |
| 3-21G、6-31G | 双 ζ | 中等精度、几何优化 |
| 6-31G(d,p) | 双 ζ + 极化 | 有机化学常规选择 |
| 6-311+G(d,p) | 三 ζ + 极化 + 弥散 | 阴离子、弱相互作用 |
| cc-pVDZ / cc-pVTZ | 相关一致（correlation-consistent） | 高精度、CC 计算 |

<span class="marginnote">Dunning 的 <strong>cc-pVnZ</strong>（correlation-consistent polarized valence）系列专为电子相关方法设计：随着 n 增大（D→T→Q→5），函数按「角动量层」一致增加，能量系统地向完备极限收敛。它是 CC/MP 计算的首选，也是「外推完备基组极限」的标准工具。</span>

**辨析｜易错点：** 「基组越大越好」这句话需要限定。基组增大到一定程度后，数值上会遇到**近线性依赖**（基函数几乎线性相关，重叠矩阵接近奇异，SCF 不稳定）。而且基组与方法是**耦合**的：对小基组，HF 与高精度方法（如 CCSD(T)）差距巨大；随基组变大，方法间差异才真正显现。正确的做法是同时升级基组与方法，并做**基组完备性外推**。

## 4 公式解析：为什么基组完备性如此关键

HF（或任何方法）的能量，在基组内是精确的，但基组本身只是完备空间的有限近似。定义**基组完备极限下的能量** $E_\infty$，则有限基组能量 $E_K$ 与它的差为：

$$E_K - E_\infty = -A\, e^{-\alpha K} \quad \text{或} \quad E_K = E_\infty + \frac{B}{K^3}$$

其中 $K$ 是表征基组大小的量（如 cc-pV$K$Z 的 $K$）。拆解这条外推公式：

- **指数形式**（对 cc 系列更适用）：基组误差随 $K$ **指数衰减**，因为每个新角动量层都被一致补上。
- **幂律形式**：对部分基组族误差按 $1/K^3$ 衰减，$K$ 每升一级，误差缩到约 $1/8$。
- **外推操作**：算两个相邻基组（如 cc-pVTZ 与 cc-pVQZ）的能量 $E_T, E_Q$，联立方程解出 $E_\infty$——这叫 **CBS 外推**（complete basis set extrapolation）。

<span class="marginnote">为什么要费劲外推？因为关联能（如 CCSD(T)）对基组极敏感：用 cc-pVDZ 算的关联能误差常达 10% 以上，而 HF 能量对基组相对不敏感。<strong>想要可与实验媲美的能量，几乎必须做基组完备性外推</strong>——这是高精度量子化学的行业惯例。</span>

## 5 基组选择的工程智慧

实际计算中的基组选择，遵循一条「**方法—基组匹配**」的原则：

1. **先定方法的精度目标**：HF/DFT 用中等基组即可；CCSD(T) 至少 cc-pVTZ。
2. **根据体系特性补函数**：阴离子、激发态、弱键（氢键、范德华）需要**弥散函数**；弯曲的电子云需要**极化函数**。
3. **用内层近似控制成本**：重原子的内层电子几乎不参与化学，用**有效核势（ECP）**或冻结芯近似替换，计算量大降且精度几乎无损。
4. **检查基组收敛**：换相邻档基组（如 TZ→QZ）看能量变化，若 < 目标精度（如 1 kJ/mol），基组够了。

<span class="marginnote">有效核势（ECP，也叫赝势）还有<strong>相对论修正</strong>的妙用：重元素（周期表第四周期以下）内层电子相对论效应显著，直接用全电子基组误差大；ECP 把内层相对论效应打包进势里，精度反而更高——这是过渡金属、镧系元素计算的通行做法。</span>

一套稳妥的默认配方（organic 分子、DFT）：**def2-TZVP 或 6-311+G(d,p)**；高精度单点：**cc-pVTZ → cc-pVQZ → CBS 外推**；阴离子或激发态：**+aug- 前缀的弥散基组**。

### 基组重叠误差（BSSE）与 counterpoise 校正

选基组时最容易踩的坑，是**基组重叠误差（basis set superposition error, BSSE）**。它发生在计算**两个片段的结合能**（如氢键、吸附、弱相互作用）时：小基组下，片段 A 会「借用」片段 B 的基函数来描述自己的电子，从而人为地降低 A 的能量、虚增结合强度。

$$E_{\text{bind}} = E_{\text{AB}} - E_{\text{A}} - E_{\text{B}} \quad (\text{偏大，因为 } E_{\text{A}}, E_{\text{B}} \text{ 被低估})$$

**修正方法——counterpoise（CP）校正**：在**完整超分子基组**下分别计算两个片段：

$$E_{\text{bind}}^{\text{CP}} = E_{\text{AB}}^{\text{AB}} - E_{\text{A}}^{\text{AB}} - E_{\text{B}}^{\text{AB}}$$

上标表示「用哪个基组」：$E_{\text{A}}^{\text{AB}}$ 是片段 A 在完整超分子基组（含 B 的基函数，但 B 的原子核不放置）下的能量。<span class="marginnote">BSSE 的大小随基组缩小而增大，随基组完备而趋于零——所以「大基组 + 弥散函数」本身就能抑制 BSSE。对小基组算弱相互作用，不做 CP 校正的误差可以比真实结合能还大；许多程序提供 `counterpoise` 关键词一键完成校正。</span>

**辨析｜易错点：** BSSE 与「基组不收敛」是两个不同的问题。BSSE 是**方法系统性偏向**（高估结合能），而基组不收敛是**精度未达标**。两者常同时出现，但修正手段不同：前者用 CP 校正，后者用增大/外推基组。

**一条底线原则**：无论选什么基组，都要在论文里写清「方法/基组」并做收敛检查。基组不是「越多越好」的黑箱旋钮，而是「精度与成本」的显式权衡——理解它的物理（收缩、极化、弥散），才能把它当工具而不是咒语。

## 6 小结

- 基组把轨道展开成基函数的线性组合；**GTO 的乘积仍为高斯**，使多中心积分可解析求解——量子化学可计算化的关键。
- **收缩**：多个原始高斯合成一个基函数，兼顾形状与效率；数字编码（6-31G）记录收缩方案。
- **极化函数**允许轨道变形，**弥散函数**覆盖远核区域；两者按需加入。
- **基组完备性**是精度天花板，需做 **CBS 外推**才能逼近极限；关联能对基组尤其敏感。
- 选基组讲究**方法—基组匹配**：先定方法精度，再补函数，重元素用 ECP，最后做收敛检查。
