## 为什么从交换相关泛函开始

上一篇的 Kohn-Sham 方程把全部未知量赶进了一个量：**交换相关能 $E_{xc}[\rho]$**。它的精确形式无人知晓，但物理学家用**近似阶梯**一层层逼近。这一篇介绍泛函的「雅各布天梯」（Jacob's ladder）——从最朴素的 LDA 到最精细的杂化泛函，每一级都往 $E_{xc}$ 里塞进更多的物理信息。

为什么值得花一整篇讲泛函？因为**DFT 的精度几乎完全由泛函决定**：同一个分子，不同泛函算出的反应能可能相差几到几十 kcal/mol。会选泛函，是量子化学家最重要的实用技能之一。

## 1 交换相关能的构成

交换相关能可以形式地分解为两部分：

$$E_{xc}[\rho] = E_x[\rho] + E_c[\rho]$$

- **交换能 $E_x$**：来自费米子反对称性，是「自旋平行电子之间的排斥」，对应 HF 里的交换项。它是 $E_{xc}$ 的**大头**（对多数体系约占 60–80%）。
- **相关能 $E_c$**：来自电子瞬时运动的关联，是 HF 里缺失的那部分。它小但至关重要，尤其对弱相互作用。

**严格条件**：任何泛函都应满足一些**精确约束**（exact constraints），例如：均匀电子气的交换能精确已知；$E_c \le 0$；自相互作用消除（self-interaction error 应为零）。泛函设计的艺术，就是「满足尽可能多的约束 + 拟合尽可能少的数据」。

<span class="marginnote">Perdew 有一句名言：「一条准绳，胜过千个拟合参数。」（a ladder with many rungs built on exact constraints beats a soup of fitted parameters.）物理约束让泛函有<strong>可迁移性</strong>——不依赖拟合数据的体系也能算准。拟合参数太多的泛函（如早期的 B3LYP 之外的许多经验泛函）在小分子上漂亮，但外推能力差。</span>

## 2 雅各布天梯：五级泛函

Perdew 提出用「雅各布天梯」比喻泛函从地面（HF 无关联）通向化学精度（FCI 精确）的五个台阶：

**第一级 LDA（局域密度近似）**：$E_{xc}^{\text{LDA}} = \int \rho(\mathbf{r}) \, \varepsilon_{xc}^{\text{unif}}(\rho(\mathbf{r})) \, d\mathbf{r}$。只依赖每一点的密度，取均匀电子气的交换相关能密度。对固体能带、金属是经典之选，但对分子会**系统性高估键能**（结合能过大、键长偏短）。<span class="marginnote">LDA 的交换能形式是 $\varepsilon_x^{\text{unif}} = -\frac{3}{4}\left(\frac{3\rho}{\pi}\right)^{1/3}$，源自均匀电子气的 Thomas-Fermi-Dirac 理论。尽管朴素，LDA 在固体物理里至今常用——因为固体的密度变化比分子平缓，LDA 的近似相对成立。</span>

**第二级 GGA（广义梯度近似）**：$E_{xc}^{\text{GGA}}[\rho] = \int \varepsilon_{xc}(\rho, \nabla\rho)\, d\mathbf{r}$，同时依赖密度**及其梯度**，能抓住密度不均匀带来的修正。代表：PBE、PW91、BLYP。GGA 比 LDA 更准，但**对弱相互作用仍然几乎无效**。

**第三级 meta-GGA**：再加入**动能密度** $\tau = \frac{1}{2}\sum_i|\nabla\phi_i|^2$，能部分处理自相互作用误差。代表：TPSS、SCAN。

**第四级 杂化泛函（hybrid）**：把**精确的 HF 交换**混入 DFT 交换，这是最重要的实用飞跃：

$$E_{xc}^{\text{hybrid}} = E_{xc}^{\text{GGA}} + a_x\left( E_x^{\text{exact}} - E_x^{\text{GGA}} \right)$$

$a_x$ 是混合系数。代表：**B3LYP**（$a_x = 0.20$，Becke 三参数混合）、**PBE0**（$a_x = 0.25$）、**ωB97X**（长程校正）。

**第五级 双杂化（double hybrid）**：除 HF 交换外，还混入 **MP2 级关联**。代表：B2PLYP、ωB97X-2。精度接近 CC，但成本也接近 MP2。

## 3 公式解析：B3LYP 的组成

B3LYP 是历史上使用最广泛的泛函，理解它的构成就理解了杂化泛函的一切：

$$E_{xc}^{\text{B3LYP}} = E_x^{\text{LDA}} + a_0(E_x^{\text{HF}} - E_x^{\text{LDA}}) + a_x(E_x^{\text{GGA}} - E_x^{\text{LDA}}) + E_c^{\text{VWN}} + a_c(E_c^{\text{LYP}} - E_c^{\text{VWN}})$$

其中 $a_0 = 0.20$、$a_x = 0.72$、$a_c = 0.81$ 是 Becke 用拟合确定的参数。逐项拆解：

- **$E_x^{\text{LDA}}$**：LDA 交换，作为基准；
- **$a_0(E_x^{\text{HF}} - E_x^{\text{LDA}})$**：混入 20% 的 HF 精确交换（$a_0 = 0.20$）——这是杂化泛函的核心动作，它部分消除了自相互作用误差；
- **$a_x(E_x^{\text{GGA}} - E_x^{\text{LDA}})$**：加上 72% 的 GGA 梯度修正交换；
- **$E_c^{\text{VWN}}$**：VWN 局域相关能作为基准；
- **$a_c(E_c^{\text{LYP}} - E_c^{\text{VWN}})$**：混入 81% 的 LYP 梯度相关。

<span class="marginnote">三个参数 $a_0, a_x, a_c$ 之所以取 0.20/0.72/0.81，是 Becke 当年对一组分子（原子化能、电离能、质子亲和能）拟合的结果。B3LYP 因拟合面广、对有机化学出奇地稳，成了二十年的「默认泛函」——尽管它的真实误差比后人测的要大。</span>

**辨析｜易错点：** 新手常以为「泛函越高级越准」。实际上：**杂化泛函对热化学更好，但对弱相互作用未必优于 meta-GGA；LDA 对固体能带很好但对分子键能很差**。没有万能泛函——这就是「选泛函」必须按体系定制的根本原因。

## 4 泛函的系统性病：自相互作用误差与离域化

所有实用泛函（尤其 LDA/GGA）都有一个著名缺陷：**自相互作用误差（self-interaction error, SIE）**。氢原子只有一个电子，交换能应精确抵消库仑项，但 LDA 不能，导致：

**离域化误差（delocalization error）**：泛函过度分散电子，低估电荷转移能量、高估扩展体系的导电性；
对自由基、色散、氢迁移反应垒的描述系统性偏差。

另一个大问题是 **色散相互作用（dispersion）**：LDA/GGA 完全不描述瞬时偶极关联，范德华作用几乎为零。**修正方法**：

**DFT-D**（Grimme 的半经验色散校正）：$E_{\text{DFT-D}} = E_{\text{DFT}} - \sum_{AB} f_{\text{damp}}(R_{AB}) \frac{C_6^{AB}}{R_{AB}^6}$，给 DFT 加上原子对色散项；
**VDW-DF**（非局域泛函）、**SCAN-rVV10** 等从头色散泛函。

<span class="marginnote">DFT-D 是工业界最实用的色散修正：它只加一个 $-\sum C_6/R^6$ 项（阻尼函数控制短程），成本几乎为零，却能把氢键、π 堆积、吸附能的误差降一个量级。<strong>任何涉及分子间相互作用或构象搜索的 DFT 计算，都应配 D3/D4 校正</strong>——这是今天的行业共识。</span>

## 5 如何选泛函：一张实用决策表

选泛函没有银弹，但有可操作的决策路径：

| 你要算什么 | 推荐泛函 | 理由 |
| --- | --- | --- |
| 有机分子热化学 | ωB97X-D、PBE0-D3 | 杂化 + 色散，系统误差小 |
| 弱相互作用/超分子 | ωB97X-D、SCAN-D4 | 色散处理关键 |
| 过渡金属配合物 | MN15、ωB97X-D | 开壳层、d 电子 |
| 固体能带 | PBE、SCAN | 周期体系、LDA/GGA 适用 |
| 激发态（TD-DFT） | CAM-B3LYP、ωB97X | 长程校正避免 CT 错误 |
| 大体系/生物分子 | BLYP-D3（快）或 PM6（半经验） | 成本优先 |

<span class="marginnote">长程校正泛函（CAM-B3LYP、ωB97X 族）在激发态与电荷转移问题上优于普通杂化泛函——因为它们把 HF 交换在<strong>长程</strong>比例逐渐升到 100%，纠正了 GGA 在长距离上的离域化误差。这是 TD-DFT 计算里最关键的选择之一。</span>

**通用建议**：默认起步 **ωB97X-D 或 PBE0-D3BJ**，做任何涉及分子间作用的体系必须带色散校正；对比两个不同族泛函（如 GGA 与杂化）看结果是否稳定，是廉价而有效的「泛函一致性检查」。

### 泛函设计中的「参数 vs 约束」之争

泛函世界里一直存在两种设计哲学：**经验拟合**与**物理约束**。

**经验拟合派**（如 B3LYP 的三参数、MN15 的多参数）：在分子数据库上拟合参数，小体系上精度高，但**外推能力差**——换一个数据库里没有的化学环境，可能突然失准；
**约束派**（如 SCAN、PBE）：满足尽可能多的**精确约束**（均匀电子气极限、渐近行为、自相互作用条件），参数少，**可迁移性好**，但可能在某些特定性质上不如拟合派。

<span class="marginnote">Perdew 的「准绳与拟合」之辩（Jacob's ladder 论文的著名论点）主张：约束是泛函「不出错」的保证，拟合是泛函「在数据内变准」的手段。今天的主流共识是<strong>两者结合</strong>——好的泛函（如 ωB97X-D）既满足关键约束，又用少量参数微调，才能兼顾精度与迁移性。这也是「没有万能泛函」的深层原因：每种泛函都在「约束完备性」与「数据拟合」之间选了一个折中点。</span>

**实操启示**：因为泛函各有「性格」，稳健的做法是**两个不同族泛函交叉验证**——若 GGA 与杂化泛函给出定性一致的结论，结论可信度高；若二者分歧很大，说明结果对泛函敏感，需要更高精度方法仲裁。

## 6 小结

- $E_{xc} = E_x + E_c$：交换是大头、相关是小头但关键；好泛函满足**精确约束**。
- **雅各布天梯**五级：LDA → GGA → meta-GGA → 杂化 → 双杂化，每级多一个变量、多一分物理。
- **B3LYP** 是历史最常用的三参数杂化泛函，$a_0=0.20$ 的 HF 交换混入是精髓。
- 泛函的系统性病：**自相互作用误差**（离域化）与**无色散**；用 **DFT-D** 校正。
- 选泛函**按体系定制**：热化学选杂化、弱作用带色散、固体选 PBE/SCAN、激发态选长程校正。
