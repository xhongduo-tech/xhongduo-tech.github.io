## 为什么换一种思路选步长

牛顿法有个隐隐的不安：二次模型只是 $f$ 的局部近似，它在离 $x_k$ 很远的地方可能完全失真——但牛顿法还是照用它的顶点作为下一步。上一篇靠**线搜索**来兜底（方向照走，长度现场试），这一篇换一个更聪明的姿势：**先划定一个「信任半径」，我们只在半径内信任这个二次模型；然后直接在这个半径内求模型的最优，再根据实际函数值确认这步是否可信，动态调整半径。** 这个思想叫**信赖域（trust region）**，它和线搜索是数值优化里并驾齐驱的两条主线。二者不矛盾：信赖域不假设「方向永远可信」，而是把「方向该多长」和「模型是否可信」合并成一个问题来解——这使它天然适合 Hessian 不定、模型不可靠的病态问题。

## 1 子问题：把「走多远」变成约束

在 $x_k$ 附近，我们信任的二次模型是

$$
m_k(p) = f(x_k) + \nabla f(x_k)^T p + \frac12 p^T B_k p
$$

其中 $B_k$ 是 Hessian 的某个近似（真 Hessian 或拟牛顿矩阵）。**信赖域子问题（trust-region subproblem）**就是在半径约束下最小化模型：

$$
\min_{p \in \mathbb{R}^n}\ m_k(p) \qquad \text{s.t.} \quad \|p\| \le \Delta_k
$$

半径 $\Delta_k > 0$ 就是「信任半径」。求解后得到候选步 $p_k$，再算一个**实际下降与预测下降的比值**：

$$
\rho_k = \frac{f(x_k) - f(x_k + p_k)}{m_k(0) - m_k(p_k)}
$$

分子是真实的下降，分母是模型预测的下降。<span class="marginnote">$\rho_k \approx 1$ 说明模型预测得极准，值得扩大半径；$\rho_k$ 接近 0 甚至为负说明模型彻底失准，要缩小半径、重新求子问题；$0 < \rho_k$ 不太大时按当前半径接受这一步。这就是「信任—验证—调整」的闭环。</span>若 $\rho_k > \eta$（阈值如 $10^{-4}$），接受这步，否则留在原地只缩小半径重试。

### 算法流程：信赖域方法的骨架

「信任—验证—调整」的闭环写成循环就是这个样子：

```text
算法：信赖域方法
输入：f(x)，x0，初始半径 Δ0，接受阈值 η≈1e-4，
     扩大阈值 γ1≈2，缩小因子 γ2≈0.5
1.  k = 0
2.  while 未收敛  do
3.      构造模型 m_k(p) = f_k + g_kᵀp + ½ pᵀB_k p
4.      解子问题  min‖p‖≤Δ_k m_k(p)，得候选步 p_k
5.      ρ_k = (f(x_k) − f(x_k+p_k)) / (m_k(0) − m_k(p_k))
6.      if ρ_k < 0.25 then Δ_{k+1} = γ2·Δ_k          # 模型不可信，缩半径
7.      else if ρ_k > 0.75 且 ‖p_k‖ = Δ_k then Δ_{k+1} = γ1·Δ_k  # 可信，扩半径
8.      if ρ_k > η then x_{k+1} = x_k + p_k else x_{k+1} = x_k
9.      k = k + 1
10. return x_k
```

第 6–7 行的「缩/扩」就是算法的自适应灵魂：**比值 $\rho_k$ 是模型可信度的体温计**。

## 2 与线搜索的本质区别

两条路在概念上泾渭分明，用一张表对比最清楚：

| 维度 | 线搜索 | 信赖域 |
| --- | --- | --- |
| 决策顺序 | 先定方向，再定长度 | 方向与长度联合决定 |
| 核心参数 | 步长 $\alpha$ | 半径 $\Delta$ |
| 模型失准时 | 缩步长重试 | 缩半径重试 |
| 不定 Hessian | 需专门修正 | 天然容忍 |
| 收敛阶 | 依赖方向选择 | 牛顿半径下二次收敛 |

两条路在概念上泾渭分明：

**线搜索**：先定方向 $p_k$（通常是负梯度或牛顿方向），**再沿这条方向选一个标量步长 $\alpha$**。方向错了，步长再准也无济于事。
- **信赖域**：**方向和步长在同一个约束问题里被联合决定**。若约束 $\|p\| \le \Delta$ 不活跃，解就是牛顿步；若约束活跃，方向会「弯」向更保守的路径，天然把步长限制在模型可信范围内。

更妙的是，信赖域**天然处理不定 Hessian**：模型在某个方向上是马鞍形也不要紧，半径约束把搜索限制在局部，子问题仍有全局最优解。而牛顿方向需要 Hessian 正定，线搜索框架下不定 Hessian 是个要专门修补的麻烦——信赖域把这个问题化解于无形。<span class="marginnote">信赖域子问题本身可以高效求解：理论上最优步 $p^*$ 满足 $p^* = -(B + \lambda I)^{-1} g$，其中 $\lambda \ge 0$ 由 $\|p^*\| = \Delta$ 或 $B + \lambda I$ 半正定来决定。这个「加 $\lambda I$」的形式是不是很眼熟？它正是 Levenberg–Marquardt 的阻尼项，也是岭回归 $\lambda I$ 的来源——同一个数学结构在不同场景反复出现。</span>

## 3 收敛性：信赖域也能二次收敛

只要模型 $m_k$ 与 $f$ 的差异随 $\Delta_k \to 0$ 而按平方阶消失（真 Hessian 情形），信赖域方法就能在最优附近取得**与牛顿法一样的二次收敛**；实际实现中通常让 $B_k$ 等于真 Hessian，且在接近解时半径自动缩小，模型越来越准。若 $B_k$ 用拟牛顿近似，则收敛为超线性。工程上信赖域的稳健性来自那条简单的规则：**表现好就信任更多，表现差就缩回身来**——这使它成为几乎所有高鲁棒性专业求解器的默认框架（如 MINPACK、KNITRO）。

## 4 公式解析：信赖域子问题与比值判据

把最重要的两个公式拆开：

$$
\min_{\|p\| \le \Delta_k}\ m_k(p) = \min_{\|p\| \le \Delta_k}\ \left[ f_k + g_k^T p + \frac12 p^T B_k p \right]
$$

- **第一步，读三项**：常数项 $f_k$ 与步长无关，可忽略；线性项 $g_k^T p$ 惩罚「逆着梯度走」；二次项 $\frac12 p^T B_k p$ 用曲率惩罚/奖励「往高处或低处走」。整个子问题在 $\|p\| \le \Delta_k$ 的球内求最小。
- **第二步，看解的结构**：若球约束不起作用，驻点条件 $B_k p = -g_k$ 给出牛顿步 $p = -B_k^{-1} g_k$；若球约束起作用，最优解形如 $p = -(B_k + \lambda I)^{-1} g_k$，$\lambda$ 像一个「收紧的拉链」，把步长缩进球内——阻尼的几何直觉就在这里。
- **第三步，验货**：算出候选步后代入 $\rho_k = \frac{f(x_k) - f(x_k+p_k)}{m_k(0) - m_k(p_k)}$。分母恒正（$m_k$ 在可行域内必有下降），比值符号就看分子——分子是负数（函数值上升），立刻拒绝这步并缩小 $\Delta_k$。这一条**自适应**规则让算法几乎不可能发散。

**辨析｜易错点：** 信赖域与「带 $L_2$ 正则的二次优化」形式相似（都是 $\min \frac12 p^T B p + g^T p + \frac{\lambda}{2}\|p\|^2$），但语义不同：信赖域的 $\Delta$ 是**几何约束**，对偶拉格朗日乘子 $\lambda$ 才是解；而正则化是主动加罚。理解这个「约束 vs 惩罚」的对偶关系，正是下一篇《对偶理论与 KKT》的入口。

## 5 深度学习里没有名分，却无处不在

深度学习中几乎不叫「信赖域」，但同一个思想反复潜伏：**TRPO** 用 KL 散度约束策略更新步（模型更新距离受限），本质上就是策略空间里的信赖域；**自然梯度法**用 Fisher 矩阵替换 $B_k$，也是「信任模型的范围」思想的变体；而 **Adam 的分母 $\sqrt{\hat v_t} + \epsilon$ 可以看成每个坐标独立的小信赖半径**。读到这里，你会发现：优化的底层结构是稀疏的，翻来覆去就是曲率、信任、约束这三个词在组合。<span class="marginnote">TRPO（Trust Region Policy Optimization，Schulman et al., 2015）是强化学习里把信赖域思想带上战场的代表作，见第三级《强化学习》的《策略梯度与 TRPO》。</span>

回顾全篇，信赖域方法最值得带走的不是某个公式，而是那条朴素的自适应原则：**给模型分配信任，而不是给步长赌运气**——模型好就多走，模型差就收回来。这一原则将在后面的《非线性最小二乘与 LM》里以「阻尼」的面目再次登场。

## 6 小结

- **信赖域子问题**：$\min_{\|p\| \le \Delta_k} m_k(p)$，方向与步长联合决定，半径约束解决「模型不可信」问题。
- **自适应判据**：$\rho_k = \frac{\text{真实下降}}{\text{预测下降}}$，据此接受步长、扩大或缩小半径——算法因此极难发散。
- 与线搜索互补：线搜索「先方向后长度」，信赖域「先定范围再联合解」；信赖域天然容忍不定 Hessian。
- 解的结构 $p = -(B+\lambda I)^{-1}g$ 与阻尼、岭回归同构；**模型好就信更多，模型差就缩回来**是全部秘密。
- 深度学习里的 TRPO、自然梯度、Adam 分母都是信赖域思想的化身。
- 工程经验：半径更新因子、接受阈值几乎是固定超参（$0.25 / 0.75 / 2 / 0.5$），**不需要像学习率那样每任务重调**，这正是信赖域「免调参」的工程红利。
- 子问题的近似解法（折线法 dogleg、柯西点、截断共轭梯度）把「精确解子问题」的成本降到可以接受，是大规模信赖域真正可行的关键。

在下一节，我们将看到一条优雅的中间路线：既不要 Hessian 的昂贵，又避免最速下降的锯齿——利用**共轭方向**，让每一步都与前面的步不再打架。
