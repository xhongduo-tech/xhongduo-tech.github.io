## 为什么要「罚」而不是「除」

上一篇的 KKT 条件把约束问题的最优性讲透了，但那是「判断」，不是「算法」。这一篇进入「求解」：如何真的把一个带约束问题算出来？最朴素的答案是**把约束的违反程度算进目标函数里**——这就是罚函数思想的全部直觉：**别管约束了，先优化一个「带惩罚的目标」，罚得越重，解就越靠近约束边界**。<span class="marginnote">Courant 1943 年提出二次罚函数；一百多年后它换了个名字「soft constraints」又出现在优化与控制里。它的命运曲线很像一段寓言：简单，好用，但罚因子趋于无穷时会病态。</span>而乘子法（增广拉格朗日）则是对二次罚的一场外科手术式升级：**用拉格朗日乘子信息修正罚函数的中心**，让解在有限罚强度下就能精确满足约束——这一小步，让它成了现代约束求解器的栋梁，也是 ADMM 与内点法的近亲。

## 1 二次罚函数：最朴素的暴力

对于等式约束问题 $\min f(x)\ \text{s.t.}\ c(x) = 0$，构造**二次罚函数（quadratic penalty）**：

$$
Q_\rho(x) = f(x) + \frac{\rho}{2} \|c(x)\|^2
$$

算法极简单：**逐步放大 $\rho$，对每个 $\rho$ 最小化 $Q_\rho$，用上一步的解做初值**。$\rho \to \infty$ 时，任何残留的违反 $c(x) \ne 0$ 都会被罚得「倾家荡产」，于是解被迫收敛到约束面。但这个策略有一个理论代价：**罚因子 $\rho$ 越大，$Q_\rho$ 的 Hessian 条件数越差（正比于 $\rho$）**，数值上越来越病态；而且精确解只在 $\rho \to \infty$ 的极限取得——「越准越病态」，两头都难。

看一个能手算的例子：$\min x^2\ \text{s.t.}\ x = 1$。罚问题 $\min x^2 + \frac{\rho}{2}(x-1)^2$ 的平稳条件是 $2x + \rho(x-1) = 0$，解得 $x^*(\rho) = \frac{\rho}{\rho+2}$。$\rho=2$ 时 $x = 0.5$，$\rho=10$ 时 $x \approx 0.833$，$\rho=100$ 时 $x \approx 0.98$——**有限 $\rho$ 下解永远到不了 $x = 1$**，只能无限逼近。这就是「非精确罚」这个名字的由来。<span class="marginnote">二阶罚的 Hessian 是 $\nabla^2 f + \rho \nabla c \nabla c^T$，沿约束法线方向的特征值增长到 $O(\rho)$，条件数 $\kappa \sim \rho$。用梯度法解它，收敛速度随 $\rho$ 线性变差——这是罚函数的「阿喀琉斯之踵」。</span>

## 2 L1 精确罚函数：一次就到位

二次罚永远差一口气（极限才精确），但**L1 罚函数**却是**精确（exact）**的——存在有限的 $\rho$ 使它的解就是原问题的解：

$$
Q(x) = f(x) + \rho \sum_{i} |c_i(x)|
$$

为什么精确？因为 L1 在 $c_i = 0$ 处**有尖角（不可微）**，即使 $\rho$ 不大，$Q$ 的最小值点也能正好落在约束面上——尖角提供了「把解钉在边界上」的力。代价是 $Q$ 不可微，需要次梯度或光滑化。工程上常用它的光滑近似（如 Huber 化）来换取可微性，也可直接套用《次梯度与近端方法》里的近端框架——L1 罚项的次微分与软阈值，在上一节已经见过面。<span class="marginnote">L1 罚的「精确性」与稀疏正则同出一源：$|x|$ 的尖角让最小值点有概率恰好在 0 处——上一节《次梯度与近端方法》里软阈值的稀疏性，和这里的精确罚，是同一个几何现象的两张面孔。</span>工程上常用它的光滑近似（如 Huber 化）来换取可微性。

## 3 增广拉格朗日 / 乘子法：把乘子也迭代起来

二次罚的病灶是「$\rho$ 必须很大」；乘子法（method of multipliers，即**增广拉格朗日（augmented Lagrangian）**）的处方是：**在二次罚外面再加一项拉格朗日乘子，并用乘子迭代替代 $\rho$ 的无限增大**。构造增广拉格朗日函数：

$$
\mathcal{L}_\rho(x, \lambda) = f(x) + \lambda^T c(x) + \frac{\rho}{2}\|c(x)\|^2
$$

算法分两步循环：

1. 固定 $\lambda_k$，对 $x$ 最小化 $\mathcal{L}_{\rho}(x, \lambda_k)$；
2. **乘子更新**：$\lambda_{k+1} = \lambda_k + \rho\, c(x_{k+1})$。

第二步的来源非常深刻：在解处，KKT 平稳性要求 $\nabla f + \lambda^T \nabla c = 0$，而 $\mathcal{L}_\rho$ 对 $x$ 的梯度是 $\nabla f + \lambda_k^T \nabla c + \rho \nabla c^T c$；令其为零并在约束面（$c = 0$）上取值，恰好得到 $\lambda^* = \lambda_k + \rho c$——所以乘子更新就是「用当前约束违反量修正乘子估计」，每轮都让 $\lambda$ 逼近真乘子 $\lambda^*$。<span class="marginnote">有了乘子的「助攻」，$\rho$ 不需要趋于无穷就能精确满足约束——误差以 $O(1/\rho)$ 衰减，条件数问题大幅缓解。这就是「加一项乘子」比「单纯加罚」值钱之处，也正是 ADMM 把它拆到两块变量上做分布式优化的基础。</span>

为什么乘子能「顶住」间隙？回到几何：二次罚的最优点总在「约束面外侧偏一截」的地方，因为罚力是「往约束面拉」的；而乘子项 $\lambda^T c$ 给了目标一个「往约束面反方向推」的偏移，两力一抵，解正好落在约束面上。**乘子就是那个「提前预支的拉力」**，它的量级恰好是约束的边际价格（影子价格）。

### 算法流程：增广拉格朗日（乘子法）的骨架

```text
算法：增广拉格朗日（等式约束）
输入：f(x)，c(x)，x0，乘子初值 λ0，罚初值 ρ0>0，放大因子 γ，容差 ε
1.  k = 0
2.  while ‖c(x_k)‖ > ε  do
3.      x_{k+1} = argmin_x  f(x) + λ_kᵀc(x) + (ρ_k/2)·‖c(x)‖²   # 子问题
4.      λ_{k+1} = λ_k + ρ_k·c(x_{k+1})          # 乘子更新（关键一步）
5.      ρ_{k+1} = γ·ρ_k                          # 按需放大罚因子
6.      k = k + 1
7.  return x_k, λ_k
```

第 4 行是「灵魂一步」，第 5 行只是辅助：**乘子在主导收敛，罚因子只是兜底**——这与二次罚（死磕 $\rho$）的思路彻底分道扬镳。

## 4 公式解析：乘子更新为什么恰好收敛

把核心公式 $\lambda_{k+1} = \lambda_k + \rho\, c(x_{k+1})$ 拆开：

**第一步，回到 KKT**：最优点处，约束违反 $c(x^*) = 0$，平稳性 $\nabla f(x^*) + (\lambda^*)^T \nabla c(x^*) = 0$。我们不知道 $\lambda^*$，但可以「逐步猜」。
- **第二步，看增广函数的最小化条件**：$x_{k+1}$ 最小化 $\mathcal{L}_{\rho}(x, \lambda_k)$，故 $\nabla f(x_{k+1}) + \lambda_k^T \nabla c(x_{k+1}) + \rho \nabla c(x_{k+1}) c(x_{k+1}) = 0$。
- **第三步，读出更新**：把中间项并成 $[\lambda_k + \rho c(x_{k+1})]^T \nabla c(x_{k+1}) = -\nabla f(x_{k+1})$，与 KKT 平稳性对照，就知道括号里那一坨就是对 $\lambda^*$ 的下一步估计——于是 $\lambda_{k+1} = \lambda_k + \rho\, c(x_{k+1})$ 不是拍脑袋，而是**用梯度平衡方程反解乘子**。

**辨析｜易错点：** 二次罚的乘子项是 $\frac{\rho}{2}\|c\|^2$，增广拉格朗日是 $\lambda^T c + \frac{\rho}{2}\|c\|^2$——不要混淆。区别不是「多一项」这么简单：二次罚的极小点在 $c$ 与 $0$ 之间永远差 $O(1/\rho)$ 的间隙（除非 $\rho$ 无穷大）；而乘子法用 $\lambda$ 项「顶住」这个间隙，让解在**有限 $\rho$** 下就精确落在约束面上。另外一个易错点：乘子更新用的是「当前子问题的解 $x_{k+1}$」，不是迭代前的 $x_k$。

三类「把约束搞进目标」的家族对比：

| 方法 | 函数形式 | 精确性 | 病态风险 | 代表应用 |
| --- | --- | --- | --- | --- |
| 二次罚 | $f + \frac{\rho}{2}\|c\|^2$ | 仅 $\rho\to\infty$ 极限 | 高（$\kappa\sim\rho$） | 教学、简易实现 |
| L1 罚 | $f + \rho\sum\|c_i\|$ | 有限 $\rho$ 精确 | 中（不可微） | 稀疏、LP 罚 |
| 增广拉格朗日 | $f + \lambda^T c + \frac{\rho}{2}\|c\|^2$ | 有限 $\rho$ 精确 | 低 | 通用求解器、ADMM |

「精确性」一行说明一切：**只有前两种存在「必须把 $\rho$ 拉到无穷」或「必须把 $\rho$ 拉很大」的妥协，增广拉格朗日靠乘子把这两份妥协都省了**。

## 5 增广拉格朗日的大舞台

增广拉格朗日的应用远远超出教科书例题：它是**约束优化通用求解器（如 LANCELOT、以及许多 MATLAB 内建约束优化器）**的核心；把二次罚项拆到多块变量上就得到 **ADMM**，后者统治了信号处理、图像去噪、分布式学习和推荐系统；在深度学习里，**硬约束训练（权重归一化、谱约束、物理约束神经网络 PINN）**也常用增广拉格朗日把约束逐步收紧，避免硬投影的跳变。<span class="marginnote">ADMM 的每一次子迭代都在交替做近端/最小化两块变量、再更新对偶——它把《对偶理论与 KKT》的乘子、《次梯度与近端方法》的近端、本篇的增广拉格朗日三样东西缝在了一起。推荐系统里的矩阵分解、LLM 推理里的目标函数分解都能见到它的影子。</span>

补一个务实的选型建议：**约束个数少、非光滑、且你能写出闭式子问题时，优先乘子法**（ADMM 就是它的分布式变体）；约束个数多、结构规则时，内点法（本专题末篇）常更省心；约束强非线性、规模中等时，SQP 是最稳的旗舰。三套方法各守一段战场，理解它们的差异就是工程选型的全部。

还有一个常被忽略的优点值得记下：**增广拉格朗日天然输出对偶变量 $\lambda$**——解完约束问题，约束的边际价格（影子价格）免费到手。这对经济调度、资源定价、以及需要灵敏度分析的工程场景，几乎等于白送一层分析能力。

回顾全篇的脉络：从「靠 $\rho$ 硬拽」的二次罚，到「靠尖角钉住」的 L1 精确罚，再到「靠乘子预支拉力」的增广拉格朗日——**每一步都在用更聪明的数学换取「不需要把 $\rho$ 拉到无穷」**。当你想对一个约束问题「给个能跑的算法」，这一节的三件套就是最快的起点。

## 6 小结

- **二次罚函数** $f + \frac{\rho}{2}\|c\|^2$：简单直观，但**只在 $\rho \to \infty$ 极限精确**，且 Hessian 病态（$\kappa \sim \rho$）。
- **L1 罚函数**：**精确罚**，靠尖角把解钉在约束面上，代价是不可微。
- **增广拉格朗日** $\mathcal{L}_\rho = f + \lambda^T c + \frac{\rho}{2}\|c\|^2$：**乘子更新 $\lambda_{k+1} = \lambda_k + \rho c(x_{k+1})$** 由 KKT 平稳性反解，有限 $\rho$ 即精确，条件数大幅缓解。
- 增广拉格朗日是 **ADMM、约束求解器、PINN 硬约束训练**的公共底座。
- 一个可手算的迷你验证：$\min x^2\ \text{s.t.}\ x = 1$。取 $\rho=1$、$\lambda_0=0$，子问题最小化 $x^2 + \lambda_0 x + \tfrac12(x-1)^2$ 得 $x_1 = \tfrac13$；乘子更新 $\lambda_1 = 0 + 1\cdot(\tfrac13-1) = -\tfrac23$；第二轮得 $x_2 = \tfrac59 \to 1$——**乘子把解一步步「钓」到约束面上**，而二次罚只靠 $\rho$ 硬拽，这就是两者的手感差异。
- 工程口诀：**子问题不必精确解**——每轮只需把 $\mathcal{L}_\rho$ 大致最小化（提前终止），乘子更新照常有效；这条「不精确原则」是它适合嵌套进大流程的关键。
- 与下一篇衔接：乘子法把约束「吸收」进目标，靠乘子迭代精修；而 SQP 走的是另一条路——把约束原样线性化、解 QP 子问题。**一个「收编」，一个「共存」**，是约束优化两大流派的分水岭。
- 一句话记忆：**罚函数是「靠 $\rho$ 硬拽」，L1 罚是「靠尖角钉住」，乘子法是「靠 $\lambda$ 预支拉力」**——三个动词记全三个家族。
- 提醒回读：《对偶理论与 KKT》里乘子被定义成「约束的边际价格」，本篇把它变成了「每轮迭代在更新的量」——**同一个 $\lambda$，从理论到算法，身份始终一致**。
- 下一篇我们将看到约束优化的另一极：不做「吸收」，而是「线性化保留」——**序列二次规划 SQP**。
- 不等式约束版本只需一处小改：把「违反量」替换成 $c_+(x) = \max(0, g(x))$，乘子更新为 $\lambda \leftarrow \max(0,\ \lambda + \rho\, g(x))$——**非负的「顶」对应乘子非负的 KKT 约束**，理论完全自洽。

在下一节，我们换一种更「牛顿」的姿势对付约束：把约束问题的 KKT 方程整体当成一个方程组，直接用牛顿法去解——这就是**序列二次规划（SQP）**。
