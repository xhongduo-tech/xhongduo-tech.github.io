## 为什么从梯度下降开始

上一篇《凸优化基础》已经给出了一行合法性证明：在可微凸函数上，沿负梯度方向走一小步，函数值必然下降。这一篇把这句话兑现成一个完整的算法。梯度下降是全部优化算法里最古老、最简单、也最「谁都会用」的一个——但正因为它简单，它成了一面镜子，把步长怎么选、收敛有多快、为什么有时慢如蜗牛这些根本问题全部照出来。<span class="marginnote">1857 年柯西（Augustin-Louis Cauchy）就在一封信里提出「沿最陡方向下降」的迭代法，距今已近 170 年，是数值优化真正意义的起点。</span>深度学习中几乎每一个优化器（SGD、动量、Adam）都是在这面镜子上加料的结果，所以这一篇必须读得扎实。

## 1 最速下降法：沿着梯度往下走

考虑无约束可微优化问题 $\min_{x \in \mathbb{R}^n} f(x)$。**梯度下降（gradient descent）**：给定当前点 $x_k$，取搜索方向 $p_k = -\nabla f(x_k)$（负梯度方向），再走一个步长 $\alpha_k > 0$，迭代：

$$
x_{k+1} = x_k - \alpha_k \nabla f(x_k)
$$

为什么是负梯度？因为梯度 $\nabla f(x)$ 指向 $f$ 上升最快的方向，那么 $-\nabla f(x)$ 就是下降最快的方向——**在所有「单位步长」里，负梯度方向给出的线性下降率最大**，这就是「最速下降」名字的来历。

方向选好了，剩下的问题是走多远：步长 $\alpha_k$ 太小，收敛如蚂蚁爬；太大，步子跨过山谷底，来回振荡甚至发散。**步长的选取就是「线搜索」的全部内容。**

「为什么是负梯度」还有一层严谨的说法：单位方向 $d$（$\|d\| = 1$）上 $f$ 的方向导数等于 $\nabla f(x)^T d = \|\nabla f(x)\|\cos\theta$，其中 $\theta$ 是 $d$ 与 $\nabla f(x)$ 的夹角；当 $d = -\nabla f(x)/\|\nabla f(x)\|$ 时 $\cos\theta = -1$，方向导数取到最小值——**在所有单位方向里，负梯度方向的初始下降率最大**。注意「初始」二字：这只是局部最优方向，整体上未必，这正是锯齿悲剧的伏笔。

## 2 线搜索：如何选步长

**线搜索（line search）**：固定当前点 $x_k$ 与搜索方向 $p_k$，把函数限制在一维上，选一个让 $f(x_k + \alpha p_k)$ 足够小的 $\alpha$。常见的策略有：

- **精确线搜索**：解一维问题 $\min_{\alpha>0} f(x_k + \alpha p_k)$，代价高，只在理论分析里常用。
- **Armijo 条件（充分下降）**：要求
  $$
  f(x_k + \alpha p_k) \le f(x_k) + c_1 \alpha \nabla f(x_k)^T p_k, \qquad 0 < c_1 < 1
  $$
  右边的直线是「可接受的下降底线」，步长必须让函数值跌到这条线以下才算数。<span class="marginnote">$c_1$ 通常取 $10^{-4}$ 量级。直觉：不是要下降得多狠，而是要保证「这步确实在下降」，别让振荡拖垮收敛。</span>
- **Wolfe 条件**：在 Armijo 之上再加一条**曲率条件** $\nabla f(x_k + \alpha p_k)^T p_k \ge c_2 \nabla f(x_k)^T p_k$（$0 < c_1 < c_2 < 1$），防止步长小到「几乎没动」；对光滑凸函数，Wolfe 条件保证相邻搜索方向夹角有界，是收敛证明的关键。
- **回溯（backtracking）**：实现最省事的工程方案——先取大步长，若不满足 Armijo 就按比例缩小重试，通常步长因子取 $\rho \in (0,1)$ 如 $0.5$。

Armijo 条件可以画出来理解：在 $\alpha$ 轴上看，$f(x_k + \alpha p_k)$ 是一条从 $\alpha=0$ 出发的曲线，过原点的那条切线斜率是 $\nabla f(x_k)^T p_k < 0$；Armijo 要求的，是这条曲线在「$c_1$ 倍切线斜率」的直线之下。因为直线比真实曲线「陡」（更缓地下降），在 $\alpha$ 足够小时不等式必成立——**可接受区间一定非空**，回溯法总能停下，且不会停得太早。

三种线搜索策略的取舍一目了然：

| 策略 | 判据 | 每步代价 | 特点 |
| --- | --- | --- | --- |
| 精确线搜索 | 一维精确极小 | 高 | 理论干净，工程昂贵 |
| Armijo 回溯 | 充分下降判据 | 低 | 最实用，工业标准 |
| Wolfe 条件 | 充分下降 + 曲率 | 中 | 收敛证明最友好 |

线搜索的另一个隐藏收益：**它让算法对方向长度免疫**。搜索方向只要「与负梯度夹角小于 90°」（即下降方向），配合回溯线搜索就能保证每步充分下降；方向本身的缩放被 $\alpha$ 吸收掉了。这意味着任何「改造方向」的算法（动量、共轭、牛顿），只要保住方向是下降方向，线搜索就能替它们兜底。

### 算法流程：回溯线搜索的完整骨架

把「方向 + 步长」打包成一个能跑的循环：

```text
算法：梯度下降 + 回溯线搜索
输入：f(x)，初始点 x0，初始步长 α0，缩小因子 ρ∈(0,1)，
      Armijo 常数 c1≈1e-4，停止容差 ε
1.  k = 0
2.  while ‖∇f(x_k)‖ > ε  do
3.      p_k = -∇f(x_k)                       # 负梯度方向
4.      α   = α0
5.      while f(x_k + α p_k) > f(x_k) + c1·α·∇f(x_k)ᵀp_k:
6.          α = ρ·α                          # 不满足充分下降，缩步长重试
7.      x_{k+1} = x_k + α p_k
8.      k = k + 1
9.  return x_k
```

内层 while 就是回溯：**从大步长开始，一旦跨过 Armijo 阈值就按 ρ 收缩**，几乎不会多余计算——这也是为什么工业实现偏爱它胜过精确线搜索。

## 3 收敛速度：被条件数卡住

对强凸且光滑的二次函数 $f(x) = \frac12 x^T A x - b^T x$（$A$ 对称正定），用精确线搜索的最速下降法收敛率是：

$$
\|x_k - x^*\| \le \left( \frac{\kappa - 1}{\kappa + 1} \right)^k \|x_0 - x^*\|
$$

其中 **条件数（condition number）** $\kappa = \lambda_{\max}(A) / \lambda_{\min}(A)$ 是 Hessian 最大与最小特征值之比。收敛率只由 $\kappa$ 决定：$\kappa=1$ 时一次到位；$\kappa$ 越大，括号里的比率越接近 1，收敛越慢。<span class="marginnote">椭圆等高线的「扁长程度」正是条件数的几何化身：圆 $\kappa=1$，一步到心；细长椭圆 $\kappa$ 巨大，梯度方向与指向最优的方向严重错位，于是形成上一篇图里那种锯齿形轨迹——相邻两步近似垂直，越靠近谷底越「横跳」。</span>这就是那句反直觉的结论：**「最速下降」并不「最速」，它在病态条件数下可能慢得无法忍受。**

![最速下降法在椭圆等高线上的锯齿形轨迹](/images/optimization-algorithms/gradient-descent-line-search-1.svg)

实操中如何「观测」收敛快慢？三种惯用指标对应不同的停止判据：**函数值差** $f(x_k) - f(x_{k+1})$（看曲线是否走平）、**梯度范数** $\|\nabla f(x_k)\|$（最接近「离最优多远」的度量，也是标准停止条件）、**参数距离** $\|x_k - x_{k+1}\|$（最容易误报，因为参数可能早就不动了而函数还在缓降）。画收敛曲线时，横轴用「迭代次数」，纵轴用对数刻度——**一条近乎笔直的线才是干净的指数（线性）收敛，弯成平尾说明卡在了噪声或振荡区**。

拿具体数字感受收敛率的「残酷」：对 $f(x) = \frac12(x^2 + 100\,y^2)$（$\kappa = 100$），从 $x_0 = (1, 1)$ 出发做精确线搜索的最速下降，第一行会得到 $x_1 \approx (0.98, -0.02)$——$x$ 分量几乎一步收敛，$y$ 分量却要按每步乘 $(\kappa-1)/(\kappa+1) \approx 0.98$ 的比率，花掉几百步才逼近 0。**条件数把一维的「简单」拉伸成了高维的「折磨」**；而牛顿法或坐标变换（把 $y$ 换到 $\sqrt{\kappa}y$ 的度量下）都能让这个问题一步到位——这正是下一节「为什么需要曲率」的动机。

## 4 公式解析：迭代步与 Armijo 条件

把本专题第一个真正运行的公式拆开：

$$
x_{k+1} = x_k + \alpha_k p_k, \qquad p_k = -\nabla f(x_k)
$$

- **第一步，定方向**：$p_k = -\nabla f(x_k)$ 是下降方向，因为沿它移动，$f$ 的方向导数 $\nabla f(x_k)^T p_k = -\|\nabla f(x_k)\|^2 < 0$，函数值在下降。
- **第二步，定步长**：$\alpha_k$ 由线搜索给出。用 Armijo 条件时，$\alpha_k$ 必须满足 $f(x_k + \alpha_k p_k) \le f(x_k) + c_1\alpha_k \nabla f(x_k)^T p_k$——注意右侧的直线斜率是 $c_1 \nabla f(x_k)^T p_k$，它比真实切线斜率（在 $\alpha=0$ 处为 $\nabla f(x_k)^T p_k$）更「缓」，保证了可接受区间非空。
- **第三步，迭代与停止**：重复直到 $\|\nabla f(x_k)\| \le \varepsilon$。在凸光滑情形，这等价于「已接近最优」，因为梯度范数是与最优性残差直接挂钩的度量。

**辨析｜易错点：** 学习率固定为常数 $\alpha$ 与「线搜索」是两回事。固定步长要求 $\alpha \le 2/L$（$L$ 为梯度李普希茨常数）才能保证收敛；一旦 $\alpha$ 略超阈值，函数值就会振荡甚至爆炸——这正是深度学习训练中「loss 突然变 NaN」的常见元凶之一。

## 5 从一维到高维：为什么深度网络靠它也能走

高维非凸问题里，$f$ 不再是碗，梯度方向也不再「全程可信」，但梯度下降的三个性质依然成立：**计算量小**（只需一阶导数，反向传播恰好免费给出全部梯度）、**内存少**（不存 Hessian）、**对噪声有天然的「钝感」**（即使梯度带噪声，平均意义下仍朝下降方向）。这三个性质让梯度下降成为唯一能放进几十亿参数网络的优化器雏形。第三级《深度学习》中的反向传播正是「梯度下降 + 计算图」的工程实现；而下一节我们将看到，只靠一阶信息天花板很低——把二阶曲率信息请进来，就是牛顿法。

一个实用提醒：**把「梯度下降」当成一切优化器的对照基准**。任何新优化器上线前，先看它是否显著优于「步长调好的最速下降 + 回溯线搜索」；在许多凸问题上（如逻辑回归、岭回归），优化良好的最速下降配合 Wolfe 条件，收敛速度其实相当体面，性价比极高。深度学习里它被随机梯度（SGD）替代，不是因为「最速下降差」，而是因为「全量梯度付不起」——这个区分，是读懂下一篇《随机梯度下降与方差减小》的钥匙。

## 6 小结

- **最速下降法** $x_{k+1} = x_k - \alpha_k \nabla f(x_k)$ 是最简单的迭代算法；**负梯度是单位步长内下降最快的方向**。
- 步长由**线搜索**给出：Armijo 保证充分下降，Wolfe 加曲率条件防停滞，回溯法是最实用的实现。
- 二次情形收敛率为 $(\kappa-1)/(\kappa+1)^k$，**条件数 $\kappa$ 越大收敛越慢**，形成锯齿轨迹——「最速下降」并不最速。
- 固定步长需 $\alpha \le 2/L$，否则发散；深度学习靠「梯度免费 + 内存小」这两条，把梯度下降用到了极限。

在下一节，我们给最速下降装上「曲率眼镜」：用二阶信息直接指向山谷中心，收敛率从线性跃升到二次——这就是**牛顿法与拟牛顿**。
