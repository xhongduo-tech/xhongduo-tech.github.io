# 共轭梯度法

<div class="epigraph">

## 为什么需要一条「不返工」的路

最速下降的锯齿悲剧已经反复上演：每一步都垂直切进等高线，等于**把上一步的进度打回重来**。我们需要的是一族搜索方向，让后一步与前面所有的步「井水不犯河水」——不抵消前面的进展。这种方向叫作**共轭方向（conjugate directions）**，而靠梯度自动生成共轭方向的算法，就是**共轭梯度法（conjugate gradient，CG）**。它最初是 1952 年 Hestenes 与 Stiefel 为求解大规模稀疏线性方程组 $Ax = b$ 发明的；1950 年代后期 Fletcher 与 Reeves 把它推广到非线性最小化。<span class="marginnote">CG 的传奇之处：面对 $n$ 维强凸二次问题，理论上至多 $n$ 步收敛到精确解，而全程只用到矩阵-向量乘 $A p$，<strong>从不显式构造或求逆矩阵</strong>。对于 $n$ 巨大但 $A$ 稀疏（如有限元、图网络、隐式神经网络）的问题，这是唯一的可行路线。</span>

## 1 共轭方向：让每一步不返工

对对称正定矩阵 $A$，两个非零向量 $p_i, p_j$ 称为 **$A$-共轭（$A$-conjugate）**，若

$$
p_i^T A p_j = 0
$$

共轭的几何意义：$A$ 定义了内积 $\langle u, v\rangle_A = u^T A v$，$A$-共轭就是在这个内积下**正交**。为什么正交方向不返工？因为二次函数 $f(x) = \frac12 x^T A x - b^T x$ 沿方向 $p_i$ 精确线搜索后，新残差满足 $r_{k+1}^T p_i = 0$（残差与已用方向正交）；而共轭性保证后续方向 $p_j$ 与 $p_i$ 在 $A$ 内积下正交，于是在 $p_j$ 上的极小化**不会破坏**在 $p_i$ 上已经取得的极小。<span class="marginnote">类比：在欧氏空间里两两正交的基让坐标互不干扰；$A$-共轭就是「把等高线压成正圆之后的正交」。把椭圆坐标系「重排」成直角坐标系，问题就变成逐个坐标解——这正是 CG 至多 $n$ 步收敛的几何解释。</span>

## 2 共轭梯度法：梯度自动生成共轭方向

直接构造共轭方向需要预知 $A$ 的谱分解，太贵。CG 的天才之处在于：**不需要事先知道方向，每一步用当前残差（即负梯度）与上一步方向的线性组合就能生成新的共轭方向。** 线性情形 CG 的迭代如下：

$$
\begin{aligned}
p_{k} &= -r_k + \beta_k p_{k-1}, \qquad \beta_k = \frac{r_k^T r_k}{r_{k-1}^T r_{k-1}} \\
\alpha_k &= \frac{r_k^T r_k}{p_k^T A p_k} \\
x_{k+1} &= x_k + \alpha_k p_k, \qquad r_{k+1} = r_k + \alpha_k A p_k
\end{aligned}
$$

其中残差 $r_k = A x_k - b$ 恰好等于 $-\nabla f(x_k)$。三个量各司其职：**$\alpha_k$ 是沿 $p_k$ 的精确步长；$\beta_k$ 是新方向里「掺入」旧方向的系数（Fletcher–Reeves 形式）；$r_{k+1}$ 用一步矩阵-向量乘迭代更新，全程不碰矩阵本身。**

### 算法流程：线性 CG 的完整骨架

把「共轭 + 步长 + 残差」串成循环，就是 Hestenes–Stiefel 的原版 CG：

```text
算法：线性共轭梯度（解 Ax = b，A 对称正定）
输入：A, b，初始点 x0
1.  r0 = A x0 - b；p0 = -r0；k = 0
2.  while ‖r_k‖ > ε  do
3.      α_k = (r_kᵀ r_k) / (p_kᵀ A p_k)      # 沿 p_k 的精确步长
4.      x_{k+1} = x_k + α_k p_k
5.      r_{k+1} = r_k + α_k A p_k             # 一步矩阵-向量乘更新残差
6.      β_{k+1} = (r_{k+1}ᵀ r_{k+1}) / (r_kᵀ r_k)
7.      p_{k+1} = -r_{k+1} + β_{k+1} p_k      # 新方向 = 残差 + 共轭修正
8.      k = k + 1
9.  return x_k
```

全程只有两种运算：**矩阵-向量乘 $A p$ 与向量内积**——这保证了稀疏大系统上的可行性。第 7 行的「残差 + 共轭修正」正是「不用预知共轭方向」的天才所在。

## 3 非线性共轭梯度

把 CG 用到一般光滑函数 $f$ 上，关键是让 $\beta_k$ 只依赖梯度历史而不依赖显式的 $A$：

- **FR（Fletcher–Reeves，1964）**：$\beta_k = \dfrac{\|\nabla f(x_{k+1})\|^2}{\|\nabla f(x_k)\|^2}$；
- **PR（Polak–Ribière，1969）**：$\beta_k = \dfrac{\nabla f(x_{k+1})^T (\nabla f(x_{k+1}) - \nabla f(x_k))}{\|\nabla f(x_k)\|^2}$，非线性问题上通常比 FR 稳健。

非线性 CG 不再保证 $n$ 步收敛（函数不是二次），但在**大规模、内存受限**的优化里是标准选择：它不需要任何矩阵，只存三个向量，内存 $O(n)$，比 L-BFGS 更省。<span class="marginnote">深度学习里全量 batch 用满二阶方法的内存开销不可接受，但「只存向量」的路线给了希望——这正是许多内存高效二阶近似的设计出发点，见第三级《LLM 预训练》中的内存工程章节。</span>

## 4 公式解析：为什么 $n$ 步之内必收敛

把一个具体的数字例子能让「至多 $n$ 步」变得可触：对 $f(x) = \frac12\|x\|_2^2$（即 $A = I$），从任意 $x_0$ 出发，CG 第一步的精确步长 $\alpha_0 = r_0^T r_0/(r_0^T r_0) = 1$，一步就归零——因为 $A = I$ 时残差即负梯度、方向就是梯度，CG 退化为「一步牛顿」。对 $A$ 有 $k$ 个不同特征值的情形，CG 的实际步数上限会更紧：**至多 $k$ 步**（而不是 $n$ 步）。这个「谱越稀疏，收敛越快」的性质，正是预处理得以奏效的根本原因。

一个「几乎免费」的收敛定理拆开看——对 $n$ 维强凸二次问题，CG 至多 $n$ 步达到精确解：

- **第一步，理解共轭集的维数**：$A$-共轭向量组在 $A$ 内积下两两正交，最多 $n$ 个（$\mathbb{R}^n$ 的 $A$-正交基）。CG 每步生成一个新的共轭方向 $p_k$，这个方向与先前所有 $p_0, \dots, p_{k-1}$ 都 $A$-共轭。
- **第二步，看残差子空间**：可以证明 $x_k$ 属于由 $A$ 与 $r_0$ 生成的 Krylov 子空间 $\mathcal{K}_k = \mathrm{span}\{r_0, A r_0, \dots, A^{k-1} r_0\}$，且 $x_k$ 在这个子空间里是 $f$ 的最优。
- **第三步，封顶**：当 $k = n$，Krylov 子空间充满 $\mathbb{R}^n$（若中途残差未归零），于是 $x_n$ 就是全空间的全局最优——精确解。这就解释了 $n$ 步收敛，也解释了为什么实际中 CG 往往远远快于最速下降：**它对残差的「谱」做了隐式的最优压缩**，收敛率取决于 $A$ 的谱分布，而非只取决于条件数。

**辨析｜易错点：** 非线性 CG 里 $\beta_k$ 若由精确线搜索退化到近似线搜索，FR 与 PR 的收敛保证会受影响；工程上常用 **PR+**（对 $\beta_k$ 取非负截断）或周期性**重启（restart）**——每若干步把 $p_k$ 重置为 $-\nabla f(x_k)$，丢掉旧的共轭信息。忘记重启，是手写非线性 CG 最常见的坑。

补充一个判定细节：**CG 与最速下降在「第一步」可能完全一样**（都是从 $-\nabla f(x_0)$ 出发做精确线搜索），区别从第二步才开始——最速下降第二步仍是 $-\nabla f(x_1)$，而 CG 的第二步是「残差 + 共轭修正」。所以判断一个实现是否真的是 CG，要看方向更新里有没有 $\beta_k$ 这一项；没有它，收敛率就退回 $(\kappa-1)/(\kappa+1)^k$ 的老路。

## 5 预处理：把条件数再救一把

CG 的快慢由 $A$ 的谱决定，而谱由条件数主导。**预处理（preconditioning）**把方程换成 $M^{-1} A x = M^{-1} b$（$M$ 为近似 $A$ 的矩阵），等价地在 $A$-内积里用 $M$ 的 Cholesky 因子做变量替换，让新条件数 $\kappa(M^{-1}A) \ll \kappa(A)$。一个好预处理器（对角 Jacobi、不完全 Cholesky、神经场里的 identity+低秩）能把 CG 的迭代次数从 $O(\kappa)$ 压到 $O(\sqrt{\kappa})$。**预处理 + CG** 是现代科学计算里求解大规模对称正定系统的默认组合，也是「共轭」思想得以进入工程的核心前提。

### 三种无约束方法的「信息代价」对比

把 CG 放进方法谱系里，它的位置一目了然：

| 方法 | 使用信息 | 内存 | 二次问题收敛步数 | 典型成本 |
| --- | --- | --- | --- | --- |
| 最速下降 | 一阶梯度 | $O(n)$ | 无穷（线性率） | 极低 |
| 共轭梯度 | 一阶 + 方向记忆 | $O(n)$ | $\le n$（实际 $O(\sqrt{\kappa})$ 量级） | 极低 |
| 牛顿法 | 二阶 Hessian | $O(n^2)$ | $1$ 步 | 高 |

**CG 是「只有 $O(n)$ 内存、却能拿到近似牛顿收敛行为」的方法**——在买不起 Hessian、又嫌弃最速下降的大规模场景，它就是那个黄金折中点。

值得再强调 CG 在现代大规模计算的「隐形地位」：当你解一个隐式线性系统（如有限元刚度阵、图拉普拉斯、扩散算子的离散化、神经网络的 Hessian 向量积），**CG 是默认的求解引擎**；它不显式构造矩阵，只要一个「能算 $A p$ 的盒子」。在深度学习里，Hessian 向量积 $Hv$ 可以靠反向传播算出来（详见第三级《深度学习》的 §二阶优化），配合 CG 就能做「不显式建 Hessian 的牛顿类更新」——这个组合正在内存高效二阶优化里复苏。

## 6 小结

- **$A$-共轭**：$p_i^T A p_j = 0$，即「压圆后的正交」；共轭方向让后续极小化不破坏先前成果，消除锯齿返工。
- **线性 CG**：每步用残差与上一步方向生成新共轭方向，全程只需矩阵-向量乘，**对 $n$ 维二次问题至多 $n$ 步精确收敛**。
- **非线性 CG**（FR / PR）：$\beta$ 只依赖梯度历史，内存 $O(n)$，是大规模无约束优化的省内存之选；工程上要**重启**并截断 $\beta_k$。
- **预处理**：用 $M$ 压低条件数，迭代数从 $O(\kappa)$ 降到 $O(\sqrt{\kappa})$。
- 实战三件套：**重启**（丢旧共轭信息）、**PR+**（截断 $\beta$ 非负）、**预处理**（对角 Jacobi 起步）——非线性 CG 是否好用的差距，九成在这三条里。
- 一句话记忆：**最速下降是「走一步看一步」，牛顿是「一步到位」，CG 是「每步都不返工、且只花 $O(n)$ 内存」**——它是大规模稀疏系统的黄金折中点。
- 在《LLM 预训练》的优化器近似（如 GaLore 的低秩投影）里，CG 式的「方向记忆」思想也正在被重新挖掘。
- 边界提醒：CG 只适用**对称正定**系统；非对称问题要换 GMRES、BiCG 等 Krylov 兄弟——「CG 一统天下」是初学者最常见的越界假设。
- 收尾提醒：把本篇与《牛顿法与拟牛顿》对照——CG 的「共轭修正」是 $O(n)$ 内存下的曲率代理，L-BFGS 的「割线历史」是 $O(mn)$ 内存下的曲率代理，**两者都在为同一件事（曲率）付不同的租金**。
- 一句话总结全篇：**共轭 = 「压圆后的正交」，CG = 「让每一步都不返工且只要 $O(n)$ 内存的迭代」**。
- 下一篇将把「残差平方和」的结构化红利用足：从高斯-牛顿到 Levenberg-Marquardt——**最小二乘是少数几个能「既快又稳」的特例**。
