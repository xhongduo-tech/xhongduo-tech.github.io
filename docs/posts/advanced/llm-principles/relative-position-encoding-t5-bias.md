## 为什么"相对"比"绝对"更接近语言

人类理解句子时，几乎从不关心「这个词是第 47 个位置」，而关心「它和指代词隔了几个词」。**相对位置编码**把这个直觉直接做成模型结构：不编码「位置号」，而编码「位置差 $j - i$」。T5 的方案是其中最简洁的一个——把相对距离**离散化成桶**，每个桶学一个**可学习的偏置标量**，直接加到注意力分数上。<span class="marginnote">T5（Text-to-Text Transfer Transformer，2020）在「统一文本到文本」范式上名声大噪，其位置编码也成了经典。它的相对位置偏置只给「注意力分数」加一个标量偏置，不加到输入嵌入——位置信息因此只影响「谁更该被关注」，不影响「表示内容本身」。</span>

## 1 核心思想：距离分桶的偏置

T5 相对位置编码的要点：

- **相对距离**：位置 $i$ 对位置 $j$ 的「偏置」由 $j - i$ 决定（注意符号方向：$j$ 是 key 位置，$i$ 是 query 位置）。
- **分桶（bucketing）**：不直接对每个距离学一个参数（那会爆炸且难泛化），而是把距离**映射到有限个桶**。桶数 $n_b$ 通常取 32（单方向），T5 常用 **32 桶/方向**（双向共 64）。
- **每个桶学一个标量**：桶 $b$ 对应一个可学习标量 $\beta_b$，加在注意力分数上。

注意力分数变成：

$$
\text{score}(i, j) = \frac{q_i \cdot k_j}{\sqrt{d_k}} + \beta_{\text{bucket}(j-i)}
$$

其中 $\text{bucket}(\cdot)$ 是距离到桶的映射函数。<span class="marginnote">注意这个偏置<strong>加在 softmax 之前</strong>的注意力分数上，与因果掩码的加法是同一位置——所以「掩码 + 相对偏置」可以一次性加到 $QK^{\top}/\sqrt{d_k}$ 上再 softmax。实现上用一个<strong>「桶号 → 偏置值」的查表</strong>（形状 `[num_heads, num_buckets]`），每个头有自己的偏置向量。</span>

## 2 分桶函数：近处精细、远处粗糙

T5 的分桶设计非常巧妙，用一个「近线性、远对数」的映射：

```python
import math

def bucket(d, num_buckets=32, max_distance=128, bidirectional=True):
    """把相对距离 d = j - i 映射到有限个桶。"""
    if bidirectional:                       # 双向：正负各占一半桶
        num_buckets //= 2
        offset = num_buckets if d < 0 else 0
        d = abs(d)
    else:
        offset = 0
    max_exact = num_buckets // 2            # 近线性段的桶数（每距离一桶）
    if d < max_exact:                       # 近距离：线性分桶
        return offset + d
    # 远距离：对数分桶，越远越粗糙，并截断到最后一桶
    val = max_exact + int(
        math.log(d / max_exact) / math.log(max_distance / max_exact)
        * (num_buckets - max_exact)
    )
    return offset + min(val, num_buckets - 1)
```

直觉是：**距离 0–7 用精确的桶（每距离一桶），距离 8–127 用对数桶（越远越粗糙），超过 127 全部并到最后一个桶**。为什么这么设计？因为：

**近处需要精细**：邻近词的关系对语法至关重要（**冠词 the** 的**名词 cat** 与**动词 ran** 距离 1），必须区分得很细。
**远处可以粗糙**：距离 50 与距离 51 的「关系类型」几乎没有差别，合并它们能节省参数、增强泛化。
**超出训练范围仍有兜底**：最远桶兜住所有「很远」的距离，让模型对超长距离也有一个「超远关系」的响应，**天然支持外推**。<span class="marginnote">「近精细、远粗糙」是一个普遍的设计原则——人类对空间的感知也是如此：近处用米，远处用公里。对数分桶让有限个桶覆盖无限大的距离范围，这是它外推能力的来源。</span>

## 3 为什么加在"分数"而不是"表示"上

正弦编码把位置加到输入表示上（加性、表示级）；T5 把位置偏置加到**注意力分数**上（加性、分数级）。两者的差别很本质：

**表示级**：位置信息参与「每个 token 的表示是什么」——位置会影响特征内容。
**分数级**：位置信息只影响「谁被关注」——位置决定「关系」，不影响「内容」本身。

T5 的哲学是：**注意力决定关系，表示决定内容**。既然相对位置主要刻画「关系」（A 是 B 的宾语），把它放在「关系计算」的位置（注意力分数）更干净。这带来一个好处：**输入嵌入保持纯语义**，位置的「关系作用」与「内容作用」解耦。<span class="marginnote">对比 RoPE（乘法、分数级），T5 是「加法、分数级」——两者都在分数层做手脚，只是 RoPE 旋转的是 Q/K 向量本身，T5 加的是独立偏置。这个「加法偏置」家族还包括 ALiBi（固定的线性偏置），下一节会见到它的「无需学习」版本。</span>

## 4 公式解析：分桶偏置的外推行为

分析「近线性、远对数」分桶为什么能外推。设桶编号函数为 $b(d)$，偏置为 $\beta_{b(d)}$，则注意力分数：

$$
\text{score}(i, i+d) = \frac{q_i \cdot k_{i+d}}{\sqrt{d_k}} + \beta_{b(d)}
$$

对这条式子做三步拆解：

- **第一步，读懂 $d$ 的正负**：$d > 0$ 表示 key 在未来（推理时被掩码挡住，仅训练时存在）；$d < 0$ 表示 key 在过去。T5 用双向标志把正负分开映射到桶的上半区与下半区。
- **第二步，读懂 $\beta_{b(d)}$ 的粒度**：$\beta$ 的取值只分「桶」，同桶内的所有距离共享同一个偏置。近处桶细（每距离一个），远处桶粗（对数合并）——模型在近处学「精确距离关系」，在远处学「大方向关系」。
- **第三步，读出外推**：当 $d$ 超出训练见过的最大距离，$b(d)$ 落入最后一个桶，$\beta$ 取「超远关系」的偏置——**不会越界，也不要求模型见过这个精确距离**。这是「对数分桶天然支持外推」的数学本质：桶的个数有限，任何大的距离都能映射到已有的桶。

**辨析｜易错点：** T5 偏置是「每个注意力头一套」，不是全局一套。**每头一套独立偏置（`[num_heads, num_buckets]`）**的查表意味着不同头可以学不同的「距离偏好」——有的头偏爱邻近、有的偏爱全局。这与「多头提供多视角」的原则一致。别把桶数当成头的数量，它们是两个独立维度。

## 5 T5 相对编码与其他方案的对比

| 方案 | 位置信息注入点 | 是否需要学习 | 外推能力 |
| --- | --- | --- | --- |
| 正弦绝对 | 输入表示（加性） | 否 | 公式可算、效果衰减 |
| 可学习绝对 | 输入表示（加性） | 是 | 查表越界 |
| T5 相对偏置 | 注意力分数（加性） | 是（每个桶/头） | 对数桶兜底 |
| ALiBi | 注意力分数（加性） | 否（固定斜率） | 强 |
| RoPE | Q/K 向量（乘法） | 否 | 需插值 |

T5 的位置偏置虽然「需要学习」，但桶的数量有限（如 32 或 64），参数开销极小（**`num_heads × num_buckets`**，如 12×64=768），却能给注意力注入精确的相对距离先验——这是它长期被 encoder-decoder 与 T5 系模型使用的原因。

## 6 术语速查表

| 术语 | 英文 | 一句话定义 |
| --- | --- | --- |

| 偏置 | bias | 每个桶一个可学习标量 |

## 7 数值算例：不同距离落在哪个桶

设 32 桶（双向）、`max_distance=128`：

| 距离 $d$ | 桶号 | 说明 |
| --- | --- | --- |
| 1 | 1 | 近距离线性桶（精确） |
| 5 | 5 | 每距离一桶 |
| 30 | 约 16 | 对数桶（略粗糙） |
| 100 | 约 27 | 对数桶 |
| 500 | 31（最远桶） | 超远兜底 |

**读这张表**：距离 0–7 精确分桶，8–127 对数分桶，128+ 全部并到最远桶——**「近精细、远粗糙、超远兜底」的完整形态**。模型对「距离 1」能精确区分「相邻关系」，对「距离 500 与 600」则给同样的「超远关系」偏置。

**辨析｜易错点：** 桶号是「相对距离」的函数，与「绝对位置」无关——位置 10 对位置 8（$d=-2$）与位置 1000 对位置 998（$d=-2$）落在同一个桶。**「相对性」意味着模型学的是「距离关系」，可迁移到任何位置**——这正是相对编码能外推的结构原因。

## 8 位置编码四大流派速查

| 需求 | 位置编码 |
| --- | --- |
| 简单绝对 | 正弦 / 可学习 |
| 相对距离显式 | T5 偏置 |
| 免学习外推 | ALiBi |
| 现代开源主流 | RoPE |

T5 偏置是「相对位置思想」的经典落点——它用「有限桶 + 分数级偏置」把「相对距离」干净地注入注意力。理解它，就理解了「位置编码为什么越来越『相对』」。

## 9 小结

- T5 相对编码的要点：**距离分桶 + 每桶可学习标量偏置 + 加在注意力分数上**。
- 分桶函数**近线性、远对数**：近处精细、远处粗糙、最远兜底——外推能力的来源。
- 位置信息注入「分数级」而非「表示级」：**关系与内容解耦**。
- 每个头一套偏置，**按桶号索引**查表，参数极少。
- 与正弦编码、ALiBi、RoPE 共同构成位置编码的四大流派。
