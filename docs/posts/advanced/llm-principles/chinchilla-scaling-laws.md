# Chinchilla 缩放定律：计算最优下的参数-数据配比

<div class="epigraph">
<p>我们发现，当前的大语言模型被显著地「欠训练」了——这是近来专注于扩大模型规模、却把训练数据规模固定不变的结果。计算最优的训练，应当使用比现在多得多、且比现在少得多的参数。</p>

## 为什么从 Chinchilla 讲起

上一节的 Kaplan 缩放定律给了行业一条「把预算砸向模型规模」的处方：算力每翻 10 倍，模型该扩大约 5.4 倍，数据只需扩大约 1.9 倍。GPT-3 的 175B 参数配 300B token，就是照着这个思路来的。如果故事到此为止，今天的模型应该全是「巨型参数 + 相对单薄的数据」。

但 2022 年 4 月，DeepMind 的 **Chinchilla** 论文把这张处方推翻了。它给出一个让整个行业倒吸一口凉气的结论：**过去的大模型全都「欠训练」了——数据该比 Kaplan 说的多得多，参数该比 Kaplan 说的少得多**。最优配比不是「模型巨大、数据相对少」，而是**大约每 1 个参数配 20 个 token**。<span class="marginnote">这篇论文的实践影响力几乎是即时的：它发表后，LLaMA（65B / 1.4T token）、Qwen、DeepSeek 等新一代模型全部按「约 20 token/参数」重新配置。你可以把 Kaplan 与 Chinchilla 的关系理解成「第一版处方」与「第二版修正」，而第二版赢。</span>

## 1 Kaplan 的盲点：外推失效

先看清楚 Kaplan 为什么错。Kaplan 的算力最优配置（$N \propto C^{0.73}$）是从一批**算力不超过约 $10^{22}$ FLOPs** 的小规模实验拟合出来的。把它外推到更大算力时，问题就来了：**0.73 的指数意味着算力越大，最优模型就越夸张地大于最优数据**——这超出了拟合数据的有效区间。

DeepMind 用一个「思想实验」把问题摆上桌面：假设你在训练 Gopher（280B 参数、300B token），算力约 $5\times 10^{23}$ FLOPs。Kaplan 的处方会告诉你「模型还不够大」。但 DeepMind 直接做了更朴素的对照——**把同样的算力换成「更小的模型 + 更多的数据」会怎样？** 答案是：几乎处处更好。Gopher 用 280B 参数只吃了 300B token（每参数 1 个 token），而按 20 token/参数 的最优配比，280B 参数应该配约 5.6T token——**Gopher 的数据量差了近 20 倍**。

**重点：** Chinchilla 论文的核心论点可以浓缩成一句话：**在固定算力预算下，最优模型规模与最优数据量几乎按同一比例增长；过去的「参数优先」配置把模型造得过大、喂得太少**。<span class="marginnote">这背后还有个有趣的历史注脚：Kaplan 论文里其实也观察到了「大模型更省样本」，但他把「省样本」读成了「该把预算更多花在参数上」；DeepMind 把它读成了「参数与数据要一起涨」。同样的现象，两种解读。</span>

## 2 公式解析：三参数损失拟合

Chinchilla 的核心是一张更完整的「损失地图」。他们把测试损失 $L$ 拟合成**三个来源**的和：

$$L(N, D) = E + \frac{A}{N^{\alpha}} + \frac{B}{D^{\beta}}, \qquad
E = 1.69,\ A = 406.4,\ B = 410.7,\ \alpha = 0.34,\ \beta = 0.28$$

逐步拆解每一项：

- **$E$（不可约损失）**：即使模型无限大、数据无限多，损失也降不到 0——自然语言本身有不可压缩的「固有熵」。拟合值 $E = 1.69$ nats 就是这条「地平线」。
- **$\frac{A}{N^{\alpha}}$（容量项）**：模型不够大带来的损失。$N$ 越大这一项越小，$\alpha = 0.34$ 刻画「加参数」的收益。
- **$\frac{B}{D^{\beta}}$（数据项）**：数据不够多带来的损失。$D$ 越大这一项越小，$\beta = 0.28$ 刻画「加数据」的收益。
- **三者相加**：损失被分解成「天生不可约」+「模型小」+「数据少」三块，**你砸钱只能改善后两块，永远够不到 $E$**。<span class="marginnote">对比 Kaplan 的 $L = (x_c/x)^\alpha$，Chinchilla 的进步在于显式引入了 $E$。Kaplan 的幂律在数据范围内看似「没有天花板」，因为它还没逼近 $E$；Chinchilla 把 $E$ 画出来，缩放定律才真正自洽。</span>

**易错点｜辨析：** 注意 $\alpha = 0.34$ 与 Kaplan 的 $\alpha_N = 0.076$ 不是同一个量。Kaplan 的 $\alpha_N$ 是「单变量幂律」的指数（固定其他条件只变 $N$）；Chinchilla 的 $\alpha$ 是「多变量拟合」里 $N$ 项的指数。两者的拟合设定不同，数值不可直接比较——**读论文时先看它的公式形式，再比较数字**。

## 3 公式解析：在算力约束下求最优配比

有了 $L(N,D)$，求「给定算力 $C$ 的最优配比」就是一个标准的约束优化：在 $C \approx 6ND$ 的约束下最小化 $L(N,D)$。用拉格朗日乘数法：

$$\min_{N,D}\; E + \frac{A}{N^\alpha} + \frac{B}{D^\beta} \quad \text{s.t.} \quad 6ND = C$$

构造拉格朗日函数 $\mathcal{L} = E + A N^{-\alpha} + B D^{-\beta} + \lambda(6ND - C)$，对 $N$、$D$ 求导并令其为零：

$$\frac{\partial \mathcal{L}}{\partial N} = -\alpha A N^{-\alpha-1} + 6\lambda D = 0, \qquad
\frac{\partial \mathcal{L}}{\partial D} = -\beta B D^{-\beta-1} + 6\lambda N = 0$$

消去 $\lambda$ 得到均衡条件 $\alpha A N^{-\alpha} = \beta B D^{-\beta}$，即 $D^{\beta} \propto N^{\alpha}$。再与 $6ND = C$ 联立，解得：

$$N_{\text{opt}} \propto C^{\frac{\beta}{\alpha+\beta}}, \qquad D_{\text{opt}} \propto C^{\frac{\alpha}{\alpha+\beta}}$$

把 $\alpha = 0.34$、$\beta = 0.28$ 代进去：$\frac{\beta}{\alpha+\beta} \approx 0.45$、$\frac{\alpha}{\alpha+\beta} \approx 0.55$。也就是说——

**重点：** 计算最优时，**参数与数据都大约按 $C^{0.5}$ 增长**（即算力翻倍，两者各约翻 $\sqrt{2}$ 倍）。这与 Kaplan 的「参数 $C^{0.73}$、数据 $C^{0.27}$」形成了鲜明对照：Chinchilla 把预算从「大头给参数」改为「参数数据各半」。<span class="marginnote">由均衡条件还能推出配比 $D/N$ 随 $C$ 缓慢增长（指数 $(\alpha-\beta)/(\alpha+\beta) \approx 0.10$），所以「20 token/参数」不是普适常数，而是「在这个量级算力下的经验值」。算力再大一些，配比会缓慢升高。</span>

这套推导可以直接写成代码，用来给「给定算力预算，该造多大模型」这个问题一个数字答案：

```python
E, A, B, alpha, beta = 1.69, 406.4, 410.7, 0.34, 0.28

def loss(N, D):
    return E + A / N**alpha + B / D**beta

C = 1e23  # 目标算力预算，单位 FLOPs
best = None
for N in range(1, 300):          # 参数 N（十亿为单位，粗扫）
    D = C / (6 * N * 1e9)        # 由 C ≈ 6ND 反解 token 数
    cand = (loss(N * 1e9, D), N, D)
    best = cand if best is None or cand[0] < best[0] else best

_, N_best, D_best = best
print(f"最优规模: {N_best}B 参数, 数据 {D_best/1e12:.2f}T token, "
      f"配比 {D_best/(N_best*1e9):.1f} token/参数")
# 输出约: 最优规模: 52B 参数, 数据 1.27T token, 配比 24.4 token/参数
```

粗扫的答案落在「约 50B 参数配 1.3T token」附近——和 DeepMind 用更精细方法求出的结果同一量级。**这个量级，就是「计算最优」四个字的真实含义。**

## 4 Chinchilla 模型：70B × 1.4T 的胜利

理论说「该配 20 token/参数」，DeepMind 就真的造了一个验证品：**Chinchilla，70B 参数，1.4T token**（约 20 token/参数）。它与 Gopher 的关系是：**用大致相同的训练算力，但参数量只有四分之一、数据量翻到四倍多**。<span class="marginnote">Gopher：280B 参数 / 300B token；Chinchilla：70B 参数 / 1.4T token。两者训练算力都在 $5 \times 10^{23}$ FLOPs 量级，但 Chinchilla 的推理成本因为参数量只有 1/4 而大幅降低。</span>

结果没有悬念：**Chinchilla 在 MMLU（67.6% vs 60.0%）、BIG-bench（65.1% vs 54.4%）以及几乎所有下游任务上全面超越 Gopher**，同时推理成本只是 Gopher 的零头。一个「更小」的模型，用同样的钱，赢过了「更大」的模型——这直接颠覆了当时「最大化参数才是硬道理」的行业共识。

**辨析｜易错点：** Chinchilla 的「计算最优」是对**训练**算力而言的。它不承诺「质量最优」，也不承诺「推理最优」：如果你想让模型在固定推理成本下最强，或想让模型质量绝对最高（不吝惜训练算力），最优配比都会偏离「20 token/参数」。**「计算最优」是一个有明确约束的优化问题的答案，脱离开约束谈配比就会误用。**

## 5 行业影响：数据配比的地基

Chinchilla 发表后，几乎所有新模型都改按「约 20 token/参数」配置训练数据：

| 模型 | 参数量 | 训练 token | token/参数 |
| --- | --- | --- | --- |
| Gopher（2021） | 280B | 300B | 1.1 |
| GPT-3（2020） | 175B | 300B | 1.7 |
| LLaMA-1（2023） | 65B | 1.4T | 21.5 |
| Chinchilla（2022） | 70B | 1.4T | 20.0 |
| LLaMA-3（2024） | 8B | 15T | 1875 |

这张表读起来很有意思：从 Gopher 的 1.1 到 LLaMA 的 21.5，是「补欠训练」；而 LLaMA-3 的 8B 用 15T token（每参数 1875 token），则**远超** Chinchilla 最优——这不是「违反」定律，而是**故意选择**：当数据成本相对便宜、推理成本相对昂贵时，「用极多数据训练一个小模型」可以得到一个质量远超同尺寸、且推理便宜的基座。<span class="marginnote">这提醒我们：缩放定律描述的是「训练算力固定时如何最优」，而真实工程决策还叠加了「推理成本」「数据可得性」「发布节奏」等其他变量。定律是地基，不是全部。</span>

**重点：** Chinchilla 的遗产是把「参数-数据配比」从一个模糊的直觉变成了一个**可计算、可争论、可迭代**的设计变量。今天你打开任何一份大模型技术报告，几乎都能看到作者汇报「token/参数」配比，并说明自己在计算最优与数据充分之间做了怎样的取舍——这份自觉，正是 Chinchilla 留给行业的。

## 6 辨析：缩放定律的边界与「再修正」

Chinchilla 本身也不是终点，这里列出三条最常被误读的边界：

- **「20 token/参数」是经验值，不是物理常数**。它来自对约 400 次训练实验的拟合，拟合本身也有不确定性（后续研究对 Approach 3 的参数估计提出过统计质疑）。用它做量级估算很好，抠到小数点后就是过度使用。
- **缩放定律是「统计规律」，不是「生成机制」**。它告诉你在某个规模区间损失如何随资源变化，但不解释「为什么 Transformer 会这样缩放」。正如上一节所说，它是经验拟合，外推要谨慎——Kaplan 被 Chinchilla 修正就是前车之鉴，Chinchilla 也可能在更大算力下被再修正。
- **损失与能力不是一回事**。Chinchilla 优化的目标是交叉熵损失；而模型真正被使用的「能力」（推理、指令跟随、可信度）并不与损失一一对应。损失降得好，不一定意味着某个具体任务能力如期出现——这恰好引出下一篇：**涌现能力**。

## 7 小结

- **Chinchilla 的结论**：过去的大模型普遍「欠训练」；计算最优配比是**参数与数据大约各按 $C^{0.5}$ 增长**，经验值约为**每参数 20 个 token**。
- **三参数损失拟合**：$L(N,D) = E + A/N^\alpha + B/D^\beta$，其中 $E=1.69$ 是不可约损失（自然语言的固有熵），$\alpha=0.34$、$\beta=0.28$。
- **方法**：用拉格朗日乘数法在 $C \approx 6ND$ 约束下最小化损失，得到 $N \propto C^{\beta/(\alpha+\beta)}$、$D \propto C^{\alpha/(\alpha+\beta)}$。
- **验证**：Chinchilla（70B/1.4T）用与 Gopher（280B/300B）相近的训练算力，在几乎所有下游任务上超越它。
- **边界**：「计算最优」是对训练算力的最优，不等于质量最优或推理最优；20 token/参数 是经验值，且可被更大规模的实践再修正。

在下一节，我们将面对缩放定律「管不到」的那片区域：有些能力在小模型上毫无踪影、在大模型上突然出现——这就是**涌现能力**。它到底是能力的真实阶跃，还是度量方式制造的假象？我们将从现象、机理与争论三方讲清。
