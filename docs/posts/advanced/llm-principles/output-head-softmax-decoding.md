## 为什么「logits 之后」还有学问

模型前向的终点是 logits——每个 token 一个分数。但从 logits 到「实际输出的文本」之间还有一整片决策空间：**选哪个 token、怎么权衡多样性、如何避免重复**。这部分叫**解码（decoding）**。看似只是「取最大还是采样」的选择，实则决定了模型的「性格」——temperature 控制冒险程度、top-k 控制视野、top-p 控制质量。<span class="marginnote">解码策略是把「概率分布」变成「具体输出」的策略——它是「数学」到「体验」的最后一层翻译。同样的模型，用不同解码策略可以输出截然不同的文本：贪心最稳但呆板，高温采样最活但可能离谱。理解解码，才算理解「模型怎么说话」。</span>

## 1 输出头与 Softmax：logits 到概率

输出头把最后一层表示映射到词表空间，得到 logits $z \in \mathbb{R}^{V}$；Softmax 把 logits 变成概率分布：

$$
p(w) = \frac{\exp(z_w / T)}{\sum_{v=1}^{V} \exp(z_v / T)}
$$

其中 $T$ 是**温度（temperature）**。注意温度 $T$ 出现在分母上：

- $T = 1$：标准 softmax。
- $T > 1$：logits 被「除小」——分布变**平缓**（更随机、更多样）。
- $T < 1$：logits 被「除大」——分布变**尖锐**（更确定、更保守）。
- $T \to 0$：退化为 argmax（贪心）。

**温度的直觉**：$T$ 控制「模型有多敢赌」——高温让「次优 token」也有机会，低温让「最优 token」几乎必胜。<span class="marginnote">形象理解：温度是「创造力的旋钮」。写代码要低温度（0.1–0.3）——要准确；写故事要高温度（0.8–1.2）——要多样。这也解释了为什么「同一个模型 + 不同 temperature」能覆盖「严谨」与「创意」两种需求——解码策略就是模型的「人格调节器」。</span>

## 2 贪心解码与 Top-k

**贪心解码（greedy decoding）**：每步选概率最大的 token：

$$
w_t = \arg\max_w p(w \mid x_{\\lt t})
$$

- 优点：确定、稳定。
- 缺点：**呆板且易重复**——贪心会陷入「我我我我」或「然后然后然后」的循环；且「每一步局部最优 ≠ 全局最优」——一个次优的起始词可能导向更好的整句，贪心永远发现不了。

**Top-k 采样**：从概率最高的 $k$ 个 token 中采样（按它们的归一化概率）：

$$
p'(w) = \frac{p(w)}{\sum_{v \in \mathcal{V}_{\text{top-k}}} p(v)} \quad \text{若 } w \in \mathcal{V}_{\text{top-k}}，\text{否则 } 0
$$

其中 $\mathcal{V}_{\text{top-k}}$ 是概率最高的 $k$ 个 token 的集合。

- 优点：避免「几乎不可能的 token」；比贪心多样。
- 缺点：$k$ 是**全局固定**的——但「该看多少个候选」应该随上下文变化（有的地方很确定，只需 1 个候选；有的地方很开放，需要 50 个）。Top-k 用固定的 $k$ 无法适应这种「分布形状」的变化。<span class="marginnote">Top-k 的「固定 k」问题：设某一步概率分布很集中（top-1 占 90%），Top-k=50 会从「一堆几乎不可能的」里采样——浪费；反过来分布很平（top-50 各占 2%），Top-k=50 又「太窄」。这就是 Top-p 出现的动机：<strong>用「累计概率」代替「固定数量」</strong>，让候选集合随分布形状自适应。</span>

## 3 Top-p（核采样）：按累计概率截断

**Top-p（nucleus sampling）**：选「累计概率刚好超过 $p$」的最小集合作为候选：

$$
\mathcal{V}_{\text{top-p}} = \text{最小的 } S，使得 \sum_{w \in S} p(w) \ge p
$$

- 候选集合的**大小是自适应的**：分布集中时集合小，分布平坦时集合大。
- $p$ 通常取 0.9–0.95——「保留 90% 的概率质量」。
- 效果：在「确定的地方严格」、在「开放的地方放开」——比 Top-k 更贴合「人类的生成直觉」。

**对比总结**：

| 策略 | 机制 | 多样性 | 稳定性 | 典型参数 |
| --- | --- | --- | --- | --- |
| 贪心 | 取 max | 最低 | 最高 | 无 |
| 纯采样 | 按全分布采样 | 最高 | 最低 | 无 |
| Top-k | 从 top-k 采样 | 中 | 中 | $k=50$ |
| Top-p | 从累计概率 $p$ 采样 | 中-高 | 中 | $p=0.9$ |
| Top-k + Top-p | 组合 | 高 | 中-高 | $k=50, p=0.9$ |

**工业实践**：几乎都用「Top-k + Top-p + Temperature」组合——先 Top-k 粗滤、再 Top-p 精滤、最后温度采样。

## 4 公式解析：Temperature 对分布形状的影响

设原始 logits 为 $z$，温度 $T$。考察「最高分 $z_{\max}$ 与次高分 $z_{\text{next}}$」之间的概率比：

$$
\frac{p(w_{\max})}{p(w_{\text{next}})} = \exp\left(\frac{z_{\max} - z_{\text{next}}}{T}\right)
$$

对这条式子做三步拆解：

- **第一步，读懂差 $z_{\max} - z_{\text{next}}$**：这是「最优与次优的 logits 差距」。差距越大，本来就越确定。
- **第二步，读懂 $T$ 的分母作用**：$T > 1$ 时指数变小——**差距被「稀释」，两者概率比趋近 1**（更接近「均等机会」）；$T < 1$ 时指数变大——**差距被放大**，最优 token 概率比飙升（更确定）。
- **第三步，读出温度的本质**：**温度是「logits 差距的放大器/稀释器」**——它不改变 token 的排序（$T>0$ 时单调保持），只改变「差距的感知强度」。所以「低温度 = 更确定的输出」在数学上就是「把差距放大到几乎必胜」。

**辨析｜易错点：** 温度**不改变 token 的相对排序**——$z_a > z_b$ 时，无论 $T$ 取多少，$p(a) > p(b)$ 恒成立。温度改变的是「概率的集中程度」，不是「哪个 token 更优」。想让「次优变最优」必须靠采样（随机性），不是靠调温——**温度调「集中度」，采样调「偶然性」**。

## 5 更高级的解码策略

- **Beam Search（束搜索）**：每一步保留 top-k 条完整路径，最后选总概率最高的一条——**追求「全局最优」，适合翻译/摘要**，但计算量大、可能过度重复。
- **Repetition penalty / no_repeat_ngram**：惩罚已出现的 n-gram，抑制重复。
- **Contrastive Search（对比搜索）**：兼顾「与已生成内容的差异」与「预测质量」，是「高质量长文生成」的优选。
- **Speculative decoding（推测解码）**：用小模型「猜」多个候选，大模型一次验证——**加速采样**（见大模型部署专题）。

## 7 数值算例：温度如何改变「差距感知」

设最优与次优 logits 差 $\Delta = z_{\max} - z_{\text{next}} = 2$：

| 温度 $T$ | 概率比 $e^{\Delta/T}$ | 效果 |
| --- | --- | --- |
| 0.5 | $e^4 \approx 54.6$ | 几乎必胜（确定） |
| 1.0 | $e^2 \approx 7.4$ | 明显偏好最优 |
| 2.0 | $e^1 \approx 2.7$ | 次优也有机会（多样） |

**读这张表**：同一个 logits 差距 2，温度 0.5 时最优 token 概率是次优的 54 倍，温度 2 时只剩 2.7 倍——**温度把「确定的差距」放大或稀释**。这也解释了「写代码用低温度、写故事用高温度」的直觉来源。

**辨析｜易错点：** 温度「不改变排序」——任何温度下「最优 token 仍是概率最大」。想让「次优 token 被选中」只能靠「采样」（引入随机性）。**低温度 = 更确定，高温度 = 更随机，但「哪个最优」不变**——别把「调温」当成「改答案」。

## 8 场景 → 解码策略速查

| 场景 | 解码策略 |
| --- | --- |
| 翻译 / 摘要 | Beam Search |
| 写代码 | 低温度 Top-p（0.1–0.3） |
| 写故事 / 创意 | 高温 Top-p（0.8–1.2） |
| 问答 | 低温度（0.2–0.5） |
| 高质量长文 | 对比搜索 |

**原则**：**「准确优先」用低温度 + 束搜索，「多样优先」用高温度 + Top-p**——解码策略是「按任务调模型人格」的旋钮。

## 9 小结

- **输出头 + Softmax**：logits → 概率；**温度 $T$ 是「logits 差距的放大/稀释器」**。
- **贪心**：最稳最呆，易重复；**Top-k**：固定候选数，无法自适应。
- **Top-p**：按累计概率截断，候选集自适应——「该严则严、该放则放」。
- 工业标配：**Top-k + Top-p + Temperature** 组合。
- 高级策略：Beam Search（全局最优）、对比搜索、推测解码。
