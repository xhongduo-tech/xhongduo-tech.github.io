# T5 与统一文本到文本（Text-to-Text）范式

## 为什么从统一范式讲起

上一节我们看到 GPT 路线用「把规模做到极端」逼出了上下文学习。本节的主角 T5 走了另一条路：**不靠更大，靠更统一**。2019 年 10 月，谷歌的 Raffel 等人发表《Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer》，提出一个极简抽象——**把一切 NLP 任务都写成「文本进、文本出」**。翻译是「文本进、文本出」，摘要也是，情感分类还是。既然是同一个形状，就能用同一个模型、同一个损失、同一个解码过程。

这个「统一」看似只是工程上的整理，实际带来的是一份巨大的方法论红利：**当所有任务共用一套骨架，研究者就能像控制变量一样，逐个对比预训练目标、模型大小、数据规模的影响**。T5 论文因此成为 NLP 历史上最著名的一份「消融实验教科书」——后来的很多预训练决策（比如「掩码 span 比逐词掩码好」「更大模型更平滑地涨点」）都出自它的实验表格。

## 1 文本到文本：给每个任务加一个前缀

T5 的做法直白到令人惊讶：给每个任务规定一个**任务前缀（task prefix）**，把「任务指令」和「任务输入」拼成一段文本，模型需要输出的也只是一段文本。

```text
翻译：把英语翻译成德语     "That is good."      => "Das ist gut."
摘要：summarize            "…长文章…"            => "一句话摘要"
分类：cola sentence        "It is raining."     => "acceptable"
相似度：stsb sentence1 …   "猫" / "狗"           => "3.8"（0–5 分）
```

无论原任务是生成、分类还是回归，输入输出都被重写成**文本**：分类的标签变成文本（`acceptable` / `unacceptable`），相似度分数也变成文本（`3.8`）。<span class="marginnote">「把分数写成文本」看起来有点浪费，但它是统一的关键一步——模型只需要学会「读文本、写文本」一种能力，其余全部交给解码。这个思想后来演化为各类「提示前缀」，是 In-Context Learning 的同行者。</span>

**重点：** 统一的代价与收益并存。代价是「把回归当文本生成」在数值精度上吃亏；收益是**架构、损失函数、解码过程全站共享**，让「对比实验」变得干净。T5 论文把这一点贯彻到了极致——所有实验用同一个 3B 模型、同一种训练方式，只改一个变量。

## 2 公式解析：Text-to-Text 的条件概率目标

统一框架的数学形式极其简洁：对所有「输入-目标」对做最大似然。

$$
\max_{\theta} \sum_{(x, y) \in \mathcal{D}} \log p_{\theta}(y \mid x)
$$

- **$(x, y)$**：一对「输入文本-目标文本」。$x$ 是加了前缀的任务输入（如 `translate English to German: That is good.`），$y$ 是期望输出（如 `Das ist gut.`）。
- **$p_{\theta}(y \mid x)$**：编码器-解码器模型把 $x$ 编码成上下文，再**自回归地生成 $y$**——每次生成一个 token，条件于「已经生成的 $y_{<t}$」。这与我们在上一节见到的条件概率完全同构，只是这里的条件里明确含「任务前缀」。
- **$\sum_{(x,y)}$**：对所有任务的（输入，目标）对求和。**不同任务只是不同的 $(x,y)$ 对**，权重与损失形状没有区别。

**易错点｜辨析：** T5 的「统一」不意味着「只有一个损失」。它仍然是「序列到序列的最大似然」——只是把**分类**（softmax 在标签集上）与**回归**（均方误差）全部**重新包装成文本生成**。包装不改变任务难度，改变的是**任务的接口**。接口统一之后，多任务联合训练（把不同任务的数据混在一起训）就变成了一件自然的事。

## 3 数据工程：C4 与「干净的网页」

T5 需要一份足够大的通用语料来支撑系统性实验。当时的主流语料各有短板：BooksCorpus 只有书籍，WebText 未公开。T5 于是自建了 **C4（Colossal Clean Crawled Corpus，巨型干净爬虫语料）**——从 2019 年 4 月的 Common Crawl 网页快照出发，经过一套**启发式清洗流水线**，得到约 **750 GB、约 1560 亿 token** 的英文文本。<span class="marginnote">C4 的清洗规则包括：只留以句号/问号/叹号结尾的行、删掉少于 5 句的页面、去掉含「lorem ipsum」或花括号 `{}`（代码/模板）的页面、用词表过滤脏词、语言识别置信度 ≥ 0.99，最后做「三句去重」——任何连续三句在语料中重复出现即被删去。这些规则后来成为开源数据管线（如 RedPajama、FineWeb）的直接祖先。</span>

但「干净」是有代价的。2021 年 Dodge 等人的审计发现：C4 的脏词过滤等启发式规则**不成比例地删掉了少数族裔与方言写作**——所谓「干净」，其实隐含着一种文化偏好。<span class="marginnote">数据审计是预训练数据工程里的「冷门但致命」一环：清洗规则在删除噪声的同时，也在塑造模型学到什么、学不到什么。本专题《预训练数据工程》篇会展开「清洗的政治经济学」。</span>

**重点：** C4 的价值不只是「大」，而是**可复现**——它让 T5 的所有消融实验在同一份数据上公平比较。数据工程与实验方法论的绑定，是 T5 成为「教科书」的隐性前提。

## 4 Span Corruption：用哨兵 token 压缩掩码

预训练目标怎么选？BERT 的 MLM 是逐词掩码，但 T5 注意到一个工程细节：**逐词掩码的训练信号太稀疏、且生成任务需要更长的目标**。T5 的方案是 **Span Corruption（跨度破坏）**：随机掩掉一段**连续**的 token 序列（平均长度约 3 个 token，共占 15%），用**一个哨兵 token** 代替整段，模型需要把这段内容「补写」出来。

举例，原始文本：

```text
Thank you for inviting me to your party last week.
```

随机选两段破坏（`for inviting` 与 `last week`），用哨兵 token `<X>`、`<Y>` 替换后作为**输入**：

```text
Thank you <X> me to your party <Y> .
```

模型的**目标**是把这两个哨兵分别「展开」成被掩掉的跨度，并按序重新拼接：

```text
<X> for inviting <Y> last week <Z>
```

最后一个哨兵 `<Z>` 是「结束标记」——它告诉模型「所有跨度都补完了」。<span class="marginnote">哨兵 token 是 T5 的一个精巧设计：它让「目标」不再是「被破坏的整句」，而是「一串待填充的跨度」，长度大幅变短、训练更快，同时强迫模型按原文顺序复原内容。若掩码长度固定为 1，Span Corruption 就退化成 BERT 式 MLM——所以 MLM 是 Span Corruption 的特例。</span>

**重点：** 相比逐词 MLM，Span Corruption 有两个优势：**目标更短**（训练吞吐更高）、**更像「生成」**（模型要把一段话补全，而不只是猜一个词）——这与 T5「文本到文本」的生成取向天然契合。

## 5 公式解析：Span Corruption 的输入-目标构造

把上面的例子抽象成公式。设原始序列为 $\mathbf{x} = x_1 x_2 \cdots x_n$，随机选中 $M$ 段互不相交的跨度 $\mathcal{S} = \{s_1, \ldots, s_M\}$：

$$
\tilde{\mathbf{x}} = \phi\big(\mathbf{x}, \mathcal{S}\big), \qquad
\mathbf{y} = s_1 \ \langle X_2 \rangle \ s_2 \ \cdots \ \langle X_M \rangle s_M \ \langle X_{M+1} \rangle
$$

- **$\tilde{\mathbf{x}}$（输入）**：把 $\mathbf{x}$ 中每段 $s_j$ 替换为哨兵 $\langle X_j \rangle$ 得到的**损坏序列**——模型只能看到它。
- **$\mathbf{y}$（目标）**：依次输出每段被掩掉的内容，段与段之间用哨兵 token 隔开，最后以哨兵 $\langle X_{M+1} \rangle$ 结尾。
- **训练损失**：与上一节一样，最大化 $\log p_\theta(\mathbf{y} \mid \tilde{\mathbf{x}})$，即**给定损坏输入、复原完整跨度**。

**易错点｜辨析：** 目标里的哨兵顺序必须与输入里的破坏顺序一致——它们不是「同一个 token 的多次使用」，而是**位置占位符**。模型要学会「输入里第 $j$ 个哨兵对应的内容，就填在输出的第 $j$ 个位置」。哨兵之间没有共享参数语义，只是「第几个坑」的标记。

## 6 规模谱系与消融实验的方法论

T5 一口气训练了五个尺寸，全部是编码器-解码器结构：

| 模型 | 参数量 |
| --- | --- |
| T5-Small | 6000 万 |
| T5-Base | 2.2 亿 |
| T5-Large | 7.7 亿 |
| T5-3B | 30 亿 |
| T5-11B | 110 亿 |

然后在同一份 C4 数据上系统对比了十几种预训练目标的组合——前缀语言模型（prefix LM）、BERT 式逐词掩码、Span Corruption，以及不同的掩码比例与跨度长度——最后得出结论：**Span Corruption 综合最优**。

更重要的是 T5 的**方法论**：它在可控条件下回答了「迁移学习里哪些设计真正有用」，这比任何单个模型的刷榜都更有长远价值。<span class="marginnote">T5 的结论可以浓缩成几条：① span 破坏优于逐词掩码；② 更大的模型带来平滑且持续的提升；③ 多任务微调 + 模型在通用语料上继续训练可以进一步提升。这些结论后来直接影响了 T0、Flan-T5 等指令微调家族。</span>

**重点：** T5 证明了「统一」本身就是一种研究策略——**当所有任务长成一个样子，你就能一个变量一个变量地做实验**。这种「系统化」气质，与 GPT 路线的「规模即能力」形成互补：一个在宽度上统一，一个在高度上突破。

## 7 小结

- **T5 的抽象**：一切 NLP 任务 = **文本进、文本出**；分类、回归、生成统一为条件概率 $\max_\theta \sum \log p_\theta(y \mid x)$。
- **C4 数据集**：约 750 GB 的启发式清洗网页语料，成为开源数据管线的祖先；其清洗规则也隐含文化偏好，是数据审计的经典案例。
- **Span Corruption**：掩 15% 的连续跨度、用哨兵 token 代替，模型复原跨度；它是 BERT 式 MLM 的推广，目标更短、更接近生成。
- **统一范式的方法论红利**：同一骨架让研究者能做「控制变量」的消融实验，结论（span 破坏更优、更大更平滑）直接滋养了后续指令微调家族。
- 与 GPT 路线互补：**一个在宽度上统一，一个在高度上突破**。
