# 大模型原理

LLM 为什么有效：架构、数据、训练与缩放的系统性拆解。

## 主题规划

- [ ] 大模型发展史：从 GPT-1 到 GPT-4 及开源生态
- [ ] 缩放定律（Scaling Laws）：Kaplan 与 Chinchilla
- [ ] Tokenizer：BPE、WordPiece 与 SentencePiece
- [ ] GPT 架构详解：Decoder-only 的每一处设计
- [ ] 主流架构对比：LLaMA、Qwen、DeepSeek 与 Gemma
- [ ] 位置编码的演进：RoPE、ALiBi 与 YaRN
- [ ] 注意力变体：MQA、GQA 与 MLA
- [ ] 归一化与激活：Pre-LN、RMSNorm 与 SwiGLU
- [ ] 预训练数据工程：清洗、去重、配比与质量筛选
- [ ] 预训练目标：CLM、MLM、UL2 与课程学习
- [ ] 长上下文技术：外推、插值与稀疏注意力
- [ ] 混合专家模型（MoE）：路由、负载均衡与 DeepSeekMoE
- [ ] 多模态大模型：视觉编码器、对齐与 VLM 架构
- [ ] 推理能力：Chain-of-Thought 与测试时计算（Test-time Compute）
- [ ] 检索增强生成（RAG）：索引、检索与重排
- [ ] Agent 范式：工具调用、规划与多智能体
- [ ] 幻觉的来源、检测与缓解
- [ ] 大模型评测：Benchmark、人工评测与 LLM-as-a-Judge
- [ ] 对齐（Alignment）总览：SFT、RLHF 与宪法 AI
