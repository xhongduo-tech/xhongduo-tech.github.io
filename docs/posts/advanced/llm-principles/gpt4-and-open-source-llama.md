## 为什么从开源生态讲起

前几节我们走完了「规模即能力」的路线图：GPT-3 证明了大模型的涌现式上下文学习，InstructGPT 与 ChatGPT 证明了对齐可以被工程化。但 2023 年之后的世界，出现了两个明显分化的阵营：**闭源前沿**与**开源生态**。

2023 年 3 月 14 日，OpenAI 发布 GPT-4，能力空前，却只给了一篇「几乎没有技术细节」的技术报告——架构、规模、训练方法全部保密。而就在两个月前，Meta 悄悄发布了 LLaMA，把「用公开数据训练出接近 GPT-3 的模型」这件事变成了一串可下载的权重。一场由 LLaMA 引爆的社区爆发就此开始：Alpaca、Vicuna、Guanaco 在几周内接连出现，微调成本从千万美元级骤降到几百美元。**这一节讲的就是这段「闭源登顶、开源追上」的历史，以及它留下的范式遗产。**<span class="marginnote">「开源」一词在本节需要谨慎使用：我们更准确地说它们是「开放权重（open-weight）」。权重可下载 ≠ 训练数据、代码、全过程公开，二者的法律与科学含义差异极大，第三节会专门辨析。</span>

## 1 GPT-4：闭源的顶点

GPT-4 是当时（2023 年 3 月）能力最强的模型：支持图像与文本输入，在 SAT、Uniform Bar Exam 等大量标准化考试中超过 90% 的人类考生，多语言与长文本能力都远超 GPT-3.5。<span class="marginnote">GPT-4 的多模态是「视觉编码器 + 语言模型」的复合输入，与后来把图像直接 token 化的原生多模态不同——这条线索会在本专题《多模态大模型》一篇详细展开。</span>

但真正划时代的不是能力，而是它的「黑箱姿态」。技术报告通篇在谈**评测与安全**，唯独不谈**架构与训练**。OpenAI 在随后的博客《Containing the Ascent》中解释：前沿模型能力太强、风险太高，需要「渐进式部署」。这套逻辑有其正当性，却也把「顶级模型如何训练」这个科学问题关进了保险箱。

**重点：** GPT-4 的封闭，让「复现顶级模型」变得不可能；而恰好在这时，一条完全相反的路——把权重直接交到社区手里——正在 Meta 的实验室里生长。

## 2 LLaMA-1：公开数据与「小模型追平大模型」

2023 年 2 月，Meta AI 发布 **LLaMA（Large Language Model Meta AI）**：7B、13B、33B、65B 四个尺寸，全部只用**公开数据**训练（约 1.4T token），上下文 2K。<span class="marginnote">LLaMA 的意义在于两点：一是「只用公开数据」——这对被版权与数据墙困扰的研究者是巨大福音；二是它的 13B 在多项基准上超过 175B 的 GPT-3，直接动摇了「模型越大越贵才越好」的预设，也预告了下一节要讲的 Chinchilla 缩放定律。</span>

LLaMA-1 采用 decoder-only 结构，身上已经带着后来开源模型的「标准三件套」：**RMSNorm** 替换 LayerNorm、**SwiGLU** 激活、**RoPE** 旋转位置编码。<span class="marginnote">RMSNorm 去掉均值中心化、SwiGLU 是门控线性单元的 Swish 变体、RoPE 把位置信息编码进旋转矩阵——这三件套会在《LLaMA 架构剖析》一篇逐一拆解。看到这里你已经知道它们在 LLaMA 里第一次成套出现。</span>但 LLaMA-1 只对研究者开放申请，且禁止商用。这份克制没有维持多久——**2023 年 3 月初，权重被泄露到网上，几小时内传遍全球**。泄露是「未经授权的」，但它客观上把 LLaMA 变成了可复现的基座。

## 3 社区爆发：几百美元微调一个大模型

权重一旦在手，社区的创造力爆发了。关键是把「微调」的成本打到地板价：

**Alpaca（斯坦福，2023.3）**：用 self-instruct 方法，让 `text-davinci-003` 依据 175 条种子指令自动生成 5.2 万条「指令-回答」数据，再在 LLaMA-7B 上监督微调。总训练成本约 **500 美元**，8 张 A100 跑 3 小时。
**Vicuna（LMSYS，2023.4）**：从 ShareGPT 抓取 7 万条真实用户与 ChatGPT 的对话，微调 LLaMA-13B，对话体验逼近 ChatGPT。
**WizardLM、Guanaco（QLoRA）**：前者用「进化指令」算法自动升级指令复杂度；后者靠 QLoRA 在单张 48GB 显卡上微调 65B 模型，让「一人一卡调大模型」成为现实。

这批工作的共同技术底座，就是 **LoRA（Low-Rank Adaptation，低秩适配）**——冻结原模型，只训练一小块低秩增量。它把「微调 65B 模型」从「需要几十张 A100」变成「一张消费级显卡」：这是开源生态能被点燃的工程前提。<span class="marginnote">QLoRA 在 LoRA 基础上再加两层压缩：把预训练权重量化到 4-bit（NF4），用双重量化减少显存，并在反向传播时反量化。它把「单卡可微调的最大模型」一夜之间推高了约一个数量级。</span>

## 4 公式解析：LoRA 的低秩近似

LoRA 的核心假设是：**预训练模型的权重微调，其「增量」是低秩的**。即存在一个小秩 $r \ll \min(d,k)$，使得权重更新矩阵 $\Delta W$ 可以被分解成两个小矩阵的乘积。

$$
W' = W_0 + \frac{\alpha}{r}\, B A, \qquad B \in \mathbb{R}^{d \times r},\ A \in \mathbb{R}^{r \times k}
$$

逐步拆解：

- **$W_0 \in \mathbb{R}^{d \times k}$**：预训练得到的原始权重，**完全冻结**，不参与梯度更新。
- **$BA$**：把 $\Delta W$ 近似为两个低秩矩阵的乘积。$B$ 是 $d \times r$，$A$ 是 $r \times k$，两者相乘仍是 $d \times k$，但参数总量从 $dk$ 降到 $r(d+k)$。
- **$\alpha / r$**：缩放因子。$r$ 是秩，$\alpha$ 是任务相关的常数；初始化时让 $A$ 为零、$B$ 为随机，这样微调一开始 $W' = W_0$，训练稳定。
- **为什么有效**：前向计算 $h = W_0 x + \tfrac{\alpha}{r} B A x$。第一个分支走冻结的预训练权重，第二个分支走可训练的微小增量——**模型的主体能力来自 $W_0$，LoRA 只在上面「拧」一个很浅的旋钮**。

算一笔账：设某注意力投影层 $d = k = 4096$（7B 模型的典型宽度）。全量微调要训练 $4096^2 \approx 1677$ 万个参数；取秩 $r = 8$，LoRA 只训练 $4096 \times 8 \times 2 = 65536$ 个参数，**可训练量不到原来的 0.4%**。这就是「几百美元微调大模型」的数学来源。

在 HuggingFace PEFT 生态里，配一个 LoRA 只需几行配置。这段代码完全对应上面的公式——`target_modules` 指定对哪些权重矩阵做低秩更新，`r` 就是公式里的秩 $r$，`lora_alpha` 就是 $\alpha$：

```python
from peft import LoraConfig, get_peft_model

lora_config = LoraConfig(
    r=8,                                 # 秩 r
    lora_alpha=16,                       # α
    target_modules=["q_proj", "v_proj"], # 对哪些权重矩阵做低秩更新
)
model = get_peft_model(model, lora_config)
```

真正跑起来时，PEFT 会把每个 `target_modules` 里的线性层替换为「冻结原权重 + 可训练 $BA$」的组合——正是 $W' = W_0 + \tfrac{\alpha}{r}BA$ 的工程实现。**rank 从 8 提到 64，可训练参数按比例增长，但模型能力并不一定跟着涨**，这提醒我们：低秩近似的「秩」是容量旋钮，不是越大越好。<span class="marginnote">「微调增量是低秩的」不是数学定理，而是经验事实：对全量微调后的权重做 SVD，发现其更新量的大部分能量集中在前若干个奇异值上。这与第二级《线性代数》里用 SVD 做「低秩近似」的思想一脉相承。</span>

**辨析｜易错点：** LoRA 是「参数高效微调」，不是「模型压缩」。它不减少推理时的计算量——权重仍然按 $W_0 + \Delta W$ 合成后再前向。它省的是**训练时的显存与优化器状态**，这一点常被混淆。另外「$\alpha$ 与 $r$ 一起缩放」：$\alpha$ 不是学习率，改变 $\alpha$ 时 $r$ 若不变，只改缩放、不改秩，效果不等于换了一个秩。

## 5 LLaMA-2：把开源推向商用

2023 年 7 月 18 日，Meta 发布 **LLaMA-2**：7B、13B、70B 三个尺寸，预训练数据增至 **2T token**，上下文翻倍到 4K，全尺寸加入 **GQA（分组查询注意力）**，并首次允许**商用**（社区许可，限制主要针对月活超 7 亿的超大平台）。<span class="marginnote">GQA 是「多查询注意力（MQA）的折中」：把查询头分成若干组，组内共享 K/V 头，在保证质量的同时大幅削减 KV Cache 显存——这一设计会在《GQA 与高效注意力》一篇专门讲解。</span>

更关键的是对齐工艺的成熟。LLaMA-2-Chat 用 **RLHF** 训练，收集了**超过 100 万条人类标注**，并引入 **Ghost Attention（GAtt）** 技巧让模型在多轮对话中「记住」系统指令。论文详细公开了从 SFT 到 RLHF 的完整配方——这等于把上一节我们讲的 InstructGPT 流程，变成了一份开源可复制的工程手册。<span class="marginnote">GAtt 的核心思想：在监督微调阶段，给不同轮次对话注入系统消息并让模型预测它，从而让「跟随系统指令」在多轮对话里保持一致——它是 LLaMA-2 在对话连贯性上比 LLaMA-1 大幅提升的关键之一。</span>

## 6 LLaMA-3 与新生态格局

2024 年 4 月，Meta 发布 **LLaMA-3**（8B、70B），同年 7 月补齐 **405B**。LLaMA-3 的预训练数据达 **15T+ token**，词表扩到 **128K**（改用类 tiktoken 的分词器，中文与多语言表示大幅改善），原生 8K 上下文、可外推 128K。它把「开源模型的预训练规模」推到了与闭源模型同一数量级。<span class="marginnote">128K 词表是多语言性能的关键：更大的词表意味着常用中文词组可以被整体编码，减少 token 碎片化。这是《Tokenizer 与分词》一篇「词表设计」与「中文的分词税」两节的直接预告。</span>

围绕 LLaMA 及同类权重，一个完整的**开放工具生态**迅速成形：

**推理层**：`llama.cpp`（纯 C++，能在笔记本 CPU 上跑 7B）、`Ollama`（一键本地运行）、`vLLM`（高吞吐推理引擎）。
**部署层**：`GGUF` 量化格式、`GPTQ`、`AWQ`，让百亿参数模型能塞进单张显卡。
**微调层**：`PEFT`（含 LoRA/QLoRA）、`LLaMA-Factory`，把「调大模型」平民化。
**社区与中文系谱**：Hugging Face 成为开源模型的中枢；国内 ChatGLM、Baichuan、Qwen、DeepSeek 相继开源，其中 Qwen 与 DeepSeek 在第四篇会作为独立的架构谱系重点剖析。

这条生态链的「触达成本」低到了可以随手实验。一个 7B 模型用 GGUF 量化后约 4–5 GB，普通笔记本即可运行：

```bash
ollama run llama2:7b
```

这套「一条命令跑模型」的体验，是 2023 年之前不可想象的——它把「消费大模型」从 API 时代带入了「私有化部署」时代。也因此，开源模型的评测、量化与本地部署成为独立的研究方向，后续《评测》与《大模型部署》两个专题都会反复回到这里。

**重点：** 从 LLaMA-1 的「研究者专属」到 LLaMA-2 的「可商用」再到 LLaMA-3 的「规模对齐闭源」，Meta 用三年时间定义了一个新范式——**模型权重可以开源，而生态的价值由社区共同创造**。开源不再只是「研究玩具」，而是与闭源并列的一条发展主线。

## 7 辨析：开放权重 ≠ 开源软件

「LLaMA 开源了」这句话，需要精确化。**LLaMA 系列发布的是权重（open-weight），而不是完整意义的开源（open-source）**：

**开放了什么**：模型参数文件、推理代码、部分评测配置。
**没开放什么**：训练数据、完整训练管线、数据清洗代码——而这些恰恰是复现一个模型最耗时、最昂贵、最能沉淀科学知识的部分。
**许可差异**：LLaMA-1 仅限研究；LLaMA-2/3 的社区许可允许商用但带使用条款限制；而 OSI 定义的「开源」要求自由再分发、可修改、无歧视，二者并不等同。<span class="marginnote">Mistral 早期发布权重时也引起过同样争论。到 DeepSeek 发布技术报告并逐步公开训练细节时，「开放权重 + 开源论文」成为新标杆，但也仍未完全达到 OSI 意义上的开源。</span>

**易错点｜辨析：** Alpaca、Vicuna、Guanaco 是**基于 LLaMA 权重微调的第三方模型**，不是 Meta 官方发布的产品。它们继承的是 LLaMA 的「底座能力」，但训练数据、对齐方式各不相同。把「Alpaca 的效果」当成「LLaMA 的效果」，或以讹传讹地说「Meta 发布了 Alpaca」，都是常见误区。社区爆发恰恰建立在这种「底座 + 再创作」的协作模式之上。

## 8 小结

- **GPT-4** 代表了闭源前沿：能力顶尖、技术细节保密（架构、规模、训练方法均未公开），开启了「渐进式部署」的安全叙事。
- **LLaMA-1**（2023.2）用公开数据证明了小模型可追平大模型，权重泄露点燃了社区。
- **LoRA/QLoRA** 把微调成本从千万级降到几百美元：冻结 $W_0$、训练低秩增量 $\tfrac{\alpha}{r}BA$，可训练参数不到 0.4%。
- **LLaMA-2**（2023.7）首次允许商用，配 GQA、2T token 与成熟的 RLHF 工艺；**LLaMA-3**（2024）把开源规模推向闭源同级（15T token、128K 词表）。
- **开放权重 ≠ 开源**：权重可下载 ≠ 数据与训练管线公开；Alpaca/Vicuna 等是第三方衍生，不是 Meta 官方模型。

在下一节，我们将离开「谁开源、谁闭源」的历史，回到一条更硬的科学线索：**缩放定律**。GPT-3 之后，人们第一次发现「损失随规模的变化」可以被一条幂律精确描述——这就是 Kaplan 等人 2020 年提出的**缩放定律**，也是预测「下一个里程碑」的标尺。
