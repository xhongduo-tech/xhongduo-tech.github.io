## 为什么 o1 是「推理的范式跃迁」

CoT、Self-Consistency、ToT 都是「提示技巧」——在「已训练好的模型」上「引导推理」。o1 走得更远：**用强化学习（RL）把「长思维链」训练成模型的本能**——模型不靠「prompt 引导」，而是「天生就会」把复杂问题拆解、推理、自我纠错。o1 在数学、代码、科学推理上大幅超越 GPT-4o，靠的不是「更大参数」，而是「更会推理」——**RL + 长思维链 = 推理范式的新阶段**。<span class="marginnote">o1 的「范式跃迁」在于它改变了「推理能力的来源」：<strong>以前的推理能力来自「预训练时读过推理文本」（被动）或「提示技巧引导」（外部）；o1 的推理能力来自「RL 直接训练推理过程」（主动）</strong>。模型被「奖励」去「分步思考、自我纠错」——推理成为「训练目标」而非「提示技巧」。</span>

## 1 o1 的核心：RL 训练「推理」

o1 的训练大致分为三阶段（从 o1 的技术报告推断）：

**① 推理数据构造**：用「长思维链数据」——问题 + 详细的推理过程（含思考、验证、修正）——做 SFT（监督微调），让模型「先学会模仿长思维链」。

**② RL 训练推理**：用 RL（策略优化）直接优化「推理过程」：

**奖励**：正确答案 + **推理质量**（过程奖励，PRM 式）。
**策略**：模型被鼓励「生成更长的思维链、更仔细地推理」——因为「想得多」被奖励。

**③ 推理时缩放**：o1 推理时「生成思考 token」——「想得越久，答得越准」成为「可调节的」——用户可让 o1「多思考」（慢）或「少思考」（快）。<span class="marginnote">o1 的关键突破在于「<strong>RL 把『推理策略』变成『可优化的东西』</strong>」：以前「怎么推理」是模型「隐性学到的」，o1 把它「显式奖励」——模型学会「主动生成思考步骤」「在困惑时回溯」「验证自己的答案」。这像「学生被训练『先列提纲再写作』」——「方法」本身被教学。</span>

## 2 长思维链（Long CoT）：o1 的「工作方式」

o1 在推理时生成 **长思维链（long chain of thought）**——可能上千甚至上万 token 的「思考过程」：

```
用户：鸡兔同笼，头 35，脚 94，各几只？
<reasoning>
设鸡 x 只、兔 y 只。由头数：x + y = 35；由脚数：2x + 4y = 94。
由第一式得 y = 35 − x，代入：2x + 4(35 − x) = 94
化简：2x + 140 − 4x = 94 ⟹ −2x = −46 ⟹ x = 23，y = 12。
检验：23 + 12 = 35 ✓；2×23 + 4×12 = 46 + 48 = 94 ✓。
</reasoning>
答案：鸡 23 只，兔 12 只。
```

**长思维链的特点**：

**自我纠错**：生成过程中「发现不对、重新算」——这是 RL 训练出来的「检查习惯」。
**分解问题**：把复杂问题「拆成子问题」逐步解决。
**验证答案**：用「另一种方法」验证「当前答案」——「双保险」。

**长思维链 vs CoT**：CoT 是「prompt 引导的短思维链」；o1 是「RL 训练的长思维链」——**「长」不只是长度，更是「结构」**（拆解、回溯、验证、多解）。<span class="marginnote">o1 的思维链与「人类做难题」高度相似：<strong>先理解、再拆解、卡住了回头换思路、做完检查一遍</strong>。这提示「推理能力」的本质可能是「<strong>有结构地使用思考时间</strong>」——o1 用 RL 教会模型「如何有效思考」。</span>

## 3 为什么 RL 是关键：从「会模仿」到「会策略」

o1 之前的模型「见过推理文本」（SFT 就能模仿），但「不会主动推理」——RL 的关键作用：

- **SFT 只教「模仿」**：模型学会「生成推理文本的样子」，但「不知道该在哪一步多想、什么时候检查」。
- **RL 教「策略」**：通过「奖励（答对 + 过程好）」，「试错」学到「什么推理策略有效」——「多想想能得高分」→ 学会「多思考」；「检查能纠错」→ 学会「验证」。

**RL 的「探索」能力**：RL 让模型「试出」人类没写过的推理模式——**「策略」不限于「人类示范的」，而是「被奖励塑造的」**。这解释了为什么 o1 能「超越训练数据的推理水平」——它「发明」了有效的思考方式。

## 4 公式解析：o1 的 RL 目标

o1 的 RL 训练目标（策略优化）可以写成：

$$
\max_{\theta} \; \mathbb{E}_{r \sim \pi_{\theta}} \big[ R(r, \text{answer}) \big] - \beta \cdot D_{\text{KL}}\big(\pi_{\theta} \| \pi_{\text{ref}}\big)
$$

其中 $r$ 是「生成的推理过程」，$R$ 是奖励（答案正确 + 过程质量），$\beta$ 是 KL 约束权重。

对这条式子做三步拆解：

- **第一步，读懂期望项**：$\mathbb{E}_{r \sim \pi_{\theta}}$——从「当前策略」采样推理过程，求「奖励的期望」。**最大化这个期望 = 让策略「更会产出高奖励的推理」**。
- **第二步，读懂奖励 $R$**：奖励包含「答案对不对」与「过程好不好」——**RL 同时优化「结果」与「过程」**。这是 o1 学会「长思维链」的驱动力：长思维链「通常带来高奖励」，所以策略「倾向于生成长思维链」。
- **第三步，读懂 KL 约束**：$\beta \cdot D_{\text{KL}}(\pi_{\theta} \| \pi_{\text{ref}})$——惩罚「策略偏离参考模型太多」——**防止 RL 把模型「学坏」（输出乱码、语义漂移）**。这是「RL 训练稳定性」的标准技术（RLHF 也用）。

**辨析｜易错点：** o1 的「长思维链」不是「无限长就越好」——有「最优长度」：太短「想不透」，太长「浪费时间 + 可能跑偏」。o1 的 RL 学到的是「<strong>在关键处多想、在简单处少想</strong>」——「按需思考」而非「一律长考」。**「推理预算」是「分配」问题，不是「堆量」问题**。

## 5 o1 范式的影响与批评

**影响**：

- 开启「推理模型」时代——DeepSeek-R1、Kimi-K2、QwQ 等纷纷跟进「RL + 长思维链」。
- 重新定义「测试时计算」的价值——「思考」成为可付费的产品功能。
- 「RL 教策略」的思路扩散到「Agent 训练」（第十五篇）。

**批评与局限**：

- **计算成本高**：长思维链的推理开销是普通模型的数倍到数十倍。
- **可解释性争议**：o1 的「思维链」不完全公开（安全原因）——「思考过程」成黑箱。
- **应用边界**：长思维链对「简单任务」是浪费；「快思考」任务（对话、翻译）不适合。

## 7 数值算例：长思维链的成本

设普通模型对一道难题输出 100 token 答案，o1 额外生成 2000 token 的思考：

| 模型 | 输出 token | 相对成本 |
| --- | --- | --- |
| 普通模型 | 100 | 1× |
| o1（快速） | 100 + 500 | 约 6× |
| o1（深度思考） | 100 + 2000 | 约 21× |

**读这张表**：o1 的「深度思考」成本是普通模型的 21 倍——这是「用算力换准确率」的显式定价。o1 产品把「思考预算」做成可调节的档位（快速/深度），本质是「让用户按任务难度买推理」——**「想多久」第一次成为产品上的可选项**。

**辨析｜易错点：** 长思维链不是「越长越好」——超过一定长度后收益递减甚至下降（想太多跑偏）。o1 的 RL 学到的是「**在关键处多花思考**」，而非「无脑堆长度」。评估推理模型，要按「准确率/成本比」看，而不是「思考多长」。

## 8 CoT 提示 vs o1 范式：一张对照

| 维度 | CoT 提示 | o1 RL 范式 |
| --- | --- | --- |
| 能力来源 | 外部 prompt 引导 | 内部 RL 训练 |
| 思维链长度 | 短（几十 token） | 长（数千 token） |
| 自我纠错 | 弱 | 强（RL 奖励） |
| 是否改模型 | 否 | 是 |
| 思考预算 | 固定 | 可调 |

CoT 是「让已有能力显式化」，o1 是「把推理能力练成本能」——**两者不是竞争而是递进**：CoT 证明了「推理可引导」，o1 证明了「推理可训练」。当前推理模型（DeepSeek-R1 等）都在这条「RL 训练推理」的延长线上。

## 9 小结

- **o1 范式**：RL 训练「长思维链」——推理成为「训练目标」而非「提示技巧」。
- 三阶段：**长思维链 SFT → RL 优化推理 → 推理时缩放**。
- 长思维链 = 拆解 + 自我纠错 + 验证——「有结构地使用思考时间」。
- **RL 教「策略」**：从「模仿推理」到「发明推理策略」。
- 影响：推理模型时代开启；批评：算力贵、思维链黑箱、简单任务浪费。
