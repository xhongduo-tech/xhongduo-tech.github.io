# 涌现能力：现象描述、机理解释与"度量假象"之争

<div class="epigraph">

## 为什么从涌现能力讲起

前两节的缩放定律给了一个美好而平滑的承诺：**损失随规模按幂律下降，双对数坐标下是一条直线**。如果世界真的这么平滑，那么「更大的模型更强」就该是一条可以无限外推的曲线，没有任何惊喜。

但现实给了这个承诺一记闷棍。GPT-3 时代的实验经常出现这样的曲线：横轴是模型规模，纵轴是某个任务的准确率——小模型一直在 0% 附近躺平，到了某个规模点，准确率突然跳到 70%、90%。这不是曲线的「斜率变陡」，而是**从无到有的阶跃**。Kaplan 的幂律预测的是「稳步变好」，阶跃却意味着「从不会到会」——**而「从不会到会」正好是缩放定律那条直线解释不了的东西**。<span class="marginnote">这正是「涌现」这个词在物理里的味道：水在 100°C 突然沸腾、铁在居里温度突然失去磁性——宏观性质在临界点发生不连续变化。2022 年的研究者们忍不住借用这套语言来描述大模型能力的突然出现。</span>

一个被反复引用的例子来自 BIG-bench：让模型做三位数加法，参数量在百亿以内时准确率始终贴着 0%，一旦跨过约千亿参数，准确率直接跳到 80% 以上——中间几乎没有任何过渡带。**这样的曲线放在两年前，任何缩放定律都画不出来**，于是它被当作「规模带来了质变」的头号证据。本节要做的，就是先看现象、再给机理、最后把它放进「度量放大」与「能力分层」的争论中重新校准。

## 1 现象：量表上的「阶跃」

2022 年 8 月，Google 的 Wei 等人发表《Emergent Abilities of Large Language Models》，给这个现象起了名字并系统化。**涌现能力（emergent abilities）**：指**在较小的模型中不存在、而在较大的模型中出现的那些能力**——更精确地说，是无法通过外推小模型性能来预测的能力。

论文把涌现现象归为三类触发方式：

- **少数样本提示（few-shot prompting）任务**：如三位数加法、单词乱序重组、国际音标转写。小模型怎么提示都不行，大模型给几个例子就会了。
- **增强式提示（augmented prompting）任务**：如**思维链（chain-of-thought）**、自洽性采样。给模型一句「请逐步思考」，在某个规模点，多步推理能力突然解锁。<span class="marginnote">思维链是涌现研究里最戏剧性的例子：PaLM 在参数量超过约 1000 亿后，GSM8K 小学数学题从约 18% 跃到近 57%。「鼓励模型先写推理过程」这个提示技巧本身，就是第十三篇《推理能力》的主角。</span>
- **指令微调（instruction tuning）能力**：模型能否在未见过的指令上泛化，也在某个规模点突然变好。

这三类有一个共同点：**在曲线图上，它们都表现为「先平后陡」的 S 形阶跃，而不是平滑上升**。<span class="marginnote">BIG-bench 的论文甚至给这个现象配了「里程碑（milestone）」的解读：超过某个规模，模型在任务上的表现出现可识别的飞跃。这张「从 0 到 1」的曲线图，后来成了这场争论的战场。</span>

## 2 机理解释（第一派）：能力分层与相变

对「为什么会有阶跃」，第一派给出的是**能力分层**的故事。

大模型处理复杂任务，往往依赖若干**子能力**的组合：做三位数加法，先要「按位对齐」，再要「逐位进位」；做多步推理，先要「识别中间步骤」，再要「按序执行」。如果每个子能力都是随规模平滑增长的，但**任务要求所有子能力同时在线**——那么只有当最弱的一环也跨过门槛时，整体能力才突然显现。<span class="marginnote">打个比方：三个水龙头各自缓慢放水，水缸要等三个水龙头都出水后才开始上涨。任何单条管道都是平滑的，但「水缸水面」在第三个龙头打开时才突然抬升。子能力之间若有「与」的关系，宏观表现就会是阶跃。</span>

更物理化的说法是**相变**：规模是控制参数，任务表现是序参量，阶跃点就是临界点。这个类比优美且诱人，但它有一个软肋——**它没有预测能力**。你无法事先知道哪个规模会触发哪个任务的能力涌现，每个任务的阶跃点都不一样。这恰恰是第二派攻击的靶心。

## 3 争议：是能力涌现，还是度量假象？

2023 年 4 月，斯坦福的 Schaeffer、Miranda、Koyejo 三人发表了那篇引爆争论的论文——《Are Emergent Abilities of Large Language Models a Mirage?》（「度量假象」一词即源于此）。它的论点锋利而直接：**所谓涌现，不是能力的问题，而是度量（metric）的问题。**

他们的论证分三步：

- **第一步，观察**：研究者用**非线性或不连续的度量**（如「精确字符串匹配」「多选题判分」）来评测模型。这类度量有一个特性：**只要有一处不对，整题算错**。
- **第二步，重算**：把同一批模型的**同一批输出**，改用**平滑的度量**（如 token 级正确概率、字符串编辑距离、Brier 分数）重新打分。结果涌现「蒸发」了——性能变成平滑、连续、可预测的上升。
- **第三步，统计**：在 BIG-bench 上，**超过 92% 的「涌现」现象只出现在两种度量下**：多选题判分（不连续）与精确字符串匹配（非线性）。换成平滑度量，阶跃消失。他们甚至用**故意制造的非线性度量**，在卷积网络等毫无语言能力的视觉模型上「人工造出」了涌现——反向证明了「度量决定涌现」。

**重点：** 第二派的立场不是「大模型没变强」，而是「**能力的进步是平滑的，阶跃只是你选择的尺子制造出来的错觉**」。你拿着一把非线性、不连续的尺子去量一个平滑增长的量，量出来的就是一段陡峭的崖壁。<span class="marginnote">这篇论文拿到了 NeurIPS 2023 的 Outstanding Paper 奖，可见其影响力。它也被广泛用于解释为什么「小模型评测用精确匹配、大模型评测用判断式评分」会带来不公平的比较——度量的选择本身就是一种隐藏的立场。</span>

## 4 公式解析：为什么「精确匹配」会放大平滑的进步

「度量决定涌现」可以用一个极简的数学模型说清。设模型随规模平滑提升，**每个 token 被正确生成的概率**为 $p(N)$，它随规模 $N$ 平滑上升（比如在 $\log N$ 上呈逻辑斯蒂曲线）。一个答案由 $n$ 个 token 组成，那么：

$$
A_{\text{EM}}(N) \approx \big(p(N)\big)^{n}, \qquad
A_{\text{edit}}(N) \approx n \cdot \big(1 - p(N)\big)
$$

逐步拆解：

- **$p(N)$**：单 token 正确概率，是「平滑的真相」。它从 0.5 缓步升到 0.95。
- **$A_{\text{EM}}(N) \approx p^n$**：**精确匹配**要求 $n$ 个 token **全部**正确（粗略地视为独立事件，概率相乘）。$p$ 从 0.7 到 0.9，$p^5$ 从 0.17 猛蹿到 0.59——**乘积运算把平滑的输入放大成了陡峭的输出**。
- **$A_{\text{edit}}(N) \approx n(1-p)$**：**编辑距离**只统计「错几个 token」，是 $p$ 的**线性函数**。$p$ 从 0.7 到 0.9，编辑距离从 1.5 平滑降到 0.5——看不出任何阶跃。
- **对数横轴再添一把火**：当横轴用 $\log N$，大部分「规模增长」被压缩在右端，非线性度量产生的陡升就更像「临界相变」。

同一个 $p(N)$，线性度量读出「平滑」，非线性度量读出「阶跃」——**这就是「度量假象」的全部机制**。用代码模拟一遍，印象会深得多：

```python
import numpy as np

log_N = np.linspace(7, 12, 200)          # 参数规模（对数刻度）
p = 1 / (1 + np.exp(-(log_N - 10)))      # token 正确概率平滑上升
n = 5                                    # 答案由 5 个 token 组成

em = p ** n                              # 精确匹配：非线性
edit = n * (1 - p)                       # 编辑距离：线性

print("在 log_N = 9.6 处:")
print(f"  p = {p[52]:.3f} → EM 准确率 = {em[52]:.3f}（几乎为 0）")
print(f"  p = {p[80]:.3f} → EM 准确率 = {em[80]:.3f}（突然抬升）")
# 同一个 p 从 0.60 涨到 0.73，em 从 0.08 猛增到 0.21，而 edit 只从 2.0 降到 1.35
```

输出会让你直观看到：**精确匹配在 $p$ 越过某个阈值后才「启动」，而编辑距离全程匀速下降**。涌现的「阶跃」，至少有一部分就是这条 $p^n$ 曲线。

**辨析｜易错点：** 「度量假象」不等于「涌现不存在」。Schaeffer 等人论证的是：**在「外推性」的意义上，涌现是不可靠的——因为阶跃很大程度上是度量造成的**。但「在某个规模点，模型确实第一次能在某任务上给出全对答案」这个**行为事实**依然成立：对用户来说，一个能把三位数加法算对的模型与算不对的模型之间，就是存在一道行为鸿沟。争论的焦点是「这道鸿沟是能力的本质属性，还是尺子的放大」，而不是「模型有没有变强」。

## 5 反方与更细的图景

「度量假象」很有说服力，但它不是最终答案。后续研究拼出了更复杂的图景：

- **并非所有涌现都能被平滑度量消解**：有研究在更严格、更平滑的度量下（如「Beyond the Imitation Game」基准的若干任务）仍然观察到不可平滑化的能力跳跃。度量假象解释了大多数，但可能不是全部。
- **「断裂的神经缩放定律」（broken neural scaling laws）**：Cabannes 等人（2023）发现，小模型沿着一条幂律改进，而**大模型会「上翘」脱离这条幂律，表现优于外推**。这给了「真实超线性涌现」一个更精确的数学表达——不是 0→1 的阶跃，而是「在某个规模点斜率突然变陡」。
- **从「有没有」转向「可不可预测」**：争论至今的共识性表述已经细化——涌现可以定义为「**从较小模型性能不可预测**」。在这个意义上，即便机制尚不明朗，「不可预测」本身就是一个需要认真对待的工程事实：它意味着你无法用几十亿参数的模型外推出万亿参数模型到底会不会某个技能。<span class="marginnote">这一「可预测性」视角与缩放定律形成了微妙的对位：缩放定律预测「损失」很可靠，但预测「某项任务的能力」很不可靠。损失与能力之间的这条裂缝，正是涌现研究至今仍活跃的原因。</span>

**重点：** 三派——现象派（Wei）、度量派（Schaeffer）、统计派（broken scaling laws）——并不完全矛盾。可以共存的理解是：**底层（损失、token 级概率）平滑，中层（某些任务的表层表现）被度量放大成阶跃，而某些真正复合的能力可能确实在规模上表现出超线性增益**。涌现更像是一副多层透镜的成像，而非单一事实。

## 6 辨析：涌现 ≠ 神迹，也不否定缩放定律

最后厘清三个高频误读：

- **涌现不否定缩放定律**。缩放定律说的是「损失随资源平滑幂律下降」；涌现说的是「某些任务表现出现阶跃」。两者描述的**不是同一个量**——前者平滑，后者被度量放大。把「涌现」当成缩放定律的反例，是把「损失」和「任务准确率」混为一谈。
- **涌现 ≠ 训练中的 grokking**。涌现是「随模型规模变大而出现」；**grokking** 是「小模型在训练后期突然泛化」——两者一个是横轴（规模）、一个是横轴（训练步数），机制也各不相同。
- **「阶跃」是评测曲线的形状，不是推理过程的形状**。模型内部没有「突然开启某个开关」；阶跃往往只是「所有子能力都过线」的宏观投影。**别把曲线形状直接读成内部机制**。

## 7 小结

- **现象**：Wei 等人（2022）定义**涌现能力**——小模型没有、大模型突然出现的能力，多表现为「先平后陡」的阶跃，涉及少数样本提示、思维链与指令微调三类。
- **机理一**：能力分层与相变——复杂任务依赖多个子能力同时在线，整体表现呈阶跃。
- **机理二（度量假象）**：Schaeffer 等人（2023）证明，用非线性/不连续的度量（精确匹配、多选题判分）会把平滑的 token 级进步放大成阶跃；换成平滑度量，涌现「蒸发」。
- **公式核心**：$A_{\text{EM}} \approx p^n$（非线性）对比 $A_{\text{edit}} \approx n(1-p)$（线性）——度量决定你读出阶跃还是平滑。
- **综合图景**：底层平滑、表层被放大、部分复合能力可能确有超线性增益；争论焦点已从「是否存在」转为「是否可预测」。

在下一节，我们将告别「规模与能力」这一整条主线，进入一个新的知识树分支——**Tokenizer 与分词**。无论模型多大、能力多强，它首先要面对的问题是：**连续的文本，是怎么被切成一串离散 token 的？** 下一节我们从「字符、词与子词」这三种粒度的权衡讲起。
