## 为什么总有人想"干掉注意力"

注意力的 $O(L^2)$ 复杂度是长序列的天花板。FlashAttention 只是让它「算得动」，没改变复杂度本身。**线性注意力**与**状态空间模型（SSM）**走的更远：它们把「每个位置看全部历史」换成「用一个固定大小的状态压缩历史」，复杂度降到 $O(L)$。Mamba 就是这条路线目前最成功的代表——它用**选择性扫描**让 SSM 获得「内容相关」的注意力，在长序列上比 Transformer 更快，在某些任务上表现相当。<span class="marginnote">这场「注意力 vs 线性替代」之争本质是「记忆机制」之争：注意力用「显式的历史缓存」（KV Cache）精确回看；线性模型用「隐式的压缩状态」记住历史。前者精确但随长度膨胀，后者恒定但会「遗忘」。Mamba 的价值在于：它证明了压缩状态这条路线在规模化后并不像想象中那样弱。</span>

## 1 线性注意力的核心：核技巧

标准注意力权重是 $\text{softmax}(QK^{\top})$——非线性的归一化让「历史缓存」无法简化。线性注意力把 softmax 换成**核函数**：

$$
\text{Attention}(Q,K,V) \approx \phi(Q) \cdot \left(\phi(K)^{\top} V\right)
$$

关键步骤是改变结合顺序：

$$
\phi(Q)\,(\phi(K)^{\top} V) = \underbrace{(\phi(Q) \phi(K)^{\top})}_{\text{不显式构造 } L \times L} V \Rightarrow \phi(Q) \cdot \underbrace{(\phi(K)^{\top} V)}_{S: d \times d, \text{与 } L \text{无关}}
$$

- 标准：先算 $L \times L$ 的注意力矩阵，再乘 V——$O(L^2)$。
- 线性：先算 $S = \phi(K)^{\top} V$（$d \times d$ 的「累积状态」），再乘 $\phi(Q)$——$O(L)$。

**直觉**：$\phi(K)^{\top} V$ 是一个「把历史 K 与 V 压缩成的 $d \times d$ 矩阵」，它不随 $L$ 增长。模型把「看过的历史」压进一个固定大小的状态——这就是「恒定显存」的来源。<span class="marginnote">这个 $d \times d$ 的累积矩阵非常像「协方差」或「自相关」——它统计「key 与 value 的关联模式」。线性注意力的哲学是：<strong>历史不需要逐个记住，只需要记住「key-value 关联的统计」</strong>。代价是失去「精确回看」能力——某个具体 token 的信息被平均掉了。</span>

## 2 从 RNN 到 S4 到 Mamba：状态空间模型的脉络

状态空间模型（SSM）是另一个更系统的「恒定状态」路线。连续时间状态空间模型：

$$
\dot{h}(t) = A h(t) + B u(t), \qquad y(t) = C h(t)
$$

离散化后变成递归形式（很像 RNN）：

$$
h_t = \bar{A} h_{t-1} + \bar{B} x_t, \qquad y_t = C h_t
$$

**S4**（2021）的关键贡献：发现这种递归可以用**卷积**并行计算，且用结构化参数（HiPPO 矩阵）让 $A$ 能记住长程信息——解决了 RNN「梯度消失、不能并行」两大顽疾，但 $A, B, C$ 是**输入无关**的（对所有 token 用同一套参数），缺乏「内容选择性」。

**Mamba**（2023）的关键改进：让 $B, C$（以及 $\Delta$）**依赖输入**——「选择性扫描」：

$$
B_t = f_B(x_t), \qquad C_t = f_C(x_t), \qquad \Delta_t = f_{\Delta}(x_t)
$$

**每个 token 用自己的 B/C/Δ**，模型得以「决定」哪些 token 该记、哪些该忘——这赋予了 SSM 类似注意力的「内容感知」能力，同时保持 $O(L)$ 复杂度。<span class="marginnote">Mamba 的「选择性」是它与前代 SSM 的分水岭：S4 对所有 token 一视同仁（像「匀速记录」），Mamba 能「遇到重要 token 记牢、遇到噪声跳过」（像「选择性笔记」）。这也是它首次让 SSM 在大语言模型上与 Transformer 正面竞争。不过选择性让并行化变难——这是它的工程挑战，Gu & Dao 用「并行扫描（parallel scan）」解决。</span>

## 3 Mamba 与 Transformer 的对比：各自的权衡

| 维度 | Transformer（注意力） | Mamba（SSM） |
| --- | --- | --- |
| 复杂度 | $O(L^2)$ 计算、KV 缓存 $O(L)$ | $O(L)$ 计算、恒定状态 |
| 历史记忆 | 显式、精确回看 | 隐式、压缩状态（会遗忘） |
| 长序列 | 成本高但能力强 | 成本低、能力因遗忘受限 |
| 并行训练 | 完全并行（因果掩码） | 并行扫描（硬件技巧） |
| 内容选择 | 注意力权重天然选择性 | 靠选择性 B/C/Δ |
| 主流地位 | 事实标准 | 挑战者 |

**关键问题：Mamba 能否替代注意力？** 目前的答案（截至主流大模型训练实践）：

**能**：长序列（10 万+）、纯序列流式、低延迟推理场景，Mamba 有显著优势。
**不能（完全）**：复杂推理、精确检索（如「找到第 5 段的数字」）、多跳指代，Transformer 的显式缓存仍是上限更高的机制。**压缩必然损失信息**——状态有限，远记忆的精度不如 KV 缓存。
**折中**：混合架构（Jamba、Zamba、GPT-4 的推测）——**注意力层 + SSM 层交替**，用少量注意力保精确、多数 SSM 保效率。这可能是「最佳实践」：两头的好处都要。<span class="marginnote">「混合是出路」的直觉：语言里有两种信息——「必须精确回看」的（指代、数字、引用）与「统计式记住即可」的（整体语义、风格、常识）。纯注意力为前者付出 $L^2$ 的代价，纯 SSM 为后者牺牲精确性。混合架构按「每层按需选择」分配，理论上能两全——这是 Mamba-2、Jamba 之后的研究主方向。</span>

## 4 公式解析：选择性扫描的递推

Mamba 的核心递推（离散、选择性）：

$$
h_t = \bar{A}(\Delta_t) \, h_{t-1} + \bar{B}(\Delta_t) x_t, \qquad y_t = C(\Delta_t) h_t
$$

其中 $\bar{A}, \bar{B}$ 是依赖输入 $\Delta_t$ 的离散化矩阵，$B, C$ 也由输入决定。

对这条式子做四步拆解：

- **第一步，读懂 $h_t$**：这是固定大小（$d_N$ 维）的**隐藏状态**，压缩了「截至 $t$ 的全部历史」。对比注意力的 KV 缓存（随 $t$ 增长），$h_t$ 大小恒定。
- **第二步，读懂 $\bar{A} h_{t-1}$**：$A$ 是「遗忘/保持」矩阵——它决定「旧状态被记住多少」。这是状态模型能否长程记忆的关键。
- **第三步，读懂选择性 $\Delta_t, B_t, C_t$**：$\Delta$ 控制「新信息写入强度」（采样间隔），$B$ 控制「输入如何进入状态」，$C$ 控制「状态如何读出」。三者都依赖输入——**模型按 token 决定记什么、忘什么、读什么**。
- **第四步，读出复杂度**：每步只做「矩阵乘向量」$O(1)$（固定状态），总 $O(L)$——**且不需要 KV 缓存**，推理显存恒定。这就是「线性复杂度 + 恒定记忆」的定量表达。

**辨析｜易错点：** Mamba 的「状态」不是 KV 缓存，它比 KV 缓存小得多（$d_N$ 维 vs $2Hd_k \cdot L$ 元素）——但也正因如此，它是**有损压缩**。别把「SSM 的恒定状态」理解成「无损记住全部历史」：它记住的是「统计概要」，不是「逐 token 记录」。这个区别决定了它无法完全替代注意力的精确回看。

## 5 Mamba 的现状与启示

- **Mamba-2**：用「结构化状态空间对」统一了注意力与 SSM 的数学，让两者共享实现内核。
- **工业应用**：长上下文 RAG 的索引段、超长文档理解、低延迟流式推理。
- **教训**：**「恒定状态」不免费**——压缩必损失。注意力的「贵」正是它的「强」：显式缓存换来精确。未来的大模型大概率是**混合**而非替代：能忍受的损失用线性，必须精确的用注意力。

## 7 数值算例：$L=100k$ 时的复杂度对比

设序列 $L=100\text{k}$、$d=4096$、SSM 状态维 $d_N=4096$：

| 方案 | 注意力计算量 | 记忆量 |
| --- | --- | --- |
| Transformer | $L^2 = 10^{10}$ 个分数对 | KV 缓存随 $L$ 增长 |
| Mamba | $L \cdot d_N \approx 4.1\times10^8$ | 恒定 $d_N$ 状态 |

**读这笔账**：100k 序列下，Transformer 的注意力对是 $10^{10}$、Mamba 约 $4\times10^8$——**差约 25 倍**，且 Mamba 的记忆恒定。这就是「长序列自由」的含义——**SSM 的吸引力随长度放大**。当然，代价是「压缩必损失」：精确回看能力被状态容量限制。

**辨析｜易错点：** Mamba 的「$O(L)$」是「计算」的复杂度——它的「并行扫描」需要特殊内核（CUDA 优化）才能高效。**「理论线性」与「实际快」之间隔着工程**——没有优化内核，Mamba 的递推反而是串行的。

## 8 场景选型速查

| 场景 | 首选 |
| --- | --- |
| 超长序列（10 万+） | Mamba / SSM |
| 精确回看（找数字/引用） | Transformer 注意力 |
| 流式低延迟推理 | SSM（无 KV 增长） |
| 复杂多跳推理 | Transformer |
| 折中 | 混合架构（Jamba 等） |

**原则**：**「需要精确记忆」用注意力，「需要低长成本」用 SSM，两头都要用混合**——注意力与 SSM 不是替代，而是互补。

## 9 小结

- **线性注意力**：用核技巧把「$L^2$ 注意力矩阵」换成「$d \times d$ 累积状态」——$O(L)$ 复杂度。
- **状态空间模型**：递归 $h_t = \bar{A}h_{t-1} + \bar{B}x_t$，恒定状态、线性复杂度。
- **Mamba** 的选择性扫描让 $B/C/Δ$ 依赖输入——**内容感知的 SSM**，首次与 Transformer 正面对抗。
- 权衡：**精确回看（Transformer）vs 恒定压缩（SSM）**——压缩必损失。
- 现实：**混合架构**（注意力 + SSM 交替）是主流方向，而非完全替代。
