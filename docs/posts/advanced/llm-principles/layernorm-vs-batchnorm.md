## 为什么两种归一化长得像却命运不同

BatchNorm 横扫了 CNN 时代，LayerNorm 则在 Transformer 时代独占鳌头。两者公式几乎一样——减去均值、除以标准差——差别只在**沿着哪个轴归一化**。这个「轴」的选择，决定了它们对「批次大小」「序列长度」「训练/推理行为」的适应性完全不同。理解这个轴，就理解了为什么 NLP 的答案注定是 LayerNorm。<span class="marginnote">归一化的共同动机：深度网络内部协变量偏移（Internal Covariate Shift）会让各层输入的分布随训练漂移，导致梯度不稳定、收敛慢。归一化把每层输入拉回「零均值单位方差」，让训练过程更平稳——这是两者的共同祖先。</span>

## 1 定义：归一化在哪条轴上做

设一个批次的输入为张量 $X \in \mathbb{R}^{B \times L \times d}$（$B$=批量，$L$=序列长，$d$=特征维）。

**BatchNorm** 沿着**批次维度**归一化：对每个特征通道 $j$，用「所有样本、所有位置的该通道」统计均值与方差。也就是统计范围是 $\{b, l\}$，特征是 $j$。

$$
\text{BN}(X)_{blj} = \gamma_j \frac{x_{blj} - \mu_j}{\sqrt{\sigma_j^2 + \epsilon}} + \beta_j
$$

**LayerNorm** 沿着**特征维度**归一化：对每个样本的每个位置，用「该位置的所有特征」统计均值与方差。统计范围是 $\{j\}$，样本是 $(b, l)$。

$$
\text{LN}(X)_{bl} = \gamma \frac{x_{bl} - \mu_{bl}}{\sqrt{\sigma_{bl}^2 + \epsilon}} + \beta
$$

其中 $\mu, \sigma$ 都是统计量，$\gamma, \beta$ 是可学习的缩放/平移参数，$\epsilon$ 是防除零的小常数。<span class="marginnote">记忆口诀：<strong>BN 横着归（跨样本），LN 竖着归（跨特征）</strong>。对一张「$B \times d$」的表，BN 是「按列归一化」，LN 是「按行归一化」。Transformer 里每个 token 是一行，LN 保证「每一行」都变成单位分布——与 token 数量无关。</span>

## 2 为什么 NLP 用 LayerNorm：三个致命理由

**理由一：BN 对「小批次」敏感。** BN 的统计量依赖批次——批次越小，统计越抖。NLP 里由于序列变长，往往被迫用小批次（甚至 batch=1 做长序列推理），BN 的均值/方差估计噪声巨大，训练不稳。LN 不依赖批次，**batch=1 也稳如泰山**。<span class="marginnote">更极端的是「在线学习/流式推理」：BN 在训练与推理时行为不同（推理用累积统计量），而 LN 的训练与推理完全同构——这对自回归生成尤其重要，因为生成天然是 batch 很小、逐 token 前进的过程。</span>

**理由二：序列长度可变。** NLP 的序列长度长短不一（padding 到同长），BN 按通道跨样本统计时，padding 位置会污染统计量；LN 按位置独立统计，**每个位置自带归一化**，与序列长度无关。

**理由三：BN 的训练-推理不一致。** BN 推理时要用「训练期累积的移动平均」，一旦数据分布偏移，统计量就过期；LN 不需要维护任何全局状态，推理即训练——**状态无关**是工程上的巨大优势。

## 3 公式解析：LN 的参数与梯度

LayerNorm 对每个 token 的 $d$ 维向量独立归一化。给定向量 $x \in \mathbb{R}^d$：

$$
\hat{x}_j = \frac{x_j - \mu}{\sqrt{\sigma^2 + \epsilon}}, \qquad
\mu = \frac{1}{d}\sum_{j=1}^{d} x_j, \qquad
\sigma^2 = \frac{1}{d}\sum_{j=1}^{d} (x_j - \mu)^2
$$

对这条式子做四步拆解：

- **第一步，读懂 $\mu, \sigma$**：它们由「这一个 token 自己的 $d$ 个特征」算出，与批次里的其他 token 无关。这正是「逐位置归一化」的含义。
- **第二步，理解可学习参数**：归一化后乘 $\gamma_j$ 加 $\beta_j$——否则所有 token 都被压成标准正态，模型的表达能力受限。$\gamma, \beta$ 让模型「保留自定义的分布形状」。
- **第三步，读出梯度结构**：LN 的反向要把梯度沿「减均值、除方差」两步展开——相当于把 $x$ 投影到与全 1 向量正交的子空间再缩放。这个结构让梯度在特征维上「去均值化」，防止特征间偏移。
- **第四步，理解为何稳定**：LN 对输入缩放不变（把 $x$ 整体放大 k 倍，$\hat{x}$ 不变），这给了模型对「层间信号幅度漂移」的天然鲁棒性——这正是 Pre-LN 稳定性的微观来源。

**辨析｜易错点：** LN 不是「对每个 token 独立」的软说法，而是严格如此。但要注意**参数 $\gamma, \beta$ 是跨位置共享的**（同一层所有 token 用同一组 $\gamma_j, \beta_j$），不是每个 token 一套。归一化的统计量是逐 token 的，可学习的仿射参数是全层共享的——别把两者搞混。

## 4 对比表与各自的适用场景

| 维度 | BatchNorm | LayerNorm |
| --- | --- | --- |
| 统计轴 | 跨批次（特征通道） | 跨特征（单个样本） |
| 依赖批次大小 | 强（小 batch 不稳） | 无（batch=1 可用） |
| 序列长度适配 | 差（padding 污染） | 好（逐位置独立） |
| 训练/推理一致性 | 不一致（用移动平均） | 一致 |
| 典型场景 | CNN、视觉 | Transformer、NLP |
| 额外状态 | 移动均值/方差 | 无 |

还有第三、四种候选：**InstanceNorm**（跨特征、单样本，风格迁移用）与 **GroupNorm**（特征分组内归一化，视觉里的 BN 替代品）——它们都是「选哪条轴、按什么分组」的排列组合。**归一化的轴选择，本质是「你相信哪个方向的信息不该被混在一起」。**<span class="marginnote">一个有趣的细节：Transformer 里通常只对「特征维」归一化，而<strong>不归一化 token 间的幅度</strong>。因为 token 间的相对幅度可能携带有用信息（某个位置显著更重要），LN 不动它，保留了这种信息。这解释了为什么 LN 是「温和」的归一化。</span>

## 5 LN 在大模型里的实际形态

- **RMSNorm**：LN 的一个激进简化——去掉均值平移，只做方差缩放。LLaMA、Qwen、Mistral 全用它。下一篇专讲。
- **Pre-LN + LN 的位置**：LN 放在残差分支内部（Pre-LN），与残差流协作。
- **归一化嵌入输出**：有些实现会对「输入嵌入 + 位置」先做一次 LN，稳定第一层输入。
- **Final LN**：输出头前再加一层 LN，把最后一层的表示稳定后再投影到词表。

## 6 小结

- **BatchNorm 跨批次归、LayerNorm 跨特征归**——轴的选择决定一切。
- NLP 选 LN 的三个理由：**小批次鲁棒、序列变长适配、训练推理一致**。
- LN 逐 token 独立归一化 + **全层共享仿射参数**，梯度结构稳定、输入缩放不变。
- 归一化轴的本质是「哪个方向的信息不该混」——BN/LN/IN/GN 都是它的排列。
- 现代大模型进一步简化为 **RMSNorm**。
