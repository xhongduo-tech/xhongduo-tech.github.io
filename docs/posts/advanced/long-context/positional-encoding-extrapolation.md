## 为什么从位置编码外推开始

前面的优化都在回答「怎么算得动更长」；但长上下文还有一道更隐蔽的坎——**模型根本不知道位置在哪**。注意力是「袋装词」（bag of words）式的：把顺序打乱，$QK^{\top}$ 的分数完全不变。是位置编码在给每个 token 贴上「时间戳」。Vaswani 等人的正弦位置编码在训练长度内工作良好，**一旦上下文超过训练长度，模型的表现常常断崖式崩溃**——不是算力不够，是「时间戳」没油了。

这一节的主题叫**外推（extrapolation）**：能不能让模型在训练时只见过 4096 个位置的情况下，顺滑地用到 128k？三条路各有各的哲学：RoPE 用**旋转**表达相对位置，ALiBi 用**线性惩罚**让「最近的 token 天然占优」，YaRN 则把 RoPE 的**频率**拆开精细调校。今天的 Llama、Mistral、DeepSeek 等几乎所有大模型的外推能力，都是这三条路的组合或后代。

## 1 先分清：内插还是外推

**外推为什么成为一门显学**：2023–2025 年间，主流模型的上下文窗口以每年约百倍的速度膨胀（4k → 32k → 128k → 1M），而训练成本不允许把每个长度都重训一遍。「短训长测」因此不只是学术趣味，而是决定模型能否低成本升级的工程问题——这也是本节三个方法都被写进各家大模型配置文件、而不是躺在论文里的原因。

**一个常见的误区**：「外推长度」与「训练长度」之间没有免费的午餐——任何声称「零微调外推到 X 倍」的方法，都要追问它推理时是否偷偷调整了位置配置（换了基频、改了温度、动了位置标尺）。读长上下文论文，第一件事就是检查它在外推时改了哪些超参。

**核心概念：** 设模型训练时见过的最大位置为 $L_{\text{train}}$。若推理时位置超过 $L_{\text{train}}$，模型面临两种选择：

- **外推（extrapolation）**：直接用训练时的位置编码公式，把新位置硬塞进公式——不做任何额外调整，希望模型自己泛化过去。
- **内插（interpolation）**：把更长的序列**压扁**到 $L_{\text{train}}$ 的范围内，每个位置的间距变小——位置分布变了，通常需要少量微调让模型适应新刻度。

两者的分水岭是：外推「位置标尺没变，只是更长」，内插「位置标尺被拉伸，间距变了」。**说「外推」却背地里做内插、或者只报微调后的成绩，是长上下文文献里最常被吐槽的混淆**——真正的零微调外推，才配叫 extrapolation。<span class="marginnote">Press 等人的论文标题就是《Train Short, Test Long: Attention with Linear Biases Enables Input Length Extrapolation》——「短训长测」是 ALiBi 的核心卖点，它在外推上做到了<strong>无需微调</strong>。</span>

## 2 RoPE：用旋转编码相对位置

**旋转位置编码（Rotary Position Embedding, RoPE）**（Su et al., 2021）：不把位置**加**进 token 表示，而是**旋转**查询与键向量。把 $d$ 维向量按两两一组拆成 $\frac{d}{2}$ 个二维平面，第 $k$ 组在平面上旋转角度 $m \cdot \theta_k$，其中

$$
\theta_k = b^{-2k/d}, \quad b = 10000, \qquad
R_m(q) = \text{每对分量} (q_{2k}, q_{2k+1}) \text{旋转 } m\theta_k
$$

**核心要点：** 旋转的好处在于**相对位置自然涌现**：$R_m(q)$ 与 $R_n(k)$ 的内积等于 $R_{n-m}(q)$ 与 $k$ 的内积——注意力分数只依赖两个 token 的**相对距离** $n - m$，与绝对位置无关。而且旋转只改变相位、不改变范数，query 与 key 的「强度」被完美保留。

**为什么外推这么难**：位置编码在训练长度内学到的是「位置 → 表示」的映射；训练范围之外，函数值完全靠公式硬推。绝对正弦编码与原生 RoPE 在训练长度附近「拐弯」，是因为公式在训练范围内被 softmax 打磨过、范围外则是裸奔。外推的本质问题是「让公式在未见过的输入上仍给出合理值」——它与注意力结构无关，纯粹是编码函数的事。

用一个二维例子把「旋转」落到纸上。设 $q = (1, 0)$，第 $k=0$ 组的 $\theta_0 = 1$（即 base 的 0 次方，未缩放）。位置 $m$ 的旋转角是 $m \theta_0 = m$，旋转矩阵把 $q$ 转成 $R_m(q) = (\cos m, \sin m)$。于是 $R_2(q)$ 与 $R_5(k)$ 的内积是 $\cos(5-2) = \cos 3$——**分数只由位置差 3 决定**。$d$ 维时每个 token 有 $\frac{d}{2}$ 个这样的平面，各以不同频率 $\theta_k$ 旋转，构成一个「多频率的相位钟」：低频钟走全球、高频钟走局部。<span class="marginnote">这个「频率分工」正是后来 NTK 缩放与 YaRN 的抓手——后面马上会看到，调外推其实就是调这只钟每个指针的转速。</span><span class="marginnote">这是 RoPE 相比绝对正弦编码的哲学差异：绝对位置编码让模型去「学会」相对性，RoPE 则把相对性直接<strong>编码进数学结构</strong>。同样的思想在信号处理里叫「相位是距离的记忆」。</span>

**RoPE 的外推困境**：RoPE 的频带是固定的——$\theta_k$ 由基频 $b = 10000$ 决定。位置 $m$ 越大，最高频分量的相位 $m\theta_{d/2}$ 旋转越频繁，很快超出训练分布，高频维度对「未见过的位置」失去分辨力。这就是为什么原生 RoPE 的外推能力有限、需要 YaRN 这类频率调校。

在 YaRN 之前，社区已经有两级铺垫。**第一级，位置内插（Position Interpolation, PI）**：把位置 $m$ 直接除以比例 $s$，让长序列压回训练范围——有效，但需要相当数量的微调，且高频细节被压平。**第二级，NTK-aware 缩放**：把基频 $b$ 换成 $b' = b \cdot s^{\frac{d}{d-2}}$，用「放大基频」来压低高频转速，试图在不动位置标尺的前提下减少高频失真。YaRN 的贡献，是把第二级的「一刀切」升级成「按波长分段」——低频内插、高频不动、中间平滑。

## 3 ALiBi：什么都不加，只加一条距离惩罚

**带线性偏置的注意力（Attention with Linear Biases, ALiBi）**（Press et al., 2022）走向另一个极端：**完全不做位置编码**，只在注意力分数上按距离减去一个线性惩罚：

$$
\text{score}(i, j) = q_i \cdot k_j - m_h \cdot |i - j|
$$

**核心要点：** 第 $h$ 个头有一个固定斜率 $m_h$，各头的斜率构成几何序列 $2^{-8/H}, 2^{-16/H}, \dots, 2^{-8}$（$H$ 为头数）。斜率从 $2^{-8}$ 起步是实验调出来的：太大则模型只看得到紧邻 token，太小则距离惩罚形同虚设——$2^{-8/H}$ 到 $2^{-8}$ 的区间，让不同头恰好覆盖了从「极近」到「很远」的全谱。<span class="marginnote">以 8 头为例，斜率恰为 $1/2, 1/4, \dots, 1/256$。斜率的语义是「遗忘速率」：斜率大的头强烈偏好近邻，斜率小的头能看较远的距离——不同头各司其职，天然形成多尺度注意力。</span>

**为什么 ALiBi 天然会外推？** 因为它的偏置只依赖相对距离 $|i - j|$，而**相对距离的分布不会随序列变长而改变**——无论总长是 4096 还是 128k，相邻两个 token 的距离永远是 1。位置信息「无量纲化」了，模型在训练时学会的局部偏好在长序列上原样适用。<span class="marginnote">这背后是一个先验假设：<strong>最近的 token 平均而言更重要</strong>。ALiBi 把这条先验硬编码成归纳偏置，训练时无需学习位置参数，推理时也无需微调。</span>

**代价**：ALiBi 的长程能力完全依赖「距离惩罚 + 深层传播」，它不提供「精确的相对位置读数」——模型知道「越近越该看」，但不一定知道「第 100 与第 200 个位置之间隔了 100」这个确切事实。Mistral 7B 用 RoPE 而不用 ALiBi，正是因为它需要更强的相对定位。

**ALiBi 的实证**：Press 等人用 1.3B 参数模型在 512 长度上训练、直接外推到 2048 测试——无需任何微调，困惑度几乎不涨；对照组里，绝对正弦编码与原生 RoPE 在长度翻倍后困惑度明显抬升。这个「短训长测」的成功，让 ALiBi 一度成为长上下文语言模型（如 MPT、BLOOM 系）的默认位置编码。**ALiBi 之后**：线性惩罚后来被推广为学习式的相对偏置（如 T5 的 bias），以及 RoPE + bias 的混合方案——「距离惩罚」未必线性，但 ALiBi 证明了「最简方案也能外推」这条底线。

## 4 YaRN：把 RoPE 的频率拆开调校

**YaRN（Yet another RoPE extensioN）**（Peng et al., 2023）不换位置编码，而是回答一个更精细的问题：RoPE 的 $\frac{d}{2}$ 个频带，**该对哪些频带做内插、哪些保持外推？** 关键观察来自「波长」视角：第 $k$ 个频带的波长为 $\lambda_k = 2\pi b^{2k/d}$，低频（大波长）编码长程位置、高频（小波长）编码局部细节。<span class="marginnote">波长思想与 NTK（神经正切核）外推一脉相承：高频维度负责局部、低频维度负责全局，一视同仁地缩放会同时破坏两者——这是「NTK-aware」缩放兴起的起点。</span>

**YaRN 的做法（NTK-by-parts + 温度）**：

1. **按波长分三段**：设训练长 $L$、目标长 $L'$、比例 $s = L'/L$。波长超过 $L'\beta$ 的低频段**完整内插**（$\theta \to \theta / s$）；波长小于 $L\alpha$ 的高频段**保持不动**（继续外推）；中间段用斜坡函数 $\gamma$ 平滑混合。超参数默认 $\alpha = 1, \beta = 32$。<span class="marginnote">直觉：高频段改动会毁掉 token 间的局部语法（如相邻词的搭配），低频段不改则长程位置完全错位——所以「局部不动、全局内插、中间平滑」。</span>
2. **温度校正**：缩放会改变注意力分数的量纲，导致 softmax 变「平」。YaRN 引入温度 $t$，满足 $\sqrt{1/t} = 0.1 \ln s + 1$，等价于把注意力分数除以 $t\sqrt{d_k}$，补偿 logits 的膨胀。**YaRN 的实用性与成本**：它的全部改动只是「换一组 $\theta$、加一个温度」——不改模型权重、不改训练目标，微调几步即可生效。这种「配置即扩展」的属性，是它被各大模型直接采纳的根本原因。

效果：Llama 2（训练 4k）仅用约 400 步微调就能外推到 32k，几乎不掉点；若完全不微调，零样本外推的困惑度也显著优于原生 RoPE。DeepSeek V2/V3、Qwen 的 32k→128k 扩展都直接采用了 YaRN 的温度公式——「频率分段 + 温度校正」这套组合拳，事实上已经成了大模型上下文扩展的行业默认工具。<span class="marginnote">Llama 3.1 的 128k 上下文走了另一条简化路线：把 RoPE 基频从 10000 直接拉到 500000——高频维度被压慢，本质上是一种全局的 NTK 缩放。</span>

## 5 公式解析：把三条路摆在同一张公式台上

把三种方案统一写成「注意力分数的修正」：

$$
\text{score}(i, j) =
\begin{cases}
q_i^\top k_j, & \text{RoPE 用旋转后的 } R_m(q_i)^\top R_n(k_j) \\
q_i^\top k_j - m_h |i - j|, & \text{ALiBi 的线性惩罚} \\
R'_m(q_i)^\top R'_n(k_j) \big/ \sqrt{t}, & \text{YaRN 的缩放旋转 + 温度}
\end{cases}
$$

- **RoPE**：位置信息藏在**旋转角度** $m\theta_k$ 里，分数表达相对距离，但高频频带在外推时失真。
- **ALiBi**：位置信息是一段**距离惩罚**，常数 $m_h$ 给出遗忘速率，天然外推、没有可学习位置参数。
- **YaRN**：用波长把旋转频率**分段治理**，再乘温度校正恢复 softmax 尺度——是「RoPE 的外推补丁」，而非新的位置编码。

把三条路的取向总结成一张对照表，方便选型时查阅：

| 方案 | 位置信息 | 免微调外推 | 相对定位精度 | 典型用户 |
| --- | --- | --- | --- | --- |
| RoPE | 旋转相位 | 中（高频失真） | 高 | Llama、Qwen、DeepSeek |
| ALiBi | 距离线性惩罚 | 高 | 中低 | MPT、BLOOM 系 |
| YaRN | 分段调频 + 温度 | 中（需少量微调） | 高（继承 RoPE） | Llama 系长上下文扩展 |

**辨析｜易错点：** 三种方法经常被混着用，但它们的**互补关系**要分清：RoPE 强在相对定位、弱在外推；ALiBi 强在外推、弱在精确定位；YaRN 不改定位能力，只是把 RoPE 推到更长的区间。选型是「要精确定位还是要免微调外推」的权衡，不是简单的谁取代谁——这也是为什么主流大模型几乎都选 RoPE + 事后外推补丁（YaRN 一族），而不是直接用 ALiBi。一句话把握三者的分工：**RoPE 负责「精确的相对位置」，ALiBi 负责「免微调的外推」，YaRN 负责「把 RoPE 也变成长跑选手」**。回到本专题的主线：位置编码外推与前几节的复杂度优化是**正交**的——稀疏化与 FlashAttention 决定「算不算得动」，位置编码决定「读不读得懂位置」；长上下文模型要同时过这两关。回望本节开头：外推问题的本质是「位置编码函数的泛化」——旋转、惩罚、分段，都是让这个函数在更长的定义域上仍给出合理值的不同配方。

## 6 小结

- **外推**是零微调地用超出训练长度；**内插**是压扁标尺、通常要微调。两者常被混谈，需警惕。
- **RoPE**：旋转编码相对位置，数学优雅、定位精确，但高频频带在外推时失真。
- **ALiBi**：不加位置编码，只加距离线性惩罚，斜率几何序列 $2^{-8/H}\sim 2^{-8}$，天然免微调外推，但定位粗。
- **YaRN**：按波长分段——低频内插、高频不动、中频斜坡混合，加温度校正 $\sqrt{1/t} = 0.1\ln s + 1$。
- Llama、Mistral、DeepSeek 等主流模型的位置外推能力，几乎都是这三条路的组合或后代。
- 选型口诀：要精确相对定位用 RoPE，要免微调外推用 ALiBi，要 RoPE 的长跑用 YaRN。
- 读论文先查「外推时改了什么超参」——零微调外推的承诺，常在推理配置里藏着条件。
- 外推的底线：位置编码函数必须在训练范围之外仍给出合理值——旋转、惩罚、分段都是实现它的配方。
