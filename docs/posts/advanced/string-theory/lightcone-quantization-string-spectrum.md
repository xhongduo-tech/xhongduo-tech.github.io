# 弦量子化与谱（光锥量子化）

## 为什么从光锥量子化开始

上一节我们把弦的动力学写成了波动方程，解是「质心平动 + 无限多个振动模式」。这一节做一件物理学家最爱的仪式：**量子化**。弦的每个振动模式都是一维谐振子，量子化后对应产生/湮灭算符与模式占据数——于是弦的谱（质量平方的集合）变成一堆振子激发之和。

量子化弦有好几条路：协变量子化、光锥（lightcone）量子化、BRST 量子化。Zwiebach 教材走的是**光锥量子化**，因为它在路径最短的同时给出了完整的谱与临界维数 $D=26$。<span class="marginnote">光锥量子化的思路：用光锥坐标把 Virasoro 约束显式解掉，只保留横向量子化。它的代价是洛伦兹对称性不再明显，但换来的是「约束先解后量子化」的清晰谱。协变量子化与 BRST 形式见 Polchinski Vol. 1 第 2–3 章。</span>这一篇我们用光锥方法把开弦与闭合弦的谱分别算出来，并直面那个著名的尴尬：基态是 tachyon。

## 1 谐振子回顾：量子化弦的最小单元

一维量子谐振子的哈密顿量是

$$
H = \hbar\omega (a^\dagger a + \tfrac{1}{2}), \qquad [a, a^\dagger] = 1
$$

能级 $E_n = \hbar\omega(n + \tfrac12)$，其中零点能 $\tfrac12\hbar\omega$ 不可忽略。弦的每个振动模式 $\alpha_n^\mu$ 就是这样一个振子，且 $\alpha_n^\mu \propto a_n^\mu$（按 $n$ 归一化）。对开弦，质量平方公式是

$$
m^2 = \frac{1}{\alpha'}\left( N - a \right), \qquad N = \sum_{n=1}^{\infty} \sum_{\mu} n\, \hat{N}_{n,\mu}
$$

其中 $\hat{N}_{n,\mu}$ 是模式占据数（模式 $n$ 在第 $\mu$ 方向被激发的个数），$N$ 是**总振子数（level）**，$a$ 是总零点能常数。**弦的质量平方被「振子数减去常数」直接决定**——这是弦谱的全部秘密，也是 Regge 轨迹 $J = \alpha' m^2 + \alpha_0$ 的量子版本。

## 2 光锥规范：把约束显式解掉

在光锥坐标下定义 $X^\pm = (X^0 \pm X^{D-1})/\sqrt{2}$，横向指标 $i = 1,\dots,D-2$。选择规范 $X^+ = x^+ + p^+\tau$（光锥时间当参数），Virasoro 约束变成代数方程，可解出 $X^-$ 完全由横向模式决定：

$$
\alpha_n^- = \frac{1}{\sqrt{2\alpha'} p^+} \sum_{m\in\mathbb{Z}} \alpha_{n-m}^i \alpha_m^i, \qquad n \neq 0
$$

**这就是光锥量子化的灵魂**：纵向自由度 $X^-$ 不再独立，由横向振动模式 $\alpha_n^i$ 的二次型决定；物理自由度只剩 $D-2$ 个横向振子。<span class="marginnote">「$D-2$ 个物理自由度」的说法来自此：$X^\pm$ 被规范条件与约束消掉两个自由度。这让人想起电磁场只有两个横极化——弦论里同一套计数逻辑，从麦克斯韦时代延续至今。</span>于是谱只由横向振子 $\alpha_n^i$ 算出来，横向指标 $i$ 只有 $D-2$ 个取值。

## 3 开弦的谱：从 tachyon 到光子

对开弦，零点能求和

$$
a = \frac{D-2}{2} \sum_{n=1}^\infty n
$$

这个发散的和要用 **zeta 函数正规化**：$\sum n = \zeta(-1) = -\tfrac{1}{12}$，于是 $a = -(D-2)/24$。逐层写谱：

- **$N = 0$（基态）**：$m^2 = -a = \tfrac{D-2}{24\alpha'} > 0$？不——$m^2 = -a$，代入 $a<0$，得 $m^2 = -(D-2)/(24\alpha')$，**是负数**。这是一个虚质量的粒子，即 **tachyon（快子）**。
- **$N = 1$（第一激发）**：$m^2 = (1-a)/\alpha' = \tfrac{D-2-24+24}{24\alpha'}$……具体展开：$m^2 = (1 + \tfrac{D-2}{24})/\alpha'$。由 $\alpha_1^i$ 构造的态 $\alpha_{-1}^i |0\rangle$ 是矢量，洛伦兹不变性要求它无质量——这强制 $m^2 = 0$，即 $a = 1$，即 $(D-2)/24 = 1$，于是 **$D = 26$**。第一激发是时空中的**无质量自旋 1 粒子**，恰如光子（开弦对应规范场）。
- **$N \ge 2$**：有质量的高自旋激发，构成 Regge 轨迹。

**重点：临界维数 $D=26$ 由「第一激发必须是矢量（无质量）」这一条洛伦兹对称性要求强行逼出**。这不是硬凑出来的巧合，而是闭弦/开弦谱与洛伦兹不变性自洽的唯一选择。<span class="marginnote">在协变量子化中 $D=26$ 同样从「无鬼定理」（no-ghost theorem）出现：$D=26$ 时负范数态全部被 Virasoro 条件消掉。两种方法殊途同归，互证临界维数的必要性。</span>

## 4 公式解析：零点能与 $D=26$

$$
a = \frac{D-2}{2}\sum_{n=1}^{\infty} n = \frac{D-2}{2} \times \left(-\frac{1}{12}\right) = -\frac{D-2}{24}
$$

三步拆解：

- **第一步，$D-2$ 从哪来**：横向自由度有 $D-2$ 个，每个振子方向对零点能贡献 $\tfrac12\sum_n n$；求和指标 $n$ 是频率（单位 $\alpha'$ 的弦长标度）。
- **第二步，$\sum n = -1/12$ 怎么算**：$1+2+3+\cdots$ 发散。正规化后 $\zeta(s) = \sum_{n\ge1} n^{-s}$，解析延拓得 $\zeta(-1) = -1/12$。**辨析｜易错点：** 这不是「把发散级数硬说成 -1/12」——它是正规化程序的结果，物理上对应的是「把零点能重新定义为有限值」的手续，与卡西米尔效应同源。
- **第三步，$a = 1$ 的物理**：要求第一激发 $N=1$ 的态无质量（否则破坏洛伦兹不变性），即 $1 - a = 0$，得 $a = 1$；代入 $a = -(D-2)/24$ 解得 $D-2 = 24$，即 $D = 26$。

**弦论在 $D=26$ 时，负范数（鬼）态从谱中消失**——物理态空间干净了。

## 5 闭合弦的谱：引力子的出现

闭合弦是左行与右行两种行波独立传播，物理态要满足**level-matching 条件** $N_L = N_R$（左右振动数相等）。质量平方公式为

$$
m^2 = \frac{4}{\alpha'}\left( N - a \right) = \frac{4}{\alpha'}\left( N_L - 1 \right), \qquad N_L = N_R
$$

谱：

- **基态 $N_L = N_R = 0$**：$m^2 = -4/\alpha'$，又是 **tachyon**（比开弦的负得更多）。
- **第一激发 $N_L = N_R = 1$**：$m^2 = 0$，态由 $\alpha_{-1}^i \tilde{\alpha}_{-1}^j |0\rangle$ 构造，这是一个对称无迹张量场——正是 **引力子（graviton）**，其伴随的是反对称张量场 $B_{\mu\nu}$（NS-NS 场的 $B$ 场）与无迹标量场（dilaton $\Phi$）。<span class="marginnote">闭合弦的第一激发同时包含：对称无迹的 $g_{\mu\nu}$（引力子）、反对称的 $B_{\mu\nu}$、标量的 $\Phi$（dilaton）。一出手就同时给出「自旋 2」与两个伴随场，这是弦论自诩「量子引力自然候选」的底气。</span>

**重点：闭合弦谱里天然出现自旋 2 的无质量粒子——引力子**。在标准量子场论里，自旋 2 的相互作用是极度受限的（必须满足爱因斯坦方程的一致性与相互作用的唯一性），弦论却「免费」送出一个自洽的引力子。这就是「弦论是量子引力理论」的最强论据。

## 6 弦谱 vs 点粒子场论谱

| 弦类型 | 基态 | 第一激发 | 无质量场 |
| --- | --- | --- | --- |
| 开弦 | tachyon（$m^2<0$） | 矢量 $\alpha_{-1}^i|0\rangle$ | 规范场 $A_\mu$ |
| 闭合弦 | tachyon（$m^2<0$） | 张量 $\alpha_{-1}^i\tilde{\alpha}_{-1}^j|0\rangle$ | 引力子 $g_{\mu\nu}$、$B_{\mu\nu}$、dilaton $\Phi$ |

所有无质量粒子都是弦的振动模式的组合——**弦论里没有「基本粒子」，只有弦的激发态**。这回答了「为什么会有这么多不同粒子」：它们全是同一根弦的不同振动模式。**辨析｜易错点：** 不要以为「tachyon 消失是因为取临界维数」——$D=26$ 解决的是鬼态（负范数），tachyon 依然健在。消除 tachyon 是超对称弦（GSO 投影）才完成的任务，见本专题《超弦与 GSO 投影》。

### 谱的补充：弦态的爆炸式增长

第 $N$ 层的态数 $d_N$ 由振子配分函数给出

$$
\sum_{N=0}^{\infty} d_N\, x^N = \prod_{n=1}^{\infty} \left(1 - x^n\right)^{-24}
$$

（开弦，$D=26$ 的 24 个横向振子）。它按 $d_N \sim N^{-27/4}\, e^{4\pi\sqrt{N}}$ 增长——**弦的态数随 level 指数爆炸**。这个「指数简并」正是弦的高温熵 $\propto$ 面积的统计来源（见《量子引力与黑洞熵》），也是「一根弦 = 巨大内部态空间」的定量表达：同样质量的弦，态密度远高于任何点粒子场论。

**Regge 斜率 $\alpha'$ 的物理尺度**：历史上一度认为弦就是强子，Regge 斜率来自强子谱 $J = \alpha' m^2$，实验值 $\alpha' \approx 0.9\,\mathrm{GeV}^{-2}$。若弦即强子，弦长 $l_s = \sqrt{\alpha'} \sim 10^{-15}\,\mathrm{m}$——这个尺度与量子引力冲突，于是「弦=强子」的方案被放弃，$\alpha'$ 被推到普朗克尺度（$l_s \sim 10^{-33}\,\mathrm{m}$）。但强子谱的**线性 Regge 轨迹**在实验里至今毫发无损——弦论留给粒子物理的第一份遗产从未失效。

## 7 小结

- 弦谱 = 无限多维谐振子，质量平方 $m^2 = (N - a)/\alpha'$（开弦），$N$ 为总振子数。
- **光锥量子化**把 Virasoro 约束显式解掉，物理自由度只剩 $D-2$ 个横向量子。
- 零点能正规化 $a = -(D-2)/24$；要求第一激发为无质量矢量强制 **$D=26$**。
- 开弦谱：基态 tachyon，第一激发光子；闭合弦谱：基态 tachyon，第一激发**引力子** + $B_{\mu\nu}$ + dilaton，并满足 level-matching $N_L = N_R$。
- 粒子不是基本的，是弦的激发模式。
