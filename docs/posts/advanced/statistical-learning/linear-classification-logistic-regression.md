## 为什么从线性分类开始

上一节我们学会了用一条超平面拟合数值输出。可现实中更多的任务是**分类**：垃圾邮件还是正常邮件、肿瘤是良性还是恶性、图像里是猫还是狗。分类不是回归的简单改名——它的输出是离散的，度量误差的方式、模型的形式、优化的目标全都要换。<span class="marginnote">本节接续《线性回归与最小二乘》。分类是监督学习的第二支柱，第四级后续的 SVM、决策树、神经网络本质都在做同一件事：学一个从特征到类别的映射，只是表达与训练方式各异。</span>

**逻辑回归（logistic regression）**是分类问题里绕不开的入口。它把「线性模型 + 二次损失」换成「线性模型 + 对数几率 + 交叉熵损失」，神奇的是后者的训练算法竟与线性回归高度同构——迭代加权最小二乘（IRLS）在每一轮都是一次加权最小二乘。学懂逻辑回归，你同时学懂了「为什么分类不能用线性回归硬凑」和「换损失之后一切重新顺理成章」。

## 1 分类问题的形式化

样本 $(x_i, y_i)$ 中 $y_i$ 现在取离散值。先看最简单的二分类 $y_i \in \{0, 1\}$。一个直接的想法是**直接用线性回归预测类别编号**，把 $y$ 当数值来拟合。<span class="marginnote">线性回归硬凑分类为什么不行：其一，预测值 $\hat y$ 会落在 $[0,1]$ 之外，无法解释为概率；其二，把 $y\in\{0,1\}$ 编码成任意数字（比如 0 与 100）会改变结果，编码方式没有语义。ESL 里有一个经典图示：三点加一个右上方的离群点，直线边界就会被彻底拉歪。</span>

更合理的思路是换一种目标：不去预测类别编号，而是预测**后验概率** $P(y=1 \mid x)$。把「概率」作为输出，天然落在 $[0,1]$，且允许我们结合损失函数给出决策规则——后验概率大于 0.5 判为类 1，否则类 0。问题随之变成：怎么让一个「线性分数」$\beta_0 + \beta^\top x$ 变成一个合法概率？

## 2 从线性分数到概率：逻辑函数

答案是用 **逻辑函数（logistic / sigmoid）** 把实数轴压缩进 $(0,1)$：

$$\hat p(x) = \frac{e^{\beta_0 + \beta^\top x}}{1 + e^{\beta_0 + \beta^\top x}} = \frac{1}{1 + e^{-(\beta_0 + \beta^\top x)}}$$

等价地，反解得到**对数几率（log-odds）**：

$$\log \frac{\hat p(x)}{1 - \hat p(x)} = \beta_0 + \beta^\top x$$

这是一个线性函数。<span class="marginnote">对数几率是「线性」的：每增加一个单位 $x_j$，几率 $\frac{p}{1-p}$ 变为原来的 $e^{\beta_j}$ 倍。这就是为什么逻辑回归系数常被解释为「优势比（odds ratio）」——它是在乘法尺度上谈影响，与线性回归的加法尺度相对。</span>

**解析｜易错点：** 线性回归要求残差同方差、正态分布，逻辑回归对特征没有任何分布假设。它直接建模条件概率 $P(y \mid x)$，这种「直接对后验建模」的做法称为**判别式（discriminative）**方法，与下一节 LDA 的**生成式（generative）**路线相对——LDA 先假定 $x$ 的分布再推 $P(y|x)$。

## 3 最大似然与交叉熵损失

从概率视角定损失：对每个样本，模型给出 $\hat p_i = P(y_i=1|x_i)$，样本 $(x_i, y_i)$ 的对数似然是

$$\ell(\beta) = \sum_{i=1}^N \Bigl[ y_i \log \hat p_i + (1 - y_i)\log(1 - \hat p_i) \Bigr]$$

最大化 $\ell(\beta)$ 等价于最小化**交叉熵损失（cross-entropy loss）** $-\ell(\beta)$。注意它是 $N$ 个**凹函数（$\log$）的和**，整体凹，因此极大值存在且唯一（特征满秩时）。<span class="marginnote">交叉熵这个名字来自信息论：$-\sum_k q_k \log p_k$ 度量「用分布 $p$ 去编码真实分布 $q$ 的平均代价」，见第二级《概率论与数理统计》的信息熵一节。当 $p$ 错得离谱（$\hat p \to 0$ 而 $y=1$），对数趋于 $-\infty$，梯度极大——这是分类损失「对犯错下重手」的来源。</span>

与最小二乘不同，最大化对数似然没有闭式解，梯度为

$$\nabla_\beta \ell = X^\top (y - \hat p)$$

令梯度为零得 $X^\top(y - \hat p) = 0$，这组方程非线性（因为 $\hat p$ 依赖 $\beta$），只能迭代求解。

## 4 求解：迭代加权最小二乘

牛顿法推广到似然函数，得到**迭代加权最小二乘（IRLS, iteratively reweighted least squares）**。每一步都解一个加权线性回归：

$$\beta^{(t+1)} = \bigl(X^\top W X\bigr)^{-1} X^\top W z,$$

其中 $W = \mathrm{diag}\bigl(\hat p_i(1-\hat p_i)\bigr)$ 是权重对角阵（方差倒数），$z = X\beta^{(t)} + W^{-1}(y - \hat p)$ 是所谓的「工作响应」。<span class="marginnote">直觉：$\hat p_i(1-\hat p_i)$ 在 $\hat p_i = 0.5$（最不确定）时最大，给该样本最高权重——最有争议的样本对参数更新贡献最大。这与「支持向量」精神异曲同工，都是让边界附近的点说了算。</span>

**公式解析：IRLS 更新式**
- **第一步**，把牛顿步化简成加权最小二乘：牛顿法需要 Hessian，恰好 $-\nabla^2\ell = X^\top W X$，而 $X^\top W X$ 正是「带权重 $w_i = \hat p_i(1-\hat p_i)$ 的 $X^\top X$」。
- **第二步**，把梯度方程改写成线性形式：令 $z = X\beta^{(t)} + W^{-1}(y - \hat p)$，则 $X^\top W (z - X\beta) = 0$ 与梯度为零等价——于是每一轮迭代都在解一个加权正规方程。
- **第三步**，循环直到收敛：通常十几次迭代即可，每个特征的权重会随 $\hat p$ 变化，因此每一步都「重新加权」。历史上 IRLS 就是拟合逻辑回归的标准方法，如今梯度下降同样可行。

## 5 多分类与决策边界

二分类的 sigmoid 推广到 $K$ 类，就是 **softmax**：

$$P(y = k \mid x) = \frac{e^{\beta_k^\top x}}{\sum_{j=1}^K e^{\beta_j^\top x}}, \qquad k = 1, \dots, K$$

参数通过最大化多项对数似然（交叉熵）求解。决策边界由 $P(y=k|x) = P(y=l|x)$ 决定，即 $\beta_k^\top x = \beta_l^\top x$——仍是**超平面**，所以逻辑回归是「线性分类器」。<span class="marginnote">softmax 的指数化处理是解决「多类概率归一」的万能模板：先算每个类别的线性分数，再除以总分。你在《神经网络基础》与所有大语言模型的最后一层 softmax 里还会反复见到它。</span>

**解析｜易错点：** 当两类数据**线性可分**时，逻辑回归的 MLE 会发散——因为存在一条完美的分割超平面，把 $\beta$ 的模长推得越大，$\hat p$ 越接近 0/1，似然越高，最优解在无穷远处。现实中处理方式是加正则化或早停，这也是后文正则化专题再展开的主题。

## 6 小结

- **分类 ≠ 回归**：线性回归硬凑分类会得到无意义的概率与任性的决策边界，必须换用概率模型。
- **逻辑函数**：$\hat p(x) = 1/\bigl(1 + e^{-(\beta_0 + \beta^\top x)}\bigr)$ 把线性分数压进 $(0,1)$；对数几率 $\log\frac{p}{1-p}$ 是线性函数。
- **交叉熵损失**：$-\sum_i [y_i\log\hat p_i + (1-y_i)\log(1-\hat p_i)]$，损失函数凹，有唯一极大。
- **IRLS**：把牛顿法化成每轮一次的加权最小二乘，权重 $\hat p_i(1-\hat p_i)$ 偏爱边界附近的争议样本。
- **softmax**：逻辑回归到 $K$ 类的自然推广，是多分类的默认末端，也是神经网络的标准输出层。
- **判别式 vs 生成式**：逻辑回归直接建模 $P(y|x)$；与之相对的是下一节 LDA 的生成式路线。

在下一节，我们回答「为什么还有别的分类器」：生成式方法**线性判别分析（LDA）**从「假设 $x$ 服从什么分布」出发反推类别，还有更古老的**感知机**——它们各自给出了「线性分类」的另一种语法。
