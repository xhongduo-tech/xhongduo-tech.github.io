# 核方法与 SVM

<div class="epigraph">
<p>如果一个物体在特征空间中可以用线性模型表示，那么它在原空间中就是非线性的——这就是核技巧的魔术。</p>

## 为什么「升维」能救线性模型

感知机的教训是：线性分类器面对线性不可分数据毫无办法。核方法给出的回答匪夷所思：**把数据映射到更高维的空间，线性不可分就变成线性可分了**。<span class="marginnote">经典例子：二维平面上圆心在原点的圆内点 vs 圆外点，任何一条直线都切不开。但映射到三维：$(x_1, x_2) \mapsto (x_1, x_2, x_1^2 + x_2^2)$，一个「高度」为半径平方的平面 $z = \mathrm{const}$ 就切开了。升维把非线性结构「展平」成线性结构。</span>

但盲目升维有个致命问题：维度爆炸。把 $p$ 维特征升到所有二阶单项式，就有 $\binom{p+2}{2}$ 维；升到 $k$ 阶就有 $\binom{p+k}{k}$ 维——直接算内积会疯。**核技巧（kernel trick）**就是「升维而不算升维」：只要模型只依赖特征的内积，我们就用核函数直接算内积，永远不显式触碰高维坐标。本节把这两块拼起来：**核方法**（怎么安全地升维）与**支持向量机**（为什么间隔最大化是最优解），两者互相成就。

## 1 特征映射与核技巧

设 $\phi: \mathcal{X} \to \mathcal{H}$ 把原空间映射到特征空间 $\mathcal{H}$。很多算法（如 Ridge、感知机、距离度量）只用到**内积** $\langle \phi(x_i), \phi(x_j) \rangle$。核函数就是在原空间里直接计算该内积的函数：

$$k(x, x') = \bigl\langle \phi(x), \phi(x') \bigr\rangle$$

**解析｜易错点：** 不是随便什么 $k$ 都行——它必须对应某个内积，即存在 $\phi$ 使得上式成立。**Mercer 定理**给出充要条件：$k$ 对称且在任意有限点集上的格拉姆矩阵 $K_{ij}=k(x_i,x_j)$ 半正定。满足条件的核叫 **Mercer 核**（或正定核），常用的是 RBF、多项式核 $(x^\top x' + c)^d$、线性核。这也是上一节 GP 要求核矩阵正定的同一根弦——核方法把「高维空间」简化为「一个满足半正定条件的相似度函数」。<span class="marginnote">Mercer 定理为什么重要？它把「找特征映射」这个不可行的任务替换成「验证一个函数半正定」这个可行的检查。反过来看，半正定核对应的特征空间甚至可能是无穷维（如 RBF）——「升维」不再受坐标数目限制，只受「内积是否好算」限制。这也是核方法能超越显式升维（如多项式特征工程）的根本原因。</span>

RBF 核尤其值得注意：

$$k(x, x') = \exp\bigl(-\|x-x'\|^2/(2\ell^2)\bigr)$$

它对应的特征空间是**无穷维**的（Mercer 展开为无穷项），却依然可算——这是「核技巧」最震撼的例证：**无穷维的内积，在常数时间里算完**。<span class="marginnote">RBF 核的特征空间为什么无穷维？因为指数展开 $\exp(-\|x-x'\|^2/2\ell^2)$ 可以写成 $\sum_{j\ge0} \psi_j(x)\psi_j(x')$ 的形式，其中 $\psi_j$ 是无穷多个基函数（高斯/厄米基），每个对应一维。这就是「径向基」的来历——核值只依赖两点距离，像个以 $x'$ 为中心、向四周衰减的基函数。</span>

常用核放一张表，各自的「性格」一目了然：

| 核 | 形式 | 特征空间 | 适用场景 |
| --- | --- | --- | --- |
| 线性核 | $x^\top x'$ | 原空间 | 高维稀疏（文本） |
| 多项式核 | $(x^\top x' + c)^d$ | 有限维 | 有交互特征 |
| RBF 核 | $\exp(-\|x-x'\|^2/2\ell^2)$ | 无穷维 | 默认、通用 |
| 拉普拉斯核 | $\exp(-\|x-x'\|/\ell)$ | 无穷维 | 对尺度变化更钝感 |

**解析｜易错点：** 选核没有免费定理，只有两条经验：其一，**先试 RBF**——它只有一个长度尺度、能表达绝大多数非线性，配标准化基本够用；其二，**多项式核的次数 $d$ 别太高**——高次会产生病态的大内积与数值溢出。真正的「核选择」通常发生在交叉验证阶段：在「线性核（快但弱）」与「RBF（强但慢）」之间，按验证误差而不是「看起来酷」来定。

## 2 支持向量机：最大间隔分类器

有了核，还需一个好分类器。**支持向量机（SVM, support vector machine）**是最大间隔思想 + 核技巧的完美结合。先看线性可分情形：

$$\max_{\beta, \beta_0, \|\beta\|=1} M \qquad \text{s.t.} \quad y_i (\beta_0 + \beta^\top x_i) \ge M,\; \forall i$$

$M$ 是**间隔（margin）**——离超平面最近样本的距离。SVM 要**把间隔尽量拉大**。<span class="marginnote">为什么最大间隔最优？理论上是「间隔大小」控制泛化：间隔越大的超平面，对样本的微小扰动越稳健（VC 维的上界与间隔成反比）。直觉上，边界「最胖」的分类器最不怕测试时样本挪动一点。这也回应了感知机的教训——它只求「有一条线」，而 SVM 要「最肥的那条线」。</span>

一个具体的对称性观察：**间隔只由「离超平面最近的那几个点」决定，其余点一概不参与**——这既让 SVM 稳健（远离边界的噪声无关痛痒），也是它「稀疏」的根源。对比逻辑回归：每个点（哪怕离边界很远）都对似然有微小贡献，因此解是全稠密的。<span class="marginnote">「稀疏」带来的工程红利：训练完只需存支持向量，模型大小只与支持向量个数成正比。2000 年代 SVM 在文本分类（动辄上百万特征）上能跑，正是靠这份稀疏——这也反向解释了为什么它后来被更擅长海量数据的核近似方法（如随机特征、SGD 版核学习）逐步补充。</span>

改写为标准形式：最小化 $\frac12\|\beta\|^2$ 约束 $y_i(\beta_0 + \beta^\top x_i) \ge 1$，用拉格朗日对偶解得

$$\beta = \sum_{i=1}^N \alpha_i y_i x_i$$

**只有 $\alpha_i > 0$ 的样本才参与决定 $\beta$**——这些点恰好落在间隔边界上，称为**支持向量（support vector）**。<span class="marginnote">这是 SVM 得名的由来：最终分类器只由少数几个「关键点」决定，其余样本点全部无关。间隔边界上 $\alpha_i > 0$，内部 $\alpha_i = 0$。稀疏性带来效率与可解释：测试时只需与支持向量算内积。这也让 SVM 对内存友好，成为 2000 年代文本分类的事实标准。</span><span class="marginnote">「支持向量」这个名字本身就是答案：向量（样本点）在「支撑」着分类边界——把它们移走，超平面就会动；其余点移走，边界纹丝不动。你可以在任何二维数据集上做这个实验：删掉所有非支持向量，SVM 的决策边界完全不变。</span>

### 数值算例：一维数据的最大间隔

一维点 $x = (1, 2, 5)$，标签 $y = (-1, -1, +1)$。要找一个阈值 $b$：$x < b$ 判 $-1$、$x > b$ 判 $+1$。最大间隔解落在 $b = 3.5$（两个异类区段的中间），间隔 $M = 1.5$——支持向量是 $x = 2$ 与 $x = 5$（距离最近的两个异类点），$x = 1$ 无关。把 $x=1$ 挪到 $1.9$，间隔纹丝不动；把 $x=2$ 挪到 $2.9$，间隔立刻缩小——**「谁撑着边界」一测便知**，这正是「支持向量」一词的精确含义。

## 3 软间隔：允许犯错的最大间隔

线性不可分（或有噪声）时，硬间隔不可行。**软间隔 SVM（soft-margin）**引入松弛变量 $\xi_i \ge 0$：

$$\min_{\beta, \beta_0, \xi} \left\{ \frac12\|\beta\|^2 + C \sum_{i=1}^N \xi_i \right\} \quad \text{s.t.} \quad y_i(\beta_0+\beta^\top x_i) \ge 1 - \xi_i$$

$C$ 是惩罚参数：$C$ 大 → 严打误分类（方差大、可能过拟合）；$C$ 小 → 容忍更多错误（偏差大、更平滑）。从损失函数视角，SVM 等价于**最小化合页损失（hinge loss）**：<span class="marginnote">$C$ 的直觉：它是「误分类代价」与「间隔大小」之间的天平——$C$ 大时宁可牺牲间隔也要少犯错，$C$ 小时宁可多犯错也要更大的间隔。$C \to \infty$ 退化为硬间隔，$C \to 0$ 退化为「尽可能大的间隔、几乎不管错误」。这个 $C$ 与逻辑回归里的正则化强度 $\lambda$ 是对偶的两面：$C$ 大 $\leftrightarrow \lambda$ 小。</span>

$$\min_\beta \; \frac{1}{2}\|\beta\|^2 + C \sum_{i=1}^N \max\bigl(0, 1 - y_i(\beta_0 + \beta^\top x_i)\bigr)$$

合页损失 $\max(0, 1 - y_i f(x_i))$：分类正确且置信高时损失为 0，错误时线性增长。它与逻辑回归的对数损失同为分类损失的「凸替身」，但**合页损失对已正确分类的点完全不罚**——这正是它偏爱稀疏支持向量的原因。<span class="marginnote">损失函数一览：0-1 损失不可微难优化；合页损失（SVM）与对数损失（逻辑回归）是它的凸上界/平滑代理；平方损失（感知机的变体）处处可微但离群点敏感。选损失=选「哪些错误值得在意」：SVM 只在乎边界附近，逻辑回归在乎所有点的置信度。</span>

把四种常见分类损失并列，各自的「性格」立即分明：

| 损失 | 形式 | 优化难度 | 对正确样本 |
| --- | --- | --- | --- |
| 0-1 损失 | $\mathbb{1}(y \neq f(x))$ | 不可微、NP 难 | 完全不罚 |
| 合页损失（SVM） | $\max(0,1-yf(x))$ | 凸、可子梯度 | 置信高时不罚 |
| 对数损失（逻辑回归） | $\log(1+e^{-yf(x)})$ | 凸、处处可微 | 越近越轻、永不为 0 |
| 平方损失 | $(1-yf(x))^2$ | 凸、可微 | 正确过头也罚 |

**解析｜易错点：** 合页损失与对数损失的区别值得反复体会——逻辑回归「鼓励」样本置信度尽量高，SVM 则「只要过了间隔线就不再管」。因此逻辑回归的系数常比 SVM 更「卷」，SVM 的解也更稀疏、更稳。

## 4 公式解析：核 SVM 的决策函数

把软间隔 + 核技巧合体，对偶问题得到最终决策函数：

$$f(x) = \mathrm{sign}\left( \sum_{i \in \mathcal{S}} \alpha_i y_i \, k(x, x_i) + \beta_0 \right)$$

$\mathcal{S}$ 是支持向量集合。拆三步理解：

- **第一步，对偶解出 $\beta$ 的核表示**：原问题 $\beta = \sum_i \alpha_i y_i x_i$，把内积 $\beta^\top x$ 换成 $\sum_i \alpha_i y_i \langle x_i, x \rangle$。
- **第二步，用核替换内积**：$\langle x_i, x \rangle \to k(x_i, x)$，于是升维后的线性分类器 $f(x) = \mathrm{sign}(\sum \alpha_i y_i k(x_i,x) + \beta_0)$ 在**原空间就是非线性**的，但我们从未显式构造 $\phi$。
- **第三步，稀疏求和**：非支持向量 $\alpha_i = 0$，求和只遍历支持向量集 $\mathcal{S}$。预测时只需要对每个支持向量算一次核值——计算成本正比于支持向量个数，而非全样本数。

**解析｜易错点：** 核 SVM 的「非线性」完全由核定义，而**核与超参（$\ell$, $C$）的选择决定成败**，都靠交叉验证。RBF 核只有一个长度尺度，对特征尺度敏感，必须标准化特征。另外 SVM 的输出是「边界的符号」，**不给出概率**——要概率得用 Platt 缩放（事后接一个逻辑回归把分数映射成概率），这是它与逻辑回归、GP 的一个现实差异。<span class="marginnote">「SVM 不给概率」的工程后果：需要不确定性输出的任务（如医学诊断、推荐排序要校准置信度）不能直接用 SVM，得加 Platt 校准或换逻辑回归/GP。反过来，只关心「分对/分错」的任务里，SVM 的稀疏解让它比全稠密的逻辑回归更省内存——两个方法各有所长。</span>

## 6 小结

- **核技巧**：$k(x,x') = \langle \phi(x), \phi(x')\rangle$，升维而不显式计算高维坐标；Mercer 定理保证核合法性。
- **RBF 核**：对应无穷维特征空间，仍可在常数时间算内积，是核方法最常用的「默认核」。
- **最大间隔**：SVM 最大化间隔 $M$，等价于最小化 $\frac12\|\beta\|^2$，对偶解 $\beta = \sum \alpha_i y_i x_i$。
- **支持向量**：只有 $\alpha_i>0$ 的边界样本决定模型，分类器稀疏、由数据中的「关键点」代言。
- **软间隔**：松弛变量 $\xi_i$ + 惩罚 $C$ 容忍噪声，等价于合页损失正则化。
- **核 SVM 决策**：$f(x) = \mathrm{sign}(\sum_{i\in\mathcal{S}}\alpha_i y_i k(x,x_i) + \beta_0)$，预测只算支持向量的核值。
