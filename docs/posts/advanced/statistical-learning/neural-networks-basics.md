## 为什么神经网络是「统计学习的集大成者」

前面的方法各有分工：线性回归管光滑超平面，样条管一维曲线，SVM 管间隔最大化，树管矩形划分。**神经网络（neural network）**用一种结构把这一切统一起来：多层「加权求和 + 非线性激活」的函数复合。它不挑任务——分类、回归、图像、文本、强化学习，同一套优化框架通吃。<span class="marginnote">本节对标 ESL §11（当时还叫「神经网络」，今天叫「深度学习」）。从「从极限到大模型」的主线看，这里是你把微积分（链式法则）、线性代数（矩阵）、概率论（似然）、优化（梯度下降）全部焊在一起的接口，也是通往大模型内部的第一级台阶。</span>

理解神经网络的钥匙有两把：**表达**（它能表示什么样的函数）与**学习**（怎么学出参数）。前者靠「足够宽足够深就能逼近任何函数」的万能逼近定理，后者靠**反向传播（backpropagation）**——它只是链式法则的工程化，却被《自然》杂志称为「1980 年代机器学习最重要的思想」。本节把这两把钥匙都递到你手上。

## 1 从感知机到多层感知机

感知机 $\sigma(\beta_0 + \beta^\top x)$ 只能切一条直线，且激活是硬阈值（$\mathrm{sign}$），不可微、无法梯度训练。多层感知机（MLP）的三处升级：

1. **堆叠隐藏层**：函数复合 $f(x) = g\bigl(W^{(2)}\, \sigma(W^{(1)}x + b^{(1)}) + b^{(2)}\bigr)$，层与层之间是非线性激活；
2. **可微激活**：$\sigma$ 换成 sigmoid、$\tanh$、ReLU 等光滑（或分段光滑）函数；
3. **连续可微损失**：回归用平方损失，分类用交叉熵，全部可对参数求梯度。<span class="marginnote">MLP 的起源：鲁姆哈特、辛顿与威廉姆斯 1986 年发表的《通过误差反向传播学习内部表征》是深度学习史的开篇。而 1989 年辛顿的学生给出了「万能逼近」的味道：单隐层、足够宽、sigmoid 激活的网络可以任意精度逼近任何连续函数——前提是宽度够大。这也是「第一代大模型=足够宽的网络」的理论底座。</span>

激活函数值得单独说。**ReLU**：$\sigma(z) = \max(0, z)$，如今是默认选择——它线性、不饱和、梯度不消失；而 sigmoid 在两端梯度趋近 0，深层网络里梯度连乘会「死」掉，这就是著名的**梯度消失（vanishing gradient）**问题。<span class="marginnote">为什么线性激活（如恒等映射）不行？若所有激活都是线性的，多层网络退化成一层线性变换——堆多少层都没意义。所以激活必须「非线性但导数稳定」：ReLU 恰好两点都满足（非线性 + 导数 0/1），sigmoid 满足非线性但导数不稳定。这是「非线性」与「梯度」两个需求打架后，工程上找到的折中。</span><span class="marginnote">梯度消失的数学：反向传播把每层梯度乘上 $\sigma'(z)$，sigmoid 导数最大才 0.25，十几层一乘，梯度指数级缩小到 0——深层网络学不动。ReLU 的导数是 0 或 1，要么梯度正好不衰减、要么干脆「死亡 ReLU」。这是深度学习的第一个工程教训，也是 batch norm、残差连接等一切「稳定梯度」技术的动机。</span>

## 2 学习：梯度下降与反向传播

训练目标是最小化经验损失

$$\mathcal{L}(\theta) = \sum_{i=1}^N \ell\bigl(y_i, f(x_i; \theta)\bigr),$$

$\theta$ 是所有权重与偏置。没有闭式解（非线性），只能迭代：**梯度下降** $\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}$，$\eta$ 是**学习率（learning rate）**。<span class="marginnote">大批量 vs 小批量：全量梯度稳定但每步都贵；随机梯度下降（SGD）每步只看一个样本、噪声大但便宜；实践中折中是小批量（mini-batch，如 32–256 个样本）。小批量的随机性还有一个隐藏好处——噪声本身就是一种正则化，帮模型逃离尖锐极小值。</span>

**反向传播**回答「$\nabla_\theta \mathcal{L}$ 怎么高效算」。以单隐层网络 $f = W_2\,\sigma(W_1 x + b_1) + b_2$ 为例：

- **前向**：$z_1 = W_1x + b_1$，$a_1 = \sigma(z_1)$，$z_2 = W_2a_1 + b_2$，$\hat y = z_2$；
- **反向**：先算输出层误差 $\delta_2 = \partial \mathcal{L}/\partial z_2$，再沿链式法则回传 $\delta_1 = W_2^\top \delta_2 \odot \sigma'(z_1)$；
- **更新**：$\nabla_{W_2}\mathcal{L} = \delta_2 a_1^\top$，$\nabla_{W_1}\mathcal{L} = \delta_1 x^\top$。

**公式解析：反向传播的一步**（这里单看 $\delta_1$）

$$\delta_1 = W_2^\top \delta_2 \odot \sigma'(z_1)$$

- **第一步，看结构**：$\delta_1$ 是「第 1 层神经元对损失的梯度贡献」，$\delta_2$ 是第 2 层（输出层）的对应量。$\odot$ 是逐元素乘。
- **第二步，追溯误差来源**：$z_1$ 影响 $z_2 = W_2\sigma(z_1)+b_2$，而 $z_2$ 影响损失。链式法则：$\frac{\partial \mathcal{L}}{\partial z_1} = \frac{\partial \mathcal{L}}{\partial z_2} \cdot \frac{\partial z_2}{\partial z_1}$。
- **第三步，两块的形状**：$\frac{\partial z_2}{\partial z_1} = W_2 \odot \sigma'(z_1)$（每路只经自己的激活函数，故逐元素），所以 $\delta_1 = (W_2^\top \delta_2) \odot \sigma'(z_1)$。**误差被 $W^\top$ 沿反向传回、再用激活导数「门控」**——这就是「反向传播」的名字来源，误差像溪水一样从输出倒流回每一层。

### 数值算例：一个样本的反向传播

把上面的公式走一遍具体数字。设单隐层网络：输入 $x = 1$，$W_1 = 2$、$b_1 = 0.5$，激活用 ReLU $\sigma(z) = \max(0,z)$，输出层 $W_2 = 1$、$b_2 = 0$，目标 $y = 2$，损失取平方损失 $\mathcal{L} = \frac12(\hat y - y)^2$。

**前向**：$z_1 = 2\times 1 + 0.5 = 2.5$，$a_1 = \max(0, 2.5) = 2.5$，$\hat y = 1\times 2.5 + 0 = 2.5$。

**反向**：$\delta_2 = \hat y - y = 0.5$；$\nabla_{W_2}\mathcal{L} = \delta_2 a_1 = 0.5\times 2.5 = 1.25$；沿链回传 $\delta_1 = W_2\delta_2\cdot\mathbb{1}(z_1>0) = 1\times 0.5\times 1 = 0.5$，于是 $\nabla_{W_1}\mathcal{L} = \delta_1 x = 0.5$。

若学习率 $\eta = 0.1$，则 $W_2 \leftarrow 1 - 0.1\times 1.25 = 0.875$，$W_1 \leftarrow 2 - 0.1\times 0.5 = 1.95$。**每个权重的梯度恰好是「输出端误差 × 该权重通往的激活值」**——这就是「误差倒流」最朴素的模样，也是你手工验算任何深度学习框架输出时要用到的第一把尺子。

## 3 过拟合与调参：正则化的神经网络版

神经网络的参数数以百万计，过拟合风险极大，但它没有 $X^\top X$ 可加惩罚，正则化手段自成体系：

- **权重衰减（weight decay）**：损失加 $\lambda\|\theta\|_2^2$，就是 Ridge 在神经网络里的名字；<span class="marginnote">权重衰减为什么在神经网络里尤其重要？因为参数以百万计，模型容量巨大，不加惩罚几乎必然过拟合。它还有一层几何含义：$\theta \leftarrow (1-\eta\lambda)\theta - \eta\nabla\mathcal{L}$——每步更新前先把参数往原点「缩」一点，等价于「每次都向更小的权重靠拢」。现代大模型训练几乎无一例外带着 weight decay。</span>
- **早停（early stopping）**：监测验证集误差，一旦开始回升就停止训练——本质是隐式的正则化；
- **Dropout**：训练时随机让一部分神经元「失活」（以概率 $p$ 置零），迫使网络不依赖任何单个神经元，等于同时训练大量子网络再平均；<span class="marginnote">Dropout 由辛顿团队 2012 年提出，是深度学习「免费」正则化里最著名的一个。它的贝叶斯解释：相当于给参数乘伯努利噪声，在训练目标里注入「模型平均」。如今大模型训练仍在用它，只是披着「随机失活」的名字。</span>
**数据增强**：对输入做合法变换（旋转、平移、加噪），扩大有效样本量——视觉与语音领域的默认武器。<span class="marginnote">数据增强的思想与《决策树与随机森林》的 Bagging 异曲同工：都是「造出更多略有差异的样本，让模型见过更多变体」。区别是 Bagging 在特征/样本上重采样，增强在输入空间做保持语义的变换——每张旋转过的猫图都是「另一只猫」，模型因此学到旋转不变性而非死记像素。</span>
**批归一化（batch normalization）**：在每层激活前把一批数据的均值方差归一到 0/1 再缩放平移，让每层输入的分布稳定——它不直接惩罚复杂度，却让深层网络的梯度更容易流动，是「稳定训练」家族的代表成员。

把这些正则化手段放在一张表里，各自的「治什么病」一目了然：

| 手段 | 机制 | 对付的问题 | 备注 |
| --- | --- | --- | --- |
| 权重衰减 | 损失加 $\lambda\|\theta\|_2^2$ | 过拟合（容量过大） | 即 Ridge，现代大模型训练标配 |
| 早停 | 验证误差回升即停 | 过拟合（训练过久） | 隐式正则化，零额外成本 |
| Dropout | 随机置零神经元 | 过拟合（依赖单神经元） | 等价于子网络模型平均 |
| 数据增强 | 输入做保持语义的变换 | 样本不足 | 视觉与语音的默认武器 |
| 批归一化 | 每层输入归一到 0/1 再缩放平移 | 梯度难流动、训练不稳 | 不罚复杂度，只稳定分布 |

**解析｜易错点：** 早停与权重衰减可以并存、并非互斥——早停从「训练时长」这一维度压缩模型，权重衰减从「权重范数」这一维度压缩模型，两者加起来往往比单独用任何一个都稳。同理 Dropout 与数据增强也不冲突：一个在「模型内部」注入随机性，一个在「数据外部」注入变体，机制互补。

**解析｜易错点：** 学习率 $\eta$ 是全局最敏感的超参：太大，损失震荡不收敛甚至发散；太小，训练蜗牛爬。实用口诀是「先试大的（0.1 量级），loss 爆炸就除以 10」。而**特征必须标准化**（否则大数值特征主导梯度），分类用交叉熵（不要用平方损失配 sigmoid，会学不动），权重用小随机数初始化（对称权重会让神经元退化一致）。

「用交叉熵、别用平方损失配 sigmoid」这条值得展开：平方损失配 sigmoid 时，输出层误差 $\delta = (\hat y - y)\sigma'(z)$ 会乘上接近 0 的 $\sigma'(z)$（两端饱和），梯度被压死；交叉熵与 sigmoid 天生相消，$\delta = \hat y - y$ 直接等于残差，梯度不再被激活导数拖累。**损失与激活的搭配不是风格问题，而是梯度能否流动的生死问题**——这个洞察贯穿所有分类网络的设计。

## 4 从全连接到现代架构

单隐层 MLP 对图像任务很弱：图像是 $224\times224\times3$ 的像素张量，全连接参数爆炸。三招现代的升级：

- **卷积（CNN）**：权重共享的局部感受野，平移不变，参数量锐减；<span class="marginnote">卷积为什么省参数？一个 $3\times3$ 卷积核在整张图上滑动、权重完全共享——无论图像多大，每层只需 9 个权重（加偏置）。对比全连接层：$224\times224$ 的图像第一层全连接就要几百万参数。卷积的「参数共享」+「局部连接」正是《正则化》思想的极端版本：用极强的先验（平移不变）换取巨大的参数压缩。</span>
- **循环（RNN/LSTM）**：共享权重沿时间展开，处理序列；<span class="marginnote">一个提醒：本专题到《神经网络基础》为止还是「经典的统计学习阶段」。CNN 与 RNN 之后，2017 年 Transformer 用自注意力替换了循环，把「并行 + 长程依赖」做到极致——那就是第三级/第四级另一条线《深度学习》与《大模型》的主场。这里的每一块砖（损失、正则化、反向传播、SGD）在 Transformer 里原封不动地被沿用。</span>
- **残差连接（ResNet）**：$y = F(x) + x$，让梯度有高速公路直达浅层，解决更深网络的退化。<span class="marginnote">残差连接解决的问题非常具体：网络深到一定程度，性能反而退化（不是过拟合，是优化困难——梯度难以穿过几十层）。加上恒等捷径后，梯度可以从最后一层「抄近路」直达任意浅层，层数从几十推到上千。这个「给梯度开路」的思路，在 Transformer 里以同样的 $x + \mathrm{Attn}(x)$ 形态出现，是深度网络最通用的结构件。</span>

## 6 小结

- **MLP**：感知机 + 隐藏层 + 可微激活（ReLU 首选），用函数复合拟合任意光滑映射。
- **反向传播**：链式法则的工程实现，误差 $\delta$ 沿 $W^\top$ 回传、被 $\sigma'(z)$ 门控，复杂度与前向同阶。
- **梯度下降**：$\theta \leftarrow \theta - \eta\nabla\mathcal{L}$；小批量 SGD 是默认引擎，学习率 $\eta$ 是头号超参。
- **正则化**：权重衰减、早停、Dropout、数据增强，共同对抗百万级参数带来的过拟合。
- **易错**：梯度消失（sigmoid 深层）、特征未标准化、对称初始化、平方损失配 sigmoid。
- **承前启后**：卷积/循环/残差是深度学习的下一次跃迁，而 Transformer 与注意力把这条路带到「大模型」。
