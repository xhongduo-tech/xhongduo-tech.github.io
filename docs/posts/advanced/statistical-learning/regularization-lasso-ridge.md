## 为什么「宁可偏，不可抖」

线性回归的最小二乘解 $\hat\beta = (X^\top X)^{-1}X^\top y$ 优雅、无偏、在无偏估计中方差最小——那为什么我们还要换掉它？因为**无偏并不等于误差最小**。测试误差可以分解成三块：

$$\mathbb{E}[(y_0 - \hat f(x_0))^2] = \underbrace{\mathrm{Var}(\hat f(x_0))}_{\text{方差}} + \underbrace{\mathrm{Bias}(\hat f(x_0))^2}_{\text{偏差}^2} + \sigma^2$$

一个完全无偏但方差爆炸的模型，总误差仍然可能惨不忍睹；反过来，**主动引入一点点偏差，把方差压下去，总误差反而更小**。<span class="marginnote">偏差-方差分解是统计学习的元定理：更复杂的模型偏差小、方差大；更简单的模型偏差大、方差小。平衡点在哪，取决于数据量 $N$、特征数 $p$ 与真实关系的光滑程度。这个概念贯穿本专题每一篇：树的剪枝、神经网络的早停、Boosting 的学习率，全是同一件事。</span>

**正则化（regularization）**就是这架跷跷板上最直接的旋钮：在损失函数上追加一个对系数大小的惩罚项，把大系数「罚」回去，从而限制模型复杂度。

## 1 两种惩罚，两种几何

对线性回归，加上 $L_q$ 范数惩罚就得到一族模型。最重要的两个成员：

**岭回归（Ridge）**——$L_2$ 惩罚：

$$\hat\beta^{\text{ridge}} = \arg\min_\beta \left\{ \sum_{i=1}^N \bigl(y_i - x_i^\top \beta\bigr)^2 + \lambda \sum_{j=1}^p \beta_j^2 \right\}$$

**Lasso（least absolute shrinkage and selection operator）**——$L_1$ 惩罚：

$$\hat\beta^{\text{lasso}} = \arg\min_\beta \left\{ \sum_{i=1}^N \bigl(y_i - x_i^\top \beta\bigr)^2 + \lambda \sum_{j=1}^p |\beta_j| \right\}$$

两者的差别初看只是平方与绝对值，却带来截然不同的行为：**Ridge 把系数整体收缩但几乎不归零，Lasso 会把不少系数恰好压到 0——自带特征选择**。<span class="marginnote">Lasso 由 Tibshirani 1996 年提出，名字直译「套索」——像套索一样把不重要系数的绳子拉断。它与 1995 年前后统计学家们的「基追踪」（basis pursuit）不谋而合，如今是高维稀疏建模（包括神经网络的稀疏剪枝、大模型的稀疏注意力）的祖传工具。</span>

把两种惩罚并排比较，行为差异一目了然：

| 特性 | Ridge（$L_2$） | Lasso（$L_1$） |
| --- | --- | --- |
| 解的形式 | 全部系数收缩，几乎不归零 | 部分系数恰好压到 0 |
| 闭式解 | $(X^\top X+\lambda I)^{-1}X^\top y$ | 无（坐标下降 / LARS） |
| 特征选择 | 无（全部保留） | 自带（稀疏选择） |
| 强相关特征 | 一起收缩，结果稳定 | 倾向随机只挑一个 |
| 约束可行域 | 圆 / 球（无尖角） | 菱形（坐标轴上有尖角） |

这张表是本节的地图：§2 讲「为什么」——$L_1$ 的尖角几何如何制造稀疏；§4 讲「怎么办」——弹性网如何弥补 Lasso 的随机取舍。

## 2 公式解析：为什么 $L_1$ 产生稀疏解

这是本节最值得停下的问题。把约束视角打开：最小化带惩罚的目标，等价于在约束 $\sum_j \beta_j^2 \le t$（Ridge）或 $\sum_j |\beta_j| \le t$（Lasso）下最小化 RSS。

- **第一步，看可行域的形状**：$L_2$ 约束的可行域是**圆/球**（在二维是圆盘），$L_1$ 约束的可行域是**菱形**。目标 RSS 的等高线是中心在最小二乘解 $\hat\beta^{\text{OLS}}$ 的椭圆族。
- **第二步，找椭圆与可行域的切点**：最优解是等椭圆与可行域边界**首次相切**的点。菱形在坐标轴上有**尖角**，椭圆一旦碰到尖角，切点就落在轴上——某个坐标恰好为 0。
- **第三步，稀疏由此而来**：当椭圆沿坐标轴方向被尖角「勾住」时，$\hat\beta_j = 0$。特征越多、$\lambda$ 越大，被勾住的坐标越多，于是 Lasso 解天然稀疏。Ridge 的圆盘没有尖角，切点通常在圆盘内部或边界上但不在轴心，所以系数只收缩、不归零。

Ridge 的解析解可以显式写出：

$$\hat\beta^{\text{ridge}} = (X^\top X + \lambda I)^{-1} X^\top y$$

相比最小二乘，它把 $X^\top X$ 的对角元整体加上 $\lambda$——**把矩阵「正则化」得更好求逆**，这正是 $p > N$ 时 $X^\top X$ 奇异、加 $\lambda I$ 后重新可逆的原因。<span class="marginnote">Ridge 的收缩方向可做奇异值分解看清：若 $X = UDV^\top$，则 $\hat\beta^{\text{ridge}} = V(D^2+\lambda I)^{-1}D U^\top y$。系数按特征值平方 $d_j^2$ 缩放——小奇异方向被收缩得最狠，对应「数据信息量少的方向」被压平。这也说明 Ridge 从不正交于任何坐标，它更像把整个系数向量「捏」向原点。</span>

### 数值算例：Ridge 闭式解怎么「动」

接着上一篇《线性回归与最小二乘》的一维算例：中心化后 $X^\top X = 5$，$X^\top y = 4$。取 $\lambda = 2$，则

$$\hat\beta^{\text{ridge}} = \frac{X^\top y}{X^\top X + \lambda} = \frac{4}{5+2} \approx 0.571$$

对比最小二乘的 0.8：加 $\lambda$ 后系数向 0 收缩了约三成。再试 $\lambda = 0.5$：$\hat\beta = 4/5.5 \approx 0.727$，收缩较轻；$\lambda = 50$：$\hat\beta \approx 0.073$，几乎被压没。**$\lambda$ 从小到大，就是从「信任数据」平滑滑向「什么都不信」的过程**——分母被 $\lambda$ 抬升，正是「$X^\top X$ 奇异时加 $\lambda I$ 重新可逆」在 $p=1$ 上的缩影：即使 $X^\top X$ 这一维退化成 0（比如数据全是同一个值），加 $\lambda$ 后分母依然大于 0。

## 3 怎么选 $\lambda$：交叉验证

$\lambda$ 是超参数：$\lambda = 0$ 时回到最小二乘（过拟合），$\lambda \to \infty$ 时系数全压到 0（欠拟合）。选 $\lambda$ 的标准做法是 **$K$ 折交叉验证（cross-validation）**：把数据分成 $K$ 份，轮流用 $K-1$ 份训练、1 份验证，对每个候选 $\lambda$ 记录验证误差，取误差最小者。<span class="marginnote">交叉验证是统计学习里最通用的「选超参」办法，它把「未来测试误差」用一个分割过的训练集来估计。第一级「从极限到大模型」里所有模型的调参，本质都是同一件事：用一个 hold-out 部分评估泛化。样本足够时，一次随机分割（训练/验证/测试）也够用，但 $K$ 折更稳。</span>

沿着 $\lambda$ 从小到大扫一遍，就画出**正则化路径（regularization path）**：Lasso 路径上系数逐个从 0 被「唤醒」，呈分段线性——这催生了高效算法 LARS（最小角回归）与坐标下降。<span class="marginnote">坐标下降在单个坐标上解一维 Lasso 有闭式（软阈值）：$\hat\beta_j = \mathrm{soft}\left(\frac{x_j^\top r}{N}, \lambda\right)$。每个坐标一次内积、一次软阈值操作，扫几轮就收敛，是高维 Lasso 的默认引擎，glmnet 与 scikit-learn 都靠它。</span>

实践中 $\lambda$ 的候选值在对数刻度上排成网格，逐个跑交叉验证。例如 $N=100$ 的回归，试 $K=5$ 折、10 个 $\lambda$ 值，典型结果可能是：

| $\lambda$ | 5 折 CV 均方误差 | 非零系数个数 |
| --- | --- | --- |
| 0.0001 | 1.82 | 15 |
| 0.01 | 1.71 | 9 |
| 0.1 | 1.65 | 4 |
| 1.0 | 2.03 | 1 |

取误差最小的 $\lambda \approx 0.1$ 即可。注意到一个规律：**$\lambda$ 从很小开始误差先降（抑制过拟合），再升（欠拟合）**——选 $\lambda$ 就是在曲线谷底附近取点，与选树的剪枝强度、选神经网络的轮数是同一个动作。

## 4 从 Lasso 到弹性网：群组与相关性

Lasso 有一个已知的短板：特征强相关时，它倾向于**只随机挑一个**代表，解不稳定。弹性网（elastic net）把两个惩罚线性组合：

$$\hat\beta^{\text{en}} = \arg\min_\beta \left\{ \mathrm{RSS} + \lambda_1 \|\beta\|_1 + \lambda_2 \|\beta\|_2^2 \right\}$$

$L_2$ 部分先把相关特征「聚拢」成组，$L_1$ 部分再整组地选进或剔除——于是**强相关特征被一起选上**，弥补了 Lasso 的随机性。<span class="marginnote">弹性网由 Zou & Hastie 2005 年提出，实践中几乎是 Lasso 的默认替代：它既保留稀疏，又稳定了选择。类似的「$L_2$ 聚合 + $L_1$ 选择」思想也出现在 group lasso、以及深度学习的 weight decay（Ridge 在神经网络中的化身）里。</span>

**解析｜易错点：** 正则化必须在**标准化的特征**上进行——惩罚 $\sum \beta_j^2$ 对各维度一视同仁，若 $x_j$ 量纲不同（比如身高与收入），惩罚实际只作用在量纲大的维度上。标准化（减去均值、除以标准差）后每个特征才真正「平等参与惩罚」。另一个常见坑是**不要用 $\lambda$ 选完再重新估计**：惩罚项本身已包含在估计里，直接取带惩罚的解即可。

## 5 小结

- **偏差-方差权衡**：$\text{测试误差} = \text{偏差}^2 + \text{方差} + \sigma^2$，正则化用可控的偏差换取方差的大幅下降。
- **Ridge（$L_2$）**：$\min \mathrm{RSS} + \lambda\|\beta\|_2^2$，闭式解 $(X^\top X + \lambda I)^{-1}X^\top y$，系数收缩但不归零，且解决 $p>N$ 的奇异性。
- **Lasso（$L_1$）**：$\min \mathrm{RSS} + \lambda\|\beta\|_1$，菱形可行域的尖角制造稀疏解，自带特征选择。
- **超参 $\lambda$**：由 $K$ 折交叉验证选出，从 0 到 $\infty$ 画正则化路径；高维高效算法是坐标下降与 LARS。
- **弹性网**：$L_1+L_2$ 混合，解决 Lasso 对强相关特征的随机取舍。
- **前提**：特征需先标准化，惩罚才有意义。
