## 为什么还要学这两个「老家伙」

逻辑回归直接建模后验概率 $P(y|x)$，是**判别式**路线。但统计学习历史上还有另一条路：先建模**每类的输入分布** $P(x|y)$，再借助贝叶斯公式反推后验——这就是**生成式**路线，它的代表作是费希尔 1936 年就提出的**线性判别分析（LDA）**。<span class="marginnote">LDA 比逻辑回归早了几十年，罗纳德·费希尔（Ronald Fisher）最初用它做鸢尾花分类。生成式模型不仅给出分类器，还给出「每类长什么样」的完整概率描述，这在样本量小、分布有先验知识时尤其有利。</span>

**感知机（perceptron）**则是另一条血脉：罗森布拉特 1958 年在康奈尔做的神经元仿真，是**神经网络**的精神祖先，也是「最大间隔」这条线索的起点——它犯的错误恰好引导后人走向支持向量机。本节把这两个「老家伙」放在一起，不是怀旧，而是因为它们的成败边界把后面所有分类器的设计动机照得清清楚楚：**假设越强越稳、假设越弱越灵活，代价各有不同**。

## 1 生成式：从类分布到判别边界

贝叶斯决策理论告诉我们，让期望 0-1 损失最小的决策是选**后验概率最大**的类：

$$P(y = k \mid x) = \frac{\pi_k \, f_k(x)}{\sum_{j=1}^K \pi_j f_j(x)},$$

其中 $\pi_k$ 是第 $k$ 类的先验概率，$f_k(x)$ 是第 $k$ 类输入的条件密度。所谓**生成式**，就是先估计 $f_k(x)$ 与 $\pi_k$，再由上式算出后验——「先造出数据，再作分类」。

**线性判别分析（LDA, linear discriminant analysis）**作了两个关键假设：

1. 每一类 $k$ 的 $x$ 服从**多元高斯分布** $x \mid y=k \sim \mathcal{N}(\mu_k, \Sigma_k)$；
2. 各类**共享同一个协方差矩阵**：$\Sigma_k = \Sigma$。<span class="marginnote">这两个假设一个都不能少：高斯假设给「每类长什么样」一个可估计的形状，共享协方差则让判别函数里唯一的二次项 $-\frac12 x^\top\Sigma^{-1}x$ 在类与类之间相消——只留下线性项。若只破共享假设（各类协方差不同），二次项残留，模型就退化为 QDA。所以「线性」两个字，正是由「共享协方差」这一假设买来的。</span>

代入高斯密度并取对数后，比较「类 $k$ 与类 $l$ 哪个后验大」，等价于比较线性判别函数

$$\delta_k(x) = x^\top \Sigma^{-1}\mu_k - \frac{1}{2}\mu_k^\top \Sigma^{-1}\mu_k + \log \pi_k$$

的大小。$\delta_k(x)$ 是 $x$ 的**线性函数**——这正是「线性」判别分析的由来。<span class="marginnote">共享协方差 $\Sigma_k=\Sigma$ 使二次项 $-\tfrac12 x^\top\Sigma_k^{-1}x$ 在类间相消，只留下线性项；如果放开共享假设，二次项残留，就变成二次判别分析（QDA），决策边界从超平面变成二次曲面。QDA 更灵活，但要估计的参数更多。</span>

## 2 公式解析：LDA 判别函数

以二分类为例，把「选 $k$ 而非 $l$」的判定写出来：

$$\delta_k(x) - \delta_l(x) = x^\top \Sigma^{-1}(\mu_k - \mu_l) - \frac{1}{2}(\mu_k^\top\Sigma^{-1}\mu_k - \mu_l^\top\Sigma^{-1}\mu_l) + \log\frac{\pi_k}{\pi_l} > 0$$

拆三步：

- **第一步，取对数比**：后验之比 $\frac{\pi_k f_k(x)}{\pi_l f_l(x)} > 1$ 即选 $k$。取 $\log$ 后，先验与类密度分离为 $\log\frac{\pi_k}{\pi_l} + \log\frac{f_k}{f_l}$。
- **第二步，代入高斯**：$\log f_k(x) = -\tfrac12 (x-\mu_k)^\top\Sigma^{-1}(x-\mu_k) + \text{const}$。两类的二次项 $-\tfrac12 x^\top\Sigma^{-1}x$ 完全相同，相消——**共享协方差的假设把二次边界打折成线性边界**。
- **第三步，得线性判定**：剩下的交叉项 $-2 \cdot \tfrac12 x^\top\Sigma^{-1}\mu_k$ 对 $x$ 线性，于是 $\delta_k(x) - \delta_l(x) = 0$ 是 $x$ 空间里的一个超平面，法向量正比于 $\Sigma^{-1}(\mu_k-\mu_l)$。

直觉：把两个高斯中心连成一条线，沿马氏距离（由 $\Sigma^{-1}$ 度量）方向找中点作垂直平分超平面。样本量足够时，这个线性边界接近最优（贝叶斯误差率）。<span class="marginnote">费希尔最初提出 LDA 时的表述是「找一个投影方向，使类间散度与类内散度之比最大」——这等价于上面的贝叶斯视角，只是先投影再分类。投影的好处是直观：把高维数据压到一条线上，类与类分得越开、类内聚得越拢，这条线越好。这种「找判别方向」的思想，后来直接催生了线性判别投影与广义特征值问题。</span>

### 数值算例：一维 LDA 的判别边界

设两类都服从一维高斯、共享方差 $\sigma^2 = 1$，类均值 $\mu_1 = 0$、$\mu_2 = 2$，先验相等 $\pi_1 = \pi_2 = 0.5$。判别函数 $\delta_k(x) = \frac{x\mu_k}{\sigma^2} - \frac{\mu_k^2}{2\sigma^2} + \log\pi_k$。令 $\delta_1 = \delta_2$：$0 = 2x - 2$，解得边界 $x = 1$——**恰在两类均值的正中**。若先验不等（$\pi_1 = 0.8$），边界向小的一类移动：$\log\frac{0.8}{0.2} = 2x - 2$，得 $x = 1 - \frac12\log 4 \approx 0.31$——**先验越大的类，它的判别区域被「撑」得越大**。这个数字变化直观展示：LDA 的边界由「均值差」「共享协方差」「先验比」三件事共同决定，任何一个被误估，边界都会系统性偏移。

生成式与判别式的取舍，也可以收敛成一张对比表：

| 维度 | 生成式（LDA） | 判别式（逻辑回归） |
| --- | --- | --- |
| 建模对象 | $P(x \mid y)$ 与先验 $\pi_k$ | 直接建模 $P(y \mid x)$ |
| 假设 | 各类高斯 + 共享协方差 | 无分布假设（logit 线性） |
| 估计 | 矩估计（闭式解） | 迭代（IRLS / 梯度下降） |
| 小样本 | 强假设省参数，较稳 | 假设少、易过拟合 |
| 假设不符 | 系统性偏差 | 无「假设错误」之说 |
| 副产品 | 能生成样本、处理缺失 | 不能生成 |

**解析｜易错点：** 这张表也澄清一个常见误解——「LDA 不如逻辑回归」并不是结论，而要看假设是否成立。两类严格高斯、协方差确为共享时，LDA 在小样本下方差更低、边界更稳；分布被严重扭曲时，逻辑回归的「无假设」反而是优势。**选生成式还是判别式，本质是「你有多信任分布假设」的选择**——这与选岭回归还是 Lasso 是同一种心智：用先验换方差，还是让数据自己说话。

## 3 感知机：犯错驱动的学习

罗森布拉特的感知机是分类史上第一个「学习算法」。模型把特征线性组合后经过一个**符号激活**：$f(x) = \mathrm{sign}(\beta_0 + \beta^\top x)$，输出 $\pm 1$。<span class="marginnote">感知机是最简单的人工神经元：输入加权求和、过阈值、输出 0/1。它启发了 1980 年代的多层感知机与今天的大模型，但单层感知机只能分割线性可分的数据——马尔文·明斯基 1969 年据此批评它连 XOR 都做不了，一度浇灭了神经网络研究，史称「AI 之冬」的引子。</span>

训练目标是使**误分类样本**驱动更新：每次看到一个分类错误的样本 $(\beta_0 + \beta^\top x_i) y_i \le 0$，就沿梯度方向修正：

$$\beta \leftarrow \beta + y_i x_i, \qquad \beta_0 \leftarrow \beta_0 + y_i$$

若 $y_i=+1$ 被判成 $-1$（$\beta^\top x_i$ 太小），就加上 $x_i$ 增大分数；反之减去。**每次只改一个样本**，直到所有样本都被正确分类。<span class="marginnote">这个更新规则可以看作「随机梯度下降」的雏形：对误分类样本，损失取 $\max(0, -y_i(\beta_0+\beta^\top x_i))$，其梯度恰好是 $-y_i x_i$——所以「加 $y_i x_i$」正是沿损失下降方向走一步。感知机是最早把「错误驱动的在线学习」形式化的算法，SGD 家族的谱系由此展开。</span>

### 数值算例：一次误分类更新

设两个样本 $x_1 = (1,1)$、$y_1 = +1$ 与 $x_2 = (0,-1)$、$y_2 = -1$，取初值 $\beta = (1,0)$、$\beta_0 = 0$。检查 $x_1$：分数 $\beta_0 + \beta^\top x_1 = 1 > 0$，判对。再检查 $x_2$：分数 $0 + 1\times 0 + 0\times(-1) = 0$，而 $y_2(\beta_0 + \beta^\top x_2) = 0 \le 0$——**误分类**。按更新规则：

$$\beta \leftarrow \beta + y_2 x_2 = (1,0) + (-1)\cdot(0,-1) = (1,1), \qquad \beta_0 \leftarrow 0 + (-1) = -1$$

重新检查：$x_1$ 分数 $-1 + 1 + 1 = 1$，判对；$x_2$ 分数 $-1 + 0 - 1 = -2$，$y_2\cdot(-2) = 2 > 0$，判对。**一次更新后两个样本全部正确分类**——但注意只是「判对了」：换一个初始 $\beta$，算法会停在另一条同样能分割数据的直线上。这正是「感知机解不唯一」的最直观证据，也是它不追求最大间隔的根本原因。

**Novikoff 收敛定理**：若训练集**线性可分**，存在间隔 $\gamma > 0$，则感知机算法在有限步内收敛，且误分类次数有上界 $\propto \frac{R^2}{\gamma^2}$，其中 $R$ 是样本最大模长。<span class="marginnote">这个定理揭示了一个关键矛盾：间隔 $\gamma$ 越大，收敛越快；但算法本身并不「追求」大间隔——任何可行解都可能被找到。这正是后人加「间隔最大化」约束、发明支持向量机的动机。</span>

定理中的 $\frac{R^2}{\gamma^2}$ 值得琢磨：**分子 $R$ 越大（数据越分散）、分母 $\gamma$ 越小（可分得越勉强），收敛越慢**。若间隔 $\gamma$ 接近 0——数据勉强可分——上界爆炸，算法可能要极多轮才停下；若数据本就线性不可分，上界失效，算法永远停不下来。这个「越难分越慢」的定量描述，是理解「为什么线性不可分时必须换模型」的第一块砖。

**解析｜易错点：** 感知机**不收敛于唯一的解**——线性可分时解不唯一，算法停在哪取决于样本顺序。更糟的是线性不可分时它**永远不收敛**，只会无限震荡。这两个缺陷让后人同时走向两条路：一是允许犯错并把间隔做大的软间隔 SVM；二是把输入升维、用核技巧变成非线性（见《核方法与 SVM》）。

## 4 三种分类器放在一张表里

| 方法 | 路线 | 核心假设 | 边界 | 训练算法 |
| --- | --- | --- | --- | --- |
| 逻辑回归 | 判别式 | 无（直接建模 $P(y\|x)$） | 超平面 | IRLS / 梯度下降 |
| LDA | 生成式 | 各类高斯 + 共享协方差 | 超平面（QDA 为二次） | 矩估计（闭式） |
| 感知机 | 判别式 | 线性可分 | 超平面（任一条） | 误分类驱动更新 |

LDA 胜在**样本量小、分布假设可信**时稳定高效（闭式解、无需迭代）；逻辑回归对分布假设更宽松，通常在真实数据上更稳；感知机的意义更多是历史与概念上的——它是 SVM 与神经网络共同的前身。<span class="marginnote">ESL §4.3 对比发现：两类协方差相同、且各类严格高斯时，LDA 与逻辑回归的估计其实会收敛到同一条边界；差别在「假设是否成立」时显现——这也提醒我们，选模型=选假设，没有免费午餐。</span><span class="marginnote">这条对比给出一条实用经验法则：样本小、且你有理由相信数据近似高斯 → LDA 更稳；样本够大、不知道分布长什么样 → 逻辑回归几乎总是更安全的选择。两类方法在「线性分类」这个目标上殊途同归，正说明「线性可分」本身才是分类器的第一性条件。</span>

## 6 小结

- **贝叶斯决策**：最优分类 = 取后验概率最大的类，生成式模型先建模类密度 $f_k(x)$ 再反推后验。
- **LDA**：各类高斯 + 共享协方差 ⇒ 判别函数 $\delta_k(x)$ 对 $x$ 线性；放开共享协方差得 QDA（二次边界）。
- **感知机**：$\mathrm{sign}(\beta_0+\beta^\top x)$ + 误分类驱动更新；线性可分时收敛（Novikoff），线性不可分时永不收敛。
- **对比**：LDA 是生成式的典型（强假设、闭式解），逻辑回归是判别式的典型（弱假设、迭代解），感知机则是「间隔」思想的源头。
- **承上启下**：感知机的「间隔」缺陷 → 最大间隔的 SVM；单层神经元 → 多层神经网络。
