# 前馈网络的编码

<div class="epigraph">

## 为什么前馈网络是感觉编码的起点

上一节在状态空间里看了整群神经元。但感觉系统有一条极简又极强大的架构：**信息沿层级向前流**——视网膜 → 外侧膝状体（LGN）→ 初级视皮层（V1）→ 更高级皮层，几乎没有往回走的连接。这种**前馈（feedforward）**结构是感觉编码的第一近似，也是人工神经网络（多层感知机、CNN）的直接生物学灵感。<span class="marginnote">严格说，视通路有大量反馈连接（V1 到 LGN 的连接数是正向往回的两倍）。但「前馈层级」仍是第一步近似，而且它解释了惊人的多的现象。建模的智慧在于：先抓住主干的骨架，再补细节。</span>这一节回答：**一层前馈网络如何把原始刺激重新编码成对下游有用的表示？**

## 1 线性-非线性（LN）模型：单个前馈神经元的输入输出

感觉神经元对刺激的响应，最成功的入门模型是 **LN 模型（linear-nonlinear model）**：先对刺激做线性滤波（加权求和），再过非线性：

$$
r = f\big(\mathbf{k} \cdot \mathbf{s} + b\big)
$$

$\mathbf{s}$ 是刺激向量（如一幅图像的像素、一段声音的声谱），$\mathbf{k}$ 是神经元的**感受野/调谐向量**（加权模板），$b$ 是偏置，$f$ 是非线性（如整流、饱和、阈值）。<span class="marginnote">LN 模型既简单又能拟合大量数据：对每个神经元，用白噪声刺激 + 回归（spike-triggered average）就能估计出 $\mathbf{k}$，再用发放入口函数估计 $f$。这是「系统识别」方法的范式：不假设具体机制，直接测输入-输出映射。</span>

LN 模型的成功告诉我们：**感觉神经元的输入输出在很大程度上是「先线性滤波、再非线性压缩」**。一个 V1 简单细胞 = 一个带方向的 Gabor 滤波器 + 一个阈值非线性；一个视网膜神经节细胞 = 一个中心-外周拮抗滤波器 + 饱和非线性。<span class="marginnote">注意这条桥：LN 模型 = 线性滤波 + 点非线性，这正是人工神经元「权重求和 + 激活函数」的模板。前馈 ANN 几乎就是 LN 模型的堆叠——只是把每层学到的 $\mathbf{k}$ 从「手调/白噪声回归」换成了「反向传播」。</span>

## 2 群体编码：重叠感受野的几何

单个神经元的信息量有限（调谐曲线、噪声），但**一群神经元**合起来可以精确编码。**群体编码（population coding）**的关键是**感受野重叠**：相邻神经元偏好相近但不相同的刺激，整群的发放模式构成一个「指纹」。

如果第 $i$ 个神经元的调谐是高斯（中心 $s_i$，宽度 $\sigma$），刺激 $s$ 产生的发放率为：

$$
r_i(s) = r_\mathrm{max} \exp\left[-\frac{(s - s_i)^2}{2\sigma^2}\right]
$$

整群神经元的发放模式是「刺激 $s$ 的位置」的唯一编码——**位置体现在「哪些神经元活跃、活跃多少」的分布里**。<span class="marginnote">这是「种群向量解码」（上一节）成立的前提：发放率沿偏好轴形成一座「活动的山」，山的中心就是刺激估计。感受野越密（神经元越多）、调谐越窄，估计越准——但噪声也在涨，存在一个最优宽度（Fisher 信息论会精确化这一点，见神经信息论一篇）。</span>

群体编码的三个性质值得记住：

- **鲁棒性**：单个神经元死掉，群体编码仍能继续（冗余）。
- **精度超单神经元**：调谐宽度远大于相邻偏好间距时，群体仍能超高精度编码（插值）。
- **自然且连续**：刺激空间（朝向、位置、颜色）连续，群体编码自然地表示连续量。

## 3 从视网膜到 V1：分层前馈的特征层级

前馈层级的经典实证是视觉系统。每层把输入**重新编码**，提取更高层的特征：

| 层级 | 神经元类型 | 感受野性质 |
| --- | --- | --- |
| 视网膜 | 神经节细胞 | 中心-外周拮抗（ON/OFF 同心圆） |
| LGN | 中继细胞 | 与视网膜类似，增加对比度增益 |
| V1 简单细胞 | 朝向选择性 | 条形 Gabor（空间频率+朝向） |
| V1 复杂细胞 | 位置不变性 | 对条的位置轻度平移不变 |
| V2/V4/IT | 复杂特征 | 轮廓、纹理、面孔等 |

Hubel 与 Wiesel 的层级假说：**简单细胞 = 若干 LGN 中心-外周感受野的线性组合**，复杂细胞 = 若干简单细胞响应的非线性聚合（如取最大值）。<span class="marginnote">这个「简单 → 复杂 → 更复杂」的构造，本质是把低级特征的<strong>组合</strong>变成高级特征。CNN 的卷积层 + 池化层几乎逐条复现了这个设计：卷积 = 简单细胞的线性滤波，池化 = 复杂细胞的不变性聚合。80 年的生物学探索，最后在深度学习里给出了工程版本。</span>

**辨析｜易错点：** 层级前馈不是「每层逐像素处理」。每一层是**并行**的：V1 的几亿神经元同时处理整个视野，靠的是感受野重叠与大规模并行，而不是串行扫描。「前馈」指的是**信号流方向**，不是**串行处理**——这是两个常被混淆的概念。

## 4 公式解析：除性归一化——群体的增益控制

前馈编码不能只是「线性+非线性」：真实视觉系统还有**增益控制**——刺激越强，神经元的响应越受**整个群体的活动**抑制，防止饱和。这就是**除性归一化（divisive normalization）**，可视为生物学版的 softmax：

$$
r_i = \frac{R_i}{C + \sum_j R_j}, \qquad R_i = f(\mathbf{k}_i \cdot \mathbf{s})
$$

其中 $R_i$ 是第 $i$ 个神经元的原始响应（LN 输出），$C$ 是半饱和常数，分母是全体神经元的响应之和。

三步拆解它的作用：

- **第一步，分子是「我的原始响应」**：刺激落在我的感受野里时 $R_i$ 大。
- **第二步，分母是「大家的原始响应之和」**：刺激越强、覆盖的神经元越多，分母越大。
- **第三步，除法实现对比度不变性**：把刺激整体变亮（所有 $R_j$ 同比例上升），分子分母同比例放大，$r_i$ 基本不变——网络对**亮度**不敏感、对**相对对比**敏感。

**辨析｜易错点：** 归一化的分母包含**全体神经元**（或一个局部池），所以它引入了**群体层面的相互作用**——单个神经元的输出不再是独立于其他神经元的。这打破了「神经元独立」的简化假设，也让解码变得复杂（神经元之间有相关性）。但正是这种群体相互作用，实现了亮度不变性、对比度增益控制等单神经元做不到的性质。<span class="marginnote">除性归一化被大量实证支持：V1 的对比度增益、V4/MT 的刺激竞争、皮层多单元响应，都能用这个框架解释。有趣的是，它还连接着深度学习的 attention 与 softmax——「竞争性归一化」的思想在两个领域独立长成参天大树。</span>

## 5 前馈编码的边界与补充

前馈层级解释了很多，但必须承认它的局限：

- **无时间**：经典前馈模型是静态的（输入与输出同时刻），而真实感觉处理有精确的时间结构（V1 在刺激后约 50 ms 响应，IT 在约 100 ms）。时间本身是编码的一部分。
- **无反馈**：真实系统反馈连接密布，前馈是「第一次通过」（first pass）的近似。反馈参与注意、预测、上下文调制。
- **无学习**：前馈权重不是固定模板，而是随经验被 Hebbian/STDP 与任务信号持续塑造。

这些「缺失」正是后面几篇的主角：时间与预测属于循环网络；任务调制属于决策与强化学习。前馈层级是骨架，骨架之上还有很多层「肉」。

## 6 稀疏化：让前馈编码更高效

前馈层级要表示的信息很多（整个视野的特征），但神经资源与能量有限。**稀疏编码（sparse coding）**的思想：每次只用**少部分神经元**活跃（其余近乎静默），用「少数强响应」而非「全部弱响应」来表示输入。

稀疏编码的三个收益：

- **能量**：只有活跃神经元耗能——神经活动的能量账单大降。
- **容量**：$N$ 个神经元里 $k$ 个活跃的稀疏模式有 $\binom{N}{k}$ 种组合，比 $N$ 个全量模式多得多——**稀疏提升表示容量**。
- **可解释性**：少数强特征比稠密混合更接近「语义成分」（边缘、朝向、部件）。

**辨析｜易错点：** 稀疏 ≠ 弱活动。稀疏编码是「**少数神经元强发放、多数近零**」，不是「所有神经元都发一点」的均匀弱活动。两者的信息论性质完全不同：稀疏模式在统计上更「可分离」，也更接近真实皮层的发放统计。<span class="marginnote">自然图像稀疏编码的经典结果：在「用一组 Gabor 基函数稀疏重建图像」的约束下，学出的基函数与 V1 简单细胞的感受野惊人相似（Olshausen & Field, 1996）——「稀疏性」这一条原则，就能从自然图像统计里推出现实皮层的感受野结构。这是「高效编码假说」最漂亮的一次胜利。</span>

**一个反直觉的补充**：前馈层级越深，神经元的「偏爱」越复杂，但响应也越慢——IT 神经元比 V1 晚约 50–100 ms 响应。所以「前馈」不是「瞬间」：深度是有时间代价的，而大脑愿意付这个代价，因为它换来的是更抽象的表示。

**感受野不是天生的，而是被经验塑造的**。关键期实验（Hubel-Wiesel 的猫）：出生后缝合一只眼，那只眼对应的 V1 柱就萎缩，另一只眼垄断皮层。这证明前馈权重是「经验依赖的」——前馈编码的「模板」是 Hebbian 学习与关键期塑形共同刻出来的。这也是前馈编码与突触可塑性、循环网络相连的接口：**前馈结构决定「第一遍怎么算」，可塑性决定「这个结构怎么被经验改写」**。

**一句话点题**：前馈网络是感觉编码的「第一遍扫描」——快、层级化、可塑；但它既没有时间、也没有反馈、更没有学习闭环。记住这三个「没有」，你就知道为什么大脑的完整计算必须在接下来的循环网络与可塑性里补全。

## 7 小结

- **LN 模型**：$r = f(\mathbf{k}\cdot\mathbf{s} + b)$——线性滤波 + 非线性压缩，是感觉神经元输入输出的第一近似，也是人工神经元的模板。
- **群体编码**：重叠调谐曲线让整群神经元的发放模式唯一编码刺激，鲁棒且超精度。
- **视觉层级**：视网膜 → LGN → V1 → 高级皮层逐步提取更抽象特征，Hubel-Wiesel 假说与 CNN 逐条对应。
- **除性归一化**：$r_i = R_i/(C + \sum_j R_j)$ 实现亮度不变性与对比度增益，是群体相互作用的关键机制。
- 前馈是**无时间、无反馈、无学习**的第一近似，缺的由后面几篇补齐。
