# 整合发放（IF）模型

<div class="epigraph">
<p>神经元把它的输入整合起来，直到越过一个阈值，然后发放——这是神经计算的基本动作。</p>

## 为什么需要整合发放模型

上一篇的 Hodgkin-Huxley 模型能重现动作电位的每一个细节，但它有 4 个状态变量、几十个参数，仿真一个神经元已经很贵，仿真一个皮层微环路（约 1 万个神经元）就昂贵得难以承受。而神经科学家真正关心的，很多时候不是「脉冲长什么样」，而是「**脉冲什么时候发**」——发放的时机、频率、模式。整合发放（integrate-and-fire, IF）模型正是为此而生：**把「整合」保留、把「发放」压缩成一个事件**。它是理论神经科学的「简谐振子」——简单到可以解析求解，又真实到能复现神经元对输入的许多核心响应。读懂 IF 模型，你就拿到了理解神经编码、神经网络动力学的第一把钥匙。

## 1 从 HH 到 IF：去掉波形，留下事件

HH 模型里动作电位由 $\ce{Na+}$、$\ce{K+}$ 电流产生；IF 模型做一个暴力的抽象：**动作电位的形状不重要，重要的是「发不发」**。<span class="marginnote">这个抽象和数字电路里的想法一致：模拟波形会被压缩成「上升沿」，后续电路只关心沿的时刻。IF 模型的输出就是一串沿——一个时间戳序列。后面讲「神经元的编码与解码」时，编码对象正是这串时间戳。</span>

IF 模型只保留两个状态：

1. **膜电位 $V(t)$** 的次阈值动力学——由漏电与输入电流决定；
2. **一个阈值 $V_\mathrm{th}$** 与 **一个重置规则**——$V$ 到达阈值就输出一个「尖峰」事件，然后 $V$ 被重置到 $V_\mathrm{reset}$（并经历不应期）。

最简单的版本是**漏电整合发放模型（leaky integrate-and-fire, LIF）**：

$$
\tau_m \frac{dV}{dt} = - (V - V_\mathrm{rest}) + R_m I(t)
$$

$V_\mathrm{rest}$ 是静息电位（约 $-70\ \mathrm{mV}$），$R_m$ 是膜电阻，$\tau_m = R_m C_m$ 是**膜时间常数**（约 10–20 ms）。左边是电容充电速率，右边第一项是「漏电」——膜电位向静息值指数回落的趋势，第二项是注入电流。<span class="marginnote">注意「漏电」项 $-(V - V_\mathrm{rest})$：它让 $V$ 总是被拉回静息。没有它，IF 模型就成了「完美积分器」——每次输入都被永久累积，响应线性增长。真实神经元的膜本来就会漏电，这个「漏」字至关重要。</span>

当 $V$ 到达 $V_\mathrm{th}$（约 $-55\ \mathrm{mV}$）：

- 记录一次发放事件（时刻 $t^\mathrm{spike}$）；
- $V \leftarrow V_\mathrm{reset}$（约 $-65\ \mathrm{mV}$）；
- 在绝对不应期 $t_\mathrm{ref}$（约 1–2 ms）内保持不响应。

## 2 输入与响应：从电流到发放率

IF 模型最有价值的产出，是**神经元输入-输出关系（F-I 曲线）**：给定恒定电流 $I$，稳态发放率 $r$ 是多少？

**无泄漏时（完美积分器）**：$dV/dt = I/C$，$V$ 线性上升，到阈值的时间正比于 $1/I$，发放率 $r \propto I$——线性关系。

**有泄漏时（LIF）**：膜电位向平衡点 $V_\infty = V_\mathrm{rest} + R_m I$ 指数趋近。如果 $V_\infty < V_\mathrm{th}$（电流太弱），永远发不出；只有电流强到让平衡点越过阈值才开始发放。这个临界电流是：

$$
I_\mathrm{th} = \frac{V_\mathrm{th} - V_\mathrm{rest}}{R_m}
$$

LIF 的 F-I 曲线是**非线性**的：低于 $I_\mathrm{th}$ 发不出，刚过阈值时发放率从 0 跳起，然后随电流增大渐近地变稀疏。<span class="marginnote">这条「阈值以上非线性上升」的曲线，是对真实神经元 F-I 曲线的合理近似。真实神经元（如皮层锥体细胞）的 F-I 曲线在阈值附近往往更陡甚至不连续，而有些神经元（如中间神经元）则近似线性。LIF 是它们共同的第一近似。</span>

稳态发放率公式（含不应期 $t_\mathrm{ref}$）：

$$
r(I) = \frac{1}{t_\mathrm{ref} + \tau_m \ln \frac{V_\infty - V_\mathrm{reset}}{V_\infty - V_\mathrm{th}}}
$$

**辨析｜易错点：** 分子分母不要写反。从 $V_\mathrm{reset}$ 升到 $V_\mathrm{th}$ 需要的时间是对数项，所以 $\ln$ 里是「到平衡点的距离之比」——$(V_\infty - V_\mathrm{reset})$ 在分子、$(V_\infty - V_\mathrm{th})$ 在分母。两个距离都是正的（因为 $V_\infty > V_\mathrm{th} > V_\mathrm{reset}$）。写反了 log 变负，发放率变负，逻辑立即崩。

## 3 公式解析：LIF 的 F-I 曲线

**为什么会有对数？** 拆解发放率公式，看「到阈值的时间」从哪来：

$$
t_\mathrm{up} = \tau_m \ln \frac{V_\infty - V_\mathrm{reset}}{V_\infty - V_\mathrm{th}}
$$

- **第一步，解膜电位方程**：恒定电流下，$V(t) = V_\infty + (V_\mathrm{reset} - V_\infty)e^{-t/\tau_m}$。它从 $V_\mathrm{reset}$ 出发，指数逼近 $V_\infty$，永远「够不到」但可以无限接近。
- **第二步，解出到阈值的时间**：令 $V(t) = V_\mathrm{th}$，得到 $e^{-t/\tau_m} = (V_\infty - V_\mathrm{th})/(V_\infty - V_\mathrm{reset})$，两边取负对数就得上式。
- **第三步，对数项的行为**：当 $V_\infty$ 远高于 $V_\mathrm{th}$ 时，比值接近 1，$\ln$ 接近 0，$t_\mathrm{up}$ 很小，发放率由不应期主导（上限 $1/t_\mathrm{ref}$）；当 $V_\infty$ 只比 $V_\mathrm{th}$ 高一点，比值很大，$\ln$ 发散，发放率趋于 0。这个「越靠近阈值越慢」的奇点，正是神经元对弱输入反应极慢、对强输入反应极快的定量描述。

## 4 IF 模型家族：从漏电到多维

LIF 只是最基础的成员，IF 家族各有分工：

| 模型 | 关键差异 | 补足的能力 |
| --- | --- | --- |
| 完美积分器（IF） | 无漏电，$V$ 线性积分 | 解析最简，历史最早 |
| LIF | 加漏电项，向 $V_\mathrm{rest}$ 回落 | 逼近真实膜动力学 |
| 指数 IF（EIF） | 阈值附近加指数非线性 | 复现动作电位上升沿的临界特性 |
| LIF + 适应电流 | 加 AHP 电流 $w$，随发放累积 | 复现 spike-frequency adaptation |
| Izhikevich 模型 | 双变量、$v, u$ 耦合 | 以 2 变量复现 20 余种发放模式 |

其中 **Izhikevich 模型**值得一提：它用两个状态变量就能复现规则发放、爆发发放、棘波适应等丰富模式，计算成本仅比 LIF 高一点，是「便宜且丰富」的折中选择。<span class="marginnote">真实神经元有几十种离子通道，但很多通道在「编码与网络」的问题上只是冗余细节。Izhikevich 的工作展示了一个方法论：用最少的变量抓住目标现象，多余的复杂度留给特定问题。这与深度学习中「用最小模型解释数据」的 Occam 精神一脉相承。</span>

**辨析｜易错点：** IF 模型把动作电位「压缩成事件」，代价是无法解释动作电位本身——它假设你已接受 HH 那套机制。所以在 IF 里问「动作电位为什么是这个形状」是没有答案的；它的职责是**在发放时刻这个精度上**模拟神经元。每个模型都有自己的「责任精度」，用错了精度就会得出荒谬结论。

## 5 为什么 IF 模型是网络的基石

IF 模型最大的价值在**规模**。一个 LIF 神经元每步只需几次浮点运算，一万个神经元构成的小网络可以在普通笔记本上实时仿真。这让研究者可以：

研究**发放率的编码**：给定输入分布，网络发放率的统计性质；
研究**同步与振荡**：神经元群体的集体发放模式；
研究**时间编码**：脉冲串的精确时序如何携带信息。

经典结果：**带漏电的 IF 神经元是一个「非线性低通滤波器」**——它对瞬态输入（如突然的脉冲）响应快，对持续输入（缓慢变化的电流）响应平稳；而网络的集体动力学可以产生复杂得多的行为。<span class="marginnote">把这与后面的内容连线：循环网络的「吸引子」、工作记忆的「持续活动」，底层载体常是 IF 神经元。IF 模型是连接「单神经元机制」与「网络功能」的枢纽——这正是 Dayan & Abbott 把 Model Neurons 放在全书第四章、网络模型放在第六章的用意。</span>

## 6 噪声驱动的发放：IF 的概率面孔

真实神经元总被噪声输入包围（突触噪声、通道噪声）。把噪声加进 LIF——输入变成 $I(t) + \xi(t)$——模型立刻从「确定性积分器」变成**概率发放器**：即使平均输入低于阈值，噪声的峰值也可能把 $V$ 推过阈值，产生「自发发放」。

这个行为的定量描述是**逃逸率（escape rate）**：单位时间内越过阈值的概率，随膜电位与阈值的距离指数变化：

$$
\nu(V) \propto \exp\!\left(-\frac{(V_\mathrm{th} - V)^2}{2\sigma^2}\right)
$$

- **$V$ 远低于阈值**：逃逸率指数压低，几乎不发——「静默」。
- **$V$ 接近阈值**：逃逸率骤升——「可能发、可能不发」的随机窗。
- **噪声强度 $\sigma$ 是关键**：$\sigma$ 太小，神经元退化成确定性阈值；$\sigma$ 太大，自发发放淹没信号。

**辨析｜易错点：** 「噪声是有害的」是直觉，但**次阈值输入 + 噪声可以让弱信号更可被检测**——这叫**随机共振（stochastic resonance）**：一定的噪声恰好把弱信号「抬」到阈值附近，反而提高了检测灵敏度。生物感觉系统（触觉、听觉）有证据支持。**噪声在神经计算里既是误差源、也是机制**——这正是神经信息论要定量处理的对象。<span class="marginnote">逃逸率框架也解释了「噪声输入让神经元有自发发放率」：皮层神经元在无外部刺激时仍以 1–10 Hz 自发发放——这不是故障，而是「待机状态」，让神经元随时能被弱输入驱动。这个背景发放率是后面一切「群体统计」的基线。</span>

## 7 小结

- IF 模型把 HH 的动作电位**压缩为事件**：只保留次阈值积分、阈值判决与重置。
- LIF 方程 $\tau_m\,dV/dt = -(V - V_\mathrm{rest}) + R_m I$：漏电项让 $V$ 向静息回落，时间常数 $\tau_m = R_m C_m$ 约 10–20 ms。
- 有电流阈值 $I_\mathrm{th} = (V_\mathrm{th} - V_\mathrm{rest})/R_m$，低于它不发、高于它发放率非线性上升。
- F-I 曲线含对数奇点：越逼近阈值发放率越低，强输入下由不应期限制。
- IF 家族（完美积分器、LIF、EIF、适应 LIF、Izhikevich）以复杂度换取不同的真实感。
- IF 是**网络仿真**的主力单元，是连接单神经元机制与集体动力学的枢纽。
