## 为什么从基准开始

算法说一千道一万，最终要在统一的数据集上分出高下。离线强化学习长期没有像 ImageNet 之于视觉、GLUE 之于 NLP 那样的标准考场——各家用各自收集的数据自说自话。2020 年 Fu 等人的 **D4RL**（Datasets for Deep Data-Driven Reinforcement Learning）结束了这种混乱，为离线算法提供了统一的数据集、统一的质量层级与统一的分数口径。DT 论文的主实验结果就建立在 D4RL 之上。这篇讲清：D4RL 是什么、分数怎么归一化、DT 考了多少分、以及读这些分数时要避开哪些坑。

## 1 D4RL：离线 RL 的标准考场

D4RL 由 Berkeley 团队（Fu, Kumar, Nachum, Tucker, Levine）于 2020 年发布，覆盖多个域，每个域自带「已成定局的离线数据」，训练中不许再与模拟环境交互。<span class="marginnote">「不许交互」是离线 RL 的硬约束：算法只能从固定数据集学习，然后一次性部署评估。这逼着研究者直面分布偏移、覆盖度不足等真问题，而不是靠试错刷分数。</span>DT 论文主打的两个域：

**MuJoCo 运动控制**：halfcheetah（猎豹）、hopper（跳跃）、walker2d（行走）——状态是低维关节向量，动作是连续力矩，是离线 RL 的「标准班课」；
- **Atari 2600**：56 个游戏，状态是像素画面（用卷积编码器），动作是离散的，检验 DT 在视觉、高维输入下的表现。

D4RL 的意义不只是「提供数据」：它把「什么数据质量、多少覆盖度」都显式化了，让不同算法在**同一批数据**上比较，才使「DT 是否达到离线 SOTA」这个问题有了可判定的答案。

先认识一下 MuJoCo 的这三个「标准班课」的具体形态：halfcheetah 的状态是 17 维（躯干位姿、关节角与速度）、动作是 3 维（关节力矩）；hopper 与 walker2d 类似但维度略有不同。都是低维连续控制——状态、动作都是小向量，这让 DT 的嵌入层可以保持极简（线性层即可），也把「序列建模 vs Q-learning」的对比隔离在纯粹的算法层面，不被视觉输入的工程复杂度干扰。

## 2 数据集质量层级

以 MuJoCo 为例，每个环境都提供一组不同质量的版本，这是 D4RL 最巧妙的设定之一：

| 数据集 | 数据从哪来 | 特点 |
| --- | --- | --- |
| random | 随机策略采样 | 覆盖广但几乎无好行为 |
| medium | 训练到中等水平的策略 | 有部分好行为，大量平庸数据 |
| medium-replay | 同一策略训练过程中的**回放缓冲** | 混合了早期低质量与后期较好数据，覆盖不均 |
| medium-expert | medium 与 expert 数据**各半混合** | 高回报轨迹与中等轨迹并存，最考验「挑选」能力 |
| expert | 专家（近最优）策略采样 | 行为质量高、多样性低 |

**重点：medium-expert 是理解 DT 的核心考场。** 它里面既有平庸轨迹又有专家轨迹，恰好检验一个离线算法能不能「从混合数据里挑出好行为」——这正是 return-to-go 条件被设计出来干的事。<span class="marginnote">如果数据全是 expert，行为克隆已经很强，算法没有发挥空间；如果全是 random，谁都学不出好策略。medium-expert 的「一半好一半坏」才把算法之间的差距拉大。这也是为什么论文的对照表里 medium-expert 一栏最有戏剧性。</span>

数据质量层级的另一个维度是**覆盖度**（coverage）：expert 数据覆盖窄（只有专家走过的状态）、random 覆盖广（哪里都去过但都不好）、medium-replay 覆盖最「真实」（训练过程中的全部足迹）。覆盖度决定了离线算法「能把模型推多远」：覆盖越广，DT 的条件分布越丰满、插值越可靠；覆盖越窄，DT 越容易在未见状态上失灵。读 D4RL 结果时，把「质量」和「覆盖」两个轴都放在心里，很多表面的「算法强弱」其实是数据性质的差异。

## 3 归一化分数：随机 0 分、专家 100 分

不同环境回报的量级天差地别（halfcheetah 的回报上千，Atari 的回报上万），直接比较原始回报毫无意义。D4RL 用**归一化分数**把一切都压到同一把尺子上：

$$
\text{normalized score} = 100 \times \frac{J_{\pi} - J_{\text{random}}}{J_{\text{expert}} - J_{\text{random}}}
$$

其中 $J_{\pi}$ 是待评估策略的平均回报，$J_{\text{random}}$ 与 $J_{\text{expert}}$ 分别是随机策略与专家策略的平均回报。于是：随机策略恒为 0，专家策略恒为 100，分数越高越好，**超过 100 意味着超越了采数据集时的专家策略**。

## 4 公式解析：归一化分数

- **第一步，认分子**：$J_\pi - J_{\text{random}}$ 度量「待评估策略比瞎走好多少」——这是策略的真实增量。
- **第二步，认分母**：$J_{\text{expert}} - J_{\text{random}}$ 度量「专家比瞎走好多少」——这是该任务在随机基线上的「可行空间」。
- **第三步，认比例**：两者相除再乘 100，得到「策略填补了可行空间的百分之多少」。0 表示没比随机好，100 表示达到专家水平。
- **第四步，认超过 100 的情形**：归一化分数超过 100 完全正常。在 medium-expert 数据里，混合出的轨迹组合有时比纯专家采样表现更好（比如把两个专家行为的关键片段拼接起来），于是「数据里的最优」可以高于「专家策略的平均」——DT 在 hopper 与 walker2d 的 medium-expert 上都拿到了超过 100 的分数（107.6 与 108.1，见论文表 1）。<span class="marginnote">这也顺便说明：medium-expert 数据里「更好的轨迹」是真实存在的，问题只在于算法能不能把它们找出来。DT 靠 return-to-go 条件「挑选高回报轨迹」，在这类数据上特别占便宜。</span>

**辨析｜易错点：** 归一化分数的分母因数据集而异，所以**不同任务间的分数不可直接相加或平均**——一个「80」的 halfcheetah 和一个「80」的 hopper 并没有可比性。论文里给出的都是**多次随机种子评估的均值 ± 标准差**，读表时先看方差，再看均值。

两个锚点（0 与 100）还有一个用途：它们让你立刻判断一个结果「值不值得看」。分数在 40–60 区间的算法，意味着它只比随机好一半——通常属于「数据集本身弱，或算法没挑出好行为」；分数 90 以上，意味着基本追平甚至超越专家。**把 0 与 100 当作心理标尺，读任何离线 RL 表格的速度都会快一倍。** 至于「超过 100」到底多稀奇，取决于数据里是否真的有超专家轨迹——这正是 D4RL 故意埋进 medium-expert 里的彩蛋。

## 5 DT 在 D4RL 上的表现

论文的核心实验结论可以压缩成三句话（完整表格见论文 Table 1）：

**在 medium-expert 数据上，DT 一骑绝尘。** 例如 halfcheetah-medium-expert 上 DT 取得 **86.8 ± 1.3**，明显超过该表中所列的行为克隆与若干约束型离线 RL 基线。hopper、walker2d 的 medium-expert 更是超过 100。<span class="marginnote">论文报告里的基线数值在不同论文之间存在再评估差异（例如同一 CQL 在原始论文与后续复现里可能报出不同分数），读对照表时要认准「同一张表内的比较」，跨论文拼数字很容易出错。</span>

**在 medium 与 medium-replay 数据上，DT 大幅超过行为克隆**，与 CQL 一类强离线算法互有胜负、大体相当——这证明「无动态规划的监督学习」也能与精心设计的保守值函数方法正面竞争。

**在 expert 数据上，DT 与行为克隆基本持平**——这符合预期：expert 数据里几乎都是好行为，条件没有用武之地，大家都是在「背」一份高质量行为分布。

把论文表 1 里 MuJoCo 三个环境的九个数据集分档列出（DT 列，均值 ± 标准差）：

| 数据集 | DT 分数 |
| --- | --- |
| halfcheetah-medium-v2 | 42.6 ± 0.1 |
| hopper-medium-v2 | 67.6 ± 1.0 |
| walker2d-medium-v2 | 74.0 ± 1.4 |
| halfcheetah-medium-replay-v2 | 36.6 ± 0.4 |
| hopper-medium-replay-v2 | 82.7 ± 7.0 |
| walker2d-medium-replay-v2 | 66.6 ± 3.0 |
| halfcheetah-medium-expert-v2 | 86.8 ± 1.3 |
| hopper-medium-expert-v2 | 107.6 ± 1.8 |
| walker2d-medium-expert-v2 | 108.1 ± 0.2 |

三行观察：其一，**medium-expert 三档全部最高或接近最高**，因为这类数据「好轨迹明摆着存在，只差挑选」；其二，**hopper 与 walker2d 的 medium-expert 超过 100**，因为混合数据里存在比纯专家采样更好的轨迹组合；其三，**medium-replay 的方差明显偏大**（hopper 达 ±7.0），说明数据覆盖不均时条件建模的稳定性开始承压。<span class="marginnote">这些数字在不同论文的再评估里可能有细微出入（例如某些复现把 CQL 在 halfcheetah-medium-expert 上报到 90 以上），但 DT 自己的分数是论文原表、反复被引用的稳定值。读表时把注意力放在「相对格局」而不是「绝对一位小数」上。</span>

在 **Atari** 上，论文的结论同样耐人寻味：DT 的表现与行为克隆大体相当，并未显著超越。原因有三：Atari 数据集本身行为克隆已很强；像素输入下的回报条件帮助有限；更重要的是 **Atari 的随机性让 return-to-go 条件变得不精确**——这正是我们在第 3 篇预告过的「条件边界」在实验里的第一次现身。

## 6 评估的细节与坑

读 D4RL 结果、或自己复现 DT 时，有几个实操细节必须知道：

- **目标回报怎么选**：MuJoCo 评估时通常以数据集的**最大轨迹回报**（或按环境设定的比例）作为目标 $g$；条件太高（超出数据范围）会崩坏，条件太低则退化为平庸行为。<span class="marginnote">Atari 里论文把回报按常数归一化（如除以 100），避免巨大回报量级淹没条件信号——这是第 3 篇「回报尺度归一化」的具体落地。</span>
- **评估多次取均值**：离线评估随机性大，标准做法是多种子评估取均值 ± 标准差，每次评估跑固定步数后记录回报。
- **看趋势别只看单点**：表格里一个「85」与一个「82」的差距，往往不及同一个算法在相邻数据集之间的一致性重要。DT 的稳健性（方差小、训练稳定）在对比里也是隐形的加分项。
- **跨论文数字不可直接拼**：不同论文的基线实现、种子数、甚至 D4RL 数据版本都可能不同，最安全的做法是只对比同一张表。
- **上下文长度按域设置**：MuJoCo 上论文用 $K=20$ 左右，Atari 上则用 $K=30$–$50$（Pong 取 50，多数游戏取 30）。Atari 的 $K$ 更大，是因为像素输入的视觉历史更长才能形成稳定的行为上下文；这也提醒我们：**$K$ 不是通用常数，而是跟着数据与任务调的超参数**（呼应第 2 篇）。
- **D4RL 不止 MuJoCo**：它还有 antmaze（迷宫导航）、adroit（灵巧手）、kitchen（厨房操作）等域，检验算法在稀疏奖励、拼接需求更强的场景下的表现。DT 论文主实验聚焦 MuJoCo 与 Atari，但后续工作在这些域上对 DT 的适配（如 antmaze 上表现平平）恰恰印证了第 7 篇的边界分析——迷宫类任务强依赖轨迹拼接，而拼接恰恰是条件生成最弱的一环。

## 7 小结

- D4RL 是离线 RL 的标准考场，DT 论文主实验用 **MuJoCo 运动控制 + Atari**。
- 数据集按质量分 **random / medium / medium-replay / medium-expert / expert**，medium-expert 最考验「从混合数据里挑好行为」。
- 归一化分数把一切压到同一把尺子：**随机 = 0，专家 = 100**，超过 100 意味着超越数据中的专家策略。
- DT 结果三句话：medium-expert 突出（如 halfcheetah-medium-expert 86.8）、medium/medium-replay 大幅超越 BC 并接近 CQL、expert 上与 BC 持平；Atari 上大体等于 BC。
- 读表注意：分数不可跨任务平均，跨论文拼数字有风险，条件目标要选在数据覆盖范围内。
- 数据有「质量」与「覆盖度」两个轴：覆盖越广，DT 条件分布越丰满；覆盖越窄，越容易在未见状态上失灵。
- $K$ 按域设置（MuJoCo 约 20，Atari 约 30–50），不是通用常数；antmaze 等域对拼接的强依赖恰好暴露 DT 的软肋。
- 0 与 100 是两个心理标尺：40–60 意味着比随机好一半，90 以上意味着追平甚至超越专家。
- 复现 DT 时记得在轨迹内部采样、按多种子取均值，这两条做到，数字才可复现。

在下一节，我们把 DT 与它的最大对手放到天平上：不依赖值函数与动态规划的它，凭什么与 **Offline Q-learning** 正面对垒——这场对比会揭开离线 RL 两条路线各自的全部底牌。先记住一个数字当作入场券：**86.8**，halfcheetah-medium-expert 上的 DT，它是我们论证的起点，也是对照表的焦点。
