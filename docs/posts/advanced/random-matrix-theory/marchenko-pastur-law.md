## 为什么从 Marchenko–Pastur 律开始

半圆律管的是「方阵的谱」，可统计学家和数据科学家手里的矩阵几乎都不是方阵：$p$ 个变量、$n$ 次观测，数据堆成 $p \times n$ 的矩形，关注的量是**样本协方差矩阵** $\frac{1}{n}XX^T$ 的特征值。当维度 $p$ 与样本量 $n$ 同阶（$p/n \to c$）时，经典大样本统计全部失效——**Marchenko–Pastur 律**（1967）是这扇新世界的大门：它精确刻画矩形矩阵奇异值平方的极限谱，是主成分分析、信号检测、高维统计推断的理论基石。它比半圆律「更近代」：半圆描述物理世界的对称矩阵，MP 律描述现代数据世界。两者合起来，才是「随机矩阵」在数学与应用两条战线的完整画像。

## 1 样本协方差矩阵与 Wishart 矩阵

**样本协方差矩阵**：设 $X$ 是 $p \times n$ 的随机矩阵，列代表 $n$ 次独立观测，行代表 $p$ 个变量（$X_{ij}$ 是第 $j$ 次观测第 $i$ 个变量的值），均值为 0、方差为 1。样本协方差阵定义为

$$S = \frac{1}{n} X X^T \qquad (p \times p)$$

它的特征值刻画「数据在不同方向上的方差」。经典统计（$p$ 固定、$n \to \infty$）说 $S \to \Sigma$（真实协方差）；可现代数据通常是 $p$ 和 $n$ **同阶增长**，此时 $S$ 的谱远非 $\Sigma$ 的谱，而是被一层「噪声谱」包裹。<span class="marginnote">关键参数是<strong>纵横比</strong> $c = p/n$。当 $c$ 固定而 $p,n \to \infty$，我们进入「高维渐近」；$c \to 0$ 回到经典小样本极限。Marchenko–Pastur 律的全部内容，就是回答「$S$ 的谱在 $c$ 固定时收敛到什么」。</span>

若 $X$ 的元素是独立标准正态，则 $S$ 服从 **Wishart 分布**（多元正态的样本协方差分布，是 $\chi^2$ 分布的高维推广）。Wishart 矩阵是随机矩阵理论里与高斯系综并列的经典对象，而 MP 律对 $X$ 的分布要求极弱——只要元素独立、均值 0、方差 1，谱就只由 $c$ 决定。<span class="marginnote">这里能再次看见「普适」的踪迹：$S$ 的极限谱不依赖 $X$ 元素的具体分布，只依赖方差与纵横比。这与半圆律「只依赖方差」是同一哲学的延续，见第 9 篇。</span>

## 2 Marchenko–Pastur 律：陈述

设 $p/n \to c \in (0, \infty)$，$X$ 元素独立、均值 0、方差 1，$S = \frac{1}{n}XX^T$。则 $S$ 的经验谱分布依概率收敛到 **Marchenko–Pastur 分布** $\mu_c$：

$$\mu_c = \left(1 - \frac{1}{c}\right)_{+} \delta_0 \;+\; \frac{1}{2\pi c x}\sqrt{(x - a)(b - x)}\,\mathbf{1}_{[a,b]}(x) \, dx$$

其中 $a = (1 - \sqrt{c})^2$，$b = (1 + \sqrt{c})^2$，$(1 - 1/c)_+ = \max(0, 1 - 1/c)$。

逐块读：

- **支撑 $[a, b]$**：特征值全部落在 $[a,b]$ 内，$a,b$ 由 $c$ 唯一决定。$c$ 越小，$a,b$ 越接近 1；$c \to 0$ 时 $[a,b] \to [1,1]$，回到「$S \to I$」的经典极限。
- **$x^{-1}$ 因子**：密度在支撑下端点 $a$ 处以平方根消失，但含 $1/x$，故当 $a$ 靠近 0（$c$ 大）时，密度在 0 附近发散。
- **原子 $\delta_0$**：当 $c > 1$（即 $p > n$），矩阵 $S$ 秩 $\le n \lt  p$，至少 $p - n$ 个特征值恒为 0，质量 $1 - 1/c$ 聚在 0 处。<span class="marginnote">$c>1$ 的原子是「数据维数超过样本量」的直接指纹：观测不足，样本协方差必然退化。这是高维统计里「$p>n$ 问题」在最纯谱层面的体现。</span>

**与半圆的对照**：半圆是「对称方阵的谱」，MP 是「矩形矩阵的谱」；半圆支撑 $[-2,2]$ 关于 0 对称，MP 支撑 $[(1-\sqrt c)^2, (1+\sqrt c)^2]$ 全在非负半轴。一个天然的对应：**Wishart 矩阵 $S$ 的谱 = 矩形矩阵 $X$ 的奇异值平方谱**，而奇异值本身（$S$ 特征值的平方根）的谱叫「四分之一圆律」。

## 3 公式解析：Stieltjes 自洽方程

MP 律的证明核心是 Stieltjes 变换的自洽方程。设 $m(z) = \int \frac{d\mu_c(x)}{x - z}$，则 $m$ 满足

$$c\, z\, m(z)^2 + (z + c - 1)\, m(z) + 1 = 0$$

把它拆开看：

- **$m(z)$ 是经验谱分布 $m_N(z) = \frac{1}{p}\operatorname{tr}(S - zI)^{-1}$ 的极限**。Stieltjes 变换把「谱的极限」变成「解析函数的极限」，而 $m_N$ 满足一个可用秩一扰动技巧逼近的自洽关系。
- **$c$ 只出现在第一项 $czm^2$ 与 $(c-1)m$ 里**：纵横比是唯一参数。这正是「谱只由 $c$ 决定」的方程层面证据。
- **解出 $m$ 即得密度**：对 $x \in (a,b)$ 取 $z \to x + i0$，$\sqrt{(z+c-1)^2 - 4cz} = \sqrt{(z-a)(z-b)} \to i\sqrt{(x-a)(b-x)}$，于是 $\operatorname{Im}m(x) = \frac{\sqrt{(x-a)(b-x)}}{2\pi c x}$ 除以 $\pi$ 即得 $\rho(x)$——正是上节密度。

方程的**来历**一句话概括：把 $S = \frac{1}{n}XX^T$ 的解析式 $m_N$ 对矩阵元求条件期望，利用 $X$ 元素独立与方差 1，在 $N \to \infty$ 时消去随机涨落，留下一个关于 $m$ 的二次方程。<span class="marginnote">自洽方程技术是随机矩阵理论最重要的分析工具之一：先用「秩一扰动」把 $m_N$ 写成含 $X$ 列信息的式子，再对 $X$ 取条件期望，把随机对象化为确定性方程。半圆律的 Stieltjes 方程 $m^2 + zm + 1 = 0$ 正是 $c \to \infty$ 极限下的退化情形——它们共享同一套方法论。</span>

**验证 $c \to 0$**：方程退化为 $(z - 1)m + 1 = 0$，即 $m = 1/(1-z)$——正是 $\delta_1$（恒等阵谱）的 Stieltjes 变换。经典极限自动恢复。

## 4 高维渐近中的相变

MP 律最精彩的数学是支撑端点处的行为，它随 $c$ 变化呈现两种截然不同的「边」：

**软边（soft edge, $c > 1$ 与 $c \to \infty$ 的情形）**：当 $a > 0$，即 $(1-\sqrt c)^2 > 0 \iff c \ne 1$，下端点 $a$ 处的密度以平方根消失（$c \lt  1$ 时），最大特征值在 $b$ 处以 $N^{-2/3}$ 尺度涨落——**Johnstone（2001）**证明，Wishart 最大特征值的涨落服从 **Tracy–Widom 分布**，与高斯系综的软边完全同构。这是第 5 篇结果向 Wishart 的移植。

**硬边（hard edge, $c > 1$）**：当 $c > 1$，特征值在 0 处被「硬墙」顶住——它们不能穿越 0，涨落尺度是 $N^{-2}$，极限核从 Airy 换成 **Bessel 核**，由 β 决定的指数 $\nu = p - n - 1$ 进入分布。这是「有界支撑边界」与「谱半轴起点」的本质区别。

**临界点 $c = 1$**：$a = b = 0$，支撑坍缩成一个点，密度在 0 处发散（$1/\sqrt{x}$），相变发生在 $c = 1$——样本量与维度相等之处。<span class="marginnote">$c=1$ 处谱的剧烈变化对应统计里的「维数灾难」临界点：$p$ 恰好等于 $n$ 时，样本协方差在 0 附近堆积、最小特征值趋向 0，条件数发散。理解这个相变，是理解正则化（如收缩估计）为何必要的第一原理。</span>

## 5 应用：噪声地板与信号检测

MP 律在高维统计里扮演「噪声基线」：若数据没有真实结构（纯噪声），协方差谱必然落在 MP 分布内。任何**超出 $[a,b]$ 支撑的特征值，都可能是信号的证据**。这给出一个简单的「相位判断」：

**纯噪声**：所有特征值 $\in [a,b]$，最大特征值 $\to b$，涨落为 TW。
**含单信号**（秩一扰动 $\Sigma = I + \theta vv^T$）：当信噪比 $\theta > \sqrt{c}$（即 $\theta^2 > c$），最大特征值跳出 $b$ 形成**分离的特征值**；当 $\theta \le \sqrt{c}$，信号被噪声淹没在 $[a,b]$ 内。

这个门槛正是 **Baik–Ben Arous–Péché 相变**（2005）：信号是否可检测，在谱层面有一个清晰的临界阈值 $\theta = c^{1/4}$（对奇异值平方）或 $\theta^2 = c^{1/2}$ 等价的表述。<span class="marginnote">BBP 相变是现代高维统计的标志性结果：它说明「主成分能否被看到」不是样本量问题，而是信噪比与纵横比的比拼。低于阈值，即使 $n,p \to \infty$ 也永远看不见信号——这是「不可检测相」的严格证明。</span>

由此衍生出整套**高维推断方法学**：用 MP 分布拟合噪声谱、估计噪声方差（如随机矩阵谱聚类的方差估计）、确定主成分数（超过 $b$ 的特征值个数）、随机矩阵正则化。在**无线通信**里，MP 律刻画多天线信道矩阵奇异值的谱，用于容量估计；在**金融**里，用它从协方差阵谱中区分「市场因子」与「噪声墙」。<span class="marginnote">实践提示：真实数据几乎不严格满足 MP 假设（元素独立、等方差）。但 MP 律作为「零模型」极有价值——把观测谱与 MP 谱对比，偏离处即结构所在。这是「随机矩阵 = 噪声基线」这一思想的最小可行单元。</span>

## 6 术语速查表与临界算例

| 术语 | 记号 / 公式 | 一句话含义 |
| --- | --- | --- |
| 样本协方差 | $S = \frac{1}{n}XX^T$ | 高维数据的基本统计量 |
| Wishart 分布 | 高斯元素时 $S$ 的分布 | $\chi^2$ 的高维推广 |
| 纵横比 | $c = p/n$ | 决定极限谱的唯一参数 |
| MP 分布 | $\frac{1}{2\pi c x}\sqrt{(x-a)(b-x)}$ | 样本协方差极限谱 |
| 支撑 | $[a,b]$，$a=(1-\sqrt c)^2$、$b=(1+\sqrt c)^2$ | 特征值集中区域 |
| 原子 | $(1-\frac1c)_+\delta_0$ | $p>n$ 时零特征值的质量 |
| 软边 | 端点密度平方根消失 | $N^{-2/3}$、Airy、TW |
| 硬边 | 端点被 0 顶住 | $N^{-2}$、Bessel 核 |
| 自洽方程 | $c z m^2 + (z+c-1)m + 1 = 0$ | Stieltjes 变换的方程 |
| BBP 相变 | 信噪比超阈值才可检测 | 信号 vs 噪声的谱决策 |

**临界算例（$c = 1$）**：$p = n$ 时 $a = b = 0$，MP 密度变为 $\rho(x) = \frac{\sqrt{4-x}}{2\pi\sqrt{x}}$，支撑 $(0,4]$，在 $x \to 0$ 处以 $x^{-1/2}$ 发散。这是「维数 = 样本量」临界点的谱指纹。

- **最小特征值**：趋向 0，条件数 $\kappa = \lambda_{\max}/\lambda_{\min} \to \infty$——样本协方差在 $c=1$ 时注定病态，任何求逆都不可靠。
- **相变的连续性**：$c$ 从 1 两侧逼近时，密度连续但导数奇异；$c>1$ 出现 $\delta_0$ 原子（秩亏），$c\lt 1$ 时最小特征值 $>0$——谱在 $c=1$ 处「结构相变」。
- **正则化的必要**：$c \approx 1$ 的真实数据必须用收缩/裁剪/Ledoit–Wolf 型正则化稳定谱——MP 理论精确预言了何时非做不可。

**实践食谱：检验谱是否为 MP**。拿到一个样本协方差的谱：

1. 估计 $c = p/n$ 与噪声方差 $\sigma^2$（可用特征值均值 $\bar\lambda \approx \sigma^2$）。
2. 计算 $a = \sigma^2(1-\sqrt c)^2$、$b = \sigma^2(1+\sqrt c)^2$。
3. 把观测特征值直方图与 MP 密度叠放，检查是否被「夹在 $[a,b]$ 内」。
4. 跳出 $b$ 的特征值用 TW 检验显著性（第 5 篇）。

这是高维数据探索性分析的「第一张图」，也是随机矩阵应用到真实数据的标准入口。

**辨析｜易错点：** MP 律的「方差为 1」假设对应 $X$ 元素方差 $\sigma^2$ 的一般缩放：真实数据只需把支撑改写为 $a = \sigma^2(1-\sqrt c)^2$、$b = \sigma^2(1+\sqrt c)^2$。常见错误是拿原始特征值直方图直接对比「标准」MP 密度而忽略 $\sigma^2$——正确做法是先估计 $\sigma^2$（可用特征值均值 $\bar\lambda \approx \sigma^2$），再缩放支撑后比较。

## 7 小结

- **样本协方差** $S = \frac{1}{n}XX^T$，纵横比 $c = p/n$ 是唯一决定极限谱的参数。
- **MP 分布**：密度 $\frac{1}{2\pi cx}\sqrt{(x-a)(b-x)}$ 于 $[a,b]$，$a=(1-\sqrt c)^2$、$b=(1+\sqrt c)^2$；$c>1$ 时另含质量 $1-1/c$ 的 $\delta_0$ 原子。
- **Stieltjes 自洽方程**：$c z m^2 + (z+c-1)m + 1 = 0$，解出的虚部即密度。
- **两类边**：软边（$N^{-2/3}$、Airy、Tracy–Widom）与硬边（$N^{-2}$、Bessel 核）；$c=1$ 是谱的结构相变点，$c>1$ 时 $\delta_0$ 原子出现。

在下一节，我们将追问：为什么 MP 与半圆看起来不同、本质上却是同一个「自由」定律的两副面孔——这正是自由概率引论的主题。
