## 为什么从行列式点过程开始

上一讲的最后我们得到：GUE 特征值的 $k$-点关联函数是某个核的 $k$ 阶行列式。这看起来像巧合，其实是一个更宏大理论的冰山一角——**行列式点过程（determinantal point process, DPP）**。它是一族以「所有关联函数都是行列式」为定义特征的点过程，随机矩阵只是它的众多化身之一：自由费米子基态、非相交随机游走、随机格点上的无碰撞粒子、机器学习里的「多样性抽样」，全都通向同一个行列式结构。理解 DPP，等于理解了「排斥」这个概念的最一般数学形式，也等于拿到了通向 Tracy–Widom、普适性乃至辛几何（Wigner 猜测）的一把总钥匙。

## 1 从关联函数反推定义

上一讲定义了 $k$-点关联函数 $R_k(x_1, \dots, x_k)$。它们满足一个自然的**约化一致性**：$R_k$ 对任意一个变量积分，应回到 $R_{k-1}$（乘上因子 $N - k + 1$ 或作相应归一）。这个约束很松——绝大多数点过程都满足它。DPP 的定义是：存在一个**核（kernel）** $K(x, y)$，使得

$$R_k(x_1, \dots, x_k) = \det \bigl[ K(x_i, x_j) \bigr]_{1 \le i,j \le k} \qquad \text{对一切 } k \ge 1$$

**行列式点过程（DPP）**：一个空间点过程，若存在局部可积函数 $K$ 使上式对所有 $k$ 成立，就称为以 $K$ 为核的行列式点过程。<span class="marginnote">「行列式」三个字是定义的核心：$R_2(x,y) = K(x,x)K(y,y) - K(x,y)^2$，由于 $|K(x,y)|^2 \le K(x,x)K(y,y)$，必有 $R_2(x,x) = 0$——两个点在同一点的关联密度为 0，这是「排斥」的最纯形式。</span>

这个定义有两重意义。其一，**$R_k$ 被 $K$ 完全决定**——理论上讲，一个 DPP 的全部统计信息都编码在一个二元函数 $K$ 里，这是巨大的维度压缩。其二，**$R_k$ 是行列式而非别的什么**——行列式的组合结构让一切积分都能用积分算子技巧处理。

## 2 存在性：什么样的核才行

不是随便一个 $K$ 都能定义 DPP。必要的条件是 **$K$ 是投影核（projection kernel）**：把 $K$ 看成算子 $K: L^2 \mapsto L^2$，则需满足

$$K^2 = K \quad (\text{幂等}), \qquad K^* = K \quad (\text{自伴}), \qquad 0 \le K \le I \quad (\text{有界})$$

直观地说，$K$ 的特征值都要落在 $[0,1]$ 之间。对自伴幂等核（即正交投影），$K(x,y) = \sum_i \phi_i(x)\overline{\phi_i(y)}$，$\{\phi_i\}$ 是 $L^2$ 的标准正交系。<span class="marginnote">投影核的物理解读：$K(x,y)$ 是 $N$ 个单粒子波函数的密度矩阵，特征值 $\in \{0,1\}$ 对应「占据或未占据」。这正是「自由费米子基态 = DPP」的数学根源，我们第 3 节展开。</span>

当 $K$ 是 $N$ 维投影（有 $N$ 个特征值等于 1）时，DPP 恰好有 $N$ 个点（以概率 1）。这正是「$N$ 个特征值」的抽象：GUE 的核 $K_N$ 是 $N$ 维投影核，于是恰好有 $N$ 个特征值点。

## 3 公式解析：核如何编码一切

以 GUE 为例，把抽象定义落到具体。GUE 的核是

$$K_N(x, y) = \sum_{k=0}^{N-1} \varphi_k(x) \overline{\varphi_k(y)}$$

其中 $\varphi_k$ 是以 $e^{-x^2/2}$ 为权正交化的 **Hermite 多项式**。代入联合密度公式：

$$p_N(\lambda_1, \dots, \lambda_N) = \frac{1}{N!} \det \bigl[ K_N(\lambda_i, \lambda_j) \bigr]_{i,j=1}^{N}$$

- **$\varphi_k$ 是 Hermite 正交基**：$\int \varphi_k(x)\varphi_l(x) \, dx = \delta_{kl}$，这是上一讲「正交多项式核」的显式化。正交性正是「$K_N$ 是投影」的来源——$\sum \varphi_k(x)\varphi_k(y)$ 作用两次等于作用一次。
- **$\det[K_N(\lambda_i,\lambda_j)]$ 是 $N$ 阶行列式**：把 $N$ 个点塞进核的行列式。范德蒙德乘积 $\Delta(\lambda)^2$ 与 $\det[K_N]$ 之间的等价，由行列式乘法公式（Cauchy–Binet）保证。
- **$1/N!$ 与「无标号」**：联合密度是「无序点集」的密度，$N!$ 消除点的标号冗余。特征值本身无标号，密度是对称的。

**推论（最常用的一条）**：对任意单点可测集 $B$，点落进 $B$ 的个数的方差为

$$\operatorname{Var}\bigl(N(B)\bigr) = \int_B K(x,x)\, dx - \int_B\int_B |K(x,y)|^2 \, dx\,dy \;\le\; \mathbb{E}[N(B)]$$

方差小于均值——**负相关**（相对于泊松的「方差 = 均值」）。这就是 DPP 的招牌性质：点倾向于互相「推开」，不团聚。<span class="marginnote">泊松点过程的方差等于均值（无相关性），DPP 的方差严格更小（负相关），而「正相关」的点过程则聚团。三类点过程构成了空间统计的基本分类：排斥、独立、聚集。随机矩阵的特征值属于排斥型——这也是为什么它们不会「堆成一团」。</span>

## 4 体相极限：sine 核

DPP 理论在随机矩阵中的第一个伟大成果，是取「体相极限」后得到普适核。把 GUE 特征值在谱中心处按局部间距缩放：$\lambda_i = x_i / \rho_{\text{sc}}(x_i)$ 之类局部平均间距归一化后，核趋于 **sine 核**

$$K(x, y) = \frac{\sin\bigl(\pi(x - y)\bigr)}{\pi (x - y)}$$

它是对应于「自由无界费米子」的平移不变投影核。<span class="marginnote">sine 核的普适性远超 GUE：它不依赖矩阵元素的分布、不依赖谱的具体位置（只要不在边缘）、甚至对非高斯系综也成立。这个「体相普适性」是第 9 篇普适性问题的核心结论之一，由 Pastur–Shcherbina、Tao–Vu、Erdős–Yau 等人完成严格证明。</span>

sine 核给出两个标志性结果。其一，**最近邻间距分布**：相邻特征值间距 $s$（以平均间距归一）的密度为 $p(s) = \frac{d^2}{ds^2} F(s)$，其中 $F(s) = \det\bigl[K(x_i, x_j)\bigr]$ 在某 $s$ 相关区间上展开，结果是 $p(s) \sim s^2$（GUE，$\beta=2$）——与第 2 篇表里的行为一致。其二，**数涨落**：$N(a,b)$（区间 $[a,b]$ 内特征值数）的方差随 $\log N$ 增长（对数涨落），这是 sine 过程的特征——与泊松的线性涨落截然不同。

## 5 DPP 遍布数学与工程

DPP 不只是随机矩阵的内部语言，它几乎是「排斥点系统」的通用母语：

**自由费米子**：$N$ 个非相互作用费米子的基态波函数之模方，恰是 $N$ 点 DPP 的联合密度——$K$ 是单粒子密度矩阵。随机矩阵特征值 = 费米子位置，排斥 = 泡利不相容。
**非相交随机游走 / 随机格点**：不相交路径的集合、破缺 KPZ 界面，在极限下都由 DPP 控制。
**机器学习与组合优化**：**DPP 抽样**用于从候选集里选「多样且高质量」的子集（如推荐系统的结果去重）。计算上，DPP 的采样与边缘化都有多项式算法，核心正是「行列式可分解」。

<span class="marginnote">一条贯穿的直觉：<strong>凡是要「选一组互相排斥的个体」的地方，行列式都会出现</strong>。因为排斥 = 负相关 = 行列式的交叉项带负号。随机矩阵只是第一个被发现、也是最干净的例子。</span>

## 6 术语速查表与有限 DPP 算例

| 术语 | 记号 / 公式 | 一句话含义 |
| --- | --- | --- |
| 点过程 | 空间中的随机点集 | 特征值的抽象载体 |
| $k$-点关联函数 | $R_k(x_1,\dots,x_k)$ | 同时找到 $k$ 个点的密度 |
| 核 | $K(x,y)$ | 编码全部关联信息的二元函数 |
| 行列式结构 | $R_k = \det[K(x_i,x_j)]$ | DPP 的定义特征 |
| 投影核 | $K^2=K$、$K^*=K$、$0\le K\le I$ | DPP 存在性的充要条件 |
| 负相关 | $\operatorname{Var}(N(B)) \le \mathbb{E}[N(B)]$ | 点互相排斥的定量刻画 |
| sine 核 | $K(x,y)=\frac{\sin\pi(x-y)}{\pi(x-y)}$ | 体相普适核 |
| L-系综 | $K = L(I+L)^{-1}$，$L$ 半正定 | 有限 DPP 的构造与抽样 |
| 泊松点过程 | $R_k \equiv 1$（无关联） | DPP 的「无排斥」退化 |
| Wigner 猜测 | $p(s) \approx \frac{32}{\pi^2}s^2e^{-4s^2/\pi}$ | 最近邻间距的简洁近似（GUE） |

**有限 DPP 算例（L-系综）**：设 $S$ 是有穷集（$|S|=M$），$L$ 是 $M\times M$ 半正定矩阵。由 $L$ 定义 DPP：$\mathbb{P}(A \subseteq \text{点集}) = \det(L_A)$，$L_A$ 是 $L$ 在子集 $A$ 上的主子式。行列式的展开给出归一化：

$$\det(I + L) = \sum_{A \subseteq S} \det(L_A)$$

- **抽样 = 特征子空间的随机基**：$L = \sum_k \lambda_k v_k v_k^T$ 时，对每个 $\lambda_k$ 以概率 $\lambda_k/(1+\lambda_k)$ 独立选入 $v_k$，再对选中向量 Gram–Schmidt——得到的点集服从 DPP。
- **排斥的来源**：选中的特征向量互相正交，点不会「复制」；已选方向上的点概率为 0。
- **工程意义**：机器学习「从 $M$ 个候选中选多样子集」正是 L-系综——行列式可多项式时间计算与采样，这是 DPP 走出理论的关键。

**从核到最近邻间距**：sine 过程的行列式结构直接给出相邻点间距分布。小间距行为 $p(s) \sim s^\beta$ 来自 $R_2$ 在 $s \to 0$ 时消失；**Wigner 猜测**用单变量解析式近似它：$p(s) = \frac{32}{\pi^2}s^2 e^{-4s^2/\pi}$（GUE）。这个近似与精确分布的误差小于 2%，是「排斥」在最直观单变量层面的写照。

**连接**：DPP 的负相关性质（方差 ≤ 均值）是「排斥」的最一般定义。它统摄了第 3 篇的 Vandermonde 排斥、第 5 篇的 TW 边缘、第 11 篇的零点排斥——凡是以行列式为核的随机结构，都在这一讲的屋檐下。

**一个直觉检验**：若 $K$ 是 $N$ 维投影核，DPP 恰好有 $N$ 个点。这解释了「GUE 特征值恰好有 $N$ 个」为何不是巧合——核的维数就是点的个数，行列式结构把「点数」与「核」焊死在一起。

**一句话收束**：DPP 用「一切关联都是行列式」这一个人造而优美的规则，把排斥、可计算、普适三件事焊成一体——它是随机矩阵理论献给概率论与工程学最通用的礼物。

## 7 小结

- **定义**：$k$-点关联函数 $R_k = \det[K(x_i,x_j)]$ 的点过程称为行列式点过程，一切信息编码在核 $K$ 中。
- **投影核**：$K^2 = K$、自伴、$0 \le K \le I$；$N$ 维投影核对应恰好 $N$ 个点。
- **GUE 实例**：$K_N = \sum_{k<N}\varphi_k(x)\varphi_k(y)$（Hermite 正交多项式核），联合密度 $= \det[K_N]/N!$。
- **负相关**：$\operatorname{Var}(N(B)) \le \mathbb{E}[N(B)]$——排斥的定量刻画。
- **sine 核**：体相极限下 $K = \frac{\sin\pi(x-y)}{\pi(x-y)}$
