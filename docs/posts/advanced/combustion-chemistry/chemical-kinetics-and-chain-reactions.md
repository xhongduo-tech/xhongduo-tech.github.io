## 为什么从动力学开始

上一节回答了「燃烧能放出多少热」，这一节回答「燃烧以多快的速率进行」。这个问题的答案决定了火焰是「噗」地熄灭还是「轰」地爆燃，决定了着火延迟有多长，也决定了污染物生成的多少。<span class="marginnote">同样的甲烷空气混合气，在室温下可以存放几小时不发生反应，而一粒火花就能让它在毫秒内烧完——热力学无法解释这个差别，只能由<strong>动力学</strong>给出答案。</span>燃烧动力学的核心是：宏观的总包反应其实由大量**基元反应（elementary reaction）** 组成，而其中起决定作用的是一类特殊的机制——**链式反应**。它与第二级《化学动力学》衔接，却是本专题后续火焰理论共同的引擎。

## 1 基元反应与速率定律

**基元反应**：反应物分子在一步内直接转化为产物的反应，化学方程式直接给出分子层面的碰撞事件。例如 $\ce{H + O2 -> OH + O}$ 是一个基元反应，而 $\ce{2H2 + O2 -> 2H2O}$ 则是一个**总包反应（overall reaction）**，真实过程要经过几十步基元反应。

基元反应的速率定律可以直接由化学计量写出：对 $a\ce{A} + b\ce{B} \rightarrow$ 产物，

$$\frac{d[\ce{A}]}{dt} = -k\,[\ce{A}]^a[\ce{B}]^b$$

其中 $k$ 是**速率常数（rate constant）**，指数是反应物的计量系数。<span class="marginnote">这是基元反应与总包反应最大的区别：总包反应的速率定律必须由实验测定，指数可能不是整数；基元反应的速率定律则天然由碰撞逻辑决定。把「指数等于计量系数」当成普遍规律，是初学动力学最常犯的错误。</span>

总包反应的速率定律为什么不能直接写出？因为总包反应描述的只是「初态到终态」的净结果，真实过程经手几十个基元反应，净速率由其中最慢的步长决定——**瓶颈步长（rate-determining step）** 的概念由此而来。在燃烧机理里，找到瓶颈步长就等于找到了调控总包速率的那只手：例如甲烷氧化的瓶颈常是 $\ce{CH3 + O2 -> CH2O + OH}$ 或后续的 $\ce{HCO}$ 氧化步，催化剂与抑制剂的选择都围绕它展开。

## 2 阿伦尼乌斯定律

速率常数 $k$ 强烈依赖温度，其经验形式由**阿伦尼乌斯定律**给出：

$$k = A T^n \exp\!\left(-\frac{E_a}{RT}\right)$$

$A$ 是指前因子，$E_a$ 是**活化能（activation energy）**，$R$ 是气体常数。<span class="marginnote">活化能的物理图像是一道「能量门槛」：只有碰撞能量超过 $E_a$ 的分子对才能越过过渡态发生反应。温度每升高一点，越过门槛的分子比例按指数增长——这就是「温度对反应速率影响极其剧烈」的数学来源。</span>燃烧中大多数速率常数取 $n = 0$ 或 $n$ 很小的修正因子，工程上常用修正阿伦尼乌斯形式。

取对数得到工程上最常用的线性化形式：$\ln k = \ln A + n\ln T - E_a/RT$。固定温度区间、忽略 $\ln T$ 的慢变化，$\ln k$ 对 $1/T$ 作图得一条直线，斜率即 $-E_a/R$——这就是**阿伦尼乌斯图（Arrhenius plot）**，从实验数据提取活化能的标准方法。<span class="marginnote">燃烧文献里处处是阿伦尼乌斯图：一条直线的斜率读出活化能，截距读出指前因子；两条机理曲线斜率差异明显时，一眼就能看出哪一步「更怕冷」。</span>

**算例：温度对速率常数的威力。** 取活化能 $E_a = 80\ \text{kJ/mol}$ 的反应，对比 1000 K 与 1500 K：$\ln(k_2/k_1) = \frac{E_a}{R}\left(\frac{1}{T_1} - \frac{1}{T_2}\right)$，代入得 $k_2/k_1 \approx 25$——温度只升高一半，速率常数却快了约 25 倍。燃烧反应的活化能普遍更高（$E_a > 150\ \text{kJ/mol}$ 很常见），温度敏感性只会更强，这正是火焰「差一度点不着、热几度就爆炸」的数学根源。

## 3 链式反应与自由基

燃烧过程中真正干活的是**自由基（radical）**——带未成对电子的活泼中间体，如 $\ce{H}$、$\ce{O}$、$\ce{OH}$、$\ce{CH3}$。它们一个接一个地引发新的反应，像链条一样把反应传播下去，这就是**链式反应（chain reaction）**。

按自由基的净变化，链式反应的步长可分为三类：

**链引发（initiation）**：由稳定分子生成自由基，需打破强键，活化能高，速率慢。例如 $\ce{H2 + O2 -> 2 OH}$。
**链传播（propagation）**：自由基总数不变，一个自由基反应生成另一个自由基。例如 $\ce{OH + H2 -> H2O + H}$。
**链分支（branching）**：一个自由基变成两个自由基，自由基总数增加，反应加速。例如 $\ce{H + O2 -> OH + O}$。<span class="marginnote">链分支是燃烧「自加速」的发动机：$\ce{H + O2 -> OH + O}$ 这一步的产物 $\ce{O}$ 又参与 $\ce{O + H2 -> OH + H}$，自由基总数翻倍式增长，混合气才能从「缓慢氧化」跃迁到「爆炸」。这也是氢气与甲烷爆炸极限差异的根源。</span>
**链终止（termination）**：自由基结合为稳定分子，或碰撞器壁而湮灭。例如 $\ce{H + OH + M -> H2O + M}$，其中 $M$ 是任意第三体，带走多余的能量。

**核心概念：链分支（chain branching）**：自由基数目不守恒、净增加的一类链式反应步，是燃烧与爆炸得以自加速的关键。

链式反应还有一个描述效率的量：**链长（chain length）**，定义为每个被引发的自由基平均引发的反应步数。链长长意味着一个引发事件就能点燃大量分子——氢气氧化的链长可达 $10^5$ 量级，这是它爆炸极限极宽、反应极快的动力学根源。<span class="marginnote">链长与链分支速率直接相关：分支越强，链越长。当链长趋于无穷大时，正是上一节引入的爆炸判据 $\phi = k_b - k_t > 0$——链长无穷大即「一发不可收拾」，这是把「链式反应」与「爆炸」两套语言接起来的桥梁。</span>

链终止除了气相三体复合，还有**器壁终止**：自由基扩散到容器壁面被吸附复合。器壁终止速率与容器尺寸反相关——容器越小、比表面积越大，终止越强。<span class="marginnote">器壁终止把「化学」与「几何」耦合起来：火焰能否在管道里传播，不仅取决于混合气本身，还取决于管径。这个现象在《着火、熄火与可燃极限》的熄火距离概念中会以工程形式再次出现。</span>

## 4 稳态近似与速率推导

链式反应机理几十步，如何求出总包速率？最常用的工具是**稳态近似（steady-state approximation）**：对活泼中间体，设其生成速率与消耗速率近似相等，浓度变化率为零。

$$\frac{d[\ce{自由基}]}{dt} \approx 0$$

对每一步涉及自由基的方程联立求解，即可把自由基浓度表示成稳定组分浓度的函数，再代回产物生成速率。<span class="marginnote">稳态近似的成立条件是中间体浓度远低于稳定组分且寿命极短——自由基恰好满足：它们一生成就迅速被消耗，像一条传送带上快速流过的工件，存量虽小但通量巨大。</span>

稳态近似之外还有**平衡近似（partial equilibrium assumption）**：对正逆都极快的反应，直接令正逆速率相等而非浓度恒定。两者常结合使用——快反应用平衡近似，慢反应用稳态近似——这是简化机理的标准做法，把几十步机理压缩到几步的同时保住决定性动力学。简化机理的验收标准，通常是看它能否同时复现火焰速度与着火延迟这两个独立的动力学观察量。对氢气-氧气系统，用稳态近似解出关键自由基浓度后，总包速率与实验测得的压力-组成依赖吻合得非常好，这是机理化学的经典胜利。

## 5 公式解析：链分支条件下的自由基增长

链式反应最精彩的结果，是自由基数目随时间的变化规律。考虑简化的传播-分支-终止模型，自由基浓度 $n$ 满足：

$$\frac{dn}{dt} = f(t) + k_b n - k_t n$$

其中 $f(t)$ 是引发速率（近似常数），$k_b$ 是分支速率，$k_t$ 是终止速率。<span class="marginnote">这是一个线性一阶微分方程：$f(t)$ 是「外部注入」，$k_b n$ 是「自繁殖」，$-k_t n$ 是「自身消亡」。整个方程只描述一件事——自由基池是增长还是衰减。</span>分三步拆解：

**第一步，判断净系数**：记 $\phi = k_b - k_t$。若 $\phi > 0$，分支占优；若 $\phi \lt  0$，终止占优；$\phi = 0$ 是临界。
**第二步，解方程**：$n(t) = n_0 e^{\phi t} + \frac{f}{\phi}(e^{\phi t} - 1)$。
**第三步，读行为**：$\phi \lt  0$ 时自由基浓度趋近有限定态，反应稳定进行；$\phi > 0$ 时浓度按指数爆炸增长，即**热着火 / 爆炸的动力学判据**。

这个线性模型的预测与真实系统定性吻合：真实燃烧中 $\phi$ 随温度与压力连续变化，爆炸边界因此在温度-压力平面上勾勒出一条马蹄形的边界——这正是氢气等燃料著名的**爆炸半岛（explosion peninsula）**，是爆炸安全研究中反复出现的图形。<span class="marginnote">爆炸半岛的形状可以直接用「$\phi$ 的等值线」理解：低压区三分子的链终止占优（稳定区），中压区分支占优（爆炸区），高压区又是终止占优（稳定区）——同一温度下随压力升降，混合气可能「安全→危险→安全」走一遍，这是热力学无法预言的纯动力学现象。</span>

这个判据解释了为什么可燃极限是「存在一个边界」：边界两侧 $\phi$ 的符号改变，反应行为从温和氧化突然切换为爆炸。<span class="marginnote">压力与温度通过 $k_b$、$k_t$ 进入判据：加压时三分子的终止反应加快（碰撞更频繁），所以高压有时反而抑制爆炸；而升温主要加速分支反应（活化能更高），所以存在<strong>爆炸极限的温度-压力图</strong>。这些细节将在下一节《着火、熄火与可燃极限》展开。</span>

## 6 速率定律的测定与反应级数

基元反应的速率定律由碰撞逻辑直接写出，但真实燃烧里我们面对的几乎都是总包反应，其速率定律必须靠实验测定：

$$r = k\,[\ce{F}]^a[\ce{O2}]^b$$

其中指数 $a$、$b$ 是**反应级数（reaction order）**，由实验确定，可能是分数甚至负值。

测定反应级数最常用的两类方法：

- **初始速率法（initial rate method）**：固定其他浓度、只改变一个反应物浓度，测初始速率的变化。浓度加倍而速率加倍，则该物质一级；速率不变则零级；速率变四倍则二级。<span class="marginnote">初始速率法的关键是「在反应刚开始、产物干扰最小的时刻读数」，一次只动一个变量，指数就一个个被测出来。甲烷空气总包反应的氧指数约 1、燃料指数约 $-0.3$——负指数并不罕见，它意味着燃料浓度升高反而使总包速率略降，这是链抑制效应的表现。</span>
**半衰期法（half-life method）**：一级反应半衰期与初始浓度无关，二级反应半衰期与初始浓度成反比。测不同初始浓度下的半衰期，即可判定级数。

| 反应级数 | 速率定律 | 半衰期依赖 |
| --- | --- | --- |
| 0 级 | $r = k$ | $t_{1/2} \propto [\ce{A}]_0$ |
| 1 级 | $r = k[\ce{A}]$ | $t_{1/2}$ 与 $[\ce{A}]_0$ 无关 |
| 2 级 | $r = k[\ce{A}]^2$ | $t_{1/2} \propto 1/[\ce{A}]_0$ |

**辨析｜易错点：** 总包反应的「级数」与基元反应的「分子数」是两个概念。分子数是「一步反应实际碰撞的粒子数」，只能取 1、2、3；级数是「实验测得的浓度指数」，可以是任意实数。三分子基元反应（如 $\ce{H + OH + M -> H2O + M}$）与「三级总包反应」没有直接对应关系——后者只是对实验数据的拟合结果。

## 7 从氢气到碳氢燃料

氢气-氧气机理是最简洁的链式反应样板，真实碳氢燃料的机理则复杂得多。甲烷燃烧的核心骨架包括 $\ce{CH4 -> CH3 -> CH2O -> HCO -> CO -> CO2}$ 的逐步氧化链，加上 $\ce{C2}$ 物种的生成路径，完整机理（如 GRI-Mech）包含上百个基元反应。<span class="marginnote">工程上用<strong>简化机理（reduced mechanism）</strong> 提取骨架：把快速物种做稳态近似消去，保留慢的、决定性的几步，例如甲烷两到三步的总包简化机理就能捕捉火焰速度的主要趋势。</span>无论机理多大，分析工具不变——阿伦尼乌斯定律 + 稳态近似 + 分支判据。

## 8 小结

- **总包反应 ≠ 基元反应**：燃烧的真实过程是几十到几百步基元反应，只有基元反应的速率定律指数等于计量系数。
- **阿伦尼乌斯定律** $k = A T^n e^{-E_a/RT}$ 是速率常数的温度依赖形式，活化能越高，温度敏感性越强。
- **链式反应**由引发、传播、分支、终止四类步长组成；**链分支**使自由基指数增长，是燃烧自加速的根源。
- **稳态近似**把活泼中间体浓度设为定值，是把机理化简为可解速率方程的核心工具。
- 分支-终止竞争给出爆炸判据 $\phi = k_b - k_t$：$\phi > 0$ 指数爆炸，$\phi \lt  0$ 趋于稳定，临界处即爆炸边界。
- **简化机理**用稳态/平衡近似把几十步压缩到几步，是工程反应流仿真的标准手段。

在下一节，我们将拿着这把「$\phi$ 的判据」，去看混合气在什么温度、什么压力、什么配比下会着起来——进入着火、熄火与可燃极限。
