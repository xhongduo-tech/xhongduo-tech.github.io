## 为什么从谐振腔开始

前两篇我们弄清了介质里的反转与增益，但还有一个问题悬而未决：增益介质很长（比如几厘米、几十米），光在其中走一圈只放大一次，根本不够；更何况放大的光四面八方乱跑，方向性从何而来？答案是**光学谐振腔**——两面镜子面对面把光「关」在里面，让同一束光反复穿越增益介质，放大千万次，同时只让沿腔轴方向、相位恰好自洽的光存活下来。<span class="marginnote">谐振腔其实是第一篇《受激辐射》里「受激辐射光子与原光子全同」的必然推论：只有相位能自洽叠加的光才可能在往返中保持相干增长。你可以在第一级《波动光学》的多光束干涉（法布里-珀罗）里找到它的近亲——谐振腔本质上就是一个强反馈的法布里-珀罗干涉仪。</span>这一篇我们回答三件事：什么样的腔是**稳定**的、腔里有哪些**模式**、模式之间相隔多远。

## 1 谐振腔：反馈与选模
谐振腔最基本的形态是**两镜腔**：两面球面镜（或一面平面一面球面）相距 $L$，增益介质夹在中间。<span class="marginnote">两面镜子中有一面通常是「输出镜」——反射率略低于 100%（比如 95%），让一部分光透射出去成为激光输出。反射率是激光设计里要精心权衡的参数：太高则输出太小，太低则阈值增益太高（见上一篇阈值条件）。</span>腔的作用有两条，缺一不可：

**提供反馈**：光在两面镜子间往返，每一次穿过增益介质都受激放大一次。一趟趟积累，弱光也能滚成强光——这对应第一篇里「雪崩式放大」的机制。

**模式选择**：不是任何频率、任何方向的光都能在腔内稳定存在。光往返一圈回到原处，必须与自身**相位自洽**——即一个往返的光程恰好等于波长整数倍；否则往返途中相位错乱、自相抵消，光就衰减下去。能自洽存活的场分布，就叫**模式（mode）**。

模式按空间维度分成两类：沿腔轴的**纵模（longitudinal / axial mode）**决定频率，垂直腔轴的**横模（transverse mode）**决定光束截面上的强度分布。频率由纵模决定，截面形状由横模决定——激光输出的「单色性」与「光束质量」分别由它们管辖。

## 2 稳定性条件：什么样的腔能锁住光
腔能不能锁住光，取决于镜子能否把偏离轴线的光一次次「掰回」腔内。用两个无量纲参数描述两面镜子，令

$$
g_1 = 1 - \frac{L}{R_1}, \qquad g_2 = 1 - \frac{L}{R_2}
$$

其中 $R_1, R_2$ 是两面镜子的曲率半径（凹面向腔时取正）。**稳定性条件（stability condition）**是：

$$
0 \lt  g_1 g_2 \lt  1
$$

满足它的腔叫**稳定腔**：光在腔内往返任意多次都不会越跑越偏；不满足的叫**非稳腔**，光会逐渐逃逸。<span class="marginnote">稳定性条件的推导要用 ABCD 矩阵：把光线的坐标与斜率写成向量，一次往返就是一次矩阵作用，稳定要求往返 N 次后矩阵元不发散，等价于 $|A + D| &lt; 2$，整理出来正是 $0 &lt; g_1 g_2 &lt; 1$。这套「矩阵追踪光线」的方法与第三级《线性代数》里矩阵幂的稳定性分析是同一套数学。</span>把 $g_1, g_2$ 画成坐标平面，稳定区是两条坐标轴与双曲线 $g_1 g_2 = 1$ 围成的两个阴影区，几个标志性腔型都落在图上：

![谐振腔稳定性图：阴影区为稳定腔，共焦腔、平行平面腔、共心腔是三个典型位置](/images/laser-physics/optical-resonator-modes-1.svg)

- **共焦腔（confocal）**：$R_1 = R_2 = L$，即 $g_1 = g_2 = 0$，位于原点，最稳定，模式计算最简单。
- **平行平面腔（plane-parallel）**：$R_1 = R_2 = \infty$，即 $g_1 = g_2 = 1$，落在边界 $g_1 g_2 = 1$ 上，属「临界稳定」——对镜面失调极敏感。
- **共心腔（concentric）**：$R_1 = R_2 = L/2$，即 $g_1 = g_2 = -1$，也落在边界上。

**稳定区边界上的腔「勉强能用但很娇气」**：稍微失调就滑出稳定区。实际激光器大多工作在稳定区内部，比如 $g_1 = g_2 = 0.5$ 附近，兼顾稳定与调节裕度。

## 3 纵模：腔「同意」哪些频率
沿腔轴方向，光必须满足**往返相位自洽**：往返光程 $2L$ 等于波长整数倍，即

$$
2L = q\lambda_q \;\Longleftrightarrow\; \nu_q = q\frac{c}{2L} \quad (q = 1, 2, 3, \dots)
$$

每个整数 $q$ 对应一个纵模频率 $\nu_q$，$q$ 叫纵模序数。相邻两个纵模的频率间隔是：

$$
\Delta\nu_q = \nu_{q+1} - \nu_q = \frac{c}{2L}
$$

对一台 $L = 30\ \text{cm}$ 的腔，$\Delta\nu_q = c/(2L) = 3\times10^8 / 0.6 = 500\ \text{MHz}$。<span class="marginnote">这个间隔通常远小于增益介质的增益线宽：红宝石、钕玻璃等介质的增益线宽动辄几十 GHz 到几百 GHz，于是腔内往往同时满足几十个纵模的频率——激光在频率上并非「一条线」，而是一簇间隔 $c/2L$ 的梳齿。正是这簇齿，为后面《锁模与超短脉冲》埋下了伏笔：让这些齿相位对齐，就合成超短脉冲。</span>如果介质增益线宽只有几百 MHz（如氦氖激光器），则只有少数几个甚至一个纵模能起振，激光呈现高度单色。

把数字连起来看，纵模「梳齿」的密度立刻具体起来。仍取 $L = 30\ \text{cm}$、镜面反射率 $R = 0.99$：精细度 $F = \pi\sqrt{R}/(1 - R) \approx 312$，冷腔线宽 $\Delta\nu_c = \Delta\nu/F \approx 1.6\ \text{MHz}$。若增益介质是增益线宽约 $180\ \text{GHz}$ 的 Nd:YAG，腔内能同时起振的纵模数约 $180\times10^9/5\times10^8 = 360$ 个——远不止「一条线」；而氦氖介质线宽只有约 $1.5\ \text{GHz}$，可起振的纵模仅约 3 个，这正是氦氖激光「天然接近单模」的原因。

## 4 公式解析：纵模频率间隔
**纵模间隔是全激光物理里最简单、也最常被直接调用的公式。** 它来自一次往返的相位自洽，三步看透：

$$
\nu_q = q\frac{c}{2L}, \qquad \Delta\nu_q = \frac{c}{2L}
$$

- **第一步，为何往返是 $2L$**：光从一面镜到另一面镜走 $L$，再反射回来再走 $L$，一个往返光程 $2L$。相位自洽要求 $2L = q\lambda$。
- **第二步，为何间隔是 $c/2L$**：两个相邻纵模 $q$ 与 $q+1$ 都满足往返自洽，它们的频率差为 $\nu_{q+1} - \nu_q = (q+1)c/2L - qc/2L = c/2L$——间隔只由腔长决定，与增益介质无关。
- **第三步，理解量级**：$L$ 越大，间隔越小，腔「允许」的纵模越密；$L$ 越短（微腔、VCSEL），间隔越大，越容易做出单纵模。这就是为什么短腔是单频激光的首选方案。

再补一个腔的品质因子：腔的**Q 值**定义为单位周期储能与损耗之比，$Q = 2\pi\nu t_c$，其中 $t_c$ 是腔内光子寿命；Q 越高，腔对频率的筛选越「挑剔」。Q 值概念在后面《调 Q 技术》和《激光线宽》里还会反复出现。

## 5 横模：光束的截面形状
垂直于腔轴，场的横向分布也必须是自洽的——往返一次，横向图案还原。满足条件的横向图案叫**横模（transverse mode）**，记作 $\text{TEM}_{mn}$（transverse electromagnetic），$m, n$ 是两个横向阶数。<span class="marginnote">最低阶横模 $\text{TEM}_{00}$ 是中心最强的圆形高斯光斑，没有节点；$\text{TEM}_{10}$ 沿一个方向有一条暗线，$\text{TEM}_{01}$ 沿另一方向……阶数越高，光斑上的暗纹越多。下一节《高斯光束》讨论的就是 $\text{TEM}_{00}$——激光最常用、也是光束质量最好的一档。</span>横模的光斑大小随阶数增大，频率也有微小位移（横模与纵模耦合产生「模簇」）。多横模会使光束发散、聚焦变差，所以工业与科研激光常通过腔内光阑或增益设计**选模**，只保留 $\text{TEM}_{00}$。

**辨析｜易错点：纵模管频率、横模管截面，二者不能混为一谈。** 「单模激光」如果指单纵模，说的是频率上只有一条线；如果指单横模（$\text{TEM}_{00}$），说的是截面是干净的高斯斑。一台单横模激光器可能同时有好几个纵模（多频率），反过来单纵模也可能带着高阶横模。描述激光的模结构，两个维度都要说清。

## 6 术语速查表
| 术语 | 含义 |
| --- | --- |
| 纵模（轴向模） | 沿腔轴满足往返相位自洽的频率，间隔 $\Delta\nu = c/2L$ |
| 横模 | 垂直于腔轴的场分布，记作 $\text{TEM}_{mn}$ |
| $g$ 参数 | $g_i = 1 - L/R_i$，决定腔的稳定性 |
| 稳定条件 | $0 \lt  g_1 g_2 \lt  1$，稳定腔的判据 |
| 共焦腔 | $R_1 = R_2 = L$，位于稳定区中心 |
| 自由光谱范围 FSR | 相邻纵模间隔 $c/2L$ |
| 精细度 | $F = \pi\sqrt{R}/(1-R)$，腔的频率筛选锐度 |
| Q 值 | $Q = 2\pi\nu t_c$，储能与损耗之比 |
| 光子寿命 | 光子在腔内平均存活时间 $t_c$ |
| $\text{TEM}_{00}$ | 最低阶横模，输出高斯光斑 |

## 7 常见疑问
**问：为什么平行平面腔是「临界稳定」？**
答：它落在 $g_1g_2 = 1$ 的边界上，光线往返既不收敛也不发散，镜面稍有失调就滑入非稳区，所以对装配精度与热变形极敏感。

**问：长腔与短腔的纵模密度差多少？**
答：纵模间隔 $c/2L$，腔长 1 m 时约 150 MHz，腔长 1 mm 时约 150 GHz——短腔天然更容易单纵模，这也是后面 VCSEL 能单纵模工作的原因之一。

## 8 小结
- 谐振腔的职责是**反馈放大**与**模式选择**：让自洽的光反复穿过增益介质，其余的光被淘汰。
- 腔的稳定性由参数 $g_i = 1 - L/R_i$ 判定：**稳定条件 $0 \lt  g_1 g_2 \lt  1$**；共焦腔位于稳定区中心，平行平面腔、共心腔在边界上。
- **纵模**决定频率：$\nu_q = qc/(2L)$，相邻间隔 $\Delta\nu_q = c/2L$；腔越短间隔越大。
- **横模**决定截面：$\text{TEM}_{mn}$ 中 $\text{TEM}_{00}$ 是高斯光斑，光束质量最好，工业科研都优先选它。
- 腔的 Q 值 = 储能/损耗之比，衡量腔对频率的筛选能力。
- 稳定腔靠 $g$ 参数判据 $0 \lt  g_1g_2 \lt  1$ 判定，边界上的腔型对失调极敏感。
- 纵模管频率、横模管截面，描述激光模结构时两个维度缺一不可。
- 自由光谱范围 FSR = $c/2L$ 是所有纵模计算的出发点。
- 共焦腔位于稳定区中心、模式计算最简单，是腔型设计的起点。


谐振腔是「反馈」思想在光学里的化身——没有反馈就没有激光。这条主线在控制论、电子放大乃至大模型的推理循环里反复出现。
在下一节，我们将俯身细看 $\text{TEM}_{00}$ 的完整轮廓：它如何在自由空间里传播、如何被透镜聚焦与变换——那就是《高斯光束及其变换》。
