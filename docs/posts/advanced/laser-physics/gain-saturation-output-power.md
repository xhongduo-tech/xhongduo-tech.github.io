## 为什么从增益饱和开始

阈值条件告诉我们激光何时起振，却没回答起振之后的事：腔内光强越来越强，会不会一路涨到把原子能量抽干、把腔烧掉？答案是——**增益饱和（gain saturation）**拦住了失控增长。光越强，消耗反转粒子越快，增益被「压低」；最终增益恰好压到等于损耗，激光进入稳定振荡。<span class="marginnote">增益饱和是激光器「自我调节」的核心：它让激光器变成一个稳定输出、不炸不灭的装置。你可以类比电路里的负反馈：光强是反馈信号，增益是受控量，两者咬合成一个自洽的稳态。回想第二级《控制论》里的负反馈思想，激光器正是光学世界的一台自动调节器。</span>这一篇我们从饱和的物理机制讲起，区分均匀与非均匀加宽，再导出决定激光输出功率的关键公式，并回答工程上的头号问题——输出镜反射率该取多少。

## 1 增益为什么会饱和
回顾上一篇：增益系数 $g = \sigma\Delta N$，反转 $\Delta N$ 由泵浦维持。但**激光本身也在消耗反转**——光子不断刺激受激辐射，把上能级粒子「打」下来。光越强，消耗越快，$\Delta N$ 越小，增益越低。稳态时，泵浦补充反转的速率与激光消耗反转的速率达成平衡，增益被压到某个低于小信号值 $g_0$ 的水平。

把光强记为 $I$，均匀加宽介质中的饱和规律是：

$$
g = \frac{g_0}{1 + I / I_s}
$$

其中 $g_0 = \sigma \Delta N_0$ 是**小信号增益**（弱光、没有饱和时的增益），$I_s$ 叫**饱和光强（saturation intensity）**，是「增益减半」对应的光强。<span class="marginnote">$I_s$ 由增益介质本身决定，$I_s = h\nu/(\sigma\tau_{21})$ 量级——受激发射截面越大、上能级寿命越短，饱和越容易发生。对典型固体激光器 $I_s$ 在 kW/cm² 量级，对半导体增益介质则低得多。记住一点：<strong>饱和光强是介质的内禀属性，不是腔的参数</strong>。</span>当 $I \ll I_s$，增益 ≈ $g_0$，激光处于弱信号线性放大；当 $I$ 接近或超过 $I_s$，增益被明显压低——这正是激光腔内必然发生的状态。

## 2 均匀加宽与非均匀加宽
「光强减半增益」的描述只对**均匀加宽（homogeneous broadening）**介质严格成立。均匀加宽指所有原子共享同一条增益线（谱线宽度来自寿命、碰撞等整体机制），**一束光饱和整个增益谱**——所有原子同等被消耗。气体激光器常见的**非均匀加宽（inhomogeneous broadening）**则相反：多普勒效应使不同速度的原子贡献不同频率的增益，一束光只饱和与它共振的那群原子，增益谱上烧出一个凹陷，叫**烧孔（spectral hole burning）**。

$$
g_{\text{inhom}} = \frac{g_0}{\sqrt{1 + I/I_s}}
$$

均匀与非均匀两种介质的饱和规律对比如下：

| 特征 | 均匀加宽 | 非均匀加宽 |
| --- | --- | --- |
| 饱和后的增益 | $g = g_0/(1 + I/I_s)$ | $g = g_0/\sqrt{1 + I/I_s}$ |
| 单束光的影响 | 饱和整个增益谱 | 只烧穿与它共振的原子群 |
| 典型介质 | 固体、半导体 | 低压气体（氦氖、CO₂） |
| 多个纵模 | 互相竞争抢同一群原子 | 可各自「各烧各的孔」共存 |

**辨析｜易错点：均匀加宽介质里「强者通吃」，非均匀加宽介质里「各有山头」。** 均匀加宽中，一旦某个纵模率先起振、把增益饱和到阈值，其他纵模就没有增益可用了——激光倾向于单纵模运转；非均匀加宽中，各纵模只与自己那组原子互动，可以同时共存多纵模。这是激光器「单模/多模」行为差异的根源之一。<span class="marginnote">均匀加宽介质的「模态竞争」在锁模、单频激光里尤其重要：要做出单纵模激光，均匀加宽介质比非均匀加宽更省力。反过来，非均匀加宽的多纵模共存正是《锁模与超短脉冲》能用一簇纵模合成脉冲的前提——两种介质在后续各篇还会反复出场。</span>

## 3 稳态条件：增益被「钳制」在阈值
激光器稳定振荡时，腔内光强恒定，意味着**每个往返增益恰好等于损耗**，增益系数被钳制在阈值增益：

$$
g = g_{th} = \alpha + \frac{1}{2L}\ln\frac{1}{R_1 R_2}
$$

把饱和公式 $g = g_0/(1 + I/I_s)$ 代入，解得腔内光强：

$$
I = I_s\left(\frac{g_0}{g_{th}} - 1\right)
$$

**只要泵浦高于阈值（$g_0 > g_{th}$），腔内就有光强 $I > 0$；泵浦越强，$g_0$ 越大，光强越高，但增益始终钉在 $g_{th}$ 不动。** 这就是激光器的稳态图景：泵浦决定了「有多少光」，阈值决定了「增益停在哪儿」。<span class="marginnote">增益钳制解释了激光的「自限」特性：即使泵浦疯狂加大，反转也不会无限增长，因为多余的能量全部转化为更强的光。这也是为什么激光输出功率可以做到千瓦、万瓦而不失控——每一点超额泵浦都变成了输出，而不是积累在介质里。</span>

## 4 公式解析：输出功率与最佳透射率
稳态光强已知，输出功率就出来了。设输出镜透射率为 $T$（另一面镜全反），束腰截面面积为 $A$，腔长 $L$，单程内部损耗 $\alpha$，则输出功率为：

$$
P_{out} = \frac{1}{2} A I_s\, T\left(\frac{2 g_0 L}{2\alpha L + T} - 1\right)
$$

三步拆解：

- **第一步，看分子**：$2g_0 L$ 是往返小信号增益，$2\alpha L + T$ 是往返总损耗（内部损耗加输出透射）。比值 $2g_0L/(2\alpha L + T) > 1$ 是激光能起振的前提，也正是「$g_0 > g_{th}$」的另一种写法。
- **第二步，看整体结构**：$T$ 在外头乘、又在分母里加——$T$ 既是输出通道，也是损耗来源。$T$ 太小，光出不来；$T$ 太大，损耗过高、腔内光强被压低，输出反而变小。**必然存在一个最优透射率 $T_{opt}$**。
- **第三步，求最优值**：对 $P_{out}$ 关于 $T$ 求极值，得

$$
T_{opt} = \sqrt{2 g_0 L \cdot 2\alpha L} - 2\alpha L
$$

代入功率公式即得最大输出功率。$T_{opt}$ 的物理含义是：**让「内部损耗」与「输出损耗」恰好相配**——内部损耗大的腔需要更大的输出耦合来匹配，内部损耗小的腔则用小输出镜、让光在腔内多走几趟充分提取。

**最佳透射率不是拍脑袋定的，而是让输出损耗与内部损耗「匹配」的平衡点。** 实际激光器常取略低于 $T_{opt}$ 的值，以降低阈值、换取更稳的单模运转。<span class="marginnote">一个工程直觉：增益高、腔长的激光器（如大功率固体激光）内部损耗相对小，$T_{opt}$ 可取 10%–30%；增益低、单模要紧的激光器（如氦氖）输出镜透射率常常只有 1%–2%，让微弱增益能攒够阈值。参数表上的「输出耦合 5%」「输出镜 R=98%」都是这么来的。</span>

## 5 从稳态到动态
增益饱和给我们的是一幅**静态**图景：稳态功率、稳态增益。但真实激光器经常要「动起来」——瞬间把阈值抬高再放下来（调 Q），或者把相位锁定成脉冲（锁模）。这两种动态操作，本质都是在主动摆弄「增益 vs 损耗」这个平衡：

- **调 Q**：先让损耗极高、阻止振荡，泵浦把反转攒到远高于阈值，再瞬间降低损耗，把积累的能量一次性释放成巨脉冲。
- **锁模**：让所有纵模相位锁定，把连续稳态输出「折叠」成极短的脉冲序列，脉冲峰值功率可以高出平均功率几个数量级。

这两条路都建立在增益饱和建立的稳态之上——没有稳态，就谈不上「偏离稳态」。下一篇，我们从**调 Q**开始。

## 6 术语速查表
| 术语 | 含义 |
| --- | --- |
| 小信号增益 $g_0$ | 弱光、无饱和时的增益系数 |
| 饱和光强 $I_s$ | 增益降为一半所对应的光强 |
| 均匀加宽 | 全体原子共享谱线、整体饱和 |
| 非均匀加宽 | 原子群各自共振、局部烧孔 |
| 烧孔 | 非均匀加宽中增益谱上的饱和凹陷 |
| 阈值增益 $g_{th}$ | 增益恰好等于损耗的临界值 |
| 增益钳制 | 稳态下增益被钉在阈值不动 |
| 输出耦合 | 输出镜透射率 $T$ |
| 最佳透射率 $T_{opt}$ | 使输出功率最大的透射率 |
| 内部损耗 $\alpha$ | 除输出耦合外的腔内单程损耗 |

## 7 小结
- 增益饱和是激光器自我调节的机制：光强 $I$ 使增益按 $g = g_0/(1 + I/I_s)$（均匀加宽）或 $g_0/\sqrt{1 + I/I_s}$（非均匀加宽）下降。
- **饱和光强 $I_s$** 是介质内禀参数，光强达到 $I_s$ 时增益减半。
- 均匀加宽饱和整条增益线、模态竞争激烈；非均匀加宽只烧孔、多纵模可共存。
- 稳态时增益被钳制在阈值 $g_{th}$，腔内光强 $I = I_s(g_0/g_{th} - 1)$。
- 输出功率 $P_{out} = \frac{1}{2}AI_s T(2g_0L/(2\alpha L + T) - 1)$，**最佳透射率 $T_{opt} = \sqrt{2g_0L\cdot 2\alpha L} - 2\alpha L$**。
- 均匀加宽介质模态竞争激烈、倾向单模；非均匀加宽各模各烧各的孔、可以共存。
- 稳态激光器的增益永远等于损耗，泵浦只决定输出功率、不改变增益。
- 饱和光强 $I_s$
