## 为什么从 Trajectory Transformer 开始

Decision Transformer 并不是「序列建模 RL」的唯一化身。

与它同年（2021）出场的 **Trajectory Transformer（Trajectory Transformer, Janner 等）** 走了另一条路：DT 把「目标」写进条件、只预测动作；Trajectory Transformer 把**整条轨迹**都当成要预测的序列——状态、动作、奖励全是 token，学一个完整的轨迹生成模型，推理时用束搜索（beam search）做规划。

这一课对照这两个「序列建模 RL」的代表作，看清同一个工具箱能拼出多么不同的两张脸。<span class="marginnote">Janner, Li, Levine, "Offline Reinforcement Learning as One Big Sequence Modeling Problem"（NeurIPS 2021）。它把 RL 全面转译成「轨迹 = 一句话、策略 = 补全、规划 = 搜索」，是理解 DT 最佳坐标。</span>

## 1 Trajectory Transformer：把整条轨迹当文本

**Trajectory Transformer（TT）**：把一条轨迹按维度拆散成 token 序列，训练一个自回归 Transformer 来拟合整条轨迹的密度模型，再用束搜索在「数据支持域内」挑选高回报的动作。

token 化的方式与 DT 有一个关键差别：**TT 连状态与奖励也要预测，而且按「逐维度」离散化**——每个连续量的每一维（位置的 x、y、z，速度的 vx 等）都被量化成 256 个 bin 之一，变成离散 token。

于是一条轨迹长这样：

$$
\tau = \left( s^1_t, s^2_t, \dots, a^1_t, \dots, r_t,\ s^1_{t+1}, \dots \right)
$$

模型的任务是对整条轨迹做最大似然：$p_\theta(\tau) = \prod p_\theta(\text{token}_i \mid \text{token}_{<i})$。

**预测目标不再只是动作，而是「下一个出现的任何东西」**——这需要模型同时学会环境动力学、奖励函数与行为策略。<span class="marginnote">逐维度离散化的动机是让自回归模型能处理连续量：把连续值切到离散 bin 后，交叉熵损失直接可用，而且模型对「值域边界」天然具备表达能力。代价是 bin 粒度带来的量化误差。</span>

## 2 一个数值例子：逐维度离散化长什么样

拿一个二维状态举个最小的例子。

设某个状态的 x 分量是 1.37、y 分量是 -0.52，动作是 0.08，奖励是 2.0。

TT 的做法是把每个量各自映射到 bin 序号：

$$
x = 1.37 \mapsto [i_x], \qquad y = -0.52 \mapsto [i_y], \qquad a = 0.08 \mapsto [i_a], \qquad r = 2.0 \mapsto [i_r]
$$

其中每个 $[i_\cdot]$ 都是 0~255 之间的整数（256 个 bin 之一）。

于是「时刻 $t$ 的这一行状态」在序列里占几个 token 位置，取决于状态与动作的维数——比如「二维状态 + 一维动作 + 奖励」就是 $2 + 1 + 1 = 4$ 个 token。

**一个时间步的轨迹，在 TT 眼里是好几个 token；在 DT 眼里是加和后的一个位置**——这个「时间步的粒度」差异，是两者结构哲学的第一个分歧点。

离散化的直接后果是**量化误差**：bin 越大，token 越少但信息越粗；bin 越小，信息越细但序列越长、训练越贵。

TT 论文用的 256 个 bin 是一个「精度与成本的折中」。<span class="marginnote">对照 DT：DT 用连续值线性嵌入，理论上精度更高，却要求动作是「可回归」的（MSE 或高斯分布）；TT 用离散交叉熵，对「多峰动作分布」更宽容。两者各让了一步。</span>

## 3 推理：束搜索式的规划

训练出一个「会说话」的轨迹生成模型后，**用**它有两种方式，TT 论文两者都试。

1. **纯规划（planning）**：给定当前状态，用束搜索展开多条未来轨迹，选出「期望奖励最高的动作」执行——这相当于在模型的「想象」里做价值评估，**价值来自密度模型，而不是独立的 $Q$ 网络**。
2. **行为克隆式**：把过去轨迹喂进去，直接续写当前动作。

关键的**约束动作（constrained actions）**思想与 BCQ 一脉相承：束搜索产生的候选动作，都来自模型学到的「数据里会怎么走」的分布，**永远不会跳出数据支持域**——分布外的高估风险被生成模型天然屏蔽。

**「规划」在这里不再是「在一张环境模型上滚动」，而是「在一条学过的文本上续写并择优」。**<span class="marginnote">对比 BCQ：BCQ 用条件 VAE 圈住动作空间，TT 用自回归密度模型圈住动作空间——工具不同，哲学相同：「别碰数据没说过的话。」</span>

束搜索的实现细节值得一提：TT 在展开时并行维护多条候选轨迹（束），每步对每条候选展开若干动作分支，按「累计奖励」截断保留 top-$b$ 条。

**这等于把「规划」实现成了「在生成分布上做宽度优先的择优」**——它不依赖任何显式动力学模型，也不依赖 $Q$ 函数，唯一的「知识」是轨迹的文本分布。

## 4 与 DT 的同框对比

两个「序列建模 RL」代表并排，差异立刻分明：

| 维度 | Decision Transformer | Trajectory Transformer |
| --- | --- | --- |
| 预测对象 | 只预测动作 | 状态、动作、奖励全预测 |
| 轨迹表示 | 每步 (RTG, s, a) 三 token，连续量用线性嵌入 | 每维离散 bin token，全序列 |
| 目标信息 | 外置条件 $\hat{R}_t$（目标写进输入） | 在生成的奖励 token 里隐式涌现 |
| 推理 | 条件续写动作，按 $\hat{R}_{t+1} = \hat{R}_t - r_t$ 修正 | 束搜索规划，选期望奖励最高的动作 |
| 价值来源 | 无（条件密度直接给策略） | 由轨迹密度模型的想象给出 |
| 与 RL 的距离 | 近于条件 BC | 近于「模型 + 规划」的现代 MPC |

**一句话概括分水岭**：DT 是「**条件生成**」——目标在输入端，直接产动作；TT 是「**生成 + 搜索**」——先学会轨迹的完整分布，再用搜索从分布里挑好结果。

两者共享「序列建模」的骨架，却在「目标怎么进入模型」上分道扬镳。<span class="marginnote">这两条路后来演化为两大谱系：以 DT/RvS 为代表的条件生成系，与以 TT/GPT-Dynamics 为代表的「学习动力学再规划」系。理解这个谱系，才能读懂后续 Online Decision Transformer 改良的落点。</span>

## 5 公式解析：两条目标函数的对照

把两个模型的训练目标并排，差异是数学级的：

$$
\underbrace{\max_\theta \sum_{t} \log \pi_\theta\!\left( a_t \mid \hat{R}_t, s_t, \dots \right)}_{\text{DT：只对动作位置做 MLE}}
\qquad
\underbrace{\max_\theta \sum_{i} \log p_\theta\!\left( x_i \mid x_{<i} \right)}_{\text{TT：对全部 token 做 MLE}}
$$

三步拆解。

**第一步，看求和范围**：DT 的求和跑在「动作位置」上，状态与返回目标是给定的输入；TT 的求和跑在「每一个 token」上，状态与奖励也是被预测的输出。

**TT 要学的分布更全面，也因此更吃力**——它必须同时拟合动力学与奖励。

**第二步，看目标怎么进来**：DT 的目标是**显式外置**（$\hat{R}_t$ 写在条件里，离线算出）；TT 的目标是**隐式涌现**（奖励作为 token 被生成，束搜索靠「想象出的奖励」择优）。

外置显式、涌现隐式——这是两种「目标进入模型」的根本路线。

**第三步，看各自的代价**：DT 省事，但把「目标」丢给超参 $g$，条件不可靠时乏力；TT 的束搜索等于在生成分布上做隐式的价值估计，**能自然处理长程奖励结构，却要付离散化误差与搜索开销**。

两者都以「避开分布外查询」为代价，换掉了传统 $Q$ 学习的整套装置。

## 6 小结

- **TT** 把整条轨迹按维度离散成 token，学全序列密度模型，推理用束搜索规划。
- **离散化的粒度**是精度与序列长度的折中：256 bin 是 TT 的默认答案，代价是量化误差。
- **TT 的「约束」** 与 BCQ 同源：动作候选来自数据分布，分布外高估被天然屏蔽。
- **分水岭**：DT 是条件生成（目标在输入端），TT 是生成 + 搜索（目标在想象里涌现）。
- **代价对照**：DT 省、依赖条件；TT 全、付离散化与搜索开销。
- **谱系**：条件生成系（DT/RvS）vs 动力学规划系（TT/GPT-Dynamics），两条路此后各自生长。
