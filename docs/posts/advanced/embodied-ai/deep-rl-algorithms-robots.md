## 为什么从三大算法开始

机器人深度 RL 的实践基本被三个算法统治：**PPO**（在策略、稳定、适合并行仿真）、**TD3**（离策略、确定性、样本高效）、**SAC**（离策略、随机、最大熵）。
它们共享 actor-critic 骨架，
却在「用不用历史数据」「探索怎么来」上分道扬镳——**理解何时用哪个，等于理解了 on/off-policy 与样本效率**<span class="marginnote">三篇论文都出自 2015–2018 的深度 RL 黄金期：TD3（2018，
富士山/AAAI）、SAC（2018，
Haarnoja）、PPO（2017，
OpenAI）。
十年来它们是机器人 RL 的「御三家」，
几乎所有仿真-真机流水线都跑在这三套上。
</span>。

## 1 三大算法的谱系

所有现代深度 RL 都是 **actor-critic** 结构：

- **actor（策略）** $\pi_\theta(a\mid s)$：决定怎么动；
- **critic（价值）** $Q_\phi(s,a)$：估计「这个动作多好」。

按「数据怎么用」分两类：

- **在策略（on-policy）**：只用**当前策略**产生的数据更新，
更新完数据作废。
稳定（数据分布始终匹配），
但样本效率低。
- **离策略（off-policy）**：用**历史数据**（回放缓冲）反复更新。
样本效率高，
但有分布偏移风险（数据不全是当前策略产生的）。

**样本效率的差异决定了机器人的用法**：真机交互贵，
离策略能吃更多数据；
仿真并行便宜，
在策略也能堆出样本。

## 2 PPO：裁剪让更新别太猛

**PPO（Proximal Policy Optimization）** 是在策略算法的代表，
核心是**裁剪的代理目标（clipped surrogate objective）**：

$$L^{CLIP}(\theta) = \mathbb{E}\Big[ \min\big( r_t(\theta) A_t,\; \mathrm{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\, A_t \big) \Big]$$

其中 $r_t(\theta)=\pi_\theta(a_t\mid s_t)/\pi_{\theta_{old}}(a_t\mid s_t)$ 是新旧策略的动作概率比。

- **直觉**：想让策略朝「优势大的动作」更新，但**限制每步更新幅度**（比例在 $[1-\epsilon,1+\epsilon]$ 内），防止一步把策略改崩；
- **好处**：不需要 TRPO 那套复杂的 KL 约束计算，稳定且调参友好。

**用法**：PPO 在 **Isaac Gym 等 GPU 并行仿真**里是默认选择——上万并行环境让「样本效率低」不再是问题，稳定性和鲁棒性才是王道。<span class="marginnote">并行仿真的范式：<strong>PPO 的缺点（样本效率）被并行算力「物理性」解决</strong>——一万个并行环境一分钟产出百万步经验，PPO 稳定地吃掉它。所以「仿真学动作，PPO 永远正确；真机学动作，PPO 常常太慢」。</span>

## 3 TD3 与 SAC：离策略、样本高效

**TD3（Twin Delayed DDPG）** 修复 DDPG 的**价值高估**问题：

- **双 critic 取最小值**：两个 Q 网络都估，取较小的——抵消系统性高估；
- **目标策略平滑**：目标动作加噪声，避免 Q 对动作「尖峰」敏感；
- **延迟更新**：actor 比 critic 更新慢，保证 critic 先学稳。

**SAC（Soft Actor-Critic）** 走最大熵路线：

$$J(\pi) = \mathbb{E}\Big[ \sum_t \gamma^t \big( r_t + \alpha\,\mathcal{H}(\pi(\cdot\mid s_t)) \big) \Big]$$

- 在回报上加**熵奖励** $\alpha\mathcal{H}(\pi)$——鼓励策略保持随机，**探索与鲁棒性天然内置**；
- 随机策略 + 最大熵 → 更不容易卡局部最优、对扰动更稳。

**两者都用回放缓冲（replay buffer）**：过去的交互反复学习，
样本效率远超 PPO——这是真机 RL 能「跑几千步就学会一个动作」的原因。

## 4 机器人应用的选型

工程上三条主流路线：

- **仿真规模化：PPO**。
Isaac Gym 里上万环境并行训练四足、灵巧手，
学好后 Sim2Real 迁移（第 15 章）；
- **真机直接学：SAC/TD3**。
几千步内学会简单动作（倒立摆、机械臂到达），
配合自动复位装置；
- **混合**：仿真 PPO 学粗动作 → 真机 SAC 微调。**最实用的工业配方**。

**关键现实**：不管算法多好，
真机 RL 的成功率由**奖励塑形、自动复位、安全监控**决定——「一跑一晚上，
天亮看曲线」是常态。
<span class="marginnote">一个反直觉事实：<strong>真机 RL 里「自动复位装置」的功夫常常比算法本身多</strong>——每 10 步失败要 5 秒复位，
几千步的训练里复位时间占比极高。
研究 demo 里的「神速学习」，
一半是复位系统的功劳。
</span>

## 5 公式解析：SAC 的目标函数

$$
J(\pi) = \mathbb{E}_{s,a}\Big[ Q^\pi(s,a) + \alpha\,\mathcal{H}\big(\pi(\cdot\mid s)\big) \Big], \qquad \mathcal{H}(\pi(\cdot\mid s)) = -\mathbb{E}_a\big[\log\pi(a\mid s)\big]
$$

- **第一步，看熵项**：$\mathcal{H}$ 是策略分布的熵——随机性越大熵越高。**SAC 不只最大化回报，还最大化「每个状态下的随机性」**
  - **第二步，看 $\alpha$**：熵系数权衡「追求回报」与「保持随机」。$\alpha$ 大 → 更爱探索、更鲁棒但可能不收敛到最优；$\alpha$ 小 → 更贪回报。
现代 SAC 把 $\alpha$ 也自适应调整。
- **第三步，看随机策略的收益**：随机性 = 天然探索 + 对模型误差的鲁棒性——**同样一个策略，SAC 学出来的分布比确定性策略在真机上更稳**（遇到扰动时不会「一条道走到黑」）
  - **第四步，看与 TD3 的差异**：TD3 是**确定性**策略 + 目标平滑
  SAC 是**随机**策略 + 最大熵
  确定性策略逼近极限时抖动，
随机策略更平滑——**两者样本效率相近，鲁棒性 SAC 更优，确定性任务 TD3 更直白**。
## 6 辨析｜在策略 vs 离策略；探索与利用

**辨析｜易错点一：离策略不是「免费午餐」。** 回放缓冲里的旧数据与当前策略分布不一致，
会造成**分布偏移**——离策略算法都带「修正」（TD3 的双 critic、SAC 的重要性权重处理）来缓解，
但数据过旧时仍可能学坏。**回放缓冲清空/更新策略也是工程操作**。
<span class="marginnote">选型铁律：<strong>仿真并行充足 → PPO（稳定优先）；
样本贵/真机 → SAC/TD3（效率优先）</strong>。
别在真机上跑 PPO 指望几千步收敛，
也别在超大仿真上跑 SAC 浪费并行资源。
</span>

**辨析｜易错点二：探索不是「加噪声」这么简单**。
动作噪声（ε-greedy、OU 噪声）是**动作空间**探索，
但 RL 需要的是**状态空间**探索——「去过没去过的地方」。
SAC 的熵奖励、PPO 的随机策略都在做后者。**只加动作噪声、不加状态探索，学出来的策略「看起来很动」但其实没见过世界**。

**再辨析｜PPO 的裁剪不是「越小越稳」**。
$\epsilon$ 太小更新太慢、探索停滞；
$\epsilon$ 太大失去裁剪意义。
工程默认 $\epsilon\approx0.2$，
但**对机器人类的高维连续控制，常需要更小 $\epsilon$ + 更大 batch** 才稳——「默认超参 ≠ 最优超参」在 RL 里尤其成立。

## 7 小结

- **PPO**：在策略、裁剪代理目标、稳定、适合 GPU 并行仿真。
- **TD3**：双 critic 取小 + 目标平滑 + 延迟更新，
修 DDPG 高估，
确定性。
- **SAC**：最大熵 + 随机策略，
探索与鲁棒性内置，
样本高效。
- **选型**：仿真并行 → PPO；
真机/样本贵 → SAC/TD3；
混合 = 仿真 PPO + 真机 SAC。
- 真机 RL 的成功率由奖励、复位、安全决定——算法只是必要条件。
