# RT-2：视觉-语言模型的动作化迁移

## 为什么从 RT-2 开始

RT-1 证明了「真实数据 + Transformer」能学操作；**RT-2** 再进一步：**把互联网级的大视觉-语言模型（VLM）「变成」机器人策略**。
它的洞察极富想象：**机器人动作只是一串特殊的 token——那为什么不直接让 VLM 输出它？** 于是 RT-2 让 VLM 在「互联网知识 + 机器人数据」上联合微调，
动作变成模型输出的文本 token。
互联网知识随模型一起迁移，
机器人获得了「没见过也大概会做」的语义泛化<span class="marginnote">RT-2 的论文标题叫《RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control》——「Web 知识转移到机器人控制」。
它把具身智能带进「预训练大模型时代」：<strong>不再从零学机器人，
而是让「已经懂世界的模型」学会动</strong>。
</span>。

## 1 核心思想：动作只是另一串 token

RT-1 的动作 token 还局限在「机器人专用」的离散 bin；
RT-2 的关键跨越是——**动作 token 用文本表示，和 VLM 的输出 token 完全同构**：

- 末端位移、旋转、夹爪状态**离散化后编码成文本 token**（如 `action: [0.1, -0.2, 0.3, ...]`）；
- 模型的输出空间 = VLM 原本的文本词表 + 动作 token；
- **整个网络就是一个（微调过的）大 VLM**——它既会「看图说话」，
也会「看图出动作」。

于是**互联网学到的视觉-语言知识**（物体长什么样、物体之间什么关系、指令怎么理解）**自动参与动作预测**。
RT-2 不再「从零学抓杯子」，
而是「一个懂杯子是什么的模型，
学习如何把这种理解变成动作」。

## 2 联合微调：机器人数据 + Web 数据

RT-2 的训练是**联合（co-finetuning）**：

- **机器人数据**：RT-1 数据集（13 万条真实示范）——教模型「具体怎么动」；
- **Web 规模 VLM 数据**：图像-文本对（物体识别、视觉问答）——保「懂世界」的能力不退化。

两者混在同一个序列建模目标里：**一段数据是「看图 → 描述文字」，另一段是「看图 → 输出动作 token」**——同一个 Transformer，
两种输出，
联合学习。
这防止了「只学机器人数据导致世界知识遗忘」（灾难性遗忘）的问题。

## 3 结果：语义泛化的跃迁

RT-2 相对 RT-1 的核心提升在**泛化**：

- **未见任务**：成功率约为 RT-1 的 **3 倍**；
- **涌现行为（emergent capabilities）**：模型从互联网知识「涌现」出没有直接训练过的能力——比如把「香蕉放到某个物体上」泛化到从未见过的物体组合；
- **符号理解**：模型能理解「把图里的东西分类」「推理物体关系」再执行动作——**「推理」与「动作」在同一个模型里耦合**。

**为什么泛化强**：RT-1 只见过机器人数据（有限任务）；
RT-2 的底座见过**整个互联网**——「杯子」「香蕉」「放在上面」这些概念在预训练里已经牢牢掌握，
微调只是教它「把这些概念翻译成动作」。
<span class="marginnote">RT-2 的「涌现」最有名的例子：模型被问到「把可乐罐挪到写着'可口可乐'的图片上」这类需要<strong>阅读图片文字 + 理解动作语义</strong>的任务——它在没有直接训练过的情况下做到了。
这被解读为「视觉-语言知识在动作空间的迁移」的直接证据。
</span>

## 4 公式解析：动作 token 化与联合目标

$$
\mathcal{L} = \sum_{(I, x) \in \mathcal{D}_{robot}} \mathrm{CE}\big( y_{action}, p_\theta(\cdot \mid I, x_{inst}) \big) + \sum_{(I, y) \in \mathcal{D}_{web}} \mathrm{CE}\big( y_{text}, p_\theta(\cdot \mid I) \big)
$$

- **第一步，看机器人项**：输入图像 $I$ 与指令 $x_{inst}$，
模型输出动作 token $y_{action}$，
交叉熵训练——**动作被当作「文本」预测**。
- **第二步，看 Web 项**：输入图像 $I$，
模型输出文字描述 $y_{text}$——**保住 VLM 原有的语言/视觉能力**。
- **第三步，看两项的协同**：机器人项学「动作翻译」，
Web 项保「世界知识」。**联合训练 = 让同一个参数空间同时装下「懂世界」与「会动作」**。
- **第四步，看动作 token 的粒度**：动作离散成 bin（RT-1 遗产），
bin 越细动作越精但分类越难。**RT-2 是「高层动作」**——输出末端意图，
底层控制器执行——和 RT-1 同构。

## 5 辨析｜RT-2 vs RT-1；动作-as-文本 vs 专用动作头

**辨析｜易错点一：RT-2 不是 RT-1 换个大模型，是「知识来源」的质变。** RT-1 的知识只来自机器人数据；
RT-2 的知识来自**互联网**（物体概念、关系、指令理解）——**差距在「没训练过的东西会不会」**：RT-1 只会「见过组合」，
RT-2 会「没见过的组合 + 推理」。
<span class="marginnote">一个关键理解：<strong>VLA 的「智能」主要在预训练，
不在机器人微调</strong>。
微调只教「把知识翻译成动作」，
知识本身在 Web 预训练里。
所以「预训练数据规模」比「机器人微调数据量」更能预测 VLA 的泛化——这也是 RT-2 用 55B 模型的原因。
</span>

**辨析｜易错点二：动作-as-文本有得有失。** 好处：复用 VLM 的一切（架构、训练、知识）；
代价：**文本 token 表达连续动作有精度损失**（bin 化），
且「动作」与「语言」共享词表可能互相干扰。**用 VLM 的文本空间存动作 = 换泛化、让精度**——这是 VLA 路线至今的核心权衡。

**再辨析｜RT-2 是「端到端」但不是「低层控制」**。
RT-2 输出的是**高层动作意图**（末端目标、运动方向），
不是关节力矩——**底层是阻抗/位置控制**。
VLA 负责「做什么」，
低层控制负责「怎么稳定做到」。
「端到端」指「感知到动作意图端到端」，
不指「感知到关节力矩」。

## 6 小结

- **RT-2** = 大 VLM（PaLI-X/PaLM-E 底座）+ 动作 token 化为文本，
联合微调。
- **核心洞见**：动作是另一串 token——互联网知识自动参与动作预测。
- **联合训练**：机器人数据（会动）+ Web 数据（懂世界），
防灾难性遗忘。
- **结果**：未见任务成功率约为 RT-1 的 3 倍，
涌现「推理 + 动作」的耦合能力。
- VLA 的智能在预训练不在微调；
动作-as-文本换泛化让精度；
RT-2 是高层动作、低层控制兜底。
