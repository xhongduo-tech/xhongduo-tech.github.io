## 为什么从阻抗控制开始

位置控制假设「环境是硬的、任务是无接触的」。
但打磨、装配、拖拽、人机协作，
任务本质是**接触**——机器人必须与环境交换可控的力。**阻抗控制（impedance control）** 由 Neville Hogan 在 1985 年奠定：不直接控制力，
而是控制**力与运动之间的关系**——让机器人对接触表现成「可编程的弹簧-阻尼-质量」。
它把「刚性位置控制」换成「柔性交互控制」，
是现代力控与人机协作的基石<span class="marginnote">Hogan 的洞见是：机器人与环境交互时，
不能既硬性指定位置又硬性指定力（两者在接触处冲突）。
所以干脆控制「阻抗」——<strong>运动到力的动态映射</strong>，
让机器人「弹着」应付接触，
任务自然稳定。
</span>。

## 1 位置控制与接触的冲突

纯位置控制器的行为像**无穷刚度弹簧**：轨迹是刚性的，
一旦接触被障碍物顶住，
位置误差迅速拉大，
控制器输出无穷大的力去「硬闯」——接触力尖峰、机构过载、甚至损坏工件。

**接触任务的本质矛盾**：位置精度与接触力不可兼得——想要位置精确就得刚性，
想要力温和就得柔顺。**阻抗控制在这个矛盾里取平衡**：让机器人像弹簧一样「可以推得动」，
但推多少、回多少由你设定。

## 2 阻抗控制：把机器人变成质量-弹簧-阻尼

**阻抗控制律**（笛卡尔空间，
$x$ 为末端位姿）：

$$F_{cmd} = M_d\,(\ddot x_d - \ddot x) + B_d\,(\dot x_d - \dot x) + K_d\,(x_d - x)$$

- $K_d$：**期望刚度**——位置偏了往回拉的力；
$K_d$ 大 = 刚性任务，
$K_d$ 小 = 柔顺任务；
- $B_d$：**期望阻尼**——抑制振荡，
让接触后不来回抖；
- $M_d$：**期望惯量**——接触瞬态时「让多少」；
- 通过**力雅可比**转成关节力矩：$\tau = J^T F_{cmd} + \text{动力学前馈}$。

**关键**：不直接设「接触力多大」，
而是设「遇到外力时怎么反应」。
当机器人被推离 $x_d$，
阻抗控制器像弹簧一样往回拉——**力 = 刚度 × 偏差**，
接触力自动被限制在「弹簧力」的量级，
不会尖峰。
<span class="marginnote">直觉：把机械臂末端想象成「一根你可以设定硬度的弹簧」。
打磨时把弹簧调软（顺着工件表面走），
插孔时把弹簧调硬（保持位置）再沿孔轴方向调软。
阻抗控制就是这根可编程弹簧。
</span>

## 3 导纳控制：位置控制臂也能力控

**导纳控制（admittance control）** 是阻抗的对偶：**测力，反算运动**。

$$x_c = x_d + \int\!\!\int M_d^{-1}\big(F_{cmd} - B_d\Delta\dot x - K_d\Delta x\big)\,dt$$

- 用**力/力矩传感器**测量接触力，
经「导纳滤波器」产生位置/速度修正量，
送给底层位置控制器执行；
- 它天然适合**位置控制型**工业机械臂——外挂一个力控环，
把「该往哪动」算出来，
底层照样跑位置环。

**阻抗 vs 导纳的分工**：

| 维度 | 阻抗控制 | 导纳控制 |
| --- | --- | --- |
| 驱动 | 力矩源（直接输出力） | 运动源（输出位置/速度） |
| 测量 | 运动（位置/速度） | 力（F/T 传感器） |
| 适用 | 力矩控制型机器人 | 位置控制型机器人 |
| 接触刚性环境 | 需低阻抗防振荡 | 较稳（内层位置环） |

## 4 公式解析：阻抗定律的每一项

$$
F_{cmd} = M_d\,\ddot{\tilde x} + B_d\,\dot{\tilde x} + K_d\,\tilde x, \qquad \tilde x = x_d - x
$$

- **第一步，看 $\tilde x$（位置偏差）**：偏差 $\tilde x$ 是「想要的」与「实际的」差。
阻抗定律说：**输出力是偏差及其导数的线性组合**——这就是「弹簧-阻尼-质量」模型的力表达。
- **第二步，看稳态**：静止接触时 $\dot{\tilde x}=\ddot{\tilde x}=0$，
$F_{cmd}=K_d\tilde x$——**稳态接触力 = 刚度 × 位置偏差**。
想要「顶 10 N 的力」，
就设 $K_d$ 使偏差达到对应值。
- **第三步，看瞬态**：$B_d$ 项在接触瞬间吸收冲击（阻尼耗能），
$M_d$ 项决定「多快反应」。**$B_d$ 太小会振荡，$M_d$ 太小会「撞上去很冲」**——三者按二阶系统整定。
- **第四步，看与位置控制的统一**：$K_d\to\infty$、$B_d\to\infty$ 时阻抗控制退化为位置控制；**阻抗是位置控制的推广**——位置控制是阻抗控制的一个极端点。

## 5 辨析｜阻抗 vs 导纳；接触稳定性；柔顺方向

**辨析｜易错点一：阻抗需要力矩控制，导纳需要力测量。** 阻抗直接输出力矩，
装不了 F/T 也能做（用模型估计外力），
但要求底层是力矩接口；
导纳必须有 F/T 测量，
但底层随便什么位置环都行。**选型看你的硬件**：力矩控制臂 → 阻抗，
工业位置臂 → 导纳。
<span class="marginnote">实务上还有个混合选择：<strong>垂直方向用阻抗（接触力可控），
水平方向用位置（跟踪精确）</strong>——把任务空间按方向拆开，
各用各的控制，
这就是力/位混合控制的雏形（下一节）。
</span>

**辨析｜易错点二：阻抗控制接触刚性环境会不稳定。** 若环境刚度远大于机器人期望刚度，
阻抗环与环境构成正反馈式振荡（弹簧-弹簧相互作用）。
对策：降低 $K_d$、加大 $B_d$、或改用导纳（位置环内层天然稳定）。**「越要贴紧刚性面，越要把阻抗调软」是反直觉但正确的经验**。

**再辨析｜阻抗控制 ≠ 力控制**。
阻抗控制的是「力-位置关系」，
不直接给定力值；
真要「保持恒定接触力」，
要用**力控制环**（力反馈 + 力误差调节）。
阻抗给柔顺，
力控给精确力——两类任务不同，
工具不同。

## 6 小结

- **接触任务**要求可控的力-运动关系，
纯位置控制会产生接触力尖峰。
- **阻抗控制**：$F = M_d\Delta\ddot x + B_d\Delta\dot x + K_d\Delta x$，
把机器人变成可编程弹簧-阻尼-质量。
- **导纳控制**：测力 → 算运动修正 → 位置环执行，
适合位置控制臂。
- **阻抗 = 力矩源 + 运动测量；导纳 = 运动源 + 力测量**——选型看硬件。
- 接触刚性环境要调软阻抗防振荡；
稳态接触力 = 刚度 × 偏差。

在下一节，
我们把柔顺控制推进到多方向：**力/位混合控制与操作空间控制（Operational Space Control）**——不同方向各用各的规矩。
