## 为什么从状态估计开始

机器人永远不知道自己在哪、动得多快——传感器有噪声，
运动有误差。**状态估计（state estimation）** 的任务是从噪声测量里递归地融合出状态的最优估计。
三大滤波器各守一摊：**卡尔曼滤波**管线性高斯、**扩展卡尔曼**管弱非线性、**粒子滤波**管多模态非高斯。
它们是定位、SLAM、VIO 的共同引擎<span class="marginnote">状态估计的哲学一句话：<strong>两种带噪声的信息源——运动模型的预测与传感器的测量——按各自的不确定度加权平均</strong>。
卡尔曼滤波给出的「权」就是著名的卡尔曼增益 $K$。
谁能把不确定性想清楚，
谁就掌握了状态估计。
</span>。

## 1 从贝叶斯滤波到卡尔曼滤波

设状态 $x_k$（位置、姿态、速度）、控制 $u_k$、测量 $z_k$。**马尔可夫假设**：当前状态只依赖上一状态与控制，
测量只依赖当前状态。
于是递归贝叶斯滤波给出后验

$$\mathrm{bel}(x_k) = \eta\, p(z_k \mid x_k) \int p(x_k \mid x_{k-1}, u_k)\, \mathrm{bel}(x_{k-1})\, dx_{k-1}$$

这个积分一般算不动。
但当**模型线性、噪声高斯**时，后验恒为高斯分布，只需传递均值与协方差——这就是**卡尔曼滤波（Kalman filter, KF）**，1960 年卡尔曼在矩阵形式下给出闭合解。

**线性高斯模型**：

$$x_k = A x_{k-1} + B u_k + w_k, \qquad z_k = H x_k + v_k$$

其中 $w_k \sim \mathcal{N}(0,Q)$、$v_k \sim \mathcal{N}(0,R)$ 分别是过程噪声与测量噪声。

## 2 卡尔曼滤波：预测 + 更新两步

KF 每时刻做两步：

**预测（predict）**——用运动模型推状态：

$$\hat x_k^- = A\hat x_{k-1} + B u_k, \qquad P_k^- = A P_{k-1} A^T + Q$$

**更新（update）**——用测量修正：

$$K = P_k^- H^T \big(H P_k^- H^T + R\big)^{-1}$$

$$\hat x_k = \hat x_k^- + K\big(z_k - H\hat x_k^-\big), \qquad P_k = \big(I - KH\big)P_k^-$$

**卡尔曼增益 $K$** 决定「信测量还是信预测」。测量噪声 $R$ 大 → $K$ 小 → 主要信预测；预测协方差 $P^-$ 大 → $K$ 大 → 主要信测量。<span class="marginnote">$z_k - H\hat x_k^-$ 叫<strong>新息（innovation）</strong>，是「测量与预测的差异」。KF 的更新本质是：把新息按增益加权加回去。没有新息（测量=预测）就不更新，这个直觉贯穿所有滤波器。</span>

## 3 扩展卡尔曼滤波：把非线性线性化

真实机器人几乎没有线性模型（旋转是三角函数、里程计是积分）。**扩展卡尔曼滤波（EKF）** 对非线性模型

$$x_k = g(x_{k-1}, u_k) + w_k, \qquad z_k = h(x_k) + v_k$$

在**当前估计处**做一阶泰勒展开，
用雅可比代替转移矩阵：

$$G = \frac{\partial g}{\partial x}\Big|_{\hat x_{k-1}}, \qquad H = \frac{\partial h}{\partial x}\Big|_{\hat x_{k}}$$

然后把 $A\to G$、$H$ 用线性化结果代入 KF 的框架。**结构与 KF 完全一样**，只是矩阵变成了雅可比。

代价是**线性化误差**：强非线性时，在均值处展开的一阶近似会明显失真，甚至发散。
缓解手段是迭代 EKF（IEKF）、无损变换（UKF），或直接用粒子滤波。

## 4 粒子滤波：不假设高斯，直接采样

**粒子滤波（particle filter, PF）** 不参数化分布，用一组带权重的**粒子** $\{(x_k^{[m]}, w_k^{[m]})\}$ 离散近似后验。标准流程（SIS）：

1. **采样（proposal）**：从提议分布（常用运动模型 $p(x_k\mid x_{k-1},u_k)$）为每个粒子采样新状态；
2. **加权（weighting）**：按测量似然 $w_k^{[m]} \propto w_{k-1}^{[m]}\, p(z_k\mid x_k^{[m]})$ 更新权重并归一化；
3. **重采样（resampling）**：按权重重新抽样粒子，扔掉权小的、复制权大的，防止「粒子退化」。

PF 不需要线性、不需要高斯，能表示**多模态**分布（机器人可能在这个房间也可能在那个房间）——全局定位与「绑架问题」（kidnapping）是它的经典主战场。
代价是**维度灾难**：高维状态空间需要海量粒子。

## 5 公式解析：卡尔曼增益在干什么

$$
K = P_k^- H^T \big(H P_k^- H^T + R\big)^{-1}
$$

- **第一步，看协方差怎么转**：$H P_k^- H^T$ 是「预测协方差投影到测量空间」；
加上测量噪声 $R$，得到**新息协方差** $S = H P_k^- H^T + R$——测量与预测总不确定度。
- **第二步，看交叉项**：$P_k^- H^T$ 是状态与测量之间的协方差，编码「状态的哪些分量能通过测量观测到」。
- **第三步，看增益的极限**：$R\to 0$（测量近乎无噪声）时 $K \to H^{-1}$，完全采信测量；
$P^-\to 0$（预测近乎完美）时 $K\to 0$，完全忽略测量。**增益就是两个不确定度的比值**。
- **第四步，理解闭合形式**：$K$ 是最小化后验协方差 $P_k$ 的最优加权。
因为高斯分布下「最优估计 = 条件期望」，而线性高斯下条件期望就是这种线性加权——**KF 是 MMSE/MAP 意义下最优的**。

## 6 辨析｜三个滤波器怎么选

**辨析｜易错点一：线性高斯才有 KF 的最优性。** 模型真线性且高斯时，KF 是最小均方误差最优；EKF 因线性化而**次优**，且强非线性可能发散；PF 只要粒子够多就逼近最优，但计算贵。

**辨析｜易错点二：EKF 的雅可比在「估计均值」处展开，单点近似。** 对高度非线性（如机器人接近奇异、测量函数严重弯曲），展开点本身误差大，线性化误差被放大。<span class="marginnote">经验法则：<strong>先问「后验是单峰吗」</strong>。单峰弱非线性 → EKF 足够；单峰强非线性 → UKF 或 IEKF；多模态/全局定位/绑架 → PF。维度一高（>10），PF 的粒子数爆炸，回头用 EKF/UKF 更实际。</span>

**再辨析｜噪声参数 Q、R 是工程核心。** 滤波器输出的置信度完全由 $Q,R$ 决定：$Q$ 设小了滤波器「过度自信」，会锁死在错估计上；$R$ 设小了会疯狂跟着测量抖。标定 $Q,R$ 用**一致性检验（NEES）**——统计滤波误差与协方差的匹配程度，这是判断「滤波器没调好」的科学方法，而不是看曲线好不好看。

## 7 小结

- **贝叶斯滤波**是母体：$\mathrm{bel}(x_k) = \eta\, p(z_k\mid x_k)\int p(x_k\mid x_{k-1},u_k)\,\mathrm{bel}(x_{k-1})$。
- **KF**：线性高斯闭合解，预测+更新两步，增益 $K$ 是最优加权。
- **EKF**：雅可比线性化非线性，结构同 KF，弱非线性够用、强非线性会发散。
- **粒子滤波**：采样+加权+重采样，能表示多模态，但高维有维度灾难。
- 选型看「后验是否单峰、非线性强弱」；
$Q,R$ 用 NEES 标定。
