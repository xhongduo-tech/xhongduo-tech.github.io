## 为什么从静力平衡开始

速度分析回答「末端怎么动」，
静力学回答「末端使多大的力」。
两件事被同一个雅可比矩阵绑定：**关节速度映射到末端速度用 $J$，末端力映射到关节力矩用 $J^T$**。
阿基米德的杠杆是最早的力-速度对偶：长臂省力费距离、短臂费力省距离，
力与位移的乘积守恒。
机械臂的雅可比就是一条多维、可变的杠杆。
<span class="marginnote">这一节是力控、抓取、遥操作力反馈的共同地基。
后面讲阻抗控制、力/位混合控制时，
几乎所有控制器最终都要落回 $\tau = J^T F$ 这个式子。
</span>

## 1 力雅可比：从末端力到关节力矩

在静力平衡下，
机械臂末端施加的**力旋量（wrench）** 记为 $F=(f,m)\in\mathbb{R}^6$，
其中 $f$ 是力、$m$ 是力矩。
要让机械臂保持平衡，
各关节必须提供合力矩向量 $\tau$。
二者的关系是

$$\tau = J^T F$$

$J$ 可以是空间或物体雅可比，
取决于 $F$ 表达在哪个坐标系——**雅可比与力旋量必须同一坐标系**，
这是最容易出错的地方。

先给直觉：**末端力在某个方向越大，能传递到各关节的力矩就越大；而末端在哪个方向「能用力」，取决于 $J$ 的行空间**。行空间与零空间互为正交补，这直接刻画了奇异时力与速度的此消彼长。

## 2 力-速度对偶性与虚功原理

对偶的严格推导来自**虚功原理（principle of virtual work）**：在静力平衡下，
关节虚位移 $\delta\theta$ 与末端虚位移 $\delta X$ 满足

$$\delta X = J\,\delta\theta$$

虚功相等：$\tau^T \delta\theta = F^T \delta X$。
代入 $\delta X$，
得 $\big(\tau - J^T F\big)^T \delta\theta = 0$ 对任意虚位移成立，
于是

$$\tau = J^T F$$

<span class="marginnote">注意方向：速度是 $J$ 左乘，
力是 $J^T$ 左乘——「转置」不是可有可无的记号，
正是它把两个互为对偶的向量空间（关节空间与任务空间）的度量联系起来。
这与线性代数里「线性映射与其伴随映射」的抽象关系完全一致。
</span>

**力-速度对偶性（force-velocity duality）** 可以总结为四条对应：

| 速度侧 | 力侧 |
| --- | --- |
| $V = J\dot\theta$ | $\tau = J^T F$ |
| 末端速度来自关节速度 | 关节力矩来自末端力 |
| 可达速度方向 = $J$ 的列空间 | 可传力方向 = $J$ 的行空间 |
| 奇异时失去某方向速度 | 奇异时失去某方向传力 |

在奇异位形，
$J$ 的列空间缩小，**速度方向丢失**；
同时 $J^T$ 的行空间缩小，**传力方向也丢失**——两者同时发生，
且丢失的方向互补。

## 3 公式解析：τ = J^T F

$$
\tau = J^T F, \qquad J = \frac{\partial X}{\partial \theta}
$$

- **第一步，看清角色**：$\tau\in\mathbb{R}^n$ 是关节力矩，
$F\in\mathbb{R}^6$ 是末端力旋量，
$J\in\mathbb{R}^{6\times n}$。
公式成立的前提是**静力平衡**——忽略惯性、阻尼、摩擦与重力（或把这些也当作外力并入 $F$）。
- **第二步，追来源**：虚功原理把「力 × 位移」这个标量放在等号两侧，
两边都消掉「虚位移」的自由度，
就只剩力与几何的关系。
维数检查：$J^T$ 是 $n\times 6$，
左乘 $6$ 维 $F$ 得 $n$ 维 $\tau$，
量纲自洽。
- **第三步，含重力时的推广**：若把重力当成作用在质心上的外力 $F_g$，
则重力矩就是 $\tau_g = J_c^T F_g$，
其中 $J_c$ 是质心的雅可比。**这正是重力补偿控制器的实现方式**：前馈一个 $\tau_g$，
机械臂就像在无重力环境里工作。
- **第四步，验证物理直觉**：单关节平面杠杆中 $J=[L]$，
于是 $\tau = L\cdot F$，
即「力臂 × 力」——回到阿基米德。

## 4 对偶的工程应用

- **重力补偿**：$\tau_g = J_c^T(0,0,-mg)$ 前馈，
配合零力控制实现「拖拽示教」。
- **笛卡尔刚度控制**：把期望的末端刚性写成 $F = K_c\,(X_d - X)$，
则关节指令为 $\tau = J^T K_c (X_d - X)$——这是阻抗控制的雏形，
也是后面力控篇的主线。
- **抓取分析**：手指接触力 $F_i$ 通过各自雅可比映射到手指关节力矩，
抓取的力封闭性（force closure）本质上是对所有接触力旋量集合 $J_i^T F_i$ 的锥分析。
<span class="marginnote">抓取与力封闭详见本专题第八篇《抓取基础：力封闭与抓取质量指标》。
那里你会再次遇到 $J^T$，
只是每一根手指都有一份。
</span>
- **遥操作力反馈**：主端检测操作员施加的力，
从端用 $J^T$ 折算成关节力矩，
操作员就「摸到了」远端环境。

## 5 辨析｜J^T 与 J^{-1} 千万不可混用

**辨析｜易错点：** 速度求解常用 $J^{-1}$（解析速率控制 $\dot\theta = J^{-1}V_d$），
力求解用 $J^T$。
两者名字相近，
性质完全不同：

- $J^{-1}$ 只在 $J$ 为**方阵且满秩**时存在，
奇异时爆炸；
它把任务速度**逆映射**回关节速度。
- $J^T$ 对任意 $J$ 都良定义，
奇异时不爆炸；
它把末端力**对偶传递**到关节力矩，
永不要求满秩。
- 冗余机械臂（$n>6$）没有 $J^{-1}$，
速度用**伪逆** $J^+$；
但力永远是 $J^T$，
不要试图用伪逆代替。

**语义上**：$J^{-1}$ 是「已知末端速度求关节速度」（运动学的逆问题），
$J^T$ 是「已知末端力求关节力」（静力学的对偶问题）。
在奇异位形，
$J^{-1}$ 爆炸而 $J^T$ 有限——末端在某个方向已使不上力，
但公式依然给出「零」而不是「无穷」。
<span class="marginnote">一个记忆锚点：速度是「几何量」用逆，
力是「度量量」用转置。
转置与「距离/力」这类带度量性质的对象绑定，
贯穿整个机器人学。
</span>

## 6 小结

- **力雅可比**：静力平衡下 $\tau = J^T F$，
与速度雅可比 $V=J\dot\theta$ 互为对偶。
- **虚功原理**是两者之间的桥：$\delta X = J\delta\theta$ 与虚功相等，
一步推出转置关系。
- **可达速度与可传力方向互补**：分别对应 $J$ 的列空间与行空间，
奇异时同时丢失。
- **力椭球半轴 $1/\sigma_i$**：动得快的地方使不上劲（上一节已证，
这里在静力语境下复现）。
- $J^T$ **恒存在**、奇异时有限；
$J^{-1}$ 需满秩、奇异时爆炸，
两者不可混用。

在下一节，
我们离开静力学，
进入完整的动力学：末端要加速，
关节到底要输出多大的力矩？
这就是**牛顿-欧拉递推动力学算法（RNEA）**。
