## 为什么从拓扑容错阈值开始

第 9 篇把环面码搬到了平面上（表面码），理论上很漂亮，但工程上只有一个问题说了算：**现实硬件的噪声到底有多大，才不至于拖垮逻辑量子比特？** 这个问题有一个精确的答案形状——**容错阈值（fault-tolerance threshold）**。阈值以上，逻辑错误率随码距指数压制；阈值以下，越纠越错。表面码的阈值约在百分之一量级——这是一个「既苛刻又够得着」的数字：比十年前的超导量子门保真度差一个数量级，又比今天最好的物理门好一个数量级。<span class="marginnote">「阈值」概念对应《量子计算》专题的阈值定理：只要物理错误率低于阈值，就可以用多项式开销把逻辑错误压到任意小。表面码的贡献，是把「阈值存在」的理论定理变成了「阈值约 1%」的可实现工程数字。</span>

本篇的推进顺序是：第 1 节讲清「为什么需要主动纠错」，第 2 节给出码距与噪声模型这两个基本量，第 3 节推导逻辑错误率的指数定律，第 4 节介绍解码器，第 5 节把全部数字拼成一张可推算的工程路线图。**读完你会获得一个直觉：容错量子计算不是「做得更准」，而是「码距设计 + 解码正确」。**

## 1 从拓扑保护到主动纠错

第 7 篇的拓扑保护是「被动」的：能隙隔离 + 非局域编码。但现实里任意子会被噪声**产生出来**——一对 $e$、一对 $m$ 被错误地激发，只要它们没绕成非平凡构型，信息仍安全。于是主动纠错的角色就位了：

**测量综合征**：测出哪些顶点/面是缺陷（$A_s=-1$、$B_p=-1$）；
- **解码**：推断最可能的错误路径，把任意子配对起来；
- **修复**：用局域操作把配好的对消掉。

**重点：表面码的纠错，纠的就是「任意子被错误地激发、且可能形成长链」。** 只有当错误的任意子链**穿过整个平面**（或绕环一圈），才会真正翻转逻辑比特。这就是「码距」的物理含义。<span class="marginnote">这里有个漂亮的同构：第 2 篇「局域扰动指数改变不了拓扑标签」、第 9 篇「任意子配对即解码」、本篇「逻辑错误率随码距指数压降」——三句话描述的是同一件事的三个侧面：<strong>拓扑信息只能被全局过程破坏</strong>。</span>

**一个纠错周期的动作分解：** 以边长 $L = 5$ 的表面码为例，一轮纠错分三步：(1) 对所有稳定子做同步测量，得到综合征位图；(2) 用解码器推断最可能的错误链；(3) 对错误链施加反向的局域操作。**每轮约 $O(L^2)$ 个测量、$O(L^2\log L)$ 个经典计算步**——经典后处理的速度直接决定逻辑时钟频率。

**为什么「主动」纠错必不可少：** 拓扑保护提供「能隙隔离 + 非局域编码」，但真正的表面码没有无限能隙——任意子以速率 $R \sim e^{-\Delta/k_BT}$ 被热激发，随着码距增大，被激发的任意子会越来越多。若不测量、不解码、不修复，激发最终会绕成逻辑错误。**被动保护决定「错得慢」，主动纠错决定「错得被抹掉」**——两者合起来才是完整方案。

## 2 码距与噪声模型

**码距（code distance）$d$**：能造成逻辑错误的最小物理错误数。对边长 $L$ 的方形表面码，$d = L$——一条跨过整个平面的错误链才能翻转逻辑比特。

**数值算例：$L$ 与 $d$。** 边长 $L = 3$ 的表面码有 $2L^2 - 1 = 17$ 个数据比特、$L^2 = 9$ 个面，码距 $d = L = 3$——能检测 $d-1 = 2$ 个错误、纠正 $\lfloor (d-1)/2 \rfloor = 1$ 个错误。$L = 27$ 时数据比特约 1457 个，能扛 13 个物理错误。**「把码距翻一倍，逻辑错误率平方级压降，物理比特却只多几倍」——这是指数压降的工程对价。**

**码距的物理代价：** 码距 $d = L$ 意味着逻辑比特「铺在」边长 $L$ 的整个格子上——信息越分散，越难被局部破坏，但物理比特也越多。**这是一个根本性的权衡：可靠性与资源成正比**。表面码把这份权衡做得近乎最优：它在「平面 + 边界」的约束下，用最少的辅助比特实现 $d$ 的码距。

噪声模型要诚实：每个物理比特有概率 $p$ 出错（比特翻转 / 相位翻转 / 二者，depolarizing），**测量本身也以概率 $p_m$ 出错**（测量错误会产生错误的综合征历史，解码时必须跨多轮「时间方向」匹配）。电路级（circuit-level）噪声模型把门、测量、等待全都算进去。<span class="marginnote">区分两类模型很关键：<strong>code capacity</strong>（只有数据比特错、测量完美）给出乐观阈值，<strong>circuit-level</strong>（一切都会错）给出真实阈值。论文里报阈值必须说明模型，否则数字毫无意义——这是读表面码文献最容易踩的坑。</span>

**两类噪声模型对照：**

| 模型 | 数据比特错 | 测量错 | 门错 | 表面码阈值 |
| --- | --- | --- | --- | --- |
| code capacity | 是 | 否 | 否 | $\sim 10\%$ |
| phenomenological | 是 | 是 | 否 | $\sim 3\%$ |
| circuit-level | 是 | 是 | 是 | $\sim 0.5\%$–$1\%$ |

**读文献必查模型：** 同一张表面码，不同模型给出差一个数量级的阈值——「阈值约 1%」只有配合「circuit-level depolarizing」才成立。看到任何一个数字前，先问「用的什么模型」。

## 3 公式解析：逻辑错误率为什么指数压降

逻辑错误率 $p_L$ 与物理错误率 $p$、码距 $d$ 的关系（表面码，depolarizing）：

$$
p_L \approx C\left(\frac{p}{p_{\mathrm{th}}}\right)^{(d+1)/2}
$$

三步拆解：

- **第一步，最小逻辑错误的权重**：要翻转逻辑比特，至少需要 $\lceil d/2 \rceil$ 个物理错误排成一条穿越全平面的链（对奇数 $d$ 是 $(d+1)/2$）。$d$ 条链里任选 $(d+1)/2$ 条出错，概率 $\sim p^{(d+1)/2}$。
- **第二步，为什么是比值**：解码器能消除「短链」（配成局域对），只有「长到足以把解码器骗过」的错误才漏成逻辑错误。比值 $p/p_{\mathrm{th}}$ 编码了「错误长得快还是消得快」的竞争：$p < p_{\mathrm{th}}$ 时消得快，$p > p_{\mathrm{th}}$ 时长得快。
- **第三步，指数就是生命线**：$p < p_{\mathrm{th}}$ 时，每把码距翻一倍，逻辑错误率按 $(p/p_{\mathrm{th}})$ 的 $\sim d/2$ 次方再压一截——**逻辑比特的可靠性随物理资源多项式增长、而错误指数下降**。这正是阈值定理的工程形态。

**一个小验证：为什么是 $(d+1)/2$ 而非 $d$。** 一串任意子链横跨平面才能翻逻辑比特，但链有「两条互补的路径」，解码器总会选择较短的一侧来修复。只要一侧的缺陷数少于 $d/2$，修复路径就绕开「长链」，逻辑比特安然无恙；只有两侧都堆到 $\ge d/2$ 时，解码器才会选错。**因此逻辑错误的最小权重是 $\lceil d/2 \rceil$，不是 $d$**——这个「除以 2」正是解码器存在的意义。

**把 $p$ 读成「每个比特每轮的出错概率」：** 电路级噪声模型里，$p$ 是单次门/测量的错误率，一轮纠错要执行 $O(L)$ 层门，所以有效错误率还要乘上「每轮接触的错误比特数」。**严格说，公式里的 $p$ 应理解为「每轮每稳定子的等效错误率」**——这正是为什么同一个 $p$，在不同码尺寸下给出的逻辑保真度不同。

**物理直觉：$p_{\mathrm{th}}$ 是「任意子对的生成速率」与「解码器消除速率」打成平手的噪声强度。** 阈值是码的固有性质（对 circuit-level depolarizing，表面码 $p_{\mathrm{th}} \sim 1\%$ 量级），与具体硬件无关——它回答的问题是「这台机器的单门错误率必须低于百分之几」。<span class="marginnote">具体数值：理想测量 + 纯比特翻转（code capacity）时阈值约 10%（Dennis–Kitaev–Landahl–Preskill，2002）；含测量错误的 circuit-level depolarizing 时阈值降到约 0.5%–1%。「约 1%」是工程界常用的粗略口哨。</span>

**数值算例：把 $p_L$ 公式用起来。** 取 $p_{\mathrm{th}} = 1\%$、$p = 0.1\%$（当前超导门保真度量级），则 $p/p_{\mathrm{th}} = 0.1$。码距 $d = 21$ 时 $(d+1)/2 = 11$，$p_L \approx C \times 10^{-11}$——配一个合理的 $C \sim 1$，逻辑错误率已到 $10^{-11}$ 量级，逼近大数分解所需的 $10^{-12}$。**每个数量级的物理错误改进，等价于把码距提高几个单位**：这就是「物理保真度 ↔ 码距 ↔ 逻辑保真度」三者的定量换算。

## 4 解码：最小权重完美匹配

指数压降的前提是**解码成功**。表面码的标准解码器：

把每轮综合征里的任意子位置当作图的顶点，任意两点的距离 = 最短错误链长度；
- 找一组**完美匹配**（每个顶点配一个对），使总权重（链长之和）最小——**最小权重完美匹配（minimum weight perfect matching, MWPM）**；
- 权重最小的配对 = 最可能的错误历史；修复按这个配对做局域操作。

MWPM 可用经典的 Blossom 算法在多项式时间内求解，工程上常用 `pymatching` 等库；更快的近邻匹配、机器学习解码器也在不断改进。<span class="marginnote">解码的精度与速度直接决定实际可达的逻辑错误率：匹配错了，本可修复的错误会酿成逻辑错误。因此「更好的解码器 = 更低的有效逻辑错误率」，这是表面码研究的活跃前线。</span>

**数值演练：MWPM 的一次执行。** 某轮测量出 4 个缺陷（两个 $e$ 对、两个 $m$ 对）。解码器把它建模成图：顶点 = 缺陷位置，边权重 = 任意子间的曼哈顿距离。最小权重完美匹配在 4 个顶点间找 2 条总权重最小的不相交配对——若两个 $e$ 相邻、两个 $m$ 相邻，就配成「$e$–$e$、$m$–$m$」两组局域对，各自用 $\sigma^z$/$\sigma^x$ 链消掉。**「配对对了就修好，配对错了就翻转逻辑比特」——解码错误率直接叠加到逻辑错误率上。**

**解码器的军备竞赛：** MWPM 是经典标准，但并非唯一。张量网络解码器、神经网络解码器、以及针对特定噪声模型的自适应解码器，都在竞相压低「有效逻辑错误率」。**关键洞察：解码器越好，同样的物理硬件能达到的逻辑保真度越高**——解码是「用经典算力换量子保真度」的划算买卖。

**辨析｜易错点：测量错误必须「跨时间」解码。** 测量本身出错会留下假的综合征，若不处理，假缺陷会被当成真错误。标准做法是把「时间」也当成一维空间，在 3 维时空里做匹配——忽略这一点，阈值会显著高估或低估。初读表面码文献时这是最常见的技术陷阱。

## 5 从阈值到工程：一个可推算的蓝图

有了阈值和码距，可以画一张可推算的路线图。设物理门错误率 $p$、目标逻辑错误率 $10^{-12}$（大数分解等应用所需量级），需要

$$
d \sim 2\,\frac{\log(p_L / C)}{\log(p/p_{\mathrm{th}})} - 1
$$

把 $p_{\mathrm{th}} \approx 1\%$ 代入：$p = 0.3\%$ 时 $d \approx 27$ 附近；$p = 0.1\%$ 时 $d$ 降到 20 以下。物理比特总数约 $2d^2$（含测量辅助比特）——**这就是「1% 阈值」对硬件指标的意义：它让路线图可计算，也让「哪条硬件路线能到」变得清清楚楚**。<span class="marginnote">当前主流路线（超导、离子阱、中性原子）的单门保真度已在 99.9% 附近，即 $p \sim 10^{-3}$——低于阈值约一个数量级，这正是各大实验室密集攻关表面码的底气来源。</span>

**一张路线图速览（目标逻辑错误率 $10^{-12}$）：**

| 物理门错误率 $p$ | 所需码距 $d$ | 数据比特约 $2d^2$ |
| --- | --- | --- |
| $0.3\%$ | $\approx 27$ | $\approx 1500$ |
| $0.1\%$ | $\approx 18$ | $\approx 650$ |
| $0.03\%$ | $\approx 14$ | $\approx 400$ |

**结论：把单门错误率降一个数量级，需要的物理比特减少约一半——「更准的硬件」与「更大的码距」是两条可互相折算的路线。**

**从阈值到「距离预算」：** 逻辑错误率公式取对数，得到 $d \sim \frac{2\log p_L}{\log(p/p_{\mathrm{th}})}$。给定目标 $p_L$ 与实测 $p$，就能反解所需码距——**这就是「距离预算」：把目标逻辑错误率「花」成若干层码距**，每一层由不同噪声源（比特翻转、相位翻转、测量）分摊。

**辨析｜易错点：阈值不是「硬件指标」。** 阈值是码的固有性质（由码的结构、噪声模型决定），不是「这台机器有多好」。工程上要问的是「单门错误率低于阈值了吗」，而不是「阈值是多少」——同一张表面码，配不同解码器、不同噪声模型，报出来的阈值可以差十倍。**数字本身不重要，重要的是「低于阈值」这个事实。**

**本篇在整个专题中的位置：** 第 7 篇给出拓扑保护的原理（被动），本篇把它转成「阈值 + 码距」的量化工程（主动）。接下来第 11 篇的 Majorana 与表面码是两条互补路线：Majorana 用「天然任意子」降低物理错误率，表面码用「人工任意子」容忍物理错误——**阈值是这两条路线共同的语言**。

**术语速查：** 本篇关键词，一句话一个。

| 术语 | 一句话解释 |
| --- | --- |
| 容错阈值 | 物理错误率低于它时，逻辑错误率可指数压到任意小 |
| 码距 $d$ | 造成逻辑错误的最小物理错误数，表面码 $d = L$ |
| code capacity | 理想测量 + 纯数据比特错，乐观阈值约 10% |
| circuit-level | 门、测量、等待全错，真实阈值约 0.5%–1% |
| MWPM | 最小权重完美匹配，表面码标准解码器 |
| Blossom 算法 | 多项式时间内求解完美匹配的经典算法 |

## 6 小结

- **容错阈值**：物理错误率低于 $p_{\mathrm{th}}$ 时，逻辑错误率可随码距指数压到任意小。
- **码距** $d$ = 最小逻辑错误权重 = 表面码的边长；逻辑错误率 $p_L \approx C(p/p_{\mathrm{th}})^{(d+1)/2}$。
- 表面码阈值：code capacity 下约 10%，**circuit-level depolarizing 下约 0.5%–1%**。
- **解码 = 任意子配对**：MWPM（最小权重完美匹配）是标准方案，测量错误需跨时间维度处理。
- 阈值把「拓扑保护」与「主动纠错」统一：拓扑信息只能被全局过程破坏，工程问题因此变成可计算的码距设计。

在下一节，我们走向本专题最后也是最热闹的实验战场——**拓扑超导体与 Majorana 零模**：一种真实的、正在被许多实验室追逐的非阿贝尔任意子候选。
