## 为什么从 X 射线光学元件开始

上一节我们得到了高亮度、宽谱、可调谐的同步辐射光——但那是一束**白光**，能量混杂、束斑发散。真正做实验前，必须把它「提纯」和「聚焦」：只留想要的那一个能量，把光集中到样品上的微米甚至纳米级焦点。完成这些任务的就是**X 射线光学元件**：反射镜、单色器、波带片。它们的共同难点是——**X 射线几乎不折射、反射率极低**，普通光学元件的经验在这里全部失效，必须另起炉灶。<span class="marginnote">可见光的折射率约 1.5，X 射线的折射率却只比 1 小百万分之几（$n = 1 - \delta + i\beta$，$\delta \sim 10^{-5}$）。这正是 X 射线光学「处处反直觉」的根源。</span>

## 1 折射率比 1 小一点：X 射线的光学「怪癖」

X 射线在任何材料中的复折射率都可以写成：

$$n = 1 - \delta + i\beta$$

其中 $\delta$（约 $10^{-5}$–$10^{-6}$）描述**色散**，$\beta$ 描述**吸收**，两者都正比于材料的电子密度与波长的平方。注意符号：$\delta$ 前是减号，意味着**X 射线的折射率小于 1**——这与可见光恰好相反。

折射率小于 1 带来两个直接后果。其一，光从真空斜入射进入材料时，按斯涅耳定律会**远离法线**偏折，而不是靠近；当入射角小于某个**临界角** $\theta_c$ 时，发生**全外反射**（total external reflection）——这是 X 射线反射镜能工作的物理基础。其二，因为 $\delta$ 极小，只有**掠入射**（入射角仅约零点几度）才能让反射镜工作，正入射反射率几乎为零。<span class="marginnote">$\delta$ 正比于 $\lambda^2$：波长越长、能量越低，$\delta$ 越大、临界角越大。软 X 射线（长波长）比硬 X 射线更容易反射聚焦，这也是软 X 射线显微术常用反射镜而硬 X 射线常依赖晶体与波带片的部分原因。</span>

## 2 掠入射反射镜：把 X 射线「擦」过去

**掠入射反射镜**（grazing-incidence mirror）利用全外反射：让 X 射线以小于临界角的角度掠射抛光镜面，反射率接近 100%，同时把不需要的高能（谐波）滤掉。

平面反射镜只改变方向；要做**聚焦**，镜面必须有曲率。几种经典方案：

**Kirkpatrick-Baez（K-B）镜对**：两块互相垂直的柱面镜串联，一块聚焦水平、一块聚焦垂直，两块独立调节，能在微米级焦点上工作——这是同步辐射光束线最常见的聚焦方案之一。<span class="marginnote">K-B 镜的妙处是把三维聚焦拆成两个一维问题：两片柱面镜各自只管一个方向，互不耦合，调试简单。它的名字来自 1948 年提出该构型的 Paul Kirkpatrick 与 Albert Baez（物理学家 Joan Baez 的父亲）。</span>

**环形镜（toroidal mirror）**：一块镜子同时有水平与垂直曲率，一次反射同时聚焦两个方向，结构紧凑，但像散校正困难。

掠入射反射镜还承担**谐波抑制**的功能：晶体单色器会同时选出基波与其整数倍谐波，而反射镜的临界角恰好把高能谐波挡在反射之外，二者配合得到纯净的单色光。

## 3 晶体单色器：布拉格筛选

要得到能量单一（单色）的 X 射线，最精确的元件是**晶体单色器**：利用晶体原子面的布拉格衍射，只反射满足衍射条件的那一个波长：

$$2d\sin\theta = n\lambda$$

其中 $d$ 是晶面间距，$\theta$ 是掠射角（布拉格角），$n$ 是衍射级次。固定晶体材料（如硅 111 面，$d = 3.135$ Å），旋转晶体改变 $\theta$，就能把入射白光中的某一个波长「挑」出来。<span class="marginnote">一块硅晶体的能量分辨本领 $\Delta E/E$ 可达 $10^{-4}$ 量级。调能量只需转动晶体——这使单色器成为光束线「能量旋钮」的核心。</span>

实际光束线几乎都用**双晶单色器（double-crystal monochromator）**：两块平行晶体串联，第一块选出波长，第二块把出射光恢复到与入射光平行的方向（保持束线几何固定）。两块晶体同步旋转、间距随角度变化，工程上还要考虑热负载对晶面间距的微扰（$\Delta d/d$ 会改变波长）。

单色器的能量分辨率可从布拉格条件微分得到：$\Delta E/E = \Delta\lambda/\lambda = \cot\theta\,\Delta\theta$。在低掠射角（高能量）端，$\cot\theta$ 大，分辨率对角度抖动更敏感——这是高能单色化更困难的原因。

## 4 波带片：用衍射聚焦

**菲涅耳波带片**（Fresnel zone plate）是用衍射聚焦 X 射线的元件：由同心交替的透明与不透明环带组成，环带半径满足

$$r_n^2 = n\lambda f$$

其中 $f$ 是一级焦距，$n$ 是环带序号。透过相邻环带的光在焦点处相位差 $2\pi$，因此同相叠加、实现聚焦。最外环带宽度 $\Delta r_N$ 直接决定空间分辨率：

$$\text{resolution} \approx 1.22\, \Delta r_N$$

现代纳米波带片的最外环带可窄到约 10–30 nm，因而能在软 X 射线波段实现数十纳米级的成像分辨率。<span class="marginnote">波带片 = 一块「只留下同相环带」的衍射光栅。它是软 X 射线显微与扫描显微镜的首选聚焦元件；硬 X 射线段因环带高宽比极限，制造困难，转而常用 K-B 镜或复合折射透镜。</span>

## 5 公式解析：全外反射临界角

**「为什么 X 射线镜要掠入射」是 X 射线光学一切几何设计的原点。** 从折射定律出发，临界角由 $\delta$ 决定：

$$\theta_c = \sqrt{2\delta}$$

分三步拆解：

- **第一步，写折射定律**：光从真空（$n_1 = 1$）以掠射角 $\theta_1$（相对表面的余角）进入折射率 $n_2 = 1 - \delta$ 的材料，斯涅耳定律为 $\cos\theta_1 = (1-\delta)\cos\theta_2$（用余角改写）。
- **第二步，令折射角为零**：全反射发生时 $\theta_2 = 0$，即 $\cos\theta_c = 1 - \delta$。小角近似 $\cos\theta_c \approx 1 - \theta_c^2/2$，代入得 $1 - \theta_c^2/2 = 1 - \delta$。
- **第三步，解出临界角**：$\theta_c = \sqrt{2\delta}$。由于 $\delta \sim 10^{-5}$，$\theta_c$ 只有约 0.3°（约 5 mrad）量级——这就是「掠入射」三个字的数值来源。

$\delta$ 又正比于材料电子密度：重材料（铂、铑）$\delta$ 大、临界角大，同等掠射角下反射率更高，因此 X 射线反射镜常用铂、铑、金作涂层，以兼顾反射率与耐热。

## 6 从反射到折射：复合折射透镜

X 射线聚焦不一定靠反射或衍射——**复合折射透镜**（compound refractive lens, CRL）用一长串凹面透镜把微小的折射累积起来。单块透镜在 X 射线下的焦距极长（约百米级），但 $N$ 块串联后焦距为：

$$f = \frac{R}{2N\delta}$$

其中 $R$ 是单个凹面的曲率半径。用低吸收的铍或铝做材料，CRL 能在硬 X 射线段把同步辐射光聚焦到微米级。它的优点是结构简单、与光轴同轴，缺点是吸收损耗与像差。<span class="marginnote">CRL 是「把不利因素变有利」的典范：X 射线折射力太弱本是麻烦，但串起 100 多块透镜就把弱折射累积成可用焦距——硅的 $\delta \approx 10^{-5}$，$N = 100$ 块、$R = 0.5$ mm 的透镜组，$f \approx 0.25$ m。</span>

**辨析｜易错点：** 三种聚焦元件的原理容易混淆——反射镜靠**全外反射**（掠入射、折射率小于 1）、单色器靠**布拉格衍射**（同时实现单色化）、波带片靠**菲涅耳衍射**（聚焦软 X 射线）、CRL 靠**弱折射累积**（聚焦硬 X 射线）。另一个常见误区是把临界角当成「越大越好」的单调指标——临界角大的代价是吸收也大，选择镜材要在反射率与吸收之间权衡。

## 7 光束线总装：光学元件如何协同

单个元件各有所长，真实的光束线（beamline）把它们按序组装：**前端区**（源）→ **光学棚屋**（单色与聚焦）→ **实验棚屋**（样品与探测器）。一条典型的硬 X 射线光束线长这样：

白光从源出发，先经过**初级准直/反射镜**压低发散并抑制谐波；然后进**双晶单色器**选出目标能量；再经**聚焦镜（K-B 镜对或 CRL）**把光束聚到样品；样品前后各有一组**狭缝**限制束斑、压低背景；样品处或下游布置探测器记录信号。

每一步都有取舍：反射镜反射率高但掠入射使视场小；单色器能量分辨好但热负载大；聚焦元件增益高但会引入像散。光束线设计就是在这组约束里找平衡，用 **Zemax / Shadow** 等光线追迹软件在建造前做全程模拟。<span class="marginnote">光束线设计是「光学 + 真空 + 精密机械 + 控制」的系统工程：镜面粗糙度要压到亚纳米、真空度要维持到 $10^{-8}$ mbar 量级、热负载要靠水冷/液氮冷却稳定到毫开尔文——每一环都是极限工程。</span>

**辨析｜易错点：** 初学者常以为「光束线把光越聚焦越好」，其实许多实验（粉末衍射、SAXS）需要的是**均匀平顶光**而不是最细焦点；聚焦束会引入额外的发散与剂量集中。光学设计必须服务实验方法学，而不是盲目追求最小焦点。

## 8 延伸：光学工程的极限挑战

X 射线光学元件的制造是工程学与物理学的硬碰硬。掠入射反射镜要求镜面粗糙度低于 1 Å、面形误差控制在纳米级——这已逼近原子级加工与干涉检测的极限；单色器晶体要从完美晶体上切出、热负载下晶面形变以微弧度计，需要液氮冷却把温度稳定到毫开尔文；波带片的最外环带只有几十纳米宽、深宽比极大，依赖电子束光刻与电铸工艺（第六级《光学工程》《精密加工》的交叉地带）。

这些元件也塑造了光束线的「性格」：能量分辨率、聚焦能力、谐波抑制、相干保持，每一项都直接决定实验能问什么问题。可以说，**同步辐射的每一条光束线，都是光学工程教科书的一章**。

对后续章节，本节是「硬件预备」——衍射、SAXS、XAFS、CDI 的实验设计都默认你已经知道：白光怎么变单色、平行光怎么聚焦、信号怎么被探测。掌握了这层硬件语言，后面的物理才接得上地气。

把四种光学元件的「分工」压缩成一句口诀：要滤高能谐波找反射镜，要提纯能量找单色器，要聚焦软 X 射线找波带片，要聚焦硬 X 射线找 CRL 或 K-B 镜。元件选型永远跟着实验要求走，而不是相反。

而一条光束线的成败，往往就藏在这些元件的协同细节里——理解它们，等于拿到了同步辐射实验的「准入证」。对本章而言，光学元件是「硬件语法」，后面的衍射、散射、吸收谱与成像，都在这套语法上运行。

## 9 小结

- X 射线复折射率 $n = 1 - \delta + i\beta$ 小于 1，导致全外反射、掠入射光学成为必然。
- 反射镜：掠入射聚焦（K-B 镜对、环形镜），兼作谐波抑制；临界角 $\theta_c = \sqrt{2\delta}$。
- 晶体单色器：用布拉格条件 $2d\sin\theta = n\lambda$ 选能量，双晶构型保持出射方向，分辨率 $\Delta E/E = \cot\theta\,\Delta\theta$。
- 波带片：菲涅耳衍射聚焦，分辨率约 $1.22\,\Delta r_N$，软 X 射线首选。
- 复合折射透镜：$f = R/(2N\delta)$，靠 $N$ 块凹透镜把弱折射累积成硬 X 射线微焦。
- 光束线总装：准直镜 → 双晶单色器 → 聚焦镜 → 狭缝 → 探测器，每一步都是分辨率、通量、热负载与视场之间的权衡。
- 元件选型口诀：滤谐波找反射镜，提纯能量找单色器，聚焦软 X 射线找波带片，聚焦硬 X 射线找 CRL 或 K-B 镜。

光学元件把同步辐射的白光驯成了实验可用的单色束，X 射线物理的「硬件语言」至此齐备。接下来的衍射、散射、吸收谱与成像，都在这套语法上运行——下一节就从「看见原子」的衍射运动学理论开始。
