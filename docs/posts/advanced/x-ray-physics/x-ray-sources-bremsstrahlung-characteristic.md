## 为什么从 X 射线源开始

上一节我们学会了「X 射线进入物质后如何被衰减」，但要真正做实验，先得有一束可靠的 X 射线。一百多年里，人类制造 X 射线的方式走过了一条从**实验室气体放电管**到**同步辐射光源**、再到**自由电子激光**的长路。而这一切的起点，是 1895 年伦琴（Röntgen）发现的那种简单管子，以及它内部两种最基本的辐射机制：**轫致辐射**与**特征辐射**。<span class="marginnote">现代同步辐射与 X 射线自由电子激光本质上仍是「给电子加速、让电子发光」，只是加速得更高、安排得更巧——把本节讲透的两种机制（连续谱与线谱）放到后面几节，就能理解为什么第三代光源要造得那么大。</span>理解 X 射线管，等于拿到了解读一切 X 射线谱的通用钥匙。

## 1 从阴极到阳极：X 射线管的构造

经典 X 射线管是一根高度抽真空的玻璃管，内部装有两个电极。**阴极**是一根被电流加热到白炽的灯丝，热电子在高温下逸出表面（热电子发射）；**阳极**（靶，target）是高熔点金属块，通常是钨、铜或钼。阴极与阳极之间加上数万伏的高压 $V$，热电子被强电场加速，以动能 $eV$ 轰击阳极。

电子进入金属靶后急剧减速，把动能转给物质，产生两种截然不同的 X 射线：<span class="marginnote">电子束的加速电压是 X 射线管的「旋钮」：调高电压，连续谱的硬端变硬、强度增大，但焦点热负荷也随之上升。工程上还要在焦点处用旋转阳极散热——这是「旋转阳极 X 射线管」存在的理由。</span>

**轫致辐射（bremsstrahlung）**：电子在原子核库仑场中偏转、减速，把动能以电磁波形式辐射出去。德语 Bremsstrahlung 字面就是「刹车辐射」。它产生**连续谱**——因为电子的减速过程千差万别，损失的能量从零到 $eV$ 连续分布。

**特征辐射（characteristic radiation）**：入射电子把靶原子内层（K 层、L 层）的电子撞出，外层电子回填空穴，辐射出能量等于两能级差的**线谱**。线的能量由靶元素决定，与电压无关——所以叫「特征」。

两种机制在同一张谱上叠加：一条平滑的连续谱，上面竖起几根尖锐的荧光峰。

## 2 轫致辐射：连续谱

轫致辐射连续谱的形状由电子在库仑场中的减速过程决定，最显著的特征是**存在一个最短波长截止**，称为**杜安-亨特极限**（Duane-Hunt limit）：一个电子最多把全部动能 $eV$ 交给一个光子，因此光子能量不能超过 $eV$，即

$$\lambda_{\min} = \frac{hc}{eV}$$

当加速电压为 $V$（千伏），$\lambda_{\min}[\mathrm{nm}] \approx 1.24 / V[\mathrm{kV}]$。<span class="marginnote">40 kV 的管子，连续谱最短波长约 0.031 nm。这个尖锐的截止端是实验中标定能量轴的天然刻度。</span>

连续谱的强度分布大致是：从 $\lambda_{\min}$ 处陡峭升起，在约 $1.5\lambda_{\min}$ 处达到极大，然后缓慢下降。总辐射功率近似正比于 $Z V^2$（$Z$ 为靶原子序数），这正是钨（$Z = 74$）常被选作靶材的原因之一——原子序数越高，轫致辐射产额越大。

但轫致辐射的能量转换效率极其低下：**典型 X 射线管把超过 99% 的电子动能变成热，只有不足 1% 变成 X 射线**。这就是为什么阳极必须耐高温、为什么要旋转阳极、为什么大功率管要用铍窗（低吸收）引出 X 射线。

## 3 特征辐射：线谱与莫塞莱定律

当入射电子（或初级 X 光子）把靶原子内层电子撞出后，外层电子回填内层空穴，辐射能量等于两能级之差的特征光子。最常用的是 K 系谱线：**Kα**（L 层 → K 层，能量最高、强度最大）与 **Kβ**（M 层 → K 层，能量稍高、强度约低一个数量级）。

特征线的能量随靶元素而变，规律由**莫塞莱定律**（Moseley's law）给出。对 Kα 线：

$$\sqrt{\nu_{K\alpha}} = C\,(Z - \sigma)$$

其中 $\nu$ 是谱线频率，$C$ 是与 Rydberg 常数有关的比例常数，$\sigma$ 是**屏蔽常数**（对 Kα，$\sigma \approx 1$）。莫塞莱定律表明，特征线频率的平方根随原子序数线性增大——这正是 1913 年莫塞莱为元素周期表提供实验排序依据、确立原子序数物理意义的关键发现。<span class="marginnote">莫塞莱定律是「原子序数」概念的实验源头：在莫塞莱之前，周期表按原子量排列，但特征 X 射线显示决定化学性质的是原子核电荷数 $Z$。这是 X 射线物理深刻影响化学的经典时刻。</span>

特征谱线的强度分布有一个实用的经验规律：Kβ 约为 Kα 的 1/5 到 1/8。因此单色实验常先用**滤波片**滤掉 Kβ：例如铜靶（Cu Kα 1.5406 Å，Cu Kβ 1.3922 Å）用薄镍片滤波——镍的 K 吸收边恰好落在两者之间，吸收 Kβ 而放过 Kα。

## 4 公式解析：杜安-亨特极限

**「一个电子最多只能制造一个能量等于其全部动能的光子」是 X 射线连续谱的硬上限。** 把公式写全：

$$\lambda_{\min} = \frac{hc}{eV}$$

分四步拆解：

- **第一步，能量守恒**：电子的全部动能来自电场加速，$E_k = eV$。一个轫致辐射光子最多拿走这份能量，所以光子能量 $E_{\gamma} \le eV$。
- **第二步，能量-波长互换**：光子能量 $E_{\gamma} = hc/\lambda$，于是 $hc/\lambda_{\min} = eV$，解得 $\lambda_{\min} = hc/(eV)$。
- **第三步，代入常数**：$h = 6.626\times10^{-34}\ \mathrm{J\cdot s}$，$c = 3\times10^8\ \mathrm{m/s}$，$e = 1.602\times10^{-19}\ \mathrm{C}$，算得 $hc/e = 1.240\ \mathrm{nm\cdot kV}$，即 $\lambda_{\min}[\mathrm{nm}] \approx 1.24/V[\mathrm{kV}]$。
- **第四步，物理图像**：$\lambda_{\min}$ 是「电子一头撞停、把全部动能一次性交给一个光子」的极限情形。大多数电子与原子核擦肩而过、只减速一部分，于是连续谱的大部分光子能量都低于这个上限——这正是谱形在 $\lambda_{\min}$ 处陡峭起跳、随后整体缓慢下落的由来。

这条公式还有一层实用含义：**调节管电压就能改变 X 射线的「硬度」**。软组织摄影用较低的 kV（约 40–60），骨密度高或需穿透厚的检查用高 kV（约 100–140），这正是放射科「千伏值」操作背后的物理。

## 5 从实验室管到同步辐射源

X 射线管在实验室里至今仍不可替代——廉价、小巧、稳定，足以支撑常规晶体衍射、荧光分析与医学影像。但它的先天局限也很清楚：**强度有限、连续谱谱形固定、只有少量离散特征线、焦点大、亮度低**。

同步辐射光源（下一节详述）在几个维度上彻底超越：电子在储存环中被磁场偏转，辐射谱从红外延伸到硬 X 射线连续可调；插入件让特定能量段的亮度提升多个数量级；脉冲时间结构与天然偏振更是实验室管无法企及的。<span class="marginnote">亮度（brightness）是衡量光源品质的关键量：单位时间、单位面积、单位立体角、单位带宽内的光子数。同步辐射光源的亮度比旋转阳极 X 射线管高出约 10–12 个数量级——这是它能做衍射、吸收谱等「光子饥饿」实验的根本。</span>理解这条谱线进化史（管 → 弯曲磁铁 → 插入件 → FEL），就理解了 X 射线物理百年来「如何把光做得更亮、更短、更相干」的主线。

**辨析｜易错点：** 初学者常混淆「轫致辐射连续谱」与「特征线谱」的来源。连续谱来自入射电子在核库仑场中的减速，能量连续、与靶材料无关（只与 $Z$ 决定产额）；线谱来自靶原子内层空穴被回填，能量由能级差决定、与入射电子能量无关。另一个常见误区是以为「X 射线管的辐射全部来自特征谱」——实际上连续谱占了总产额的主体，特征线是叠加其上的尖峰。

## 6 X 射线管的工程学：焦点、热负载与铍窗

X 射线管的物理决定了它的工程形态。电子轰击靶面时，99% 的能量变成热，而热的集中区就是**焦点**（focal spot）——X 射线从焦点发出，焦点越小，成像越清晰，但功率密度越高、靶越容易熔毁。工程上靠三招破解这对矛盾：

**线焦点原理**：把电子束压成长条形焦点，从靶面正面看面积小（成像清晰），从侧面 45° 看面积大（散热面大）。放射科「小焦点/大焦点」两档切换，正是这条原理的临床体现。

**旋转阳极**：把阳极做成高速旋转的钨盘，焦点热区不断移走、冷区轮换受热，功率可提高一个量级。现代大功率管转速达每分钟上万转，配合铜基体导热与油循环冷却。<span class="marginnote">旋转阳极 X 射线管的功率密度可达 $10^{5}$ W/cm² 量级——比太阳表面还高。工程上把「不能散热」的问题变成「让热跑开」的问题。</span>

**铍窗**：X 射线从靶面以一定角度射出，穿过管壳上的薄窗。铍原子序数低、吸收小，让低能 X 射线也能透出管外；重元素管壳则吸收杂散辐射，既保护环境也屏蔽有害剂量。

还有一个几何效应值得记住：**脚跟效应**（heel effect）——从靶面以掠射角出射的 X 射线在阳极侧被靶体自身吸收更多，导致束流强度在阳极侧弱、阴极侧强。对要求均匀照明的成像系统，工程师会把样品放在强度均匀的区间，或用补偿滤波片修正。

## 7 延伸：X 射线源的社会版图

X 射线源早已不只是实验室仪器。**医疗影像**（DR、CT、乳腺摄影）用旋转阳极管每天服务千万人次；**安检与海关**用双能 X 射线看行李箱内部；**无损检测**（NDT）用管源给焊缝、铸件「体检」；**荧光分析**（XRF）用手持式小型管做田野地质勘探与文物鉴定——廉价的 X 射线管让「看见内部」成为工业与社会的常规能力。

这条源谱系还向两个极端延伸。向下是**微焦点与液态金属靶源**：把焦点压到微米甚至亚微米，用液态金属喷流散热，在实验室里实现接近同步辐射分辨能力的成像与衍射。向上则是本专题接下来的主角——同步辐射与 X 射线自由电子激光：它们不再是「管」，而是国家级的**大科学装置**，一条光束线就是一个学科群。

第二级《高等物理》讲过电子在电场中的加速，这里我们看到同一物理的工程归宿；而「怎样把电子变成光」这条主线，从本节的热阴极一路延伸到第九级《加速器物理》与《高能物理实验方法》——X 射线源的进化史，就是电子动力学与工程学的共同编年史。

用一个数值实例收束：一台 60 kV 的旋转阳极铜靶管，连续谱最短波长约 0.0207 nm，Kα 特征线在 0.154 nm，加 0.02 mm 镍箔滤掉 Kβ 后，就是无数实验室的标准「准单色 Cu Kα 源」。操作面板上两个旋钮各有分工——管电压定能量上限、管电流定光子产额，互不干扰，这是读任何 X 射线谱之前先要建立的直觉。

常用参数速查：

| 参数 | 含义 | 典型值 |
| --- | --- | --- |
| 管电压 $V$ | 电子加速能量，定连续谱硬端 | 20–150 kV |
| 管电流 | 电子数率，定光子产额 | 1–1000 mA |
| 靶材 | 决定特征线能量与产额 | W、Cu、Mo |
| $\lambda_{\min}$ | 连续谱最短波长 | $\approx 1.24/V$ nm |
| 滤波片 | 吸收 Kβ、留 Kα | Ni 配 Cu 靶 |
| 焦点 | 决定成像清晰度 | 0.1–1 mm |
| 铍窗 | 让低能 X 射线透出管外 | 0.1–1 mm |

从「源」再望一眼全专题：无论同步辐射还是自由电子激光，核心目标仍然是「把电子加速得更猛、让发光更可控」——本节埋下的连续谱与线谱二分法，会以「宽带白光 vs 单色可调」的形式在后续章节反复出现。

## 8 小结

- X 射线管用高压加速热电子轰击金属靶，产生两种辐射：**轫致辐射**（连续谱）与**特征辐射**（线谱）。
- 连续谱存在硬截止 **杜安-亨特极限** $\lambda_{\min} = hc/(eV) \approx 1.24/V[\mathrm{kV}]$，是电子能量守恒的直接推论。
- 特征线（Kα、Kβ…）的能量由靶原子能级决定，服从**莫塞莱定律** $\sqrt{\nu} \propto (Z - \sigma)$，随原子序数线性增大——这是「原子序数」概念进入化学分类的实验源头。
- 单色化实操：Kβ 约为 Kα 强度的 1/5–1/8，配对的滤波片（如 Ni 配 Cu 靶）可把 Kβ 压到可忽略，得到「准单色」的实验室标准光源。
- 工程三要素：**线焦点**平衡清晰度与功率密度、**旋转阳极**把热点轮流移走、**铍窗**让低能 X 射线透出管外；**脚跟效应**提醒成像时束流强度分布不均。
- 从管到同步辐射的主线是「亮度」：同步辐射比旋转阳极管高出约 10–12 个数量级，这是 X 射线物理百年「把光做得更亮」的编年史。

在下一节，我们将从「源」走向「光路」：X 射线如何被聚焦、单色化并打到样品上——晶体单色器与光学系统的物理，是实验室里「把谱看准」的另一半。
