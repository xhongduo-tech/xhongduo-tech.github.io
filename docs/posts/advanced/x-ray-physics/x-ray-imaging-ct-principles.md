## 为什么从成像与 CT 开始

1895 年伦琴把妻子的手放在 X 射线管前拍下第一张「手骨照片」，医学影像由此诞生。一百多年后，X 射线成像从一张二维投影演化出**计算机断层扫描（CT）**——绕着物体转一圈、拍数百张投影，再靠数学把三维结构重建出来。CT 是 X 射线物理与数学结合最完美的产物：它的重建核心是**拉东变换与中心切片定理**，一条与衍射、散射完全不同的路。<span class="marginnote">CT 的数学根基早在 1917 年就由奥地利数学家约翰·拉东（Johann Radon）为纯数学目的写出——半个世纪后才被豪斯菲尔德用进医用扫描机，1979 年获得诺贝尔生理学或医学奖。这是「纯数学的百年回响」的经典案例。</span>理解成像与 CT，既要懂物理（投影 = 线积分），也要懂数学（反演 = 重建）。

## 1 投影：把三维压成二维

上一节第一课讲过：X 射线穿过非均匀介质，透射强度是衰减系数的线积分：

$$I = I_0\, \exp\left(-\int_L \mu(x,y)\, dl\right)$$

把两边取对数，就得到**投影数据** $p$：

$$p = -\ln\left(\frac{I}{I_0}\right) = \int_L \mu(x,y)\, dl$$

一张普通 X 光片（radiograph）就是物体沿某方向的**投影**：三维物体被压成二维图像，深度信息沿射线方向被积分抹平。这就是为什么 X 光片上看骨折清楚、却分不清前后重叠的结构——投影是二维的，深度维度丢了。<span class="marginnote">投影运算正是 CT 重建要「反演」的对象：已知大量不同角度的投影 $p_\theta(s)$，反推出二维分布 $\mu(x,y)$。伦琴时代做不到，因为只能拍一个方向；CT 时代多方向拍齐，问题才可解。</span>

## 2 吸收衬度成像

普通 X 光片利用的是**吸收衬度**：不同组织衰减系数不同，透射强度不同，形成明暗。衰减系数主要来自光电吸收（$\propto Z^4$）与康普顿散射：

**骨骼与软组织**：骨含钙（$Z = 20$），$\mu$ 远大于软组织（碳氢氧，$Z \le 8$），所以骨在片上发白、软组织发灰、空气发黑。这一条我们在第一节的 $Z^4$ 关系里已经埋下伏笔。

**造影剂**：需要观察血管、消化道等软组织结构时，引入高 $Z$ 元素（碘、钡）提高衬度——碘造影剂注入血管、钡餐吞入消化道，X 光片和 CT 就能「看见」这些原本衬度不足的结构。<span class="marginnote">现代数字 X 光与 CT 用平板探测器（闪烁体 + 光电二极管阵列）替代胶片，动态范围大、剂量低、可量化——「数字化」让 X 射线成像从定性走向定量。</span>

吸收衬度成像的分辨能力受剂量、探测器像素与焦点尺寸限制；软组织之间衬度低是它的天然短板——这正是相位衬度成像的用武之地。

## 3 相位衬度：看软组织的另一只眼

软组织的吸收衬度极低，但它们的**折射率**（$\delta$）仍有差异——X 射线穿过不同组织时**相位延迟**不同。**相位衬度成像**（phase contrast imaging）把这个相位信息转成可测量的强度变化：

**传播式相位衬度（propagation-based）**：让相干 X 射线穿过样品后自由传播一段距离，相位梯度在近场衍射下变成边缘增强的强度图。边界清晰如「描边」，软组织轮廓跃然而出。

**光栅干涉法（grating interferometry）**：用两片光栅把相位梯度转成可探测的莫尔条纹位移，能同时给出吸收、相位与小角散射（暗场）三种衬度——医用相位 CT 与乳腺癌筛查的热门方向。<span class="marginnote">相位衬度把「看软组织」的分辨门槛大大降低：同剂量下，相位衬度的灵敏度可比吸收衬度高约 1–2 个数量级。同步辐射（高相干）是相位衬度的理想光源，台式微焦点源也能用光栅方案实现。</span>

**分析器成像（analyzer-based）**：利用完美晶体的角敏感反射，把折射角变成强度变化，灵敏度极高但装置复杂。

## 4 CT 与拉东变换

CT 要做的，是从一族投影重建二维分布。数学框架由**拉东变换**给出：沿方向 $\theta$、位置 $s$ 的投影 $p_\theta(s)$ 是 $\mu(x,y)$ 沿直线 $x\cos\theta + y\sin\theta = s$ 的线积分：

$$p_\theta(s) = \iint \mu(x,y)\, \delta(x\cos\theta + y\sin\theta - s)\, dx\, dy$$

$$p_\theta(s) = \int_{-\infty}^{\infty} \mu(s\cos\theta - t\sin\theta,\ s\sin\theta + t\cos\theta)\, dt$$

CT 重建就是求**拉东逆变换**：从所有角度 $\theta$ 的 $p_\theta(s)$ 反解 $\mu(x,y)$。豪斯菲尔德把这一数学理想变成了临床现实，而现代 CT 都靠一族高效算法实现反演，其中最经典的是**滤波反投影**（filtered backprojection, FBP）。<span class="marginnote">CT 装置基本构型：X 射线源与探测器阵列围绕物体同步旋转，扇形或锥形束扫过物体，每个旋转角采集一条投影。围绕一圈（约 360°）后，数据即「拉东变换的离散采样」——重建的采样充分性由角度数决定。</span>

## 5 公式解析：中心切片定理

**「一条投影的傅里叶变换 = 物体二维傅里叶变换过原点的一条直线」是 CT 重建的全部数学枢纽。** 设 $\tilde\mu(u,v)$ 是 $\mu(x,y)$ 的二维傅里叶变换，则：

$$\mathcal{F}\left[p_\theta\right](\nu) = \tilde\mu(\nu\cos\theta,\ \nu\sin\theta)$$

分三步拆解：

- **第一步，写投影的傅里叶变换**：$\tilde p_\theta(\nu) = \int_{-\infty}^{\infty} p_\theta(s) e^{-2\pi i\nu s} ds$，把 $p_\theta$ 的线积分定义代入，用 $\delta$ 函数把二维积分「压」到一条线上。
- **第二步，换元合并指数**：把二维傅里叶积分 $\tilde\mu(u,v) = \iint \mu(x,y)e^{-2\pi i(ux+vy)}dx\,dy$ 与上式对照，令 $u = \nu\cos\theta$、$v = \nu\sin\theta$，两边恰好相等。
- **第三步，读出几何含义**：$\tilde\mu$ 的取值域是 $u$-$v$ 平面上过原点、方向角 $\theta$ 的一条直线。**改变投影角度 $\theta$，就在二维频域里「画」出不同方向的直线**；角度扫满 180°，频域就被径向直线铺满——于是二维傅里叶变换可由各方向投影拼出来，再逆变换即得 $\mu(x,y)$。

这条定理点明 CT 重建的本质：**频域采样是极坐标网格，不是直角网格**。直接把频域数据反傅里叶变换会因中心过采样、边缘欠采样产生伪影——因此必须做**滤波**（用 $\lvert\nu\rvert$ 斜坡滤波，即 Ram-Lak 滤波）补偿极坐标采样的不均匀，再做反投影，这就是 FBP 的由来。

## 6 从滤波反投影到迭代重建

FBP 是 CT 重建的经典解，两步走：先对每条投影做**斜坡滤波**（频率越高加权越大，抵消反投影的低频过饱和），再沿原投影方向**反投影**回图像空间，各方向叠加即得重建。FBP 快、稳定，但假设数据完备——角度稀疏、噪声大、锥束几何下都容易产生条纹伪影。

**迭代重建**（iterative reconstruction）则把重建当成最优化问题：给定初始 $\mu$，正投影得到预测投影，与实测投影比较得到误差，沿梯度反投影修正 $\mu$，迭代直至收敛。它能自然地引入**先验约束**（平滑性、非负性、稀疏性）与**统计权重**（按光子噪声加权），在低剂量、稀疏角度、锥束 CT 中质量明显优于 FBP——如今已全面进入临床。<span class="marginnote">从 FBP 到迭代重建，CT 走过了与 CDI 相位恢复相似的路：把反演问题变成「正投影-比较-修正」的迭代循环。二者在数学上同属「反问题求解」家族，只是约束不同。</span>

**辨析｜易错点：** 初学者常把「反投影」当成「重建」——只反投影不滤波，得到的图像会因低频过重而模糊发糊，这正是 Ram-Lak 斜坡滤波存在的理由。另一个误区是以为 CT「转得越多越好」：角度采样过剩会使剂量上升，现代临床用迭代算法在**稀疏角度 + 低剂量**下重建，用先验约束弥补缺失数据，而不是盲目加转。

## 7 剂量与辐射安全：医学成像的边界

X 射线成像的一切技术追求，最终都落在同一个约束上——**剂量**。诊断 X 射线带来的随机性风险虽小，但遵循「无阈值线性」（LNT）模型，即风险正比于剂量，没有绝对安全的低限。因此医学影像有两个铁律：

**ALARA 原则**：在保证诊断质量的前提下，把剂量压到「合理且可达」的最低水平。体现在临床上：儿童用专门的低剂量协议、CT 检查前评估「是否非做不可」、用铅衣保护生殖腺等敏感器官。

**剂量-图像质量的权衡**：噪声随剂量按 $\text{SNR} \propto \sqrt{\text{dose}}$ 增长——剂量翻四倍，信噪比才翻一倍。这条平方根关系决定了低剂量成像的艰难：每省一点剂量，都要用更好的探测器、更聪明的重建算法去补。<span class="marginnote">常用剂量单位换算：一次胸部 X 光约 0.02 mSv，一次头部 CT 约 2 mSv，一次腹部 CT 约 8 mSv，而天然本底辐射年均约 2.4 mSv。「检查的获益是否大于风险」是每次拍摄前的伦理考量。</span>

**迭代重建与深度学习降噪**：临床 CT 已全面转向迭代重建，用统计模型与先验约束在低剂量下保持图像质量；近年来**深度学习降噪**更进一步——训练神经网络从低剂量噪声图还原高剂量级清晰图，但必须警惕「网络幻觉」把不存在的结构「画」出来，医学上要求严格的验证与监管。

**辨析｜易错点：** 患者常把「CT 越多越安心」当作原则，但每次额外扫描都带来真实的累积剂量。医生与物理师的责任是判断检查的必要性，而不是满足「做个检查更放心」的心理——这正是影像学「合理使用」准则的现实意义。

## 8 延伸：医学影像的完整版图

X 射线成像只是医学影像的「一系」：**CT** 看密度差、**MRI** 看氢原子核磁共振、**PET/SPECT** 看放射性示踪分子、**超声**看声阻抗——四者互补，构成现代诊断影像的四方阵（第五级《医学影像学》《核医学》的完整专题）。X 射线系的特点是快、普及、对骨与钙化敏感；它的短板（软组织衬度差、有电离辐射）正是 MRI 与超声的用武之地。

CT 的数学核心（投影-反演）还通向下游：**锥束 CT** 用二维平板探测器一次转出三维体数据（口腔颌面、介入导航），**双能 CT** 用两个能谱的衰减差异分解出「骨/碘/软组织」成分，**相位 CT** 用同步辐射给软组织高衬度成像。而这些都共享本节的中心切片定理骨架。

放射学也是一门「合理使用」的学问：检查的选择、剂量的控制、结果的解读，牵涉医学、物理与伦理（第七级《医学伦理学》）。理解了成像物理，你就能听懂放射科报告里每一项参数的由来。

最后，把 CT 的数学放进更大的图景：从拉东变换到 FBP，从迭代重建到深度学习重建，这条演化线的本质是「用越来越多的先验信息，换取越来越少的剂量」。放射物理由此凝练出一条公理——**信息不增加，剂量就省不下来**；每一代重建算法，都是在用计算换取光子。

对初学者，本节最该带走的是那张「投影-反演」的对仗图：正投影是物理（X 射线走过介质），反投影是数学（从投影还原介质），而中心切片定理是连接两者的桥。真正上手时，从一束 X 光到一张 CT 图像，跨越的正是这座桥——这也是放射科医生与物理师每天默认运行的那套心智模型。

补充一句面向读者的实用换算：图像噪声与剂量的平方根关系（$\mathrm{SNR} \propto \sqrt{\mathrm{dose}}$）意味着，想降一半噪声就得四倍剂量——这把「剂量换图像」的账算得明明白白，也解释了为什么低剂量重建永远是最活跃的工程方向。

## 9 小结

- 普通 X 光片是**投影**：$p = \int_L \mu\, dl$，深度被积分抹平。
- 吸收衬度依赖 $Z^4$ 的光电吸收与康普顿散射；软组织用造影剂或**相位衬度**增强。
- **CT** 从多角度投影重建三维，核心是**拉东变换** $p_\theta(s) = \int_L \mu(x,y)\, dl$ 及其逆变换。
- **中心切片定理**把投影的傅里叶变换与物体的二维傅里叶变换连起来，是滤波反投影（FBP）与 Ram-Lak 斜坡滤波的数学依据。
- **剂量铁律**：$\mathrm{SNR} \propto \sqrt{\mathrm{dose}}$，低剂量靠迭代重建、先验约束与深度学习降噪补偿；ALARA 是医学影像的第一原则。
- 影像版图：CT 看密度、MRI 看氢核、PET/SPECT 看示踪分子、超声看声阻抗，四者互补构成诊断影像的四方阵。

从投影到重建的这条数学链，是 X 射线物理与数学交汇最深的一吻；它在医学影像之外的延伸——工业无损检测、考古断层、地球物理层析——共享同一座「拉东桥」。理解了「信息不增加，剂量就省不下来」这条公理，你就握住了放射物理一百年的演进逻辑。
