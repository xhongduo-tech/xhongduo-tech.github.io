## 为什么从快速傅里叶变换开始

波动方程解出了波的形状，但物理学家真正想问的是：「这个信号里有哪些频率、各占多少？」

**傅里叶变换就是把「幅度随时间如何变」翻译成「幅度随频率如何分布」的字典**——光谱学、脉冲响应、滤波、噪声分析、天文观测、以及今天所有音频与图像的压缩，全都依赖这本字典能翻得快。

直接按定义算离散傅里叶变换（DFT）要 $O(N^2)$ 次运算，而 **快速傅里叶变换（FFT）把它压到 $O(N\log N)$**。

对 $N=10^6$ 的序列，这是 $10^{12}$ 与 $2\times10^7$ 的差距——**五个数量级，等于「算不动」与「瞬时完成」的差别**。

FFT 的发明是二十世纪数值算法最重要的单点突破之一。

<span class="marginnote">1965 年库利（Cooley）与图基（Tukey）发表经典论文，但高斯在 1805 年就已用过同样的分治思想——算法史著名的「迟到的重新发现」。你若有兴趣，本博客《算法导论》分治篇章还会与它重逢：FFT 是分治策略最漂亮的教科书。</span>

## 1 从 DFT 说起：定义里藏着多少冗余

对 $N$ 个采样 $x_0,\dots,x_{N-1}$，离散傅里叶变换定义为

$$X_k = \sum_{n=0}^{N-1} x_n\, e^{-i 2\pi kn/N}, \qquad k = 0,\dots,N-1$$

每个 $X_k$ 是 $N$ 项求和，$N$ 个 $k$ 就是 $N^2$ 次复数乘法。

但观察结构：令 $\omega = e^{-i 2\pi/N}$ 为单位根，则 $X_k = \sum_n x_n \omega^{kn}$。

**$\omega$ 的幂是高度周期化的**：$\omega^{kn}$ 随 $k,n$ 各自以 $N$ 为周期、还有一堆对称关系 $\omega^{k+N/2} = -\omega^k$。

这些冗余就是省算力的金矿。

<span class="marginnote">周期关系不是小聪明，而是整个 FFT 的引擎：$\omega^{2} = e^{-i4\pi/N}$ 是 $N/2$ 次单位根，于是偶数项与奇数项各自构成「半尺寸」的变换——把大问题切成两个半问题，递归自相似的结构就此诞生。分治递归 + 单位根对称，缺一不可。</span>

## 2 分治之舞：把 $N$ 变成两个 $N/2$

把 $x_n$ 按下标奇偶分成两组，代入定义并整理：

$$X_k = \sum_{m=0}^{N/2-1} x_{2m}\, \omega^{2mk} \;+\; \omega^k \sum_{m=0}^{N/2-1} x_{2m+1}\, \omega^{2mk}$$

**第一项是偶数下标序列的 $N/2$ 点 DFT，第二项是奇数下标序列的 $N/2$ 点 DFT 再乘一个「扭转因子」$\omega^k$。**

于是计算 $N$ 点变换的成本 $T(N)$ 满足递归式

$$T(N) = 2\,T(N/2) + O(N) \;\Longrightarrow\; T(N) = O(N \log N)$$

递归地拆下去：$N=2^m$ 时，每次把规模减半、把结果两两合并，总共 $\log_2 N$ 层，每层 $O(N)$ 次操作。

这就是著名的**蝶形（butterfly）合并**，名字来自合并时两条线交叉的图样。

<span class="marginnote">朴素递归版 FFT 需要 $N$ 是 2 的幂，处理任意长度时先补零到最近的 2 次幂再变换——补零不会改变峰值位置，只会让频谱变「细」。现代实现（如 FFTW）走混合基（mixed-radix）路线，把 $N$ 的素数因子逐个消化，任何长度都能高效处理。</span>

## 3 快速卷积：FFT 的第一个超级应用

两个序列的卷积在时域是 $O(N^2)$ 的滑动求和，但它有个著名的对应关系：**时域卷积 = 频域点乘**。

于是快速卷积的三步曲是：

1. 对两个序列分别做 FFT；
2. 在频域逐点相乘；
3. 逆 FFT（IFFT）回时域。

总成本 $O(N\log N)$ 而非 $O(N^2)$。

这个「**先变到好算的域，算完再变回来**」的套路，是数字信号处理的支柱：滤波（频域乘一个窗口）、相关分析（互相关 = 卷积的变体）、甚至多项式乘法都靠它提速。

<span class="marginnote">下一篇《随机过程模拟：自相关与功率谱》的主角之一就是它：自相关函数在时域是 $O(N^2)$ 的滑动求和，转到频域就成了功率谱——维纳-辛钦（Wiener–Khintchine）定理说「功率谱是自相关的傅里叶变换」，FFT 让两边都便宜到能跑。这里埋的线，到那时收。</span>

## 4 物理应用：从光谱到噪声再到偏微分方程

FFT 在计算物理里无处不在：

**光谱分析**：把时间序列变换到频域，峰的位置对应振荡频率、峰宽给出衰减率——脉冲响应、电子自旋共振、声学模态测量全是这个套路。
- **频域滤波**：设计低通/带通窗口在频域乘上去，再 IFFT 回来，噪声被削掉、信号形状大体保留。这是「频域整形」范式。
- **PDE 的谱方法**：上一篇的热方程，若空间均匀、用 FFT 做空间导数（导数在频域就是乘 $ik$），时间步进变成逐频率的点乘——**谱方法（spectral method）对光滑问题能达到「谱精度」**：误差随模式数指数下降，远甩有限差分。

<span class="marginnote">这解释了为什么湍流、大气与海洋模拟偏爱谱/伪谱方法：同样的网格，谱方法用更少的点拿到更高的精度，代价是要求解域规则、边界周期化。Gould & Tobochnik 的《计算机模拟导论》用一整章示范「在频域解热方程」，是 Newman 教材本章的最佳互补阅读。</span>

## 5 公式解析：蝶形合并 $X_k = E_k + \omega^k O_k$

**蝶形是 FFT 的最小砖块，一行公式包含全部的分治智慧。**

拆解如下：

- **第一步，缩写**：令 $E_k$ 为偶数下标序列的 $N/2$ 点 DFT，$O_k$ 为奇数下标序列的 $N/2$ 点 DFT。于是 $X_k = E_k + \omega^k O_k$，其中 $k = 0,\dots,N-1$。
- **第二步，看一半就够了**：$E_k$ 与 $O_k$ 对 $k$ 是周期 $N/2$ 的（因为它们是 $N/2$ 点变换），所以 $X_{k+N/2} = E_k + \omega^{k+N/2} O_k = E_k - \omega^k O_k$。**利用 $\omega^{N/2} = -1$，后半段的 $X$ 不用重算，只差一个负号**——这是蝶形「一次合并算出两个输出」的由来。
- **第三步，画出流程**：两条输入线（$E_k$ 与 $O_k$）进一个蝶形节点，$O_k$ 线乘 $\omega^k$ 后分叉成「加」与「减」，分别输出 $X_k$ 与 $X_{k+N/2}$。交叉的蝴蝶翅膀，就是 $N \log_2 N$ 次操作中最小的一拍。
- **第四步，数出成本**：$N$ 个蝶形/层，$\log_2 N$ 层，总操作 $O(N\log_2 N)$。**它省下的不是常数因子，而是把指数从 2 降到 1——让「频谱」从奢侈品变成日用品。**

## 6 易错点与小结

**辨析｜易错点：** FFT 的索引约定没有全局标准——输出 $X_k$ 的峰值落在 $k$ 上时，实际频率是 $f_k = k f_s / N$（$f_s$ 是采样率）。

对实数信号，频谱关于 $N/2$ 对称，只有前半有意义。

**把频谱的 $x$ 轴标成「k」而非「频率」是信号处理菜鸟的第一大灾难。**

**辨析｜易错点：** 采样率低于信号最高频率的两倍（**奈奎斯特条件**），高频分量会被「折叠」（aliasing）成低频伪影。

FFT 再快也算不出采样时已经丢掉的信息——**防混叠要在采样端解决，而不是在变换端补救。**

- **DFT $O(N^2)$ → FFT $O(N\log N)$**：靠单位根对称 + 奇偶分治的递归自相似。
- **蝶形合并** $X_k = E_k \pm \omega^k O_k$：一个节点两个输出，负号来自 $\omega^{N/2}=-1$。
- **快速卷积** = FFT + 频域点乘 + IFFT，是滤波与相关分析的引擎。
- **谱方法**在频域算导数，光滑问题拿「谱精度」；滤波与去噪是它的日常应用。
