## 为什么从电磁理论开始

前面五篇我们一直在「波动光学」的框架里打转：光线、波前、光程差。但一个根本问题悬而未决——**光到底是什么波**？惠更斯说它是弹性介质里的机械波，杨与菲涅耳也沿用这个图像；但弹性波需要介质，而光却能穿过真空从太阳到达地球。答案在 1860 年代由麦克斯韦给出：光是**电磁波**，是电场与磁场互相感应的自维持扰动，根本不需要介质。这一节是第六篇的第三步：把光的波动图像安放进麦克斯韦方程这个总框架，并借此引出描述光在界面反射折射行为的**菲涅尔公式**——它是波动光学与几何光学之间最后一块拼图。<span class="marginnote">麦克斯韦方程把电学、磁学、光学三个此前各自独立的领域统一进一组方程，被公认为 19 世纪物理学最伟大的成就之一。光速 $c \approx 3\times10^8$ m/s 直接<strong>从方程组里的常数 $\epsilon_0, \mu_0$ 算出来</strong>——麦克斯韦因此断言光是电磁波，与实验测量误差仅在几个百分点以内。</span>

## 1 麦克斯韦方程与光的波动方程

真空中麦克斯韦方程组的微分形式为：

$$\nabla\cdot\mathbf{E} = 0, \qquad \nabla\cdot\mathbf{B} = 0, \qquad \nabla\times\mathbf{E} = -\frac{\partial \mathbf{B}}{\partial t}, \qquad \nabla\times\mathbf{B} = \mu_0\epsilon_0\frac{\partial \mathbf{E}}{\partial t}$$

对电场方程取旋度，再代入磁场方程，得到**电场波动方程**：

$$\nabla^2 \mathbf{E} = \mu_0\epsilon_0\,\frac{\partial^2 \mathbf{E}}{\partial t^2}$$

它和所有波动方程同形，波速为

$$v = \frac{1}{\sqrt{\mu_0\epsilon_0}} = c \approx 2.998\times10^8\ \mathrm{m/s}$$

麦克斯韦据此算出「电磁扰动」在真空中的传播速度，恰好等于实验测得的光速——这是物理学史上最著名的一次「巧合」，它让光被当场收编为电磁波。<span class="marginnote">这组方程的对称之美在于：变化的电场感生磁场、变化的磁场感生电场，两者互相喂养，于是扰动无需介质也能自持地传播。机械波需要弹性的绳子，电磁波本身就是「场」在自我递进。</span>

在介质中，光速降为 $v = c/n$，其中折射率 $n = \sqrt{\mu_r\epsilon_r}$（非磁性材料 $\mu_r \approx 1$，$n \approx \sqrt{\epsilon_r}$）。**折射率由此获得了微观解释**——它来自介质对电磁场的介电响应，这正是第七篇讲色散与吸收时的理论基础。

## 2 平面波、坡印廷矢量与光强

波动方程的最简单解是**平面波**：

$$\mathbf{E}(\mathbf{r}, t) = \mathbf{E}_0 \cos(\mathbf{k}\cdot\mathbf{r} - \omega t)$$

其中 $\mathbf{k}$ 是波矢，$\omega = ck$。电磁波是**横波**：$\mathbf{E}$、$\mathbf{B}$、$\mathbf{k}$ 三者互相垂直，$\mathbf{E}$ 与 $\mathbf{B}$ 同相，且 $E = cB$。

光的**能流密度**由**坡印廷矢量（Poynting vector）**描述：

$$\mathbf{S} = \frac{1}{\mu_0}\,\mathbf{E}\times\mathbf{B}$$

$\mathbf{S}$ 的方向即能量传播方向，大小 $S$ 是单位时间垂直流过单位面积的能量。对周期振荡的平面波，取时间平均得**光强（intensity）**：

$$I = \langle S \rangle = \frac{1}{2}\,\epsilon_0 c\,E_0^2$$

**光强正比于振幅的平方**——这是全书最常用的一句话。干涉、衍射、偏振的全部强度计算，都建立在这个 $I \propto E_0^2$ 之上。<span class="marginnote">太阳在地球表面的辐照度约 $1.36\times10^3$ W/m²，对应电场振幅约 $E_0 \approx \sqrt{2I/\epsilon_0 c} \approx 1000$ V/m。激光则不同：1 mW 的氦氖激光聚焦到微米级光斑，电场振幅可达 $10^6$ V/m 量级——高场强正是激光能引发非线性效应的原因。</span>

## 3 菲涅尔公式：界面上的反射与透射

光斜入射到两种介质的分界面时，反射光与折射光的**振幅**由**菲涅尔公式（Fresnel equations）**给出。光波电场可分解为垂直于入射面的 **s 分量**（$E_s$）与平行于入射面的 **p 分量**（$E_p$）。对 s 分量（电场垂直入射面）：

$$r_s = \left(\frac{E_r}{E_i}\right)_s = \frac{n_1\cos\theta_1 - n_2\cos\theta_2}{n_1\cos\theta_1 + n_2\cos\theta_2}, \qquad t_s = \frac{2n_1\cos\theta_1}{n_1\cos\theta_1 + n_2\cos\theta_2}$$

对 p 分量：

$$r_p = \frac{n_2\cos\theta_1 - n_1\cos\theta_2}{n_2\cos\theta_1 + n_1\cos\theta_2}, \qquad t_p = \frac{2n_1\cos\theta_1}{n_2\cos\theta_1 + n_1\cos\theta_2}$$

这里 $\theta_1$、$\theta_2$ 满足斯涅耳定律 $n_1\sin\theta_1 = n_2\sin\theta_2$。$r$、$t$ 是振幅反射率与透射率；**能量反射率（反射比）**是 $R = r^2$，透射比 $T = 1 - R$（无吸收时能量守恒）。<span class="marginnote">菲涅尔公式推导的关键是边界条件：在界面上，电场切向分量连续、磁场切向分量连续。它把几何光学里「反射定律 + 折射定律 + 能量分配」一次性全部给出——几何光学只说光往哪走，菲涅尔公式还说<strong>有多少光被反射、相位是否反转</strong>。</span>

菲涅尔公式立刻解释了三个著名现象：

**半波损失**：光从光疏射向光密（$n_2 > n_1$）正入射时，$r_p = r_s = (n_1 - n_2)/(n_1 + n_2) < 0$——反射光相对入射光相位突变 $\pi$，等效半波损失。这为本专题第一篇《杨氏双缝》的洛埃镜实验提供了微观依据。

**布儒斯特角**：当入射角满足 $\tan\theta_B = n_2/n_1$ 时，$r_p = 0$——p 分量完全透射，反射光只剩 s 分量，成为完全偏振光。这就是布儒斯特窗、偏振眼镜消除水面反光的原理。

**掠入射全反射**：入射角接近 $90°$ 时 $R \to 1$，几乎所有光被反射——湖面的斜照、玻璃墙的反光都源于此。

## 4 公式解析：正入射时的反射率

最常用的特例是**正入射**（$\theta_1 = \theta_2 = 0$）。此时 s、p 分量合并，菲涅尔公式退化为：

$$R = \left(\frac{n_1 - n_2}{n_1 + n_2}\right)^2$$

- **第一步，代入公式**：正入射 $\cos\theta_1 = \cos\theta_2 = 1$，$r = (n_1-n_2)/(n_1+n_2)$，取平方得能量反射率。
- **第二步，空气—玻璃**：$n_1 = 1$、$n_2 = 1.5$，$R = (0.5/2.5)^2 = 0.04$——每面只反射 4%。这就是普通玻璃看起来「透明」的原因。
- **第三步，多层叠加**：虽然单面反射只有 4%，但一片透镜有两个表面，光在两面间还会来回反射；一套 6 片镜头的照相机有 12 个面，累积反射损耗显著，且产生眩光与鬼影。
- **第四步，镀膜**：在表面镀一层折射率介于两者之间、光学厚度为 $\lambda/4$ 的薄膜，两界面反射相消，反射率可降到 0.1% 以下——**增透膜（anti-reflection coating）**。这就是镜头表面那层蓝紫色膜的作用。

## 5 电磁理论给光学带来了什么

把光视为电磁波，光学从此获得了统一且可计算的基础：

| 现象 | 几何/波动时代 | 电磁理论解释 |
| --- | --- | --- |
| 折射率 $n$ | 经验参数 | $n = \sqrt{\mu_r\epsilon_r}$，源于介电响应 |
| 光强 | 主观亮度 | $I = \tfrac12\epsilon_0 c E_0^2$ |
| 半波损失 | 经验规则 | $r < 0$，相位突变 $\pi$ |
| 布儒斯特角 | 观测事实 | $r_p = 0$ 的条件 |
| 反射能量 | 无从计算 | $R = r^2$，能量守恒 $T = 1-R$ |

这些统一不是装饰性的：现代光学工程的每一步——镀膜设计、光纤通信、激光谐振腔、超表面——都直接建立在电磁理论之上。<span class="marginnote">电磁理论也留下两个「未完成」：其一，经典电磁场无法解释黑体辐射谱与光电效应，这需要量子力学（本博客第三级《量子力学》）登场；其二，光速不变引出了狭义相对论。光学再一次成为物理学的先行者。</span>

## 7 小结

- **光是电磁波**：由麦克斯韦方程导出波动方程，真空光速 $c = 1/\sqrt{\mu_0\epsilon_0}$ 从常数中算出。
- 平面电磁波是**横波**，$\mathbf{E}$、$\mathbf{B}$、$\mathbf{k}$ 两两垂直；**光强 $I \propto E_0^2$** 是所有强度计算的基础。
- **菲涅尔公式**给出 s、p 两分量的反射/透射振幅，统一解释**半波损失、布儒斯特角、全反射**。
- 正入射反射率 $R = ((n_1-n_2)/(n_1+n_2))^2$，普通玻璃单面反射 4%，**λ/4 增透膜**可将其降到 0.1% 以下。
- 电磁理论把折射率、光强、反射全部纳入统一框架，但也暴露了经典光学在量子现象上的边界。

在下一节，我们把「光的偏振态」系统化——既然光是横波，电场矢量的取向就大有文章：线、圆、椭圆偏振与琼斯矩阵。
