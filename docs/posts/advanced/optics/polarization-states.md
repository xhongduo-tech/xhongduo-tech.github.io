## 为什么从偏振态开始

前三篇的干涉与衍射，其实只用到了光强（振幅平方）——光矢量的**方向**一直没被认真对待。但光矢量的方向本身携带信息，而且是非常丰富的结构信息：振动方向、振动轨迹、以及振动随时间旋转的方向。这就是**偏振（polarization）**。<span class="marginnote">偏振是「光在垂直于传播方向的平面里怎么振动」的全部学问。它只属于横波——声波是纵波，谈不了偏振；光作为横波，偏振就是它区别于声波的身份证明。偏振态在现代科技里无处不在：3D 电影的偏振眼镜、液晶屏幕的显示原理、光的偏振遥感、量子通信的偏振编码，全是这一个概念的不同变体。</span>这一篇先把偏振态的三大家族——线、圆、椭圆——讲清楚，并给出它们统一的数学描述：两个正交分量的振幅比与相位差。

## 1 偏振：横波的身份证明

回顾第一篇的结论：光是横波，光矢量（电场）垂直于传播方向 $z$。于是在任意时刻，光矢量都在 $z$ 轴垂直的平面里。**光矢量端点的运动轨迹**，就是这个光波的**偏振态（polarization state）**。

沿 $z$ 传播的光，电场可分解为 $x$、$y$ 两个正交分量：

$$E_x = E_{0x}\cos(\omega t - kz + \varphi_x), \qquad E_y = E_{0y}\cos(\omega t - kz + \varphi_y)$$

两分量的**振幅比** $E_{0y}/E_{0x}$ 与**相位差** $\delta = \varphi_y - \varphi_x$，完全决定了偏振态。$\delta = 0, \pi/2, \pi$ 这些特殊值给出线偏振与圆偏振，一般 $\delta$ 给出椭圆偏振。<span class="marginnote">把偏振态看成「一个点的轨迹」，就抓住了要害：$x$、$y$ 两个简谐振动合成，就像两个互相垂直的简谐振动合成李萨如（Lissajous）图形——只是频率相同，所以轨迹是稳定的直线、圆或椭圆，而不是开放的曲线。偏振态其实就是「同频正交振动合成的李萨如图」。</span>

## 2 三种偏振态

### 线偏振（linear polarization）

$\delta = 0$ 或 $\pi$（两分量同相或反相）时，两个分量同时到达最大、同时过零，合成矢量始终沿一条**固定直线**振动：

$$E_y = \frac{E_{0y}}{E_{0x}}E_x$$

振动方向与 $x$ 轴的夹角由振幅比决定：$\tan\theta = E_{0y}/E_{0x}$。线偏振光也叫**平面偏振光**，因为它的光矢量始终在一个固定平面里振动。<span class="marginnote">线偏振光的直觉图像：光矢量像一根绷紧的弦在固定方向上来回「抖」。自然光经偏振片后透出的就是线偏振光，其振动方向就是偏振片的透振方向。太阳镜、相机偏振镜滤掉的是特定方向的偏振分量。</span>

### 圆偏振（circular polarization）

$E_{0x} = E_{0y} = E_0$ 且 $\delta = \pm\pi/2$ 时，两分量振幅相等、相位差 90°。合成矢量的**长度恒定**（$E_0$），方向绕 $z$ 轴匀速旋转——轨迹是一个圆。$\delta = +\pi/2$ 时旋转方向满足右手螺旋，叫**右旋圆偏振（RCP）**；$\delta = -\pi/2$ 为**左旋（LCP）**。<span class="marginnote">旋向约定是偏振学最混乱的地方：有的教材从「迎着光看」定义，有的用右手螺旋。为避免歧义，物理上常用「看向光源方向时矢量顺时针/逆时针旋转」来约定，并说清参考系。做实验前先确认约定，否则左旋右旋会全反——这是偏振文献里最常见的乌龙源头。</span>

### 椭圆偏振（elliptical polarization）

一般情况（振幅不相等、相位差不等于 0 或 π/2）：合成矢量端点画**椭圆**，长轴与短轴的方向和大小由振幅比与相位差共同决定。**线偏振与圆偏振都是椭圆偏振的退化情形**——椭圆偏振是「一般态」，线、圆是两个特例。

## 3 公式解析：椭圆的轨迹方程

消去时间 $t$，把 $E_x$、$E_y$ 的关系写成轨迹方程：

$$\frac{E_x^2}{E_{0x}^2} + \frac{E_y^2}{E_{0y}^2} - 2\frac{E_x E_y}{E_{0x}E_{0y}}\cos\delta = \sin^2\delta$$

逐项拆解：

- **第一步，这是什么**：一个椭圆的方程（$E_x, E_y$ 平面上）。它告诉我们光矢量端点在每一时刻的 $(E_x, E_y)$ 都落在这条椭圆曲线上。
- **第二步，特殊相位差**：$\delta = 0$ 时方程退化为 $(E_x/E_{0x} - E_y/E_{0y})^2 = 0$，即 $E_y = (E_{0y}/E_{0x})E_x$——一条过原点的直线，**线偏振**。$\delta = \pi/2$ 且 $E_{0x} = E_{0y}$ 时退化为 $E_x^2 + E_y^2 = E_0^2$——圆，**圆偏振**。
- **第三步，为什么 $\cos\delta$ 是「混合项」**：椭圆相对于坐标轴是倾斜的（长轴不在 $x$ 或 $y$ 上），正是 $\cos\delta$ 这一项造成倾斜。$\delta = \pi/2$ 时 $\cos\delta = 0$，椭圆长轴恰好沿坐标轴，不倾斜。
- **第四步，看旋转方向**：$\sin\delta$ 的符号决定旋转方向（右旋还是左旋）。$\delta$ 从 0 到 $\pi$ 扫过时，偏振态从线偏振（$\delta=0$）经斜椭圆到圆偏振（$\delta=\pi/2$），再到反向线偏振（$\delta=\pi$）——**半圈相位差走完一整类偏振态**。

## 4 自然光与部分偏振光

现实中我们碰到的绝大多数光，不是上面任何一种「纯偏振态」。

**自然光（natural light）**：普通光源发出的光，光矢量在垂直传播方向的平面里**随机取向**、且随时间无规则变化，任意两个正交方向的振动之间没有固定相位关系。它不是线偏振、圆偏振或椭圆偏振的任何一种，而是**非偏振光（unpolarized light）**。数学上，自然光可分解为两个振幅相等、相位随机变化的正交分量，平均强度各占一半。<span class="marginnote">自然光不是「各方向同时振动」——那会是线偏振。它是「方向无规则地快速变化」，以至于任何瞬间都无法定义固定的振动方向。人眼对偏振不敏感，所以看自然光和部分偏振光没有区别；但偏振片一放，立刻现形：自然光透过任意方向偏振片都是原来一半强度，而线偏振光透过透振方向垂直的偏振片则完全消失。</span>

**部分偏振光（partially polarized light）**：介于自然光与完全偏振光之间——某一方向振动占优，但仍有随机成分。天空散射光是典型的部分偏振光（偏振度随观察方向变化），这就是为什么偏振太阳镜能滤掉天空的眩光。

**偏振度（degree of polarization）**定量描述「偏振的成分占多少」：

$$P = \frac{I_{\max} - I_{\min}}{I_{\max} + I_{\min}}$$

$P = 1$ 是完全偏振光，$P = 0$ 是自然光，中间是部分偏振光。<span class="marginnote">这个定义与干涉条纹的对比度 $V = (I_{\max}-I_{\min})/(I_{\max}+I_{\min})$ 形式完全一样！这不是巧合：对比度度量「干涉的纯度」，偏振度度量「偏振的纯度」，两者都是「相干/有序成分占比」的度量。物理里「有序度」的定义常常长这个模样，从光学到统计力学一脉相承。</span>

## 5 琼斯矢量与庞加莱球：偏振的完整语言

对完全偏振光，有更紧凑的数学表示。**琼斯矢量（Jones vector）**把偏振态写成复数列矢量：

$$\mathbf{J} = \begin{pmatrix} E_{0x} \\ E_{0y}e^{i\delta} \end{pmatrix}$$

线偏振沿 $x$ 是 $(1, 0)^T$，右旋圆偏振是 $\frac{1}{\sqrt{2}}(1, -i)^T$ 等。偏振光学器件（偏振片、波片）对应**琼斯矩阵**，光通过器件就是矩阵乘矢量——偏振计算从此变成线性代数。<span class="marginnote">琼斯矢量只能描述完全偏振光，对部分偏振光需要用<strong>斯托克斯参数（Stokes parameters）</strong>与<strong>穆勒矩阵（Mueller matrix）</strong>——四个实数描述任意偏振态，包括部分偏振与自然光。更漂亮的图景是<strong>庞加莱球（Poincaré sphere）</strong>：所有偏振态一一对应球面上的点——北极右旋圆、南极左旋圆、赤道一圈是各种方向的线偏振，一般点对应椭圆偏振。偏振光学用这「一个球」把全部态装了进去，就像黎曼球面装下全部复数。这套语言是后续《波片》《旋光》的标准工具。</span>

## 6 小结

- **偏振**是横波独有：光矢量在垂直传播方向的平面里的振动轨迹，由两正交分量的**振幅比**与**相位差** $\delta$ 决定。
- **线偏振**（$\delta = 0$ 或 $\pi$）、**圆偏振**（振幅相等、$\delta = \pm\pi/2$）、**椭圆偏振**（一般情形）——椭圆是最一般态，线与圆是退化。
- 轨迹方程 $E_x^2/E_{0x}^2 + E_y^2/E_{0y}^2 - 2(E_xE_y/E_{0x}E_{0y})\cos\delta = \sin^2\delta$，$\delta$ 半圈扫过一类偏振态。
- **自然光**是随机振动的非偏振光，偏振度 $P = (I_{\max}-I_{\min})/(I_{\max}+I_{\min})$，$P=0$ 自然光、$P=1$
