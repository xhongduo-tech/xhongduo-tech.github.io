# 光学（经典与波动光学）

光学研究光的产生、传播及其与物质相互作用的规律，涵盖几何光学、干涉、衍射、偏振与傅里叶光学，是物理专业本科主干必修课，也是连接电磁学与量子力学的关键桥梁。对标权威教材体系，按章节逐节写成博文，学完一个学科 = 写完该学科权威教材对应的全部博文。

## 对标教材

- 赵凯华、钟锡华《光学（上、下册）》北京大学出版社
- E. Hecht, *Optics* (Pearson)
- M. Born, E. Wolf, *Principles of Optics* (Cambridge University Press)
