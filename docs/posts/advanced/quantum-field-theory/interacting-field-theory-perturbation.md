## 为什么从相互作用场论开始

前几篇我们量子化了三个**自由场**——它们各自演化、互不干扰，就像三把调好音却从不同台演奏的乐器。但真实世界是**相互作用**的：电子发射光子、光子被电子散射、正反电子对湮灭成光子。要描述这些，必须在拉格朗日密度里加上耦合项（如 QED 的 $e\bar\psi\gamma^\mu\psi A_\mu$），并发展一套系统的计算工具。这一篇是全书的分水岭：我们把「自由场 + 相互作用」打包成**相互作用绘景 + Dyson 展开 + 费曼图**三件套，从而把「量子场论能算任何过程」变成现实。<span class="marginnote">费曼图的美妙在于：它把「对一个具体物理过程的微扰级数」浓缩成「一张图 + 一套规则」。图不是修饰，图就是计算。P&S 第四章用一整章的篇幅把「从拉格朗日量到费曼规则」的机器完整组装起来。</span>它是上一篇《电磁场量子化》的自然延续——光子与费米子的耦合正是相互作用的最简单样板。

## 1 相互作用绘景与 Dyson 展开

物理里常用三套绘景：薛定谔绘景（态演化、算符不动）、海森堡绘景（算符演化、态不动）、以及这里的主角**相互作用绘景（interaction picture）**——算符按自由哈密顿量 $H_0$ 演化，态按相互作用 $H_{\rm int}$ 演化。拆分：

$$H = H_0 + H_{\rm int}, \qquad U(t, t_0) = T\left\{ \exp\left[-i\int_{t_0}^{t} dt'\, H_{\rm int}^I(t')\right] \right\}$$

**Dyson 展开**把演化算符写成 $H_{\rm int}$ 的时间排序指数，再逐级展开成幂级数。$\mathcal{T}$ 是时间排序算符，它保证「早的算符作用在右、晚的算符作用在左」，从而把因果性编进每一级。<span class="marginnote">Dyson 展开之所以能逐级算，全靠自由场理论可精确求解：$H_0$ 产生的多粒子态、传播子都是闭合的。微扰论的全部前提就是「自由部分有精确解」。</span>

## 2 S 矩阵与相关函数的联系

物理量是**S 矩阵（散射矩阵）**：把「初态粒子」变成「末态粒子」的振幅 $S_{\beta\alpha} = \langle\beta|\mathcal{T}\exp[-i\int d^4x\,\mathcal{L}_{\rm int}]|\alpha\rangle$。展开到第 $n$ 级，振幅由 $n$ 个相互作用顶点的时空积分给出。

**重点**：这一整套可以全部转写进一个优雅的公式——**LSZ 约化公式（Lehmann-Symanzik-Zimmermann）**，它把 S 矩阵元与场的关联函数（Green 函数）联系起来：

$$\langle \text{out}|\text{in}\rangle \sim \prod_i \int d^4x_i\, e^{-ip_i x_i}(i\not\partial-m) \cdots G^{(n)}(x_1,\dots,x_n)$$

LSZ 说的是：**算散射，只要算关联函数 $\langle 0|T\{\phi(x_1)\cdots\}|0\rangle$，再用传播子与波函数「约化」外线即可**。关联函数成了核心对象，而计算关联函数的最强工具是下一节的正规序 + Wick 定理。<span class="marginnote">LSZ 的名字乍看吓人，本质就一句话：<strong>外线是「入射/出射粒子」，内线是「传播子」，顶点是「相互作用」，图就是积分</strong>。LSZ 为这张图提供了严格的证明与归一化规则。</span>

## 3 正规序与 Wick 定理

自由场的乘积里有大量「产生算符在左、湮灭算符在右」以外的杂序，它们的真空期望为零。**正规序（normal ordering）** 把产生算符全部移到左边、湮灭算符全部移到右边，记号 $:\mathcal{O}:$。**Wick 定理**则把任意算符乘积拆成「全部可能的收缩 + 正规序」之和：

$$T\{\phi(x_1)\phi(x_2)\cdots\} = :\text{全部配对 + 收缩}:$$

其中每个**收缩（contraction）** $\overline{\phi(x_i)\phi(x_j)}$ 就是费曼传播子 $D_F(x_i - x_j)$。于是：**一个 $n$ 点的真空期望，等于所有配对方式的传播子乘积之和**——这正是费曼图的代数根源。<span class="marginnote">Wick 定理把「两个场收缩成一个传播子」与「图里连一条线」一一对应。配对方式 = 连线的拓扑结构；每一种配对的贡献 = 该连线的传播子之积。费曼图不是画出来的，是 Wick 展开「排」出来的。</span>

## 4 公式解析：$e^+e^-$ 对产生的最简单过程

以「电子-正电子对从虚光子创生」为例，说明 Dyson 展开与费曼规则的组装。相互作用顶点 $\mathcal{L}_{\rm int} = e\bar\psi\gamma^\mu\psi A_\mu$ 的一级展开给出一个顶点；要对上「初态 $e^+e^-$、末态 $e^+e^-$」需要一个光子介导的两顶点图，其 S 矩阵元（$\phi^4$ 或 QED 各取所需，这里取 QED）写作：

$$
i\mathcal{M} = (ie)^2\, \bar u(p_2)\gamma^\mu v(p_3)\, D_{F\,\mu\nu}(q)\, \bar u(p_4)\gamma^\nu v(p_1)
$$

三步拆解：

- **第一步，读图**：两个费米子顶点（各带 $ie\gamma^\mu$），中间一条光子线（$D_F^{\mu\nu}(q)$，$q$ 是转移动量）。图的「结构」完全由 Wick 收缩决定，$i\mathcal{M}$ 就是「读图写公式」。
- **第二步，读旋量**：$\bar u(p_2)\gamma^\mu v(p_3)$ 是「电子→光子」的跃迁流，$v$ 代表反粒子；$\bar u(p_4)\gamma^\nu v(p_1)$ 是另一条腿。旋量外线符号的书写顺序（$\bar u$ 在前、$v$ 在后）是费曼规则固定的约定。
- **第三步，读守恒**：每个顶点动量守恒，$q = p_2 + p_3 = p_1 + p_4$；每条内线有 $\int \frac{d^4q}{(2\pi)^4}$ 待积（本过程顶点给足，故无剩余积分）。把 $i\mathcal{M}$ 取模方、做自旋求和、代入相空间，就得到散射截面——这就是下一篇《QED 过程计算》的全部工序。

## 5 费曼规则速查

从作用量出发，一套机械化的规则把「图」翻译成「积分」：

| 图形元素 | 代数因子 |
| --- | --- |
| 费米子外线（进/出） | $u(p)$、$\bar u(p)$、$v(p)$、$\bar v(p)$ |
| 费米子内线 | $\frac{i(\not p+m)}{p^2-m^2+i\varepsilon}$ |
| 光子内线 | $\frac{-ig^{\mu\nu}}{k^2+i\varepsilon}$ |
| 顶点 | $-ie\gamma^\mu$ |
| 动量守恒 | 每个顶点 $\delta^{(4)}(\sum p_{\rm in}-\sum p_{\rm out})$ |
| 内线动量 | 未确定的内线动量做 $\int\frac{d^4k}{(2\pi)^4}$ |
| 相对论归一化 | 外线 $\sqrt{2E_{\boldsymbol p}}$、相空间因子 |

**辨析｜易错点**：初学者最常犯的两个错——一是忘了每个顶点要乘 $\delta^{(4)}$ 动量守恒，二是把「外线也归一化」遗漏。正确流程：先写 $\mathcal{M}$，再对其平方，再做自旋/极化和，最后乘相空间因子——顺序错一步，符号就会错。

## 6 真空图与「删掉没意思的图」

Dyson 展开里会出现与外部粒子完全断开的**真空图（vacuum bubbles）**——它们对应真空到真空的跃迁振幅，因子无关地乘在总振幅上。**重点**：在所有可观测量（散射截面）里，真空图与归一化因子相消，可以安全忽略。费曼规则在正式定义时常引入「只保留连通图」的约定，正是为了删掉这些冗余。

## 7 核心对比表：自由场论 vs 相互作用场论

| 性质 | 自由场论 | 相互作用场论 |
| --- | --- | --- |
| 哈密顿量 | $H_0$ 可精确对角化 | $H = H_0 + H_{\rm int}$ |
| 态演化 | 解析 | Dyson 展开 |
| 关联函数 | 单个传播子 | 传播子的配对和（Wick 定理） |
| 计算工具 | 精确 | 费曼图 + 费曼规则 |
| 粒子数 | 守恒 | 不守恒（创生/湮灭） |
| 计算精度 | 精确 | 微扰级数（需小耦合） |

## 7 延伸：微扰论什么时候失效

Dyson 展开假设耦合常数小。QED 的耦合 $\alpha \approx 1/137$ 很小，展开飞快收敛——这正是 QED 精度的来源。但微扰论有两大盲区，值得现在就说清：

**强耦合区**：QCD 在低能下耦合常数 $\alpha_s \sim 1$，微扰级数发散，夸克被禁闭在强子内部——必须靠格点 QCD 等非微扰方法（见《非微扰方法》一篇）。所以「微扰论」不是 QFT 的全部，而是它的半壁江山。

**发散与重正化**：费曼积分到圈图会碰到紫外发散。微扰论展开的每一项都要先「正规化」再「重正化」，无穷大被吸收进物理参数——这是《圈图与发散》《重整化》两篇的主题。今天记住结论：**微扰级数里的每个阶都必须有定义，才算真的可计算**。

在 P&S 第四章的叙事里，费曼规则先于重正化登场，是刻意的教学顺序：先让读者跑通「树图 + 简单圈图」的完整流程，再回头处理发散。<span class="marginnote">一个可执行的心态：<strong>先把「图 → 公式 → 数值」的机器跑顺，再谈它的病痛</strong>。顺序颠倒，你会在无穷大里迷路，永远走不到 Compton 散射的公式。</span>

## 8 小结

- **相互作用绘景**：算符按 $H_0$ 演化、态按 $H_{\rm int}$ 演化；演化算符是时间排序指数（Dyson 展开）。
- **S 矩阵**与关联函数通过 **LSZ 约化公式**相连——算散射 = 算关联函数。
- **Wick 定理**把算符乘积拆成收缩之和，收缩 = 费曼传播子，配对 = 费曼图。
- 从拉格朗日量出发，**费曼规则**机械地把图翻译成 $\mathcal{M}$ 积分。
- 真空图在可观测量里相消，可安全忽略；只保留连通图。

在下一节，我们把这套机器开动起来：用 QED 费曼规则实际计算 $e^+e^- \to \mu^+\mu^-$ 等过程，得到可与实验对照的散射截面——这就是**QED 过程计算**。
