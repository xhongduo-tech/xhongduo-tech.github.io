## 为什么费曼规则是场论的语言

前几节的生成泛函给出了「图 = 配对的求和」，但还没给出「如何把一张图变成数」。
**费曼规则（Feynman rules）** 就是这本翻译词典：每个图元（线、顶点、外腿）对应一个代数因子，把图照规则写成振幅，整张图的值 = 所有因子乘起来 × 对称因子倒数 × 对内动量积分。
<span class="marginnote">费曼规则是<strong>从拉格朗日量到数字振幅</strong>的最短路。同样的规则既可从 Wick 定理推出，也可从路径积分（顶点 = $-i\mathcal{L}_{int}$ 的傅里叶变换）推出——两条路殊途同归，规则表却只有一张。</span>本节以 $\phi^4$ 理论与 QED 为标本，把规则表完整列出来，并讲解最容易出错的对称因子。

## 1 位置空间规则：从拉格朗日量出发

先给「图 ↔ 代数」的对应做一次直观建立。对一个相互作用项 $\mathcal{L}_{\text{int}} = -\frac{\lambda}{4!}\phi^4$，Wick 定理与路径积分都给出：

**传播子（线）**：连接两个时空点 $x, y$ 的线，因子 $D_F(x-y) = \int\frac{d^4p}{(2\pi)^4}\frac{i}{p^2-m^2+i\epsilon}e^{-ip\cdot(x-y)}$。
**顶点**：位于 $x$ 的 4 条线交汇，因子 $-i\lambda\int d^4x$（对顶点位置积分）。

于是 $n$ 阶振幅 = 画出所有顶点、把所有线两两相连（含外腿）、按上述因子相乘、对每个顶点位置积分。位置空间的规则直观但积分繁重——实际计算几乎都在**动量空间**。

## 2 动量空间规则：标准对照表

**动量空间费曼规则**把位置积分消掉，换成「动量守恒 + 动量积分」。对 $\phi^4$ 理论（$\mathcal{L}_{\text{int}} = -\frac{\lambda}{4!}\phi^4$）：

| 图元 | 因子 |
| --- | --- |
| 内线（传播子） | $\frac{i}{p^2 - m^2 + i\epsilon}$ |
| 顶点 | $-i\lambda$ |
| 外腿（入射/出射） | $1$ |
| 每个顶点动量守恒 | $(2\pi)^4\delta^{(4)}\!\left(\sum p_{\text{in}} - \sum p_{\text{out}}\right)$ |
| 每条内线动量 | $\int \frac{d^4k}{(2\pi)^4}$ |
| 对称因子 | $1/S$ |

QED（$\mathcal{L}_{\text{int}} = -e\bar\psi \gamma^\mu\psi A_\mu$）规则：

| 图元 | 因子 |
| --- | --- |
| 电子传播子 | $\frac{i(\not p + m)}{p^2 - m^2 + i\epsilon} = \frac{i}{\not p - m + i\epsilon}$ |
| 光子传播子（费曼规范） | $\frac{-ig_{\mu\nu}}{k^2 + i\epsilon}$ |
| 顶点 | $-ie\gamma^\mu$ |
| 出射电子（外腿） | $\bar u^s(p)$ |
| 入射电子（外腿） | $u^s(p)$ |
| 出射正电子 | $v^s(p)$ |
| 入射正电子 | $\bar v^s(p)$ |
| 出射光子 | $\epsilon^{*\mu}(k)$ |
| 入射光子 | $\epsilon^{\mu}(k)$ |

QED 里外腿不再是 $1$，而是自旋子与极化矢量——因为外腿要「把自由粒子波函数接上去」。<span class="marginnote"><strong>为什么外腿接自旋子</strong>：外腿的 $J$ 导数给出的是「在源处产生粒子的耦合」，正好与入射/出射单粒子态的波函数 $u, \bar u, v, \bar v, \epsilon$ 对应。标量场的外腿是 $1$，因为 $\phi^4$ 顶点无内部结构——最简单的规则来自最简单的理论。</span>

## 3 对称因子：图的「等价计数」

对称因子 $S$ 是初学者最容易栽的坑。它来自：**一张图的 Wick 配对/顶点排列存在 $S$ 种方式给出同一个图**。对 $\phi^4$ 理论：

$$S = \prod_{\text{每个内部顶点}} \left(\text{经顶点交换后的对称数}\right) \times \prod_{\text{每对等价内线}} 2$$

两个最重要的经验法则：

- 连接同一对顶点的**两条等价内线**贡献因子 $2$（如「鱼泡图」的圈）。
- 顶点上若有多条线可以「自我连接」成圈，会有额外的对称性。

例如 $\phi^4$ 理论的「真空图」——一条内线两端都接同一顶点（$\infty$ 形图）——其对称因子 $S = 2\times 3! = 12$。漏算对称因子，振幅就放大一个整数倍。<span class="marginnote">对称因子能算错，是因为「同一张图」有不止一种画法：把图旋转、把顶点重标号，物理上完全同一张。规则的 $1/S$ 正是要除以「画出它的方式数」。<strong>先画图，再逐项数对称性，是唯一可靠的方法。</strong></span>

## 4 公式解析：$\phi^4$ 树级 4 点振幅

**费曼规则的第一场实战：两粒子散射到两粒子，树级。** 拆解三步：

$$
-i\mathcal{M} = (-i\lambda)^2 \frac{i}{(p_1+p_2)^2 - m^2 + i\epsilon} \times (\text{三通道之和})
$$

- **第一步，画图**：入射 $p_1, p_2$，出射 $p_3, p_4$。树级只有三个拓扑：$s$ 通道（中间线动量 $p_1+p_2$）、$t$ 通道（$p_1-p_3$）、$u$ 通道（$p_1-p_4$）。每条通道：两个顶点（$(-i\lambda)^2$）× 一根内线 $\frac{i}{q^2-m^2}$。
- **第二步，写因子**：每条通道的值 $= (-i\lambda)^2 \frac{i}{q^2 - m^2 + i\epsilon}$。三个通道相加，因为「三张图」是三种独立的过程振幅。$s$ 通道的 $q = p_1+p_2$，$t$ 通道的 $q = p_1-p_3$，$u$ 通道的 $q = p_1-p_4$。
- **第三步，对称因子与守恒**：树级 4 点图没有等价内线，$S = 1$；四个顶点动量守恒 $\delta$ 函数自动把中间线动量唯一固定为上述值——所以树级不需要内动量积分。**树级规则 = 全部由外动量决定，是最干净的费曼规则应用。**

## 5 辨析｜易错点

- **费米子传播子分母的符号**：$\frac{i}{\not p - m}$（不是 $+m$）。而分母里的 $\not p$ 是 $\gamma^\mu p_\mu$，不是数——矩阵求逆意味着「乘以 $\not p + m$ 再除以 $p^2 - m^2$」。
- **费米子线方向与闭合环的 $-1$**：费米子线带箭头（正时向），闭合费米子环贡献一个额外 $-1$（因为反对易的循环次序）。**每条闭合费米子环 × (−1)**，漏掉会整体错符号。<span class="marginnote"><strong>括号里的小规定</strong>：外腿的 $u/\bar u/v/\bar v$ 要看「入射/出射 + 粒子/反粒子」四个组合；$\bar u$ 总在入射电子、$v$ 总在出射正电子的位置上。沿费米子线从后往前读矩阵因子。</span>
**对称因子的「顶点重排」别与「图同构」混淆**：只有**不改变图结构**的置换才产生对称因子。两条不同内线互换位置但图看起来一样，才计 $2$；若两条线物理上可区分，不计。

## 6 延伸：从规则到自动化计算

费曼规则把「物理过程」翻译成「代数表达式」，这给现代计算打开了两条路：

**FeynArts + FormCalc**：符号计算软件直接按规则生成振幅、做旋量代换与迹运算，取代手工的 Casimir 技巧。今天的标准模型精确计算（如 $g-2$、Higgs 过程）几乎全依赖这类工具。
**MadGraph / Comix**：自动生成树级振幅并按能量排序，LHC 唯象学的标准流水线。它内部做的正是「枚举图 + 查规则表 + 数值求值」。

理解手工规则仍然是必要的——因为**自动化工具只能处理规则表里已有的东西**。对称因子、规范选择、费米子符号约定、截断与正规化，这些「规则的规则」必须由人理解。当物理超出已知规则（新物理模型、非标准顶点），你要能自己写新的规则表。

一个练习建议：别只背规则表，试着把 $\phi^4$ 与 QED 的规则分别从「Wick 定理」和「路径积分」各推一遍。推通了，你就拥有了「为什么规则长这样」的深层答案，而不是「规则长这样」的表面记忆。

## 7 小结

- 费曼规则 = 从拉格朗日量到振幅的翻译表：线、顶点、外腿各一因子。
- $\phi^4$：传播子 $\frac{i}{p^2-m^2}$，顶点 $-i\lambda$，外腿 $1$，动量守恒 + 内动量积分。
- QED：电子 $\frac{i}{\not p - m}$，光子 $\frac{-ig_{\mu\nu}}{k^2}$，顶点 $-ie\gamma^\mu$，外腿 $u,\bar u,v,\bar v,\epsilon$。
- **对称因子 $1/S$** 修正图的「重画等价性」；闭合费米子环 ×(−1)。
- 树级图无内动量积分，振幅直接由外动量确定。

在下一节，我们回答「算出的振幅 $i\mathcal{M}$ 怎么变成实验可测的数」——**S 矩阵与散射截面**，把量子场论与对撞机数据接上。
