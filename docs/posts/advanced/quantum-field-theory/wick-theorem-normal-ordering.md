# Wick 定理与正规序

<div class="epigraph">
<p>把所有产生算符挪到左边——剩下的那一点「收缩」，就是费曼图的全部秘密。</p>

## 为什么需要正规序

有了自由场，下一步是加相互作用——比如 $\mathcal{L}_{\text{int}} = -\frac{\lambda}{4!}\phi^4$。
微扰论需要计算**时序乘积** $T\{\phi(x_1)\phi(x_2)\cdots\}$ 在真空里的期望值。
但场算符 $\phi$ 是 $a$ 与 $a^\dagger$ 的混合：对易/反对易关系会让乘积里的算符顺序非常混乱，直接硬算是灾难。
**正规序（normal ordering）** 是整理工具，**Wick 定理** 则是把「时序乘积归约为正规序 + 收缩」的机器——它一次性地把场论计算变成了**配对（contraction）的求和**，而每个配对就是一条费曼图的线。<span class="marginnote">Wick 定理的威力：<strong>把量子场论的真空期望值问题，翻译成古典的组合配对问题</strong>。微扰展开的每一阶，真空期望 = 所有可能的「配对」贡献之和——这正是费曼图为什么是图：每条配对线就是一根传播子。</span>

## 1 正规序：让真空期望归零

**正规序（normal ordering）**：把每个场算符里的产生算符 $a^\dagger, b^\dagger$ 全部挪到湮灭算符 $a, b$ 的左边。记作 $:\mathcal{O}:$。例如：

$$:\phi(x)\phi(y): = \phi^+(x)\phi^+(y) + \phi^-(x)\phi^+(y) + \phi^+(y)\phi^-(x) + \phi^-(x)\phi^-(y)$$

其中 $\phi^+$ 是产生部分、$\phi^-$ 是湮灭部分。正规序的核心性质：

$$\langle 0 | :\mathcal{O}: | 0 \rangle = 0$$

因为正规序里产生算符都在左边、湮灭算符都在右边，作用在 $|0\rangle$ 上时湮灭算符直接给出 0。
<span class="marginnote">一句话直觉：<strong>正规序 = 抹掉真空零点涨落</strong>。它把「无穷大零点能」这类问题物理地定义为「不计入」——重正化的第一次手动操作。</span>于是哈密顿量里那些 $\frac12[a,a^\dagger]\delta^{(3)}(0)$ 常数项，在正规序记号下自动消失：$H = \int \frac{d^3p}{(2\pi)^3}E_{\boldsymbol{p}}\, a^\dagger a = :H:$。

## 2 收缩与费曼传播子

**收缩（contraction）** 定义：两个场算符的收缩是它们的时序乘积减去正规序之差：

$$\overset{\text{\_\_}}{\phi(x)\phi(y)} \equiv T\{\phi(x)\phi(y)\} - :\phi(x)\phi(y):$$

收缩是一个**c 数**（普通函数，不再是算符），它对玻色子取对易子、对费米子取反对易子。在自由场论里，这个 c 数正是**费曼传播子（Feynman propagator）**：

$$\overset{\text{\_\_}}{\phi(x)\phi(y)} = \langle 0 | T\{\phi(x)\phi(y)\} | 0\rangle = D_F(x-y) = \int \frac{d^4p}{(2\pi)^4}\frac{i}{p^2 - m^2 + i\epsilon}e^{-ip\cdot(x-y)}$$

传播子回答「从 $y$ 到 $x$ 传播一个粒子的振幅」。
$i\epsilon$ 小量是因果性的签名：它把正频解沿 $t_x > t_y$ 传播、负频解沿 $t_x < t_y$ 传播的次序编码进积分围道。<span class="marginnote">$i\epsilon$ 不是数值上的可忽略项——它决定了围道绕极点的方向，等价于「正能向前传播、反能向后传播」。没有 $i\epsilon$，传播子就定义不清。</span>

## 3 Wick 定理

**Wick 定理（Wick's theorem）**：$N$ 个场算符的时序乘积，等于把这些算符做**全部分组**，每组内两两收缩、组间保持正规序，再把所有项相加：

$$T\{\phi_1\phi_2\cdots\phi_N\} = :\phi_1\cdots\phi_N: + \sum_{\text{单收缩}} :\cdots\overset{\text{\_\_}}{\phi_i\phi_j}\cdots: + \sum_{\text{双收缩}} :\cdots: + \cdots$$

对费米子每个收缩项还带一个 $(-1)$ 符号（交换奇偶次）。
这个定理可以用归纳法证明：先证明 $T\{AB\} = :AB: + \overset{\text{\_\_}}{AB}$（收缩的定义就是它自己），再逐次插入新场并利用对易/反对易关系把「移位产生的项」全部吸收成收缩。<span class="marginnote"><strong>Wick 定理不是假设，是 $T\{AB\} = :AB: + \text{收缩}$ 的反复迭代</strong>。每加入一个场，要么进入正规序部分，要么与前面的场形成新收缩——组合学决定它必然长成「所有配对」的形式。</span>

## 4 公式解析：真空期望 = 完全收缩之和

**Wick 定理最常用的特例：$N$ 个场的时序乘积取真空期望。** 正规序部分贡献为零，只有「完全收缩」（每个场都被配对）才存活：

$$
\langle 0 | T\{\phi(x_1)\phi(x_2)\phi(x_3)\phi(x_4)\} | 0\rangle = D_F(x_1-x_2)D_F(x_3-x_4) + D_F(x_1-x_3)D_F(x_2-x_4) + D_F(x_1-x_4)D_F(x_2-x_3)
$$

三步拆解：

- **第一步，为什么只有完全收缩**：真空期望 $\langle 0|:\cdots:|0\rangle = 0$。任何留下未配对场的项，其正规序里总有一侧是真空态作用——给出 0。所以只有**每一对都缩完**的项非零。
- **第二步，计数配对**：4 个场有 $3$ 种完全配对方式：$(12)(34), (13)(24), (14)(23)$。一般地 $2N$ 个场的完全收缩数是 $(2N-1)!! = (2N-1)(2N-3)\cdots 1$。这个组合数正是「$\phi^4$ 理论 N 阶图的数量级」。
- **第三步，物理读图**：每一项 $D_F(x_i-x_j)$ 都是「$i$ 与 $j$ 之间一根传播子」。$x_1$ 到 $x_4$ 的 $4$-点真空期望 = 3 根「线」把 4 个端点两两连起来——**这正是树级 4 点图的 3 种拓扑**。组合配对 → 费曼图，一步到位。

## 5 辨析｜易错点

- **正规序不改变算符代数、只改变定义**：$:\phi(x)\phi(y): \neq \phi(x)\phi(y)$ 作为算符是相等的？不——正规序是「重新排列」后的**新算符**，等于原乘积**减去收缩**。它改变了算符本身，是定义层面的操作，不是恒等变形。<span class="marginnote"><strong>对易 vs 反对易的符号</strong>：费米子的 Wick 定理每个收缩交换都要乘 $(-1)$。若忘记这个符号，费米子费曼图整体相位会错——典型考题陷阱。</span>
- **收缩总是 c 数、且总是自由场传播子**：收缩是在自由场论里定义的（$a, a^\dagger$ 代数）。相互作用图像里 Wick 定理照用，但收缩仍是**自由**传播子 $D_F$——相互作用效应全部体现在「顶点」，而不是改动传播子本身。
- **把 $D_F$ 当成「真实的场传播」**：$D_F(x-y)$ 既含正能向前、也含反能向后的部分。它不是一个「粒子从 $x$ 走到 $y$」的简单概率幅，而是场论因果性的打包对象。读懂 $i\epsilon$ 才能读懂它。

## 6 延伸：收缩、传播子与图的计数

Wick 定理给场论装上了一个「组合机器」，它的三个输出值得单独强化：

- **收缩 = 自由传播子**：$T\{\phi\phi\} - :\phi\phi:$ 是 c 数，等于 $D_F(x-y)$。读作「两点之间的关联」——传播子是一条线，因为关联是两两的。
- **完全收缩计数**：$2N$ 个场有 $(2N-1)!!$ 种配对。对 $\phi^4$ 的 4 点函数，$3$ 种配对 = 3 张树图；对更高阶，这个数给出「图的拓扑数量级」。
- **正规序 = 去掉真空涨落**：$:\mathcal{O}:$ 对真空期望为零，等价于「把零点能、虚粒子对这类纯量子噪声定义为不计入」。

这套「配对求和」的语言在路径积分里会再次出现：$Z_0[J] = \exp(-\frac12\int J D_F J)$ 的展开，每一项的 $J$ 配对正是 Wick 收缩。**正则量子化的 Wick 定理与路径积分的高斯积分，是同一个物理的两种语法。**

一个实用的提示：费米子的 Wick 定理每交换一对产生一个 $(-1)$。做涉及费米子圈的图（比如电子自能）时，闭合费米子环的整体 $(-1)$ 是「反周期边界条件」的签名，漏掉它振幅就错符号。

### 本节记忆锚点

- 正规序：产生算符全部左移，真空期望为零。
- 收缩 = 传播子：$D_F(x-y) = \int\frac{d^4p}{(2\pi)^4}\frac{i}{p^2-m^2+i\epsilon}e^{-ip\cdot(x-y)}$。
- 完全收缩计数：$(2N-1)!!$；4 点真空期望 = 3 种配对 = 3 张树图。
- 费米子符号：每次交换一个 $(-1)$，闭合环整体 ×(−1)。
- 交叉引用：与《组合数学》的配对计数、第二级《量子力学》的谐振子对照。

## 7 小结

- **正规序** $:\mathcal{O}:$ 把产生算符全挪到左、湮灭全挪到右，真空期望为零，抹掉零点涨落。
- **收缩** $\overset{\text{\_\_}}{\phi(x)\phi(y)} = T\{\cdots\} - :\cdots:$ 是 c 数，等于自由场费曼传播子 $D_F(x-y)$。
- **Wick 定理**：时序乘积 = 所有配对方式的求和（费米子带符号）。
- 真空期望只留**完全收缩**；$2N$ 场的完全收缩数是 $(2N-1)!!$，对应费曼图的拓扑计数。
- 传播子里的 $i\epsilon$ 是因果性的签名。

在下一节，我们把 Wick 定理接上相互作用——用时序微扰展开构造**费曼路径积分**与路径积分量子化，那是另一种全新的量子化视角。
