# 对称性保护与十重分类

<div class="epigraph">
<p>自由费米子的拓扑态只有十种，不多不少——这张由对称性写成的周期表，是过去半个世纪凝聚态物理最深刻的收获之一。</p>

## 为什么从十重分类开始

读到这里，你已经见过陈数（量子霍尔）、$Z_2$（量子自旋霍尔与三维拓扑绝缘体）、绕数（SSH 与 Kitaev 链）、手性电荷（外尔点）——这么多不变量，它们之间是什么关系？有没有一个统一的框架把它们一网打尽？答案是肯定的，而且优雅得惊人：**只要系统是无相互作用的费米子、具有某个能隙（绝缘体或超导体），它的拓扑分类只由三条离散对称性决定，一共只有十类，且不变量随空间维数按 8 为周期循环。**<span class="marginnote">这就是 <strong>Altland–Zirnbauer 十重分类</strong>（也叫 AZ 分类 / 周期表）。它 1997 年由 Altland 与 Zirnbauer 从随机矩阵理论提出，2008 年 Schnyder、Ryu、Furusaki、Ludwig 与 Kitaev 把它翻译成拓扑物态的完整周期表。它回答的问题朴素而彻底：「拓扑绝缘体与拓扑超导体的所有可能类型，总共就这十种。」</span>

这一节，我们把前八节的零散不变量放进这张周期表，看清「对称性 → 拓扑分类 → 不变量 → 维数」这条完整链条，然后讨论一个更深的问题：能带论之外的相互作用会把这张表改成什么样。

## 1 三条离散对称性：T、P、S

AZ 分类的输入是三条离散（反幺正/幺正）对称性，每条要么存在、要么不存在，存在时其「平方」还有两种可能。它们是：

**时间反演对称（TRS）**，算符 $T$：把 $\mathbf{k}$ 映到 $-\mathbf{k}$，且 $T^2 = \pm 1$。对自旋 $1/2$ 费米子 $T^2 = -1$；对无自旋（或自旋单态）系统 $T^2 = +1$；不存在时记 $T = 0$。
**粒子-空穴对称（PHS）**，算符 $C$：BdG 超导自带的对称性，$C^2 = \pm 1$ 或 $C = 0$。
**手征对称（chiral/sublattice symmetry）**，算符 $S$：$S = T \cdot C$（当 $T, C$ 都存在时），或单独定义。$S^2 = 1$，把哈密顿量映到自身变号。

每条对称性有一个「二值 + 特殊情况」的取值空间，排列组合给出 $3 \times 3 = 9$ 种组合，再加上「$T = 0, C = 0$ 但 $S$ 存在」这第 10 种，正好是 **10 个 AZ 类**。<span class="marginnote">这三个「算子」并非平等的：$T$ 与 $C$ 是反幺正（含复共轭），$S$ 是幺正。它们对哈密顿量的作用分别是 $T H(\mathbf{k}) T^{-1} = H(-\mathbf{k})$、$C H(\mathbf{k}) C^{-1} = -H(-\mathbf{k})$、$S H(\mathbf{k}) S^{-1} = -H(\mathbf{k})$。记不住这些式子的精确形式没关系——记住「对称性把 $H$ 映到自身或负自身、并决定 $\mathbf{k}$ 是否反号」就够用了。</span>

**辨析｜易错点：** 十重分类里的「时间反演」与日常讲的「时间反演不变」需要分清。一个材料可以「保持时间反演」但 $T^2$ 不同（自旋 $1/2$ 是 $-1$，无自旋是 $+1$），它们落入**不同的 AZ 类**。所以「$T$ 存在」还不够，必须同时说明 $T^2 = \pm 1$——这是初学者最容易丢的信息。

### 三个对称性在能带/BdG 系统中的「出场位置」

把三条对称性与前几节的物理一一对应，能帮你建立「对称性 → 物理对象」的直觉：

**$T$ 出现在普通能带系统**：量子自旋霍尔（AII 类）、量子霍尔（破缺 $T$ 后落入 A 类）——它管的是「自旋向上/向下」的配对。
**$C$ 出现在 BdG 超导系统**：Kitaev 链（D 类）、DIII 类拓扑超导——它管的是「电子/空穴」的配对。
**$S$ 是「子格/手征」对称**：SSH 模型的子格对称（AIII 类）、某些超导的手征对称——它管的是「两分空间」的配对。

这条对应关系也解释了为什么周期表里「AII 的 $Z_2$」与「D 的 $Z_2$」长得像却物理上不同：前者保护的是螺旋边缘态（绝缘体），后者保护的是 Majorana 零模（超导体）——同一格点符号，两套物理。

## 2 周期表：维数、不变量与 Bott 周期

给定 AZ 类与空间维数 $d$，拓扑不变量由 K 理论（或等价地，Clifford 代数分类）给出。结果落进三档：**$\mathbb{Z}$**（整数，如陈数）、**$\mathbb{Z}_2$**（二值，如 $Z_2$ 指标）、**$0$**（无拓扑）。最奇妙的是 **Bott 周期性**：表格沿维数方向以 8 为周期重复。<span class="marginnote">Bott 周期（Bott periodicity）是数学里一条深奥定理：复 K 理论的分类空间以 2 为周期，实 K 理论以 8 为周期。物理上它意味着：三维的某种拓扑绝缘体的「高维表亲」，可以在 3+8=11 维再现同样的分类。虽然实验上走不到 11 维，但周期表在维度方向的「翻译」为理解不同维度物态之间的关系提供了坐标系。</span>

用几个我们已经见过的「坐标点」来给这张表定位：

| AZ 类 | $T$ | $C$ | $S$ | 一维 | 二维 | 三维 |
| --- | --- | --- | --- | --- | --- | --- |
| A（无对称） | 0 | 0 | 0 | $0$ | $\mathbb{Z}$ | $0$ |
| AII（自旋，$T^2=-1$） | $-1$ | 0 | 0 | $0$ | $\mathbb{Z}_2$ | $\mathbb{Z}_2$ |
| AIII（手征） | 0 | 0 | 1 | $\mathbb{Z}$ | $0$ | $\mathbb{Z}$ |
| D（超导，$C^2=+1$） | 0 | $+1$ | 0 | $\mathbb{Z}_2$ | $\mathbb{Z}$ | $0$ |
| DIII（自旋超导） | $-1$ | $+1$ | 1 | $\mathbb{Z}_2$ | $\mathbb{Z}_2$ | $\mathbb{Z}$ |

对照检查我们前八节讲过的每一个不变量，全部对号入座：整数量子霍尔是 A 类二维的 $\mathbb{Z}$（陈数）；量子自旋霍尔与三维拓扑绝缘体是 AII 类二维/三维的 $\mathbb{Z}_2$；Kitaev 链是 D 类一维的 $\mathbb{Z}_2$（绕数模 2）；SSH 模型是 AIII 类一维的 $\mathbb{Z}$（绕数）。<span class="marginnote">这张表的「翻译能力」是它最大的价值：你不需要记住每一个具体模型的每一个不变量，只要知道它属于哪个 AZ 类、处于几维，就能读出它的拓扑分类。反过来，若要设计某种「新」拓扑态，先看它落在周期表的哪个格子，就知道用哪种不变量去度量。</span>

## 3 完整周期表：全部十类 × 八个维度

把十个 AZ 类与维度 $d = 0$ 到 $7$ 全部列出来，就是那张著名的「周期表」。表格中 $\mathbb{Z}$ 表示整数不变量（陈数、绕数）、$\mathbb{Z}_2$ 表示二值不变量、$2\mathbb{Z}$ 表示偶数整数（自旋单态系统给出的偶数化约束）、$0$ 表示无拓扑分类：

| AZ 类 | $T$ | $C$ | $S$ | $d=0$ | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ | $7$ |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| A | 0 | 0 | 0 | $\mathbb{Z}$ | 0 | $\mathbb{Z}$ | 0 | $\mathbb{Z}$ | 0 | $\mathbb{Z}$ | 0 |
| AIII | 0 | 0 | 1 | 0 | $\mathbb{Z}$ | 0 | $\mathbb{Z}$ | 0 | $\mathbb{Z}$ | 0 | $\mathbb{Z}$ |
| AI | $+1$ | 0 | 0 | $\mathbb{Z}$ | 0 | 0 | 0 | $2\mathbb{Z}$ | 0 | $\mathbb{Z}_2$ | $\mathbb{Z}_2$ |
| BDI | $+1$ | $+1$ | 1 | $\mathbb{Z}_2$ | $\mathbb{Z}$ | 0 | 0 | 0 | $2\mathbb{Z}$ | 0 | $\mathbb{Z}_2$ |
| D | 0 | $+1$ | 0 | $\mathbb{Z}_2$ | $\mathbb{Z}_2$ | $\mathbb{Z}$ | 0 | 0 | 0 | $2\mathbb{Z}$ | 0 |
| DIII | $-1$ | $+1$ | 1 | 0 | $\mathbb{Z}_2$ | $\mathbb{Z}_2$ | $\mathbb{Z}$ | 0 | 0 | 0 | $2\mathbb{Z}$ |
| AII | $-1$ | 0 | 0 | $2\mathbb{Z}$ | 0 | $\mathbb{Z}_2$ | $\mathbb{Z}_2$ | $\mathbb{Z}$ | 0 | 0 | 0 |
| CII | $-1$ | $-1$ | 1 | 0 | $2\mathbb{Z}$ | 0 | $\mathbb{Z}_2$ | $\mathbb{Z}_2$ | $\mathbb{Z}$ | 0 | 0 |
| C | 0 | $-1$ | 0 | 0 | 0 | $2\mathbb{Z}$ | 0 | $\mathbb{Z}_2$ | $\mathbb{Z}_2$ | $\mathbb{Z}$ | 0 |
| CI | $+1$ | $-1$ | 1 | 0 | 0 | 0 | $2\mathbb{Z}$ | 0 | $\mathbb{Z}_2$ | $\mathbb{Z}_2$ | $\mathbb{Z}$ |

这张表有几条值得细看的规律：

**右上-左下的「反三角」平移**：每一行沿 $d$ 增大方向，非零条目按「$\mathbb{Z} \to 0 \to \mathbb{Z}_2 \to \mathbb{Z}_2 \to \mathbb{Z} \to 0 \to 0 \to 0$」（实类）或「$\mathbb{Z} \to 0$ 交替」（复类）循环——这就是 **Bott 周期**（实类周期 $8$，复类周期 $2$）。
**对角线结构**：$d$ 增大时，某一行与「升高一行」的关系是固定的：$\mathbb{Z}$（某类 $d$ 维）总伴随 $\mathbb{Z}_2$（下一类 $d+1$ 维）。这正是「维数提高一类就降级」的层级关系。
**我们熟悉的所有格点**：A 类 $d=2$ 的 $\mathbb{Z}$（陈数）、AII 类 $d=2,3$ 的 $\mathbb{Z}_2$、D 类 $d=1$ 的 $\mathbb{Z}_2$（Kitaev）、AIII 类 $d=1$ 的 $\mathbb{Z}$（SSH 绕数），全部是这张大表的「坐标」。

十重分类的「十」是怎么数出来的？用群论/Clifford 代数可以严格推出，但最朴素的计数可以这样理解——对 $T$ 与 $C$，各自的「取值」有三种：不存在（记 $0$）、存在且平方 $+1$（记 $+1$）、存在且平方 $-1$（记 $-1$）。于是 $T$ 有 3 种、$C$ 有 3 种，共 $3\times3 = 9$ 种组合。$S$ 不是独立变量：

- **第一步，先看 $T$ 与 $C$**：九种组合里，每一种都自动决定 $S$ 是否「存在」：$S = TC$。当 $TC$ 是良定义的对称性时，$S$ 存在；特殊地，$T = C = 0$ 的组合里 $S$ 不存在，这是普通 A 类。
- **第二步，加出手征独有的情形**：存在 $T = 0, C = 0$ 但 $S$ 单独存在的类（AIII，手征幺正类）——$S$ 可以独立于 $T, C$ 存在。于是总数 $9 + 1 = 10$。
- **第三步，检查闭合性**：可以验证，这 10 类在「组合、取子、对偶」的代数操作下闭合——它们构成 Clifford 代数的完整分类，不多不少。

**辨析｜易错点：** 千万别以为「$T$ 与 $C$ 都为零 = A 类」这个等式在「$S$ 单独存在」时不成立。**A 类要求「三条对称性全没有」**；只要 $S$ 存在（哪怕 $T = C = 0$），就落入 AIII 类。判断 AZ 类必须三条对称性逐一排查，不能只查 $T$ 与 $C$。

## 4 公式解析：对称性作用式——从哈密顿量读出 AZ 类

十重分类的全部输入，浓缩在三条「对称性作用式」里。把每一项拆开，你就能自己判断任何自由费米子哈密顿量落在哪一类：

$$T H(\mathbf{k}) T^{-1} = H(-\mathbf{k}), \qquad C H(\mathbf{k}) C^{-1} = -H(-\mathbf{k}), \qquad S H(\mathbf{k}) S^{-1} = -H(\mathbf{k})$$

- **第一步，盯住「变号」与「反号」两处开关**：三条式子只在两个地方不同——$H$ 是保持符号（$T$）还是取负（$C, S$），动量 $\mathbf{k}$ 是反号（$T, C$）还是不反（$S$）。$C$ 与 $S$ 都把 $H$ 取负，意味着它们都保证「能谱关于 $E=0$ 对称」；而 $S$ 不反 $\mathbf{k}$，是说手征对称是「逐点（每个 $\mathbf{k}$ 各自）」成立的——这一点把 AIII 类与 D/DIII 类清楚地区分开。
- **第二步，补上平方符号**：$T^2, C^2$ 各取 $\pm 1$。平方符号有可观测后果：$T^2 = -1$ 给出 Kramer 简并（每条能级至少二重），这正是 AII 类 $Z_2$ 分类「多出来的那一层结构」的来源；$C^2 = +1$ 与 $C^2 = -1$ 则区分 D 类与 C 类不同的配对方式。
- **第三步，验证闭合**：把三条式子连起来检查相容性——若 $T, C$ 同时成立则 $S = TC$ 必自动成立；若 $S$ 成立而 $T = C = 0$，就是手征独有的 AIII 类。三次检查做完，$3 \times 3 + 1 = 10$ 类自然闭合，不多不少。

**辨析｜易错点：** 反号与变号是两件独立的事。$T$「反号不取负」：时间反演翻转动量、保持能量；$C$「反号且取负」：粒子-空穴变换同时翻转动量并配对负能；$S$「取负不反号」：子格变换逐点配对能谱。把「$\mathbf{k}$ 是否反号」与「$H$ 是否变号」当作两个独立坐标去读这张表，就能避开绝大多数分类错误。

## 5 十重分类的物理含义：什么被「保护」

「对称性保护」这四个字到底指什么？它的精确含义是：**只要保持该对称性，两个属于不同 AZ 类的哈密顿量之间就不存在「保持对称性且能隙始终开启」的连续路径**。换句话说：

- 对称性限定「合法形变」的范围；
- 在合法形变范围内，拓扑不变量不变；
- 要改变拓扑类，要么关闭能隙，要么破缺对称性。

这给「拓扑相」下了精确的定义：**在「保持对称 + 保持能隙」的条件下不能互相连续变形的两个态，属于不同的拓扑相。**<span class="marginnote">注意这个定义里「对称性」与「能隙」是两把锁：只保持对称不保持能隙，可以通过金属态绕路（能隙关闭处拓扑定义失效）；只保持能隙不保持对称，也可以通过「偷偷破缺对称再恢复」绕路。两把锁同时锁住，「相」才分得开。</span>

从这里能推出几个前几节已经「用起来」但没挑明的结论：

**为什么外磁场破坏 $T$ 后量子化消失**：外场把系统从 AII 类（$T^2=-1$）推到了别的类，$Z_2$ 不变量失去定义或变成平凡。
**为什么 Majorana 零模的「零能」被钉死**：零能是 D/DIII 类里粒子-空穴对称的固定点，破缺 $C$ 才能移动它。
**为什么手征对称保护 SSH 的 $\pi$ 相位**：AIII 类的一维 $\mathbb{Z}$ 不变量要求 $S$ 存在，破坏子格对称后绕数失去意义。

## 6 超越能带论：相互作用与拓扑序

十重分类的前提是「无相互作用的自由费米子」。真实材料有电子-电子相互作用，问题立刻变复杂：**相互作用能摧毁或创造拓扑态吗？** 答案对「能带拓扑」是——有些被摧毁（如某些 $Z_2$ 被关联效应破坏），有些反而被创造（相互作用驱动的拓扑相，如 Haldane 在自旋链上预言的物态）。<span class="marginnote">相互作用把分类从「十重」推向「无限丰富」：出现了不在十重表里的新物态——<strong>拓扑序（topological order）</strong>，它没有对称性保护，也能有非平凡的基态简并与非阿贝尔任意子。分数量子霍尔效应就是拓扑序的典范：同样的几何、同样的磁场，电子间相互作用把「填充因子」变成了分数。这是下一节《分数陈绝缘体与拓扑序》的主题。</span>

**辨析｜易错点：** 「对称性保护的拓扑相（SPT）」与「拓扑序（topological order）」是两类不同的物态，常被混淆。**SPT 必须靠对称性才能非平凡（如 $Z_2$ 拓扑绝缘体），破缺对称就变成平庸；拓扑序不需要任何对称性就非平凡（如分数量子霍尔、自旋液体），基态简并度与准粒子统计由其内在结构决定。** 简单说：SPT 是「借对称性的光」，拓扑序是「自带光芒」。

## 7 小结

- **AZ 十重分类**：自由费米子拓扑态的完整分类由 $T, C, S$ 三条离散对称性决定，共 10 类。
- **周期表**：每类在维数 $d$ 下的不变量为 $\mathbb{Z}$、$\mathbb{Z}_2$ 或 $0$，沿维数以 8 为周期（Bott 周期）。
- **对号入座**：陈数 = A 类二维 $\mathbb{Z}$；$Z_2$ = AII 类 $\mathbb{Z}_2$；Kitaev 绕数 = D 类一维 $\mathbb{Z}_2$；SSH 绕数 = AIII 类一维 $\mathbb{Z}$——前几节的所有不变量都在表上有自己的格子。
- **对称性保护的定义**：在「保持对称 + 保持能隙」两把锁下不能连续变形，才算不同拓扑相；破缺对称或关闭能隙都能「绕路」。
- **能带论的边界**：十重分类只对无相互作用的费米子成立；相互作用既能摧毁也能创造拓扑态，还孕育出十重表之外的拓扑序。

在下一节，我们将看向十重分类里最耀眼的角落：当 D 类一维系统的绕数取到非平凡值，链两端会出现一种能用于量子计算的奇异准粒子——**拓扑超导体与 Majorana 零模**。
