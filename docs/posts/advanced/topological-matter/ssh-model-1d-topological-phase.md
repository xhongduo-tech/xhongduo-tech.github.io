## 为什么从 SSH 模型开始

前几节的舞台都在二维以上：布里渊区是环面，不变量是陈数。但拓扑物态的最小模型其实藏在**一维**里——一条「单键双键交替」的碳链。1979 年，苏武沛（Su）、施里弗（Schrieffer）与黑格（Heeger）为了解释聚乙炔（polyacetylene）的导电性反常，写出了后来被称为 **SSH 模型**的紧束缚哈密顿量。他们当时并不知道自己造出了一件拓扑物态的标准教具：**它只有两条能带、一个二值的 Zak 相位、两个「相位不同」的端点态，却完整展现了拓扑绝缘体的全部精髓**。<span class="marginnote">SSH 模型之所以珍贵，是因为它「小而全」：能用纸笔精确解出基态、边缘态、拓扑不变量和相变点，是检验任何拓扑概念的试金石。后来的研究者常把它当作「一维拓扑学实验室」——几乎每一本拓扑物态教材都用它开篇，也正是本专题如此编排的原因。</span>

这一节，我们亲手把 SSH 模型从头算到尾：写出哈密顿量、求色散、算 Zak 相位、找边缘态，最后理解是什么对称性在「保护」那个相位。

## 1 哈密顿量：二聚化的碳链

聚乙炔分子是碳原子连成的长链。由于二聚化（Peierls 失稳），碳-碳键长呈现**交替**——单键与双键间隔排列，于是每个原胞里有两个不等价的格点，记为 $A$ 与 $B$。<span class="marginnote">Peierls 失稳是一维金属的经典命运：均匀的一维链在费米面处对晶格畸变不稳定，晶格自发二聚化，打开能隙，系统从金属变成绝缘体。二聚化程度越大，能隙越大，这是理解 SSH 模型为什么「有一个可调参数」的关键。</span>

设胞内（$A \leftrightarrow B$）跃迁强度为 $v$，胞间（$B \rightarrow A'$）跃迁强度为 $w$，且 $v, w > 0$，$v \neq w$（二聚化）。紧束缚哈密顿量写作

$$H = v \sum_{n=1}^{N} \big( \lvert B,n \rangle \langle A,n \rvert + \text{h.c.} \big) + w \sum_{n=1}^{N-1} \big( \lvert A,n+1 \rangle \langle B,n \rvert + \text{h.c.} \big)$$

这里 $\lvert A,n \rangle$ 表示第 $n$ 个原胞 $A$ 子格上的态，$\lvert B,n \rangle$ 类似。$N$ 是原胞数，取**开放边界**（链两端不连回）。跃迁矩阵元 $v$、$w$ 的比值 $v/w$ 是唯一的控制参数——它决定了系统处于哪种「相」。

两个极限最直观：

- **$w \to 0$（$v/w \to \infty$）**：链被打散成 $N$ 个孤立的二聚体（每个二聚体是 $A_n$–$B_n$ 强键），每个二聚体给出一个成键态（能量 $-v$）与一个反键态（能量 $+v$）。体系是绝缘体，边缘上孤零零的原子各自贡献「悬挂键」。
- **$v \to 0$（$v/w \to 0$）**：胞内跃迁消失，剩下的跃迁把 $B_n$ 与 $A_{n+1}$ 连成 $N-1$ 个二聚体，两端各剩一个未成键的原子。

两个极限看起来几乎一样：都是有能隙的绝缘体，内部都是二聚体。但它们有一个微妙而根本的差别——**边缘上有没有「悬挂键」**。这个差别就是拓扑。

## 2 布洛赫哈密顿量与色散关系

取周期边界，用布洛赫变换 $\lvert A,n\rangle = \tfrac{1}{\sqrt{N}}\sum_k e^{ikna}\lvert A,k\rangle$，哈密顿量在动量空间分解为 $H = \sum_k \psi_k^\dagger \mathcal{H}(k)\psi_k$，其中 $\psi_k = (\lvert A,k\rangle, \lvert B,k\rangle)^T$，$2\times2$ 的布洛赫哈密顿量为

$$\mathcal{H}(k) = \begin{pmatrix} 0 & v + w\,e^{-ika} \\ v + w\,e^{ika} & 0 \end{pmatrix} = \mathbf{d}(k)\cdot\boldsymbol{\sigma}$$

第二等式引入了重要的向量形式：$\boldsymbol{\sigma}$ 是泡利矩阵，而

$$\mathbf{d}(k) = \big( v + w\cos ka,\; w\sin ka,\; 0 \big)$$

即 $d_x = v + w\cos ka$，$d_y = w\sin ka$，$d_z = 0$。**对角化布洛赫哈密顿量即得能带**：

$$E_\pm(k) = \pm \lvert \mathbf{d}(k) \rvert = \pm \sqrt{v^2 + w^2 + 2vw\cos ka}$$

能隙大小是 $2\min_k\lvert\mathbf{d}\rvert = 2\,|v - w|$：当 $v = w$ 时能隙关闭（金属），否则绝缘。<span class="marginnote">$\mathcal{H}(k) = \mathbf{d}\cdot\boldsymbol{\sigma}$ 的形式在拓扑物态里无处不在——「把哈密顿量写成泡利矩阵的线性组合」等于把一个二能级系统映射到参数矢量 $\mathbf{d}$。能隙、Berry 曲率、拓扑不变量全部编码在这个 $\mathbf{d}$ 矢量「扫过的形状」里。这个表示对应的是上一节 Haldane 模型的二能带骨架。</span>

## 3 拓扑相：$\mathbf{d}$ 矢量绕的圈数

现在关键问题：$\mathbf{d}(k)$ 矢量在 $k$ 扫过整个布里渊区（$ka \in [0, 2\pi)$）时，在 $\mathbf{d}$ 平面里画出一条什么曲线？代入定义：

$$d_x = v + w\cos ka, \qquad d_y = w\sin ka$$

这是一个**圆心在 $(v, 0)$、半径为 $w$ 的圆**。于是「$\mathbf{d}$ 矢量绕原点的圈数」完全由 $v$ 与 $w$ 的相对大小决定：

- **$v > w$**：圆心在半径之外，圆不包围原点，绕数 $= 0$（平庸相）。
- **$v \lt  w$**：圆心在半径之内，圆包围原点一圈，绕数 $= 1$（拓扑相）。

这个绕数（winding number）就是 SSH 模型的一维拓扑不变量，它与 Zak 相位的关系是 $\gamma_{\text{Zak}} = \pi \times (\text{winding number})$（模 $2\pi$）。**拓扑相变点正是 $v = w$，此时圆过原点、能隙关闭。**<span class="marginnote">绕数是「$\mathbf{d}$ 矢量绕原点转了几圈」，这是拓扑学里最基本的「映射 $S^1 \to S^1$ 的度」（mapping degree）。一维里没有 Berry 曲率的「面积分」，但有绕数的「圈数」，两者同宗同源——都是同伦不变量。</span>

**辨析｜易错点：** 判断一维拓扑相时，很多人只看「$v \lt  w$」这一个条件，却不理解为什么 $v = w$ 是分界。正确的图像是：**能隙关闭 ⇔ $d_x^2 + d_y^2$ 有零点 ⇔ 圆过原点 ⇔ 绕数改变**。只要能隙开着，绕数（整数）就钉住不变；能隙一关，整数可以跳变。所以「相变一定伴随能隙关闭」在一维同样成立。

## 4 公式解析：Zak 相位的完整计算

Zak 相位是本模型的第二主角。我们要算的是占据带（下带）的 Berry 相位

$$\gamma_{\text{Zak}} = i \int_{-\pi/a}^{\pi/a} \mathrm{d}k\; \langle u_-(k) \rvert \partial_k \lvert u_-(k) \rangle$$

分三步：

- **第一步，写出占据带本征态**：$\mathcal{H}(k) = \mathbf{d}\cdot\boldsymbol{\sigma}$ 的负能量本征旋量，在球坐标里取 $\hat{\mathbf{d}} = (\cos\theta, \sin\theta, 0)$ 时是 $\lvert u_-(k)\rangle = \tfrac{1}{\sqrt2}(e^{-i\theta(k)}, -1)^T$，其中 $\tan\theta = d_y/d_x$。
- **第二步，代入求导**：$\partial_k\lvert u_-\rangle = \tfrac{-i}{\sqrt2}\partial_k\theta\,(e^{-i\theta}, 0)^T$，于是 $\langle u_- \rvert \partial_k \lvert u_-\rangle = -\tfrac{i}{2}\partial_k\theta$。代入积分，$i$ 与 $-i$ 相消：$\gamma_{\text{Zak}} = \tfrac12 \int_0^{2\pi} \mathrm{d}\theta = \pi$（如果 $\theta$ 绕满一圈）。
- **第三步，读出答案**：$k$ 扫过布里渊区一周时，$\theta(k)$ 绕一圈当且仅当 $\mathbf{d}$ 矢量绕原点一圈——正好是 $v<w$。所以 $\gamma_{\text{Zak}} = \pi$（拓扑相）或 $0$（平庸相）。**一个被保护的二值相位，就这么算出来了。**

这个结果还暴露了一个有趣的细节：$\theta(k)$ 不是 $k$ 的周期函数（$k\to k+2\pi/a$ 时可能差 $2\pi$），但 $\gamma_{\text{Zak}}$ 是规范不变的，正因如此它才能当物态标签。<span class="marginnote">Zak 相位取值的「二值性」来自时间反演对称（$H(k)$ 是实的）与一维性：实哈密顿量的波函数可以选为实函数，实函数的 Berry 相位只能是 $0$ 或 $\pi$。这也是「对称性保护」的最朴素体现——一旦对称性被破坏，相位就可以取任意值，相就「不保护」了。</span>

## 5 边缘态：端点上的零能孤子

周期性边界下的 Zak 相位，与开放边界下的边缘态，靠**体边对应**联系：**Zak 相位为 $\pi$ 的拓扑相，在开放链两端各有一个能量严格为零的边缘态**。<span class="marginnote">可以这样理解体边对应：把开放链看成「体内（$v<w$ 的周期链）+ 两个边界」。边界处能隙必须关闭（真空相当于平庸绝缘体，绕数 $1\to0$ 必须经过关闭点），而能隙关闭「泄漏」出来的态，正是局域在端点的零能态。这就是为什么「边界态数目 = 拓扑不变量之差」。</span>

具体地，令 $v/w = \lambda \lt  1$，可以严格解出边缘态波函数。左端边缘态为

$$\lvert \psi_L \rangle \propto \sum_{n=1}^{N} \left(-\frac{v}{w}\right)^{n-1} \lvert B, n \rangle$$

这是一个**从端点指数衰减**的波函数，衰减长度 $\xi = 1/\ln(w/v)$：$v/w$ 越接近 $1$，边缘态越「胖」；$v/w \to 0$ 时边缘态完全局域在最末端。$E = 0$ 的边缘态有两个，分别局域在左右两端，它们之间被能隙完全隔离——除非把它们拉近到能隙长度可比。

这套「零能边缘态」的图像有真实的化学对应：拓扑相的端点相当于「悬挂键」，物理上表现为未成键的孤子（soliton）。SSH 模型最初正是用它解释聚乙炔中「孤子携带分数电荷」的奇特现象——一个拓扑缺陷携带半个电子电荷，这是分数化的早期先声。<span class="marginnote">分数电荷孤子（每端 $\pm e/2$ 的平均电荷）是 1970–80 年代凝聚态物理最轰动的预言之一，它直接启示了后来分数量子霍尔效应里的分数电荷与分数统计。一维孤子、二维量子霍尔、三维外尔点，拓扑物态一路都在「把整体性质搬进缺陷/边界」。</span>

## 6 什么在保护拓扑相：手征对称

为什么 SSH 模型的拓扑相那么「结实」？答案是一种离散对称性——**手征对称（chiral symmetry）**，也叫子格对称。观察哈密顿量：跃迁只在 $A$ 与 $B$ 子格之间发生，$A$ 到 $A$、$B$ 到 $B$ 的跃迁统统为零。这等价于

$$\sigma_z \, \mathcal{H}(k)\, \sigma_z = -\mathcal{H}(k)$$

即「翻转子格标签 + 变号」使哈密顿量回到自身。<span class="marginnote">手征对称的直接后果：能带关于 $E=0$ 成对出现（$\pm E$），且边缘态的能量被钉在零。一旦在模型里加上 $A$–$A$ 或 $B$–$B$ 的跃迁（打破手征对称），边缘态会从零能移开、Zak 相位不再是二值的，拓扑「保护」就失效了。这正是「对称性保护的拓扑相」中「保护」二字的含义。</span>

三句话总结保护机制：

- **手征对称存在** → Zak 相位只能取 $0$ 或 $\pi$，拓扑相与平庸相被能隙隔开。
- **手征对称被破坏** → 相位连续变化，两个「相」可以无相变地连续变形，拓扑标签失效。
- **改变 $v/w$ 跨越 $1$** → 能隙必然关闭，相变必然发生，无论手征对称存在与否。

注意这里的微妙之处：$v/w$ 从 $1.5$ 变到 $0.5$，手征对称始终存在，但拓扑相变了——**相变不需要对称性破缺，只需要能隙关闭**。这挑战了朗道相变理论的直觉（朗道范式要求序参量 + 对称性破缺），是「超越朗道范式」的第一课，也是《对称性保护与十重分类》一节的预告。

## 7 小结

- **SSH 模型**：一维双原子链，胞内/胞间跃迁 $v$、$w$ 二聚化，哈密顿量 $\mathcal{H}(k) = \mathbf{d}(k)\cdot\boldsymbol{\sigma}$。
- **色散**：$E_\pm = \pm\sqrt{v^2 + w^2 + 2vw\cos ka}$；能隙 $2|v-w|$，$v=w$ 时关闭（金属）。
- **拓扑不变量**：$\mathbf{d}$ 矢量绕原点圈数，$v<w$ 时绕数 $1$、Zak 相位 $\pi$（拓扑相）；$v>w$ 时绕数 $0$、相位 $0$（平庸相）。
- **体边对应**：拓扑相在开放链两端各有一个零能边缘态，波函数从端点指数衰减。
- **对称性保护**：手征对称 $\sigma_z\mathcal{H}\sigma_z = -\mathcal{H}$ 钉住零能态并让 Zak 相位二值化；对称性被破坏则拓扑保护失效。
- **超越朗道范式**：$v/w$ 跨越 $1$ 的相变不伴随对称性破缺，只伴随能隙关闭。
