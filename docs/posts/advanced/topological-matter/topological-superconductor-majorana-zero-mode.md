## 为什么从拓扑超导体开始

前六节的拓扑都发生在「绝缘体」上：能隙是单粒子能隙，不变量是能带几何的产物。但拓扑不变量并不挑剔「能隙的起源」——只要系统有能隙、有波函数，就能谈拓扑。**超导体**恰好提供了一个全新的舞台：它的能隙来自库珀对凝聚，粒子数与对称性都换了玩法，于是拓扑超导体成为「陈数/ $Z_2$ 思想」在配对系统里的延伸。<span class="marginnote">拓扑超导体最重要的「产出」不是超导本身，而是一种奇异的准粒子——<strong>Majorana 零模</strong>：一个能量严格为零、局域在缺陷/边界处、且等于它自身反粒子的激发。它不仅是拓扑物态研究的明珠，更是「拓扑量子计算」的物理载体——这可能是拓扑物理最有实用前景的方向。</span>

Majorana 费米子是个「失踪了八十年的粒子」：1937 年意大利物理学家埃托雷·马约拉纳（Ettore Majorana）发现狄拉克方程有一个实数解——粒子等于它的反粒子。基本粒子世界里至今没找到 Majorana 费米子（中微子可能是），但凝聚态物理「山不转水转」：把单个电子劈成两半的准粒子，正是马约拉纳想要的。这一节从超导的 BdG 形式出发，用一维 Kitaev 链把 Majorana 零模造出来，再讲它为什么能用于量子计算。

## 1 超导的 Bogoliubov–de Gennes 形式：粒子-空穴对称

要谈拓扑超导体，先要把超导写成「单粒子能带论」的样子。Bogoliubov 变换把库珀对配对写成二次量子化哈密顿量，在 Nambu 旋量 $\Psi = (\psi_\uparrow, \psi_\downarrow, \psi_\downarrow^\dagger, -\psi_\uparrow^\dagger)^T$ 下，超导哈密顿量写成 BdG 形式

$$\mathcal{H}_{\text{BdG}} = \frac{1}{2}\sum_{\mathbf{k}} \Psi^\dagger(\mathbf{k})\, H_{\text{BdG}}(\mathbf{k})\, \Psi(\mathbf{k})$$

$H_{\text{BdG}}(\mathbf{k})$ 是 $4\times4$ 矩阵，同时描述电子与空穴。BdG 形式自带一个对称性——**粒子-空穴对称（particle–hole symmetry）**：把电子变成空穴、同时变号，哈密顿量不变。数学上

$$\Xi\, H_{\text{BdG}}(\mathbf{k})\, \Xi^{-1} = -H_{\text{BdG}}(-\mathbf{k}), \qquad \Xi = \tau_x K$$

其中 $\tau_x$ 作用在 Nambu（粒子/空穴）空间，$K$ 是复共轭。<span class="marginnote">粒子-空穴对称是「超导必须有的」对称性：BdG 形式把粒子与空穴放在同一个矩阵里，能谱必然关于 $E=0$ 对称——一个能量为 $E$ 的准粒子态必有一个能量为 $-E$ 的空穴伙伴。这条对称性正是后面十重分类里「超导进入 D 类、DIII 类」的原因。注意它与时间反演 $T$ 是两回事。</span>

**辨析｜易错点：** BdG 的粒子-空穴对称常被误当成「某种守恒律」。它不是守恒对称——$N$ 不守恒（超导本来就破缺粒子数守恒），而是「能谱的配对结构」。它保证的是一条谱学事实：**只要系统有超导能隙，准粒子谱关于零能成对**。后面 Majorana 零模之所以特别，正是因为它落在「粒子-空穴对称的固定点」——$E = 0$ 处，粒子与空穴态重合。

## 2 Majorana 算符：把电子劈成两半

一个普通费米子湮灭算符 $c$ 满足 $c^\dagger c + c c^\dagger = 1$（费米反对易）。Majorana 算符是「实费米子」的数学化身，定义为一对自伴随算符

$$\gamma_1 = c + c^\dagger, \qquad \gamma_2 = -i(c - c^\dagger)$$

反解得到 $c = \tfrac12(\gamma_1 + i\gamma_2)$。<span class="marginnote">这个分解值得盯着看：一个普通费米子 = 两个 Majorana「半个费米子」。$\gamma_1, \gamma_2$ 满足 $\gamma^\dagger = \gamma$ 且 $\{\gamma_i, \gamma_j\} = 2\delta_{ij}$——它们是「实数」的费米算符。物理图像：$c$ 的「粒子部分」与「反粒子部分」在 Majorana 表象里被拆开，如果这两个半体在空间上分开很远，它们就各自成为一个「看不见对方」的独立自由度。</span>

普通超导体的 Bogoliubov 准粒子是电子与空穴的混合，但仍可写成一对 Majorana 的和；这两个 Majorana 通常局域在同一点，凑成一个有能量的费米子。**拓扑超导体的非凡之处在于：某些 Majorana 对的两个半体被「扯开」，各局域在不同的位置（如导线两端），能量被钉死为零**——这样的激发叫 **Majorana 零模（Majorana zero mode）**。它的出现，等于说「单个电子的一半」独立存在于空间某处，而这半个没有能量、没有电荷量子数，只有「存在与否」这一个自由度。

## 3 Kitaev 链：一维拓扑超导的教科书

2001 年，Kitaev 给出了拓扑超导的最小模型。一根一维导线，每个格点一个电子，配 $p$ 波配对（最近邻配对振幅 $\Delta$）与化学势 $\mu$：

$$H = -\mu\sum_n c_n^\dagger c_n - t\sum_n \big(c_{n+1}^\dagger c_n + \text{h.c.}\big) + \Delta\sum_n \big(c_{n+1}^\dagger c_n^\dagger + \text{h.c.}\big)$$

$p$ 波配对的关键是它连接「相邻格点」，且在 Majorana 表象下变得极其简单。把每个 $c_n = \tfrac12(\gamma_{2n-1} + i\gamma_{2n})$ 代入，取「拓扑相」的极限参数（$\mu = 0$，$t = \Delta$），哈密顿量化为

$$H = -2t \sum_n i\, \gamma_{2n}\, \gamma_{2n+1}$$

这是一个「相邻 Majorana 配对」的哈密顿量：每个「键」$i\gamma_{2n}\gamma_{2n+1}$ 是一个二能级系统，基态是配对占据。注意看：$\gamma_1$ 与 $\gamma_{2N}$ 没有出现在任何一项里——**它们被排除在配对之外，孤立地悬在链的两端**，能量为零，这就是 Kitaev 链的两个 Majorana 零模。<span class="marginnote">这个推导是理解 Majorana 零模最省力的途径：一维链的哈密顿量在 Majorana 表象下「自动」把两个 Majorana 晾在两端。不需要解薛定谔方程，只需代数配对。任何「两端各有一个零能模」的结论，都可以追溯到这里的「孤儿 Majorana」。</span>

## 4 公式解析：为什么零模是拓扑保护的

Kitaev 链告诉我们「零模存在」，但要说清它为什么「结实」，得把拓扑不变量算出来。Kitaev 链的 BdG 哈密顿量在动量空间是

$$H_{\text{BdG}}(k) = \begin{pmatrix} -2t\cos k - \mu & 2i\Delta\sin k \\ -2i\Delta\sin k & 2t\cos k + \mu \end{pmatrix}$$

这是 D 类（只有粒子-空穴对称）的一维系统。它的拓扑不变量是 **winding number**（$\mathbf{d}$ 矢量绕圈数）：

- **步骤一，写出 $\mathbf{d}$ 矢量**：$H_{\text{BdG}} = d_x \sigma_x + d_y \sigma_y + d_z \sigma_z$，其中 $d_x = 0$，$d_y = -2\Delta\sin k$，$d_z = -2t\cos k - \mu$。$\mathbf{d}$ 矢量在 $y$–$z$ 平面里画椭圆。
- **步骤二，判绕圈**：椭圆中心在 $(0, -\mu)$。当 $|\mu| \lt  2t$ 时，椭圆包围原点，绕数 $w = 1$（拓扑相）；$|\mu| > 2t$ 时，不包围原点，$w = 0$（平庸相）。
- **步骤三，读结论**：$w = 1$ 时两端各有一个 Majorana 零模；$w = 0$ 时没有。**绕数相变点在 $|\mu| = 2t$，恰是能隙关闭处。**<span class="marginnote">绕数 $w$ 与陈数是同一族「整数不变量」在不同维度的化身。D 类一维系统的 $w$ 直接数 Majorana 对的个数——这就是拓扑超导的「体边对应」：体内的绕数 = 边界上 Majorana 零模的对数。别忘了把这个与 SSH 模型的绕数对比：一个是平庸电子链，一个是配对超导链，但数学结构惊人地相似。</span>

Majorana 零模的「拓扑保护」体现在三点：

**零能量**：$E = 0$ 被粒子-空穴对称钉死，任何扰动只能把一对 Majorana 一起推开，不能单独移动一个。
**空间分离**：两端距离越远，两个 Majorana 之间的相互作用指数衰减——退相干指数压低。
**抗局域扰动**：零模的「位置」是拓扑量，杂质、声子都动不了它。唯一的破坏途径是体态拓扑相变（$|\mu|$ 跨过 $2t$）。

## 5 非阿贝尔统计与拓扑量子计算

Majorana 零模真正的价值在于它的统计性质。交换（braiding）两个 Majorana 零模，波函数不是简单地乘一个相位，而是**非阿贝尔**的——交换顺序不同，结果不同。这个「非阿贝尔统计」是量子计算的梦想燃料。<span class="marginnote">非阿贝尔的含义：把两个零模交换再交换，得到的态与原来不同，且「先换 A 再换 B」≠「先换 B 再换 A」。数学上，交换操作 $B$ 满足 $B^2 \neq 1$ 而 $B^4 = 1$——这是「任意子」中非阿贝尔一支的标志，对应 $2\times2$ 的泡利矩阵表示。拓扑量子计算就是把这些交换操作当「门」来用。</span>

用 Majorana 搭量子比特的思路：四个 Majorana 零模（$\gamma_1, \gamma_2, \gamma_3, \gamma_4$）可以组成两个普通费米子，占据数给出一个二态系统——但信息是**非局域**存储的：$\lvert 0 \rangle$ 与 $\lvert 1 \rangle$ 的区别在于「哪对 Majorana 配对」，而不是「哪个格点被占据」。因此：

**退相干免疫**：局域噪声只能同时扰动局域在一处的 Majorana 对，而量子比特信息分布在整个网络中——局域噪声够不着。
**门靠编织**：把 Majorana 在空间上绕来绕去（编织），每一步交换都是「拓扑操作」，精度不受实现细节影响。
**容错潜力**：拓扑保护的纠错能力是「硬」的——错误率被指数压低，而不是靠软硬件纠错码。

**辨析｜易错点：** 一个常见误解是「测到零偏压峰 = 有 Majorana」。实际上，Andreev 束缚态、无序导致的近零能态、甚至普通超导的相干峰都可能产生零偏压电导峰。**确认 Majorana 需要多角度交叉验证**：零偏压峰 + 峰高量子化（$2e^2/h$）+ 磁场/栅压依赖 + 两端零模的非局域关联，缺一不可。

## 6 实验进展：纳米线、铁原子链与未来

Majorana 零模的实验实现是过去十年的硬仗。主流平台有三类：

- **半导体-超导纳米线**：InAs / InSb 纳米线加上邻近效应铝电极，轴向磁场驱动系统进入拓扑相，在线的两端测到零偏压电导峰。这个方案是 2010 年前后由理论（Lutchyn、Oreg 等）预言的，2012 年起多个实验组观测到零偏压峰，但「确认无疑」的 Majorana 证据仍在争论中。<span class="marginnote">纳米线方案的优雅之处：一个装置同时提供「拓扑超导」（近邻配对）、「时间反演破缺」（磁场）、「一维性」（纳米线本身）。参数旋钮少、可控性好，是当前最接近实用化的路线。</span>
**铁原子链 + 超导体**：把铁原子链放在铅超导体表面，链内的磁序与超导配对共同作用，产生 Majorana 束缚态。扫描隧道谱在链端测到清晰的零偏压峰，空间局域、能量为零。
**二维平台**：量子反常霍尔绝缘体与超导邻近结合、拓扑绝缘体表面 + 超导薄膜等，正在走向「可编织」的器件结构。

真正的里程碑仍未到来：**对两个 Majorana 的编织（braiding）操作**——那是证明非阿贝尔统计、迈向拓扑量子比特的决定性实验。目前的零模探测属于「静态证据」；编织需要把 Majorana 从「端点」变成「可移动的结」，是工程与物理的双重挑战。<span class="marginnote">一句话概括现状：Majorana 零模的「存在证据」已相当充分，但「用它做量子计算」的最后一公里——编织与读出——尚未走完。这也是本世纪凝聚态与量子信息交叉领域最值得追踪的方向之一，可衔接第四级《拓扑量子计算》专题。</span>

## 7 对照表：拓扑绝缘体与拓扑超导体

两者共享「拓扑 + 能隙」的骨架，但底层机制与产物完全不同。用一张表收束全篇：

| 特征 | 拓扑绝缘体 | 拓扑超导体 |
| --- | --- | --- |
| 能隙来源 | 单粒子能隙（能带） | 库珀对凝聚（配对能隙） |
| 基本对称性 | 时间反演 $T$ | 粒子-空穴 $\Xi$ |
| 拓扑不变量 | $Z_2$、陈数 | 绕数 $w$、$Z_2$（DIII 类） |
| 边界激发 | 狄拉克锥/螺旋边缘态 | Majorana 零模 |
| 边界激发自共轭？ | 否 | 是（$\gamma^\dagger = \gamma$） |
| 粒子数守恒 | 守恒 | 破缺（超导） |
| 应用潜力 | 低功耗电子学、自旋电子学 | 拓扑量子计算 |

这张表还揭示了一个「对应」：**时间反演 $T$ 在绝缘体里扮演的角色，粒子-空穴对称 $\Xi$ 在超导体里扮演同样的角色**——都提供「能带成对」的结构、都为零能/零点提供保护。这种「对称性互换」正是《对称性保护与十重分类》一节的核心思想：不同对称性的组合，决定拓扑物态的完整周期表。<span class="marginnote">特别值得注意最后一行「粒子数守恒」：超导破缺粒子数守恒，让「半个电子」（Majorana）的存在成为可能——这正是拓扑超导独有的自由度。绝缘体里永远造不出 Majorana，因为它没有「配对」这回事。</span>

## 8 小结

- **Majorana 费米子**：满足 $\gamma^\dagger = \gamma$、$\{\gamma_i,\gamma_j\} = 2\delta_{ij}$ 的「实」费米算符；一个普通费米子 = 两个 Majorana 半体。
- **BdG 与粒子-空穴对称**：超导能谱关于 $E=0$ 成对，$E=0$ 是粒子-空穴对称的固定点，Majorana 零模正坐落在该点。
- **Kitaev 链**：一维 $p$ 波超导链，拓扑相（$|\mu| \lt  2t$）两端各有一个零能 Majorana，绕数 $w = 1$；相变点 $|\mu| = 2t$ 恰是能隙关闭处。
- **拓扑保护的三层含义**：零能量被粒子-空穴对称钉死、两端空间分离指数压低退相干、局域扰动无法单独移动一个零模。
- **非阿贝尔统计**：编织两个 Majorana 得到 $B^4 = 1$ 的交换矩阵，拓扑量子计算把这些交换操作当「门」——信息非局域存储，天然免疫局域噪声。
- **实验现状**：纳米线、铁原子链、二维平台都测到了零偏压峰，但「确认无疑」的编织实验仍是未竟之路。

在下一节，我们将离开「能隙与单粒子」的框架，进入相互作用主导的领域：当拓扑与强关联相遇，会出现分数化的准粒子与拓扑简并的基态——**分数陈绝缘体与拓扑序**。
