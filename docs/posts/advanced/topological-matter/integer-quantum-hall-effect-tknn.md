# 整数量子霍尔效应与 TKNN 不变量

## 为什么从整数量子霍尔效应开始

**拓扑物态**这整座大厦，第一块基石是一桩「精度离谱」的实验现象：把二维电子气放进强磁场并降温，霍尔电导会以令人难以置信的精度锁死在 $\tfrac{e^2}{h}$ 的整数倍上，哪怕样品杂质多寡、形状大小完全不同。这个效应无法用任何「逐点微扰」的语言解释——杂质怎么改，整数就是不变。要解释「为什么整数化、为什么那么精确」，物理学家被逼着借来了一门纯数学：**拓扑学**。<span class="marginnote">拓扑学是研究「连续变形下保持不变」的性质的数学分支。一个甜甜圈（环面）与一只咖啡杯在拓扑学里是同一个东西，因为二者可以连续捏合；而球面与环面则不同——因为要在球面上「撕开一个洞」才能变成环面。这个「洞的个数」就是最早的拓扑不变量，见第二级《拓扑学》。</span>

量子的平台化、精确化、鲁棒化，三位一体地指向一个结论：**霍尔电导的量子化不是材料细节的产物，而是能带结构的整体拓扑性质**。这一节，我们从经典霍尔效应出发，一步步走到 TKNN 不变量——拓扑物态的语言从这里正式开始。

先给一个全篇的路线图：这一节先讲清「现象」（经典霍尔 → 量子霍尔平台），再讲清「能级」（朗道能级与填充因子），再讲清「不变量」（TKNN 陈数），最后回到「边界」（边缘态与体边对应）——一条从实验到理论再到实验的闭环。

## 1 经典霍尔效应：一场 1879 年的面试

1879 年，还在约翰·霍普金斯大学读博士的埃德温·霍尔（Edwin Hall）问了一个当时没人想过的问题：磁场作用在导线里的载流子上，会不会产生一个「横向」的电压？答案是会。**霍尔效应（Hall effect）**：电流沿 $x$ 方向流动，垂直方向加磁场 $B_z$，则在 $y$ 方向出现横向电压。

成因直观而经典：载流子在磁场中受洛伦兹力 $F = qv \times B$，被横向推向一侧堆积，堆积产生的电场又反过来平衡洛伦兹力，最终达到稳态。<span class="marginnote">稳态条件是电场力与洛伦兹力等大反向：$qE_y = qv_d B_z$，于是 $E_y = v_d B_z$。再代入电流密度 $j_x = n e v_d$，就得到霍尔系数 $R_H = E_y / (j_x B_z) = 1/(ne)$——它只依赖载流子浓度 $n$！这正是霍尔效应最初被用来测载流子浓度的原因。</span>

霍尔系数反比于载流子浓度，符号还随载流子是电子还是空穴而改变——这曾是半导体工业测量载流子类型的标准手段。但注意，经典霍尔效应里 $R_H$ 是**随材料、随温度连续变化**的：把磁场调大一点，霍尔电压就平滑地涨一点。没有任何「平台」、没有「量子化」的影子。

## 2 整数量子霍尔效应：1980 年的精确平台

转折发生在 1980 年。克利青（Klaus von Klitzing）在研究 MOSFET 的二维电子气时发现：当温度降到约 1.5 K、磁场强到约 18 T，霍尔电阻 $R_{xy}$ 随磁场 $B$ 的变化**不再是平滑曲线，而是出现一系列平台**，平台处的取值精确等于

$$R_{xy} = \frac{h}{\nu e^2}, \qquad \nu = 1, 2, 3, \dots$$

同时，纵向电阻 $R_{xx}$ 在平台处**严格降为零**。<span class="marginnote">$\nu$ 被称为「填充因子」。电阻是电导的倒数：$R_{xy} = \rho_{xy}$，而 $\sigma_{xy} = \rho_{xy}/(\rho_{xy}^2 + \rho_{xx}^2)$；在平台处 $\rho_{xx}=0$，于是 $\sigma_{xy} = 1/\rho_{xy} = \nu e^2/h$。电导的量子化与电阻的量子化是同一件事的两面。</span>

为什么必须在二维？因为在三维体材料里，即使填充因子对应的条件满足，第三个空间方向上的电子也能自由输运，横向电导不会被完全「锁死」；而二维电子气的输运被限制在平面内，拓扑保护的无耗散电流通道才成为主导。实验上，二维电子气由高迁移率的 GaAs/AlGaAs 异质结或硅 MOSFET 反型层提供——电子被限制在界面附近几十纳米厚的薄层里，垂直方向动能为零，等效于一个理想的二维系统。<span class="marginnote">高迁移率是关键前提：无序势的强弱由「迁移率 × 磁场」控制，只有迁移率足够高、磁场足够强，朗道能级的展宽 $\Gamma \ll \hbar\omega_c$，量子霍尔平台才能被分辨出来。这也是为什么这个效应在 1980 年才被发现——直到分子束外延（MBE）技术成熟，才能造出足够干净的二维电子气。</span>

两个细节让物理学家确信这不是普通的实验误差：

- **精度**：平台值相对 $h/e^2$ 的偏离在 $10^{-10}$ 量级——比当时最好的电阻标准还精确。1985 年克利青因此获诺贝尔物理学奖，如今 $h/e^2$ 直接定义了电阻单位欧姆。
- **鲁棒性**：改变样品杂质浓度、改变形状、换材料体系，平台值**纹丝不动**。杂质本来会让电子散射，可量子霍尔态恰恰**不怕杂质**——这正是拓扑鲁棒性的第一次现身。

要理解「为什么精确等于整数除以 $e^2/h$」，先得把二维电子气在强磁场下的能级结构算清楚。

## 3 朗道能级与填充因子

忽略电子相互作用，二维自由电子气在垂直磁场中的哈密顿量为

$$H = \frac{(\mathbf{p} + e\mathbf{A})^2}{2m}$$

规范取 $\mathbf{A} = (-By, 0, 0)$（朗道规范），动量算符代入并配方，问题化为一个「沿 $x$ 自由的平面波 × 沿 $y$ 的谐振子」。能谱分裂为一系列高度简并的能级——**朗道能级（Landau level）**：

$$E_n = \hbar\omega_c\left(n + \frac{1}{2}\right), \qquad \omega_c = \frac{eB}{m}, \qquad n = 0, 1, 2, \dots$$

这里 $\omega_c$ 是回旋频率。每个朗道能级容纳的态数正比于磁场：

$$N_B = \frac{eB}{h} A$$

其中 $A$ 是样品面积。<span class="marginnote">这个简并度 $N_B$ 可以这样直觉理解：朗道能级上的波函数在实空间占据面积约一个磁长度平方 $\ell_B^2 = \hbar/(eB)$，把样品面积 $A$ 除以单个波包面积 $\ell_B^2$ 再乘上简并因子，就得到 $A eB/h$。磁场越强，朗道能级挤得越紧，每支能级上能坐的电子越多。</span>

把电子一个个「放进」朗道能级，填满 $\nu$ 支能级后，费米能恰好处在朗道能级之间的能隙里——此时系统处于**绝缘体**状态（导带满、价带空、有能隙）。填充因子 $\nu$ 就是被填满的朗道能级支数。

## 4 公式解析：霍尔电导为什么量子化

有了能隙，为什么电导就量子化？这正是 TKNN 理论（1982，Thouless–Kohmoto–Nightingale–den Nijs）回答的问题。它的核心结论是一条貌似平凡、实则深刻至极的公式：

$$\sigma_{xy} = \frac{e^2}{h} \, C, \qquad C = \frac{1}{2\pi} \int_{BZ} \mathrm{d}^2k \, \Omega(k)$$

对这条公式做三步拆解：

- **第一步，看懂 $C$ 是什么**：$C$ 是**陈数（Chern number）**——布里渊区（一个环面 $\mathbb{T}^2$）上的 Berry 曲率 $\Omega(k)$ 对整个区域的积分除以 $2\pi$。Berry 曲率本身来自布洛赫波函数 $\lvert u_n(k) \rangle$ 的几何相位，是能带结构的「曲率」。
- **第二步，为什么 $C$ 是整数**：布里渊区是环面，环面上的一个闭合曲面上的 Berry 曲率积分除以 $2\pi$ 必为整数。这纯粹是拓扑学定理：环面上的规范场（U(1) 联络）的「磁通量子数」是整数。$C$ 只能取 $0, \pm 1, \pm 2, \dots$，不可能取 $1/3$ 或 $1.37$。
- **第三步，为什么实验值精确**：$\sigma_{xy} = (e^2/h)C$ 只依赖整数 $C$，不依赖材料参数（质量、介电常数、杂质浓度全部没出现）。杂质、缺陷、微弱形变都只是**连续变形**，不会改变整数 $C$——这就是平台值精确到 $10^{-10}$ 的拓扑解释。

**辨析｜易错点：** 初学者常误以为「量子霍尔电导 = $e^2/h$」就是「一个电子贡献一份 $e^2/h$」。严格说，**陈数 $C$ 是整条能带（所有被填满的朗道能级）的集体拓扑性质**，不是单电子的属性；单电子在均匀电场下的响应是「所有占据态对角速度的求和」，只有求和后得到的净横向漂移才给出 $\sigma_{xy} = C e^2/h$。

## 5 实验证据：把 $h/e^2$ 变成电阻单位

量子霍尔效应不只是学术珍奇，它还直接改写了计量学。因为平台电阻只依赖两个基本常数 $h$ 与 $e$，与样品无关，国际计量界在 1990 年起就以它定义「欧姆」的实用标准，2019 年国际单位制（SI）改革后，$R_K = h/e^2 \approx 25812.80745\ \Omega$ 被定为**冯·克利青常数（von Klitzing constant）**，成为新的电阻单位定义的一部分。<span class="marginnote">一个固体物理实验反哺了计量基准，这在物理学史上是罕见的成就。以前定义电阻需要一支精心保管的实物标准棒，如今只需在实验室里搭一个二维电子气装置，通电一测，电阻就「自然」地长在 $h/e^2$ 的整数倍上。</span>

实验中要把「平台」读出来，靠的是两步操作：

**扫磁场、找平台**：固定低温与电流，扫描 $B$，记录 $R_{xy}$ 与 $R_{xx}$。每当前者落在 $h/(\nu e^2)$、后者跌到零，就确认进入第 $\nu$ 个量子霍尔平台。
**判定平台质量**：判断平台是否「真实」，要看 $R_{xx}$ 是否在同一磁场区间内严格为零（受限于测量噪声，一般要求低于 $10^{-6}$ 量级）。只要 $R_{xx}$ 不清零，说明还有背向散射通道，系统尚未进入完美量子霍尔态。

平台宽度由朗道能级间的能隙与展宽的竞争决定：无序会把朗道能级展宽成带状，能隙中央的扩展态（extended state）参与输运，两侧的局域态（localized state）不导电——**局域态恰恰是平台「宽而平」的功臣**，因为它们把「能隙」的有效范围撑大了。<span class="marginnote">这是个看似反直觉的细节：杂质通常被认为有害，但在量子霍尔效应里，正是无序产生的局域态让平台在很宽的磁场范围内保持精确。平台的「平」由局域态保证，平台的「整数值」由拓扑保证——两者各司其职。</span>

## 6 边缘态：体边对应与无耗散输运

拓扑不变量藏在体能带里，可实验测到的输运却发生在边缘——这个矛盾由**体边对应（bulk-boundary correspondence）**弥合：**非零陈数的体能带，必然在样品边界撑起手性（chiral）的边缘态**。<span class="marginnote">边缘态为什么存在？在边界处，真空相当于一个「陈数为零的绝缘体」；陈数从体里的 $C$ 变到真空里的 $0$，这个整数不可能连续变化，唯一的出路是在界面处让能隙关闭、允许能带穿过费米能——穿过费米能的那些态就是边缘态。</span>

边缘态有三个关键特征：

**手性**：边缘态沿边界只朝一个方向传播，背向散射被禁戒（没有反向通道），因此**不产生焦耳热**，$R_{xx} = 0$ 由此而来。
**数量由体决定**：边缘态通道数恰好等于陈数 $|C|$，这就是「体边对应」的定量内容。
**抗杂质**：即使边缘上有缺陷，边缘态绕过去继续走，不回头——这是拓扑保护的直观图景。

## 7 从量子霍尔到拓扑绝缘体：一次关键的思想平移

量子霍尔效应需要强磁场。能不能**没有磁场**也得到拓扑非平凡的能带？2005 年前后，Haldane 与 Kane–Mele 分别给出了答案：让「自旋向上」和「自旋向下」的电子感受到**相反方向**的等效磁场（由自旋轨道耦合提供），两者各自携带相反的陈数 $C_\uparrow = -C_\downarrow$，总陈数 $C = C_\uparrow + C_\downarrow = 0$，但新的拓扑不变量 $Z_2$ 非零——这就是**量子自旋霍尔效应**与**时间反演对称拓扑绝缘体**。<span class="marginnote">这是一次范式级的平移：从「外加磁场破坏时间反演」换成「自旋轨道耦合在体内有效模拟磁场」，拓扑非平凡态不再需要外场。这个 $Z_2$ 不变量我们将在《量子自旋霍尔效应与 $Z_2$ 不变量》一节专门展开。</span>

这一平移让「拓扑物态」从实验室的极端条件走向普通材料：只要材料有强自旋轨道耦合且体能隙合适，无需外磁场就能成为拓扑绝缘体。此后的故事——三维拓扑绝缘体、拓扑超导体、外尔半金属——全都从这里出发。

## 8 小结

- **整数量子霍尔效应**：二维电子气在强磁场低温下，霍尔电阻出现精确平台 $R_{xy} = h/(\nu e^2)$，纵向电阻为零。
- **朗道能级**：磁场把二维电子气能谱劈裂为能级 $E_n = \hbar\omega_c(n+\tfrac12)$，每支简并度 $N_B = eBA/h$；填满 $\nu$ 支能级即为填充因子 $\nu$。
- **TKNN 公式**：$\sigma_{xy} = \tfrac{e^2}{h}C$，陈数 $C$ 是布里渊区环面上 Berry 曲率的积分，拓扑学保证其为整数。
- **鲁棒性来源**：整数不能连续变化，杂质与缺陷只造成连续变形，故平台值精确且不受样品细节影响。
- **体边对应**：非零陈数 ⇒ 边界出现手性边缘态，边缘态单向传播、背向散射禁戒，给出无耗散输运。
- **计量价值**：$h/e^2$ 因量子霍尔平台而成为电阻单位定义（冯·克利青常数），固体物理实验反哺计量基准。

**辨析｜易错点：** 平台上的量子霍尔态是「无耗散输运」，但不是超导。两者都满足纵向电阻为零，但机制完全不同：超导靠库珀对的凝聚（见第四级《超导物理》），量子霍尔靠的是手性边缘态的「没有反向通道」；前者是玻色凝聚，后者是单粒子拓扑输运。此外，量子化的对象也不同——超导量子化的是磁通，量子霍尔量子化的是横向电导。

在下一节，我们把「陈数」公式里的 Berry 曲率 $\Omega(k)$
