## 为什么从分数陈绝缘体开始

前面十节里有一个始终被悬置的前提：**电子之间没有相互作用**。十重分类、陈数、$Z_2$、绕数全都建立在「单粒子能带」之上。但真实电子彼此排斥。当相互作用足够强，会发生一件单粒子语言完全无法描述的事：**电荷量子化被打破**。整数量子霍尔里一个电子贡献 $e$，而分数量子霍尔里一个「准粒子」只带 $e/3$——电荷本身分数化了。<span class="marginnote">电荷分数化是拓扑物态从「单粒子」跨向「多体」的标志性事件：$e/3$ 不是「一个电子的三分之一」，而是「集体激发的拓扑荷」。它意味着系统的信息不能归约到任何单个粒子，必须看整体。这种「整体性」正是拓扑序（topological order）的核心——一个没有对称性保护、却能稳定区分物态的新范式。</span>

这一节从分数量子霍尔效应出发，先看相互作用如何造出分数电荷与任意子，再介绍它的晶格版本——**分数陈绝缘体**（不需要磁场的 FQHE 表亲），最后把「拓扑序」这个比十重分类更深的框架讲清，并以非阿贝尔任意子与拓扑量子计算收尾。读这一节时请带着一个问题：当「基本粒子的电荷都能被改写」，还有什么是真正不可约化的？——拓扑序给出的答案，是「整体」。

## 1 分数量子霍尔效应：相互作用把 $e$ 变成 $e/3$

1982 年，崔琦（Tsui）、施特默（Störmer）与戈萨德（Gossard）在比整数量子霍尔更强、更冷的条件下发现：填充因子 $\nu = 1/3$ 处出现霍尔平台，$\sigma_{xy} = \tfrac{1}{3}\tfrac{e^2}{h}$。整数平台可以用朗道能级填充解释；$1/3$ 平台则完全无法用单粒子图像理解——费米能落在朗道能级中间的能隙里，为什么会绝缘、为什么会分数？<span class="marginnote">朗道能级是高度简并的：填充因子 $\nu = 1/3$ 意味着每个朗道能级态平均只有 $1/3$ 个电子。单粒子理论下这应该是个「部分填充的金属」——电子多的是空位，一定能导电。但实验测到的是绝缘体 + 分数霍尔平台，说明电子之间「商量」出了一个全新的基态，这就是多体拓扑的起点。</span>

劳克林（Laughlin）在 1983 年给出关键答案：$1/3$ 填充的基态是**凝聚态波函数**

$$\psi_{1/3}(z_1, \dots, z_N) = \prod_{i<j} (z_i - z_j)^3\, e^{-\frac{1}{4\ell_B^2}\sum_i |z_i|^2}$$

其中 $z_i = x_i + i y_i$ 是复坐标，$\ell_B$ 是磁长度。这个波函数的幂次 $3$ 是相互作用「写」进去的：电子两两相对角动量 $3\hbar$，刚好把库仑排斥压到最低。它的拓扑含义在准粒子激发里完全显现：在 $z_0$ 处放一个「准空穴」，波函数变成

$$\psi_{\text{qh}} = \prod_i (z_i - z_0)\, \psi_{1/3}$$

相比基态，多了一个因子 $(z_i - z_0)$——这个准空穴携带的电荷是 $e/3$，且它的统计是「分数」的：两个 $e/3$ 准空穴交换，波函数乘 $e^{i\pi/3}$，既不是玻色子也不是费米子，而是**任意子（anyon）**。

## 2 复合费米子：分数霍尔序列的语言

$1/3$ 不是唯一的分数平台：$\nu = 2/5$、$3/7$、$2/3$、$3/5$……实验上观测到长长的分数序列。这些平台之间是什么关系？1990 年前后，Jain（J. K. Jain）给出了漂亮的统一图像——**复合费米子（composite fermion）**：每个电子绑定偶数个磁通量子，成为一个「电子 + 磁通」的复合体。<span class="marginnote">为什么电子要绑磁通？因为强磁场下电子之间的相互作用可以「改写」为：电子被「部分通量」环绕，等效地感受一个减弱的磁场。把「每个电子 + 2 个磁通」打包成中性复合费米子后，原来的强关联电子系统变成了「弱磁场下整数填充的复合费米子」——整数填充是单粒子问题，好解！</span>

具体地，$\nu = p/(2p+1)$ 分数态 = 复合费米子在「约化磁场」下的第 $p$ 个整数朗道能级填充。这个映射解释了一切：

**$p=1$**：$\nu = 1/3$——一个复合费米子填满第一级，对应劳克林 $1/3$ 态。
**$p=2$**：$\nu = 2/5$——两个复合费米子朗道能级，给出 $2/5$ 平台。
**全体奇数分母**：$p$ 取遍正整数，$\nu = p/(2p+1)$ 给出 $1/3, 2/5, 3/7, \dots$ 的完整序列。

复合费米子图像的精髓：**把「相互作用的分数问题」翻译成「自由粒子的整数问题」**。这是凝聚态物理最成功的「降维打击」之一，也解释了为什么分数序列不是零散的偶然——它们是同一物理的整数级台阶。<span class="marginnote">这一图像还与前面的物态网络呼应：复合费米子 = 「电子 + 拓扑荷」的绑定，正如 Majorana = 「电子的一半」、外尔点 = 「Berry 曲率的单极子」。拓扑物态的大家庭里，「准粒子」从来不是基本粒子的复制品，而是集体态织出的新对象。</span>

## 3 任意子：玻色子与费米子之外的第三种统计

三维空间里只有两种统计：交换两次等于不换（玻色子），或等于乘 $-1$（费米子）。但在**二维**，路径的拓扑允许更丰富的选择：交换两个粒子 $\theta$ 角后波函数乘 $e^{i\theta}$，$\theta$ 可以是任意角——这叫**分数统计（fractional statistics）**，拥有它的粒子叫任意子。<span class="marginnote">为什么二维可以？三维里交换两个粒子可以绕过去不碰它们（绳子可以从上方绕过），等价于「交换两次 = 恒等」；二维里粒子被「困」在平面上，绕过去必然与另一个粒子「交缠」——交换操作产生的是辫群（braid group）而非置换群，于是出现了连续可调的相位角。维数是拓扑物理里最关键的自由度之一。</span>

任意子分两支：

**阿贝尔任意子（Abelian anyon）**：交换只改变相位 $e^{i\theta}$。$e/3$ 准空穴属于这类，$\theta = \pi/3$。
**非阿贝尔任意子（non-Abelian anyon）**：交换改变的是「内部态」，即交换操作是矩阵而非相位。两个非阿贝尔任意子交换后，系统可以进入不同的量子态——这正是拓扑量子计算的资源。

**辨析｜易错点：** 「分数电荷」与「分数统计」经常被混为一谈。**分数电荷是「准粒子带多少电荷」的问题，分数统计是「交换准粒子波函数怎么变」的问题**——两个独立的概念。$\nu = 1/3$ 态里两者同时出现（电荷 $e/3$、统计角 $\pi/3$），但原则上可以有分数电荷 + 费米统计、或整数电荷 + 分数统计的组合。判断一个拓扑序「用哪个不变量刻画」，要看它的任意子数据。

## 4 拓扑序：没有对称性也非平凡的物态

十重分类的物态（SPT）靠对称性「保护」；分数霍尔态的非凡之处在于它**不需要任何对称性**也能与平庸态区分。这个更深的分类叫**拓扑序（topological order）**，它有三个不依赖对称性的标志：

**基态简并度（ground state degeneracy）**：在环面（或高亏格曲面）上，拓扑序的基态不止一个。$\nu = 1/3$ 态在环面上有 $3$ 重简并——这个数字「$3$」本身就是拓扑量，与材料细节无关。<span class="marginnote">环面上的基态简并度等于「任意子种类数」——这是 Verlinde 公式的雏形。它给了实验一个可测的拓扑标签：把系统做成环面几何（如冷原子环状光晶格、环形超导体阵列），数基态个数。二维 SPT 在环面上基态是非简并的（$Z_2$ 拓扑绝缘体只有 1 个基态），这是 SPT 与拓扑序最干净的判别式。</span>
**长程纠缠（long-range entanglement）**：拓扑序的基态不能在局域幺正变换下变成直积态——信息纠缠在「整个空间」的层级，无法用任何局域操作拆散。
**任意子数据（anyon data）**：系统的准粒子种类、融合规则、编织相位构成一个完整的数学结构——这是拓扑序的「身份证」。

**辨析｜易错点：** 拓扑序不是「强关联的能带拓扑」。能带拓扑（SPT）即使有相互作用，也总可以（在保持对称与能隙的意义下）与某个单粒子态连续连接；拓扑序则**根本不能用单粒子波函数描写**——它的非平凡性来自「多体波函数的拓扑结构」。一句话：**SPT 可以「约化到能带」，拓扑序不能。**

## 5 公式解析：Laughlin 波函数为什么给出 $e/3$

Laughlin 波函数是整篇的枢纽。它的三条性质——绝热可连接性、精确性、分数性——用三步理解：

**第一步，为什么 $\nu = 1/3$ 填满**：填充因子由「幂次决定」：波函数 $\prod (z_i-z_j)^m$ 描述填充因子 $\nu = 1/m$。理由是多体波函数反对称要求 $m$ 为奇数（$m=3,5,\dots$），且 $m=1$ 时就是填充因子的整数情形。$m=3$ 给出 $1/3$。
- **第二步，为什么准空穴带 $e/3$**：准空穴波函数 $\prod_i(z_i-z_0)\psi_{1/3}$ 中，每个电子「失去」了对 $z_0$ 的 $m=3$ 重排斥中的一个因子。用等离子体映射（把波函数模方看成二维等离子体）可严格算出：失去 $1/m$ 个「排斥单位」对应缺失 $e/m$ 的电荷——这就是 $e/3$。**分数电荷来自「集体缺失」，不是「粒子碎片」**。
- **第三步，为什么它稳定**：Laughlin 态与所有保持能隙的扰动「绝热连接」——无论杂质势怎么变、样品怎么弯，只要能隙不关，$e/3$ 与统计角 $\pi/3$ 都不变。拓扑保护在这里表现为「电荷与统计的量子化」。

## 6 分数陈绝缘体：晶格上复现 FQHE

分数量子霍尔需要强磁场——那很贵。2003 年、2011 年前后，理论家提出：**能不能在零磁场的晶格模型里复现分数量子霍尔？** 答案是可以，条件是找一张「平的陈带」：一条占据带陈数为 $C=1$、带宽远小于相互作用能、且 Berry 曲率分布均匀——这样的带像极了「单个朗道能级」，电子填充其中一部分时，相互作用就会重新造出分数霍尔态。<span class="marginnote">「平带」思想是分数量子霍尔理论在晶格上的推广：把「磁场的朗道能级」换成「晶格的拓扑陈带」，把「填充因子」换成「陈带的占据分数」。分数陈绝缘体（fractional Chern insulator）的理论预言 2011 年在 Haldane 模型（见 §3 的蜂窝晶格模型）等平带模型中被数值证实——在零磁场下出现分数陈数与任意子激发。</span>

分数陈绝缘体与 FQHE 的对照：

| 特征 | 分数量子霍尔（FQHE） | 分数陈绝缘体（FCI） |
| --- | --- | --- |
| 需要的磁场 | 强磁场（朗道能级） | 零磁场（拓扑陈带） |
| 「能级」来源 | 朗道量子化 | 能带拓扑 + 平带设计 |
| 填充因子 | $\nu = 1/3$ 等 | 陈带占据分数 $1/3$ 等 |
| 准粒子 | 分数电荷任意子 | 分数电荷任意子 |
| 平台 | $\sigma_{xy} = \frac{1}{3}\frac{e^2}{h}$ | 陈数 $C = 1/3$ 等 |

FCI 的实验探索仍在进行中——MoTe$_2$、转角摩尔材料（twisted bilayer）等平台是当前热门候选。<span class="marginnote">转角石墨烯与转角 MoTe$_2$ 的兴起让 FCI 的研究进入「材料时代」：摩尔超晶格天然提供平带，而拓扑陈带可以通过层间转角与位移场调谐。2023 年后，多个小组在转角 MoTe$_2$ 中报道了可能的分数陈绝缘体迹象，但确认仍需更严格的输运与谱学证据。</span>

## 7 非阿贝尔任意子与拓扑量子计算

拓扑序最诱人的应用是非阿贝尔任意子。回想 Majorana 零模（§7）：交换两个 Majorana 给出的就是非阿贝尔相位——但 Majorana 的编织只能生成有限的（克利福德）操作集。更丰富的非阿贝尔任意子（如 Fibonacci 任意子）能生成**普适量子门**：只要会编织，就能做任何量子计算。

拓扑量子计算的逻辑：

- **信息非局域存储**：量子比特编码在任意子的融合空间里，局域噪声改变不了融合类别。
- **门 = 编织**：把任意子在空间中绕来绕去，每一步交换实现一个矩阵操作，误差来自「绕路的方式」而非「绕路的精度」——天然容错。
- **读出 = 融合**：把两个任意子拉到一起融合，融合产物决定测量结果。

**辨析｜易错点：** 「非阿贝尔任意子能普适量子计算」不等于「已经在实验里实现了」。当前实验（Majorana 纳米线、分数量子霍尔 $\nu = 5/2$ 态）距离可编程编织还有整个「操作系统」的距离：需要可移动的任意子、可控制的编织路径、高保真的读出，以及对抗退相干的全程保护。**拓扑量子计算的「原理已明、工程未竟」**，和量子计算机的整体现状一致。

## 8 小结

- **分数量子霍尔**：填充因子 $\nu = 1/m$ 的霍尔平台，准粒子带分数电荷 $e/m$，劳克林波函数 $\prod(z_i-z_j)^m$ 给出精确基态。
- **任意子**：二维特有的分数统计，交换相位 $e^{i\theta}$ 连续可调；阿贝尔任意子只换相位，非阿贝尔任意子换「内部态」。
- **拓扑序**：不依赖对称性的物态分类，标志是环面基态简并度、长程纠缠、任意子数据；与 SPT（依赖对称性）有本质区别。
- **分数陈绝缘体**：零磁场的「平陈带」上复现分数量子霍尔，用「拓扑陈带 × 相互作用」代替「朗道能级 × 相互作用」。
- **非阿贝尔任意子**：交换即矩阵操作，可编码普适量子门，编织即计算、融合即读出。
- **实验现状**：FQHE 平台已充分验证；FCI 在转角 MoTe$_2$ 等材料中出现候选迹象；非阿贝尔编织仍是「原理已明、工程未竟」。
- **SPT vs 拓扑序**：SPT 可约化到能带、需对称性保护；拓扑序无对称性也非平凡，靠基态简并度与任意子数据区分。
- **维数关键**：分数统计是二维特有的「辫群」产物，三维空间只有玻色/费米两种统计。
- **贯穿全篇**：从陈数到拓扑序，「整数 → 分数 → 非阿贝尔」是拓扑物态不断深化的一条主线。
- **复合费米子**：$\nu = p/(2p+1)$ 分数序列 = 复合费米子在约化磁场下的整数填充；「相互作用分数问题」被翻译成「自由粒子整数问题」。
- **分数陈绝缘体**：零磁场、平陈带、$C=1$、带宽 << 相互作用——用「拓扑陈带 × 相互作用」替代「朗道能级 × 相互作用」。

至此，「拓扑物态与拓扑绝缘体」专题的十一篇全部收束：从量子霍尔的整数平台出发，我们一路走过 Berry 几何、陈数、$Z_2$
