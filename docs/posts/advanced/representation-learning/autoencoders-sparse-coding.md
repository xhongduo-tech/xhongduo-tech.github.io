## 为什么第一个可训练表示机器是「自编码器」

前两篇确立了目标：让机器自己学到好表示。但「好」需要一个**机器可优化的目标函数**。自编码器给了最朴素的一个：**让网络把输入压成一个更小的表示，再用这个表示把输入还原回来。** 如果还原得好，说明表示里没丢关键信息——这份「压缩后仍能还原」的信息，就是机器被迫学到的表示。<span class="marginnote">这就是「瓶颈（bottleneck）」思想：结构上的约束（中间层更窄）代替了手工设计的目标。先哲们早在 1980 年代就用这个思路做过数据压缩，深度学习只是把它放进了端到端的梯度训练框架。</span>

本篇从自编码器切入，再引出它最具生物学色彩的近亲——稀疏编码：这是表示学习「生成式路线」的第一个正式成员。

## 1 自编码器的骨架：编码—解码—重构

**自编码器（autoencoder）**：一个由编码器与解码器构成的神经网络，目标是把输入经过瓶颈再还原为自身。

$$
\underbrace{x}_{\text{输入}} \xrightarrow{\ \ f \ \ } \underbrace{h}_{\text{表示（code）}} \xrightarrow{\ \ g \ \ } \underbrace{\hat{x}}_{\text{重构}}
$$

- **编码器（encoder）** $f$：把输入 $x$ 压缩成低维表示 $h = f(x)$；
- **解码器（decoder）** $g$：把 $h$ 还原成 $\hat{x} = g(h)$；
- **重构误差**：衡量 $\hat{x}$ 与 $x$ 的差异，是训练的唯一目标。

它「自己教自己」，不需要标签——所以自编码器是最古老的自监督学习方法之一。关键在于：**编码器被迫丢弃输入中「对重构而言不重要」的信息**，只保留「决定性」的信息，于是 $h$ 里承载的是数据的本质结构。<span class="marginnote">一个经典结论：当编码器与解码器都是线性、且只用 MSE 重构损失时，学到的 $h$ 恰好落在 PCA（主成分分析）张成的子空间上——自编码器可以被看成「非线性 PCA」。</span>

## 2 欠完备与过完备：瓶颈的两种玩法

按表示维度 $d_h$ 与输入维度 $d_x$ 的关系，自编码器分两类：

**欠完备自编码器（undercomplete）**：$d_h < d_x$，表示必须「存精华、扔冗余」。优点：结构上强制压缩，无需额外正则。缺点：只靠维度限制，可能学到的是「恒等映射的近似」而非「有意义的特征」——它能压缩，但压缩出的维度之间仍可能高度冗余。

**过完备自编码器（overcomplete）**：$d_h > d_x$，表示层比输入还宽。此时单靠重构损失会把表示退化成「直接把输入复制过来」（学到恒等映射），因此必须引入**正则项**来逼出好结构——稀疏性、去噪、收缩，都是不同形式的正则。

这个「太窄不够、太宽要管」的两难，正是后面 VAE 用「变分下界 + 先验」同时解决的两个问题：既给瓶颈结构，又给表示强加「可解释先验」。到 VAE 那一篇我们再回头看这句话。

用一句话记住本节：**瓶颈负责「逼出结构」，正则负责「选定结构的方向」**。

## 3 稀疏编码与稀疏自编码器

从神经科学的观察出发：自然图像在视觉皮层的激活是**稀疏**的——每个刺激只激发少数神经元。**稀疏表示（sparse representation）**：让表示向量 $h$ 的大多数分量为 0，只有少数分量非零。<span class="marginnote">奥肖森与菲尔德（Olshausen & Field, 1996）提出：自然图像可以用「少量基元（如边缘、条纹）的稀疏组合」来逼近，且学出的基元与 V1 皮层感受野惊人相似——这是「能生成 = 理解了」最早的实验证据之一。</span>

**稀疏编码（sparse coding）**把「稀疏 + 重构」写成最优化问题：给定字典 $D$（基元矩阵），对输入 $x$ 求一个稀疏系数向量 $h$：

$$
\min_{h} \ \lVert x - D h \rVert_2^2 + \lambda \lVert h \rVert_1
$$

其中 $\lVert h \rVert_1 = \sum_k |h_k|$ 是 L1 范数，它在零点不可导的尖角性质天然鼓励系数「整批归零」——这正是「稀疏」二字的数学来源。<span class="marginnote">为什么是 $\ell_1$ 而不是 $\ell_2$？$\ell_2$ 只会让系数整体变小（惩罚均匀收缩），而 $\ell_1$ 对每个坐标独立施压，把「冗余的坐标」彻底清零——这正是「稀疏」的数学开关。$\ell_1$ 稀疏性在第二级《优化》与压缩感知里还会反复出现。</span>

**稀疏自编码器（sparse autoencoder）**则是把稀疏性当作正则写进自编码器的训练目标：

$$
\mathcal{L} = \mathbb{E}_x\left[\lVert x - g(f(x)) \rVert_2^2\right] + \lambda \sum_{k} \lVert f_k(x)\rVert_1
$$

两步读它：第一项是重构损失（表示要有信息量），第二项是稀疏正则（表示要简洁）。两者博弈——信息量要求「用得上」，稀疏要求「用得少」，网络被迫在矛盾中把表示组织成「少数高价值特征」。

这里留一个在后面会反复用到的句式：**自编码器系列的一切变体，都是「重构 + 一项额外约束」**。记住了这个句式，VAE、β-VAE 都可以被解读为「换一种更聪明的额外约束」。

**辨析｜易错点：** 稀疏编码与稀疏自编码器常被混用，但有一个关键差别：稀疏编码里字典 $D$ 对每个输入重新解优化问题（$h$ 是变量），而稀疏自编码器的 $h = f(x)$ 是一次前向传播直接算出的（$h$ 是网络输出）。前者是「在线求解」，后者是「函数近似」——工程上后者快得多，也是深度学习选它的原因。

## 4 去噪与收缩：让表示「抗扰动」

如果说稀疏正则逼出「简洁」，去噪自编码器（denoising autoencoder, DAE）逼出的则是「鲁棒」：把输入 $\tilde{x}$（加了噪声的版本）喂给编码器，却要求解码器还原出**干净**的 $x$。

$$
\mathcal{L}_{\text{DAE}} = \mathbb{E}_{\tilde{x} \sim q(\tilde{x} \mid x)}\left[\lVert x - g(f(\tilde{x})) \rVert_2^2\right]
$$

它的哲学呼应第一篇里的「平滑性」：能从不完整的输入还原出完整输入，说明表示捕获的是数据的**因果结构**而非表面噪声。<span class="marginnote">DAE 与另一类「收缩自编码器」（对编码函数加 Jacobian 范数惩罚）都被证明在学习「数据所在的低维流形」——这直接预告了后面《流形学习假设》一篇，那里我们会正式引入流形这个几何对象。</span>

## 5 公式解析：一个三层自编码器的完整损失

把上述所有想法装进一个最小的三层自编码器（输入 $x \in \mathbb{R}^{d_x}$，隐层 $h$，输出 $\hat{x}$）：

$$
\mathcal{L} = \frac{1}{n}\sum_{i=1}^{n} \left\lVert x^{(i)} - g\left(f\left(x^{(i)}\right)\right) \right\rVert_2^2 + \lambda \sum_{k} \lvert h_k \rvert
$$

- **第一步，读结构**：$f(x) = \sigma(W_1 x + b_1)$ 是编码器，$g(h) = W_2 h + b_2$ 是解码器，整个网络参数为 $\theta = \{W_1, b_1, W_2, b_2\}$。
- **第二步，读第一项（重构）**：对训练集中每个样本 $x^{(i)}$，要求 $\hat{x}^{(i)} = g(f(x^{(i)}))$ 尽量接近 $x^{(i)}$；$\ell_2^2$ 意味着用平方误差惩罚。这一项保证表示「有信息量」。
- **第三步，读第二项（稀疏）**：$\lambda$ 是正则强度，$|h_k|$ 惩罚每个隐单元的绝对值之和；$\lambda$ 越大，越稀疏。这一项保证表示「简洁且可解释」。
- **第四步，把握全局**：两者合在一起，就是「用一个窄/稀疏的瓶颈把数据过一遍」——凡是数据里重复出现、可组合的结构，都会被逼进少数几个稳定激活的维度里。**瓶颈 + 目标 = 表示**，这是整个生成式路线一以贯之的配方，VAE 只是把它变得更概率化、更可生成。

## 6 一张地图：自编码器家族的变体谱系

自编码器有几十种变体，它们不是随意的「魔改」，而是对同一配方「瓶颈 + 目标」在不同轴上的调节。认清这张谱系，后面读文献就能快速定位：

| 变体 | 在哪个轴上动手 | 逼出的性质 | 损失中的体现 |
| --- | --- | --- | --- |
| 欠完备自编码器 | 结构：$d_h < d_x$ | 压缩 | 重构项 |
| 稀疏自编码器 | 正则：$\ell_1$ 惩罚 | 简洁、可解释 | 稀疏正则项 |
| 去噪自编码器 | 输入：加噪 | 鲁棒、抗扰动 | 噪声分布 $q(\tilde{x}\mid x)$ |
| 收缩自编码器 | 正则：Jacobian 范数 | 平滑、流形局部 | $\lVert J_f \rVert_F^2$ 惩罚 |
| 变分自编码器 | 目标：变分下界 | 可生成、连续 | ELBO（下一篇） |
| β-VAE | 目标：加权的 ELBO | 解耦 | $\beta \cdot \text{KL}$（下下篇） |

读这张表时抓住两条线索。其一，**所有正则本质上都是「在保真与结构之间交易」**——稀疏用「损失信息」换「简洁」，去噪用「牺牲重构精度」换「鲁棒」，收缩用「限制变化」换「平滑」。其二，**从自编码器到 VAE 的演进，是把「正则」升级为「概率先验」**——VAE 不再手工挑惩罚项，而是让 KL 散度自动把表示组织成先验形状，这是更「自洽」的一步，也是下两篇的入口。

## 7 小结

- **自编码器** = 编码器 + 解码器 + 重构损失，是最古老的自监督表示学习器；线性版本等价于 PCA。
- 两类玩法：**欠完备**靠维度限制逼压缩，**过完备**必须靠正则避免退化成恒等映射。
- **稀疏编码**：$ \min_h \lVert x - Dh\rVert_2^2 + \lambda\lVert h\rVert_1 $，$\ell_1$ 的尖角把冗余坐标清零；**稀疏自编码器**把它变成一次前向传播。
- 辨析：稀疏编码在线求解 $h$，稀疏自编码器用函数近似 $h$。
- **去噪自编码器**用「噪声输入还原干净输出」逼出鲁棒表示，是流形学习的前奏。
- 中心配方：**瓶颈 + 目标 = 表示**。

在下一节，我们给自编码器装上概率引擎——**变分自编码器（VAE）**：它把「瓶颈 + 重构」升级成「变分下界 + 先验」，让机器不仅能压缩表示，还能凭空生成新样本。
