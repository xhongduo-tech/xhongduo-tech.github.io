# 表示学习导论

## 为什么从「什么是表示」开始

如果一个人只能记住深度学习的一句话，那应该是：**深度学习之所以强大，不是因为模型更深，而是因为深度网络学会了「好的表示」。** 这句话贯穿「从极限到大模型」的全部课程——第一级里我们学极限与函数，是在学「表示一个变量如何被另一个变量驱动」；第二级线性代数教会我们用向量与矩阵表示空间里的点与变换；到了第三级，模型开始把「表示」本身当作训练对象。

本专题的全部 10 篇，都在回答同一个问题：**表示从哪来、怎么学、怎么评价。**<span class="marginnote">「从极限到大模型」这条主线的暗线，其实是从「人用数学表示世界」走向「机器用数据学习表示」——表示学习就是这条暗线最终的显影剂。</span>

## 1 表示：把世界翻译成机器能运算的形式

**表示（representation）**：一组刻画某个数据实例的特征值，机器学习算法就是在这些特征值上做运算的。<span class="marginnote">分类、回归、聚类……一切机器学习任务的上游，都先是「表示」。同一个物体，表示选得不同，任务难度天差地别。</span>

一张 224×224 的彩色图片，原始表示是一维向量 $x \in \mathbb{R}^{150528}$；一句话，原始表示可以是 one-hot 词袋向量，也可以是词嵌入。这些都属于「表示」。经典机器学习非常依赖**手工特征工程**：研究者分析数据、设计特征提取器——图像领域的 SIFT、HOG，语音领域的 MFCC，都是人花几十年打磨出来的表示。

这套路线的问题在于：**特征的设计者是人，而人并不知道什么特征对任务最优。** 表示学习想要改变这个分工——

**表示学习（representation learning）**：让机器自己从数据中学到「对当前任务而言更好」的特征表示，而不是由人手工设计。

深度前馈网络天然就是一个表示学习器：它的每一层都在把上一层的表示变换成新的表示，最后一层才完成具体任务。**「学习」与「表示学习」在深度学习里几乎是同义词**，这正是本专题与第四级《神经网络》专题重叠又分岔的地方——前者讲怎么训练，本专题讲训练出来的中间层**学到了什么、凭什么好**。

这里有一条重要的分寸要把握好：**表示学习不等于「多学一个中间层」**。它把注意力从「输出」移到「中间产物」——评估表示好不好，看的是它能不能迁移、能不能解耦、能不能线性可分，而不仅是终点任务的分数。后续各篇的评估方法（线性探测等）正是围绕这一立场展开的。

## 2 好的表示长什么样

Goodfellow 在《Deep Learning》§15 里给出了好的表示的若干标准，本专题后面各篇会逐一深化，这里先立起框架：

**平滑性（smoothness）**：输入的小扰动不应导致表示发生剧烈跳变。<span class="marginnote">平滑性几乎是所有分类器的隐含假设——$f(x)$ 与 $f(x+\epsilon)$ 应当接近。它是后面《流形学习假设》一篇的基础。</span>

**线性化（linearity）**：许多我们关心的变化——光照、表情、姿态——在合适的表示下近乎线性地作用，从而可以被简单的线性模型或线性变换捕获。

**分布式（distributed）**：表示由许多「可组合」的特征协同构成，每个特征只对一部分输入激活。这是下一篇《分布式表示与因子解耦》的主角。

**因子解耦（disentangling）**：数据背后的成因（生成因子）彼此独立，好的表示应当把每种成因分到单独的维度上去。

把这些标准浓缩成一句话——**好的表示 = 平滑 + 近似线性 + 分布式 + 解耦。** 后面的 9 篇全部围绕这句话展开：VAE 与 β-VAE 回应「解耦」，流形假设回应「平滑与线性」，InfoNCE 回应「怎样不靠标签也能学出这种表示」，线性探测回应「怎么度量它好不好」。四个标准可以快速自检：

| 标准 | 通俗含义 | 检验方式 | 本专题对应 |
| --- | --- | --- | --- |
| 平滑 | 输入小变，表示小变 | 加噪声看表示变化 | 流形学习假设 |
| 近似线性 | 语义变化 ≈ 线性位移 | 表示空间做插值/算术 | 流形学习假设、GAN |
| 分布式 | 多维度协作、特征共享 | 激活模式的重叠度 | 分布式表示 |
| 因子解耦 | 一维一因子、可独立操控 | 逐个维度扰动看效果 | β-VAE |

## 3 深度何以带来指数级收益

既然表示这么好，一个自然的问题是：为什么要「深」？浅层模型也可以定义表示。Goodfellow 引用了一个关键论断：**对某些函数族，用深度表示只需要多项式级参数，而用浅层表示需要指数级参数。**

直觉可以这样看：把表示理解为「把输入空间不断折叠/展开到更容易分类的形态」。深网络一层层地组合更简单的特征——边缘组合成轮廓、轮廓组合成物体、物体组合成场景。每一层都复用前一层的成果，于是**表示能力随深度近似指数增长**，而不是线性增长。<span class="marginnote">这条「深度 > 宽度」的论证在深度学习理论里至今是热门话题；实践中反复出现的现象是：把三层网络压成一层，效果经常骤降。</span>

这也解释了本专题的技术路线图：我们不需要手动指定这些分层特征，而是给网络一个目标（重构、生成、对比、聚类），让它在完成目标的过程中自己学会分层表示。

## 4 公式解析：网络的中间层就是表示

把「深度网络在学表示」这句话写成公式。一个 $L$ 层前馈网络，把输入 $x$ 逐层变换：

$$
h^{(1)} = \sigma(W^{(1)} x + b^{(1)}), \quad h^{(2)} = \sigma(W^{(2)} h^{(1)} + b^{(2)}), \quad \dots, \quad \hat{y} = W^{(L)} h^{(L-1)} + b^{(L)}
$$

三步拆解这条链：

- **第一步，读符号**：$h^{(k)}$ 是第 $k$ 层隐藏表示（隐向量），$W^{(k)}$ 与 $b^{(k)}$ 是该层的权重与偏置，$\sigma$ 是逐元素非线性（如 ReLU）。
- **第二步，理解「表示 = 变换 + 非线性」**：若没有 $\sigma$，多层线性变换会塌缩成一层线性变换，深度毫无意义；非线性才是让每一层表示「长得」不同于上一层的引擎。因此深度网络学到的表示，是**逐层非线性变换的复合**。
- **第三步，抓住本专题的视角**：$h^{(L-1)}$ 是最后一层分类器直接使用的特征。分类器的训练目标固然是让 $\hat{y}$ 接近标签，但**为了让 $\hat{y}$ 好，优化过程被迫在 $h^{(L-1)}$ 处把各类别「分开」**——于是「分类准确」与「表示可分」成了一枚硬币的两面。后面《表征评估与线性探测》会把这一面单独拧出来量化。

## 5 表示学习的两条技术脉络

读本专题的其余 9 篇前，值得先认清它们分属两大阵营：

**生成式路线**：让网络学会「重新造出数据」。自编码器（重构）、VAE（重构 + 变分推断）、GAN（生成对抗）都在此列。它们的共同哲学是——**能生成 = 理解了**：只有抓住数据背后的真实成因，才能造出以假乱真的样本；表示就藏在被迫理解成因的那个瓶颈里。

<span class="marginnote">这句「能生成 = 理解了」并非严格定理，而是工程直觉；但它在控制论、认知科学里都有古老回声——「理解一辆车，就是能造出/预测一辆车」。</span>

**判别式 / 对比式路线**：不需要完整生成数据，只要求表示把「相似的东西拉近、不同的东西推远」。InfoNCE 对比学习、DeepCluster 聚类都属此类，它的哲学更轻巧——**我不需要学会画猫，只要学会「认出猫和狗不一样」**，这往往更容易、也更容易扩展到海量无标签数据。

| 对比维度 | 生成式路线 | 对比 / 判别式路线 |
| --- | --- | --- |
| 代表方法 | 自编码器、VAE、GAN | InfoNCE、DeepCluster |
| 监督信号 | 重构 / 变分 / 博弈 | 正负样本对 / 聚类伪标签 |
| 哲学口号 | 能生成 = 理解了 | 能区分 = 够用了 |
| 训练难度 | 高（要造出完整数据） | 相对低（只学相似性） |
| 本专题篇章 | 第 3–5、8 篇 | 第 6、10 篇 |

两条脉络会在《变分自编码器 VAE》与《对比学习与 InfoNCE》两篇中交汇：现代自监督学习的很多成功，正是把生成目标换成对比目标后的产物。

## 6 表示学习的三次转变：一部微型史

把「表示由谁定义」当作一条时间线，可以看清表示学习的完整脉络。

**第一次转变（1980s–2000s）：从手工到浅层。** 早期机器学习几乎全靠人工特征。图像用 SIFT/HOG、语音用 MFCC，研究者的精力都花在「怎么把世界翻译成特征」上。表示是**人**定义的，模型只负责在特征之上做分类。这一阶段的一切工作，都是「特征工程 + 通用分类器」的两段式。

**第二次转变（2006–2012）：深度无监督预训练。** 辛顿（Hinton）等人在 2006 年提出用受限玻尔兹曼机逐层贪心预训练深层网络，第一次让「深」可行。随后 2012 年 AlexNet 在 ImageNet 上以端到端监督训练横扫全场——人们发现，**只要数据够多、算力够强，深层网络自己就能涌现出分层表示**：低层边缘、中层部件、高层语义。表示从此由**任务目标**定义，而不是由人。

**第三次转变（2018–）：自监督的大规模表示。** 端到端监督需要海量标签，标签是稀缺的。于是「无标签数据 + 自监督目标」登场：对比学习、掩码重建（BERT 的 mask 语言建模）、聚类伪标签……表示由**数据自身的结构**定义。

语言大模型、CLIP、图像自监督模型都建立在这一层之上。<span class="marginnote">这三次转变有一个共同方向：表示的定义权，从「人」一步步移交给「数据」。本专题的每一篇，都在讲第三次转变里的某个具体机制；而它与《大模型》专题的接口，也正是在这里。</span>

## 7 小结

- **表示**是特征向量，是机器运算的原料；**表示学习**让机器自己发现好表示，取代手工特征工程。
- 好的表示的四个标准：**平滑、近似线性、分布式、因子解耦**——本专题后续各篇都是对这四个标准的深化。
- 深度的价值：**深而窄的表示能力以指数速度超过浅而宽**，因为深层特征逐层复用组合。
- 中间层 $h^{(k)}$ 就是学到的表示；分类目标的副产品是让表示可分。
- 两条技术脉络：**生成式**（自编码器 / VAE / GAN）与**对比判别式**（InfoNCE / DeepCluster），本专题逐篇展开。

在下一节，我们将深入「分布式」这一标准：为什么把表示拆成一组可组合的特征，比「一个概念占一个神经元」的局部表示强大得多——这就是**分布式表示与因子解耦**。
