# 变分自编码器 VAE

<div class="epigraph">

## 为什么自编码器要变成「变分」的

上一节末尾埋了一句话：VAE 把自编码器「瓶颈 + 重构」的配方升级成「变分下界 + 先验」。这句话的动机来自自编码器的三个痛处。

第一，普通自编码器的表示空间是「一块死板的地方」：latent 点没有先验结构，解码器只能把它当成「索引」用，中间的空隙是毫无意义的点，随便插一个点进去还原出的东西必然一团糟。

第二，它不能生成：没有「从表示空间采样 → 生成新样本」的机制。第三，它没有不确定性：表示是一个点，而不是一个分布，无法表达「我有多确定」。<span class="marginnote">一句话概括 VAE 的贡献：它把表示从「点」升级成「高斯分布」，并给出一个可微的目标函数（ELBO）让这个分布可训练。这个「从点到分布」的升级，是整个概率生成模型家族（Normalizing Flow、扩散模型）共同的地基。</span>

## 1 从潜在变量模型说起

**VAE 是一个潜在变量生成模型（latent variable generative model）**。假设数据 $x$ 由一个低维潜在变量 $z$ 通过生成过程 $p_\theta(x \mid z)$ 产生：

$$
p_\theta(x) = \int p_\theta(x \mid z)\, p(z)\, dz
$$

$p(z)$ 是先验（常取标准正态 $\mathcal{N}(0, I)$），$p_\theta(x \mid z)$ 是解码器（常取高斯，其均值由神经网络给出）。学习的目标是让 $p_\theta(x)$ 尽量拟合真实数据分布。

问题是：这个积分没法算。$z$ 是高维连续变量，直接数值积分指数级爆炸；而真实后验 $p_\theta(z \mid x)$ 同样不可计算——这正是「变分」一词出现的理由。

**凡是「两边都用得上、两边都算不动」的模型，几乎都要走变分这条路**——这句话可以原封不动地搬去读扩散模型的训练目标。

## 2 变分下界 ELBO：把不可计算的积分换成可优化的界

**变分推断（variational inference）**的思路：用一个好算的分布族 $q_\phi(z \mid x)$（编码器，输出高斯分布的均值与方差）去逼近真实后验 $p_\theta(z \mid x)$，然后把「最大化似然」换成「最大化似然的下界」。

$$
\log p_\theta(x) \ge \underbrace{\mathbb{E}_{z \sim q_\phi(z \mid x)}\big[\log p_\theta(x \mid z)\big]}_{\text{重构项}} - \underbrace{D_{\text{KL}}\big(q_\phi(z \mid x) \,\|\, p(z)\big)}_{\text{先验正则项}} = \text{ELBO}
$$

这个 ELBO（evidence lower bound，证据下界）就是 VAE 的训练目标——一个要最大化的目标，也就是普通自编码器「损失」的相反数。<span class="marginnote">「证据」指的是 $p_\theta(x)$（数据的边际似然），因为它「支持」了观测数据；ELBO 之所以叫「下界」，是因为 KL 散度恒非负：$\log p(x) = \text{ELBO} + D_{\text{KL}}(q \| p) \ge \text{ELBO}$。最大化 ELBO = 在提高下界的同时，也把 $q$ 推向真实后验。</span>

这里值得停下来体会「变分」的代价：我们**不是**在最大化真正的似然 $\log p_\theta(x)$，而是在最大化它的一个下界。下界松不松，取决于 $q_\phi(z \mid x)$ 这一族分布离真实后验有多远——所以 VAE 学到的表示质量，本质上是「用一个高斯分布逼近真实后验」这一近似造成的「近似误差」。这个视角在后续读 VAE 的种种改进（normalizing flow 做后验、两阶段训练）时会反复出现。

## 3 公式解析：ELBO 的三步拆解

ELBO 是全篇的灵魂公式，拆开读：

- **第一步，读重构项 $\mathbb{E}_{z \sim q_\phi}[\log p_\theta(x \mid z)]$**：从编码器给出的分布里采样 $z$，看解码器能多好地还原 $x$。它对应自编码器的重构损失，但更「概率化」——若 $p_\theta(x \mid z)$ 取高斯，$\log p_\theta(x \mid z)$ 就是带符号的 MSE。这一项逼表示「有信息量」。
- **第二步，读先验正则项 $-D_{\text{KL}}(q_\phi(z \mid x) \| p(z))$**：KL 散度衡量编码器输出的分布离先验 $\mathcal{N}(0, I)$ 多远。它逼表示「有结构」——每个样本的 latent 分布被拉向标准正态，于是表示空间被填成一个连续的、大部分区域都有意义的「云」，而不是一个个孤立的点。
- **第三步，读两者的博弈**：重构项想把每个 $z$ 精确塞进各自的位置（编码分布变尖、位置发散），正则项想把它们都拢回原点附近（分布变平、聚拢）。**训练就是在这两个力之间找平衡**——这也是为什么 VAE 学出的表示里，相邻的 latent 点对应语义相近的样本，从而能「在表示空间插值、得到新样本」。

三者合起来就是一句话：**VAE = 一个会生成的自编码器**，它的瓶颈不只是一个窄层，而是一组「均值 + 方差」，解码器不再把 latent 当索引，而是当真随机变量。

## 4 重参数化技巧：让采样变得可微

ELBO 里有个采样操作 $z \sim q_\phi(z \mid x)$，而采样不可微，梯度无法回传到编码器。**重参数化技巧（reparameterization trick）**把它绕开：

$$
z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon, \qquad \epsilon \sim \mathcal{N}(0, I)
$$

把「从分布采样」改写成「从固定分布 $\mathcal{N}(0, I)$ 采样噪声 $\epsilon$，再做确定性的仿射变换」。于是随机性被「外包」给与参数无关的 $\epsilon$，而 $z$ 关于 $\mu_\phi, \sigma_\phi$ 是确定且可微的，梯度就能畅通无阻地穿过采样层。

<span class="marginnote">这个技巧的意义远超 VAE：它是「随机模型端到端梯度训练」的通用开关，Normalizing Flow、强化学习的策略梯度、Gumbel-Softmax 等都受益于同一思想。</span>

一个容易忽略的细节：重参数化同时抬高了「解码器不再见到确切的 $z$」——每次前向，$z$ 都带着随机扰动。这本身就像一种**随机正则化**：解码器必须学会「对 $z$ 的微小扰动不敏感」，于是生成函数被磨得平滑。这又和第一篇「平滑性是好的表示标准」呼应上了。

**辨析｜易错点：** 初学者常把「编码器输出 $q(z \mid x)$ 是高斯」误解成「$z$ 一定服从高斯」。准确说法是：$z \mid x$ 被建模成高斯（均值、方差由网络给出），且先验 $p(z) = \mathcal{N}(0, I)$；正则项把二者往一起拉，所以训练结束后，**边际分布 $p(z) = \int q(z \mid x) p_{\text{data}}(x) dx$ 近似标准正态**——但它是「近似」，不是定理。

另一个常见误解是「VAE 就是加了噪声的自编码器」——VAE 的噪声（方差）本身也是学出来的，并且直接参与生成，性质完全不同。

## 5 VAE 表示的性质与局限

训练好后，编码器 $q_\phi(z \mid x)$ 就是一个**表示学习器**，它把 $x$ 映射到表示空间的一个高斯分布（实践上常用均值 $\mu_\phi(x)$ 作为表示向量）。它的好处正是本专题反复强调的——把前几篇的标准对照着看，你会发现 VAE 逐一兑现：

**连续的、有意义的表示空间**：可以插值、算术（表示空间里的「王 − 男 + 女 ≈ 后」这类操作在 VAE 表示上同样出现）；
- **可生成**：从先验 $\mathcal{N}(0, I)$ 采样即可合成新样本；
- **自带不确定性**：方差 $\sigma_\phi(x)$ 就是「模型对这幅图的表示有多大把握」的一个信号。<span class="marginnote">VAE 也常被批评：它学出的表示往往「解耦不足」——重构目标的压力让多种因素纠缠在同一维度。这个「保真 vs 解耦」的天平，正是下一篇 β-VAE 要在 ELBO 上动手脚的地方。</span>

| 对比维度 | 普通自编码器 | VAE |
| --- | --- | --- |
| 表示形态 | 一个点 $h$ | 一个分布 $q(z\mid x)$ |
| 潜在空间连续性 | 差（孤立的点） | 好（连续的云） |
| 能否生成新样本 | 不能 | 能（从先验采样） |
| 训练目标 | 重构损失 | ELBO |
| 是否概率模型 | 否 | 是（潜在变量模型） |

这张表的本质差别只有一个：**自编码器把表示当「编码的结果」，VAE 把表示当「潜在变量」**。正是这个立场变化，让一切都变了。

## 6 一个走查：VAE 在 MNIST 上的生命周期

把抽象降到具体，跟一遍 VAE 在 MNIST 手写数字上的完整生命周期。

**训练前**。输入是 $28 \times 28 = 784$ 维像素向量。选潜在维度 $d_z = 2$（为了可视化）。编码器 $q_\phi(z \mid x)$ 输出 2 维均值 $\mu$ 与 2 维方差 $\sigma^2$；解码器 $p_\theta(x \mid z)$ 从 2 维 $z$ 重建 784 维图像。目标就是 ELBO，$\beta = 1$ 的标准版。

**训练中**。两个力在拉扯：重构项要求「从 $z$ 能还原出 $x$」，KL 项要求「$q(z \mid x)$ 靠近 $\mathcal{N}(0, I)$」。于是编码器学会「把每张图的本质信息编码成两个数」，同时「保证这两个数别离原点太远」。注意：**KL 项是随样本逐个算的**——每张图贡献自己的一份「离先验多远」的惩罚，所以哪怕不同图片的编码相差很远，它们的分布整体也会被拢成一个连续的云。

**训练后——生成**。从 $\mathcal{N}(0, I)$ 里采样 $z$，过解码器。因为训练把整个 $z$ 平面填满了「有意义的点」（不只是一个孤立样本的编码），所以任意采样的 $z$ 都能解码出「像数字」的图像。这是普通自编码器做不到的：它的潜在空间是「稀疏的插孔」，插孔之间是无效区域。

**训练后——插值**。取「0」的编码 $\mu_0$ 与「8」的编码 $\mu_8$，沿直线 $\mu_0 + t(\mu_8 - \mu_0)$ 走，每一步解码：会看到数字从 0 平滑过渡到 8，中间是「既像 0 又像 8」的合法字形。<span class="marginnote">这个「插值成立」的实验，是 VAE 表示「连续、有结构」最直观的证据，也是它区别于「死板的索引式表示」的试金石。后来大模型的 latent 空间（如 Stable Diffusion 的潜空间）里做插值，用的正是同一个思想。</span>

我们把这个 2 维潜空间的横纵轴打开看，往往会发现：一个轴大致对应「数字的形状粗细」，另一个轴对应「倾斜/角度」——尽管没有任何标签，结构还是被组织了出来。这就是「表示自己涌现出结构」的现场：没有人在训练时告诉模型「粗细」是什么，但为了同时满足重构与先验，它自己把这两个轴摆了出来。

## 7 小结

- VAE = 潜在变量生成模型 + 变分推断：用**编码器 $q_\phi(z \mid x)$ 逼近真实后验**，用**解码器 $p_\theta(x \mid z)$ 生成**。
- 训练目标是 **ELBO**：重构项 + 先验正则项（KL 散度），两个力的平衡决定表示的形态。
- **重参数化技巧**把采样改写为「噪声 + 可微变换」，让随机模型端到端可训练。
- VAE 的表示是**分布而非点**：连续、可插值、可生成、自带不确定性。
- 辨析：$z \mid x$ 建模为高斯 ≠ $z$ 一定服从高斯；「加噪声」只是表象，方差本身是学出来的。
- VAE 的短板是解耦不足——为下一篇铺路。

在下一节，我们把 ELBO 里的 KL 项装上「旋钮」——**解纠缠表示与 β-VAE**：一个加权的 KL 项，如何换来可解释、可控的表示。
