## 为什么从微波网络开始

上一篇我们把一条传输线描述成「特性阻抗 + 传播常数」；但一个微波系统是几十个器件级联的庞然大物——功分器、耦合器、滤波器、放大器、天线。把每个器件看成一个**多端口网络**，只关心端口之间「波进波出」的关系，系统设计就变成矩阵代数。这个语言就是 **S 参数（散射参数）**，整个射频工业的通用方言。<span class="marginnote">为什么不能沿用低频的阻抗矩阵 $[Z]$ 或导纳矩阵 $[Y]$？因为微波下开路与短路难以实现（寄生、辐射、振荡），而「端接 50 Ω、测波」是可重复的物理操作。S 参数是唯一「用实验可测、用数值可算、用设计可写」的三栖语言。</span>

这一篇把 S 参数讲透，再用它重新审视上一篇的匹配网络与无源器件——你会看到「器件」与「网络」只是同一个东西的两种称呼。

**为什么低频不用 S 参数**：集总电路里电压、电流可测、可列基尔霍夫方程，所以 $Z/Y/ABCD$ 参数顺手。但频率升高后，测试夹具的开路/短路本身充满寄生——「开路」会辐射、「短路」会振荡，**唯一可重复的端接是匹配负载**，于是 S 参数（以匹配为基准的散射量）天然胜出。这不是 S 参数更「高级」，而是它更「可测」。

## 1 S 参数：定义与物理意义

定义一组**归一化入射波与反射波**：端口 $n$ 的入射波 $a_n = \frac{V_n^+}{\sqrt{Z_0}}$、反射波 $b_n = \frac{V_n^-}{\sqrt{Z_0}}$，各端口的反射波与入射波通过**散射矩阵**联系：

$$
\begin{bmatrix} b_1 \\ b_2 \\ \vdots \\ b_N \end{bmatrix}
= \mathbf{S}
\begin{bmatrix} a_1 \\ a_2 \\ \vdots \\ a_N \end{bmatrix}, \qquad
S_{ij} = \left. \frac{b_i}{a_j} \right|_{a_k = 0,\, k \ne j}
$$

**物理意义**：$S_{ij}$ 是「只有端口 $j$ 有入射波、其余端口接匹配负载时，从端口 $j$ 到端口 $i$ 的传输」。对角线元素 $S_{ii}$ 是各端口的**回波/反射系数**，非对角线 $S_{ij}$ 是**传输系数**。所有端口都以 $Z_0$ 端接——这正是「可测」的物理基础。

拿最常见的**二端口网络**把四个元素说清楚：

| S 参数 | 物理含义 | 工程指标 |
| --- | --- | --- |
| $S_{11}$ | 端口 1 反射 | 回波损耗/输入 VSWR |
| $S_{21}$ | 1→2 前向传输 | 插入损耗/增益 |
| $S_{12}$ | 2→1 反向传输 | 隔离度/反向增益 |
| $S_{22}$ | 端口 2 反射 | 输出回波损耗 |

一张滤波器数据表、一台功放的规格书，讲的都是这四格：**$|S_{21}|$ 是增益曲线、$|S_{11}|$ 是匹配曲线、$|S_{12}|$ 是隔离**。看懂这张 2×2 表，就看懂了几乎所有微波器件的规格。<span class="marginnote">S 参数是「频率的函数」：每个频率一个复数矩阵。数据表里的曲线就是扫频后的 $S_{ij}(f)$——滤波器的通带是 $|S_{21}|$ 高、$|S_{11}|$ 低的区间，放大器的增益带宽是 $|S_{21}|$ 平坦的区间。<strong>「读 S 参数曲线」是微波工程师的日常阅读</strong>。</span><span class="marginnote">$S_{ij}$ 是复数，幅度给大小、相位给延时：$|S_{21}|$ 是前向传输的幅度比，$\angle S_{21}$ 是传输相位（换算成群延时就是「信号走了多久」）。一张 $N \times N$ 复数矩阵，把 $N$ 端口网络在某个频率的全部行为压缩干净。</span>

## 2 S 参数的性质：互易与无损

S 矩阵不是任意的，物理约束刻在它的结构里：

**互易（reciprocity）**：由各向同性媒质构成的无源网络满足 $S_{ij} = S_{ji}$，S 矩阵对称——**传输方向对调，结果不变**。例外是非互易器件（铁氧体隔离器、环行器），它们靠外加磁场打破时间反演对称。
**无损（lossless）**：无耗网络满足 $\mathbf{S}^\dagger\mathbf{S} = \mathbf{I}$（S 矩阵酉），即 $\sum_k S_{ki}S_{kj}^* = \delta_{ij}$——**每行模方和为 1，功率守恒**。有耗网络各端口的模方和小于 1，差量就是耗散的功率。
**匹配与对称**：$S_{ii} = 0$ 表示端口匹配（无反射）；物理对称的网络 S 矩阵还有结构对称性。

**辨析｜易错点：** 三端口无损互易网络不可能三端口全匹配——酉性 + 对称性会导出矛盾。这正是《射频匹配与微波无源器件》里威尔金森功分器「用隔离电阻换全匹配」的数学根源：**没有耗损，就没有全匹配的三端口**。

用无损条件做一次数值体检：一个理想二端口滤波器，若通带内 $|S_{21}| = -0.5$ dB（即 $|S_{21}| = 0.944$），则 $|S_{21}|^2 = 0.891$，无损要求 $|S_{11}|^2 = 0.109$，即 $|S_{11}| = 0.330$、RL ≈ 9.6 dB——**通带插损与带内回波是绑定的**：插损越小，能允许的回波越大。这个「守恒账本」让工程师一眼就能判断一份 S 参数数据表「物理上是否可信」——若插损与回波对不上守恒律，数据就有问题。<span class="marginnote">这个技巧在验收时极其好用：看到一份数据表，先算「$|S_{11}|^2 + |S_{21}|^2$ 是否约等于 1」。若明显小于 1，说明网络有耗（可能合理）；若大于 1，说明测量有错。<strong>「S 参数自检」是射频工程师最便宜的质量守门员</strong>。</span><span class="marginnote">这条「不可能定理」是微波网络理论最漂亮的结论之一：设计者想给三端口都匹配，唯一出路是引入损耗（隔离电阻）或打破互易（环行器）。工程上的每一类三端口器件，都对应定理的某一条「逃逸路线」。</span>

## 3 从 S 参数到系统：级联与变换

**S 参数里还藏着第三个量——群延时**：$\tau_g = -\frac{d\phi_{21}}{d\omega}$（$\phi_{21} = \angle S_{21}$）。它度量「信号穿过网络需要多久」，滤波器的群延时不平坦会造成波形失真（色散在器件层面的对应物）。所以高端滤波器数据表除了 $|S_{21}|$ 曲线，还必附群延时曲线——**幅度响应选频、相位响应定失真，两张图一起看才算看清一个滤波器**。

单个器件只是矩阵，系统是矩阵的运算：

**级联**：两个双端口网络级联时，S 参数不能直接相乘（中间端口的波同时耦合进两端），需先转成**传输散射矩阵（T 参数）**再相乘——信号流图（signal flow graph）就是为此发明的图形代数，每个节点是波、每条边是 S 参数，用梅森增益公式求系统传递函数。
**阻抗变换**：S 参数与 $Z$、$Y$、$ABCD$ 参数之间有标准换算表——在哪个坐标系分析方便就换到哪个，如同傅里叶变换在时频域间切换。

这些运算让「指标推导」机械化：放大器增益、滤波器插损、天线反射，最终都能写成「若干 S 参数的函数」——**设计微波系统 = 组装 S 参数网络**。

**算一条级联链路**：滤波器（插损 -1 dB）→ 放大器（增益 +20 dB）→ 另一段线（-0.5 dB），三段功率沿链路走一遍：输入 -30 dBm → 滤波后 -31 dBm → 放大后 -11 dBm → 输出 -11.5 dBm——**每一项都是加减法，因为功率在 dB 域是线性的**。这就是为什么射频系统设计全在 dB 域进行：S 参数本身就是「dB 域的乘法变加法」，整个链路预算因此变成一张简单到可以心算的表格。<span class="marginnote">dB 域加减还有一个隐藏好处：它把「乘除」变成「加减」，让工程师能边开会边心算链路增益。你只要记住「+3 dB = 功率 ×2、-10 dB = 功率 ×1/10」，整条链路的预算就能在脑海里跑起来——这是射频工程师最常用的一项「人肉计算」。</span><span class="marginnote">信号流图把射频工程师的直觉系统化：看到反射就画一条边、看到传输就画一条边，环路的贡献一目了然。它和反馈放大器理论同源，学会后回头看多级级联，不再是「黑箱叠黑箱」。</span>

## 4 网络分析：矢量网络分析仪与校准

S 参数不是纸上谈兵，测它的仪器是**矢量网络分析仪（Vector Network Analyzer, VNA）**。它内部是反射计——用定向耦合器把端口上的入射波与反射波分开，再比幅度与相位，扫频测出每个端口的 $S_{ij}$。

**校准（calibration）**是测量精度的一半：SOLT（短路-开路-负载-直通）或 TRL（直通-反射-线）校准把参考面从仪器面板搬到被测件端口，抵消电缆、转接头、夹具的误差。**校准的本质是「只留被测件」**——不校准的矢网读数是夹具的读数，不是器件的读数。<span class="marginnote">矢网「扫一条曲线」的背后是频率合成器 + 定向耦合器 + 四通道接收机 + 校准算法：每一条 $S_{21}$ 曲线，都是一组波经过分离、下变频、比值与误差修正之后的产物。它的动态范围可达 120 dB——能同时看到「-110 dB 的泄漏」与「+10 dB 的增益」。</span>

**时域变换**：把频域 S 参数做反傅里叶变换，矢网还能给出「反射发生在线上哪个位置」——用等效时域定位故障点与不连续，这是排障的利器。

**一支典型矢网扫一条 $S_{21}$ 曲线的旅程**：合成器扫频输出 → 定向耦合器把入射/反射分开 → 四通道接收机下变频、检波 → 处理器按校准系数修正误差 → 屏幕上出现一条曲线。**整条链路里，校准系数决定曲线的「绝对值准不准」，接收机动态范围决定「小信号看得见看不见」**——把这两个旋钮想清楚，矢网的所有参数（扫描点数、IF 带宽、平均次数）都有了意义。

**两种主流校准方案的取舍**：

| 校准法 | 需要的标准件 | 适用场景 |
| --- | --- | --- |
| SOLT | 短路、开路、负载、直通 | 同轴接口、标准连接器，最常用 |
| TRL | 直通、反射、一段线 | 非标接口（夹具、探针台）、宽带精确 |

**辨析｜易错点：** 校准不是「调一次就完」——参考面是**频率的函数**，扫多宽的频带就要在对应频点上校准；而且校准件本身要有「可溯源的已知值」，否则「用不准的标准去校准，只会把误差规范化」。所以严谨的射频实验室把「校准件有效期」与「仪器周期检定」看得和仪器本身一样重。<span class="marginnote">探针台与夹具测量是校准的极端场景：被测件是芯片焊盘，根本没有标准接口——工程师用校准片（cal kit on wafer）做 TRL 校准，把参考面设到探针尖端。这正是「校准的本质是只留被测件」的最纯粹体现。</span>

## 5 无源器件网络的速览

用 S 参数语言重读无源器件，每条指标都是一条 S 参数：

| 器件 | 端口数 | 核心 S 参数指标 | 一句话机制 |
| --- | --- | --- | --- |
| 威尔金森功分器 | 3 | $|S_{21}|=|S_{31}|=-3$ dB、$S_{11}=S_{22}=S_{33}=0$、$S_{23}=0$ | 隔离电阻换全匹配 |
| 定向耦合器 | 4 | 耦合度、方向性、隔离度 | 平行线相位耦合 |
| 滤波器 | 2 | $|S_{21}|$ 通带/阻带、$|S_{11}|$ 匹配 | 谐振级联选频 |
| 隔离器/环行器 | 2/3 | $S_{12}\ne S_{21}$ 非互易 | 铁氧体磁各向异性 |
| 衰减器 | 2 | $|S_{21}|$ 固定值 | 电阻网络耗功率 |

**功分器**：威尔金森功分器 $|S_{21}| = |S_{31}| = -3$ dB（等分）、三端口匹配、两输出隔离 $S_{23} = 0$。
**定向耦合器**：四端口，耦合度 $C = -20\log|S_{31}|$、方向性 $D = -20\log\frac{|S_{31}|}{|S_{41}|}$——方向性越好，测正向功率时反射泄漏越小。
**滤波器**：带内插损 $-20\log|S_{21}|$、回波 $-20\log|S_{11}|$、带外抑制、矩形系数；从低通原型经频率与阻抗变换到分布实现。
**隔离器/环行器**：铁氧体非互易器件，$S_{12} \ne S_{21}$；隔离器保护功放、环行器实现雷达收发共用天线。它们的规格书同样只用 S 参数书写：正向插损 $|S_{21}|$（0.3–0.5 dB）、反向隔离 $|S_{12}|$（20 dB 以上）、各端口匹配——非互易网络与互易网络的差别，不过是一个对称性条件的破缺。

**公式解析：S 参数与四项指标的换算**——插损 $\mathrm{IL} = -20\log|S_{21}|$ dB，回波损耗 $\mathrm{RL} = -20\log|S_{11}|$ dB，VSWR $= \frac{1+|\Gamma|}{1-|\Gamma|}$（$\Gamma = S_{11}$），隔离度 $= -20\log|S_{12}|$ dB。<span class="marginnote">射频工程师的「心头换算」：$|S_{21}| = 0.891$ ⇔ $-1$ dB ⇔ 功率通过 79%；$|S_{11}| = 0.1$ ⇔ $-20$ dB ⇔ 反射 1%。这些数字不必查表，用 $20\log$ 心算成习惯后，S 参数曲线读图就像读刻度尺。</span>

## 6 小结

- **S 参数**是微波网络的通用语言：$S_{ij}$ 是「只有端口 $j$ 入射时从 $j$ 到 $i$ 的传输」，所有端口以 $Z_0$ 端接，物理可测。
- **互易网络** $S_{ij}=S_{ji}$；**无损网络** $\mathbf{S}^\dagger\mathbf{S}=\mathbf{I}$；三端口无损互易不可能全匹配——威尔金森用损耗破解。
- 系统设计 = S/T 参数级联 + 信号流图 + 阻抗/导纳坐标变换。
- 测量靠**矢网 + SOLT/TRL 校准**，校准把参考面搬到被测件端口；时域变换可定位不连续。
- 无源器件的每一条指标——功分、耦合、隔离、滤波——都是一条 S 参数。
