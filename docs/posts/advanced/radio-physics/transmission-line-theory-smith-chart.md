## 为什么从传输线开始

上一篇我们看电磁波在自由空间旅行；这篇看它被「装进管道」之后的旅行。天线到收发机之间、收发机内部各级之间，能量都靠**传输线（transmission line）**搬运——同轴线、微带线、双绞线、带状线。当线的长度与波长可比时，「电压在某点是一个数」的集总电路直觉彻底失效，必须用**分布参数**的眼光重看电磁学。<span class="marginnote">判据很朴素：波长与电路尺寸可比时，相位沿导线显著变化，传输线效应不可忽略。2.4 GHz 的波长约 12.5 cm，一块手机主板的走线动辄几厘米——所以射频设计处处是传输线，低频电路的经验全部要重学。</span>

传输线是连接「场」与「路」的桥梁：它的方程从麦克斯韦方程导出，却可以用电压、电流、阻抗这些电路语言描述。掌握传输线，等于掌握射频设计的第一门方言。

它也把本专题的两端接起来：向前看，它是《微波网络》里 S 参数的载体（每个端口都端接在一条特性阻抗线上）；向后看，它是《射频匹配与微波无源器件》里一切匹配网络、功分器、滤波器的物理舞台。**传输线不是「一根线」，而是「一部完整的波导理论在电路语言里的投影」**——这一篇把它讲透，后面所有器件设计都有了共同的地基。

## 1 分布参数与特性阻抗

把一段长度为 $\Delta z$ 的传输线看成由**单位长度分布参数**组成的级联：串联电阻 $R$、串联电感 $L$、并联电导 $G$、并联电容 $C$。当 $\Delta z \to 0$，得到电报方程：

$$
\frac{\partial V}{\partial z} = -(R + j\omega L) I, \qquad \frac{\partial I}{\partial z} = -(G + j\omega C) V
$$

两个方程联立得到**波动方程**，其解是沿 $\pm z$ 方向的两列波。关键参数由此诞生：**特性阻抗（characteristic impedance）** $Z_0 = \sqrt{\frac{R + j\omega L}{G + j\omega C}}$，无损时简化为 $Z_0 = \sqrt{L/C}$。<span class="marginnote">特性阻抗不是「一段线两端量出来的电阻」——它是「行波电压与行波电流之比」，是一个波的概念，与线的长度无关。50 Ω 与 75 Ω 是历史与工程折中的结果：50 Ω 在功率容量与损耗之间取中，75 Ω 早期同轴电视更佳，于是各自成派。</span>

传播常数同样来自电报方程：$\gamma = \sqrt{(R+j\omega L)(G+j\omega C)} = \alpha + j\beta$。**整条线的全部行为，只由 $Z_0$ 与 $\gamma$ 两个参数决定**——这是传输线理论最浓缩的结论。

**电报方程的谱系**是工程史的一课：海维赛德（Oliver Heaviside）在 1887 年用这套方程研究海底电报电缆的畸变，发现「加感」（在电缆上串接电感）能改善衰减——这正是今天双绞线的前世。**同一个方程，一百年前治电报畸变，一百年后算 5G 毫米波走线**：传输线理论是「最老」也是「最现代」的射频工具。<span class="marginnote">海维赛德的贡献不止电报方程：他独立发明了算子微积分（今天的拉普拉斯变换），还把麦克斯韦方程组改写成今天教科书里的四方程矢量形式。微波工程最深处的数学，一半是这位自学成才的工程师打下的。</span>

常用线的参数记忆：50 Ω 半刚性同轴、75 Ω 视频同轴、100 Ω 差分对、微带线按介质板可做到任意 $Z_0$——**选 $Z_0$ 就是在「损耗、功率、制造」三轴里选位置**。

## 2 反射系数、驻波与回波损耗

当线上存在阻抗不连续（如负载 $Z_L \ne Z_0$），入射波在负载处部分反射。**电压反射系数（voltage reflection coefficient）**：

$$
\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}
$$

入射波与反射波干涉，线上形成**驻波（standing wave）**。**电压驻波比（VSWR）** $= \frac{V_{\max}}{V_{\min}} = \frac{1 + |\Gamma|}{1 - |\Gamma|}$，它度量「驻波有多强」——$|\Gamma|=0$ 时 VSWR = 1（全匹配），$|\Gamma|=1$ 时 VSWR → ∞（全反射）。<span class="marginnote">工程上常用<strong>回波损耗（return loss）</strong> $\mathrm{RL} = -20\log|\Gamma|$ dB：VSWR 2:1 对应 $\mathrm{RL} = 9.5$ dB，即 11% 的功率被反射。天线验收、功放保护的指标几乎都以「VSWR ≤ 某值」或「RL ≥ 某值」给出——三种语言（$\Gamma$、VSWR、RL）随时互算。</span>

沿线的输入阻抗随位置周期变化：$\lambda/4$ 处阻抗倒置（$Z_{in} = Z_0^2/Z_L$），$\lambda/2$ 处阻抗还原（$Z_{in} = Z_L$）——这两条规律是下面匹配设计的杠杆。

**把三种语言换算成一张速查表**，是射频读数的基本功：

| 反射 $|\Gamma|$ | VSWR | 回波损耗 RL | 反射功率占比 |
| --- | --- | --- | --- |
| 0.1 | 1.22 | 20 dB | 1% |
| 0.2 | 1.50 | 14 dB | 4% |
| 0.316 | 1.92 | 10 dB | 10% |
| 0.5 | 3.0 | 6 dB | 25% |
| 1.0 | ∞ | 0 dB | 100% |

**记住两个锚点**：VSWR 2:1 ↔ RL 9.5 dB ↔ 反射 11%；VSWR 1.5:1 ↔ RL 14 dB ↔ 反射 4%。天线允许 VSWR ≤ 2、功放要求 ≤ 1.5——同一套换算，两种口径，结论天差地别。<span class="marginnote">为什么「口径」如此关键？因为 VSWR 2 的天线在功放看来仍是 11% 反射，功放会把这 11% 的功率反射回来烧自己——所以功放端口的「好天线」标准比天线自己的标准严得多。设计交接时「口径不一致」是最大的坑。</span>

一个实际例子：50 Ω 系统接 75 Ω 负载，$\Gamma = (75-50)/(75+50) = 0.2$，RL 14 dB、VSWR 1.5——看起来「还行」，但这 4% 的反射在级联多级后会累积成驻波灾难，这也是为什么「整条链路统一 50 Ω」是射频的第一条纪律。

## 3 史密斯圆图：把一切画在圆上

**史密斯圆图（Smith chart）**是 1939 年 P. H. Smith 发明的图形化工具，把整个复反射系数平面保角映射到单位圆内。圆图上的每一点同时携带四组信息：归一化电阻、归一化电抗、反射系数、VSWR 与等衰减圆。

**用法即直觉**：向源移动 = 沿圆顺时针转；向负载移动 = 逆时针转。串联电感沿等电阻圆顺时针走，串联电容逆时针；并联电感沿等电导圆顺时针，并联电容逆时针。

**亲手画一次 L 型匹配**：负载 $Z_L = 25 - j50\,\Omega$，50 Ω 系统。先在圆图上标出归一化 $0.5 - j1$，沿等电阻圆（串联电感）或等电导圆（并联元件）走到与匹配圆相交——交点给出两个解，选实现容易的那个，再走线段回圆心。**整个过程就是「沿圆走、再沿圆走」，无需求解方程**——这是 1939 年以来四代工程师共用的一门手艺。<span class="marginnote">圆图操作的两条金律：<strong>串联元件沿等电阻/电抗圆走、并联元件沿等电导/电纳圆走</strong>；<strong>向源顺时针、向负载逆时针</strong>。每次设计前后都用圆图目测一遍「反射系数落在哪」，比盲信仿真更能抓住直觉性错误——它是射频工程师永不退休的草图本。</span>

圆图还能读带宽：匹配点在圆心的「足迹」随频率画出一条弧，弧落在 VSWR ≤ 2 圆内的频率范围就是匹配带宽——**带宽不是算出来的，是「画」出来的**，这也是「史密斯圆图是射频代数的几何」这句话的注脚。<span class="marginnote">圆图为什么风行八十年？因为它把「乘除法」变成「画弧」：传输线上走一段距离，就是绕圆心转一个角度 $2\beta l$；加一个电抗，就是沿圆滑一段弧。二战雷达工程师用圆图配匹配网络，今天 EDA 工具仍以它做交互界面——它的几何就是微波代数的几何。</span>现代设计在软件里完成，但理解圆图仍是最快的「出错检查器」：**任何匹配网络的带宽、任何走线的长度换算，都能在圆图上目测核对。**

## 4 阻抗匹配：从 λ/4 变换到短截线

**阻抗匹配（impedance matching）**的目标是把负载阻抗变换到源阻抗，让反射为零、功率最大传输。经典手段：

**λ/4 变换器**：在负载与 $Z_0$ 之间插一段 $\lambda/4$ 线，特性阻抗 $Z_1 = \sqrt{Z_0 Z_L}$，一次变换把 $Z_L$ 变到 $Z_0$。窄带（匹配只在 $\lambda/4$ 附近成立），但结构最简单。
**单短截线匹配**：在距负载某位置并联或串联一段可调短截线，用圆图找位置与长度——灵活，但仍受限于频带。
**双元件 L 型网络**：串并联各一个电抗，任意负载可匹配，圆图上有两个解（两支拓扑），带宽取决于元件位置。

**宽带匹配**靠多级变换与切比雪夫渐变实现：级数越多、带宽越宽，但线更长、损耗更大——**带宽、阶数、损耗三者不可兼得**，这是匹配设计不变的权衡。

**λ/4 变换的算例**：50 Ω 系统匹配 100 Ω 负载，$Z_1 = \sqrt{50 \times 100} = 70.7\,\Omega$——插一段 70.7 Ω 的 $\lambda/4$ 线即完成变换。这个数字精确到用微带线就能实现：选择合适的介质板宽长比，蚀刻一条 $\lambda/4$ 长的 70.7 Ω 线，匹配就完成了。**但它的带宽很窄**：只在 $\lambda/4$ 附近全匹配，偏离一个百分点的频率，VSWR 就爬上去——所以窄带点频（如功放输出、天线馈电点）常用它，宽带系统必须上多级或渐变。

**为什么匹配只谈「窄带/宽带」不谈「快慢」**：匹配网络不追求「响应快」（那是脉冲/数字电路的事），只追求「一个频带内反射够小」。射频里「快」=「带宽宽」，而带宽总以效率与损耗为代价——这是贯穿《微波网络》与《射频器件》两篇的同一句话。<span class="marginnote">匹配网络的「带宽」永远是相对概念：同一网络，功放要求 VSWR ≤ 1.5（RL ≥ 14 dB）与天线要求 VSWR ≤ 2（RL ≥ 9.5 dB），得到的带宽结论完全不同——设计前先钉死指标口径，是射频工程师的第一课。</span>

## 5 公式解析：反射系数 $\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$

这条公式是全部传输线现象的入口，四步拆解：

- **第一步，写出波**：线上电压 $V(z) = V^+ e^{-j\beta z} + V^- e^{j\beta z}$，前向波与后向波叠加；电流 $I(z) = \frac{1}{Z_0}(V^+ e^{-j\beta z} - V^- e^{j\beta z})$。

这套「前向 + 后向」的写法有一个隐蔽的好处：它天然解释了一切传输线现象——**线上任意一点的状态，都是两列波的瞬时和**。驻波的波腹是两列波同相叠加、波节是反相相消；VSWR 度量的是这个干涉的对比度；而匹配，就是消灭后向波让线上只有一列波。**「把多列波简化成一列波」就是匹配的哲学**。
- **第二步，代入边界**：在负载端 $z = 0$，$V(0)/I(0) = Z_L$，即 $\frac{V^+ + V^-}{V^+ - V^-} = Z_L/Z_0$。
- **第三步，解出比值**：令 $\Gamma = V^-/V^+$，上式解出 $\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$——**反射比只由两个阻抗决定**，是匹配问题的唯一核心。
- **第四步，读三种极限**：$Z_L = Z_0$ 时 $\Gamma = 0$（全吸收）；$Z_L = 0$（短路）时 $\Gamma = -1$（反相反射）；$Z_L = \infty$（开路）时 $\Gamma = +1$（同相反射）。$|\Gamma| = 1$ 时 VSWR 发散，纯驻波——能量完全困在线里，这正是谐振腔的工作基础。

用公式反推一句常识：**为什么「失配」一定要修？** 以 $\Gamma = 0.3$ 为例，$|\Gamma|^2 = 9\%$ 的功率被反射回功放；若功放输出不匹配，这部分功率在功放与负载之间来回反射、反复耗散在功放输出级——轻则效率暴跌、重则烧管。**反射系数从 0.1 到 0.3，只差一次不合格的接头**——这就是为什么射频系统的每一个连接点都要按扭矩规范拧紧、都要测 S 参数验收。<span class="marginnote">把 $\Gamma$ 想成「两个阻抗的拔河」：负载与特征阻抗差得越远，反射越强。它还隐含一个方向：从「+ 端」看与从「− 端」看符号相反——所以圆图上「向负载」与「向源」永远反向，这是阻抗变换的本质。</span>

## 6 传输线的族谱与损耗

实际工程选哪种线，看频段、功率与集成度：

**同轴线**：TEM 模、宽带、屏蔽好，仪器连接与高功率馈线首选；频率上限受高次模截止限制。
**微带线**：平面化、易光刻，射频芯片与 PCB 的绝对主力；缺点是半开放结构有辐射损耗与色散。
**带状线与共面波导**：前者全屏蔽、对层间干扰不敏感，后者正反面都可走线，常用于 MMIC 内部。
**介质波导与光波导**：频率升到太赫兹与光频，金属导波让位给介质约束——这是下一篇的话题。

**损耗的构成**：导体损耗（趋肤效应，随 $\sqrt{f}$ 增长）、介质损耗（$\tan\delta$）、辐射损耗（开放结构）。

把损耗摊到「每厘米多少 dB」，设计就有了手感：FR-4 微带线在 2.4 GHz 约 0.1 dB/cm、28 GHz 约 1 dB/cm；同轴线更优、波导最优。**射频走线的第一条戒律是「线越短越好」**——因为损耗是长度的一次函数，而线路板上每一厘米都要用链路预算来付账。

**算一条典型链路**：功放到天线馈点之间 20 cm 的 FR-4 微带线，在 2.4 GHz 吃掉 2 dB、在 28 GHz 吃掉 20 dB——后者直接把功放一半的功率烧在走线上。这就是毫米波设计必须用低损耗板材（Rogers/陶瓷）、并尽量把功放紧贴天线的全部理由：**「损耗 × 长度」这条乘法，是射频版图布局的第一优化目标**。<span class="marginnote">介电损耗还随 $\tan\delta$ 走：FR-4 的 $\tan\delta \approx 0.02$、Rogers 4350B 约 0.0037——材料好十倍，高频损耗就差十倍。所以「换板材」是毫米波链路预算里见效最快的杠杆，代价是成本与机械强度。工程选材 = 在损耗、成本、加工性三者里划一条可接受的线。</span>

**介质色散与高次模**是频率上限的另一把锁：微带线频率升高会出现色散与表面波泄漏、同轴线出现 TE/TM 高次模——每类线都有「建议频率上限」，超过就换结构。这和本专题《波导与谐振结构》的截止频率是同一件事的两副面孔。<span class="marginnote">微带线的损耗预算常这样记：FR-4 板材在 2.4 GHz 约 0.1 dB/cm，到 28 GHz 时接近 1 dB/cm——毫米波设计必须换用低损耗板材（如 Rogers），且尽量把线做短。损耗不是抽象的「Q 值」，而是每一厘米的 dB 数，链路预算里的真金白银。</span>

## 7 小结

- **分布参数模型**：线由单位长度 $R,L,G,C$ 描述，波动方程解出 $Z_0$ 与 $\gamma$ 两个参数决定一切。
- **特性阻抗 $Z_0 = \sqrt{L/C}$** 是行波的概念，与长度无关；50 Ω/75 Ω 是工程折中。
- **反射系数 $\Gamma = (Z_L-Z_0)/(Z_L+Z_0)$**，与 VSWR、回波损耗三语互通。
- **史密斯圆图**把匹配问题变成画弧；λ/4 变换、短截线、L 型网络是三大匹配工具，宽带靠多级与渐变。
- 线族分同轴、微带、带状线、共面波导等，按频段、功率、集成度取舍；损耗按 dB/cm 计入预算。

在下一节，我们将给传输线装上「网络」的眼镜——用 **S 参数**描述多端口微波器件，这就是**微波网络与无源器件**。
