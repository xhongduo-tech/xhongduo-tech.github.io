# 射频匹配与微波无源器件

<div class="epigraph">

## 为什么从无源器件开始

一部射频前端由有源器件（功放、低噪放、混频器）与**无源器件**（功分器、耦合器、滤波器、谐振器、隔离器）组成。无源器件不放大、不产生能量，只做四件事：**分路、合成、滤波、隔离**。它们的共同语言是**散射矩阵（S 参数）**——第12篇不连续性一章已经引入，现在用它来定义和设计每一类器件。掌握无源器件，等于掌握射频系统的「管道与阀门」。<span class="marginnote">无源器件「免费而珍贵」：它们不耗直流、线性好、几乎不产生噪声，却决定系统的频带、功率分配与隔离度。一个优秀的收发前端，一半的功夫花在无源网络的拓扑与实现上。</span>

上一节我们看信号在空间如何传播；本节看信号在器件里如何被「整形」——从匹配网络与 Smith 圆图的应用，到威尔金森功分器、定向耦合器、滤波器的原理与指标。

## 1 匹配网络：S 参数视角的回顾

匹配网络（第7篇传输线一章讲过 λ/4 变换与短截线）在器件设计里是基本功。这里补充两个工程细节：

**双元件匹配（L 型网络）**：串并联各一个电抗元件，把任意负载匹配到 $Z_0$。圆图上有两个解（两种拓扑），选哪个取决于带宽与实现难度。
**宽带匹配**：多级 λ/4 变换、切比雪夫渐变、巴特沃斯/切比雪夫多阶网络——带宽与阶数的权衡，就是滤波器综合的雏形。

**匹配质量指标**：回波损耗（RL）、VSWR、反射系数三者互通。**辨析｜易错点：** 匹配网络的「带宽」以 VSWR ≤ 2 为界，但功率放大器常要求 VSWR ≤ 1.5（RL ≥ 14 dB），天线常容忍 VSWR ≤ 2（RL ≥ 9.5 dB）——**同一网络，指标不同，带宽结论不同**。设计前先明确指标口径。<span class="marginnote">Smith 圆图上匹配的「三角板操作」：串联电感沿等电阻圆顺时针走、串联电容逆时针走、并联电感沿等电导圆顺时针、并联电容逆时针。熟练工程师的匹配设计是「在圆图上画几条弧」的事，现代 EDA 只是把这件事自动化。</span>

## 2 功分器：威尔金森功分器

**威尔金森功分器（Wilkinson power divider）**是最常用的等分/不等分功率分配器。等分二路威尔金森：

两路 $\lambda/4$ 传输线，特性阻抗 $Z_0\sqrt{2}$；
输出端之间跨接隔离电阻 $2Z_0$。

它的三项核心指标：

- **功分**：$|S_{21}| = |S_{31}| = -3$ dB（等分）；
- **匹配**：三个端口都匹配（$S_{11} = S_{22} = S_{33} = 0$）；
- **隔离**：两个输出端相互隔离（$S_{23} = 0$）。

<span class="marginnote">威尔金森的隔离电阻是关键：它消耗两输出端「来回反射」的功率，使两路即使负载失配也互不串扰。没有隔离电阻的 T 型功分器做不到三端口同时匹配（三端口无损互易器件不可能全匹配——这是 S 矩阵的数学结论）。威尔金森用「有损」元件换来了「全匹配」。</span>

**S 矩阵视角**：三端口无损互易网络不可能三端口全匹配（$S_{11}=S_{22}=S_{33}=0$ 与酉性矛盾）；威尔金森引入隔离电阻（有损）才打破这个不可能。这一结论是微波网络理论的重要一课。

## 3 定向耦合器

**定向耦合器（directional coupler）**把输入功率的一部分耦合到特定方向，其余直通。四端口器件，主要指标：

**耦合度（coupling）**：$C = -10\log|S_{31}|^2$ dB——耦合端口从输入抽走的功率；
**方向性（directivity）**：$D = -10\log(|S_{31}|^2/|S_{41}|^2)$ dB——理想时隔离端口无输出；
- **隔离度（isolation）**：$I = -10\log|S_{41}|^2$ dB。

典型实现：两条平行传输线相距四分之一波长、通过耦合缝耦合。**解析｜方向性的价值**：定向耦合器用于功率监测时，只希望「正向功率」耦合到监测口、「反向功率」到隔离口；方向性越好，测正向功率时反射功率的泄漏越小——方向性 20 dB 意味着反向泄漏只有正向耦合的 1%。<span class="marginnote">定向耦合器是矢网、功率计、反射计的心脏：VSWR 测量本质是「用定向耦合器分开正向与反射波，再比幅度」。90° 混合耦合器（quadrature hybrid）更是 I/Q 调制器、镜像抑制混频器、平衡放大器的核心——它把信号等分且相位差 90°，是无数前端拓扑的「分相器」。</span>

## 4 滤波器：从低通原型到实现

微波滤波器设计走「**原型综合**」路线：

1. **低通原型**：设计归一化的集总 L-C 梯形网络（巴特沃斯最平、切比雪夫等波纹、椭圆最陡），给出元件值与阶数；
2. **频率/阻抗变换**：把低通原型变换到所需频段（低通/高通/带通/带阻）与阻抗；
3. **实现**：用分布元件（微带线、腔体）实现每个集总元件。

**关键指标**：插入损耗（带内 $S_{21}$）、回波损耗、带外抑制、矩形系数（过渡带陡峭度）、群延时平坦度。<span class="marginnote">「切比雪夫 vs 巴特沃斯」的取舍：切比雪夫带内有等波纹（可做到 -0.1 dB 纹波）、带外更陡；巴特沃斯带内最平、带外较缓。通带纹波与过渡带陡峭度不可兼得——和天线里的旁瓣/主瓣权衡是同一类对偶。现代滤波器（SAW/BAW 声学滤波器、介质滤波器）把这条综合路线推到 GHz 以上的极致小型化。</span>

**辨析｜易错点：** 滤波器阶数 ≠ 抑制能力线性增长。每增加一阶，带外抑制约改善 6 dB/oct（巴特沃斯），但群延时恶化、插损累积。**「阶数 = 性能 = 损耗」三者的平衡**是滤波器选型的核心判断。

## 5 隔离器与环行器：非互易器件

**隔离器（isolator）**与**环行器（circulator）**是少见的**非互易**无源器件：它们的 S 矩阵不满足 $S_{ij} = S_{ji}$。物理基础是**铁氧体的磁各向异性**——外加磁场下，铁氧体对正反两个方向传播的波呈现不同响应（法拉第旋转效应）。

**环行器**：三端口，信号只按一个方向环流（1→2→3→1），反向不通。
**隔离器** = 环行器一端接匹配负载：信号从 1 到 2 通过，从 2 来的反射被 3 的负载吸收——**保护功放免受天线失配反射的伤害**。

<span class="marginnote">功率放大器的「防反盾」：功放输出接隔离器，天线失配的反射功率被隔离器吸收而不是反射回功放——否则反射功率会让功放过载、自激甚至烧毁。环行器还用于雷达收发共用一副天线（发射时环形到天线、接收时天线环形到接收机），这是单天线雷达的标配拓扑。</span>

## 6 公式解析：威尔金森功分器 $|S_{21}| = |S_{31}| = -3\ \mathrm{dB}$

把威尔金森的指标用 S 矩阵语言拆透：

- **第一步，理想等分**：输入功率 $P_1$ 平分到两输出，$P_2 = P_3 = P_1/2$。$|S_{21}|^2 = 1/2$，即 $|S_{21}| = 1/\sqrt{2}$，dB 表达 $20\log(1/\sqrt{2}) = -3.01$ dB。**「-3 dB」就是「功率一半」**——射频里最常用的换算。
- **第二步，匹配条件**：三端口全匹配要求 $S_{11} = S_{22} = S_{33} = 0$。等分威尔金森通过 λ/4 变换 $Z_0\sqrt{2}$ 把输出阻抗变换到输入，再靠隔离电阻平衡，实现全匹配。
- **第三步，隔离条件**：$S_{23} = 0$ 要求两输出间不互串——隔离电阻 $2Z_0$ 把「一路反射 → 另一路」的耦合功率在电阻上耗掉。
- **第四步，无损校验**：$|S_{21}|^2 + |S_{31}|^2 = 1$（等分时两路已分完），但加上 $|S_{23}|^2$ 这一项，三端口功率守恒要求 $|S_{21}|^2+|S_{31}|^2+|S_{11}|^2 = 1$——隔离电阻上恰好耗掉 $|S_{23}|^2$ 对应的功率。**「用有损换全匹配」的账本，就在这一条守恒律里。**

## 7 无源器件的家族图谱

功分器与耦合器之外，射频无源网络还有几个高频成员：

**巴伦（balun）**：平衡-不平衡变换器，把双端口的平衡信号变成单端口的非平衡信号，是推挽功放、差分天线馈电、混频器本振输入的标准接口。它的核心指标是**平衡度**（两路幅度相等、相位差 180°）与**共模抑制**。

**混合耦合器（hybrid）**：正交（90°，branch-line / Lange）与反相（180°，rat-race）两类。90° 混合把输入等分且相位差 90°，是 I/Q 调制器、镜像抑制混频器、平衡放大器的分相核心；180° 混合（rat-race）用于合路/分路与单边带抑制。<span class="marginnote">拉特环（rat-race）的周长是 $1.5\lambda_g$，沿环每隔 $\lambda_g/4$ 引一个端口——四个端口等间隔分布在环上，靠传输线相位实现「同相相加、反相相减」。它的带宽不如 branch-line，但结构简单、相位关系精确。</span>

**衰减器与移相器**：固定衰减器用电阻网络（T 型、π 型）提供可预测的插损；可变衰减器用 PIN 二极管或 MMIC 晶体管实现电调。移相器是相控阵的核心，其相位误差直接决定波束指向误差。

**谐振器与滤波器再访**：腔体滤波器（高 Q、低插损、功率容量大）、介质滤波器（小型化）、声学滤波器（SAW/BAW，GHz 以下极高 Q）——它们都是「储能结构 + 耦合」的实例，指标语言完全相同：中心频率、带宽、插损、带外抑制、群延时。

## 8 无源器件的测量与指标

无源器件好不好，靠一套标准测量来判定：

**S 参数测量**：矢网（VNA）扫频测 $S_{11}$、$S_{21}$、$S_{22}$、$S_{12}$。测前必须**校准**（SOLT 或 TRL），把测量参考面从仪器端口搬到被测件端口，否则电缆与转接头的损耗会混进结果——**校准的本质是「去掉夹具，只留被测件」**。

**常用指标换算**：插损 $\mathrm{IL} = -20\log|S_{21}|$ dB；回波损耗 $\mathrm{RL} = -20\log|S_{11}|$ dB；VSWR $= (1+|\Gamma|)/(1-|\Gamma|)$；隔离度 $I = -20\log|S_{12}|$ dB。**四指标互算，是射频测量的基本功**——矢网上读一个 S 参数，其余全在脑子里换算。

**功率容量与无源互调**：无源器件还有两类「功率」指标——最大可承受功率（烧毁/击穿门限）与**无源互调（PIM）**（接触不良、非线性介质在双频激励下产生的杂散）。高功率链路（基站、雷达）必须测 PIM，一个松动接头可能让杂散抬升几十 dB。<span class="marginnote">PIM 是射频工程最隐蔽的敌人：两个大信号在锈蚀接头、劣质介质处「混频」，产生落在接收频段的三阶互调产物——它像噪声又像干扰，却来自自己的发射链路。所以高功率无源器件的验收单上，PIM 与 S 参数并列。</span>

## 9 无源器件的设计权衡

把无源器件的设计压缩成一张权衡清单，工程决策就有了抓手：

| 权衡 | 两端 | 工程取向 |
| --- | --- | --- |
| 带宽 vs 插损 | 宽带网络元件多、损耗大 | 只做够用的带宽 |
| 功率 vs 尺寸 | 高功率要腔体/波导，体积大 | 按峰值功率选结构 |
| 隔离 vs 损耗 | 高隔离要更多耦合级 | 隔离够指标即可 |
| 小型化 vs Q 值 | 介质/声学器件 Q 高但功率小 | 按频段与功率分流 |

**解析｜「先器件后系统」**：无源器件是射频系统的「积木」，但每一块积木的指标都会累积进系统预算——功分器 0.3 dB 插损、耦合器 0.1 dB 插损、滤波器 1 dB 插损，串进链路就吃掉 1.4 dB。**系统设计者必须知道每块积木「值多少钱」**，这也是 S 参数语言比集总电路语言更适用于射频的原因：它直接告诉你每级的损耗与反射。

## 10 小结

- **威尔金森功分器**用隔离电阻打破「三端口无损互易不可能全匹配」，实现等分、全匹配、高隔离。
- **定向耦合器**靠耦合度、方向性、隔离度三个指标刻画；方向性越好，测正向功率越干净。
- **滤波器**走「低通原型 → 频率/阻抗变换 → 分布实现」路线，带外抑制与通带纹波不可兼得。
- **隔离器/环行器**是非互易器件，靠铁氧体的磁各向异性保护功放、实现收发共用天线。
- 无源器件用**S 参数**统一描述，测量靠矢网 + 校准，验收还要看功率容量与 PIM。
