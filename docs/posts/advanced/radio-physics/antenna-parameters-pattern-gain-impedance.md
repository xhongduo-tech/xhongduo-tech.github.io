## 为什么从天线参数开始

一副天线「好不好」，不能靠感觉：工程师用一组标准参数说话——**方向图**看能量往哪走，**方向性/增益**看集中度与效率，**输入阻抗**看是否与馈线匹配，**极化**看与来波是否对齐。这组参数是天线规格书的全部内容，也是天线选型、链路预算、雷达方程的共同语言。任何天线，从手机里的 PIFA 到射电望远镜的抛物面，最终都要翻译成这组参数来评估。<span class="marginnote">天线参数是「从物理到工程」的翻译层：物理关心场与电流，工程关心方向图与增益。学天线，一半功夫在场上（辐射积分），一半功夫在把场翻译成参数（本节）。</span>

上一节偶极子给了我们第一个方向图与辐射电阻；本节把它们系统化为通用度量体系，并补充波束宽度、旁瓣电平、带宽与有效口径等完整工具箱。

## 1 辐射方向图与波束

**辐射方向图（radiation pattern）**是辐射特性（场强或功率）随空间方向的分布图。常画成两个正交面的剖面：E 面（含电场方向与波束轴的面）与 H 面（含磁场方向与波束轴的面）。方向图的关键特征：

**主瓣（main lobe）**：最大辐射方向附近的波束；**半功率波束宽度（HPBW）**：功率降到一半（-3 dB）的两个方向夹角。
**旁瓣（side lobes）**：主瓣之外的局部极大。**第一旁瓣电平（FSLL）**通常以 dB 计（低于主瓣）。
- **零点（nulls）**：辐射为零的方向——雷达测向、干扰抑制恰恰利用零点。

**辨析｜易错点：** 方向图有三种密度口径——**场强方向图** $|F(\theta,\phi)|$、**功率方向图** $|F|^2$、**方向性方向图** $U(\theta,\phi)$。读图时先确认画的是哪种：场强图与功率图相差平方（-3 dB 点位置不同），把两者混用是初学者常犯的错误。<span class="marginnote">dB 视角：场强 -3 dB = 功率 -6 dB？不对——场强 $|F|$ 降到 $1/\sqrt{2}$ 即 -3 dB 时，功率 $|F|^2$ 降到 1/2 即 -3 dB，两者同时发生。HPBW 用哪个算结果一致，但「场强相对功率的换算」必须记牢 $P\,\mathrm{dB} = 2E\,\mathrm{dB}$（场强加倍 = 功率 +6 dB）。</span>

**波束立体角（beam solid angle）** $\Omega_A = \iint |F(\theta,\phi)|^2\, d\Omega$ 与方向性系数直接相关，是把方向图「积分成一个数」的关键。

## 2 方向性与增益

**方向性系数（directivity）**：最大辐射方向上的辐射强度与平均辐射强度之比：

$$
D_0 = \frac{U_{\max}}{U_{\mathrm{avg}}} = \frac{4\pi U_{\max}}{P_{\mathrm{rad}}}
$$

理想各向同性源 $D_0 = 1$（0 dBi）；偶极子 1.76 dBi；反射面天线可达 40–50 dBi。方向性与波束宽度存在近似反比关系（无损耗口径近似）：

$$
D_0 \approx \frac{4\pi}{\theta_{1r}\,\theta_{2r}} \approx \frac{41253}{\theta_{1\deg}\,\theta_{2\deg}}
$$

其中 $\theta_{1r},\theta_{2r}$ 是两个正交面的半功率波束宽度（弧度），41253 是球面度的平方度常数。<span class="marginnote">「方向性 × 波束面积 ≈ 4π」是一条深刻的对偶：波束越窄，方向性越高——天线把能量「捏」得越紧，辐射强度越大。这个近似关系让工程师在暗室里扫一遍方向图，就能立刻估出方向性，不必积分。</span>

**增益（gain）**：考虑效率后：

$$
G = \eta_a D_0, \qquad \eta_a = \frac{R_r}{R_r + R_{\mathrm{loss}}}
$$

**辨析｜易错点：** 方向性与增益的区别是「效率」——方向性只看「场怎么分布」，增益还问「进去的功率有多少真的辐射出来」。损耗大的天线（短偶极子、加载天线）增益远低于方向性。文献里常写 dBi（相对各向同性源）与 dBd（相对半波偶极子），两者差 2.15 dB：$\mathrm{G[dBd]} = \mathrm{G[dBi]} - 2.15$。

## 3 输入阻抗、反射系数与带宽

天线的**输入阻抗（input impedance）** $Z_{\mathrm{in}} = R_{\mathrm{in}} + jX_{\mathrm{in}}$，其中 $R_{\mathrm{in}} = R_r + R_{\mathrm{loss}}$（辐射电阻 + 损耗电阻），$X_{\mathrm{in}}$ 是输入电抗。馈电点看进去的反射系数与驻波比：

$$
\Gamma = \frac{Z_{\mathrm{in}} - Z_0}{Z_{\mathrm{in}} + Z_0}, \qquad \mathrm{VSWR} = \frac{1+|\Gamma|}{1-|\Gamma|}
$$

**阻抗匹配**要求 $Z_{\mathrm{in}} = Z_0$（通常 50 Ω）——天线谐振时 $X_{\mathrm{in}} = 0$，匹配网络把 $R_{\mathrm{in}}$ 变换到 $Z_0$。<span class="marginnote">半波偶极子的输入阻抗约 73 + j42.5 Ω（有教材按不同馈电点修正为 73 + j0 附近），用「折叠偶极子」（约 300 Ω）或馈电网络匹配到 50 Ω。为什么 73 Ω 如此有名？因为它是半波偶极子的辐射电阻，也是「天线阻抗家族」的基准值。</span>

**带宽（bandwidth）**：天线参数满足指标要求的频率范围，常用 VSWR ≤ 2 或回波损耗 ≥ 10 dB 定义。带宽与 Q 值、尺寸互为约束——电小天线的窄带（Chu 极限）与宽带宽角扫描的矛盾，是天线设计的永恒主题。

## 4 有效口径与天线定理

接收天线的能力用**有效口径（effective aperture）**描述：$A_e = P_{\mathrm{rec}}/S_{\mathrm{inc}}$，即接收功率与入射功率密度之比。它与增益之间有一条普适关系——**天线定理（antenna theorem）**：

$$
A_e = \frac{\lambda^2}{4\pi}\,G
$$

对无损耗天线 $A_e = \frac{\lambda^2}{4\pi}D_0$。<span class="marginnote">这条公式是所有链路预算的心脏：已知发射天线增益、频率与距离，就能算出接收天线收到的功率（Friis 公式）。它还把「增益（方向性）」与「接收口径（面积）」统一起来——同一副天线收发互易，发射强方向性 = 接收大口径。抛物面的 $A_e$ 接近物理面积，所以射电望远镜靠大「盘子」收集微弱信号。</span>

**Friis 传输公式**连接收发两端：

$$
P_r = P_t\, G_t\, G_r\left(\frac{\lambda}{4\pi R}\right)^2
$$

$(\lambda/4\pi R)^2$ 是**自由空间路径损耗（free-space path loss）**。链路预算就是这条公式的工程化：距离翻倍，接收功率降 6 dB——这是所有无线通信系统的「距离惩罚」。

## 5 极化、天线温度与互易性

- **极化**：天线有发射极化与接收极化（第5篇极化章节），失配损耗 $\mathrm{PLF}$ 计入链路。
- **天线噪声温度**：天线接收的不仅有信号，还有环境热噪声——天线的**噪声温度** $T_A$ 综合了背景辐射与损耗，是灵敏度的核心（射电天文、卫星通信最看重）。
- **互易性（reciprocity）**：线性互易天线的收发方向图相同——发射增益 = 接收增益，$Z_{12} = Z_{21}$。它让「测量发射方向图」与「测量接收方向图」等价，是天线测量节省一半工作量的理论依据。<span class="marginnote">互易性还带来一个实用推论：天线的匹配网络、馈电点选择，只需在发射态调一次，接收态自动同性能。几乎所有天线设计软件（HFSS 等）都利用互易性简化仿真与测量。</span>

## 6 公式解析：$D_0 = \frac{4\pi U_{\max}}{P_{\mathrm{rad}}}$ 与 $G = \eta_a D_0$

把方向性到增益的完整链条拆成四步：

**第一步，辐射强度 $U$**：$U(\theta,\phi) = r^2 S(\theta,\phi)$（W/sr），与距离无关。最大值 $U_{\max}$ 就是主瓣方向的辐射强度。
**第二步，方向性 = 峰值 ÷ 平均**：平均辐射强度 $U_{\mathrm{avg}} = P_{\mathrm{rad}}/(4\pi)$（总功率摊到整个球面）。$D_0$ 就是「峰值方向集中了多少倍平均」。各向同性源 $U = U_{\mathrm{avg}}$，$D_0 = 1$。
- **第三步，引入效率**：输入功率 $P_{\mathrm{in}} = P_{\mathrm{rad}} + P_{\mathrm{loss}}$，效率 $\eta_a = P_{\mathrm{rad}}/P_{\mathrm{in}}$。增益用输入功率做分母：$G = \frac{4\pi U_{\max}}{P_{\mathrm{in}}} = \eta_a D_0$。
- **第四步，dB 表达与换算**：$G[\mathrm{dBi}] = 10\log_{10}G$；相对半波偶极子 $G[\mathrm{dBd}] = G[\mathrm{dBi}] - 2.15$。**一个数三种写法，先看基准再看数值**——这是天线规格书阅读的第一课。<span class="marginnote">举例：某基站天线标称 17 dBi，意味着相对各向同性源功率集中 $10^{1.7} \approx 50$ 倍；若效率 90%，则方向性约 17.5 dBi。链路预算里直接用 $G$ 的 dBi 值相加，不必回头乘效率——这就是「增益」存在的理由。</span>

## 7 链路预算实战：一个例子

把本章参数体系用到一次真实的链路估算：地面站 → 卫星（GEO）的下行链路。

**已知条件**：卫星 EIRP（等效全向辐射功率）= 50 dBm，GEO 距离约 36,000 km，频率 12 GHz（Ku 波段），地面站天线增益 40 dBi，接收机噪声温度 200 K，带宽 36 MHz，所需 SNR 8 dB。

**第一步，自由空间损耗**：$L_{fs} = 92.4 + 20\log 12 + 20\log 36000 \approx 92.4 + 21.6 + 91.1 = 205.1$ dB。

**第二步，接收功率**：$P_r = \mathrm{EIRP} - L_{fs} + G_r = 50 - 205.1 + 40 = -115.1$ dBm。注意 EIRP 已含卫星发射增益，路径损耗用全向基准，故接收端加地面站增益。

**第三步，噪声与灵敏度**：$P_n = -174 + 10\log(36\times10^6) + 10\log 200/290 \approx -174 + 75.6 - 1.6 = -100$ dBm；加所需 SNR 8 dB，灵敏度约 -92 dBm。

**第四步，判决**：$P_r = -115.1$ dBm 远低于灵敏度 -92 dBm——链路不通。怎么救？提卫星 EIRP、加大地面站口径（增益每 +3 dB 就 +3 dB 余量）、降带宽、降噪声温度。**这就是链路预算的价值：一眼看出「差多少 dB、从哪补」**——所有无线系统的设计决策，最后都回到这张表的加减法。

## 8 小结

- **方向图**用主瓣、HPBW、旁瓣、零点刻画；场强图与功率图差平方，读图先辨口径。
- **方向性** $D_0 = 4\pi U_{\max}/P_{\mathrm{rad}}$，与波束面积成反比（≈41253/θ₁θ₂）。
- **增益** $G = \eta_a D_0$：方向性 × 效率；dBi 与 dBd 相差 2.15 dB。
- **输入阻抗**与反射系数、VSWR 相连；带宽常以 VSWR ≤ 2 定义。
- **有效口径** $A_e = \lambda^2 G/(4\pi)$
