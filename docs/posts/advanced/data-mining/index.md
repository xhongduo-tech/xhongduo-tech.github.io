# 数据挖掘

从海量数据中发现有意义的模式与知识，是数据库与机器学习交叉的核心学科。覆盖频繁模式、聚类、离群点检测与流挖掘，是把原始数据转化为决策价值的必由之路。

## 对标教材

- Han, Kamber & Pei《Data Mining: Concepts and Techniques》(Morgan Kaufmann, 3rd ed.)
- 周志华《机器学习》(清华大学出版社)
- Aggarwal《Data Mining: The Textbook》(Springer)
