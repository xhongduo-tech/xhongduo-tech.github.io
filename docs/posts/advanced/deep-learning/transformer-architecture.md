## 为什么从 Transformer 整体架构开始

自注意力是「零件」，**Transformer** 是「整机」。2017 年《Attention Is All You Need》提出 Transformer，用一个「纯注意力 + 前馈」的结构取代 RNN——它在机器翻译上取得突破，并迅速统治了 NLP，进而扩散到视觉、语音、乃至一切「序列/集合建模」。今天所有大语言模型（GPT、BERT、LLaMA）都是 Transformer 的变体——**理解了 Transformer 的整体架构，就理解了现代 AI 的「发动机」**。

Transformer 的架构看起来复杂（编码器-解码器、多头注意力、前馈、残差、归一化、位置编码），但它的设计哲学极其清晰：**用「注意力」做信息交互，用「前馈网络」做逐位置处理，用「残差 + 归一化」保证可训练，用「位置编码」补顺序信息**。本节先把「整机」的框架搭起来——编码器块与解码器块各自包含什么、信息如何流动——后续几节再逐个零件精讲。<span class="marginnote">「Transformer 的名字」来自「变换器」——它把「注意力的组合」当作一种「变换」反复应用。它的诞生是「架构简化史」的又一章：RNN（顺序复杂）→ 注意力辅助（2015）→ 纯注意力（2017）——「把复杂的顺序机制全部拿掉，只剩注意力 + 前馈」，结果反而更强。这个「去掉复杂、保留简单」的教训，在深度学习史里反复出现。</span>

## 1 Transformer 的总体结构：编码器-解码器

Transformer 沿用「编码器-解码器」的 Seq2Seq 骨架，但每个部分都由 **Transformer 块** 堆叠而成：

```text
编码器（理解输入）                             解码器（生成输出）
┌───────────────────────────┐              ┌─────────────────────────────┐
│ 编码器块 ×N               │              │ 解码器块 ×N                 │
│  自注意力                  │              │  掩码自注意力（只看已生成词） │
│     ↓                     │              │    ↓                       │
│  残差 + LayerNorm          │              │  交叉注意力 ◄── 编码器输出   │
│     ↓                     │              │    ↓                       │
│  前馈 FFN                  │              │  残差 + LayerNorm           │
│     ↓                     │              │    ↓                       │
│  残差 + LayerNorm          │              │  前馈 FFN                   │
└───────────┬───────────────┘              │    ↓                       │
            │                              │  残差 + LayerNorm           │
            └────────────────────────────► │    ↓                       │
                                           │  线性 + Softmax → 下一个词   │
                                           └─────────────────────────────┘
```

**编码器（encoder）**：$N$ 个编码器块堆叠，每个块 =「多头自注意力 + 前馈网络」，各配残差与归一化。编码器**双向**——每个位置能看全部源序列位置。

**解码器（decoder）**：$N$ 个解码器块堆叠，每个块 =「掩码自注意力 + 交叉注意力 + 前馈网络」。解码器**单向**（掩码自注意力只看已生成的词）+ **交叉注意力**（从编码器取用信息）。

**「编码器理解输入、解码器生成输出」**——这是「编码-解码」框架在注意力时代的延续。<span class="marginnote">「Transformer 的 N」：原论文 N=6（6 层编码器 + 6 层解码器）。现代变体的「层数」差异巨大——BERT-base 12 层、GPT-3 96 层。「层数」是 Transformer 的「深度旋钮」，与 ResNet 的「层数」同义——更深通常更准，但更贵、更难训。</span>

**易错点：** Transformer 不是「必须编码器-解码器」——只有编码器（BERT）、只有解码器（GPT）都是合法变体。**「编码器-解码器」是「翻译/生成」任务的标配；「编码器」适合「理解」任务；「解码器」适合「自回归生成」**——第六篇的 BERT 与 GPT 两节会分别展开。

## 2 编码器块：自注意力 + 前馈

一个**编码器块（encoder block）**的内部结构（Pre-LN 形式，现代主流）：

```text
输入 x
  │
  ▼
LayerNorm ──► 多头自注意力 ──► (＋) 残差相加 ──► LayerNorm ──► 前馈 FFN ──► (＋) 残差相加 ──► 输出
  ▲                                ▲                                   ▲
  └── 输入 x 保留（残差捷径）────────┘          └── 中间结果保留（残差捷径）──┘
```

**每个子层都是「操作 → 残差 → 归一化」**的三段式：自注意力/前馈负责「变换」，残差保证梯度流，LayerNorm 稳定分布。**「先残差后归一化（Pre-LN）」或「先归一化后残差（Post-LN）」** 是位置之争（第六篇《Pre-LN/Post-LN》专门讲）。

**前馈网络（Feed-Forward Network, FFN）**：每个位置独立的两层 MLP：

$$
\text{FFN}(\boldsymbol{x}) = \boldsymbol{W}_2\,\text{ReLU}(\boldsymbol{W}_1\boldsymbol{x} + \boldsymbol{b}_1) + \boldsymbol{b}_2
$$

**「注意力管『位置之间』的交互，FFN 管『每个位置内部』的变换」**——这是 Transformer 的分工核心。<span class="marginnote">「注意力 vs FFN 的分工」是读懂 Transformer 的钥匙：注意力是「序列维」的信息混合（不同位置交互），FFN 是「特征维」的逐位置变换（每个位置独立加工）。现代研究表明 FFN 像个「键值记忆」——存储「知识模式」，注意力决定「调取哪些知识、放到哪个位置」。这个「注意力取用 + FFN 存储」的解读，是理解大模型知识存储的流行框架。</span>

## 3 解码器块：掩码 + 交叉注意力

一个**解码器块**比编码器块多一个子层：

```text
已生成的输出序列
  │
  ▼
掩码自注意力（因果掩码：不能看未来）──► 残差 + LayerNorm
  │
  ▼
交叉注意力（Q 来自解码器，K/V 来自编码器）──► 残差 + LayerNorm
  │
  ▼
前馈 FFN ──► 残差 + LayerNorm
  │
  ▼
线性层 + Softmax ──► 预测下一个词
```

**掩码自注意力（masked self-attention）**：生成第 $t$ 个词时，只能「看」前 $t-1$ 个词——用**因果掩码（causal mask）**把「未来位置」的注意力权重设为 $-\infty$（softmax 后为 0）。**「解码器不能偷看未来」**——这是自回归生成的根本约束。

**交叉注意力（cross-attention）**：查询来自解码器、键/值来自编码器——**解码器从编码器「按需取用」源序列信息**。这正是第五篇「注意力机制」的经典用法。

**「解码器 = 掩码自注意力（自回归约束）+ 交叉注意力（取用编码器） + FFN」**——三件套的组合。<span class="marginnote">「因果掩码」的实现细节：注意力权重矩阵 $\boldsymbol{A}\in\mathbb{R}^{n\times n}$ 的上三角部分全部设为 $-\infty$（softmax 前），这样位置 $i$ 对 $j>i$ 的权重为 0——「只能看自己与过去」。这个「掩码」技巧在 GPT 等纯解码器里同样使用（第六篇《GPT 系列》）。「掩码」是「自回归约束」的注意力实现——「先掩码、后 softmax、再加权」的顺序是实现的铁律。</span>

**易错点：** 交叉注意力的「查询、键、值」来自**不同**序列——查询（解码器）与键/值（编码器）维度要匹配（都是 $d_k, d_v$），但「序列长度」可以不同（源长 $n$、目标长 $m$）。**「跨序列注意力的维度匹配看『特征维』，不看『长度维』」**。

## 4 公式解析：Transformer 块的信息流

把一个编码器块的完整信息流写成数学（Pre-LN 形式）。输入 $\boldsymbol{x}\in\mathbb{R}^{n\times d}$：

$$
\boldsymbol{a} = \text{LayerNorm}\big(\boldsymbol{x} + \text{MHA}(\boldsymbol{x})\big)
$$

$$
\boldsymbol{o} = \text{LayerNorm}\big(\boldsymbol{a} + \text{FFN}(\boldsymbol{a})\big)
$$

- **第一步，看自注意力子层**：$\boldsymbol{x}$ 先过「多头注意力 MHA」（序列维交互），输出与 $\boldsymbol{x}$ 相加（残差），再过 LayerNorm——**「交互 + 残差 + 归一化」**。
- **第二步，看 FFN 子层**：$\boldsymbol{a}$ 先过 FFN（特征维变换），输出与 $\boldsymbol{a}$ 相加，再过 LayerNorm——**「变换 + 残差 + 归一化」**。
- **第三步，读结构**：**两个子层的骨架完全相同**（「操作 + 残差 + 归一化」），只是「操作」不同（MHA vs FFN）。**「残差 + 归一化」的复用，是 Transformer 块可堆叠深度的保证**——与 ResNet 的「残差 + 批量归一化」同构。<span class="marginnote">「残差 + 归一化」的组合是 Transformer 的「可训练性保险」：残差让梯度沿「恒等捷径」直达任意层（ResNet 的思想），LayerNorm 稳定每层输入分布——两个机制叠加，让「深层 Transformer（上百层）」可训练。对比 RNN 的「时间维残差缺失」：「Transformer 的深度可堆叠」很大程度归功于这对「保险」。</span>

## 5 位置编码与整体设计哲学

**位置编码（positional encoding）**：注意力本身「置换不变」（不知道顺序），必须把位置信息注入——第六篇《位置编码》专门讲。这里先立住「为什么需要」：**「注意力管『取用什么』，位置编码管『提醒在哪』」**。

**Transformer 的设计哲学总结**：

1. **注意力负责「位置间交互」**（动态、全连接、并行）。
2. **FFN 负责「位置内变换」**（逐位置、非线性、记忆）。
3. **残差 + 归一化负责「可训练性」**（梯度流 + 稳定分布）。
4. **位置编码负责「顺序信息」**（补注意力的置换不变）。

**「四个职责、各司其职」**——理解了这个分工，Transformer 的任何变体（BERT、GPT、ViT）都只是「调整这四部分的组合方式」。<span class="marginnote">「设计哲学的普适性」：Transformer 的「注意力 + 前馈 + 残差 + 归一化」四件套，在视觉（ViT：图像分块当序列）、语音（Whisper）、多模态（CLIP）里原样复用——「把任意结构的数据切成 token 序列，用 Transformer 处理」成了现代 AI 的「万金油」。这个「序列化一切 + 注意力处理」的范式，是「Transformer 为何统治现代 AI」的根本原因。</span>

## 6 小结

- **Transformer** = 编码器-解码器骨架，每个块由「多头注意力 + 前馈 + 残差 + 归一化」组成。
- **编码器块**：自注意力 + FFN——双向理解输入。
- **解码器块**：掩码自注意力 + 交叉注意力 + FFN——自回归生成 + 取用编码器。
- **FFN** 逐位置变换（记忆），**注意力** 跨位置交互（取用）——分工明确。
- **残差 + 归一化**保证深层可训练（Pre-LN/Post-LN 位置之争后续讲）。
- 四件套（注意力/FFN/残差+归一化/位置编码）的职责清晰——一切 Transformer 变体的母版。
