## 为什么从束搜索开始

Seq2Seq 的推断目标是「找到整句概率最大的目标序列」——但「整句最优」是**组合搜索问题**：词表 $V$、句长 $m$，候选空间是 $V^m$（指数爆炸）。贪心只保留 1 条轨迹（太快但短视），穷举搜索保留全部（最优但不可行）。**束搜索（beam search）**站在中间：每步保留 $k$ 条**最优候选轨迹**（$k$ 为束宽），既比贪心「看得全」，又比穷举「算得起」。

束搜索是「解码时最有用的算法」：翻译、摘要、语音识别——几乎所有 Seq2Seq 系统的推断都靠它。它的思想（「并行保留多条最优路径」）也超出了深度学习：是「启发式搜索」在「概率生成」里的标准应用。本节把束搜索的算法流程、束宽的含义、长度归一化等细节讲透。<span class="marginnote">束搜索与经典的搜索算法（第三级《算法》）同源：它本质上是「宽度优先 + 剪枝」——每层只保留 $k$ 个「最有希望」的节点。与「维特比算法」的区别：维特比是「精确」的动态规划（适用于 HMM 等有结构的问题），束搜索是「近似」的贪心剪枝（适用于「无结构的神经网络打分」）。「精确不可行时用近似剪枝」，是解码问题的通用智慧。</span>

## 1 从贪心到束搜索：中间地带

先看两个极端：

**贪心解码（beam size = 1）**：每步只保留 1 个最佳词。快、确定，但「一步错、步步错」——局部最优不是全局最优。

**穷举搜索（beam size = ∞）**：保留所有候选。最优，但 $V^m$ 指数爆炸，不可行。

**束搜索（beam size = $k$）**：每步保留 $k$ 个最佳候选。**「用 $k$ 条轨迹并行探索，最后挑整句最好的」**。

**直觉**：束宽 $k$ 是「同时探索几条路」的度量——$k=1$ 是贪心（一条路走到黑），$k$ 越大越接近最优但越贵。**「束宽是『探索深度』与『计算成本』的旋钮」**。<span class="marginnote">「束搜索能救贪心的错」的经典例子：贪心每步选「概率最大的词」，可能在第 2 步就锁死一条「看似最优、实则跑偏」的轨迹；束搜索在第 2 步保留「第 1 和第 2 可能的两个词」，让「概率略低但方向正确」的候选也有机会。实践中束宽 5–10 就能大幅超过贪心——「几条路比一条路好，很多条路不如几条路」。</span>

**易错点：** 束搜索**不是**「每步采样多个词」的随机——它是**确定性**的「保留 top-$k$」。随机采样与束搜索是两种不同的解码哲学：前者靠「概率抽样的多样性」，后者靠「系统搜索的最优性」——**「生成要多样用采样，生成要最优用束搜索」**。

## 2 束搜索的算法流程

**束搜索**的逐步算法：

1. **初始化**：候选集 $\mathcal{B}_0 = \{\emptyset\}$（空序列），长度为 1。
2. **扩展**：对候选集里每个序列，计算「接上每个词」后的整句对数概率，得到 $k\times V$ 个新候选。
3. **剪枝**：从 $k\times V$ 个候选中保留**对数概率最高的 $k$ 个**，作为新候选集 $\mathcal{B}_t$。
4. **终止**：重复直到「所有 $k$ 条候选都出现 $\langle\text{eos}\rangle$」或达到最大长度。
5. **选择**：从完成的候选中，选「（长度归一化的）整句对数概率最高」的。

**每步的「扩展 + 剪枝」**：第 $t$ 步从 $k$ 条候选「生」出 $k\times V$ 条，再「剪」回 $k$ 条——**「每步维持 $k$ 条，但探索了 $k\times V$ 的空间」**。

**对数概率的使用**：用对数概率（而非概率）累乘，避免「很多个 <1 的数相乘下溢」——$\log P(\text{整句}) = \sum_t \log P(w_t \mid \text{前缀})$。<span class="marginnote">「对数化」是束搜索的数值细节：概率连乘在长句下会指数下溢到 0（float 表示不了 $10^{-100}$），取对数后「乘法变加法」，数值稳定。这与语言模型损失用「负对数似然」是同一动机——「一切概率计算，能对数就对数」是深度学习的通用纪律。</span>

**易错点：** 束搜索的「剪枝」是**启发式**的——它不能保证找到全局最优（剪掉的候选里可能藏着最优解）。但实践上「束宽 5–10 的近似解」已经足够好——**「近似但不差」是束搜索的定位**。

## 3 公式解析：束搜索的剪枝准则

把束搜索的「保留准则」写成数学。第 $t$ 步，候选序列 $\boldsymbol{y}_{1:t}$ 的分数是「前缀的对数概率之和」：

$$
\text{score}(\boldsymbol{y}_{1:t}) = \sum_{j=1}^{t} \log P(y_j \mid \boldsymbol{y}_{<j}, \boldsymbol{x})
$$

剪枝保留「分数最高的 $k$ 条」：

$$
\mathcal{B}_t = \arg\max_{k} \{\text{score}(\boldsymbol{y}_{1:t}) : \boldsymbol{y}_{1:t} \text{ 从 } \mathcal{B}_{t-1} \text{ 扩展} \}
$$

- **第一步，看分数**：整句分数 = 前缀逐词对数概率之和——**分数越高，模型认为这句越「好」**。
- **第二步，看剪枝**：每步从「$k$ 条候选 × $V$ 个词」里取「分数最高的 $k$ 条」——**「扩展全部、保留最优」**。
- **第三步，看长度偏置**：直接比「分数之和」会让**短句占便宜**（项少、累计分数不一定小但「平均」容易被高估），所以最终比较常做长度归一化：$\frac{1}{t}\text{score}(\boldsymbol{y}_{1:t})$——**「长度惩罚」纠正短句偏置**。<span class="marginnote">「长度归一化」的必要性：假设每个词的对数概率平均为 $-1$，两句「5 个词」与「10 个词」的分数分别是 $-5$ 与 $-10$——模型会倾向「短句」（$-5 > -10$），即使长句语义更完整。除以长度后，两者都是 $-1$，公平比较。现代解码里的「length_penalty」参数（如 GPT 的 `lenpen`）就是它——「要不要鼓励长输出」由任务决定（摘要要短，翻译要准）。</span>

**易错点：** 长度归一化的「幂」$\alpha$ 是超参数：$\frac{1}{t^\alpha}\text{score}$。$\alpha=0$ 不归一化（倾向短句），$\alpha=1$ 完全归一化（长度中立），$\alpha>1$ 反而倾向长句。**「长度惩罚的强度」由任务与验证集决定**。

## 4 束搜索的变体与采样对比

束搜索有一些实用变体：

**分组束搜索（group beam search）**：把候选分成 $g$ 组，每组内做束搜索——用于「生成多样化的多条结果」（如「给一个问题的多种答案」）。它缓解「束搜索输出的前几个词总是一样」的问题（束搜索倾向「同质化」——$k$ 条候选常常只在结尾不同）。

**对比束搜索（contrastive search）**：在「与已生成词的相似度」与「概率」之间权衡——缓解「束搜索的重复问题」（$k$ 条轨迹经常生成「同一句话的重复」）。

**束搜索 vs 随机采样**：

| | 束搜索 | 随机采样（含温度/top-p） |
| --- | --- | --- |
| 目标 | 整句最优 | 多样生成 |
| 确定性 | 确定（可复现） | 随机（每次不同） |
| 适用 | 翻译、摘要（一个正确解） | 对话、故事（多个合理解） |
| 风险 | 同质化、重复 | 不稳、可能胡扯 |

**「找『正确答案』用束搜索，找『多种可能』用采样」**——这是解码策略的第一原则。<span class="marginnote">「束搜索的重复问题」在长生成里尤其明显：因为束搜索总选「概率最高」的路径，而「重复自己刚写的词」在语言模型里概率往往很高（自回归的惯性），导致「死循环式重复」。现代 LLM 用「重复惩罚（repetition penalty）」「no_repeat_ngram_size」等约束来治它——「搜索最优 ≠ 生成最好」，这是解码工程反复遇到的教训。</span>

## 5 束搜索在 Seq2Seq 与 LLM 中的定位

束搜索是 Seq2Seq 推断的**标准组件**（翻译、摘要），在现代 LLM（GPT 系列）里的角色则「微妙」：

- **翻译/摘要类任务**：束搜索仍是首选（一个正确答案）。
- **开放式生成（对话、写作）**：采样（温度 + top-p）更合适——束搜索的「最优」在这里反而「呆板」。
- **LLM 的解码**：ChatGPT 等提供「温度 + top-p + 频率惩罚」等采样参数，束搜索在「确定性任务」（如代码生成、数学解题）里仍有用。

**「束搜索不退休，只是『择任务而用』」**——「搜索 vs 采样」的选择，取决于「任务要一个正确答案，还是多个合理答案」。<span class="marginnote">「GPT 用采样而不用束搜索」的深层原因：束搜索的「整句概率最大」倾向「平庸而安全的文本」（概率最大的文本往往是「最平均」的），而采样能探索「更出彩但概率略低」的表达。生成模型「要最优还是要有趣」，是解码哲学里永恒的张力——理解它，你就理解了「为什么同一个模型，改个解码参数就像换了个人」。</span>

## 6 小结

- **束搜索**：每步保留 $k$ 条最优候选，「扩展全部、剪枝保留」——贪心与穷举的折中。
- 束宽 $k$：探索深度的旋钮；$k=1$ 是贪心，$k=5$–10 是实践甜点。
- 分数 = 逐词对数概率之和（对数化防下溢）；剪枝保留分数最高的 $k$ 条。
- **长度归一化**：$\frac{1}{t^\alpha}\text{score}$ 纠正短句偏置——「长度惩罚」强度是超参数。
- 束搜索确定性、偏最优，但同质化/重复；采样多样、偏创意。
- 选型：翻译/摘要用束搜索，对话/写作用采样；「要一个正确答案还是要多种可能」。
