## 为什么从信息论开始

上一节我们用最大似然推出了交叉熵损失，但这只是故事的入口。信息论给出了交叉熵的**另一重出身**：熵回答「一个随机事件携带多少比特的不确定性」，KL 散度回答「两个分布之间有多远」。这两把尺子直接量出了深度学习最常用的损失函数，也量出了「模型的概率估计准不准」。<span class="marginnote">香农在 1948 年用数学回答了「信息是什么」——信息不是语义（一句话的意思），而是「消除不确定性的多少」。这与深度学习里的「表征」哲学暗合：一个好模型在压缩信息、保留对预测有用的那部分。</span>

这一节对标花书 §3.13 的信息论部分，以及 §5.5 里交叉熵的出场。我们在第一级《信息论》与第二级《信息论与数理统计》已经见过熵的雏形，这一节从深度学习的视角把它重新组装成三件工具：**自信息与熵**、**交叉熵**、**KL 散度**，最后用一个公式解析把它们与最大似然缝在一起。

## 1 自信息与熵：不确定性有多少比特

先说单个事件。若事件 $x$ 发生的概率是 $P(x)$，它的**自信息（self-information）**定义为

$$
I(x) = -\log P(x)
$$

对数的底取 2，单位是**比特（bit）**；取自然对数，单位是奈特（nat）。直觉：**越不可能的事件，发生后带来的信息越多**。「太阳从东边升起」（概率接近 1）几乎不带来信息；「下一枚硬币是正面」有一比特；「摇出六合彩头奖号码」信息量巨大。<span class="marginnote">自信息的单调性来自「极小概率事件 = 极大惊讶」：$P(x)$ 越小，$-\log P(x)$ 越大。对数还带来了可加性：两个独立事件同时发生的自信息等于各自自信息之和，因为 $-\log(P(x)P(y)) = -\log P(x) - \log P(y)$——这与我们直觉里「信息的叠加」一致。</span>

把分布里所有事件的期望自信息平均起来，就是**熵（entropy）**：

$$
H(P) = \mathbb{E}_{x \sim P}\big[-\log P(x)\big] = -\sum_{x} P(x)\log P(x)
$$

**熵是「平均不确定性的量」**。一个分布越平坦，熵越大；越尖峭，熵越小。二值随机变量（伯努利）的熵最直观：

$$
H(P) = -p\log p - (1-p)\log(1-p)
$$

$p=0.5$ 时熵最大，等于 1 比特——「最不知道结果」；$p$ 逼近 0 或 1 时熵趋近 0——「几乎确定了」。**熵在均匀分布处取最大**，这是「最大熵原理」的先声：在约束下，熵最大的分布是最不武断的分布。

对连续随机变量，把求和换成积分得到**微分熵（differential entropy）** $H(P) = -\int p(x)\log p(x)\,dx$。它在固定方差的所有连续分布里于高斯处取最大值——这就是上一节《常见分布》里「高斯是默认分布」的信息论背书。

## 2 交叉熵与 KL 散度：两个分布有多远

熵衡量**一个**分布的确定性。当有两个分布——真实的 $P$ 与模型估计的 $Q$——我们想要一把「尺子」量它们差多远。**KL 散度（Kullback–Leibler divergence）** 就是这把尺子：

$$
\mathrm{KL}(P \| Q) = \mathbb{E}_{x \sim P}\left[\log \frac{P(x)}{Q(x)}\right] = \sum_{x} P(x)\log \frac{P(x)}{Q(x)}
$$

它读作「从 $P$ 到 $Q$ 的 KL 散度」，量的是**用 $Q$ 去近似 $P$ 时损失的信息量**。两条核心性质：

- **非负性**：$\mathrm{KL}(P \| Q) \ge 0$，且等号成立当且仅当 $P = Q$。它像「距离」，但**不是对称的**：$\mathrm{KL}(P\|Q) \neq \mathrm{KL}(Q\|P)$ 一般不成立，所以它叫「散度」而不叫「距离」。
- **可分解性**：把对数拆开，KL 恰好等于**交叉熵减熵**：

$$
\mathrm{KL}(P \| Q) = -\sum_{x} P(x)\log Q(x) - \big(-\sum_{x} P(x)\log P(x)\big)
= H(P, Q) - H(P)
$$

其中 **交叉熵（cross-entropy）** 定义为

$$
H(P, Q) = -\sum_{x} P(x)\log Q(x)
$$

直观记法：**交叉熵 = 熵 + KL 散度**。因为 $H(P)$ 只依赖真实分布 $P$、与模型 $Q$ 无关，所以在优化 $Q$ 时，最小化 $H(P,Q)$ 与最小化 $\mathrm{KL}(P\|Q)$ 是**同一件事**——这就是为什么深度学习里「交叉熵损失」和「KL 散度损失」常常被混着说。<span class="marginnote">KL 不对称的直觉：$\mathrm{KL}(P\|Q)$ 在 $Q$ 的支撑比 $P$ 小（$Q$ 在 $P$ 有质量处为零）时会爆炸到无穷大——「用 $Q$ 描述 $P$」若 $Q$ 干脆把 $P$ 的可能结果判为不可能，代价无穷大。这提醒我们：交叉熵惩罚「模型对不可能事件给出高置信概率」，也就是惩罚过度自信。</span>

**辨析｜易错点：交叉熵不满足三角不等式，KL 也不是度量。** 两者都非对称，且都不能当「距离」用在几何直觉里。另外注意记号方向：$H(P,Q)$ 是「用分布 $Q$ 编码来自 $P$ 的样本」的平均码长，$P$ 在「真实」位、$Q$ 在「编码」位，次序不能调换。

## 3 信息论在深度学习中的面孔

信息论的三件工具在深度学习里几乎无处不在：

**分类损失 = 交叉熵**。上一节已推导：多分类 `softmax` 输出的交叉熵损失 $-\sum_i \sum_k y_{ik}\log \hat{y}_{ik}$，正是「真实标签分布」与「模型预测分布」的交叉熵。因为真实标签是 one-hot，交叉熵退化为「对正确类别的预测概率取负对数」——让正确类别的概率越大越好。
**最大似然 = 最小化 KL**。把真实数据分布记作 $p_{\text{data}}$，模型分布记作 $p_{\theta}$。最大似然估计 $\arg\max_\theta \sum \log p_\theta(x^{(i)})$ 在期望意义下等价于最小化 $\mathrm{KL}(p_{\text{data}} \| p_{\theta})$。上一节用「负对数似然」推导，这一节用「KL 散度」推导，**两条路在同一个结论会合**——这也印证了频率派与信息论本是同源的两种语言。
**互信息（mutual information）**：$I(X;Y) = H(X) - H(X\mid Y) = \mathrm{KL}\big(P(X,Y)\,\|\,P(X)P(Y)\big)$，量「知道 $Y$ 让 $X$ 的不确定性减少多少」。它在表示学习、对比学习（第三篇 SimCLR、MoCo 的思想源头）里反复出现：好的表征应当与任务标签有高互信息。
**熵正则与策略熵**：强化学习里常用熵作为「探索程度」的奖励；模型蒸馏用 KL 散度让「学生」分布逼近「教师」分布。

```python
import numpy as np

def cross_entropy(p, q):
    q = np.clip(q, 1e-12, 1.0)     # 防 log(0)：把下界夹到 1e-12
    return -np.sum(p * np.log(q))

# one-hot 真实标签：正确类别在第 0 位
# 自信预测：正确类别概率 0.9 → 损失 ≈ 0.105
print(cross_entropy([1, 0, 0], [0.9, 0.05, 0.05]))   # 0.105
# 预测错误：正确类别只拿到 0.05 → 损失 ≈ 2.996 ≈ 3
print(cross_entropy([1, 0, 0], [0.05, 0.5, 0.45]))    # 2.996
```

预测错的样本损失接近 3，比自信预测高出一个量级——**交叉熵惩罚「把高概率押在错误类别上」**。<span class="marginnote">$\log 0 = -\infty$ 到 $10^{-12}$ 这一行是数值安全的必需品：$Q$ 出现 0 概率时 $\log 0 = -\infty$，交叉熵爆炸。这与第四篇《数值计算：上溢、下溢与病态条件》里的防溢出思路同源——先把对数函数的输入挡在安全区外。</span>

## 4 公式解析：为什么 KL 散度不小于零

KL 散度的非负性（Gibbs 不等式）是整套理论的地基——「用 $Q$ 近似 $P$ 至少不赚，最多持平」。它的证明非常轻巧，值得走一遍：

$$
\mathrm{KL}(P \| Q) = \sum_{x} P(x)\log \frac{P(x)}{Q(x)} \;\ge\; 0
$$

- **第一步，把对数换成「减」**。利用对所有 $t>0$ 成立的不等式 $\log t \le t - 1$（对数曲线在 $t-1$ 这条切线下方，$t=1$ 处相切）。取 $t = \frac{Q(x)}{P(x)}$，得
  $$
  -\log\frac{Q(x)}{P(x)} = \log\frac{P(x)}{Q(x)} \;\ge\; 1 - \frac{Q(x)}{P(x)}
  $$
- **第二步，对 $P$ 加权求和**。两边同乘 $P(x) \ge 0$ 再对所有 $x$ 求和：
  $$
  \sum_x P(x)\log\frac{P(x)}{Q(x)} \;\ge\; \sum_x P(x)\Big(1 - \frac{Q(x)}{P(x)}\Big) = \sum_x P(x) - \sum_x Q(x)
  $$
- **第三步，用归一化收尾**。$\sum_x P(x) = 1$ 且 $\sum_x Q(x) = 1$（两个都是合法分布），所以右边等于 $1 - 1 = 0$。于是 $\mathrm{KL}(P\|Q) \ge 0$。
- **第四步，看清等号何时取**。$\log t = t-1$ 只在 $t=1$ 处成立，即 $P(x) = Q(x)$ 对所有 $x$ 成立。**KL 为零，当且仅当两个分布完全相同**。

这个证明只用了一个对数不等式和两条归一化条件，却给出「散度 ≥ 0」这种全局性的结论——这正是概率论里「信息」与「度量」交织的优美之处。它也是「交叉熵 ≥ 熵」的直接推论，解释了为什么用错误分布编码总会多花一些比特。

## 5 小结

- **自信息** $I(x) = -\log P(x)$ 量单事件的「惊讶度」；**熵** $H(P) = -\sum P(x)\log P(x)$ 是平均自信息，量一个分布的平均不确定性，在均匀分布处最大。
- **交叉熵** $H(P,Q) = -\sum P(x)\log Q(x)$ 量「用 $Q$ 编码来自 $P$ 的样本」的平均码长；**KL 散度** $\mathrm{KL}(P\|Q) = H(P,Q) - H(P)$ 量「$P$ 与 $Q$ 的差」，非负且不对称。
- **三者的关系**：交叉熵 = 熵 + KL 散度；优化 $Q$ 时最小化交叉熵等价于最小化 KL 散度。
- **与最大似然同源**：MLE 在期望意义上等价于最小化 $\mathrm{KL}(p_{\text{data}}\|p_\theta)$——两条推导路径殊途同归。
- **在深度学习里**：分类交叉熵损失、表示学习的互信息、强化学习的熵正则，都是三件工具的直接应用。
- **易错**：KL 非对称、非度量；交叉熵的次序不能调换；实现里要防 $\log 0$（clip）。
