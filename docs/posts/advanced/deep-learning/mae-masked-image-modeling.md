## 为什么从掩码自编码器开始

对比学习用「增强 + 对比」学视觉表示，但它的「负样本 + 大 batch」工程复杂。**掩码自编码器（Masked Autoencoder, MAE）**（He 等, 2022）走了一条「更简单、更像 BERT」的路：**把图像的 75% 块遮住，让模型从剩下的 25% 重建整幅图像**。MAE 用「掩码重建」这个极简任务，达到了对比学习的效果，甚至更好——它证明了「**掩码重建」在视觉里同样强大**（BERT 的 MLM 在 NLP 里的成功，被「翻译」到了视觉）。

MAE 的成功不只是「又一个自监督方法」——它揭示了三件事：**高掩码率（75%）是「关键配方」**（逼模型学「语义」而非「像素」）、**非对称编码器-解码器**（编码器只看可见块、解码器重建全图，效率极高）、以及「**重建式自监督在视觉里的复兴**」（对比学习之后，「掩码重建」成为视觉预训练的新主流）。本节把 MAE 的架构、掩码率的作用、与 BERT/对比学习的对比讲透。<span class="marginnote">「MAE 的『翻译』逻辑」：BERT 用「掩码 token + 双向 Transformer」学文本表示；MAE 用「掩码图像块 + Transformer」学视觉表示——「<strong>把 NLP 的 MLM 范式『翻译』到视觉</strong>」。但图像与文本有一个关键差异：图像「高度冗余」（相邻像素相似、空间结构强），所以「掩码率可以极高」（75%，而文本是 15%）——「<strong>视觉的高冗余 = 高掩码率的可行性</strong>」，这是 MAE 的核心洞察。</span>

## 1 MAE 的架构：非对称的编码器-解码器

**MAE 的流程**：

1. **分块**：图像切成 $16\times16$ 的块（patch）。
2. **掩码**：随机遮住 75% 的块（只留 25% 可见）。
3. **编码器**：只看**可见块**，经 ViT 编码（省 75% 计算！）。
4. **解码器**：把编码结果 + 掩码位置的占位符，重建完整图像（预测每个像素）。
5. **损失**：只对被掩码的位置算「重建误差」（MSE）。

**非对称设计**：

**编码器**：只处理「可见块」——**计算量只有「全图」的 25%**（效率关键）。
**解码器**：轻量（小 ViT），处理「编码结果 + 掩码标记」重建全图——**只在训练时存在**（推理时丢弃）。

**「编码器只算可见块、解码器重建全图」**——这个「非对称」让 MAE 训练极其高效（对比「全图编码」省 75% 算力）。<span class="marginnote">「为什么编码器只看可见块」：如果编码器处理「全图」（含掩码占位符），计算量是全图的——MAE 的「只看可见块」让「编码器计算量 ∝ 可见率（25%）」——「<strong>掩码不仅是『学习信号』，也是『计算加速』</strong>」。这个「少算 = 快训练」的设计，让 MAE 的训练速度比「全图方法」快 3–4 倍。</span>

**易错点：** 掩码位置的信息（「哪块被遮」）要「显式」告诉解码器——MAE 用「位置编码 + 掩码标记」让解码器知道「掩码块在哪」。**「解码器需要『掩码的位置信息』才能重建」**——「知道缺什么、在哪缺」是重建的前提。

## 2 掩码率：为什么 75% 是「甜点」

MAE 论文最反直觉的发现：**掩码率 75% 效果最好**（远高于 BERT 的 15%）。

**为什么视觉可以「掩 75%」？** 图像的**空间冗余度极高**：相邻像素、相邻块高度相似。即使掩掉 75%，剩下的 25% 仍包含「足够信息」去推断全局结构（物体轮廓、背景）。

**为什么「高掩码率」反而更好？** 两个原因：

1. **逼学「语义」而非「像素」**：掩码率低时，模型可以「靠相邻像素插值」重建（学像素级冗余，不学语义）；掩码率高时，「插值」不可能，必须学「物体的语义结构」（知道「这是猫，所以这里该有耳朵」）。
2. **任务难度合适**：掩码率太低 → 任务太易（学不到东西）；太高（如 95%）→ 任务太难（学不动）。75% 是「难到逼出语义、又不至于学不动」的甜点。

**「高掩码率 = 把『像素级捷径』堵死，逼模型走『语义路径』」**——这是 MAE 的核心洞察。<span class="marginnote">「图像 vs 文本的掩码率差异」：文本 15%（语义密度高，掩太多信息不足）、图像 75%（视觉冗余高，掩 75% 仍够）——「<strong>掩码率 = 数据冗余度的镜像</strong>」。「数据越冗余，能掩的越多」——这个「冗余度 → 掩码率」的关系，是「掩码重建」任务设计的通用规律。</span>

**易错点：** 高掩码率只在「重建式任务」里好——如果任务是「对比」或「判别」，掩码率的意义不同。**「掩码率与任务类型绑定」**——MAE 的 75% 是「重建式 + 图像」的结论，别乱迁移。

## 3 MAE vs BERT vs 对比学习

把 MAE 放进「自监督光谱」里对比：

| | MAE | BERT（MLM） | SimCLR（对比） |
| --- | --- | --- | --- |
| 任务 | 掩码块重建 | 掩码 token 预测 | 增强视图对比 |
| 掩码率 | 75% | 15% | 无掩码 |
| 编码器 | 只看可见块 | 处理全序列 | 处理全图 |
| 负样本 | 无 | 无 | 需要（大量） |
| 损失 | 重建 MSE | 交叉熵 | InfoNCE |
| 计算效率 | 高（只算可见） | 中 | 低（全图 ×2 视图） |

**「MAE 的『简洁』」**：没有负样本、没有对比、没有动量编码器——**「一个掩码 + 一个重建损失」就是全部**。它比对比学习「简单一个数量级」，效果却不输——「<strong>简单到极致，就是深刻</strong>」（再次印证「简单 × 规模」）。

**MAE 相对对比学习的优势**：

1. **无负样本**：不用「大 batch / 队列」——显存友好、实现简单。
2. **高效编码**：只算可见块——训练快。
3. **语义重建**：高掩码率逼「语义理解」。

**「MAE 证明了『重建式自监督在视觉里同样强大』」**——对比学习之后，掩码重建成为视觉预训练的新主流。<span class="marginnote">「MAE 与对比学习的『分工』」：MAE 学「重建语义」（物体是什么、结构怎样），对比学习学「不变性」（什么像什么）——两者是「不同侧面」的表示。「<strong>最佳实践常常是「混合」：先 MAE 预训练（语义重建）、再对比微调（判别细调）</strong>」——「不同自监督任务互补」是「表示学习」的现代共识（见《自监督学习》的「三大家族」）。</span>

**易错点：** MAE 的「重建」是「像素级 MSE」——它可能「平均」出模糊的图像（像 VAE 一样）。但 MAE 的目的不是「生成」，而是「学表示」——「<strong>重建是手段（学表示），不是目的（生成）</strong>」。模糊的「重建结果」不影响「表示质量」。

## 4 公式解析：MAE 的损失与「语义」

把 MAE 的「重建损失」写清楚。设可见块 $\boldsymbol{x}_v$（25%）、掩码块 $\boldsymbol{x}_m$（75%），编码器 $f_\theta$、解码器 $g_\phi$：

$$
\hat{\boldsymbol{x}}_m = g_\phi\big(f_\theta(\boldsymbol{x}_v), \text{mask tokens}\big)
$$

损失（只对掩码块算）：

$$
L = \frac{1}{|\mathcal{M}|}\sum_{i\in\mathcal{M}} \big\|\boldsymbol{x}_m^{(i)} - \hat{\boldsymbol{x}}_m^{(i)}\big\|^2
$$

- **第一步，看「非对称」**：编码器只输入 $\boldsymbol{x}_v$（可见块），解码器用「编码结果 + 掩码标记」重建 $\boldsymbol{x}_m$——「编码器看少、解码器猜多」。
- **第二步，看损失范围**：只对被掩码的块算 MSE（可见块不需要重建）——「只监督『猜』的部分」。
- **第三步，读语义**：要「猜对被掩的块」，模型必须知道「这是什么物体」（猫 → 这里该有耳朵）——**「重建掩码 = 逼出语义知识」**。<span class="marginnote">「MAE 的『任务难度』分层」：不同掩码模式对应不同难度——掩「主体」难（要懂整体语义）、掩「背景」易（纹理插值）——「<strong>随机掩码 = 混合难度，让模型兼顾『语义』与『纹理』</strong>」。这个「难度混合」让表示「既懂语义、又懂细节」——「全难或全易都不好，混合最优」。</span>

## 5 MAE 的现代影响与变体

MAE 开启了「掩码图像建模（MIM）」的视觉预训练浪潮：

**BEiT / SimMIM**：掩码重建的早期探索（在 MAE 前后）。
**VideoMAE**：把掩码重建用于视频（掩掉时空块）。
**多模态 MAE**：掩码重建用于「图文」与「音频」。
**与扩散结合**：把「掩码重建」升级为「去噪重建」（视觉自监督的生成式路线）。

**「MAE 的遗产：『掩码重建』成为跨模态的自监督通用范式」**——从 BERT（文本）到 MAE（图像）到 VideoMAE（视频），「掩码 + 重建」的统一框架贯穿所有模态。「<strong>掩码重建是自监督的『万金油』</strong>」——它是「预训练时代」最通用的表示学习配方之一。<span class="marginnote">「掩码重建 vs 语言模型 vs 对比」的终极统一：语言模型是「因果掩码 + 重建」（预测下一个），MLM 是「双向掩码 + 重建」，MAE 是「高比率掩码 + 重建」，对比是「增强 + 判别」——「<strong>所有主流自监督都可以被理解为『某种破坏 + 某种恢复』或『某种对比』</strong>」。「破坏-恢复」（重建式）与「相似-差异」（对比式）是自监督的两大母题——理解了这两个母题，就理解了「现代预训练的一切」。</span>

**易错点：** MAE 的「编码器」在「下游任务」里要「保留」（作为骨干网络），「解码器」要「丢弃」——**「预训练的解码器只在预训练时用，微调时扔掉」**（与 BERT 的任务头同理）。「预训练与微调的结构不对称」是预训练范式的常态。

## 6 小结

- **MAE**：掩掉 75% 图像块，从可见块重建全图——「掩码重建」学视觉表示。
- **高掩码率（75%）**：堵死「像素插值捷径」，逼模型学「语义结构」——「冗余度决定掩码率」。
- **非对称架构**：编码器只看可见块（省 75% 算力）、解码器重建全图（训练时才用）。
- 损失：只对掩码块算 MSE——「重建掩码 = 逼出语义」。
- 对比 BERT（15% 掩码、文本）与对比学习（无掩码、需负样本）——MAE「简单 + 高效」。
- 遗产：掩码重建成为跨模态自监督的通用范式——「破坏-恢复」是自监督两大母题之一。
