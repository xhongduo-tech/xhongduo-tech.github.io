## 为什么从 Swin Transformer 开始

ViT 证明「纯注意力」能打平甚至超过 CNN，但它有两个硬伤：**$O(n^2)$ 的计算随分辨率爆炸**（高分辨率图像扛不住），以及**缺乏层级结构**（没有「由粗到精」的多尺度特征，这对检测、分割任务至关重要）。**Swin Transformer**（Liu 等, 2021）用两个关键设计解决它们：**窗口注意力**（只在局部窗口内做注意力，计算量线性化）与**移位窗口**（窗口之间交替移位，实现「跨窗口信息交流」）。Swin 还引入了**层级金字塔结构**（像 CNN 一样逐级下采样），成为检测、分割任务的首选视觉骨干。

Swin 的「窗口 + 移位」设计，是「局部高效 + 全局交流」的典范——它把注意力的「全局性」用「局部窗口 + 跨窗口移位」近似，在保持表达力的同时把复杂度从 $O(n^2)$ 降到 $O(n)$。本节把「窗口注意力」「移位窗口」「层级金字塔」讲透——它是「ViT 的工程化改良」，也是「现代视觉骨干」的代表。<span class="marginnote">「Swin 的名字」：Swin = Shifted Window——「移位窗口」。它来自「层级视觉 Transformer」的追求：<strong>既要 Transformer 的「动态注意力」，又要 CNN 的「层级多尺度」与「高效局部性」</strong>。「<strong>Swin = Transformer 与 CNN 的『联姻』</strong>」——它在 ImageNet 上刷新纪录，也成为检测/分割骨干（Mask R-CNN 的 Swin 版本称霸检测榜单）。</span>

## 1 窗口注意力：把全局切成局部

**窗口注意力（window attention）**：不在一整幅图上做注意力，而是**把特征图切成不重叠的窗口**（如 $7\times7$），**只在每个窗口内**做自注意力。

**计算复杂度**：设特征图 $h\times w$，窗口大小 $M\times M$。全局注意力的复杂度 $O(h^2w^2)$；窗口注意力的复杂度是「窗口数 × 每个窗口内的注意力」：

$$
O\Big(\frac{hw}{M^2} \times M^4\Big) = O(hw\, M^2)
$$

**「$O(n^2)$ → $O(n)$」**：复杂度从「随特征图平方」降到「随特征图线性」（$M$ 是常数）——**窗口注意力让高分辨率成为可能**。<span class="marginnote">「窗口大小的『局部性』」：窗口注意力等价于「把全局注意力『截断』成局部」——每个块只看「窗口内」的块（对比 ViT 的「看全图」）。<strong>「窗口 = 可调的感受野」</strong>：窗口越大越接近全局（但越贵），窗口越小越局部（但便宜）——「<strong>窗口大小是『全局性 vs 效率』的旋钮</strong>」。Swin 用 $7\times7$ 窗口在「效率」与「表达力」间取平衡。</span>

**易错点：** 窗口注意力**牺牲了跨窗口的信息交流**——「窗口 A 的块看不到窗口 B 的块」——如果只有窗口注意力，模型「局部近视」。**「跨窗口交流」需要额外机制**——这正是「移位窗口」的用途。

## 2 移位窗口：让信息「流动」起来

**移位窗口（shifted window）**：交替地「窗口偏移半个窗口大小」——让相邻两层的窗口**错位**，从而「跨窗口」的块在下一层「落入同一个窗口」。

**两层交替**：

- **层 1**：普通窗口（从 (0,0) 开始切）。
- **层 2**：移位窗口（从 $(\lfloor M/2\rfloor, \lfloor M/2\rfloor)$ 开始切）——**窗口边界移动，原窗口边界的块现在与「隔壁窗口」的块同窗**。

**效果**：经过「普通窗口 → 移位窗口」的交替，每个块既能「看本窗口」，又能「经由移位」与「相邻窗口」交流——**「移位窗口实现了『跨窗口信息流动』」**。

**「窗口 + 移位 = 局部高效 + 全局可达」**：不直接做全局注意力（贵），而是用「两层窗口交替」让信息「逐窗口扩散」——**「信息的『全局化』通过『局部交流的迭代』实现」**。<span class="marginnote">「移位窗口的『信息扩散』直觉」：一层窗口让「相邻块交流」，移位后「窗口边界」的块与「新的邻居」交流——经过多层「窗口 + 移位」，信息从「任意块」逐步「扩散」到「全图」——<strong>「用『局部迭代』近似『全局』」</strong>（这与 CNN 的「逐层扩大感受野」同理，但用「动态注意力」而非「固定卷积」）。</span>

**易错点：** 移位窗口的实现有个「掩码技巧」——移位后「特征图边缘」的窗口「不完整」（块数不足），需要用「循环移位 + 注意力掩码」处理——**「移位窗口的实现复杂度」是 Swin 工程上的难点**（论文用了精巧的「掩码」让不完整窗口也能批量计算）。

## 3 层级金字塔：像 CNN 一样多尺度

**层级结构（hierarchical structure）**：Swin 像 CNN 一样「逐级下采样」——分辨率逐级减半、通道逐级翻倍，形成**特征金字塔**：

```
Stage 1: H/4 × W/4 × C      (4×4 块嵌入后)
Stage 2: H/8 × W/8 × 2C     (下采样)
Stage 3: H/16 × W/16 × 4C
Stage 4: H/32 × W/32 × 8C
```

每个 Stage 由「窗口注意力块」堆叠，Stage 之间用「下采样」（patch merging，把 $2\times2$ 块拼成一个、通道翻倍）。

**为什么层级结构重要？**

1. **多尺度特征**：不同 Stage 提供不同分辨率的特征——检测（大物体看低分辨率特征、小物体看高分辨率）与分割（像素级密集预测）**需要多尺度**。
2. **效率**：高分辨率只在浅层处理（贵但必要），低分辨率在深层（便宜）——**「先细后粗」的计算调度**。
3. **与 CNN 骨干兼容**：层级特征图可以直接替换 ResNet 的骨干——**Swin 成为「即插即用」的现代骨干**。<span class="marginnote">「Swin vs ViT 的『层级』」：ViT 全程「单分辨率」（196 个块、无下采样），Swin「逐级下采样」（多尺度金字塔）——「<strong>ViT 是『平铺』的，Swin 是『金字塔』的</strong>」。多尺度对「检测/分割」至关重要（不同大小物体需要不同分辨率特征）——这是「Swin 在检测/分割上碾压 ViT」的结构性原因。Swin 的层级设计「直接继承了 CNN 的多尺度智慧」。</span>

**易错点：** Swin 的「层级」让「序列长度」逐级缩短——Stage 1 是 $\frac{H}{4}\times\frac{W}{4}$ 个 token、Stage 4 是 $\frac{H}{32}\times\frac{W}{32}$——**「序列长度 = 当前分辨率下的 token 数」**，Stage 越深 token 越少、注意力越便宜。这个「由长到短」的节奏，是 Swin 效率的另一个来源。

## 4 公式解析：窗口注意力的复杂度对比

把「全局 vs 窗口」注意力的复杂度算清楚。特征图 $h\times w$、窗口 $M\times M$：

**全局注意力**：

$$
\text{FLOPs}_{\text{global}} = 4\,h^2w^2\,d + 2\,h^2w^2\,d = O(h^2w^2)
$$

**窗口注意力**（$\frac{hw}{M^2}$ 个窗口，每个窗口内 $M^2$ 个 token）：

$$
\text{FLOPs}_{\text{window}} = \frac{hw}{M^2} \times \underbrace{4M^4d + 2M^4d}_{\text{单个窗口的注意力}} = O(hw\,M^2)
$$

- **第一步，看全局的平方**：$h^2w^2$ 来自「$hw$ 个 token × $hw$ 个 token」的注意力矩阵——**随分辨率平方增长**。
- **第二步，看窗口的线性**：$hw\,M^2$ 来自「$hw$ 个 token × $M^2$ 个窗口内 token」——**随分辨率线性增长**（$M$ 是常数）。
- **第三步，读对比**：$hw=56^2$、$M=7$ 时，窗口注意力是全局的 $\frac{1}{(hw/M^2)} = \frac{1}{64}$——**省约 64 倍**。<span class="marginnote">「线性 vs 平方」的意义：分辨率翻倍时，全局注意力贵 4 倍、窗口注意力贵 2 倍——「<strong>高分辨率任务（检测/分割）必须用窗口注意力</strong>」。这也是「Swin 在检测/分割（高分辨率）上可用、ViT 不可用」的根本原因——「<strong>复杂度的『阶』决定架构的『应用边界』</strong>」。</span>

## 5 Swin 的影响与现代地位

Swin 的影响力：

- **检测/分割骨干**：Swin 成为 Mask R-CNN、Cascade R-CNN 的「即插即用骨干」，在 COCO 检测与 ADE20K 分割上刷新纪录。
- **通用视觉骨干**：Swin 的层级设计成为「现代视觉 Transformer 的范式」（Swin v2、SwinIR 超分辨率等）。
- **与自监督结合**：Swin 作为 MAE、对比学习的骨干——「层级 + 掩码」的组合。

**「Swin 教会我们：『全局注意力』不是唯一选项」**——「局部窗口 + 层级 + 移位」的「工程化 Transformer」，在实际任务（检测/分割/高分辨率）上比「纯全局」更实用——「<strong>好的架构是『理论最优』与『工程可行』的折中</strong>」。<span class="marginnote">「Swin 之后的『视觉骨干』谱系」：ViT（纯全局）→ Swin（窗口 + 层级）→ Swin v2（更深更稳）→ ConvNeXt（向 CNN 的「回归」：用卷积复刻 Swin 的配方）——「<strong>视觉骨干在『Transformer 与 CNN 之间来回震荡』</strong>」。这个「来回」揭示了一个深层事实：<strong>「有效的视觉结构」是「局部 + 全局 + 层级」的某种平衡，Transformer 与 CNN 只是不同的实现</strong>。</span>

**易错点：** 别以为「窗口注意力」是「退化」——Swin 的移位窗口在「跨窗口交流」上做了精心设计，实践中「窗口 + 移位」的表达力接近「全局注意力」却便宜得多。**「『局部 + 迭代』不是妥协，而是『可扩展的全局』」**。

## 6 小结

- **Swin**：窗口注意力（局部高效）+ 移位窗口（跨窗口交流）+ 层级金字塔（多尺度）——「ViT 的工程化改良」。
- **窗口注意力**：复杂度 $O(hwM^2)$（线性）vs 全局 $O(h^2w^2)$（平方）——省约 64 倍，高分辨率可行。
- **移位窗口**：相邻层窗口错位，「局部交流的迭代」实现「全局信息流动」。
- **层级金字塔**：逐级下采样、多尺度特征——检测/分割的必需结构。
- 对比 ViT（平铺单分辨率）——Swin「金字塔 + 窗口」更贴近 CNN 的多尺度智慧。
- 地位：检测/分割的现代骨干；「局部 + 迭代」不是妥协，而是「可扩展的全局」。
