## 为什么从语义分割与全卷积网络、U-Net开始

目标检测用「框」标出物体；**语义分割（semantic segmentation）**更细——**给图像的每个像素分类**（「这个像素是猫、这个是背景」）。它是「像素级的理解」，也是自动驾驶（识别道路/行人/车）、医学影像（分割肿瘤/器官）的核心任务。**全卷积网络（FCN）**是分割的开山之作，**U-Net** 则是医学影像分割的经典——两者代表了「分割网络」的两大设计思路。

语义分割的核心挑战：**输入是图像、输出是「同尺寸的像素标签」**——网络要「下采样提取语义」（编码器）、再「上采样恢复分辨率」（解码器）。**FCN** 把分类网络的「全连接层换成卷积」（全卷积化），用「转置卷积」上采样；**U-Net** 用「编码器-解码器 + 跳跃连接」——「把下采样丢失的细节补回来」。本节把「全卷积」「转置卷积」「U-Net 的跳跃连接」讲透——它们是「像素级任务」的骨干设计。<span class="marginnote">「分割 vs 检测 vs 分类」的『粒度』：分类（整图一个标签）、检测（几个框 + 标签）、分割（每个像素一个标签）——「<strong>分割是『最细粒度』的视觉理解</strong>」。「<strong>分割的输出与输入同尺寸</strong>」——「这是分割网络的『结构约束』：要恢复分辨率」。</span>

## 1 全卷积网络：分类网络 → 分割网络

**FCN（Fully Convolutional Network）**（Long 等, 2015）的关键思想：**把分类网络（如 VGG）的「全连接层」换成「卷积层」**——让网络「全卷积化」，能接受任意尺寸输入、输出「像素级预测」。

**为什么「全连接 → 卷积」可行？** 全连接层是「固定维度」的映射；卷积层是「空间共享」的局部映射——**全连接层可以等价成「卷积层」**（核大小 = 输入特征图大小）——「<strong>全卷积化 = 保留空间结构，输出变成「特征图」而非「向量」</strong>」。

**FCN 的输出**：最后一层输出「每个像素的类别分数」——$H\times W\times C$ 的特征图（$C$ 类），逐像素 Softmax。

**上采样（恢复分辨率）**：下采样后特征图变小，要用「上采样」恢复——FCN 用**转置卷积（transposed convolution）**（也叫反卷积）：「<strong>把低分辨率特征图『放大』回高分辨率</strong>」——是「卷积的『反向』」（把每个输入点「扩散」成输出区域）。<span class="marginnote">「转置卷积 vs 普通卷积」：普通卷积「把大图变小」（下采样），转置卷积「把小图变大」（上采样）——「<strong>转置卷积是卷积的『梯度反向』视角的『上采样卷积』</strong>」。「<strong>转置卷积是『可学习的上采样』</strong>」（对比双线性插值的「固定上采样」）——「代价是可能有『棋盘伪影』（重叠区域）」。理解「转置卷积 = 可学习的上采样」即可。</span>

**易错点：** 转置卷积不是「卷积的逆运算」（不能精确还原下采样前的图）——它是「<strong>可学习的上采样层</strong>」，学「怎么把低分辨率放大」。**「『反卷积』的称呼有误导性，它不是逆运算」**。

## 2 分割的编码器-解码器：下采样 + 上采样

语义分割网络的**通用骨架**：

```
输入图像
   ↓
编码器（下采样，提取语义）
   ↓
瓶颈（最深层语义）
   ↓
解码器（上采样，恢复分辨率）
   ↓
像素级标签图（H×W×C）
```

**编码器**：与分类网络的「骨干」相同（ResNet/VGG）——「下采样提取语义」（高层特征含「是什么」，缺「在哪」）。

**解码器**：上采样恢复分辨率——「把低分辨率语义图『放大』回像素级」——「<strong>解码器负责『从语义到像素』</strong>」。

**「分割 = 编码器（懂语义）+ 解码器（找回位置）」**——这个「编码-解码」结构是分割网络的共同骨架（也是 U-Net、DeepLab 的基础）。<span class="marginnote">「分割的『语义 vs 细节』矛盾」：<strong>下采样给『语义』（知道是什么）、丢『细节』（忘了在哪）；上采样找回『分辨率』、但细节已丢</strong>——「<strong>分割的核心矛盾 = 语义与细节的『兼得』</strong>」。「U-Net 的跳跃连接、DeepLab 的膨胀卷积——都是『兼得』的手段」。「<strong>理解这个矛盾，就理解了分割网络的设计动机</strong>」。</span>

**易错点：** 分割的「下采样」不能太狠——「分辨率降太多，细节丢光，上采样也找不回」——「<strong>分割网络的『下采样倍数』是精度与感受野的权衡</strong>」（通常 8×/16×/32×，配跳跃连接补细节）。

## 3 U-Net：跳跃连接补细节

**U-Net**（Ronneberger 等, 2015）是医学影像分割的经典，也是「编码-解码 + 跳跃连接」的典范：

**结构（「U」形）**：

```
输入 ──→ 编码器（下采样×4）──→ 瓶颈 ──→ 解码器（上采样×4）──→ 输出
            │  ←──── 跳跃连接（拼接对应层特征，补细节）────→  │
```

**「U 形」的两个半边**：编码器（下采样提取语义）+ 解码器（上采样恢复分辨率）——形似「U」。

**核心设计：跳跃连接（skip connections）**——解码器上采样的每一层，**拼接**编码器对应层的特征：

编码器的「浅层特征」含「细节」（边缘、纹理——位置信息）。
解码器「拼接」它 → **用细节补全上采样丢失的信息**。

**「跳跃连接 = 把『下采样丢失的细节』从编码器直接传给解码器」**——「<strong>语义来自深层、细节来自浅层，两者拼接兼得</strong>」。<span class="marginnote">「跳跃连接 vs ResNet 的残差」：ResNet 的跳跃连接「加」恒等（梯度流）、U-Net 的跳跃连接「拼接」特征（信息流）——「<strong>ResNet 加、U-Net 拼</strong>」。「U-Net 的拼接把『不同分辨率的特征』组合——让解码器『既懂语义又看细节』」。「<strong>U-Net 的跳跃连接是『多尺度特征融合』的早期典范</strong>」（与 FPN 异曲同工）。</span>

**易错点：** U-Net 的「拼接」要求「编码器与解码器的特征图尺寸一致」——「<strong>下采样与上采样的『对称』是 U-Net 的结构约束</strong>」。「改一个下采样倍率，所有层都要跟着对称调整」——「U-Net 的『U 形对称』是设计铁律」。

## 4 公式解析：转置卷积的「上采样」

把「转置卷积」的机制写清楚。设输入 $2\times2$（每个点一个值）、转置卷积核 $3\times3$、步幅 2。转置卷积的「正向」：**每个输入点「展开」成一个 $3\times3$ 区域，与核相乘后「叠加」到输出**：

$$
y[i:i+3, j:j+3] \mathrel{+}= x[i,j] \cdot \boldsymbol{K}
$$

- **第一步，看「点 → 区域」**：每个输入点贡献一个「核大小的区域」到输出——「<strong>输入稀疏，输出稠密</strong>」——「点被『扩散』成区域」。
- **第二步，看「叠加」**：相邻输入点的区域「重叠」处**相加**——「<strong>重叠叠加 = 输出比输入大</strong>」——「上采样的机制」。
- **第三步，看输出尺寸**：$2\times2$ 输入、$3\times3$ 核、步幅 2 → $4\times4$ 输出（公式 $\lfloor(H-1)\times s + k\rfloor$）——「<strong>尺寸放大</strong>」。<span class="marginnote">「转置卷积的『重叠伪影』」：核重叠处「相加」可能「叠加过强」（某些区域比别处亮）——「<strong>棋盘伪影</strong>」。「缓解：插值 + 卷积（先双线性放大、再卷积）」——「<strong>『可学习上采样』的代价是『可能失真』</strong>」。「工程上常『插值上采样 + 卷积』替代转置卷积（更稳）」。</span>

## 5 分割的评估与现代演进

**分割评估：mIoU（mean Intersection over Union）**——各类别 IoU 的平均：

$$
\text{mIoU} = \frac{1}{C}\sum_{c=1}^{C} \frac{\text{类别 }c \text{ 的交集}}{\text{类别 }c \text{ 的并集}}
$$

「<strong>mIoU = 预测的分割与真实分割的『重叠度』平均</strong>」——分割的「总分数」。

**分割的现代演进**：

- **膨胀卷积（Dilated/Atrous Convolution）**：不降分辨率、扩大感受野（DeepLab 系）——「<strong>用『孔洞』替代『池化』，保住细节</strong>」。
- **特征金字塔（FPN）**：多尺度特征融合——「分割与检测共享的多尺度骨干」。
- **Transformer 分割（SegFormer）**：用 Transformer 做分割骨干——「视觉 Transformer 的迁移」。

**「分割从 FCN → U-Net → DeepLab → SegFormer」**——「<strong>主线是『语义与细节的兼得』：转置卷积（FCN）、跳跃连接（U-Net）、膨胀卷积（DeepLab）、注意力（SegFormer）</strong>」。<span class="marginnote">「分割与检测的『共享骨干』」：现代分割与检测共享「多尺度骨干」（FPN、DeepLab 的 ASPP）——「<strong>『提特征』的部分（骨干）可以共享，『做任务』的部分（分割头/检测头）不同</strong>」。「理解『骨干 + 头』的分工，是现代视觉模型读源码的关键」。</span>

**易错点：** 分割的「像素级分类」用「逐像素交叉熵」损失，但「类别不平衡」严重（背景像素远多于物体）——「<strong>分割损失要处理不平衡（加权交叉熵、Dice 损失）</strong>」。「U-Net 在医学影像里常用 Dice 损失（与 mIoU 相关的可微形式）」——「<strong>损失与评估指标『对齐』（Dice 损失 ≈ 优化 mIoU）</strong>」。

## 6 小结

- **语义分割**：给每个像素分类——「像素级的理解」，输出与输入同尺寸。
- **FCN**：全连接换卷积（全卷积化）+ 转置卷积上采样——「分类网络 → 分割网络」。
- **转置卷积**：可学习的上采样——「每个点展开成区域叠加」；不是卷积的逆运算。
- **编码-解码骨架**：下采样提语义 + 上采样找细节——「分割的核心矛盾：语义 vs 细节」。
- **U-Net**：U 形编码-解码 + 跳跃连接（拼接浅层细节）——「语义 + 细节兼得」的典范。
- **评估 mIoU**：各类别 IoU 平均——分割的总分数；演进：膨胀卷积、FPN、SegFormer。

在第八篇里，我们还会回到「图像 + 文本」的交汇——用对比学习把图像与文本对齐到同一个向量空间，这就是**多模态学习：CLIP 与图文对齐**——视觉-语言模型的真正开端。
