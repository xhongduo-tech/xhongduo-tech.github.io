## 为什么从 BERT 开始

Transformer 有两个「半身」：编码器与解码器。GPT 用了「解码器」（自回归生成），**BERT**（Devlin 等, 2019）用了「编码器」（双向理解），并引入了一个优雅的自监督任务——**掩码语言模型（Masked Language Model, MLM）**：把句子里 15% 的词遮住，让模型「猜」被遮住的词。这个「填空题」式的任务让 BERT 可以在海量无标注文本上预训练，学到「双向上下文」的深度表示——然后只需轻量微调，就能统治几乎所有 NLP 任务。

BERT 是「预训练 + 微调」范式的奠基者之一：**先用无监督数据预训练一个「通用语言理解器」，再用少量标注数据微调到具体任务**。它在 11 项 NLP 任务上刷新纪录，开启了「预训练时代」——今天所有大语言模型的工作方式，都直接或间接来自 BERT 与 GPT 确立的这个范式。本节把 BERT 的 MLM、预训练细节、与「预训练 + 微调」范式的精髓讲透。<span class="marginnote">「BERT 名字」：Bidirectional Encoder Representations from Transformers——「来自 Transformer 的双向编码器表示」。它的核心创新不是「新架构」（就是 Transformer 编码器），而是「新预训练任务」（MLM）——「<strong>让双向编码器有东西可学</strong>」。这个「用任务设计释放架构潜力」的思路，是 BERT 最重要的方法论贡献。</span>

## 1 从自回归到掩码：为什么语言模型不够

**语言模型**（GPT 的方向）是「自回归」的——预测下一个词，**只能看左边的上下文**（因果约束）。这对「生成」是必要的，但对「理解」是浪费：判断「bank」在「river bank」里是「河岸」还是「银行」，需要看**右边的词**（「river」在左边、但上下文词「bank」的歧义要看全句）。

**BERT 的目标**：让模型**双向**看上下文——「每个词的表示同时编码左右两侧的信息」。

**但「双向语言模型」有矛盾**：若直接「预测下一个词」且「能看右边」，那「下一个词」就「已经看到了」（泄漏）。BERT 的解法是**改任务**：不预测「下一个」，而是「**预测被遮住的词**」——把词遮住，让模型从「左右两侧」推理出它。

**掩码语言模型（MLM）**：随机遮住 15% 的词（用 `[MASK]` 替换），让模型预测被遮的词。**「填空」任务天然双向**——推理「被遮住的词」需要看它左右的所有词。<span class="marginnote">「为什么 MLM 是天才设计」：语言模型的「预测下一个」是「从左到右」的因果任务（无法用右边信息）；MLM 的「填空」是「去噪」任务（从完整上下文推断缺失项）——它把「双向理解」变成了「可监督的自监督任务」。这个「任务重塑」的灵感来自「完形填空」（Cloze），也是「自编码式预训练」与「自回归式预训练」的分水岭——「<strong>自编码（MLM）适合理解，自回归适合生成</strong>」（下一篇《GPT 系列》）。</span>

## 2 MLM 的具体实现：掩码策略

BERT 的掩码策略（细节决定成败）：

**随机选 15%** 的 token 位置做掩码。
被选中的位置，**80%** 替换为 `[MASK]`，**10%** 替换为随机词，**10%** 保持不变。

**为什么不是「全替换成 [MASK]」？** 因为「推理时模型永远看不到 [MASK]」（推理时输入是完整句子）——若只在「全 [MASK]」上训练，模型会对 [MASK] 过于敏感，微调时「没见过完整输入」。**「80/10/10」让模型学会「处理各种输入形态」**——既会填 [MASK]、也会纠错（随机词）、也会「保持原样时仍给正确表示」。

**损失**：只对被选中的 15% 位置算预测损失（其余位置不参与）——**「只监督被遮的部分」**。

**易错点：** MLM 的「随机词替换」不是「噪声」——它让模型学会「当输入有错时，仍给出合理表示」（去噪训练）。**「80/10/10 不是拍脑袋，而是『让模型适应推理时的输入分布』」**——这个「训练/推理分布对齐」的思想，与《数据集增强》一脉相承。<span class="marginnote">「15% 的掩码率」是权衡：太高（如 50%）训练「太难」（每句太多词要猜，模型学不动）；太低（如 5%）训练「太易」（大多数句子没有要猜的词，学不到东西）。15% 是「每句约有 1–2 个词要猜」的甜点——「<strong>每句都有事做，又不过载</strong>」。</span>

## 3 BERT 的预训练：两个任务一起学

BERT 的预训练用**两个任务**联合优化：

**任务一：掩码语言模型（MLM）**——如上，预测被遮的词（双向理解）。

**任务二：下一句预测（Next Sentence Prediction, NSP）**——给两个句子 A、B，判断 B 是否是 A 的下一句（二分类）。目的：让模型学习「句子间的关系」（连贯性）。

**输入格式**：两句话用 `[SEP]` 分隔，句首加 `[CLS]`：

```text
[CLS] 我的小狗很可爱 [SEP] 它喜欢在公园里玩 [SEP]
```

`[CLS]` 的最终表示作为「整个句对的聚合表示」（用于 NSP 分类，微调时用于「句对分类」任务如自然语言推理）。<span class="marginnote">「NSP 的作用」在后来的研究里被质疑（RoBERTa 发现去掉 NSP 性能更好），但它的设计初衷值得理解：很多 NLP 任务（问答、推理）需要「理解句子间关系」，纯 MLM 只学「句内」不学「句间」。NSP 是「<strong>给编码器补上句间建模</strong>」的尝试——虽然后来被「更简单的办法」替代（RoBERTa 的更长序列 + 更大数据），但它代表「预训练任务要覆盖任务需要的全部能力」的设计思路。</span>

**预训练数据**：BooksCorpus（8 亿词）+ 英文维基百科（25 亿词）——**无标注文本 + 自监督任务**，数据「免费」。

**易错点：** NSP 的「负样本」是「随机拼接的下一句」（不是「真实但无关的句子」）——**「下一句预测」训练的是「连贯性判别」，不是「语义相关性」**。这个「负样本构造方式」决定了模型学到什么。

## 4 公式解析：预训练 + 微调的完整流程

把「预训练 + 微调」范式写成数学。**预训练**：在无标注语料 $\mathcal{D}_{\text{pre}}$ 上，最小化 MLM 损失：

$$
L_{\text{MLM}} = -\mathbb{E}_{\boldsymbol{x}\sim\mathcal{D}_{\text{pre}}}\Big[\sum_{t \in \mathcal{M}} \log P(x_t \mid \boldsymbol{x}_{\setminus \mathcal{M}})\Big]
$$

其中 $\mathcal{M}$ 是掩码位置集合，$\boldsymbol{x}_{\setminus\mathcal{M}}$ 是被掩码后的句子。

**微调**：用预训练权重初始化，在标注数据 $\mathcal{D}_{\text{ft}}$ 上按任务微调：

$$
L_{\text{task}} = -\mathbb{E}_{(\boldsymbol{x}, y)\sim\mathcal{D}_{\text{ft}}}\Big[\log P(y \mid \boldsymbol{x}; \boldsymbol{\theta}_{\text{pretrained}} + \Delta)\Big]
$$

- **第一步，看预训练**：无标注数据 + MLM 自监督——「先学通用语言理解」。
- **第二步，看微调**：预训练权重做初始化，加任务头（分类头/问答头），在标注数据上继续训练——「再学任务特定能力」。
- **第三步，读范式**：**「预训练给『通用表示』，微调加『任务头』」**——海量无标注数据（便宜）提供表示，少量标注数据（贵）提供任务方向。这个「先通用、后专用」的范式，是大模型时代的核心工作方式。<span class="marginnote">「预训练 + 微调 vs 从头训练」的效率对比：从头训练要「从零学语言 + 学任务」（数据需求大）；预训练让「语言」这一大部分被无标注数据「免费」学好，微调只需「学会任务」——标注数据需求从「百万」降到「千」。这个「<strong>无标注数据换标注需求</strong>」的杠杆，是预训练范式「经济上颠覆」NLP 的根本原因。</span>

## 5 BERT 的微调：一个模型，处处可用

BERT 微调的精妙：**同一个预训练模型，换不同的「任务头」就能做不同的任务**：

| 任务 | 微调方式 | 输入/输出 |
| --- | --- | --- |
| 句子分类（情感） | `[CLS]` 表示 + 分类头 | 单句 → 类别 |
| 句对分类（推理） | `[CLS]` 表示 + 分类头 | 句对 → 类别 |
| 词标注（NER） | 每个 token 表示 + 分类头 | 单句 → 每词标签 |
| 问答（SQuAD） | 每个 token 表示 + 起止预测 | 问题+段落 → 答案起止 |

**「换个头，换任务」**——预训练学到的是「通用的语言表示」，微调只是「在这个表示上接一个任务特定的小头」。这背后是「表示的可迁移性」：BERT 的中间层表示包含了「词法、句法、语义」的丰富信息，不同任务只需要「挑取」所需的部分。

**易错点：** 微调时「任务头」是**随机初始化**的（预训练没有这个头），要**较大学习率**（相比预训练参数）；预训练参数用**小学习率**微调——**「新头大学习率、旧参数小学习率」**是微调的工程配方。<span class="marginnote">「BERT 的可迁移性证据」：研究者用「冻结的 BERT 表示 + 简单分类器」也能在许多任务上达到不错效果——说明「表示本身」已经编码了任务需要的大部分信息，微调只是「锦上添花」。这个「冻结也有效」的现象，是「预训练表示 = 通用特征」的最直接证据，也启发了后来「prompt 化」的趋势（下一篇《下游任务微调与提示学习》）。</span>

## 6 数值算例：MLM 的掩码比例与预训练量

把 BERT 的预训练关键数字钉住。BERT-base：12 层编码器、隐藏维 768、12 个头、约 1.1 亿参数；预训练语料约 33 亿词的 BooksCorpus + Wikipedia。

**掩码语言模型（MLM）的具体规则**：随机选 15% 的 token 做掩码，其中 80% 换成 `[MASK]`、10% 换成随机词、10% 保持原词——模型只在这 15% 的位置上算交叉熵。

**为什么不能全换成 `[MASK]`？** 三个数字讲清：80% 掩码让模型学会「根据上下文补缺失词」；10% 随机替换让模型知道「位置可能被换词」（避免「看见 [MASK] 就当噪声忽略」）；10% 保留原词让模型「对正确的词也敢保持」——**三种情况逼模型同时理解「缺失、错误、正确」三种信号**。<span class="marginnote">对比 GPT 的自回归：BERT 的预训练目标是「双向」的——预测一个被掩码的词时，它能同时看左边和右边的上下文（Transformer 编码器无因果掩码）；而 GPT 只能看左边（解码器有因果掩码）。<strong>「双向 vs 单向」是理解 BERT 与 GPT 分工的钥匙</strong>：BERT 擅长「理解/分类」（完形填空式的理解），GPT 擅长「生成」（接续式生成）。这也解释了为何下游任务里 BERT 系主导理解类任务、GPT 系主导生成类任务。</span>

**一个常被问的工程细节**：为什么 MLM 用「预测被掩码词」而不是「预测下一句」？因为完形填空式的双向任务能让每个位置都获得「左右」的监督信号，学习效率更高——而「预测下一句（NSP）」后来被证明贡献不大，RoBERTa 去掉 NSP 后表现反而更好（见《预训练任务设计》）。

## 7 小结

- **BERT**：Transformer 编码器 + **掩码语言模型（MLM）**——双向理解的预训练。
- **MLM**：遮住 15% 的词让模型「填空」——「去噪式」自监督，天然双向。
- 掩码策略 80/10/10：`[MASK]`/随机词/保持原样——让模型适应推理时的完整输入。
- 预训练双任务：**MLM（句内）+ NSP（句间）**；无标注数据免费。
- **预训练 + 微调范式**：无标注数据学通用表示，少量标注数据加任务头——「先通用、后专用」。
- BERT 是「理解系」代表（双向），与 GPT 的「生成系」（单向自回归）互补——下一篇。

在下一节，我们看「预训练 + 微调」范式的另一半——用「解码器」做自回归预训练，这就是 **GPT 系列：自回归语言建模**。
