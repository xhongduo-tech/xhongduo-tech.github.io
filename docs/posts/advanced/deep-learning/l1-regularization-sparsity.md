## 为什么从 L1 正则化开始

上一节的 L2 正则把权重「温和地缩小」，但缩小后的权重**几乎总是不为零**——只是变小。这在很多场景不够用：我们希望特征选择（哪些特征真正有用）、希望模型可解释（权重为零的特征直接排除）、希望压缩存储（零权重不用存）。**L1 正则化**的正则项用权重的**绝对值之和**代替平方和，它有一个 L2 没有的惊人性质：**让许多权重精确等于零**，从而产生**稀疏（sparse）解**。

「稀疏」在深度学习里是一个反复出现的高频词：稀疏权重、稀疏激活、稀疏注意力、稀疏特征。本节讲清楚 L1 如何实现稀疏、为什么几何上必然稀疏、与 L2 的精确对比，以及它在现代模型里的实际角色（它已经不只是「正则化」，而是「诱导稀疏结构」的工具）。<span class="marginnote">L1 稀疏性的故事横跨多个学科：统计里的 Lasso（Tibshirani，1996）用它做变量选择，信号处理里的压缩感知用它从欠定测量中恢复稀疏信号，深度学习里则用来做特征选择与稀疏表示。不同学科用同一个数学对象，核心都是「$\ell_1$ 范数在原点有尖角」这个几何事实。</span>

## 1 定义与梯度行为：绝对值不可导怎么办

**L1 正则化**：在损失上加权重绝对值的和：

$$
\tilde{J}(\boldsymbol{\theta}) = J(\boldsymbol{\theta}) + \alpha \|\boldsymbol{w}\|_1 = J(\boldsymbol{\theta}) + \alpha \sum_i |w_i|
$$

**L1 在原点不可导**——这正是稀疏性的来源，也是实现上要处理的问题。在 $w_i \ne 0$ 处，梯度的符号决定惩罚的推力方向：

$$
\frac{\partial \tilde{J}}{\partial w_i} = \frac{\partial J}{\partial w_i} + \alpha\,\text{sign}(w_i)
$$

- 若 $w_i > 0$，惩罚项把权重**往下推**（减 $\alpha$）。
- 若 $w_i < 0$，惩罚项把权重**往上推**（加 $\alpha$）。
- 若 $w_i = 0$，惩罚项没有定义（次梯度可取 $[-\alpha, \alpha]$ 中任意值）。

**直觉**：无论权重在哪一侧，L1 都把它**推向零**；而一旦到零，就停在那里不动——因为「继续穿越零」需要付出代价。这就是 L1 让权重**精确归零**的机制。<span class="marginnote">对比 L2：$w_i$ 越接近零，L2 的推力 $2\alpha w_i$ 越小，于是权重「缓慢逼近零但永远到不了零」；而 L1 的推力 $\alpha\,\text{sign}$ 在零附近保持恒定，像一个恒力把权重「哐当」推到零。用物理类比：L2 是橡皮筋（越远拉力越大，到不了零），L1 是恒力弹簧（恒定推力，能顶到挡板）。</span>

## 2 为什么几何上 L1 必然稀疏：角点效应

理解 L1 稀疏性最直观的窗口是**几何**。正则化等价于「在 $\|\boldsymbol{w}\|_p \le C$ 的约束下最小化损失」。约束区域的形状随 $p$ 不同：

**L2 约束**：$\|\boldsymbol{w}\|_2 \le C$ 是**圆形**（光滑，无角点）。
**L1 约束**：$\|\boldsymbol{w}\|_1 \le C$ 是**菱形**（在坐标轴上带尖角）。

**角点效应（corner effect）**：损失函数的等高线（椭圆）与约束区域相切时，最优解倾向于落在菱形的**尖角**上——而尖角恰好在坐标轴上，意味着该维权重为零。高维下更极端：L1 球是「高维的十字星」，几乎所有的「面」都在坐标轴附近，随机相切也极易落在角上——所以稀疏不是巧合，而是**几何必然**。<span class="marginnote">高维 L1 球的直觉：$\mathbb{R}^n$ 里 $\ell_1$ 单位球的表面几乎全部集中在坐标轴上（「维度灾难」的几何体现），于是「损失等高线与 L1 球相切」这个事件，落在坐标轴上的概率远高于 L2。这也是「L1 在高维下稀疏性更明显」的原因。</span>

**L2 vs L1 的精确对比**：

| 性质 | L2（权重衰减） | L1 |
| --- | --- | --- |
| 正则项 | $\frac{\alpha}{2}\|\boldsymbol{w}\|_2^2$ | $\alpha\|\boldsymbol{w}\|_1$ |
| 解的性质 | 权重缩小但**几乎不为零** | 权重**精确等于零**（稀疏） |
| 等价先验 | 高斯先验 | 拉普拉斯先验 |
| 约束区域 | 圆形（光滑） | 菱形（带尖角） |
| 典型用途 | 通用防过拟合 | 特征选择、稀疏结构 |

## 3 拉普拉斯先验：L1 是「我相信权重稀疏」

与 L2 对应高斯先验一样，**L1 正则化对应拉普拉斯先验**：

$$
p(\boldsymbol{w}) \propto \exp\big(-\alpha |w|\big)
$$

拉普拉斯分布在原点**有尖峰**：它把大量概率质量堆积在 0 附近，尾部比高斯更厚。「尖峰」意味着先验强烈偏好「恰好为零」，而高斯先验偏好「靠近零但不为零」。**「稀疏先验」与「收缩先验」的差异，就是拉普拉斯与高斯的形状差异**。

这个贝叶斯视角在信号处理与统计里极其有用：当我们相信「真实信号是稀疏的」（如自然图像的小波系数、基因表达矩阵里只有少数基因起作用），就应使用 L1 诱导稀疏解。<span class="marginnote">为什么自然信号常常稀疏？因为真实世界的信息是「低维结构」：一张自然图像的小波系数只有少数大系数、其余接近零；一段文本的 TF-IDF 特征只有少数非零。稀疏是「信号有结构」的数学表达——这也是稀疏编码、稀疏表示长期在脑科学（视皮层稀疏编码）与机器视觉里受关注的原因。</span>

## 4 稀疏性在深度学习中的三重用途

L1 稀疏在现代深度学习中至少有三种重要用途：

**用途一：特征选择。** 输入特征是 1 万维，其中 100 维真正有用。L1 让无关维的权重归零，剩下的非零权重就是「被选中的特征」——模型自带解释性。这在基因数据、文本词袋、医学特征上尤为实用。

**用途二：稀疏权重与模型压缩。** 权重精确为零的条目**不需要存储、不需要计算**。训练后把零权重剪掉（pruning），模型体积与推理代价大幅下降——这是模型部署里「结构化剪枝」的数学根基。相比 L2 的「全小但非零」，L1 的「多数为零」对压缩友好得多。

**用途三：稀疏激活的预演。** L1 正则不止能用在不同**特征**上，还能用在不同**神经元**上：给隐藏单元的激活加 L1 惩罚，逼迫网络只在少数神经元上「点亮」，得到稀疏的分布式表示。这在稀疏自编码器（第七篇）里是核心手段。<span class="marginnote">把 L1 用在「神经元激活」而非「权重」上，是理解稀疏自编码器（SAE）的钥匙：SAE 的目标就是让每个输入用少数几个「字典原子」的线性组合表示——这与「L1 在原点有尖角」是同一个机制。近年大模型可解释性研究大量使用 SAE 来发现「稀疏特征」，见第七篇《稀疏自编码器》与第四级《AI 安全与对齐》。</span>

## 5 公式解析：L1 的次梯度与近端更新

由于 L1 在原点不可导，梯度下降需要特殊处理。最优雅的处理是**近端梯度法（proximal gradient）**，它把 L1 惩罚的更新写成「**软阈值（soft-thresholding）**」操作：

$$
\text{prox}_{\eta\alpha}(w) = \text{sign}(w)\,\max\big(|w| - \eta\alpha,\; 0\big) = \begin{cases} w - \eta\alpha, & w > \eta\alpha \\ 0, & |w| \le \eta\alpha \\ w + \eta\alpha, & w < -\eta\alpha \end{cases}
$$

每步更新 $\boldsymbol{w} \leftarrow \text{prox}_{\eta\alpha}\big(\boldsymbol{w} - \eta\nabla J(\boldsymbol{w})\big)$：

- **第一步，先按数据梯度走一步**：$\boldsymbol{w} - \eta\nabla J$（与普通梯度下降相同）。
- **第二步，再做软阈值**：绝对值大于 $\eta\alpha$ 的权重被**削减** $\eta\alpha$；绝对值小于 $\eta\alpha$ 的权重被**直接置零**。
- **第三步，读稀疏性来源**：软阈值的「死区」$|w| \le \eta\alpha$ 把所有「不够大」的权重**一次性清零**——这就是 L1 稀疏性在优化算法里的具体形态。<span class="marginnote">软阈值与「硬阈值」对比鲜明：硬阈值（$|w|<\eta$ 就清零，否则保留）等价于「不光滑的剪枝」，会导致目标函数不连续；软阈值则是「光滑的稀疏解」——它正是 L1 问题的精确解算子。近端梯度法在凸优化里有完整的收敛理论，见第二级《最优化理论》的近端方法一章。</span>

**易错点一：** 在深度网络里，标准框架的 L1 正则通常以「手动加到损失」实现（如 `loss = loss + alpha * w.abs().sum()`），此时优化器仍是 SGD/Adam，并不执行精确的软阈值——梯度在零点按「次梯度=0」处理，效果是「近似稀疏」而非「精确稀疏」。要得到精确零权重，需用专门的近端优化器或训练后剪枝。

**易错点二：** L1 稀疏性与 L2 的「组稀疏」不同。L1 是**逐元素**稀疏；若希望「整组特征一起保留或一起丢弃」（如一个 one-hot 编码的类别所有维度），要用**组 Lasso（group lasso）**——把一组权重的 L2 范数当整体做惩罚。<span class="marginnote">组 Lasso 与 L1 的关系值得记住：L1 是「组大小为 1 的组 Lasso」；把组做成「一层神经元」「一个卷积核」的组稀疏，就能得到结构化剪枝——这是模型压缩研究的重要方向。</span>

## 6 数值算例：L1 与 L2 的「几何差」

把「L1 精确归零、L2 只缩小」的几何原因画出来。考虑一维情形：目标为 $\tilde{J}(w) = J(w) + \alpha\,|w|$（L1）或 $+\frac{\alpha}{2}w^2$（L2），最优解满足「数据梯度 + 正则梯度 = 0」。

**关键差异在原点**：L1 在 $w=0$ 处**不可导**，正则项在 $w>0$ 一侧给出 $-\alpha$ 的推力、$w<0$ 一侧给出 $+\alpha$ 的推力——**只要数据的梯度绝对值小于 $\alpha$，最优解就被「钉」在 $w=0$**。L2 在 $w=0$ 处可导、梯度为零，解只会被「推向」原点附近但从不恰好停在原点。<span class="marginnote">二维以上的直觉同样成立：<strong>L1 的可行域是「菱形」（有尖角在坐标轴上），L2 是「圆形」（处处光滑）</strong>。数据目标的最优解在约束下取「相切点」——菱形相切点常在顶点（某些坐标恰为 0），圆形相切点几乎不会恰好落在坐标轴上。所以「L1 出稀疏解」不是玄学，是<strong>不可导的尖角恰好落在坐标轴上</strong>这一几何事实的直接推论。</span>

**三个实践记忆点。**
- L1 让「无关特征」的权重精确变 0，等价于**特征选择**——模型自动挑出「有用的输入维」。
- L2 只把权重等比缩小，保留所有特征但降低其影响。
- L1 的目标函数在原点不可导，优化需用**近端梯度**或次梯度；L2 处处可导、直接梯度下降即可。
- 稀疏性的另一面：选中的特征会「互相竞争」，超参数 $\alpha$ 越大，留下的特征越少。
- 深度学习中 L1 常用于「稀疏激活/稀疏特征选择」，而「权重衰减」默认仍是 L2。
- 几何机制：L1 约束是**菱形**，最优解倾向落在坐标轴尖角上；高维下角点效应更强。
- 贝叶斯视角：L1 对应**拉普拉斯先验**（原点尖峰）——「稀疏先验」 vs L2 的「收缩先验」。
- 三重用途：**特征选择、权重剪枝压缩、稀疏激活表示**。
- 精确稀疏由**软阈值**更新实现：$|w|\le\eta\alpha$ 的权重直接置零。
- 框架里手加 L1 只给「近似稀疏」，精确稀疏需近端优化或剪枝。

在下一节，我们离开「对权重的惩罚」，转向「对数据本身做手脚」的正则——凭空造出更多训练样本，这就是**数据集增强与噪声鲁棒性**。
