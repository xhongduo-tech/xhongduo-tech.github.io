## 为什么从学习率策略开始

在所有超参数里，**学习率（learning rate）几乎总是最重要、最敏感的一个**：太大，训练震荡甚至发散；太小，训练龟爬不动。而更关键的是——**最优学习率不是常数**：训练初期参数离解很远，需要大步快走；训练后期参数已接近解，需要小步精修。**学习率策略（learning rate schedule）**就是「学习率随时间变化」的设计：从**衰减**（step/exponential）到**预热**（warmup），再到**余弦退火**（cosine annealing）。

理解学习率策略的本质，是理解「**噪声随学习率缩小**」这条线索（见《SGD》）：学习率大 → 每步走得远 → 梯度噪声影响大 → 探索与逃逸；学习率小 → 每步精修 → 噪声影响小 → 收敛。一条好的调度就是「先探索、后精修」的节拍器——它把「在广阔空间里找对区域」与「在局部区域里精雕细琢」两个阶段分开。<span class="marginnote">「学习率策略是训练脚本的灵魂」这个说法不过分：同样的模型与数据，仅换调度策略就能让最终性能差几个百分点。现代大模型训练里，<strong>warmup + 余弦退火（或类似）几乎是通用配方</strong>——它是从「炼丹」到「科学训练」的关键一步，也直接决定「训练步数预算」如何被使用。</span>

## 1 为什么需要「先大后小」：探索与精修

单靠「固定学习率」训练，两头不讨好：

**全程大学习率**：参数剧烈震荡，在解附近「绕着走」，无法精确收敛；甚至早期就被「踢出」好的优化区域。
**全程小学习率**：训练慢如蜗牛；且噪声太小，可能无法逃离鞍点与平台（失去「噪声逃逸」能力）。

于是标准做法是**分段**：

1. **探索期（大学习率）**：大步快走，快速进入「有希望的盆地」；大噪声帮助逃离坏区域。
2. **精修期（小学习率）**：小步慢走，在盆地底部精确定位；小噪声保证收敛稳定。

**「先探索后精修」是几乎所有调度的共同内核**——衰减、退火、预热都是这个内核的不同实现。<span class="marginnote">一个反直觉的经验：<strong>训练最终性能在很大程度上由「早期的大学习率阶段」决定</strong>——早期怎么走决定了「落在哪个盆地」，后期只是「在盆地底部挖深」。这也解释了为什么「随机初始化 + 大学习率早停」有时能媲美精心调参的完整训练：优化轨迹的「早期定向」比「晚期精修」更影响泛化。</span>

## 2 衰减策略：逐步缩小

最简单的策略是「按规则衰减」。三种经典实现：

**Step 衰减**：每训练 $S$ 个 epoch，学习率乘以衰减因子 $\gamma$（如每 30 epoch 乘以 0.1）：

$$
\eta_t = \eta_0 \cdot \gamma^{\lfloor t/S \rfloor}
$$

**指数衰减**：每个 epoch 学习率乘以一个小于 1 的因子，平滑连续下降：

$$
\eta_t = \eta_0 \cdot \gamma^{t}
$$

**分数衰减**：按 $\eta_t = \eta_0/(1 + k t)$ 衰减，理论上是凸问题上「收敛友好」的形式。<span class="marginnote">Step 衰减是最「工程」的选择：它允许「大学习率跑一段时间 → 突然缩小 → 再跑一段」的节奏，每个台阶都是一个「换挡提速」。实践中「在验证误差平台期把学习率除以 10」的<strong>手动衰减</strong>仍是很多老手的最爱——它把「何时衰减」也交给验证集判断（ReduceLROnPlateau 就是它的自动化）。</span>

**易错点一：** 衰减的**时机**与**幅度**比「用哪种公式」更重要。常见误区是「衰减太早太狠」——模型还没探索够就被钉死在局部区。经验：先让大学习率跑足够久（观察损失不再下降再衰减），每次衰减一个数量级（×0.1）通常够用。

## 3 余弦退火：平滑地衰减到零

**余弦退火（cosine annealing）**（Loshchilov & Hutter, 2017）：学习率按余弦函数从初始值平滑降到（接近）零：

$$
\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})\Big(1 + \cos\Big(\frac{\pi t}{T}\Big)\Big)
$$

其中 $T$ 是总训练步数，$\eta_{\max}$、$\eta_{\min}$ 是上下界。特点：

- **平滑**：没有阶梯的突然跳变，全程连续下降。
- **前期慢降、后期快降**：余弦形状让学习率在早期保持较大（充分探索）、后期快速收敛（精修），节奏贴合「探索-精修」需求。
- **配合「带重启的余弦退火」**：余弦退火可以配**周期性重启（warm restart）**——每过 $T$ 步把学习率拉回 $\eta_{\max}$，形成「退火 → 重启 → 再退火」的循环。重启让模型周期性地「跳出当前盆地、重新大范围探索」，常能带来性能提升（SGDR 论文）。

**易错点二：** 余弦退火需要预设**总步数 $T$**。若实际训练步数超过 $T$，学习率会继续「停在 $\eta_{\min}$」；若远小于 $T$，学习率根本没降下来。**「调度长度」是余弦退火的关键超参数**，应尽量与「训练预算」匹配。

**易错点三：** 「重启」不是免费的。每次重启会把学习率拉大，训练损失会**跳升**（正常现象！），随后再降。看着损失反弹而惊慌地提前终止，是「带重启训练」最常见的误操作——**要习惯「重启后的跳变」是设计的预期行为**。<span class="marginnote">余弦退火在现代大模型里几乎是默认选择（如 GPT、LLaMA 训练脚本）。它相比 Step 衰减的一个优势是「对步数预算更鲁棒」：在总步数没跑满时，学习率尚未降到底，收敛质量损失不大。这也是「不知该用哪种调度时，选余弦退火」的工程理由。</span>

## 4 预热：为什么开头要「小步」

**预热（warmup）**：训练的最初若干步（或若干 epoch）里，学习率从**很小**线性升到目标值，之后才开始正常衰减。

$$
\eta_t = \eta_0 \cdot \frac{t}{T_{\text{warmup}}} \quad (t \le T_{\text{warmup}})
$$

**为什么需要预热？** 两个原因：

- **初始化不稳**：训练初期参数离解很远，损失曲面局部形状「陌生」，大步更新可能把参数踢到坏区域。小步起步让模型「先站稳」。
- **BatchNorm/自适应统计量未就绪**：早期 batch 统计量、Adam 的二阶矩估计都未稳定，直接大学习率会放大这些「未校准的估计」。

预热在**大 batch 训练**（线性缩放规则下学习率很大）与**Transformer/大模型**（学习率大、训练深）里几乎是必需的——BERT、GPT 的训练脚本都以「预热 + 退火」为标准配置。<span class="marginnote">「预热」还有一层更微妙的解释：大学习率早期会让参数在「尖锐方向」上剧烈摆动；预热先让模型在「温和地形」上定位到「宽而平」的方向，再放大步长——这与「大 batch + 线性缩放学习率」的配合是 2018 年后大规模训练的标配。没有预热的大 batch 训练，参数往往在第一步就被「踢飞」。</span>

## 5 公式解析：一条完整的调度曲线

把「预热 + 余弦退火」的完整调度写成统一公式（现代大模型的典型配置）：

$$
\eta_t = \begin{cases} \eta_{\max}\,\dfrac{t}{T_{\text{warm}}}, & t < T_{\text{warm}} \\[8pt] \eta_{\min} + \dfrac{1}{2}(\eta_{\max}-\eta_{\min})\Big(1 + \cos\dfrac{\pi(t - T_{\text{warm}})}{T - T_{\text{warm}}}\Big), & t \ge T_{\text{warm}} \end{cases}
$$

- **第一步，看第一段（预热）**：$t$ 从 0 到 $T_{\text{warm}}$，学习率从 0 **线性上升**到 $\eta_{\max}$。斜率是 $\eta_{\max}/T_{\text{warm}}$，预热步数越长越平缓。
- **第二步，看第二段（余弦）**：$t$ 从 $T_{\text{warm}}$ 到总步数 $T$，学习率从 $\eta_{\max}$ **余弦下降**到 $\eta_{\min}$。前期下降慢（保持探索）、后期下降快（加速精修）。
- **第三步，看关键超参**：$\eta_{\max}$（峰值学习率）、$T_{\text{warm}}$（预热长度，常为总步数的 1–5%）、$T$（总步数）、$\eta_{\min}$（通常设为 $\eta_{\max}$ 的 1–10%）。**整条曲线四个参数，每个都有明确语义，这是「科学调参」的基础**。<span class="marginnote">「学习率扫描（LR sweep）」是确定 $\eta_{\max}$ 的标准方法：用「预热后固定学习率」快速跑一小段，观察损失曲线——能快速下降的学习率上限即 $\eta_{\max}$ 的候选。这个「先用 LR finder 定峰值、再配调度」的流程，是第九篇《调参方法论》的核心技巧之一。</span>

## 5 数值算例：余弦退火的一次完整曲线

把学习率调度的「形状」落到具体数字。设训练 100 个 epoch，初始学习率 $\eta_{\max} = 10^{-3}$，余弦退火策略：

$$
\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})\left(1 + \cos\frac{t\pi}{T}\right)
$$

代入几个关键时刻（$\eta_{\min}=0$）：第 0 epoch $\eta=10^{-3}$、第 25 epoch $\approx 8.5\times10^{-4}$、第 50 epoch（中点）$\approx 5\times10^{-4}$、第 75 epoch $\approx 1.5\times10^{-4}$、第 100 epoch（终点）$=0$。

**曲线特征是「先缓降、中点加速、末端逼近零」**——它比「线性衰减」在早期多保留学习率（利于快速探索）、在后期平滑收敛（利于精调）。对比「Step 衰减」（每 30 epoch 除以 10）：余弦更平滑、无需手动选「在哪一步衰减」——**「余弦退火」把「衰减时机」变成了「自动的连续函数」，这就是它成为现代训练默认的原因之一**。<span class="marginnote">「预热（warmup）+ 退火」是现代大模型训练的标配组合：<strong>前几十步先「线性升温」到 $\eta_{\max}$，再进入余弦退火</strong>。为什么需要预热？训练初期参数离「稳定区」远，过大的学习率会让 BatchNorm 统计量剧烈抖动、或直接发散；先小幅探索「稳住统计」，再放大学习率「大步前进」。这个「先稳后冲」的节奏，正是《调参方法论》里「学习率几乎总最重要」的具体落地。</span>

## 6 实践决策表与小结

| 场景 | 推荐策略 |
| --- | --- |
| 小模型、快速验证 | 固定学习率 + 早停 |
| 中规模 CNN | Step 衰减或 ReduceLROnPlateau |
| 大 batch 训练 | 预热 + 线性缩放 + Step/余弦 |
| Transformer/大模型 | 预热（1–5% 步数）+ 余弦退火 |
| 需要周期性探索 | 带重启的余弦退火 |

- **核心直觉**：学习率策略 = 「先探索、后精修」的节拍器；噪声随学习率缩小。
- **衰减**：Step/指数/分数，简单有效；时机与幅度比公式更重要。
- **余弦退火**：平滑降到零，配预热是大模型标配；需要预设总步数。
- **预热**：小步起步，稳初始化、稳统计量；大 batch 与大模型必需。
- 「重启后的损失跳升」是设计行为，别误判为发散。

在下一节，我们让学习率「逐参数自适应」——每个维度拥有自己的步长，这就是 **AdaGrad 与 RMSProp**。
