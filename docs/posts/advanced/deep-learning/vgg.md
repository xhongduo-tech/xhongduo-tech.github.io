## 为什么从 VGG 开始

AlexNet 证明了「更大更深更好」，但它的大核（$11\times11$、$5\times5$）与不规则的层配置，让「深度」看起来像「玄学」：为什么是 8 层？为什么核大小不一？**VGG**（Simonyan & Zisserman, 2014）把「深度」从玄学变成**可系统探索的设计**：它规定了一个极简的构建单元——**连续堆叠的 $3\times3$ 卷积 + 一个池化**——然后只问一个问题：**堆多深会更好？** 答案是 VGG-16、VGG-19 这样的深度，把 ImageNet top-5 错误率压到 7.3%。

VGG 的贡献不在「某个新部件」，而在**设计方法**：**「块（block）」** 的抽象。它把「几层卷积 + 一次池化」打包成一个可复用的块，网络 = 块的序列。这个「模块化设计」思想成为此后一切 CNN（GoogLeNet 的 Inception 块、ResNet 的残差块）乃至 Transformer（encoder block）的通用语法——**「块」是现代神经网络的积木**。本节把 VGG 块的构造、深度探索的方法论、以及它「为什么用 3×3」的逻辑讲透。<span class="marginnote">VGG 论文的标题《Very Deep Convolutional Networks for Large-Scale Image Recognition》本身就是方法论的宣言：他们系统性实验了「深度的作用」，对比 11 层到 19 层的性能曲线，给出「深度确实带来提升、但存在收益递减」的经验规律。这种「把架构当作可系统搜索的空间」的思路，是深度学习从「手工作坊」走向「实验科学」的标志。</span>

## 1 VGG 块：3×3 卷积的重复 + 池化

**VGG 块（VGG block）**：连续 $n$ 个「$3\times3$ 卷积 + ReLU」，末尾接一个 $2\times2$ 最大池化。

```python
def vgg_block(num_convs, in_channels, out_channels):
    layers = []
    for _ in range(num_convs):
        layers.append(nn.Conv2d(in_channels, out_channels,
                                kernel_size=3, padding=1))
        layers.append(nn.ReLU())
        in_channels = out_channels
    layers.append(nn.MaxPool2d(kernel_size=2, stride=2))
    return nn.Sequential(*layers)
```

**为什么只用 $3\times3$？** 三层 $3\times3$ 的感受野 = $7\times7$（一层 $7\times7$ 的感受野），但参数只有 $\frac{3\times9}{49} \approx 55\%$，且多两次非线性（表达力更强）。**「用小核堆出大感受野，省参数、强非线性」**——这是 VGG 的核心设计原则。

**块内通道数如何变？** 每个块内通道数不变；**块之间通道翻倍**（64 → 128 → 256 → 512），同时空间尺寸减半。这条「**通道翻倍、空间减半**」的节奏，成为 CNN 设计最经典的「尺度法则」——它让特征图「越来越抽象、越来越浓缩」。<span class="marginnote">「空间减半、通道翻倍」背后的信息论直觉：空间上每降一次采样，损失一半位置信息，但通道翻倍让每个位置保留更多「特征种类」——<strong>用通道维的丰富度补偿空间维的损失</strong>。这个「面积减半、深度翻倍」的法则，在 VGG 之后的几乎所有网络里被沿用。</span>

**易错点：** VGG 块内**不做**降采样（卷积都是 padding=1、步幅 1），降采样完全由块末的池化完成。把「卷积（提特征）」与「池化（降采样）」在块内明确分工，是「块」设计的重要约定。

## 2 VGG 网络：块的堆叠

VGG 由「若干 VGG 块 + 全连接分类头」组成。以 VGG-16 为例（数字 16 = 13 卷积 + 3 全连接）：

| 阶段 | 配置 | 输出尺寸 |
| --- | --- | --- |
| 输入 | $224\times224\times3$ | — |
| 块 1 | 2×(3×3,64) + 池化 | $112\times112\times64$ |
| 块 2 | 2×(3×3,128) + 池化 | $56\times56\times128$ |
| 块 3 | 3×(3×3,256) + 池化 | $28\times28\times256$ |
| 块 4 | 3×(3×3,512) + 池化 | $14\times14\times512$ |
| 块 5 | 3×(3×3,512) + 池化 | $7\times7\times512$ |
| 分类头 | 摊平 + FC(4096) + FC(4096) + FC(1000) | $1\times1\times1000$ |

**规律**：块内卷积数从 2 逐步加到 3（深层块更「厚」）；通道 64→128→256→512 逐块翻倍；空间 224→112→56→28→14→7 逐块减半。**整个网络是一张「越来越窄、越来越深、通道越来越宽」的特征金字塔**。<span class="marginnote">VGG 的「参数大头」与 AlexNet 一样仍在全连接层（三个 FC 各 1 亿+ 参数，占总参数约 88%）。但 VGG 的意义在于证明了「<strong>深度本身有价值</strong>」——从 11 层到 19 层的逐层加深带来一致且显著的准确率提升（在 ImageNet 上），而参数量主要被「深度」而非「宽度」推动。</span>

**易错点：** VGG 的计算量很大（约 15–20 GFLOPs，是 AlexNet 的十几倍）——「深度」不是免费的。VGG 之后的架构（GoogLeNet、ResNet）纷纷在「同等深度下更省计算」上做文章，VGG 则被当作「精度基准」而非「效率模范」。

## 3 深度探索的方法论：为什么「深」有用

VGG 论文最有价值的部分是对「深度」的系统实验：

| 网络 | 层数 | ImageNet top-5 错误率 |
| --- | --- | --- |
| VGG-11 | 11 | 8.8% |
| VGG-13 | 13 | 8.2% |
| VGG-16 | 16 | 7.4% |
| VGG-19 | 19 | 7.3% |

**观察**：11→16 层，错误率稳步下降；16→19 层，提升几乎停滞——**深度带来收益，但收益递减**。为什么深有用？两个互补的解释：

1. **感受野与抽象**：更深的层看更大的有效感受野、抽象更高层的语义——「层层递进」的表达需要足够多的层。
2. **非线性复合**：每层一次非线性，深度 = 非线性的「复用」——深网络能以更少的参数表达同样复杂的函数（见《深度前馈网络》的组合复用）。

**「深度收益递减」的工程含义**：不是「越深越好」，而是「深度是资源，投入有上限」。在 VGG 的 19 层之后，继续加深开始遇到**梯度问题**——直到 ResNet 用残差连接把「可训练的深度」推进到 100+ 层。<span class="marginnote">「深度收益递减 + 梯度瓶颈」是 VGG 留给后人的未竟问题：它最深只到 19 层，再深就训不动（梯度消失）。ResNet（2015）用残差连接一举把可训练深度推到 152 层、甚至 1000+ 层——「VGG 定义了深度的价值，ResNet 解决了深度的瓶颈」。这条「价值→瓶颈→解决」的链条，是架构演进的标准节奏。</span>

**易错点：** 不要以为「VGG-19 一定优于 VGG-16」——它们在 ImageNet 上的差距只有 0.1%，而 19 层的计算量多 20%。**「更深」要权衡「更贵」**，工程上常常选「性价比最优」的版本而非「最深的版本」。

## 4 公式解析：3×3 堆叠的参数与感受野

把「3×3 堆叠」的省钱逻辑用数学算清。设堆 $L$ 层 $3\times3$ 卷积（通道数为 $C$），等价感受野为

$$
r = 2L + 1
$$

而一层 $r\times r$ 大核的参数（同样 $C$ 通道）为 $C^2 r^2$。

- **第一步，算小核参数**：$L$ 层 $3\times3$ 的参数 = $L \times 9 C^2$。
- **第二步，算等价大核参数**：一层 $r\times r$（$r=2L+1$）的参数 = $(2L+1)^2 C^2$。
- **第三步，对比**：$L=3$（$r=7$）时，小核参数 $= 27C^2$，大核参数 $= 49C^2$——**省约 45%**；且小核多 $L-1=2$ 次非线性。**「更少的参数 + 更强的非线性，达到同等的感受野」**，这就是 VGG 用 3×3 的全部理由。<span class="marginnote">这个「省参数 + 多非线性」的二重优势，是「小核深堆」在 VGG 之后的架构里被反复使用的根本原因。一个更极端的推论：$1\times1$ 卷积没有感受野，但用于「通道混合」（见《1×1 卷积》）；$3\times3$ 是「空间感知的最小核」，所以它成为 CNN 的「原子」。</span>

## 5 块（Block）思想的遗产

VGG 的「块」抽象是它最持久的遗产——此后几乎所有网络都用「块」作为构建单元：

**GoogLeNet**：Inception 块（多尺度并行）。
**ResNet**：残差块（恒等捷径）。
**Transformer**：Encoder Block / Decoder Block。

**「块 = 可复用的结构单元」** 让网络设计从「逐层搭积木」变成「组装标准化零件」：每一代架构本质上都是「发明一种更好的块 + 用块搭更深的网络」。理解「块」的思维，是读懂现代一切神经网络架构的第一把钥匙。<span class="marginnote">「块」思维的另一面是「可移植性」：一个在图像上验证的块（如残差块）可以被移植到其他模态（语音、图）；一个在 CNN 上发明的块思想（如「短接」）会被 Transformer 借用（残差）。<strong>架构创新往往是「块的创新」，而非「层的创新」</strong>——记住这一点，读新论文时先找它的「块」。</span>

**易错点：** VGG 的「块」里没有 BatchNorm（2014 年 BN 尚未问世）。复现时加 BN 通常更快更稳——但「加 BN 后的 VGG」已经不是「原版 VGG」。**「复现基准网络」时，要明确「哪些是现代增强、哪些是原版结构」**。

## 6 小结

- **VGG 块** = 连续 $3\times3$ 卷积 + ReLU + 池化；**空间减半、通道翻倍**的尺度法则。
- 三层 $3\times3$ = 一层 $7\times7$ 的感受野，但参数省 45%、非线性多 2 次。
- VGG-16/19 用深度系统探索证明「深度有价值，但收益递减」。
- 深度有用的解释：感受野扩大 + 非线性复用的表达力。
- 「块」思维是 VGG 最持久的遗产：此后 GoogLeNet/ResNet/Transformer 都用块搭建。
- 深度不是免费的——「更深」要权衡「更贵」，工程上选性价比最优的版本。

在下一节，我们看 VGG 之后第一个「不走寻常路」的架构——它发明了「网络中的网络」与全局平均池化，这就是 **NiN：网络中的网络与全局平均池化**。
