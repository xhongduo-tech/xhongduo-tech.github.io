## 为什么从性能指标与默认基准模型开始

模型训练好了，「好不好」怎么判断？**性能指标（performance metrics）**是把「模型行为」量化成「一个数」的尺子——但**选错尺子会误导一切**：类别不平衡时准确率会骗人，回归用错误尺度会掩盖系统偏差。而「默认基准模型（baseline）」则是你「新想法」的对照组——没有它，你无法判断「你的模型到底是好是坏」。本节把「指标设计」与「基线对比」这两件「实验的裁判工作」讲透——它们是「深度学习实验」的科学性基石。

「先定指标、再定基线、然后才训练模型」——这个「先设计评估，再开始实验」的顺序，是把深度学习从「调参玄学」变成「实验科学」的第一步。<span class="marginnote">「指标即目标」的警示：如果你用「准确率」当指标，模型会「优化准确率」——在类别不平衡时，这意味着「全预测多数类」（准确率高但没用）。「<strong>指标选择 = 对『什么重要』的声明</strong>」——「选错指标，优化错方向」是机器学习最常见的「成功但失败」。</span>

## 1 分类指标：准确率不是唯一

**准确率（accuracy）**：预测正确的比例——但它在**类别不平衡**时极具误导性。

**混淆矩阵（confusion matrix）**：分类结果的四象限——真正例（TP）、假正例（FP）、真负例（TN）、假负例（FN）。从它派生出核心指标：

| 指标 | 公式 | 回答的问题 |
| --- | --- | --- |
| 准确率 | $\frac{TP+TN}{TP+FP+TN+FN}$ | 全部里对多少 |
| 精确率（precision） | $\frac{TP}{TP+FP}$ | 预测「正」的里真有几个正 |
| 召回率（recall） | $\frac{TP}{TP+FN}$ | 真正的「正」里抓到几个 |
| F1 | $\frac{2\cdot P\cdot R}{P+R}$ | 精确率与召回率的调和平均 |

**精确率 vs 召回率的权衡**：精确率高 = 「预测的正基本都对」（宁缺毋滥）；召回率高 = 「真正的正基本都抓到」（宁滥毋缺）——**两者此消彼长**（提高阈值 → 精确率升、召回率降）。F1 用「调和平均」平衡两者（对「极端值」敏感——一个为 0 则 F1 为 0）。

**什么时候用什么**：

- **垃圾邮件过滤**：重精确率（别把正常邮件误杀）。
- **癌症筛查**：重召回率（别漏掉癌症患者）。
- **两者都重要**：F1。

**易错点：** 「准确率」在类别不平衡时失真——99% 正常、1% 异常时，全预测「正常」有 99% 准确率但毫无用处。**「看混淆矩阵 + 精确率/召回率，别只看准确率」**是分类评估的第一纪律。<span class="marginnote">「不平衡数据的『99% 陷阱』」：类别不平衡时，准确率会被「多数类」主导——「<strong>模型只要『学会说多数类』就能拿高分</strong>」。破解：看「少数类的精确率/召回率」、用「平衡准确率」「AUC」，或对少数类加权损失。「<strong>指标要匹配『任务的真实目标』</strong>」——「医疗筛查重召回、垃圾过滤重精确」是「指标随任务」的经典案例。</span>

## 2 排序指标：AUC 与 top-k

很多任务不是「二分类」而是「排序」——「把正样本排在前面」。此时用**排序指标**：

**AUC（Area Under the ROC Curve）**：ROC 曲线的面积——「随机抽一个正样本、一个负样本，正样本得分高于负样本的概率」。AUC = 0.5 是瞎猜、1.0 是完美、0.5–0.7 较差、0.7–0.9 较好、0.9+ 优秀。

**AUC 的优点**：**阈值无关**（不依赖「预测 > 0.5 才算正」的阈值）、**类别不平衡鲁棒**（对正负比例不敏感）。

**top-k 准确率**：预测的「前 k 个」里是否包含正确类别——ImageNet 的 top-5、推荐系统的「top-k 命中率」。

**易错点：** AUC 对「排序质量」敏感、对「校准」不敏感——**「AUC 高不代表概率校准好」（见《Softmax 回归》的校准问题）**。选「排序指标」还是「阈值指标」取决于任务——「检索/推荐看排序，筛查/过滤看阈值」。<span class="marginnote">「ROC 曲线 vs PR 曲线」：ROC（真正例率 vs 假正例率）在「类别极不平衡」时会「虚高」（负样本太多，假正例率被稀释）；PR 曲线（精确率 vs 召回率）对不平衡更敏感——「<strong>不平衡数据看 PR 的 AUC（AP），平衡数据看 ROC 的 AUC</strong>」——「指标的选择也要看『数据平衡度』」。</span>

## 3 回归指标：MSE、MAE 与 R²

**回归**的输出是连续值，指标与分类完全不同：

| 指标 | 公式 | 特点 |
| --- | --- | --- |
| MSE（均方误差） | $\frac{1}{n}\sum(y-\hat{y})^2$ | 惩罚大误差（平方放大）；对离群点敏感 |
| MAE（平均绝对误差） | $\frac{1}{n}\sum\|y-\hat{y}\|$ | 对大误差不放大；更鲁棒 |
| R²（决定系数） | $1-\frac{SS_{\text{res}}}{SS_{\text{tot}}}$ | 「模型解释了多大比例的方法」；1 = 完美 |

**MSE vs MAE**：MSE「平方」放大离群点（大误差被重罚）、MAE「绝对」一视同仁（鲁棒但梯度在零处不可导）。**「选 MSE 还是 MAE」取决于「大误差是否不可容忍」**——「房价预测」大误差（差 100 万）与「小误差」（差 1 万）的代价不同。

**易错点：** MSE 的「单位」是「平方」的（不好直接解释）——报告回归结果常配「RMSE」（开根号，单位还原）。**「指标的『可解释性』也是选择标准」**——「RMSE 比 MSE 好解释，R² 给『解释比例』」。<span class="marginnote">「回归指标的『尺度依赖』」：MSE/MAE 的单位随「预测目标的尺度」变化（预测「房价（万）」vs「温度（度）」的 MSE 不可比）——「<strong>跨任务比较回归指标要用『归一化』的形式</strong>」（如 R² 或「归一化的 RMSE」）。「指标的可比性」是「跨模型/跨任务评估」的前提。</span>

## 4 默认基准模型：没有基线的实验是自嗨

**基准模型（baseline）**：你的「新模型」要超越的「参考对象」——它是实验的「对照组」。

**为什么必须有基线？** 没有基线，你不知道「模型的 90% 准确率」是「好」还是「差」——也许一个「简单的线性模型」就有 89%。**「基线给出了『改进幅度的参照』」**。

**常见基线类型**：

1. **平凡基线**：多数类预测（分类）、均值预测（回归）——「模型至少要比『瞎猜』好」。
2. **简单模型基线**：线性回归、逻辑回归——「深度模型至少要比『简单模型』好」。
3. **经典模型基线**：SVM、随机森林、XGBoost——「深度模型 vs 传统模型」。
4. **SOTA 基线**：当前最佳方法——「你的新方法 vs 当前最先进」。

**「基线选择决定结论」**：对「强基线」只提升 0.1% 与对「弱基线」提升 20%，结论完全不同——**「挑弱基线会夸大贡献、挑强基线才诚实」**。<span class="marginnote">「基线选择的『科学伦理』」：一个诚实的研究报告，基线要「公平」（同数据、同预处理、同超参搜索）——「<strong>用『弱基线』衬托『强模型』是夸大；用『强基线』对比才可信</strong>」。深度学习研究的「复现危机」部分源于「基线设置不当」——「基线是实验的『公平性』的锚点」。</span>

**易错点：** 基线模型也要「调参」——「拿一个没调参的 XGBoost 当基线，然后说『我的深度模型赢了』」是不公平的。**「基线要『尽力调好』，你的模型才有『可信的超越』」**。

## 5 实践流程：先定指标与基线

把「指标 + 基线」落到实验流程：

1. **定指标**：根据「任务目标」选指标（不平衡用 PR/AUC、回归用 RMSE/R²）——「指标 = 目标的操作化」。
2. **建基线**：从「平凡基线」开始，再跑「简单模型」——「逐级递进的参照系」。
3. **跑实验**：你的模型与基线**同一数据、同一预处理、同一评估**——「公平对比」。
4. **看差距**：统计显著性（多次重复实验的均值与方差）——「提升是不是真的」。

**「实验的『裁判』是『指标 + 基线』的组合」**——「先立裁判，再上擂台」，是「深度学习实验科学」的第一课。<span class="marginnote">「统计显著性的『常识』」：一次实验的「0.5% 提升」可能是「随机波动」（换随机种子结果不同）——「<strong>跑多次实验（不同种子），报告均值 ± 标准差，别只看单次结果</strong>」。这个「重复实验」的纪律，是「深度学习的『可复现性』」的底线（与《超参数与交叉验证》的「验证集纪律」呼应）。</span>

**易错点：** 「指标好」≠「部署成功」——「离线指标」（测试集）与「在线表现」（真实环境）常常不一致（数据分布漂移）。**「离线指标是『门槛』，在线表现是『真相』」**——「先过门槛，再验真相」。

## 6 小结

- **分类指标**：准确率（不平衡时误导）、精确率/召回率（此消彼长）、F1（调和平衡）——「指标随任务」。
- **排序指标**：AUC（阈值无关、不平衡鲁棒）、top-k——「检索/推荐看排序」。
- **回归指标**：MSE（放大离群点）、MAE（鲁棒）、R²（解释比例）——「选指标=选代价」。
- **基准模型**：平凡 → 简单 → 经典 → SOTA——「基线是实验的对照与公平性的锚」。
- 流程：先定指标与基线，再训练——「先立裁判，再上擂台」。
- 「指标好 ≠ 部署成功」——离线指标是门槛，在线表现是真相。
