## 为什么从数据预处理开始

模型再强，也吃不下「原始数据」：图像像素值 0–255、文本是离散 token、表格数据含缺失值与不同尺度。**数据预处理（data preprocessing）**把「原始数据」变成「模型能吃的格式」——它是「数据 → 模型」的最后一公里，也是最容易被忽视的「隐形性能杠杆」：同样的模型，预处理得当与粗糙，性能可以差几个百分点。

本节覆盖预处理的三大块：**数值缩放**（归一化/标准化）、**缺失与类别处理**（缺失值填充、类别编码）、**增强策略**（何时用哪些增强）。理解预处理的「为什么」比「怎么做」更重要——**「缩放改变优化地形」「缺失填充影响偏差」「增强注入先验」**——预处理不是「机械步骤」，而是「有语义的数据工程」。<span class="marginnote">「预处理的『为什么』」：每个预处理步骤都有「隐藏的机制」——归一化「改善条件数（优化）」、类别编码「让符号可计算」、数据增强「注入不变性（正则）」。「<strong>理解『为什么预处理』，你才能判断『什么时候预处理会反噬』</strong>」——预处理不是「照抄流程」，而是「匹配数据与模型」的工程决策。</span>

## 1 归一化与标准化：让特征「同尺度」

**归一化（normalization）**与**标准化（standardization）**都做「特征缩放」，但目标不同：

**标准化（standardization / z-score）**：让特征「零均值、单位方差」：

$$
x' = \frac{x - \mu}{\sigma}
$$

**归一化（min-max normalization）**：让特征「缩放到 $[0,1]$」：

$$
x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}}
$$

**为什么需要缩放？** 三个理由：

1. **优化地形**：特征尺度悬殊 → 损失曲面「拉长」→ 梯度下降震荡（病态条件，见《优化问题》）。缩放到同尺度 → 地形更「圆」→ 优化更快更稳。
2. **正则公平**：L2 正则对「大尺度特征」惩罚更重（权重被特征尺度放大）——缩放让正则「公平对待」所有特征。
3. **数值稳定**：避免「大数 × 大数」溢出。

**易错点：** 统计量（$\mu, \sigma, x_{\min}, x_{\max}$）**必须在训练集上计算**，测试集用「训练集的统计量」缩放——**「绝不用测试集算统计量」**（否则泄漏信息）。「<strong>统计量从训练集来，应用到所有数据</strong>」是预处理的铁律。<span class="marginnote">「缩放与优化的『条件数』」：两个特征一个范围 0–1、一个范围 0–10000，损失曲面在「大尺度特征方向」极陡、另一方向极缓——梯度下降「顾此失彼」（见《优化问题的病态条件》）。「<strong>标准化 ≈ 给损失曲面『整容』，让各方向尺度均衡</strong>」——「预处理直接改善优化，不只是『格式转换』」。</span>

**易错点二：** 图像数据用「像素归一化」（除以 255 或标准化）——但**对图像而言，均值/方差来自「数据集统计」**（如 ImageNet 的均值/方差是公开常数）。「图像的『数据集标准化』是标准做法」。

## 2 缺失值与类别特征

**缺失值（missing values）**处理——「数据里有洞，怎么补」：

| 策略 | 做法 | 适用 |
| --- | --- | --- |
| 删除 | 删掉含缺失的行/列 | 缺失少、删除不影响样本量 |
| 均值/中位数填充 | 用列均值/中位数补 | 数值特征、缺失随机 |
| 插值 | 用前后值/回归插值 | 时间序列、有结构的数据 |
| 模型预测 | 用其他特征预测缺失值 | 缺失有规律、数据充分 |

**「填充方式影响偏差」**：均值填充「低估方差」（把缺失值推向中心）、删除「丢失信息」——**「没有『免费』的填充，每个策略都有偏差」**。

**类别特征（categorical features）**编码——「符号怎么变成数」：

**独热编码（one-hot）**：类别 → 向量（1 个 1、其余 0）——「类别无序时」。
**标签编码（label encoding）**：类别 → 整数（0,1,2,…）——「类别有序时」（如「小/中/大」）。
**嵌入（embedding）**：类别 → 可学习向量——「类别很多时」（用户 ID、商品 ID）。

**易错点：** 独热编码的「维度灾难」——类别数很大（如用户 ID 百万个）时，独热向量爆炸——**「高基数类别用嵌入或目标编码」**。而「标签编码」如果类别**无序**，会给「类别」强加「顺序」（模型可能学「3 > 2」）——**「无序类别用独热，有序类别才用标签」**。<span class="marginnote">「高基数类别的『嵌入』」：用户 ID 有 1000 万个，独热是 1000 万维（灾难）；嵌入把它变成「可学习的 100 维向量」——「<strong>嵌入 = 高基数类别的『降维编码』</strong>」（推荐系统的核心技巧，见《词嵌入》的「嵌入 = 符号 → 向量」）。「类别编码的选择 = 基数与语义的函数」。</span>

## 3 数据增强策略：什么时候用哪些

**数据增强（data augmentation）**（见《数据集增强与噪声鲁棒性》）在预处理里的「策略」问题：

**图像增强的层次**：

1. **几何**：翻转、旋转、裁剪、缩放——「位置/姿态不变性」。
2. **颜色**：亮度、对比度、颜色抖动——「光照不变性」。
3. **混合**：Mixup、CutMix——「组合语义」。
4. **掩码**：Cutout、随机遮挡——「鲁棒性」。

**增强的「策略」原则**：

**匹配任务**：翻转对「b/d 识别」有害（会改变语义）——「增强必须保持标签语义」。
**强度随数据量**：数据少 → 强增强（救命）；数据多 → 弱增强（避免失真）。
**测试时增强（TTA）**：测试时对输入做多种增强、平均预测——「免费的推理提升」。

**易错点：** 增强是「训练时的正则」，**测试时**不能「随机增强」（会引入不确定性）——除非是「测试时增强（TTA）」这种「确定性多视图平均」。**「训练随机增强、测试确定性」**是增强的纪律。<span class="marginnote">「TTA 的『集成视角』」：测试时增强（对同一张图做多种增强、平均预测）本质是「<strong>多个增强视图的『模型集成』</strong>」——「不同视角的预测平均，比单视角稳定」。TTA 是「免费的泛化提升」（不训练、只推理），在「医学影像」等「低容错」场景尤其常用——「<strong>用『多视角』换『稳健性』</strong>」。</span>

## 4 公式解析：标准化的「优化地形」效应

把「标准化」对优化的影响用数学看穿。设两个特征 $x_1, x_2$ 尺度悬殊（$x_1$ 范围 1、$x_2$ 范围 $10^4$），线性模型 $y = w_1 x_1 + w_2 x_2$。损失对权重的曲率：

$$
\frac{\partial^2 L}{\partial w_i^2} = \mathbb{E}\big[x_i^2\big]
$$

- **第一步，看曲率比**：$\frac{\partial^2 L/\partial w_2^2}{\partial^2 L/\partial w_1^2} = \frac{\mathbb{E}[x_2^2]}{\mathbb{E}[x_1^2]} \approx 10^8$——**两个方向的曲率差 8 个数量级**（病态条件）。
- **第二步，看梯度下降**：沿 $w_2$（大尺度特征）方向梯度巨大（震荡）、沿 $w_1$ 方向梯度微小（龟爬）——「一个学习率无法同时适配两个方向」。
- **第三步，读标准化**：标准化后 $\mathbb{E}[x_i^2] = 1$（单位方差）——**曲率比回到 1**，各方向均衡——「<strong>标准化 = 把条件数从 $10^8$ 拉到 1</strong>」。<span class="marginnote">「曲率分析的另一面」：自适应优化器（Adam/RMSProp）本身也能「逐维缩放」缓解病态条件——所以「用 Adam 时标准化的重要性下降」——「<strong>优化器越『自适应』，对预处理的依赖越小</strong>」。但「标准化」仍是「便宜且有效」的默认做法——「先标准化，再用任何优化器都不吃亏」。</span>

**易错点：** 标准化的「$\mu, \sigma$」对「离群点」敏感——数据含大离群点时，均值/方差被拉偏，标准化反而「放大离群点的干扰」。**「离群点多时，用『鲁棒缩放』（中位数 + IQR）」**。

## 5 预处理的完整流程

把预处理的步骤串成「标准流水线」：

1. **探索**：看数据分布、缺失、离群——「先了解，再处理」。
2. **清洗**：处理缺失、去重、修错误——「数据质量是地基」。
3. **编码**：类别特征 → 独热/嵌入——「符号变数」。
4. **缩放**：数值特征 → 标准化/归一化——「同尺度」。
5. **增强**：训练时数据增强——「注入不变性」。
6. **划分**：训练/验证/测试（分层）——「公平评估」。

**「预处理的『可复现性』」**：整个流水线要**固化**（同一套统计量、同一套增强参数）——「预处理不一致，实验不可复现」。「<strong>预处理是实验的一部分，要像模型一样『版本化』</strong>」。<span class="marginnote">「预处理的『管道化』」：现代实践用「预处理管道」（如 sklearn 的 `Pipeline`、PyTorch 的 `transforms.Compose`）把「统计量计算 → 变换 → 增强」串成「可复用、可保存」的对象——「<strong>管道 = 预处理的『可复现封装』</strong>」。保存「训练时的统计量」随模型一起部署——「部署时用『训练时的预处理』，不能用『新的统计量』」。</span>

**易错点：** 预处理与「数据泄漏」——若「统计量」用了「包含测试集的数据」算，模型「偷看」了测试分布（评估失真）。**「统计量只从训练集来」**是防泄漏的第一规则（前面已强调，但值得重复——它是「最常见的数据泄漏」）。

## 6 小结

- **标准化/归一化**：让特征同尺度——「改善条件数（优化）、公平正则、数值稳定」。
- 统计量从训练集算、应用到所有数据——「防数据泄漏」的铁律。
- **缺失值**：删除/填充/插值/预测——「没有免费填充，每个策略有偏差」。
- **类别编码**：无序用独热、有序用标签、高基数用嵌入——「编码 = 基数与语义的函数」。
- **增强策略**：匹配任务、强度随数据量、测试时确定性——「TTA 是免费的推理提升」。
- 预处理是实验的一部分——「管道化、版本化、防泄漏」。
