## 为什么从损失函数设计开始

前面几节我们「随手」用了 MSE 和交叉熵，但没回答一个根本问题：**为什么分类用交叉熵、回归用 MSE？换个损失行不行？** 花书给出的答案深刻而统一：**几乎所有损失函数，都来自同一个原理——最大似然估计（MLE）**。你选什么损失，等价于你假设「数据是怎么生成的」，然后让模型去最大化生成这批数据的概率。

这个视角把「选损失」从「试出来的经验」升华为「可推导的设计」：给定任务，先决定输出单元（它编码了条件分布 $P(y \mid \boldsymbol{x})$ 的形态），损失函数就被最大似然原理唯一地决定。本节把「输出单元 + 损失函数」作为一个整体来设计：**输出单元是分布的形状，损失是分布的负对数似然**。<span class="marginnote">这是第一篇《最大似然估计与贝叶斯统计》在神经网络里的落地：网络输出的不再是「答案」，而是「条件分布的参数」。这个视角在后面处处有用——VAE 的重构损失、扩散模型的噪声预测、GAN 的判别器，全部是「输出单元 + 似然」的不同组合。</span>

## 1 统一框架：损失 = 负对数似然

设网络输出为 $\boldsymbol{o}$，通过输出单元把它解释为条件分布 $p(\boldsymbol{y} \mid \boldsymbol{x}; \boldsymbol{\theta})$ 的参数，那么训练目标就是**最大化训练集的对数似然**：

$$
\boldsymbol{\theta}^* = \arg\max_{\boldsymbol{\theta}} \sum_{i=1}^{n} \log p\big(\boldsymbol{y}^{(i)} \mid \boldsymbol{x}^{(i)}; \boldsymbol{\theta}\big)
$$

等价地，**损失函数定义为负对数似然（negative log-likelihood, NLL）**：

$$
L(\boldsymbol{\theta}) = -\mathbb{E}_{(\boldsymbol{x},\boldsymbol{y}) \sim \hat{p}_{\text{data}}} \log p(\boldsymbol{y} \mid \boldsymbol{x}; \boldsymbol{\theta})
$$

三步拆解这个统一框架：

- **第一步，看语义**：$\hat{p}_{\text{data}}$ 是训练集的经验分布。期望就是对样本平均，最大化似然就是最小化平均负对数似然。
- **第二步，看与 KL 的关系**：最小化 NLL 等价于最小化 $D_{\text{KL}}(p_{\text{data}} \,\|\, p_{\text{model}})$（多一个常数项）——**训练就是在把模型分布拉向数据分布**。
- **第三步，看为什么好**：NLL 损失的梯度性质优秀——它在模型「信心十足却错误」时给出巨大梯度（$\log$ 在概率趋零时发散），惩罚极狠；且 NLL 与很多输出单元组合后，梯度形式简洁稳定（如 Softmax + 交叉熵的梯度是 $\hat{y}-y$）。<span class="marginnote">NLL 相比「平方误差直接怼概率」的核心优势：平方误差对「概率」这种有界量做回归，梯度会被压缩（概率接近 0/1 时梯度趋零）；而 NLL 的 $\log$ 把「概率的指数压缩」重新拉开，梯度始终与「预测差了多少」成正比——这就是「分类别用 MSE」的深层原因。</span>

## 2 回归的输出单元：线性单元 + 高斯似然

**回归任务**：$y$ 是连续实数。最自然的假设是**输出服从高斯分布**，均值由网络给出，方差固定：

$$
p(y \mid \boldsymbol{x}) = \mathcal{N}\big(y; \hat{y}(\boldsymbol{x}), \sigma^2\big), \qquad \hat{y}(\boldsymbol{x}) = \boldsymbol{w}^{\top}\boldsymbol{h} + b
$$

输出单元就是**线性单元**（无激活函数），直接输出均值 $\hat{y}$。

代入 NLL 并丢掉与 $\boldsymbol{\theta}$ 无关的常数项，得到**均方误差**：

$$
L = \frac{1}{2}\big(y - \hat{y}\big)^2 \quad\Longleftrightarrow\quad -\log p(y \mid \boldsymbol{x}) = \frac{1}{2}\log(2\pi\sigma^2) + \frac{(y-\hat{y})^2}{2\sigma^2}
$$

**这就是 MSE 的完整来历**：它不是「随手选的度量」，而是「高斯噪声假设」下的负对数似然。若噪声不是高斯而是拉普拉斯分布，NLL 会给出 L1 损失 $|y-\hat{y}|$——**换噪声假设，损失随之改变**。<span class="marginnote">一个实用推论：如果回归数据的误差分布长尾（有离群点），高斯假设下的 MSE 会被离群点主导，此时改用 L1（Huber 损失更稳）是「换更鲁棒的噪声假设」。鲁棒损失设计在统计里是专门课题，见第二级《数理统计》与《最优化理论》。</span>

**易错点：** 线性输出单元无上界，这意味着模型可以输出任意实数。若把回归标签归一化到 $[0,1]$ 再用线性单元 + MSE，模型可能输出越界的预测——「归一化标签 + 有界激活」还是「保持线性 + 原尺度标签」，要在预处理时就统一。

## 3 二分类的输出单元：Sigmoid + 伯努利似然

**二分类**：$y \in \{0,1\}$，自然假设是**伯努利分布**，其参数（成功概率）由网络输出：

$$
p(y \mid \boldsymbol{x}) = \hat{y}^y (1-\hat{y})^{1-y}, \qquad \hat{y} = \sigma(\boldsymbol{o})
$$

Sigmoid 把 logit $\boldsymbol{o}$ 压缩到 $(0,1)$。NLL 损失展开：

$$
L = -y \log \hat{y} - (1-y) \log(1-\hat{y})
$$

这就是**二元交叉熵（binary cross-entropy）**。它的梯度特别漂亮：$\frac{\partial L}{\partial \boldsymbol{o}} = \hat{y} - y$——**预测概率减真实标签**。这意味着：预测偏高（$\hat{y} > y$）就往低调，偏低就往上调，调整量与误差成正比。梯度里指数项全部抵消，数值极稳定。

**易错点：** 工程上应直接对 logits 用 `BCEWithLogitsLoss`（内部融合 Sigmoid + 交叉熵），而不要先 `sigmoid` 再 `BCELoss`——后者在 $\hat{y}$ 接近 0 或 1 时遭遇 $\log$ 的数值灾难（`log(0)`）。与 Softmax 的情形完全同构。<span class="marginnote">二分类的 Sigmoid 与多分类的 Softmax 是同一枚硬币：Softmax 是「竞争式」归一化（所有类概率和为 1），Sigmoid 是「独立式」概率（每类各自 $(0,1)$，互不相干）。多标签分类（一张图同时有猫和狗）必须用 Sigmoid，因为多个标签可以同时为 1——这是「用哪个输出单元」的经典决策点。</span>

## 4 多分类的输出单元：Softmax + 多项分布

**多分类**：$y \in \{1,\dots,k\}$，假设**多项分布（multinoulli）**，Softmax 输出各类别概率：

$$
p(\boldsymbol{y} \mid \boldsymbol{x}) = \text{softmax}(\boldsymbol{o})_y = \frac{\exp(o_y)}{\sum_j \exp(o_j)}
$$

NLL 损失（上一节已见）为：

$$
L = -\log \hat{y}_{\text{true}} = -\log \text{softmax}(\boldsymbol{o})_{\text{true}}
$$

**为什么用指数族分布而不用「直接回归到独热向量」？** 因为 Softmax 天然保证输出是一个合法的概率分布（非负、和为一），而直接对独热向量做最小二乘会给出无界、可能为负的输出。更本质地：**Softmax 对应「类间竞争」的逻辑，每个类别都在抢夺概率质量**——这正是分类任务的语义。

把三类任务的「分布假设 → 输出单元 → 损失」汇总成一张总表：

| 任务 | 分布假设 | 输出单元 | 损失（NLL） |
| --- | --- | --- | --- |
| 回归 | 高斯 | 线性 | MSE |
| 回归（鲁棒） | 拉普拉斯 | 线性 | L1 / Huber |
| 二分类 | 伯努利 | Sigmoid | 二元交叉熵 |
| 多分类 | 多项 | Softmax | 交叉熵 |
| 多标签分类 | 独立伯努利 | 多个 Sigmoid | 各维度 BCE 之和 |

## 5 设计损失时的「最大似然」纪律

把本节的方法论提炼成操作纪律，写模型前先走一遍：

1. **先声明输出语义**：这个问题输出是「实数」「0/1 概率」还是「各类别分布」？
2. **选分布假设**：由输出语义定，如回归→高斯、二分类→伯努利、多分类→多项。
3. **定输出单元**：分布的形状决定激活——线性、Sigmoid、Softmax。
4. **损失即负对数似然**：不要「发明」损失，从 NLL 推导；若想用自定义损失，先问它对应什么分布假设、梯度行为是否健康。

**易错点一：给分类配 MSE。** 概率是有界的（$(0,1)$），对概率做平方回归会让梯度在饱和区消失，且优化面非凸。交叉熵是分类的默认，没有之一。

**易错点二：给回归配分类损失。** 回归没有「类别」，套交叉熵需要先离散化标签——除非确实想做「分桶回归」，否则是画蛇添足。

**易错点三：忽略标签噪声。** 真实数据标签常有错（如人工标注错误）。NLL 会对「错标签」给出巨大惩罚。缓解手段：标签平滑（把独热换成 $\epsilon$ 注入均匀分布）——它等价于「承认标签可能错」，在分类任务里几乎是免费的正则。<span class="marginnote">标签平滑（label smoothing）在大型语言模型里已成为标配：训练时把真实标签从 1 替换为 $1-\epsilon + \epsilon/k$，防止模型对训练标签过度自信，换取校准更好、泛化更强的模型——详见第六篇《BERT》与《预训练任务设计》中关于训练技巧的讨论。</span>

## 6 小结

- **统一原理**：损失 = 负对数似然；选损失 = 声明「数据如何生成」。
- 回归 → **高斯假设 → 线性单元 + MSE**；换拉普拉斯假设 → L1/Huber。
- 二分类 → **伯努利假设 → Sigmoid + 二元交叉熵**，梯度 $\hat{y}-y$。
- 多分类 → **多项分布 → Softmax + 交叉熵**；多标签 → 多个独立 Sigmoid。
- Softmax 输出合法分布且带类间竞争，比「回归独热向量」合理。
- 纪律：先定输出语义 → 定分布 → 定输出单元 → 从 NLL 得损失。
