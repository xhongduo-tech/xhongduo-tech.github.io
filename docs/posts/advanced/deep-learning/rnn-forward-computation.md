## 为什么从循环神经网络的结构与前向计算开始

n-gram 用「固定长度的记忆」处理序列，被「记忆长度」锁死。**循环神经网络（Recurrent Neural Network, RNN）**给出了「可变长记忆」的方案：它在每个时间步维护一个**隐状态（hidden state）**，这个状态像一条「滚动的河流」——每个时间步读取新输入、更新记忆、输出预测。因为隐状态会「一直携带前文信息」，RNN 理论上可以记住任意远的过去。

RNN 的核心思想是**权重跨时间共享**：处理第 1 个词与第 100 个词用的是**同一组权重**。这既符合「时间平移不变」的先验（词的处理规则不该随位置改变），也是 RNN 参数量可控的原因。本节把 RNN 的结构、前向计算的展开（unfold）、以及它相对前馈网络的本质区别讲透。<span class="marginnote">「RNN = 时间维上的参数共享」与「CNN = 空间维上的参数共享」是完美对偶的两个结构：CNN 在空间上共享核，RNN 在时间上共享权重。这个「在哪个维度共享 = 对哪个维度的平移不变」的视角（见《参数绑定与参数共享》），是理解一切序列结构的第一性原理。</span>

## 1 隐状态：滚动的记忆

**RNN 的核心结构**：在时间步 $t$，输入 $x_t$（如第 $t$ 个词的嵌入），前一个隐状态 $\boldsymbol{h}_{t-1}$，两者共同计算新隐状态 $\boldsymbol{h}_t$ 与输出 $o_t$：

$$
\boldsymbol{h}_t = \tanh\big(\boldsymbol{W}_{hx}\boldsymbol{x}_t + \boldsymbol{W}_{hh}\boldsymbol{h}_{t-1} + \boldsymbol{b}_h\big)
$$

$$
\boldsymbol{o}_t = \boldsymbol{W}_{oh}\boldsymbol{h}_t + \boldsymbol{b}_o
$$

**隐状态 $\boldsymbol{h}_t$ 是 RNN 的记忆**：它编码了「从序列开头到第 $t$ 步」的所有信息（以压缩形式）。注意两个权重矩阵的角色：

- $\boldsymbol{W}_{hx}$：把**当前输入**投影进隐状态空间。
- $\boldsymbol{W}_{hh}$：把**上一时刻的记忆**递进到当前时刻——**这就是「循环」**：$h$ 既依赖输入，也依赖自己（上一时刻）。

**「循环」的本质**：$\boldsymbol{h}_t$ 的定义里含 $\boldsymbol{h}_{t-1}$，而 $\boldsymbol{h}_{t-1}$ 又含 $\boldsymbol{h}_{t-2}$……**隐状态把「整个历史」压缩进一个固定维向量**。这是 RNN 记忆任意长历史的机制——但也埋下了梯度问题的伏笔（同一矩阵 $\boldsymbol{W}_{hh}$ 反复相乘，见《通过时间的反向传播》）。<span class="marginnote">「$\tanh$ 的选择」：隐状态更新用 $\tanh$ 而非 ReLU，是 RNN 的经典选择——$\tanh$ 输出在 $(-1,1)$，有界、可正可负，适合「累积性记忆」（记忆可以是「增强」也可以是「抑制」）；ReLU 无上界，累加容易发散。这个「记忆用有界激活」的原则，是理解 LSTM 门控的铺垫。</span>

## 2 前向计算的展开：把循环画成时间线

RNN 的「循环」在计算时被**展开（unfold）**成一张沿时间轴的前馈图——第 $t$ 步的计算依赖第 $t-1$ 步的输出，串行推进：

```
h0 → h1 → h2 → h3 → ... → hT
      ↕     ↕     ↕          ↕
     o1    o2    o3         oT
      ↕     ↕     ↕          ↕
     x1    x2    x3         xT
```

**展开后的 RNN 等价于一个「权重共享的超深前馈网络」**：时间步 $T$ 的 RNN ≈ 深度 $T$ 的前馈网络，且每一层（时间步）用同一组权重。这个等价关系有两个推论：

1. **反向传播 = 沿展开图的链式法则**：就是「通过时间的反向传播（BPTT）」（下一篇）。
2. **梯度问题与深度网络同源**：展开后是「深层」网络，梯度消失/爆炸同样出现——且因为权重共享，$\boldsymbol{W}_{hh}$ 反复相乘使问题更尖锐。

**易错点：** RNN 的「展开」是**计算上的展开**，不是「复制权重」——展开图里的每一层**共享同一组参数**。把「展开」误解为「每步独立参数」，就会漏掉梯度累加（BPTT 的「+" 规则），实现必然出错。

## 3 RNN 的输入输出模式：多种「映射」

RNN 的「输入输出」可以组合出多种序列映射，按任务分类：

| 模式 | 输入→输出 | 典型任务 |
| --- | --- | --- |
| 多对一 | 序列 → 一个输出 | 情感分类、序列分类 |
| 一对多 | 一个输入 → 序列 | 图像描述、音乐生成 |
| 多对多（同步） | 序列 → 等长序列 | 逐词标注（POS tagging） |
| 多对多（异步） | 序列 → 变长序列 | 机器翻译（Seq2Seq） |

**「多对一」**：只取最后一步的隐状态 $\boldsymbol{h}_T$ 作为「整个序列的摘要」，接分类头——RNN 当「序列编码器」。
**「一对多」**：从初始输入出发，每步把「上一步输出」当「下一步输入」——RNN 当「序列生成器」。
**「异步多对多」**：编码器读完整个序列，解码器逐步生成（Seq2Seq，见后续）。

**「输入输出模式」由任务决定，结构相同**——同一个 RNN 骨架，接不同的输入输出头，就变成不同的模型。<span class="marginnote">「多对一」的「最后隐状态 = 序列摘要」有个著名局限：最后状态必须「装下」整个序列的信息，长序列时早期信息被「挤」掉（遗忘）。这个「压缩瓶颈」是注意力机制（第五篇末）要解决的问题——注意力让解码器「直接看」编码器的每一步，而不是只依赖最后状态。</span>

**易错点：** 「一对多」生成的**训练**与**推断**不同：训练时用「真实上一步词」作为输入（教师强制，teacher forcing），推断时用「自己上一步的输出」。这个「训练/推断输入来源不一致」是生成模型的经典痛点（曝光偏差），Seq2Seq 一节会展开。

## 4 公式解析：单步前向的维度走查

把 RNN 单步前向的维度完整走一遍，防止实现出错。设词嵌入维 $d$、隐状态维 $h$：

$$
\boldsymbol{h}_t = \tanh\big(\underbrace{\boldsymbol{W}_{hx}}_{h\times d}\underbrace{\boldsymbol{x}_t}_{d} + \underbrace{\boldsymbol{W}_{hh}}_{h\times h}\underbrace{\boldsymbol{h}_{t-1}}_{h} + \underbrace{\boldsymbol{b}_h}_{h}\big) \in \mathbb{R}^h
$$

- **第一步，看输入投影**：$\boldsymbol{W}_{hx}\boldsymbol{x}_t$ 是 $h\times d$ 乘 $d$ 得 $h$ 维——「把词嵌入变换到隐状态空间」。
- **第二步，看记忆递进**：$\boldsymbol{W}_{hh}\boldsymbol{h}_{t-1}$ 是 $h\times h$ 乘 $h$ 得 $h$ 维——「把旧记忆变换到新时刻」。
- **第三步，看合并与非线性**：两个 $h$ 维向量**相加**（加偏置），再过 $\tanh$，得 $h$ 维新隐状态。**维度全程为 $h$，干净利落**——RNN 的隐状态维 $h$ 是唯一要关心的尺寸。<span class="marginnote">「$h$ 维隐状态」是 RNN 的「内存大小」：$h$ 越大，能装的历史信息越多（容量越大），但也更容易过拟合、梯度问题更严重。RNN 的调参里，$h$ 与「记忆能力」直接挂钩——「隐状态维 = 记忆容量」是理解 RNN 超参数的第一直觉。</span>

**易错点：** 批处理时输入是 $\boldsymbol{X}_t\in\mathbb{R}^{n\times d}$（$n$ 个样本同一步），隐状态是 $\boldsymbol{H}_t\in\mathbb{R}^{n\times h}$，公式变为矩阵乘——**逐样本的循环在批量下变成「矩阵乘法 + 并行」**，但每个样本的记忆仍独立演化（互不干扰）。理解「批量并行 + 样本隔离」是正确实现 RNN 批处理的关键。

## 5 RNN 的能力与局限

**RNN 的能力**：

- **变长输入**：任何长度的序列都能处理（隐状态维固定）。
- **时间参数共享**：参数量与序列长度无关——「规则不随位置变」。
- **理论上的无限记忆**：理论上 $\boldsymbol{h}_T$ 编码全部历史。

**RNN 的局限**：

1. **长程记忆失效**：实践中 $\boldsymbol{W}_{hh}$ 的反复相乘让「远处的梯度」指数衰减——RNN 实际只能记住几十步（梯度消失，见下一篇）。
2. **串行计算**：前向必须逐时间步推进，无法像 CNN 那样并行——训练慢。
3. **压缩瓶颈**：单隐状态向量要装下整个历史，信息被「压扁」。

**「RNN 的理论美好 vs 实践受限」**是序列建模演进的驱动力：LSTM/GRU 治「长程记忆」，注意力治「压缩瓶颈」与「串行性」——每一步演进都在补 RNN 的一个洞。<span class="marginnote">「RNN 的串行性」是它最终被 Transformer 取代的关键原因之一：GPU 的并行能力在 RNN 的逐时间步推进前「有力使不出」。Transformer 用注意力让「所有位置的交互一次性并行计算」，把序列长度从「串行瓶颈」变成「并行矩阵」——这是「RNN 时代 → Transformer 时代」最本质的效率跃迁（第六篇详述）。</span>

## 6 小结

- **RNN 核心**：隐状态 $\boldsymbol{h}_t = \tanh(\boldsymbol{W}_{hx}\boldsymbol{x}_t + \boldsymbol{W}_{hh}\boldsymbol{h}_{t-1} + \boldsymbol{b}_h)$——「滚动记忆」，权重跨时间共享。
- **展开**：RNN ≈ 权重共享的超深前馈网络；反向传播 = BPTT（链式法则沿时间）。
- 输入输出模式：多对一（分类）、一对多（生成）、多对多同步（标注）、异步（翻译）。
- 单步维度走查：输入投影 + 记忆递进 + 相加 + 非线性，全程 $h$ 维。
- 能力：变长输入、参数共享、理论无限记忆；局限：长程失效、串行、压缩瓶颈。
- RNN 的演进史 = 补洞史：LSTM 补记忆、注意力补瓶颈与并行。
