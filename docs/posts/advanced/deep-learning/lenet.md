## 为什么从 LeNet 开始

卷积、池化、通道——这些部件都讲完了，现在把它们**拼成第一个完整的网络**。**LeNet-5**（LeCun 等, 1998）是历史上第一个真正成功的卷积网络：它用「卷积 + 池化 + 全连接」的完整流水线，在 90 年代就实现了手写数字识别（MNIST）的自动化，被美国邮政系统用于邮政编码与支票识别。它的结构虽然「只有 5 层、6 万个参数」，却确立了 CNN 的**黄金模板**——之后的 AlexNet、VGG、ResNet，全都沿用了「卷积提特征 → 池化降采样 → 全连接分类」的骨架。

理解 LeNet 的意义有三层：其一，它是「卷积 + 池化 + 全连接」这套**组合语法**的首次系统实现；其二，它证明了「端到端梯度训练」比当时的手工特征方法更优；其三，它当年「输给」了 SVM，沉寂十年后才在 2012 年被 AlexNet 复兴——**「技术的命运不取决于当下的胜负，而取决于硬件的时机」**。本节把 LeNet-5 的每一层拆开，再用 PyTorch 完整实现它。<span class="marginnote">LeNet 的「5」指它的可学习层数：2 个卷积 + 3 个全连接。LeCun 团队用它处理的不是普通图像而是「手写数字」——这个看似简单的任务，让「局部性 + 平移不变」的先验第一次在真实系统里证明了价值。它当年在 MNIST 上约 0.7% 的错误率，是那个时代最好的成绩。</span>

## 1 LeNet-5 的架构：逐层拆解

LeNet-5 处理 $32\times32$ 灰度图，结构如下：

| 层 | 操作 | 核/窗口 | 输出尺寸 | 参数 |
| --- | --- | --- | --- | --- |
| 输入 | 灰度图 | — | $32\times32\times1$ | — |
| C1 | 卷积 | $5\times5$，6 输出通道 | $28\times28\times6$ | 156 |
| S2 | 平均池化 | $2\times2$，步幅 2 | $14\times14\times6$ | 12 |
| C3 | 卷积 | $5\times5$，16 输出通道 | $10\times10\times16$ | 1516 |
| S4 | 平均池化 | $2\times2$，步幅 2 | $5\times5\times16$ | 32 |
| C5 | 卷积 | $5\times5$，120 输出 | $1\times1\times120$ | 48120 |
| F6 | 全连接 | — | 84 | 10164 |
| 输出 | 高斯连接 | — | 10 | 850 |

**结构模式**清晰可见：**「卷积（提特征）→ 池化（降采样）→ 卷积 → 池化 → 摊平 → 全连接 → 输出」**。这个「先卷积降维、再全连接分类」的两段式，就是 CNN 的经典语法。<span class="marginnote">注意 C3→C5 的过渡：C5 用的是 $5\times5$ 卷积把 $5\times5\times16$ 压成 $1\times1\times120$——这一步是「把整张特征图卷积成一个向量」，等价于「全连接但用卷积实现」。这种「用卷积替代全连接」的技巧（全卷积化）在现代网络里反复出现（NiN、FCN），是理解「卷积与全连接等价性」的经典例子。</span>

**S2/S4 用平均池化而非最大池化**：LeNet 时代最大池化尚未流行，平均池化（配一个可学习缩放与偏置）是当时的「平滑降采样」。现代实现大多换成最大池化或步幅卷积，但「卷积 + 池化」的骨架不变。

**易错点：** LeNet 的输入是 $32\times32$，而 MNIST 原始图像是 $28\times28$——LeNet 会先**填充到 $32\times32$**。这个「输入尺寸」的细节决定了卷积后特征图尺寸的推算，复现时务必对齐。

## 2 LeNet 为什么能成功：三个关键选择

**选择一：局部感受野 + 参数共享。** 手写数字由「局部笔画」组成（竖线、横线、弯钩），局部性极强；卷积核正好提取局部笔画模式，参数共享让「同一笔画检测器」到处可用。

**选择二：端到端梯度训练。** LeNet 是第一个用**反向传播**端到端训练多层卷积网络的工作。对比当时的主流——手工设计特征（方向直方图、拓扑特征）+ 浅层分类器——LeNet 让特征**自己从数据里学出来**，这是「表示学习」的第一次胜利。

**选择三：逐层抽象。** C1 学低级笔画、C3 组合成部件级模式、全连接做最终判别——**「从笔画到数字」的层级表示**让网络对笔迹变化鲁棒。<span class="marginnote">LeNet 的「层级特征」并非设计者手工指定的，而是<strong>反向传播自动学出来的</strong>——这印证了「深度学习的特征不需要人设计」这个根本观点。LeCun 后来在多个场合强调：LeNet 的成功不是「设计对了特征」，而是「设计对了学习机制」。</span>

**易错点：** LeNet 用 Sigmoid/Tanh 激活，在 2012 年后被 ReLU 取代。现代复现常把激活换成 ReLU（并去掉平均池化的可学习参数）以提升性能——**「复现历史架构」时，激活函数按现代实践替换是合理的**。

## 3 用 PyTorch 从零实现 LeNet

```python
import torch
import torch.nn as nn

class LeNet5(nn.Module):
    def __init__(self):
        super().__init__()
        # 特征提取：卷积 + 池化；padding=2 让输入保持 32×32
        self.features = nn.Sequential(
            nn.Conv2d(1, 6, kernel_size=5, padding=2),  # 32×32 → 32×32
            nn.ReLU(),
            nn.AvgPool2d(kernel_size=2, stride=2),      # 32×32 → 16×16
            nn.Conv2d(6, 16, kernel_size=5),            # 16×16 → 12×12
            nn.ReLU(),
            nn.AvgPool2d(kernel_size=2, stride=2),      # 12×12 → 6×6
        )
        # 分类头：摊平 → 全连接 → 10 类
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(16 * 6 * 6, 120),   # 摊平后 16×36 = 576
            nn.ReLU(),
            nn.Linear(120, 84),
            nn.ReLU(),
            nn.Linear(84, 10),
        )

    def forward(self, x):
        return self.classifier(self.features(x))

net = LeNet5()
print(net(torch.randn(1, 1, 32, 32)).shape)  # torch.Size([1, 10])
```

（为适配现代习惯，这里用了 padding=2 与 ReLU，输入为 $32\times32$；若直接喂 $28\times28$ MNIST，去掉 padding 即可。）**训练循环**与《Softmax 回归》中的完全一致：交叉熵损失 + SGD/Adam + 若干 epoch——LeNet 在 MNIST 上几十个 epoch 就能达到约 99% 准确率。

**易错点：** 全连接层的输入尺寸必须与「卷积输出摊平后的维数」匹配——$32$ 来自「16 通道 × 6×6 特征图」。**改动卷积/池化配置后忘记同步 $16$ 的输入维，是复现 LeNet 最常见的报错**。<span class="marginnote">「手推一遍特征图尺寸」在实现 CNN 时不可或缺：输入 $32\times32$ → Conv(5,pad2) 保 $32$ → pool 到 $16$ → Conv(5) 到 $12$ → pool 到 $6$ → 摊平 $16\times36=576$。用《填充、步幅与感受野》的公式手推一遍，实现几乎不会错。</span>

## 4 LeNet 的历史遗产：从 1998 到 2012

LeNet 在 1998 年达到实用水平，但随后的十年里，神经网络整体沉寂——SVM 与手工特征（HOG、SIFT）在通用视觉任务上更吃香，LeNet 只活在「手写识别」这个窄领域。**为什么？** 不是 LeNet 的方法错了，而是**算力与数据**没到：深网络需要大量标注数据与足够快的 GPU，90 年代两者皆缺。

2012 年 AlexNet 在 ImageNet 上横扫，其结构几乎是 LeNet 的「放大版」：**更多的层、更宽的通道、ReLU、GPU 训练、大规模数据**。LeNet 的骨架终于等到了它的时代。**「LeNet 定义语法，AlexNet 证明规模」**——这是卷积网络史最简洁的概括。<span class="marginnote">「硬件与数据决定技术的命运」是深度学习史反复出现的主题：LeNet 1998 年就有今天 CNN 的全部要素，但直到 2012 年 GPU 算力 + 百万级数据集 + 大规模工程实践才让它「起飞」。这提醒我们：<strong>评价一项技术，要把它放进「当时的算力与数据约束」里</strong>——LeNet 超前于它的时代，不是失败而是「预演」。</span>

## 5 数值算例：LeNet-5 逐层尺寸追踪

把 LeNet-5 对一张 $32\times32$ 输入图的逐层尺寸追一遍，理解「卷积降空间、池化翻倍降、全连接汇总」的节奏：

| 层 | 操作 | 输入 | 核/步幅 | 输出 | 作用 |
| --- | --- | --- | --- | --- | --- |
| C1 | 卷积 | $32^2\times1$ | $5\times5$ | $28^2\times6$ | 提底层特征 |
| S2 | 平均池化 | $28^2\times6$ | $2\times2$ 步幅 2 | $14^2\times6$ | 降采样 |
| C3 | 卷积 | $14^2\times6$ | $5\times5$ | $10^2\times16$ | 提中层特征 |
| S4 | 平均池化 | $10^2\times16$ | $2\times2$ 步幅 2 | $5^2\times16$ | 降采样 |
| C5/F5 | 卷积/全连接 | $5^2\times16$ | $5\times5$ | $120$ | 拍平成向量 |
| F6 | 全连接 | $120$ | — | $84$ | 特征汇总 |
| OUTPUT | 全连接 | $84$ | — | $10$ | RBF/Softmax 分类 |

**读这张表的关键**：空间尺寸一路减半（$32\to28\to14\to10\to5\to1$），通道数一路增加（$1\to6\to16$）——**「空间变小、通道变多」是卷积网络的经典节奏**，一直延续到今天的视觉模型。<span class="marginnote">一个常被忽略的细节：LeNet-5 的 C3 层不是「每个输出通道连所有 6 个输入通道」——它用了一个稀疏的连接模式（部分通道只连部分输入），目的是「打破对称性、让各通道学不同特征」。这个「稀疏连接」后来被 AlexNet/现代网络抛弃（统一全连接输入通道），但它提醒我们：<strong>LeNet 时代很多「设计」是为省算力或破对称的工程选择，不一定是普适真理</strong>。</span>

**LeNet 的历史坐标**：1998 年 Yann LeCun 团队提出，用于银行支票数字识别；到 2012 年 AlexNet 之前，它是「卷积网络能行」的最有力证据。**它的价值不在「性能」，而在「确立了 CNN 的骨架语法」**——卷积、池化、全连接、多层级抽象，这套模板至今未变。

## 6 小结

- **LeNet-5**：2 卷积 + 3 全连接，处理 $32\times32$ 手写数字；确立「卷积提特征 → 池化降采样 → 全连接分类」的黄金模板。
- 成功三要素：**局部感受野 + 参数共享、端到端梯度训练、逐层抽象**。
- 卷积输出到全连接之间用「摊平」衔接，输入维必须与特征图尺寸匹配。
- C5 用 $5\times5$ 卷积把特征图压成向量——「全连接卷积化」的早期例子。
- LeNet 1998 年即成功，但因算力/数据限制沉寂十年，2012 年 AlexNet 以「更大 LeNet」身份复兴——**「LeNet 定义语法，AlexNet 证明规模」**。
