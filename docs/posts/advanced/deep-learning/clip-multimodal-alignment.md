## 为什么从 CLIP 与图文对齐开始

前八篇的模型都「单模态」：要么视觉、要么语言。**多模态学习（multimodal learning）**处理「多种模态的数据」（图像 + 文本、图像 + 语音……），目标是让模型「跨模态理解」。**CLIP（Contrastive Language-Image Pre-training）**（Radford 等, 2021）是图文多模态的里程碑：它用「对比学习」把「图像」与「文本」对齐到**同一个向量空间**——配对的图文应该靠近、不配对的应该远离。训练后，CLIP 可以用**自然语言**「零样本」做图像分类——「给一张猫图 + 一段描述『一只猫』，模型判断是否匹配」。

CLIP 的意义远超「一个模型」：它证明了「**图文对齐 = 通用的视觉理解**」——CLIP 学到的图像表示，能泛化到「训练时没见过的类别与任务」（零样本分类、检索、生成条件注入）。它是「视觉-语言模型」的开山之作，也是 Stable Diffusion 的「文本条件编码器」、GPT-4V 的多模态基础。本节把 CLIP 的「双编码器」「对比对齐」「零样本迁移」讲透——它是第八篇「多模态」的核心。<span class="marginnote">「CLIP 的『对比』思想」：CLIP 用「对比学习」（见《SimCLR》）做图文对齐——「<strong>不是『让模型生成图片的描述』（重建式），而是『让配对的图文表示靠近』（对比式）</strong>」。对比式的效率：4 亿图文对就够了（重建式要更多数据）。「<strong>『对齐』比『生成』更容易学，也更通用</strong>」——这是 CLIP 的方法论核心。</span>

## 1 双编码器：图像与文本各走一路

**CLIP 的架构**：两个独立的编码器——**图像编码器**与**文本编码器**：

**图像编码器**（ViT 或 ResNet）：图像 $\to$ 图像表示 $\boldsymbol{I} \in \mathbb{R}^d$。
**文本编码器**（Transformer）：文本 $\to$ 文本表示 $\boldsymbol{T} \in \mathbb{R}^d$。

**「两个编码器把『图像』与『文本』各自映射到 $d$ 维向量」**——关键目标：让「配对的图文」在向量空间里「靠近」。

**CLIP 的零样本分类**：不用「训练分类头」，而是用「文本模板」——给每个类别构造一段文本（「一张{猫}的照片」），算文本表示；把测试图像表示与所有类别文本表示比对，取「最相似」的类别。

**「分类头被『文本』替代」**——这是 CLIP 零样本能力的来源：类别不是「固定的数字标签」，而是「自然语言描述」，可以「自由扩展」到任意类别。<span class="marginnote">「CLIP 的『文本即标签』」：传统分类器的类别是「训练时固定的索引」（加新类要重训）；CLIP 的类别是「文本」（加新类只需写一段新文本，无需重训）——「<strong>把『分类』变成『文本匹配』，让类别可以无限扩展</strong>」。这个「标签开放化」是「零样本迁移」的核心机制，也启发了后来「prompt 化」的趋势。</span>

**易错点：** CLIP 的「双编码器」是**独立的**（图像与文本不共享编码器）——「对齐」发生在「表示空间」（通过对比损失把两边的表示拉近），不是「共享网络」。**「独立编码 + 共享空间」**是 CLIP 的结构。

## 2 对比对齐：拉近配对、推远不配对

CLIP 的训练目标是**对比对齐**：在一个 batch 里，有 $N$ 对「配对的图文」（$N$ 张图 + $N$ 段描述）。目标是让「第 $i$ 张图」与「第 $i$ 段描述」的相似度最高（它们是配对的），与其他描述（不配对）的相似度低。

**InfoNCE 式损失**（对称的图文对比损失）：

$$
L = -\frac{1}{N}\sum_i \Big[\log\frac{\exp(\text{sim}(\boldsymbol{I}_i, \boldsymbol{T}_i)/\tau)}{\sum_j \exp(\text{sim}(\boldsymbol{I}_i, \boldsymbol{T}_j)/\tau)} + \log\frac{\exp(\text{sim}(\boldsymbol{I}_i, \boldsymbol{T}_i)/\tau)}{\sum_j \exp(\text{sim}(\boldsymbol{I}_j, \boldsymbol{T}_i)/\tau)}\Big]
$$

第一项「图 → 文」方向（图从所有文本里认出它的配对），第二项「文 → 图」方向（文本从所有图里认出它的配对）——**两个方向都做对比**。

**「对比对齐」教给模型什么**：图像与文本的「匹配关系」——「图与它的描述共享语义，与不相关文本不共享」。学完后，图像表示与文本表示**落在同一语义空间**，可以直接算相似度。<span class="marginnote">「CLIP 的『语义对齐』原理」：对比损失迫使「配对的图文表示」在空间里靠近——因为「同一语义」（一只猫的图像与「一只猫」的文字）被拉近，「<strong>跨模态的语义被『对齐』进同一个空间</strong>」。这个「对齐」让「图像检索文本」「文本检索图像」「图像分类（用文本当类别）」都变成「向量相似度」运算——「<strong>一个对齐的向量空间，解锁全部跨模态任务</strong>」。</span>

**易错点：** CLIP 的「对比」需要「大批量」（负样本多，对比才有意义）——CLIP 用 **32768 的 batch**。**「大 batch 是 CLIP 训练的关键工程」**（对比学习的「负样本规模」依赖，见《SimCLR》）。

## 3 零样本迁移：CLIP 的杀手锏

**CLIP 的零样本（zero-shot）能力**：在训练时**没见过的任务**上直接用——因为它把「任务」翻译成了「文本匹配」：

**图像分类**：给类别写文本模板 → 图像与各类别文本比对。
**图像检索**：文本查询 → 检索相似图像。
**图文匹配**：判断图文是否匹配。

**为什么零样本可行？** 预训练时 CLIP「见过」海量图文对（互联网爬取），文本里蕴含了「各种任务的语言形式」（分类、检索、描述）——「<strong>模型学会了『图像 ↔ 语言』的通用对齐，任何『语言表达的任务』都能触发它</strong>」。

**零样本 vs 少样本**：CLIP 零样本在 ImageNet 上达到约 76% 准确率（与 2012 年的监督 ResNet-50 相当）——**「零样本 ≈ 2012 年的监督水平」**，且无需任何训练。<span class="marginnote">「CLIP 的『零样本』局限」：它擅长「常见类别」（预训练文本覆盖过），但「细粒度/专业类别」（稀有物种、专业术语）表现差——「<strong>零样本的『上限』取决于预训练文本的『覆盖度』</strong>」。这也解释了「为什么 CLIP 之后出现『更大的图文数据』『更好的文本编码器』等改进」——「零样本能力 = 数据覆盖度的函数」。</span>

**易错点：** CLIP 的「零样本」是「无微调」，不是「无训练」——它经过了大规模预训练。「<strong>『零样本』指『下游任务零训练』，不是『模型零训练』</strong>」。

## 4 公式解析：CLIP 的图文匹配

把 CLIP 的「图文对齐」写成可操作的「匹配分数」。给定图像 $\boldsymbol{x}$ 与文本 $\boldsymbol{t}$，CLIP 的匹配分数：

$$
\text{score}(\boldsymbol{x}, \boldsymbol{t}) = \frac{f_{\text{img}}(\boldsymbol{x}) \cdot f_{\text{text}}(\boldsymbol{t})}{\|f_{\text{img}}(\boldsymbol{x})\|\,\|f_{\text{text}}(\boldsymbol{t})\|} = \cos\big(f_{\text{img}}(\boldsymbol{x}), f_{\text{text}}(\boldsymbol{t})\big)
$$

- **第一步，看表示**：图像经 $f_{\text{img}}$（ViT）、文本经 $f_{\text{text}}$（Transformer），都到 $d$ 维向量。
- **第二步，看相似度**：匹配分数 = 两个表示的**余弦相似度**——「图与文的语义接近度」。
- **第三步，读任务**：分类 = 「图像与『各类别文本』的相似度取最大」；检索 = 「查询文本与『各图像』的相似度排序」——**「一切任务 = 相似度计算」**。<span class="marginnote">「CLIP 的『统一表示空间』的威力」：因为图像与文本在同一个空间，你可以做「图像 + 文本 = 图像」的运算——「<strong>用文本描述『想要什么变化』，在表示空间里『移动』图像</strong>」（如「一张猫的图 + 『戴着帽子』的文本」→ 检索「戴帽子的猫」）。这个「跨模态向量运算」是「文本引导的图像编辑/检索」的基础，也是「视觉-语言模型」的通用玩法。</span>

## 5 CLIP 的现代影响：从视觉到多模态

CLIP 的影响极其深远：

**零样本视觉**：CLIP 开启「视觉零样本」——「用语言做视觉任务」成为范式。
**生成条件**：**Stable Diffusion** 用 CLIP 的文本编码器做「文本条件」——「CLIP 是文本到图像的『理解端』」。
**多模态大模型**：GPT-4V、LLaVA 等用 CLIP 的视觉编码器「看图像」——「CLIP 是视觉-语言大模型的『视觉眼』」。
**跨模态检索**：图文检索、视频检索——「CLIP 表示 = 通用跨模态特征」。

**「CLIP 确立了『对比式多模态预训练』范式」**——「图文对比对齐」成为多模态学习的标准配方，后续的 ALIGN、SigLIP 等都是它的改进。CLIP 是「视觉-语言模型」时代的开创者。<span class="marginnote">「CLIP 与『多模态大一统』」：CLIP 让「图像」与「文本」共享表示空间——这是「多模态大一统」的第一步：<strong>如果图像与文本能对齐，语音、视频、3D 也能对齐到同一空间</strong>。「<strong>多模态的终极目标 = 一个共享的语义空间，容纳所有模态</strong>」——CLIP 是这个目标的第一块里程碑（第八篇《多模态学习》与第四级《多模态大模型》会继续这条线）。</span>

**易错点：** CLIP 的「图文对齐」是「粗粒度」的（整图 ↔ 整句）——它不对齐「图像区域 ↔ 文本片段」（细粒度对齐需要 GLIP、RegionCLIP 等扩展）。**「CLIP = 全局对齐，细粒度对齐是后续方向」**。

## 6 小结

- **CLIP**：双编码器（图像 ViT + 文本 Transformer）+ 对比对齐——「图像与文本共享表示空间」。
- **对比对齐**：InfoNCE 式对称损失——拉近配对图文、推远不配对——「大 batch（32768）关键」。
- **零样本迁移**：把「分类/检索」翻译成「文本匹配」——「类别开放化、任务无需训练」。
- 匹配分数 = 图文表示余弦相似度——「一切任务 = 相似度计算」。
- 影响：零样本视觉、Stable Diffusion 的条件、多模态大模型的「视觉眼」。
- 范式：对比式多模态预训练——「多模态大一统」的第一块里程碑。
