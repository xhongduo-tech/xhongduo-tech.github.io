# 深度学习

从感知机到 Transformer，理解深度网络为何有效、如何训练。

## 主题规划

- [ ] 神经网络基础：前向传播与计算图
- [ ] 反向传播的完整推导
- [ ] 激活函数：Sigmoid、ReLU 家族与 SwiGLU
- [ ] 参数初始化与梯度消失/爆炸
- [ ] 优化器：SGD、动量、Adam 与 AdamW
- [ ] 学习率调度与 warmup
- [ ] 正则化：Dropout、权重衰减与数据增强
- [ ] 归一化：BatchNorm、LayerNorm 与 RMSNorm
- [ ] CNN 基础：卷积、池化与感受野
- [ ] CNN 架构演进：LeNet → AlexNet → VGG → ResNet
- [ ] RNN、LSTM 与 GRU
- [ ] Seq2Seq 与 Bahdanau 注意力
- [ ] Attention 机制：自注意力与多头注意力
- [ ] Transformer 架构逐层解析
- [ ] 位置编码：正弦、可学习与 RoPE
- [ ] 预训练范式：BERT、GPT 与 T5
- [ ] 视觉 Transformer：ViT 与 Swin
- [ ] 生成模型：VAE 与 GAN
- [ ] 扩散模型：DDPM 原理与采样
- [ ] 自监督学习与对比学习（SimCLR、CLIP）
- [ ] 混合精度训练与分布式训练（DP/DDP/FSDP）
- [ ] PyTorch 工程实践：Dataset、AMP 与性能分析
