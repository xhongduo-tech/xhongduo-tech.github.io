## 为什么从量子数开始

量子数是一张粒子的「身份证」：每个数字都记下粒子在某一方面取的值——电荷是多少、重子数是几、自旋是几。守恒定律则是一部「交通法规」：它规定哪些反应过程被允许、哪些被禁止。在粒子物理里，你判断一个衰变「能不能发生」，先不查微分截面，而是先做一道**量子数算术**——四个数加起来对不上，这个过程根本不存在。本章是全书最「可操作」的一章，也是从「认识粒子」迈向「计算过程」的第一步。

## 1 什么是量子数

**量子数（quantum number）**：描述粒子某个物理量取值的一个离散数，通常是某个算符的本征值。它分两类：

- **加性量子数（additive）**：反应前后求和守恒。例如电荷、重子数 $B$、轻子数 $L_e$、奇异数 $S$、同位旋第三分量 $I_3$。
- **乘性量子数（multiplicative）**：反应前后取乘积守恒。例如宇称 $P$、电荷共轭 $C$。一条反应若包含 $n$ 个初态、$m$ 个末态粒子，乘性量子数要求 $\prod_{\text{初}} q_i = \prod_{\text{末}} q_j$。

<span class="marginnote">怎么分辨？凡是「某粒子数」大多是加性的，凡是「某变换的±1」大多是乘性的。宇称在反粒子处不变号，所以它不是加性量子数——它像一把「世界是镜子」的开关，只有 ±1 两档。</span>

粒子的「身份」由一组量子数完全指定。例如质子：$Q = +1$，$B = +1$，$S = 0$，自旋 $J = 1/2$。反质子：$Q = -1$，$B = -1$，其余同。**反粒子的全部加性量子数变号，乘性量子数与固有属性不变**——这是上一章「反粒子」定义的精确版本。

## 2 重子数与轻子数：经验守恒

标准模型里真正「根本」的守恒来自对称性（下一章《诺特定理》），但有两类守恒是**经验规律**：至今没看到任何违反，却无法从基本原理推导。

- **重子数（baryon number）$B$**：每个夸克 $B = 1/3$，每个反夸克 $B = -1/3$；重子（质子、中子等三个夸克）$B = 1$；介子 $B = 0$。**所有已知反应都满足 $\Delta B = 0$。** 质子非常稳定，部分原因正是 $B$ 守恒——最轻的重子无处可衰（第 5 节详谈）。
- **轻子数（lepton number）**：更精细，分为三代 $L_e$、$L_\mu$、$L_\tau$，各代内分别守恒。$e^-$ 有 $L_e = 1$，$\nu_e$ 有 $L_e = 1$，而 $\mu^-$ 有 $L_\mu = 1$（$L_e = 0$）。

<span class="marginnote">三代轻子数分开守恒是个经验事实，直到 1998 年中微子振荡被发现才被打破——那意味着「代内轻子数」并非严格守恒，这正是第五篇《中微子振荡与质量》的主题。</span>一个著名的验证：μ 子衰变 $\mu^- \to e^- + \bar{\nu}_e + \nu_\mu$。检验轻子数：初态 $L_e = 0$、$L_\mu = 1$；末态 $e^-$ 给 $L_e = 1$，$\bar{\nu}_e$ 给 $L_e = -1$，$L_e$ 合计 0；$\nu_\mu$ 给 $L_\mu = 1$，合计 1。每一代都守恒，反应被允许——事实上这正是 μ 子最主要的衰变道。

## 3 公式解析：量子数算术判断一个反应

判断反应是否可能，是本章的核心技能。以 μ 子衰变 $\mu^- \to e^- + \gamma$ 为例——这个「看上去很美」的衰变（放一个 γ 光子）实际观测不到，为什么？

$$
\mu^- \;\not\rightarrow\; e^- + \gamma
$$

- **第一步，列加性量子数**。初态 $\mu^-$：$Q = -1$、$L_e = 0$、$L_\mu = 1$、$B = 0$。末态 $e^-$：$Q = -1$、$L_e = 1$、$L_\mu = 0$、$B = 0$；$\gamma$：一切加性量子数为 0。
- **第二步，逐项核对**。电荷：$-1 = -1 + 0$ ✅；重子数：$0 = 0 + 0$ ✅；$L_\mu$：$1 \neq 0 + 0$ ❌。
- **第三步，结论**。末态 $L_\mu = 0$ 而初态 $L_\mu = 1$，代轻子数不守恒，该衰变被禁戒。实验上确未观测到 $\mu \to e\gamma$，其上界为分支比 < 10⁻¹¹。
- **第四步，推广为方法**。任何过程的判断流程都一样：写初态末态 → 列守恒量 → 逐项检查 → 全过才允许。若初末态总数不同，还要记得**乘性量子数取乘积**。

这道题背后是一条更普遍的原理：**如果一个「几乎可以发生」的过程始终观测不到，要么它违反某个守恒律，要么它被某条更高阶的机制压制。** 粒子物理许多新物理搜索（如 $\mu \to e\gamma$、质子衰变）都是沿着这个思路设计实验的。

## 4 守恒律的「层级」

不同守恒律的牢固程度不同，物理学家按被违反的难度把它们分层：

| 守恒量 | 类型 | 可靠程度 | 违反实例 |
| --- | --- | --- | --- |
| 能量、动量、角动量 | 时空对称性 | 绝对 | 无 |
| 电荷 $Q$ | 规范对称性 | 绝对 | 无 |
| 重子数 $B$、轻子数 $L$ | 经验 | 极高 | 无（振荡除外） |
| 奇异数 $S$、同位旋 $I$ | 近似（强作用） | 强作用守恒 | 弱衰变 $K^+ \to \mu^+\nu_\mu$ |
| 宇称 $P$、电荷共轭 $C$ | 弱作用中破缺 | 强/电磁守恒 | 弱衰变中不守恒 |

<span class="marginnote">这个「层级」是全书的骨架之一：强作用与电磁作用遵守的守恒律最多，弱作用破坏最多——宇称、奇异数、$C$、$CP$ 都在弱作用中失守。你学完本专题回来看这张表，会有「一切尽在表中」的通透感。</span>

奇异数 $S$ 是个特别好的例子：它定义 $S = N_{\bar{s}} - N_s$（反奇异夸克数减奇异夸克数）。强作用与电磁作用中 $S$ 守恒，所以奇异粒子「协同产生」（$K^-$ 与 $\Lambda$ 总是成对出现）；但弱衰变中 $S$ 可改变 $\pm 1$，所以奇异粒子只能通过弱作用慢慢衰变——寿命长得反常（约 10⁻¹⁰ s，比强衰变的 10⁻²³ s 长 13 个数量级），正是这种「又慢又一定发生」的矛盾，让物理学家给它们起了个名字叫「奇异」。

## 5 什么是「真正的」基本粒子

量子数还给了我们一个判定「基本性」的严格标准：**一个粒子若是基本的，它的一切量子数都是「初等的」——无法再被更小的组分来解释。** 质子有分数电荷的夸克组分（$uud$），所以它不是基本粒子；电子没有内部结构（至今），所以它是。

反过来说，最轻的重子（质子）因为 $B$ 守恒而无从衰变，成了宇宙中稳定的「积木」。中子比质子重 1.29 MeV，可以衰变：$n \to p + e^- + \bar{\nu}_e$（检验 $B$：$1 = 1 + 0 + 0$ ✅；$L_e$：$0 = 1 - 1 + 0$ ✅），这就是 β 衰变的本质。而质子若想衰变就必须违反 $B$ 守恒——这正是大统一理论（第五篇）预言质子衰变的出发点。

### 拓展：守恒律检验实例集

把「量子数算术」用在更多真实反应上，是掌握本章最有效的练习。下表列出几个关键过程及其守恒检查结果（$Q$、$B$、$L_e$、$L_\mu$、$L_\tau$、$S$ 逐项核对）：

| 反应 | $Q$ | $B$ | 轻子数 | $S$ | 判决 |
| --- | --- | --- | --- | --- | --- |
| $\pi^+ \to \mu^+ + \nu_\mu$ | ✓ | ✓ | ✓ | ✓ | 允许（弱衰变） |
| $\mu^- \to e^- + \gamma$ | ✓ | ✓ | ✗（$L_\mu$） | ✓ | 禁戒 |
| $n \to p + e^- + \bar\nu_e$ | ✓ | ✓ | ✓ | ✓ | 允许（β 衰变） |
| $p \to e^+ + \pi^0$ | ✓ | ✗（$\Delta B$） | ✗（$L_e$） | ✓ | 禁戒（需 $B$ 破坏） |
| $\pi^0 \to \gamma\gamma$ | ✓ | ✓ | ✓ | ✓ | 允许（电磁衰变） |
| $K^+ \to \mu^+\nu_\mu$ | ✓ | ✓ | ✓ | ✗（$\Delta S$） | 允许（弱衰变） |

- **「禁戒」与「不允许」的区别**：$\mu^- \to e^-\gamma$ 与 $p \to e^+\pi^0$ 都标为「禁戒」，但禁戒的原因不同——前者违反代轻子数（标准模型内的守恒律），后者违反重子数（标准模型外的理论可能允许）。**物理学里「观测不到的禁戒过程」正是新物理搜索的靶子**：$\mu \to e\gamma$ 的上界约束轻子味破坏，质子衰变的下界约束大统一。
- **奇异数的一行**：$K^+ \to \mu^+\nu_\mu$ 改变奇异数（$S = +1 \to 0$），只能通过弱作用发生，所以 $K^+$ 寿命长（约 $1.2\times10^{-8}$ s）——这就是第 11 篇「奇异粒子缓慢衰变」的量子数根源。

这套检验方法在粒子物理中无处不在：实验者拿到一个新共振态候选，第一步就是检查它能否通过所有守恒律「合法」地衰变；理论家构造新粒子时，也必须保证它与已知守恒律不冲突。**守恒律是粒子物理的「语法」，而量子数算术是它的「拼写检查」。**

### 补充：从对称性看轻子数、重子数的地位

第 5 节的「层级表」值得从诺特定理的角度再推敲一层：为什么电荷守恒最可靠？

- **电荷**：对应定域 $U(1)$ 规范对称性——它是「必然」守恒，因为规范对称性必须严格成立，否则理论不自洽。
- **轻子数、重子数**：对应整体（global）$U(1)$ 对称性——它们只是「碰巧」守恒，因为标准模型的拉格朗日量恰好含这些对称性，但没有原理要求它们存在。
- **差异的后果**：整体对称性可以被任何「额外项」破坏——中微子质量项（第 29 篇）、大统一的 $B$ 破坏玻色子（第 33 篇）、瞬子效应（斯法勒荣）都可能违反它们。

| 守恒量 | 对称性类型 | 是否原理保证 |
| --- | --- | --- |
| 电荷 | 定域规范 | 是 |
| 轻子数 | 整体 | 否（意外） |
| 重子数 | 整体 | 否（意外） |

**核心洞见**：规范对称性保护的量「想违反也违反不了」，整体对称性保护的量「想违反就能违反，只是还没找到途径」。这解释了为什么 $B$、$L$ 是大统一与中微子物理的突破口，而电荷永远安全。

## 6 小结

- **量子数**是粒子的离散身份证：加性（电荷、$B$、$L$、$S$、$I_3$）在反应中求和守恒，乘性（$P$、$C$）取乘积。
- **重子数 $B$** 与**代轻子数 $L_e, L_\mu, L_\tau$** 是经验守恒律，至今无违反（中微子振荡除外）。
- **判断反应的算术方法**：写初末态 → 列守恒量 → 逐项核对；$\mu \to e\gamma$ 因 $L_\mu$ 不守恒被禁戒。
- **守恒律有层级**：能量动量电荷绝对守恒，奇异数与宇称在弱作用中失守。
- **基本粒子的判据**：量子数无法再分解；质子因 $B$ 守恒而稳定。

下一篇是本书第一个「定理篇」：**诺特定理**。它将告诉你守恒定律的深层来源——为什么时空的平移对称性必然带来能量守恒，为什么旋转对称性必然带来角动量守恒。量子数表从此有了理论根基。
