# 对称性与守恒律

<div class="epigraph">
<p>如果一个物理系统经受某种变换后保持其行为不变，那么这个变换就对应一条守恒定律。</p>
<footer>—— 埃米 · 诺特（Emmy Noether，1918）</footer>
</div>

## 为什么从对称性与守恒律开始

粒子物理的核心问题之一，是回答「什么可以发生、什么被禁止」。答案的很大一部分藏在**对称性**里：物理规律在某种变换下不变，就对应一条守恒律；反之，守恒量不足，则暗示对称性被破坏。Griffiths 第四章从诺特定理出发，把守恒律分成**精确的**（电荷、重子数、轻子数）与**近似的**（同位旋、奇异数、宇称）两类——这条分界线，正是我们理解强作用「宽容」、弱作用「挑剔」的钥匙。

在课程体系里，本篇承接上一篇的粒子谱，把「粒子有什么属性」升级为「这些属性为何守恒」；它又为后面的夸克模型（同位旋与奇异数的来源）和电弱统一（对称性破缺）埋下伏笔。

## 1 诺特定理：对称性决定守恒量

**诺特定理（Noether's theorem）**：每个连续对称性对应一个守恒量。这是 20 世纪物理最深刻的统一原理之一，其对应关系：

| 对称性（变换） | 守恒量 |
| --- | --- |
| 时间平移 | 能量 |
| 空间平移 | 动量 |
| 空间旋转 | 角动量 |
| 规范变换 | 电荷（及轻子数、重子数） |
| 内部对称（如同位旋旋转） | 同位旋 |

<span class="marginnote">诺特（1882—1935）在 1918 年证明这一定理时，正值她因性别被哥廷根大学拒绝授予教职的艰难岁月。如今「诺特」几乎成了「对称与守恒」的同义词。</span>

对应关系是**一对一**的：时间平移不变→能量守恒，旋转不变→角动量守恒。反过来，一条守恒律被破坏，必然对应某个对称性不成立——宇称破坏就是一个教科书级的例子。

## 2 宇称：空间的镜像对称

**宇称（parity）**：空间反射变换（$\mathbf{r} \to -\mathbf{r}$）下的行为。若物理规律在镜像世界与真实世界完全一样，称宇称守恒。对单个粒子，宇称是个乘法量子数 $P = \pm 1$；对多粒子系统，总宇称是各粒子宇称之积再乘轨道部分 $(-1)^\ell$。

<span class="marginnote">为什么是相乘而不是相加？因为反射两次回到原样，$P^2 = 1$，只有 $+1$ 与 $-1$ 两个本征值；乘法的出现正是「本征值相乘」的量子力学必然。</span>

1956 年以前，几乎所有物理学家默认宇称守恒。李政道与杨振宁注意到，弱作用（尤其 β 衰变）的现有实验从未检验过宇称守恒，于是提出：**弱作用可能不守恒宇称**。吴健雄在 1957 年用极化的钴-60 做 β 衰变实验，观测到电子出射方向强烈不对称——镜像世界的 β 衰变速率竟与真实世界不同，宇称确实被破坏了。

**辨析｜易错点：** 宇称破坏不是「左手电子不衰变」，而是「电子出射角分布在镜像下改变」。弱作用里，中微子几乎总是左手（螺旋度 $-1$），反中微子几乎总是右手——这一「手性」选择，正是宇称破坏的根源，也是 V-A 理论的出发点。

## 3 电荷共轭与 CP：粒子与反粒子的互换

**电荷共轭（charge conjugation, C）**：把每个粒子换成它的反粒子。对电磁与强作用，C 守恒；但弱作用连 C 也不守恒——左手中微子的反粒子是右手反中微子，C 变换会把左手中微子变成左手反中微子，而后者根本不存在。

于是引入**CP 联合变换**：先 C 换粒子为反粒子，再 P 做空间反射。左手中微子 $\nu_L$ 经 CP 变成 $\nu_R^c$（右手反中微子）——这正是存在的粒子。1964 年克罗宁与菲奇在 $K^0$ 衰变中发现 CP 也轻微破坏（比例约 $2\times 10^{-3}$），这一微小破缺后来被证明是宇宙物质-反物质不对称的关键线索。

<span class="marginnote">CPT 定理说，把 C、P、T（时间反演）三者全做一次，任何洛伦兹不变局域理论都必须对称。这意味着 CP 破坏等价于 T 破坏——粒子物理里「时间之箭」的微观来源。</span>

### P、C、T 如何作用于物理量

把离散对称性落实到「改变什么」，一张表说清：

| 变换 | 位置 $\mathbf{r}$ | 动量 $\mathbf{p}$ | 自旋 $\mathbf{s}$ | 螺旋度 |
| --- | --- | --- | --- | --- |
| 宇称 P | $-\mathbf{r}$ | $-\mathbf{p}$ | 不变（轴矢量） | 变号 |
| 电荷共轭 C | 不变 | 不变 | 不变 | 不变（粒子↔反粒子） |
| 时间反演 T | 不变 | $-\mathbf{p}$ | $-\mathbf{s}$ | 不变 |

- **P 翻转动量而 C 不翻转**，所以左手中微子 $\nu_L$ 经 P 变右手 $\nu_R$（自然界没有），经 C 变左手反中微子 $\nu_L^c$（也没有）；只有 CP 联合才把它送到存在的 $\nu_R^c$。**这就是「弱作用破坏 P 与 C、却可能守恒 CP」的几何来源。**
- **T 翻转动量与自旋**，相当于把轨迹倒放——若 CP 破坏等价于 T 破坏，微观过程就有了「时间之箭」的不对称。

## 4 同位旋：近似对称与多重态

**同位旋（isospin, I）**：质子和中子的强作用几乎相同，质量相差不到 0.2%。海森伯 1932 年提议把它们看作同一种粒子——核子——在「同位旋空间」的两个态，$I = 1/2$，第三分量 $I_3 = +1/2$（质子）、$-1/2$（中子）。

强相互作用对同位旋旋转（质子↔中子混合）近似不变，于是**强作用近似守恒同位旋**。它的直接后果是**电荷多重态**：质量相近的一族粒子共享同一个 $I$，成员按 $I_3$ 区分电荷。例如：

- 核子二重态：$p, n$（$I = 1/2$）
- π 介子三重态：$\pi^+, \pi^0, \pi^-$（$I = 1$）
- Δ 共振四重态：$\Delta^{++}, \Delta^{+}, \Delta^{0}, \Delta^{-}$（$I = 3/2$）

<span class="marginnote">多重态成员数 $= 2I + 1$，与角动量多重态完全同构——同位旋在数学上就是「电荷空间的角动量」。这个类比后来被推广成 SU(3) 味对称，见第四篇《强子与夸克模型》。</span>

同位旋**只是近似**守恒：电磁作用分辨质子与中子（带电不同），弱作用更彻底地破坏它。所以严格说，同位旋只在强作用里是好量子数。

## 5 公式解析：Gell-Mann-Nishijima 关系

同位旋、奇异数 $S$、电荷 $Q$ 与超荷 $Y = B + S$ 之间有一条漂亮的桥梁公式：

$$
Q = I_3 + \frac{Y}{2} = I_3 + \frac{B + S}{2}
$$

- **$Q$**：电荷（以电子电荷为单位）。例如 $\pi^+$：$Q = +1$。
- **$I_3$**：同位旋第三分量。π 介子属 $I=1$ 三重态，$\pi^+$ 的 $I_3 = +1$。
- **$B$**：重子数，重子取 $+1$、反重子取 $-1$、介子取 $0$。
- **$S$**：奇异数，奇夸克 $s$ 使粒子 $S = -1$（注意符号惯例与 $I_3$ 相关）。

验算 $\pi^+$：$B = 0, S = 0, I_3 = +1$，于是 $Q = 1 + 0 = +1$，正确。再验 $\Sigma^-$（奇异数 $S=-1$，同位旋 $I=1$ 的 $I_3=-1$）：$Q = -1 + (0 + (-1))/2 = -1.5$——咦，不对。这是因为 $\Sigma$ 三重态实际 $S = -1$，$B=1$，$I_3$ 对 $\Sigma^-$ 是 $-1$，代入得 $Q = -1 + (1 + (-1))/2 = -1$，正确。<span class="marginnote">这条公式的验算非常容易踩符号坑：$Y$ 里的 $S$ 用的是「味」符号，与 $I_3$ 的符号约定必须同时取。Griffiths Ch.4 有专门的练习，值得亲手算一遍。</span>它的意义在于：把三个看似独立的量子数（电荷、同位旋、奇异数）压进一个关系，从而能由任意两个推出第三个。

### 守恒律的精确度分级

粒子物理实验里，守恒律被分成「硬」与「软」两档，这是实验语言的基本常识：

| 守恒量 | 精确度 | 由什么保证 / 被什么破坏 |
| --- | --- | --- |
| 能量、动量、角动量 | 精确（零误差内） | 时空平移与旋转对称 |
| 电荷 | 精确到 $10^{-21}$ | 规范对称 |
| 轻子数、重子数 | 极精确（实验上限内） | 理论预言被 sphaleron 轻微破坏 |
| 宇称 P、C、CP | 弱作用破坏 | 弱相互作用 |
| 同位旋、奇异数、粲数、底数 | 强/电磁近似守恒 | 弱作用改变味 |

- 前两行来自**时空对称性**（诺特定理给出的「绝对」守恒），后三行来自**内部对称性**，精确度由具体相互作用决定。
- 一个有趣的推论：**「几乎守恒」的量反而是寻找新物理的最佳哨兵**——质子寿命实验把重子数守恒检验到 $10^{34}$ 年，任何超出理论预言的事件都是新物理的信号。

## 6 小结

- **诺特定理**：连续对称性 ↔ 守恒量；能量、动量、角动量、电荷都是对称性的产物。
- **宇称**：空间反射对称，1957 年吴健雄实验证实弱作用破坏宇称。
- **电荷共轭与 CP**：C 与 CP 都被弱作用破坏；CPT 定理保证三者的乘积严格对称。
- **同位旋**：近似对称，源于质子与中子强作用相同；产生电荷多重态（$2I+1$ 个成员）。
- **Gell-Mann-Nishijima 关系**：$Q = I_3 + Y/2$，把电荷、同位旋、超荷绑定在一起。

在下一节，我们将转向实验语言：**截面、衰变率、四维动量**——对称性回答「能不能」，运动学与探测器回答「有多少、怎么测」。
