## 为什么从标准单位开始

粒子物理的数值世界与我们熟悉的宏观世界隔着一道「单位的鸿沟」：电子质量不是 9.1×10⁻³¹ kg，而是 0.511 MeV；质子的尺度不是 0.84×10⁻¹⁵ m，而是……几乎不用米。为了不写一长串科学计数法，粒子物理学家采用**自然单位**：让 $\hbar = c = 1$，于是能量、动量、质量用同一个单位（电子伏特及其派生）度量，时间与长度的量纲与能量互为倒数。这套记号遍布本书每一个公式，不先掌握它，读后面的章节会处处碰壁。

## 1 自然单位：把 $\hbar$ 与 $c$ 关进盒子里

设定 $\hbar = c = 1$ 的意思是：**在计算中不再显式写出 $\hbar$ 与 $c$，最后需要换算回 SI 单位时再用量纲分析补回。** 这样做的理由有两层：

- 物理上，$\hbar$ 与 $c$ 是「换算因子」而不是基本物理常数——它们的存在只是因为人类选了「秒、米、千克」这套单位。在粒子物理关心的尺度，用「能量」做唯一基本量纲最自然。
- 操作上，公式被大幅简化：$E^2 = p^2c^2 + m^2c^4$ 变成 $E^2 = p^2 + m^2$；德布罗意波长 $\lambda = h/p$ 变成 $\lambda = 1/p$。

<span class="marginnote">怎么换算？查量纲：$[E] = [m] = [p]$，$[x] = [t] = [1/E]$。要把质量「0.5 GeV」换算成 kg，用 $1\,\text{GeV} = 1.78\times10^{-27}\,\text{kg}$（因为 $m = E/c^2$，$c^2$ 只在这里显身）。</span>

这套记号的实用价值立刻显现：**说「质子质量 $m_p = 0.938$ GeV」比「$1.67\times10^{-27}$ kg」更有物理直觉**——它同时告诉你，产生质子-反质子对至少需要约 1.88 GeV 能量。质量、动量、能量三位一体，都是 GeV。

## 2 能量单位：电子伏特家族

基本能量单位是**电子伏特（electron-volt, eV）**：一个电子通过 1 伏电压获得的能量。

$$
1\,\text{eV} = 1.602\times10^{-19}\,\text{J}
$$

日常在粒子物理中出现的是它的派生：

| 单位 | 值 | 代表对象 |
| --- | --- | --- |
| meV | 10⁻³ eV | 凝聚态能标 |
| keV | 10³ eV | X 射线、电子束缚能 |
| MeV | 10⁶ eV | 电子/μ 子质量、核能标 |
| GeV | 10⁹ eV | 质子质量、对撞机能标 |
| TeV | 10¹² eV | LHC 束流能量 |

<span class="marginnote">感觉一下数量级：1 焦耳 ≈ 6.24×10¹⁸ eV，而 LHC 单束流 7 TeV 分摊到约 10¹⁴ 个质子，每个质子约 7 µJ——质子的宏观「动能密度」其实不高，靠的是单个粒子能量与亮度。若把 7 TeV 换成宏观物体，约等于一只蚊子飞行时的动能。</span>

**单位换算表**（SI ↔ 自然单位）是每位粒子物理学家的随身工具：

- 质量：$1\,\text{GeV}/c^2 = 1.78\times10^{-27}\,\text{kg}$
- 动量：$1\,\text{GeV}/c = 5.34\times10^{-19}\,\text{kg·m/s}$
- 长度：$1\,\text{GeV}^{-1} = 0.197\,\text{fm}$（1 fm = 10⁻¹⁵ m）
- 时间：$1\,\text{GeV}^{-1} = 6.58\times10^{-25}\,\text{s}$

这条换算的威力在于：**所有长度、时间都用能量读出。** 比如强作用尺度约 1 fm = 5 GeV⁻¹，弱作用尺度约 1/100 fm = 500 GeV⁻¹——一张能量表就是一张尺度表。

## 3 公式解析：衰变宽度与寿命的关系

粒子物理里粒子的「寿命」常不以秒给出，而是以**宽度（width）$\Gamma$** 给出。宽度与寿命满足不确定关系：

$$
\Gamma = \frac{\hbar}{\tau} \quad\Longrightarrow\quad \Gamma\,\tau = \hbar
$$

在自然单位 $\hbar = 1$ 下简化为 $\Gamma = 1/\tau$。

- **第一步，物理意义**：宽度 $\Gamma$ 是粒子质量 $m$ 的不确定度。一个寿命 $\tau$ 很短的粒子，其能量-质量在测量上呈洛伦兹峰（Breit-Wigner 分布），峰半高全宽就是 $\Gamma$。
- **第二步，量纲**：$\tau$ 是时间，$1/\tau$ 在自然单位下是能量——所以 $\Gamma$ 用 MeV 度量。「$Z^0$ 玻色子宽度 2.5 GeV」的意思就是它的寿命 $\tau = 1/\Gamma \approx 1/(2.5\,\text{GeV}) \approx 2.6\times10^{-25}\,\text{s}$。
- **第三步，与衰变分支比的关系**：总宽度是各衰变道宽度之和，$\Gamma_{\text{tot}} = \sum_i \Gamma_i$，分支比 $B_i = \Gamma_i/\Gamma_{\text{tot}}$。测各道的分支比分布，就能反推粒子与哪些粒子耦合、强度如何——希格斯玻色子的发现与性质测量，本质上就是测它的宽度与分支比。
- **第四步，为什么用宽度而不用寿命**：寿命短到 10⁻²³ s 的粒子根本飞不出一个原子，实验测不到「飞行距离」；但宽度可以直接从共振曲线的形状读出来。**宽度是实验可见的，寿命是理论换算的。**

## 4 粒子的记号规范

读粒子物理文献，记号有一套不成文的规定，Griffiths 书中贯穿始终：

- **电荷上标**：$e^-$、$\mu^-$、$W^+$、$\pi^+$、$K^0$。中性粒子分两类：**真中性**（自身即反粒子，如 $\gamma$、$Z^0$、$\pi^0$）与**别致中性**（有反粒子，如 $K^0/\bar{K}^0$、$B^0/\bar{B}^0$）。
- **自旋-宇称 $J^P$**：如 $J^P = 0^-$（π）、$1^-$（ρ）、$1^+$（$a_1$）。$J$ 是总自旋，$P$ 是内禀宇称（±1）。这套标记是第三篇《介子与重子》的骨架。
- **超荷与同位旋**：$Y = B + S$（或更一般含粲、底），$I$ 与 $I_3$。记号 $I^G(J^{PC})$ 之类常见于粒子数据表。
- **多重态记号**：$\boldsymbol{1}$、$\boldsymbol{8}$、$\boldsymbol{10}$ 表示 SU(3) 表示——第 18 篇《SU(3) 八重态》的主角。

<span class="marginnote">一个常被忽视但至关重要的记号细节：<strong>$K^0$ 与 $\bar{K}^0$ 的混合物</strong>。中性 K 介子衰变时以 $K_S$、$K_L$ 两种本征态出现，寿命相差 600 倍——这是第二篇《离散对称性与宇称破坏》与第五篇《CP 破坏》的实验基础。记号里的「别致中性」总是藏着这种故事。</span>

粒子数据表（Particle Data Group, PDG）是这些记号与数值的权威总汇。学会查 PDG、读懂 $J^P$、$\Gamma$、分支比这几列，你就拿到了粒子物理的「字典」。

### 拓展：用自然单位快速估算

自然单位的最大实用价值是「心算估算」。几个常见问题可以一口答出：

- **对撞机能产生什么？** 两束各 7 TeV 的质子对撞，质心能量 $\sqrt{s} = 14$ TeV。要产生质量 $m$ 的新粒子，需要 $\sqrt{s} \gtrsim 2m$（对撞机）——所以 LHC 直接产生的最重粒子约 7 TeV，正好覆盖顶夸克（173 GeV）与任何质量低于约 5 TeV 的新物理。
- **一个尺度对应多少能量？** 质子半径约 0.84 fm，换算成能量标度：$1/(0.84\,\text{fm}) = 1/(0.84 \times 0.197\,\text{GeV}^{-1}) \approx 1.2$ GeV——这就是「强子标度约 1 GeV」的由来。弱作用尺度约 10⁻¹⁸ m，对应约 100 GeV——正好是 W/Z 质量量级。
- **寿命对应多少宽度？** 某粒子寿命 $10^{-24}$ s，则 $\Gamma = 1/\tau = 10^{24}\,\text{s}^{-1}$。换算：$1\,\text{GeV}^{-1} = 6.58\times10^{-25}$ s，所以 $\Gamma = 1.5$ GeV——这就是为什么强子共振宽度都是 GeV 量级。

| 想算什么 | 速算公式 | 结果 |
| --- | --- | --- |
| 新粒子质量上限 | $\sqrt{s}/2$ | LHC：约 7 TeV |
| 长度 → 能量 | $1/r$ | 0.84 fm → 约 1.2 GeV |
| 时间 → 宽度 | $1/\tau$ | $10^{-24}$ s → 1.5 GeV |

**这套心算的价值**：粒子物理里几乎每个量都能翻译成「多少 GeV」，而「多少 GeV」又直接告诉你它属于哪个能标、由哪台机器可及。自然单位不是「约定俗成的偷懒」，而是**把不同尺度的物理统一到同一个数轴上**——这本身就是粒子物理统一精神的体现。

## 6 小结

- **自然单位** $\hbar = c = 1$：能量、质量、动量同用 GeV；长度时间由能量的倒数给出（$1\,\text{GeV}^{-1} = 0.197$ fm）。
- **电子伏特家族**：meV → keV → MeV → GeV → TeV，覆盖从凝聚态到 LHC 的完整能标。
- **宽度-寿命**：$\Gamma = \hbar/\tau$，宽度可从共振曲线直接读出，寿命是换算结果。
- **记号规范**：$e^-/\bar{e}$、$J^P$、$K^0/\bar{K}^0$、多重态数字，PDG 是权威字典。
- **关键常数**：$m_e$、$m_p$、$\alpha$、$G_F$、$\alpha_s$、$m_H$——整个标准模型的数值骨架。

至此，粒子物理的「工具三件套」——粒子是什么、守恒量是什么、单位记号怎么说——已经齐备。下一篇进入本书的**对称性篇**：**诺特定理**，把「守恒量」从经验清单升级为对称性的必然推论。这将是我们推导同位旋、奇异数、Gell-Mann-Nishijima 公式的统一框架。
