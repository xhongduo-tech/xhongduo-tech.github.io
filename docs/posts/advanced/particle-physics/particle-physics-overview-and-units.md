## 为什么从粒子物理概览与单位制开始

本专题的其余篇章——夸克模型、电弱统一、希格斯机制、超越标准模型——都要在一张总地图上展开。这张地图就是**标准模型的粒子谱**：谁是基本粒子、谁传递相互作用、它们如何按代排列。而粒子物理的公式又写在一种特殊的语言里：**自然单位制**。如果不用 $\hbar = c = 1$，几乎每一条计算都要拖着光速和约化普朗克常数的尾巴，物理学家根本没法交谈。因此这一篇把两件事一并解决：先给你一张粒子总谱，再教你粒子物理的「通用度量衡」。

在课程体系中，本篇对应 Griffiths 第一章的历史导论与第三章相对论运动学的开头部分，也直接服务下一篇《对称性与守恒律》——因为守恒律正是作用在粒子谱上的「算盘」。

## 1 标准模型的粒子谱

标准模型（Standard Model, SM）的**物质粒子**是自旋 1/2 的费米子，分三代，每一代含两个夸克与两个轻子：

| 代 | 上型夸克 | 下型夸克 | 带电轻子 | 中微子 |
| --- | --- | --- | --- | --- |
| 第一代 | 上夸克 $u$ | 下夸克 $d$ | 电子 $e^-$ | $\nu_e$ |
| 第二代 | 粲夸克 $c$ | 奇异夸克 $s$ | $\mu^-$ | $\nu_\mu$ |
| 第三代 | 顶夸克 $t$ | 底夸克 $b$ | $\tau^-$ | $\nu_\tau$ |

<span class="marginnote">注意「代」的英文是 generation；每一代的高一代粒子几乎只是重一些的复制品。为什么恰好三代、为什么代际质量悬殊，标准模型本身不回答——这是第五篇《超出标准模型的新物理》的悬案之一。</span>

传递相互作用的**规范玻色子**自旋为 1：光子 $\gamma$（电磁）、胶子 $g$（强）、$W^\pm$ 与 $Z^0$（弱）；外加自旋 0 的希格斯玻色子 $H$，负责赋予粒子质量。总计 6 夸克 + 6 轻子 + 6 规范玻色子 + 1 希格斯，外加各自的反粒子，构成了我们今天称之为「基本粒子」的全部成员。

一个常被忽略却极其重要的事实：**普通物质只需第一代粒子**。质子由 $uud$ 构成、中子由 $udd$ 构成，电子绕核运行，光子传递电磁力。第二、三代粒子在宇宙中几乎不现身，只活在加速器与宇宙线里。它们的「多余」正是粒子物理最深的问题之一。

## 2 自然单位制：$\hbar = c = 1$

粒子物理的第一条约定是**把单位造得让公式干净**。物理常数只有在单位制里才有数值，我们可以选择一套单位，让 $\hbar = c = 1$。这样做的理由：

- 能量与质量等同：由 $E = mc^2$，在 $c=1$ 时质量直接用能量表示，1 eV 的质量等于 $1\ \mathrm{eV}/c^2$。粒子数据表里「电子质量 $m_e = 0.511\ \mathrm{MeV}$」说的就是这个。
- 长度与时间等同：由 $\Delta E \Delta t \sim \hbar$，在 $\hbar=1$ 时长度、时间、能量互为倒数。1 $\mathrm{GeV}^{-1}$ 的距离约等于 $0.197\ \mathrm{fm}$。

<span class="marginnote">换算密钥只有一条：$\hbar c = 197.3\ \mathrm{MeV\cdot fm}$（约 200 MeV·fm）。凡是要把能量倒成长度，或把长度倒成能量，都用它；记得住 197.3 就记住了粒子物理的全部单位换算。</span>

这套单位制的代价是**验证量纲时要小心**。例如把 $\hbar c = 197.3\ \mathrm{MeV\cdot fm}$ 写进公式前，先确认两边都有质量/能量的量纲。习惯之后，你会觉得拖着一堆 $c$ 的教科书反而碍眼。

## 3 不变质量与两体系统

粒子物理最常用的运动学量不是能量或动量本身，而是**不变质量（invariant mass）**：它由四维动量组合而成，在一切洛伦兹参考系里取同一数值。

对单粒子，不变质量就是静止质量 $m$；对一个由多个粒子组成的系统，定义其四维总动量为各粒子四动量之和，于是**系统不变质量**

$$
M^2 = \left(\sum_i E_i\right)^2 - \left|\sum_i \mathbf{p}_i\right|^2
$$

（自然单位下 $c=1$）。这一量有两个决定性优点：

- **它是洛伦兹不变量**：无论从哪个参考系看，$M$ 都相同。实验中末态粒子的能量动量测得后，就可以算出「产生它的母粒子质量」——即使母粒子从未被直接探测到。
- **它能诊断「母粒子」**：若某共振态衰变为若干个可测粒子，把它们的不变质量画成直方图，会在母粒子质量处出现一个峰。2012 年发现希格斯玻色子，正是靠 $H \to \gamma\gamma$ 与 $H \to ZZ^*$ 事例中两光子（或两轻子对）不变质量谱上的峰值。

## 4 公式解析：不变质量的三种用法

$$
M^2 = \left(\sum_i E_i\right)^2 - \left|\sum_i \mathbf{p}_i\right|^2
$$

- **$E_i$**：第 $i$ 个末态粒子的能量。注意是**总和再平方**，不是平方再求和——这是「加性」与「平方」次序的差别，容易算错。
- **$\mathbf{p}_i$**：第 $i$ 个末态粒子的三维动量矢量。**总和是矢量求和**，先画图再相加，别把方向丢掉。
- **$M$**：系统的不变质量，即母粒子的质量。静止系里（总动量 $=0$），$M = \sum_i E_i$，退化为「把能量直接相加」。

三个典型场景：

- **两束对撞**：$e^+ e^-$ 对撞中，正负电子对撞湮灭产生 $Z^0$。质心系里 $M = 2E_e$，扫能量扫描出的共振峰位置就是 $m_Z \approx 91.2\ \mathrm{GeV}$。
- **衰变**：$K^+ \to \pi^+ \pi^0$，用末态两个 π 的能量动量反推 $m_K \approx 494\ \mathrm{MeV}$，与直接测量一致。
- **丢失能量**：中微子逃出探测器带走了能量动量，末态「看不到」它。这时用可见粒子算出的不变质量会偏小——这正是 $W$ 质量测定里最难啃的部分。

## 5 能量标度：从 eV 到普朗克质量

粒子物理用一套能量标度丈量世界，理解它们是理解「什么实验能做什么」的关键：

| 标度 | 数值 | 对应的物理 |
| --- | --- | --- |
| 电子质量 | 0.511 MeV | 原子物理、康普顿散射 |
| 质子质量 | 938 MeV | 核物理、强子质量谱 |
| $Z^0$ 质量 | 91.2 GeV | 电弱标度、LEP 对撞机 |
| 希格斯质量 | 125.1 GeV | 电弱对称破缺标度 |
| LHC 质心能 | 13–14 TeV | 当前人类能造的最高能量 |
| 普朗克质量 | $1.22\times 10^{19}\ \mathrm{GeV}$ | 量子引力标度，遥不可及 |

<span class="marginnote">普朗克质量 $M_P = \sqrt{\hbar c / G} \approx 1.22\times 10^{19}\ \mathrm{GeV}$，在自然单位下量纲与质量相同。实验室能量离它差着 16 个数量级——这就是为什么「大统一」「量子引力」只能靠理论推断与早期宇宙。</span>

一个直观的换算：**要「看见」多小的尺度，就要用多高的能量**。德布罗意波长 $\lambda = \hbar/p$，1 TeV 的粒子波长约 $10^{-18}$ m，恰好能「探」到弱作用尺度；而要在 100 TeV 直接产生大统一粒子，需要的对撞机大约比现有 LHC 大 7 倍。

| 常数 | 数值 | 用途 |
| --- | --- | --- |
| $\hbar c$ | 197.3 MeV·fm | 长度 ↔ 能量换算 |
| $\hbar$ | $6.582\times 10^{-22}$ MeV·s | 寿命 ↔ 宽度换算 |
| $k_B$ | $8.617\times 10^{-5}$ eV/K | 温度 ↔ 能量换算 |
| $G_F$ | $1.166\times 10^{-5}\ \mathrm{GeV}^{-2}$ | 弱作用强度 |
| $\alpha$ | $1/137.036$ | 精细结构常数 |
| $m_e$ | 0.511 MeV | 电子质量 |
| $m_\mu$ | 105.66 MeV | μ 子质量 |
| $m_p$ | 938.27 MeV | 质子质量 |

### 单位换算三步法

把 SI 量换成自然单位只需三步。以「温度 1 MeV 对应的宇宙温度」为例：

- **第一步，找出要用的换算常数**：温度要转能量，用的是玻尔兹曼常数 $k_B = 8.617\times 10^{-5}\ \mathrm{eV/K}$。
- **第二步，倒过来算**：$1\ \mathrm{MeV} / k_B = 10^6 / 8.617\times 10^{-5} \approx 1.16\times 10^{10}\ \mathrm{K}$——早期宇宙在 $t \sim 1$ s 时温度约 $1.2\times 10^{10}$ K，正是中微子退耦的温度。
- **第三步，验证直觉**：$1\ \mathrm{eV} \approx 11605\ \mathrm{K}$，室温 $300\ \mathrm{K} \approx 0.026\ \mathrm{eV}$——这正好是「$k_B T$ 等于室温热能」的说法来源。

再练一个长度换算：**1 fm 是多少 GeV⁻¹？** $1\ \mathrm{fm} = 197.3\ \mathrm{MeV^{-1} \cdot fm} / 197.3\ \mathrm{MeV\cdot fm} = 197.3^{-1}\ \mathrm{GeV^{-1}} \approx 5.07\ \mathrm{GeV^{-1}}$。于是质子半径 $0.84\ \mathrm{fm} \approx 4.3\ \mathrm{GeV^{-1}}$——「强子尺度 ~ GeV⁻¹」的说法由此而来。

## 6 小结

- **标准模型粒子谱**：三代费米子（6 夸克 + 6 轻子）+ 规范玻色子（$\gamma, g, W^\pm, Z^0$）+ 希格斯 $H$；普通物质只需第一代。
- **自然单位制**：取 $\hbar = c = 1$，质量、能量用同一种单位（eV），长度、时间互为倒数。
- **换算密钥**：$\hbar c = 197.3\ \mathrm{MeV\cdot fm}$，是能量↔长度换算的唯一常数。
- **不变质量** $M^2 = (\sum E_i)^2 - |\sum \mathbf{p}_i|^2$ 是洛伦兹不变量，是「看不见的母粒子」的质量来源。
- **能量标度**：从 eV 到 $10^{19}$ GeV 横跨 19 个数量级，德布罗意关系把能量与可探尺度绑在一起。

在下一节，我们将进入粒子物理的「算盘」：为什么某些量子数守恒、某些不守恒？这就是**对称性与守恒律**。
