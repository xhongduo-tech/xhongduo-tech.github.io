# Gell-Mann-Nishijima公式

<div class="epigraph">

## 为什么从这条公式开始

同位旋、超荷、奇异数，本组前三章的量子数看似各自独立。盖尔曼与西岛和彦各自独立发现，它们被一条简洁的代数式锁定：

$$
Q = I_3 + \frac{Y}{2}
$$

这条 **Gell-Mann-Nishijima 公式**把粒子的电荷 $Q$ 分解为同位旋第三分量 $I_3$ 与超荷 $Y$ 的组合。它的价值有三层：**核对**——任何强子的三个量子数必须满足它；**分类**——它决定了强子谱在 $(I_3, Y)$ 平面上的排布；**预言**——它把「电荷」这个电磁性质与「同位旋、超荷」这些强作用量子数锁在一起，暗示它们来自同一个更深的结构。理解这条公式，等于拿到了第三篇《夸克模型》的门票。

## 1 公式的来历：两条经验规律的交汇

1953–1956 年间，盖尔曼与西岛（Nishijima）整理奇异粒子数据时发现两条独立规律：

- 电荷 $Q$、重子数 $B$、奇异数 $S$ 之间存在关系 $Q = I_3 + (B + S)/2$。
- 把 $B + S$ 命名为**超荷 $Y$**，公式化为对称形式 $Q = I_3 + Y/2$。

验证几个粒子立刻清楚：

| 粒子 | $I_3$ | $Y$ | $Q = I_3 + Y/2$ |
| --- | --- | --- | --- |
| $p$ | +1/2 | 1 | $1/2 + 1/2 = 1$ ✅ |
| $n$ | −1/2 | 1 | $-1/2 + 1/2 = 0$ ✅ |
| $\pi^+$ | +1 | 0 | $1 + 0 = 1$ ✅ |
| $\pi^0$ | 0 | 0 | $0$ ✅ |
| $K^+$ | +1/2 | 1 | $1$ ✅ |
| $\Lambda$ | 0 | 0 | $0$ ✅ |
| $\Xi^-$ | −1/2 | −1 | $-1/2 - 1/2 = -1$ ✅ |

<span class="marginnote">公式的美在于它把「电磁的电荷」与「强作用的 $I_3, Y$」统一进一个关系——电磁作用原来不是外来的，它「知道」强子谱的内部结构。后来夸克模型解释：因为 $Q$、$I_3$、$Y$ 都只是夸克量子数的线性组合。</span>

值得注意的是，这条公式对**所有**强子（介子、重子）都成立。这不是偶然——在夸克图像里，$Q$、$I_3$、$Y$ 分别是夸克电荷、同位旋、超荷的加和，而每个夸克自身的这三个量都满足同一公式（第 3 节验证）。

## 2 公式的深层意义：强子谱在 $(I_3, Y)$ 平面上的规则排布

Gell-Mann-Nishijima 公式的推论是：**每个同位旋多重态在 $Y$ 轴上占据固定一行，电荷由 $I_3$ 决定。** 于是强子按 $(I_3, Y)$ 排布，形成规则图案。例如自旋-宇称 $J^P = 1/2^+$ 的重子：

| 多重态 | $Y$ | $I$ | 成员 |
| --- | --- | --- | --- |
| 核子 | 1 | 1/2 | $p, n$ |
| $\Lambda$ | 0 | 0 | $\Lambda$ |
| $\Sigma$ | 0 | 1 | $\Sigma^+, \Sigma^0, \Sigma^-$ |
| $\Xi$ | −1 | 1/2 | $\Xi^0, \Xi^-$ |

把这些成员画在 $Y$-$I_3$ 平面上，恰好构成一个**六边形（八重态）**。盖尔曼的八正法正是以此为起点，把强子按 SU(3) 的表示排布（第 18 篇）。公式在这里扮演了「排布规则」的角色：**电荷不再是每个粒子孤立查表的值，而是由它在 $(I_3, Y)$ 平面上的位置唯一决定。**

更妙的推论：**同一同位旋多重态内电荷不同（如 $\pi^+, \pi^0, \pi^-$），但 $Y$ 相同**——所以多重态的「行」由 $Y$ 标记，「列」由 $I_3$ 标记，电荷沿列递增。物理学家可以只看强子的 $Y$ 与 $I_3$ 就写出它的电荷，反之亦然。

## 3 公式解析：在夸克层面验证并重写

夸克模型里，$Q$、$I_3$、$Y$ 都是加性的，公式对单夸克成立则对任意强子自动成立。以三种轻夸克为例：

| 夸克 | $Q$ | $I_3$ | $Y$ | 验证 $Q = I_3 + Y/2$ |
| --- | --- | --- | --- | --- |
| $u$ | +2/3 | +1/2 | 1/3 | $1/2 + 1/6 = 2/3$ ✅ |
| $d$ | −1/3 | −1/2 | 1/3 | $-1/2 + 1/6 = -1/3$ ✅ |
| $s$ | −1/3 | 0 | −2/3 | $0 - 1/3 = -1/3$ ✅ |

**第一步，确认 $Y$ 对夸克的值**：$u$、$d$ 有 $Y = 1/3$（因为 $B = 1/3$、$S = 0$）；$s$ 有 $Y = B + S = 1/3 - 1 = -2/3$。
**第二步，验证每个夸克**：代入公式，三个轻夸克全部满足。
**第三步，强子验证**：任何强子由夸克线性组合，两边都是加性的，逐夸克满足 ⇒ 整体满足。例如 $K^+ = u\bar{s}$：$Q = 2/3 + 1/3 = 1$，$I_3 = 1/2 + 0 = 1/2$，$Y = 1/3 + 2/3 = 1$，代入得 $1 = 1/2 + 1/2$ ✅。
**第四步，看出深层结构**：公式之所以对所有强子成立，是因为**夸克层面就成立**。而夸克层面 $Q = I_3 + Y/2$ 并非巧合——它源于 $u$、$d$、$s$ 之间由 SU(3) 对称性确定的量子数赋值。公式因此是味道 SU(3) 群论在量子数空间的一个投影。

## 4 用公式判断新粒子的量子数

Gell-Mann-Nishijima 公式最大的实用价值：**当你测得一个强子的部分量子数，可以用公式推出其余部分。** 例如：

发现一个新共振态，已知其电荷与同位旋多重态结构，可由 $Y = 2(Q - I_3)$ 反推超荷，从而确定其奇异数。
1964 年 $\Omega^-$ 的预言正是如此：分类学给出 $I = 0$、$S = -3$，由公式得 $Y = -2$、$Q = 0 + (-1) = -1$——预言 $\Omega^-$ 带一个单位负电荷、质量约 1672 MeV。实验结果完全吻合。

<span class="marginnote">公式还能反过来「排除错误」：若某个候选粒子的量子数组合不满足 $Q = I_3 + Y/2$，那它要么不是强子，要么数据标错了。粒子物理数据分析里，这条公式是最快的「自检器」。</span>

**辨析｜易错点：** 公式中 $Y$ 用**超荷**而非奇异数。若你记的是 $Q = I_3 + (B+S)/2$，别忘 $B+S$ 对介子是 $S$ 本身（$B=0$），对重子是 $1+S$。混淆 $Y$ 与 $S$ 是初学最常犯的错——介子 $K^+$ 有 $Y = 1$ 但 $S = 1$，巧合；而 $\Lambda$ 有 $Y = 0$ 但 $S = -1$，就不一样了。**先想清楚对象是介子还是重子，再代入公式。**

## 5 公式的现代推广：从 SU(3) 到电弱统一

Gell-Mann-Nishijima 公式在标准模型里还有一个更深刻的现代版本。在电弱统一理论中，电荷 $Q$ 与弱同位旋 $T_3$、弱超荷 $Y_W$ 满足

$$
Q = T_3 + \frac{Y_W}{2}
$$

结构上与强子版的公式完全相同，只是把「强同位旋 $I_3$、强超荷 $Y$」换成了「弱同位旋 $T_3$、弱超荷 $Y_W$」。这意味着：**同样的代数结构在强弱两种相互作用里各自出现一次**——这不是巧合，而是「把粒子按某种量子数分群」这一普遍方法在不同力下的应用。电弱版公式决定了电子、中微子、W/Z 玻色子的电荷与弱荷（第 24 篇《电弱统一》详解）。<span class="marginnote">Gell-Mann-Nishijima 公式的「可迁移性」是粒子物理方法论的绝佳示范：同一套量子数线性关系，在强作用（$I_3, Y$）与弱作用（$T_3, Y_W$）中各出现一次，背后是两次独立的对称性自发破缺。</span>

### 拓展：公式背后的超荷赋值——从数据到约定

Gell-Mann-Nishijima 公式在历史上是从实验数据「凑」出来的，但它的超荷赋值有一套逻辑，值得看清：

- **重子数守恒 + 奇异数守恒**决定了 $Y = B + S$ 是守恒的（在强作用中）——这是公式成立的前提。
- **对核子**：$B = 1$、$S = 0$，所以 $Y = 1$。对 π 介子：$B = 0$、$S = 0$，$Y = 0$。
- **对奇异粒子**：$K^+$ 有 $S = +1$、$Y = 1$；$\Lambda$ 有 $S = -1$、$Y = 0$；$\Xi$ 有 $S = -2$、$Y = -1$。**超荷恰好按奇异数步进**——这就是「超荷轴」的由来。

把公式改写成实验可检验的形式：

$$
Y = 2(Q - I_3)
$$

- **反推超荷**：只要测得一个强子的电荷与同位旋第三分量，就能预言它的超荷（从而奇异数）。$\Omega^-$ 的预言正是这个流程：$Q = -1$、$I_3 = 0$ $\Rightarrow Y = -2$ $\Rightarrow S = -3$。
- **公式的「闭合性」**：它把三个独立来源的量子数（电磁的 $Q$、强子的 $I_3$、味道的 $S$）锁在一起——任何「自由组合」的强子候选若对不上，就直接出局。

**一个历史注记**：西岛与盖尔曼独立得到这条公式的时间相近（1953–1956），反映了「数据足够多时，正确的代数结构会自己浮现」。这条公式不是第一性原理推导，但它揭示的「$Q$、$I_3$、$Y$ 线性相关」强有力地指向更深的 SU(3) 结构——**它是八正法的代数预演**。

## 6 小结

- **公式**：$Q = I_3 + Y/2$，其中 $Y = B + S$，对一切强子成立。
- **来历**：盖尔曼与西岛独立从奇异粒子数据归纳，是经验规律被理论化的典范。
- **分类学意义**：强子谱在 $(I_3, Y)$ 平面规则排布，电荷由平面位置唯一决定，八正法由此展开。
- **夸克根基**：公式在夸克层面逐条成立（$u$、$d$、$s$ 都满足），故对任意组合自动成立。
- **电弱推广**：$Q = T_3 + Y_W/2$，同一代数在弱相互作用中重现，通到第四篇。

本组的量子数之旅到此，离散对称性还欠着账。下一篇进入**CPT 定理**：电荷共轭、宇称、时间反演三种离散变换的乘积为何必定守恒？它是所有量子数故事里最「铁」的一条定律。
