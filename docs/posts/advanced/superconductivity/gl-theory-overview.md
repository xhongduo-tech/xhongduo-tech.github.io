## 为什么从 GL 理论开始

伦敦理论告诉我们超导有两个尺度 $\lambda$、$\xi$，却没告诉我们它们从哪来。金兹堡-朗道理论（GL 理论，1950）给出答案的第一步：**超导态可以用一个复序参量 $\Psi(\boldsymbol{r})$ 来描述**，所有宏观性质都从这个序参量在空间中的分布推出来。它是朗道二级相变理论的超导化，也是通往 BCS 微观理论的桥——**GL 理论提供了语言，BCS 理论提供了语法**。学这一章，关键不是背两个方程，而是理解「用一个序参量统一穿透深度、相干长度、临界场」这件事本身，就是一次深刻的物理经济学。<span class="marginnote">GL 理论发表于 1950 年，比 BCS 早七年。它的惊人之处在于：<strong>一个建立在「猜序参量」上的现象学理论，日后被证明在 $T_c$ 附近与 BCS 严格一致</strong>——1959 年戈尔科夫（L. P. Gor'kov）从 BCS 出发「推导」出了 GL 方程，为这场跨越七年的对话画上句号。</span>

## 1 序参量：超导态的身份标签

朗道相变理论的中心思想：**每一个连续相变，都对应一个从零生长起来的「有序度」——序参量（order parameter）**。铁磁体的序参量是磁化强度，反铁磁的是交错磁化，而超导体的序参量是一个**复标量场**：

$$
\Psi(\boldsymbol{r}) = |\Psi(\boldsymbol{r})|\,e^{i\varphi(\boldsymbol{r})}
$$

模方 $|\Psi|^2 = n_s$ 正比于超流电子密度，相位 $\varphi$ 是宏观量子相位。<span class="marginnote">复序参量是超导独有的「奢侈」：它的相位 $\varphi$ 不是摆设——约瑟夫森效应、磁通量子化、涡旋的相位绕数，全都从 $\varphi$ 的空间变化读出。$T > T_c$ 时 $|\Psi| = 0$（无序），$T < T_c$ 时 $|\Psi| > 0$（有序），这是二级相变的模板。</span>

GL 理论假设：在 $T_c$ 附近，超导态的吉布斯自由能密度可以对 $\Psi$ 做小量展开，保留到最低阶允许的项：

$$
g_s = g_n + \alpha(T)\,|\Psi|^2 + \frac{\beta}{2}\,|\Psi|^4 + \frac{1}{2m^*}\left|(-i\hbar\nabla - e^*\boldsymbol{A})\Psi\right|^2 + \frac{B^2}{2\mu_0}
$$

$\alpha(T) = \alpha_0(T - T_c)$ 在 $T_c$ 处变号，是相变的引擎；$\beta > 0$ 保证自由能有下界；梯度项与矢势项模拟「序参量空间不均匀」的代价；末项是磁场能。$m^*, e^*$ 是超流元胞的有效质量与电荷——BCS 理论后来给出 $e^* = 2e$（库珀对的电荷）。

## 2 两个 GL 方程：序参量的「运动方程」

对 $g_s$ 分别对 $\Psi^*$ 与 $\boldsymbol{A}$ 做变分，得到两个 GL 方程，它们是超导态在空间中的完整约束：

**第一 GL 方程**（序参量的非线性薛定谔方程）：

$$
\alpha\,\Psi + \beta\,|\Psi|^2\Psi + \frac{1}{2m^*}\left(-i\hbar\nabla - e^*\boldsymbol{A}\right)^2\Psi = 0
$$

**第二 GL 方程**（超流电流的表达式）：

$$
\boldsymbol{j}_s = \frac{e^*}{2m^*}\left[\Psi^*\left(-i\hbar\nabla - e^*\boldsymbol{A}\right)\Psi + \text{c.c.}\right]
$$

注意第一方程里 $\Psi^2$ 的**非线性**：序参量自己和自己相互作用，这正是「配对」在现象学上的体现——密度越大，越难再增大。第二方程则是电流密度的量子力学表达式，把 $\Psi$ 的相位梯度翻译成真实的超流。

## 3 公式解析：两个尺度如何从 GL 涌现

GL 理论最漂亮的产出，是它**推导出**伦敦理论的两个尺度，而不是把它们当作输入：

$$
\xi(T) = \frac{\hbar}{\sqrt{2m^*|\alpha(T)|}}, \qquad \lambda(T) = \sqrt{\frac{m^*}{\mu_0 e^{*2}|\Psi|^2}}
$$

- **第一步，解均匀系统**：$\boldsymbol{A} = 0$、序参量均匀时，第一 GL 方程化为 $\alpha\Psi + \beta|\Psi|^2\Psi = 0$，解得 $|\Psi|^2 = |\alpha|/\beta$。它给出平衡序参量与「凝聚能密度」$\Delta g = B_c^2/2\mu_0 = |\alpha|^2/2\beta$。
- **第二步，读出 $\xi$**：让序参量偏离均匀解一个小量，方程里的梯度项给出恢复的特征长度 $\xi(T) = \hbar/\sqrt{2m^*|\alpha|}$。因为 $\alpha \propto (T_c - T)$，所以 **$\xi(T) \propto (T_c - T)^{-1/2}$，在 $T_c$ 处发散**——这就是**GL 相干长度**。
- **第三步，读出 $\lambda$**：把均匀解的 $|\Psi|^2$ 代入第二方程附近的屏蔽分析，得到 $\lambda(T) \propto (T_c - T)^{-1/2}$——同样在 $T_c$ 处发散。两个尺度同型发散，但比值恒定。
- **第四步，Ginzburg-Landau 参数**：**$\kappa = \lambda(T)/\xi(T)$ 与温度无关**，它是材料的固有属性。GL 理论进一步证明：$\kappa < 1/\sqrt2$ 为 I 类超导、$\kappa > 1/\sqrt2$ 为 II 类超导——两类超导的分野第一次有了**定量判据**。

顺带一提，临界场 $H_c$ 也由序参量读出：$B_c = \sqrt{\mu_0|\alpha|^2/\beta}$。**穿透深度、相干长度、临界场——三件伦敦理论里各自为政的事，在 GL 里是同一个 $\Psi$ 的三个投影。**

## 4 GL 理论能做什么：从界面能到涡旋

GL 理论的实用价值在空间不均匀问题，这是伦敦理论做不到的：

- **界面能**：在正常-超导界面上序参量从零爬升到 $|\Psi|^2 = |\alpha|/\beta$，宽度约 $\xi$；磁场渗入宽度约 $\lambda$。两者的竞争给出 $\sigma_{ns}$ 的正负，定量地重演了《伦敦方程与宏观电磁性质》里 $\kappa$ 的分野。<span class="marginnote">GL 还能给出界面能的解析式 $\sigma_{ns} \approx B_c^2\,\delta/2\mu_0$，其中 $\delta$ 是 $\lambda$ 与 $\xi$ 的差——这个公式是判断「涡旋是否值得形成」的判据，也是后续钉扎物理的基础。</span>
- **薄膜与几何效应**：薄膜的 $T_c$ 随厚度变化、涡旋在盘状样品里的布洛赫-阿布里科索夫构型、微桥的相位滑移——GL 方程都能算，是「介观超导」工具箱的底座。
- **时间依赖的 TDGL**：加上弛豫动力学，TDGL 方程是模拟磁通运动、涡旋动力学与相滑移的标准工具，也是理解非平衡超导的桥梁。

## 5 GL 理论的边界：它在哪里失效

GL 理论如此好用，也正因为如此，必须清楚它的**适用范围**——三条边界，条条都指向物理的深层：

- **温度边界**：自由能展开在 $|\Psi|$ 小时才可靠，严格说只在 $T_c$ 附近（$|T - T_c|/T_c \ll 1$）成立。远离 $T_c$，序参量不再小，高阶项与微观修正进场——这时要换成 BCS 的定量计算。<span class="marginnote">高温超导的相图里，赝能隙区与临界涨落区都「逃离」了 GL 的平均场描述——那正是《高温超导》《超导涨落效应》两篇的战场。</span>
- **局域性边界**：GL 是局域理论，而纯金属里 $\xi_0 \gg \lambda_L$（Pippard 非局域）。但戈尔科夫证明了一个重要的「翻盘」：**在脏极限（dirty limit，平均自由程 $l \ll \xi_0$）下，GL 方程反而在整个温区都相当精确**——这正是合金与工程超导材料（NbTi 正是脏极限）的幸运，也让 GL 成为工程设计的标准工具。
- **涨落边界**：GL 是平均场理论，忽略了序参量的热涨落。在常规三维超导里涨落可忽略；但低维体系、纳米颗粒、高温超导的短相干长度，都把涨落放大到不可忽视——那需要《超导涨落效应》的配分函数语言。

理解这三条边界，才算是真正「拥有」了 GL 理论：**知道它哪里对，也知道它哪里不对，用起来才不会越界**。

## 6 阿布里科索夫的涡旋预言：GL 的胜利

GL 理论最辉煌的成就，是 1957 年阿布里科索夫（A. A. Abrikosov）用它在 $\kappa > 1/\sqrt2$ 的情形下预言了**涡旋态**：外场超过 $H_{c1}$ 时，磁场以单根涡旋（每根携带一个磁通量子 $\Phi_0 = h/2e$）的形态渗入超导体，涡旋按三角格排列——即**阿布里科索夫涡旋晶格（Abrikosov vortex lattice）**。

当时这个预言被主流物理学界忽视——因为实验上「干净」的 I 类超导一统天下，没有人相信磁场真能钻进超导体。直到 1960 年代合金与 Nb$_3$Sn 等高场材料普及、小角中子散射直接看到涡旋晶格，阿布里科索夫的预言才被承认，并最终为他赢得 2003 年诺贝尔物理学奖。<span class="marginnote">涡旋的相位绕数正是 §1 里 $\varphi$ 的用武之地：绕涡旋中心一圈，相位改变 $2\pi$，磁场被「锁」在芯子里。<strong>磁通量子化 + 相位绕数 + 涡旋晶格</strong>，这三位一体是《二类超导体与磁通涡旋》一篇的主角。</span>

对照表把 GL 的家底收拢：

| 概念 | GL 表达式 | 物理意义 |
| --- | --- | --- |
| 序参量 | $\Psi = |\Psi|e^{i\varphi}$ | 超导有序度与相位 |
| 平衡密度 | $|\Psi|^2 = |\alpha|/\beta$ | 超流电子密度 $n_s$ |
| 相干长度 | $\xi = \hbar/\sqrt{2m^*|\alpha|}$ | 序参量恢复的尺度 |
| 穿透深度 | $\lambda = \sqrt{m^*/(\mu_0 e^{*2}|\Psi|^2)}$ | 磁场渗入的尺度 |
| GL 参数 | $\kappa = \lambda/\xi$ | I/II 类判据（$1/\sqrt2$ 分界） |
| 临界场 | $B_c = \sqrt{\mu_0|\alpha|^2/\beta}$ | 凝聚能密度的平方根 |

## 7 小结

- **GL 理论**把超导态编码为一个复序参量 $\Psi$，是朗道二级相变理论的超导化——$e^* = 2e$ 暗示配对，为 BCS 埋伏笔。
- **两个 GL 方程**分别给出序参量的空间分布与超流电流；第一方程的非线性项 $|\Psi|^2\Psi$ 是「配对相互作用」的现象学化身。
- **GL 参数** $\kappa = \lambda/\xi$ 与温度无关，$1/\sqrt2$ 是 I/II 类超导的定量分水岭——两类分野第一次有了判据。
- **$\xi(T)$、$\lambda(T)$ 都在 $T_c$ 处以 $(T_c-T)^{-1/2}$ 发散**——临界点附近一切尺度都「发炎」，这是二级相变的共性。
- **阿布里科索夫涡旋**（1957）是 GL 理论最成功的预言：$\kappa > 1/\sqrt2$ 时磁场碎裂成 $\Phi_0$ 涡旋、排成三角格——二十世纪后期才被实验完全证实。
- GL 是通往 BCS 的桥：戈尔科夫 1959 年从 BCS 推导出 GL，两者在 $T_c$ 附近等价——**现象学与微观理论在临界点会师**。
- **适用边界**：GL 只在 $T_c$ 附近、局域、平均场三个前提下严格成立；脏极限（NbTi 类合金）是它的「主场」，低维与高温超导则被涨落送出边界。
- **方法观**：GL 的「一个序参量统一多个可观测」是凝聚态物理最可复制的思维模板——本博客《凝聚态物理》专题的对称性破缺叙述正是同一脉络。
- **实验印证**：小角中子散射、扫描霍尔显微镜、比脱纹饰（Bitter decoration）都直接「看见」了涡旋三角格——GL 预言的几何不是纸上谈兵。
- **思想史坐标**：涡旋预言 1957 年诞生、半个世纪后（2003 诺贝尔奖）才被广泛承认——正确理论等待实验的时代错位，本身就是物理史的一课。

在下一节，我们将把 GL 预言的涡旋态彻底展开——磁通量子化如何给出 $\Phi_0$、涡旋如何在 II 类超导里形成混合态与阿布里科索夫晶格、以及钉扎如何决定工程电流密度，这就是 **二类超导体与磁通涡旋**。
