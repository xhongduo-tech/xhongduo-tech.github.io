## 为什么评测要专门测「说谎」

前几篇评测回答「模型会什么」，而幻觉（hallucination）要回答另一个问题：**模型会不会一本正经地编造？** 一个知识面再广的模型，若在不确定时自信地胡编，在医疗、法律、金融场景里就不是「能力缺陷」而是「安全风险」。评测必须专门把它揪出来。

所谓**幻觉**，是指**模型生成了与事实不符、或与给定来源不一致的内容**。它不同于「答错」——答错是能力不足，幻觉是**在错误上叠加了自信**。评判幻觉的核心难点在于：**幻觉没有标准答案，只能靠「与事实/来源的一致性」来判**。<span class="marginnote">Lin, S. 等，「TruthfulQA: Measuring How Models Mimic Human Falsehoods」，ACL 2022；Li, J. 等，「HaluEval: A Large-Scale Hallucination Evaluation Benchmark for Large Language Models」，2023。前者测「会不会复述人类的错误认知」，后者测「能否检测出已发生的幻觉」。</span>

把幻觉评测与前面的基准并排看，它的独特之处在于：知识基准有「标准答案」，代码基准有「编译测试」，而幻觉**没有天然的正确判据**——判定「这是不是编造」本身就需要外部事实或权威来源。这让幻觉评测天然依赖「裁判」，也让「裁判的偏见」成为绕不开的话题（见本专题第 5 篇）。

## 1 幻觉的两种源头

先建立分类，评测设计才谈得上针对性：

**忠实性幻觉（faithfulness hallucination）**：生成内容**偏离了给定来源**——如「请根据这篇文章摘要」，模型却写进了文章里没有的信息。这类幻觉发生在「有源任务」里，可以对照原文判定。

**事实性幻觉（factuality hallucination）**：生成内容**与客观事实不符**，即使没有给定来源也站不住脚——如问「谁发现了青霉素」，模型答「居里夫人」。这类幻觉发生在「开放问答」里，判定依赖外部事实。

**重点：幻觉评测的第一个设计决策，是选「忠实」还是「事实」作为标尺。** 前者判「对不对得上原文」，后者判「对不对得起世界」。两者所需的数据与裁判完全不同。

两类幻觉的判据、场景与缓解手段也各自成线，用表对照：

| 维度 | 忠实性幻觉 | 事实性幻觉 |
| --- | --- | --- |
| 违反对象 | 给定的来源文本 | 客观世界事实 |
| 典型场景 | 摘要、问答、翻译 | 开放问答、常识题 |
| 判定依据 | 对照原文即可 | 依赖外部事实 / 权威 |
| 常见成因 | 上下文遗忘、过度概括 | 知识缺口、复述错误认知 |

**为什么要先分这两类？** 因为缓解手段完全不同：忠实性幻觉靠「给足上下文 + 检索增强」缓解，事实性幻觉靠「拒答 + 外部校验」缓解。选错标尺，评测就测不到想测的东西——这正是幻觉评测区别于普通知识评测的第一道分岔。

## 2 TruthfulQA：测「会不会模仿人类的错」

TruthfulQA 选择了**事实性**这条线，但它的设计异常刁钻：**817 道题全部是「人类普遍容易答错」的问题**，分布在 38 个主题——误解、伪科学、阴谋论、都市传说、广告夸大等。题目故意不按教科书出，而是按「人类集体常识里的错误」出，用来测试一个假说：**大模型的「诚实度」，最大的敌人不是无知，而是模仿——模型在训练语料里学到的恰恰是人类说错话的方式。**

评测采用两个正交指标：

**真实度（truthfulness）**：回答是否避免了任何虚假陈述——回答「我不知道」也算真实；
- **信息度（informative）**：回答是否包含有用信息——真实但空洞的回答信息度为 0。

结果极具戏剧性：人类 94% 真实、96% 信息；而 GPT-3 175B 有 **58%** 的真实度、信息度却仅有 **7%**。<span class="marginnote">「58% 真实但 7% 信息」是 TruthfulQA 最著名的发现：模型学会了「不瞎说」却还没学会「好好说」——用「我不知道」蒙混过关能保真实度，却牺牲了实用性。TruthfulQA 因此坚持两个指标并列报告，缺一不可。</span>后续研究发现：模型越大，通常越真实（也更擅长「装无知」），但幻觉并未随规模消失——这为「对齐」刻下了一道刺眼的注解。

## 3 HaluEval：测「能否抓出幻觉」

如果说 TruthfulQA 测「会不会生成幻觉」，**HaluEval** 则测「能不能认出幻觉」。它构造了约 **3.5 万**样本，每样本是「一个问题/对话 + 一段回答 + 一个标签：这段回答是否包含幻觉」，覆盖问答、对话、摘要三类任务。回答由 ChatGPT 生成，幻觉由脚本与人工混合标注。

评测任务是**幻觉检测（hallucination detection）**：给模型一个「问题 + 回答」对，让它判断回答里有没有幻觉，并指出幻觉片段。这之所以重要，是因为检测是修正的前提——**在 RAG、摘要、智能体等系统里，「先检测幻觉、再触发重生成或拒答」是主流的兜底策略**（见第 10 篇智能体评测）。

把两套基准并排对照，测的东西其实完全不同：

| 维度 | TruthfulQA | HaluEval |
| --- | --- | --- |
| 任务形态 | 开放问答 | 问答 / 对话 / 摘要中的检测 |
| 规模 | 817 题 | 约 3.5 万样本 |
| 测什么 | 会不会**生成**幻觉 | 能不能**认出**幻觉 |
| 判据 | 真实度 + 信息度 | 与标注的一致性（F1） |
| 数据来源 | 人类精心设计的「易错题」 | LLM 生成 + 脚本/人工混合标注 |

一句话概括分工：**TruthfulQA 测「出题人能不能骗到你」，HaluEval 测「质检员能不能抓出骗子」**——一个管「产出」，一个管「质检」，构成了幻觉防线的一前一后。

## 4 公式解析：幻觉检测的 F1

幻觉检测是一个**二分类**问题，HaluEval 用标准分类指标评估。以「检测到幻觉」为正类，四种结果构成混淆矩阵：

| 预测 \ 实际 | 有幻觉 | 无幻觉 |
| --- | --- | --- |
| 检出 | TP（真阳性） | FP（误报） |
| 未检出 | FN（漏报） | TN（真阴性） |

三个指标定义如下：

$$
\text{Precision} = \frac{TP}{TP+FP}, \quad
\text{Recall} = \frac{TP}{TP+FN}, \quad
\text{F1} = \frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}
$$

拆成四步理解：

- **第一步，Precision 问「检出的有多少是真凶」**：分母是「所有被检出的」，分子是「检出且确实是幻觉的」。它惩罚误报——把好回答当成幻觉，同样浪费系统资源。
- **第二步，Recall 问「真凶被揪出了多少」**：分母是「所有真实存在的幻觉」，分子是「被检出的」。它惩罚漏报——幻觉漏网，危害最大。
- **第三步，F1 是两者的调和平均**：取调和而非算术平均，是为了**只在高分者拖低者时大幅降分**——Precision 与 Recall 差得越远，F1 越难看。
- **第四步，应用到 HaluEval**：把模型的检测结果与标注比对，逐类任务算 F1。一个「永远回答没幻觉」的模型 Recall 为 0、F1 为 0；一个「什么都检出」的模型 Precision 崩盘、F1 同样惨淡。

用一个 100 条样本的算例把三个指标落到具体数字上。设测试集里真实存在幻觉的回答有 40 条，模型的检测结果如下：

| 结果 | 数量 |
| --- | --- |
| TP（检出真幻觉） | 30 |
| FP（误报好回答为幻觉） | 10 |
| FN（漏网的真幻觉） | 10 |
| TN（正确放行） | 50 |

则 $\text{Precision} = 30/(30+10) = 0.75$，$\text{Recall} = 30/(30+10) = 0.75$，$\text{F1} = 0.75$。若模型改用「更保守」的策略：只检出 20 条真幻觉、误报 0 条，则 Precision 升到 1.0、Recall 跌到 0.5、F1 只剩 0.67——**F1 的调和平均不会奖励「靠牺牲一边换另一边」**，这正是它作为单一报告的合理性。<span class="marginnote">实践中 RAG 系统往往宁可误报也不漏报：把「可疑的回答」转去人工复核的成本，远低于把幻觉直接交付给用户的代价——于是团队常有意压低 Precision、抬高 Recall，再视业务容忍度定阈值。</span>

**辨析｜易错点：** 幻觉检测的判定本身依赖裁判（LLM 裁判或标注者），而裁判对「幻觉」的理解并不一致——一段「合理但不准确」的回答，判它幻觉还是非幻觉，各实验室差异很大。因此**跨论文比较 F1 时必须连同判幻觉的定义一起看**。

## 5 局限与小结

TruthfulQA 与 HaluEval 都依赖「人类或 LLM 裁判」来判定真实性/幻觉，成本与一致性仍是瓶颈；它们还都聚焦「事实性」这一种幻觉，而**在创作、翻译、角色扮演里，「不忠实」与「好表达」之间本来就存在张力**——幻觉评测的边界，至今仍在动态拓展。

## 6 小结

- 幻觉分**忠实性**（偏离来源）与**事实性**（违背事实）两类，评测先选标尺。
- **TruthfulQA** 用「人类易错题」测模型是否复述人类错误，双指标**真实度 + 信息度**并列报告。
- **HaluEval** 用 3.5 万标注样本测「幻觉检测」能力，是 RAG 兜底策略的组件。
- 检测是二分类问题，**Precision / Recall / F1** 各自惩罚误报与漏报。
- 幻觉判定依赖裁判，跨论文比较须连同「幻觉定义」一起看。
