## 为什么讲 MAE

前几篇的对比学习在**判别**世界里打转：区分正负样本、逼近互信息。MAE（Masked Autoencoder, He et al. 2021）代表另一条完全不同的主线——**生成式自监督**：不比较、不区分，只做一件事——**把遮住的像素重建回来**。它的前身是自编码器，它的精神兄弟是 NLP 的 BERT。MAE 用一个看似简单的做法取得了当时视觉自监督的最强线性评估成绩，并深刻揭示了两件事：**高遮蔽率 + 非对称架构**让视觉掩码建模第一次真正可行；视觉与语言的自监督，本是一家人。<span class="marginnote">MAE 论文题为 "Masked Autoencoders Are Scalable Vision Learners"——「可扩展」是它的关键词：模型越大、数据越多，收益越明显，这与 BERT 在语言上的经验完全同构。</span>

## 1 把 BERT 的配方搬到图像：为什么「照搬」会失败

BERT 的成功配方是：遮掉 15% 的 token，让 Transformer 重建。自然有人想：把「token」换成「图像 patch」不就行了？早期尝试（如 ViT 的 MAE 前身）却效果平平。问题出在图像与文本的**信息冗余度**天差地别：

文本里相邻 token 几乎不冗余——遮一个词，上下文能推出它，但推错会损失语义；
- 图像里相邻像素高度冗余——遮一块，靠周围像素的插值就能「蒙混过关」，模型学不到语义，只学到局部平滑。

于是早期做法遮得少（15%），因为遮多了重建不动；而遮得少，又学不到高层语义。**死结在于遮蔽率与任务难度**。MAE 的破局点正是把遮蔽率提到 75% 甚至更高——遮得够多，插值失效，模型只能依赖「全局理解」来重建，语义就被逼出来了。

值得注意的是，「图像去噪自编码器（dAE）」的失败教训在 2008 年前后就已被记录：把整图输入、加噪、重建，学到的表征在分类任务上毫无用处——因为重建目标与分类目标需要的表征粒度不同。MAE 的贡献不在于「自编码器」本身，而在于**用「高遮蔽率 + 非对称」把自编码器重新武装成了有效的视觉预训练器**：当遮蔽多到无法插值时，重建任务被迫转向「理解」，重建目标与语义目标终于在表征空间里对齐。<span class="marginnote">这是「难度充分」原则（见本专题第 1 篇）的教科书级应用：任务的难度不是越高越好，而是要「高到让捷径失效」——75% 恰好卡在「插值失效」的临界点。</span>

## 2 MAE 的四大设计

MAE 的架构延续自编码器：编码器读可见部分，解码器重建整体。但它有三处刻意为之的「不对称」：

**第一处不对称：遮蔽策略。** 图像切为 $16\times16$ 的 patch，随机无重叠地遮住 75%（MAE 验证 75% 是最优；BERT 只遮 15%——遮蔽率是语义级差异，不是缩放级差异）。

**第二处不对称：编码器只看可见 patch。** 被遮的 patch 根本不进编码器。这是计算效率的关键：只处理 25% 的 token，计算量约为全量的 $1/4$，且随遮蔽率上升还更省。这让 MAE 可以把编码器做得很大（ViT-Large、ViT-Huge）——省下来的算力都给了模型容量。<span class="marginnote">对比 BERT 要处理全部 token、只是把 15% 的表示换成可学习的 [MASK]，MAE 直接「不处理」——它把「遮罩」从输入改造升级成了计算裁剪。</span>

**第三处不对称：解码器轻量且独立。** 重建是「低级任务」（预测像素），不需要太大模型，MAE 用一个小解码器（几层 Transformer，宽度远小于编码器）。被遮位置的输入是共享的**可学习 mask token**，解码器把所有位置（可见 + 被遮）拼回完整序列，输出完整像素。

位置信息如何恢复值得特别说明：编码器输入的 patch 序列**不打乱、保持原空间顺序**，每个 patch 自带绝对位置编码；被遮 patch 进入解码器时再补上各自的位置编码。于是「这个被遮块在左上还是右下」的信息，是由位置编码而非 patch 内容携带的——模型必须学会「看到邻居的形状，推断此处的缺失」。

**损失。** 只对被遮 patch 的像素算 MSE（像素归一化后），可见 patch 不参与损失——它们已经被编码器「看见」了，无需重建。

## 3 公式解析：MAE 的目标与信息流

MAE 的损失可以写成：

$$
\mathcal{L}_{\text{MAE}} = \mathbb{E}_{x \sim p_{\text{data}}}\left[\frac{1}{|\mathcal{M}|} \sum_{i \in \mathcal{M}} \left\| \hat{p}_i - p_i \right\|_2^2\right]
$$

逐项拆解：

- **$x$**：一张输入图像，切为 $N$ 个 patch，每个 patch 摊平为像素向量 $p_i$。
- **$\mathcal{M}$**：被遮 patch 的下标集合，$|\mathcal{M}| \approx 0.75 N$。
- **$\hat{p}_i$**：解码器对被遮位置 $i$ 输出的重建 patch（经过像素归一化处理）。
- **$\|\cdot\|_2^2$**：均方误差，重建值与真值的逐通道平方差。
- **$1/|\mathcal{M}|$**：只对**被遮**的 patch 求平均——可见 patch 既不算损失，也不进解码器的重建目标。

再看信息流。设 $z$ 为编码器对可见 patch 输出的潜表征，$\mathbf{m}$ 为可学习的 mask token：

$$
\hat{x}_{\mathcal{M}} = D\left( z \oplus \mathbf{m}_{\mathcal{M}} \right), \qquad z = E\left( x_{\setminus \mathcal{M}} \right)
$$

- **$E(\cdot)$**：编码器，只吃可见 patch $x_{\setminus \mathcal{M}}$；
- **$\oplus$**：把被遮位置的 mask token 与可见位置的 $z$ 按原空间顺序拼回完整序列——顺序信息用位置编码恢复，保证解码器知道「哪里被遮」；
- **$D(\cdot)$**：轻量解码器，输出全部 patch 的重建，再取出被遮部分算 MSE。

一个值得点破的工程细节：**像素归一化**。MAE 在算 MSE 前，先对每个被遮 patch 的像素做 patch 内均值/方差归一化，让网络预测「归一化像素」而非「原始像素值」。原因是未归一化的像素目标方差大、被「平均色」这类平凡解主导，模型会偷懒去预测「一张模糊的平均图」而不是真正的结构。这看似微小的预处理，在消融里值好几个点的精度——也再次印证第 1 篇「难度充分」：**任何让捷径失效的预处理，都是在给表征质量定价**。

**辨析｜易错点：** 有人误以为 MAE 学到的表征只能用于重建任务。实际上**编码器输出 $z$ 才是迁移的载体**，解码器训练完就弃用。预训练期强迫编码器「看见可见块就能脑补整体」，它的表征因此内化了全局语义——线性探针与微调都只动编码器。这与你用 BERT 时「扔解码器只留 encoder」是同一个习惯。

## 4 为什么高遮蔽率 + 非对称架构成立

把 MAE 的三大设计放到一起看，它们互为因果：

1. **75% 遮蔽逼出语义**：重建任务「够难」，插值捷径失效，模型被迫学全局结构；
2. **可见块不浪费计算**：只处理 25% 的 token，省下 3.5 倍计算，撑得起更大模型；这个「省算力」的红利被 MAE 全部转投给编码器容量，是「非对称」策略的真实回报；

3. **轻量解码器管重建**：重建是低阶任务，把容量让给编码器，保证学到的表征「深」而不是「糙」。

MAE 与同一时期的 BEiT 形成一组极佳对照：BEiT 也做掩码建模，但把目标从「重建像素」换成了「预测被遮 patch 的离散视觉 token」（先用另一个模型把图像量化成 token 词典）。BEiT 走的是「图像版 BERT」路线，前期精度更高但依赖额外的 tokenizer；MAE 走「端到端像素重建」路线，目标更原始、更可扩展，最终以更简单的配方在更大模型上反超。**这一组对照证明：掩码建模的核心是「遮蔽 + 重建」这个结构，而非「重建什么」**——像素与 token 只是重建粒度的选择。

实验结果极具说服力：MAE 用 ViT-Large，在 ImageNet 线性评估上达到当时最高；下游目标检测、分割的微调也全面领先。**缩放规律**尤其关键——MAE 的收益随模型变大、数据变多而持续上升，这正是「生成式自监督」能成为大模型底座的根本原因。作者也给出直觉：编码器处理的是「稀疏的高语义」输入（25% 可见块），解码器处理的是「密集的低语义」重建，两条路径的计算强度天然悬殊——把解码器做得与编码器一样大，是纯粹的浪费，这就是「非对称」的工程依据。<span class="marginnote">对比之下，对比方法在小模型上常表现更好、更省数据；生成式方法（MAE、GPT）的强项在「可扩展」。这一「对比与生成的优劣互补」是读懂本专题对标综述 §2 主线的钥匙。</span>

## 5 MAE 与对比家族的三种对照

| 维度 | 对比家族（SimCLR/MoCo） | MAE |
| --- | --- | --- |
| 信号 | 正负样本对的距离 | 被遮像素的重建 |
| 负样本 | 必需 | 完全不需要 |
| 训练目标 | 互信息下界 | 像素似然（MSE） |
| 对冗余敏感 | 依赖增强产生视角 | 依赖遮蔽消除冗余 |
| 擅长 | 小模型、少数据 | 大模型、大数据 |

这张表的最后一行，恰好预告了第 9 篇评估协议的核心告诫：**MAE 在线性探针上往往不如 SimCLR（线性可分性稍弱），但在「全量微调」「迁移检测」上反超**。若只看单一指标，很容易得出相反结论——这正是「多协议矩阵」比「单指标排行」更可信的原因。

两条主线并不矛盾：**冗余是敌人**。对比方法用「增强 + 区分」消除冗余，MAE 用「遮蔽 + 重建」消除冗余——殊途同归，都在逼表征丢弃冗余、保留语义。后来的多模态方法（如 CLIP 与 image-text 掩码）把它们彻底缝合，那是本专题第 10 篇的故事。对于实践者，MAE 的「非对称架构」还有一个普适启示：**把「重计算」留给必要部分、把「轻计算」用于附属部分**——这个省算力的原则在蒸馏、MoE、乃至大模型推理加速里反复出现。

## 6 小结

- MAE = 掩码自编码器：遮 75% 的 patch，让解码器重建被遮像素，MSE 只算被遮块。
- 只对被遮 patch 算损失；可见 patch 已进编码器，不参与重建目标。
- 高遮蔽率是关键：让「像素插值」捷径失效，逼模型学全局语义。
- 非对称架构：编码器只看可见块（省 3.5 倍计算），轻量解码器补 mask token 重建。
- 位置编码携带「哪被遮」的信息；与 BEiT 对照说明掩码建模的重心在「遮蔽 + 重建」结构本身。
- 训练后解码器弃用，编码器的潜表征才是迁移的载体。
- 与对比家族同消灭「冗余」：一个用区分，一个用遮蔽。
- 解码器训练后弃用、像素归一化值几个点精度——工程细节在 MAE 里同样决定成败。
- 线性探针弱、微调强：MAE 与对比方法的强弱随评估协议翻转，验证多协议评估的必要。
- 高遮蔽率的代价也需知晓：表征的重建导向强，某些判别型下游需要更长微调才能发挥。

在下一节，我们回到对比家族里最「叛逆」的一支：BYOL 声称去掉负样本也能学——它的秘密在于把「对比」内化成了自己的结构，用 EMA 与预测器自造了一位「慢速老师」。
