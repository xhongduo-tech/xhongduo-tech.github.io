## 为什么讨论局限

从 Funk-SVD 到 SVD++，矩阵分解把一个稀疏评分矩阵压进低维隐空间，漂亮地打赢了 Netflix 大奖赛。但**打赢比赛不等于赢下生产环境**：真实的推荐系统里，每天都有新物品上线、每个用户都有画像、每个请求都有上下文。矩阵分解在这些场景里暴露出的短板，恰好指出了后续每一篇的方向——内容推荐、因子分解机、深度模型、LLM 推荐。

这一篇是第三篇的收官。我们像外科医生一样，把矩阵分解的四个局限摊开，看看它「地图」与真实「疆域」之间到底差在哪里。

## 1 局限一：冷启动——没见过的物品没有向量

矩阵分解里，物品 $i$ 的一切信息都封装在向量 $q_i$ 里，而 $q_i$ 只能从「用户对 $i$ 的交互」中学习。**一个新上线的物品，交互数为零，$q_i$ 无从谈起。**

- 预测 $\hat r_{ui} = \mu + b_u + b_i + q_i^{\mathsf{T}} p_u$ 里，$q_i$ 缺失，只能退化成基线——等于没推荐。
- 更糟的是**时间差**：新物品恰恰最需要曝光，而 MF 对它只能「装死」。这违背了推荐系统的长尾使命。

**辨析｜易错点：** 这里的「泛化能力弱」不是指在测试集上过拟合，而是指**对从未出现的物品/用户，模型无法给出像样的表示**。隐向量是「学」出来的，不是「推」出来的——没有交互就没有表示，这是 ID 类模型的共同宿命，也是第四篇《基于内容的推荐》要正面解决的问题。<span class="marginnote">同理，新用户也没有 $p_u$。第九篇《冷启动》会把「用户侧 / 物品侧 / 系统侧」三种冷启动分别讨论；MF 在这里是反面教材，而内容特征与注册信息是解药。</span>

举一个具体的生产场景：视频网站每天上架数千条新内容，它们的 $q_i$ 初始为零，预测只能退化成基线 $\mu + b_u + b_i$，而 $b_i$ 也因无人评分而趋近于 0——新内容在 MF 眼里与「不存在的物品」几乎没有区别。运营只能靠「随机撒流」让新内容积累交互，等 $q_i$ 学出来已是几天之后。这段「空窗期」，正是内容推荐与冷启动算法的意义所在。

把「没有向量」按对象分三类，MF 都束手无策：

- **新物品**：$q_i$ 未学出，只能给基线预测，等于「没有推荐」；
- **新用户**：$p_u$ 未学出，无法做任何个性化，与「猜你喜欢」的初心背道而驰；
- **低频老用户**：交互太少，$p_u$ 估计噪声极大，实际上处于「半个冷启动」状态。

## 2 局限二：只用交互，浪费特征

MF 的输入只有「用户 × 物品」的交互矩阵。可一个物品远不止一个 ID：它有**类目、导演、出品年份、封面图、文本简介**；一个用户有**性别、年龄、地域、设备**；一次请求还有**时间、季节、是否周末**。这些特征 MF 全都看不见。

后果是**当交互稀疏时，模型没有退路**。协同过滤的精髓是「集体智慧」——交互足够多时，隐向量能间接编码出类目等信息（爱看科幻的用户隐因子会互相靠近）。但长尾物品交互极少，「集体」不存在，特征就成了唯一救命稻草。

数据里其实躺着大量 MF 用不上的信息。一个物品在特征工程里可以长这样，MF 却只能看见它的 ID：

- **内容属性**：标题、简介文本、类目层级、标签、导演与演员；
- **呈现属性**：封面图、时长、出品年份、语言与地域；
- **用户侧**：注册年龄、设备型号、消费能力、常住地；
- **上下文**：请求的时段、星期、季节、所处页面与推荐位。

第六篇我们会看到，把这些特征显式喂给模型（LR、FM、DeepFM）后，预测能力常常反超纯 ID 交互——因为特征携带了 ID 交互之外的、可跨物品迁移的结构知识。<span class="marginnote">隐向量确实能「学出」一些语义：在隐空间里，同为喜剧片的 $q_i$ 往往聚在一起。但这种语义是<strong>数据量堆出来的副产品</strong>，不可控、不可解释、冷启动时不存在——这正是第六篇 FM 用「显式特征交叉」取代「隐式学语义」的动机。</span>

## 3 局限三：内积的低秩天花板

矩阵分解假设：用户对物品的偏好 $r_{ui}$ 可以写成 $p_u$ 与 $q_i$ 的**内积**。内积是双线性形式，表达力受限于「低秩 + 线性」两层约束。

- **低秩**：整个被估计的评分矩阵 $\hat R = P Q^{\mathsf{T}}$ 的秩不超过 $k$（隐因子个数）。$k$ 一般只有几十到几百，而真实偏好空间的复杂度远高于此。
- **线性**：内积只能刻画「两个向量在同一个隐因子方向上的一致程度」，无法表达**折取式（或）偏好**。

**重点：** 低秩既是 MF 泛化的原因，也是它的天花板——隐空间只有 $k$ 维，信息密度有限，这是用「共享表示换泛化」必须付的代价。

## 4 公式解析：为什么低秩既是优点也是上限

把所有预测写成矩阵形式。$P \in \mathbb{R}^{n \times k}$ 是用户矩阵，$Q \in \mathbb{R}^{m \times k}$ 是物品矩阵，预测矩阵是

$$
\hat R = P Q^{\mathsf{T}}, \qquad \mathrm{rank}(\hat R) \le k
$$

逐条拆解这条式的含义：

- **第一步，看维度**：$\hat R$ 是 $n \times m$，有 $nm$ 个元素；但 $P Q^{\mathsf{T}}$ 只有 $k(n+m)$ 个参数。**自由度从 $nm$ 压缩到 $k(n+m)$**，$k \ll \min(n,m)$ 时这是巨大的压缩——这就是泛化能力的来源：用一个共享的低维子空间解释所有交互。
- **第二步，看秩的性质**：秩 ≤ $k$ 意味着 $\hat R$ 的列（所有物品的预测向量）都落在同一个 $k$ 维子空间里。**任何不在该子空间里的偏好结构，模型结构上就无法表达**——不是调参能解决的，是「模型假设」的硬边界。
- **第三步，看折取式偏好**：设用户喜欢「动作」**或**「爱情」，但不喜欢混合体。用二维隐因子（一维动作、一维爱情），真实偏好函数是「$\max(u_1, u_2)$ 高则喜欢」。内积 $p_u^{\mathsf{T}} q_i = u_1 v_1 + u_2 v_2$ 在 $v_1, v_2 > 0$ 时，只在**两个维度都高**时取到高值——它天然建模「且」，建模不了「或」。
- **第四步，看深度模型的解药**：给内积外层加一层非线性（MLP、注意力），就能拟合「或」——这正是第六篇之后深度模型（DeepFM、DIN）与神经网络协同过滤的动机。**MF 的「线性内积」假设，是它最优雅、也最脆弱的部位。**

用一个数字例子把「内积搞反」演出来。设用户向量 $p_u = (1, 1)$（对动作与爱情都敏锐），纯动作片 $q_A = (1, 0)$、纯爱情片 $q_B = (0, 1)$、混合片 $q_C = (0.8, 0.8)$。内积给出 $p_u \cdot q_A = 1$、$p_u \cdot q_B = 1$、$p_u \cdot q_C = 1.6$——混合片得分最高。若该用户的真实偏好是「要么纯动作、要么纯爱情，排斥混搭」，内积就把顺序完全搞反了；而一个带非线性激活的 MLP 却能拟合出「$q_C$ 低分」的决策面。线性内积的天花板，在这里看得清清楚楚。

## 5 局限四：稀疏性、长尾与流行度偏差

矩阵分解对每个物品一视同仁，但数据并不一视同仁：

- **长尾物品估计方差大**：只有 3 条评分的物品，$q_i$ 由 3 个方程决定，任意噪声都会被放大。这就是偏差—方差权衡里的高方差。
- **流行度偏差的反馈回路**：热门物品交互多、$q_i$ 可靠，于是 MF 倾向推荐热门；越推荐越热门，冷门物品越得不到交互——**马太效应**被算法固化。离线指标往往还看不出来，因为评测数据本身偏斜于热门物品。<span class="marginnote">这就是我们第一篇里「超越准确性」的由来：<strong>只优化 RMSE 的 MF 会牺牲多样性、新颖性</strong>。第十一篇《重排与多样性》专门讲如何在列表层面把流行度偏差掰回来。</span>

**辨析｜易错点：** 不能说「矩阵分解不解决稀疏性」——它天然处理稀疏矩阵（只在已知评分上优化）。准确的说法是：**它处理「随机缺失」的稀疏，处理不了「结构性缺失」**。长尾物品的评分缺失不是随机的，而是「根本没被看见」，MF 对此无能为力。

这条回路有实测痕迹：工业实践中反复观测到，纯 MF 的推荐里头部热门物品的占比远高于它们在交互数据中的自然占比——用户看了《教父》，系统推的却是同梯队的全民爆款，而非他的小众口味。离线 RMSE 常常测不出这种偏差，因为评测集本身也偏斜于热门。这催生了后来的消偏（debias）研究，也再次印证第一篇《超越准确性》的论断：**指标选错了，模型就长歪了**。

流行度偏差不是一次性事故，而是一个自我强化的循环：

1. **偏好起点**：热门物品交互多，$q_i$ 估计可靠、误差小；
2. **放大**：MF 在 RMSE 压力下倾向推荐这些「稳」的热门物品；
3. **固化**：热门被反复推荐、长尾得不到曝光，长尾的 $q_i$ 越发不可靠；
4. **闭环**：回到第 1 步，头部越滚越大，长尾越埋越深。

## 6 出路预览：内容、特征与深度模型

四条局限指向四类解法，正好是后续几篇的地图：

| 局限 | 对应的解法 | 后续篇目 |
| --- | --- | --- |
| 冷启动、无向量可用 | 物品内容特征生成表示 | 第四篇《基于内容的推荐》、第九篇《冷启动》 |
| 只用交互、浪费特征 | 显式特征 + 特征交叉 | 第六篇《排序模型演进》（LR、FM、GBDT+LR） |
| 内积线性天花板 | 非线性深度模型 | 第六篇（DeepFM、DIN）、第七篇（序列模型） |
| 稀疏长尾、流行度偏差 | 向量检索 + 重排 + 语义特征 | 第五篇《召回策略》、第十一篇《重排与多样性》、第十四篇《LLM 与推荐》 |

**重点：** 矩阵分解没有「死」，它只是退居为一个**子模块**——今天的工业推荐里，MF 的思想以 Embedding 的形式活在双塔、FM 与深度模型里。局限不是终点，而是分工的起点。评估一个推荐模型是否「够用」，不能只看离线 RMSE，还要问三件事：它能不能给新物品一个起点？它有没有把已有的特征用上？它在长尾上是不是在「装懂」？——这三问，正是后续每篇选题的标尺。<span class="marginnote">第十四篇我们还会看到，当特征从「ID + 类目」升级为「文本语义」时，MF 的隐向量被 LLM 生成的 Embedding 取代，低秩假设被语义空间取代——那是「ID 推荐到语义推荐」的范式跃迁。</span>

## 7 小结

- **冷启动**：没有交互就没有向量，MF 对新物品/新用户「装死」，泛化到未见对象的能力弱。
- **特征浪费**：只用「用户 × 物品」交互，类目、画像、上下文等特征全部被忽略，稀疏时没有退路。
- **低秩 + 线性天花板**：$\mathrm{rank}(\hat R) \le k$ 且偏好为内积，建模不了「或」类折取偏好；深度非线性模型是解药。
- **稀疏长尾与流行度偏差**：长尾物品估计方差大，热门物品被反复推荐，形成马太效应。
- MF 以 **Embedding** 的形式活在后来的每个模型里；局限指明了后续内容、特征、深度、语义四条路线。

下一篇我们离开「交互矩阵」，进入一个完全不同的世界：**不看别人怎么看，只看物品本身是什么**——基于内容的推荐，用物品画像与用户画像做第一场正面交锋。
