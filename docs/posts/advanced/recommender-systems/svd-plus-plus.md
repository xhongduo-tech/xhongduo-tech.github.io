## 为什么从 SVD++ 开始

BiasSVD 把显式评分拆成了「偏置 + 隐因子」，ALS-WR 教会我们隐式信号怎么用。但两者各占一个极端：BiasSVD 只吃评分数值，连「用户评过哪些物品」这种信息都浪费了；ALS-WR 又只建模「有没有交互」，把辛苦打出的分数抛在一边。

SVD++ 的野心是**两者都要**：预测仍以显式评分为主，但给每个用户叠加一套由「他评过的物品集合」生成的隐式因子。2008 年 Koren 提出这一模型，成为 Netflix 大奖赛夺冠方案 BellKor 的核心组件之一。<span class="marginnote">模型名里的 <strong>++</strong> 指「在 SVD 之上又叠加一个信号源」：显式评分 + 隐式行为。Koren 的论文标题叫 <em>Factorization Meets the Neighborhood</em>（分解遇见邻域）——它把矩阵分解与 UserCF 的邻域聚合思想缝合在了一起。</span>

## 1 显式与隐式：评分之外的免费信号

先澄清「免费信号」是什么。假设我们只有评分矩阵，没有额外的行为日志。对一个用户 $u$，除了他给出的评分值，**「他评过哪些物品」本身也是一条信息**——这个集合记作 $N(u)$。它反映用户的口味范围：评过《黑客帝国》说明他可能吃科幻这一套。

**重点：** 哪怕评分值是 1 分（不喜欢），「评过」这个动作仍说明用户**知道**这个物品、并愿意花时间表态——这本身就是弱的隐式偏好。SVD++ 把 $N(u)$ 当作免费信号，不需要任何额外数据。

**辨析｜易错点：** 在 SVD++ 里，$N(u)$ 通常取**用户评过的全部物品**，与评分高低无关。若只取高分物品，反而丢掉「低分也暴露了兴趣边界」的信息。这与 ALS-WR 中「$p_{ui}=1$ 只要交互过」的判断一致。

## 2 SVD++ 的模型：给用户叠加一组隐式因子

BiasSVD 的预测式是 $\hat r_{ui} = \mu + b_u + b_i + q_i^{\mathsf{T}} p_u$。SVD++ 只改一处：把用户向量 $p_u$ 换成「显式向量 + 隐式向量的聚合」：

$$
\hat r_{ui} = \mu + b_u + b_i + q_i^{\mathsf{T}} \left( p_u + |N(u)|^{-1/2} \sum_{j \in N(u)} y_j \right)
$$

其中 $y_j$ 是物品 $j$ 的**隐式因子向量**（与显式因子 $q_j$ 并列的一套向量），$|N(u)|$ 是 $N(u)$ 的元素个数。把括号里的整体记为用户的**有效因子**：

$$
p_u^{+} = p_u + |N(u)|^{-1/2} \sum_{j \in N(u)} y_j
$$

**重点：** $p_u$ 是从显式评分里学出来的「用户基本盘」，而 $\sum_{j \in N(u)} y_j$ 是「用户评过的所有物品」的隐式因子之和——它像 UserCF 里聚合邻居评分一样，把用户的整个历史行为压缩成一个向量。**分解与邻域，在同一式子里相遇。**

## 3 公式解析：预测式与 $y_j$ 的梯度累积

误差 $e_{ui} = r_{ui} - \hat r_{ui}$，对单个样本的损失 $\ell = e_{ui}^2 + \lambda(\|p_u\|^2 + \|q_i\|^2 + \sum_{j \in N(u)} \|y_j\|^2)$。求偏导，注意 $y_j$ 藏在内积里：

- 对 $p_u$：$\dfrac{\partial \ell}{\partial p_u} = -2e_{ui}\, q_i + 2\lambda p_u$
- 对 $q_i$：$\dfrac{\partial \ell}{\partial q_i} = -2e_{ui}\, p_u^{+} + 2\lambda q_i$，其中 $p_u^{+}$ 是含隐式项的有效因子
- 对每个 $j \in N(u)$：$\dfrac{\partial \ell}{\partial y_j} = -2e_{ui}\, q_i\, |N(u)|^{-1/2} + 2\lambda y_j$

于是 SGD 更新规则（步长 $\eta$）：

$$
p_u \leftarrow p_u + \eta\left(e_{ui} q_i - \lambda p_u\right), \qquad
q_i \leftarrow q_i + \eta\left(e_{ui} p_u^{+} - \lambda q_i\right)
$$

$$
y_j \leftarrow y_j + \eta\left(e_{ui}\, |N(u)|^{-1/2} q_i - \lambda y_j\right), \qquad \forall j \in N(u)
$$

逐步拆解：

- **第一步，看 $q_i$ 的更新**：它把「用户有效因子」$p_u^{+}$ 当作信号源——隐式聚合直接参与了物品向量的学习。
- **第二步，看 $y_j$ 的更新**：梯度里出现 $|N(u)|^{-1/2} q_i$，意思是「把当前误差按 $q_i$ 的方向，摊回用户评过的每一个物品的隐式因子上」。
- **第三步，看「累积」**：一条训练样本 $(u,i)$ 会**同时更新 $N(u)$ 里所有物品的 $y_j$**——一个样本带动一个集合的更新。这是 SVD++ 比 BiasSVD 计算量大的根源，也是它信息量的来源。
- **第四步，看 $p_u$**：它只吃显式信号；隐式信号全部走 $y_j$ 通道，两者不打架。

**辨析｜易错点：** $y_j$ 与 $q_j$ 是**两套独立的向量**——$q_j$ 是「物品 $j$ 作为被预测目标」的显式因子，$y_j$ 是「物品 $j$ 作为用户历史」的隐式因子。同一个物品两种身份，参数互不共享。忘了把 $y_j$ 加进正则，会出现：物品越热门，$y_j$ 越膨胀。

## 4 训练细节与 $|N(u)|^{-1/2}$ 的直觉

**归一化为什么是 $|N(u)|^{-1/2}$ 而不是 $|N(u)|^{-1}$？** 若用 $-1$ 次方，$p_u^{+}$ 里隐式项就是纯平均，信息被稀释；若不归一化，评过 1000 部的重口用户其隐式项会把 $q_i$ 淹没。Koren 在论文里比较了多种指数，$-1/2$ 是经验最优——它在「保持聚合强度」与「压制重口用户」之间取平衡。<span class="marginnote">$-1/2$ 源自「和的模长近似按 $|N(u)|^{1/2}$ 增长」的统计直觉：若 $y_j$ 相互独立，则 $\|\sum_{j} y_j\| \approx \sqrt{|N(u)|}\cdot \|y_j\|$，除以 $|N(u)|^{1/2}$ 恰好把模长压回单位量级。这个「按方差量级归一」的思想，你在第一级《概率》里会再见。</span>

训练代码的关键只在 `y` 的更新循环：

```python
def svdpp_update(ratings, P, Q, Y, bu, bi, Nu, mu, lr, lam):
    """一条样本 (u, i, r) 的更新；Nu[u] 是用户 u 评过的物品列表。"""
    norm = len(Nu[u]) ** -0.5                # |N(u)|^{-1/2}
    eff = P[u] + norm * sum(Y[j] for j in Nu[u])   # 有效用户因子
    e = r - (mu + bu[u] + bi[i] + Q[i] @ eff)
    bu[u] += lr * (e - lam * bu[u])
    bi[i] += lr * (e - lam * bi[i])
    P[u]  += lr * (e * Q[i] - lam * P[u])
    Q[i]  += lr * (e * eff - lam * Q[i])
    for j in Nu[u]:                          # 累积更新整个集合
        Y[j] += lr * (e * norm * Q[i] - lam * Y[j])
    return e
```

注意 `eff` 被复用了两次（预测与 $q_i$ 更新），别在循环里重算。

用一个**玩具数字验证归一化**。设用户 A 只评过 1 部片（$|N(u)| = 1$），隐式聚合项模长约 $\|y_1\|$；用户 B 评过 100 部（$|N(u)| = 100$），若不归一化，按方差量级估算，聚合项模长约 $\sqrt{100}\,\|y\| = 10\|y\|$——B 的隐式信号会把 $q_i$ 完全淹没。乘上 $100^{-1/2} = 0.1$ 后，A、B 的隐式贡献回到同一量级；而若用 $-1$ 次方（$1/100$），B 的聚合被压缩得过狠，100 部片的集体智慧只剩一部片的强度。**$-1/2$ 是对「集体背书」与「个体强度」的折中**，这就是为什么它落在两个朴素选项之间。

## 5 为什么它能赢：「分解遇见邻域」

SVD++ 的价值不只是多了一组参数。它的结构性洞察是：**显式评分稀疏，而「评过什么」相对稠密。** 在 Netflix 数据上，平均每个用户只评了约 200 部片，而「$N(u)$ 里有哪些物品」这一信息，能显著缓解单个评分的噪声——一个用户的口味，由他评过的整个集合共同背书。

这正呼应了更早的邻域方法：UserCF 用「相似用户的评分」做加权平均，SVD++ 用「自己评过的物品的隐式因子之和」做聚合。**矩阵分解给了它表达力，邻域聚合给了它稳定性**——两条路线在 SVD++ 里合流，也解释了为什么它是夺冠方案里被反复使用的组件。<span class="marginnote">这套「ID 交互 + 行为聚合」的骨架在深度时代演变成：<strong>双塔、DIN 里的目标注意力池化、以及第十四篇 LLM 的语义表示</strong>——聚合的对象从隐式因子变成了 Embedding，但「用一个集合共同刻画用户」的哲学没变。</span>

**辨析｜易错点：** 不要把 SVD++ 误解为「只是加了更多参数」。参数变多是表象，本质是**引入了一条新的信息通道（用户的行为集合）**。若数据里用户交互极少，$N(u)$ 近乎空集，SVD++ 的优势也随之消失——这一点在评估时要心里有数。

SVD++ 的训练有几个实操要点：

- **正则**：$y_j$ 必须与 $q_j$ 一起进正则，否则热门物品的 $y_j$ 会持续膨胀、主导预测。
- **复杂度**：每条样本要更新整个 $N(u)$，评分稠密时开销可观；数据量大可对 $N(u)$ 子采样，代价是损失一部分聚合信息。
- **初始化**：$y_j$ 用 0.1 量级小随机数起步即可；注意聚合项把初始噪声放大约 $|N(u)|^{1/2}$ 倍，量级过大会起步发散。
- **收敛**：沿用 BiasSVD 的学习率与衰减策略即可，SVD++ 没有引入需要特调的新超参。

## 6 小结

- SVD++ 预测式 $\hat r_{ui} = \mu + b_u + b_i + q_i^{\mathsf{T}}(p_u + |N(u)|^{-1/2}\sum_{j\in N(u)} y_j)$：在 BiasSVD 上叠加**隐式因子聚合**。
- $N(u)$ 是**用户评过的物品集合**，与评分高低无关，是零成本的免费信号。
- 用户有效因子 $p_u^{+}$ 由「显式向量 + 归一化的隐式聚合」组成，一条样本会**同时更新 $N(u)$ 里所有 $y_j$**。
- $y_j$ 与 $q_j$ 是**两套独立向量**，必须分别正则；归一化 $|N(u)|^{-1/2}$ 在「保留聚合强度」与「压制重口用户」间取平衡。
- SVD++ 把矩阵分解的表达力与邻域聚合的稳定性合流，是 Netflix 夺冠方案的核心组件。

SVD++ 把显式、隐式、偏置都榨干了，矩阵分解自身的**天花板**也到了该审视的时候：它真的能泛化到没见过的物品吗？它真的利用够了特征吗？下一节，我们直面矩阵分解的局限。
