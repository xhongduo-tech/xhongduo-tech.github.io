## 为什么从超越准确性开始

上一节我们把评分预测的 RMSE / MAE、Top-N 的 Precision / Recall 逐一算透，但请回忆那篇结尾埋下的话：**离线指标只是「用户满意度」的一个组成部分**。<span class="marginnote">上一篇《离线评估指标》第 6 节点出的结论：一个预测极准的系统，可能因为推荐的尽是你已知的东西而让你觉得「没意思」。</span>今天就把这句话展开成四个具体维度——**覆盖率、多样性、新颖性、惊喜度**。它们共同回答一个问题：**准确性之外，推荐系统还该被怎样衡量？**

项亮在书中反复强调一个观点：**准确率高的系统不一定让用户满意，而满意度才是产品意义上的终极指标**。这四个维度都指向同一种缺失——系统只知道「推荐得对不对」，却不知道「推荐得有没有意思、有没有新东西、有没有惊喜」。从这一节开始，我们进入「人」的视角。

## 1 覆盖率：系统到底能推荐多少东西

覆盖率（coverage）是最容易理解、也最容易误解的指标。给定全体用户 $U$ 与全部物品集合 $I$，设 $R(u)$ 是系统给用户 $u$ 的推荐列表，定义：

$$Coverage = \frac{\left|\bigcup_{u \in U} R(u)\right|}{|I|}$$

**分子是「至少被某个用户推荐到过一次」的物品种类数**，即所有用户推荐列表的并集大小。它度量的是：**系统能把多长尾的物品推出去？**

**辨析｜易错点：** 覆盖率不是「单条推荐列表里不同物品的占比」，而是**跨所有用户**统计的。一个系统若只推 100 部热门电影，哪怕每次推荐都很准，$Coverage$ 也会低得可怜——它天生惩罚「头部集中」。这与之前学的混淆矩阵视角完全不同：Precision 度量「命中比例」，Coverage 度量「触及广度」，一个看质，一个看面。

但物品覆盖率只看「种类数」，仍可能被钻空子：系统把长尾物品每样「象征性」推荐一次，Coverage 也能变高，可那些物品几乎没人点。于是项亮引入了第二层度量——**看推荐系统的流行度分布是否公平**，也就是「马太效应」有多严重。<span class="marginnote">马太效应：热门物品因被更多人推荐而更热门，长尾物品无人问津。推荐系统理应缓解它，现实中却常常加剧它——这正是「从极限到大模型」主线里「幂律分布」在消费侧的体现，第一级《概率》中的长尾分布是其数学背景。</span>

度量流行度分布是否公平，两个工具最常见：**Gini 系数**与**信息熵**，我们在第 4 节逐项拆解。

## 2 多样性：列表内部的「不相似」

覆盖率管「系统整体」，多样性（diversity）管「单个列表」。一个用户收到的 Top-N 列表里，物品两两之间越不像，列表越「多样」。定义用户 $u$ 的推荐列表 $R(u)$ 的内部多样性为：

$$Diversity(u) = 1 - \frac{2 \sum_{i, j \in R(u),\, i \neq j} \mathrm{sim}(i, j)}{|R(u)| \cdot (|R(u)| - 1)}$$

分母 $|R(u)|(|R(u)|-1)/2$ 是列表内「物品对」的数目，分子是「所有物品对相似度之和」。**列表内物品两两越相似，多样性越低**；当列表里全是同类物品时 $Diversity \to 0$。<span class="marginnote">$\mathrm{sim}(i,j)$ 是物品间相似度——这正是下一篇《相似度计算》的主角。多样性指标把「相似度」这个基本原料，直接烧成了「列表质量」。</span>

为什么多样性重要？想想视频网站：你刚看完一部科幻片，系统推来十部几乎同款的科幻片。单独看每一部，相关度都不低，可**十部叠在一起，信息量约等于一部**。多样性让列表「一首歌有十个音符」，而不是「一个音符重复十遍」。这不只是体验问题，还直接影响留存——千篇一律的列表很快让人腻味。

## 3 新颖性与惊喜度：没见过的，和没想到的

新颖性（novelty）回答「用户是否见过」。离线评测无法直接问用户，常用的替代指标是**推荐列表的平均流行度**：物品流行度越高，越可能被用户见过，越不新颖。

$$Novelty(u) = \frac{1}{|R(u)|} \sum_{i \in R(u)} \mathrm{pop}(i), \qquad \text{越小越新颖}$$

惊喜度（serendipity）则苛刻得多，它要求「意外」与「满意」同时成立：**用户没料到会被推荐它（意外），看到之后还真喜欢（满意）**。<span class="marginnote">经典例子：给你推荐一部从未听过的冷门佳片，点开一看大呼过瘾——这是惊喜；给你推荐一部没听过但毫无兴趣的影片，那是「怪异」而不是「惊喜」。惊喜度在论文里常写作「serendipity」，是学术界公认最难离线度量的指标之一。</span>

**辨析｜易错点：新颖性 ≠ 惊喜度。** 新颖性只要求「没见过」，不需要「喜欢」；惊喜度必须「意外 + 满意」双条件成立。一个纯随机推荐器的新颖性极高（尽推冷门），惊喜度却极低（几乎不命中兴趣）。所以离线度量惊喜度，通常要在「新颖」的候选里再过滤「相关」的——它本质上是一个与准确性叠加的复合指标。

## 4 公式解析：Gini 系数与信息熵，两把尺子量公平

覆盖率讲完，来拆解第 1 节提到的两个「流行度公平性」指标。设共有 $n$ 个物品，把它们的流行度占比 $p_1, p_2, \dots, p_n$（满足 $\sum_i p_i = 1$）**从低到高排序**，即 $p_1 \le p_2 \le \cdots \le p_n$。

**Gini 系数：**

$$G = \frac{1}{n-1} \sum_{i=1}^{n} (2i - n - 1)\, p_i$$

逐项拆解：

- **第一步，看排序**：$p_1$ 是最冷门的物品，$p_n$ 是最热门的。排序是 Gini 的灵魂——它对比「累积份额」与「绝对公平」之间的偏离。
- **第二步，看权重 $(2i - n - 1)$**：这个系数从 $-(n-1)$ 线性涨到 $+(n-1)$。冷门物品（$i$ 小）拿负权重，热门物品（$i$ 大）拿正权重。**流行度完全平均时，$\sum (2i-n-1)p_i = 0$，故 $G = 0$，绝对公平；全部流行度集中到最热门的 $p_n = 1$ 时，$G$ 趋近 $1$，极端马太效应。**<span class="marginnote">直觉：Gini 量的是「洛伦兹曲线」与对角线之间的面积之比。你不需要画图，只需记住：<strong>Gini 越小越平均，越大越集中</strong>，$G \in [0,1]$。</span>
- **第三步，对照使用**：两个系统，一个 $G = 0.3$、一个 $G = 0.8$，后者把推荐流量集中到少数头部物品上，长尾几乎无人问津——Gini 是推荐系统的「贫富分化指数」。

**信息熵：**

$$H = -\sum_{i=1}^{n} p_i \log_2 p_i$$

- **第一步，看单项 $-\log_2 p_i$**：一个物品被推荐的概率越低（$p_i$ 小），$-\log_2 p_i$ 越大——这是信息论里的「自信息」，度量「这件事多让人意外」。<span class="marginnote">信息熵会在第二级《概率论与数理统计》与第三级《信息论》中完整展开。今天只需直觉：<strong>熵越高，分布越均匀；熵越低，分布越集中</strong>。</span>
- **第二步，加权平均**：对每个物品的自信息按概率加权求和。完全均匀时 $p_i = 1/n$，熵取最大值 $\log_2 n$；完全集中时熵为 0。
- **第三步，与 Gini 的关系**：两者都惩罚「集中」，但 Gini 对「少数头部」更敏感，熵对「整体混乱度」更敏感。工程上常两个都算，互为印证。

## 5 为什么这些指标彼此打架

四个指标不是四条平行线，它们彼此之间、以及与准确性之间，**存在此消彼长的内在张力**：

| 目标 | 倾向 | 与准确率的冲突 |
| --- | --- | --- |
| 覆盖率 | 把长尾推出去 | 长尾命中概率低，拉低 Precision |
| 多样性 | 列表内部差异化 | 差异化可能推入不相关物品 |
| 新颖性 | 推没见过的 | 没见过的更可能不相关 |
| 惊喜度 | 意外且满意 | 意外性天然与「预测准确」矛盾 |

**这就是推荐系统最核心的权衡：准确率与多样性 / 新颖性之间的「跷跷板」。** 项亮给出的工程心态是：**不要追求单一指标最大，而是设定约束、在约束下优化**——比如「保证 Precision ≥ 0.3 的前提下，最大化覆盖率」。

**辨析｜易错点：** 别「为了多样性而多样性」。一个冷门但完全跑题的长尾列表，覆盖率、新颖性、多样性全都极高，用户却可能直接卸载 App。**多样性、新颖性必须以「相关性」为下限**——这正是「探索与利用」问题的起点：系统需要在「推稳的」（exploit）与「推新的」（explore）之间动态取舍，我们将在专题第十篇《探索与利用》系统化地解决它。

## 6 用代码算一遍

用 Python 把 Gini 系数算出来（可直接运行）：

```python
def gini(p):
    """p：各物品被推荐的次数占比列表；返回 Gini 系数（0=绝对平均，越接近 1 越集中）。"""
    p = sorted(p)                            # 升序：从最冷门到最热门
    n = len(p)
    # 权重 2i-n+1 对应公式的 2i-n-1：Python 下标从 0 起、公式下标从 1 起
    num = sum((2 * i - n + 1) * p[i] for i in range(n))
    return num / (n * sum(p))                # 分母多除一个 sum(p)，不要求占比恰好归一化
```

代码里权重用 $2i - n + 1$ 对应公式的 $2i - n - 1$，是因为 Python 下标从 0 开始、公式下标从 1 开始；分母多除一个 $\sum p$ 是为了不要求占比恰好归一化。

## 7 小结

- **覆盖率**度量系统整体能触及多长尾，$Coverage = |\bigcup_u R(u)| / |I|$；再辅以 **Gini 系数**与**信息熵**度量流行度分布的公平性。
- **多样性**度量单个列表内部物品两两的不相似度；**新颖性**用平均流行度近似「用户是否见过」；**惊喜度**要求「意外 + 满意」双条件。
- **易错点**：新颖性 ≠ 惊喜度；覆盖率 ≠ 单列表多样性；别为多样性牺牲相关性底线。
- **核心权衡**：准确率与覆盖率、多样性、新颖性天然此消彼长，工程上以「约束下优化」应对。
