# GBDT+LR：特征交叉的自动化（Facebook 方案）

## 为什么从 GBDT+LR 开始

上一节我们看到 LR 的命门：**特征交叉全靠人工**。Facebook 在 2014 年给出一个优雅的补法：用 **GBDT（梯度提升决策树）自动找交叉，把找好的交叉喂给 LR 学权重**。这一「树 + 线性」的组合，是特征交叉自动化的第一次工业落地，也是后来「模型组合」范式（Wide & Deep、DeepFM）的思想源头。<span class="marginnote">GBDT 属于集成学习里的 Boosting 一族，逐轮用残差训练新树。它的细节（损失、正则、调参）在第三级《机器学习》的 GBDT/XGBoost 专题中展开，这里我们只关心它作为「特征变换器」的角色。</span>

这一节讲清：GBDT 为什么擅长找交叉、它怎么把原始特征变成新特征、以及这套方案在实践中的得与失。

## 1 从人工交叉到自动交叉

LR 时代构造一个「年龄×性别×类目」的三阶交叉，需要人工枚举组合、写特征生成逻辑。组合一多就爆炸。GBDT 的切入点是换一个思路：**树模型天生就在做特征交叉**。

一棵决策树从根到叶子的每条路径，都是一连串「特征 + 阈值」的判断组合。例如路径「年龄 ≤ 25 且 性别 = 女 且 类目 = 美妆」，本质就是一个三阶交叉特征——只不过这个交叉是树在训练中**自动学出来的**，不用人枚举。<span class="marginnote">树模型自动交叉的能力，来自它分裂时对特征的贪婪选择：每层只看当前最有区分力的特征，多层叠加就形成了隐式的高阶组合。这正是 [[logistic-regression-ctr-feature-engineering]] 里「人工交叉」想达到但做不到的效果。</span>

## 2 GBDT 作为「特征变换器」

FB 方案的精髓是把 GBDT 当成**有监督的特征编码器**，分两步：

1. **训练一个 GBDT**：用原始特征 $x$ 预测点击。训练完后，每棵树的结构就固定下来。
2. **特征变换**：对一条样本，让它穿过每棵树，落到某片叶子；把所有树落的叶子做 **one-hot**，拼成一个高维稀疏向量，作为新的特征表达。

具体地，若有 $T$ 棵树、每棵 $L$ 片叶子，样本 $x$ 被变换成维度为 $T \times L$ 的 0/1 向量，其中每棵树的对应叶子上是 1。**每个「叶子位」代表「该样本满足了一条从根到叶的路径」**——也就是一个自动生成的交叉特征。

## 3 LR 接过权重：稀疏交叉特征的线性打分

变换出的稀疏向量交给 LR 做最终打分：

$$
\hat{p} = \sigma\left(w_0 + \sum_{t=1}^{T} \sum_{\ell \in \text{path}_t(x)} w_{t,\ell}\right)
$$

其中 $\text{path}_t(x)$ 是样本 $x$ 在第 $t$ 棵树上落到的叶子，$w_{t,\ell}$ 是该叶子的 LR 权重。样本每棵树只激活一片叶子，所以求和里每个 $t$ 只取一项——**模型实际上是在给「这条样本命中的 T 个交叉特征」的权重求和**。

## 4 公式解析：为什么 LR 比 GBDT 本身更适合当最后打分器

一个自然的问题：**既然 GBDT 已经能直接预测点击率，为什么还要外面套一层 LR？** 拆三步看：

- **第一步，GBDT 是「局部」决策器**：每棵树输出的是「落在某叶子的回归值/预测值」，预测值是分段常数。它擅长捕捉组合模式，但**不擅长拟合全局光滑的概率曲面**，且难以直接给出校准良好的概率。
- **第二步，LR 是「全局」校准器**：LR 在叶子特征上学一组权重，本质是在学「哪些交叉模式更有价值、各值多少分」。它把树的分段输出加权合成一个光滑的概率估计，且 sigmoid 输出天然在 $(0,1)$ 内，可直接当 CTR。
- **第三步，两者互补**：**树负责「找到值得区分的组合」，线性层负责「给这些组合定权重」**。实验证明这个组合比单独用任一者效果更好，这也是它成为 2010 年代工业标配的原因。

另一个实践原因是**可解释性与可控性**：LR 的权重仍然可读，运营可以查看「哪个叶子组合最值钱」，也便于做线上概率校准（calibration）。

## 5 工程要点与局限

**训练上的坑**：

- GBDT 与 LR 是**两阶段、非联合训练**：GBDT 的叶子是离线先学好的，LR 在其上再学。两阶段各有自己的验证集，避免泄漏。
- 树的结构要**按点击目标训练**，但树的深度、棵树直接决定交叉的阶数上限（深度 = 最大交叉阶数）。深度太浅交叉不够，太深过拟合。
- 类别特征要多，连续特征最好先离散化或让树自己找分裂点。

**局限**：

- 树模型对**高维稀疏的 ID 类特征不友好**（one-hot 后分裂点选择困难），而推荐系统恰恰充满 ID 特征。
- 两阶段割裂：GBDT 看不到 LR 的最终目标，交叉质量未必全局最优。
- 树深了线上推理要遍历多棵树，延迟成本随树数线性涨。

这些局限把接力棒传给了 **FM**（参数化二阶交互，直接吃稀疏特征）与 **Wide & Deep**（联合训练的深度模型）。

## 辨析｜GBDT+LR 与深度模型的两个取舍点

GBDT+LR 常被拿来与深度 CTR 模型（DeepFM 等）对比，选型时有两点值得想清楚：

**取舍一：树的「硬分裂」与 embedding 的「软映射」。** GBDT 的每个分裂点是「硬阈值」——特征值一过阈值就归到一边，是分段常数拟合；embedding 是「软映射」——相似特征在向量空间里连续靠近。硬分裂的优点是「解释精确」（能说清「年龄≤25 就走这条路」），缺点是「边界生硬」（24 岁和 26 岁被完全分开）。**当特征关系本质是「分段」的（年龄、价格带），树擅长；当特征是「连续渐变」的（兴趣强度），embedding 擅长**。

**取舍二：两阶段 vs 端到端。** GBDT+LR 是两阶段（先树后 LR），树的叶子在「看不到 LR 最终目标」的情况下生成，可能不是全局最优；深度模型端到端联合训练，特征交叉与打分目标对齐。**但两阶段也有优势**：树可以先在「大而全」的样本上把交叉学好，再让 LR 去适配业务目标，训练解耦、便于 debug——这也是它至今仍被用作「强基线」的原因。

**工程提醒**：GBDT 叶子特征进入 LR 时，叶子数决定了 LR 的输入维度。若树太多、太深，叶子 one-hot 后的特征空间会很大，需要 LR 侧用 L1 正则做稀疏化，避免维度灾难。

**一句话**：GBDT+LR 是「精确分段 + 可解释」的性价比之选；要「连续映射 + 端到端最优」则上深度模型——两者不是谁取代谁，而是按特征形态与调试需求选择。

**补充｜GBDT+LR 的「调参清单」**：几个直接影响效果的关键旋钮，按重要性排序：

- **树的深度**：决定「交叉的阶数上限」。深度 3~5 是常见起点——太浅交叉不够，太深过拟合且叶子太碎。
- **树的数量**：决定「特征变换的表达宽度」。几百棵树是常见规模，太多则「叶子特征维度爆炸」。
- **每棵树叶子数的约束**：控制「每片叶子的样本下限」，防止「孤儿叶子」产生噪声特征。
- **LR 侧的正则**：叶子 one-hot 后特征极稀疏高维，**L1 正则几乎是必须**——它同时做「特征选择」，把「没用的叶子位」压成 0。

**一个调试技巧**：GBDT 训练完，先看「哪些叶子被高频命中」——**高频叶子对应「普遍适用的交叉规则」，低频叶子对应「罕见的特异组合」**。低频叶子如果占比过高，说明树过深或样本不够，要剪枝或加树的下限。

**补充｜GBDT+LR 的「局限深化」：为什么它被深度模型取代**：

GBDT+LR 曾是工业标配，现在被深度模型（DeepFM 等）取代，原因不只是「精度」，还有三个结构性短板：

- **树模型不擅长「高维稀疏」**：GBDT 的分裂点选择在「稀疏 one-hot 特征」上效率低、效果差——而推荐的核心信号（用户 ID、物品 ID）恰恰是高维稀疏的。**树的「擅长区」在「稠密/类别特征」，不在「ID 稀疏特征」**。
- **两阶段的信息损失**：树先定交叉、LR 再学权重，**LR 看到的「叶子」是「树的压缩结果」**——树在生成叶子时「不知道 LR 怎么用」，压缩过程丢了信息。深度模型端到端「没有中间压缩」。
- **难以「在线更新」**：GBDT 的树结构「重建代价高」，不适合「每条反馈更新」——**深度 embedding 模型可以「按行更新 embedding」，树不行**。实时推荐（[[realtime-recommendation-streaming]]）的时代，树的「静态性」成了硬伤。

**一句话**：GBDT+LR 的「树自动交叉」启发了整个「自动特征交叉」的方向，但它「不适稀疏、两阶段割裂、难在线」三个短板，恰好都是深度模型的长处——**它是「过渡态」，不是「终点态」**。

**补一句**：GBDT+LR 的「两阶段」虽然被「端到端」取代，但「先用树找交叉、再学权重」的「模块化思想」仍有价值——「复杂任务拆成两个可解释的模块」在「资源有限」时是务实选择。

**一个提醒**：GBDT 的「叶子特征」在「上线」时也要「保持一致」——「训练时的树」与「线上用的树」必须是「同一版本」，否则「叶子编号对不上」，LR 的权重就「错位」。

## 6 小结

- **GBDT+LR** 用树自动找特征交叉，用 LR 学交叉权重，是特征交叉自动化的第一次工业落地。
- 树路径 = 自动交叉特征；叶子 one-hot 后交给 LR，**每棵树只激活一片叶子**。
- 分工：**树负责找组合，LR 负责定权重与概率校准**，互补且可解释。
- 局限：两阶段割裂、对高维稀疏 ID 特征不友好，促使后续模型走向联合训练与深度化。

**术语速查**：

| 术语 | 一句话 |
| --- | --- |
| GBDT | 梯度提升决策树，逐轮拟合残差 |
| 叶子 one-hot | 把树路径编码成 0/1 稀疏向量 |
| 特征变换器 | 把原始特征变成交叉特征的黑箱 |
| 硬分裂 | 树的阈值切分，分段常数拟合 |
| 两阶段 | 先树后 LR，非联合训练 |
