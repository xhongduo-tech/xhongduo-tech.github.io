## 为什么需要「求解」而不只是「定义」

上一篇给出了 LFM 的模型形状 $\hat{r}_{ui} = p_u^{\mathsf{T}} q_i$，但这只是「骨架」——$p_u$、$q_i$ 还是未知数。这一篇把**学习过程**讲透：怎么定义「解得好」、怎么用梯度下降把参数解出来。这条路线有一个响亮的名字：**Funk-SVD**，它是 2006 年 Netflix 大奖赛（Netflix Prize）上由程序员 Simon Funk 提出、后来成为推荐系统矩阵分解标准解法的模型。<span class="marginnote">Netflix 大奖赛是推荐系统史上的「启蒙运动」：2006 年 Netflix 悬赏 100 万美元，把比赛算法的预测准确率提高 10%。Funk 的方法论传遍全球，<strong>矩阵分解从此取代邻域方法成为业界主力</strong>——关于这场比赛的细节，我们在第八篇《评分预测问题》还会展开。</span>

## 1 经典 SVD 为什么不能直接用

线性代数里的奇异值分解（SVD）你已经在第二级学过：任意矩阵 $R$ 都能分解成 $R = U \Sigma V^{\mathsf{T}}$。但直接把它套到推荐上有两个硬伤：

- **SVD 要求矩阵完整**：推荐矩阵是稀疏的，90% 以上格子缺失，SVD 无从分解。
- **把缺失当 0 是危险的**：若先把缺失填 0 再分解，等于假装「用户没看过 = 不喜欢」，会引入系统性偏差——我们在《协同过滤的优缺点》里强调过，**缺失里有信息，不能粗暴当负例**。

**辨析｜易错点：** 推荐系统圈子里说的「SVD」，几乎都不是数学教科书里的奇异值分解，而是 **Funk-SVD（也叫 LFM、潜在因子模型）**。两者都叫 SVD，但一个要求完整矩阵、一个只在已知评分上优化——**名字相同，血缘不同**。读到文献里的「SVD-based CF」，默认是指后者。

## 2 损失函数：只在已知评分上优化

Funk-SVD 的核心思想只有一句话：**只优化「我们确实知道的评分」**。设 $\mathcal{K} = \{(u,i) : r_{ui} \text{ 已知}\}$ 为所有已知评分的集合，定义损失：

$$
L = \sum_{(u,i) \in \mathcal{K}} \left( r_{ui} - \hat{r}_{ui} \right)^2
\;+\;
\lambda \left( \sum_u \|p_u\|^2 + \sum_i \|q_i\|^2 \right)
$$

- **第一项（误差项）**：在已知评分上，预测 $\hat{r}_{ui} = p_u^{\mathsf{T}} q_i$ 与真实评分 $r_{ui}$ 的**均方误差**。我们希望预测逼近真实。
- **第二项（正则项）**：$\lambda$ 是正则化系数，把 $p_u$、$q_i$ 的**模长**压住。没有它，模型会为了拟合已知评分而把向量设得极大，在未见数据上崩掉——这就是**过拟合**。<span class="marginnote">正则化在第三级《机器学习》里反复出现：<strong>损失函数 = 拟合项 + 惩罚项</strong>。$\lambda$ 控制「拟合数据」与「保持简单」的权衡，是推荐里最敏感的调参对象之一。</span>

注意求和只在 $\mathcal{K}$ 上——**缺失评分完全不进入损失**，这是与「填 0 再 SVD」的本质区别。

## 3 公式解析：梯度下降更新规则

损失函数是个关于 $p_u$、$q_i$ 的凸二次函数（对单个变量），用**随机梯度下降（SGD）**求解：每次随机取一个已知评分 $(u,i)$，让 $\hat{r}_{ui}$ 逼近 $r_{ui}$ 的同时小步更新两个向量。定义**误差**：

$$
e_{ui} = r_{ui} - \hat{r}_{ui} = r_{ui} - p_u^{\mathsf{T}} q_i
$$

对单个样本的损失 $\ell = e_{ui}^2 + \lambda(\|p_u\|^2 + \|q_i\|^2)$ 求偏导，用链式法则：

- **对 $p_u$ 求导**：$\dfrac{\partial \ell}{\partial p_u} = -2 e_{ui}\, q_i + 2\lambda\, p_u$
- **对 $q_i$ 求导**：$\dfrac{\partial \ell}{\partial q_i} = -2 e_{ui}\, p_u + 2\lambda\, q_i$

沿负梯度方向走一步，学习率 $\eta$，得到更新规则：

$$
p_u \leftarrow p_u + \eta\left( e_{ui}\, q_i - \lambda\, p_u \right), \qquad
q_i \leftarrow q_i + \eta\left( e_{ui}\, p_u - \lambda\, q_i \right)
$$

四步拆解：

- **第一步，算误差 $e_{ui}$**：预测减真实。误差为正说明预测低了，下一步把两个向量往「更贴近真实」的方向推；误差为负则反推。
- **第二步，看 $e_{ui}\, q_i$ 项**：把误差「顺着」对方向量方向传播。$p_u$ 更新时，误差乘以 $q_i$——**$q_i$ 告诉我们该往哪个隐因子方向修正 $p_u$**。这就是「梯度信号在向量间传递」。
- **第三步，看 $-\lambda\, p_u$ 项**：正则项把 $p_u$ 往零拽，防止向量无限膨胀。$\lambda$ 越大，向量越短，模型越保守。
- **第四步，看学习率 $\eta$**：步长。太大震荡不收敛，太小收敛慢。工程上常取 $0.001 \sim 0.1$，配合每轮衰减。

**辨析｜易错点：** 更新 $p_u$ 用的是**当轮、更新前的** $q_i$，而不是更新后的 $q_i$。在 SGD 里对每个样本通常**先更新 $p_u$、再更新 $q_i$**（或反之），但两次更新共用同一个 $e_{ui}$。若先更新 $p_u$ 再用新 $p_u$ 重算 $e_{ui}$ 去更新 $q_i$，就变成了「两步梯度」，收敛行为会变——保持「一个样本、一次误差、两次更新」是标准做法。

## 4 从公式到代码：一个完整的训练循环

把上面的规则翻译成代码，整个训练函数只有三十行左右：

```python
import numpy as np

def train_lfm(ratings, K=20, lr=0.01, lam=0.1, epochs=30):
    """ratings: list of (user, item, rating) 三元组；K 为隐因子个数。"""
    U = max(u for u, _, _ in ratings) + 1
    I = max(i for _, i, _ in ratings) + 1
    # 参数初始化：小随机数，避免对称性与零梯度
    P = np.random.rand(U, K) * 0.1
    Q = np.random.rand(I, K) * 0.1
    for epoch in range(epochs):
        np.random.shuffle(ratings)          # 随机打乱，SGD 需要
        for u, i, r in ratings:
            e = r - np.dot(P[u], Q[i])      # 第一步：误差
            P[u] += lr * (e * Q[i] - lam * P[u])   # 更新 p_u
            Q[i] += lr * (e * P[u] - lam * Q[i])   # 更新 q_i
        # 每轮打印训练集 RMSE，观察收敛
        loss = np.sqrt(np.mean([(r - np.dot(P[u], Q[i]))**2 for u, i, r in ratings]))
        print(f"epoch {epoch+1}: RMSE = {loss:.4f}")
    return P, Q
```

训练完成后，**预测就是一次内积** $\hat{r}_{ui} = P[u] \cdot Q[i]$——线上一张向量表，毫秒级返回。这就是《向量召回》里「物品向量」的雏形。<span class="marginnote">注意初始化的细节：参数用 <strong>0.1 量级的小随机数</strong>。初始化为 0 会导致梯度为零、模型学不动；初始化太大则起步就发散。第三级《机器学习》里「对称破坏」的思想在这里有最直观的体现。</span>

## 5 决定效果的四个关键参数

项亮在 §2.5 里强调，LFM 的效果主要由四个参数决定，按重要性大致排序：

| 参数 | 含义 | 调参直觉 |
| --- | --- | --- |
| **负正样本比例** | 隐式反馈只有正样本，需要采负样本 | 对隐式数据影响最大，常取 1~3 |
| **隐因子个数 $K$** | 模型的表达能力 | 太小欠拟合、太大过拟合，常用 20~200 |
| **正则系数 $\lambda$** | 防过拟合强度 | 越大模型越保守，需配合数据量 |
| **学习率 $\eta$** | SGD 步长 | 太大震荡、太小缓慢，可随轮数衰减 |

其中「**负正样本比例**」对隐式反馈（点击、购买）特别关键：隐式数据只有正例，必须**从「用户没行为的物品」里采样负例**，且采样比例直接影响效果——这是第三篇《隐式反馈的矩阵分解》要深入展开的话题。<span class="marginnote">负采样是隐式推荐的「隐形战场」：<strong>采样比例、采样分布（热门/冷门加权）都改变模型学到的语义</strong>。这个坑我们在第五篇《双塔召回中的负采样》会再次遇到——届时 batch 内负采样是它的现代版本。</span>

## 6 小结

- **经典 SVD** 要求矩阵完整，推荐矩阵稀疏，不能直接用；推荐圈说的「SVD」实为 **Funk-SVD**。
- **损失函数** $L = \sum_{(u,i)\in\mathcal{K}}(r_{ui}-\hat{r}_{ui})^2 + \lambda(\|p_u\|^2+\|q_i\|^2)$：只在**已知评分**上优化，用正则项防过拟合。
- **更新规则** $p_u \leftarrow p_u + \eta(e_{ui}q_i - \lambda p_u)$、$q_i \leftarrow q_i + \eta(e_{ui}p_u - \lambda q_i)$：误差在向量间传递，正则把向量往零拽。
- 训练是**随机梯度下降**，参数初始化用 0.1 量级小随机数；预测时一次内积、毫秒级返回。
- 效果由 **负正样本比例、$K$、$\lambda$、$\eta$** 四个参数主导，其中负采样对隐式反馈影响最大。

Funk-SVD 已经能学出不错的隐向量，但它还不够精致：它假设**所有用户的评分基准都一样**，可现实中有人慷慨给高分、有人吝啬——这种「个人尺度」差异该由谁来消化？下一篇《带偏置项的矩阵分解（BiasSVD）》会用一个巧妙的偏置项解决它。
