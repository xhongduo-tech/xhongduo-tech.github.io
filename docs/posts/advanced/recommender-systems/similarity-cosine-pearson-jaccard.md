## 为什么从相似度开始

上一篇搭好了邻域方法的四步框架，但刻意留了一个关键空位：**「相似度」到底怎么算？** 框架里「找邻居」这一步，全靠相似度来定义「谁是我的邻居」——相似度算错，后面的邻居、预测、推荐全是错的。**相似度是邻域方法的引擎，也是整个协同过滤最核心的度量**。<span class="marginnote">相似度的选择不只是数学细节：同样的数据，用余弦和用皮尔逊，找出的「最相似用户」可能完全不同，推荐结果也随之变。工程上这一步定生死。</span>

这一篇把三种最经典的相似度逐一算透：**余弦相似度（cosine）**、**皮尔逊相关系数（Pearson）**、**Jaccard 相似度**。它们分别对应「数值向量」「去均值后的数值向量」「集合」三种数据形态。

## 1 把用户和物品变成向量

协同过滤的一切相似度，都建立在把用户（或物品）表示成向量上。

以用户 $u$ 为例，把他对所有物品的行为值排成一列，就是他的**行为向量** $\vec{u} = (r_{u1}, r_{u2}, \dots, r_{um})$。用户 $u$ 与 $v$ 的相似度，就是这两个向量的「相近程度」。<span class="marginnote">这是「从极限到大模型」主线的老朋友：把现实对象映射成向量，再在向量空间里讨论距离与角度——第二级《线性代数》的内积、范数、夹角在这里全部派上用场。</span>

注意一个现实约束：**向量往往只在其「共同评过」的维度上比较**。两个用户几乎没评过相同的物品，相似度就无从谈起——这再次把我们带回「稀疏性」这个根本约束。

## 2 余弦相似度：看方向，不看长度

**余弦相似度（cosine similarity）** 度量两个向量夹角的余弦：

$$\mathrm{sim}_{cos}(u, v) = \frac{\vec{u} \cdot \vec{v}}{\|\vec{u}\| \, \|\vec{v}\|} = \frac{\sum_{i} r_{ui}\, r_{vi}}{\sqrt{\sum_i r_{ui}^2} \cdot \sqrt{\sum_i r_{vi}^2}}$$

它的几何直觉是：**只看两个向量「指向」是否一致，不管它们「多长」**。夹角为 0 时相似度为 1（完全同向），夹角 90° 时为 0（无关），夹角 180° 时为 −1（完全反向）。

这个「不管长度」的性质是双刃剑。一方面它天然免疫「评分尺度」——用户 A 习惯打 4~5 分、用户 B 习惯打 1~2 分，只要两人对物品的相对喜好一致，方向就接近，余弦就高。<span class="marginnote">但要注意：余弦只对「乘性」的尺度差异免疫（A 的评分整体是 B 的 2 倍），对「加性」的偏移却不免疫——A 总比 B 高 2 分时，方向已经不同了。这个缺陷正是皮尔逊要修的。</span>

## 3 皮尔逊相关系数：去掉各自的「习惯」

**皮尔逊相关系数（Pearson correlation coefficient）** 在余弦之前，先各自减去用户的平均分：

$$\mathrm{sim}_{pear}(u, v) = \frac{\sum_{i \in I_{uv}} (r_{ui} - \bar{r}_u)(r_{vi} - \bar{r}_v)}{\sqrt{\sum_{i \in I_{uv}} (r_{ui} - \bar{r}_u)^2} \cdot \sqrt{\sum_{i \in I_{uv}} (r_{vi} - \bar{r}_v)^2}}$$

其中 $I_{uv}$ 是两用户共同评过的物品集合，$\bar{r}_u$、$\bar{r}_v$ 是各自的平均分。**减去平均分，就是把「评分习惯」抹平**：A 总打高分、B 总打低分，没关系，我们只看「在各自基准之上，谁高谁低」。皮尔逊的取值在 $[-1, 1]$，比余弦多了一个重要信息——**负相关**：你不喜欢的我偏喜欢，这同样是强信号。

**核心事实：皮尔逊相关系数 = 对「去均值后的向量」算余弦相似度。** 这是理解两者关系的钥匙，我们在第 5 节用具体数字验证。

## 4 Jaccard 相似度：只看「有没有」

如果数据里没有评分，只有「买没买」「点没点」这类**二值行为**，向量退化成集合——这时用 **Jaccard 相似度（Jaccard coefficient）**：

$$J(A, B) = \frac{|A \cap B|}{|A \cup B|}$$

A 与 B 分别是两个用户「有过行为的物品集合」。**分子是共同行为数，分母是行为并集数**。两人都买过的物品越多、各自独有的越少，Jaccard 越大。<span class="marginnote">Jaccard 天然是 0~1 的比率，直观且稳健，但它<strong>丢弃了行为强度</strong>：反复购买 10 次的用户，和只买 1 次的用户，在集合视角下权重相同。这在只有点击/购买日志的隐式反馈场景里是最常用的选择——我们在《数据来源》一篇说过隐式反馈只有「有/无」。</span>

## 5 公式解析：余弦与皮尔逊，差一个「去均值」

用一个具体数字感受余弦与皮尔逊的差别。设三位用户在共同的三部电影上的评分为：

| 用户 | 电影 a | 电影 b | 电影 c | 平均分 |
| --- | --- | --- | --- | --- |
| A | 4 | 3 | 5 | 4.0 |
| B | 2 | 1 | 3 | 2.0 |
| C | 4 | 1 | 5 | 3.33 |

**第一步，算 A 与 B 的余弦相似度。** 分子 $= 4\times 2 + 3\times 1 + 5\times 3 = 26$；$\|\vec{A}\| = \sqrt{16+9+25} = \sqrt{50} \approx 7.07$，$\|\vec{B}\| = \sqrt{4+1+9} = \sqrt{14} \approx 3.74$。于是

$$\mathrm{sim}_{cos}(A,B) = \frac{26}{7.07 \times 3.74} \approx 0.983$$

**第二步，算 A 与 B 的皮尔逊相关。** 去均值：$\vec{A}' = (0, -1, 1)$（各减 4），$\vec{B}' = (0, -1, 1)$（各减 2）。两个去均值向量完全一样，所以

$$\mathrm{sim}_{pear}(A,B) = \frac{0\times0 + (-1)(-1) + 1\times1}{\sqrt{0+1+1}\cdot\sqrt{0+1+1}} = 1.0$$

**第三步，看差异从哪来。** A 的每一项都比 B 高 2 分——B 是 A 的「等比缩小版」，偏好形状完全一致，只是整体低两档。余弦只得了 0.983，**因为加性偏移把方向拉歪了一点**；皮尔逊减去均值后完美对齐，得到 1.0。<span class="marginnote">这就是两者的分工：<strong>余弦对乘性差异免疫、对加性偏移敏感；皮尔逊对加性偏移也免疫，因为它把每个人的平均分当作「自己的基准」</strong>。若你觉得用户「总打高分」是个人习惯、不该算进相似度，就用皮尔逊。</span>

**第四步，对比 A 与 C。** 余弦：$\frac{16+3+25}{\sqrt{50}\times\sqrt{16+1+25}} = \frac{44}{7.07\times6.48} \approx 0.960$；皮尔逊：$\vec{C}' = (0.67, -2.33, 1.67)$，$\frac{0+2.33+1.67}{\sqrt{2}\times\sqrt{8.67}} \approx 0.961$。两者接近——因为 C 与 A 的均值差异不大，加性偏移影响小。

这个例子说明：**选择余弦还是皮尔逊，本质上是在回答「评分中的个人习惯算不算相似度的一部分」。** 工业界里，显式评分（如 1~5 星）常用皮尔逊，隐式反馈（点击/购买）常用余弦或 Jaccard。

## 6 ItemCF 的特殊处理：调整的余弦

物品相似度的计算有一个额外陷阱。ItemCF 里要算「物品 $i$ 与 $j$ 的相似度」，但**不同用户打分的宽严不同**：A 习惯打 5 分、B 习惯打 3 分，他们给同一件商品打的分数不能直接比。于是 ItemCF 用**调整的余弦相似度（adjusted cosine）**——先减去**每个用户的平均分**，再算余弦：

$$\mathrm{sim}(i, j) = \frac{\sum_{u \in U_{ij}} (r_{ui} - \bar{r}_u)(r_{uj} - \bar{r}_u)}{\sqrt{\sum_{u \in U_{ij}} (r_{ui} - \bar{r}_u)^2} \cdot \sqrt{\sum_{u \in U_{ij}} (r_{uj} - \bar{r}_u)^2}}$$

对比第 3 节的皮尔逊公式，唯一区别是：UserCF 里减的是「用户的平均分」（和皮尔逊一样），这里同样减用户平均分——**区别在于这里的求和是对「共同评过 $i, j$ 的用户」做**。调整的余弦之所以重要，是因为它把「用户的评分习惯」从物品相似度中剥离——否则，一个「评分慷慨」的用户会无差别抬高所有他评过的物品之间的相似度。<span class="marginnote">一个易混淆点：UserCF 的皮尔逊和 ItemCF 的调整余弦在数学形式上几乎一样（都是「减用户均值后的余弦」），<strong>区别只在求和的方向——前者按物品维度对齐两个用户，后者按用户维度对齐两个物品</strong>。</span>

## 7 用代码算一遍

三种相似度用 Python 实现都很短（可直接运行）：

```python
import numpy as np

def cosine(a, b):
    return float(a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))

def pearson(a, b):
    a, b = a - a.mean(), b - b.mean()      # 去均值：皮尔逊 = 去均值后的余弦
    return float(a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))

def jaccard(set_a, set_b):
    return len(set_a & set_b) / len(set_a | set_b)

A = np.array([4., 3., 5.]); B = np.array([2., 1., 3.]); C = np.array([4., 1., 5.])
print(f"cosine(A,B) = {cosine(A,B):.3f}, pearson(A,B) = {pearson(A,B):.3f}")
# cosine(A,B) = 0.983, pearson(A,B) = 1.000
print(f"cosine(A,C) = {cosine(A,C):.3f}, pearson(A,C) = {pearson(A,C):.3f}")
# cosine(A,C) = 0.960, pearson(A,C) = 0.961

print(jaccard({'a','b','c'}, {'a','b','d'}))   # 2 / 4 = 0.5
```

## 8 选择建议与辨析

| 数据形态 | 代表场景 | 首选相似度 | 为什么 |
| --- | --- | --- | --- |
| 显式评分（1~5 星） | 电影、电商评分 | 皮尔逊 / 调整余弦 | 消除个人评分习惯 |
| 隐式反馈（点击、购买） | 短视频、新闻 | 余弦 / Jaccard | 只有「有/无」，无均值可减 |
| 纯集合（无数值） | 标签、加购 | Jaccard | 天然处理二值集合 |

**辨析｜易错点：** 三个高频坑。其一，**别在隐式反馈上硬用皮尔逊**——点击数据没有「评分均值」的稳定含义，减均值反而引入噪声。其二，**别忘记只算共同维度**——余弦在零填充的完整向量上会被大量「共同为 0」稀释，实践上只在两用户共同评过的维度上计算。其三，**相似度不是相关性**：Jaccard 只看「同现」，不度量「此消彼长」的负相关；若你的业务需要捕捉「喜欢 A 的人讨厌 B」，Jaccard 无能为力。

## 9 小结

- **余弦相似度**看向量夹角、不看长度，对乘性尺度免疫、对加性偏移敏感。
- **皮尔逊相关系数** = 去均值后的余弦，抹平「评分习惯」，取值 $[-1, 1]$，能捕捉负相关。
- **Jaccard 相似度**用集合交并比度量「同现」，适合只有「有/无」的隐式反馈。
- **ItemCF 用调整的余弦**：减用户均值，按用户维度对齐两个物品，剥离评分慷慨度。
- **选型口诀**：有评分用皮尔逊，无评分用余弦 / Jaccard，只算共同维度。
