## 为什么从制药讲起

一颗药片的有效成分是固体，而固体的**形态**（晶型、非晶、粒径）直接决定药效：有的晶型不溶于水，吃了白吃；有的晶型稳定，放五年不变质。药学家最想要的，往往是「分子没变、只是把堆积方式调一调」就解决问题——这正是机械化学的用武之地。<span class="marginnote">机械化学之于制药的意义，不只是「研磨更细」这么简单：它能<strong>不换分子只换形态</strong>——造共晶、调多晶型、做无定形，而全程几乎不用溶剂。</span>

制药机械化学在产业界已是真金白银的技术：共晶药物获批上市、球磨工艺进入产线。本篇讲清楚三件事：药物固体的困境、共晶是什么、研磨怎么造出它们。

## 1 药物固体的形态问题

活性药物成分（API）是以**固体**形式存在的分子，而同一分子可以有无数种固体形态：

**多晶型（polymorphs）**：同一分子的不同晶体堆积；
- **溶剂化物/水合物**：晶格里嵌着溶剂分子；
- **盐**：API 与反离子成离子键；
- **无定形（amorphous）**：没有长程有序的玻璃态。

**重点：** 这些形态分子相同、性质迥异。溶解度、溶出速率、吸湿性、化学稳定性、可压片性，全部跟着形态走。而形态之间自由能差往往只有几 kJ·mol⁻¹，极易在工艺中被温度、湿度、机械力偷偷翻转——**「做对了分子，输给了形态」是制药工程最经典的翻车现场**。

## 2 共晶：不改变分子、只改变堆积

**药物共晶（pharmaceutical cocrystal）**：API 与一种或多种固体共形成分子（coformer）通过**非共价相互作用（主要是氢键）**组装在同一晶格里的结晶材料。关键特征是**没有质子转移**——不同于盐，API 与共形成分子以分子形式共存。

共晶的设计逻辑很聪明：若 API 的某官能团（如酰胺、羧基）能与其他分子形成更稳定的氢键网络，就能把 API「拖进」一个溶解度更高、更稳定的晶格。经典案例：

- **咔马西平-烟酰胺**共晶：卡马西平的溶解行为被彻底改写；
- **咖啡因-草酸**共晶：咖啡因微溶问题得到改善；
- **布洛芬-烟酰胺**共晶：布洛芬的溶出加快。

2018 年，美国 FDA 发布《药物共晶的监管分类指南》，正式承认共晶是一类可申报的固体形态——共晶从此走上产业正轨。<span class="marginnote">共晶的「稳」来自晶格能：共形成分子像锚点一样把 API 锁进更致密的氢键网络，比纯 API 多晶型更抗潮解、更可预测。</span>

## 3 研磨制备共晶：NG 与 LAG

共晶怎么造？经典路线是溶液结晶——把 API 与共形成分子溶解后再结晶。但溶液路线受溶解度匹配、溶剂种类限制，还浪费大量溶剂。**机械化学路线用研磨直接「干搓」出共晶**：

**干研磨（neat grinding, NG）**：API 与共形成分子粉末直接混合研磨，靠机械力诱发固态氢键重组，形成共晶。
- **液体辅助研磨（liquid-assisted grinding, LAG）**：加微量溶剂（几十微升），结晶度与产率显著提升。第 2 篇的 η 参数在这里是法宝：η 调得好，共晶一次成；调不好，出来的是混合相或无定形。

2004 年，特拉斯克（Trask）与琼斯（Jones）等人用「溶剂滴研磨」系统制备了一系列共晶，开创了高通量共晶筛选范式：**用研磨取代溶液结晶，几个小时内就能把几十对候选 API/共形成分子扫一遍**。<span class="marginnote">研磨筛选比溶液筛选快一个数量级，且不受溶解度约束——「溶不了」的候选对在研磨下照样能成共晶，这正是机械化学「绕开溶解」价值的最佳注脚。</span>

## 4 研磨诱导非晶化：无定形药物

共晶之外，研磨的另一大制药用途是**非晶化**：高能球磨把晶态 API 磨成无定形。无定形没有晶格能束缚，表观溶解度与溶出速率远高于晶体，对难溶药物（BCS II/IV 类）是提升生物利用度的捷径。

代价是无定形**热力学不稳定**：有重结晶回晶态的趋势，储存期可能失效。产业界的解法是与稳定剂共研磨（如与聚合物共球磨、做固溶体），让无定形被高分子「托住」，减缓回晶。<span class="marginnote">研磨造无定形的好处是<strong>不用溶剂、一步到位</strong>：传统喷雾干燥/冻干要过大量溶剂，研磨罐里几十分钟完事，而且粒径同时被细化，一举两得。</span>

**辨析｜易错点：** 研磨参数对产物形态的敏感性极高。同一种药，低能研磨可能只细化晶粒（保持晶型），高能研磨才非晶化，加 LAG 溶剂又可能诱导重结晶回另一晶型。**「磨什么出来」是能量注入与动力学路径的平衡问题**——这正是第 4 篇「机械诱导相变」的制药现场版。

## 5 公式解析：Noyes–Whitney——研磨为什么提升药效

「形态决定药效」的定量核心是**溶出速率**。Noyes–Whitney 方程描述药物溶解的速度：

$$
\frac{\mathrm{d}C}{\mathrm{d}t} = \frac{D\,A}{h}\,\bigl(C_{\mathrm{s}} - C\bigr)
$$

四步拆解，看研磨动了哪一个旋钮：

- **第一步，$D$ 与 $h$**：扩散系数与扩散层厚度。分子本性决定，工艺难改。
- **第二步，$A$**：固体与溶液的接触面积。**这就是研磨动的大旋钮**——粉碎/非晶化让比表面积暴涨，溶出速率成正比提高。
- **第三步，$C_{\mathrm{s}}$**：饱和溶解度。晶型与无定形的差异在这里体现：无定形 $C_{\mathrm{s}}$ 更高，溶出更猛。
- **第四步，$(C_{\mathrm{s}}-C)$**：浓度差驱动的「爬坡」。前期浓度低、梯度大，溶出快；越接近饱和越慢。

**重点：** 研磨同时动了 $A$ 与 $C_{\mathrm{s}}$ 两个旋钮（细化+可能非晶化），因此对溶出的提升是双重的。而共晶的妙处在于——它提升 $C_{\mathrm{s}}$ 的方式不是破坏晶格（非晶化的高能态），而是**换了一个更「亲水」的晶格**，即提升了稳定性与溶出的双赢。

再给几个具体的共晶体系，让「共形成分子」这个抽象概念落地：

| API | 共形成分子 | 主要收益 |
| --- | --- | --- |
| 咔马西平 | 烟酰胺 | 调控多晶型与溶出 |
| 咖啡因 | 草酸/水杨酸 | 提高溶解度与稳定性 |
| 布洛芬 | 烟酰胺 | 加速溶出 |
| 茶碱 | 多种羧酸 | 改善加工性 |

选择共形成分子的经验法则：**官能团互补**（氢键给体配受体）、**分子大小相近**（匹配晶格位点）、**安全性已知**（最好已是药用辅料）。这些规则让共晶设计从「碰运气」变成「按图纸搭积木」。

**重点：** 共晶与盐的根本区别在于**有无质子转移**。判断实验是看红外/固体核磁中的官能团振动与化学位移——发生质子转移就是盐，没有就是共晶。FDA 指南与专利诉讼里，这一字之差常常决定专利效力。

## 6 从共晶筛选到注册申报：一条产业路径

把共晶从实验室带到药房，大致要走四步：

- **筛选**：用 NG/LAG 研磨（可配 η 扫描）在几十对 API/共形成分子间高通量筛出「能成晶」的组合——研磨让筛选不受溶解度限制。
- **表征确证**：PXRD 确认新晶相、单晶/粉末解析晶格、DSC 测熔点与热稳定、DVS 测吸湿性、溶出实验验证收益——确证「真共晶，非混合物」是申报前提。
- **稳定性评估**：共晶要过高温高湿加速试验，确认不会脱共形成分子、不回变为 API 单体。
- **注册申报**：按 FDA 2018 指南把共晶作为固体形态申请，配套的晶型控制策略要写进生产工艺。

**重点：** 这条路径里机械化学的身影贯穿「筛选」与「放大」：研磨既做了高通量发现工具，又是可放大的制备工艺（大型行星磨/挤出机，见第 12 篇）。**共晶因此成了「机械化学最先跑通全流程」的制药场景**——分子设计、绿色制备、注册申报三点一线。

**一句话备忘**：制药机械化学的核心三问——磨出什么相（形态控制）、为什么是这相（动力学路径）、怎么稳定它（工艺设计）。三个问题的答案，分别来自第 4 篇的相变、第 5 篇的理论与第 12 篇的工程。**形态决定疗效，工艺决定形态。**

**延伸提醒**：读药物固体的文献时，留意论文是否报了「制备条件五元组」（转速、球料比、时间、球材、气氛/η）——不报的，结果往往不可复现。这个习惯，从第 2 篇设备篇就该养成了。

**一句话总结**：制药机械化学的要义，是用研磨这把「形态手术刀」，在不改变分子的前提下改药物命运——共晶、无定形、多晶型，都是这把刀的手术对象。

**延伸**：药企评价机械路线，最终看三件事：可控性（批间一致）、稳定性（保质期）、合规性（可申报）——三者缺一，工艺再绿也难上市。

## 7 小结

- 药物固体的形态（多晶型/共晶/盐/无定形）决定溶解度与稳定性，分子没变、形态翻车是制药大忌。
- **共晶**：API 与共形成分子以氢键组装、无质子转移；FDA 2018 年已将其纳入监管分类。
- 研磨制备共晶：**NG 干磨 + LAG 液体辅助**，η 参数决定结晶质量；研磨把共晶筛选变成高通量工艺。
- 研磨也做**非晶化**，提升溶出但需与稳定剂共研磨防回晶。
- Noyes–Whitney 方程 $\mathrm{d}C/\mathrm{d}t = DA(C_{\mathrm{s}}-C)/h$ 揭示：研磨同时放大表面积 $A$ 与溶解度 $C_{\mathrm{s}}$，是药效双引擎。
