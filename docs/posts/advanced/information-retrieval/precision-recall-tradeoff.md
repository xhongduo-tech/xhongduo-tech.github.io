## 为什么把两个率放在一起

上一篇我们造好了评测的原料：相关文档集合 $R_q$（答案）与系统检出集合 $A_q$（答卷）。这一篇要把两份集合放进一张四格表，催生出信息检索**最基础、也被用得最多**的两个指标——**查准率（Precision）**与**查全率（Recall）**。

它们几乎回答了用户对检索结果的全部朴素期待：**「返回来的，是不是都相关？」** 和 **「相关的，是不是都被返回了？」** 这两个问题互相拉扯——把结果列表拉长，第二句容易满足，第一句却更难保证；把列表收紧，第一句漂亮了，第二句又漏了。理解这套「权衡」，是理解后续一切排序指标（F 值、MAP、NDCG）的起点，也是理解今天 RAG 评测中「召回率 vs 上下文质量」拉锯的同一根轴。<span class="marginnote">在第四级《机器学习》的分类评估里，查准率 / 查全率 / F1 是每本教材的必修课；在第四级《大模型原理》第十四篇的 RAG 评测里，「检索召回率」与「生成忠实度」又是一对类似的天平。信息检索是把这对概念讲得最本质的地方。</span>

## 1 从判定到计数：四格表

上一篇的两个集合可以拼成一张 2×2 的**列联表（contingency table）**：横轴是「系统是否检出」，纵轴是「实际是否相关」。四个格子各有名字：

| | 检出（retrieved） | 未检出（not retrieved） |
| --- | --- | --- |
| **相关（relevant）** | 真正例 tp（true positive） | 假负例 fn（false negative） |
| **不相关（not relevant）** | 假正例 fp（false positive） | 真负例 tn（true negative） |

四个格子的直觉对照着记：

- **tp（true positive）**：检出了，而且确实相关——这是系统唯一的「战绩」。
- **fp（false positive）**：检出了，但其实不相关——「误报」，浪费用户眼球的噪音。
- **fn（false negative）**：该检出却没检出——「漏报」，用户最想看的被埋没了。
- **tn（true negative）**：没检出，也确实不相关——「正确地忽略」，存在感最低，但数量通常最大。

注意一个不对称：$R_q$ 的大小是 $tp + fn$（相关文档的总量），$A_q$ 的大小是 $tp + fp$（系统检出的总量）。**$tp$ 同时出现在两个总量里，是两个指标的公共分子**——这一点是理解 P / R 权衡的钥匙。

## 2 定义查准率与查全率

两个指标用四个格子里的三个来定义：

$$\text{Precision} = P = \frac{tp}{tp + fp} = \frac{|R_q \cap A_q|}{|A_q|}$$

$$\text{Recall} = R = \frac{tp}{tp + fn} = \frac{|R_q \cap A_q|}{|R_q|}$$

给两种直觉：

- **查准率看「检出里的纯度」**：在系统返回的所有文档里，真正相关的占比。它惩罚**误报**——返回一堆垃圾，查准率就塌了。
- **查全率看「相关里的覆盖度」**：在所有相关文档里，系统找回来的占比。它惩罚**漏报**——该找的没找全，查全率就塌了。

写成一段 Python，就是四个集合的规模之比：

```python
retrieved = {...}     # 系统检出的集合 A_q
relevant  = {...}     # 相关文档集合 R_q

tp = len(retrieved & relevant)      # 检对：两集合的交集
fp = len(retrieved - relevant)      # 误报：检出了但不相关
fn = len(relevant - retrieved)      # 漏报：相关但没检出

precision = tp / (tp + fp) if tp + fp else 0.0
recall    = tp / (tp + fn) if tp + fn else 0.0
```

**辨析｜易错点：查准率的分子是 tp，不是「检出的相关数」以外的任何东西；分母也不是文档总数。** 初学者最容易写错的是把 Precision 写成 $tp / (tp + fn)$（那是 Recall），或把分母误当作文档全集。记住一句话：**Precision 的分母是「系统说了算的部分」（$A_q$），Recall 的分母是「客观相关的那部分」（$R_q$）**——一个以系统输出为准，一个以地面真值为准。

## 3 公式解析：两个率为什么「此消彼长」

把两个公式并排放在一起，看它们的结构：

$$P = \frac{tp}{tp + fp}, \qquad R = \frac{tp}{tp + fn}$$

四步拆解这个「权衡」的机理：

- **第一步，分子是同一个 $tp$。** 两个指标共享同一个分子——「找对了的相关文档」。因此 P 和 R 不是两个独立的指标，而是**同一份战绩（tp）被两个不同的分母归一化**的结果。
- **第二步，分母的区别。** $P$ 的分母是「检出量」$tp+fp$，它随系统**主动行为**变化；$R$ 的分母是「相关总量」$tp+fn$，它由**测试集判定**固定，不随系统行为变化。
- **第三步，把结果列表拉长的效果。** 让系统返回**更多**文档（把截断点 $k$ 调大）：$R_q$ 不变，于是**Recall 单调不降**——每多检出一篇相关文档，$tp$ 增加，$R$ 增大；即使多检出的不相关，$R$ 也不变。但 **Precision 没有这种保证**：新加进来的文档若是相关的，$P$ 可能**上升**；若是不相关的，$P$ 就**下降**。<span class="marginnote">很多人以为「召回升高查准率必然降低」——这不严谨。严格的说法是：<strong>Recall 单调不降；Precision 整体随截断点后移而倾向下降，但会在局部上下跳动。</strong> 这个「跳动」在画 P-R 曲线时会形成锯齿，下一篇的插值查准率就是为抹平锯齿而生。</span>
- **第四步，两个极端工作点。** 把全部文档都返回：$tp = tp + fn$，所以 $R = 1.0$（全中），但 $P$ 往往极低；只返回一篇「最有把握相关」的文档：若它确实相关，$P = 1.0$，但 $R$ 微乎其微。**你选择在哪个 $k$ 处截断，就是在 P 与 R 之间挑选工作点**——这就是「权衡」的精确含义：不是两个数字打架，而是你决定在哪里下刀。

用一个具体例子看这个拉锯。设某个查询有 4 篇相关文档（$|R_q| = 4$），系统返回 10 篇，其中相关文档排在**第 1、3、5、6 位**。逐截断点算 P@k 与 R@k：

| 截断点 k | 返回的相关数 tp | P@k | R@k |
| --- | --- | --- | --- |
| 1 | 1 | 1.000 | 0.250 |
| 2 | 1 | 0.500 | 0.250 |
| 3 | 2 | 0.667 | 0.500 |
| 4 | 2 | 0.500 | 0.500 |
| 5 | 3 | 0.600 | 0.750 |
| 6 | 4 | 0.667 | 1.000 |
| 10 | 4 | 0.400 | 1.000 |

这张表把两个现象都演示出来了：**R@k 一路从 0.25 爬到 1.0，绝不回头；P@k 却在 0.5、0.667、0.5、0.6 之间来回跳**——k=6 时 P 反而比 k=5 高，因为第 6 位恰好是相关文档。这就是「整体下降、局部锯齿」的实证。

## 4 用一条曲线看权衡

把上表画成曲线：横轴是 Recall，纵轴是 Precision，每个截断点 $k$ 对应一个点，按 $k$ 增大依次连起来。这条 **P-R 曲线**是评测检索系统最经典的图。

P-R 曲线有几个必须读懂的几何事实：

- **曲线越往右上，系统越好。** 理想系统在 $R=1.0$ 处仍然保持 $P=1.0$（右上角），而现实系统的曲线总是从左上往右下塌。
- **曲线呈锯齿状是正常的。** 每跨过一个「相关文档」的截断点，P 跳一下；每跨过一个「不相关」的截断点，P 跌一下。锯齿不是 bug，是相关文档在排序中分布不均匀的必然结果。
- **单点指标不够，要看整体。** 只报「P@10 = 0.4」丢掉了曲线形状；把整条曲线纳入比较，才看得出一个系统是「前几篇特别准」还是「从头到尾都稳」。

基于这条曲线，IR 定义了若干实用的单点派生量，它们都是「在 P 与 R 之间选一个折衷」：

- **R-Precision**：在**第 $|R_q|$ 个位置**截断时的 P 与 R——即「返回前 4 篇（相关文档总数）时的查准率」。上例中 $|R_q| = 4$，R-Precision = P@4 = 0.5。
- **Break-even point（平衡点）**：P 与 R 恰好相等的那个点。
- **Average Precision（平均查准率，AP）**：只对「相关文档被检出的位置」处的 P 求平均——它是下一节《平均查准率 MAP》的主角，也是从「单点权衡」走向「整条曲线概括」的关键一步。

**辨析｜易错点：P 与 R 不是彼此的函数。** 给定一个 $R$，$P$ 可以取很大范围的值——因为 $fp$ 是自由变量。所以在比较两个系统时，**不能只比一个数**（「我的 P 高所以我的好」），必须要么固定 $R$ 比 $P$、要么固定 $P$ 比 $R$、要么用一个把两者合并的指标（F 值、AP）。只看单边，是评测中最常见的误用。

## 5 小结

- **四格表**：tp（检对）、fp（误报）、fn（漏报）、tn（正确忽略）；$|R_q| = tp+fn$，$|A_q| = tp+fp$。
- **查准率** $P = tp/(tp+fp)$：检出的文档里相关的占比，惩罚误报；**查全率** $R = tp/(tp+fn)$：相关的文档里检出的占比，惩罚漏报。
- **权衡的机理**：分子共享同一个 $tp$，分母一个以系统输出为准、一个以地面真值为准；把截断点后移，Recall **单调不降**，Precision **整体倾向下降但局部锯齿**。
- **工作点**：在哪个 $k$ 截断，就是在 P 与 R 之间选择折衷；两个极端是「全部返回」（$R=1$，P 塌）与「只返回一篇」（$P=1$，R 塌）。
- **派生量**：R-Precision、平衡点、Average Precision，都是「从整条 P-R 曲线里提炼单点」的不同方式。
