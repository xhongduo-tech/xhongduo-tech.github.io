## 为什么从"画像"开始

上一篇立住了个性化的定位：把用户信息纳入排序。但"用户信息"是一个模糊词——它到底是什么？**用户画像（user profiling / user modeling）** 就是把"用户是谁、喜欢什么、此刻要什么"建构成可计算的形式。它是个性化的地基：画像的质量，直接决定个性化排序的质量。

画像面临一个核心矛盾：**长期与短期的张力**。用户的**长期兴趣**稳定但宽泛（喜欢深度学习、关注科技），**短期意图**具体但易变（此刻在找"深度学习 GPU 显卡"）。只建模长期，会忽略当下的具体需求（个性化跑偏）；只建模短期，会丢失稳定的偏好（个性化碎片化）。**好的画像要同时捕捉"长期兴趣"与"短期意图"，并让它们按场景协同**。<span class="marginnote">"长期 vs 短期"的建模张力，在推荐系统里叫"长期偏好 vs 会话意图"，在广告里叫"用户价值 vs 即时需求"。<strong>它本质上是"稳定信号 vs 即时信号"的时间尺度问题</strong>——长期信号稳定但滞后，短期信号即时但噪声大。工业画像的通行做法是"分层时间衰减"：不同时间粒度的行为按不同衰减率加权，长期用慢衰减、短期用快衰减。</span>

## 1 画像的输入：从行为到特征

用户画像的原料是**行为数据**——用户留下的每一个痕迹都是画像的线索：

| 行为 | 画像信号 | 强度 |
| --- | --- | --- |
| 搜索历史 | 主题偏好、术语水平 | 强（直接表达需求） |
| 点击记录 | 点击哪些文档/类目 | 强（隐式反馈） |
| 浏览/停留 | 停留时长、滚动深度 | 中（兴趣强度） |
| 收藏/分享/购买 | 显式偏好 | 强（明确信号） |
| 设备/地域/语言 | 静态属性 | 中（上下文） |

**重点：画像的本质是"把行为翻译成可计算的用户特征"。** 每个行为是一条证据，画像把证据聚合成"用户喜欢什么、现在要什么"——**行为是原材料，画像是提炼品**。<span class="marginnote">画像的特征表示有两种风格：<strong>显式特征（可解释）</strong>——用户兴趣的主题分布、点击的类目权重、常用术语；<strong>隐式表示（向量）</strong>——用户行为的嵌入向量（把用户历史行为映射成用户向量）。显式特征可解释、可调试，但手工设计；隐式向量表达力强、可端到端，但黑盒。工业上两者并用：显式特征做可解释的个性化规则，隐式向量做端到端的个性化排序。</span>

## 2 长期画像：稳定兴趣的累积

**核心概念：长期画像（long-term profile）**：捕捉用户**稳定的**兴趣偏好，由长期行为累积而成，随时间缓慢演化。

长期画像的关键设计：

**主题聚合**：把点击/浏览的文档聚合成"兴趣主题"（如"机器学习"、"美食"），每个主题带权重。
**时间衰减**：旧行为的权重随时间衰减——**3 个月前的点击比 3 天前的可信度低**（用户兴趣会漂移）。
**遗忘机制**：长期不访问的主题权重持续下降——**画像要"忘掉"过时的兴趣**，否则画像固化、个性化僵化。<span class="marginnote">时间衰减的经典形式是"指数衰减"：<strong>行为权重 $\propto e^{-\lambda t}$，$\lambda$ 控制遗忘速度</strong>。$\lambda$ 大 = 忘得快（画像敏捷，但可能丢了稳定兴趣）；$\lambda$ 小 = 忘得慢（画像稳定，但可能固化）。长期画像的"衰减率"是它的核心旋钮——它决定画像"多善变"与"多顽固"的平衡。这个"记忆 vs 遗忘"的建模，与人的记忆规律（遗忘曲线）异曲同工。</span>

**辨析｜易错点：长期画像不是"历史行为的简单平均"。** 平均会抹平演化——一个 3 年前爱看动画、现在只看纪录片的人，平均画像会把两样都保留，反而都抓不准。**正确做法是"时间加权"（新行为权重大）+ "主题分离"（不同兴趣分开建模）**——画像要反映"现在喜欢什么"，不是"平均喜欢过什么"。

## 3 短期画像：当前会话的意图

**核心概念：短期画像（short-term profile）**：捕捉用户**当前会话**的具体意图，由本次会话的行为构成，会话结束即过期。

短期画像的独特性：

**时间窗短**：只看本次会话（几分钟到几十分钟）——搜了什么、点了什么、停留多久。
**目标明确**：会话通常围绕一个具体任务（买手机、查资料）——短期画像要抓住"这个任务是什么"。
**信号密集但噪声大**：会话内行为连贯性强，但也可能误触、跳转——**短期画像要在噪声中提取"当前目标"**。

**重点：长期画像回答"这个用户是谁"，短期画像回答"这个用户此刻在干什么"——两者协同，才是个性化的完整输入。** 长期告诉你偏好方向，短期告诉你当前任务——**排序时要同时用：长期信号定"大方向"，短期信号定"即时命中"**。<span class="marginnote">一个具体例子：用户长期爱看科技新闻（长期画像：科技主题），此刻搜索 "RTX 4090 对比"（短期画像：在比较显卡）——排序时，长期画像把科技类显卡测评排前，短期画像把"显卡对比、购买"内容排前。<strong>两者的加权（长期多少、短期多少）是画像协同的核心调参</strong>——新闻类查询短期权重高（当下需求强），通用类查询长期权重高（稳定偏好更重要）。</span>

## 4 公式解析：画像的更新机制

画像不是静态文件，而是随每个行为持续更新的动态结构。设主题 $c$ 的画像权重为 $w_c$，新行为（点击了一篇主题为 $c$ 的文档）到来时，更新为：

$$w_c \leftarrow w_c \cdot e^{-\lambda \Delta t} + \alpha$$

其中 $e^{-\lambda \Delta t}$ 是时间衰减（$\Delta t$ 是距上次更新的时间），$\alpha$ 是本次行为的增量。

三步拆解：

- **第一步，读衰减项**：$w_c \cdot e^{-\lambda \Delta t}$——旧权重随时间指数衰减。**时间过去越久，旧兴趣越弱**。
- **第二步，读增量项**：$+\alpha$——新行为给主题加分。**新行为越强（停留久、点击深），$\alpha$ 越大**。
- **第三步，看平衡**：更新 = "旧兴趣衰减" + "新行为注入"——**衰减率 $\lambda$ 与增量 $\alpha$ 的比值，决定画像是"念旧"还是"迎新"**。

**核心结论：画像是一个"持续衰减 + 增量注入"的动态系统——它的更新规则决定了画像对兴趣变化的响应速度。**<span class="marginnote">这个"衰减 + 注入"的更新机制，与你在《操作系统》学的"老化"（aging）调度、与神经网络里的"指数滑动平均（EMA）"都是同一个数学结构：<strong>$x_t = \gamma x_{t-1} + (1-\gamma) x^{\text{new}}$</strong>。理解了这个通用结构，你就同时理解了画像更新、滑动平均、以及无数"随时间演化的加权"系统的运作方式——一个公式，多个领域。</span>

## 5 画像的现代形态：向量画像与隐私边界

用户画像随深度学习演进了形态：

**向量画像（user embedding）**：把用户的历史行为（点击的文档向量）聚合成"用户向量"——与文档向量在同一空间，直接用余弦做个性化匹配。**向量画像与双塔检索天然契合**（用户向量 = 查询的个性化修正）。
**行为序列模型**：把用户的行为序列（点击流）喂给序列模型（RNN/Transformer），预测"下一个行为"——**画像从"静态快照"变成"动态预测"**。
**隐私边界**：画像依赖用户数据，触碰隐私红线——**欧盟 GDPR、中国个保法对用户画像的使用有严格限制**（告知、授权、可删除）。画像工程必须把"数据最小化"与"匿名化"内建到设计里。<span class="marginnote">画像的隐私问题是个性化最大的伦理约束：<strong>越精细的画像 = 越精确的个性化 = 越敏感的数据使用</strong>。工业上的平衡做法：本地画像（数据留在设备端，如 Apple 的 on-device personalization）、联邦画像（模型在端上训练，只传梯度不传数据）、差分隐私（在数据里加噪声保护个体）。<strong>画像工程的未来，是在"个性化质量"与"隐私保护"之间找新的平衡点</strong>。</span>

**辨析｜易错点：画像 ≠ 用户本人，画像是"模型"。** 画像是行为数据的统计推断，必然有噪声与偏差——**画像可能错、可能过时、可能被误用**。把画像当成"用户的真实画像"（而非"模型的近似"），会放大个性化错误与伦理风险。**工程与伦理上都要记得：画像是工具，不是结论。**

## 6 小结

- **用户画像**：把"用户是谁、喜欢什么、此刻要什么"建模成可计算形式——个性化的地基。
- **画像输入**：搜索历史、点击、浏览、收藏、静态属性——行为是原料，画像是提炼品。
- **长期画像**：稳定兴趣 + 时间衰减 + 遗忘机制——回答"用户是谁"，慢演化。
- **短期画像**：会话意图 + 时间窗 + 噪声提取——回答"用户此刻要什么"，会话级时效。
- **更新机制**：$w \leftarrow w e^{-\lambda\Delta t} + \alpha$——衰减 + 注入的动态系统，与 EMA 同构。
- **现代形态与边界**：向量画像、行为序列模型；隐私（GDPR/个保法）是硬约束。
