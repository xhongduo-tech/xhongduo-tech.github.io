## 为什么从"概率"开始

前四篇我们把检索建成了"几何"——TF-IDF 向量 + 余弦相似度，相关性是空间里的夹角。这套框架直观、可算、有效，但它有一个没有回答的根本问题：**为什么"夹角小"就意味着"相关"？** 余弦相似度是工程师的直觉，不是理论家的论证——它没有说明"相关"到底是什么。

**概率检索（probabilistic retrieval）** 从另一个起点出发：**相关是一个不确定性事件**。给定查询 $q$ 与文档 $d$，我们无法确定 $d$ 是否相关，但可以估计"$d$ 相关的概率"。**排序就是按这个概率降序排列**——把最可能相关的文档排最前。这个听起来像废话的原则，一旦被数学地表述出来，就获得了惊人的推导力：它能从"概率"这个出发点，一步步推出具体的排序函数（BM25 就是它的嫡传）。<span class="marginnote">概率检索的理论根基是 <strong>Robertson 与 Spärck Jones 1976 年的论文</strong>，他们把"排序按相关概率"这个直觉正式化，称为<strong>概率排序原理（Probability Ranking Principle，PRP）</strong>。它的思想源头可以追溯到信息检索理论家 William Cooper 的"排序逻辑"——但把它变成可推导的数学框架，是 1976 年那篇论文的贡献。</span>

## 1 一个精确的表述

**核心概念：概率排序原理（PRP）**：给定查询 $q$，若每篇文档都有"相关"概率 $P(R=1 \mid d, q)$，则**按该概率降序排列文档**是"最优"的排序——它使检索的整体效用（如期望的相关文档数）最大化。

形式化地，检索系统输出排序后的文档序列 $d_1, d_2, \dots, d_n$，PRP 要求：

$$P(R=1 \mid d_1, q) \ge P(R=1 \mid d_2, q) \ge \cdots$$

**重点：PRP 把"排序"归结为"估计相关概率"。** 它不规定概率怎么算（那是 BIM、BM25 的事），只规定**排序规则**——一旦你有了概率估计，最优排序就是按它降序。**PRP 是"目标"，概率模型是"实现"**。<span class="marginnote">PRP 的"最优"需要一些假设：文档的相关性是<strong>独立的</strong>（一篇文档相关不影响另一篇），且返回给用户的文档序列是<strong>线性浏览</strong>的。当这些假设被打破（比如结果间的冗余、多样性需求），PRP 就不是严格最优——这催生了"最大化边际相关（MMR）"等修正，见推荐系统与多样性检索的文献。</span>

## 2 为什么按概率排序是最优的

PRP 的"最优"不是一句口号，它可以被严格论证。设想两种排序：按概率降序（$P_1 \ge P_2 \ge \cdots$）与某种乱序。**直觉论证**是：用户从前往后看结果，越靠前的文档被看到的概率越高。把最可能相关的文档放在最容易被看到的位置，期望上看到的"相关文档数"就最多。

**期望论证**：设用户看前 $k$ 篇文档，期望的相关文档数是 $\sum_{i=1}^{k} P_i$。若第 $i$ 篇的概率 $P_i$ 小于第 $j$ 篇的 $P_j$（$i < j$），把它们对调，前 $k$ 篇的期望和增加 $P_j - P_i > 0$。**只要存在"高概率文档排在低概率文档后面"，交换它们就能提升期望——所以最优排序必是概率降序。**<span class="marginnote">这个论证在经济学里叫<strong>交换论证（exchange argument）</strong>，在算法设计里也极常用：证明某个顺序最优，只需证明"任何违反该顺序的相邻对交换后不变差"。它与你在《算法设计与分析》里证明贪心算法最优用的手法完全一致。</span>

**辨析｜易错点：PRP 最优是"期望意义"上的，不是"每次都对"。** 概率高不保证"这次相关"，只保证"长期来看，按此排序看到的期望相关文档最多"。**别把"最优排序"误解为"每次都能把相关文档排前面"——不确定性下没有这种保证，只有期望最优。**

## 3 从 PRP 到排序分数：把概率换成可算的量

PRP 给出目标，但 $P(R=1 \mid d, q)$ 怎么算？直接估计这个条件概率几乎不可能——文档空间太大。检索文献的经典技巧是**贝叶斯变换**：比较"相关"与"不相关"两个假设的概率之比。

设 $R=1$ 表示相关，$R=0$ 表示不相关。排序可以按**比值** $P(R=1 \mid d, q) / P(R=0 \mid d, q)$ 降序——这个比值与 $P(R=1)$ 单调同序（比值大 ⇔ 概率大），但更好算。用贝叶斯定理展开：

$$\frac{P(R=1 \mid d, q)}{P(R=0 \mid d, q)} = \frac{P(d \mid R=1, q) \cdot P(R=1 \mid q)}{P(d \mid R=0, q) \cdot P(R=0 \mid q)}$$

右边的 $P(R=1 \mid q) / P(R=0 \mid q)$ 对同一查询是常数，不影响排序，于是**核心变成"相关文档的似然 / 不相关文档的似然"**——这也就是"似然比（likelihood ratio）"排序的由来。<span class="marginnote">这个变换是概率检索的灵魂：<strong>把"估计条件概率"（难）变成"比较两个生成模型的似然"（可行）</strong>。相关文档可以用"相关文档长什么样"的模型 $P(d \mid R=1)$ 描述，不相关文档用文集整体模型 $P(d \mid R=0)$ 描述——下一节《二元独立模型》就把这两个模型具体化。</span>

## 4 公式解析：为什么比值比概率好算

把"为什么用比值"算到数字层面。设某查询有两篇文档 $d_1, d_2$，且：

$$P(R=1 \mid d_1, q) = 0.2, \quad P(R=1 \mid d_2, q) = 0.1$$

直接排序：$d_1$ 在前。再看比值（假设 $P(R=0 \mid d_i) = 1 - P(R=1 \mid d_i)$）：

$$\frac{P(R=1 \mid d_1)}{P(R=0 \mid d_1)} = \frac{0.2}{0.8} = 0.25, \qquad \frac{P(R=1 \mid d_2)}{P(R=0 \mid d_2)} = \frac{0.1}{0.9} = 0.111$$

三步拆解：

- **第一步，看单调性**：$0.25 > 0.111$，比值排序与概率排序一致——因为 $f(p) = p/(1-p)$ 是单调递增函数。
- **第二步，看为什么用比值**：$P(d \mid R=1)$ 与 $P(d \mid R=0)$ 可以**分别建模**（相关文档生成模型 vs 文集整体模型），而 $P(R=1 \mid d)$ 必须联合建模——**比值把联合问题拆成了两个独立问题**。
- **第三步，看对数化**：工程上常取 $\log$，把"比值乘积"变成"对数之和"，数值更稳、可解释性更好——BM25 的输出本质就是**对数似然比**的近似。

**核心结论：PRP 的正确实现路径是"建模似然比，而非直接估计后验"。** 这个"把联合估计拆成两个独立模型"的技巧，让概率检索从理论变成可计算的方法。<span class="marginnote">这个技巧你在机器学习里也常见：<strong>生成式模型 $P(x \mid y)$ 与判别式模型 $P(y \mid x)$ 之争</strong>。概率检索选择了生成式路径——分别建"相关文档长什么样"与"不相关文档长什么样"，再比较。下一篇的 BIM 与再下一篇的 BM25，都是这个选择的落地。</span>

## 5 PRP 的局限与现代意义

PRP 是理论基石，但不是圣旨，看清它的局限反而能更准确地用它：

**相关独立性假设**：假设文档间相关独立，忽略"结果冗余"——前两篇都讲同一件事时，第二条结果对用户价值骤降，但 PRP 不惩罚。**多样性（diversification）与 PRP 相抵触**，现代搜索用 MMR、MMR 变体或学习排序来补。
**概率估计的偏差**：PRP 只承诺"按真概率排序最优"，不承诺"你的概率估计准"——若 $P(R=1\mid d,q)$ 估得差，最优排序也救不回来。**PRP 是天花板，估计质量决定你离天花板多远。**<span class="marginnote">这解释了一个重要现象：<strong>现代学习排序（Learning to Rank）并没有推翻 PRP，而是把"估计 $P(R=1 \mid d, q)$"这件难事交给了机器学习</strong>。LambdaMART 等模型的输出，可以被理解为"对相关概率的更优估计"。PRP 的目标层与学习排序的实现层，是一体的。</span>

**重点：PRP 的现代意义是"目标函数"而非"算法"。** 它告诉你"按相关概率排"是最优目标；至于概率怎么估——古典用统计模型（BIM/BM25），现代用机器学习——是实现细节。**理解了 PRP，你就理解了为什么检索系统的一切努力（从 TF-IDF 到神经网络）都可以看成"更准地估计相关概率"。**

## 6 数值算例：交换论证现场演示

把"按概率降序最优"从定理变成算术。设查询 $q$ 有四篇文档，相关概率分别为 $P = (0.9, 0.7, 0.3, 0.1)$，已经按降序排好。假设用户只浏览前 2 篇，期望的相关文档数是：

$$E = 0.9 + 0.7 = 1.6$$

现在故意违反降序：把第 2、3 篇对调，变成 $(0.9, 0.3, 0.7, 0.1)$，前 2 篇的期望变成：

$$E' = 0.9 + 0.3 = 1.2$$

三步读这个例子：

- **看期望的下降**：一次违反降序的相邻交换，期望相关文档数从 1.6 降到 1.2——**排序越乱，期望损失越大**。
- **看损失的量**：交换 0.7 与 0.3 损失 $0.7 - 0.3 = 0.4$——**恰好等于被降级文档的概率差**。这就是上一节"对调增加 $P_j - P_i$"的数值版。
- **看一般化**：无论用户看前 $k$ 篇（$k$ 取任何值），只要存在"高概率在低概率后面"，交换都不变差。**降序是唯一让"任何前缀期望"都最大的排序**——这是 PRP 的完整论证。

这里有个值得强调的直觉：**PRP 关心的是"前缀期望"，不是"单篇是否相关"**。单篇概率 0.7 的文档可能这次不相关，但把它排在 0.3 前面，长期看一定更优。**排序优化的对象是"分布"，不是"这一次的运气"**——这一点贯穿所有概率检索模型，也解释了为什么检索评测用"平均指标"（MAP、NDCG）而不是"单次命中"。

**辨析｜易错点：PRP 不是"概率越大越相关的断言"，而是"按概率排序最优的定理"。** 它不告诉你 $P(R=1\mid d,q)$ 的真实值是多少，只承诺"一旦估对了，降序就是最优"。**把 PRP 误读成"相关概率的定义"是常见错误——它是排序规则，不是概率模型。**

## 8 小结

- **PRP**：按 $P(R=1 \mid d, q)$ 降序排列是最优排序——排序问题归结为概率估计问题。
- **最优性论证**：交换论证——任何违反降序的相邻对交换后期望相关文档数不降。
- **从后验到似然比**：$P(R=1|d,q)/P(R=0|d,q)$ 与概率同序，且可拆成两个独立的生成模型。
- **对数似然比**是工程上的标准形态，BM25 是它的著名近似。
- **局限**：相关独立性假设与多样性相抵触；PRP 是最优目标，估计质量决定实现高度。

在下一节，我们把"相关文档生成模型"具体化为一个可计算的假设——文档只是一袋子词，每个词独立地出现或不出现在相关文档里，这就是**二元独立模型（BIM）**。
