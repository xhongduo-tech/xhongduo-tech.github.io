## 为什么从细胞类型鉴定与聚类开始

数据管线（上一节）产出的是降维后的细胞云图。现在真正的生物学问题来了：**这片云里有几群细胞？每一群是谁？** 这是 scRNA-seq 最日常、也最容易翻车的环节——因为「分组」与「命名」是两件不同的事，而几乎所有错误都源于把两件事混为一谈。**聚类（clustering）** 用无监督学习找出「自然分群」，**注释（annotation）** 用生物学知识给每个群贴上「细胞类型」标签。本节讲清这两步各自的数学工具与陷阱，并给出从「簇」到「类型」的可靠路径。

## 1 图聚类：为什么不用 k-means

早期 scRNA-seq 用过 k-means，但很快被**基于图的聚类**取代。流程是：在 PCA 空间构建**K 近邻图（KNN graph）**——每个细胞是一个节点，与它最近的 K 个细胞连边；然后做 **Louvain / Leiden** 社区发现算法，把「抱团紧密」的节点划成同一簇。

为什么图聚类胜出？

- **不需要预设簇数**：Leiden 自动决定分几群，而 k-means 要手选 $k$；
- **对密度不均鲁棒**：真实数据里稀有亚群密度低、大亚群密度高，图结构比欧氏距离更擅长分辨「团块」；
- **计算可扩展**：图是稀疏的，能处理数十万细胞。

标准流程可以拆成五步：

- **PCA 降维**：把高维表达压缩成前几十个主成分；
- **建 KNN 图**：每个细胞连向最近的 K 个邻居（K 常见 15–30）；
- **Leiden 社区发现**：在图上迭代优化模块度，产出簇；
- **调分辨率**：用分辨率旋钮控制簇的粗细；
- **人工复核**：回看 UMAP 与 marker 表达，确认每簇可解释。

**核心要点：** Leiden 比 Louvain 更可靠。Louvain 可能出现「不连通社区」（把一个簇切碎后保证不了质量），Leiden 通过保证所有社区内部连通来修正这一点——它已是当前（Seurat、Scanpy）的默认选项。

## 2 公式解析：模块度 Q——聚得「好不好」的度量

Louvain/Leiden 优化的目标函数是**模块度（modularity）**：衡量「组内边密度比随机期望高出多少」。

$$
Q = \frac{1}{2m}\sum_{i,j}\left[A_{ij} - \frac{k_i k_j}{2m}\right]\delta(c_i, c_j)
$$

- **第一步，看符号**：$A_{ij}=1$ 表示节点 $i,j$ 之间有边；$k_i$ 是节点 $i$ 的度；$m$ 是总边数；$\delta(c_i,c_j)=1$ 当且仅当 $i,j$ 在同一簇。
- **第二步，读直觉**：$\dfrac{k_i k_j}{2m}$ 是「如果边随机连接，$i,j$ 之间期望的边数」。若实际边数 $A_{ij}$ 超过随机期望、且两者同簇，就为 $Q$ 贡献正值——**簇内的边比随机多，聚得就好**。
- **第三步，理解算法**：Louvain/Leiden 就是贪心调整簇分配使 $Q$ 上升，直到收敛。$Q$ 介于 -1 到 1，经验上 $Q>0.3$ 就说明有明显社区结构。<span class="marginnote">模块度是全课程里「图与网络」思想的又一次登场：从社交网络的社区检测到蛋白质互作网络，$Q$ 都是同一套语言。第 3 级《图论》里的社区发现，与这里的细胞聚类共享数学内核。</span>

套一个微型数字：若某个小区有 4 个细胞、彼此之间共 4 条边，把「两两同类」的细胞分成两簇，比较「实际组内边数」与「按度随机连边时的期望组内边数」，就能算出 $Q$ 的正负。直觉是：**组内边越多、组间边越少，$Q$ 越高；当簇分配与随机无异时 $Q \approx 0$**——聚类的全部算法努力，就是在把这一项推向正方向。

## 3 从簇到细胞类型：注释的三种武器

聚类给的是「数字编号 0、1、2……」，注释把它翻译成人话。三种主流策略：

**Marker 驱动（经典法）**：找出每个簇的**差异表达基因**（与其它簇比、显著上调的基因），对照已知 marker 列表判型。例如 CD3D/CD3E → T 细胞，CD79A → B 细胞，LYZ/FCGR3A → 髓系细胞。<span class="marginnote">Marker 判型的经典陷阱：单 marker 会误判。CD8 也可能是 NK 细胞、CD14 可能被环境 RNA 稀释——所以金标准是「多个 marker 联合表决」，并回到原始数据可视化确认（violin/UMAP 图上逐 marker 核对）。</span>

常用 lineage marker 一览：

| 细胞类型 | 典型 marker | 常见误判 |
| --- | --- | --- |
| T 细胞 | CD3D、CD3E | CD8 也可能是 NK 细胞 |
| B 细胞 | CD79A、MS4A1 | 浆细胞 CD79A 表达降低 |
| 髓系（单核/巨噬） | LYZ、FCGR3A | CD14 易被环境 RNA 稀释 |
| NK 细胞 | NKG7、KLRD1 | 与 T 细胞部分重叠 |
| 红细胞 | HBA1、HBB | 微滴污染常混入
- **参考映射（reference-based）**：把未知数据投到已注释的参考图谱上，用分类器（如 scmap、SingleR、Azimuth）给每个细胞打分。适合已有高质量参考的领域（血液、免疫），能统一命名体系。
- **整合 + 人工复核**：把数据整合进大图谱、按层次注释，再人工抽查。对稀有种群和过渡态，这一步不可省。

落到实操，注释可以按四步走：

- **先粗后细**：先用 marker 把大谱系分开，再对每个大群细拆亚型；
- **多 marker 联合**：用「且 / 或」逻辑组合，避免单基因误判；
- **参考库交叉**：把结果与已知参考图谱比对，统一命名体系；
- **人工抽检**：回到 UMAP/violin 逐簇核对，是最后一道保险。

**辨析｜易错点：** **聚类 ≠ 注释**。聚类回答「结构」，注释回答「身份」。同一群细胞可以对应多种标记性状态（如 T 细胞 vs Treg），同一细胞类型在不同批次里可能被聚成两簇。把「簇编号」直接当「细胞类型」写进论文，是初学者最常见的硬伤。

## 4 评估聚类质量：不只是「看起来对」

如何知道聚类结果「好」？分两个层面：

- **无标签内部度量**：轮廓系数、DB 指数衡量「簇内紧凑、簇间分离」。但它们对单细胞的稀疏高维数据不太敏感，只能做粗筛。
- **有标签外部度量**：用**调整兰德指数（ARI）** 比较聚类结果与已知注释的一致性。

$$
\text{ARI} = \frac{\text{一致对数} - \text{随机期望对数}}{\text{最大值} - \text{随机期望对数}}, \qquad \text{ARI} \in [-1, 1]
$$

**核心要点：** ARI 减去随机期望、再归一化，所以「随机乱分」的 ARI 约为 0，完美一致为 1，负值说明比随机还差。它同时惩罚「切碎真实簇」与「合并不同簇」，是评价聚类注释一致性的标准指标。<span class="marginnote">ARI 的构造逻辑——「观测一致性减去随机基线，再归一化」——与 Kappa 系数、F1 中的机会校正同出一源。学透一个，其余自通。</span>

套个数字：若「已知注释里的同类对」与「聚类结果里的同类对」完全重合，ARI = 1；若聚类只是随机打散，期望一致对数恰好等于随机水平，ARI ≈ 0。实践惯例是 **ARI > 0.7 视为与注释高度一致，0.3–0.7 为中等，低于 0.3 就要重新审视聚类参数**。补充一句：对单细胞这类高维稀疏数据，内部度量（轮廓系数）只能做粗筛，真正可信的评估仍依赖外部注释——因为「分得好不好」终究是生物学问题。

## 5 分辨率：一个旋钮，一套哲学

Seurat/Scanpy 里都有一个**分辨率（resolution）**参数：调大 → 分出更多更细的簇，调小 → 合并成更大更粗的簇。这本质上是「多粗才算细胞类型」的判断。

**辨析｜易错点：** 分辨率没有「正确值」。同一份数据，分辨率 0.1 给 5 群、0.8 给 30 群，都可能「合理」——区别在于你要讲什么故事。判断标准是**生物学可解释性**：每个簇是否有独立的 marker、是否能被参考库或实验验证、是否有稳定的功能注释。盲目追求「细」会造出「每一簇都是噪声」的假亚群。

分辨率取值没有普适「标准」，但经验区间可以参考：

- **0.1–0.3**：偏粗，适合找主要谱系（如 T / B / 髓系大群）；
- **0.5–0.8**：中等，适合亚型拆分（如 CD4/CD8、各亚群）；
- **1.0 以上**：偏细，适合稀有亚群，但需逐一验证是否「假亚群」；
- 判断真假的终极标准只有一个：**每个簇能否被独立 marker、参考库或实验解释**。

## 6 术语速查表

| 术语 | 一句话定义 | 易混淆点 |
| --- | --- | --- |
| KNN 图 | 每个细胞连向最近 K 个邻居的图 | K 太小切碎、太大糊在一起 |
| Louvain / Leiden | 图社区发现算法 | Leiden 保证社区内部连通，更稳 |
| 模块度 Q | 簇内边比随机期望多多少 | Q>0.3 说明有明显结构 |
| marker 基因 | 特异标记某类细胞的基因 | 单 marker 判型易误判 |
| 参考映射 | 把未知数据投到已注释图谱打分 | 依赖参考库质量 |
| ARI | 聚类 vs 已知注释的一致性 | 随机分约等于 0 |
| 分辨率 | 控制簇粗细的旋钮 | 判据是生物学可解释性 |

把这张表放在手边，聚类 → 注释 → 评估 → 调参的每一步，都能查到对应的工具与陷阱。

## 7 小结

- 聚类与注释是两步：**无监督找结构 + 生物学命名**，不可混淆。
- 图聚类（KNN 图 + **Leiden**）是当前标准，它优化**模块度 Q**——簇内边比随机期望多多少。
- 注释三武器：**marker 驱动、参考映射、整合 + 人工复核**。
- **ARI** 评价「聚类 vs 已知注释」的一致性，随机分约等于 0。
- **分辨率**是聚类哲学旋钮，判据是生物学可解释性而非数字。
