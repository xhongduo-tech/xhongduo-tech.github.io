## 为什么从单细胞表观组学开始

序列相同的细胞，命运可以完全不同。同一个受精卵分化出的神经元与肝细胞携带几乎相同的 DNA，区别全在「哪些基因被打开、哪些被锁死」——这就是**表观遗传（epigenetics）**：不改变 DNA 序列、却改变基因表达的稳定修饰。三类最核心的表观信息是：**DNA 甲基化**（胞嘧啶上加甲基，通常抑制转录）、**组蛋白修饰**（染色质包装状态的开关）与**染色质可及性**（chromatin accessibility，DNA 是否「裸露」可被蛋白质结合）。单细胞表观组学把这些「调控层」从平均值拆到单个细胞，回答 scRNA-seq 无法回答的问题：**为什么这些细胞会变成现在这个样子？** 它与转录组共同构成「调控 → 输出」的完整链条，也为我们后面做多组学整合（第 11 篇）埋下伏笔。

## 1 染色质可及性：DNA 的「开与关」

基因组 DNA 缠绕在组蛋白上形成**染色质**，被包装得紧的区域（异染色质）无法被转录因子接触，是「关」；包装松弛的区域（常染色质中的启动子、增强子等调控元件）裸露出 DNA，是「开」。**可及性（accessibility）** 就是这种「开」的程度。

**scATAC-seq（单细胞转座酶可及性染色质测序）** 利用高活性转座酶 Tn5 的偏好：Tn5 会**优先插入开放（可及）的染色质区域**，同时把插入片段两端切下并接上测序接头。于是：

- 可及区域 → 有转座酶插入 → 产生读段 → 测序能看到；
- 封闭区域 → 无插入 → 沉默。

测序后，把读段堆叠到基因组上，那些**读段富集的峰（peak）**就是「开放染色质」的地图——启动子、增强子、CTCF 结合位点等调控元件。每个细胞的 peak 地图，就是它当前「允许哪些基因被调控」的快照。<span class="marginnote">「ATAC」里最动人的细节：Tn5 兼作「切割者」与「接头贴标机」，一次反应同时完成片段化与文库标记。这种「一步到位」的工程设计，让单细胞 ATAC 从可能变成现实。</span>

一个 ATAC 的数字感受：一个开放染色质位点通常能捕获几十到几百个转座酶插入读段，而封闭区域几乎没有；典型的单细胞 ATAC 数据中，每个细胞可检测到数千到数万个可及峰，其中启动子与增强子是最密集的两类。峰的数量本身就是细胞状态的粗略指纹——「开放得越多，越活跃」。

**辨析｜易错点：** 可及性 ≠ 表达。一个基因的启动子是开放的，说明它「被允许表达」，但不代表此刻正在表达——它还差转录因子与共激活因子那一步。可及性是「可能性」，mRNA 是「现实」，两者之间的差，正是细胞命运可以「未定」的原因。

ATAC 与甲基化看的是染色质的两个侧面：可及性反映「物理上能不能被接触」，甲基化反映「化学上被标记成什么」。两者在启动子区域通常负相关——甲基化高则转录因子难结合、可及性低。把它们放在同一细胞上测（如 scNMT-seq 或 ATAC + 甲基化联合方案），就能同时看到「结构状态」与「化学标记」两层信息。

为什么「开放」如此重要？因为转录因子要先能结合 DNA，才能招募转录机器。染色质可及性相当于「先遣部队的探路」——它不决定最终谁转录，但决定了哪些位置「有机会」被转录。这也是为什么可及性图谱常被当作「调控潜力」的代理。

## 2 单细胞甲基化：测的是「化学修饰」

**DNA 甲基化**指 DNA 甲基转移酶把甲基（$-\ce{CH3}$）加到胞嘧啶（C）的 5' 位，形成 5-甲基胞嘧啶（5mC），主要发生在 CpG 二核苷酸上。启动子区 CpG 高度甲基化通常沉默基因。单细胞测量方法以 **scBS-seq（单细胞重亚硫酸盐测序）** 为代表：用**重亚硫酸盐（bisulfite）**处理 DNA，未甲基化的 C 会脱氨变成 U（测序时读成 T），而甲基化的 C 保持 C 不变——于是「读成 C 还是 T」就直接编码了「是否甲基化」。

**核心要点：** 甲基化数据的单位不是峰，而是位点：每个 CpG 位点是一个二分类状态（甲基化/未甲基化）。单个细胞的覆盖极稀疏——一个细胞通常只覆盖到全部 CpG 中很小一部分，这是单细胞甲基化数据「天生残缺」的根源，也让它的统计建模比 ATAC 更困难。

| 技术 | 原理 | 单细胞适用性 |
| --- | --- | --- |
| scBS-seq | 重亚硫酸盐 + 全基因组 | 覆盖稀疏、需深测 |
| scRRBS | 富集 CpG 岛区域 | 覆盖集中、较浅 |
| scCGI-seq | 甲基化 CpG 岛测序 | 高效率、低覆盖 |

甲基化还有一个独特的功能视角：它常常是**稳定的**——一旦建立，可以在细胞分裂中继承。这让甲基化成为「细胞历史」的记录器：同一个细胞群里的甲基化差异，可能记录了它们过去走过的命运岔路，而不仅仅是当下的状态。这一特性让甲基化在谱系推断中有不可替代的位置。

## 3 公式解析：甲基化水平 β 值

甲基化水平最常用的定量指标是 **β 值（beta value）**：某个位点上甲基化分子数占全部分子数的比例。

$$
\beta = \frac{C_m}{C_m + C_u}, \qquad \beta \in [0, 1]
$$

- **第一步，看符号**：$C_m$ 是测得为「甲基化」（读成 C）的分子数，$C_u$ 是「未甲基化」（读成 T）的分子数。$\beta$ 是 0 到 1 之间的连续量：1 表示完全甲基化，0 表示完全未甲基化。
- **第二步，读懂直觉**：同一组织里的细胞，某个 CpG 位点的 $\beta$ 若在 0.2 与 0.8 之间摆动，说明它呈现**细胞间异质性**——一部分细胞开了甲基、另一部分没开。这正是单细胞甲基化能看到、bulk 只能看到平均值 0.5 的地方。<span class="marginnote">β 值本质上是一个伯努利成功率的估计：把每个分子看作一次伯努利试验。当覆盖分子数很少（比如只有 3 个）时，β 只能取 0、1/3、2/3、1——离散且噪声巨大，这提醒我们统计功效的真实瓶颈是覆盖度而非算法。</span>

套数字看覆盖度的重要性：若某 CpG 位点只被 3 个分子覆盖，β 只能取 0、1/3、2/3、1 四个离散值，置信区间巨大；被 30 个分子覆盖时，β 才有接近连续的分辨率。**单细胞甲基化的「稀疏」，本质是每个位点可用分子数太少**——这也是为什么单细胞甲基化统计比 ATAC 更难：ATAC 一个区域有多个插入位点可聚合，甲基化一个位点只有两条染色单体、几份分子。

另一个常被问的问题：为什么不用「甲基化 / 未甲基化」的计数，而用 β？因为不同细胞、不同位点的覆盖度差异巨大，直接用计数会把「测得多」误当成「甲基化程度高」。β 是「比例」，天然消除了覆盖度差异——前提是覆盖度不能太低。
**第三步，注意与 ATAC 的统一视角**：把 β 值按基因组区间聚合，与 ATAC 的峰信号并置，就能看到「甲基化降低 ⇔ 可及性上升」的经典负相关——调控层与结构层在同一条染色质上协同动作。

## 4 从单细胞表观到调控程序推断

单细胞表观数据最终要回答：**哪些调控元件组合（cis-regulatory programs）在驱动这群细胞？**

分析管线大致是：质控（剔除低片段数细胞）→ 峰聚合 → 每细胞 × 峰的二值/计数矩阵 → 降维聚类 → 找「差异可及区域（differentially accessible regions）」→ 用 motif 富集推断驱动这些区域的转录因子。于是你能得到类似「这群细胞启动了增强子 X，而增强子 X 富含转录因子 Y 的结合基序」的结论。

**辨析｜易错点：** motif 富集 ≠ 转录因子已结合。motif 只是「潜在的结合位点序列」，是否真的结合还取决于转录因子是否表达、染色质状态是否允许。严谨的表述是「该区域的序列支持 Y 的潜在结合」，而不是「Y 正在这里调控基因」。

分析管线里最核心的一步是「差异可及区域」的解读。找到一群差异区域后，标准动作是**基序富集（motif enrichment）**：把差异区域与转录因子结合基序数据库比对，统计哪些基序显著富集。一个典型结果可能是「这组区域显著富集 NF-κB 结合基序」，提示这群细胞正被 NF-κB 通路驱动——**把「哪里开放」翻译成「谁在调控」**，是表观分析相对转录组的独有价值。

**术语速查：**
- **可及性（accessibility）**：DNA 被蛋白质可接触的程度；
- **peak**：读段富集的开放染色质区域；
- **β 值**：某 CpG 位点甲基化分子占全部分子的比例；
- **motif**：转录因子的结合序列基序；
- **5mC**：5-甲基胞嘧啶。

调控程序推断的终点往往是「图谱级」的：把许多细胞的可及性图谱整合，识别「共变的调控元件模块」，再与转录组的细胞类型注释对照。若一个模块的元件在「这群细胞」里同步开放、且在注释里对应「这群细胞」——这就是「顺式调控程序」最直接的操作化定义。

从可及性还能读出**顺式调控元件间的协同**：当某个增强子与某个启动子在许多细胞里同步打开，它们很可能构成一个「增强子-启动子对」，共同驱动下游基因。这类「共可及性」分析把调控推断从「单基因」推进到「调控模块」，是表观组学相对转录组的独有能力——它揭示的是「谁和谁被编排在一起」，而转录组只能看到编排的结果。

## 5 表观数据的统计特性：稀疏与二元

把 ATAC 与甲基化放在一起，能看到它们共享的统计底色：**稀疏 + 二元**。

- ATAC 的数据是「峰 × 细胞」的二值 / 计数：一个峰在该细胞「有插入」还是「没有」，插入数服从零膨胀分布；
- 甲基化是「位点 × 细胞」的二分类（甲基化 / 未甲基化），覆盖度极低时近乎「大量缺失」。

这决定了单细胞表观的降维与聚类通常不能直接套 scRNA-seq 的假设：泊松 / 负二项模型对「零很多」的 ATAC 计数常常欠拟合，实践常用**二项 / 逻辑斯蒂**或专门的零膨胀模型；而 β 值的离散性让「均值、方差」这类连续统计量失真，需要按覆盖度加权。

**辨析｜易错点：** 把 scRNA-seq 的归一化（CPM + log）直接套到 ATAC 上，会把「二值结构」洗成伪连续分布，制造出不存在的「中间状态」。**先用对的数据分布建模，再谈归一化。**

一个实用的缓解手段是「聚合」：把单细胞表观信号按细胞类型（或按聚类）聚合后，覆盖度大幅提升，β 值 / 峰计数变得稳定——代价是丢失单细胞分辨率。实践中常走「单细胞聚类定位 → 聚合增强解读」的两步路线。

## 6 与转录组的合流：为什么单细胞表观需要配对

单细胞表观数据回答了「允许/不允许」，但它的稀疏性与高噪声让它难以独立支撑细胞命运推断。实践上越来越多地采用**配对（paired）策略**：同一细胞同时测转录组与表观组（如 scNMT-seq 测甲基化 + 转录组，ATAC + RNA 双测），用转录组的丰度给表观的稀疏补上上下文。<span class="marginnote">这也呼应了全课程的一条主线：单一模态是「带残缺的观测」，多模态互补才能逼近完整状态。第 11 篇《多组学单细胞整合》会用数学语言（WNN、MOFA）把这种互补显式建模。</span>

配对分析的输出因此更丰富：既能看到「启动子开放 + 基因高表达」的一致，也能看到「启动子开放但基因沉默」的异步——后者往往是「等待转录因子到位」的蓄势状态。这类「可及但不表达」的细胞，在纯转录组里完全不可见，是单细胞表观独有的信息窗。

而配对的终极形态是「三合一」：同一细胞的转录组 + 表观 + 蛋白（如 CITE-seq + ATAC 的双模态甚至三模态方案）。每多一个模态，对「这个细胞正在发生什么」的置信度就多一分——这也是下一节《多组学单细胞整合》要系统化的方向。

从「从极限到大模型」的视角看，表观组学是「控制流」：基因组是程序，转录组是输出，表观修饰是控制「哪段代码被编译」的开关。把控制流与数据流同时建模，正是多组学整合与「条件生成模型」共享的核心思想。

## 7 小结

- 三类核心表观信息：**DNA 甲基化、组蛋白修饰、染色质可及性**——单细胞版本把它们逐格拆开。
- **scATAC-seq** 用 Tn5 转座酶偏爱开放染色质，测的是「可能性地图」，**不等于表达**。
- **scBS-seq** 用重亚硫酸盐把「是否甲基化」编码成「C 还是 T」，每个位点是二分类。
- **β 值**是甲基化分子比例，覆盖度低时高度离散，统计功效的瓶颈是覆盖度。
- 单细胞表观稀疏又高噪，实践上倾向与转录组**配对测序**，多模态互补。

在下一节，我们将回到转录组，开始把原始计数矩阵变成可分析的对象：**scRNA-seq 数据分析流程**——质控、归一化、批次校正与降维，整条管线的每一步为何如此设计。
