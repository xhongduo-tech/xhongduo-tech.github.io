## 为什么从「表征与正则化」切入

上一节的因果估计说明 MTP「对哪些 token 更重视」；这一节回答「重视之后，模型内部发生了什么」。答案是两个互为表里的机制：**表征学习**——MTP 逼隐藏表示编码长程信息；**隐式正则化**——这个「逼」本身比任何手工正则项都更贴近任务。二者一起解释了为什么 MTP 不只是「更好的损失」，而是「更好的学习」。

## 1 表征学习视角：表示必须「推得出未来」

一个隐藏表示 $h_t$ 承载的信息量是有限的。它往哪分配，取决于损失逼它往哪分配：

- **单 Token**：$h_t$ 只需支撑预测 $x_{t+1}$。于是它优先存储**局部词法**信息——$h_t$ 变成「短程统计的特征向量」。
- **MTP**：$h_t$ 必须同时支撑预测 $x_{t+1}, \dots, x_{t+K}$。它被迫存储**结构、计划、语法骨架**——那些对未来多步都有预测力的信息。

**表征的「未来视野」被拉长了**：$h_t$ 从「只够回答下一句」变成「足以推导出接下来 K 句」的压缩状态。<span class="marginnote">一个恰当的类比是下棋：只看下一步的棋手，表征里装的是「当前局面的局部特征」；看五步的棋手，表征里装的是「局面走向的战略评估」。同一个棋盘，不同的损失，逼出完全不同的表征内容。</span>

**关键推论**：MTP 的表征红利不只服务多步预测任务——因为长程信息对**所有**需要全局理解的推理都通用，所以 MTP 训练的模型在思维链、代码理解上普遍更强。

## 2 隐式正则化：最忠实于任务的约束

「正则化」通常让人想到显式惩罚项（L2、dropout），但 MTP 的约束是**隐式**的：它没有给损失加任何惩罚项，而是通过改变目标函数，把「表征必须可推出未来」写进了优化的隐空间。

**显式正则化**：直接约束参数的复杂度（如 L2），与任务内容无关。
**隐式正则化（MTP）**：约束表征的「预测力」，由任务本身定义——「一个好的 $h_t$ 必须是能推出未来 K 步的表示」。

<strong>辨析｜易错点：</strong>「隐式正则化」不是「正则化力度更大」的代名词。它的特殊性在于**方向**：L2 约束的是「参数别太大」，dropout 约束的是「别过拟合特定路径」，MTP 约束的是「表示要有远期预测力」。**三者可能同时起效，但只有 MTP 的正则化方向与任务目标完全一致**——它不牺牲任务能力去换泛化，而是通过让表示更「深」来同时获得两者。<span class="marginnote">这也是为什么 MTP 的收益表现为「同样数据下泛化更好」，而不是「训练损失更低」——它正则化的是表征内容，不是损失函数本身。</span>

## 3 归纳头的涌现：小模型的质变

Gloeckle 2024 §5 最惊艳的实验证据来自**归纳头（induction head）**。归纳头是 Transformer 内部实现「模式补全」（看见 A B … A 就补 B）的注意力机制，通常被认为是推理能力的组件。

在 ≤3000 万非嵌入参数的小模型上，单 Token 训练**形不成**归纳头。
改用双 Token 预测后，这些模型**涌现出归纳头**，或显著改善——即使模型小到单 Token 学不会。

<span class="marginnote">这个结果极其重要：它说明 MTP 不是「在已有能力上加一点」，而是<strong>在模型容量不足时也能逼出新的机制</strong>。论文的解释与因果估计一致——双 Token 预测给「模式补全」这类跨位置信息传递任务翻了倍的权重，让原本不够强的梯度信号足以支撑归纳头的形成。</span>

**更深一层**：论文还发现，一旦归纳头形成，单 Token 任务也能局部完成——这说明 MTP 先让模型「长出结构能力」，再让短程预测「搭便车」。**MTP 的收益不是长期依赖单 Token 的缺位，而是先建立结构、再让局部任务受益**。

## 4 公式解析：表征的信息约束

把「表示必须推得出未来」写成信息论约束。设 $Z_t$ 是隐藏表示的随机变量，MTP 的训练相当于对 $Z_t$ 施加约束：

$$
I\!\left(Z_t;\, X_{t+1}, \dots, X_{t+K}\right) \;\longrightarrow\; \text{最大化}
$$

- **第一步，认对象**：$I(Z_t; X_{t+1}, \dots, X_{t+K})$ 是隐藏表示与「未来 K 个 token」之间的互信息——表示里关于未来的信息量。
- **第二步，看单 Token 的基线**：单 Token 只最大化 $I(Z_t; X_{t+1})$——表示只保证「与下一步相关」。
- **第三步，看 MTP 的扩展**：MTP 把约束扩展到 K 个未来 token。由于远期 token 的不确定性更大（熵更高），这个约束要求 $Z_t$ 携带**结构性的、跨步的**信息，而非局部词法。
- **第四步，读含义**：约束的对象变了，优化解就变了——$Z_t$ 的**信息分配策略**从「短程优先」转为「长程兼容」。这就是表征学习与隐式正则化共同的数学表述：**MTP 重新定义了「什么是一个好的表示」**。

## 5 小结

- **表征学习**：MTP 逼 $h_t$ 编码「足以推出未来 K 步」的结构信息，拉长表示的「未来视野」。
- **隐式正则化**：约束「表征的远期预测力」，方向与任务完全一致，不同于 L2/dropout 的通用约束。
- **归纳头涌现**：小模型在单 Token 下形不成的机制，双 Token 下能涌现——MTP 先建结构，局部任务再搭便车。
- 信息论表述：MTP 把约束从 $I(Z_t; X_{t+1})$ 扩到 $I(Z_t; X_{t+1}, \dots, X_{t+K})$
