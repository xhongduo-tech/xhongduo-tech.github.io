## 为什么从「表征与正则化」切入

上一节的因果估计说明 MTP「对哪些 token 更重视」；这一节回答「重视之后，模型内部发生了什么」。答案是两个互为表里的机制：**表征学习**——MTP 逼隐藏表示编码长程信息；**隐式正则化**——这个「逼」本身比任何手工正则项都更贴近任务。二者一起解释了为什么 MTP 不只是「更好的损失」，而是「更好的学习」。

## 1 表征学习视角：表示必须「推得出未来」

一个隐藏表示 $h_t$ 承载的信息量是有限的。它往哪分配，取决于损失逼它往哪分配：

- **单 Token**：$h_t$ 只需支撑预测 $x_{t+1}$。于是它优先存储**局部词法**信息——$h_t$ 变成「短程统计的特征向量」。
- **MTP**：$h_t$ 必须同时支撑预测 $x_{t+1}, \dots, x_{t+K}$。它被迫存储**结构、计划、语法骨架**——那些对未来多步都有预测力的信息。

**表征的「未来视野」被拉长了**：$h_t$ 从「只够回答下一句」变成「足以推导出接下来 K 句」的压缩状态。<span class="marginnote">一个恰当的类比是下棋：只看下一步的棋手，表征里装的是「当前局面的局部特征」；看五步的棋手，表征里装的是「局面走向的战略评估」。同一个棋盘，不同的损失，逼出完全不同的表征内容。</span>

**关键推论**：MTP 的表征红利不只服务多步预测任务——因为长程信息对**所有**需要全局理解的推理都通用，所以 MTP 训练的模型在思维链、代码理解上普遍更强。

## 2 隐式正则化：最忠实于任务的约束

「正则化」通常让人想到显式惩罚项（L2、dropout），但 MTP 的约束是**隐式**的：它没有给损失加任何惩罚项，而是通过改变目标函数，把「表征必须可推出未来」写进了优化的隐空间。

**显式正则化**：直接约束参数的复杂度（如 L2），与任务内容无关。
**隐式正则化（MTP）**：约束表征的「预测力」，由任务本身定义——「一个好的 $h_t$ 必须是能推出未来 K 步的表示」。

<strong>辨析｜易错点：</strong>「隐式正则化」不是「正则化力度更大」的代名词。它的特殊性在于**方向**：L2 约束的是「参数别太大」，dropout 约束的是「别过拟合特定路径」，MTP 约束的是「表示要有远期预测力」。**三者可能同时起效，但只有 MTP 的正则化方向与任务目标完全一致**——它不牺牲任务能力去换泛化，而是通过让表示更「深」来同时获得两者。<span class="marginnote">这也是为什么 MTP 的收益表现为「同样数据下泛化更好」，而不是「训练损失更低」——它正则化的是表征内容，不是损失函数本身。</span>

## 3 归纳头的涌现：小模型的质变

Gloeckle 2024 §5 最惊艳的实验证据来自**归纳头（induction head）**。归纳头是 Transformer 内部实现「模式补全」（看见 A B … A 就补 B）的注意力机制，通常被认为是推理能力的组件。

在 ≤3000 万非嵌入参数的小模型上，单 Token 训练**形不成**归纳头。
改用双 Token 预测后，这些模型**涌现出归纳头**，或显著改善——即使模型小到单 Token 学不会。

<span class="marginnote">这个结果极其重要：它说明 MTP 不是「在已有能力上加一点」，而是<strong>在模型容量不足时也能逼出新的机制</strong>。论文的解释与因果估计一致——双 Token 预测给「模式补全」这类跨位置信息传递任务翻了倍的权重，让原本不够强的梯度信号足以支撑归纳头的形成。</span>

**更深一层**：论文还发现，一旦归纳头形成，单 Token 任务也能局部完成——这说明 MTP 先让模型「长出结构能力」，再让短程预测「搭便车」。**MTP 的收益不是长期依赖单 Token 的缺位，而是先建立结构、再让局部任务受益**。

## 4 公式解析：表征的信息约束

把「表示必须推得出未来」写成信息论约束。设 $Z_t$ 是隐藏表示的随机变量，MTP 的训练相当于对 $Z_t$ 施加约束：

$$
I\!\left(Z_t;\, X_{t+1}, \dots, X_{t+K}\right) \;\longrightarrow\; \text{最大化}
$$

- **第一步，认对象**：$I(Z_t; X_{t+1}, \dots, X_{t+K})$ 是隐藏表示与「未来 K 个 token」之间的互信息——表示里关于未来的信息量。
- **第二步，看单 Token 的基线**：单 Token 只最大化 $I(Z_t; X_{t+1})$——表示只保证「与下一步相关」。
- **第三步，看 MTP 的扩展**：MTP 把约束扩展到 K 个未来 token。由于远期 token 的不确定性更大（熵更高），这个约束要求 $Z_t$ 携带**结构性的、跨步的**信息，而非局部词法。
- **第四步，读含义**：约束的对象变了，优化解就变了——$Z_t$ 的**信息分配策略**从「短程优先」转为「长程兼容」。这就是表征学习与隐式正则化共同的数学表述：**MTP 重新定义了「什么是一个好的表示」**。

## 5 数值算例：等容量的信息再分配

把「信息分配」落成一个思想实验。设隐藏表示 $Z_t$ 的有效信息容量为 $C=10$（归一化单位）：

- **单 Token 分配**：$I(Z_t; X_{t+1}) = 6$（局部词法）、$I(Z_t; X_{t+2}) = 2$、$I(Z_t; X_{t+3}) = 1$、其余 1——**信息高度集中在紧邻 token**。
- **MTP（K=4）分配**：$I(Z_t; X_{t+1}) = 4$、$I(Z_t; X_{t+2}) = 3$、$I(Z_t; X_{t+3}) = 2$、$I(Z_t; X_{t+4}) = 1$——**信息被摊平到更远的未来**。

同 10 个单位的信息，MTP 把它从「押注下一步」改成了「兼顾未来四步」。这不是容量变大了，而是**同一个容量换了一种更有远见的分配**——这正是「表征的未来视野被拉长」的量化含义。<span class="marginnote">注意这个算例是示意性的：真实表示的信息分配更复杂（存在非线性交互），但它抓住了本质——<strong>MTP 不增加表示容量，只改变表示的分配策略</strong>，这是它「便宜而有效」的根源。</span>

<strong>辨析｜易错点：</strong>「表示推得出未来」不等于「模型能直接输出未来」。$h_t$ 携带长程信息，与「生成时是否利用它」是两件事。推理时如果不做任何处理，这些长程信息只是**潜在地**帮助了生成；投机解码、思维链等手段才把「携带」变成「显式利用」。**表征红利是前提，显式利用是放大器**——两者都齐了，MTP 的收益才完整。

## 6 显式与隐式正则化的对照表

| 正则化 | 约束对象 | 方向 | 与任务关系 | 代价 |
| --- | --- | --- | --- | --- |
| L2 | 参数范数 | 参数别太大 | 与任务无关 | 可能压扁能力 |
| Dropout | 神经元激活 | 别过拟合路径 | 通用 | 训练/推理不一致 |
| 早停 | 训练步数 | 别过度拟合 | 通用 | 需要验证集 |
| **MTP（隐式）** | 表示的远期预测力 | 表示能推出未来 | **与任务完全一致** | 几乎没有 |

**MTP 作为「隐式正则化」的独特之处**：它是唯一「约束方向 = 任务方向」的正则化——不牺牲能力换泛化，而是让能力本身更「深」。

## 7 延伸：表征与可解释性

「表征变得更「深」」听起来抽象，它其实有具体的观测方式——**探针实验（probing）**。研究者可以训练一个轻量分类器，从 $h_t$ 里解码出「预测目标是短程还是长程信息」，从而观察 MTP 改变表征的程度：

| 探针目标 | 单 Token 模型的 $h_t$ | MTP 模型的 $h_t$ |
| --- | --- | --- |
| 预测下一 token | 高准确率 | 高准确率（不退步） |
| 预测下下 token | 中准确率 | 显著更高 |
| 预测句子结构 | 中 | 更高（长程信息入表示） |

**探针结果直接印证「未来视野被拉长」**：同样的 $h_t$，MTP 训练后能解码出更多关于远期 token 的信息——这不是想象，是可测量的表征变化。

<strong>辨析｜易错点：</strong>「探针解码出远期信息」不等于「模型一定在推理时用上了」。探针证明的是「信息在表示里」，而「生成时是否利用」取决于解码策略。所以探针结论的正确表述是：**MTP 让远期信息「可用」**，至于「是否被用」，要看推理侧。

另一个可观测的窗口是**注意力模式**：MTP 训练的小模型涌现归纳头，本质上是注意力模式的结构化——模型学会了「复制上一步的模式」。这种「机制级」的变化，比「损失下降」更能说明「模型真的学会了新东西」。

- **探针要轻**：探针分类器要小，否则它自己在「学」而非「解码」。
- **对照要同**：单 Token 与 MTP 用同一探针架构，才可比。
- **指标要分**：短程与长程探针分开报告，别混在一个数字里。

把表征学习的意义放到博客主线里：**「表示能推出未来」与「极限」的思维一脉相承**——数学里我们用极限逼近「远处的值」，MTP 用监督逼近「远处的 token」。**让表示向更远处看，是贯穿数学与深度学习的一条共同母题**。

高等数学里，我们说「局部线性化」——用切线逼近曲线在一点附近的行为；MTP 做的是「局部多步化」——用一个表示逼近未来 K 步的行为。**从「局部近似」到「多步近似」，是分析思想在语言建模里的投影**。

加上一个「正则化如何体现为泛化」的注脚：MTP 训练的模型在未见过的推理分布上泛化更好，正是「表示承载长程结构」的直接后果——结构一旦进入表示，就比「背下来的局部统计」更能迁移。

这些观测放在一起，回答了本节开头的问题「重视之后，内部到底发生了什么」——内部发生了三件事：表示变得更深、注意力变得更结构化、泛化变得更强。三者互为表里，构成「MTP 为什么有效」的完整内部图景。

需要提醒的是：这些表征层面的红利，并不总是转化为「训练损失更低」——它们更多体现为「同样数据下泛化更好」。**评估 MTP 时，要同时看训练损失与下游泛化，只看前者会低估它**。

到这里，因果估计（对哪些 token 加权）与表征学习（加权后内部怎么变）两条线终于合流：**MTP 通过目标函数的再平衡，重塑了模型的内部表征，进而重塑了它的泛化能力**。

## 8 小结

- **表征学习**：MTP 逼 $h_t$ 编码「足以推出未来 K 步」的结构信息，拉长表示的「未来视野」。
- **隐式正则化**：约束「表征的远期预测力」，方向与任务完全一致，不同于 L2/dropout 的通用约束。
- **归纳头涌现**：小模型在单 Token 下形不成的机制，双 Token 下能涌现——MTP 先建结构，局部任务再搭便车。
- 信息论表述：MTP 把约束从 $I(Z_t; X_{t+1})$ 扩到 $I(Z_t; X_{t+1}, \dots, X_{t+K})$——**重新定义「什么是一个好的表示」**。
- MTP 不增加表示容量，只改变信息分配策略：从「押注下一步」到「兼顾未来多步」。
