## 为什么从「差异」切入

前面几节分别讲了单 Token 的局限、MTP 的定义、损失与架构。这一节把两者并排放到解剖台上：**MTP 不只是「把损失函数从一项变 K 项」的机械改动**。在优化信号、表征压力、样本效率、推理形态四个维度上，它们属于不同的范式。理解这些差异，才知道什么场景该用哪种。

## 1 优化信号：局部监督 vs 多尺度监督

标准下一 token 预测的梯度只来自**一个目标**：

$$\nabla_\theta \mathcal{L} \propto \nabla_\theta \left[ - \log P(x_t \mid x_{<t}) \right]$$

MTP 的梯度则同时携带 K 个尺度：

$$\nabla_\theta \mathcal{L}_{\text{MTP}} \propto \sum_{i=1}^{K} \nabla_\theta \left[ - \log P(x_{t+i} \mid h_t) \right]$$

<span class="marginnote">把两种监督想象成两种批改作业：单 Token 是「老师只告诉你下一个字该写什么」，MTP 是「老师同时告诉你接下来一句怎么写」。<strong>同样的输入，MTP 拿到了 K 份反馈</strong>——这是两者在优化层面最本质的差别。</span>

这个差别带来一个连锁后果：**短期目标的高度冗余**。对「The cat sat on the __」这类句子，预测 `mat` 只需要局部词法知识；但预测再往后几步的 `,`、`and`、`the`，则要求模型理解句子的整体走向。**MTP 迫使梯度流经「跨多步的因果链」**，而单 Token 的梯度可以只停在局部。

## 2 表征压力：短程统计 vs 长程规划

为什么监督尺度的差异会改变模型内部的表征？Gloeckle 2024 §5 给出了一个关键论证：**模型会在隐藏表示里「提前编排」那些未来 token 所依赖的信息**。

单 Token 模型：只要隐藏表示足以预测 $x_t$ 即可。高频共现（如 `is` 接 `a`）容易被「记住」而非「理解」，模型倾向于把容量花在**短程条件概率**上。
MTP 模型：预测 $x_{t+2}, x_{t+3}$ 需要语法骨架、语义角色、甚至程序的结构信息。模型被迫把**这些信息压缩进 $h_t$**——于是同样的维度，承载了更「深」的内容。

<span class="marginnote">论文用「隐式正则化」来描述这种效果：多步预测相当于给表征施加了一个约束——你必须是「足以推导出未来 K 步」的表示。这比任何手工设计的正则项都更贴近任务本身，详见第4篇《为什么有效：表征学习与隐式正则化视角》。</span>

**差异可以浓缩成一句话：单 Token 优化的是「条件概率表」，MTP 优化的是「能推出未来 K 步的状态表示」。**

## 3 样本效率：一份数据，K 份监督

这是最「实惠」的差异，也最容易量化。一段长度 $T$ 的序列：

| 范式 | 监督信号数 | 每个输入看到的输出数 | 相对数据效率 |
| --- | --- | --- | --- |
| 单 Token（$K=1$） | $T$ | 1 | 基线 |
| MTP（$K=2$） | $2T$（近似） | 2 | 约 2× |
| MTP（$K=4$） | $4T$（近似） | 4 | 约 4× |

**这里的「约」字很关键**：因为越远的 token 越难预测，第 $i$ 步的监督信号质量随 $i$ 衰减，不能把 $K=4$ 简单等同「4 倍有效数据」。但即便折损，MTP 在样本稀缺的领域（代码、数学、低资源语言）的收益仍然显著——**同样的语料库，MTP 让模型「读」得更充分**。<span class="marginnote">这也解释了为什么 MTP 论文的强结果集中在代码生成与数学推理：这些领域的训练数据昂贵、标注稀缺，多一步监督就多一分宝贵信号。见第4篇《MTP 在推理与代码生成任务上的增益》。</span>

## 4 推理形态：纯训练范式 vs 可加速范式

单 Token 模型在推理时别无选择：只能一步步自回归。MTP 模型则有两个选项：

- **丢弃头**：推理行为与单 Token 模型完全一致，**零成本**——MTP 的红利全部固化在训练期。
- **保留头做投机解码**：用 MTP 头当草稿模型，一次猜 K 个 token，主模型验证。猜对了就能**一步生成多个 token**，把第1篇《单 Token 预测范式的效率局限》里浪费的访存摊薄。

**这是最容易被误解的一点**：MTP 并不天然更快，它给的是「训练时更聪明、推理时可选加速」的**范式自由度**。单 Token 范式没有这个选项，因为它根本没有多余的头。下表总结四个维度的差异：

| 维度 | 单 Token 预测 | MTP |
| --- | --- | --- |
| 优化信号 | 单尺度，局部为主 | 多尺度，含远期 |
| 表征压力 | 短程统计优先 | 长程规划优先 |
| 样本效率 | 每位置 1 份监督 | 每位置 K 份监督 |
| 推理形态 | 只能自回归 | 丢弃头（零成本）或投机解码（加速） |
| 任务倾向 | 全面均衡 | 长程生成任务更强 |

## 5 公式解析：K 份监督的边际收益为何递减

MTP 内层损失的每一项难度不同，把它写成条件熵的语言：

$$
I\!\left(x_{t};\, x_{t+i} \mid x_{<t}\right) \;\geq\; I\!\left(x_{t+1};\, x_{t+i} \mid x_{<t}\right) \quad (i \geq 1)
$$

- **第一步，认对象**：$I(\cdot;\cdot\mid\cdot)$ 是条件互信息——已知前文时，两个未来 token 之间有多少共享信息。
- **第二步，读不等式**：$x_t$ 与 $x_{t+i}$ 之间隔着一个 $x_{t+1}$；已知前文时，$x_t$ 蕴含的关于 $x_{t+i}$ 的信息**至少不比** $x_{t+1}$ 蕴含的少（因为 $x_{t+1}$ 是由 $x_t$ 及前文推出的中间量）。
- **第三步，看含义**：预测 $x_{t+i}$ 时，与其直接硬猜，不如先知道 $x_{t+1}$——紧邻 token 是预测远期 token 的**最强中间变量**。
- **第四步，读衰减**：随着 $i$ 增大，$x_{t+i}$ 与 $x_t$ 之间的条件互信息逐级下降（信息经过中间的 token 逐层稀释），因此「新增第 $i$ 步」的边际收益递减——这就是 K 取 2–4 而非更大的信息论依据。

## 6 数值算例：条件互信息的衰减

把「边际收益递减」落成一个具体数字。设相邻 token 间的条件互信息每步衰减一半，即 $I(x_t; x_{t+1} \mid x_{<t}) = 1.0$（归一化单位），则：

- 第 1 步（$i=1$）：新增监督携带的信息量 1.0。
- 第 2 步（$i=2$）：$I(x_{t+1}; x_{t+2}) \approx 0.5$。
- 第 3 步（$i=3$）：$I(x_{t+2}; x_{t+3}) \approx 0.25$。
- 第 4 步（$i=4$）：$I(x_{t+3}; x_{t+4}) \approx 0.125$。

前三步累计 1.75，再加第四步只到 1.875——**新增信息量被稀释**。这解释了为什么把 K 从 3 推到 4 的收益远小于从 1 推到 2：远景监督的边际价值递减，是 MTP 参数选择的硬约束。

<strong>辨析｜易错点：</strong>递减不等于「第四步没有用」。代码与数学里，个别远 token（如函数结尾的 `}`）仍是高价值信号；只是**平均**下来新增步的信号密度下降。工程上常配合衰减权重 $w_i \propto 1/i$ 使用——给远步更低的信任度，而不是直接砍掉。

## 7 延伸：两种范式在实践中的互补

MTP 与单 Token 不是「二选一」，而是**实践中通常同时存在**：

- **主损失仍是单 Token**：DeepSeek-V3 的 $\mathcal{L}_{\text{CE}}$ 权重为 1，MTP 只是 $\lambda=0.3$ 的辅助。
- **推理默认仍是逐 token**：不复用 MTP 头时，模型行为与单 Token 完全一致。
- **MTP 是「增强」而非「替换」**：它在一个不变的单 Token 骨架上，额外提供了远期监督与可选加速。

<strong>辨析｜易错点：</strong>「MTP 模型」不是一个单独训练出来的新模型，而是「用 MTP 目标训练过的单 Token 模型」。说「MTP 模型」时，指的仍是同一个 Transformer，只是它的训练目标里多了远期监督——这个措辞细节，避免了很多无谓的争论。

这个互补关系可以用一句话概括：**单 Token 是地基，MTP 是地基上长出来的增强**。理解这一点，就不会在「该用哪种」上纠结——实际决策通常是「单 Token 为主，MTP 为辅，按需取舍」。

再补一个实用视角：**两者可以共享同一个检查点**。训练到中后期，如果你想对比「单 Token 继续训」与「MTP 继续训」的效果，只需在同一个主损失下开关 MTP 项——这比训练两套完整模型便宜得多，也是消融实验常用的手法。

## 8 小结

- **优化信号**：单 Token 只有局部梯度，MTP 携带 K 个尺度的梯度，迫使梯度流经跨步因果链。
- **表征压力**：单 Token 优化「条件概率表」，MTP 优化「能推出未来 K 步的状态表示」。
- **样本效率**：每位置 1 份 vs K 份监督，但远步信号质量衰减，「4 倍监督」要打折扣。
- **推理形态**：单 Token 只能自回归；MTP 有「丢弃头（零成本）」与「投机解码（加速）」两个选项。
- **边际收益**：条件互信息随步长衰减，K 取 2–4 是甜区，DeepSeek 取 K=1 求稳。
