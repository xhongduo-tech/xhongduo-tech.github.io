## 为什么从「采样效率」切入

第1篇提过 MTP 的「K 份监督」，第2篇《MTP 训练数据与样本构造》讲了样本怎么切。这一节回答那个最关键的实证问题：**K 份监督到底让模型从同样的数据里多学到了什么？** 用论文的语言说，就是**采样效率（sample efficiency）**——达到同等质量所需的样本数，以及**数据利用率**——每个 token 的监督信号有多少真正被吸收。

## 1 采样效率的定义与测量

**采样效率**：为达到某个目标（如困惑度、下游基准分数），模型所需的训练样本（token）数量。效率越高，所需越少。

测量的标准方法是**等 token 曲线**：固定模型大小，让 MTP 与单 Token 模型吃**完全相同的 token 数**，比较谁的困惑度 / 基准分数更低（更高）。Gloeckle 2024 的曲线呈现出稳定的形态：

- **训练初期**：单 Token 的困惑度更低——它把全部容量压在短程统计上，收敛快。
- **训练中后期**：MTP 反超——它积累的「长程表征」开始兑现，曲线下穿单 Token。
- **越训越拉开**：差距随训练推进扩大，而非缩小。

<span class="marginnote">这个「先落后、后反超」的形态很容易被误读成 MTP 收敛慢。实际上它是<strong>不同学习内容的时间表差异</strong>：短程统计立竿见影，长程规划需要样本积累。等 token 对比看的是「同一预算下的最终质量」，MTP 在终点占优。</span>

## 2 数据利用率的机制：K 份监督的信号质量

「K 份监督」听起来像白赚，但每一份的质量不同。按步长分解：

| 步长 i | 预测目标 | 信号性质 | 信息价值 |
| --- | --- | --- | --- |
| $i=1$ | $x_{t+1}$ | 短程词法 | 高信噪比，但高度冗余 |
| $i=2$ | $x_{t+2}$ | 中程语法/语义 | 有增量信息 |
| $i=4$ | $x_{t+4}$ | 长程结构/计划 | 低信噪比，但稀缺有价值 |

**数据利用率 = K 份监督里「携带增量信息」的部分**。$i=1$ 的信号与单 Token 完全重叠；真正让 MTP 赢的是 $i \ge 2$ 的信号——它们逼模型把「下一步之后会发生什么」也编进表示。**利用率不是 4 倍，而是「1 + 增量」**。<span class="marginnote">把数据利用率的提升理解为「给模型发了一份超前练习册」最贴切：同一份语料，单 Token 只要求「读懂下一句」，MTP 要求「预判后面的走向」。超额信息来自「预判」，不是来自「复读」。</span>

一个容易忽略的细节：**远期监督还带有正则化效应**——它迫使表示「即使看不到未来 token，也要为未来做准备」，这比任何显式的 dropout 都更贴近任务。这正是第4篇《为什么有效》要展开的视角。

## 3 实证：收益随任务与规模分布不均

Gloeckle 2024 §3 的实证给出了「采样效率提升」的精确地图：

**代码生成（MBPP / HumanEval）**：提升最大。等量 token 下，MTP 的 pass@k 明显更高；反过来看，达到同一 pass@k，MTP 需要的 token 显著更少。
**数学推理**：提升显著，逻辑链的远期可预测性是红利来源。
- **自然语言困惑度 / 常识**：基本持平，甚至偶有轻微下降——远期监督在自由文本上的增量信息有限。
- **模型规模**：同样 K 下，规模越大，等 token 曲线拉开得越早、越宽。

<span class="marginnote">这张地图与第1篇《MTP 训练数据与样本构造》的数据偏好结论互相印证：<strong>采样效率的提升集中在「结构可预测」的数据上</strong>。代码的函数体、数学的证明步骤都有「非此不可」的走向；散文的下一句则近乎随机，多步监督给不出可靠信号。</span>

**工程启示**：不要问「MTP 提升了多少采样效率」，而要问「**我的语料里有多少长程可预测结构**」。语料结构性强 → MTP 的采样效率提升显著；语料自由 → 收益有限。

## 4 公式解析：达到目标质量所需的样本数

把采样效率写成可计算的比值。设单 Token 达到困惑度 $\mathcal{L}^*$ 需要 $D_1$ 个 token，MTP 需要 $D_K$ 个，则采样效率提升为

$$
\eta = \frac{D_1}{D_K} \quad \Rightarrow \quad \text{节省} = \left(1 - \frac{1}{\eta}\right) \times 100\%
$$

- **第一步，认定义**：$\eta > 1$ 表示 MTP 更省样本。$\eta = 1.5$ 意味着达到同等质量只需三分之二的 token。
- **第二步，看来源**：$\eta$ 不是常数，它随训练推进变化——初期 $\eta \lt  1$（MTP 落后），中后期 $\eta > 1$ 并扩大。
- **第三步，看极限**：$\eta$ 有上界。远期监督的信息增量有限，数据利用率不可能无限提升；实测中代码任务 $\eta$ 可达 1.5–2 量级，通用语言接近 1。
- **第四步，落预算**：把 $\eta$ 乘回 $C \approx 6ND$，就知道同等质量下能省多少 FLOPs——**采样效率提升最终转化为算力预算的节省**，这是 MTP 在工业界被采纳的底层账本。

## 5 数值算例：η 如何折算成预算

把 η 翻译成钱。设单 Token 达到目标需要 $D_1 = 1.4\text{T}$ token、模型 $N=70\text{B}$，则预算 $C = 6ND \approx 5.9\times10^{23}$ FLOPs。

- 若 MTP 在代码/数学语料上达到 $\eta = 1.67$（省 40%）：$D_K = 0.84\text{T}$，预算降到 $\approx 3.5\times10^{23}$。
- **省下的 $2.4\times10^{23}$ FLOPs，可以再训一个 40B 的模型**，或用于加大主模型、增加消融实验。
- 若通用语言语料 $\eta \approx 1.05$（省 5%）：$D_K \approx 1.33\text{T}$，节省微不足道——**这就是「语料结构决定 ROI」的账本表达**。

<strong>辨析｜易错点：</strong>η 是「达到同等质量」的比值，但「同等质量」在不同基准上定义不同。代码的 pass@k 与语言的困惑度不可直接换算——**跨任务比较 η 前，先确认两者量的是同一个目标**。论文里最扎实的 η 报告都限定在单一任务内。

## 6 采样效率 vs 推理速度：两种「快」

MTP 同时改善两种不同的「快」，务必分清：

| 维度 | 采样效率提升 | 推理加速 |
| --- | --- | --- |
| 发生阶段 | 训练期 | 推理期 |
| 表现 | 同等质量用更少 token | 同等硬件更快出 token |
| 来源 | K 份监督的表征红利 | MTP 头投机解码 |
| 优化指标 | 困惑度 / pass@k 曲线 | TPOT / 吞吐 |
| 代价 | 每步计算略增 | 草稿步的少量开销 |

**两者都来自同一个 MTP 训练，但兑现的环节不同**——训练侧省数据、推理侧省时间，这正是一个「训练范式」同时带来的双重回报，也是 MTP 相比单 Token 的独特之处。

## 7 延伸：等 token 对比的严谨做法

「等 token 曲线」是判断采样效率的标准工具，但它的严谨性取决于几个细节：

<strong>辨析｜易错点：</strong>第一，**token 数要真的相等**——MTP 每步多算 K 个头，如果按「步数」而非「token 数」对齐，会高估或低估收益。必须保证两边吃掉的 token 总量一致，才能公平对比。

第二，**模型大小要一致**——MTP 的头占 1%–3% 参数，若不控制模型规模，混入了「更大模型」的收益，结论就失真了。理想做法是让非嵌入参数量严格对齐。

第三，**评估基准要跨任务**——只报代码任务会偏乐观，只报困惑度会偏悲观。至少覆盖「结构型任务（代码/数学）+ 通用型任务（语言/常识）」两组，才能看出 MTP 的选择性。

严谨的对比流程建议如下：

- 固定模型大小与优化器，只改目标函数（单 Token vs MTP）。
- 用**相同的 token 预算**跑完，记录完整训练曲线。
- 在多个下游基准上评估，分别报告「提升」与「持平/下降」。
- 结论按任务分组，避免「平均」掩盖选择性收益。

**等 token 对比做严谨了，才能回答「MTP 到底值不值」**——否则可能被「任务选择」与「预算对齐」这两个细节带偏结论。

## 8 小结

- **采样效率** = 达到目标质量所需样本数；MTP 的等 token 曲线「先落后、后反超」。
- 数据利用率 = **1 + 增量信息**：$i=1$ 的信号冗余，$i \ge 2$ 的远期信号才是增量来源。
- 远期监督自带**正则化效应**，逼表示「为未来做准备」。
- 实证地图：**代码/数学显著，通用语言持平；模型越大提升越早、越宽**。
- 采样效率提升最终转化为**算力节省**：$\eta = D_1/D_K$，η 越高，省下的预算越多。
