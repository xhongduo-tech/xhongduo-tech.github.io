# 多 Token 预测的因果估计

<div class="epigraph">
<p>模型对下一个 token 的预测里，藏着一个看不见的估计目标：这个 token 与它的后继到底共享多少信息。</p>

</div>

<div class="article-byline">

## 为什么从「因果估计」切入

「MTP 为什么有效」可以有直觉解释（提前规划、长程监督），但 Gloeckle 2024 §5 给出了一条更硬的路径：**用信息论把 MTP 与单 Token 的估计目标精确写出来**。结论是：MTP 本质上改变了模型对不同 token 的「重视程度」——它把相邻 token 之间互信息 $I(X;Y)$ 的权重翻倍，从而让模型优先学好那些「对后续生成至关重要」的 token。这一节把这个「因果估计」的论证完整走一遍。

## 1 估计目标：单 Token 与双 Token 各自优化什么

设当前位置的下一 token 为 $X$，第二下 token 为 $Y$。用交叉熵损失衡量，模型在位置 $t$ 的优化目标分别是：

- **单 Token 预测**：最小化 $H(X)$——即「给定前文，预测 $X$ 的不确定性」。
- **双 Token 预测**：最小化 $H(X) + H(Y)$——同时压两份不确定性。

乍看两者之和在两次位置更新后相等（位置 $t$ 预测 $X$，位置 $t+1$ 预测 $Y$，总损失也是 $H(X)+H(Y)$）。**差别不在总量，而在分解**——同一个 $H(Y)$，单 Token 是「等 $X$ 真实发生后」才去压，双 Token 是「在 $X$ 还未知时」就和 $H(X)$ 一起压。<span class="marginnote">这个「提前到同一位置压 $Y$」正是因果估计的关键：模型不得不在不知道 $X$ 的真实值之前，就把 $Y$ 纳入损失。它被迫在 $X$ 的表示里「预留」对 $Y$ 有用的信息——而单 Token 可以把对 $Y$ 的预测责任完全推给下一步。</span>

## 2 公式解析：互信息 $I(X;Y)$ 的权重翻倍

核心论证是把两个目标各自做互信息分解：

$$
\begin{aligned}
H(X) &= H(X \mid Y) + I(X;Y) \\
H(X) + H(Y) &= H(X \mid Y) + H(Y \mid X) + 2\,I(X;Y)
\end{aligned}
$$

- **第一步，认分解**：条件熵 $H(X\mid Y)$ 是「$Y$ 已知后，$X$ 还剩多少不确定性」；$I(X;Y)$ 是「$X$ 与 $Y$ 共享的信息量」（互信息），即相邻 token 之间的因果/统计耦合。
- **第二步，看单 Token**：位置 $t$ 的目标只有 $H(X)$，其中 $I(X;Y)$ 出现**一次**。
- **第三步，看双 Token**：$H(X)+H(Y)$ 展开后，$I(X;Y)$ 出现**两次**——因为它在 $H(X)$ 里出现一次、在 $H(Y)$ 里又出现一次。
- **第四步，读结论**：相对单 Token，**双 Token 预测把相邻 token 互信息的权重翻倍**。模型被迫把更多容量分配给「与后继强相关」的 token——这些正是决定文本走向的 token。论文把这称为「因果估计」的再平衡：MTP 放大了对**有因果延续力**的 token 的学习强度。

## 3 「选择点」视角：哪些 token 被加权了

信息论分解的直觉版本是论文里的**选择点（choice point）**论证。文本中并非所有 token 同等重要：

- **无足轻重的 token**：同义替换不影响大局（如 `the` 换成 `a`），它的后继与它关联弱。
- **选择点 token**：决定文本命运的关键决策（如函数名、判断方向），它的后继与它高度关联，因为「选对了，后面全对」。

MTP 对选择点的加权重构如下：一个 $K$-token 预测器通过**与其关联的后继 token** 间接给选择点累积权重，论文的分析显示该权重近似 $K(K+1)/2$——随 K 二次增长。<span class="marginnote">为什么是 $K(K+1)/2$？因为选择点不仅影响紧邻的下一步，还通过「一步带一步」影响后面每一层预测，权重像三角形数一样累加。K 越大，选择点被加权的倍数越高——这就是 MTP「隐式聚焦关键决策」的定量表达。</span>

**这解释了 MTP 的一个反直觉现象**：它没有显式告诉模型「哪些 token 重要」，只是通过「多步一起预测」这个目标，就让模型自己学会了重视选择点——**因果估计的权重再平衡是涌现出来的，而非手工设计的**。

## 4 与「为什么有效」的衔接

因果估计的分析不是孤立的，它与 MTP 的实证现象严丝合缝：

**代码/数学上收益大**：这些领域的选择点极多——函数签名、变量名、逻辑分支，每一个都是「选错全盘皆输」的决策点。MTP 的权重再平衡精准命中了它们。
**通用语言上收益平**：散文里的选择点稀疏，多数字符都是「无足轻重」的填充，互信息 $I(X;Y)$ 本来就低，翻倍了也翻不出多少增量。
- **规模越大收益越宽**：大模型有容量承接「为选择点预计算」的要求；小模型连单步都学不满，多出来的权重无处安放。

<span class="marginnote">把这条因果估计的主线串起来：<strong>MTP = 目标函数的权重再平衡 → 放大大模型对选择点的学习 → 在结构性强、选择点密集的任务上兑现为显著的采样效率与表征红利</strong>。这也是本专题各篇共同落脚的终点。</span>

## 5 数值算例：选择点权重的二次增长

把 $K(K+1)/2$ 落成具体数字，看选择点被加权的幅度：

| K | 选择点相对权重 $K(K+1)/2$ | 相对 K=1 的倍数 |
| --- | --- | --- |
| 1 | 1 | 1× |
| 2 | 3 | 3× |
| 3 | 6 | 6× |
| 4 | 10 | 10× |
| 5 | 15 | 15× |

**K 从 1 涨到 4，选择点在目标函数里的相对权重从 1 涨到 10**——这就是「多步监督让模型聚焦关键决策」的定量强度。<span class="marginnote">对比之下，无足轻重的 token 即使被翻倍加权，绝对值依然很小——<strong>MTP 的权重再平衡不是「平均加钱」，而是「给少数关键点大幅加钱」</strong>，这正是它能在不损失语言流畅性的前提下提升长程能力的原因。</span>

<strong>辨析｜易错点：</strong>$K(K+1)/2$ 是论文分析框架下的**近似权重**，不是目标函数里的字面系数。真实训练里选择点并无显式标签，加权是「通过关联后继累积」的涌现结果。**把近似权重当成精确公式去推其它结论，会高估 MTP 的确定性**——它的价值在于解释「为什么方向是对的」，而非「精确到第几位小数」。

## 6 因果估计与其它 MTP 理论的对照表

| 理论视角 | 核心主张 | 回答的问题 | 与本节的关系 |
| --- | --- | --- | --- |
| 因果估计（本节） | 互信息权重翻倍，聚焦选择点 | MTP 重视哪些 token | 主角 |
| 表征学习 | 表示被逼编码长程信息 | 重视之后内部变了什么 | 因果估计的下一环 |
| 隐式正则化 | 约束「表示能推出未来」 | 为什么是「更好的学习」 | 表征学习的别名 |
| 采样效率 | 同等质量更少 token | 效果有多少 | 因果估计的实证兑现 |

**四条线是同一枚硬币的四面**：因果估计讲「目标怎么变」，表征学习讲「表示怎么变」，正则化讲「为什么更稳」，采样效率讲「省了多少」——它们共同构成了「MTP 为什么有效」的完整答案。

## 7 延伸：因果估计与自监督学习的关系

「权重再平衡」这个思路，在自监督学习里其实有更广的背景。MTP 的因果估计，可以看成「让目标函数自己发现数据里的结构」的一个实例：

- **对比学习**：通过「正负样本」让表示学会判别——目标函数显式定义「什么像什么」。
- **掩码语言建模（MLM）**：随机遮住 token 让模型补全——权重均匀分布在被遮的位置。
- **MTP 因果估计**：通过「多步一起预测」让模型自己发现选择点——权重由数据的内在结构决定，是**涌现**的。

MTP 与对比学习、MLM 的区别在于：它**不手工指定**哪些 token 重要，而是让「多步监督」这种机制自动把权重导向选择点。这既是它优雅的地方，也是它的限制——**权重分布由数据决定，你无法精确控制它聚焦哪里**。

<strong>辨析｜易错点：</strong>「涌现的权重」不等于「无法分析」。因果估计的贡献恰恰是事后把这种涌现机制解释清楚了（互信息翻倍、选择点加权）——**它让「看不见的机制」变得可解释、可预测**。这正是理论工作的价值：不是设计机制，而是解释机制。

把「目标函数决定注意力」的对照画出来：

| 方法 | 谁决定权重 | 是否可控制 |
| --- | --- | --- |
| 对比学习 | 手工定义的正负样本 | 是 |
| MLM | 随机遮罩 | 部分 |
| MTP | 数据内在结构 | 否（但可解释） |

**可解释但不完全可控**——这是 MTP 因果估计最诚实的定位：我们事后能说清它聚焦了哪里，却不能精确指定它聚焦哪里。这也是未来工作的方向之一：在保留涌现性优点的同时，给 MTP 加一点「可引导性」——比如按任务给不同步长的监督加权，本质上就是在「引导」权重再平衡的方向。

从更广的视角看，MTP 的因果估计与「预训练任务设计」的原则一脉相承：**好的自监督目标，应该让模型的注意力自然流向任务的关键结构**——MTP 在语言建模上示范了这一点，而它在代码、推理上的突出表现，正是「结构自然被聚焦」的直接证据。

## 8 小结

- 单 Token 在位置 $t$ 优化 $H(X)$，双 Token 优化 $H(X)+H(Y)$——**总量相同，分解不同**。
- 互信息分解显示：双 Token 把相邻 token 的 $I(X;Y)$ **权重翻倍**，放大对「有因果延续力」token 的学习。
- **选择点**是文本中决定走向的关键 token，MTP 通过关联后继给它们近似 $K(K+1)/2$ 的权重，随 K 二次增长。
- 权重再平衡是**涌现**的，不是手工设计的——模型自己学会了重视关键决策。
- 与实证严丝合缝：代码/数学选择点密集所以收益大，通用语言选择点稀疏所以收益平。

在下一节，我们从「对哪些 token 加权」走到「内部到底怎么变」：**为什么有效——表征学习与隐式正则化视角**。
