## 为什么从「把波函数升级成 Green 函数」开始

至此，我们反复用「散射矩阵 + 相位」讲输运，但有一类问题它力不从心：**当系统同时有非平衡驱动（偏压）、相互作用（库仑、电子-声子）和有限温度时，电流怎么算？** Landauer 公式假设电子弹道穿过势垒；库仑阻塞的黄金规则假设隧穿是「小事件」。这些假设一旦松动——比如加电压时电子在量子点里驰豫、或者跟声子交换能量——就需要一套更一般的机器。

这套机器就是**非平衡 Green 函数（nonequilibrium Green's functions, NEGF）**，也叫 **Keldysh 形式**。
它由 Kadanoff-Baym、Keldysh 在 1960 年代建立，是当代介观输运、量子点物理、分子电子学、量子输运计算的「标准引擎」。
<span class="marginnote">NEGF 的威力在于它统一了「平衡」与「非平衡」：平衡时它退回标准的有限温度 Green 函数；
非平衡时它多出一整套描述「电子密度如何被偏压重塑」的新结构。兰道尔公式、BTK 曲线、库仑阻塞，都能从 NEGF 里作为极限情形重新导出来。
</span>

## 1 一个系统的四种 Green 函数

对非平衡系统，人们同时定义四个 Green 函数：**推迟（retarded）$G^R$、超前（advanced）$G^A$、小于（lesser）$G^<$、大于（greater）$G^>$**。

$G^R$ 描述「因果传播」：电子注入一点后，系统如何响应——它决定能谱（极点是准粒子能量）。
- $G^A$ 是 $G^R$ 的厄米共轭，$G^A = (G^R)^\dagger$。
- $G^<$ 描述「占据信息」：它是非平衡版的「费米函数」，告诉我们在某个能量上有多少电子。<span class="marginnote">$G^<$ 是 Keldysh 形式里最有用的量：电流、电子数、噪声都可以写成 $G^<$ 的组合。平衡时 $G^<(E) = -2\pi i f(E)\,\mathrm{Im}G^R(E)$——退化成「能谱 × 费米占据」，非平衡时这个简单关系被打破，$G^<$ 独立演化。</span>

推迟函数的定义给出

$$G^R(E) = \left[E - H - \Sigma^R(E)\right]^{-1}$$

其中 $\Sigma^R$ 是**自能（self-energy）**，它编码了所有「与环境的耦合」：电极的耦合、库仑相互作用、声子的吸收发射。
<span class="marginnote">自能是 NEGF 的「调节旋钮」：把电极画成「自能的虚部」$\Gamma = i(\Sigma^R - \Sigma^A)$，于是「样品与电极耦合得多紧」被编码成一个可算的量。
整个输运问题变成了「给自能建模」的问题。</span>

## 2 从 NEGF 导出 Landauer 公式

把样品连上左右电极，每个电极用一个自能 $\Sigma_{L,R}$ 描述。在「无相互作用 + 弹道」极限下，电流公式（Meir-Wingreen 公式）化简为

$$I = \frac{2e}{h}\int dE\; T(E)\,\big[f_L(E) - f_R(E)\big]$$

其中透射函数

$$T(E) = \mathrm{Tr}\left[\Gamma_L\, G^R\, \Gamma_R\, G^A\right]$$

这就是 **Meir-Wingreen 公式**——它是 Landauer 公式的完整版：偏压、温度、电极态密度全部通过 $\Gamma$ 与费米函数进入积分，比「$T$ 是常数」的低温极限更一般。
<span class="marginnote">把 $T(E) = \mathrm{Tr}[\Gamma_L G^R \Gamma_R G^A]$ 看成「从左边进来（$\Gamma_L$）→ 在样品里传播（$G^R$）→ 从右边出去（$\Gamma_R$）」的链式图景，就记住了它的结构。
这套「进来-传播-出去」的节奏，与散射矩阵的 $t^\dagger t$ 完全同构。</span>

NEGF 的统一性在于：**同一个公式框架里**，只要改自能就能覆盖所有场景——加相互作用项得到库仑阻塞的自洽解，加声子自能得到非弹性电流，把电极换成超导自能得到 BTK 与 Andreev 输运。
前面几节的问题，在这套机器里都只是「选择哪一项自能」。

## 3 非平衡：Keldysh 环路与 $G^<$

为什么非平衡需要一套更复杂的结构？因为**平衡系统的假设「占据由单一费米函数决定」在加偏压后崩溃了**：左边电极的电子带 $\mu_L$ 的费米函数，右边的带 $\mu_R$，样品内部则处于两者的混合——不存在一个统一的化学势。

Keldysh 的解决办法是：把时间轴绕成一个闭合环路（先朝前再朝后），在环路上定义 Green 函数，让「向前传播」与「向后传播」分别携带不同占据。
推迟与超前函数只关心「因果与能谱」，而 $G^<$ 则独立地携带「占据演化」的信息。<span class="marginnote">Keldysh 环路可以直观地理解为「给系统正着演一遍、反着演一遍，然后把两段拼起来」——两段的拼接点正是非平衡信息（偏压、泵浦）注入的地方。
这套「环路」思想后来也滋养了量子场论里很多别的方法。</span>

在非平衡态，电流公式不能只看 $G^R$：电流由 $G^<$ 决定。噪声谱（上一节的 $F = 1/3$ 等结果）更需要对 $G^<$ 与 $G^>$ 一起做积分——这正是「从 NEGF 推噪声」的标准路线：噪声 = $G^<G^>$ 型的两粒子关联。

## 4 数值例子：单能级共振隧穿

让 NEGF 在一个最小模型上走一遍，比任何抽象叙述都更能建立直觉。取一个只有一个能级 $\varepsilon_0$ 的量子点，左右各连电极。
推迟 Green 函数为

$$G^R(E) = \frac{1}{E - \varepsilon_0 + i(\Gamma_L + \Gamma_R)/2}, \qquad \Gamma_L = 2\pi\,|t_L|^2 \nu_L$$

其中 $\Gamma_{L,R}$ 是量子点与左右电极的耦合宽度。代入 $T(E) = \mathrm{Tr}[\Gamma_L G^R \Gamma_R G^A]$，得

$$T(E) = \frac{\Gamma_L \Gamma_R}{(E - \varepsilon_0)^2 + (\Gamma_L + \Gamma_R)^2/4}$$

这是一条**洛伦兹线形**：能量 $E$ 扫过 $\varepsilon_0$ 时透射率出现峰值为 $4\Gamma_L\Gamma_R/(\Gamma_L+\Gamma_R)^2$ 的共振。
<span class="marginnote">洛伦兹线形是「共振隧穿」的教科书签名：峰位给出能级位置，半高全宽给出耦合宽度 $\Gamma$，峰高由 $\Gamma_L\Gamma_R$ 的比值决定——当 $\Gamma_L = \Gamma_R$ 时峰高取到 1（透射率 100%）。
一张透射谱，能级位置与耦合强度全都在里面。</span>

对称耦合（$\Gamma_L = \Gamma_R = \Gamma/2$）时，零温零偏压电导为

$$G = \frac{2e^2}{h}\,T(E_F) = \frac{2e^2}{h}\frac{\Gamma^2/4}{(E_F - \varepsilon_0)^2 + \Gamma^2/4}$$

**门电压调节 $\varepsilon_0$ 扫过费米面，电导画出一条洛伦兹峰**——这正是《量子点能级与输运谱》里共振峰的微观来源。
而峰宽 $\Gamma$ 直接对应「量子点与电极的耦合强度」：耦合强、$\Gamma$ 大、峰宽但峰矮（$\Gamma_L \neq \Gamma_R$ 时），耦合弱、$\Gamma$ 小、峰窄而尖。
<span class="marginnote">把「$G(E_F)$ 的洛伦兹峰」与上一节的库仑菱形对照：单能级模型描述「无相互作用」的共振；
加上充电能 $E_C$ 后，峰劈裂成一串库仑峰，间距 $e/C_g$——从洛伦兹峰到库仑峰，差的正是「给能级加一个 $E_C$ 的相互作用自能」。
NEGF 的「可换自能」在此具体化了。</span>

再加一层：如果量子点与声子耦合（自能含声子谱），透射谱会出现**弹道主峰 + 两侧声子伴峰**（非弹性隧穿），伴峰间距等于声子能量——这就是用输运谱「听到」单个分子振动的机制（单分子电子学、非弹性电子隧穿谱 IETS）。
<span class="marginnote">IETS 是把「改自能」推向极致的例子：一个分子被两个电极夹住，声子自能让电子的非弹性通道打开，输运谱里就多出等间距的伴峰——间距即振动能量。
现代单分子电子学里，IETS 是「看」分子结构的第一手段，而它背后的数学正是本节这条公式。</span>

## 5 公式解析：$I = \frac{2e}{h}\int dE\; T(E)\,[f_L(E) - f_R(E)]$

这条 Meir-Wingreen 公式把本专题最重要的几条线缝在一起，拆成三步：

**第一步，结构与 Landauer 公式的对应**：$T(E)$ 现在是能量依赖的透射函数，$f_L - f_R$ 是费米窗口——低温低偏压时窗口退化为 $\pm1$，$T(E) \to T$，积分回到 $G = (2e^2/h)T$。**Landauer 公式是 Meir-Wingreen 公式在「$T$ 不随能量变化」时的特例**。
- **第二步，$T(E)$ 的链式结构**：$\Gamma_L$（从左电极进来）、$G^R$（在样品里传播）、$\Gamma_R$（从右电极出去），三者相乘取迹——它把「输运 = 注入 × 传播 × 取出」的直觉变成可计算的代数。
- **第三步，自能如何进入**：$\Gamma_{L,R}$ 是电极自能的虚部，编码「耦合强度 × 电极态密度」；相互作用则进 $G^R$ 的 $H + \Sigma$。**改自能 = 改物理，这是 NEGF 的「可编程性」**——从弹道到强关联，都是同一个公式换不同的 $\Sigma$。<span class="marginnote">「改自能 = 改物理」这句话值得记住：NEGF 的价值不在公式本身，而在它是一个「可换插件的框架」。分子电子学、量子点、超导结、自旋阀——全部是同一台机器，只是拧不同的自能旋钮。这也是当代量子输运软件（如量子点主方程、Landauer-Büttiker 数值包）的统一底层。</span>

**辨析｜易错点：**

- **$G^R$ 管能谱，$G^<$ 管占据，分工不同**：推迟函数 $G^R$ 的极点给出准粒子能量，小于函数 $G^<$ 才携带「某个能量上有多少电子」的信息。把「电流 = $G^R$ 的函数」当成全部，会在非平衡系统上出错——电流与噪声都要从 $G^<$ 出发。
- **Landauer 公式是 Meir-Wingreen 的特例，不是前提**：$G = (2e^2/h)\mathrm{Tr}[tt^\dagger]$ 只在「无相互作用 + 低偏压 + 弹道」极限下成立；有库仑、声子或强偏压时，必须回到 $T(E) = \mathrm{Tr}[\Gamma_L G^R \Gamma_R G^A]$ 并带上相互作用自能。
- **自能 $\Sigma$ 不是「修正项」而是「耦合的定义」**：$\Gamma = i(\Sigma^R - \Sigma^A)$ 直接编码「样品与电极耦合多紧 × 电极态密度」——把电极「换」成自能，是 NEGF 的建模起点，不是事后补丁。

## 6 小结

- **NEGF / Keldysh 形式**是处理「非平衡 + 相互作用」输运的标准框架，用 $G^R, G^A, G^<, G^>$ 四个函数完整描述系统。
- **自能** $\Sigma$ 编码与环境的所有耦合，$G^R = [E - H - \Sigma^R]^{-1}$；改自能就是改物理。
- **Meir-Wingreen 公式** $I = (2e/h)\int dE\,T(E)[f_L-f_R]$，透射函数 $T(E) = \mathrm{Tr}[\Gamma_L G^R \Gamma_R G^A]$，Landauer 公式是它的低温低偏压特例。
- $G^<$ 携带非平衡占据信息，噪声与电流的微观计算都从 $G^<$ 出发。
- 库仑阻塞、BTK、声子非弹性输运在 NEGF 里只是「选择不同自能」的不同分支。

在下一节，我们把注意力从「电荷」转向「自旋」：当电子除了电荷还携带自旋角动量时，输运多出一个全新的自由度，可以造出磁场控制的电流开关——这就是**自旋输运与自旋电子学**。
