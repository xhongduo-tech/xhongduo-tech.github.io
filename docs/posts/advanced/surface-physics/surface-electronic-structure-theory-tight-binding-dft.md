## 为什么需要理论方法

上一节我们「知道」表面态存在，但要预言它能级多高、色散多陡、被电子占据还是空着，必须解表面体系的薛定谔方程。表面理论的核心困难是：**体系既非无限周期（体相），也非孤立分子（真空），而是半无限**。<span class="marginnote">「半无限」无法直接套用布洛赫定理。理论家们想出两条路：把表面嵌进周期性超胞（slab），或把半无限问题化成可在边界匹配的方程。本专题第2篇其余内容（功函数、光学性质、散射）都依赖这些方法给出的电子结构。</span>

从最直觉的紧束缚模型，到现代第一性原理 DFT，这一节梳理表面电子结构计算的方法谱系，以及各自能回答什么问题。

## 1 紧束缚模型：用原子轨道搭出表面

紧束缚（tight binding, TB）假设电子局域在原子轨道上，波函数是原子轨道的线性组合。对表面体系，把表面原子与体内原子一视同仁地放进轨道基组，只需让**表面层的原子参数**与体相不同——例如悬键引起的轨道能抬升、键长弛豫引起的跳跃积分变化。<span class="marginnote">TB 的优点是透明：你能「看见」表面态源于哪些轨道的组合。Si 表面的悬键态、过渡金属 d 带表面的 Shockley 态，用 TB 都能给出半定量的色散图像。</span>

对半无限体系，还有一种漂亮的分析解：把垂直方向当作一维链，平行方向保持周期，则表面态的存在条件化为**一个可解的方程**——例如在简单 s 带模型下，表面态存在的判据是表面处势场突变使某能级被「拉」进带隙，其波函数 $e^{-\kappa z}$ 的衰减长度由 $\kappa$ 决定。<span class="marginnote">这种「一维链 + 表面端」模型历史上用于证明 Tamm 态与 Shockley 态的存在，至今仍是理解「什么条件下表面有态」的最简工具。</span>

## 2 从紧束缚到第一性原理：DFT 登场

紧束缚参数需要拟合，不能预言新体系。真正的预言来自**第一性原理**：不依赖实验参数，从电子与原子核的薛定谔方程出发。直接解多体薛定谔方程不可行，密度泛函理论（DFT）把它转化为单粒子方程——**Kohn–Sham 方程**：

$$\left[ -\frac{\hbar^2}{2m}\nabla^2 + V_{ext}(\mathbf{r}) + V_H(\mathbf{r}) + V_{xc}(\mathbf{r}) \right]\psi_i(\mathbf{r}) = \varepsilon_i\,\psi_i(\mathbf{r})$$

其中 $V_{ext}$ 是原子核势（含赝势），$V_H$ 是电子间库仑排斥（Hartree 势），$V_{xc}$ 是交换关联势——它把所有多体效应「打包」进一个局域或半局域的泛函。<span class="marginnote">Kohn–Sham 方程把「多体问题」简化为「有效势中的单粒子问题」，代价是 $V_{xc}$ 未知。近似得好坏，决定了计算结果与实验的差距——这是 DFT 的「含羞的引擎」。</span>

## 3 表面计算的工程：超胞、赝势与泛函

把 DFT 用到表面，需要三件工程工具：

**超胞（slab）方法**：用一层真空（10–20 Å）夹着若干原子层的板（slab），构成三维周期超胞。真空足够厚则相邻板互不影响，slab 上下两个面就是待研究的表面。<span class="marginnote">slab 必须厚到「中间层行为像体相」——通常 6–12 层；太薄则两侧表面相互作用，太厚则计算代价爆炸。收敛性检查（厚度、真空层、k 点）是表面 DFT 的第一课。</span>
**赝势与投影缀加波（PAW）**：把内层电子（化学上「惰性」）与原子核合并成离子赝势，只显式处理价电子，大幅降低基组需求；平面波基组配合 k 点采样得到收敛的能带。
**交换关联泛函**：局域密度近似（LDA）与广义梯度近似（GGA，如 PBE）是主力，但它们系统性**低估带隙**（半导体 Si 算出来约 0.6 eV，实验 1.17 eV）。<span class="marginnote">带隙问题对表面态尤其致命——表面态能量刚好依赖带隙位置。修正路线有杂化泛函（HSE）、GW 多体方法；GW 用格林函数算自能修正，能给出与实验吻合的表面态与带隙，代价是贵一个量级。</span>

## 4 公式解析：Kohn–Sham 方程的三层读法

Kohn–Sham 方程是表面电子结构计算的总开关，拆解它：

$$\left[ -\frac{\hbar^2}{2m}\nabla^2 + V_{ext} + V_H + V_{xc} \right]\psi_i = \varepsilon_i\,\psi_i$$

- **第一步，动能项** $-\frac{\hbar^2}{2m}\nabla^2$：描述电子的自由传播。它是「波动性」的根源，也决定表面态向真空的衰减行为——动量越大（能量越深），衰减越快。
- **第二步，三个势**：$V_{ext}$ 把原子核骨架「粘」进来（赝势版还埋掉了内层电子）；$V_H$ 处理电子间的平均排斥；$V_{xc}$ 是「多体残差」。**每一项都做近似，近似误差就沉淀在 $\varepsilon_i$ 里**——带隙偏小主要归咎于 $V_{xc}$ 的近似。
- **第三步，自洽循环**：$\psi_i$ 给出电子密度 $\rho = \sum_i |\psi_i|^2$，$\rho$ 又决定 $V_H, V_{xc}$，方程左右互为条件——需迭代至自洽。表面计算里这一步在数十个 k 点上重复，直到能量变化低于阈值。

## 5 表面计算能给出什么

现代表面 DFT 的产出早已超出能带本身：

**几何弛豫**：优化原子位置，预言表面重构的原子坐标（如 Si(100)(2×1) 二聚体的键长与倾角）——与 LEED、STM 定量对照。
**功函数**：slab 两侧的静电势差给出功函数（下一节详述）；吸附分子引起的功函数变化也能定量重现。<span class="marginnote">功函数对交换关联与真空层厚度敏感，是检验 slab 收敛性的敏感标尺。</span>
**表面态色散与自旋**：预言表面态沿 $k_\parallel$ 的色散，直接与角分辨光电子谱（ARPES）对照；含自旋轨道耦合的计算可预言拓扑表面态与自旋纹理（第4篇低维材料）。
**吸附与反应势垒**：把吸附分子放上表面优化几何、算吸附能，用 NEB 方法算反应路径势垒——这是表面催化理论（第3篇）的核心工具。

### 易错辨析｜DFT 的结果有多「真」

**辨析｜易错点：**

- **Kohn–Sham 本征值不是准粒子能量**：KS 能级只是构造电子密度的辅助量，严格说不是电子激发能量。用它直接读带隙必然偏差（LDA/GGA 低估 30%–50%），读表面态位置也要谨慎——文献里「DFT 算出的表面态能量」都附带泛函误差。
- **slab 有两个表面**：超胞上下各有一个表面，若结构不对称则上下表面态不同；计算功函数、表面能时必须对称处理，或明确说明看的是哪个面。
- **收敛性检查是计算结果的一部分**：层数、真空层厚度、k 点网格、平面波截断能都需要逐项收敛。直接拿未收敛结果发表，等于数据造假——表面 DFT 的第一课就是「你收敛了吗」。

### 核心对比：紧束缚与第一性原理 DFT

| 特征 | 紧束缚（TB） | 第一性原理 DFT |
| --- | --- | --- |
| 参数来源 | 拟合 / 半经验 | 从头计算 |
| 计算代价 | 低 | 高（随体系非线性增长） |
| 预言能力 | 半定量 | 定量 |
| 表面处理 | 表面层参数化 | slab 超胞 + 真空层 |
| 透明性 | 高（能看清轨道贡献） | 中（需后处理分解） |
| 典型用途 | 色散、机制、拓扑分类 | 几何、能带、吸附能、反应势垒 |

### 数值实例：PBE 低估 Si 带隙

用 PBE 泛函计算体相 Si，带隙约 0.6 eV，实验值 1.17 eV——低估近半。对表面态这类「依赖带隙位置」的量，这种误差会整体平移表面态能量。改用 HSE 杂化泛函或 GW，Si 带隙恢复到 1.1–1.2 eV，但计算量上升一个量级。**「带隙问题」是表面电子结构计算必须时刻记在心里的系统误差。**

### 连接与拓展：理论—实验闭环

表面电子结构计算与 LEED、STM、ARPES 形成双向闭环：DFT 预言表面态色散 → ARPES 实测校验；STM 的实空间态密度图 → DFT 模拟衬度对比。第7篇的镜像态能级（$-0.85/(n+a)^2$ eV）、第9篇的功函数（slab 静电势差），都是「理论算、实验验」的标准产物。当代的材料筛选（第18篇 d 带中心 + 催化火山曲线）更是把 DFT 从「解释工具」变成了「预言机器」。

### 速查：本节核心公式与要点

| 公式 / 概念 | 一句话含义 |
| --- | --- |
| Kohn–Sham 方程 $[-\frac{\hbar^2}{2m}\nabla^2 + V_{ext} + V_H + V_{xc}]\psi_i = \varepsilon_i\psi_i$ | 多体问题 → 有效势中的单粒子方程 |

### 本节一句话

**表面电子结构计算 = 从「透明的近似」到「精确的预言」**：紧束缚讲机制、DFT 做定量、GW 补带隙，三者配合 LEED/STM/ARPES 形成理论—实验闭环——这是把「表面态」从猜测变成知识的工具链。

值得强调的是，计算与实验在表面科学中是「互相定义」的：没有 DFT，STM 图像无法解释；没有 STM/ARPES，DFT 无法验证。今天「理论计算 + 实验验证」已是表面物理发表研究的标配，甚至反过来——DFT 先预言、实验后证实的「计算优先」模式，正在改变材料发现的方式（第18篇催化筛选）。

这套「算—测互证」的方法论，也是本专题后续电子结构篇章（功函数、吸附诱导态、拓扑表面态）共同的工作方式。

## 6 小结

- **紧束缚**用原子轨道基组，透明、直观，适合半定量色散与机制分析；表面参数化是关键。
- **DFT/Kohn–Sham**把多体问题化为有效单粒子方程，是表面计算的主力；$V_{xc}$ 的近似质量决定结果精度。
- slab 超胞 + 真空层是表面 DFT 的标准配置：厚度、真空层、k 点必须逐项做收敛性检查。
- **LDA/GGA 系统性低估带隙**（Si 算成 0.6 eV，实验 1.17 eV）；HSE 与 GW 修正但贵一个量级。
- 表面计算产出几何弛豫、功函数、表面态色散、吸附能级与反应势垒（NEB）。
- KS 本征值不是准粒子能量：读带隙与表面态位置都要小心泛函误差；slab 有两个表面，对称处理。
- 理论—实验闭环：DFT 预言 → ARPES/STM 验证，当代材料筛选把 DFT 从解释工具变成预言机器。
- 紧束缚的一维链 + 表面端模型是证明 Tamm 态与 Shockley 态存在的最简工具，至今仍是判断「什么条件下表面有态」的起点。
