## 为什么先讲物理吸附

气体分子与表面相互作用分两类：物理吸附（弱）与化学吸附（强）。物理吸附基于**范德瓦尔斯色散力**——没有化学键、没有电荷转移，分子保持自身身份。<span class="marginnote">它看似「不重要」，却是所有吸附的<strong>基础层</strong>：任何分子在化学吸附之前，先要经历物理吸附的预吸附态；物理吸附也是低温物理、气体储存（储氢）、气相色谱、以及多孔材料应用的支柱。</span>

物理吸附的能量虽弱（数十 meV），但足以让分子在表面停留，形成可精确刻画的热力学平衡——吸附等温线由此成为最干净的「分子—表面相互作用」实验窗口。

## 1 吸附势：Lennard–Jones 型位能曲线

分子在表面上方感受到的势能 $V(z)$ 由两部分构成：远距离的**吸引**与近距离的**排斥**。吸引来自原子—表面间的范德瓦尔斯（London 色散）相互作用，随距离衰减为

$$V_{att}(z) = -\frac{C_3}{z^3} \qquad (z \gg z_0)$$

其中 $C_3$ 是色散系数，正比于吸附原子极化率与衬底介电响应。<span class="marginnote">$z^{-3}$ 的指数是「原子—平面」系统的标志：两个原子是 $z^{-6}$，把其中一个换成无限大半空间，积分两次就把幂次从 6 降到 3。这个「降幂」是表面物理独有的几何效应。</span>

近距离排斥来自 Pauli 排斥（电子云交叠），通常用指数或 $z^{-9}$ 形式近似。两者叠加得 **Lennard–Jones 型吸附势**：

$$V(z) = \frac{C_{12}}{z^{9}} - \frac{C_3}{z^{3}}$$

势阱深度 $E_{ph}$ 即物理吸附能，典型值 10–100 meV（约 1–10 kJ/mol），平衡距离 $z_0 \approx 0.3$ nm——分子中心离表面约一个范德瓦尔斯半径。<span class="marginnote">物理吸附的判据：$E_{ph}$ 远小于化学键能（1–10 eV），且没有电荷转移与成键态形成。稀有气体（He、Ar、Kr、Xe）与分子晶体表面是纯物理吸附的经典体系。</span>

## 2 吸附等温线：覆盖度如何依赖压力与温度

**吸附等温线（adsorption isotherm）**：固定温度下，覆盖度 $\theta$ 随气压 $p$ 的变化。它由吸附层与气相之间的**化学势平衡**决定。最基础的是 **Langmuir 等温线**，假设表面吸附位等价、吸附分子不相互作用、单层封顶：

$$\theta = \frac{Kp}{1 + Kp}, \qquad K = \frac{1}{p_0}\,e^{E_{ph}/RT}$$

其中 $K$ 是吸附平衡常数，$p_0$ 是参考压强。<span class="marginnote">取极限检验：$p$ 很小时 $\theta \approx Kp$（Henry 定律，覆盖度正比于压力）；$p$ 很大时 $\theta \to 1$（饱和单层）。Langmuir 等温线的「L 形」饱和曲线，是单层吸附的标志性形状。</span>

当吸附层允许多层堆积，Langmuir 失效，需用 **BET 等温线（Brunauer–Emmett–Teller）**：第一层吸附能 $E_1$ 与后续层（等同液化）的能量 $E_L$ 不同，等温线出现**多层台阶**。BET 是测粉末比表面积的标准方法（N₂ 吸附）。<span class="marginnote">BET 的两个物理：单层饱和 + 多层凝聚。它的线性化公式 $\frac{p}{v(p_0-p)}$ 对 $p/p_0$ 作图得直线，斜率与截距反演出单层容量——是实验室里「称量表面积」的标尺。</span>

## 3 吸附热的测定与 Clausius–Clapeyron

吸附的热力学核心量是**等量吸附热（isosteric heat）$q_{st}$**：在覆盖度不变（等量）条件下，温度变化引起的平衡压力变化。由 Clausius–Clapeyron 关系：

$$\left( \frac{\partial \ln p}{\partial (1/T)} \right)_\theta = -\frac{q_{st}}{R}$$

测量方法：做一族不同温度下的等温线，在固定 $\theta$ 处作 $\ln p$ 对 $1/T$ 图，斜率即 $-q_{st}/R$。<span class="marginnote">$q_{st}$ 随覆盖度的变化是诊断表面均匀性的窗口：表面均匀时 $q_{st}$ 近似常数；表面有多类位点或吸附分子相互排斥时，$q_{st}$ 随 $\theta$ 下降。测等量吸附热 = 给表面做「能量体检」。</span>

## 4 公式解析：Langmuir 等温线的统计物理

Langmuir 等温线看似经验公式，其实有干净的统计物理推导。把表面看成 $N$ 个独立吸附位，每个位点要么空、要么被一个分子占据，配分函数为

$$Z = (1 + e^{(E_{ph}+\mu)/k_BT})^N$$

- **第一步，理解括号**：每个位点两种状态：空（权重 1）或占据（权重 $e^{(E_{ph}+\mu)/k_BT}$，吸附能 $E_{ph}$ 与化学势 $\mu$ 都进指数）。$E_{ph}>0$ 表示吸附放热，占据态被能量加权。
- **第二步，求占据概率**：平均覆盖度 $\theta = \frac{\partial \ln Z}{\partial \ln z}$（$z = e^{\mu/k_BT}$ 是逸度），得到 $\theta = \frac{z e^{E_{ph}/k_BT}}{1 + z e^{E_{ph}/k_BT}}$。
- **第三步，气相代入**：理想气体化学势 $\mu = k_BT\ln(p/p_0)$，于是 $z = p/p_0$，代入即得 $\theta = \frac{(p/p_0)e^{E_{ph}/RT}}{1 + (p/p_0)e^{E_{ph}/RT}}$——正是 $Kp/(1+Kp)$。**Langmuir 式是「独立位点 + 理想气体」的必然结果**，它的一切局限（忽略相互作用、忽略位点差异）都写在假设里。

## 5 从等温线到二维相

物理吸附层还是研究**二维物质**的舞台。覆盖度与温度可以驱动吸附层自身的相变：

**二维气体 → 二维凝聚**：低温高覆盖时，吸附分子在表面形成有序结构（二维固体或二维液体），其相图与三维物质平行。He 吸附在石墨上是二维量子流体的经典体系。
**相称与不相称**：吸附层周期与衬底周期匹配（相称，commensurate）或失配（不相称，incommensurate）。失配层随覆盖度发生**畴壁**运动，类似二维再构相变。<span class="marginnote">这类二维相变可用 LEED 的分数阶斑强度跟踪，是第5篇表面相变思想在吸附层的延伸。</span>
**预湿润与分层**：多层吸附中，表面可能先形成二维液膜（预湿润），再发展为体相凝聚——预熔化的吸附层版本。

### 易错辨析｜物理吸附与化学吸附的判据

**辨析｜易错点：**

- **「吸附能大小」不是唯一判据**：物理吸附能可达几十 kJ/mol（重稀有气体），化学吸附弱时可低于它——真正的判据是**有无化学键与电荷转移**。
- **Langmuir 等温线不代表实验必呈 L 形**：真实表面位点不均、有相互作用，等温线可能呈 S 形或阶梯形——把任意等温线硬套 Langmuir 拟合是常见错误。
- **BET 的「单层容量」是模型参数**：多孔材料的 BET 单层容量对应「等效单层」，不是严格原子层数——报告比表面积时要注明模型假设。

### 核心对比：物理吸附 vs 化学吸附

| 特征 | 物理吸附 | 化学吸附 |
| --- | --- | --- |
| 作用力 | 范德瓦尔斯色散 | 化学键 |
| 吸附能 | 10–100 meV | 1–10 eV |
| 电荷转移 | 无 | 有 |
| 平衡距离 | ~0.3 nm | 更近（成键） |
| 活化能 | 无（或极小） | 常有 |
| 可逆性 | 常可逆 | 常不可逆 |

### 数值实例：从等量吸附热判断表面均匀性

某表面在 $\theta = 0.2$ 时 $q_{st} = 40$ kJ/mol，$\theta = 0.8$ 时降到 25 kJ/mol——$q_{st}$ 随覆盖度明显下降，说明吸附位能量分布宽、分子间排斥显著（表面不均匀）。而石墨上 Kr 的 $q_{st}$ 几乎不随 $\theta$ 变，说明其吸附位高度均匀。**等量吸附热曲线是给表面做「能量体检」的标准手段。**

### 连接与拓展：物理吸附的工程角色

物理吸附虽弱，却在工程中无处不在：储氢材料靠物理吸附容纳氢气、气相色谱靠吸附差异分离混合物、低温泵靠物理吸附清除残余气体、甚至 MOF/沸石的选择性吸附都从色散力出发。物理吸附是「弱相互作用的大生意」——理解色散力与等温线，就理解了吸附分离与气体储存的物理基础。

### 速查：本节核心公式与要点

| 公式 / 概念 | 一句话含义 |
| --- | --- |
| $V_{att}(z) = -C_3/z^3$ | 原子—平面范德瓦尔斯吸引（降幂效应） |
| $V(z) = C_{12}/z^{9} - C_3/z^{3}$ | 吸附势 = 排斥 + 吸引 |
| Langmuir $\theta = Kp/(1+Kp)$ | 独立位点单层吸附等温线 |
| BET 等温线 | 多层吸附，比表面积测量标准 |
| Clausius–Clapeyron $(\partial\ln p/\partial(1/T))_\theta = -q_{st}/R$ | 从等温线族提取等量吸附热 |
| 二维气体→凝聚 / 相称转变 | 吸附层的二维相变 |

### 本节一句话

**物理吸附是最弱的束缚，也是最干净的实验窗口**：色散力 + 等温线 + 吸附热，把「分子—表面相互作用」变成可精确刻画的热力学——这是化学吸附与催化的基础层。

## 6 小结

- **物理吸附**由范德瓦尔斯色散力驱动，能量 10–100 meV，无化学键与电荷转移；吸附势 $V(z) = C_{12}/z^{9} - C_3/z^{3}$，吸引项 $\propto z^{-3}$ 是「原子—平面」几何的标志。
- **Langmuir 等温线** $\theta = Kp/(1+Kp)$：独立位点、单层封顶；低压回到 Henry 定律，高压饱和。
- **BET 等温线**处理多层吸附，是比表面积测量的标准工具。
- **等量吸附热** $q_{st}$ 由 Clausius–Clapeyron 式 $(\partial\ln p/\partial(1/T))_\theta = -q_{st}/R$ 提取，随覆盖度的变化给表面做「能量体检」。
- 物理吸附层是二维物质实验室：二维气体→凝聚、相称/不相称转变，He/石墨是二维量子流体经典体系。
- 工程角色：储氢、气相色谱、低温泵、MOF/沸石选择性吸附——「弱相互作用的大生意」。
