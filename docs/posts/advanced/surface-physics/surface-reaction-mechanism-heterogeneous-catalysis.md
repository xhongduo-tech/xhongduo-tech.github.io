## 为什么表面反应是表面物理的「毕业大考」

前面十几篇铺垫的吸附、扩散、电子结构、振动，最终都要回答一个问题：**分子如何在表面上反应**。多相催化——工业上约九成化学过程的主角——正是表面反应的宏大应用。<span class="marginnote">催化机理研究是表面科学的第一驱动力：费曼说「如果我们能控制单个原子，化学将彻底改变」，而表面科学让人类至少能控制「一层原子上的反应」。</span>

这一章把吸附动力学接到**速率理论**，建立从微观基元步骤到宏观反应速率的完整链条。

## 1 两类表面反应机理

两个反应物分子在表面相遇并反应的途径主要有两种：

**Langmuir–Hinshelwood（L–H）机理**：两个反应物都先吸附在表面，在表面扩散相遇，成键反应，产物脱附。绝大多数表面反应走这条路。<span class="marginnote">L–H 的标志性速率依赖：反应速率对两反应物压力先升后降（因强吸附时位点竞争）。CO 氧化、氨合成、加氢反应都是 L–H。</span>
**Eley–Rideal（E–R）机理**：一个反应物吸附在表面，另一个**直接从气相**撞上来反应，不等后者吸附。E–R 路径通常很快但要求表面反应物「接得住」。<span class="marginnote">E–R 很罕见，但正是它让某些反应能在极低温度下发生（如 H 原子与吸附 H 结合生成 H₂）。区分 L–H 与 E–R 的实验判据是反应速率对压力与覆盖度的依赖关系。</span>

## 2 表面反应速率：微观基元步骤

任何表面反应都可分解为**基元步骤**：吸附（A + \* → A\*）、表面扩散、表面反应（A\* + B\* → AB\* + \*）、脱附（AB\* → AB + \*）。其中 \* 表示表面位点。每一步有各自的活化能与速率常数（Arrhenius 形式）：

$$k = \nu\,e^{-E_a/RT}$$

其中 $\nu$ 是尝试频率（约 $10^{12}$–$10^{13}$ s⁻¹），$E_a$ 是基元步骤活化能。<span class="marginnote">总反应速率由<strong>速控步骤（rate-limiting step）</strong>决定——最慢的那一步。识别速控步骤是催化动力学分析的核心：速控步骤不同，速率方程形式完全不同。</span>

对 L–H 机理，双分子表面反应 $A\* + B\* \to$ 产物的速率为

$$r = k\,\theta_A\,\theta_B = \frac{k\,K_A\,K_B\,p_A\,p_B}{(1 + K_A p_A + K_B p_B)^2}$$

其中 $\theta_A, \theta_B$ 是两反应物的表面覆盖度，$K_A, K_B$ 是各自的 Langmuir 吸附平衡常数，$p_A, p_B$ 是分压。<span class="marginnote">注意分母的平方：两个反应物争夺同一批表面位点。若 A 吸附远强于 B（$K_A p_A \gg 1$），速率 $\propto p_B/p_A$——A 过度占领表面反而<strong>毒化</strong>反应。这就是「吸附太强也坏事」的数学表达。</span>

## 3 Sabatier 原理与火山曲线

催化活性对吸附强度有一个**最优值**：吸附太弱，反应物活化不了；吸附太强，产物脱不下来、表面被毒化。这就是 **Sabatier 原理**。<span class="marginnote">把不同金属的活性（如周转频率 TOF）对吸附能作图，得到一条<strong>火山曲线（volcano plot）</strong>：顶端是「刚刚好」的金属。氨合成（Fe、Ru 在峰顶附近）、氧还原（Pt 在峰顶）都是火山曲线的经典例子。</span>

理论催化（第8篇 DFT + 第14篇 d 带中心）给了火山曲线以预测力：吸附能可由 d 带中心估算，而活化能与吸附能之间存在 **Brønsted–Evans–Polanyi（BEP）关系**——活化能随吸附能近似线性变化。于是「吸附能一个标量」就决定了整条反应能面的走向。<span class="marginnote">BEP + 线性标度关系让理论催化家能「计算筛选」新材料：给定 d 带中心，预言火山峰位置，再挑出最优催化剂组分。这是计算驱动材料发现的典范流程。</span>

## 4 公式解析：L–H 速率方程的三层读法

$$r = \frac{k\,K_A\,K_B\,p_A\,p_B}{(1 + K_A p_A + K_B p_B)^2}$$

- **第一步，分子是「两覆盖度之积」**：$r = k\theta_A\theta_B$——反应速率正比于两反应物在表面相遇的概率，即覆盖度乘积。覆盖度由 Langmuir 式 $\theta_i = K_i p_i/(1+\sum K_j p_j)$ 给出。
- **第二步，分母是位点竞争**：$(1 + K_Ap_A + K_Bp_B)$ 是「一个空位 + 被 A 占 + 被 B 占」的总权重，平方来自两个反应物各需一个位点。分压升高，分母增长，速率先升后降——**火山形状的动力学根源**。
- **第三步，极限检验**：低覆盖（$K_ip_i \ll 1$）时 $r \approx kK_AK_Bp_Ap_B$——二级反应；A 强吸附（$K_Ap_A \gg 1$）时 $r \approx kK_Bp_B/K_Ap_A$——被 A 毒化，速率反比于 $p_A$。两种极限都能从实验中认出。

## 5 从基元步骤到工业催化

动力学分析的目标是**微动力学模型**：把每个基元步骤的速率常数组装起来，预测反应条件下的稳态速率与覆盖度。现代流程：

**DFT 算能垒**：对催化循环的每个基元步骤算活化能（NEB 方法）。
**平均场微动力学**：把表面当作均匀覆盖层，解稳态方程得 TOF 与覆盖度。
**动力学蒙特卡洛（KMC）**：显式模拟表面位点的随机反应—扩散事件，捕捉覆盖度非均匀与表面重构。<span class="marginnote">KMC 弥补平均场忽略的局域效应：吸附岛的边界、台阶位的高活性、反应物的偏析，都在单事件模拟中显形。理论与实验（operando 谱学、同位素标记）互证，是现代催化研究的标准方法论。</span>

### 易错辨析｜速控步骤与速率方程

**辨析｜易错点：**

- **「最慢步骤决定速率」是稳态假设下的结论**：中间物浓度不随时间变化时才成立；若中间物积累（非稳态、诱导期），速率方程完全不同——做动力学分析前先声明稳态假设。
- **火山曲线的「峰顶」不是绝对最优**：峰顶位置依赖反应条件（温度、压力、覆盖度），同一催化剂在不同条件下可能落在火山曲线的不同侧面。
- **Arrhenius 活化能 ≠ 反应焓**：活化能是过渡态与始态的能量差，反应焓是产物与始态的能量差——「活化能低」不代表「放热多」，两个概念别混。

### 核心对比：L–H 与 E–R 机理

| 特征 | Langmuir–Hinshelwood | Eley–Rideal |
| --- | --- | --- |
| 反应物状态 | 都吸附在表面 | 一吸附 + 一气相 |
| 速率对压力 | 双饱和、可被毒化 | 正比于气相分压 |
| 活化能 | 较低（表面相遇） | 较高（直接碰撞） |
| 普遍性 | 绝大多数反应 | 少数（H+H 等） |
| 实验判据 | 速率随两分压先升后降 | 速率随气相分压线性 |

### 数值实例：CO 氧化的 CO 中毒

对 Pt 上的 CO 氧化 $2\mathrm{CO}+\mathrm{O_2}\to2\mathrm{CO_2}$，L–H 机理预言：$p_{O_2}$ 升高速率上升；但 $p_{CO}$ 过高时 CO 过度覆盖表面、O₂ 无处吸附，速率反而随 $p_{CO}$ 下降——这就是实验中的「CO 中毒」，也是汽车尾气催化剂在富燃工况（CO 多、O₂ 少）效率骤降的原因。

### 连接与拓展：从表面物理到工业催化

催化是表面物理的「毕业考场」：吸附能（第14篇）→ 覆盖度（第13篇）→ 表面反应（本篇）→ 宏观速率。现代催化剂设计已进入「计算优先」时代：用 DFT 筛材料（第8篇）、用 d 带中心排活性（第14篇）、用微动力学与 KMC 预测工业工况下的 TOF。表面物理的知识，从这里真正走向工厂。

### 速查：本节核心公式与要点

| 公式 / 概念 | 一句话含义 |
| --- | --- |
| L–H：$r = k\theta_A\theta_B$ | 双吸附反应，速率 = 两覆盖度乘积 |
| $r \approx \frac{kK_AK_Bp_Ap_B}{(1+K_Ap_A+K_Bp_B)^2}$ | 位点竞争 → 强吸附毒化、火山形状 |
| E–R：$r \propto p_{气相}$ | 气相分子直接撞吸附物反应 |
| Arrhenius $k = \nu e^{-E_a/RT}$ | 基元步骤速率的温度依赖 |
| Sabatier 原理 + 火山曲线 | 吸附能存在最优值，顶端是「刚刚好」 |
| BEP 关系 | 活化能随吸附能近线性变化 |

### 本节一句话

**表面反应 = 吸附 + 扩散 + 成键 + 脱附的接力**：L–H 与 E–R 两种机理、Sabatier 原理与 BEP 标度，共同把「哪个金属当催化剂」从经验变成可计算的科学——这是表面物理回报工业最慷慨的一章。

催化也是本专题吸附线的「毕业考试」：物理吸附（第13篇）提供预吸附、化学吸附（第14篇）提供活化、吸附动力学（第17篇）提供入口速率、电子结构（第16篇）提供活性起源——八篇吸附内容在此汇成一条「从分子到工厂」的完整链条。

这条链条的终点是工业：氨合成、石油裂解、尾气净化、燃料电池电极——每一个都在这套「吸附—反应—脱附」的微观剧本上运转。

## 6 小结

- 表面反应两大机理：**Langmuir–Hinshelwood**（双吸附）与 **Eley–Rideal**（气相撞击吸附物），以前者为主。
- 反应速率由**基元步骤**与**速控步骤**决定，每一步遵循 Arrhenius $k = \nu e^{-E_a/RT}$。
- **L–H 速率方程** $r = k\theta_A\theta_B = \frac{kK_AK_Bp_Ap_B}{(1+K_Ap_A+K_Bp_B)^2}$：位点竞争导致强吸附毒化，速率随分压先升后降。
- **Sabatier 原理 + 火山曲线**：吸附能存在最优值，顶部金属「刚刚好」；d 带中心与 BEP 标度让筛选可以「计算先行」。
- **微动力学模型**组装基元步骤：DFT 算能垒、平均场解稳态、KMC 补局域效应，是现代催化研究的标准流程。
- CO 氧化（Pt 上）是 L–H 的教科书案例：$p_{CO}$ 过高时 CO 毒化表面，速率随 $p_{CO}$ 反降。
- 「最慢步骤决定速率」只在稳态假设下成立；做动力学分析前先声明稳态假设。
