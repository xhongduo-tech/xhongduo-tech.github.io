## 为什么从「自旋」开始

前几篇的凝聚体，原子内态一直被「锁死」：磁阱只囚禁低场趋场态，所有原子挤在同一个 $m_F$ 分量里，自旋只是一个被动的标签。但如果把原子放进自旋自由的容器（第 5 篇的光学势阱），凝聚体的每个原子都同时「有资格」待在任何内态——自旋从被动标签变成**动力学变量**：序参量变成多分量的，系统自己决定自旋怎么排布。这就是**旋量凝聚体（spinor condensate）**。它把 BEC 从「物质波」升级成「物质波 × 自旋」，直接通向自旋涡旋、拓扑缺陷与量子信息。

## 1 多分量序参量

碱金属原子的「自旋」其实是超精细自旋 $\mathbf F = \mathbf I + \mathbf J$（核自旋与电子总角动量耦合）。$^{87}$Rb 与 $^{23}$Na 的基态都是 $F=1$，$^{87}$Rb 激发态还有 $F=2$。$F=1$ 的旋量凝聚体序参量是三分量复矢量：

$$\Psi(\mathbf r) = \big(\Psi_{+1}(\mathbf r),\; \Psi_0(\mathbf r),\; \Psi_{-1}(\mathbf r)\big)^T$$

三个分量分别对应 $m_F = +1, 0, -1$ 内态。<span class="marginnote">旋量凝聚体只能在光学势阱里做——磁阱的磁场方向会把自旋「钉」成一个分量，等价于把序参量压成一维。光学势阱（第 5 篇）让三个分量都活起来；这也是为什么「光学势阱 → 旋量」这条路线在实验上几乎是绑定出现的。</span>每个分量有自己的密度和相位，而分量之间的相对相位是真正的新物理：它给出 $F=1$ 系统特有的「向列（nematic）」自由度——即使 $\langle \mathbf F\rangle = 0$，序参量仍然携带方向信息。

## 2 自旋相关相互作用与基态相

旋量凝聚体的能量比单分量多出一项自旋相关相互作用。对 $F=1$，相互作用可写成对称部分与自旋部分：

$$\mathcal E_{\rm int} = \frac{c_0}{2}\,n^2 + \frac{c_2}{2}\,n^2\,\langle\mathbf F\rangle^2/n^2 \equiv \frac{c_0}{2}\,n^2 + \frac{c_2}{2}\,\big|\sum_{\alpha,\beta}\Psi_\alpha^* \mathbf F_{\alpha\beta}\Psi_\beta\big|^2$$

耦合常数由两个散射长度组合出来：

$$c_0 = \frac{4\pi\hbar^2}{3m}(a_0 + 2a_2), \qquad c_2 = \frac{4\pi\hbar^2}{3m}(a_2 - a_0)$$

其中 $a_0, a_2$ 分别是两个原子处于总自旋 $F_{\rm tot}=0, 2$ 的散射长度。$c_2$ 的符号决定基态：

- **$c_2 < 0$：铁磁（ferromagnetic）相**，$\langle\mathbf F\rangle$ 取最大，如 $^{87}$Rb（$a_2 - a_0 \approx -2.2\ a_0 < 0$）；
- **$c_2 > 0$：极化 / 反铁磁（polar, antiferromagnetic）相**，$\langle\mathbf F\rangle = 0$、自旋沿某根轴呈向列序，如 $^{23}$Na（$a_2 - a_0 \approx +2.6\ a_0 > 0$）。

<span class="marginnote">「铁磁/反铁磁」是从磁有序角度打的比方，但 $F=1$ 的极化相其实更像液晶的「向列相」：自旋方向平均为零，却仍有一个「轴」的方向是确定的——这个轴由序参量的向列张量描述。不要被「反铁磁」三个字误导：极化相不是「相邻自旋反着排」，而是「自旋取向不确定、轴确定」。</span>

## 3 自旋动力学与自旋纹理

旋量凝聚体不只是静态的相——它的自旋分量之间会**相互转换**，产生真正的动力学：

- **自旋混合振荡（spin-mixing dynamics）**：两个 $m_F=0$ 原子碰撞变成 $+1$ 与 $-1$ 各一个（$0+0 \leftrightarrow +1-1$），粒子数在不同分量间周期振荡，频率由 $c_2$ 与密度定；
- **自旋波与自旋涡旋**：磁场梯度或淬火后，自旋场形成空间纹理；$F=1$ 系统承载 **Skyrmion**（斯格明子）与半量子涡旋——凝聚体的自旋方向绕着一个圈转一整圈，却因「向列自由度」只转半圈，这类拓扑缺陷无法被连续形变抹掉；
- **量子信息的载体**：三个内态构成 qutrit 空间，自旋动力学天然是量子门，这使其成为量子计算实验的候选平台。

**辨析｜易错点：** 这里说的「自旋」不是电子的裸自旋 $\mathbf S$，而是超精细总角动量 $\mathbf F$。而且注意：磁场的存在会立刻通过 Zeeman 效应冻结自旋动力学（自旋被钉向 $\mathbf B$ 方向），所以旋量实验要么在零场附近做、要么用特定磁场让二阶 Zeeman 效应可容忍——实验上「磁场即旋钮」在旋量系统里变成了「磁场即敌人」。

## 4 公式解析：自旋相关耦合常数

$$c_2 = \frac{4\pi\hbar^2}{3m}(a_2 - a_0)$$

- **前因子 $4\pi\hbar^2/3m$**：与 GP 耦合常数 $g = 4\pi\hbar^2a/m$ 同构，只是把「一个散射长度」换成「两个散射长度的组合」，并除以 3 作归一化。它保证 $c_0$ 是密度部分、$c_2$ 是自旋部分的「强度」。
- **$a_2$ 与 $a_0$**：分别对应两原子总自旋 $F_{\rm tot}=2$（对称轨道）与 $F_{\rm tot}=0$（反对称轨道）的散射长度。为什么有两个？因为两个 $F=1$ 原子耦合后总自旋可取 $0,1,2$，其中 $F_{\rm tot}=1$ 项被对称性禁止，只剩 $a_0$ 与 $a_2$。
- **差 $a_2 - a_0$**：符号决定一切。负 → $c_2<0$ → 能量喜欢 $\langle\mathbf F\rangle$ 大（铁磁）；正 → $c_2>0$ → 能量喜欢 $\langle\mathbf F\rangle=0$（极化）。同一个 $|c_2|$ 的小差，在自然界里分别对应 Rb 与 Na 两种截然不同的基态——物理的丰富性藏在微小的散射细节里。
- **整体读法**：$c_2$ 是旋量系统的「自旋刚度」，$|c_2|n$ 决定自旋动力学的时间尺度（如自旋混合振荡频率）与空间纹理的尺寸。数值上 $|c_2| \ll c_0$（约小两个数量级），所以自旋动力学是慢过程，可被外场轻易操控。

### 从自旋涡旋到量子信息：旋量的现代用途

旋量凝聚体近年成为量子技术与拓扑物理的交叉热点：

- **半量子涡旋**：$F=1$ 极化相中存在「自旋转半圈、轨道转半圈」的复合涡旋，其拓扑荷是普通涡旋的一半，是被寄望承载非阿贝尔统计的候选载体；
- **自旋纹理的逐点成像**：量子气体显微镜（最后一篇细讲）能逐格点读出内态，直接给自旋纹理「拍照」；
- **qutrit 平台**：$F=1$ 的三个内态构成天然 qutrit，自旋混合振荡本身就是两体量子门——实验上已用它演示纠缠协议。

| 研究对象 | 关键参数 | 典型尺度 |
| --- | --- | --- |
| 自旋混合振荡周期 | $2\pi\hbar/(|c_2|n)$ | 数十 ms 量级 |
| 自旋纹理尺寸 | $\sim \sqrt{\hbar^2/2m|c_2|n}$ | $\mu$m 量级 |
| 铁磁/极化能量差（每原子） | $|c_2|n/2$ | 约 0.1 nK 量级 |

注意最后一行的能量标度：自旋物理的能量（nK 量级）比凝聚能（几十 nK）还小一个量级——旋量动力学是「慢、弱、易操控」的物理，这既是它的脆弱所在，也是它适合当量子比特的原因。

### 自旋分量：一组可供「擦写」的量子寄存器

旋量凝聚体最有想象力的用途，是把三个内态当作一组可在宏观尺度相干操作的量子寄存器。关键性质与经典比特对照：

- **相干长度宏观**：凝聚体的相位在全域一致，内态之间的相对相位可以在宏观距离上保持相干——普通原子气体做不到；
- **耦合可控**：自旋混合振荡 $|0,0\rangle \leftrightarrow |+1,-1\rangle$ 就是两体相互作用门，振荡频率由 $|c_2|n/\hbar$ 定，是天然的时钟；
- **读出精准**：Stern–Gerlach 分离后逐分量成像，可以直接「读出」每个自旋分量的空间分布。

| 平台 | 编码空间 | 相干时间 |
| --- | --- | --- |
| 光子 | 偏振 2 态 | 短（ms） |
| 离子 | 超精细 2 态 | 长（s） |
| 旋量凝聚体 | $F=1$ 的 3 态 | 亚 s–s |

旋量凝聚体算不上最好的量子比特（相干时间不如离子、操控不如光子），但它「宏观 + 自旋 + 拓扑」三位一体——这正是量子信息研究者眼里稀缺的组合。

## 5 小结

- 旋量凝聚体的序参量是**多分量**的，如 $F=1$ 的 $(\Psi_{+1},\Psi_0,\Psi_{-1})$；分量间相对相位是全新自由度。
- 自旋相关相互作用 $c_2 = 4\pi\hbar^2(a_2-a_0)/3m$：$c_2<0$ 铁磁（$^{87}$Rb）、$c_2>0$ 极化向列（$^{23}$Na）。
- 极化相 $\langle\mathbf F\rangle=0$ 但仍有「轴」确定——是向列序，不是简单的反铁磁。
- 自旋混合振荡、Skyrmion、半量子涡旋等自旋动力学与拓扑缺陷是核心新物理。
- 必须在**光学势阱 + 弱磁场**条件下做；磁场是旋量实验最需要小心的环境。

记住一个反直觉结论：旋量物理的能量标度（nK 级）远小于凝聚能（几十 nK），所以「把磁场调对」往往比「把温度降好」更关键——这是旋量实验与普通 BEC 实验最大的体验差异。

**辨析｜易错点：** 旋量凝聚体的「自旋」是超精细总角动量 $\mathbf F$，它的动力学由 $c_2$ 驱动——但 $c_2$ 很小（比 $c_0$ 约小两个数量级），所以自旋动力学慢、弱、易受磁场影响。一个常见的误解是把旋量凝聚体的「极化相」直接类比成反铁磁：其实极化相的基态是「自旋方向不确定、但轴确定」的向列序，与反铁磁的长程交替序完全不同——这个区别在读自旋纹理文献时非常关键。

在下一节，我们把舞台换成费米子：泡利不相容让「配对」成为新主角，而 Feshbach 旋钮把弱吸引的 BCS 超流与强吸引的分子 BEC 连续地连接起来——**BCS-BEC 穿越**。
