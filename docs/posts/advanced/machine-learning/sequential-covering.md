## 为什么从序贯覆盖开始

上一节确立了规则学习的目标：学出一组可读、覆盖全空间的 if-then 规则。但「同时学出一组规则」是困难的组合问题——规则之间相互牵制（谁覆盖哪些样本）。**序贯覆盖（sequential covering）**给出一个极简而有效的拆解：**一次只学一条规则，学完就把这条规则覆盖的样本「删掉」，再学下一条**。把「学一组规则」变成「反复学单条规则」。

这个「学一条 → 删覆盖 → 再学一条」的循环，像「剥洋葱」一层层剥掉数据；也被称为**逐步覆盖（covering）算法**，是绝大多数规则学习算法的骨架——FOIL、CN2、以及各种规则归纳算法都建立在它之上。<span class="marginnote">「序贯」指规则的生成是<strong>串行</strong>的：后一条规则只在前一条规则没覆盖的「剩余样本」上学。这样天然保证「互斥」（样本只被最先覆盖它的规则处理）与「完备」（直到样本被分完或无法再学）。把组合问题拆成串行子问题，是「分而治之」在规则学习里的又一次胜利。</span>

## 1 算法骨架：学一条、删一批**序贯覆盖算法**的流程：
```text
序贯覆盖(训练集 D, 属性集 A):
    规则集 R = 空
    while D 非空:
        从 D 学一条「好」的规则 r（覆盖尽量多的同类样本）
        把被 r 正确覆盖的样本从 D 中删除
        把 r 加入 R
    return R
```

三个关键点：

1. **学单条规则**：怎么从当前样本里长出一条规则（下一节）；
2. **删除策略**：通常只删除**被 r 正确覆盖**的样本（保留被 r 误覆盖的样本，让后续规则有机会修正）——这是「错误覆盖样本留作后患」的设计；
3. **停止条件**：D 空、或无法再学到「好规则」（此时用默认规则/多数类兜底）。<span class="marginnote">「只删正确覆盖的样本」是序贯覆盖的精细处：如果连误覆盖的样本也删掉，规则之间的「纠错空间」就没了。保留误覆盖样本，后续规则可以专门去「捞」它们——规则集因此有机会达到「互斥但不盲区」的覆盖。这个设计与 Boosting 的「下一轮关注上一轮的错误」有异曲同工之妙。</span>

## 2 单条规则怎么长：自顶向下「从当前样本学一条规则」最常用的策略是**自顶向下（general-to-specific）**：从**最一般的规则**出发，逐步**添加条件**使其更精确。
1. **初始**：规则条件为空，覆盖全部当前样本（极其一般、准确率可能低）；
2. **扩展**：试着加一个条件（如「色泽 = 青绿」），看「准确率提升 + 覆盖率损失」的权衡；
3. **挑选**：选「性价比最高」的条件加入（用下一节的评价函数打分）；
4. **重复**：继续加条件，直到规则准确率达到阈值（或不能再提升）。

**直觉**：这是一棵「规则生长树」——每个节点是一条规则，孩子是「在父亲条件上多一个条件」的规则；搜索的目标是找一条「够准」的叶规则。<span class="marginnote">「自顶向下」与第4章决策树的生长方向相反但思路同源：决策树是「从全集开始选属性分裂」，规则生长是「从最一般开始加条件细化」——两者都在「越来越具体」地逼近目标。区别是决策树强制所有样本走同一棵树的共享前缀，序贯覆盖让每条规则独立生长。</span>

## 3 公式解析：一条规则从「一般」到「具体」设当前样本集 $D$，正在生长的规则条件为「（已有条件）∧（候选新条件）」；加入候选条件 $a$ 后，覆盖集变为 $R$，其中类别 $c$ 的样本数为 $R_+$。**评价候选条件的常用函数**（加号项表示「准确率 × 覆盖率」类合成）：
$$\text{score}(a) = \frac{|R_+|}{|R|} \times \frac{|R|}{|D|}$$

- **第一步，看第一项**：$\frac{|R_+|}{|R|}$ 是加入条件后的**准确率**——想要它高（条件够具体）；
- **第二步，看第二项**：$\frac{|R|}{|D|}$ 是**覆盖率**——想要它别太低（条件别太苛刻）；
- **第三步，看乘积**：两者相乘，兼顾「准」与「广」——条件既不稀里糊涂也不苛刻到没人；
- **第四步，看生长**：每步选 score 最高的候选条件加入，直到准确率达标——规则在「逐步收紧」中长成。

**直觉一句话**：序贯覆盖把「学一组规则」拆成「串行学一条条规则」，每条规则从最一般出发、按「准确×覆盖」打分逐步加条件，直到它足够精确。

## 4 辨析：序贯覆盖的特点与边界**辨析｜易错点：**
- **贪心无回退**：每条规则一旦定稿、覆盖样本被删除，**不可反悔**——早期规则的错误会影响后续。这与第9章 AGNES 的「合并不可撤销」是同一类贪心风险。
- **规则顺序重要**：序贯覆盖的规则有先后（前面的规则优先），对「重叠覆盖」样本的归类依赖顺序——需用「规则排序/优先级」明确决策。
- **对噪声敏感**：噪声样本可能被「硬凑」成一条低覆盖率高准确率的规则——需要剪枝（下一节）与阈值把关。
- **与决策树对比**：序贯覆盖每次学单条规则、不受共享前缀约束，但缺少「全局视角」——它看不到「后续规则能长多好」，只顾当前最优。<span class="marginnote">「只顾当前」的贪心在序贯覆盖里有个具体后果：可能学出「覆盖窄、冗余多」的规则集（前面把好样本都占了，后面只能抠边角料）。缓解手段包括「先粗学再剪枝」、允许规则重叠后按置信度排序、以及用「覆盖增益」而非纯准确率来评价条件。</span>

## 知识速查：序贯覆盖

**本节关键词**
- 序贯覆盖
- 逐步覆盖
- 自顶向下
- 贪心
- 删覆盖样本
- 条件生长
- 误覆盖保留
- 规则集

**三条常见误区**
1. 把「删覆盖样本」当删所有覆盖——只删正确覆盖；
2. 忽略贪心无回退的局部最优风险；
3. 以为规则顺序无关——顺序决定重叠样本归属。

**核心结论**
1. 序贯覆盖一次学一条规则、删覆盖再学；
2. 只删正确覆盖的样本留纠错空间；
3. 单条规则自顶向下加条件生长；
4. 贪心无回退、规则顺序重要。

**与全书/后续的连接**
- 第4章决策树生长同源；
- 第15章剪枝优化后续；
- 第9章 AGNES 的贪心同病。

**常见面试题**
1. 问：为什么只删正确覆盖的样本？ 答：保留误覆盖样本给后续规则纠错机会。
2. 问：单条规则怎么生长？ 答：从最一般开始按「准确×覆盖」打分逐步加条件。

**一句话记忆**
序贯覆盖 = 一次学一条规则、删掉正确覆盖的样本再学下一条，直到覆盖全空间。

## 5 小结- **序贯覆盖**把「学一组规则」拆成「串行学一条条规则」：学一条 → 删正确覆盖样本 → 再学下一条。- 只删「正确覆盖」的样本，保留误覆盖样本给后续规则纠错空间。
- 单条规则用**自顶向下**生长：从最一般出发，按「准确率 × 覆盖率」打分逐步加条件。
- 评价函数如 $\frac{|R_+|}{|R|} \times \frac{|R|}{|D|}$ 兼顾「准」与「广」。
- 特点：贪心无回退、规则有顺序、对噪声敏感——需剪枝与优先级机制配套。
