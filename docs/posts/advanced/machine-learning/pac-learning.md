## 为什么从 PAC 学习开始

上一节我们有了学习的形式化语言，但还缺一个**判定标准**：什么样的任务算「可学习」？「可学习」又需要多少样本？1984 年，Leslie Valiant 给出了第一个严格框架——**PAC 学习（Probably Approximately Correct，概率近似正确）**，一举奠定了计算学习理论的基石。

PAC 学习把「学到好模型」拆成两个现实要求：**「近似」**——误差足够小（≤ ε）；**「概率」**——这个保证以高概率（≥ 1−δ）成立，而不是绝对成立。没有人能保证「永远对」，但可以说「以 1−δ 的概率，误差 ≤ ε」。这一节讲清 PAC 的定义、可学习的含义、以及有限假设空间下需要多少样本（样本复杂度）。<span class="marginnote">「Probably Approximately Correct」六个字翻译过来就是：<strong>大概（1−δ 概率）近似（误差≤ε）正确</strong>。它优雅地把「不确定性」吸收进定义本身——学习理论不追求「必然」，只追求「以大概率足够好」。Valiant 因这一框架于 2010 年获得图灵奖。</span>

## 1 PAC 学习的定义令 $\mathcal{H}$ 为假设空间，$D$ 为数据分布，目标概念（真实函数）$c \in \mathcal{H}$（**可 PAC 学习的最简情形**）。对 $0 < \epsilon, \delta < 1$，若存在算法 $\mathcal{L}$，使得对任意分布 $D$，算法从 $m$ 个样本中学习后输出的假设 $h$ 满足：`$$`P\left(E(h) \leq \epsilon\right) \geq 1 - \delta`$$`即**以至少 $1-\delta$ 的概率，泛化误差不超过 $\epsilon$**，则称该学习算法能 PAC 学习这个概念类。这里的概率既来自样本的随机抽样，也来自算法可能引入的随机性。
**辨析｜易错点：** PAC 的定义不要求「对每个样本都学对」，也不要求「总是学对」——它允许：

**近似误差**：$h$ 与真实概念 $c$ 有 $\epsilon$ 量级的差异；
**失败概率**：有 $\delta$ 的概率学得不好（比如抽到不具代表性的样本）。

这两个「放松」不是偷懒，而是**必要的现实**：有限样本不可能把误差压到 0，也不可能有 100% 保证。PAC 把「不可能精确」变成了「可以近似保证」的严格陈述。<span class="marginnote">「允许失败概率 $\delta$」是一个务实的让步：训练样本是随机抽的，总有倒霉的时候抽到不具代表性的数据（比如全部抽到同一类）。PAC 说：这种倒霉情况发生的概率不超过 $\delta$。它把「运气」放进了概率里，剩下的交给保证。</span>

## 2 一致学习器的样本复杂度**样本复杂度（sample complexity）**问：要满足 PAC 条件，需要多少训练样本 $m$？对有限假设空间（$|\mathcal{H}| < \infty$）且目标概念在空间内，一个**一致学习器**（总能找到训练误差为 0 的假设）需要的样本量为`$$`m \;\geq\; \frac{1}{\epsilon}\left( \ln|\mathcal{H}| + \ln\frac{1}{\delta} \right)`$$`- **第一步，看 $\epsilon$**：想让误差 ≤ $\epsilon$，样本量至少反比于 $\epsilon$——要误差减半，样本要翻倍；- **第二步，看 $|\mathcal{H}|$**：假设空间越大，所需样本越多（对数增长）——模型越复杂越「吃数据」；
**第三步，看 $\delta$**：想让失败概率从 $\delta$ 降到 $\delta^2$，样本增加 $\ln(1/\delta)$——概率保证的边际成本很低（对数）；
**第四步，看直觉**：有限假设空间下，「可学习」被翻译成一个**可计算的样本量公式**——**这是「学一个模型需要多少数据」的第一个定量答案**。<span class="marginnote">样本复杂度公式是「复杂度 vs 数据量」的直接体现：$\ln|\mathcal{H}|$ 告诉你要多少数据才够；而后面 VC 维一节会把「$|\mathcal{H}|$ 有限」推广到「无穷假设空间」——用 VC 维替代 $\ln|\mathcal{H}|$，公式结构几乎不变。记住这个结构：<strong>样本量 ∝ (复杂度 + 概率项)/误差</strong>。</span>

## 3 公式解析：样本复杂度怎么推导出来以二分类、一致学习器为例，推导从「坏假设」的计数开始：- **第一步，定义坏事件**：若 $h$ 泛化误差 $E(h) > \epsilon$，但训练误差为 0（一致），则它「蒙混过关」了。这样的 $h$ 叫「坏假设」。- **第二步，估坏假设的概率**：对单个坏假设 $h$，在 $m$ 个样本上训练误差全为 0 的概率至多 $(1-\epsilon)^m \leq e^{-\epsilon m}$（Hoeffding 界的离散版）。- **第三步，用并界（union bound）**：任何坏假设「蒙混过关」的概率 ≤ 所有坏假设概率之和 ≤ $|\mathcal{H}| \cdot e^{-\epsilon m}$。- **第四步，令其 ≤ $\delta$**：$|\mathcal{H}| e^{-\epsilon m} \leq \delta \Rightarrow m \geq \frac{1}{\epsilon}(\ln|\mathcal{H}| + \ln\frac{1}{\delta})$。

**直觉一句话**：PAC 的推导走的是「反证」路线——先估「有个坏模型骗过训练」的概率，用并界把所有坏模型打包，再要求这个总概率足够小——**把「要多少样本」变成了「要让骗过训练的概率小于 δ」**。

## 4 从有限到无穷：为什么需要 VC 维PAC 的定义不限于有限假设空间，但样本复杂度公式里的 $|\mathcal{H}|$ 在无穷空间下没有意义（决策树、SVM 核空间都是无穷的）。出路是找一个**能度量假设空间「有效大小」的标量**——即使空间无穷，它在「区分样本」这件事上的「有效复杂度」可能是有限的。这个标量就是下一节的 **VC 维**。<span class="marginnote">「无穷空间有有限的有效复杂度」是 VC 维的神奇之处：线性分类器对应无穷多个超平面，但它们「能打出的不同标签模式」是有限的（平面上最多打散 3 个点）——VC 维数的正是这个「打散能力」。PAC 的框架 + VC 维，就能处理真实世界的无穷假设空间。</span>## 5 数值算例：算出「要多少样本」

把样本复杂度公式用到具体数字上。设假设空间含 $|\mathcal{H}| = 10^5$ 个假设，要求误差 $\epsilon = 0.1$、失败概率 $\delta = 0.01$：

- **第一步，代公式**：$m \geq \frac{1}{\epsilon}\left(\ln|\mathcal{H}| + \ln\frac{1}{\delta}\right) = 10 \times (\ln 10^5 + \ln 100)$；
- **第二步，算对数**：$\ln 10^5 \approx 11.5$、$\ln 100 \approx 4.6$，合计约 $16.1$；
- **第三步，得答案**：$m \geq 161$——约 **161 个样本**就能以 0.99 概率学到误差 ≤ 0.1 的假设；
- **第四步，看敏感度**：把误差要求收紧到 $\epsilon = 0.05$，样本数翻倍到约 322；把 $\delta$ 从 0.01 收紧到 $10^{-4}$，样本只多 $\frac{1}{0.1}\ln 10000 \approx 92$——**误差目标主导样本量，概率保证的边际成本很低**。

**直觉一句话**：PAC 把「要多少数据」变成了一道可代入的算术题——误差定规模、概率定尾巴、空间大小定常数。<span class="marginnote">公式里 $\epsilon$ 在分母、$\ln|\mathcal{H}|$ 在分子，决定了两种「加数据」的回报差异：为把误差减半必须把样本翻倍（$1/\epsilon$ 线性），而把假设空间扩大一万倍只多要十几个样本（$\ln$ 项）。工程上这个不对称很有用：模型容量可以大方加，误差要求才是真正吃数据的地方。</span>

**三条常见误区**
1. 把 PAC 的「概率」当可有可无——δ 是必要让步；
2. 忽略样本复杂度与 ε 成反比的标度；
3. 以为 PAC 保证找到最优——只保证近似正确。

**核心结论**
1. PAC = 以 1−δ 概率找到误差 ≤ ε 的假设；
2. 样本复杂度 m ≥ (ln|H|+ln(1/δ))/ε；
3. 推导用并界打包坏假设；
4. 无限空间需 VC 维替代 ln|H|。

**常见面试题**
1. 问：PAC 的 ε 与 δ 各指什么？ 答：ε 是误差上限、δ 是失败概率。
2. 问：为什么并界是关键步骤？ 答：把所有「骗过训练集」的坏假设概率打包，令其 ≤ δ。

**一句话记忆**
PAC = 以 1−δ 概率找到误差 ≤ ε 的假设；样本量公式给出「要多少数据」。

## 6 小结- **PAC 学习**：以至少 $1-\delta$ 概率，找到泛化误差 ≤ $\epsilon$ 的假设——「概率近似正确」。- 两个放松（近似 $\epsilon$ + 概率 $\delta$）是有限样本下的必要让步。- 有限假设空间的**样本复杂度**：$m \geq \frac{1}{\epsilon}(\ln|\mathcal{H}| + \ln\frac{1}{\delta})$。- 推导用**并界**：把所有「骗过训练集的坏假设」的概率打包，令其 ≤ $\delta$。- 无穷假设空间需用 **VC 维**替代 $\ln|\mathcal{H}|$——下一节的主题。
