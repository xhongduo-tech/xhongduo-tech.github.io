## 为什么从 L1 正则化开始

过滤式（Relief）与包裹式（LVW）都把「特征选择」和「模型训练」分成两步：先选特征、再训练。但有一种更优雅的路线——**把特征选择融进训练过程**：让训练算法自己「顺手」把无关特征的权重压成 0，训练完特征选择也自动完成了。这就是**嵌入式选择（embedded selection）**，而它最有力的工具是 **L1 正则化**。

L1 正则化的魔力一句话就能概括：**给损失函数加上「权重绝对值之和」，最优解里会有一批权重恰好变成 0。** 权重为 0 意味着对应特征「说了不算」——于是特征被自动丢弃，稀疏性（sparsity）在优化中自然涌现。这一节讲清 L1 为什么稀疏、与 L2 的区别、以及怎么求解。<span class="marginnote">L1 正则化是「稀疏学习」的大门，也是统计与机器学习最有影响力的思想之一：LASSO（Tibshirani, 1996）把 L1 引入线性回归，此后它在高维统计、信号处理、压缩感知（第11章末）里无处不在。而「让权重归零」这件事，在深度学习的剪枝、大模型的稀疏化里也是核心手法。</span>

## 1 正则化回顾：L2 与 L1以线性回归为例，给目标函数加正则项：- **L2 正则化（岭回归）**：$\min_{\boldsymbol{w}} \sum_i (y_i - \boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i)^2 + \lambda \|\boldsymbol{w}\|_2^2$——惩罚**平方和**；- **L1 正则化（LASSO）**：$\min_{\boldsymbol{w}} \sum_i (y_i - \boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i)^2 + \lambda \|\boldsymbol{w}\|_1$——惩罚**绝对值之和**。

两者都让权重「变小」以防过拟合，但性质完全不同：**L2 把权重均匀地压小，L1 把权重「清零」**。<span class="marginnote">「L2 压缩、L1 清零」这一对对比，是稀疏学习最核心的记忆点。深度学习中 L2 权重衰减已是标配；而 L1 则用于「让模型更精简」的场景。两者还能组合（弹性网 Elastic Net，即 $\lambda_1\|\boldsymbol{w}\|_1 + \lambda_2\|\boldsymbol{w}\|_2^2$），兼顾「稀疏」与「稳定」。</span>

## 2 公式解析：为什么 L1 会「归零」而 L2 不会几何直觉最能说明问题。设只有两个特征，权重解空间里，损失函数的**等值线**是椭圆族（中心是最小二乘解），正则项约束是一个「可行域」：- **L2 可行域是圆**：椭圆与圆相切点通常**不在坐标轴上**——解的两个分量都非零，只是都被压小；- **L1 可行域是菱形**：菱形有**尖角（顶点）**在坐标轴上，椭圆与菱形相切时，切点**很容易落在顶点**——解的一个分量为 0。

形式化地，L1 正则化问题的最优解满足「软阈值」性质。对**正交设计**（各特征不相关）的 LASSO，解为

$$\hat{w}_j = \text{sign}(\tilde{w}_j) \cdot \max\left(0, \; |\tilde{w}_j| - \lambda/2\right)$$

其中 $\tilde{w}_j$ 是普通最小二乘解。<span class="marginnote">「软阈值」公式是整个稀疏学习的核心：$|\tilde{w}_j| \leq \lambda/2$ 的系数被<strong>直接置零</strong>，大于阈值的被<strong>收缩</strong>一个固定量 $\lambda/2$。把「比阈值小的分量清零」这一步，就是 L1 产生稀疏性的机制——而 L2 对应的「岭估计」$\hat{w}_j = \tilde{w}_j/(1+\lambda)$ 只是整体缩小，永远不会归零。</span>

**第一步，看阈值化**：$|\tilde{w}_j| - \lambda/2$ 若为负，则取 $\max(0, \cdot)$ 后为 0——**弱特征被清零**；
**第二步，看收缩**：$|\tilde{w}_j| > \lambda/2$ 的强特征，也被减掉 $\lambda/2$——**整体向零收缩**；
**第三步，看 $\lambda$ 的角色**：$\lambda$ 越大，阈值越高，清零的特征越多——**$\lambda$ 就是「稀疏度旋钮」**；
**第四步，对照 L2**：岭估计 $\tilde{w}_j/(1+\lambda)$ 只缩小不置零——所以 L2 不稀疏。

**直觉一句话**：L1 的菱形「尖角」让解更容易落在坐标轴上——**几何上被压成 0，代数上是软阈值**，两个视角殊途同归。

## 3 嵌入式选择怎么「选特征」在 LASSO（或其他带 L1 的模型）训练完成后：- 权重 $\hat{w}_j \neq 0$ 的特征**被保留**；- 权重 $\hat{w}_j = 0$ 的特征**被剔除**。

训练一次，特征选择自动完成——不需要像 LVW 那样反复训练。这就是「嵌入式」：**选择内嵌于训练过程**。实际工程里常用 **L1 结构化稀疏**（如组稀疏 Group LASSO，让整组特征一起进一起出），以及把 L1 用于逻辑回归、SVM 等模型。

**辨析｜易错点：** L1 选择的特征**不保证「真实重要」**——它只是「在最小化训练损失 + L1 惩罚的意义上最有用的特征」。当特征高度相关时，L1 会**任意地只保留其中一个**（系数在相关的特征间随机分配），选哪个带偶然性。所以「L1 选了谁」要谨慎解读，必要时用「稳定性选择」重复多次看哪些特征总被选中。<span class="marginnote">「L1 在相关特征间随机挑一个」是它的著名弱点，也是它与 L2（相关特征系数分摊）的本质差异之一。对「选哪些特征」敏感的金融、医疗场景，常用「稳定性选择（stability selection）」——多次重采样跑 L1，只保留高频被选中的特征。</span>

## 4 怎么求解：梯度不光滑的挑战$\|\boldsymbol{w}\|_1$ 在 0 点不可导，普通梯度下降不能直接用。两类主流解法：- **近端梯度下降（Proximal Gradient Descent）**：把损失拆成「光滑部分 + 非光滑部分」，光滑部分走梯度、非光滑部分做**近端算子**（对 L1 就是软阈值），交替迭代——现代稀疏求解的默认框架。- **坐标下降（Coordinate Descent）**：每次只优化一个坐标，固定其余——L1 的软阈值解使每步更新闭式、极快，sklearn 的 LASSO 就用它。<span class="marginnote">坐标下降与近端梯度是「稀疏优化」的两大实用算法。它们与第5章 BP 的「逐层更新」、第9章 k 均值的「逐变量交替」共享同一个「分而治之的迭代」气质——把整体问题拆成局部可解的块，循环逼近。</span>

**辨析｜易错点：** L1 的解**不唯一**时（如特征相关导致损失等值面与菱形相切于一整条边），优化器会选到一个特定的稀疏解——但并非「唯一正确答案」。这是优化方法的选择问题，不是错误。

## 知识速查：嵌入式选择与 L1

**本节关键词**
- L1 正则
- LASSO
- 软阈值
- 稀疏性
- L2 正则
- 近端梯度
- 坐标下降
- 组稀疏

**三条常见误区**
1. 把 L1 当「更强的正则」——它清零而 L2 只缩小；
2. 忽略 L1 在相关特征间任意挑选；
3. 以为 L1 问题可直接梯度下降——0 点不可导。

**核心结论**
1. L1 正则让弱特征权重归零；
2. 几何上菱形尖角、代数上软阈值；
3. L2 只缩小不归零；
4. 近端梯度/坐标下降是求解器。

**常见面试题**
1. 问：L1 与 L2 的关键行为差异？ 答：L1 清零、L2 压缩。
2. 问：为什么 L1 在相关特征间任意挑？ 答：解不唯一时优化器选到任一稀疏解。

**一句话记忆**
L1 = 菱形尖角让解落坐标轴，软阈值让弱特征清零。

## 5 小结- **嵌入式选择**把特征选择融进训练：训练完，权重为 0 的特征即被剔除。- **L1 正则化**（LASSO）惩罚 $\|\boldsymbol{w}\|_1$，几何上因**菱形尖角**让解落在坐标轴，代数上是**软阈值**——弱特征被清零。- **L2 正则化**（岭回归）只把权重压小、不归零，所以不稀疏。- $\lambda$ 是稀疏度旋钮：$\lambda$ 越大，清零特征越多。
- 求解用**近端梯度 / 坐标下降**；L1 在相关特征间可能任意挑选，需谨慎解读。
