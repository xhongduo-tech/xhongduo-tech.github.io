## 为什么从学习与推断开始

前三节我们认识了三种概率图模型（HMM、MRF、CRF）。但「会建模」不等于「会用」——两个根本问题悬而未决：**学习**（参数从哪来）与**推断**（给定证据，怎么算后验）。这一节把这两件事放在一起，看它们如何共享同一个核心武器：**利用图结构的分解**。

推断问「已知部分变量，求另一些变量的后验」（第7章贝叶斯网已见）；学习问「从数据估计参数」。两者看似不同，但都卡在同一个敌人面前：**联合分布的求和/最大化是组合爆炸**。而图的局部结构——链、树、稀疏图——恰恰提供了解药：把全局计算拆成局部计算。这一节以**变量消去**与**消息传递**为主线，讲清「图结构如何让推断与学习可行」以及「复杂到什么时候就不可行了」。<span class="marginnote">「推断与学习共享同一套局部化武器」是第14章的枢纽：HMM 的前向算法、CRF 的 Viterbi、贝叶斯网的后验、MRF 的配分函数——全是「利用链/树/稀疏结构的动态规划」。理解变量消去，等于理解了一半图模型计算的本质。</span>

## 1 推断：变量消去**推断**的目标（以贝叶斯网为例）：已知证据变量，求查询变量的后验 $P(X_Q \mid X_E)$。联合分布可分解为 $P(\boldsymbol{x}) = \prod_i P(x_i \mid pa_i)$，但我们要的边缘后验需要对无关变量求和——**直接求和是指数级**。**变量消去（variable elimination）**利用分解的「乘法结构」，**逐变量求和（消去）**，把大求和拆成小求和。设要求 $P(x_5)$，联合分布里有因子 $\psi(x_1,x_2), \psi(x_3,x_4), \psi(x_5)$ 等，则：

$$P(x_5) = \sum_{x_4} \sum_{x_3} \sum_{x_2} \sum_{x_1} \prod \psi(\cdot) \;\xrightarrow{\text{逐变量消去}}\; \text{先消 } x_1, \text{再消 } x_2, \dots$$

每消一个变量，就把它相关的因子**乘起来再求和**，得到一个「关于剩余变量的中间因子」，替代原先一组因子。<span class="marginnote">变量消去的每一步都是「乘局部因子 → 对某变量求和」——像逐步「压缩」概率表。复杂度取决于「消去过程中中间因子的最大变量数」（树宽），而非总变量数。图越稀疏，中间因子越小，推断越可行——这就是「图结构决定推断代价」的精确形态。</span>

## 2 公式解析：变量消去的一次操作设图中有因子 $\psi_1(x_1, x_2)$、$\psi_2(x_2, x_3)$，要求边缘 $P(x_3)$（求和掉 $x_1, x_2$）。直接算：$P(x_3) = \sum_{x_2}\sum_{x_1}\psi_1(x_1,x_2)\psi_2(x_2,x_3)$。- **第一步，看朴素复杂度**：若每个变量取 $K$ 个值，先对 $x_1, x_2$ 双变量求和，是 $K^2$ 量级；
- **第二步，交换求和顺序**：$P(x_3) = \sum_{x_2} \psi_2(x_2,x_3) \left[\sum_{x_1}\psi_1(x_1,x_2)\right]$——$\psi_1$ 不含 $x_3$，可以**先对 $x_1$ 求和**；
- **第三步，看中间因子**：$\sum_{x_1}\psi_1(x_1,x_2) = \phi(x_2)$ 只关于 $x_2$——一个 $K$ 大小的表，替代了 $K^2$ 的表；
- **第四步，收尾**：$P(x_3) = \sum_{x_2} \psi_2(x_2,x_3)\phi(x_2)$——最后对 $x_2$ 求和，得 $x_3$ 的边缘。

**直觉一句话**：变量消去把「一次算完的大求和」拆成「一维一维地消」——每消一个变量只付出该变量「局部邻域」的代价，全局复杂度由图的**树宽**决定。

## 3 消息传递与信念传播变量消去是「一次性」的（为每个查询重跑）。**信念传播（belief propagation）**把它升级为「一次算完、处处可得」：在**树结构**上，每个节点向邻居**传递消息（message）**——「我这边对『你的取值』的看法」。消息沿树传播两轮（叶→根、根→叶），每个节点的**信念（belief）**即后验：$$b_i(x_i) \propto \phi_i(x_i) \prod_{k \in N(i)} m_{k \to i}(x_i)$$

其中 $m_{k \to i}$ 是从邻居 $k$ 传来的消息。**树结构上信念传播给出精确后验**；对带环的图，**环信念传播（loopy BP）**不保证精确但常常给出很好的近似。<span class="marginnote">「消息 = 邻居对我的看法」是信念传播的社交隐喻：每个人综合所有邻居传来的「对我每种取值的支持度」，归一化后就是我的后验。树结构保证消息不「打架」（没有环），从而精确；有环时消息会在环里打转，变成近似——这为下一节《近似推断》埋下伏笔。</span>

## 4 学习：完备与不完备数据**学习**分两种情形：- **完备数据**：所有变量都被观测。此时**极大似然**有闭式解——参数就是「条件概率表的频率计数」（贝叶斯网）或「最大化条件似然的梯度」（CRF）。有向图可以直接计数；无向图要算配分函数，用梯度/迭代方法。
- **不完备数据（含隐变量/缺失）**：似然不可直接最大化，用**EM 算法**（第7章）——E 步用当前参数对隐变量做推断（正好用到前向/信念传播），M 步按「补全的后验」重估参数。<span class="marginnote">「学习中的推断」是图模型的一条暗线：EM 的 E 步要推断隐变量的后验，CRF 的梯度里要算「模型期望」（本质也是推断），Viterbi 用于「硬 EM」。<strong>学图模型 = 反复做推断</strong>——这也是为什么「推断快不快」直接决定「学习能不能跑」。深度时代把「推断」换成「前向传播」，同理。</span>

## 5 学习的复杂度边界：NP 难**辨析｜易错点：** 精确推断与学习**不总是可行**。一般图上的精确推断是 **NP 难**的——树宽可以大到等于变量数，变量消去退化为指数枚举。所以图模型的应用有一个基本判断：- 图是**链/树/低树宽**：精确推断可行（HMM、CRF、树贝叶斯网）；
- 图是**高树宽/稠密**：精确推断不可行，必须用**近似推断**——下一节的 MCMC 与变分推断。

**「能否精确推断由树宽决定」是图模型计算的铁律**，它把图模型分成「可解」与「必须近似」两半。<span class="marginnote">树宽与 NP 难的关系：树宽 = 消去过程中最大中间因子的大小。树宽小（链、树）→ 多项式；树宽大（稠密图）→ 指数。这也是为什么现实建模总是尽量用「稀疏图」——不是图越复杂越好，而是<strong>「够用的结构 + 可解的树宽」</strong>才是工程正解。</span>

## 知识速查：学习与推断

**本节关键词**
- 变量消去
- 信念传播
- 消息传递
- 树宽
- MLE
- EM
- NP 难
- 精确/近似

**三条常见误区**
1. 把推断当「枚举求和」——变量消去靠图结构压缩；
2. 忽略树宽决定可解性；
3. 以为学习与推断无关——学图模型 = 反复做推断。

**核心结论**
1. 变量消去逐变量求和、复杂度由树宽决定；
2. 信念传播在树上给精确后验、带环是近似；
3. 学习：完备数据 MLE、不完备用 EM；
4. 高树宽图上精确推断 NP 难。

**与全书/后续的连接**
- 第7章贝叶斯网推断；
- 第14章 HMM/CRF 的动态规划；
- 第14章近似推断承接 NP 难。

**常见面试题**
1. 问：树宽为什么决定推断可行性？ 答：它等于消去过程中最大中间因子的大小。
2. 问：为什么学图模型=反复做推断？ 答：EM 的 E 步、CRF 的梯度都要算推断。

**一句话记忆**
推断与学习共享同一武器：利用图结构把全局计算拆成局部计算，树宽决定代价。

## 6 小结- **推断**（求后验）与**学习**（估参数）都靠「利用图结构分解」来对抗组合爆炸。- **变量消去**：逐变量「乘局部因子 → 求和」，复杂度由**树宽**决定。- **信念传播**：消息在树上传播，一轮「叶↔根」后各节点得到精确后验；带环图是近似（loopy BP）。
- **学习**：完备数据用 MLE（有向可计数、无向要梯度）；不完备数据用 **EM**（E 步即推断）。
- 精确推断对高树宽图是 **NP 难**——必须转入近似推断。
