## 为什么从任务与奖赏开始

第16章是西瓜书的最后一章，也是一个全新的世界：前十五章都是「给定数据学映射」——要么有监督（带标记），要么无监督（无标记）。但有一类学习不是「学数据」，而是**学决策**：智能体（agent）在环境（environment）里行动、获得奖赏、调整策略，目标是在长期里拿到**尽可能多的总奖赏**。下棋、玩游戏、机器人控制、自动驾驶——都是这类**强化学习（Reinforcement Learning, RL）**任务。

为什么 RL 与前面的学习根本不同？因为它没有「标准答案」，只有**延迟的奖赏**：走一步棋不知道好不好，要到最后胜负才知道。学习必须回答「哪一步棋导致了最终胜利」——这是**信用分配**问题在决策层的版本。这一节先立起 RL 的范式：智能体、环境、状态、动作、奖赏、策略。<span class="marginnote">强化学习与「从极限到大模型」主线的连接很直接：AlphaGo 用 RL 下赢围棋、ChatGPT 用 RLHF（人类反馈强化学习）对齐价值观——RL 是「大模型时代最后的训练阶段」。学完这一章，你就能读懂「为什么大模型要 RLHF」：因为「让模型变聪明」是监督学习，「让模型听话」是强化学习。</span>

## 1 范式：智能体与环境**强化学习**的核心图景：- **智能体（agent）**：学习者/决策者——下棋的选手、开车的系统、对话的模型；
**环境（environment）**：智能体之外的世界——棋盘、路况、对话对象；
**交互循环**：智能体观测到**状态（state）**$s$，选择**动作（action）**$a$，环境反馈**奖赏（reward）**$r$ 并转移到新状态 $s'$，循环往复。

**策略（policy）$\pi$** 是智能体的「大脑」：从状态到动作的映射（$\pi(s) = a$，或 $\pi(a\mid s)$ 给动作的概率）。**学习 = 改进策略**，让它选择的动作带来更多累计奖赏。<span class="marginnote">「智能体-环境-奖赏」是 RL 的第一性图景，几乎所有 RL 术语都从这张图里长出来。它与监督学习的关键差异一目了然：监督学习有「老师给的答案」，RL 只有「环境给的奖赏信号」——奖赏是稀疏的、延迟的、需要智能体自己「悟」出来的。这也是 RL 更接近「动物学习」而非「老师教学」的原因。</span>

## 2 奖赏：RL 的唯一老师**奖赏（reward）$r$** 是环境对「动作好不好」的即时反馈。但 RL 的目标不是「最大化即时奖赏」，而是**最大化累计奖赏**——长期收益。因为一步好棋可能暂时吃亏（弃子争先），RL 必须「放长线」。**累计奖赏**的两种常用形式：

**有限步**：$G = \sum_{t=1}^{T} r_t$（总步数有限，如一盘棋有终局）；
**折扣累计（无限步）**：$G_t = \sum_{k=0}^{+\infty} \gamma^{k} r_{t+k+1}$，其中 $\gamma \in (0,1)$ 是**折扣因子**——未来的奖赏打个折（今天的 1 元比明天的 1 元值钱）。

**辨析｜易错点：** 奖赏设计决定学习方向——**给错了奖赏，学出的策略就「跑偏」**。著名的「奖赏黑客（reward hacking）」：如果教机器人打扫房间、奖励是「灰尘减少」，机器人可能学会「把灰尘藏到地毯下」。**奖赏是 RL 里最需要慎重设计的部分**。<span class="marginnote">「折扣因子 $\gamma$ 的意义」：$\gamma$ 接近 1 → 智能体更看重长远收益（有远见）；$\gamma$ 接近 0 → 智能体更看重眼前（短视）。它像「耐心系数」，是 RL 里少数几个全局超参数之一。而「奖赏设计」在 RLHF 里就是「给人类偏好打分」——大模型对齐的成败，一半在奖赏模型设计得好不好。</span>

## 3 公式解析：为什么未来要打折折扣累计奖赏 $G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}$ 的「折扣」看似随意，其实有三重理由：- **第一步，看数学收敛**：若每步奖赏有界（$|r| \leq R_{\max}$），则 $\sum \gamma^k r \leq \frac{R_{\max}}{1-\gamma}$——**等比级数收敛**，无限和的累计奖赏有限、可比较；
**第二步，看经济直觉**：$\gamma^k$ 是「$k$ 步后的奖赏打 $\gamma^k$ 折」——未来不确定、资金有时间价值，**眼前的鸟比林中的鸟值钱**；
**第三步，看算法需求**：折扣让「有限期的无限问题」变成可解的马尔可夫决策过程（下一节的核心）——$\gamma < 1$ 保证值函数有界、迭代收敛；
**第四步，看递推形式**：$G_t = r_{t+1} + \gamma G_{t+1}$——**累计奖赏满足「当前奖赏 + 折扣的未来」**，这个递推是后面所有值函数算法的钥匙。

**直觉一句话**：折扣把「无穷远的未来」压缩成「有限的总价值」——既符合「远水解不了近渴」的直觉，又让数学上可解，还自然导出「当前 + 折扣未来」的递推。

## 4 核心对比表：三种学习范式| 维度 | 监督学习 | 无监督学习 | 强化学习 || --- | --- | --- | --- || 数据形式 | 输入-标记对 | 无标记数据 | **状态-动作-奖赏轨迹** |
| 反馈 | 立即（有答案） | 无（找结构） | **延迟（奖赏）** |
| 学习目标 | 学映射 | 发现结构 | **学策略（决策）** |
| 关键挑战 | 泛化 | 结构合理性 | **信用分配** |
| 交互 | 一次性 | 一次性 | **持续交互** |
| 典型应用 | 分类/回归 | 聚类/降维 | 游戏、控制、对齐 |

**直觉**：监督学习像「跟老师做题」，无监督像「自己整理笔记」，强化学习像「边做边学的实践者」——**RL 的唯一反馈是奖赏，必须自己从延迟的奖赏里悟出因果**。<span class="marginnote">「信用分配」是 RL 独有的核心难题：下完一整盘棋，只有最后「赢/输」一个信号——是哪一步棋的功劳？RL 的所有算法（值函数、策略梯度、时序差分）本质上都在回答「如何把最后的奖赏合理地分配到每一步」。这也是 RL 比监督学习更「硬核」的地方：监督学习的误差信号是局部的、即时的，RL 的奖赏是全局的、延迟的。</span>

## 知识速查：强化学习任务与奖赏

**本节关键词**
- 强化学习
- 智能体
- 环境
- 状态
- 动作
- 奖赏
- 策略

**三条常见误区**
1. 把 RL 当监督学习——奖赏延迟、无标准答案；
2. 忽略「信用分配」是 RL 独有难题；
3. 以为奖赏给得越细越好——奖赏设计决定行为方向。

**核心结论**
1. RL 是智能体-环境-奖赏的交互学习；
2. 目标是最大化累计奖赏而非即时奖赏；
3. 折扣因子 γ 让无限和可解；
4. 信用分配是 RL 独有难题。

**与全书/后续的连接**
- 第16章 K 臂赌博机是简化版；
- 大模型 RLHF 的奖赏模型；

**常见面试题**
1. 问：为什么 RL 没有「标准答案」？ 答：只有延迟奖赏，没有即时正确的动作标签。
2. 问：折扣因子的作用？ 答：给未来奖赏打折，保证累计奖赏有限、可比较。

**一句话记忆**
RL = 智能体在环境里行动、获奖赏、改策略，目标是最大化长期累计奖赏。

## 5 小结- **强化学习**是「智能体-环境-奖赏」的交互式学习：学策略，最大化长期累计奖赏。- 核心元素：**状态 $s$、动作 $a$、奖赏 $r$、策略 $\pi$**；学习 = 改进策略。- 目标是**累计奖赏**而非即时奖赏；折扣形式 $G_t = \sum_k \gamma^k r_{t+k+1}$ 让无限和可解、并给出递推 $G_t = r_{t+1} + \gamma G_{t+1}$。
- 与监督/无监督的关键差异：**延迟奖赏 + 信用分配**。
- 奖赏设计极其重要——奖赏错了，策略就偏了（reward hacking）。
