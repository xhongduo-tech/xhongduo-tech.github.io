## 为什么从值函数近似开始

前面的 Q-learning、Sarsa 都用一个**查找表（lookup table）**存 Q 值——每个「状态-动作」对一行。但真实任务的状态空间大到爆炸：围棋 $10^{170}$ 个状态、机器人连续的姿态、图像像素的组合——**查表根本不现实**，绝大多数状态一辈子都没见过一次。怎么办？

**值函数近似（value function approximation）**的回答：不查表，用**一个参数化的函数** $Q_\theta(s,a)$ 去**近似**真正的 Q 函数。参数 $\theta$ 通常远少于状态数，因此**没见过的新状态也能被「推算」出价值**——这就是**泛化**：学到的不是「一堆格子的值」，而是「一种关于状态价值的规律」。当近似函数是神经网络时，就是**深度强化学习**——DQN 由此登上历史舞台。<span class="marginnote">「查表 → 函数近似」是 RL 从「经典」走向「深度」的分水岭：查表只能处理小状态空间，函数近似让 RL 能处理「状态连续、海量、未见」的真实任务（像素输入、机器人关节角、对话历史）。它借的就是第5章神经网络「从数据泛化」的能力——把「记住状态价值」升级为「学会状态价值」。</span>

## 1 近似：用参数函数代替查表设 $\boldsymbol{\theta}$ 是参数向量（线性近似的权重，或神经网络的权重），目标是找
$$Q_{\boldsymbol{\theta}}(s, a) \approx Q^{\pi}(s, a), \qquad V_{\boldsymbol{\theta}}(s) \approx V^{\pi}(s)$$

近似函数把「状态-动作」映射到「价值」。**学习方式**：像监督学习一样最小化「预测与目标」的误差——目标来自 TD（上一节）：$r + \gamma Q_{\boldsymbol{\theta}}(s', a')$ 或 $r + \gamma \max_{a'}Q_{\boldsymbol{\theta}}(s',a')$。

**梯度更新**（以 Q-learning 目标为例）：

$$\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} + \alpha\left[ r + \gamma \max_{a'} Q_{\boldsymbol{\theta}}(s', a') - Q_{\boldsymbol{\theta}}(s, a) \right]\nabla_{\boldsymbol{\theta}} Q_{\boldsymbol{\theta}}(s, a)$$

——「TD 误差 × 预测对参数的梯度」，与第5章 BP 的「误差 × 梯度」同构。<span class="marginnote">「值函数近似 = 用监督学习的方法学一个回归函数，只是标签由 TD 目标动态产生」——这是理解深度 RL 的最短路径。它不是「给定标签学映射」，而是「目标本身在变」（用当前估计当标签），所以它本质是「自举 + 近似」的双重近似，这让收敛分析远比普通监督学习困难。</span>

## 2 线性近似与神经网络近似- **线性近似**：$Q_{\boldsymbol{\theta}}(s,a) = \boldsymbol{\theta}^{\mathrm{T}}\boldsymbol{\phi}(s,a)$，用状态-动作的**特征** $\boldsymbol{\phi}$ 线性组合。理论性质好（某些条件下保证收敛），但表达力有限、依赖手工特征。- **神经网络近似**：$Q_{\boldsymbol{\theta}}(s,a)$ 是一层层非线性变换，**特征自动学习**。表达力强、无需手工特征，但带来新的不稳定问题——于是有了 DQN 的三大技巧。

**辨析｜易错点：** 神经网络 + RL 的「不稳定」根源在于**三大关联**：

1. **样本相关**：RL 的连续轨迹里相邻样本高度相关（不满足监督学习「独立同分布」假设）；
2. **目标漂移**：TD 目标用「当前参数」计算，参数一变、目标就变——学一个「移动的靶子」；
3. **动作-值耦合**：$Q$ 的微小变化可能翻转动作选择，导致剧烈波动。<span class="marginnote">「三大不稳定来源」是深度 RL 独有的困境，也是 DQN 论文（Nature 2015）最著名的贡献点。普通监督学习的「固定数据集 + 固定目标」在 RL 里全部失效——理解这三条，就理解了为什么「深度强化学习」比「深度监督学习」难这么多。</span>

## 3 公式解析：DQN 如何稳住学习**DQN（Deep Q-Network）**用三个技巧化解不稳定：
$$L(\boldsymbol{\theta}) = \mathbb{E}\left[ \left( r + \gamma \max_{a'} Q_{\boldsymbol{\theta}^-}(s', a') - Q_{\boldsymbol{\theta}}(s, a) \right)^2 \right]$$

- **第一步，看目标网络（target network）**：TD 目标用**固定的目标网络** $Q_{\boldsymbol{\theta}^-}$（参数 $\boldsymbol{\theta}^-$ 定期从 $\boldsymbol{\theta}$ 拷贝，平时不动）——**目标不再每步漂移**，化解「目标漂移」；
- **第二步，看经验回放（experience replay）**：把交互的「转移」$(s,a,r,s')$ 存进**经验池**，训练时**随机抽样**小批量——打散样本相关性、重复利用数据，化解「样本相关」；
- **第三步，看损失**：最小化「TD 目标（用目标网络算）− 当前预测」的平方——标准的监督式回归；
- **第四步，看整体**：DQN = Q-learning + 目标网络 + 经验回放 + 卷积网络（处理像素输入）——四个组件各治一个「病」。

**直觉一句话**：DQN 把「会飘、会相关、会翻转」的 RL 训练，改造成「目标固定、样本打散」的监督式回归——**用「冻结目标」与「随机回放」两个技巧，把深度学习的稳定搬进 RL**。<span class="marginnote">DQN 在 2013/2015 年用「像素 + 神经网络」在 Atari 游戏上超越人类，是深度强化学习的开山之作。它的「目标网络 + 经验回放」至今是几乎所有深度 off-policy 算法的标准组件——理解 DQN，等于理解了深度 RL 的「工程稳定学」。</span>

## 4 辨析：近似的代价与边界**辨析｜易错点：**
**函数近似不保证收敛**：经典 Q-learning 查表保证收敛；加上近似后（尤其非线性近似），**收敛性不再是定理**——只能靠工程技巧（目标网络、回放、调整学习率）实践上稳住；
**近似误差会累积**：$Q_{\boldsymbol{\theta}}$ 的近似误差通过自举向后传播，长期可能放大（但实践中可控）；
**对状态特征的依赖**：线性近似的好坏取决于手工特征；神经网络近似则「特征自动学」，但要更多数据与调参。

**直觉**：值函数近似用「泛化」换「精度」——它牺牲了查表式的精确保证，换来了处理海量状态的能力；深度 RL 的全部技巧，都是在这个「换」里尽量稳住。<span class="marginnote">值函数近似也是「从状态价值到策略」的桥梁：有了可泛化的 $Q_{\boldsymbol{\theta}}$，策略就是「每步选 $Q_{\boldsymbol{\theta}}$ 最大的动作」——这被称为「贪心 + 近似」或「演员-评论家」中的评论家部分。下一节的「策略梯度」则直接学策略函数本身，是另一条路线——值函数近似与策略函数近似合起来，构成了深度 RL 的两大支柱。</span>

## 知识速查：值函数近似

**本节关键词**
- 函数近似
- DQN
- 目标网络
- 经验回放
- 三大不稳定
- 深度 RL
- TD 误差
- 泛化

**三条常见误区**
1. 把近似当查表——它要泛化到未见状态；
2. 忽略样本相关/目标漂移/动作翻转三大不稳定；
3. 以为 DQN 保证收敛——近似下收敛是工程问题。

**核心结论**
1. 值函数近似用参数化函数代替查表；
2. DQN 用目标网络冻结目标、经验回放打散样本；
3. 三大不稳定：样本相关/目标漂移/动作翻转；
4. 近似不保证收敛、靠工程技巧稳住。

**与全书/后续的连接**
- 第5章神经网络作为函数近似器；
- 第16章 Q-learning 是 DQN 的母版；
- 深度 RL 专题展开。

**常见面试题**
1. 问：为什么 RL 的样本不满足 iid？ 答：连续轨迹中相邻样本高度相关。
2. 问：目标网络解决了什么？ 答：TD 目标不再每步随参数漂移。

**一句话记忆**
值函数近似 = 用参数化函数代替查表，DQN 用目标网络+回放稳住学习。

## 5 小结- **值函数近似**用参数化函数 $Q_{\boldsymbol{\theta}}(s,a)$ 代替查表，让 RL 能处理海量/连续/未见状态——「从记住到泛化」。- 更新公式：$\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} + \alpha(\text{TD 误差})\nabla_{\boldsymbol{\theta}}Q_{\boldsymbol{\theta}}(s,a)$——「误差 × 梯度」。
- **线性近似**理论好但靠手工特征；**神经网络近似**表达力强但引入三大不稳定。
- **DQN** = Q-learning + **目标网络**（冻结目标）+ **经验回放**（打散样本）——化解三大不稳定。
- 函数近似牺牲「收敛保证」，换取「处理大状态空间」——深度 RL 的技巧都是为稳住这个交换。
