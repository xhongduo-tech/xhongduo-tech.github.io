## 为什么从马尔可夫随机场开始

上一节的 HMM 是**有向**图模型：边有方向（状态 → 状态、状态 → 观测），方向表示「因果/生成」关系。但现实中有很多关系是**双向的、非因果的**：图像里一个像素与周围像素互相影响（没有「谁导致谁」）、一张社交网络里邻居之间相互感染。表达这类「互惠」关系，需要**无向**图模型——**马尔可夫随机场（Markov Random Field, MRF）**。

MRF 是第14章的第二块基石，也是图像去噪、分割、以及很多物理系统建模的经典工具。它用「**团 + 势函数**」定义联合分布，用「**条件独立**」编码局部性，并第一次让我们直面一个重要的数学对象——**配分函数（partition function）**。<span class="marginnote">「有向 vs 无向」是概率图模型的第一性区别：有向图（贝叶斯网、HMM）用条件概率表、天然支持因果与采样；无向图（MRF、CRF）用势函数、擅长表达对称的局部约束。选择哪类，取决于「依赖是单向生成还是双向约束」——图像像素间是后者。</span>

## 1 无向图与团**马尔可夫随机场**用**无向图**表示变量间的相互依赖：
- 节点 = 随机变量（像素、词性、用户状态）；
- 边 = 变量间的「互相影响」——无方向，表示对称约束。

**团（clique）**：无向图中**两两相连**的节点子集（完全子图）。极大团（maximal clique）是不能被更大团包含的团。**MRF 的核心性质**：变量的联合分布可以分解为**极大团**上的势函数的乘积——局部的「团能量」乘起来定义全局分布。<span class="marginnote">「联合分布 = 团势函数的乘积」是 MRF 的灵魂：它把「全局的复杂分布」拆成「局部小组内的能量」——图像的一个像素只与它所在的小邻域「发生关系」，全局分布由这些局部关系拼接而成。这与 HMM 的「转移 × 发射」分解是同一精神，只是从链推广到了任意图。</span>

## 2 联合分布：团势函数与配分函数设无向图中极大团的集合为 $\mathcal{C}$，每个极大团 $Q$ 有一个**势函数（potential function）**$\psi_Q(\boldsymbol{x}_Q)$（非负），则 MRF 的联合分布为：
$$P(\boldsymbol{x}) = \frac{1}{Z} \prod_{Q \in \mathcal{C}} \psi_Q(\boldsymbol{x}_Q), \qquad Z = \sum_{\boldsymbol{x}} \prod_{Q \in \mathcal{C}} \psi_Q(\boldsymbol{x}_Q)$$

- $\psi_Q$ 度量「该团内变量的某种组合有多「被喜欢」」——势函数越大，该组合越「合理」；
- **配分函数 $Z$** 是归一化常数，对所有可能的 $\boldsymbol{x}$ 求和，保证 $P$ 是概率分布。

**辨析｜易错点：** 势函数**不是条件概率**——它只给出「相对偏好」，不直接等于概率；真正的概率要靠配分函数归一化。这带来一个深层代价：$Z$ 对变量数是指数求和，**计算配分函数一般不可行**——这是无向模型推断（第14章近似推断）困难的根源。<span class="marginnote">「势函数好定义，配分函数算不动」是 MRF 的宿命：$Z = \sum_{\boldsymbol{x}}$ 要遍历所有变量组合（指数级）。所以无向模型的训练与推断几乎总要借助采样（MCMC）或变分近似——这直接引向第14章《近似推断》一节。有向图没有这个坎（条件概率表天然归一），无向图为此买单。</span>

## 3 公式解析：用能量函数理解 MRF势函数通常写成**能量**形式：$\psi_Q(\boldsymbol{x}_Q) = e^{-E_Q(\boldsymbol{x}_Q)}$。于是联合分布变成
$$P(\boldsymbol{x}) = \frac{1}{Z} \exp\left(-\sum_{Q\in\mathcal{C}} E_Q(\boldsymbol{x}_Q)\right)$$

- **第一步，看能量与概率的关系**：能量越小，概率越大——「低能量 = 更合理」；
- **第二步，看乘法变加法**：团势函数的乘积变成能量的**求和**——「每个团的意见相加」；
- **第三步，看图像直觉**：图像去噪里，能量项常是「像素值与观测的一致性」+「相邻像素的平滑性」——能量最小化 = 既忠于观测、又保持平滑；
- **第四步，看结论**：**MRF 的概率建模 = 设计势函数 = 设计能量函数**；推断与学习都是在「低能量区域」做文章。<span class="marginnote">「能量函数」让 MRF 与统计物理（Boltzmann 分布）、以及第5章的 Boltzmann 机直接挂钩——它们都是「能量 → 概率」的框架。现代生成模型（扩散模型的能量视角）也承袭这一脉络。记住「低能 = 合理」这一直觉，很多图模型都好懂了。</span>

## 4 马尔可夫性与条件独立无向图的**马尔可夫性**（马尔可夫性质的推广）：给定某个变量的**所有邻居**，它与**图中其余所有变量**条件独立。即
$$x_i \perp \boldsymbol{x}_{V \setminus (i \cup N(i))} \;\mid\; \boldsymbol{x}_{N(i)}$$

其中 $N(i)$ 是 $x_i$ 的邻居。「知道了邻居，其余都无关」——这是「局部性」的严格表达，也是 MRF 之所以叫「马尔可夫」随机场的原因。<span class="marginnote">马尔可夫性让 MRF 的推断可以「局部地」进行：一个像素的后验只依赖它的邻居——这与图像处理里的「局部滤波」直觉一致。同时它定义了图上的「分离」概念：若两组变量的所有路径都被第三组变量「隔断」，则它们条件独立——这是无向图的 d-分离（称「全局马尔可夫性」）。</span>

## 5 核心对比表：有向图 vs 无向图| 维度 | 有向图（贝叶斯网/HMM） | 无向图（MRF） || --- | --- | --- |
| 边的含义 | 因果/生成方向 | 对称的相互约束 |
| 局部结构 | 条件概率表 $P(x_i\mid pa_i)$ | 势函数 $\psi_Q$（非概率） |
| 联合分布 | $\prod_i P(x_i\mid pa_i)$ | $\frac{1}{Z}\prod_Q\psi_Q$ |
| 归一化 | 天然 | 需**配分函数**（难算） |
| 采样 | 天然（按拓扑序） | 需 MCMC |
| 擅长 | 因果、生成、序列 | 图像、空间局部约束 |

**辨析｜易错点：** 有向图也能表达「相互影响」（用双向边变成环），但无向图是「表达对称约束更自然」的选择。选择原则：**有因果/时序方向用有向，有对称局部约束（图像、网格）用无向**。<span class="marginnote">MRF 的「局部约束 + 能量」框架在 AI 里无处不在：图像去噪/分割（经典 MRF）、语义分割（CRF 后处理）、以及结构化预测。深度学习兴起后，MRF 的势函数常被神经网络参数化（Deep MRF），但「无向局部约束」的骨架未变——第14章《条件随机场》就是 MRF 的判别式变体。</span>

## 知识速查：马尔可夫随机场

**本节关键词**
- MRF
- 无向图
- 团
- 势函数
- 配分函数
- 能量
- 马尔可夫性
- 局部约束

**三条常见误区**
1. 把势函数当条件概率——它要配分函数归一化；
2. 忽略配分函数指数求和、一般不可算；
3. 把「能量低」当硬规则——它是概率偏好。

**核心结论**
1. MRF 用无向图表达对称约束；
2. 联合分布 = 团势函数乘积 / 配分函数；
3. 势函数用能量形式：低能 = 合理；
4. 马尔可夫性：给定邻居与其余条件独立。

**与全书/后续的连接**
- 第5章 Boltzmann 机同源；
- 第14章 CRF 是判别式变体；
- 第14章 MCMC 为它采样。

**常见面试题**
1. 问：为什么配分函数难算？ 答：对所有变量组合指数求和。
2. 问：有向图与无向图的建模区别？ 答：有向表达因果、无向表达对称局部约束。

**一句话记忆**
MRF = 无向图局部约束 + 能量函数定义概率，配分函数是它算不动的宿命。

## 6 小结- **MRF** 用无向图表达变量间的相互约束，联合分布分解为**极大团势函数**的乘积。- 联合分布 $P(\boldsymbol{x}) = \frac{1}{Z}\prod_Q\psi_Q(\boldsymbol{x}_Q)$，**配分函数** $Z$ 使归一化可行但一般不可算。
- 能量视角：$\psi_Q = e^{-E_Q}$，「低能量 = 合理」，概率建模 = 设计能量函数。
- **马尔可夫性**：给定邻居，与其余变量条件独立——局部性即推断的钥匙。
- 有向图擅长因果/生成、无向图擅长对称局部约束；$Z$ 难算是无向模型的推断之痛。
