## 为什么从神经元模型开始

第4章结束，我们用决策树建立了一套「符号式」的机器学习图景：划分、剪枝、规则，每一步都讲得清、看得懂。但从这一章开始，画风突变——我们要进入**神经网络**，一种被许多学者视为「从大脑结构获得启发」的模型家族。它不追求每条规则可读，而追求用大量**简单计算单元**的协作，逼近任意复杂的函数。

一切的起点是一个极其简单的数学对象：**神经元模型**。半个多世纪前，麦卡洛克（McCulloch）与皮茨（Pitts）把生物神经元的「兴奋 / 抑制」抽象成一个加权求和 + 阈值判断的式子。今天支撑起 GPT、AlphaGo 的千亿参数网络，本质上仍是这一式子的**大规模堆叠与改造**。<span class="marginnote">「深度学习再深，也是从 M-P 神经元长出来的」——这句话要留到第5章《深度学习》一节才会完全展开，但今天请先记住神经元是那个最小的积木。</span>

## 1 从生物到数学的抽象生物神经元接受树突传来的电信号，经过整合后，若总刺激超过某个**阈值**，就在轴突上发放一个脉冲（兴奋），否则不发放（抑制）。M-P 神经元模型把这一过程翻译成四个部分：- **输入**：来自其他神经元的信号 $x_1, x_2, \dots, x_n$；- **权重**：$w_1, w_2, \dots, w_n$，表示各条输入「说话的分量」——连接越强权重越大；- **求和与阈值**：加权和 $\sum_i w_i x_i$ 与阈值 $\theta$ 比较；
- **激活函数**：把比较结果映射到输出 $y$，决定最终兴奋程度。

**M-P 神经元（McCulloch-Pitts neuron）**的数学形式：

$$y = f\left(\sum_{i=1}^{n} w_i x_i - \theta\right)$$

当 $f$ 是阶跃函数时，神经元就是一个「加权投票器」：加权和超过 $\theta$ 输出 1（兴奋），否则输出 0（抑制）。<span class="marginnote">注意阈值 $\theta$ 常被改写为 $-b$ 并吸收进求和式：$y = f\left(\sum_i w_i x_i + b\right)$，其中 $b$ 叫<strong>偏置（bias）</strong>。两种写法等价，但偏置记号在神经网络文献里更通用。</span>

## 2 激活函数：让神经元「会说话」若 $f$ 是阶跃函数，输出只有 0/1 两档，这种「硬」激活不可导、不光滑，难以用梯度方法学习。于是需要**连续可导**的激活函数。教材重点介绍了 **sigmoid 函数**：$$\text{sigmoid}(x) = \frac{1}{1 + e^{-x}}$$它把 $(-\infty, +\infty)$ 压缩到 $(0, 1)$，且在 $x=0$ 附近近似线性、两端饱和。**辨析｜易错点：** 阶跃函数与 sigmoid 的差别是「非黑即白」与「程度渐变」。阶跃不可导，无法用梯度下降训练；sigmoid 处处可导，且导数为 $\text{sigmoid}(x)(1 - \text{sigmoid}(x))$——这个漂亮的导数形式在后面的 BP 推导里会反复出现。<span class="marginnote">现代深度网络更常用 ReLU、tanh 等激活函数，但 sigmoid 是理解「为什么激活函数必须是可导非线性的」的第一把钥匙，见下一节《感知机与多层网络》。</span>

## 3 从神经元到网络一个神经元的能力很有限——它是**一条直线**的决策边界（$\sum_i w_i x_i - \theta = 0$）。真正强大的，是把大量神经元**按层组织、互相连接**：- **输入层**：接收外部特征，每个输入神经元对应一个属性值；- **隐含层（隐层）**：不直接与外部交互，负责中间计算；- **输出层**：给出最终预测；
- **连接权**：每条边上的 $w$ 是网络要学的参数。

**神经网络的强大**在于：足够多神经元的恰当连接，可以逼近任意连续函数（这是第5章末尾会讲到的万能逼近直觉）。而**学习**就是调整所有连接权，使网络输出在训练集上逼近真实标记。<span class="marginnote">「连接结构 + 可调权重」这一配方，正是「从数据中自动发现特征组合」的来源——它不需要人手工设计 if-then 规则，这把它与决策树彻底区分开来。</span>

## 4 公式解析：M-P 神经元的一步计算设一个神经元有 3 个输入 $x = (1, 0, 1)$，权重 $\boldsymbol{w} = (0.5, 0.3, -0.8)$，阈值 $\theta = 0.2$，激活为 sigmoid。- **第一步，加权求和**：$\sum_i w_i x_i = 0.5 \times 1 + 0.3 \times 0 + (-0.8) \times 1 = -0.3$。- **第二步，减去阈值（或加偏置）**：$-0.3 - 0.2 = -0.5$。若用偏置形式，$b = -\theta = -0.2$，加权和加偏置 $-0.3 + (-0.2) = -0.5$，结果一致。- **第三步，过激活函数**：$y = \text{sigmoid}(-0.5) = \dfrac{1}{1 + e^{0.5}} \approx 0.378$。

**直觉拆解**：第一条输入「投了赞成票」($0.5$)，第三条「投了反对票」($-0.8$)，净得分 $-0.3$，再被阈值压掉 $0.2$，总刺激为负——神经元整体倾向抑制，输出只有 0.378。**一个神经元做的事，就是「把输入按权重加权、减阈值、过激活」。** 权重符号表示赞成或反对，权重大小表示说话分量，阈值表示「要多大刺激才肯兴奋」——整套机器学习的学习，本质就是把这三个问题在大量神经元上同时答好。


M-P 神经元是 1943 年的「上古」模型，但它的三个组件——加权、阈值、激活——在今天的深度网络里全部健在，只是形式演化：- **加权求和**：被矩阵乘法取代（一层所有神经元的加权求和 = 一个矩阵乘法 $Wx+b$）；- **阈值**：被偏置项 $b$ 取代，且常与权重一起随机初始化；- **激活函数**：从阶跃 → sigmoid → **ReLU**（$\max(0,x)$）→ GELU，一路解决「梯度消失」与「表达力」问题。现代神经元（如 Transformer 里的前馈层）仍是一个「线性变换 + 非线性激活」的单元——**M-P 神经元的骨架没变，变的只是规模、连接方式与训练方法**。**思考题**：为什么现代激活函数（ReLU）在正半轴导数恒为 1，而不是像 sigmoid 那样「饱和」？这与 BP 的梯度传播有什么关系？
## 拓展：神经元的现代演化

M-P 神经元是 1943 年的「上古」模型，但它的三个组件——加权、阈值、激活——在今天的深度网络里全部健在，只是形式演化：

- **加权求和**：被矩阵乘法取代（一层所有神经元的加权求和 = 一个矩阵乘法 $Wx+b$）；
- **阈值**：被偏置项 $b$ 取代，且常与权重一起随机初始化；
- **激活函数**：从阶跃 → sigmoid → **ReLU**（$\max(0,x)$）→ GELU，一路解决「梯度消失」与「表达力」问题。

现代神经元（如 Transformer 里的前馈层）仍是一个「线性变换 + 非线性激活」的单元——**M-P 神经元的骨架没变，变的只是规模、连接方式与训练方法**。

**思考题**：为什么现代激活函数（ReLU）在正半轴导数恒为 1，而不是像 sigmoid 那样「饱和」？这与 BP 的梯度传播有什么关系？

## 知识速查：神经元模型

**本节关键词**
- M-P 神经元
- 加权求和
- 阈值/偏置
- 激活函数
- sigmoid
- 阶跃函数
- 输入/隐/输出层
- 连接权

**三条常见误区**
1. 把阈值 θ 与偏置 b 当两个东西——它们只是符号差；
2. 以为阶跃函数可用于梯度训练——不可导；
3. 把单个神经元当强分类器——它是线性单元。

**核心结论**
1. M-P 神经元 = 加权求和 + 减阈值 + 激活；
2. 阈值 θ 与偏置 b 只是符号差；
3. sigmoid 处处可导、导数形式优美；
4. 单个神经元是线性分类器。

**与全书/后续的连接**
- 第5章感知机继承其学习规则；
- 第16章强化学习的状态-动作值也用加权结构；
- 大模型的前馈层仍是「线性+激活」。

**常见面试题**
1. 问：为什么激活函数必须可导？ 答：BP 需要梯度，阶跃函数不可导无法梯度训练。
2. 问：偏置 b 与阈值 θ 的关系？ 答：b = -θ，把减阈值吸收进求和式。

**一句话记忆**
神经元 = 加权求和 → 减阈值 → 过激活，深度学习的最小积木。

## 5 小结- **M-P 神经元**：$y = f\left(\sum_i w_i x_i - \theta\right)$，把生物神经元的「加权求和 + 阈值判断」抽象成数学式。- **激活函数**：阶跃函数给出 0/1 判断但不可导；**sigmoid** $\frac{1}{1+e^{-x}}$ 连续可导、值域 $(0,1)$，是可梯度学习的入门激活。- **神经网络** = 输入层、隐含层、输出层的神经元**按层连接**，学习即调整所有**连接权**。- 单个神经元是线性分类器；**多层连接**才换来逼近任意函数的能力。- 阈值 $\theta$ 与偏置 $b$ 是同一件事的两种写法：$b = -\theta$。
