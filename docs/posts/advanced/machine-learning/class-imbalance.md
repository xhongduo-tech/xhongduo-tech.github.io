## 为什么从类别不平衡开始

前三节我们学了线性模型、对数几率回归与多分类学习，它们都默认一个隐含前提：**训练集中各类别样本数目大致相当**。可现实世界很少这么客气。信用卡反欺诈里，一万笔交易才有几笔盗刷；癌症筛查里，绝大多数人是健康的；广告点击率预估里，千次曝光才有一两次点击。在这些场景里，正例（少数类）与反例（多数类）的比例可以悬殊到 1:100 甚至更高，这就是**类别不平衡（class imbalance）**问题。

本章这一节要回答的核心问题是：**当训练数据本身的比例已经「说谎」时，学到的模型如何才不说谎？** 它会把你带回第2章的性能度量——精度高并不等于模型好，也会为后续第6章支持向量机的软间隔、第7章的代价敏感学习埋下伏笔。

## 1 什么是类别不平衡**类别不平衡（class imbalance）**：分类任务中，训练集中不同类别的样本数目差别很大的情况。设正例数目为 $m^+$、反例数目为 $m^-$，当 $m^+ \ll m^-$（或反过来）时，数据就是不平衡的。<span class="marginnote">本书称较少的一类为「正例」，较多的一类为「反例」。注意这个称呼与直觉相反：我们真正关心、真正稀有、预测错了代价最大的那个类，才是正例。</span>不平衡的度量常用**不平衡比（imbalance ratio）**，即多数类与少数类的数目之比 $m^- / m^+$。1:1 是完全平衡；1:10 需要警惕；1:100 以上属于极端不平衡，几乎必须专门处理。
**为什么普通分类器会失效**：以对数几率回归为例，其决策边界是在最小化经验误差（对不平衡数据即最小化错误率）的过程中学出来的。当 99.9% 的样本都是反例时，「永远预测反例」的模型错误率只有 0.1%，是错误率意义上的「最优解」——但它对真正的正例毫无检出能力。<span class="marginnote">这正是第2章《性能度量》里强调过的：错误率不是万能的。在类别不平衡场景，查全率（召回率）、查准率、ROC 与 PR 曲线、F1 度量比错误率更能反映模型真实水平。</span>

## 2 危险的直觉：精度陷阱先做一个思想实验。假设交易数据里欺诈占比 0.1%，你训练一个模型在测试集上达到 99.9% 的准确率。这个数字令人兴奋吗？取决于它怎么做到的。- 若模型能识别出相当一部分欺诈，同时误伤少量正常交易，那 99.9% 是真实的胜利；- 若模型只是把所有交易都判为正常，那 99.9% 是彻底的失败——所有欺诈都漏检了。

**辨析｜易错点：** 在类别不平衡数据上，**错误率 / 精度几乎不携带信息**，一个只输出多数类的「傻子分类器」就能拿到近乎满分的精度。所以评估时必须换成查准率（precision）、查全率（recall）、$F_1$、ROC 曲线下面积（AUC）或代价曲线——这些指标对少数类的表现敏感。多数工业界的反欺诈、推荐系统上线评估，看的是这类指标而非精度。

## 3 再缩放：从观测几率回到真实几率直觉上的第一反应是：**样本少，就多采样一点；样本多，就丢掉一些。** 这确实是常用办法，但还有一个更优雅的思路——不动数据，只动决策规则。对数几率回归（以及所有以「几率」做决策的模型）的预测规则是：当预测几率大于阈值时判为正例，即
$$\frac{y}{1-y} > 1 \quad \Longrightarrow \quad \text{判为正例}$$

其中 $y$ 是模型预测的「正例概率」。这个规则隐含假设：训练集中正反例一样多，所以观测到的几率就是真实的先验几率。当 $m^+ \neq m^-$ 时，这个假设被打破——模型学到的是「在训练集比例下的几率」，而非「在真实比例下的几率」。

**再缩放（rescaling）**：假设训练集是真实分布的无偏采样，那么只需把决策规则改写成

$$\frac{y'}{1-y'} = \frac{y}{1-y} \times \frac{m^+}{m^-}$$

即当 $\dfrac{y}{1-y} > \dfrac{m^+}{m^-}$ 时判为正例。<span class="marginnote">直觉：正例少（$m^+ / m^-$ 小），阈值就被压低——模型不必那么「确信」是正例也可以投正例一票，用更宽松的判定换取对稀有正例的检出。</span>再缩放也被称为**类别平衡缩放（class-balance rescaling）**，因为它把决策阈值重新校准到真实类先验的比例上。

## 4 公式解析：再缩放为什么是「乘上比值」设真实分布中正例与反例的先验比例为 $P(y=1) : P(y=0)$。若训练集正反例数目为 $m^+$ 与 $m^-$，则模型实际上是用观测比例 $m^+ : m^-$ 近似真实比例。对数几率回归的输出 $y$ 是后验概率 $P(y=1 \mid \boldsymbol{x})$ 的估计，其几率形式为$$\frac{y}{1-y} = \frac{P(y=1 \mid \boldsymbol{x})}{P(y=0 \mid \boldsymbol{x})}$$
用贝叶斯公式展开后验：

$$\frac{P(y=1 \mid \boldsymbol{x})}{P(y=0 \mid \boldsymbol{x})} = \frac{p(\boldsymbol{x} \mid y=1) \cdot P(y=1)}{p(\boldsymbol{x} \mid y=0) \cdot P(y=0)}$$

- **第一步，分离先验与似然**：上式把后验拆成了似然比 $\dfrac{p(\boldsymbol{x} \mid y=1)}{p(\boldsymbol{x} \mid y=0)}$ 与先验比 $\dfrac{P(y=1)}{P(y=0)}$ 的乘积。
- **第二步，承认偏差来源**：模型在训练时，把训练集中的先验比 $m^+ / m^-$ 当成了 $P(y=1)/P(y=0)$。当采样有偏时，这两者不一致。
- **第三步，除以观测先验、乘以真实先验**：要得到真实后验的判定，就把模型里掺入的观测先验 $\dfrac{m^+}{m^-}$ 换掉，代之以真实先验比。于是：

$$\frac{y'}{1-y'} = \frac{y}{1-y} \times \frac{P(y=1)/P(y=0)}{m^+/m^-}$$

若认为训练集无偏，则真实先验比正是 $m^+ / m^-$，比值相消，得到再缩放公式 $\dfrac{y'}{1-y'} = \dfrac{y}{1-y} \times \dfrac{m^+}{m^-}$。**整个推导的精髓只有一句话：几率是「似然比 × 先验比」，训练数据污染了先验比，就在决策时把它乘回去。**<span class="marginnote">用第2章的偏差-方差语言说：类别不平衡引入的是「先验估计的系统偏差」，再缩放做的是一次确定性的修正，不增加方差。</span>

## 5 三大工程策略再缩放给出了原则，工程上还有三种直接改数据的做法，与改规则的做法互补：- **欠采样（undersampling）**：随机丢弃一些反例，使 $m^+$ 与 $m^-$ 接近。优点：训练开销小；缺点：丢弃了大量数据，浪费信息。改进版 **EasyEnsemble** 把反例分成若干份，每次用全部正例 + 一份反例训练一个模型，最后集成，避免信息浪费。- **过采样（oversampling）**：对正例做插值扩充，使两类数目接近。优点：不丢失数据；缺点：简单复制会过拟合。经典改进是 **SMOTE（Synthetic Minority Oversampling Technique）**：对每个正例样本，在它的近邻正例连线上随机生成新样本，制造「人工正例」而非复制。
- **阈值移动（threshold moving）**：不碰数据，直接用再缩放公式调整决策阈值。优点：不改变训练集分布、无额外开销；缺点：阈值如何定得恰到好处需要验证。

**辨析｜易错点：** 欠采样与过采样都**改变了训练集分布**，因此必须保证只作用于训练集，测试集保持原始比例——否则评估会失真。另外过采样制造的合成样本与真实样本分布未必一致，极端不平衡下容易在少数类上「过度自信」。

## 6 与代价敏感学习的联系再缩放是一个更一般思想的特例。若把「把正例误判为反例」的代价记为 $c_{10}$、「把反例误判为正例」的代价记为 $c_{01}$，则**代价敏感学习（cost-sensitive learning）**把决策规则改为$$\frac{y}{1-y} > \frac{c_{01}}{c_{10}} \times \frac{m^+}{m^-} \quad \Longrightarrow \quad \text{判为正例}$$
当两类错误代价相等时，$c_{01}/c_{10} = 1$，退化为再缩放；当漏掉一个正例的代价远高于误伤一个反例（如癌症漏诊 vs 过度检查）时，阈值进一步压低，模型变得更「大胆」。<span class="marginnote">第2章《性能度量》里的代价敏感错误率与代价曲线，讲的是「如何评估」；这里的代价敏感学习讲的是「如何据此训练」。评估与训练用同一套代价语言，才是闭环。</span>这也是为什么很多库把 `class_weight` 参数设成反比于类频率——它正是在隐式地做类别平衡缩放。


除了本章的再缩放与三大策略，现代工程里还有一套更精细的「不平衡工具箱」值得掌握。- **评估先行**：先确认「不平衡是否真的有害」——用 PR 曲线与 AUC 而非精度评估（第2章），若少数类本就不重要，可能无需处理；- **Focal Loss**：在损失函数里给「难分样本」更高权重、给「易分样本」降权——从损失侧缓解不平衡，是目标检测（YOLO/RetinaNet）的标配；- **代价敏感训练**：把「错分少数类」的代价写进训练（如 class_weight），比事后调阈值更平滑；- **合成过采样**：SMOTE 的改进版（Borderline-SMOTE、ADASYN）只在边界样本附近合成，减少噪声。**思考题**：1. 阈值移动与代价敏感学习的本质关系是什么？（提示：都是改决策阈值，只是改法不同）2. 为什么过采样容易过拟合？SMOTE 用「插值」替代「复制」解决了什么？3. 一份 99:1 的数据，模型精度 99%——你能立刻判断它好坏吗？为什么？（提示：回顾查全率）
## 拓展：不平衡数据的现代工具箱

除了本章的再缩放与三大策略，现代工程里还有一套更精细的「不平衡工具箱」值得掌握。

- **评估先行**：先确认「不平衡是否真的有害」——用 PR 曲线与 AUC 而非精度评估（第2章），若少数类本就不重要，可能无需处理；
- **Focal Loss**：在损失函数里给「难分样本」更高权重、给「易分样本」降权——从损失侧缓解不平衡，是目标检测（YOLO/RetinaNet）的标配；
- **代价敏感训练**：把「错分少数类」的代价写进训练（如 class_weight），比事后调阈值更平滑；
- **合成过采样**：SMOTE 的改进版（Borderline-SMOTE、ADASYN）只在边界样本附近合成，减少噪声。

**思考题**：
1. 阈值移动与代价敏感学习的本质关系是什么？（提示：都是改决策阈值，只是改法不同）
2. 为什么过采样容易过拟合？SMOTE 用「插值」替代「复制」解决了什么？
3. 一份 99:1 的数据，模型精度 99%——你能立刻判断它好坏吗？为什么？（提示：回顾查全率）

## 知识速查：类别不平衡

**本节关键词**
- 类别不平衡
- 不平衡比
- 再缩放 rescaling
- 欠采样/过采样/阈值移动
- SMOTE
- 代价敏感学习
- 查准率与查全率
- F1 与 AUC

**三条常见误区**
1. 把「永远预测多数类」的模型误判为优秀——必须看查全率等指标；
2. 过采样复制样本导致过拟合——SMOTE 用插值缓解；
3. 欠采样/过采样只许作用于训练集，测试集保持原始比例。

**核心结论**
1. 再缩放的本质是修正被训练集污染的类先验比；
2. 精度在不平衡数据上失真，查全率/查准率/AUC 才是裁判；
3. 过采样会过拟合，SMOTE 用插值缓解；
4. 阈值移动不碰数据只改决策规则。

**与全书/后续的连接**
- 第2章性能度量给出不平衡场景的评估工具；
- 第3章对数几率回归的决策阈值即再缩放的落点；
- 第6章软间隔的代价 $C$ 与代价敏感学习相通。

**常见面试题**
1. 问：不平衡比 1:100 时，最该先看哪个指标？ 答：查全率与 PR 曲线——精度会被多数类主导。
2. 问：SMOTE 与简单复制过采样的差别？ 答：SMOTE 在近邻连线插值制造新样本，而非复制旧样本。

**一句话记忆**
在真实分布比例与训练分布比例不一致时，把观测几率乘回真实先验比。

## 7 小结- **类别不平衡**指训练集中各类别样本数目悬殊（如 $m^+ \ll m^-$），使普通分类器偏向多数类。- 不平衡数据上**错误率/精度失真**，「永远预测多数类」的傻子模型也能拿高分，须改用查准率、查全率、F1、AUC 等指标。- **再缩放**：$\dfrac{y'}{1-y'} = \dfrac{y}{1-y} \times \dfrac{m^+}{m^-}$，本质是修正被训练集污染的类先验比。- 三大策略：**欠采样**（EasyEnsemble）、**过采样**（SMOTE）、**阈值移动**；后者的理论依据正是再缩放。
- 再缩放是**代价敏感学习**的特例，当错误代价不对称时，决策阈值还要再乘一个代价比。
