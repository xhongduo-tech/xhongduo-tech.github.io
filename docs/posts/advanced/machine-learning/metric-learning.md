## 为什么从度量学习开始

第10章一路走来都在围绕「距离」做文章：kNN 用距离、MDS 保持距离、PCA/KPCA 重定义空间、流形学习展开距离。但所有这些方法都把**距离当作给定的**——欧氏距离、核函数、测地距离，都是人选的。如果连「什么算近」都可以从数据里学出来呢？

**度量学习（metric learning）**正是这个问题的答案：**从数据中自动学习一个距离度量**，让「同类样本距离小、异类样本距离大」。它是第10章的收官，把「选距离」升级为「学距离」——这个能力在现代机器学习里无处不在：人脸识别的「孪生网络」、推荐系统的「物品嵌入」、大模型的「语义向量空间」，本质上都在学一种距离。<span class="marginnote">度量学习是「距离」这个概念的最终归宿：先有距离公理（第9章），再有距离的选择（本章前半），最后是距离的学习（本节）——三层递进，把「相似」从人的直觉变成了机器优化的对象。</span>

## 1 马氏距离：把空间「各向异性」化学习的起点是**马氏距离（Mahalanobis distance）**。欧氏距离对各维等权、各维独立；马氏距离允许一个**度量矩阵（metric matrix）$\mathbf{M}$** 来描述「各维的重要性与相关性」：`$$`dist_{\mathbf{M}}^2(\boldsymbol{x}_i, \boldsymbol{x}_j) = (\boldsymbol{x}_i - \boldsymbol{x}_j)^{\mathrm{T}} \mathbf{M} \, (\boldsymbol{x}_i - \boldsymbol{x}_j)$$
- 当 $\mathbf{M} = \mathbf{I}$，退化为欧氏距离；
- 当 $\mathbf{M}$ 是对角阵，等于给每维加了权重（**特征加权**）；
- 当 $\mathbf{M}$ 是满的对称半正定矩阵，还能编码**维度间的相关**——把坐标轴旋转、缩放，形成椭圆度量。<span class="marginnote">马氏距离的经典用法是「用协方差矩阵的逆」：$\mathbf{M} = \mathbf{\Sigma}^{-1}$ 时，距离把数据各维的方差归一、相关性去除——把椭圆的点云变成标准圆，再量距离。它让「近」的语义从「欧氏近」变成「统计意义上近」。</span>

**约束**：要满足距离公理（尤其三角不等式），$\mathbf{M}$ 必须**半正定**。所以度量学习常写成「学一个半正定矩阵 $\mathbf{M}$」或等价地「学一个线性变换 $\mathbf{P}$，令 $\mathbf{M} = \mathbf{P}^{\mathrm{T}}\mathbf{P}$」——后者把「学度量」变成「学一个投影到新空间的线性映射」，更易优化。

## 2 度量学习的目标：近邻约束度量要「好」，好坏的标尺来自**监督信息**。最自然的目标是：**让「近邻」尽可能同类，让「异类」尽量远离**。形式化为两类约束：- **同类约束**：若 $\boldsymbol{x}_i$ 与 $\boldsymbol{x}_j$ 同类别，则 $dist_{\mathbf{M}}(\boldsymbol{x}_i, \boldsymbol{x}_j)$ 应**小**；- **异类约束**：若类别不同，则距离应**大**（或至少大于某个边界）。

把这两类约束写进一个目标函数，度量学习就变成一个**优化问题**——而约束的来源，正是第10章 kNN 的分类依据：**我们希望 kNN 的「最近邻」恰好是同类样本**。<span class="marginnote">「让 kNN 在学到的度量下表现更好」是度量学习的经典动机：学出 $\mathbf{M}$ 后，再用学到的马氏距离跑 kNN。这也把第10章前后打通——降维、度量学习、kNN 是「距离驱动学习」的一体三面。</span>

## 3 三种代表性度量学习方法教材给出三类典型做法：- **近邻成分分析（NCA, Neighbourhood Components Analysis）**：把「$\boldsymbol{x}_i$ 被同类近邻选中的概率」最大化——用软分配（每个点以概率被拉向各近邻），最大化「随机选择近邻时选中同类」的概率，直接优化 kNN 的预期表现。- **大间隔最近邻（LMNN, Large Margin Nearest Neighbor）**：要求每个样本的 $k$ 个同类近邻都**被拉近**，同时异类样本**不侵入**以每个样本为中心的「边界」——像 SVM 那样撑开间隔，只是这次撑的是**距离空间**里的间隔。<span class="marginnote">LMNN 与第6章 SVM 的精神同源：都最大化「安全距离」。只是 SVM 在分类器层面撑间隔，LMNN 在距离度量层面撑间隔——「大间隔」这个主题贯穿全书。LMNN 一度是人脸识别、验证任务里最火的度量学习方法。</span>
- **MMC（Mahalanobis Metric for Clustering）**：以「同类样本间距离最小化、异类样本间距离最大化」为目标，在聚类场景下学度量。

## 4 公式解析：LMNN 的目标长什么样LMNN 的优化目标可以写成「拉近 + 推开」两部分的组合（示意形式）：`$$`\min_{\mathbf{M}} \; \sum_{i,j \in \mathcal{N}(i)} dist_{\mathbf{M}}^2(\boldsymbol{x}_i, \boldsymbol{x}_j) \;+\; \mu \sum_{i,j,l} \left[1 + dist_{\mathbf{M}}^2(\boldsymbol{x}_i,\boldsymbol{x}_j) - dist_{\mathbf{M}}^2(\boldsymbol{x}_i,\boldsymbol{x}_l)\right]_+$$
- **第一步，看第一项（拉近）**：$\mathcal{N}(i)$ 是 $\boldsymbol{x}_i$ 的同类近邻集合；这一项要求同类近邻间的马氏距离**小**。
- **第二步，看第二项（推开）**：$[z]_+ = \max(0, z)$ 是合页函数（第6章见过）；当异类样本 $\boldsymbol{x}_l$ 距离太近（小于「同类近邻距离 + 1」）时，这一项被激活，要求把它推远——**异类不得侵入边界**。
- **第三步，看权重 $\mu$**：平衡「拉近」与「推开」，$\mu$ 大则更在意边界不被侵犯。
- **第四步，看解的结构**：$\mathbf{M}$ 半正定的约束使问题成为**半定规划（SDP）**，可用凸优化求解；$\mathbf{M}$ 学出来后，新距离就是马氏距离。

**直觉一句话**：LMNN 在距离空间里复制了 SVM 的「间隔」——同类贴紧、异类离远、谁越界罚谁，最后学出一个「能把同类聚拢、异类隔开」的马氏度量。

## 5 核心对比表：度量学习与降维的家族关系| 方法 | 学什么 | 监督 | 本质 || --- | --- | --- | --- || PCA | 投影方向 | 无 | 线性降维（方差） || MDS/Isomap | 低维坐标 | 无 | 距离/测地距离保持 |
| LLE | 低维坐标 | 无 | 局部重构保持 |
| **度量学习** | **度量矩阵 $\mathbf{M}$** | **有（同类/异类）** | **学距离** |
| 深度嵌入 | 映射网络参数 | 有（对比/三元组） | 学非线性度量 |

**辨析｜易错点：** 度量学习与降维的关系常被混淆：**降维是在「换一个空间」里保持结构，度量学习是在「原空间」里重新定义距离**。但两者数学上相通——学 $\mathbf{M} = \mathbf{P}^{\mathrm{T}}\mathbf{P}$ 等价于先做线性变换 $\mathbf{P}$ 再算欧氏距离，所以度量学习**可以看作「变换数据后的欧氏距离」**；学到的度量如果只取前几个主方向，就近似一个降维。深度时代的度量学习则用**三元组损失/对比损失**训练神经网络直接学嵌入，人脸识别、相似检索都在用——那是「非线性度量学习」的现代形态。<span class="marginnote">「度量学习」的思想在大模型里无处不在：CLIP 学「图像与文本的距离」、推荐系统学「用户与物品的余弦相似」、检索系统学「query 与 document 的嵌入距离」——所有「算相似度」的地方，都有度量学习的影子。学完这一节，你就掌握了这条主线的理论源头。</span>

## 知识速查：度量学习

**本节关键词**
- 度量学习
- 马氏距离
- 半正定
- LMNN
- NCA
- 三元组损失
- 同类近异类远
- 嵌入

**三条常见误区**
1. 把度量学习当降维——它改距离而非换空间；
2. 忽略 M 半正定的公理约束；
3. 把学到的度量当绝对真理——它绑定训练数据。

**核心结论**
1. 度量学习从数据学距离度量 M；
2. 马氏距离 dist²=(x-z)ᵀM(x-z)；
3. M 半正定保证距离公理；
4. LMNN/NCA 是典型方法。

**与全书/后续的连接**
- 第9章距离公理是约束；
- 第10章 kNN 是它的验收标准；
- 大模型嵌入/对比学习是它的现代形态。

**常见面试题**
1. 问：度量学习与降维的关系？ 答：学 M=PᵀP 等价于先变换再算欧氏距离。
2. 问：三元组损失学的是什么？ 答：非线性嵌入，让同类近、异类远。

**一句话记忆**
度量学习 = 从数据学一个距离，让同类近、异类远。

## 6 小结- **度量学习**从数据里学距离度量，目标让**同类近、异类远**。- **马氏距离** $dist_{\mathbf{M}}^2 = (\boldsymbol{x}_i-\boldsymbol{x}_j)^{\mathrm{T}}\mathbf{M}(\boldsymbol{x}_i-\boldsymbol{x}_j)$ 是学度量的载体，$\mathbf{M}$ 半正定保证距离公理。- 典型方法：**NCA**（优化近邻选中同类的概率）、**LMNN**（拉近同类近邻 + 合页推开异类）、**MMC**（聚类导向）。- 度量学习与降维相通：$\mathbf{M}=\mathbf{P}^{\mathrm{T}}\mathbf{P}$ 等价于先线性变换再算欧氏距离。
- 现代形态：三元组/对比损失训练神经网络学**非线性嵌入**——人脸识别、检索、大模型语义空间的共同基础。
