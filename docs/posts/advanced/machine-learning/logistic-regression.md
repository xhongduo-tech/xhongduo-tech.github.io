## 为什么有了回归还要学分类

上一篇的线性回归把「拟合」这件事讲透了，但现实里大量任务不是预测一个数，而是**判定一个类**：这封邮件是不是垃圾邮件、这个细胞是不是癌变、这只瓜是不是好瓜。答案只有两类（或更多类），输出不是一个连续值。

最简单的想法是把回归结果硬切一刀：$f(\mathbf{x}) = \mathbf{w}^{\mathrm{T}}\mathbf{x} + b$ 大于 0 判正类，小于 0 判负类。可惜这条「硬阈值」的线有三个致命伤：其一，**它不给出置信度**——得分 0.01 和得分 100 都被判成正类，但两者显然不该等信；其二，**它对噪声极敏感**——一个异常点就能把边界推得老远；其三，它**不可微**，没法做梯度优化的优雅推导。**对数几率回归（logistic regression，学界更准确的译名是「对数几率回归」而非「逻辑回归」）就是为了解决这三个问题而生的**：它把线性输出平滑地压进 $(0,1)$，让「预测」变成「估计概率」。

## 1 从线性回归到概率：Sigmoid 函数回顾广义线性模型（上一篇 §3.2）：$y = g^{-1}(\mathbf{w}^{\mathrm{T}}\mathbf{x} + b)$。分类任务想要的是「输出落在 $(0,1)$ 之间、可解释为概率」，于是我们挑一个把整个实数轴 $\mathbb{R}$ 压进 $(0,1)$ 的单调函数——**Sigmoid 函数**，也叫**对数几率函数（logistic function）**：

$$y = \frac{1}{1 + e^{-z}}, \qquad z = \mathbf{w}^{\mathrm{T}}\mathbf{x} + b$$

**核心概念：Sigmoid 函数**：形如 $y = \frac{1}{1+e^{-z}}$ 的 S 形曲线。$z \to +\infty$ 时 $y \to 1$，$z \to -\infty$ 时 $y \to 0$，$z=0$ 时 $y=0.5$——它在 $z=0$ 附近几乎是线性的，两端则渐近饱和。这个「中间灵敏、两端饱和」的形状，正是「软阈值」的数学化身。<span class="marginnote">Sigmoid 是「神经元模型」里阶跃函数的平滑替代：阶跃函数在 0 处跳变且不可导，Sigmoid 处处可导，这让它成了第 5 章神经网络里最早的激活函数。后来深度网络里它被 ReLU 部分取代，是因为「两端饱和」会导致梯度消失——这是后话。</span>

**重点：分类模型的全部哲学都藏在这个函数里——不硬切，而是软化。** 把上式做个代数变换：

$$\ln \frac{y}{1-y} = \mathbf{w}^{\mathrm{T}}\mathbf{x} + b$$

若把 $y$ 视为「样本为正类的概率」$p(y=1 \mid \mathbf{x})$，则 $\frac{y}{1-y}$ 称为**几率（odds）**，表示「正类的相对可能性」；取对数后 $\ln \frac{y}{1-y}$ 称为**对数几率（log-odds，也叫 logit）**。于是对数几率回归这个名字的由来一目了然：**它在用线性模型去拟合「对数几率」，而不是直接拟合标记 $y$。** 模型对线性输出做了什么？套了一个「概率外衣」，把回归的实数输出翻译成概率。

## 2 公式解析：从极大似然到负对数似然既然 $y$ 被解读为概率，训练目标就不再是最小二乘，而是**极大似然估计（maximum likelihood estimation，MLE）**：找一组参数，让「当前这批样本被观测到的概率」最大。记 $\boldsymbol{\beta} = (\mathbf{w}; b)$、$\hat{\mathbf{x}} = (\mathbf{x}; 1)$（继续用吸收偏置的技巧），把两类概率写成统一形式：

$$p(y=1\mid \hat{\mathbf{x}}; \boldsymbol{\beta}) = \frac{e^{\boldsymbol{\beta}^{\mathrm{T}}\hat{\mathbf{x}}}}{1 + e^{\boldsymbol{\beta}^{\mathrm{T}}\hat{\mathbf{x}}}}, \qquad p(y=0\mid \hat{\mathbf{x}}; \boldsymbol{\beta}) = \frac{1}{1 + e^{\boldsymbol{\beta}^{\mathrm{T}}\hat{\mathbf{x}}}}$$

对全部 $m$ 个样本取对数似然，最大化它等价于最小化它的相反数，整理后得到对数几率回归的**目标函数**：

$$\ell(\boldsymbol{\beta}) = \sum_{i=1}^{m} \left( -y_i \boldsymbol{\beta}^{\mathrm{T}}\hat{\mathbf{x}}_i + \ln\!\left(1 + e^{\boldsymbol{\beta}^{\mathrm{T}}\hat{\mathbf{x}}_i}\right) \right)$$

对这条式子做三步拆解：

- **第一步，看懂每一项**：当 $y_i = 1$ 时只剩 $-\boldsymbol{\beta}^{\mathrm{T}}\hat{\mathbf{x}}_i + \ln(1 + e^{\boldsymbol{\beta}^{\mathrm{T}}\hat{\mathbf{x}}_i})$；当 $y_i = 0$ 时只剩 $\ln(1 + e^{\boldsymbol{\beta}^{\mathrm{T}}\hat{\mathbf{x}}_i})$。两种情形都被**同一个光滑式子覆盖**，这正是统一写法的好处。
- **第二步，验证直觉**：若正类样本的得分 $\boldsymbol{\beta}^{\mathrm{T}}\hat{\mathbf{x}}_i$ 很大，则 $\ln(1 + e^{\text{大数}}) \approx \text{大数}$，两项相减后损失接近 $0$——模型「很有把握」，代价很小；若得分是很大的负数而样本却是正类，则损失 $\approx -(\text{大负数}) + \ln(1+0) = \text{大正数}$——模型「判断反了」，代价很大。**方向正确，代价小；方向错误，代价大。**
- **第三步，确认凸性**：$\ell(\boldsymbol{\beta})$ 关于 $\boldsymbol{\beta}$ 是**凸函数**，因此它只有唯一的最小值点。这意味着对数几率回归虽无解析解，但**不存在局部最优陷阱**——用梯度下降或牛顿法从任意起点出发，最终都收敛到同一个全局最优。这与第 5 章神经网络的「局部极小」困境形成鲜明对比，是它身为「好公民」的第二个证据。

**重点：对数几率回归的目标函数没有解析解，但有凸性保底。** 牛顿法（Newton method）的迭代式是：

$$\boldsymbol{\beta}^{t+1} = \boldsymbol{\beta}^t - \left( \frac{\partial^2 \ell}{\partial \boldsymbol{\beta} \partial \boldsymbol{\beta}^{\mathrm{T}}} \right)^{-1} \frac{\partial \ell}{\partial \boldsymbol{\beta}}$$

其中一阶导、二阶导（Hessian 矩阵）都能对 $\ell(\boldsymbol{\beta})$ 干净地求出来——这又是「对数几率」这个选型带来的红利：因为损失函数来自指数族分布，其导数结构非常优美。

**辨析｜易错点：** 对数几率回归**名字带「回归」，本质是分类**。它从未试图「回归」一个连续值，而是估计「正类的概率」，再用概率做分类。另一个高频误区是把目标函数记成 $\sum_i \left( y_i \ln \hat{y}_i + (1-y_i)\ln(1-\hat{y}_i) \right)$ 的「交叉熵形式」就以为懂了——**那只是把上式换个写法**：对上式取负、展开 $\ln(1+e^z)$ 项，得到的正是「负交叉熵」。两者是同一个目标函数，理解了任何一个都等于理解了另一个。<span class="marginnote">「负对数似然」与「交叉熵」在二分类里是同一回事，这解释了为什么深度学习的分类损失也叫 cross-entropy——它们共享同一套「用分布之间的差异度量错误」的思想，向上可追溯到第二级《信息论》里的 KL 散度。</span>

## 3 用代码看一条决策边界理论讲完，用一段代码把「训练 → 边界」落成可见的东西。scikit-learn 里的逻辑回归拟合后，权重和偏置直接可读，决策边界就是 $\mathbf{w}^{\mathrm{T}}\mathbf{x} + b = 0$：

```python
from sklearn.linear_model import LogisticRegression

clf = LogisticRegression().fit(X, y)
w, b = clf.coef_[0], clf.intercept_[0]   # 超平面法向量与偏置
proba = clf.predict_proba(X)             # 每个样本属于各类的概率
```

`w` 给出了超平面 $\mathbf{w}^{\mathrm{T}}\mathbf{x} + b = 0$ 的法向量——它垂直于决策边界，指向正类一侧；`proba` 告诉你模型对每个点的把握程度，这正是硬阈值分类器给不出的信息。你也可以用 `predict_proba` 一次性得到全部分类的概率矩阵，工程上它比手写 Sigmoid 更稳（内部做了数值溢出保护）。<span class="marginnote">概率输出带来的能力远不止「好看」：在代价敏感学习中（第二章《性能度量》），你可以把阈值从 0.5 调低或调高，在「多判正类」与「多判负类」之间换取不同的查准率/查全率；在排序任务里，概率还直接决定样本的顺序。阈值只是最后一步的旋钮，模型学到的是一整个连续刻度。</span>

## 4 为什么它是「好公民」：三个难得的性质把对数几率回归的优点集中说清，它值得在整本书里占据这么高的地位：

- **可直接用于分类**：不依赖「先聚类再判定」之类的间接手段，直接对类别概率建模，得到的 $\hat{y}$ 就是类别后验概率的估计——**不需要额外的校准步骤**。
- **凸目标、可微、可解释**：凸性保证唯一最优，可微性让梯度类算法畅通无阻；而 $\mathbf{w}$ 仍然是一份「配方」，每个权重的符号和大小依然说人话，线性模型的可解释性完整保留。
- **概率输出的正确姿势**：模型学到的是 $p(y=1 \mid \mathbf{x})$ 的连续估计，阈值 0.5 只是使用时的选择。这让它在需要概率、排序、代价敏感决策的场景里是天然的正确选择。

**重点：对数几率回归是「线性分类」的范式样板——所有后续的线性分类器（SVM 的合页损失、神经网络的交叉熵）都在回答同一个问题：「怎么给线性边界加一个既平滑、又可导、又凸的损失」**，只是选择了不同的损失函数罢了。

### 一张表看清它与线性回归的区别

两兄弟共享同一个骨架 $\mathbf{w}^{\mathrm{T}}\mathbf{x} + b$，却因为「输出外衣」的不同而分道扬镳。把关键差异摆在一张表里：

| 维度 | 线性回归 | 对数几率回归 |
| --- | --- | --- |
| 任务类型 | 回归（预测连续值） | 分类（估计正类概率） |
| 输出 | $(-\infty, +\infty)$ 的任意实数 | $(0,1)$ 的概率 |
| 输出外衣 | 无（直接输出线性值） | Sigmoid $y = \frac{1}{1+e^{-z}}$ |
| 目标函数 | 均方误差（最小二乘） | 负对数似然（交叉熵） |
| 最优解 | 解析解 $\hat{\mathbf{w}}^* = (\mathbf{X}^{\mathrm{T}}\mathbf{X})^{-1}\mathbf{X}^{\mathrm{T}}\mathbf{y}$ | 无解析解，牛顿法 / 梯度下降迭代 |
| 决策方式 | 阈值切分（人为设定） | 概率 + 阈值（默认 0.5） |

**辨析｜易错点：** 表格里的「目标函数」差异是最值得记住的。**回归配平方误差，分类配对数似然**——为什么不能把平方误差直接用在分类上？因为分类的输出是概率，而平方误差假设误差服从高斯分布、对「小概率事件」的惩罚不合理；用负对数似然则与「概率」这一语义天然匹配。**损失函数的选择不是任意的，它必须与任务的「输出的语义」对齐。**

这条「线性骨架 + 不同输出外衣 + 不同损失」的配方，还会在全书里以几乎相同的结构反复出现：SVM 的合页损失、神经网络输出层的 Softmax 与交叉熵、第 7 章贝叶斯分类器里的似然估计——**它们共享同一张蓝图，只是换了一层「壳」**。对数几率回归的意义，正在于它是这张蓝图第一次完整、干净、凸地落地。

## 5 小结- **对数几率回归是分类器**：用 $y = \frac{1}{1 + e^{-(\mathbf{w}^{\mathrm{T}}\mathbf{x} + b)}}$ 把线性输出压进 $(0,1)$，估计正类概率。
- **名字的由来**：$\ln\frac{y}{1-y} = \mathbf{w}^{\mathrm{T}}\mathbf{x} + b$——它拟合的是**对数几率**（log-odds），不是 $y$ 本身。
- **训练目标**：极大似然估计，等价于最小化负对数似然 $\ell(\boldsymbol{\beta}) = \sum_i \left(-y_i \boldsymbol{\beta}^{\mathrm{T}}\hat{\mathbf{x}}_i + \ln(1 + e^{\boldsymbol{\beta}^{\mathrm{T}}\hat{\mathbf{x}}_i})\right)$。
- **性质**：目标函数是凸的、可微的，无解析解但无局部最优陷阱，可用梯度下降或牛顿法求解；「负对数似然」与「交叉熵」在二分类里是同一目标。
- **工程要点**：决策边界仍是 $\mathbf{w}^{\mathrm{T}}\mathbf{x} + b = 0$ 的超平面，$0.5$ 只是默认阈值，可按代价敏感需求调节。
- **对照记忆**：线性回归配平方误差、有解析解；对数几率回归配负对数似然、用迭代求解——「任务语义决定损失函数」。
