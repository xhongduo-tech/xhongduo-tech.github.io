## 为什么从稀疏表示与字典学习开始

上一节的 L1 正则化让「稀疏性」第一次登场：权重变稀疏、特征被挑选。但稀疏性的舞台远不止「选特征」——它可以用来**表示数据本身**。想一想自然图像：一张人脸图有成千上万个像素，但它本质可以用**少数几个「基元」（眼睛、鼻子、纹理块）的组合**来刻画；一段音频也可以用少数几个「音素」来描述。用**少数原子**表达复杂数据，这就是**稀疏表示（sparse representation）**。

而**字典学习（dictionary learning）**回答的是更进一步的问题：**这些「原子」从哪里来？** 不靠人设计（像小波、傅里叶基那样预先给定），而是**从数据里学**——学一本「字典」，让每个样本都能用字典里少数几个原子稀疏地重构出来。它是稀疏学习的高级形态，也是压缩感知（下一节）的前奏。<span class="marginnote">「稀疏表示 = 用少数基元说话」的思想遍布现代机器学习：图像去噪、人脸识别、压缩感知、深度稀疏编码，乃至大模型的稀疏注意力。而「从数据里学表示基元」正是表征学习（第5章深度学习）的另一条血脉——字典学习是它最干净的数学形态。</span>

## 1 稀疏表示：用少数原子说话设有一本**字典（dictionary）**$\mathbf{D} \in \mathbb{R}^{d \times n}$，它的列 $\boldsymbol{d}_1, \dots, \boldsymbol{d}_n$ 叫**字典原子（atom）**，是「基元」。一个样本 $\boldsymbol{x} \in \mathbb{R}^d$ 若能用**少数几个原子**的线性组合近似重构：$$\boldsymbol{x} \approx \mathbf{D} \boldsymbol{\alpha} = \alpha_1 \boldsymbol{d}_1 + \alpha_2 \boldsymbol{d}_2 + \cdots + \alpha_n \boldsymbol{d}_n$$
且系数 $\boldsymbol{\alpha}$ 中**绝大多数为 0**（只有 $k \ll n$ 个非零），则称 $\boldsymbol{x}$ 在该字典下有**稀疏表示**。<span class="marginnote">「稀疏」是相对字典规模说的：字典可能很大（$n$ 上千），但每个样本只用其中 $k$ 个原子——像「用一本大辞典里的几个词描述一句话」。稀疏表示的好处：压缩（只需存 $k$ 个系数）、去噪（噪声难以用少数原子稀疏表示）、可解释（知道样本由哪几个基元构成）。</span>

给定字典 $\mathbf{D}$，求稀疏表示系数是一个**稀疏编码（sparse coding）**问题：

$$\min_{\boldsymbol{\alpha}} \; \|\boldsymbol{x} - \mathbf{D}\boldsymbol{\alpha}\|_2^2 + \lambda \|\boldsymbol{\alpha}\|_1$$

L1 惩罚（上一节的软阈值机制）让系数稀疏；这一项与 LASSO 同构——**稀疏编码就是「每个样本做一次 LASSO」**。<span class="marginnote">理论上最自然的稀疏度量是 L0 范数（非零个数），但 L0 是组合优化、NP 难；L1 是它的凸松弛——上一节 L1 的几何直觉（菱形尖角）在这里原样复用。稀疏编码是「L1 从选特征走向表示数据」的关键一跃。</span>

## 2 字典学习：原子从数据里长出来上一节的稀疏编码假设**字典已知**。但什么样的字典最好？答案是：**让所有样本都能用少量原子稀疏重构**的字典最好——而这可以从数据里学。**字典学习（dictionary learning）**同时优化字典 $\mathbf{D}$ 与所有样本的稀疏系数 $\{\boldsymbol{\alpha}_i\}$：
$$\min_{\mathbf{D}, \boldsymbol{\alpha}_1, \dots, \boldsymbol{\alpha}_m} \; \sum_{i=1}^{m} \|\boldsymbol{x}_i - \mathbf{D}\boldsymbol{\alpha}_i\|_2^2 + \lambda \sum_{i=1}^{m}\|\boldsymbol{\alpha}_i\|_1$$

**交替优化（alternating optimization）**是标准解法：

1. **固定字典 $\mathbf{D}$，求各样本的稀疏编码 $\boldsymbol{\alpha}_i$**——$m$ 个独立的稀疏编码问题（LASSO），可并行；
2. **固定系数，更新字典 $\mathbf{D}$**——一个二次规划，通常用梯度法或 KSVD 等专门算法；
3. 交替迭代直到收敛。<span class="marginnote">「交替优化」是本书反复出现的模式：EM 算法（E/M 步）、k 均值（分配/重估）、坐标下降，全是「固定一部分、优化另一部分」的循环。字典学习的两个子问题各自可解，合起来却难直接同时求解——交替是必然选择。</span>

**辨析｜易错点：** 字典学习学出的原子**不一定「像」数据里的样本**——它们是「最能稀疏表达数据的基元」，可能是数据中反复出现的局部模式（图像里的边缘、条纹），也可能是抽象的过完备基。原子没有语义标签，需要靠人来解读或用在下游任务。

## 3 公式解析：稀疏编码为什么 L1 而不是 L0- **第一步，理想目标**：$\min_{\boldsymbol{\alpha}} \|\boldsymbol{x} - \mathbf{D}\boldsymbol{\alpha}\|_2^2 \quad \text{s.t.} \quad \|\boldsymbol{\alpha}\|_0 \leq k$——限制非零系数个数 ≤ $k$（L0 约束）。- **第二步，L0 的困难**：组合优化，需遍历「从 $n$ 个原子选 $k$ 个」的所有组合，NP 难；且 L0 不凸，无高效算法。- **第三步，L1 松弛**：把 $\|\boldsymbol{\alpha}\|_0 \leq k$ 换成 $\lambda\|\boldsymbol{\alpha}\|_1$ 加入目标——凸问题，坐标下降可解，且（在字典满足一定条件时）L1 解与 L0 解**一致**。- **第四步，读出条件**：字典越「不相干」（原子间夹角大、相关性低），L1 越能还原真稀疏解——这为「字典该学成什么样」提供了方向：**好字典的原子应当各具特色、互不雷同**。<span class="marginnote">「字典不相干性 → L1 还原真稀疏」正是下一节压缩感知的理论基石（受限等距性质 RIP、不相干性）。从这里开始，「稀疏表示」与「信号采样」两个领域正式交汇。</span>

**直觉一句话**：字典学习把「表示」也变成了学习对象——先让数据告诉我们「该用哪些原子」，再用 L1 保证「每个样本只用少数原子」。

## 4 稀疏表示与字典学习的应用- **图像去噪 / 修复**：噪声在字典下**不稀疏**，真实结构**稀疏**——稀疏编码后，噪声被「滤掉」，重构出干净图像。- **人脸识别**：用每个人的「稀疏字典」表示测试样本，看用谁的原子重构误差最小——著名的稀疏表示分类（SRC）方法。- **压缩感知**：若信号在某个字典下稀疏，则**远少于奈奎斯特率的采样**也能精确重建——下一节的主题。- **深度稀疏编码**：把稀疏编码当作网络的一层，端到端学习——稀疏思想与深度学习的结合。<span class="marginnote">稀疏表示在深度学习里也有一席之地：稀疏自编码器、Dropout（随机「关闭」神经元，强迫网络不依赖单个单元）都带着稀疏的思想。甚至大模型里「稀疏激活的专家混合（MoE）」——每次只激活少数专家——也是「用少数基元工作」的现代版本。稀疏性的价值贯穿 AI。</span>

**三条常见误区**
1. 把稀疏表示当「特征选择」——它是数据表示；
2. 忽略字典学习是交替优化的双变量问题；
3. 以为 L0 可直接求解——NP 难需 L1 松弛。

**核心结论**
1. 稀疏表示 = 用字典少数原子重构样本；
2. 稀疏编码 = 每样本一次 LASSO；
3. 字典学习交替优化编码与字典；
4. L1 是 L0 的凸松弛。

**常见面试题**
1. 问：稀疏编码与特征选择的差别？ 答：前者是数据表示，后者是特征挑选。
2. 问：好字典的原子应具备什么？ 答：不相干——原子间相关性低，L1 才能还原真稀疏。

**一句话记忆**
稀疏表示 = 用字典里少数原子重构样本；字典也从数据里学。

## 5 小结- **稀疏表示**：样本 $\boldsymbol{x} \approx \mathbf{D}\boldsymbol{\alpha}$ 用字典 $\mathbf{D}$ 里**少数原子**线性重构，系数 $\boldsymbol{\alpha}$ 绝大多数为 0。- **稀疏编码** = 固定字典求系数：$\min \|\boldsymbol{x}-\mathbf{D}\boldsymbol{\alpha}\|_2^2 + \lambda\|\boldsymbol{\alpha}\|_1$，是「每样本一次 LASSO」。- **字典学习**：交替优化「编码（求 $\boldsymbol{\alpha}$）+ 更新字典 $\mathbf{D}$」，原子从数据里学出来。- L1 是 L0 的**凸松弛**，字典不相干时 L1 解与真稀疏解一致。
- 应用：图像去噪、稀疏表示分类、**压缩感知**、深度稀疏编码。
