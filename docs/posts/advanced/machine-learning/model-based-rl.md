## 为什么从有模型学习开始

K 摇臂赌博机没有状态，只能「试错」。但真实 RL 任务都有**状态**：棋盘的局势、机器人的姿态、对话的上下文。状态之间的转移遵循一定规律——下棋有规则、机器人有力学。如果智能体**知道环境的转移模型**（在状态 $s$ 做动作 $a$ 会以什么概率到什么状态 $s'$、得到什么奖赏），学习就能「算」而不必「试」——这就是**有模型学习（model-based RL）**。

有模型学习建立在**马尔可夫决策过程（Markov Decision Process, MDP）**之上——RL 的标准数学模型。它用**动态规划**直接算出最优策略：既然知道环境规律，就「向后推」——从最终状态倒推每一步的最优选择。这一节是 RL 的理论心脏：MDP 五元组、值函数、Bellman 方程、策略迭代。<span class="marginnote">「有模型」vs「免模型」（下一节）是 RL 的第一大分野：有模型知道「世界怎么转」（转移概率已知），用动态规划精确求解；免模型不知道，只能靠交互数据学。现实里模型几乎总未知，但理解「有模型」是理解一切 RL 算法的地基——免模型算法本质上都在「估计模型或绕过模型」。</span>

## 1 马尔可夫决策过程：RL 的数学模型**马尔可夫决策过程（MDP）**由五元组刻画：
$$\langle S, A, P, R, \gamma \rangle$$

- $S$：状态集；$A$：动作集；
- **$P$：状态转移函数**——$P(s' \mid s, a)$：在状态 $s$ 做动作 $a$ 转移到 $s'$ 的概率；
- **$R$：奖赏函数**——$r(s, a, s')$：转移时得到的即时奖赏；
- $\gamma$：折扣因子（上一节）。

**马尔可夫性质**：下一状态只依赖当前状态与动作（$P(s'\mid s,a)$），与更早的历史无关——这让「向后推」的动态规划可行。**策略 $\pi$** 是从状态到动作的映射（或分布）；RL 的目标是找**最优策略 $\pi^*$**，使累计折扣奖赏最大化。<span class="marginnote">「马尔可夫性质 + 五元组」让 RL 从「试错故事」变成「可计算的优化问题」：已知 $P$ 与 $R$，求最优策略就是一个「动态规划」问题。MDP 是强化学习最标准的抽象——下棋、走迷宫、机器人导航都能装进这个框架；「模型」指的就是 $P$ 与 $R$，有模型学习 = 已知 $P,R$ 求解。</span>

## 2 值函数：给状态「打分」**值函数（value function）**是 RL 的核心概念：给状态（或状态-动作对）一个数值，表示「从这开始的期望累计奖赏」。
**状态值函数**（策略 $\pi$ 下，从状态 $s$ 开始的期望折扣累计奖赏）：

$$V^{\pi}(s) = \mathbb{E}_{\pi}\left[ G_t \mid s_t = s \right] = \mathbb{E}_{\pi}\left[ \sum_{k=0}^{\infty} \gamma^k r_{t+k+1} \;\middle|\; s_t = s \right]$$

**状态-动作值函数（Q 函数）**（从状态 $s$ 先做动作 $a$、之后按 $\pi$ 的期望累计奖赏）：

$$Q^{\pi}(s, a) = \mathbb{E}_{\pi}\left[ G_t \mid s_t = s, a_t = a \right]$$

**直觉**：$V$ 回答「这个状态有多好」，$Q$ 回答「在这个状态做这个动作有多好」。有了 $Q$，选动作就简单了——**选 $Q$ 最大的动作**。<span class="marginnote">「状态好」不是「即时奖赏高」，而是「从这开始的长期期望收益高」——一个看似糟糕的局面（弃子）可能是通向胜利的必经之路，$V$ 会把这种「远期潜力」算进去。$V$ 与 $Q$ 的关系：$V^\pi(s) = \sum_a \pi(a\mid s)Q^\pi(s,a)$——状态值 = 按策略加权平均的动作值。</span>

## 3 公式解析：Bellman 方程值函数满足一个优雅的**递推关系**——**Bellman 方程**。对状态值：
$$V^{\pi}(s) = \sum_{a} \pi(a\mid s) \sum_{s'} P(s'\mid s, a) \left[ r(s,a,s') + \gamma V^{\pi}(s') \right]$$

- **第一步，看内层**：从 $s$ 做 $a$ 后，得即时奖赏 $r$，转移到的 $s'$ 的价值是 $V^\pi(s')$——**「当前奖赏 + 折扣的未来」**（与上一节 $G_t = r + \gamma G_{t+1}$ 一脉相承）；
- **第二步，看外层**：对所有可能的动作 $a$（按策略概率）与所有可能的后继 $s'$（按转移概率）加权平均——**策略与环境的期望**；
- **第三步，看最优版本**：最优值函数满足

$$V^{*}(s) = \max_{a} \sum_{s'} P(s'\mid s, a) \left[ r(s,a,s') + \gamma V^{*}(s') \right]$$

——把「按策略平均」换成「取最好动作的 max」；
- **第四步，看可解性**：$V^*$ 是「最优值」，最优策略就是从任何状态都选「让右式最大的动作」——**解出 $V^*$ 即解出最优策略**。

**直觉一句话**：Bellman 方程说「最优的未来只由当前最优选择决定」——它把「全局最优化」拆成「每步取最优」，是**动态规划最优性原理**在 RL 的化身。

## 4 策略迭代与值迭代有了 Bellman 方程，可以算最优策略。两种经典算法：
- **策略迭代（policy iteration）**：交替执行「**策略评估**」（用 Bellman 方程迭代算 $V^\pi$）与「**策略改进**」（把策略改为「在每状态选 $V^\pi$ 下最优的动作」），直到策略不再变化——**策略逐步单调变好，收敛到最优**。
- **值迭代（value iteration）**：直接用「最优 Bellman 方程」迭代 $V(s) \leftarrow \max_a \sum_{s'}P(s'\mid s,a)[r + \gamma V(s')]$，直到 $V$ 收敛——收敛后的 $V$ 即 $V^*$，再从中读出最优策略。<span class="marginnote">「策略迭代 vs 值迭代」的取舍：策略迭代每轮做完整的策略评估（较贵），但策略改进后往往很快收敛；值迭代每轮只更新一次 $V$（便宜），但要迭代更多轮。两者是「精确但慢」与「简单但多次」的经典权衡——与第5章「梯度下降的各种步长方案」是同一类设计空间。有模型学习的核心思想，也是「规划（planning）」的源头：模型已知时，规划比试错高效得多。</span>

## 5 辨析：有模型学习的边界**辨析｜易错点：**
**模型要正确**：$P$ 与 $R$ 若估计错误，算出的「最优策略」是「错误模型下的最优」——**模型错了，规划就错了**（这与第13章生成式半监督的「模型假设错」是同一个教训）；
**状态空间要小**：动态规划遍历状态，状态空间巨大（围棋 $10^{170}$）时不可行——需免模型 + 函数近似；
**模型学习本身难**：现实里 $P, R$ 未知，要先学模型——「学模型再规划」可能放大误差。

**直觉**：有模型学习是「知彼知己、以算代试」——模型准且空间小，它就是最快的；模型不准或空间太大，就轮到免模型登场。<span class="marginnote">「有模型 vs 免模型」在深度 RL 里并不对立：<strong>Model-based RL</strong>（学个环境模型、在模型里想象/规划）近年回归热点——AlphaZero 用「完美模型（棋规）+ 蒙特卡洛树搜索」横扫棋类，就是有模型思想的巅峰。而 OpenAI 的很多成果用免模型的 PPO。理解「模型给规划省试错」，是理解 AlphaZero「算得深、试得少」的关键。</span>

## 知识速查：有模型学习

**本节关键词**
- MDP
- 状态转移
- 奖赏函数
- 值函数
- Bellman 方程
- 策略迭代
- 值迭代
- 动态规划

**三条常见误区**
1. 把 MDP 当 RL 的全部——模型未知时另有免模型路线；
2. 忽略 Bellman 方程是动态规划最优性原理；
3. 以为策略迭代/值迭代保证快——状态空间大时不可行。

**核心结论**
1. MDP 五元组 <S,A,P,R,γ> 是 RL 数学模型；
2. Bellman 方程给出值函数递推；
3. 策略迭代评估+改进交替、值迭代直接迭代；
4. 需模型正确且状态空间可遍历。

**与全书/后续的连接**
- 第16章免模型是它的对照；
- 第2级动态规划；
- AlphaZero 的规划思想。

**常见面试题**
1. 问：Bellman 方程说什么？ 答：最优未来只由当前最优选择决定——动态规划最优性原理。
2. 问：有模型与免模型的根本差别？ 答：前者用已知 P,R 规划，后者从交互学。

**一句话记忆**
有模型学习 = 已知转移与奖赏，用 Bellman 方程做动态规划求最优策略。

## 6 小结- **MDP** 是 RL 的数学模型：$\langle S, A, P, R, \gamma \rangle$，马尔可夫性质保证「向后推」可行。- **值函数**：$V^\pi(s)$ 状态值（期望累计奖赏）、$Q^\pi(s,a)$ 状态-动作值；有了 $Q$ 选动作即取最大。
- **Bellman 方程**：$V^\pi(s) = \sum_a\pi(a\mid s)\sum_{s'}P(s'\mid s,a)[r + \gamma V^\pi(s')]$；最优版把平均换成 max。
- **策略迭代**（评估+改进交替）与**值迭代**（直接迭代最优 Bellman）是有模型的经典求解法。
- 前提：模型 $P,R$ 正确且状态空间可遍历——否则转向免模型学习。
