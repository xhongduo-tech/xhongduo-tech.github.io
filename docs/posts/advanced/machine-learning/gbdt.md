## 为什么从 GBDT 开始

第8章集成学习里，Boosting 用「不断关注前一轮错误」提升弱学习器，AdaBoost 是分类代表。但真实工业界（搜索排序、推荐、风控、广告点击率）几乎统治性的 Boosting 实现，是**面向回归与任意可导损失**的 **GBDT（Gradient Boosting Decision Tree）**。它是「Boosting 思想的通用化」：不限于分类、不限于指数损失，而是**用损失函数的负梯度来引导每棵树**。

为什么 GBDT 是表格数据的「默认神器」？因为它把第8章的 Boosting 用最通用的数学语言（梯度下降）重写了一遍——每棵新树去拟合「当前模型的负梯度方向」，整个集成像「函数空间的梯度下降」。它配合回归树，天然处理非线性、特征交互、缺失值，且训练快、泛化稳。<span class="marginnote">GBDT 由 Jerome Friedman 在 2001 年正式提出（Gradient Boosting），是 Boosting 从「AdaBoost 特例」到「通用框架」的飞跃。XGBoost、LightGBM（后两节）都是它的工程加速版——理解 GBDT 的原理，是理解两大工程框架的钥匙，也是 Kaggle 表格竞赛「机器学习冠军配方」的理论核心。</span>

## 1 从残差到负梯度先看最直觉的情形：**平方损失**回归。设当前集成模型为 $F(\boldsymbol{x})$，第 $i$ 个样本的目标是 $y_i$。理想的新树应该**补上差距**——拟合**残差**：$$r_i = y_i - F(\boldsymbol{x}_i)$$

加一棵拟合残差的树 $h$，更新 $F \leftarrow F + h$，模型的误差就进一步下降。**但残差只是「平方损失下的特殊情况」**——对任意损失函数（绝对值损失、对数损失、自定义损失），「该补什么」没有这么直白。

**Friedman 的关键洞察**：对任意可导损失 $L$，「当前最该补的方向」不是残差，而是损失对当前预测的**负梯度**：

$$r_i = -\left[ \frac{\partial L(y_i, F(\boldsymbol{x}_i))}{\partial F(\boldsymbol{x}_i)} \right]$$

**平方损失**的负梯度恰好是残差 $y_i - F(\boldsymbol{x}_i)$（验证：$\frac{\partial}{\partial F}\frac{1}{2}(y-F)^2 = -(y-F)$）。**负梯度是「残差」对任意损失的自然推广**——GBDT 就是「每轮用一棵回归树去拟合负梯度」的通用框架。<span class="marginnote">「负梯度 = 万能残差」是 GBDT 的灵魂：把「拟合残差」这个特定操作的直觉，提升为「沿损失下降最快的方向走」的一般原理。类比第5章 BP：BP 在参数空间做梯度下降，GBDT 在<strong>函数空间</strong>做梯度下降——每棵树是「函数空间里的一步」。这个「在函数空间做梯度下降」的视角，也是理解 XGBoost、甚至神经网络的「提升式训练」的共同透镜。</span>

## 2 GBDT 的算法流程**GBDT（Gradient Boosting Decision Tree）**的完整流程：1. **初始化**：用常数值初始化模型 $F_0(\boldsymbol{x}) = \arg\min_c \sum_i L(y_i, c)$（如均值的平方损失最优初值）；
2. **循环 $m = 1, 2, \dots, M$**：
   - 计算负梯度（伪残差）$r_{im} = -\left[\frac{\partial L(y_i, F(\boldsymbol{x}_i))}{\partial F(\boldsymbol{x}_i)}\right]$；
   - 用一棵**回归树**拟合 $\{(\boldsymbol{x}_i, r_{im})\}$，得到 $h_m$（树的叶节点给出「该区域该补多少」）；
   - 对每个叶节点，求**最优的叶值** $\gamma_{jm} = \arg\min_\gamma \sum_{\boldsymbol{x}_i \in R_{jm}} L(y_i, F_{m-1}(\boldsymbol{x}_i) + \gamma)$；
   - 更新 $F_m(\boldsymbol{x}) = F_{m-1}(\boldsymbol{x}) + \nu \sum_j \gamma_{jm} \mathbb{I}(\boldsymbol{x}\in R_{jm})$；
3. **输出** $F_M$。

**$\nu$ 是学习率（shrinkage）**：每棵树的贡献被打折（通常 $\nu \in [0.01, 0.1]$），配合更大的树数 $M$——**「小步慢走」比「大步快跑」泛化更好**，这是 GBDT 工程调参的第一原则。<span class="marginnote">「学习率 × 更多轮数」的配合是 GBDT 的核心调参规律：$\nu$ 小 → 每步贡献小、需要更多树、但更不易过拟合；$\nu$ 大 → 收敛快但易过拟合。实践中「$\nu=0.1$ + 上千棵树 + 早停」是默认配方。这个「小步走得更远」与第5章梯度下降的学习率直觉完全一致——GBDT 就是函数空间的梯度下降。</span>

## 3 公式解析：平方损失下 GBDT 退化为「拟合残差」- **第一步，算负梯度**：$L = \frac{1}{2}(y - F)^2$，则 $r_i = -\frac{\partial L}{\partial F} = y_i - F(\boldsymbol{x}_i)$——**正是残差**；- **第二步，拟合树**：回归树拟合这些残差，叶值 $\gamma_j$ = 该叶内残差的均值（平方损失的最优叶值）；- **第三步，更新**：$F \leftarrow F + \nu \cdot (\text{残差树})$——每轮把「没拟合好的部分」补上一点；
- **第四步，看通用化**：换成绝对值损失 $L = |y-F|$，负梯度是 $\text{sign}(y-F)$（符号），拟合的是「该往上还是往下」——**损失函数一变，拟合目标自动变**，这就是 GBDT 的「通用」所在。

**直觉一句话**：GBDT 每轮问「当前模型在每样本上该往哪个方向修正最有效」——答案是负梯度；然后用一棵树「分区域地」回答这个修正，一步步逼近损失最小值。**它把「提升」变成「函数空间里沿负梯度的迭代」**。

## 4 GBDT 的工程实现要点- **回归树作基学习器**：每棵树用 CART 回归树（第4章），叶子输出连续值（修正量）；树的深度通常浅（3–8），**每棵树是弱学习器**，靠集成变强；- **正则化**：学习率 $\nu$、树深度、叶节点最少样本、子采样（随机选样本训练每棵树）——共同抑制过拟合；- **对缺失值友好**：树分裂天然处理缺失（把缺失样本分到增益最大的一侧）——GBDT 系框架对「脏表格数据」极宽容；
- **特征重要性**：累加各特征在所有树分裂中的增益，可排序出「哪些特征重要」——与随机森林的变量重要性并列的两大标准工具。<span class="marginnote">「浅树 + 小步学习率 + 子采样」是 GBDT 泛化的三件套：浅树保证每棵弱、小学习率保证每步小、子采样保证每棵见的数据不同（多样性）——这与第8章「好而不同」的集成原则精确对应。而「树数 $M$」靠<strong>早停</strong>（验证集误差不再降就停）来定，是 GBDT 里唯一需要「看着数据」选的量。</span>

## 知识速查：GBDT 原理与实现

- 函数空间

**三条常见误区**
1. 把 GBDT 当「拟合残差」特例——负梯度是通用形式；
2. 忽略学习率 ν 与树数的配合；
3. 以为 GBDT 只做分类——回归与任意可导损失都行。

**核心结论**
1. GBDT 在函数空间做梯度下降；
2. 每轮用回归树拟合负梯度；
3. 平方损失下负梯度即残差；
4. 学习率 × 早停是核心调参。

**与全书/后续的连接**

- 第4章回归树是基学习器；

**常见面试题**
1. 问：GBDT 的「负梯度」是什么？ 答：损失对当前预测的导数取负，是残差的推广。
2. 问：为什么学习率小 + 多轮更好？ 答：小步慢走更不易过拟合，配早停定树数。

**一句话记忆**
GBDT = 在函数空间做梯度下降，每轮用回归树拟合负梯度。

## 5 小结- **GBDT** 把 Boosting 通用化为「函数空间的梯度下降」：每轮用回归树拟合损失函数的**负梯度**。- 平方损失下负梯度即**残差**——「拟合残差」是 GBDT 的特例。- 算法：初始化 → 循环「算负梯度 → 拟合树 → 最优叶值 → 打折更新」。
- **学习率 $\nu$** 是核心超参数：小步 + 多轮 + 早停 = 泛化配方。
- 工程要点：浅回归树、子采样、缺失值友好、特征重要性——表格数据的「默认神器」。
