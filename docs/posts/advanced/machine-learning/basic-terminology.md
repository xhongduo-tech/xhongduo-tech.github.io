# 基本术语

<div class="epigraph">
<p>如果某程序在任务 $T$ 上的性能 $P$，随经验 $E$ 的增加而提高，则称该程序从经验 $E$ 中学习了任务 $T$。</p>

## 为什么从基本术语开始

「从极限到大模型」这条主线走到这里，刚刚用**集合**为整个数学建立了第一语言，接下来就要进入一个全新的世界：让机器自己从数据里找出规律。这就是**机器学习（machine learning）**。它处在整条主线的正中间——往下，它消费第一级《基础数学》的概念（数据集是集合、样本是元素、特征构成空间）；往上，它是第四级《深度学习》乃至大模型的底座，如今的大模型，本质上就是在互联网规模的数据上做一次极其庞大的机器学习。

任何学科的第一章都最难写，因为新词铺天盖地。**数据集、样本、特征、标记、样例、模型、泛化、过拟合**——这些词将在本书每一章反复出现。与其孤立地背定义，不如先把它们放进一幅完整的图景里一次看懂。这一篇，就是整个机器学习的「识字课」。

## 1 机器学习是什么：从数据中学到模型设想你是一位有经验的瓜农，一敲一听就知道手里的瓜甜不甜。这份「经验」是怎么来的？是你从小到大看过、摸过、敲过成千上万个西瓜，从它们的**色泽、根蒂、敲声**与**好坏**之间归纳出了一条判断规律。机器学习做的事情几乎一模一样，只是把「你」换成「计算机」，把「经验」换成「数据」：

**机器学习（machine learning）：研究如何通过计算的手段，利用经验（数据）来改善系统自身的性能。**

更具体地说，计算机拿到一组「历史记录」——比如周志华《机器学习》全书反复使用的**西瓜数据集**：每一行是一个西瓜的色泽、根蒂、敲声，以及它最终是好瓜还是坏瓜<span class="marginnote">「西瓜」是周志华老师在《机器学习》中精心挑选的贯穿全书的主线例子：理解清晰、贴近生活、任何算法都能在它上面跑起来。后续讲分类、决策树、SVM 时，我们还会反复回到这颗瓜。</span>。计算机从数据集中学出一条规律，比如「色泽青绿 ∧ 根蒂蜷缩 ∧ 敲声浊响 → 好瓜」，再用这条规律去判断**没见过的**新瓜。这个从数据中学得规律的过程，叫作**学习（learning）**或**训练（training）**；学得的规律以可计算的形式保存下来，就叫作**模型（model）**。

- **模型（model）**：从数据中学得的结果，是对数据背后潜在规律的近似刻画；也常称为**假设（hypothesis）**，而规律本身称为**真相（ground-truth）**——学到的模型再好，也只是对真相的逼近。
- **学习算法（learning algorithm）**：在数据上产生模型的算法。注意「模型」和「算法」不是一回事：算法是「怎么学」的方法，模型是「学完之后拿到的那个规律」。

**重点：机器学习的整个过程是「数据 → 算法 → 模型 → 预测」。** 数据是原料，算法是手艺，模型是产品，预测是用途。后面所有章节，都是在换不同的「手艺」，做出更好的「产品」。

## 2 数据集、样本与特征把西瓜数据集展开成一张表，前三列是每个西瓜的属性，最后一列是它的好坏：

| 编号 | 色泽 | 根蒂 | 敲声 | 好瓜 |
| --- | --- | --- | --- | --- |
| 1 | 青绿 | 蜷缩 | 浊响 | 是 |
| 2 | 乌黑 | 蜷缩 | 沉闷 | 是 |
| 3 | 乌黑 | 稍蜷 | 沉闷 | 否 |
| 4 | 浅白 | 硬挺 | 清脆 | 否 |

这张表就是一份**数据集（data set）**。逐行、逐列地读：

- **样本（sample）**：每一行记录，是关于一个西瓜的完整描述；也称**示例（instance）**。数据集就是样本的集合 $D = \{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_m\}$——回到第一级《基础数学》，这正是一个用列举法写出的集合，$m$ 是样本总数。
- **特征（feature）**：每一列，如「色泽」「根蒂」「敲声」，刻画样本在某方面的性质，也称**属性（attribute）**；表格里的具体取值（青绿、蜷缩、浊响）称为**属性值（attribute value）**。
- **特征向量（feature vector）**：一个样本的 $d$ 个属性值拼成一个向量 $\mathbf{x} = (x_1; x_2; \dots; x_d)$，它就是样本空间中的一个点。这里 $d$ 称为**维数（dimensionality）**。

**重点：一个样本就是一个向量，一个数据集就是向量空间里的一个有限点集。** 这一句把机器学习和第一级《基础数学》的集合、向量无缝接上了：我们所说的**样本空间（sample space）**或**属性空间**，就是这个 $d$ 维空间；每个样本是其中的一个点，数据集是它的一个有限子集。<span class="marginnote">维数 $d$ 是机器学习里最重要的数字之一。$d$ 稍大（比如几千、几万），空间就会「空旷」得超出直觉——样本点彼此远离，规律更难找，这就是著名的<strong>维数灾难（curse of dimensionality）</strong>，第十章的降维方法正是为它而生。</span>

## 3 标记、样例与学习任务西瓜数据集的最后一列「好瓜」，回答了「这个西瓜到底好不好」。这一列的信息称为**标记（label）**，记作 $y$；全部标记构成的集合 $\mathcal{Y}$ 称为**标记空间（label space）**或**输出空间**。

- **样例（example）**：带有标记的样本，记作 $(\mathbf{x}_i, y_i)$。有标记的样本才叫样例，没标记的只能叫样本——这个词很绕，却是后面一切讨论的起点。

有了「标记」，就能给学习任务分类。**如果训练数据带标记，任务叫监督学习（supervised learning）；如果完全不带标记，叫无监督学习（unsupervised learning）。** 监督学习里又分两类：

- **分类（classification）**：预测的标记是**离散值**。只有两个类别时叫**二分类（binary classification）**，通常把其中一类叫**正类（positive class）**、另一类叫**负类（negative class）**，比如「好瓜 / 坏瓜」；多于两个类别时叫**多分类（multi-class classification）**。
- **回归（regression）**：预测的标记是**连续值**。比如根据西瓜的特征预测成熟度 0.96、含糖量 12.5%，或者预测明天的气温、某套房子的价格。

无监督学习的代表任务是**聚类（clustering）**：训练数据只有样本、没有标记，让算法自己把「长得像」的西瓜聚成若干簇——它学到的不是「好瓜」这种外部给出的答案，而是数据内部天然的分组结构。<span class="marginnote">为什么会有无监督学习？因为<strong>标记很贵</strong>：请专家给每个西瓜打分要花钱花时间。现实中大量数据没有标记，于是「少量标记 + 大量无标记」的<strong>半监督学习（semi-supervised learning）</strong>应运而生，第十三章专门讨论。如今大模型的「预训练」正是无监督/自监督学习的极致规模，详见第四级《深度学习》。</span>

这三类任务，连同不靠数据标记、只靠环境奖赏学习的**强化学习（reinforcement learning）**，构成了一张机器学习地图：

| 学习类型 | 训练数据 | 学习信号 | 典型任务 | 代表方法（本书章节） |
| --- | --- | --- | --- | --- |
| 监督学习 | 带标记的样例 $(\mathbf{x}, y)$ | 预测与真实标记的差异 | 分类、回归 | 线性模型、决策树、SVM（第 3–8 章） |
| 无监督学习 | 无标记的样本 $\mathbf{x}$ | 数据内部的结构 | 聚类、降维 | k 均值、PCA、流形学习（第 9–10 章） |
| 强化学习 | 与环境交互的状态—动作序列 | 环境给予的奖赏 | 策略选择 | 时序差分、Q 学习（第 16 章） |

**辨析｜易错点：** 「监督 / 无监督」的划分依据只有一个——**训练数据里有没有标记**，而不是「有没有人看着」。模型自己迭代、自己校验，仍是监督学习；反之，让算法从无标记数据里找结构，才是无监督学习。强化学习与二者都不同：它连「正确答案」都没有，只靠环境的奖赏信号摸索，这是它与监督学习的根本区别。

## 4 训练集与测试集光学到模型还不够，还要知道它**好不好用**。于是数据要分成两部分：

- **训练集（training set）**：喂给学习算法、用来学得模型的那部分样本。
- **测试集（test set）**：用来检验模型的那部分样本，其中的样本称为**测试样本（test sample）**；测试集里的样本绝不能参与训练，否则检验就失去了意义。

整个过程分两段：先在训练集上**训练**出模型，再用模型对测试样本做**预测**，拿预测结果去对照真实标记，检验模型到底学得怎么样。

```python
# 概念演示：训练集与测试集的分工
from sklearn.model_selection import train_test_split

# 数据集 D：特征矩阵 X（每行一个样本）与标记向量 y
X = [[1, 1, 2], [2, 1, 1], [3, 3, 3], [1, 2, 1]]  # 色泽、根蒂、敲声的编码
y = [1, 1, 0, 0]                                   # 1 = 好瓜，0 = 坏瓜

# 把数据集拆成互不重叠的两部分
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42)

model = fit(X_train, y_train)   # 学习算法在训练集上学得模型
y_pred = model.predict(X_test)  # 模型对测试样本预测（泛化）
```

上面的 `fit` 与 `predict` 正是「训练」与「测试」的缩影：`fit` 只见过 `X_train`，而 `X_test` 是它从未谋面的「新瓜」。**测试集之所以存在，就是为了模拟「未来遇到新样本」这个真实场景。**

## 5 泛化与过拟合：机器学习的核心矛盾模型真正的价值，不在训练集上——训练集里的样本它都「见过」了，表现得再好在真实世界里也说明不了什么。模型的全部意义在于对**新样本**的判断，这种能力叫作**泛化（generalization）**：

**泛化（generalization）**：学得模型适用于新样本的能力。

于是机器学习的终极目标就非常清晰：**在训练集上学得好（经验拟合），又对测试集乃至未来的新样本预测得准（泛化）。** 这两者并不总是同时成立，最典型的失败模式是**过拟合（overfitting）**：

- **过拟合（overfitting）**：模型把训练数据里**偶然的、个别的**特点，当成了普遍的规律。「死记硬背」每个西瓜的长相，对训练集百发百中，可一遇到没背过的新瓜就原形毕露。<span class="marginnote">过拟合是机器学习中最核心、最需要重视的问题，而且<strong>原则上无法完全避免</strong>：样本再多也只是对真实分布的有限抽样，从有限证据推断无限规律，本质上不可能做到万无一失。第二章《经验误差与过拟合》会专门展开。</span>
- **欠拟合（underfitting）**：另一头的失败——训练程度不够，连训练集本身都没学好，规律学得太粗糙。

**重点：学习不是「记住」，而是「举一反三」。** 记住每个训练样本是过拟合，什么都没学到是欠拟合，恰到好处的归纳才是泛化。深度学习里五花八门的技巧——正则化、Dropout、数据增强、早停——绝大多数都是在与过拟合搏斗（见第四级《深度学习》第三篇「正则化与优化」）；而今天的大模型虽然「见过」海量文本，核心考验仍是泛化：会背题的模型不等于会解题的模型，这正是「从极限到大模型」主线上，机器学习与人工智能相交最深的地方。

## 6 公式解析：误差率与精度怎么定量地说「一个模型在测试集上有多准」？周志华《机器学习》第二章《模型评估与选择》给出了最基础的度量——**错误率（error rate）**：

$$
E(h; \mathcal{D}) = \frac{1}{m} \sum_{i=1}^{m} \mathbb{I}\big(h(\mathbf{x}_i) \neq y_i\big)
$$

拆成四步看：

- **第一步，读符号**：$h$ 是学得的模型，$\mathcal{D}$ 是测试集，$m$ 是测试集中的样本个数，$\mathbf{x}_i$ 与 $y_i$ 分别是第 $i$ 个测试样本的特征向量与真实标记。
- **第二步，理解 $\mathbb{I}(\cdot)$**：这是**指示函数（indicator function）**——括号里的命题为真时取 $1$，为假时取 $0$。于是 $\mathbb{I}(h(\mathbf{x}_i) \neq y_i)$ 的意思就是：「模型对第 $i$ 个样本的预测 $h(\mathbf{x}_i)$ 和真实标记 $y_i$ 不一致」时，记一次「错」。
- **第三步，求和**：$\sum_{i=1}^{m}$ 把 $m$ 个测试样本的「错」全部加起来，得到一个 $0$ 到 $m$ 之间的整数——总共错了多少个。
- **第四步，取平均**：除以 $m$，得到「错误的比例」。若 $m = 100$、错了 $5$ 个，则 $E = 0.05$，即错误率 $5\%$。<span class="marginnote">指示函数把「命题」翻译成 0/1，这正是第一级《基础数学》里集合论的思想：命题「$h(\mathbf{x}_i) \neq y_i$」定义了一个「出错样本」的集合，$\mathbb{I}$ 就是该集合的特征函数。错误率本质上是「出错样本集合」在测试集里所占的比例。</span>

与错误率互补的是**精度（accuracy）**：

$$
acc(h;\mathcal{D}) = 1 - E(h;\mathcal{D})
$$

即「预测正确的比例」。这两个词将贯穿全书——第二章《性能度量》会给它们安排更讲究的变体（查准率、查全率、ROC 与 AUC 等），但最朴素的思想就是这里的一句话：**错误率 = 错的样本数 ÷ 样本总数。**

## 7 小结- **机器学习的定义**：通过计算的手段，利用经验（数据）来改善系统自身的性能；本质是「数据 → 算法 → 模型 → 预测」。
- **基本概念**：**数据集**是样本的集合；**样本**是对象的一条描述，由**特征**构成**特征向量**；带**标记**的样本才叫**样例**。
- **学习任务**：带标记的是**监督学习**（分类、回归），不带标记的是**无监督学习**（聚类），只靠奖赏信号的是**强化学习**。
- **训练与测试**：**训练集**用来学得模型，**测试集**用来检验模型，二者必须互不重叠。
- **泛化与过拟合**：模型的真正价值在于对新样本的**泛化**能力；把训练数据的特点当普遍规律是**过拟合**，学得太粗糙是**欠拟合**。
