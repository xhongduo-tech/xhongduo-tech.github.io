## 为什么从 BP 算法开始

上一节我们说多层网络能逼近任意函数，但留下一个大坑：**权重怎么学？** 感知机的更新规则只适用于「输出直接等于误差」的单层结构；一旦有了隐含层，中间神经元的权重错了，误差信号却看不到——它既不在输出层，也不知道自己该为最终错误负多大责任。这就是著名的**信用分配问题（credit assignment problem）**。

**误差逆传播算法（error BackPropagation，简称 BP）**在 1986 年由 Rumelhart、Hinton 与 Williams 系统化推广，给出答案：**从输出层开始，把误差沿连接逐层「往回传」，每个权重按它对最终误差的「贡献度」来修正。** 今天深度学习的一切梯度训练——从 AlexNet 到 GPT——用的都是这个思想。<span class="marginnote">BP 不是一次发明，而是多重发现：Werbos 1974 年在博士论文里已给出雏形。但 1986 年的论文让全世界意识到「多层网络 + BP」可行，直接引爆了第一波神经网络研究浪潮。</span>

## 1 学习目标：最小化均方误差以教材的标准设定为例：一个隐层的前馈网络，输入层 $d$ 个神经元、隐层 $q$ 个、输出层 $l$ 个。对训练样本 $(\boldsymbol{x}_k, \boldsymbol{y}_k)$，网络输出为 $\hat{\boldsymbol{y}}_k = (\hat{y}_1^k, \dots, \hat{y}_l^k)$，则**均方误差（mean squared error）**为$$E_k = \frac{1}{2} \sum_{j=1}^{l} \left(\hat{y}_j^k - y_j^k\right)^2$$
前面的 $\frac{1}{2}$ 纯粹是为了求导时把平方的 2 消掉，方便推导。<span class="marginnote">「学习 = 最小化一个可导的误差函数」是 BP 与一切梯度方法的共同框架。第3章线性回归的最小二乘是它的特例；第7章极大似然估计是它更一般的母版（负对数似然）。</span>BP 的目标是调节所有连接权，使 $E_k$ 尽可能小。

## 2 核心思想：链式法则BP 的关键不是发明新数学，而是把微积分里最普通的**链式法则**用到网络结构上。误差 $E_k$ 是输出层神经元值的函数，输出神经元值又是隐层输出的函数，隐层输出又是输入的函数——误差对任一权重求导，就是沿着这条**计算路径**逐层应用链式法则。- **前向传播（forward）**：输入从输入层走到输出层，算出 $\hat{\boldsymbol{y}}_k$ 与 $E_k$。- **反向传播（backward）**：从输出层往回，用链式法则逐层算出 $E_k$ 对每个权重的梯度（偏导数）。
- **更新**：梯度下降，权重沿负梯度方向挪一小步：$w \leftarrow w + \Delta w$，$\Delta w = -\eta \frac{\partial E_k}{\partial w}$。

**直觉**：误差像一个「责任账单」，从输出端沿网络反向派发。输出层的神经元先知道「我错在哪」，然后按连接强度把责任分摊给隐层神经元，隐层再继续往更深的层分摊。<span class="marginnote">「逆传播」的名字正来自这里：信号传播是向前的，误差传播是向后的，两条方向相反的信息流在同一张网络上穿梭。</span>

## 3 两组关键更新公式令 $b_h$ 为第 $h$ 个隐层神经元的输出，$x_i$ 为第 $i$ 个输入，$w_{hj}$ 为隐层 $h$ 到输出 $j$ 的连接权，$v_{ih}$ 为输入 $i$ 到隐层 $h$ 的连接权。BP 的两类梯度项为：**输出层**（其中 $\hat{y}_j^k$ 为输出层神经元经 sigmoid 后的值）：
$$g_j = \hat{y}_j^k \left(1 - \hat{y}_j^k\right)\left(y_j^k - \hat{y}_j^k\right)$$

**隐层**（$e_h$ 是隐层神经元的「净误差」）：

$$e_h = b_h \left(1 - b_h\right) \sum_{j=1}^{l} w_{hj} \, g_j$$

权重更新（学习率 $\eta$）：

$$\Delta w_{hj} = \eta \, g_j \, b_h, \qquad \Delta v_{ih} = \eta \, e_h \, x_i$$

**公式结构值得停下来品**：$g_j$ 里 $\hat{y}_j^k(1-\hat{y}_j^k)$ 是 sigmoid 的导数（见神经元一节），$(y_j^k - \hat{y}_j^k)$ 是误差信号；$e_h$ 里 $\sum_j w_{hj} g_j$ 表示「隐层神经元把各输出节点的责任按连接权加权回收」。**每一层的误差项 = 激活导数 × 从上一层回收的加权误差**，一层层像多米诺一样反向递推。<span class="marginnote">这就是「逆传播」的全部秘密：不需要知道误差函数的全局形状，只要每层都能求导、都能把误差传给上一层，梯度就能算出来。它把「对百万参数求导」化成了「对每一层做局部求导 + 乘起来」。</span>

## 4 公式解析：输出层梯度项从哪来为什么 $g_j = \hat{y}_j^k(1-\hat{y}_j^k)(y_j^k - \hat{y}_j^k)$？逐步拆：- **第一步，定义误差对输出的偏导**：$\dfrac{\partial E_k}{\partial \hat{y}_j^k} = \dfrac{\partial}{\partial \hat{y}_j^k} \left[\frac{1}{2}(\hat{y}_j^k - y_j^k)^2\right] = \hat{y}_j^k - y_j^k$（平方求导，$\frac{1}{2}$ 恰好消掉系数）。- **第二步，输出对净输入求导**：输出 $= \text{sigmoid}(\beta_j)$，其中 $\beta_j$ 是该神经元的加权和减阈值；$\dfrac{\partial \hat{y}_j^k}{\partial \beta_j} = \hat{y}_j^k(1 - \hat{y}_j^k)$（sigmoid 导数）。
- **第三步，链式法则相乘**：$\dfrac{\partial E_k}{\partial \beta_j} = \dfrac{\partial E_k}{\partial \hat{y}_j^k} \cdot \dfrac{\partial \hat{y}_j^k}{\partial \beta_j} = (\hat{y}_j^k - y_j^k)\cdot \hat{y}_j^k(1-\hat{y}_j^k)$。
- **第四步，取符号得梯度项**：梯度下降要沿负梯度方向走，所以 $g_j = -\dfrac{\partial E_k}{\partial \beta_j} = \hat{y}_j^k(1-\hat{y}_j^k)(y_j^k - \hat{y}_j^k)$。

**直觉**：$y_j^k - \hat{y}_j^k$ 越大（错得越离谱），$g_j$ 越大；$\hat{y}_j^k(1-\hat{y}_j^k)$ 在 $\hat{y}=0.5$ 时最大（此时神经元最「犹豫」，责任也最大），在 $\hat{y}$ 接近 0 或 1 时趋近 0（已经「确定」的神经元，误差再大也懒得大改）——这个「饱和就停」的特性，既是 BP 能稳定工作的原因，也是深层网络梯度消失的伏笔。

## 5 BP 的工程变体与过拟合- **标准 BP 与累积 BP**：标准 BP 每看一个样本就更新一次权重（**在线 / 增量**），更新频繁、可能震荡；累积 BP 先算完整训练集的平均误差再更新（**批量**），更稳定但每轮开销大。两者目标函数不同：标准 BP 在最小化各样本误差之和的近似，累积 BP 在最小化整体均方误差。<span class="marginnote">现代深度学习的「小批量（mini-batch）梯度下降」正是两者的折中：每看一小批样本更新一次。这个折中思想在后面第16章强化学习、以及深度学习中都是标配。</span>- **过拟合与早停（early stopping）**：BP 很容易把训练集误差压到极小而过拟合。教材给出的经典策略是**早停**：把数据分成训练集与验证集，训练中每轮看验证集误差，**验证集误差开始上升时停止训练**——此时权重「恰好」在泛化最好的位置附近。这与第4章剪枝用验证集判断取舍是同一个哲学：**训练信号与验证信号要分开**。- **其他对策**：正则化（第6章软间隔会讲）、模型平均（集成学习）、权重衰减等，都与「别让训练集把模型喂太胖」有关。

用一个极简的深层网络体验「梯度消失」的数值：设 3 层 sigmoid 网络，每层权重都让激活落在饱和区（输出接近 0 或 1）。BP 的梯度是每层「激活导数 × 误差」的连乘：- sigmoid 导数最大 0.25，假设三层各取 0.25、0.2、0.1：梯度传到第一层要乘 $0.25\times0.2\times0.1=0.005$——**第一层权重几乎学不动**；- 若换成 ReLU（正区间导数为 1）：连乘项全是 1——**梯度畅通无阻**；- 残差连接 $y=x+F(x)$ 更彻底：梯度沿 $x$ 这条「捷径」直接传回，连乘项里多了一个「恒等项」。这就是「为什么 ReLU 和残差是深度学习基石」的数值原因——它们修的是**梯度连乘缩水**这条病根。**思考题**：如果网络权重初始得太大，连乘会怎样？（提示：梯度爆炸）深层网络初始化为什么讲究「方差保持」？

## 知识速查：误差逆传播

**本节关键词**
- BP
- 链式法则
- 梯度下降
- 前向传播
- 反向传播
- 信用分配
- 早停
- 标准/累积 BP

**三条常见误区**
1. 把 BP 当作「新数学」——它只是链式法则；
2. 忽略 sigmoid 导数在深层中的衰减（梯度消失）；
3. 用训练集做早停——要用验证集。

**核心结论**
1. BP 用链式法则沿计算路径反向求梯度；
2. 误差像责任账单从输出层往回分摊；
3. 输出层/隐层梯度项都是「激活导数×回收误差」；
4. 标准 BP 在线更新、累积 BP 批量更新。

**与全书/后续的连接**
- 第5章全局极小与局部极小讨论其收敛性质；
- 第16章值函数近似共享「误差×梯度」；
- 专题一 GBDT 也在函数空间做梯度下降。

**常见面试题**
1. 问：BP 的「逆传播」指什么？ 答：误差沿连接反向传播，与信号前向方向相反。
2. 问：为什么深层网络梯度会消失？ 答：sigmoid 导数≤0.25 连乘指数级缩水，ReLU/残差补救。

**一句话记忆**
BP = 前向算误差、反向用链式法则分摊责任、沿负梯度更新。

## 6 小结- **BP 算法**：前向算出误差，反向用链式法则求梯度，沿负梯度更新所有权重；误差像「责任账单」沿网络反向派发。- 误差项结构统一为**激活导数 × 加权回收误差**：输出层 $g_j = \hat{y}_j^k(1-\hat{y}_j^k)(y_j^k-\hat{y}_j^k)$，隐层 $e_h = b_h(1-b_h)\sum_j w_{hj}g_j$。- 更新规则：$\Delta w_{hj} = \eta g_j b_h$、$\Delta v_{ih} = \eta e_h x_i$，$\eta$ 为学习率。- **标准 BP（在线）** 与 **累积 BP（批量）** 的折中即深度学习的**小批量**训练。
- BP 会过拟合，**早停**、正则化是标准对策；「验证集看泛化、训练集做优化」的分离贯穿全书。
