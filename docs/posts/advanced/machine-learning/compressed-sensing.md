## 为什么从压缩感知开始

上一节的稀疏表示告诉我们：许多信号本质上是稀疏的——可以用少数基元表达。这一节问一个更大胆的问题：**既然信号这么「省」，采样时能不能也「省」？** 传统采样的铁律是**奈奎斯特-香农采样定理**：采样频率必须达到信号最高频率的两倍，否则信息丢失、无法重建。但医学 MRI、单像素相机、雷达成像等场景里，「采够奈奎斯特率」往往很贵、很慢、甚至做不到。

**压缩感知（compressed sensing）**颠覆了这个铁律：**如果一个信号在某个字典下是稀疏的，那么用远少于奈奎斯特率的「随机线性测量」，也能精确重建原信号。** 它由 Candès、Tao、Donoho 等在 2006 年前后建立，是稀疏学习与信号处理交叉的里程碑。<span class="marginnote">压缩感知让「采样」与「压缩」合二为一：传统流程先按奈奎斯特率采满、再压缩编码（浪费）；压缩感知直接采「压缩后的信息」——用随机测量把高维信号投影到低维，再用稀疏性从低维里恢复高维。它也是第11章「稀疏学习」思想的终极应用。</span>

## 1 核心问题：欠定方程怎么解设原始信号 $\boldsymbol{x} \in \mathbb{R}^{d}$，用**测量矩阵** $\boldsymbol{\Phi} \in \mathbb{R}^{m \times d}$（$m \ll d$）做线性测量，得到观测$$\boldsymbol{y} = \boldsymbol{\Phi}\boldsymbol{x}$$
$\boldsymbol{y} \in \mathbb{R}^{m}$ 只有 $m$ 个分量，而未知数 $\boldsymbol{x}$ 有 $d$ 个——**$m < d$，方程欠定，有无穷多解**。凭什么能唯一恢复 $\boldsymbol{x}$？凭的就是**稀疏性**：在「所有满足 $\boldsymbol{y} = \boldsymbol{\Phi}\boldsymbol{x}$ 的解」里，真实的 $\boldsymbol{x}$ 是**最稀疏**的那个。

若 $\boldsymbol{x}$ 在字典 $\mathbf{D}$ 下稀疏（$\boldsymbol{x} = \mathbf{D}\boldsymbol{\alpha}$，$\boldsymbol{\alpha}$ 稀疏），则问题变成

$$\boldsymbol{y} = \boldsymbol{\Phi}\mathbf{D}\boldsymbol{\alpha} = \mathbf{A}\boldsymbol{\alpha}, \qquad \mathbf{A} = \boldsymbol{\Phi}\mathbf{D}$$

在「$m$ 个方程、$n$ 个未知系数」的欠定系统里，找最稀疏的 $\boldsymbol{\alpha}$。<span class="marginnote">「欠定 + 稀疏 = 可解」是压缩感知的惊人结论：方程数少于未知数，按理不可解，但「真实解是稀疏的」这一先验把解空间大大压缩——在无穷多个解里，稀疏的那一个「鹤立鸡群」，可以被算法找到。这也是「正则化 / 先验」价值的极致体现。</span>

## 2 两个关键条件：稀疏性与不相干性压缩感知能成功，需要两条保证：- **稀疏性**：$\boldsymbol{\alpha}$ 确实稀疏（非零系数 $k \ll n$）——这是**信号侧的假设**，与上一节字典学习相同；- **不相干性 / 受限等距性质（RIP）**：测量矩阵 $\boldsymbol{\Phi}$（或组合矩阵 $\mathbf{A} = \boldsymbol{\Phi}\mathbf{D}$）要「好」——它不能把不同的稀疏信号「压」成同一个观测。

**RIP（Restricted Isometry Property）**的直观含义：$\mathbf{A}$ 对任意稀疏向量的作用都近似「保距」——稀疏信号被 $\mathbf{A}$ 映射后，长度基本不变。这保证「不同稀疏信号 → 不同观测」，从而唯一可恢复。<span class="marginnote">「随机测量矩阵（如高斯随机矩阵）以高概率满足 RIP」是压缩感知的理论基石：随机性让测量「各向同性」，不太可能把两个稀疏信号混为一谈。这个「随机即好」的结论很反直觉，却正是随机矩阵理论的美妙之处。</span>

**辨析｜易错点：** 压缩感知不是「对任何信号都能少采样」——它**强烈依赖稀疏性假设**。若信号在字典下不稀疏（处处高频、毫无结构），欠定问题仍无解。稀疏性 + 不相干性是两个前提，缺一不可。

## 3 公式解析：L1 重建为什么可行给定观测 $\boldsymbol{y}$，重建稀疏系数 $\boldsymbol{\alpha}$ 的「理想」问题是 L0 最小化：$$\min_{\boldsymbol{\alpha}} \; \|\boldsymbol{\alpha}\|_0 \quad \text{s.t.} \quad \boldsymbol{y} = \mathbf{A}\boldsymbol{\alpha}$$
- **第一步，看 L0 的困境**：$\|\boldsymbol{\alpha}\|_0$ 是非零个数，组合优化、NP 难——直接解不现实。
- **第二步，换成 L1**：在 $\mathbf{A}$ 满足 RIP 的条件下，L1 最小化给出与 L0 **相同**的解：

$$\min_{\boldsymbol{\alpha}} \; \|\boldsymbol{\alpha}\|_1 \quad \text{s.t.} \quad \boldsymbol{y} = \mathbf{A}\boldsymbol{\alpha}$$

- **第三步，看为什么 L1 能行**：L1 的菱形「尖角」会优先落到坐标轴上（第11章 L1 一节的几何），而稀疏解正是「落在坐标轴附近」的解——**L1 在几何上「偏爱」稀疏解**。
- **第四步，看工程实现**：带等式约束的 L1 最小化可用基追踪（Basis Pursuit）、或加噪声的 LASSO（$\min \|\boldsymbol{y}-\mathbf{A}\boldsymbol{\alpha}\|_2^2 + \lambda\|\boldsymbol{\alpha}\|_1$）求解——**压缩感知的重建 = 又一次稀疏编码**。

**直觉一句话**：压缩感知说「少采样没问题」——只要信号稀疏、测量够好，重建就是解一个 L1 稀疏优化，把「欠定方程」变成「可解问题」。

## 4 应用与意义- **单像素相机**：传统相机每个像素都要采集，单像素相机只用**一个**光电探测器 + 随机掩膜，做 $m$ 次随机测量重建整幅图像——压缩感知的招牌应用。- **磁共振成像（MRI）加速**：MRI 慢在「采满频域」，压缩感知用随机欠采样 + 稀疏重建，把扫描时间缩短数倍——已是医学影像的成熟技术。- **雷达成像 / 天文**：在观测极稀疏的场合，压缩感知用稀疏先验补全信息。- **通信与 A/D 转换**：亚奈奎斯特采样降低硬件成本。<span class="marginnote">压缩感知的思想还外溢到机器学习：<strong>主动学习 / 最坏情况下的信息获取</strong>、<strong>低秩矩阵补全</strong>（Netflix 推荐补全的数学基础）、以及<strong>深度学习的「更少标注」</strong>——它们共享同一个先验：「真实结构是稀疏/低秩的，少数信息即可还原」。这正是第11章稀疏学习的收官彩蛋。</span>

## 知识速查：压缩感知

**本节关键词**
- 压缩感知
- 欠定方程
- 稀疏性
- RIP
- 不相干性
- L1 重建
- 奈奎斯特
- 随机测量

**三条常见误区**
1. 把压缩感知当「无损压缩」——它靠稀疏先验；
2. 忽略 RIP 是重建的理论前提；
3. 以为任何信号都能少采样——非稀疏则无效。

**核心结论**
1. 压缩感知 = 稀疏信号 + 随机测量 + L1 重建；
2. 远少于奈奎斯特也能重建；
3. 两个条件：稀疏性 + RIP；
4. L0 重建 NP 难，L1 给出相同解。

- 第2级信号处理采样定理；

**常见面试题**
1. 问：压缩感知重建的本质？ 答：在欠定方程的所有解里找最稀疏的那个。
2. 问：为什么随机测量矩阵好？ 答：随机性让不同稀疏信号几乎不可能映射到同一观测。

**一句话记忆**
压缩感知 = 稀疏信号 + 随机测量 + L1 重建，远少于奈奎斯特也能恢复。

## 5 小结- **压缩感知**：信号稀疏时，用远少于奈奎斯特率的 $m \ll d$ 次随机测量也能精确重建。- 数学本质：解**欠定方程** $\boldsymbol{y} = \boldsymbol{\Phi}\boldsymbol{x}$，靠「稀疏解唯一」这一先验。- 两个条件：**稀疏性**（信号侧）+ **不相干性/RIP**（测量侧，随机矩阵以高概率满足）。- 重建方法：L0 是 NP 难，**L1 最小化**（基追踪 / LASSO）在 RIP 下给出相同解。
- 应用：单像素相机、MRI 加速、雷达成像；思想外溢到低秩矩阵补全与深度学习。
