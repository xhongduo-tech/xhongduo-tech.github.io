## 为什么从核函数开始

上一节的对偶问题把 SVM 的解变成了只依赖样本内积 $\boldsymbol{x}_i^{\mathrm{T}}\boldsymbol{x}_j$ 的形式。这个看似巧合的数学形态，打开了一扇大门：**如果样本在原空间线性不可分，那么把它们映射到更高维的特征空间，往往就变得线性可分了**——而核函数让我们能在这个高维空间里做内积，却**不必显式地做映射**。这就是**核技巧（kernel trick）**，SVM 从「线性分类器」一跃成为「非线性分类器」的关键。

这一节要建立三件事：为什么需要映射、核技巧如何绕过显式映射、以及什么样的函数才能当核。<span class="marginnote">核方法的影响力远超 SVM 本身：第10章的核化线性降维（KPCA）、第6章末的核方法、甚至高斯过程回归，都用同一套「核 = 隐式高维内积」的语言。学透这一节，等于掌握了整个「核」家族的通关密码。</span>

## 1 线性不可分怎么办：升维想象一个二维平面上的数据：正样本围成一圈，负样本在圆心。任何一条直线都分不开它们——线性不可分。但若把每个点映射到三维特征空间，例如 $\phi(\boldsymbol{x}) = (x_1, x_2, x_1^2 + x_2^2)$，让「到圆心的距离」成为第三维，那么在三维空间里用一个平面就能切开：**数据在高维空间线性可分了**。**直觉**：维数越高，表达力越强；「分不开」往往只是「在低维看不穿」。「把样本映射到高维特征空间 $\phi(\boldsymbol{x})$，然后在特征空间里学线性 SVM」——这就是非线性 SVM 的思路。但直接算 $\phi(\boldsymbol{x})$ 有两个问题：**映射可能无穷维**（如高斯核对应的映射），且**高维内积计算昂贵**。核技巧正是来救场的。
## 2 核技巧：不映射，只算内积设 $\phi(\boldsymbol{x})$ 是特征映射，特征空间中的内积为 $\langle \phi(\boldsymbol{x}_i), \phi(\boldsymbol{x}_j)\rangle$。**核函数（kernel function）**定义为一个函数 $k$，使得$$k(\boldsymbol{x}_i, \boldsymbol{x}_j) = \langle \phi(\boldsymbol{x}_i), \phi(\boldsymbol{x}_j)\rangle$$
即：**核函数直接给出高维空间里两个样本的内积，而不用先把样本显式映射过去。** 对偶问题的所有内积 $\boldsymbol{x}_i^{\mathrm{T}}\boldsymbol{x}_j$ 换成 $k(\boldsymbol{x}_i, \boldsymbol{x}_j)$，非线性 SVM 的对偶形式就写成：

$$\max_{\boldsymbol{\alpha}} \; \sum_{i=1}^{m} \alpha_i - \frac{1}{2} \sum_{i,j} \alpha_i \alpha_j y_i y_j k(\boldsymbol{x}_i, \boldsymbol{x}_j)$$

模型为 $f(\boldsymbol{x}) = \sum_i \alpha_i y_i k(\boldsymbol{x}_i, \boldsymbol{x}) + b$。<span class="marginnote">核技巧最反直觉的地方：我们<strong>根本不知道 $\phi$ 长什么样</strong>，也能用核。只要 $k$ 合法，就存在某个隐式特征空间，$k$ 在其中是内积。这相当于「请了个看不见的巨人，只借用他的脚印」。</span>

**用高斯核（RBF）体验一下**：$k(\boldsymbol{x}_i, \boldsymbol{x}_j) = \exp\left(-\frac{\|\boldsymbol{x}_i - \boldsymbol{x}_j\|^2}{2\sigma^2}\right)$。它的展开对应一个**无穷维**特征映射，但计算只需一次指数运算——这正是核技巧威力的浓缩：理论上无穷维，计算上一步到位。

## 3 常用核函数| 核函数 | 表达式 | 特点 || --- | --- | --- || 线性核 | $k(\boldsymbol{x}_i, \boldsymbol{x}_j) = \boldsymbol{x}_i^{\mathrm{T}}\boldsymbol{x}_j$ | 即不做映射，退化为线性 SVM || 多项式核 | $k(\boldsymbol{x}_i, \boldsymbol{x}_j) = (\boldsymbol{x}_i^{\mathrm{T}}\boldsymbol{x}_j)^d$，$d \geq 1$ 为次数 | 对应 $d$ 次多项式特征空间 |
| 高斯核（RBF） | $k(\boldsymbol{x}_i, \boldsymbol{x}_j) = \exp\left(-\dfrac{\|\boldsymbol{x}_i - \boldsymbol{x}_j\|^2}{2\sigma^2}\right)$ | 无穷维映射，最常用；$\sigma$ 控制「局部作用半径」 |
| 拉普拉斯核 | $k(\boldsymbol{x}_i, \boldsymbol{x}_j) = \exp\left(-\dfrac{\|\boldsymbol{x}_i - \boldsymbol{x}_j\|}{\sigma}\right)$ | 对噪声更鲁棒 |
| Sigmoid 核 | $k(\boldsymbol{x}_i, \boldsymbol{x}_j) = \tanh(\beta \boldsymbol{x}_i^{\mathrm{T}}\boldsymbol{x}_j + \theta)$ | 某些条件下对应带隐层的神经网络 |

**辨析｜易错点：** 高斯核的 $\sigma$ 不是「越大越好」也不是「越小越好」。$\sigma$ 太小，每个样本只在极小的邻域内影响分类，容易把训练集「圈」成一块块孤岛——**过拟合**；$\sigma$ 太大，核近似常数，所有样本彼此几乎不分——**欠拟合**。工程上 $\sigma$ 与惩罚参数 $C$ 一起，是最需要调的 SVM 超参数。

## 4 公式解析：高斯核为什么「局部」高斯核 $k(\boldsymbol{x}_i, \boldsymbol{x}_j) = \exp\left(-\dfrac{\|\boldsymbol{x}_i - \boldsymbol{x}_j\|^2}{2\sigma^2}\right)$ 拆成四步理解：- **第一步，看自变量**：它是样本**距离** $\|\boldsymbol{x}_i - \boldsymbol{x}_j\|$ 的减函数——两个样本越近，核值越大（越相似）。- **第二步，看极限**：当 $\boldsymbol{x}_i = \boldsymbol{x}_j$ 时 $k = 1$；当距离趋于无穷时 $k \to 0$。核值域落在 $(0, 1]$。
- **第三步，看 $\sigma$ 的作用**：$\sigma$ 是「尺度」参数。$\sigma$ 大，指数衰减慢，即使距离较远核值仍不小——影响范围大、边界光滑；$\sigma$ 小，核值快速跌到 0——每个样本只影响自己的小邻域。
- **第四步，看模型含义**：$f(\boldsymbol{x}) = \sum_i \alpha_i y_i k(\boldsymbol{x}_i, \boldsymbol{x}) + b$ 意味着预测时，每个支持向量按它与 $\boldsymbol{x}$ 的相似度「投票」——高斯核下，只有离 $\boldsymbol{x}$ 近的支持向量才有实质影响力，这正是「局部加权」式的决策。

**直觉一句话**：高斯核把「线性 SVM」升级成了「以每个支持向量为中心、按距离衰减的高斯核加权投票」——一个自动形成的、可解释为局部模板匹配的分类器。

## 5 什么样的函数能当核：核矩阵半正定不是随便一个二元函数都能当核。**核矩阵（kernel matrix）**$\mathbf{K} = [k(\boldsymbol{x}_i, \boldsymbol{x}_j)]_{m \times m}$ 是一个 $m \times m$ 的对称矩阵。一个函数是合法核的充要条件是：**对任意样本集，核矩阵是半正定的**（Mercer 定理 / 核函数判定）。- 半正定保证：存在特征映射 $\phi$，使 $k(\boldsymbol{x}_i,\boldsymbol{x}_j) = \langle\phi(\boldsymbol{x}_i), \phi(\boldsymbol{x}_j)\rangle$ 成立——即「合法的核 = 某个隐式内积」；- 常用核都满足这一性质，也可由「核的组合」构造新核：核的正数倍、核之和、核之积仍是核。<span class="marginnote">「核矩阵半正定」是连接泛函分析（第二级）与机器学习的桥。实际实现中，如果自定义一个核，第一步就是检查核矩阵的半正定性，否则优化问题不再凸，对偶不成立。</span>


实践中如何验证「自定义核合法」？步骤很机械：1. 取一组样本，计算核矩阵 $K=[k(x_i,x_j)]_{m\times m}$；2. 检查 $K$ 是否**对称**（$k(x_i,x_j)=k(x_j,x_i)$）；3. 计算 $K$ 的**特征值**，检查是否全部 ≥ 0（半正定）；4. 若有负特征值，说明 $k$ 不是合法核——需要修改设计。一个反例：$k(x_i,x_j) = \|x_i - x_j\|^2$（欧氏距离平方）**不是**合法核（对应「负定」），它不能写成某个特征空间的内积。而高斯核、多项式核、线性核都满足半正定。**思考题**：为什么「核的和、积、正数倍仍是核」？用「核 = 隐式内积」这个视角怎么理解？
## 拓展：核矩阵的半正定检查

实践中如何验证「自定义核合法」？步骤很机械：

1. 取一组样本，计算核矩阵 $K=[k(x_i,x_j)]_{m\times m}$；
2. 检查 $K$ 是否**对称**（$k(x_i,x_j)=k(x_j,x_i)$）；
3. 计算 $K$ 的**特征值**，检查是否全部 ≥ 0（半正定）；
4. 若有负特征值，说明 $k$ 不是合法核——需要修改设计。

一个反例：$k(x_i,x_j) = \|x_i - x_j\|^2$（欧氏距离平方）**不是**合法核（对应「负定」），它不能写成某个特征空间的内积。而高斯核、多项式核、线性核都满足半正定。

## 知识速查：核函数

**本节关键词**
- 核技巧
- 特征映射
- 内积
- 高斯核
- 多项式核
- 核矩阵
- 半正定
- Mercer 定理

**三条常见误区**
1. 以为需要知道 φ 才能用核——核直接给内积；
2. 把 σ 当越大越好——太小过拟合太大欠拟合；
3. 忽略核矩阵半正定这一合法性检查。

**核心结论**
1. 核 = 隐式高维空间的内积；
2. 核技巧不用显式映射即可算高维内积；
3. 高斯核对应无穷维映射；
4. 核矩阵半正定是合法核的充要条件。

**与全书/后续的连接**
- 第6章核方法是核技巧的一般化；
- 第10章 KPCA 把核用到降维；
- 高斯过程把核当协方差。

**常见面试题**
1. 问：为什么高斯核能处理任意非线性？ 答：它对应无穷维特征映射，表达力来自维度。
2. 问：σ 太小时会发生什么？ 答：每个样本只影响小邻域，容易过拟合。

**一句话记忆**
核 = 隐式高维空间的内积，只算内积、不显式映射。

## 6 小结- 非线性 SVM 的思路：把样本映射到高维特征空间 $\phi(\boldsymbol{x})$ 再做线性分类。- **核技巧**：$k(\boldsymbol{x}_i,\boldsymbol{x}_j) = \langle\phi(\boldsymbol{x}_i),\phi(\boldsymbol{x}_j)\rangle$，只算高维内积、不显式映射，绕开「无穷维」与「计算贵」两个难题。- 常用核：线性、多项式、**高斯（RBF）**、拉普拉斯、Sigmoid；高斯核对应无穷维映射，是最常用的默认选择。- 核函数合法的充要条件是**核矩阵半正定**（Mercer 定理）；核的组合仍是核。
- 高斯核的 $\sigma$ 是双刃剑：太小过拟合、太大欠拟合。
