## 为什么从低维嵌入开始

上一节 kNN 让我们看到了维数灾难的可怕：高维数据里距离失去意义，所有样本都「差不多远」。既然高维是负担，那最直接的对策就是——**把数据降回一个「够用」的低维空间**。这就是**降维（dimensionality reduction）**：在尽量保留原始结构的前提下，把样本从高维映射到低维。

**低维嵌入（low-dimensional embedding）**是降维的统称，而**多维缩放（Multidimensional Scaling, MDS）**是其中「保持距离」思路的鼻祖：它要求降维后的样本两两距离，**尽可能等于**原始空间的距离。这一节以 MDS 为主线，讲清「降维为什么可能、MDS 怎么做到保持距离、以及它和 PCA 的关系」。<span class="marginnote">MDS 的历史比机器学习早得多，起源于心理学与计量学（把「相似度评分」还原成空间坐标），是「从距离数据重构坐标」的老牌方法。它的现代亲戚遍布各处：社交网络嵌入、词向量可视化、以及流形学习的先声。</span>

## 1 降维为什么可能：数据不是真高维高维数据的本质常是「虚胖」：$d$ 维特征里很多是**冗余**的——要么互相相关（同一事实的多种度量），要么变化很小（几乎恒定）。真正决定样本差异的**内在自由度**往往远小于 $d$。**例子**：一张 100×100 的灰度照片是 10000 维向量，但同一物体在自然光照下的照片，其本质变化只有姿势、光照等少数几个因素——数据其实「躺」在一个远低于 10000 维的低维结构（流形）上。**降维就是把这层「低维真相」从高维表象里剥离出来。**<span class="marginnote">「数据躺在一个低维流形上」是第10章后半段流形学习的核心假设，也是深度学习里「表征学习」的直觉来源——网络每一层都在逐级「去冗余、提本质」。降维不是丢掉信息，而是<strong>剔除伪装成信息的冗余</strong>。</span>## 2 MDS 的目标：保持两两距离**多维缩放（MDS）**的目标很直接：给定 $m$ 个样本在原始空间的距离矩阵 $\mathbf{D} = [dist_{ij}]$，求它们在 $d'$ 维空间（$d' < d$）中的表示 $\mathbf{Z} = [\boldsymbol{z}_1, \dots, \boldsymbol{z}_m]$，使得`$$`\|\boldsymbol{z}_i - \boldsymbol{z}_j\| \approx dist_{ij}, \qquad \forall i, j`$$`即**降维后样本间的欧氏距离尽量等于原距离**。这样，kNN 等「距离驱动」的方法在低维空间里就能重新正常工作——降维把「维数灾难」的空间「拉回人间」。
**什么时候能精确保持**：若距离矩阵来自某个低维欧氏空间（存在真实坐标），MDS 能**精确重构**；若距离只是近似（含噪声），MDS 给出**最优近似**。<span class="marginnote">「从距离反推坐标」听起来像魔术，其实用的是线性代数：把距离平方矩阵中心化后，得到的就是样本内积矩阵 $\mathbf{B} = \mathbf{Z}\mathbf{Z}^{\mathrm{T}}$，对 $\mathbf{B}$ 做特征分解即可读出坐标。距离决定内积、内积决定坐标——中间只隔一次特征分解。</span>

## 2 公式解析：MDS 的推导脉络- **第一步，从距离到内积**：设降维后样本内积矩阵 $\mathbf{B} = \mathbf{Z}\mathbf{Z}^{\mathrm{T}}$，即 $b_{ij} = \boldsymbol{z}_i^{\mathrm{T}}\boldsymbol{z}_j$。利用恒等式 $\|\boldsymbol{z}_i - \boldsymbol{z}_j\|^2 = \|\boldsymbol{z}_i\|^2 + \|\boldsymbol{z}_j\|^2 - 2\boldsymbol{z}_i^{\mathrm{T}}\boldsymbol{z}_j$，距离平方 $d_{ij}^2$ 与内积 $b_{ij}$ 线性相关。- **第二步，中心化消除平移**：令样本中心在原点（$\sum_i \boldsymbol{z}_i = \mathbf{0}$），可解出内积矩阵元素：`$$`b_{ij} = -\frac{1}{2}\left(d_{ij}^2 - d_{i\cdot}^2 - d_{\cdot j}^2 + d_{\cdot\cdot}^2\right)`$$`其中 $d_{i\cdot}^2$ 是第 $i$ 行距离平方的均值、$d_{\cdot j}^2$ 是第 $j$ 列均值、$d_{\cdot\cdot}^2$ 是全矩阵均值——这三项把「平方距离矩阵」中心化，剥掉平移与缩放自由度。
**第三步，特征分解取坐标**：对 $\mathbf{B}$ 做特征分解 $\mathbf{B} = \mathbf{V}\mathbf{\Lambda}\mathbf{V}^{\mathrm{T}}$，取前 $d'$ 个最大特征值及其特征向量，得 $\mathbf{Z} = \mathbf{\Lambda}^{1/2}\mathbf{V}^{\mathrm{T}}$（保留前 $d'$ 维）。**前 $d'$ 个特征值的大小，对应这 $d'$ 维能解释多少距离信息。**
**第四步，选择 $d'$**：看特征值谱——特征值骤降处就是「内在维度」的提示；也可按「保留累计贡献 ≥ 某阈值」来定。

**直觉一句话**：MDS 把「保持距离」翻译成「对平方距离矩阵中心化 → 得内积矩阵 → 特征分解取主方向」——降维问题的解，藏在特征分解里。

## 3 MDS 与 PCA 的关系MDS 与下一节的 PCA 有深层联系：- **目标不同**：MDS 保持**两两距离**（基于距离矩阵）；PCA 最大化**投影后方差**（基于协方差矩阵）。- **结果相通**：当 MDS 用欧氏距离、且样本已中心化时，MDS 的结果与 PCA 等价——因为平方欧氏距离的中心化矩阵，恰好是协方差矩阵的 $\mathbf{X}\mathbf{X}^{\mathrm{T}}$ 形式，两者的特征分解共享同一套主方向。<span class="marginnote">「欧氏 MDS = PCA」是第10章最值得记的等价关系之一：一个从「距离」出发、一个从「方差」出发，却殊途同归。区别在于 MDS 只需距离矩阵（连原始特征都不用给），所以它能处理「只有相似度、没有坐标」的数据——比如问卷打分、用户相似度表。</span>**辨析｜易错点：** MDS 是**线性**降维——它假设低维结构能用全局线性坐标表示。如果数据的低维结构是**弯曲**的（如 S 形流形），全局欧氏距离会被「切弯取直」，MDS 重构失真——这正是流形学习（Isomap、LLE，第10章后段）要解决的问题：**先按流形上的「测地距离」而非欧氏距离来算距离，再做 MDS**。

## 知识速查：低维嵌入与 MDS

**本节关键词**
- 降维
- 低维嵌入
- MDS
- 距离保持
- 内积矩阵
- 特征分解
- 中心化
- 欧氏等价 PCA

**三条常见误区**
1. 把 MDS 当「画图工具」——它是降维方法；
2. 忽略中心化在从距离到内积中的角色；
3. 以为 MDS 处理弯曲流形——它是线性方法。

**核心结论**
1. MDS 让降维后距离尽量等于原距离；
2. 从平方距离矩阵中心化得内积矩阵；
3. 特征分解取前 d' 特征向量重构坐标；
4. 欧氏 MDS 与 PCA 等价。

**与全书/后续的连接**
- 第10章 PCA 与其等价；
- 第10章 Isomap 把 MDS 用于测地距离；
- 第2级线性代数特征分解。

**常见面试题**
1. 问：MDS 只需什么输入？ 答：距离矩阵，连原始坐标都不用给。
2. 问：MDS 为何处理不了弯曲流形？ 答：它是线性方法，全局欧氏距离会切弯取直。

**一句话记忆**
MDS = 从距离矩阵反推低维坐标，一次特征分解搞定。

## 4 小结- **降维**在保留结构的前提下把高维映射到低维，破解维数灾难；数据「虚胖」是因为内在自由度常远小于特征维数。- **MDS** 要求降维后距离 $\|\boldsymbol{z}_i-\boldsymbol{z}_j\| \approx dist_{ij}$，只需距离矩阵即可工作。- 推导三步：**距离→内积**（中心化）、**特征分解 $\mathbf{B}=\mathbf{V}\mathbf{\Lambda}\mathbf{V}^{\mathrm{T}}$**、**取前 $d'$ 特征值重构坐标**。- 欧氏距离下的 MDS 与 **PCA 等价**（距离视角 vs 方差视角殊途同归）。- MDS 是**线性**方法，对弯曲流形失真——那正是流形学习的战场。
