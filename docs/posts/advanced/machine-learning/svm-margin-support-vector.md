## 为什么从间隔与支持向量开始

第5章的神经网络靠「多层堆叠 + 梯度下降」逼近任意函数，但它的学习过程像在黑箱里摸索——没有清晰的理论边界。第6章的**支持向量机（Support Vector Machine, SVM）**走的是另一条路：**从几何直觉出发，把分类问题定义成一个带约束的凸优化问题，追求一个「最稳」的划分超平面**。它也许是机器学习里理论最优雅的模型——第2章的偏差-方差、第3章的线性模型、第12章的 VC 维，都能在 SVM 身上找到落点。

这一节先建立 SVM 的几何基础：什么是**间隔**、什么是**支持向量**、为什么「间隔最大」的超平面最好。这三块拼图拼起来，就是 SVM 的全部出发点。<span class="marginnote">SVM 由 Vapnik 与 Chervonenkis 在 1960 年代提出，理论基础横跨统计学习理论。它一度是 2000 年代机器学习的事实标准，直到深度学习复兴——但它的思想至今活在核方法、SVR、以及一切「最大间隔」式的建模里。</span>

## 1 划分超平面不止一条对线性可分数据，能把两类分开的超平面**有无穷多条**：稍微平移一点、旋转一点，都是合法的划分。但它们的「稳」不一样。在样本空间中，划分超平面可用线性方程描述：
$$\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b = 0$$

其中 $\boldsymbol{w} = (w_1, \dots, w_d)$ 是法向量，决定超平面方向；$b$ 是位移项，决定超平面与原点的距离。样本点 $\boldsymbol{x}$ 到超平面的距离为

$$r = \frac{\left|\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b\right|}{\|\boldsymbol{w}\|}$$

**直觉**：离超平面越近的样本，越容易被「震一下」就分错类——它们就像战场上最前沿的哨兵。一个稳健的分类器，应当让超平面离两侧最近的样本都足够远。

## 2 间隔与支持向量对线性可分的数据，总可以**对超平面缩放**，使最近的正反例满足 $\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i + b = \pm 1$（这种规范化只是缩放 $\boldsymbol{w}, b$，不改变超平面本身）。于是：**间隔（margin）**定义为两个异类支持向量到超平面的距离之和：
$$\gamma = \frac{2}{\|\boldsymbol{w}\|}$$

**支持向量（support vector）**定义为距离超平面最近的那几个训练样本点——它们恰好落在间隔边界上，满足 $\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i + b = \pm 1$。除了支持向量，其他样本到超平面的距离都更大，因此在约束中「不活跃」。

**为什么支持向量重要？** 因为它决定了整个模型：**丢掉所有非支持向量，重新训练，得到的超平面完全不变。** 这意味 SVM 的解只由少数边界样本决定，而非常依赖数据整体分布——这是它与逻辑回归、神经网络「所有样本都参与决策」的本质区别。<span class="marginnote">「解只由支持向量决定」这个性质，让 SVM 天然具有稀疏性——模型存储只需要记住支持向量与权重，这也在后续引出核函数时变得至关重要（核 SVM 只需支持向量的内积）。</span>

## 3 最大间隔：最稳的超平面**核心思想：选择间隔最大的超平面。** 在所有能正确分类的 $\boldsymbol{w}, b$ 中，最大化 $\gamma = 2 / \|\boldsymbol{w}\|$，等价于最小化 $\|\boldsymbol{w}\|^2 / 2$。加上「所有样本分类正确且在间隔外」的约束，得到 SVM 的**基本型（primal form）**：`$$`\min_{\boldsymbol{w}, b} \; \frac{1}{2}\|\boldsymbol{w}\|^2 \quad \text{s.t.} \quad y_i\left(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i + b\right) \geq 1, \quad i = 1, 2, \dots, m$$
其中 $y_i \in \{+1, -1\}$。**最大间隔超平面（maximum margin hyperplane）**就是上述问题的解。

**为什么最大间隔的泛化好？** 直觉上，间隔越大，超平面对样本的轻微扰动越不敏感——分类决策的「安全垫」越厚。这一直觉在理论上被计算学习理论严格化：**间隔与泛化误差上界相关，间隔越大，结构风险上界越紧**（第12章会展开）。<span class="marginnote">把「间隔最大化」与第2章的偏差-方差对照：最小化 $\|\boldsymbol{w}\|^2$ 本质是一种<strong>结构风险最小化</strong>——它限制模型复杂度，降低过拟合；这与正则化殊途同归，下一节《软间隔与正则化》会精确到「SVM 的正则项就是 $\|\boldsymbol{w}\|^2$」。</span>

## 4 公式解析：为什么最大化间隔 = 最小化 $\|\boldsymbol{w}\|^2$- **第一步，几何间隔的定义**：样本到超平面的几何间隔是 $\dfrac{y_i(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i + b)}{\|\boldsymbol{w}\|}$。分子带 $y_i$ 是为了取正号——分类正确的样本，$y_i(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i + b) > 0$。- **第二步，规范化使支持向量处分子为 1**：对超平面缩放，使最近样本满足 $y_i(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i + b) = 1$。这一步把「距离」的分子固定成 1，间隔只剩分母 $\|\boldsymbol{w}\|$ 在起作用。- **第三步，最小化 $\|\boldsymbol{w}\|^2$ 代替最大化 $1/\|\boldsymbol{w}\|$**：最大化 $\dfrac{2}{\|\boldsymbol{w}\|}$ 与最小化 $\|\boldsymbol{w}\|$ 等价；为了求导方便写成 $\dfrac{1}{2}\|\boldsymbol{w}\|^2$，系数 1/2 是为了让 $\|\boldsymbol{w}\|^2$ 的导数是 $\boldsymbol{w}$ 而不是 $2\boldsymbol{w}$。- **第四步，读出约束的含义**：$y_i(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i + b) \geq 1$ 要求每个样本要么在间隔边界外（$\geq 1$），要么恰好落在边界上（$= 1$，即支持向量）——**不允许任何样本进入间隔内部**。

**直觉一句话**：SVM 在「所有样本都分对」的前提下，把超平面往正反例中间**推得最开**；谁卡住了它，谁就是支持向量。

## 5 核心对比表：SVM 与相邻模型| 维度 | 感知机 | 逻辑回归 | SVM（硬间隔） || --- | --- | --- | --- || 解的类型 | 任一可行超平面 | 概率最大化解 | **间隔最大**超平面 || 决策依据 | 误分类样本 | 全体样本（似然） | **支持向量** |
| 损失视角 | 误分类计数 | 对数似然损失 | 合页损失（Hinge） |
| 正则化 | 无 | 显式加正则项 | 内嵌 $\|\boldsymbol{w}\|^2$ |
| 解的稀疏性 | 否 | 否 | 是 |

**辨析｜易错点：** 感知机只要求「分对」，找到**任意一个**可行超平面就停（依赖初始值）；SVM 在可行解里再挑**间隔最大**的那个，解唯一且更稳。这就是「可行」与「最优」的天壤之别——也是 SVM 名字里「支持向量」只关心边界样本的原因。<span class="marginnote">逻辑回归虽然也产出「概率」，但它让所有样本都对边界「施加压力」，因此权重由全局数据决定、无稀疏性；SVM 则让支持向量「独揽大权」。两种建模哲学的取舍，在离群点与数据规模上会分道扬镳。</span>


SVM 的最大间隔与正则化之间有更精确的换算，值得一记：软间隔 SVM 的目标 $\min \frac{1}{2}\|w\|^2 + C\sum_i \xi_i$ 等价于`$$`\min_w \sum_i \ell_{\text{hinge}}(y_i w^\top x_i) + \lambda \|w\|^2, \qquad C = \frac{1}{\lambda}`$$`也就是说：**SVM 就是「合页损失 + L2 正则」**，最大间隔是 L2 正则的几何解释。这个双向视角让 SVM 与逻辑回归（交叉熵 + 正则）、岭回归（平方损失 + 正则）在「损失 + 正则」的统一框架里会师——第6章《软间隔与正则化》的伏笔在这里闭环。**思考题**：为什么「间隔越大，VC 维的有效值越小」？这与 SVM 用核升维却不过拟合矛盾吗？
## 拓展：间隔与正则化的双向视角

SVM 的最大间隔与正则化之间有更精确的换算，值得一记：

软间隔 SVM 的目标 $\min \frac{1}{2}\|w\|^2 + C\sum_i \xi_i$ 等价于

$$\min_w \sum_i \ell_{\text{hinge}}(y_i w^\top x_i) + \lambda \|w\|^2, \qquad C = \frac{1}{\lambda}$$

也就是说：**SVM 就是「合页损失 + L2 正则」**，最大间隔是 L2 正则的几何解释。这个双向视角让 SVM 与逻辑回归（交叉熵 + 正则）、岭回归（平方损失 + 正则）在「损失 + 正则」的统一框架里会师——第6章《软间隔与正则化》的伏笔在这里闭环。

## 知识速查：间隔与支持向量

**本节关键词**
- 支持向量机
- 间隔
- 支持向量
- 几何间隔
- 最大间隔
- 基本型
- 结构风险
- 稀疏性

**三条常见误区**
1. 把「任意可行超平面」当 SVM 解——SVM 求的是最优；
2. 忽略「解只由支持向量决定」的稀疏性；
3. 把间隔与函数间隔混用——几何间隔才是不变量。

**核心结论**
1. SVM 在所有正确划分里选间隔最大的；
2. 支持向量落在间隔边界、决定整个模型；
3. 最大化间隔等价于最小化 ||w||²；
4. 解只由支持向量决定、天然稀疏。

**与全书/后续的连接**
- 第3章线性模型是它的基础；
- 第12章间隔与泛化界挂钩；
- 第6章软间隔与正则化是它的延续。

**常见面试题**
1. 问：为什么间隔大泛化好？ 答：安全垫厚、对扰动不敏感，理论对应更紧的泛化界。
2. 问：支持向量与一般样本的区别？ 答：丢掉非支持向量重训解不变，模型只记住边界样本。

**一句话记忆**
SVM = 在所有正确划分里选间隔最大的那一个，支持向量独揽决策权。

## 6 小结- 划分超平面 $\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b = 0$ 有无穷多条，SVM 选择**间隔最大**的一条。- **间隔** $\gamma = 2/\|\boldsymbol{w}\|$ 是两侧支持向量间的距离；**支持向量**是落在间隔边界上的最近样本，解只由它们决定。- **基本型**：$\min_{\boldsymbol{w},b}\frac{1}{2}\|\boldsymbol{w}\|^2$ s.t. $y_i(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i + b) \geq 1$，是结构风险最小化思想的体现。- 最大间隔直觉上是「安全垫最厚」，理论上与泛化误差上界挂钩。
- 与感知机、逻辑回归对比：SVM 求**最优**而非**可行**解，且解**稀疏**。
