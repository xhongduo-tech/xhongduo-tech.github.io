## 为什么从多样性开始

前面几节反复强调集成需要「好而不同」的个体，但「不同」一直是个模糊的说法。这一节要把「不同」**量化**：集成的误差到底怎么分解成「个体的误差」与「个体间的分歧」？度量多样性的尺子有几把？以及最实际的——**怎样在工程上制造多样性**？它是第8章的收官，把「集成为什么有效」从一个比喻变成一个等式。

**误差-分歧分解（error-ambiguity decomposition）**给出了让人吃惊的结论：**集成的误差 = 个体平均误差 − 个体间的平均分歧**。换句话说，个体越「笨」（平均误差大）集成越差，但个体越「各执一词」（分歧大）集成反而越好——多样性第一次被写进一个精确的公式。<span class="marginnote">误差-分歧分解最初由 Krogh & Vedelsby（1995）给出，适用于回归与多数投票的近似分析。它的意义不仅是理论上的：它明确告诉你「训练个体时太追求一致反而伤集成」，为后文的多样性增强提供了理论执照。</span>

## 1 误差-分歧分解：集成误差 = 平均误差 − 平均分歧以回归为例（集成取平均 $H = \frac{1}{T}\sum_t h_t$），对样本 $\boldsymbol{x}$，设真实值 $f(\boldsymbol{x})$。定义：- **个体误差**：$E_t = \left(h_t(\boldsymbol{x}) - f(\boldsymbol{x})\right)^2$；- **分歧（ambiguity）**：$A_t = \left(h_t(\boldsymbol{x}) - H(\boldsymbol{x})\right)^2$——个体与集成之差的平方，度量「这个个体有多不合群」。

**误差-分歧分解**：

$$E = \bar{E} - \bar{A}$$

其中 $\bar{E} = \frac{1}{T}\sum_t E_t$ 是个体平均误差，$\bar{A} = \frac{1}{T}\sum_t A_t$ 是个体平均分歧。**集成的误差 = 个体的平均误差 − 个体的平均分歧。**<span class="marginnote">这个等式还能写成「偏差-方差」的语言：个体误差均值 $\bar{E}$ 反映「大家平均有多偏」，分歧 $\bar{A}$ 反映「大家有多不齐」。分解告诉我们：一个集成想成功，要么把 $\bar{E}$ 压小（个体都准），要么把 $\bar{A}$ 拉大（个体差异大），两条路都通向更小的集成误差。</span>

## 2 公式解析：分解为什么成立把三项都写成期望的形式，验证等式：- **第一步，展开集成误差**：$E = \left(H(\boldsymbol{x}) - f(\boldsymbol{x})\right)^2$。- **第二步，用恒等变形**：$H - f = \frac{1}{T}\sum_t (h_t - f)$，于是 $E = \left[\frac{1}{T}\sum_t (h_t - f)\right]^2$。
- **第三步，展开平方**：由「平方的均值 = 均值的平方 + 方差」，$\left(\frac{1}{T}\sum_t d_t\right)^2 = \frac{1}{T}\sum_t d_t^2 - \frac{1}{T}\sum_t(d_t - \bar{d})^2$，其中 $d_t = h_t - f$。
- **第四步，认回各量**：$\frac{1}{T}\sum_t d_t^2 = \bar{E}$（个体误差均值）；$\frac{1}{T}\sum_t(d_t - \bar{d})^2$ 正是平均分歧 $\bar{A}$（因为 $h_t - H = d_t - \bar{d}$）。于是 $E = \bar{E} - \bar{A}$ 成立。

**直觉一句话**：集成的「平均」把个体的误差互相抵消了一部分，抵消的量恰是「个体间分歧」——**分歧就是可被平均掉的那部分误差**。

## 3 多样性度量：几把尺子理论说「多样好」，实践需要**度量多样性**。常用尺子（两两分类器在 $m$ 个样本上的不一致程度）：- **不合度量（disagreement）**：$dis_{ij} = \frac{1}{m}\sum_{k=1}^{m}\mathbb{I}\left[h_i(\boldsymbol{x}_k) \neq h_j(\boldsymbol{x}_k)\right]$——两人意见不合的样本比例。- **相关系数（correlation coefficient）**：把两个分类器的输出（±1）当两个随机变量，算 Pearson 相关——相关性越低越多样。
- **Q 统计量**：对「两者都对 / 都对 / 一错一对」的计数组合构造的统计量，取值范围 $[-1,1]$，越接近 0 越多样。
- **Kappa 统计量**：度量两个分类器在去掉「碰巧一致」后的真实一致性，$\kappa = \frac{p_0 - p_e}{1 - p_e}$，$\kappa$ 越低越多样。<span class="marginnote">Kappa 是评估「一致率中剔除偶然成分」的标准工具：两个分类器可能因为「都偏爱多数类」而经常一致，但这并不代表「真正协同」。$\kappa$ 把这种偶然一致扣除后，剩下的才是有意义的共识。它在医学诊断一致性研究里也是标配。</span>

## 4 多样性增强：四种「扰动」有了度量的尺子，更重要的是**制造**多样性的工程手段。教材归纳为四类扰动：- **数据样本扰动**：让不同个体用不同数据子集训练——自助抽样（Bagging）是典型；对数据敏感的学习器（如决策树）扰动效果显著。- **输入属性扰动**：让不同个体用不同特征子集——随机森林的特征随机；对属性冗余的数据效果好。
- **输出表示扰动**：改动输出编码/标记——如把多分类拆成多个二分类的**纠错输出码（ECOC）**，不同的码表给不同个体制造差异。
- **算法参数扰动**：对同一算法用不同超参数/初始点——如不同隐层数的神经网络、不同惩罚系数的 SVM。<span class="marginnote">「扰动」是多样性增强的总纲：无论是摇样本、换特征、改输出还是调参数，本质都是让每个个体「只看到世界的一个侧面」。对<strong>不稳定</strong>的算法（决策树、神经网络）扰动效果最强，对<strong>稳定</strong>的算法（线性模型、KNN）效果有限——因为稳定的算法对数据扰动不敏感。</span>

**辨析｜易错点：** 多样性不是越高越好。误差-分歧分解里 $\bar{A}$ 大了 $\bar{E}$ 往往也大（过于「各执一词」通常意味着个体在某处乱猜）。**「好而不同」是联合要求**：要在个体误差不过度上升的前提下拉大分歧。极端情况——纯随机猜测的个体分歧极大，但平均误差也极大，集成照样糟糕。<span class="marginnote">这个「不能只追多样性」的告诫在实际调参里极常见：把 Bagging 的抽样搞得过分极端、或把随机森林的特征子集压得过小，个体变弱，集成反而退化。多样性是「在保持准确前提下」的多样性。</span>

## 知识速查：多样性

**本节关键词**
- 误差-分歧分解
- 不合度量
- Q 统计量
- Kappa
- 数据扰动
- 特征扰动
- 输出扰动
- 参数扰动

**三条常见误区**
1. 把「分歧越大越好」当真理——个体变弱集成也变差；
2. 忽略多样性度量要剔除偶然一致（Kappa）；
3. 以为扰动对所有算法都有效——稳定算法不敏感。

**核心结论**
1. 误差-分歧分解：集成误差 = 平均误差 − 平均分歧；
2. 分歧 = 可被平均掉的那部分误差；
3. 多样性度量的尺子有不合度量/Kappa 等；
4. 多样性须与准确性联合考量。

**常见面试题**
1. 问：误差-分歧分解说明了什么？ 答：个体误差小或分歧大都能改善集成。
2. 问：为什么不能只追多样性？ 答：分歧大通常伴随个体乱猜，平均误差也大。

**一句话记忆**
误差-分歧分解：集成误差 = 个体平均误差 − 平均分歧。

## 5 小结- **误差-分歧分解**：$E = \bar{E} - \bar{A}$，集成误差 = 个体平均误差 − 平均分歧；分歧是「可被平均掉的那部分误差」。- 多样性度量：**不合度量、相关系数、Q 统计量、Kappa 统计量**，本质都是「个体间不一致程度」。- 多样性增强四手段：**数据样本扰动、输入属性扰动、输出表示扰动、算法参数扰动**。- 对不稳定算法（树、神经网络）扰动收益大；对稳定算法（线性模型）扰动无效。
- 多样性必须与准确性联合考量——「好而不同」才是目标，只追多样性反而伤集成。
