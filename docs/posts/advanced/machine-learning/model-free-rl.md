## 为什么从免模型学习开始

上一节的动态规划依赖「已知转移模型 $P$ 与奖赏 $R$」——但现实里这几乎从不成立：没人给你一张「状态转移概率表」，环境只会通过交互「回答」你的动作。**免模型学习（model-free RL）**放弃「先学模型再规划」的路线，**直接从交互数据里学习值函数或策略**——不知道世界怎么转，也能学会怎么走。

免模型学习的两条经典路线——**蒙特卡洛（Monte Carlo, MC）**与**时序差分（Temporal Difference, TD）**——对应 RL 的两大血脉，并最终催生现代深度 RL 的基石 **Q-learning** 与 **Sarsa**。<span class="marginnote">「有模型 vs 免模型」的分界在应用上极为关键：AlphaZero 用「棋规 = 完美模型」做规划；而 OpenAI 的机器人控制、聊天机器人的 RLHF 都没有可用模型，只能免模型。免模型是 RL 的「常态」，因为它只要求「能交互」——这是最现实的条件。</span>

## 1 蒙特卡洛：回合终了才学**蒙特卡洛方法**的思路是「等到一局结束再总结」：
1. 用当前策略跑完**一整回合（episode）**，得到轨迹 $s_0, a_0, r_1, s_1, \dots, s_T$；
2. 回合结束后，计算每个状态的真实累计奖赏 $G_t$（事后诸葛，知道全程了）；
3. 用 $G_t$ 更新值函数：

$$V(s_t) \leftarrow V(s_t) + \alpha\left(G_t - V(s_t)\right)$$

**特点**：$G_t$ 是「无偏」的（真实观察到的累计奖赏），但**方差大**（整局运气都算进去），且**必须等回合结束**才能更新——学习「慢一拍」。<span class="marginnote">「回合制」是 MC 的前提：必须有一局能跑到头（棋类、游戏可以；但「围棋中盘」这种没终局的任务不行）。MC 的 $G_t$ 无偏但方差大——就像「等考试成绩出来才复盘」，反馈真实但滞后且波动大。它的「事后总结」思路很直觉，但效率不高。</span>

## 2 时序差分：走一步学一步**时序差分（Temporal Difference, TD）**是 MC 的升级：**不用等回合结束**，每走一步就用「当前奖赏 + 下一状态的值」作为「目标」更新当前状态：
$$V(s) \leftarrow V(s) + \alpha\left[ \underbrace{r + \gamma V(s')}_{\text{TD 目标}} - V(s) \right]$$

**与 MC 的本质差别**：

- MC 用**真实的** $G_t$（事后完整信息），TD 用 **估计的** $r + \gamma V(s')$（走一步就用下一步的估计）——这叫「**自举（bootstrapping）**」：用「估计」去更新「估计」；
- TD 的目标**有偏**（$V(s')$ 是估计，不准）但**方差小**、可**在线更新**（每步都学）——「走一步学一步」，效率远高于 MC。

**直觉**：TD 像「学走路时每迈一步就自评一次」，MC 像「走到终点才回头看全程」。TD 更快但带点自我估计的偏差，MC 更真实但慢——这是「偏 vs 方差」的又一次经典权衡。<span class="marginnote">「自举」是 TD 家族的精髓：用「当前估计」更新「当前估计」。它让学习无需等回合结束（支持在线、无限任务），代价是引入估计偏差。MC vs TD 的「无偏慢 vs 有偏快」是 RL 里最值得记住的一对权衡——后面几乎所有免模型算法都是在这条轴上的选择。</span>

## 3 公式解析：Q-learning 与 SarsaTD 思想应用到 **Q 函数**上，得到两个最著名的免模型算法：
**Q-learning**（离策略，off-policy）：

$$Q(s, a) \leftarrow Q(s, a) + \alpha\left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$

**Sarsa**（在策略，on-policy）：

$$Q(s, a) \leftarrow Q(s, a) + \alpha\left[ r + \gamma Q(s', a') - Q(s, a) \right]$$

- **第一步，看相同骨架**：都是「$Q$ 沿 TD 目标挪一小步」，$\alpha$ 是学习率；
- **第二步，看关键差别**：TD 目标里的「下一个动作」——Q-learning 用 $\max_{a'}Q(s',a')$（**假设下一步做最优动作**，与当前策略无关，故称「离策略」）；Sarsa 用 $Q(s',a')$（**下一步实际按当前策略选的动作**，故称「在策略」）；
- **第三步，看含义**：Q-learning 学的是「**最优策略**下的 Q」（乐观，总是假设未来最优）；Sarsa 学的是「**当前策略**下的 Q」（务实，反映实际走法）；
- **第四步，看后果**：Sarsa 更「谨慎」（探索中的失误会被计入 Q），Q-learning 更「大胆」（无视当前策略、直奔最优）——**Q-learning 收敛到最优 Q，Sarsa 收敛到当前探索策略下的 Q**。

**直觉一句话**：Q-learning 与 Sarsa 的分水岭是「下一步按最优算还是按实际算」——**一个乐观、一个务实**，这是 off-policy 与 on-policy 的经典分界。<span class="marginnote">「on-policy vs off-policy」是 RL 最重要的分类之一：on-policy（Sarsa）用「正在执行的策略」产生的数据学自己；off-policy（Q-learning）可以用「任何策略」产生的数据学最优策略（所以可以「吃着碗里看着锅里」）。off-policy 的「数据效率」优势让 Q-learning 成为深度 RL（DQN）的基石——DQN 就是「Q-learning + 神经网络 + 经验回放」。</span>

## 4 核心对比表：MC vs TD vs 有模型| 维度 | 蒙特卡洛 | 时序差分（TD） | 有模型（DP） || --- | --- | --- | --- |
| 需要模型 | 否 | 否 | **是** |
| 更新时机 | 回合结束 | **每步** | 任意 |
| 更新目标 | 真实 $G_t$（无偏） | $r+\gamma V(s')$（自举） | Bellman 精确 |
| 方差 | 高 | 低 | 无（精确） |
| 偏差 | 无 | 有 | 无 |
| 效率 | 低 | 高 | 高（但需模型） |

**辨析｜易错点：** 免模型不是「没有模型」，而是「**不显式学模型、直接学值函数/策略**」。TD 的「自举」意味着它其实隐含了对未来值的「模型」（用 $V(s')$ 近似），只是不学显式的 $P, R$。<span class="marginnote">免模型家族的现代形态：DQN（Q-learning + 深度网络）、DDPG/PPO/SAC（策略梯度 + 演员-评论家）统治了深度 RL。而「TD 的自举 + 神经网络的函数近似」也带来新的不稳定问题（第5章局部极小的深度版）——这些是工程专题讨论的地带。学完 MC/TD/Q-learning/Sarsa，你就掌握了免模型 RL 的全部核心骨架。</span>

## 知识速查：免模型学习

**本节关键词**
- 蒙特卡洛
- 时序差分
- 自举
- Q-learning
- Sarsa
- on/off-policy
- TD 目标
- 免模型

**三条常见误区**
1. 把 MC 当「更准确」——它无偏但方差大、要等回合；
2. 忽略 TD 的自举引入偏差；
3. 把 Q-learning 与 Sarsa 混为一谈——off/on-policy 之别。

**核心结论**
1. MC 等回合用真实 G_t 更新、无偏但方差大；
2. TD 每步用 r+γV(s') 自举、有偏但高效；
3. Q-learning 离策略用 max、Sarsa 在策略用实际；
4. DQN 是 Q-learning 的深度化。

**与全书/后续的连接**
- 第16章有模型对照；
- 第7章自举思想同源；
- DQN 是 Q-learning 的深度化。

**常见面试题**
1. 问：MC 与 TD 的更新时机差别？ 答：MC 回合结束、TD 每步。
2. 问：off-policy 与 on-policy 的差别？ 答：Q-learning 假设未来最优，Sarsa 按当前策略实际走。

**一句话记忆**
免模型 = 不学模型直接从交互学值函数；MC 等回合、TD 走一步学一步。

## 5 小结- **免模型学习**不学模型，直接从交互数据学值函数/策略——是 RL 的现实常态。- **蒙特卡洛（MC）**：回合结束后用真实 $G_t$ 更新，无偏但方差大、必须等回合。
- **时序差分（TD）**：每步用「$r + \gamma V(s')$」自举更新，有偏但方差小、在线高效。
- **Q-learning**（离策略，用 $\max_{a'}Q(s',a')$）学最优 Q；**Sarsa**（在策略，用实际 $Q(s',a')$）学当前策略的 Q。
- MC vs TD 是「无偏慢 vs 有偏快」；off-policy vs on-policy 是「乐观 vs 务实」——两对权衡贯穿整个 RL。
