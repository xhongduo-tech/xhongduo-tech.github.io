## 为什么从全局最小与局部极小开始

上一节的 BP 算法沿负梯度方向调整权重——它在逻辑上自洽，却藏着一个数学上的不安：**梯度下降只是「沿着当前最陡的下坡走」，它无法保证停在整片地形的最低处。** 权重空间里的误差函数 $E(\boldsymbol{w})$ 起伏不定，像一片真实的山地，布满了波谷与洼地。BP 从某个随机起点滚下去，很可能停在一个**局部极小**就再也不动了，而真正的**全局最小**远在山的那一头。

这一节是「优化的直觉课」，也是第2章「模型评估」与第12章「计算学习理论」之间的桥梁。它回答三个问题：地形长什么样、为什么只能贪心、以及如何尽可能逃出局部极小。<span class="marginnote">对「全局 vs 局部」的焦虑在深度学习时代被重新审视：高维空间里局部极小点往往不再是灾难，这一点我们留到本节最后一小节展开。</span>

## 1 误差曲面的地形把网络的所有权重拼成一个向量 $\boldsymbol{w}$，误差函数 $E(\boldsymbol{w})$ 定义在权重空间上。几个关键地标：- **全局最小（global minimum）**：$\boldsymbol{w}^*$ 使 $E$ 取全局最小值，是理想的解；- **局部极小（local minimum）**：$\boldsymbol{w}$ 的某个邻域内 $E$ 最小，但全局未必——梯度为零、且四周都比它高；- **局部极大（local maximum）**：梯度为零、四周都比它低，是「山脊」上的点；- **鞍点（saddle point）**：梯度为零，但在某些方向是谷、某些方向是峰——是「马鞍」形地形，既非极小也非极大。
**核心结论：梯度为零的点（驻点）未必是极值点。** 一维情形梯度为零且二阶导为正才是局部极小；高维情形还要检查 Hessian 矩阵的正定性。<span class="marginnote">「梯度为零」只是必要条件。判断是极小、极大还是鞍点，要看 Hessian 矩阵的特征值符号——这一整套判据在第二级《最优化理论》里有完整展开，这里只建立直觉。</span>

## 2 为什么 BP 只会「贪心」BP 的更新规则 $w \leftarrow w + \Delta w$，$\Delta w = -\eta \frac{\partial E}{\partial w}$，本质是**梯度下降**。它的每一步都只看**当前点的局部信息**（梯度），不知道远处的地形。后果是：- 从不同随机初始点出发，BP 可能收敛到**不同的局部极小**——权重初始化对结果影响巨大；- 一旦进入某个波谷，梯度在谷底两侧指向谷底，模型「被吸住」，无法自己翻过两侧的山脊去看更低的谷。**辨析｜易错点：** 不要以为「误差为 0 就万事大吉」。训练集误差为 0 可能只是**恰好过拟合**；同样，**局部极小在训练集上未必比全局最小差多少**——两者都只是训练集上的表现，泛化性能才是终极裁判。这也是第2章反复强调「留出测试集」的原因：**优化看训练误差，评估看测试误差，两套信号必须分开。**
## 3 逃出局部极小的经典策略教材给出几种打破「贪心」的手段，它们都在「允许偶尔向上爬一点」上做文章：- **以多组不同参数值初始化多个网络**：按标准流程训练，取其中误差最小的解——相当于派多支登山队从不同山脚出发，总有一支更接近真正的谷底。这是**多起点（multiple restarts）**思路，最简单也最常用。- **模拟退火（simulated annealing）**：每步以一定概率接受「更差」的解，接受概率随「温度」下降而降低。高温时允许乱跑（有机会跨过山脊），低温时逐渐只接受改进——像金属退火一样慢慢「凝固」到低能态。<span class="marginnote">模拟退火源于统计力学：高温下粒子能越过能垒，降温后锁定在低能构型。它的接受概率公式（Metropolis 准则）与第14章 MCMC、第16章强化学习里的探索-利用权衡同源。</span>- **随机梯度下降与动量**：随机采样带来的**噪声**本身就能帮模型跳出浅的局部极小；**动量（momentum）**记录历史梯度方向，像滚雪球一样冲过窄谷与小坡。- **遗传算法（genetic algorithm）**：把一组权重当「种群」，通过选择、交叉、变异迭代演化，属于**全局搜索**方法，不依赖梯度，可在高维空间大范围探索。
## 4 一个关键的视角转换：高维地形当参数数量从几十涨到几百万，直觉要换一次。深度学习实践中人们发现：高维误差曲面上**鞍点远比局部极小常见**——因为在 $d$ 维空间，一个驻点是极小要求 Hessian 在所有 $d$ 个方向都为正，概率随 $d$ 指数下降。因此训练卡住往往不是「掉进局部极小」，而是**在鞍点附近停滞**（梯度接近零但不为极值）。更重要的是，深度学习实验表明：**在高维空间中，不同的局部极小在训练误差上往往非常接近，且都能泛化得不错**——真正坏的极小（训练误差很高）罕见，因为网络参数冗余、存在大量对称性。<span class="marginnote">这与教材成书年代的经典图景（少量参数、多个分离的局部极小）已有微妙差别。理解这一差异，是读懂后来深度学习「训练技巧为何有效」的钥匙：我们通常不需要「找到全局最小」，只需要「找到一个足够好的低误差区域」。</span>想亲眼看看「局部极小」长什么样？两个实用工具：- **损失地形可视化（loss landscape）**：选两个随机方向 $u,v$，把权重画成 $\theta = \theta_0 + \alpha u + \beta v$，对 $\alpha,\beta$ 网格采样算损失，画成三维曲面——论文里的「损失地形图」就是这个；- **训练轨迹投影**：把 SGD 每步的权重投影到 PCA 主平面上，看优化器在误差地形上的「行走路线」。这些可视化揭示了一个重要事实：**现代深度网络的损失地形比传统想象的「平缓」得多**——鞍点比局部极小常见，且大量局部极小性能相近。这也是「多起点 + 动量」等启发式在实践上够用的原因。**思考题**：为什么高维空间里「鞍点比局部极小常见」？（提示：驻点是极小的条件随维度指数变严）## 拓展：可视化误差地形的方法

## 知识速查：全局最小与局部极小

**本节关键词**
- 全局最小
- 局部极小
- 鞍点
- 梯度为零
- 多起点
- 模拟退火
- 动量
- 高维地形

**三条常见误区**
1. 把「梯度为零」当「极小」——还可能是鞍点/极大；
2. 以为训练误差为 0 就万事大吉——可能过拟合；
3. 用一维直觉理解高维——鞍点远比局部极小常见。

**核心结论**
1. 梯度为零只是驻点，不一定是极小；
2. BP 贪心下降可能停在局部极小；
3. 多起点/模拟退火/动量是逃逸手段；
4. 高维空间鞍点比局部极小更常见。

**常见面试题**
1. 问：为什么高维中鞍点常见？ 答：驻点是极小要求 Hessian 全方向为正，随维数指数变严。
2. 问：「误差为 0」意味着什么？ 答：可能只是过拟合了训练集，泛化未必好。

**一句话记忆**
梯度下降只保证「停在谷底」，不保证「停在最低的谷」——多起点与扰动来补救。

## 5 小结- 误差曲面有**全局最小、局部极小、局部极大与鞍点**；「梯度为零」只是驻点的必要条件。- **BP（梯度下降）是贪心算法**：只依赖当前点的局部梯度，可能停在局部极小；初始化决定它滚向哪个谷。- 逃逸策略：**多起点**、**模拟退火**、**随机噪声与动量**、**遗传算法**，核心都是「允许偶尔向上，换取跳出浅谷」。- 高维空间中**鞍点比局部极小更常见**，且局部极小之间的训练误差往往相近——深度学习的目标是「找到一个足够好的低误差区域」，而非执念于全局最小。## 本节路线图
