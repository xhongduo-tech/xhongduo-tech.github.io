## 为什么从连续值与缺失值开始

前几节的决策树都默认属性是**离散枚举值**：色泽取「青绿 / 乌黑 / 浅白」，根蒂取「蜷缩 / 稍蜷 / 硬挺」，按取值直接分叉即可。但真实数据远没有这么规整——「含糖率」是连续实数，能取无穷多个值，没法「每个取值一个分支」；「纹理」这类字段又常常缺掉，样本里空着一格。这两个问题不解决，决策树就只能在玩具数据上工作。

这一节是决策树的「工程关」。连续值靠**二分法**把它变成离散的两段，缺失值靠**带权重的样本处理**让信息不白白流失。<span class="marginnote">这两个技术对后续章节影响深远：C4.5 与 CART 的工业实现、以及工程专题里特征工程对缺失值的处理，思想都源于此。</span>

## 1 连续值处理：二分法连续属性 $a$ 在样本 $D$ 上有 $n$ 个不同取值 $a^1, a^2, \dots, a^n$（从小到大排好序）。**二分法（bi-partition）**的思路是：不按每个值分叉，而是只切**一刀**，把样本分成「$\leq t$」与「$> t$」两段。候选切分点取相邻取值的中点：
$$T_a = \left\{ \frac{a^i + a^{i+1}}{2} \;\middle|\; 1 \leq i \leq n-1 \right\}$$

于是连续属性被当作一个**候选切分点集合**，每个 $t \in T_a$ 都对应一次二分类划分。选择时不再看「用哪个属性」，而是看「用哪个属性的哪一刀」——划出来的两段子集 $D_t^-$（$a \leq t$）与 $D_t^+$（$a > t$）的加权熵之和最小者胜出：

$$Gain(D, a) = \max_{t \in T_a} \, Gain(D, a, t), \qquad Gain(D,a,t) = Ent(D) - \sum_{\lambda \in \{-,+\}} \frac{|D_t^\lambda|}{|D|} \, Ent(D_t^\lambda)$$

**辨析｜易错点：** 与离散属性不同，**连续属性可以作为内部节点被多次复用**——离散属性分一次就耗尽（从候选属性集中移除），而连续属性切完一刀后，左右子节点还可以再对同一属性切下一刀（因为值域被切小了）。这与离散属性的「用完即弃」完全不同。<span class="marginnote">C4.5 的官方处理正是如此：同一连续属性可沿树路径多次使用。这也是为什么「厚度 > 0.3 且厚度 < 0.5」这种区间规则能被一棵树表达出来。</span>

## 2 公式解析：候选切分点的信息增益设样本含糖率排序后为 $\{0.1, 0.2, 0.3, 0.5, 0.6\}$（$n=5$），类标记为 $\{+, -, +, -, +\}$，$Ent(D)=0.971$。我们来比较两个候选切分点。- **第一步，枚举中点**：$T_a = \{(0.1+0.2)/2, (0.2+0.3)/2, (0.3+0.5)/2, (0.5+0.6)/2\} = \{0.15, 0.25, 0.4, 0.55\}$。- **第二步，算 $t=0.4$ 的增益**：$D_{0.4}^- = \{0.1,0.2,0.3\}$ 全为 $+$，$Ent = 0$；$D_{0.4}^+ = \{0.5,0.6\}$ 全为 $-$，$Ent = 0$；于是 $Gain(D,a,0.4) = 0.971 - (\tfrac{3}{5}\cdot 0 + \tfrac{2}{5}\cdot 0) = 0.971$。
- **第三步，比较所有切分点**：$t=0.15$ 时左段 $\{0.1\}$ 为 $+$、右段 $\{0.2,0.3,0.5,0.6\}$ 含两类，增益约为 0.62；$t=0.4$ 的增益 0.971 最大，故选 $t=0.4$。**直觉：把两类彻底切开的那一刀，增益最大；连续值划分就是在所有「一刀切」的位置里找最锋利的一刀。**

## 3 缺失值处理：两个子问题样本在属性 $a$ 上的取值缺失时，会遇到两个问题：1. **属性选择时**：如何在有缺失值的属性里挑出最好的那个？2. **划分时**：缺失了该属性的样本，该分到哪个分支？

设 $D$ 的全部样本在属性 $a$ 上无缺失的集合为 $\tilde{D}$，每个样本 $\boldsymbol{x}$ 带权重 $w_{\boldsymbol{x}}$（初始为 1）。

- **无缺失比例**：$\rho = \dfrac{\sum_{\boldsymbol{x} \in \tilde{D}} w_{\boldsymbol{x}}}{\sum_{\boldsymbol{x} \in D} w_{\boldsymbol{x}}}$——表示 $a$ 上有多少信息可用。
- **修正后的类比例**：$\tilde{p}_k = \dfrac{\sum_{\boldsymbol{x} \in \tilde{D}_k} w_{\boldsymbol{x}}}{\sum_{\boldsymbol{x} \in \tilde{D}} w_{\boldsymbol{x}}}$——只在无缺失子集里统计各类占比。
- **修正后的取值比例**：$\tilde{r}_v = \dfrac{\sum_{\boldsymbol{x} \in \tilde{D}^v} w_{\boldsymbol{x}}}{\sum_{\boldsymbol{x} \in \tilde{D}} w_{\boldsymbol{x}}}$——无缺失样本中取值为 $v$ 的比例。

于是带缺失的属性选择准则修正为

$$\widetilde{Gain}(D, a) = \rho \cdot Gain(\tilde{D}, a)$$

即在**无缺失子集**上计算信息增益，再乘以无缺失比例 $\rho$。<span class="marginnote">直觉：属性缺失越严重（$\rho$ 越小），它的信息增益被折扣得越狠——它「供不上料」，自然不该轻易当选。</span>

## 4 缺失样本怎么分：按比例划入各分支属性选好后，无缺失样本正常划入对应分支；**缺失该属性的样本则按权重拆分**，按 $\tilde{r}_v$ 的比例同时进入每个分支，并把权重按比例缩减：$$w_{\boldsymbol{x}}' = \tilde{r}_v \cdot w_{\boldsymbol{x}}$$
例如某个缺失「纹理」的样本权重为 1，而 $\tilde{r}_{\text{清晰}} = 0.7$、$\tilde{r}_{\text{稍糊}} = 0.3$，则它将以权重 0.7 进入「清晰」分支、以权重 0.3 进入「稍糊」分支继续生长。<span class="marginnote">这本质是「软划分」：一个样本不硬性只去一个分支，而是携带分数去所有分支。这个「权重分裂」的思想在第13章半监督学习、第14章概率图模型的推断里会反复出现。</span>最终叶节点的类标记，也按该节点内样本权重的多数决定。

**辨析｜易错点：** 缺失值处理与「填零 / 填均值」的预处理完全不同。后者在进入模型前就把缺失值造一个数补上；而决策树的处理是在**生长过程中动态利用**缺失样本——它不假设缺失值等于某个数，而是把不确定性「平摊」到各分支，并靠权重折扣体现信息损失。


面对缺失值，机器学习有三套世界观，决策树用的是第三套：- **删除派**：删样本（缺失严重时）或删特征（缺失率过高时）——最简单，但丢信息；- **填补派**：均值/中位数/众数/回归预测填上——假设「缺失等于某个值」，可能引入偏差；- **模型吸收派**（决策树/GBDT）：不填，把「缺失」当一种状态让模型学——**「缺失本身可能携带信息」**（如「用户没填年龄」可能暗示特定人群）。决策树的「权重分裂」甚至让一个缺失样本同时进入多个分支——它不假设缺失值等于什么，而是把不确定性平摊。这套「让模型自己吸收缺失」的思想，正是专题一里 GBDT 对脏表格宽容的根源。**思考题**：为什么「填均值」对线性模型必要、对树模型反而可能有害？这两类模型对「缺失状态」的处理能力有何不同？
## 拓展：缺失值的三种世界观

面对缺失值，机器学习有三套世界观，决策树用的是第三套：

- **删除派**：删样本（缺失严重时）或删特征（缺失率过高时）——最简单，但丢信息；
- **填补派**：均值/中位数/众数/回归预测填上——假设「缺失等于某个值」，可能引入偏差；
- **模型吸收派**（决策树/GBDT）：不填，把「缺失」当一种状态让模型学——**「缺失本身可能携带信息」**（如「用户没填年龄」可能暗示特定人群）。

决策树的「权重分裂」甚至让一个缺失样本同时进入多个分支——它不假设缺失值等于什么，而是把不确定性平摊。这套「让模型自己吸收缺失」的思想，正是专题一里 GBDT 对脏表格宽容的根源。

**思考题**：为什么「填均值」对线性模型必要、对树模型反而可能有害？这两类模型对「缺失状态」的处理能力有何不同？

## 知识速查：连续值与缺失值

**本节关键词**
- 二分法
- 候选切分点
- 连续属性复用
- 缺失比例 ρ
- 权重分裂
- 软划分
- 防泄漏
- C4.5

**三条常见误区**
1. 把连续属性当离散属性「用完即弃」——它可多次复用；
2. 把缺失处理等同于填均值——树模型要「吸收缺失」；
3. 忘了缺失样本按比例拆入各分支。

**核心结论**
1. 连续值用二分法取相邻中点作候选切分点；
2. 连续属性可在树中多次复用；
3. 缺失属性选择乘以无缺失比例 ρ 打折；
4. 缺失样本按比例软划分入各分支。

**常见面试题**
1. 问：连续属性与离散属性在树中的复用性差异？ 答：离散用完即弃，连续可沿路径多次切。
2. 问：缺失值处理为何不是简单填均值？ 答：树模型把「缺失」当一种状态，不假设缺失等于某值。

**一句话记忆**
连续值二分、缺失值按权重平摊——决策树对「不完美数据」的宽容由此而来。

## 5 小结- **连续值**：二分法取相邻取值中点作候选切分点 $T_a$，比较所有切分点的信息增益，选增益最大的一刀；连续属性可在树中**多次复用**。- **缺失值属性选择**：在无缺失子集上算增益再乘无缺失比例 $\rho$，即 $\widetilde{Gain}(D,a) = \rho \cdot Gain(\tilde{D},a)$，缺失越多折扣越大。- **缺失样本划分**：按 $\tilde{r}_v$ 比例拆成权重副本进入各分支，权重变为 $w_{\boldsymbol{x}}' = \tilde{r}_v w_{\boldsymbol{x}}$。- 缺失值处理**不等于**粗暴填补，它把不确定性平摊给各分支，不引入虚假信息。
