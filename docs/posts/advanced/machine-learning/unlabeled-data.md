## 为什么从未标记样本开始

前十二章的监督学习默认：训练数据**都有标记**。但真实世界恰好相反——**标记是稀缺资源，未标记数据泛滥成灾**。给一张图打上「猫/狗」的标签要人工，但互联网上有海量的图；一份病历要医生标注，但电子病历库里躺着上亿条未标注的记录。标记贵，未标记几乎免费。

**半监督学习（semi-supervised learning）**研究的正是这个中间地带：**同时利用「少量有标记样本 + 大量未标记样本」来学习**。它的核心问题令人着迷：**未标记样本没有「答案」，它们凭什么能帮学习？** 这一节先把场景、假设与分类讲清楚。<span class="marginnote">「未标记数据能否以及如何帮助学习」是半监督学习的第一性问题。它没有表面答案——随机加一堆不知道类别的数据，理论上不该有信息。但现实里未标记数据确实有用，秘密在于它们携带「结构信息」：数据的分布形状、簇的结构、流形的走向——这些「无标签的规律」能约束模型的猜测。</span>

## 1 为什么未标记数据有用：两大假设未标记样本的价值建立在一个前提上：**它们携带的数据分布信息，能约束模型**。教材给出两个核心假设：- **聚类假设（cluster assumption）**：数据存在天然的簇结构，**同一簇的样本很可能属于同一类别**。于是未标记样本的「抱团」模式，把类别边界「钉」在了簇与簇之间的低密度区——模型不会把边界切进一个稠密簇中间。
**流形假设（manifold assumption）**：数据分布在一个低维流形上，**流形上邻近的样本应有相同标记**。未标记样本勾勒出流形的形状，让模型沿着流形「光滑地」变化，而非在流形间的空隙里乱跳。<span class="marginnote">聚类假设与流形假设其实「一脉相承」：两者都在说「结构相近 ⇒ 标记相近」。第10章学过的流形学习正是流形假设的体现；而「沿着流形光滑」这一约束，也是第13章图半监督方法（用图传播标签）的理论依据——未标记样本把「光滑性」这条先验注入了学习。</span>

**为什么没有这些假设就不行**：若数据完全随机、毫无结构，未标记样本确实毫无信息——半监督学习「免费午餐」的前提，正是数据结构的存在。**没有结构假设，就没有半监督。**

## 2 半监督学习的两种形态半监督学习按「要不要预测未标记样本」分两种：- **纯半监督学习（pure semi-supervised learning）**：学一个模型，用于**从未见过的**新样本预测——未标记样本只参与训练；
**直推学习（transductive learning）**：只关心**训练里见过的那些未标记样本**的标签——不要求推广到新样本。直推学习的目标更「窄」，问题也相对简单。<span class="marginnote">「纯半监督 vs 直推」的区别在于<strong>预测对象</strong>：纯半监督要「开疆拓土」（新样本），直推只求「填完眼前的空格」（现有未标记样本）。工程里不少方法（如图传播）天然是直推式的——它给已有样本传标签容易，给新样本推断需要额外机制。</span>

## 3 未标记数据帮了什么：一个直觉例子考虑一个线性分类器。只用少量有标记样本，边界可以随意摆放——两种分法在标记样本上都「正确」。但加上大量未标记样本后，聚类假设发挥作用：**边界应避开稠密区域**。- 若未标记样本聚集在两个「团」里，边界被推向两团之间的空隙——一个「唯一」而合理的解；
若没有未标记样本，无数种边界都能解释标记数据——**模型方差巨大**。

**直觉**：未标记样本像「看不见的脚手架」，把模型的自由度「钉」在数据结构的合理位置上，**大幅降低方差**（第2章语言）。这解释了半监督学习的普遍收益模式：**小样本时收益大，样本充足时收益趋近于 0**——因为标记样本多了，结构信息已被充分覆盖。<span class="marginnote">「未标记数据的收益随标记样本数递减」是半监督学习的经验规律：标记样本从 10 到 100 时，未标记数据作用显著；从 10000 到 100000 时，边际贡献趋近于 0。这个规律提醒我们：半监督是「标记稀缺」的救急方案，不是越多越好的魔法。</span>

| 未标记样本 | 无 | 大量 | 全部 |
| 学习目标 | 学映射 | 学映射（借结构） | 发现结构 |
| 信息瓶颈 | 标记要够 | **结构假设要成立** | 无「正确性」 |
| 代表方法 | 全章前文 | 本节起至第13章末 | 第9章聚类 |

**辨析｜易错点：** 半监督学习**不是**「监督 + 无监督的简单拼盘」——不是先无监督聚类、再给簇贴标签。它的精妙在于：有标记样本与未标记样本**协同**——未标记数据用结构约束模型的形状，有标记数据提供「锚点」防模型跑偏。简单拼盘往往浪费了协同效应。<span class="marginnote">半监督学习的现代回声无处不在：伪标签（self-training）、对比学习的无监督预训练 + 少样本微调、以及大模型里的「自监督预训练 + 指令微调」——预训练用海量无标记文本学结构，微调用少量标记数据对齐任务。半监督思想是这条主线的理论源头。</span>

## 知识速查：半监督学习：未标记样本

**本节关键词**
- 半监督学习
- 未标记样本
- 聚类假设
- 流形假设
- 纯半监督
- 直推学习
- 结构信息
- 低密度

**三条常见误区**
1. 把半监督当「聚类+贴标」——未标记数据通过结构约束参与；
2. 忽略收益随标记样本增多而递减；
3. 以为未标记数据「免费」——结构假设不成立时反而有害。

**核心结论**
1. 半监督用少量标记 + 大量未标记；
2. 未标记有用的前提是聚类/流形假设；
3. 纯半监督推广新样本、直推只填现有；
4. 未标记像脚手架、降低方差。

**与全书/后续的连接**
- 第9章聚类的簇结构假设；
- 第13章各方法都靠这两大假设；
- 大模型自监督预训练是它的现代形态。

**常见面试题**
1. 问：未标记数据凭什么有用？ 答：携带结构信息，把边界钉在低密度区。
2. 问：为什么样本充足后半监督收益趋零？ 答：标记样本已充分覆盖结构信息，未标记边际贡献趋零。

**一句话记忆**
未标记数据携带结构信息，用聚类/流形假设把模型的自由度钉在合理位置。

## 5 小结- **半监督学习**用「少量有标记 + 大量未标记」学习，应对「标记贵、数据多」的现实。- 未标记数据有用的前提：**聚类假设 / 流形假设**——结构相近 ⇒ 标记相近。- 两种形态：**纯半监督**（推广新样本）vs **直推学习**（只填现有未标记样本）。
- 未标记数据像「脚手架」，把边界钉在低密度区，**降低方差**；收益随标记样本增多而递减。
- 半监督不是简单拼盘，而是标记锚点与结构约束的协同。
