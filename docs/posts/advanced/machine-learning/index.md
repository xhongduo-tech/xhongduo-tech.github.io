# 机器学习

经典机器学习体系：模型、优化与概率视角，是进入深度学习前的必修课。

## 主题规划

- [ ] 机器学习总览：监督、无监督与强化学习
- [ ] 线性回归：最小二乘、正则化与贝叶斯视角
- [ ] 逻辑回归与最大熵模型
- [ ] 感知机与线性可分的几何
- [ ] 支持向量机：间隔、对偶与核方法
- [ ] 朴素贝叶斯与生成式分类器
- [ ] K 近邻与度量学习
- [ ] 决策树：ID3、C4.5 与 CART
- [ ] 集成学习：Bagging、随机森林与 AdaBoost
- [ ] 梯度提升树：GBDT、XGBoost 与 LightGBM
- [ ] 聚类：K-Means、层次聚类、DBSCAN 与高斯混合模型
- [ ] EM 算法及其变体
- [ ] 降维：PCA、LDA、t-SNE 与 UMAP
- [ ] 特征工程：编码、选择与构造
- [ ] 模型评估：交叉验证、偏差-方差分解与超参搜索
- [ ] 概率图模型初步：贝叶斯网络与马尔可夫随机场
- [ ] 隐马尔可夫模型与条件随机场
- [ ] 强化学习初步：MDP、Q-Learning 与策略梯度
