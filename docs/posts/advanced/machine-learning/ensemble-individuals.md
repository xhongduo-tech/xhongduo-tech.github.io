## 为什么从个体与集成开始

前面七章学的都是**单个模型**：一棵决策树、一个 SVM、一个贝叶斯分类器。但机器学习的实战经验告诉我们：**把多个模型结合起来，往往比任何一个单独的模型都强**。这就是**集成学习（ensemble learning）**——「三个臭皮匠」的机器学习版本。

为什么「一群不完美的模型」能胜过「一个尽力调优的模型」？直觉藏在生活的经验里：让十个人独立估计一个罐子里豆子的数量，把他们的答案平均，往往比任何一个人的猜测都接近真相。这一节先把集成学习的两个基本问题讲清楚：**集成是什么、为什么有效**。它要铺垫的「准确性 + 多样性」这一对要求，是整个第8章的纲领——后面的 Boosting、Bagging、随机森林，本质上都是「如何造出既准又不同的个体学习器」的工程方案。<span class="marginnote">集成学习在工业界地位极高：GBDT/XGBoost/LightGBM（本专题的三个工程专题）与随机森林，几乎统治了表格数据场景的机器学习竞赛与生产系统。理解「个体与集成」的原理，是理解这些工具的第一步。</span>

## 1 什么是集成学习**集成学习（ensemble learning）**：通过构建并结合**多个个体学习器（individual learner）**来完成学习任务。流程分两步：1. **生成**一组个体学习器（可用同一种算法生成，称**同质集成**，如全是决策树；也可用不同算法，称**异质集成**）；2. 用某种**结合策略**把它们的输出合成最终预测（平均法、投票法、学习法，见第8章《结合策略》）。**个体学习器**通常由现有的**基学习算法**（base learner，如决策树、SVM）从训练数据训练而来；集成里的个体也叫**基学习器（base learner）**。同质集成里若基学习器是决策树，则集成叫「决策树集成」。<span class="marginnote">「弱学习器」与「基学习器」常被混用：弱学习器指「略好于随机猜测」的算法，Boosting 正需要这种「弱而可提升」的基学习器；Bagging 则用「强而多样」的基学习器。第8章两大会员——Boosting 与 Bagging——对基学习器的要求恰恰相反，这是理解它们差别的钥匙。</span>

## 2 集成为什么有效：好而不同集成要成功，个体学习器必须满足两条：- **准确性（accuracy）**：个体学习器不能太差，至少要比随机猜测好；- **多样性（diversity）**：个体学习器之间要有差异，不能「全是一个模子」。为什么多样性如此关键？设想一群全是「同一个模型」的学习器——它们的错误完全相同，投票时错误不会相互抵消，集成就是原地踏步。反之，如果每个学习器**错在不同的地方**，多数投票或平均就能让错误「相互抵消」、让正确「叠加放大」。

**辨析｜易错点：** 「好而不同」是个体学习器的**联合要求**，不是分别要求。只准不准（都犯同样的错）不行；只不同不准（都乱猜）更不行。集成学习的全部艺术，就在于**在保持准确的同时制造多样性**——第8章的方法（重抽样、加权、扰动）都在平衡这一对矛盾。<span class="marginnote">「准确 + 多样」的双重要求可以形式化为第8章末的误差-分歧分解：集成的泛化误差 = 个体平均误差 - 个体分歧。分歧越大、平均误差越小，集成越好——多样性第一次被量化。</span>

## 3 公式解析：为什么多数投票能「翻盘」设集成有 $T$ 个个体分类器，每个的错误率都为 $p$（假设相互独立），用**多数投票**决定最终类别。集成的错误率是「超过一半个体都错」的概率：`$$`P(\text{集成错误}) = \sum_{k = \lfloor T/2 \rfloor + 1}^{T} \binom{T}{k} p^{k} (1-p)^{T-k}`$$`- **第一步，看单个个体**：每个分类器出错概率 $p$，独立假设下错误事件相互独立。- **第二步，看多数投票**：$T$ 个分类器里出错个数 $k$ 服从二项分布 $\mathrm{Bin}(T, p)$。
**第三步，看集成错的条件**：当出错个数 $k$ 超过一半（$k > \lfloor T/2\rfloor$）时，多数投票给出错误答案。
**第四步，代数字验证**：设 $T = 3$、$p = 0.35$，则集成错误率 $= 3\times 0.35^2\times 0.65 + 0.35^3 \approx 0.282$——**比单个的 0.35 更低**。若 $T = 11$、$p=0.35$，集成错误率降到约 $0.023$，数量级下降。

**直觉**：独立投票有「大数定律」式的纠错效应——只要个体略优于随机（$p < 0.5$），人数越多、多数投票越可靠。这也点出了关键前提：**「独立性」假设**。若个体高度相关（错误的都是同一样本），翻盘效应就大打折扣——这正是「多样性」的理论出处。<span class="marginnote">「独立个体、多数投票、错误率随规模指数下降」是集成学习的理论根基。但现实中个体很难真独立，所以集成方法都在努力制造「近似独立」——随机抽样、特征扰动、样本加权，都是为了打散个体之间的相关性。</span>

## 4 集成学习的四大家族第8章将依次展开四条路线：- **Boosting**：个体学习器**串行**生成，后一个关注前一个**做错的样本**（重赋权），最终加权结合——典型：AdaBoost。- **Bagging / 随机森林**：个体学习器**并行**生成，各自用**自助抽样**的数据子集训练，投票结合——典型：随机森林。- **结合策略**：平均法（回归）、投票法（分类）、学习法（Stacking）——把个体输出合成最终结果。- **多样性**：为什么个体要不同、怎么度量不同、怎么制造不同。<span class="marginnote">两条主线的分工：Boosting 通过「不断纠错」提升<strong>偏差</strong>（把弱学习器变强），Bagging 通过「平均不相关个体」压制<strong>方差</strong>——第2章的偏差-方差语言在这里被用到了极致。这一「纠错 vs 降方差」的分野贯穿整个第8章。</span>

## 知识速查：个体与集成

**本节关键词**
- 集成学习
- 个体学习器
- 基学习器
- 准确性
- 多样性
- 多数投票
- 同质/异质
- 误差-分歧

**三条常见误区**
1. 只追多样性不顾准确性——都是乱猜也没用；
2. 把 Boosting 与 Bagging 的结合方式混淆；
3. 忽略「独立」假设——个体高度相关则集成失效。

**核心结论**
1. 集成 = 生成多个个体 + 结合策略合成；
2. 个体须「好而不同」；
3. 独立投票下错误率随规模指数下降；
4. Boosting 治偏差、Bagging 治方差。

**与全书/后续的连接**
- 第8章 Boosting/Bagging 是两条路线；
- 第12章泛化理论解释集成为何有效；
- 专题一 GBDT 是 Boosting 的工程化。

**常见面试题**
1. 问：为什么「不同」如此重要？ 答：错误相互抵消、正确叠加放大；全同则原地踏步。
2. 问：多数投票有效的关键前提？ 答：个体近似独立且错误率低于 0.5。

**一句话记忆**
集成 = 好而不同的个体 + 聪明的结合；分歧就是可被平均掉的误差。

## 5 小结- **集成学习** = 生成多个个体学习器 + 用结合策略合成预测；同质集成用同一基算法，异质集成用不同算法。- 集成有效的两条要求：**准确性**（个体别太差）与**多样性**（个体错在不同处）。- 多数投票在独立个体下能把错误率从 $p$ 压到 $\sum_{k>T/2}\binom{T}{k}p^k(1-p)^{T-k}$——「独立」是关键前提。- 四大家族：**Boosting**（串行纠错）、**Bagging/随机森林**（并行降方差）、**结合策略**、**多样性**。- 集成的目标与第2章偏差-方差直接挂钩：Boosting 治偏差、Bagging 治方差。
