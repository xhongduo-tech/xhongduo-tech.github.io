## 为什么「中微子有质量」撼动标准模型

振荡实验（1998 大气、2002 太阳）确凿证明中微子有**非零质量差**，
而标准模型里中微子**严格无质量**——这是标准模型遭遇的第一个重大实验反例。
更深刻的问题是：中微子的质量项是哪一种？
**狄拉克（Dirac）**中微子的粒子与反粒子不同，
像电子一样；
**马约拉纳（Majorana）**中微子的粒子就是自己的反粒子，
这在标准模型所有费米子中独一无二。
这个「是哪种」的判定，直接决定质量起源机制、轻子数是否守恒，
以及通往超越标准模型物理的方向。
本节把这两种图像讲透。

## 1 标准模型里中微子为什么「恰好无质量」

在标准模型中，费米子质量来自**希格斯（Higgs）机制**：左手与右手费米子通过希格斯场耦合，
获得正比于真空期望值 $v\approx 246\ \mathrm{GeV}$ 的质量。
例如电子：

$$\mathcal{L}_m^e = -y_e\, \bar{e}_L\, \phi\, e_R + \text{h.c.}, \qquad m_e = y_e \frac{v}{\sqrt{2}}$$

但中微子无法照抄这套配方，原因只有一个：**标准模型里根本没有右手中微子 $\nu_R$**。
弱相互作用只提供左旋 $\nu_L$，
没有右旋伙伴，希格斯机制无从下手——左手与右手一对的费米子才成质量项。
于是标准模型里中微子质量**被设为精确为零**，
不是近似，而是「无 $\nu_R$」这一结构性事实的直接后果。
<span class="marginnote">这段「标准模型恰好容不下中微子质量」的历史，
是理解后面所有机制的关键。电荷轻子与夸克都有左右手分量（虽然右手中微子也存在，
但标准模型为简约而省略），只有中微子天生「只有一半」。
</span>

一旦实验发现中微子有质量，就必然要求**新物理**：要么引入右手中微子（狄拉克质量），
要么接受中微子是马约拉纳粒子（马约拉纳质量），
要么两者兼有（跷跷板）。

## 2 狄拉克中微子：粒子与反粒子不同

**狄拉克中微子（Dirac neutrino）**：中微子与反中微子是**两个不同的粒子**，
像电子与正电子一样，由电荷共轭区分。
它需要四个独立分量：$\nu_L, \nu_R$（粒子）与 $\bar{\nu}_R, \bar{\nu}_L$（反粒子）。
质量项：

$$\mathcal{L}_D = -m_D\, \big(\bar{\nu}_R \nu_L + \bar{\nu}_L \nu_R\big), \qquad m_D = y_\nu \frac{v}{\sqrt{2}}$$

这个图像直接继承标准模型的费米子质量配方：引入一个**右手中微子 $\nu_R$**（不参与任何已知弱相互作用，
故称「惰性/sterile」），与左手中微子通过希格斯场配对。
<span class="marginnote">狄拉克图像里，
轻子数 $L$ 是守恒的：产生 $\nu$ 与产生 $\bar{\nu}$ 是两个可区分的、对称的过程。
若中微子是纯狄拉克，那么无中微子双 β 衰变严格禁止——马约拉纳与狄拉克在此分野。
</span>

但狄拉克图像有一个尴尬：为什么 $y_\nu$（中微子-希格斯耦合）比电子耦合 $y_e \sim 10^{-6}$ 还小十几个数量级？
若 $m_\nu \sim 0.1\ \mathrm{eV}$，
则 $y_\nu \sim 10^{-13}$——这个「莫名的小数」让人怀疑质量机制另有玄机。

## 3 马约拉纳中微子：粒子即反粒子

**马约拉纳中微子（Majorana neutrino）**：中微子与反中微子是**同一个粒子**，
不存在独立的 $\bar{\nu}$。
这之所以可能，是因为中微子**电中性**——一个带电粒子（如电子）绝不可能等于自己的反粒子（电荷相反），
但中性粒子可以。
质量项写为：

$$\mathcal{L}_M = -\frac{1}{2}\, m_M\, \overline{\nu_L^c}\, \nu_L + \text{h.c.}$$

其中 $\nu_L^c$ 是 $\nu_L$ 的电荷共轭。
<span class="marginnote">马约拉纳质量项只含左旋场——这正好契合标准模型「只有 $\nu_L$」的结构，
不需要引入任何新粒子！代价是质量项<strong>破坏轻子数守恒</strong>（$\Delta L = 2$）。
1937 年马约拉纳提出这种对称形式时，
正值反粒子概念诞生之初，他的想法沉寂数十年，
直到中微子质量被发现才成为研究主流。
</span>

马约拉纳图像的后果深远：

- 轻子数不守恒（$\Delta L = 2$），中微子可以「自己消灭自己」。
- 唯一直接可测的签名是**无中微子双 β 衰变（$0\nu\beta\beta$）**——马约拉纳中微子才允许这个过程。
- 它为质量起源提供了一条更自然的路径（跷跷板），见下一节。

## 4 公式解析：两种质量项与「惰性」分量

把两种质量项的差别拆开看：

- **第一步，狄拉克质量项 $\bar{\nu}_R \nu_L$**：它把左手与右手两个**独立**场连接起来。若 $\nu_R$ 存在，中微子有 4 个分量，粒子与反粒子不同，轻子数守恒。质量 $m_D$ 由希格斯耦合产生，与电荷轻子同机制。
- **第二步，马约拉纳质量项 $\overline{\nu_L^c} \nu_L$**：它把左手场与它**自己**的电荷共轭连接。因为 $\nu_L^c$ 是 $\nu_L$ 的「镜像」，粒子等于反粒子，只有 2 个分量。这个项可独立于希格斯存在，也不需要用 $\nu_R$——代价是破坏 $\Delta L = 2$。
- **第三步，一般情形**：物理上最一般的中微子质量矩阵是两者的混合（见下节跷跷板）：

$$\mathcal{L}_m = -\frac{1}{2}\begin{pmatrix} \overline{\nu_L^c} & \overline{\nu_R} \end{pmatrix} \begin{pmatrix} M_L & m_D \\ m_D^T & M_R \end{pmatrix} \begin{pmatrix} \nu_L \\ \nu_R^c \end{pmatrix} + \text{h.c.}$$

马约拉纳项 $M_L, M_R$ 与狄拉克项 $m_D$ 的竞争关系，
决定了中微子的**本性（Majorana 程度）**与**质量标度**。

## 5 如何判定：无中微子双 β 衰变

狄拉克与马约拉纳的图像在大部分实验中**不可区分**——振荡、衰变、散射都对两种图像给出相同预言（涉及 $\nu_L$ 的部分一致）。
唯一的本质区别出现在 $\Delta L = 2$ 过程中。

**无中微子双 β 衰变（$0\nu\beta\beta$）**是决定性判据：

$$\ce{^A_ZX -> ^A_{Z+2}Y + 2e^- + (\text{无中微子})}$$

普通双 β 衰变放出两个反中微子（$2\nu\beta\beta$，
已被观测）；若中微子是马约拉纳粒子，
一个虚中微子可以作为中间传播子「从第一个 β 衰变传到第二个」，
实现**无中微子**版本。其速率正比于**马约拉纳有效质量**：

$$\Gamma_{0\nu\beta\beta} \propto \lvert m_{\beta\beta}\rvert^2, \qquad \lvert m_{\beta\beta}\rvert = \Big\lvert \sum_i U_{ei}^2 m_i \Big\rvert$$

$m_{\beta\beta}$ 是当前一代实验（如 CUORE、LEGEND、KamLAND-Zen、nEXO）正在探测的量，
现有上限约 $\lvert m_{\beta\beta}\rvert \lt  0.05$–0.2 eV。
<span class="marginnote">$m_{\beta\beta}$ 不是简单的中微子质量加权和——含 PMNS 矩阵元 $U_{ei}$ 的<strong>平方</strong>与马约拉纳相角。
即使 $\sum m_i$ 大，
相角相消也可能让 $m_{\beta\beta}$ 趋零，
所以「测不到」不能立即否定马约拉纳，只能缩小参数空间。
</span>

**若 $0\nu\beta\beta$ 被观测到**，
将一箭三雕：中微子是马约拉纳粒子、轻子数不守恒、质量起源含马约拉纳质量项——这是本专题《无中微子双β衰变》的专章内容。

## 6 两种图像的对照表

| 特征 | 狄拉克中微子 | 马约拉纳中微子 |
| --- | --- | --- |
| 粒子 = 反粒子？ | 否 | **是** |
| 独立分量 | 4（含 $\nu_R$） | 2（只 $\nu_L$） |
| 需要的右旋场 | 必须引入 $\nu_R$ | 不需要 |
| 轻子数守恒 | 守恒 | 破坏（$\Delta L=2$） |
| 需要新物理 | 需要（新场） | 不一定（质量项即可） |
| 无中微子双 β 衰变 | 禁止 | 允许（唯一判据） |
| 质量来源 | 希格斯耦合 $y_\nu v/\sqrt2$ | 马约拉纳项 $m_M$ |
| 理论动机 | 最小扩展 | 与跷跷板天然契合 |

## 7 小结

- 标准模型**恰好容不下中微子质量**——因为没有右手中微子 $\nu_R$，希格斯机制无从下手。
- **狄拉克中微子**：粒子 ≠ 反粒子，需引入惰性 $\nu_R$，轻子数守恒，质量由希格斯耦合产生。
- **马约拉纳中微子**：粒子 = 反粒子，只有 2 个分量，破坏 $\Delta L=2$，不需新粒子。
- 判定两种图像的**唯一实验窗口**是**无中微子双 β 衰变**，其速率 ∝ 马约拉纳有效质量 $m_{\beta\beta}^2$。
- 一般质量矩阵同时含狄拉克与马约拉纳项——二者的竞争正是下节跷跷板机制的舞台。
