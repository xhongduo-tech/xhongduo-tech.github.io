## 为什么必须理解弱相互作用的结构

中微子只参与弱相互作用，因此**所有**中微子过程——产生、散射、探测、振荡中的物质效应——都是弱相互作用的具体实现。
这一节不满足于「中微子通过弱作用耦合」这句口号，
而要讲清楚它的**规范结构**：为什么只耦合左旋、为什么 W 与 Z 玻色子行为不同、带电流与中性流过程有何差别。
弄懂这张「相互作用蓝图」，后面计算散射截面、分析探测器信号（逆 β 衰变、相干散射）就都有了统一框架。

## 1 从四费米子理论到规范玻色子

费米 1934 年的 β 衰变理论是**点相互作用**：四个费米子场在同一时空点上耦合，
用一个耦合常数 $G_F$ 描述：

$$\mathcal{L}_F = \frac{G_F}{\sqrt{2}}\, \bar{p}\,\gamma^\mu\, n\ \cdot\ \bar{e}\,\gamma_\mu\, \nu_e + \text{(h.c.)}$$

这个「四费米子顶点」能正确给出 β 谱，
却在高能下失禁——它的散射截面随能量线性增长，
最终**违背幺正性**（概率超过 1）。
<span class="marginnote">费米理论的图景是「四个粒子挤在一点」。
截面 $\sigma \sim G_F^2 E^2$，
能量越高反应越强，到 $E \sim 1/\sqrt{G_F} \approx 1\ \mathrm{TeV}$ 时散射概率超出一，
理论自爆。这是量子场论中「非重整化理论」的典型症状。
</span>

1967–1968 年温伯格、萨拉姆与格拉肖（Weinberg–Salam–Glashow）把这个点顶点「展开」成**中间玻色子交换**：弱相互作用其实是 $\mathrm{SU(2)_L \times U(1)_Y}$ 规范对称性自发破缺的结果，
传递相互作用的不是点接触，而是三个重的规范玻色子——两个带电的 $W^\pm$ 与一个中性的 $Z^0$，
外加光子 $\gamma$。
<span class="marginnote">把「点」换成「交换重粒子」，
高能行为立刻被修复：截面不再无限增长，
理论变得可重整。1983 年鲁比亚（Rubbia）等人在 CERN 找到 $W^\pm$ 与 $Z^0$，
质量 $M_W \approx 80.4\ \mathrm{GeV}$、$M_Z \approx 91.2\ \mathrm{GeV}$，
与预言完全吻合。</span>

对中微子而言，这一「展开」意味着：**所有中微子过程都可以画成一张费曼图——初态中微子与靶粒子之间交换一个 W 或 Z 玻色子。
**

## 2 带电流与中性流

按交换玻色子的不同，中微子相互作用分成两大类，
这是理解一切中微子信号的钥匙：

**带电流（charged current, CC）过程**：交换 $W^\pm$。
$W$ 带电，因此初末态的电荷必须改变。
中微子吸收 $W^+$ 变成带电轻子：$\nu_\ell + X \to \ell^- + X'$。
最著名的例子是逆 β 衰变 $\bar{\nu}_e + p \to e^+ + n$——反应堆探测的看家反应，
也是莱因斯–考恩实验的基础。
<span class="marginnote">CC 过程的标志是<strong>味守恒</strong>：$\nu_e$ 只能产生 $e^-$，
$\nu_\mu$ 只能产生 $\mu^-$。
1962 年莱德曼–施瓦茨–斯坦伯格实验正是靠「$\nu_\mu$ 不产生电子」证明了缪中微子与电子中微子不同。
</span>

**中性流（neutral current, NC）过程**：交换 $Z^0$。
$Z$ 不带电，中微子散射后仍是中微子：$\nu_\ell + X \to \nu_\ell + X'$，
靶粒子被反冲。典型例子是弹性散射 $\nu + e^- \to \nu + e^-$ 与相干弹性中微子-核散射（CEνNS）。

两类过程的物理后果大不相同：

| 特征 | 带电流 CC | 中性流 NC |
| --- | --- | --- |
| 交换玻色子 | $W^\pm$ | $Z^0$ |
| 末态中微子 | 变成带电轻子 | 仍是中微子 |
| 味是否改变 | 味守恒但「物化」 | 味不变 |
| 对中微子「味」敏感 | 是——分辨 $\nu_e,\nu_\mu,\nu_\tau$ | 否——三种味等价 |
| 典型过程 | 逆 β 衰变、$\nu_e$ 弹性散射 | 相干散射、中性流弹性散射 |

**辨析｜易错点：** NC 过程对三种味中微子**一视同仁**——这是它最珍贵的实验用途。
太阳中微子实验 SNO 正是「CC 只数电子型 + NC 数全部味」双通道并用，
才一举证明太阳中微子「缺失」是振荡而非消失，
详见本专题《太阳中微子实验》。

## 3 拉格朗日量与 V−A 结构

把上面的图像写成拉格朗日量，中微子的弱作用耦合是：

$$\mathcal{L}_{\mathrm{int}} = -\frac{g}{\sqrt{2}}\,\sum_{\ell}\ \bar{\nu}_{\ell L}\,\gamma^\mu\,\ell_L\, W_\mu^+ + \text{h.c.} \;-\; \frac{g}{2\cos\theta_W}\ \bar{\nu}_{\ell L}\,\gamma^\mu\,\nu_{\ell L}\, Z_\mu$$

这串式子信息量很大，逐项拆解：

- **$\nu_{\ell L}$ 与 $\ell_L$**：下标 $L$ 表示只出现**左旋投影** $\psi_L = \frac{1-\gamma^5}{2}\psi$。$W$ 玻色子只耦合左旋粒子——这就是中微子「只左旋」的数学表达，也是宇称不守恒的根源。$\ell$ 是味指标（$e, \mu, \tau$），求和号表示三代轻子各有一条相同形式的耦合。
- **$\gamma^\mu$ 与 $V-A$**：顶点结构是 $\gamma^\mu(1-\gamma^5)/2$，即**矢量减轴矢量（V−A）**结构。它让弱作用不仅破坏宇称（P），还以独特方式破坏电荷共轭（C）。这与电磁相互作用（纯 V）形成鲜明对照。
- **$\theta_W$ 与混合**：$Z^0$ 的耦合含 $\cos\theta_W$（温伯格角），体现电弱统一：$Z^0$ 是 $\mathrm{SU(2)_L}$ 与 $\mathrm{U(1)_Y}$ 两个规范场的线性组合，$\theta_W$ 决定混合比例。

## 4 公式解析：四费米子与 W 交换的等价性

在低能极限下，重 $W$ 玻色子的传播子可以「收缩」成点相互作用，
费米常数与规范耦合之间由此建立联系：

$$\frac{G_F}{\sqrt{2}} = \frac{g^2}{8 M_W^2} = \frac{1}{2 v^2}$$

拆解这条关系：

- **第一步，传播子的收缩**：交换 $W$ 的振幅正比于 $g^2 / (q^2 - M_W^2)$。当转移动量 $q^2 \ll M_W^2$（低能，如 β 衰变、反应堆中微子），传播子近似 $g^2/M_W^2$，与费米点顶点的 $G_F$ 对号入座。
- **第二步，代入电弱关系**：电弱理论中 $M_W = \frac{1}{2}gv$，其中 $v \approx 246\ \mathrm{GeV}$ 是希格斯场的真空期望值。于是 $g^2/8M_W^2 = g^2/(8\cdot g^2 v^2/4) = 1/(2v^2)$。
- **第三步，读出物理**：**费米常数不是基本常数，而是电弱统一标度 $v$ 的化身**。测得 $G_F \approx 1.166\times 10^{-5}\ \mathrm{GeV^{-2}}$，就「看见」了 $v = 246\ \mathrm{GeV}$。这条等式是中微子物理与电弱对称性破缺之间的桥梁——也是后续讨论中微子质量（通过希格斯或类似机制）的参照系。

## 5 中微子散射与过程分类

把顶点知识用于实际过程，中微子的散射反应按靶粒子与玻色子类型可系统分类：

- **中微子-电子弹性散射** $\nu_\ell + e^- \to \nu_\ell + e^-$：既有 NC（三种味都有），又有 CC（仅 $\nu_e$，通过 W 交换）。这是太阳中微子水基探测器（如超级神冈）的主要信号通道。
- **逆 β 衰变** $\bar{\nu}_e + p \to e^+ + n$：纯 CC，反应堆实验的黄金通道，有阈值 $E_\nu > 1.8\ \mathrm{MeV}$。
- **中微子-核子准弹性散射** $\nu_\ell + n \to \ell^- + p$：加速器长基线实验（如 T2K、NOVA）探测 $\nu_\mu$ 的主要通道。
- **相干弹性中微子-核散射（CEνNS）** $\nu + (Z,A) \to \nu + (Z,A)$：纯 NC，中微子与整颗核相干散射，截面随 $N^2$ 增强。2017 年 COHERENT 实验首次观测，开启了低能中微子探测的新窗口。<span class="marginnote">CEνNS 的截面被相干因子 $N^2$（$N$ 为中子数）放大，但反冲能量极低（keV 级），要求探测器极其灵敏。它既可用于反应堆监控，也是暗物质直接探测实验的主要本底——中微子可以「假扮」暗物质事件，这是中微子物理与暗物质物理的交汇点，见本专题《中微子作为暗物质候选》。</span>

## 6 小结

- 弱相互作用从**四费米子点理论**发展为**规范玻色子交换**，$W^\pm$、$Z^0$ 的发现确认了电弱统一。
- 中微子过程分**带电流（CC）**与**中性流（NC）**：CC 把中微子变成带电轻子、味守恒、分辨味；NC 让中微子保持中微子、三种味等价。
- 顶点结构是 **V−A**：只耦合左旋，是宇称破坏的根源；$Z^0$ 通过温伯格角 $\theta_W$ 与光子混合。
- 费米常数 $G_F$ 与电弱标度 $v$ 通过 $G_F/\sqrt{2} = 1/(2v^2)$
