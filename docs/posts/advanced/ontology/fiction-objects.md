# 虚构对象的本体论地位

## 为什么从福尔摩斯开始

上一节迈农已经给本体论出了一道难题：**不存在之物（如飞马、福尔摩斯）算不算某种「存在」？** 我们从《论何物存在》看到了奎因的回答——存在就是成为约束变量的值，福尔摩斯不是任何量词的取值，于是他不存在。但故事还没讲完：我们明明可以谈论福尔摩斯、可以追问「福尔摩斯住在哪儿」、可以比较他与另一位侦探的智商，语言与实践都离不开他。这种「既没有实在性、又无法被抹掉」的对象，正是当代形而上学里争论最激烈的领域之一，也是知识工程绕不开的坑——因为你的知识图谱里几乎必然躺着几个福尔摩斯。

## 1 问题的精确形状

先把问题说清楚。**虚构对象（fictional object）**：由虚构作品（小说、戏剧、神话、电影）引入、在作品世界里拥有属性、但在现实世界中不存在的那类对象，如夏洛克·福尔摩斯、哈姆雷特、飞马、孙悟空。

「福尔摩斯住在贝克街 221B」这句，表面上是**关于福尔摩斯**的——主词位置站着一个名字。问题因此劈成两半：

- **语义问题**：这句真吗？若真，它的真由什么担保？
- **本体论问题**：如果存在一个「福尔摩斯」作为句子主词的所指，他是哪种存在物？

直觉给出互相打架的答案。说「福尔摩斯是虚构的」，仿佛承认他存在（否则我们谈的是谁？）；说「福尔摩斯不存在」，又像是在否定一个有名字的东西。**这条张力叫「虚构对象悖论」，也叫「柏拉图胡子」的文学版**——它逼我们解释：虚构话语有真有假，可世界上并没有与之对应的实体。<span class="marginnote">奎因用「打领结的人」比喻本体论话语：谈论「福尔摩斯不存在」时，「福尔摩斯」出现在主词位，但我们可以用摹状词把它改写掉——「有一个住在贝克街、破过若干案件的侦探」是假的，于是无需承诺福尔摩斯存在。这句话的现代版我们已经在《罗素摹状词理论》一节见过。</span>

## 2 五种立场

对虚构对象的地位，当代哲学家给出至少五种彼此竞争的方案。它们构成一张光谱，从「最实在」到「最省」：

| 立场 | 福尔摩斯是什么 | 代表 |
| --- | --- | --- |
| 柏拉图主义式实在论 | 不依赖作品而独立存在的抽象对象 | 温和模态实在论者 |
| 迈农主义 | 存在（being）但不存在（existence）的对象 | 迈农、帕森斯 |
| 创造主义 | 由作者创作出的抽象人工制品 | 托马森、萨尔茨曼 |
| 虚构论 / 假装论 | 不是对象；虚构话语是假装的真 | 沃尔顿、约赫 |
| 消灭论 | 根本没有虚构对象；句子在量词下为假 | 奎因、范·因瓦根 |

**重点：光谱两极的区别是「抽象但真实」与「根本不真实」。** 柏拉图主义者与迈农主义者都认为福尔摩斯「在某个意义上有」——分歧在于他是否依赖作品；而假装论与消灭论都认为福尔摩斯「没有」，分歧只在于如何解释我们有意义的谈话。<span class="marginnote">这张表是纯概念主题的替代公式解析：哲学立场不像数学公式可推导，它们的「运算规则」是本体论承诺与解释力之间的权衡——每一行都回答了同一个问题「福尔摩斯算哪类存在」，但付出的形而上学代价各不相同。后文工程策略表与它一一对应。</span>

### 消灭论：改写掉名字

消灭论（eliminativism）是最「省」的立场，奎因是旗手。它的策略在《罗素摹状词理论》一节已经演练过：**把虚构名字改写为描述，再把含描述的句子放进量词之下，指出它假。**「福尔摩斯住在贝克街 221B」被改写为「存在一个 x，x 是住在贝克街 221B 的侦探，且 x 被称作福尔摩斯」——真值取决于现实中是否有这样的人，答案是没有，于是整句为假。**「福尔摩斯」不再是名字，而是压缩了的摹状词；摹状词不指称对象，只是逻辑表达式。**

消灭论的代价同样清晰：它把「福尔摩斯是虚构的」也一并处理为「不存在 x 使 x 满足侦探摹状词」，可这句话在我们的语言实践里明明有所断言——我们是在谈论作品、谈论文化对象，而不是仅仅在否定一个量化命题。批评者（创造主义者）指出：消灭论把**「关于虚构的谈话」**错误地降格成了**「虚构内部的谈话」**的否定，丢掉了「福尔摩斯是 19 世纪以来英语世界最著名的虚构侦探之一」这类明显为真的外部断言。

### 迈农主义

迈农区分**存在（existieren）**与**持存（bestehen）**：一切对象都有**存在（being）**——即使它不实存，也至少「作为对象被给予」。飞马有「存在」，只是没有「实存」。这条路线给虚构对象、圆方形等一个统一安置处，但代价是本体论仓库被塞满——任何你能想到的东西，哪怕自相矛盾，都有了「存在」。奎因讥之为「迈农的杂货铺」：货架上什么都有，只是分「实存」与「不实存」两排。<span class="marginnote">注意与《迈农对象理论与「不存在之物」问题》一节的衔接：那里处理的是量词难题，这里把同样的货架对准虚构对象——迈农铺子里，福尔摩斯与贝克街 221B 同处「不实存但存在」的货架。</span>

### 创造主义

**创造主义（creationism）**（托马森《虚构与形而上学》）：福尔摩斯是柯南·道尔**创作出来的抽象人工制品（abstract artifact）**。作品诞生之前他不在，作品诞生之后他被引入——他是真实的（真实到可以成为百科条目、可以成为版权讨论的对象），但他的存在模式是抽象、依赖心智与文化的。创造主义让虚构对象获得「适度的实在性」：它们是文化进化的产物，与法律、货币、交响乐同属一类「社会建构的抽象物」。这一派的好处是能够解释虚构对象的历史性——1902 年之前的福尔摩斯不存在，这个直觉它原样保留。

### 假装论

沃尔顿的**假装论（pretense theory）**：虚构作品是「角色扮演游戏」的脚本，「福尔摩斯住在贝克街」在字面上假，但在假装语境里真——我们作为读者参与一场想象游戏，句子在游戏中得到真值。于是没有虚构对象，只有游戏与道具（作品文本、演员、木偶）。这把本体论问题整个取消：我们不再需要给福尔摩斯安排存在方式，只需描述游戏的规则。假装论最擅长解释「对虚构人物产生情感」这个怪现象：我们对游戏里的危险感到恐惧，并不需要危险真实存在。

## 3 内部真值与外部真值

无论选哪一派，都必须回答：**「福尔摩斯住在贝克街 221B」与「福尔摩斯是虚构的」这两句话，真值为何不同？** 当代分析哲学的通行做法是区分两个层面：

- **内部真值（internal truth）**：在作品世界的标准内，福尔摩斯住在贝克街 221B——这是**虚构为真（true in the fiction）**。它与「作品世界」相对，不要求现实世界的对应。
- **外部真值（external truth）**：福尔摩斯不存在、福尔摩斯是虚构的——这是**关于虚构为真（true about the fiction）**，真值是绝对的，因为它讨论的是现实世界中的作品、作者与读者关系。

**重点：同一枚名字在两个层面获得完全不同的真值，却毫不冲突。** 消灭论者靠这个区分把「福尔摩斯住在贝克街」整个降级为「在《福尔摩斯探案集》的故事里，福尔摩斯住在贝克街」——前者假、后者真。创造主义者则相反：两个层面都是真的，因为它们分别描述了现实中的抽象对象与作品内的规定属性。<span class="marginnote">这正好是《弗雷格：意义与指称》一节的延伸：弗雷格发现「晨星」与「暮星」同指时，需要意义层来解释信息差；虚构话语把同样的结构推到底——福尔摩斯这个名字有丰富的意义（故事规定的一切），却几乎没有指称（除非你接受创造主义）。</span>

这个双层面结构几乎是所有虚构理论的最低共识，无论本体论立场如何。它也是下一节知识表示的地基：**「作品内为真」与「现实中为真」必须分属不同的知识空间，否则一切推理都会被污染。**

内部/外部真值还拖出一个混合情形：**真实人物进入虚构作品**。托尔斯泰的《战争与和平》里，拿破仑登场——拿破仑是真实存在的历史人物，但在小说里他有了作品规定的属性与台词。此时「拿破仑在奥斯特里茨战役中做了什么」要分两层回答：历史层的拿破仑由史料判定，作品层的拿破仑由小说文本判定。两者同名同姓却隶属不同本体论范畴，知识图谱对此的惯例是建立**两个节点**：历史人物 `Napoleon` 与虚构角色 `Napoleon (War and Peace)`，再以「`based on` 历史人物」关联——这正是本体工程里「角色参照真实原型」的建模模式，与「福尔摩斯无原型」的情形形成对照。虚构对象的本体论，最终总是落在这种「分域 + 关联」的工程决策上。

## 4 垂直与水平虚构对象

创造主义内部还有一个对工程影响深远的区分，来自托马森：**虚构对象可以按「在多少作品里延续」分成两类。**

- **垂直虚构对象（vertical fictional character）**：跨越多部作品延续的存在，如福尔摩斯横跨柯南·道尔的 60 个故事、亚瑟王横跨中世纪无数文本、孙悟空横跨《西游记》及其后一切改编。它们像滚雪球，同一性由「历史传承」决定——后一部作品声称接着前一部讲，角色就延续下来。
- **水平虚构对象（horizontal fictional character）**：只在单一作品内存在，如某个三流小说里出场一次就消失的角色。它们的全部属性都在这一部作品里规定完，没有跨作品的历史。

**重点：区分的关键不是「出场次数」，而是「同一性是否跨越作品的边界被继承」。** 垂直对象的同一性类似真实人物的传记连续性——只是这条传记链由作者群的约定而非因果历史构成；水平对象则像一次性照片，拍到什么就是什么。<span class="marginnote">这个区分对应工程上的经典难题：当《大侦探福尔摩斯》电影把原作角色改编得面目全非，图谱里到底放一个福尔摩斯还是两个？托马森的答案在哲学上给出了判据——原作与改编共享同一条创作传承链，是同一个垂直对象；而一部与原著毫无传承关系的致敬作品，则只是新造的水平对象。这比拍脑袋的「相似度阈值」规范得多。</span>

垂直/水平之分解释了另一个现象：**为什么我们对垂直对象的错误主张比对水平对象更敏感。** 说「福尔摩斯会魔法」比说「某三流小说角色会魔法」更刺耳——因为前者违背了一个跨越 60 部作品建立的丰富形象，后者只违背了一部作品的规定。知识图谱里，这种「违背」就是**约束违反（constraint violation）**：垂直对象携带大量跨作品的默认属性，任何单一来源的冲突都会显眼。

这个区分也让创造主义与假装论的争论变得更具体：假装论者可以把水平对象轻松解释为「单场游戏内的道具」，但对垂直对象（亚瑟王——存在过吗？哪个文本是「真的」？）就力不从心，因为游戏与游戏之间的继承关系需要额外的说明。**创造主义在这类对象上占据天然优势，这也正是百科类知识图谱更接近创造主义而非假装论的原因。**

## 5 知识图谱里的福尔摩斯

哲学争论远不是书斋游戏——**工程上你必须替福尔摩斯做决定**。一个标准的知识图谱（如 Wikidata、DBpedia）都有数万个「虚构角色」条目，它们与真实人物共享同一套类与属性。这里出现三种工程策略，恰好对应哲学光谱的三个折衷点：

| 工程策略 | 福尔摩斯建模 | 对应哲学立场 |
| --- | --- | --- |
| 单库共存 | 与华盛顿同库，`instance of 虚构侦探` | 温和创造主义 |
| 现实/虚构分域 | 本体层分 `Person` 与 `FictionalCharacter` | 类层面的实在论区分 |
| 作品内嵌 | 作为《福尔摩斯探案集》的属性载体 | 内部/外部真值分离 |

- **单库共存**：福尔摩斯与华盛顿同处一个图谱，用「`instance of` 虚构侦探」标注类别。优势是查询统一（「列出所有住在伦敦的侦探」一次命中），风险是**类别污染**——统计「伦敦人口」时若不过滤虚构标记会出错。
- **现实/虚构分域**：用本体层面区分 `Person`（现实人物）与 `FictionalCharacter`（虚构角色），让它们不共享关键属性约束。这正是上层本体里「实在论派」（如 BFO）与「概念派」（如 DOLCE）的工程化分歧——详见第七篇。
- **作品内嵌**：把虚构实体建模为「作品」的组成部分，福尔摩斯成为《福尔摩斯探案集》的属性载体而非独立个体。语义最干净，但损失查询便利——你无法直接问「所有侦探里谁最著名」。

Wikidata 的做法可以作为参照：它给福尔摩斯一个实体条目，属性「`instance of` 虚构侦探」「`creator` 柯南·道尔」「`present in work` 福尔摩斯探案集」，同时用「`based on`」之类的属性连接真实原型。查询虚构角色时，社区约定必须显式带 `FictionalCharacter` 过滤条件。这套约定没有理论上的必然性，却把哲学光谱折衷成了一套可执行的规则——**本体论分歧在工程里的最终归宿，就是「分类 + 约定」**。

**易错点｜虚构对象的同一性**：现实对象按时空连续体判同，虚构对象却没有稳定的同一性标准——两个版本的福尔摩斯（柯南·道尔的原作 vs. 当代改编电影）是不是同一个福尔摩斯？知识工程里这个问题翻译为「实体消解（entity resolution）的边界条件」：什么时候该合并、什么时候该保留为不同实体。判定标准往往要落到「作品源」（source）属性上——一个角色来自哪部作品，往往比它「是谁」更稳定。<span class="marginnote">同一性问题是本体论最硬的钉子之一：现实里「我」的同一性靠身体、记忆、时空路径；虚构里福尔摩斯的同一性靠什么？这直接对应第八篇《知识融合：实体对齐与实体消解》的合并判据——那里我们讨论的算法，正是在替福尔摩斯这类「没有因果历史」的对象发明同一性。</span>

## 6 小结

- 虚构对象悖论来自**语义真值与本体论空无的张力**：句子有真值，却找不到所指。
- 五种立场构成光谱：**实在论 / 迈农主义 / 创造主义 / 假装论 / 消灭论**，代价依次递减、解释力也递减。
- 创造主义把虚构对象解释为**文化的人工制品**，与法律、货币同类，是中间路线里最流行的一支。
- 假装论**取消问题**：虚构话语是想象游戏，本体论仓库不为此扩容。
- **内部真值与外部真值**的区分是各派最低共识，也是工程上「作品内为真 ≠ 现实中为真」的理论根。
- **垂直与水平虚构对象**的区分，为「跨作品改编是否同一实体」提供了规范判据。
- 真实人物进入虚构作品时，工程惯例是**分节点 + `based on` 关联**，把历史层与作品层隔离。
- 知识图谱的工程决策是哲学争论的镜像：**单库共存、分域建模、作品内嵌**三种策略对应不同的本体论承诺。
- 同一性判据是核心难点：虚构对象的「谁是谁」没有因果历史可依，只能靠作品源与传承链。

在下一节，我们将离开哲学线，跨入工程的另一半——从 Davis、Shrobe 与 Szolovits 那篇著名的《什么是知识表示》开始，看看**知识表示的五种角色**如何把「存在之问」变成可执行的系统设计：一个知识系统里承诺哪些实体、为何承诺、又怎样推理。
