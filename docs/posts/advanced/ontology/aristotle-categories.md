## 为什么从「范畴」开始

上一章我们立住了亚里士多德的第一哲学纲领：**存在以多种方式被言说，但都以实体为中心**。这一句是宣言，而《范畴篇》是这份宣言的**第一张详细图纸**。亚里士多德在此回答一个任何本体论都必须回答的问题：当我们把世界切成概念块时，**切分的刀口一共有几种？** 他的答案是十种——十种「不结合其他语词」就能有意义地言说存在者的方式，后来被称为**十个范畴（category）**。

这个问题的工程分量不容低估。今天一个知识图谱的 schema 层要做的事，恰恰就是**给论域里的所有存在者分类**：什么是类、什么是属性、什么是关系、什么是事件。两千三百年前，亚里士多德把「分类这件事本身」做成了学问。更妙的是，他的分类逻辑——区分「被述说的」与「存在于其中的」——几乎原封不动地复现在计算机的数据模型里。<span class="marginnote">「范畴」一词英文 category 源自希腊语 κατηγορία（katēgoria），原义是「指控、谓述」，即对一个主词「说些什么」。亚里士多德用它指「可以独立地用以谓述事物的最一般类别」——这正是「类别 / class」概念的哲学始祖。</span>

## 1 《范畴篇》的位置：逻辑学与本体论的十字路口

《范畴篇》（*Categoriae\*）在传统上被编为亚里士多德《工具论》（*Organon\*）的**开卷第一篇**，它谈的是「语词如何有意义地被使用」——表面上是逻辑学；但它列出的十种谓述方式，实质上是对**存在者**的分类，因此它同时是本体论。一篇文本，两个身份，这个双重性本身就是重要信号：**亚里士多德的逻辑学从来不是纯形式的，它一开始就绑定在存在者的结构上。**

这里的核心问题是「不结合其他语词的语词」（τὰ ἄνευ συμπλοκῆς λεγόμενα）——即「人」「白」「昨天」「在广场上」这类可以单独说的词，而不是「人坐在广场上」这类完整句子。亚里士多德问：这类简单语词所指的东西，一共分几类？答案是十类，即十范畴。

在进入十范畴之前，必须先掌握《范畴篇》第 2 章给出的**两把更基本的刀**，因为十范畴正是用这两把刀切出来的。这两把刀是一对区分：

**「述说一个主词」（said of a subject）**：一个语词的名称与定义可以应用于某个主词，例如「人」被述说于「这个具体的人」——「苏格拉底是人」。
**「存在于一个主体」（present in a subject）**：一个东西存在于另一个东西之中，不是作为其部分，且不能离开所依存者独立存在，例如「某种语法知识」存在于「某个灵魂」之中。<span class="marginnote">注意两把刀方向不同：「述说主词」是逻辑—谓述关系（predication），「存在于主体」是存在—依存关系（inherence）。前者回答「它是不是被用来形容某物」，后者回答「它能不能脱离某物单独存在」。把它们混为一谈，是初读《范畴篇》最容易犯的错。</span>

用这两把刀的「是 / 否」交叉，得到四类东西，亚里士多德的分类学从这里开始：

| | 存在于主体 | 不存于主体 |
| --- | --- | --- |
| **述说主词** | 普遍的偶性：如「知识」述说「语法知识」，又存在于灵魂 | 第二实体（普遍实体）：如「人」述说个体，却不存于任何主体 |
| **不述说主词** | 个别偶性：如「这个人的某种语法知识」 | 第一实体（个别实体）：如「这一个人」「这一匹马」 |

这张四格表是整个西方本体论的**第一块分形结构**：往下每一层都在这张表里找位置。先记住右下格——「既不述说主词、又不存于主体」的东西，亚里士多德称之为**第一实体**，它是后面一切讨论的地基。<span class="marginnote">这张四格表值得你在脑中存成图像：它把「语言上的谓述」和「存在上的依存」正交起来，得到四种存在者。今天的面向对象建模、数据库范式、知识图谱的类层次，本质都在重复这张表——只是换了术语。</span>

## 2 十种范畴：存在的十种最一般谓述方式

有了两把刀，再看十范畴就顺了。**核心概念：范畴（category）**：对存在者最一般的谓述方式——任何简单语词所指的东西，都必落入且仅落入十范畴之一。篇首引文逐一举了例子，这里补齐全表：

| 范畴 | 希腊语 | 英文 | 例子 |
| --- | --- | --- | --- |
| 实体 | οὐσία | substance | 人、马 |
| 数量 | ποσόν | quantity | 两肘长、三肘长 |
| 性质 | ποιόν | quality | 白的、通晓语法的 |
| 关系 | πρός τι | relative | 二倍、一半、较大 |
| 处所 | ποῦ | where | 在吕克昂学园、在市场 |
| 时间 | ποτέ | when | 昨天、去年 |
| 姿态 | κεῖσθαι | being-in-a-position | 躺着、坐着 |
| 状态 | ἔχειν | having | 穿着鞋、带着武器 |
| 动作 | ποιεῖν | doing | 切割、灼烧 |
| 承受 | πάσχειν | being-affected | 被切割、被灼烧 |

这张表看似朴素，却有两条内在结构，是理解它的钥匙。

**第一条：十范畴有「主从」之分。** 前九个（数量、性质、关系、处所……）都是**依存性的存在方式**——「白的」一定依赖某个白的东西，「两肘长」一定依赖某个长的东西，「在市场上」一定依赖某个在哪里的东西。唯独**实体**不依赖任何其他东西而能独自存在。所以亚里士多德说实体是「最根本的存在者」：前九个范畴是「关于实体的存在方式」，实体是它们共同的落脚点。这正应了上一章那句「存在以多种方式被言说，但都朝向实体这个中心」。

**第二条：十范畴不是「对象清单」，而是「问题清单」。** 每个范畴对应一个可以针对任何事物追问的问题：它是什么？（实体）它多大？（数量）它怎样？（性质）它与什么相关？（关系）它在哪？（处所）它何时？（时间）它处于什么姿势？（姿态）它有什么？（状态）它对什么做了什么？（动作）它遭受了什么？（承受）。**十个范畴 = 十种「关于任何存在者都能问的问题」**，这是把「分类」做成「穷尽性问题清单」的智慧，后世的分体论、模态论都在补这十个问题的角。

## 3 实体：唯一独立的存在方式

十范畴里，实体居于唯一中心的宝座，值得单独停下来看它凭什么。

**重点：实体是主词，其余九范畴都是谓词；主词可以独立存在，谓词必须依附主词存在。** 这是整个西方本体论的第一张骨架。亚里士多德的论证分两步：

**依赖关系不对称**：「白」需要一个白的东西作为主体才存在，而「这个人」不需要「白」才存在。依赖是单向的——谓词依赖主词，主词不依赖谓词。
**谓述关系有底**：任何关于世界的陈述，追到底都是一个谓词述说一个实体。你说「苏格拉底是白的」「苏格拉底在广场上」，主语始终落在实体范畴上。

这个论证在逻辑上等价于今天的一个判断：**在知识表示里，个体（individual）是论域的主语，属性与关系是挂在个体上的谓词。** RDF 三元组的「主语—谓词—宾语」结构，主语位天然预留给实体；一个「没有主语的三元组」根本无法形成一条陈述。

《范畴篇》在这里立刻抛出一个更细的划分，也是下一章的主题：实体内部还要分**第一实体**（个别的事物，如「这一个人」）与**第二实体**（属与种，如「人」「动物」）。第一实体是最根本的，第二实体是「述说第一实体的方式」。这一刀切开后，共相问题的火药桶——「人」这个普遍概念到底存不存在、以什么方式存在——就被埋下了。<span class="marginnote">注意亚里士多德在《范畴篇》里说得很克制：第二实体存在，但它的存在方式依附于第一实体。这个「克制」为后文阿奎那的温和实在论预留了空间：共相「在人心中作为概念、在个体中作为共同本性」存在，而不像柏拉图那样独立于个体。共相之争到中世纪才全面爆发，见本专题第五章。</span>

## 4 范畴的歧义：语法学还是存在论

**辨析｜易错点：《范畴篇》的十范畴究竟是「语词的分类」还是「事物的分类」？** 这是两千年来读《范畴篇》的第一道分水岭。答案不是二选一，而是**「语词—概念—事物」三层对应**：亚里士多德把「不结合语词的语词」拿来分类，是因为他相信**语词的谓述方式对应概念的谓述方式，而概念结构又映照事物的结构**。十范畴同时是：十个最一般的谓词类型（语言层）、十种最一般的思想功能（心灵层）、十种最一般的存在方式（存在层）。

这个三层对应是整场本体论的一个核心赌注：**世界可以被语言如实地切分。** 你若接受它，就走上了实在论的路；你若怀疑它（语言只是约定，切分只是习俗），就走上了唯名论的路。中世纪共相之争，不过是把这个赌注放大到极致。知识表示工程站在同样的分叉口：**schema 的类名是「发现」世界的真实结构，还是「发明」一套便于计算的约定？** 第七篇里 BFO（实在论导向）与 DOLCE（认知导向）的对立，就是这道选择题的工程版。<span class="marginnote">现代语言学更审慎：语言结构显然受认知与文化塑造，不可能天真地等同于存在结构。但反过来，若语词分类与存在结构完全无关，科学理论（也是语词系统）怎么可能预测世界？十范畴的三层对应，是一个朴素而深刻的问题起点——它不值得被嘲笑，而值得被重新论证。</span>

## 5 范畴理论对知识表示的三个启示

亚里士多德没写过一行代码，但他的范畴分析几乎预先回答了知识表示工程的三个核心设计问题。

**启示一：类型层级不是任意目录，而是依赖关系的地图。** 十范畴告诉工程者：类别之间有「谁依赖谁」的严格次序。实体类可以独立，偶性类（属性、关系）必须依附于实体类。今天设计知识图谱 schema 时问「这个类能不能没有主语独立存在」，问的正是亚里士多德两千年前的问题。

**启示二：分类要「穷尽且互斥」。** 十范畴的设计目标是：任何存在者都落进且只落进一类。「穷尽」保证没有漏网之鱼，「互斥」保证没有模糊地带。这与数据库设计的完整性约束、与本体工程里「类的 disjointness 公理」是同一种追求。<span class="marginnote">「穷尽且互斥」在后来的本体论里被反复修正——十范畴其实并不严格互斥（「白」既是性质又是可述说的普遍者），但作为方法论它立住了标准：好的本体分类应当经得起「任何对象都能归类」与「没有对象能归两类」的双重检验。</span>

**启示三：谓述与存在的区分，对应 schema 与数据的区分。** 「述说主词」是类型层面的关系（schema 层的 rdfs:subClassOf），「存在于主体」是个体层面的关系（数据层的 rdf:type 与属性断言）。把这两层混起来，正是后来语义网络「链接到底意味着什么」的语义危机之源——这个话题我们到第四篇《知识表示基础》再系统处理。

把三个启示落成代码，就是问一个 OWL 本体：哪些类是「实体类」，哪些是「偶性 / 属性」，两类如何分层。下面这个 OWL 2（Turtle 语法）片段，是亚里士多德骨架的最小工程投影：

```turtle
:人        a                owl:Class .
:苏格拉底  a                :人 .                  # 第一实体：个体

:肤色      a                owl:DatatypeProperty ;
           rdfs:domain      :人 .                  # 偶性：依附于实体
:父亲      a                owl:ObjectProperty ;
           rdfs:domain      :人 ;
           rdfs:range       :人 .
```

这段代码的要点不在具体构子，而在结构：**实体类落在主语位，偶性类被声明为属性并声明 domain——这就是「谓词依附主词」的 RDF 翻译。** 一个没有 domain 声明的属性，就像没有主体的偶性，游离在本体之外。

## 6 核心对比表：十范畴 × 知识表示构件

本主题以概念辨析为主、无核心公式，故以「核心对比表」代替公式解析——按编辑章程第 5 节执行。

| 亚里士多德范畴 | 回答的问题 | 知识表示对应构件 | 例子 |
| --- | --- | --- | --- |
| 实体（第一 / 第二） | 它是什么？ | 个体 / 类 | :苏格拉底、:人 |
| 数量 | 它多大、多少？ | 数据属性（数值） | :身高 170 |
| 性质 | 它怎样？ | 数据属性（质） | :肤色 白 |
| 关系 | 它与什么相关？ | 对象属性 | :父亲 :苏格拉底 |
| 处所 / 时间 | 它在哪、何时？ | 时空属性 / 时间戳 | :所在 :雅典、:出生 前470年 |
| 姿态 / 状态 | 它处于什么姿势 / 拥有什么？ | 状态属性、持有关系 | :姿态 :坐着、:持有 :拐杖 |
| 动作 / 承受 | 它做了什么 / 遭了什么？ | 事件、过程、因果属性 | :实施 :思考、:遭受 :审判 |

这张表最值得注意的一列是**「回答的问题」**：十个问题合起来，就是对一个存在者可以发问的完整问题集。知识表示里「一个实体的完整画像」是什么？就是用这十类问题把它的属性填满。亚里士多德两千年前列出的问题清单，今天仍是数据建模的需求清单。

## 7 小结

- **《范畴篇》的双重身份**：既是《工具论》的逻辑学开篇，也是本体论的第一张详细图纸——逻辑与存在在此不分家。
- **两把刀**：「述说一个主词」（谓述）与「存在于一个主体」（依存）正交，交叉得到四类存在者，右下格是**第一实体**。
- **十范畴**：实体、数量、性质、关系、处所、时间、姿态、状态、动作、承受——是「不结合语词的语词」的十种最一般谓述方式。
- **实体唯一独立**：前九个范畴依附实体而存在；实体是主词，其余是谓词。这直接对应 RDF 里「主语—谓词—宾语」的主语优先结构。
- **三层对应**：语词—概念—事物的同构是十范畴的赌注，也是实在论与唯名论的分岔口。
- **工程启示**：类型层级是依赖地图；分类要穷尽且互斥；谓述与存在的区分对应 schema 与数据的区分。

在下一章，我们将盯着十范畴里那个唯一的中心——实体——把它拆开：为什么「这一个人」比「人」更实在，属与种作为「第二实体」又凭什么存在。那是**第一实体与第二实体**的篇章，也是通往共相问题的第一级台阶。
