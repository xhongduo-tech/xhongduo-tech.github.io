## 为什么从单对象范畴开始

上一节我们用 Set 与 Hask 做锚，这一节展示范畴论的第一个「把戏」——
**把一个代数结构「重新说成」范畴**。主角是**幺半群（monoid）**，
一个每个程序员都熟悉的结构（字符串拼接就是幺半群）。范畴论的
洞察是：**一个幺半群恰好是一个「只有一个对象」的范畴**。
这个看似无害的观察，是通往「单子是自函子范畴上的幺半体」
（那口号）的第一级台阶——它示范了范畴论的核心方法论：
**把「元素与运算」重述为「态射与复合」，一切视角就变了**。

## 1 幺半群的定义：代数侧

**幺半群（monoid）**：一个集合 $M$ 配上二元运算 $\cdot: M \times M \to M$，
满足：

- **封闭**：$a \cdot b \in M$（运算不跑出集合）。
- **结合律**：$(a \cdot b) \cdot c = a \cdot (b \cdot c)$。
- **单位元**：存在 $e \in M$，使 $e \cdot a = a = a \cdot e$。

程序员的例子俯拾皆是：

- 自然数 + 加法：单位元 0。
- 字符串 + 拼接：单位元 `""`。
- 列表 + 连接：单位元 `[]`。
- 集合上的自函数 + 复合：单位元恒等函数。

**重点：幺半群是「最简的代数结构」——一个运算、三条性质。**
它无处不在，但正因为太常见，反而不被注意。范畴论的看法是：
**把「运算」看成「态射的复合」，幺半群就变成了范畴**——这个
视角转换，是理解抽象的一把钥匙。<span class="marginnote">为什么先讲幺半群？
因为它同时是「代数结构」与「范畴」——它是两个世界的接缝。
理解了「幺半群 = 单对象范畴」，你就理解了范畴论的核心动作：
<strong>不是发明新结构，而是把旧结构换一种语言重述</strong>。这几乎就是
「抽象」的定义。</span>

## 2 公式解析：幺半群 → 单对象范畴

关键构造：给定一个幺半群 $(M, \cdot, e)$，定义范畴 $\mathcal{C}_M$：

- **对象**：只有一个，记作 $*$（一个「占位对象」）。
- **态射**：$\mathrm{Hom}(*, *) = M$——**幺半群的每个元素
  是一个态射**。
- **复合**：元素 $a$ 与 $b$（作为态射）的复合是 $a \cdot b$。
- **单位态射**：$1_* = e$。

**逐项拆解这个「翻译」：**

- **对象只有一个**：所以所有态射都是从 $*$ 到 $*$（自态射）。
- **元素变态射**：`"hello"`、`"world"`、`0`、`5` 都成了箭头。
- **运算变复合**：`"hello" · "world"`（拼接）就是「先走
  `"hello"` 再走 `"world"`」的复合。
- **单位元变单位态射**：`""` 就是恒等箭头——拼上它等于没拼。

**重点：验证一下，幺半群的结合律恰好就是范畴的结合律，
单位元恰好就是单位律——所以 $\mathcal{C}_M$ 确实是一个范畴。**
反过来，任何「单对象范畴」也自动给出一个幺半群（取它的
自态射集）。**「幺半群」与「单对象范畴」是同一枚硬币的两面**——
范畴论对「结构」的重新包装，第一次显形。<span class="marginnote">「元素变箭头」这个
动作会在 Yoneda 引理、单子等处反复出现。它的力量在于：<strong>元素
本来是「被动的东西」，变成箭头后就成了「可以复合的动作」</strong>。
视角从「存在什么」转向「能做什么」——这正是关系本体论的
又一次胜利：连「元素」都被重述为「关系」。</span>

## 3 直觉：对象只是占位符

单对象范畴第一次明确地展示了范畴论的原则：**对象不重要**。

在这个范畴里，对象 $*$ 没有任何内容——它只有一个，所以它
「是什么」完全无所谓。**真正的结构全在态射（幺半群的元素）
与复合（运算）里。** 对象 $*$ 只是「让态射有地方起止」的
占位符。

**重点：这就是「对象是态射的端点」的极端版本。**
一个对象、一堆箭头、一套复合——就构成了一个完整的范畴，
而对象本身可以是「空的」。**范畴论的「存在」不依赖对象的内容，
只依赖关系的结构**——这个原则在单对象范畴里被推到极致，
也为 Yoneda 引理「对象由关系网络决定」埋下伏笔。<span class="marginnote">「占位对象」在
本书哲学语境里意味深长：它几乎就是「实体本体论的空壳」——
范畴论说「实体（对象）可以是空壳，只要关系（态射）在」。
这正面回答了第一篇「存在是什么」：<strong>在最抽象的层面，
存在可以是「纯位置」，内容可以全无，只要结构完备</strong>。</span>

## 4 例：把熟悉的幺半群放进范畴

把几个熟悉的例子「范畴化」：

| 幺半群 | 单对象范畴 |
| --- | --- |
| 自然数 + 加法 | 态射 = 自然数，复合 = 加法，单位 = 0 |
| 字符串 + 拼接 | 态射 = 字符串，复合 = 拼接，单位 = `""` |
| 列表 + 连接 | 态射 = 列表，复合 = `++`，单位 = `[]` |
| 自函数 + 复合 | 态射 = `a -> a`，复合 = `.`，单位 = `id` |

**重点：这些例子的价值是「练眼」——看熟「运算 = 复合」的翻译。**
当你看到 `concat`、`++`、`add` 时，养成「这是一个幺半群」
的反射；当你说「这是一个幺半群」时，自动想到「这是一个
单对象范畴」。**这种「双重视角」正是范畴论训练的核心能力**——
同一个东西，能用两种语言描述，抽象力就上了一个台阶。<span class="marginnote">对程序员
最实用的幺半群是「列表 + 拼接」：`foldMap` 可以把任何
幺半群当目标——「把一个列表折叠进一个幺半群」是无数
聚合操作（求和、求字符串、收集错误）的统一模式。<strong>幺半群的
抽象，让「怎么聚合」变成一个参数</strong>——这又是「抽象即参数化」。</span>

## 5 通往单子的路标

「幺半群是单对象范畴」不只是智力游戏，它是那著名口号的第一站：

> **「单子（monad）是自函子范畴上的幺半体。」**

这个口号的解读方式是「把『幺半群是单对象范畴』升级」：

- 普通幺半群：在**一个对象的范畴**里的幺半群。
- 单子：在**自函子构成的范畴**里的幺半群——对象换成函子，
  态射换成自然变换，复合换成「函子的复合」。

**重点：如果「幺半群 = 单对象范畴」没吃透，「单子」口号
就是天书。** 这个口号不是比喻，而是字面的结构对应——单子
就是在「自函子范畴」这个具体范畴里做「单对象范畴」的构造。
**本节是理解那个口号的第一级台阶**：先学会「幺半群是单对象
范畴」，下一节到函子、再到自函子范畴，最后单子水到渠成。<span class="marginnote">给读者一个
学习路线：本节（幺半群 = 单对象范畴）→ 函子（第 7 节）→
自然变换（第 8 节）→ 自函子范畴 → 单子（第 9 节，口号落地）。
<strong>每一步都是「在更高的范畴里重复同一个构造」</strong>——范畴论的
递进，靠的是「同一个想法在不同层级的重现」。</span>

## 6 小结

- **幺半群**：集合 + 结合运算 + 单位元——最简代数结构。
- **幺半群 = 单对象范畴**：元素变态射、运算变复合、单位元变单位态射。
- 验证：幺半群的结合律/单位元 = 范畴的结合律/单位律。
- 直觉：**对象只是占位符**——结构全在态射与复合里。
- 常见例子：**自然数加法、字符串拼接、列表连接、函数复合**。
- 方法论：**把「元素与运算」重述为「态射与复合」**——视角即抽象。
- 路标：这是「单子是自函子范畴上的幺半体」的第一级台阶。
