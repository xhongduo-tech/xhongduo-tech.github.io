# 从 KL-ONE 到描述逻辑：术语系统的谱系

<div class="epigraph">
<p>KL-ONE 的初衷，是把语义网络中「看起来像知识」的图，改造成「经得起语义检查」的术语系统。</p>
<footer>—— 罗纳德·布拉赫曼与詹姆斯·施莫尔泽（Ronald Brachman, James Schmolze），《KL-ONE 综述》(1985)</footer>

## 为什么从 KL-ONE 开始

第四篇的终点是一场未竟的工程：语义网络死于语义含混，框架死于语义宽松。
第五篇的主角——**描述逻辑（Description Logic, DL）**——就是这场危机的产物：
它要「鱼与熊掌兼得」，既保留语义网络与框架的建模直觉（类、属性、继承），
又给它们配上一阶逻辑式的严格语义，还要保证推理**可判定**。而这一切的起点，
是布拉赫曼在 1970 年代末设计的 **KL-ONE**——第一个「结构化」的术语表示系统。
理解 KL-ONE 的谱系，你就理解了描述逻辑为什么长成今天这个样子：
为什么它只谈概念与角色，为什么它执着于可判定性，
以及为什么今天 OWL 的每一个构子都带着四十年前的设计胎记。

## 1 语义网络的严格化冲动

KL-ONE 出场前的背景是伍兹的审判（第四篇《语义危机》）：
语义网络的 is-a 五种歧义、量词缺失、节点含混。布拉赫曼的回应不是抛弃图，
而是给图装上「结构的骨架」与「定义的纪律」：

- **概念（concept）与角色（role）分离**：概念对应「类」，角色对应「关系」——
  把语义网络里混在一起的节点与弧，分成两个截然不同的范畴。
- **结构定义化**：每个概念不再只是一个带名字的节点，而是一组**结构描述**
  （它与哪些角色相连、角色被什么限制）——概念的含义由结构给出。
- **原始概念 vs 定义概念**：原始概念（primitive）只给出必要属性（无法完全定义），
  定义概念（defined）给出必要且充分的条件。这个区分至今在 OWL 里以
  rdfs:subClassOf（必要）与 owl:equivalentTo（必要且充分）的形式活着。

**重点：KL-ONE 的野心是「让图里的每一个节点都能被检查」**——概念的定义
不是画出来的，而是写出来、可以被算法验证的。这从根上回应了伍兹
「链接必须有意义」的审判。<span class="marginnote">「原始 vs 定义」的概念论区分
在第三篇哲学线上有深远的回声：阿奎那区分「本质的必然属性」与「可被定义的
充分条件」；KL-ONE 把「必要」与「必要且充分」变成了语言的两个构造子——
本体论的古老区分，在工程语言里安了家。</span>

## 2 KL-ONE 的结构：概念、角色与结构化包含

KL-ONE 里，一个概念由它的**角色（role）**及其**限制**来刻画。例如「鸟」：

角色 has-part 被限制为「至少一个翅膀」；
角色 flies 被限制为「默认真」（KL-ONE 的默认机制，后来被 OWL 抛弃）。

概念之间用 **subsumption（包含）** 组织成层级：若概念 $C$ 的结构包含了
概念 $D$ 的全部结构，则 $C$ 包含于 $D$（$D$ 是 $C$ 的上位概念）。
KL-ONE 的推理是**结构化包含（structural subsumption）**：比较两个概念的
结构描述，看一个是否「结构上更强」——这就是「分类」的雏形。

**公式化**：设 $C, D$ 是两个概念，$C \sqsubseteq D$（$C$ 包含于 $D$）
当且仅当 $D$ 的结构描述是 $C$ 的结构描述的逻辑后承。
对「鸟」与「动物」：鸟的结构（有翅、有喙、会飞）蕴含了动物的结构（有生命），
故 鸟 ⊑ 动物。<span class="marginnote">注意 ⊑ 与语义网络 is-a 链接的区别：
is-a 是画出来的、靠直觉继承；⊑ 是<strong>算出来的</strong>——由结构描述推出。
这是「定义驱动分类」与「声明驱动继承」的分水岭，也是 DL 效率与可靠性的根基。</span>

KL-ONE 的问题也在这里：结构包含靠语法比较，语义缺乏模型论支撑——
两个结构上不同、语义上等价的描述（如「有翼的鸟」与「会飞的鸟」）
可能被判为不包含。**KL-ONE 是「半严格」的：比语义网络强，比逻辑弱。**
这个半吊子状态，正是下一节 DL 要补的课。

## 3 从 KL-ONE 到描述逻辑：语义的补课

1991 年，施密特-绍斯与斯莫尔卡（Schmidt-Schauß & Smolka）迈出关键一步：
把 KL-ONE 式的语言**翻译成带模型论语义的逻辑**，并证明其推理可判定。
这一步把「术语系统」升格为「描述逻辑」：

**语义模型化**：概念被解释为论域的子集，角色被解释为论域上的二元关系；
  「$C$ 包含于 $D$」被定义为「所有模型里，$C$ 的解释都是 $D$ 的解释的子集」。
**语言家族化**：不再有「一个 KL-ONE」，而是一族语言——
  按「能表达什么」从小到大排成谱系（下一节详述）。
**可判定性中心化**：DL 研究的头号问题是「这个语言的包含/可满足性
  能否在有限时间内判定」——这是工程可用的前提。

**重点：描述逻辑 = KL-ONE 的建模直觉 + 一阶逻辑的模型论语义 + 可判定性保证。**
它是第四篇所有表示（语义网络、框架、FOL）的「集大成者」：
图的直觉、结构的组织、逻辑的严格、可判定的工程承诺。<span class="marginnote">这一补课
正是第二篇哲学线的复现：语义网络像「日常语言的含混」，DL 像弗雷格
「概念文字的精确化」——把含混的表达翻译成无歧义的形式语言。
DL 是弗雷格工程在知识表示上的完成形态。</span>

## 4 描述逻辑家族：一张谱系表

DL 不是一种语言，而是一个家族。家族成员按表达力排序，
「概念构造子」决定了它能表达什么：

| 语言 | 关键构造子 | 表达力 | 备注 |
| --- | --- | --- | --- |
| FL⁻ | ⊓（合取）、∃R（存在限制）、值限制 | 最弱 | 经典入门 |
| EL | FL⁻ 全称 + ⊑ | 多项式可判定 | 生物本体（SNOMED） |
| ALC | 加入 ¬（否定）、全称限制 | 表达力适中 | DL 的标准语言 |
| SHOIN | ALC + 传递角色、逆角色、数限制、名义 | 强 | OWL DL 的原型 |
| SROIQ | SHOIN + 属性链、自反/非自反 | 极强 | OWL 2 DL |

**易错点｜「表达力越强越好」是错觉**：每加一个构造子，推理复杂度就跳一档。
EL 可在多项式时间做包含判定（适合百万级概念的医学本体），
SROIQ 的包含判定最坏是指数级的（但仍可判定）。工程选语言，
不是选「最厉害的」，而是选「刚好够表达你的领域、又保证推理够快」的那一档。
**表达力与可计算性，是 DL 家族唯一的定价轴。**<span class="marginnote">这张谱系表的
哲学注脚：DL 家族的「表达力—复杂度」权衡，是第四篇「KR 五角色」里
「推理理论」与「计算效率」两角色互斥的直接体现。你会在第七篇
「OWL 2 Profiles 选型」里再次看到这张表的工程版。</span>

## 5 从 KL-ONE 到 OWL：一份家谱

把谱系画完整，你会看到一条清晰的传承链：

```text
语义网络（semantic networks）
   │  缺语义：节点含混、is-a 五义（伍兹审判）
   ▼
KL-ONE
   │  给结构：概念/角色分离、结构定义化、分类
   ▼
描述逻辑（DL）
   │  给语义：模型论解释 + 可判定性（1991）
   ▼
OWL 1（SHOIN）
   │  给标准：W3C 标准化、工程工具链
   ▼
OWL 2（SROIQ）
   │  给表达力：属性链、自反/非自反角色
   ▼
知识图谱（TBox/ABox 工程）
```

每一站都解决上一站的遗留问题：语义网络缺语义 → KL-ONE 给结构 → DL 给语义与
可判定性 → OWL 给标准化与工程工具。**描述逻辑的「谱系」不只是历史，
它是理解 OWL 一切设计决策的地图**：为什么 OWL 只有一元谓词与受限二元关系？
因为 DL 的可判定片段就是这样。为什么 OWL 没有默认值？因为默认破坏可判定性。
为什么 OWL 用开放世界假设？因为它继承了 DL 的模型论语义。
这些问题，第六篇会逐一展开。<span class="marginnote">一句话记住这条线：
<strong>KL-ONE 是 DL 的结构之祖，DL 是 OWL 的语义之祖，OWL 是知识图谱的工程之祖</strong>。
你手里任何一份 .owl 文件，都是这条四十年家谱的最新后代。</span>

## 6 小结

- KL-ONE 是语义网络危机的**结构回应**：概念/角色分离、原始/定义概念、
  结构定义化。
- KL-ONE 的推理是**结构化包含**：分类由结构描述算出，而非靠弧的直觉。
- KL-ONE 的局限是**缺模型论语义**：结构比较无法识别语义等价。
- 1991 年施密特-绍斯与斯莫尔卡把术语系统**翻译成带语义的逻辑**，
  并证明可判定——「描述逻辑」由此得名。
- DL 是一个**语言家族**，按构造子排成谱系：EL ⊂ ALC ⊂ SHOIN ⊂ SROIQ，
  表达力与复杂度同步上升。
- 工程铁律：**选语言看「表达够用 + 推理够快」**，不是越强越好。
- 传承链：语义网络 → KL-ONE → DL → OWL 1 → OWL 2，理解谱系即理解 OWL。

在下一节，我们将进入 DL 的两层结构——**TBox 与 ABox**：
术语知识（概念公理）与世界断言（个体事实）如何分工，又如何协同推理。
