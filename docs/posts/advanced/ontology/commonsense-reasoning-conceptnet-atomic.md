## 为什么从常识推理开始

本书从第四篇「默认逻辑与限定逻辑」就埋下了「常识表示」的线——
麦卡锡要「给常识立法」的梦想。这一节看它的当代进展：**常识知识库**
（ConceptNet、ATOMIC）如何用图存储「人人会、没人教」的常识，
以及 **LLM 的常识**是隐式的、够用的还是不够的。常识推理是 AI
「显而易见」却最难的领域——Winograd 代词的消歧、物理世界的
直觉、社会行为的得体，都是它的战场。理解常识推理，
你就看到了知识图谱「最野心」的形态：不只是事实，而是
**世界运作的默认规则**。

## 1 常识问题的谱系：从 Cyc 到 ConceptNet

**常识（commonsense）**：关于日常世界的、默认被所有人共享的知识——
物理（东西会往下掉）、心理（人想要好东西）、社会（迟到要道歉）、
语言（「它」指什么）。

常识表示的历史谱系：

- **Cyc（1984）**：手工编码数百万条常识公理——精确但不可扩展
  （第八篇已述）。
- **WordNet（1985）**：词汇语义网络——词与词的关系。
- **ConceptNet（1999 起）**：众包常识图谱——**把常识写成
  「概念—关系—概念」的边**，用游戏与社区协作收集。
- **ATOMIC（2019）**：事件级常识——「如果 X 发生，那么 Y」。

**重点：常识知识库的形态是「图谱」**——概念为节点、常识关系为边。
与普通知识图谱的区别是**内容**：它存的是「咖啡→可浇灌→植物」
这类世界运作的默认知识，而非「谷歌→位于→美国」这类事实。
**常识图谱是「世界运作规则的图」。**<span class="marginnote">把常识图谱与
第五篇的 DL 对照：ConceptNet 的边（`UsedFor`、`HasProperty`）≈
关系角色，但<strong>语义比 DL 松</strong>——它们是「倾向性」的常识关联，
不是严格公理。这也是常识图谱「重召回、轻精确」的原因：
常识本来就「大概如此」，强行公理化（Cyc 的教训）会窒息。</span>

## 2 ConceptNet：概念的常识网

**ConceptNet** 是最著名的常识图谱之一：

**节点**：概念（词/短语，多语言）。
**关系**：`RelatedTo`、`IsA`、`PartOf`、`HasProperty`、
  `UsedFor`、`CapableOf`、`MotivatedByGoal` 等约 30 种。
**数据来源**：众包（Open Mind Common Sense）+ 游戏 + 集成
  WordNet/Wiktionary 等语言资源。
**权重**：每条边带权重，表示「常识的强度」。

典型三元组：

```text
(咖啡, UsedFor, 提神)
(咖啡, HasProperty, 苦)
(伞, UsedFor, 挡雨)
```

**重点：ConceptNet 的价值是「覆盖广、多语言、可检索」。**
它补的是「百科图谱里没有的常识边」——Wikidata/DBpedia 里可能没有
「咖啡→提神」，但这是常识。**工程用法：把 ConceptNet 当作
「常识检索层」，给 LLM 补「显而易见」的背景。**<span class="marginnote">ConceptNet 与
第七篇「上层本体」的关系值得玩味：上层本体给「概念分类」提供
顶层，ConceptNet 给「概念关联」提供常识层——一个是「类怎么分」，
一个是「物怎么用」。两者互补：上层本体管结构，常识图谱管内容。</span>

## 3 ATOMIC 与 COMET：if-then 的常识

**ATOMIC**（Sap et al., 2019）转向「事件级常识」——不是概念间
的关系，而是**「如果事件发生，那么会怎样」**的推断知识：

```text
(去餐厅, xIntent, 吃饭)
(去餐厅, xNeed, 有钱)
(下雨, xEffect, 路滑)
```

**ATOMIC 的关系都是「if-then」形状**：`xIntent`（意图）、`xNeed`
（前提）、`xWant`（想要）、`xEffect`（结果）、`xReact`（情绪反应）、
`xAttr`（属性判断）。它覆盖 9 种「社会常识」推断类型，
由众包 + 自动构建生成。

**COMET**（Bosselut et al., 2019）更进一步：用 ATOMIC 训练一个
Transformer，让它**给定事件自动生成常识推断**——不再需要
检索边，而是「生成边」。COMET 让常识推理从「查库」变成
「生成 + 查库」双通道。

**重点：ATOMIC/COMET 的标志是「推断型常识」**——它不止存
「咖啡提神」这种直接关联，还存「如果张三去餐厅，他的意图是
吃饭」这种**跨步骤的因果/意图推断**。这是常识从「关系图」
走向「推理图」的关键一步。<span class="marginnote">ATOMIC 的 if-then 结构与第四篇
「默认逻辑/规则」惊人相似：if 部分 ≈ 规则的「前提」（前件），
then 部分 ≈ 规则的「结论」（后件）。<strong>区别在语义强度</strong>：默认逻辑是
「除非反证否则成立」的硬规则，ATOMIC 是「通常如此」的软关联。
常识图谱把非单调推理的「默认」做成了「带权重的统计」——软硬之间
的连续谱，正是神经—符号的接缝。</span>

## 4 公式解析：一条常识推断的检索与生成

问：「张三去餐厅吃饭。他坐下后，服务员会给他什么？」

**第一步，事件解析**：识别事件「张三去餐厅」「他坐下」。
**第二步，图谱检索（ConceptNet/ATOMIC）**：
（去餐厅, MotivatedByGoal, 吃饭）、（坐下, HasProperty, 等上菜）；
ATOMIC：（张三去餐厅, xIntent, 吃饭）。
**第三步，生成补全（COMET）**：给定「去餐厅」，模型生成
  「意图：吃饭」「结果：服务员递来菜单」等推断。
**第四步，综合**：图谱证据 + 生成推断拼成上下文，
  送给 LLM 作答：「服务员会给他菜单」。

**重点：常识推理 = 图谱检索 + 模型生成 + 语言回答的三级流水线。**
图谱提供「可查的常识」，COMET 提供「可生成的常识」，
LLM 负责「把常识变成答案」。**「显式常识库 + 隐式常识模型」
的合流，是常识推理从实验室走向应用的关键。**<span class="marginnote">这条三级流水线
是第九篇「神经—符号融合」的缩影：<strong>检索/规则（符号）确定框架，
生成/语言（神经）填充内容</strong>。常识是「软」的，所以最适合
「符号给骨架、神经给血肉」的混合——下一节会把这个融合
系统化。</span>

## 5 LLM 的常识：够用还是不够

LLM 到底有没有常识？答案是「有，但不稳」：

**够用的部分**：训练语料里满是常识，LLM 能处理大量日常推理
  （Winograd 的大多数、物理直觉的常见情况）。
**不够的部分**：
**罕见组合**：「把盐倒进咖啡里」——训练数据少见，模型茫然。
**精确因果**：多步物理/时序推理仍会出错。
**对抗样例**：精心构造的 Winograd 变体、反事实场景。

**工程对策——常识检索增强：**

从 ConceptNet/ATOMIC 检索相关常识边，拼进提示
  （「提示里带上常识图谱」）。
用 COMET 生成常识推断作为「中间推理」。
把常识图谱当作「锚」，校验 LLM 输出是否违背常识。

**重点：LLM 的常识是「隐式的分布」，常识图谱是「显式的锚」。**
单靠 LLM，常识「大概对」；加上图谱，常识「有据可查」。
**「隐式为主、显式兜底」是当前的主流**——大多数场景 LLM 够用，
关键场景用图谱补足与校验。<span class="marginnote">LLM 常识的「分布性」值得哲学审视：
它学的不是「规则」，而是「语料里的共现规律」——「咖啡→提神」
不是作为公理存在，而是作为「高频共现」存在。这与第四篇
「默认逻辑的公理化」是两条路：<strong>一条显式立法，一条统计涌现</strong>。
常识推理的未来，大概率是这两条路的合流。</span>

## 6 小结

- 常识问题是 AI 最难啃的骨头：**物理、心理、社会、语言的「默认知识」**。
- 谱系：**Cyc（精确不可扩展）→ WordNet → ConceptNet（众包常识图）→
  ATOMIC/COMET（if-then 推断）**。
- **ConceptNet**：概念—关系—概念，`UsedFor`/`IsA` 等约 30 种关系。
- **ATOMIC**：事件级 if-then 常识（`xIntent`/`xNeed`/`xEffect`/`xReact`）；
  **COMET** 用 Transformer 生成常识推断。
- 常识推理 = **图谱检索 + 模型生成 + 语言回答**的三级流水线。
- LLM 有常识但不稳：**隐式为主、显式图谱兜底**。
- 定位：常识图谱是「世界运作规则的图」——知识图谱最野心的形态。

在下一节，我们将系统化这种「符号 + 神经」的协作——**神经—符号融合**：
符号推理与统计学习的结合点，从互补原理到工程范式。
