# Agent 的世界模型：图谱作为长期记忆

<div class="epigraph">
<p>一个智能体如果只有上下文窗口，就只活在当下；它需要一张「世界的地图」，才能记得自己从哪里来、要往哪里去。</p>

## 为什么从 Agent 记忆开始

前几节讲的都是「单次生成」，而真正的 Agent 是**长期运行的**：
它要执行多步任务、记住中间结果、在不同会话间积累知识。
LLM 的上下文窗口是它的「短期记忆」，装不下也留不住长期知识。
这一节讲知识图谱如何成为 Agent 的**长期记忆与世界模型**——
Agent 用图谱「读」世界来规划（像 GraphRAG），「写」新知识回图谱
（像抽取管道），图谱成为它跨会话持续积累的「外部大脑」。
理解 Agent 记忆，你就看到了知识图谱在 LLM 时代最有想象力的角色
——不只是「给回答提供依据」，而是**给智能体提供存在感**。

## 1 智能体的记忆问题

LLM Agent 的经典架构：**LLM + 工具 + 记忆 + 规划循环**。
其中「记忆」是最大的短板：

- **上下文窗口有限**：几万到几十万 token，一次对话装不下长期知识。
- **会话不持久**：每次会话从零开始，前一次学的不记得。
- **状态易失**：多步任务里的中间状态，窗口一满就被挤掉。

三种记忆类型（认知科学的分法）：

- **语义记忆（semantic memory）**：关于世界的持久事实
  （「张三就职于谷歌」）。
- **情节记忆（episodic memory）**：发生过的事件序列
  （「上个任务里我查了张三的履历」）。
- **程序记忆（procedural memory）**：怎么做的技能/规则。

**重点：LLM 的权重是「预训练的语义记忆」，上下文是「短暂的工作记忆」，
两者之间缺一块「持久、可查、可更新的长期记忆」。**
知识图谱恰好能填这个空：它是**结构化的外部记忆**——持久、
可查、可更新、跨会话共享。<span class="marginnote">「记忆」这个词在 LLM Agent 里
常被滥用。用第五篇的语言严格说：上下文是「瞬时的 ABox」，
LLM 权重是「隐式 TBox」，而知识图谱是「显式的 TBox + ABox」——
Agent 需要的是<strong>显式、持久、可版本化的知识层</strong>，而不是
「把更多文本塞进窗口」。</span>

## 2 图谱承载三种记忆

一张知识图谱可以同时扮演三种记忆：

| 记忆类型 | 图谱中的形态 | 例子 |
| --- | --- | --- |
| 语义记忆 | 实体 + 关系 | `(张三, worksFor, 谷歌)` |
| 情节记忆 | 事件 + 时序 | `(任务3, 查询了, 张三的履历)` |
| 程序记忆 | 规则 + 策略 | `IF 需要公司信息 THEN 查图谱` |

- **语义记忆**：图谱的常规内容——世界的持久事实。
- **情节记忆**：把「做过的事」也建成节点（事件本体），
  记录时间、上下文、结果——Agent 能回顾「上次怎么做的」。
- **程序记忆**：把「怎么决策」写成规则/策略，存进图谱或
  附属规则层——Agent 能按规则行事。

**重点：图谱的「结构化」让三种记忆都能被精确检索与更新。**
「忘了上次查到什么」→ 查图谱情节节点；
「新学了一家公司」→ 写进图谱语义节点；
「该按什么规则处理」→ 读图谱规则层。**记忆从「模型的隐式状态」
变成「图谱的显式数据」——可审计、可共享、可继承。**<span class="marginnote">三种记忆
放进本书坐标：语义记忆 ≈ 第五篇的 ABox，情节记忆 ≈ 时间本体
（第四篇的时间中的存在 + 事件建模），程序记忆 ≈ 第四篇的产生式
规则。<strong>Agent 记忆架构，把本书的符号知识全部复用了</strong>——图谱
不是新东西，而是给旧知识找到了新主人（Agent）。</span>

## 3 公式解析：读—写—更新的循环

Agent 与图谱的交互是持续循环：

1. **读（规划前）**：任务开始时，Agent 从图谱检索相关子图
   ——「先看看我知道什么」。
2. **规划**：基于检索到的图谱结构（多跳关系）制定步骤。
3. **执行**：调用工具完成任务。
4. **写（执行后）**：把学到的新事实写回图谱
   ——「查到的、发现的、确认的」都落库。
5. **更新/校验**：新事实过校验闭环（上一节），冲突则消解。

**逐项拆解这个循环的要点：**

- **读**决定「知道什么」：检索质量 = GraphRAG 的局部查询。
- **写**决定「记住什么」：写入质量 = 抽取 + 校验的质量。
- **更新**决定「记忆对不对」：冲突消解 = 第八篇知识融合的延续。

**重点：Agent × 图谱是「双向飞轮」**——图谱让 Agent 更聪明
（检索增强），Agent 让图谱更完整（写回新知识）。**每执行一次
任务，图谱和 Agent 都各长进一分**——这是「记忆增强智能体」
与「知识图谱自动化」的合流。<span class="marginnote">这个循环与第四篇的
「识别—行动」循环呼应：读图谱 ≈ 识别状态，写图谱 ≈ 更新记忆。
而「写回的知识要与旧知识一致」——这正是框架问题（第四篇）
的软版本：<strong>Agent 更新世界模型时，必须知道哪些没变、哪些变了</strong>。</span>

## 4 世界模型：从内部表示到外部图谱

**世界模型（world model）**：智能体对「世界状态及其变化规律」的
内部表示。传统 Agent 的世界模型在程序里（隐式、难更新）；
LLM Agent 的世界模型在上下文里（短暂、易失）。

**图谱作为世界模型的价值，是把「世界模型」外部化：**

- **显式**：世界状态写成实体与关系，看得见、查得到。
- **可更新**：世界变了，改图谱节点——比改程序/上下文都容易。
- **可校验**：世界模型与事实冲突时，校验层能发现（上一节）。
- **可共享**：多个 Agent 共享同一张图谱 = 共享同一个世界模型。

**重点：外部化让「世界模型」从「智能体的私有心理」变成
「团队的公共资产」。** 这正是全书哲学线的工程高潮——第三篇
「随附性/形而上学基础」追问世界如何被表征，这里给出一个
工程答案：**让世界模型是一张可读、可写、可校验的图。**
「心灵的外部化」在知识图谱里获得了字面意义。<span class="marginnote">哲学上，这呼应
「外在主义（externalism）」：认知不只在头脑里，而在头脑与
环境的耦合中。Agent 的「记忆」不在权重里，而在「权重 +
图谱」的耦合里——<strong>图谱是 Agent 的「体外认知」，这让 Agent
的记忆可继承（新 Agent 接上图谱即有旧记忆）、可审计、可版本化</strong>。</span>

## 5 挑战与前沿

Agent 记忆的挑战不容回避：

- **一致性**：多 Agent 并发写图谱，冲突消解压力大。
- **遗忘与压缩**：图谱无限增长，旧记忆要压缩/衰减——「该忘什么」。
- **检索相关**：图谱大了，「读哪部分」越来越难——检索质量成为瓶颈。
- **与上下文的分工**：哪些进上下文、哪些进图谱、哪些进权重——
  三层记忆的「路由」尚无定论。

**前沿方向**：MemGPT 式的「虚拟上下文管理」（把记忆当分页）、
记忆的自动总结与提炼（把细粒度事件聚合成知识）、
以及「图谱引导的规划」（用图谱结构约束 Agent 的步骤）。
**Agent 记忆是当下最活跃的图谱 × LLM 研究前线。**

## 6 小结

- Agent 的短板：**上下文有限、会话不持久、状态易失**。
- 图谱承载**三种记忆**：语义（事实）、情节（事件）、程序（规则）。
- **读—写—更新循环**：检索增强规划，写回新知识，校验保持一致。
- 图谱让**世界模型外部化**：显式、可更新、可校验、可共享。
- 哲学呼应：**图谱是 Agent 的「体外认知」**——记忆可继承、可审计。
- 挑战：**一致性、遗忘压缩、检索相关、三层记忆路由**。
- 定位：Agent 记忆让知识图谱从「回答的依据」升级为「智能体的存在感」。
