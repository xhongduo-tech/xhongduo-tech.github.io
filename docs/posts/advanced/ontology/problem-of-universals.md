## 为什么一场中世纪争论至今未熄

第二章我们学到：亚里士多德区分了第一实体（个体）与第二实体（属与种），并说第一实体更实在。但「人」「动物」这些**共相（universal）**——普遍概念——到底以什么方式存在？亚里士多德的克制回答没有终结问题，反而点燃了中世纪哲学最长的一场火：**共相之争（the problem of universals）**。极端实在论说共相独立自存，唯名论说它们只是名字，温和实在论说它们存在于个体之中。三方吵了上千年。

这场争论对「从极限到大模型」的读者绝非故纸堆。**任何一个知识图谱的 schema、任何一个本体的类层次，都是在替建模者回答「共相是什么」：** 「人」这个类，是独立于个体而真实存在的东西（实在论），还是仅仅是我们给一群相似个体贴的标签（唯名论），还是我们头脑里基于真实相似性形成的概念（概念论）？哲学史上吵了一千年的问题，今天被每个本体工程师用建模决策重新回答一遍。到第七篇，BFO 自称「实在论导向」、DOLCE 自称「认知导向」，都是这场争论的现代续篇。<span class="marginnote">「共相」的英文 universal 来自拉丁语 universalis（普遍的），指「可以同时述说多个个别者的东西」——「人」述说苏格拉底、柏拉图、亚里士多德，因此是共相；「苏格拉底」只指一个，是殊相（particular）。整场争论的问题就一句：这个「可以述说多个个体」的普遍者，它的存在地位是什么？</span>

## 1 问题起源：波菲利之问与波埃修斯的中介

争论的导火索不在亚里士多德，而在三世纪新柏拉图主义者**波菲利**。他在为《范畴篇》写的导论（*Isagoge\*）里，把关于属与种的三问摆上台面——它们是不是独立自存的实体？如果是，是有形还是无形？是与可感事物分离还是寓于其中？——然后**拒绝回答**，说这问题太深，留待高明。

这个「波菲利之问」由**波埃修斯（Boethius）**翻译并评注，传到拉丁西方，成了中世纪经院教育里每代学者都必须面对的第一道大题。为什么三问如此致命？因为它把亚里士多德《范畴篇》里那个被克制的裂缝彻底撬开：如果第二实体（属与种）存在，它要么独立于个体（那就滑向柏拉图），要么依附于个体（那就得说清「依附」是什么）；而两边的答案都通向神学——若共相先于万物存在，它就是上帝心中的原型；若共相只是名字，那教义里的「原罪」「人性」这些普遍者又算什么？**一场逻辑学问题，因神学压力而升级为存在论的总决战。**<span class="marginnote">波菲利之问的结构与今天「schema 优先还是 data 优先」的问题惊人同构：共相是否独立自存 ↔ schema 是否独立于实例存在；共相是否寓于个体 ↔ schema 是否只是对数据的归纳。两千年前的三个选项，原封不动地活在今天的数据库设计与本体工程里。</span>

## 2 三种立场：极端实在论、唯名论与概念论

争论的谱系可以大致分成三个阵营。为便于对照，先用一张草图给出三方的核心主张，再逐条展开：

**极端实在论（exaggerated realism）**：共相先于、独立于个别事物而实在存在。「人」是一个真实的东西，苏格拉底只是分有它。
**唯名论（nominalism）**：共相只是名字（nomen）、只是声音（flatus vocis）。真实存在的只有个别事物。
**概念论（conceptualism）**：共相是心灵中的概念，以个别事物间的真实相似性为基础。

**极端实在论**的代表是香波的威廉（William of Champeaux）。他主张一个共相「整个地、同时地」存在于它的每一个个体中——「人」完整地在苏格拉底里，也完整地在柏拉图里。于是个体之间的差别不是「本质」差别，而只是偶性差别。这个立场把个别性贬为附带现象，很快在阿伯拉尔（Abelard）的批评下站不住脚：如果「人」作为实体完整存在于两人之中，两人的实体岂不完全相同？那苏格拉底与柏拉图岂不只是同一个实体的两个偶性变体？

**唯名论**的代表是贡比涅的罗色林（Roscelin of Compiègne）。他把共相还原为「声音的气息」（flatus vocis）——一个词，一个音，别无其他。罗色林把唯名论推得如此之远，以至于连「三位一体」里共有的神性都被质疑，招致教会谴责。他的论敌阿伯拉尔在《逻辑初阶》里反驳：如果「人」只是声音，那「人是有死的」这条命题谈论的就只是空气的振动，知识就会沦为对声音的运算——这显然是荒谬的。

**概念论**通常挂在**阿伯拉尔（Peter Abelard）**名下（尽管他常被后世归为温和唯名论）。阿伯拉尔的精妙之处在于区分：共相作为**词（sermo）**存在于语言中，作为**概念（conceptus）**存在于心灵中，而概念的基础是个别事物之间的**「状态」（status）**——苏格拉底和柏拉图确实共享「是人」这个状态，这个状态不是独立实体，但也不是纯虚构。概念论由此走出第三条路：**共相不独立自存，但也不是无中生有的名字，它是对真实相似性的心灵抽象。**<span class="marginnote">阿伯拉尔最有名的人生是那场与爱洛伊丝的悲剧恋爱，但在逻辑史上，他是 12 世纪最锋利的概念分析者。他的「状态」概念——既非实体、又非虚构——让「普遍性」第一次有了一个既不需要柏拉图式实体、又不沦为纯粹声音的位置。这个「第三位置」在今天的语义网里，正是「类作为共享约定」的位置。</span>

## 3 阿奎那的温和实在论：共相以三种方式存在

13 世纪，托马斯·阿奎那（Thomas Aquinas）给出中世纪最成熟的综合——**温和实在论（moderate realism）**。他的关键洞见是：**共相的存在不是「一个还是多个」的问题，而是「几个层面」的问题。** 阿奎那提出共相以三种方式存在：

**在物之先（ante rem）**：作为上帝心中的原型——「人」的观念先于任何具体的人而存在于神智中。这是创世论维度的实在论。
**在物之中（in re）**：作为个别事物的**共同本性（common nature）**——苏格拉底与柏拉图各自拥有「人性」，但这个共同本性在他们各自那里被个体化（individuated），变成「苏格拉底的人性」与「柏拉图的人性」。
**在物之后（post rem）**：作为人心从个别事物中抽象出的概念——认知层面的共相。

**重点：阿奎那用「存在方式」的多元性化解了「存在与否」的二元争执。** 共相既不是独立实体（那会摧毁个体的实在性），也不是纯名字（那会摧毁知识的普遍性），而是「在物中作为共同本性、在人心中作为概念、在神心中作为原型」的**三层存在**。这个「in re」的核心，是对亚里士多德「第二实体依附于第一实体」的忠实延伸——共相内在于个体，是它的真实结构，而不是外加的标签。<span class="marginnote">阿奎那的「共同本性」在后世被比作「个体的构成结构」：苏格拉底与柏拉图是同一个物种（human species）的两个 token。用今天的话说，阿奎那主张「类型（type）内在于其样本（token）之中」，而不是悬在样本之上。这个直觉正是现代本体里「类与实例是两层面而非两个独立存在域」的哲学源头。</span>

阿奎那的三层模式为后文埋了一个重要线索：**「in re / post rem」的区分，几乎就是「schema 与数据」与「schema 与心智模型」两组区分的哲学模板。** 一个本体既有「在数据中实现的模式」（in re），也有「工程师头脑中、文档中的概念模型」（post rem），还有「作为设计蓝图的上层本体」（ante rem，如果它有规范权威的话）。

## 4 奥卡姆的剃刀：只有个体存在

14 世纪的威廉·奥卡姆（William of Ockham）给出最锋利的一刀。他的出发点是极简主义原则：**如无必要，勿增实体（entia non sunt multiplicanda praeter necessitatem）**——即后来广为人知的「奥卡姆剃刀」。我们会在本专题专章讨论剃刀本身，这里只看它如何判决共相问题。

奥卡姆的结论是：**只有个体存在，共相是记号（sign）。** 一个词如「人」，它的功能不是指向一个独立实在，而是**指谓（supposit）**许多个别的人；一个概念如「人」，是心灵对多个相似个体的一个记号，其普遍性来自「心灵的意向」，而非对象的实在结构。奥卡姆由此断言：「人」并不比它的诸多个例更实在——实在的只有苏格拉底、柏拉图，以及每一个别的人。

**辨析｜易错点：奥卡姆不是罗色林式的极端唯名论。** 罗色林把共相说成「声音的气息」，奥卡姆则把共相处理为「概念—记号」：概念在心智中真实存在，只是它不指谓一个独立于个体的对象。奥卡姆的立场更接近「概念论」而非「声音唯名论」——他把普遍性从「对象层面」移到「语言与心智层面」。中文学界常把奥卡姆简单贴上「唯名论」标签，严格说他主张的是「个体实在 + 概念普遍」。

奥卡姆这一刀的历史后果极其深远：**它把「类」从世界结构里请出去，塞进语言与心智。** 两百多年后，近代科学正是在这个「类只是命名」的语境里起步——牛顿的「万有引力」不再需要一个「引力本质」的类来担保，只要方程预测现象即可。科学实在论与工具主义之争，是共相之争的近代变体。<span class="marginnote">奥卡姆的剃刀不是一条「删繁就简」的审美原则，而是一个本体论承诺：一个理论只承诺它不得不承诺的实体。这条原则到第七篇《奥卡姆的剃刀》专章会细讲——它既是本体工程「别建多余的类」的建模纪律，也是大模型时代「别假设模型内部藏了一个完整本体」的方法论警告。</span>

## 5 共相之争在现代的重演：从科学到本体工程

共相之争没有随中世纪结束，它在近代科学里换了一副面孔继续。洛克区分「实在本质」（real essence）与「名义本质」（nominal essence）：他认为我们只能命名「名义本质」——我们约定的一组可观察特征——而「实在本质」不可知。这几乎是阿奎那「post rem」与奥卡姆「记号论」的科学版：**类的划分是心智的约定，不是世界自带的标签。** 到了现代科学哲学，实在论者坚持「自然类」（natural kinds，如电子、水、物种）真实存在且由科学发现，唯名论者坚持类只是理论构造——这场拉锯直到今天仍在物理哲学与生物哲学里进行。

对本专题更切身的是它在**本体工程**里的重演。建一个本体时，建模者必须回答：**我的 schema 是「发现」还是「发明」？**

**实在论导向**（如 BFO）：类的划分应当反映世界真实的切分，最好与科学共同体的实体清单对齐；「人」「细胞」「过程」不是因为方便而建，而是因为它们对应真实存在者。
**认知 / 概念论导向**（如 DOLCE）：类是人类认知的产物，本体是「描述人类认知结构的概念化」；同一个世界可以有多个同样合理、互不还原的分类方案。

这个分歧不是抽象的——它决定一个本体的**验收标准**。实在论者问：「这个类在科学上是真实的吗？」概念论者问：「这个类对我们的认知与交流有解释力吗？」两套标准都说得通，但会产出不同的 schema。落到代码上，同一个论域可以用两种姿态建模：

```turtle
# 姿态 A：本质定义（实在论）——「人」= 具有人类基因组者
:Human a owl:Class ;
       owl:equivalentClass [ a owl:Restriction ;
                             owl:onProperty :hasGenome ;
                             owl:someValuesFrom :HumanGenome ] .

# 姿态 B：约定角色定义（概念论）——「顾客」= 至少购买过一次者
:Customer a owl:Class ;
          owl:equivalentClass [ a owl:Restriction ;
                                owl:onProperty :hasPurchased ;
                                owl:minCardinality 1 ] .
```

姿态 A 用「本质」给类下定义（人 = 具有人类基因组者），姿态 B 用「约定角色」给类下定义（顾客 = 至少购买过一次者）。**两种写法在 OWL 里都是合法的，但背后站着完全不同的本体论承诺**：A 承诺「人」这个类在世界里有对应的真实结构，B 只承诺「顾客」是一个服务于应用的约定。中世纪吵了一千年的问题，今天被一个 `owl:equivalentClass` 声明悄悄回答。

## 6 核心对比表：三种立场 × 语义网 / 知识图谱的类

本主题以概念辨析为主、无核心公式，故以「核心对比表」代替公式解析——按编辑章程第 5 节执行。

| 维度 | 极端实在论 | 温和实在论（阿奎那） | 唯名论 / 概念论（奥卡姆） |
| --- | --- | --- | --- |
| 共相存在方式 | 独立于个体自存 | 在物中为共同本性、在人心中为概念 | 只是记号 / 概念，个体才实在 |
| 「人」是什么 | 一个真实存在的普遍实体 | 个体内共同本性的抽象 | 指谓众多个体的记号 |
| 个体与共相关系 | 个体分有共相 | 共相内在于个体并被个体化 | 共相后于个体、源于抽象 |
| 科学知识的基础 | 把握真实共相 | 把握个体中的共同本性 | 把握个体及其相似性 |
| 工程对应：schema 的地位 | schema 独立真实，数据分有 schema | schema 内在于数据，是数据的结构归纳 | schema 是约定记号，只有数据真实 |
| 语义网中类的角色 | 类是第一位的 | 类 = 实例共同结构的抽象 | 类 = 共享 IRI 约定，不增实体 |
| 上层本体代表 | 柏拉图式层级 | 实在论导向（如 BFO） | 认知导向（如 DOLCE） |

这张表最后两行最值得停住。**第七篇的 BFO 与 DOLCE，就是这场争论的现代工程版**：BFO 宣称自己是实在论导向——类应当反映世界真实的切分，最好落在科学家认可的实体上；DOLCE 则明言自己是认知导向——本体的类是人类认知的产物，不承诺独立于心智的实在。选 BFO 还是 DOLCE，不只是一个技术选型，而是一次**本体论立场表态**。中世纪吵了一千年的问题，今天被一个 `rdfs:subClassOf` 语句重新提起。<span class="marginnote">在大模型时代，共相之争还有第三个投影：神经网络里学到的「类别」算不算「共相」？一个语言模型把「猫」这个词关联到千万张猫的图片分布，它的「猫」概念更像概念论（对相似性的统计抽象）还是唯名论（只是语境中的记号）？这个问题留到第九篇「神经—符号融合」再深挖。</span>

## 7 小结

- **波菲利之问**：属与种是否独立自存？经波埃修斯翻译传入中世纪，成为神学压力下的存在论总决战。
- **三阵营**：极端实在论（共相独立自存）、唯名论（只是名字）、概念论（基于真实相似性的心灵概念）；阿伯拉尔是概念论的枢纽。
- **阿奎那温和实在论**：共相以三种方式存在——物先（神智原型）、物中（共同本性）、物后（心灵概念）；「in re」忠实延续亚里士多德。
- **奥卡姆的剃刀**：如无必要勿增实体；只有个体存在，共相是记号；严格说是概念论而非声音唯名论。
- **现代重演**：洛克「名义本质」、科学实在论与工具主义、BFO 与 DOLCE 的上层本体之争、LLM 习得的「概念」——都在重演共相之争的三分结构。
- **工程落地**：同一个论域可用「本质定义」（实在论姿态）或「约定角色定义」（概念论姿态）建模，owl:Class 的两用法即两种承诺。

在下一章，我们将继续中世纪—近代的交界：托马斯·阿奎那把「存在（esse）」与「本质（essentia）」区分开来——那是为「上帝存在」论证服务的、也是本体论最精巧的一对概念区分。
