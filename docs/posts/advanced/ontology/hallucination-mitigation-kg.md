# 幻觉抑制：知识图谱作为事实锚点

<div class="epigraph">

## 为什么从幻觉抑制开始

第九篇一路走来，「互补」的最终动机其实很朴素：**LLM 会骗人——不是
存心，而是幻觉（hallucination）**。它自信地编造事实、张冠李戴、
用过期知识作答，自己却浑然不觉。在医疗、金融、法律，「大概对」
就是错。这一节讲**幻觉抑制**的完整武器库：知识图谱如何作为
**事实锚点（fact anchor）**，通过**落地生成、约束生成、事实验证**
三条机制，把 LLM 从「自信地编」变成「有据地说」——并且，
当图谱没有答案时，**学会诚实地说「不知道」**。这是第九篇的
收官，也是「图谱 × LLM」价值最清晰、最可量化的理由。

## 1 幻觉的成因与类型

**幻觉（hallucination）**：LLM 生成的、与事实不符或无法验证的内容。
它不是你「哪里写错了」，而是**生成机制的结构性倾向**——模型
按「最像」而非「最真」生成。

三种常见类型：

- **事实编造（fact fabrication）**：生成不存在的实体/事件/数字。
- **知识过期（stale facts）**：训练数据截止前的旧信息被当现状。
- **矛盾（contradiction）**：生成内容与自身其他内容、或常识冲突。

**成因**：生成目标是最小化「语言上的困惑」，不是最大化「事实上的
正确」——**模型优化的不是「真」，是「像真的」**。这个错位，
就是幻觉的结构性根源。

**重点：幻觉无法靠「让模型更努力」根除**——模型不知道自己在编
（它没有「外部事实」的概念）。**唯一的出路是「引入外部事实」**：
让生成基于可验证的锚——这正是知识图谱的角色。<span class="marginnote">幻觉的哲学
根源在第四篇「替身」概念：模型的「世界」是权重里的分布，
是世界的<strong>统计替身</strong>——替身忠实于「语料的规律」，不忠实于
「世界的事实」。知识图谱是<strong>显式的替身</strong>（逐条可查），
用它替换/约束「统计替身」，就是把「像真」升级为「是真」的
第一步。</span>

## 2 知识图谱锚定生成的三条机制

知识图谱抑制幻觉，靠三条机制：

| 机制 | 做法 | 对应章节 |
| --- | --- | --- |
| 落地生成 | 检索图谱事实，条件生成（Grounding） | GraphRAG |
| 约束生成 | 用 schema 限定输出结构 | schema 约束生成 |
| 事实验证 | 生成后对照图谱核查 | 校验闭环 |

- **落地生成（grounded generation）**：不靠模型记忆，靠检索到的
  图谱事实生成——「答案的原料从图谱来」。
- **约束生成**：schema 让输出结构合法（上一节）。
- **事实验证（fact verification）**：生成后把「声明（claim）」
  与图谱事实比对——一致则通过，矛盾则标记或重生成。

**重点：三机制的分工是「事前、事中、事后」。**
落地生成在**事前**锚定原料（防患），约束生成在**事中**限定形状
（防形错），事实验证在**事后**核查内容（纠实错）。**完整的
幻觉防线是「三管齐下」**——只靠一层，都有漏网之鱼。<span class="marginnote">三机制对照
第五篇的推理任务：落地生成 ≈ ABox 检索（从库里拿证据），
事实验证 ≈ 蕴含检查（声明是否被知识库蕴含）。<strong>幻觉抑制
在符号层的对应物，就是「让生成内容成为知识库的模型」</strong>——
LLM 不再「自由发挥」，而是「在知识库的约束下发挥」。</span>

## 3 公式解析：一次事实验证走查

验证一条 LLM 生成的声明「张三于 2020 年加入谷歌」：

- **第一步，声明抽取**：从生成文本中抽出可验证的原子声明
  `(张三, 加入时间, 2020, 谷歌)`。
- **第二步，图谱查询**：查知识图谱——
  `张三 worksFor 谷歌`、`张三 joinTime 2020` 存在吗？
- **第三步，判定**：
  - 图谱有 `joinTime 2019` → **矛盾**：标记，重生成或拒发。
  - 图谱无 `joinTime` 记录 → **未知**：保守输出
    「图谱未记录入职时间」或触发检索补全。
  - 图谱有 `joinTime 2020` → **通过**：输出，并附证据出处。
- **第四步，证据回填**：答案附上「依据：图谱节点 X，来源 Y」——
  让用户能复核。

**重点：验证的本质是「把声明变成查询，把查询结果变成判定」。**
这等于把 LLM 的「陈述」翻译成 ABox 断言，再交给知识库的
「实例检查」去裁决——**幻觉抑制是第五篇推理服务的直接应用**。
「通过/矛盾/未知」三分，比「对/错」二分诚实得多。<span class="marginnote">「未知」这个
答案是本书反复出现的主题：第六篇 OWA 的「没声明=不知道」、
第五篇实例检查的「无法判定」。<strong>诚实地说「不知道」是比幻觉
高级得多的系统行为</strong>——知识图谱让 LLM 第一次能「诚实地无知」。</span>

## 4 权衡与边界：覆盖率 vs 幻觉

幻觉抑制有个绕不开的权衡——**图谱覆盖率（coverage）**：

- **图谱全，验证严** → 幻觉少，但**覆盖率低时大量「未知」**，
  回答显得「无能」。
- **图谱松，验证宽** → 回答流畅，但**漏网幻觉多**。

**工程对策：**

- **分级回答**：图谱有据 → 自信作答；图谱无据 → 检索增强补全；
  仍无据 → 明确声明「无可靠来源」，而非编造。
- **置信度标注**：把「有据/无据」作为置信度传达给用户。
- **图谱补全**：把高频「未知」反馈回抽取管道（第 3 节），
  持续扩大覆盖。

**重点：幻觉抑制的成熟形态是「知晓自身边界」。**
好的系统不是「永不幻觉」（做不到），而是「**幻觉发生时
能被发现、被发现时能诚实认错**」——「有据才说、无据就说
无据」是比「追求全对」更现实的工程目标。<span class="marginnote">「知晓边界」呼应
全书的认识论主线：第五篇的 OWA 承认「知识不完备」，
第七篇的「能力问题」界定「本体边界」。<strong>一个知道「自己不知道
什么」的系统，比一个「自信地什么都知道」的系统更可靠</strong>——
这是从阿奎那的「存在层级」到现代 LLM 一以贯之的智慧。</span>

## 5 从抑制到事实保证：评测

幻觉抑制的效果怎么量？近年出现专门指标：

- **事实验证准确率**：生成的声明中「与知识库一致」的比例。
- **FaithScore**：衡量生成内容对给定知识/上下文的「忠实度」。
- **引用可溯性**：答案是否附可验证的来源。
- **弃权率（abstention rate）**：该说「不知道」时说「不知道」的
  比例——**合理的弃权率是优点，不是缺点**。

**重点：评测的转向是「从流畅到忠实」。** 传统指标（BLEU 等）
只衡量「像不像人话」，事实验证指标衡量「是不是真话」。
**当知识图谱参与评测时，「忠实度」第一次可以被自动计算**——
这又回到知识图谱的老本行：显式、可查、可比对。<span class="marginnote">「忠实度」的
可计算，是知识图谱给幻觉研究最大的礼物：没有显式知识库，
「幻觉」只能靠人工判定；有了图谱，「忠实」变成可自动评估的
指标。<strong>知识图谱不只是「抑制幻觉的工具」，也是「度量幻觉的尺子」</strong>。</span>

## 6 小结

- **幻觉**是生成机制的结构性倾向：模型优化「像真」而非「是真」。
- 三类型：**事实编造、知识过期、矛盾**；根源是「无外部事实概念」。
- 三机制：**落地生成（事前）、约束生成（事中）、事实验证（事后）**。
- **事实验证** = 声明→查询→判定（通过/矛盾/未知）——第五篇推理服务的应用。
- 权衡：**覆盖率 vs 幻觉**——分级回答 + 置信度 + 图谱补全。
- 成熟形态：**「有据才说、无据说无据」的诚实系统**。
- 评测转向：**从流畅到忠实**——图谱让「忠实度」可自动计算。
