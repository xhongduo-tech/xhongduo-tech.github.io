# 知识图谱的概念史：从语义网到 Google Knowledge Graph

<div class="epigraph">
<p>搜索引擎不再只给你一串链接——它给你「事物」本身，以及关于这个事物的知识。这就是知识图谱。</p>
<footer>—— 谷歌 Knowledge Graph 发布词（Amit Singhal, 2012）：things, not strings</footer>
</div>

<div class="article-byline">
<p>第四级 · 本体论 ｜ Hogan et al.《知识图谱》(ACM Computing Surveys, 2021)；Paulheim《知识图谱反思》(2017) ｜ 2026-08-07</p>
</div>

## 为什么从概念史开始

第六篇我们讲到语义网「理想—落差—复活」的曲线，而「复活」的主角正是
**知识图谱（knowledge graph, KG）**。2012 年谷歌把它带上热搜，
但知识图谱的血统远不止十年——从 1960 年代的语义网络，到 1980 年代的
专家系统知识库与 Cyc，到 2001 年语义网宣言、2007 年 DBpedia/Freebase，
再到 2012 年谷歌 Knowledge Graph 一词定乾坤。理解这段概念史，
你就明白了知识图谱「为什么长成这样」：它既不是横空出世，
也不是语义网的简单改名，而是**语义网愿景 × 工业规模 × 搜索引擎**
三股力量合流的结果。

## 1 前史：从语义网络到 Cyc

知识图谱的第一批祖先，我们早在第四篇就见过：

- **1960 年代**：语义网络（奎利安）——节点—弧的知识图，直觉的源头。
- **1970–80 年代**：专家系统的知识库（MYCIN、XCON）——「知识 = 规则 +
  事实」的工业验证。
- **1984 年起**：**Cyc** 项目——道格拉斯·莱纳特（Douglas Lenat）立志
  把人类常识全部编码成形式化公理，规模宏大却耗时漫长，成为
  「人工建知识库」最激进的尝试与最深刻的教训。
- **1985 年起**：**WordNet**——普林斯顿的词汇语义数据库，给「词」
  建立概念网络。

**重点：这段前史确立了两条遗产——「知识可以结构化」与「手工结构化
不可扩展」。** Cyc 花了数十年才编码几十万条常识公理，而互联网
每分钟产生的数据比它一年编码的还多。**「手工建库」的天花板，
成了后来「自动构建」的原动力**——这也是知识图谱与 Cyc 的根本分野。<span class="marginnote">Cyc 的教训
是全书最深刻的反例之一：它证明了「本体正确」不等于「规模可行」。
今天的知识图谱从 Cyc 继承了「常识」这个理想，却把实现路径
从「手工公理」改成了「众包 + 自动抽取」——理想不变，工程换血。</span>

## 2 语义网与链接数据：标准与生态的铺垫

2000 年代，语义网从「愿景」长出「标准」与「数据」两支：

**2001 年**：Berners-Lee 语义网宣言（第六篇）。
**2004 年**：W3C 发布 RDF/RDFS/OWL 标准。
**2006 年**：伯纳斯-李提出**链接数据（Linked Data）四原则**——
  用 IRI 命名事物、让 IRI 可反解、复用别人的 IRI、链接到他人数据。
**2007 年**：**DBpedia** 从维基百科自动抽取结构化数据；
  **Freebase** 众包知识库上线（后来被谷歌收购，成为 KG 的前身）。
**2012 年**：**Wikidata** 上线——维基媒体基金会的结构化知识库，
  众包 + 开放许可，成为今天最大的开放 KG 之一。

**重点：链接数据与 DBpedia 证明了一件事——「自动从开放文本里
抽取结构化知识」是可行的。** DBpedia 把维基百科的几十亿条
事实变成 RDF，让「开放数据」第一次有了大规模实体。
**这是语义网「生态未长成」困境的第一次破局**：数据不是
等来的，是自动抽出来的。<span class="marginnote">链接数据四原则里最反直觉的一条是
「复用别人的 IRI」——它要求你<strong>不要给已有事物发明新名字</strong>。
这条原则直接塑造了后来的实体对齐：知识图谱里同名 IRI 越少，
合并成本越低。第九篇 LLM 抽取时，这条原则变成了「先查库再生成」。</span>

## 3 Google Knowledge Graph：一词定乾坤

2012 年 5 月，谷歌发布 **Knowledge Graph**——不是新发明，而是
把 Freebase + 自己的数据整合成「实体—关系」库，给搜索结果
右侧加了一个「知识面板（knowledge panel）」。随后的口号：
**「things, not strings」——搜索的不再是字符串，而是事物。**

这一发布的冲击是**命名与转向**：

「知识图谱」一词（曾有零星学术使用）被谷歌「重新注册」，
  从此成为整个领域的通用名。
搜索引擎的范式从「匹配文档」转向「理解实体」——查询先被
  解析成「实体 + 关系」，再检索知识图谱，最后才是文档。
知识面板让「机器可读知识」第一次以**面向普通用户的产品**
  形态出现——语义网苦等的「杀手级应用」终于来了。

**重点：谷歌的贡献不是技术，而是「验证 + 命名」。** 技术构件
（RDF、本体、实体消解）都是现成的；谷歌把它们组装成
十亿级规模的线上服务，并给了它一个响亮的名字。**知识图谱
从此 = 语义网的工程验证 + 面向大众的接口。**<span class="marginnote">「things, not strings」的
哲学分量：它宣布「字符串只是指称，事物才是本体」——这正是
第二篇弗雷格「意义与指称」的搜索引擎版。搜索的本质被重新定义为
「沿着指称找到事物及其关系」，而不是「字面匹配」。哲学思想
在工业产品里完成了一次大规模落地。</span>

## 4 里程碑年表

把关键节点收进一张表：

| 年代 | 事件 | 意义 |
| --- | --- | --- |
| 1968 | 语义网络（奎利安） | 知识图的直觉源头 |
| 1984 | Cyc 启动 | 手工常识编码的极限尝试 |
| 1985 | WordNet | 词汇语义网络 |
| 2001 | 语义网宣言 | 机器可读语义的愿景 |
| 2006 | 链接数据四原则 | 开放数据互连的规范 |
| 2007 | DBpedia / Freebase | 自动抽取与众包知识库 |
| 2012 | Google Knowledge Graph / Wikidata | 一词定名 + 开放 KG 里程碑 |
| 2013+ | GraphRAG、LLM 时代 | 知识图谱与大模型合流（第九篇） |

**重点：年表的走向是一条「从手工到自动、从学术到工业」的曲线。**
每一个新节点都解决了上一个节点的瓶颈：语义网络太糊 → 本体给语义 →
手工太慢 → 自动抽取 → 学术无场景 → 谷歌验证场景。<span class="marginnote">把这张表与
第六篇分层蛋糕对照着读：蛋糕是「标准栈」的时间切片，年表是
「标准栈 + 数据 + 产品」的演化史。知识图谱的每一次跃迁，
都是「标准准备好了 + 数据终于够了 + 产品恰好出现」三者的巧合。</span>

## 5 从概念史看知识图谱的本质

回望整条线，可以给知识图谱一个「历史定义」：

**知识图谱（knowledge graph）**：以图结构组织、以实体为节点、
以关系为边、支持规模化的存储/查询/推理的「机器可读知识系统」——
它是语义网标准的工业继承者，用工程手段实现「语义网愿景」。

三个区别于前身的本质特征：

**规模**：亿级实体、十亿级三元组——Cyc 与早期本体的「手工小库」
  完全不在一个量级。
**自动构建**：从文本、网页、数据库自动抽取——而非手工编码。
**服务导向**：为搜索、问答、推荐等产品服务——而非纯学术研究。

**重点：知识图谱是「语义网的下半场」**——它没有推翻 RDF/OWL 的标准，
而是把它们放进十亿级数据的工程架构里，让「语义」第一次
「跑得动、用得上、赚得到」。**理解了这个历史定位，后面每一节
（构建、存储、查询、嵌入、大模型）都有了坐标系。**<span class="marginnote">这一节的历史
视角也回答了「知识图谱 vs 本体」的关系：本体是「语义的 schema」，
知识图谱是「schema + 海量实例 + 服务」的完整系统。<strong>本体是 KG 的
骨架，KG 是本体的血肉与生命</strong>——第八篇后续章节将围绕这条主线展开。</span>

## 6 小结

- 知识图谱的概念史：**语义网络 → Cyc/WordNet → 语义网标准 → 链接数据 →
  DBpedia/Freebase → Google KG → LLM 时代**。
- Cyc 的教训：**手工建库不可扩展**——自动构建成为必然。
- 链接数据 + DBpedia 证明**自动抽取可行**，为生态破局。
- 谷歌 2012 年的贡献是**验证 + 命名**：「things, not strings」转向实体。
- 知识图谱的本质特征：**规模、自动构建、服务导向**。
- 它是**语义网愿景的工业继承者**——标准未变，工程换血。
- 一句话：**本体是 KG 的骨架，KG 是本体的血肉与生命**。

自顶向下与自底向上两条路线，如何从零到十亿级实体搭建一张图。
