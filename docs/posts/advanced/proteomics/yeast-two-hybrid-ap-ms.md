## 为什么从蛋白相互作用开始

前面的分节都在问「这个蛋白是什么、有多少、怎么修饰」。但**单个蛋白在细胞里几乎从不单打独斗**：信号通路靠蛋白一个传一个，复合物靠多个亚基拼装，功能是「网络的涌现性质」而不是「单个分子的性质」。

因此，蛋白质组学要回答的下一个问题是：**蛋白与蛋白之间谁和谁结合？** 酵母双杂交（yeast two-hybrid, Y2H）与亲和纯化-质谱（affinity purification-mass spectrometry, AP-MS）是两条最经典的答案：前者在活细胞里「配对」，后者把复合物「钓出来称重」。理解它们，就理解了互作组学的两大方法论支柱。

## 1 相互作用：从「清单」到「关系网」

**蛋白-蛋白相互作用（protein-protein interaction, PPI）** 指两个或多个蛋白通过非共价结合形成功能单位。PPI 是信号转导、转录调控、酶复合物、细胞骨架等几乎所有生物过程的执行方式。

测量 PPI 的方法按「证据的性质」分两大类：

- **遗传学方法**：把「相互作用」读成「基因产物之间的功能关联」——Y2H 是代表，酵母里两个融合蛋白若结合，就激活报告基因。
- **生物化学方法**：直接「抓住」物理结合的复合物再鉴定——AP-MS、免疫共沉淀（Co-IP）、交联质谱是代表。

两类方法互补：遗传学方法**高通量、能筛全基因组**，生物化学方法**直接、能反映真实复合物**。一张可靠的互作图，通常需要两类证据相互印证。

<span class="marginnote">记住两条路线的核心差别：<strong>Y2H 测的是「两个蛋白能不能结合」，AP-MS 测的是「一个蛋白被谁带着一起纯化下来」</strong>。前者是「一对一配对」，后者是「一对多整篮子」——它们回答的是不同层次的问题。</span>

## 2 酵母双杂交：在活细胞里「配对」

**酵母双杂交**由菲尔德斯与宋（Fields & Song）于 1989 年建立，核心思想是把「蛋白结合」翻译成「转录激活」。酵母转录因子 Gal4 可拆成两个功能域：**DNA 结合域（DNA-binding domain, BD）** 与**转录激活域（activation domain, AD）**，两者分开时不激活转录，靠近时恢复功能。

实验设计：

- **诱饵（bait）**：目标蛋白与 BD 融合，表达后结合到报告基因上游的 DNA 序列。
- **猎物（prey）**：候选蛋白与 AD 融合，在文库中随机表达。
- **若诱饵与猎物结合**：AD 被带到启动子附近，激活报告基因（如 LacZ 产蓝色、HIS3 在缺组氨酸培养基上长菌落），**「有相互作用」就在酵母表型上显形**。

Y2H 的优势在**规模化**：把全基因组文库做成猎物，一次杂交就能筛出与目标蛋白互作的全部候选——人类互作组的大规模图谱正是靠 Y2H 这类方法拼起来的。<span class="marginnote">Y2H 的两类经典误报值得警惕：<strong>自激活</strong>（诱饵自带转录激活能力，未结合也激活报告基因）与<strong>「粘」蛋白</strong>（疏水或高丰度蛋白非特异结合，谁都能搭）。验证 Y2H 结果几乎必须回做 Co-IP。</span>

## 3 亲和纯化-质谱：把复合物「钓」出来称重

**亲和纯化-质谱（AP-MS）** 走的是物理路线：给目标蛋白加一个**亲和标签**，用标签特异结合把「目标蛋白 + 它的结合伙伴」整个纯化下来，再用质谱鉴定纯化产物里的每一个蛋白。

- **标签选择**：FLAG、HA、Myc 是短肽表位标签（抗体亲和）；**链霉亲和素标签（Strep-tag）**与 **TAP（串联亲和纯化）**是双步纯化——TAP 用两次亲和（蛋白 A + 钙调素结合肽）串行，背景更低、纯度更高。
- **纯化流程**：表达标签融合蛋白 → 裂解 → 亲和珠结合 → 洗涤去杂 → 洗脱 → 酶解 → 质谱鉴定。与诱饵共纯化的蛋白，就是在细胞里与它结合的伙伴。
- **对照是关键**：用「空标签」或「无关诱饵」平行纯化，鉴定出的背景蛋白（热激蛋白、核糖体、细胞骨架等「粘手」蛋白）逐一扣除。

AP-MS 的优势是**反映天然复合物**：得到的不仅是「谁和谁结合」，还有**复合物组成与相对丰度**；结合质谱定量（如 SILAC、TMT 或 label-free），还能评估每个伙伴的相对化学计量。局限则是**瞬时或弱相互作用**在洗涤中容易丢失、膜蛋白与过度表达的人工结合是老大难。

## 4 核心要点对比：Y2H 与 AP-MS

本章为互作方法主题，以核心对比表收束两条路线：

| 维度 | 酵母双杂交（Y2H） | 亲和纯化-质谱（AP-MS） |
| --- | --- | --- |
| 原理 | 转录因子重装配激活报告基因 | 标签亲和纯化 + 质谱鉴定 |
| 环境 | 酵母细胞核（异源） | 天然细胞环境 |
| 检测对象 | 二元相互作用 | 复合物（多亚基） |
| 规模 | 可全基因组筛选 | 单诱饵一轮一篮 |
| 优点 | 高通量、能筛库 | 直接、反映真实复合物 |
| 局限 | 假阳性高、漏膜蛋白 | 漏瞬时互作、需对照扣除背景 |
| 典型产出 | 互作候选列表 | 复合物成员 + 相对丰度 |

一句话：**Y2H 是「撒大网筛候选」，AP-MS 是「精准钓复合物」**——前者用于发现，后者用于确认与细化，二者叠加才能得到可信的互作图。

## 5 公式解析：AP-MS 的富集比

AP-MS 结果筛选的最朴素指标是**富集比（enrichment ratio）**：某个蛋白在「诱饵纯化」里相对于「对照纯化」的丰度倍数：

$$R = \frac{A_{\text{bait}}}{A_{\text{control}}}$$

对这条式子做三步拆解：

- **第一步，认识 $A$**：$A_{\text{bait}}$ 与 $A_{\text{control}}$ 分别是该蛋白在诱饵纯化与对照纯化中的定量丰度（谱图计数或峰面积）。丰度来自质谱定量，因此 AP-MS 通常配 label-free 或标记定量来做「比值筛选」。
- **第二步，为什么能筛互作**：真正的结合伙伴在诱饵里被特异富集，$A_{\text{bait}}$ 远大于 $A_{\text{control}}$，$R$ 显著大于 1；而「粘」蛋白在两种纯化里都高，$R$ 接近 1，被滤掉。富集比因此是「特异结合 vs 背景结合」的直接判据。
- **第三步，怎么定阈值**：先看对照的波动，通常取 $R$ 高于对照分布（如对照均值 + 2–3 倍标准差）者入选；更严格的工具（如 SAINT）会用谱图计数建立贝叶斯概率而非简单比值。**比值阈值只是第一关，生物学重复与功能注释才是最终裁决**——富集比高的候选仍要逐一验证。

### 深入：互作数据的「可信度金字塔」

把 Y2H 与 AP-MS 的结果叠起来，互作证据是分层的——一张可信的互作图从不靠单条证据：

- **第一层，单一方法高通量命中**：Y2H 文库筛选或单次 AP-MS 给出的候选，可能混入大量假阳性——只配「候选」之名。
- **第二层，双方法/双实验验证**：同一个互作被两种方法（Y2H + Co-IP）或两个独立实验重复，可信度明显上升。
- **第三层，正交 + 功能证据**：加互作结构域共结晶、突变破坏互作、功能实验（敲低后表型改变）——这才接近「被证实」。

大规模互作组研究的教训由此而来：**酵母双杂交时代早期的人类互作图，不同团队之间重叠率低得惊人**，因为每家的假阳性集合各不相同。今天的主流做法是「证据打分」：给每条边标注来源方法、重复次数与置信度，用户只信高置信子图。<span class="marginnote">读互作文献的铁律：<strong>先看证据来自几种方法，再看置信度阈值</strong>——「一次 Y2H 命中」与「双方法 + 功能验证」的含金量差着几个数量级。把「候选」当「事实」是互作组学最常见的过度解读。</span>

### 延伸：从互作候选到通路——下游怎么用

拿到一篮子互作候选，科学的用法不是直接信，而是放进更大的坐标系：

- **去重与映射**：把不同方法、不同诱饵的结果统一 ID，合并去重——重复出现的互作更可能是真的。
- **网络化**：把「诱饵-猎物」对画成图，看候选是否聚成已知复合物或通路模块——若一个新候选落在已知「核糖体模块」里，可信度天然加分。
- **功能注释**：用 GO/通路数据库（KEGG、Reactome）看互作富集在哪些功能——这既是验证，也是「这篮子互作在生物学上意味着什么」的第一步回答。
- **交回实验**：挑 3–5 条最关键的候选，用 Co-IP、共定位（免疫荧光）独立验证——**验证是互作研究的句号，而不是起点**。

一句话：Y2H 与 AP-MS 产出的不是「结论」，而是「名单」；把名单变成结论，靠的是网络上下文与实验验证的接力。

### 延伸：互作组学的组学化方向

互作研究正从「单蛋白为中心」走向「全组学网络」：**大规模 Y2H 与 AP-MS 已拼出酵母、线虫、果蝇与人类的部分互作组**；配合结构生物学（AlphaFold 的互作预测）、交联质谱与空间邻近标记（BioID、APEX，靠近邻蛋白被标记「捕获」）——互作组学从「证明一条边」走向「画一整张图」。这一节的两件工具，正是理解这些现代图谱的起点。

## 6 小结

- PPI 测量分**遗传学（Y2H）**与**生物化学（AP-MS）**两类，证据互补、互相印证。
- **Y2H** 靠 Gal4 的 BD/AD 重装配激活报告基因：诱饵-猎物结合 → 表型显形，可全基因组筛库。
- Y2H 要防**自激活**与**粘蛋白**两类假阳性；结果需回做 Co-IP 验证。
- **AP-MS** 用亲和标签（FLAG、Strep、TAP）把复合物纯化下来，质谱鉴定成员并定量相对丰度。
- 富集比 $R = A_{\text{bait}}/A_{\text{control}}$ 区分特异结合与背景结合，阈值之上还要重复与功能验证。
- 互作证据分三层：**单方法候选 → 双方法验证 → 正交 + 功能证实**；读文献先看证据来源与置信度。
- 现代方向：**大规模互作组 + AlphaFold 预测 + BioID/APEX 邻近标记**，从「证明一条边」走向「画一整张图」。
