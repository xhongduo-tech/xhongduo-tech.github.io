# 蛋白质组学

蛋白质组学在基因组学之后系统研究细胞与组织中全部蛋白质的组成、结构、丰度、修饰与相互作用，是后基因组时代连接基因型与表型的核心组学，也是人类蛋白质组计划（HUPO）框架下的基础学科。对标权威教材体系，按章节逐节写成博文，学完一个学科 = 写完该学科权威教材对应的全部博文。

## 对标教材

- Timothy Palzkill, *Proteomics* (Kluwer Academic / Springer)
- R. M. Twyman, *Principles of Proteomics* (2nd ed., BIOS / CRC Press)
