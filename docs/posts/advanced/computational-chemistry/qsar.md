## 为什么从 QSAR 讲起

前两节的描述符与数据库，都是为了回答同一个问题：**分子的结构与它的活性/性质之间，能不能建立可预测的关系？** 这就是**定量构效关系（quantitative structure–activity relationship, QSAR）**——化学信息学最经典、也最具实用价值的建模范式。从 1960 年代的 Hansch 方程到今天的机器学习 QSAR，它的方法论骨架始终如一：**描述符做输入、性质做输出、统计模型做桥梁、严格的验证做裁判**。理解 QSAR，你就掌握了化学 ML 的通关文牒。

## 1 从 Hansch 方程到现代 QSAR

1964 年，Corwin Hansch 提出第一个 QSAR 方程：

$$
\log(1/C) = k_1 \log P + k_2 (\log P)^2 + \rho\sigma + \delta
$$

其中 $C$ 是活性浓度，$\log P$ 是脂水分配系数（疏水性），$\sigma$ 是 Hammett 电子常数（电子效应）。**这个方程体现了 QSAR 的永恒直觉：活性是疏水、电子、立体三类效应的加权和**。<span class="marginnote">Hansch 方程的奠基意义在于它把「结构-活性关系」从定性描述（SAR）升级为<strong>可定量预测的回归方程</strong>（QSAR）。它的现代后代就是你熟悉的 ML 模型：<strong>用 3 个物理描述符换成几百个描述符 + 随机森林/神经网络</strong>，本质不变——活性 = f(分子特征)。</span>

QSAR 的两种形态：

- **分类 QSAR**：活性/非活性（用 AUC、准确率评估），用于虚拟筛选初筛。
- **回归 QSAR**：预测连续值（pIC50、logP、溶解度），用于先导优化。

## 2 数据准备：QSAR 的成败关键

QSAR 建模的第一步不是调模型，而是**把数据整成可用形态**：

1. **活性标注**：从 ChEMBL 取 pIC50 等，统一实验来源、去重、处理多测量值。
2. **描述符计算**：2D 描述符 + 分子量 + logP + TPSA，或 ECFP 指纹。**描述符必须对训练集与测试集用同一管线计算**。
3. **数据集划分**：随机划分只是基线，更好的做法是**按骨架（scaffold）划分**——把化学结构相似的分子分进同一组，测试集包含训练集没见过的新骨架，才能评估真实外推能力。<span class="marginnote"><strong>随机划分会严重高估模型性能</strong>：因为同一化学系列里的相似分子共享活性趋势，模型在随机测试集上「捡漏」了记忆而非泛化。骨架划分（scaffold split）与时间划分（按实验年份）是检验真实泛化的两种主流方案——<strong>论文里不写划分方式的 QSAR，可信度要打折扣</strong>。</span>

## 3 建模与特征选择：从线性到非线性

经典路径：

- **线性模型**（Hansch 传统）：多元线性回归 + 逐步特征选择。可解释性强，但表达力有限。
- **树模型**：随机森林、梯度提升（GBDT）——对高维稀疏描述符稳健，是 QSAR 的实用主力。
- **神经网络**：DNN 直接吃描述符/指纹，能学复杂非线性关系，但小数据下易过拟合，需要正则化与交叉验证。

**特征选择**的核心矛盾：描述符动辄上千维，而活性数据常常只有几百到几千条。维度太高必然过拟合。常用策略：相关性过滤、方差过滤、L1 正则（套索）或直接靠树模型的特征重要性。<span class="marginnote">QSAR 的样本量天花板是硬约束：ChEMBL 里一个靶标有 10k 级活性数据已经是「大样本」，而描述符维度可能上千。<strong>降维不是可选项而是必需品</strong>。这也解释了为什么「机器学习比线性回归好」并不总是成立——数据少时，简单模型反而更稳。</span>

## 4 模型验证：QSAR 的科学底线

QSAR 最容易造假的地方不在建模，在**验证**。可靠验证的三件套：

- **交叉验证（CV）**：k-fold 交叉验证估计泛化误差。回归常用 $Q^2$（交叉验证 $R^2$），分类用 ROC-AUC。
- **外部测试集**：**独立于训练**的测试集（骨架划分），报告 $R_{\text{ext}}^2$。
- **适用域（applicability domain）**：模型只在其训练数据覆盖的化学空间内可信——预测新分子前要检查它是否落在适用域内。<span class="marginnote">QSAR 领域有一条著名的「经验铁律」：<strong>$Q^2$ 高并不代表预测准</strong>。1990 年代有人系统证明：对随机数据做多次交叉验证，也能得到很高的 $Q^2$。可靠性的真正判据是<strong>外部测试集表现 + 适用域定义 + 机制可解释性</strong>——三个一起看，缺一不可。</span>

## 5 公式解析：交叉验证的 $Q^2$

$Q^2$ 是 QSAR 报告里出现频率最高的数字，它的定义值得逐项拆解：

$$
Q^2 = 1 - \frac{\sum_{i}(y_i - \hat{y}_i^{(-i)})^2}{\sum_{i}(y_i - \bar{y})^2}
$$

- **第一步，认符号**：$y_i$ 是第 $i$ 个分子的真实活性；$\hat{y}_i^{(-i)}$ 是**把第 $i$ 个样本排除在训练之外**后模型的预测值（留一法或 k-fold）；$\bar{y}$ 是训练集活性均值。
- **第二步，看分子**：分子的平方误差是**预测误差**——注意预测来自「没见过 $i$ 的模型」，这是它与普通 $R^2$ 的本质区别。普通 $R^2$ 用训练集内预测，必然虚高。
- **第三步，看分母**：$\sum(y_i - \bar{y})^2$ 是「用均值做预测」的基准误差。$Q^2 = 1$ 表示完美预测，$Q^2 = 0$ 表示与均值预测一样差，$Q^2 < 0$ 表示**比均值还差**——模型在有系统地误导。
- **第四步，理解用途**：$Q^2$ 帮你**比较不同模型**（同一数据集上）与**判断过拟合**。但它只是内部验证，**最终判决必须靠外部测试集**——这条界线在 QSAR 论文评审里被反复强调。

## 6 QSAR 的现代形态：从描述符到图神经网络

- **经典 QSAR**：描述符 + 传统 ML，可解释、轻量、工业级成熟。
- **图神经网络 QSAR**：直接吃分子图，自动学习表征，不需要手工描述符——在大型活性数据集上往往超越经典 QSAR，但数据需求大、可解释性差。<span class="marginnote">经典 QSAR 与 GNN-QSAR 的关系不是取代而是互补：<strong>经典方法在小数据 + 高可解释性场景（如 ADMET 规则、专利检索）依然首选；GNN 在大数据 + 高精度场景（大规模虚拟筛选）更优</strong>。夹在中间的还有「描述符 + 深度学习」的混合路线，往往兼顾两者优点。</span>

## 7 QSAR 的回归指标详解

读 QSAR 论文，绕不开几个指标，逐个钉清：

- **$R^2$（训练决定系数）**：训练集内拟合优度。**$R^2$ 高不代表好**——过拟合模型能拿接近 1 的 $R^2$。
- **$Q^2$（交叉验证决定系数）**：留一法/k-fold 的预测决定系数，我们已在公式解析里拆过。经验上 $Q^2 > 0.5$ 常被当作「可接受的内部预测能力」，但这只是门票。
- **RMSE（均方根误差）**：预测与真实的平均偏差，单位与活性一致（如 log 单位）。**RMSE 比 $R^2$ 更直接**——它告诉你「平均错多少」。
- **$R_{\text{ext}}^2$（外部测试决定系数）**：在**独立测试集**上的表现，是泛化能力的最终判决。$Q^2$ 高而 $R_{\text{ext}}^2$ 低 = 内部拟合好但泛化差 = 白做。
- **分类模型用 ROC-AUC**：曲线下面积，0.5 是随机、1.0 是完美。<span class="marginnote">一条审稿铁律：<strong>只报 $R^2$ 与 $Q^2$、不报外部测试集 $R_{\text{ext}}^2$ 的 QSAR，几乎一定会被要求补充</strong>。因为 $Q^2$ 在过度拟合时也能虚高，而独立测试集是唯一诚实的泛化裁判。记住：RMSE 和 $R_{\text{ext}}^2$ 才是该先看的两个数。</span>

## 8 QSAR 的行业标准与监管现实

QSAR 不只是学术玩具，它是监管与工业里的正式工具：

- **OECD 原则**：经济合作与发展组织（OECD）给 QSAR 模型定了五条使用规范——明确终点、明确算法、定义适用域、足够验证、可机读规则。**满足 OECD 原则的模型才能在监管申报里被接受**。
- **监管应用**：REACH 法规允许在特定条件下用 QSAR 预测填补动物实验数据缺口——这是「计算替代实验」在立法层面的落地。
- **ADMET 建模**：溶解度、渗透性、代谢稳定性、hERG 心脏毒性等 QSAR/分类模型是药物研发管线里的常驻环节。
- **工业落地**：药企的 QSAR 平台把「数据 → 模型 → 预测 → 决策」做成自动化服务，服务虚拟筛选与先导优化。<span class="marginnote">QSAR 从「实验室论文」走向「监管工具」的关键就是 <strong>OECD 原则的适用域与验证要求</strong>——它把「模型能用」变成了「有证据、有边界、可审计地能用」。这给所有计算建模的启示：<strong>一个模型要被严肃使用，必须配齐「适用范围 + 验证证据 + 可重复的规则」三件套</strong>。</span>

## 9 QSAR 的局限与未来

- **局部性**：QSAR 是「插值工具」，只在其训练化学空间内可靠——跨化学类型外推是它最大的软肋。
- **活性悬崖**：结构微小变化导致活性剧变的「悬崖」，QSAR 几乎无法预测——这是由「结构-活性关系本质不连续」决定的，不是模型缺陷。
- **从 QSAR 到 QSPR**：把「活性（SAR）」推广到「任意性质（SPR）」——溶解度、毒性、反应性、材料性质，同一套方法论。
- **从 2D 到 3D + 动态**：3D-QSAR（CoMFA/CoMSIA）与构象集合结合，纳入「诱导契合」信息。
- **从描述符到表征学习**：图神经网络自动学表征，摆脱手工描述符——但代价是可解释性，以及「小数据下更易过拟合」。<span class="marginnote">QSAR 的终极局限是它的「经验本质」：<strong>它建立的是统计相关，不是因果机制</strong>。相关可能随化学空间漂移而失效。真正稳健的路线是「QSAR + 机理验证」双轮驱动：<strong>用机理理解约束 QSAR 的适用域，用 QSAR 反哺机理假设</strong>——这也是「计算化学从预测走向理解」的大方向。</span>

### 一句话记住 QSAR

**「描述符要可复现、验证要分内外、适用域要讲清」**。QSAR 的成败在数据与验证，不在模型复杂度——一个老老实实报告外部测试集与适用域的线性模型，比一个只报训练 $R^2$ 的神经网络可信得多。

**速记要点**：QSAR = 活性 = f(描述符)，从 Hansch 方程到 ML；数据准备是成败关键，骨架划分是严格测试；验证三件套 = $Q^2$ + 外部测试集 + 适用域；$Q^2$ 高不代表准；OECD 原则是监管使用的规范；QSAR 是插值工具、活性悬崖是本质局限。

## 10 小结

- QSAR 把「结构决定性质」写成可预测的方程：**活性 = f(描述符)**，从 Hansch 方程到 ML 一路演进。
- 数据准备是成败关键：统一活性标注、同一描述符管线、**骨架划分**测试集。
- 建模在「表达力 vs 过拟合」间权衡：数据少用线性/树模型，数据多再上 DNN/GNN。
- **验证是科学底线**：k-fold CV 的 $Q^2$ + 外部测试集 + 适用域，三者缺一不可；$Q^2$ 高不等于预测准。
- 现代 QSAR 从手工描述符走向图神经网络，经典与现代在数据规模与可解释性上互补。

在下一节，我们把 QSAR 的「预测活性」升级为「预测势能面」——**机器学习势函数**，看神经网络如何逼近量子化学的能量与力。
