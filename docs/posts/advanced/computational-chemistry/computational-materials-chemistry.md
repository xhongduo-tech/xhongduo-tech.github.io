## 为什么从材料计算讲起

材料科学与分子化学的不同在于**周期性**：一块晶体是原胞在三维空间的无穷重复。计算化学处理周期性体系靠的是**平面波 DFT + 周期性边界**——这套组合在半导体、电池、催化剂、二维材料的研究里是绝对主力。更激动人心的是，**高通量计算 + 机器学习**正在把「试材料」从实验台的偶然变成数据库的扫描。这一节讲清材料计算的物理概念（能带、形成能）、方法要点与数据驱动的范式转移。

## 1 周期性体系与布洛赫定理

晶体中电子感受到的是**周期性势场**：$V(\mathbf{r} + \mathbf{R}) = V(\mathbf{r})$（$\mathbf{R}$ 是晶格矢量）。**布洛赫定理**说：这样的体系里，电子波函数可以写成平面波与周期函数的乘积

$$
\psi_k(\mathbf{r}) = e^{i\mathbf{k}\cdot\mathbf{r}} u_k(\mathbf{r})
$$

其中 $\mathbf{k}$ 是晶体动量（倒空间矢量），$u_k(\mathbf{r})$ 是周期函数。**这个定理把「无穷个原子的波函数」约化成「一个原胞内、对每个 $\mathbf{k}$ 求解」**——周期性让无限体系变成了可计算体系。<span class="marginnote">$\mathbf{k}$ 点的重要性：体系的基态性质要对倒空间（布里渊区）里的所有 $\mathbf{k}$ 积分。数值上只能在<strong>离散的 $\mathbf{k}$ 网格</strong>（Monkhorst–Pack 网格）上采样。<strong>绝缘体用稀疏 $\mathbf{k}$ 网格即可，金属需要很密的网格</strong>（费米面附近的态密度急剧变化）——$\mathbf{k}$ 网格收敛测试是每个固体计算的必修课。</span>

## 2 平面波基组与赝势：处理内层电子

材料体系动辄上百个原子，且周期边界让「每个原子的基函数」定义变得复杂。主流方案是**平面波基组 + 赝势**：

**平面波基组**：用平面波 $e^{i\mathbf{G}\cdot\mathbf{r}}$ 展开 $u_k$，截断动能 $E_{\text{cut}}$ 控制基组大小。**平面波基组与原子位置无关、完全系统收敛**（调 $E_{\text{cut}}$ 即可逼近基组极限），这是它胜过局域基组的最大优点。
**赝势（pseudopotential）**：内层电子（芯态）在化学成键中几乎不参与，用光滑的赝势**替换**内层电子 + 核的陡峭势，只显式处理价电子。**PAW 方法**（投影缀加平面波）在赝势的框架里保留了全电子精度，是现代标准。<span class="marginnote">为什么不直接用全电子方法？因为芯态波函数在核附近剧烈振荡，需要极高截断能的平面波才描述得了。<strong>赝势/PAW 的「软化」让平面波基组可负担，代价是转移了误差：不同赝势的精度与可移植性不同</strong>。VASP、Quantum ESPRESSO 都内置验证过的赝势库，但换赝势需重做收敛测试。</span>

## 3 材料性质的计算：能带、形成能与缺陷

周期性 DFT 能产出的核心性质：

**能带结构与带隙**：沿布里渊区高对称线画出 $\varepsilon(\mathbf{k})$，给出带隙（导体/半导体/绝缘体的判据）、有效质量、态密度。**DFT 的带隙系统性低估**（LDA/GGA 约低估 30–50%），需用杂化泛函（HSE）或 GW 修正——这是材料计算最大的「已知陷阱」之一。<span class="marginnote">带隙低估的本质：交换-相关泛函对「准粒子自能」的描述不准确。<strong>LDA/GGA 算出的带隙是「Kohn–Sham 能隙」，不是「真正的光学带隙」</strong>。如果论文里的带隙没有标注方法，先别信——HSE06 或 GW 才算准。这个坑每年坑掉无数初学材料计算的文献读者。</span>
**形成能与相稳定性**：$\Delta H_f = E_{\text{化合物}} - \sum n_i E_{\text{单质}}$，判断化合物是否热力学稳定、比较竞争相。**凸包（convex hull）分析**从一批化合物的形成能画出「相图骨架」，距离凸包的距离（hull distance）衡量亚稳程度。
**缺陷与掺杂**：空位、间隙、替位缺陷的形成能与迁移能垒，决定材料的导电性、发光、催化活性。<span class="marginnote">缺陷计算有个经典陷阱：<strong>在有限超胞里算缺陷，缺陷的周期性镜像会互相作用</strong>。修正方法（如 Freysoldt 校正、大超胞外推）是缺陷研究的标准流程。缺陷化学是半导体物理与电池材料的核心，也是《凝聚态物理》一节的天然接口。</span>

## 4 公式解析：形成能

形成能是材料计算最基础的判据，拆解如下：

$$
\Delta H_f(A_a B_b) = E_{\text{tot}}(A_a B_b) - a E_{\text{tot}}(A) - b E_{\text{tot}}(B)
$$

- **第一步，认符号**：$E_{\text{tot}}(A_a B_b)$ 是化合物原胞总能量；$E_{\text{tot}}(A)$、$E_{\text{tot}}(B)$ 是**参考态**（元素单质或标准态）每原子的能量；$a$、$b$ 是原胞中的原子数。
- **第二步，看定义**：形成能 = 化合物能量 − 各元素参考态能量之和。**负值表示化合物比纯元素更稳定**（放热形成），越负越稳定。
- **第三步，注意参考态**：参考态的选择会**直接改变数值**——用金属镍单质还是气体 Ni 原子做参考，结果差一个升华能。**同一材料系统的形成能对比必须在同一参考态下进行**。
- **第四步，连接凸包**：把所有化合物画成「组成 → 形成能」的散点，**下包络线就是凸包**；落在凸包上的相是热力学稳定相，凸包上方的相是亚稳相。**凸包距离是材料发现的筛选标准**——它把「这个材料能不能做出来」量化成了可计算的数。

## 5 高通量与机器学习：材料发现的范式转移

- **高通量计算（high-throughput DFT）**：对成千上万个候选结构自动跑 DFT，产出标准化的性质数据库。Materials Project（~15 万+ 材料）、OQMD、AFLOW 都是这样的「材料百科全书」。
- **机器学习加速**：用数据库训练 ML 势或性质预测器，把 DFT 的「一次算一个」变成「一次扫一片」。**图神经网络 + 等变网络**（见《机器学习势函数》）是主流架构。<span class="marginnote">高通量 + ML 的范式意义：材料发现从「灵感 + 实验」走向「<strong>数据驱动筛选</strong>」。但两个陷阱要警惕：<strong>① 高通量数据全是 DFT 级精度，误差会进入所有下游结论；② ML 模型外推到训练集外的化学空间不可靠</strong>。高通量筛选出的「候选」，最终仍需实验或高精度计算验证。</span>
**逆向设计**：给定目标性质（如大带隙、低形成能），用生成模型（见《分子生成》）在晶体空间里搜索候选结构。

## 6 结构预测与晶体搜索：从组成到结构

材料性质依赖结构，但很多时候**我们不知道晶体长什么样**——这就是结构预测的用武之地：

**晶体结构预测（CSP）**：从化学组成出发，搜索可能的晶体堆积方式（空间群 + 原胞内坐标），排序形成能/自由能，预测最稳定的晶型。
**全局搜索算法**：进化算法、随机采样、粒子群——在结构空间中找能量最低点，避免落入局部极小。
**AI 辅助**：大模型时代的结构生成器（如基于扩散的晶体生成）正在加速这一搜索——从「枚举 + DFT」走向「生成 + 快速评估」。
**应用场景**：药物多晶型（不同晶型溶解度、生物利用度不同）、新材料的未知相、高压相预测。<span class="marginnote">结构预测的难点在<strong>「能量差极小」</strong>：不同晶型的形成能差常在 1–10 meV/atom，而 DFT 的误差就达这个量级——所以「预测最稳定晶型」常常比「预测存在哪些晶型」更难。<strong>结构预测的结论必须带误差意识</strong>：排第一的不一定真的最稳定，但「候选集合」本身是极有价值的实验起点。</span>

## 7 从计算到实验：验证闭环

计算材料学最怕「算完就结束」——可靠的材料研究走「计算-实验闭环」：

**可验证的预言**：计算给出「某材料应有某性质」（带隙、磁性、超导转变温度），实验去测。预言被证实 → 计算可信；不符 → 找原因（方法误差？合成的是不同相？）。
**合成可行性**：凸包距离判据预测「能否合成」（太亚稳 = 难合成）；实验合成产物与预测结构比对（XRD 谱图对比）。
**性质对标**：计算谱（吸收、发射、振动、XRD）与实验谱对账，确认「算的就是测的」。
**迭代修正**：实验发现的新相/新性质回填数据库，训练下一代模型。<span class="marginnote">计算-实验闭环里，<strong>XRD 谱图对账是最常用也最有力的验证</strong>：计算结构 → 模拟 XRD → 与实测 XRD 比峰位与强度，几乎「一锤定音」。这也解释了为什么材料计算论文常以「结构解析」而非「性质预测」开头——<strong>先证明「算的结构对了」，后面算的性质才有资格被信</strong>。</span>

## 8 声子与晶格动力学：把热力学算进材料

材料的稳定性与热力学性质不只是电子结构的事，还取决于**晶格振动（声子）**：

**声子谱**：对优化后的晶体算 Hessian（力常数矩阵），对角化得到振动频率 $\omega(\mathbf{q})$——这就是声子色散关系，包含材料的动力学稳定性信息。
**动力学稳定性**：若声子谱出现**虚频**（$\omega^2 < 0$），说明该结构在振动下不稳定，会自发弛豫到别的相——**这是「算出的稳定结构」是否真稳定的第二道检查**（第一道是凸包热力学稳定性）。
**热力学修正**：声子频率给出零点能、振动熵、热容，把 0 K 的 DFT 总能修正到有限温度的自由能——**这是预测相变温度、熔点的基础**。<span class="marginnote">「热力学稳定」与「动力学稳定」是两个不同的判据：<strong>凸包上（热力学稳定）但声子有虚频（动力学不稳定）的结构，会在振动中塌掉</strong>。反之，凸包上方一点但动力学稳定的结构，可能是可合成的亚稳相（如金刚石相对石墨亚稳，但室温下亿年不变）。材料研究的完整证据链 = 凸包 + 声子谱 + 合成实验。</span>

### 一句话记住材料计算化学

**「能带看方法、凸包判稳定、声子验动力学、谱图对账终审」**。材料计算的四条纪律：带隙必须标注方法（LDA 低估、HSE/GW 为准），稳定性用凸包距离判断，动力学稳定性查声子虚频，最后用计算 vs 实测 XRD 谱图对账——四条走完，材料结论才站得住。

**速记要点**：
- 布洛赫定理把无限晶体约化成原胞内 $\mathbf{k}$ 采样。
- 平面波 + 赝势/PAW 是标准组合。
- 带隙必须标方法（LDA 低估，HSE/GW 为准）。
- 凸包距离判热力学稳定性；声子虚频验动力学稳定性。
- 高通量 + ML 加速筛选，但受 DFT 精度与外推上限约束。
- 计算 vs 实测谱图对账是结构判定的终审。

**拓展思考**：材料计算的「计算-实验闭环」有一个独特之处——**计算往往跑在实验前面**：先算出一个新相的稳定性与性质，再按计算预言去合成。这是「计算指导合成」的范式，比「合成后再解释」先进一个时代。但要记住：**计算的预言必须有可证伪性**——它必须具体到「这个材料应该有 X 性质、晶体参数约为 Y」，否则无法被实验检验。

**本节启下**：材料计算的每个概念——能带、凸包、声子、缺陷——都与《凝聚态物理》一节的物理图像一一对应。想深入材料电子结构的物理本质，那里是你的下一站。

**一句提醒**：材料计算最贵的是「从头开始算一个新结构」——善用数据库与机器学习预训练模型，可以让你站在前人的肩膀上出发，而不是每次从零算起。

**一句忠告**：材料领域从不缺「计算出的漂亮结构」，缺的是「经得起谱图对账与实验合成检验的结论」——**让计算结论接受实验检验，是材料计算从论文走向应用的最后一道关**。

## 9 小结

- 材料计算的核心是**周期性 + 平面波 DFT**：布洛赫定理把无限晶体的电子结构约化成原胞内对 $\mathbf{k}$ 求解。
- 平面波基组系统可收敛（调 $E_{\text{cut}}$），**赝势/PAW** 处理内层电子，是主流标准。
- 核心性质：能带/带隙（**DFT 带隙系统性低估**，需杂化或 GW）、形成能（凸包分析）、缺陷与掺杂。
- 形成能 = 化合物能量 − 参考态能量和，**参考态必须统一**；凸包距离是稳定性筛选标准。
- **高通量 + 机器学习**正把材料发现推向数据驱动，但 DFT 精度上限与 ML 外推风险需时刻警惕。
