## 为什么从量子比特开始

从「从极限到大模型」一路走过来，我们打磨了复数、内积、算符、谱分解、张量积、测量公设、密度算符、Schmidt 分解——**工具箱已经齐了**。今天第一次把它们套在一个具体的物理对象上：**量子比特（qubit）**。

前面的工作是「语言的语法」，量子比特是「第一个说出来的句子」。它是量子信息的原子：量子线路的一根线、量子算法里的一个寄存器、量子密钥里的一次收发，全都是量子比特。理解 $|0\rangle$、$|1\rangle$ 与叠加，等于理解整个量子计算的「最小呼吸」——之后所有惊心动魄的算法，不过是成千上万个这样的最小呼吸按规则编排。

## 1 从经典比特到量子比特

经典计算机的信息单位是**比特（bit）**：一个只有两种取值（0 或 1）的物理系统——电压的高与低、磁畴的上下。量子计算机的信息单位叫**量子比特（quantum bit / qubit）**：一个**二维量子系统**。它的两个特殊状态是

$$
|0\rangle = \begin{pmatrix}1\\0\end{pmatrix}, \qquad |1\rangle = \begin{pmatrix}0\\1\end{pmatrix}
$$

它们构成 $\mathbb{C}^2$ 的一组标准正交基，叫**计算基（computational basis）**。与经典比特的根本不同在于：**量子比特不必是二者之一**，它可以是两者的**复线性组合**：

$$
|\psi\rangle = \alpha\,|0\rangle + \beta\,|1\rangle, \qquad \alpha, \beta \in \mathbb{C}, \quad |\alpha|^2 + |\beta|^2 = 1
$$

$\alpha, \beta$ 叫**概率振幅（probability amplitude）**，它们的模平方给出测量概率（玻恩定则）。归一化条件 $|\alpha|^2 + |\beta|^2 = 1$ 保证「测到 0 或测到 1」的总概率是 1。<span class="marginnote">量子比特是「两能级系统」的抽象：电子的自旋（上/下）、光子的偏振（水平/竖直）、原子的基态/激发态，物理上五花八门，数学上全是同一个 $\mathbb{C}^2$。这就是为什么量子信息能无视具体硬件谈论「量子比特」——第九篇《量子比特的物理实现》会讲这些真实的载体。</span>

**辨析｜易错点：** $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ 不是「有 $|\alpha|^2$ 的概率是 0、$|\beta|^2$ 的概率是 1」——那是**混合态**的语言（见《密度算符》）。一个处于叠加态的量子比特是**确定地**处于这个叠加里，两个振幅**同时**存在、彼此相干。测量之前问「它到底是 0 还是 1」不是一个有意义的物理问题；测量那一刻，概率才从振幅的模平方里涌现出来。

## 2 叠加态：两个世界并存

**叠加原理（superposition principle）**说的是：态空间是矢量空间，所以任意两个合法态的复线性组合仍是合法态。对量子比特，这意味着一个量子比特的「状态集合」不是两个点，而是一个**连续的球面**——后面布洛赫球一节会看到。

叠加的威力要用「并存」而不是「混合」来理解。量子比特处于 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ 时，它同时「携带」两个计算基分量的信息；而量子门是线性算符，会**同时作用于两个分量**。这就是《为什么更快》那篇里「量子并行」的微缩版：一次操作，处理两个「路径」的信息。

但叠加本身不是加速的关键，**干涉（interference）才是**。振幅可以相加或相消——同向的加强、反向的抵消——于是不同路径的概率会发生经典的「和」不会出现的调制。我们会在公式解析一节亲眼看到一次干涉。

## 3 相位：看不见却最关键的自由度

一个复数振幅可以写成「模长 × 相位」：$\alpha = |\alpha|e^{i\phi_\alpha}$，$\beta = |\beta|e^{i\phi_\beta}$。把它们都提出来：

$$
|\psi\rangle = e^{i\phi_\alpha}\Big(|\alpha|\,|0\rangle + |\beta|\,e^{i(\phi_\beta - \phi_\alpha)}|1\rangle\Big)
$$

前一个因子 $e^{i\phi_\alpha}$ 是**全局相位（global phase）**，它只是给整个态戴了一顶模长为 1 的帽子。**全局相位没有任何可观测后果**——任何测量概率 $|\langle m|\psi\rangle|^2$ 都含 $|e^{i\phi_\alpha}|^2 = 1$，被整体约掉；它等于给态矢量「转了同一把钥匙」却不改变锁。

真正有意义的是**相对相位（relative phase）** $\phi = \phi_\beta - \phi_\alpha$。两个态

$$
|+\rangle = \frac{|0\rangle + |1\rangle}{\sqrt2}, \qquad |-\rangle = \frac{|0\rangle - |1\rangle}{\sqrt2}
$$

在计算基下测量，都是各 1/2 的概率，**看起来一模一样**；但在 $X$ 基下，$|+\rangle$ 永远给出 $+$，$|-\rangle$ 永远给出 $-$——相对相位 $\phi = 0$ 与 $\phi = \pi$ 的差别是物理上真实的。<span class="marginnote">相对相位相当于「两条路之间的光程差」。杨氏双缝实验里，改变某条缝的光程就会移动干涉条纹——量子比特的相对相位就是这条「光程差」，只是它藏在复数里，肉眼看不见、却能用合适的测量暴露出来。第二级《光学》里双缝干涉的一切直觉，在这里都是字面意义的正确。</span>

**重点：** 一个量子比特的「信息内容」不是两个实数（$|\alpha|,|\beta|$），而是**三个**——$|\alpha|,|\beta|$ 加上相对相位 $\phi$（受 $|\alpha|^2+|\beta|^2=1$ 约束，剩三个独立实数）。正是这多出来的相位自由度，给了量子计算超越经典比特的余地。

## 4 布洛赫球：一个量子比特的全部几何

去掉全局相位后，任意量子比特可以唯一地参数化为两个实角：

$$
|\psi\rangle = \cos\frac{\theta}{2}\,|0\rangle + e^{i\phi}\sin\frac{\theta}{2}\,|1\rangle, \qquad 0 \leq \theta \leq \pi, \quad 0 \leq \phi < 2\pi
$$

**为什么是 $\theta/2$？** 因为我们要让 $|0\rangle$ 与 $|1\rangle$ 变成球上的**对跖点**（南北极）：$\theta = 0$ 给出 $\cos 0\,|0\rangle = |0\rangle$（北极），$\theta = \pi$ 给出 $\sin\frac{\pi}{2}|1\rangle = |1\rangle$（南极）。若用 $\theta$ 而非 $\theta/2$，$|1\rangle$ 会落在「赤道」而不是南极——用 $\theta/2$ 恰好把「比例」与「球面纬度」对齐。

于是每个量子比特态对应单位球面（半径 1）上的一点：$\theta$ 是极角（决定 $|0\rangle/|1\rangle$ 的比例），$\phi$ 是方位角（决定相对相位）。这个球叫**布洛赫球（Bloch sphere）**，它以物理学家费利克斯 · 布洛赫（Felix Bloch）命名。

![布洛赫球上的量子比特](/images/quantum-computing/qubit-superposition-1.svg)

**重点：** 布洛赫球上**每个点**都是一个合法的量子比特态；$|0\rangle,|1\rangle,|+\rangle,|-\rangle$ 只是几个地标（极与赤道）。单比特的量子门（下一篇的主题）在球面上就是**旋转**——这也是为什么「量子门」听起来玄乎，其实是球面的刚体运动。注意布洛赫球是**实**几何，却编码了**复**信息：因为全局相位已经被约定好「不看」，球面少了一个维度，才刚好是二维。<span class="marginnote">布洛赫球只对单个量子比特成立。两个及以上量子比特的态空间是 $\mathbb{C}^{2^n}$，维数随 n 指数爆炸，任何球面都装不下——「球」的直觉在多数比特时自动失效，这正是纠缠的世界。</span>

## 5 测量：量子比特的终结与新生

叠加态到底怎么变回经典数据？对计算基 $\{|0\rangle,|1\rangle\}$ 做投影测量（见《投影测量与广义测量》），规则是玻恩定则：

$$
p(0) = |\alpha|^2, \qquad p(1) = |\beta|^2
$$

测得 0 后，态**塌缩**到 $|0\rangle$；测得 1 后塌缩到 $|1\rangle$。此后立即再测一次，结果必然与第一次相同——因为已经是基态，没有了不确定性。

测量有两个不可逆的后果，必须刻进直觉。第一，**振幅的信息被丢弃**：测得 0 后，$|\beta|^2$ 那份概率连同相对相位一起消失，我们再也无法从态里还原出 $|\alpha|^2,|\beta|^2,\phi$ 三个数。第二，**测量是一次「抽样」而非「探测」**：它不告诉你「态本来是啥」，只给你一次按概率抽签的结果——想知道概率，就得制备许多个相同的态、测许多次、数频率。**这就是量子计算输出端的设计逻辑**：算法必须在测量前把「想要的答案」变成几乎确定的高概率，而不是寄希望于运气。

用 Qiskit 可以直观看到抽样的统计性：

```python
from qiskit import QuantumCircuit, Aer, execute

qc = QuantumCircuit(1)
qc.h(0)                       # |0> -> (|0> + |1>)/√2，α = β = 1/√2
qc.measure_all()
counts = execute(qc, Aer.get_backend('qasm_simulator'), shots=1024).result().get_counts()
print(counts)                 # 大约 {'0': ~512, '1': ~512}，每次运行略有起伏
```

## 6 公式解析：干涉是量子计算的心跳

叠加如果没有干涉，只是「两路并行的经典概率」；有了干涉，才出现经典世界不存在的调制。用 Hadamard 门 $H$（下一篇的主角）看一次完整的干涉。$H$ 的定义是

$$
H = \frac1{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}, \qquad
H|0\rangle = \frac{|0\rangle+|1\rangle}{\sqrt2} = |+\rangle, \qquad
H|1\rangle = \frac{|0\rangle-|1\rangle}{\sqrt2} = |-\rangle
$$

- **第一步，先叠加**：$H|0\rangle = |+\rangle$，一个「两头各半」的叠加态。
- **第二步，再干涉**：对 $|+\rangle$ 再施加一次 $H$。$H$ 是线性的，作用于两个分量之和等于分别作用再相加：

$$
H|+\rangle = \frac1{\sqrt2}\Big(H|0\rangle + H|1\rangle\Big)
= \frac1{\sqrt2}\Big(|+\rangle + |-\rangle\Big)
$$

- **第三步，展开与相消**：代入 $|+\rangle, |-\rangle$ 的显式：

$$
H|+\rangle = \frac1{\sqrt2}\left(\frac{|0\rangle+|1\rangle}{\sqrt2} + \frac{|0\rangle-|1\rangle}{\sqrt2}\right)
= \frac12\Big(|0\rangle + |1\rangle + |0\rangle - |1\rangle\Big) = |0\rangle
$$

**看中间那步：$|1\rangle$ 出现了两次，一次 +1/2、一次 −1/2，恰好抵消；$|0\rangle$ 两次同号，叠加成 1。** 这就是干涉：振幅相加时携带符号，符号相反则相消。如果走的是「概率相加」的经典路，$|1\rangle$ 的概率会是 $1/2 + 1/2 = 1$ 而不是 0——**量子计算里，两条路径不会白白并存，它们会在振幅层面谈判、妥协，最终决定输出的形状**。Grover 搜索的「振幅放大」、Shor 算法的「相位估计」，全部建立在同一种干涉机制上。

**辨析｜易错点：** 干涉发生在**振幅**层面，不是概率层面：$|a + b|^2 \neq |a|^2 + |b|^2$，多出来的交叉项 $2\mathrm{Re}(ab^*)$ 正是干涉项。一个叠加态的测量概率是「振幅和的模平方」，而不是「各分量概率之和」——忘记这一点，就会误以为 $|0\rangle + |1\rangle$ 与 $|0\rangle - |1\rangle$ 只是符号差别，忽略了它们干涉出的不同世界。

## 7 小结

- **量子比特**是二维量子系统：$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$，$|\alpha|^2 + |\beta|^2 = 1$；$\alpha, \beta$ 是复振幅，模平方是测量概率。
- **叠加 ≠ 混合**：叠加是相干地同时存在，混合是按概率分布「各是各」。
- **相位**：全局相位不可观测；**相对相位**是真实的物理自由度，$|+\rangle$ 与 $|-\rangle$ 用 $X$ 基可分辨。
- **布洛赫球**：$|\psi\rangle = \cos\frac{\theta}{2}|0\rangle + e^{i\phi}\sin\frac{\theta}{2}|1\rangle$，每个点一个态；单比特门 = 球面旋转。
- **测量**：按玻恩定则抽样并塌缩，信息不可逆丢失；算法必须在测量前把答案变成高概率。
- **干涉**是量子计算的心跳：振幅带符号相加，$H$ 两次作用让 $|1\rangle$ 相消、$|0\rangle$ 加强。

在下一节，我们把这颗球正式立起来：详细展开**布洛赫球**的坐标、地标与旋转——你会看到 $X, Y, Z$、Hadamard 与相位门，全都是这颗球上优雅的转动，而量子比特的「全部家当」已经浓缩在 $\theta$ 与 $\phi$ 两个角里。
