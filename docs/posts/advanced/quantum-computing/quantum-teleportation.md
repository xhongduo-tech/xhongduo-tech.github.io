## 为什么从量子隐形传态开始

上一篇结尾我们留下一个悬念：不可克隆定理禁止「复制」，那不可克隆定理允许什么呢？答案的第一半你已经见过——**转移**。量子隐形传态（quantum teleportation）就是「转移」最漂亮的一次演出：Alice 手里有一个**未知**的量子态 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$，她没有量子信道、甚至不知道这个态是什么，却能把 $|\psi\rangle$ 完整地「隔空」送到远处的 Bob 手里——传送的不是物质，不是能量，而是**态本身**，即那段信息（贝特森说的「差异」）。

这件事在经典世界里没有对应物。传真机传的是「形状」的扫描结果，原件的状态信息没有离开；而隐形传态是**原态被摧毁、异地重建**——这恰好避开了不可克隆定理：始终只有一份 $|\psi\rangle$ 存在。本篇会完整走一遍协议、把线路演算逐步拆解，然后回答两个尖锐的问题：它为什么不违反不可克隆定理？它为什么不违反「不能超光速」？<span class="marginnote">1993 年贝内特（Bennett）、布拉萨德（Brassard）、克雷波（Crépeau）、乔萨（Jozsa）、佩雷斯（Peres）与沃特斯（Wootters）在 PRL 发表《经由经典与 EPR 双信道隐形传态未知量子态》。注意开头的名字：正是不可克隆定理的作者沃特斯，又出现在这里——同一批人，同一个问题。</span>

## 1 问题设定：没有量子信道，怎么送未知态

先把「不可能」说清楚。Alice 想传给 Bob 一个未知态 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$。为什么不能直接发？两个障碍：

- **不能先测量再发**：测量会把 $|\psi\rangle$ 塌缩成 $|0\rangle$ 或 $|1\rangle$，$\alpha, \beta$ 的信息永远丢失。未知态只能被**演算**，不能被**读出**。
- **不能复制再发**：不可克隆定理禁止复制 $|\psi\rangle$ 一份留着、一份寄走。

看起来死路一条。但协议需要两样资源：一条**经典信道**（可以发比特，跑不赢光速）和一对**预先共享的贝尔态** $|\Phi^+\rangle = \frac{|00\rangle + |11\rangle}{\sqrt2}$——Alice 拿一个比特（记为 $A$），Bob 拿另一个（记为 $B$）。贝尔对是这对「隔空」的锚点：它不携带 $|\psi\rangle$ 的任何信息，却是重建 $|\psi\rangle$ 必需的量子资源。传态的代价是一比特纠缠 + 两个经典比特，换一个未知量子比特的转移。**协议的核心思想是：把未知态的信息「纠缠进」贝尔对，再靠两个经典比特把重建所需的「补丁」告诉 Bob。**

## 2 协议四步：从线路图看全景

先给出完整线路，再逐句解释每一步在干什么。

![量子隐形传态线路图：①制备贝尔对 ②Alice 用 CNOT 与 H 纠缠未知态 ③测量两个比特 ④Bob 依据经典比特施加 Z、X 校正门](/images/quantum-computing/quantum-teleportation-1.svg)

**第一步，制备共享贝尔对。** 在 $q_1, q_2$（分别属于 Alice 与 Bob）上先做 $H$、再做以 $q_1$ 为控制位、$q_2$ 为目标位的 CNOT，得到 $|\Phi^+\rangle$。这个态在 Alice 与 Bob 之间预先建立好——「共享」指双方各执一半，哪怕相隔几公里。

**第二步，Alice 把未知态纠缠进贝尔对。** 对 $q_0 = |\psi\rangle$ 与 $q_1$ 做 CNOT（控制位 $q_0$、目标位 $q_1$），再对 $q_0$ 做 $H$。这两下把 $|\psi\rangle$ 的 $\alpha, \beta$ 信息「摊开」到三比特的纠缠态里——现在信息不再只属于 $q_0$，而是分布在整个系统里。

**第三步，Alice 测量并读出两个经典比特。** 对 $q_0$ 与 $q_1$ 做计算基测量，得到 $c_0, c_1 \in \{0,1\}$。**关键性质：四个结果 $(00, 01, 10, 11)$ 等概率出现，各占 $1/4$。** 测量把三比特态「投影」到四个分支之一，同时 $|\psi\rangle$ 的原版被摧毁——这一刻就是「拆原件」。

**第四步，Bob 依据经典比特施加校正门。** Alice 把 $(c_0, c_1)$ 用经典信道发给 Bob（这一段以光速为上限，无法更快）。Bob 在自己的比特 $q_2$ 上按规则施加 $Z^{c_0} X^{c_1}$——即测到 01 就补一个 $X$，测到 10 就补一个 $Z$，测到 11 就 $Z$ 再 $X$，测到 00 什么都不用做。**校正之后，$q_2$ 上就精确躺着 $|\psi\rangle$。**

为什么恰好是这个校正规则？这是本篇的核心，下一节逐行推导。

## 3 公式解析：四步演算逐项拆解

把整个协议写成连续的状态演算。记号上，三比特态按 $(q_0, q_1, q_2)$ 排列，$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$。

**第一步，初态。**
$$
|\psi\rangle|0\rangle|0\rangle = (\alpha|0\rangle + \beta|1\rangle)|0\rangle|0\rangle
$$

**第二步，制备贝尔对**（对 $q_1$ 做 $H$，再 CNOT $q_1 \to q_2$）：
$$
\longrightarrow \frac{1}{\sqrt2}(\alpha|0\rangle + \beta|1\rangle)\,(|00\rangle + |11\rangle)_{q_1 q_2}
$$

**第三步，CNOT $q_0 \to q_1$。** 规则：当控制位 $q_0 = 1$ 时翻转目标位 $q_1$。逐项作用：
$$
\frac1{\sqrt2}\big[\alpha|000\rangle + \alpha|011\rangle + \beta|110\rangle + \beta|101\rangle\big]
$$
这里把交叉项仔细核对一遍：$\beta$ 分支里 $|100\rangle$ 变 $|110\rangle$、$|111\rangle$ 变 $|101\rangle$——因为 $q_0 = 1$ 把 $q_1$ 翻转了。<span class="marginnote">对比第二步与第三步的项数：第二步是「一个量子比特 $\times$ 贝尔对」，本质是两项；第三步展开后仍只有四项，但 $\beta$ 的项已经「钻」进了 $q_1$ 的位置——这就是把未知态与贝尔对纠缠起来的意思：$|\psi\rangle$ 的信息从 $q_0$ 一处扩散到了 $q_0$ 与 $q_1$ 的联合自由度里。</span>

**第四步，对 $q_0$ 做 $H$。** $H|0\rangle = \frac{|0\rangle+|1\rangle}{\sqrt2}$，$H|1\rangle = \frac{|0\rangle-|1\rangle}{\sqrt2}$，代入并展开成八项，再按「Alice 测到的 $(q_0,q_1)$」分组：

$$
\frac12\Big[\, \alpha|000\rangle + \alpha|100\rangle + \alpha|011\rangle + \alpha|111\rangle + \beta|010\rangle - \beta|110\rangle + \beta|001\rangle - \beta|101\rangle \,\Big]
$$

按 $(q_0, q_1)$ 归并后，$q_2$ 上的状态一目了然：

| Alice 测到 $(c_0,c_1)$ | 此时 $q_2$ 上的态 | Bob 应施加 | 结果 |
| :---: | :--- | :---: | :--- |
| $00$ | $|\psi\rangle$ | $I$ | $|\psi\rangle$ |
| $01$ | $X|\psi\rangle$ | $X$ | $|\psi\rangle$ |
| $10$ | $Z|\psi\rangle$ | $Z$ | $|\psi\rangle$ |
| $11$ | $XZ|\psi\rangle$ | $ZX$（先 $Z$ 后 $X$） | $|\psi\rangle$ |

**要点拆解：**

- **四项各占 $1/4$。** 因为 $|\alpha|^2 + |\beta|^2 = 1$，八个项中每组两项的模方和正好是 $\frac14$。于是 Alice 的测量结果**完全随机**，她无法通过测量「选择」哪个分支——这正是 no-signaling 的伏笔。
- **$q_2$ 的状态与 $\alpha, \beta$ 无关地悬着。** 只看 Bob 那一端、不拿到经典比特，$q_2$ 的约化密度算符是 $I/2$——完全混合态。信息不在 Bob 手里，也不在 Alice 手里，而在「测量结果 + 校正规则」的关联里。
- **四个「补丁」正好覆盖四种情况。** $X$ 交换 $\alpha \leftrightarrow \beta$，$Z$ 翻转 $\beta$ 的符号：$Z|\psi\rangle = \alpha|0\rangle - \beta|1\rangle$。每一种 Alice 可能测到的结果，都对应一个「把 $q_2$ 拨回 $|\psi\rangle$」的幺正门。

**辨析｜易错点：** 校正门的顺序是 $Z^{c_0}X^{c_1}$——先 $X$ 后 $Z$，不是先 $Z$ 后 $X$。因为测到 $11$ 时 $q_2$ 上是 $XZ|\psi\rangle$，需要乘以它的逆 $(XZ)^{-1} = Z^{-1}X^{-1} = ZX$（$X, Z$ 都是自逆的）。不过 $X$ 与 $Z$ 反交换：$ZX = -XZ$，差的只是一个全局相位 $-1$，物理上不可观测——所以两种顺序写出的**末态**完全等价，只是中间记号不同。初学时把顺序记成「$q_2$ 上是哪个门乘积，就反过来乘一遍」即可。

## 4 为什么这不违反不可克隆定理

这是读者最常问的问题：「把 $|\psi\rangle$ 传过去，不就是复制了一份吗？」答案藏在**原态的结局**里。

**传态摧毁原态。** 第三步 Alice 对 $q_0$ 的测量，把三比特态随机投影到四个分支之一。测量之后，$|\psi\rangle$ 的原始载体 $q_0$ 已经塌缩成确定的 $|0\rangle$ 或 $|1\rangle$，$\alpha, \beta$ 的量子信息从 $q_0$ 里被**彻底删掉**——它只以「经典结果 $(c_0,c_1)$ + 量子关联」的形式残留。所以整个过程始终只有**一份** $|\psi\rangle$：先在 $q_2$ 上悬着，再被校正出来。这与不可克隆定理的证明前提（两个副本同时存在）不冲突。<span class="marginnote">把传态想成「拆掉原件，把图纸寄过去重装」：图纸（两个经典比特）在路上，原件（$q_0$ 上的态）已经被测量毁掉；克隆则是「原件不动，另造一份」。差别就在测量那一脚——传态必然毁掉原态，克隆则要求保留原态。这也是上一篇《不可克隆定理》结尾埋的线。</span>

**传态不超光速。** 很多人听说「隔空传送」就想到瞬间移动。但协议里 Bob 要**先收到** $(c_0, c_1)$ 才能施加校正——这封信以光速为上限。在经典比特到达之前，Bob 手里的 $q_2$ 是 $I/2$，从中读不出任何信息。所以传态的速度上限是**经典信道的光速**，不违反相对论。

## 5 隐形传态的真正意义：信息与物质的分离

理解了协议，再看它为什么重要。传态传的不是**载体**，而是**状态**——$q_0$ 这个物理比特始终留在 Alice 身边，飞向 Bob 的只有经典比特；但「$|\psi\rangle$ 这个量子态」却完整地搬到了 Bob 的比特上。**这是「量子信息可以脱离其物理载体存在」的最直接证据。**

- **纠缠是消耗品。** 每传一个未知态，就**用掉**一对贝尔态。共享纠缠是一笔要预先储存的量子资源，传态不能凭空创造它——这呼应了「信息是物理的」：转移不是免费的。
- **量子中继与量子互联网。** 在长距离量子通信里，光子衰减是硬伤。把传态和「纠缠交换」（entanglement swapping）组合起来，可以让中继站不做测量、只做贝尔测量，把纠缠「接力」到更远——这是第十三篇《量子互联网与量子中继》的技术核心。
- **测量基元。** 传态中的贝尔测量（第四篇会系统化）与经典反馈，是很多量子纠错码和容错方案的标准构件。

**辨析｜易错点：** 隐形传态不是「传送物质或能量」，也不是「超光速通信」。它传送的是**量子信息**，且必须借道经典信道、必然消耗共享纠缠。好莱坞式的「瞬移一个人」超出了量子信息论的适用范围——因为把人当作量子态，其规模远超任何可想象的资源量级。

## 6 一个可运行的示例（Qiskit）

把协议放进代码，能看到每个测量结果对应的校正确实是自洽的。下面用 Qiskit 构造完整线路并验证：无论 Alice 测到哪个结果，Bob 校正后都能在 $q_2$ 上重建出输入态。

```python
from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister

qr = QuantumRegister(3, "q")          # q0 未知态, q1 Alice 半对, q2 Bob 半对
cr = ClassicalRegister(2, "c")        # 两个经典比特
qc = QuantumCircuit(qr, cr)

qc.h(1)                               # 第一步: 制备 |Φ+⟩
qc.cx(1, 2)
qc.cx(0, 1)                           # 第二步: 把 |ψ⟩ 纠缠进去
qc.h(0)
qc.measure([0, 1], [0, 1])            # 第三步: 测量 -> 经典比特
qc.z(2).c_if(cr, 2)                   # 若 c = 10, 施加 Z
qc.x(2).c_if(cr, 1)                   # 若 c = 01, 施加 X
qc.z(2).c_if(cr, 3)                   # 若 c = 11, 先 Z
qc.x(2).c_if(cr, 3)                   # 再 X
```

初学时不必纠结 API 细节——`c_if` 的意思是「当经典寄存器满足某值时施加该门」，正好对应表格里「Bob 应施加」那一列。这篇的目的不是写程序，而是把协议的逻辑链条看清楚。

## 7 小结

- **量子隐形传态**：用 1 对共享贝尔态 + 2 个经典比特，把一个**未知**量子态从 Alice 转移到 Bob，不移动任何物质、不超光速。
- 四步协议：制备贝尔对 → CNOT + H 把未知态纠缠进贝尔对 → 测量得 2 个经典比特 → Bob 施加 $Z^{c_0}X^{c_1}$ 校正。
- 四个测量结果等概率（各 $1/4$）；只看 Bob 一端，$q_2$ 是 $I/2$，经典比特没到就毫无信息。
- **不违反不可克隆定理**：测量摧毁原态，始终只有一份 $|\psi\rangle$。
- **不违反相对论**：校正依赖经典信道，速度上限是光速。
- 传态把**量子信息与其物理载体分离**，是量子中继、量子互联网与容错计算的共同基元。

在下一节，我们把同一个贝尔对反过来用：Alice 只发一个量子比特，Bob 却收到**两个**经典比特的信息——这就是与隐形传态互为镜像的**超密编码（superdense coding）**。你会发现两份协议共享同一套贝尔态工具箱，只是资源换了个方向。
