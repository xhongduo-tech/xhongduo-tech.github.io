## 为什么从查询复杂度开始

接下来几篇要讲的 Deutsch-Jozsa、Bernstein-Vazirani、Simon、Grover 算法，有一个共同结构：**问题被编码成一个黑盒（oracle），算法的好坏以「问黑盒多少次」来度量。** 这种度量就叫**查询复杂度（query complexity）**。它把「问题本身有多难」与「黑盒内部怎么实现」剥离，从而在经典与量子之间做最公平的比较——因为无论实现细节如何，一次「查询」就是一次标准操作。<span class="marginnote">查询复杂度是量子算法理论最成熟的部分：它让我们在还不清楚「量子门能多快」时，就能先回答「量子能少问多少次」。所有里程碑式的加速（Deutsch-Jozsa 指数、Grover 平方、Simon 指数）都是查询复杂度意义上的。</span>本节先把黑盒模型立起来。

这一节还为你铺垫一个重要区分：**查询复杂度回答「要问多少次」，线路复杂度回答「要花多少门」**。前者干净、可证下界，后者贴近工程。量子算法理论的大多数「加速」声明都在查询层面成立——这也是为什么必须先把「查询」这个单位定义清楚，后面的每一仗才有公平的标尺。

## 1 黑盒模型：查询是什么

**查询模型（query model）**：问题输入是一串 $N$ 个数据点，算法不能直接读数据，只能通过查询黑盒访问。在经典情形，一次查询把下标 $i$ 交给黑盒，返回 $f(i)$。在量子情形，查询变成**量子查询**：一个酉算符 $O_f$ 作用在「寄存器」上，可以同时查询多个下标。

量子查询的标准形式（对布尔函数 $f:\{0,1\}^n \to \{0,1\}$）是**相位查询**与**翻转查询**两种等价的实现：

$$
\text{相位查询：} \lvert x\rangle \to (-1)^{f(x)} \lvert x\rangle, \qquad \text{翻转查询：} \lvert x\rangle\lvert y\rangle \to \lvert x\rangle\lvert y \oplus f(x)\rangle
$$

相位查询只改变相位、不改变寄存器值；翻转查询把答案「异或」进一个辅助比特。<span class="marginnote">两者通过 Hadamard 技巧互相转换：把翻转查询的辅助比特制备成 $\lvert-\rangle = \frac{1}{\sqrt2}(\lvert0\rangle-\lvert1\rangle)$，翻转查询就等价于相位查询。所以分析时用哪种都行，教材常混用。</span>**一次量子查询可以对叠加态上所有下标同时作用**——这正是查询模型里量子优势的源头。

**辨析｜易错点：** 「一次量子查询同时查询所有下标」不等于「一次得到所有答案」。它得到的是「所有答案的相位叠加」——真正的答案要靠后续的干涉与测量才能读出。所以量子查询的优势不是「免费获得信息」，而是「把信息藏进相位，再用干涉放大」——信息论上并没有被绕过，而是被编码进了一种更有利于干涉的形式。

## 2 查询复杂度的定义

**量子查询复杂度 $Q(f)$**：计算函数 $f$ 所需的最少量子查询次数（对所有可能的量子算法取最小、对最坏输入取最大）。类似地，**经典查询复杂度** $R(f)$（随机化）与 $D(f)$（确定性）衡量经典算法的最少查询次数。<span class="marginnote">记号：$D(f)$ 确定性、$R(f)$ 随机化（错误概率 $\le 1/3$）、$Q(f)$ 量子（同样允许小错误）。三者都取「最坏输入 + 最优算法」。常见的关系：$Q(f) \le R(f) \le D(f)$，量子在查询上从不比经典更差——因为量子算法总能「退化成经典」。</span>

黑盒模型下有几个经典问题常被当作「加速的标尺」：

| 问题 | 输入 | 确定性 $D(f)$ | 量子 $Q(f)$ | 加速类型 |
| --- | --- | --- | --- | --- |
| Deutsch 问题 | $f:\{0,1\}\to\{0,1\}$ | 2 | 1 | 常数倍 |
| Deutsch-Jozsa | $f:\{0,1\}^n$ 平衡或常数 | $2^{n-1}+1$ | 1 | **指数** |
| Bernstein-Vazirani | 隐藏比特串 $s$ | $n$ | 1 | **线性**（非指数） |
| Simon | 周期 $s$ | $O(2^{n/2})$ | $O(n)$ | **指数** |
| Grover | 无结构搜索 | $N$ | $\sqrt{N}$ | 平方 |

Deutsch-Jozsa 与 Simon 是「指数级量子优势」在查询模型里最早的两个证明——它们不需要大数分解，结构简单、可验证，是理解量子并行与干涉如何换加速的理想教材。

## 3 公式解析：翻转查询为什么等价于相位查询

这是查询模型里最常用的一个代数操作。设辅助比特为 $\lvert-\rangle$：

$$
O_f(\lvert x\rangle \lvert-\rangle) = \lvert x\rangle \frac{\lvert 0 \oplus f(x)\rangle - \lvert 1 \oplus f(x)\rangle}{\sqrt2}
$$

- **第一步，作用翻转查询**：目标比特与 $f(x)$ 异或。若 $f(x)=0$，目标比特不变；若 $f(x)=1$，目标比特翻转。
- **第二步，看符号变化**：$f(x)=0$ 时结果是 $\lvert x\rangle\lvert-\rangle$；$f(x)=1$ 时结果是 $\lvert x\rangle\frac{\lvert1\rangle-\lvert0\rangle}{\sqrt2} = -\lvert x\rangle\lvert-\rangle$——多了一个负号。
- **第三步，提取全局相位**：把负号提出来，写成 $(-1)^{f(x)}\lvert x\rangle\lvert-\rangle$。辅助比特一直是 $\lvert-\rangle$，可以忽略，等价于对寄存器作用相位查询。<span class="marginnote">这个「把答案藏进相位」的技巧是全篇主旋律：Deutsch-Jozsa、Simon、Grover 的 oracle 全部先把答案编码进相位，再用干涉把相位差放大成可测的概率差。量子算法的「魔法」一大半在这里。</span>

## 4 为什么查询模型如此有效

查询模型之所以成为量子算法理论的主战场，有三个原因：

**它避开实现细节**：在还不知道量子门可靠实现前，就能推导「下界」——任何算法至少要问多少次，无论门多完美。
**它给出清晰的下界工具**：多项式方法、adversary 方法（Ambainis）、谱方法等经典技术，都能在查询模型里证明量子下界，而线路复杂度下界至今难如登天。<span class="marginnote">对 Grover 问题 $Q(f) = \Omega(\sqrt{N})$ 的下界，正是用 adversary 方法或多项式方法证明的——第七篇会专门讲「$\sqrt{N}$ 是最优的」为什么成立。</span>
- **它可直接迁移**：许多「查询加速」能通过适当编码，升级成「时间加速」的真实算法。

**辨析｜易错点：** 查询复杂度**不是**线路复杂度。查询复杂度只数「问 oracle 的次数」，不数 oracle 内部的代价，也不数 oracle 之外的门。一个「$Q(f)=1$ 的算法」若 oracle 本身极贵，总时间照样可以很大（这正是 Shor 里模幂 oracle 的处境）。比较两类算法时，务必说明比的是查询、时间还是线路。

## 5 常见误区与自查练习

| 误区 | 事实 |
| --- | --- |
| 「一次量子查询 = 免费读所有答案」 | 得到的是相位叠加，答案要靠干涉与测量才能读出 |
| 「查询复杂度 = 线路复杂度」 | 前者只数 oracle 调用，不数内部代价；两者必须区分 |
| 「量子查询总是更快」 | $Q(f)\le R(f)\le D(f)$，量子从不更差，但加速幅度因问题而异 |
| 「下界是小事」 | 下界（如 $\Omega(\sqrt N)$）是「最优性」的另一半，没有下界就没有「最优」 |

**自查问题**：

1. 相位查询与翻转查询如何互相转换？——用 $\lvert-\rangle$ 辅助比特，把「翻转」变成「相位」。
2. 五个标杆问题的加速类型各是什么？——Deutsch-Jozsa/Simon 指数、Grover 平方、BV 线性、Deutsch 常数。
3. 为什么查询模型能证下界而线路模型难？——查询模型信息结构清晰，有多项式/adversary/谱三类成熟工具。
4. 查询加速何时能升级成时间加速？——当 oracle 本身实现得足够便宜时。

## 6 术语速查表

| 术语 | 含义 |
| --- | --- |
| 黑盒 / oracle | 隐藏问题输入的查询接口 |
| 相位查询 | $\lvert x\rangle\to(-1)^{f(x)}\lvert x\rangle$，把答案编进相位 |
| 翻转查询 | $\lvert x\rangle\lvert y\rangle\to\lvert x\rangle\lvert y\oplus f(x)\rangle$，把答案异或进辅助位 |
| $D(f)$ / $R(f)$ / $Q(f)$ | 确定性 / 随机化 / 量子查询复杂度 |
| 多项式方法 | 用多项式度证明量子查询下界的技术 |
| adversary 方法 | Ambainis 提出，证明 Grover 下界 $\Omega(\sqrt N)$ 的工具 |

## 7 小结

- **查询模型**：输入藏在黑盒里，算法以「查询次数」为代价单位；量子查询 $\lvert x\rangle \to (-1)^{f(x)}\lvert x\rangle$ 可并行作用于叠加态。
- **查询复杂度** $Q(f)$：最少量子查询次数；经典 $D(f)$、$R(f)$ 对应确定/随机。
- 翻转查询与相位查询**等价**：把答案编进相位（$\lvert-\rangle$ 技巧）。
- 五个标杆问题的加速类型：Deutsch-Jozsa 与 Simon 指数级，Grover 平方级，Bernstein-Vazirani 仅线性。
- 查询复杂度 ≠ 线路复杂度：前者剥离 oracle 内部代价。
- **观念**：量子查询把信息藏进相位，再用干涉放大——「免费并行」是错觉，编码方式的改变才是本质。
- **数值锚点**：Deutsch-Jozsa 从 $2^{n-1}+1$ 次压到 1 次、Grover 从 $N$ 压到 $\sqrt N$、BV 从 $n$ 压到 1 次——加速类型因问题结构而异。

**练习**：

1. 把翻转查询转成相位查询——准备 $\lvert-\rangle$ 辅助比特，翻转即相位。
2. 为 Deutsch-Jozsa 写出相位查询——$(-1)^{f(x)}$，平衡函数给一半负号、常数函数全正或全负。
3. 解释为什么「一次量子查询」不能读全部答案——得到相位叠加，答案要靠后续 $H$ 与测量读出。
4. 对比查询复杂度与线路复杂度——前者只数 oracle 调用，后者数门数；两者不同时才算得清。
5. 记忆五个标杆问题的加速类型——Deutsch-Jozsa/Simon 指数、Grover 平方、BV 线性、Deutsch 常数，这张表是查询模型的「速度表」。
