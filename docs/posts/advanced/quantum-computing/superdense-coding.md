## 为什么从超密编码开始

上一篇我们问：一份纠缠能做什么？隐形传态给出第一个答案——**用纠缠把量子信息「搬」过经典信道**。今天看它的镜像协议：**超密编码（superdense coding）**——Alice 只把一个量子比特「物理地」寄给 Bob，Bob 却能从中读出**两个**经典比特。一个量子比特装着两比特经典信息？这听起来直接违反常识，甚至像在挑战信息论。它当然没有违反信息论——秘诀在于 Alice 和 Bob 之间**预先共享了一对纠缠比特**，那才是真正多出来的「一比特」。

从香农那句话的视角看，超密编码是在回答一个很基本的问题：**一条信道每用一次，到底能可靠地传多少信息？** 经典信道每次传一比特；一个裸量子比特每次最多传一比特（Holevo 定理）；但「一个量子比特 + 一对预先共享的纠缠」这个组合，每次能传两比特。理解超密编码，就是理解**纠缠是一笔可以预支的通信资源**——这正是它与隐形传态共享的核心课。

## 1 问题设定：一份纠缠，四个信号

Alice 要给 Bob 发一个两比特的消息 $b_1 b_0 \in \{00, 01, 10, 11\}$。她有一根量子信道（能把一个量子比特寄过去），但没有经典信道。Bob 需要能从收到的单个量子比特上读出**两个**比特——这只有靠共享纠缠才可能。

协议分三步：

1. **预备。** Alice 与 Bob 预先共享一对贝尔态 $|\Phi^+\rangle = \frac{|00\rangle + |11\rangle}{\sqrt2}$：Alice 执第一个比特，Bob 执第二个。<span class="marginnote">1968 年斯蒂芬 · 威斯纳（Stephen Wiesner）在研究「共轭编码」时就提出过类似想法，但因过于超前被同行搁置；直到 1992 年才由贝内特（Bennett）与威斯纳正式发表（PRL 69, 2881）。这比隐形传态早一年——超密编码是先被想出来的那个。</span>
2. **编码。** Alice 根据自己想发的两个比特，在自己的比特上施加**四个可能门中的一个**：$\{I, X, Z, ZX\}$。四个门把 $|\Phi^+\rangle$ 变成四个**不同的贝尔态**（下一节推导）。这一步 Alice 没有测量、没有读出任何东西，只是「把消息写进贝尔对的相位与翻转结构」。
3. **解码。** Alice 把自己的比特寄给 Bob。现在 Bob 手里有两个比特（Alice 寄来的 + 自己留下的），他对这两个比特做一次**贝尔测量**，读出 $b_1 b_0$。

关键在第二步与第三步的连接：**四个编码门对应四个两两正交的贝尔态**，而正交态可以无歧义地区分——所以 Bob 能完美恢复那两比特。纠缠在这里的作用是：让 Alice 的单比特上「挂」着四种可区分的全局状态，而不仅仅是 $|0\rangle$ 或 $|1\rangle$ 的两种。

## 2 四个编码门与四个贝尔态

把编码写成表格，这是全篇的地图。记 Alice 对第一个比特施加 $G$，Bob 不动，即整体算符 $G \otimes I$：

| Alice 要发的比特 $b_1 b_0$ | 编码门 $G$ | 作用后 $G\otimes I\,|\Phi^+\rangle$ | 贝尔态 |
| :---: | :---: | :---: | :---: |
| $00$ | $I$ | $\frac{|00\rangle + |11\rangle}{\sqrt2}$ | $|\Phi^+\rangle$ |
| $01$ | $X$ | $\frac{|01\rangle + |10\rangle}{\sqrt2}$ | $|\Psi^+\rangle$ |
| $10$ | $Z$ | $\frac{|00\rangle - |11\rangle}{\sqrt2}$ | $|\Phi^-\rangle$ |
| $11$ | $ZX$ | $\frac{|01\rangle - |10\rangle}{\sqrt2}$ | $|\Psi^-\rangle$ |

**重点：四个结果两两正交。** $\langle\Phi^+|\Phi^-\rangle = 0$、$\langle\Psi^+|\Psi^-\rangle = 0$、跨类也正交——它们是两比特态空间里的一组正交基。正交是可区分性的前提：量子力学允许完美区分正交态（测量可以设计成把每个正交态映射到不同的经典结果），所以 Bob 的贝尔测量能确定性地读出 $b_1 b_0$，而不是概率性的。

**辨析｜易错点：** 编码门是「选一个」，不是「四个都要」——Alice 根据消息**只施加其中恰好一个**。另一个常见困惑是为什么用 $ZX$ 而不是 $Y$：其实 $ZX = iY$，二者只差全局相位 $i$，产生的贝尔态相同；不同教材可能写 $Y$，你只要抓住「四个门对应四个贝尔态」即可，记号只是约定。

## 3 公式解析：编码与解码的矩阵演算

把「为什么恰好是这四个态」推导出来，分两段。

### 第一段：编码，$G\otimes I$ 把 $|\Phi^+\rangle$ 送到哪

先看 $X$。$X|0\rangle = |1\rangle$、$X|1\rangle = |0\rangle$，所以

$$
X\otimes I\,|\Phi^+\rangle = \frac{X|0\rangle|0\rangle + X|1\rangle|1\rangle}{\sqrt2}
= \frac{|1\rangle|0\rangle + |0\rangle|1\rangle}{\sqrt2} = |\Psi^+\rangle
$$

再看 $Z$。$Z|0\rangle = |0\rangle$、$Z|1\rangle = -|1\rangle$：

$$
Z\otimes I\,|\Phi^+\rangle = \frac{Z|0\rangle|0\rangle + Z|1\rangle|1\rangle}{\sqrt2}
= \frac{|00\rangle - |11\rangle}{\sqrt2} = |\Phi^-\rangle
$$

最后 $ZX$，即「先 $X$ 后 $Z$」。上一步已得 $X\otimes I|\Phi^+\rangle = |\Psi^+\rangle$，再作用 $Z$：

$$
Z X\otimes I\,|\Phi^+\rangle = Z|\Psi^+\rangle
= \frac{|0\rangle|1\rangle - |1\rangle|0\rangle}{\sqrt2} = |\Psi^-\rangle
$$

**要点：** 每次作用 $X$ 是「交换两个计算基分量」，作用 $Z$ 是「给 $|1\rangle$ 分量加负号」。四个门正好把 $|\Phi^+\rangle$ 里的「正负号 + 是否翻转」四种组合各敲出一种——这四种组合刚好张成两比特态空间的整组贝尔基。<span class="marginnote">换个角度看：$|\Phi^+\rangle$ 的两个振幅都是 $+1/\sqrt2$。$X$ 把两个分量「互换」，$Z$ 把第二个分量「变负」，$ZX$ 两个都做。于是四种选择对应四组 $(+,+), (+, -), (+, +)$ 的重新排布，恰好构成四维空间的一组正交基。</span>

### 第二段：解码，贝尔测量把贝尔态拉回计算基

Bob 拿到两比特后，先做 CNOT（控制第一位、目标第二位），再对第一位做 $H$，最后按计算基测量。这叫**贝尔测量**，它的效果是把四个贝尔态一一映射到计算基。以 $|\Psi^+\rangle$ 为例逐步看：

$$
|\Psi^+\rangle = \frac{|01\rangle + |10\rangle}{\sqrt2}
$$

CNOT 把 $|10\rangle \to |11\rangle$（控制位是 1，翻转目标位），$|01\rangle \to |01\rangle$：

$$
\frac{|01\rangle + |11\rangle}{\sqrt2} = \frac{|0\rangle + |1\rangle}{\sqrt2} \otimes |1\rangle = |+\rangle|1\rangle
$$

$H$ 把 $|+\rangle \to |0\rangle$（$H$ 的定义：$H|+\rangle = |0\rangle$），于是末态是

$$
|0\rangle|1\rangle = |01\rangle \quad\longrightarrow\quad \text{测到 } 01
$$

把四种情况都跑一遍，得到解码表：

| 编码后的贝尔态 | CNOT + H 后 | Bob 测到 |
| :---: | :---: | :---: |
| $|\Phi^+\rangle$ | $|00\rangle$ | $00$ |
| $|\Psi^+\rangle$ | $|01\rangle$ | $01$ |
| $|\Phi^-\rangle$ | $|10\rangle$ | $10$ |
| $|\Psi^-\rangle$ | $|11\rangle$ | $11$ |

**编码表与解码表首尾相接**：Alice 发 $01$ → 编码成 $|\Psi^+\rangle$ → Bob 测到 $01$。消息被无损复原。

## 4 为什么这不违反信息论

现在回答那个最扎眼的问题：「一比特传两比特，香农错了？」没有——关键在于**资源核算**要算对。

- **裸量子比特的上限是 1 比特。** Holevo 定理说：不借助共享纠缠，$n$ 个量子比特最多传送 $n$ 个经典比特的信息（Nielsen & Chuang §12.1.1）。所以一个被寄出去的裸量子比特，信息量上限就是 1 比特，与直觉一致。<span class="marginnote">Holevo 定理是量子通信的「紧箍咒」：量子信道单独用，容量不会超过经典信道。超密编码的「2 比特」并没有打破它，因为协议额外预支了一比特纠缠——Holevo 定理的前提「不借助共享纠缠」恰好不适用。</span>
- **共享纠缠本身是资源。** 建立一对 $|\Phi^+\rangle$ 需要一次量子通信（或一个纠缠源分发），这笔成本是**事先付掉的**。把整个协议记账：$1$ 个已共享纠缠对（ebit）+ $1$ 个已传输量子比特 $\to 2$ 个经典比特。等价的说法是，预支纠缠使量子信道的**纠缠辅助容量**翻倍：每用一次信道传 $2$ 比特。
- **信息不在单一比特里。** Alice 寄出的那个量子比特单独看，仍然只含不到 1 比特的信息；Bob 把它与自己留下的那半**合在一起**做联合测量，才读出 2 比特。信息藏在**两比特的关联结构**里，而这结构由共享纠缠提供。

**辨析｜易错点：** 超密编码传的是**经典**信息，不是量子态——它与隐形传态正好方向相反。隐形传态：经典信道（2 比特）+ 纠缠（1 ebit）→ 传 1 个未知量子态；超密编码：量子信道（1 量子比特）+ 纠缠（1 ebit）→ 传 2 个经典比特。两份协议共享同一套贝尔态工具箱，只是把资源往不同方向兑换。

## 5 超密编码与隐形传态：一面镜子的两面

把两份协议并排看，结构对称得赏心悦目：

| | 预共享资源 | 实际传输 | 得到 |
| :--- | :---: | :---: | :---: |
| 隐形传态 | $1$ ebit | $2$ 个经典比特 | $1$ 个未知量子比特 |
| 超密编码 | $1$ ebit | $1$ 个量子比特 | $2$ 个经典比特 |

两条公式可以「互相兑换」：**量子比特与经典比特在纠缠的帮助下可以互相转换**。这是量子信息理论里最优雅的恒等式之一，也是「纠缠是一种可兑换资源」的教科书证据。很多教材把这两节放在一起，正是要让读者看到：贝尔态 + 贝尔测量 = 一整套「信息兑换交易所」，量子信息与经典信息在这里按固定的汇率换算。

**重点：** 两份协议都离不开**贝尔测量**。它是编码的逆操作，也是把纠缠「兑现」成经典信息的最后一步。贝尔测量与贝尔态一起，是后续贝尔不等式（第四篇）、量子纠错（第八篇）反复使用的基元——这一节先把它们焊进工具箱。

## 6 一个可运行的示例（Qiskit）

用 Qiskit 走一遍：Alice 发「10」，Bob 应测回「10」。

```python
from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister

qr = QuantumRegister(2, "q")     # q0 = Alice 的比特, q1 = Bob 的比特
cr = ClassicalRegister(2, "c")
qc = QuantumCircuit(qr, cr)

# 预备：共享 |Φ+⟩
qc.h(0)
qc.cx(0, 1)

# 编码：Alice 按消息 b1b0 选门（b1 决定 Z, b0 决定 X）
message = "10"
if message[0] == "1":
    qc.z(0)
if message[1] == "1":
    qc.x(0)

# Bob 收到 q0 后做贝尔测量：CNOT + H
qc.cx(0, 1)
qc.h(0)
qc.measure([0, 1], [0, 1])
```

如果发送 `10`，测量结果必然是 `10`——这正是「编码表与解码表首尾相接」的程序版。把 `message` 改成其他三种再跑，结果都会一一对应。

## 7 小结

- **超密编码**：用 $1$ 个共享贝尔对 + $1$ 个实际传输的量子比特，传送 $2$ 个经典比特。
- 编码：Alice 按消息在 $\{I, X, Z, ZX\}$ 中选一个门，把 $|\Phi^+\rangle$ 变成对应的贝尔态；四个编码门 ↔ 四个正交贝尔态。
- 解码：Bob 做**贝尔测量**（CNOT + H），把贝尔态一一映射回计算基，无损读出两比特。
- **不违反信息论**：裸量子比特仍受 Holevo 定理约束（≤1 比特）；「2 比特」靠**预共享纠缠**这个额外资源兑出——资源核算要算上那 1 ebit。
- 与隐形传态互为镜像：$1$ ebit + 2 cbits ↔ $1$ qubit；**纠缠是可兑换的通信资源**。
- 贝尔态与贝尔测量是整套协议的基石，也将是贝尔不等式、量子纠错的共同基元。
