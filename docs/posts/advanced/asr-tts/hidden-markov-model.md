## 为什么从 HMM 开始

上一节我们得到了帧特征矩阵——但它只是「特征」，不是「内容」。一秒钟的语音里有十来个音素，如何从一帧帧向量反推出背后的音素序列？关键在于一个深刻的观察：**我们能观测到的只是声学特征，说话人究竟处于哪个音素，是看不见的**——这正是「隐」字的由来。

**隐马尔可夫模型（Hidden Markov Model，HMM）** 是经典语音识别二十年的统治范式，也是理解一切现代 ASR 的 DNA：CTC、RNN-T、甚至是注意力机制，都能看成「如何放宽 HMM 的某一条假设」。「状态是隐藏的、观测是可见的、状态只在相邻步转移」，这三句话搭起的骨架，至今仍是端到端模型的底层图景。<span class="marginnote">第一级《概率论》里的条件概率与贝叶斯公式在这里直接上岗：前向算法就是一个大号的「全概率公式」递归，维特比算法则是「最大后验路径」的动态规划。</span>

**核心概念：隐马尔可夫模型（HMM）**：一个关于「隐藏状态链 + 可见观测序列」的双重随机过程。状态按马尔可夫链转移，每个状态按发射分布产生观测。

## 1 马尔可夫链与「隐」字

先看一半——**马尔可夫链**。它描述一条状态序列 $q_1, q_2, \dots, q_T$，满足**一阶马尔可夫性**：当前状态只依赖于前一状态，与更早的历史无关。

$$
P(q_t = S_j \mid q_{t-1}, q_{t-2}, \dots, q_1) = P(q_t = S_j \mid q_{t-1})
$$

这当然是对语音的简化——真正的发音有长期的韵律与上下文。但它换来一个巨大的回报：**所有序列概率都能写成相邻转移概率的连乘**，让整个模型可计算、可学习。

HMM 在此基础上加一个「隐」：状态本身看不见，每个状态只会概率地吐出观测。形式化地，HMM 由五元组刻画 $\lambda = (N, M, A, B, \pi)$：

- $N$：状态数（语音里常是音素或子音素单元，每个音素往往拆成 3 个状态——起、中、收）；
- $A = [a_{ij}]$：状态转移矩阵，$a_{ij} = P(q_t = S_j \mid q_{t-1} = S_i)$；
- $B = \{b_j(o_t)\}$：发射分布，第 $j$ 个状态产生观测 $o_t$ 的概率（声学特征由 GMM 或神经网络给出）；
- $\pi$：初始状态分布。

## 2 HMM 的三个经典问题

一套模型配三个问题，各回答一种「现实需求」：

- **评估（Evaluation）**：给定模型 $\lambda$ 与观测 $O = o_1 o_2 \dots o_T$，求 $P(O \mid \lambda)$。用于「打分」——哪条声学路径更可能，是解码的基础。
- **解码（Decoding）**：给定模型与观测，求最可能的状态序列 $\hat{Q} = \arg\max_Q P(Q \mid O, \lambda)$。用于「认字」——把最优状态链翻译回音素、再连成文字。用**维特比（Viterbi）算法**。
- **学习（Learning）**：给定大量观测，估计参数 $\lambda$。用**前向–后向算法（Baum–Welch，本质是 EM）**。

三个问题各有自己的「问法、算法、代价」，放在一起对照最清楚：

| 问题 | 问的是什么 | 代表算法 | 复杂度 |
| --- | --- | --- | --- |
| 评估 | 这串观测有多可能？$P(O\mid\lambda)$ | 前向算法 | $O(N^2T)$ |
| 解码 | 最可能的状态链是哪条？ | 维特比 | $O(N^2T)$ |
| 学习 | 参数 $A,B,\pi$ 该取多少？ | 前向–后向（Baum–Welch） | 迭代收敛 |

注意评估与解码复杂度同为 $O(N^2T)$：两者在网格上走的步数一样多，区别只在「求和」与「取最大」——这为下文「维特比是前向的把求和换成取最大」埋下伏笔。

三个问题正好对应工程三部曲：先学习，再解码，同时处处要评估。<span class="marginnote">EM 算法在第二级《统计学习》或《机器学习》里会系统出现：E 步用旧参数算隐藏状态的期望，M 步用期望重估参数。Baum–Welch 是 EM 在 HMM 上的具体化——语音界发明它的时间，比 EM 的名字广为人知还早十年。</span>

## 3 公式解析：前向算法

直接按定义算 $P(O \mid \lambda)$ 需要对全部 $N^T$ 条状态路径求和，指数爆炸。前向算法用一条递归把它降到 $O(N^2 T)$。定义**前向变量** $\alpha_t(j)$：时刻 $t$ 处于状态 $S_j$ 且已观测到 $o_1 \dots o_t$ 的概率：

$$
\alpha_t(j) = \left[ \sum_{i=1}^{N} \alpha_{t-1}(i)\, a_{ij} \right] b_j(o_t)
$$

逐步拆解：

- **第一步，看递推的骨架**：$\alpha_{t-1}(i) a_{ij}$ 表示「上一步在状态 $i$、然后跳到 $j$」的概率；对全部 $i$ 求和，就是用**全概率公式**枚举到达 $j$ 的一切可能来源。
- **第二步，乘以发射**：$b_j(o_t)$ 是状态 $j$ 产生当前观测 $o_t$ 的概率。到达 $j$ 且产生观测，两个条件都满足，相乘是概率的链式法则。
- **第三步，设定边界**：初始化 $\alpha_1(j) = \pi_j b_j(o_1)$，最终 $P(O \mid \lambda) = \sum_j \alpha_T(j)$。
- **第四步，读懂复杂度**：每一步只做 $N^2$ 次乘加，$T$ 步后是 $O(N^2 T)$，与 $N^T$ 的暴力求和是天壤之别——**动态规划把「指数的枚举」变成「线性的递推」**，这正是整门算法的精髓，与第一级《数列》里学递推、第三级《算法》里学 DP 是同一条思想血脉。

**数值算例**：设两状态（$S_1$=静音、$S_2$=发声）、观测 $O=o_1o_2o_3$，初始 $\pi=[0.6,0.4]$，转移 $A=\begin{pmatrix}0.7&0.3\\0.2&0.8\end{pmatrix}$，发射 $b_1(o_1)=0.5,\ b_2(o_1)=0.4$，$b_1(o_2)=0.3,\ b_2(o_2)=0.6$，$b_1(o_3)=0.4,\ b_2(o_3)=0.5$。初始化 $\alpha_1(1)=0.6\times0.5=0.30$、$\alpha_1(2)=0.4\times0.4=0.16$；第二步

$$
\alpha_2(1)=\big[0.30\times0.7+0.16\times0.2\big]\times0.3\approx0.0726,\quad
\alpha_2(2)=\big[0.30\times0.3+0.16\times0.8\big]\times0.6\approx0.1308
$$

第三步 $\alpha_3(1)=\big[0.0726\times0.7+0.1308\times0.2\big]\times0.4\approx0.0308$，$\alpha_3(2)=\big[0.0726\times0.3+0.1308\times0.8\big]\times0.5\approx0.0632$，于是 $P(O\mid\lambda)=0.0308+0.0632\approx0.094$。全程只有「全概率求和 × 发射」——把定义式里的每一项都落到了具体数字上。

维特比与前向几乎同构，只把「求和」换成「取最大」——记录每步最优来源，回溯即得最可能状态链。

## 4 从 HMM 到 ASR：音素、三音子与发射模型

HMM 如何从「玩具」变成「ASR 主力」？关键是把「状态」赋予语音语义：

- 每个音素拆成 3 个状态，强制**从左到右**转移（语音里的状态不能倒退），自环负责时长的弹性——一个音素读多久，由在状态上的停留时间决定。
- 同一音素在前后音素不同的语境下发音不同，于是用**上下文相关的三音子（triphone）**建模：把「/k/ 前接 /a/、后接 /i/」当成一个独立的建模单元，状态数动辄上万。
- **发射分布** $b_j(o_t)$ 起初用高斯混合模型（GMM）拟合，后来换成**DNN**直接输出状态后验——这就是「GMM-HMM」到「DNN-HMM」的进化，也是本专题《声学模型 DNN/TDNN》一节的剧情。

到这里，经典 ASR 的骨架已经完整：HMM 管时序结构，特征管观测表示。但 HMM 有个著名的「尴尬」：它要求显式定义状态、要独立发射假设、还要精心设计音素→状态→词的层级。下一节我们将看到，**CTC 如何用一个「空白符号」把状态对齐的重担从模型设计者肩上卸下来**——那是对 HMM 最优雅的一次改良。

**术语速查**：

| 术语 | 一句话含义 |
| --- | --- |
| 一阶马尔可夫性 | 当前状态只依赖前一状态，序列概率可写成连乘 |
| 五元组 $\lambda=(N,M,A,B,\pi)$ | 状态数、观测符号数、转移、发射、初始分布 |
| 三音子（triphone） | 把「前/后语境」都算进音素标识的建模单元 |
| 前向变量 $\alpha_t(j)$ | $t$ 时刻停在状态 $j$ 且已见 $o_1..o_t$ 的概率 |
| 维特比回溯 | 记录每步最优来源，反向还原整条状态链 |
| Baum–Welch | EM 在 HMM 上的实现，交替重估 $A,B,\pi$ |

**辨析｜易错点：** 不要把「状态数 $N$」与「观测符号数 $M$」混为一谈——$N$ 是隐藏层有多少个状态单元，$M$ 是每个状态能吐出多少种观测（语音里 $N$ 对应音素/子音素，$M$ 对应量化后的特征码本或连续分布）。另一个常错点是以为「一个状态 = 一个音素」：实际每个音素通常拆成 3 个左到右状态，靠自环上的停留时间建模时长——「起、中、收」三段的状态绑定正是 HMM 能表达语速变化的来源。

## 5 小结

- **一阶马尔可夫性**：状态只依赖前一状态，使序列概率可写成连乘。
- **HMM 五元组** $\lambda=(N,M,A,B,\pi)$：隐藏状态链 + 发射分布；语音中每个音素拆成 3 个状态，左到右转移。
- **三大问题**：评估（前向算法）、解码（维特比）、学习（前向–后向 / Baum–Welch=EM）。
- **前向递推** $\alpha_t(j) = \big[\sum_i \alpha_{t-1}(i)a_{ij}\big] b_j(o_t)$ 用动态规划把指数复杂度降到 $O(N^2T)$。
- 经典 ASR = HMM（时序结构）+ 上下文相关三音子 + GMM/DNN 发射，是理解一切端到端模型的思想母体。

在下一节，我们将直面 HMM 最别扭的环节——状态对齐——并看 CTC 如何用一行「空白符号」消解它，开启端到端语音识别的时代。
