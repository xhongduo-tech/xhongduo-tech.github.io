# 超流与Landau判据

<div class="epigraph">
<p>超流体的惊人之处不在于「没有摩擦」——而在于它**为什么**没有摩擦。Landau 的答案是：一个运动物体若想减速，就必须把能量交给体系里的激发；如果它跑得太慢、连最便宜的激发都激发不起，那么它就只能永远滑下去。</p>

## 为什么需要理解超流

液氦冷却到 2.17 K 以下，会突然进入**超流相（superfluid phase）**：它可以毫无阻力地流过直径比原子还小的毛细管、沿着杯壁「爬」出来、甚至在容器里自行转圈永不停止。这不再是「低粘度」的问题——粘度是**精确为零**。更神奇的是，超流体的转动行为与刚体完全不同（量子化涡旋），且它的热导率比铜还高。

超流现象的微观理解是 20 世纪理论物理的杰作。BEC 给了我们「凝聚」的图像，但理想玻色气体凝聚并不会超流（理想气体没有激发谱结构）；**Landau 在 1941 年给出的判据**才是超流的动力学核心：超流稳定性由激发谱的形状决定。这一篇我们讲透 Landau 判据、双流体模型与氦-4 谱的深刻联系。<span class="marginnote">历史：1938 年 Kapitza 与 Allen-Misener 同时发现液氦超流；同年 London 提出与 BEC 的联系；Landau 1941 年从激发谱出发建立超流理论；1947 年 Bogoliubov 证明弱相互作用玻色气体的激发谱确实满足 Landau 判据。超流「为什么」的问题，靠的是理论家们前后 20 年的接力。</span>

## 1 Landau 判据

考虑一个质量为 $M$ 的物体（或杂质、或流动的超流整体）以速度 $\mathbf{v}$ 在超流体中运动。它能减速吗？减速意味着把动能转给体系的激发。设物体动量从 $M\mathbf{v}$ 变为 $M\mathbf{v}'$，激发一个能量 $\varepsilon_{\mathbf{k}}$、动量 $\mathbf{k}$ 的准粒子。由能量-动量守恒：

$$\frac{1}{2}Mv^2 = \frac{1}{2}Mv'^2 + \varepsilon_{\mathbf{k}}, \qquad M\mathbf{v} = M\mathbf{v}' + \mathbf{k}$$

消去 $v'$，得激发能够发生（体系可以吸收能量）的条件：

$$M(v^2 - v'^2) = \varepsilon_{\mathbf{k}}\Big[1 - \frac{\mathbf{v}\cdot\mathbf{k}}{\varepsilon_{\mathbf{k}}}\,\cdots\Big]$$

在最有利情形（$\mathbf{k}$ 与 $\mathbf{v}$ 反向），能量守恒要求 $v$ 至少满足：

$$v \ge v_c = \min_{\mathbf{k}}\frac{\varepsilon_{\mathbf{k}}}{k}$$

**重点：Landau 临界速度 $v_c$ 是激发谱能量-动量比的最小值。** 如果物体速度 $v \lt  v_c$，那么**任何**激发都无法被同时满足能量与动量守恒地产生——物体无法把能量交给体系，减速在动力学上被禁止。这就是超流的本质：**不是没有摩擦机制，而是摩擦机制在低速度下被能量-动量守恒「冻住」**。<span class="marginnote">Landau 判据的严格推导要小心：上面用的是「单个激发」条件，更严谨的表述是「不可能存在一个激发，其能量与动量满足 $\varepsilon_{\mathbf{k}} \lt  \mathbf{v}\cdot\mathbf{k}$」——这等价于 $v \lt  \min_k \varepsilon_k/k$。当多个激发协同时还有别的通道，但对均匀超流与单个杂质，判据是准确的。</span>

## 2 为什么 Bogoliubov 谱能超流

把 Landau 判据应用到上一节的 Bogoliubov 谱 $\varepsilon_k = \sqrt{\varepsilon_k^{(0)2} + 2gn_0\varepsilon_k^{(0)}}$：

$$\frac{\varepsilon_k}{k} = \sqrt{\Big(\frac{\hbar k}{2m}\Big)^2 + \frac{2gn_0\hbar^2}{m}}\cdot\frac{1}{\hbar} \ge \sqrt{\frac{gn_0}{m}} = c$$

**重点：Bogoliubov 谱的 $\varepsilon_k/k$ 在 $k\to0$ 时取最小值 $c$（声速）**，所以 $v_c = c$。只要超流速度小于声速 $c$，体系就稳定超流。长波的线性声子谱是超流的充分条件——**「声子谱 → 有限的 $v_c$ → 超流」**这条链完整闭合。<span class="marginnote">对比：<strong>理想玻色气体没有相互作用（$g=0$），谱是抛物线 $\varepsilon_k = \hbar^2k^2/2m$，$\varepsilon_k/k = \hbar k/2m\to 0$，$v_c = 0$</strong>——理想气体<strong>不能</strong>超流！这解释了 Landau 1941 年的困扰：BEC 本身不等于超流，必须有相互作用（有限 $g$）给出线性声子谱。Bogoliubov 1947 年正是补上了这一环。</span>

**辨析｜易错点：** 初学者常以为「BEC 就是超流」。这是错的——理想玻色凝聚体不超流（$v_c=0$）；而某些**非凝聚**体系（如一维玻色子或某些相）也可能有超流关联。**超流 = 凝聚 + 有限临界速度**，后者来自相互作用产生的声子谱。两者的关系是「凝聚是超流的必要条件（一般意义下），但充分条件是激发谱满足 Landau 判据」。

## 3 氦-4 的激发谱与旋子

液氦-4 的激发谱（实验上由中子散射测得，Landau 1947 年修正自己的理论时参考了它）比 Bogoliubov 谱更丰富：

$$\varepsilon(k) = c\hbar k \quad (\text{声子}) \xrightarrow{\ k\ \text{增大}\ } \Delta + \frac{\hbar^2(k-k_0)^2}{2\mu} \quad (\text{旋子})$$

在波矢 $k_0 \approx 1.9\,\text{Å}^{-1}$ 附近出现能量极小值 $\Delta \approx 8.7\,\text{K}$——这个极小值叫**旋子（roton）**。旋子的存在意味着 $\varepsilon_k/k$ 的最小值由旋子段决定：

$$v_c = \min\Big[\frac{\varepsilon(k_0)}{k_0}, \frac{\varepsilon(k\to0)}{k}\Big] \approx \frac{\Delta}{k_0}$$

**重点：氦-4 的临界速度由旋子决定，约为 $60\,\text{m/s}$。** 旋子的物理图像：它对应「环绕一个原子核的环流涡环」——液氦里局部密度涨落形成的旋涡结构。旋子解释了氦-4 谱的复杂性，也解释了为什么液氦超流（而非理想气体）的实验临界速度比 $c$ 更小、且与几何相关。<span class="marginnote">旋子直到 2010 年代才被完全理解：Feynman 1954 年把它与密度涨落的关联函数联系起来，指出旋子是「原子排列成近邻壳层」的量子化回声；现代观点把旋子与「接近晶体化的倾向」联系在一起——液氦里原子想结晶却凝不动，旋子就是这种「想结晶」的振动回声。</span>

## 4 双流体模型与第二声波

超流液氦有**两个组分**，构成**双流体模型（two-fluid model）**（Tisza 1938、Landau 1941）：

$$\rho = \rho_s + \rho_n$$

- **超流组分 $\rho_s$**：零熵、零粘度，无摩擦流动，不携带热量；
- **正常组分 $\rho_n$**：携带熵与热量，有粘度，行为像普通流体。

超流速度与正常速度可以**同时、独立地**流动。由此预言了两类声波：

**第一声波（first sound）**：密度振荡（$\delta\rho$），即普通声波，速度 $c_1$。
**第二声波（second sound）**：超流与正常组分的**反相振荡**（$\delta\rho_s = -\delta\rho_n$），纯熵波/温度波，速度 $c_2 = \sqrt{\frac{\rho_s T s^2}{\rho_n c_v}}$。

**重点：第二声波是超流体的「指纹」——正常流体不可能有纯温度波。** 第二声波的存在与速度直接测量 $\rho_s/\rho_n$（超流密度随温度的下降），是双流体模型最漂亮的实验验证。第二声波也是理解超流输运（He II 的极高热导）的基础。<span class="marginnote">Landau 从第二声波的速度 $c_2$ 与比热数据反推出了 $\rho_s(T)$ 曲线，与实验吻合得极好——这是 Landau 超流理论最著名的「预测后验证」。今天第二声波也在冷原子气（准二维 BEC）里被直接观测到。</span>

**超流密度的温度依赖**：$\rho_s(T)$ 在 $T=0$ 时等于总密度 $\rho$，随温度升高而减小，在 $T_\lambda = 2.17\,\text{K}$（λ 点）处连续降至零——超流转变是二级相变。$\rho_n$ 由热激发（声子 + 旋子）贡献，$\rho_n \propto T^4$（声子）低温主导。

## 5 公式解析：Landau 判据的能量-动量论证

把判据从「能量-动量守恒」严格推一遍，理解那个「最便宜激发」为何决定一切：

**第一步，写守恒条件**：物体从 $(E,P)$ 到 $(E',P')$，激发一个 $(\varepsilon_{\mathbf{k}}, \mathbf{k})$。$E - E' = \varepsilon_{\mathbf{k}}$，$\mathbf{P} - \mathbf{P}' = \mathbf{k}$。
**第二步，用物体动能展开**：$E = P^2/2M$，$E' = (P-k)^2/2M$。能量差 $E - E' = \frac{\mathbf{P}\cdot\mathbf{k}}{M} - \frac{k^2}{2M} = \mathbf{v}\cdot\mathbf{k} - \frac{k^2}{2M}$。当 $M\to\infty$（重物体），第二项可忽略，条件简化为 $\varepsilon_{\mathbf{k}} = \mathbf{v}\cdot\mathbf{k}$。
- **第三步，转成不等式**：激发能发生当且仅当存在 $\mathbf{k}$ 使 $\varepsilon_{\mathbf{k}} \le \mathbf{v}\cdot\mathbf{k}$（$M\to\infty$ 极限）。为使**任何** $\mathbf{k}$ 都不满足，要求 $v \lt  \min_k \varepsilon_k/k = v_c$。
- **第四步，物理**：$v_c$ 是「超流可以存在的最大速度」。超过它，体系就能「找到」一个准粒子来吸收物体的动能——超流被破坏。**$v_c$ 完全由激发谱 $\varepsilon_k$ 的几何决定**，不依赖杂质细节。

**重点：Landau 判据把「是否超流」这个宏观问题，还原成「激发谱 $\varepsilon_k/k$ 的最小值」这个纯谱问题。** 这是「宏观性质由低能激发谱决定」最直接、最有力的范例——也预告了后面「物相由激发结构标记」的现代观点（拓扑序）。

## 6 超流与「从极限到大模型」

超流是「从极限到大模型」里「**稳定性由谱决定**」的绝佳隐喻。一个系统的「稳健性」（不被扰动击穿）不是由「扰动力有多强」决定的，而是由「系统自身的激发结构」决定的——只要激发谱有一个正的「能隙/斜率」，系统就能承受任意慢的、任意弱的扰动而不改变相。<span class="marginnote">这几乎就是机器学习里「鲁棒性/泛化」的物理版：模型的「临界速度」$v_c$ 对应它抵抗对抗扰动、分布偏移的能力——由模型的「激发谱」（表征的几何、损失的 Landscape）决定，而非由扰动大小单独决定。<strong>平坦损失景观 + 宽极小</strong> = 高 $v_c$ = 稳健模型。可参考第四级《大模型原理》与《安全与对齐》。</span>

对多体理论自身，超流把我们带到了凝聚态与粒子物理的交汇：超流的相位相干、涡旋量子化与 Josephson 效应（下一节）构成「相干宏观系统」的完整故事——而超导正是超流的一个「带电版本」。

## 7 小结

- **Landau 判据**：超流临界速度 $v_c = \min_k\varepsilon_k/k$；物体速度低于 $v_c$ 时无法激发任何准粒子，超流稳定。
- **声子谱 → 超流**：Bogoliubov 谱 $\varepsilon_k/k \ge c$，$v_c=c$；理想玻色气体（$g=0$）$v_c=0$ **不超流**。
- 液氦-4 的激发谱含**旋子**极小值（$\Delta\approx8.7\,\text{K}$），$v_c=\Delta/k_0$，由旋子决定。
- **双流体模型**：$\rho=\rho_s+\rho_n$，超流组分零熵无粘，正常组分携带熵；两类声波（第一/第二声波）。
- **第二声波**是纯温度/熵波，速度 $c_2$ 直接测量 $\rho_s/\rho_n$——双流体模型的实验验证。
- 超流 = 凝聚 + 有限临界速度；「是否超流」由激发谱的几何决定。

在下一节，我们把「凝聚 + 相位相干」搬到带电费米子世界：**Cooper 不稳定性与 BCS 超导**——两个电子如何通过声子交换结成对，以及费米面为何对任意弱的吸引都不稳定。


## 公式速查：一页纸复习

| 对象 | 公式 | 一句话要点 |
| --- | --- | --- |
| Landau 判据 | $v_c = \min_k \varepsilon_k/k$ | 低于临界速度无法激发准粒子 |
| Bogoliubov 声速 | $c = \sqrt{gn_0/m}$ | 声子谱给出 $v_c=c$ |
| 理想气体 | $v_c = 0$ | 抛物线谱，不超流 |
| 旋子 | $\Delta \approx 8.7$ K，$k_0\approx1.9$ Å⁻¹ | 氦-4 临界速度由旋子决定 |
| 双流体 | $\rho = \rho_s + \rho_n$ | 超流组分零熵无粘 |
| 第二声波 | $c_2 = \sqrt{\rho_s T s^2/\rho_n c_v}$ | 纯熵波，测 $\rho_s/\rho_n$ |

**易错复盘**：两点要盯住。其一，BEC 不等于超流——理想玻色凝聚体 $v_c=0$ 不超流，超流必须靠相互作用给出线性声子谱；其二，旋子的存在让氦-4 的临界速度由旋子决定而非声速——激发谱的几何（$\varepsilon_k/k$ 的最小值）是判据的全部。

**知识连线**：Landau 判据建立在第 3 篇 BEC 与 Bogoliubov 谱之上；旋子是氦-4 谱的独特性，其解释连接第 3 篇重正化群（「想结晶」的回声）。「超流稳定性由激发谱决定」是「从极限到大模型」里「稳健性由系统自身的激发结构决定」的直接物理原型。

**实践与辨析**：为什么 $\varepsilon_k/k$ 的最小值决定临界速度？提示：重物体激发单个准粒子需满足 $\varepsilon_k = \mathbf{v}\cdot\mathbf{k}$，最有利情形给出 $v\ge\varepsilon_k/k$。为什么理想玻色气体 $v_c=0$？提示：抛物线谱 $\varepsilon_k/k = \hbar k/2m\to0$
