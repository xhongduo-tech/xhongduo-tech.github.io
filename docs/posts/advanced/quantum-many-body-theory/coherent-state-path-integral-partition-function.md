# 相干态路径积分与配分函数

## 为什么需要路径积分

前面几篇全部在**算符语言**里工作：Green 函数、Wick 定理、Dyson 方程、Kubo 公式。这套语言功能强大，但有一个局限——它要求你先有「自由解」$G^{(0)}$ 才能展开微扰。面对强相互作用、对称破缺、相变这些没有天然「自由起点」的问题时，算符语言会显得笨拙。

**路径积分（path integral）**提供另一套世界观：配分函数不再是对算符求迹，而是对**所有可能的场构型**做泛函积分。在这个视角下，「平均场」就是积分的**鞍点**（saddle point），「量子涨落」就是鞍点周围的**高斯积分**，「对称破缺」就是鞍点出现简并。文小刚在《量子多体理论》里用这一整套语言重新组织了整个多体物理——**从经典场论的起点，到声子、光子、电子的起源**。这一篇我们打好基础：相干态、Grassmann 数、以及把配分函数写成路径积分。<span class="marginnote">Feynman 1948 年提出路径积分后，几乎立刻被用于量子场论；1960 年代 Hubbard、Stratonovich 等人把它引入凝聚态多体。今天，从超导到拓扑序，路径积分已是凝聚态理论的第一语言。</span>

## 1 玻色相干态

**相干态（coherent state）**是湮灭算符的本征态：

$$\hat{a}\,|z\rangle = z\,|z\rangle, \qquad z \in \mathbb{C}$$

对单模玻色场，相干态可以显式写出：

$$|z\rangle = e^{-|z|^2/2}\, e^{z\hat{a}^\dagger}\,|0\rangle = e^{-|z|^2/2}\sum_{n=0}^{\infty}\frac{z^n}{\sqrt{n!}}\,|n\rangle$$

**相干态是过完备的（overcomplete）**：任意两个相干态内积为 $e^{z^*z'}$，非正交；但它们给出**单位分解**：

$$\int \frac{d^2z}{\pi}\,|z\rangle\langle z| = \hat{I}$$

**重点：相干态把「态」替换成「复数」**——一个算符问题变成对复数 $z$ 的积分。这正是指标 $z$ 的物理含义：它是场的复振幅，路径积分就是对这条复振幅路径的求和。<span class="marginnote">相干态最著名的物理实现是激光：激光的态就是光子数很大的相干态，$z$ 对应经典电磁场的复振幅。所以「把多体问题写成相干态路径积分」在精神上就是「用量子化的经典场去描述体系」。</span>

## 2 费米相干态与 Grassmann 数

费米子的相干态不能直接照搬玻色子方案——费米湮灭算符 $c$ 满足 $c^2 = 0$，它的「本征值」不可能是一个普通复数。解决方案是引入**Grassmann 数（Grassmann number）**：一种满足**反对易**的代数对象：

$$\eta_1\eta_2 = -\eta_2\eta_1, \qquad \eta^2 = 0$$

Grassmann 数是「无穷小」的代数化：任何函数 $f(\eta)$ 只能展开到线性项 $f(\eta) = a + b\eta$。费米相干态定义为 $|\eta\rangle = e^{-\eta c^\dagger}|0\rangle$，满足 $c|\eta\rangle = \eta|\eta\rangle$。其单位分解为：

$$\int d\eta^* d\eta\, e^{-\eta^*\eta}\,|\eta\rangle\langle\eta| = \hat{I}$$

**重点：玻色子路径积分积分的是普通复数，费米子路径积分积分的是 Grassmann 数。** 这套「数」的差别正是「对易」与「反对易」在积分层面的体现——一切统计性质再次内建在数学对象本身。<span class="marginnote">Grassmann 数的积分规则反直觉地「反常」：$\int d\eta\, 1 = 0$、$\int d\eta\, \eta = 1$。这套规则（Berezin 积分）等价于「对平移不变性 + 线性」的公理，它自动保证费米子配分函数里的所有圈图带负号——Wick 定理的负号在路径积分里「免费」获得。</span>

## 3 配分函数的路径积分表示

有了相干态与单位分解，就可以把配分函数写成路径积分。把虚时 $0 \to \beta$ 切成 $N$ 段，在每一段插入单位分解，取 $N\to\infty$ 极限，得到：

$$Z = \text{Tr}\,e^{-\beta H} = \int \mathcal{D}[\psi^*,\psi]\; e^{-S[\psi^*,\psi]}$$

其中费米子的泛函测度为 $\mathcal{D}[\psi^*,\psi] = \prod_{\mathbf{k},n} d\psi^*_{\mathbf{k}n}\,d\psi_{\mathbf{k}n}$，而**欧氏作用量（Euclidean action）**为：

$$S[\psi^*,\psi] = \int_0^\beta d\tau\Big[\sum_{\mathbf{k}}\psi^*_{\mathbf{k}}(\tau)\,\partial_\tau\psi_{\mathbf{k}}(\tau) + H\big(\psi^*(\tau),\psi(\tau)\big)\Big]$$

**重点：配分函数 = 对所有虚时场构型 $(\psi^*(\tau),\psi(\tau))$ 的加权积分，权重是 $e^{-S}$。** 至此，「量子 + 温度」的多体问题被彻底翻译成一个经典统计力学的泛函积分——只是积分变量是场而不是数，且费米场是 Grassmann 的。一切热力学量由 $F = -k_BT\ln Z$ 给出。<span class="marginnote">这条路径积分表示把「量子」与「统计」统一起来：虚时周期 $\beta$ 同时承载温度与量子涨落。相变理论里所谓「量子相变 = 虚时方向上的经典相变」，正是这句话的推论——量子涨落在虚时方向被映射成热涨落。</span>

## 4 公式解析：自由费米气体的路径积分

用自由费米气体把路径积分从头走一遍，检验整套构造的自洽性：

- **第一步，写出作用量**：$S = \sum_{\mathbf{k}}\int_0^\beta d\tau\Big[\psi_{\mathbf{k}}^*\,\partial_\tau\psi_{\mathbf{k}} + \xi_{\mathbf{k}}\,\psi_{\mathbf{k}}^*\psi_{\mathbf{k}}\Big]$，其中 $\xi_{\mathbf{k}}=\varepsilon_{\mathbf{k}}-\mu$。
- **第二步，Fourier 到松原频率**：$\psi(\tau) = \frac{1}{\sqrt{\beta}}\sum_{i\omega_n}\psi(i\omega_n)e^{-i\omega_n\tau}$，作用量变成对角形式 $S = \sum_{\mathbf{k},n}\psi^*_{\mathbf{k}n}\big[-i\omega_n + \xi_{\mathbf{k}}\big]\psi_{\mathbf{k}n}$。
- **第三步，高斯积分**：对 Grassmann 变量的高斯积分给出 $\int e^{-\psi^* M\psi} = \det M$。于是 $Z = \prod_{\mathbf{k},n}(-i\omega_n + \xi_{\mathbf{k}})$。
- **第四步，取对数得自由能**：$\ln Z = \sum_{\mathbf{k},n}\ln(-i\omega_n+\xi_{\mathbf{k}})$，完成松原求和后得到 $\ln Z = \sum_{\mathbf{k}}\ln(1+e^{-\beta\xi_{\mathbf{k}}})$——这正是自由费米气体的标准结果。**自洽！**

**重点：自由体系的路径积分 = 高斯积分，必然严格可解。** 所有「相互作用」进入作用量的高次项（$\psi^*\psi^*\psi\psi$），高斯积分被破坏，就需要微扰（把相互作用当额外权重展开）或近似（把非高斯部分作鞍点处理）。路径积分因此把多体问题的困难精确定位为：**非高斯积分的求值**。

## 5 鞍点：路径积分里的平均场

路径积分最强大的地方在于给平均场一个自然的几何图像。对作用量 $S[\psi^*,\psi]$，**鞍点方程**由变分 $\delta S/\delta\psi^* = 0$ 给出：

$$\partial_\tau\psi_{\mathbf{k}} = -\frac{\partial H}{\partial\psi_{\mathbf{k}}^*}$$

鞍点解 $\psi_0$ 就是**经典场构型**——即平均场近似：忽略所有涨落，只保留使作用量取极值的构型。鞍点周围的**高斯涨落**给出量子修正（即 RPA 或单圈修正）。**重点：平均场不是「把算符换成 c 数」的权宜之计，而是路径积分在鞍点处的精确近似**——它告诉你什么时候平均场可信（涨落小），什么时候会失效（鞍点简并或涨落发散，即相变临界点）。<span class="marginnote">在相变临界点，鞍点附近存在「零模」（Goldstone 模）导致高斯积分发散——这说明平均场必然失效，必须用重正化群处理。这条「鞍点简并 → 对称破缺 → Goldstone 模」的链条，是文小刚书第 3 章的核心，本专题第 2 篇的《对称破缺、序参量与 Goldstone 模》将专门展开。</span>

## 6 路径积分与「从极限到大模型」

路径积分是「从极限到大模型」主线的又一个深刻共鸣。它的核心思想——**用一个可积分的测度 $e^{-S}$ 定义分布，一切复杂行为都藏在测度的选择里**——正是生成模型的世界观：扩散模型把数据生成定义为一个带噪声调度的路径积分；能量模型把分布写成 $\exp(-E(x))$，与配分函数 $Z$ 的归一化困境一一对应。<span class="marginnote">VAE 的「重参数化技巧」本质上是把隐变量的高斯积分写成一个可微路径；而分数阶扩散（score-based generative model）的得分函数就是作用量对场的梯度 $\delta S/\delta\psi$——「鞍点 = 最可几构型」在生成模型里就是「最概然样本」。想深入见本博客第四级《生成模型》与《大模型原理》。</span>

对多体物理自身，路径积分是后续几乎每一篇的基底：对称破缺的有效理论、玻色凝聚的 Bogoliubov 理论、Hubbard-Stratonovich 变换、重正化群——全都以「配分函数 = 泛函积分」为出发点。

## 7 小结

- **玻色相干态**是湮灭算符本征态，过完备但给出单位分解，把态替换成复振幅 $z$。
- **费米相干态**必须用 **Grassmann 数**，反对易代数自动实现费米子统计与圈图负号。
- **配分函数路径积分** $Z=\int\mathcal{D}[\psi^*,\psi]e^{-S}$，欧氏作用量 $S=\int_0^\beta d\tau[\psi^*\partial_\tau\psi + H]$。
- 自由体系 = **高斯积分**，严格可解（$Z=\det M$）；相互作用进入非高斯项，是困难的精确所在。
- **平均场 = 鞍点近似**；鞍点周围高斯涨落给量子修正；鞍点简并预示对称破缺与 Goldstone 模。
- 量子与温度统一在虚时周期 $\beta$ 上，量子相变 = 虚时方向上的经典相变。

在下一节，我们将带着这套完整武器进入第一个实战问题：**均匀电子气与交换关联能**——用 Hartree-Fock 与更精细的方法，计算这个「最简单的相互作用多体系统」的能量，并体会交换空穴与关联空穴的物理图像。


## 公式速查：一页纸复习

| 对象 | 公式 | 一句话要点 |
| --- | --- | --- |
| 玻色相干态 | $\hat{a}|z\rangle = z|z\rangle$ | 湮灭算符本征态，$z$ 是复振幅 |
| 单位分解 | $\int \frac{d^2z}{\pi}|z\rangle\langle z| = \hat{I}$ | 相干态过完备但可分解单位 |
| 费米相干态 | $c|\eta\rangle = \eta|\eta\rangle$ | Grassmann 数，$\eta^2=0$ |
| 配分函数 | $Z = \int\mathcal{D}[\psi^*,\psi]\,e^{-S}$ | 对场构型的泛函积分 |
| 欧氏作用量 | $S = \int_0^\beta d\tau\,[\psi^*\partial_\tau\psi + H]$ | 虚时 + 温度统一进 $\beta$ |
| 自由气体 | $Z = \prod(-i\omega_n+\xi_{\mathbf{k}})$ | 高斯积分严格可解 |

**易错复盘**：两点要盯住。其一，费米路径积分的积分变量是 Grassmann 数——普通复数的微积分不适用，Berezin 积分规则（$\int d\eta\,\eta=1$）自动给出费米子圈负号；其二，自由体系 = 高斯积分必然可解，相互作用进入非高斯项——「非高斯积分的求值」是多体问题的精确定位。

**知识连线**：路径积分把第 1 篇的算符语言整体重写为场积分，平均场 = 鞍点近似（第 2 篇有效理论）；鞍点简并预示对称破缺（第 3 篇），反复积掉短距涨落就是重正化群（第 3 篇）。「配分函数 = 泛函积分」是后续几乎所有理论的基底。

## 8 数值算例：玻色与费米配分函数的 ±1

把路径积分的统计效力落到一个数上。自由气体的配分函数：

$$
Z_{\text{fermi}} = \prod_{\mathbf{k}}\big(1+e^{-\beta\xi_{\mathbf{k}}}\big), \qquad Z_{\text{bose}} = \prod_{\mathbf{k}}\big(1-e^{-\beta\xi_{\mathbf{k}}}\big)^{-1}
$$

- **第一步，看符号**：费米子配分函数里的 $+1$ 与玻色子的 $(-1)$ 由高斯积分的 $\det M$（费米）与 $1/\det$（玻色）自动给出——「积分 Grassmann 数」与「积分普通复数」只差这一个符号，却决定了全部统计。
- **第二步，看占据**：$T=0$ 时费米占据 $n_{\mathbf{k}}=\Theta(-\xi_{\mathbf{k}})$ 给出费米海，玻色占据 $n_{\mathbf{k}}=1/(e^{\beta\xi_{\mathbf{k}}}-1)$ 给出基态凝聚（BEC 的配分函数先兆）。
- **第三步，读结论**：玻色凝聚 vs 费米海的全部差异，在路径积分语言里只是「积分哪种数」这一个选择——统计性质被完全内建在数学对象里。

**重点：这套「一个选择决定统计」的语言，让费米-玻色混合系统（BCS 超导里的复合玻色子、磁性理论里的自旋子）在同一条路径积分里得到统一处理。** 这也是文小刚书里用路径积分统一描述声子、光子与电子的起点。

**实践与辨析**：为什么相干态是过完备的（非正交）？提示：$\langle z|z'\rangle = e^{z^*z'}\neq\delta$；正因相干态相互重叠，才需要积分全体 $z$ 才能分解单位——这正是路径积分「积分所有场构型」的根源。
