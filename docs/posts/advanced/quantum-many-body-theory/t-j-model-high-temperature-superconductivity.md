# t-J模型与高温超导

<div class="epigraph">

## 为什么需要 t-J 模型

1986 年 Bednorz-Müller 发现铜氧化物高温超导（$T_c$ 高达 130 K 以上），立即引爆凝聚态物理：BCS 理论（声子配对）的 $T_c$ 上限远低于此。这些材料有一个共同母体——**反铁磁 Mott 绝缘体**（如 La₂CuO₄）——掺杂少量空穴后，反铁磁被压制、超导出现。

Anderson 在 1987 年提出关键洞见：高温超导可能来自**掺杂的 Mott 绝缘体**本身——电子不能双重占据（$U$ 无穷大的极限），空穴的移动与自旋的交换纠缠在一起。这个物理的最小模型就是 **t-J 模型（t-J model）**——它只有两个过程：空穴跳跃（$t$）与自旋交换（$J$），但「不许双重占据」的约束把两者强行耦合。这一篇我们从 Hubbard 模型推导 t-J 模型，理解它为何是高温超导的核心候选，并看它如何预言 d 波配对。<span class="marginnote">t-J 模型的历史：源自 Zhang-Rice 1988 年的工作，把铜氧化物简化为「单带 + 空穴」的有效模型；它是 Anderson 的 RVB（共振价键）理论的载体。虽然 40 年过去高温超导机制仍无定论，t-J 模型始终是理论界的主战场——「t-J 模型有没有超导、为什么」至今是悬而未决的世纪难题。</span>

## 1 从 Hubbard 到 t-J：大 $U$ 极限

在 $U\to\infty$（实际是 $U\gg t$）的 Hubbard 模型里，双重占据被**完全禁止**。用投影算符 $P_G = \prod_i(1-n_{i\uparrow}n_{i\downarrow})$ 把 Hilbert 空间限制在「每格点最多一个电子」，并在二阶微扰中保留跳跃 + 交换，得到 **t-J 模型**：

$$\hat{H} = -t\sum_{\langle ij\rangle\sigma}P_G\big(c^\dagger_{i\sigma}c_{j\sigma}\big)P_G + J\sum_{\langle ij\rangle}\Big(\mathbf{S}_i\cdot\mathbf{S}_j - \frac{1}{4}n_in_j\Big)$$

其中 $J = 4t^2/U$（与 Heisenberg 篇相同）。**重点：t-J 模型的灵魂是投影 $P_G$——电子只能在「空位」（空穴）上移动，永远不能落到已占据的格点。** 这个约束让 $t$ 与 $J$ 不再是独立的：空穴移动必然扰动自旋背景，自旋交换必然受空穴分布影响——电荷与自旋**不可分离**。<span class="marginnote">t-J 模型与 Hubbard 的关系：t-J 是大 $U$ 极限下的有效模型，去掉了「双占据中间态」的电荷涨落，只保留低能（无双占据）子空间。对 $U/t \gtrsim 10$，t-J 是 Hubbard 的可靠近似；对更小的 $U$ 需要保留双占据（如三带模型）。Zhang-Rice 单带化把铜氧化物映射到 t-J 型模型，$t\approx0.4\text{ eV}$、$J\approx0.13\text{ eV}$。</span>

## 2 空穴掺杂：从反铁磁到超导

铜氧化物相图：母体是反铁磁 Mott 绝缘体（$T_N\approx300\text{ K}$）；掺杂空穴 $\delta$ 后，反铁磁被压制，出现赝隙区与超导区（最佳掺杂 $\delta\approx0.16$ 时 $T_c$ 最大）；过掺杂后超导消失，回归费米液体。

**t-J 模型的图景**：空穴在反铁磁背景里移动时，它「擦去」沿途的磁有序（空穴所在格点无自旋）——反铁磁被空穴破坏，这是掺杂压制磁序的机制。Anderson 的 **RVB（共振价键）** 理论更进一步：当空穴足够多，自旋不再形成 Néel 序，而是组成**自旋单态对（价键）**的动态共振——**自旋单态是「预配对的 Cooper 对」**，掺杂后这些价键变成移动的配对，承载超流。<span class="marginnote">RVB 的直观：反铁磁背景里，相邻自旋倾向于形成局域单态（价键，类似 Heisenberg 的束缚态）。基态不是「一个确定的价键图样」，而是<strong>所有价键图样的量子叠加</strong>——「共振」。空穴移动时，价键图样重组，但单态配对的特征保留下来——这就是「预形成配对」的图像：配对在进入超导之前就存在（赝隙相的候选解释）。</span>

**重点：t-J 模型的中心思想——超导配对来自「自旋的磁关联」，而非声子。** 如果高温超导的配对机制是磁性的，那么配对是**库珀对的磁性版**：两个空穴/电子通过交换磁涨落（自旋子）吸引。这是与 BCS（声子）本质不同的配对机制。

## 3 d 波配对对称性

t-J 模型预言的配对对称性（由平均场与数值研究支持）是 **d 波（d-wave）**：

$$\Delta_{\mathbf{k}} = \Delta_0(\cos k_x a - \cos k_y a)$$

**重点：d 波配对在节点方向（$k_x=\pm k_y$）能隙为零，在反节点方向能隙最大——符号改变、各向异性。** 这与 BCS 的 s 波（各向同性、能隙处处非零）截然不同。d 波的实验指纹：**相位敏感实验**（SQUID 干涉、半边 Josephson 结）显示超导相位绕一圈改变符号——这是 d 波的决定性证据，也是「非 s 波」的明确信号。<span class="marginnote">d 波配对的物理根源：反铁磁交换 $J\sum\mathbf{S}_i\cdot\mathbf{S}_j$ 是「排斥性的、动量依赖的」吸引——它倾向在动量空间相隔 $(\pi,\pi)$ 的两个电子配对，这恰好是 d 波的对称性。所以 d 波不是「凑出来的」：<strong>从反铁磁交换出发，配对对称性被自动锁定为 d 波</strong>——这是 t-J 模型作为高温超导理论的最强预言之一。</span>

## 4 平均场：slave-boson 与 RVB 平均场

处理 t-J 模型的平均场工具是 **slave-boson 方法**（slave-boson / slave-fermion 分解）。把电子写成「自旋子（spinon）× 空穴子（holon）」的组合，约束「每格点电子数 + 空穴数 = 1」：

$$c_{i\sigma} = f_{i\sigma}\,b^\dagger_i \quad(\text{slave-boson: 电子 = 费米子自旋子 × 玻色子空穴子})$$

代入 t-J 模型，平均场分解出**配对序参量**与**hopping 序参量**，得到 d 波配对的平均场解。能隙方程在 $T_c$ 处：

$$T_c \sim J\,e^{-1/\lambda_{\text{eff}}}$$

与 BCS 结构相似，但耦合来源是 $J$（磁交换）而非声子。<span class="marginnote">slave-boson 把「无双重占据」的硬约束变成「玻色子（空穴）的动力学」：空穴是玻色子，自旋子是费米子，两者耦合。这套分解让 t-J 模型的平均场可解，但约束的规范结构（$U(1)$ 或 $SU(2)$ 规范）极其重要——不同的规范选择给出自旋液体 vs d 波超导等不同相，是 t-J 模型理论最微妙也最深刻的部分。</span>

**辨析｜易错点：** 初学者常把「t-J 模型」与「Hubbard 模型」混为一谈。区别：**Hubbard 保留 $U$（双占据要付出有限能量），t-J 取 $U=\infty$ 极限（双占据完全禁止，投影掉）**。t-J 是 Hubbard 的低能有效模型，丢掉「电荷涨落」（双占据）只保留「低能自旋 + 空穴」自由度。另一个易错点：**t-J 模型不是「BCS 加个约束」**——约束彻底改变了配对机制（从声子到磁性）与配对对称性（从 s 波到 d 波）。

## 5 公式解析：t-J 模型的平均场配对

用 slave-boson 平均场演示「磁性交换如何产生 d 波配对」：

**第一步，重写交换项**：$\mathbf{S}_i\cdot\mathbf{S}_j$ 用自旋子写成 $-\frac{1}{2}(f^\dagger_{i\alpha}f_{i\beta}f^\dagger_{j\beta}f_{j\alpha} - \cdots)$，分解出配对通道 $\Delta_{ij} = \langle f_{i\alpha}f_{j\alpha}\rangle$。
**第二步，平均场哈密顿量**：$H_{\text{MF}} = \sum_{\langle ij\rangle}\frac{J}{2}\big[\Delta_{ij}^*f_{i\uparrow}f_{j\downarrow} + \text{h.c.}\big] + \text{hopping 项} + \text{约束项}$。配对项结构 = BCS 的配对项，只是耦合常数是 $J$。
- **第三步，解自洽方程**：$\Delta_{ij}$ 的自洽方程 $\Delta_{ij} = \langle f_{i\uparrow}f_{j\downarrow}\rangle$。在正方格子解，发现最低能解是**交错符号的配对**（$\Delta_{ij}$ 在 $x$ 方向为正、$y$ 方向为负）——**这正是 d 波**。
- **第四步，物理**：反铁磁交换的动量结构（$J_{\mathbf{k}} = J(\cos k_x+\cos k_y)$）使「动量差 $(\pi,\pi)$ 的配对」最有利，对应 d 波。**配对对称性不是自由参数，而是磁交换几何的必然。**

**重点：t-J 模型把「高温超导机制」压缩成一个问题——「磁性交换能否在现实参数下产生足够强的 d 波配对」。** 至今的数值研究（DMRG、Monte Carlo）在 t-J 模型里**确实**看到 d 波超导的强信号，但「是否自洽地解释实验相图」仍在争论——这使它成为凝聚态理论最活跃的战场。

## 6 t-J 模型与「从极限到大模型」

t-J 模型是「从极限到大模型」里「**约束如何产生新机制**」的绝佳范例：仅仅加上「不许双重占据」这一个约束，就把配对机制从声子（BCS）切换到磁性（d 波）、把基态从费米液体切换到复杂相图。**约束不是「限制」，而是「产生新物理的种子」。**<span class="marginnote">这在机器学习里对应<strong>归纳偏置（inductive bias）</strong>：给模型加上合理的约束（稀疏、对称、低秩、结构化），不是「限制能力」而是「引导出新能力」——正如 t-J 的约束引导出 d 波配对。而「电荷-自旋不可分离」提示：<strong>模型的特征/能力之间也可能有硬约束耦合</strong>，理解这些耦合是理解涌现的关键。可参考第四级《大模型原理》与《表示学习》。</span>

对多体理论自身，t-J 模型是高温超导、赝隙、自旋液体共享的战场；下一节我们进入它最深奥的延伸——**量子自旋液体与拓扑序**：没有序参量的物相。

## 7 小结

- **t-J 模型**：$U\to\infty$ 极限的 Hubbard 有效模型，含跳跃 $t$、交换 $J$ 与「无双重占据」投影 $P_G$。
- 投影约束使**电荷与自旋不可分离**——空穴移动扰动磁背景，这是 t-J 与 BCS 的本质区别。
- 铜氧化物：反铁磁 Mott 绝缘体 → 掺杂压制磁序 → d 波超导；**RVB** 理论把超导配对归因于自旋单态的共振。
- **d 波配对** $\Delta_{\mathbf{k}} = \Delta_0(\cos k_x - \cos k_y)$：节点零能隙、符号改变，是磁性配对的决定性预言。
- **slave-boson 平均场**把电子写成自旋子 × 空穴子，约束的规范结构决定自旋液体 vs d 波超导。
- 配对机制从声子（BCS）切换到磁性交换——「约束产生新机制」是 t-J 的核心启示。

在下一节，我们登上本专题最强关联的高地：**量子自旋液体与拓扑序**——当所有常规序都被摧毁，物相如何依然存在，且由非局域的拓扑性质标记。


## 公式速查：一页纸复习

| 对象 | 公式 | 一句话要点 |
| --- | --- | --- |
| t-J 哈密顿量 | $\hat{H} = -t\sum P_G(c^\dagger c)P_G + J\sum(\mathbf{S}_i\cdot\mathbf{S}_j - \tfrac{1}{4}n_in_j)$ | 跳跃 + 交换，双占据被投影掉 |
| 交换与跳跃 | $J = 4t^2/U$ | 来自 Hubbard 的大 $U$ 极限 |
| d 波配对 | $\Delta_{\mathbf{k}} = \Delta_0(\cos k_x a - \cos k_y a)$ | 节点零能隙、符号改变，磁交换的必然 |
| slave-boson | $c_{i\sigma} = f_{i\sigma}\,b_i^\dagger$ | 电子 = 自旋子 × 空穴子，约束规范结构 |
| 临界温度 | $T_c \sim J\,e^{-1/\lambda_{\text{eff}}}$ | BCS 结构，但耦合来源是磁交换 |

**易错复盘**：三处要分清。其一，t-J 与 Hubbard 的区别：Hubbard 保留有限 $U$（双占据要付能量），t-J 是 $U\to\infty$ 极限（双占据完全禁止）；其二，t-J 不是「BCS 加约束」——约束把配对机制从声子切换到磁性、把配对对称性从 s 波切换到 d 波，是质变；其三，d 波不是「凑出来的」——它由反铁磁交换的动量结构（$J_{\mathbf{k}}$）自动锁定。

**知识连线**：t-J 模型把第 3 篇的 Hubbard 模型、第 4 篇的 Heisenberg 交换与第 4 篇的自旋液体概念串成一条线：母体是 Mott 绝缘体（Hubbard 强关联），配对来自磁交换（Heisenberg），超导相与赝隙/自旋液体相邻（第 4 篇《量子自旋液体与拓扑序》）。「约束产生新机制」是本篇对「从极限到大模型」主线最鲜明的贡献。

**思考题**：为什么反铁磁交换倾向于 d 波而非 s 波配对？提示：把 $J_{\mathbf{k}} = J(\cos k_x + \cos k_y)$ 代进配对通道看哪种对称性最省能量。空穴掺杂为什么压制反铁磁？提示：空穴占据格点抹去自旋，破坏交错磁化。
