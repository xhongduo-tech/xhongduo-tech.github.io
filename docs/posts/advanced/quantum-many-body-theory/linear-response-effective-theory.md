## 为什么需要有效理论

到目前为止，我们一直从**微观哈密顿量**出发：写出电子气的 $H$，算 Green 函数，求响应函数。但真实的凝聚态体系——哪怕是一片铝、一小块高温超导体——其微观哈密顿量包含 $10^{23}$ 个粒子的所有细节。没有物理学家真的去解它；我们做的是另一件事：**只在低能、长波尺度上问「体系看起来像什么」**。

**有效理论（effective theory）**正是这套思路的数学形式。它的核心思想：把「不重要的高能快变自由度」系统地**积掉（integrate out）**，剩下描述低能物理的「慢变量」与它们之间的有效相互作用。文小刚的《量子多体理论》通篇贯彻这条哲学——**物质的性质不是由微观细节决定的，而是由低能有效理论的结构决定的**，而线性响应正是「探测」有效理论的实验窗口。<span class="marginnote">「积掉高能自由度」是有效理论的灵魂操作：把高能模式对配分函数的贡献以高斯积分「积」掉，代价是得到一个新的、含重整化耦合常数的低能作用量。Wilson 的重正化群正是反复做这件事（本专题第 3 篇《重正化群与临界现象》）。</span>

## 1 快慢分离：有效理论的第一步

设想一个体系，场变量 $\phi$ 有高能分量与低能分量。有效理论的第一步是**快慢分离（fast-slow separation）**：把高能（快）分量 $\phi_h$ 积掉，保留低能（慢）分量 $\phi_l$。配分函数写为：

$$Z = \int \mathcal{D}\phi_l\, \mathcal{D}\phi_h\, e^{-S[\phi_l, \phi_h]} = \int \mathcal{D}\phi_l\, e^{-S_{\text{eff}}[\phi_l]}$$

其中有效作用量：

$$e^{-S_{\text{eff}}[\phi_l]} = \int \mathcal{D}\phi_h\, e^{-S[\phi_l, \phi_h]}$$

**重点：积掉高能自由度不是「扔掉」它，而是把它的影响「吸收」进低能作用量。** 即使高能模式本身无法直接观测，它们也通过重整化低能耦合常数（质量、速度、相互作用强度）而留下痕迹。这就是为什么一块金属的声速、比热、导电性可以用少数几个常数描述，而不需要知道每个离子的精确排列。<span class="marginnote">经典例子：晶格振动的高频光学支模式对低温比热的贡献被指数压低，所以低温下固体「看起来」只有声学声子——光学声子被「积掉」，只剩下有效声子谱。有效理论的合法性来自能量分离：低能观测不分辨高能细节。</span>

## 2 线性响应作为有效理论的窗口

线性响应（Kubo 公式那一套）恰好是探测有效理论的理想工具。微观体系对外场的响应系数（电导、磁化率、极化率）——这些「响应函数」在低能极限下由**有效理论里的耦合常数**决定，而微观细节只通过少数重整化参数进入。

具体来说：线性响应函数 $\chi_{AB}(\omega)$ 在长波极限（$\omega, q\to0$）展开为：

$$\chi_{AB}(\omega) = \chi^{(0)}_{AB} + i\omega\,\chi^{(1)}_{AB} + \omega^2\chi^{(2)}_{AB} + \cdots$$

**重点：这个展开式的每一项都是有效理论里的「基本常数」。** 静态磁化率 $\chi^{(0)}$ 对应有效理论里的刚度系数；电导率 $\sigma = \chi^{(1)}$ 对应耗散系数；$\chi^{(2)}$ 对应「质量」项。实验测出的每一条响应曲线，都在告诉有效理论的耦合常数是什么——**实验 = 有效理论的谱学**。<span class="marginnote">这正是「响应函数包含所有信息」的精确表述：只要测遍所有可能的响应 $\chi_{AB}(\omega)$，原则上就能重建整个低能有效理论。费米液体理论里的 Landau 参数 $F_0^s, F_1^s$ 等，就是通过测量比热、压缩率、有效质量等响应确定的有效耦合常数。</span>

## 3 有效作用量的 Landau-Ginzburg 形式

对「软模」问题（即将发生对称破缺或相变的体系），有效理论有一个通用的标准形式——**Landau-Ginzburg 有效作用量**。设序参量场为 $\phi(\mathbf{x},\tau)$（例如磁化密度），有效作用量在低能极限可展开为：

$$S_{\text{eff}}[\phi] = \int d^d x\,d\tau\Big[\frac{1}{2}(\partial_\tau\phi)^2 + \frac{c^2}{2}(\nabla\phi)^2 + \frac{r}{2}\phi^2 + \frac{u}{4!}\phi^4 + \cdots\Big]$$

其中 $r$ 是「质量项」或「失谐参数」，$u$ 是相互作用强度，$c$ 是模式速度。**重点：这个形式不依赖于具体微观模型**——不管是磁性、超导还是液晶，只要序参量有相同的对称性，低能有效理论就长同一个样子。这就是「普适性（universality）」的起源：相变的临界行为只由对称性与维度决定，与微观细节无关。<span class="marginnote">Landau-Ginzburg 有效理论的合法性来自<strong>对称性分析</strong>：把序参量按体系的对称性分类，写出所有允许的低阶项。这是「有效理论 = 对称性 + 维度 + 低能展开」这一普适公式的第一个实例，后面重正化群会把「临界指数只由对称性决定」的普适性讲得更彻底。</span>

**辨析｜易错点：** 初学者常把有效理论误解为「近似」或「粗化」。其实它是**精确的**（在给定能量截断下）：$S_{\text{eff}}$ 完全编码了低能物理，误差只来自「把高能效应吸收进耦合常数」这一操作本身。近似发生在「截断后只保留最低阶项」这一步——把 $\phi^6$、梯度高次项等忽略。有效理论的方法论是「先精确地降维，再可控地截断」，两者必须分开。

## 4 公式解析：积掉一个高斯模式

用一个可严格完成的最小例子，展示「积掉快变量」的机制。设作用量含快变量 $\psi$ 与慢变量 $\phi$ 的耦合：

$$
S[\phi,\psi] = \int d\tau\Big[\frac{1}{2M}\dot{\phi}^2 + \frac{r}{2}\phi^2\Big] + \int d\tau\Big[\frac{1}{2m}\dot{\psi}^2 + \frac{\omega_0^2}{2}\psi^2 + g\,\phi\psi\Big]
$$

- **第一步，分离**：把 $\phi$ 当固定外场，对 $\psi$ 的积分是高斯积分。对每个频率 $\Omega$，$\psi$ 部分配分函数 $\propto \int\mathcal{D}\psi\,e^{-\frac{1}{2}\int(\Omega^2/m + \omega_0^2)\psi^2 - g\phi\psi}$。
- **第二步，完成高斯积分**：$\int dx\, e^{-\frac{1}{2}ax^2 - bx} = \sqrt{2\pi/a}\,e^{b^2/2a}$，得有效因子 $e^{g^2\phi^2/(2a)}$，其中 $a = \Omega^2/m + \omega_0^2$。
- **第三步，回到作用量**：$S_{\text{eff}}[\phi] = \frac{1}{2M}\dot{\phi}^2 + \frac{1}{2}\big[r - g^2\chi_0\big]\phi^2 + \cdots$，其中 $\chi_0 = \int\frac{d\Omega}{2\pi}\frac{1}{\Omega^2/m+\omega_0^2} = \frac{1}{2\omega_0}\sqrt{m}$。
- **第四步，读出物理**：快变量的存在把慢变量的质量项从 $r$ **重整化**为 $r - g^2\chi_0$。如果 $r$ 本来就小，重整化甚至能把 $r$ 变成负——**这正是一阶相变或失稳的机制**（对称破缺！）。

**重点：积掉快变量 = 用快变量的「极化率」$\chi_0$ 修正慢变量的耦合常数。** $g^2\chi_0$ 项就是「快变量对慢变量的屏蔽/极化反馈」。这个机制在声子软化、超导、磁性里反复出现——**微扰性相互作用通过积掉一个高能圈，改变低能模式的刚度**。

## 5 有效理论与「从极限到大模型」

有效理论是「从极限到大模型」主线的哲学核心。它宣称：**宇宙不需要「从第一性原理解出来」——物质的性质由低能有效理论决定，而有效理论由对称性 + 维度 + 少数参数决定。** 这是「复杂系统可以被理解」的乐观主义基础，也是「从极限到模型」这句话的物理学版本：真正的「模型」从来不是微观哈密顿量，而是有效的低能描述。<span class="marginnote">大模型对这套思想的映射几乎是逐字对应：神经网络被训练到收敛后，其行为可以被一个<strong>低维有效描述</strong>（表征流形、功能电路、scaling law）近似，而具体权重只是「高能细节」。这解释了为什么不同架构的大模型会涌现相似的能力——就像不同的微观模型共享同一个 Landau-Ginzburg 有效理论。可进一步参考第四级《大模型原理》与《涌现》。</span>

对多体理论自身，线性响应与有效理论是通往对称破缺、相变与量子磁性全部篇章的枢纽——下一节，我们先把「低能激发谱」应用到真实材料：**电子-声子相互作用与极化子**，看看电子如何拖着晶格畸变一起运动。

## 6 小结

- **有效理论**把高能快自由度积掉，把低能物理编码进少数重整化耦合常数；它不丢信息，只降维。
- 快慢分离与高斯积分是积掉快变量的标准机制；积掉的效果是**重整化低能耦合常数**。
- **线性响应函数**是探测有效理论的窗口：$\chi(\omega)$ 的长波展开项对应有效理论的基本常数。
- **Landau-Ginzburg 有效作用量**由对称性决定，不依赖微观细节——这是普适性的起源。
- 有效理论先精确降维、再可控截断；「把高能效应吸收进耦合常数」是精确操作，忽略高阶项才是近似。
- 积掉快变量可用快变量的极化率 $\chi_0$ 重整化慢变量刚度，$r \to r - g^2\chi_0$ 是失稳/对称破缺的机制。

在下一节，我们进入真实的相互作用：**电子-声子相互作用与极化子**——晶格振动如何与电子耦合，电子如何拖着一团晶格畸变（极化子）运动，以及这套耦合在超导与电荷密度波里的角色。


## 公式速查：一页纸复习

| 对象 | 公式 | 一句话要点 |
| --- | --- | --- |
| 有效作用量 | $e^{-S_{\text{eff}}[\phi_l]} = \int \mathcal{D}\phi_h\, e^{-S[\phi_l,\phi_h]}$ | 积掉高能自由度，低能耦合常数被重整化 |
| 高斯积分 | $\int dx\, e^{-\frac{1}{2}ax^2 - bx} = \sqrt{2\pi/a}\,e^{b^2/2a}$ | 积掉快变量的标准机制 |
| 重整化质量 | $r \to r - g^2\chi_0$ | 快变量的极化反馈改变慢变量的刚度 |
| Landau-Ginzburg 作用量 | $S = \int d^dx d\tau\big[\tfrac{1}{2}(\partial_\tau\phi)^2 + \tfrac{c^2}{2}(\nabla\phi)^2 + \tfrac{r}{2}\phi^2 + \tfrac{u}{4!}\phi^4\big]$ | 由对称性决定，微观模型无关 |
| 响应展开 | $\chi_{AB}(\omega) = \chi^{(0)} + i\omega\chi^{(1)} + \omega^2\chi^{(2)} + \cdots$ | 长波展开各项 = 有效理论的基本常数 |

**易错复盘**：两点需要特别分清。其一，「有效理论」不是「近似」——积掉高能自由度是精确操作（误差只来自截断后丢弃高阶项）；其二，「快慢分离」的合法性来自能量尺度的分离（$\omega_{\text{high}}\gg\omega_{\text{low}}$），没有分离时有效理论失效——这正是强关联体系（$U\sim W$）无法简单积掉的根源。

**知识连线**：本篇的「积掉快变量 → 重整化耦合常数」是第 2 篇 RPA（把粒子-空穴对积掉得到屏蔽相互作用）与第 3 篇重正化群（反复粗粒化到不动点）的共同母题；Landau-Ginzburg 作用量则是第 3 篇对称破缺与 Goldstone 模的有效理论起点。这条「有效理论」主线贯穿全书。

**思考题**：为什么积掉一个高能声子圈会把电子质量项从 $r$ 改成 $r-g^2\chi_0$？提示：回忆 $\chi_0$ 是快变量的极化率。Landau-Ginzburg 作用量里为什么 $\phi$ 只能以偶次幂出现？提示：考虑 $\phi\to-\phi$ 的对称性。

- 用一句话解释「积掉高能自由度」与「粗粒化」的等价性，并指出误差来源在哪一步。

- 解释为什么 Landau-Ginzburg 有效作用量的系数（$r, u, c$）只依赖对称性与维度，不依赖微观模型。
