## 为什么从文生图开始

文生图是本专题所有知识的一次总检阅：一个 **prompt**（一句话）进去，一幅 512×512 的高清图像出来。**Stable Diffusion（SD）** 在 2022 年 8 月开源，把整套文生图能力交到了每个人手里，直接引爆了生成式 AI 的全民浪潮。它是「潜在扩散模型 + 文本条件 + 大规模工程」三者的合体——本专题前 18 篇铺垫的 VAE、交叉注意力、扩散采样、加速技巧，全部在这条流水线里汇流。

理解 Stable Diffusion，就是理解当代文生图的**标准架构**：一个文本编码器（听懂语言）、一个潜空间自编码器（压缩与还原）、一个条件扩散 UNet（在潜空间里生成）。更重要的，它还引入了**无分类器引导（classifier-free guidance, CFG）**——这个「拉大条件与无条件差异」的小技巧，是文生图质量的决定性开关，也是从扩散模型到一切条件生成的通用增强器。<span class="marginnote">Stable Diffusion 的意义在「开源」二字：它不仅让研究者能复现，更催生了庞大的社区生态——LoRA、ControlNet、检查点（checkpoint）、微调数据集。理解了 SD 的架构，就等于拿到了拆解整个文生图生态的地图。</span>

## 1 全景：一条 prompt 变成一幅图的流水线

Stable Diffusion 的推理流程分四段：

1. **文本编码**：prompt 经分词器切成 token，再经 CLIP 文本编码器变成条件向量 $\tau_\theta(y)$（通常 77 个 token 的嵌入）。
2. **潜空间初始化**：从标准高斯采样一个 $64\times64$ 的潜噪声 $z_T$（对 $512\times512$ 图，下采样因子 $f=8$）。
3. **条件去噪**：在潜空间里用 UNet 迭代 $T$ 步（默认 20–50 步），每步以文本条件通过交叉注意力注入，逐步从噪声「长」出语义潜变量 $z_0$。
4. **解码**：VAE 解码器 $D(z_0)$ 把潜变量还原成像素图像。

这条流水线把「语言」与「图像」接在一起的枢纽是 **CLIP 文本编码器**——它把文本映射到一个与图像特征对齐的向量空间，让「文字描述」与「画面内容」在语义上可算距离。**一个 prompt 的好坏，首先取决于它能否被 CLIP 准确编码**，这解释了为什么「提示词工程」如此重要。<span class="marginnote">CLIP 用海量「图文对」做对比学习，把文本与图像拉进同一向量空间——它的背景在《多模态学习》专题。SD 用的是 CLIP 的文本编码器分支（而非完整模型），只负责「听懂语言」。</span>

## 2 无分类器引导：让模型「更听话」的配方

SD 生成质量的关键开关是 **无分类器引导（classifier-free guidance, CFG）**。训练时，模型既学习「条件去噪」$\varepsilon_\theta(z_t, t, y)$（有文本），也随机把文本置空学习「无条件去噪」$\varepsilon_\theta(z_t, t, \emptyset)$。推理时，把两者按强度 $w$ 拉开：

$$
\hat{\varepsilon}_\theta(z_t, t, y) = \underbrace{\varepsilon_\theta(z_t, t, \emptyset)}_{\text{无条件}} + w\Big(\underbrace{\varepsilon_\theta(z_t, t, y) - \varepsilon_\theta(z_t, t, \emptyset)}_{\text{条件带来的修正方向}}\Big)
$$

拆解三步：

- **第一步，算无条件方向**：模型在「没有文本」时的预测噪声——代表「默认的、不受控的」生成趋势。
- **第二步，算条件修正**：有文本与无文本的噪声差，指向「条件想让生成走向哪里」的方向。
- **第三步，按强度放大**：$w>1$（通常 7 左右）把条件修正放大，让模型更严格服从 prompt；$w$ 过大会导致过饱和、伪影，过小则 prompt 响应弱。

**直觉**：无条件预测是「模型的默认审美」，条件预测是「被 prompt 拽向的方向」，CFG 把「被拽」的程度放大了 $w$ 倍。**它是文生图「质量与服从度」的总开关**，也是负向提示词（negative prompt）的机制基础：把「不要出现的概念」当作无条件的一侧反向引导，就能把「多余的手指」「模糊」等不良内容推离画面。<span class="marginnote">负向提示词的原理：如果你想避免「模糊」，就同时输入「模糊」作为负面条件，让采样沿「远离模糊方向」走——它本质上是一种「排斥性引导」。工程上「负面提示 + 高 CFG」几乎成了通用配方。</span>

## 3 公式解析：从条件去噪到条件扩散训练

Stable Diffusion 的训练目标与 LDM 完全相同，只是把条件具体化为「文本 + 随机置空」：

$$
\mathcal{L} = \mathbb{E}_{z_0,\,y,\,t,\,\varepsilon}\Big[\big\|\varepsilon - \varepsilon_\theta(z_t,\, t,\, \tau_\theta(y))\big\|_2^2\Big] + \underbrace{\mathbb{E}_{z_0,\,t,\,\varepsilon}\Big[\big\|\varepsilon - \varepsilon_\theta(z_t,\, t,\, \emptyset)\big\|_2^2\Big]}_{\text{无条件分支}}
$$

拆解三步：

- **第一步，条件分支**：以文本嵌入 $\tau_\theta(y)$ 为条件预测噪声，学习「文本 → 噪声」的映射。
- **第二步，无条件分支**：以概率（如 10%）丢弃文本、用空标记 $\emptyset$，让模型同时学会无条件去噪——这是 CFG 能工作的训练前提。
- **第三步，联合优化**：两个分支共享同一 UNet，只在条件注入处不同。

**训练细节决定成败**：文本丢弃概率、条件与无条件损失的配比、以及 UNet 的预训练初始化，都是 SD 训练配方里的关键超参数。也正因如此，微调 SD 时「少改训练配方」是社区奉行的金律。

## 4 生态：检查点、LoRA 与组合式创作

Stable Diffusion 开源的真正遗产是**生态**，理解这个生态才能理解当代文生图实践：

- **检查点（checkpoint）**：SD 的完整权重快照。社区微调出大量风格化检查点（动漫、写实、水墨……），每个都建立在「换底座 + 重微调」之上。
- **LoRA（低秩适配）**：用低秩矩阵微调少量参数，注入特定风格或角色，权重文件只有几十 MB——「冻结主干 + 旁路适配」范式在 SD 社区的爆发式应用。<span class="marginnote">LoRA 与 ControlNet 同属「不动主干、注入能力」的 PEFT 家族：ControlNet 注入「结构控制」能力，LoRA 注入「风格/角色」能力，两者可叠加——这解释了为什么设计师能同时挂多个 LoRA 与 ControlNet 组合创作。</span>
**采样器与步数**：DDIM、Euler、DPM-Solver 等采样器决定质量—速度权衡；步数 20–50 是常用区间。
**放大与二次编辑**：高清放大（img2img + 放大）、修复（inpainting）、ControlNet 组合，让一张图可以被反复精修成作品。

**SD 版本演进**也是一部「文生图发展史」：SD 1.5（2022）奠定基础，SD 2.x 换了更大数据与文本编码器，**SDXL**（2023）升级为双文本编码器 + 更大 UNet + 更好的构图，**SD 3 / Flux**（2024）转向流匹配（rectified flow）与扩散 Transformer（DiT）——架构在变，但「文本编码 + 潜空间 + 条件去噪 + 解码」的流水线骨架始终未变。<span class="marginnote">Flux、SD3 引入的扩散 Transformer（DiT）把 UNet 换成 DiT，用纯注意力架构在潜空间做去噪——这是「扩散 + Transformer」的合流，也让文生图与大语言模型在架构上更加同构，详见本专题《多模态生成》篇。</span>

## 5 文生图在课程体系中的位置

文生图是本专题的「成果验收站」：

- **输入侧**：文本理解来自《大模型原理》的语言模型与《多模态学习》的 CLIP。
- **生成侧**：潜空间压缩来自 VAE 系，条件去噪来自扩散系，少步加速来自一致性/流匹配系。
- **工程侧**：采样器、CFG、LoRA、ControlNet，全部是前文每一篇概念的工程化产品。

从「极限到大模型」的主线看，文生图示范了「语言与视觉如何在一个统一生成框架里协同」：语言提供抽象意图，扩散提供具体像素。而这条「从语言到多模态」的路径，正通向本专题最后的大模型生成与前沿篇章——视频、3D、音乐、多模态。**Stable Diffusion 是「单模态条件生成」的终点，也是「多模态统一生成」的起点**。

## 6 提示词工程：为什么 prompt 有效

理解了 SD 的架构，就能理解「提示词工程」到底在优化什么——它不是玄学，而是在「摸清 CLIP 文本编码器的脾气」。

**第一，CLIP 是「压缩器」。** prompt 先被切成 token（最多 77 个），再被 CLIP 编码成一个固定向量。**信息在编码时被压缩了**：写得太长、太啰嗦、太抽象的描述，会在编码阶段丢失细节。所以「一个词一个词地精简、突出关键词」有用——它在帮你保住压缩后仍在场的语义。

**第二，交叉注意力是「检索器」。** 图像潜空间的每个位置通过 attention 从文本 token 里「检索」信息。于是：

- **主体词靠前、用逗号分隔**，让每个概念都有独立的注意力权重；
- **「戴红帽子的猫」vs「猫戴着红帽子」**——语序影响注意力分布，稳定的句法更利于稳定生成；
- **权重词（如「杰作」「最佳质量」）** 在 CLIP 编码后成为「全局风格向量」，压低采样熵。

**第三，负向提示词是「推离器」。** 与 CFG 机制直接绑定：把「模糊、低质量、多余肢体」写进负向 prompt，采样时沿「远离这些概念」的方向走。**负向 prompt 的质量与正向同等重要**——它们是同一枚硬币的两面。

**辨析｜易错点：** 提示词工程**不能创造模型没有的能力**——它只能「更充分地调用已有能力」。如果模型从没见过「水豚穿宇航服」，任何 prompt 都难画出可信效果。**prompt 是「放大器」不是「造物主」**——理解这条边界，就不会把「prompt 不好用」误判为「模型不行」，也不会对 prompt 抱有过高期待。把 Stable Diffusion 的实践要点再收几条：

- 流水线四段：文本编码 → 潜空间采样 → 条件去噪 → 解码。
- CLIP 是「压缩器 + 翻译官」：prompt 的每个词都要能被它精准编码。
- CFG 是质量总开关：$w\approx7$ 常见，过高过饱和、过低不听话。
- 负向提示词 = 排斥性引导：把「不要的」写进去，采样沿反方向走。
- 采样器与步数：20–50 步 + DDIM/欧拉是默认起跑线。
- LoRA 与 ControlNet 可叠加：一个注入风格、一个注入结构，可组合创作。
- 架构演进：UNet → DiT、扩散 → 流匹配，但「四段式」骨架不变。
- 提示词工程的本质：把意图「翻译」成 CLIP 熟悉的句法，让编码向量落在目标区域。
- prompt 是放大器不是造物主：模型没有的能力，prompt 变不出来。
- 随机种子控制构图：同一种子可复现，换种子改布局。
- 课程启示：文生图是「语言意图 → 像素实现」的完整案例，贯通全专题。

## 7 小结

- **Stable Diffusion 流水线**：CLIP 文本编码 → 潜空间采样 → 条件去噪 UNet（交叉注意力）→ VAE 解码。
- **无分类器引导（CFG）** 放大「条件修正方向」，是质量与服从度的总开关，也是负向提示词的机制基础。
- 训练需同时学条件与无条件分支（文本随机置空），这是 CFG 能用的前提。
- **生态**：检查点、LoRA、ControlNet、采样器、放大工具构成组合式创作栈。
- 架构演进：UNet → DiT、扩散 → 流匹配，但「文本编码 + 潜空间 + 条件去噪 + 解码」骨架不变。
