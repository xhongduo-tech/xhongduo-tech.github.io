## 为什么从潜在扩散模型开始

DDPM 在像素空间直接扩散，一张 $512\times512$ 的图像就有 78 万个像素维度——在这么高的维度上跑上千步扩散，训练与推理都昂贵得难以工业化。**潜在扩散模型（latent diffusion model, LDM）** 的解法一句话就能说清：**先用 VAE 把图像压缩成一个低维潜在表示，再在潜空间里跑扩散**。它把扩散模型从「像素空间」搬进「表示空间」，计算量骤减一个数量级，也因此成为 Stable Diffusion 的理论内核，成就了 2022 年至今的文生图浪潮。

LDM 的地位远不止「加速」。它把本专题前面两条线——**VAE 的潜空间压缩**与**扩散的稳定生成**——完美焊接：VAE 负责「理解什么值得保留」（感知压缩），扩散负责「在压缩后的空间里创造」。这种「先压缩、再生成」的分层结构，后来被视频生成、3D 生成普遍复制。<span class="marginnote">LDM 的两个组件各司其职：自编码器（AE）做「有损感知压缩」——丢弃人眼不敏感的高频细节，保留语义结构；扩散模型在压缩后的潜空间做「生成」——因为空间维度低，训练与采样都便宜得多。</span>

## 1 为什么在像素空间扩散不划算

回到扩散模型的计算账本：训练时每个样本要前向网络一次，采样时要迭代 $T$ 步。**成本 ≈ 每步的计算量 × 步数**，而每步计算量与输入维度直接相关。像素空间的高维带来三重代价：

**训练显存爆炸**：高分辨率图直接喂网络，batch 与网络容量互相挤兑。
**采样慢**：$T$ 步 × 高维前向，实时性无从谈起。
**冗余计算**：图像有大量人眼不敏感的高频冗余，网络却要在这些冗余上花同等算力。

**关键直觉**：扩散模型真正要学的不是「每个像素的噪声」，而是「图像的语义结构」。像素级扩散把大量算力浪费在无关紧要的纹理上。那么，能不能先让一个「感知压缩器」把冗余丢掉，只保留语义，再在压缩后的空间生成？这正是 LDM 的回答。

## 2 LDM 的三段式架构

LDM 把生成拆成三个模块：

1. **编码器 $E$**：把图像 $x\in\mathbb{R}^{H\times W\times 3}$ 压缩成潜表示 $z=E(x)\in\mathbb{R}^{h\times w\times c}$，其中 $\frac{H}{h}=\frac{W}{w}$ 是下采样因子 $f$（Stable Diffusion 用 $f=8$，维度降了 64 倍）。
2. **扩散模型**：在潜空间跑标准的去噪扩散——前向加噪、逆向去噪都发生在 $z$ 上。
3. **解码器 $D$**：把生成的潜表示 $z_0$ 解码回像素图像 $\tilde{x}=D(z_0)$。

**压缩不是越小越好**：$f$ 太大（潜空间太挤）会丢失细节，生成模糊；$f$ 太小（压缩不足）则失去加速意义。LDM 在下采样因子 $f=4,8,16,32$ 之间做了权衡实验，发现 **$f=8$ 在质量与速度之间最优**——这是一个典型的「感知压缩率」工程权衡。<span class="marginnote">LDM 的自编码器用「感知损失 + 对抗损失」训练（而非纯 L2）：感知损失让重建在特征空间接近，对抗损失让重建锐利。这正是 VQ-GAN 与 LDM 共享的「感知 + 对抗」重建配方，补上了 VAE 重建模糊的老毛病。</span>

## 3 公式解析：潜空间里的去噪训练

LDM 的训练目标几乎就是 DDPM 的 MSE，只不过作用在潜表示上：

$$
\mathcal{L}_{\text{LDM}} = \mathbb{E}_{z\sim E(x),\, \varepsilon\sim\mathcal{N}(0,I),\, t}\Big[\big\|\varepsilon - \varepsilon_\theta(z_t,\, t,\, \text{cond})\big\|_2^2\Big]
$$

拆解四步：

- **第一步，编码**：$z=E(x)$ 把图像压进潜空间，训练时缓存或即时计算。
- **第二步，加噪**：$z_t = \sqrt{\bar{\alpha}_t}\,z + \sqrt{1-\bar{\alpha}_t}\,\varepsilon$，与 DDPM 完全相同的闭式加噪。
- **第三步，条件注入**：$\varepsilon_\theta$ 接收 $\varepsilon_\theta$——类别、文本等条件信号。
- **第四步，MSE**：预测噪声与真实噪声比对。

**这里训练与推理的关键差异**：模型始终在低维潜空间工作。Stable Diffusion 的 UNet 处理的是 $64\times64$ 的潜特征图（对 $512\times512$ 图），相比像素空间维度降了 64 倍，显存与算力压力天差地别。**这就是 LDM 能把扩散模型从「实验室」推向「产品」的核心杠杆**。

## 4 条件注入：用交叉注意力把文本接进来

LDM 作为文生图引擎，最关键的设计是**条件注入**。它不在输入处简单拼接，而是在 UNet 的每一层用**交叉注意力（cross-attention）**把文本条件「织」进图像特征：

$$
\text{Attention}(Q, K, V) = \mathrm{softmax}\Big(\frac{Q K^{\top}}{\sqrt{d}}\Big) V, \qquad Q = W_Q\, \varphi(z_t),\; K = W_K\, \tau_\theta(y),\; V = W_V\, \tau_\theta(y)
$$

拆解三要素：

- **Query 来自图像**：$z_t$ 经投影得到 $Q$——潜空间每个位置「想知道什么信息」。
- **Key 与 Value 来自条件**：文本 $y$ 经文本编码器 $\tau_\theta$ 得到 $K,V$——「条件提供了什么信息」。
- **attention 加权融合**：图像每个位置从文本 token 里「检索」最相关的语义，融合进特征。

**交叉注意力让「文本描述」能够以任意粒度影响生成的每个位置**——「一只戴红帽子的猫」的「红帽子」会通过 attention 权重精确地落在画面中帽子的位置附近。这是 Stable Diffusion 能精准响应复杂 prompt 的机制基础，也是后续一切「用注意力做条件」的扩散模型的标准件。<span class="marginnote">交叉注意力的引入，把「条件生成」从「拼接向量」升级成「内容感知的检索式融合」——图像特征主动去文本里找自己要的东西。这个设计与《大模型原理》里的 cross-attention（编码器—解码器）是同一种运算在不同模态间的复用。</span>

## 5 LDM 的应用矩阵与课程坐标

LDM 是一个通用框架，换条件、换目标，就能派生出无数应用：

| 任务 | 条件 | 代表系统 |
| --- | --- | --- |
| 文生图 | 文本 | Stable Diffusion |
| 图像修复（inpainting） | 掩码 + 周围像素 | SD Inpainting |
| 超分辨率 | 低分辨率图 | LDM-SR |
| 图像翻译 | 结构图/深度图 | ControlNet（下一篇） |
| 视频生成 | 文本 + 帧序列 | 视频 LDM |

**LDM 的教学意义**在于它是「分层生成」的样板：**感知压缩层 + 生成层 + 解码层的三段式**。这启发了后来的视频扩散（先在低维时空潜空间生成）、3D 扩散、以及「先粗后细」的分级生成策略。<span class="marginnote">从「极限到大模型」主线看，LDM 把「表征学习」与「生成学习」明确分成两层——压缩层负责「懂」，扩散层负责「创」。这个「先懂后创」的分层，在大模型里同样成立：tokenizer 负责「懂」文本，Transformer 负责「创」文本。</span>

## 6 LDM 的工程实践要点

LDM 是「理论简洁、工程繁复」的典型：架构三句话能讲完，但让它在真实数据上稳定训练，需要一系列精心设计的细节。

**要点一：条件丢弃（conditioning dropout）。** 训练时以一定概率（如 10%）把条件置空（文本置为空白、类别置为 None）。这不是缺陷而是刻意设计——它让模型同时学会「无条件去噪」，是推理时 CFG 能工作的前提。**没有条件丢弃，就没有 CFG**——这条因果链在 Stable Diffusion 训练代码里写得很清楚。

**要点二：先训自编码器，再训扩散。** LDM 是「两阶段」训练：第一阶段单独训练感知自编码器（编码器 + 解码器，用感知损失 + 对抗损失），让它把图像压进高质量的潜空间；第二阶段冻结自编码器，只在固定潜空间里训练扩散模型。**两阶段解耦的好处**：潜空间质量与生成质量可以分别调优，且扩散训练不用背负「重建好图像」的负担。

**要点三：KL 正则 vs 量化。** LDM 论文对比了「KL 正则潜空间」（类似 VAE，连续）与「VQ 潜空间」（VQ-VAE，离散）两种自编码器，发现**两者在最终生成质量上差别不大**，但行为略有差异——KL 版潜空间更平滑、适合插值，VQ 版更利于后续做「离散 token 建模」。Stable Diffusion 最终选了 KL 正则版。

**要点四：跨注意力维度的选择。** UNet 每个层的交叉注意力把图像特征「检索」文本信息；特征分辨率越低、文本 token 越多，注意力成本越高。工程上常限制文本 token 数（SD 用 77）并在高分辨率层跳过交叉注意力，以平衡质量与显存。

这些要点共同传递一个信号：**LDM 的成功一半是「把 VAE 与扩散焊在一起」的思想，另一半是「两阶段训练 + 条件丢弃 + 注意力裁剪」的工程**——思想与工程缺一不可。把 LDM 的工程要点再压缩成几条速记：

- 两阶段训练：先训感知自编码器，再冻结它训扩散——解耦使两者可分别调优。
- 条件丢弃（约 10%）是 CFG 的前提：没有无条件分支就没有引导。
- KL 潜空间连续平滑，适合插值；VQ 潜空间离散，适合 token 建模。
- 交叉注意力在低分辨率层注入文本，高分辨率层常跳过以省显存。
- 下采样因子 $f=8$ 是质量—速度平衡的工程经验值。
- 潜空间是「语义操作空间」：插值、加方向向量都可解码出语义渐变。
- 与 VAE 的承接：感知损失 + 对抗损失补上了 VAE 重建模糊的老毛病。
- 与扩散的承接：在低维潜空间跑扩散，维度降 64 倍，算力压力骤减。
- 生态影响：Stable Diffusion 的整个社区都建立在「冻结潜空间 + 条件扩散」之上。
- 课程启示：先压缩、再生成的分层结构，被视频、3D 普遍复制。

## 7 小结

- **LDM 的核心**：用 VAE 把图像压缩成低维潜表示，再在潜空间跑扩散——计算量降一个数量级，是 Stable Diffusion 的内核。
- **感知压缩**靠自编码器（感知损失 + 对抗损失），下采样因子 $f=8$ 是质量与速度的最佳平衡。
- **训练目标**与 DDPM 相同，只是作用在 $z=E(x)$ 上；条件通过**交叉注意力**在每层注入。
- **交叉注意力**让文本条件精确影响生成内容，是文生图响应 prompt 的机制基础。
- 三段式架构（压缩—生成—解码）被视频、3D 等后续生成领域普遍复制。

在下一节，我们把「条件」从文本扩展到**结构控制**：如何用边缘、深度、姿态草图精确指挥扩散模型，又不破坏其生成能力——这就是 **ControlNet** 与条件扩散的艺术。
