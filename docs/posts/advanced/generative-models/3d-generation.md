## 为什么从 3D 生成开始

图像、视频生成的是**观测**，3D 生成要生成**世界本身**——一个可以被任意角度观察、被光照、被动画、被放进游戏引擎或打印成实物的三维物体。这项任务的独特难点在于：**「3D 正确」比「2D 好看」苛刻得多**。一张图可以只满足一个视角；一个 3D 物体必须在所有视角下都自洽——正面是狮子，侧面也必须还是同一只狮子。

3D 生成的挑战还在于**数据**：互联网上海量的 2D 图像唾手可得，但高质量的 3D 模型却稀缺昂贵。这个「数据鸿沟」决定了 3D 生成的技术路线与 2D 截然不同——它必须学会**从 2D 观测中「逆推」3D 结构**。2022 年的 DreamFusion 用一条「分数蒸馏采样（SDS）」把预训练 2D 扩散模型的先验「搬」进 3D 空间，让「一句话生成一个 3D 模型」成为可能——这是 3D 生成史上最重要的范式突破。<span class="marginnote">3D 生成的「表示」问题几乎与「生成算法」同等重要：用体素、点云还是隐式函数？表示决定了你能生成什么、怎么优化。2020 年代 NeRF 与 SDF 等隐式表示大放异彩，是 3D 生成能起飞的地基。</span>

## 1 3D 的表示：生成什么、以什么形式

生成 3D 内容前，先要选定「3D 的表示形式」。五种主流表示各有权衡：

| 表示 | 形式 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 体素（voxel） | 3D 网格 | 直观、易卷积 | 分辨率受立方增长限制 |
| 点云（point cloud） | 离散点集 | 稀疏、便宜 | 无表面信息、难渲染 |
| 网格（mesh） | 顶点 + 面 | 工业标准、可动画 | 拓扑固定、难优化 |
| NeRF | 连续辐射场 | 可微渲染、高质量 | 推理慢、难提取表面 |
| 隐式 SDF | 距离场 | 表面光滑、可提取 mesh | 需大量采样 |

**关键观察**：不同表示适合不同生成方法。体素、点云适合**判别式/扩散式生成**（直接预测网格上的值）；NeRF、SDF 适合**基于优化的生成**（用一个 3D 表示 + 可微渲染器，通过「渲染出的 2D 图与目标 2D 图比对」来优化 3D 参数）。后者正是「从 2D 先验逆推 3D」的技术基础。<span class="marginnote">NeRF 的核心是「可微渲染」：把 3D 场景参数化成一个网络，渲染过程本身可导，于是「让渲染图逼近目标图」的梯度能一路传回 3D 参数。这一「渲染可微」的杠杆，是 3D 生成一切优化方法的支点。</span>

## 2 三条技术路线：从原生 3D 到 2D 先验

3D 生成的历史上有三条递进路线：

**路线一：原生 3D 生成模型**——直接学习 3D 数据分布。3D-GAN 用体素做 GAN，Point-E 用扩散模型在点云上生成。优点：直接、天然多视图一致；缺点：**受限于稀缺的 3D 训练数据**，多样性受限。

**路线二：多视图生成 + 3D 重建**——先用 2D 扩散生成一个物体的多个视角图，再用 3D 重建算法（如 NeRF）把它们合成 3D 模型。优点：复用 2D 先验；缺点：多视图之间容易不一致，重建后「正面狮子、背面怪物」。

**路线三：分数蒸馏采样（SDS）**——不生成多视图，而是让 3D 表示**直接接受 2D 扩散模型的分数「指导」**，每个视角都按「2D 扩散认为这是什么」来优化。DreamFusion 的这条路线同时解决「数据稀缺」与「多视图不一致」——**把 3D 优化问题变成「让所有视角的渲染图都通过 2D 扩散的审查」**。<span class="marginnote">三条路线反映了「3D 数据稀缺」这一根本约束的三种应对：硬学（路线一）、拼凑（路线二）、借力（路线三）。借力 2D 先验成为主流，因为它把「巨大的 2D 生成能力」直接输送给 3D，而不需要等 3D 数据积累。</span>

## 3 公式解析：分数蒸馏采样（SDS）

SDS 是 DreamFusion 的心脏，它让一个 3D 表示 $\theta$ 通过「渲染出图像、接受 2D 扩散打分」来优化。梯度形式：

$$
\nabla_\theta \mathcal{L}_{\text{SDS}} = \mathbb{E}_{t,\,\varepsilon}\Big[w(t)\big(\varepsilon_\phi(z_t,\, t,\, y) - \varepsilon\big)\frac{\partial z}{\partial \theta}\Big]
$$

拆解四步：

- **第一步，渲染并加噪**：从当前 3D 参数 $\theta$ 渲染一个随机视角的图像，用 VAE 编码成潜变量 $z$，再按扩散前向加噪到 $z_t$。
- **第二步，2D 扩散「审查」**：把带噪潜变量与文本条件 $y$ 喂给预训练 2D 扩散模型 $\varepsilon_\phi$，让它预测噪声——**预测误差 $\varepsilon_\phi-\varepsilon$ 反映了「这张渲染图有多不像（文本所描述的）真实分布」**。
- **第三步，误差反传**：把这个误差当作「指导信号」，沿 $\frac{\partial z}{\partial \theta}$ 回传——**2D 模型说「哪里不对」，3D 参数就往「更对」的方向改**。
- **第四步，权重 $w(t)$**：不同噪声时刻的误差加权，控制「粗结构」与「细纹理」的优化节奏。

**SDS 的巧妙**在于它不要求 2D 扩散输出图像，只要求它给出「分数」（噪声误差）——这个分数像一位「永不疲倦的 2D 评审员」，盯着每一个视角的渲染图说「这里还不对」。于是 **3D 优化被拆成无数个「单视角的 2D 生成问题」**，2D 先验的力量被彻底激活。<span class="marginnote">SDS 的直觉：DreamFusion 不做「先生成多视图再拼」，而是让 3D 模型自己「想象」每个视角下应该长什么样，再让 2D 扩散来纠正想象。这个「想象—纠正」循环，本质上是把 2D 扩散当成了 3D 优化的可微监督器。</span>

## 4 SDS 的问题与后续进化

SDS 不是终点，它带来两个著名顽疾：

- **过饱和（oversaturation）**：2D 扩散会「夸大」颜色与纹理，生成的 3D 模型常色彩过艳、表面「烤焦」。原因：SDS 用噪声误差做监督，对每个视角独立打分，缺乏「多视角一致的全局约束」。
- **Janus 问题（多面神）**：模型学出「每个视角都想生成一张正脸」，于是 3D 物体出现多个正面（如雕像前后都是脸）——因为 2D 扩散只见过「正面为主」的图像分布。

后续工作沿「修正这两点」进化：**ProlificDreamer（VSD，变分分数蒸馏）**用更精细的分布匹配替代单一分数；**Zero-1-to-3** 直接训练「新视角合成」扩散模型，让多视角天然一致；**MVDream** 用多视图扩散模型让各视角共享注意力；还有 **3D Gaussian Splatting** 把 3D 表示从 NeRF 换成可实时渲染的高斯点云，让 3D 生成的速度与质量同时跃升。<span class="marginnote">3D Gaussian Splatting（2023）是 3D 领域的技术新星：用数百万个带颜色的高斯椭球表示场景，渲染速度远超 NeRF，配合扩散先验能在几分钟内重建一个 3D 场景。它让「3D 生成」从「离线渲染」走向「实时交互」。</span>

**2024 年的趋势**是「3D 扩散直接生成 + 实时渲染」：用 3D 扩散模型（如基于点云、三平面或 latent 3D 的扩散）端到端生成 3D 表示，再用 Gaussian Splatting 实时渲染——「从文本到可交互 3D 资产」的延迟被压到秒级。

## 5 3D 生成在课程体系中的位置

3D 生成是「生成模型 × 几何 × 渲染」的交汇点：

- **前置**：隐式表示与可微渲染来自《计算机图形学》（NeRF、体渲染）；分布的生成来自本专题全部内容；条件注入复用 CLIP 文本对齐。
- **与视频的共通**：3D 与视频都面临「多视角/多帧一致性」——视频是「时间一致」，3D 是「视角一致」，两者的技术（注意力跨视角、跨帧）互相借鉴。
- **与具身的接口**：3D 生成是《具身智能》的资产供给——机器人训练需要大量 3D 场景与物体，生成式 3D 正在成为合成数据的主力。<span class="marginnote">从「极限到大模型」主线看，3D 生成是「世界模型」拼图的关键一块：机器若能在头脑中生成三维世界，就获得了「想象空间」的能力——这在规划、导航、科学可视化中都有深远价值。</span>

## 6 3D 生成的评估：多视角的裁决

3D 生成的评估有自己独特的两难：**3D 内容要「从所有角度看都好」，但评估的人只有「2D 的眼睛」**。这个矛盾塑造了 3D 评估的整套方法论。

**评估的三个层次：**

- **多视角渲染 + 2D 指标**：把 3D 模型渲染成多个视角的 2D 图像，再用图像指标（FID、CLIP 分数）评估。优点：复用成熟的 2D 评估工具；缺点：**视角采样有偏**——只渲染「好看的视角」，能掩盖「背面崩坏」。
- **几何质量**：对能提取 mesh 的表示，评估「表面光滑度」「拓扑正确性」「几何对称性」——这类指标测「形状对错」，是 3D 特有的。
- **多视角一致性**：从不同角度渲染同一物体，检验「是不是同一个东西」。这正是 3D 生成的核心质量——正面像狮子、侧面也必须像狮子。

**实践中的关键指标是 CLIP 类指标**：把「文本描述」与「多视角渲染图」都编码进 CLIP 空间，算匹配分数——它同时测「是否符合 prompt」与「各视角是否语义一致」。但 CLIP 指标对「Janus 多面神」问题并不敏感——模型可能在每个视角都渲染出「很狮子」但形状诡异的图，CLIP 分数照样高。<span class="marginnote">「CLIP 分数高 ≠ 3D 好」这个坑，几乎每个做文生 3D 的人都踩过：CLIP 看的是「语义匹配」，不是「几何合理」。所以严谨的 3D 评测必须「CLIP 分数 + 多视角人工抽检」双管齐下。</span>

**一句话总结 3D 评估的困境**：指标能测「语义对不对」，难测「几何对不对」；能测「单视角好不好」，难测「全视角一致」。这决定了 3D 生成的研究进展，往往要靠「渲染出 GIF 给人看」来判定——**当自动指标不够用时，人眼仍是最终裁决**。把 3D 生成的要点再收几条：

- 表示决定路线：体素/点云适合直接生成，NeRF/SDF 适合优化式生成。
- 数据鸿沟是根本约束：3D 数据稀缺，必须借力 2D 先验。
- SDS 把 3D 优化拆成单视角 2D 问题：用扩散分数做可微监督。
- Janus 问题：多视角独立打分导致「多个正面」，需多视图一致性约束。
- 过饱和：2D 扩散「夸大」颜色纹理，需 VSD 等改进。
- 3D Gaussian Splatting：可实时渲染的表示，让 3D 从离线走向交互。
- 评估分三层：多视角渲染 + 几何质量 + 多视角一致性。
- 表示与评估互相锁定：选 NeRF 表示，就被迫接受「多视角渲染评估」的不完备。
- CLIP 分数高 ≠ 3D 好：CLIP 测语义匹配，不测几何合理。
- 可用性是终极维度：能否导入引擎、能否被编辑、渲染效率如何。
- 多视图路线：先生成多视角图再重建，「正面狮子背面怪物」的风险仍在。
- 三平面 / latent 3D：把 3D 压成 2D 平面表示，复用 2D 架构。
- 从 2D 到 3D 的迁移：潜空间扩散、条件注入、少步采样全部可复用。
- 与视频的共通：视频求「时间一致」，3D 求「视角一致」。
- 与具身的接口：3D 生成为机器人训练供给合成数据。
- 世界模型拼图：能生成三维世界，就获得「想象空间」的能力。
- 趋势：3D 扩散直接生成 + 实时渲染，延迟压到秒级。

## 7 小结

- **3D 生成**的独特难点是「所有视角自洽」与「3D 数据稀缺」。
- **表示选择决定路线**：体素/点云适合直接生成，NeRF/SDF + 可微渲染适合优化式生成。
- 三条路线：原生 3D 生成、多视图 + 重建、**SDS 分数蒸馏**（借力 2D 扩散先验，当前主流）。
- **SDS** 用 2D 扩散的噪声误差作可微监督，把 3D 优化拆成无数单视角 2D 问题。
- 顽疾：过饱和与 Janus 多面神；进化：VSD、多视图扩散、3D Gaussian Splatting 实时渲染。
