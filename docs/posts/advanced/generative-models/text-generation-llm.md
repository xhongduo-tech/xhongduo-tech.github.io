## 为什么从文本生成与大语言模型衔接开始

本专题从「概率生成模型的分类树」出发，一路走过 VAE、GAN、归一化流、扩散——现在回到树根处那棵最朴素、也最庞大的枝干：**自回归**。大语言模型（LLM）本质上是生成模型家族里最成功的成员：它用「预测下一个 token」这一最朴素的链式法则，在万亿级数据上练出了能续写、能对话、能写代码、能推理的能力。从生成模型的视角看，**LLM 没有什么神秘的新原理——它是自回归模型 + 最大似然 + 规模效应三者相乘的结果**。

这一节承担「衔接」职责：把 LLM 放回生成模型的理论框架里，澄清「LLM 的生成」与「我们前面学的生成模型」之间的继承与差异。你会看到，temperature、top-p、beam search 这些「解码策略」，本质上都是「如何从一个学好的条件分布 $p(x_t\mid x_{\\lt t})$ 里采样」的不同选择——而「采样」正是本专题第一篇就埋下的主题。<span class="marginnote">衔接的意义在于：图像领域的扩散模型与文本领域的自回归 LLM，看似分属两个世界，其实共享同一套生成哲学——学分布、按分布采样。理解这个共性，才能看懂多模态生成（本专题《多模态生成》）如何把两者统一起来。</span>

## 1 语言模型就是条件分布生成

把文本看成一个 token 序列 $x_1, x_2, \dots, x_T$，语言建模的目标与自回归生成模型完全一致——最大化整个序列的联合概率，按链式法则分解：

$$
p(x_1,\dots,x_T) = \prod_{t=1}^{T} p(x_t \mid x_1,\dots,x_{t-1})
$$

**LLM 的全部能力都建立在「估计 $p(x_t \mid x_{\\lt t})$」这一件事上**。训练时用交叉熵损失最大化逐位对数概率，这与 PixelCNN 对图像做的事情在数学上完全同构，只是把「像素」换成「token」。<span class="marginnote">「语言模型」这个名称来自统计语言建模的传统：n-gram 模型（见第二级《NLP》/《大模型原理》）用词频近似 $p(x_t\mid x_{\\lt t})$，神经网络语言模型用网络参数逼近同一个分布。LLM 只是把「模型容量」与「训练数据」推到了极限。</span>

从生成模型分类树的视角看，LLM 同时踩中两个位置：

- **自回归支**：显式可解密度，精确最大似然——这是它在「似然可算」上的血统。
- **隐变量支**：每一层的隐藏状态就是隐变量，注意力机制隐式地在「条件依赖」上做选择。

这解释了为什么 LLM 训练稳定、可扩展——它没有 GAN 的博弈不稳定，也没有扩散的多步采样负担，只有最简单的「下一步预测」。**它的代价是串行生成**：一个 token 一个 token 地吐，速度受制于序列长度。

## 2 生成循环：从概率分布到一句回答

LLM 的推理是一个**自回归循环**：

1. 把已生成的 token 序列（prompt + 已输出）喂给模型；
2. 模型前向一次，输出下一个 token 的概率分布 $p(x_t\mid x_{\\lt t})$（softmax 层，维度 = 词表大小）；
3. 按某种**解码策略**从分布中选出一个 token；
4. 把新 token 拼回序列，回到第 1 步，直到遇到结束符 `<eos>`（end-of-sequence）或达到最大长度。

这个循环里的每一步都是「从分布里抽一个符号」——**选 token 的方式，就是解码策略**。它们可以粗暴地分成两类：**确定性**（每次都选最可能）与**随机性**（按概率抽样）。

| 解码策略 | 机制 | 特点 |
| --- | --- | --- |
| 贪心解码 | 每次取概率最大 token | 快、但易重复/平庸 |
| Beam Search | 维护 $k$ 条最优候选序列 | 适合翻译等追求最优解的任务 |
| Temperature 采样 | 软化/锐化分布后抽样 | 控制随机性，常用 |
| Top-k 采样 | 只在概率最高的 $k$ 个里抽 | 过滤长尾噪声 |
| Top-p（核采样） | 只在前 $p$ 概率质量里抽 | 自适应截断，最常用 |

**辨析｜易错点：** 「贪心」不等于「最好」——逐位置最优点组合起来常是最平庸或重复的句子；beam search 追求「全局高概率」却可能让文本机械平淡。**文本生成的艺术恰恰在「适当的随机」**：语言是多样性的，最可能的下一词往往不是人类最想要的下一词。

## 3 公式解析：Temperature 与核采样

**Temperature 采样**通过调整 softmax 的温度参数 $\tau$ 控制分布「锐利度」：

$$
p(x_t = v \mid x_{\\lt t}) = \frac{\exp\big(z_v / \tau\big)}{\sum_{v'} \exp\big(z_{v'} / \tau\big)}
$$

拆解三步：

- **第一步，logits 缩放**：模型输出的 logits $z_v$ 除以温度 $\tau$。$\tau$ 越小，logits 差距被放大，分布越尖；$\tau=1$ 是原始 softmax；$\tau\to 0$ 退化为贪心。
- **第二步，softmax 归一化**：仍是合法概率分布。
- **第三步，抽样**：从该分布中随机抽取一个 token。$\tau>1$ 时分布变平，低概率词被「解冻」，输出更多样但也更散乱。

**核采样（top-p / nucleus sampling）** 是另一种截断：把所有 token 按概率降序排列，取累计概率刚好达到 $p$（如 0.9）的最小集合，**只在这个集合里归一化后抽样**——它自适应当前分布的形态：分布尖锐时截断很小，分布平坦时截断很大。

工程实践常用「temperature + top-p」组合：temperature 控制整体随机性，top-p 负责剪掉长尾噪声。**一套好的解码策略，往往比换更大的模型更立竿见影地提升生成质量**。

## 4 生成计算：为什么 LLM 生成慢

自回归的代价在推理时格外突出：生成 $T$ 个 token 需要 $T$ 次前向，而每次前向都要重算之前 token 的注意力。工程上有两个关键优化：

- **KV 缓存（KV cache）**：缓存每个已生成 token 的 Key/Value 向量，后续 token 只算新位置的注意力，不必重算历史——把生成从「每步全量重算」降为「每步只算一步」。
- **并行解码**：投机解码（speculative decoding）用小模型「猜」一串候选 token，大模型一次验证；批量解码一次处理多条序列。

**「文本生成慢」是自回归的结构性代价**，这与扩散模型的「多步采样慢」是两种不同性质的慢：前者受「序列长度 × 步数」约束，后者受「固定步数」约束。大模型推理优化（量化、KV cache、投机解码）是第四级《大模型部署》的专题内容，这里只需记住：**生成速度问题归根结底是「串行依赖」问题**。<span class="marginnote">有趣的是，图像扩散模型也曾面临同样的「多步串行」困境，最终靠「少步采样 + 流匹配」突围；文本自回归的「串行」则靠「投机解码 + 并行验证」缓解——两个领域在「减少串行步骤」上殊途同归。</span>

## 5 LLM 作为生成模型的「溢出效应」

从生成模型的视角看 LLM，有几个值得留意的现象：

**「涌现」不是新损失**：训练目标始终是「预测下一个 token」，但参数量与数据量跨过阈值后，推理、代码、指令遵循等能力「涌现」。这更像**分布学习到极致后的组合泛化**，而非目标函数改变。
**采样即创造力**：temperature 调低，LLM 输出「确定性、可靠」；调高，输出「多样、发散」。**同一模型，不同的解码策略就是不同的人格**——这与扩散模型的「随机种子」控制同出一辙。
**对齐是一种「重定向分布」**：RLHF、指令微调本质上都在**重新塑造 $p(x_t\mid x_{\\lt t})$ 的条件分布**，让模型从「续写」转向「遵循意图」——这是生成模型「条件」思想在安全维度的延伸，见本专题《生成模型的可控性》《安全与版权》两篇。<span class="marginnote">「预测下一个 token」在哲学上被反复讨论：有人称之为「随机鹦鹉」，有人认为是「世界模型」——无论哪种立场，都承认 LLM 生成的本质是「在极大规模上估计条件分布」，这与本专题的生成模型框架完全一致。</span>

## 6 温度、长度与创造力的实际手感

解码策略的「手感」，只有上手试过才能建立直觉。这里给三个典型的可观察现象，帮你把「temperature」这个旋钮具象化。

**现象一：低温下 LLM 会「车轱辘话」。** temperature=0 时，模型每次都选概率最大的 token。如果最可能的续写是重复上下文中的句子（语言模型容易对高频模式「着迷」），就会陷入「我认为……我认为……我认为……」的循环。**低温 ≠ 高质量，它只是「确定」**——很多场景下，确定性意味着平庸与重复。

**现象二：高温下 LLM 会「跑题发疯」。** temperature=1.2 以上，低概率 token 被解冻，模型开始选「出人意料的词」，语句可能「有创意但崩坏」——语法还在、逻辑已散。**温度是「概率分布的锐度」，不是「创造力开关」**：它放大的是分布的尾部，不是模型的推理能力。

**现象三：top-p 与 temperature 是「互补的双旋钮」。** temperature 全局压扁/拉尖分布，top-p 只截断长尾。组合起来：temperature=0.8 + top-p=0.9 是「适度随机 + 不碰尾巴」的通用配方；写代码（要确定）用低温度 + 高 top-p；写故事（要发散）用高温度 + 中 top-p。

**这条直觉可以迁移到整个生成模型**：扩散模型的「随机种子与 CFG」、图像生成的「多样性—质量旋钮」、语音合成的「稳定—自然度」，本质上都是「在条件分布的哪个位置采样」的选择。**「采样策略即性格」**——这句话对 LLM、对扩散模型、对一切生成模型都成立。把 LLM 生成手感的规律再收几条：

- 低温 ≠ 高质量：确定性强但易重复、平庸，需配合重复惩罚。
- 高温 ≠ 有创意：发散过头会语法崩坏、逻辑散架。
- temperature 与 top-p 互补：前者调整体随机性，后者剪长尾。
- 采样配置是对模型「人格」的塑造：同一模型可可靠可发散。
- 评估必须固定采样配置：否则「模型 A 比 B 好」可能只是采样更讨巧。
- 与扩散的对照：随机种子、CFG 与 temperature 是同一种「分布操纵」的分身。

## 7 小结

- **LLM = 自回归生成模型 + 最大似然 + 规模效应**：全部能力建立在「估计 $p(x_t\mid x_{\\lt t})$」之上，与 PixelCNN 同构、只是换数据换规模。
- **生成循环**是「前向一次、按解码策略采样、拼接、再前向」的串行过程。
- **解码策略**是「如何从分布里抽 token」的选择：贪心/beam 确定性，temperature/top-k/top-p 随机性；「适当的随机」是文本生成的艺术。
- **生成慢**是自回归串行依赖的结构代价，KV 缓存与投机解码是两大工程解药。
- 对齐、温度、采样策略，本质上都是对「学好的条件分布」的再操纵。
