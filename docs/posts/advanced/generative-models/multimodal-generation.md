## 为什么从多模态生成开始

前面几篇分别讲了文本、图像、视频、3D、音频的生成——它们各自为战。但真实的人类创作从来是**多模态的**：导演边看画面边听音乐，设计师边画图边读文案，你给朋友发的消息里图文并茂。**多模态生成**要做的，就是让一个模型学会「任意模态之间互相生成」：文本描述出图像、图像配一段文字、文字配一段语音、图像配一段音乐……甚至「从一段视频里抽一帧配上解说」。

多模态生成是生成模型「最后一块拼图」，它把本专题的所有主线——自回归、扩散、VQ-VAE、条件生成、潜空间——放进同一个系统里，让它们协作而非竞争。它的技术路线之争，本质上是「用什么表示来统一多模态」之争：是像语言一样把一切都离散成 token（统一 token 派），还是让每个模态各用各的生成引擎、再用「对齐层」接起来（专家协同派）。理解了这场路线之争，就理解了 2024 年后生成式 AI 的格局。<span class="marginnote">「多模态」在这里特指「生成」的多模态——注意与《多模态学习》专题的区别：那里的核心是「理解」（CLIP、图文检索），这里的核心是「生成」（从一种模态造出另一种模态）。两者共享对齐技术，但目标不同。</span>

## 1 统一 token：把世界压成同一种语言

**统一 token 派**的核心主张：既然文本可以 token 化、图像可以 VQ-VAE 成码字、音频可以 EnCodec 成离散流，那为什么不把**所有模态都切成 token**，交给同一个 Transformer 建模？这样：

训练目标统一为「预测下一个 token」——无论下一个 token 属于哪个模态。
文本、图像、音频可以在**同一个序列里混合**（一张图 + 一行字 + 一段音），模型自动学到模态间的关联。
架构与语言模型完全一致，享受「规模即能力」的红利。

**代表系统**：Meta 的 **CM3Leon**（图文统一 token）、**Chameleon**（文本 + 图像统一）、**Unified-IO**（几乎所有模态）。这类系统的哲学是「**世界即 token 序列**」——只要表示统一，Transformer 就能消化一切。<span class="marginnote">统一 token 派的终极想象：把「视频 patch + 音频 token + 文本 token」拼成一条超长序列，让一个模型同时学会「看到画面、听懂声音、说出台词」——Sora 的时空 patch、Gemini 的全模态 token 化，都是这一哲学的实践。</span>

**统一 token 的代价**：图像、音频的 token 序列比文本长得多（一张图 = 数百 token，一段视频 = 上万 token），序列长度的计算代价巨大；且离散化会损失模态内的精细结构。于是出现另一派。

## 2 专家协同：各模态用各的引擎，再「对齐」

**专家协同派**主张：图像就交给图像扩散模型（它最强），音频就交给音频模型（它最强），文本就交给语言模型——**不强行统一表示，而是训练「连接器」让它们互相理解**。架构通常是：

1. **模态编码器**：把输入模态映射到语言模型的嵌入空间（用连接器，如 Q-Former、MLP adapter）。
2. **语言模型主干**：理解输入、规划输出——「大脑」。
3. **模态生成器**：把语言模型输出的指令「转译」成目标模态（如把文本指令交给扩散模型出图、交给 TTS 出语音）。

**代表系统**：**NExT-GPT**（文本 + 图像 + 音频 + 视频的任意组合）、**CoDi**（任意输入模态 → 任意输出模态）。这类系统的哲学是「**各模态各司其职，对齐让它们协作**」——它把「生成」这一最高难度任务交给最擅长的专家，语言模型只负责「调度」。

**辨析｜易错点：** 专家协同不是「把几个模型的文件拷到一起」。**对齐层是灵魂**：它必须让「语言模型想表达的内容」与「生成器能理解的条件」在语义上严格一致——语言模型输出「画一只戴红帽子的猫」，图像生成器必须真的收到「红帽子」的约束。对齐的质量直接决定跨模态生成的准确性，这正是 CLIP 等对比学习模型的核心价值。<span class="marginnote">对齐层的训练常用「指令微调」：构造大量「输入模态 → 输出模态」的配对数据，让连接器学会「把图像的特征翻译成语言模型听得懂的 token」——本质上是在两个模态的表示空间之间学一个可微的「翻译官」。</span>

## 3 公式解析：跨模态生成的条件框架

无论走哪条路线，多模态生成都可以统一写成「条件生成」的框架：从一个源模态 $y$ 生成目标模态 $x$：

$$
p_\theta(x \mid y) = \prod_{t} p_\theta\big(x_t \mid x_{\\lt t},\, \text{Encoder}(y)\big)
$$

拆解三步：

- **第一步，源模态编码**：输入模态 $y$（文本、图像、音频）经各自的编码器变成条件向量 $\text{Encoder}(y)$。
- **第二步，目标模态序列化**：目标模态 $x$（图像、音频、视频）被离散化成 token 序列 $x_1,\dots,x_T$——无论哪个模态，都变成「序列」。
- **第三步，条件自回归**：每个目标 token 以「历史 token + 源模态条件」为条件——这就是标准的「条件自回归生成」。

**这个框架揭示了多模态生成的统一本质**：**「文本生成图像」与「图像生成文本」在数学上完全对称**——都是「给定一个模态，条件生成另一个模态」，差别只在「谁编码、谁序列化」。理解了这一点，就能理解为什么那么多跨模态任务可以共享同一套方法。

**跨模态对齐的另一种工具是扩散**：CoDi 直接在「多模态联合空间」里跑扩散——不同模态的表示被映射进同一个潜空间，扩散模型在其中生成后按模态解码。**统一 token 与扩散对齐，代表了「序列建模」与「分布建模」两大传统在多模态的汇合**。

## 4 多模态生成的核心挑战

- **模态失衡**：文本数据多、视频数据少，模型对「文本 → 图像」远强于「视频 → 音频」。不同模态的数据规模差几个数量级，训练时需精心配比。
- **对齐精度**：跨模态生成的「对齐」比同模态更易出错——图文对齐的小误差会被生成器放大成「多只手指」。
- **评估困难**：「这段音乐与这幅画配不配」没有客观标准，多模态生成的评估比单模态更难——见本专题《生成模型的评估》。<span class="marginnote">模态失衡的一个典型现象：图像生成模型对「稀有物体」（消防栓、水豚）的理解明显弱于常见物体——因为图文配对的分布本身是偏斜的。这催生了「数据平衡」「课程学习」等专门技术。</span>

## 5 多模态生成在课程体系中的位置

多模态生成是本专题的「集大成者」，它把全专题的线索收拢进一个系统：

**自回归支**：统一 token 路线用「下一个 token 预测」跨模态建模。
**扩散支**：跨模态条件扩散用「潜空间 + 条件」生成目标模态。
**VQ/离散化支**：图像、音频、视频的离散 token 化是多模态统一的物质基础。
**对齐支**：CLIP、对比学习来自《多模态学习》与《大模型原理》。<span class="marginnote">从「极限到大模型」主线看，多模态生成是「大模型」的终极形态：一个能看、能听、能说、能画、能写的统一生成体。它把语言模型的「通用推理」与生成模型的「多模态创造」合二为一——这是 2024 年后整个领域最明确的航向。</span>

**展望**：多模态生成的下一个前沿是「理解与生成的统一」——同一个模型既能回答「这张图里有什么」，又能画出「这段描述的画面」。当理解与生成共享同一套表示，AI 就真正获得了「通感」的能力。

## 6 多模态生成的评估：没有「标准答案」的难题

多模态生成把评估难题推到了极限：**「这段音乐配这张图好不好」「这句话翻译成图像贴不贴切」，根本没有客观标尺**。它的评估困境有三个层次：

**第一层：模态内质量。** 生成的图像是否高清、音频是否自然——这可以复用单模态指标（FID、MOS）。但「单模态都合格」不代表「多模态配合得好」。

**第二层：跨模态对齐。** 「文本与图像是否相符」「图像与音频是否匹配」——这需要**跨模态一致性**指标。常用手段：用 CLIP 计算「图文匹配分数」，用「音画对齐模型」评估「图像—音频」语义一致。但这类「对齐分数」仍不能完全代表「人类觉得配不配」。

**第三层：任务正确性。** 「从这句话生成视频，是否准确表达了句意」——这几乎没有自动指标，只能靠人工评测（让标注者对比「条件」与「生成结果」的语义保真度）。

**实践中的组合：** 「单模态指标 × 跨模态对齐分 × 人工评测」三件套并用。但最核心的仍是**人类评测**——多模态生成的「好」本质是「人的多感官体验」，任何单一自动指标都无法覆盖。<span class="marginnote">这也解释了为什么多模态大模型的评测会走向「竞技场」模式（如 Chatbot Arena 的图文版本）：让模型两两对战、人类投票，用群体偏好替代自动指标。<strong>当「好」无法定义时，就让足够多的人来共同定义。</strong></span>

**一个更深的方法论启示**：多模态评估的困难，反过来暴露了「评估权」的集中——谁定义「跨模态配得好」，谁就塑造了多模态生成的发展方向。这提醒研究者：**不要被「一个 CLIP 分数」带偏，多模态的进步必须由「多指标 + 人」共同判定**。把多模态生成的要点再收几条：

- 统一 token 派：一切模态离散化 + 一个 Transformer，哲学是「世界即 token 序列」。
- 专家协同派：各模态用最强引擎 + 连接器对齐，语言模型做调度。
- 对齐层是灵魂：语义不一致，跨模态生成必然失真。
- 统一框架：$p(x\mid y)$——源模态编码 + 目标模态序列化 + 条件自回归。
- 扩散对齐：在联合潜空间扩散，统一 token 与扩散代表「序列 vs 分布」两传统。
- 模态失衡：文本多、视频少，需精心配比数据。
- 评估三难：模态内质量、跨模态对齐、任务正确性，靠「多指标 + 人」。
- 条件泄漏陷阱：模型可能利用「图文统计相关」而非真理解，需反偏置数据集。
- 理解与生成的统一是终极形态：同模型既能回答又能画出。
- 序列长度代价：图像视频 token 远多于文本，计算压力大。
- 离散化损失：牺牲模态内精细结构，是统一派的软肋。
- 连接器类型：Q-Former、MLP adapter 等，本质是「可微翻译官」。
- 从 NExT-GPT 到 CoDi：任意输入 → 任意输出的全能生成系统。
- 指令微调训练对齐：构造大量「输入模态 → 输出模态」配对。
- 与《多模态学习》分工：那里重理解，这里重生成，共享对齐技术。
- 竞技场式评测：多模态大模型靠人类投票定胜负。
- 通感能力：当理解与生成共享表示，AI 获得跨模态「通感」。

## 7 小结

- **多模态生成** = 任意模态间的互相生成，是生成模型的「最后一块拼图」。
- **统一 token 派**：所有模态离散化 + 一个 Transformer 统一建模，哲学是「世界即 token 序列」。
- **专家协同派**：各模态用最擅长的引擎 + 连接器对齐，语言模型做调度，哲学是「专家协作」。
- 跨模态生成统一为条件生成 $p(x\mid y)$：源模态编码 + 目标模态序列化 + 条件自回归。
- 核心挑战：模态失衡、对齐精度、评估困难。
- 终极形态：理解与生成统一的多模态生成体。

在下一节，我们从「生成什么」转向「怎么控制生成」：如何让生成结果精确、可编辑、可交互地符合人的意图——这是 **生成模型的可控性**。
