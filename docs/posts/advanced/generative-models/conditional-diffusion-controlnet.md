## 为什么从条件扩散开始

文生图模型能听懂「一只戴红帽子的猫」，却对「精确姿势、精确构图、精确边缘」无能为力——一句「人物左手叉腰、背景是巴黎铁塔、画面构图遵循这张草图」会把任何 prompt 工程逼疯。**条件扩散**要解决的就是这类**结构级控制**：不是用语言描述，而是直接给模型一张**参考图**——边缘图、深度图、姿态骨架、分割掩码——让生成严格遵循它的几何结构。

2023 年的 **ControlNet** 把这个需求变成了工程事实：它冻结住 Stable Diffusion 的全部参数，只训练一小撮**可插拔的控制分支**，就让扩散模型既能「听懂结构条件」，又几乎不损伤原有的生成能力。ControlNet 的价值不只是「一个插件」：它示范了一种**「冻结主干 + 旁路适配」的参数高效微调范式**，与 LoRA、Adapter 一脉相承，是「在不动大模型的前提下注入新能力」的教科书方案。<span class="marginnote">ControlNet 的出现让「条件扩散」从学术概念变成设计师的日常工具：姿态控制（OpenPose）、深度控制（MiDaS）、边缘控制（Canny）……一句话 + 一张骨架图 = 精确构图的高质量图像，这是文生图从「盲画」走向「听话」的关键一步。</span>

## 1 结构条件为什么难：从「语义」到「几何」

文本条件（cross-attention）擅长控制**语义**——「红色的猫」能精确影响画面里猫的颜色；但它不擅长控制**几何**——「猫的右前爪抬到 30°」这种描述无法被语言精确编码，即使编码了，attention 也无法保证「每个像素都服从」。

结构条件（边缘、深度、姿态）提供的是**逐像素的几何约束**：Canny 边缘图里每条线都必须在输出里出现，姿态骨架里每个关节点都要被遵守。这类条件的特点是：

- **强约束**：不是「提示」而是「指令」，逐像素生效。
- **与文本条件正交**：文本管「是什么」，结构管「在哪、什么姿势」。
- **很难直接复用 cross-attention**：结构图是空间信号，需要注入到特征图的每一个空间位置，而不是「检索式」地融合。

**ControlNet 的核心设计**：把结构图当作输入，在 UNet 每个尺度都开一条「控制通道」，让几何约束贯穿整个生成过程。

## 2 ControlNet 架构：冻结主干 + 可训练旁路

ControlNet 的架构设计贯彻「不动主干」原则：

1. **冻结原 UNet**：Stable Diffusion 的 UNet 所有参数固定不动——保证已有的文本生成能力完好无损。
2. **复制一份编码器**：把 UNet 的编码器部分（12 个块）复制成可训练的「控制分支」，接收结构图 $c$ 作为输入。
3. **零卷积（zero convolution）**：控制分支的输出通过**初始化为零**的 1×1 卷积与原特征相加。零初始化的意义：训练开始时控制分支输出恒为 0，**新加入的结构条件不会破坏预训练模型的输出分布**，模型从「等于原模型」出发平稳地学出控制能力。
4. **各尺度注入**：控制特征在 UNet 每个空间尺度与原特征相加，让结构约束从粗到细全程生效。

$$
x_{\text{new}} = x_{\text{orig}} + \mathcal{Z}\big(\text{ControlBranch}(c)\big)
$$

**零卷积是灵魂**：零卷积在训练开始时输出恒零，保证「旁路完全不影响主干」；随着训练，零卷积逐步学习从结构图到特征调整的映射，主干被「点拨」出结构感知能力，而自身权重不变。<span class="marginnote">零卷积的直觉：它像一个「初始无感的接线员」——一开始旁路完全静默，随着训练才慢慢把结构信号的梯度放行。这个「从零开始平滑接入」的设计避免了新条件与预训练能力的冲突，是 ControlNet 训练稳定的关键。</span>

## 3 公式解析：控制分支的训练目标

ControlNet 的训练目标与 LDM 相同，只是把结构条件加进噪声预测网络：

$$
\mathcal{L} = \mathbb{E}_{z_0,\,c,\,t,\,\varepsilon}\Big[\big\|\varepsilon - \varepsilon_\theta\big(z_t,\, t,\, \text{text},\, \underbrace{\text{Control}(z_0, c)}_{\text{结构条件}}\big)\big\|_2^2\Big]
$$

拆解四步：

- **第一步，采样潜变量与条件**：从图像编码器取 $z_0$，取结构图 $c$，随机时刻 $t$。
- **第二步，构造条件化带噪输入**：$\text{Control}(z_0, c)$ 把结构图与当前潜变量配对，作为控制分支输入；主 UNet 同时接收文本与结构两条条件。
- **第三步，预测噪声**：$\varepsilon_\theta$ 在「既懂文本、又服从结构」的约束下预测噪声。
- **第四步，MSE**：与真实噪声比对，反向传播——**只更新控制分支与零卷积**，主 UNet 冻结。

训练数据是「图像 + 对应结构图」的配对：一张照片配上它的 Canny 边缘、Depth 深度或 OpenPose 骨架。**数据的可获得性决定了 ControlNet 的覆盖范围**——这是结构控制模型最大的工程瓶颈，也是社区会互相共享「控制模型」的原因。

## 4 ControlNet 家族与应用矩阵

ControlNet 是一套「换条件、换数据、换应用」的通用框架。社区围绕它构建了完整的控制生态：

| 控制类型 | 结构图来源 | 典型用途 |
| --- | --- | --- |
| Canny 边缘 | Canny 算子 | 线稿上色、构图保持 |
| 深度图 | MiDaS 等单目深度估计 | 3D 感构图、景深控制 |
| 姿态骨架 | OpenPose | 人物姿势精确控制 |
| 分割掩码 | 语义分割模型 | 布局精确控制 |
| 法线图 / 线稿 | 渲染器 / 提取器 | 动漫线稿、材质控制 |

**控制与生成的博弈**是始终存在的主题：结构约束越强，模型「发挥」空间越小——边缘控制过强会让模型变成「描边机」，纹理细节被压平；约束太弱则「不听指挥」。ControlNet 引入了「控制强度」旋钮（control strength / guidance scale），让用户自由调节「服从结构」与「自由创作」的平衡。<span class="marginnote">「听话」与「有创意」是一对永恒的矛盾：结构条件是硬约束，text prompt 是软约束。这个「强度调节」思想后来被 Canny 边缘 + 提示词 + 采样步数的三元组合进一步细化为工程实践，成为设计师每天调节的三要素。</span>

## 5 条件扩散在课程体系中的位置

条件扩散是「可控生成」主题的工程高地，它把本专题多条线接在一起：

**承接**：LDM 的潜空间 + 交叉注意力（本专题《潜在扩散模型》）是 ControlNet 的运行底座；「结构条件注入」是条件 GAN 的「拼接/投影」方案在扩散时代的全面升级。
**与参数高效的共鸣**：冻结主干 + 训练旁路 + 零卷积，与 LoRA、Adapter、Prefix Tuning 同属「不动大模型、注入新能力」的范式，可对照第四级《大模型微调》的 PEFT 章节。
**与可控性的连接**：ControlNet 是「显式结构控制」，而「隐式语义控制」（概念编辑、instruct 编辑）属于本专题《生成模型的可控性》一篇的范畴——两条控制路线互补。

从「极限到大模型」的主线看，ControlNet 示范了生成模型从「令人惊喜」到「令人可控」的工程进化：**能力的价值不只在于「有多强」，更在于「多听话」**。结构控制让生成模型从玩具走向生产工具，也预告了「可编辑、可交互、可迭代」的生成式设计未来。<span class="marginnote">当控制与生成结合到极致，AI 绘画就从「抽卡」变成了「可逆的创作流」——设计师画草图、调结构、精修细节，生成模型成为真正的「数字画笔」而非「自动贩图机」。</span>

## 6 ControlNet 的数据与训练配方

ControlNet 的架构占成功的一半，另一半在「数据怎么来、训练怎么配」。

**数据构造是最大瓶颈。** 训练一个「Canny 边缘控制」模型，需要「图像 + 该图像的 Canny 边缘」配对——Canny 边缘可以自动提取，训练数据相对好造。但「姿态控制」就要难得多：需要先训练/使用 OpenPose 检测器从真实照片里提取人体骨架，再配对训练。**结构控制模型的覆盖范围，几乎等于「结构提取器能自动生成的配对数据的范围」**。

**训练配方的三个关键选择：**

- **冻结 vs 微调**：ControlNet 冻结主 UNet 与文本编码器，只训练控制分支。这个「冻结主干」的选择让训练成本降了一个量级（只更新约 1/10 参数），也让「换基础模型」时控制分支仍可复用——社区里大量「为 SD1.5 训练的 ControlNet 无缝迁移到 SD2.x」的例子正是得益于此。
- **训练顺序**：论文先在低分辨率（256）训练、再上高分辨率微调——「先学结构、再学细节」的渐进策略，与 PGGAN 逐层生长、扩散多尺度加噪是同一个「由粗到细」哲学的又一种落地。
- **与 CFG 的配合**：ControlNet 输出会与文本条件同时注入 UNet，推理时的 CFG 会同时放大「文本引导」与「结构引导」。实践中常分别设置「文本 CFG」与「结构权重」，因为结构约束太强时高 CFG 反而会引入伪影。

**一句话总结数据与架构的关系**：架构决定了「控制能力能注入到哪里」，数据决定了「控制能力能学会什么」——两者缺一不可，也是社区生态里「谁有更好的配对数据，谁就能训练出更好的控制模型」的原因。把 ControlNet 的架构与数据要点再收几条：

- 冻结主干 + 旁路适配：只训练控制分支，成本低、可换底座复用。
- 零卷积是稳定关键：控制分支从「零影响」起步，不破坏预训练能力。
- 结构条件逐尺度注入：粗到细全程生效，比「只接输入」强得多。
- 数据决定能力边界：Canny 可自动提取，姿态需先跑 OpenPose，成本递增。
- 控制强度是旋钮：结构约束过强变「描边机」，过弱「不听话」。
- 与文本条件互补：文本管语义、结构管几何，可同时使用。
- 与 PEFT 同源：ControlNet、LoRA、Adapter 共享「不动主干、注入能力」范式。
- 训练渐进：低分辨率先学结构，再上高分辨率补细节。
- 工程现状：社区已用同一框架训练上百种专用控制模型，验证了其可插拔性。

## 7 小结

- **结构条件**（边缘/深度/姿态）提供逐像素几何约束，与文本的语义条件正交互补。
- **ControlNet** 冻结主 UNet，复制编码器做可训练旁路，用**零卷积**让控制能力从零平稳接入，不损伤原生成能力。
- 训练目标仍是噪声预测 MSE，只更新控制分支；训练数据是「图像 + 结构图」配对。
- **控制强度**调节「服从结构」与「自由创作」的平衡，是设计师的关键旋钮。
- 谱系：冻结主干 + 旁路适配的参数高效范式，与 LoRA 同源，贯通整个大模型微调方法论。
