## 为什么从视频生成模型开始

图像生成解决了「一张图」，视频生成要解决「一串连续变化的图」。这看起来只是把问题从 2D 升到 3D，实际上是一次质变：**视频不仅要有每一帧的空间质量，还要有帧与帧之间的时间连贯性**——人物不闪烁、动作不跳变、物理规律不崩塌。正因如此，视频生成长期被认为是比图像生成难一个数量级的任务，直到 2022–2024 年扩散模型把「图像生成」做成成熟技术后，视频生成才迎来爆发。

视频生成是生成模型「维度扩展」的标准样本：把「空间条件生成」推广到「时空联合生成」。它的技术路线几乎都是图像方法的直接升级——图像用 2D UNet，视频用 **3D UNet**（多一个时间维）；图像在潜空间扩散，视频在**时空潜空间**扩散；图像用 CLIP 文本对齐，视频用「文本 + 图像 + 视频」三模态对齐。2024 年 Sora 的出现更是把视频生成推向「模拟世界」的想象——它用扩散 Transformer 直接建模原始视频 patch。<span class="marginnote">视频生成的核心矛盾一句话：<strong>空间要锐利、时间要连贯、长度要可控、算力要合理</strong>——四个目标互相拉扯。理解了这对矛盾，就理解了视频生成的全部技术选择。</span>

## 1 视频生成的三条技术路线

视频生成没有一条通吃路径，历史上出现过三套思路，各有取舍：

**路线一：逐帧自回归（frame-by-frame autoregression）**——把视频当「按时间排列的帧序列」，像语言模型一样逐帧生成，每帧以之前所有帧为条件。VideoGPT、早期的帧预测模型走这条路。优点：复用自回归基建；缺点：**误差沿时间累积**，长视频必然漂移，且生成速度受「帧数 × 每帧成本」约束。

**路线二：时间插值（frame interpolation）**——先生成关键帧，再用插值模型补中间帧。Make-A-Video 等早期文生视频用它降低难度。优点：大幅减少要生成的总帧数；缺点：插值质量上限受关键帧约束，长时运动难保一致。

**路线三：时空联合扩散（joint spatiotemporal diffusion）**——把整段视频（或潜空间表示）当作一个「3D 张量」直接扩散，让模型同时学习空间与时间结构。这是当前的主流。Video Diffusion Models（2022）把 UNet 的 2D 卷积升级成 3D 卷积，一次建模整段视频，时间一致性从根本上被保证。<span class="marginnote">把「逐帧生成」和「整体扩散」对比很有意思：自回归像「一个词一个词地写句子」（容易跑题），整体扩散像「先想好整篇文章再落笔」（全局一致但计算昂贵）。视频扩散选后者，用算力换一致性。</span>

## 2 时空扩散：把视频变成 3D 张量

主流的视频扩散模型把视频表示为一个时空张量 $x\in\mathbb{R}^{T\times H\times W\times 3}$（$T$ 帧、$H\times W$ 分辨率、3 个颜色通道），然后：

- **潜空间压缩**：用 3D 自编码器（Video VAE）把视频压缩成时空潜表示 $z\in\mathbb{R}^{t\times h\times w\times c}$，空间与时间同时下采样。
- **3D UNet 去噪**：把 2D 卷积替换为 3D 卷积（或 2D 卷积 + 时间注意力），在潜空间做条件去噪。
- **时间注意力**：每一层除了空间注意力，还加时间注意力，让「这一帧」能参考「相邻帧」——这是时间一致性的关键机制。

**训练目标与 LDM 几乎相同**，只是把图像换成了视频：

$$
\mathcal{L}_{\text{vid}} = \mathbb{E}_{z\sim E(x),\,y,\,t,\,\varepsilon}\Big[\big\|\varepsilon - \varepsilon_\theta\big(z_t,\, t,\, y\big)\big\|_2^2\Big]
$$

其中 $z=E(x)$ 来自 3D 自编码器，$y$ 是文本/图像条件。**换一个输入张量，整个扩散管线照搬**——这正是「扩散是通用生成引擎」的又一例证。<span class="marginnote">视频潜空间的「时间下采样」是个关键选择：压缩掉多少帧决定了「时间分辨率」与计算量的权衡。过度压缩会丢失运动细节，欠压缩则显存爆炸——这是视频生成工程里最痛苦的超参数之一。</span>

## 3 公式解析：时间一致性从哪来

视频生成最怕「闪烁」「跳变」，其数学根源是**逐帧独立采样缺乏跨帧约束**。时空扩散如何保证一致性？看它的条件结构：

$$
p_\theta\big(z^{(1:T)}_0 \mid y\big) = \int p_\theta\big(z^{(1:T)}_{0} \mid z^{(1:T)}_{1}\big) \cdots p_\theta\big(z^{(1:T)}_{T}\mid z^{(1:T)}_{T}\big)\, d z^{(1:T)}_{1:T}
$$

拆解三步：

- **第一步，整段联合建模**：条件分布作用在**整段视频潜变量** $z^{(1:T)}$ 上，而不是逐帧独立——每一帧的去噪都「看着」全部帧。
- **第二步，共享去噪网络**：同一个 $\varepsilon_\theta$ 处理所有帧，通过 3D 卷积/时间注意力让「邻居帧」的信息互相流通。
- **第三步，时间注意力传递运动**：时间注意力层让某帧的特征「去参考」其他帧的特征——运动模式在特征层面被学习，而不是靠每帧各自猜。

**通俗地说**：时空扩散让模型「整段视频一起想」，而不是「一帧一帧想」——整段想的模型天然不会在帧间「忘记」上一帧是什么样。这也解释了为什么它比逐帧自回归更能保持长时间一致性。

## 4 从 Video Diffusion 到 Sora：DiT 的登场

视频生成的进化史可以用三个里程碑概括：

- **Video Diffusion Models（2022）**：3D UNet 视频扩散的奠基，证明「扩散 + 时空建模」可行。
- **Make-A-Video（2022）**：用「文本 → 图像 → 视频」的分步迁移，让文生视频第一次「可用」。
- **Sora（2024）**：把视频切成**时空 patch**，用**扩散 Transformer（DiT）**在 patch 序列上建模——不再用卷积 UNet，而是让注意力网络直接「想象」整个视频。Sora 证明了「视频生成」能扩展到分钟级、保持对象恒存（一只狗从画面左侧走到右侧，还是同一只狗）。<span class="marginnote">Sora 的「时空 patch」思想与语言模型的 token 化高度同构：图像切成 patch、视频切成时空 patch、文本切成 token——一旦都变成「token 序列」，就能用同一个 Transformer 统一建模。这就是通向《多模态生成》的门。</span>

视频生成的开放难题依然严峻：**长时记忆**（对象几秒后还能记住自己长什么样）、**物理正确**（水流、碰撞、光影是否遵守物理）、**可控性**（精确控制镜头运动与角色动作）、**与音频同步**（对白口型）。这些问题让视频生成仍是「前沿中的前沿」。

## 5 视频生成在课程体系中的位置

视频生成是「时空生成」的样板，它把本专题的多个核心概念推向更高维度：

- **维度扩展的普适规律**：从 2D 到 3D，核心不是「换个网络」，而是「把时间当作另一个空间维」——3D 卷积、时间注意力、时空 patch 都是「把时间空间化」的具体手段。
- **与图像生成的继承**：潜空间扩散、CFG、交叉注意力、少步采样，全部从图像迁移而来——**生成模型的工具箱是模态无关的**。<span class="marginnote">这种「工具箱可迁移」正是本专题想传递的核心直觉：无论图像、视频、3D 还是音乐，生成的底层数学（分布、条件、采样、扩散）是同一套，变的只是数据的表示形式。</span>
- **与物理/世界的接口**：视频生成的终极形态被想象成「世界模型」——一个能预测「接下来会发生什么」的生成模型，这与《强化学习》的「世界模型」、与《具身智能》的「预测式控制」暗合。

从「极限到大模型」的主线看，视频生成站在「从静态理解到动态模拟」的转折点：当机器能稳定生成物理一致的长视频，它就离「理解世界如何运转」更近了一步。

## 6 视频生成的评估难题

视频生成的评估比图像更棘手，因为「视频好不好」是时间维度与空间维度的叠加——这直接决定了我们很难照搬图像指标。

**从图像指标借来的不够用。** FID 可以逐帧计算再平均，但「逐帧 FID 平均」会掩盖时间瑕疵：一个「每帧都清晰、但帧间乱跳」的视频，帧级 FID 很好看，实际观感却崩坏。**帧间一致性恰恰是视频的核心质量，而它不在逐帧指标里。**

**视频需要专属维度：**

- **时序一致性**：物体是否在帧间保持同一身份、运动是否连续——这需要「跨帧跟踪」式评估，比单帧质量难测得多。
- **运动物理性**：重力、碰撞、形变是否符合物理常识——目前主要靠人工看，自动指标稀缺。
- **长时结构**：几秒内叙事是否连贯、镜头语言是否合理——这是「秒级质量」之上更高的层次。

**实践中的组合拳：** 帧级质量用 FID/KID，时序一致性用「帧间光流误差」「对象跟踪成功率」，加上**人类评估**（让评测者给「连贯性」「物理正确性」打分）。由于自动指标覆盖不全，**视频生成的评估至今仍高度依赖人工抽检**——这也是它被称为「前沿中的前沿」的原因之一。<span class="marginnote">视频评估的「人工依赖」与语言生成的「ELo 人类偏好」异曲同工：当自动指标测不准「好」，就让人类直接当裁判。这提示了一个通用规律——生成模态越复杂，自动指标的覆盖率越低，人类评估的分量越重。</span>

**这个难题的积极面**：它逼着研究者发明「时序感知的指标」，而这些指标（如视频 FVD——在视频特征空间算 Fréchet 距离）反过来又推动了「视频特征学习」本身。**评估需求催生表征进步**——这与图像时代 FID 倒逼 Inception 特征研究如出一辙。把视频生成的工程要点再收几条：

- 时间下采样是关键超参：压太多丢运动，压太少爆显存。
- 时空潜空间 + 3D UNet 是主流：训练目标与图像 LDM 同构。
- 时间注意力是「帧间记忆」：让每帧参考邻居，一致性由此而来。
- 逐帧自回归误差累积：长视频必然漂移，被整体扩散取代。
- 帧插值降难度：先生成关键帧再补中间帧，早期文生视频的常用手段。
- Sora 的时空 patch + DiT：把视频切成 token，用注意力统一建模。
- 评估靠「帧级指标 + 时序指标 + 人工」三件套：自动指标覆盖不全。
- 长时记忆是开放难题：对象几秒后还能记住自己的身份。
- 物理正确是硬骨头：水流、碰撞、光影，生成模型常「反物理」。
- 可控性滞后于图像：镜头运动、角色动作的精确控制仍在攻关。
- 音画同步（口型、对白）是音频与视觉的汇合点。
- 课程启示：维度扩展的核心是「把时间当另一个空间维」。

## 7 小结

- **视频生成**比图像难在「时间连贯性」：空间锐利、时间连贯、长度可控、算力合理四者互相拉扯。
- 三条路线：逐帧自回归（误差累积）、帧插值（降低难度）、**时空联合扩散**（主流，整段建模）。
- **时空扩散**把视频当 3D 张量，用 3D 卷积 + 时间注意力保证帧间一致，训练目标与图像 LDM 同构。
- 里程碑：Video Diffusion → Make-A-Video → **Sora**（时空 patch + DiT），向「世界模拟」逼近。
- 开放难题：长时记忆、物理正确、可控性、音画同步。
- 生成模型的工具箱是**模态无关**的——图像学到的经验几乎全部可迁移到视频。

在下一节，我们继续「升维」：从 2D 图像、2D+时间的视频，走向真正 3D 的几何与体积——这是 **3D 生成模型**的领域。
