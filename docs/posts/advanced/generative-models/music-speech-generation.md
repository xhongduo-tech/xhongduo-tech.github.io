## 为什么从音乐与语音生成开始

视觉生成占据聚光灯，但**音频生成**可能是生成模型最早的工业应用：语音合成（TTS）从 20 世纪就有实用需求，音乐生成则是「创造性 AI」最迷人的战场。音频与图像的本质差异在于**表示**：图像是像素网格，音频是**一维时间序列的波形**——每秒上万个采样点，而且人耳对时域细节极度敏感：音色、节奏、呼吸、停顿，任何一丝失真都会立刻被听出来。

音频生成的技术演进是「表示学习」的一部缩影：从直接合成波形（WaveNet 的自回归），到中间表示（梅尔频谱 + 声码器），再到**离散音频 token**（把音频切成「声音的 token」），最后到「音频语言模型」——用 Transformer 直接生成音频 token 序列。这条「离散化 → 序列建模」的路线，让音乐与语音生成最终汇入了大语言模型的技术洪流：**音频生成与文本生成在架构上越来越同构**。<span class="marginnote">语音生成（说人话）与音乐生成（奏旋律）看似相近，技术侧重点却大不同：语音强调「可懂、自然、音色像谁」，音乐强调「结构、和谐、风格多样」。前者偏工程精度，后者偏创作自由度。</span>

## 1 音频的表示：波形、频谱与 token

生成音频前，先回答「用什么东西表示声音」。三种主流表示：

| 表示 | 形式 | 特点 | 用途 |
| --- | --- | --- | --- |
| 原始波形 | 采样点序列（16kHz/44.1kHz） | 信息无损、维度极高 | WaveNet、扩散 TTS |
| 梅尔频谱 | 时频图（帧 × 频带） | 维度低、符合听觉 | 中间表示，配声码器 |
| 离散 token | 量化后的码字序列 | 与语言模型同构 | AudioLM、音乐生成 |

**关键权衡**：原始波形信息最全但维度爆炸，扩散模型在波形上生成需要极强的去噪网络；梅尔频谱维度低但需额外**声码器**（如 HiFi-GAN、DiffWave）把它转回波形；离散 token 牺牲一点保真度，换来「音频 = token 序列」的终极便利——**可以用标准的自回归/扩散架构直接生成**。<span class="marginnote">声码器（vocoder）是「频谱 → 波形」的逆变换器，早期基于信号处理（Griffin-Lim），后来被神经声码器（WaveNet、HiFi-GAN）取代——它是「中间表示」路线里不可或缺的最后一公里。</span>

**离散音频 token** 的代表是 **SoundStream / EnCodec**：用类似 VQ-VAE 的编码器把音频波形压缩成离散码流（每秒几十到几百个 token），再用 Transformer 在 token 序列上生成。这与图像领域的「VQ-VAE + 自回归」路线惊人地同构——**离散化是通往「统一生成」的通用桥梁**。

## 2 语音生成：从拼接合成到神经 TTS

语音合成（text-to-speech, TTS）的目标：输入文本，输出自然的人声。它的技术史清晰展示了「生成模型如何逐代升级」：

**拼接合成**：从录音库里拼出整句。音质真实但僵硬、可调节性差。
**参数合成**：统计模型预测声学参数。流畅但音质「电子感」强。
**神经 TTS**：端到端「文本 → 频谱 → 波形」。Tacotron 用注意力对齐文本与频谱，WaveNet 用自回归生成波形——2016 年起大幅提升自然度。
**零样本语音克隆**：输入几秒的参考语音，就能用「该音色」读出任意文本——YourTTS、Voicebox 等通过「说话人嵌入 + 条件生成」实现，这是 2020 年后的核心能力。<span class="marginnote">零样本克隆的原理：把「说什么」（内容）与「谁在说」（音色）解耦成两个条件——内容来自文本，音色来自参考语音的嵌入。解耦得越干净，克隆越像——这与 β-VAE 的解耦思想同出一源。</span>

**最新范式**：语音也被离散化成 token，用「语音语言模型」（如 VALL-E、SpeechGPT）直接把文本 token 与语音 token 拼接建模——**一个模型既能「听懂」又能「说出」，语音与语言在 token 层面彻底打通**。这条「语音即语言」的路线，正在把 TTS、语音识别、语音翻译统一成同一个多模态语言模型。

## 3 音乐生成：结构与风格的生成

音乐生成比语音更「高维」：不仅要合成声音，还要生成**音乐结构**——和弦进行、旋律动机、节奏型、段落反复。两条主要路线：

**符号音乐生成**：先生成乐谱（MIDI 序列），再渲染成音频。表示轻、可编辑性强，但音质受渲染器限制。MusicLM 早期、MuseNet 走这条线。
**音频级生成**：直接生成波形/频谱，音质高但难以精确控制「哪个音在哪」。Jukebox 用 VQ-VAE 把音乐离散化后做自回归，AudioLM、MusicLM 用离散音频 token + 语义 token 双层建模。

**MusicLM** 是一个分水岭：它把音频 token 分成两层——**语义 token**（捕捉「这个声音是什么」）与**声学 token**（捕捉「具体怎么发声」），先生成语义 token 序列（相当于「先想好要写什么音乐」），再据此生成声学 token（「再用什么音色演奏」）。**「先内容后音色」的分层生成**，与 LDM 的「先结构后纹理」是同一个哲学在音频里的投影。<span class="marginnote">「语义 token + 声学 token」的双层设计，巧妙地把「创作」与「演奏」分开：语义层负责创造力（旋律、结构），声学层负责表现力（音色、质感）。这种「内容/表达分层」的思想在视频（内容 vs 渲染）、3D（几何 vs 材质）里同样成立。</span>

## 4 公式解析：音频条件扩散 / 自回归的生成目标

以语音克隆为例，条件自回归音频生成的训练目标可以写成：

$$
p(\mathbf{a} \mid \text{text},\, \text{speaker}) = \prod_{t} p_\theta\big(a_t \mid a_{\\lt t},\, \text{text},\, e_{\text{spk}}\big)
$$

拆解三步：

- **第一步，音频 token 序列**：$\mathbf{a} = a_1, \dots, a_T$ 是离散音频 token 序列——生成被还原成「逐 token 预测」。
- **第二步，双条件**：内容来自文本（经语言模型编码），音色来自说话人嵌入 $e_{\text{spk}}$（由参考语音编码）——「说什么」与「谁在说」分离。
- **第三步，自回归逐位生成**：每个音频 token 以「已生成 token + 文本 + 音色」为条件——与语言模型的下一个 token 预测完全同构。

而扩散式 TTS（如 DiffWave、Grad-TTS）把梅尔频谱当「图像」，在频谱上跑去噪扩散，再用声码器转波形——**音频扩散与图像扩散共享同一个 MSE 去噪目标，只是数据的维度形态不同**。<span class="marginnote">对比可见：音频生成横跨「自回归」（token 序列）与「扩散」（频谱/波形）两大范式——音频的多尺度性质（从毫秒级波形到秒级语义）让它同时适合两种建模。这种「多表示并存」在 3D 生成里同样明显。</span>

## 5 音频生成的挑战与课程坐标

音频生成的开放难题：

**长时结构**：音乐要跨越几十秒甚至几分钟的结构连贯，当前的 token 窗口难以胜任。
**实时性**：语音合成要延迟低到「对话级」，扩散式 TTS 的多步采样是负担（少步采样技术同样适用）。
**版权与安全**：音乐生成触及版权，语音克隆触及身份冒用——这在本专题《生成模型的安全与版权》中详述。

从课程线看，音频生成是「生成模型工具箱 × 音频领域知识」的样本：它复用本专题的自回归、扩散、VQ-VAE、条件生成全部技术，只是把数据换成了「时间序列的声音」；同时它与《语音技术》《信号与系统》等课程共享对音频本身的理解。<span class="marginnote">从「极限到大模型」主线看，音频生成示范了「离散化作为统一接口」：一旦音频变成 token，它就能与文本、图像 token 一起，被同一个 Transformer 建模——这是通向《多模态生成》的又一座桥。</span>

## 6 音频生成的评估：耳朵比指标更挑剔

音频生成评估有与图像本质不同的难点：**音频是时间序列，听感是主观的，自动指标与人耳的一致性长期存疑**。

**可自动化的指标有限：**

**客观质量指标**：PESQ、STOI 等用于语音，衡量「自然度/可懂度」，但主要针对「有参考」的任务（语音增强、TTS 与真声对比）。
**频域距离**：梅尔频谱距离（MCD）比较生成与真实音频的频谱差异——简单但与人耳听感相关性一般（频谱接近≠好听）。
**MOS（Mean Opinion Score）**：让人类听众多维度打分（自然度、音色、韵律）——这是音频评估的「金标准」，但昂贵、主观、难复现。

**为什么自动指标这么难**：人耳对「毛刺、金属感、口型不同步」等细节极度敏感，而这些恰恰是「频域距离」等统计指标测不出来的。一个在 MCD 上很低的模型，听感可能依旧「假」——因为人类听的是「连续感知」，指标算的是「帧级统计」。

**实践配方：** 语音任务用「MOS + PESQ 组合 + AB 测试」；音乐生成主要靠「人工聆听 + 风格分类准确率 + 结构指标」。近年还引入「音色一致性」「韵律自然度」等细粒度人工维度。<span class="marginnote">音频评估的教训与图像 FID 一致又更进一步：<strong>指标只能照亮「统计接近」，人耳裁决「感知真实」</strong>。当模型进步到「统计上已接近、听感仍有差距」时，评估的重心就彻底倒向人工——这是高维感知生成（图像、音频、视频）共同的宿命。</span>

**一个值得记住的历史教训**：WaveNet 刚发表时，客观指标（MCD）的提升并不惊艳，但 MOS 人耳评分刷新纪录——它「听上去」的自然度远超指标显示的幅度。**在音频领域，永远把人耳当作最终的、也是最好的评估器**。把音频生成的要点再收几条：

- 表示决定路线：波形（信息全、维度高）、频谱（低维、需声码器）、token（与 LM 同构）。
- 语音强调可懂与音色，音乐强调结构与风格，技术侧重不同。
- 零样本克隆 = 内容与音色解耦：解耦越干净，克隆越像。
- 语音语言模型把语音 token 与文本 token 统一：TTS / ASR / 翻译走向一体。
- 语义 token + 声学 token 分层：先想内容、再定音色，与 LDM「先结构后纹理」同构。
- 实时性是硬指标：扩散 TTS 的多步采样需靠少步采样技术缓解。
- 评估靠 MOS + PESQ + 人工聆听：自动指标与人耳一致性长期存疑。
- 鲁棒性评估不可省：嘈杂环境、手机压缩、变速下是否仍自然。
- 高分可能是「过拟合测试环境」的假象：评估要覆盖多样信道与噪声。
- WaveNet 的教训：客观指标平平，MOS 人耳刷新纪录。
- 长时结构是音乐难题：几十秒到几分钟的连贯，token 窗口难以胜任。
- 版权与安全：音乐生成触及版权，语音克隆触及身份冒用。
- 离散化是统一接口：音频 token 与文本、图像 token 可同框建模。
- 与《语音技术》的衔接：这里偏「生成」，那里偏「分析」。

## 7 小结

- **音频生成**的独特难点：波形维度极高 + 人耳对时域敏感；表示决定路线（波形 / 频谱 / 离散 token）。
- **语音生成**演进：拼接 → 参数 → 神经 TTS → 零样本克隆；最新范式是「语音语言模型」把语音 token 与文本 token 统一。
- **音乐生成**侧重结构与风格；MusicLM 的「语义 token + 声学 token」分层把「创作」与「演奏」分开。
- 离散音频 token 让音频生成与语言模型同构，自回归与扩散两大范式在音频里并存。
- 挑战：长时结构、实时性、版权安全。
- 离散化是通往「统一多模态生成」的通用桥梁。

在下一节，我们把这些「模态的桥」全部收拢：文本、图像、视频、音频、3D 在一个模型里统一生成——这就是 **多模态生成模型**。
