## 为什么从 VAE 的改进开始

VAE 给了我们一个可生成、可插值的连续隐空间，但它有两个刺眼的缺陷：一是重建与生成的图像偏模糊，二是隐空间的维度纠缠在一起——一个维度同时编码「颜色、位置、姿态」，你没法单独拧「旋转」这一个旋钮而不动其他属性。2017 年的两篇工作分别击中这两个软肋：**β-VAE** 用一个小改动换取**解耦（disentanglement）**，**VQ-VAE** 用离散码本换取**锐利重建**。

这两篇论文的价值远超「修 bug」。β-VAE 把「KL 项的权重」从 1 改成 $\beta$，意外揭示了 ELBO 里那个看似琐碎的常数在控制隐空间的统计独立性；VQ-VAE 把隐变量从连续高斯换成**离散码表**，直接催生了 VQ-GAN、DALL·E 的离散化路线，也让我们看清「语言模型的 token 与图像模型的码字」其实是同一件事。<span class="marginnote">离散隐变量是理解大模型的一把钥匙：语言天然离散，图像经 VQ-VAE 也被离散化成码字序列，于是自回归 Transformer 可以同时处理两者——多模态生成因此有了统一语言。</span>

## 1 β-VAE：旋大正则项旋钮

β-VAE 的改动小到只有一处：给 ELBO 的 KL 项加上权重 $\beta$：

$$
\mathcal{L}(\phi,\theta;x) = \mathbb{E}_{z\sim q_\phi(z\mid x)}\big[\log p_\theta(x\mid z)\big] - \beta\, D_{KL}\!\big(q_\phi(z\mid x)\,\|\, p(z)\big)
$$

当 $\beta=1$ 就是标准 VAE。当 $\beta>1$（实验常用 $\beta=4$ 到 $8$），正则项被放大，编码器被迫把隐变量的信息「摊」到各维度上，使维度之间尽量统计独立。<span class="marginnote">直观图景：KL 是「信息税」，税率提高后，编码器不敢把信息挤在同一维度里打包，只好均匀分到多个正交维度——于是每个维度逐渐对齐一个独立语义因子。</span>

**解耦（disentanglement）**：隐空间中存在一组维度，每个维度单独控制一个可解释的语义因子，且不同维度互不干扰。

对 dSprites 这类合成数据集，β-VAE 能学出「隐变量维度 = 形状/尺度/旋转/位置」的漂亮对齐。**辨析｜易错点：** 解耦不等于质量提升——β 过大时重建质量明显下降（信息被「税」掉了），解耦与重建又是一场拔河；且真实数据（自然图像、文本）上不存在天然正交的语义轴，β-VAE 的解耦在真实数据上远不如合成数据那么干净。

## 2 VQ-VAE：把连续隐空间换成离散码本

**VQ-VAE（vector-quantized variational autoencoder）** 的动机一句话：**图像重建模糊，是因为连续高斯输出在平均化细节；改用离散码字 + 更丰富的输出分布，就能保住锐利纹理**。

VQ-VAE 的架构有四件套：

1. **编码器 $E$**：把图像 $x$ 映射成空间特征图 $z_e(x)$。
2. **码本（codebook）$e\in\mathbb{R}^{K\times D}$**：$K$ 个可学习的离散码字，每个是 $D$ 维向量。
3. **量化器**：对每个空间位置，把 $z_e(x)$ 替换成码本中与之最近的码字，得到离散表征 $z_q(x)$。
4. **解码器 $G$**：从 $z_q(x)$ 重建图像。

$$z_q(x) = e_k, \qquad k = \arg\min_j \| z_e(x) - e_j \|_2$$

**整张图被压缩成一个「码字索引图」**——每个 $8\times8$ 的 patch 对应一个码字编号，图像变成一串离散 token。这与文本的 tokenization 完全同构：`图像 → 码字序列`，等价于 `文本 → token 序列`。

## 3 公式解析：VQ 的三大损失

离散量化让「最近邻取码」这个操作不可导，VQ-VAE 用**直通估计器（straight-through estimator）**解决：前向取最近邻码字，反向梯度直接拷贝给编码器输出（仿佛没有量化）。在此基础上，损失分三块：

$$
\mathcal{L} = \underbrace{\|x - G(z_q(x))\|_2^2}_{\text{重建}} + \underbrace{\|\text{sg}[z_e(x)] - e\|_2^2}_{\text{码本}} + \underbrace{\beta_q \| z_e(x) - \text{sg}[e]\|_2^2}_{\text{承诺}}
$$

逐项拆解：

- **第一项 重建损失**：量化后的表征 $z_q$ 经解码器还原 $x$，逼码字携带足够信息。
- **第二项 码本损失**：把码字 $e$ 拉向编码器输出。`sg` 表示 stop-gradient（梯度不穿过它），避免码字与编码器互相追逐发散。
- **第三项 承诺损失**：把编码器输出拉向已选码字，防止编码器「随意漂移」，让量化结果稳定。

**辨析｜易错点：** `sg` 不是「没有梯度」而是「切断梯度」——它在反向传播中充当常数锚点。很多实现里码本损失会乘以较小权重（如 0.25）来平衡训练步调；码本更新的稳定性问题（某些码字永不匹配）还需靠 **EMA 更新** 或「重新播种」缓解，这在工程上比标准 VAE 更琐碎。

## 4 从 VQ-VAE 到 VQ-GAN：锐利生成的第一步

VQ-VAE 重建已比 VAE 清晰，但真正的图像生成升级在 **VQ-GAN**：用 VQ-VAE 把图像离散化成码字序列，再训练一个自回归 Transformer（或扩散模型）在码字序列上建模——生成时先预测码字序列，再经解码器还原成图像。这条流水线成为许多文生图系统的雏形：

| 组件 | 角色 | 类比 |
| --- | --- | --- |
| VQ-VAE 编码器 + 码本 | 图像 → 离散 token | 词法分析 |
| 码字索引序列 | 离散表征 | token 序列 |
| 自回归 Transformer | 学习码字序列分布 | 语言模型 |
| VQ-VAE 解码器 | 离散 token → 图像 | 渲染/解码 |

VQ-GAN 还引入了**感知损失与对抗损失**，让重建不再只靠 L2，进一步锐化纹理。这解释了为什么后来的 DALL·E、图像扩散系统的潜空间多继承自 VQ 家族或与感知损失配合——**离散 + 感知 + 对抗，三者合力补上了 VAE 模糊的短板**。<span class="marginnote">VQ 离散化的另一好处：码本天然可作为「词汇表」，配合自回归模型做<strong>顺序建模</strong>，让图像也能享受 Transformer 的并行训练与长程依赖建模——这条线在《多模态生成》与《文生图》两篇会再次交汇。</span>

## 5 两种改进路线对照

β-VAE 与 VQ-VAE 看似无关，实则分别回答「隐空间质量」与「重建质量」两个正交问题：

| 维度 | β-VAE | VQ-VAE |
| --- | --- | --- |
| 隐变量类型 | 连续 | 离散码字 |
| 核心改动 | KL 权重 $\beta$ | 最近邻量化 + 直通估计 |
| 目标 | 解耦、可解释维度 | 锐利重建、离散 token 化 |
| 代价 | 重建下降 | 码本不均衡、工程复杂 |
| 谱系 | 可控生成、表征学习 | VQ-GAN、文生图、多模态 token |

两条路后来殊途同归：**真实世界的生成既需要可控的隐空间，也需要锐利的重建**。潜在扩散模型（LDM）正是用 VAE 的感知重建作为潜空间、再用扩散模型在其中生成——本专题《潜在扩散模型》会把这条线接上。

## 6 工程细节：码本训练的「手艺活」

VQ-VAE 的论文页面很短，真正的挑战藏在实现细节里。三个反复出现的工程问题值得记住：

**问题一：码本「死码字」。** 训练初期某些码字从不被任何特征选中，成为「僵尸码字」——白白占用码本容量。两个经典解法：**EMA 更新**（用指数移动平均平滑地更新被选中的码字，让码字更稳定地「生长」）与**码字重新播种**（检测长期不匹配的码字，随机重置到当前活跃特征附近）。社区经验是：**EMA 通常比梯度更新更稳**，是首选。

**问题二：码本大小 $K$ 怎么选。** $K$ 太小（如 128）会让不同 patch 被迫共享同一码字，重建粗糙；$K$ 太大（如 16384）会让码字利用率急剧下降、死码字变多。常见选择在 512–8192 之间，且**与数据的复杂度和下采样因子 $f$ 强相关**——这是「表示容量 vs 利用率」的权衡。

**问题三：β-VAE 的 β 怎么调。** β 太小解耦不明显，太大重建崩溃。实践常从 β=1 开始，每观察到「重建变糊」就下调一档；或采用**渐进式 β 退火**（训练中从小 β 慢慢升到大 β），先保住重建、再逐步加强解耦。

这些「手艺活」看似琐碎，却是把论文模型变成可用系统的关键。**表示学习模型的成败，往往藏在「如何维护离散/连续表征的稳定性」这些工程细节里**——这也是社区会为「哪个码本更新方式更好」反复争论的原因。把 VQ / β 的工程经验再压缩成几条速记：

- 码本大小与数据复杂度匹配：512–8192 是图像任务常见区间，太小糙、太大废。
- EMA 优先于梯度更新：码字更新要平滑，避免「码字与编码器互相追逐」。
- β 退火是默认操作：先小（保重建）后大（求解耦），比固定 β 更容易两全。
- 死码字主动清理：定期统计命中率，长期不命中的重置到活跃区域。
- 表示维护的本质：稳定性（EMA）与灵活性（播种）的权衡，适用于一切表征学习。
- 与大模型 embedding 的联系：token 嵌入同样面临「冷启动、利用率」问题，思路可移植。
- 工程结论：表示学习模型的成败，往往藏在「表示维护的稳定性」这些细节里。

## 7 小结

- **β-VAE**：把 KL 项权重改为 $\beta$，用「信息税」逼迫维度解耦；代价是重建质量下降，真实数据上解耦不如合成数据干净。
- **VQ-VAE**：用 $K$ 个码字的最近邻量化把图像变成离散 token，直通估计器让量化可导。
- **VQ 三损失**：重建 + 码本 + 承诺，`sg`（stop-gradient）是各司其职的锚点。
- **离散化的意义**：图像 token 与文本 token 同构，让自回归与扩散都能统一建模多模态。
- **谱系**：β-VAE → 可控生成；VQ-VAE → VQ-GAN → 文生图离散路线。

在下一节，我们从「近似隐变量」转向「精确可逆」：把简单分布通过一系列可逆变换推成复杂分布，似然全程精确可算——这就是**归一化流模型**。
