## 为什么从氮磷硫开始

碳循环讲了「谁在搬」，水循环讲了「车夫是谁」，但还缺一个问题：**车夫的燃料从哪来？** 生物要生长，光有碳不够——蛋白质需要氮，核酸与能量货币（ATP）需要磷，蛋白质的空间结构需要硫。这三个元素合称**营养元素（nutrients）**，它们的循环决定了一个关键指标：**初级生产力（primary productivity）**，即光合作用固定碳的总速率。

营养元素循环与碳循环有三大根本区别，这决定了它们各自的叙事：<span class="marginnote"><strong>记住一句话：碳是「冗余供给」（大气里碳很充裕，限制的是吸收通道），营养元素是「稀缺供给」（它们的可用量直接限制生长）。</strong>碳的问题是要处理太多，营养元素的问题是够不够用。</span>

**限制定律**：碳不是限制因子（大气 $\ce{CO2}$ 对植物而言通常过剩），而氮磷常常是**限制因子**——海洋里谁缺氮磷，谁就封顶了生产力。
**大气储库的差异**：氮有巨大的惰性大气储库（$\ce{N2}$ 占大气 78%），但植物用不了；磷几乎没有气相形态，全靠岩石风化供给。
**人类扰动的性质**：碳是人类在**排放**，氮磷是人类在**制造并投放**——人类固氮已超过自然固氮，这是所有循环里最彻底的人类主导。

## 1 氮循环：从惰性到活性

**核心概念：** 氮循环（nitrogen cycle）是氮元素在五种氧化态（$-\text{3}$ 到 $+\text{5}$）之间的转化链条，它把大气中惰性的 $\ce{N2}$ 转化为生物可利用的活性氮。

天然氮循环有五个关键工序：

**固氮（nitrogen fixation）**：把 $\ce{N2}$ 还原为氨（$\ce{NH3}$），由固氮微生物（根瘤菌、蓝藻）与闪电完成。这是氮进入生物圈的**唯一天然入口**。

氮的五种关键氧化态值得用一张表记住——它们是「谁转化成谁」的地图：

| 氧化态 | 主要形态 | 在循环中的角色 |
| --- | --- | --- |
| $-\text{3}$ | 氨/铵（$\ce{NH3}$、$\ce{NH4^+}$） | 固氮产物、同化入口 |
| $0$ | 氮气（$\ce{N2}$） | 大气惰性储库 |
| $+\text{3}$ | 亚硝酸盐（$\ce{NO2^-}$） | 硝化中间态 |
| $+\text{5}$ | 硝酸盐（$\ce{NO3^-}$） | 植物最易吸收、最易淋失的形态 |

**读这张表的要诀是氧化态**：氮循环的每一步本质上都是**氧化还原反应**——固氮把 0 价还原到 $-3$，硝化把 $-3$ 氧化到 $+5$，反硝化再走回 0 价。生物用这些「电子转移」完成化学能的交换，这与第二级《无机化学》里的氧化还原化学完全同构。
**硝化（nitrification）**：氨被氧化为亚硝酸盐（$\ce{NO2^-}$）再到硝酸盐（$\ce{NO3^-}$）。硝酸盐是植物最易吸收的形态。
**同化（assimilation）**：植物把硝酸盐/氨合成氨基酸与蛋白质。
**氨化（ammonification）**：分解者把有机氮矿化回氨，供下一轮使用。
**反硝化（denitrification）**：$\ce{NO3^-}$ 被还原回 $\ce{N2}$ 释放入大气，关闭循环。这是天然系统「卸压」的阀门。<span class="marginnote">天然氮循环的「预算」：全球自然固氮约每年 1.1–1.3 亿吨氮，反硝化约等量——收支大致平衡。人类的出现把这个平衡打破了。</span>

**人类干扰——哈伯-博施法的世纪：** 1913 年哈伯-博施（Haber-Bosch）工艺把 $\ce{N2}$ 与 $\ce{H2}$ 直接合成氨，人类从此可以不依赖微生物制造活性氮。如今化肥工业固氮约每年 1.2 亿吨，再加农田豆科固氮与燃烧排放，**人类造成的活性氮通量已经超过全部自然固氮之和**。这是本专题行星边界一章中「生物地球化学流」边界被突破的直接原因。

氮循环的人为扰动还有一条**隐蔽的支线**：反硝化的不完全产物氧化亚氮（$\ce{N2O}$）。化肥过量施用与污水排放使反硝化速度加快，但最后一步「$\ce{N2O} \to \ce{N2}$」常被打断，于是温室气体 $\ce{N2O}$ 逸入大气——它的单分子增温潜势约为 $\ce{CO2}$ 的 273 倍，且会催化平流层臭氧损耗。**过量施氮因此同时伤害气候、臭氧层与水体**——一条化肥链，牵动三条地球系统底线。

## 2 磷循环：没有气相的「单行道」

磷与氮最本质的区别：**磷没有显著的气相形态**，大气循环对磷几乎不起作用。它的循环是岩石到沉积岩的「单行道」：

岩石风化 → 土壤磷酸根（$\ce{PO4^{3-}}$）→ 植物吸收 → 食物链 → 分解/流失 → 河流入海 → 深海沉积

**重点：磷循环的时间尺度由地质过程（风化与抬升）决定，以万年至百万年计。** 这带来两个后果：其一，磷是典型的**不可再生养分**——磷矿是有限的，磷肥依赖磷矿开采；其二，磷在陆地系统里「只出不进」，流失的磷要等地质循环重新抬升沉积岩，人类世代内无法恢复。<span class="marginnote">磷肥的「峰值磷（peak phosphorus）」讨论与石油峰值类似：按当前储量与开采速度，优质磷矿的开发峰值可能出现在本世纪内。磷循环因此既是生态问题，也是资源战略问题。</span>

人类对磷循环的干扰集中在**富营养化**：磷肥与生活污水里的磷进入湖泊、河流与近海，刺激藻类暴发，藻华死亡分解耗尽氧气，形成缺氧死区（dead zone）。墨西哥湾、波罗的海都是磷氮共同超载的典型死区。

## 3 硫循环：火山、海洋与酸雨

硫循环的独特之处在于它**横跨还原与氧化、陆地与海洋、自然与污染**多个维度：

**自然源**：火山喷发释放 $\ce{SO2}$ 与 $\ce{H2S}$；海洋浮游植物释放**二甲基硫（DMS，$\ce{(CH3)2S}$）**，进入大气后氧化为硫酸盐气溶胶——它们影响云凝结核与反照率，是海洋与气候耦合的化学通道。<span class="marginnote">DMS-气溶胶-云这条链是著名的「克莱森假说（CLAW hypothesis）」主角：海洋生物可能通过 DMS 调节云量、影响温度，构成一条生物→气候的负反馈。证据仍在争论中，但它是「生物圈调节气候」叙事的最经典案例。</span>
- **人为源**：煤炭与石油中的硫燃烧生成 $\ce{SO2}$，在大气中被氧化为硫酸（$\ce{H2SO4}$），随降水形成**酸雨（acid rain）**。20 世纪后半叶，欧美与东亚的大面积酸雨造成了森林退化、湖泊酸化与建筑材料腐蚀。
- **治理范例**：通过脱硫（烟气脱硫）、使用低硫燃料与排放控制，欧美 $\ce{SO2}$ 排放已大幅下降，酸雨显著缓解——**硫循环是人类成功治理环境污染的少数完整案例**，为今天的气候治理提供了「可以逆转」的实证。

## 4 公式解析：雷德菲尔德比

营养元素循环最精炼的定量表达，是海洋生物学家雷德菲尔德（Alfred Redfield）1934 年发现的**雷德菲尔德比率**：海洋浮游植物体内碳、氮、磷的平均摩尔比接近恒定。

$$\ce{C : N : P = 106 : 16 : 1}$$

- **第一步，读比例的含义**：海洋浮游植物每固定 106 摩尔碳，大约需要 16 摩尔氮与 1 摩尔磷。这个比例把碳、氮、磷三套循环用**化学计量**焊在了一起。
- **第二步，读「恒定」的来历**：海水深层溶解的无机碳、氮、磷之比，恰好与浮游植物体内的比例接近——因为生物吸收与再矿化是双向的：光合吸收按此比例取走，分解再矿化按此比例放回。<span class="marginnote">更深一层：比例之所以稳定，可能是生态进化的结果——长期共同演化让浮游生物的元素组成与海水的供给耦合。它因此成为全球海洋生物地球化学模式（见第三篇《地球系统模式》）里的固定参数。</span>
**第三步，读人类干扰的后果**：当氮磷比被人为打乱（比如农业大量施氮、而磷相对稀缺），海洋局部就出现「氮多磷少」或反之的失衡，生产力与群落结构随之改变。**雷德菲尔德比是衡量这种失衡的天然标尺。**

**辨析｜易错点：** 雷德菲尔德比是**海洋浮游生物**的统计规律，不是陆地植物或所有生物的通用比例。陆地植物碳氮比通常远高于海洋藻类（木材以碳为主）。把它直接套到陆地生态上，是初学者常犯的越界。

## 5 小结

营养元素循环与碳循环的根本区别：碳是**冗余供给**，氮磷是**稀缺供给**；限制的不是吸收通道而是可用量。
氮循环是五种氧化态间的转化链；**固氮**是唯一天然入口，**反硝化**是天然卸压阀。
哈伯-博施工艺让人类固氮**超过全部自然固氮之和**——人类已主导氮循环。
磷循环是**没有气相的岩石单行道**，时间尺度以地质计，磷矿有限、流失不可逆，富营养化与死区是核心干扰后果。
硫循环横跨自然与人为源；**酸雨治理是环境污染可逆转的完整实证**。
雷德菲尔德比 $\ce{C:N:P = 106:16:1}$ 是海洋化学计量的标尺，但**不适用于陆地**。
过量施氮的反硝化产物 $\ce{N2O}$ 是强温室气体并催化臭氧损耗——一条化肥链牵动气候、臭氧与水体三条底线。
氮循环的核心是**氧化还原态转换**：固氮还原、硝化氧化、反硝化回归，与无机化学的电子转移完全同构。

在下一节，我们终于从物质循环转向能量的根本来源——**气候系统与辐射平衡**。氮磷硫决定生命长多快，而辐射决定地球有多热。

## 延伸阅读与深度追问

**深度追问：四个值得多想一步的问题**

**追问 1：为什么海洋常出现「氮磷共同限制」而不是单一限制？**
  经典雷德菲尔德理论假设浮游植物按 $\ce{C:N:P = 106:16:1}$ 取用氮磷，谁的供应先耗尽谁就限制生长。但观测显示许多海区在季节与空间上是**氮限制、磷限制交替**，甚至两者同时不足。原因有二：一是固氮蓝藻能自行制造氮，把「缺氮」海区慢慢往磷限制推；二是不同物种的元素需求不同，群落层面的限制是多种限制的加权。**「单一限制因子」只是教科书的一阶近似，真实海洋是动态的共同限制系统。**<span class="marginnote">这也解释了为什么海洋施肥实验（撒铁或撒氮）从未产生稳定的增产效果：补上一个限制因子，立刻暴露出下一个——就像给旱地浇水后，发现土壤又缺钾。</span>

- **追问 2：固氮蓝藻为什么没有被氮肥「喂死」？**
  氮肥充足时，固氮是昂贵的（每固定一分子 $\ce{N2}$ 要消耗大量能量），蓝藻会主动关闭固氮酶、转而直接利用现成氮——固氮优势只在缺氮时存在。这造成一个悖论：**人为富氮可能抑制自然固氮，让系统更依赖工业氮**，一旦化肥供给中断，生态恢复反而受阻。这是氮循环「人类主导」之后的新议题。

- **追问 3：硫循环的酸雨治理为什么成功了，而碳循环还没有？**
  因为硫和碳的「治理经济学」完全不同。硫的可替代性强（可以用低硫煤、脱硫装置、天然气替代），排放源集中（电厂与冶炼厂是点源），且酸雨损害以**局地/区域**为主——受益者就是治理者自己。碳则相反：源分散、无现成替代、且损害是全球公共品。**硫治理成功证明了「环境问题可逆」，碳治理缓慢证明了「公共品难题」，两者共同解释了第15章治理章节的结构性困难。**

- **追问 4：营养循环如何制约碳汇？**
  第6章讲过陆地碳汇的「施肥效应」受养分限制：缺氮磷的森林无法充分利用额外 $\ce{CO2}$。海洋同理——铁限制着许多高营养海区的浮游植物。**碳、氮、磷、铁的耦合，决定了「碳汇能吸多少」这个碳循环公式里的 $S$ 项**。因此营养循环不是碳循环的附属品，而是它的上限约束。
