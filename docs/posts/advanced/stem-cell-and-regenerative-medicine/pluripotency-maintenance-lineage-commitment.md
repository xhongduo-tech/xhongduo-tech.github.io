## 为什么从多能性讲谱系分化

上一节我们在细胞层面回答了「干细胞如何保持自我」，这一节把镜头推向**细胞状态的空间**：一个多能干细胞如何「记住」自己是多能的、又如何一步步「决定」走向肝、神经还是血细胞？<span class="marginnote">沃丁顿 1957 年用「表观遗传景观」比喻发育：细胞像从山脊滚下的球，多能态在山顶，越往下分叉越多、选择越窄；所谓「分化」就是沿着山谷走向某个终态。这张景观图至今仍是理解干性维持与谱系承诺的最佳心智模型。</span>多能性的**维持**与**退出**是同一个硬币的两面——维持靠核心转录网络的自稳，退出靠信号诱导的「分叉选择」。

## 1 多能性的核心调控网络

多能性不是某个单一基因决定的，而是一组转录因子构成的**自稳环路（self-sustaining loop）**。在胚胎干细胞（ESC）中，核心是三个转录因子：

**Oct4**：POU 家族转录因子，多能性的「主开关」，其表达量必须在特定窗口内——过高促分化，过低也促分化。<span class="marginnote">Oct4 的表达剂量敏感是干细胞生物学的经典现象：正常水平的 Oct4 维持多能性，过量或不足都会把 ESC 推向分化。这说明多能性网络对「剂量」而非仅「有无」敏感，是典型的非线性调控。</span>
**Sox2**：与 Oct4 形成异二聚体，共同结合下游靶基因增强子，二者协同激活多能性基因（含 Nanog、FGF4 等）并抑制分化基因。
**Nanog**：同源框转录因子，2010 年代被广泛研究的「多能性卫士」；高表达 Nanog 的细胞更倾向于维持未分化态，其表达存在异质性——同批 ESC 里 Nanog 高低不同的细胞，对分化信号的「抵抗」不同。

三个因子互相激活、又共同激活自身与对方，构成**正反馈**：只要这个环在运转，多能态就是稳定的吸引子；一旦环被外部信号打破（如撤去白血病抑制因子 LIF），细胞就从多能态「滑落」向分化态。

## 2 多能性的维持：外因信号与内因状态

维持 ESC 多能性需要**外源信号**与**内源网络**配合。小鼠 ESC 的经典配方是培养基中加入 **LIF（白血病抑制因子）+ 血清或 BMP4**：

**LIF/STAT3 通路**：LIF 结合 LIFR-gp130 受体，激活 JAK-STAT3 信号，直接维持核心网络——撤去 LIF，小鼠 ESC 迅速分化。
**BMP4/Smad 通路**：血清中的 BMP4 通过 Smad 激活 Id 基因，抑制神经外胚层分化，同时诱导 c-Myc 支持自我更新。

**核心要点：** 「LIF + BMP」其实是一对**攻守组合**——LIF 守住多能性本身，BMP 压制第一条分化路径（神经），两者协同把细胞钉在多能态。这与 2i（两个小分子抑制剂）培养法对照鲜明：2i 用 PD0325901 抑制 MEK、CHIR99021 抑制 GSK3，通过**屏蔽分化信号 + 模拟自我更新信号**达成同一目标。<span class="marginnote">2i 培养使小鼠 ESC 回到更「原始」的多能态（ground state），Nanog 表达趋于均匀，为研究多能性的分子机制提供了更纯的模型；人类 ESC 的对应状态需要额外激活 NODAL/ACTIVIN 通路，说明人多能性的维持逻辑比小鼠更复杂。</span>人和鼠 ESC 的维持信号并不完全一致，这是本章最容易出错的地方：**小鼠 ESC 靠 LIF/STAT3，人 ESC 靠 bFGF/ACTIVIN 通路**，两者不可互换。

## 3 谱系分化的启动：信号分叉与多能态退出

分化启动的本质是**多能性网络的「解锁」**：某个谱系决定信号把核心网络压制到阈值以下，同时激活第一批谱系特异的转录因子。以三胚层建立为例，最早的分子分叉依赖几个形态发生素：

**TGF-β/Activin/Nodal**：高浓度 Nodal 激活内胚层程序（Sox17、FoxA2），低浓度则偏向中胚层。
**BMP4**：浓度梯度决定中胚层与外胚层的边界；高 BMP 促中胚层/滋养层，BMP 抑制则促神经外胚层。
- **Wnt**：参与中胚层与后轴命运；Wnt 抑制与 Activin 协同促进前部神经命运。
- **FGF**：支持中胚层、神经命运的后续维持。

**辨析｜易错点：** 不要把「某个因子决定某谱系」读成一对一的指令。**形态发生素是浓度依赖、时间依赖的多次阅读**——同一个 BMP4，在高浓度、低浓度、不同时序下给出不同结果。体外定向分化实验里最难复现的正是这种「剂量-时序」的精确安排，这也是为什么分化方案往往需要几十次优化。

## 4 谱系承诺的层级：从多能到定型

分化不是一步到位的「跳变」，而是逐级收窄的**承诺阶梯**。每一级都由一组**谱系特异转录因子**（lineage-specific TFs）驱动，并伴随**表观遗传锁定**：

| 层级 | 状态 | 代表转录因子 | 特征 |
| --- | --- | --- | --- |
| 多能态 | pluripotent | Oct4, Sox2, Nanog | 可分三胚层，可自我更新 |
| 定型祖细胞 | committed progenitor | 依谱系而定（如 Pax6 神经、Scl/Tal1 血液） | 潜能收窄，但仍可分裂 |
| 前体细胞 | precursor | 谱系特异 + 效应基因启动 | 有限分裂后走向终末 |
| 终末分化 | terminally differentiated | 效应基因（如珠蛋白、胰岛素） | 退出细胞周期，丧失可塑性 |

<span class="marginnote">「承诺」在分子上意味着什么？一是<strong>转录因子的自我激活</strong>（谱系 TF 激活自身，形成新的自稳环），二是<strong>表观遗传的锁定</strong>（分化基因位点获得活性修饰，多能性基因位点被 DNA 甲基化与 Polycomb 沉默）。承诺越深，用外力「逆转」就越难——这正是重编程与直接转分化要对抗的「下山容易上山难」。</span>理解这个阶梯对再生医学至关重要：**再生策略不一定要回到多能态**。把成纤维细胞直接转分化为肝细胞或神经元（不经过多能态的「直接转分化」），正是绕开多能态、在承诺阶梯的「半山腰」切换命运——这是第2篇《体细胞核移植与直接转分化》的核心。

## 5 公式解析：多能性网络的布尔逻辑

把多能性网络抽象成最小可算的模型，便于看清「为什么扰动会触发分化」。设 $O$、$S$、$N$ 分别表示 Oct4、Sox2、Nanog 的活性（取 0 或 1），三者的自稳环可写成布尔方程：

$$
O_{\text{next}} = (O \lor S) \land \neg D, \qquad N_{\text{next}} = (O \land S) \lor N
$$

- **第一步，读懂第一式**：$O_{\text{next}} = (O \lor S) \land \neg D$。$O \lor S$ 表示「Oct4 或 Sox2 激活自身/对方」，$\neg D$ 表示「分化信号 $D$ 未出现」。只要分化信号被抑制，Oct4 就靠正反馈自持。
- **第二步，读懂第二式**：$N_{\text{next}} = (O \land S) \lor N$。Nanog 要么被 Oct4 与 Sox2 共同激活，要么一旦开启就自我维持——这是 Nanog 高异质性的来源：已经 ON 的细胞倾向于保持 ON。
- **第三步，看扰动如何翻转**：当分化信号 $D=1$（例如撤去 LIF、加入 RA），第一式的 $\neg D$ 变为假，Oct4 失去正反馈来源，$O$ 归零；$O$ 归零又使第二式第一项失效，$N$ 只能靠自身维持——但 Nanog 的自我维持同样依赖多能网络支持，在持续的分化信号下很快也归零，整个环路在数轮内坍缩到 $O=S=N=0$，细胞跨过多能态与分化态之间的壁垒，开始执行谱系程序。
- **第四步，从布尔模型回看生物现实**：布尔近似丢掉了剂量、时滞与随机性，但它抓住了最关键的一点——**多能性是一个带自锁的「整体状态」，而不是单个基因的开关**。外部信号只有把多个节点同时拉离阈值，环路才整体解锁。这也为第2篇《重编程》中「重编程效率低、且是整体状态切换」的观察埋下分子伏笔：把一个坍缩的网络重新拉回多能态，远比维持它困难。这种「状态 = 吸引子、转变 = 越过壁垒」的语言，正是本站「系统生物学」脉络里动力系统视角在细胞命运上的重现。

## 6 两种多能态：naive 与 primed

小鼠与人的多能性维持逻辑不同，根源在于两者处于**不同的多能态**：小鼠 ESC 是**原始态（naive）**，人 ESC 与 iPSC 是**始发态（primed）**——它们对应着发育时间轴上的两个不同瞬间。

| 特征 | Naive 多能态 | Primed 多能态 |
| --- | --- | --- |
| 代表细胞 | 小鼠 ESC（经典培养） | 人 ESC/iPSC、小鼠 EpiSC |
| 维持信号 | LIF/STAT3（+BMP 或 2i） | bFGF/Activin-Nodal |
| 雌性 X 染色体 | 两条均活化 | 一条已随机失活 |
| 克隆形态 | 圆顶状、致密、立体感强 | 扁平、铺展、单层 |
| 嵌合体种系传递 | 能参与 | 几乎不能 |
| 对应发育阶段 | 囊胚 ICM | 上胚层（epiblast）稍晚 |

**辨析｜易错点：** 很多人误以为「人 ESC 只是小鼠 ESC 的『人类版本』，培养配方通用」——实际二者隔着一个 naive/primed 的状态差。<span class="marginnote">同源关系的正解是：<strong>小鼠 ESC ≈ 小鼠 EpiSC（体外转变）+ 人 ESC</strong> 分别对应囊胚 ICM 与植入后上胚层两个时刻；小鼠 ESC 与小鼠 EpiSC 之间可以体外相互转变，这证明 naive/primed 是可切换的状态而非宿命。</span>这也解释了为什么「把小鼠配方直接搬到人上」总是失败：**人在培养皿里天然落在 primed 态，需要的是 bFGF 而非 LIF。**

## 7 多能态的异质性：流动的干性

即便在一瓶「纯」的 ESC 里，多能性也并非均匀。**Nanog 的表达存在显著的细胞间异质性**：同一培养皿中，Nanog 高的细胞更抗分化信号，Nanog 低的细胞更容易被推向分化。

**核心要点：** 这种异质性不是噪音，而是多能性「可塑性」的体现——**ESC 群体是围绕多能吸引子波动的集合**，单细胞会在高/低多能状态之间流动。实验上已证明：分选出 Nanog 低表达的细胞重新培养，群体又能恢复到 Nanog 高的分布——说明这是动态平衡而非固定的亚群。

这对实验室与产业都有直接含义：**分化实验的「起点」从来不是一个点，而是一条分布。** 分布越宽，分化结果越不齐；这也是为什么「2i 培养使 Nanog 表达均匀化」会被视为迈向 ground state 的标志——把起点分布收紧，是提高分化可重复性的关键一步，也是第5篇《GMP》里「过程控制」要解决的微观问题。

## 8 从景观到工艺：谱系承诺如何指导再生医学

理解了承诺阶梯，就能看懂体外定向分化为什么必须「顺着发育走」——这正是第2篇《拟胚体与体外分化》的方法论前提。

**谱系承诺就是体外分化方案的「地图」**：既然多能态要经定型祖细胞逐级走到终末，诱导方案就要像重演发育一样逐站施加信号。最经典的范本是 β 细胞五步法：先让 ESC 走向定型内胚层（Activin/Nodal），再拉成肠管（FGF、维甲酸），继而背侧化胰腺（RA、SHH 拮抗）、内分泌祖细胞（Notch 抑制），最后成熟为胰岛素分泌细胞——每一步都对应承诺阶梯上的一级，都要用标志物设卡验证纯度。

**多能性维持质量直接决定分化质量**：分化实验的起点状态（naive/primed、传代代数、核型）如果不达标，后面所有步骤的效率都会打折。这也是为什么临床级生产要先管好「种子库」——**谱系分化的上限，在细胞还没开始分化时就已经决定了**。

**承诺阶梯还解释了「直接转分化」的工程价值**：跳过被锁定的中间状态、用谱系因子在「半山腰」直接换道（第2篇《体细胞核移植与直接转分化》），本质是用工程手段绕开承诺阶梯的漫长路径。代价是不能扩增，收益是快与低风险——两条路的选择，取决于产品需要「产量」还是「直达」。

## 9 小结

- 多能性由 **Oct4/Sox2/Nanog 自稳环路**维持，是「带自锁的整体状态」；剂量敏感、可被分化信号整体解锁。
- 维持外因：小鼠 ESC 靠 **LIF/STAT3 + BMP**（或 2i），人 ESC 靠 **bFGF/Activin**；人鼠不可互换，根源是 naive/primed 状态差。
- 分化启动 = 形态发生素（Nodal/BMP/Wnt/FGF）的**浓度-时序依赖阅读**，读出第一批谱系特异转录因子。
- 谱系承诺是**逐级收窄的阶梯**：多能 → 定型祖细胞 → 前体 → 终末；越深越难逆转，表观遗传锁得越死。
- 多能性是**流动的**：Nanog 异质性让 ESC 群体围绕吸引子波动，「收紧起点分布」是提高分化可重复性的关键。
- 承诺阶梯是定向分化方案的「地图」：五步法重演发育、逐步设卡；起点质量决定分化上限。
- 人鼠培养配方的差异根源是 naive/primed 状态差，正确对照是「小鼠 ESC ↔ 人 ESC（primed）+ 小鼠 EpiSC」，而非「人 = 小鼠的人类版」。
- 布尔模型提醒我们：多能性是「整体自锁状态」，重编程本质是「重新建环」——这为下一节信号通路的分子语法做好了铺垫。
