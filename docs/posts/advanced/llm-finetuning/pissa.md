## 为什么从 PiSSA 开始

LoRA 有一个常被忽视的细节：**它的 $A$ 矩阵是随机初始化的**。而 $A$ 定义了「低秩子空间」的基底——从随机基底出发，意味着模型要先「找到」合适的方向再学，这一步是浪费的。2024 年的 **PiSSA**（Principal Singular values and Singular vectors Adaptation）提出一个更聪明的起点：**用基座权重的主奇异分量来初始化 LoRA 矩阵**。

名字本身就是方法：**P**rincipal **I**S**SA**——把权重 $W_0$ 做奇异值分解，把最大的 $r$ 个奇异值对应的分量「搬进」可训练的低秩分支。论文声称 PiSSA 比 LoRA **收敛更快、最终效果更好**，尤其在低秩、低数据场景。它的思路也对「LoRA 为什么有效」给出了新的解释。<span class="marginnote">PiSSA 与 DoRA 可以看作 LoRA 改进的两个互补方向：<strong>DoRA 改的是「训练什么」（方向 vs 幅度），PiSSA 改的是「从哪出发」（随机 vs 主奇异）</strong>。两者不冲突，后来甚至有人把它们叠加使用。</span>

## 1 LoRA 的隐藏浪费：随机初始化的 $A$

回顾 LoRA 的初始化：$A \sim \mathcal{N}(0, \sigma^2)$、$B = 0$。$B$ 置零保证了「从基座出发」，但 $A$ 是随机的——这意味着：

**训练初期，$A$ 定义的子空间是「随机朝向」的**。模型必须先花大量步数，把 $A$ 从随机方向「旋转」到真正有用的方向，然后才谈得上学习增量。这好比你要在一个房间里找出口，却先蒙着眼转了几圈才看清门在哪。

更深一层：**LoRA 的低秩子空间到底是「学出来的」还是「早就该有的」？** PiSSA 认为，适合微调的低秩子空间，很大程度已经隐含在基座权重里——$W_0$ 的**主奇异方向**（最大奇异值对应的左右奇异向量）就是这个子空间的天然基底。与其随机初始化再慢慢学，不如**直接把这些方向搬出来当起点**。

## 2 PiSSA 的思想：把主奇异分量搬进可训练分支

PiSSA 的初始化分三步：

1. **奇异值分解**：$W_0 = U \Sigma V^\top$，其中 $\Sigma$ 的对角元是奇异值 $\sigma_1 \ge \sigma_2 \ge \dots$；
2. **取主分量**：只保留前 $r$ 个奇异值与对应奇异向量，构成「主分量」$W_0^{\text{principal}} = U_r \Sigma_r V_r^\top$；
3. **重新装配**：把主分量拆进 LoRA 分支——令 $A = \Sigma_r V_r^\top$、$B = U_r$（等价于 $BA = U_r \Sigma_r V_r^\top$），基座则改成「去掉主分量」的残差：

$$
W = \underbrace{W_0 - W_0^{\text{principal}}}_{\text{冻结的残差}} + \underbrace{B A}_{\text{可训练的主分量}}
$$

训练时，**残差部分冻结，$A$、$B$ 更新**。注意这与 LoRA 的根本差别：LoRA 的 $\Delta W$ 从 0 开始，PiSSA 的 $BA$ 一开始就等于 $W_0$ 的主分量——**可训练参数不再是「零增量」，而是「最重要的那部分权重本身」**。<span class="marginnote">一个直观类比：LoRA 是「画一张透明纸盖在地图上，从白纸开始描路线」；PiSSA 是「把地图上最重要的几条路先描出来，再让你在它们附近微调」——起点就是有用的，学习自然更快。</span>

把两者并排，差异就在一行初始化里：

| 维度 | LoRA | PiSSA |
| --- | --- | --- |
| $A$ 初始化 | 随机高斯 | 主奇异分量 $\Sigma_r^{\frac12} V_r^\top$ |
| $B$ 初始化 | 零 | 主奇异分量 $U_r \Sigma_r^{\frac12}$ |
| 初始 $\Delta W$ | 0（从基座出发） | $W_0$ 的主分量（从最重要方向出发） |
| 冻结部分 | $W_0$ 全部 | $W_0$ 去掉主分量的残差 |
| 训练起点信息 | 无 | 有（主奇异方向） |
| 适用场景 | 通用 | 小秩、少数据、要更快收敛 |

这一行「初始 $\Delta W$」的差别，就是收敛速度与最终效果差异的全部来源——其余训练配置几乎可以原样沿用。

一个 $2\times 2$ 的完整算例，可以把「搬主分量」落到可手算的数字上。设 $W_0 = \begin{pmatrix}3 & 0 \\ 0 & 1\end{pmatrix}$，其 SVD 可直接读出：$U = I$、$\Sigma = \mathrm{diag}(3, 1)$、$V = I$。取 $r = 1$：

- $W_0^{\text{principal}} = U_1\Sigma_1 V_1^\top = \begin{pmatrix}3 & 0 \\ 0 & 0\end{pmatrix}$——最大奇异值 3 对应的主方向；
- 残差 $W_0 - W_0^{\text{principal}} = \begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix}$——次奇异值 1 的部分，训练中冻结；
- 可训练分支：$B = \begin{pmatrix}\sqrt3\\0\end{pmatrix}$、$A = \begin{pmatrix}\sqrt3 & 0\end{pmatrix}$，二者相乘 $BA = \begin{pmatrix}3 & 0 \\ 0 & 0\end{pmatrix}$，正好等于主分量。

每一步都能手算验证，PiSSA「把最重要的部分搬进可训练分支」就不再是黑箱。换成 LoRA：$B = 0$、$A$ 随机，$\Delta W$ 从零出发、要花步数慢慢逼近主方向——同样的矩阵，起点天差地别。

## 3 公式解析：从 SVD 到 PiSSA 的参数重排

把 PiSSA 与 LoRA 放在同一张公式表里，差异一目了然。设 $W_0 \in \mathbb{R}^{d \times k}$ 的 SVD 为 $W_0 = U \Sigma V^\top$：

$$
W_{\text{LoRA}} = W_0 + \frac{\alpha}{r} B_{\text{rand}} A_{\text{rand}}, \qquad
W_{\text{PiSSA}} = \underbrace{(W_0 - U_r \Sigma_r V_r^\top)}_{\text{残差，冻结}} + \frac{\alpha}{r}\, U_r \Sigma_r^{\frac12} \cdot \Sigma_r^{\frac12} V_r^\top
$$

逐项拆解：

- $U_r, \Sigma_r, V_r$：前 $r$ 个奇异向量与奇异值（$\Sigma_r$ 是 $r \times r$ 对角阵）；
- **LoRA**：$B_{\text{rand}} A_{\text{rand}}$ 从随机开始，增量 $\Delta W$ 初始为 0；
- **PiSSA**：$B = U_r \Sigma_r^{\frac12}$、$A = \Sigma_r^{\frac12} V_r^\top$，$BA = U_r \Sigma_r V_r^\top = W_0$ 的主分量；
- **残差** $W_0 - U_r \Sigma_r V_r^\top$：$W_0$ 去掉主分量后的部分，秩不超过 $\min(d,k) - r$，被冻结。

**直觉**：SVD 把 $W_0$ 拆成「主方向」与「次方向」两部分。PiSSA 把主方向交给我们要训练的低秩分支——于是训练一开始，模型就能利用最重要的 $r$ 个方向；而 LoRA 必须花步数「无中生有」地找到它们。这正是收敛加速的机制来源。

## 4 为什么收敛更快、效果更好

PiSSA 论文报告了几个核心结论，与它的机制一脉相承：

- **收敛更快**：由于起点就是主奇异方向，训练初期 loss 就低于随机初始化的 LoRA，达到同等效果所需的步数明显更少；
- **最终效果更好**：在低秩（$r$ 小）、低数据场景，PiSSA 的优势最明显——因为随机初始化的小秩子空间最容易「学偏」，而主奇异方向天然是「信息最密」的 $r$ 个方向；
- **等价视角**：PiSSA 可以看作「对主分量做全参微调」——它训练的参数恰好是 $W_0$ 最重要的部分，这解释了为什么它比「在随机子空间里微调」更接近全参微调。

一个值得注意的边界：**PiSSA 的优势随 $r$ 增大而缩小**。$r$ 很大时，主分量已经覆盖 $W_0$ 的绝大部分信息，随机初始化与主奇异初始化的差距被稀释——所以 PiSSA 的价值主要在「小秩 + 少数据」的场景。<span class="marginnote">论文里还有一个「等效性」讨论：<strong>从数学上看，PiSSA 最终学到的解空间包含 LoRA 的解空间</strong>（因为 LoRA 的解是「零增量」，而 PiSSA 的解是「主分量 + 增量」，主分量可被增量抵消）。这为「PiSSA ≥ LoRA」提供了理论上的合理性。</span>

从「等价视角」还能得到一个更直观的结论：**PiSSA ≈ 对主奇异方向做全参微调**——因为训练开始后，$A$、$B$ 的更新就是在主分量所在的子空间里自由移动，而这正是「最重要的 $r$ 个方向」。这解释了为什么它能用小秩逼近全参：它从一开始就锁定了信息最密的方向，而 LoRA 需要自己「找」这些方向。

## 5 实现与注意事项

PiSSA 的实现只有两个「多出来的动作」：

1. **对每个目标矩阵做一次 SVD**：`W0 = U @ S @ Vh`，取出前 `r` 个奇异向量与奇异值 `U_r, S_r, Vh_r`；
2. **用主奇异分量初始化低秩矩阵**：`A = sqrt(S_r) @ Vh_r`、`B = U_r @ sqrt(S_r)`，并把冻结基座设为残差 `W0 - U_r @ S_r @ Vh_r`。

几个工程要点：

**SVD 的成本**：对每个目标矩阵做一次 SVD，7B 模型约几十秒到几分钟，可离线完成；高精度建议用 FP32 算（BF16 SVD 精度损失会污染初始化）；
**与量化兼容**：PiSSA 也能用在量化基座上（先反量化做 SVD，再量化残差），是 QLoRA 的升级版思路；
**训练超参**：PiSSA 的 $\alpha/r$ 缩放与 LoRA 相同，学习率经验值也接近，通常不用大改训练脚本。<span class="marginnote">PiSSA 已经进入主流 PEFT 生态（HF PEFT 的 `init_lora_weights="pissa"` 参数支持「主奇异初始化」）。它给所有 LoRA 用户的启示很简单：<strong>如果数据少、秩小、想更快收敛，把随机初始化换成主奇异初始化，通常零成本得利</strong>。</span>

还有一个实操判断值得记下：**何时 PiSSA 的 SVD 开销「不值」**。当 $r$ 已经很大（如 128+）、数据充足、训练步数多时，随机初始化经过足够多的训练步也能「转正」，PiSSA 的起点优势被稀释，多花的 SVD 时间就显得浪费。反之，**只要「训练步数少」或「数据少」任一项成立，PiSSA 基本稳赚**——因为它的价值恰恰在于「用离线计算换在线步数」。

## 6 小结

- **PiSSA 用主奇异分量初始化 LoRA 矩阵**：$W_0$ 的 SVD 主分量搬进可训练分支，残差冻结。
- 前向 $W = (W_0 - U_r\Sigma_r V_r^\top) + \frac{\alpha}{r} U_r \Sigma_r^{\frac12} \Sigma_r^{\frac12} V_r^\top$——可训练参数一开始就是「最重要的权重部分」。
- **收敛更快**：起点就是主方向，省去「从随机方向旋转到有用方向」的步数。
- **效果更好**：低秩、低数据场景优势最明显；$r$ 增大后优势缩小。
- 实现要点：SVD 用 FP32 离线算、与量化兼容、训练超参基本沿用 LoRA。
- 定位：与 DoRA 互补（DoRA 改训练什么、PiSSA 改从哪出发），可叠加使用。
- 一句话决策：**训练步数少或数据少时，PiSSA 基本稳赚；否则随机初始化也够**。
- 工程提醒：SVD 是「一次性的离线成本」，可以预计算缓存；它换来的收敛加速，在小预算实验里通常值回票价。
