## 为什么从 ReST 开始

上一节的 RAFT 已经展示了「采样器随训练升级」的雏形。Google 的 **ReST**（Reinforced Self-Training）把这个雏形系统化成一套干净的迭代算法——**G/I 循环**：先**生成**（Grow）数据，再**改进**（Improve）模型，交替进行，模型一轮比一轮强。

ReST 的价值在于：它把「拒绝采样」从「一次性技巧」升级为「可重复的方法论」，并与「专家迭代（expert iteration）」「STaR」「自举（self-training）」等经典思想接通。理解了 ReST，你就理解了一条重要的对齐路线：**不依赖强化学习，也能让模型利用自己的输出持续进步**。<span class="marginnote">ReST 的灵感谱系值得一提：AlphaGo/AlphaStar 的「专家迭代」、语言模型的 STaR（自举推理）、以及经典的「自训练」——它们共享一个循环：<strong>用当前模型产生数据 → 用外部信号筛选 → 训练 → 再产生</strong>。ReST 把这条循环在 LLM 对齐上做成了「可复现的食谱」。</span>

## 1 自举的循环：模型如何用自己的输出变强

「自举」听起来像悖论——模型怎么可能教自己？破解悖论的关键是**外部信号**：模型生成的是「候选」，而「哪个候选值得学」由外部判断（奖励模型、验证器、或阈值）说了算。

ReST 的循环建立在「**生成与判断分离**」之上：

**生成**：模型负责「产出候选」——它的分布就是「候选的采样器」；
**判断**：奖励模型（或规则验证器）负责「筛选」——它决定哪些候选进训练集；
**改进**：模型在「筛出的候选」上做 SFT——它的分布向「高分区域」收缩。

于是每一轮循环，模型都「更靠近高分区域一点」；下一轮生成时，它的采样更可能落在高分区域——**候选质量水涨船高，循环越转越强**。这就是「自提升」的机制：不是模型凭空变强，而是「外部信号 + 模型自己的采样」共同推动。

## 2 ReST 的 G/I 循环：生成与改进

ReST 把循环分成两个明确阶段：

**G 阶段（Grow，生成）**：

1. 用当前模型对提示池采样，得到一批「模型输出」；
2. 用奖励模型（或质量指标）给每个输出打分；
3. **按阈值筛选**：只保留分数高于阈值（如 top 分位或绝对阈值）的输出，组成新数据集 $D$。

**I 阶段（Improve，改进）**：

1. 在筛选出的数据集 $D$ 上做 SFT（注意：**提示 + 筛中的输出**配对）；
2. 得到改进后的模型 $\pi_{t+1}$；
3. 回到 G 阶段，用 $\pi_{t+1}$ 重新采样。

两个阶段交替进行：**G 让数据变好（模型采样 + 筛选），I 让模型变好（SFT）**。ReST 论文里还强调一个细节：**G 阶段采样的提示池可以逐步扩充**（加入更多任务），让每轮迭代的数据既有质量又有广度。<span class="marginnote">一个经常被问的问题：「G 阶段采样多少合适？」经验上，<strong>每轮采样量要足够大（如每个提示几十个回答），否则筛选后留下的样本太少，I 阶段的 SFT 没有足够数据</strong>。采样量 = 数据多样性的下限，宁多勿少。</span>

ReST 的 G/I 循环在代码里只有两层循环：

```python
for t in range(num_rounds):                     # 外层：G/I 交替
    # —— G 阶段：采样 + 筛选 ——
    candidates = sample(model_t, prompts, n_per_prompt)
    scores = reward_model(candidates)
    D_t = candidates[scores >= threshold]        # 只留高分样本

    # —— I 阶段：在筛出的数据上 SFT ——
    for step in range(M):                        # I 内部可多轮直到收敛（ReST^EM）
        model_t = sft(model_t, D_t)
```

两个旋钮最值得调：**筛选分位**（**top-50%** 是「留一半」，越严数据越精但量越少）与 **I 内部轮数**（**M** 对应 ReST^EM 的「M 步内部收敛」）。它们一起决定了「每轮提升多少、稳不稳定」——分位太松、内部轮数太多，模型容易在「不够精的数据」上过拟合。## 3 公式解析：ReST^EM 与期望最大化

ReST 论文提出了一个理论变体 **ReST^EM**，把「筛选阈值」从「拍脑袋」升级为「有依据」。它的核心是**用「数据质量」替代「生成概率」来重加权**——形式上与**期望最大化（EM）算法**同构：

$$
\pi_{t+1} = \arg\max_\pi\; \mathbb{E}_{x \sim \mathcal{D}}\Big[ \log \pi(y \mid x) \Big], \qquad y \sim \text{筛选}(\,采样(\pi_t, x)\,)
$$

逐项拆解：

- $\pi_t$：当前模型（E 步的「当前估计」）；
- 采样 + 筛选：从 $\pi_t$ 采样、按质量筛选——**相当于 E 步的「隐变量估计」**（估计「哪些输出是高分的」）；
- $\log\pi(y \mid x)$：在筛出的数据上最大化——**相当于 M 步的「极大化」**；
- 迭代循环：E 步（采样 + 筛选）与 M 步（SFT）交替——**与 EM 的「估计-最大化」交替同构**。

**ReST^EM 的实操价值**：它给出了「筛选阈值」的理论依据——**阈值应选在「让下一轮 SFT 提升最大」的位置**。论文的做法是：用「分数高于某个分位数」作为阈值，且**I 阶段内部可以多次 SFT 直到收敛**，再进入下一轮 G——对应 EM 的「M 步内部迭代到收敛」。这个「内部收敛」细节，是 ReST^EM 比「每轮只训一步」更稳的原因。<span class="marginnote">把 ReST^EM 与 EM 的联系点破，有一个实际收益：<strong>EM 的理论告诉你「循环单调不减」——每轮 I 阶段后，模型在「筛选分布」上的质量不下降</strong>。这给了实践者信心：迭代不是盲目尝试，而是有收敛保证的。当然，前提是筛选器（奖励模型）本身不偏差。</span>

## 4 为什么迭代有效：课程式自提升

迭代拒绝采样为什么比「一次性拒绝采样」更强？三个机制：

**① 采样天花板随迭代抬升**。一次性 RFT 的采样器是固定模型，它的「最好样本」受限于该模型的上限；ReST 每轮用**新模型**采样——模型变强，采到的「最好样本」也变强，循环的天花板随之抬升。

**② 数据质量随迭代分层**。第一轮筛出的高分样本，在第二轮里可能只是「普通」——因为模型已经会了。每轮筛选都在「当前水平的更高分位」上取样本——**训练数据像是「逐步进阶的课程」**，难度随模型能力同步增长。

**③ 天然的抗遗忘机制**。每轮 G 阶段都从**当前模型**采样，数据分布与当前模型匹配——这比「一次采样、固定数据」更不容易造成「旧数据分布与新模型失配」的问题（与离线偏好优化的分布偏移问题相关，详见本篇最后一节）。<span class="marginnote">「课程式自提升」也解释了为什么 ReST 适合「能力本身在提升的任务」（如数学、代码）——这类任务的「高分样本」定义清晰、可以持续往上爬。对「价值观对齐」这类「标准模糊」的任务，迭代的收益较小、风险较大（筛选器偏差会被多轮放大）——选型时注意区分。</span>

## 5 与 PPO、DPO 的关联与取舍

把 ReST 放进偏好优化的坐标系：

| 方法 | 数据来源 | 优化方式 | 在线性 |
| --- | --- | --- | --- |
| ReST | 当前模型采样 + 筛选 | SFT | 半在线（每轮更新） |
| PPO | 当前策略采样 + 奖励 | 策略梯度 | 全在线（每步更新） |
| DPO | 固定偏好数据 | 直接偏好损失 | 离线 |

三个关键观察：

- **ReST 是「PPO 的廉价版」**：同样「用当前模型的数据」更新自己，但用 SFT 替代策略梯度——稳定得多，代价是「每轮只能筛出最好的，学不到「为什么差」的负信号」；
- **ReST 可以给 DPO 供数据**：迭代筛选出的高质量「提示-回答」对，天然是 DPO 的偏好数据（高分 vs 低分）——**ReST 与 DPO 常组合使用**；
- **ReST 不是 PPO 的替代品**：对「需要持续在线探索」的场景（RLVR 的数学推理，见后文），PPO 式的在线采样仍不可替代。

选型建议：**对齐的第一轮，用拒绝采样/ReST 快速把模型拉到「不错」；需要冲刺「很强」时，再叠加 DPO 或 PPO**——ReST 不是终点，而是「低成本起跑」。

## 6 小结

- **ReST = G/I 循环**：G 阶段（采样 + 筛选）→ I 阶段（SFT），交替进行，模型逐轮变强。
- **自举靠外部信号**：模型生成候选、外部筛选决定「学什么」——不是凭空变强，是「采样 + 判断」共同推动。
- **ReST^EM**：与 EM 算法同构——E 步（采样筛选）与 M 步（SFT）交替，有「单调不减」的收敛保证。
- **迭代有效的三个机制**：采样天花板抬升、数据课程式分层、天然抗分布偏移。
- 与 PPO/DPO 的坐标：ReST 是「PPO 的廉价版」，也可给 DPO 供数据；不是替代品而是「低成本起跑」。
- 适用判断：**标准清晰、能力持续爬升的任务**（数学、代码）收益最大；价值观类任务慎用多轮迭代。
