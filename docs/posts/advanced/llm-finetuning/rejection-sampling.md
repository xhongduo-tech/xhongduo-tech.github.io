## 为什么从拒绝采样开始

PPO 很强，但四模型、在线采样、KL 调参的复杂度劝退了很多团队。有没有一种「更省事」的对齐方式，能拿到 PPO 的大部分收益？

**拒绝采样微调（rejection sampling fine-tuning）** 提供了一条「RL-free」路线：**不跑强化学习，而是「生成一批 → 筛出好的 → 微调学好样本」**。它把「策略优化」这个难题，替换成「采样 + 筛选」两个更简单的问题。它的两个代表变体——**RFT**（Rejection Fine-Tuning）与 **RAFT**（Reward rAnked Fine-Tuning）——在实际中被广泛使用，常常能以远低于 PPO 的成本取得接近的效果。对很多团队来说，「拒绝采样 + SFT」就是性价比最高的对齐起点。<span class="marginnote">为什么「筛出好样本再学」能work？因为<strong>模型的质量上限由「见过的最好样本」决定</strong>——若能稳定地产出并学到「高分回答」，效果上就接近「学会了生成高分回答」。拒绝采样把「在线优化」换成「离线蒸馏」，工程复杂度骤降，代价是「受限于采样器的多样性」。</span>

## 1 拒绝采样的思想：采样 → 筛选 → 微调

拒绝采样的三步，每一步都很朴素：

1. **采样**：用一个模型（SFT 模型或当前迭代的模型）对提示 $x$ 采样出 $N$ 个回答 $y_1, \dots, y_N$；
2. **筛选**：用奖励模型（或验证器）给每个回答打分，挑出**分数最高的 $k$ 个**（或超过阈值的）；
3. **微调**：把「提示 + 高分回答」当作 SFT 数据，训练模型学习这些好样本。

循环往复（或一次性），模型学会「产出更像那些高分样本的回答」。**整个过程没有任何策略梯度、没有价值网络、没有 KL 调参**——就是一个普通的 SFT，只不过「训练数据」是动态筛选出来的。

**它为什么有效？** 直觉是「择优录取」：模型天然会从训练数据里学习分布；若训练数据里「高分回答」占主导，模型就会偏向生成「高分回答」。拒绝采样的本质，是**用「数据选择」替代「目标函数设计」**——用筛选器（奖励模型）判断什么好，用 SFT 让模型模仿。

## 2 Best-of-N：推理期的择优

在进入微调之前，先认识拒绝采样最朴素的形式——**Best-of-N（N 选 1）**，它甚至不需要训练：

$$
y^* = \arg\max_{y \in \{y_1, \dots, y_N\}} r_\phi(x, y)
$$

逐项拆解：

- $y_1, \dots, y_N$：对同一个提示 $x$ 采样出的 $N$ 个候选回答；
- $r_\phi$：奖励模型（或任何验证器）；
- $y^*$：奖励最高的那个——**推理时直接返回它**。

**Best-of-N 是「推理期的拒绝采样」**：它不做任何训练，只是在生成时「多采样几个、挑最好的」。它的质量随 $N$ 增长——$N$ 越大，越有可能采到高分回答（上限是「采样器自身能达到的最优」）。**这个特性让 Best-of-N 成为一切对齐方法的天然基线**：任何训练方法，至少要能打过「采样 16 个挑最好」的推理期开销。<span class="marginnote">Best-of-N 的局限也很明显：<strong>推理成本随 $N$ 线性增长</strong>——采 64 个就要 64 倍生成算力。拒绝采样微调的意义，正是把「推理期的多采样」蒸馏成「训练期的一次采样」——让模型自己就能生成「曾经需要 N 选 1 才有」的高分回答。</span>

## 3 公式解析：把 Best-of-N 蒸馏进模型

拒绝采样微调的训练目标，就是标准 SFT，只不过数据来自「筛选后的高分回答」：

$$
\mathcal{L}_{\mathrm{RFT}} = -\frac{1}{|D_{\mathrm{filtered}}|}\sum_{(x, y^*) \in D_{\mathrm{filtered}}} \log \pi_\theta\big(y^* \mid x\big)
$$

逐项拆解：

- $D_{\mathrm{filtered}}$：筛选后的数据集——每个提示 $x$ 只保留筛选出的高分回答 $y^*$；
- $\log \pi_\theta(y^* \mid x)$：模型生成 $y^*$ 的对数概率——SFT 的标准目标；
- **与普通 SFT 的唯一区别**：$y^*$ 不是「人写的示范」，而是「模型自己采样 + 奖励筛选出来的高分回答」。

**关键洞察**：$D_{\mathrm{filtered}}$ 里的回答，是从「当前采样模型」的分布里挑出来的——**模型学习的是「自己分布里最好的那部分」**。这带来一个良性循环（也是 RAFT 的核心）：模型变好 → 采样的「天花板」变高 → 筛选出的样本更好 → 模型再进步。**拒绝采样不是一次性的，而是可以迭代自提升的**——这正是下一篇《ReST 与迭代式拒绝采样》的主题。

## 4 RFT 与 RAFT：两种落地流程

**RFT（Rejection Fine-Tuning）**：最直接的版本。用**固定**的采样模型（通常是 SFT 模型）批量采样 → 奖励筛选 → SFT。一次成型、简单稳定，但采样模型不更新——「天花板」是固定的。

**RAFT（Reward rAnked Fine-Tuning）**：把采样与训练**交替进行**，并引入「金标数据」防止遗忘。核心流程：

1. 用**当前训练中的模型**采样 $N$ 个回答，奖励筛选出最好的 $k$ 个；
2. 训练数据 = 筛选出的高分对 + **一小部分「金标数据」**（高质量人工示范）；
3. SFT 一步，回到第 1 步——**采样器随训练不断更新**。

RAFT 的两处设计值得注意：

- **「用当前模型采样」**：让筛选出的样本始终与模型当前水平匹配——模型进步，样本同步升级；
- **「混金标数据」**：防止模型只顾学「自己采的高分」，把人工标注的高质量示范也混进来保底——这是对「自举漂移」的缓冲。<span class="marginnote">RAFT 的「自举」有一个必须警惕的风险：<strong>如果奖励筛选器有系统性偏差（比如偏好长回答），拒绝采样会把模型越带越偏</strong>——因为模型只会学「被筛中的样本」，而筛中样本集中了偏差。这就是为什么「好筛子」在拒绝采样里比在 PPO 里更关键：它直接决定「学什么」，没有 KL 惩罚之类的纠偏。</span>

一个最简 RFT 循环的实现骨架（理解「采样-筛选-微调」的节奏即可）：

```python
# 一个最简 RFT 循环：采样 → 筛选 → SFT
for it in range(num_iters):
    # 1. 采样：用当前采样器对提示 x 采样 N 个回答
    ys = [sample(x, model=sampler) for _ in range(N)]
    # 2. 筛选：奖励模型打分，挑出最高分的 k 个
    ys_topk = filter_topk(rm, ys, k)
    # 3. 微调：把 (x, ys_topk) 当作 SFT 数据更新策略
    sft_update(policy, [(x, y) for y in ys_topk])
    # 4. RAFT 的关键：每轮都用最新策略更新采样器（RFT 则固定在循环外）
    sampler = policy
```

注意第 1 步的**采样器（sampler）**是「当前模型」——若只在循环外采一次、循环内不更新采样器，就是 RFT；若每轮都用最新模型采样，就升级成了 RAFT。**「采样器跟不跟训练走」，是 RFT 与 RAFT 的唯一区别**，也决定了「自举天花板」能否被打破。## 5 拒绝采样 vs PPO：一张取舍表

把拒绝采样与 PPO 放在一起，选型依据就清楚了：

| 维度 | 拒绝采样（RFT/RAFT） | PPO |
| --- | --- | --- |
| 训练方式 | 采样 + 筛选 + SFT | 策略梯度 + 裁剪 |
| 模型数 | 2（策略 + 奖励） | 4（策略 + 参考 + 奖励 + 价值） |
| 在线性 | RFT 离线 / RAFT 半在线 | 全在线 |
| 工程复杂度 | 低 | 高 |
| 稳定性 | 高（就是 SFT） | 中（易发散） |
| 对采样器的依赖 | 强（多样性受限） | 弱（在线探索） |
| 效果上限 | 中高（受采样器天花板限制） | 高（可持续挖掘新样本） |

**选型口诀**：预算有限、求稳 → **拒绝采样**（尤其是 RFT）；要极限效果、有调参团队 → **PPO**。实践中很多团队用「拒绝采样打底 + PPO 或 DPO 微调收尾」的组合——先用便宜的方法把模型拉到不错水平，再用贵的方法冲刺。

## 6 小结

- **拒绝采样 = 采样 → 筛选 → 微调**：用「数据选择」替代「目标函数设计」，全程是 SFT。
- **Best-of-N**：推理期采 N 个挑最好的——质量随 N 增长，是一切对齐方法的天然基线。
- **蒸馏**：$-\log\pi_\theta(y^*\mid x)$——把「N 选 1 的高分回答」蒸馏成模型的一次采样能力。
- **RFT**：固定采样模型 + 一次性筛选——简单稳定；**RAFT**：当前模型采样 + 混金标数据——可自举、防遗忘。
- 与 PPO 取舍：拒绝采样**便宜稳**、上限受采样器限制；PPO **贵而强**、可持续在线探索。
- 警惕：**筛选器偏差会被自举放大**——好筛子在拒绝采样里比在 PPO 里更重要。
- 一句话记忆：**拒绝采样 = 「择优录取」——采样出高分回答，SFT 学会它**；比 PPO 便宜，上限受采样器限制。
- 与 DPO 的衔接：拒绝采样筛出的「高分 vs 低分」回答对，天然是 DPO 的偏好数据——**两者常组合使用**（ReST 供数据、DPO 学偏好）。

在下一节，我们把「迭代自提升」展开成一套方法论：**ReST 与迭代式拒绝采样——数据-训练循环的自提升**，把「采样器随训练升级」这件事做成系统的流程。
