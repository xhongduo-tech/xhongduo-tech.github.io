## 为什么从 Adapter 开始

PEFT 的时间线从 **Adapter** 开始。2019 年 Houlsby 等人的论文《Parameter-Efficient Transfer Learning for NLP》提出了第一个「冻结大模型、只训小模块」的成熟方案：在 Transformer 的每个子层后面插一个小型可训练模块，其余权重全部冻结。它被证明在 GLUE 等基准上能用不到 3% 的参数逼近全参微调——这是「参数高效」第一次被严肃证明。

Adapter 的贡献不仅是方法本身，更是**范式**：它确立了「旁路模块」这个思路。后来的 Prefix-Tuning、LoRA 本质上都是「在必经之路上挂一个可学习的旁路」，只是旁路的样子不同。学懂 Adapter，你就拿到了整个 PEFT 家族的第一把钥匙。<span class="marginnote">Adapter 与 LoRA 常常被放在一起比较，但它们的设计哲学不同：<strong>Adapter 加的是「非线性小网络」，LoRA 加的是「线性低秩增量」</strong>。前者能表达更复杂的函数，后者更简洁、推理可合并。二者各有擅场，后面会反复对照。</span>

## 1 从全参到旁路：冻结模型，只训小模块

全参微调直接更新 $W_0$；Adapter 换了一条路：**$W_0$ 一字不动，在它的输出后面接一个「小门」**。训练时只调这个门，推理时模型的主体与预训练完全一致。

这个设计带来三个直接好处：

1. **显存大幅下降**：可训练参数只有适配器本身，优化器状态与梯度只跟小模块挂钩——7B 模型上，可训练参数量从 7B 降到几千万，静态显存从上百 GB 降到几 GB；
2. **基座不被破坏**：冻结的主体保持预训练学到的通用能力，适配器只在主体输出上做「微调式改写」，灾难性遗忘的风险远低于全参微调；
3. **多任务共存**：同一份冻结基座可以挂多个适配器，不同任务各用一个，互不干扰——「一基座多适配器」的部署模式从这里起步。

代价也直接：**推理时每个适配器都是一段额外计算**，层数一多、序列一长，延迟就会累积——这是 Adapter 与「可合并」方法（LoRA）最大的差别。

## 2 瓶颈结构：压下去，再撑回来

Adapter 的「小门」长什么样？答案是一个**瓶颈结构（bottleneck）**：

1. **降维投影（down-projection）** $D$：把 $d$ 维的隐藏向量压到瓶颈维度 $r$（通常 $r \ll d$，如 64 对 4096）；
2. **非线性激活**：如 ReLU / GELU，给适配器注入非线性表达能力；
3. **升维投影（up-projection）** $U$：把 $r$ 维撑回 $d$ 维，与输入同形才能相加。

于是整个适配器就是一个「胖—瘦—胖」的沙漏，可训练参数集中在两个投影矩阵上：$D$ 有 $d \times r$ 个参数，$U$ 有 $r \times d$ 个参数，合计 $2dr$——对 4096 维、$r=64$ 的情况，约 52 万参数，只占该层几百万参数的百分之几。<span class="marginnote">瓶颈的「窄」不是无奈，而是刻意：<strong>降维逼着适配器把「要学的东西」压缩到 $r$ 维的子空间里表达</strong>——这其实是最早的「低秩假设」，比 LoRA 的论文早两年。$r$ 越大表达越强但参数越多，是适配器自己的「秩旋钮」。</span>

## 3 公式解析：Adapter 的前向

设 Transformer 某个子层（如 MLP）的输入为 $x \in \mathbb{R}^d$，输出为 $h \in \mathbb{R}^d$。带残差的 Adapter 前向为：

$$
h' = h + U\,\sigma\big(D\,h\big), \qquad D \in \mathbb{R}^{r \times d},\; U \in \mathbb{R}^{d \times r}
$$

逐项拆解：

- $D\,h$：降维投影，把 $h$ 从 $d$ 维压到 $r$ 维——这一步提取「值得调整的 $r$ 维特征」；
- $\sigma(\cdot)$：非线性激活，使适配器不是又一个线性层，能表达非线性变换；
- $U\,\sigma(\cdot)$：升维投影，把 $r$ 维特征撑回 $d$ 维，恢复与 $h$ 相同的形状；
- $h' = h + \cdots$：**残差连接**——关键设计。若适配器学到的变换是无用的，$U\sigma(Dh)$ 会被推近 0，$h' \approx h$，模型自动「退化为基座」；
- 训练时**只有 $D$、$U$ 可更新**，$W_0$（以及通常还有 LayerNorm 参数）被冻结。

**直觉**：残差 + 瓶颈的组合让适配器天然「从零开始、逐步生效」——初始化时 $U$ 为 0（或很小），适配器一开始是恒等映射，训练逐步把它「撑开」。这个「从恒等出发」的设计后来被 LoRA 直接继承（$B$ 初始化为 0），是整个旁路方法族的共同基因。<span class="marginnote">注意与 LoRA 的细微差别：Adapter 的残差在「子层输出」层面，LoRA 的增量加在「权重矩阵」层面——<strong>Adapter 改的是特征流，LoRA 改的是权重映射</strong>。一个作用在激活空间，一个作用在参数空间，这是理解两种方法本质差异的关键。</span>

实现层面，一个 Adapter 模块就是十几行 PyTorch：

```python
class Adapter(nn.Module):
    def __init__(self, d, r):
        super().__init__()
        self.down = nn.Linear(d, r)        # 降维投影 D：d → r
        self.up = nn.Linear(r, d)          # 升维投影 U：r → d
        self.act = nn.GELU()
        nn.init.zeros_(self.up.weight)     # 关键：U 初始化为 0
        nn.init.zeros_(self.up.bias)

    def forward(self, h):
        return self.up(self.act(self.down(h)))   # U σ(D h)
```

注意 `nn.init.zeros_(self.up.weight)`（升维投影 U）权重清零这行：**它保证训练初期 Adapter 输出为 0、模型行为不变**，随后逐步「撑开」。绝大多数 Adapter 变体（Pfeiffer、并行、AdapterFusion）都只是在这十几行上改结构，核心的「瓶颈 + 残差 + 从零开始」三要素不变。

## 4 放置位置与变体

「把适配器放哪、放几个」决定了它的效果与开销。经典与主流的几种配置：

**Houlsby 原始配置**：每个 Transformer 块里放**两个**适配器——一个接在自注意力输出后、一个接在 MLP 输出后。效果好，但每层两个模块，推理开销最大。

**Pfeiffer 配置（2020）**：每个块只放**一个**适配器，接在 MLP 之后，且前加一个 LayerNorm。参数更省、推理更快，成为后续很多工作的默认选择。

**并行适配器（parallel adapter，He et al., 2021）**：适配器与子层**并联**而非串联——$h' = \text{SubLayer}(x) + \text{Adapter}(x)$。并联避免与主路径串行累积延迟，更适合多适配器并行服务。

**AdapterDrop**：训练后按重要性**丢弃部分适配器**以加速推理，验证了「不是每个适配器都同等重要」。

**AdapterFusion**：多个任务适配器 + 一个融合层，让同一基座服务多任务并共享知识。

这些变体围绕两个旋钮打转：**数量**（每层几个）与**拓扑**（串联还是并联）。选型时，质量和开销的平衡点是「每块一个、放在 MLP 后」——大多数场景的甜区。

## 5 优缺点与选型

把 Adapter 与 PEFT 家族的其他成员放一起，它处于一个独特的位置：

| 维度 | Adapter | LoRA | Prompt-Tuning |
| --- | --- | --- | --- |
| 方法族 | 加性 | 重参数化 | 加性 |
| 推理开销 | 每层小计算 | 可合并，零 | 占序列长度 |
| 表达能力 | 非线性强 | 线性低秩 | 较弱 |
| 可训练参数 | 0.5%–3% | 0.1%–1% | 极小 |
| 结构改动 | 需改模型代码 | 包装层即可 | 只加前缀 |

**适合用 Adapter 的场景**：需要比线性低秩更强的表达能力（复杂映射）、希望在主体之外挂多种结构、或不在乎每层那点推理延迟。**不适合的场景**：对推理延迟极敏感的部署（此时 LoRA 更优）、或参数预算极紧（Prompt-Tuning 更省）。

一个实务建议：**Adapter 与 LoRA 可以混用**——例如在 LoRA 之外给某些层加一个 Adapter 补非线性。PEFT 生态里它们互相兼容，别把它们当互斥选项。

## 6 小结

- **Adapter 是 PEFT 的起点**：冻结主体、训练旁路小模块，用 <3% 参数逼近全参效果。
- 瓶颈结构 = **降维 + 激活 + 升维 + 残差**；残差保证「从恒等出发」，逐步生效。
- 前向公式 $h' = h + U\sigma(Dh)$：适配器改的是**特征流**，LoRA 改的是**权重映射**。
- 配置旋钮：**数量**（每块 1–2 个）与**拓扑**（串/并联）；「每块一个、放 MLP 后」是甜区。
- 变体：Pfeiffer、并行适配器、AdapterDrop、AdapterFusion——围绕「开销 × 表达」两个旋钮演进。
- 选型：要强表达用 Adapter，要零推理开销用 LoRA，要最省参数用 Prompt-Tuning；可混用。
