## 为什么从 DoRA 开始

LoRA 的能力天花板在哪里？2024 年，Microsoft 的 **DoRA**（Weight-Decomposed Low-Rank Adaptation）论文给出了一个深刻的诊断：**LoRA 把权重的「方向」和「幅度」混在一起改，而全参微调其实是分开改的**。

DoRA 的做法是**权重分解**：把每个权重矩阵拆成「幅度（magnitude）」与「方向（direction）」两部分，对方向用 LoRA、对幅度直接全量训练。就这么一个看似简单的分解，让 DoRA 在常识推理、数学等多个基准上稳定超过 LoRA，尤其在小样本场景。它是 LoRA 家族里「质量逼近全参」路线的重要一站。本节从「方向 vs 幅度」的直觉讲起，推导出 DoRA 的前向公式，最后落到实现与选型。<span class="marginnote">DoRA 论文的一个核心论据来自对微调行为的分析：全参微调的权重更新里，<strong>幅度变化与方向变化是「半独立」的</strong>——而 LoRA 的低秩增量同时改两者，且方式受低秩约束。把两者解耦，就能分别用最合适的方式优化。</span>

## 1 一个向量的两副面孔：方向与幅度

一个权重矩阵的每一列，可以看成一个高维向量。这个向量有两个独立属性：

- **方向**：这个向量指向高维空间里的哪个位置——决定了「模型关注输入的哪个模式」；
- **幅度**：这个向量有多长——决定了「这个模式的信号有多强」。

任何权重矩阵 $W$ 都能唯一分解成方向与幅度的乘积：

$$
W = m \odot \frac{W}{\|W\|_c}
$$

其中 $\|W\|_c$ 是**按列求的范数**（每列一个数），$m = \|W\|_c$ 是幅度向量，$\frac{W}{\|W\|_c}$ 是每列归一化后的方向矩阵。<span class="marginnote">为什么按列分解？因为线性层 $y = Wx$ 里，$W$ 的每一列对应输出空间的一个坐标轴——<strong>每列的方向决定「这个输出维度看输入什么」，每列的幅度决定「这个输出维度的增益</strong>」。按列分解正好把这两个语义分开。</span>

**关键问题**：微调时，方向与幅度各自该怎么变？全参微调同时改两者（且幅度向量的变化通常更「有规律」）；LoRA 的低秩增量 $\Delta W$ 则同时以耦合的方式改变两者。DoRA 的假设是：**把两者解耦、分别用合适的方式优化，能比耦合的 LoRA 更接近全参微调的效果**。

论文用一组「消融实验」支持这个假设：先拿全参微调的结果，把其中的幅度变化单独提取出来；再对比 LoRA 与全参微调在幅度上的差异。结论是——**LoRA 的幅度调整方式与全参微调显著不同，而这部分差异正是 LoRA 落后于全参的主要来源**。把幅度「赎」出来，等于堵住了最大的失分点。

## 2 DoRA 的公式：方向走 LoRA，幅度直接训

DoRA 的前向定义为：

$$
W' = m \cdot \frac{W_0 + \Delta W_{\text{LoRA}}}{\big\| W_0 + \Delta W_{\text{LoRA}} \big\|_c}
$$

其中 $m$ 是**可学习的幅度向量**（初始化为 $\|W_0\|_c$），$\Delta W_{\text{LoRA}} = \frac{\alpha}{r} B A$ 是方向部分的低秩增量。逐项拆解：

- $W_0 + \Delta W_{\text{LoRA}}$：先用 LoRA 更新权重（这一步与普通 LoRA 相同）；
- $\big\| \cdots \big\|_c$：按列归一化——把「方向」单独拎出来，单位化；
- $m$：乘上独立的幅度向量——**幅度可以不受低秩约束地自由调整**；
- 训练时：**$m$ 直接更新（满秩向量，参数极少），$A, B$ 走 LoRA（低秩）**，$W_0$ 冻结。

**参数成本**：$m$ 是一个 $d$ 维向量（对 $d \times k$ 矩阵只有 $d$ 个参数），相比 $BA$ 的 $r(d+k)$ 几乎可忽略。所以 DoRA 的参数量只比 LoRA 多一点点，却多了「满秩幅度」这个自由度。

## 3 公式解析：为什么「方向 LoRA + 幅度满秩」更接近全参

把全参微调、LoRA、DoRA 放进同一个坐标系，三种方法对「方向与幅度」的处理一目了然：

| 方法 | 方向怎么改 | 幅度怎么改 | 幅度自由度 |
| --- | --- | --- | --- |
| 全参微调 | 任意 | 任意 | 满秩 |
| LoRA | 低秩增量耦合改变 | 与方向耦合改变 | 受低秩约束 |
| DoRA | 低秩增量（LoRA） | 独立向量直接更新 | **满秩** |

DoRA 的关键洞察是：**幅度虽然重要，但它的「信息量」很小**——每个矩阵只有一个 $d$ 维向量，直接满秩训练它几乎没有显存代价；而方向包含的信息量大，才需要低秩近似。于是 DoRA 做到了「该省的省（方向用 LoRA），该精的精（幅度满秩）」——这在理论上解释了它为什么比「两头都低秩」的 LoRA 更接近全参微调。<span class="marginnote">论文还有一个有意思的对比实验：如果把 LoRA 学到的 $\Delta W$ 的幅度变化「换成」全参微调的幅度变化，效果立刻逼近全参——反过来说，LoRA 的幅度部分是「短板」，DoRA 正是把这块短板补成了满秩。</span>

## 4 实现与效果

DoRA 在实现上几乎就是「LoRA + 一个幅度向量」：

```python
class DoRALayer(nn.Module):
    """DoRA：方向走 LoRA（低秩），幅度走满秩向量。"""
    def __init__(self, w0, r, alpha):
        super().__init__()
        self.w0 = w0.detach()                          # 冻结基座 W0（in × out）
        self.m = nn.Parameter(                         # 幅度向量，初始化为基座列范数
            torch.linalg.vector_norm(w0, dim=0)
        )
        self.lora_A = nn.Parameter(torch.randn(w0.shape[0], r) / r**0.5)
        self.lora_B = nn.Parameter(torch.zeros(r, w0.shape[1]))
        self.scaling = alpha / r

    def forward(self, x):
        dw = self.scaling * (self.lora_B @ self.lora_A)   # 低秩增量 ΔW
        w = self.w0 + dw
        direction = w / torch.linalg.vector_norm(w, dim=0, keepdim=True)  # 按列归一化
        return x @ (self.m * direction).T
```

注意两个实现要点：其一，**幅度向量必须初始化为基座的列范数**（否则一开始就偏离基座）；其二，**前向要做一次按列归一化**——这一步是额外计算，也是 DoRA 比 LoRA 推理略贵的来源（不过合并后同样可消除）。

效果方面，DoRA 在多个基准上稳定超过 LoRA：

在常识推理、数学、指令遵循等任务上，DoRA 通常比同秩 LoRA 高 **1–3 个点**，小样本场景差距更大；
论文特别强调**低资源（few-shot）场景**的优势——数据越少，DoRA 相对 LoRA 的领先越明显；
代价：训练时前向多一次归一化，参数量略增，推理合并后与 LoRA 同样零开销。<span class="marginnote">DoRA 的「幅度满秩、方向低秩」思想后来被 PiSSA（主奇异初始化）等方法进一步吸收——它们共同指向一个趋势：<strong>PEFT 的竞争焦点从「省多少参数」转向「用同样参数逼近全参多少」</strong>。</span>

### 选型：什么时候换 DoRA

DoRA 不是 LoRA 的全面替代，而是「多付一点实现复杂度，换更高质量」的选项：

| 场景 | LoRA | DoRA |
| --- | --- | --- |
| 数据充足、任务常规 | ✅ 首选，简单够用 | 增益有限 |
| few-shot / 低资源 | 可用 | ✅ 领先明显 |
| 追求逼近全参效果 | 高秩硬扛 | ✅ 同参数更接近 |
| 对实现简单度敏感 | ✅ 生态最成熟 | 需引入 DoRA 层 |
| 长序列、大 batch | ✅ 无额外归一化 | 前向多一次归一化 |

一条实用的判断：**先用 LoRA 跑通基线，若评测差口气、且数据量不大，换成 DoRA 通常是最低成本的提分手段**——它只改 LoRA 层的实现，训练脚本几乎不动。## 5 小结

- **DoRA = 权重分解 + 解耦优化**：把权重拆成幅度与方向，方向用 LoRA、幅度满秩直训。
- 前向 $W' = m \cdot (W_0 + \Delta W_{\text{LoRA}}) / \|W_0 + \Delta W_{\text{LoRA}}\|_c$；$m$ 初始化为基座列范数。
- **为什么更接近全参**：幅度信息量小但被 LoRA 拖累，DoRA 把幅度从低秩约束中解放出来——「该省的省、该精的精」。
- 效果：多个基准超过同秩 LoRA 1–3 个点，**few-shot 场景领先更大**；参数量几乎不增、推理合并后零开销。
- 选型：先跑 LoRA 基线，评测差口气且数据少时，换 DoRA 是最低成本的提分手段。
- 意义：PEFT 竞赛从「省参数」转向「逼近全参」；幅度/方向解耦成了后续方法的通用思路。
- 一句话记忆：**LoRA 是「方向和幅度一起低秩地改」，DoRA 是「方向低秩、幅度满秩」**——把最便宜的自由度还给了模型。
- 实现成本：DoRA 只比 LoRA 多「一个幅度向量 + 一次按列归一化」，**换来的 1–3 个点提升在低资源场景尤其值**。
