## 为什么从 IPO 与 KTO 开始

DPO 很成功，但它有两个「原生短板」：其一，**sigmoid 损失在训练后期饱和**，可能导致过拟合（上一节的过拟合根源）；其二，**DPO 要求成对数据**（$y_w, y_l$），而很多场景只有单条「好/坏」标注，凑不成对。

2023–2024 年的两个方法分别修补这两个短板：**IPO** 用平方损失替换 sigmoid，从「排序」走向「回归」，训练更稳；**KTO** 干脆放弃配对数据，引入行为经济学里的**前景理论（prospect theory）**，只用「这条回答是好的/坏的」二进制信号。两者共同拓宽了「偏好优化」的边界——不是所有对齐都要「两两比较」。<span class="marginnote">把三个方法并排看：<strong>DPO 学「A 比 B 好」，IPO 学「A 比 B 好多少」并校准回归，KTO 学「A 是好的」</strong>——对数据的要求从「成对」降到「单条二进制」，方法也从「分类」走向「回归」与「价值函数」。数据越粗，方法越要「稳」。</span>

## 1 IPO：修 DPO 的「正则化缺陷」

**IPO（Identity Preference Optimization，身份偏好优化）** 论文（Azar et al., 2023）的起点是一个理论诊断：**DPO 的 sigmoid 损失并不精确对应「KL 正则化的 RLHF 目标」**——它可能导致「奖励偏差」（模型对胜者过度自信）与过拟合。

IPO 的修复思路是：**把偏好优化直接定义成一个「回归问题」**——不再问「胜者概率多大」，而是问「胜者与败者的隐式奖励差，应该被推到多大」。

$$
\mathcal{L}_{\mathrm{IPO}} = \mathbb{E}\Big[ \Big( \log \frac{\pi_\theta(y_w)}{\pi_{\mathrm{ref}}(y_w)} - \log \frac{\pi_\theta(y_l)}{\pi_{\mathrm{ref}}(y_l)} - \frac{1}{2\beta} \Big)^2 \Big]
$$

逐项拆解：

- 括号里前两项：胜者与败者的「对数概率比之差」——即 DPO 的隐式奖励差；
- $-\frac{1}{2\beta}$：**目标间隔**——期望奖励差被推到 $\frac{1}{2\beta}$ 而不是无限大；
- **平方损失**：把「差值推到目标值」变成回归问题——**差值超过目标后，损失继续惩罚**（不像 sigmoid 那样饱和）。

**为什么平方损失更稳？** 因为 sigmoid 在「胜者已远高于败者」时梯度趋近 0——模型可以无限「自信」，过拟合由此而生。IPO 的平方损失**在越过目标后仍在「往回拽」**——它要求「差到目标值即可，不要过头」——这给了训练一个「自然的停止点」，从原理上抑制过拟合。<span class="marginnote">IPO 的「身份」一词来自它的理论主张：它优化的是「偏好的身份」而非「偏好概率」——直接让「隐式奖励差」对齐目标值，而不是经由 sigmoid 的间接变换。论文证明，这个回归形式在理论上与「KL 正则化 RLHF」的对应更精确，且对超参（β）的敏感性更低。</span>

IPO 的实现同样只有几行——把 sigmoid 换成平方：

```python
import torch.nn.functional as F

# 胜者与败者的隐式奖励差（对数概率比之差）
log_diff = beta * (log_π_w - log_ref_w) - beta * (log_π_l - log_ref_l)
loss = (log_diff - 1 / (2 * beta)) ** 2    # 对齐目标间隔的平方回归（MSE）
```

与 DPO 逐行对比会发现：**DPO 的 `-log σ(·)` 项换成了平方（MSE）**——仅此而已。这也说明了 IPO 的「低成本升级」定位：数据管线、参考模型、训练框架全都不用动，只换一行损失。## 2 公式解析：KTO——前景理论的「损失厌恶」

**KTO（Kahneman-Tversky Optimization）**（Ethayarajh et al., 2024）从行为经济学借来一个核心洞察：**人类对「损失」比「收益」更敏感（损失厌恶）**。这直接启发了它的损失设计——模型应该被「做错事」强烈惩罚，而「做对事」只需温和奖励。

KTO 只需要**二进制标签**：每条回答标「好的（desirable）」或「坏的（undesirable）」，无需配对。它的损失：

$$
\mathcal{L}_{\mathrm{KTO}} = \mathbb{E}\Big[\, \lambda_D \cdot \sigma\big(z_0 - r(x, y)\big)\ \big|\ y \text{ 是好的} \Big] + \mathbb{E}\Big[\, \lambda_U \cdot \sigma\big(r(x, y) - z_0\big)\ \big|\ y \text{ 是坏的} \Big]
$$

其中 $r(x, y) = \beta \log \frac{\pi_\theta(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}$ 是隐式奖励，$z_0$ 是**参考点**。逐项拆解：

- $r(x, y)$：模型相对参考对这条回答的「偏爱程度」；
- $z_0$：**参考点**——「什么样算好/坏」的阈值，通常取「模型自身输出」的平均隐式奖励；
- **好的回答**：$r$ 应该高于 $z_0$，于是 $\sigma(z_0 - r)$ 越小越好——**温和地推高好回答**；
- **坏的回答**：$r$ 应该低于 $z_0$，于是 $\sigma(r - z_0)$ 越小越好——**推低坏回答**；
- $\lambda_D$、$\lambda_U$：好坏两类的权重——**坏的权重通常更高**（$\lambda_U > \lambda_D$），这正是「损失厌恶」的落地：做错事受的惩罚更重。

**直觉**：KTO 把对齐从「比较两个回答」降为「判断单条回答的好坏」，并通过「损失厌恶」的不对称权重，让模型「宁可少犯错，不要冒险讨喜」。它在数据形态上更灵活——**只需要「这条回答行不行」的标注，不需要费力的两两比较**。<span class="marginnote">KTO 与前景理论的连接很直接：前景理论认为人类价值函数在「损失域」比「收益域」更陡——KTO 把这个不对称性编码进 $\lambda_U > \lambda_D$。一个实际的后果：KTO 训练的模型倾向于「保守」，更少说「可能会错的话」——这对「诚实」维度的对齐尤其有吸引力。</span>

KTO 的损失实现也直观——一条「好/坏」分支各算一份：

```python
import torch.nn.functional as F

r = beta * (log_π - log_ref)          # 隐式奖励
if is_desirable:                       # 这条回答是「好的」
    loss = lambda_D * F.sigmoid(z0 - r)     # 温和推高：r 越高于 z0，损失越小
else:                                   # 这条回答是「坏的」
    loss = lambda_U * F.sigmoid(r - z0)     # 强惩罚：r 越低于 z0，损失越小
```

注意两处设计：**$z_0$** 是「参考点」（阈值），**$\lambda_U > \lambda_D$ 的不对称权重**实现「损失厌恶」。这两个旋钮就是 KTO 的全部「哲学」——**阈值定「什么算好」、权重定「做错多可怕」**。## 3 数据形态的三种哲学：配对、目标值、二进制

把 DPO、IPO、KTO 放在「数据形态」的坐标系里，它们的适用边界一目了然：

| 方法 | 数据要求 | 损失形式 | 核心主张 |
| --- | --- | --- | --- |
| DPO | 成对偏好（$y_w, y_l$） | sigmoid 排序 | 隐式奖励的 BT 模型 |
| IPO | 成对偏好（$y_w, y_l$） | 平方回归 | 校准目标间隔，防过拟合 |
| KTO | 单条二进制（好/坏） | sigmoid 价值函数 | 损失厌恶，无需配对 |

三个观察：

- **成对数据是「金标准」但最贵**：DPO/IPO 的信息密度高，但标注成本高；
- **KTO 的数据最便宜**：二进制标注可以来自「模型输出是否被用户采纳」「人工快速打标」等更粗的渠道；
- **KTO 不要求「严格可比较」**：成对数据隐含「同一提示的两个回答」，KTO 甚至可以用「不同提示」的好/坏样本——数据收集的自由度大得多。

一个容易被忽视的实践影响：**数据形态决定了你能「从哪些渠道」收集数据**。成对偏好数据几乎只能靠「人工标注」或「强模型对比」产生；而「好/坏」二进制标注可以从**线上信号**直接获得——用户采纳、点赞、举报、负面反馈。这也是 KTO 在「产品侧对齐」场景越来越受关注的原因：它让「用户行为数据」能直接变成训练信号，而不必每次都拉人标注偏好对。

值得补充的是，KTO 的「二进制 + 损失厌恶」组合还有一个隐藏红利：**它对「噪声标注」更稳健**。成对数据里若「胜者/败者标反了」，会直接产生「教反」的信号；而 KTO 的单条「好/坏」标注即使偶尔标错，影响也更局部——「损失厌恶」的强惩罚让模型更「小心」，不会被个别坏标注带偏。这让 KTO 在「粗标注、高噪声」的产品数据上尤其好用。

## 4 选型：什么时候用 IPO / KTO

选型建议收成三句话：

- **有干净成对数据、DPO 又过拟合** → **IPO**。它几乎是「DPO 的免费升级」——数据要求不变，损失换一个更稳的形式；
- **只有好/坏信号、凑不成对** → **KTO**。它对数据形态的容忍度最高，是「粗标注也能对齐」的选项；
- **希望模型保守、少犯错** → **KTO**（损失厌恶天然偏向「不做错」）。

一个工程提醒：**KTO 的 $z_0$ 参考点需要小心设定**——它是「好/坏」的阈值，设偏了会让模型整体「过于自信」或「过于保守」。实践中常用「当前模型对提示池采样的平均隐式奖励」作为 $z_0$，并随训练动态更新。

## 5 小结

- **IPO 修 DPO 的过拟合**：把 sigmoid 排序换成平方回归，要求「隐式奖励差对齐目标值 $\frac{1}{2\beta}$」，不追求「无限自信」。
- **KTO 引入前景理论**：用二进制「好/坏」信号 + 损失厌恶权重（$\lambda_U > \lambda_D$），让模型「宁可少犯错」。
- **三种数据哲学**：DPO 成对、IPO 成对但回归、KTO 单条二进制——数据越粗，方法越稳。
- **选型**：成对数据且 DPO 过拟合 → IPO；只有好/坏信号 → KTO；想要保守模型 → KTO。
- KTO 的参考点 $z_0$ 是关键旋钮——用「模型自身采样的平均隐式奖励」动态更新。
