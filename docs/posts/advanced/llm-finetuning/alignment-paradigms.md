## 为什么从对齐范式开始

「从极限到大模型」走到这里，你已经看完三阶段的流水线：预训练给了模型语言与世界知识，指令微调（SFT）把「会续写」改造成「会听话」。可你还欠一个关键问题：**模型会听话，不等于守规矩**。它会谄媚、会编造、会复述偏见，甚至会一本正经地教人危险操作——SFT 的示范数据只告诉它「怎么答」，没告诉它「哪种答法更好」。

把「价值观」写进权重的这一步，就叫**对齐（alignment）**。本专题第六篇《偏好优化》将逐条拆解它的每一种算法，而这一篇是总览：两大路线——**基于人类反馈的强化学习（RLHF）**与**直接偏好优化（DPO）**——各自解决什么、数学上长什么样、工程上怎么选。读完这篇，你会拥有一张看懂后续所有偏好算法论文的地图。

## 1 对齐要解决什么：从「能答」到「会做人」

先看清 SFT 的两个盲区。

**盲区一：示范只有「对错」，没有「好坏」。** SFT 的标签是人工写好的回答，它教会模型「照葫芦画瓢」，却答不了「这两个回答哪个更好」。而「更好」恰恰是价值观所在——诚实、有用、无害，这些都不是单个回答能定义的属性，而是在**比较**中浮现的偏好。<span class="marginnote">「有用、诚实、无害」（helpful, honest, harmless）是 Anthropic 对齐研究中反复使用的三原则缩写，常记作 HHH。注意「无害」不是「永不拒绝」，而是「在不违背用户合理需求的前提下不做有害的事」——拒绝阈值的拿捏，正是本专题第六篇与《AI 安全》专题共同关心的问题。</span>

**盲区二：示范的覆盖面永远不够。** 人类写示范时只能写下「他认为对的回答」，写不出「他不愿回答的请求」，也写不出「微妙到无法用语言描述的偏好」。对齐阶段补上的，正是「偏好」这个信号：让人类或 AI 在多个候选回答之间做**成对比较**，再把「比较」翻译成训练目标。

两大路线对「如何把比较变成训练」给出了截然不同的回答：

- **RLHF**：把比较数据训练成一个**奖励模型（reward model）**，再用强化学习让语言模型去最大化这个奖励——先「读懂人类偏好」，再「按偏好去优化」。
- **DPO**：从数学上把上面的两步合并成一步——**直接**用一个闭式损失，让模型在偏好数据上一步到位，绕开奖励模型与强化学习。

**重点：两条路线共享同一种偏好数据（成对比较），分歧在于「要不要显式建模奖励、要不要用强化学习」**——这是理解全部后续争论的总钥匙。

## 2 RLHF 路线：奖励模型 + 强化学习

RLHF 是 2017 年起在机器人领域萌芽、2022 年由 OpenAI 的 InstructGPT 工作带入大模型主流的经典路线。它由三件套组成。

### 第一步：偏好数据与 Bradley-Terry 模型

拿到「（提问，被偏好的回答 $y_w$，不被偏好的回答 $y_l$）」三元组后，RLHF 假设人类的偏好服从 **Bradley-Terry 模型**：回答被选中的概率只取决于两者的奖励之差经过 logistic 函数：

$$
p(y_w \succ y_l \mid x) = \frac{\exp\big(r(x, y_w)\big)}{\exp\big(r(x, y_w)\big) + \exp\big(r(x, y_l)\big)} = \sigma\big(r(x, y_w) - r(x, y_l)\big)
$$

这里 $\sigma$ 是 sigmoid 函数，$r(x, y)$ 是某种「潜在奖励」——它还没出现，是待训练的。

### 第二步：训练奖励模型

用一个打分模型 $r_\phi(x, y)$ 去拟合上述偏好：对每一对偏好数据，最大化「被偏好回答排在前」的对数似然：

$$
\mathcal{L}_{\mathrm{RM}}(\phi) = -\mathbb{E}_{(x,y_w,y_l)\sim\mathcal{D}}\log \sigma\big(r_\phi(x,y_w) - r_\phi(x,y_l)\big)
$$

训练完成后，$r_\phi$ 就是一个「会打分」的奖励模型：给它一个（提问，回答），它输出一个标量，数值越高代表越符合人类偏好。<span class="marginnote">奖励模型通常用 SFT 模型加一个标量输出头来初始化——它和语言模型共享大部分权重，但输出从「词表上的分布」变成「一个实数」。奖励模型的训练细节（排序损失变体、集成、校准）在第六篇《偏好数据收集》与《奖励模型训练》两节展开。</span>

### 第三步：用 PPO 最大化奖励、同时压住偏离

有了奖励模型，就把它当成强化学习里的「环境反馈」。用 **PPO** 训练策略 $\pi_\theta$，目标是：

$$
\max_{\pi_\theta} \ \mathbb{E}_{x\sim\mathcal{D},\, y\sim\pi_\theta(\cdot\mid x)}\big[ r_\phi(x, y) \big] - \beta\ \mathbb{E}_{x\sim\mathcal{D}} D_{\mathrm{KL}}\big[ \pi_\theta(\cdot\mid x) \,\|\, \pi_{\mathrm{ref}}(\cdot\mid x) \big]
$$

**重点：第二项 KL 惩罚是 RLHF 的命门。** 奖励模型是近似品，如果只最大化奖励，模型会迅速「钻空子」——编造高分话术骗过奖励模型，而不是真正变好。KL 惩罚像一根橡皮筋，把 $\pi_\theta$ 拴在参考模型 $\pi_{\mathrm{ref}}$（通常就是 SFT 模型）附近，不允许它为了刷分而走得太远。<span class="marginnote">奖励模型被「钻空子」有一个专门的名字：奖励黑客（reward hacking）——模型找到最大化奖励但违背真实意图的行为，例如用「我保证」「绝对安全」等空洞措辞刷高分。它的识别与缓解在第九篇《reward hacking》专讲。</span>

这条路线是**在线**的：每次更新后，模型产生新回答、交给奖励模型打分、再用分数更新模型——数据在训练循环内部不断「自我生成」。

## 3 DPO 路线：把 RLHF 闭式求解

RLHF 强大，但工程上繁琐：要训练奖励模型、要写强化学习循环、要调 PPO 的一堆超参数。2023 年，斯坦福的 Rafailov 等人提出 **DPO（直接偏好优化）**，问了一个漂亮的问题：**KL 约束下的最优策略，其奖励能否反解出来？**

答案是能。受 KL 约束的强化学习问题有闭式解：最优策略对任意回答给出的奖励，等于「对数概率比乘以温度 $\beta$」再加上一个与回答无关的归一化常数（下一节推导）。把这条关系代回 Bradley-Terry 模型，奖励模型 $r_\phi$ 就被彻底消掉了——最终得到只含 $\pi_\theta$ 与参考模型 $\pi_{\mathrm{ref}}$ 的损失：

$$
\mathcal{L}_{\mathrm{DPO}}(\theta) = -\mathbb{E}_{(x,y_w,y_l)\sim\mathcal{D}}\log\sigma\Big(\beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\mathrm{ref}}(y_w\mid x)} - \beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\mathrm{ref}}(y_l\mid x)}\Big)
$$

**重点：DPO 没有消灭「奖励」，而是把奖励隐式地编码进了概率比。** 它不再需要一个显式的打分模型，也不需要 PPO——训练就是一轮普通的梯度下降，甚至可以用 SFT 的同一套代码。

DPO 是**离线**的：训练数据就是预先收集好的偏好三元组，训练循环里不再有「模型生成 → 打分 → 反馈」的环节。这个「在线/离线」的差别看似工程细节，实则是后续几乎所有变体（KTO、ORPO、GRPO、迭代 DPO）的分水岭，我们会在第六篇逐一展开。

## 4 公式解析：从 RLHF 目标到 DPO 损失

把上一节「消掉奖励」的推导补全，这是理解 DPO 的数学核心。

**第一步，解出最优策略。** 对 RLHF 目标里的每个输入 $x$，它是一个带 KL 约束的优化问题。拉格朗日法给出最优策略的闭式解：

$$
\pi^*(y\mid x) = \frac{1}{Z(x)}\,\pi_{\mathrm{ref}}(y\mid x)\exp\Big(\frac{1}{\beta}\,r(x, y)\Big)
$$

其中 $Z(x) = \sum_y \pi_{\mathrm{ref}}(y\mid x)\exp(r(x,y)/\beta)$ 是配分函数（归一化常数）。**直觉**：最优策略就是在参考模型的基础上，按「奖励的指数」做重加权——奖励高的回答获得更高的概率。

**第二步，把奖励反解出来。** 对上面的等式取对数并移项：

$$
r(x, y) = \beta\log\frac{\pi^*(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)} + \beta\log Z(x)
$$

逐符号看：$\beta$ 是温度系数，控制对奖励的敏感度；$\pi^*$ 是（理想中的）最优对齐策略；$Z(x)$ 只依赖 $x$ 不依赖 $y$，是后面会被消掉的「幽灵项」。

**第三步，代回 Bradley-Terry。** 把 $r(x,y_w) - r(x,y_l)$ 代入第 2 节偏好概率的表达式，$Z(x)$ 项相减后消失，得到：

$$
p(y_w \succ y_l) = \sigma\Big(\beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\mathrm{ref}}(y_w\mid x)} - \beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\mathrm{ref}}(y_l\mid x)}\Big)
$$

对整条式子取负对数、对数据取期望，就得到 DPO 损失。**逐项拆解**：

- $\beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\mathrm{ref}}(y_w\mid x)}$：回答 $y_w$ 的「隐含奖励」——模型对它比参考模型更偏好多少（对数概率比 × 温度）；
- 两项相减：被偏好回答与不被偏好回答的隐含奖励之差；
- $\sigma(\cdot)$：把差值压到 0–1，作为「$y_w$ 胜出的概率」；
- 取负对数再求期望：与奖励模型的训练目标（第 2 节 $\mathcal{L}_{\mathrm{RM}}$）**结构完全同构**——区别只是把显式奖励换成了概率比。

**直觉**：DPO 的梯度会同时做两件事——提高模型产出 $y_w$ 的概率、压低产出 $y_l$ 的概率，而「拉高/压低」的尺度由 $\beta$ 与参考模型的概率比共同决定。<span class="marginnote">一个值得注意的对称性：DPO 损失的形态与第 2 节奖励模型的损失只差一个「奖励函数」的换元。这也是很多教程说「DPO = 把奖励模型训练到语言模型自己身上」的原因。</span>

代码里，DPO 损失可以浓缩成几行：

```python
import torch
import torch.nn.functional as F

def dpo_loss(logps_w, logps_l, ref_logps_w, ref_logps_l, beta=0.1):
    implicit_rw = beta * (logps_w - ref_logps_w)     # 隐含奖励：偏好回答
    implicit_rl = beta * (logps_l - ref_logps_l)     # 隐含奖励：不偏好回答
    logits = implicit_rw - implicit_rl
    return -F.logsigmoid(logits).mean()
```

## 5 两大路线对比与易错辨析

把两条路线并排看：

| 维度 | RLHF（PPO） | DPO |
| --- | --- | --- |
| 是否显式训练奖励模型 | 是 | 否（奖励隐式编码在概率比里） |
| 是否用强化学习 | 是（PPO） | 否（单轮监督式梯度下降） |
| 在线 / 离线 | 在线（模型边生成边优化） | 离线（固定偏好数据） |
| 计算开销 | 高（价值网络、经验回放、KL 控制） | 低（与 SFT 相当） |
| 稳定性 | 敏感，超参数多 | 相对稳，但依赖数据与参考模型 |
| 分布偏移鲁棒性 | 较高（能探索新回答） | 较低（回答空间被数据锁死） |

**辨析｜易错点：** 四个高频误区。

1. **以为 DPO 不需要偏好数据。** DPO 免掉的是「显式奖励模型」与「强化学习循环」，**偏好三元组一个都不能少**——它只是把「比较」直接用进了损失。
2. **以为 DPO 没有参考模型。** $\pi_{\mathrm{ref}}$ 在损失里以「分母」出现，通常取 SFT 模型，必不可少。真正去掉参考模型的是 ORPO、SimPO（第六篇讲），不是 DPO。
3. **以为 RLHF 与 DPO 必然等价。** 闭式推导假设偏好数据「覆盖充分、分布匹配」。离线 DPO 在新输入分布上会因回答空间受限而退化；在线 RLHF 因能自我探索、不断产生新回答，分布偏移鲁棒性更强——这也是业界「迭代 DPO」「在线变体」盛行的原因。
4. **搞错 KL 惩罚的方向。** RLHF 的 KL 项约束的是「$\pi_\theta$ 别离 $\pi_{\mathrm{ref}}$ 太远」，方向是防止策略漂移、防止奖励黑客，不是反过来让模型贴近某种「真实分布」。

## 6 小结

- **对齐**解决 SFT 的两大盲区：示范只含「对错」不含「好坏」，且覆盖面永远不够；偏好数据以「成对比较」补齐。
- **RLHF**：偏好数据 → Bradley-Terry 训练奖励模型 → PPO 最大化奖励 + KL 惩罚防漂移，是**在线**、需要奖励模型与强化学习的完整管线。
- **DPO**：受 KL 约束的最优策略把奖励反解为「概率比 × 温度」，代回 Bradley-Terry 后奖励模型被消掉，得到只用 $\pi_\theta$ 与 $\pi_{\mathrm{ref}}$ 的**离线**损失。
- **共享数据、分歧在训练范式**：两条路线用同一份成对偏好数据，区别是「显式奖励 + 强化学习」还是「隐式奖励 + 一步梯度下降」。
- **选型**：要稳健、能自我探索选在线 RLHF；要轻量、可复现、算力有限选 DPO；理解这条权衡线，是读懂第六篇所有偏好算法变体的前提。

在下一节，我们从「用哪种算法」退一步，问一个更基础的问题：**微调到底吃多少数据、多大模型，才值得？** 数据量、模型规模与下游收益之间的缩放定律，决定你预算的每一分钱该花在哪。
