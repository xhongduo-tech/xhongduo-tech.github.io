## 为什么从继续预训练开始

在《微调范式总览》里，我们建立了三段式流水线：预训练 → 指令微调 → 对齐。但真实工程里，第二站之前往往还插着一站：**继续预训练（continual pre-training, CPT）**。基座模型读懂了「通用世界」，可它未必懂你的领域——中文法律条文怎么断句、这家医院的病历缩写是什么意思、这个代码仓库的 API 惯例是什么。直接拿通用基座做指令微调，模型会「听懂指令但给不出内行答案」，因为它脑子里根本没有领域知识。

继续预训练，就是**用领域语料让基座模型再读一遍书**。它不改变目标函数（仍是下一个词预测），只改变阅读材料。这篇我们讲清楚三件事：选什么语料、按什么比例混合、用什么策略训练。

## 1 继续预训练是什么

**继续预训练（CPT）**：在已预训练好的基座模型之上，用特定领域语料继续做因果语言建模，把领域知识写进权重，同时尽量不破坏已有通用能力。

它和「从零预训练」的区别不在数学，而在规模与意图：

| 维度 | 从零预训练 | 继续预训练 |
| --- | --- | --- |
| 起点 | 随机初始化 | 已预训练基座 |
| 语料 | 数万亿 token，通用 | 数十亿到百亿 token，领域为主 |
| 学习率 | 相对大 | 明显更小（约低 1 个数量级） |
| 步数 | 数十万步 | 数千到数万步 |
| 目标 | 学会语言与世界 | 补充领域知识、更新知识 |

三类典型场景：**领域适配**（法律、医疗、金融）、**语言扩充**（基座的中文或非英语能力不足）、**知识更新**（让模型知道停更之后的新知识）。<span class="marginnote">「领域适配」是研究最多的场景。2020 年 Gururangan 等人的经典论文标题就叫《Don't Stop Pretraining》，用领域语料对 RoBERTa 做继续预训练，让下游任务普遍涨点——「别停，继续预训练」从此成为一条方法论。</span>

**重点：继续预训练改的是「知识」与「语言」，不是「行为」。** 它读的还是续写文本，不会因此学会「你问我答」——那是下一步指令微调的活。把 CPT 和 SFT 混为一谈，是这一专题最常出现的误解之一。

拿真实案例看配比。**BloombergGPT（2023）**：金融领域的 7000 亿 token 预训练模型，训练数据在 3450 亿金融语料之外混入约 3630 亿通用语料，几乎是「金融 : 通用 = 1:1」；**Meditron-70B（2023）**：医疗模型以约 48 亿 token 的医学语料做继续预训练，并引入课程式混合来维持通用能力。两个案例指向同一条经验：**领域越窄、专业密度越高，混合比反而越要克制**——因为领域语料相对通用语料小得多，用力过猛就会遗忘。<span class="marginnote">「领域语料远小于通用语料」是配比的第一约束：医疗语料以亿计，通用语料以万亿计。混合的意义不是在数量上抗衡，而是在每个 batch 里给领域信号一个「在场权重」。</span>

## 2 语料选择：领域语料从哪里来、怎么清洗

语料是 CPT 的地基。领域语料通常来自：

- **公开领域语料库**：法律条文、判例、财报、论文、专利、医学教科书；
- **业务数据**：企业内部的文档、工单、聊天记录、代码仓库（注意合规）；
- **合成语料**：用大模型基于领域资料生成问答或解析，再回灌（对应第二篇《数据工程》的蒸馏路线）。

拿到原始文本后，清洗流水线大致是：**去重 → 去噪 → 过滤 → 配比**。去重尤其关键：训练数据里高比例重复，会让模型学会「背诵」而非「理解」，也在后续评测里造成数据污染。<span class="marginnote">数据污染是评测中的经典陷阱：如果评测题就在训练语料里，模型「记住答案」会被误读为「学会了推理」。本专题第九篇《评估与诊断》会专门讲污染检测。</span>

**重点：语料质量比语料数量更重要。** 继续预训练里，「百万条重复工单」远不如「十万条干净、多样、有长程依赖的文档」。低质量语料会压低模型原有的语言能力——这是一个真实的、可观测的退化。

## 3 混合配比：通用语料与领域语料的比例

如果只喂领域语料，模型会逐渐「忘记」通用能力——这就是**灾难性遗忘（catastrophic forgetting）**。缓解的第一道闸门就是**混合配比（data mixing）**：在领域语料里掺入一部分通用语料。

工程上常见的做法：领域与通用按 **9:1 到 7:3** 混合，或随训练进程做**退火混合（annealed mixing）**——早期领域占比高、快速吸收领域知识，后期通用占比回升、把「说话的基本功」找补回来。<span class="marginnote">「退火」借用了冶金学意象：先加热再缓慢降温，让材料结构稳定下来。训练里则是先猛学领域、再缓学通用，让权重从领域语料的热量中平稳落回稳定结构。</span>

**重点：通用数据不是「浪费」，是「保险」。** 它占的算力比例不高，却决定模型在领域之外还能不能好好说话、能不能被后续指令微调与对齐承接。

## 4 训练策略：学习率、步数与课程

CPT 的关键调参直觉只有一句：**温和**。基座已经接近一个很好的局部最优，用力过猛会把它推坏。

- **学习率**：约 $1\times10^{-5}$ 到 $3\times10^{-5}$（比预训练低约 10 倍），且常配 warmup；
- **步数**：通常只需「读完一遍领域语料」量级的步数，即 1–3 个 epoch；
- **序列长度与批大小**：可适当加大，让模型看到更长的领域文本（对应第五篇《长序列微调》）；
- **课程（curriculum）**：从易到难排列语料，或按时间顺序排列新闻语料，让模型平滑吸收。<span class="marginnote">「知识更新」类 CPT 尤其依赖时间排序：如果先讲 2025 年再回讲 2023 年，模型会陷入矛盾。时间课程让新信息稳定地「压」在旧信息之上。</span>

训练时要盯**双指标**：领域验证集 loss 与通用能力抽查（例如一段通用文本的困惑度，或一个轻量通用基准）。领域 loss 收敛、通用指标刚开始下滑，就是收手的信号——**CPT 讲求「够了就停」，而不是「越低越好」**。

**辨析｜易错点：** 新手最常犯的两个错。一是**学习率照搬预训练**——把领域模型直接训崩（loss 剧烈震荡、通用能力断崖）；二是**epoch 过多**——领域语料通常只有几十亿 token，反复读十几遍，模型开始逐字背诵语料、丧失泛化。CPT 的 KPI 不是「训练 loss 越低越好」，而是「**领域能力上去 + 通用能力不塌**」，两个指标要一起看。

## 5 公式解析：混合训练目标

继续预训练的损失在数学上与预训练毫无区别——都是下一个词的交叉熵。区别全在「对哪些数据算」：

$$
L_{\text{CPT}}(\theta) = -\frac{1}{T}\sum_{t=1}^{T} \log P_\theta(x_t \mid x_{<t})
$$

这里 $x_{<t}$ 是位置 $t$ 之前的全部 token，$P_\theta(x_t \mid x_{<t})$ 是模型认为真实 token $x_t$ 是下一个词的概率，$T$ 是序列长度。**这条式子与预训练逐字相同**——所以 CPT 常被称作「把预训练再做一遍，只是换了语料」。

引入通用数据后，目标变成两个期望的加权和：

$$
L_{\text{CPT}}(\theta) = (1-\alpha)\,\mathbb{E}_{d\sim\mathcal{D}_{\text{domain}}}\big[\ell_d(\theta)\big] + \alpha\,\mathbb{E}_{g\sim\mathcal{D}_{\text{general}}}\big[\ell_g(\theta)\big]
$$

逐步拆解：

- **$\ell_d(\theta)$、$\ell_g(\theta)$**：领域样本与通用样本各自的单样本交叉熵——两者形式相同，只是来源不同；
- **$\alpha$**：通用数据的混合权重。$\alpha = 0$ 是纯领域（遗忘最凶），$\alpha = 0.1$–$0.3$ 是常见设定（保通用），$\alpha$ 接近 1 则退化成原预训练（领域知识吸收慢）；
- **期望 $\mathbb{E}$**：在工程里换成「从对应数据池按比例采样」——采样比例正是上一节说的配比；
- **退火混合**：让 $\alpha$ 随步数从低到高变化，先 $(1-\alpha)$ 大（猛学领域），后 $\alpha$ 大（找回通用）——同一公式，参数随时间变化而已。

**直觉**：每个 batch 里混着两种「教材」，模型同时面对「领域生词」和「通用老词」，梯度是两类信号的平均。领域信号把它往领域专家推，通用信号把它往「正常说话」拽——$\alpha$ 就是这两个力之间的杠杆。<span class="marginnote">这正对应下一篇《领域自适应预训练与通用能力保持的权衡》：混合配比只是控制遗忘的第一层杠杆，更精细的手段（正则化、蒸馏、参数高效）我们下一篇展开。</span>

一个简化的训练循环骨架：

```python
for step, batch in loader:          # loader 按 (1-α : α) 混装领域与通用 batch
    x = batch["input_ids"]           # (B, T)
    logits = model(x).logits         # (B, T, V)
    loss = cross_entropy(logits[:, :-1], x[:, 1:])   # 下一个词预测
    loss.backward()
    optimizer.step()                 # 学习率 ~1e-5，全局 warmup
    scheduler.step()                 # 可选：随 step 抬高 α，实现退火混合
```

## 6 小结

- **继续预训练（CPT）** = 在基座上用领域语料继续做下一个词预测，补知识、扩语言、更新知，不改变目标函数。
- **语料**：公开语料 + 业务数据 + 合成语料，核心是**去重、去噪、质量优先**。
- **混合配比**：领域 : 通用 ≈ 9:1 到 7:3，或做**退火混合**，防止灾难性遗忘。
- **训练策略**：学习率约 $10^{-5}$ 量级、1–3 个 epoch、可选课程学习——一切求「温和」。
- **CPT 改知识不改行为**，它只是 SFT 的铺垫，不是替代。

在下一节，我们把「防止遗忘」这件事单独拎出来：当领域自适应预训练与通用能力发生冲突时，除了调配比，还有哪些更精细的手段——这就是**领域自适应预训练与通用能力保持的权衡**。
