# 一维原子链振动

## 为什么从一维原子链开始

晶体的原子并非钉死在格点上，它们围绕平衡位置**热振动**。
这些振动不是孤立的——相邻原子通过相互作用耦合，振动以**波**的形式在晶体中传播，这就是**格波（lattice wave）**。
格波是理解固体热容、热导、相变、甚至超导（声子中介）的钥匙。<span class="marginnote">三维晶体里 $10^{23}$ 个原子的耦合振动看起来无法下手，但<strong>一维单原子链把全部物理浓缩成一道可以手算的方程</strong>。
先把它吃透，三维只是把 3 个偏振方向加进来而已——这是物理学家「从最简模型出发」的标准策略。</span>

本节研究最简单的周期体系：一条无限长的、质量相同的原子链，近邻之间用弹簧（力常数 $K$）连接。
它的解已经包含了声子的全部核心图像。

## 1 单原子链的运动方程

设原子质量为 $M$，平衡间距为 $a$，第 $n$ 个原子相对平衡位置的位移为 $u_n$。
近邻间是弹性力（胡克定律），第 $n$ 个原子受到的合力来自左右两个邻居：

$$M \frac{d^2 u_n}{dt^2} = K(u_{n+1} - u_n) - K(u_n - u_{n-1}) = K(u_{n+1} + u_{n-1} - 2u_n)$$

这是一组耦合的常微分方程——每个方程都牵动邻居。
解耦的关键是**猜出行波解**：

$$u_n(t) = A e^{i(qna - \omega t)}$$

其中 $q$ 是波矢（沿链方向的「空间频率」），$\omega$ 是角频率。
代入运动方程，两边约去公因子，得到**色散关系（dispersion relation）**：

$$\omega(q) = 2\sqrt{\frac{K}{M}} \left|\sin\frac{qa}{2}\right|$$

这是凝聚态物理最重要的公式之一。<span class="marginnote"><strong>色散关系</strong>：波的频率 $\omega$ 与波矢 $q$ 的关系，决定波如何传播。
它把「振动」变成「波」——$q$ 是周期结构给振动打的「动量标签」，后面会看到它与声子动量一一对应。</span>

## 2 色散关系告诉了我们什么

### 长波极限：声速

当 $q \to 0$（波长 $\lambda \gg a$），$\sin(qa/2) \approx qa/2$，于是：

$$\omega \approx \sqrt{\frac{K}{M}}\, a\, q = v_s q$$

频率与波矢**线性关系**，斜率就是**声速** $v_s = a\sqrt{K/M}$。
这正是连续介质里声波的色散——**长波长时，原子链退化为连续弹性介质**，周期结构「看不见了」。<span class="marginnote">这就是为什么宏观声速可以由原子参数算出：固体中的声波就是原子格波的长波极限。
对铜，$a \approx 3.6$ Å、$K/M \sim 10^{26}$ s⁻²，估算 $v_s \sim 3$ km/s，与实测（纵波约 4.7 km/s）量级吻合——<strong>只用胡克定律和原子间距就解释了宏观声速</strong>。</span>

### 短波极限：布里渊区边界

在 $q = \pm \pi/a$（第一布里渊区边界），$\sin(\pi/2) = 1$，频率取最大值：

$$\omega_{\max} = 2\sqrt{\frac{K}{M}}$$

此时相邻原子**反相振动**（$u_{n+1} = -u_n$），波长为 $2a$，是链上能传播的最短格波。
波长更短的波（$q$ 越过 $\pi/a$）实际上与某个更长波长的波等价——周期性把频率压进有限范围。

**重点：一切物理信息都在第一布里渊区里。** 对任何 $q' = q + 2\pi m/a$（$m$ 为整数），$\sin(q'a/2) = \sin(qa/2)$，色散关系完全重复。格波的「动量」只能定义在 $[-\pi/a, \pi/a]$ 内，多出去的 $2\pi m/a$ 纯粹是周期性假象。

## 3 双原子链：光学支与声学支

把链改成两种原子交替排列（质量 $M_1 > M_2$，间距仍为 $a$，但两原子组成一个原胞，原胞周期 $2a$）。
解方程得到**两支**色散关系：

$$\omega_{\pm}^2(q) = K\left(\frac{1}{M_1} + \frac{1}{M_2}\right) \pm K\sqrt{\left(\frac{1}{M_1} + \frac{1}{M_2}\right)^2 - \frac{4\sin^2(qa)}{M_1 M_2}}$$

- **声学支（acoustic branch）** $\omega_-(q)$：$q \to 0$ 时 $\omega \to 0$，两支原子**同相**移动，像声波一样压缩-拉伸。
- **光学支（optical branch）** $\omega_+(q)$：$q \to 0$ 时 $\omega = \sqrt{2K(1/M_1+1/M_2)}$，两支原子**反相**振动，偶极矩周期性振荡，能与光（红外电磁波）耦合——因此得名「光学」。<span class="marginnote">光学支的微观图像：正负离子像「拉伸的弹簧偶极子」一样反相振动，产生振荡偶极矩，所以能吸收与发射红外光。<strong>NaCl 在红外区有强吸收带，就是光学声子被光子激发</strong>——这也是微波炉里某些陶瓷发热的微观机制。</span>

### 两支之间的频率隙

在布里渊区边界 $q = \pi/a$ 处，声学支 $\omega_- = \sqrt{2K/M_1}$，光学支 $\omega_+ = \sqrt{2K/M_2}$。
若 $M_1 \neq M_2$，两者之间出现一段**没有格波能存在的频率区间**——声子带隙。
频率落在此区间的波在晶体里指数衰减，无法传播。

## 4 公式解析：单原子链色散关系推导

$$\omega(q) = 2\sqrt{\frac{K}{M}} \left|\sin\frac{qa}{2}\right|$$

- **第一步，代入行波解**：$u_n = A e^{i(qna - \omega t)}$，则 $u_{n+1} = A e^{i(q(n+1)a - \omega t)} = u_n e^{iqa}$，$u_{n-1} = u_n e^{-iqa}$。
- **第二步，化简运动方程**：$M(-\omega^2) u_n = K(e^{iqa} + e^{-iqa} - 2)u_n$，左边是 $\ddot u_n$ 带来的 $-M\omega^2 u_n$。
- **第三步，用恒等式**：$e^{iqa} + e^{-iqa} - 2 = 2\cos(qa) - 2 = -4\sin^2(qa/2)$。
- **第四步，解出频率**：$M\omega^2 = 4K\sin^2(qa/2) \Rightarrow \omega = 2\sqrt{K/M}\,|\sin(qa/2)|$。

整条推导只需要「代一猜解 + 一次三角恒等式」——行波解让耦合方程组变成了单变量代数方程，这是把「集体运动」转成「单波」的通用技巧，和傅里叶分析把信号拆成正弦分量的思路完全一致。

**辨析｜易错点：**色散关系是**正弦函数取绝对值**，不是 $\sin(qa/2)$ 本身（否则频率为负，无物理意义）。写 $\omega(q)$ 时务必带 $|\cdots|$，并记住物理上只取 $\omega \ge 0$ 的分支；对同一 $\omega$，$+q$ 与 $-q$ 对应传播方向相反的两列波。

## 5 玻恩-冯·卡门边界条件

真实晶体有限，但边界效应必须处理。
**玻恩-冯·卡门（Born–von Karman）边界条件**把有限链首尾相接成环，要求：

$$u_{n+N} = u_n$$

对含 $N$ 个原子（周期 $Na$）的环，行波解要求 $e^{iqNa} = 1$，于是：

$$q = \frac{2\pi m}{Na}, \qquad m = 0, \pm 1, \ldots, \pm\frac{N}{2}$$

**第一布里渊区内的 $q$ 恰好有 $N$ 个离散值**——与 $N$ 个自由度一一对应，没有遗漏也没有多余。<span class="marginnote">周期性边界条件把无限链的连续 $q$ 变成离散的 $N$ 个模式，这是「有限大体系量子化波矢」的通用手法，在后面声子、电子能带、量子化磁场里反复出现。<strong>$N$ 个自由度的系统总有 $N$ 个独立振动模式</strong>——自由度守恒。</span>

## 6 小结

- **单原子链**色散 $\omega = 2\sqrt{K/M}\,|\sin(qa/2)|$，长波极限退化为声波，声速 $v_s = a\sqrt{K/M}$。
- 频率在**第一布里渊区** $[-\pi/a, \pi/a]$ 内取值；边界处相邻原子反相，$\omega_{\max} = 2\sqrt{K/M}$。
- **双原子链**出现**声学支与光学支**两支，之间有频率隙；光学支与红外电磁波耦合。
- **玻恩-冯·卡门条件**把 $q$ 离散成 $N$ 个值，与自由度一一对应。
- 行波解 + 色散关系 = 把耦合振动「解耦」成独立格波的通用方法。
