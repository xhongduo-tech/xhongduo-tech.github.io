## 为什么从二级相变与序参量开始

前面几节已经见过多次「相变」：铁磁在 $T_C$ 失去磁化、超导在 $T_c$ 失去零电阻、反铁磁在 $T_N$ 失去交错序。
这些转变有一个共同结构：**某个宏观量（磁化、能隙）从零变成非零**。
把它们统一起来的语言，就是**序参量（order parameter）**与**朗道相变理论**。<span class="marginnote">朗道理论的野心：<strong>不关心微观机制，只靠「对称性」与「自由能」就预言相变的一切定性行为</strong>。
铁磁、超导、液晶、结构相变，统统装进同一个框架。
它把相变研究从「逐个案例」变成「一门学科」——这正是凝聚态物理「多者异也」的精神：现象千差万别，结构惊人地统一。</span>

本节讲清楚：相变怎么分类、序参量是什么、朗道自由能如何描述对称性破缺。

## 1 相变的分类：一级与二级

按热力学量在转变点的行为，相变分两类（埃伦费斯特分类）：

| 特征 | 一级相变 | 二级相变（连续相变） |
| --- | --- | --- |
| 自由能一阶导（熵、体积） | 不连续 | 连续 |
| 自由能二阶导（比热、压缩率） | 发散/有限 | 发散 |
| 潜热 | 有 | 无 |
| 两相共存 | 有 | 无 |
| 序参量 | 跳跃 | 连续从零增长 |
| 例子 | 冰-水、汽化、多数熔化 | 铁磁 $T_C$、超导 $T_c$、结构相变 |

**重点：二级相变没有潜热，序参量连续地从零长起来**。冰变成水是一级（0°C 潜热、冰水共存）；铁在居里点变成顺磁是二级（磁化连续消失、比热发散）。<span class="marginnote">判定相变级别的最实用方法：<strong>画序参量随温度曲线</strong>——一级是「啪」地跳到非零，二级是「咻」地从零连续增长。二级相变点也叫<strong>临界点</strong>，那里涨落达到无穷大，正是下一节「临界现象与普适类」的主角。</span>

## 2 序参量

**序参量（order parameter）**：一个刻画「有序程度」的物理量，在无序相为零，在有序相非零。它是相变理论的灵魂。

| 相变 | 序参量 | 对称性变化 |
| --- | --- | --- |
| 铁磁 | 磁化强度 $\vec{M}$ | 旋转对称性 → 破缺（选一个方向） |
| 反铁磁 | 交错磁化 $\vec{N}$ | 平移+自旋转动 → 破缺 |
| 超导 | 复能隙 $\Delta = |\Delta|e^{i\theta}$ | U(1) 相位对称 → 破缺 |
| 超流 | 凝聚波函数 $\psi = \sqrt{n_s}e^{i\theta}$ | U(1) → 破缺 |
| 结构相变 | 声子软模位移 $\langle u\rangle$ | 晶格对称性 → 破缺 |
| 液晶 | 取向有序张量 | 旋转 → 破缺 |

**序参量不一定是标量**：可以是矢量（磁化）、复函数（超导能隙）、张量（液晶取向）。**它的对称性决定相变的分类与临界行为**——这就是朗道理论的起点。<span class="marginnote">一个深刻的统一：<strong>铁磁的 $\vec{M}$、超导的 $\Delta$、晶体的位移，本质都是「某个对称性的自发破缺」</strong>。对称性破缺概念来自粒子物理（南部阳一郎，2008 年诺奖），在凝聚态里开花结果——「序」的本质就是「对称性降了一级」。</span>

## 3 朗道自由能

朗道假设：靠近相变点时，自由能密度可以展开成序参量 $\eta$ 的幂级数：

$$F(\eta, T) = F_0(T) + \frac{1}{2}a(T)\eta^2 + \frac{1}{4}b\eta^4 + \cdots$$

其中 $a(T) = a_0(T - T_c)$，$b > 0$ 常数。
**体系取 $F$ 对 $\eta$ 的极小**。

### 为什么只有偶次项？

对称性：对铁磁，$F$ 必须在 $\eta \to -\eta$ 下不变（翻转所有自旋，物理不变）——所以没有 $\eta$、$\eta^3$ 项。
**自由能继承序参量的对称性**，这是朗道理论的骨架。<span class="marginnote">「缺奇次项」不是疏忽，是<strong>对称性强制</strong>：序参量反号时系统物理不变，自由能自然只含偶次项。
假如对称性允许奇次项（如某些共线序与晶格耦合），相变立即变成一级——<strong>对称性决定相变级别</strong>，这是朗道理论最犀利的推论。</span>

## 4 公式解析：极小条件与序参量的温度依赖

$$F = F_0 + \frac{1}{2}a_0(T - T_c)\eta^2 + \frac{1}{4}b\eta^4$$

对 $\eta$ 求极值：

- **第一步，写极小条件**：$\frac{\partial F}{\partial \eta} = a_0(T - T_c)\eta + b\eta^3 = 0$。
- **第二步，解方程**：$\eta\left[a_0(T - T_c) + b\eta^2\right] = 0$，两根：$\eta = 0$ 或 $\eta = \pm\sqrt{\frac{a_0}{b}(T_c - T)}$。
- **第三步，判稳定**：$T > T_c$ 时 $a > 0$，唯一的极小是 $\eta = 0$——无序相；$T < T_c$ 时 $a < 0$，$\eta = 0$ 是极大（不稳定），两个对称的极小 $\eta = \pm\sqrt{a_0(T_c-T)/b}$——有序相。
- **第四步，读出临界指数**：$\eta \propto (T_c - T)^{\beta}$，**$\beta = 1/2$**——序参量按温度的 1/2 次方增长。

**朗道理论给出序参量的定量温度依赖，但它忽略了涨落**（平均场近似）。真实系统的临界指数往往偏离 1/2（铁磁 $\beta \approx 0.32$），这正是下一节「临界现象与普适类」要处理的问题——涨落改写了临界指数，却保留了普适性。

**辨析｜易错点：**朗道理论是**平均场**：它假设每个序参量「看到」的是平均环境，忽略了局部涨落。在相变点附近，涨落关联长度发散，平均场失效——这就是临界区。**朗道理论在临界区之外定量正确，在临界点定性错误（指数错、普适类错）**。区分「朗道区」与「临界区」是相变学习的第一道坎。<span class="marginnote">直观理解涨落为何致命：<strong>$T_c$ 处比热发散，说明系统在临界点「太敏感」，任何局部波动都被放大到全系统</strong>。关联长度 $\xi \to \infty$，平均场（假设关联很短）自然崩盘。下一节的威尔逊重整化群，就是为收拾这个烂摊子而生的。</span>

## 5 对称性破缺与更广的应用

朗道框架的应用远超磁性：

- **超导/超流**：序参量是复的 $\Delta = |\Delta|e^{i\theta}$，对称性是 U(1) 相位。破缺 U(1) 给出零电阻、磁通量子化（上一节）。
- **结构相变**：声子软模——某个声子频率在 $T_c$ 处软化到零，位移冻结成新结构。
- **液晶**：取向序参量是张量，其本征值变化驱动各向同性-向列相变。
- **向粒子物理的延伸**：希格斯机制就是「规范对称性自发破缺」——质量从「没有」到「有」，与磁化从零到非零同构。**对称性破缺是贯穿凝聚态与粒子物理的公共语言**。

**辨析｜易错点：**「二级相变点序参量连续到零」——对，但**注意序参量的涨落**：临界点处涨落发散，序参量的平均值虽然趋于零，局部却剧烈起伏。因此「临界点是序参量精确为零的干净状态」是错误的——它是「平均为零但涨落无穷大」的临界态。<span class="marginnote">这也解释了一个常见的现象学困惑：<strong>为什么铁在 $T_C$ 附近磁化看起来「消失得很快」？</strong> 因为真实系统有杂质、不均匀、临界点移动，宏观测量被抹平。纯净系统的临界行为，必须用「涨落」而非「平均」来描述——这是从平均场走向现代临界理论的必经之路。</span>

### 算例：朗道自由能的数值极小

设 $a_0 = 1$（J·K⁻¹·m⁻³），$b = 1$（J·m⁻³），$T_c = 100$ K。
在 $T = 80$ K（$T < T_c$）：

$$F(\eta) = F_0 + \frac12(1)(80-100)\eta^2 + \frac14(1)\eta^4 = F_0 - 10\eta^2 + 0.25\eta^4$$

令 $\partial F/\partial\eta = -20\eta + \eta^3 = 0$，得 $\eta = 0$（极大，不稳定）或 $\eta = \pm\sqrt{20} \approx \pm4.47$（两个对称极小）。
代入：

$$F(\pm4.47) = F_0 - 10 \times 20 + 0.25 \times 400 = F_0 - 200 + 100 = F_0 - 100$$

**有序相的自由能比无序相低 100（相对单位）**——这就是自发对称破缺：系统「选择」$\eta = +4.47$ 或 $-4.47$ 之一，两个选择物理等价（对称），但任一选择都破缺了「$\eta \to -\eta$」的对称性。**「对称的方程，非对称的解」**——对称性破缺的精确写照。

## 6 小结

- 相变分**一级**（潜热、两相共存、序参量跳跃）与**二级**（连续相变、比热发散、无潜热）。
- **序参量**从零连续增长，其对称性决定相变类型；铁磁 $\vec{M}$、超导 $\Delta$、液晶张量都是序参量。
- **朗道自由能** $F = F_0 + \frac12 a_0(T-T_c)\eta^2 + \frac14 b\eta^4$，偶次项由对称性强制。
- 极小条件给出 $\eta \propto (T_c-T)^{1/2}$，临界指数 $\beta = 1/2$（平均场）。
- 朗道理论忽略涨落，临界区失效——为重整化群与普适类铺路。
