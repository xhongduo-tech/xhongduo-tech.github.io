# 顺磁与铁磁

<div class="epigraph">

## 为什么从顺磁与铁磁开始

上一节的原子磁矩是「自由」的：给它加磁场，它偏向场方向（顺磁）；
撤掉磁场，热运动把它打乱（消磁）。
但铁不是这样——**铁在零外场下也有自发磁化**，且撤掉外场依然带磁。
磁矩之间必然存在某种「隐形的手」让它们自发对齐。
找到这只手，就是本节的主题：**交换作用**。<span class="marginnote">顺磁与铁磁的分水岭：顺磁的磁矩之间没有强关联（$\chi \propto 1/T$，撤场即乱）；
铁磁的磁矩之间有<strong>交换耦合</strong>（$T < T_C$ 自发有序）。
同一批原子，为什么有的顺磁有的铁磁？
——答案全在电子云的重叠方式里，也就是量子力学的交换能。</span>

## 1 顺磁：居里定律与泡利顺磁

### 局域磁矩：居里定律

上一节的朗之万/布里渊函数，在高温弱场极限给出：

$$\chi = \frac{n\mu_0\mu^2}{3k_BT} = \frac{C}{T}, \qquad C = \frac{n\mu_0\mu^2}{3k_B}$$

**居里定律（Curie's law）**：磁化率反比于温度。物理：温度高，热涨落强，磁矩取向随机；温度低，磁场更容易「说服」磁矩对齐。$C$ 是**居里常数**，由磁矩大小与密度决定。

### 金属电子：泡利顺磁

金属的自由电子没有「局域磁矩」——费米海里的电子能级被填满，泡利原理禁止多数电子翻转自旋。
只有费米面附近 $\sim k_BT$ 的电子能响应外场，得到**泡利顺磁（Pauli paramagnetism）**：

$$\chi_P = \mu_0\mu_B^2\, g(E_F)$$

**关键：泡利顺磁与温度几乎无关**（正比于费米面态密度，而 $g(E_F)$ 随温度变化极小）——这与居里定律的 $1/T$ 截然不同。<span class="marginnote">泡利顺磁是「金属里有电子气」的又一证据：<strong>$\chi_P$ 不随 $1/T$ 变化，说明参与磁化的不是「所有磁矩」，而是费米面附近的一层</strong>。测金属的 $\chi$ 温度无关性 + 电子比热 $\gamma$，两者都正比于 $g(E_F)$，可以交叉验证态密度——这与索末菲模型的预言完全一致。</span>

## 2 交换作用：磁性的隐形之手

磁矩之间为什么自发对齐？
**不是磁偶极相互作用**（太弱，只能解释 $T_C \sim 1$ K，而铁的 $T_C = 1043$ K）。
真正的手是**交换作用（exchange interaction）**——它源于**泡利不相容原理 + 库仑作用**，纯量子效应，没有经典对应。

### 海森堡模型

**海森堡模型（Heisenberg model）** 把自旋之间的交换耦合写成：

$$H_{\text{ex}} = -\sum_{\langle i,j\rangle} J_{ij}\,\vec{S}_i\cdot\vec{S}_j$$

- $J > 0$：自旋平行能量低 → **铁磁**；
- $J < 0$：自旋反平行能量低 → **反铁磁**（下一节）；
- $J$ 由原子间轨道重叠决定，可正可负、可近可远（RKKY 甚至振荡）。

**交换能 $J$ 为什么来自量子力学？** 两个电子（位置 $\mathbf{r}_1, \mathbf{r}_2$）的波函数必须反对称。若自旋平行（三重态），空间波函数反对称——两电子「互相回避」，库仑排斥能低；若自旋反平行（单重态），空间波函数对称——两电子可以靠得很近，库仑排斥能高。**能量差就是 $J$，它把自旋排列与空间波函数绑定**。<span class="marginnote">交换作用一句话：<strong>自旋的排列，通过泡利原理，决定了电子的空间分布，从而决定库仑能</strong>。平行自旋「强迫」电子分开 → 省库仑能 → 铁磁。这不是磁力，是「量子统计 + 静电」的合谋——所以 $J$ 可以比磁偶极作用大几千倍，解释 $T_C$ 的千开尔文量级。</span>

## 3 铁磁：外斯分子场理论

1907 年**外斯（Weiss）**提出**分子场理论（molecular field theory）**：每个磁矩感受到的，除了外场 $B$，还有一个来自邻居的**分子场** $B_{\text{mf}} = \lambda M$（正比于磁化强度）。
于是有效场：

$$B_{\text{eff}} = B + \lambda M$$

用布里渊函数 $B_J(x)$ 做自洽求解：$\frac{M}{M_0} = B_J\left(\frac{\mu_0\mu(g_J J)(B + \lambda M)}{k_BT}\right)$。

### 自发磁化与居里温度

当 $B = 0$，若 $\lambda$ 足够大、$T$ 足够低，方程存在**非零解 $M \neq 0$**——磁矩自发对齐，无需外场。
临界温度：

$$T_C = \frac{n\mu_0\mu^2\lambda}{3k_B}$$

**居里温度（Curie temperature）$T_C$**：铁磁序存在的上限。$T > T_C$ 时铁磁序瓦解，材料退化为顺磁；$T < T_C$ 时自发磁化 $M_s(T)$ 随温度下降而增大，$T = 0$ 时饱和。

### 居里-外斯定律

在 $T > T_C$ 的顺磁区，分子场修正居里定律：

$$\chi = \frac{C}{T - T_C}$$

**居里-外斯定律（Curie–Weiss law）**：磁化率在 $T_C$ 处发散——**实验上画 $1/\chi$ 对 $T$，直线的截距就是 $T_C$**，这是测定铁磁-顺磁转变的标准手段。<span class="marginnote">分子场理论的威力与局限：<strong>它正确预言了 $T_C$ 的存在与居里-外斯定律</strong>，却无法算出 $\lambda$（交换作用的强度）——那要靠量子交换理论。分子场是「平均场」：每个磁矩看到的邻居被平均成均匀场，忽略了涨落。平均场在相变点附近总是高估有序性，这是「二级相变与序参量」一节要修的主题。</span>

## 4 公式解析：居里温度与外斯分子场

$$T_C = \frac{n\mu_0\mu^2\lambda}{3k_B}, \qquad \chi = \frac{C}{T - T_C}$$

- **第一步，分子场**：$B_{\text{eff}} = \lambda M$，$\lambda$ 度量邻居对单个磁矩的作用强度。
- **第二步，居里定律改写**：$M = \frac{C}{T}(B + \lambda M)$（高温顺磁近似 $M = \chi B$）。
- **第三步，自洽**：整理得 $M\left(1 - \frac{C\lambda}{T}\right) = \frac{C}{T}B$，即 $M = \frac{C/T}{1 - C\lambda/T}B$。
- **第四步，读出 $T_C$**：分母 $1 - C\lambda/T$ 在 $T = C\lambda$ 处为零——磁化率发散，这就是 $T_C = C\lambda$。代入 $C = n\mu_0\mu^2/(3k_B)$ 得公式。**$T_C$ 正比于交换强度 $\lambda$ 与磁矩平方**——交换越强、磁矩越大，铁磁越耐高温。

## 5 磁畴与磁滞

铁磁体宏观上可以是「无磁」的（如没磁化的铁钉），因为自发磁化分成了许多**磁畴（domain）**——每个畴内磁矩对齐，但各畴取向不同，净磁化抵消。

**磁畴为何存在？** 交换能偏好整齐排列，但整体排列会产生大的退磁场能（静磁能）。把磁体分成反平行或闭合的畴，退磁能降低——**能量最小化在「整齐」与「无退磁场」之间妥协**，畴结构就是妥协的产物。畴壁（domain wall）处磁矩缓慢转向，宽约几十到几百纳米。

**磁滞回线**：外场扫一圈，$M(B)$ 画出的回线。矫顽力 $H_c$ 决定材料是软磁（$H_c$ 小，易磁化去磁，做变压器铁芯）还是硬磁（$H_c$ 大，保持磁化，做永磁体、磁存储）。<span class="marginnote">磁畴是「多尺度物理」的典范：<strong>量子交换决定单畴内整齐，静磁能决定畴壁结构，缺陷钉扎决定矫顽力</strong>——一个宏观回线，层层叠着微观机制。硬盘存储的原理就是：用写头把磁畴方向翻转，用读头感知畴壁位置。信息就住在磁畴里。</span>

**辨析｜易错点：**①「铁磁体没有外磁场也会自己带磁」——对，但宏观未磁化的铁磁体**净磁化为零**（畴抵消），只有施加外场磁化后才显示宏观磁性。②「$T_C$ 是磁矩消失的温度」——错，$T_C$ 以上磁矩依然存在（顺磁），消失的是**磁矩之间的长程有序**。③ 居里-外斯定律只在 $T \gg T_C$ 精确，靠近 $T_C$ 时涨落效应显著、$1/\chi$ 曲线偏离直线——这是临界现象（后面一节）的领域。

### 算例：从居里温度估交换强度

铁的居里温度 $T_C = 1043$ K。
用分子场 $T_C = C\lambda$ 反推分子场强度：$\lambda = T_C/C$。
若每个原子磁矩约 2.2 $\mu_B$，密度 $n \approx 8.5\times10^{28}$ m⁻³：

$$\lambda \approx \frac{3 k_B T_C}{n\mu_0\mu^2} \approx \frac{3\times1.38\times10^{-23}\times1043}{8.5\times10^{28}\times1.26\times10^{-6}\times(2.04\times10^{-23})^2} \approx 10^3$$

**分子场 $B_{mf} = \lambda M \sim 10^3$ T！** 这是个惊人的数字——铁里的「隐形磁力」等效于上千特斯拉的外磁场，远超任何实验室能造的静磁场（约 45 T）。

**为什么这么强？** 因为交换作用来自泡利原理 + 库仑作用，能量尺度是电子伏特级，比磁偶极相互作用（微电子伏特级）强几千倍。**分子场理论用「一个巨大的等效场」换掉了复杂的多体问题**——粗糙但犀利。

## 6 小结

- **顺磁**：局域磁矩居里定律 $\chi = C/T$；金属电子泡利顺磁 $\chi_P = \mu_0\mu_B^2 g(E_F)$ 与温度无关。
- **交换作用** $H = -J\sum\vec{S}_i\cdot\vec{S}_j$：泡利原理 + 库仑作用，$J>0$ 铁磁、$J<0$ 反铁磁。
- **外斯分子场** $B_{\text{mf}} = \lambda M$ 给出自发磁化与居里温度 $T_C = n\mu_0\mu^2\lambda/(3k_B)$。
- **居里-外斯定律** $\chi = C/(T - T_C)$：$1/\chi$ 直线截距就是 $T_C$。
- **磁畴与磁滞**：能量最小化产生畴结构；矫顽力区分软磁/硬磁。
