## 为什么从衍射开始

晶体结构是原子尺度的秘密，原子间距约 1–3 Å，远小于可见光波长（约 5000 Å）——普通显微镜根本看不见。
唯一能「看见」原子的探针，是波长同样在 Å 量级的 X 射线。
1912 年劳厄用 X 射线照射晶体得到衍射斑点，直接证明了晶体是周期结构；
此后百年，**衍射一直是测定晶体结构的标准手段**。
DNA 双螺旋、石墨烯、蛋白质结构，无一不是靠衍射读出来的。<span class="marginnote">衍射的物理实质：<strong>周期结构与波相互作用时，某些方向上散射同相叠加（相长干涉），形成强反射峰</strong>。
这与你把激光照在 CD 光盘上看到彩虹斑点同源——CD 的坑道间距约 1.6 μm，正是可见光的「晶面」。</span>

## 1 布拉格定律：把衍射当反射

布拉格父子把衍射简化成一种「反射」：晶面族 $(hkl)$ 如同一面面平行的镜子，相邻晶面的反射光因路程差产生干涉。

**布拉格定律（Bragg's law）**：

$$2d \sin\theta = n\lambda$$

- $d$：晶面间距；
- $\theta$：掠射角（入射光与晶面的夹角）；
- $n$：正整数（反射级数）；
- $\lambda$：X 射线波长。

**推导**：两条平行光线分别被相邻晶面（间距 $d$）反射，光程差为 $2d\sin\theta$。当光程差等于波长的整数倍 $n\lambda$ 时，两束反射光同相叠加，出现强度极大。<span class="marginnote">注意 $\theta$ 是<strong>掠射角</strong>而非入射角——与镜面反射的记号相反。很多初学者把 $\theta$ 当入射角代入，得到离谱的 $d$ 值。这是 X 射线衍射中最常见的错误。</span>

布拉格定律等价于倒空间的劳厄条件——它们是同一物理事实的两种写法。

## 2 劳厄条件：动量守恒的表述

设入射波矢 $\vec{k}$、散射波矢 $\vec{k}'$（弹性散射，$|\vec{k}'| = |\vec{k}| = 2\pi/\lambda$）。
衍射极大条件为：

$$\vec{k}' - \vec{k} = \vec{G}$$

其中 $\vec{G}$ 是某个倒格矢。
这个式子就是**劳厄条件（Laue condition）**。

**为什么必然是这样？** 每个原胞散射的振幅正比于 $e^{i(\vec{k}' - \vec{k}) \cdot \vec{R}_n}$，其中 $\vec{R}_n$ 是格点位置。总散射振幅对所有格点求和：

$$\sum_{\vec{R}_n} e^{i\Delta\vec{k} \cdot \vec{R}_n} = \sum_{n_1,n_2,n_3} e^{i\Delta\vec{k} \cdot (n_1\vec{a}_1 + n_2\vec{a}_2 + n_3\vec{a}_3)}$$

当 $\Delta\vec{k} = \vec{k}' - \vec{k}$ 等于倒格矢 $\vec{G}$ 时，每一项的相位 $e^{i\vec{G}\cdot\vec{R}_n} = e^{i 2\pi \times \text{整数}} = 1$，**所有散射完全同相**，振幅如 $N$ 个原子相叠加——这是巨大衍射峰；
否则各原胞相位随机，互相抵消。<span class="marginnote">这是<strong>相长干涉 = 相位都取 1</strong>的经典判据。
它与调频广播阵列、相控阵雷达、甚至大模型注意力中的相位对齐同构：<strong>让所有「发声单元」步调一致，信号就被放大 N 倍</strong>。</span>

把布拉格定律与劳厄条件挂钩：$|\Delta\vec{k}| = 2|\vec{k}|\sin\theta = 2(2\pi/\lambda)\sin\theta = |\vec{G}| = 2\pi/d$，即得 $2d\sin\theta = \lambda$（$n=1$）。

## 3 结构因子：为什么有些峰消失了

劳厄条件只说了「哪些方向有衍射」，没说「有多强」。
强度由**结构因子（structure factor）**决定：

$$S_{\vec{G}} = \sum_{j} f_j(\vec{G})\, e^{i\vec{G}\cdot\vec{r}_j}$$

其中 $\vec{r}_j$ 是原胞内第 $j$ 个原子的位置，$f_j$ 是它的原子散射因子。
原胞内原子的**相对相位**决定峰强。

**辨析｜易错点：系统消光**。当原胞含多个原子时，某些满足劳厄条件的衍射峰可能**完全消失**，这称为系统消光（systematic absences）。经典例子是体心立方（BCC）：

$$\vec{r}_1 = 0, \quad \vec{r}_2 = \tfrac{1}{2}(\vec{a}_1 + \vec{a}_2 + \vec{a}_3)$$

对 $\vec{G} = h\vec{b}_1 + k\vec{b}_2 + l\vec{b}_3$：

$$S_{\vec{G}} = f\left[1 + e^{i\pi(h+k+l)}\right]$$

当 $h+k+l$ 为奇数时，$e^{i\pi(h+k+l)} = -1$，$S_{\vec{G}} = 0$——**这个峰消失了**。
所以 BCC 的衍射图只出现 $h+k+l$ 为偶数的峰。<span class="marginnote">从晶体结构（1 与 3 的坐标）能直接预言哪些峰消失，反过来，<strong>观察哪些峰消失就能反推原胞内容</strong>——这是结构测定中最有力的推理。
中心原子的存在「抹掉」了一半衍射峰，衍射图的「空位」同样是信息。</span>

## 4 公式解析：布拉格定律的完整推导

$$2d\sin\theta = n\lambda$$

- **第一步，画光程**：平行入射束中两条光分别打到间距 $d$ 的相邻晶面上，被「镜面反射」。两条反射线汇聚到探测器。
- **第二步，求路程差**：入射时，靠下晶面的光线多走 $d\sin\theta$；反射时，又同样多走 $d\sin\theta$。总光程差 $= 2d\sin\theta$。
- **第三步，干涉判据**：相长干涉要求光程差是波长整数倍：$2d\sin\theta = n\lambda$。由于 $d$ 与 $\lambda$ 同量级（$d \sim 1$ Å，$\lambda \sim 1$ Å），$n \le 2$，所以一级反射 $\sin\theta \approx \lambda/2d$ 处出现第一个峰，实验上 $\theta$ 通常只有几度到几十度。
- **第四步，反过来用**：测出峰位 $\theta$，已知 $\lambda$，立即得到晶面间距 $d$。对不同 $n$ 的峰依次求解，就能还原整套晶面族的间距，从而还原点阵常数——**这就是结构测定的第一步**。

## 5 三类衍射实验

| 方法 | 几何安排 | 探测器信息 | 适用 |
| --- | --- | --- | --- |
| 劳厄法 | 固定单晶 + 连续谱 X 射线 | 每个倒格点取一个斑点 | 晶体的定向与对称性判定 |
| 转动晶体法 | 单晶绕轴转动 + 单色 X 射线 | 层线图，倒格点逐点进入反射条件 | 精确测定晶胞参数 |
| 粉末法（德拜-谢勒） | 多晶粉末 + 单色 X 射线 | 同心圆环（每环 = 一族晶面） | 物相鉴定、点阵常数测定 |

粉末法最有工程价值：样品无需长成单晶，研磨成粉末即可。
粉末中所有取向的微晶同时满足反射条件，无数晶粒的衍射锥在胶片上形成同心圆环——每一环对应一族 $(hkl)$ 晶面。
通过环的位置与强度，与标准 PDF 卡片比对，几秒内就能识别材料物相，这是 X 射线衍射（XRD）在材料科学、制药、刑侦中的日常用法。

**辨析｜易错点：**粉末法测的是 $d$ 与强度，**不是直接的位置坐标**。从衍射强度反推原子坐标需要傅里叶合成与相位问题（相位是衍射实验看不见的），这是晶体学「相位难题」，X 射线结晶学的历史就是一部围绕相位展开的博弈——直到蛋白质结构测定用了同晶置换、分子置换等手段绕过它。<span class="marginnote">衍射只能给出强度的平方 $|S_{\vec{G}}|^2$，<strong>相位信息丢失</strong>。这是所有「由散射反推结构」问题的共同困难，也出现在电子衍射、中子衍射甚至 X 射线自由电子激光里。相位难题是结构生物学的核心难题之一。</span>

### 算例：用布拉格定律测晶面间距

用波长 $\lambda = 1.54$ Å 的铜靶 X 射线照射铝粉，测得一级衍射峰在 $\theta = 19.2°$（这是 FCC 铝的 $(200)$ 面）。
由布拉格定律：

$$d_{200} = \frac{\lambda}{2\sin\theta} = \frac{1.54}{2\sin 19.2°} \approx \frac{1.54}{2 \times 0.329} \approx 2.34\ \text{Å}$$

**反过来定晶格常数**：对 FCC，$d_{hkl} = a/\sqrt{h^2+k^2+l^2}$，故：

$$a = d_{200}\sqrt{2^2+0+0} = 2.34 \times 2 = 4.68\ \text{Å}$$

**与铝的公认晶格常数 4.05 Å 接近**（误差来自把一级峰当 $(200)$ 的简化）。这个「峰位 → 间距 → 晶格常数」的三步链，就是 XRD 物相鉴定的全部原理：每个峰对应一族晶面，峰位定间距，间距组合定晶格，与标准卡片比对定物相。

## 6 小结

- **布拉格定律** $2d\sin\theta = n\lambda$：衍射 = 晶面对波的镜面反射 + 干涉。
- **劳厄条件** $\vec{k}' - \vec{k} = \vec{G}$：衍射极大 = 倒空间动量守恒；两者等价。
- **结构因子** $S_{\vec{G}} = \sum_j f_j e^{i\vec{G}\cdot\vec{r}_j}$ 决定峰强；原胞内原子相位抵消导致**系统消光**。
- 三类实验：**劳厄法**（单晶定向）、**转动法**（精测晶胞）、**粉末法**（物相鉴定）。
- 衍射测强度、丢相位；相位难题贯穿结构测定全程。

在下一节，我们暂时离开实验，问一个能量学的问题：原子凭什么愿意聚在一起形成晶体？
——这就是**晶体的结合与内能**。
