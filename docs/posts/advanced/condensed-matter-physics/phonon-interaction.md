## 为什么从声子相互作用开始

简谐近似让每个声子模式**完全独立**：声子谱像一盒互不说话的玻色子。
但真实固体里声子会**碰撞、分裂、融合**——这些相互作用全部来自势能的**非简谐项**。
别小看这些「修正项」，它们是许多最重要物理的起源：热阻（上一节）、热膨胀、声子寿命，以及**超导中的电-声耦合**。<span class="marginnote">把话说透：<strong>简谐近似解释了「固体为什么像固体」，非简谐项解释了「固体为什么不是理想气体」</strong>——没有声子相互作用，热导率无穷大、没有热平衡、金属也不会在低温下配对成超导。
本节的声子相互作用，是通往 BCS 超导理论的必经之路。</span>

## 1 非简谐势与相互作用哈密顿量

把势能展开到三阶、四阶：

$$U = \frac{1}{2}\sum \Phi_{ij} u_i u_j + \frac{1}{3!}\sum \Phi_{ijk} u_i u_j u_k + \frac{1}{4!}\sum \Phi_{ijkl} u_i u_j u_k u_l + \cdots$$

- 二阶项：简谐近似，声子独立。
- 三阶项：**三声子过程**——一个声子分裂成两个，或两个合并成一个。
- 四阶项：四声子过程（双声子散射），以及三声子过程的有限温度修正。

写成产生湮灭算符，三阶项形如 $c^\dagger c^\dagger c + c^\dagger c c + \text{h.c.}$：两个产生一个湮灭（合并）或一个产生两个湮灭（分裂）。<span class="marginnote">声子相互作用在语言上完全可以类比粒子物理：三阶项 = 「三声子顶点」，能量守恒与动量守恒（准动量）在顶点处成立。
<strong>把固体当粒子物理来读，是理解许多凝聚态现象的捷径</strong>——声子、磁振子、激子都按同一套费曼图规则相互作用。</span>

## 2 三声子过程与选择定则

考虑一个声子（$q_1, \omega_1$）与另一个（$q_2, \omega_2$）合并成（$q_3, \omega_3$）。
要求：

- **能量守恒**：$\hbar\omega_1 + \hbar\omega_2 = \hbar\omega_3$；
- **准动量守恒**：$q_1 + q_2 = q_3$（N 过程）或 $q_1 + q_2 = q_3 + \mathbf{G}$（U 过程）。

### N 过程 vs U 过程

- **正常过程（Normal process, N）**：$\mathbf{q}_1 + \mathbf{q}_2 = \mathbf{q}_3$ 落在第一布里渊区内。声子动量在声子气内部重新分配，**总晶格动量守恒**，声子气保持无阻尼流动——不产生热阻、不改变声子漂移。
- **倒逆过程（Umklapp process, U）**：$\mathbf{q}_1 + \mathbf{q}_2 = \mathbf{q}_3 + \mathbf{G}$。**声子动量的一部分交给整个晶格（倒格矢 $\mathbf{G}$）**，相当于「刹车」——把定向声子流打散为随机热运动，这是**本征热阻的唯一来源**。

**辨析｜易错点：**U 过程并不违反动量守恒，而是把「多余动量」交给晶格整体。晶格平移对称性只保证声子动量模 $\mathbf{G}$ 守恒（准动量），N 过程保持准动量，U 过程改变它——**只有 U 过程让声子真正「失去方向」**。判断一个过程是 N 还是 U，画倒空间图最直观：合并后的 $\mathbf{q}_3$ 若越出第一布里渊区，就折回区内的等价点并差一个 $\mathbf{G}$——这就是 U。<span class="marginnote">回忆「倒格子与布里渊区」：所有物理波矢都折回第一布里渊区。<strong>U 过程 = 声子动量越界 + 折叠</strong>。折叠后产生的「额外 $\mathbf{G}$」被晶格吸收，成为热阻的微观来源。这也解释了为什么高温下 $\kappa \propto 1/T$：温度越高声子动量越容易越界，U 过程越频繁。</span>

## 3 声子-电子相互作用

声子不止与声子碰撞，还强烈影响电子。
**电-声耦合（electron-phonon coupling）** 有两种重要表现：

- **电子被声子散射**：电子吸收或发射声子，改变动量与能量。这是金属电阻的主要来源——**为什么金属越热电阻越大**：声子数 $\propto T$，电子被声子散射的概率随之增大，电导下降。
- **声子调制的势**：离子实随声子振动，改变了电子感受到的周期势，从而「调制」电子能量。这种动态势就是电-声相互作用哈密顿量的核心。

在相互作用图像里，电子发射一个虚声子，再被第二个电子吸收——**交换虚声子**在电子间产生一个**吸引的有效相互作用**：

$$V_{\text{eff}}(\omega) \sim \frac{|g_{\mathbf{q}}|^2 \, \hbar\omega_{\mathbf{q}}}{\omega^2 - \omega_{\mathbf{q}}^2}$$

当两个电子能量差小于 $\hbar\omega_{\mathbf{q}}$（$\omega \to 0$），$V_{\text{eff}} < 0$——**声子介导的吸引**。
这正是 BCS 超导的种子：费米面附近的电子通过交换声子配对，克服库仑排斥。<span class="marginnote">这段吸引是理解超导的钥匙：<strong>在时间反演对（动量 $+p$ 与 $-p$）的两个电子之间交换虚声子，会获得净吸引</strong>。
虽然单个电子-声子作用远弱于库仑排斥，但配对机制有「合作增强」——这在「BCS 理论」一节会完整展开。
现在只需记住：声子不仅是热载体，还是<strong>力的传递者</strong>。</span>

## 4 公式解析：三声子散射率（费米黄金规则）

非简谐项给声子带来有限寿命。
把三阶势当作微扰，用**费米黄金规则（Fermi's golden rule）**求跃迁率：

$$\Gamma = \frac{2\pi}{\hbar} \left|M_{fi}\right|^2 \delta(E_f - E_i) \times (\text{相空间因子})$$

以「1 个声子分裂成 2 个」为例：

- **第一步，写初末态**：初态一个声子 $(q,\omega)$，末态两个声子 $(q_1,\omega_1)$ 与 $(q_2,\omega_2)$。能量守恒要求 $\hbar\omega = \hbar\omega_1 + \hbar\omega_2$。
- **第二步，矩阵元**：三阶项 $\Phi_{ijk}u_i u_j u_k$ 对应 $\langle 1_{q_1}, 1_{q_2}| H_3 |1_q\rangle \propto \sqrt{n_q}\sqrt{n_1+1}\sqrt{n_2+1}\cdot \mathcal{M}$，其中 $n_q$ 是初态占据数，$n_1+1$ 来自「产生声子」的玻色子增强因子。
- **第三步，相空间求和**：对所有满足守恒律的 $q_1, q_2$ 求和。散射率正比于初态占据数 $n_q$——**声子越多，散射越快**，这就是为什么高温下声子寿命短、热阻大。
- **第四步，寿命与线宽**：$\tau = 1/\Gamma$。有限寿命把声子频率展宽成洛伦兹峰，半高宽 $\Delta\omega \sim \Gamma$——**测非弹性散射峰宽，就测到了声子寿命**。

## 5 声子寿命的实验观测量

声子相互作用最直接的证据来自实验：

- **热导率温度依赖**（上一节）：高温 $\kappa \propto 1/T$，定量反映 U 过程散射。
- **非弹性中子/X 射线散射线宽**：峰的展宽给出声子寿命与散射率，可直接与理论 $\Gamma$ 比较。
- **拉曼光谱线宽**：光学声子的寿命决定拉曼峰宽度。
- **热脉冲（声子回波）**：极低温下注入相干声子，测量其衰减——直接测声子平均自由程。
- **超导转变温度**：$T_c$ 的依赖关系（同位素效应）反证电-声耦合强度。

**辨析｜易错点：**「声子寿命越短，热导率越低」正确，但**声子寿命短 ≠ 声子不存在**——寿命短只是说它是「衰减模式」（quasiparticle 有有限宽度），只要宽度 $\ll$ 能量，准粒子图像仍有效。只有当非简谐极强（如软声子、近相变点），声子概念本身才失效——此时要退回到「局域振动 + 液体样行为」的图像。

### 算例：一个具体的 U 过程

一维单原子链，第一布里渊区 $[-\pi/a, \pi/a]$。
设两个声子 $q_1 = 3\pi/4a$ 与 $q_2 = 3\pi/4a$ 合并，名义和 $q_1 + q_2 = 3\pi/2a$ **超出边界 $\pi/a$**——物理波矢必须折回：

$$q_3 = \frac{3\pi}{2a} - \frac{2\pi}{a} = -\frac{\pi}{2a}$$

**折回时差出一个倒格矢 $G = 2\pi/a$**——这就是 U 过程。若两个声子都能动起来（高温），这类「越界 + 折回」的事件频繁发生，动量不断被交给晶格，热流被打散。

**对比 N 过程**：$q_1 = \pi/3a$ 与 $q_2 = \pi/4a$ 合并得 $q_3 = 7\pi/12a$（仍在区内）——正常过程，动量在声子气内部重新分配，不产热阻。

**一个算例就分清 N 与 U**：看「合并后的波矢落在区内还是区外」。落在区内是 N，落在区外折回是 U。**U 过程的频率随温度升高而爆炸性增长，这正是高温热阻 $1/T$ 的来源**。

### 算例：声子寿命的数量级

声子寿命 $\tau = 1/\Gamma$，由三声子散射率决定。室温下典型晶体声子 $\tau \sim 1$ ps（$10^{-12}$ s），对应平均自由程：

$$\ell = v_s \tau \approx 5000\ \text{m/s} \times 10^{-12}\ \text{s} = 5\ \text{nm}$$

**平均自由程只有 5 nm，约 15 个原子间距**——室温下声子「撞来撞去」，走不了多远。这就是为什么室温固体热导率有限。

**降温到液氮（77 K）**：声子数剧减（玻色分布 $n_B \propto e^{-\hbar\omega/k_BT}$），三声子散射率下降，$\tau$ 可能到 100 ps，$\ell$ 达 500 nm——热导率随之上升。**测热导率的温度依赖，就是在「滴定」声子散射率**。

**对比电子**：金属室温电子 $\tau \sim 10^{-14}$ s、$\ell \sim 100$ Å。声子的 $\ell$ 与电子的 $\ell$ 一起决定了「热导率/电导率比」（维德曼-弗朗兹定律的微观内容）。

## 6 小结

- 声子相互作用来自**非简谐项**：三阶项给三声子过程、四阶项给四声子过程。
- **三声子过程**满足能量与准动量守恒；N 过程保准动量、U 过程把动量交给晶格（倒格矢 $\mathbf{G}$）。
- **U 过程是高温热阻的唯一本征来源**，$\kappa \propto 1/T$ 由此而来。
- **电-声耦合**：声子散射电子造成金属电阻；交换虚声子在电子间产生**吸引**，是超导配对的种子。
- 费米黄金规则给出声子寿命 $\tau = 1/\Gamma$；散射线宽可被实验直接测量。

在下一节，我们离开晶格振动，进入第三篇「电子论与能带」——从最简单的**自由电子气与索末菲模型**开始，认识金属中的电子海。
