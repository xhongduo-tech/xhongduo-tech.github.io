## 为什么从光敏化与猝灭开始

前几节都在讲单个分子：吸收、
发光、
电子转移。
但光化学的绝大多数实际应用——光动力疗法、
光固化、
光催化制氢、
OLED 敏化——都依赖**两个分子之间的能量/电子接力**。
其中真正的主角是**光敏化（photosensitization）**：一个分子（敏化剂，
sens 或 D）吸光后，
不自己反应，
而是把激发能转交给旁观分子（底物，
A），
由后者去反应。

敏化的反面是**猝灭（quenching）**：激发态的能量被别的分子「抽走」，
发光变暗、
反应停摆。
猝灭在应用上往往是坏事（荧光探针被污染猝灭），
但也是**最强大的动力学探针**——Stern-Volmer 分析用一次简单的荧光滴定，
就能测出激发态寿命与双分子速率常数，
这是分子光化学最重要的定量实验之一。
<span class="marginnote">光动力疗法（PDT）是最直观的敏化应用：敏化剂（卟啉类）进肿瘤后光照，敏化生成单线态氧 $\ce{^1O2}$ 杀灭癌细胞——敏化剂不直接损伤组织，它只负责「把光变成毒」。
</span>

## 1 两种接力：能量转移与电子转移

双分子接力有两大类，
先分清：**能量转移（energy transfer）** 转交的是「激发能」，
**电子转移（electron transfer）** 转交的是「电子」。
二者产物不同、
判据不同：

**能量转移**：$\ce{^3D^* + A -> D + ^3A^*}$，要求敏化剂激发态能量 $E_T(\ce{D})$ ≥ 底物激发态能量 $E_T(\ce{A})$——能量只能从高往低流，这是**光谱重叠判据**的实质。
- **电子转移**：$\ce{^3D^* + A -> D^{\cdot+} + A^{\cdot-}}$，判据是 Rehm-Weller 自由能（上一节），转交的是电荷而非能量。

**辨析｜易错点：** 能量转移不产生自由基离子，
电子转移必然产生自由基离子。
二者常被混淆，
因为「都让激发态变暗」。
区分实验很简单：用能带阻隔——当敏化剂被激发而底物自身不吸光，
若底物出现了**激发态光谱**（如敏化三线态吸收）则是能量转移；
若出现**自由基离子吸收**则是电子转移。
<span class="marginnote">能量转移还有两种机制：Dexter（短程，需轨道重叠，电子交换）与 Förster（长程，偶极-偶极，靠光谱重叠）。
Förster 是 FRET 生物探针的物理基础，
第四级《生物成像》会专门展开。
</span>

## 2 三重态敏化：让「长命客」干活

上一节我们强调三重态是溶液光化学的主力，
敏化正是把这一点用足。
典型流程：

$$\ce{Sens ->[h\nu] ^1Sens* ->[ISC] ^3Sens* ->[ET] Sens + ^3A* ->[反应] 产物}$$

其中关键一步是 $\ce{^3Sens^*}$ 把能量交给 $A$，
得到 $A$ 的三重态——**底物甚至不需要自己吸光**。
经典敏化剂：二苯甲酮（羰基 nπ\*，
ISC 极快）、
亚甲基蓝（红光激发、
高效产单线态氧）、
钌/铱配合物（金属-配体电荷转移态，
寿命长）。

**重点：敏化剂的选择准则是「三重态能量高、寿命长、ISC 量子产率高」，三缺一不可。** 三重态能量够高才能给底物（能量判据），
寿命够长才有时间完成碰撞（扩散时间 ~ns 尺度），
ISC 产率高才把能量囤积在 $T_1$。
<span class="marginnote">三重态-三重态能量转移的效率由 Dexter 机制主导，要求给受体轨道重叠——所以长程（>1 nm）能量转移几乎全是 Förster 单重态通道，三线态转移是「近身肉搏」。
</span>

## 3 公式解析：Stern-Volmer 方程与猝灭测量

猝灭的定量核心是 **Stern-Volmer 方程**。
若底物 $Q$ 以速率 $k_q$ 猝灭激发态，
激发态寿命从 $\tau_0$ 缩短为 $\tau$：

$$\frac{\Phi_0}{\Phi} = 1 + k_q \tau_0\,[Q]$$

对这条公式做四步拆解：

- **第一步，$\Phi_0/\Phi$ 是发光比**：无猝灭剂时的发光强度除以加入 $[Q]$ 后的强度，动态猝灭下发光强度正比于量子产率。
- **第二步，斜率 $K_{SV} = k_q \tau_0$**：对 $[Q]$ 作图，斜率就是 Stern-Volmer 常数，单位 $\mathrm{M^{-1}}$。
- **第三步，$\tau_0$ 独立测**：时间分辨荧光测出无猝灭剂时的寿命。
- **第四步，解出 $k_q$**：$k_q = K_{SV}/\tau_0$。若 $k_q$ 接近扩散极限（$10^9$–$10^{10}\ \mathrm{M^{-1}s^{-1}}$），说明每次碰撞都猝灭——激发态「命里犯冲」。

**辨析｜易错点：** Stern-Volmer 的线性图不能证明猝灭是动态的。
**静态猝灭**（基态形成配合物，
$Q$ 提前「绑架」荧光分子）也给出直线 $\Phi_0/\Phi = 1 + K_a[Q]$。
区分办法是**比较寿命与强度**：动态猝灭两者同时缩短（$\tau_0/\tau = \Phi_0/\Phi$），
静态猝灭寿命不变、
只有强度下降。
只看强度曲线，
就会把两种物理混为一谈。
<span class="marginnote">顺带一提，动态猝灭是热力学第二定律的体现：它给能量「多开了一条下水道」，所以发光必然变暗。
这也提醒我们，
猝灭数据永远是「激发态活得短」的证据，
而非「激发态不存在」的证据。
</span>

## 4 能量图解法：Weller 与敏化效率

设计一套敏化体系时，
常用的纸上工具是**能量图**：把敏化剂三重态能量、
底物三重态能量、
电子转移自由能摆在同一张能级图上。
三个判据依次检查：

1. $E_T(\ce{Sens}) \ge E_T(\ce{A})$：能量转移可行。
2. $\Delta G_{ET} < 0$：电子转移可行。
3. 两者竞争时，
**看相对速率**——能量转移走 Dexter 短程、
电子转移可长可短，
实际结果由实验猝灭产物定夺。

这套「先画能量图、
再验判据、
最后测产物」的流程，
是所有光催化、
光敏反应设计的通用方法论：**能量图告诉你「能不能」，Stern-Volmer 告诉你「多快」，产物分析告诉你「走了哪条」**。

## 5 小结

- **光敏化**：敏化剂吸光→ISC→三重态→能量/电子转交底物，底物无需直接吸光。
- **能量转移 vs 电子转移**：前者转能量不产自由基离子，后者转电荷必产自由基离子；判据分别是能量高低与 $\Delta G_{ET}$。
- 敏化剂三准则：**三重态能量高、寿命长、ISC 产率高**。
- **Stern-Volmer 方程** $\Phi_0/\Phi = 1 + k_q\tau_0[Q]$：用一次荧光滴定测出 $k_q$ 与 $\tau_0$。
- **静态 vs 动态猝灭**：动态猝灭寿命与强度同降，静态猝灭只有强度降——必须用 $\tau$ 佐证。
