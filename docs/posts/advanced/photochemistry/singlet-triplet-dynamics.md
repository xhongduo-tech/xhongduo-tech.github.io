# 单重态与三重态动力学

<div class="epigraph">

## 为什么从激发态动力学开始

前几节我们认识了能级和跃迁，
但**能级图是静态的，激发态是动态的**。
分子吸收光子后，
$S_1$、
$T_1$ 的布居（population）随时间涨落，
每种去路按自己的速率抢食，
最终全部衰亡。
这一节把「速率竞争」翻译成**动力学方程**：单重态与三重态各自何时布居最高、
寿命多长、
能持续多久干化学。

为什么值得单开一节？因为光化学里几乎所有「效果」都依赖态的**寿命**：荧光分子要活得够久才好成像，
光敏剂要活得够久才能把能量/电子交给底物，
而三重态往往才是真正的「工作态」——因为 $T_1$ 寿命是 $S_1$ 的上千上万倍，
化学反应有机会在衰亡前完成。
这与「从极限到大模型」主线中概率与动力学的语言天然相接：布居方程就是概率演化，
寿命就是平均停留时间。
<span class="marginnote">第一级《概率》里的马尔可夫链与第二级《常微分方程》的解线性方程组，正是本节速率方程的数学原型——激发态动力学本质上是一组耦合的一阶线性 ODE。
</span>

## 1 激发态的一生：时间轴上的各就各位

一个激发态分子的「一生」按时间尺度排开：

| 事件 | 时间量级 | 说明 |
| --- | --- | --- |
| 吸收 | $10^{-15}$ s | 电子跃迁，核不动 |
| 振动弛豫 | $10^{-13}$–$10^{-11}$ s | 落到 $S_1$ 底部（Kasha） |
| $S_1$ 荧光 | $10^{-9}$–$10^{-7}$ s | 允许，快 |
| 系间窜越 | $10^{-12}$–$10^{-8}$ s | 视 SOC 强弱 |
| $T_1$ 磷光 | $10^{-3}$ s 以上 | 禁阻，极慢 |
| 化学键断裂 | $10^{-13}$–$10^{-12}$ s | 若势能面引导 |

**重点：$S_1$ 是「短命客」，$T_1$ 是「长住客」。** 荧光分子还没来得及做反应就已发光；
而三重态因为发光慢、
去路少，
反而积攒了「作案时间」——绝大多数溶液态光化学反应发生在 $T_1$，
这正是三重态在光化学里地位崇高的原因。
<span class="marginnote">一句话记忆：三重态寿命长 = 三重态化学丰富。
这也是为什么上一节我们反复强调 ISC——能进 $T_1$，
才有后面的能量转移与电子转移反应。
</span>

## 2 布居方程：把竞争写成方程组

设 $n_S(t)$、
$n_T(t)$ 分别为 $S_1$、
$T_1$ 的布居数，
$k_f$、
$k_{nr}$、
$k_{isc}$、
$k_p$、
$k_T^{nr}$、
$k_T^{rxn}$ 为各通道速率，
则动力学由耦合方程描述：

$$\frac{dn_S}{dt} = P(t) - (k_f + k_{nr} + k_{isc})\, n_S, \qquad \frac{dn_T}{dt} = k_{isc}\, n_S - (k_p + k_T^{nr} + k_T^{rxn})\, n_T$$

- **第一条方程**：$S_1$ 的布居来源是泵浦 $P(t)$（光吸收速率），去向是「所有离开 $S_1$ 的通道之和」乘以现有布居——典型的**一级衰减**。
- **第二条方程**：$T_1$ 的来源只有一个——从 $S_1$ 经由 ISC 流入（$k_{isc}n_S$），去向是磷光、三重态无辐射与三重态化学反应之和。
- **两条方程耦合**：因为 $T_1$ 依赖 $S_1$ 的布居，这不是两个独立衰减，而是一个**级联**：$S_1$ 先蓄水，再把水放进 $T_1$。
- **稳态解法**：光持续照射时取 $\dfrac{dn_S}{dt} = 0$，得 $n_S^{ss} = \dfrac{P}{k_f + k_{nr} + k_{isc}}$，代入第二式得到 $T_1$ 的稳态布居——这正是光敏化反应里「持续光照下的有效工作浓度」的来源。<span class="marginnote">对脉冲光（闪光光解）则解瞬态解：$n_S(t) = n_S(0)e^{-(k_f+k_{nr}+k_{isc})t}$，这就是时间分辨荧光寿命的直接表达式。</span>

## 3 脉冲还是连续：两种实验视野

动力学实验分两大流派，
理解它们等于理解「单重态/三重态布居如何被观测」：

**闪光光解（flash photolysis）**：用纳秒甚至飞秒激光脉冲瞬间泵浦，之后用探测光跟随布居衰减。1950 年代 George Porter 正是靠它让三重态「显形」，拿下 1967 年诺贝尔化学奖。<span class="marginnote">闪光光解让「看不见的瞬态物种」有了光谱：吸收变化 $\Delta A$ 直接正比于 $n_T$，于是磷光与三重态吸收的时间曲线成了最常用的动力学探针。</span>
- **稳态光解**：连续光照，测量子产率与产物分布。它给不出中间态的时间信息，却给出「总效率」，与动力学互为补充。

**辨析｜易错点：** 很多人把「三重态寿命」等同于「磷光寿命」。
二者只在「磷光是 $T_1$ 唯一出口」时才相等。
一旦存在三重态反应（$k_T^{rxn}$）或三重态能量转移（猝灭），
$T_1$ 实际寿命 $\tau_T = 1/(k_p + k_T^{nr} + k_T^{rxn} + k_{q}[Q])$ 会**远短于**磷光本征寿命。
测寿命而不考虑淬灭，
就会把「反应/转移」误算成「发光的慢」。

## 4 量子产率与分支比：动力学的「结果层」

把布居方程的稳态解代入，
就得到各级量子产率——它们是动力学的**积分输出**：

$$\Phi_f = \frac{k_f}{k_f + k_{nr} + k_{isc}}, \qquad \Phi_{isc} = \frac{k_{isc}}{k_f + k_{nr} + k_{isc}}, \qquad \Phi_p = \Phi_{isc} \cdot \frac{k_p}{k_p + k_T^{nr} + k_T^{rxn}}$$

- **$\Phi_f$**：$S_1$ 里发光所占的分支比；
- **$\Phi_{isc}$**：$S_1$ 里进 $T_1$ 的分支比；
- **$\Phi_p$**：先「进 $T_1$」再「在 $T_1$ 里发光」，两步相乘。

这套「分支比」语言可以推广到任意竞争：任何去路 $i$ 的量子产率都是 $\Phi_i = k_i/\sum_j k_j$——**分母是 $S_1$（或 $T_1$）全部出口速率之和**。
这与概率论里「按权重分派概率」、
与机器学习里 softmax 归一化的结构完全同构：谁快谁拿得多。

## 5 公式解析：从寿命推速率

实验给的是寿命与产率，
理论要的是速率，
桥梁公式是**总衰变速率等于寿命倒数**：

$$\tau_S^{-1} = k_f + k_{nr} + k_{isc}, \qquad \tau_T^{-1} = k_p + k_T^{nr} + k_T^{rxn}$$

拆解四步：

- **第一步，$\tau_S$ 是 $S_1$ 荧光寿命**：从时间分辨荧光曲线 $I(t) = I_0 e^{-t/\tau_S}$ 拟合得到，是「所有出口合计」的倒数。
- **第二步，$\Phi_f = k_f \tau_S$**：已知 $\tau_S$ 与 $\Phi_f$，立即解得 $k_f$——这是最常用的解耦手段。
- **第三步，$k_{isc} = \Phi_{isc}/\tau_S$**：测三重态产率（或用磷光/敏化产率反推），再得 ISC 速率。
- **第四步，合成**：$\tau_S$、$\Phi_f$、$\Phi_{isc}$ 三个可测量，解出 $k_f$、$k_{nr}$、$k_{isc}$ 三个不可测量。**测两个量、解三个未知数，缺一个方程——所以动力学测量总是成组出现，交叉验证。**

## 6 小结

- 激发态生命周期按时间尺度分层：$S_1$ 短命（ns），$T_1$ 长命（ms 级）——**三重态是溶液光化学的主战场**。
- 布居演化由耦合的一阶 ODE 描述：$S_1$ 出口是 $(k_f + k_{nr} + k_{isc})$，$T_1$ 出口是 $(k_p + k_T^{nr} + k_T^{rxn})$。
- **闪光光解**看瞬态布居（时间分辨），**稳态光解**看总产率（积分结果），两者互补。
- 量子产率是分支比：$\Phi_i = k_i/\sum_j k_j$，与概率归一、softmax 同构。
- 用寿命与产率反推速率：$\tau_S^{-1}$ 是总出口，$\Phi_f = k_f\tau_S$ 解耦 $k_f$；测量必须成组交叉验证。
