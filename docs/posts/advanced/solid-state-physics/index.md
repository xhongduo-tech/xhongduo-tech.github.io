# 固体物理

研究晶体中原子周期性排列及其对电子、声子行为决定性影响的基础学科，是凝聚态物理的入门与基石。学通固体物理，就打通了从「电子、原子如何排布」到「材料的导电、导热、磁性、光学性质从何而来」的整条物理主线，中国物理专业本科必修主干课。

## 对标教材

- C. Kittel, Introduction to Solid State Physics, Wiley（8th ed.）
- N. W. Ashcroft, N. D. Mermin, Solid State Physics, Cengage
- 阎守胜《固体物理基础》北京大学出版社
