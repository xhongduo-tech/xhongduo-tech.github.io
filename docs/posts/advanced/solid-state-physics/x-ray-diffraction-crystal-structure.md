## 为什么从X射线衍射开始

前几讲我们搭好了晶体结构的语言：格子、基元、对称性、倒空间。但**语言不能代替证据**——晶体的周期到底多大、原子到底怎么摆，必须用实验测出来。X 射线就是那把尺子：它的波长（约 0.1–2 Å）与晶面间距同量级，照射晶体时会被周期排列的原子相干散射，形成只有特定方向才出现的强反射——**衍射斑点**。读懂了衍射图，就反推出了晶体结构。

布拉格父子（William Henry Bragg 与其子 William Lawrence Bragg）在 1912–1913 年建立的这一整套方法，换来两座诺贝尔奖，也让「晶体学」成为一门定量科学。今天，蛋白质结构、新材料解析、半导体晶圆质量检测，用的都是这一讲的原理。<span class="marginnote">1947 年之后，同一套衍射几何被移植到电子与中子上，发展出电子衍射与中子衍射：<strong>电子散射强、适合薄膜表面，中子对氢原子与磁性敏感</strong>。三大衍射手段共享同一张倒格子地图。</span>

## 1 布拉格定律：把晶面当作镜子

最简单的衍射图像，是把一组平行晶面当作「半透明镜子」。设相邻晶面间距为 $d$，入射角为 $\theta$（与晶面的夹角），则相邻两面反射波的**光程差**为 $2d\sin\theta$。相长干涉要求光程差是波长整数倍：

$$2d\sin\theta = n\lambda, \qquad n = 1, 2, 3, \dots$$

这就是**布拉格定律（Bragg's law）**。$n$ 称为反射级数。<span class="marginnote">注意布拉格角 $\theta$ 是入射线与<strong>晶面</strong>的夹角，不是与晶面法线的夹角——入射光与反射光之间的夹角是 $2\theta$。实验图里标「$2\theta$」扫描的正是这个二倍角。</span>

![布拉格反射：相邻晶面的光程差 2d sinθ 决定相长干涉的方向](/images/solid-state-physics/x-ray-diffraction-crystal-structure-1.svg)

布拉格定律立刻给出一个判断：当 $\lambda > 2d$ 时无解，衍射不可能发生——这就是为什么用可见光（几千 Å）照晶体只能看到均匀反射，必须换 X 射线。

## 2 劳厄条件：衍射的倒格子语言

布拉格定律是对同一现象的「几何语言」，**劳厄条件（Laue condition）**给出等价但更深刻的「倒空间语言」：

$$\mathbf{k}' - \mathbf{k} = \mathbf{G}$$

其中 $\mathbf{k}, \mathbf{k}'$ 分别是入射与散射波矢，$\mathbf{G}$ 是某个倒格矢。它说：**衍射发生在「动量转移恰好等于一个倒格矢」时**。因为 $|\mathbf{k}'|=|\mathbf{k}| = 2\pi/\lambda$（弹性散射），这等价于：

$$|\mathbf{G}| = 2|\mathbf{k}|\sin\theta \quad\Longrightarrow\quad \frac{2\pi n}{d} = \frac{4\pi}{\lambda}\sin\theta$$

即回到布拉格定律（这里 $G = 2\pi n/d$，$d$ 是相应晶面间距）。两种语言无缝互译：**布拉格看「实空间的晶面」，劳厄看「倒空间的格点」。**

**埃瓦尔德球（Ewald sphere）**是劳厄条件的几何画法：让 $\mathbf{k}$ 从球心指向球面上一点（原点附近的倒格点），以入射波矢长为半径作球；若球面恰好经过另一个倒格点 $\mathbf{G}$，则 $\mathbf{k}' = \mathbf{k} + \mathbf{G}$ 指向它，衍射方向即确定。转动晶体（或改变波长）就是让倒格点「扫过」球面。

## 3 米勒指数与晶面间距

给晶面编号是衍射工作的第一步。**米勒指数（Miller indices）** $(hkl)$：晶面在三条晶轴上的截距取倒数、再化为最简整数比。<span class="marginnote">$(hkl)$ 的三个数正是倒格矢 $\mathbf{G}=h\mathbf{b}_1+k\mathbf{b}_2+l\mathbf{b}_3$ 的系数：一组晶面唯一对应一个倒格矢，且 $\mathbf{G}$ 垂直于这组晶面。米勒指数因此<strong>直接从倒格子读出</strong>。</span>

立方晶系的晶面间距最常用：

$$d_{(hkl)} = \frac{a}{\sqrt{h^2 + k^2 + l^2}}$$

| 晶面 | 立方晶系 $d$ | 说明 |
| --- | --- | --- |
| (100) | $a$ | 立方体的一个面 |
| (110) | $a/\sqrt{2}$ | 面对角线方向的面 |
| (111) | $a/\sqrt{3}$ | 八面体面，最密排 |

## 4 结构因子：谁在决定衍射强度

布拉格定律只决定「在哪个方向有衍射」，**强度由结构因子（structure factor）决定**。基元里有 $s$ 个原子、第 $j$ 个原子位于 $\mathbf{r}_j$、散射本领为 $f_j$，则倒格矢 $\mathbf{G}$ 对应的衍射振幅为：

$$S_{\mathbf{G}} = \sum_{j=1}^{s} f_j\, e^{-i\mathbf{G}\cdot\mathbf{r}_j}$$

当 $S_{\mathbf{G}} = 0$ 时，即使满足布拉格条件，该方向也**没有衍射**——这叫**系统消光（systematic absence）**，是判读格子类型的关键指纹。

## 5 公式解析：为什么 fcc 的 (100) 衍射消失

把结构因子套到面心立方上，就能解释晶体学的著名现象。fcc 基元含 4 个原子，取坐标 $(0,0,0)$、$(\tfrac12,\tfrac12,0)$、$(\tfrac12,0,\tfrac12)$、$(0,\tfrac12,\tfrac12)$（以晶胞为单位），代入：

$$S_{\mathbf{G}} = f\left[1 + e^{-i\pi(h+k)} + e^{-i\pi(h+l)} + e^{-i\pi(k+l)}\right]$$

分三步看：

- **第一步，指数项判奇偶**：$e^{-i\pi m} = (-1)^m$，只要 $m$ 为奇数即为 $-1$。
- **第二步，分类讨论**：若 $h,k,l$ 为全偶或全奇，四个括号里所有指数都同号相加，$S = 4f$ 或 $-4f$，衍射出现；若混奇偶（如 $h,k,l$ 中有两奇一偶），括号和恰为零，$S=0$。
- **第三步，得到消光规则**：fcc 只出现 **h,k,l 全偶或全奇** 的衍射；(100)、(110)、(210) 全部消失。

同样的推演给出：**sc 全反射，(100) 存在；bcc 要求 $h+k+l$ 为偶数**。一套衍射图的「存在—消失」模式，直接告诉你格子是 P、I 还是 F——这就是结构测定的第一步。

## 6 从衍射图到结构：实验方法

三类经典方法按「保持布拉格条件的方式」区分：

- **劳厄法（Laue method）**：单晶固定，用连续谱 X 射线。改变波长使某些 $\lambda$ 恰满足布拉格条件，底片上留下对称斑点——常用于快速判定晶体的取向与对称性。
- **旋转晶体法（rotating crystal）**：单晶绕固定轴转动，用单色 X 射线。倒格点逐次扫过埃瓦尔德球，斑点排成层线。
- **粉末法 / 德拜-谢勒法（Debye–Scherrer）**：多晶粉末含无数随机取向的小晶粒，等效于所有方向同时满足条件，得到一组同心衍射环。适合测定未知材料的晶胞参数。

把各环的 $2\theta$ 换成 $d$，按 $(hkl)$ 指标化，再核对消光规律，就能定出晶系、格子、晶胞参数，进而解出基元中每个原子的位置。<span class="marginnote">现代自动化把这一步推向极致：蛋白质数据库（PDB）里超过 20 万个结构，绝大多数由 X 射线衍射解出；2024 年诺贝尔化学奖颁给的计算蛋白质设计（AlphaFold 一代也训练于衍射结构数据）背后，站着的正是这套方法。</span>

### 数值例子：指标化一张粉末衍射图

用布拉格定律反推晶胞参数。测得硅的粉末衍射第一环 $2\theta = 28.4°$（$\lambda = 1.54$ Å，Cu Kα 辐射）：

- **第一环指标**：硅是金刚石结构（fcc），最小衍射面为 (111)，$\sin\theta = \sin 14.2° = 0.245$。
- **晶面间距**：$d_{111} = \lambda/2\sin\theta = 1.54/(2\times0.245) = 3.14$ Å。
- **晶胞参数**：$a = d\sqrt{h^2+k^2+l^2} = 3.14\times\sqrt{3} = 5.44$ Å。

实测硅的晶胞参数 $a = 5.431$ Å——**一次衍射测量就把晶格常数定到千分位**。这就是粉末衍射的日常工作：量 $2\theta$ → 换 $d$ → 指标化 → 报出晶胞参数。

### 消光规律的另一面：结构因子的相

结构因子不只是零与非零的差别，其**相位**携带原子的位置信息。写出 $F_{hkl} = |F_{hkl}|e^{i\phi_{hkl}}$，通过多波长反常散射（把重原子共振频率附近的色散项加入散射因子）可以解出相位——这就是**直接法与多波长反常散射（MAD）**解蛋白质晶体结构的原理。2024 年诺奖得主解蛋白结构的流程，核心仍是「测衍射振幅 + 解相位 + 反演电子密度」，只是把每一步都自动化、规模化到了大数据时代。

## 7 辨析｜易错点：衍射判读的几个坑

- **消光 ≠ 没满足布拉格条件**：消光是结构因子为零（原子散射相消），不是几何条件不满足。二者要分清。
- **布拉格角是掠射角**：$\theta$ 是入射线与晶面的夹角；「$2\theta$」是探测器转角，两个符号别混。
- **一阶、二阶反射**：$2d\sin\theta = n\lambda$ 中 $n>1$ 是同一组晶面的高阶反射，也可把 $d$ 换成 $d/n$ 当作虚拟的 $(nh,nk,nl)$ 面处理。
- **消光规则只适用于 X 射线**：电子衍射、中子衍射的散射因子不同，消光条件会变化。

## 8 小结

- **布拉格定律** $2d\sin\theta = n\lambda$：晶面当镜子，光程差 $2d\sin\theta$ 必须为波长整数倍。
- **劳厄条件** $\mathbf{k}'-\mathbf{k}=\mathbf{G}$：衍射即「动量转移等于倒格矢」，与布拉格定律等价；埃瓦尔德球是其几何表示。
- **米勒指数** $(hkl)$：晶面 ↔ 倒格矢一一对应；立方晶系 $d = a/\sqrt{h^2+k^2+l^2}$。
- **结构因子**决定强度，消光规律暴露格子类型：**sc 全反射，bcc 需 $h+k+l$ 为偶数，fcc 需 $h,k,l$ 全奇或全偶**。
