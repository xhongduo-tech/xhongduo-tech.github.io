## 为什么从磁共振开始

磁性不只在宏观上产生吸引与排斥，还能当「探针」用：把样品放进强磁场，用射频或微波照射，自旋会像音叉一样在特定频率「共振」吸收能量。这个现象叫**磁共振（magnetic resonance）**。它让化学家看见分子的骨架（核磁共振 NMR）、让医生无创地看见人体组织（MRI）、让材料学家探测缺陷与自由基（电子顺磁共振 EPR）——三个诺贝尔奖的领域，共享同一条拉莫进动的物理。

从主线看，这一讲把前两讲的磁矩、自旋、交换作用变成**测量技术**。磁共振是「把量子力学能级读成谱线」的典范，与光学光谱、光电子谱、中子散射并列，构成固体研究的谱学工具箱。

## 1 拉莫进动与共振条件

带磁矩 $\boldsymbol{\mu}$ 的自旋在磁场 $\mathbf{B}_0$ 中受到力矩 $\boldsymbol{\mu}\times\mathbf{B}_0$，不改变大小、只改变方向——磁矩绕场**进动**，角频率为**拉莫频率（Larmor frequency）**：

$$\omega_0 = \gamma B_0$$

$\gamma$ 是**旋磁比（gyromagnetic ratio）**。量子图像：自旋在磁场中分裂成能级 $E = -\gamma\hbar B_0 m_s$，相邻能级间距 $\Delta E = \hbar\gamma B_0 = \hbar\omega_0$。**共振条件**：当外加射频光子能量 $\hbar\omega$ 恰等于能级间距，吸收跃迁发生：

$$\omega = \gamma B_0$$

质子在 1 T 场下的共振频率约 42.6 MHz（射频）；电子在同样场下约 28 GHz（微波）——**电子旋磁比比核大约 660 倍**，因为电子质量小。<span class="marginnote">旋磁比是粒子的「频率-磁场比」：$\gamma = g\mu/\hbar$。电子 $g\approx2.0023$（略偏离 2 是量子电动力学修正），核的 $g$ 因子则因核素而异——<strong>不同核素共振频率不同，是 NMR 能区分氢、碳、磷的根源</strong>。</span>

## 2 布洛赫方程：进动加弛豫

宏观磁化 $\mathbf{M}$ 的动力学由**布洛赫方程（Bloch equations）**描述：

$$\frac{d\mathbf{M}}{dt} = \gamma\mathbf{M}\times\mathbf{B} - \frac{M_x\hat{x}+M_y\hat{y}}{T_2} - \frac{(M_z - M_0)\hat{z}}{T_1}$$

两项弛豫各有含义：

- **纵向弛豫 $T_1$（自旋-晶格）**：$M_z$ 回到平衡 $M_0$ 的特征时间，能量传给晶格（声子）。
- **横向弛豫 $T_2$（自旋-自旋）**：$M_{xy}$ 消相的特征时间，自旋间互相搅扰。<span class="marginnote">一句话记两种弛豫：<strong>$T_1$ 是「磁化强度找回 z 轴方向」的时间，$T_2$ 是「横向分量散伙」的时间</strong>。通常 $T_2 \le T_1$。MRI 的图像对比度很大程度靠 $T_1$ 与 $T_2$ 的差异。</span>

## 3 核磁共振（NMR）与 MRI

NMR 测量原子核（最常见 $^1$H）在磁场中的共振吸收：

**化学位移（chemical shift）**：核周围电子云屏蔽外场，使共振频率偏移 $\delta$（ppm 量级）。不同化学环境的核频率不同——一张 NMR 谱就是分子结构的「指纹」。
**自旋耦合（J-coupling）**：相邻核通过化学键的间接作用把谱线劈成多重峰，给出邻近原子数。
- **MRI（磁共振成像）**：把 NMR 从「平均信号」升级成「空间分辨」——利用磁场梯度让不同位置的共振频率不同，反演图像。软组织对比度远胜 X 射线 CT。<span class="marginnote">MRI 的物理就是 NMR + 梯度场 + 图像重建：<strong>沿 $z$ 加线性梯度场，则 $x$ 处共振频率 $\omega(x) = \gamma(B_0 + Gx)$，测到的是频率编码的空间信息</strong>。现代 MRI 已是医学影像的三大支柱之一。</span>

## 4 电子顺磁共振（EPR/ESR）

EPR 检测**未配对电子**：自由基、缺陷、过渡金属离子、顺磁杂质。与 NMR 的差别：

频率高（X 波段约 9 GHz）、对局域环境极敏感。
**g 因子各向异性**：晶体里 $g$ 随方向变化，反映轨道角动量混合——EPR 谱能定出缺陷的对称性与晶格位置。
- **超精细结构**：电子与附近核自旋的相互作用把谱线劈裂，直接读出电子波函数与核的重叠。<span class="marginnote">EPR 是「孤电子侦察兵」：半导体里的空位、色心（金刚石的 NV 中心）、催化剂表面的活性位，都是 EPR 的猎物。<strong>NV 中心（氮-空位色心）甚至被用作量子比特</strong>——单个自旋的 EPR 控制是现代量子传感的基础。</span>

## 5 公式解析：共振频率 ω = γB

$\omega = \gamma B_0$ 从经典进动到量子吸收，三步说清：

**第一步，力矩方程**：磁矩进动 $\frac{d\boldsymbol{\mu}}{dt} = \gamma\boldsymbol{\mu}\times\mathbf{B}_0$，角速度 $\omega_0 = \gamma B_0$。
**第二步，量子能级**：自旋 $S$ 在磁场中 $E = -\gamma\hbar B_0 m_S$，$m_S$ 取 $-S$ 到 $+S$，相邻能级差 $\hbar\gamma B_0$。
- **第三步，光子匹配**：射频光子 $\hbar\omega = \hbar\gamma B_0$，即共振条件。**频率固定时扫磁场（或场固定扫频率），吸收极大即共振**——这就是磁共振谱仪的原理。

## 6 谱学信息

磁共振谱能读出的信息密度极高：

- **化学位移与裂分** → 分子结构与邻近原子。
- **线宽** → 弛豫时间、分子运动性、有序度（固态 NMR 的线宽反映晶格环境）。
- **信号强度** → 自旋数目（定量分析，如核磁定量、MRI 的质子密度成像）。
- **g 因子与超精细常数** → 电子波函数的轨道成分与核接触密度。

固体物理里，NMR/EPR 常与比热、中子散射联用：**同一样品，比热给声子谱、NMR 给局域磁环境、中子散射给磁结构**——三者拼出完整图景。<span class="marginnote">磁共振的另一个现代角色是<strong>量子计算</strong>：核自旋的相干时间长、可控性好，曾用于早期量子算法演示（液态 NMR 量子计算），现在仍是量子传感的明星。</span>

### 数值例子：算一个质子共振频率

用 $\omega = \gamma B$ 做一次实战。质子的旋磁比 $\gamma_p = 2.675\times10^8$ s⁻¹·T⁻¹，于是：

- **$B_0 = 1$ T**：$f_0 = \gamma B_0/2\pi = 42.6$ MHz——FM 广播频段。
- **$B_0 = 7$ T**（常见高场 NMR）：$f_0 \approx 298$ MHz。
- **电子（$g\approx2.0023$）在 1 T**：$f_0 \approx 28$ GHz——微波 X 波段。

同一磁场下电子与质子的频率相差约 660 倍，这正是 NMR 与 EPR 用不同波段的根源。NMR 谱里的「化学位移」以 ppm 计：$\delta = (\nu-\nu_{\text{ref}})/\nu_0 \times 10^6$。在 298 MHz 下移动 1 ppm = 298 Hz——**ppm 让不同场强的仪器可以直接对比谱图**。

### 弛豫时间怎么测：脉冲序列

现代磁共振用脉冲而不是连续扫场。一个最简单的序列是**反转恢复（inversion recovery）**：先用 180° 脉冲把磁化翻到 $-z$，等 $t$ 后测信号。磁化恢复满足

$$M_z(t) = M_0\left(1 - 2e^{-t/T_1}\right)$$

当 $M_z = 0$ 时 $t = T_1\ln 2$——**扫几个 $t$，找过零时间，$T_1$ 就出来了**。MRI 的 T₁ 加权、T₂ 加权图像，本质就是选择不同回波时间凸显不同组织的弛豫差异。

### 磁共振谱学能干什么：一张应用地图

| 技术 | 探测对象 | 典型应用 |
| --- | --- | --- |
| 液相 NMR | 溶液分子 | 有机结构鉴定 |
| 固态 NMR | 固体核环境 | 材料、电池电解液 |
| MRI | 体内质子密度与弛豫 | 医学成像 |
| EPR/ESR | 未配对电子 | 自由基、缺陷、催化剂 |
| 磁共振显微 | 微米分辨质子 | 小动物成像 |
| 核四极共振（NQR） | 非零核四极矩 | 毒品/炸药探测 |

所有变体共享同一个核心物理——**磁场下自旋能级分裂 + 共振吸收 + 弛豫编码**。谱学技术的丰富，只是「同一台收音机调到不同波段、不同信号」的差异。这也是磁共振成为跨学科标准工具的原因：物理原理固定，应用面极宽。

### 磁共振与量子传感

单个自旋的磁共振已从「统计平均」走向「单量子探测」。金刚石中的 NV 色心（氮-空位缺陷）是一个孤立电子自旋，室温下可用光探测磁共振（ODMR）读出其状态；它对磁场、电场、温度、应力都极敏感，是纳米尺度的量子传感器。NV 色心还能用作量子比特，其相干时间在室温下可达毫秒级。<span class="marginnote">从「一块样品的 NMR」到「一颗色心的 ODMR」，磁共振走了 70 年——<strong>同一个 $\omega = \gamma B$ 原理，从宏观统计延伸到单自旋控制</strong>。这正是本讲开头那句话的现代注脚：磁共振是一台永远在改进的量子听诊器。</span>

## 7 辨析｜易错点：磁共振的常见误区

- **共振频率不是「越大越好」**：不同核素 $\gamma$ 不同，比较谱峰要换算成化学位移（ppm），不能直接比 Hz。
- **$T_1$ 与 $T_2$ 别混**：$T_1$ 管纵向恢复（能量弛豫），$T_2$ 管横向消相（熵弛豫）；MRI 加权成像靠区分两者。
- **EPR 的 g 因子不是常数 2**：晶体中 g 各向异性是信息，不是噪声。
- **NMR 不是「只测氢」**：$^{13}$C、$^{31}$P、$^{29}$Si 等核都能测，只是丰度与灵敏度不同。

## 8 小结

- **拉莫进动** $\omega_0 = \gamma B_0$：磁矩绕场进动；量子能级差 $\hbar\omega_0$，光子匹配即共振。
- **布洛赫方程**：进动 + $T_1$（纵向弛豫）+ $T_2$（横向弛豫）共同决定磁化强度动力学，是核磁共振成像与电子顺磁共振的理论支柱。
