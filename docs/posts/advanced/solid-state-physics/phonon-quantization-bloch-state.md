## 为什么从声子开始

上一讲我们求出了晶格振动的色散关系 $\omega(k)$，但那是**经典**图像：原子位移是连续的实数。真实世界是量子的——振动能量只能取分立的台阶。当一个振动模式的能量从一个量子跳到另一个量子，我们就说晶格里多（或少）了一个**声子（phonon）**。声子不是一种新粒子，而是**晶格振动的能量量子**，一种准粒子。引入声子，就像给电磁场引入光子：一切关于热传导、热容、比热的计算都变得简洁而自然。

从主线看，声子是我们遇到的第一个「**量子化场**」范例：经典波 → 模式 → 谐振子 → 占据数。这套程序与量子电动力学里光子场的处理完全相同，只是换了一台「量子化机器」。理解它，等于预演了整个量子多体物理的入场式。

## 1 简正模式：把振动解耦成独立谐振子

$N$ 个原子的晶格有 $3N$ 个自由度，运动方程彼此耦合。**简正坐标（normal coordinates）** $Q_s(\mathbf{k})$ 通过傅里叶变换把耦合解除：

$$u_n(t) = \sum_{\mathbf{k},s} Q_s(\mathbf{k})\, e^{i\mathbf{k}\cdot\mathbf{r}_n}$$

在这个坐标下，总能量变成一组**互相独立的谐振子**之和：

$$H = \sum_{\mathbf{k},s} \left[\frac{|P_s(\mathbf{k})|^2}{2M} + \frac{1}{2}M\omega_s^2(\mathbf{k})|Q_s(\mathbf{k})|^2\right]$$

每个指标 $(\mathbf{k}, s)$（波矢 + 支）对应一个独立的、频率为 $\omega_s(\mathbf{k})$ 的一维谐振子。<span class="marginnote">「解耦」是一切多体问题的梦：三万个耦合原子没法解，但写成 <strong>3N 个独立谐振子</strong>后，每个都能精确求解。这个「傅里叶变换 → 对角化」的操作，和主成分分析、信号去噪里对角化协方差矩阵是同一个套路。</span>

## 2 量子化：声子的诞生

把每个独立谐振子量子化：频率为 $\omega$ 的量子谐振子，能级为

$$E_n = \left(n + \frac{1}{2}\right)\hbar\omega, \qquad n = 0, 1, 2, \dots$$

能级间隔 $\hbar\omega$ 均匀，$n$ 是这个模式被激发的量子数。**说「晶格处于第 $n$ 激发态」，等价于说「有 $n$ 个能量为 $\hbar\omega$ 的声子占据这个模式」**。<span class="marginnote">用算符语言：引入产生湮灭算符 $\hat{a}^\dagger, \hat{a}$，谐振子哈密顿量写成 $\hat{H} = \hbar\omega(\hat{a}^\dagger\hat{a} + \tfrac12)$，占据数算符 $\hat{n}=\hat{a}^\dagger\hat{a}$。<strong>这种「把场写成产生湮灭算符」的二次量子化语言，是光子、声子、电子的统一语法。</strong></span>

于是晶格振动的量子态由一组占据数 $\{n_{\mathbf{k},s}\}$ 完全描述。**声子（phonon）**= 模式 $(\mathbf{k},s)$ 上的一个能量量子 $\hbar\omega_s(\mathbf{k})$、准动量 $\hbar\mathbf{k}$。

## 3 声子是什么粒子：玻色子与晶体动量

声子有两个区别于实粒子的重要身份：

**第一，声子是玻色子（boson）**。任何数目的声子可以占据同一模式——占据数无上限，服从**玻色-爱因斯坦分布**：

$$\bar n(\mathbf{k},s) = \frac{1}{e^{\hbar\omega_s(\mathbf{k})/k_B T} - 1}$$

这是晶格热容（下一讲）的统计基础：$k_BT \gg \hbar\omega$ 时 $\bar n \approx k_BT/\hbar\omega$，高温极限。

**第二，声子的动量是准动量（crystal momentum）**。声子之间散射时动量并不严格守恒，而是「模倒格矢」守恒：

$$\hbar\mathbf{k}_1 + \hbar\mathbf{k}_2 = \hbar\mathbf{k}_3 + \hbar\mathbf{G}$$

$\mathbf{G}\neq 0$ 的散射叫**倒逆（U过程，umklapp）散射**——它把波矢从第一布里渊区「打回去」，是有限热导率的根本原因。<span class="marginnote">准动量守恒里的 $\mathbf{G}$ 项是晶格周期性的印记：<strong>晶体吸收或放出一个倒格矢的动量而自身不动</strong>。这解释了为什么热导率不随温度无限增大——U 过程限制了声子的自由程（见第 5 章热导率）。</span>

## 4 布洛赫态：周期晶格中的平面波标记

声子模式为什么用 $\mathbf{k}$ 标记、而且只用第一布里渊区内的 $\mathbf{k}$？因为原子位移场在周期性晶格中满足**布洛赫形式**：沿晶格平移一个格矢 $\mathbf{R}$，模式只改变一个相位因子：

$$u_{\mathbf{k},s}(\mathbf{r} + \mathbf{R}) = e^{i\mathbf{k}\cdot\mathbf{R}}\, u_{\mathbf{k},s}(\mathbf{r})$$

这正是布洛赫定理（第 7 章将用于电子波函数）对位移场的版本。任何 $\mathbf{k}' = \mathbf{k} + \mathbf{G}$ 给出相同的物理模式（相位因子只差 $e^{i\mathbf{G}\cdot\mathbf{R}}=1$），因此**只需取第一布里渊区内的 $\mathbf{k}$**。<span class="marginnote">「布洛赫态」的数学实质：本征态可按不可约表示分类，平移对称性给出量子数 $\mathbf{k}$。<strong>这和把分子轨道按点群不可约表示分类是同一套群论逻辑</strong>——对称性决定量子数的编号。</span>

## 5 公式解析：谐振子能量量子化

一维谐振子的薛定谔方程 $-\frac{\hbar^2}{2M}\frac{d^2\psi}{dx^2} + \frac12 M\omega^2 x^2\psi = E\psi$，能级取分立值 $E_n = (n+\tfrac12)\hbar\omega$。三步理解：

- **第一步，尺度分析**：组合 $\hbar, M, \omega$ 只有一个能量尺度，即 $\hbar\omega$；能级间隔必为 $\hbar\omega$ 的倍数，故 $E_n$ 具有 $n\hbar\omega$ 的形式。
- **第二步，零点能来自不确定性原理**：若 $n=0$ 时能量为零，则位置 $x$ 与动量 $p$ 可同时为零，违反 $\Delta x\Delta p\ge\hbar/2$。$\tfrac12\hbar\omega$ 正是最小不确定性允许的「生存能量」。
- **第三步，均匀间隔的含义**：任意两个相邻能级间隔相同，所以「激发 $n$ 份 $\hbar\omega$」与「放进 $n$ 个全同玻色子」在计数上完全等价——这就是声子语言的来源。

## 6 核心对比表：声子 vs 电子（玻色子 vs 费米子）

| 维度 | 声子 | 电子 |
| --- | --- | --- |
| 来源 | 晶格振动的量子化 | 物质粒子的量子场 |
| 统计 | 玻色-爱因斯坦（可占据任意多个） | 费米-狄拉克（每个态至多一个） |
| 能量 | $\hbar\omega_s(\mathbf{k})$，可为零（静止无质量） | $\hbar^2k^2/2m$，有静止质量 |
| 动量 | 准动量，散射模 $\mathbf{G}$ 守恒 | 准动量，类似 |
| 色散 | 声学支 $\omega\propto k$（低能） | $\epsilon\propto k^2$（自由） |
| 零点能 | 每模式 $\tfrac12\hbar\omega$ | 无（费米面除外） |

这张表是理解固体「三热两电」现象的分水岭：**导热靠声子（与电子）携带能量，导电只能靠电子**。两种粒子在晶格里共存、碰撞，构成了热与电的全部故事。

### 数值例子：一个模式里有多少声子

用玻色-爱因斯坦分布 $\bar n = 1/(e^{\hbar\omega/k_BT}-1)$ 算不同温度下的平均声子数。取光学声子 $\hbar\omega = 60$ meV（约 700 K 对应的模式）：

- **$T = 300$ K**：$x = \hbar\omega/k_BT = 60/26 = 2.3$，$\bar n = 1/(e^{2.3}-1) \approx 0.1$——平均每 10 个原胞才有 1 个光学声子。
- **$T = 600$ K**：$x = 1.16$，$\bar n \approx 0.5$。
- **$T \to \infty$**：$\bar n \approx k_BT/\hbar\omega$——声子数随温度线性增长。

对比声学声子（$\hbar\omega \to 0$ 的长波模式）：$\bar n \approx k_BT/\hbar\omega \to \infty$——**低频模式在高温下可容纳海量声子**，这正是声学支主导热容、光学支主导红外吸收的原因。一个模式里声子数的数量级差异，决定了它在热学与光学中扮演的角色。

### 声子与光子：一对类比

把声子与光子并排看，固体物理与电磁学的结构完全平行：

| 维度 | 声子 | 光子 |
| --- | --- | --- |
| 场 | 晶格位移 | 电磁场 |
| 色散 | 声学支 $\omega = v_sk$ | $\omega = ck$ |
| 量子 | $\hbar\omega$ 能量量子 | $\hbar\omega$ 光子 |
| 统计 | 玻色-爱因斯坦 | 玻色-爱因斯坦 |
| 元激发 | 准粒子（在晶格中） | 真实粒子（可在真空中） |

两者都满足布洛赫/波矢量子化、都是玻色子、都承载能量输运。**一旦掌握声子，光子与磁振子等一切玻色型元激发都触类旁通**——这就是「元激发」这个概念的力量。

## 7 辨析｜易错点：声子的常见误解

- **声子不是真正的粒子**：它不能独立于晶格存在，没有静止质量，也不出现在真空中。把它当「粒子」只是方便的计数语言。
- **声子数与能量是两回事**：高温下声子数 $n$ 大，但每个声子能量 $\hbar\omega$ 不变；别把「声子变多」理解成「声子能量变大」。
- **U 过程不是错误**：动量不守恒的 U 过程恰恰是晶格对称性的正确体现，缺了它，热导率会发散。
- **零声子态不是「无振动」**：即使 $n=0$，每个模式仍有 $\tfrac12\hbar\omega$ 零点能，晶体在绝对零度仍在量子振动。

## 8 小结

- 简正坐标把 $3N$ 个耦合振动**解耦**成独立谐振子；量子化后每个模式 $( \mathbf{k},s)$ 能级 $E_n=(n+\tfrac12)\hbar\omega$。
- **声子** = 模式上的能量量子 $\hbar\omega$，准动量 $\hbar\mathbf{k}$；是**玻色子**，服从玻色-爱因斯坦分布。
- 声子散射满足**准动量守恒**（模 $\mathbf{G}$），$\mathbf{G}\neq0$ 的 U 过程决定有限热导率。
- 位移场满足**布洛赫形式**，$\mathbf{k}$ 只需取第一布里渊区；「布洛赫态」是平移对称性给出的量子数分类。
- 声子（玻色子）与电子（费米子）的对照，是后面全部输运与热学讨论的分水岭。
