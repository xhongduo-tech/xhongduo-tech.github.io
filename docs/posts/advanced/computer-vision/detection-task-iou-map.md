## 为什么从检测任务定义开始

图像分类告诉我们"图里有什么"，但真实世界（自动驾驶、安防、机器人）还需要知道"**在哪**"。**目标检测（object detection）**的任务是：给图像里每个目标一个**边界框（bounding box）**与一个**类别标签**。它比分类难一个量级——目标数量不定、位置不定、尺度不一、可能相互遮挡。

在讨论任何检测算法之前，必须先把两件事钉死：**目标长什么样（边界框表示）**与**怎么算对（评估指标）**。没有统一的度量，就无从比较 R-CNN 与 YOLO 谁更好。这一节是检测的"语言规范"，后面所有检测算法都在这个语言里说话。<span class="marginnote">检测的经典数据集是 PASCAL VOC 与 COCO：VOC 20 类、COCO 80 类。它们定义了检测的"考纲"。注意 COCO 用 IoU 0.5~0.95 的平均 mAP（更严），VOC 用 IoU 0.5 的 mAP（宽松）——<strong>同样的模型在两个榜单上的分数不可直接比较</strong>，这是最常见的误解之一。</span>

## 1 边界框与检测输出

**边界框（bounding box）**的两种表示：

- **$(x, y, w, h)$**：左上角坐标 + 宽高——直观，OpenCV 默认。
- **$(c_x, c_y, w, h)$**：中心坐标 + 宽高——YOLO 系列默认，回归更稳定。

一次检测的输出是若干 $(类别, 置信度, 框)$ 三元组。**置信度（confidence / score）**表示"这个框有多可能是该类别"——分类得分与定位质量可分离。检测算法的目标就是输出"**一组**高质量三元组"：该检的全检到、不该检的别乱检、框得准。

## 2 IoU：框与框的重叠度量

**IoU（Intersection over Union，交并比）**是两个框的重叠程度：

$$
\text{IoU} = \frac{\text{Area}(A \cap B)}{\text{Area}(A \cup B)}
$$

- 完全重合：IoU = 1；完全不相交：IoU = 0。
- **判定"检测对了"**：预测框与真值框的 IoU 超过阈值（VOC 用 0.5，COCO 用 0.5~0.95 多档），算**正样本（TP）**。

**辨析｜易错点：** IoU 的分子是交集、分母是并集，**不是小框比大框**（那是"覆盖率"）。两个框一个完全包住另一个时，IoU 取决于大小比——这在 NMS 去重与匹配时都会用到，别和"谁包含谁"混淆。

## 3 从 TP/FP/FN 到 Precision/Recall

把检测结果与真值匹配后，每个预测框归为三类：

- **TP（True Positive）**：与某真值框 IoU 超阈值且类别对，且该真值框首次被匹配。
- **FP（False Positive）**：没有匹配到真值框的预测（误检），或与已匹配的真值重复。
- **FN（False Negative）**：没被任何预测覆盖的真值框（漏检）。

于是定义**查准率（Precision）**与**查全率（Recall）**：

$$
\text{Precision} = \frac{TP}{TP + FP}, \qquad
\text{Recall} = \frac{TP}{TP + FN}
$$

**Precision 回答"检出的里面有多少是对的"，Recall 回答"该检的里面检出了多少"**。两者此消彼长：阈值高（只信高分）→ Precision 高 Recall 低；阈值低 → 反过来。**检测器的完整表现是一条 Precision-Recall 曲线**，而不是一个点。

## 4 mAP：检测的"总成绩"

**mAP（mean Average Precision）**把 Precision-Recall 曲线压成一个数：

1. **AP（Average Precision）**：对某一类，按置信度降序扫描所有预测，在每个 Recall 点取当前最大 Precision，对 Recall 轴积分（即 PR 曲线下面积）。

$$
\text{AP} = \int_0^1 P(r) \, dr
$$

2. **mAP**：对所有类别的 AP 取平均。

**mAP 的直觉**：它同时惩罚"置信度排序不好"（高置信度的应该是真目标）与"检出不全/不精"。**一个完美的检测器 mAP=1**——每个真值都被高置信度、精确匹配地检出，且无任何误检。

**辨析｜易错点：** mAP 对**框定位误差**的惩罚是离散的（IoU 过阈值才算对）——两个框一个 IoU 0.51、一个 0.99，只要都过阈值，在二值 mAP 里算同样"对"。COCO 用 IoU 0.5~0.95 平均缓解了这个问题（定位越准分越高）。**定位精度被 IoU 阈值量化，这是 mAP 的已知粗糙处**。

## 5 公式解析：AP 曲线下面积为什么是"排序质量"的度量

**为什么 mAP 与"置信度排序"强相关？** 拆开看 PR 曲线怎么画出来的。

- **第一步，排序**：把所有预测按置信度降序排列。**置信度是"检测器对每个框的自信程度"，排序反映"它认为谁最可能是真目标"。**
- **第二步，逐点扫**：从最高置信度开始，逐个判定 TP/FP，累计计算 Precision 与 Recall，得到一条从高置信度端（Recall 低、Precision 高）向低置信度端延伸的曲线。
- **第三步，曲线下面积**：面积大 ⇔ 曲线"高高在上"⇔ **在 Recall 高的同时仍保持高 Precision** ⇔ 高置信度的预测几乎全是真目标。若检测器把真目标排在低置信度（乱排序），曲线在 Recall 中段就掉下去，面积小。
- **第四步，单一分数**：mAP 把"排序质量 + 检出能力 + 定位质量"揉成一个数，方便跨模型比较——**它同时度量了"排得好"与"检得全"**。

**一句话：mAP = 把检测器按置信度排序的好坏，换算成 PR 曲线下的面积，再按类别平均。** 它是对"输出质量"的单一、可排序的度量。

## 6 指标之外：NMS 与检测的工程现实

真实检测管线还有一道必须的工序：**非极大值抑制（NMS，Non-Maximum Suppression）**。因为一个目标会被输出多个重叠框，NMS 的做法：

1. 按置信度排序所有框。
2. 取最高置信度框，删除所有与它 IoU 超阈值（如 0.5）且类别相同的框。
3. 重复直到处理完所有框。

**NMS 保证"一个目标一个框"**——它是检测输出的最后一道清理，也是评估里隐含的组成部分。后面所有检测算法（R-CNN、YOLO、DETR）都会遇到它（DETR 则试图用集合预测绕开它）。<span class="marginnote">检测指标与分类指标的一个微妙差别：分类的准确率只有一个标签；检测的 mAP 要处理"多个目标、多个类别、位置误差"三个维度。这也是为什么检测的评测比分类更"严苛"——一个模型分类 99%、检测 mAP 60% 都是正常的。理解"检测 = 分类 + 定位 + 计数"的三重性，是进入检测算法的准备。</span>

## 7 检测指标的工程理解与数据

检测指标在工程里的正确理解，有几个要点：

- **mAP 对"定位精度"是离散的**：IoU 0.51 与 0.99 在阈值 0.5 下都算"对"——**"mAP 不能区分'刚好对上'与'非常精确'"**。COCO 用 IoU 0.5~0.95 平均缓解；对定位极度敏感的任务（自动驾驶），另测"框中心误差"。
- **AP 的"类别平均"掩盖不平衡**：mAP 对每类求平均，**稀有类表现被稀释**——"mAP 高但小物体类很差"完全可能。看论文要同时看 **AP_small / AP_medium / AP_large**（COCO 提供）与每类 AP。
- **mAP vs FPS 的权衡**：检测器评测通常"精度（mAP）与速度（FPS）一起报"——**"没有免费的午餐"**，两阶段的精度来自两阶段的耗时。**"精度-速度曲线"**（多个模型的 mAP-FPS 点）比单一分数更能反映工程价值。
- **训练与评测的 IoU 阈值要一致**：训练时正样本的 IoU 定义（如 0.5）影响模型，评测阈值的选取影响分数——**"设定一致性"是复现结果的前提**。

**检测数据的规模感**：COCO 12 万训练图、80 类、5 万+ 实例；检测标注（框 + 类）比分类（一个标签）贵一个量级——**"检测吃数据、更吃标注成本"**，这也是半监督/弱监督检测（用分类数据辅助）活跃的原因。**"指标、数据、成本"三者一起看，才理解检测任务的真实形态**。

## 8 检测评测的现代发展与开放问题

检测评测自身也在演进，几个现代方向：

- **开放词汇检测（OVD）**：检测"任意文本描述的物体"——**评测从"固定类别"到"开放类别"**（LVIS 基准）。传统 mAP 按"类别集"算，开放检测要测"新类别的泛化"。
- **长尾分布（long-tail）**：现实数据里"常见类很多、稀有类极少"——**传统 mAP 被常见类主导**；长尾评测（LVIS 的分层 mAP）把稀有类单独报告——"**稀有类才是真实瓶颈**"。
- **零样本/少样本检测**：检测器在没见过/只见过几张的类别上表现——"**从'会检测'到'会迁移检测'**"。
- **检测 + 大模型**：检测器与多模态大模型结合（Grounding DINO 等）——"**检测从'专用'走向'通用能力'**"。

**检测评测的开放问题**：**"mAP 之外还该看什么？"**——定位质量、边界精度、跨域鲁棒、对攻击的稳健——"**一个分数掩盖太多维度**"。

**对学习者的启示**：检测评测的演进说明——"**评测定义任务**"：mAP 定义了"检测 = 定位 + 分类"，开放词汇定义了"检测 = 理解 + 检索"。**"指标的变迁，就是领域定义的变迁"**——理解检测，要连它的"考纲"（评测）一起理解。

## 9 小结

- **检测任务**：输出 $(类别, 置信度, 边界框)$ 三元组集合；框用 $(x,y,w,h)$ 或 $(c_x,c_y,w,h)$。
- **IoU** = 交并比，判定"框对了没有"；阈值因数据集而异（VOC 0.5、COCO 0.5~0.95）。
- **TP/FP/FN** 定义检出质量；**Precision** 问"检出多对"，**Recall** 问"该检多全"。
- **mAP** = PR 曲线下面积按类平均，度量"排序 + 检出 + 定位"的综合质量。
- **NMS** 去重重叠框，是检测管线的标准收尾。
