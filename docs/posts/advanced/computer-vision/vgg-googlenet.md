## 为什么从 VGG 与 GoogLeNet 开始

AlexNet 证明了"深"有用，但"怎么深"成了新问题：乱堆层数，要么参数爆炸、要么梯度消失、要么过拟合。2014 年的两篇工作给出了两条截然不同的答案：

- **VGG**：**把架构统一成"清一色 3×3 卷积 + 2×2 池化"**，用最简单的重复单元把网络推到 16~19 层。它的极简主义让它成为之后所有网络的"特征提取器标准件"。
- **GoogLeNet（Inception）**：**在同一层并行使用不同大小的卷积核**（1×1、3×3、5×5 + 池化），再用 1×1 卷积控制通道数，把网络做到 22 层却只有 500 万参数。

这两条路代表"深"的两种哲学：**串联重复**（VGG）与**并联多尺度**（GoogLeNet）。理解它们的权衡，就理解了 CNN 架构设计的核心张力。<span class="marginnote">为什么都是 2014 年？因为 2013 年之后"深度学习赢过手工特征"已成定局，问题从"要不要深"变成"怎么深才好"。VGG 与 GoogLeNet 在同一个 ImageNet 竞赛里交手，GoogLeNet 以更少的参数拿了第一，但 VGG 因其简洁而成为更常用的特征提取器——<strong>"拿奖的未必最流行，最流行的未必最先进"是工程演进的常态</strong>。</span>

## 1 VGG：小核深堆的极致

**VGG 的核心思想只有一句：所有卷积都用 3×3（stride 1, pad 1），所有池化都用 2×2（stride 2）。** 结构（VGG-16）：

```text
输入 224×224×3
├─ 卷积块1：3×3,64（×2）   → 2×2 池化
├─ 卷积块2：3×3,128（×2）  → 2×2 池化
├─ 卷积块3：3×3,256（×3）  → 2×2 池化
├─ 卷积块4：3×3,512（×3）  → 2×2 池化
├─ 卷积块5：3×3,512（×3）  → 2×2 池化
└─ 全连接 4096 → 4096 → 1000（softmax）
```

设计要点：

**统一 3×3**：上一节已证，三个 3×3 感受野 = 7×7，参数少、非线性多。
**通道数每池化一次翻倍**（64 → 128 → 256 → 512）：空间缩小一半，用更多通道弥补信息。
**最后用大全连接层**（4096）聚合全局特征。

VGG 的遗产：**它成了"用预训练 VGG 提特征"的标准件**——目标检测（R-CNN 家族）、风格迁移、图像描述全用它当骨干。VGG 的代价：**参数集中在全连接层（约 1.38 亿），体积大、算力贵**——这推动了后来的"全卷积化"与 1×1 卷积压缩。

## 2 GoogLeNet：Inception 模块与多尺度

GoogLeNet 的思路是**"不知道哪种核大小最好，就全用"**——每个 **Inception 模块**并行跑 1×1、3×3、5×5 卷积与 3×3 池化，把四种结果在通道维拼接：

```text
输入特征图
├─ 1×1 卷积（64）────────────────┐
├─ 1×1 卷积（96）→ 3×3 卷积（128）────┤
├─ 1×1 卷积（16）→ 5×5 卷积（32）─────┤
└─ 3×3 最大池化 → 1×1 卷积（32）─────┘
              通道维拼接 → 输出 256 通道
```

三个关键技术：

**1×1 卷积降维**：每个分支前先接 1×1 卷积，把通道数压下去再算大的核——**"瓶颈"结构**大幅省参数。
**多尺度并行**：同一层同时捕捉小模式（1×1）、中模式（3×3）、大模式（5×5）。
**辅助分类器**：中间层加小分类头辅助梯度传播（缓解深层梯度消失）。

**GoogLeNet 22 层只有约 500 万参数**，而 VGG-16 约 1.38 亿——**多尺度 + 1×1 瓶颈让"深"变得"便宜"**。它的名字致敬 LeNet（GoogLeNet 是 Google 的 LeNet 梗）。

## 3 公式解析：1×1 卷积到底在做什么

**1×1 卷积看似"没用"（感受野就 1 像素），却是 GoogLeNet 的省钱核心。** 拆解它的作用：

**第一步，通道混合**：1×1 卷积核作用于输入的所有通道：$S(i,j) = \sum_{c} W_c \, I(i,j,c)$。它**不聚合空间信息，只重新加权组合通道**——把 $C_{in}$ 个通道线性映射到 $C_{out}$ 个通道。
**第二步，降维**：若 $C_{out} < C_{in}$（如 512 → 128），1×1 把"通道数"压缩——**信息量不变（可逆性不保证），计算量大减**。5×5 卷积本来要在 512 通道上算，现在先在 128 通道上算，乘法量降到原来的 $128/512 = 1/4$。
**第三步，非线性**：1×1 卷积后面接 ReLU，等于给"通道混合"加了非线性——提高表达能力。
**第四步，跨层连接**：1×1 还可做"通道维的线性变换 + 融合"，是 ResNet 瓶颈、SE 注意力、MobileNet 深度可分离卷积的共同构件。

**一句话：1×1 卷积是"通道维的全连接"——它把昂贵的空间卷积先投影到低维再做，是"深而省"的架构手术刀。**

## 4 深度与梯度：辅助分类器与批量归一化

深网络的两个工程障碍，GoogLeNet 用**辅助分类器**缓解，而下一节 ResNet 的残差连接从根上解决：

**梯度消失**：层深后，反向传播梯度逐层衰减，浅层学不动。GoogLeNet 在中间层挂辅助分类器（让梯度从中间也回流）；ResNet 用残差连接（梯度有"高速公路"直达浅层）。
**训练不稳定**：每层输入的分布随前层变化（内部协变量偏移），需要很小的学习率才能训。**批量归一化（Batch Normalization，BN）**在每层后把激活标准化为均值 0 方差 1，再用可学习的缩放平移恢复——它大幅加速训练、允许更大学习率，成为此后所有网络的标配。

**批量归一化的直觉：它把每一层的输入"拉回"到一个稳定分布，让网络不再依赖精细初始化与微小学习率。** BN 是继 ReLU 之后"深训练"的第二大功臣。<span class="marginnote">BN 在推理时的处理值得一提：训练时用 batch 的统计量，推理时用训练阶段累积的<strong>全局统计量</strong>（滑动平均）。很多初学者在"训练/推理不一致"上踩坑——BN 的均值和方差是固定的，不是每批重新算的。这个细节在部署量化模型时尤其关键。</span>

## 5 VGG vs GoogLeNet：两种深度的哲学

对比两条路线的设计取舍：

| 维度 | VGG | GoogLeNet/Inception |
| --- | --- | --- |
| 核心单元 | 统一 3×3 串联 | 多尺度并联 + 1×1 瓶颈 |
| 深度 | 16~19 层 | 22 层 |
| 参数 | 1.38 亿 | 500 万 |
| 计算量 | 高 | 低 |
| 设计哲学 | 极简重复 | 多尺度组合 |
| 后续影响 | 标准特征提取器 | Inception 系列、深度可分离思想的源头 |

**VGG 用"重复的力量"，GoogLeNet 用"组合的巧思"**——前者便于实现与迁移（所以火了），后者参数效率更高（所以进化成 Inception v2/v3/v4）。两条路后来在 ResNet 里合流：残差连接被加到 Inception 上（Inception-ResNet），而 VGG 的小核堆叠成为 ResNet 的主体。

## 6 更深网络的后续演进与启示

VGG/GoogLeNet 之后的"更深"探索，把"深度"推向极限：

- **ResNet（2015）**：残差连接解决退化——"深度从 19 层跳到 152 层"（下一节）。
- **DenseNet（2017）**：每层接所有前层（稠密连接）——"特征充分复用，参数更少"。
- **ResNeXt（2017）**：分组卷积 + 残差——"增加宽度比增加深度更划算"。
- **SENet（2018）**：通道注意力（SE 模块）——"让网络学会'关注哪些通道'"。

**"深"的三重收益**：

1. **表达力**：更深的非线性堆叠能表达更复杂的函数。
2. **层次化特征**：每层学到不同抽象层次（边缘 → 部件 → 物体）。
3. **感受野**：层数越多，每像素看到的范围越大。

**"深"的三重代价**：

1. **梯度问题**：深了梯度消失/爆炸（残差解决）。
2. **计算与内存**：深了贵（轻量网络解决）。
3. **数据需求**：深了要更多数据防过拟合（正则/预训练解决）。

**对学习者的启示**："更深"不是无脑堆——**"深度的收益有前提（残差、数据、算力）"**。VGG/GoogLeNet 的探索教会我们：**"架构创新的本质，是解决'更深的代价'（退化、梯度、算力）"**——每次"更深的成功"都是一次"代价的解救"。这个"代价-收益"框架，适用于理解所有架构演进。

## 7 小结

- **VGG**：清一色 3×3 + 2×2 池化，极简深堆，16~19 层；成为通用特征提取器，但全连接层参数巨大。
- **GoogLeNet**：Inception 模块并行 1×1/3×3/5×5 + 池化，1×1 卷积做瓶颈降维；22 层仅 500 万参数。
- **1×1 卷积 = 通道维全连接**：降维省算力 + 加非线性，是深而省的关键构件。
- **批量归一化**稳定深网络训练，是继 ReLU 之后"深训练"的第二功臣。
- VGG 串联合并、GoogLeNet 并联多尺度，两条"深"的哲学在 ResNet 合流。
