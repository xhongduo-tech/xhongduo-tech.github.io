# 潜在扩散模型（LDM）与 Stable Diffusion 架构

## 为什么从 LDM 开始

DDIM 把采样从 1000 步减到 50 步，但扩散模型仍然在**像素空间**里工作——每步都在处理一张大图（512×512×3），网络重、显存大、训练慢。**潜在扩散模型（Latent Diffusion Model，LDM，2022）**提出一个釜底抽薪的方案：**不在像素空间扩散，而在一个"低维潜空间"里扩散**。

LDM 的思路：

1. 用**自编码器（VAE）**把图像压缩进低维潜空间（512×512×3 → 64×64×4，缩小 64 倍）。
2. 在潜空间里做扩散（训练去噪网络）。
3. 生成时，从潜空间去噪，再用**解码器**把潜向量放大回图像。

**Stable Diffusion 就是 LDM 的著名实现**——它是第一个"普通 GPU 也能跑"的文本生成图像模型，引爆了 AIGC 时代。这一节把 LDM 的架构与为什么它"又快又省"讲清楚。<span class="marginnote">LDM 的论文标题是 "High-Resolution Image Synthesis with Latent Diffusion Models"。它的关键洞察：<strong>图像的"感知细节"（纹理、颜色）与"语义结构"（物体、布局）是可以分离的</strong>——VAE 编码器把感知细节"压"进潜空间（低维但保留了足够重建信息），扩散模型专注学"语义结构如何从噪声浮现"。<strong>"先在低维潜空间想清楚结构，再解码出细节"——这就是 LDM 既快又好的根本原因</strong>。</span>

## 1 LDM 的三阶段架构

LDM 由三部分组成：

1. **感知压缩（perceptual compression）**：VAE 编码器 $E$ 把图像 $x$ 压缩成潜向量 $z = E(x)$（如 64×64×4）；解码器 $D$ 把潜向量还原成图像 $\hat{x} = D(z)$。**这步负责"细节"**——压缩掉感知冗余，保留语义。
2. **潜空间扩散（latent diffusion）**：在潜向量 $z$ 上做标准的扩散训练——去噪网络 $\epsilon_\theta(z_t, t, c)$ 学"在潜空间去噪"。
3. **条件注入（conditioning）**：文本（或图像）条件 $c$ 通过**交叉注意力**注入去噪网络——**"文字指导潜空间怎么生成"**。

**分工**：VAE 管"感知细节的压缩与重建"，扩散管"语义结构从噪声浮现"，文本管"内容指令"——**三模块各司其职**。

## 2 为什么在潜空间扩散划算

**潜空间扩散的收益可以量化**：

- **维度降低**：64×64×4 vs 512×512×3——**潜空间的体素是像素空间的 $1/64$**（$8\times 8$ 的空间下采样 × 通道 4/3）。
- **计算量**：扩散网络的处理规模随空间维度平方下降——**每步计算约降两个数量级**。
- **训练与采样的整体成本**：训练更省、显存更低、采样更快——**"普通消费者 GPU 也能训/跑"**。

**代价**：VAE 的重建有损（潜空间不是像素的精确保真）——但感知压缩的损失对视觉几乎不可见（"感知等价"）。**"用感知不可察觉的压缩，换两个数量级的效率"**——这个交易太划算了。

## 3 交叉注意力：文本如何引导生成

LDM 的条件注入用**交叉注意力（cross-attention）**——把文本条件"注入"去噪网络的每个阶段：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left( \frac{Q K^T}{\sqrt{d}} \right) V
$$

- $Q$：来自去噪网络的**中间特征**（"当前潜空间的某块"）。
- $K, V$：来自**文本嵌入**（CLIP 文本编码器输出）。

**直觉**：潜空间的每一块特征作为"查询"，去文本里"找与它相关的词"，再按相关性"取"词的语义——**"画面的每个区域去文字里找它该是什么"**。交叉注意力让"一只猫在草地上"的文字精确地控制"哪里画猫、哪里画草地"。

**多阶段注入**：每个去噪块都有交叉注意力层——**文本指令在整个去噪过程中持续生效**（从粗结构到细纹理）。<span class="marginnote">交叉注意力是 LDM 连接文本与图像的桥梁——它的 QKV 结构与 Transformer 完全一致，只是"查询来自图像、键值来自文本"。<strong>这个"跨模态的交叉注意力"是 CLIP 之后多模态交互的标准接口</strong>——后文的 BLIP-2、LLaVA 也用它连接视觉与语言。理解了交叉注意力，就理解了"多模态模型怎么把两种模态融起来"。</span>

## 4 公式解析：LDM 的训练目标

**LDM 的训练目标与标准扩散几乎一样，只是"在潜空间"进行。** 拆解：

- **第一步，编码到潜空间**：$z_0 = E(x)$——图像 $x$ 经 VAE 编码器得潜向量 $z_0$。
- **第二步，潜空间加噪**：$z_t = \sqrt{\bar{\alpha}_t} z_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon$——在潜空间加噪声。
- **第三步，去噪损失**：

$$
\mathcal{L}_{LDM} = \mathbb{E}_{t, z_0, \epsilon, c} \left[ \lVert \epsilon - \epsilon_\theta(z_t, t, c) \rVert^2 \right]
$$

网络输入带噪潜向量 $z_t$、步数 $t$、条件 $c$，预测噪声 $\epsilon$——**与像素空间扩散的损失形式相同，只是数据从"像素"换成了"潜向量"**。
- **第四步，解码生成**：采样得到 $\hat{z}_0$ 后，用解码器 $D(\hat{z}_0)$ 放大回图像。

**一句话：LDM = "VAE 编码到潜空间 + 在潜空间做标准扩散 + 文本条件交叉注意力注入"——扩散的公式没变，变的只是"在哪里扩散"与"谁指导扩散"。**

## 5 Stable Diffusion 的生态

Stable Diffusion（LDM 的开放实现）构建了庞大的生态：

- **文生图**：文本 → 图像（基础能力）。
- **图生图**：输入图 + 文本 → 按指令修改。
- **ControlNet**：用边缘/姿态/深度图**精确控制生成结构**（"给骨架，生成动作"）。
- **LoRA/微调**：在 SD 上加小模块，定制风格/角色（"一个人的 LoRA 学会画他"）。
- **Inpainting/Outpainting**：修复、扩展画面。

**Stable Diffusion 的意义**：把"文生图"从研究变成**大众工具**——开源的模型、权重与生态让 AIGC 成为现实。<span class="marginnote">把 LDM 与全书主线连接：LDM 的"VAE 压缩 + 扩散生成"是"感知/语义分离"思想的极致——与 SMPL 的"参数压缩人体"、CLIP 的"语义空间"同构：<strong>"先压缩到低维语义空间，再在低维空间操作"是高效生成与理解的通用配方</strong>。而 Stable Diffusion 的交叉注意力与后文 BLIP-2/LLaVA 的视觉-语言桥接完全同源——<strong>LDM 既是图像生成的王者，也是多模态大模型的近亲</strong>。</span>

## 6 Stable Diffusion 的工程实践与局限

使用 Stable Diffusion 系模型的工程要点：

- **CFG（Classifier-Free Guidance）强度**：采样时"无条件 + 条件"的差值被放大——**CFG 越大越贴文本但越"过曝"**（饱和、不自然）。典型 5~8，按需调。**"CFG 是文本遵从度与图像质量的旋钮"**。
- **分辨率与步数**：SD 训练分辨率（512/768）内生成最稳；超分辨率要额外模型（upscaler）——**"生成分辨率要匹配训练分布"**。采样步数 20~50（DPM-Solver 类），步数少快但糙。
- **种子与确定性**：同一 seed 生成同一结果——**"seed 是潜空间采样点"**，调 seed 是"换一张"的标准操作。
- **负面提示（negative prompt）**：CFG 里把"不要的东西"（模糊、畸形）作为无条件端——**"负面提示是 SD 的实用魔法"**。

**SD 的局限**：

- **文字渲染弱**：SD 早期画不清文字（"招牌上的字是鬼画符"）——**"文本渲染"是扩散模型的通病**（新模型在改善）。
- **结构可控性差**：裸 SD 对"空间布局、姿势"控制弱——**ControlNet（用边缘/深度/骨架控制）** 补上结构控制。
- **身体畸形**：手指、手部细节常错——**"细节生成是扩散的软肋"**，靠负面提示 + 后处理缓解。
- **计算成本**：多步采样 + 大 U-Net，实时仍难——**少步采样（LCM、SD-Turbo）** 在推进。

**SD 与全书主线的连接**：SD 是"LDM + CLIP 文本编码器 + U-Net 去噪"的拼装——**它把本专题几乎所有的构件（自编码器、Transformer、CLIP、扩散）合成一个产品**。**"基础模型 = 组件复用 + 巧妙拼装"**——理解 SD 的每个部件，就理解了现代 AIGC 的底层逻辑。

## 7 小结

- **LDM** = VAE 压缩到潜空间 + 潜空间扩散 + 条件注入——"不在像素空间扩散"。
- **感知压缩**：VAE 管细节，扩散管语义结构——两模块分工。
- **效率**：潜空间 $1/64$ 的体素，计算降两个数量级——"普通 GPU 可跑"。
- **交叉注意力**：潜空间特征"查"文本——文本指令指导生成。
- **Stable Diffusion**：LDM 的开放实现，文生图/图生图/ControlNet/LoRA 生态。
- 意义："先在低维想清楚结构，再解码出细节"——高效生成的通用配方。
