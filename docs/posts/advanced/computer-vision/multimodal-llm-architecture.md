## 为什么从多模态大模型架构开始

LLaVA 示范了"视觉 + LLM"的一种实现。但多模态大模型（Multimodal Large Language Model，MLLM）是一个**家族**——GPT-4V、Gemini、Claude、Qwen-VL、LLaVA……它们的架构虽有差异，却共享同一个骨架：**视觉编码器 + 桥接模块 + LLM**。这一节把"桥接"这个核心问题系统讲透——它是多模态大模型架构设计的枢纽。

核心问题只有一个：**怎么把"图像"变成 LLM 能读的"输入"？** 答案分两条路线：

- **投影桥接（projection）**：把视觉特征映射到 LLM 的词嵌入空间（LLaVA 的线性投影、BLIP-2 的 Q-Former）。
- **原生多模态（native）**：把图像标记直接与文本标记一起，在同一个 Transformer 里训练（Gemini、Chameleon）。

理解架构，才能理解多模态大模型"能做什么、不能做什么、为什么"。<span class="marginnote">多模态大模型的历史分水岭是 2023 年 GPT-4V 的发布——它把"读图"与"语言推理"首次大规模融合。此后 MLLM 的演进极快（Gemini、LLaVA-1.5、Qwen-VL、InternVL、GPT-4o）——<strong>但万变不离其宗：视觉编码器提供"看"，LLM 提供"想"，桥接负责"让想的人看得懂"</strong>。理解这个骨架，就能理解任何 MLLM。</span>

## 1 统一的骨架：编码器 + 桥接 + LLM

几乎所有 MLLM 共享三段式骨架：

1. **视觉编码器（vision encoder）**：CLIP/DINOv2 预训练的 ViT——把图像编码成视觉特征（"看"）。
2. **桥接模块（connector / projector）**：把视觉特征变成 LLM 能读的"视觉标记"（"翻译"）。
3. **大语言模型（LLM）**：读"视觉标记 + 文本标记"，推理并生成回答（"想与说"）。

**视觉编码器决定"能看到多细"，LLM 决定"能想到多深"，桥接决定"视觉信息无损地传给 LLM"**——三者的配合决定模型整体能力。**升级任何一环都能提升模型**（这也是为什么"换更大的 LLM"、"换更强的视觉编码器"是 MLLM 迭代的常见路径）。

## 2 桥接的两条路线

**路线一：投影桥接（projector-based）**——把视觉特征"翻译"成文本嵌入：

- **线性投影（linear）**：LLaVA——视觉特征过一层线性映射，直接当词嵌入。**简单高效**，但视觉信息压缩在固定数量标记里。
- **MLP 投影（MLP）**：LLaVA-1.5——线性换成两层 MLP，**表达能力更强**（视觉细节更保真）。
- **Q-Former（query）**：BLIP-2——可学习查询压缩视觉特征。**标记数少（32 个）**，适合"借冻结 LLM"。

**路线二：原生多模态（native / interleaved）**——图像与文本标记在**同一个 Transformer**里统一处理：

- **Gemini / Chameleon**：视觉标记与文本标记混合成一个序列，训练整个模型——**没有"桥接层"，模型自己学会跨模态**。
- 优点：信息无压缩损失、模态间关系由模型自由学习。
- 代价：**训练成本高**（整个模型全模态训练）、实现复杂。

**"投影桥接"与"原生"的本质区别**：**前者把视觉"翻译"成语言（模型看到的是"语言化的视觉"），后者让模型在"原生的多模态"里训练**——前者省、后者强，两者在工程上各有拥趸。

## 3 公式解析：桥接的"标记压缩"与信息损失

**"视觉标记的数量"为什么是多模态架构的关键参数？** 拆解。

- **第一步，视觉特征量**：CLIP ViT 对 336×336 图输出 576 个标记（patch 数 + [CLS]）。
- **第二步，标记压缩**：投影/Q-Former 把 576 个标记压缩成 $N$ 个（LLaVA 用 576 全保留或 256，BLIP-2 用 32）——**喂给 LLM 的标记数从 576 到 32 不等**。
- **第三步，权衡**：标记多 → **信息全**（细粒度、小物体、OCR 好）但 **LLM 计算贵**（自注意力随标记数平方增长）；标记少 → 计算省但**视觉信息被压缩**（细节丢）。
- **第四步，LLM 的上下文长度**：LLM 能处理的标记有限——576 个视觉标记 + 文本可能超长。**"标记预算"成为架构设计的中心约束**——这也是为什么高分辨率（更多标记）需要专门的压缩策略。

**一句话：桥接的本质是"在信息保真与计算成本之间分配标记预算"——视觉标记数是多模态架构最关键的设计旋钮。**

## 4 视觉编码器的选择：CLIP vs DINOv2 vs 更高分辨率

视觉编码器的选择同样关键：

- **CLIP 特征**：语义对齐文本——**适合"理解图里是什么"**（回答、描述）。
- **DINOv2 特征**：结构丰富——**适合"精细空间/几何"**（分割、对应、细节）。
- **高分辨率编码**：把图切成多个 patch（或分块放大）——**提升小物体与 OCR**，代价是标记数暴增。

**现代 MLLM 常用组合**：**CLIP 管语义 + DINOv2 管结构**，两个视觉编码器的特征拼接——"双编码器"让模型既懂"是什么"又懂"在哪、多细"。

**编码器选择的影响**：**"看的能力"决定了模型的地基**——CLIP 学不到的细节（空间关系、精细纹理），LLM 再聪明也"看不到"。**升级视觉编码器是提升 MLLM 最直接的手段之一**。

## 5 训练流程：预训练对齐 + 指令微调

MLLM 的标准训练流程（LLaVA 家族）：

1. **预训练（对齐）**：冻结视觉编码器与 LLM，训桥接层——用"图 + 描述"数据，让桥接学会"把视觉翻译成 LLM 能懂的标记"。
2. **指令微调（SFT）**：解冻 LLM（与桥接），用"图 + 指令 + 回答"数据微调——让模型学会"按指令看图回答"。
3. **（可选）偏好对齐（RLHF/DPO）**：用人类偏好数据，让回答更符合用户期望、更少幻觉。

**训练的数据配方**决定能力边界：**预训练数据（对齐质量）+ 指令数据（任务广度）+ 偏好数据（行为质量）**——三个阶段的燃料各不相同。<span class="marginnote">把 MLLM 架构与全书主线连接：视觉编码器 = CLIP/DINOv2（前文基础模型）；桥接 = Q-Former/投影（BLIP-2/LLaVA）；LLM = 大语言模型（大模型原理专题）；训练 = 预训练-微调-对齐（迁移学习 + 大模型对齐）。<strong>多模态大模型是全书所有主线（视觉基础模型 + 语言大模型）的最终汇合</strong>——它把"看"（本专题的全程）与"想"（大模型）装进一个模型，是"从极限到大模型"这条主线在视觉侧的终点。</span>

## 6 多模态大模型的评测与安全考量

多模态大模型（MLLM）的评测与安全，是它能否真正被信任的关键：

**评测维度**：

- **综合能力基准**：MMBench、MM-Vet、MMMU——把能力拆成"感知、OCR、推理、知识"等维度打分——"**能力剖面**比单一分数有意义"。
- **细粒度任务**：TextVQA（读图里的字）、MathVista（图表数学）、ChartQA（图表理解）——"**专测某类能力的压力测试**"。
- **对齐与偏好**：人类偏好评测（有用性、无害性）——"**'好回答'不等于'正确回答'**"。

**安全考量**：

- **幻觉**：MLLM 会"编造"图里没有的内容（前文详述）——"**安全的关键不是更强，而是更诚实**"。
- **偏见**：训练数据偏见在图文场景放大（性别/种族/文化）——"**多模态让偏见更隐蔽**"。
- **滥用**：图像理解可被用于监控、伪造、绕过内容审核——"**能力的双刃剑**"。
- **隐私**：MLLM 处理图像可能泄露个人信息——"**图像即隐私**"。

**MLLM 的定位**：它是"视觉 + 语言"的最终融合形态——**"一个模型能看、能说、能想"**。它的能力来自"视觉基础模型（看）+ 大语言模型（想）+ 桥接（连）"，它的风险也来自这两者的叠加。**"技术的终点不是'更强'，而是'可靠'"**——评测与安全，是 MLLM 走向真实世界的必经关。

**一个实用的心智模型**：遇到任何 MLLM 论文，先回答三个问题——"**它用什么看（编码器）？怎么连（桥接）？用什么想（LLM）？**"——"**编码器决定'看到多细'，桥接决定'信息传多少'，LLM 决定'想到多深'**"。用这个框架读 MLLM，任何新模型都逃不出你的理解——"**架构的骨架只有那三块，变体都是三块的排列组合**"。

**本专题的收束**：多模态大模型是计算机视觉在本书中的"终点站"——从成像几何、底层图像处理出发，经过特征、几何、三维、深度学习、Transformer、基础模型、生成模型，最终汇聚到"一个能看、能说、能想的模型"。它也是"从极限到大模型"这条主线在视觉侧的完成——**"视觉的所有积累，最终都化成了'理解图像'的一种能力"**。这也是为什么本书把计算机视觉放在第四级高阶专题：它不是孤立的技术清单，而是一条从"像素"通向"智能"的完整道路。

下一节（也是本专题的最后一节）将回答"这条路走到了哪、哪里还不可靠"——多模态模型的评测与幻觉问题。

## 7 小结

- **MLLM 骨架**：视觉编码器（看）+ 桥接（翻译）+ LLM（想与说）。
- 桥接两路线：**投影**（线性/MLP/Q-Former，省）与**原生**（统一序列训练，强）。
- **视觉标记数** = 信息保真与计算成本的权衡——架构的关键旋钮。
- 视觉编码器：CLIP（语义）+ DINOv2（结构）——"双编码器"更全。
- 训练三阶段：**预训练对齐 → 指令微调 → 偏好对齐**。
- 多模态大模型 = 视觉基础模型 + 语言大模型的最终汇合。
