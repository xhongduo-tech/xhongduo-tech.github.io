## 为什么从三维表示开始

图像有天然网格（像素），卷积直接可用。但三维数据没有统一的"网格"——**怎么把三维世界喂给神经网络？** 这个"表示选择"问题决定了后续一切。历史上三条路：

- **体素（voxel）**：把空间规则地网格化，像"3D 像素"——直观但**内存爆炸**（分辨率每翻倍、体素数乘 8）。
- **多视图**：把 3D 渲染成多张 2D 图，用 2D CNN——简单但丢失 3D 结构。
- **点云网络（PointNet 等）**：直接吃原始点云——**最原生、最高效，但要解决"无序性"这个根本挑战**。

**PointNet（2017）**证明了"直接用点云"可行，用**对称函数**解决无序性；**PointNet++** 补上局部结构，成为点云深度学习的基石。这一节把"表示选择"与"PointNet 家族"讲透。<span class="marginnote">为什么点云网络"迟到"了？因为 CNN 时代大家都默认"输入得是规则的"——点云的无序性让卷积无处下刀。PointNet 的贡献是证明：<strong>只要设计一个对"点的顺序不变"的函数（对称函数），无序点云就能直接进网络</strong>。这个"对称性设计"思想，与 CNN 的"平移不变性"、Transformer 的"置换不变性"一脉相承——<strong>"先想清楚你要什么不变性，再设计网络"是深度学习的元方法论</strong>。</span>

## 1 体素：规则的 3D 网格

**体素表示（voxel representation）**把三维空间划分成规则立方体网格，每个格子存"有没有点"（占用）或"点的聚合特征"（密度）。它把 3D 卷积直接套用：

- **3D CNN**：3D 卷积核在体素网格上滑动，与 2D 卷积完全同构。
- **优点**：规则、有序，2D 卷积的所有工具（池化、BN）直接迁移。
- **致命缺点**：**内存按 $O(N^3)$ 增长**——128³ 体素 = 200 万格，256³ = 1600 万格。分辨率与内存不可兼得。
- **缓解**：**八叉树（octree）**、**稀疏卷积（sparse convolution）**——只在有内容的体素上计算（MinkowskiEngine、TorchSparse 等）。

**体素的定位**：空间规则但"浪费"（大部分体素是空的）。它在自动驾驶的 3D 检测（VoxelNet、PointPillars）里仍被广泛使用——因为 LiDAR 点云在空旷场景里稀疏，稀疏卷积刚好高效。

## 2 PointNet：对称函数解决无序性

**PointNet** 的核心设计：**用对称函数聚合所有点的信息，使输出与点的顺序无关**。

分类网络结构：

$$
f(\{x_1, x_2, \ldots, x_n\}) = \gamma\left( \max_{i} \left( h(x_i) \right) \right)
$$

- $h$：共享的 MLP，把每个点 $x_i \in \mathbb{R}^3$（+颜色等）映射到高维特征。
- $\max$：**逐元素最大池化**——对 $n$ 个点的特征逐维取最大。**max 是置换不变的**（顺序怎么打乱，逐维最大值不变），且是"对称函数"。
- $\gamma$：再过一个 MLP，得到分类结果。

**为什么 max 池化够用**：分类只需知道"有没有某个特征"（比如"这簇点里有尖锐凸起"）——max 恰好提取"最强烈证据"。**PointNet 用"每点独立特征 + 全局 max"证明：无序点云可以端到端学习**。

PointNet 还做两件配套：

- **T-Net（空间变换网络）**：预测一个变换矩阵，把输入点云"对齐"到规范姿态——**对旋转鲁棒**（网络自己学出"转正"）。
- **分割**：把全局 max 特征与每个点的局部特征拼接，实现逐点分类。

**PointNet 的局限**：它只看"全局最强烈特征"，**忽略了局部结构**——两个形状不同的物体可能因为"最尖锐的特征相同"而被混淆。这引出了 PointNet++。

## 3 PointNet++：分层局部聚合

**PointNet++** 补上局部结构，用**分层采样-分组-聚合**模拟 CNN 的"局部感受野 + 层级抽象"：

1. **采样**（最远点采样）：选一组"均匀散布"的代表点。
2. **分组**：每个代表点找邻域内的点构成一个"局部点集"（相当于 CNN 的感受野）。
3. **聚合**：对每个局部点集跑一个小 PointNet（共享），得到该局部的特征。
4. **分层**：重复"采样-分组-聚合"，局部特征逐步抽象成全局——**深层的局部对应"更大的区域"**。

**PointNet++ = PointNet 的"卷积化"**——局部 PointNet 就是"3D 卷积核"，分层结构就是"加深网络"。它解决了 PointNet 对局部结构无感的问题，成为点云分类/分割的标准骨干。

## 4 公式解析：为什么 max 池化是置换不变的

**"max 为什么能当对称函数"是这个领域的第一个证明题。** 拆解：

- **第一步，置换不变的定义**：函数 $f$ 对输入点集置换 $\sigma$ 不变：$f(\{x_1,\ldots,x_n\}) = f(\{x_{\sigma(1)},\ldots,x_{\sigma(n)}\})$。
- **第二步，max 的性质**：$\max(a_1, \ldots, a_n)$ 不依赖元素的顺序——$\max$ 的结果只看"数值集合"，与排列无关。**逐维 max 同理：每个维度独立取最大，顺序无关。**
- **第三步，组合**：$\gamma(\max_i h(x_i))$ 中，$h(x_i)$ 是逐点的（每点独立），$\max$ 是置换不变的，$\gamma$ 是单变量函数——**整个复合函数对点序置换不变**。
- **第四步，表达能力**：为什么"逐维 max"够用？任意对称函数都可以用"逐点映射 + max"近似（PointNet 论文有理论证明：连续对称函数可被这类结构任意逼近）——**max 池化不是"碰巧有效"，而是理论上完备的对称聚合**。

**一句话：max 池化"只看集合不看顺序"，配合逐点 MLP 与后处理 MLP，构成了置换不变且表达完备的点云网络——这是 PointNet 的数学根基。**

## 5 现代三维深度学习

PointNet 之后的演进：

- **注意力/Transformer 点云**（PCT、Point Transformer）：用自注意力替代 max 池化，建模点间长程关系——更强但更贵。
- **隐式表示**（Occupancy Network、NeRF）：用神经网络直接表示连续 3D 场，不依赖离散点/体素——"任意分辨率、无网格"（下一节）。
- **3D 生成**（Point-E、Shape-E）：扩散模型直接在点云/隐式场上生成 3D。
- **3D 基础模型**：从文本/图像生成 3D、开放词汇 3D 分割——三维视觉正在复制 2D 的"基础模型"路线。

**表示选择的现代答案**：**显式（点云/网格）保真高效，隐式（神经场）灵活连续**——两者互补，现代系统（如 3DGS）甚至混合使用。<span class="marginnote">把三维表示的选择与全书主线连接：图像用"规则网格"（卷积）、点云用"无序集合"（max/注意力）、体素用"规则 3D 网格"（3D 卷积）、神经场用"连续函数"（MLP/哈希）——<strong>"怎么表示数据"决定了用什么网络结构</strong>。PointNet 的"对称函数"、Transformer 的"置换不变性"、CNN 的"平移不变性"，都是"先定不变量、再设计网络"的同一方法论。</span>

## 6 3D 深度学习的任务与应用

PointNet 系网络支撑的 3D 深度学习任务，是理解"为什么需要它们"的关键：

- **3D 分类/分割**：点云分类（这个物体是什么）、语义/实例分割（点云逐点分类）——**PointNet 系列的主战场**（自动驾驶的点云语义分割、物体识别）。
- **3D 检测**：在点云里找物体框（自动驾驶的 LiDAR 3D 检测——VoxelNet/PointPillars 用体素 + 稀疏卷积）——"点云检测是自动驾驶的核心感知"。
- **3D 配准的深度学习化**：学习特征点 + 匹配做点云配准（替代手工 FPFH）——"PointNet 特征让配准更鲁棒"。
- **3D 生成**：用点云/隐式场做生成（Point-E、Shape-E）——"生成模型 + 点云表示"。
- **场景理解**：室内点云的分割、物体关系理解——"点云是机器人/AR 的场景语言"。

**点云 vs 图像 vs 体素的生态位**：

| 表示 | 优点 | 缺点 | 主导任务 |
| --- | --- | --- | --- |
| 点云 | 原生、高效、无网格化 | 无序、稀疏 | LiDAR 感知、配准 |
| 体素 | 规则、可直接卷积 | 内存 $O(N^3)$ | 3D 检测（稀疏卷积缓解） |
| 多视图 | 复用 2D CNN | 丢 3D 结构 | 3D 检索/识别 |
| 隐式场 | 连续、任意分辨率 | 需查询、难编辑 | NeRF、3D 重建 |

**3D 深度学习的趋势**：与 2D 平行——**从"手工特征"到"学习表示"到"基础模型"**。3D 点云 Transformer（PCT、Point Transformer）正在追赶 2D 的 Transformer 化；**"多模态（图像 + 点云 + 文本）融合"** 是自动驾驶与机器人感知的主流。理解 PointNet 的"对称函数"设计，是进入整个 3D 深度学习的入口。

## 7 小结

- **三维表示三路线**：体素（规则但 $O(N^3)$ 内存）、多视图（丢 3D 结构）、点云（原生但无序）。
- **PointNet**：逐点 MLP + **max 池化**（对称函数）+ T-Net 对齐——置换不变且表达完备。
- **max 池化**只看数值集合、不看顺序，是理论上完备的对称聚合。
- **PointNet++**：分层"采样-分组-聚合"，局部 PointNet 模拟感受野——补上局部结构。
- 现代：注意力点云、隐式神经场（NeRF）、3D 生成与基础模型；显式与隐式互补。
