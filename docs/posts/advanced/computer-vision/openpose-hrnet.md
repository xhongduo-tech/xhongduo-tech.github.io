## 为什么从 OpenPose 与 HRNet 开始

上一节我们把多人姿态估计分成自顶向下与自底向上两派。这一节深入两派各自最具代表性的工作：

- **OpenPose（2017）**：自底向上的集大成者。它用**部件亲和场（PAF）**解决了"把关节组装成人"这个自底向上的核心难题，首次让多人实时 2D 姿态估计成为可能，也引爆了"姿态 → 行为 → 交互"的应用浪潮。
- **HRNet（2019）**：自顶向上的精度巅峰。它**始终维持高分辨率特征图**，拒绝"编码-解码先降再升"的做法，在多人姿态与关键点定位上全面刷新纪录，成为姿态估计的精度标准。

一个解决"分组难"，一个解决"分辨率丢"——它们是自底向上与自顶向下两条路各自的"标准答案"。<span class="marginnote">OpenPose 是 CMU 曹哲团队的工作，一经开源就成为视觉应用的现象级工具（舞蹈教学、康复、游戏动作捕捉）。HRNet 是清华孙可团队（微软亚洲研究院）的工作，它的高分辨率设计后来也用于分割与检测。<strong>两个方法代表了两条范式的极致，理解它们就理解了 2D 姿态估计的技术全貌</strong>。</span>

## 1 OpenPose 的三要素

OpenPose 的完整流程：

1. **热图分支（heatmap）**：输出所有关键点的热图——"每个关节可能在哪些位置"。
2. **PAF 分支（Part Affinity Fields）**：输出**关键点之间的连接向量场**——"相邻关节之间，肢体朝哪个方向"。
3. **二分匹配组装**：用热图找关节候选，用 PAF 的积分评估"两个候选关节构成肢体"的置信度，再用匈牙利算法做全局最优配对。

**PAF（部件亲和场）是 OpenPose 的灵魂**：它不只是告诉网络"左肘在哪、左腕在哪"，还告诉网络**"从肘到腕的肢体路径上的方向向量"**。有了方向，网络就能判断"这个肘配那个腕是不是同一只手臂"——**把"关节-关节的配对"变成"沿肢体路径的积分匹配"**。

## 2 PAF：让网络"看见"肢体

**部件亲和场（Part Affinity Field，PAF）**定义：对相邻关节对 $j_1, j_2$（如肘-腕），肢体上每个像素被赋予一个**单位方向向量** $\mathbf{v}$：

$$
\mathbf{v} = \frac{\mathbf{x}_{j_2} - \mathbf{x}_{j_1}}{\lVert \mathbf{x}_{j_2} - \mathbf{x}_{j_1} \rVert}
$$

即"从肘指向腕"的方向。网络为每对相邻关节输出一张"方向场图" $L_c$——**它编码了肢体的位置与方向**。

组装时，对候选关节 $d_1$（肘）与 $d_2$（腕），评估"它们是否构成一个肢体"的置信度 = **沿两点连线的 PAF 场积分**：

$$
E = \int_{u=0}^{1} L_c\left( \mathbf{p}(u) \right) \cdot \frac{d_2 - d_1}{\lVert d_2 - d_1 \rVert} \, du
$$

如果连线上的方向场与"肘→腕"方向一致（点积大），置信度高——**PAF 把"组装判断"变成了"路径积分"，同时利用了位置与方向两种证据**。

**PAF 的洞见**：纯热图只知道"关节在哪"，不知道"关节属于谁"；PAF 用"肢体方向"这个中间表示，把"配对"问题变成网络可以直接监督学习的任务。<span class="marginnote">为什么 PAF 比"先找关节再拼"更鲁棒？在拥挤场景里，两个人的肘都在热图上有峰，用方向场一"扫"，谁连谁就清楚了——因为方向场区分了"这条手臂朝这边"与"那条手臂朝那边"。<strong>PAF 是"把关系变成场"的经典</strong>：从"点与点的关系"到"场与场的匹配"，鲁棒性来自"场"的连续性与方向性。</span>

## 3 HRNet：高分辨率一路到底

**HRNet（High-Resolution Net）**的核心思想：**不做"先降分辨率再升回来"的编码-解码，而是始终并行维持高分辨率分支**。

传统编码-解码（Hourglass、U-Net 的编解码）：

```
高分辨率 → 逐级下采样 → 低分辨率 → 逐级上采样 → 高分辨率
（先压缩语义、再恢复细节，U 形 / 沙漏结构）
```

HRNet 的结构：

```
高分辨率分支 ────────────────────────── 输出
中分辨率分支 ── 阶段间反复融合交换 ────── 输出
低分辨率分支 ────────────────────────── 输出
（多分支并行，高分辨率始终保留）
```

**HRNet 并行多个分辨率的分支，各分支之间反复融合（交换信息）**：高分辨率分支始终存在，细节不被"压扁再放大"。它的三个特点：

**全程高分辨率**：空间细节不丢，关键点定位更准。
**跨分辨率信息交换**：低分辨率分支提供语义，高分辨率分支保持细节，融合（像 FPN 的跨尺度）。
**无需上采样重建**：没有"信息压缩-恢复"的损失。

**HRNet 的姿态精度**：在 COCO 关键点数据集上显著超过 Hourglass 等编码-解码方法——**"不降分辨率"比"降了再升"更保真**。

## 4 公式解析：HRNet 的跨分辨率融合

**HRNet 的"并行分支交换信息"在做什么？** 看两条分支之间的融合。

**第一步，两分支状态**：设高分辨率特征 $X_h \in H\times W\times C_h$、低分辨率特征 $X_l \in \frac{H}{2}\times\frac{W}{2}\times C_l$。
**第二步，高→低**：$X_h$ 经 $3\times3$ stride-2 卷积降采样，得到与 $X_l$ 同尺寸的特征，**逐元素相加**——低分辨率分支"吸收"高分辨率的信息。
**第三步，低→高**：$X_l$ 经双线性上采样 + 1×1 卷积升到与 $X_h$ 同尺寸，**逐元素相加**——高分辨率分支"吸收"低分辨率的语义。
**第四步，反复交换**：这个"上下互换 + 相加"在多个阶段反复进行——**每个分辨率分支逐步汇集所有尺度的信息**，形成"既高分辨又全尺度"的特征。

**一句话：HRNet 的融合 = 每个分支都把自己"升级/降级"成邻居的尺寸再相加——多分辨率信息在并行结构里持续对流，没有一次性的"压缩-重建"。**

## 5 两派会师：现代多人姿态估计

OpenPose 与 HRNet 代表了"自底向上 vs 自顶向下"的经典二分，但现代方法正在融合：

**HigherHRNet**：HRNet 的多人版——高分辨率 + 反卷积上采样，同时解决"小人（多人小目标）"与"大姿态"。
**DEKR / CenterGroup**：把多人姿态变成"中心点 + 关节回归"（CenterNet 思路）——**"自底向上的关节 + 自顶向下的中心"混合**。
**RTMPose / ViTPose**：Transformer 姿态估计，把 HRNet 的高分辨率与注意力的全局建模结合。

**趋势**：精度由"高分辨率 + 注意力"共同决定，速度由"自底向上的单次前向"保证——**"一次前向 + 高分辨率 + 关系建模"正在成为新的标准配方**。<span class="marginnote">把姿态估计的技术演进与全书主线对照：热图回归（分布编码）来自关键点定位；PAF 的"场表示关系"呼应光流里的"矢量场"；HRNet 的高分辨率设计呼应 DeepLab 空洞卷积的"保分辨率"；注意力组装呼应 DETR 的查询匹配。<strong>姿态估计是全书大部分技术的"集成测试"——每个部件都能在它身上找到对应物</strong>。</span>

## 6 姿态估计的工程实践与下游应用

姿态估计（OpenPose/HRNet）的工程与下游，几个关键：

**工程实践**：

- **多人后处理**：自顶向下要"先检测再单人"（检测框漏人则姿态丢）；自底向上要"热图峰值 + PAF 组装 + 匈牙利匹配"——**"后处理链条长、易错，要逐环节调试"**。
- **热图峰值提取**：找峰值（局部极大）→ 亚像素精化 → 按阈值过滤低置信度——**"峰值提取的质量直接决定关键点质量"**。
- **姿态归一化**：多人姿态要按"检测框/人体尺度"归一化再比较（OKS 已讲）——**"尺度归一化是公平比较的前提"**。
- **实时性**：OpenPose 在 CPU 上慢、HRNet 更慢——**"移动端姿态估计要用轻量版（MobileNet 骨架 + 精简头）"**。

**下游应用**：

- **行为识别**：姿态序列 → 动作分类（"走路 vs 跑步"看关节轨迹）——"姿态是行为的低维表示"。
- **人机交互**：手势/肢体姿态 → 控制指令（体感游戏、手语识别）。
- **体育分析**：姿态 → 动作质量评估（跳高角度、挥拍速度）。
- **动画/游戏**：姿态 → 驱动虚拟角色（mocap 的低成本替代）。
- **康复医学**：姿态 → 关节活动度评估（远程康复监控）。

**姿态估计与现代趋势**：**3D 姿态**（从 2D 关键点 + SMPL 恢复 3D）与**视频姿态**（时序一致性）是两大方向——**"2D 姿态是基础、3D 姿态是目标、行为理解是终点"**。姿态估计从"找关节"走向"理解人体"，与后文的具身智能、行为识别无缝衔接。

## 7 小结

- **OpenPose**：自底向上多人姿态，热图找关节 + **PAF 组装** + 匈牙利匹配。
- **PAF** = 肢体方向场：沿连线积分判断"两个关节是否构成肢体"，用方向消解拥挤歧义。
- **HRNet**：自顶向下精度标杆，**并行多分辨率分支 + 跨分辨率信息交换**，全程保高分辨率。
- HRNet 融合 = 各分支"升级/降级到邻居尺寸再相加"，信息持续对流。
- 会师：HigherHRNet、CenterGroup、ViTPose——"一次前向 + 高分辨率 + 注意力"成新标准。
