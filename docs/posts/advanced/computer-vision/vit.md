## 为什么从 ViT 开始

卷积是视觉几十年的默认工具，但 2020 年一篇论文提出了一个近乎挑衅的问题：**如果图像可以被当作"一串词"来处理，我们还需要卷积吗？** **ViT（Vision Transformer，2021）**的回答是：不需要。它把图像切成固定大小的**分块（patch）**，每个分块当一个"标记"，直接用纯 Transformer 的注意力做图像分类——**在大规模数据上，ViT 超过了最好的 CNN**。

ViT 的意义是范式性的：它证明"注意力可以完全取代卷积"，为视觉打开了一条与 NLP 统一的道路——**同一个 Transformer 架构，既能处理文本也能处理图像**。它是后续一切视觉 Transformer、视觉基础模型（CLIP、SAM、DINO）的共同起点。<span class="marginnote">ViT 论文的标题是 "An Image is Worth 16×16 Words"（一张图像值 16×16 个词）——标题本身就是它的全部主张：图像可以被切成一串"词"，然后用处理词的模型处理图像。<strong>ViT 的简洁性极具欺骗性：结构几乎就是标准 Transformer，唯一的视觉改造是"图像分块"</strong>。这种"极简改造 + 全面成功"正是它影响力巨大的原因。</span>

## 1 从图像到标记：Patch Embedding

ViT 的第一步是把图像变成"标记序列"——**Patch Embedding**：

1. **切块**：把 $H\times W\times 3$ 的图像切成 $N$ 个 $P\times P$ 的分块（$N = HW/P^2$）。标准设置：$224\times224$ 图、$P=16$ → $14\times14 = 196$ 个分块。
2. **展平 + 线性投影**：每个分块展平成 $P^2 \cdot 3$ 维向量，过**线性投影（可学习的矩阵）**映射到 $d$ 维嵌入——得到 196 个 $d$ 维标记。
3. **加位置编码**：给每个标记加一个**可学习的位置嵌入（position embedding）**——告诉模型"这个分块在图像的哪个位置"。

$$
\mathbf{z}_0 = [\mathbf{x}_{\text{cls}}; \mathbf{E}\mathbf{p}_1; \mathbf{E}\mathbf{p}_2; \cdots; \mathbf{E}\mathbf{p}_N] + \mathbf{E}_{\text{pos}}
$$

- $\mathbf{E}\mathbf{p}_i$：第 $i$ 个分块的线性投影。
- $\mathbf{x}_{\text{cls}}$：一个**可学习的类别标记（[CLS] token）**，位置 0——它的最终表示用于分类（类比 BERT 的 [CLS]）。

**"切块 + 投影 + 位置编码"**是 ViT 对图像的全部改造——之后就是标准 Transformer 编码器。

## 2 编码器与分类头

ViT 把 196+1 个标记送入标准 **Transformer 编码器**——$L$ 层，每层是：

1. **LayerNorm + 多头自注意力**（全局交互）。
2. **残差连接**（$x + \text{Attn}(x)$）。
3. **LayerNorm + MLP**（前馈网络，两层全连接 + GELU）。
4. **残差连接**。

经过 $L$ 层后，**[CLS] 标记的最终表示**汇聚了全局信息（它通过注意力"看过"所有分块），再接一个分类头：

$$
\mathbf{y} = \text{softmax}(W \, \mathbf{z}_L^{\text{cls}})
$$

**分类 = 读 [CLS] 标记的输出**——这是 BERT 风格的标准做法，也让 ViT 的训练目标与分类任务直接对齐。

## 3 ViT 需要的"三件套"：数据、预训练、微调

ViT 论文最重要的实证结论：**ViT 在小数据上不如 CNN，在大数据上反超 CNN**。

- **在 ImageNet（128 万张）上**：ViT 略逊于 ResNet——因为**注意力没有卷积的"平移不变性"归纳偏置**，需要更多数据才能学到。
- **在 JFT-300M（3 亿张）或 ImageNet-21k 上预训练，再在 ImageNet 微调**：ViT 全面超越 CNN——**数据够多时，"更少的先验 + 更多的学习"反而更优**。

**结论：ViT 是"数据饥渴"模型——它用"放弃归纳偏置"换"更强的表示能力"，前提是有足够数据喂。** 这解释了为什么 ViT 之后，大规模预训练（MAE、CLIP）成为视觉标配。<span class="marginnote">ViT 的"数据饥渴"与全书对照：CNN 有强归纳偏置（平移不变、局部性）→ 小数据好但表达受限；Transformer 几乎无偏置 → 大数据强但小数据差。<strong>"偏置与数据的权衡"是模型选择的根本张力</strong>——这也解释了为什么后来 MAE（掩码自监督）要专门给 ViT 造"无限数据"。理解了这个权衡，就理解了"为什么 2021 年后视觉都在搞预训练"。</span>

## 4 公式解析：自注意力的复杂度与 ViT 的计算账

**"全局注意力很贵"是 ViT 的代价。** 算一笔账：

**第一步，注意力复杂度**：$N$ 个标记的自注意力，每个标记要与所有标记做点积——**复杂度 $O(N^2)$**（准确的：$O(N^2 d)$）。
**第二步，ViT 的 $N$**：$224\times224$ 图、16×16 分块 → $N = 196$。$O(196^2) = O(38416)$ 次点积/层——**对单张图可接受**。
**第三步，高分辨率的问题**：把分辨率提到 $384\times384$ → $N = 576$ → $O(576^2) = O(33万)$——**$N^2$ 让高分辨率输入的计算暴涨**。这正是 ViT 在检测/分割（需要高分辨率）里初期的短板。
**第四步，缓解方向**：**层级 Transformer**（Swin，下一节）用窗口限制注意力范围、金字塔结构逐步降采样——**把 $O(N^2)$ 摊到窗口内**。这是 ViT 之后的重要工程演进。

**一句话：ViT 的全局注意力既是优势（任意位置交互）也是负担（$O(N^2)$）——高分辨率场景要用"窗口化"来救。**

## 5 ViT 的遗产与局限

ViT 的贡献：

**证明纯注意力能做视觉**：CNN 不再是必需，视觉与 NLP 架构统一。
**开启视觉预训练时代**：ViT + 大规模预训练（MAE、CLIP）成为视觉基础模型的标配。
**可解释性的红利**：注意力的权重可以直接可视化——模型"看哪里"一目了然（比 CNN 的卷积核更直观）。

局限：

**数据饥渴**：小数据不如 CNN，需要预训练。
**$O(N^2)$ 计算**：高分辨率/密集任务受限。
**缺归纳偏置**：对旋转、尺度变化的鲁棒性不如 CNN（需要数据/增强补）。

**ViT 的教训：架构的通用性（一个模型通吃）与效率（$O(N^2)$）之间存在张力——后续工作（DeiT、Swin、MAE）都在这个张力里找平衡。**<span class="marginnote">把 ViT 与全书主线连接：ViT 的 [CLS] 标记 = "查询"的原型（它去注意力地读全局），这直接通向 DETR 的 object query、Mask2Former 的 mask query、CLIP 的图文对齐。<strong>"一个可学习的标记去查询全局"这个设计，是 ViT 留给视觉最深的遗产</strong>——它让"查询-注意力"成为视觉的通用交互语言。</span>

## 6 ViT 的工程实践与现代演进

ViT 的工程使用与现代演进，几个关键：

**工程实践**：

- **预训练的必要性**：ViT 几乎必须预训练（ImageNet-21k/22k 或自监督 MAE）——"**单数据集从零训 ViT 效果差**"（DeiT 的蒸馏是例外）。
- **训练技巧**：AdamW + 长训练 + 数据增强——"**ViT 训练对超参敏感**"（比 CNN 更娇气）。
- **分块大小**：$16\times16$ 默认、$14\times14$（微调时）——"**分块小 = 标记多 = 更细但更贵**"。
- **高分辨率微调**：预训练 224 → 微调 384/512——"**位置编码要插值**"，是 ViT 迁移的标准操作。

**现代演进**：

- **层级 ViT**：Swin（窗口 + 金字塔）——"**把 CNN 的层级带回 ViT**"（前文）。
- **自监督 ViT**：MAE/DINO——"**让 ViT 不需要标注**"（前文）。
- **ViT 的检测/分割应用**：ViT 当骨干（DETR、SegFormer）——"**ViT 从分类走向通用骨干**"。
- **高效 ViT**：蒸馏（DeiT）、线性注意力（Performer 类）——"**给 ViT 减负**"。

**ViT 与 CNN 的最终关系**：不是"谁取代谁"而是**融合**——**"现代骨干（ConvNeXt、Swin、UniFormer）兼取两者之长"**：CNN 的层级/效率 + Transformer 的动态建模。**"卷积与注意力是互补的，不是对立的"**——理解 ViT，就是理解注意力这条"新传统"，而它与卷积这条"旧传统"正在合流。

**ViT 的启示**：它证明了"**架构的通用性**"——**"一个架构（Transformer）同时统治 NLP 与视觉"**。这对研究者最大的启发是：**"不要被'领域惯例'束缚——图像不一定非要卷积"**。这种"重新思考基本假设"的精神，是深度学习进步的最大动力。

## 7 小结

- **ViT** = 图像分块（patch）+ 位置编码 → 标准 Transformer 编码器 → [CLS] 分类。
- **Patch Embedding**：切块 → 线性投影 → 加位置编码——图像变成"标记序列"。
- **分类**：读 [CLS] 标记的最终表示。
- **数据饥渴**：小数据不如 CNN，大数据（预训练 + 微调）反超——"偏置 vs 数据"的权衡。
- 注意力的 $O(N^2)$ 复杂度让高分辨率受限——Swin 用窗口化解决。
