## 为什么从 LeNet 与 AlexNet 开始

上一节我们有了 CNN 的构件（卷积、池化、感受野、ReLU），但"构件"与"能用的网络"之间还隔着关键的一步：**架构设计**。历史上真正把 CNN 从"一个想法"变成"一个系统"的两个里程碑，正是 LeNet 与 AlexNet——一个在 1998 年证明了 CNN 能处理真实任务（手写数字识别），一个在 2012 年用碾压性的 ImageNet 成绩引爆了深度学习革命。<span class="marginnote">这两篇论文相隔 14 年，结构其实很像（卷积+池化+全连接），差距全在"规模与工程"：AlexNet 比 LeNet 深、宽，用了 ReLU 与 Dropout、在 GPU 上训练。<strong>"同样的骨架 + 规模与技巧的跨越 = 质的突破"</strong>——2012 年的故事是这句话最生动的注脚。顺带一提，2012 年的 AlexNet 作者三人组（Krizhevsky、Sutskever、Hinton）后来都成为深度学习教父级人物。</span>

## 1 LeNet-5：CNN 的第一个完整系统

**LeNet-5** 是 Yann LeCun 1998 年为手写数字识别（MNIST）设计的网络，也是历史上第一个成功的卷积网络。结构（简化）：

```
输入 32×32 灰度
 → Conv 5×5, 6 核 → 池化 2×2 → Conv 5×5, 16 核 → 池化 2×2
 → Conv 5×5, 120 核 → 全连接 84 → 全连接 10（输出 10 个数字类）
```

它的设计智慧：

- **逐级抽象**：边缘/笔画 → 部件 → 数字整体，由卷积层级组合。
- **参数共享 + 池化**：对平移、轻微形变鲁棒。
- **"卷积+池化"交替**：每层扩大感受野同时压缩空间，最后用全连接做分类。

LeNet-5 在 MNIST 上把错误率压到 1% 以下，被美国邮政、银行用于支票数字识别——**CNN 第一次从论文走进工业**。但它的成功也止步于此：更大更复杂的自然图像（ImageNet）远超它的能力，而当时没有足够的算力与数据让它长大。

## 2 2012 年的爆发：ImageNet 与 AlexNet

**ImageNet**（2009，李飞飞团队）提供了 1400 万张标注图像、1000 类——一个前所未有的训练集。**AlexNet**（2012）在这个数据上把 Top-5 错误率从 26% 直接砍到 16%，比第二名低 10 个百分点，震惊了整个领域。

AlexNet 相对 LeNet 的四个关键升级：

1. **更深的架构**：8 层（5 卷积 + 3 全连接），每层更多核、更大特征图。
2. **ReLU 激活**：收敛速度远快于 tanh（LeNet 时代的主流），让深网络训练成为可能。
3. **Dropout**：全连接层随机"丢"一半神经元，抑制过拟合——训练时随机丢、预测时全用。
4. **GPU 并行 + 数据增强**：两块 GTX 580 并行训练；随机裁剪、翻转、颜色抖动扩充数据。

**AlexNet 的贡献不是某个新构件，而是证明了"深 + 宽 + 大数据的 CNN 能在大规模真实任务上碾压传统方法"**——它把整个领域从"手工特征"推向了"表示学习"。

## 3 为什么 AlexNet 能成功：数据、算力、正则

把 AlexNet 的成功拆成三根支柱：

- **数据**：ImageNet 的百万级标注提供了足够样本，让深层网络的数百万参数"学得动"。
- **算力**：GPU 让"大规模卷积 + 反向传播"在数天内可行（2012 年已是奇迹）。
- **正则**：Dropout + 数据增强 + 权重衰减，把模型的泛化能力撑住。

**深层网络是"高容量模型"**——它能记住训练集（过拟合），也能在正则约束下学到泛化特征。AlexNet 之前的困境是：容量大了没数据训练、有数据了没算力训练、能训练了又过拟合。三根支柱同时成立，革命才发生。<span class="marginnote">一个常被忽略的细节：ImageNet 之前的图像识别用 SIFT/Fisher Vector + SVM 这类"手工特征 + 经典分类器"。AlexNet 的最大意义不是"它赢了"，而是"它让所有人看到：<strong>端到端学习的特征比手工特征好一个量级</strong>"。此后"深度学习 = 视觉主流"成为共识，ImageNet 也成了深度学习模型的"高考"。</span>

## 4 公式解析：为什么 ReLU 让深网络训得快

**激活函数的选择是"深"能否成立的关键。** 对比 tanh 与 ReLU 的梯度。

- **第一步，tanh 的饱和**：$\tanh(x)$ 在 $|x|$ 大时趋近 ±1，导数 $\tanh'(x) = 1 - \tanh^2(x) \to 0$。反向传播时梯度逐层乘以 $\tanh' < 1$ 的因子——**网络越深，梯度乘得越多，越接近 0**（梯度消失），浅层几乎学不动。
- **第二步，ReLU 的"线性半区"**：$\text{ReLU}(x) = \max(0,x)$，在 $x>0$ 时导数恒为 1。反向传播时梯度在正半区**不衰减**——深层梯度能顺利传回浅层。
- **第三步，稀疏激活**：ReLU 让约一半神经元输出 0（负输入），产生稀疏激活——既省算力，也天然带一点正则效果。
- **第四步，实证**：AlexNet 论文报告，ReLU 网络的收敛速度比 tanh 快约 6 倍——在当时的算力下，这 6 倍就是"能不能训"的差距。

**一句话：ReLU 的"正半区导数恒 1"是深度网络梯度传播畅通的原因，它把"深度"从不可能变成可能。**

## 5 LeNet → AlexNet → 现代：架构演化的脉络

把两代网络放进更大的演化图景：

- **LeNet（1998）**：奠基，证明 CNN 可行，但小、浅、限于简单任务。
- **AlexNet（2012）**：引爆革命，深 + 宽 + 大数据 + 工程技巧。
- **VGG（2014）**：用统一的小核堆叠（3×3），把"深度"推到 16~19 层。
- **GoogLeNet/Inception（2014）**：多分支并行卷积，用 1×1 卷积降维。
- **ResNet（2015）**：残差连接，让网络可以堆到 1000+ 层（下一节）。

**每一次架构跃迁，都是"让网络更深/更高效地表达"的一次工程回答**——深度是主线，算力与数据是推动力。

## 6 深度学习的"三大件"：数据、算力、算法

LeNet 与 AlexNet 的故事不是孤例——它揭示深度学习的"三大件"缺一不可：

- **数据**：MNIST（6 万张）支撑 LeNet，ImageNet（1400 万张）支撑 AlexNet。**"没有数据，容量再大的模型也白搭"**——数据决定了模型"学什么"。
- **算力**：LeNet 在 90 年代的 CPU 上训练，AlexNet 靠 GPU——**"算力决定模型能不能训得动"**。深度学习每次爆发都伴随算力跃迁：GPU、TPU、NPU。
- **算法**：ReLU、Dropout、卷积本身——**"算法决定同样的数据与算力能榨出多少能力"**。

**三者的平衡**：数据不足 → 过拟合（用正则、数据增强补）；算力不足 → 训不动（用更小的模型、加速补）；算法不足 → 学不好（用更好的结构、损失补）。**深度学习进步史 = 三大件轮流补短板的史**：

| 时期 | 数据 | 算力 | 算法突破 |
| --- | --- | --- | --- |
| 1998 LeNet | MNIST | CPU | 卷积 + 池化 |
| 2012 AlexNet | ImageNet | GPU | ReLU、Dropout |
| 2015 ResNet | ImageNet+ | GPU 集群 | 残差连接 |
| 2020+ 大模型 | 互联网级 | TPU/万卡 | Transformer、自监督 |

**对学习者的启示**：读任何深度学习论文，都值得问一句"它动了三大件的哪一件"——**LeNet/AlexNet 动的是"算法 + 数据"**，理解了这个框架，就能看懂深度学习每一次"看似神秘"的突破背后的真实驱动力。

## 7 从 LeNet 到 AlexNet 的"范式转移"再审视

LeNet 与 AlexNet 的对比，藏着深度学习发展的几条根本规律：

**规律一：同样的思想，规模改变一切**：LeNet 与 AlexNet 结构几乎一样（卷积 + 池化 + 全连接）——**"差的不是思想，是规模（数据 + 算力 + 深度）"**。这提示：**"深度学习里，规模本身是一种维度"**——不是所有进步都是"新思想"。

**规律二：工程技巧决定成败**：ReLU、Dropout、GPU 并行——**"让思想能跑起来"的技巧，与思想本身同等重要**。AlexNet 的三板斧（ReLU/Dropout/GPU）都是"工程"，却决定了成败——"**工程是思想的载体**"。

**规律三：基准改变认知**：ImageNet 提供了一个"足够难、足够大"的基准，才让"深度学习 > 手工特征"被看清——"**没有大基准，就没有范式转移**"。基准（评测）定义进步——"**先有'考纲'，才有'学霸'**"。

**规律四：突破是累积的**：AlexNet 不是凭空出现——LeNet 的骨架、ImageNet 的数据、GPU 的算力、ReLU 的技巧，缺一不可——"**突破 = 所有条件的汇合**"。

**对学习者的启示**：LeNet → AlexNet 的故事告诉我们：**"不要只盯着'新模型'，要看'让模型变好的三件套'（数据、算力、算法）"**——"**读懂一个突破，要读它背后的全部条件**"。这个视角，能帮你理解深度学习后来的每一次跃迁。

## 8 小结

- **LeNet-5**：1998 年的第一个完整 CNN，卷积+池化+全连接的骨架，在手写数字上达到实用精度。
- **AlexNet**：2012 年 ImageNet 碾压性胜出，引爆深度学习革命。
- AlexNet 的四个升级：**更深 + ReLU + Dropout + GPU/数据增强**。
- 成功的三支柱：**大数据、大算力、正则**（深层高容量模型"学得动"且"不飘"）。
- **ReLU 的梯度不衰减**是深网络训练可行的关键（对比 tanh 梯度消失）。
- 演化脉络：LeNet → AlexNet → VGG/Inception → ResNet，深度是主线。
