# 全景分割与现代统一分割框架

## 为什么从全景分割开始

语义分割把所有"车"归一类，实例分割只分前景个体、丢弃背景——**两者的输出无法直接合并**（语义图把两辆车画成同一块，实例掩码里没有天空）。**全景分割（panoptic segmentation）**的目标是给"完整场景理解"一个统一答案：**每个像素都有归属——前景（thing）分实例，背景（stuff）分类别**。

2019 年 Kirillov 提出全景分割的任务定义与评估（PQ），2021 年 Mask2Former 用"查询 + 掩码"把语义/实例/全景统一到一个模型。这一节讲清楚全景分割"统一什么、怎么评测、怎么用一个框架做所有分割"——它是分割谱系的收束点，也是后文视觉基础模型（SAM）的直系前身。<span class="marginnote">Kirillov 2019 的论文标题就是 "Panoptic Segmentation"，他本人也是后来 SAM（Segment Anything）的通信作者。<strong>全景分割的"统一场景理解"理念，加上 DETR 的"查询"技术，催生了 Mask2Former 与 SAM——"统一一切分割"成为视觉基础模型时代的主题</strong>。全景分割是这条思想线的关键中转站。</span>

## 1 全景分割的任务定义

**全景分割（panoptic segmentation）**的输出是**一幅全图的分段图（panoptic map）**：每个像素被赋予一个"段 ID + 语义标签"。

- **thing 类**（人、车、动物）：每个实例一个独立段，段与段之间语义标签相同但 ID 不同。
- **stuff 类**（天空、道路、草地）：整个类别一个段（不区分实例）。

形式化：每个段 $Z_i$ 有 $(l_i, \text{ID}_i)$，其中 $l_i$ 是语义标签。**输出是"划分 + 标记"的联合**——既回答了"这一块是什么类别"，也回答了"这个类是哪一个个体"。

**评估指标 PQ（Panoptic Quality）**：

$$
PQ = \frac{\sum_{(p,g) \in TP} \text{IoU}(p, g)}{|TP| + \frac{1}{2}|FP| + \frac{1}{2}|FN|}
$$

PQ 综合了两件事：**识别质量（RQ，匹配上多少段）**与**分割质量（SQ，匹配上的段 IoU 多高）**。它同时惩罚"段没找对"与"段分得糊"。

## 2 PQ 的分解：识别质量 × 分割质量

PQ 可以拆成两个因子的乘积：

$$
PQ = \underbrace{\frac{\sum_{(p,g)} \text{IoU}}{|TP|}}_{\text{SQ 分割质量}} \times \underbrace{\frac{|TP|}{|TP| + \frac{1}{2}|FP| + \frac{1}{2}|FN|}}_{\text{RQ 识别质量}}
$$

逐步拆解：

- **第一步，匹配**：预测段 $p$ 与真值段 $g$ 的 IoU > 0.5 才算匹配（一个预测段最多匹配一个真值段）。匹配上的叫 TP，没匹配上的预测叫 FP，没匹配上的真值叫 FN。
- **第二步，SQ（分割质量）**：所有 TP 对的平均 IoU——"分对的段，分得多准"。
- **第三步，RQ（识别质量）**：F1 分数的变体——"段找对的比例"（TP / (TP + FP/2 + FN/2)）。
- **第四步，乘积的直觉**：**必须既找对段（RQ）又分得准（SQ）才能得高分**。PQ 的特别之处是它对 stuff 和 thing 一视同仁——**背景的分割质量同样被计入总分**，这是它区别于实例分割 mask AP 的地方。

**一句话：PQ = 找对多少段（RQ） × 分准多少段（SQ），语义与实例统一评估。**

## 3 从两路合并到统一：Panoptic FPN 的路径

早期全景分割走**两路合并**：把语义分割输出与实例分割输出"拼"起来。**Panoptic FPN（2019）**是代表：

1. 语义头 + 实例头（Mask R-CNN 的掩码）并行输出。
2. **融合规则**：先放实例掩码（thing），再用语义结果填充剩余（stuff），处理重叠与冲突（一个像素被语义判为"路"又被实例判为"车"，按置信度仲裁）。

两路合并的问题：**两个头独立训练，输出可能互相矛盾；融合规则是手工设计的**。这催生了"统一"思路——**让一个模型直接输出全景结果，不分成两条路**。

## 4 Mask2Former：查询即掩码的统一分割

**Mask2Former（2021）**用一个模型统一语义/实例/全景分割，核心是 DETR 的**"查询 + 集合预测"**：

1. **掩码查询（mask query）**：$N$ 个可学习查询，每个输出一个"掩码 + 类别 + 置信度"。
2. **掩码注意力（masked attention）**：每个查询的注意力**只在自己预测的掩码区域内**做——"查询关注自己负责的那块区域"，计算高效、边界更精细。
3. **二分匹配**：与真值掩码集合做匈牙利匹配，端到端训练。
4. **一个模型，三个任务**：训练时按任务换损失与匹配（语义/实例/全景），推理时同一个网络输出不同格式。

**Mask2Former 的统一原理**：语义、实例、全景分割在"查询-掩码"表示下没有本质区别——**都是"一组掩码 + 标签"**，差异只在"哪些掩码要区分个体"。因此一个模型就能覆盖全部。

**辨析｜易错点：** Mask2Former 的"掩码注意力"只对"当前查询预测的区域"做注意力——如果查询一开始预测错区域（训练初期），注意力就困在错误区域。解决靠"高分辨率特征 + 多尺度 + 足够长的训练"——**"掩码注意力"依赖初始掩码的质量，是它的迭代依赖**。<span class="marginnote">把 Mask2Former 与 SAM 连起来看：Mask2Former 的"查询即掩码"到了 SAM 变成"提示即掩码"——SAM 用"点/框/文字提示"取代"类别查询"，把"分割指定类别"升级成"分割任意指定东西"。<strong>从 DETR 的检测查询 → Mask2Former 的分割查询 → SAM 的提示，查询机制的通用化是视觉基础模型的进化主线</strong>。</span>

## 5 全景分割与现代视觉的汇合

全景分割站在多个趋势的交叉点：

- **统一的场景理解**：自动驾驶里，"可行驶区域（stuff）+ 车辆行人（thing）"的全景输出正好是规划控制需要的完整输入。
- **与基础模型融合**：SAM 做"分割一切"，结合 CLIP 的语义理解，可以实现"提示驱动的全景理解"（如 Grounded SAM）。
- **视频全景分割**：把全景分割扩展到视频（每个实例有轨迹），是视频理解的前沿。

**全景分割的意义**：它是"逐像素完整理解"的目标函数——**一个能输出全景分割的模型，已经"看懂"了图的每一寸**。从 FCN 到 Mask2Former，分割从"逐像素分类"进化到"查询驱动的统一分割"，而全景分割提供了衡量"完整理解"的标尺。<span class="marginnote">回顾分割谱系与技术演化的汇合：FCN/U-Net（稠密预测）→ DeepLab（多尺度上下文）→ Mask R-CNN（检测+掩码）→ Mask2Former（查询统一）→ SAM（提示分割一切）。<strong>每次演进都是"表示能力"的提升：从逐像素、到框+掩码、到查询、到提示——模型的"接口"越来越接近自然语言式的交互</strong>。这也是后文多模态大模型的伏笔。</span>

## 6 全景分割的工程实践与挑战

全景分割落地时的工程问题，比"模型结构"更实际：

- **thing-stuff 的冲突仲裁**：早期两路合并法里，一个像素可能被"实例头判为车"又被"语义头判为路"——**"融合时要按置信度仲裁"**；统一方法（Mask2Former）天然避免冲突——"一个模型一个输出，没有两路打架"。
- **预测数量不固定**：全景分割的段数每图不同（thing 实例数不定）——**"模型要处理可变数量的输出"**（查询方法用固定查询上限 + 填充）。
- **评估的细节**：PQ 里"段与段匹配"要求 IoU > 0.5——**"小物体段的匹配更难"**（小物体段间 IoU 天然波动大），所以全景分割对"小 thing"的精度波动敏感。
- **与下游的衔接**：自动驾驶用"全景分割"（可行驶区域 + 车辆行人）做完整场景理解——"**全景输出 = 一个模型给出规划所需的一切**"。

**全景分割的挑战**：

- **小物体与遮挡**：密集人群、远处小车的"实例分离"难。
- **模糊边界**：thing 与 stuff 的边界（车与地面的阴影）难分。
- **数据标注贵**：全景标注（每个像素的段 + 类）比检测/语义贵得多——"**数据成本是全景分割的隐性门槛**"。

**全景分割的定位**：它是"完整场景理解"的目标函数——**"能做好全景分割的模型，已经'看懂'了图的每一寸"**。它连接了识别（分类）、检测（定位）、分割（像素）三大任务——**"全景分割是视觉理解任务的'总集成'"**，也是通往"视频全景分割"与"基础模型统一理解"的跳板。

## 7 全景分割与基础模型的衔接

全景分割与"分割基础模型"（SAM 等）的衔接，是理解它现代意义的关键：

**全景分割为 SAM 提供了"任务骨架"**：SAM 的"提示分割任意物体"继承了全景分割的"thing/stuff 统一"思想——"**全景分割首次让'一切像素都有归属'成为目标，SAM 把这个目标做成'一切东西都可分割'**"。

**全景分割的"完整理解"标准**：它是"**是否看懂了一幅图**"的试金石——"**一个能输出正确全景分割的模型，已经同时回答了'有什么类'（语义）'有几个'（实例）'各在哪'（分割）'哪些是背景'（stuff）**"。这是视觉理解"完整度"的最高标尺。

**从全景到世界理解**：

- **视频全景分割**：给全景加时间维——"理解一段视频的完整场景"。
- **全景 + 语言**：用文本驱动全景（"分割并描述这个场景"）——"全景分割与 VL 模型的结合"。
- **全景 + 3D**：多视角全景重建——"三维世界的完整理解"。

**对学习者的启示**：全景分割是"**统一**"的典范——"**把看似不同的任务（语义/实例）统一成一个目标，用一个模型解决**"。这个"统一化"趋势（一个模型做所有分割、所有检测、所有理解）是视觉基础模型时代的核心——**"全景分割是'统一理解'这个概念最好的入门教材"**。

## 8 小结

- **全景分割**：全图统一——thing 分实例、stuff 分类别，每个像素有归属。
- **PQ** = RQ（找对多少段） × SQ（分准多少段），语义与实例统一评估。
- 早期路线**两路合并**（Panoptic FPN）：语义头 + 实例头手工融合，有冲突。
- **Mask2Former**：查询即掩码 + 掩码注意力 + 二分匹配，一个模型统一三分割。
- 汇合：自动驾驶完整输入、与 SAM/CLIP 融合、视频全景分割；通向"提示驱动的理解"。
