## 为什么从 LLaVA 开始

BLIP-2 用 Q-Former 桥接视觉与 LLM，让模型能"回答"，但它的交互方式是"预先定义的任务"。**LLaVA（Large Language and Vision Assistant，2023）**把多模态推向 LLM 时代的方式：**视觉指令微调（visual instruction tuning）**——**用"指令-图像-回答"的数据微调模型，让大语言模型学会"按用户的自然语言指令看图办事"**。

LLaVA 的架构极简：**视觉编码器 + 线性投影 + 大语言模型**——把图像变成"视觉标记"直接喂给 LLM，然后像微调 LLM 一样微调整个模型。它的关键创新是**数据**：**用 GPT-4 自动生成"图像-指令-回答"的训练数据**——"让大模型教小模型怎么看图说话"。

LLaVA 证明了"视觉指令微调"这条路可行，成为开源多模态大模型的事实标准（LLaVA、LLaVA-1.5、LLaVA-NeXT 系列），也定义了"多模态 LLM"的通用形态。<span class="marginnote">LLaVA 的全称是 "Large Language and Vision Assistant"。它的数据生成方案非常巧妙：<strong>先让一个视觉模型把图像"翻译"成文字描述（caption + 区域描述），再让 GPT-4 基于这些文字生成"像人问的问题与答案"</strong>——因为 GPT-4 看不到图，就用"文字化图像"绕过它。<strong>"用现成模型造指令数据"与 SAM 的数据引擎、BLIP 的 CapFilt 一脉相承</strong>——指令数据是让 LLM 学会"对话"的关键燃料。</span>

## 1 从"任务微调"到"指令微调"

传统 VL 模型的用法：**一个任务（VQA）一个微调**——模型只会"图 + 问题 → 答案"这一种交互。**指令微调（instruction tuning）**换一种思路：

- **训练数据**：（图像，指令，回答）三元组——指令是**任意形式的自然语言**："描述这张图"、"图里有什么动物"、"这张图适合做海报吗"。
- **训练目标**：让模型学会"对任意指令，看图给出恰当回答"。
- **效果**：**一个模型、无数任务**——用户想怎么问就怎么问，模型按指令切换行为。

**指令微调的本质**：**把"任务"从"预先定义"变成"自然语言描述"**——任务定义被"软编码"进指令文本，模型学会了"听懂指令并按指令做事"。这正是"从任务专用到对话通用"的关键一步。

## 2 LLaVA 的架构：视觉标记 + LLM

LLaVA 的架构简到极致：

```text
图像 ──► CLIP ViT（视觉编码器）──► 图像特征
                                        │
                                        ▼
                                  线性投影（可学习）
                                        │ 视觉标记 V
                                        ▼
指令文本 ──► Tokenizer ──► 文本标记 T ──► 拼接 [V; T]
                                              │
                                              ▼
                                        LLM（Vicuna / LLaMA）
                                              │
                                              ▼
                                            回答文本
```

- **视觉编码器**：CLIP 的 ViT（冻结或微调）——把图像编码成特征。
- **线性投影**：一个可学习的线性层——把视觉特征"翻译"成 LLM 能读的"词嵌入"（视觉标记）。
- **LLM**：Vicuna/LLaMA 等大语言模型——负责"理解指令 + 视觉标记 + 推理回答"。

**关键设计：视觉标记与文本标记拼接在一起，作为同一个 LLM 的输入序列**——LLM 用它的自注意力"同时看图和文字"，用它的语言能力"组织回答"。**"让 LLM 把视觉标记当另一种语言来读"——这就是多模态大模型的基本形态**。

## 3 两阶段训练：对齐与指令微调

LLaVA 的训练分两阶段：

- **阶段一（特征对齐）**：冻结视觉编码器与 LLM，只训**线性投影**——用"图像描述"数据，让模型学会"把视觉特征与文本描述关联起来"（"这是什么"）。
- **阶段二（端到端指令微调）**：解冻 LLM（与投影），用"指令-图像-回答"数据微调——**让模型学会"按指令看图回答"**（"描述它"、"分析它"、"改它"）。

**两阶段的逻辑**：先"让视觉和语言对得上"（对齐），再"让模型学会用"（指令）——**"先学会读图，再学会用图办事"**。

**辨析｜易错点：** 阶段二的"指令数据"质量决定模型的对话能力——LLaVA 用 GPT-4 生成数据（高质量但可能引入幻觉）；数据多样性（问题类型、指令风格）影响泛化。**"指令数据的广度与质量 = 模型的能力上限"**。

## 4 公式解析：视觉指令微调的损失

**LLaVA 的微调目标是什么？** 拆解。

- **第一步，输入序列**：视觉标记 $V$（来自投影）与文本指令标记 $T$ 拼接：$\text{input} = [V; T]$。
- **第二步，自回归生成**：LLM 逐 token 生成回答，用标准**自回归损失（交叉熵）**：

$$
\mathcal{L} = -\sum_{t} \log p_\theta(y_t \mid y_{\\lt t}, V, T)
$$

模型预测每个答案 token 的概率，与真实回答对比——**"最大化回答的概率"**。
- **第三步，只监督回答部分**：损失只计算"回答" token（指令与图像部分不计算——它们是"条件"不是"输出"）。
- **第四步，与 LLM 微调同构**：**视觉指令微调的损失与纯文本 LLM 微调完全一样**——只是输入多了视觉标记。**"视觉被当作一种输入模态，微调框架原样复用"**——这就是 LLaVA 架构极简的原因。

**一句话：LLaVA = "视觉标记 + 文本指令"喂给 LLM，用标准自回归损失微调——视觉只是多了一种输入标记，其余全是 LLM 的现成机制。**

## 5 LLaVA 的能力与局限

LLaVA 的能力（视觉指令微调带来的）：

- **多轮对话**：看图连续问答（"这张图里有什么？"→"猫。""它在干嘛？"→"睡觉。"）。
- **多任务**：描述、VQA、OCR（读图里的字）、空间推理、角色扮演（"你是营养师，看这张餐盘评价它"）。
- **零样本泛化**：未见的指令/任务也能合理应对。

局限：

- **幻觉（hallucination）**：会"编造"图里没有的东西（LLM 的"过度自信"）。
- **细粒度/空间推理弱**：计数、精确位置、小物体易错。
- **视觉细节损失**：CLIP 特征（256 个标记）压缩了图像细节——LLaVA-1.5 用更高分辨率与更多标记缓解。

**LLaVA 的遗产**：它确立"视觉指令微调"范式，成为开源 MLLM 的标准；**"视觉编码器 + 投影 + LLM + 指令微调"是 2023 年后几乎一切多模态大模型的模板**。<span class="marginnote">把 LLaVA 与全书主线连接：LLaVA 是"提示范式"的终极形态——<strong>"用自然语言指令指挥一个通用模型"</strong>。它的视觉编码器来自 CLIP（对比预训练）、投影是"桥接"的极简版（Q-Former 的替代）、LLM 是"借来"的推理引擎。<strong>从 CLIP（对齐）→ BLIP（生成）→ LLaVA（对话），多模态模型最终"统一"成了一个"能看、能说、能想"的对话模型</strong>——这是视觉从"感知"走向"智能"的收束。</span>

## 6 LLaVA 的工程细节与评测

用 LLaVA 系模型的工程问题：

- **视觉标记的压缩**：CLIP ViT 对 336 图输出 576 个标记，直接喂 LLM 会让上下文爆掉——**LLaVA 常把相邻标记合并（grid 池化）到 256 或更少**——"标记数是'视觉细节 vs LLM 长度'的权衡"。LLaVA-1.5 用 336 分辨率 + 576 标记（可支持）提升细粒度。
- **分辨率与视觉细节**：LLaVA-NeXT 用**任意分辨率切分（anyres）**——把高分辨率图切成多块分别编码——**"小物体与 OCR 要更高分辨率"**。
- **双视觉编码器**：LLaVA-1.5 的变体用 **CLIP（语义）+ DINOv2（结构）** 双编码器——"语义与结构特征互补"（前文讲过）。
- **投影的选择**：线性 vs MLP——MLP 表达更强、细粒度更好——**"桥接层的容量影响视觉信息传递"**。

**评测**：

- **通用基准**：MMBench、MM-Vet（综合能力）、VQAv2、GQA（问答）、TextVQA（OCR）——**"一个模型的多维度体检"**。
- **幻觉评测**：POPE（物体存在性）、CHAIR（描述里幻觉物体的比例）——**"LLaVA 类的开源模型幻觉率偏高"**（闭源模型普遍更低）。
- **细粒度短板**：计数、空间关系、小物体——**"开源 MLLM 在这些维度系统性偏弱"**。

**LLaVA 的定位**：它是"视觉指令微调"的开源标准，证明了"**CLIP 编码 + 投影 + LLM + 指令数据**"这条路的可行性——**"开源模型 + 开源数据 + 可复现"**让它成为研究多模态大模型的首选起点。它的弱点（幻觉、细粒度）也是整个多模态大模型领域当前的瓶颈。

## 7 小结

- **LLaVA** = 视觉编码器 + 线性投影 + LLM——**视觉标记 + 文本指令**喂给 LLM，指令微调。
- **视觉指令微调**：用（图像，指令，回答）数据训练——任务从"预定义"变成"自然语言描述"。
- **数据生成**：GPT-4 基于"文字化图像"生成指令数据——"大模型教小模型"。
- 两阶段：**特征对齐（投影）→ 指令微调（端到端）**。
- 损失 = 标准自回归交叉熵（视觉标记只是额外输入）。
- 能力：多轮对话、多任务、零样本泛化；局限：幻觉、细粒度弱。
- 遗产："视觉编码器 + 投影 + LLM + 指令微调"成为多模态大模型模板。
