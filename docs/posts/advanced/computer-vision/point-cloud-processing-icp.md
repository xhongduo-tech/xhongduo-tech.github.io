## 为什么从点云开始

前面从图像重建出了点云——**点云（point cloud）**是三维世界的原生表示之一：LiDAR 扫描、深度相机、MVS 重建，输出的都是点云。点云由**无序的 3D 点集**组成，每个点带坐标（常带颜色/法向）。它简单、真实、无网格化误差，是自动驾驶（LiDAR 感知）、机器人（建图定位）、测绘、数字孪生的数据基础。

但点云是"原始数据"——它无序、稀疏不均、带噪声、多帧需对齐。这一节把点云的基本操作讲透：**滤波**（去噪下采样）、**配准**（多帧对齐，ICP）、**特征**（描述局部结构）。理解了这些，才能谈 PointNet 等深度学习怎么处理点云。<span class="marginnote">点云与图像的根本差异是<strong>无序性（permutation invariance）</strong>：图像是规则网格，像素有固定邻居；点云没有顺序，点的"邻居"要按距离查。这个差异决定了图像用卷积（规则邻域），点云要专门设计（PointNet 用对称函数、后续用图/注意力）。<strong>"数据结构决定网络结构"是 3D 深度学习的出发点</strong>。</span>

## 1 点云滤波与下采样

原始点云噪声大、密度不均，处理前的标准操作：

- **统计滤波（statistical outlier removal）**：对每个点，计算它到 $k$ 个最近邻的平均距离；距离分布偏离均值过大的点判为离群点剔除——**去掉"飞点"**。
- **半径滤波（radius outlier removal）**：邻域半径内点数少于阈值的点剔除——**去掉稀疏孤立点**。
- **体素下采样（voxel downsampling）**：把空间划分成小立方体（体素），每个体素内的点用一个代表点（重心或第一个点）替代——**大幅减少点数、均匀密度**，是处理大点云的第一步。

**滤波的目标：保留"真表面"、剔除"测量噪声"**——点云质量决定下游一切任务的精度。

## 2 配准与 ICP

**点云配准（registration / alignment）**：把不同坐标系下的点云（不同时刻扫描、不同视角）对齐到同一坐标系——找刚体变换 $R, t$ 使两片点云重合。应用：多帧拼接、SLAM 的帧间对齐、物体与模型的匹配。

**ICP（Iterative Closest Point，迭代最近点）**是最经典的点云配准算法，思路朴素到惊人：

1. **找对应**：对源点云每个点，找目标点云中**最近的点**作为对应。
2. **估计变换**：用对应点对估计刚体变换 $R, t$（最小化对应距离的平方和——正交 Procrustes / SVD 求解）。
3. **应用变换**：把源点云按 $R, t$ 变换。
4. **迭代**：重复 1~3，直到收敛（变换量小于阈值）。

**ICP 的核心假设**："最近的点就是对应的点"——在初值大致对齐时成立，所以**ICP 需要好的初始对齐**（否则陷入局部最优）。

## 3 公式解析：SVD 求解刚体变换

**ICP 每一步"估计 $R, t$"怎么解？** 给定对应点对 $\{\mathbf{p}_i\}$（源）与 $\{\mathbf{q}_i\}$（目标），最小化：

$$
\min_{R, t} \sum_i \lVert R\mathbf{p}_i + t - \mathbf{q}_i \rVert^2
$$

**最优解有闭式形式（Kabsch 算法 / 正交 Procrustes）**：

- **第一步，去质心**：把两组点都减去各自的质心 $\bar{\mathbf{p}}, \bar{\mathbf{q}}$——**平移 $t$ 的最优解先解耦出来**：$t^* = \bar{\mathbf{q}} - R\bar{\mathbf{p}}$。
- **第二步，交叉协方差**：$H = \sum_i (\mathbf{p}_i - \bar{\mathbf{p}})(\mathbf{q}_i - \bar{\mathbf{q}})^T$（3×3 矩阵）。
- **第三步，SVD**：$H = U\Sigma V^T$，则最优旋转 $R^* = V U^T$（必要时修正行列式保证 $\det R = 1$）。
- **第四步，为什么有效**：把问题化简成"最大化 $\sum \mathbf{q}_i^T R \mathbf{p}_i$"，SVD 恰好给出使这个迹最大的正交矩阵——**旋转的闭式最优解 = 交叉协方差的 SVD 分解**。

**一句话：ICP 的"估计变换"步骤是闭式可解的（去质心 + SVD），整个 ICP 就是"找对应 → 闭式解变换 → 迭代"三个动作的循环。**

## 4 点云特征：局部结构的描述

点云处理也要"特征"——描述一个点的局部几何，用于匹配与识别：

- **FPFH（快速点特征直方图）**：统计邻域内点对的几何关系（相对角度等），形成直方图特征——**对旋转/噪声鲁棒**，用于点云配准的粗匹配（先 FPFH 找对应，再 ICP 精化）。
- **法向估计**：每个点的法向由邻域点的协方差矩阵的最小特征向量给出——**局部平面的朝向**，是几乎所有点云算法（重建、配准、分割）的必需输入。
- **SHOT、Spin Image**：其他局部描述子（用于 3D 物体识别）。

**点云特征与图像特征的类比**：SIFT 描述"图像的局部梯度模式"，FPFH 描述"点云的局部几何模式"——**"局部描述 + 匹配"是 2D 与 3D 共有的通用范式**。

## 5 工程实践与深度学习的衔接

点云处理的工程要点：

- **数据结构**：KD 树用于最近邻查询（配准、滤波都要用）——**KD 树是点云的"索引"**，把最近邻从 O(N) 降到 O(log N)。
- **法向估计**：先估法向再做大部分操作（曲面重建、特征）。
- **ICP 的变体**：**Point-to-Plane ICP**（点对"目标点的切平面"距离而非点对点）收敛更快更准；**多尺度 ICP** 由粗到细。

**深度学习接棒**：PointNet 直接吃原始点云（对称函数处理无序性），PointNet++ 加局部结构（分层聚合），后续还有基于注意力/Transformer 的点云网络——这些是下一节的内容。<span class="marginnote">值得记住：<strong>点云是 3D 数据最"原生"的表示</strong>——LiDAR 直接输出点云，深度学习也只是在其上加工。与之相对，体素是把点云"网格化"（规则但贵），网格是"表面化"（紧凑但丢失内部）。<strong>"用哪种 3D 表示"（点云/体素/网格/隐式）决定了算法的数据结构与计算代价</strong>——这是三维深度学习的核心设计抉择。</span>

## 6 点云的应用全景与坐标系

点云处理的输出（对齐后的完整点云）是众多 3D 应用的数据基础：

- **建图（Mapping）**：SLAM 用 ICP 把连续帧点云对齐，拼出环境地图——**"每帧对齐一点，累积成完整世界"**。建图质量直接决定机器人的定位与导航精度。
- **物体识别与抓取**：把传感器点云与 CAD 模型配准（ICP/特征匹配），确定物体的位姿——**"知道它在哪、朝向哪，才能抓它"**。
- **测量与质检**：扫描点云与设计模型对比（配准后算偏差），检测制造误差。
- **三维重建的终态**：MVS/深度相机输出的点云，经滤波、配准、重建成为可用模型。

**坐标系的意识**：点云处理的每一步都涉及坐标系——LiDAR 有自己的坐标系、相机有自己的、机器人基座有基座系。**"把不同传感器的点云对齐到同一坐标系"是传感器融合的第一步**（自动驾驶的 LiDAR-相机标定就是"点云-图像的外参标定"）。**"坐标系与变换"是点云工程最容易被忽略却最重要的意识**——一帧点云的数据本身（坐标值）毫无意义，它所在的坐标系才赋予它意义。

**点云与网格、隐式的选型**：点云（无序、真实、稀疏）、网格（规则拓扑、适合渲染与物理）、隐式场（连续、适合学习）——**"用哪种表示取决于下游要什么"**：渲染要网格、测距要点云、学习要隐式。现代方法（如 3DGS）甚至混合：显式点 + 连续渲染。**"表示选择"是 3D 领域永恒的决策点**。

## 7 点云处理的评测与现代演进

点云处理（滤波/配准/特征）的评测与演进：

**评测**：

- **配准的精度**：估计的 $R, t$ 与真值的误差（旋转误差 + 平移误差）——"**配准准不准**"；常用"配准后点对的平均距离"（RE，Registration Error）。
- **滤波的效果**：去噪后"保真 + 去噪"的平衡（保留细节 vs 去掉噪声）——"**别把细节当噪声滤掉**"。
- **特征的可重复性**：同一物体在不同视角/噪声下的特征稳定性——"**特征的鲁棒性**"。

**现代演进**：

- **学习式配准**：PointNet 特征 + 可微 ICP（Deep Closest Point）——"**学习特征替代手工 FPFH**"。
- **端到端点云网络**：PointNet/PointNet++（前文）之后，注意力/Transformer 点云网络处理更大规模与更复杂结构。
- **点云 + 多模态**：点云 + 图像 + 文本融合（自动驾驶、机器人）——"**多模态 3D 感知**"。

**点云处理的定位**：它是"3D 深度学习之前的手工阶段"，也是"3D 系统里的必备工序"——**"无论深度学习多强，滤波、配准、坐标系变换这些'几何基本功'不会消失"**。**"深度学习替代的是'特征'与'分类'，替代不了'对齐'与'坐标'"**——理解点云的基本操作，是理解 3D 系统的地基。

## 8 小结

- **点云**：无序 3D 点集，真实测量、稀疏不均、带噪声；无序性决定网络设计。
- **滤波**：统计/半径滤波去离群点，体素下采样降密度——保真表面、去噪声。
- **ICP**：找最近对应 → SVD 闭式解刚体变换 → 迭代；需好初值。
- **SVD 解变换**：去质心解耦平移 + 交叉协方差 SVD 得旋转（Kabsch）。
- **点云特征**：法向、FPFH 描述局部几何，用于配准与识别。
- 工程：KD 树索引、Point-to-Plane ICP；深度学习（PointNet）接棒。
