## 为什么从金字塔开始

到目前为止，我们都在**单一分辨率**下处理图像：一张 1024×1024 的图，一个 3×3 的核，扫过全图。但真实世界天然是**多尺度**的——一条斑马线，隔 2 米看是几厘米宽的黑条，隔 100 米看就是一条灰带；一棵树，近看是叶、远看是冠。一个在单一尺度下工作的方法，面对「尺度的变化」会无所适从。

**图像金字塔（image pyramid）** 就是应对「尺度」的组织方式：把同一幅图做成一系列**分辨率逐级减半**的副本，叠在一起像一座塔。它是多尺度处理的母语——**高斯金字塔**负责「降分辨率」，**拉普拉斯金字塔**负责「记录丢失的细节」。理解金字塔，你便同时打通了三条线：图像融合、多尺度特征检测、以及图像压缩。<span class="marginnote">金字塔还是「特征检测」到「深度学习」之间的一座桥：SIFT 的 DoG 检测器就是高斯金字塔相邻层相减；而卷积神经网络里的「多尺度特征图」（如 FPN 特征金字塔网络）延续的正是同一套思想。</span>

多尺度的需求在深度学习里同样真实：早期的 CNN 直接在一个分辨率上训练，遇到尺度差异大的物体就抓瞎；后来的**特征金字塔网络（FPN）** 在卷积特征图上建「金字塔」，多尺度目标检测能力立刻上一个台阶——这正是「图像金字塔」思想在现代框架里的直接转世，我们在《目标检测》一节的 FPN 主题还会系统展开。

## 1 为什么不能直接缩小图像：混叠

先做一个危险的直觉操作：把一张 1024×1024 的图每隔一个像素抽一行一列，得到 512×512 的「缩小版」。看起来省事了，但结果往往惨不忍睹——细密条纹变成了乱七八糟的摩尔纹，边缘出现锯齿。这就是**混叠（aliasing）**。

原因在《数字图像的采样与量化》一节已经埋下伏笔：采样频率必须高于信号最高频率的两倍（奈奎斯特条件）。直接隔行抽样的**下采样（downsampling）**把采样率减半，那些频率超过新采样率一半的细节（细条纹、锐利边缘）就会「伪装」成低频假象——混叠。<span class="marginnote">混叠是采样定理的逆运算直觉：<strong>降采样前必须先低通滤波</strong>。图像里「先模糊、后抽样」的两步，与音频里「抗混叠滤波器 + 降采样」的 ADC 设计是同一个原理。</span>

所以金字塔的每一级下降都必须是两步：**先平滑（低通），再抽样**。把「模糊」这一步做好，正是上一节高斯滤波的用武之地——这就是「高斯金字塔」名字的由来。

## 2 高斯金字塔：平滑 + 下采样的反复

**高斯金字塔（Gaussian pyramid）**：自底向上，每一层先做高斯平滑（以 $\sigma$ 控制，核大小随尺度不变），再隔行隔列抽样，分辨率减半。递归地写：

$$G_{k+1} = \text{REDUCE}(G_k) = \text{降采样}\Big( G_k * g \Big)$$

其中 $g$ 是高斯核，$G_0$ 是原始图像。最底层 $G_0$ 分辨率最高，越往上越模糊、越小，顶层 $G_n$ 可能只剩几十个像素——整个结构像一座塔：

![高斯金字塔与拉普拉斯金字塔的层级结构](/images/computer-vision/image-pyramids-1.svg)

高斯金字塔的每一层是「越来越糊的同一张图」。但**丢了什么**？丢了「上一层与下一层之间的差异」——正是这些差异携带了该尺度下的边缘与细节信息。把这些差异显式地记录下来，就得到拉普拉斯金字塔。

## 3 拉普拉斯金字塔：把「丢失的细节」存下来

**拉普拉斯金字塔（Laplacian pyramid）** 不存图，而存**残差**。第 $k$ 层的拉普拉斯层定义为：原层减去「把上一层放大回本层尺寸」的结果：

$$L_k = G_k - \text{EXPAND}(G_{k+1})$$

**EXPAND** 是 REDUCE 的逆运算：先隔行隔列**插零**，再用高斯核**卷积插值**，把 $G_{k+1}$ 放大回 $G_k$ 的尺寸。<span class="marginnote">注意 EXPAND 只是 REDUCE 的近似逆：<strong>REDUCE 丢了高频，EXPAND 补不回来</strong>——这正是残差 $L_k$ 非零的原因。整座塔存 $G_n$ 一层 + 全部 $L_k$ 层，恰好可以无损重建原始图像，这就是它用于压缩的原理。</span>

$$G_k = L_k + \text{EXPAND}(G_{k+1})$$

重建从最顶层开始：$G_n = L_n$（顶层残差约定为 $G_n$ 本身），然后逐层「放大 + 加残差」，一路回到原始分辨率。**拉普拉斯金字塔存的是「细节」**，层内大多数值接近 0、只有边缘处有较大值——这天然的稀疏性，正是它可压缩的根本原因。直观地看，$L_k$ 近似于「带通滤波」的结果：每一层只保留「这一尺度」频段的信息。

**辨析｜易错点：** 拉普拉斯金字塔的每一层 $L_k$ **不是**「边缘增强图」，而是「这一尺度丢失的带通残差」——它记录的是 $G_k$ 到 $G_{k+1}$ 之间被丢掉的那一段频率，并非全图的边缘。另一个高频误解是把 EXPAND 当成 REDUCE 的逆：EXPAND 只是插值补值，**REDUCE 丢的高频它补不回来**，所以残差非零；若误以为两者互逆、重建时跳过残差层，得到的就是一张严重模糊的图。

## 4 公式解析：REDUCE 与 EXPAND 的完整写法

把两步算子写全，便于逐项理解（以 1D 示意，2D 只是对两个方向各做一遍）：

$$
\text{REDUCE}(G_k)[i] = \sum_{m=-2}^{2} w(m)\; G_k[2i + m]
$$

$$
\text{EXPAND}(G_{k+1})[i] = \sum_{j=-2}^{2} w(j)\; G_{k+1}\!\left\lfloor\frac{i - j}{2}\right\rfloor
$$

- **第一步，理解 REDUCE 的下标 $2i + m$**：$m$ 在高斯核 $w$ 上求和，而输出位置 $i$ 取输入位置 $2i+m$——「间隔 2」正是**抽样**的体现，$w$ 是 5 点高斯核，权重和归一化为 1。
- **第二步，理解 EXPAND 的下标 $\lfloor(i-j)/2\rfloor$**：输出位置 $i$ 映射回上一层的位置并插零；每两个输出才「真正对应」一个已知像素，中间由 $w$ 的卷积填平。
- **第三步，理解残差的意义**：$L_k = G_k - \text{EXPAND}(G_{k+1})$。若 REDUCE/EXPAND 是精确逆，残差为 0；正是因为它们不是，残差才编码了「这一尺度独有的信息」。**拉普拉斯金字塔 = 一组带通滤波器**，每一层对应一个频带。

工程实现要点：REDUCE 的核通常取 5 点高斯 $w = \frac{1}{16}[1, 4, 6, 4, 1]$（归一化和为 1），这个核在「抗混叠」与「保留信号」之间有良好平衡，是 Burt 与 Adelson 在 1983 年提出金字塔时的标准选择。

## 5 金字塔的三大用途

先看构建与重建的完整代码，把 REDUCE/EXPAND 落到实处：

```python
import cv2
import numpy as np

def gauss_pyramid(img, levels=5):
    g = img.copy()
    pyr = [g]
    for _ in range(levels - 1):
        g = cv2.pyrDown(g)          # REDUCE：高斯平滑 + 隔行抽样
        pyr.append(g)
    return pyr

def laplacian_pyramid(img, levels=5):
    gp = gauss_pyramid(img, levels)
    lp = [gp[-1]]                    # 顶层直接存 G_n
    for i in range(levels - 1, 0, -1):
        expand = cv2.pyrUp(gp[i])    # EXPAND：插零 + 放大核补值
        lp.append(cv2.subtract(gp[i - 1], expand))
    return lp

img = cv2.imread('photo.jpg')
lp = laplacian_pyramid(img, 5)
reconstructed = lp[0]
for layer in lp[1:]:
    reconstructed = cv2.add(cv2.pyrUp(reconstructed), layer)
print(np.max(np.abs(reconstructed.astype(np.float32) - img.astype(np.float32))))  # ≈ 0
```

`cv2.pyrDown` 内部用的正是归一化的 5 点高斯核 $[1,4,6,4,1]/16$，`cv2.pyrUp` 先插零再用放大核补值——两者直接对应公式里的 REDUCE 与 EXPAND。重建出的 `reconstructed` 与原始 `img` 几乎逐点相等，这就是「拉普拉斯金字塔可无损重建」的实证。

### 多尺度特征与模板匹配

小物体在大图上不好找，但把图降几层分辨率，物体就变「大」了。**在金字塔的每一层上做特征检测/模板匹配，尺度问题就被离散化了**——这正是 SIFT 检测器（DoG = 高斯金字塔相邻层相减）与多尺度模板匹配的做法。每层对应一个「尺度」，层间插值还能得到亚层级的连续尺度。

### 图像融合：多波段混合

拼接全景图时，直接在原始分辨率上融合，会因两张图亮度/结构差异露出生硬接缝。**多分辨率融合（multi-band blending）** 把两张图各自建成拉普拉斯金字塔，按尺度分别加权融合，再重建：低频（整体光照）慢慢过渡，高频（细节）在哪边清晰就偏向哪边——这就是经典全景拼接（如 Photoshop Photomerge、OpenCV Stitcher）背后的核心技巧。<span class="marginnote">这也是「金字塔金字塔」最优雅的一次展示：<strong>不同尺度的问题用不同尺度的金字塔层解决</strong>——融合接缝是低频问题，细节对齐是高频问题，分开处理。</span>

### 图像压缩

拉普拉斯金字塔的残差层稀疏、熵低，量化后压缩率可观——这在 JPEG 出现前是静态图像压缩的重要方案。JPEG 2000 的小波编码，正是金字塔思想的现代升级：把「带通层」换成更精致的小波子带。

把两种金字塔对照着看，差别与分工一目了然：

|  | 高斯金字塔 | 拉普拉斯金字塔 |
| --- | --- | --- |
| 存什么 | 逐级模糊 + 缩小后的图像 | 相邻级间的残差（细节） |
| 构建 | REDUCE = 平滑 + 下采样 | $L_k = G_k - \mathrm{EXPAND}(G_{k+1})$ |
| 层数 | 一直降到极小 | 比高斯少一层（顶层存 $G_n$） |
| 信息量 | 冗余，可重建 | 稀疏，近无损压缩 |
| 典型用途 | 多尺度模板匹配、DoG 检测 | 多波段融合、压缩 |

## 6 小结

- 直接下采样会**混叠**：降分辨率前必须先**高斯低通滤波**——「先模糊、后抽样」。
- **高斯金字塔**：反复 REDUCE（平滑 + 抽样），分辨率逐层减半，越往上越糊。
- **拉普拉斯金字塔**：存残差 $L_k = G_k - \text{EXPAND}(G_{k+1})$，顶层另存 $G_n$，可**无损重建**。
- EXPAND 只是 REDUCE 的近似逆，残差非零正是它编码细节的原因；拉普拉斯层 ≈ 带通滤波。
- 三大用途：**多尺度检测/匹配**、**多波段图像融合**、**图像压缩**。
- REDUCE 标准核 $[1,4,6,4,1]/16$：抗混叠与保信号的平衡。

在下一节，我们将跳出空间域，登上图像处理最强大的舞台——**傅里叶变换与频域滤波**。卷积定理会把「卷积」变成「逐点相乘」，而金字塔里的「带通」「低通」，在那里会获得一个精确、优美的频谱语言。
