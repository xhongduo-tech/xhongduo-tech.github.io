## 为什么从双流网络开始

早期视频理解用"单帧 CNN + 时间池化"，把"时间"简单平均掉——但动作识别（"挥手"、"跑步"）的核心信号恰恰在**运动**里：光流告诉模型"哪里在动、怎么动"。2014 年，Simonyan 与 Zisserman 提出**双流网络（Two-Stream）**：**用两个独立分支分别建模"空间"与"时间"，最后融合**。

- **空间流（spatial stream）**：输入单帧 RGB——识别"场景与物体"（是什么、在哪）。
- **时间流（temporal stream）**：输入**光流堆（optical flow stack）**——识别"运动模式"（怎么动）。

双流网络首次系统性地把"外观"与"运动"解耦，成为视频理解的标准范式之一。它的思想——**"不同模态的信号分开建模再融合"**——也启发了后来的 SlowFast、多模态学习。<span class="marginnote">为什么用光流而不是直接给 CNN 连续帧？因为 CNN 学"运动"很难——单帧网络看到的是"静止的图片"，相邻帧的差异（运动）没有被显式编码。<strong>光流把"运动"从像素里显式提取出来</strong>（我们前文学过），直接喂给网络，网络就能学到"挥手 vs 招手"的运动差异。<strong>"显式预处理把难学的信号变成好学的信号"</strong>是双流的设计哲学。</span>

## 1 双流的架构

双流网络的结构：

```
RGB 帧 ─────────→ 空间流 CNN ────→ 空间特征
                                        ↘ 融合 → 动作类别
光流堆（多帧光流）─→ 时间流 CNN ───→ 时间特征
                                        ↗
```

- **空间流**：标准 2D CNN（AlexNet/VGG），输入单帧（或几张随机帧）。
- **时间流**：同样的 2D CNN，输入**堆叠的光流图**——连续 $L$ 帧的光流，每帧光流有 $(u, v)$ 两个分量，堆成 $2L$ 通道的输入（如 $L=10$ → 20 通道）。

**关键：时间流的输入是"运动证据"而非原始帧**——网络在这个输入上学到"这种运动模式属于哪个动作"。

## 2 光流堆：怎么把运动喂给网络

**光流堆（optical flow stack）**的构造：

1. 对视频的连续 $L$ 帧，计算相邻帧之间的光流（用前面学的 LK/Farnebäck 稠密光流）。
2. 每帧光流是一个二通道图（水平位移 $u$ + 垂直位移 $v$）。
3. 把 $L$ 帧的光流堆成 $2L$ 通道的"运动张量"，作为时间流的输入。

**为什么堆叠多帧光流？** 一个动作（如"踢腿"）由一段时间内的运动模式定义——**单帧光流只给"此刻在动"，多帧光流给"动作的轨迹"**。堆叠让网络能识别"腿从下往上抬"这类时序运动。

**辨析｜易错点：** 光流计算本身是**离线预处理**——训练与推理都要先算光流（用 OpenCV `calcOpticalFlowFarneback` 等）。**光流预计算是双流的开销与限制**（每帧都要跑一次光流），也是后来 SlowFast 用"高帧率分支"替代光流的动机。

## 3 融合策略：什么时候把两流合起来

双流最后要融合空间与时间的判断，三种时机：

- **晚期融合（late fusion）**：两流各自输出类别得分，直接**平均或加权**——最简单，两流独立训练。
- **中期融合（mid-level fusion）**：两流的**特征在中间层拼接/相加**，再接分类层——让网络学"空间特征与运动特征如何组合"。
- **早期融合（early fusion）**：把 RGB 与光流在输入层就拼接——网络从头学两模态的联合表示（但输入通道暴增）。

**融合时机的选择**：晚期简单但"两流各自为政"；中期让网络学"外观 × 运动的组合"（如"人 + 挥动 = 挥手"）——通常中期融合效果最好。<span class="marginnote">双流的"两模态"思想是多模态学习的雏形：空间流 ≈ "外观模态"，时间流 ≈ "运动模态"——与后文 CLIP 的"图像模态 + 文本模态"、视听学习的"视觉 + 音频"是同一个架构母题：<strong>"不同信号分开编码、联合决策"</strong>。双流网络是"多模态"思想在视频里的最早成功之一。</span>

## 4 公式解析：光流堆的通道结构

**"堆"到底怎么组织？** 拆解时间流的输入张量。

- **第一步，单帧光流**：第 $t$ 帧与第 $t+1$ 帧的光流图，每个像素给位移 $(u_t, v_t)$——**二通道图** $F_t \in \mathbb{R}^{H\times W\times 2}$。
- **第二步，堆叠**：取 $L$ 帧光流 $F_1, F_2, \ldots, F_L$，在通道维拼接：

$$
\mathcal{F} = [F_1; F_2; \cdots; F_L] \in \mathbb{R}^{H \times W \times 2L}
$$

- **第三步，语义**：$2L$ 个通道 = "时间维展开的空间运动场"。**2D CNN 把每个通道当一张图**——它在"多通道运动图"上滑动卷积，学到"这个时空运动模式像什么动作"。
- **第四步，为什么不直接 3D 卷积**：3D 卷积是"空间×时间联合建模"；双流是"时间编码成通道，2D 卷积学"——**前者参数量大、后者把时间"压"进通道**，两者是对时间建模的两种取舍（3D CNN 是下一节）。

**一句话：光流堆 = 把"时间运动"重排成"多通道图"，让成熟的 2D CNN 直接消费时间信息——用"通道"装"时间"是双流的工程巧思。**

## 5 双流的贡献与局限

双流的贡献：

- **首次显式建模运动**：把"光流"这个经典视觉信号接入深度学习，动作识别大幅提升（UCF101 上接近 90%）。
- **确立"外观 + 运动"的范式**：为 SlowFast（低帧率外观 + 高帧率运动）等后续方法奠定思想。

局限：

- **光流预计算的成本**：每帧算稠密光流很贵，限制了端到端与实时。
- **两流是"两个模型"**：参数翻倍，训练更复杂。
- **光流本身的误差**：光流算错，时间流跟着错（误差传导）。

**这些局限直接催生了 SlowFast**——用"高帧率分支"隐式学运动，不再显式算光流。

## 6 双流的遗产

双流的"外观/运动二分"影响深远：

- **SlowFast**：低帧率路径（外观）+ 高帧率路径（运动），但运动由"高帧率 CNN"学，不再用光流。
- **3D CNN 与视频 Transformer**：I3D 甚至把光流也喂给 3D 卷积（Two-Stream I3D），在 Kinetics 上达到当时最佳。
- **行为识别的多模态化**：骨架（姿态）+ RGB + 光流的融合，都是"多流"思想的扩展。

**"把问题按模态拆开、各自建模、联合决策"**是双流留给视频理解（乃至整个多模态学习）的方法论遗产。<span class="marginnote">把双流与全书主线对照：光流是前文《运动与跟踪》的主角，双流把它重新变成"学习的输入"——<strong>"经典信号成为深度学习的特征"这条转化线再次出现</strong>（SIFT → R-CNN 特征、Haar → 深度检测、光流 → 双流）。经典方法的价值不在"被使用"，而在"被重新激活"——好的算法思想会被更新的工具以新的方式继承。</span>

## 7 双流思想的现代遗产

双流网络是"运动建模"的重要一站，它的思想至今活跃：

**双流的三层遗产**：

1. **"外观 + 运动"的二分**：SlowFast 用"低帧率外观 + 高帧率运动"隐式实现双流；现代动作识别仍默认"既看场景也看运动"——"**双流把'看什么'分成两个维度**"。
2. **多模态/多流融合**：骨架 + RGB + 光流 + 音频的多流融合（行为识别、多模态）——"**双流是'多流'的特例**"。
3. **光流作为特征**：双流让"光流"从经典算法变成"深度学习的输入特征"——"**经典信号在学习框架里重生**"。

**双流 vs 3D 卷积 vs 注意力**：

| 方法 | 运动建模 | 光流依赖 | 端到端 |
| --- | --- | --- | --- |
| 双流 | 显式（光流分支） | 是 | 部分 |
| 3D CNN | 隐式（时间维卷积） | 否 | 是 |
| 视频 Transformer | 隐式（时空注意力） | 否 | 是 |

**双流的教训**：它证明"**显式建模运动（光流）**"有效，但也暴露了"**光流预计算的成本与误差**"——后续方法（3D CNN、SlowFast）用"让网络自己学运动"替代显式光流。**"显式先验 vs 隐式学习"的权衡**在运动建模里再次上演——**"先验省学习但受限，学习省设计但要数据"**。

**双流在现代的定位**：虽然 3D CNN/Transformer 已成主流，但"**外观-运动分离**"的视角依然指导着架构设计（SlowFast 的双路径正是双流的现代化身）——"**经典思想以新形式延续**"。

## 8 小结

- **双流网络** = 空间流（单帧 RGB，外观）+ 时间流（光流堆，运动）→ 融合。
- **光流堆**：把 $L$ 帧光流的 $u,v$ 分量堆成 $2L$ 通道，让 2D CNN 消费时间。
- **光流显式编码运动**，网络学"运动模式 → 动作"。
- 融合时机：晚期（得分平均）/中期（特征拼接）/早期（输入拼接），中期通常最优。
- 局限：光流预计算贵、参数翻倍、误差传导——SlowFast 接棒。
