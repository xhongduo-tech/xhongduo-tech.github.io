## 为什么从采样开始

上一节结束时，光线终于穿过镜头、聚焦在传感器上——但它仍然是**连续**的光场：传感器表面的辐照度是坐标 $(x, y)$ 的连续函数。而计算机能处理的只有**离散数组**。把连续变离散，靠两个操作：**采样（sampling）**——在空间网格上取点；**量化（quantization）**——把连续的幅度值四舍五入成有限个等级。<span class="marginnote">这两步几乎是所有数字技术的共同起点：声音、图像、视频莫不如此。香农那句「复现消息」，在图像里就是「用离散像素复现连续场景」。</span>

这一节要回答三个问题：采样要多密才不会丢信息？密度不够会发生什么（**混叠**）？幅度要量化成多少级才够用？这三问，是「分辨率」「画质」「摩尔纹」这些日常概念的数学内核。

## 1 数字化：两个维度的离散化

把一张连续图像写成函数 $I(x, y)$，数字化分两步走：

- **空间采样**：在规则的网格上取点，网格间距 $\Delta$ 决定**分辨率**。采样频率 $f_s = 1/\Delta$（单位：每毫米多少个点，即 ppi 的物理版）。
- **幅度量化**：把每个点的亮度值 $I$ 映射到 $2^B$ 个离散等级，$B$ 是**位深（bit depth）**。8 位图像有 256 级灰度，16 位有 65536 级。

两条轴独立、互不干扰，但各自都有自己的「够用」标准——空间轴靠**奈奎斯特定理**，幅度轴靠**信噪比**。下面分别处理。顺带一提，数码相机规格表上的两个招牌数字——分辨率与位深——对应的正是这两条轴。

## 2 采样定理：多快才算够

先从一维说起，图像是它的二维推广。设信号是角频率为 $f$ 的纯余弦 $I(x) = \cos(2\pi f x)$，以间隔 $\Delta$ 采样，采样频率 $f_s = 1/\Delta$。直觉告诉我们：**采样点太稀，波形的起伏会被漏掉**。多少才算「不稀」？

**奈奎斯特-香农采样定理（Nyquist-Shannon sampling theorem）**：若信号的最高频率为 $f_{\max}$，则当且仅当

$$f_s > 2\, f_{\max}$$

时，可以从采样值**无失真地重建**原连续信号。<span class="marginnote">$2 f_{\max}$ 叫奈奎斯特率；$f_s/2$ 叫奈奎斯特频率，是「这套采样能忠实记录的最高频率」。</span>严格地说，定理要求信号**带限**（频率有上界），重建用的是辛克（sinc）插值——那正是后面《傅里叶变换与频域滤波》一节的主场。

对图像来说：图像的「频率」是明暗变化的快慢——纹理越细密，高频越丰富。网格采样等价于把空间频率限制在 $[-f_s/2,\, f_s/2]$，**超过奈奎斯特频率的细节，采样点根本记不下来**。

带一组真实数字：全画幅传感器宽 $36\,\mathrm{mm}$、横向 $6000$ 像素，采样间距 $\Delta = 36/6000 = 6\,\mu\mathrm{m}$，采样频率 $f_s \approx 167\,\text{点/mm}$，奈奎斯特频率约 $83\,\text{点/mm}$。一支 f/8 镜头的艾里斑直径 $2.44\lambda N \approx 10.7\,\mu\mathrm{m}$（$\lambda = 550\,\mathrm{nm}$），已经接近两个像素——**镜头的低通效应恰好落在奈奎斯特频率附近生效**。这就是上一节「衍射是天然防混叠」的一个量级佐证。

## 3 公式解析：混叠——高频如何伪装成低频

采样密度不够时，高频成分不会简单地「消失」，而是会**伪装成另一个低频成分出现**。这个现象叫**混叠（aliasing）**。它为什么必然发生？用一条式子就能看穿。

设采样间隔 $\Delta = 1/f_s$，采样点在 $x = n\Delta$，$n$ 是整数。观察两个不同频率的余弦：

$$
\cos\left(2\pi f\, n\Delta\right) \quad\text{与}\quad \cos\left(2\pi (f_s - f)\, n\Delta\right)
$$

工程上还有一条铁律：**绝不在理论值上贴边采样**。奈奎斯特定理说「$> 2 f_{\max}$ 即充要」，但辛克重建对噪声、截断与量化误差极其敏感，实际系统普遍留出 2–5 倍余量：专业相机按 2–3 倍过采样设计，音频系统常取 4 倍以上。**「刚好够」只属于理想世界，工程世界要的是「足够宽裕」。**

**第一步，代入 $n\Delta = n/f_s$**：第二个式子写成

$$\cos\!\left(2\pi (f_s - f)\,\frac{n}{f_s}\right) = \cos\!\left(2\pi n - 2\pi f\,\frac{n}{f_s}\right)$$

**第二步，用三角恒等式**：$\cos(2\pi n - \theta) = \cos(-\theta) = \cos\theta$，于是它严格等于第一个式子：

$$\cos\!\left(2\pi (f_s - f)\, n\Delta\right) = \cos(2\pi f\, n\Delta)$$

**第三步，读出结论**：两个频率 $f$ 与 $f_s - f$，在采样值上**完全无法区分**。当 $f > f_s/2$（超过奈奎斯特频率）时，$f_s - f < f_s/2$——一个高频被「折叠」成了一个低频。<span class="marginnote">频率轴就像一张纸，在 $f_s/2$ 处对折：高于奈奎斯特频率的部分被折回低频区。英文把混叠频率叫 alias（别名），正是「同一个采样序列，却有两个身份」。</span>

这就是 jaggies（锯齿）、moiré（摩尔纹）与「车轮倒转」的同一数学根源：**采样遗漏的周期信息，被重新解读成一个更慢的周期**。

```python
import numpy as np

fs = 1.0                      # 采样频率 1 Hz → 奈奎斯特频率 0.5 Hz
n = np.arange(0, 20)          # 采样时刻（整数秒）

alias_high = np.cos(2*np.pi*0.8*n)   # 0.8 Hz：超过奈奎斯特频率的高频
alias_low  = np.cos(2*np.pi*0.2*n)   # 0.2 Hz：与高频在采样点上严格相等
print(np.max(np.abs(alias_high - alias_low)))  # ≈ 0 —— 无法区分
```

这就是混叠的直观面貌：同一组采样点，既可以被解释成 0.8 Hz 的高频，也可以被解释成 0.2 Hz 的低频——而人眼与算法都倾向「相信」那个更慢、更平滑的解释。

## 4 量化：灰度分辨率与量化噪声

空间轴讲完了，再看幅度轴。把连续的亮度 $I$ 量化成 $2^B$ 级，量化步长（每级间隔）为

$$q = \frac{V_{\max} - V_{\min}}{2^B}$$

量化误差均匀分布在 $[-q/2, q/2]$，均方根约为 $q/\sqrt{12}$。把信号功率与量化噪声功率之比写成 dB，得到那条工程师人手一册的经验公式：

$$\mathrm{SNR}_q \approx 6.02\,B + 1.76\ \mathrm{dB}$$

**每增加 1 位位深，量化信噪比提高约 6 dB**。<span class="marginnote">6.02 dB/位 来自「$2^B$ 个等级对应 $2B$ 倍动态范围，功率翻倍即 +6 dB」。这个公式在音频 ADC、相机、传感器里通用。</span>8 位图像约 48 dB，16 位约 98 dB。

**辨析｜易错点：** 位深不够的表现不是「噪点」而是**条带（banding / posterization）**——平滑渐变（如天空）被切成一圈圈可见的色环。它和采样混叠是两类错误：**混叠丢的是空间信息，条带丢的是幅度精度**；混叠源于采样率不够，条带源于位深不够。修复手段也完全不同：前者靠更密采样或光学低通滤波，后者靠更高位深或抖动（dithering）。

一个可见的例子：8 位图像把 $[0, 255]$ 分成 256 级，相邻两级的相对差约 $1/255 \approx 0.4\%$；在拉过对比度的天空渐变里，这个步长足以被肉眼分辨成色环。把同一张图存成 10 位或 16 位，条带立刻消失——这也是「HDR 要高位深」的直接原因。

## 5 相机的采样链与防混叠

真实相机不会让「超过奈奎斯特频率的细节」直接冲进像素——那样会产生摩尔纹。它的采样链是层层防混叠的：

1. **镜头点扩散函数（PSF）**：即使完美对焦，衍射也把点光源展成艾里斑，等效于一个低通滤波——上一节的衍射极限，在这里反而成了「自然的防混叠」。
2. **光学低通滤波片（OLPF）**：许多相机在传感器前加一片双折射晶体，刻意把像微糊一点点，压掉高于奈奎斯特频率的细节。<span class="marginnote">这就是为什么某些高端机「去掉了低通滤波」会提高锐度，却也更容易出摩尔纹。防混叠的本质是「先滤后采」：在采样之前，把带限做好。</span>
3. **感光元件的面积积分**：每个像素不是采「一个点」，而是对它覆盖的整个面积的光强做平均——又一个天然的平滑。
4. **ADC 与去马赛克**：模拟电压经模数转换量化，然后按**拜耳阵列（Bayer array）**去马赛克插值出彩色——这一步预告了下一节《颜色空间》。

**辨析｜易错点：** 「分辨率越高就一定越好」是常见误区。分辨率提高意味着每个像素面积变小、进光量变少、散粒噪声相对增大；同时数据量、存储与计算成本按平方上升。<span class="marginnote">深度学习里下采样、池化（pooling）同样面临混叠问题：步长大于 1 的卷积或池化，本质都是「不预滤波的降采样」，业界也确有在池化前加平滑来减少混叠的研究。</span>工程上讲究「够用就好」：匹配任务所需的频率范围，而不是盲目堆像素。

把整条采样链收个尾：镜头 PSF 已滤掉一部分高频，光学低通滤波再滤掉一部分，面积积分再平滑一层，最后 ADC 的量化再丢一点幅度——**每一步都在与信息丢失博弈**。设计成像系统的正确心态，是接受「必然有损」，再把损失放到人眼或算法最不敏感的地方。

## 6 小结

- **数字化 = 空间采样 + 幅度量化**，两条轴各自独立、各有标准。
- **奈奎斯特-香农采样定理**：$f_s > 2 f_{\max}$ 是带限信号无失真重建的充要条件。
- **混叠**：$f$ 与 $f_s - f$ 在采样值上不可区分，超奈奎斯特频率的高频被折叠成低频——锯齿（jaggies）、摩尔纹（moiré）、车轮倒转同源。
- **量化**：$2^B$ 级灰度，$\mathrm{SNR}_q \approx 6.02B + 1.76$ dB；位深不足表现为**条带**而非噪点。
- 相机的防混叠靠**镜头 PSF + 光学低通滤波 + 面积积分**层层把关：先滤后采。
