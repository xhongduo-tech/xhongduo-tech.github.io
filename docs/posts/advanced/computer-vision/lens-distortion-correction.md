## 为什么从去畸变开始

上一节标定法给出了畸变系数 $k_1, k_2, p_1, p_2$（也许还有 $k_3$），但"知道畸变"和"消除畸变"是两件事。**去畸变（undistortion / distortion correction）**把一张弯曲的图像"捋直"：直线变回直线，边缘的物体不再被拉伸。它是几乎一切高质量视觉任务的**前置清理步骤**——SLAM 里不去畸变，特征匹配和三角测量会系统性出错；自动驾驶里不去畸变，车道线检测会偏；全景拼接里不去畸变，接缝会错位。

这一节回答两个问题：**去畸变的数学本质是什么？工程上怎么实现得又快又对？** 答案是"反向映射 + 迭代求逆"与"查表 + 预计算"这两个组合拳。<span class="marginnote">去畸变听起来是"把畸变去掉"，但实现时并不直接算"去畸变的公式"——畸变模型是"理想→畸变"的正向映射，去畸变需要它的逆映射。逆映射没有闭式解（五阶多项式求逆），所以工程上用迭代或近似。这是"正向好算、逆向要解"类问题的一个典型。</span>

## 1 问题的两面：畸变与去畸变

**正向（畸变）**：理想坐标 $(x, y)$ → 畸变坐标 $(x_d, y_d)$：

$$
\begin{aligned}
x_d &= x(1 + k_1 r^2 + k_2 r^4 + k_3 r^6) + 2p_1 xy + p_2(r^2 + 2x^2) \\
y_d &= y(1 + k_1 r^2 + k_2 r^4 + k_3 r^6) + p_1(r^2 + 2y^2) + 2p_2 xy
\end{aligned}
$$

**逆向（去畸变）**：给定畸变坐标 $(x_d, y_d)$，求理想坐标 $(x, y)$。由于畸变是"坐标的一个非线性函数"，$x$ 出现在等式两边，没有显式逆。

**辨析｜易错点：** 很多人以为去畸变 = 把上面公式"移项解出来"，其实不成立。正确姿势是**迭代**：从 $x \leftarrow x_d$ 出发，反复把当前 $x$ 代入正向模型得到更接近 $x_d$ 的预测，用误差修正 $x$，几次迭代就收敛到亚像素精度。或者用**反向映射 + 数值逆**——从目标像素出发，问"这个无畸变像素对应哪个畸变像素"。

## 2 去畸变的实现范式：反向映射

工程实现的黄金范式是**反向映射（backward mapping）**，与《图像插值》一节一脉相承：

1. **目标**：逐像素遍历**去畸变后的输出图**，坐标为无畸变的 $(u, v)$。
2. **反内参**：$u, v$ → 归一化无畸变坐标 $(x, y) = ((u-c_x)/f_x, (v-c_y)/f_y)$。
3. **求畸变前的位置**：用迭代或近似把 $(x_d, y_d)$ 求出来（即"无畸变的这个点，在畸变图里本来是哪里"）。
4. **内参化 + 采样**：$(x_d, y_d)$ → 像素坐标 $(u_d, v_d) = (f_x x_d + c_x, f_y y_d + c_y)$，在**原畸变图**上用双线性插值采样。

**为什么必须反向映射？** 正向映射（遍历畸变图、写到无畸变图）会产生空洞与重叠，而反向映射每个输出像素恰好取一次值、不重不漏。<span class="marginnote">对比正向映射：畸变图角落的点会被"展开"到无畸变图更大的区域，中间稀疏、边缘密集，直接写会留下大量空洞。反向映射天然规避了这个问题——它问的不是"原图像素去哪了"，而是"目标像素从哪来"，保证输出图每个像素都有值。</span>

## 3 求逆的两条路线：迭代与解析近似

**路线一：固定点迭代（最常用）。** 由于畸变量通常很小（$k_1$ 是 $10^{-1}$~$10^{-3}$ 量级），$x_d \approx x$，因此迭代收敛极快。算法：

1. 初始化 $x \leftarrow x_d$，$y \leftarrow y_d$。
2. 把当前 $(x,y)$ 代入正向畸变模型，得预测 $(\tilde x_d, \tilde y_d)$。
3. 更新 $x \leftarrow x_d - (\tilde x_d - x)$，$y \leftarrow y_d - (\tilde y_d - y)$。
4. 重复 2~3 步，通常 **5 次以内**收敛到亚像素精度。

这是不动点迭代（fixed-point iteration），每次更新用"当前预测误差"修正。它的好处是**只依赖正向模型**，模型换成高阶/鱼眼也照样工作。

**路线二：查表（look-up table，LUT）。** 因为畸变系数在标定后就固定了，**每对像素的映射关系只需要算一次**：

离线预计算一张**映射表**：输出图每个像素 $(u,v)$ 对应的源采样坐标 $(u_d, v_d)$，存成两个 float 图（OpenCV 的 $(u,v)$ 正是干这个）。
在线处理时，只做一次 `cv2.remap()`（重映射 + 双线性插值），GPU 上极快。

**查表把"每个像素做迭代求逆"变成"一次性预计算 + 实时查表采样"**，是视频级去畸变的标准做法。<span class="marginnote">OpenCV 的三步曲完美体现这条路线：`getOptimalNewCameraMatrix`（可选裁剪）→ `initUndistortRectifyMap`（生成 LUT）→ `remap`（查表重采样）。换帧率换分辨率都不怕，因为 LUT 只依赖内参与畸变、不依赖图像内容。这张 LUT 本质上就是把"迭代求逆"预先摊平到一张图里。</span>

## 4 公式解析：固定点迭代为何收敛

**为什么"代入正向模型、减误差"能求出逆？** 把它写成压缩映射的框架。

**第一步，改写为不动点**：去畸变要求 $g(x) = x_d$（$g$ 是畸变函数）。定义 $F(x) = x_d - g(x) + x$，则 $x^*$ 满足 $g(x^*)=x_d$ 当且仅当 $F(x^*) = x^*$——**解方程变成了找不动点**。
**第二步，迭代**：$x^{(k+1)} = F(x^{(k)})$。我们的更新 $x \leftarrow x_d - (\tilde x_d - x)$ 正是 $x_d - g(x) + x = F(x)$。
**第三步，收敛性**：$F'(x) = 1 - g'(x)$。畸变模型 $g'(x) \approx 1 + 3k_1 r^2 + \cdots$，当 $r$ 不太大且 $k_1$ 小时 $|F'| < 1$——$F$ 是压缩映射，巴拿赫不动点定理保证迭代收敛。边缘（$r$ 大）处收敛慢，所以高阶畸变或鱼眼需要更多次迭代或解析初值。
**第四步，收敛速度**：每次迭代误差缩小约 $|F'|$ 倍，$|F'| \approx 3k_1 r^2$ 通常 $\ll 1$，5 次迭代足以把误差压到亚像素。

**一句话：去畸变求逆 = 构造压缩映射做不动点迭代，收敛速度由"畸变量"决定，畸变越小收敛越快。** 这也解释了为什么"先忽略畸变用线性解、再迭代修正"在工程里几乎总是够用。

## 5 工程要点与评价

实现去畸变时要注意：

**边界处理**：去畸变后图像边缘出现无数据区域（黑色三角），用 `getOptimalNewCameraMatrix` 调整内参（缩放 + 平移主点）让有效区域最大化，或直接裁剪。
**尺度**：畸变模型作用在**归一化坐标**，实现时务必先反内参再处理畸变，最后再乘回内参——顺序错了，$k$ 值全失效。
**精度**：重投影误差、去畸变后直线的平直度（把原图里的直线检测一遍看曲率）是两种评价方式。
**批量**：视频里每帧调 `remap`，LUT 只建一次；内存敏感时可降采样 LUT 再插值。

深度学习的"畸变校正"（如无标定的畸变估计网络）近年也在推进，但**标定 + 去畸变的几何范式在量产的 AR/VR、自动驾驶里仍是主体**——因为它可解释、可验证、误差可控。<span class="marginnote">去畸变与图像拼接形成对照：拼接用单应做"图到图"的平面配准，去畸变做"相机坐标系内"的光线修正。两者都要插值、都要反向映射、都要权衡边界，理解其一就通了另一个。这也再次说明插值那节学到的"反向映射 + 双线性"是图像几何操作的通用骨架。</span>

## 6 去畸变的工程细节与评估

去畸变的实现质量与验证，几个实操要点：

- **LUT 的精度与内存**：全分辨率 LUT（两张 float 图）内存大——**"降采样 LUT + 插值"** 是内存与精度的折衷；GPU 上可存半精度。
- **去畸变与校正的顺序**：单目先去畸变、双目再极线校正——**"顺序错了，畸变残留会污染匹配"**（前文讲过）。
- **迭代求逆的实现**：固定点迭代的初值 $x \leftarrow x_d$ 在畸变小收敛快；**大畸变（鱼眼）用解析近似或更多迭代**——"迭代次数按畸变量设"。
- **边界与裁剪**：去畸变后边缘无数据——**"先算有效 ROI（getOptimalNewCameraMatrix）再裁剪"**，避免黑边影响下游。

**去畸变质量的评估**：

- **直线度检验**：找原图里的直线（如建筑物边缘），去畸变后**它们应该变直**——"直线变直"是最直观的验证。
- **重投影误差**：标定的角点重新投影，误差应 < 0.3 像素——"标定 + 去畸变的联合精度"。
- **多视角一致性**：同一 3D 点在多张去畸变图里应对齐（对极误差小）——"去畸变让多视图几何成立"。

**去畸变与深度学习的对话**：**学习式畸变校正**（无标定、端到端估计畸变参数）近年出现——但**"标定 + 去畸变"的几何范式在精度与可解释性上仍是标准**。**"几何可验证处用显式方法，语义模糊处用学习方法"**——这个分工在畸变校正里同样适用。去畸变虽"不起眼"，却是几乎所有高质量几何视觉（SLAM、重建、拼接）的**前置工序**——"每个像素的位置对不对，从这里开始"。

## 7 畸变建模的现代发展

畸变建模（标定 + 去畸变）在现代的发展，几个方向：

- **更精细的畸变模型**：鱼眼（等距投影模型）、径向 + 切向的扩展（rational model）、环形畸变——"**不同镜头要配不同畸变模型**"，鱼眼与普通镜头的模型完全不同。
- **无标定去畸变（自校正）**：从多视图/线条先验估计畸变参数，无需标定板——"**从图像自身恢复畸变**"（如"直线应直"先验）。
- **学习式去畸变**：CNN 直接预测畸变校正图（端到端）——"**学习近似几何**"，对极端畸变（鱼眼）更鲁棒。
- **畸变与深度学习的交互**：畸变会影响 CNN 的感知（边缘变形）——"**大畸变镜头 + 深度模型要配去畸变前处理**"。

**畸变模型的本质**：畸变是"镜头光学与理想针孔的偏差"——**"模型越贴近物理，校正越准"**。普通镜头多项式够用，鱼眼要专门的投影模型，极端镜头要学习——"**模型的复杂度要匹配镜头的复杂度**"。

**对学习者的启示**：畸变校正是一面镜子，照出"**几何建模的方法论**"——"**先用物理模型描述现象，再求逆，再迭代求解**"。这个"建模-求逆-求解"的三部曲，是几何视觉的通用方法论——"**理解畸变校正，就理解了'物理建模 + 数值求逆'的模板**"。

## 8 小结

- **去畸变 = 求畸变模型的逆**：正向好算、逆向没有闭式解，用**固定点迭代**（5 次内收敛）或 **LUT 预计算**。
- 实现范式是**反向映射**：遍历无畸变输出像素 → 反内参 → 求逆畸变 → 内参化 → 在原图插值采样。
- 收敛性由**压缩映射**保证：$|1 - g'(x)| < 1$ 时迭代收敛，畸变越小越快。
- OpenCV 三步曲：`getOptimalNewCameraMatrix` → `initUndistortRectifyMap` → `remap`。
- 顺序铁律：**归一化坐标上做畸变**，先反内参、后乘内参。
