## 为什么从 SfM 开始

上一节的 BA 是"已知相机与点的初值后的精化"，但初值从哪来？**运动恢复结构（Structure from Motion，SfM）**回答这个问题：**给定一组无任何先验的普通照片，同时恢复每台相机的位姿（运动）与场景的三维结构**。它是从"一堆照片"到"三维模型"的完整流水线，是三维重建、SLAM、AR、数字孪生的公共地基。

**COLMAP** 是 SfM 的开源实现事实标准：从特征提取到增量重建到 BA 精化，一条龙。理解 SfM 的流程，就理解了"从 2D 到 3D"的完整逻辑；会跑 COLMAP，就掌握了三维重建的第一生产力工具。<span class="marginnote">SfM 与 SLAM 的异同：SfM 是"离线、批处理"——拍完一堆照片再重建，无实时性要求，追求精度；SLAM 是"在线、增量"——边移动边重建，追求实时与鲁棒。<strong>两者共享核心：特征匹配 + 对极几何 + 三角测量 + BA</strong>——SfM 是 SLAM 的"离线兄弟"。</span>

## 1 SfM 的整体流水线

SfM 的标准流程（COLMAP 的默认路线）：

1. **特征提取与匹配**：对每张图提取特征（SIFT 等）并匹配，得到两两之间的对应点。
2. **几何验证**：用 RANSAC + 对极几何（基础矩阵/单应）验证匹配，剔除误匹配。
3. **初始化**：选一对充分匹配的图，估计相对位姿（本质矩阵分解），三角测量出初始 3D 点。
4. **增量注册**：把新图像逐步加入——用 PnP（Perspective-n-Point）估计新图位姿，三角测量新 3D 点。
5. **BA 精化**：每次加入若干图后做局部/全局 BA，修正累积误差。
6. **全局对齐**：所有图注册完后做一次全局 BA，得到一致的三维重建。

**SfM = 匹配 → 对极 → 三角 → 增量注册 → BA**——它把前面学的所有几何工具串成一条完整流水线。

## 2 初始化与增量注册

**初始化**是 SfM 的第一难关：选哪两对图作为种子？标准做法：

- 选**匹配数多、基线合适**（既不过近也不过远）的图像对。
- 估计本质矩阵 $E$（五点法 + RANSAC），分解出 $R, t$。
- 三角测量公共匹配点，得初始 3D 点云与相机位姿。

**增量注册（incremental registration）**是 SfM 的心脏：每加入一张新图，用 **PnP（Perspective-n-Point）**——已知 3D 点与其 2D 投影，估计相机位姿（$n \ge 3$ 个对应点，DLT 类方法）。加入后再三角测量新 3D 点、再做 BA 精化。

**为什么增量而不是"一次全部注册"？** 因为新图的位姿依赖已重建的 3D 点——**必须先有"已知的世界"，才能定位"新的相机"**。增量式"边建边加"最稳，代价是误差会随重建增长（靠 BA 压制）。

## 3 公式解析：PnP 为什么能"由点到位姿"

**PnP 是 SfM 注册新图的引擎**。已知 $n$ 个 3D 点 $X_j$ 与它们在图像里的投影 $\mathbf{x}_j$，求相机位姿 $[R \mid t]$。投影方程：

$$
\lambda_j \mathbf{x}_j = K [R \mid t] X_j
$$

逐步拆解解法：

- **第一步，消去深度**：用叉积消掉 $\lambda_j$：$\mathbf{x}_j \times (K[R|t]X_j) = 0$——每个 3D-2D 对应给出 2 个独立方程。
- **第二步，未知数**：$R, t$ 共 6 个自由度。**3 个点给 6 个方程**——理论最小样本是 3 点（P3P，解多项式）。
- **第三步，DLT 线性解**：堆 $n$ 个点的方程成 $A\mathbf{p} = 0$（$\mathbf{p}$ 是 $[R|t]$ 的 12 个元素），SVD 解零空间——**注意结果要投影回合法的旋转矩阵（正交 + 行列式 1）**。
- **第四步，RANSAC 搭配**：实际中先 P3P + RANSAC 挑内点，再用所有内点做非线性优化（最小化重投影误差）精化——**与八点法、单应估计完全同一套路**。

**一句话：PnP 用"3D 点 → 2D 投影"的对应，反解相机位姿——它是"已知世界定位相机"的标准工具，也是 SfM 增量注册、AR、SLAM 重定位的通用引擎。**

## 4 COLMAP：从命令到实践

COLMAP 是 SfM 的事实标准开源实现。核心命令（自动特征提取 → 匹配 → 稀疏重建）：

```
colmap feature_extractor --database_path db.db --image_path images/
colmap exhaustive_matcher --database_path db.db
colmap mapper --database_path db.db --image_path images/ --output_path sparse/
colmap model_converter --input_path sparse/0 --output_path sparse/0 --output_type TXT
```

实践要点：

- **特征**：默认 SIFT（GPU 加速版），配"逐图匹配 + 几何验证"。
- **稀疏重建输出**：相机内参（每图或共享）、位姿、3D 点云——这就是 SfM 的"稀疏模型"。
- **稠密重建**：COLMAP 还提供 **MVS（多视图立体）** 稠密重建（下一节），输出密集点云、深度图、网格。
- **质量检查**：看每张图注册的点数、重投影误差；丢图、错配会在重建里表现为"漂移"。

**COLMAP 的输入可以是手机随手拍的一堆照片**——拍得越"多视角重叠"、越"无运动模糊"，重建越好。它是 NeRF、3DGS 训练前的**标准预处理工具**（提供相机位姿）。

## 5 实践注意事项

SfM 实践中的常见坑：

- **采集**：环绕拍摄、相邻图重叠 50%+、避免纯旋转（退化）、避免运动模糊与反光。
- **纹理**：SIFT 在低纹理（白墙）上匹配不足——多视角 + 场景特征点够才重建得动。
- **尺度歧义**：SfM 重建的 3D 尺度是任意的（无绝对尺寸）——要真实尺度需已知参考长度或标定物。
- **重复结构**：对称建筑、重复纹理会造成"匹配二义性"，重建错乱（需要更多约束）。<span class="marginnote">把 SfM 与深度学习联系：<strong>学习式 SfM / 深度位姿估计</strong>（如 DROID-SLAM、学习式特征）把 SIFT 换成学习特征、把 BA 换成可微迭代，精度与鲁棒性大幅提升。但"匹配 → 几何 → 优化"的骨架始终不变——COLMAP 至今仍是 NeRF/3DGS 等深度重建方法的<strong>标准位姿提供者</strong>，几何方法与学习方法在此深度协作。</span>

## 6 SfM 的评测与现代演进

SfM 的评测与演进，是理解它"为什么重要"的关键：

**评测**：

- **位姿精度**：估计的相机位姿与真值（GPS/IMU 或运动捕捉）对比——**"重建的相机位置准不准"**。
- **点云精度**：重建 3D 点与真值（LiDAR 扫描）对比——"几何准不准"。
- **鲁棒性**：对噪声、低纹理、重复结构、光照变化的稳健程度——"真实场景的可用性"。
- **数据集**：COLMAP 等在大规模无序图像集（网络爬取的旅游照片）上评估——"无序输入的鲁棒性是 SfM 的试金石"。

**现代演进**：

- **全局 SfM**：不"增量边加边优化"，而是"先全局估计旋转、再平移、再三角"——**"把增量式的累积误差换成全局一次解"**（更快、更不易漂移，但对噪声更敏感）。
- **学习式 SfM**：深度特征匹配 + 可微 BA（DROID-SLAM 等）——"学习特征替代 SIFT、可微优化替代手工 BA"。
- **SfM + 神经渲染**：COLMAP 提供位姿、NeRF/3DGS 做稠密重建——**"经典几何 + 神经表示"是当前三维重建的标准组合**。

**SfM 的定位**：它是"从无序图像到三维结构"的**起点**——**"没有 SfM 的位姿，就没有 NeRF 的渲染、3DGS 的重建、AR 的定位"**。它可能"低调"，却是三维视觉最基础的地基之一——**"理解 SfM 的每一步（匹配、对极、三角、BA），就理解了整个几何视觉的核心"**。

## 7 小结

- **SfM**：从无先验照片恢复相机位姿 + 3D 结构；匹配 → 对极 → 三角 → 增量注册 → BA。
- **初始化**：选"匹配多、基线好"的图对，五点法 + 三角测量起步。
- **增量注册**：PnP 由 3D-2D 对应定位新相机，边建边加、BA 压制误差。
- **PnP**：DLT + RANSAC + 非线性精化，"已知世界定位相机"的通用工具。
- **COLMAP**：SfM 事实标准，输出相机参数与稀疏点云，也是 NeRF/3DGS 的预处理。
