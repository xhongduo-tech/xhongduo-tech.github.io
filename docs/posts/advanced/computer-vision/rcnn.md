# R-CNN：候选区域与两阶段检测的开端

## 为什么从 R-CNN 开始

检测的朴素做法是"滑动窗口 + 分类"：在图像每个位置、每个尺度放一个窗口，用分类器判断里面有没有目标。但滑动窗口的组合空间爆炸——数千个位置 × 数十个尺度 × 长宽比，每个窗口都要跑一次 CNN，算力完全不可承受。

**R-CNN（Regions with CNN features，2014）** 换了一个聪明的思路：**先用一个廉价的"候选区域生成器"猜出"哪里可能有目标"（约 2000 个区域），再只对这些区域做 CNN 分类与框回归**。它把"在 10 万位置里滑窗"变成"在 2000 个候选里精查"——计算量降了两个数量级。R-CNN 是**两阶段检测（two-stage detection）**的开端，为后续的 Fast/Faster R-CNN 铺平了道路。<span class="marginnote">R-CNN 的"候选区域"来自<strong>选择性搜索（Selective Search）</strong>——一种纯经典方法：先把图像过分割成小块，再按颜色、纹理、尺寸、形状的相似度贪心合并，输出一组可能包含目标的框。它完全没有用深度网络，却把"目标可能在哪"猜得八九不离十。<strong>经典算法当"粗筛"，深度学习当"精审"——R-CNN 展示了两种范式的成功协作</strong>。</span>

## 1 选择性搜索：猜目标在哪

**选择性搜索（Selective Search）**生成候选区域的流程：

1. **初始过分割**：用图割/分水岭把图像分成大量小区域（超像素）。
2. **贪心合并**：按"颜色相似 + 纹理相似 + 尺寸相似 + 形状互补"的加权得分，反复合并最相似的两个区域。
3. **多尺度输出**：在不同层级记录合并出的区域，输出约 2000 个**不同尺度、不同长宽比**的候选框。

**为什么 2000 个够用？** 因为真实目标在"颜色/纹理均匀的区域"里——一辆车是连续的色块，一个人是连续的身体轮廓。**选择性搜索利用了"目标在图像上是连贯区域"这一底层先验**，所以能以远少于滑窗的候选数覆盖几乎所有真实目标。

## 2 R-CNN 的三段式流水线

R-CNN 的完整流程：

1. **生成候选区域**：选择性搜索输出约 2000 个框。
2. **裁剪 + 变形 + 提特征**：把每个候选框从原图裁剪出来，**缩放到固定尺寸**（如 227×227），分别输入预训练 CNN（AlexNet）提取 4096 维特征——每个候选框一次 CNN 前向。
3. **分类与回归**：
   - 每个框的特征过一个 **SVM**（每类一个），给出类别得分。
   - 过一个**线性回归器**（每类一个），预测**框的偏移**（把候选框"修准"成目标框）。
4. **NMS**：同一目标多个候选，NMS 去重。

**R-CNN 把检测拆成"区域提议 + 特征 + 分类/回归"三个独立模块**——每个模块都可以替换升级（这正是后续演进的方式）。

**辨析｜易错点：** R-CNN 对每个候选框**独立跑一次 CNN**（约 2000 次前向），速度极慢（单张图约 50 秒）。它慢的根源是**候选框之间大量重叠，特征被重复计算**。这个"重复计算"正是 Fast R-CNN 要消灭的——"共享卷积"是两阶段检测进化的主线。

## 3 预训练 + 微调：R-CNN 的工程配方

R-CNN 的训练也示范了迁移学习：

1. **预训练**：在 ImageNet 上预训练 CNN（AlexNet）。
2. **领域微调**：在检测数据集上，用"候选框 + 真值框"微调 CNN——把 ImageNet 的 1000 类分类头换成检测任务的类数。**这一步让 CNN 从"分类特征"适应到"检测特征"**（检测要更关注目标的边界与位置）。
3. **SVM 分类器**：用微调后的 CNN 特征训每类一个 SVM（R-CNN 用 SVM 而非 softmax 是因为 SVM 对检测任务更稳、且训练数据不平衡）。
4. **框回归器**：训一个线性回归，从候选框坐标预测真值框坐标。

**R-CNN 的启发：预训练-微调-特化，三个阶段的迁移学习配方**——这套配方被后来所有检测方法继承。

## 4 公式解析：候选框如何"回归"到真值框

**框回归（bounding box regression）**预测的是**偏移量**而非绝对坐标。设候选框 $(P_x, P_y, P_w, P_h)$，真值框 $(G_x, G_y, G_w, G_h)$，回归目标定义为：

$$
t_x = \frac{G_x - P_x}{P_w}, \quad t_y = \frac{G_y - P_y}{P_h}, \quad
t_w = \log \frac{G_w}{P_w}, \quad t_h = \log \frac{G_h}{P_h}
$$

拆解为什么这么定义：

- **第一步，中心偏移归一化**：$t_x$ 是真值中心相对候选中心的偏移，**除以候选框宽**归一化——不管框多大，"中心偏移 0.2 倍宽"是同一量纲。
- **第二步，尺寸用对数**：$t_w = \log(G_w/P_w)$——把"倍率"变成"差值"，且保证预测的宽始终为正（指数映射回宽度）。**对数让"放大 2 倍"与"缩小一半"对称**。
- **第三步，学习**：线性回归器 $t = W^T \phi(P)$ 输入候选框的 CNN 特征 $\phi$，输出预测的 $(t_x, t_y, t_w, t_h)$，用 L2 损失对真值 $t^*$ 拟合。
- **第四步，解码**：预测时从 $(P_x,\ldots)$ 与预测偏移反解出目标框。**只对与真值 IoU > 0.6 的候选框训练回归器**（太远的候选不学，回归只做"精修"）。

**一句话：框回归预测的是"归一化的偏移与对数尺度"，让"粗的候选框"精确化——这是两阶段检测"先粗后精"的数学落点。**

## 5 R-CNN 的贡献与局限

R-CNN 的历史贡献：

- **首次把 CNN 引入检测并大幅刷新精度**（PASCAL VOC mAP 从 35% 提到 53%，翻倍式提升）。
- 建立了**两阶段范式**：区域提议 → 精查分类，成为后续所有高性能检测器的骨架。

它的局限同样鲜明：

- **慢**：每图约 2000 次独立 CNN 前向，50 秒/张。
- **多阶段训练**：CNN 微调、SVM、框回归器分开训，工程繁琐。
- **存储大**：每个候选的特征都要存盘。

**这些局限定义了后续演进的改进方向**：Fast R-CNN 解决"重复计算"，Faster R-CNN 解决"选择性搜索太慢"，两个都是"同骨架换引擎"的升级。<span class="marginnote">值得记住 R-CNN 的名字：Regions with CNN features——"带着 CNN 特征的区域"。它把"区域提议"（经典）与"深度特征"（新潮）拼接成检测，是"混合范式"的典型。后续演进的关键词全是"如何让深度网络直接干提议的活"——从 Selective Search 到 RPN（Faster R-CNN），再到彻底端到端（DETR）。</span>

## 6 R-CNN 的启发与现代遗产

R-CNN 虽已被超越，但它的设计思想至今影响深远：

**三条核心启发**：

1. **"提议 + 精查"的两阶段**：先廉价地"猜可能的目标"（提议），再昂贵地"仔细确认"（精查）——**"先粗筛、后精审"是处理高成本搜索的通用策略**（从检测到检索到语音识别）。
2. **迁移学习的配方**：ImageNet 预训练 → 检测数据微调 → 任务特化（SVM/回归）——**"预训练-微调"范式**从此成为深度学习的标准流程。
3. **区域即任务接口**：R-CNN 把"检测"变成"区域分类"——**"ROI（Region of Interest）"成为把 2D 检测推广到其他任务（掩码、关键点）的接口**（Mask R-CNN 的 RoI 头）。

**R-CNN 的工程遗产**：

- **Caffe/深度学习工作流**：R-CNN 示范了"开源模型 + 微调 + 部署"的完整工程——"深度学习工程化的模板"。
- **检测器进化的分水岭**：R-CNN 之前的检测（HOG/SVM、DPM）是手工特征；之后是深度特征——**"CNN 特征全面接管检测"**是 2014 年的分水岭。

**R-CNN 的教训**：它的慢（2000 次前向）与复杂（多阶段训练）说明——**"第一个可行的方案往往又慢又繁"**，但它证明了"方向对"——后续所有改进（Fast/Faster）都是"在正确方向上的工程优化"。**"先证明可行，再优化效率"**是研究-工程的自然节奏，R-CNN 是这句话的完美注脚。

## 7 从 R-CNN 看检测的完整演进图

R-CNN 是检测演进的起点，把它放进完整图景，整个检测史一目了然：

**检测演进的完整脉络**：

```
滑动窗口+HOG（手工特征）
  → R-CNN（CNN 特征 + 区域提议）
  → Fast R-CNN（共享卷积 + RoI）
  → Faster R-CNN（RPN 端到端）
  → YOLO/SSD（单阶段）
  → FPN（多尺度）
  → Anchor-Free（去锚框）
  → DETR（集合预测）
```

**每条演进线的本质**：

1. **"慢 → 快"**：共享计算、减少重复（R-CNN → Fast → Faster）。
2. **"手工 → 学习"**：手工特征 → 学习特征 → 学习提议 → 学习集合（去先验）。
3. **"两阶段 → 单阶段 → 端到端"**：精度 → 速度 → 简洁。

**检测的三个不变问题**：无论演进到哪，都在解决——**"在哪（定位）、是什么（分类）、几个（计数）"**——"**任务不变，工具在变**"。

**对学习者的启示**：从 R-CNN 看到 DETR，是一条"**去先验、加学习**"的主线——"**每一次演进都少一个手工设计（特征/提议/锚框/NMS），多一个学习环节**"。这个"去先验"的趋势是整个深度学习的缩影——"**理解演进的方向，比记住每个模型更重要**"。

## 8 小结

- **R-CNN** = 选择性搜索（2000 候选）→ CNN 提特征 → SVM 分类 + 框回归 → NMS。
- **选择性搜索**用"颜色/纹理/尺寸相似性"贪心合并区域，用约 2000 个框覆盖真实目标。
- 训练是**预训练 → 领域微调 → SVM/回归器**的三阶段配方。
- **框回归**预测归一化偏移与对数尺度，把候选框"精修"到真值框。
- 贡献：CNN 首次进检测、两阶段范式奠基；局限：2000 次独立前向、多阶段训练、慢。
