## 为什么从傅里叶变换开始

前面的平滑、锐化、金字塔，全都在**空间域**（spatial domain）里折腾：核在图像上滑，像素乘加。但你有没有想过一个问题——为什么高斯核「平滑」、边缘核「提取边缘」？空间域里这些操作像魔术，而在**频率域（frequency domain）**里，一切都变成了直白的几何：平滑就是「把高频削掉」，锐化就是「把高频抬起来」。

**傅里叶变换（Fourier transform）** 把图像从「每个像素的灰度」改写为「各个频率正弦波的分量」，于是滤波变成了「对频谱做乘除」。这一节要建立三件事：图像如何被分解成正弦波、**卷积定理**为什么让频域滤波等价于空间域卷积、以及频域滤波的工程陷阱（振铃、混叠、边界）。<span class="marginnote">傅里叶变换是「从极限到大模型」主线的老熟人：第一级微积分的三角级数、第二级复变函数里的积分变换，都是它的近亲；而卷积神经网络里「用卷积核对图像做运算」，频率视角下同样一目了然。</span>

## 1 用正弦波重写图像：基函数视角

空间域的图像是一张「像素值的表」；频率域把它看成**一组不同频率、不同方向、不同幅度的正弦波的叠加**。就像钢琴和弦由若干单音构成，一张纹理图也可以拆成「横条波 + 竖条波 + 斜向波 + 低频平场」的和。每个「单音」由三个参数刻画：**频率（frequency）**——条纹有多密；**幅度（magnitude）**——这个条纹多强；**相位（phase）**——条纹偏移了多少。

傅里叶变换就是**从图像算出每个单音分量**的算子。频谱图（把幅度画出来）的直观读法极其有用：

**中心是直流分量**：整幅图的平均亮度，频谱里最大的一团。
**离中心越远，频率越高**：对应空间域的细纹理、锐利边缘、噪声。
**频谱的方向**：图像里横条纹对应频谱中垂直方向的亮线——因为横条纹只在竖直方向变化。<span class="marginnote">相位常常被忽略，但它才决定「条纹长在哪儿」：幅度决定强度、相位决定位置。改变相位而保留幅度，图像会变形到认不出——所以 JPEG 压缩对相位要比对幅度更谨慎。</span>

这套视角的第一个应用就是：**噪声在频谱里通常出现在高频**，边缘也出现在高频——这正是「平滑 = 砍高频」在频率域的精确表述，也是上一节金字塔「带通层」的频谱注解。

## 2 公式解析：二维离散傅里叶变换与卷积定理

一维 DFT 把序列 $f(x)$ 分解为复指数（正弦 + 余弦的复组合）的加权和：

$$
F(u) = \sum_{x=0}^{M-1} f(x)\; e^{-i\,2\pi\, ux / M}
$$

推广到二维，对 $M \times N$ 的图像 $f(x, y)$：

$$
F(u, v) = \sum_{x=0}^{M-1} \sum_{y=0}^{N-1} f(x, y)\; e^{-i\,2\pi\left(\frac{ux}{M} + \frac{vy}{N}\right)}
$$

三步拆解：

- **第一步，看指数 $e^{-i2\pi(ux/M + vy/N)}$**：这是一张「频率为 $(u,v)$、方向由 $(u,v)$ 决定」的二维正弦波模板。对每一个频率 $(u,v)$，变换就是「图像与这张模板做点积（求和）」——点积大，说明图像里这个频率的成分强。
- **第二步，看双求和**：$x$ 从 0 到 $M-1$、$y$ 从 0 到 $N-1$ 遍历全图像素。$F(u,v)$ 是复数，幅度 $\lvert F(u,v)\rvert$ 是成分强度，辐角是相位。
- **第三步，看卷积定理（本节的灵魂）**：空间域的卷积，等于频率域的**逐点相乘**——

$$
f * h \quad\overset{\mathcal{F}}{\longleftrightarrow}\quad F \cdot H
$$

即「先傅里叶、乘频谱、再逆傅里叶」得到的结果，与空间域直接卷积完全一致。这就是为什么**频域滤波等价于空间域滤波**：任何卷积核都可以搬到频域操作，反之亦然。

离散傅里叶变换（DFT）可用**快速傅里叶变换（FFT）**在 $O(N \log N)$ 内完成，比直接卷积在大核时快得多。工程实现一句话：

```python
import numpy as np

F = np.fft.fft2(img)                  # 1. 空间域 → 频域
F = np.fft.fftshift(F)                # 2. 低频挪到中心
G = F * mask                          # 3. 频谱乘掩膜（频域滤波）
g = np.fft.ifft2(np.fft.ifftshift(G)) # 4. 频域 → 空间域
result = np.real(g)                   # 5. 取实部得到滤波结果
```

## 3 频域滤波：低通、高通与带通

频域滤波就是**「构造一个乘法掩膜」**。三个经典掩膜对应三种直觉：

- **低通（low-pass）**：保留中心低频圆，砍掉外围高频。效果 = 平滑去噪——上一节高斯滤波的频域版本。掩膜越「软」（过渡越平缓），空间域越不产生振铃。
- **高通（high-pass）**：保留外围高频，砍掉中心低频。效果 = 去掉平场、留下边缘——边缘检测的另一副面孔。高通常用「全通 − 低通」实现：$H_{hp} = 1 - H_{lp}$。
- **带通（band-pass）**：保留一个环带，把极低与极高都去掉。这正是拉普拉斯金字塔每一层的频谱——只留一个频段的信息，金字塔的「带通层」在此获得精确表述。

**核心要点：频域滤波 = 用乘法掩膜编辑频谱，掩膜的形状直接决定空间域效果。** 高斯掩膜 → 无振铃平滑；理想方框掩膜 → 平滑但带振铃。掩膜的「硬度」在空间域体现为振铃，这是本节最重要的工程直觉。<span class="marginnote">这也解释了上一节的结论：为什么高斯核比盒式核好——盒式核的频谱有负瓣、过渡生硬；高斯核的频谱仍是高斯、处处光滑。空间域的核与频率域的掩膜是同一枚硬币的两面。</span>

频域还有一个直观但常被忽略的几何性质：**平移不变性**——图像平移，频谱的幅度完全不变（只变相位）。这解释了为什么许多对齐算法「用幅度谱做旋转匹配、用相位做平移匹配」：旋转 90° 的图，幅度谱跟着转 90°，而幅度谱天生不受平移干扰。<span class="marginnote">相位携带着「位置」信息，幅度携带着「强度+频率」信息——这一分工在配准（相位相关做亚像素对齐）、图像哈希（只取幅度特征）里都被反复利用。</span>

## 4 频域滤波的工程真相：振铃、混叠与边界

频域滤波优雅，但直接「FFT → 乘掩膜 → IFFT」有四个必踩的坑：

**辨析｜易错点一：理想低通产生振铃（Gibbs 现象）。** 理想方框掩膜在频域是「硬切」，对应空间域的核是 $\operatorname{sinc}$ 函数——它在图像上会拖出正负交替的涟漪，边缘附近出现明暗条纹。**凡是「硬」的频域掩膜，必有振铃。** 解法：用高斯、巴特沃斯等**平滑过渡**的掩膜。

**辨析｜易错点二：FFT 假设图像是循环边界。** 离散傅里叶变换把图像当作**周期延拓**，左边缘与右边缘「相邻」。若图像左右亮度不同，频谱里会混入一条跨越整幅图的「伪高频」——这正是《线性滤波》里「频域配循环边界」那句话说法的由来。空间滤波用镜像、频域滤波用循环，两者才真正等价。

**辨析｜易错点三：频域滤波的零填充。** 直接对原图做 FFT 乘掩膜，等效于空间域「循环卷积」；而通常想要的「线性卷积」需要在 FFT 前把图像补零到 $2M \times 2N$，否则会有环绕混叠（wraparound）。`scipy.signal.fftconvolve` 内部正是这么做的。

**辨析｜易错点四：显示时看幅度谱要先取对数。** 频谱的直流分量比高频大几个数量级，直接显示一片白。$\log(1 + \lvert F \rvert)$ 压缩动态范围后才能看清结构；同时要用 `np.fft.fftshift` 把低频挪到中心，否则频谱的「四角」是低频，与「中心是低频」的直觉相反。<span class="marginnote">这四个坑本质上是一个主题的四个侧面：<strong>DFT 的周期性假设（循环）与现实图像的非周期假设（有限）之间的鸿沟</strong>——补零、取窗、平滑掩膜，都是在弥合这条鸿沟。</span>

看频谱的标准套路，固定两行：

```python
F = np.fft.fftshift(np.fft.fft2(img))   # FFT 后把低频挪到中心
mag = np.log(1 + np.abs(F))             # 取对数压缩动态范围
```

`fftshift` 把低频挪到中心，`log(1 + |F|)` 把动态范围压到可显示区间——两者缺一，频谱图要么四角是亮斑、要么一片雪白。

## 5 频域滤波之后：从经典到深度

把这一节放回全景图里看：频域滤波是经典图像处理的「终章」，但它没有退休——**JPEG 用 DCT（离散余弦变换，DFT 的实数近亲）压缩、JPEG 2000 用小波、Wiener 滤波用频域做最优去噪、模板匹配用相位相关做亚像素对齐**，全部是频率语言的直系后裔。而深度学习的「卷积层」在频域同样有解读：卷积核学到的权重，对应的正是一组可学习的频域滤波器。<span class="marginnote">多模态大模型对图像分块后加位置编码、Transformer 的注意力对特征做加权组合——这些当代结构里，频率视角（谁在低频、谁在高频）依然是分析它们行为的常用语言。</span>

其中频率域独有、空间域难以企及的一招是**反卷积（deconvolution）**。卷积在频域是相乘：$G = F \cdot H$，于是「已知模糊核 $H$、想还原清晰图 $F$」的最朴素解就是**逆滤波** $F = G / H$。可惜 $H$ 在高频处趋近 0，直接相除会把噪声无限放大；**维纳滤波（Wiener filter）** 在逆滤波与噪声抑制之间取最优折中，正是频域「除法视角」的成熟产物，也是经典图像去模糊的标准方法。

## 6 小结

- **傅里叶变换**把图像重写为不同频率/方向/相位的正弦波叠加；频谱中心是直流，越往外频率越高。
- **卷积定理**：空间域卷积 ⇔ 频率域逐点相乘——这是频域滤波的合法性来源。
- 三种掩膜对应三种操作：**低通**（平滑去噪）、**高通**（提取边缘）、**带通**（金字塔每一层）。
- 四个工程坑：**理想低通必振铃**（用平滑掩膜）、**FFT 默认循环边界**（与镜像空间滤波不直接等价）、**线性卷积需补零防环绕**、**显示频谱要取对数 + fftshift**。
- 频域思想延续至今：DCT（JPEG）、小波、Wiener 去噪、相位相关，以及可学习的卷积核。

在下一节，我们将回到空间域，把「如何找图像里显著的点」做成一个正式问题——**边缘检测**：从 Sobel、Prewitt 到 LoG 与 Canny，用一阶导、二阶导与多尺度高斯，把「哪里发生了亮度突变」变成可计算的答案。
