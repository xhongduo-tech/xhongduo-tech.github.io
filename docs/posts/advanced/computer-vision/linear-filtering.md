## 为什么从线性滤波开始

上一节点运算只跟单个像素打交道，但图像里真正有意义的信息——边缘、纹理、结构——都藏在**像素与邻居的关系**里。要看邻居，就要引入**滤波（filtering）**：用一个**核（kernel）**扫过整幅图像，让每个输出像素成为「它周围一小块区域的加权和」。而**线性滤波**是其中最基础、最优雅的一族：输出是邻域像素的**线性组合**，数学上是卷积。

这一节的目标很实在：搞懂卷积与互相关的差别、会用高斯核做平滑、并掌握**可分离滤波器**这个让计算量大幅下降的工程利器。它不仅是经典图像处理的地基，更是后续**边缘检测、金字塔、傅里叶频域滤波**的共同语言——再往后，卷积神经网络里的「卷积层」，数学上正是本节的东西。<span class="marginnote">深度学习的卷积层其实省略了「翻转」，也就是本节说的「互相关」——这是很多教材只在角落提一句、却让初学者困惑很久的细节，我们稍后会专门辨析。</span>

## 1 从点运算到邻域运算

点运算的公式是 $g(x,y) = T(f(x,y))$，输出只看输入同位置的像素。**邻域运算（neighborhood operation）** 把视野扩大到以 $(x, y)$ 为中心的窗口 $W$：

$$g(x, y) = T\big(\{f(x + i, y + j) \mid (i, j) \in W\}\big)$$

$T$ 可以是任何函数：取窗口平均是平滑，取窗口内的最大值是膨胀，取中位数是中值滤波（后面专门讲）。当 $T$ 是**线性**的——即对窗口内像素做**加权求和**——就得到线性滤波：

$$g(x, y) = \sum_{(i, j) \in W} w(i, j)\, f(x + i, y + j)$$

**线性**在这里有两层含义：对图像是「齐次+可加」（$af + bg$ 滤波后等于 $a$ 倍滤波后 $f$ 加 $b$ 倍滤波后 $g$），对权重是「共享同一组 $w$ 作用在全图每个位置」。这个「同一个核、扫遍全图」的性质叫**位移不变（shift-invariant）**；加上线性，统称**线性位移不变系统（LSI）**——它为什么如此强大，答案藏在傅里叶变换里（频域里 LSI 变成逐点相乘），那正是《傅里叶变换与频域滤波》一节的内容。

## 2 相关与卷积：差一个「翻转」

线性滤波有两种看似孪生的定义。**互相关（cross-correlation）** 不做任何翻转：

$$(f \star w)(x, y) = \sum_{i} \sum_{j} f(x + i, y + j)\, w(i, j)$$

**卷积（convolution）** 则把核**翻转**（上下左右都翻，即 $w$ 变成 $w(-i, -j)$）：

$$(f * w)(x, y) = \sum_{i} \sum_{j} f(x - i, y - j)\, w(i, j)$$

两者只差核的翻转。<span class="marginnote">卷积的「翻转」来自信号处理的历史约定：要描述「因果系统」的响应，就必须让输出 $g(t)$ 只依赖过去的输入，于是核相对时间轴翻转。图像处理沿用了这套记号，但图像没有「过去」，翻转与否只是约定。</span>

**辨析｜易错点：** 对**对称核**（高斯、盒式滤波），翻转等于没翻，相关与卷积完全一样——所以很多入门教程含糊带过。一旦核**不对称**（如 Sobel 边缘核、模板匹配），两者就产生差异：卷积翻转核，相关不翻。更麻烦的是，**深度学习框架（PyTorch、TensorFlow）里的「卷积层」（如 `nn.Conv2d`）实际做的是互相关**（不翻转）。因此同一组权重，数学上的「卷积」与库里的「卷积层」可以差一个 180° 旋转——理解这一点，你在读代码和读论文时就不会再被绕晕。

## 3 公式解析：二维离散卷积

把卷积写全，并拆开它的每一步：

$$
(I * g)(x, y) = \sum_{m=-M}^{M} \sum_{n=-N}^{N} I(x - m, y - n)\, g(m, n)
$$

其中核 $g$ 的大小是 $(2M+1) \times (2N+1)$（通常取奇数，方便中心对齐）。三步拆解：

- **第一步，对齐**：把核的中心（$m=0, n=0$）对准输出位置 $(x, y)$。核的每个格子 $(m, n)$ 对应输入像素 $I(x-m, y-n)$——注意符号：输入坐标是**减** $m$，这就是翻转的体现。
- **第二步，乘加**：把核的权重 $g(m, n)$ 与对应的输入像素相乘，再把窗口内 $(2M+1)(2N+1)$ 个乘积全部加起来，得到 $g(x,y)$。
- **第三步，滑窗**：核移动到下一个位置 $(x+1, y)$，重复同样的乘加。核扫过整幅图像，就得到输出。

对一个 $N \times N$ 的图像、$k \times k$ 的核（$k$ 为奇数），每个输出像素要做 $k^2$ 次乘加，全图共约 $N^2 k^2$ 次运算。$k$ 不大时没问题，但核一大（比如 $11 \times 11$ 的高斯），计算量就涨到 $121 N^2$——这时就需要下面的**可分离**技巧。

## 4 可分离滤波器：把二维拆成两次一维

**核心思想**：如果一个二维核能写成**两个一维核的外积**，即

$$g(m, n) = g_v(m) \cdot g_h(n)$$

那么二维卷积可以拆成**两步一维卷积**：先对每一行用 $g_h$ 卷积，再对每一列用 $g_v$ 卷积（先后顺序可交换）。**高斯核正是可分离的**——这是它被广泛使用的重要原因之一。

二维高斯核

$$
G(x, y) = \frac{1}{2\pi\sigma^2}\exp\left(-\frac{x^2 + y^2}{2\sigma^2}\right)
= \underbrace{\frac{1}{\sqrt{2\pi}\,\sigma}\exp\left(-\frac{x^2}{2\sigma^2}\right)}_{g(x)} \cdot \underbrace{\frac{1}{\sqrt{2\pi}\,\sigma}\exp\left(-\frac{y^2}{2\sigma^2}\right)}_{g(y)}
$$

指数部分 $e^{-(x^2+y^2)/(2\sigma^2)} = e^{-x^2/(2\sigma^2)} \cdot e^{-y^2/(2\sigma^2)}$，这正是「乘积拆成两段」的来源。下图把「外积」可视化：二维核的每个格子 $K[i,j]$ 恰是竖直一维核第 $i$ 个值乘水平一维核第 $j$ 个值：

![可分离滤波器：二维高斯核分解为两个一维核的外积](/images/computer-vision/linear-filtering-1.svg)

**省下的计算量是量级的。** 二维直接卷积每像素 $k^2$ 次乘加；拆成两步一维后，每像素先做一次 $k$ 点的水平卷积、再一次 $k$ 点的竖直卷积，共 $2k$ 次：

$$N^2 k^2 \ \longrightarrow\ N^2 k + N^2 k = 2 N^2 k$$

对 $k = 5$ 的高斯核，加速约 $2.5$ 倍；对 $k = 11$，加速约 $5.5$ 倍。<span class="marginnote">可分离性还能用来<strong>推导</strong>：两个可分离核的卷积仍是可分离的，这一性质在图像金字塔与多尺度特征里反复出现。</span>实现上只需两次一维卷积：

```python
import numpy as np
from scipy import ndimage

kernel = np.array([1, 4, 6, 4, 1]) / 16.0   # 一维 5 点高斯核（可分离）

# 先水平、再竖直：两步一维卷积
tmp = ndimage.convolve1d(img, kernel, axis=1, mode='reflect')
out = ndimage.convolve1d(tmp, kernel, axis=0, mode='reflect')
```

可分离实现的结果与直接做一次 $5\times5$ 二维卷积（同样边界条件下）数值上**几乎逐点相等**——这就是可分离滤波的正确打开方式。

## 5 边界处理：核伸到图像外怎么办

核在图像内部滑动没问题，但一到边缘，窗口会超出图像范围。工程上有几套标准处理，结果各不相同：

| 策略 | 做法 | 特点 |
| --- | --- | --- |
| 零填充 zero-pad | 边界外补 0 | 简单，但边缘出现暗晕 |
| 复制 clamp / replicate | 边界外重复最近像素值 | 平滑自然，常用 |
| 镜像 reflect | 边界外镜像回折 | 无间断，信号处理常用 |
| 循环 wrap | 图像按周期延拓 | 与傅里叶变换配套 |
| 收缩 crop | 只算核不越界的区域 | 输出比输入小 |

**辨析｜易错点：** 零填充会让边缘像素被「人为拉暗」，在多尺度金字塔或拼接时会产生可见的暗边；如果一幅图要连续做多次滤波，边界策略的差异会逐次累积。选边界策略不是随便的事——镜像或复制是默认安全选择。<span class="marginnote">傅里叶域滤波天然是循环边界，所以「空间滤波用镜像、频域滤波用循环」往往能保证两者结果一致——到频域那一节你会看到这条暗线的呼应。</span>

把边界处理好，线性滤波的工具就完整了：**核（权重）+ 卷积/相关（运算）+ 边界策略（工程细节）** 三者齐备，就可以去平滑、去噪、锐化、求导、做模板匹配——而所有这些，都是同一个「加权求和」的不同核。

## 6 小结

- **线性滤波** = 同一核在全图滑动的加权求和，属线性位移不变系统（LSI）。
- **互相关不翻核，卷积翻核**；对称核两者相同，非对称核差一个 180° 旋转。
- **深度学习里的「卷积层」实际是互相关**——读代码、读论文时别再被名字骗了。
- 二维卷积每像素 $k^2$ 次乘加；**可分离核**（尤其高斯）拆成两步一维，成本降为 $2k$。
- 高斯核可分离，源于 $\exp(-(x^2+y^2)/2\sigma^2)$ 可拆成两个一维指数的乘积。
- **边界策略**（零填充/复制/镜像/循环）影响边缘质量，多级滤波会累积差异，务必显式选择。

在下一节，我们将用线性滤波的工具去处理三种典型任务——**平滑滤波**（盒式、高斯）与它们如何平衡「去噪」与「保细节」，那将第一次把「信号」的视角引入图像。
