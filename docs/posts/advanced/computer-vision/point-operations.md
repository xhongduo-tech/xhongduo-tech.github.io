## 为什么从点运算开始

图像已经数字化了：每个像素是一个灰度值 $I(x, y)$。但「数字好」不等于「好看、好用」——照片太暗看不清、对比度太低灰蒙蒙、夜间监控画面一团黑。这些问题的共同修法，是**只改每个像素的值、不动像素之间的位置关系**。这就是图像处理里最朴素也最常用的一族操作：**点运算（point operation）**。

它还是后续一切图像处理的「第一课」：没有邻居参与、没有窗口、没有滤波——先学会对**单个像素**做文章，再去碰需要看邻居的线性滤波。<span class="marginnote">点运算与《颜色空间》关系紧密：同一套灰度变换也能分别施加在 RGB 各通道上，但更专业的做法是转到 Lab/HSV 的亮度通道再处理。</span>

## 1 点运算的定义：逐像素的悄悄话

**点运算（point operation）**：对图像 $f$，用同一个函数 $T$ 作用在**每个像素**上，得到输出 $g$：

$$g(x, y) = T\big(f(x, y)\big)$$

关键是：$T$ 的输入只有一个像素值，**完全不管邻居**。输出图像与输入图像**尺寸相同**，位置一一对应，改变的只是灰度值。这一「点对点」的性质让点运算实现起来极其简单，也极其快——查表（lookup table）就能完成：提前算好 $T(0), T(1), \dots, T(255)$ 这张 256 长度的表，运行时每个像素一次数组取址即可。

**辨析｜易错点：** 点运算的「点」是「像素点」，不是「像素点邻域」。一个像素的输出只取决于它自己的输入值——如果输出还要看邻域像素（比如「取 $3\times3$ 窗口的平均」），那就不是点运算，而是下一节《线性滤波》的对象。判断方法很简单：**打乱像素顺序，点运算结果逐点不变**；滤波结果则全乱。

## 2 常用灰度变换：四张基础映射

### 线性拉伸与对比度

一张 8 位图像的灰度本来落在 $[0, 255]$，但实际内容常常只占了其中一小段（比如暗图只用了 $[10, 80]$）。**线性拉伸（contrast stretching）** 把 $[a, b]$ 线性映射到 $[c, d]$：

$$T(r) = c + (d - c)\,\frac{r - a}{b - a}$$

当 $c = 0,\ d = 255$，就是把有内容的那一段拉满全范围——对比度立刻提上来。

### 伽马校正

显示器、传感器对亮度的响应不是线性的，于是需要**伽马校正（gamma correction）**：

$$T(r) = c\, r^{\gamma}$$

当 $\gamma < 1$ 时，暗部被提亮（曲线整体上凸）；$\gamma > 1$ 时，暗部被压暗、亮部拉开。手机「调节屏幕亮度曲线」、HDR 显示器的电光转换函数（OETF/EOTF），底层都是这条幂函数。<span class="marginnote">sRGB 标准的编码伽马约等于 $1/2.2$，即先做 $\gamma = 2.2$ 的幂运算再存储。这是数字图像「看不见却无处不在」的一个常数。</span>

### 反色与阈值

**反色（negative）**：$T(r) = L - 1 - r$，医学 X 光片常把底片反色显示。**阈值化（thresholding）**：$T(r) = 0 \ \text{或}\ 1$ 取决于 $r$ 是否大于某个阈值——它是后续分割、检测的雏形。

这三类映射有个共同点：它们都是**单调**的（值域顺序不变），所以不破坏图像的明暗次序；一旦用非单调映射，灰度关系就会发生「反转」，通常只在艺术效果里出现。

## 3 直方图：一张图的灰度家谱

要对「对比度不足」「太暗」做出**定量**判断，需要**直方图（histogram）**。把图像 $f$ 里灰度值为 $r_k$ 的像素个数记为 $n_k$，总像素数为 $N$，则

$$p(r_k) = \frac{n_k}{N}$$

$p(r_k)$ 是灰度 $r_k$ 出现的频率，整个 $p$ 就是灰度的**概率分布**。<span class="marginnote">直方图是一个概率分布——这个视角极其关键：图像处理中大量方法（均衡化、匹配、Otsu 阈值）本质上都是在摆弄「灰度的概率分布」。概率论里的累积分布函数（CDF）概念，在这里原封不动地上场。</span>

看图说话：一张「偏暗」的图像，直方图整体挤在左侧（低灰度）；「对比度低」的图像，直方图挤在中间一小段，两头（纯黑、纯白）几乎没人用；「对比度高」的图像，直方图向两侧舒展。**修图的第一直觉，就是把挤成一团的直方图「摊开」。** 怎么摊最科学？——直方图均衡化。

## 4 公式解析：直方图均衡化

**直方图均衡化（histogram equalization）**的目标：找一个灰度变换 $T$，使得输出图像的灰度**近似均匀分布**——让每个灰度级别都被充分利用。它不需要任何参数，只从图像自己的直方图出发。

### 连续情形的推导

设输入灰度 $r$ 的概率密度为 $p_r(r)$，做变换 $s = T(r)$。变换前后概率质量守恒：$p_s(s)\, ds = p_r(r)\, dr$，所以

$$p_s(s) = p_r(r)\,\left|\frac{dr}{ds}\right| = \frac{p_r(r)}{ds/dr}$$

现在选择 $s = T(r)$ 为 $r$ 的**累积分布**：

$$
s = T(r) = (L - 1) \int_0^{r} p_r(w)\, dw
$$

**第一步，对 $r$ 求导**：由微积分基本定理，$\dfrac{ds}{dr} = (L - 1)\, p_r(r)$。
**第二步，代入概率守恒式**：$p_s(s) = \dfrac{p_r(r)}{(L - 1)\, p_r(r)} = \dfrac{1}{L - 1}$。
**第三步，读出结论**：输出灰度 $s$ 是 $[0, L-1]$ 上的**均匀分布**——这就是「均衡化」的名字来源。把 CDF 当作映射，输出就自动展平。

### 离散实现

连续公式落到数字图像，积分变成求和，得到离散版本的映射：

$$
s_k = T(r_k) = (L - 1) \sum_{j=0}^{k} p(r_j) = \frac{L - 1}{N} \sum_{j=0}^{k} n_j
$$

也就是：**每个灰度值映射成「它及其以下所有灰度累计占比 × (L-1)」**，最后四舍五入取整。累计占比正是 CDF。短短几行就能实现：

```python
import numpy as np

def histeq(img, L=256):
    hist = np.bincount(img.ravel(), minlength=L)  # 灰度直方图 n_k
    cdf = hist.cumsum()                            # 累积分布 ∑ n_j
    cdf = (L - 1) * cdf / cdf[-1]                  # 归一化到 [0, L-1]
    return cdf[img].astype(np.uint8)               # 查表完成映射
```

**辨析｜易错点：** 直方图均衡化有两个常被忽略的副作用。其一，它是**全局**的——把整幅图当成一个分布来处理，暗部细节与亮部细节是「零和博弈」；其二，直方图**很稀疏**的灰度区间会被拉开，而噪声恰好常驻在那里，于是均衡化可能**放大噪声**。对平坦区域居多的图像（如夜空），要谨慎使用。

## 5 直方图匹配：要的不是均匀，是「指定形状」

均衡化把直方图推向均匀分布，但很多场景里我们并不想要均匀——比如希望输出图像的直方图长得像另一张参考图的直方图。这叫**直方图匹配（histogram matching / specification）**。

思想分三步：

1. **对源图做均衡化**：得到源图 CDF 变换 $s = T(r) = (L-1)\,C_r(r)$，把源灰度 $r$ 映射到 $s$。
2. **对目标直方图也做「均衡化」**：$s = G(z) = (L-1)\,C_z(z)$，把目标灰度 $z$ 映射到同一个 $s$ 轴上。因为 $s$ 是共同的「均匀标尺」，源与目标在 $s$ 轴上可比。
3. **反解**：令 $T(r) = G(z)$，即 $z = G^{-1}\big(T(r)\big)$——先查源图 CDF，再查目标 CDF 的逆。

最终映射 $r \mapsto z$ 把源图直方图「捏成」目标形状。<span class="marginnote">直方图匹配是「照猫画虎」：参考一张理想曝光的图的灰度分布，去改造另一张图。它在风格迁移出现之前，是「让两张图观感一致」的经典手段，也常见于多传感器图像的归一化。</span>

用一句话记住两者的关系：**均衡化是匹配的特例——目标直方图是均匀分布时的匹配**。所以先学均衡化，匹配就只是多走一步逆查表。

## 6 小结

- **点运算** $g(x,y) = T(f(x,y))$ 逐像素映射，不涉邻居，可查表实现，速度极快。
- 基础映射：**线性拉伸**提对比度、**伽马校正** $\gamma$ 调亮度曲线、**反色/阈值**做门限。
- **直方图**是灰度取值的概率分布，是图像「暗/亮/平」的定量画像。
- **直方图均衡化**用 CDF 作映射：连续情形下 $p_s(s) = 1/(L-1)$ 均匀，离散实现即「累计占比 × (L-1)」。
- **直方图匹配** = 源图 CDF 与目标 CDF 对齐后反查，均衡化是它的特例。
- 小心副作用：全局处理零和博弈、稀疏区间噪声被放大。

在下一节，像素终于要开始「看邻居」了：**线性滤波**——卷积与互相关、可分离滤波器。它将引入图像处理里最重要的一把武器，也是后来卷积神经网络（CNN）一切故事的起点。
