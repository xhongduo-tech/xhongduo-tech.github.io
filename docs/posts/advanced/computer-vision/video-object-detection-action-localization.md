## 为什么从视频目标检测与时序定位开始

动作识别回答"整个视频在干什么"，但真实需求往往更精确：

- **视频目标检测（video object detection）**：视频的每一帧里目标在哪——"这个物体从哪帧出现、在每帧的哪个框"。
- **时空动作定位（spatio-temporal action localization / temporal action localization）**：**动作在"何时（起止时间）"与"何地（空间框）"发生**——不只是"视频里有喝水"，而是"第 3~8 秒、画面右上角的人在喝水"。

这两个任务把"检测"（空间定位）与"时序"（时间定位）结合——是自动驾驶（追踪移动目标）、视频监控（定位事件）、视频检索（找关键片段）的核心。它们也是从"单帧检测"走向"视频理解"的桥梁。<span class="marginnote">动作定位的两种粒度：<strong>时序动作定位（temporal action localization）</strong>只在时间轴找"动作片段"（从哪帧到哪帧），是"1D 检测"；<strong>时空动作检测（spatio-temporal action detection）</strong>还要在每帧给框，是"2D+1D 检测"。两者共享"滑窗/候选 + 分类"的检测骨架，只是"框"的维度不同——<strong>检测的思想在时间轴上重演了一遍</strong>。</span>

## 1 视频目标检测：把单帧检测"串"起来

**视频目标检测**比单帧检测难在哪？

**运动模糊 / 遮挡 / 姿态突变**：某些帧目标模糊或藏起来，单帧检测会漏。
**时间不一致**：逐帧独立检测，同一目标在相邻帧的框会抖动、类别会跳变。

典型方法（**tubelet 思路**）：

1. **逐帧检测**：用单帧检测器（Faster R-CNN 等）在每帧出框。
2. **时序聚合**：用光流/跟踪把相邻帧的框"串"成**tubelet（时空管）**——把"目标轨迹"作为检测单元，用管内的时序信息补全"漏检帧"（这帧没检到，用前后帧的管来补）。
3. **管级分类**：对整个 tubelet 做分类（融合多帧证据），而不是只看单帧。

**核心思想：用"时间"补"空间"**——单帧不可靠时，让时间维的证据帮忙。<span class="marginnote">视频目标检测与多目标跟踪（SORT/Deep SORT）的关系：MOT 是"检测 + 关联"（跟踪身份），视频检测是"检测 + 时序聚合"（利用时间补漏）。两者都离不开单帧检测器，但<strong>MOT 关心"身份连续"，视频检测关心"检测结果稳定"</strong>——现代系统常把两者合一（检测即跟踪），这也是后文"视频分割与跟踪统一"的趋势。</span>

## 2 时序动作定位：在时间轴上找动作

**时序动作定位（temporal action localization）**：给定未剪辑的长视频，找到所有动作片段的**起止时间**与**动作类别**。它与目标检测在数学上同构——**"时间轴上的框"就是"起止时刻"**。

两类方法：

- **两阶段（proposal + classification）**：先用**时序候选（temporal proposals）**生成器（如边界预测、滑窗）找"可能含动作的时间段"，再对每个候选分类——**与 R-CNN 的"提议 + 分类"完全同构**。
- **单阶段**：直接回归每个时刻的"动作边界与类别"——**与 YOLO/FCOS 的"直接回归"同构**。

**把检测的"空间框回归"搬到"时间框回归"**，是时序定位的核心迁移。

## 3 公式解析：时序候选生成的"边界匹配"

**时序定位的候选怎么生成？** 以 **BMN（Boundary-Matching Network）**为例：

- **第一步，边界概率**：网络预测每个时刻的**开始概率** $P_s(t)$ 与**结束概率** $P_e(t)$——"动作从 $t$ 开始的概率"。
- **第二步，候选采样**：按开始/结束概率的峰值采样候选片段 $[t_s, t_e]$，并对每个候选均匀采样 $N$ 个时刻构成"匹配特征"。

$$
\phi(t_s, t_e) = \left[ F(t_s + \frac{i}{N}(t_e - t_s)) \right]_{i=0}^{N}
$$

$F$ 是每时刻的特征序列——**把候选片段"采样"成固定长度的向量**。
- **第三步，评估与回归**：对每个候选，预测"它含动作的概率"与"边界偏移"（修正起止时间），再像检测一样用 NMS 去重、按置信度排序。
- **第四步，与检测对比**：这个流程与"锚框 → 分类 + 回归 → NMS"几乎逐对应——**只是从 2D 框换成 1D 时间段**。

**一句话：时序动作定位 = 把检测算法"降维"到时间轴——候选时间段替代候选框，起止回归替代框回归，NMS 去重照旧。**

## 4 时空动作检测：空间与时间联合

**时空动作检测（spatio-temporal action detection）**最完整：输出每个动作的"时间片段 + 每帧空间框"——一个 **3D 的 tubelet**。

方法：

- **自顶向下**：先用**时空候选（tubelet proposals）**（如把单帧检测框沿光流/跟踪扩展成管），再对管分类。
- **自底向上**：先找"动作区域"（每帧热图），再串联成时空管。
- **端到端（现代）**：用 3D CNN / 视频 Transformer 直接输出"动作管"（如 MOC 检测器把动作定位建模成"从起点找终点"的路径预测）。

**评测**：时空检测用 **video-mAP**——在时间与空间 IoU 都达标时才算检测成功。**"时空都对齐"是高要求的度量**，也反映了任务难度。

## 5 现代视频检测与定位

现代演进趋势：

- **统一检测**：视频动作定位与检测、跟踪、分割走向统一（如"视频全景分割"——每个物体在每帧有掩码 + 轨迹）。
- **端到端时序建模**：视频 Transformer 直接做定位（用"片段查询"替代候选生成）。
- **大模型辅助**：用视频-语言模型做"开放词汇的动作定位"——"找出视频里'做饭'的片段"（文本驱动的时序定位）。

**从"单帧检测"到"时空定位"到"视频理解大模型"**，是视频视觉沿着"更精确的时空建模"演进的完整脉络。<span class="marginnote">把本章与全书主线连接：视频检测/定位复用了一切——检测（IoU、mAP、NMS）、跟踪（tubelet 串联）、光流（时序证据）、时序建模（3D CNN/注意力）。<strong>视频任务不是新任务，而是"空间任务 + 时间轴"的组合</strong>——理解了空间任务的每个组件，就能理解它们在时间维上的迁移。这就是为什么全书先讲空间、后讲时间。</span>

## 6 视频检测与时序定位的工程实践

视频检测/定位的工程问题，比"模型"更贴近落地：

**工程实践**：

- **关键帧 vs 逐帧**：逐帧检测贵（视频帧数多）——**"关键帧检测 + 帧间传播（光流/跟踪）"** 是省算力的标准做法——"**检测稀疏化、跟踪补中间**"。
- **时序上下文**：单帧判断动作不可靠（"举手"要看前后帧）——**"用前后帧的特征增强当前帧"**（时序聚合、Temporal RoI）。
- **长视频的处理**：长视频不能整段进网络——**"滑窗 + 分段检测 + 合并"**（与目标检测的滑窗同构）。
- **评测的严谨性**：时序定位的 mAP 对"边界误差"敏感（起止差一点就算错）——"**边界质量是时序定位的核心挑战**"。

**时序定位的难点**：

- **边界模糊**：动作的起止没有清晰定义（"喝水"从哪一帧开始？）——"**边界标注的主观性**"。
- **长尾动作**：稀有动作样本少——"数据不平衡"。
- **上下文依赖**：有些动作要"看前面才能判断"（"倒水"要在"拿起杯子"之后）——"**长程时序依赖**"。

**与现代趋势的衔接**：视频 Transformer 直接做"片段查询"（免候选）；视频-语言模型做"文本驱动的时序定位"（"找出'做饭'的片段"）——**"从手工候选到学习查询、从固定类别到开放词汇"**。理解"检测思想在时间轴的迁移"，就理解了时序定位的全部套路——**"时空检测 = 空间检测 + 时间维"**。

## 7 时空建模的统一视角

视频检测/定位的众多方法，共享几个"时空建模"的统一视角：

**视角一：视频 = 图像序列 + 时间结构**：所有视频任务都建立在"单帧理解"之上，再加时间结构——"**空间是基础，时间是增量**"。这就是为什么图像检测（Faster R-CNN/YOLO）是视频检测的起点。

**视角二：时间的三层作用**：

1. **时间作为证据**：多帧投票（一帧看不清，多帧看清）——"**时间给更强的感知**"。
2. **时间作为约束**：时序一致性（物体运动连续、动作有起止）——"**时间给几何/语义先验**"。
3. **时间作为语义**：动作本身是时序模式（"跑步" = 双腿交替）——"**时间本身就是识别对象**"。

**视角三：检测/定位 = 空间与时间的"联合搜索"**：目标检测在 2D 空间搜框、时序定位在 1D 时间搜片段、时空检测在 3D 搜"时空框"——"**同一个'搜索'问题，维度不同**"。

**对学习者的启示**：视频检测/定位教会我们"**时间维的三层用法**"——"**遇到视频问题，先问'时间在这里是证据、约束、还是语义'**"。这个提问方式，能帮你准确理解任何视频方法的设计动机——"**看懂'时间被用来干什么'，就看懂了视频方法的一半**"。

## 8 小结

- **视频目标检测**：逐帧检测 + 光流/跟踪串成 **tubelet**，用时间补单帧漏检。
- **时序动作定位**：在时间轴找动作片段（起止 + 类别）——检测思想在 1D 重演。
- 候选生成（BMN）：边界概率 + 候选采样 + 分类回归 + NMS。
- **时空动作检测**：输出"时间片段 + 每帧空间框"——video-mAP 评估。
- 现代：统一检测/分割/跟踪、视频 Transformer 端到端、视频-语言开放词汇定位。
