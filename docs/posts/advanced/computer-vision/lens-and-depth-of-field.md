## 为什么从镜头开始

上一节的针孔相机有两个致命缺陷：**孔太小，进光量不够，像太暗**；孔太大，又不再满足「唯一光线」的假设，像变糊。真实相机用**镜头**解决进光问题——一块凸透镜把大范围的光汇聚到传感器上，成像又亮又清晰。但镜头带来了新问题：它只在特定的距离上「合焦」，前后一定范围内的物体清晰、之外的物体发虚。这段「看起来还算清晰」的距离范围，就是**景深（depth of field）**。<span class="marginnote">景深不只是摄影爱好者的审美概念，它直接决定相机能捕获多少信息：手机镜头景深大、背景全清楚；专业人像镜头景深极浅。计算机视觉里的「拍得清楚吗」，很大程度是景深问题。</span>

这一节，我们建立镜头的几何模型：从薄透镜方程出发，推导出模糊的定量描述——**弥散圆（circle of confusion）**，再回答「光圈、焦距如何塑造景深」。

## 1 从针孔到薄透镜

把针孔换成一块**理想薄透镜（thin lens）**：它足够薄，可以当作一个平面；平行于光轴入射的光线，经过透镜后会聚于一点，称为**焦点**，焦点到透镜的距离就是**焦距（focal length）** $f$。<span class="marginnote">「理想」二字意味着忽略厚度与像差。真实镜头由多片透镜组成，为的就是把像差压到可忽略；几何推导时，薄透镜近似已经足够精确。</span>

薄透镜的成像规律只有一条，叫**高斯透镜方程**：

$$\frac{1}{f} = \frac{1}{u} + \frac{1}{v}$$

其中 $u$ 是物距（物体到透镜的距离），$v$ 是像距（透镜到清晰像面的距离）。**透镜本身没有「焦点平面」那么复杂的机关，它只是一条关于 $u, v, f$ 的代数关系**——给定任意两个，第三个就被唯一确定。

镜头替代针孔的直接收益在**进光量**：进入镜头的总光通量正比于入瞳面积，即 $\propto A^2$，其中 $A$ 是**光圈（aperture）**的有效直径。光圈直径翻倍，进光量变四倍——这就是为什么光圈能当「曝光旋钮」用。工程上习惯用**光圈数（f-number）** $N = f / A$ 描述：$N$ 每变小 $\sqrt{2}$ 倍（如 f/4 → f/2.8），进光量恰好翻一档。<span class="marginnote">$N$ 是纯几何量：f/2 表示「光圈直径 = 焦距 ÷ 2」。斜杠是「除以」的意思，所以 f/2 的开口比 f/4 大——读作「f 二」，不是「f 分之二」。</span>

几何上，薄透镜把「物点 → 像点」的全部关系压缩进一条方程；工程上，设计一组镜头就是反复解这条方程的逆问题——先定想要的像距与像质，再反推各镜片的曲率与间距。这条「正解、逆解」的循环，正是光学设计的日常。

## 2 公式解析：薄透镜方程 1/f = 1/u + 1/v

把这条方程拆成三步：

**第一步，认识两个极限**：当物体在无穷远（$u \to \infty$），$1/u \to 0$，方程退化为 $v = f$——无穷远的物体成像在焦平面上。这正是「把镜头对准远方，焦点在传感器上」的数学版本；也解释了为什么天文望远镜只需把探测器放在焦点处。当物体逼近 $u = f$ 时，$v \to \infty$——物体放在焦点上，出射光平行，不成像。

**第二步，解出像距**：把方程变形为

$$v = \frac{f u}{u - f}$$

只要 $u > f$，就有 $v > 0$，成**实像**，像在透镜另一侧。$u$ 越大，$v$ 越小、越逼近 $f$；$u$ 越接近 $f$，$v$ 越大。一句话：**物体越近，像越靠后**。

**第三步，理解「对焦」**：所谓对焦，就是移动镜头（改变 $v$）让传感器恰好落在像距处。对焦完成后，只有物距恰好等于 $u$ 的那一层物体是清晰的。<span class="marginnote">手机镜头一般是对焦在一个固定距离（或靠多摄、算法做全焦），专业相机则用马达移动镜组改变 $v$。实时对焦（auto-focus）在计算机视觉里对应「估计当前场景深度 → 反推所需 $v$」。</span>

这套符号约定只对「物在透镜前方、成实像」成立。若物距 $u < f$，则 $v < 0$——像在透镜同侧、成**虚像**（放大镜正是如此）。薄透镜方程并不挑剔正负，只是不同情形下 $u, v$ 的符号不同；后面的镜头设计、显微镜光学，都是这条方程加符号规则的组合拳。

## 3 景深与弥散圆：模糊的定量描述

现在关键问题来了：对焦点前后的物体，为什么会模糊？看配图。

![薄透镜对焦与弥散圆](/images/computer-vision/lens-and-depth-of-field-1.svg)

- 物点 $A$（物距 $u_f$）的光线在传感器上会聚成一个点，清晰。
- 物点 $B$（更近，$u < u_f$）的像距 $v_B > v_f$，会聚点落在传感器**之后**；光线穿过传感器平面时，截到的是一个圆斑，而不是点。

这个圆斑叫**弥散圆（circle of confusion, CoC）**。由圆锥几何，直径 $c$ 与光圈直径 $A$ 成正比：

$$c = A\,\frac{|v - s|}{v}$$

其中 $s$ 是传感器到透镜的距离（即对焦时的像距），$v$ 是被观察物点应有的像距，$A$ 是光圈直径。**只要 $v \ne s$，就一定有模糊；光圈越大（$A$ 越大），同样的离焦下弥散圆越大。**

**景深**的定义与弥散圆绑定：把「可以接受的最大弥散圆直径」记为 $c_0$（35mm 全画幅常用 $0.03\,\mathrm{mm}$ 左右），凡是弥散圆不超过 $c_0$ 的物点范围，就是景深。$c_0$ 的取值直接决定景深大小——它来自「把照片放大多大、在正常观看距离下看不出模糊」的经验，而非某个物理定律；传感器越小，同样的放大倍数对 $c_0$ 要求越苛刻（这也是手机小底景深大的原因之一）。

还要纠正一个常见直觉：**景深不是一条硬边界**。弥散圆随离焦量连续增大，所谓「景深」只是「弥散圆不超过 $c_0$」的区间；走出这个区间后模糊是渐进的，而不是一步到位。离焦的高光点会形成弥散圆的形状——**散景（bokeh）**——它的几何形状由光圈叶片决定：叶片越多越接近圆形，六边形光圈就拍出六边形高光。这个看似纯审美的细节，其实仍是「$c = A|v-s|/v$」这条式子的直接推论。

## 4 光圈、焦距如何塑造景深

把上面几条公式整理一下，可以得到摄影里的标准结论。定义**超焦距（hyperfocal distance）**：

$$H \approx \frac{f^2}{N\, c_0}$$

其中 $N = f / A$ 是**光圈数（f-number）**——注意它是「焦距 ÷ 光圈直径」，所以 $N$ 越大、光圈反而越小（f/16 比 f/2.8 开口小）。景深近界与远界为：

$$D_N = \frac{H s}{H + (s - f)}, \qquad D_F = \frac{H s}{H - (s - f)}$$

从这三条式子读出三个反直觉的结论：

- **光圈越大（$N$ 越小），景深越浅**：$H \propto 1/N$，$H$ 越小，$D_F$ 的分母越小，远界迅速拉近。这是「大光圈虚化背景」的数学来源。<span class="marginnote">摄影师说「大光圈」时指的是 f/1.4 这种小数值，而「小光圈」指 f/16——这个称呼和历史有关：光圈刻度上数字小、开口大。刚入门的人最容易在这里反着记。</span>
**焦距越长，景深越浅**：$H \propto f^2$，长焦镜头的 $H$ 大，景深范围窄。广角镜头拍风景时「前后都清楚」，人像镜头「背景糊成一片」，主要就是 $f$ 的差异。
**对焦在超焦距 $H$ 上，景深远界到达无穷远**：当 $s = H$ 时 $D_F = \infty$。风景摄影常用的「泛焦」手法，就是利用这一点。

把这套公式写成一个函数，可以直观感受数值：

```python
def depth_of_field(f, N, s, c0=0.03):
    H = f**2 / (N * c0)           # 超焦距
    D_N = H * s / (H + (s - f))   # 景深近界
    D_F = H * s / (H - (s - f))   # 景深远界
    return D_N, D_F
```

同样对焦在 3 米，f/8 的景深是 f/1.4 的十几倍——数字把「大光圈虚化」说得很清楚。带一组具体的数走一遍：全画幅、$f = 50\,\mathrm{mm}$、$c_0 = 0.03\,\mathrm{mm}$、对焦在 $s = 3\,\mathrm{m}$。$N = 8$ 时超焦距 $H = 50^2/(8 \times 0.03) \approx 10.4\,\mathrm{m}$，景深近界约 $2.33\,\mathrm{m}$、远界约 $4.27\,\mathrm{m}$；换到 $N = 2.8$，$H \approx 29.8\,\mathrm{m}$，景深收窄到约 $2.72$–$3.33\,\mathrm{m}$。若改把焦点放到超焦距 $10.4\,\mathrm{m}$ 处，景深就从 $5.2\,\mathrm{m}$ 一直延伸到无穷远——**「泛焦」不是玄学，正是 $D_F \to \infty$ 这条式子本身**。

焦距还决定**视场角（field of view）**：$\tan(\theta/2) = (W/2)/f$，$W$ 是传感器宽度。全画幅上 $f = 24\,\mathrm{mm}$ 对应视场约 $73°$，$f = 85\,\mathrm{mm}$ 只剩约 $24°$。<span class="marginnote">广角与长焦的差异，本质是「同一块传感器，从多窄的角度收集光线」。视场角在多视图几何、全景拼接里是反复出现的量，到时候用这条式子就能把「等效焦距」换算清楚。</span>

**辨析｜易错点：** 光圈越小一定越清楚吗？不是。当光圈小到一定程度，衍射成为主角——点光源的像不再是点，而是**艾里斑（Airy disk）**，直径约 $2.44\lambda N$。$\lambda \approx 550\,\mathrm{nm}$，于是 $N = 11$ 时艾里斑已经约 $15\,\mu\mathrm{m}$，接近像素尺寸。**景深与衍射是一对矛盾，存在最优光圈**，而非「越小越好」。这也是为什么专业镜头常常「收两档使用」：全开光圈时球差与像差最重，收两档后，球差被压下去而衍射还不明显，成像恰好达到最佳。

## 5 从理想到现实：像差与畸变

薄透镜是理想模型，真实镜头还有**像差（aberration）**：球差（边缘光线与中心光线焦点不同）、色差（不同波长折射率不同）、彗差、场曲等。对计算机视觉影响最大的是**镜头畸变（lens distortion）**——直线的像不再直：桶形畸变（广角端常见）、枕形畸变（长焦端常见）。<span class="marginnote">畸变在像素上通常很小（几十个像素以内），但对需要精确几何的任务（相机标定、拼接、三维重建）是致命的。Szeliski 在 §2.1.6 用径向畸变模型描述它，后面《相机内参：畸变》一节会专门处理。</span>

正是为了控制像差与畸变，真实镜头是「多片透镜的组合」，而不是一块薄片；「薄透镜」是我们用来建立直觉的第一级近似，工程实现则是围绕它做修正。对计算机视觉而言，畸变模型（如径向畸变的偶次多项式）是标定的标准部件；而对摄影而言，像差正是镜头「味道」的来源——不同镜头风格差异，很大程度是各自的像差曲线不同。

对计算机视觉来说，这套镜头模型还启发了**计算摄影**：手机用多摄与算法模拟「大光圈浅景深」，本质是「估计深度 → 按深度做局部模糊」，仿的正是景深公式；「全焦（focus stacking）」则反着来——多张不同对焦的照片按清晰度合成一张全清晰的图。**理解景深的几何来源，才能读懂这些算法在做什么**：它们不是魔法，而是把「$c$ 与离焦量成正比」这条规律在数字域里复现。

## 6 小结

- **薄透镜方程** $1/f = 1/u + 1/v$：物距、像距、焦距三者由一条代数关系约束；**对焦 = 调节 $v$**。
- **弥散圆** $c = A|v-s|/v$：离焦物体在传感器上形成圆斑，是模糊的定量描述。
- **景深**由可接受弥散圆 $c_0$ 界定；**光圈越大景深越浅、焦距越长景深越浅**，超焦距对焦使远界达无穷。
- **衍射与景深是矛盾**：光圈太小衍射糊、太大景深浅，存在最优光圈。
- **景深是渐变而非硬边界**；离焦高光的形状（散景）由光圈叶片决定。
- **视场角** $\tan(\theta/2) = (W/2)/f$：广角与长焦的本质，是同一块传感器从多窄的角度收集光线。
- 真实镜头还有**像差与畸变**，几何上精确的任务必须显式建模（径向畸变）。

在下一节，光线终于穿过镜头、落在传感器上——但它还是**连续的**。把连续的光场变成离散的像素，需要**采样与量化**，以及那条著名的奈奎斯特定理。
