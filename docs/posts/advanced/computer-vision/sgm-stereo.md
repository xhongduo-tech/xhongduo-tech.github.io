# 半全局匹配（SGM/SGBM）算法

## 为什么从 SGM 开始

上一节的全局方法（图割、置信度传播）精度好，但计算量太大，难以实时。局部的块匹配快，但没有平滑约束。**半全局匹配（Semi-Global Matching，SGM）**在 2008 年由 Hirschmüller 提出，目标是在两者之间找到甜点：**既保留"相邻像素平滑"的全局思想，又把计算压到近实时**。

它的核心 trick 是"**把二维的全局平滑，拆成一维的方向扫描**"：沿 8 个方向（上下左右 + 4 个对角）各做一次动态规划式的代价累积，再把各方向结果求和。每条一维路径上的优化是精确的（动态规划），多条路径求和近似全局——所以叫"半全局"。SGM 是 OpenCV SGBM 的实现基础，也是车载立体、无人机避障的事实标准。<span class="marginnote">SGM 的取名很诚实："全局"是它的目标，"半"是它的手段——用一维路径拼出二维的全局近似。它把 2D MRF 能量最小化（NP-hard 的近似）变成 8 个一维 DP 问题（每个都是精确解），时间上从"分钟级"降到"毫秒级"。这是"用结构近似换计算量"的经典教科书案例。</span>

## 1 SGM 的能量函数

SGM 优化的能量函数与全局方法同构，但平滑项采用**逐像素对（pairwise）**形式：

$$
E(D) = \sum_p C(p, d_p) + \sum_{(p,q)\in\mathcal{N}} P_1 \cdot [|d_p - d_q| = 1] + P_2 \cdot [|d_p - d_q| > 1]
$$

两个关键设定：

- $P_1$：相邻视差差 1 的小惩罚——允许**倾斜表面/渐变**的平滑过渡。
- $P_2$：视差跳变的大惩罚——容忍**物体边界**的深度断裂，且 $P_2$ 常随像素梯度自适应：$P_2' = P_2 / (|I_p - I_q| + 1)$。**梯度大的地方（真实边界）$P_2$ 变小，允许断裂**；梯度小的平坦区 $P_2$ 大，强制连续。

**这个"梯度自适应平滑"是 SGM 保边性能的关键**：它在能量层面编码了"有纹理差异才允许深度跳变"的先验。

## 2 公式解析：路径代价聚合

SGM 的核心公式是沿某方向 $\mathbf{r}$ 的**路径代价（path cost）**递归：

$$
L_{\mathbf{r}}(p, d) = C(p, d) + \min\Big\{
L_{\mathbf{r}}(p - \mathbf{r}, d), \\
L_{\mathbf{r}}(p - \mathbf{r}, d-1) + P_1, \\
L_{\mathbf{r}}(p - \mathbf{r}, d+1) + P_1, \\
\min_{d'} L_{\mathbf{r}}(p - \mathbf{r}, d') + P_2
\Big\} - \min_{d'} L_{\mathbf{r}}(p - \mathbf{r}, d')
$$

逐步拆解：

- **第一步，结构**：当前像素在视差 $d$ 下的路径代价 = **数据项** $C(p,d)$ + **上一像素（沿路径方向）的代价** + 平滑惩罚。
- **第二步，四种候选**：上一像素取同视差 $d$（不罚）、取 $d\pm1$（罚 $P_1$）、取任意其他 $d'$（罚 $P_2$）——四种情况的最小值。
- **第三步，减去当前最小值**：$-\min_{d'} L_{\mathbf{r}}(p-\mathbf{r}, d')$ 防止代价沿路径无限累积（数值稳定），它不影响最优视差的选择。
- **第四步，多方向求和**：对 8 个方向各算一遍，聚合：

$$
S(p, d) = \sum_{\mathbf{r}} L_{\mathbf{r}}(p, d)
$$

最终取 $d^*(p) = \arg\min_d S(p,d)$。

**一句话：SGM 沿 8 条一维路径各做一次"带平滑惩罚的动态规划"，求和后取代价最小的视差。** 每条路径是精确的 1D 优化，8 条求和是 2D 平滑的近似——这就是"半全局"。

## 3 SGBM：OpenCV 的实用实现

OpenCV 的 **SGBM（Semi-Global Block Matching）** 是 SGM 的实用变体，几个实现细节值得注意：

- **Census 代价**：默认用 Census 变换计算初始代价——对光照变化稳健（比较像素间序关系而非绝对亮度）。
- **多方向 DP**：OpenCV 默认 5 或 8 个方向，可配置（`numDisparities` 决定搜索范围、`blockSize` 决定代价窗口）。
- **块匹配前缀**：SGBM 在代价计算阶段仍用局部窗口（block），然后走 SGM 的路径聚合——所以叫 "Block Matching + Semi-Global"。
- **WTA + 后处理**：路径聚合后 WTA 取视差，再接后处理（见下一节）。

**SGBM 的典型参数**：`numDisparities`（视差范围，需为 16 的倍数）、`blockSize`（奇数，如 5~11）、`P1`、`P2`（平滑惩罚）。调参的核心经验：**$P_1$、$P_2$ 决定平滑强度，blockSize 决定纹理匹配的稳定性**。<span class="marginnote">为什么 OpenCV 默认用 Census？Census 把窗口内每个像素与中心比较，生成二进制串，再用汉明距离当代价——它是"序关系"的编码，天然免疫整体亮度偏移。在户外光照剧烈变化的车载场景，Census + SGM 的组合是久经考验的黄金搭档。</span>

## 4 为什么 SGM 能实时：复杂度分析

**SGM 的计算复杂度是 $O(W \times H \times D)$**，其中 $W, H$ 是图像尺寸、$D$ 是视差范围——这是**每像素 × 每视差一次操作**的量级，与像素个数线性相关，没有迭代。对比：

图割/BP：多次迭代，每轮都要在图上传播信息，常数项大得多。
SGM：单遍扫描 + 多方向，纯数据并行友好，**在 GPU/FPGA/嵌入式上极易向量化**。

这就是为什么车载摄像头、无人机、机器人立体相机都选 SGM——**在"精度足够"的前提下，把每一帧的时间预算压到几毫秒**。<span class="marginnote">SGM 论文里作者实测：1280×960 图像、128 级视差，在当年的 CPU 上约 0.2~1 秒，在 GPU 上达到 10+ fps。放到今天的硬件，实时 30fps 毫无压力。这也是"算法设计决定硬件可行性"的典型例子——全局方法可能永远上不了嵌入式，SGM 一出生就是为实时设计的。</span>

## 5 SGM 的局限与改进

SGM 不是万能的：

**条纹伪影（streaking）**：由于只在有限方向做路径聚合，长而无纹理的区域（墙面、天空）会出现沿扫描方向的条纹。后处理（中值滤波、一致性检查）能缓解。
**大视差范围**：$D$ 大时 $O(WHD)$ 仍会撑爆内存与算力，需要分层/由粗到细策略。
**Census 的纹理敏感**：Census 在低纹理区仍缺乏证据，平滑项撑场面的能力有限。

改进方向：**分层 SGM（多尺度）**、**与边缘感知聚合结合**、**深度学习后处理**（用 CNN 精化 SGM 输出的视差图——这是许多半学习方法的组合拳）。<span class="marginnote">一个有意思的演化：深度学习立体匹配（如 PSMNet）的"代价体（cost volume） + 3D 卷积聚合"结构，与 SGM 的"代价体 + 多方向聚合"惊人同构——SGM 的方向扫描被 3D CNN 的卷积取代，平滑项被正则项取代。经典算法的结构蓝图，在深度时代以可学习的形式重生。</span>

## 6 SGM 的工程实践与参数调优

SGM/SGBM 落地时，参数与后处理决定质量：

**OpenCV SGBM 的核心参数**：

- **numDisparities**：视差搜索范围（需 16 的倍数）——**"范围要覆盖场景的实际视差"**（基线/距离决定范围）。范围太小截断远处、太大浪费计算。
- **blockSize**：代价计算的窗口大小（奇数）——**"大窗口抗噪声但糊边界，小窗口保边界但噪"**。
- **P1 / P2**：平滑惩罚——**"P2 通常设为 P1 的 4~8 倍"**（小跳变便宜、大跳变贵），且随图像梯度自适应（有纹理处允许跳变）。
- **uniquenessRatio**：唯一性约束（代价最低与次低的比例）——"防重复纹理误匹配"。
- **disp12MaxDiff**：左右一致性检查的阈值——"不一致的标记为无效"。

**SGM 的典型后处理链**（衔接前文）：

1. **左右一致性检查（LRC）**：比较左→右与右→左视差，不一致的点判为遮挡/误匹配（`disp12MaxDiff` 控制阈值）。
2. **唯一性检查**：代价最低与次低相差不足 `uniquenessRatio` 则判无效，抑制重复纹理误匹配。
3. **亚像素插值**：对最优视差邻域做抛物线拟合，把视差精度从整像素提到亚像素。
4. **中值 / 双边滤波**：去除路径聚合留下的条纹伪影，同时保住边界。
5. **无效点填补**：用邻近有效视差填补 LRC 标记的洞（必要时按深度分层插值）。

**调参经验**：

- **先调 numDisparities 与 blockSize**（影响最大），再调 P1/P2（平滑），最后 uniquenessRatio（唯一性）——"从大到小调"。
- **光照变化大用 Census**（SGBM 默认）——"户外鲁棒靠 Census"。
- **纹理弱场景**（白墙）SGM 靠平滑撑——"低纹理区视差会'糊'，用语义/深度先验补"。

**SGM 与现代方法的配合**：深度学习立体（PSMNet）输出 + SGM 的几何验证（一致性检查）——**"深度估计 + 几何后处理"**组合；或"SGM 做粗糙初值 + 深度网络精化"。**"经典方法的可靠性（几何可验证）+ 深度方法的表示力"**再次组合。

## 7 小结

- **SGM** = 半全局：用 8 条一维动态规划路径近似二维全局平滑，代价 $O(WHD)$。
- 能量 = 数据项 + 逐对平滑（$P_1$ 小渐变、$P_2$ 大跳变，且 $P_2$ 随图像梯度自适应）。
- 路径代价递归：**数据 + 上一像素四种候选 + 平滑惩罚 − 当前最小值**，多方向求和取 WTA。
- OpenCV **SGBM** 用 Census 代价 + SGM 路径聚合，参数（numDisparities、blockSize、P1、P2）决定质量。
- 局限：长纹理区条纹伪影、视差范围大时算力紧张；深度后处理可精化。
