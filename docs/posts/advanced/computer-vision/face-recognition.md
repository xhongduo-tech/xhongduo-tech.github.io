## 为什么从人脸识别开始

人脸检测找到脸、人脸对齐标准化脸，接下来是终极问题：**这张脸是谁？** 人脸识别（face recognition）包含两种任务：

- **人脸验证（verification）**：两张脸是不是同一个人（1:1，手机解锁、闸机）。
- **人脸识别（identification）**：这张脸是注册库里的谁（1:N，安防检索）。

传统方法（特征脸、LBP）在小规模、受控条件下可用，但面对姿态、光照、年龄变化就崩溃。**DeepFace（2014）与 FaceNet（2015）**确立了现代人脸识别的范式：**用深度网络把脸编码成一个"嵌入向量（embedding）"，让同一人的向量距离近、不同人的距离远**——即**度量学习（metric learning）**。这套范式让机器识别人脸超过了人类（LFW 上 99%+）。<span class="marginnote">人脸识别是"最成功也最敏感"的视觉应用：成功在准确率超过人类、支撑了全球几十亿人的身份验证；敏感在隐私、偏见（深肤色误判率更高）、监控滥用。<strong>技术能力与伦理边界的张力，在人脸识别上体现得最充分</strong>——这也是它区别于其他视觉任务的地方。</span>

## 1 从分类到嵌入：人脸识别的范式转变

早期深度人脸识别把它当**分类问题**：每人一个类别，softmax 分类。但注册库是**动态变化**的（新用户随时加入），分类头必须跟着重建——不实用。

**范式转变：学"嵌入"而非"分类"**。用网络把人脸映射到 $d$ 维向量 $\mathbf{f} \in \mathbb{R}^d$（如 128 维）：

- **同一人**的脸 → 嵌入向量**距离小**。
- **不同人**的脸 → 嵌入向量**距离大**。

之后识别 = 比较向量距离：

- **验证**：距离 < 阈值 → 同一人。
- **识别**：与注册库所有向量比距离，取最近（且低于阈值）。

**关键：网络学到的是"脸的相似度空间"，而不是"特定的类别集合"**——新用户只需把他的脸嵌入存进库，无需重训网络。这就是"嵌入范式"能服务动态用户库的原因。

## 2 度量学习：让嵌入"拉开"

**度量学习（metric learning）**：训练网络让"同类近、异类远"。核心是**三元组损失（triplet loss）**（FaceNet 提出）：

$$
\mathcal{L} = \sum_i \max\left( 0, \; \lVert f(a_i) - f(p_i) \rVert^2 - \lVert f(a_i) - f(n_i) \rVert^2 + \alpha \right)
$$

其中 $(a, p, n)$ 是**锚点、正样本、负样本**三元组：$a$ 与 $p$ 是同一人、$a$ 与 $n$ 是不同人。$\alpha$ 是"间隔（margin）"。

**训练时**：从训练集里采样三元组（同一人的不同照片做 $a,p$，不同人的照片做 $n$），最小化损失——**把 $a$ 拉向 $p$、推离 $n$**。

**辨析｜易错点：** 三元组的采样质量决定训练成败。**随机采三元组，绝大多数"太简单"**（$a$ 和 $n$ 早就离得远，损失为 0），学不到东西。必须**困难样本挖掘（hard mining）**：优先采"$a$ 与 $n$ 很接近"的三元组。**"简单样本没有梯度，困难样本才有梯度"是度量学习的关键工程**。<span class="marginnote">三元组损失的数学直觉：它在"同一人 vs 不同人"之间硬性要求一个间隔 $\alpha$——比"只要求同类近"更强的约束。用间隔学习的价值：<strong>分类边界被推得离样本远，新样本的泛化更稳</strong>。这个"margin"思想与 SVM 的间隔最大化、人脸验证里"距离阈值"的选择一脉相承——"留出余地"是鲁棒识别的共同要求。</span>

## 3 DeepFace：对齐 + 深度特征的开端

**DeepFace（Facebook，2014）**是"深度学习 + 人脸识别"的开山之作，确立了三段式：

1. **检测 + 3D 对齐**：用 3D 人脸模型把检测到的人脸**正脸化**（3D alignment）——比 2D 仿射对齐更强，把侧脸"掰正"。
2. **深度 CNN 提特征**：对齐后的人脸过 CNN（8 层），输出 4096 维特征。
3. **度量**：用**孪生网络（Siamese network）**学习"两特征距离 → 是否同一人"，或用余弦距离。

DeepFace 在 LFW 上达到 97.35%（接近人类 97.5%），首次让机器在人脸识别上逼近人类——它证明"深度学习 + 对齐"的人脸识别可行。

## 4 FaceNet：端到端嵌入，抛弃显式对齐

**FaceNet（Google，2015）**更进一步：**用一个网络直接输出嵌入，不依赖对齐到标准姿态**。

- **架构**：CNN（GoogleNet/Inception）+ **L2 归一化**（嵌入落在单位球面上）+ **三元组损失**端到端训练。
- **关键**：对齐不再是显式预处理，网络自己学到"姿态不变"的表示（数据够多时，对齐被隐式吸收）。
- **结果**：LFW 99.63%，远超人类。

**FaceNet 的贡献**：证明**"原始像素 → 嵌入 → 度量"可以完全端到端**，无需手工对齐——对齐的活儿被数据量与网络容量"学"走了。这也奠定了"嵌入范式"在通用视觉（图像检索、ReID）里的地位。

**辨析｜易错点：** 嵌入向量要不要 L2 归一化？FaceNet 归一化到单位球（用余弦/欧氏距离等价）。**归一化让"距离"变成"角度"**——对光照引起的向量幅度变化更鲁棒。但归一化也压缩了"置信度信息"（幅度也能反映"像不像一张脸"）。工程里要按任务权衡。

## 5 公式解析：三元组损失的梯度行为

**为什么三元组损失能"拉近拉远"？** 看它对嵌入向量的梯度。

- **第一步，损失形式**：$\mathcal{L} = \max(0, D_{ap}^2 - D_{an}^2 + \alpha)$，其中 $D_{ap} = \lVert f(a) - f(p) \rVert$。
- **第二步，对 $f(a)$ 的梯度**：当损失 > 0（违反间隔）时：

$$
\frac{\partial \mathcal{L}}{\partial f(a)} = 2(f(a) - f(p)) - 2(f(a) - f(n))
$$

**$f(a)$ 被"拉向 $p$"（第一项）同时"推离 $n$"（第二项）**——一个更新同时做两件事。
- **第三步，对 $f(p)$、$f(n)$ 的梯度**：$f(p)$ 被拉向 $a$，$f(n)$ 被推离 $a$——**三元组里三个向量都在被优化**。
- **第四步，当损失 = 0**（已经满足间隔）：梯度为零，不更新——**"够好了就不动"，节约算力与泛化**。这个"仅惩罚违反间隔的样本"正是间隔损失的自适应性。

**一句话：三元组损失在损失非零时，同时对锚、正、负三个向量施加"拉近/推远"的梯度——度量空间的形状就是这样被"挤"出来的。**

## 6 现代人脸识别与反思

人脸识别的最新进展：

- **ArcFace（2018）**：用**加性角度间隔（additive angular margin）**的 softmax 变体，比三元组更稳、更准——"在分类框架里嵌入间隔"。
- **大规模 ID 库**：百万级身份的余弦嵌入检索，配合 Faiss 等向量数据库。
- **对抗与防伪**：活体检测（防止照片/视频/面具攻击）成为人脸识别的必需配套。

**反思**：人脸识别是"能力-风险"失衡的典型——**技术极强但伦理极敏感**。偏见（种族/性别误判差异）、隐私（面部数据不可匿名）、监控滥用，都是这门技术的现实代价。**"能做什么"与"该做什么"的分离，是学习人脸识别时必须意识到的维度**。<span class="marginnote">把 FaceNet 的嵌入范式与后文 CLIP 联系起来：CLIP 用对比学习把"图像嵌入"与"文本嵌入"拉到同一个空间——<strong>与 FaceNet 把"同一人的脸拉近"是同一套对比学习机制</strong>。事实上，CLIP 的损失就是"多模态版的三元组/对比损失"。<strong>从人脸识别到图文匹配，度量学习是贯穿"识别类任务"的底层语言</strong>。</span>

## 7 人脸识别的评测与工程实践

人脸识别是"评测驱动"的领域，工程里几个关键：

**评测基准**：

- **LFW / CPLFW / CFP-FP**：跨年龄、跨姿态的**人脸验证基准**（1:1）——"同一人 vs 不同人"的准确率。LFW 99%+ 早已饱和，**现代看更难基准**（CFP-FP 侧脸、AgeDB 跨年龄）。
- **MegaFace / IJB-C**：**大规模识别（1:N）**——从百万级注册库中找出正确的人，测"大规模检索的精度"。
- **评测协议**：验证（成对判断）、识别（1:N 检索）、闭集/开集（注册库是否包含目标）——**"协议不同，分数不可比"**。

**工程实践**：

- **对齐的必需性**：现代人脸识别通常"检测 → 5 点对齐 → 112×112 → 嵌入"——**"对齐是识别的隐形前提"**，对齐质量直接决定嵌入质量。
- **嵌入的归一化与阈值**：FaceNet 用余弦距离 + 阈值判断——**"阈值是业务参数"**：安全场景调低（多拒真）、便利场景调高（少误拒）——"阈值调在哪，由误拒/误识的代价决定"。
- **大规模检索**：百万级人脸库用**向量数据库（Faiss、Milvus）+ ANN 索引**——"嵌入空间 + 近似最近邻"是工业检索的标配。
- **活体检测的配套**：识别前先过活体（上一节）——**"识别 + 活体"是安全人脸系统的双保险**。

**人脸识别的成熟度**：它是"深度学习在视觉里最成功的落地"之一——**准确率超过人类、支撑全球几十亿次验证**。但它的"成熟"也伴随着"滥用"的阴影——**"技术成熟 ≠ 使用正当"**，评估一项人脸识别技术，既要看准确率，也要看它被用在哪儿、对谁。

## 8 小结

- **人脸识别**：验证（1:1）与识别（1:N）；范式从"分类"转向"嵌入"。
- **嵌入范式**：网络把人脸编码成向量，同类近、异类远，新用户免重训。
- **DeepFace**：3D 对齐 + CNN 特征 + 孪生度量，首次逼近人类。
- **FaceNet**：端到端嵌入 + **三元组损失** + L2 归一化，超过人类。
- **三元组损失**：拉锚-正、推锚-负，间隔 $\alpha$ 保证鲁棒；困难样本挖掘是关键。
- 现代：ArcFace 角度间隔、向量检索、活体检测配套；伦理敏感需谨慎。
