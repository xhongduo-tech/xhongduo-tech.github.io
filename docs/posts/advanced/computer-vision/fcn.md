## 为什么从 FCN 开始

图像分类网络（AlexNet、VGG）的输出是一个类别向量——它把整张图"压"成一个标签。但分割要求**每个像素一个标签**，输出必须与输入同尺寸。最简单粗暴的想法是"把分类网络接到一个上采样器上"，但浅层细节早已被池化抹掉，直接上采样只能得到糊成一团的分割图。

**FCN（Fully Convolutional Network，全卷积网络，2015）**是第一个真正端到端的语义分割网络。它的两个核心贡献：

1. **全卷积化**：把分类网络的**全连接层换成卷积层**——网络可以接受任意尺寸输入、输出任意尺寸的分类图。
2. **跳跃连接（skip connection）**：把**浅层的高分辨率特征与深层的语义特征融合**，让分割图既"懂语义"又"有细节"。

FCN 是"编解码分割"范式的开山之作，也是理解 U-Net、DeepLab 一切分割网络的地基。<span class="marginnote">FCN 的灵感来自"任何卷积网络本质上都是特征提取器"：分类网络前几层学的是"边缘→部件→物体"的层级特征，这些特征对分割同样有用。FCN 的洞察是——<strong>不用为分割另造网络，把分类网络的输出层改造一下、再把特征"放大"回像素空间即可</strong>。它首次证明了"迁移 + 改造"在像素级任务上的威力。</span>

## 1 全卷积化：把全连接换成卷积

分类网络的最后一层是**全连接层**：把 $7\times7\times512$ 的特征图展平成向量，接 $4096$ 维全连接。全连接层**要求输入尺寸固定**，且丢失空间结构。

**FCN 的关键改造**：把全连接层换成**等价的卷积层**（如 $7\times7$ 卷积把 $7\times7$ 特征图变成 $1\times1\times4096$）——数学上等价，但保留空间结构、接受任意输入尺寸。

改造后的网络成为**全卷积网络**：输入任意大小图像 → 输出任意大小的分类图（每个位置一个类别得分）。再用**转置卷积（deconvolution / transposed convolution）**或上采样把分类图放大回原图尺寸。

**"全卷积"的意义：网络从"图 → 标签"变成"图 → 图"，输入输出对齐，可以端到端训练。** 这是"稠密预测（dense prediction）"家族（分割、深度估计、光流）的通用网络形态。

## 2 上采样：转置卷积与双线性插值

把缩小的特征图放大回原尺寸，两种手段：

- **双线性插值**（上采样）：无参数、平滑，但不能学习。
- **转置卷积（transposed convolution / deconvolution）**：可学习的上采样——把每个输入像素"摊"到更大的区域（正向卷积的逆运算，带可学习核）。

**辨析｜易错点：** 转置卷积不是"卷积的逆"，它只是"梯度翻转的卷积"——把前向时"多对一"的池化/步长关系变成"一对多"。它会产生**棋盘伪影（checkerboard artifacts）**（重叠区域权重不均），现代实现常与双线性上采样 + 3×3 卷积组合使用。

## 3 跳跃连接：语义与细节的融合

分类网络逐层下采样，特征图越来越小：浅层（如第 3 层）分辨率高、细节足但语义弱；深层（最后层）语义强但分辨率低。**只从最后一层上采样**，会丢失所有边缘细节——分割图"大块色块"没有边界。

**FCN 的跳跃连接（skip connection）**：把**不同深度的特征图直接上采样并相加/融合**。

- **FCN-32s**：只从最后层上采样 32 倍（糊）。
- **FCN-16s**：融合第 4 池化层的特征（好一些）。
- **FCN-8s**：再融合第 3 池化层（细节更好）——跳跃连接逐级注入浅层细节。

**跳跃连接的本质：让"高分辨率的位置信息"与"低分辨率的语义信息"在不同尺度上结合。** 这正是上一节 FPN 的"自上而下融合"在分割里的版本——也预示了 U-Net 的对称跳跃结构。<span class="marginnote">FCN 的跳跃连接与 ResNet 的残差连接名字相似但作用不同：ResNet 的捷径是"跨层传递梯度防退化"，FCN 的跳跃是"跨尺度融合特征保细节"。一个保"训练",一个保"分辨率"——它们是深度学习里两个最容易被混淆的"跳跃"。到 U-Net 和 FPN 里，这两种跳跃被融合使用。</span>

## 4 公式解析：转置卷积的数学本质

**转置卷积"怎么把一个像素变成一块"？** 从矩阵运算看最清楚。

- **第一步，卷积的矩阵形式**：二维卷积可以写成矩阵乘法 $\mathbf{y} = C \mathbf{x}$，其中 $\mathbf{x}$ 是展平的输入、$C$ 是稀疏的卷积矩阵（每行对应一个输出位置的加权组合）、$\mathbf{y}$ 是展平的输出。**输出小于输入**（$C$ 是"瘦"矩阵）。
- **第二步，转置卷积**：用 $C^T$ 做变换 $\mathbf{y} = C^T \mathbf{x}$——输入展平后经 $C^T$ 放大。**$C^T$ 是"胖"矩阵，输出大于输入**——一个输入像素被"摊"到多个输出位置，权重由核决定。
- **第三步，为什么叫"转置"**：反向传播时，卷积层的梯度传递是 $C^T$；转置卷积等于"把前向当作反向传播的梯度路径来用"——数学上就是对偶运算。
- **第四步，可学习性**：$C^T$ 里的核参数可训练，网络学会"怎么放大才能恢复细节"——比固定插值更灵活。

**一句话：转置卷积 = 卷积的转置矩阵运算，把特征图"放大"且参数可学习；它是"可学习上采样"的标准构件。**

## 5 FCN 的局限与后续

FCN 的历史贡献：**第一个端到端的全卷积分割网络，语义分割从"分块分类"变成"逐像素分类"**。它的局限：

- **上采样粗糙**：转置卷积放大，边缘细节仍不精细（跳跃连接缓解但未根治）。
- **全局上下文弱**：逐像素分类"各看各的"，对"大物体各部分一致"缺乏全局约束（DeepLab 的空洞卷积与 CRF 来补）。
- **空间精度**：池化丢失的位置信息难以完全恢复。

FCN 之后，分割网络沿三条线演进：**编码-解码对称结构**（U-Net，跳跃全尺度）、**空洞卷积保持分辨率**（DeepLab）、**注意力/Transformer 全局建模**（SegFormer、Mask2Former）。但 FCN 的"全卷积 + 跳跃"依然是它们共同的地基。<span class="marginnote">把 FCN 与后文的扩散模型联系起来：扩散模型（Stable Diffusion）里的 U-Net 就是"FCN 的编解码 + 全尺度跳跃"结构——<strong>FCN 的跳跃思想跨越了二十年的技术断层，成为现代生成模型的骨干</strong>。理解 FCN，等于理解了"编码器压缩语义、解码器恢复细节、跳跃连接连接两端"这个视觉生成的最通用模板。</span>

## 6 FCN 的训练细节与逐像素损失

FCN 的训练与分类网络有几点关键差异，理解它们才知道"分割网络怎么训"：

- **逐像素 softmax 损失**：FCN 输出的每个位置过一个 softmax 分类器，损失是所有像素的交叉熵之和——**"把每个像素当一个小分类问题"**。这让 FCN 可以在**整图任意尺寸**上训练（全卷积接受任意输入）。
- **类别不平衡**：分割数据集里背景像素远多于前景（或不同类别像素数悬殊）——**朴素交叉熵会被大类别主导**。常用**类别权重**（$w_c \propto 1/\text{freq}_c$，给稀有类更高权重）或 **Dice/Focal 损失**缓解。
- **上采样层的初始化**：转置卷积若随机初始化，初期输出呈"棋盘噪点"；常用**双线性核初始化**（上采样核初始为双线性插值，再微调）——**"从合理的上采样起步，再让网络学细节"**。
- **跳跃连接的训练**：FCN-8s 融合浅层特征，浅层（第 3 层）的梯度来自分割损失——**浅层特征被"分割任务"重塑**，不再是纯分类特征。

**为什么逐像素训练可行**：全卷积化让"整张图一次前向"产出"全图分类图"，梯度逐像素回传——**一个 batch 就是"对每个像素的分类问题"**。这个"稠密监督"让网络学到"像素级的语义"。

**FCN 的遗产再审视**：它是"稠密预测"（分割、深度、光流、姿态热图）的共同模板——**"编码器提特征 + 上采样还原 + 逐像素预测"**。今天 U-Net 的跳跃、DeepLab 的空洞、SegFormer 的 Transformer，都在这个模板上做改进。**"全卷积 + 逐像素损失"是图像到图像任务的标准训练范式**，FCN 是它的原点。

## 7 从 FCN 到现代分割的衔接

FCN 之后，语义分割沿着几条主线演进，理解这些主线才能看懂现代分割：

- **编码-解码**（U-Net）：对称结构 + 全尺度跳跃——"细节恢复更好"（前文）。
- **空洞卷积**（DeepLab）：保持分辨率 + 多尺度上下文——"上下文建模"（前文）。
- **Transformer 分割**（SegFormer、Mask2Former）：注意力做全局建模、查询做统一分割——"全局 + 统一"（前文）。
- **基础模型分割**（SAM）：提示驱动任意分割——"分割能力而非分割任务"（前文）。

**FCN 的"骨架"在现代方法里依然可见**：SegFormer 也有编码器-解码器（金字塔编码 + 解码头）、Mask2Former 也有"特征 + 解码"——**"FCN 确立的'编码提特征 + 解码出逐像素结果'骨架从未被推翻"**。

**语义分割的关键挑战（贯穿各代）**：

1. **边界质量**：物体边缘的精细分割。
2. **小物体**：小目标的分割（依赖高分辨率）。
3. **类别不平衡**：背景/大物体主导损失。
4. **上下文理解**：大物体各部分一致、遮挡处合理推断。

**对学习者的启示**：FCN 是"从分类到逐像素"的分水岭——**"理解 FCN 的'全卷积 + 跳跃'，就抓住了语义分割 90% 的骨架"**。读任何分割论文，都先问"它的编码器在哪、解码器在哪、跳跃/上下文怎么做的"——**"FCN 的问题框架，至今是分割论文的提问框架"**。

## 8 小结

- **FCN** = 全卷积化 + 转置卷积上采样 + 跳跃连接，第一个端到端语义分割网络。
- **全卷积化**：把全连接换成卷积，网络输入输出都任意尺寸——稠密预测的通用形态。
- **转置卷积** = 卷积矩阵的转置运算，可学习的上采样；注意会产生棋盘伪影。
- **跳跃连接**：融合浅层细节与深层语义（FCN-8s > FCN-16s > FCN-32s）。
- 局限：上采样粗糙、全局上下文弱；U-Net 与 DeepLab 接棒。
