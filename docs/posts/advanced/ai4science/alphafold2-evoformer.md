## 为什么从 Evoformer 开始

前两篇把问题与原料都备齐了：**问题**是「由序列定结构」（Anfinsen），**原料**是进化信号（MSA 共进化）。现在只剩最后一块拼图：**一个能把这些原料变成三维结构的模型**。AlphaFold2 之所以在 2020 年的 CASP14 上让全场震惊，不是因为它用了什么闻所未闻的新数学，而是因为它把一堆「已有部件」——Transformer、注意力、图神经网络式的消息传递——重新组装成一套端到端可微、且**把蛋白质的几何结构嵌进架构本身**的机器。<span class="marginnote">读 AlphaFold2 架构有一条主线：它反复在问「哪些不变性必须内置、哪些可以从数据里学」。对称性、三角不等式这类几何事实被写进结构，其余交给训练——这正是《对称性与等变性》一篇的设计哲学在蛋白质上的具体化。</span>

这一篇聚焦它的**特征抽取器：Evoformer**，以及其中最具原创性的**三角注意力更新**。结构模块（不变点注意力 IPA）留给下一篇。读懂 Evoformer，你就理解了 AlphaFold 一半的「聪明」。

## 1 AlphaFold2 的总体骨架：两条表示、一个循环

AlphaFold2 是一个**端到端**模型：输入 MSA 与可选模板，直接输出每个残基的三维坐标。内部维护着**两条并行、不断互馈的表示**：

- **MSA 表示（MSA representation）** $m$：形状 $S \times N \times c_m$，$S$ 是比对中的序列数，$N$ 是目标蛋白残基数。它携带「每一条同源序列在每一个位置」的信息，即上一篇讲的共进化原始数据。
- **成对表示（pair representation）** $z$：形状 $N \times N \times c_z$，$c_z = 128$。$z_{ij}$ 是「残基 $i$ 与残基 $j$ 关系」的向量，是后续一切三维推断的工作台——残基间距离、方向、接触都从这里读出。<span class="marginnote">成对表示在概念上非常接近图神经网络里的「边特征」：$N$ 个节点是残基，$z_{ij}$ 是边 $(i,j)$ 的特征。所以 AlphaFold2 本质上是把「完整图（每对节点都有边）」喂给一个特殊的 GNN——这也解释了它为什么经常被归入图网络一脉。</span>

两条表示经过 **48 层 Evoformer** 的反复迭代，最后把 MSA 表示压缩掉、由成对表示进入**结构模块（Structure Module）**输出坐标。核心设计问题因此变成：**如何让 $m$ 与 $z$ 在每一层里充分交换信息，同时让 $z$ 变得越来越「几何自洽」？** Evoformer 的每个块给出两套答案——注意力交换信息，三角更新保证几何一致。

## 2 Evoformer 的循环：信息如何在两条表示间流动

Evoformer 块的基本操作分两组。

**第一组：MSA 表示内部的注意力。** 把 $m$ 看成 $S \times N$ 的矩阵，沿两个方向分别做自注意力：

- **沿序列方向（row-wise / per-row attention）**：对固定位置 $i$，各序列之间互相注意——模型在这里学习「哪些序列片段共同支持某个位置的状态」。
- **沿残基方向（column-wise / per-column attention）**：对固定序列，各残基位置之间互相注意——这里学习「一条序列内部的远距离依赖」，类似语言模型对 token 序列的建模。<span class="marginnote">把 MSA 矩阵同时当作「序列集合」和「位置序列」来读，是 AlphaFold 的巧妙之处：同一个张量，两种注意力读出两种语义。这相当于把「进化维度」与「序列维度」都建模了。</span>

**第二组：MSA 表示 → 成对表示，外积平均。** 把 $m$ 的每一行（一条序列）投影成两组向量 $a_{si}$ 与 $b_{si}$，对每对残基 $(i,j)$ 做外积并对所有序列平均，得到 $z$ 的增量。这是两条表示之间最重要的信息泵——它把「共进化」从 MSA 里抽出来，灌进成对表示。这条公式是本节重点，放在第 3 节单独拆解。

随后成对表示还会经历一系列自注意力与三角更新（第 4 节），并把信息回传给 MSA 表示。**48 层里每一层都重复「MSA → pair → 更新 → 回传」的节奏**，进化信号就这样一层层被蒸馏成几何信息。

把 Evoformer 块内的部件按「作用对象」与「功能」列成一张表，整个循环一目了然：

| 部件 | 作用对象 | 主要功能 |
| --- | --- | --- |
| 行注意力（row attention） | MSA 表示，固定位置 $i$、跨序列 | 在进化维度上比较各序列 |
| 列注意力（column attention） | MSA 表示，固定序列、跨位置 | 在序列维度上建模远距离依赖 |
| 外积平均（outer product mean） | MSA 表示 → 成对表示 | 抽取共进化信号，灌进 $z$ |
| 三角乘法更新 | 成对表示 | 经第三残基 $k$ 的消息传递 |
| 三角注意力（start/end） | 成对表示 | 用第三条边做偏置，软性协调几何 |
| 成对→MSA 回传 | 成对表示 → MSA 表示 | 把几何信息反馈回序列通道 |

注意表格的流向：**三条操作朝「下」（MSA → pair），两条操作朝「内」（pair 自精化），一条操作朝「上」（pair → MSA）**——$m$ 与 $z$ 在这样的双向流里共同进化，这就是 Evoformer 名字里「evo」（共进化）的由来。

## 3 公式解析：外积平均

外积平均（outer product mean）把 MSA 表示的一小片信息变成成对表示。对每个残基 $i$、每个位置 $j$、每个通道对 $(\alpha, \beta)$：

$$
O_{ij,\alpha\beta} = \frac{1}{S}\sum_{s=1}^{S} a_{si,\alpha}\; b_{sj,\beta}, \qquad
a_{si} = \mathrm{Linear}(m_{si}),\ \ b_{sj} = \mathrm{Linear}(m_{sj})
$$

随后把 $O_{ij}$ 摊平并通过一个线性层，作为 $z_{ij}$ 的更新。四步拆解：

- **第一步，$a_{si}$ 与 $b_{sj}$ 是什么**：它们是对 MSA 表示 $m$ 的**两次不同线性投影**——分别编码「残基 $i$ 的角色」与「残基 $j$ 的角色」。为什么要两组？因为外积 $a \otimes b$ 需要两侧来自不同的线性变换，才能捕捉「$i$ 的某特征 × $j$ 的某特征」的配对模式。
- **第二步，外积 $a_{si} \otimes b_{sj}$ 在做什么**：$a_{si} \otimes b_{sj}$ 是 $c \times c$ 的矩阵，第 $(\alpha,\beta)$ 元是 $a_{si,\alpha} b_{sj,\beta}$。它穷举了「$i$ 的每一个特征与 $j$ 的每一个特征如何组合」——在**单条序列 $s$** 的视角下，记录 $i$ 与 $j$ 的「联合特征」。
- **第三步，对 $s$ 求平均**：$\frac{1}{S}\sum_s$ 把单序列的联合特征聚合成**整个进化家族的一致意见**。如果大量同源序列里，$i$ 的 $\alpha$ 通道特征与 $j$ 的 $\beta$ 通道特征**总是同时出现或同时消失**（即共进化），平均外积在 $(\alpha,\beta)$ 处就大——**共进化信号在这里被数学地抽了出来**。<span class="marginnote">对照上一篇的 DCA：协方差 $C_{ij}(a,b) = f_{ij}(a,b) - f_i(a)f_j(b)$ 也是「两位置联合出现率」的度量。外积平均是同一思想的<strong>可微、端到端</strong>版本——不再显式算协方差，而是让神经网络自己学会在哪个通道对上加总。</span>
- **第四步，投影回成对表示**：$O_{ij}$ 是 $c^2$ 维（$c=32$ 时是 1024 维），摊平后经线性层降到 $c_z=128$ 维，作为残差加到 $z_{ij}$。**这一步把「进化上的联合变异」翻译成「空间上的潜在关系」，正是 AlphaFold 的直觉来源。**

实现的核心不过几行 NumPy——把「对所有序列求外积的平均」翻译成矩阵乘法：

```python
import numpy as np

# msa: (S, N, C)  MSA 表示；S 序列数，N 残基数，C 通道数
def outer_product_mean(msa, d_pair=128):
    S, N, C = msa.shape
    a = msa @ np.random.randn(C, C)          # (S, N, C)  投影 a
    b = msa @ np.random.randn(C, C)          # (S, N, C)  投影 b
    O = np.einsum('sic,sjd->ijcd', a, b) / S # (N, N, C, C) 平均外积
    return O.reshape(N, N, C * C) @ np.random.randn(C * C, d_pair)  # → (N, N, d_pair)
```

`einsum('sic,sjd->ijcd', a, b)` 正是「对每个序列 $s$ 做残基 $i$、$j$ 之间的外积，再对所有 $s$ 求和并除以 $S$」——公式与代码一一对应。读代码时请盯住这一行：**它把共进化信号从「序列集合的统计」压缩成「残基对的特征」**，其余行都只是维度整形。

## 4 三角注意力更新：把几何一致性写进注意力

外积平均给了成对表示新信息，但**成对表示内部需要自洽**——否则 128 维向量之间会互相矛盾。蛋白质几何给自洽性提供了一个硬约束：**三角形不等式**。任意三个残基 $i, j, k$，它们两两之间的距离必须满足三角不等式；换成「成对表示」的语言，就是**三条边 $(i,j)$、$(i,k)$、$(j,k)$ 的特征必须彼此协调**。AlphaFold2 的原创贡献，就是用注意力实现这种「三角形协调」，分两招。

**第一招：三角乘法更新（triangular multiplicative update）。** 更新边 $(i,j)$ 时，聚合所有「通过第三个残基 $k$ 的路径」——用 $a_{ik}$（$i$ 到 $k$ 的信息）与门控后的 $b_{jk}$（$j$ 到 $k$ 的信息）做逐元素相乘求和：

$$
z'_{ij} = z_{ij} + \sum_{k} a_{ik} \odot g_{jk} \qquad (\text{outgoing 版本示意})
$$

它很像图神经网络里的**消息传递**：边 $(i,j)$ 从所有「以 $k$ 为中转」的两条边收集信息。物理直觉：$i$ 与 $j$ 的关系，理应由「$i$ 与第三者 $k$ 的关系」和「$j$ 与第三者 $k$ 的关系」共同约束——这正是三角不等式的「特征版本」。

**第二招：三角注意力（triangle attention）。** 更精巧。更新边 $(i,j)$ 时，注意力不再只看一条边，而是构造一个**以残基 $i$ 为起始节点（starting node）的三角形**：

$$
\alpha^{h}_{ijk} = \mathrm{softmax}_{k}\left(\frac{(q^{h}_{ij})^{\mathsf{T}} k^{h}_{ik}}{\sqrt{c}} + b^{h}_{jk}\right), \qquad
o^{h}_{ij} = g^{h}_{ij} \odot \sum_{k} \alpha^{h}_{ijk}\, v^{h}_{ik}
$$

- **query 来自被更新的边 $(i,j)$**，**key 与 value 来自共享起始节点 $i$ 的边 $(i,k)$**——注意力在「$i$ 出发的所有边」上分配权重。
- **bias $b^{h}_{jk}$ 来自第三条边 $(j,k)$**：这是三角性的关键——$k$ 相对 $j$ 的关系，作为先验偏置进入注意力打分。
- 一个**门控** $g^{h}_{ij}$（sigmoid 化的边特征）逐元素调节输出；最终 $z_{ij} \leftarrow z_{ij} + \mathrm{Linear}(\mathrm{concat}_h\, o^h_{ij})$，残差更新。

对称地，还有「以 $j$ 为终止节点（ending node）」的版本：query 仍来自 $(i,j)$，key/value 换成共享 $j$ 的边 $(k,j)$，bias 换成 $(i,k)$。**两个方向交替使用，保证三角形三条边都被对称地协调。**

**辨析｜易错点：** 三角注意力并不显式地「检查三角不等式」——它不会计算三条边长度再比较。它是**软性地、可微地**把「第三条边」的信息注入「两条边」的更新，让网络在训练中学会让三者彼此一致。<span class="marginnote">「软性约束 vs 硬性约束」是深度学习里的经典取舍：硬约束（把三角不等式直接写进损失）保证不出错但僵化；软约束（用注意力结构暗示）灵活但需要学。AlphaFold 选的是后者。</span>把「三角」理解为「一次只协调三个节点 $i, j, k$ 的关系」，就抓住了它的本质。

## 5 48 层之后：成对表示如何变成坐标

Evoformer 迭代 48 层之后，模型丢弃 MSA 表示，把成对表示 $z$ 连同残基序列特征交给**结构模块（Structure Module）**。结构模块用另一种原创机制——**不变点注意力（invariant point attention, IPA）**——在三维空间里直接摆放每个残基，并通过**多次循环精化**逐步逼近最终构象。那里有一组保证「预测坐标对旋转平移不变」的数学设计，正是《对称性与等变性》一篇思想最彻底的执行。

IPA 属于下一篇的主题，这里只强调一点：**整条管线从 MSA 到坐标全程可微**，所以网络可以拿「预测坐标与真实结构的距离」直接做梯度训练，端到端地同时优化「如何用进化信息」与「如何摆原子」。这种「特征提取与几何推断联合学习」的紧耦合，是 AlphaFold2 与传统「先算特征、再对接」路线的根本区别。<span class="marginnote">端到端训练的价值在 AlphaFold 身上体现得淋漓尽致：外积平均、三角注意力、IPA 全部协同优化，任何一环单独拿出来都只是「不错的部件」，组合起来才达到 CASP14 的原子级精度。</span>

## 6 小结

- AlphaFold2 是**端到端**模型：输入 MSA，输出三维坐标，内部维护 **MSA 表示**与**成对表示**两条互馈通道。
- **Evoformer** 共 48 层，每层包含 MSA 内部的双向注意力、把 MSA 抽成成对表示的**外积平均**，以及成对表示的自我精化。
- **外积平均** $O_{ij} = \tfrac{1}{S}\sum_s a_{si}\otimes b_{sj}$ 把共进化信号从序列统计里**可微地**抽出来灌进成对表示。
- **三角更新**用「三个节点 $i,j,k$ 两两协调」实现几何一致性：乘法更新做消息传递，三角注意力把第三条边作为偏置注入注意力打分。
- 三角约束是**软性的**——不显式检查不等式，而是让网络在训练中学到协调。
- 48 层之后，成对表示交给**结构模块（IPA）**输出坐标，全程可微、联合优化。

在下一节，我们将进入结构模块内部，回答：**不变点注意力（IPA）如何在保证旋转平移不变的前提下，把成对表示「摆」成三维坐标？**——这是《对称性与等变性》设计哲学在蛋白质预测里的收官之战。
