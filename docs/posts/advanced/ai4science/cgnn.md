## 为什么从晶体图网络开始

上一篇解决了「晶体怎么表示」——答案是「周期图」。接下来自然是：**谁在图上工作？** 2018 年，Xie 与 Grossman 提出的 **CGCNN（Crystal Graph Convolutional Neural Network）** 第一次把「晶体图卷积」做成通用性质预测器——形成能、带隙、弹性模量一个模型通吃。它的成功奠定了「晶体 ML = 图网络」的路线。但 CGCNN 有天花板：**它只能「读固定结构的性质」，不能「动结构」**。于是出现了更强大的**等变图网络**——**M3GNet、CHGNet**——它们不仅能预测性质，还能给出「力」，从而能做结构弛豫与分子动力学模拟：**从「读心」（预测）升级为「读身」（模拟）**。<span class="marginnote">「预测性质」与「模拟演化」是两回事：预测是「给定结构，读它的性质」；模拟是「给定结构，算出原子受的力，让结构自己动」。后者需要的正是「<strong>力</strong>」——而力是能量对坐标的导数，等变图网络正好让「能量与力自洽地同时给出」。这是 CGCNN 到 M3GNet 的本质跨越。</span>

这一篇拆解 CGCNN 的架构、它与等变网络的差别、M3GNet/CHGNet 的「通用原子间势」定位，以及「什么时候用哪个」。

## 1 CGCNN：把晶体图喂给卷积网络

**核心概念：CGCNN**。构造晶体图：**节点 = 原子**（特征 = 元素的物理属性向量：族、周期、电负性、价电子数等）；**边 = 近邻原子对**（特征 = 距离的高斯展开）。然后跑「图卷积」：

- **卷积层**：每个原子从邻居收集「消息」，消息由「邻居特征 × 边特征（距离）」构成——**距离越近、邻居的贡献权重越特殊**（学出来的）。
- **堆叠多层**：感受野扩大——原子「看到」越来越远的化学环境。
- **读出**：把全部原子特征「加权池化」成晶体级向量，再映射到性质（形成能、带隙）。

**关键设计：边特征用「距离的高斯展开」。** 把距离 $d$ 用一组高斯基展开（$d$ 落在哪个高斯 bin 里）：

$$
e_{ij} = \Big[ \exp\Big(-\frac{(d_{ij} - \mu_k)^2}{2\sigma^2}\Big) \Big]_{k=1}^{K}
$$

- **$\mu_k$**：第 $k$ 个高斯中心（如 0, 0.5, 1.0, … Å）——把「连续距离」变成「距离的分布编码」。
- **为什么高斯展开**：比「裸距离」信息更丰富（保留距离的局部结构）、且「光滑」（对微小位移连续）——神经网络更容易学。<span class="marginnote">「距离的高斯展开」几乎是所有结构 ML 的默认边特征（分子 GNN、蛋白网络、材料图网络通用）。它与「傅里叶特征映射」思想同源：<strong>把连续标量提升成一组「带位置信息的基」，让网络能区分「近/中/远」</strong>。</span>

CGCNN 的成功还在于**可解释性**：它给每个邻居一个「注意力式权重」，可以画出来看「哪个原子/键主导性质预测」——对材料科学家很有吸引力（「为什么这个结构稳定」）。

## 2 公式解析：晶体图卷积的消息传递

CGCNN 的一层卷积（以原子 $i$ 为中心）：

$$
\mathbf{v}_i^{(t+1)} = \mathbf{v}_i^{(t)} + \sum_{j \in \mathcal{N}(i)} \sigma\big( \mathbf{z}_{ij}^{(t)} \odot \mathbf{W}_s \mathbf{v}_j^{(t)} + \mathbf{b}_s \big)
$$

其中 $\mathbf{z}_{ij}^{(t)} = \sigma\big( \mathbf{z}_{ij}^{(0)} \mathbf{W}_z^{(t)} + \mathbf{b}_z^{(t)} \big)$，$\mathbf{z}_{ij}^{(0)} = e_{ij}$（边特征）。

- **$\mathbf{v}_i^{(t)}$**：原子 $i$ 第 $t$ 层的特征；$\mathcal{N}(i)$ 是它的邻居（含跨晶胞的镜像，见上一篇）。
- **$\mathbf{z}_{ij}$ 是「门控」**：由边特征经线性层 + sigmoid 得到——**它决定「这条消息放行多少」**。距离近的边可能「全放行」，远的「半放行」——门控让网络学会「依赖距离的邻居权重」。
- **$\mathbf{W}_s \mathbf{v}_j^{(t)}$**：邻居 $j$ 的特征经线性变换——「邻居的化学信息」。
- **逐元素相乘 $\odot$**：门控 × 邻居信息——「按距离调制邻居贡献」。
- **残差求和**：$\mathbf{v}_i^{(t)} + \sum_j(\cdots)$——保留自身信息，累积邻居贡献。<span class="marginnote">注意 CGCNN 与分子 GNN（MPNN）的差别：<strong>CGCNN 的门控直接依赖「距离」（边特征），分子 GNN 的边特征通常是「键类型」</strong>——因为晶体的「键」没有离散类型，只有连续距离。这个「连续距离驱动门控」的设计，是晶体图网络特有的工程智慧。</span>

读出层做「归一化池化」：$\mathbf{v}_\text{crystal} = \frac{1}{N}\sum_i \mathbf{v}_i^{(L)}$（或带注意力权重），再过 MLP 输出性质。**整个网络对「原子顺序」置换不变**（求和/池化不依赖顺序），对「晶胞平移」不变（距离特征），但**不满足完整旋转等变**——这是它与等变网络的差距所在。

## 3 从「性质预测」到「力场」：等变图网络的跃迁

CGCNN 的输出是「性质标量」，不提供「力」。而材料科学的许多核心任务需要力：

**结构弛豫（relaxation）**：把「近似结构」放到能量最小点——需要「原子受的力」来迭代移动原子。
**分子动力学（MD）模拟**：按「牛顿方程」演化原子轨迹——每一步都要「力」。

**核心概念：原子间势（interatomic potential）**：一个「给定结构 → 能量（和力）」的函数。传统势（EAM、MEAM、Lennard-Jones）是人工设计的近似；**机器学习势（ML potential）** 用数据训练——而**等变图网络正是最成功的 ML 势骨架**。

为什么「等变」对力场是必须的：**力是向量**——旋转结构，力必须跟着转（等变）；能量是标量——旋转不变。若用非等变网络输出「力」，同一个结构的旋转副本会得到「不旋转的力」（错误）。**等变网络保证「能量不变、力等变」，且 $F = -\nabla E$ 自动满足**——「能量与力从一个自洽的模型同时给出」是它碾压非等变网络的核心优势。<span class="marginnote">「等变力场」的另一个巨大好处是<strong>数据效率</strong>：训练时「能量 + 力」同时监督（力是能量的梯度，信息更丰富），且等变性让旋转副本自动共享——同样的数据量，等变网络学得更准。这就是为什么 MACE、NequIP（下一篇）能逼近 DFT 精度而训练数据少得多。</span>

## 4 M3GNet 与 CHGNet：通用原子间势

**M3GNet**（Chen & Ong, 2022）与 **CHGNet**（Deng 等, 2023）是「通用机器学习势」的代表——目标不是「一种材料一个势」，而是「一个势覆盖整个元素周期表与化合物空间」。

**M3GNet**：基于等变 GNN，同时预测能量与力；训练数据来自「DFT 弛豫轨迹」（不止静态结构，还有演化过程的中间态）——让它学到的势「理解结构如何演化」。
**CHGNet**：在 M3GNet 思路上更进一步，训练数据覆盖「声子计算 + 弛豫结构」；独特之处是**捕捉「磁矩」（磁化强度）**——用「原子磁矩」作为可学习/可预测的量，让它能处理磁性材料（很多过渡金属氧化物的磁性对性质至关重要）。<span class="marginnote">「通用势」的意义：DFT 计算一次约秒到分钟、只能算单结构；通用势一次前向毫秒级、可批量。M3GNet/CHGNet 的野心是「<strong>让材料的 DFT 精度模拟变成机器学习的速度</strong>」——结构搜索、高通量弛豫、分子动力学全部提速几个量级。</span>

**重点：从 CGCNN 到 M3GNet/CHGNet 的演进，是「性质预测器」到「通用模拟器」的跨越。** CGCNN 答「这个结构稳定吗、带隙多大」；M3GNet/CHGNet 答「结构会怎么动、能量面长什么样」——后者能「自己探索结构空间」（弛豫、MD），这是「发现新材料」的关键能力（下一篇 GNoME 正是大规模用这类能力）。

## 5 效果、局限与选择

**效果**：

**CGCNN**：形成能、带隙等标准性质上，误差接近 DFT 的典型水平（形成能误差约几十 meV/atom）；「每材料毫秒级」批量扫描。
**M3GNet/CHGNet**：在「通用势基准」（如 Material Project 的弛豫能量）上逼近 DFT，能做结构弛豫、弹性常数、声子、MD；CHGNet 在磁性/电荷态相关性质上有独特优势。<span class="marginnote">「逼近 DFT」是个需要澄清的说法：ML 势的误差（约 10–50 meV/atom）比「DFT 与实验的误差」小，但比「高精度 DFT（HSE/杂化泛函）」差。<strong>ML 势是「DFT 的代理」，不是「实验的代理」</strong>——它继承 DFT 的系统误差，只是把 DFT 的计算成本换成了一次前向。</span>

**局限**：

- **训练分布边界**：通用势「通用」在「见过多的元素组合」，但「未见过的化学计量比/极端状态（高温高压）」仍不可靠——外推是 ML 势的永恒课题。
- **等变的代价**：等变网络实现复杂、计算比非等变重——大规模扫描时「用 CGCNN 粗筛、用等变势精算」是务实组合。
- **数据标签**：M3GNet/CHGNet 的训练依赖大规模 DFT 数据集（生成成本高）——「先花大钱造势，后省小钱模拟」的经济模型。

**选择法则**：要「性质批量扫描」→ CGCNN 类（快、够用）；要「结构弛豫/MD/力」→ 等变势（M3GNet、CHGNet、MACE）；要「发现新材料」→ 两者配合（图网络筛选 + 等变势精算 + DFT 验证）。

## 6 进阶辨析：晶体图网络的「实现陷阱」与「从 CGCNN 到通用势的选型」

把 CGCNN 类模型跑对，几个实现陷阱值得列出——以及「性质预测 vs 通用势」的选型判据。

**实现陷阱一：距离特征的「归一化」。** 距离的高斯展开要「匹配实际距离分布」——「cutoff 内的距离范围与高斯中心的分布要对齐」——「中心定太疏，距离分辨率不够；太密，特征冗余」。**「按数据集的『实际距离直方图』定高斯中心」比「均匀铺」更稳**。

**实现陷阱二：门控的「数值稳定」。** CGCNN 的门控用 sigmoid（输出 0-1）——「梯度容易饱和」——「门控的初始化与学习率要小心」——「门控饱和会让『消息传递失效』（门控全 0 或全 1）」。**「监控门控的分布」是训练诊断的必备**。

**实现陷阱三：池化的「信息损失」。** 「平均池化」把原子特征压成晶体级——「会丢失『分布信息』（哪些原子贡献大）」——**「注意力池化/加权的『重要原子』信息，对性质预测常常更好」**——「池化方式的选择影响可解释性（能不能看『哪个原子主导性质』）」。

**选型判据：性质预测 vs 通用势。** 「只要性质（形成能/带隙）」→ CGCNN 类「便宜、够用、可解释」；「要力/弛豫/MD」→ 等变势（M3GNet/CHGNet/MACE）「必要、贵、强」。**「判据：你的下游需不需要『结构演化』」**——「只读静态 → 性质预测器；要动结构 → 必须力场」。

**一个工程建议：先 CGCNN 做基线。** 任何晶体性质任务，先用 CGCNN 类跑出「基线」（便宜、快、可解释），再决定「值不值得上等变」——**「等变的增益要在『同数据、同任务』的公平对比里验证，不是『听名字更高级』」**——「基线先行，复杂后上」是晶体 ML 的工程纪律。

**辨析｜易错点：** 别把「CGCNN 的『可解释性』（注意力权重）当『化学因果』」——「注意力权重大的原子『与预测相关』，不一定是『决定性质的化学原因』」——「归因与因果的差距，在晶体 ML 里同样存在」。

## 7 小结

- **CGCNN**：晶体图 + 门控卷积——节点是元素特征、边是距离的高斯展开；预测形成能、带隙等，毫秒级批量扫描，且可解释。
- **卷积公式**：$\mathbf{v}_i^{(t+1)} = \mathbf{v}_i^{(t)} + \sum_{j\in\mathcal{N}(i)} \sigma(\mathbf{z}_{ij} \odot \mathbf{W}_s\mathbf{v}_j^{(t)} + \mathbf{b}_s)$——门控由连续距离驱动。
- **等变跃迁**：从「性质预测」到「力场模拟」需要「力」；等变网络保证「能量不变、力等变、$F=-\nabla E$ 自洽」。
- **M3GNet/CHGNet**：通用原子间势——等变 GNN + 大尺度 DFT 训练数据（弛豫轨迹/声子），能做弛豫、MD；CHGNet 捕捉磁矩。
- **效果与局限**：逼近 DFT 但继承其系统误差；外推受限；等变计算更重。
- **务实组合**：CGCNN 粗筛 → 等变势精算 → DFT 验证——「快粗 + 准精 + 真验」的三层漏斗。
