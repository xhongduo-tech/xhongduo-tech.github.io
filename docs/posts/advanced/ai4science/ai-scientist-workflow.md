## 为什么从工作流开始

上一篇《AI for Science 的兴起》立起了「第四范式」的坐标系，但范式是宣言，**工作流才是范式落地的骨架**。AlphaFold2、GNoME、FunSearch 这些名字之所以有冲击力，不是因为它们各自的模型有多精巧，而是因为它们分别补上了科学发现这条流水线上一段原先要靠人肉完成的工序。本篇把这条流水线拆开来看：**假设生成 → 实验设计 → 数据分析 → 自动化闭环**，每一段现在都有 AI 的身影，而「闭环」把它们串成一台自动运转的机器。<span class="marginnote">读懂工作流，你就拥有了给后面每一篇技术文章「对号入座」的框架：AlphaFold 是数据分析段的重构，GNoME 是主动学习式的实验设计，FunSearch 是假设生成段的尝试。</span>

它与本课程的关系：往低处看，科学方法的分歧（归纳 vs 演绎、证实 vs 证伪）是第一级《科学史与科学哲学》的内容，本篇的工作流是那套哲学争论的工程化版本；往高处看，贝叶斯优化依赖第二级《概率论与数理统计》，闭环自动化又直通第四级《强化学习》与第十篇的《科学 Agent》。工作流，是连接哲学与代码的那层胶水。

## 1 科学的经典循环：假设—实验—数据—分析

科学方法最朴素的形式，是一个**四段循环**：

$$
\text{观察} \longrightarrow \text{假设} \longrightarrow \text{预测} \longrightarrow \text{实验检验} \longrightarrow \text{分析修正} \longrightarrow \text{新假设} \longrightarrow \cdots
$$

这个循环通常被叫作**假说—演绎法（hypothetico-deductive method）**：先从观察中归纳出一个可检验的假设，再从假设演绎出可观测的推论，用实验检验推论，最后根据结果保留、修正或抛弃假设。波普尔（Karl Popper）把「可证伪性」放在这个循环的中心：**一个命题要成为科学命题，必须能够被某个可能的实验推翻**。<span class="marginnote">波普尔的证伪主义在本篇有一个朴素但重要的工程后果：好的自动化科学系统，必须能对「假设被否定」做出反应，而不是只会重复验证已知正确的路径。</span>

传统上，这个循环的四个节点由四种角色完成：科学家提出假设，实验员设计并执行实验，统计学家分析数据，再回到科学家修正假设。**人在这四个节点之间来回传递信息，而每一次传递都有成本、延迟与偏见**——这正是 AI for Science 介入的位置：它不取代科学，而是把循环中的节点逐一自动化，最后把整个循环变成一台可以自己转动的机器。

**辨析｜易错点：** 常见的误解是「AI 科学家 = 一个自动做实验的机器人」。实际上工作流自动化是**分层**的：可以先只自动化数据分析（AlphaFold），也可以只自动化实验设计（GNoME 的主动学习），最后才谈全自动闭环。每一层都有独立的科学价值，不必一步到位。

## 2 假设生成：从人类直觉到机器生成

四段循环里，**假设生成是最难自动化的一段**，因为它需要「创造性想象力」——这正是爱因斯坦那段话的用意。人类科学家靠领域直觉、类比与运气提出假设；机器要复制这个过程，必须先在巨大的解空间里做有导向的搜索。

FunSearch（2023）是一个经典样本。它的目标不是直接训练一个模型，而是**用大语言模型在程序空间里搜索**：把「产生候选函数」这件事交给语言模型，再让演化算法去挑选并迭代这些候选程序。<span class="marginnote">FunSearch 的名字是 Function Search 的合成词。它击中的不是代码生成，而是「在数学与算法的程序空间里做发现」：语言模型负责生成有希望的程序，演化算法负责筛选与组合，两者互补。</span>在 cap set 问题上，它找到了比人类已知构造更大的集合；在装箱问题上，它发现了比人类启发式更好的在线装箱策略——而且这些发现以**可读程序**的形式呈现，而不是黑箱权重。

在纯数学方向，2025 年出现的 Pattern Boost 展示了另一条路线：让语言模型**基于现有数学对象反复提出「模式」猜想**，再用形式化验证器或符号计算去检验，被否定的猜想反馈给模型以修正方向。它的产出是「此前人类未注意到、但机器可验证」的新猜想——这在十年以前还被认为是不可想象的。

两条路线共享一个要点：**机器生成的假设必须经过外部验证才能进入科学**。FunSearch 靠演化选择与穷举验证，Pattern Boost 靠形式化证明器。机器可以负责「发散」，但「收敛」必须交给无情的检验器。

## 3 实验设计：把「下一步做什么」变成优化问题

假设有了，接下来要决定**做哪些实验**。在药物筛选、材料合成、参数标定这类场景里，每个实验都昂贵且耗时，于是「选哪个实验先做」本身就成了一个需要优化的决策问题。

**主动学习（active learning）**给出第一个框架：模型已经有一个不确定的预测，那么**选择能让模型信息增益最大的数据点去标注**。例如训练一个预测材料稳定性的模型，与其随机挑材料做实验，不如挑「模型最拿不准」的那些——一次实验同时削减最多个不确定性。

**贝叶斯优化（Bayesian optimization）**把这件事做得更数学化：用一个廉价的高斯过程代理模型逼近昂贵的真实目标函数，再用一个**采集函数（acquisition function）**决定下一个采样点。它同时利用两个信号——代理模型给出的**预测均值**（哪里看起来最好）与**预测方差**（哪里最不确定），在这两者之间做权衡。这恰好回应了上一篇强调的科学数据「稀疏而昂贵」的特点：数据贵，所以每一步选择都要精打细算。<span class="marginnote">高斯过程（Gaussian Process）是第二级《概率论与数理统计》中多元正态分布在无穷维的推广：它不只给出一个预测值，还给出每个位置的完整置信区间——这正是「不确定度」的数学来源。</span>

三种实验选择策略可以放在一起对照，差别一目了然：

| 策略 | 下一步选哪个实验 | 是否用历史数据 | 典型场景 |
| --- | --- | --- | --- |
| 随机选择 | 任意 | 否 | 基线、数据极稀疏 |
| 主动学习 | 模型最不确定的点 | 是 | 数据标注成本高的分类任务 |
| 贝叶斯优化 | 采集函数最大化 | 是 | 目标函数昂贵且连续（材料、药物、参数） |

三者的共同点是都承认「实验有成本」：随机选择把钱花在运气上，主动学习花在「信息」上，贝叶斯优化花在「目标函数的期望改进」上。**把「做哪个实验」从凭感觉变成优化问题，本身就是工作流自动化迈出的第一步。**

## 4 数据分析：从人工统计到自动模式发现

循环的第三段——**数据分析**——是 AI for Science 最早成熟的环节，也是上一篇《科学数据的特点》的落地场景。传统分析流程是：清洗数据 → 降维 → 统计检验 → 画图 → 人工读图。这套流程里，**「识别模式」这一步最依赖人的眼睛与直觉**，而神经网络恰好擅长从高维数据中识别模式。

AlphaFold 把「由序列推断结构」当成一个数据分析问题：输入是进化数据（多序列比对），输出是三维坐标，中间的学习模型自动提取出「序列的哪些位置倾向于空间靠近」这类模式。机器学习的优势在于，它不需要人预先指定「该看什么特征」——特征本身从数据里长出来。

更一般地，自动化的数据分析包含三件事：**表征学习**（把原始数据变成有用的向量）、**模式挖掘**（找到相关性与结构）、**不确定性报告**（告诉科学家这个结论有多可靠）。其中第三件最容易被人忽略，却最接近科学精神——一个没有置信度的预测，无法进入「假设—检验」的循环。

把数据分析放到「科学」而非「工程」的语境里看，还有一个特殊要求：**分析结论必须能与物理或化学规律对账**。纯机器学习模型可能在训练分布内非常准，却在物理上不可信——例如预测的能量低于物理下限。这正是上一篇《科学机器学习的问题分类》提到的「物理约束」在工作流这一端的具体形态：自动分析不是越准越好，而是**越符合已知规律越好**。可解释性与不确定性，在这里不是锦上添花，而是让分析结果能回到「假设—检验」循环的通行证。<span class="marginnote">「让模型同时给出预测与置信度」正是第四篇《科学基础模型》与第十一篇《误差估计与不确定性量化》反复出现的主题；本篇先立住它在工作流里的必要性。</span>

## 5 公式解析：预期改进（Expected Improvement）

贝叶斯优化能「聪明地选实验」，靠的是采集函数。最常用的采集函数是**预期改进（Expected Improvement, EI）**，它回答的问题是：给定当前最好的观测值 $f_{\text{best}}$，在候选点 $x$ 处做实验，**平均能比现状好多少**？

$$
\mathrm{EI}(x) = \mathbb{E}\left[\max(f(x) - f_{\text{best}},\ 0)\right]
= \big(\mu(x) - f_{\text{best}}\big)\,\Phi\!\left(\frac{\mu(x) - f_{\text{best}}}{\sigma(x)}\right) + \sigma(x)\,\varphi\!\left(\frac{\mu(x) - f_{\text{best}}}{\sigma(x)}\right)
$$

对这条公式做四步拆解：

- **第一步，认清 $f(x)$ 是什么**：$x$ 是一个候选实验（如一组合成条件），$f(x)$ 是该实验的真实结果（如产率）。$f$ 是昂贵、无解析表达的黑箱，所以要用代理模型去猜。
- **第二步，读出两个主角 $\mu(x)$ 与 $\sigma(x)$**：它们来自高斯过程代理模型的后验——$\mu(x)$ 是「该点的期望结果」，$\sigma(x)$ 是「该点结果的不确定度」。不确定度大，可能来自数据稀疏，也可能来自该区域波动剧烈。
- **第三步，看懂两项的分工**：第一项 $(\mu - f_{\text{best}})\Phi(\cdot)$ 是**利用（exploitation）**——朝预测结果最好的地方去；第二项 $\sigma(x)\,\varphi(\cdot)$ 是**探索（exploration）**——朝最不确定的地方去，因为那里可能藏着惊喜。EI 把两者按概率加权，正是「既抓当下最优，又保留翻盘机会」的数学表达。
- **第四步，机械地做决策**：对候选集合里的每个 $x$ 算出 $\mathrm{EI}(x)$，选最大者做下一个实验，做完更新代理模型，再算下一轮。整个「实验设计」就这样被翻译成了**反复最大化一个廉价函数**。

值得强调：$\Phi$ 与 $\varphi$ 分别是标准正态的分布函数与密度函数，它们在第二级《概率论与数理统计》里反复出现。<span class="marginnote">「探索—利用权衡」（exploration–exploitation tradeoff）是整个决策科学的母题：在《强化学习》里它是 ε-greedy 与置信上界，在《推荐系统》里它是多臂老虎机，在贝叶斯优化里它由 EI 一次给出。</span>

实现不过十几行。用 SciPy 的两个函数即可算出任意候选点的 EI：

```python
from scipy.stats import norm

def expected_improvement(mu, sigma, f_best):
    """mu/sigma: 代理模型在候选点的后验均值/标准差；f_best: 当前最优观测。"""
    z = (mu - f_best) / sigma
    return (mu - f_best) * norm.cdf(z) + sigma * norm.pdf(z)
```

读出公式与代码的对应关系：`(mu - f_best) * norm.cdf(z)` 是第一项「利用」，`sigma * norm.pdf(z)` 是第二项「探索」。**给两个候选点套同一个函数，EI 大的那个就是下一场实验的选择**——整个「实验设计」的智力劳动，被压缩成了一个一行可写的函数。

## 6 自动化闭环：自驱动实验室与闭环科学

当循环的四段——假设、设计、实验、分析——各自都被自动化之后，把它们**首尾相接**，就得到**自驱动实验室（self-driving lab）**：机器人执行实验，仪器自动读数据，算法分析并更新假设，再由下一个采集函数决定下一轮实验，人类只在起点给定搜索范围与目标。

一个成熟案例是 2023 年伯克利团队报道的 **A-Lab**：它把文献中已知的合成配方与一个预测稳定性的模型结合，让机器人在高温炉里自动合成候选材料、自动表征产物，并将结果反馈回模型。在预定的候选空间里，A-Lab 自主合成了数百种目标材料，其中大量被确认稳定——整个「提出假设—设计—合成—验证—修正」的循环，不再需要人守在炉边。<span class="marginnote">把闭环放在第九篇《自动化化学实验室》与第十篇《科学 Agent》再往前想一步：当语言模型能读文献、能写代码、能调用仪器接口时，「科学家」的角色会被重新分配。这不是预言，而是已经在发生的工作流迁移。</span>

**辨析｜易错点：** 必须区分**自动化（automation）**与**自主（autonomy）**。自动化是「每个步骤按固定规则执行」，自主是「系统自己决定步骤」。A-Lab 在给定搜索空间内是自主的，但它不会自己决定「该研究什么新问题」——那个「问题边界」仍由人划定。**闭环的边界在哪里，是评估任何「AI 科学家」系统时首先要问的问题**；也是第十篇《科学 Agent》里「人在环内 vs 人在环外」争论的技术版本。

把「工具还是方法」的追问（见上一篇）落到工作流上，结论就清晰了：**AI 每接管循环的一段，就是把一种曾经需要人的能力固化成了可复用的机器能力**。接管的段数越多，科学的「吞吐量」越大；而始终留在人手中的，是问题本身的提出与价值判断。

## 7 小结

- 科学发现是一个**四段循环**：假设生成、实验设计、数据分析、闭环迭代；AI for Science 逐个自动化这些节点。
- **假设生成**最难自动化，代表方向是 FunSearch 的程序空间搜索与 Pattern Boost 的猜想生成——机器生成的假设必须经过外部验证。
- **实验设计**被翻译成优化问题：主动学习选「信息增益最大」的点，贝叶斯优化用采集函数平衡利用与探索。
- **数据分析**是最早成熟的环节：深度学习自动提取特征、识别模式，并应输出不确定性。
- **预期改进公式** $\mathrm{EI}(x) = (\mu - f_{\text{best}})\Phi(\cdot) + \sigma\,\varphi(\cdot)$ 是「探索—利用权衡」的数学落地。
- **自动化闭环**把四段首尾相接成自驱动实验室；但**自动化 ≠ 自主**，问题边界仍由人划定。

在下一节，我们将从「科学家的流程」转入「蛋白质的世界」，回答一个困惑了生物学家半个世纪的问题：**氨基酸序列如何决定三维结构？**——从 Anfinsen 原理到 Levinthal 悖论。
