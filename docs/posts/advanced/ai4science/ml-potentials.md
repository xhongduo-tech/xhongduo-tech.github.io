## 为什么从机器学习力场开始

上一篇文章提到：等变图网络能给出「力」，从而驱动结构弛豫与分子动力学（MD）。这一篇把「力从哪来」讲透——**原子间势函数（interatomic potential）**。MD 模拟的每一步都要「算力」，而「力」来自「能量对坐标的梯度」——问题变成：**怎么又快又准地计算「给定结构 → 能量」**？这条路上有三代角色：**经验势**（快但糙）、**第一性原理**（准但贵）、以及当下的主角——**机器学习力场（ML force field, MLFF）**：用神经网络从第一性原理数据里学势能面，目标是「**DFT 的精度，经典势的速度**」。<span class="marginnote">「算力」是原子模拟的生死线：DFT 驱动的 MD 只能跑几百个原子、几皮秒；经典势能跑百万原子、纳秒级，但精度不足（配位、电荷转移、方向键全被简化）。<strong>ML 力场要的是「两全」——把 DFT 的精度「蒸馏」进一个毫秒级前向的网络</strong>。2020 年代，NequIP、MACE 用「等变神经网络」把这件事做到了接近实战。</span>

这一篇讲原子间势的演化、ML 力场的基本框架（描述符 + 逐原子网络）、等变力场（NequIP/MACE）的关键创新，以及「力场基础模型」这个前沿。

## 1 原子间势的演化：从经验势到 DFT 到 ML 势

**核心概念：原子间势（interatomic potential）**：把「原子结构」映射到「系统总能量」的函数 $E(\mathbf{r}_1, \ldots, \mathbf{r}_N)$——力是它的梯度：$\mathbf{F}_i = -\nabla_{\mathbf{r}_i} E$。

三代角色的对比：

| 类型 | 代表 | 精度 | 速度 | 适用 |
| --- | --- | --- | --- | --- |
| 经验势 | Lennard-Jones、EAM、REBO | 粗（简化键合） | 极快 | 惰性气体、简单金属、粗筛 |
| 第一性原理 | DFT（从头算 MD） | 高 | 极慢 | 小体系、短时间、单点验证 |
| ML 力场 | DeepMD、NequIP、MACE | 逼近 DFT | 快（毫秒/步） | 中大规模 MD、弛豫、高通量 |

**为什么「中间地带」长期空白**：经验势缺「方向性/电荷转移」等量子效应，DFT 又贵得无法做长时间 MD——**「精度」与「速度」之间缺一座桥**。ML 力场的思路：**用 DFT 数据训练神经网络，让它成为「DFT 的快速代理」**——训练集是「（结构，DFT 能量，DFT 力）」，推理时网络秒级给出能量与力。<span class="marginnote">ML 力场的「教父」是 Behler-Parrinello 2007 年的工作：用「原子中心对称函数（ACSF）」做描述符 + 逐元素神经网络，首次让「DFT 精度 × 经典势速度」成为可能。此后 DeepMD（深度势）、MTP（矩张量势）把「描述符」越做越好，而 NequIP/MACE 用「等变」把数据效率提升到新高度——<strong>这是一条「描述符 → 表征」的进化线</strong>。</span>

## 2 ML 力场的基本框架：描述符 + 逐原子网络

无论具体架构如何，ML 力场共享一个「逐原子求和」的骨架：

$$
E(\text{structure}) = \sum_{i=1}^{N} \varepsilon_\theta\big( \mathcal{D}(\mathbf{r}_i; \{\mathbf{r}_j\}_{j \in \mathcal{N}(i)}) \big)
$$

- **$\mathcal{D}(\mathbf{r}_i; \cdots)$ 是「原子 $i$ 的环境描述符」**：把「原子 $i$ 及其邻居的几何」转成「对旋转/平移不变的向量」——它是「原子 $i$ 身处何环境」的压缩编码。
- **$\varepsilon_\theta$ 是「逐原子能量网络」**：从描述符到「原子 $i$ 的能量贡献」——一个 MLP。
- **总能量 = 各原子贡献求和**：这个「加和性假设」是几乎所有 ML 力场的基石——它让「系统能量」分解为「原子局部贡献」，且天然满足「平移/置换不变」。
- **力 = 能量对坐标的梯度**：$\mathbf{F}_i = -\nabla_{\mathbf{r}_i}E$——**由能量自动微分得到，不用单独学**。<span class="marginnote">「力 = 能量的梯度」是 ML 力场最重要的设计：<strong>能量与力天然自洽</strong>（不必分别学两个网络），而且训练时「力」作为监督信号（梯度信息）大大增强了数据效率——一个「力标注」相当于给能量面加了「局部斜率」信息。这也是为什么「只报能量误差」的力场论文不够严谨：真正的考验是「力的精度」与「MD 轨迹的物理合理性」。</span>

**描述符的设计史**：早期用「手工对称函数」（ACSF，对旋转不变但表达力有限）；现代用「消息传递」（DeepMD、NequIP 把描述符变成「可学习的表征」）——「描述符从设计走向学习」的又一例证。

## 3 公式解析：等变消息传递与不可约表示

NequIP 与 MACE 的突破在于「**E(3) 等变消息传递**」——用「球谐张量」（不可约表示）作为特征，让「旋转」与「消息传递」数学上自洽。一个等变消息层的骨架：

$$
\mathbf{h}_i^{(l+1)} = \mathbf{h}_i^{(l)} + \sum_{j \in \mathcal{N}(i)} Y^l\big( \hat{\mathbf{r}}_{ij} \big) \otimes \mathbf{h}_j^{(l)} \cdot f\big( \lVert \mathbf{r}_{ij} \rVert \big)
$$

- **$\mathbf{h}_i^{(l)}$ 是「不可约表示（irreps）」特征**：每个特征是一个「按旋转矩阵 $D^l$ 变换的向量」——不是「标量」，而是「携带旋转行为信息的张量」。
- **$Y^l(\hat{\mathbf{r}}_{ij})$ 是球谐函数**：把「方向 $\hat{\mathbf{r}}_{ij}$」提升为「按旋转等变的基」——**方向信息被保留为「会跟着转的量」，而不是被压缩成标量丢掉**。
- **$\otimes$ 是张量积**：把「方向信息」与「邻居特征」耦合——MACE 的关键创新在这里（见下节）。
- **$f(\lVert \mathbf{r}_{ij}\rVert)$ 是距离权重**：标量函数，调制「多近的邻居影响多大」。

**为什么等变这么有用**：等变特征让网络「天生知道旋转」，因此：

1. **数据效率**：同一结构的所有旋转副本自动共享特征——不再需要数据增强或海量数据去「学」旋转不变性。
2. **方向信息不丢**：非等变网络把方向「压成标量」（如距离），丢掉了「这个邻居在哪个方向」——对力、对方向性键合（如 sp³ 杂化）是致命损失。<span class="marginnote">「等变 vs 不变」的工程权衡：等变网络（NequIP、MACE）精度高、数据省，但实现复杂、计算更重；非等变网络（DeepMD）简单快，但需要更多数据去补偿「学方向」。<strong>在数据充足时差距缩小，在数据稀缺（新材料体系）时等变优势显著</strong>——这解释了为什么「小数据 + 等变」是当前主流配方。</span>

## 4 NequIP 与 MACE：等变力场的两级进化

**NequIP**（Batzner 等, 2022）：把「E(3) 等变消息传递」系统化为「通用 ML 力场骨架」——球谐张量特征 + 张量积消息 + 力的梯度训练。它在「小数据力场基准」（如 CH 体系的 MD）上以「几百个 DFT 帧」就达到逼近 DFT 的力精度——**数据效率的显著提升**。

**MACE**（Batatia 等, 2022）：在 NequIP 之上加了一个关键数学创新——**消息传递 + 多体展开**。MACE 的洞察：标准的「一次张量积」只建模「两体/三体」相互作用；MACE 通过「把消息传递的多层输出做更高阶的张量积」，**高效构造「任意阶多体相互作用」**——从二体、三体一直延伸到「很多体」。

$$
\mathbf{h}_i^{(\text{many-body})} = \sum_{\text{orders } n} \Big( \text{tensor product of } n \text{ messages} \Big)
$$

- **为什么多体重要**：原子间的相互作用本质是多体的（电荷极化、多中心键合）——经验势只到二/三体，所以糙；MACE 让「多体阶数」成为可调的表达力旋钮。
- **效果**：MACE 在多个基准上（分子、材料）达到或超越当时的 SOTA，且**数据效率进一步上升**。<span class="marginnote">MACE 的「多体展开」与「原子簇展开（atomic cluster expansion）」理论一脉相承——把势能面展开成「不同阶数的多体项之和」。<strong>「把物理的展开结构写进网络」是 MACE 超越「纯黑箱等变网络」的关键</strong>：它不是「更深的网络」，而是「更正确的结构」。</span>

**重点：NequIP 是「等变 + 梯度力」的奠基，MACE 是「把多体物理写进等变」的升华**——两者的组合（等变 + 多体）奠定了现代 ML 力场的基本范式。

## 5 数据、训练与基础模型

**数据**：ML 力场训练需要「（结构，DFT 能量，DFT 力）」三元组——生成成本不菲。质量要点：

**采样覆盖**：训练数据要覆盖「模拟时会遇到的构型空间」——不能只放平衡结构（MD 会跑到非平衡态）。主动学习采样（DFT 算「模型不确定的区域」）是关键。
**力的重要性**：力标注是「免费的高信息量」——必须用（只报能量的训练浪费了梯度信息）。

**训练技巧**：

**损失 = 能量损失 + 力损失**（加权）：$\mathcal{L} = \lambda_E \lVert E_\theta - E_{\text{DFT}} \rVert^2 + \lambda_F \lVert \mathbf{F}_\theta - \mathbf{F}_{\text{DFT}} \rVert^2$。
**多任务 / 多性质**：同时训练能量、力、应力（弹性）。
**主动学习**：模拟中检测「模型不确定度」（集成方差）高的构型，补算 DFT——「模拟与训练同步进化」。<span class="marginnote">「力场基础模型」是 2023 年后的新前沿：<strong>MACE-MP-0</strong> 用 Materials Project 的 DFT 数据训练「通用力场」，覆盖元素周期表的大部分组合——下游任务只需轻量微调。这与大语言模型的「预训练 + 微调」完全同构：<strong>「先在大数据上学通用化学，再在小数据上适配特定体系」</strong>——是「科学基础模型」趋势在力场上的落地（本专题第十章详述）。</span>

**局限**：

- **外推风险**：训练分布外的极端状态（高温、高压、缺陷浓度）不可靠——「学到的势能面」不等于「真实势能面」。
- **长程作用**：静电、范德华是长程的，局域图网络难捕捉——需要「长程修正项」（如 Ewald 求和式神经网络）。
- **不确定性**：模型不知道自己「没见过什么」——集成/校准是必要的安全网。

## 6 进阶辨析：ML 力场的「验收标准」与「何时够好」

ML 力场「训得好不好」，不能只看「训练误差」——要用「模拟层面的验收」。

**验收一：能量的「热力学一致性」。** 误差再小，也要验「热力学量」（内能、热容、相变温度）与实验/DFT 的一致——**「能量面的『一阶（力）二阶（振动）性质』都要验」**——「只报能量 MAE 是不够的」。

**验收二：动力学的「长时间稳定性」。** 跑「长 MD」看「能量漂移、结构是否失真」——**「训练误差小 ≠ 模拟稳定」**——「滚 100 万步能量不漂移，才是可用力场」。

**验收三：外推区域的「刻意测试」。** 测试「训练分布外」的状态（高温、高应变、缺陷）——**「知道『哪里会崩』，比『不知道哪里崩』好」**——「外推边界要测出来、标出来」。

**何时够好**：当「ML 力场误差 < DFT 泛函差异」且「模拟稳定」——再提升意义有限，瓶颈在标签（DFT）——「够用即可，不必追极限」。

**辨析｜易错点：** 别把「对训练集的力误差」当「通用性」——「力场对『训练过的体系』准，对『新元素/新化学』未必」——「通用力场（MACE-MP 类）也要『按体系验证』，不能无脑迁移」。

## 7 小结

- **原子间势**：$E(\mathbf{r})$ 决定 MD 的每一步；经验势快而糙、DFT 准而贵——**ML 力场要「DFT 精度 × 经典速度」**。
- **逐原子框架**：$E = \sum_i \varepsilon_\theta(\mathcal{D}(\mathbf{r}_i))$——加和性假设 + 描述符 + 逐原子网络；**力 = 能量梯度**（自动微分，能量力自洽）。
- **等变消息传递**：球谐张量特征 $Y^l(\hat{\mathbf{r}}_{ij})$ + 张量积——旋转自洽、方向信息不丢、数据效率大增。
- **NequIP vs MACE**：前者奠基「等变 + 梯度力」，后者用「多体展开」把多体物理写进等变——「更正确的结构」胜过「更深的网络」。
- **数据与训练**：主动学习覆盖构型空间、能量 + 力联合损失、集成不确定度。
- **前沿**：MACE-MP-0 等力场基础模型——「预训练 + 微调」进入原子模拟。
