## 为什么从单细胞基础模型开始

上一篇讲完经典流程——每一步用专门工具、每步都要人工判断。但单细胞数据正在爆炸式增长（人类细胞图谱计划要测上亿细胞），经典流程的「每步一个模型」开始显得奢侈。2023–2024 年，**单细胞基础模型**（scGPT、Geneformer、scFoundation）登场：**用一个预训练在千万级细胞上的 Transformer，学出「通用细胞表征」，再让聚类、注释、批次校正、扰动预测等下游任务统统从它派生**。它们的口号与大语言模型如出一辙——「先在大数据上学通用生物学，再在小数据上适配具体任务」。<span class="marginnote">单细胞基础模型的「大数据」从哪来？公开的 scRNA-seq 数据已积累到「亿级细胞」（人类细胞图谱、CellxGene 等）。<strong>「数据足够多」是基础模型的前提</strong>——这在单细胞领域已基本满足，而在很多其他科学领域（如稀缺疾病的样本）还不满足。这也是为什么单细胞是「科学基础模型」最早落地的领域之一。</span>

这一篇逐个拆解三大模型的「预训练任务」与「架构选择」，它们如何统一各类下游任务，以及——**基础模型的「强」与「骗」**：它们真的学会了生物学，还是只是在「背数据」？

## 1 从「模块化流程」到「一个模型」：范式转换

回顾上一篇：经典流程是「归一化 → HVG → PCA → 聚类 → 注释」——**每一步换一个模型**。基础模型的思路是：**训练一个模型，让它输出「细胞的通用嵌入」，下游全部任务共享这个嵌入**。

$$
\mathbf{z}_i = \mathrm{Encoder}_\theta(\text{cell } i \text{ 的表达}), \qquad
\text{下游}：\text{聚类}(\mathbf{z}),\ \text{注释}(\mathbf{z}),\ \text{批次校正}(\mathbf{z}),\ \text{扰动预测}(\mathbf{z})
$$

**为什么这个「统一表征」有吸引力**：

- **跨任务共享**：注释学到的信息帮聚类、批次校正帮注释——「一个模型，到处复用」。
- **跨数据集迁移**：在大数据集预训练，小数据集（罕见疾病）只需微调。
- **少样本/零样本**：未见过的新细胞类型，靠「嵌入的相似性」也能初步推断。<span class="marginnote">「基础模型的承诺」是：<strong>把「每任务一个模型」变成「一个模型 + 轻量适配头」</strong>。这个承诺在 NLP/视觉被验证过，单细胞基础模型试图在生物上复刻——但「验证程度」远不如 NLP，这是要清醒认识的一点。</span>

## 2 预训练任务：怎么让 Transformer 学「细胞的语言」

三个模型共享「Transformer + 自监督预训练」，但「预训练任务」设计不同——这决定了它们学到什么。

**Geneformer（2023）**：把细胞当成「按表达量排序的基因序列」——每个细胞 = 「高表达到低表达的基因 token 序列」（截断到前 2048 个）。预训练任务：**掩码语言建模（MLM）**——遮住基因，让它从上下文预测被遮住的基因。**它学的是「哪些基因倾向于共同高表达」（基因调控共现）**。

**scGPT（2023–2024）**：把细胞 = 「基因的集合」（无顺序），每个基因 token 带「表达量的分箱（bin）嵌入」。预训练任务：**掩码基因 + 表达量预测**——遮住部分基因，预测它们是否表达、表达多少。它学的是「细胞类型特异的表达模式」。

**scFoundation（2023）**：把「表达量」当成**连续值**直接建模，用「**xTrimoGene**」架构 + **掩码值预测**——不只要预测「基因在不在」，还要预测「表达多高」。它主打「从细胞状态中学习高精度表征」。<span class="marginnote">三者预训练任务的差异，对应「生物学的不同假设」：<strong>Geneformer 假设「基因的共现顺序有意义」、scGPT 假设「表达量分箱够用」、scFoundation 假设「连续表达量不可丢失」</strong>。谁对？——取决于下游任务。实测中，scGPT/scFoundation 在「细胞类型注释、批次校正」上表现好，Geneformer 在「调控关系」上更出名——「任务决定模型」的又一例证。</span>

**核心概念：细胞嵌入（cell embedding）**：预训练后，把细胞输入编码器，取「序列级池化」得到向量 $\mathbf{z}_i$——**这是细胞的「通用指纹」**，下游一切任务用它做输入。

## 3 公式解析：掩码表达预测与细胞嵌入

以 scGPT 的预训练目标为例，把「掩码基因预测」写成数学。设细胞 $i$ 的基因集合 $\mathcal{G}_i$，每个基因 $g$ 有 token 嵌入 $e_g$ 与表达分箱嵌入 $p_g(\text{bin})$：

$$
\mathbf{h}_g^{(L)} = \mathrm{Transformer}^{(L)}\big( e_g + p_g + \text{位置/类型} \big), \qquad
\hat{y}_g = \sigma\big( \mathbf{W} \mathbf{h}_g^{(L)} \big)
$$

- **输入**：基因 token 的「嵌入 + 表达分箱嵌入」之和——**每个基因的输入同时携带「它是谁」与「它表达多少」**。
- **掩码**：预训练时随机遮住一部分基因——被遮住的基因不提供自己的表达，模型要**从其他基因的上下文推断它**。
- **预测目标 $\hat{y}_g$**：对每个被遮基因预测「它是否表达」或「表达落入哪个分箱」——损失是交叉熵。
- **细胞嵌入**：预训练后，$\mathbf{z}_i = \text{Pool}(\{\mathbf{h}_g^{(L)} : g \in \mathcal{G}_i\})$——所有基因的最终表征池化成「细胞向量」。<span class="marginnote">「掩码预测」为什么能学到生物学：<strong>要预测被遮基因的表达，模型必须学会「基因之间的共表达规律」</strong>——哪些基因总是一起高表达（同一细胞类型/同一调控通路）。这与 BERT 学「词的共现」、蛋白质语言模型学「残基的共进化」完全同构——「遮住一部分，用上下文补全」是自监督的万能配方。</span>

**下游适配**：细胞嵌入 $\mathbf{z}_i$ 可以直接喂给「聚类」（对 $\mathbf{z}$ 做 k-NN + Leiden）、「注释」（$\mathbf{z}$ → 细胞类型分类头）、「批次校正」（$\mathbf{z}$ 对批次不敏感）、「扰动预测」（条件化生成）——**同一个嵌入，所有任务共用**。

## 4 下游任务：基础模型能做什么

把「统一表征」派生的典型下游任务列成表：

| 下游任务 | 怎么做 | 基础模型的价值 |
| --- | --- | --- |
| 细胞类型注释 | $\mathbf{z}_i$ → 分类头 | 零样本/少样本注释，跨数据集泛化 |
| 批次校正 | 训练/对齐时用 $\mathbf{z}$（对批次鲁棒） | 无需专门的 Harmony/Seurat |
| 聚类 | 对 $\mathbf{z}$ 做 k-NN + Leiden | 嵌入更「语义化」，罕见类型更容易分 |
| 扰动响应预测 | 条件化（敲低基因 → 预测细胞变化） | 「基因扰动 → 表达变化」的泛化 |
| 数据集成 | 把多个数据集的 $\mathbf{z}$ 对齐 | 跨平台/跨物种整合 |

**重点：基础模型的「卖点」是「一个嵌入，全下游复用」**——尤其「零样本注释」与「扰动预测」是经典流程做不到的：经典流程需要「每数据集重训练」，基础模型可以「未见过该数据集就直接嵌入」。<span class="marginnote">「扰动预测」是单细胞基础模型最有想象力的应用：<strong>如果模型真的学会了「基因如何调控表达」，那么「敲低基因 X」就能通过「条件化编码器」预测「细胞会变成什么样」</strong>——这让「虚拟基因编辑」成为可能，是药物靶点发现（本篇章最后一篇）的引擎之一。但「想象力」不等于「可信度」——扰动预测的外推性仍有争议。</span>

## 5 批判性评估：基础模型真的「学」了吗

单细胞基础模型的论文铺天盖地，但社区的批判同样尖锐——**它们的「强」需要被拆开看**：

**基线不公平**：很多「vs 经典方法」的对比没有调好经典基线（Seurat/Harmony 在公平设置下仍很强）。
**信息泄漏**：预训练数据与下游评测数据重叠时，模型「记住」了答案——「零样本」其实见过。
**提升幅度有限**：在「公平 + 严格切分」的基准上，基础模型的增益常是「几个点」而非「量级」——远不如 NLP 里基础模型对经典方法的碾压。
**可解释性缺失**：嵌入是「黑箱」——「为什么这群细胞被分到一起」难以用标记基因解释。<span class="marginnote">一个值得记住的结论（来自 2024 年多项独立评估）：<strong>单细胞基础模型在「标准下游任务」上通常「持平或略优于」经典工具，但在「大规模整合、少样本、跨物种」等经典工具薄弱处有明显优势</strong>。用「NLP 的期待」去要求单细胞基础模型会失望；用「场景选择」去用它们会受益。</span>

**辨析｜易错点：** 「基础模型」不是「银弹」。嵌入再强，也受「预训练数据的分布」限制——**对训练数据里稀有的细胞类型/物种，嵌入不可靠**。而且「嵌入的好」不等于「解释的好」——用嵌入做科学结论（「这群细胞是新的疾病亚型」）前，必须用标记基因/实验验证。「<strong>嵌入用于发现，经典用于确认</strong>」——这条纪律放之单细胞而皆准。

## 6 进阶辨析：单细胞基础模型的「选型」与「正确使用」

单细胞基础模型不是「一个」，而是一族「任务取向不同」的模型——选型与使用有讲究。

**选型一：按「表征粒度」选。** Geneformer（基因序列顺序）适合「基因调控关系」类任务；scGPT（基因集 + 表达分箱）适合「细胞注释、批次校正」；scFoundation（连续表达）适合「表达量的精细预测」。**「模型的设计取向 = 它擅长的任务类型」**——「没有『最好』，只有『匹配任务』」。

**选型二：按「数据分布」选。** 预训练数据决定「适用人群/物种」——「人类数据预训练的模型，在小鼠上要谨慎」；「多组织预训练 vs 单组织预训练」影响「泛化 vs 特化」。**「预训练分布的覆盖 = 模型的适用边界」**——「用之前，先看它见过什么数据」。

**正确使用一：嵌入 + 经典工具的组合。** 基础模型的价值在「嵌入」——但「下游处理」仍可复用「经典工具」：「用基础模型出嵌入 → 用 Leiden 聚类 → 用标记基因注释」——**「基础模型的嵌入 + 经典流程的后续」是最务实的组合**——「不必把整个流程都换掉」。

**正确使用二：批次的「显式处理」。** 即使基础模型声称「批次鲁棒」，实际使用时仍要「检查批次效应是否残留」——「用批次标签可视化嵌入，看是否混杂」——**「模型声称的『鲁棒』要用数据验证，不能直接相信」**。

**正确使用三：注释的「双重确认」。** 用基础模型做「零样本注释」时，仍要「用标记基因二次确认」——**「嵌入给的『标签』与标记基因给的『证据』一致时，才可采信」**——「AI 注释 + 经典确认」是「发现 + 验证」分工的单细胞版。

**一个常见的「过度解读」要避免**：基础模型「在扰动预测上表现好」——不意味着它「理解了调控机制」——**「预测表达变化」与「理解为什么变化」是两回事**——「预测可用于『假设生成』，理解仍需『机制实验』」。

把「选型 + 使用」合起来，就是单细胞基础模型的「正确姿势」：**「按任务选模型、按分布看边界、嵌入复用经典工具、批次与注释双重确认」**——「基础模型是『更强的表征器』，不是『自动的科学结论生成器』」。

**辨析｜易错点：** 别把「基础模型的嵌入可视化」当「生物学结论」——「UMAP 上靠近」不自动等于「同一类型」——「嵌入的邻近性需要『标记基因/独立验证』支撑，才能成为生物学主张」。「可视化是探索，验证才是结论」。

## 7 小结

- **单细胞基础模型**：预训练在千万级细胞上的 Transformer，产出「通用细胞嵌入」，聚类/注释/批次校正/扰动预测全部派生。
- **三大模型**：Geneformer（基因序列 + MLM）、scGPT（基因集 + 掩码表达预测）、scFoundation（连续表达 + 掩码值预测）——「预训练任务 = 对生物学的假设」。
- **公式**：$\hat{y}_g = \sigma(\mathbf{W}\mathbf{h}_g^{(L)})$——掩码基因预测迫使模型学「基因共表达规律」；细胞嵌入 = 基因表征池化。
- **下游**：零样本注释、批次校正、扰动预测是「经典流程做不到」的卖点。
- **批判**：基线不公平、信息泄漏、增益有限、不可解释——「持平或略优」是公允评价。
- **纪律**：嵌入用于发现、经典用于确认；预训练分布决定嵌入的适用范围。
