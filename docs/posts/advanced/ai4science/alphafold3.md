## 为什么从 AlphaFold3 开始

AlphaFold2 回答的是「一条蛋白链怎么折叠」。但真实的生物功能几乎总是发生在**复合物**里：酶结合底物、抗体结合抗原、蛋白与 RNA 组装成机器、药物分子嵌入活性口袋。要把 AI 结构预测推进到「可做药物设计」的层次，必须同时摆对**蛋白质、核酸、小分子配体、金属离子**的联合结构。<span class="marginnote">AlphaFold3（2024，Nature）带来的突破不止精度：它把蛋白质、DNA/RNA、小分子与翻译后修饰统一进同一个生成框架，药物-靶点结合姿态预测的基准成功率显著领先此前所有方法——这是「从结构预测到药物发现」的关键一跃。</span>

与 AlphaFold2 相比，AF3 的架构发生了三处本质变化：**统一 token 化**（把残基、核苷酸、配体原子都变成 token）、**Pairformer 替代 Evoformer**（更快的成对表示处理）、以及最革命性的**扩散模块替代 IPA 回归**（从「直接回归坐标」变成「用扩散生成模型去噪出坐标」）。这篇文章把这三处一一讲透，重点落在扩散模块上。

## 1 从「蛋白独奏」到「复合物合奏」：AF3 要解决什么问题

AlphaFold2 的输入是「一个序列」，输出是「一条链」。真实世界的问题则是：给定**蛋白质序列 + DNA/RNA 序列 + 配体 SMILES + 金属离子**，预测它们结合后的**联合三维结构**。这带来两个新困难：

**异构 token**：残基是「一整块」原子，配体的每个重原子却需要独立建模，核酸介于两者之间。一个统一的模型要能同时表达「残基层级」与「原子层级」。
**非键相互作用**：复合物的功能由氢键、盐桥、π 堆积、疏水接触等**非键作用**主导，这些相互作用没有共价键「兜底」，预测错了就是整体错位。

AF3 的答案是**统一 token 化**：把每个蛋白质残基、每个核苷酸、配体的每个重原子都映射为「token」，token 再展开成它覆盖的原子集合。由此，整个复合物变成一个「token 序列 + 原子图」的联合体，模型在这个统一表示上做推理。<span class="marginnote">token 化粒度是有意设计的：残基/核苷酸用「残基级 token」（每个 token 覆盖多个原子），配体用「原子级 token」（每个重原子一个 token）。这样既控制序列长度（配体原子数通常 ≤ 几十），又保留原子级精度。</span>

## 2 Pairformer 与三角乘法：轻量化的成对表示

AF3 的骨干网络是 **Pairformer**——Evoformer 的精简版，处理核心仍是**成对表示** $z_{ij}$。它去掉了 Evoformer 里 MSA 表示的整条通道，但保留了三角更新中最核心的部分：

**三角乘法更新（triangle multiplication）**：保留——边 $(i,j)$ 经第三 token $k$ 的消息传递，保证成对表示的几何一致性。
**三角注意力（triangle attention）**：移除——为节省计算。
**逐行/逐列注意力与转移**：保留，处理「残基特征 → 成对表示」与「成对表示 → 残基特征」的双向流动。

**重点：AF3 在「信息抽取」上比 AF2 更省，在「坐标生成」上比 AF2 更费。** 这一加一减透露了设计哲学——进化的共进化信号（MSA）被降级为可选输入，模型更依赖**训练数据本身的多样性**与**扩散生成的力量**来产出结构。<span class="marginnote">Pairformer 的提速对 AF3 至关重要：复合物预测要处理的 token 数与原子数远大于单链蛋白，若沿用 48 层 Evoformer，训练与推理成本将不可承受。速度上的松绑，换来了原子级生成的空间。</span>

## 3 公式解析：结构扩散的训练目标

AF3 的结构预测头是一个**扩散模型**。训练时，给定真实结构 $x_0$，前向过程逐步添加高斯噪声；模型学习「从加噪坐标还原干净坐标」。用一个加噪公式概括：

$$
x_t = \sqrt{\bar{\alpha}_t}\, x_0 + \sqrt{1 - \bar{\alpha}_t}\, \epsilon, \qquad
\epsilon \sim \mathcal{N}(0, I)
$$

- **$x_0$**：真实原子坐标（全体原子拼接成的向量）。
- **$t$**：噪声步，$t=0$ 是干净结构，$t$ 越大噪声越强；$\bar{\alpha}_t$ 是预定义的噪声调度（noise schedule），单调递减地把坐标推向纯噪声。
- **$x_t$**：加噪到第 $t$ 步的坐标，训练时直接采样得到，无需逐步迭代——这是扩散训练「一步到位」的便利。
- **$\epsilon$**：标准高斯噪声，是扩散模型里「随机性」的来源；推理时正是从它出发逐步去噪，因此**每次采样得到略有差异的构象**——这赋予 AF3 天然的多构象采样能力。

模型的训练目标是**预测干净结构 $x_0$**：$\min_\theta \mathbb{E}_{t, x_0, \epsilon}\big[\, w(t)\, \big\lVert \hat{x}_\theta(x_t, c, t) - x_0 \big\rVert^2 \,\big]$，其中 $c$ 是表示网络提供的条件（成对表示、token 特征等），$w(t)$ 是随噪声步的损失权重。<span class="marginnote">「预测 $x_0$ 而非预测噪声 $\epsilon$」是 AF3 相对经典 DDPM 的取舍，在结构域里通常配合对坐标的<strong>平移/旋转对齐</strong>使用——因为坐标本身不定义在规范坐标系里，直接回归 $x_0$ 需要先做姿态对齐。这也与 FAPE 损失的「对齐再比」一脉相承。</span>

**辨析｜易错点：** 扩散不是「加上随机性让结果更花哨」——它把结构预测从「单点回归」变成「分布建模」。AlphaFold2 直接输出一个最可能的坐标，AF3 输出一个**坐标上的分布**，可以采样出多个候选构象。这对配体结合这种「多结合模式」问题至关重要：真实结合不总是唯一的。

## 4 推理采样：从噪声坐标到原子级结构

推理时，扩散模块从随机坐标 $\hat{x}_T \sim \mathcal{N}(0, I)$ 出发，沿训练学到的逆向过程**逐步去噪**：

1. 给定当前坐标 $\hat{x}_t$ 与条件 $c$，网络预测干净结构 $\hat{x}_0 = \hat{x}_\theta(\hat{x}_t, c, t)$。
2. 用预测结果回推 $t-1$ 步的坐标：$\hat{x}_{t-1} = a_t\, \hat{x}_t + b_t\, \hat{x}_0 + \sigma_t\, \epsilon'$（$a_t, b_t, \sigma_t$ 由噪声调度与采样器决定）。
3. 重复若干步（论文用数十步），直到得到 $\hat{x}_0$ 的最终估计。

最终坐标读出每个原子位置，与输入 token 的原子映射对应。<span class="marginnote">采样步数是一个「质量/速度」旋钮：步数越多越接近训练分布、越稳，但更慢。AF3 论文报告在数百采样步内得到可靠结果，AlphaFold Server 则用预设步数换取在线响应速度。</span>

**重点：条件 $c$ 是表示网络的输出，扩散模块本身不做「蛋白质推理」——它只负责「把表示变成坐标」。** 这种「表示学习与坐标生成解耦」的架构，让 AF3 的扩散模块可以换成任何更强的生成器而不动上游，也为后续工作（如 RFdiffusion 用扩散做蛋白质设计）铺平了道路。

## 5 置信度头与性能：一次跨越

AF3 仍保留置信度头，输出 **pLDDT**（每 token）与 **PAE**（每 token 对），延续上一篇的解读框架。但它的性能是一次跨越式提升：

**蛋白-蛋白复合物**：优于 AF2-Multimer 的基准。
**蛋白-核酸复合物**：此前几乎没有专用工具，AF3 显著拉开差距。
**蛋白-小分子配体结合姿态**：在 PoseBusters 等基准上，AF3 的成功率大幅领先对接软件与传统打分函数——这是药物发现最关心的指标。<span class="marginnote">正是这个「配体结合姿态」能力让 AlphaFold Server 迅速成为结构生物学与药物化学社区的标准工具之一。当然，「预测结合姿态」与「预测结合亲和力」仍有距离——这是下下篇《虚拟筛选》的主题。</span>

**辨析｜易错点：** AF3 的精度高，不等于「结合亲和力也能直接读出来」。它能告诉你「配体最可能怎么摆」，但「摆进去之后结合多紧」涉及能量学，扩散模型不直接建模。另一个误区是把 AF3 当「万能对接器」——对高度灵活的构象变化（大段无序区的诱导契合），扩散仍可能给出一个过度自信的单一答案，解读时必须结合置信度。

## 6 进阶辨析：AF3 的「预测姿态」与「药物设计的现实约束」

把 AF3 用于药物发现，要把它「能做什么」与「不能做什么」划得清清楚楚——这是它从「明星模型」变成「可信工具」的关键。

**第一，结合姿态 ≠ 结合亲和力。** AF3 预测「配体最可能怎么摆」——但它不直接给「结合多紧」（ΔG 或 Ki）。一个摆姿完美的配体，可能因为去溶剂化、构象熵等「能量因素」而结合很弱。**「姿态准」与「亲和力强」是两个正交的问题**——AF3 解决前者，亲和力仍需打分函数或自由能计算（本专题《虚拟筛选》一篇）。

**第二，「多构象采样」的正确用法。** AF3 的扩散头能采样出多个候选姿态——**「多个姿态」不全是「合理结合模式」，可能只是「模型的不确定」**。解读时要用「置信度 + 姿态聚类」：多个低置信度且彼此差异大的姿态，说明「模型没把握」，而非「存在多结合模式」。

**第三，诱导契合的盲区。** AF3 通常假设「受体结构固定」（或仅轻度柔化）——真实结合常有「诱导契合」（配体结合引起蛋白构象变化）。**「柔性口袋 + 大构象变化」的场景，AF3 的单一结构预测可能失真**——此时要「多受体构象」（ensemble docking）而非单一预测。

**第四，数据边界。** AF3 的训练数据（PDB 复合物）偏向「高亲和力、易结晶」的复合物——对「弱结合、瞬时复合物、无序区参与的结合」，预测可靠性下降。**「训练数据的覆盖」决定 AF3 的可靠范围**——这与所有科学 ML 的「分布内」原则一致。

把「AF3 在药物设计里的定位」总结成一张检查清单：

| 用途 | 可靠程度 | 注意 |
| --- | --- | --- |
| 蛋白-配体姿态预测 | 高（基准领先） | 结合模式可信，亲和力另算 |
| 蛋白-核酸复合物 | 高（此前无工具） | 核酸构象的柔性要小心 |
| 构象多采样 | 中 | 结合置信度与姿态聚类解读 |
| 诱导契合/大构象变化 | 低 | 需要多构象 + 实验验证 |

**辨析｜易错点：** 别把「AF3 预测的姿态」直接当「对接结果进筛选管线」——AF3 的定位是「复合物结构预测」，不是「高通量对接引擎」。把它用在「少数关键复合物的精细建模」上，比用在「百万分子筛选」上更符合它的设计初衷。

## 7 小结

- **AF3 的问题扩展**：从「单条蛋白链」到「蛋白 + 核酸 + 配体 + 离子」的复合物联合结构预测。
- **统一 token 化**：残基、核苷酸、配体重原子都映射为 token，原子级精度与残基级效率兼得。
- **Pairformer**：精简版 Evoformer，保留三角乘法更新、去掉三角注意力与 MSA 通道，为原子级生成腾出计算预算。
- **扩散头**：$x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon$，模型学习从加噪坐标还原 $x_0$；推理时从噪声采样、逐步去噪，天然支持多构象采样。
- **「表示学习」与「坐标生成」解耦**：表示网络输出条件，扩散模块负责生成。
- **性能跃迁**：蛋白-配体结合姿态等基准大幅领先；置信度头（pLDDT/PAE）保留并沿用。
