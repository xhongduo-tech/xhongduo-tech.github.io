## 为什么从基准与开放问题收尾

本专题从「第四范式」讲到「人机协同」，覆盖了 AI4Science 的各个角落。最后一篇，退到最高的视角，问两个「元问题」：**怎么比较科学 ML 系统（基准），以及还有哪些没解决（开放问题）**。基准决定了「我们以为进步了多少」，开放问题决定了「真正的进步在哪里」——两者一起，刻画了这个领域的「真实坐标」。这一篇讲科学 ML 的基准版图、基准的「信任危机」、评估指标的「欺骗性」，以及我眼中「下一个十年」的开放问题。<span class="marginnote">「本专题的一句话总结」：<strong>AI4Science 的承诺是「把科学的『搜索与验证』交给机器，把『提问与判断』留给人类」——但「机器搜索得好不好」要有尺子，「还有什么搜不动」要有清单</strong>。基准与开放问题，就是这把尺子与这份清单。</span>

## 1 科学 ML 的基准版图

科学 ML 的基准按领域「各自为政」，先画一张地图：

| 领域 | 代表基准 | 测什么 |
| --- | --- | --- |
| 分子性质 | QM9、MoleculeNet | 能量、能隙、活性、溶解度 |
| 材料 | MatBench、Materials Project | 形成能、带隙、弹性 |
| 蛋白质 | CASP（结构预测）、AlphaFold DB | 结构精度 |
| 分子生成 | GuacaMol、ZINC 子集 | 有效性、多样性、性质 |
| PDE 学习 | PDEBench、Darcy/NS 标准测试 | 求解精度、网格不变性 |
| 天气 | ERA5 回算、标准技巧分数 | 预报 RMSE/ACC |
| 单细胞 | 各数据集内部任务 | 注释、批次校正、扰动 |
| 科学 Agent | DiscoveryBench、ScienceQA | 知识、发现过程 |

**特点：领域碎片化、标准不统一**——「每个领域有自己的尺子」，跨领域比较几乎不可能。这与「通用基础模型」的「统一评测」需求存在张力。<span class="marginnote">「基准碎片化的代价」：<strong>「分子上 SOTA」与「材料上 SOTA」可能是「两个完全不同的评测标准下的产物」——无法判断「哪个模型更通用」</strong>。科学基础模型（第十章）的兴起，正在推动「跨领域统一评测」——但「不同领域的『准』怎么换算」仍是未解的度量问题。</span>

## 2 基准的「信任危机」：可复现与可比较

科学 ML 的基准正面临与 LLM 同源的「信任危机」，且叠加「科学特有」的问题：

- **可复现性危机**：论文报告「误差 1%」，复现时常常对不上——**数据切分、训练细节、随机种子、算力版本**都可能造成差异。「科学 ML 论文的可复现率」是领域之耻。
- **比较不公平**：不同论文用不同的「训练数据量、分辨率、验证集、评价指标」——「SOTA」常常是「在我的设置下 SOTA」。
- **基准饱和**：早期基准（QM9 的部分任务）已被刷到接近下界——「刷新纪录」的新闻信息量递减。
- **泄漏**：预训练数据与评测数据重叠——「零样本」实际「见过」。
- **指标单一**：只报「平均误差」，不报「分布内/外」「极端情况」「不确定性校准」——「平均好」掩盖「角落差」。<span class="marginnote">「科学 ML 可复现的『行业规范』」：<strong>公开代码、固定数据版本、明确超参数、报告多次运行的标准差、用标准切分</strong>——这些「常识」在科学 ML 里远未普及。<strong>「可复现是科学的最低要求，不是加分项」</strong>——「一个不能复现的『SOTA』，对科学没有贡献」。</span>

**重点：基准的「比较对象」比「绝对分数」重要**——「AI 模型 vs 传统方法（在公平设置下）」的对比，比「AI 模型 A vs AI 模型 B」更能说明「AI 有没有用」。**「对传统基线公平」是科学 ML 基准的第一纪律**。

## 3 公式解析：评估指标的「欺骗性」

科学 ML 的常用指标（相对误差、RMSE、准确率）会「骗人」——用一个小例子说明。设真解为 $u$，模型预测为 $\hat{u}$，相对误差：

$$
\mathrm{RelErr} = \frac{\lVert \hat{u} - u \rVert}{\lVert u \rVert}
$$

**相对误差的三宗罪**：

1. **被「大分量」主导**：若 $u$ 的大部分区域「值很大」（如高温区），误差集中在「值小的区域」（低温区）会被「平均掉」——**「平均好」可能「关键处差」**（天气预报里「平均 RMSE 好」但「极端暴雨差」）。
2. **对「零值区域」失灵**：$u \approx 0$ 处，分母趋零，相对误差爆炸——**「相对误差」在物理场「过零」时无意义**。
3. **不区分「分布内外」**：一个「外推区全错」的模型，只要「分布内几乎全对」，平均相对误差仍然好看——**「平均指标」掩盖「外推崩溃」**。

**更诚实的指标**：分区域的误差（分布内/外分别报）、极端值误差（P95/P99 误差）、物理一致性误差（守恒破缺量）、不确定性校准（ECE）。<span class="marginnote">「指标选择的科学意义」：<strong>「怎么度量」决定「怎么优化」——「只优化平均 RMSE」的模型，天然会「牺牲极端、照顾平均」</strong>——这对天气、材料、医学这类「极端事件最要紧」的领域是灾难。「指标设计」本身就是「价值观」——<strong>「你奖励什么，模型就擅长什么」</strong>，这在本专题《AI 科研助手评测》一章已反复强调。</span>

## 4 开放问题：十个未解之题

把本专题的「未竟之事」收束成一份清单，是这一篇最重要的部分：

1. **外推与泛化**：模型在训练分布外的可靠性——「预报新天气、新材料、新参数」仍是最大短板（没有通用解法）。
2. **长期稳定性**：自回归/滚动预测的误差累积——「单步准 ≠ 滚得稳」（本专题流体、天气、扩散都撞上它）。
3. **物理一致性保证**：「守恒、价键、无散」的「硬保证」——目前多是「软约束」（损失惩罚），「结构保证」只在少数架构（HNN、等变）里实现。
4. **不确定性量化**：可靠、校准、可用的 UQ——「知道准不准」尚未成为科学 ML 的标配。
5. **数据效率**：科学数据昂贵——「少量标注 + 强先验 + 主动学习」还远未成熟。
6. **科学基础模型的「规模化收益」**：缩放定律在科学里「打折」——「更大是否真的更好」尚无定论。
7. **可复现性**：论文可复现率低——「科学 ML 自身还不是科学」。
8. **发现型基准**：怎么测「新知识」——「发现」的自动评价仍是开放难题。
9. **多物理场与多尺度**：真实工程的「多场耦合 + 多尺度」——「单场玩具」到「真实世界」的鸿沟。
10. **伦理与责任**：AI 参与科研的「署名、责任、信任」——科学共同体尚未形成新规范。<span class="marginnote">「开放问题排序的『优先级』」：<strong>「外推、长期稳定、物理一致性」是『技术硬骨头』，「可复现、基准、伦理」是『共同体软问题』——两者都卡着领域的成熟</strong>。有意思的是，纯「规模」不在最前列——「科学 ML 的瓶颈更多在『结构与信任』，而非『算力』」——这与 LLM「堆规模就有进步」的路径显著不同。</span>

## 5 从「预测」到「发现」：下一个十年

最后，给一个「方向性的判断」——科学 ML 的下一个十年，主线是从「预测」走向「发现」：

**第一个十年（已走过的）**：**「预测」**——「给定结构预测性质、给定初始场预报天气、给定序列预测结构」——「把已知规律（或学到的规律）应用到新实例」。成熟度高。

**下一个十年（正在展开）**：**「发现」**——「从数据发现新规律、设计新分子/材料/蛋白、自动提出并验证假设」——「创造未知」。GNoME 的候选晶体、FunSearch 的程序、AlphaGeometry 的构造——都是「发现」的早期形态。

**「发现」比「预测」难在哪**：预测有「标准答案」可验证，发现没有——「新颖性」无自动判据、「价值」无客观度量。**「发现型科学 ML」的成熟，需要「发现型基准 + 发现型评价 + 人机协同流程」三者同步推进**——这正是本专题最后几篇（评测、人机协同）的交汇点。<span class="marginnote">「『预测 → 发现』的隐喻」：<strong>「预测」是「把书读得更快」（理解已知规律、应用更快），「发现」是「写出新的一页」（创造未知规律）</strong>——AlphaFold 是「读得快」（预测已存在的折叠），GNoME 是「写新页」（发现新晶体）。「下一个十年的分水岭，在于科学 ML 能否从『重读』走向『书写』」——而「书写」需要人机协同（AI 搜索 + 人判断）来共同完成。</span>

## 6 进阶辨析：科学 ML 的「可复现规范」与「诚实报告清单」

把「可复现」从口号变成纪律，科学 ML 需要一套「报告清单」——以及一种「自我设限」的诚实文化。

**可复现规范一：固定「数据版本 + 切分」。** 报告要写明「数据集的精确版本、训练/验证/测试的切分方式（随机 or 按结构聚类）、切分种子」——**「不报切分的『SOTA』，是半个 SOTA」**。「按相似性聚类切分」要优于「随机切分」（防泄漏）——「切分方式本身就是研究贡献」。

**可复现规范二：报告「多次运行」而非「单次最好」。** 深度学习有随机性——**「报『最好的一次』是挑，报『均值 ± 标准差』是科学」**——「多次独立运行（不同种子）的均值与方差，才能说明『这个方法真这么强』」。

**可复现规范三：基线要「公平调优」。** 「我们的方法 1.0，基线 0.8」——这个对比有意义的前提是「基线也被调到了它的最佳」——**「用一个没调好的基线衬托自己，是科学 ML 最常见的『礼貌性作弊』」**。「报告基线的最佳配置」与「报告自己的最佳配置」同样重要。

**诚实报告清单（一份可复用的模板）**：

1. 数据版本、来源、切分方式与种子。
2. 训练的超参数、随机种子、算力环境。
3. 多次运行的均值 ± 标准差（而非单次最好）。
4. 与「调优后的最强基线」的公平对比。
5. 误差的分解（分布内/外、极端值、不确定性校准）。
6. 失败案例与已知局限（不只报成功）。

把「规范 + 清单」合起来，就是科学 ML 的「体面」：**「可复现不是『加分项』，是『最低要求』；诚实报告不是『自我贬低』，是『职业尊严』」**。

**辨析｜易错点：** 别把「论文的『我们超越 SOTA』」当「事实」——「超越 SOTA」的声明需要「上述清单」支撑，否则「只是一个声称」。**「读到『超越 SOTA』时，先看清单，再决定信不信」**——「清单齐全的可复现 SOTA」，才配叫 SOTA。

## 7 小结

- **基准版图**：分子/材料/蛋白/PDE/天气/单细胞各领域「各自为政」——「领域碎片化、标准不统一」。
- **信任危机**：可复现率低、比较不公平、基准饱和、泄漏、指标单一——「可复现是科学的最低要求」。
- **指标的欺骗性**：相对误差被大分量主导、零值失灵、不区分分布内外——「你奖励什么，模型就擅长什么」。
- **十个开放问题**：外推、长期稳定、物理一致性、UQ、数据效率、规模化收益、可复现、发现型基准、多物理场、伦理——「结构与信任」的瓶颈大于「算力」。
- **下一个十年**：从「预测」（重读已知）走向「发现」（书写未知）——需要「发现型基准 + 发现型评价 + 人机协同」同步推进。
- **本专题的收束**：AI4Science 的承诺——「搜索与验证交给机器，提问与判断留给人类」——是贯穿「从极限到大模型」这条路的指南针。
