## 为什么从 ADMET 开始

上一篇文章聊「分子与靶点结合多紧」。但临床失败的教训残酷地说明：**活性只是第一步，大多数候选药死在 ADMET 上**——吸收不好、代谢太快、毒性太高。业界常引用的统计是：约三分之一的临床失败归因于药代动力学与毒性问题。于是有了一个朴素的工程目标：**在合成与实验之前，就预测「这个分子进了人体会怎样」**——这就是 ADMET 预测，也是 AI 在药物发现里「最省钱」的环节之一。<span class="marginnote">ADMET 五个字母对应五个维度：<strong>A</strong>bsorption（吸收）、<strong>D</strong>istribution（分布）、<strong>M</strong>etabolism（代谢）、<strong>E</strong>xcretion（排泄）、<strong>T</strong>oxicity（毒性）。它把「体外活性」与「体内有效」之间的鸿沟，拆成了一个个可计算的端点。</span>

这一篇讲清楚：类药性规则（Lipinski 五规则）的来龙去脉、五大端点的具体内涵、ADMET 数据的特殊性，以及机器学习（尤其多任务 GNN）在其中的应用与陷阱。读完你会明白，为什么 ADMET 是「预测」但更是「工程」——数据的稀缺与异质比模型本身更决定成败。

## 1 成药性的瓶颈：药物为什么在人体里失败

一个候选分子的命运大致经过：体外活性（hit → lead）→ 动物实验 → 人体临床试验。每次升级都是一道过滤器，而过滤条件里，**活性之外的性质占据半壁江山**：

**吸收不足**：口服药要穿过肠道上皮进入血液。溶解度过低、通透性差 → 生物利用度低。
**代谢过快**：肝脏的 CYP 酶把药物分解得太快 → 半衰期短、疗效不足。
**毒性**：hERG 通道阻断（心律失常）、肝脏损伤、基因毒性（Ames）→ 直接判死刑。
**分布与排泄**：血浆蛋白结合过高（有效浓度低）、清除率异常。

**重点：ADMET 是「多终点」问题。** 一个分子必须同时通过多个性质的关卡才算成药——这不同于活性预测的「一个分数定高低」。这也解释了为什么 ADMET 预测天然适合**多任务学习**：多个相关的性质端点共享表征，相互借力。<span class="marginnote">「fail early, fail cheap」是药物发现的座右铭：越早筛掉注定失败的候选，成本越低。ADMET 预测就是把「临床失败」的判决提前到「合成之前」——这也是它商业价值极高的原因。</span>

## 2 类药性规则：Lipinski 五规则及其局限

1997 年，Christopher Lipinski 统计了大量进入临床的候选药，提出著名的 **Lipinski 五规则（Rule of Five）**——口服吸收良好的药物，通常满足：

| 性质 | 阈值 | 直觉 |
| --- | --- | --- |
| 分子量 MW | ≤ 500 | 太大难跨膜 |
| logP（亲脂性） | ≤ 5 | 太亲脂难溶、易被代谢 |
| 氢键供体 | ≤ 5 | 太多极性太大 |
| 氢键受体 | ≤ 10 | 同上 |

后来 Veber 等补充：可旋转键 ≤ 10、TPSA ≤ 140 Å²。这些「经验法则」简单、可解释，至今仍是筛选管线的第一道闸。<span class="marginnote">「五规则」是典型的「描述符 + 阈值」模型——它是机器学习时代之前最成功的「性质预测器」。它的成功证明了：<strong>可解释的简单规则有时比黑箱更耐用</strong>。但它只是「启发式」，不是「物理定律」。</span>

**辨析｜易错点：** 五规则**不是硬性排除标准**——大量上市药物违反其中一条或多条（如部分抗生素、天然产物）。它的本意是「风险提示」：违反越多，口服成药风险越高，但不是不可能。另一个误区是把 logP 当作「越接近 0 越好」——**亲脂性过低也会损害透膜与靶点结合**，理想的 logP 有合适区间，而非单调。规则的价值在于「快速粗筛」，精筛必须回到定量预测。

## 3 ADMET 五大端点：要预测什么

ADMET 的预测端点（endpoint）可以罗列成一张实用的地图：

| 维度 | 代表端点 | 数据类型 |
| --- | --- | --- |
| 吸收 | 水溶性（logS）、Caco-2 通透性、人肠道吸收 | 回归 / 分类 |
| 分布 | 血浆蛋白结合率、血脑屏障穿透、分布容积 | 回归 / 分类 |
| 代谢 | CYP3A4/2D6 抑制或底物、清除率、半衰期 | 分类 / 回归 |
| 排泄 | 肾清除率 | 回归 |
| 毒性 | hERG 阻断、Ames 致突变、肝毒性、急性毒性 LD50 | 分类 / 回归 |

数据来源混杂：一部分是公开的体外实验（Tox21、PubChem 的 bioassay），一部分是文献整理的私有数据库，还有少量临床数据。**每个端点的样本量、标签噪声、正负比例都不同**——这是 ADMET 建模最棘手的现实。<span class="marginnote">Therapeutics Data Commons（TDC）把 ADMET 端点标准化成公开基准，极大推动了可复现研究。它同时提供了「按 scaffold 划分」的数据切分——防止模型靠记忆相似结构刷分，这在 ADMET 评测里是生死攸关的细节。</span>

## 4 公式解析：多任务加权的分类损失

ADMET 预测的主流模型是「分子表征（指纹或 GNN 嵌入）+ 多任务分类头」。训练目标是一个**带类别加权的多任务交叉熵**：

$$
\mathcal{L} = \frac{1}{T}\sum_{t=1}^{T} \Bigg[ -\frac{1}{N_t} \sum_{i=1}^{N_t} \Big( w_{+}^{t}\, y_i^{t} \log \hat{y}_i^{t} \;+\; w_{-}^{t}\, (1 - y_i^{t}) \log (1 - \hat{y}_i^{t}) \Big) \Bigg]
$$

- **$T$ 个任务，$N_t$ 个样本**：第 $t$ 个端点（如 hERG）有自己的标签集 $y_i^t \in \{0,1\}$。多任务让所有端点共享分子嵌入——**一个端点学到的化学，帮助另一个端点**。
- **$w_+^t, w_-^t$ 是类别权重**：ADMET 端点通常正负例极不平衡（如肝毒性阳性样本稀少）。权重平衡了两类的梯度贡献，防止模型「全都预测为阴性」的偷懒解。
- **$\log \hat{y}_i^t$ 是交叉熵**：预测概率 $\hat{y}_i^t$（来自 sigmoid 输出）越偏离真实标签，惩罚越大。<span class="marginnote">为什么要多任务而不是单任务拼装？因为 ADMET 端点之间<strong>高度相关</strong>（如 CYP 抑制与代谢清除、亲脂性与毒性都有耦合），共享表征能学出跨端点的通用化学表示，在样本稀缺时尤其关键。经验上，多任务在中小数据集上常显著优于单任务。</span>

**辨析｜易错点：** 多任务不是免费午餐——若某个端点与其余任务分布冲突，可能拖累整体。另一个常见错误是**把类别权重当万能药**：权重只能缓解不平衡，不能治愈「阳性样本太少以至于信号本身不存在」的数据缺陷。极端不平衡下，「召回率优先」的任务要换评价指标（AUC-PR 而非 ACC）并接受低绝对准确率。

## 5 数据、模型与陷阱：ADMET 预测的工程现实

ADMET 模型的性能天花板主要由**数据**决定，而非模型。三个结构性事实：

1. **端点异质**：体外 assay 与体内行为差距大——模型预测的是「assay 结果」，不是「人体效果」。Caco-2 通透性 ≠ 人体吸收。
2. **标签噪声**：不同实验室、不同实验方案测同一端点，结果常不一致；把噪声当真相训练，模型自然学出噪声。
3. **分布外风险**：训练数据（已知化合物）与真实待筛分子（新骨架）差异越大，预测越不可靠——**AI 再强，也填不平化学空间的鸿沟**。<span class="marginnote">ADMET 预测的「软肋」在于：它不是纯物理问题。CYP 抑制涉及酶动力学，肝毒性机制复杂、个体差异大——<strong>模型只能学到「统计关联」，学到不「因果机制」</strong>。理解这一点，就不会把 ADMET 分数当判决书。</span>

工程上的应对之道：

**严格数据切分**：按骨架（scaffold）而非随机划分训练/测试，防止相似结构泄漏。
**多模型集成 + 不确定性**：多个模型投票，输出置信区间——低置信度的分子宁可多花实验费，也不要冒险放行。
**规则 + 模型混合**：先过 Lipinski/Veber 快速过滤，再上 GNN 精排，最后人工复核——人机协同，而不是模型独断。<span class="marginnote">在真实管线里，ADMET 分数通常用作<strong>排序信号</strong>而非硬闸门：把「预测很差的」标记出来、把「预测好的」优先推进。这种「软约束」比「硬过滤」更稳健，因为它承认了预测的不确定性。</span>

## 6 进阶辨析：ADMET 预测的「数据工程」与「决策整合」

把 ADMET 预测送进「真实决策」，两块内容决定成败：**数据工程**（模型之外的功夫）与**决策整合**（从分数到行动的桥梁）。

**数据工程一：端点数据的「清洗与对齐」。** ADMET 端点来自不同实验室、不同 assay 形式——**「同一个端点的数据，测量单位、实验条件、cutoff 定义都可能不同」**——「直接拼用」会学出「assay 差异」而非「化学规律」。「数据清洗（单位统一、批次校正、离群处理）」是 ADMET 建模的第一工作量。

**数据工程二：缺失与不平衡的「策略」。** 端点数据「缺失严重」（不是每个分子测了所有端点）——「直接丢弃缺失样本」浪费数据，「补全缺失」引入噪声。**「多任务 + 掩码缺失」是主流策略**（每个端点只在有标签的样本上算损失）——「让模型从『部分标注』里学习，而不是丢掉」。

**数据工程三：时间维度的「防泄漏」。** ADMET 数据有「时间戳」（发表的年份）——**「用『未来数据』训练、『过去数据』测试」是泄漏**——「真实场景是『用过去预测未来』」——「按时间切分」比「随机切分」更接近部署现实。

**决策整合一：从「分数」到「风险等级」。** 原始分数（如 hERG 的 IC50）要转成「决策可用」的等级——「绿色（安全）、黄色（需关注）、红色（高风险）」——**「把连续分数离散成风险等级，是让决策者能用的关键翻译」**——「别让决策者读『IC50 = 3.2 μM』，让他们读『这条红线（高风险）』」。

**决策整合二：与「化合物设计的闭环」。** ADMET 预测的价值不在「评估」，在「指导」——「哪些位置改一下能改善溶解度、哪个官能团是 hERG 风险来源」——**「可解释的 ADMET（归因到结构片段）」让预测从『打分』变成『设计建议』**——「从『这个分子不行』到『这里改一改就行』，是 ADMET AI 的增值路径」。

**决策整合三：不确定性进入决策。** 「低置信的预测」不该与「高置信的预测」同权——**「预测置信度要影响决策权重」**——「对低置信端点，宁可用『更保守』的判断，或多做实验」。**「不确定性校准让 ADMET 从『敢说』变成『知道什么该说』」**——与《可靠性》一章完全一致。

把「数据工程 + 决策整合」合起来，就是 ADMET 预测的「生产级」：**「清洗对齐的数据 + 掩码多任务 + 时间切分 + 风险等级 + 可解释设计建议 + 不确定性权重」**——「ADMET 不是『一个模型』，是『从数据到决策的一条管道』」。

**辨析｜易错点：** 别把「ADMET 预测通过」当「药物安全」——ADMET 预测的是「体外端点」，真实安全还依赖「体内、长期、人群」的层层考验。「预测通过」只是「安全评估的一个证据」，不是「安全的保证」。

## 7 小结

- **ADMET** 五维度（吸收/分布/代谢/排泄/毒性）是临床失败的主因之一，预测它 = 把失败提前到合成之前。
- **Lipinski 五规则**（MW ≤ 500、logP ≤ 5、供体 ≤ 5、受体 ≤ 10）是经验粗筛，违反可容忍但风险升高，不是硬排除。
- **端点地图**：logS、Caco-2、CYP 抑制、hERG、Ames、肝毒性等，数据量、噪声、类别比例各不相同。
- **多任务加权 BCE** 是主流目标：$w_+/w_-$ 平衡不平衡端点，共享表征跨端点借力。
- **天花板在数据**：端点异质、标签噪声、分布外风险是三大陷阱；严格切分、集成、不确定性输出是工程应对。
- ADMET 预测学的是**统计关联**而非因果机制——当排序信号用，不当判决书用。
