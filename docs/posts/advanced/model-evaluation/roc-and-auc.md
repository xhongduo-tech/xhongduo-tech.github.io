## 为什么从 ROC 开始

上一节我们处理「分数可不可信」，这一节处理「分数长什么样」。分类器输出的往往不是硬标签，而是一个**得分**（概率、置信度），我们要选一个**阈值**把它切成两类。问题来了：阈值选 0.3 还是 0.7，结果天差地别——阈值选低了，多抓（可能多错）；选高了，少错（可能少抓）。**ROC 曲线的天才之处，是把所有阈值下的表现一口气画成一条曲线，评价时完全不用管阈值怎么定**。它在医学诊断里长盛不衰，如今是 Kaggle 与论文报告的二分类标配。<span class="marginnote">本篇对标 ESL §4.4.5（Logistic regression 一节讨论分类评估）与 Murphy §4.6（Model evaluation in classification）。ROC 的「发明」公认归功于二战时期的信号检测研究——雷达操作员在噪声里判断有没有敌机，正是「真正率 vs 假正率」的原始舞台。</span>

## 1 混淆矩阵：四类错误的账本

把「预测」与「真实」两两配对，二分类只有四种结局，这就是**混淆矩阵（confusion matrix）**：真正例 TP、假正例 FP、假负例 FN、真负例 TN。<span class="marginnote">命名容易绕晕，一个助记：第二个字母是「预测对不对」——P/N 表示预测为正/负，第一个字母 T/F 表示这个预测「对不对」。TP = 预测正且对了，FP = 预测正但错了（虚报），FN = 预测负但错了（漏报），TN = 预测负且对了。</span>

由这四格可以派生出一族比率，其中两对最重要：

$$
\text{TPR} = \frac{TP}{TP + FN} \;(\text{真正率，召回率}), \qquad
\text{FPR} = \frac{FP}{FP + TN} \;(\text{假正率})
$$

**真正率（TPR / recall / sensitivity）**：真实为正的样本里，被我们抓住的比例；**假正率（FPR）**：真实为负的样本里，被我们误判为正的比例。抓得越多，越容易误伤——TPR 与 FPR 总是此消彼长，ROC 就是这两兄弟打架的全程录像。

## 2 ROC 曲线：阈值扫过全场

**ROC 曲线（Receiver Operating Characteristic curve）**：横轴是 FPR，纵轴是 TPR。对得分排序后，把阈值从最高扫到最低，每个阈值在图上点一个点 $(FPR, TPR)$，连起来就是 ROC 曲线：

- 阈值极高：谁都不判正 → $TPR = 0, FPR = 0$，曲线从原点出发；
- 阈值极低：谁都判正 → $TPR = 1, FPR = 1$，曲线止于右上角；
- 随机猜：无论阈值怎么扫，TPR ≈ FPR，曲线贴着**对角线**。

于是曲线越「拱」向左上角，模型越好——左上角意味着「用很小的误伤代价换到很高的抓获率」。

![ROC 曲线与 AUC：曲线越拱向左上角越好，对角线上方是随机基线](/images/model-evaluation/roc-and-auc-1.svg)

**重点：ROC 曲线是「阈值无关」的**——它把不同阈值下的权衡全部摊开，你选哪个阈值，只决定曲线上取哪个点，不改变曲线本身。这就是它比「挑一个阈值报一组准确率」高明的地方。

## 3 公式解析：AUC 的双重身份

**AUC（Area Under the ROC Curve）** 是 ROC 曲线下的面积，一个数概括整条曲线。它有两个等价的解读，一个几何、一个排序：

$$
\mathrm{AUC} = \int_0^1 \mathrm{TPR}(t)\, d\,\mathrm{FPR}(t)
= P\left(s(x^+) > s(x^-)\right)
$$

- **第一行，几何解读**：曲线下的面积。随机分类器是 0.5（三角形面积的一半），完美分类器是 1，所以 AUC 落在 $[0.5, 1]$。
- **第二行，排序解读**：随机取一个正样本 $x^+$ 和一个负样本 $x^-$，模型给正样本**更高得分**的概率。这被称为 **Wilcoxon-Mann-Whitney 统计量**——它只用**相对排序**，不关心得分的绝对大小。

第二行的解读极其有用：AUC 其实**不用画曲线就能算**——把得分排序，数一数「正样本排在负样本前面」的比例。它还揭示了 AUC 的本质属性：**AUC 度量的是排序质量，不是校准质量**。一个把所有得分都压到 [0.3, 0.4] 但排序完全正确的模型，AUC 照样是 1——所以工程上要概率校准（calibration），得另看可靠性图（reliability diagram）。<span class="marginnote">这也解释了为什么 AUC 对类别不平衡相对稳健：它只关心正负样本的排序，正样本只有 1% 时，排序关系依然成立，AUC 不会像准确率那样被「全猜负」的简单策略骗走。</span>

## 4 辨析：AUC 的隐藏陷阱

**辨析｜易错点：** AUC 是一个「平均表现」，它用一条曲线遮蔽了三个细节：

**正负样本比例极悬殊时，AUC 依然偏乐观**。负样本占 99% 时，FPR 的微小上升就是几千个误报；AUC 把「误伤大量负样本」摊薄在横轴上，看起来仍很美。此时改看 **PR 曲线（precision-recall）**更贴合业务：PR 曲线对正类占比敏感，类别越不平衡，它的形状越诚实。<span class="marginnote">经验法则：正类占比 < 5% 时，优先 PR 曲线；正类占比接近平衡时，两者结论基本一致。医疗筛查、欺诈检测、推荐冷启动都是 PR 的天下。</span>
- **AUC 对不同阈值段的敏感度不同**。两个模型 AUC 相同，一个在低 FPR 段更强（适合「宁缺毋滥」的筛查），另一个在高 TPR 段更强（适合「一个不漏」的排查）。报 AUC 前先想清楚业务要的是曲线哪一段。
- **AUC 是二分类指标，多分类要拆成一对其余（one-vs-rest）分别画，再取平均（macro）**，且每一对的类不均衡程度不同，直接比意义有限。

还有一条工程铁律：**画 ROC 之前，先把特征构造、缺失值填充等一切「看到测试集信息」的步骤排除干净**——否则得到的不是评估，是数据泄漏（详见本专题末篇《数据泄漏与评估陷阱》）。ROC 再漂亮，泄漏的数据算出来的也是幻觉。

## 5 小结

- **混淆矩阵**把二分类结果记成 TP/FP/FN/TN 四格，派生出的 **TPR**（真抓率）与 **FPR**（误伤率）是 ROC 的两轴。
- **ROC 曲线**扫过全部阈值，是「阈值无关」的综合评估；越拱向**左上角**越好，**对角线**是随机基线。
- **AUC** 是曲线下面积，等价于「随机正样本得分高于随机负样本」的概率（Wilcoxon-Mann-Whitney），本质度量**排序质量**而非校准质量。
- 辨析：类别**极不平衡**、关心低 FPR 段、或多分类时，AUC 会失真，须改用 **PR 曲线**、分段审视或 one-vs-rest。

在下一节，我们将不再满足于「不分轻重地计数」，而是把「每种错误值多少钱」摆上桌面——这就是**代价敏感学习与混淆矩阵**。
