## 为什么从机器学习开始

本专题一路走来有一个贯穿性瓶颈：**筛选很贵**。每轮定向进化都要真金白银地测几千几万个变体。这一课回答：能不能让计算机「预知」哪些序列值得测，从而把筛选预算花在刀刃上？**机器学习指导的定向进化（machine-learning-assisted directed evolution, MLDE）**做的事正是如此——先用一轮小规模实验训练一个「序列 → 功能」的预测模型，再用模型在大得多的虚拟序列空间里挑选下一轮该测的候选。它是本专题与「从极限到大模型」主线最直接的交汇点：**蛋白质也是一串 token，语言模型的思路可以原样搬过来**。<span class="marginnote">MLDE 的吸引力来自一个反直觉的事实：实验测 1000 个变体，只能知道 1000 个点；但如果用这 1000 个点训练一个模型，模型能对 $10^6$–$10^8$ 个未测序列给出预测，且「挑选策略」比「随便抽」高效得多。进化从「物理筛选」升级成「先虚拟搜索，再定向验证」。</span>

## 1 MLDE 循环：训练、预测、挑选

MLDE 不是抛弃定向进化，而是给达尔文循环装一个「大脑」。标准循环四步：

1. **小规模起步**：随机或按结构挑几十到几百个变体，实验测定其功能（作为训练数据）。
2. **训练模型**：学「序列 → 功能」的映射（回归问题）。
3. **虚拟筛选**：对候选序列空间（如所有单/双突变组合）用模型打分。
4. **主动挑选**：按「预测价值 + 不确定性」选出下一批要实验测的序列，测定后**把新数据加进训练集，再循环**。

关键区别在「挑选」这一步。纯进化是「测什么全凭随机/直觉」，MLDE 是**主动学习（active learning）**：每一轮都选「最有信息量」的序列去测，让模型越学越准。<span class="marginnote">主动学习把「探索（exploration，测不确定性高的区域）与利用（exploitation，测预测性能最好的区域）」的权衡变成了算法问题——这是贝叶斯优化的标准味道（参见《优化》与《贝叶斯统计》的采集函数）。当模型不确定性和性能预测都进决策时，搜索效率显著优于纯随机。</span>

## 2 序列怎么进模型：编码与模型家族

「序列」是文本，机器要的是向量。编码方式构成一个谱系：

**独热（one-hot）**：每个位置 20 维。简单但丢了「氨基酸相似性」——丙氨酸与缬氨酸在编码上毫无关系。
- **理化特征**：每个残基换成疏水性、体积、带电等性质向量。保留相似性，但依赖人工特征工程。
- **进化信息/嵌入（embeddings）**：用大量序列训练的**蛋白质语言模型**（如 ESM 系）把序列编码成稠密向量——模型从无标注序列里学会了「哪些位置在进化上相关」。这是目前最强的通用编码。<span class="marginnote">蛋白质语言模型与 ChatGPT 系语言模型同源：在大量序列上做掩码预测，学会序列的统计规律。ESM 等模型还提供「预测突变效应」的零样本（zero-shot）能力——不需要你的实验数据，单靠序列进化模式就能排名突变。它与《深度学习》《NLP》课程的词向量思想一脉相承：表示即一切。</span>

模型家族同样有谱系：**高斯过程（Gaussian process）**在数据少时给「均值 + 方差」双输出（方差即不确定性，天然适合主动学习）；**随机森林**稳健好调；**深度神经网络 / Transformer** 数据量大时更强，能学到非线性与上位效应。

## 3 公式解析：高斯过程与采集函数

MLDE 里最优雅的一族模型是高斯过程回归。它假设「序列越相似，功能越相关」，输出每个候选的两个量：预测均值 $\mu(s)$ 与预测方差 $\sigma^2(s)$：

$$
\mu(s) = k(s, S)^\top (K + \sigma_n^2 I)^{-1} \mathbf{y}, \qquad \sigma^2(s) = k(s,s) - k(s,S)^\top (K + \sigma_n^2 I)^{-1} k(s,S)
$$

不必逐项背，三步抓住直觉：

- **第一步，预测 = 数据加权**：$\mu(s)$ 是「已知样本功能 $\mathbf{y}$」按「与候选 $s$ 的相似度 $k(s, S)$」加权求和——**离已知点越近的序列，预测越贴近已知值**。$k$ 是核函数（如序列编辑距离核）。
- **第二步，不确定性 = 没被数据覆盖的程度**：$\sigma^2(s)$ 反映「$s$ 离所有已测点有多远」。已经测过的地方不确定性小，没测过的区域不确定性大——**方差就是模型的「无知程度」**。
- **第三步，采集函数把两者合成**：选下一批时打分 $U(s) = \mu(s) + \beta\,\sigma(s)$（上置信界 UCB，$\beta$ 权衡探索/利用）或期望改进 EI。于是「该测哪个」变成「预测好 + 拿不准」的加权——**这就是主动学习的数学心脏**。

**辨析｜易错点：** MLDE 最容易翻车的三个地方。其一，**训练/预测分布漂移**：模型在「训练数据附近的序列」上可靠，拿去预测「远处的高突变序列」就纯属外推——所以好流程都限制在单/双突变邻域内迭代。其二，**模型只是代理**：它学的是「已测过的定义下的功能」，若实验指标有噪声或有偏，模型会忠实地放大噪声。其三，**数据量门槛**：Transformer 类大模型在小数据下过拟合严重，通常几十到几百个样本时高斯过程/随机森林反而更好——「模型复杂度要配数据量」。

## 4 应用与收益：虚拟空间里的效率跃升

MLDE 最成功的几个方向：

- **荧光蛋白**：Wu 等用「高通量测序 + 模型」优化绿色荧光蛋白，在仅仅三轮、每轮约 100 个候选的实验下，就追平甚至超过此前基于海量文库筛出的最优变体——**用模型的「虚拟搜索」替掉了「物理大海捞针」**。
- **酶热稳定性与活性**：以单个数据生成批次训练高斯过程/随机森林，预测稳定性或活性排名，指导后续突变组合，常见报道是「以少 10–100 倍的实验量达成同等提升」。
- **抗体亲和力成熟**：结合噬菌体/酵母展示的测序数据，模型挑「可能更亲和」的突变组合，压缩亲和力成熟轮次。<span class="marginnote">这些案例共享同一个信号：<strong>当「筛到好变体」的瓶颈从「文库大」变成「测得起」，MLDE 就把预算从「碰运气」变成「定向」</strong>。工业界的吸引力还在于：每次实验测出的数据都沉淀为模型资产，下一轮进化不从头开始。</span>

把 MLDE 放回本专题的坐标系：它是「达尔文循环」的加速器，不改变进化逻辑，只改变「多样性如何被利用」。它也不是计算设计的替代品——上一课 Rosetta 从结构出发，这一课从数据出发，两者在《从头设计》一课将由语言模型与扩散模型合流。

## 5 小结

- MLDE = 用小规模实验数据训练「序列→功能」模型，再让模型**虚拟筛选 + 主动挑样**，把进化从物理筛选升级为「先算后测」。
- 序列编码谱系：独热 → 理化特征 → **蛋白质语言模型嵌入**；模型谱系：高斯过程（带不确定性）→ 随机森林 → Transformer。
- 高斯过程的核心公式 $\mu(s)$、$\sigma^2(s)$：**预测=按相似度加权，不确定性=离数据点有多远**；采集函数 $U = \mu + \beta\sigma$ 把探索与利用合成决策。
- 三大陷阱：分布漂移（别外推到远突变）、代理有偏（模型放大实验噪声）、模型复杂度要配数据量。
- 收益模式：以少 10–100 倍实验量达成同等或更优提升；数据沉淀为可复用资产。

在最后一节，我们把所有线索收拢到「创造」的极限：**从头设计蛋白质**——不靠天然序列、不靠随机突变，直接设计一条自然界从未存在过的、却能折叠成预定结构的序列。
