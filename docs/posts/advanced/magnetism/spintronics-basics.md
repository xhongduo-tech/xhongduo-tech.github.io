# 自旋电子学基础

<div class="epigraph">

## 为什么从自旋电子学开始

传统半导体电子学把电子当作「电荷的载体」，只关心它跑不跑、跑多快；而磁性材料早就知道电子还有**自旋**这一个自由度。
1980 年代起，人们开始问：能不能既用自旋存信息（磁存储），又用自旋算信息（器件）？
这个方向就是**自旋电子学（spintronics）**——它把「电荷」与「自旋」两个自由度同时搬上舞台。

它的产业影响是里程碑式的：GMR 与 TMR 读头让硬盘面密度指数增长，STT-MRAM 正在冲击「通用内存」，自旋轨道矩与二维磁性则是下一代候选。
本节承接《薄膜多层膜、交换偏置与巨磁电阻》，但把镜头拉回**基础机制**：自旋极化、自旋相关输运、自旋注入与磁隧道结。

历史坐标：1988 年 Baibich、Fert 等在 Fe/Cr 超晶格中首次报道 GMR；同年 Grünberg 在 Fe/Cr/Fe 三层膜中观察到反铁磁耦合与 GMR；2007 年费尔与格林贝格共享诺贝尔物理学奖。从发现到硬盘读头量产只用了十年——这是凝聚态物理「基础到产业」最快的转化之一。

## 1 自旋极化：电流里两种自旋不再对半

普通金属中，自旋向上与自旋向下的电子等量，电流无自旋信息。但**铁磁金属**不同：交换劈裂使费米面附近两种自旋的态密度不同（如铁约 45% 与 55%），于是导电电子携带净自旋极化。

这种「自旋选择」的根源可以在量子力学里找到：交换劈裂 + 态密度之差。在《洪德定则与原子磁矩》里我们算过孤立原子的磁矩，这里要记住的是——在金属里，自旋极化不再是「个别电子」的性质，而是**费米面整体**的性质，是能带结构决定的集体量。

**自旋极化率**定义为

$$P = \frac{n_\uparrow - n_\downarrow}{n_\uparrow + n_\downarrow}$$

$P > 0$ 表示向上自旋占多。铁约 45%，钴约 42%，镍约 33%——这是所有自旋电子学器件「自旋源」的起点：要产生自旋极化电流，先放进一块铁磁体。

<span class="marginnote">为什么铁磁金属能「选择」自旋？交换劈裂使两种自旋的能带错开，费米面处态密度不同；导电性正比于费米面态密度，于是两种自旋的导电性不同。自旋极化率 $P$ 就是这条「选择性」的定量标尺。</span>

## 2 GMR：自旋相关散射的器件化

**巨磁电阻（GMR）**1988 年由费尔与格林贝格独立发现：Fe/Cr 多层膜中，反铁磁耦合态电阻高、平行态电阻低，变化率可达 50%–100%。

机制是**自旋相关散射**：传导电子在磁性层中被散射的强度依赖「电子自旋 vs 层内磁化」的取向——平行散射弱、反平行散射强。
反铁磁耦合时两个自旋通道都被挡，电阻高；加场使两磁层平行后，每个自旋方向都有一条畅通通道，电阻骤降。

**重点：** GMR 的电阻变化可以写成 $R = R_0 + \frac{1}{2}\Delta R(1 - \cos\theta)$，其中 $\theta$ 是两磁层磁化夹角——电阻是夹角的函数，这正是「自旋阀」能感知磁化方向的本质。现代硬盘读头就是自旋阀，靠 GMR/TMR 把磁化方向变成电阻信号。

工程化的自旋阀结构通常是「三层夹心 + 钉扎」：铁磁**自由层**（感应磁记录介质的磁场、磁化跟着转）+ 非磁间隔层 + 铁磁**参考层**（被反铁磁层钉扎、方向固定）。
自由层与参考层夹角变化 → 电阻变化 → 输出信号。交换偏置钉扎层的工程细节见《薄膜多层膜、交换偏置与巨磁电阻》。

<span class="marginnote">GMR 的两种几何：CIP（电流平行膜面）容易制备但信号弱；CPP（电流垂直膜面）信号强但工艺难。现代读头多用 TMR（磁隧道结），室温变化率超 200%——见下一节。</span>

## 3 磁隧道结与 TMR：隧穿时的自旋选择

**磁性隧道结（MTJ）**：两层铁磁电极夹一层 1–2 nm 的绝缘势垒（如 $\ce{MgO}$、$\ce{Al2O3}$），电子靠量子隧穿穿过势垒。
隧穿概率依赖两电极磁化的相对取向，电阻差叫**隧穿磁电阻（TMR）**：

$$\mathrm{TMR} = \frac{R_{\mathrm{AP}} - R_P}{R_P} = \frac{2P_1 P_2}{1 - P_1 P_2}$$

其中 $P_1$、$P_2$ 是两电极的自旋极化率。MgO/CoFeB 结因**相干隧穿**效应，室温 TMR 实测超过 200%，远超简单的 Julliere 公式预测。

**MTJ 是当今磁存储的中枢**：STT-MRAM 的存储单元就是一个 MTJ，读靠 TMR 电阻、写靠自旋转移矩翻转自由层。它是「既读又写、非易失、高速、耐久」的全能存储单元候选。

**磁传感器**是自旋电子学最早的商业化出口：GMR 传感器广泛用于汽车轮速检测、电流传感（漏电保护器）与生物检测（磁标记免疫分析）。一个冰箱门磁簧开关的灵敏度，与工业级 GMR 传感器的原理同源。

**MTJ 的应用版图**：除 MRAM 外，MTJ 还用作高频振荡器（自旋转移矩振荡器，GHz 级）与微波探测器，正在进入 5G/雷达的器件库。

## 4 自旋注入与自旋积累

把自旋极化电流**注入**非磁金属或半导体，极化信息不会立刻消失——自旋在失去记忆前能传播一段距离，这叫**自旋输运**，特征是**自旋扩散长度 $l_s$**（数百纳米量级）。

自旋注入产生**自旋积累（spin accumulation）**：非磁体中向上与向下自旋化学势分离，可以用「自旋电化学势劈裂」描述。测量自旋积累的经典手段是**非局域自旋阀（nonlocal spin valve）**：注入器与检测器分离，只检测纯自旋电流、不混入电荷电流。

自旋扩散长度的量级值得记住：Cu 约数百纳米、Al 约 1 微米、石墨烯可达数十微米（且可用栅压调节），而半导体的 $l_s$ 通常很短。
器件设计的原则就是「自旋要传得比器件特征尺寸远」——因此石墨烯等长自旋寿命材料成为热门，也是《前沿专题》二维自旋电子学的基础。

<span class="marginnote">自旋注入有三种基本手段：铁磁接触注入（欧姆接触）、自旋隧穿注入（势垒界面）与自旋霍尔注入（由自旋霍尔效应产生，见《自旋轨道效应》）。半导体自旋电子学的瓶颈始终在自旋扩散长度短——直到二维材料（石墨烯、MoS₂）提供了长自旋寿命的新平台。</span>

## 5 公式解析：TMR 与自旋极化

把 Julliere 模型拆开：

$$\mathrm{TMR} = \frac{R_{\mathrm{AP}} - R_P}{R_P} = \frac{2P_1 P_2}{1 - P_1 P_2}$$

- **第一步，看平行电阻 $R_P$**：两磁化平行时，每个自旋方向都「匹配」地隧穿，总电导是两自旋通道电导之和，$G_P = G_\uparrow + G_\downarrow$。
- **第二步，看反平行电阻 $R_{AP}$**：反平行时自旋「错配」，隧穿被压制，$G_{AP} = 2G_\uparrow G_\downarrow/(G_\uparrow+G_\downarrow)$（串联模型）。
- **第三步，取比值**：代入 $P = (G_\uparrow-G_\downarrow)/(G_\uparrow+G_\downarrow)$，整理即得 $\mathrm{TMR} = 2P_1P_2/(1-P_1P_2)$。
- **第四步，看极限**：$P = 0$ 时 TMR = 0（非磁性无效应）；$P \to 1$ 时 TMR 发散（完全极化的理想半金属，如 $\ce{CrO2}$、$\ce{La0.7Sr0.3MnO3}$）。MgO 结超 200% 的 TMR 超出此公式，是因为相干隧穿还额外依赖势垒的对称性选择。

## 6 核心对比表：GMR vs TMR

| 特征 | GMR | TMR |
| --- | --- | --- |
| 输运机制 | 金属内自旋相关散射 | 绝缘势垒隧穿 |
| 结构 | 铁磁/非磁多层膜 | 铁磁/绝缘体/铁磁 MTJ |
| 室温变化率 | 10%–100% | 100%–600% |
| 几何要求 | CIP 或 CPP | 必须 CPP（垂直） |
| 代表材料 | Fe/Cr、Co/Cu | MgO/CoFeB |

两者共享同一个核心逻辑：**自旋依赖的输运**——只是「依赖」的机制从散射换成了隧穿。这也是自旋电子学「用磁性控制电输运」的通用范式。

从「用磁性控制电」到「用电流控制磁性」只差一步：把自旋极化电流反过来注入磁体，极化电子把角动量交给局域磁矩，就能驱动磁化翻转——这就是**自旋转移矩（STT）**，也是 MRAM 写入方案的物理。它标志着自旋电子学从「读」（传感器）走向「写」（存储器），详见《磁化动力学》与《自旋轨道效应》。

## 7 小结

- **自旋电子学**同时利用电子的电荷与自旋，把「存储」与「逻辑」统一到同一物理。
- **自旋极化率 $P$** 是铁磁体作为自旋源的定量标尺，Fe、Co、Ni 的 $P$ 在 33%–45%。
- **GMR** 靠自旋相关散射，**TMR** 靠自旋相关隧穿，都是「电阻随磁化取向变化」的器件化。
- **MTJ** 是 STT-MRAM 的核心，读用 TMR、写用自旋转移矩。
- 自旋注入、自旋积累与自旋扩散长度描述自旋信息在非磁体中的传播。
- GMR/TMR 传感器已是成熟的产业（硬盘读头、汽车传感、生物检测）。
- 自旋电子学的下一步需要更高效的自旋源与控制手段——这正是《自旋轨道效应》要讲的内容。
- 从「用磁性控制电」（读）到「用电流控制磁」（写），STT 使 MRAM 成为现实。

自旋电子学的完整图景到这里已经成形：铁磁体做自旋源、GMR/TMR 做自旋探测器、STT 做自旋写入。但所有这些都是「有铁磁体」的方案——而下一节的主角，能在**无磁性材料**里凭空产生自旋极化。

在下一节，我们将看一种「不需要铁磁体」就能产生自旋极化电流的机制——这就是**自旋轨道效应**。
