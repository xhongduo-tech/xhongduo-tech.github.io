## 为什么从顺磁性开始

前两章处理了「没有净磁矩的原子」——
抗磁是它们的全部回应。
现在轮到主角登场：
**含有未成对电子的原子或离子，本身就带着一个磁矩**。
把这样的原子放进磁场，磁矩会趋向沿场排列；
但热运动又在把排列搅乱。
顺磁性就是这场拉锯战的平衡态。
它是磁学里第一个「统计物理」问题：
用玻尔兹曼分布把微观磁矩的方向求平均。
居里定律与布里渊函数，正是这第一次平均的成品。
从顺磁走向铁磁，只差一步——
当原子之间开始「互相商量」，有序就降临了。

## 1 无相互作用磁矩的统计

考虑 $N$ 个互相不作用的磁矩，每个磁矩大小 $\mu$，外场 $B$ 沿 $z$ 方向。
单个磁矩的能量

$$E = -\vec{\mu}\cdot\vec{B} = -\mu_z B$$

玻尔兹曼分布给出磁矩沿 $z$ 的平均：
$\langle \mu_z \rangle = \int \mu_z \cos\theta\, e^{\mu B\cos\theta/k_BT}\,\mathrm{d}\Omega / \int e^{\mu B\cos\theta/k_BT}\,\mathrm{d}\Omega$，积分得到**朗之万函数**

$$L(x) = \coth x - \frac{1}{x}, \qquad x = \frac{\mu B}{k_B T}$$

宏观磁化强度 $M = N\langle \mu_z\rangle = N\mu L(x)$。
<span class="marginnote">朗之万函数是「经典极限」：把磁矩方向当作连续分布。
1905 年朗之万用它处理经典磁偶极子。
它后来成了顺磁、
铁磁、
介电（偶极取向极化）共用的数学模型——
一个函数，养活半个凝聚态。
</span>

## 2 布里渊函数：量子化的磁矩方向

但磁矩方向不是连续的。
量子力学要求 $\mu_z = g_J m_J \mu_B$ 只取 $2J+1$ 个分立值。
把求和替代积分，朗之万函数被替换成**布里渊函数**

$$B_J(x) = \frac{2J+1}{2J}\coth\frac{(2J+1)x}{2J} - \frac{1}{2J}\coth\frac{x}{2J}, \qquad x = \frac{g_J\mu_B JB}{k_B T}$$

于是

$$M = Ng_J\mu_B J\, B_J(x)$$

当 $J\to\infty$ 时 $B_J(x) \to L(x)$，量子图像平滑地退回经典极限——
这正是两种描述的衔接点。
<span class="marginnote">对 $J=1/2$（纯自旋），布里渊函数退化为最简单的双能级形式 $B_{1/2}(x) = \tanh x$，磁化强度 $M = N\mu\tanh(\mu B/k_BT)$。
这个 $\tanh$ 形式后面在铁磁分子场理论里还会再次出现——
记住它，第2篇《分子场理论》会省一半力气。
</span>

## 3 居里定律与小场极限

当外场很弱或温度很高，$x = \mu B/k_BT \ll 1$，布里渊函数展开到一阶 $B_J(x) \approx (J+1)x/3J$，于是

$$M = \frac{N g_J^2 \mu_B^2 J(J+1)}{3k_B T} B = \frac{C}{T} H, \qquad \chi = \frac{C}{T}$$

这就是**居里定律（Curie's law）**：
磁化率与绝对温度成反比。
居里常数

$$C = \frac{\mu_0 N g_J^2 \mu_B^2 J(J+1)}{3k_B} = \frac{\mu_0 N \mu_{\mathrm{eff}}^2}{3k_B}$$

把 $\mu_{\mathrm{eff}} = g_J\sqrt{J(J+1)}\mu_B$ 代回——
注意这正是一章前朗德公式里的「有效磁矩」。
**顺磁测量反推出居里常数，直接读出离子磁矩**，这就是磁化学鉴定离子的标准方法：
实测 $\chi$ 对 $1/T$ 作图，斜率即 $C$，从 $C$ 反推 $\mu_{\mathrm{eff}}$，再与洪德定则报价单对比。

**辨析｜易错点：
** 居里定律的成立条件是 $\mu B \ll k_BT$，即**小场/高温极限**。
饱和效应在强场低温出现：
$\chi$ 不再是常数，$M(H)$ 弯向饱和。
常见错误是把居里定律硬用到 $\mu B \sim k_BT$ 的区域，那里必须用完整的布里渊函数。
判据很简单：
计算 $\mu_B B/k_BT$ 与 1 比较，1 T 场、
室温时约 0.002，安全；
2 K 时约 0.5，危险。

## 4 公式解析：居里定律的推导链条

$$\chi = \frac{C}{T}, \qquad C = \frac{\mu_0 N g_J^2\mu_B^2 J(J+1)}{3k_B}$$

把这条公式从玻尔兹曼分布一步步看：

- **第一步，能量**：磁矩在外场中的取向能 $E = -\mu_z B = -g_J\mu_B m_J B$，共 $2J+1$ 个能级。
- **第二步，配分函数**：玻尔兹曼平均 $\langle m_J\rangle = \sum m_J e^{-E/k_BT}/\sum e^{-E/k_BT}$，小场展开时 $\langle m_J\rangle \approx -(g_J\mu_B J(J+1)/3k_BT)B$。
- **第三步，宏观化**：乘上 $N g_J\mu_B$ 得 $M$，再除以 $B/\mu_0$ 得 $\chi$，整理出 $C$。整条链的物理核心一句话：**热涨落（$k_BT$）越大，取向越乱，$\chi$ 越小**。
- **第四步，读结构**：$C$ 里的 $N$ 是磁矩密度，$J(J+1)$ 来自量子取向的平方平均，$1/3$ 是三维空间取向的几何平均因子——三个因素，三个故事。

## 5 居里-外斯定律与交互的征兆

居里定律假设磁矩互不作用，但真实材料总有些耦合。
经验上把居里定律推广成**居里-外斯定律**

$$\chi = \frac{C}{T - \theta}$$

其中 $\theta$ 是居里-外斯温度：
$\theta > 0$ 暗示铁磁耦合的预兆（高温端向上翘），$\theta \lt  0$ 暗示反铁磁耦合。
它是第2篇《分子场理论与居里-外斯定律》的正式入口——
相互作用登场前的第一声信号。
<span class="marginnote">居里-外斯定律最初是经验公式，分子场理论给了它理论外壳。
但要注意：
$\theta$ 的正负只给出「耦合倾向」，要坐实铁磁或反铁磁，必须在 $\theta$ 处或 $\theta_N$ 处观察到磁有序的相变，以及临界温度以下的自发磁化或交错磁化。
单靠顺磁区拟合，下结论要谨慎。
</span>

## 6 小结

- **顺磁性**来自未成对电子的固有磁矩，平衡由玻尔兹曼分布决定。
- **布里渊函数 $B_J(x)$** 处理量子化取向，$J\to\infty$ 退化为经典**朗之万函数 $L(x)$**；$J=1/2$ 时退化为 $\tanh$。
- **居里定律 $\chi = C/T$** 是小场高温极限，**居里常数 $C$ 直接反推有效磁矩 $\mu_{\mathrm{eff}}$**。
- **居里-外斯定律 $\chi = C/(T-\theta)$** 引入相互作用，$\theta>0$ 铁磁、$\theta\lt 0$
