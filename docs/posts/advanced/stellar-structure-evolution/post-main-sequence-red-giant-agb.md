## 为什么从后主序演化开始

主序是恒星一生的黄金时代，但黄金时代有尽头：核心的氢终会烧尽。上一课的质光关系告诉我们，质量越大的恒星越早耗竭——于是恒星告别主序的时刻，由它的初始质量决定。本课追踪恒星走出主序后的漫漫长路：从核心收缩、氢壳层点燃，到膨胀成**红巨星（red giant）**；低质量星以一场剧烈的**氦闪**（helium flash）重新点火，最终沿着**渐近巨星支（asymptotic giant branch, AGB）**走向生命终点；大质量星则一路烧向碳、氧、硅，直至铁核的绝境。<span class="marginnote">红巨星的「红」来自它巨大的半径与偏冷的表面：一颗 1 倍太阳质量恒星的核心氢耗尽后，半径可膨胀到太阳的 200 倍以上，表面温度降到 3000 K 上下。萨根笔下的「膨胀红巨星吞噬地球」，正是这条演化链在 50 亿年后的现实投影。</span>

## 1 氢耗尽与壳层燃烧

主序星核心的氢烧成氦后，核心不再产能，只能靠残热支撑；由于没有能源补偿，核心开始**收缩**，温度与密度随之升高。<span class="marginnote">这里第二次用到位力定理的负热容：核心失能→收缩→升温。升高的温度把核心外围尚未烧尽的氢点燃，形成一层薄薄的<strong>氢壳层燃烧</strong>（hydrogen shell burning）。壳层燃烧是红巨星阶段最持久的能源，它源源不断地把新氦「倾倒」进核心。</span>氢壳层燃烧的威力来自一个巧妙的位置差：壳层燃烧区的温度比核心高（因为核心已钝化为惰性氦核、温度梯度把热集中在壳层），而壳层的新鲜氢又源源不断——**惰性核心 + 活跃氢壳**，是后主序演化的第一个基本结构。

核心质量与总质量之比有一个临界值：**申伯格–钱德拉塞卡极限（Schönberg–Chandrasekhar limit）**——约 $0.37$ 倍核心外质量。超过此比值，惰性氦核无法维持等温，不得不收缩升温，恒星被迫向红巨星演化。质量越大的恒星，惰性核越早逼近这个极限，离开主序也越早。这就是为什么 H-R 图上质量大的主序星更早「转弯」。

氢壳层燃烧还有一个优雅的**热镜面效应（thermal mirror）**：壳层燃烧产生的能量向外流，使包层膨胀；而包层膨胀又反过来使核心受压升温。壳层燃烧区像一面热镜，把核心的每一次收缩都「翻译」成包层的剧烈响应——这使后主序恒星的光度对核心状态高度敏感，也让红巨星成为结构最「紧绷」的恒星。

## 2 红巨星分支（RGB）

核心收缩升温的同时，恒星整体却急剧**膨胀**。这个「核心收缩、包层膨胀」的反直觉组合，根源是第四课的**不透明度机制**：壳层燃烧产生的能量向外流，途经温度降低、氢氦部分电离的区域时，不透明度 $\kappa$ 骤增，辐射输运受阻，包层被迫大幅膨胀以排出多余能量。恒星因此沿**红巨星分支（red giant branch, RGB）**在 H-R 图上向右上方移动——表面温度降到 3000 K 上下，光度却升到几百倍太阳光度。

红巨星最惊人的数字是它的**密度对比**：核心密度高达 $10^5\,\mathrm{g\,cm^{-3}}$（简并前兆），而包层密度低到 $10^{-6}\,\mathrm{g\,cm^{-3}}$。**一颗红巨星内部是「高密度核 + 稀薄巨包层」的两级结构**，如同一栋摩天楼立在火柴盒上。<span class="marginnote">红巨星包层还有一个招牌特征：几乎完全对流。膨胀后的包层温度太低，辐射输运根本不够用，对流从表面一直延伸到壳层燃烧区附近。因此红巨星表面会「露出」内部深处的化学指纹——这使红巨星的表面丰度成为窥探恒星内部的窗口。</span>太阳的未来就此注定：约 50 亿年后进入 RGB，半径将膨胀到约 1.2 天文单位，逼近并可能吞噬地球轨道。

红巨星的膨胀并非无限：表面温度存在一条硬下限——**林忠四郎线（Hayashi line）**。表面温度低到约 3000–4000 K 时，外层完全对流、结构逼近对流平衡的极限，温度再降就找不到静力学平衡解。因此红巨星沿 Hayashi 线「向上爬」：温度几乎不变、半径与光度持续增大。<span class="marginnote">Hayashi 线是 H-R 图上恒星右下方的「物理墙」：任何完全对流的恒星都不能跨过它。红巨星、AGB 星乃至恒星形成早期的原恒星都贴着这面墙行走——它是恒星结构理论给出的最清晰的「禁区边界」之一。</span>太阳的未来时间线值得具体列出来：

| 距今年数 | 事件 |
| --- | --- |
| 0 | 主序，光度 $1\,L_\odot$ |
| 约 50 亿年 | 核心氢耗尽，离开主序 |
| 约 70 亿年 | 红巨星，半径约 1.2 AU |
| 约 76 亿年 | 氦闪，转入氦燃烧 |
| 约 120 亿年 | AGB，热脉冲 + 强星风 |
| 约 122 亿年 | 行星状星云 → 白矮星 |

这张时间表把萨根那句「最后一颗完美的一天」翻译成了精确的演化学：地球宜居期只剩约 10 亿年（太阳增亮使海洋蒸干），而彻底毁灭发生在 50 亿年后的红巨星阶段。

## 3 氦闪与氦燃烧

红巨星的结局取决于核心质量。对初始质量约低于 $2\,M_\odot$ 的恒星，惰性氦核在收缩中**简并化**——第三课的简并压开始主导。简并核心的压强与温度无关，因此核心升温**不会**触发压强响应与自我调节。当温度终于高到足以点燃氦聚变时，反应释放的热量无法让简并核膨胀散热，反而进一步加热、加速反应——**热失控**发生，一场持续约几分钟的剧烈爆发把核心照得通亮，这就是**氦闪（helium flash）**。<span class="marginnote">氦闪的爆发功率可与整个银河系相当，但因为发生在致密简并核心、且被厚重包层包裹，闪光几乎完全被吸收，恒星表面几乎看不出异常——「被闷在壳里的爆炸」。氦闪释放的能量最终让核心脱离简并，恢复理想气体行为，恒星进入相对平静的氦燃烧阶段。</span>

大质量恒星（$M\gtrsim 2\,M_\odot$）的氦核不会在点燃前简并：它们的核心质量大、温度升得快，在达到简并之前就已点燃氦，平稳进入**氦燃烧**。无论以哪种方式点火，氦燃烧都通过**3α 过程**把三个氦核合成碳-12，下一节公式解析会拆解它的机制。

氦闪之后，简并被解除，核心恢复理想气体行为，恒星收缩、表面升温，在 H-R 图上移向**水平分支（horizontal branch, HB）**——氦核心燃烧与氢壳层燃烧并存的阶段。球状星团里的水平分支星（含 RR 天琴座变星）正是这一阶段的样本，它们的脉动特性是下一课《恒星脉动》的重要素材。

## 4 渐近巨星支（AGB）与热脉冲

氦燃烧阶段结束后，恒星再次面临「核心惰性、壳层燃烧」的局面，只是这次是**双壳层**：外层氢壳、内层氦壳同时燃烧。恒星沿**渐近巨星支（AGB）**再度膨胀，成为比红巨星更红的红超巨星。<span class="marginnote">AGB 的名字来自它在 H-R 图上「渐近」逼近 RGB 的位置——两条演化支在图上几乎平行，只有细微的偏移，仿佛恒星在走第二遍同样的路。AGB 是低质量星生命里最热闹的阶段：核燃烧、热脉冲、强星风、核合成同时上演。</span>

AGB 的招牌现象是**热脉冲（thermal pulse）**：氦壳燃烧在简并条件下不稳定，周期性地「打火」，每次脉冲把壳层间的对流区搅动一番，把核合成产物（碳、以及慢中子俘获的 **s 过程**重元素）翻到恒星表面——这就是 AGB 星表面出现碳、钡、锝等元素异常的来源。<span class="marginnote">s 过程（slow neutron capture）在 AGB 的热脉冲间于壳层里进行：铁种子核逐个俘获中子，沿稳定谷向上爬，直到半衰期限制的转折点。太阳系中约一半的比铁重的元素（锶、钇、锆……以及钡）来自 AGB 星——我们身体里的一部分重元素，曾在某颗 AGB 星内部被锻造出来。</span>与此同时，AGB 星经历剧烈的**质量损失**：星风把包层一层层剥去，最终露出炽热的简并核心，剥离的气体外壳被电离、照亮，形成**行星状星云（planetary nebula）**——哈勃望远镜拍下的那些彩色气泡，正是恒星生命最后一幕的舞台布景。

热脉冲还有一个关键的副产品——**挖掘事件（dredge-up）**：脉冲引起的对流一次次深入到壳层燃烧区，把核合成产物翻到表面。第一挖掘把 CNO 燃烧产物带上表面，第二、第三挖掘把碳与 s 过程重元素翻出，观测上表现为 AGB 星表面的碳/氧比异常——**碳星**的「碳星光谱」正是这么来的。AGB 是恒星向星际介质回馈物质的主要通道，它与行星状星云共同完成了恒星物质循环的最后一环。

## 5 公式解析：3α 过程与 Hoyle 共振

氦燃烧的核心反应是 **3α 过程**：三个 α 粒子（氦核）合成一个碳-12。它看似简单，实则是一场精彩的核物理奇迹，拆成四步看：

**第一步，先凑对**：两个 α 粒子碰撞生成铍-8：${}^{8}\mathrm{Be} \leftrightharpoons 2\alpha$。但铍-8 极不稳定，半衰期仅约 $2.6\times10^{-16}\,\mathrm{s}$，瞬间又裂回两个 α。它本身几乎不存在，只能以极微的平衡丰度「借」身。
**第二步，Saha 平衡给丰度**：$n_8 \propto n_\alpha^2\,T^{-3/2}\,e^{-Q/k_BT}$，其中 $Q = 0.09\,\mathrm{MeV}$。铍-8 的丰度与 α 密度的平方成正比——密度越高，这个「一闪而逝」的中间体越多。
**第三步，Hoyle 共振救命**：第三步 $^{8}\mathrm{Be} + \alpha \rightarrow {}^{12}\mathrm{C}$ 若按普通路径，速率低得可怜。霍伊尔（Fred Hoyle）在 1954 年**预言**碳-12 在 7.654 MeV 处存在一个激发态（恰好落在 ⁸Be+α 的能量上），后来被实验证实——正是这个**霍伊尔态（Hoyle state）**的共振，把反应速率放大了约一百万倍。
- **第四步，算账**：净反应 $3\alpha \rightarrow {}^{12}\mathrm{C} + 7.275\,\mathrm{MeV}$。它的温度敏感度极端：$\varepsilon_{3\alpha} \propto \rho^2 Y^3 T^{40}$（$Y$ 是氦丰度）。**$T^{40}$ 意味着氦燃烧在约 $10^8\,\mathrm{K}$ 处像开关一样点火**——这解释了为什么氦燃烧温度被钉在极窄的范围，也解释了简并核心为何会氦闪。

霍伊尔那句「宇宙必须由碳构成，我们才能存在」的自明论证，从这四步里得到了最精确的物理注脚。这个推理后来被视为**人择原理（anthropic principle）**最早的物理例证：正因为碳-12 恰好在该能量有共振，宇宙中才有足够的碳构成生命；而能观察到碳-12 的我们，本身就要求这个共振存在。恒星物理在这里与存在论打了个照面——这也是本专题最接近哲学的时刻。

## 6 后主序的时间尺度

后主序演化的节奏比主序快得多，而且越到后期越快。以 1 倍太阳质量恒星为例：

| 阶段 | 持续时间 | 备注 |
| --- | --- | --- |
| 主序 | 约 $10^{10}$ 年 | 黄金时代，最漫长 |
| 红巨星分支（RGB） | 约 $10^9$ 年 | 壳层燃烧稳步推进 |
| 氦燃烧（水平分支） | 约 $10^8$ 年 | 核心 3α 供能 |
| 渐近巨星支（AGB） | 约 $10^6$–$10^7$ 年 | 热脉冲加速 |
| 行星状星云 | 约 $10^4$ 年 | 外壳被吹散的瞬间 |
| 白矮星冷却 | 超过 $10^9$ 年 | 漫长的余晖 |

这张表揭示了一个残酷的节奏：**恒星越接近死亡，走得越快。** 主序烧了百亿年，RGB 只烧十亿年，氦燃烧一亿年，AGB 只撑几百万年，而行星状星云阶段不过万年——恒星生命的最后一个百分点，浓缩了它最剧烈、最热闹的全部剧情。<span class="marginnote">时间尺度的剧烈收缩是「燃料越贵、烧得越急」的直接后果：氢燃烧 $T\sim10^7\,\mathrm{K}$，氦燃烧 $T\sim10^8\,\mathrm{K}$，碳、氧燃烧需 $10^9\,\mathrm{K}$ 量级——温度指数 $\nu$ 越大，反应越快、阶段越短。这也解释了为什么夜空中的红巨星与 AGB 星数量稀少：它们不是不常见，而是「活」得太短。</span>

从观测的角度，这条时间尺度表还回答了一个悖论：既然恒星演化最终都要走向白矮星或超新星，为什么我们能同时看到各个演化阶段的恒星？因为银河系里有上千亿颗恒星、年龄各异——**恒星的演化时间尺度与星系的时间尺度交叠，使我们得以在一张 H-R 图上「看尽」所有年龄的恒星。** 这正是恒星统计天文学的基础。

## 7 不同质量的后主序路径

后主序的终点由初始质量一分为三，这是恒星演化中最清晰的分水岭：

- **低质量（$M \lesssim 2\,M_\odot$）**：RGB → 氦闪 → 氦燃烧 → AGB → 行星状星云 → **碳氧白矮星**。太阳走这条路。
- **中等质量（约 $2$–$8\,M_\odot$）**：平稳氦燃烧 → AGB（热脉冲更剧烈、s 过程更充分）→ 行星状星云 → 碳氧白矮星（质量略大）。
- **大质量（$M \gtrsim 8\,M_\odot$）**：氦燃烧后继续点燃碳、氧、硅……形成**洋葱状分层结构**，中心烧到铁核即终止（铁聚变吸能而非产能），随即铁核坍缩——**超新星爆发**。这是第十一课的主题。

`<center>`
| 初始质量 | 后主序路径 | 终点 |
| --- | --- | --- |
| $\lesssim 2\,M_\odot$ | 氦闪 + 双壳层 | 碳氧白矮星 |
| $2$–$8\,M_\odot$ | 平稳氦燃 + AGB | 碳氧白矮星 |
| $\gtrsim 8\,M_\odot$ | 逐级重元素燃烧 | 超新星 → 中子星/黑洞 |


无论走哪条路，后主序都指向同一个哲学：**恒星以燃烧维持平衡，燃料耗尽之时，便是结构重组之日。** 低质量星靠「温柔」的抛壳退役，大质量星则以一声巨响谢幕。

边界本身也随化学组成漂移：金属丰度越低，不透明度越小、恒星越紧凑，8 倍太阳质量的分界线会下移；而在极低金属丰度的第一代恒星（星族 III），演化路径甚至可能与今天完全不同。**后主序的「质量分岔图」不是一张固定的表格，而是一张随宇宙化学成分演化的动态地图。**

## 8 小结

- 主序终结于**核心氢耗尽**：核心收缩升温，点燃**氢壳层燃烧**，恒星进入后主序演化。
- **申伯格–钱德拉塞卡极限**（惰性核质量约 0.37 倍外核质量）决定恒星何时离开主序。
- **红巨星分支（RGB）**由核心收缩 + 不透明度驱动的包层膨胀造成，形成「高密度核 + 稀薄对流包层」的两级结构；太阳 50 亿年后将膨胀到地球轨道附近。
- 低质量星在简并核心内发生**氦闪**，大质量星平稳点燃氦；氦燃烧靠**3α 过程**（含霍伊尔共振）合成碳。
- **AGB** 是双壳层 + 热脉冲 + 强星风的阶段，s 过程在此合成一半以上的重元素，最终以行星状星云把外壳抛回星际介质。
- 后主序终点由质量分岔：白矮星（$\lesssim 8\,M_\odot$）或超新星（$\gtrsim 8\,M_\odot$），分岔边界随金属丰度漂移。
- 后主序的节奏越到后期越快：主序百亿年、RGB 十亿年、氦燃烧一亿年、AGB 几百万年——恒星生命的最后一个百分点，浓缩了它最剧烈、最热闹的全部剧情。

在下一节，我们将从「恒星如何变老」转向「恒星如何心跳」：恒星脉动——那类用周期丈量密度、用周光关系丈量宇宙的变星。
