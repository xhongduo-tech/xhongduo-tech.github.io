## 为什么从联盟开始

拍卖解决「怎么竞争地分」，而现实中大量任务是**只有合作才做得成**的：三个机器人各自搬不动一块大板，合起来才行；几家物流公司共享一辆满载卡车，成本才能降下来。**联盟形成（coalition formation）** 研究「哪些智能体结成一伙、收益怎么分」，**任务分配（task allocation）** 研究「来了一个任务堆，怎么派给最合适的智能体」。它们是合作性多智能体系统的两块基石，也是把上一篇的「协作」从理念落成算法的两条路。这一篇先讲合作博弈的数学工具——**特征函数、核、夏普利值**——再讲工程协议——**合同网协议**。

## 1 为什么值得结盟

**联盟（coalition）**：一组决定**共同行动、共享收益**的智能体。<span class="marginnote">结盟不是道德选择，是数学选择：只有当联盟的总收益<strong>严格大于</strong>成员各自单干收益之和时，结盟才有意义。这个差值叫<strong>协同增益（synergy）</strong>。</span>

记 $v(\{i\})$ 为智能体 $i$ 单独行动的价值，$v(C)$ 为联盟 $C$ 共同行动的价值。结盟的动机就是：

$$
v(C) > \sum_{i \in C} v(\{i\})
$$

协同增益来自**互补能力**（我有技术你没工具）、**规模经济**（量大便宜）、**风险分担**（一起扛不确定性）。但注意：协同增益只是「饼变大了」，还不保证每个成员都愿意加入——**分配问题**接踵而至：饼做大之后怎么分，分不好，联盟立刻解体。这正是合作博弈论的核心主题。

## 2 特征函数博弈

联盟形成的数学框架是**合作博弈 / 特征函数博弈（characteristic function game）**：$N$ 个玩家，每个子集 $S \subseteq N$ 有一个值 $v(S)$（$S$ 结盟能创造的总价值），且 $v(\varnothing)=0$。<span class="marginnote">与上一篇的「非合作博弈」对比：非合作博弈强调个体策略与均衡，合作博弈直接讨论「哪些子集能创造多少价值、收益怎么分」——玩家在联盟内假设会遵守约定，分账问题才是中心。</span>

有了特征函数，两个经典问题浮现：

**联盟结构生成（coalition structure generation, CSG）**：把 $N$ 个智能体划分成若干个**不相交**的联盟（可能含单例），使**联盟结构的总价值最大化**：

$$
\max_{\{C_1,\ldots,C_k\}} \sum_{t=1}^k v(C_t)
$$

**收益分配（payoff division）**：给定一个联盟，把它创造的 $v(C)$ 公平地分给成员，使得**没人想退出**、**没人觉得被亏待**。

**辨析｜易错点：** CSG 是「分堆」问题，不是「组队」问题——它要把所有智能体**全部分**进某堆（可能自己是孤堆）。而且 CSG 在计算上极难：$n$ 个玩家的联盟结构数量是**贝尔数** $B_n$，增长快于指数，$n=20$ 时已超过 $5\times10^{13}$ 种，暴力枚举不可行。

**一个直觉例子**：三个智能体 $A, B, C$，单人价值都是 1；$AB$ 合起来值 4，$AC$ 值 3，$BC$ 值 3，三人合起来值 5。那么可能的联盟结构有 $\{\{A,B,C\}\}$（值 5）、$\{\{A,B\},\{C\}\}$（值 $4+1=5$）、$\{\{A,C\},\{B\}\}$（值 4）、$\{\{A\},\{B,C\}\}$（值 4）、$\{\{A\},\{B\},\{C\}\}$（值 3）。最优结构是「三人一起」或「AB 搭档 + C 单干」——两者总价值相同，选择谁取决于后续分配是否稳定。这个三智能体的例子已足以看出：**结构选择与分配稳定性是两件事，必须放在一起权衡**。

## 3 收益分配：核

分账第一要义：**稳定**。一个分配 $x=(x_1,\ldots,x_n)$（$\sum x_i = v(N)$）若满足：对任意联盟 $S$，都有 $\sum_{i\in S} x_i \ge v(S)$，则 $S$ 没有动机脱离大联盟单干——这种分配构成**核（core）**。

核的含义是：**没有任何子联盟能通过「退出」使自己变得更好**。<span class="marginnote">核是「联盟稳定性」的直接翻译：只要存在一个子联盟 $S$ 分到的少于它单干能挣的 $v(S)$，$S$ 就会威胁退出，大联盟就hold不住。核里的分配让所有威胁都失效。</span>

但核有一个尴尬性质：**它常常是空的**。当联盟收益的「结构」使得无论怎么分都有某个子联盟觉得吃亏时（例如某些市场博弈），核不存在——稳定分配这个目标本身可能做不到。于是需要更温和的分账原则。

## 4 收益分配：夏普利值

当核为空或太大时，我们用**夏普利值（Shapley value）** 作为「公平」的替代方案。它不问「稳定不稳定」，而是问：**每个玩家对这个联盟的贡献，平均该得多少？** 想法是把玩家按**随机顺序**逐个加入，看每次加入带来多少**边际贡献**，再对所有顺序取平均。<span class="marginnote">夏普利值 1953 年提出，可以从四条公理（效率、对称性、哑元、可加性）唯一推出——它是「按边际贡献平均分账」的严格数学化。2012 年夏普利因此获诺贝尔经济学奖。</span>

## 5 公式解析：夏普利值

记 $v$ 为特征函数，$N$ 为玩家集合，$S$ 是不含 $i$ 的任意子集，$|S|=s$，$n=|N|$。玩家 $i$ 的夏普利值为：

$$
\phi_i(v) = \sum_{S \subseteq N \setminus \{i\}} \frac{s!(n-s-1)!}{n!} \left[ v(S \cup \{i\}) - v(S) \right]
$$

逐步拆解这条公式：

- **第一步，读懂边际贡献 $v(S \cup \{i\}) - v(S)$**：$i$ **加入**联盟 $S$ 时，给 $S$ 带来的价值增量。这是 $i$ 在一种「入场顺序」下的贡献。
- **第二步，读懂权重 $\dfrac{s!(n-s-1)!}{n!}$**：有多少种入场顺序会让 $i$ 恰好加进一个大小为 $s$ 的联盟？分子 $s!(n-s-1)!$ 是「$S$ 内部先排 + 其余人后排」的排列数，分母 $n!$ 是总排列数——所以这个权重就是「$i$ 在第 $s+1$ 位加入 $S$」这一事件的概率。
- **第三步，求和**：对所有可能的 $S$ 把「贡献 × 概率」加总，得到 $i$ 的**期望边际贡献**——这就是夏普利值。<span class="marginnote">直觉收束：夏普利值 = 「如果所有人随机排成一队逐个加入大联盟，每个人在入场那一刻贡献的平均值」。它天然满足 $\sum_i \phi_i = v(N)$（效率），把饼分得一分不剩。</span>
**第四步，对比核**：核追求「稳定」（没人想退），夏普利值追求「公平」（按贡献分）；核可能为空，夏普利值永远存在且唯一。工程上常用夏普利值作为默认分账方案。<span class="marginnote">在机器学习里，夏普利值也被借用来做特征归因——SHAP 就是它的实现，用「每个特征对预测的边际贡献」解释黑箱模型，是 XAI 的主流工具，见《可解释 AI》专题。</span>

## 6 任务分配：合同网协议

联盟形成是「先找人，再分工」；**任务分配（task allocation）** 是「任务已经摆在那，怎么派」。最经典的工程协议是 **合同网协议（Contract Net Protocol, CNP）**，由 Smith 在 1980 年提出，至今仍是分布式任务分配的实际标准。<span class="marginnote">Smith, R. G., *The Contract Net Protocol: High-Level Communication and Control in a Distributed Problem Solver\*, IEEE Transactions on Computers, 1980。它把任务分配模拟成「招标」：管理节点发标，承包商投标，管理节点定标。</span>

合同网的四个角色/阶段：

**任务通告（announcement）**：管理者把任务需求广播出去——任务描述、截止时间、资格条件。

**投标（bidding）**：有能力且有意愿的智能体评估自身能力与负载，提交投标。

**定标（awarding）**：管理者按评标规则选标（例如最早完成者、最低成本者），把任务授予中标者。

**执行与报告（expediting）**：中标者执行任务并回报结果，可再作为管理者**分包**子任务——形成递归的合同网。<span class="marginnote">CNP 的优雅之处在于它的<strong>递归性</strong>：任何一个承包商都可以把任务再分包给更合适的 agent，形成一棵任务树。这也让 CNP 天然适配分层组织——与现实公司「层层发包」一一对应。</span>

CNP 简单、鲁棒、天然分布式，但它也有短板：**招标—投标的通信开销**大，评标规则若太简单（如只看报价）容易把任务派给能力不匹配者。改进方向包括用**市场定价**、**学习型投标策略**以及结合信任模型（第2篇）评估投标者可信度。

## 7 核心对比：联盟形成与任务分配

两条「合作落地」的路线放一张表：

| 维度 | 联盟形成 | 任务分配 |
| --- | --- | --- |
| 出发点 | 先决定「和谁一起干」 | 先有任务，「派给谁」 |
| 数学基础 | 特征函数博弈、核、夏普利值 | 组合优化、合同网协议 |
| 核心问题 | 分堆 + 分账 | 指派 + 激励 |
| 典型协议 | CSG 算法、Shapley 分配 | 合同网协议 CNP、市场机制 |
| 难点 | 联盟结构爆炸、分配不稳定 | 通信开销、评标规则 |
| 失败形态 | 核为空、联盟解体 | 任务积压、资源错配 |

**辨析｜易错点：** 不要混淆「联盟形成的收益分配」与「任务分配的报酬支付」。前者是在**共同创造**的价值里分账（先有合作产出）；后者是对**单方执行**任务的定价（先有明确任务）。前者要解决「没人想退出」，后者要解决「有人愿意接」。一条是博弈论问题，一条是协议工程问题。

**核心术语速查**：

| 术语 | 一句话定义 |
| --- | --- |
| 联盟 Coalition | 决定共同行动、共享收益的智能体组 |
| 协同增益 | 联盟总价值 > 成员单干价值之和的差值 |
| 特征函数博弈 | 用 v(S) 刻画每个子集价值的合作博弈 |
| 联盟结构生成 | 把全体智能体分堆使总价值最大（贝尔数爆炸） |
| 核 Core | 没有任何子联盟想退出的稳定分配集合 |
| 夏普利值 | 按随机入场顺序的期望边际贡献分账 |
| 合同网协议 | 发标—投标—定标—执行的分布式任务分配 |

## 8 小结

- **结盟动机**：协同增益 $v(C) > \sum v(\{i\})$——饼变大了才值得结盟。
- **特征函数博弈**：$v(S)$ 刻画每个子集能创造的价值；CSG 与收益分配是两大核心问题。
- **联盟结构生成**：把全体智能体划分成不相交联盟使总价值最大；数量是贝尔数，计算极难。
- **核**：稳定分配的集合——没有任何子联盟有动机退出；但核可能为空。
- **夏普利值**：按随机入场顺序的期望边际贡献分账，公平且唯一，但不管稳定；$\sum \phi_i = v(N)$
