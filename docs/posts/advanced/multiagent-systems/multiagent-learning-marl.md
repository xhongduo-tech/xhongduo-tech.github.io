# 多智能体学习及与深度 MARL 的衔接

<div class="epigraph">

## 为什么从学习开始

经典 MAS 有一个共同的隐含前提：智能体的**策略由设计者写死**——协商策略是让步函数，博弈策略是均衡求解。但真实世界没有这份奢侈：对手的策略未知、环境不断漂移、很多场景根本写不出好策略。于是最后一块拼图是：**让智能体自己从交互经验里学会策略**。这一篇是经典 MAS 与现代深度强化学习（Deep RL）的接缝——先讲多智能体学习为什么比单智能体难（非平稳性），再讲经典算法（独立 Q 学习、虚构对局、minimax-Q），最后讲深度 MARL 如何用**中心化训练—分布式执行**突破瓶颈，并把它接回《强化学习》与《AI 智能体》专题。

## 1 为什么多智能体需要学习

把「学习」装进多智能体的动机有三条：<span class="marginnote">动机一以蔽之：<strong>写策略不如学策略</strong>。当交互对象复杂到无法建模（对手、队友、环境都会变），预编程规则必然失灵，只能让智能体边交互边改进。</span>

**规则写不出来**：围棋、扑克、多机器人对抗这类任务，好的策略复杂到无法手工编码——必须从对局数据里学。

**对手会变**：对手也在学习。一套针对「静态对手」学出的策略，遇到「会适应你的对手」就会失效——策略必须持续更新。

**未知环境**：MAS 部署的环境（开放市场、动态电网）充满不可预测性，学习让智能体无需事先建模就能自适应。

但把单智能体强化学习直接搬进多智能体，会撞上一个根本性困难——**环境不平稳**。

## 2 非平稳性：MARL 的核心难题

回顾单智能体强化学习的框架：智能体在**马尔可夫决策过程（MDP）**里学习，环境的转移概率是**固定的**，于是「最优策略」是一个明确定义的静止对象。多智能体系统里，这个前提碎了：<span class="marginnote">这是多智能体学习与单智能体学习的分水岭：MDP 假设环境平稳（stationary），而多智能体环境<strong>内生地非平稳</strong>——别人的策略在变，你的「环境」就在变。参见《强化学习》专题对 MDP 的定义。</span>

你的下一个状态转移，取决于**所有智能体**的联合行动：

$$
P(s' \mid s, a_1, a_2, \ldots, a_n)
$$

而其他智能体的策略 $\pi_j$ 在学习中不断改变，所以从你眼里看，转移概率**随时间漂移**。单智能体的经典算法（Q-learning、策略梯度）都建立在「环境平稳」的收敛保证上，直接套用多智能体场景，**收敛保证失效**，甚至可能震荡。

**辨析｜易错点：** 多智能体学习 ≠ 「多个单智能体学习并行」。把每个智能体当独立单智能体来训（叫**独立学习**），是**最简单也最常翻车**的做法——因为各自把别人当「环境的一部分」，而环境在动，经典收敛定理全不适用。理解这一点，才算握住 MARL 的命门。

## 3 公式解析：Q-learning 与它为什么失效

先看单智能体 **Q-learning** 的更新：记 $Q(s,a)$ 为状态-动作值函数，$\alpha$ 为学习率，$r$ 为奖励，$\gamma$ 为折扣因子，$s'$ 为转移后的状态，则：

$$
Q(s,a) \leftarrow Q(s,a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s,a) \right]
$$

逐步拆解这条公式：

- **第一步，读懂 $\max_{a'} Q(s',a')$**：它取「新状态里能得到的最大未来价值」——这是把**当前最优策略**的估值当作目标的一部分。它假设：**从 $s'$ 起的最优价值是固定可估的**。
- **第二步，读懂误差项 $r + \gamma \max_{a'} Q(s',a') - Q(s,a)$**：这是「时序差分误差」（TD error）——把当前估计向「实际奖励 + 最优未来」方向推近一点。
- **第三步，看它为什么在多智能体失效**：$r$ 与 $s'$ 都取决于**别人的动作**。别人策略一变，同样的 $(s,a)$ 会导向不同的 $r, s'$——你的 Q 表目标自己就在漂移，`max` 项不再是「环境固有的最优」，而是「在别人当前策略下的最优」。于是更新朝着移动的靶子射击，收敛保证荡然无存。<span class="marginnote">一句话：Q-learning 的收敛证明依赖「环境的转移与奖励是固定的马尔可夫过程」，而多智能体里它们随他人策略漂移——这是所有独立学习法失效的共同根源。</span>

## 4 经典多智能体学习算法

面对非平稳性，经典 MARL 发展出几条路线：<span class="marginnote">这些算法在 Shoham & Leyton-Brown 教材第7-8章有系统整理。核心思想：要么显式建模他人的策略，要么把博弈论解概念当作学习目标。</span>

**独立 Q 学习（independent Q-learning）**：每个智能体跑自己的 Q-learning，把别人当环境。简单、可扩展到大规模，但无收敛保证——实践中在相对稳定的场景里「够用」。

**虚构对局（fictitious play）**：每个玩家把对手的历史行动频率当作其混合策略估计，再针对该估计取最优回应。在两人常和博弈等条件下收敛到纳什均衡——它是「把对手建模成经验分布」的经典范式。<span class="marginnote">虚构对局的直觉很朴素：我记录你历史上每种招式的出现频率，然后最优应对「平均的你」。它揭示了「学习 = 建模对手 + 最优应对」这一 MARL 基本配方。</span>

**minimax-Q**：在**零和博弈**里，把对手当作「最小化我收益」的敌对者，用 minimax 算子替换 Q-learning 里的 `max`——专门面向对抗场景，有收敛保证。<span class="marginnote">minimax-Q（Littman, 1994）是 MARL 理论奠基作之一：它在两人零和随机博弈里证明收敛。对抗安全、游戏 AI 里至今沿用这个「假设最坏对手」的思路。</span>

**Nash-Q**：把学习目标定为**纳什均衡价值**——不只学自己的 Q，还联合估计所有玩家的 Q，再求均衡。理论上优雅，但需要观测他人动作、且均衡不唯一时难以选择。

**辨析｜易错点：** 经典 MARL 的「均衡」与博弈论的「均衡」是两回事。博弈论均衡是**给定静态博弈**的解；MARL 的收敛目标是**学习过程中**是否逼近均衡——两者有关联但不相等。一个学出来的「均衡策略」未必是博弈论意义上唯一的均衡。

### 一个最小例子：剪刀石头布的独立学习

用最简单的例子体会非平稳性的滋味：两个智能体反复玩剪刀石头布，各自用独立 Q 学习（把对手当环境）。设石头、剪刀、布为三个动作，赢 +1、平 0、输 −1。

若对手的策略固定为「永远出石头」，独立 Q 学习很快学会「永远出布」，长期收益 +1——单智能体逻辑完美工作。但一旦对手也在学习，它也会发现「对手总出布」而转向「出剪刀」；于是你发现「出布」开始输，又转向「出石头」……策略进入永动的「石头—剪刀—布」循环。

这个例子一针见血地展示：**当双方都在学习，环境每一轮都在变，「最优策略」是一个追不上的移动目标**。固定策略 vs 学习对手会得到截然不同的行为——这正是为什么 MARL 需要比「把别人当环境」更高级的工具（建模对手、CTDE、均衡目标）。理解了这个三动作小博弈，你就握住了整个 MARL 非平稳性问题的直觉内核。

## 5 深度 MARL：用网络替代表格

经典 MARL 受制于**状态-动作空间爆炸**与**无法处理连续/高维观测**。深度 MARL（Deep MARL）用深度神经网络做价值/策略函数，并结合**中心化训练—分布式执行（CTDE, Centralized Training with Decentralized Execution）** 突破瓶颈：<span class="marginnote">CTDE 是深度 MARL 最具影响力的设计范式：训练时可以共享全局信息（中心化），部署时每个智能体只用自己的局部观测（分布式）。它绕开「非平稳性」的一个办法是——训练时给每个智能体喂别人的信息，让它学到的局部策略已经隐式兼容队友。</span>

代表方法：<span class="marginnote">这一节只需建立印象，具体推导见《强化学习》专题的多智能体部分。三家代表：MADDPG（连续动作）、QMIX（集中式 Q 混合）、COMA（反事实基线）。</span>

**MADDPG（Multi-Agent DDPG）**：演员-评论家架构，**评论家**用全体智能体的观测与动作做价值估计（中心化），**演员**只用自己的观测选动作（分布式）。适合连续动作的对抗/协作混合场景。

**QMIX**：集中式训练一个**混合网络**，把各智能体的局部 Q 值**单调混合**成全局 Q 值，保证「局部贪心 = 全局贪心」——适合完全协作的团队任务。

**COMA**：用**反事实基线（counterfactual baseline）**解决**信用分配**问题——团队打得好，功劳是谁的？它用「如果这个智能体做了别的动作会怎样」作为基线，把团队奖励拆到个体。

深度 MARL 的工程难点同样突出：**非平稳性依旧**（CTDE 缓解但不能根除）、**信用分配**难、**探索**在联合动作空间里指数变难、**训练不稳定**。但它已经在星际争霸、Dota、多机器人协作中做出超越人类的表现——是当前 MAS 最活跃的前沿。

## 6 核心对比：经典 MARL 与深度 MARL

| 维度 | 经典 MARL | 深度 MARL |
| --- | --- | --- |
| 函数表示 | 表格（Q 表） | 深度网络 |
| 状态空间 | 离散、小规模 | 高维/连续 |
| 核心思想 | 博弈论解概念（均衡/minimax） | CTDE、函数近似 |
| 代表方法 | 独立 Q、虚构对局、minimax-Q、Nash-Q | MADDPG、QMIX、COMA |
| 非平稳处理 | 建模他人策略/均衡目标 | 中心化训练兼容 |
| 落地场景 | 小规模博弈、抽象模型 | 游戏 AI、机器人、交通 |

**核心术语速查**：

| 术语 | 一句话定义 |
| --- | --- |
| 非平稳性 | 环境的转移与奖励随他人策略漂移 |
| 独立 Q 学习 | 每个智能体把别人当环境跑 Q-learning |
| 虚构对局 | 用对手历史动作频率作估计、取最优应对 |
| Minimax-Q | 零和博弈里假设最坏对手的价值学习 |
| CTDE | 中心化训练、分布式执行，兼顾信息与部署 |
| 信用分配 | 团队结果如何归因到每个智能体的贡献 |
| 反事实基线 | 「如果这个动作换成别的会怎样」作为归因基准 |

## 7 小结

- **学习动机**：规则写不出来、对手会变、环境未知——写策略不如学策略。
- **非平稳性是 MARL 的核心难题**：转移概率随他人策略漂移，单智能体收敛保证失效。
- **Q-learning 的失效**：$Q \leftarrow Q + \alpha[r + \gamma \max_{a'} Q(s',a') - Q]$
