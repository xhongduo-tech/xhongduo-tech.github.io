## 为什么从电离开始

质谱测量的是质荷比（$m/z$），但质谱仪里的真空环境与中性分子互不感应——**分子必须先在电离源里带上电荷，才能被电场驱动、被质量分析器按质荷比分选。** 电离是质谱所有信息的第一道闸门：电离效率直接决定灵敏度，电离方式决定「什么分子能测」。<span class="marginnote">代谢组学最常用的两大常压电离源是电喷雾（ESI）与大气压化学电离（APCI）。它们都是「软电离」——不像电子轰击（EI）那样把分子打得粉碎，而是尽量保留完整的分子离子，这对鉴定代谢物至关重要。</span>本节拆解 ESI 与 APCI 的机制，讲清它们各自擅长什么分子，以及为什么「同一个实验室两种源都要有」。

## 1 电喷雾电离（ESI）：溶液里的离子搬运工

**电喷雾电离（electrospray ionization, ESI）**把溶液中的离子直接「搬」进气相。其过程分四步：

1. **喷雾（nebulization）**：含分析物的溶液流经细管，管端施加高电压（2–5 kV），强电场使液体表面带电，形成**泰勒锥（Taylor cone）**，锥尖喷射出带电荷的微小液滴。
2. **去溶剂（desolvation）**：干燥气体与加热辅助，液滴中溶剂不断蒸发、体积缩小。
3. **库仑爆炸（Coulomb fission）**：液滴电荷密度随蒸发增大，达到**瑞利极限**后静电排斥超过表面张力，液滴分裂成更小的带电液滴。
4. **气相离子生成**：反复蒸发-分裂，最终分析物以**去溶剂化的气相离子**（如 $\ce{[M+H]+}$、$\ce{[M-H]-}$）进入质谱。

**关键事实：ESI 测的是「溶液中已存在的离子或易质子化分子」。** 氨基酸、核苷酸、有机酸、多肽等极性、可电离化合物是 ESI 的主场。ESI 的离子化效率与溶液条件高度相关：pH 决定质子化/去质子化方向，有机相比例影响去溶剂效率，盐浓度影响离子抑制。

## 2 公式解析：瑞利极限

液滴稳定性的临界条件由**瑞利极限（Rayleigh limit）**给出。设液滴半径 $r$、表面电荷 $Q$、溶剂表面张力 $\gamma$，则液滴分裂的临界电荷为：

$$
Q_{\text{Rayleigh}} = 8\pi\sqrt{\varepsilon_0\,\gamma\, r^{3}}
$$

- $\varepsilon_0$：真空介电常数。
- $\gamma$：溶剂表面张力（水很高，因此水液滴更稳定、更难分裂）。
- $r$：液滴半径，随蒸发不断缩小。

对这条式子做三步拆解：

- **第一步，读出量纲关系**：$Q_{\text{Rayleigh}} \propto r^{3/2}$。液滴越小，能稳定携带的电荷越少——所以蒸发是必须的：只有体积缩小，电荷密度才能逼近极限。
- **第二步，理解库仑爆炸的必然性**：一旦液滴电荷超过 $Q_{\text{Rayleigh}}$，表面张力撑不住静电斥力，液滴必须分裂。这个「分裂—蒸发—再分裂」的循环就是 ESI 把离子逐级浓缩到气相的根本机制。
- **第三步，联系实验参数**：加辅助加热、提高干燥气流速，都是为加快蒸发、更高效地逼近瑞利极限；而水的表面张力大、难蒸发，所以 LC-MS 流动相总要用高比例有机相帮助去溶剂。<span class="marginnote">这解释了一个反直觉现象：纯水溶液反而不利于 ESI——水既难蒸发又表面张力大。流动相里甲醇/乙腈比例越高，去溶剂越顺利、离子化效率越高。这也是 LC-MS 方法开发时「有机相比例」常被优先调的原因。</span>

## 3 大气压化学电离（APCI）：气相化学反应的接力

**大气压化学电离（atmospheric pressure chemical ionization, APCI）**走的是另一条路：分析物**先气化，再在气相中被化学电离**。

1. **气化**：溶液经雾化管喷入加热区（400–500°C），溶剂与分析物瞬间气化。
2. **电晕放电**：针电极施加高电压，产生电晕放电，生成初级反应离子（由流动相分子如 $\ce{N2+}$、$\ce{H3O+}$ 等）。
3. **化学电离**：初级离子与分析物分子发生**质子转移**等气相离子-分子反应，生成 $\ce{[M+H]+}$。

APCI 擅长**中等极性到弱极性**、可气化且热稳定的化合物：脂质、类固醇、维生素、多环芳烃等。它不依赖分析物在溶液中的电离能力，因此对 ESI 难电离的分子往往更有效。

**辨析｜易错点：** 初学者常以为「APCI 是 ESI 的加强版」。实际上两者机制完全不同：ESI 是「溶液离子 → 气相离子」的直接搬运，APCI 是「中性分子 → 气相质子转移」的化学电离。对强极性、热不稳定分子，APCI 的高温气化反而会使其降解；对弱极性分子，ESI 又常常离子化不足。**二者互补，不是替代。**

## 4 核心对比：ESI 与 APCI 怎么选

| 维度 | ESI | APCI |
| --- | --- | --- |
| 离子化机制 | 溶液离子直接喷入气相 | 气化后气相化学电离 |
| 适用极性 | 极性、可电离 | 中等～弱极性 |
| 适用分子量 | 大（可到蛋白） | 小到中等（<1500 Da 更佳） |
| 热稳定性要求 | 低（室温附近） | 高（需加热气化） |
| 多电荷 | 可生成多电荷离子 | 基本单电荷 |
| 典型化合物 | 氨基酸、有机酸、核苷、多肽 | 脂质、类固醇、维生素、PAH |
| 基质效应 | 明显（离子抑制） | 相对较轻 |

**重点：许多代谢组学方法把 ESI 设为默认、APCI 作为补充。** 正离子模式 ESI 测碱性与中性可质子化分子，负离子模式测有机酸等酸性分子；对 ESI 死活电离不出的弱极性分子，才切换到 APCI。一个完整平台往往正负模式各跑一遍，必要时再补 APCI。

## 5 电离带来的挑战：基质效应

无论 ESI 还是 APCI，常压电离源都共享一个难题：**基质效应（matrix effect）**。共洗脱的基质成分（盐、磷脂、未气化的蛋白）会干扰分析物的电离，导致信号增强或**离子抑制（ion suppression）**。

**离子抑制**的直接后果：相同浓度的代谢物，在不同基质背景下信号强度不同——定量失真。应对策略包括：

**色谱分离**：让目标物与基质成分在时间上分开（改善选择性）。
**前处理净化**：SPE、LLE 去除磷脂等强抑制物（见《代谢物提取与化学衍生化》）。
- **同位素内标**：与目标物同步受抑制，校正效应。
- **稀释进样**：基质效应随浓度非线性，适当稀释可减轻。

## 6 电离源的选择与调试实战

电离源的选择看似「仪器问题」，实则是「方法学决策」。实战中的判断顺序：

**第一步：按分析物极性对号入座。** 强极性/可电离/大分子 → ESI；中等极性、弱极性、热稳定 → APCI；非极性到中等极性 → 也可试 APPI（大气压光电离）。不确定时，**正负模式各跑一遍 ESI 预扫描**——多数化合物至少在一个极性下可电离。

**第二步：用标准品调源参数。** 用代表性标准品（含目标物类别）做调谐：喷雾电压、离子源温度、雾化气/干燥气流速、碰撞能量。目标不是「信号最强」，而是「信号稳定 + 加合物可控 + 碎片可控」。

**第三步：控制加合物。** 流动相加甲酸/乙酸铵等添加剂，把电离引导到单一主离子（如 `[M+H]+`），减少 `[M+Na]+`、`[M+NH4]+` 等加合物的分散。**一个代谢物若以五种加合物形式出现，灵敏度被摊薄五份。**

**第四步：做基质效应检查。** 用「后提取加标法」：把标准品加到提取后的空白基质里，与纯溶剂标准品对比信号——比值越接近 100%，基质效应越小。若抑制严重，改色谱、改前处理或换离子源。

**一个实用判据**：同一化合物 ESI 与 APCI 都能电离时，优先 ESI（软、适合大分子与热不稳定物）；ESI 信号太弱或抑制严重时，换 APCI 对比——**以实测数据而非直觉决定电离源**。

<span class="marginnote">一个反直觉的事实：离子源的「参数窗口」比想象中宽——偏离最优参数 20–30% 通常仍能工作，只是灵敏度略降；但<strong>加合物分布对流动相组成极其敏感</strong>。因此调源时先固定流动相，再调源参数，顺序不能反。</span>

**辨析｜易错点：** 不要把「正离子模式 ESI 测不到」直接判定为「这化合物测不了」——可能负离子模式信号极强，也可能 APCI 是正解。**电离源选择是一个搜索过程，不是一次定论。**

## 7 思考与延伸

**自测问题：**

1. 瑞利极限 $Q = 8\pi\sqrt{\varepsilon_0 \gamma r^3}$ 中，为什么水的表面张力大会让液滴更难分裂？这如何解释 LC-MS 流动相要用高比例有机相？
2. ESI 与 APCI 的机制差别是什么？为什么「APCI 是 ESI 的加强版」是一个错误直觉？
3. 离子抑制的后果是什么？色谱分离、前处理净化、同位素内标三种对策各自从哪个环节入手？
4. 正离子模式测不到，下一步应该试什么？为什么说「电离源选择是一个搜索过程」？

<span class="marginnote"><strong>自查练习</strong>：选三种代谢物（如谷氨酸、胆固醇、胆酸），判断它们在正/负 ESI 与 APCI 下的电离前景——做完你就有了「对号入座」的直觉。</span>

**延伸阅读**：离子抑制是《LC-MS 分析流程》与《质控》反复出现的主题——把本节机制带回去，理解为什么 QC 与内标必不可少。

## 8 小结

- 电离是质谱第一道闸门：电离效率决定灵敏度，电离方式决定可测分子范围。
- **ESI** 四步走：泰勒锥喷雾 → 去溶剂 → 库仑爆炸 → 气相离子；擅长极性、可电离分子。
- **瑞利极限** $Q = 8\pi\sqrt{\varepsilon_0\gamma r^3}$
