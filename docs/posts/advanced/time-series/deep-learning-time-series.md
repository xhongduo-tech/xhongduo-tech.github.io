## 为什么从深度学习开始

本专题的收尾交给深度学习，因为它站在一条十字路口上：LSTM 与 Transformer 在自然语言与图像上称王，也自然而然地被请进了时间序列预测。但你得先听懂一个反直觉的事实——**深度学习不是自动胜过 ARIMA/ETS**：在多数业务序列（样本小、结构简单）上，经典方法依然占优；深度学习真正的优势在「数据量大、依赖结构复杂、需要跨特征融合」的场景。<span class="marginnote">Hyndman 教材第 12 章明确给出这一判断：深度学习时序的适用条件是「数据充足 + 复杂非线性依赖 + 多变量/多特征」。M4 竞赛里纯统计模型与纯深度模型互有胜负，融合模型才笑到最后——这本身就是最好的实证。</span>

从课程坐标看，这是「从极限到大模型」主线的又一次交汇：你在这里见到的**注意力机制**，正是大模型世界的同一件武器，只是被征用到了预测任务里。

## 1 循环神经网络与梯度消失

经典 **RNN** 逐时间步共享权重：$h_t = \tanh(W_h h_{t-1} + W_x x_t + b)$。它把「历史」压缩进隐藏态 $h_t$，天然是时序的——但训练时误差要通过**时间反向传播（BPTT）**回传，权重在几十步里反复相乘，**梯度要么爆炸要么消失**，长依赖（比如「三个月前的那个异常影响了今天」）根本学不到。<span class="marginnote">梯度消失的本质是「乘积的收敛/发散」：连续矩阵相乘，谱半径小于 1 就指数萎缩，大于 1 就指数爆炸——这跟上一节 VAR 平稳性的特征值判据是同一个数学内核，只不过这次发生在梯度上。</span>LSTM 正是为对抗梯度消失而设计的。

## 2 LSTM：用「门」控制记忆

**长短期记忆网络（LSTM）** 的核心发明是一条**细胞状态 $C_t$** 高速公路，信息可以在它上面直通而几乎不衰减；三个「门」负责决定写什么、留什么、放什么出来：

$$f_t = \sigma(W_f[h_{t-1}, x_t] + b_f), \qquad i_t = \sigma(W_i[h_{t-1}, x_t] + b_i), \qquad o_t = \sigma(W_o[h_{t-1}, x_t] + b_o)$$

$$\tilde{C}_t = \tanh(W_C[h_{t-1}, x_t] + b_C), \qquad C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t, \qquad h_t = o_t \odot \tanh(C_t)$$

直觉读法：**$f_t$ 是「忘掉多少」，$i_t$ 是「写入多少」，$\tilde C_t$ 是「候选的新信息」，$C_t$ 是「旧记忆 × 忘记比例 + 新信息 × 写入比例」**，$o_t$ 决定把细胞状态「放出多少」当输出。<span class="marginnote">三个门都经过 sigmoid（输出在 0–1），相当于对「记忆操作」做软开关；细胞状态的加性更新让梯度可以沿 $C_t$ 高速路一路畅通，从而学到几十步外的依赖。</span>

**Seq2Seq 结构**把 LSTM 组织成「编码器 → 解码器」：编码器把整个历史压缩成最后一个隐藏态，解码器逐时刻生成未来——这与我们在 GARCH、卡尔曼里「先吸收历史再外推」的思想一脉相承，只是「压缩历史」的方式换成了可学习的循环。

## 3 公式解析：自注意力——把「对齐」变成可学习

Transformer 干脆取消循环，让每一步输出都直接对**所有历史时刻**做加权求和——这就是**自注意力（self-attention）**：

$$
\text{Attention}(Q, K, V) = \operatorname{softmax}\!\left(\frac{Q K^\top}{\sqrt{d_k}}\right) V
$$

拆解四个符号：

- **$Q, K, V$**：查询、键、值。把每个时间步的表示投影成三份：$Q$ 问「我在找什么」，$K$ 说「我代表什么」，$V$ 是「我给出的内容」。三者都是输入经不同权重矩阵得到的。
- **$QK^\top$**：查询与键的点积矩阵，衡量「每个时刻对每个时刻的对齐程度」——即「该把注意力分给谁」的原始分数。
- **$\sqrt{d_k}$**：缩放因子，$d_k$ 是键向量的维度。点积随维度增大而膨胀，除以 $\sqrt{d_k}$ 把方差拉回可控范围，避免 softmax 落入饱和区、梯度消失。
- **$\operatorname{softmax}(\cdot)$**：把每行分数归一化成概率（和为 1），即「注意力权重」；再乘 $V$ 得到加权输出——**输出就是「按关注度加权的内容」**。

对照读法：**自注意力 = 让每个时刻自由地「检索」所有历史，权重由数据学习**。循环网络是「被迫依次传递信息」，注意力是「直接跳转、按需取用」。时间序列天然需要这种能力：预测今天的销量，最该参考的可能不是昨天，而是**去年同期的促销日**——这样的「跳跃对齐」正是注意力最擅长的事。<span class="marginnote">Transformer 里「位置」本身用<strong>位置编码</strong>（正弦函数或可学习向量）注入，因为注意力对顺序不敏感——这一点与《季节性分解》里季节指数「按位置记忆规律」是同一思路的深度学习版。</span>

## 4 深度时序模型的实战纪律

深度学习时序想打得赢，纪律比网络结构更重要。四条铁律：

**数据量是前提**。深度模型参数多、饥渴数据，通常需要数千到上万样本才显出优势；几百个点的小序列，ETS/ARIMA 依然是你最好的朋友。一个可操作的经验界限：单变量序列少于约 1000 期、又没有跨序列共享信息可借，先别上深度模型；多变量/多序列（如几百家门店的销量共享一套网络参数）时，深度模型才靠「借力」赢得优势。

**预处理三件套**：归一化（深度学习对输入尺度极敏感）、处理缺失值、必要时做**差分**——把非平稳抹平（直接借用了本专题《平稳性与单位根检验》的工具，不少实现里差分红是标配）。<span class="marginnote">差分在这里的作用没有变：深度学习与 ARIMA 一样学不会「无限趋势」，把 $y_t$ 换成 $y_t - y_{t-1}$ 常常是误差减半的捷径。</span>

**评估必须 walk-forward**：上一节的滚动预测原点是唯一公平的验收方式，在深度学习里尤其重要——训练/测试切分的偶然性会随随机初始化被放大。

**与经典方法对照**：任何深度方案都要和 ETS/SARIMA 基线比 MASE。学术界与工业界的共同结论是：**「经典方法 + 深度特征」的混合方案，往往强过纯深度方案**——正如 M4 竞赛的冠军组合。

关于训练本身还有三条小事，常被低估却往往决定成败：**学习率与批大小**通常比网络结构更影响最终误差；**提前停止（early stopping）**必须在验证集（而非测试集）上判断；**随机种子**要多跑几次看方差——深度模型的结果有随机性，单次跑赢基线不算数，要看分布。这三条做好了，模型的「真实水平」才不会被训练噪声掩盖。

数据准备还有一个深度时序特有的环节——**滑窗切分（windowing）**：把序列切成「长度为 $W$ 的输入窗口 → 长度为 $h$ 的输出窗口」的样本对，训练集就是全体滑窗。窗口长度 $W$ 是重要超参数：太小装不下季节性（把 $W$ 设成季节周期的整数倍几乎是约定俗成），太大则样本数骤减、训练变慢。切分时务必保证**滑窗不跨「训练/验证」分界**——这一步的粗心是时序泄漏最常见的入口，比模型结构错误更难排查。

**辨析｜易错点：** 两个高频坑。其一，**把测试集写进训练**：时序泄漏（用未来信息训练）会让指标好看得离谱，但上线即翻车；窗口切分必须严格「过去 → 未来」。其二，**忽略不确定性**：LSTM 默认只给点预测，若要预测区间须配合分位数损失或 MC dropout——否则你连「该不该信这个预测」都不知道。

### 注意力权重的数值例子

用 3 个时刻把「注意力怎么分」算给你看。设历史两个参考值：$x_1 = 0.2$（普通日的销量，键 $k_1 = 0.3$）与 $x_2 = 1.0$（去年同期促销日的销量，键 $k_2 = 1.2$）；今天的查询 $q = 0.9$（「我在寻找与今天相似的日子」）。取 $d_k = 1$，打分 $q\cdot k$：$0.9\times0.3 = 0.27$ 与 $0.9\times1.2 = 1.08$。进 softmax：

$$\text{权重} = \frac{e^{0.27}}{e^{0.27}+e^{1.08}},\ \frac{e^{1.08}}{e^{0.27}+e^{1.08}} \approx 0.31,\ 0.69$$

输出 $= 0.31\times 0.2 + 0.69\times 1.0 = 0.73$。读一下：**模型把约 69% 的注意力压给了「去年同期促销日」**，输出被它主导——这正是注意力在时序里的用武之地：预测今天的销量，该重点参考的不是普通历史，而是「结构与今天相似的过去」。缩放因子 $\sqrt{d_k}$ 的意义也在此刻浮现：若 $d_k$ 很大，打分不加缩放会膨胀到 softmax 饱和区，权重退化成一盆浆糊，除以 $\sqrt{d_k}$ 把分数拉回合理范围。

实际使用的注意力常是**多头（multi-head）**的：并行跑 $H$ 组 $(Q,K,V)$，每组学习一种「对齐模式」——一组看「去年同期」，另一组看「最近三天」，输出拼起来。这就是「注意力不只有一种关注方式」的工程化表达，也是它比单一加权平均表达力更强的来源。代价是计算复杂度随序列长度 $L$ 平方增长（$O(L^2)$），长序列上要靠稀疏注意力或滑动窗口来救场——这正是「Informer 等变体」的优化动机。

### 深度时序模型动物园

在 LSTM 与 Transformer 之外，还有一批值得认识的选手。**TCN（时间卷积网络）**：用扩张因果卷积取代循环，训练可并行、梯度更稳，在不少基准上追上 LSTM。**N-BEATS**：纯全连接 + 残差堆叠，把「基础」与「趋势/季节」分解为可解释的块，在 M4 竞赛中大放异彩——它的结构灵感与《季节性分解》一节的趋势/季节二分法一脉相承。**Informer 等时序 Transformer 变体**：针对长序列预测优化注意力复杂度，处理「极长历史」的依赖。选型经验：数据量中等且要可解释，先试 N-BEATS；序列特别长，试 Informer；多步预测要求高稳定性，TCN 与 LSTM 都值得留作对照。<span class="marginnote">这条「从 N-BEATS 的分块思路到分解理论」的暗线说明：深度学习时序的不少成功，恰恰来自把经典时序的结构直觉（趋势、季节、周期性）织进网络架构——经典与现代并非敌人。</span>

### 一个实战对照表

| 场景 | 首选方案 | 原因 |
| --- | --- | --- |
| 样本 < 1000，单变量 | ETS / SARIMA | 参数少、不饥饿、预测区间成熟 |
| 多变量、非线性、数据充足 | LSTM / Transformer | 能学跨变量复杂依赖 |
| 超长历史依赖 | 时序 Transformer 变体 | 注意力直接跳跃对齐 |
| 可解释 + 基准赛 | N-BEATS | 分块结构自带解释 |

**辨析｜易错点：** 最后一关提醒——**无论选哪个深度模型，都要用上一节的 MASE 对 ETS/SARIMA 基线打分**。深度学习在时序上「赢了」的结论，几乎总是建立在「基线调得不够好」的基础上；M4 与 Makridakis 系列竞赛反复证明，认真调过的统计基线能赢下大半比赛。

### 多步预测的策略：递归、直接与多输出

深度时序预测要预测未来 $h$ 步，有三种做法，选择直接影响误差累积方式：

**递归（recursive）策略**：只训练「一步预测器」，把上一步的预测当输入喂回模型。实现最简单，但误差会**逐期累积**——一步的偏差在第 2 步被放大，第 $h$ 步可能面目全非，尤其当预测被喂回自身时，模型会「越走越偏」。

**直接（direct）策略**：为每个步长训练独立的模型（$\hat y_{t+1}, \hat y_{t+2}, \dots, \hat y_{t+h}$ 各一个），步长之间不传染误差，但代价是 $h$ 个模型、训练成本高，且割裂了步长之间的依赖。

**多输出（MIMO）策略**：一个模型同时输出未来 $h$ 步的向量，用专门的输出头与损失函数学习「未来路径」的整体形态——现代时序 Transformer（如 Informer）与 seq2seq 的主流做法。<span class="marginnote">三类策略的取舍，本质是在「误差传染」与「模型复杂度/信息共享」之间做权衡。经验：噪声大的短序列用递归省事，形态重要（如库存补货曲线）用 MIMO。经典统计那边同样存在等价选择——多步评估时 ARIMA 用闭式递推，ETS 用状态递推，只是「策略」这个名词常为深度学界专用。</span>

**辨析｜易错点：** 无论哪种策略，**训练时的输入绝不能混入未来观测**——递归策略训练「一步预测器」若用未来的 $y$ 做输入，就是时序泄漏；而直接策略的「每个步长独立模型」若共享同一份含未来的特征，同样泄漏。泄漏在时序深度学习里的隐蔽性远高于经典方法（特征工程给的「便利」最多），是上线翻车的第一大来源。

## 5 小结

- 深度学习时序的适用条件是**数据充足 + 复杂非线性依赖 + 多特征**；小数据业务序列上 ETS/ARIMA 依然占优。
- **RNN 的梯度消失**本质是连乘收缩，**LSTM 用细胞状态高速路 + 三个门**对抗它，从而学到长依赖。
- **自注意力** $\operatorname{softmax}(QK^\top/\sqrt{d_k})V$ 让每个时刻直接检索所有历史，权重由数据学习——这是大模型世界里同一件武器。
- 深度时序的实战纪律：**数据量前提、预处理差分、walk-forward 评估、与经典基线对照**。
- 混合方案（经典 + 深度）在 M4 等竞赛中反复夺冠——深度学习是扩展件，不是替代品。
- **多步预测**三策略（递归/直接/多输出）在「误差传染」与「信息共享」之间权衡；无论选哪种，训练输入严禁混入未来观测。

到此，我们走完了时间序列分析的主干：从 ARIMA 与 SARIMA 的经典建模，到单位根与协整的理论地基，到 VAR、GARCH、状态空间的系统化框架，再到 ETS 与深度学习的现代前线。这十篇博文已经把你训练成一个能「先看数据、再选模型、后用评估验收」的时序工程师——而「从极限到大模型」的下一程，正等着你把这套时间感带进更广阔的世界。
