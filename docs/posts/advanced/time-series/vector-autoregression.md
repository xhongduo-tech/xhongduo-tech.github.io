## 为什么从 VAR 开始

前五篇研究的都是一个或两个变量。但真实世界是一个系统：利率影响房价，房价影响消费，消费又反馈利率。单方程模型无法刻画这种**双向反馈**，于是我们需要一个让所有变量「互为解释变量」的框架——这就是 **VAR（向量自回归）**。<span class="marginnote">VAR 由 Sims 在 1980 年提出，直接导致宏观计量从「大方程组结构模型」转向「让数据自己说话」的简约式（reduced-form）路径。Hamilton 教材第 11 章整章讨论 VAR 及其识别。</span>

在课程坐标里，VAR 是协整的多变量升级版，也是所有现代宏观计量与金融实证的骨架；它还用上了第三级线性代数的全部家伙——矩阵、特征值、逆矩阵。理解了 VAR，你就理解了「如何用一个系统的视角做预测」。

## 1 VAR(p)：把 p 阶 AR 推广到向量

**向量自回归（Vector Autoregression, VAR）** 让 $n$ 个变量的滞后值互相解释。$p$ 阶 VAR 记作 VAR(p)：

$$y_t = c + A_1\, y_{t-1} + A_2\, y_{t-2} + \cdots + A_p\, y_{t-p} + u_t$$

其中 $y_t$ 是 $n$ 维列向量，$A_i$ 是 $n\times n$ 系数矩阵，$c$ 是常数向量，$u_t$ 是 $n$ 维白噪声（可同期相关，但跨期不相关）。<span class="marginnote">与单变量 AR 的对照很整齐：单变量里 $\phi_i$ 是标量，这里换成矩阵 $A_i$；矩阵第 $i$ 行第 $j$ 列的元素，就回答「$y_{j}$ 的滞后值对 $y_{i}$ 的当期值有多大影响」。</span>

VAR(p) 的优点和代价一样醒目：**优点**是不需要预设「谁解释谁」，所有反馈关系全部由数据决定；**代价**是参数爆炸——$n$ 个变量 $p$ 阶就有 $n^2p$ 个系数，四个变量三阶就 48 个参数，样本不够时会疯涨。控制参数的方法包括用信息准则降阶、以及结构简化（如因子模型）。

## 2 稳定性：特征值说的算

VAR 平稳的条件沿用了 AR 的「特征根」逻辑，只是推广到矩阵。定义**伴随矩阵（companion matrix）**，把 VAR(p) 改写成 $\xi_t = A\,\xi_{t-1} + v_t$ 的一阶系统，其中 $\xi_t = (y_t^\top, y_{t-1}^\top, \dots, y_{t-p+1}^\top)^\top$。**VAR(p) 平稳当且仅当伴随矩阵 $A$ 的全部特征值模长小于 1**：

$$\max_i |\lambda_i(A)| < 1$$

这里直接借用了线性代数里「矩阵迭代收敛 ⟺ 谱半径小于 1」的结论：冲击被不断压缩，系统被拉回均值。**辨析｜易错点：** 千万别把 $A_i$ 单个矩阵的特征值当判据——平稳性看的是把它们拼成大伴随矩阵 $A$ 之后整体的谱半径，单看 $A_1$ 会误判。

伴随矩阵的构造本身值得一看：把 $n$ 维 $p$ 阶的 VAR 改写成 $np$ 维一阶系统，伴随矩阵是「第一行放系数 $A_1 \dots A_p$、副对角放单位阵、其余为零」的块状矩阵。这个「高阶降为一阶、单位阵垫位」的技巧，正是第三级线性代数里「把递推写成矩阵迭代」的同一招式——**递推关系与矩阵幂的对应，是贯穿本专题最锋利的工具之一**。谱半径的计算也顺带解释了为什么 VAR 平稳判据比单变量更严格：系统的记忆体现在伴随矩阵的全体特征值上。

## 3 Granger 因果：谁在「先」谁

VAR 能回答的第一个问题就是「谁影响谁」。**Granger 因果（Granger causality）** 定义：若 $y_{2t}$ 的滞后值能显著改善对 $y_{1t}$ 的预测（在控制了 $y_{1t}$ 自身滞后值之后），则称 $y_2$ **Granger 引起** $y_1$。数学上就是检验 VAR 中「$y_2$ 的所有滞后系数同时为 0」——一个标准的联合 $F$ 检验。

**辨析｜易错点：** Granger 因果不等于真实因果。它检验的是「**时序上的预测力**」而非「结构性因果」：天气领先于降雨量，但天气不「导致」降雨。把它理解为「谁的信息先到」更准确。

## 4 公式解析：脉冲响应函数

VAR 最难也最有用的产物是**脉冲响应函数（Impulse Response Function, IRF）**：给某个变量一个单位的冲击，看整个系统在未来各期如何反应。这本质上是 Wold 分解的向量版——把 VAR 写成无穷冲击的加权和：

$$y_t = \mu + \sum_{k=0}^{\infty} \Psi_k\, u_{t-k}$$

其中 $\Psi_k$ 是 $n\times n$ 矩阵，第 $(i,j)$ 个元素 $\psi^{(k)}_{ij}$ 表示「$j$ 变量在 $k$ 期前受到的一单位冲击，对 $i$ 变量当期值的影响」——这就是 IRF。拆解三个要点：

- **$\Psi_0 = I$**：冲击当期只影响自身，这正是向量版 Wold 的起点。
- **递推计算**：从 VAR 系数递推 $\Psi_1 = A_1$，$\Psi_k = A_1\Psi_{k-1} + \cdots + A_p\Psi_{k-p}$，可逐期算出整条响应曲线。
- **识别问题**：$u_t$ 的各分量可以同期相关，单看 $\Psi_k$ 会混入「同搏共振」。实务中常用 Cholesky 分解正交化（对 $u_t$ 的协方差阵做三角分解），把「同期影响」按某种顺序归因——**顺序不同，IRF 就不同**，这是 VAR 结果解读中最微妙的争议点。

## 5 方差分解：谁贡献了预测不确定性

**预测误差方差分解（Forecast Error Variance Decomposition, FEVD）** 回答另一个问题：未来 $h$ 期预测的误差里，各变量的冲击各占多少比例？它对每个预测期把均方误差分解成来自各个冲击源的份额。**如果 $y_2$ 的冲击在 $y_1$ 的预测误差里占 60%，说明 $y_2$ 是 $y_1$ 不确定性的主要来源**——这是比 Granger 检验更「定量」的因果画像。IRF 管「路径」，FEVD 管「份额」，两者合起来构成 VAR 动态分析的左右手。

用上节的例子感受份额：对 $y_1$ 做 $h=5$ 步预测，预测误差的方差来自两条渠道——$y_1$ 自身的冲击，以及经方程 0.3 传入的 $y_2$ 冲击。随着 $h$ 增大，$y_2$ 的份额从 0 逐步爬到某个稳态占比（这里由两股噪声的方差比决定），**「$y_2$ 对 $y_1$ 的长期不确定性贡献」就是 FEVD 在 $h \to \infty$ 时的取值**。这也是「$y_2$ 是 $y_1$ 重要驱动」的定量证据，比 Granger 检验的 0/1 结论更细腻。需要再次强调，FEVD 与 IRF 共享同一个 Cholesky 顺序依赖：**变量排序变化，份额与路径都会变**——稳健的做法是换几种合理顺序看结论是否稳定，结论随顺序翻转时，只报告「先后次序敏感」而不下绝对因果断言。

VAR 的应用边界还值得提醒两点。其一，**VAR 是简约式而非结构式**：它的系数矩阵描述的是「观测层面」的动态关联，不等于经济上的因果方程——要讲因果，必须回到结构 VAR 或引入外生实验。其二，**预测力不等价于模型质量**：BVAR 因先验收缩常常预测更准，但它的「先验」同时压扁了脉冲响应——研究者需要在「预测精度」与「结构解读」之间做取舍，这正是宏观实证里 VAR 与 BVAR 各有一席之地的原因。

### 一个双变量 VAR(1) 的完整小例子

设两变量 $(y_{1t}, y_{2t})$ 的 VAR(1)（$c=0$，无同期相关）：

$$y_{1t} = 0.5\,y_{1,t-1} + 0.3\,y_{2,t-1} + u_{1t}, \qquad y_{2t} = 0.2\,y_{2,t-1} + u_{2t}$$

**系数矩阵** $A_1 = \begin{pmatrix} 0.5 & 0.3 \\ 0 & 0.2 \end{pmatrix}$。先读结构：$y_2$ 的滞后进入 $y_1$ 的方程（0.3），但 $y_1$ 的滞后不进入 $y_2$ 的方程（左下角为 0）——**预测关系是单向的：$y_2$ Granger 引起 $y_1$，反过来不成立**，这正是一个现实经济例子的骨架（如「利率 Granger 引起投资，反之不成立」）。

**稳定性**：$A_1$ 是上三角，特征值就是对角线 0.5 与 0.2，模长都小于 1，系统平稳，冲击会衰减。

**脉冲响应**：给 $y_2$ 一个单位的冲击（$u_{2,1}=1$），看 $y_1$ 在随后各期的反应——即 $\Psi_k$ 的 $(1,2)$ 元素。递推 $\Psi_1 = A_1$，$\Psi_2 = A_1^2$，逐项算出：

| 期 $k$ | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| $y_1$ 对 $y_2$ 冲击的响应 | 0 | 0.30 | 0.21 | 0.117 | 0.065 |

$y_2$ 的冲击经 $y_1$ 方程里的 0.3 传入，随后按 0.5 衰减——**从 0 冲高再回落**，这就是一条完整的脉冲响应曲线。若再对 $u_t$ 的协方差阵做 Cholesky 分解，同期传播路径会变化，但「衰减回零」的定性结论不变。

报告 IRF 时必须同时报告**置信带**——因为 IRF 是参数的非线性函数，置信带用**残差 bootstrap** 构造：从拟合残差里重采样、重估 VAR、重算整条 IRF，重复上千次取分位数。没有置信带的 IRF 曲线就像没有误差棒的实验测量：你只能看出形状，看不出「这条形状是否显著」。实践中经常出现「点估计漂亮、置信带横跨零」的情况——那意味着该冲击实际上没传出去。

### 估计与阶数选择

VAR 的估计出奇地直接：**每个方程单独跑最小二乘**，在误差跨期不相关的假设下，逐方程 OLS 与系统极大似然等价。阶数 $p$ 用信息准则挑：AIC 倾向选较大 $p$（牺牲简洁换拟合），BIC 与 HQ 更节俭。选完阶数还要做**残差诊断**：对每个方程的残差做 Ljung–Box 检验，确认无自相关残留。

变量一多，普通 OLS 就撑不住了：$n=10$、$p=4$ 时每方程 40 个系数，样本一短就「过拟合式爆账」。三条出路：**先降维再 VAR**（主成分/因子）；**参数收缩**（岭回归、弹性网）；**贝叶斯 VAR（BVAR）**——给系数套「越远期影响越小的先验」（Minnesota 先验），把极端估计拉向先验均值。BVAR 如今是宏观预测的主力，因为它用「合理先验」换回了「小样本下的稳定估计」，这正是经典 VAR 的已知短板。

### 结构 VAR：识别才是硬骨头

简约式 VAR 的扰动 $u_t$ 可以同期相关，这导致 IRF 无法唯一确定——**同样的数据，不同正交化顺序给出不同因果解读**。结构 VAR（SVAR）引入经济理论约束（如 Cholesky 的因果顺序、符号约束、长期零约束）来识别「真正的」冲击，是宏观实证里最讲究的一环。<span class="marginnote">一句话概括识别问题的本质：$u_t$ 有 $n$ 个方差协方差参数，而结构冲击有 $n^2$ 个待估参数，需要 $n(n-1)/2$ 个约束来补齐缺口——约束从哪来，正是宏观计量百年争论的焦点。</span>

### 用 VAR 做预测

VAR 的一步预测就是把估计系数套进方程：$\hat y_{t+1} = \hat c + \hat A_1 y_t + \cdots + \hat A_p y_{t-p+1}$；多步预测则把预测值当真实值代回递归外推。与单变量 ARIMA 相比，VAR 的优势是**每个变量都利用了其他变量的滞后信息**——若 $y_2$ 领先于 $y_1$，它的滞后值就能压低 $y_1$ 的预测误差。预测误差方差同样可算：$\hat y_{t+h}$ 的均方误差由冲击协方差与系数逐期累积，这正好是前面 FEVD 的原料——**误差分解的百分比，就是各变量对预测不确定性的贡献清单**。值得注意的是，VAR 预测的效果高度依赖阶数 $p$ 与平稳性：非平稳序列（单位根）直接进 VAR 会有伪回归之忧，正确的做法是差分后建 VAR，或改用下一节的误差修正形式。

### VECM：VAR 与协整的合流

当 VAR 里的变量存在协整时，直接差分会丢掉长期均衡信息，直接跑水平 VAR 又有伪回归风险——**向量误差修正模型（VECM）**是两者的合流：对水平 VAR 做「约束差分」，把长期均衡项保留成显式变量。它以误差修正形式出现，等价于「协整 + 短期动态」的联合估计，其参数结构与上一节 ECM 完全同构，只是从单方程推广到向量。**辨析｜易错点：** VECM 只适用于「变量间确有协整」的情形；若变量都是 $I(0)$，VECM 退化为普通 VAR；若都 $I(1)$ 但无协整，应该差分后再建 VAR。**先做协整检验、再选 VAR 还是 VECM，顺序不能反**——这正是把本专题前几节串起来的枢纽。

### 模型选用对照

把本专题的模型地图收拢成一张案头对照表，实战里按情形取用：

| 情形 | 模型 | 关键点 |
| --- | --- | --- |
| 单变量、平稳或差分后平稳 | ARIMA | Box-Jenkins 识别—估计—诊断 |
| 多变量、互相反馈 | VAR | 平稳看伴随矩阵谱半径 |
| 多变量、存在协整 | VECM | 先协整检验、再决定差分或水平 |
| 多变量、小样本 | BVAR | Minnesota 先验收缩 |

## 6 小结

- **VAR(p)**：$y_t = c + A_1 y_{t-1} + \cdots + A_p y_{t-p} + u_t$，让所有变量互为解释变量，代价是参数爆炸。
- **平稳条件**是伴随矩阵全部特征值模长小于 1——谱半径判据，别只看单个 $A_i$。
- **Granger 因果**检验「谁的滞后能改善预测」，是时序预测力而非结构性因果。
- **IRF**（$\Psi_k$ 序列）刻画冲击的传播路径，正交化顺序会影响结果。
- **FEVD** 把预测误差按冲击来源分解，给出各变量的相对贡献。

在下一节，我们把 VAR 框架用在「波动率」上：股票收益率的均值看似随机，它的**方差**却会聚集、可预测——这就是 **GARCH 波动率建模**。
