## 为什么从 GARCH 开始

前六篇都在建模收益率（或某个序列）的**水平**。但金融资产的收益率水平几乎不可预测（接近随机游走），真正可预测、且能卖出大钱的是它的**波动率**：期权定价、风险管理（VaR）、组合再平衡，全部建立在「明天的波动多大」之上。波动率序列有一个肉眼可见的铁律——**大波动后跟大波动，小波动后跟小波动**，即**波动聚集（volatility clustering）**。<span class="marginnote">Engle 1982 年提出 ARCH，Bollerslev 1986 年推广为 GARCH；Engle 因此获 2003 年诺贝尔经济学奖。Hamilton 教材第 21 章系统处理条件异方差建模。</span>

在课程坐标里，GARCH 是「对残差方差建模」的第一次显式操作：之前我们假设残差是恒定方差的白噪声，GARCH 把这个假设升级为**条件方差是时变的、且可预测的**。它把 ARIMA 的整套「滞后结构」哲学，从均值搬到了方差。

## 1 金融收益率的三个风格事实

任何波动率模型都必须解释三个**风格化事实（stylized facts）**：

**波动聚集**：大波动倾向持续若干期，小波动亦然——收益率的平方（或绝对值）高度自相关，而其本身（水平）几乎不相关。<span class="marginnote">检验波动聚集的最快方法：算收益率平方的 ACF，你会看到它像随机游走一样慢衰减——水平无记忆，平方却有强记忆。这是 ARCH 效应的直接证据。</span>

**厚尾**：收益率分布比正态分布「中间高、两端厚」，极端涨跌出现频率远超正态预测。

**杠杆效应（leverage effect）**：大跌后的波动率上升幅度，大于同幅度大涨后的上升幅度——坏消息的冲击比好消息更猛烈。直觉上的解释是：股价下跌时公司杠杆率（负债/权益）被动抬升，股东承受的风险变大，波动随之放大；反过来上涨则风险被稀释。<span class="marginnote">杠杆效应在 GARCH 基准模型里完全捕捉不到——因为 $\varepsilon_{t-1}^2$ 只记录「幅度」不记录「方向」，这正是 EGARCH 与 GJR-GARCH 存在的理由。</span>

## 2 公式解析：从 ARCH(q) 到 GARCH(p,q)

**ARCH（自回归条件异方差）** 的想法是让方差本身服从自回归。设均值方程 $y_t = \mu + \varepsilon_t$，其中 $\varepsilon_t = \sigma_t\, z_t$，$z_t$ 是标准白噪声，条件方差。用**平方**冲击 $\varepsilon_{t-i}^2$ 而非冲击本身是有意的：方差是二阶矩、天然非负，平方既保证 $\sigma_t^2 \ge 0$，又「抹掉方向」只留幅度——这正是波动聚集只关心「多剧烈」、不关心「涨还是跌」的数学化表达。条件方差

$$\sigma_t^2 = \omega + \sum_{i=1}^{q}\alpha_i\,\varepsilon_{t-i}^2$$

ARCH(q) 让「当期波动」等于「过去 $q$ 期平方冲击」的加权和。它抓住了波动聚集，但实际中需要很大的 $q$ 才能拟合，于是 **Bollerslev 的 GARCH(p,q)** 在方程右边加上方差的滞后项：

$$
\sigma_t^2 = \omega + \sum_{i=1}^{q}\alpha_i\,\varepsilon_{t-i}^2 + \sum_{j=1}^{p}\beta_j\,\sigma_{t-j}^2
$$

拆解 GARCH(1,1)（最常见）的三个符号：

- **$\omega > 0$**：长期基准，常数项；无条件方差 $\operatorname{Var}(\varepsilon_t) = \omega/(1-\alpha-\beta)$ 由它决定。
- **$\alpha \ge 0$**：对「上期新信息」$\varepsilon_{t-1}^2$ 的敏感度——**ARCH 项，管短期的即时反应**。大跌大涨当天 $\varepsilon_{t-1}^2$ 巨大，$\alpha$ 把它放大成当期高波动。
- **$\beta \ge 0$**：对「上期波动水平」$\sigma_{t-1}^2$ 的惯性——**GARCH 项，管波动的持久性**。$\alpha + \beta$ 接近 1 时波动极持久，波动聚集明显；$\alpha+\beta < 1$ 是平稳条件，保证无条件方差有限。

对照读法：**今天的波动 = 昨天的波动惯性（$\beta$） + 昨天新消息的冲击（$\alpha$） + 长期基准（$\omega$）**。$\alpha+\beta$ 被称为波动率的持久性指标，真实金融序列通常高达 0.9 以上——波动聚集之所以难消除，正因为这个和接近 1。GARCH 用很少的参数就抓住了厚尾：$\varepsilon_t = \sigma_t z_t$ 中波动本身随机，等价于残差分布比正态更厚尾。

为什么实务里 GARCH(1,1) 几乎「一统江湖」？因为高阶 GARCH(p,q) 的参数通常相互重叠、难以识别，而 (1,1) 已经能复现全部三个风格事实。经验法则是：**除非残差检验明确不满意，否则从 (1,1) 起步、不轻易升级**——这与信息准则里「用最少的参数解释最多的现象」是同一个原则。

## 3 估计与检验

GARCH 的参数用**极大似然估计（MLE）**：在 $z_t$ 服从正态（或学生 $t$、偏态 $t$，后者更贴合厚尾）的假设下，把条件密度相乘取对数并最大化。常用**学生 $t$ 分布**替代正态，因为正态假设会低估尾部风险——这正是「厚尾」事实对模型选择的直接要求。选择分布时可用似然比检验或信息准则对照：正态与 $t$ 的估计差异不大时选正态更省心；$t$ 显著更优则说明尾部确实厚于正态，风险报告必须以 $t$ 为准。

MLE 的直觉值得点透：给定参数，模型对每一期生成一个条件正态分布，该期观测落在其中的概率即**似然**；把所有期的似然乘起来、取对数，就是我们要最大化的目标。波动大时观测容易落得散、波动小时落得密——**MLE 本质上在问「哪组 $(\omega,\alpha,\beta)$ 最让这些观测像它们自己」**。正因为它拟合的是「条件分布的疏密」，才能同时抓住均值的噪声与方差的聚集。

建模流程与 Box-Jenkins 平行：先估均值方程、用残差平方的 Ljung–Box 检验确认存在 ARCH 效应，再定 GARCH 阶数（通常 (1,1) 就够），最后再检验标准化残差 $z_t = \varepsilon_t/\hat\sigma_t$ 是否已无平方相关——**若 $z_t^2$ 仍显著相关，说明波动没抽干净**。

## 4 GARCH 家族的扩展

GARCH 基准模型有两个被批评的盲点：其一，它把好消息与坏消息对称处理，无法刻画**杠杆效应**；其二，$\alpha+\beta$ 接近 1 时，无条件方差可能不存在（接近 IGARCH 的极端情形）。两个经典扩展：

**EGARCH（指数 GARCH）**：对 $\log \sigma_t^2$ 建模，允许 $\alpha$ 的符号随 $\varepsilon_{t-1}$ 的正负而变——好消息与坏消息的冲击不对称，直接纳入杠杆效应，且对数形式自动保证方差非负。

**GJR-GARCH**：在 GARCH 方程里加一个「只在大跌时激活」的哑变量项，同样实现对不对称性的刻画，实现更简单。

选择基准还是扩展，取决于是否有关心不对称效应的理由（如风险管理偏重下行风险）——若不关心方向，基准 GARCH 的不对称短板不影响使用。**辨析｜易错点：** GARCH 建模的对象是**条件方差**，不是收益率水平；不要用 GARCH 去预测方向，它预测的是「波动幅度」。另注意均值方程里残余的水平自相关必须先清理干净，否则波动方程会吸收均值的信息，误判 ARCH 效应。还要区分 GARCH 与「随机波动率（SV）模型」：SV 让波动率本身带独立噪声，比 GARCH 更灵活但估计更贵——这是往工程前沿再迈一步的方向。

### 手算一条 GARCH(1,1) 的方差路径

设 $\omega=0.2,\ \alpha=0.2,\ \beta=0.7$。先算无条件方差：$\sigma^2_\infty = \omega/(1-\alpha-\beta) = 0.2/0.1 = 2$，这是波动的「引力中心」。初始 $\sigma_1^2 = 2$，收益率为 $\varepsilon_1 = 3$（一个大涨）：

$$\sigma_2^2 = 0.2 + 0.2\times 3^2 + 0.7\times 2 = 0.2 + 1.8 + 1.4 = 3.4$$

大冲击让方差瞬间从 2 跳到 3.4——这就是**波动聚集**的来源。接着 $\varepsilon_2 = 0.5$：

$$\sigma_3^2 = 0.2 + 0.2\times 0.25 + 0.7\times 3.4 = 0.2 + 0.05 + 2.38 = 2.63$$

再看 $\varepsilon_3 = 0.3$：

$$\sigma_4^2 = 0.2 + 0.2\times 0.09 + 0.7\times 2.63 = 0.2 + 0.018 + 1.841 \approx 2.06$$

三条记录拼出一条完整的故事：**大冲击把方差顶上去，随后在 β=0.7 的惯性下逐期回落、逼近长期均值 2**。若此时再来一个大冲击，方差又被顶起——波动在高位与低位之间的「聚集 + 回归」，正是 GARCH 用 3 个参数就捕捉到的全部金融本质。同时注意 $\alpha+\beta = 0.9$：波动持久性很高，回落到均值需要多期，这正是真实金融序列 $\alpha+\beta$ 普遍在 0.9 以上的原因。

### 从方差到风险：VaR 与波动预测

GARCH 的落地场景是风险管理。**一步波动率预测**就是递归一步：$\hat\sigma_{t+1}^2 = \omega + \alpha\varepsilon_t^2 + \beta\sigma_t^2$。有了它，**在险价值（Value at Risk, VaR）** 就能直接写出：

$$\text{VaR}_{t+1}^{95\%} \approx 1.645 \times \hat\sigma_{t+1}$$

含义是「正常情况下，明天亏 1.645 倍波动率以内的概率是 95%」。用学生 $t$ 分布时把 1.645 换成 $t$ 分布的分位数（更厚尾、更保守）。**辨析｜易错点：** VaR 衡量的是**尾部损失**而非平均损失，只报一个分位数会低估极端情形——严谨的汇报还要补上条件尾期望（ES）。另注意波动率预测是**多步扩张的**：$h$ 步预测方差向无条件方差 $\omega/(1-\alpha-\beta)$ 收敛，长期 VaR 不会线性变坏，但也不会比长期均值更乐观。

### 波动率建模的完整顺序

把 GARCH 建模的流程拧成一条可执行的清单：

1. **检验**：先看收益率序列的 ACF——水平无自相关、平方有自相关，是 ARCH 效应的第一证据；再用残差平方的 Ljung–Box 检验或 ARCH-LM 检验正式确认。
2. **建均值方程**：若水平仍有自相关，先建 ARMA/ARIMA 把均值信息抽干净，取残差 $\varepsilon_t$ 作为 GARCH 的输入——**均值方程与方差方程是两段式，先均值后方差**。
3. **定阶与估计**：从 GARCH(1,1) 起步，用 MLE 估计，分布选正态或学生 $t$；对比更高阶与对称扩展，用信息准则选择。
4. **诊断**：检验标准化残差 $z_t$ 与其平方的白噪声性；再检验 $z_t^2$ 对 $z_{t-1}^2$ 等是否仍有解释力——若显著，说明波动结构没描述完整，需要升级模型。

这套顺序与 Box-Jenkins 三步曲平行，只是把「残差」换成了「标准化残差」。**关键一条：均值方程没建干净就进方差方程，是 GARCH 建模最常见的系统性错误**——均值里的结构会伪装成波动聚集。

估计环节还有一个实务细节：GARCH 的似然函数在参数空间里常有多个峰，数值优化要从多个起点出发、对比结果；且**正态假设下的 MLE 即使真实分布不是正态，仍是「拟极大似然（QMLE）」**，系数估计仍一致，但标准误需要用稳健形式（HAC/Bollerslev–Wooldridge 稳健标准误）。一句话：**结论要读系数，显著性要读稳健标准误**——这两条一起守住，GARCH 的估计才不会给出虚高的置信。

## 5 小结

- 金融收益率的三个风格事实：**波动聚集、厚尾、杠杆效应**——任何波动率模型都要能解释它们。
- **ARCH(q)**：$\sigma_t^2 = \omega + \sum\alpha_i\varepsilon_{t-i}^2$，让方差依赖平方冲击的历史。
- **GARCH(p,q)**：再加方差的滞后项，$\sigma_t^2 = \omega + \sum\alpha_i\varepsilon_{t-i}^2 + \sum\beta_j\sigma_{t-j}^2$；$\alpha+\beta$ 是持久性指标。
- 参数用**MLE**估计，厚尾用学生 $t$ 分布；残差 $z_t^2$ 的白噪声检验是模型是否到位的判据。
- **EGARCH / GJR-GARCH** 引入好坏消息的不对称，解决杠杆效应。

在下一节，我们要走出「同一个模型家族」，进入一个可以**统一所有线性模型的通用框架**：把观测方程与状态方程分开写，用滤波递推在线学习——这就是**状态空间与卡尔曼滤波**。
