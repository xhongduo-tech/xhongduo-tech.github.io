## 为什么从状态空间开始

到目前为止，我们学的每个模型（ARIMA、SARIMA、GARCH）都自带一套固定的参数结构。但有一类问题它们处理起来别扭：**被观测的只是系统的「影子」，真正的系统状态不可直接观测**。导弹的位置测不到但能测加速度、GDP 的「真实潜在产出」看不到但能看各种指标、一只基金的「真实特质」看不到但能看到净值。状态空间模型把「系统」与「观测」分开成两层，并用**卡尔曼滤波**逐期递推地估计看不见的那层。<span class="marginnote">卡尔曼滤波由 Kalman 在 1960 年提出，最初用于航天（阿波罗登月导航），如今是工程、金融、计量与信号处理的共同底座。Hamilton 教材第 13 章把它引入时间序列，证明几乎所有线性模型都可写成状态空间形式。</span>

更重要的是，状态空间是**统一框架**：ARIMA、随机游走+噪声、时变系数回归、结构时序模型，全都能写成它的特例。学完这一节，你会获得一把「把新模型翻译成标准结构」的瑞士军刀。

## 1 状态空间表示：两层方程

状态空间模型由两个方程组成。**状态方程（transition equation）** 描述看不见的状态如何随时间演化：

$$\alpha_{t+1} = T\,\alpha_t + \eta_t, \qquad \eta_t \sim \mathcal{N}(0, R)$$

**观测方程（observation / measurement equation）** 描述状态如何被「翻译」成观测：

$$y_t = Z\,\alpha_t + \varepsilon_t, \qquad \varepsilon_t \sim \mathcal{N}(0, H)$$

其中 $\alpha_t$ 是 $k$ 维**状态向量**，$y_t$ 是 $n$ 维观测，$T$ 与 $Z$ 是已知的转移矩阵与输出矩阵，$\eta_t$ 与 $\varepsilon_t$ 是互不相关的高斯白噪声，协方差分别为 $R$ 与 $H$。<span class="marginnote">两个「方程 + 两个噪声」就是全部。状态演化是线性的、观测映射是线性的——线性是高斯的「家」：高斯输入过线性系统仍是高斯，卡尔曼滤波恰好在这种结构下闭式可解。非线性场景（无迹/粒子滤波）就是丢掉了这个方便假设。</span>

两个噪声的职责要分清：**$\eta_t$（状态噪声）刻画「系统自身的演化不确定性」**——它让状态真的在漂移；**$\varepsilon_t$（观测噪声）刻画「测量环节的误差」**——它让观测偏离真状态。一个模型的「信多少观测」之争，本质上就是这两股噪声方差的比值之争，而卡尔曼增益正是这场争论的裁判。

用最朴素的**局部水平模型（local level model）**感受一下：$y_t = \alpha_t + \varepsilon_t$（观测 = 状态 + 噪声），$\alpha_{t+1} = \alpha_t + \eta_t$（状态 = 昨天的状态 + 扰动）。这就是「水平随时间随机游走、观测加噪声」的模型——**它等价于 ARIMA(0,1,1)**，状态空间把 ARIMA 的盒子重新打开了。<span class="marginnote">这个等价关系是全节的彩蛋：Harvey 等证明，任意 ARIMA(p,d,q) 都能改写成状态空间形式。所以学会卡尔曼滤波，等于同时学会了一种更普适的 ARIMA 估计算法。</span>

## 2 卡尔曼滤波：预测与更新

卡尔曼滤波回答的核心问题是：**给定截至当期 $t$ 的所有观测，状态 $\alpha_t$ 的条件分布是什么？** 高斯假设下条件分布仍是高斯，只需递推均值和协方差。每期做两步：

**预测步骤（Predict）**：用上期状态估计外推本期。

$$\alpha_{t|t-1} = T\,\alpha_{t-1|t-1}, \qquad P_{t|t-1} = T\,P_{t-1|t-1}\,T^\top + R$$

**更新步骤（Update）**：当期观测 $y_t$ 到达后修正估计。

$$K_t = P_{t|t-1}\,Z^\top \left(Z\,P_{t|t-1}\,Z^\top + H\right)^{-1}$$

$$\alpha_{t|t} = \alpha_{t|t-1} + K_t\left(y_t - Z\,\alpha_{t|t-1}\right), \qquad P_{t|t} = \left(I - K_t Z\right)P_{t|t-1}$$

![卡尔曼滤波的预测—更新循环](/images/time-series/state-space-kalman-filter-1.svg)

这套两步循环的直觉是一条朴素的认知法则：**先相信「模型的外推」，再用「观测的证据」修正**。初始状态 $\alpha_{0|0}, P_{0|0}$ 给定后，滤波逐期滚动，每期只依赖前一期的估计——**在线、递推、只需存一期**，这是它在导航（每秒都要算）里无可替代的原因。计算量上，每期最贵的是增益里那个矩阵求逆（$n\times n$），复杂度约 $O(n^3)$——对单变量局部水平模型不过是标量除法，而高维系统的实时滤波至今仍是工程研究的课题；数值上还常用**平方根滤波**或 Joseph 形式更新协方差，避免 $P_t$ 因舍入误差失去半正定性。

还有一个被反复确认的「小参数、大用处」：卡尔曼滤波的每一步都同时给出状态估计与其不确定性（$P_t$）——**不确定性本身也是输出**。这使它天然适合风险敏感的应用：导航报告位置的同时报告定位误差，金融模型估期望收益的同时估状态噪声——「不只给你答案，还给你答案的可信度」。

## 3 公式解析：卡尔曼增益 K_t

滤波的灵魂是**卡尔曼增益（Kalman gain）** $K_t$，它决定「该信新观测多少」：

$$
K_t = \underbrace{P_{t|t-1}}_{状态不确定性}\,Z^\top\left(\underbrace{Z P_{t|t-1} Z^\top}_{观测侧的预测误差} + \underbrace{H}_{观测噪声}\right)^{-1}
$$

拆成三块理解：

- **$P_{t|t-1}$**：状态估计的不确定性（协方差），越大越「没把握」。
- **$Z P_{t|t-1} Z^\top + H$**：观测预测误差的方差——「模型的预测 $Z\alpha_{t|t-1}$ 与真实观测 $y_t$ 的差距」有多大，来源一是状态没估准，二是观测本身带噪。
- **$K_t$ 是两者的比值**：状态越不确定（相对观测噪声），$K_t$ 越大，越要用力拽向观测；反之观测噪声极大时 $K_t \to 0$，几乎不信观测、全信外推。

对照读法：**$K_t$ 就是「证据与模型的加权开关」**。更新式里 $y_t - Z\alpha_{t|t-1}$ 是**新息（innovation）**——「观测比模型预测多出来的那部分」，乘以 $K_t$ 就是对状态的修正量。这一修正结构（预测误差 × 增益）与 ECM 的误差修正（上一节 $\alpha\,\hat{u}_{t-1}$）惊人地同构：**「模型认为的偏差」乘以「该信多少」，是时序统计里反复出现的母题**。

## 4 滤波、平滑与预测的分工

同一套状态空间可以回答三类问题，对应三种算法：

**滤波（filtering）**：用截至 $t$ 的观测估计 $\alpha_t$，实时逐期递推——上面讲的卡尔曼滤波。适合在线应用。

**平滑（smoothing）**：用**全部**观测（$T$ 期全部样本）回头估计 $\alpha_t$（$t \le T$）。信息更多，估计更准。常见的是 Kalman 平滑器，从滤波结果倒序回推：先跑一遍正向滤波，再从 $t=T$ 倒着回推，把「未来观测」的信息注入每一期的状态估计。**滤波是「边走边估」，平滑是「看完再改」**——回测与分析历史（如估计真实潜在产出）用平滑，实时决策（如导航、交易下单）用滤波，分工如此。

**预测（forecasting）**：用截至 $t$ 的观测预测 $\alpha_{t+h}$ 与 $y_{t+h}$——滤波的预测步骤直接外推 $h$ 步即得，预测误差方差也可顺带算出，这为「预测区间」提供了现成材料（见《预测评估指标与预测区间》）。

参数估计与滤波咬合得很紧：当 $T, Z, R, H$ 未知时，把它们当作要优化的参数，用滤波输出的**一步预测误差（新息）**构造似然函数——高斯假设下，每个新息是零均值高斯、方差就是滤波里的预测方差，似然是这些正态密度的乘积。于是「滤波给出似然 → 优化参数 → 再滤波」形成闭环，EM 算法与数值优化都可以走这条路。<span class="marginnote">这也是「状态空间能统一估计」的原因：不管模型多复杂，只要写成状态空间，参数的似然都经由滤波自动给出——ARIMA 的 Box-Jenkins 人工定阶，在状态空间里被「似然优化 + 信息准则」自动取代。</span>

**辨析｜易错点：** 三处高频混淆。其一，**滤波 ≠ 平滑**：滤波只吃「过去」，平滑吃了「全部」，用途（在线 vs 离线）完全不同。其二，**把 $T$（转移矩阵）当参数估计**：$T, Z, R, H$ 若未知，需用似然函数（滤波给出的预测误差可直接构造）或 EM 算法估计，滤波本身假设它们已知。其三，**遗忘初值**：初始 $\alpha_{0|0}, P_{0|0}$ 对短序列影响大，应设为合理先验或扩散先验，而非草率取 0。

### 手算局部水平模型的滤波

用局部水平模型 $y_t = \alpha_t + \varepsilon_t$、$\alpha_{t+1} = \alpha_t + \eta_t$ 把卡尔曼滤波完整跑一遍。设 $Z=1,\ T=1,\ H=1,\ R=0.5$，初始 $\alpha_{0|0} = 0$、$P_{0|0} = 1$。观测为 $y_1 = 2,\ y_2 = 1.5$。

**$t=1$，预测步**：$\alpha_{1|0} = \alpha_{0|0} = 0$，$P_{1|0} = P_{0|0} + R = 1.5$。

**$t=1$，更新步**：增益 $K_1 = 1.5/(1.5+1) = 0.6$；新息 $y_1 - \alpha_{1|0} = 2 - 0 = 2$；状态修正为 $\alpha_{1|1} = 0 + 0.6\times 2 = 1.2$，方差 $P_{1|1} = (1-0.6)\times 1.5 = 0.6$。

**$t=2$，预测步**：$\alpha_{2|1} = \alpha_{1|1} = 1.2$，$P_{2|1} = 0.6 + 0.5 = 1.1$。

**$t=2$，更新步**：$K_2 = 1.1/(1.1+1) \approx 0.524$；新息 $1.5 - 1.2 = 0.3$；$\alpha_{2|2} = 1.2 + 0.524\times 0.3 \approx 1.357$，$P_{2|2} = (1-0.524)\times 1.1 \approx 0.524$。

读出三层信息：其一，**$K_t$ 从 0.6 降到 0.52**——状态估计越确定，越不信任单个观测；其二，**$P_t$ 从 1 降到 0.52**——两个观测把状态方差压掉近一半；其三，**估计从 0 被观测拽到 1.36**——收敛方向正确（数据均值是 1.75）。这套「越估越准、越准越信自己」的循环，就是卡尔曼滤波的全部灵魂。

### 什么时候该用状态空间

三个实战场景让状态空间框架物超所值：**缺失数据**（观测方程可「跳过」缺失期，状态估计照常递推，ARIMA 做不到这种天然处理）；**时变参数**（把回归系数本身放进状态向量，系数逐期漂移——动态回归）；**多变量融合**（多个观测方程共享同一状态，如多只股票的价格共同反映「市场因子」）。碰到这三类问题之一，就该把模型翻译成状态空间，而不是硬套 ARIMA。

**预测与不确定性是同一条链。** 滤波给出 $\alpha_{t|t}$ 后，$h$ 步预测直接是外推：$\hat y_{t+h|t} = Z T^h \alpha_{t|t}$，而预测误差方差由状态协方差 $P_{t+h|t}$ 与观测噪声 $H$ 叠加而成——**预测区间无需额外假设，就是滤波的顺带产物**（这正是《预测评估指标与预测区间》里状态空间类模型能给出正规区间的机理）。至于非线性场景（$T, Z$ 不再恒定或状态方程非线性），线性卡尔曼滤波失效，退而求其次用**扩展卡尔曼滤波**（EKF，一阶线性化）或**无迹/粒子滤波**（采样近似）——它们没有闭式解，但继承了「预测 + 更新」的同一骨架。

还有一个值得建立的视角：**卡尔曼滤波是「线性最优估计」的一个实例，而它给出的 $\alpha_{t|t}$ 恰好也是所有线性估计（包括 OLS）里均方误差最小的**。事实上，把状态方程与观测方程叠起来看，滤波等价于一个「带先验的加权最小二乘」：每一步更新都在「外推的预测」与「观测的证据」之间做方差加权折中——这与第三级线性回归里的广义最小二乘（GLS）共享同一个思想内核。理解这一层，卡尔曼滤波就不再是「一段神秘递推」，而是「高斯假设下的最优在线估计」，这让你在非线性、非高斯场景里也知道该往哪个方向改造（扩展卡尔曼、粒子滤波、以及后来的深度状态空间模型）。

## 5 小结

- 状态空间由**状态方程** $\alpha_{t+1} = T\alpha_t + \eta_t$ 与**观测方程** $y_t = Z\alpha_t + \varepsilon_t$ 组成，ARIMA、局部水平模型都是它的特例。
- 卡尔曼滤波每期**两步**：预测（外推状态与协方差）→ 更新（用观测修正）。
- **卡尔曼增益** $K_t$ 是「状态不确定性 / 观测噪声」的比值，控制该信新观测多少；新息 $y_t - Z\alpha_{t|t-1}$ 乘 $K_t$ 即修正量。
- 同一框架回答三类问题：**滤波**（在线）、**平滑**（离线全样本）、**预测**（外推 $h$ 步）。
- 高斯 + 线性下条件分布闭式可解，这是卡尔曼滤波在工程与计量中经久不衰的原因。
