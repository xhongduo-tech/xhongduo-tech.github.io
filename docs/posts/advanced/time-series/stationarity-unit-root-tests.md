## 为什么从平稳性开始

前两篇里我们一直在用「平稳」这个词：AR 的平稳条件是特征根在单位圆外、SARIMA 先差分再建模。但如果平稳性只是一个可以随意假设的前提，那整个 ARIMA 大厦就悬空了。本节要把这个前提本身拿上台面：**平稳性到底是什么、怎么判断一个序列是不是平稳、非平稳的「非」字到底来自哪里**。<span class="marginnote">Hamilton 教材把单位根理论放在第 15 章，它是理解真实经济序列（股价、汇率、产出）一切诡异行为的基础：这些序列的「假回归」现象，直到 Granger 与 Newbold 在 1974 年发表《Spurious Regressions in Econometrics》才被彻底揭示。</span>

平稳性也是本专题的枢纽：往下，单位根检验决定差分次数 d；往平，协整理论（Hamilton 第 19 章）恰恰研究「多个非平稳序列之间如何形成平稳的组合」。不理解「非平稳」，就无法理解为什么普通回归会骗人，更无法理解协整的珍贵。

## 1 严格平稳与弱平稳

**严格平稳（strict stationarity）** 要求联合分布随时间平移不变：任意 $k$ 个时刻的 $(y_{t_1}, \dots, y_{t_k})$ 与 $(y_{t_1+h}, \dots, y_{t_k+h})$ 同分布。这是个很强的要求，实际中几乎无法检验。

实务中用的是**弱平稳（weak / covariance stationarity）**，只约束前两阶矩：

**弱平稳**要求三条：均值恒定 $\operatorname{E}[y_t] = \mu$；方差恒定 $\operatorname{Var}(y_t) = \gamma_0$；且**自协方差只依赖滞后 $k$**：

$$\gamma_k = \operatorname{Cov}(y_t, y_{t-k}) = \operatorname{E}[(y_t-\mu)(y_{t-k}-\mu)]$$

$\gamma_k$ 称为**自协方差函数（autocovariance function）**，除以 $\gamma_0$ 就得到**自相关函数（ACF）** $\rho_k = \gamma_k / \gamma_0$。<span class="marginnote">弱平稳的直觉是「统计意义上的规则」：序列可以来回波动，但它的均值、波动幅度、以及「相隔 k 期相关多少」这三件事不随时间改变。预测之所以可能，正是因为 $\gamma_k$ 长期稳定，历史的相关结构可以外推。</span>两条定义的差别值得记牢：**严格平稳管「全部分布」，弱平稳只管「均值、方差、自协方差」**。白噪声两者都满足，随机游走两者都不满足。

自协方差函数还有两条值得注意的性质：**对称性** $\gamma_k = \gamma_{-k}$（「相隔 $k$ 期」与「向前 $k$ 期」等价），以及**半正定性**（由任意有限个自协方差拼成的矩阵非负定——这正是后面谱分析、以及把 $\gamma_k$ 当协方差阵做回归诊断的依据）。再补一个实用关系：$\operatorname{Var}(y_t) = \gamma_0$，方差只是自协方差函数在 $k=0$ 处的取值——**「平稳」的方差恒定，本质是「自协方差函数完全由滞后决定」这句话的一个特例**。

## 2 单位根：非平稳的精确来源

为什么随机游走 $y_t = y_{t-1} + \varepsilon_t$ 不平稳？代入弱平稳定义：$y_t = \sum_{j=0}^{t-1}\varepsilon_{t-j} + y_0$，方差 $\operatorname{Var}(y_t) = t\,\sigma^2$ 随 $t$ 线性膨胀——**冲击永不衰减，方差无上限**。

把 AR(1) 的平稳条件 $|\phi_1|<1$ 改写成特征方程 $1 - \phi_1 z = 0$，根是 $z = 1/\phi_1$。平稳要求根在单位圆外，即 $|z|>1 \Leftrightarrow |\phi_1|<1$。**当 $\phi_1 = 1$，特征根恰在单位圆上（$z=1$），这就是单位根（unit root）**：冲击不是衰减而是完全延续。更一般地，若 AR 特征方程 $\phi(z)=0$ 含单位根，序列就是**差分平稳（difference stationary）**——差 $d$ 次后变平稳，$d$ 正是单位根的个数。<span class="marginnote">单位根的名字就来自「根的模长等于 1」。它和不含单位根的趋势平稳（trend stationary，均值是一条时间曲线、去趋势后即平稳）是两类不同的非平稳，统计性质与预测含义截然不同。</span>

一个单位根 = 一个完全持续的记忆。股价、汇率这类序列接近单位根，所以「今天的价格几乎包含全部历史信息」——这正是随机游走假说。

## 3 单位根检验：Dickey-Fuller 与 ADF

判断是否含单位根，最直觉的想法是回归 $y_t = \rho y_{t-1} + \varepsilon_t$，看 $\rho$ 是否显著小于 1。**检验在单位根原假设下 $t$ 统计量不再服从标准正态，而是服从 Dickey-Fuller 分布**（因为回归元 $y_{t-1}$ 本身非平稳，破坏了经典渐近理论）。

**Dickey-Fuller 检验**的回归式是改写后的差分形式：

$$\Delta y_t = \alpha + \beta t + \gamma\, y_{t-1} + \varepsilon_t, \qquad \gamma = \rho - 1$$

原假设 $H_0: \gamma = 0$（存在单位根，非平稳），备择 $H_1: \gamma < 0$（平稳）。若 $t_\gamma$ 小于 DF 分布的临界值则拒绝原假设，判定平稳。

**ADF（Augmented Dickey-Fuller）** 在回归式右侧补上滞后差分项 $\sum_{i=1}^{p}\phi_i \Delta y_{t-i}$，吸收残差的自相关，使 $\varepsilon_t$ 近似白噪声；滞后阶数 $p$ 常用 AIC 选取。<span class="marginnote">DF 统计量的临界值在教科书附表里以三行出现（无常数、含常数、含常数+趋势 $\alpha+\beta t$），选错规格会系统性错判——选含趋势的规格检验纯随机游走，往往会错判为平稳。这是应用单位根检验最常见的翻车点。</span>

为什么 $t_\gamma$ 不服从标准分布？因为回归元 $y_{t-1}$ 本身非平稳，经典回归的「样本增大 → 统计量渐近正态」失效，$t_\gamma$ 收敛到布朗运动的函数型分布——**单位根理论因此本质上是「非平稳渐近理论」**，这也是它独立于经典统计教材、自成体系的原因。

注意单位根检验的**低功效**：当 $\rho$ 接近但小于 1（如 0.97），检验很难拒绝原假设——单位根检验有「系统性偏好非平稳」的倾向，解读结果时要记得这一点。

**读一份 ADF 输出的正确姿势。** 软件会给出 $t_\gamma$ 统计量与对应 $p$ 值（或三个临界值）。以含常数项的规格为例，若 $t_\gamma = -3.9$，而 5% 临界值约为 $-2.86$，则 $t_\gamma$ 比临界值更负、落在拒绝域，$p < 0.05$，**拒绝单位根原假设，判定平稳**；若 $t_\gamma = -1.7$，远未达临界值，则不能拒绝，判定含单位根。两条铁律：**统计量要更负才算拒绝（这是个单侧左侧检验）**；**规格必须与序列特性匹配**——序列有明显趋势就必须在回归里加 $\beta t$，否则检验功效急剧下降。至于滞后阶数 $p$，用 AIC 选的阶数与「残差无自相关」的目视一致才算稳妥。

## 4 公式解析：为什么非平稳会制造假回归

Granger 与 Newbold 的经典教训：两个独立的随机游走互相回归，$t$ 值经常「显著」，$R^2$ 很高——这就是**伪回归（spurious regression）**。道理在于公式：

$$y_t = a + b\,x_t + u_t$$

当 $y_t$ 与 $x_t$ 都是单位根过程，$u_t$ 也会继承非平稳性，不满足最小二乘的「残差白噪声」前提。此时 $t$ 统计量没有极限分布，**一切显著性检验全部失效**，$b$ 的估计也只是「把两根无关的漂移线硬配在一起」。拆解要点：

- **原假设下的 $t$ 统计量**不再收敛到正态，而是随样本量发散——任何表面显著的 $t$ 都不可信。
- **$R^2$ 高**是因为两条序列都在「慢慢爬」，水平之间的共变不代表因果或均衡。
- **判别手段**：先做单位根检验，两个序列都非平稳时，要么差分后再回归，要么走上协整的路——这正是下一节的入口。

伪回归的实际后果值得再说透：它不只会让你「误以为两个无关序列相关」，更危险的是**会给你一个「精确得吓人」的假结论**——$R^2$ 极高、$t$ 值极显著、DW 统计量却低得反常。粗查 $R^2 > DW$ 这一条经验法则就能抓住多数伪回归：**平稳回归通常 $R^2$ 与 $DW$ 同数量级，伪回归则 $R^2$ 远大于 $DW$**。这是 Granger 与 Newbold 当年给出的一眼识破的暗号，如今仍是时序回归的第一道体检。

### 判别平稳的三板斧

实务中判断「这个序列稳不稳」，按成本从低到高走三步：

**第一板斧，看图。** 时序图若显示均值围绕水平线恒定波动，或波动幅度不随时间扩大，多半平稳；若序列一路爬升、波动扩散成喇叭形，多半非平稳。**第二板斧，看 ACF。** 平稳序列的样本 ACF 通常在几期后衰减到置信带内；单位根序列的 ACF 衰减极慢——这比肉眼更可靠。ACF 图里那两条包络线就是置信带（约 $\pm 1.96/\sqrt{n}$）：落进带内视为 0，带外显著。**第三板斧，做检验。** 对拿不准的序列用 ADF，给出正式结论。三者结论一致时才放心；不一致时以检验为准并记录可疑处。

**辨析｜易错点：** 一个常见误判是把「趋势平稳」直接当「非平稳差一分」处理。趋势平稳序列 $y_t = 0.5t + \varepsilon_t$ 去掉时间趋势即平稳；差分平稳序列 $y_t = y_{t-1} + 0.5 + \varepsilon_t$ 差分才平稳。两者在单位根检验下行为完全不同——若把趋势平稳序列做差分，会引入不必要的负自相关（过度差分）；若把差分平稳序列去趋势，残差仍含单位根。**「去趋势」与「差分」不是同一种手术**，选错会系统性地毁掉后续模型。

一个随手可做的判别练习：画一条随机游走与一条平稳 AR(1)（$\phi=0.7$），前者的 ACF 从接近 1 的位置缓慢下滑、100 个滞后后仍在置信带外；后者的 ACF 从 0.7 起指数衰减、十几期后落回置信带内。**ACF 的形状（慢滑 vs 快掉）比任何目测都更接近「有没有单位根」的真相**——这就是第二板斧比第一板斧可靠的原因。

### 一个数值例子：两种非平稳的差别

设两条序列都有上升趋势：A 是趋势平稳 $y_t^A = 0.5t + \varepsilon_t$，B 是带漂移随机游走 $y_t^B = y_{t-1} + 0.5 + \varepsilon_t$，$\varepsilon_t$ 同分布。到 $t=100$，两者的水平都在 50 附近徘徊，图形几乎分不出来；但**预测含义天差地别**：

| 视角 | 趋势平稳 A | 差分平稳 B |
| --- | --- | --- |
| 冲击持久性 | 冲击随 $t$ 衰减，序列回到趋势线 | 冲击完全持久，永不回均值 |
| 远期预测 | 收敛到趋势线 $0.5(T+h)$ | 随漂移直线外推、方差随 $\sqrt h$ 膨胀 |
| 处理方式 | 去掉时间趋势 | 差分 |

这个对比解释了为什么单位根检验如此重要：**它不只是统计仪式，而是直接决定预测的形态与预测区间的宽度**。ADF 检验在两条序列上的结果（A 拒绝单位根、B 无法拒绝）正是区分它们的钥匙。

### 定 d：差分—检验—再差分

ARIMA 建模里 $d$ 的取值不该靠猜，而是用「差分—检验—再差分」的循环确定。以含一个单位根的序列为例，标准流程是：

1. **对原序列 $y_t$ 做 ADF**：$t_\gamma$ 不显著（不能拒绝单位根）→ 序列非平稳。
2. **做一次差分 $\Delta y_t$，再对差分序列做 ADF**：$t_\gamma$ 显著（拒绝单位根）→ 差分一次即平稳，$d=1$。
3. **过度差分的预警**：若对 $\Delta y_t$ 再做一次差分，虽然 $t_\gamma$ 依旧显著，但差分序列的**方差反而增大**——这是「多差了一次」的经典信号。经验判据是「方差最小化」：比较 $d=0,1,2$ 时差分序列的样本方差，取方差最小、且检验通过的那个 $d$。

这套循环是 ARIMA 建模的第一步，也是自动建模算法（如 `auto.arima`）内部反复执行的同一逻辑。

若一次差分后 ADF 仍不显著，就继续差分（$d=2$）——价格序列（而非收益率）常出现这种情况，因为价格是收益率的累计、天然的「双倍随机游走」。要警惕的是 $d$ 很少需要超过 2：**经济序列差到 $d=2$ 还没平稳，多半是结构突变（政策断点、危机）在捣乱**，此时硬差分不如先做断点处理。这也是单位根检验与「结构性变化检验」在实战中总是成对出现的原因。<span class="marginnote">注意 ADF 原假设是「有单位根」，因此「拒绝」才意味着「平稳」——它与 KPSS 检验（原假设就是「平稳」）方向相反，两个检验一起用、要求结论一致，是最稳健的确认方式。</span>另外提醒：若序列同时含单位根与确定性趋势（如带漂移的随机游走），先差分会把漂移变成常数项，再差分则可能过差——**「先检趋势、再检单位根」的顺序能避免把趋势平稳误当差分平稳**。

## 5 小结

- **弱平稳**三条件：均值、方差恒定，自协方差只依赖滞后；**严格平稳**要求全部分布平移不变。
- **单位根**即特征方程 $z=1$ 处的根：冲击完全延续、方差随时间膨胀，是「差分平稳」非平稳的来源。
- 检验 $y_t = \rho y_{t-1}+\varepsilon_t$ 中 $\rho$ 是否小于 1 要用 **DF/ADF 分布**，而非标准 $t$ 分布。
- **伪回归**：两个独立单位根序列互回归会得到「假显著」，必须先用单位根检验把关。
- 单位根检验功效低，$\rho$ 接近 1 时易判非平稳；规格（常数/趋势）选错会系统性误判。
- 判定非平稳的**三板斧**：看图、看 ACF 衰减速度、做 ADF（配 KPSS 交叉确认）；趋势平稳与差分平稳是两种不同的手术，选错会毁掉后续模型。

在下一节，我们要问一个转折性的问题：两个都非平稳的序列，放在一起却可能很稳——这种「非平稳组合出平稳」的奇妙现象，就是**协整与误差修正**。
