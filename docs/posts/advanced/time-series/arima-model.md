## 为什么从 ARIMA 开始

ARIMA（自回归积分移动平均）是经典时间序列预测里出场率最高的模型：经济学的 GDP、电力的日负荷、股票的收益率，几乎所有教科书的入门章节都以它为圆心。它之所以值得在整门课的第一篇就学透，是因为它把三件最基本的事拧在了一起——**用过去的自己预测未来的自己**（自回归）、**用过去随机冲击的余波解释波动**（移动平均）、**用差分对付趋势**（积分）。<span class="marginnote">本专题以 Box 等的经典教材为对标体系。ARIMA 对应第 3 章，是后续 SARIMA（第 9 章）、GARCH（Hamilton 第 21 章）与深度学习时序的共同起跑线：前者加季节性，后两者换掉「线性」这一假设。</span>

学 ARIMA 之前你需要站住的支点是：第三级的线性回归（用输入解释输出）与第二级概率论里的随机变量（用分布描述不确定性）。时间序列的特殊之处在于，**样本之间不独立**——今天的 $y_t$ 与昨天的 $y_{t-1}$ 高度相关，而经典统计的独立性假设在时序里一开场就失效。ARIMA 就是一套在「不独立」的钢丝上重新搭起模型的语言。

## 1 从白噪声到随机游走

一切从最干净的随机过程讲起。**白噪声（white noise）** $\varepsilon_t$ 是满足三个条件的时间序列：均值为 0、方差恒定、任意两个不同时刻互不相关。它是「无信息」的基准，任何模型的残差都希望收敛到白噪声。

把白噪声简单累加，得到**随机游走（random walk）**：

$$y_t = y_{t-1} + \varepsilon_t$$

随机游走是「醉汉走路」：今天的值完全由昨天的值加上一步随机扰动决定。它看起来没有规律，却是理解差分的第一块跳板。**判别一个序列是否只含白噪声信息，靠的是自相关函数（ACF）**：对滞后 $k$ 定义 $\rho_k = \operatorname{Corr}(y_t, y_{t-k})$。白噪声的 ACF 在任何滞后上都接近 0；而随机游走的 ACF 衰减得极慢，因为每一步都继承了之前的所有冲击。

一个深刻的事实是**Wold 分解定理**：任何（平稳的、无确定成分的）随机过程都能写成「过去白噪声的无穷加权和」：

$$y_t = \sum_{j=0}^{\infty} \psi_j \varepsilon_{t-j}$$

Wold 分解给出了建模的根本理由：**既然一切都是白噪声的线性组合，问题就只剩「怎么用有限个系数逼近这个无穷和」**。AR 与 MA 正是两种不同的逼近方式。

## 2 自回归 AR(p)：用自己解释自己

**自回归（autoregressive）模型**说：当前值等于过去若干期值的线性组合加一个白噪声扰动。

$$y_t = c + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \cdots + \phi_p y_{t-p} + \varepsilon_t$$

p 阶 AR 模型记作 AR(p)。当 $p=1$ 时，**平稳条件**是 $|\phi_1| < 1$：否则过去的冲击不会衰减，序列会发散成非平稳。推广到一般 $p$，平稳条件变成特征方程 $\phi(z) = 1 - \phi_1 z - \cdots - \phi_p z^p = 0$ 的全部根都在单位圆外——这里用到的正是第三级线性代数里的**特征根语言**，只不过「根」现在长在滞后算子对应的多项式上。<span class="marginnote">AR(p) 的系数与偏自相关函数（PACF）的关系是：PACF 在滞后 $p$ 之后截尾为 0。这是后面 Box-Jenkins「看 PACF 定 p」的依据。</span>

AR 模型的直觉是**动量与惯性**：GDP 连续三个季度增长，则本季度大概率继续增长，因为经济系统自带惯性。它的系数 $\phi_i$ 直接可读成「$y_{t-i}$ 每增加一单位，对 $y_t$ 的边际影响」——前提是系统平稳。

## 3 移动平均 MA(q)：让历史冲击退场

**移动平均（moving average）** 模型说：当前值等于常数加上**当前及过去 $q$ 期白噪声冲击**的线性组合。

$$y_t = c + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \cdots + \theta_q \varepsilon_{t-q}$$

注意这里的「移动平均」不是算均值，而是**对冲击做加权叠加**。MA(q) 的直觉是**冲击的余波**：一场供应中断（$\varepsilon$）会直接影响当期产量，又在随后的 $q$ 期里以递减的力度残留在链条上。MA 过程天然平稳（它是白噪声的有限线性组合，方差有界），它的 ACF 在滞后 $q$ 之后**截尾**——与 AR 恰好互补。<span class="marginnote">把 ACF 与 PACF 的截尾行为对偶记忆：AR 让 PACF 截尾、ACF 拖尾；MA 让 ACF 截尾、PACF 拖尾。这是识别模型阶数的第一把钥匙，也是初学者最容易记反的地方。</span>

## 4 差分：让非平稳变得平稳

很多真实序列（股价、气温、销售）都带趋势，直接套 AR 会违反平稳假设。**差分（differencing）** 用一阶差 $\Delta y_t = y_t - y_{t-1}$ 把「水平」换成「变化」：线性趋势差一次变常数，二次趋势差两次变常数。写进滞后算子就是 $\Delta = 1 - B$，其中**滞后算子（backshift operator）** $B$ 满足 $B y_t = y_{t-1}$。

**ARIMA(p, d, q)** 就是「对 $y_t$ 先差 $d$ 次、再用 ARMA(p,q) 描述差分后的序列」。

## 5 公式解析：ARIMA 的统一表达式

ARIMA(p,d,q) 用一个式子浓缩全部信息：

$$
\phi(B)\,(1-B)^d\, y_t = c + \theta(B)\,\varepsilon_t
$$

- **$\phi(B)$**：自回归多项式 $\phi(B) = 1 - \phi_1 B - \cdots - \phi_p B^p$，负责把 $y_t$ 的滞后项搬到等式左边，即「用过去的自己解释自己」。
- **$(1-B)^d$**：差分算子重复 $d$ 次，$d=1$ 时 $(1-B)y_t = y_t - y_{t-1}$，正是把趋势抹平的关键；$d=0$ 时序列本身已平稳，退化为 ARMA。
- **$\theta(B)$**：移动平均多项式 $\theta(B) = 1 + \theta_1 B + \cdots + \theta_q B^q$，负责把「历史白噪声冲击」搬进等式，即「用过去冲击的余波解释现在」。
- **$c$**：常数项，与均值 $\mu$ 的关系为 $c = \mu\,\phi(1)$（当 $d=0$ 时），保证模型的长期水平与数据一致。
- **$\varepsilon_t$**：白噪声扰动，是模型认为「解释不掉」的纯随机部分。

对照读法是：**等式左边管「确定性的记忆」（滞后值），右边管「随机的记忆」（滞后冲击）**。差分 $d$ 相当于预处理，AR 与 MA 才是描述平稳部分的真身。把这三块拆开看，整个式子就不再是黑箱。

## 6 Box-Jenkins 三步曲与模型选择

Box 与 Jenkins 在 1970 年把 ARIMA 建模规范成三步，至今仍是经典流程：

**第一步，识别（identification）**：看 ACF/PACF 判断 p、q 的候选阶数，用 ADF 检验决定差分次数 d（见本专题《平稳性与单位根检验》）。

**第二步，估计（estimation）**：对选定的 (p,d,q)，用极大似然或条件最小二乘估计系数。

**第三步，检验（diagnostic checking）**：看残差是否白噪声。常用 **Ljung–Box 检验**：残差序列 Q 统计量若显著，说明信息没抽干净，需回头调阶数。

在候选模型间比较时用信息准则——**AIC** 与 **BIC**：

$$
\text{AIC} = -2\ln L + 2k, \qquad \text{BIC} = -2\ln L + k\ln n
$$

其中 $L$ 是似然值，$k$ 是参数个数，$n$ 是样本量。两者都是「拟合优度」与「参数惩罚」的平衡：对数似然越大越好，但每多一个参数都扣分。BIC 惩罚更重，在样本大时倾向选更简洁的模型。

**辨析｜易错点：** 两个高频错误。其一，**过度差分**：平稳序列再差一次会引入不必要的负自相关，判断标准是差分后方差是否反而变大。其二，**把 AIC 当唯一裁判**：AIC 选出的模型预测未必最好，还要过残差白噪声这一关——先验诊断，再比准则，顺序不能反。

### 手算一个 AR(1)：冲击如何衰减

数学定义容易飘，我们用数字把「平稳条件下冲击如何衰减」钉死。设 $\phi_1 = 0.6$，白噪声 $\varepsilon_t \sim \mathcal{N}(0,1)$，$y_0 = 0$。取 5 个扰动，逐步递推：

| $t$ | $\varepsilon_t$ | $y_t = 0.6\,y_{t-1} + \varepsilon_t$ |
| --- | --- | --- |
| 1 | 0.5 | $0.6\times 0 + 0.5 = 0.500$ |
| 2 | −0.8 | $0.6\times 0.5 - 0.8 = -0.500$ |
| 3 | 1.2 | $0.6\times(-0.5) + 1.2 = 0.900$ |
| 4 | −0.4 | $0.6\times 0.9 - 0.4 = 0.140$ |
| 5 | 0.3 | $0.6\times 0.14 + 0.3 = 0.384$ |

看 $t=1$ 的冲击 $\varepsilon_1 = 0.5$ 如何退场：它在 $y_1$ 里占 0.5，进 $y_2$ 只剩 $0.6\times0.5 = 0.3$，$y_3$ 里是 $0.6^2\times0.5 = 0.18$，$y_5$ 里是 $0.6^4\times 0.5 \approx 0.065$。**系数 0.6 的幂就是冲击的衰减因子**——这正是 $|\phi_1|<1$ 的直观含义：冲击逐步被吸收，序列被拉回均值附近。若 $\phi_1 = 1$（单位根），冲击永不衰减，序列就会像上一节说的随机游走那样漂出去。

这个例子还顺带演示了预测：已知 $y_5$，一步预测 $\hat y_6 = 0.6 \times 0.384 = 0.230$，两步 $\hat y_7 = 0.6 \times 0.230 = 0.138$——**预测随步长迅速回缩到长期均值 0**，这是平稳 AR 的典型指纹：远期预测收敛到均值，预测区间则收敛到无条件方差决定的带宽。

## 7 小结

- ARIMA(p,d,q) 由三块构成：**AR(p)**（用自身滞后值）、**MA(q)**（用历史白噪声冲击）、**差分 $d$**（抹平趋势）。
- **Wold 分解**告诉你一切平稳过程都是白噪声的线性组合，AR/MA 只是两种有限近似。
- ACF 与 PACF 的截尾行为是识别阶数的钥匙：AR 让 PACF 截尾，MA 让 ACF 截尾。
- Box-Jenkins 三步：**识别 → 估计 → 诊断**；残差必须通过 Ljung–Box 白噪声检验。
- AIC/BIC 用「似然 + 参数惩罚」平衡拟合与简洁；BIC 惩罚更重。

在下一节，我们将给 ARIMA 加上「季节」这根弦：当序列呈现每年一度的周期（如电商旺季、气温循环）时，普通的 ARIMA 会力不从心——这就是**季节性分解与 SARIMA**。
