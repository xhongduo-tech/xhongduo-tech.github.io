# 真空 Rabi 劈裂

## 为什么从真空 Rabi 劈裂开始

真空 Rabi 
劈裂是**强耦合腔 QED 最直接、最著名的观测签名**：
把原子放进腔，即使腔内平均光子数为零，
原子共振谱线也会从单峰劈成间隔 $2g$ 的双峰。
它把「真空涨落」从哲学概念变成了可测量的光谱结构。1983 
年，Kaluzny、Goy、Gross 与 Haroche 
在微波腔 Rydberg 原子中首次观测到；1992 年，
Raizen 等在光学腔冷原子中看到。如今它成为腔 QED 
的「验孕棒」——一测便知是否进入强耦合。<span class="marginnote">真空 
Rabi 劈裂与《Jaynes-Cummings 
模型》的缀饰态一脉相承：劈裂就是 $n=1$ 
子空间两个缀饰态 $|+,1\rangle, |-,1\rangle$ 
的能量差在光谱上的投影。</span>

## 1 从 JC 模型看劈裂的起源

在 JC 模型里，
共振（$\Delta = 0$）时 $n = 1$ 
子空间的两个缀饰态为

$$|+\rangle = \frac{1}{\sqrt{2}}(|e,0\rangle + |g,1\rangle), \qquad |-\rangle = \frac{1}{\sqrt{2}}(|e,0\rangle - |g,1\rangle)$$

能量分别为 $E_\pm = \omega_0 \pm g$，
间隔 $2g$。**这两个态是「原子激发 + 场真空」与「原子基态 + 场单光子」的纠缠叠加**——这就是劈裂的物理本体：
原子与真空场不再是独立个体，
而成了纠缠缀饰对。<span class="marginnote">注意：$n = 1$ 
的劈裂 $2g$ 
里没有「光子数」的功劳——腔里平均光子数为零，
劈裂完全由真空场提供。这正是它叫「真空」Rabi 
劈裂的原因。</span>

**重点：真空 Rabi 劈裂的间隔 $2g$ 不含 $\sqrt{n}$ 因子（那是 $n$ 光子 Rabi 频率），它纯粹是单光子耦合强度的两倍。** 
因此测到劈裂间隔，就等于直接测量 $g$。

## 2 透射谱中的双峰

实际观测不是直接看能量本征值，而是看**腔透射谱**：
一束弱探测光穿过含原子的腔，透射率 $T(\omega)$ 
在原子共振处分裂为双峰。在强耦合、弱探测极限下，
透射谱（洛伦兹型）为

$$T(\omega) \propto \frac{1}{(\omega - \omega_0 - g)^2 + (\kappa/2)^2} + \frac{1}{(\omega - \omega_0 + g)^2 + (\kappa/2)^2}$$

两个峰各在 $\omega_0 \pm g$，
线宽由耗散决定（理想时 $\kappa/2$）。
当 $g \gg \kappa$ 时两峰清晰分离；
当 $g \sim \kappa$ 
时两峰融合成宽单峰——所以「看见双峰」本身就需要强耦合。<span class="marginnote">透射谱双峰是「正常模式劈裂（normal 
mode splitting）」在单原子-单腔情形的名字。
在多原子集体情形，同样的劈裂叫集体 Rabi 劈裂，
间隔 $\propto \sqrt{N}g$——由所有原子的
偶极子集体共振决定。</span>

## 3 真空 Rabi 振荡：时域视角

劈裂的能量域表述，等价于时域的**真空 Rabi 振荡**。
初始制备在 $|e, 0\rangle$（原子激发、
腔真空），时间演化

$$|\psi(t)\rangle = \cos(gt)|e,0\rangle - i\sin(gt)|g,1\rangle$$

于是原子激发概率

$$P_e(t) = \cos^2(gt)$$

原子以频率 $g$ 在「激发 + 无光子」与「基态 + 
单光子」之间来回振荡——**一个光子被原子周期性地吸收再放出**。
这是强耦合最本质的动力学：能量的相干交换。

**辨析｜易错点：** 真空 Rabi 振荡不是经典 
Rabi 
振荡（频率 $\Omega = dE_0/\hbar$ 
正比于场振幅）。真空 Rabi 频率 $g$ 
不依赖外加场强——它在零光子时也存在。判断标准：
若振荡频率随泵浦功率变化，那是经典 Rabi；
若固定为 $g$，那是真空 
Rabi。**单光子与真空之间的纠缠交换，是腔 QED 与自由空间的根本分野。** <span class="marginnote">时域振荡与频域劈裂是同一物理的两个投影：$\cos^2(gt)$ 
的振荡频率 $g$ 对应频域劈裂 $2g$——$2\pi$ 
因子换算，别无其他。</span>

## 4 公式解析：$P_e(t) = \cos^2(gt)$

这条式子把「真空驱动原子翻转」写成最干净的形式，拆成三步：

**第一步，初始条件**：$t = 0$ 时原子在 $|e\rangle$、腔真空 $|0\rangle$。把 $|e,0\rangle$ 用缀饰态展开：$|e,0\rangle = (|+\rangle + |-\rangle)/\sqrt{2}$。
**第二步，相位演化**：$|+\rangle, |-\rangle$ 能量差 $2g$，相对相位 $e^{-i(2g)t}$，两分量干涉出 $\cos^2(gt)$。
- **第三步，半周期读法**：$t = \pi/(2g)$ 时 $P_e = 0$，原子完全变为基态 + 一个光子（$|g,1\rangle$）；$t = \pi/g$ 时回到激发态。**一个完整交换周期 $T = \pi/g$**——光子在原子与腔场之间往返一次的「心跳周期」。

## 5 从劈裂到量子技术

- **强耦合判定**：测透射谱双峰间隔 $= 2g$、峰宽 $= \kappa$，直接读出 $g, \kappa$，验证 $C = g^2/2\kappa\gamma > 1$；
- **单光子源**：强耦合下泵浦原子 → 腔发射单光子，时间分布由 $\cos^2(gt)$ 调制，可做确定性单光子源；
- **量子门**：真空 Rabi 交换 $|e,0\rangle \leftrightarrow |g,1\rangle$ 是原子-光子间的 SWAP——量子网络的原子-光接口基本操作；
- **腔 QED 量子模拟**：单原子多模式劈裂谱模拟固体中的激子-光子耦合（微腔极化激元）。

**一句话：真空 Rabi 劈裂是「真空不空」的光谱证据，也是腔 QED 强耦合的全部判据所在。** <span class="marginnote">极化激元（exciton-polariton）物理里，
同样的 $2g$ 劈裂叫 Rabi 劈裂，
只是耦合对象从「单原子」换成了「多激子」，
物理统一——量子光学与凝聚态在此相遇。</span>

## 6 小结

- 真空 Rabi 劈裂：共振强耦合下谱线劈成间隔 **$2g$** 的双峰。
- 缀饰态 $|\pm\rangle = (|e,0\rangle \pm |g,1\rangle)/\sqrt{2}$ 是纠缠态，劈裂即其能量差。
- 时域对应真空 Rabi 振荡 $P_e(t) = \cos^2(gt)$：原子与腔场相干交换单光子。
- 劈裂间隔与泵浦强度无关——它只由 $g$
