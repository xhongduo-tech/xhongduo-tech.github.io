# 结构因果模型 SCM

<div class="epigraph">

## 为什么从结构因果模型开始

前七篇我们散装地用了图（第 1 篇）、do（第 2 篇）、潜在结果（第 3 篇）、反事实（第 7 篇）——它们其实是同一个东西的不同侧面。**结构因果模型（Structural Causal Model, SCM）**就是把它们统一起来的形式化容器：一段描述「世界如何产生数据」的程序。在这个程序里，图是骨架（谁影响谁）、结构方程是肌肉（怎么影响）、外生变量是「命运」的随机源头。SCM 的价值在于：它把「因果关系」彻底降维成「方程替换」——干预是替换方程，反事实是替换方程再加证据约束——整个因果推断的三种语言，从此在同一个模型里各得其所。<span class="marginnote">SCM 的理论源头是怀特（Sewall Wright）1920 年代的路径分析，经计量经济学的联立方程、以及 Haavelmo/Simon 的因果解释，到珀尔手里成为完整的语义系统。见 Pearl, Causality, Ch.2。</span>

## 1 SCM 的四要素

一个结构因果模型 $M$ 由四部分组成：

**外生变量（exogenous variables）$U$**：模型边界之外的「命运」——一切不确定性的源头，互相独立、由模型外部的分布 $P(U)$ 给定。图论里它们是「没有父节点」的根，实践中常指未观测的个体差异。

**内生变量（endogenous variables）$V$**：模型内部要解释的变量——它们有父节点，其值由外生变量与其它内生变量共同决定。

**结构方程（structural equations）$F$**：一族函数，把 $V$ 中的每个变量表示为「父节点 + 外生扰动」的函数：

$$v_i = f_i(\text{pa}_i, u_i), \qquad i = 1, \dots, n$$

**因果假设 $P(U)$**：外生变量的联合分布。

四要素合起来记作 $M = \langle U, V, F, P(U)\rangle$。<span class="marginnote">对比概率图模型：一个 SCM 相当于「有向图 + 每个节点的条件分布」外加一层外生扰动。SCM 比普通贝叶斯网多出的正是那组确定性函数 $f_i$——它让「改方程」成为可能，从而支持干预与反事实。</span>

结构方程的关键属性是**非对称性**：$Y = \beta X + U_Y$ 断言「$X$ 是原因、$Y$ 是结果」，它**不可**等价改写成 $X = \beta' Y + U_X$ 的形式。回归的对称性在这里被打破——这就是「结构」二字的含义。

## 2 三种语言的统一：因果层级三格图

珀尔用一张「三格图」（三值逻辑）刻画 SCM 能表达的全部问题，按信息量从低到高：

| 层级 | 问题形式 | 记号 | 能否用 SCM 回答 |
| --- | --- | --- | --- |
| 关联（associational） | 看见：$Y$ 与 $X$ 有关吗？ | $P(Y \mid X)$ | 是（且无需因果） |
| 干预（interventional） | 做：若把 $X$ 设为 $x$，$Y$ 会怎样？ | $P(Y \mid \text{do}(X=x))$ | 是（需 $F$） |
| 反事实（counterfactual） | 想象：若当初 $X$ 是 $x$，$Y$ 会怎样？ | $P(Y_{X=x} \mid \text{证据})$ | 是（需 $F$ + $U$ 结构） |

三格图的第一层含义：**更高层无法从更低层推导**。只给观测数据（第一层），无法唯一决定干预（第二层）——这正是第 1 篇「分布推图不唯一」的表述；给定干预分布，反事实（第三层）依然不唯一。<span class="marginnote">这是「从数据学到反事实」的困难所在：数据来自第一层，而反事实在第三层，中间隔着不可约的鸿沟。因果发现算法（第 9 篇）能爬多少层，取决于额外假设给多少。</span>

SCM 的独特价值正在于：**它是唯一同时承载三层问题的单一对象**。普通统计模型只回答第一层；加了 do 演算的图回答前两层；只有带外生结构 $U$ 与函数 $F$ 的 SCM 才能问第三层。

## 3 从 SCM 到图：结构方程的投影

SCM 与第 1 篇的 DAG 是什么关系？答案：**每个 SCM 都诱导一张 DAG**——把每个内生变量画成节点，若有 $u$ 或 $v_j$ 出现在 $f_i$ 的右侧（即 $v_j$ 是 $v_i$ 的父节点），就画一条 $v_j \to v_i$ 的有向边。反过来，同一张 DAG 对应**无穷多个** SCM（不同的 $f_i$ 与 $P(U)$）。

这个投影带来两个重要后果：

**其一，图是 SCM 的「粗糙化」**：所有只依赖图的结论（d-分离、后门准则、do 演算的规则）都自动成立，且对 $f_i$ 的具体形式稳健——这就是为什么第 1、2 篇可以放心在图上做文章。

**其二，图不捕捉 SCM 的全部信息**：两个 $f_i$ 不同但结构相同的 SCM 可能对反事实给出不同答案。因此「图可识别效应」与「反事实可识别效应」是两回事，后者需要更强的可识别条件。<span class="marginnote">例：$Y = X + U$ 与 $Y = X^2 + U$ 的 DAG 相同，但「给定 $Y$ 时 $X$ 的反事实」完全不同。图语言看不到这个差别。</span>

## 4 公式解析：结构方程 vs 回归方程

SCM 中最容易混淆的一步，是搞不清「结构方程」与「普通回归方程」到底差在哪。以经典的教育–收入模型为例：

$$
\text{收入 } Y = \beta \cdot \text{教育 } X + U_Y, \qquad U_Y \perp X \text{（?）}
$$

- **第一步，看谁是定义**：结构方程是**因果机制的定义**——它宣称「教育以系数 $\beta$ 影响收入，其余归因于 $U_Y$」。它不是对数据的拟合，而是对世界的断言。
- **第二步，看扰动项的角色**：$U_Y$ 是外生「命运」，包含了所有未列入模型的影响因素。**$U_Y$ 与 $X$ 是否独立，是模型假设而非数据结论**：若存在「能力」同时影响教育与收入，则 $U_Y$ 与 $X$ 相关，结构模型里应有 $X$ 的父节点 $U_C$ 指向 $X$。
- **第三步，干预到底改了什么**：$\text{do}(X=x)$ 把 $X$ 的方程删掉换成 $X=x$，**$U_Y$ 保持原值**。于是 $E[Y \mid \text{do}(X=x)] = \beta x + E[U_Y]$——注意扰动项不被干预清除。这就是为什么「干预教育年限」不等于「把回归系数捡出来直接用」：回归系数只在无混杂时等于结构系数。

**辨析｜易错点：** 「结构系数」与「回归系数」同名同符号，含义截然不同。回归系数描述「给定其它变量后 $Y$ 的平均变动」，是数据拟合量；结构系数描述「单方面改变 $X$ 一个单位时 $Y$ 的因果变动」，是机制参数。**只有后者能回答干预问题，且只有无混杂时两者数值相等**——把回归结果报成因果，是观测研究里最顽固的错误之一。

用一组数字把「干预 ≠ 回归」钉死。设教育–收入结构模型为 $Y = 10000 X + 20000 + U_Y$（每多一年教育收入多 1 万元），并存在能力 $U_C$：$X = 2 + 0.5 U_C$、$U_Y = 2000 U_C + \varepsilon$，$U_C \sim \mathcal{N}(0,1)$、$\varepsilon$ 为噪声。观测回归斜率 $\operatorname{Cov}(X,Y)/\operatorname{Var}(X)$ 会混入「能力强 → 教育高且收入高」的通道，估计值明显大于 10000（$U_C$ 影响强时甚至翻倍）。而 $\text{do}(X{=}x)$ 把 $X$ 的方程删掉、$U_C$ 不再推动 $X$，效应恰为 $E[Y\mid\text{do}(X{=}x)] = 10000x + 20000 + E[U_Y]$——**系数干净地回到 10000**。同一份数据，两种解读、两个世界。

## 5 SCM 的家族与统摄力

SCM 不是孤立模型，它统摄了本专题几乎所有工具，也催生了完整的方法家族：

**线性 SCM（structural equation models, SEM）**：$f_i$ 全为线性，是计量经济学的标准形态，对应路径系数与 2SLS（第 5 篇）的载体。
**非线性 SCM**：$f_i$ 任意，是第 9 篇因果发现的「加性噪声」识别法的用武之地。
**潜在结果框架**：SCM 的每个个体对应一个外生 $u$，$Y_x(u)$ 正是潜在结果 $Y(x)$——第 3 篇的记号是 SCM 反事实记号的实例。
**与 RCT**：随机化设计本质上是在构造一个「$X$ 没有父节点」的 SCM，让干预与观测重合。

一句话总结 SCM 的地位：**它是因果推断的「汇编语言」**——图是它的反汇编视图，潜在结果是它的个体化视图，do 演算是它的指令集。学会在三种视图间切换，就掌握了整个专题的地图。

**补充｜SCM 与机器学习：** 如今「因果机器学习」的大部分工作——反事实数据增强、干预下的分布漂移、「可解释性」里的「为什么」——都可以看作 SCM 在不同层级上的工程化：特征是内生变量，模型参数是结构系数的估计，正则化是对外生结构的先验。把这篇的语言换成「节点 / 方程 / 扰动」，就拿到了读懂那一类文献的钥匙。反过来说，SCM 也给机器学习补上了「干预语义」：普通模型的参数是数据拟合量，SCM 的参数是机制量——对做可解释 AI 的读者，这一课尤其要紧。

**一句话回望本专题：** 从因果图、do 演算、潜在结果到 SCM，工具在变，核心不变——因果推断的一切，都是在回答「把某处机制改写之后，世界会怎样」。SCM 把这个问题变成了一个可执行的计算；学会在三格图与四种视图间切换，就掌握了整个因果推断的地图。而下一步的自然延伸，是从数据自动反推出这张地图本身——这正是第 9 篇「因果发现」要完成的事。

| 对象 | 内容 | 能否回答干预 | 能否回答反事实 |
| --- | --- | --- | --- |
| 普通回归 / 统计模型 | $P(Y\mid X)$ 的拟合 | 否 | 否 |
| 贝叶斯网 / 联合分布 | 条件分布 $P(v_i\mid\text{pa}_i)$ | 否（需额外规则） | 否 |
| DAG + do 演算 | 图结构 + 干预规则 | 是 | 否 |
| SCM | 图 + 函数 $f_i$ + 外生 $U$ | 是 | 是 |

| 术语 | 含义 |
| --- | --- |
| 外生变量 $U$ | 模型外部的「命运」，独立随机源头 |
| 内生变量 $V$ | 由结构方程决定的变量 |
| 结构方程 $v_i=f_i(\text{pa}_i,u_i)$ | 因果机制的确定性函数 |
| 因果层级 | 关联 → 干预 → 反事实，逐层不可约 |
| 诱导 DAG | 把每个 $f_i$ 的父变量画成有向边 |
| 结构系数 | 单方面改变 $X$ 的因果参数，≠ 回归系数 |
| 路径系数 | 线性 SCM 中沿有向边的结构系数 |

**自查清单：** 读因果论文时先分清它站在哪一层——讲的是关联（回归与相关）、干预（do 操作），还是反事实（$Y_x(u)$）。层级不同，结论的可移植性与识别假设完全不同；分清层级，是读懂整篇文献的第一步。

## 6 小结

- **SCM = $\langle U, V, F, P(U)\rangle$**：外生变量、内生变量、结构方程 $v_i=f_i(\text{pa}_i, u_i)$、外生分布。
- 结构方程**非对称**：$Y=\beta X+U$ 不可反写；干预即「替换方程、保留 $U$」。
- **三格图**：关联 → 干预 → 反事实，逐层不可约；SCM 是唯一同时承载三层的对象。
- SCM 诱导 DAG，但图是粗糙化；反事实可能依赖 $f_i$ 的具体形式。
- 结构系数 ≠ 回归系数：前者是因果机制参数，后者是数据拟合量，无混杂时才相等。

在下一节，我们从一个「反方向」的问题出发：如果没有人事先画出 DAG，能不能**从数据本身把因果图找出来**？这就是**因果发现算法**——它依赖更苛刻的假设（忠实性、加性噪声等），也正因为如此，它的适用范围与边界值得单独一章讲清。
