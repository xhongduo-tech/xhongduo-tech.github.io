## 为什么从「给世界加上时间轴」开始

第六篇用 Sora 展示了「用像素预测世界演化」，但像素流是不可编辑的。这一篇回到重建的主线，回答一个更工程化的问题：**能不能把一段视频里的动态场景，重建成一个真正的 4D 表示——三维空间 + 一维时间，随时可查询、可定格、可重演？** 答案在 2020—2024 年由两条线索接力完成：先是**动态神经辐射场**（D-NeRF、Nerfies），后是**动态高斯**（Deformable-3DGS、4D-GS），后者把「可玩可编辑的 4D」第一次推进到实用区间。<span class="marginnote">「4D」在这里不是科幻里的时空，而是工程里的索引：<strong>4D 表示 = 一个把 $(x,y,z,t)$ 映射到「该时刻该位置的几何与外观」的函数</strong>。静态 NeRF 是 $t$ 被冻结的三维特例；4D 只是把第四维请回来，并回答「时间上如何一致」。本篇的核心就是这三件事：怎么表示时间、怎么让时间连续、怎么在时间上保持物体身份不漂移。</span>

这条主线对空间智能至关重要：机器人看到的永远是**动的世界**——行人在走、门在被推、手在抓取。能重建动态场景，才能谈「预测下一时刻」「在时间上规划动作」。它也是第六篇世界模型与第四篇 3DGS 的「交叉点」：**世界模型负责「想象未来」，4D 重建负责「记住并回放真实的运动」**，两者共用同一个时间轴。

动笔之前，先厘清一个概念边界：**4D 重建（reconstruction）与 4D 生成（generation）**。4D 重建的输入是真实视频，目标是「忠实还原发生了什么」——它是「看见 + 记忆」的产物；4D 生成（由第五篇的 3D 生成 + 第六篇的视频生成延伸而来）的输入是文本/单图，目标是「想象一段新运动」——它是「推理」的产物。两者在 2024 年后开始合流：用 4D 重建为生成提供「运动先验」，用 4D 生成为重建补全缺失帧。**理解这条「重建与生成在时间轴上的双向奔赴」，是读懂本专题后半部的关键。**

在认知科学里，这一篇还对应一个深刻的经验：**人类对「物体运动」的感知远早于对「物体形状」的抽象认知**。婴儿先会「追踪移动的球」（4D 感知），之后才学会「球的形状」（3D 概念）。空间智能的演进路径与人类似——先把「动的世界」记下来，再抽象出「静的几何」。**把时间放在几何之前，不是工程妥协，而是与智能发育顺序一致的选择。**

## 1 动态重建的三大难题

把静态重建升级到动态，不是「多一个输入维度」那么简单，它带来三个环环相扣的难题：

- **表示问题**：静态场景是一个场 $F(x,y,z)$，动态场景是 $F(x,y,z,t)$——直接让 $t$ 进网络是「朴素动态」，但这样每个时刻都要重新学，信息不共享，训练数据也被摊薄（每帧的约束都少了）。更好的做法是**解耦「不变的形状」与「变化的运动」**。
- **运动问题**：同一个物体在不同时刻是「同一份几何在移动变形」，还是在「重新生成」？正确的答案是前者——必须保证**物体身份（identity）**跨时间稳定，否则就会「每帧重画一个场景」，出现闪烁与漂移。
- **时序一致问题**：重建出的 4D 在时间上必须**平滑**——不能这帧有只手、下帧手就消失。这与第六篇 Sora 遇到的「物体凭空消失」是同一个病根，只是 4D 重建可以用显式几何约束来压制它。<span class="marginnote">这三个难题其实对应了第一篇「空间智能四能力」里「记忆」与「推理」的交接：记忆要求「同一物体在时间里被认出来」（身份稳定），推理要求「运动轨迹平滑可预测」。<strong>4D 重建是「记忆」从空间延伸到时间的那一步。</strong></span>

用「数字人」这个最直观的例子感受三个难题的分量：想重建一段主播讲解的视频——「表示问题」要求主播的脸、身体、手势有一套统一的 4D 模型；「运动问题」要求表情与手势是「同一张脸在动」，而不是「每帧新画一张脸」（否则嘴唇对不上话）；「时序一致问题」要求 30 帧/秒的连续画面里没有闪烁、没有手突然换了一根。<strong>数字人就是 4D 重建的「体检报告」</strong>：任何一个难题没解决，成品都会「看着不对」。

## 2 给表示加时间的三条技术路线

把时间塞进一个 3D 表示，学界尝试过三类路线，理解它们等于理解了动态重建的设计空间：

- **路线 A：时间直接进输入（naive dynamic）**。把 $t$ 当成第 4 个坐标喂给同一个网络，即 $F(x,y,z,t) \to (c,\sigma)$。最简单，但每个时刻都被当成「一个新的静态场景」学，信息不共享、数据被摊薄，身份稳定无从谈起。**它适合「场景几乎不动」的慢变场景，作为基线存在。**
- **路线 B：标准空间 + 形变场（canonical + deformation）**。第三、四节的主角：几何存一份，运动由形变网络预测。**信息共享最好、身份最稳定**，是当前主流。
- **路线 C：4D 时空网格 / 哈希体（spacetime grid）**。把 $(x,y,z,t)$ 一起哈希进一个可微的 4D 特征网格（类似 Instant-NGP 从 3D 升到 4D），直接在网格里查「这个时空点」。**速度快、表达灵活**，但内存随 4D 体积增长，长视频会爆炸，需配合稀疏化。<span class="marginnote">三条路线不是互斥的：<strong>4D-GS 等最新工作常用「路线 B 的形变 + 路线 C 的时空网格」做混合</strong>——用时空网格预测形变，用标准高斯承载外观。这种「取各家之长」的组合，正是空间智能技术快速迭代的常态。工程师读论文时，先问「它属于哪条路线、补了哪条路线的短板」，比逐行读公式更有收获。</span>

这三条路线的演化顺序，恰好对应了「工程直觉」的进化：从「无脑加一维」到「解耦形状与运动」再到「用数据结构加速」——**每次进化都让「时间」这一维在计算上更便宜、在语义上更正确**。

给这三条路线配一个「什么时候用谁」的速查：只有几十帧、场景几乎静止、想快速看效果 → 路线 A；有几十到几百帧、物体做明显运动且需要编辑 → 路线 B；实时性要求高、场景受限（单物体、室内）→ 路线 C；工业级产品（数字人、虚拟制片）→ 路线 B + C 混合。**选路线不是比「哪个高级」，而是比「哪个匹配数据与目标」**——这也是空间智能工程里最常被忽视的判断力。

## 3 动态神经辐射场：先建「标准姿势」，再学「怎么变形」

动态 NeRF 的代表性解法是**「标准空间 + 形变场」**，它把「不变的形状」和「变化的运动」彻底分开。以 D-NeRF（2021）为例：模型学习一个**标准空间（canonical space）**里的静态 NeRF——所有时刻的物体都先「摊回」到同一个参考姿势；再用一个**形变网络（deformation network）**把任意时刻 $t$ 的观测坐标，映射回标准空间的坐标。<span class="marginnote">这个「先定标准、再学变形」的思路在动画行业已有百年历史——<strong>绑定（rigging）与形变（skinning）</strong>就是给一个模型设「标准骨架」，再用关节旋转驱动表面变形。NeRF 只是把「骨骼形变」换成了「神经网络形变」。人类直觉先行的行业惯例，常常是机器学习最好的蓝图。</span>

形式化地，把时刻 $t$ 的空间位置 $\mathbf{x}$ 通过形变场送回标准空间：$\mathbf{x}_{\mathrm{can}} = \mathbf{x} + \Delta(\mathbf{x}, t)$。标准空间的 NeRF 接受 $\mathbf{x}_{\mathrm{can}}$ 与观察方向，输出该物体的颜色与密度。渲染时对每个 $(\mathbf{x}, t)$ 都先查形变场再查颜色场，于是**几何与外观只用学一次，运动只是「怎么变」**——训练数据在时间上被共享，身份稳定也有了保证。

这条路的两个里程碑值得记住。**Nerfies（2021）**提出「学习的变形 + 学习的外观」，专门解决「手持相机自拍」这类**非刚体（non-rigid）**场景——脸部表情、衣褶变化都能被形变场吸收；**HyperNeRF（2021）**把「标准空间」升级为「高维拓扑空间」，解决「物体拓扑变化」的难题——比如张嘴、开合手掌这类无法用连续形变表达的切换。这两个名字说明了一个事实：**「标准 + 形变」不是一个技巧，而是一个家族**，它们的共同承诺是「用一次几何承载所有时刻」。

训练这一族模型的目标函数，仍是第三篇那条重建误差，但求和范围从「多张照片」扩成「所有帧 × 所有像素」：对视频的每一帧，从该帧相机位姿渲染，与真实帧做 L2 距离，梯度同时更新「标准几何」与「形变网络」。**视频的每一帧都在为一个共享的几何投票**——这正是「标准 + 形变」数据共享的具体含义，也是它比「逐帧重建」数据效率高的原因。

## 4 公式解析：形变场与时间一致性

动态高斯（Deformable-3DGS, 2023；4D-GS, 2024）把同一套「标准 + 形变」搬进显式高斯。每个高斯在标准空间里有自己的位置与形状，随时间 $t$ 由一个轻量网络（常是 4D 网格或小 MLP）预测形变：

$$
\mu(t) = \mu_{\mathrm{can}} + \Delta\mu(\mu_{\mathrm{can}}, t), \qquad \Sigma(t) = \Sigma_{\mathrm{can}} + \Delta\Sigma(\mu_{\mathrm{can}}, t)
$$

拆成三步理解这条「动态高斯」公式：

- **第一步，$\mu_{\mathrm{can}}, \Sigma_{\mathrm{can}}$ 是标准姿势**：高斯们各有一个「默认位置与形状」，类似骨架的默认姿态。
- **第二步，$\Delta\mu, \Delta\Sigma$ 是形变预测**：一个以「位置 + 时间」为输入的小网络，输出每个高斯在当前时刻的位置偏移与形状偏移——它学会的是「这个点在这个时刻该挪到哪、被拉成什么样」。
- **第三步，物理与统计上的软约束**：形变网络输出**稀疏、平滑**（局部运动一致性正则），并要求不透明度 $\alpha$ 与颜色跨时间稳定——物体表面在时间上不能凭空闪烁，这是时序一致性的工程保证。

公式的妙处在于：**高斯的位置与形状被「借来借去」**——同一批高斯承载了所有时刻的几何，运动只是「借用姿势」。因此编辑（换颜色、删物体）只需做一次，就能沿时间轴全局生效。**「标准 + 形变」是让 4D 可控的钥匙。**

这条公式还有一个值得玩味的**信息论视角**：动态场景的信息可以拆成「几何（静态，信息量巨大但时间不变）」与「运动（动态，信息量较小但随时间变化）」两部分。把两者分开表示，等于**做了维度的信息压缩**——标准空间存「不变的多数」，形变场存「变化的少数」。这也是为什么「标准 + 形变」在同等重建质量下，往往比「朴素动态」更省参数、更稳收敛。**好的 4D 表示，本质上是一次对「时间上的冗余」的压缩**——这个思路在第九篇城市级重建里会以「分块」的形式再次出现。

工程上，要让「时间平滑」这条软约束真正落地，损失函数通常还会加上几项正则：**形变幅度的 L2 惩罚**（鼓励小形变，防止网络「滥用」形变场去弥补几何错误）、**相邻时刻形变的一致性**（让运动在时间上连续）、以及**表面处的密度/不透明度稳定项**。这几项正是「时间一致性」在代码里的化身——**没有正则的形变场，会退化成「逐帧重画的快捷方式」，让身份稳定承诺落空。**<span class="marginnote">与第三篇 NeRF 的位置编码对比：这里的时间 $t$ 也常被位置编码成多频率信号，让形变网络既能表达慢的刚体运动，也能表达快的局部抖动——「时间也要调频」。读到这里你会发现，<strong>「坐标（含时间）→ 特征 → 属性」这个骨架，从静态 NeRF 到 4D 高斯从没变过，变的只是「多问了一个时刻」</strong>。</span>

## 5 从视频到 4D：重建流程与评测

把一段视频建成 4D 场景，工业流程与第六篇预告的「视频→4D」管线一致，但多了一个关键决定：**物体怎么在时间上被识别并跟踪**。当前主流的做法是「联合优化」：假设相机位姿已知（或用 SLAM 估计），把所有帧的所有高斯放进同一个优化问题，用「标准 + 形变」共享几何，同时约束运动平滑。评测则看两类指标：**新视角合成质量**（在没见过的相机角度渲染是否真实）与**时间一致性**（同一物体的外观、形状跨帧是否稳定）。

完整流程可以走一遍，帮你把各环节钉进记忆：**第一步，相机位姿**——用运动感知的 SLAM 或逐帧 SfM 估计每一帧的相机（必要时同时估计 4D，粗到细精修）；**第二步，初始化**——把第一帧（或稀疏重建）的高斯放进标准空间，作为「骨架」；**第三步，联合优化**——在全部帧上最小化重建误差，同时精修标准几何、形变网络与位姿；**第四步，输出与评测**——导出 4D 场景（高斯/网格），按新视角质量与时间一致性验收。**「先定骨架、再精修」的两段式，又一次在动态场景里登场**——它已经从「工程惯例」升级为「空间重建的通用范式」。<span class="marginnote">一个容易被低估的工程细节：动态场景重建对「初始相机位姿」极其敏感——视频里的场景在动，COLMAP 的静止假设会失效，于是很多工作改用「运动感知的 SLAM」或「光度+几何联合优化」同时估计位姿与 4D。这与第二篇「先给初值、再精修」的两段式一脉相承，只是初值更难给了。</span>

动态场景重建还在两条「边界」上快速扩张：**更长的时间跨度**（从数秒到数分钟乃至数小时，靠分段时间轴与流式更新）与**更强的编辑能力**（点选一个物体，改它的运动轨迹，或干脆让它在 4D 里「消失」）。这两条边界恰好对应空间计算（第八篇）与产业应用（第十二篇）的需求。

值得单独说一句「编辑」：静态 3DGS 里「删一个物体」只需删掉对应高斯簇，但动态场景里「删一个运动中的物体」要求把它的高斯在**所有时刻**都删干净，且不能误删被它挡住的背景——这需要一个「时间上一致」的语义分割。2024 年的 4D 编辑工作（结合基础模型做跨帧语义分割）正是为此而生。**「编辑」是检验 4D 表示是否真「结构化」的试金石**：能跨时间编辑，说明表示里真的存着「物体」，而不只是一团会动的像素。<span class="marginnote">这也解释了为什么 4D 高斯（显式）比 4D NeRF（隐式）更适合做产品：<strong>显式表示天生带有「图元边界」，分割与编辑更直接；隐式场要编辑必须先「萃取表面」再重渲染</strong>。又一次，「显式化」在工程便利上胜出——这与第四篇的结论完全一致。</span>

## 6 核心对比表：静态 vs 动态表示

| 维度 | 静态（NeRF/3DGS） | 动态（D-NeRF/4D-GS） |
| --- | --- | --- |
| 输入 | $(x,y,z)$ | $(x,y,z,t)$ |
| 表示策略 | 直接存场 | 标准空间 + 形变场 |
| 身份稳定性 | 天然（静止） | 需显式约束 |
| 数据需求 | 多视图照片 | 视频（多帧） |
| 新视角合成 | 是 | 是（任意时刻任意视角） |
| 时间重演/倒带 | 无 | 有 |
| 可编辑性 | 中 | 高（一次编辑全时生效） |
| 计算成本 | 高 | 更高 |

表中的「时间重演」与「可编辑性」两行，是 4D 表示的独特价值：**把「运动」变成可以回放、修改、重演的资产**——这正是影视虚拟制作、数字人、机器人仿真（第十二篇）梦寐以求的能力。

还有一条「本表之外」的维度值得补上：**4D 表示对机器人「训练数据」的意义**。机器人策略训练（第十篇）需要的正是「可重放、可修改、可加动作」的场景——而 4D 重建恰恰产出这种数据：把一段真实演示重建为 4D，就能在仿真里反复回放、施加不同扰动、生成海量变体。**4D 表示是「真实世界 → 仿真训练数据」的转换器**——它让现实世界本身变成了一个可无限采样的数据源。

## 7 小结

- **4D 表示 = 把 $(x,y,z,t)$ 映射到几何与外观的函数**；静态表示只是 $t$ 冻结的特例。
- 动态重建三大难题：**表示（解耦形状与运动）、运动（身份稳定）、时序一致（不闪烁不消失）**。
- 加时间的三条路线：**时间直进输入**（朴素）、**标准 + 形变**（主流）、**4D 时空网格**（快速）；最新工作常做两两混合。
- 「标准空间 + 形变场」是主流解：几何只学一次，运动由轻量网络预测——**「先定标准、再学变形」与动画的骨骼绑定一脉相承**。
- 动态高斯公式 $\mu(t) = \mu_{\mathrm{can}} + \Delta\mu$ 让同一批高斯承载所有时刻，编辑一次即可沿时间轴全局生效；「标准 + 形变」本质是对时间冗余的信息压缩。
- 数字人是最直观的体检报告：三大难题任何一个没解决，成品都会「看着不对」。
- 评测看**新视角质量 + 时间一致性**双指标；长时重建、可控编辑是两条扩张边界，显式表示的「图元边界」让 4D 编辑更直接。
