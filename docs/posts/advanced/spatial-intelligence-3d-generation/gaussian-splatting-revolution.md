## 为什么从「显式化革命」开始

上一篇结尾留下一个悬念：NeRF 画质惊人，但渲染要逐像素查网络，秒级才能出一帧。2023 年，**3D 高斯泼溅（3D Gaussian Splatting, 3DGS）**给出答案：**把场景表示成几十万个显式的 3D 高斯椭球，渲染时直接光栅化泼到屏幕上——没有一次网络查询，只有 GPU 天生的光栅化流水线**。训练在单张 GPU 上几分钟完成，渲染超过 100 fps，画质还追平乃至超过 NeRF。<span class="marginnote">「显式化革命」这个名字值得拆解：「革命」不在于发明了新数学，而在于<strong>把表示从「隐式函数」拉回「显式点集」</strong>——一次看似倒退、实为升维的螺旋回归。第三篇的隐式场解决了「连续与可微」，这一篇的显式场解决了「速度与可控」，两者在 3D 内容生成管线上各司其职。</span>

3DGS 的谱系可以回溯得很远：**点溅射（point splatting）**是 1990 年代图形学用「点/椭圆当图元」画点云的经典技术，**EWA splatting** 则用各向异性高斯做高质量滤波。3DGS 的贡献是把这套古老思想变成**可微的、可训练的**，并配上一个为 GPU 量身定制的光栅化器——「古老的图形学 + 现代可微渲染」又一次组合出惊艳结果。这也提醒我们：空间智能的很多突破，不是新概念，而是**把老概念放进可微框架**。

把这条谱系再拉远一点，你会看到完整的「螺旋回归」：**1990 年代的显式点云 → 2000 年代的隐式场（Level Set、SDF）与基于物理的渲染 → 2010 年代深度学习把「表示」交给网络（DeepSDF、Occupancy Network）→ 2020 年 NeRF 把隐式场推到巅峰 → 2023 年 3DGS 回归显式**。每一次「回归」都不是倒退，而是把上一轮学到的东西内化：3DGS 吸收了隐式场「可微渲染、端到端优化」的全部遗产，只是把存储从「函数参数」换回「显式数据」。**技术史的常态不是线性进步，而是螺旋上升——记住这个模式，读第七、九篇时你会不断重温它。**

给三个数字帮你建立「显式化革命」的体感（均为 3DGS 论文报告的代表性结果）：**训练约 7–30 分钟**（NeRF 往往要 1 小时以上）、**渲染 100+ fps**（NeRF 秒级/帧）、**PSNR 追平并超过 NeRF**。前两个数字说明「从离线走向实时」，第三个说明「快没有牺牲质量」——三者同时成立，才是这场革命成立的充要条件。也正因为如此，2023 年下半年起，几乎所有新视角合成、数字人、机器人仿真系统都默认以 3DGS 为表示层。

## 1 场景 = 几十万个 3D 高斯

3DGS 把场景表示为一组 **3D 高斯（椭球）**，每个高斯携带四组参数：

- **位置** $\mu \in \mathbb{R}^3$：椭球中心，决定「糊」在哪里。
- **协方差矩阵** $\Sigma$：椭球的形状与朝向；为保证正定，用**旋转四元数** $q$ + **各向异性尺度** $s$ 参数化：$\Sigma = R\,S\,S^\top R^\top$。
- **不透明度** $\alpha$（0~1）：椭球「实不实」。
- **颜色** $\mathbf{c}$：用**球谐系数（spherical harmonics）**表达，实现视角相关的高光。

一个 3D 高斯是空间中的高斯分布：

$$
G(\mathbf{x}) = \exp\left(-\tfrac{1}{2}(\mathbf{x}-\mu)^\top \Sigma^{-1} (\mathbf{x}-\mu)\right)
$$

**场景 = 一堆这样的小椭球「糊」在一起**：表面处椭球密且不透明，空处没有椭球，半透明处（毛发、烟）用低 $\alpha$ 的椭球堆叠。

这条公式值得与第三篇的体渲染积分对照：NeRF 的 $\sigma$ 也是「密度」，但它是从 MLP 里**查询**出来的；3DGS 的「密度」则是**每个高斯自带一个形状**。可以说 3DGS 是「把连续密度场离散化成一群带形状的基元」，体渲染积分里那段 $T\sigma$ 的加权，变成了离散的 α 混合——**同一个物理模型，换了实现方式，速度差了三个数量级**。<span class="marginnote">严格说，3DGS 的 α 混合与 NeRF 的体渲染积分在连续极限下等价——这正是「离散化正确的概率模型」的又一次体现，与第二级概率统计里「积分 = 极限下的求和」一脉相承。理解这个等价，你就同时看懂了 NeRF 与 3DGS 两个范式。</span><span class="marginnote">与 NeRF 的关键对照：NeRF 用一个共享的 MLP 记整个场景，3DGS 用几十万个<strong>独立的</strong>高斯记同一个场景。「独立」意味着每个高斯可以单独增删、移动、改变形状——这给「可控性」打开了大门：想删一个物体，直接删它对应的高斯簇；想编辑，直接移动高斯。显式表示在这方面的天然优势，是隐式函数很难企及的。</span>

初始化的细节值得交代：3DGS 的第一批高斯通常直接用 **COLMAP 稀疏点云**（第二篇的 SfM 产物）当种子，每个点变成一个高斯。这带来一个漂亮的**闭环**——第一篇的几何、第二篇的 SfM、第三篇的隐式场、本篇的显式高斯，四篇的技术在同一个管线上握手：**SfM 提供初值，神经表示负责精修**。这也是为什么本专题坚持把几何放在最前面：没有第二篇的相机位姿，4DGS 连起点都没有。

## 2 公式解析：高斯椭球如何「泼」到屏幕上

可微渲染的核心问题是：**3D 高斯怎么变成一个屏幕上的 2D 斑，并且全程可求导？** 3DGS 的做法是「先投影、再泼溅」两步走。

首先，把 3D 高斯按相机做投影变换，得到它在像平面上的 2D 高斯（其 2D 协方差由雅可比近似给出）：

$$
\Sigma' = J\,W\,\Sigma\,W^\top J^\top
$$

拆三步理解：

- **第一步，$W$ 是视图变换**：把世界坐标旋转平移到相机系，对应第一篇讲的外参 $[R\mid t]$。
- **第二步，$J$ 是投影的雅可比**：针孔投影（透视除法）是非线性的，但**在椭球中心的局部可以用一次线性近似**——雅可比矩阵就是这个局部线性化，它把 3D 协方差「推」成近似的 2D 协方差。
- **第三步，$\Sigma'$ 就是这个 2D 高斯**：它定义了屏幕上那个椭圆斑的朝向、长宽与倾斜。**「泼溅（splat）」就是把每个 3D 高斯按这个 2D 斑的形状，平铺到对应像素区域上。**

于是「渲染」变成了：**每个像素收集它被哪些 2D 斑覆盖，按深度排序，再按不透明度做 α 混合**——这与传统图形学画半透明层几乎一模一样，只是图元从「三角形」换成了「可微的高斯斑」。所有环节都是标准的可微操作，梯度可以一路流回每个高斯的 $\mu, \Sigma, \alpha, \mathbf{c}$。

还有一块拼图值得单独提：**球谐（spherical harmonics）颜色**。3DGS 不用「三通道颜色」而用一组球谐系数，是因为球谐是定义在球面上的正交基，天然适合表达「颜色随观察方向连续变化」。每个高斯存 1 阶（4 个系数/通道）或 3 阶（16 个系数/通道）的球谐，渲染时按当前视线方向查值——**用极少参数换来了近似 NeRF 的视角相关外观**。这是「显式表示 + 少量函数」的又一结合：全局用显式点，局部用基函数，两条路都不浪费。<span class="marginnote">为什么要用「先投影再泼」而不是直接把 3D 高斯采样成点？——因为一个椭球在屏幕上覆盖的是一个区域而不是一个点；只有区域化的 2D 斑才能表达「半透明椭球的整体贡献」。这一步把「点溅射」升级成了「区域溅射」，是画质提升的关键之一。</span>

## 3 可微光栅化 + 自适应密度控制：为什么能实时

3DGS 的实时性来自一个工程杀手锏：**基于分块（tile-based）的 GPU 光栅化器**。它把屏幕切成 $16\times16$ 像素的小块，对每个小块**预计算「哪些高斯可能覆盖这块」**，然后在每块内部对覆盖它的高斯按深度排序、α 混合——这样就把「全局几十万个高斯」的排序问题，拆成「每块局部几十个高斯」的排序问题，GPU 并行度拉满，同时避免逐像素查网络的昂贵代价。<span class="marginnote">排序是 α 混合正确性的关键：必须先画远的、再画近的。3DGS 把排序限制在小块内完成，把复杂度从 $O(N\log N)$（全局排序）降到块内的 $O(n\log n)$（n 为小块内的高斯数），配合 GPU 的并行归并，是「100+ fps」的直接来源。这个「分块 + 局部排序」的思路，在工程上几乎是为现代 GPU 的并行架构量身定做。</span>

训练端则靠**自适应密度控制（adaptive density control）**：网络在梯度下降的同时，每隔若干迭代检查每个高斯——**该克隆就克隆**（高斯过大、欠拟合时，复制成两个小的高斯）、**该分裂就分裂**（高频细节处把一个拉长的高斯劈成两个）、**该删除就删除**（不透明度接近 0 或体积过大的「漂浮物」直接移除）。这让高斯数目从初始的几百个稀疏点，自动增长到几十万，精确贴合场景复杂度。**「让表示自己决定需要多少参数」**，是 3DGS 训练范式的灵魂，也直接来自点云初始化（通常用 SfM/COLMAP 的稀疏点云做种子）。

一条完整的 3DGS 渲染管线可以这样走一遍，方便你把各环节串起来：**第一步，投影**——所有高斯经 $W, J$ 投影成 2D 斑；**第二步，分块**——把屏幕切成 $16\times16$ 小块，每个小块记录覆盖它的高斯 id；**第三步，排序**——块内按深度从小到大排列；**第四步，混合**——按序对每块逐像素做 α 混合，输出颜色；**第五步，反向**——把像素损失沿混合链一路求导回每个高斯的四个参数组。前向是「画」，反向是「教」，两次都在 GPU 上以毫秒级完成。<span class="marginnote">这套管线与经典图形学的距离有多近，与 NeRF 的距离就有多远——这正是它快的本质：<strong>3DGS 把「渲染」从「解网络方程」变回了「画椭圆、排前后、调透明度」</strong>，而这恰好是 GPU 自诞生起就最擅长的事。</span>

## 4 短板与快速生态：革命也需要补丁

3DGS 并非没有缺点，而且这些缺点恰恰预告了后续几篇的技术走向：

- **内存与带宽**：几十万个高斯显式存储，动辄几百 MB 到上 GB，远大于 NeRF 的紧凑参数；对大场景（第九篇）需要流式/分块管理。
- **视角一致性的边界**：球谐只到 3 阶（约 16 个系数），超宽视角、强镜面反射时有残差；需与基础反射模型（如带法线的高斯）配合。
- **动态场景**：原生 3DGS 是静态的，加时间维度需要专门的 4D 扩展——这正是第七篇《4D 动态场景》的主题。
- **无监督的「漂浮物」**：从稀疏点云初始化时，若有少量错误点云，会训出悬浮在空中的「幽灵高斯」，需正则或更干净的初始化。

围绕这些短板，2023—2024 年形成了一条庞大生态：**2D 高斯（2DGS）**把椭球压成平面以贴合表面、**GaussianEditor** 系列做高斯的语义编辑、**SplaTAM / GS-SLAM** 把高斯接进 SLAM、**4D-GS / Deformable-3DGS** 把高斯推向动态。每一支都直接服务于本专题的某篇——这是「显式化革命」深度渗透空间智能每个环节的写照。

还有一条容易被忽视的支线：**高斯压缩**。内存过大不是「忍一忍」的工程问题，而是「空间智能能否上移动设备」的门槛问题——一个 200 MB 的场景没法塞进手机或头显。为此出现了基于向量量化、结构化剪枝与感知编码的高斯压缩方案，目标是把单场景压到几 MB 而画质几乎不变。它与第八篇《空间计算平台》的终端约束直接相关：**实时渲染的表示，还必须轻到能放进用户的设备**。<span class="marginnote">一个判断技术生命力的简单标尺：<strong>看它能否长出生态</strong>。NeRF 长出了 Mip-NeRF、Instant-NGP 一整代；3DGS 在一年内长出了动态、编辑、SLAM、压缩、生成五条支线——这种「一个表示、全面开花」的态势，正是它在空间智能主线中从「可选」变成「默认」的原因。</span>

## 5 核心对比表：NeRF vs 3DGS

| 维度 | NeRF（隐式） | 3DGS（显式） |
| --- | --- | --- |
| 场景表示 | MLP 函数 | 几十万个高斯点 |
| 渲染方式 | 逐像素查网络 | 分块光栅化 + α 混合 |
| 训练时长 | 数十分钟~小时 | 数分钟~十几分钟 |
| 渲染帧率 | 秒级/帧 | 100+ fps |
| 内存 | 紧凑（参数少） | 显式存储，随场景增长 |
| 可控性 | 弱（不好编辑） | 强（直接操作高斯） |
| 抗锯齿 | 需 Mip-NeRF | 用 2D 高斯尺寸控制 |
| 工程难度 | 简单可复现 | 需 CUDA 光栅化器 |

表中的「渲染帧率」与「可控性」两行，是 3DGS 能成为空间智能基座的决定性优势：**实时渲染意味着模型可以边观察边重建（SLAM 场景、机器人导航），可控性意味着它可以被用作 3D 资产生成、场景编辑的中继格式**。第六篇、第七篇、第九篇会反复看到 3DGS 在这些岗位上的身影。

一个务实的补充：**在实际管线里，NeRF 与 3DGS 常常不是二选一，而是接力**。NeRF 谱系更擅长「欠约束」场合的合理补全（第五篇的 DreamFusion 就用 NeRF 当生成画布），3DGS 更擅长「约束充分」场合的实时重建（第九篇的大场景、第十篇的仿真）。理解两者的分工而非对立，比记住任何单一结论都重要——这也是本专题反复强调「范式互补」的原因。

## 6 小结

- **3DGS 把场景表示成显式高斯集**：位置 + 协方差（旋转四元数 × 尺度）+ 不透明度 + 球谐颜色，几十万个即可表达逼真场景。
- **投影公式 $\Sigma' = J W \Sigma W^\top J^\top$**：视图变换 + 雅可比线性化，把 3D 椭球变成可微的 2D 斑，「泼溅」即区域化平铺。
- **α 混合与体渲染积分在连续极限下等价**：同一个物理模型换了实现方式，速度差三个数量级——这是「离散化正确的概率模型」的胜利。
- **分块光栅化器**把全局排序拆成小块内排序，配合 α 混合实现 100+ fps 实时渲染；正向「画」反向「教」都在 GPU 毫秒级完成。
- **自适应密度控制**让高斯自动克隆、分裂、删除，表示规模自适应场景复杂度；初始化常吃 COLMAP 稀疏点云。
- 3DGS 的短板（内存、动态、漂浮物）催生了庞大的生态，动态、编辑、SLAM、生成四条支线直通本专题后续各篇。
- 初始化吃 COLMAP 稀疏点云，形成「几何给初值、神经做精修」的闭环——前四篇在一条管线上握手。
- 「显式化革命」的本质是**把表示从隐式函数拉回显式点集**，用速度与可控换连续与紧凑——两代范式各司其职，3DGS 由此成为空间智能基座。
- 对空间智能的整体意义：**实时性把 3D 从「离线产物」变成「在线交互对象」**，这是机器人在线导航、具身仿真、空间计算得以成立的前提。

在下一节，我们将离开「重建」二字，第一次回答「**凭空造 3D**」的问题：如何让扩散模型从一段文字里「蒸馏」出一个全新的 3D 模型。你会看到，DreamFusion 谱系巧妙地站在了本专题前四篇的肩膀上——**它用 NeRF 或 3DGS 当可微画布，用 2D 扩散先验当裁判，把「文本→3D」变成了一个纯粹的梯度优化问题**。

这是一个漂亮的「拼接」：前四篇积累的「可微 3D 表示」是插座，第五篇要插进来的「扩散先验」是电源——两者一旦接通，「从无到有的 3D 生成」就有了第一套自洽的引擎。

届时你将亲眼看到，生成与重建如何在同一套梯度优化框架下合流。
