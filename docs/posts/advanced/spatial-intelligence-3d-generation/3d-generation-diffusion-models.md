## 为什么从「让 3D 从无到有」开始

前四篇都在回答一个「反向」问题：**从观测恢复 3D**。这一篇换一个正向问题：**从一段文字（或一张图）凭空造出一个全新的 3D 模型**。这不再是对真实场景的忠实复制，而是对「合理三维形状」的采样——它要求的不是几何精确，而是**先验正确**：生成的东西得「看起来像个杯子」「从任何角度看都是个杯子」<span class="marginnote">「从任何角度看都是个杯子」这句话藏着 3D 生成与 2D 生成最本质的差别：2D 扩散只需要让一张图看起来像，3D 生成必须让<strong>所有视角</strong>看起来都像——多视角一致性是 3D 生成独有的、也是最难满足的约束。本篇会反复回到这个「一致性」主题。</span>。

这里有一条关键的知识捷径：**我们不需要从头训练 3D 扩散模型**。2023 年前后，2D 扩散模型（Stable Diffusion、Imagen）已经非常擅长「画得像」；3D 生成的核心挑战变成——**如何把 2D 扩散的「画得 2D 像」的能力，升维成「3D 一致」的能力**。DreamFusion 给出了第一个惊艳的答案：让 3D 表示在梯度下降中「自问自答」——每次渲染一个随机视角，交给 2D 扩散模型打分，再把「哪里不像」的梯度传回 3D 表示。这就是**分数蒸馏采样（Score Distillation Sampling, SDS）**。

顺带澄清一个常见的概念混淆：**「3D 扩散模型」与「用 2D 扩散做 3D」是两回事**。前者指扩散模型直接作用在 3D 数据上（如 Point-E 在点云上做扩散），需要 3D 训练集；后者指把 2D 扩散当先验去优化 3D（DreamFusion 路线），不需要 3D 训练集。DreamFusion 之所以能「以小博大」，正是因为它走了第二条路——**用 2D 扩散的巨量先验，弥补 3D 数据的匮乏**。这条「借力」思路，在本专题之后几篇（视频世界模型、具身数据）里会不断重演。

所以本篇的读者应该具备两张「前情卡」：一张是**可微 3D 表示**（第三、四篇的 NeRF 与高斯），另一张是**2D 扩散模型**（第四级《计算机视觉》里的 DDPM/Stable Diffusion——去噪、加噪、噪声预测的机制）。如果对后者生疏，建议先回《扩散模型原理》一篇把「$\epsilon$ 预测」「引导」两个概念补上——本篇的 SDS 公式会频繁用到它们。**把旧知识带在身上，是读懂这篇的关键**。

## 1 3D 生成的两种范式

要理解 DreamFusion 的位置，先给 3D 生成的两大范式划清界限：

- **直接生成（feed-forward generation）**：训练一个「3D 生成器」，输入文字/图，**一次前向**直接输出 3D 表示（点云、网格、高斯）。代表：Point-E、Shap-E（OpenAI 2022—2023）、LRM（2023）。优点：快（秒级）、可批处理；缺点：需要海量 3D 训练数据，且泛化受限于训练分布。
- **优化式生成（optimization-based generation）**：不给生成器，只给**损失函数**，对每个输入从头优化一个 3D 表示。DreamFusion 是代表：**输入文字 → 随机初始化 NeRF → 数千步梯度下降 → 得到 3D 模型**。优点：无需 3D 训练数据、质量高；缺点：慢（分钟级/模型）、需防「多脸」（Janus）等退化。

这两种范式互补，且共享同一个核心洞察：**「3D 生成」与「2D 生成」不必分开做——让 2D 扩散先验驱动 3D 表示的优化即可**。

直接生成这条线内部也分「输出什么 3D 表示」：**Point-E** 用扩散模型输出点云（几万个点），最简单直接；**Shap-E** 用扩散模型输出一个神经辐射场（隐式），再可以提取网格；**LRM（Large Reconstruction Model）**则输入单张图、输出一个三平面（triplane）编码的 NeRF，靠海量 Objaverse 数据在秒级完成「单图→3D」。它们的共同代价是**训练数据的稀缺**——3D 资产不像图片那样取之不尽，这也是第十篇《具身数据引擎》要正面解决的问题。**「数据从哪来」将是贯穿 3D 生成与空间智能全线的终极瓶颈。**

值得注意的是，数据稀缺正在被「以图代 3D」和「以视频代 3D」两条路缓解：前者用互联网图片（2D 数据无限）驱动优化式生成，后者用视频（含动态、含多视角线索）驱动世界模型式生成。**每次「用什么数据」的突破，都会带来 3D 生成能力的一次台阶**——DreamFusion 证明了「2D 图片数据够用」，Sora 正在试探「视频数据能走多远」。读下一篇时请带着这个视角：视频，是不是 3D 数据的终极来源？<span class="marginnote">为何 2D 扩散能驱动 3D？因为「这个视角下看起来像不像」是可以逐视角判定的。把 3D 渲染成任意视角，2D 扩散模型都能给出「像不像」的梯度；把所有视角的平均梯度加起来，就得到「整体 3D 像不像」的方向。<strong>先验住在 2D，参数住在 3D，渲染器负责搭桥</strong>——这是 2023 年之后 3D 生成几乎所有工作的骨架。</span>

## 2 公式解析：SDS 损失

DreamFusion 的核心是一条看似反直觉的梯度公式。设 3D 表示参数为 $\theta$，从当前角度渲染出的图像为 $x = g(\theta)$（$g$ 是可微渲染器），把 $x$ 加噪到噪声等级 $t$ 得 $x_t$，用预训练的 2D 扩散模型预测噪声 $\epsilon_\phi(x_t; y, t)$（$y$ 是文字提示）。**SDS 的梯度是：**

$$
\nabla_\theta \mathcal{L}_{\mathrm{SDS}} \approx \mathbb{E}_{t, \epsilon}\left[\, w(t)\,\big(\epsilon_\phi(x_t; y, t) - \epsilon\big)\, \frac{\partial x}{\partial \theta} \,\right]
$$

拆三步读懂这条公式：

- **第一步，$(\epsilon_\phi - \epsilon)$ 是「哪里不像」**：$\epsilon$ 是真实注入的噪声，$\epsilon_\phi$ 是扩散模型在已知提示 $y$ 下预测的噪声。两者之差衡量「当前渲染 $x_t$ 在噪声视角下有多不符合提示 $y$」——扩散模型说「这里该是杯沿」，当前渲染的「杯沿」部分就收到一个把它推向杯沿的梯度。
- **第二步，$\frac{\partial x}{\partial \theta}$ 把梯度传回 3D**：这条雅可比链正是第三、四篇辛苦搭建的**可微渲染器**在起作用——NeRF 的体渲染、3DGS 的光栅化在这里都是「桥」。**没有可微渲染，SDS 就是一句空话。**
- **第三步，$w(t)$ 是权重、$\mathbb{E}$ 是期望**：对随机视角与随机噪声等级取平均，保证优化稳定；$w(t)$ 按噪声等级调节信号强度。

与标准的扩散训练（DDPM 的 $L = \|\epsilon_\phi - \epsilon\|^2$）相比，SDS 去掉了「损失」而直接使用**梯度**，且**不反传进扩散模型**（扩散模型权重冻结，只作「裁判」）。这就是「蒸馏（distillation）」二字的含义：把 2D 扩散的判别力，蒸馏进 3D 参数。

用一个不严谨但好记的类比收束这条公式：**把 2D 扩散模型想象成一位挑剔的雕塑老师，把 3D 表示想象成一块正在被雕刻的泥坯。** 老师不看泥坯本身，只看它每个角度投在墙上的影子（渲染图）；影子不像「目标雕像」，老师就说「这里高一点、那里瘦一点」（给出梯度），泥坯就按此修整。几千次「影子 + 反馈」循环后，泥坯变成了老师挑不出毛病的雕像。SDS 里那个「随机视角」的角色，正是让老师从所有角度检查泥坯——**多视角打分的机制，保证了雕塑在全方位都合格**。<span class="marginnote">这个类比还揭示了 SDS 的一个弱点：如果老师只被要求「像一张照片」（2D 先验），她可能给不出「这是三维实心体」的约束——于是泥坯会倾向于「某个视角很像、换个视角穿帮」。这正是多脸问题的根源，也是 3D 生成「先验空间维度不足」的本质体现。</span><span class="marginnote">一个著名的工程细节：DreamFusion 用的是基于 Imagen 的扩散模型，且设置了很高的引导权重（guidance weight ~100，远超 2D 生成常用的 7.5）。高引导让生成「过于饱和、卡通化」，但换来了几何稳定——这是「质量换稳定」的典型取舍，也解释了为什么 DreamFusion 的物体常常有种「浓妆艳抹」的质感。后续 ProlificDreamer 用变分分数蒸馏（VSD）显著缓解了这点。</span>

SDS 与 2D 生成里的**分类器引导（classifier guidance）**一脉相承：都是「用扩散模型对某条件求梯度」。区别在于，分类器引导的作用对象是「图像」本身（去噪过程里逐步拽向条件），而 SDS 的作用对象是「3D 参数」——图像只是中间媒介。**这个「把梯度越过渲染器送到 3D 参数」的间接操作，是 SDS 最具创造性的部分**，也是为什么它要求渲染器必须可微：梯度路径是「像素 → 渲染 → 3D 参数」，任何一环断了，整个优化就断了。理解这条路径，你就理解了「可微 3D」在生成侧的核心价值。

## 3 DreamFusion 谱系：一条快速扩张的家谱

DreamFusion 之后两年，几乎所有新工作都在回答它留下的四个问题：

- **更快（DreamGaussian, 2023）**：用 3DGS 代替 NeRF 做优化画布，训练从小时级压到分钟级，还能直接输出可编辑的高斯资产——它把第五篇的技术直接接到第四篇的表示上。
- **更真实（ProlificDreamer / VSD, 2023）**：把 SDS 升级为变分分数蒸馏（variational score distillation），把「单一分数」换成「分数分布」，缓解过饱和与多脸，生成更接近照片级的几何与纹理。
- **多视角一致性（Zero-1-to-3、MVDream, 2023）**：不再单视角打分，而是让扩散模型直接**同时生成多个视角**（或用「单图到任意视角」的条件扩散），从根源上压制「正脸」偏好。
- **前馈化（LRM、One-2-3-45, 2023—2024）**：把「为每个输入优化一个 3D」升级为「训练一个大模型、秒出 3D」——用海量（多视图 + 3D）数据预训练一个变换器，输入单图直接吐 NeRF 或高斯。这是向「直接生成」范式的靠拢，也是 3D 生成走向「大模型化」的方向。

这条谱系的发展方向可以概括成一句话：**从「慢但无需数据」走向「快但需要数据」，两端在「用大模型 + 数据换速度」处合流**。

关于「输出什么表示」，谱系内部也有清晰的梯队：**网格（mesh）**是行业通用格式（进游戏引擎、3D 打印都要用它），但可微渲染麻烦；**点云**最易生成但质量粗糙；**神经隐式场（NeRF/SDF）**质量高但难以直接交给下游工具；**高斯（Gaussian）**则在「质量、速度、可编辑」上取得折中——于是 2024 年的生成工作普遍以「先出高斯、再提网格」为最终管线。这个「表示即产品」的选择，与第十篇《具身数据引擎》中「3D 资产生成管线」的工程选择直接挂钩。

还要给 DreamFusion 本身一个公允的评价：它远非完美——分辨率受限（约 64×64 渲染）、无纹理几何易塌陷、没有「组合多个物体」的场景能力、每个 caption 都要从头优化。但它完成了一件历史性的工作：**证明了「文生 3D」不必等 3D 大数据集，2D 扩散先验已经足够**。这个「先验共享」的论断，让整个 3D 生成领域在 2023 年一夜之间从「缺数据」变成「有路可走」，其意义远超 DreamFusion 本身生成的物体质量。

从「评测」角度看，DreamFusion 也留下了一个常用基线：它对每个 prompt 生成的结果被用作「文生 3D」能力对比的锚点，后续工作都要在与它的对比中证明「更真、更快、更一致」。**一个领域需要锚点才能进步**——DreamFusion 恰好同时充当了「技术锚」与「评测锚」，这在论文史上并不常见。<span class="marginnote">把这条谱系与第五篇《视频生成即世界模型》对照会很有意思：SDS 用「2D 扩散当裁判」造 3D，Sora 用「视频扩散当世界模型」造动态世界——两者的共同哲学是「用 2D/视频的生成先验去逼近 3D/4D 的结构」，只是在「裁判的空间维度」上分道扬镳。</span>

## 4 两大顽疾：多脸（Janus）与过饱和

SDS 类方法在工程上最先撞见两个问题，理解它们就等于理解了 3D 生成的「易错点」。

**多脸问题（Janus problem）**：因为 2D 扩散模型「见过最多的正面」，优化过程会不自觉地在所有视角都堆出「正面特征」——一个本该只有一个脸的头像，会生成三个脸（前、左、右各一张）。「Janus（双面神）」之名由此而来。解法有三种：**视角提示**（按相机仰角切换「front/back/side」文字）、**多视角评分**（MVDream 一次渲染多视角）、以及**正则项**（约束密度/法线分布）。**Janus 问题本质上暴露了「2D 先验缺乏 3D 一致性」这个根本短板**——它无法被「多打分几次」根治，只能靠更强的先验结构压制。

**过饱和（over-saturation）**：高引导权重下，生成结果颜色浓烈、表面像「塑料玩具」。根源是 SDS 把「期望梯度」当成了「瞬时梯度」，方差被高估，导致整体「往最像的地方使劲」。ProlificDreamer 用**变分分数蒸馏（VSD）**把「单个分数」换成「分数分布」，从数学上修正了这个偏差，生成的物体因此更接近真实照片。

这两个顽疾还指向一个更根本的问题：**3D 生成到底该怎么「打分」？** 2D 生成有现成的图像质量指标（FID、IS），3D 生成却要同时评价「单视角画质」与「多视角一致性」——前者可以借用 2D 指标，后者必须新造。2023 年后的常见做法是：**CLIP 相似度**衡量「与提示的语义匹配度」，**CLIP 多视角一致性**衡量「不同视角渲染在语义上是否一致」，再辅以**几何指标**（如网格的流形质量、法线连续性）与人工偏好。但必须承认，**「3D 生成的好不好」至今仍缺乏一个公认的单一指标**——这是第十一篇《空间智能评测》要面对的核心难题，届时我们会把它放到「物理推理 + 空间问答」的更大框架里再谈。

还有一个稍显冷门却极具远见的判断值得记录：**3D 生成正在从「单物体」走向「场景」**。DreamFusion 那一代生成的是「一个花瓶」「一只鸟」，而空间智能真正需要的是「一张桌子上的花瓶、椅子、窗外的光」这种**有布局、有遮挡、有光照关系的整场景生成**。2024 年的「布局生成 + 物体生成 + 合成渲染」管线（如与 LLM 合作做场景布局，再逐个生成物体并摆放）已经在试探这条更难的路线——它把 3D 生成从「造单个模型」升级为「造一个小世界」，与第七篇 4D 动态、第十二篇数字孪生直接接壤。<span class="marginnote">这两个问题值得在「评测」层面记住：多脸是「多视角不一致」的极端形态，过饱和是「分布估计偏差」的极端形态。第十一篇《空间智能评测》会看到，几乎所有 3D 生成质量指标（视角一致性、几何正确率）都是为了量化这两个问题的缓解程度而设计的。</span>

## 5 核心对比表：两种生成范式

| 维度 | 直接生成（前馈） | 优化式生成（SDS 类） |
| --- | --- | --- |
| 推理方式 | 一次前向 | 数千步梯度优化 |
| 速度 | 秒级 | 分钟级 |
| 3D 训练数据 | 需要海量 | 不需要 |
| 泛化 | 受训练分布限制 | 受 2D 先验限制 |
| 多视角一致 | 靠模型内部保证 | 靠「多视角打分」保证 |
| 代表 | Point-E、Shap-E、LRM | DreamFusion、DreamGaussian、ProlificDreamer |
| 当前趋势 | 大模型化（预训练） | 与 3DGS 结合加速 |

这张表给出了 3D 生成产业化的坐标：**要「随叫随到」就选前馈，要「质量优先」就选优化式**；2024 年后的现实方案往往两者混合——先用前馈大模型快速生成粗糙 3D，再用优化式步骤精修。

这张表还有一个更宏观的启示，值得单独划出来：**2D 扩散（2022）、3D 生成（2023）、视频世界模型（2024）在时间轴上依次成熟，而它们的「配方」惊人地一致——一个大规模生成先验 + 一个可微的「画布」**。2D 的配方是「扩散先验 + 像素网格」，3D 的配方是「扩散先验 + NeRF/高斯」，下一篇你会看到，视频世界模型的配方是「扩散先验 + 时空 patch」。「先验的维度假了，画布的维度长了」——这句总结可以一路用到底。

最后回到本专题的主线给这篇定位：**3D 生成是空间智能「推理」能力的第一块真砖**。李飞飞定义的空间智能要求「预测物理演化、回答空间问题」，而预测的前提是**能把场景表征为可操作的 3D**——生成模型恰恰提供了这种「场景先验」。当机器能「凭空造一个合理场景」时，它离「想象一个场景会怎样演化」就不远了——这正是下一篇世界模型要做的事。

## 6 小结

- 3D 生成的独特难点是**多视角一致性**：「从任何角度看都像」比「一个角度看像」难得多。
- 两条范式——**直接生成**（快、需数据）与**优化式生成**（慢、靠 2D 先验）——互补并存；「先出高斯、再提网格」是产业管线的现实选择。
- **SDS 梯度** $\nabla_\theta L \propto \mathbb{E}[w(t)(\epsilon_\phi-\epsilon)\,\partial x/\partial\theta]$：2D 扩散当裁判、可微渲染器当桥、3D 参数当学徒，三者合力把「文本→3D」变成梯度下降。
- 谱系四问——更快（DreamGaussian）、更真（VSD）、更一致（MVDream）、更前馈（LRM）——勾勒出 3D 生成两年的演进全貌。
- 两大顽疾——**多脸（Janus）**与**过饱和**——分别是「多视角不一致」与「分布估计偏差」的极端形态，是评测指标的设计靶点。
- 高引导权重（~100）等工程取舍解释了 SDS 类方法的「卡通化」倾向；生成质量至今缺乏公认单一指标，评测仍是最前沿的问题。
- 宏观配方：**「大规模生成先验 + 可微画布」**——2D、3D、视频生成共享同一副骨架，先验维度升级、画布维度拉长。

在下一节，我们将把「生成」从静态 3D 推向**动态世界**：如果 2D 扩散可以蒸馏出 3D，那么**视频扩散能不能蒸馏出「世界的演化规律」**？这就是第六篇的主题——**视频生成即世界模型**，以及围绕 Sora 的那场「物理一致性」争论。

记住第五篇留给你的一句话：**「先验的维度假了，画布的维度长了」**——下一篇的画布，将从三维空间再长出第四维：时间。
