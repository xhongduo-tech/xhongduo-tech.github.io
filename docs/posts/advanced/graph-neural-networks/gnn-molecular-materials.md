## 为什么从分子与材料开始

消息传递神经网络（MPNN）的出生证就写在一篇**量子化学**论文上——图神经网络与分子科学是天然的一对：**分子是图（原子是顶点、化学键是边），材料是图（原子是顶点、晶格键是边），蛋白质是图（残基是顶点、空间接触是边）。** 没有哪个领域比分子与材料更「天生是图」。

这一篇讲 GNN 在分子与材料里的三层应用：**分子性质预测**（这个分子毒性多大、HOMO-LUMO 能隙多少）、**3D 几何感知建模**（等变消息传递如何吃进空间坐标）、**材料晶体建模**（周期性结构怎么编码）。它会与第四级《AI for Science》专题部分重叠，但这里聚焦「图神经网络」的视角——消息、特征、等变性怎么设计。

分子图还有一个独特优势：小而规整（通常几十个原子），因此可以放心地堆深度、用层次池化、甚至做全局注意力——分子是「图算法」最舒适的实验田，这也是为什么许多 GNN 理论创新都先在分子上验证。

## 1 分子图建模：从 SMILES 到图

化学家惯用的分子表示是 **SMILES** 字符串——一种线性编码（`CC(=O)O` 表示乙酸）。但 SMILES 是「把图压成序列」，丢失了图结构，且同一分子有无数种合法 SMILES 写法（排列不变量问题在字符串形态下被隐式搅浑）。GNN 的立场很干脆：**直接用图**。

分子图的构造：

- **顶点 = 原子**，特征包括原子种类（C/N/O…）、价数、氢原子数、杂化类型、是否在环内等；
- **边 = 化学键**，特征包括键型（单键 / 双键 / 芳香键）、共轭性、环内与否；
- **图级标签** = 分子性质（活性、毒性、logP、能隙）。

与社交图不同，分子图**小而规整**（通常 <100 个原子），因此可以做很深的消息传递、层次池化、乃至全图注意力——分子是「图算法」最舒适的实验田。常见基准：QM9（约 13 万个小分子 + 12 种量子性质）、ZINC-15（用于分子生成的数据库）、MoleculeNet（多任务性质集合）。<span class="marginnote">QM9 里的「量子性质」来自密度泛函理论（DFT）计算——每个分子要花数小时到数天算出来。GNN 的终极愿景之一就是<strong>用毫秒级预测替代 DFT 级计算</strong>：先靠 GNN 粗筛海量分子，只对高分候选跑昂贵的 DFT 精算，筛选成本下降几个数量级。</span>

**辨析｜易错点：** 分子图的消息传递必须**尊重化学键语义**——单键、双键、芳香键的「消息强度」不同。直接用无权边的 GNN（把键都当 1）会丢失「键级」这一核心信息。经验是：**边特征至少编码键型**，并在消息函数里按键型分权重，效果立竿见影。

## 2 分子性质预测：MPNN 的原始动机

**分子性质预测**：输入分子图，输出一个（或几个）标量性质——这是 MPNN 论文的原始任务，也是图回归的经典形态。MPNN 的框架（消息 + 更新 + 读出）我们已经熟悉，它的分子版配方是：

1. 消息：每条边产出一条消息，融合「两端原子特征 + 键特征」；
2. 更新：用门控（GRU）或 MLP 更新原子特征；
3. 读出：对全图原子特征做 sum / mean / attention 池化，得分子向量；
4. 回归：分子向量过 MLP 预测性质。

在 QM9 上，纯拓扑（2D 图）的 GNN 能预测电子性质到不错的精度，但**要追平 DFT 级精度，必须吃进 3D 空间信息**——这就是下一节的等变模型。纯 2D 图建模的软肋在于：**化学键的立体构型、原子的空间排布，决定了许多性质（如光学活性），而 2D 图根本看不到空间**。<span class="marginnote">一个著名例子：<strong>手性（chirality）</strong>——两个分子原子连接完全相同（2D 图一模一样），但空间上互为镜像（对映体），生理活性可能天差地别（反应停事件）。2D GNN 无法区分对映体，必须注入 3D 构象或专门的「手性特征」。这既是 GNN 的软肋，也是「3D 等变 GNN」兴起的直接动机。</span>

**辨析｜易错点：** 「性质预测」的标签来源决定任务类型：DFT 计算的标签（QM9）是**准确定量**但昂贵，实验测量的标签（毒性、活性）是**真实但嘈杂且稀疏**。GNN 在这两类上表现不同——对 DFT 标签几乎可以追平理论极限，对实验标签受噪声与数据量限制，别期望过高。

## 3 3D 几何与等变：把坐标吃进消息

分子的完整描述是原子的 3D 坐标——空间距离决定相互作用。**3D 等变 GNN** 把坐标作为额外输入，并保证模型输出**随空间旋转/平移正确变换**（物理规律与坐标取向无关）。两类代表性设计：

- **不变模型（SchNet / PaiNN）**：特征只依赖**距离**（对旋转不变）。消息里用「原子间距离」的径向基展开做权重，让「近的原子消息强、远的弱」。优点是简单、稳定；缺点是距离之外的角度信息被丢弃。
- **等变模型（EGNN / NequIP / MACE）**：特征里带上**向量分量**，消息传递时让向量与坐标一起旋转。能表达角度、键角、二面角等高阶几何信息，精度更高，但实现复杂、训练更脆。<span class="marginnote">SchNet 的距离编码是个精巧设计：把连续距离 $r$ 用一组高斯径向基展开成向量 $[\exp(-(r-\mu_k)^2/\sigma^2)]$，再让消息权重依赖这个向量——等价于给模型一把「距离尺子」。后续的 PaiNN 在此基础上加向量特征，成为「不变 + 等变」混合的实用代表。</span>

**辨析｜易错点：** 3D 模型有个「构象问题」：分子在现实中不是刚性结构，而是有多个构象（原子热运动、柔性键旋转）。**给一个分子，该用哪个构象的坐标喂给模型？** 常见做法是从生成构象集合中随机取一个（数据增强），或用「构象集成」求平均预测。忽略构象多样性，是 3D 分子建模最容易翻车的地方。

## 4 材料建模：晶体的图

材料（晶体）与分子的区别在**周期性**：晶体是「一个晶胞在三维空间无限重复」。因此晶体图要额外编码周期边界——顶点是晶胞内的原子，边是「原子间的实际空间距离（含跨晶胞镜像的最近距离）」。**CGCNN（Crystal Graph CNN，2018）**是这套范式的开山之作：

- 顶点特征：原子种类 + 电负性、价电子数等物理性质（查表）；
- 边特征：成键距离、连接强度、**周期镜像距离**；
- 消息：边特征进「距离依赖」的权重，聚合原子邻居；
- 读出：晶胞级池化 → 预测带隙、形成能、热力学稳定性等。

材料 GNN 的实战价值在高通量筛选：从数百万种候选成分中筛出「高稳定性、合适带隙」的电池 / 光伏材料，把「试错实验」变成「先算后测」。它把第一性原理计算的筛选成本降了几个量级。<span class="marginnote">材料 GNN 与分子 GNN 最大的工程差异在<strong>数据分布</strong>：分子数据是「每个分子独立」，材料数据是「一个成分空间里的组合」——材料预测的泛化常考察「没见过的元素组合」。CGCNN 类模型在元素外推上仍偏弱，这是材料 GNN 的开放前沿。</span>

**辨析｜易错点：** 晶体图的「边」不能只画晶胞内部的键——**周期边界外的镜像原子也必须连边**，否则边界原子的邻居信息丢失，预测偏置。工程上常用「截断半径」：距离小于阈值的原子（含镜像）都连边，阈值选对比选模型更重要。

### 分子指纹 vs GNN：从手工特征到学习特征

在 GNN 之前，化学信息学用「分子指纹（molecular fingerprint）」做性质预测——它值得了解，因为 GNN 的价值正体现在「取代」它。

**分子指纹**的做法：把分子编码成固定长度的 0/1 位向量。最常用的是 **Morgan（ECFP）指纹**：从每个原子出发，取其「半径 $r$ 内子结构」的哈希值，置 1 到指纹向量的相应位上。本质是「枚举局部子结构 + 哈希」。优点是快、可解释（每位对应一个子结构）；缺点是：

- **固定位长**（如 1024 位），分子越大信息越挤；
- **哈希冲突**：不同子结构可能撞到同一位；
- **不可学习**：子结构集合是预设的，无法按任务调整。

GNN 与指纹的关系是「继承 + 升级」：

| 维度 | Morgan 指纹 | GNN |
| --- | --- | --- |
| 局部结构 | 半径 $r$ 的子结构枚举 | $r$ 层消息传递感受野 |
| 表示 | 稀疏 0/1 位向量 | 稠密可学习向量 |
| 子结构 | 预设哈希 | 学出来的「隐式子结构」 |
| 可学习性 | 否 | 端到端 |

关键洞察：**GNN 的消息传递在数学上可以近似 Morgan 指纹的「迭代哈希」**——每层聚合邻居等价于一次「更光滑的哈希」。区别在于 GNN 的「哈希函数」是可微、可学的，因此能按任务挑出「有用子结构」。这也解释了为什么 GNN 几乎总在分子任务上胜过指纹——但指纹仍有价值：它可作为 GNN 的**额外特征**拼接进去（「特征增强」），两者互补而不是互斥。

## 5 公式解析：SchNet 的距离依赖消息

3D 分子 GNN 的「距离如何进消息」值得拆开——这是把连续几何翻译成图消息的关键：

$$
\boldsymbol{h}_u^{(l+1)} = \boldsymbol{h}_u^{(l)} + \sum_{v \in \mathcal{N}(u)} \mathrm{MLP}\big( e\big( \| \boldsymbol{x}_u - \boldsymbol{x}_v \| \big) \big) \odot \boldsymbol{h}_v^{(l)}
$$

- **第一步，看距离**：$\| \boldsymbol{x}_u - \boldsymbol{x}_v \|$ 是两个原子的空间距离，是**旋转不变**的量——整张图转多少度，距离不变，模型输出也不该变。
- **第二步，看距离编码**：$e(\cdot)$ 把距离展开成径向基向量（一组高斯），把「连续距离」变成「模型可用的离散特征」。不同距离档位的原子，被映射到不同的特征子空间。
- **第三步，看消息权重**：$\mathrm{MLP}(e(\cdot))$ 把距离编码映射成**逐维权重**（与 $\boldsymbol{h}_v$ 逐元素相乘 $\odot$）——「近原子在哪些维度上信息更强」由网络自己学。这让模型能在「距离感知」与「类型感知」之间自由分配注意力。
- **第四步，看残差更新**：新表示 = 旧表示 + 邻居加权消息（残差式）。残差让深层传播不过平滑，这也是分子 GNN 能堆很深的技术保障——与第四级《大模型原理》里 Transformer 的残差结构同理。

## 6 小结

- 分子与材料是「天生是图」的领域：**原子是顶点、键/空间接触是边**；分子图小而规整，是图算法的舒适区。
- **分子性质预测**是 MPNN 的原始任务：消息 + 更新 + 读出 + 回归，基准有 QM9 / ZINC / MoleculeNet。
- **手性与 3D 构象**是 2D 图的软肋，催生了 3D 等变模型：不变模型看距离，等变模型带向量，各有取舍。
- **材料建模**（CGCNN）要编码**周期边界**，高通量筛选是核心应用；元素外推是开放前沿。
- 3D 模型的「构象选择」与材料模型的「截断半径」是比选模型更关键的工程细节。
- 分子图小而规整，是图算法的舒适区；QM9 / ZINC / MoleculeNet 是三个标准测试场。
- 2D 图看不到手性与构象，3D 等变模型（SchNet / EGNN）为此而生；构象选择是工程关键。
- 材料建模要编码周期边界（镜像邻居 + 截断半径），元素外推仍是开放前沿。

在下一篇，我们把图神经网络从化学实验室带到物理世界：**用 GNN 模拟物理系统**——从粒子动力学到流体、再到学习物理规律的通用神经算子。

化学与物理在图建模上共享同一套工具，只是「相互作用」的语义不同：分子里是化学键与距离，物理里是力与场。带着「分子学的图招式，到物理里哪些要改」这个问题转场，下一篇会给出答案。
