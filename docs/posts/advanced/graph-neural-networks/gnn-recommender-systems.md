## 为什么从推荐系统开始

如果说图神经网络有一个「工业最大落地场景」，那一定不是学术基准，而是**推荐系统**。淘宝、抖音、Netflix 的「猜你喜欢」，每天要对数十亿「用户—物品」对打分——而用户与物品之间的交互，天然就是一张**二分图**。把「推荐」翻译成图论语言只有一句话：**预测图里还没画出来的那条边。** 协同过滤（collaborative filtering）从诞生那天起就在隐性建模这张图，GNN 只是把「隐性」变成「显性」。

这一篇从「推荐 = 图上链路预测」的视角重讲一遍推荐系统：先看矩阵分解如何逼近邻接矩阵，再看 NGCF 如何把协同信号变成消息传递，最后落到 **LightGCN**——一个把 GNN 推回「极简」的经典工作，以及工业落地必须面对的规模化问题。它与第三级《推荐系统》专题互补：那里讲推荐的整体架构，这里聚焦「图」这一个维度。

推荐系统为什么值得在 GNN 专题里单开一篇？因为它暴露了 GNN 从论文到工业的全部磨砺：几十亿条边的规模、动态演化的图、极度稀疏的交互、以及「未曝光 ≠ 不喜欢」的偏见——每一项都是图建模假设在真实场景里的试金石。读懂推荐里的 GNN，等于读懂了「图深度学习工程化」最完整的一课。

本篇的路线是：先立「推荐 = 二分图链路预测」的视角，再依次看矩阵分解、NGCF、LightGCN 三代递进，最后谈工业落地的三关。

先立一条基线：矩阵分解是「不传播」的 GNN 特例（0 层传播），NGCF / LightGCN 是「1 层以上传播」——这条连续谱能帮你定位任何推荐模型。

## 1 推荐就是一张二分图上的链路预测

**用户—物品交互图**：顶点分两类（用户 $U$、物品 $I$），一条边「用户 $u$ 买了 / 点了 / 看了物品 $i$」连接 $u$ 与 $i$。这正是一张**带权二分图**（第三级《图神经网络》第二篇讲过二分图），权重可以是评分、点击次数、时长。

推荐任务「预测用户 $u$ 会不会喜欢物品 $i$」翻译成图任务：**估计边 $(u, i)$ 存在的概率 / 强度**。这不是冷冰冰的数学翻译——它立刻带来了新视角：**用户 $u$ 与物品 $j$ 之间虽然没有直接边，但可能有一条「$u$—$i$—$v$—$j$」的二跳路径（$u$ 买了 $i$，$v$ 也买了 $i$，$v$ 买了 $j$），这条路径正是「$u$ 和 $j$ 可能相关」的证据**。协同过滤的「物以类聚」直觉，在图上就是「路径连通」的结构信号。<span class="marginnote">传统协同过滤（第三级《推荐系统》里的近邻方法）靠「共现物品 / 共现用户」显式寻找这些路径；矩阵分解则把这些路径「压缩」进低维向量。GNN 的贡献是<strong>在结构上显式地、多层地传播这些路径信号</strong>——这是前两者都做不到的。</span>

**辨析｜易错点：** 推荐系统的二分图是**稀疏且有向语义**的——用户看到物品才有点击，没看到的不代表不喜欢（曝光偏差）。把它当普通无向图做链路预测，会把「未曝光」误当成「负样本」。工业上对负样本的采样（随机负采样 vs 曝光负采样）几乎与模型同等重要——这是图上链路预测与真实推荐之间最容易被忽略的距离。

## 2 从矩阵分解到 NGCF：协同信号的显式传播

**矩阵分解（MF）**把用户、物品各学一个向量，预测分数是内积 $\hat{y}_{ui} = \boldsymbol{p}_u^\top \boldsymbol{q}_i$。它的局限是：**$u$ 的表示只由「$u$ 直接交互过的物品」决定**——二跳、三跳的协同信号没有被显式利用。

**NGCF（Neural Graph Collaborative Filtering，2019）**把 GNN 接进来：在交互图上做多层消息传递，让用户表示沿着边传播，吸收「他买过的物品的表示」，而物品表示又吸收「买它的人」…… 一层层传播，$u$ 的最终表示里就有了「买了相似物品的其他用户喜欢的物品」的信号——**协同过滤的深层路径被显式地建模**。公式上是标准的消息传递：第 $k$ 层

$$
\boldsymbol{e}_u^{(k+1)} = \sigma\Big( W \boldsymbol{e}_u^{(k)} + \sum_{i \in \mathcal{N}(u)} \frac{1}{\sqrt{|\mathcal{N}(u)||\mathcal{N}(i)|}} \big( \boldsymbol{e}_i^{(k)} + \boldsymbol{e}_i^{(k)} \odot \boldsymbol{e}_u^{(k)} \big) \Big)
$$

其中 $\odot$ 是逐元素乘（特征交互），归一化系数抑制「大 V 用户 / 爆款物品」的过度影响。NGCF 的实验确实超过了 MF——因为它把「高阶协同信号」用上了。

**辨析｜易错点：** NGCF 的「特征交互项」$\boldsymbol{e}_i \odot \boldsymbol{e}_u$ 在后续研究里被证明**没有带来增益**——LightGCN 把它删掉后效果不降反升。这提醒我们：**GNN 里的非线性与特征交互不是越多越好**，在推荐这类「交互是线性打分」的任务上，简洁的传播往往更优。

## 3 LightGCN：把 GNN 推到极简

**LightGCN（2020）**的核心发现是「少即是多」：NGCF 里让 GNN 发挥作用的，几乎完全在于**邻域聚合与线性传播**，而非非线性变换与特征交互。于是 LightGCN 删掉非线性、删掉特征交互、删掉特征变换矩阵，只保留最纯粹的传播：

$$
\boldsymbol{e}_u^{(k+1)} = \sum_{i \in \mathcal{N}(u)} \frac{1}{\sqrt{|\mathcal{N}(u)|\,|\mathcal{N}(i)|}} \, \boldsymbol{e}_i^{(k)}, \qquad
\boldsymbol{e}_u = \sum_{k=0}^{K} \alpha_k \boldsymbol{e}_u^{(k)}
$$

- 第 $k$ 层：用户表示 = 其邻居物品表示（第 $k-1$ 层）的对称归一化求和；
- 最终表示：把**每一层**的表示按权重 $\alpha_k$ 加权求和——这等价于「在不同传播深度上的软选择」，浅层表示局部偏好、深层表示全局协同，全部保留。

LightGCN 在多个基准上**全面超过 NGCF**，同时参数量更少、训练更快——「少即是多」的实验证据。它的传播事实上收敛于「图上标签传播 / 随机游走」类的平滑，这解释了为什么它对过平滑也有一定的天然抵抗力（用加权和而非只用最后一层）。<span class="marginnote">LightGCN 的 $\alpha_k$ 通常取均匀权重 $1/(K+1)$ 或可学习；论文发现可学习权重只带来微小增益。把「多层加权和」与第四级《大模型原理》里的「残差连接」对照着看：都是「把浅层信息显式保留到深层」，图与文本的架构智慧在此汇合。</span>

**辨析｜易错点：** LightGCN 极简不等于「闭眼用」。它把「非线性与特征变换」的容量全删了，因此**严重依赖初始化嵌入的质量与传播层数 $K$ 的调参**；且它对「用户特征 / 物品特征」（侧信息）是盲的——若任务有丰富的属性特征，LightGCN 的极简反而是短板，此时该用带特征的混合模型。

## 4 工业落地：规模化、冷启动与侧信息

从论文到「线上跑起来」，推荐 GNN 要过三道关：

**规模化**：数十亿用户 × 数十亿物品，二分图上百亿条边，整图训练不可能。工业标准做法是**子图采样**（GraphSAGE 式邻居采样）+ 异步训练；更激进的把图分割到多机（Cluster-GCN 式）。推理时对每个在线请求只展开目标用户的局部子图。
**冷启动**：新用户 / 新物品没有边，GNN 聚合不出信号。三条路：用**属性特征**兜底（侧信息进消息）、用**内容特征**对齐到老物品、或回退到「基于物品内容相似」的基线。
**侧信息注入**：把「用户画像、物品属性、乃至知识图谱」接进图——商品图 + 知识图谱构成异质图，让「看过 iPhone 的人」的信号沿「品牌—类型」边传播到新机型。<span class="marginnote">把<strong>知识图谱</strong>接进推荐是近年的大方向：用户—物品图与实体—关系图共享「物品顶点」，信号跨图流动。这解决了「物品太稀疏」的冷启动困境——物品没有交互，但有丰富的语义关系（属于什么类、什么品牌）。RippleNet、KGCN 等模型都是这条线的代表。</span>

**辨析｜易错点：** 线上推荐不是「离线指标好就行」。GNN 引入的邻居采样让**训练与推理的分布不一致**（采样导致），且图结构会随新交互**动态变化**——昨天的图今天可能就不同。工业上「模型定期重训 + 图定期重建 + 在线增量」三件套是标配，任何一环缺失都会让离线 AUC 变成在线体验的谎言。

### 一个二分图传播的完整例子：谁影响了谁

用一张微型「用户—物品」二分图把 LightGCN 的传播走一遍，协同信号就显形了。设 3 个用户（$u_1,u_2,u_3$）、3 个物品（$i_1,i_2,i_3$），交互边为：$u_1\!-\!i_1$、$u_1\!-\!i_2$、$u_2\!-\!i_1$、$u_3\!-\!i_2$、$u_3\!-\!i_3$。

- **第 0 层**：$u_1$ 的表示只由它自己（可学习嵌入）决定，与 $i_3$ 毫无关联。
- **第 1 层**：$u_1$ 聚合它交互过的 $\{i_1, i_2\}$ 的表示；$u_2$ 聚合 $\{i_1\}$。此时 $u_1$ 与 $u_2$ 因为都碰过 $i_1$，表示开始靠近——「买了同一物品的两个用户相似」。
- **第 2 层**：$i_1$ 聚合「买过它的人」$\{u_1, u_2\}$，于是 $i_1$ 的表示混合了 $u_1$、$u_2$ 的信息；$u_1$ 再聚合 $\{i_1, i_2\}$ 时，$i_1$ 已携带 $u_2$ 的信息——**$u_2$ 的偏好经由 $i_1$ 传到了 $u_1$**。
- **最终预测**：$u_1$ 与 $i_3$ 的分数 = 两表示内积。经过两层传播，$u_1$ 的表示里已隐含「喜欢 $i_2$ 的人（$u_3$）也喜欢 $i_3$」这条二跳信号，所以 $u_1$—$i_3$ 的分数会高于「完全没路径」的用户物品对。

这就是协同过滤的「物以类聚」在 GNN 里的显式形态：**每一层传播 = 沿交互图扩散一层「谁可能喜欢什么」**。层数越多，能捕捉的「相似链条」越长；但太长也会引入噪声（八竿子打不着的用户也搅进来），这正是 LightGCN 用「各层加权和」折中、而非一味加深的原因。

## 5 公式解析：LightGCN 的最终预测

把 LightGCN 从头到尾写成一个可执行的式子，理解就闭环了。设传播 $K$ 层，最终用户与物品表示为各层加权和：

$$
\hat{y}_{ui} = \Big( \sum_{k=0}^{K} \alpha_k \boldsymbol{e}_u^{(k)} \Big)^\top \Big( \sum_{k=0}^{K} \alpha_k \boldsymbol{e}_i^{(k)} \Big), \qquad
\boldsymbol{e}_u^{(k+1)} = \tilde{A}_{ui} \boldsymbol{e}_i^{(k)}
$$

- **第一步，看第 0 层**：$\boldsymbol{e}_u^{(0)}, \boldsymbol{e}_i^{(0)}$ 是**可学习的嵌入**（每用户、每物品一个向量），是传播的种子。
- **第二步，看传播**：第 $k+1$ 层表示 = 邻居第 $k$ 层表示的对称归一化加权和。传播 $K$ 层后，$\boldsymbol{e}_u^{(K)}$ 里包含了「$K$ 跳内所有协同路径」聚合出的信号。
- **第三步，看加权和**：最终表示不取最后一层，而是各层 $\alpha_k$ 加权——**浅层（局部偏好）+ 深层（全局协同）并蓄**。这是对过平滑的直接对抗：不会因为层数多就把局部信号洗掉。
- **第四步，看打分**：用户最终表示与物品最终表示做内积，即「推荐分数」。内积大 = 两个向量方向一致 = 用户的偏好与物品的画像在传播后对齐——整条链路（嵌入 → 传播 → 加权 → 内积）端到端可微，用 BPR（Bayesian Personalized Ranking）损失训练：让「正样本对分数 > 随机负样本对分数」。

## 6 小结

- **推荐 = 二分图上的链路预测**：用户与物品的交互是边，预测「未画出的边」就是推荐。
- **NGCF** 把协同信号显式传播进消息传递；但它的非线性与特征交互项被后续证明无益。
- **LightGCN** 删掉非线性与特征变换，只留对称归一化传播 + 各层加权和，效果反超——「少即是多」。
- 工业三关：**规模化**（子图采样）、**冷启动**（侧信息 / 知识图谱兜底）、**动态图**（重训 + 重建 + 增量）。
- 推荐 GNN 的设计启示：交互是线性打分任务时，简单传播常优于复杂非线性。
- 推荐 = 二分图链路预测：协同过滤的「物以类聚」在图上就是「路径连通」。
- NGCF 的教训：非线性与特征交互在推荐这类线性打分任务上无益，LightGCN 删掉它们反超。
- LightGCN 的传播 = 对称归一化 + 各层加权和：浅层局部偏好、深层全局协同，兼得不过平滑。
- 工业三关：**规模化**（子图采样）、**冷启动**（侧信息 / KG 兜底）、**动态图**（重训 + 重建 + 增量）。
- **曝光偏差**是二分图建模的隐藏陷阱：未曝光 ≠ 不喜欢，负样本采样几乎与模型同等重要。
- BPR 损失让「正样本对分数 > 随机负样本对分数」，是推荐 GNN 的标准训练目标。

在下一篇，我们把图神经网络带回到它最「物理」的舞台——**分子与材料**：用 GNN 预测分子性质、加速材料筛选，让 AI 走进化学实验室。

转场之前，把推荐场景给 GNN 留下的两条教训带上：其一，**任务的性质决定模型复杂度**——推荐是「线性打分」任务，所以 LightGCN 的极简能赢过 NGCF 的堆砌；其二，**数据的偏见比模型更决定成败**——曝光偏差、冷启动、动态演化，每一项都是「图上链路预测」的假设在真实推荐里的变形。

这两条教训在分子与材料里同样成立：分子性质预测是「回归」任务，等变比堆层更重要；材料数据是「组合空间」，泛化到新元素组合比拟合已知数据更难。
