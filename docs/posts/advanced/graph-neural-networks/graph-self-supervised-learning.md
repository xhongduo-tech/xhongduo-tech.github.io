## 为什么从图自监督学习开始

DeepWalk 那一篇我们已经见过图表示学习最朴素的「无监督」：用随机游走当语料，不需要任何标签。但它在 GraphSAGE 之后似乎被 GNN 的「监督学习」盖过风头——直到 2020 年前后，**自监督学习（self-supervised learning, SSL）**在 CV / NLP 大放异彩（对比学习、掩码重建），图领域也迎来一轮复兴。原因很简单：**图的标签比图像、文本更稀缺**——一张分子图有性质标签，但几千张才有一批；一个社交网络有用户画像，但覆盖不全。让模型先只靠结构「预习」，再拿少量标签「精修」，成了刚需。

这一篇回答三个问题：图上的自监督信号从哪里来（哪些「功课」可以无中生有）；对比学习这套范式在图里怎么落地；以及「自监督预训练」在什么条件下真的有用、什么条件下是花架子。它直接衔接下一篇《图预训练与微调》。

图自监督的价值还有一个更现实的注脚：绝大多数真实图任务没有「干净的大规模标签」。化学家标注一批分子性质要数月实验，产品团队打标签要人工审核——但图结构本身（谁连谁、谁与谁共现）是免费的。自监督学习的全部意义，就是把这份免费的结构信号变成可用表示。这也解释了为什么 2020 年后几乎所有 GNN 前沿工作都在自监督上发力。

下面按「信号设计 → 对比学习 → 非对比式 → 评价」的顺序展开：先看清有哪些「无中生有」的目标，再深入对比学习这套主流范式，最后比较它与生成式路线的取舍。

先说明评价口径：自监督是否有效，最终要看「下游任务」而非自监督损失本身——损失降了不代表表示变好，这是对比学习最常见的误判。所以本篇所有结论都以「下游提升」为最终裁判。

一句话记住本篇：**结构是免费的标签——先看有没有同分布的大图，再谈自监督**。

## 1 图自监督的「功课」：四类预训练任务

自监督的核心是**设计「无中生有的目标」**：不用标签，只从数据本身造监督信号。图上有四类经典「功课」：

- **结构预测**：把边 / 顶点 / 结构属性当预测目标——如「预测被遮住的子图是否存在」「预测两个顶点间是否有边」。链路预测本身就是最古老的结构自监督。
- **属性重建**：把顶点特征（属性）遮住一部分，让模型根据邻居结构与剩余属性**重建**被遮属性。类似 BERT 的掩码语言模型，只是把「词」换成「顶点特征」。
- **子图 / 上下文预测**：让顶点表示去预测「它所在子图的全局信息」，强制模型把局部表示与全局结构挂钩。
- **对比学习**：让「同一顶点的两个不同视角」表示靠近，让「不同顶点的视角」表示远离——这是 2020 年后的绝对主流，下面重点展开。<span class="marginnote">把「自监督」与「无监督」分开看：无监督泛指不要标签；自监督更具体，指「从数据自身构造有监督信号」。DeepWalk 的游走共现、链路预测、掩码重建、对比学习，都是图自监督的具体实例——只是早期没有这个统一名词。</span>

**辨析｜易错点：** 「自监督预训练」与「下游微调」是两个阶段、两种目标。预训练阶段只优化自监督损失（模型学「图的一般规律」），微调阶段才引入少量标签（模型学「这个任务的特定偏好」）。**混淆两者，是图自监督工程里最常见的错误**——预训练损失没跑完就开始微调，等于没预习就考试。

## 2 图对比学习：让同一个图的不同视角靠近

对比学习的核心直觉：**「同物异视」应当同表示**。一张图（或一个顶点、一条边）通过**数据增强**产生两个不同的「视角」（view），它们是同一个对象的两个分身，表示应当靠近；而不同对象的视角，表示应当远离。

图上的「数据增强」与图像截然不同——图像是旋转、裁剪、加噪，图是**结构变换**。常用的四种：

**顶点丢弃（node dropping）**：随机删掉一部分顶点（及其边）；
**边扰动（edge perturbation）**：随机增删一部分边；
**子图采样（subgraph sampling）**：以随机顶点为中心采样连通子图；
**特征掩码（feature masking）**：随机遮住一部分特征维度。

GraphCL（2020）系统验证了这些增强的组合：**分子图上「顶点丢弃 + 边扰动」组合最强，社交图上「子图采样」最强**——不同领域的「好的增强」不同，这是图对比学习最需要调的地方。<span class="marginnote">图像领域的「裁剪 / 旋转」有一致的语义（都是视角变化），图的增强语义要自己定义——删顶点是「换个角度观察」，加噪声边是「鲁棒性考察」。GRACE 等后续工作在此基础上引入「正负样本」的精细设计（顶点级对比而非图级对比）。</span>

**辨析｜易错点：** 增强不能太强也不能太弱。太弱：两个视角几乎相同，模型学不到东西（「太容易的题」）；太强：两个视角已经看不出是同一个对象，模型被逼着把不同东西当同类（「错题」）。**「增强强度」是图对比学习最敏感的超参**，需要小范围网格搜索。

## 3 对比损失：InfoNCE 在图上

图对比学习的标准损失是 **InfoNCE**——本质是「在 $N$ 个候选中找出真正的正样本」的多分类：

$$
\mathcal{L} = -\log \frac{\exp\big(\mathrm{sim}(\boldsymbol{z}_i, \boldsymbol{z}_i') / \tau\big)}{\exp\big(\mathrm{sim}(\boldsymbol{z}_i, \boldsymbol{z}_i') / \tau\big) + \sum_{j \neq i} \exp\big(\mathrm{sim}(\boldsymbol{z}_i, \boldsymbol{z}_j) / \tau\big)}
$$

- $\boldsymbol{z}_i$ 与 $\boldsymbol{z}_i'$ 是**同一个样本的两个视角**的表示（图级对比：同一张图的两个增强；顶点级对比：同一顶点的两个增强）；
- $\mathrm{sim}$ 是余弦相似度，$\tau$ 是温度系数；
- 分母里的 $\boldsymbol{z}_j$（$j \neq i$）是**批次内其他样本**的视角——它们充当**负样本**。

一次对比 = 一个问题：「在这一批 $2N$ 个视角里，哪个才是我自己的另一半？」模型被迫学会「抓住对象的身份特征」，而不是「记住像素/结构的表面」。温度 $\tau$ 控制对难负样本的惩罚强度：$\tau$ 小，模型越「严苛」，越要把负样本推开。<span class="marginnote">InfoNCE 是互信息下界（NCE 家族）在对比学习里的标准形式。图里「负样本从哪来」有讲究：同图的其他顶点、其他图、其他视角的错配……不同选择塑造不同语义。GCA（2021）进一步按「结构重要性」加权增强，让重要的边/顶点扰动更可能被保留。</span>

**辨析｜易错点：** 负样本是「批次内其他样本的视角」，因此**批次大小直接影响对比质量**——批次太小，负样本不足，表示容易退化（所有样本塌缩成一个点）。这是图对比学习「吃显存」的根源；缓解办法是「负样本池」或「动量编码器」（如 MoCo 的移动平均分支），把旧批次的表示缓存起来当负样本。

## 4 非对比式自监督：掩码重建与特征预测

对比学习不是唯一的路线。**生成式 / 预测式自监督**在图上同样活跃，而且更贴近 BERT 的直觉：

- **属性掩码重建（attribute masking / GraphMAE）**：随机遮住一部分顶点特征，让模型用「被遮顶点的邻居信息」把它重建出来。GraphMAE（2022）证明：**只要重建目标用「掩码特征」而非「结构」，图自监督就能追上甚至超过对比方法**——它避开了对比学习的「负样本设计与增强调参」两大麻烦。
- **结构掩码重建**：遮住一部分边，预测「这条边在不在」。它退化回链路预测，但作为自监督目标依然有效。
- **上下文预测（context prediction / DGI 系列）**：让顶点表示去判别「当前子图是正样本的局部还是另一个子图的局部」，把「全局—局部互信息」最大化。

**辨析｜易错点：** 对比式与生成式在「评价标准」上有微妙差别：对比学习学的表示**天然利于判别任务**（分类），生成式学的表示**更通用但分类精度可能略低**。经验是：**下游是分类 / 链路预测 → 对比式常常更直接；下游是生成 / 重建 → 生成式更对口**。别指望一个自监督目标通吃所有下游。

### 一个增强组合的实战对照：分子图该选哪种增强

用 GraphCL 论文的经典实验回答「增强怎么选」。设预训练任务是「分子性质预测」，对比学习的增强候选有：顶点丢弃、边扰动、子图采样、特征掩码。

- **顶点丢弃（删原子）**：删掉一个原子连同它的键——在分子图上相当于「摘掉一个官能团」。GraphCL 发现这个增强**很强**：分子性质本来就不依赖某个特定原子，删几个还能看「骨架」。
- **边扰动（增删键）**：随意删键会破坏化学价的合法性，但**增键**（加一条不存在的键）在分子图上破坏化学意义。GraphCL 把「边扰动」与「顶点丢弃」组合时效果最好——删原子后剩余的图仍合法，加扰动则给模型「鲁棒性训练」。
- **子图采样**：随机采连通子图——对分子这种小图，子图太小会丢失全局结构，效果反而不稳定。
- **特征掩码**：遮特征维度（如遮住原子类型），能迫使模型「从结构推断类型」，但分子任务里结构本身信息有限，增益不大。

结论（GraphCL 实测）：**分子图上「顶点丢弃 + 边扰动」组合最优**；而同样的组合搬到社交图（Reddit）上却一般——社交图更适合「子图采样」。这再次说明：**增强的语义是领域绑定的，换领域必须重新验证**。工程上把这个「验证增强」的步骤做成一个小消融，比直接信论文结论更稳。

## 5 公式解析：对比学习的目标是「互相信息最大」

把 InfoNCE 与「互信息」的联系说透，公式就活了。InfoNCE 在负样本数 $N \to \infty$ 时逼近真实互信息下界：

$$
\mathcal{L}_{\mathrm{InfoNCE}} \approx -\mathrm{I}(\boldsymbol{z}_i;\, \boldsymbol{z}_i') + \log N
$$

- **第一步，看符号**：$\mathrm{I}(\boldsymbol{z}_i; \boldsymbol{z}_i')$ 是两个视角表示之间的**互信息**——「知道一个视角，对另一个视角的把握提升多少」。互信息大 = 两个视角共享了更多身份信息。
- **第二步，看目标**：最小化 InfoNCE ≈ **最大化互信息**。于是「同物异视靠近」被翻译成「让两个视角的信息互相可预测」——比「向量距离近」更本质，因为它要求的是「信息」，而不是「坐标」。
- **第三步，看 $\log N$ 项**：负样本越多，这个「修正项」越大，损失的「信息量」越高——批次越大，学到的互信息估计越紧。这是「负样本越多越好」的数学出处。
- **第四步，回看图任务**：在图上，$\boldsymbol{z}_i, \boldsymbol{z}_i'$ 是「同一张图的两个增强」，最大化它们的互信息 = 让表示对「增强造成的扰动」不变，只保留「对象的本质」。**增强决定「什么算扰动」，互信息决定「什么算本质」**——所以增强设计是图对比学习的灵魂。

## 6 小结

- **图自监督**：不需要标签，从图本身构造监督信号；四类功课是**结构预测、属性重建、上下文预测、对比学习**。
- **图对比学习**让「同物异视」靠近、「异物异视」远离；图上增强是**结构变换**（顶点丢弃 / 边扰动 / 子图采样 / 特征掩码），不同领域增益不同。
- **InfoNCE 损失** ≈ 最大化视角间互信息；批次大小、温度 $\tau$、负样本设计是三大敏感旋钮。
- **生成式路线**（属性掩码重建 GraphMAE、DGI 上下文预测）避开对比的增强调参，判别任务上常与对比式互有胜负。
- 预训练与微调是两阶段、两目标，混淆是头号工程错误。
- 图自监督的四类功课：**结构预测、属性重建、上下文预测、对比学习**——共同点是「从图自身造监督信号」。
- 图增强是结构变换（顶点丢弃 / 边扰动 / 子图采样 / 特征掩码），不同领域增益不同，必须按领域验证。
- InfoNCE ≈ 最大化视角互信息：批次越大负样本越足，温度 $\tau$ 越严苛。
- 对比式利于判别任务、生成式（掩码重建）更通用；没有通吃一切下游的自监督目标。

在下一篇，我们把「自监督预训练」推向完整流水线：**先在无标签大图上预训练，再在标签稀缺的下游任务上微调**——图预训练与微调的全部实践与陷阱。

进入前记住本篇的关键姿态：自监督不是「免费午餐」，而是「把结构当标签」的重新定价——它的每个设计决策（增强怎么选、对比还是重建、批次多大）都对应一份「先验」的取舍。当你在下游发现自监督没起作用，别急着换模型，先回查三件事：**增强是否与领域语义匹配、对比批次是否足够、预训练与下游是否同分布**。这三问几乎覆盖了图自监督失败的绝大部分原因。带着这份排查清单，下一篇的「预训练 + 微调」流水线就不会走偏。
