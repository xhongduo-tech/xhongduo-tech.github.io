# 图预训练与微调

## 为什么从图预训练开始

上一篇文章讲了「自监督」：不用标签，从图自己身上学。这篇把它推向完整工程：**先在无标签的大规模图上预训练，再在标签稀缺的下游任务上微调**。这个「预训练 + 微调」配方在 NLP（BERT、GPT）与 CV（ImageNet 预训练）里已经是标准动作，图领域能不能照搬？答案既是「能」也是「不能」——能，因为同样的迁移逻辑成立；不能，因为**图的预训练有一个 NLP 没有的根本障碍**：图的「语义分布」差异极大，分子图与社交图的「一般规律」几乎不重叠。

这一篇从「图的迁移为什么难」讲起，给出三类预训练策略（顶点级 / 图级 / 对比式），再讨论「什么时候预训练真有用、什么时候是负迁移」，最后落到一套可执行的工程配方。

预训练 + 微调在 NLP 里近乎万能，很多人默认图也如此——但图有一条 NLP 没有的硬约束：没有「通用语言」这回事。分子图的规律、社交图的规律、程序图的规律互不相通，跨域预训练不仅白费力气，还会把错误先验带进微调。所以图预训练的第一课不是「怎么训」，而是「该不该训、在哪训」。

本篇依次回答三个问题：图迁移难在哪、三类预训练目标怎么选、以及什么时候预训练真正有用。

先记住一条判断标准：预训练有没有用，靠「与随机初始化基线的增量」说话，不靠感觉。

## 1 图的迁移困境：不像 NLP 那么幸运

NLP 的预训练能成立，靠一个隐含假设：**不同任务共享同一套语言底层规律**——语法、语义、常识都是通用的，BERT 在维基百科上预习的「语言知识」，微调时能迁移到分类、问答、生成。图的麻烦在于：**「图的规律」是高度领域绑定的**。

- 分子图的「邻居语义」是化学键与原子类型，规律是「哪个官能团决定什么性质」；
- 社交图的「邻居语义」是关注与互动，规律是「什么样的社交结构预示什么行为」；
- 程序控制流图的「邻居语义」是跳转与分支，规律是「什么样的结构是 bug 模式」。

这三类图的**顶点特征、边类型、结构先验完全不同**。在分子图上预训练的表示，拿去初始化社交图分类器，非但没有帮助，还可能**负迁移**——预训练强化的「化学结构」先验，成了社交任务的噪声。Hu 等人在 2020 年那篇论文里明确展示：**图预训练的有效性高度依赖「预训练数据与下游数据来自同一分布」**，跨领域的预训练甚至掉点。<span class="marginnote">NLP 里「语言通用性」有个直觉理由：所有人类语言的底层统计规律共享（Zipf 定律、句法层级）；而「图的规律」没有这种跨领域共性。这是图预训练与文本预训练的本质分水岭，也是图大模型（如 LLM 辅助图推理）必须跨过的一道坎。</span>

**辨析｜易错点：** 「预训练」不等于「用自监督目标随便跑一遍」。预训练的价值 = 预训练任务与下游任务的**共享信息**。如果预训练目标学到的是一堆下游用不上的细节（比如分子里的手性细节），微调时还要费力「忘掉」它。**选择预训练数据与目标，必须问一句：下游真正需要什么？**

## 2 三类预训练目标：顶点级、图级、对比式

Hu 等给出的框架把图预训练目标分成三层，各有适配的下游：

**顶点级预训练**：掩码掉一部分顶点属性，让 GNN 根据邻居重建（类似 BERT 的掩码词）。它强化的是「**局部的属性—结构关联**」，对「顶点分类、顶点属性预测」类下游最友好。

**图级预训练**：让模型预测「被遮子图的结构属性」（如「这个子图包含多少个环」），或做「整图—子图」的关系判断。它强化的是「**全局结构的语义**」，对「图分类、图性质预测」类下游最友好。

**对比式预训练**：上一篇的对比学习直接用于预训练——同一张图的两个增强靠近、不同图远离。它强化的是「**图的判别性表示**」，对「图检索、相似度判断」类下游最友好。

实际结论很有信息量：**「顶点级 + 图级」的组合预训练，在分子图（同一个分布域）上的增益最大**——因为分子性质预测同时需要局部官能团识别与全局结构理解，两类目标互补。但一旦跨域（分子 → 社交），所有预训练都失效，甚至拖累。<span class="marginnote">文献里有一条被反复验证的经验：<strong>预训练的作用是「给微调一个好起点」而不是「替代微调」</strong>。在标签量极小（每类几十条）时增益最明显；标签充足时，预训练常常只是「锦上添花」，甚至可有可无——预训练的价值随标签量递减。</span>

## 3 什么时候预训练真有用

把文献与工程经验汇总，图预训练的「收益曲线」有清晰的形状：

| 条件 | 预训练收益 |
| --- | --- |
| 下游标签极少（每类 <50 条） | 收益最大，常提升 3–10 个百分点 |
| 下游标签充足（数千条以上） | 收益趋近于零，甚至负迁移 |
| 预训练数据与下游同分布（同为分子 / 同为社交） | 收益显著 |
| 跨领域预训练（分子 → 社交） | 通常负迁移 |
| 下游是小图（几十顶点） | 收益明显（预训练补足结构先验） |
| 下游是大图 + 强特征 | 收益有限（特征已够强） |

一句话概括：**预训练是「标签稀缺 + 同分布」条件下的雪中送炭，不是所有场景的锦上添花。** 工程上最稳妥的做法不是盲猜，而是**做一个消融实验**：同一套微调代码，跑「随机初始化」与「预训练初始化」两遍，看增量——增量大于阈值（如 2%）才值得引入预训练这一层复杂度。

**辨析｜易错点：** 微调时该**微调全部参数**还是**冻结部分层**？图任务的经验与 NLP 一致但不完全一致：**全量微调**在数据充足时更好；**冻结预训练层 + 只训下游头**（线性探测）在数据极缺时更稳（防过拟合）。夹在中间的做法是「低学习率微调全部层」。注意：图模型的「层」对应「传播深度」，冻结传播层 = 固定聚合方式，只学分类头。

## 4 工程配方：一条可复用的流水线

把前几篇的零件全部组装成一条图预训练流水线：

1. **选数据**：预训练数据必须与下游**同领域**（同为分子 → 用 ZINC-15 等大分子库；同为社交 → 用大规模社交图）。没有同领域大图？**放弃预训练，直接用带强先验的架构**（如 GIN + 特征增强）往往更划算。
2. **选目标**：下游是顶点任务 → 顶点级（属性掩码重建）；下游是图任务 → 图级（子图结构预测）+ 顶点级组合；下游是检索 → 对比式。
3. **预训练**：大学习率、长训练、无标签全量数据，把 GNN 编码器练到「自监督损失收敛」。
4. **微调**：替换输出头（分类头 / 回归头），用少量标签微调。标签极稀缺 → 低学习率 + 早停；数据充足 → 正常微调。
5. **验证**：跑「随机初始化」基线对比增量；增量小就退回不用预训练。<span class="marginnote">「预训练 + 微调」的替代方案值得一提：<strong>自监督增强（self-supervised finetuning）</strong>——不用预训练，而是把自监督目标直接加进微调损失里做多任务正则（如 <code>交叉熵 + λ·InfoNCE</code>）。它在「没有合适的大图」时是预训练的廉价平替，效果往往出人意料地接近。</span>

### 一个分子预训练的成功案例：从「迁移掉点」到「提升 5 个点」

用 Hu 等人论文里的实验设计把「什么时候预训练有用」具体化。设下游任务是「分子毒性分类」，只有 500 个带标签分子（每类几十个）。

- **对照组**：直接用 500 个带标签分子训练一个 3 层 GNN，验证集 F1 记为基线。
- **实验组 A（同分布预训练）**：先用 ZINC-15（约 25 万分子，无标签）做「顶点级属性掩码 + 图级子结构预测」的预训练，再用 500 个标签微调。结果显示 F1 提升约 3–5 个百分点——**预训练补足了「小样本下学不到的化学结构先验」**。
- **实验组 B（跨域预训练）**：用「蛋白质图」预训练同样模型，再微调到分子毒性任务。结果非但没有提升，F1 反而下降约 1–2 点——**蛋白质的结构规律与分子的化学规律不兼容，预训练引入的是噪声先验**。

这个「同域 +5、跨域 −2」的对比，把上一节的「收益曲线」从理论变成了实测。它直接推导出工程动作：**先确认「有没有同领域的大图」，再决定要不要走预训练**；没有合适的预训练数据时，老老实实训练 + 强特征，比强行预训练更可靠。

**辨析｜易错点：** 「同域」不是「同一数据集」。ZINC 的分子与下游毒性分子属于同一「化学域」，但具体分子不同——预训练学的是「化学的一般规律」，微调把它适配到「毒性这个子任务」。若把预训练数据换成「与下游完全不同的化学空间」（如只有无机小分子），增益同样会缩水。

## 5 公式解析：预训练 → 微调的目标切换

预训练与微调是两个不同的优化目标，把它们并排写清，就明白了「迁移」到底迁移了什么。设 GNN 编码器参数为 $\theta$，输出头参数为 $\phi$：

$$
\text{预训练}:\quad \min_{\theta}\; \mathcal{L}_{\mathrm{self}}(\theta;\, G_{\text{pretrain}}), \qquad
\text{微调}:\quad \min_{\theta, \phi}\; \mathcal{L}_{\mathrm{task}}(\theta, \phi;\, G_{\text{task}})
$$

- **第一步，看预训练目标**：$\mathcal{L}_{\mathrm{self}}$ 只优化编码器 $\theta$，在**无标签大图** $G_{\text{pretrain}}$ 上做自监督任务（掩码重建 / 对比）。它学的是「图的通用结构表示」——**与任何具体任务无关**。
- **第二步，看微调目标**：$\mathcal{L}_{\mathrm{task}}$ 同时优化 $\theta$ 与输出头 $\phi$，在**带标签小图** $G_{\text{task}}$ 上做监督任务（分类 / 回归）。$\theta$ 从预训练点出发，带着「图的一般先验」继续被任务梯度调整。
- **第三步，看「迁移」的本质**：预训练让 $\theta$ 落在一个「对图结构信息敏感」的参数区域；微调在这个区域附近继续走，比从随机起点走更靠近「任务最优」。**迁移的不是标签，而是「先验的参数位置」**。
- **第四步，看失败模式**：若预训练域与任务域不同，$\theta$ 落点的「先验」是错的，微调被迫走出很远才能纠正——**负迁移**。这解释了为什么「同分布」是图预训练成立的第一前提。

## 6 小结

- 图预训练的成立条件与 NLP 不同：**图的规律高度领域绑定**，跨域预训练常负迁移。
- 三类预训练目标：**顶点级**（属性重建，利好顶点任务）、**图级**（子图结构预测，利好图任务）、**对比式**（判别表示，利好检索）；组合使用增益更大。
- 收益曲线：**标签极稀缺 + 同分布时增益最大**，标签充足或跨域时趋零 / 为负。
- 工程配方五步：选同领域大图 → 按下游选目标 → 预训练 → 低学习率微调 → 跑基线验证增量。
- 没有合适大图时，**自监督增强**（自监督目标混入微调损失）是廉价平替。
- 图预训练与 NLP 不同：图的规律高度领域绑定，跨域预训练常负迁移——「同分布」是第一前提。
- 三种目标（顶点级 / 图级 / 对比式）对应三类下游，组合使用（顶点级 + 图级）在分子域增益最大。
- 收益曲线：**标签极稀缺 + 同分布时增益最大**，标签充足或跨域时趋零 / 为负。
- 微调策略按标签量选：极缺时低学习率 + 冻结部分层，充足时全量微调。

在下一篇，我们从「读图」转向「写图」：模型不再从图里学表示，而是**生成新的图**。图生成与编辑（graph generation）是 GNN 最富挑战性的下游之一，也是生成式模型（见第四级《生成模型》）在离散结构上的延伸。

收束本篇前再补一层联系：预训练给了 GNN「读图」的先验，生成则要求 GNN「写图」的能力——读与写共享同一套「结构与语义的编码」，因此图生成模型的编码器往往直接复用图预训练的参数。这也解释了你将在下一篇看到的许多设计：GraphRNN 的边级解码器、扩散模型的去噪网络，本质上都在回答「给定部分图，猜剩余结构」——这与自监督里的「掩码重建」是同一个问题的不同脸。所以，带着「自监督 = 预测缺失」的直觉去读图生成，会有事半功倍之效。
