## 为什么从密集预测与跟踪继续

第六篇跟住一个物体，本篇把难度推满：**同时跟住画面里的所有物体，并为每一帧产出密集的预测**。这汇聚成两个紧邻的任务族——**视频密集预测**（每一帧逐像素/逐框打标签）与**多目标跟踪**（对每个目标维持一条跨帧的轨迹）。<span class="marginnote">这是视频理解里最「落地」的一篇：自动驾驶要同时检测车道、车辆、行人并预测轨迹，体育分析要跟踪每个球员——都是「密集预测 + 多目标跟踪」的合体。</span>

从本专题主线的角度看，跟踪是把第一篇的「递推状态」用到极致：每个目标都是一条**在线维护的时间序列**，模型要不断回答「它还是它吗、它现在在哪儿」。

## 1 密集预测：逐像素、逐帧、逐目标

**视频密集预测（video dense prediction）**：对视频的每一帧，为每个空间位置产出预测。按输出粒度的不同，分为几层：

**视频语义分割**：每帧每像素给一个语义类别（道路、车、人）——第六篇 VOS 的「全类别」版本；
- **视频目标检测**：每帧给每个物体的包围框 + 类别；
- **视频全景分割**：语义分割与实例分割的并集——「每个像素既要类别、也要实例编号」。

密集预测的难点回到那个熟悉的词：**时间一致性**。逐帧独立预测会闪烁、会漏检。解法与第六篇一脉相承：把时间信息接进来——或用光流/变形让相邻帧的预测对齐，或用注意力让当前帧「参考」历史帧的预测。<span class="marginnote">这里的核心 trick 是「把预测结果也当成序列建模的输入」：检测器每帧输出的一组框，本身就是一条时序数据——对它建模，就是跟踪。</span>

时间一致性在密集预测里的落地，比在分割里更强调「预测即序列」：检测器每帧输出的一组框，本身就是一条时序数据。于是可以给这些框序列配一个轻量的时间模块——光流引导的跨帧框融合、或一个简化的跟踪头——让「相邻帧的预测互相印证」。这一步把密集预测与跟踪真正缝在了一起，也正是本篇从「检测」走向「跟踪」的自然衔接。

把几种任务的粒度收进一张表：

| 任务 | 输出粒度 | 与图像侧对应 |
| --- | --- | --- |
| 视频语义分割 | 每帧每像素一个类别 | 语义分割 |
| 视频目标检测 | 每帧每物体一个框 + 类别 | 目标检测 |
| 视频全景分割 | 每像素类别 + 实例编号 | 全景分割 |
| 多目标跟踪 | 每个目标一条跨帧轨迹 | 无（时间专属） |

## 2 多目标跟踪：检测 + 关联

**多目标跟踪（multi-object tracking, MOT）**：持续维持画面里每个目标的身份与位置，输出一组**轨迹（trajectory）**——每条轨迹是「这个目标在各帧的检测框」连成的线。

工业界最稳的范式叫 **tracking-by-detection（先检测、后关联）**，两阶段：

1. **检测**：用单帧检测器（如 YOLO、Faster R-CNN）对每帧找出所有候选框；
2. **关联（data association）**：把相邻帧的检测框两两配对，配成同一目标的连续轨迹——这步本质是个**二分图匹配**：每条边连接「上一帧某框 ↔ 当前帧某框」，边权重是两者的相似度（IoU 重叠、外观特征余弦距离、运动模型预测的接近程度），用匈牙利算法求最大权重匹配。匹配上的并轨，匹配不上的开新轨迹或终止旧轨迹。<span class="marginnote">匈牙利算法（Kuhn–Munkres）是组合优化里的经典二分图匹配算法，在第三级《算法》与《优化》中都会正式登场。这里的用法是它的典型工程场景：每次「上一帧 vs 当前帧」就是一次小规模匹配问题。</span>

关联之外，每个轨迹通常配一个**运动模型**（如卡尔曼滤波器）在线预测目标的下一位置——预测缩小了匹配搜索范围，也扛住了短暂遮挡。

运动模型里最常见的卡尔曼滤波值得展开一句：它对每个目标维护「位置 + 速度」的状态与协方差，先按匀速/匀加速模型外推下一帧的预测框，再用检测框做观测更新。正是这个「预测缩小匹配范围」的能力，让跟踪系统在目标短暂被遮挡时仍然不会丢轨迹——预测框继续前进，等目标重新出现时检测框与预测框重新对齐。第五篇讲过的「先验 + 观测」骨架，在这里以最经典的工程形态落地。

关联阶段计算「两个框是不是同一个目标」的相似度，工程上常组合多个信号：空间上算检测框的 **IoU**（重叠越大越可能是同一个目标）；外观上用重识别（re-ID）网络提取框内特征、算余弦距离；运动上用卡尔曼预测框与检测框的接近程度。三路信号各说各话时，用加权和或学习出的融合权重裁定。**没有哪一种信号永远正确——遮挡后重识别特征会失效，快速运动时 IoU 会失灵，多信号冗余正是跟踪稳健的关键。**

**辨析｜易错点：** 检测器的失误会被关联放大。漏检 → 轨迹断裂；误检 → 产生幽灵轨迹。所以跟踪系统的成败往往不取决于关联算法，而取决于检测质量——这也是「检测强、跟踪自然强」这一经验的结构性原因。

## 3 公式解析：MOTA 指标

多目标跟踪的评测指标里，最经典的是 **MOTA（Multiple Object Tracking Accuracy）**：

$$
\text{MOTA} = 1 - \frac{\text{FN} + \text{FP} + \text{IDS}}{\text{GT}}
$$

- **第一步，看分母**：GT 是整段视频里所有目标出现的总次数（一个目标在 10 帧里出现，计 10 次）。分母把分数折算成「每个目标每次出现」的尺度。
- **第二步，看分子**：三个错误项——**FN**（missed，真目标没被检测到）、**FP**（false positive，把不是目标的东西当成目标）、**IDS**（identity switch，同一目标中途被错误换了身份编号）。
- **第三步，看直觉**：分子是「所有错误的总次数」，1 减去它除以 GT，得到「平均每个目标每次出现犯几个错」的反面。<span class="marginnote">三个错误项各有滋味：FN 与 FP 反映检测质量，IDS 单独反映关联质量——两个轨迹互相交换身份（人 A 跟成了人 B），检测没有错，但跟踪错了。所以 MOTA 高 ≠ 身份稳定，近年更流行加看 IDF1、HOTA 等以身份为核心的指标。</span>

给 MOTA 一个具体数字：设一段视频里 GT=1000 次目标出现，系统产生 FN=50、FP=30、IDS=20，则 MOTA $= 1 - (50+30+20)/1000 = 0.90$。若把 IDS 压到 5，MOTA 升到 0.915。这个算例说明：**IDS 在高分区间尤其值钱**——当 FN/FP 已很小，剩下的竞争就集中在身份稳定性上，这正是近年指标（IDF1、HOTA）把身份权重加大的原因。

MOTA 的本质是把跟踪问题**折算成分类问题的误差统计**——这让你能一眼看出：系统差在哪，是没找到目标（FN），还是乱认目标（FP），还是把目标搞混（IDS）。

## 4 单目标跟踪与长程跟踪

多目标跟踪之外，还有一支更贴近第一性的任务：**单目标跟踪（single object tracking, SOT）**——给定第一帧某个目标的框，之后每一帧都报告它的新位置，且**不允许有检测器帮忙**。SOT 不依赖检测，因此更考验「跟住」本身。

代表性算法走了一条从相关滤波到注意力的路线：

- **相关滤波（MOSSE、KCF，2010–2015）**：把目标外观编码成滤波器，在下一帧上做相关响应，峰值即目标新位置——快得能跑上百帧每秒，是那个时代的实时标杆；
- **Siamese 跟踪（SiamFC 2016 起）**：用一个孪生网络把「目标模板」与「搜索区域」映射到共享空间，响应图峰值定位目标——把模板匹配做成了可学习的；
- **Transformer 跟踪（TransT、MixFormer，2021 起）**：模板与搜索区域做交叉注意力，让模板特征动态地与搜索帧交互——第五篇的注意力又在这里落地。

**辨析｜易错点：** MOT 与 SOT 的评测不能混用。MOT 的困难在「身份关联」（谁是新的、谁是谁），SOT 的困难在「外观变化」（目标变形、遮挡、出画）。一个 SOT 算法可以完全不会关联，一个 MOT 系统也可能在长程跟丢——**先看清任务定义，再谈算法好坏。**

## 5 轨迹是时间建模的自然产物

把跟踪放回时序建模的框架（第一篇），一切豁然开朗：

检测是**空间**问题：每帧独立回答「哪有什么」；
- 关联是**时间**问题：回答「这个框和那个框是不是同一个物体」，用的正是时序信息（运动一致性、外观时序匹配）；
- 轨迹是**递推状态**：每帧更新一次「目标在哪」的隐状态，正是第一篇「递推状态」策略在目标粒度上的实例化。

所以跟踪不是孤立的任务，而是「时间一致性」这条主线在密集预测上的必然结果。<span class="marginnote">这条思路在近年被「端到端跟踪」推向极致：训练一个模型同时输出检测与轨迹（如 Trackformer、ByteTrack 也仍走检测+关联），把「关联」也变成可学习的注意力——第五篇的注意力又一次在时间维度上完成了「卷积时代的后处理」的自动化。</span>而轨迹本身又成为更高层任务的原料：预测轨迹 → 行为预测（自动驾驶），聚合轨迹 → 理解群体行为（体育分析）。

从评测回到原理，还有一个值得内化的观点：**跟踪是一个「在线」问题，而识别是「离线」问题**。识别可以看完整段视频再下结论；跟踪必须逐帧实时输出，且错误会累积——这一步跟丢，下一步就再也找不回来。所以跟踪系统的设计哲学天然倾向「小步快跑」：宁可每一步保守，也不冒进丢身份。这与第六篇「传播 + 修正」的稳健哲学同源。

本篇记号速查：

| 记号 | 含义 |
| --- | --- |
| GT | 全部目标出现总次数（分母） |
| FN / FP | 漏检 / 误检 |
| IDS | 身份切换次数 |
| MOTA | $1 - (\text{FN}+\text{FP}+\text{IDS})/\text{GT}$ |
| trajectory | 一个目标跨帧的检测框连成的轨迹 |
| MOT / SOT | 多目标跟踪 / 单目标跟踪 |

## 6 小结

- **视频密集预测**：逐帧、逐像素/逐框的标签预测，核心仍是**时间一致性**。
- **多目标跟踪**：维持每个目标的跨帧身份与位置，输出轨迹。
- **tracking-by-detection**：检测 + 二分图匹配关联 + 运动模型在线预测，是工业界标准范式。
- **MOTA** $= 1 - (\text{FN}+\text{FP}+\text{IDS})/\text{GT}$ 把跟踪误差折算成三个可定位的错误项；FN/FP 测检测，IDS 测关联。
- **辨析**：检测质量决定跟踪上限；MOTA 高 ≠ 身份稳定，需配 IDF1/HOTA 一起看。
- 跟踪是**递推状态**策略在目标粒度的实例化，轨迹是更高层任务（预测、行为理解）的原料。
- **SOT**：单目标跟踪不靠检测器，从相关滤波到 Siamese 到 Transformer，核心在「跟住」外观变化。

在下一节，视频开始开口说话：当我们把视频与自然语言放在同一个模型里对齐时，就进入了 **视频-语言多模态理解**。
