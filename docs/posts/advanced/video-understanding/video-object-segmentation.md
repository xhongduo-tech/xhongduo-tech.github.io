## 为什么从视频分割继续

前几篇回答的是「视频在干什么」（分类），本篇转向「视频里有什么、在哪儿」——逐像素、逐帧地回答。**视频目标分割（video object segmentation, VOS）**：给视频每一帧的每个目标物体标出像素级掩码。<span class="marginnote">类比图像侧：图像分割在第三级《深度学习》里是「语义分割 / 实例分割」的任务；视频分割等于把同样的问题搬到时间轴上，并额外要求「跨帧一致」。</span>

单帧分割的成熟方法（FCN、U-Net、Mask R-CNN）逐帧套用看似可行，但立刻暴露一个致命问题：**帧与帧之间会闪烁**——同一物体这帧被分割、下帧被漏掉，掩码边缘抖动。人类看视频从不会这样闪烁，因为我们是把「一个持续存在的物体」钉在时间上跟踪。视频分割的核心科学问题，正是**如何把时间一致性做进分割**。

## 1 从单帧分割到视频分割

图像分割已经能把「一只猫」从背景里分出来。视频分割多了一个维度，也迎来新的信号：

**新信号**：时间。猫在动，背景基本不动——**运动本身就是极好的分割线索**。第三篇的光流在此派上大用场：同一物体的像素共享相近的运动，物体边界往往就是运动边界。
- **新约束**：一致性。物体在时间上连续存在，所以掩码应当平滑演化，而不是逐帧独立抖动。
- **新难点**：遮挡与形变。物体被遮挡后重现、身体姿态剧烈变化，都要靠时间信息来兜底。

**辨析｜易错点：** 「逐帧分割 + 后处理平滑」不是视频分割。逐帧独立预测再取中值滤波，只能抹掉随机噪声，抹不掉「物体被遮挡后重新出现」这类需要**记忆**的语义问题——真正的 VOS 必须让时间信息参与预测本身，而不只是事后滤波。

## 2 三种任务形态

VOS 按监督强度分三种，别混淆：

- **半监督 / 单镜头 VOS（semi-supervised / one-shot）**：只给第一帧的目标掩码，模型要把它传播到整段视频。这是 VOS 研究的核心设定，也是 DAVIS 等基准的默认评测协议。<span class="marginnote">单镜头设定的优雅之处在于「可测且可练」：只给第一帧，剩下的全靠模型「跟住」物体——它同时测了分割精度与跟踪能力，是两者交叉处的纯净舞台。</span>
- **无监督 VOS**：不给任何掩码，模型要自动找出「主要物体」（通常是运动最显著的那个）并分割全片。
- **视频实例分割 / 全监督**：给定逐帧标注，训练模型同时做「是什么（类别）+ 在哪（掩码）+ 是哪个（实例编号跨帧一致）」。

三种形态难度递增，但共享同一套核心机制——**掩码在时间上的传递**。

## 3 掩码传播：半监督 VOS 的主流范式

半监督 VOS 的通用框架是「传播 + 修正」的闭环：

1. **传播**：用前一帧的掩码 $M_{t-1}$ 结合帧间运动，估计当前帧的候选掩码 $\tilde{M}_t$；
2. **修正**：结合当前帧图像内容 $I_t$，对候选掩码做精修，得到 $\hat{M}_t$。

传播的两种实现风格：

- **基于光流**：用光流把 $M_{t-1}$ 变形（warp）到当前帧。快、无参数，但光流误差会累积漂移。
- **基于匹配 / 记忆**：把之前所有帧的特征与掩码存进「时空记忆库」，当前帧从记忆里检索最相似的位置来生成掩码（如 STM，Space-Time Memory Networks）。慢一些，但能「回头看」，对遮挡重现特别稳健——本质上是用第五篇的注意力机制在「当前帧与历史帧」之间建立联系。

现代方法普遍是两者结合：光流做局部粗糙传播，匹配做全局修正。

## 4 公式解析：光流变形掩码

以「光流传播」这一路为例，看掩码如何在帧间移动：

$$
\tilde{M}_t = W\big(M_{t-1},\ F_{t-1 \to t}\big)
$$

三步拆解：

- **第一步，看输入**：$M_{t-1} \in \{0,1\}^{H \times W}$ 是 $t-1$ 帧的掩码（1 = 属于目标）；$F_{t-1 \to t}$ 是第三篇讲的稠密光流——每个像素有一个位移向量 $(u,v)$。
- **第二步，看变形（warp）**：对 $M_{t-1}$ 里每个标记为目标的像素 $(x,y)$，按光流移动它：新位置 $(x+u, y+v)$ 也标记为目标。整张掩码由此「跟随物体」来到 $t$ 帧。实现上用双线性采样：$W(M, F)(x,y) = M(x - u(x,y),\ y - v(x,y))$，反向查表保证每个输出位置都有值。
- **第三步，看局限**：变形只移动掩码，不新增信息——如果 $t$ 帧出现新的物体区域、或被遮挡物体重现，光流给不出答案，掩码就错。所以传播之后必须接**修正**：$\hat{M}_t = \text{Refine}(\tilde{M}_t, I_t)$，让网络用当前帧图像补全边界、恢复漏掉的部分。<span class="marginnote">这个「传播 + 修正」的闭环，跟视频跟踪里的「预测 + 更新」、卡尔曼滤波里的「先验 + 观测」是同一个骨架：先靠运动模型外推，再用当前观测校正。跨任务看到同构，是建立系统理解的好方法。</span>

## 5 时空一致性：把分割看成能量最小化

传播解决「怎么跟」，另一个经典视角是「怎么判」：**把整段视频的分割看成一次联合优化，显式地惩罚时间上的不一致。**

设 $\ell_t(p)$ 是第 $t$ 帧像素 $p$ 的标签（目标/背景），定义总能量

$$E = \sum_t \sum_p D_t(\ell_t(p)) + \lambda \sum_t \sum_p \sum_{q \in \mathcal{N}(p)} V\big(\ell_t(p), \ell_t(q)\big) + \mu \sum_t \sum_p W\big(\ell_t(p), \ell_{t+1}(p')\big)$$

- 第一项 **一元项** $D_t$：单帧外观与分割结果的符合度（当前帧图像更像目标还是背景）；
- 第二项 **空间平滑项** $V$：相邻像素应同标签，抑制孤立噪点；
- 第三项 **时间平滑项** $W$：$t$ 帧像素 $p$ 与其在 $t+1$ 帧的运动对应点 $p'$ 应同标签——**帧间运动一致的像素不许突然换标签**。

用图割（graph cut）或变分法最小化 $E$，得到的就是「时间上连续、空间上干净」的分割。<span class="marginnote">这一项的数学身份值得记住：它就是把第三篇的光流（运动一致性）直接写成能量约束。你学过的每个部件，都能在另一个任务里以约束的形式再生。</span>

## 6 小结

- **视频目标分割**：给视频每帧每个物体标像素级掩码，核心难题是**跨帧一致性**（防闪烁、扛遮挡）。
- **三种形态**：半监督（第一帧传播）、无监督（自主找主物体）、全监督（实例级跨帧一致）。
- 半监督 VOS 主流框架是**「传播 + 修正」**：光流变形做局部传播，匹配/记忆（注意力式检索）做全局修正。
- **光流变形掩码** $\tilde{M}_t = W(M_{t-1}, F_{t-1\to t})$ 是纯运动外推，误差会累积，必须接修正。
- 时空一致性可以显式写成**能量最小化**：一元项 + 空间平滑 + 时间平滑，用图割求解。

在下一节，我们把「跟住一个物体」放大成「同时跟住一堆物体、并预测它们的未来」——这就是 **视频密集预测与跟踪**。
