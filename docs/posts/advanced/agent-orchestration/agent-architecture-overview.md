# 智能体架构概览

<div class="epigraph">
<p>智能体是任何能够通过传感器感知环境、并通过执行器作用于环境的事物。</p>
<footer>—— 斯图尔特 · 罗素 与 彼得 · 诺维格（Stuart Russell, Peter Norvig, <em>Artificial Intelligence: A Modern Approach</em>）</footer>
</div>

## 为什么从架构开始

前三个级别里，我们一路把大模型学到「会生成下一个 token」：预训练给知识，指令微调给对话，RLHF 给对齐。但站在 2026 年回看，这些能力都停留在**单次对话**——你问一句，模型答一句，然后各回各家。<span class="marginnote">第三级《自然语言处理》里学过的自回归生成：$P(x_t \mid x_{<t})$，只依赖历史 token，不依赖任何外部世界。智能体要打破的正是这个封闭假设。</span>真正值钱的应用——查资料写报告、订机票、改代码、操作电脑——都需要模型**走出去做事**，做完一步看一眼结果再决定下一步。这个「感知—决策—行动—再感知」的闭环，就是**智能体（agent）**。本专题要拆解的是它被编排起来的方式：架构、规划、工具、记忆、协作、评估、安全。一切从架构开始。

## 1 从「会聊天」到「会做事」

罗素与诺维格的经典定义把智能体刻画成**感知（perceive）与行动（act）**的循环：智能体从环境获得观测，据此决策，再以动作改变环境，然后等待新的观测。当这个循环的「大脑」换成一个 LLM 时，就得到**LLM 智能体（LLM-based agent）**。

把单次对话与智能体并排看，差别一目了然：

| 维度 | 单次对话 | LLM 智能体 |
| --- | --- | --- |
| 状态 | 仅对话历史 | 历史 + 环境观测 + 内部记忆 |
| 反馈 | 无（答完即止） | 每次动作都有观测回写 |
| 目标 | 回答当前问题 | 完成一个可验证的任务 |
| 能力边界 | 模型权重内 | 模型 + 工具 + 环境的合力 |

一句话总结：**对话是问答，智能体是干活**。干活意味着模型不再只靠「肚子里那点知识」，而是能把搜索、计算、执行代码、操作文件这些外部能力接进来。

## 2 四大核心模块

综合 Xi 等人 2024 年的智能体综述（§2），一个 LLM 智能体的架构可以拆成四个模块：

**画像（Profiling）模块**：给智能体设定角色、性格与目标。一行「你是一名资深 Python 工程师」不是装饰，而是给后续所有决策锚定行为偏好。<span class="marginnote">画像相当于给模型一个「职业身份」，它会影响规划粒度、工具选择与话术。换一个画像，同一个任务可能走出完全不同的轨迹。</span>

**记忆（Memory）模块**：承担状态的存取。短期看是上下文窗口里的对话与动作历史，长期看是写入外部存储（向量数据库、文本文件、数据库表）的过往经验。记忆让智能体不是「每次从零开始」。

**规划（Planning）模块**：把大目标拆成小步骤、排定顺序、在失败时反思重来。这是智能体「看起来聪明」的主要来源，本专题第 2 篇《规划与任务分解》专门展开。

**行动（Action）模块**：把决策翻译成对环境的具体作用——输出一段文字、调用一个 API、执行一段代码、点击一个按钮。本专题第 3、4 篇专门讲工具与行动。

四者的关系是一个有方向的流水线：画像定调 → 记忆供料 → 规划出策 → 行动落地 → 观测回到记忆，周而复始。下图是这条闭环的示意。

## 3 大脑、手脚与旧智能体的位置

传统 AI 里的智能体大致分两派：**符号智能体（symbolic agent）**用人工写的规则与规划器（如 STRIPS、PDDL）推导动作，精确但脆弱——换一个领域就得重写规则；**强化学习智能体（reinforcement learning agent）**用环境奖励驱动策略网络 $\pi(a \mid s)$ 逼近最优行为，能在游戏里打爆人类，但需要海量试错与环境奖励信号。<span class="marginnote">第四级《强化学习》专题会详述策略与奖励的关系；这里只需记住：RL 智能体的「学习」靠梯度更新，而 LLM 智能体的「学习」主要靠提示与记忆——两者哲学不同。</span>

LLM 智能体处在中间地带：它**不靠手工规则**（世界知识都在权重里），也**不靠环境奖励训练**（参数是冻结的）。它把「常识推理」这一环从规则和奖励中解放出来，变成一个可以随对话自然发生的推理过程。代价是：它可能一本正经地编造「查过」的结果、可能忘掉上一步、可能陷入死循环——这些正是本专题后续各篇要解决的工程问题。

## 4 公式解析：智能体–环境循环

把第一节的直觉写成一个方程，就是智能体的「运动方程」：

$$
o_t = \mathcal{E}(a_{t-1}), \qquad h_t = h_{t-1} \oplus (a_{t-1}, o_t), \qquad a_t \sim \pi_\theta(\cdot \mid h_t)
$$

三步拆解：

- **第一步，$o_t = \mathcal{E}(a_{t-1})$**：$a_{t-1}$ 是智能体在上一步采取的动作，$\mathcal{E}$ 是环境（环境函数），$o_t$ 是动作落地后环境返回的观测。观测不一定是文本，也可能是截图、网页 DOM、传感器读数。
- **第二步，$h_t = h_{t-1} \oplus (a_{t-1}, o_t)$**：$\oplus$ 表示把「动作 + 观测」这对新事件追加进历史 $h$。$h_t$ 就是智能体截至当前的完整轨迹，它相当于「记忆模块」的最小形态。
- **第三步，$a_t \sim \pi_\theta(\cdot \mid h_t)$**：策略 $\pi_\theta$（冻结的 LLM）以轨迹为条件，自回归地采样下一个动作。注意这里与单次对话的生成公式只差一个关键环节——$h_t$ 里混入了**环境产生的观测**，而不是只有模型自己写的话。

**这一条公式划清了对话与智能体的边界**：对话的 $h_t$ 只含模型输出，智能体的 $h_t$ 还含外部世界的反馈。外部信息一旦进入条件，模型就被「接地（grounding）」了，幻觉空间被压缩了一大半。

## 5 辨析：提示词、多轮对话与智能体

**辨析｜易错点：** 初学者最常见的误区是把三类东西混为一谈。

- **提示词工程**：给模型加一句「请一步一步思考」只是改变生成分布，没有闭环，不是智能体。
- **多轮对话**：有历史、有状态，但模型不执行任何外部动作，观测永远来自用户而非环境，也不是智能体。
- **真正的智能体**：必须同时具备「动作执行」与「观测回写」。哪怕最简单的一个「搜索后回答」工具循环，也已经是智能体。

另一个易错点是把**上下文窗口当成记忆的全部**。上下文是「工作记忆」，一旦超出窗口就被截断；而长期记忆（向量库、文件）是主动写入、可跨会话检索的。只靠上下文窗口的智能体，做长任务时会「过目即忘」。

## 6 解剖一条真实轨迹

把一个真实任务放进闭环里走一遍，看看四大模块如何协作。假设目标是回答一个需要检索的开放问题：

```
目标：2023 年诺贝尔物理学奖颁给了谁，因什么工作获奖？

Thought 1: 我还不清楚 2023 年的获奖信息，需要先检索。
Action 1: search[2023 诺贝尔物理学奖]
Observation 1: 搜索结果出现多位科学家：阿戈斯蒂尼、克劳泽、吕利耶，关键词「阿秒光脉冲」。
Thought 2: 获奖名单有了，但获奖理由还不具体，需要细读页面。
Action 2: lookup[阿秒脉冲]
Observation 2: 「他们用实验方法产生阿秒光脉冲，用于研究物质中的电子动力学。」
Answer: 2023 年诺贝尔物理学奖授予阿戈斯蒂尼、克劳泽与吕利耶，表彰他们产生阿秒光脉冲以研究电子动力学。
```

对照四大模块看这条轨迹：**画像**把目标钉成「回答开放问题」，全程没跑偏；**记忆**把两次观测的要点累积进上下文，最后一步用得上；**规划**表现为「先查名单、再查细节、最后作答」的渐进收敛；**行动**则用两次真实的检索动作支撑起全部推理——没有这两次动作，Thought 2 与 Answer 都是无源之水。

这也是第 4 节那条方程的可视化版本：每走一步，$h_t$ 就多一段「动作 + 观测」，模型的条件分布被真实信息一步步钉牢。一个对照组足以说明观测的分量：如果删掉 Observation 2，让模型直接作答，它极可能编造出「因黑洞研究获奖」之类的答案——**外部观测不是模型的装饰，而是它的氧气**。

把轨迹各环节与模块对照，也可以整理成一张映射表：

| 轨迹环节 | 对应模块 | 作用 |
| --- | --- | --- |
| 目标 | 画像 | 锚定行为偏好 |
| 观测累积 | 记忆 | 提供作答依据 |
| Thought 序列 | 规划 | 渐进收敛到答案 |
| Action 序列 | 行动 | 把推理落到真实检索 |

这条轨迹还演示了智能体的一个隐含性质：**每一步都有明确的「状态增量」**。单次对话的状态只在对话内部滚动，而这里的每步动作都对应环境里的一次真实变更。状态变更可被记录、可被审计，这为后面评估与安全两篇埋下了伏笔——可度量、可追踪，是「可治理」的前提。

**轨迹越真实，幻觉的容身之地越少**——这句话值得在这一篇结束时记下来，它是后面九篇的共同前提。

## 7 小结

- **智能体** = 感知—决策—行动—再感知的闭环；LLM 作为大脑，工具与环境作为手脚。
- 架构四大模块：**画像、记忆、规划、行动**，构成一条有方向的流水线。
- 与符号智能体、RL 智能体的根本区别：**参数冻结**，靠提示与记忆完成「学习」。
- 核心方程 $o_t = \mathcal{E}(a_{t-1}),\ h_t = h_{t-1} \oplus (a_{t-1},o_t),\ a_t \sim \pi_\theta(\cdot \mid h_t)$：外部观测进入条件是智能体的本质。
- **提示词、多轮对话都不是智能体**；上下文窗口也不是全部记忆。

在下一节，我们进入四模块中最关键也最「反直觉」的一环——**规划与任务分解**：模型是怎么把一个模糊的大目标，拆成一串可执行的小步骤的。
