## 为什么要有记忆

前四篇的智能体每一步都在「当下」运转：规划、调工具、看观测。但有一个残酷的事实——**这次任务失败的教训，下一次开局就全部清零**。普通 LLM 智能体做同一件事十次，会犯同一个错误十次，因为它没有「上辈子」。人类不会这样：我们失败后会记住「不能从那里过河」，下次绕路。<span class="marginnote">认知科学把记忆分成感觉记忆、工作记忆与长期记忆；智能体界的对应物是上下文窗口（工作记忆）与外部存储（长期记忆）。本专题第 1 篇已经埋下伏笔，这里正式展开。</span>Reflexion（Shinn 等人，NeurIPS 2023）把「记住教训」做成了智能体的显式机制，并给了一个响亮的名字——**语言智能体的言语强化学习（verbal reinforcement learning）**。

## 1 记忆的三层结构

先看清「记忆」这个词在智能体语境里指什么，三层递进：

**工作记忆（working memory）**：上下文窗口里的当前轨迹。容量小、易失，对应我们上一篇反复警告的「上下文膨胀」问题。
- **情景记忆（episodic memory）**：**已发生经历的记录**——做过什么、结果如何、失败在哪里。这是「经验」的最小单元，Reflexion 的核心。
- **语义记忆（semantic memory）**：从多次经历中**提炼出的通用规律**，如「用户的问题常常省略城市，需要先确认」「这类 bug 的常见原因是未判空」。语义记忆是情景记忆的压缩与归纳。

智能体系统里，工作记忆靠上下文实现，情景与语义记忆靠外部存储（文本文件、数据库、向量库）实现。<span class="marginnote">向量检索式记忆（RAG）适合「回忆事实」，而 Reflexion 想解决的是「记住怎么改」——它存的不是知识，是策略修正意见。两类记忆用途不同，不能互相替代。</span>三层结构对应着智能体越来越长的时间尺度：当下、这次、累积。

## 2 Reflexion 的四个组件

Reflexion 把一次「试错」组织成四个组件的循环：

- **Actor（行动者）**：一个 LLM，根据任务、当前轨迹与已有记忆，生成下一步动作（或整段代码）。
- **Evaluator（评估器）**：判断这次轨迹成没成功。可以是规则（编译通过、测试全绿、预定成功），也可以让 LLM 打分。
- **Self-Reflection（自我反思）**：在失败后，让 LLM 用语言总结「哪里错了、下次怎么改」。这一小段文字就是「言语强化信号」。
- **Episodic Memory（情景记忆）**：把反思写进外部存储，下一轮开始时与任务一起喂给 Actor。

```
第 t 次试错：Actor 依据记忆 M 行动 → Evaluator 判定失败
         → Self-Reflection 生成教训 r_t → 存入 M → 第 t+1 次带着 M 再来
```

**要点：模型权重自始至终不动**。没有梯度、没有微调，全部的「学习」都发生在记忆文本里。这就是「言语强化学习」的含义——强化信号不是标量奖励，而是自然语言写成的修正意见。因为不动权重，Reflexion 对任意一个现成 LLM 都是即插即用的。

## 3 公式解析：反思迭代循环

把 Reflexion 的循环写成递推式，看它每一步到底发生了什么：

$$
\tau_t \sim \pi_\theta\!\left(\cdot \mid \mathcal{M}_{t-1}\right), \qquad
s_t = \mathrm{Eval}(\tau_t), \qquad
r_t = \mathrm{Reflect}(\tau_t, s_t), \qquad
\mathcal{M}_t = \mathcal{M}_{t-1} \cup \{r_t\}
$$

四步拆解：

- **第一步，$\tau_t \sim \pi_\theta(\cdot \mid \mathcal{M}_{t-1})$**：Actor 在第 $t$ 次试错时的条件里，多了一段记忆 $\mathcal{M}_{t-1}$——此前所有试错的教训文本。参数 $\theta$ 冻结，变化的只有条件。
- **第二步，$s_t = \mathrm{Eval}(\tau_t)$**：评估器对轨迹打分：通过 / 不通过，或一个分数。评估信号决定要不要进入反思。
- **第三步，$r_t = \mathrm{Reflect}(\tau_t, s_t)$**：失败时，反思器把「轨迹 + 判定」压缩成一条可执行的教训，例如「搜索超时是因为我用了过大的时间范围，下次应缩小范围」。
- **第四步，$\mathcal{M}_t = \mathcal{M}_{t-1} \cup \{r_t\}$**：教训追加进情景记忆。于是下一轮的条件里，模型「记得」了上一轮的错——**这就是递推意义上的学习：$\theta$ 不变，但条件分布随 $t$ 移动**。

**为什么文本反思能替代梯度**：梯度更新改变权重从而改变条件分布；Reflexion 直接在「条件」那一端做手脚——把「应该怎么做」写进 prompt。它对不可微的、需要常识解释的失败（「这两步顺序错了」）格外有效，因为反思是模型自己用语言推理出来的。

## 4 效果与代价

论文在三个环境里验证了这套机制：HotPotQA 上反思带来的问答提升；HumanEval 上配合微调把 pass@1 从约 80% 提到约 91%；ALFWorld（家居任务）上成功率较无反思基线大幅提升。<span class="marginnote">这些任务有个共同点：失败原因可以归因（哪个条件不满足、哪行测试挂了），评估信号清晰——反思的威力恰恰依赖这一点。</span>代价也很直白：每轮都要额外跑一次反思生成，**token 开销随试错次数线性上涨**；如果评估信号模糊（比如「感觉不太好」），反思产出也含金量不足。而且反思不保证收敛——模型可能死记一条错误的教训，越反思越偏。

## 5 辨析：反思、微调与 RLHF

**辨析｜易错点：** 三个「学习」概念容易互相踩踏。

- **反思 vs 微调**：微调改权重，反思改上下文。微调是「换脑」，反思是「带小抄」。前者贵、一次性、全局生效；后者便宜、即时、可针对单任务定制。
- **反思 vs RL 的奖励函数**：RL 用标量奖励做梯度，反思用语言做条件。RL 需要环境给数值信号，反思只需要 LLM 把失败「说清楚」。二者可以配合：RL 管权重层面的技能，反思管记忆层面的策略。
- **反思 ≠ 保证改进**：反思只是「把教训写下来」，写下来不意味着下一次真的执行对——Actor 仍可能无视教训。实践中要**校验反思是否被遵守**，否则反思会退化成自我安慰的废话。

## 6 一次反思的完整剧本

用修 bug 的场景把四个组件的协作演一遍。任务：修复一个「输入为空时会崩溃」的函数。

**第 1 轮**：Actor 收到任务与一个失败的测试输出，给出补丁。Evaluator（这里是用例测试）判定——仍然失败，因为补丁没处理空输入。轨迹 $\tau_1$ 被判不合格。

**第 2 步，反思**：Self-Reflection 读取轨迹与判定，生成教训：

```
失败原因：函数在输入为 None 时调用 len() 直接报错；
下次应先判断输入是否为 None 或空，再进入主逻辑。
```

**第 3 步，存记忆**：教训 $r_1$ 写入情景记忆，$\mathcal{M}_1 = \{r_1\}$。

**第 4 步，第 2 轮**：Actor 的条件里多了一段 $\mathcal{M}_1$。它看到「上次是因为没判空」，补丁里加上判空分支——测试通过，轨迹 $\tau_2$ 合格。

对照第 3 节的递推式，整个剧本就是公式的一次实例化：$\tau_1$ 失败 → $s_1=$ 失败 → $r_1$ 写入 $\mathcal{M}$ → $\tau_2$ 在 $\mathcal{M}_1$ 条件下成功。

把四个组件在剧本里的分工列成表：

| 组件 | 本剧本中的角色 | 判定方式 |
| --- | --- | --- |
| Actor | 生成补丁 | 依赖任务 + 记忆 |
| Evaluator | 跑测试用例 | 规则式：通过 / 失败 |
| Self-Reflection | 写教训 | 依赖评估信号清晰度 |
| Episodic Memory | 存教训、供下轮 | 追加式文本存储 |

这个剧本最容易被忽略的一点：**第 1 轮失败的具体原因（len() 崩在哪）是测试输出直接给出的**——反思的质量依赖评估信号的清晰度。如果 Evaluator 只返回「不行」，反思器无从下手，$r_t$ 就会变成「我应该更小心」这种正确的废话。所以工程上常说：**评估器决定反思的上限**。

还有一个实用细节：反思也可以**带结构**。让反思器输出「错误类型 → 根因 → 修正建议」三段，比自由写作更容易被下一轮的 Actor 采纳，也更容易跨任务复用——这就是从情景记忆走向语义记忆的第一步。

还有一点需要提醒：**反思写入记忆后，不代表一定被遵守**。Actor 可能读了教训却仍犯同样的错（上下文里教训太多、彼此矛盾时尤其如此）。严谨的做法是对「第 2 轮的输出是否包含上一轮教训的关键词」做一次核对——如果没遵守，就再来一轮。这层「对反思的反思」虽然增加成本，却是保证言语强化学习真在起作用的关键。

## 7 小结

- 记忆三层：**工作记忆（上下文）、情景记忆（经历）、语义记忆（规律）**，时间尺度递增。
- Reflexion = **Actor + Evaluator + Self-Reflection + Episodic Memory** 四件套；权重冻结，学习全在记忆文本。
- 递推式：$\mathcal{M}_t = \mathcal{M}_{t-1} \cup \{\mathrm{Reflect}(\tau_t, \mathrm{Eval}(\tau_t))\}$，教训进入下一轮条件。
- **言语强化学习**：强化信号是自然语言而非标量奖励，可即插即用地挂在任何 LLM 上。
- 易错点：**反思 ≠ 微调 ≠ RL**；反思不保证收敛；token 成本随试错线性上涨。

在下一节，一个带记忆的智能体已经能独当一面了，但人类工程里还有一层更大的杠杆——**让多个各有所长的智能体协作**：一个管规划、一个管执行、一个管质检，像一家公司那样各司其职。
