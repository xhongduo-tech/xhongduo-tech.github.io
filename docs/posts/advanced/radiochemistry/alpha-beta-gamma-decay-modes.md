## 为什么从衰变模式开始

上一篇回答了「核为何不稳定」，这一篇回答「不稳定之后往哪走」。三种基本衰变模式——**α、β、γ**——是放射化学的「三原色」：每一种粒子有其特征能量、特征射程、特征探测手段，也因此有不同的化学后果与防护含义。<span class="marginnote">同一个放射性核素往往同时放出 α/β 与 γ，但能量与频率完全不同——读任何核素衰变数据表，第一件事是分清「主要粒子」与「伴生γ」，这决定了测活度时选什么探测器。</span>

## 1 α 衰变：重核的「瘦身」

**α 衰变（alpha decay）**：原子核自发放出由两个质子、两个中子构成的 $\alpha$ 粒子（即 $\ce{^4He}$ 核），转变为质量数减少 4、原子序数减少 2 的核：

$$\ce{^{A}_{Z}X -> ^{A-4}_{Z-2}Y + ^{4}_{2}He}$$

α 衰变主要发生在 $Z \gtrsim 83$ 的重核区，因为那里库仑排斥力接近强相互作用的极限，放出一个 $^{4}$He 核是最省力的「减负」方式。两个特征值得记住：

- **能量分立**：α 粒子能量是单值的（同一初态到同一末态），可由 Q 值精确预言。α 能谱是放射化学里最干净的「指纹」，测活度、鉴定核素都靠它。
- **穿隧效应**：α 粒子要被发射出去，必须穿过核表面的库仑势垒。它的能量（约 4–9 MeV）远低于势垒高度（约 20–30 MeV），能出来靠的是量子隧穿。<span class="marginnote">α 衰变是量子隧穿最经典的宏观体现之一——Gamow 1928 年用隧穿理论成功解释 α 衰变的巨大半衰期跨度（从纳秒到亿年），这是量子力学诞生早期最耀眼的胜利之一。它与半导体结中的隧穿是同一物理。</span>势垒越厚、α 能量越低，半衰期越长——这就是盖革-努塔尔定律（Geiger-Nuttall law）的物理根源：$\log_{10} \lambda = a + b \log_{10} R_\alpha$，其中 $R_\alpha$ 是 α 粒子射程。

## 2 β 衰变：中子在质子之间的「变身」

β 衰变改变 $N/Z$ 比而不改变质量数，有三种通道：

**β⁻ 衰变**：中子过多时，核内一个中子变为质子，放出一个电子（$\beta^-$）与一个反中微子 $\bar\nu_e$：

$$\ce{^A_Z X -> ^{A}_{Z+1}Y + e^- + \bar\nu_e}$$

**β⁺ 衰变**：质子过多时，核内一个质子变为中子，放出一个正电子（$\beta^+$）与一个中微子 $\nu_e$：

$$\ce{^A_Z X -> ^{A}_{Z-1}Y + e^+ + \nu_e}$$

**电子俘获（EC）**：质子过多的核还有一条路——直接俘获核外一个电子，与一个质子合并成中子，同时放出一个中微子：

$$\ce{^A_Z X + e^- -> ^{A}_{Z-1}Y + \nu_e}$$

β 衰变有三个深刻特征：

- **能谱连续**：与 α 粒子的分立能量不同，β 粒子能量是 0 到 Q 值之间的连续分布，因为中微子分走了一部分能量。β 能谱的端点是衰变能；但 β 粒子平均能量只有端点能量的大约三分之一——做剂量估算时若把 β 能量当成端点能量，会高估辐射影响约三倍。
- **中微子假说**：为了让连续谱与能量守恒相容，泡利 1930 年假设了中微子——一个不带电、几乎无质量、几乎不与物质作用的粒子。费米 1934 年建立了 β 衰变理论，中微子成为标准模型最早的预言粒子。<span class="marginnote">泡利自嘲「假设了不可探测的粒子」，但 1956 年莱因斯（Reines）与科万（Cowan）用核反应堆的反中微子流直接探测到了它。从假设到证实，跨越 26 年。</span>
- **质量条件精细**：三种通道各有各的能量门槛，原子质量表的计算规则不同，见第 4 节公式解析。

## 3 γ 衰变：核的「情绪释放」

α 与 β 衰变常把子核留在**激发态**。激发态核向低能态跃迁时放出的高能电磁波，就是 **γ 射线（gamma ray）**。它不改变核素种类（$Z$、$A$ 都不变），只是把核内激发能带走：

$$\ce{^A_Z X^* -> ^{A}_{Z} X + \gamma}$$

γ 跃迁有两个放射化学上重要的伴生现象：

- **同核异能跃迁（isomeric transition）**：有些激发态寿命很长（毫秒到年），这种「长命激发态」称为**同核异能态**，与基态构成同核异能对。核电池、医用同位素发生器（如 $\ce{^{99}Mo \to ^{99m}Tc}$）都利用这类态。
- **内转换（internal conversion）**：激发能有时不经 γ 发射，而直接交给核外电子、把电子打出来。这种电子叫**内转换电子**，能量也是分立的；伴随它出现的是子核的俄歇电子与特征 X 射线。**初学最易误判：凡看到从核放出的电子就以为是 β 粒子——内转换电子同样是「电子的行为」，但来源完全不同。**<span class="marginnote">区分 β 电子与内转换电子有一个实用判据：β 能谱连续，内转换电子能谱分立；且内转换电子的计数率随原子序数的三次方左右增长，而 β 无此依赖。</span>

γ 跃迁的角动量选择定则由初末态的自旋差 $\Delta I$ 决定，多极阶数越高、跃迁越慢——这解释了为何某些激发态能「憋」到成为同核异能态。

## 4 公式解析：三种 β 型衰变的能量门槛

**衰变能否发生的判据始终是 Q 值，而 β⁻、β⁺、EC 三者的 Q 值在原子质量表上的写法不同。** 设 $M(Z,A)$ 为原子质量，$m_e$ 为电子静止质量，则：

$$
\begin{aligned}
\beta^-: &\quad Q = [\,M(Z,A) - M(Z+1,A)\,]\,c^2 \\[2pt]
\beta^+: &\quad Q = [\,M(Z,A) - M(Z-1,A) - 2m_e\,]\,c^2 \\[2pt]
EC:     &\quad Q = [\,M(Z,A) - M(Z-1,A)\,]\,c^2 - B_K
\end{aligned}
$$

拆成三步理解：

- **第一步，β⁻ 的直觉**：一个中子变质子，质量数不变、原子序数加一；核外多一个电子由衰变产物自带，所以原子质量之差直接就是 Q 值。
- **第二步，β⁺ 要多扣一个电子对**：正电子是「反电子」，放出一个正电子要求同时消灭掉核外对应位置的一个电子，因此必须从母核原子质量里额外扣除两个 $m_e$。**这就是为什么 β⁺ 需要比 β⁻ 多约 1.022 MeV 的能量门槛。**
- **第三步，EC 要减去束缚能**：俘获的是核外电子，子核的电子壳层缺了一个位，需扣去该电子壳层束缚能 $B_K$（内层电子优先，故写 $B_K$）。EC 与 β⁺ 竞争——能谱上 β⁺ 的分支比越高，能测到的正电子湮没 γ 越强。

**辨析｜易错点：** 三种通道写 Q 值时**必须用原子质量而不是核质量**；且 β⁺ 与 EC 的 Q 值表达式不同，很多人把两者混成一个公式，导致阈值判断差出 1 MeV 量级。这类「门槛计算」是辐射防护与核素数据表理解的第一道坎。

## 5 小结

- **α 衰变**：重核放 $\ce{^4He}$，能量分立，靠量子隧穿，遵循盖革-努塔尔定律。
- **β 衰变**：$\beta^-$、$\beta^+$、EC 三种通道都只改 $N/Z$ 不改 $A$；能谱连续，由中微子分走能量；三者的 Q 值在原子质量表上写法不同。
- **γ 衰变**：激发态向基态跃迁，不改变核素种类；伴生现象有同核异能跃迁与内转换，内转换电子易被误判为 β。
- 每条衰变通道的**分支比**决定该核素实际放射的粒子组合，是活度测量与剂量估算的起点。
