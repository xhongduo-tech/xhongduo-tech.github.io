## 为什么从 X 射线产生开始

从这一节起，我们要给「射线」找到一个具体的出生地。诊断 X 光机与治疗加速器虽然大小悬殊，但产生产生 X 射线的物理机制只有两条：**轫致辐射**与**特征辐射**。理解了这两条机制，就能解释为什么 X 射线的能谱是「连续谱上叠加尖峰」的形状，也就能理解为什么影像物理里一切关于「穿透力」「对比度」的讨论，最后都要回到这张能谱上来。<span class="marginnote">能谱是连接第 1 节（相互作用）与第 9 节（X 射线与 CT 成像物理）的枢纽：相互作用决定「不同能量光子怎么被吸收」，能谱决定「我们手里有什么能量的光子」。</span>

## 1 两条产生机制

把高速电子打到高原子序数的靶上，会产生 X 射线，来源有二：

**轫致辐射（bremsstrahlung）**：电子在靶原子核的库仑场里减速偏转，损失的能量以光子形式放出。由于电子离核的远近千差万别，损失的动能可以从「几乎为零」到「全部」，于是光子的能量**连续分布**——这是连续谱的来源。靶的原子序数越高、电子能量越大，轫致辐射产额越高。<span class="marginnote">轫致辐射这个词源自德语 bremsen（刹车）+ Strahlung（辐射），字面就是「刹车辐射」。经典电动力学里加速电荷必辐射，电子撞靶急刹，于是辐射出光子。</span>

**特征辐射（characteristic radiation）**：高速电子撞掉靶原子内壳层（K、L 层）的电子，留下空穴，外层电子回填时释放能量差，放出**能量固定**的光子——这就是特征 X 射线。因为不同元素的能级差不同，这些光子能量是靶材料的「指纹」，在能谱上表现为一根根尖锐的谱线（Kα、Kβ）。

两条机制的比例不是固定的：低能（诊断级）时轫致辐射占大头，特征峰叠加其上；临床直线上，特征峰在能谱里只是一小撮。

有个应用把特征辐射用到了极致——**乳腺 X 线摄影**：钼靶（Mo，$Z=42$）的特征线（约 17.5/19.6 keV）恰好落在乳腺软组织的对比敏感区，配钼滤过能造出一束「窄而准」的低能谱，把腺体与脂肪的微小差异显示出来。可见「靶材料选谁」不只是散热问题，更是能谱工程问题。

## 2 X 射线管：机器的解剖

诊断 X 射线管（tube）由三件核心部件构成：

**阴极（cathode）**：由钨丝（灯丝）构成，通电流加热到约 2000°C，热电子发射产生自由电子云。聚焦罩把电子云聚成一束，射向阳极。

**阳极（anode）**：钨或钨铼合金靶，承受电子轰击并产生 X 射线。旋转阳极（rotating anode）让靶面不断转动，把热量摊到一圈上，才能承受连续出束的功率；静止阳极只用于低功率场合。<span class="marginnote">钨是近乎完美的靶材料：原子序数高（74，轫致辐射产额高）、熔点高（3410°C，扛得住电子轰击）、热导率好。诊断管阳极角度通常 7–20°，影响有效焦斑大小与半影。</span>

**管壳与滤过**：玻璃（或金属）外壳保持真空，防止电子被气体分子散射；出射窗与附加滤过（通常是铝片）滤掉低能光子。

电子从阴极飞到阳极的加速电压叫**管电压**，用 **kVp**（千伏峰值）标称——它决定了电子到达靶时的最大动能，也就决定了 X 射线能谱的上限。管电流（mA）决定每秒打靶的电子数目，**管电压定「质」，管电流定「量」**。

电子轰击在阳极上留下的光斑叫**焦斑（focal spot）**。焦斑越小，几何模糊越小、图像越锐利；但焦斑越小热密度越高，靶可能熔化。工程解法是阳极倾角：把焦斑投影到成像方向看小、实际受热面积看大，鱼与熊掌兼顾——这就是「焦点、阳极角、散热」三者间的三角恋，也是足跟效应的出处。

## 3 能谱的形态：连续谱 + 特征峰

X 射线束的能谱（光子数随能量的分布）长这样：

$$
N(E) = N_{brems}(E) + \sum_i N_{char,i} \, \delta(E - E_i)
$$

- 第一部分是**连续谱**：从接近 0 的能量一路延伸到 kVp 上限，峰值大约落在 kVp 的三分之一附近。
- 第二部分是**特征谱线**：在钨的 Kα（约 59.3 keV）、Kβ（约 67–69 keV）等处冒出的尖峰。<span class="marginnote">钨的 K 边约 69.5 keV，所以特征峰集中在 59–70 keV 区间。能量更高时特征产生效率骤降——高能射线管里特征峰几乎看不见。</span>

能谱的形状直接决定影像质量与患者剂量：低能光子几乎全被皮肤与浅表组织吸收，只添剂量不添影像信息，所以临床要**滤过**掉它们。滤过后的「有效能量」上升、平均能量上升、剂量效率提高——这正是「能谱整形」的工程含义。

## 4 公式解析：杜安–亨特极限与 X 射线效率

**「一个电子最多只能把全部动能变成一只光子。」** 这是能谱上限的唯一来源，写成公式就是**杜安–亨特定律（Duane–Hunt law）**：

$$
\lambda_{min} = \frac{hc}{eV_{max}}
$$

拆成三步理解：

- **第一步，看 $\lambda_{min}$（最短波长）**：一个电子在管电压 $V_{max}$ 下获得动能 $eV_{max}$。若它把全部动能一次性交给一只光子，这只光子的能量最大、波长最短。于是能谱存在一个刚性下限 $\lambda_{min}$，对应光子能量 $E_{max} = eV_{max}$。
- **第二步，代入常数**：$hc = 1240\ \text{eV}\cdot\text{nm}$，$e = 1.602\times 10^{-19}\ \text{C}$。例如 120 kVp 时 $E_{max} = 120\ \text{keV}$，$\lambda_{min} = 1240/120000 \approx 0.0103\ \text{nm}$——注意单位换算，keV 要先写回 eV。
- **第三步，它告诉我们什么**：$V_{max}$ 定了光子能量的天花板，所以**kVp 决定能谱的最大能量与整体「硬度」**，而 mA 只改变谱的整体高度。这把「质」与「量」的区分落到了能谱上。

**易错点：** $\lambda_{min}$ 是理论下限，实际能谱在接近下限时光子数已经很少——能谱不是到 $\lambda_{min}$ 戛然而止的矩形，而是一条向高处递减的曲线。特征峰则在它自己的能量位置上叠加。

再补一条效率公式：X 射线管的**转换效率**（辐射能量 / 电子束能量）大约正比于 $Z V$，对钨靶、100 kVp 也只有约 1%，剩下 99% 都变成了阳极上的热。**X 射线管本质上是一台 99% 效率的加热器，顺便发一点 X 射线**——这个直觉对理解散热设计、焦点温度上限、乃至第 4 篇直线加速器的靶设计都至关重要。<span class="marginnote">这句「顺便」是放射物理的幽默也是事实：几乎全部能量以热的形式耗散，所以旋转阳极、冷却油路、靶面倾角设计的全部心思，都在跟「热」搏斗。</span>

## 5 影响能谱与束流性质的四大旋钮

临床操作里，能谱由四个参数共同决定：

**管电压（kVp）**：抬高 kVp，能谱整体右移、平均能量上升、穿透力增强，但对比度（靠低能光电效应）下降。影像学里 kVp 是「穿透与对比度」的权衡旋钮。

**管电流 × 时间（mAs）**：成比例地提高光子数，谱形不变。mAs 决定「黑度」与噪声，是曝光量的直接刻度。

**滤过（filtration）**：加铝片（或铜片）滤掉低能光子，平均能量上升、皮肤剂量下降。**固有滤过**（管壁、油、窗）之外还要加**附加滤过**，总滤过用「等效铝厚度」标称。<span class="marginnote">半值层（HVL）是「束流硬度」的工程量度：滤过越厚，HVL 越大，束越硬。上一节刚用 HVL 讲过衰减，这里它又回来当能谱的标尺了——同一个物理量，两处不同的用途。</span>

**靶材料与阳极角**：高 Z 靶提高产额，特征峰位置由靶材料决定；阳极角影响焦斑投影与足跟效应（heel effect）——阳极侧的束流更软更弱。

四个旋钮并非独立：抬高 kVp 与加厚滤过都会让平均能量上移，但前者同时压低对比度、后者几乎不伤对比度——所以「合适的 kVp + 合适的滤过」往往比盲目抬 kVp 更划算，这是技术参数选择的日常技巧。

## 6 能谱的测量：直接测与间接测

能谱如此重要，自然要测量它。方法分两路：

**直接测谱**：用半导体探测器（如高纯锗，HPGe）逐光子测能量，统计出谱形。直接测谱在实验室与放射源鉴定里很常用，但在强束、高注量的临床 X 光机上要小心**脉冲堆积**（两个光子几乎同时到达，被误判成一个高能光子）——需要压计数率、加窄准直。测量得到的谱还要做「反卷积」修正探测器响应，才能还原真实能谱。

**间接测束质**：临床上更多用**半值层（HVL）**与**kVp 一致性**来监控能谱。加不同厚度的铝/铜片，测穿透后的衰减曲线，找出把强度减半的厚度——HVL 每台机器都有验收基线，晨检时若 HVL 漂移，提示滤过或管电压出了问题。这正是上一节讲过的衰减定律 $I = I_0 e^{-\mu x}$ 在质量控制里的活用法。

能谱的形状还能「看」出射线管的健康：灯丝老化、靶面龟裂、管电压漂移都会让谱形悄悄变形——所以 QA 盯住 HVL 与 kVp 一致性这两个「谱形代理指标」，而不是直接测谱，正是工程上的务实选择。<span class="marginnote">对治疗级加速器，能谱监控换成「束流能量的一致性」——用射程/深度电离曲线（$R_{50}$ 等）来间接核验，这会在第 4 篇《医用直线加速器》里展开。</span>

为什么要花这么大力气盯能谱？因为**能谱变化直接改写剂量分布**：同样 60 Gy，能谱偏硬一点，建成区更浅、深部剂量更高；偏软一点，皮肤剂量陡增。2% 的能谱漂移可能带来远超 2% 的临床后果。质量控制（QA）的本质，就是把能谱这类「看不见的物理量」用可测量的代理指标钉死在一个允许范围内。

## 7 辨析：能谱的三个常见误解

**「kVp 就是平均能量」**：不对。kVp 只是上限，平均能量大约只有 kVp 的三分之一（滤过后约三分之一到二分之一）。所以 100 kVp 的束「穿透力」远低于 100 keV 的单能光子。

**「特征 X 射线是主要的」**：在诊断能区，连续轫致辐射占绝对大头；特征峰只是叠加的小尖。特征辐射在荧光分析里重要，但在临床 X 射线成像里占比有限。

**「滤过是损失」**：滤掉低能光子看似浪费，实则每一只被滤掉的光子原本只会被患者浅表吸收、只增剂量不增信息。滤过是「用机器的热，换患者的低剂量」——净收益。

**「kVp 提高就是一切变好」**：kVp 提高会同时降低对比度、增加散射噪声、提高深部剂量。穿透力与对比度此消彼长，选 kVp 永远是权衡而不是单边优化——这正是影像物理里「技术参数选择」的日常。

## 8 小结

- X 射线来自**轫致辐射**（连续谱）与**特征辐射**（靶材料指纹峰）两条机制。
- 射线管 = 阴极灯丝 + 旋转阳极钨靶 + 真空管壳；**kVp 定质、mAs 定量**。
- **杜安–亨特定律** $\lambda_{min} = hc/eV$：一个电子最多把全部动能变成一只光子，kVp 定了能谱上限（120 kVp → 约 0.0103 nm）。
- 转换效率约正比于 $ZV$，钨靶 100 kVp 也只有约 1%——X 射线管是「99% 的加热器，顺便发 X 射线」。
- 四大旋钮：**kVp**（质/穿透）、**mAs**（量/噪声）、**滤过**（整形/降剂量）、**靶材与阳极角**（足跟效应）；**半值层 HVL** 是束硬度的测量标尺。
- 能谱测量分**直接测谱**（HPGe + 反卷积）与**间接测束质**（HVL、kVp 一致性、加速器 $R_{50}$）；能谱漂移直接改写剂量分布，QA 的本质是把它钉在允许范围内。
