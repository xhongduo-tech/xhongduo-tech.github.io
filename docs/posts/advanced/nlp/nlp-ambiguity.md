## 为什么从歧义性开始

上一节我们用三次范式浪潮回答了 NLP「从哪来」。这一节要回答一个更尖锐的问题：**它为什么这么难？** 七十年来，无论规则、统计还是神经网络，都在与同一个敌人搏斗——**歧义性（ambiguity）**。

歧义性不是 NLP 的某个 bug，而是自然语言的本质属性。人能够轻松地理解含混的句子，是因为我们拥有无穷无尽的语境与常识；而机器面对的只有孤零零的文本。**几乎每一个 NLP 任务，本质上都是一次「消歧」（disambiguation）**：分词是消歧，词性标注是消歧，句法分析是消歧，机器翻译、问答、对话更是如此。把歧义这个问题想透，你就拿到了打开 NLP 全部后续章节的钥匙。<span class="marginnote">格劳乔的台词是语言学的经典笑料：介宾短语 <em>in my pajamas</em> 既可以修饰「开枪」这个动作，也可以修饰「大象」——两种读法都合法，只有一个荒唐。</span>

## 1 一层语言，五层歧义

语言是有层次的，而**歧义在每一层都存在**。从底到顶，至少可以数出五层：

| 层次 | 研究对象 | 歧义的例子 |
| --- | --- | --- |
| 语音层 | 声音、音节、声调 | 「qīng」可以是「清、青、轻、倾……」 |
| 词法层 | 词的内部结构与兼类 | *bank* 是「河岸」还是「银行」；「报告」是名词还是动词 |
| 句法层 | 词组句的结构 | 「咬死了猎人的狗」——狗被咬死，还是狗咬死了猎人 |
| 语义层 | 句子的意义 | 「鸡不吃了」——鸡不吃东西了，还是我们不吃鸡了 |
| 语用层 | 语境中的意义 | 「他」指谁；「能把盐递过来吗」是请求而非提问 |

这五层并不独立，而是层层叠加：一个句子可能同时犯下句法、语义、语用三种歧义。**人类在阅读时几乎无意识地完成全部五层消歧；机器要把这个「无意识」显式地拆解、建模、计算。**

## 2 解剖几个经典歧义句

歧义看起来抽象，解剖几个经典例子就具体了。

**「咬死了猎人的狗」**：这句话有两种句法结构。其一，「咬死了 / 猎人的狗」——宾语是「猎人的狗」，狗被咬死；其二，「咬死了猎人 / 的狗」——「狗」是主语，狗把猎人咬死了。同一个词序，两棵不同的句法树。这是**结构歧义（structural ambiguity）**。

**「鸡不吃了」**：如果「鸡」是施事（动作发出者），意思是「鸡不吃东西了」；如果「鸡」是受事（动作承受者），意思是「我们不吃鸡了」。句子没有任何一个词被替换，纯粹是**语义角色（semantic role）**分配不同——同一个句子，两种世界。这是中文里最经典的「主宾难辨」例子。<span class="marginnote">「鸡不吃了」还揭示了一个统计细节：人脑会优先选择「更常见」的解读——通常吃鸡的概率高于鸡主动绝食，所以默认读成受事。概率，正是后面所有统计模型用来排歧义的武器。</span>

**The horse raced past the barn fell.**：读前半句「The horse raced past the barn」感觉句子已经完整，读到 *fell* 才发现它是主句动词。这种「走着走着被绊倒」的句子叫**花园幽径句（garden path sentence）**——人的句法分析器先选了一个最省力的结构，结果发现错了。这是心理学与 NLP 交界处最著名的例子之一。

**The box was in the pen.**：还记得上一节巴希勒尔的例子吗？*pen* 究竟是「笔」还是「围栏」，需要世界知识（玩具盒装不进钢笔）才能判断。这提醒我们：**歧义的消解经常要越过语言本身，走向世界。**

## 3 歧义为什么不可避免：三条根源

歧义不是语言的缺陷，而是语言为「效率」付出的代价。根源有三：

- **经济性原则**：说话人总是想用最少的符号传递最多的信息。一个形式承载多种意义（一词多义、同音），是「省力」的自然结果。<span class="marginnote">这背后是著名的齐普夫定律（Zipf's Law）：词频与词频排名大致成反比，高频词又短又常见——代价是高频词几乎都是多义词。我们会在第二篇《语料统计基础》专门展开。</span>
- **离散与连续的鸿沟**：语言是离散的符号序列，世界是连续的。把连续的物体、动作、关系硬切成离散的「词」与「类」，边界处必然模糊——「高」「矮」「大」「小」没有精确分界。
- **语境缺失**：脱离上下文，任何句子都是多义的。**「你看见那个人了吗？」这句话单独出现时，连「人」是男是女、在不在场都无法确定。** 人类靠上下文、语调、表情、常识补足语境；机器要建模语境，而语境本身往往又是另一层歧义。

组合在一起，这三条根源造成了一个数学上的后果——**组合爆炸**。

## 4 公式解析：歧义的组合爆炸

歧义不仅是「有几个解释」的问题，而是「候选解释的数量可以爆炸式增长」。以中文分词为例：一句话是一串汉字，词与词之间没有空格，切分方案的数量远非手算能穷举。

只看最简单的情形——假设所有词只可能是「单字词」或「双字词」，$f(n)$ 表示把 $n$ 个字切分干净的方法数。看最后一个字：它要么自己成一个单字词（剩下 $n-1$ 个字怎么切都行），要么和倒数第二个字组成一个双字词（剩下 $n-2$ 个字怎么切都行）。于是：

$$
\begin{aligned}
f(1) &= 1, \quad f(2) = 2, \\
f(n) &= f(n-1) + f(n-2)
\end{aligned}
$$

这正是**斐波那契数列**。逐项算下去：

$$
f(10) = 89, \quad f(20) = 10946, \quad f(30) = 1346269
$$

一句 30 个字的普通句子，即便只允许单、双字词，切分方案也超过 134 万种。<span class="marginnote">这只是「切分方案数」。若允许三字词、四字词、成语，方案数增长更快，接近第二级《组合数学》里的 Catalan 数式增长。</span>真实的切分还要叠加词性、句法、语义的选择——**歧义的量不是「几个」，而是「指数级」**。

用一小段 Python 可以把递推直接写出来：

```python
def segment_count(n):
    """只考虑单字词与双字词时，n 个字的分词方案数。"""
    if n <= 1:
        return 1
    a, b = 1, 2            # f(1), f(2)
    for _ in range(3, n + 1):
        a, b = b, a + b    # f(n) = f(n-1) + f(n-2)
    return b if n >= 2 else a

print(segment_count(20))   # 10946
```

**组合爆炸的直接后果是：穷举不可行，消歧必须「排序」。** 我们不再要求「找出所有合法解释」，而是问：在所有候选中，哪一个解释的概率最高？

## 5 对付歧义的基本思路：把不确定性交给概率

既然歧义无法消灭，NLP 的出路是给每个候选解释一个概率，然后挑概率最大的。这是统计方法对规则方法最深刻的超越：**从「找规则排除歧义」变成「用概率排序歧义」。**

一个统一的消歧公式长这样：

$$
\hat{w} = \arg\max_{w} \; P(w) \cdot P(c \mid w)
$$

其中 $w$ 是候选解释（比如一个分词方案、一个词性标注、一个词义），$c$ 是可观测的上下文。拆开看：

- $P(w)$ 是**先验**：这个解释本身在语言里有多常见（「鸡」做受事的先验高于做施事）。
- $P(c \mid w)$ 是**似然**：这个解释在多大程度上能「解释」眼前的上下文。
- 两者的乘积正比于后验 $P(w \mid c)$——给定上下文后这个解释有多可靠。

人脑做的就是这件事，只不过人脑的 $P(w \mid c)$ 里悄悄藏进了整个世界。机器版本一路进化：n-gram 只建模相邻几个词（第四篇），词向量把「相似」的上下文揉成稠密向量（第五篇），BERT 用整个句子、整个段落来建模 $c$（预训练时代）。**每前进一步，机器能「看见」的上下文就更长，歧义就被压得越低。**

**辨析｜易错点：** 常见的误会是「大模型已经解决了歧义」。更准确的说法是：大模型用海量先验把绝大多数歧义压到了极低概率，但并未消灭歧义。其一，*pen* 那种需要世界知识的歧义，模型只是「猜得很准」，不是「真正理解」；其二，语言中仍存在**本质歧义（genuine ambiguity）**——有些句子在一切语境下都真的有两种意思，比如「我借他一本书」既可以理解为「借给他」，也可以理解为「向他借」。对本质歧义，概率最多给出一个偏向，无法给出唯一真解。

## 6 小结

- 歧义遍布每一层语言：**语音、词法、句法、语义、语用**。
- 歧义的三条根源：**经济性原则、离散—连续鸿沟、语境缺失**。
- 歧义的量是指数级的：单双字切分方案数按**斐波那契**增长，$f(30)=1346269$。
- 统一的解法：**把消歧写成概率最大化**，$\hat{w}=\arg\max_w P(w)P(c\mid w)$。
- 越强的上下文建模（n-gram → 词向量 → 预训练模型）越能压低歧义。
- 大模型不是消灭歧义，而是**压缩歧义**；本质歧义依然存在。
