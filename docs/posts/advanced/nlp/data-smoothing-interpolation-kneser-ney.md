## 为什么从插值开始

上一篇的两种平滑解决了「概率不能为 0」，但都只处理了一个「计数层次」。真实的三元模型有整整三套概率：$P(w_i \mid w_{i-2} w_{i-1})$、$P(w_i \mid w_{i-1})$ 与 $P(w_i)$。这三套概率之间怎么配合？最简单的想法是：**三元组有计数就用三元，没有就退到二元，再没有就退到一元**——这叫回退（backoff）。更好的想法是：**把三套模型按权重揉在一起**，让它们永远同时发声——这叫插值（interpolation）。

这一篇我们先把插值的框架讲清楚，然后引入平滑方法史上的一个里程碑——**Kneser-Ney 平滑**。它常年霸占 n-gram 平滑的性能榜首，被 Jurafsky 称为「最优雅也最常用的平滑算法」，今天的 KenLM、SRILM 等工具里依然是它的变体当家。<span class="marginnote">为什么要花这么多篇幅讲 n-gram 平滑？因为 Kneser-Ney 里的「延续计数」是对「一个词到底多常用」最深刻的一次再思考——这个词频直觉，后面讲词向量、讲神经网络语言模型时还会反复回来。</span>

## 1 回退与插值：低阶模型的两种用法

设我们要估计 $P(w_i \mid w_{i-2} w_{i-1})$。三元组「$w_{i-2} w_{i-1} w_i$」在语料里的计数可能是 0，但它的子序列「$w_{i-1} w_i$」可能出现过很多次，单看「$w_i$」更是几乎总出现过。低阶模型的信息不能浪费，于是有两种组织方式：

**回退（backoff）**：优先用高阶模型；只有当高阶计数为 0 时才降级到低阶。<span class="marginnote">Katz 在 1987 年把回退系统化：三元组计数 > 0 就用打折后的三元概率；否则乘一个归一化系数 $\alpha$ 回退到二元；二元再不行退到一元。回退是「有条件才降级」，低阶模型是被调用的后备军。</span>它的代价是：三元组计数为 1 时（很不可靠），回退照样硬用三元，白白浪费了低阶的平滑作用。

**插值（interpolation）**：无论高阶计数是多少，都把三套模型加权求和。三元组计数为 0 时，权重 $\lambda_1$ 的部分是 0，但 $\lambda_2$、$\lambda_3$ 依然在兜底；三元组计数为 1 时，低阶模型也在帮它「扶一把」。**插值是回退的平滑版本**——它把「用/不用」的硬切换，换成了「按权重混合」的软操作。

## 2 线性插值：三套模型的加权平均

最简单的插值是**线性插值（linear interpolation）**：

$$
P(w_i \mid w_{i-2} w_{i-1}) = \lambda_1 P(w_i \mid w_{i-2} w_{i-1}) + \lambda_2 P(w_i \mid w_{i-1}) + \lambda_3 P(w_i)
$$

其中 $\lambda_1 + \lambda_2 + \lambda_3 = 1$，且每个 $\lambda_j \ge 0$。权重 $\lambda$ 体现了「你有多信任每一阶模型」：$\lambda_1$ 大，说明三元组计数足够丰富、值得信任；语料很小时，$\lambda_2$、$\lambda_3$ 会占大头。

**重点：$\lambda$ 不能从训练语料本身学，否则模型会无脑地把所有权重压给拟合最好的三元模型。** 标准做法是把语料切成三份：训练集（估计计数）、**保留集（held-out，学 $\lambda$）**、测试集（评价）。$\lambda$ 的选择标准是让保留集的概率最大——这正是一次最朴素的「防过拟合」实践。<span class="marginnote">「训练集学参数、保留集学超参数、测试集只做终审」这套三分离协议，是统计机器学习的基本纪律。它会在第二级《机器学习》里反复出现，也会在大模型时代演变成「训练 / 验证 / 测试」的三段式。</span>

还有一种更精细的**上下文相关插值（conditional interpolation）**：权重不只是三个常数，而是依赖历史——「$\lambda$ 是 $w_{i-1}$ 的函数」，历史上出现的词越多，越信任高阶。它比常数权重更准，但参数更多、更易过拟合。

## 3 公式解析：插值权重如何在保留集上学习

假设只有两阶模型（二元与一元），我们要学两个权重 $\lambda_1, \lambda_2$（$\lambda_1 + \lambda_2 = 1$）。插值模型对保留集里一个二元组 $(a, b)$ 给的概率是：

$$
P_{\text{int}}(b \mid a) = \lambda_1 P(b \mid a) + (1 - \lambda_1) P(b)
$$

对保留集里所有二元组求对数似然，得到目标函数：

$$
L(\lambda_1) = \sum_{(a, b) \in \text{held-out}} \log \Big(\lambda_1 P(b \mid a) + (1 - \lambda_1) P(b)\Big)
$$

逐步拆解求解过程：

- **第一步，固定 $\lambda_1$ 的候选值**：在 $[0, 1]$ 上取一串候选，比如 $0.1, 0.2, \dots, 0.9$。
- **第二步，对每个候选算 $L(\lambda_1)$**：把保留集里每个二元组的插值概率取对数再求和。
- **第三步，选最大**：让 $L(\lambda_1)$ 最大的 $\lambda_1$ 就是答案。因为 $L$ 在 $\lambda_1$ 上是凹函数，直接求导令其为零也行，等价于用 EM 算法迭代求解。

**直觉：** 这本质上是「在保留集上做一次最优化」。数据量充足时，$\lambda_1$ 会偏向高阶模型；数据量不足时，它会自动退回到一元模型。用 Python 在 $[0,1]$ 上网格搜索一遍：

```python
import numpy as np

def log_likelihood(lam, held_out, p_bigram, p_unigram):
    # held_out: [(a, b), ...]，保留集里的二元组
    return sum(
        np.log(lam * p_bigram[(a, b)] + (1 - lam) * p_unigram[b])
        for a, b in held_out
    )

best_lam, best_ll = 0.0, -np.inf
for lam in np.arange(0.0, 1.0 + 1e-9, 0.1):     # 在 [0,1] 上以步长 0.1 搜索
    ll = log_likelihood(lam, held_out, p_bigram, p_unigram)
    if ll > best_ll:
        best_ll, best_lam = ll, lam

print(best_lam)   # 使保留集对数似然最大的 λ1
```

## 4 Kneser-Ney 的动机：旧金山问题

插值已经很好，但 Kneser-Ney 在 1995 年发现了一个被所有人忽略的盲点，它藏在**延续计数（continuation count）**里。

先看一个经典病例。英文里「Francisco」（弗朗西斯科）在语料中出现的次数不低——可它几乎永远跟在「San」（圣）后面，是「San Francisco」的组成部分。**MLE 的教训是：我们不能用 $C(\text{Francisco})$ 来判断 Francisco 有多「常用」**，否则在回退/插值到一元模型时，模型会以为「任一词后面跟 Francisco 都挺合理」——天知道其实只有在 San 后面才对。

用词频衡量，Francisco 是个「网红」；用**「它能跟在多少个不同词后面」**衡量，Francisco 是个「社恐」。后者才更接近「这个词作为一般性延续有多可靠」。**延续计数**就是把这层直觉形式化：<span class="marginnote">弗斯（Firth）那句话在这里有了精确的数学版本：一个词的「人脉」，不是它总共被用了多少次，而是它出现在多少种不同上下文里。这个「人脉」就是延续计数——它比原始词频更能刻画词的搭配多样性。</span>

$$
P_{\text{cont}}(w_i) = \frac{\big|\{w_{i-1} : C(w_{i-1} w_i) > 0\}\big|}{\big|\{(w_{i-1}, w_i) : C(w_{i-1} w_i) > 0\}\big|}
$$

分子是「$w_i$ 前面出现过的**不同**词的个数」，分母是「语料中不同二元组类型的总数」。延续概率 $P_{\text{cont}}$ 与 $w_i$ 的原始词频 $C(w_i)$ 无关——它只问：**$w_i$ 愿意给多少种不同的词「搭伴」？**

## 5 公式解析：绝对折扣与延续概率

Kneser-Ney 平滑（下称 KN）把两件事结合：**绝对折扣（absolute discounting）**与**延续概率**。先看二元版本：

$$
P_{\text{KN}}(w_i \mid w_{i-1}) = \frac{\max\big(C(w_{i-1} w_i) - d,\ 0\big)}{C(w_{i-1})} + \lambda(w_{i-1})\, P_{\text{cont}}(w_i)
$$

其中 $\lambda(w_{i-1}) = \dfrac{d\, N_{1+}(w_{i-1}\,\cdot)}{C(w_{i-1})}$，$N_{1+}(w_{i-1}\,\cdot)$ 是「$w_{i-1}$ 后面跟过的不同词的个数」。逐步拆解：

- **第一步，绝对折扣**：从每个二元组计数里减去固定常数 $d$（经验上常取 $d = 0.75$），$d = 0.75$ 保证不为负。与古德-图灵按比例打折不同，这里**无论计数多少都减同一个 $d$**——直觉是，$c$ 次观测里真正可靠的只有 $c - d$ 次，多出来的 $d$ 份要「上交给集体」。
- **第二步，算出上缴总额**：$w_{i-1}$ 后面有 $N_{1+}$ 种不同的词，每种上缴 $d$，共上缴 $d \cdot N_{1+}$，归一化后就是 $\lambda(w_{i-1})$。它保证「对所有 $w_i$ 求和，概率和为 1」。
- **第三步，把上缴的钱按延续概率分出去**：$P_{\text{cont}}(w_i)$ 决定谁分得多。**关键是：分钱不看 $w_i$ 的原始词频，只看它的延续多样性。** Francisco 虽然词频高，延续概率却极低，所以几乎分不到钱——它只在 San 后面才值得相信。

三元版本是递归地套用同一公式：先看三元计数，打折后上缴给二元 KN 概率：

$$
P_{\text{KN}}(w_i \mid w_{i-2} w_{i-1}) = \frac{\max\big(C(w_{i-2} w_{i-1} w_i) - d,\ 0\big)}{C(w_{i-2} w_{i-1})} + \lambda(w_{i-2} w_{i-1})\, P_{\text{KN}}(w_i \mid w_{i-1})
$$

## 6 公式解析：一个「我」字后的手算对比

用一个小例子看 KN 与原始频率的差别。假设「我」出现 100 次，语料中二元组类型总数为 500。候选后继词「想」与「爱」：

- $C(\text{我 想}) = 30$，「想」跟在 5 个不同的词后面；
- $C(\text{我 爱}) = 1$，「爱」跟在 8 个不同的词后面。

先算 $w_{i-1} = \text{我}$ 的参数（设 $d = 0.75$）。「我」后面的不同词共有 13 个，所以 $N_{1+}(\text{我}\,\cdot) = 13$，$\lambda(\text{我}) = 0.75 \times 13 / 100 = 0.0975$。延续概率按「不同前词的个数 / 500」算：$P_{\text{cont}}(\text{想}) = 5/500 = 0.01$，$P_{\text{cont}}(\text{爱}) = 8/500 = 0.016$。于是：

- **「想」**：$P_{\text{KN}}(\text{想} \mid \text{我}) = \dfrac{30 - 0.75}{100} + 0.0975 \times 0.01 = 0.2925 + 0.000975 \approx 0.2935$。
- **「爱」**：$P_{\text{KN}}(\text{爱} \mid \text{我}) = \dfrac{1 - 0.75}{100} + 0.0975 \times 0.016 = 0.0025 + 0.00156 \approx 0.00406$。

**直觉：** 「我想」见过 30 次，直接靠高序计数就拿到了 0.2925 的厚实概率；「我爱」只见过 1 次，第一项几乎清零，但它第二项的延续概率比「想」高（8 个前词 vs 5 个），所以从「集体上缴」里分到的钱更多——**模型在说：我虽然没怎么见过「我爱」，但我见过「爱」跟很多人搭伴，所以它作为一般性后继是可信的。** 这就是 KN 比「按词频回退」聪明的地方。

若按朴素回退到一元模型，「想」的词频 $C(\text{想})=60$ 远高于「爱」的 $C(\text{爱})=30$，回退会把钱全给「想」——这正是旧金山问题：**高频但社恐的词，被高估了普适性。**

## 7 辨析：KN 的家族与它为什么最好

**辨析｜易错点：** 很多人以为 KN 的 $d$ 是超参数要精调。其实 Chen 与 Goodman（1998）的实验表明，在 $d = 0.5$ 到 $0.8$ 之间，性能对 $d$ 相当不敏感——真正拉开差距的是**延续计数**本身。他们还提出了**改进的 KN（modified Kneser-Ney）**：对计数为 1、2、$\ge 3$ 的事件分别用三个不同的折扣 $d_1, d_2, d_{3+}$，让 $c^* = (c+1)\frac{N_{c+1}}{N_c}$ 的古德-图灵直觉重新介入，进一步压低误差。<span class="marginnote">Chen & Goodman 在 1998 年的系统对比中，把当时十余种平滑方法放在同一批语料上横向评测，改进 KN 几乎全面胜出，从此成为统计 n-gram 的事实标准。这篇文章至今仍是平滑领域被引用最多的文献之一。</span>

**辨析｜易错点：** KN 只适用于「事件计数」模型，不是万能的。它的对象是有限的 n-gram 事件集合；当词表开放、词形动态变化时（比如遇到形态丰富的语言或流式文本），事件集合本身就不稳定，KN 的 $N_{1+}$ 与延续概率也随之失真。此外 KN 是**非参数**的——它不学习词的表示，无法把「猫」和「猫咪」的相似性迁移到未见搭配上。这个「**无法泛化到从未见过的上下文**」的根本缺陷，正是下一篇神经网络语言模型要攻克的。

## 8 小结

- **回退 vs 插值**：回退是高阶计数为 0 才降级；插值是把各阶模型加权平均，永远同时发声。插值更平滑、效果更稳。
- **插值权重**：在保留集上最大化对数似然学到，体现「训练集学参数、保留集学超参数、测试集终审」的三分离纪律。
- **延续计数** $P_{\text{cont}}$：用「一个词跟在多少个不同词后面」替代原始词频，解决「旧金山问题」。
- **Kneser-Ney**：绝对折扣 $d$ 上缴概率，再按延续概率分给未见延续；递归地套用到三元、二元。
- KN 是统计 n-gram 平滑的事实标准，但它无法泛化到未见上下文——这是神经语言模型的入场券。
