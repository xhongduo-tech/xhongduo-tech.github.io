## 为什么从词性标注开始

分词把句子切成了词，但「切对了」只是第一步。计算机要知道「小猫追蝴蝶」里谁追谁，得先分清「追」是动作、「小猫」是施事——而这第一步，是给每个词贴上它的语法类别：名词、动词、形容词……这个过程就叫**词性标注（part-of-speech tagging, POS tagging）**：给句子中的每个词标注一个词性标签的任务。

词性标注处于「底层与高层之间」的枢纽位置：向下，它消化分词结果；向上，它是句法分析、语义角色标注、命名实体识别、信息抽取的共同前置。词性本身也是极其好用的特征——第十一篇《命名实体识别》会用「词性 + 词形」做实体识别，第十三篇《机器阅读理解》会把词性喂给神经网络。而它自己，恰好是我们前面由字构词（字标注）用过的**序列标注**模具的第二次亮相：状态从「字的位置角色」换成了「词的语法类别」。<span class="marginnote">从分词到词性标注，「序列标注」这个模具连续出场两次：第一次标字（B/M/E/S），第二次标词（N/V/A…）。到第六篇《序列标注》你会看到，HMM、CRF、BiLSTM-CRF 就是专门为这一类问题打造的武器库——现在学的每一条都直接复用。</span>

## 1 词性是什么：汉语的特殊性

**词性（part of speech, POS）**：按语法功能（能否作主语、谓语、带宾语、被修饰等）对词划分的类别，即通常所说的「名词、动词、形容词」等。理论上清晰，但不同语言难度天差地别。

英语的词性有**形态标记**：「record」可以是名词或动词，但「happiness」「quickly」「beautiful」一出现，形态就暴露了类别。汉语是**孤立语**，几乎没有形态变化——「工作」在「这是我的工作」（名词）与「他在工作」（动词）里长得一模一样，只能靠上下文判断。<span class="marginnote">这也是叶斯柏森那句名言的中文注脚：汉语词的「词类」强烈地由句法位置决定。一个词是不是「名词」，要看它是不是出现在主语/宾语的位置——而不是看它长什么样。</span>

**兼类词（homograph / multi-category word）**：同一个词，在不同语境中属于不同词性的词。「报告」「研究」「领导」「工作」都身兼名词与动词两职。更麻烦的是，**越是常用词越容易兼类**——语言让高频词承担更多职能，这符合「经济原则」。因此词性标注的核心矛盾是：词表有限、兼类普遍，同一个「词形」必须依据上下文择一。<span class="marginnote">高频词更兼类，这在语料统计上非常明显：覆盖语料大部分出现次数的几百个高频词里，很大比例是多义词性词。这正呼应我们在《语料统计基础：词频、齐普夫定律与稀疏性》里看到的「少量词覆盖大部分文本」——而那少量词恰好最需要消歧。</span>

## 2 标注集：给标签定标准

标注「什么标签」得先有标准，这就引出**标注集（tagset）**：一套预先定义好的词性标签体系。中文与英文各有主流标准。

### 北京大学标注集（中文）

北大《现代汉语语料库加工规范》（1998 版）把词类分为 26 类左右，一级标记用单个小写字母：

| 标记 | 词类 | 标记 | 词类 |
| --- | --- | --- | --- |
| n | 名词 | v | 动词 |
| a | 形容词 | b | 区别词 |
| r | 代词 | m | 数词 |
| q | 量词 | d | 副词 |
| p | 介词 | c | 连词 |
| u | 助词 | y | 语气词 |
| t | 时间词 | s | 处所词 |
| f | 方位词 | w | 标点 |

细粒度还可以往下细分（如 `n` 细分出 `nr` 人名、`ns` 地名、`nt` 机构名、`nz` 其他专名），这一套「分词 + 词性」联合标注规范是中文语料加工的工业标准，也是《常用中文与英文语料库》里提到的 CTB、人民日报语料标注时遵循的骨架。

### 宾州树库标注集（英文）

英文 NLP 的事实标准是 **Penn Treebank tagset**，用大写字母编码：NN 名词单数、NNS 名词复数、NNP 专有名词、VB 动词原形、VBD 过去式、VBG 现在分词、VBN 过去分词、JJ 形容词、RB 副词、IN 介词、DT 限定词、PRP 人称代词、CC 并列连词……共 45 个左右。

**辨析｜易错点：** 标注集的选择不是小事，它直接决定系统的上限与可比性。同一句话用「北大 26 类」与「细粒度含子类」标注，得到的标签序列完全不同；跨系统比较词性标注准确率前，必须先确认双方用的是同一标注集。这也是我们在《语料库的类型与构建》里强调的「标注规范一致性」在词性层面的具体体现——**先统一标签，再谈算法好坏**。

## 3 基于 HMM 的词性标注

词性标注怎么做？与分词由字构词同构：把词性当状态、词当观测，套 HMM + 维特比。差异主要在**观测层**：

- **观测从字变成了词**：字的字符集约几千个，词的词表却动辄几万、几十万，于是发射概率 $P(w_i \mid t_i)$ 的稀疏问题比分词严重得多——大量「词 + 词性」组合在训练语料里从未出现。
- **应对**：一是**平滑**（给未出现的组合一个小的非零概率，第四篇《数据平滑》专讲）；二是**词形特征**——把词尾、大小写、是否含数字等形态线索并进发射概率（英文尤其有效，如 `-tion` 结尾倾向名词）。
- **解码不变**：仍用维特比找最优标签序列，只是状态空间从 4 个（B/M/E/S）扩大到几十个词性。

下面是一个把「兼类消歧」具象化的极小例子——只有两个词「研究 工作」，两个词性 N/V，用维特比选最可能的序列：

```python
# 观测序列：「研究 工作」；词性集合：N（名词）/ V（动词）
words = ['研究', '工作']
tags = ['N', 'V']

# 发射概率 P(词 | 词性)
emit = {
    ('研究', 'N'): 0.6, ('研究', 'V'): 0.4,
    ('工作', 'N'): 0.5, ('工作', 'V'): 0.5,
}
# 转移概率 P(t_i | t_{i-1})，含句首标记 <s>
trans = {
    ('<s>', 'N'): 0.6, ('<s>', 'V'): 0.4,
    ('N', 'N'): 0.3, ('N', 'V'): 0.7,
    ('V', 'N'): 0.8, ('V', 'V'): 0.2,
}

# 维特比：v[t][tag] = 到第 t 个词为止、当前词性为 tag 的最大概率
v = [{} for _ in words]
back = [{} for _ in words]
for tag in tags:
    v[0][tag] = trans[('<s>', tag)] * emit[(words[0], tag)]
    back[0][tag] = '<s>'
for t in range(1, len(words)):
    for tag in tags:
        (prev, p) = max(
            ((p, v[t-1][p] * trans[(p, tag)] * emit[(words[t], tag)])
             for p in tags), key=lambda x: x[1])
        v[t][tag] = p
        back[t][tag] = prev

best = max(tags, key=lambda tag: v[-1][tag])   # 最后一个词的最优词性
seq = [best]
for t in range(len(words) - 1, 0, -1):
    seq.append(back[t][seq[-1]])
print(list(reversed(seq)))   # 最可能的词性序列
```

## 4 公式解析：HMM 词性标注模型

与分词的字标注模型几乎同构。给定词序列 $W = w_1 w_2 \cdots w_n$，要找最可能的词性序列 $T = t_1 t_2 \cdots t_n$。**重点：数学模型是——**

$$
T^* = \arg\max_{T} \prod_{i=1}^{n} \underbrace{P(w_i \mid t_i)}_{\text{发射：词–词性}} \cdot \underbrace{P(t_i \mid t_{i-1})}_{\text{转移：词性–词性}}
$$

- **第一步，读懂发射概率 $P(w_i \mid t_i)$**：给定词性是名词，出现词「工作」的概率是多少。它编码了「这个词能当什么词性」——兼类词的多个词性在发射概率上都会有权重。
- **第二步，读懂转移概率 $P(t_i \mid t_{i-1})$**：名词后面跟着动词的概率。它编码了**语法结构**——「动词后接名词」（动宾）比「动词后接动词」常见，正是语言规律的浓缩。
- **第三步，二者连乘、全句累乘**：既要「每个词当得起它的词性」（发射），又要「相邻词性的接续通顺」（转移）。维特比在 O(n·|T|²) 内求出使整条乘积最大的序列，其中 |T| 是词性个数。<span class="marginnote">对比分词的字标注模型（第三篇第 4 节）：两个公式的骨架完全一样，只是「字 ↔ B/M/E/S」换成了「词 ↔ N/V/A…」。理解这一点，就等于理解了「序列标注」这个大一统框架——它覆盖分词、词性标注、命名实体识别等一大堆任务。</span>

这里发射概率 $P(w_i \mid t_i)$ 用词形估计，会遭遇严重的稀疏性（未登录词的发射概率为零），所以实战系统常用**词性标注 + 生词处理**：对词典外的生词，退回到「形态 + 上下文」猜词性——英文看后缀、中文看字类与相邻词性。宗成庆《自然语言处理》7.5 节把「生词处理方法」单列，正是因为它决定了下限。

## 5 从统计到神经网络：方法与现状

词性标注的方法谱系，几乎就是整个 NLP 方法史的缩影：

**基于规则**（1960–1980s）：人工编写「如果当前词是 X 且下一个词是 Y 则标 Z」的规则，维护成本高、覆盖有限。
**基于统计**（1990s–）：HMM、最大熵（ME）、CRF。CRF 解决了 HMM 的两个强假设问题（马尔可夫性、观测独立），允许任意重叠特征，是统计时代的巅峰。<span class="marginnote">HMM 的「观测独立」假设在词性标注里特别吃亏——判断「bank」是名词还是动词，往往要看它左右各两三个词。CRF 允许把「前一词、后一词、前后词性」都做成特征，效果显著提升。HMM 与 CRF 的完整对比，我们放在第六篇《序列标注》专讲。</span>
- **基于神经网络**（2010s–）：BiLSTM-CRF 把「窗口特征」升级为「循环网络自动学到的上下文表示」，一度是 SOTA；再往后，预训练语言模型（BERT 类）把词性标注变成了一个几乎「躺赢」的下游任务——特征早已内化在上下文表示里。

**重点：词性标注的准确率已经很高（英文 >97%、中文 >95%，指在标准测试集上），但「高」不等于「解决」**——口语、网络文本、专业领域、低资源语言上的表现仍大幅下滑，兼类词与标注集不统一的问题也没有消失。这提醒我们：序列标注框架成熟，但「数据与标准」才是真正的天花板。

## 6 小结

- **词性标注**给句子每个词标语法类别，是句法分析、NER、信息抽取的共同前置，也是序列标注框架的第二次应用。
- **汉语特殊性**：无形态变化、兼类词普遍、词性由句法位置决定；**越是高频词越容易兼类**，消歧只能靠上下文。
- **标注集**：中文以北大《现代汉语语料库加工规范》的 26 类为标准，英文以 Penn Treebank tagset 为标准；跨系统比较必须统一标注集。
- **HMM 词性标注**：状态=词性、观测=词，发射 + 转移 + 维特比解码；观测由字变词后稀疏性加剧，需平滑与形态特征。
- **方法谱系**：规则 → 统计（ME/CRF）→ 神经网络（BiLSTM-CRF → 预训练模型）；准确率很高但领域与低资源场景仍是短板。

在下一节，我们回到文本预处理的「清理」环节——命名实体规范化、停用词与词形还原（Stemming & Lemmatization），把分词和词性标注之后的原始文本收拾成干净、规整的统计单元。
