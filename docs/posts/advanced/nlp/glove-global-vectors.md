## 为什么从 GloVe 开始

前面两篇的 Word2Vec，训练时一次只盯一个滑动窗口：语料里所有「共现计数」，只有落在当前窗口内的部分被用到，用完即弃。可这些计数明明可以**预先全部统计好**——一个词和另一个词在全语料里一共共现了多少次，这个数本身就是最有价值的统计量。Word2Vec 等于守着金矿，却每次只挖一铲子。

2014 年，斯坦福的彭宁顿（Jeffrey Pennington）等人提出 **GloVe（Global Vectors，全局向量）**：不再边扫语料边训练，而是先把**全局共现矩阵**算好，再直接对「共现计数的对数」做加权回归。它把信息检索里的矩阵分解传统（LSA）与 Word2Vec 的向量学习传统拧成一股绳，在语义相似度与类比任务上取得了当时的最好成绩。<span class="marginnote">GloVe 的名字就是它的立场：Global——用的是全语料的全局统计；Vectors——产出的是稠密低维向量。它与 Word2Vec 并非替代关系，而是「同一目标、不同统计口径」的两条实现路径。</span>

理解 GloVe 的关键在于一个观察：**共现计数的「比值」比「数值」更携带语义**。下面第三节我们就从这条线索出发。

## 1 共现矩阵里的语义藏在比值里

设 $X$ 是全局共现矩阵，$X_{ij}$ 表示词 $j$ 出现在词 $i$ 的上下文窗口中的次数。单独看 $X_{ij}$ 的绝对值没有太多信息——「的」和几乎所有词都高频共现。但**比值** $X_{ik} / X_{jk}$ 能剔掉高频词的干扰，暴露出真正的语义关系。

原论文用了一组经典例子。考虑词对「冰」与「蒸汽」，以及三个探针词「固体」「气体」「水」。全语料中，$X_{\text{冰},\text{固体}}$ 显著大于 $X_{\text{蒸汽},\text{固体}}$（冰是固体、蒸汽不是），于是比值 $X_{\text{冰},\text{固体}} / X_{\text{蒸汽},\text{固体}} \gg 1$；反过来关于「气体」，比值远小于 1；而「水」和两者都相关，比值接近 1。<span class="marginnote">「比值接近 1」的意思是：探针词对两个词「一碗水端平」——它区分不了冰和蒸汽，也就说明它不携带区分这二者的语义。</span>

**重点：** 这个比值是一个「三维」信息——它由三个词（$i, j, k$）共同决定。GloVe 的洞见是：要让**向量内积**来表达它，最自然的做法是令

$$
w_i \cdot w_j \approx \log X_{ij}
$$

这样比值就能写成两个内积之差：$w_i \cdot w_k - w_j \cdot w_k = w_k \cdot (w_i - w_j) \approx \log(X_{ik} / X_{jk})$。**把「对数共现计数」当作向量内积的目标，比值关系就自动编码进了向量空间**——这正是 GloVe 目标函数的第一性原理。

## 2 GloVe 的目标函数：加权对数回归

把上面的原理写成全局损失，GloVe 要最小化：

$$
J = \sum_{i,j=1}^{V} f(X_{ij}) \Big( w_i^{\top} \tilde{w}_j + b_i + \tilde{b}_j - \log X_{ij} \Big)^{2}
$$

四个符号需要说清：

- **$w_i$**：词 $i$ 的**主向量**（要学的词向量）。
- **$\tilde{w}_j$**：词 $j$ 的**上下文向量**（同一个词，在扮演「被共现的对象」时的另一套向量，与 Word2Vec 的两张表思路一致）。
- **$b_i, \tilde{b}_j$**：两个**标量偏置**。它们吸收词频带来的整体偏移——高频词天然共现多、$X_{ij}$ 大，偏置项替主向量把这部分「固定差异」扛下来，让 $w_i \cdot \tilde{w}_j$ 专注于刻画语义而非词频。
- **$f(X_{ij})$**：权重函数，控制每个词对在损失里的「信任度」，见下一节。

对每个共现对，模型要「预测」$\log X_{ij}$。为什么是**对数**？因为 $X_{ij}$ 的分布极其不均衡：绝大多数词对不共现（$X_{ij}=0$），少数高频对子动辄成千上万。取对数把动态范围从「0 到几百万」压缩成「0 到十几」，回归才做得动。<span class="marginnote">对数的出现也呼应了齐普夫定律：词频的幂律分布，取对数后接近线性，才适合用最小二乘去拟合。这条「幂律 → 取对数 → 线性建模」的链条，在信息论与统计里反复出现。</span>

## 3 权重函数：给每个词对分配信任

并非所有共现计数都同等可信。$f(X_{ij})$ 要满足三个直觉：

1. 不共现的词对（$X_{ij}=0$）应当被忽略——$f(0) = 0$，反正 $\log 0$ 无定义。
2. 频次太低的词对充满噪声，不能过度信任。
3. 频次太高的词对（「的」「了」这类功能词的搭配）也不该主导损失，否则学习退化成拟合句法垃圾。

GloVe 选择了一个分段函数：

$$
f(x) = \begin{cases} (x / x_{\max})^{\alpha} & x < x_{\max} \\ 1 & x \ge x_{\max} \end{cases}, \qquad \alpha = 0.75, \quad x_{\max} = 100
$$

它在 $0$ 处取 $0$，随 $x$ 递增，到 $x_{\max}=100$ 后封顶为 1。<span class="marginnote">$\alpha = 0.75$ 与负采样里的 $3/4$ 次幂惊人地相似——这并非巧合，两者都在做同一件事：压制超高频词的支配地位、给中频但「有信息量」的词对更多权重。词频的幂律分布催生了这套「次线性加权」的通用药方。</span>

**重点：** 权重函数让损失把注意力集中在「有区分度」的词对上——既非噪声频段，也非功能词频段，而是那些「说了点语义」的中频搭配。这是 GloVe 与朴素矩阵分解在统计口径上最本质的区别。

## 4 公式解析：GloVe 目标函数

把目标函数拆成三步，理解每个环节为什么长这样：

$$
J = \sum_{i,j=1}^{V} f(X_{ij}) \Big( w_i^{\top} \tilde{w}_j + b_i + \tilde{b}_j - \log X_{ij} \Big)^{2}
$$

- **第一步，核心项 $w_i^{\top} \tilde{w}_j$**：这是我们给「词 $i$ 与词 $j$ 的关系」指定的载体——内积。它越大，代表两个向量越同向，语义越相近。模型要学的是让这个内积恰好对上「观测到的共现强度」。
- **第二步，目标值 $\log X_{ij}$**：不是 $X_{ij}$ 本身，而是它的对数。原因是 $X_{ij}$ 横跨几十个数量级，直接回归会被几个超高频词对带偏；对数把它拉回可回归的尺度，也让「倍数关系」（比值）变成「加减关系」（差），正好与内积的线性结构匹配。
- **第三步，偏置 $b_i + \tilde{b}_j$**：词频本身会抬高所有与之相关的计数，这是「全局效应」而非「两个词之间的语义关系」。偏置项专门吸收这层效应，保证内积项只编码**相对**语义，而不是替词频背锅。
- **第四步，外层加权 $f(X_{ij})$**：把每个词对的误差平方乘以信任度。低频噪声对子权重趋近 0，超高频功能词对子权重封顶为 1，中频「语义对子」获得最大相对权重——损失变成一场由信息量主导的加权回归。

训练用梯度下降（原论文用 AdaGrad）迭代几十轮即可收敛。整个过程**没有神经网络、没有反向传播深链**，就是一次带权最小二乘——GloVe 更像「统计模型」，而不像「神经网络」。

## 5 与 LSA、Word2Vec 的关系

GloVe 站在两条传统的交叉点上：

- **LSA（潜在语义分析）**：先造共现矩阵，再做奇异值分解（SVD）取前 $k$ 个奇异向量。它是全局的，但直接在**原始计数**上做分解——被词频的幂律尾巴支配，且 SVD 无法把「对数」「加权」「偏置」这些统计设计揉进去。GloVe 等于把「对矩阵做分解」升级成「对计数做带权对数回归」。
- **Word2Vec**：局部、预测式，一次用一个窗口，逐样本更新；不直接利用全局计数，训练是「在线」的。GloVe 把统计量一次性算完，离线回归，更可控、更可复现。

**重点：** 一个常见说法是「GloVe 比 Word2Vec 更充分利用了全局统计」——这在统计口径上是对的，但二者**都**建立在本专题第五篇的分布式假设之上，也都产出稠密向量、都能做类比推理。它们在大部分评测上表现接近，谁更好取决于任务与语料，而不是「谁更先进」。<span class="marginnote">训练完成后有个值得记住的细节：GloVe 论文发现把主向量与上下文向量相加 $w_i + \tilde{w}_i$ 作为最终词向量，效果通常优于只取主向量。这等于让「两种角色」的信息互相补充——与 Word2Vec 里「取两张表的和」的做法异曲同工。</span>

GloVe 的一个简化的损失示意可以这样写：

```python
import numpy as np

# 一个 6 词的小共现矩阵：X[i][j] = 词 j 出现在词 i 上下文中的次数
X = np.array([
    [0, 3, 2, 0, 0, 0],
    [3, 0, 1, 1, 0, 0],
    [2, 1, 0, 2, 1, 0],
    [0, 1, 2, 0, 0, 3],
    [0, 0, 1, 0, 0, 1],
    [0, 0, 0, 3, 1, 0],
], dtype=float)

V, d = X.shape[0], 3
w, w_t = np.random.randn(V, d), np.random.randn(V, d)   # 主向量 + 上下文向量
b, b_t = np.zeros(V), np.zeros(V)                        # 两个标量偏置

x_max, alpha = 100, 0.75
f = np.minimum(1.0, (X / x_max) ** alpha)               # 权重函数
loss = (f * (w @ w_t.T + b[:, None] + b_t[None, :] - np.log(X + 1e-8)) ** 2).sum()

print(f"GloVe 损失 = {loss:.3f}")
```

## 6 易错辨析：GloVe 不是「对共现矩阵做 SVD」

**辨析｜易错点：** 最普遍的误解是把 GloVe 描述成「把共现矩阵 SVD 一下」。三步之差，天壤之别：第一，GloVe 的目标是**对数计数**，不是原始计数；第二，它带**偏置项**吸收词频效应；第三，它用**权重函数**重新分配每个词对的信任度，且直接优化出向量而非先分解再截断。这些设计合起来，才让 GloVe 摆脱了 SVD 被幂律支配的老毛病。

**辨析｜易错点：** 还有人误以为 GloVe 是「神经网络模型」。它**没有**神经网络——没有隐层、没有激活函数、没有反向传播深链，就是一个带权最小二乘回归。这一点也解释了为什么它训练极快、极其稳定：一个统计模型不需要「炼丹」式的调参。<span class="marginnote">理解 GloVe 是回归而非神经网络，也帮你建立一个判断框架：很多「embedding 方法」其实都落在「回归 vs 网络」的谱系上——线性回归式的（GloVe、LSA）可解释、稳定，网络式的（Word2Vec、ELMo）更灵活、能叠深度。二者没有优劣，只有取舍。</span>

## 7 小结

- GloVe 直接对**全局共现矩阵**建模：$w_i \cdot \tilde{w}_j + b_i + \tilde{b}_j \approx \log X_{ij}$。
- 语义藏在共现计数的**比值**里，对数把「比值」翻译成「内积之差」，让向量自动编码相对语义。
- **权重函数** $f(x) = \min(1, (x/x_{\max})^{0.75})$ 压制高频与低频噪声，把损失聚焦到中频「语义对子」。
- GloVe 是**带权最小二乘回归**，不是神经网络；它融合了 LSA 的全局统计与 Word2Vec 的向量学习。
- 训练后取 $w_i + \tilde{w}_i$ 作为最终词向量，效果更佳。

在下一节，我们把「未登录词」这个老大难摆上台面：无论 Word2Vec 还是 GloVe，都只能表示**训练时见过的词**。**FastText** 用子词（subword）信息让模型对没见过的词也能现场拼出向量。
