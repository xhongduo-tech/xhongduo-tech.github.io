## 1 什么是自然语言处理

**自然语言处理（Natural Language Processing，NLP）**：研究让计算机能够**处理、理解与生成人类自然语言**的学科。宗成庆在《自然语言处理》开篇给出的表述是：让计算机能够处理自然语言输入、理解自然语言并生成自然语言输出。

定义里藏着三个动词，逐个展开：

- **处理（processing）**：对文本做程序化的机械加工——清洗、切分、转换、检索、标注。这是 NLP 最「低」的层次，但也是最扎实的地基。
- **理解（understanding）**：把语言映射成某种**意义表示**，让机器「读得懂」——知道问句在问什么、陈述在断言什么、指令在要求什么。
- **生成（generation）**：从意义或意图出发，产出人读得通的自然语句——这是把理解反过来的那一面。

<span class="marginnote">图灵在 1950 年的论文《计算机器与智能》（Computing Machinery and Intelligence）中提出「模仿游戏」：让机器用自然语言对话骗过人类裁判，以此判定机器能否思考。图灵把抽象的「思考」转译成可检验的「能否对话」——NLP 由此成了智能最直接的考场。</span>

与自然语言相对的是**形式语言（formal language）**——人为设计、语法严格受限的符号系统，比如编程语言、逻辑公式。两者的差异正是 NLP 困难的根源：编程语言是设计出来给机器执行的，句法确定、无歧义；自然语言是演化出来给人交际的，灵活、含混、依赖语境。<span class="marginnote">也正因如此，计算机「天生」更适应形式语言，而把自然语言翻译成机器可计算的表示，一直是 NLP 最核心的工程任务。编程语言的处理在第三级《编译原理》中展开，与 NLP 互为镜像。</span>

## 2 为什么语言对计算机如此困难

计算机擅长精确、规则的符号运算，而自然语言恰恰在几个层面都「不配合」。把它们一一列出来，就等于画出了 NLP 要攻克的战场。

### 歧义（ambiguity）

同一个表面形式，可以对应多种解释。歧义在每一个语言层次都会出现：

- **词法歧义**：「研究生命的起源」中，「研究」既可以切分为「研究／生命」，也可以切分为「研究生／命」——切分位置不同，意思完全不同。
- **句法歧义**：「咬死了猎人的狗」到底是谁咬死了谁？「猎人的狗」被咬死，还是狗咬死了猎人？又比如英文的 *I saw the man with a telescope\*，望远镜在谁手里，句子结构完全不同。
- **语义歧义**：「鸡不吃了」——是鸡不吃食了，还是我们不吃鸡了？
- **语用歧义**：对方说「今天有点冷」，是陈述天气，还是在暗示你关窗？

**辨析｜易错点：** 歧义不是「含糊不清」这么简单。人消除歧义几乎不费力气，是因为有上下文与常识；而计算机看到的只是一串离散符号，**同一个符号串在不同层次有多个解读，机器必须学会在其中选一个**——这恰恰是 NLP 最难的命题。

### 多义（polysemy）

一词多义是语言的家常便饭。英语的 *bank\* 既是「河岸」又是「银行」；汉语的「打」可以打人、打水、打电话、打酱油。多义意味着：**词本身并不携带完整语义，语义要在使用它的句子中才能确定。**

### 离散符号与组合爆炸

语言是一套**离散符号**系统：一句话由词组成，词由字组成，彼此之间没有「渐变」——不像像素那样有中间值。更麻烦的是**组合爆炸**：词汇量动辄几十万，句子长度任意，可能的句子数量是天文数字。绝大多数合法的句子在语料中从未出现过，这就是著名的**稀疏性（sparsity）**问题。<span class="marginnote">稀疏性是统计 NLP 的梦魇：如果「没见过的组合」概率一律算作零，机器就永远学不会说新话。如何给「没见过的」一个不为零的概率，正是第四篇《n-gram 语言模型》里各种平滑方法要解决的事。</span>

### 上下文依赖

语言的解释几乎永远依赖上下文——前文说了什么、说话人是谁、场景是什么、共享的世界知识是什么。「我把它放在桌上了」里的「它」指什么，只有往前文看才知道。上下文不止于一句话，而是一层层向外扩展的语境。

## 3 NLP 任务的层次：从词法到语用

要处理如此困难的语言，NLP 把理解拆成了四个由浅入深的层次。这四个层次恰好对应语言学对语言结构的经典划分，也决定了任务清单的组织方式：

![自然语言分析的四个层次：词法 → 句法 → 语义 → 语用](/images/nlp/what-is-nlp-1.svg)

- **词法层（lexical）**：处理最小的有意义单位。中文要先**分词**，还要标注**词性（POS）**、识别**命名实体（NER）**。
- **句法层（syntactic）**：还原词与词的组合结构，做**成分句法分析**（短语怎么嵌套）或**依存句法分析**（哪个词依赖哪个词）。
- **语义层（semantic）**：判定句子「在说什么」——**词义消歧**、**语义角色标注**（谁是施事、谁是受事）、**文本蕴含**（一句话能否推出另一句）。
- **语用与篇章层（pragmatic / discourse）**：结合语境还原「想干什么」——**指代消解**（「它」指谁）、**对话意图识别**、**篇章分析**。

现实中的 NLP 任务往往横跨多层。下面这张表把典型任务按主要层次归类，是全书的路线图：

| 层次 | 代表任务 | 一句话说明 |
| --- | --- | --- |
| 词法层 | 分词、词性标注、命名实体识别 | 给文本打好词汇级地基 |
| 句法层 | 成分句法分析、依存句法分析 | 还原词与词的组合结构 |
| 语义层 | 词义消歧、语义角色标注、文本蕴含、语义解析 | 判定句子在说什么 |
| 语用/篇章层 | 指代消解、对话意图识别、篇章分析 | 结合语境还原想干什么 |
| 应用层（综合） | 情感分析、机器翻译、问答、摘要、对话 | 面向产品的端到端任务 |

中文在词法层有一个英文没有的特殊门槛：**英文天然以空格分词，中文需要专门的自动分词**。上面「研究生命的起源」就是中文分词歧义的经典例子——同一句话有「研究／生命」与「研究生／命」两种切分。切分错了，后面所有层次全部跟着错，所以第三篇会专门花大量篇幅讲分词。

```python
# 示意：同一个字符串，切分方式不同，语义完全不同
s = "研究生命的起源"
seg_a = "研究 / 生命 / 的 / 起源"   # 正确的切分
seg_b = "研究生 / 命 / 的 / 起源"   # 歧义切分，语义走样
```

## 4 公式解析：统计机器翻译的噪声信道模型

NLP 并非一开始就「端到端」。在统计方法占主流的时代，机器翻译的经典框架是**噪声信道模型（noisy channel model）**，它漂亮地展示了概率论如何进入 NLP——这也是全专题第一条核心公式。

设源语言句子为 $f$（例如英文），目标语言句子为 $e$（例如中文）。我们想要的翻译是：在已知 $f$ 的条件下，概率最大的那个 $e$。直接估计 $P(e \mid f)$ 很难，贝叶斯公式把它拆成三块：

$$
P(e \mid f) = \frac{P(f \mid e)\, P(e)}{P(f)}
$$

由于分母 $P(f)$ 与 $e$ 无关，求最大值时可以丢弃，于是：

$$
\hat{e} = \arg\max_{e} \, P(e \mid f) = \arg\max_{e} \, P(e)\, P(f \mid e)
$$

对这条式子做三步拆解：

- **第一步，$P(e)$——语言模型**：衡量 $e$ 作为目标语言「说得通不顺」。它只依赖目标语言自身的规律，与源语言无关。
- **第二步，$P(f \mid e)$——翻译模型**：衡量「$e$ 翻成 $f$」有多合理，负责忠实度。
- **第三步，$\arg\max$——解码**：在候选译文 $e$ 中搜索，挑出两项乘积最大者。

这个分解的意义被严重低估了。注意第一步的 **$P(e)$ 语言模型**——它不关心翻译，只关心「一段自然语言自身有多自然」。n-gram 语言模型、神经网络语言模型、乃至今天的大模型，本质上全都在逼近同一个东西：语言本身的概率分布 $P(w_1 w_2 \cdots w_n)$。<span class="marginnote">宗成庆《自然语言处理》§1.1 在讲机器翻译时引入的就是这个贝叶斯框架。巧合的是，贝叶斯公式也正是第二级《概率论与数理统计》与《信息论》的枢纽——NLP 与它们在此第一次握手。</span>到了大模型时代，Transformer 用条件生成直接建模 $P(e \mid f)$，不再需要贝叶斯分解——但「语言模型是理解与生成的核心部件」这条主线，从未改变。

## 5 核心对比表：NLP 研究方法的四代演进

最后回答「方法怎么演进」。NLP 的六十年大致可划分为四代，每一代都在回应上一代解决不了的瓶颈：

| 代际 | 大致年代 | 核心思想 | 代表方法与系统 | 主要局限 |
| --- | --- | --- | --- | --- |
| 规则方法 | 1950s–1980s | 人工总结语言规则 | 基于规则机器翻译、专家系统、ELIZA | 规则覆盖不全、脆弱，人工成本高 |
| 统计方法 | 1990s–2010s | 从大规模语料中学概率 | n-gram 语言模型、HMM、CRF、统计机器翻译 | 依赖语料规模，特征工程繁重 |
| 神经网络方法 | 2010s–2018 | 端到端的分布式表示 | 词向量、RNN、Seq2Seq、注意力机制 | 需要海量数据与算力，解释性弱 |
| 预训练大模型 | 2018–今 | 大规模预训练 + 微调/提示 | BERT、GPT、T5、ChatGPT | 算力成本高，幻觉与对齐问题 |

四代演进有一条清晰的暗线：**计算机从不理解语言，到越来越擅长「模拟」语言的统计规律，最终在规模足够大时逼近「读懂语言」的外在表现。** 规则方法靠人写死知识，统计方法让机器从数据里学，神经网络方法把「特征工程」变成「表示学习」，而大模型把「表示学习」进一步放大成「预训练 + 缩放」——语言模型 $P(w_1 \cdots w_n)$ 的参数从几千个膨胀到几千亿个，这条路我们在第四级《大模型原理》中会完整走一遍。<span class="marginnote">一个耐人寻味的对照：大模型时代不再需要人工设计翻译模型，直接「提示」模型就能翻译、摘要、写代码——「特征工程」让位给了「提示工程」。这正是从第四代开始的范式转移。</span>

## 6 小结

- **自然语言处理（NLP）**：让计算机处理、理解与生成人类自然语言的学科；与语法严格的形式语言相对。
- **语言对计算机困难的根源**：歧义、多义、离散符号的组合爆炸与稀疏性、上下文依赖。
- **任务四层次**：词法 → 句法 → 语义 → 语用，自底向上从符号走向意义；典型任务（分词、POS、句法分析、情感、机器翻译、问答、对话）横跨多层。
- **统计机器翻译的噪声信道模型**：$\hat{e} = \arg\max_e P(e) P(f \mid e)$，其中语言模型 $P(e)$ 是贯穿全书、通往大模型的钥匙。
- **方法四代演进**：规则 → 统计 → 神经网络 → 预训练大模型，本质是让机器越来越擅长逼近语言的统计规律。
