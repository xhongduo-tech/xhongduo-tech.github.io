## 为什么从文本分类开始

前面六篇解决的都是**给序列的每个位置贴标签**。文本分类换一个更整的问题：**给整篇文本一个类别**——这是垃圾邮件过滤、情感分析、新闻主题分类、商品评论打分的公共底座，也是 NLP 里任务形态最简单、应用最广的一类。<span class="marginnote">序列标注与文本分类是 NLP 的两大「任务母型」：一个逐位置打标签，一个整篇定类别。后续的很多任务（情感分析、问答、摘要）都可以看成这两者的变体或组合。</span>

这一篇先解决「分类的输入长什么样」——**特征工程**。在深度学习之前，特征工程是文本分类的全部手艺：怎么把一篇文档表示成计算机能算的向量，怎么从词袋里挑出真正有用的信号。它承接第三篇的 BoW/TF-IDF，也为第七篇的朴素贝叶斯、SVM 提供素材。

## 1 什么是文本分类

**文本分类（text classification / text categorization）**：给定文档 $d$ 与预定义类别集合 $C=\{c_1,\dots,c_K\}$，学习一个分类器 $f: d \mapsto c \in C$，把文档归入一个（或多个）类别。<span class="marginnote">多标签分类（一篇新闻同时属于「体育」和「国际」）对应输出多个类别；单标签分类则要求互斥。评测指标上，多标签要算每个类别的宏平均或微平均 F1——细节见第十九篇《NLP 评测》。</span>

常见应用：

- **垃圾邮件检测**：正常 / 垃圾（二分类）；
- **主题分类**：体育 / 财经 / 科技 / 娱乐……（多分类）；
- **情感极性**：正面 / 负面 / 中性（情感分析，第七篇展开）；
- **意图识别**：订机票 / 查天气 / 闲聊（第十四篇对话系统的 NLU）。

尽管形态简单，文本分类却承受着别的任务没有的压力：**特征维度极高**（词表轻松几十万维）、**数据稀疏**（每个文档只碰到词表的一小部分）、**类别不平衡**（垃圾邮件可能只占 1%）。这三座大山决定了特征工程的基本走向。

## 2 文档表示：词袋、n-gram 与 TF-IDF

分类器只能吃数值向量，第一步是把文档变向量。第三篇已经详细讲过词袋与 TF-IDF，这里从**分类视角**快速回放并补充两点：

- **词袋（BoW）**：$d \mapsto (c_{w_1}, c_{w_2}, \dots, c_{w_{|V|}})$，每个维度是词 $w$ 在文档里出现的次数（或是否出现）。**丢掉了词序**——「狗咬人」与「人咬狗」向量相同，这是 BoW 的固有盲区。
- **n-gram 扩展**：把特征从「单个词」扩到「相邻 $n$ 个词」——二元词组 `("不","喜欢")`、三元词组。**n-gram 部分恢复了词序信息**，代价是维度爆炸、数据更稀疏。<span class="marginnote">n-gram 是「词袋 + 局部词序」的廉价折中：它不建模整句结构，但把「不 喜欢」「喜欢 不」这类关键局部模式变成了可区分的特征。特征维度从 $|V|$ 涨到 $|V|^n$，所以工程上常配合下面的特征选择。</span>
- **TF-IDF 加权**：用词频 × 逆文档频率把「常见但不重要」的词（「的」「了」）压低、把「稀罕而关键」的词（「并购」「重组」）抬高。对分类，TF-IDF 几乎总是比纯词频好。

**一个关键的工程决策**：用词频还是用 TF-IDF？经验法则——TF-IDF 在浅层模型（朴素贝叶斯、SVM、逻辑回归）上几乎总是更优，因为分类决策往往由「少数判别性强的词」主导，TF-IDF 正好放大了它们。

## 3 特征工程：超越词袋的加分项

词袋只是地基。统计 NLP 时代的特征工程是一套**工具箱**，从多个角度补充信号：

| 特征类型 | 例子 | 捕捉什么 |
| --- | --- | --- |
| 字符 n-gram | 词「international」的字符 n-gram | 词形相似性、拼写变体、未登录词 |
| 词形特征 | 是否含数字、是否全大写、是否含连字符 | 产品型号、专有名词 |
| 停用词结构 | 是否含否定词（不/没有/never） | 情感翻转 |
| 词性序列 | 名词短语的出现 | 话题倾向 |
| 词典/情感词 | 是否命中情感词典 | 直接的情感信号 |
| 位置特征 | 词出现在标题/首段 | 信息密度差异 |
| 句法/依存特征 | 主语-谓语关系 | 深层语义（计算昂贵） |

**重点：特征工程的目标不是「把全部信息都放进去」，而是「让分类器能靠有限特征做对决策」。** 因为每个特征都会引入稀疏性，无脑堆特征常常适得其反——这引出了下一个问题：怎么挑特征。

## 4 公式解析：卡方检验做特征选择

特征有几百万个时，得**特征选择**：挑出对分类最有判别力的特征，丢掉其余。最经典的标准之一是**卡方检验（$\chi^2$ test）**——度量「特征 $w$ 的出现」与「类别 $c$」是否**统计独立**；越不独立，$w$ 对 $c$ 越有判别力。

对词 $w$ 与类别 $c$，统计 $2\times2$ 列联表：

|  | 属于 $c$ | 不属于 $c$ |
| --- | --- | --- |
| 包含 $w$ | $A$ | $B$ |
| 不包含 $w$ | $C$ | $D$ |

卡方统计量：

$$
\chi^2(w, c) = \frac{N\,(AD - BC)^2}{(A+B)(C+D)(A+C)(B+D)}
$$

其中 $N = A+B+C+D$ 是文档总数。逐步理解：

- **第一步，$AD - BC$**：这是「独立假设下的偏差」——若 $w$ 与 $c$ 独立，则「包含 $w$ 且属于 $c$」的比例应等于「包含 $w$」的比例乘以「属于 $c$」的比例，即 $AD$ 与 $BC$ 应近似相等。偏差越大，越不独立。
- **第二步，平方放大**：$(AD-BC)^2$ 保证贡献恒为正，且偏差越大增长越快。
- **第三步，除以各边缘和**：把偏差**归一化**，消除样本量量纲影响——否则文档多时偏差必然大。
- **第四步，使用**：对每个类别分别算 $\chi^2(w,c)$，取每个词在所有类别上的**最大值**（或加权和）作为该词的判别分，按分排序取前 $k$ 个词。**卡方越大，越值得保留**。

**直觉**：卡方检验问的是「$w$ 出现与否，能否显著改变 $c$ 的分布」。能，就说明 $w$ 携带了类别信息。这个统计量与第二级《概率论与数理统计》里的独立性检验一脉相承，只是从「检验假设」变成了「排序特征」。<span class="marginnote">除卡方外，互信息（MI）也常用于特征选择：$\text{MI}(w,c) = P(w,c)\log\frac{P(w,c)}{P(w)P(c)}$。卡方对低频词的偏置比 MI 小，实践中常两者都试、看验证集。</span>

## 5 维度灾难与工程对策

特征选择之外，还有三招常用的**降维/稀疏化**手段：

- **词频阈值过滤**：把在文档里出现次数少于阈值（如 2 次）的词直接删掉——低频词多数是噪声或拼写错误。
- **文档频率截断**：删掉在超过 90% 文档里出现的词（太常见、无判别力）与在少于 2 篇里出现的词（太稀有、学不动）。
- **特征哈希（feature hashing）**：不建词表，直接把词哈希到固定维向量（如 $2^{20}$）的桶里，碰撞就叠加。<span class="marginnote">特征哈希省内存（不用维护词表）、支持在线流式更新，代价是哈希碰撞引入少量噪声。工业级管道常靠它处理亿级特征。想深入了解，第四级《机器学习》的工程化章节与第三级《数据库》的哈希索引都是相关背景。</span>

这三招配合卡方/MI 选择，能把几十万维压缩到几千维，同时保住分类精度——**统计时代的教训是：特征不是越多越好，是越「对」越好**。

## 6 辨析｜易错点：特征工程的四个坑

**辨析｜易错点：**

- **特征选择用「训练集」做，别用「全量」**：卡方、词频阈值都必须**只从训练集统计**，否则验证集/测试集的分布被偷窥，评测失真——这属于数据泄漏（见第十九篇）。<span class="marginnote">数据泄漏是特征工程的隐形杀手：特征选择、归一化参数、TF-IDF 的 IDF 统计都只能在训练数据上计算，再套用到测试数据。泄漏的后果是「训练指标漂亮、线上崩溃」。</span>
- **n-gram 不是越大越好**：二元三元够用，四元以上维度爆炸、稀疏到学不动，通常得不偿失。
- **TF-IDF 在生成式模型上未必最优**：朴素贝叶斯假设特征独立，用词频 + 平滑更符合其概率语义；TF-IDF 的权重视角更配判别式模型。别把 TF-IDF 当万能药。
- **停用词删除要谨慎**：情感分析里「不」「没有」这类词恰恰是强信号，删了会把「不怎么样」变成「怎么样」。停用词表要按任务定制，不能一刀切。

## 7 小结

- **文本分类**：$f: d \mapsto c$，把整篇文档归入预定义类别，是垃圾邮件、主题、情感、意图等任务的公共底座。
- 文档表示从**词袋**出发，可加 **n-gram** 恢复局部词序、用 **TF-IDF** 放大判别性词。
- **特征工程**是从词形、词性、词典、位置等多角度补信号；目标是让分类器「用对特征」而非「堆满特征」。
- **卡方检验** $χ^2(w,c)=\frac{N(AD-BC)^2}{(A+B)(C+D)(A+C)(B+D)}$ 度量「词—类别」独立性，用于特征选择。
- 工程对策：词频阈值、文档频率截断、特征哈希，配合卡方/MI 降到几千维。
- **数据泄漏**是头号陷阱：特征选择与 IDF 统计只能基于训练集。

在下一节，我们用一个具体的概率模型把「特征 → 类别」变成「概率 → 类别」——**朴素贝叶斯文本分类器**，统计分类里最简单也最常被低估的模型。
