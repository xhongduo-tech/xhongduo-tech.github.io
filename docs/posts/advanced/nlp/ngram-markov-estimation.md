## 为什么从 n-gram 开始

上一篇我们得到了一个精确但不可用的公式：链式法则要求估计 $P(w_i \mid w_1 \cdots w_{i-1})$，而词的历史越长，这个条件越难从有限语料中数出来。「猫坐在垫子」这个前缀可能只出现一次，「猫坐在垫子上的那一天」可能一次都不出现。**n-gram 模型的核心想法是：干脆把历史截短**——假设第 $i$ 个词只与它前面 $n-1$ 个词有关，更早的词一概不管。这个「截断历史的假设」叫作**马尔可夫假设**，它让语言模型第一次变得可以计算。<span class="marginnote">马尔可夫假设不是 NLP 的专利：它在《概率论与数理统计》与《随机过程》里的马尔可夫链中首次被严格表述——「未来的状态只依赖当前状态」。n-gram 语言模型就是马尔可夫链在文本上的应用：把「状态」换成「最近 n−1 个词」。</span>

n-gram 模型看似简单，却是整条统计 NLP 大河的源头：数据平滑、隐马尔可夫模型、乃至神经网络语言模型，全都在回答同一个问题——「怎么让截断历史的模型不崩、更准」。这一篇我们把 n-gram 的定义、参数估计和一次完整的手算过程讲透。

## 1 马尔可夫假设：截断历史

**马尔可夫假设（Markov assumption）**：一个词的出现概率只与它前面的有限个词有关，与更早的历史无关。写作：

$$
P(w_i \mid w_1 \cdots w_{i-1}) \approx P(w_i \mid w_{i-n+1} \cdots w_{i-1})
$$

右边只保留了最近 $n-1$ 个词作为条件。取不同的 $n$，就得到不同阶的模型：

- **一元模型（unigram，n=1）**：$P(w_i \mid \cdot) \approx P(w_i)$，词与词完全独立，只看每个词自身的频率。它把「猫坐在垫子上」与「垫子坐在猫上」当成了概率相同的句子——顺序信息全部丢失。
- **二元模型（bigram，n=2）**：$P(w_i \mid w_1 \cdots w_{i-1}) \approx P(w_i \mid w_{i-1})$，每个词只依赖前一个词。
- **三元模型（trigram，n=3）**：$P(w_i \mid \cdot) \approx P(w_i \mid w_{i-2}\, w_{i-1})$，每个词依赖前两个词。

下面的图把三种模型的依赖结构画在一起：一元模型没有任何箭头，二元模型每个词只被前一个词「喂」条件，三元模型每个词被前面两个词「喂」条件。

![n-gram 模型的条件依赖关系](/images/nlp/ngram-markov-estimation-1.svg)

**重点：n 越大，模型「看」得越远，理论上越精确；但可估计性越差。** 这是语言模型的永恒权衡，也是 n 的选择没有标准答案的原因——工程上常用的是二元与三元模型，四元以上在统计时代就稀疏得难以训练了。

## 2 n-gram 模型的定义

把马尔可夫假设代回链式法则，就得到 n-gram 模型对整句概率的公式。以二元模型为例：

$$
P(w_1 w_2 \cdots w_m) \approx \prod_{i=1}^{m} P(w_i \mid w_{i-1})
$$

三元模型则是：

$$
P(w_1 w_2 \cdots w_m) \approx \prod_{i=1}^{m} P(w_i \mid w_{i-2} w_{i-1})
$$

为了处理句首与句尾，工程上引入两个特殊符号：**句首标记 $P(w_1|\text{〈s〉})$** 与**句尾标记 $\text{〈/s〉}$**。<span class="marginnote">$\text{〈s〉}$ 让第一个词的「前一个词」有了着落——$P(w_1)$ 变成 $P(w_1|\text{〈s〉})$；$\text{〈/s〉}$ 让模型知道句子该在哪里收尾，否则模型会永远倾向于生成高频词而「刹不住车」。</span>于是二元模型实际写作：

$$
P(w_1 \cdots w_m) = P(w_1 \mid \text`{ <s> }`) \prod_{i=2}^{m} P(w_i \mid w_{i-1}) \cdot P(\text{</s>} \mid w_m)
$$

## 3 参数估计：极大似然估计

n-gram 模型的「参数」就是每个条件概率 $P(w_i \mid w_{i-1})$。怎么从语料中学出这些参数？标准答案是**极大似然估计（Maximum Likelihood Estimation, MLE）**：让训练语料的概率最大，得到的估计就是**相对频率**——用计数相除：

$$
P(w_i \mid w_{i-1}) = \frac{C(w_{i-1}\, w_i)}{C(w_{i-1})}
$$

其中 $C(\cdot)$ 表示某序列在语料中出现的次数。分子是「二元组 $w_{i-1} w_i$ 连续出现的次数」，分母是「前一个词 $w_{i-1}$ 出现的总次数」。

**辨析｜易错点：** 分母必须是 $C(w_{i-1})$，不是 $C(w_i)$，也不是语料总词数。我们问的是「**在前一个词是 $w_{i-1}$ 的前提下**，$w_i$ 接上去的概率有多大」——所以要先在所有 $w_{i-1}$ 出现的地方「对齐」，再看其中多少次后面跟着 $w_i$。把分母写错，是初学 n-gram 最常见的错误。

## 4 公式解析：二元模型的一个手算例子

我们用一个小语料把公式从头到尾算一遍。设语料包含三句（已切分并加了句首尾标记）：

> 〈s〉 猫 坐在 垫子 上 〈/s〉
> 〈s〉 猫 坐在 地板上 〈/s〉
> 〈s〉 小猫 玩 毛线球 〈/s〉

先数二元组计数（只列后面要用到的）：

- $C(\text{〈s〉 猫}) = 2$，$C(\text{猫 坐在}) = 2$，$C(\text{坐在 垫子}) = 1$，$C(\text{垫子 上}) = 1$，$C(\text{上 〈/s〉}) = 1$
- 单字计数：$C(\text{〈s〉}) = 3$，$C(\text{猫}) = 2$，$C(\text{坐在}) = 2$，$C(\text{垫子}) = 1$

现在估计句子「猫 坐在 垫子 上」的概率，逐步拆解公式 $P(w_i \mid w_{i-1}) = \frac{C(w_{i-1} w_i)}{C(w_{i-1})}$：

- **第一步，算第一个词**：$P(\text{猫} \mid \text{〈s〉}) = \frac{C(\text{〈s〉 猫})}{C(\text{〈s〉})} = \frac{2}{3}$。三句话里有两句以「猫」开头。
- **第二步，算每个接续**：$P(\text{坐在} \mid \text{猫}) = \frac{C(\text{猫 坐在})}{C(\text{猫})} = \frac{2}{2} = 1$——「猫」出现过 2 次，后面都跟着「坐在」；$P(\text{垫子} \mid \text{坐在}) = \frac{1}{2} = 0.5$——「坐在」出现过 2 次，一次接「垫子」、一次接「地板上」；$P(\text{上} \mid \text{垫子}) = \frac{1}{1} = 1$；$P(\text{〈/s〉} \mid \text{上}) = 1$。
- **第三步，连乘**：

$$
P(\text{猫 坐在 垫子 上}) = \frac{2}{3} \times 1 \times \frac{1}{2} \times 1 \times 1 = \frac{1}{3} \approx 0.333
$$

**直觉：** 这个概率高，是因为句子里的每个二元组（$\text{〈s〉 猫}$、$\text{猫 坐在}$、$\text{坐在 垫子}$…）都在语料里出现过。换一个语料里没见过的二元组，比如「狗 喜欢 猫」，其中 $C(\text{狗 喜欢}) = 0$，整句概率立刻归零——这正是下一节稀疏性问题的现场。

## 5 从模型生成句子

n-gram 模型不仅能打分，还能**生成**：从 $\text{〈s〉}$ 出发，每次按 $P(w_i \mid w_{i-1})$ 采样下一个词，直到碰到 $\text{〈/s〉}$ 为止。用上面的语料做贪心生成：

1. 从 $\text{〈s〉}$ 出发：$P(\text{猫}|\text{〈s〉}) = 2/3$ 最高，选「猫」。
2. 给定「猫」：$P(\text{坐在}|\text{猫}) = 1$，必选「坐在」。
3. 给定「坐在」：「垫子」与「地板上」各 0.5，随机挑一个。

这个生成过程可以用几十行 Python 复现：

```python
from collections import defaultdict

corpus = [
    "〈s〉 猫 坐在 垫子 上 〈/s〉",
    "〈s〉 猫 坐在 地板上 〈/s〉",
    "〈s〉 小猫 玩 毛线球 〈/s〉",
]

# 统计二元组计数
counts = defaultdict(int)
for sent in corpus:
    words = sent.split()
    for w1, w2 in zip(words, words[1:]):
        counts[(w1, w2)] += 1

def next_candidates(w):
    """给定前一个词，返回 (后续词, 条件概率) 的候选列表。"""
    total = sum(c for (w1, _), c in counts.items() if w1 == w)
    return [(w2, c / total) for (w1, w2), c in counts.items() if w1 == w]

def greedy_generate():
    w, sent = "〈s〉", []
    while w != "〈/s〉":
        cands = next_candidates(w)
        w = max(cands, key=lambda t: t[1])[0]   # 贪心：取概率最大的下一个词
        sent.append(w)
    return " ".join(sent[:-1])                   # 去掉句尾标记

print(greedy_generate())                         # 猫 坐在 垫子 上
```

「从模型中采样句子」的能力，让 n-gram 在语音识别、输入法、文本补全里都是可用的生成器——直到神经网络语言模型用同样的「预测下一个词」框架把它超越，那是第四篇第六节 NNLM 的内容。

## 6 稀疏性问题与平滑预告

回到公式解析里的那个「概率归零」的例子：只要某个二元组在语料中没出现过，整句概率就是 0。问题在于，**训练语料永远只是语言冰山的一角**——测试时遇到的二元组，很多在训练里从未见过。n 越大，未见事件越多。

**重点：n-gram 的阶数越高，模型表达力越强，但稀疏性越严重。** 一元模型几乎不稀疏但毫无顺序信息，三元模型能抓住「坐在/垫子」这样的局部搭配，可「垫子上」这个二元组一旦在训练语料中缺席，三元模型就束手无策。

解决零概率问题的技术统称**数据平滑（smoothing）**：从非零事件上「匀」一点概率给零事件，保证「所有合法序列概率都大于 0」。平滑是 n-gram 模型的另一半核心——**加法平滑、古德-图灵估计、插值法与 Kneser-Ney 平滑**，是接下来的两篇要展开的内容。

## 7 小结

- **马尔可夫假设**把词的历史截短为最近 $n-1$ 个词，换来可计算性；n 越大越精确但越稀疏。
- **n-gram 模型**把链式法则与马尔可夫假设结合：一元 $\prod P(w_i)$，二元 $\prod P(w_i|w_{i-1})$，三元 $\prod P(w_i|w_{i-2}w_{i-1})$。
- **句首尾标记** $\text{〈s〉}$、$\text{〈/s〉}$ 让第一个词的起点与句子的终点有了定义。
- **极大似然估计**给出 $P(w_i|w_{i-1}) = \frac{C(w_{i-1} w_i)}{C(w_{i-1})}$，即相对频率；分母必须是前词的计数。
- 未见二元组会让整句概率归零，**数据平滑**是下一站。
