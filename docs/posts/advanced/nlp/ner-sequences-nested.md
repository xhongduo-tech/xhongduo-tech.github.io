## 为什么从 NER 开始

信息抽取的第一步，是把「哪些词是实体、是什么类型」找出来——这就是**命名实体识别（Named Entity Recognition, NER）**。它是 IE 的地基：没有实体，关系、事件、共指都无从谈起。同时 NER 也是序列标注（第六篇）最典型的应用——你已经在 BiLSTM-CRF 里见过它的雏形。<span class="marginnote">NER 的经典定义源于 MUC 评测（上一篇）：识别文本中的专有名词并归入预定义类型——人名（PER）、地名（LOC）、机构（ORG）、地点实体（GPE）等。它是最早被「评测驱动」的 NLP 任务，也是工业落地最广的 IE 模块之一（搜索、推荐、风控都要用）。</span>

这一篇从「什么是 NER」讲到「怎么做 NER」：规则 → 统计 → 神经三代的演化，以及一个更难的形态——**嵌套实体识别**（「北京大学」里还套着「北京」）。

## 1 什么是 NER

**命名实体识别（NER）**：给定文本，识别出**命名实体**（专有名词及其所指）并标注**类型**。

「**李明**在北京大学读书」→ `PER`、`ORG`；
「昨天**苹果公司**发布了**iPhone 15**」→ `ORG`、`PRODUCT`；
类型体系：人名 PER、地名 LOC、机构 ORG、地点实体 GPE、时间 TIME、金额 MONEY……具体类型集随任务定义（MUC/ACE/CoNLL 各有约定）。

**NER 的难点**：实体边界不定（「北京大学」vs「北京 大学」）、类型歧义（「苹果」是水果还是公司）、嵌套（「[北京大学]的[北京]校区」）、简写与别名（「中科院」=「中国科学院」）、以及数量庞大的长尾实体。<span class="marginnote">对比词性标注（第三篇）：词性标注给每个词贴「语法类别」，NER 给「实体片段」贴「语义类型」——前者逐词、后者逐片段。NER 的标签单位是<strong>跨度（span）</strong>，这是它与逐词标注的本质区别。</span>

## 2 三代的 NER 方法

**规则/词典时代**：靠词典（人名表、地名表）与规则模板（大写模式、后缀「·有限公司」）。精确但覆盖窄——词典里没有的实体识别不了，是「词典爆炸」的典型困境。

**统计时代**：特征工程 + 序列标注模型——把「词形、大小写、前后词、词性、词典命中」等特征喂给 **MEMM/CRF**（第六篇）。效果大幅提升，但依赖人工特征，跨领域要重新调。

**神经时代**：**BiLSTM-CRF**（第六篇）与 **BERT 类预训练模型**——特征自动学、无需手工工程，F1 从统计时代的 ~90 提升到 ~92–95（CoNLL-2003 上），预训练模型把 NER 推进到接近人类水平。<span class="marginnote">NER 是「预训练红利」最明显的任务之一：BERT 类模型的上下文表征天然编码了「这是个人名/机构」的线索，微调一个 NER 头就能在极少标注数据上获得好效果——这也是为什么工业界新项目几乎直接用预训练模型做 NER 而非从零训练。</span>

## 3 公式解析：NER 作为序列标注

平面（非嵌套）NER 的标准建模就是第六篇的**序列标注**：给每个 token 打 BIO 标签。设 token 序列 $x_1,\dots,x_n$，标签 $y_t \in \{O, B-\text{PER}, I-\text{PER}, \dots\}$，用 BiLSTM-CRF 建模：

$$
P(Y \mid X) = \frac{1}{Z(X)} \exp\Big( \sum_{t=1}^{n} \sum_{k} \lambda_k f_k(y_{t-1}, y_t, X, t) \Big)
$$

逐步拆解：

- **第一步，标签体系**：`B`（实体首字）、`I`（实体内部）、`O`（非实体），类型拼在标签里（`B-PER`/`I-ORG`）。BIOES 方案再加 `E`（末字）与 `S`（单字实体）——第六篇第一节讲过两者的取舍。
- **第二步，发射分数**：BiLSTM（或 BERT）给每个 token 输出「对各标签的倾向」，作为 CRF 的发射特征——它同时编码了「这个词像不像人名、是不是实体首字」等线索。
- **第三步，转移分数**：CRF 的转移矩阵约束合法性——`I-ORG` 不能紧跟 `O`、`I-PER` 不能紧跟 `B-ORG`。这些约束是**学出来的**（第六篇 BiLSTM-CRF 的核心思想）。
- **第四步，解码**：维特比算法找全局最优标签序列，输出实体跨度。

**直觉**：NER = 「找片段 + 定类型」两步合一。发射管「这个位置像什么」，转移管「跨位置合不合法」，全局解码管「整条序列最优」。

## 4 嵌套实体：平面标注的极限

平面 BIO 标注有一个天花板：**它无法表达嵌套结构**。

「北京大学」里的「北京」——若「北京大学」标成 `B-ORG I-ORG`，那「北京」这个 `LOC` 就没地方标了。真实文本嵌套无处不在：

- 「[【清华大学】的[【清华】校区]」；
- 「[中国[首都]北京]」；
- 金融文本「[中国[建设银行]]」。

**平面序列标注只能给每个 token 一个标签，无法同时表达「既是组织的一部分、又是地点」**。这是 NER 从「平面」走向「嵌套」的转折点。<span class="marginnote">嵌套实体的比例不小：在 ACE 等真实语料里，约 10%–20% 的实体参与嵌套。忽略嵌套，等于系统性地漏掉「大实体里的小实体」——在机构名、地点名繁多的文本（新闻、法律、生物医学）里尤其致命。</span>

## 5 嵌套 NER 的建模方法

处理嵌套的主流路线有三条：

**分层序列标注（layer-based）**：把嵌套拆成**多层**——第一层标最外层、第二层标内层……每层一个序列标注模型（或共享编码器的多头）。简单直观，但层数上限是人工定的，深度嵌套会漏。
**基于跨度的分类（span-based）**：**枚举所有候选跨度**（所有连续片段），对每个跨度分类「是/否实体 + 类型」。跨度可以互相包含，天然支持嵌套。O($n^2$) 个候选，用「跨度边界嵌入 + 长度特征」筛选。这是当前嵌套 NER 的主流框架。<span class="marginnote">span-based 与第八篇「图解析先枚举所有弧」、SRL 的 span 模型（第十篇）是同一个思想：<strong>先枚举结构候选，再逐个分类</strong>。它的代价是候选多（$O(n^2)$），但换来的是对嵌套、交叠结构的完整表达能力。</span>
**序列到序列（Seq2Seq）**：把实体预测当成「按序输出实体串」的生成任务——输出每个实体的类型与起止下标（或直接生成实体词）。灵活、能处理各种复杂结构，但训练与推理更重。

**当前趋势**：预训练模型 + span 分类是精度最高的组合；seq2seq（如基于 T5 的生成式 NER）在「多类型 + 嵌套」的复杂语料上表现亮眼。

## 6 评测与数据集

**评测**：**span 级 F1**——预测实体与真实实体的「边界 + 类型」完全一致才算对。只看 token 级准确率会被大量 `O` 标签稀释（第六篇强调过）。
**经典数据集**：
**CoNLL-2003**（英语/德语，四类：PER/LOC/ORG/MISC）——NER 的事实基准；
**OntoNotes 5.0**（英语/中文/阿拉伯语，18 类，含嵌套标注）——更丰富、更难；
**ACE 2004/2005**（多语，实体/关系/事件全套标注）。
中文 NER 常用**人民日报语料**与 **CLUENER2020**。<span class="marginnote">中文 NER 有个特殊性：<strong>分词与实体边界纠缠</strong>——「北京大学生」可以切成「北京/大学生」或「北京大学/生」，分词错了实体就错。很多中文 NER 系统直接<strong>以字为输入单元</strong>（字符级 BPE 或字级 BiLSTM），绕开分词歧义——这是中文 NER 工程的一条重要经验。</span>

## 7 辨析｜易错点：四个常见坑

**辨析｜易错点：**

**实体是「跨度」，不是「词」**：多个 token 但 1 个跨度。评测按跨度严格匹配，边界差一个字（「北京大」vs「北京大学」）就算错。<span class="marginnote">这是 NER 与词性标注（逐词）的本质差异：NER 判的是「片段」，POS 判的是「词」。把 NER 当「逐词多分类」会系统性丢边界。</span>
- **嵌套 NER 不能用平面 BIO 直接标**：平面 BIO 一个 token 一个标签，表达不了「既是 ORG 的一部分、又是 LOC」。出现嵌套需求，直接上 span 或分层方案。
- **类型体系是任务定义的，不是通用的**：CoNLL 的 MISC、ACE 的 7 类、生物医学的「蛋白质/基因」——不同语料类型集不同。跨数据集比较 F1 前先对齐类型体系。
- **预训练模型不是 NER 的银弹**：领域差异大（法律 vs 医疗的实体完全不同），预训练模型仍需**领域语料微调**——直接拿通用 BERT 抽法律实体，效果会打折扣。

## 8 小结

- **NER**：识别实体片段 + 类型，是 IE 的地基与序列标注的旗舰应用。
- 三代方法：**规则词典 → 统计特征（CRF/MEMM）→ 神经（BiLSTM-CRF / 预训练微调）**。
- 标准建模：BIO/BIOES 序列标注 + 发射/转移分数 + 维特比解码。
- **嵌套实体**是平面标注的极限：多层标注、**span 分类**、Seq2Seq 三条路线。
- 评测：**span 级 F1**；数据：CoNLL-2003、OntoNotes、ACE、中文人民日报/CLUENER。
- 中文 NER 以字为输入单元可绕开分词歧义。

在下一节，我们解决 NER 之后的第二个问题：**实体识别与实体链接（Entity Linking）**——把文本里的实体指称，链接到知识库里的具体条目。
