## 为什么从评测方法开始

整个专题讲了二十多类任务，每一类都有「指标」——准确率、F1、BLEU、ROUGE……这一篇把评测本身系统化：**这些指标到底是什么、怎么算、怎么用、有哪些坑**。评测是 NLP 的「裁判」——**没有靠谱的评测，一切「效果提升」都不可信**。它是整个专题的收官基础，也是「从极限到大模型」判断模型好坏的最终标尺。<span class="marginnote">评测在 NLP 里的地位怎么强调都不过分：一篇论文的「贡献」全押在指标上，一个系统的「上线决策」全押在评测上。但评测本身充满陷阱——指标选错、数据集泄漏、显著性不检验——<strong>「被评测骗了」是 NLP 最常见的自我欺骗方式之一</strong>。读懂评测，才算真正读懂 NLP 研究。</span>

这一篇讲评测的基石：**准确率/召回率/F1** 怎么算、**宏平均 vs 微平均**、以及**显著性检验**为什么必不可少。

## 1 从混淆矩阵到准确率

评测的起点是**混淆矩阵（confusion matrix）**——对二分类，记录「真实 vs 预测」的四格：

|  | 预测正 | 预测负 |
| --- | --- | --- |
| **真实正** | TP（真正例） | FN（假负例） |
| **真实负** | FP（假正例） | TN（真负例） |

由它定义三个基本指标：

- **准确率（accuracy）**：$\text{acc} = \frac{TP + TN}{TP + TN + FP + FN}$——「判对的占比」；
- **精确率（precision）**：$\text{P} = \frac{TP}{TP + FP}$——「预测为正的里面，有多少真对」；
- **召回率（recall）**：$\text{R} = \frac{TP}{TP + FN}$——「真实为正的里面，有多少被找到」。

**重点：准确率会骗人——类别不平衡时尤其如此。** 垃圾邮件占 1%，一个「全判正常」的分类器准确率 99%，却毫无用处——**因为它召回率为 0**。这正是精确率/召回率存在的意义：它们分开看「预测的可信度」与「查找的覆盖率」。<span class="marginnote">「准确率陷阱」在 NLP 里到处是：NER 里 90% 的词是 O（非实体），「全判 O」准确率 90%+；情感分类里正面占 80%，「全判正面」准确率 80%——<strong>单看准确率，垃圾模型也能很好看</strong>。这就是为什么实体级 F1、宏平均这类「对不平衡敏感」的指标是 NLP 的标配。</span>

## 2 公式解析：F1 与它的平衡

**F1** 是精确率与召回率的**调和平均**：

$$
F_1 = \frac{2 \times P \times R}{P + R}
$$

逐步拆解：

- **第一步，$P, R$**：精确率与召回率——一个管「准」、一个管「全」；
- **第二步，调和平均 $\frac{2PR}{P+R}$**：对「一高一低」特别敏感——$P=1, R=0$ 时 $F_1=0$（不是算术平均的 0.5）。**调和平均要求「两个都要好」**；
- **第三步，为什么用调和不用算术**：算术平均会被高的一项「带偏」（$P=0.9, R=0.1$ 算术平均 0.5），调和平均只有 0.18——**F1 惩罚「偏科」**；
- **第四步，$F_\beta$ 推广**：$F_\beta = \frac{(1+\beta^2)PR}{\beta^2 P + R}$——$\beta>1$ 偏重召回、$\beta<1$ 偏重精确（F1 即 $\beta=1$）。

**直觉**：F1 = 「准」与「全」的**平衡分数**——「又要预测对、又要找得全」。它是 NLP 分类/序列标注任务的头号指标。

## 3 宏平均与微平均

多分类（或序列标注的多标签）时，「平均」的方式决定指标含义：

- **宏平均（macro-average）**：**每个类别单独算指标，再取算术平均**——`macro-F1 = (F1_类1 + F1_类2 + ...)/K`。**每个类别权重相等**——小类别与大类别同权，对「罕见类别」敏感。
- **微平均（micro-average）**：**把所有类别的 TP/FP/FN 加起来，再算一个总 F1**——`micro-F1 = F1(总TP, 总FP, 总FN)`。**按样本量加权**——大类别主导。

**什么时候用哪个**：

- 关心**每个类别都好**（尤其罕见类别）→ 宏平均；
- 关心**总体正确率**（大类别主导）→ 微平均；
- 类别不平衡时，两者差异巨大——**宏平均对「小类表现」更诚实**。<span class="marginnote">一个具体差异：多标签情感分类里，「正面」样本 10000、「讽刺」样本 100——宏平均让「讽刺」的 F1 与「正面」同权（讽刺差就把宏平均拉下来），微平均则被「正面」主导。<strong>「你想表扬谁、想惩罚谁」，决定了选宏还是微</strong>——评测指标是有立场的。</span>

## 4 显著性检验：别把噪声当进步

模型 A 的 F1 = 88.3，模型 B = 88.5——**这 0.2 是真的进步，还是随机波动？** 答案要靠**显著性检验（significance test）**。

**为什么需要**：测试集的样本是**抽样**的——换一批测试样本，分数会变。0.2 的差距可能在「抽样波动」范围内——**不检验，就无法区分「真进步」与「运气」**。

**常用检验**：

- **配对检验（paired test）**：两个模型在**同一批样本**上比较——逐个样本看「谁对谁错」，检验「A 与 B 的差异」是否显著。经典：**配对 t 检验**、**McNemar 检验**（分类）、**配对置换检验**（非参数，更稳健）；
- **自助法（bootstrap）**：对测试集**有放回重采样**（几千次），每次算两模型分数差，看「差的分布」——若 95% 的采样里 A > B，差异显著。

**显著性检验的结论**：给出 **p 值**——「差异是随机产生的概率」。p < 0.05（行业惯例）即「显著」。<span class="marginnote">显著性检验是 NLP 论文的「质检」：没有它，「提升 0.2」可能是「随机波动」。一个常见的<strong>误用</strong>是「用同一测试集反复调参，直到分数最高」——这会让显著性检验<strong>虚高</strong>（测试集被「用熟了」，泄漏了）。正规做法是「训练集调参 + 测试集只测一次」——<strong>测试集的「一次性」与显著性检验同等重要</strong>。</span>

## 5 数据泄漏：评测的头号陷阱

**数据泄漏（data leakage）**：测试集的信息「泄漏」进训练——评测分数**虚高**、上线**崩盘**。泄漏的常见来源：

- **特征统计用全量**：TF-IDF 的 IDF、特征选择的卡方统计，**用测试集一起算**——泄漏；
- **重复数据**：训练与测试里有**重复/相似样本**——模型「见过答案」；
- **同源泄漏**：同一实体/文本的不同变体跨集分布——近重复样本。
- **调参泄漏**：反复用测试集调参——「用熟了」。

**防泄漏的守则**：**特征统计只用训练集**；**训练/测试按「来源」划分**（不是随机划分）；**测试集「一次性使用」**。<span class="marginnote">数据泄漏是「最贵的错误」：它让模型在离线评测上满分、上线后崩盘。一个著名案例：某些 NER/QA 数据集的「近重复」样本让模型靠「背答案」刷分——<strong>「评测分数」与「真实能力」脱钩</strong>。判断一篇论文/一个系统是否可信，先查「数据划分是否干净」。</span>

## 6 多任务与多维评测

现代 NLP 评测的共识是**不只看一个数**：

- **分类任务**：准确率/F1 + 分标签的指标 + 置信度校准；
- **序列任务**：span 级 F1 + token 级指标（分开报）；
- **生成任务**：自动指标（BLEU/ROUGE）+ 人工评价（多维：忠实/流畅/相关）；
- **综合基准**：一套数据集 + 一个总榜（GLUE 的「平均分」——下一篇）。

**评测的演进趋势**：从「单一指标」走向「多维评测」——因为**单一指标总被「刷爆」**（刷 BLEU、刷 F1），多维评测让「取巧」无处遁形。<span class="marginnote">「指标被刷爆」是 NLP 评测的永恒轮回：BLEU 被「复读参考」刷、F1 被「贴标签」刷、准确率被「不平衡」刷——<strong>每个指标都有漏洞，于是评测不断升级</strong>（对抗样本、多维指标、人类校验）。理解「指标会被刷」，就理解了「为什么评测方法本身是研究课题」。</span>

## 7 辨析｜易错点：四个常见坑

**辨析｜易错点：**

- **准确率高 ≠ 模型好**：类别不平衡时准确率失真——报准确率之外必须报 F1/精确率/召回率。<span class="marginnote">记忆：不平衡任务（NER、情感、垃圾邮件）看 F1 和宏平均，别让「99% 准确率」骗了你。</span>
- **F1 不是算术平均**：调和平均惩罚「偏科」——$P=1, R=0$ 时 F1 是 0 不是 0.5。把 F1 当「准确率和召回率的平均」是常见错误。
- **宏平均 ≠ 微平均**：宏平均每类同权、微平均按量加权——类别不平衡时两者差异巨大，报指标必须注明「宏 or 微」。
- **不检验显著性 = 不能下结论**：「提升 0.2」没有显著性检验就是「可能随机」——对比实验必报显著性。

## 8 小结

- 评测基石：**混淆矩阵 → 准确率/精确率/召回率**——准确率在类别不平衡时骗人。
- **F1** = 精确率与召回率的调和平均 $F_1=\frac{2PR}{P+R}$——「又准又全」的平衡分。
- **宏平均**（每类同权）vs **微平均**（按量加权）——报指标注明宏/微。
- **显著性检验**：配对检验/自助法——区分「真进步」与「随机波动」。
- **数据泄漏**是头号陷阱：特征统计只用训练集、按来源划分、测试集一次性。
- 评测趋势：**从单一指标到多维评测**——对抗样本、人工校验、综合基准。
