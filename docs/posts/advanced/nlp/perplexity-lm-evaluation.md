## 为什么从困惑度开始

前两篇我们修好了 n-gram 模型的零概率问题，但还缺一块拼图：**怎么客观地判断一个语言模型好不好？** 不能靠「生成的句子读起来顺不顺」这种主观感受——那既不可复现，也没法在训练中当目标函数。我们需要一个单一数值，能在同一份测试语料上，公平地给不同模型排队。

这个数值就是**困惑度（perplexity, PP）**。它出身于信息论，是香农在 1951 年测量英语可预测性时留下的工具，如今统治着整个 NLP 的评价体系：n-gram 模型用它排队，循环神经网络语言模型用训练损失换算它，今天的大语言模型（LLM）在预训练日志里报告的那个 `loss`，取个指数就是困惑度。<span class="marginnote">香农 1951 年的论文《Prediction and Entropy of Printed English》让真人被试逐字母猜测文本，用猜测的难度估计英语的熵。困惑度/交叉熵这套「用概率度量可预测性」的框架，源头就在这里。</span>这一篇我们把困惑度的定义、它与交叉熵的关系、以及用它评价模型时最容易踩的坑讲透。

## 1 先给直觉：模型在「面对多少个选择」

设一个语言模型给测试句子 $W = w_1 w_2 \cdots w_N$ 分配了概率 $P(W)$。直觉上，模型给 $W$ 的概率越大，说明它越「不意外」。但「概率大」这个说法受句长影响——句子越长，连乘的概率必然越小。于是我们用**几何平均**来消掉句长的影响。

先看两个极端例子，把直觉建立起来：

- **公平硬币**：每猜一次面对 2 个等可能结果，不确定性是 1 bit。一个「完美」的硬币预测模型，其困惑度恰好是 $2$。
- **公平骰子**：每猜一次面对 6 个等可能结果，不确定性是 $\log_2 6 \approx 2.58$ bit，困惑度恰好是 $6$。

**重点：困惑度可以读作「模型每预测一个词，平均相当于在多少个等可能的候选词里做选择」——它是模型眼中的「有效词表大小」。** 一个理想模型预测每个词都胸有成竹，困惑度趋近 1；一个把每个词都当等概率的均匀模型，困惑度就是整个词表大小。这就是为什么「困惑度」这个名字如此贴切——数字越大，模型越困惑。

## 2 定义：几何平均概率的倒数

把上面的直觉写下来。测试集 $W = w_1 \cdots w_N$ 的困惑度定义为

$$
\text{PP}(W) = P(w_1 w_2 \cdots w_N)^{-\frac{1}{N}}
$$

逐项拆解：

- **$P(w_1 \cdots w_N)$**：模型给整句的概率，由链式法则展开为 $\prod_{i=1}^{N} P(w_i \mid w_1 \cdots w_{i-1})$。
- **指数 $-\frac{1}{N}$**：先取 $N$ 次根，把「每词平均概率」提出来；再取倒数，把「平均概率大」翻转成「困惑度小」。这一步同时消掉了句长的影响——两句长度不同的句子可以直接比较。

对 n-gram 模型，条件历史被截短。以二元模型为例：

$$
\text{PP}(W) = \Bigg[ \prod_{i=1}^{N} \frac{1}{P(w_i \mid w_{i-1})} \Bigg]^{\frac{1}{N}}
$$

**为什么用几何平均而不是算术平均？** 因为概率连乘是「乘法」结构，只有几何平均 $\big(\prod P_i\big)^{1/N}$ 才能与连乘自洽：整个句子的平均每词概率，就是几何平均。算术平均对乘法结构没有意义。

## 3 公式解析：困惑度、交叉熵与 $2^H$

困惑度与信息论里更基础的**交叉熵（cross-entropy）**只隔一个指数。交叉熵定义为

$$
H(W) = -\frac{1}{N} \sum_{i=1}^{N} \log_2 P(w_i \mid w_1 \cdots w_{i-1})
$$

逐步拆解两者关系：

- **第一步，对困惑度取 $\log_2$**：$\log_2 \text{PP}(W) = -\frac{1}{N} \sum_{i=1}^{N} \log_2 P(w_i \mid \cdot)$，右端正是 $H(W)$。
- **第二步，两边同时取指数**：得到漂亮的恒等式

$$
\text{PP}(W) = 2^{H(W)}
$$

- **第三步，理解交叉熵的名字**：交叉熵 $H(W)$ 是「模型分布的熵」与「真实分布到模型的 KL 散度」之和，它永远不小于真实语言过程的熵。真实熵是语言本身的下限，模型再努力也只能逼近它、不能低于它。<span class="marginnote">熵 $H(p)$、交叉熵 $H(p, q)$、KL 散度 $D(p \| q)$ 三者的关系 $H(p,q) = H(p) + D(p\|q)$ 是第二级《信息论》的核心恒等式。困惑度本质上是把交叉熵从「bit 单位」翻译回「等可能选择的个数」。</span>

**实用换算**：若用自然对数（$\ln$）算损失，则 $\text{PP} = e^{H_{\text{nat}}}$。今天的大模型训练日志里的 `loss` 通常就是 $H_{\text{nat}}$，所以 `perplexity = exp(loss)` 一按即得——同一个数，换了个底。**底数取 2 还是 $e$ 不改变模型排名，只要口径一致。**

## 4 公式解析：用二元模型手算困惑度

沿用前面两篇的小语料。设测试句「猫 坐在 垫子 上」，用已学好的二元概率做手算（假设这些概率恰好等于上一篇平滑前的相对频率，且句首句尾已处理）：

- $P(\text{猫} \mid \text{`<s>`}) = \frac{2}{3}$，$P(\text{坐在} \mid \text{猫}) = 1$，$P(\text{垫子} \mid \text{坐在}) = \frac{1}{2}$，$P(\text{上} \mid \text{垫子}) = 1$，$P(\text{`</s>`} \mid \text{上}) = 1$。

逐步拆解：

- **第一步，连乘得整句概率**：$P(W) = \frac{2}{3} \times 1 \times \frac{1}{2} \times 1 \times 1 = \frac{1}{3}$。
- **第二步，数词的个数**：句子有 4 个词加 1 个句尾标记，$N = 5$（口径约定：统计到 `</s>`）。
- **第三步，取几何平均再取倒数**：$\text{PP}(W) = \big(\frac{1}{3}\big)^{-1/5} = 3^{1/5} \approx 1.246$。

**直觉：** 困惑度 1.246 意味着模型预测每个词时，平均只相当于在约 1.25 个「候选」里选择——非常自信。这是因为测试句的每个二元组在训练语料里几乎都见过。换一句含未见二元组的测试句，比如「狗 喜欢 鱼」，「狗 喜欢」在语料里计数为 0（未平滑），整句概率直接归零，$\text{PP} = 0^{-1/5} = \infty$——**这正是平滑的意义所在：没有平滑，困惑度根本无法计算。** 用代码计算：

```python
import math

def perplexity(probs):
    """probs: 测试句中每个词的条件概率列表"""
    log_p = sum(math.log(p) for p in probs)
    n = len(probs)
    return math.exp(-log_p / n)

print(perplexity([2/3, 1, 1/2, 1, 1]))  # 约 1.246
```

## 5 典型数值：NLP 界的「身高体重表」

困惑度不是绝对标尺，但经典测量能给你量级感。Jurafsky 与 Martin 在**华尔街日报（WSJ）3800 万词级语料**上训练一元、二元、三元模型，再在 150 万字的保留测试集上测困惑度，得到教科书级的经典数字：

| 模型 | 困惑度（WSJ 测试集） |
| --- | --- |
| 一元模型（unigram） | 962 |
| 二元模型（bigram） | 170 |
| 三元模型（trigram） | 109 |

**读出两个信息。** 其一，一元模型困惑度 962，意味着它几乎像是在一个约千词的均匀词表里瞎猜——词序信息一点没用上；二元把数字砍到 170，三元进一步压到 109，每一阶都在实打实地「少困惑一点」。其二，**高阶模型并非无限接近 1**——109 说明即使三元模型，平均每次预测仍相当于在 109 个候选里选。英语的冗余度远比我们想象的高，而 n-gram 只吃到了其中一小部分。

**重点：困惑度只能在「同测试集、同词表、同分词口径」下比较。** 换个领域（法律文书 vs 聊天）、换分词方式（按词 vs 按子词 BPE），数字就会大变。所以拿 962 去跟一个 BPE 分词模型的 20 比较，是毫无意义的——它们根本不在同一把尺子上。<span class="marginnote">子词（BPE）把词切成更小的单位，token 总数变多、每个 token 的平均概率变大，困惑度自然大幅下降。现代 LLM 报告的都是 token 级困惑度，跨模型比大小前必须先确认分词器一致。</span>

## 6 辨析：评价语言模型的四个坑

**辨析｜易错点一：困惑度不是任务准确率。** 困惑度衡量「模型给真实文本的概率有多高」，是一个**内在（intrinsic）**指标；机器翻译的 BLEU、对话的回复质量都是**外在（extrinsic）**指标。困惑度低不代表下游任务好——一个「把高频词概率都调高」的保守模型，困惑度可以很低，但生成的句子单调乏味。两者要分开用：训练时看困惑度，定夺时看任务。

**辨析｜易错点二：测试集难度不同，数字不可比。** 同一个模型在「他 去 了 超市」和「量子纠缠 的 贝尔不等式 验证」两段测试集上的困惑度天差地别。比较模型必须用**同一份**测试集，最好多次采样、报均值与方差。

**辨析｜易错点三：词表与分词口径必须一致。** 模型 A 的词表含「`<UNK>`」把低频词全部吞并，模型 B 不含未知词——A 的困惑度会被人为拉低。比较前要约定：是否含未知词、按词还是按子词、句尾标记是否计数。**口径不一，数字全废。**

**辨析｜易错点四：困惑度有理论下限，别追求归零。** 由交叉熵不等式，$\text{PP}(W) = 2^{H(W)} \ge 2^{H_{\text{true}}}$，真实语言的熵是下限。硬把所有词压成确定预测（困惑度趋近 1），模型就把「语言本身的多样性」也抹掉了——那是对训练集的死记硬背，不是理解。困惑度降到接近下限后，收益就进入平台期。

## 7 小结

- **困惑度** $= P(W)^{-1/N}$，读作「模型每词平均面对的等可能候选数」，越小越好。
- **交叉熵** $H(W) = -\frac{1}{N}\sum \log_2 P(w_i\mid\cdot)$，与困惑度满足 $\text{PP}(W) = 2^{H(W)}$；自然对数下即 $\text{PP} = e^{\text{loss}}$。
- **典型数值**：WSJ 上 一元 962 / 二元 170 / 三元 109，每一阶 n-gram 都在显著「减困」。
- 困惑度是**内在指标**，只能在**同测试集、同词表、同分词口径**下比较；它有熵给出的理论下限，不是越低越好。
- 从 n-gram 到大模型，困惑度/损失是同一条评价线：预训练日志里的 loss 取指数，就是今天的困惑度。
