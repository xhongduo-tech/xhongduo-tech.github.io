## 为什么从句法分析开始

前八篇里，我们一直把句子当**词的序列**：分词、标注、分类、情感——没有谁真正问过「**句子是怎么组织起来的**」。乔姆斯基那句著名的「无色的绿色思想在愤怒地沉睡」点破了要害：这句话语法完全正确，却毫无意义——**语法（句法）与语义是两套独立的系统**，句法分析研究的就是「句子按什么规则组织」。<span class="marginnote">句法（syntax）研究词如何组合成更大的单位、单位之间如何嵌套；它与语义、语用共同构成语言学的三大层级。第七级《语言学》专题会对语言学本身展开，这里聚焦计算机怎么分析句法。</span>

句法分析（syntactic parsing）让机器**看到句子的结构**——词与词之间的层级关系或支配关系。它是机器翻译（第十篇）、信息抽取（第十一篇）、问答（第十三篇）等许多任务的中间层。这一篇先把两大句法理论体系讲清楚：**短语结构语法**与**依存语法**。

## 1 两个基本问题

任何句法理论都要回答两个问题：

1. **句子由什么组成？** —— 是「一层套一层的成分（短语）」，还是「一个中心词带一群修饰」？
2. **结构怎么表示？** —— 用嵌套的树，还是用点与箭头？

两大体系分别给出不同答案：

- **短语结构语法（phrase structure grammar，又称成分语法、constituency grammar）**：句子 = 若干短语层层嵌套。名词短语（NP）里可以再套形容词短语、介词短语……像套娃。
- **依存语法（dependency grammar）**：句子 = 一个**中心词（head）** 统领全局，其他词都**依存**于某个词，词与词之间是「支配-被支配」的箭头关系，没有短语这层中间物。<span class="marginnote">两种语法各有拥趸：短语结构在英语学界与形式语言理论里是正统（乔姆斯基传统），依存语法在中文、捷克等语料库与机器翻译界更流行——因为依存关系更贴近「谁修饰谁」的语义直觉，也更容易跨语言对齐。</span>

## 2 短语结构语法：成分与嵌套

**短语结构（constituent structure）**把句子递归地拆成**成分（constituent）**——句子里可以独立移动、被替换的连续片段。看「我 爱 北京 天安门」：

```
        S（句子）
      / |      \
    NP  VP
    |    |    \
   我    V    NP
          |    |     \
         爱    NN    NN
               北京  天安门
```

- **S（sentence）**：整句，由 NP + VP 组成；
- **NP（名词短语）**：「我」是一个 NP；「北京 天安门」也是一个 NP；
- **VP（动词短语）**：「爱 北京 天安门」是 VP，由 V + NP 组成；
- **NN（名词）**：叶子上的词性标签。

**成分的关键性质**：「北京天安门」作为 NP，可以整体被替换（「我爱上海」），这说明它是一个**单位**——短语结构树就是「哪些词抱团成单位、单位如何嵌套」的完整账本。<span class="marginnote">这种嵌套结构可以用<strong>上下文无关文法（CFG）</strong>精确生成：每条规则形如「NP → 代词 | 名词 名词 | ……」。CFG 是形式语言理论（第三级《程序设计语言》的 BNF 与它同源）与计算语言学的交汇点——下一篇《CFG 与 PCFG》会展开它的形式化。</span>

## 3 依存语法：中心词与修饰语

**依存语法（dependency grammar）**不设短语层，直接给每对词建立**依存关系（dependency relation）**：一个词是**中心词（head）**，另一个是**依存词（dependent）**，从中心词到依存词画一条带标签的箭头。同一个句子：

```
        爱（root）
      /   |   \
   我     北京 天安门
  nsubj   dobj  dobj?→ 实际: 天安门→北京
```

规范画法：**中心词是「爱」，它统治三个依存词**——「我」是主语（nsubj）、「北京 天安门」是宾语。更精细的处理里，「天安门」作为名词修饰语（复合名词的第二个成分）依存于「北京」。标签体系（如 universal dependencies）规定了每种关系的语义：`nsubj` 主语、`dobj`/`obj` 宾语、`amod` 形容词修饰、`advmod` 副词修饰……<span class="marginnote">依存树与短语结构树的一个关键差异：<strong>依存树是「投影性」的</strong>——连接线通常不交叉（除非出现非投影结构）。「今天 我 把 书 看 完 了」的依存关系跨越了「把」「书」两个词，仍不交叉，这是汉语里投影性通常成立的原因。</span>

**两种表示的关系**：从短语结构树可以推导出依存树——每个短语的中心词是「决定短语类型」的那个词（NP 的中心是名词，VP 的中心是动词）。反过来，依存树缺少短语层信息。**两者是同一句子的两种视角，不是互相矛盾**。

## 4 两种表示对照

| 维度 | 短语结构（成分）语法 | 依存语法 |
| --- | --- | --- |
| 结构单位 | 短语（NP/VP/PP……） | 词与词之间的支配关系 |
| 表示 | 嵌套树（有非叶子节点） | 箭头图（只有词节点） |
| 关系 | 包含/被包含 | 中心词—依存词 |
| 根 | S（句子节点） | 唯一的根词（root） |
| 与语义 | 距离远（结构是「形式」） | 更近（依存关系≈谓词论元） |
| 经典语料 | Penn Treebank（成分树） | Universal Dependencies（依存树） |
| 主流解析算法 | CYK / 转移（下一篇） | 转移 / 图（后两篇） |

**重点：选择哪种表示，等于选择「把句子的什么信息结构化成树」**。机器翻译和语义任务更爱依存（关系直接对应「谁做了什么」），英语的经典语料偏爱成分树，但近十年依存语法（尤其是 Universal Dependencies 项目）正成为跨语言研究的事实标准。

## 5 句法歧义：句法分析的核心困难

句法分析为什么难？因为**同一个词串可以有多棵合法的树**——这就是**句法歧义（syntactic ambiguity）**。乔姆斯基的经典例子：

- 「他 看见 那个 男人 带 着 望远镜」——「带着望远镜」是修饰「男人」（那个带望远镜的男人），还是修饰「看见」（他透过望远镜看见）？<span class="marginnote">这就是著名的「PP 附着歧义」（prepositional phrase attachment）：介词短语既可以挂到动词短语上（VP-attachment），也可以挂到名词短语上（NP-attachment）。英语的 garden path 句（如「The horse raced past the barn fell」）靠句法歧义把读者带进沟里。</span>

统计句法分析的核心任务，就是在**多棵候选树里挑「最可能」的一棵**——下一篇的 PCFG 给每棵树一个概率，第四、五篇的依存解析器给每个弧一个分数，本质都是「给候选结构打分排序」。

## 6 句法分析的下游价值

- **语义与关系抽取**：依存关系直接告诉你「谁对谁做了什么」——第十一篇关系抽取的骨架；
- **机器翻译**：句法结构帮助处理长距离调序（第十篇）；
- **问答与信息检索**：问题里的疑问结构（谁/什么/何时）依赖句法识别；
- **语音合成**：短语边界决定停顿位置（第四级《语音技术》）。

当然，预训练大模型兴起后，很多端到端模型不再显式解析句法——**但这不等于句法不重要**：显式句法依然是可控生成、结构推理、低资源任务里的宝贵归纳偏置。

## 7 辨析｜易错点：三个常见误会

**辨析｜易错点：**

- **成分树 vs 依存树不是「谁对谁错」**：它们是同一句子结构的两套表示，各有适用的语料与算法。别在「哪种语法更正确」上纠结，要看「哪个任务用哪个顺手」。<span class="marginnote">一个实用判断：要「短语边界」信息（如组块、分块）用成分树；要「词间关系」（谁修饰谁、谁是谁的宾语）用依存树。</span>
- **依存关系的标签 ≠ 词性**：`nsubj`（主语）是关系标签，`NN`（名词）是词性标签——一个描述「词与词的关系」，一个描述「词的类别」。混淆两者是初学句法最典型的错误。
- **歧义不等于病句**：「他看见那个男人带着望远镜」两个意思都合法。句法歧义是语言的常态，解析器的工作是在歧义中选最可能的解释，而不是消掉歧义。

## 8 小结

- 句法分析给句子建**结构树**，两大体系：**短语结构（成分）**与**依存**。
- 短语结构语法：句子 = 短语层层嵌套（NP/VP/PP……），树有非叶子节点，可用 **CFG** 生成。
- 依存语法：句子 = 一个根词 + 词间「中心—依存」箭头，关系带标签（`nsubj`/`obj`……）。
- 两套表示可互相转换，选择取决于下游任务；依存关系更贴近语义直觉。
- **句法歧义**是核心困难：同一词串多棵合法树，解析 = 挑最可能的树。
- 句法价值：关系抽取、机器翻译、问答、语音合成的中间结构。
