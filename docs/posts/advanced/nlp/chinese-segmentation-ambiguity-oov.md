## 为什么从中文分词开始

翻开任何一篇英文文章，词与词之间天然隔着空格；而翻开中文文本，句子是一个字符接着一个字符、没有任何边界的连续串。要让计算机判断「研究生命科学」到底在讲「研究 + 生命 + 科学」还是「研究生 + 命 + 科学」，第一步就是把连续的字符串切成一个个有意义的语言单位——这就是**中文自动分词（Chinese word segmentation）**：把不含词边界的中文字符串切分为词序列的任务。它是中文信息处理的第一道关口：后面所有任务——词性标注、句法分析、命名实体识别、机器翻译、乃至大模型的分词器——都以「切对了词」为前提。<span class="marginnote">「从极限到大模型」的主线在这里第一次遇到「文本是连续串」的现实：中文不像数学公式那样有天然的 token 边界。分词本质上是在做「把连续信号离散化」的工作，与大模型训练前的 tokenization 一脉相承——只不过大模型的 token 切分可以依靠统计自动学出来。</span>

在上一篇我们见过 Zipf 定律与稀疏性（《语料统计基础：词频、齐普夫定律与稀疏性问题》），也见过歧义如何渗透到语言的每个层面（《自然语言的歧义性与 NLP 的基本困难》）。分词问题正是这两个主题的交汇点：分词方案决定了「词」这个统计单元的切分方式，而歧义切分则具体演示了歧义在真实文本里长什么样。这一篇，我们把分词的困难拆成两个问题来理解：**歧义切分**与**未登录词**。

## 1 词是什么：分词规范问题

分词的第一个难题，不是算法，而是「标准」本身。**词（word）**：语言中最小的、能够独立运用的音义结合单位。<span class="marginnote">「独立运用」的意思是可以单独成句或独立充当句法成分。「水」可以单独说「水！」；而「子」「头」这类语素一般不能独立运用，于是不单独成词。这是语言学的标准定义，落到具体文本却充满灰色地带。</span>这个定义在理论上清楚，落到具体文本却处处为难：

「吃饭」是「吃 + 饭」两个词，还是一个词？
「科学家」「桌子」这类带词缀的，切不切开？
「南京市」「长江大桥」这类地名中的行政与地理名词，合不合？

汉语没有英语那样的形态标记（英语有空格、有词尾变化），再加上「字」「语素」「词」三个层次之间没有明确边界，导致**同一个句子可以有不同的合理切分**。汉语分词规范（国家标准 GB/T 13715《信息处理用现代汉语分词规范》）给出了一套切分建议，但规范与日常语感仍常有冲突，比如「为人民服务」中的「为人民」通常规范上整体保留，而口语语感里「为 / 人民 / 服务」也说得通。<span class="marginnote">分词规范的争议恰好解释了为什么中文分词系统的评测一直用「某个人工标注语料」作为黄金标准——因为「正确」本身是相对的。不同语料库的切分标准不同，是跨系统比较 F1 时必须小心的陷阱，也是我们后面第十九篇《NLP 评测》反复强调「评测要跟着语料走」的原因。</span>

分词方案的选择还会向下游传导：切分粒度越粗（如「长江大桥」整体成词），句法分析要处理的成分越少，但词典与训练语料的规模需求越大；切分粒度越细（如「长江 / 大桥」），统计单元越稳定、对未登录词的暴露越少。**粒度选择是工程权衡，不是学术对错**——这也是为什么不同分词器、不同语料库会给出不同的「正确」切分。

## 2 歧义切分：三种类型

**歧义切分（segmentation ambiguity）**：一个字符串存在两种及以上都合法的切分方式。汉语分词中的歧义切分主要分三类。

### 交集型歧义

**交集型歧义（intersection ambiguity）**：字符串 $ABC$ 中，$AB$ 与 $BC$ 都是词典词，切分可在 $A \mid BC$ 与 $AB \mid C$ 之间摇摆。

例：「结合成」→「结合 / 成」或「结 / 合成」；「研究生命」→「研究 / 生命」或「研究生 / 命」。这类歧义由「两个词交叉重叠一个汉字」造成，是数量最多的一类。<span class="marginnote">交集型歧义有一个形式化的刻画：把句子从左到右的每个字符间隙当作节点，凡「两个位置之间是词」就连一条边，那么一个节点存在多条入边时往往就藏着交集歧义——这正是下一篇「最短路径分词」把分词建构成图的原因。图一画出来，交集型歧义立刻变得可计算。</span>

### 组合型歧义

**组合型歧义（combination ambiguity）**：$AB$ 是词，而 $A$、$B$ 也各自成词，切分可在 $A \mid B$ 与 $AB$ 之间摇摆。

例：「现在」→「现 / 在」或「现在」；「将来」→「将 / 来」或「将来」；「学会」→「学 / 会」或「学会」。组合型歧义的特点是：两个方向的切分在词典里都合法，只能靠上下文（前一个词、后一个词）来定夺。

### 真歧义

**真歧义（true ambiguity）**：即使结合上下文，也无法唯一确定语义的歧义。这类歧义占比很小，但对系统是硬伤——因为任何模型都只能靠猜测。

例：「乒乓球拍卖完了」既可以读作「乒乓球 / 拍卖 / 完了」（球拍被拍卖掉），也可以读作「乒乓球 / 拍 / 卖完了」（乒乓球拍售罄）。两句语法上都成立、语义上都有道理，真歧义只能靠世界知识来猜。<span class="marginnote">真歧义是语言歧义性的终极体现，也说明分词并不存在「完美正确答案」——评测上只能要求系统与人工标注尽量一致。这正是我们在《自然语言的歧义性》里讲的「歧义分层」在分词层面的具体化。</span>

**重点：绝大多数歧义切分可以通过上下文消解，被称为「伪歧义」（pseudo ambiguity）；只有极少数是「真歧义」。** 统计分词方法的全部功力，就在于用上下文信息去消解伪歧义——知道前文在讲「拍卖会」，自然就倾向「乒乓球 / 拍卖 / 完了」。

## 3 未登录词：真正的拦路虎

**未登录词（out-of-vocabulary word, OOV）**：分词词典中没有收录、却真实出现在文本中的词。它也叫「词典外词」。

未登录词主要包括：

**命名实体**：人名（姚明、特朗普）、地名（乌鲁木齐、塞尔维亚）、机构名（清华大学、联合国）、商标名；
**数字与时间**：年份、日期、百分比、「3·15」；
**外来词与新词**：「给力」「萌」「元宇宙」「区块链」；
**专业术语**：化学式、药品名、生物学术语。

未登录词之所以是「拦路虎」，是因为它与分词错误高度绑定：**很多被误切的「错误词」，其实并不是切错，而是这个词根本没进词典。** 实验数据普遍显示，分词错误中有相当大比例与未登录词直接相关，且未登录词对系统性能的影响往往超过歧义切分——歧义靠规则还能救，未登录词则直接让候选词集「缺了一角」，后续统计特征全部失真。

### 未登录词为什么还能被识别

未登录词「不在词典里」，但识别它们并非无米之炊——它们有强烈的**内部结构线索**：

中文人名以姓氏开头（「王」「李」「欧阳」），名字由常用字组成且长度集中在 2–3 字；统计「姓 + 名」的联合分布，可以给出一个「像不像人名」的分数。
地名以「省、市、县、区、乡、路、桥」等通名结尾，前面常常是一个 1–3 字的专名。
机构名带「公司、大学、研究所、集团」等后缀，还可能夹着「·」「—」等符号。
新词、外来词往往出现在特定语境（互联网、社交媒体），语料中反复共现、成串出现。

**重点：未登录词识别本质上是在「字符序列的模式」上做判断，而不是查表。** 这套「用内部构成模式 + 外部上下文识别词典外命名实体」的思路，正是第十一篇《命名实体识别（NER）》的主角；分词阶段的未登录词处理，可以看作 NER 的一个简化预热。<span class="marginnote">把人名、地名、机构名等命名实体与普通词分开处理，是中文分词的通行做法：先切分，再用专门的实体识别器在切分结果上套一遍。到信息抽取专题我们会看到，这套「分词 + NER」两级结构至今仍是工业界中文流水线的标配。</span>

**辨析｜易错点：** 不要以为「歧义切分」与「未登录词」是两条独立的难题。二者常常纠缠：一个字段被误切，系统可能认为是歧义处理不当，实则是某一部分是未登录词导致候选词集不完整。评估一个分词器时，要分开统计「词典内歧义消解能力」与「未登录词召回能力」，否则无法定位瓶颈。这也是为什么宗成庆《自然语言处理》把「歧义切分」与「未登录词问题」并列放进 7.1 节的同一小节——它们是同一个难点的两个侧面。

## 4 一个分词器的总体构成

无论用什么方法，主流分词器都可以抽象成三件事：**生成候选、消解歧义、处理未登录词**。

- **候选词生成（candidate generation）**：基于词典或字组合，把句子里所有可能成词的片段找出来。词典法直接查词表；统计法里的由字构词则把「切分」翻译成「给每个字打标签」。这一步决定了系统「看得见」哪些切分——候选集里没有的切分，后面再怎么消歧也选不出来。
- **歧义消解（disambiguation）**：在候选切分之间做选择。词典法用「最长优先」「词数最少」这类启发式；统计法用语言模型或序列标注模型打分，让「概率最高」的切分胜出。伪歧义主要在这里被消灭。
- **未登录词处理（OOV handling）**：词典外的命名实体、新词，要么靠独立的人名/地名/机构名识别器补漏，要么靠字级别的统计信息直接切分。未登录词问题单独列一个环节，因为它需要的特征（姓名字库、地名后缀、机构简称模式）与普通消歧完全不同。

三部分环环相扣：候选生成管「广」，歧义消解管「准」，未登录词处理管「全」。**一篇合格的评测报告，会把 $F_1$ 拆成「词典内」与「词典外」两组分数**，因为三个环节的短板会在不同的分数上暴露：词典外 $F_1$ 低，说明未登录词环节弱；词典内 $F_1$ 低，说明消歧环节弱。这个「拆分诊断」的思路，与我们在《NLP 任务的分类体系》里强调的「先定位错误类型再改进系统」是同一条方法论。

## 5 公式解析：用 F1 值评价分词器

分词系统的性能评价与文本分类共享同一套度量。设系统对测试文本切分得到词集合 $S_{\text{sys}}$，标准答案（人工标注）得到 $S_{\text{gold}}$。**重点：分词评价把「词」当作被检索的对象，精确率、召回率定义如下：**

$$
P = \frac{|S_{\text{sys}} \cap S_{\text{gold}}|}{|S_{\text{sys}}|}, \qquad
R = \frac{|S_{\text{sys}} \cap S_{\text{gold}}|}{|S_{\text{gold}}|}, \qquad
F_1 = \frac{2PR}{P + R}
$$

- **第一步，读懂 $P$（精确率，Precision）**：分子「系统切出的词里，有多少同时也是标准词」；分母是系统切出的总词数。$P$ 回答「系统切出来的词靠不靠谱」——它惩罚的是「多切」出来的错词。
- **第二步，读懂 $R$（召回率，Recall）**：分母换成标准词总数。$R$ 回答「标准里的词，系统切出了多少」——它惩罚的是「漏切」。
- **第三步，调和平均 $F_1$**：直接取平均会让高分者带节奏，调和平均则要求 $P$ 与 $R$ 都不能太低。$F_1$ 是分词（以及命名实体识别、信息抽取）最常报告的综合指标。<span class="marginnote">精确率与召回率的定义来自信息检索；在《概率论与数理统计》的假设检验视角下，它们分别对应「判定为正例中真实正例的比例」与「真实正例中被判出的比例」。这套度量在本专题第十九篇《NLP 评测》中还会系统展开。</span>

一个系统若只做最大匹配、遇到生词就切开，则 $P$ 高而 $R$ 低；若把长串一律合并，则 $R$ 高而 $P$ 低。好的分词器必须同时照顾两头——这也是为什么由字构词的统计方法能在 $F_1$ 上碾压朴素词典法（后面两篇会讲）。顺带一提，若把「词」换成「字符」，同样的公式就变成字符级评测；行业里还会报告「词级 F1」与「字符级 F1」两个视角，因为不同任务对粒度的敏感度不同。

## 6 小结

- 中文分词把无空格的连续字符串切成词序列，是中文 NLP 的第一道关口，也预示着大模型 tokenization 的雏形。
- 分词规范存在灰色地带，不同语料库切分标准不同，评测以人工标注为黄金标准，粒度选择是工程权衡。
- **歧义切分**三类：交集型（$AB$ 与 $BC$ 交叉）、组合型（$AB$ 与 $A \mid B$ 并存）、真歧义（上下文也消解不了）；绝大多数歧义是可用上下文消解的「伪歧义」。
- **未登录词**是分词错误的主要来源，包括命名实体、数字、新词等；评估时要与歧义消解能力分开统计。
- 分词系统用 $P$、$R$、$F_1$ 评测：$F_1$ 是精确率与召回率的调和平均，要求两头兼顾。
- 与后续联系：分词把「词」这个统计单元定下来，直接决定第四篇 n-gram、第五篇词向量的统计质量——「切错了词，下游全是噪声」。
