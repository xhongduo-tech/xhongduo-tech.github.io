## 为什么从 RST 开始

第一篇立了「篇章 = 单位 + 关系图」的框架，这一篇介绍把「关系图」做成**严格层次结构**的经典理论——**修辞结构理论（Rhetorical Structure Theory, RST）**（Mann & Thompson, 1988）。RST 认为，**一篇连贯的文本可以被组织成一棵树**——子句与子句之间按**修辞关系**（因果、对比、例证……）逐层结合，最终汇聚成整篇。<span class="marginnote">RST 的名字里有「修辞」——它研究的是「作者怎么用语言组织论证」，而不是「句子语法」。它给篇章分析的贡献是：<strong>一套统一的树状表示 + 一套有限的关系集</strong>——让「篇章结构」第一次可以<strong>标注、计算、评测</strong>。它是篇章分析里最有影响的正式理论，也是计算篇章分析的奠基之作。</span>

这一篇讲 RST 的核心概念——**核心/卫星**与**修辞关系**——以及篇章树的解析与应用。

## 1 RST 的核心思想

RST 的三个支柱：

1. **递归组织**：篇章由**篇章单位（EDU，基本篇章单元 ≈ 子句）**逐层组合——小的「单位对」合并成更大的单位，再与别的单位合并，直到整篇成为一个根节点；
2. **关系连接**：每个「单位对」之间有一条**修辞关系**——说明「为什么这两个单位要放在一起」；
3. **核心/卫星不对称**：关系的两端**不等价**——一个**核心（nucleus）**承载主要信息，另一个**卫星（satellite）**起辅助作用。

**RST 树的样子**（示意）：

```
                    RST 树根（整篇）
                  /            \
          Elaboration          Conclusion
           /      \                |
    [EDU1 论点]  [EDU2 解释]   [EDU3 结论]
```

「作者先提论点（核心），再解释（卫星），最后下结论（核心）」——整篇被组织成层次分明的树。<span class="marginnote">RST 的「树」假设是一个强主张：<strong>任何连贯文本都能（且应该能）被组织成一棵递归树</strong>。它对「组织良好的论证文」很合适，但对「松散的口语、并列堆砌」的文本，树形假设有时生硬——这是 RST 被批评的点之一（后续的 PDTB 就用「扁平的论元对」绕开了树形约束，第三篇会讲）。</span>

## 2 核心与卫星：不对称的关系

RST 关系的两端**不对称**——这是 RST 最鲜明的特征：

- **核心（nucleus）**：篇章的主要信息——「这段话在说什么」；
- **卫星（satellite）**：辅助核心的信息——解释、例证、背景、让步。

**经典关系**（约 25 种，分三类）：

- **卫星围绕核心**：`Elaboration`（详细说明）、`Evidence`（给出证据）、`Cause`（原因）、`Concession`（让步）、`Background`（背景）、`Example`（举例）；
- **多核心并列**：`Contrast`（对比）、`Sequence`（时序）、`List`（列举）——两端都是核心，无主次；
- **呈现类**：`Motivation`（激励）、`Enablement`（使能）——影响读者的行为。

**判断核心的方法**：把卫星删掉，核心句还能单独成立（信息略少但结构完整）；把核心删掉，卫星句就「无依无靠」——**核心是「删不得的」**。<span class="marginnote">核心/卫星的判定是 RST 标注的核心技能，也是最主观的部分——「这段是证据还是背景」标注者常犹豫。好在 RST 标注有规范（RST 标注手册），计算篇章分析的研究也用「标注一致性」衡量标注质量。核心/卫星的直觉可以借句法对照：「因为 X，所以 Y」里 Y 是核心、X 是卫星（删掉 X，Y 还成立）。</span>

## 3 公式解析：RST 树的递归表示

RST 树可以形式化地递归定义。一篇文本 $T$ 的结构是：

$$
T = \text{Relation}(N, S) \quad \text{或} \quad T = \text{Multinuc}(N_1, N_2, \dots, N_k)
$$

逐步拆解：

- **第一步，$\text{Relation}(N, S)$（核心-卫星关系）**：一个「关系」节点连接一个核心 $N$ 与一个卫星 $S$——关系类型标在节点上（`Elaboration`、`Cause`……）。树的这个分支表达「核心是主、卫星辅助」。
- **第二步，$\text{Multinuc}(N_1,\dots,N_k)$（多核心结构）**：并列关系（对比、时序）连接**多个核心**——无主次之分。
- **第三步，递归**：核心 $N$ 和卫星 $S$ 本身**又可以是子树**——「核心的内部还有核心/卫星」。RST 树因此是**递归嵌套**的：大关系里套小关系，直到叶子是基本篇章单位（EDU）。
- **第四步，整篇一个根**：所有子树最终汇聚成一个根节点——**「整篇文本是树的根，叶子是子句」**。

**直觉**：RST 树 = 「**子句是叶子、关系是内部节点**」的递归树——读一遍这棵树，就能看到「文本是怎么一段段组织起来的」。

## 4 RST 解析：预测篇章树

**RST 解析（rhetorical parsing）**：从文本自动构建 RST 树。建模与第八篇句法分析高度相似：

- **任务**：给 EDU 序列构建**树结构** + 给每个内部节点标**关系类型**；
- **建模**：把「篇章树」当「句法树」来解——用**转移式解析**（第八篇的转移系统：SHIFT/REDUCE 变成「合并两个 EDU」）或**图式解析**（枚举「相邻单位对」打分选最优结构）；
- **预训练时代**：BERT 编码 EDU，解析头预测树结构与关系——RST 解析器的性能在 RST-DT 语料上接近句法解析器水平。

**RST 解析的难点**：**关系标注的主观性**（同一文本不同标注者树不同）使评测「天花板」不高——标注一致性限制了 RST 解析的上限。<span class="marginnote">RST 解析与句法解析（第八篇）的对照很有启发：两者都是「序列 → 树」的结构预测，转移/图的方法都能用——<strong>篇章树是「句法树的上一级抽象」</strong>。区别在于：句法树有「确定的语法规则」约束，篇章树靠「语义关系」——后者更主观，因此解析更难、评测天花板更低。</span>

## 5 RST 的应用与局限

**应用**：

- **文本摘要**：RST 树里「核心」密度高的片段是摘要重点——**删卫星保核心**，天然是抽取式摘要的结构依据；
- **连贯性评测**：一篇文本能否被 RST 树「完整组织」≈ 它连不连贯——树越「可分析」，文本越连贯；
- **篇章增强的生成**：生成时「按 RST 规划结构」（先核后卫），提高生成文本的条理性。

**局限**：

- **树形假设**对松散文本生硬（前文提过）；
- **标注昂贵且主观**——RST 语料（RST-DT）只有数百篇，规模远小于句法树库；
- **预训练内化**——BERT 类模型隐式学到篇章结构，显式 RST 解析的「增量价值」变小。<span class="marginnote">RST 在摘要里的价值是它最持久的应用：「核心优先」给抽取式摘要一个理论依据——RST 树里靠近根的核心句，就是最重要的句子。现代抽取系统虽不用完整 RST 树，但「重点句 ≈ 篇章核心」的直觉被广泛采用。这也提醒我们：<strong>经典理论的价值，有时以「隐式先验」的形式活在更现代的模型里</strong>。</span>

## 6 辨析｜易错点：四个常见坑

**辨析｜易错点：**

- **RST 的「关系」不是「句法连词」**：关系是**语义/修辞**的（Elaboration、Evidence），不是「因为/所以」这类连词本身——连词只是关系的**表面信号**，同一关系可无连词。<span class="marginnote">记忆：句法（第八篇）管「从句怎么嵌」，RST 管「单位怎么组织」——一个是语法层、一个是修辞层。</span>
- **核心 ≠ 主语/主句**：核心是「信息重点」，不是「句法主干」——「因为下雨，所以取消了」（主句是「取消」，但信息重点可因上下文而异）。别拿句法概念套 RST。
- **RST 树不是「左右括号」的二叉树**：多核心关系可以连接多个子节点，核心-卫星也分左右——RST 树是一般树，不是简单的「二叉括号」。
- **RST 解析 ≠ 完美篇章理解**：预训练模型不显式解析 RST 也「理解」篇章——RST 解析是「可解释的结构化手段」，不是「理解的必要条件」。

## 7 小结

- **RST**：把篇章组织成递归树——子句是叶子、修辞关系是内部节点。
- 核心概念：**核心/卫星不对称** + **约 25 种修辞关系**（Elaboration/Evidence/Cause/Contrast……）。
- 树表示：$\text{Relation}(N,S)$ 或 $\text{Multinuc}(N_1,\dots,N_k)$——递归嵌套，整篇一个根。
- **RST 解析** = 「序列 → 篇章树」的结构预测——转移/图式方法，预训练模型增强。
- 应用：摘要（删卫星保核心）、连贯性评测、生成结构规划。
- 局限：树形假设生硬、标注昂贵主观、预训练内化。
