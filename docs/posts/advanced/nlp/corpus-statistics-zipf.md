## 为什么先学会「数词」

语料库建好了，第一件事不是跑模型，而是**数一数词**。数词这件事看似简单，数出来的规律却深刻到能决定 NLP 方法的成败：绝大多数词出现极少、极少数词反复出现，这种「长尾」分布直接塑造了语言模型的估计方式、词向量的训练目标，也制造了统计 NLP 最头疼的难题——稀疏性。<span class="marginnote">「从极限到大模型」主线的底层是数学：词频分布正是概率论里重尾分布（heavy-tailed distribution）在语言上的现身。它和网络科学里的「幂律」、财富分布的帕累托法则，是同一个家族的现象。</span>

这一节建立三块基石：**词频怎么数**、**齐普夫定律长什么样**、**稀疏性为何是统计 NLP 的头号敌人**。这三块拼起来，第四篇 n-gram 语言模型里的「平滑」就顺理成章了。

## 1 词频：token 与 type

数词之前，先分清两个容易混的概念：

- **token（词次 / 形符）**：文本中每出现一次词就算一个 token。「苹果 苹果 梨」里有 **3 个 token**。
- **type（词型 / 类符）**：去重后不同的词。「苹果 苹果 梨」里有 **2 个 type**。

词频统计给每个 type 数它出现的 token 次数，得到**词频表（frequency list）**。把词频表按出现次数从高到低排，第一位就是语料里出现最多的词——英语里通常是 *the*，汉语里通常是「的」。

词频表有两个派生指标特别常用：

- **词汇密度 / 多样性**：用**类符形符比（type–token ratio，TTR）** = $V/N$（type 数除以 token 总数）衡量。TTR 越高，说明文本用词越丰富。
- **高频词的覆盖率**：一份语料里，前几百个高频词往往就覆盖了文本的大半 token。

**辨析｜易错点：** 高频词不等于「重要词」。「的」「了」「the」「of」这类**功能词（function word）**永远霸占词频榜首，却几乎不携带内容信息。做文本分类或关键词抽取时，第一步往往就是**去掉停用词（stopwords）**，把高频噪声剔除，才能让「词频」反映内容。

## 2 齐普夫定律：词频与排名的幂律关系

把词频表画出来，会发现一个惊人的规律：**第 $r$ 高频的词，其频次大致与 $1/r$ 成正比。** 这就是 **齐普夫定律（Zipf's Law）**。

$$
f_r = \frac{C}{r^{\alpha}}
$$

通常 $\alpha \approx 1$。$C$ 是语料相关的归一化常数，约等于最高频词的频次。这条式子的威力在于：**它是跨越语言、体裁、时代的经验普适规律**——无论英语、汉语、德语，无论新闻还是小说，只要文本足够长，词频—排名都服从这个幂律。

对两边取对数，幂律会变成一条直线：

$$
\log f_r = \log C - \alpha \log r
$$

## 3 公式解析：把齐普夫定律拆开看

$$

f_r = \frac{C}{r^{\alpha}}, \qquad \log f_r = \log C - \alpha \log r

$$

对这条式子做三步拆解：

- **第一步，$r$ 是什么**：$r$ 是**排名（rank）**。把语料里所有词按频次从高到低排队，第一名 $r=1$（频次最高的词），第 $r$ 名就是频次排第 $r$ 的词。排名是相对位置，不随语料大小改变——这是它比绝对频次更「稳定」的原因。
- **第二步，$f_r$ 与 $C$**：$f_r$ 是排名为 $r$ 的词的频次；$C$ 是归一化常数，量级等于最高频词的频次。当 $r=1$ 时 $f_1 = C$，所以 $C$ 就是第一名词的频次。例如英语语料里 *the* 通常占全部 token 的 7% 左右，那么 $C \approx 0.07 \times N$。
- **第三步，指数 $\alpha$ 与对数化**：$\alpha \approx 1$ 意味着「频次与排名成反比」——第二名大约是第一名的一半，第三名大约是三分之一，第十名大约是十分之一。两边取对数后变成 $\log f_r = \log C - \alpha \log r$，在 $\log r$–$\log f_r$ 平面里是一条**斜率为 $-\alpha$ 的直线**。**幂律取对数后是直线**，这正是识别幂律分布最快捷的方法：在双对数坐标里看是不是近似一条直线。<span class="marginnote">为什么语言会服从这条定律？齐普夫自己的解释是「最少气力原则」（the principle of least effort）：说话人想少费力气多用几个高频词，听话人却需要更精确的区分、需要更多低频词，两者博弈的均衡就压出了这种幂律。这个解释仍有争议，但经验规律本身无可辩驳。</span>

## 4 稀疏性：从长尾到「没见过的组合」

齐普夫定律直接推导出统计 NLP 最核心的困难——**稀疏性（sparsity）**。稀疏性有两层，一层是词的层面，一层是组合的层面。

**词的层面：长尾与未登录词。** 因为 $f_r \propto 1/r$，词频表必然拖着一条极长的尾巴：一半以上的词在语料里只出现一两次（这类词叫 **hapax legomena**，仅现词）。这意味着无论语料多大，**总有大量合法词汇从未出现过**。当模型在测试时遇到一个从没见过的词，就是**未登录词（out-of-vocabulary，OOV）**问题。

**组合的层面：n-gram 爆炸。** 词与词的组合远比词本身稀疏。假设词汇量 $V = 10^5$，二元组合（bigram）就有 $V^2 = 10^{10}$ 种可能，而任何真实语料能覆盖的只是其中极小一部分。绝大多数「合法」的二字组合在语料里一次都没出现过——但它们显然不是概率为零的。

举一个具体的数字感受稀疏性。设词汇量 $V = 10^5$，bigram（二元组合）空间就是 $V^2 = 10^{10}$。即便你有一个 1 亿 token 的大语料，能观测到的 bigram 种类通常不过几百万，覆盖率不足万分之一；更糟的是，**测试集里大量出现过的 bigram，在训练集里从未出现过**。这就是语言模型必须做平滑的数学原因。

**辨析｜易错点：** 稀疏性不等于「词太少」，而是「**观察到的样本远不足以覆盖可能出现的组合**」。如果直接把「没见过的概率当作零」，模型会说出一大堆概率为零的句子，完全失去泛化能力。第四篇 n-gram 语言模型里的一切**平滑（smoothing）方法**，本质都是同一件事：**给「没见过的」分配一个不为零的概率**。这里的「长尾」概念，也是第五篇词向量（尤其是负采样、FastText 的子词处理）要反复对付的东西。<span class="marginnote">还有一个配套的经验定律值得记住——<strong>希普斯定律（Heaps' Law）</strong>：语料词型总数随 token 数按 $V(n) = K n^{\beta}$（$0<\beta<1$）增长。它的意思是：语料翻十倍，词型只翻不到两倍。这再次说明：无论怎么加大语料，长尾都砍不完，稀疏性无法靠「堆数据」根治。</span>

## 5 词频统计的一个最小实现

把上面这些概念落到代码上，其实就是几行 Python。用 `collections.Counter` 数词频，再画出双对数图，就能亲手「看见」齐普夫定律：

```python
import re
from collections import Counter

text = open("corpus.txt", encoding="utf-8").read()
tokens = re.findall(r"\w+", text.lower())          # 切分并小写

freq = Counter(tokens)                              # 词频表
ranked = freq.most_common()                         # 按频次降序排列

for rank, (word, count) in enumerate(ranked[:10], start=1):
    print(f"r={rank}\t{word}\t{count}")

# 验证齐普夫定律：log(freq) ≈ log(C) − log(rank)
import math
r, f = 1, ranked[0][1]
for i, (word, count) in enumerate(ranked[1:100], start=2):
    if count > 1:                                    # 跳过同频带来的并列排名
        print(math.log(i), round(math.log(count), 3))
```

这个实现虽然粗糙，却复现了语料统计的三步标准动作：**切分 → 计数 → 排序**。真正的分词要交给第三篇的专用算法，但「数词」的骨架就是这个。

## 6 词频统计的两种去向

词频表统计出来之后，有两条经典去向，预告一下：

- **做概率**：把词频归一化成概率 $P(w) = f_w / N$，这是第四篇语言模型的起点——语言的统计规律就藏在 $P(w)$ 里。
- **做权重**：直接拿词频当权重会被功能词主导，于是有了 TF-IDF——既看词在当前文档出现多频繁，又看它在多少文档里出现过（第三篇《文本表示基础》会系统展开）。

两种去向共享同一份词频统计，区别只在于「如何使用」。**词频是原料，怎么加工才决定用途**——想通这一点，语料统计这一节才算真正内化。

## 7 小结

- **token（词次）与 type（词型）**：TTR = $V/N$ 衡量用词丰富度；高频榜首多是**功能词**，做任务前要**去停用词**。
- **齐普夫定律**：$f_r = C / r^{\alpha}$，$\alpha \approx 1$；对数化后 $\log f_r = \log C - \alpha \log r$，在双对数图里是一条斜率约为 $-1$ 的直线。
- 幂律的识别方法：**双对数坐标下近似直线**；长尾由海量低频词构成，**仅现词（hapax legomena）**占一半以上。
- **稀疏性**：语料远不足以覆盖所有合法词及 n-gram 组合；OOV 与「未出现组合」都不能当作概率为零。
- **希普斯定律** $V(n) = K n^{\beta}$：词型增长远慢于 token 增长，稀疏性无法靠堆数据根治，只能靠**平滑**与**表示学习**化解。

在下一节，我们把视野从「统计语料」转向「处理语料」的第一件工具——**正则表达式与文本匹配**。它是清洗、切分、抽取各种文本模式的基本功。
