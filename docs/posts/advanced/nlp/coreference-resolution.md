## 为什么从指代消解开始

「**乔布斯**发布了 iPhone，**他**说这是革命性的产品。」——「他」和「乔布斯」是同一个实体。机器要正确理解这句话，必须把「他」**还原**到「乔布斯」。**指代消解（Coreference Resolution）**：把文本中指向同一实体的所有**指称（mention）**归并到同一个簇。<span class="marginnote">指代消解是「篇章级」IE 的起点：前面 NER、关系、事件都是句子级或实体对级的，只有指代消解要<strong>读整篇文档</strong>才能做对。它是连接「句子理解」与「篇章理解」（第十七篇）的桥梁——也是很多下游任务的「信息整合」步骤。</span>

这一篇讲指代消解的**任务形态**（指称类型）、**建模方法**（从 mention-pair 到端到端跨度模型）与**评测**（MUC/B³/CEAF）。

## 1 什么是指代消解

**指代消解**：给定一篇文档，把所有**指向同一实体**的指称分到同一个**指代链（coreference chain / cluster）**。

> 「**乔布斯**创办了苹果。**他**被赶出公司，**后来**又回归。」

- 指称（mention）：`乔布斯`、`他`、`他`——三个指称指向同一实体，归为一簇；
- 输出：$\{\text{乔布斯}, \text{他}, \text{他}\}$ 作为一个簇。

**与「指代消歧」的区别**：指代消歧（anaphora resolution）只找「代词的先行词」（他 → 乔布斯）；**指代消解（coreference resolution）是更全的任务**——所有指称（含两个「乔布斯」）都归簇，包括「同指」（两个相同名词指同一实体）。<span class="marginnote">术语辨析：<strong>回指（anaphora）</strong>是「后面提到前面」（乔布斯→他），<strong>预指（cataphora）</strong>是「前面提到后面」（他一进来，乔布斯就站起来）。指代消解把两者都覆盖，且不只代词——名词短语（「苹果公司」vs「这家公司」）与命名实体（「乔布斯」出现两次）的同指也管。</span>

## 2 指称的三种类型

指称（mention）分三类，难度递增：

- **命名实体（named）**：「乔布斯」「苹果公司」——直呼其名，最容易（NER 就能找）。
- **名词短语（nominal）**：「这位 CEO」「这家公司」「创始人」——用描述指称，需要常识判断「CEO 是不是乔布斯」。
- **代词（pronominal）**：「他」「它」「我们」——最依赖上下文，「他」可以是任何人。<span class="marginnote">代词消解在汉语里尤其麻烦：汉语代词常省略（「他回家了，（他）关上了门」——第二个「他」直接省略，叫「零形回指」）。汉语指代消解必须处理省略主语，这是中英指代研究的最大差异之一。</span>

**难度排序**：命名实体 < 名词短语 < 代词（零形最难）。三类指称混合在真实文档里，指代消解必须统一处理。

## 3 建模方法：从两两判断到排序

判别式指代消解有两条经典路线：

- **mention-pair 模型**：对每一对指称判断「是否同指」——训练时构造「正对」（同簇指称对）与「反对」（不同簇），学二分类。简单，但**局部判断、缺乏全局一致性**——「他」和「乔布斯」同指、「他」和「库克」也同指，三个两两都成立，但乔布斯 ≠ 库克，矛盾。
- **mention-ranking 模型**：对每个指称，在**候选先行词里排序**，挑最可能的先行词——比两两独立分类更符合直觉（一个指称只能有一个先行词）。<span class="marginnote">mention-pair 的「传递闭包」问题（A~B、B~C 但 A 和 C 不该同指）是它被 mention-ranking 超越的关键原因：<strong>排序模型天然处理「一个指称只归一个簇」</strong>——每个指称只选一个先行词，全局一致性好得多。现代系统几乎都是 ranking 或 cluster 视角。</span>

关键特征/信号：

- **性别与数一致性**：「他」不能指「苹果公司」（中性名词）——性别/数不匹配直接排除；
- **句法约束**：代词不能与句内某些成分共指（约束原则 B——「他看见他自己」的规则）；
- **显著性（salience）**：主语、新引入的实体更可能是先行词——篇章焦点。

## 4 公式解析：mention-ranking 的打分

mention-ranking 给每个指称 $m$ 的候选先行词 $a$ 打分：

$$
s(m, a) = \mathbf{h}_m^\top W\, \mathbf{h}_a + b
$$

逐步拆解：

- **第一步，$\mathbf{h}_m$（指称表征）**：当前指称 $m$（如「他」）的上下文语义向量，由编码器（BERT）得到——包含「他」这个词与周围上下文的信息。
- **第二步，$\mathbf{h}_a$（先行词表征）**：候选先行词 $a$（如「乔布斯」）的表征——它在文档里的语义。
- **第三步，双线性打分 $\mathbf{h}_m^\top W \mathbf{h}_a$**：度量「指称与先行词语义契合度」——与第八篇双仿射、第十二篇方面注意力的双线性形式同源。$W$ 学习「什么样的两个片段是同指关系」。
- **第四步，排序与决策**：对 `m` 的所有候选先行词按 $s$ 排序，取最高分者作为先行词（若高于阈值）；得分最低的（无合适先行词）判为「新实体」，自成一簇。

**直觉**：指代消解 = 「给每个指称找最像先行词的候选」。**性别/数等硬约束负责排除，双线性打分负责排序**——排除 + 排序结合，比纯分类精确得多。

## 5 端到端跨度指代（e2e coref）

现代指代消解的标杆是 **e2e coref**（Lee et al., 2017）——**端到端**地同时做「找指称」与「消解」：

1. **枚举跨度**：枚举文档里所有可能的指称跨度（$O(n^2)$ 个），用「跨度打分」筛出像指称的；
2. **跨度表征**：每个跨度编码成向量（首尾词 + 头词注意力）；
3. **配对打分**：对「跨度-先行词」对打分（含「不是指称」的虚拟先项），用 mention-ranking 思路选先行词；
4. **聚类**：按打分把指称连成簇。

**e2e coref 的突破**：不需要外部 NER 或语法工具，一个模型从原始文本端到端学「哪是指称、谁和谁同指」——在 OntoNotes 上大幅刷新纪录，成为神经指代消解的标准。<span class="marginnote">e2e coref 与第八篇 span-based 解析、第十一篇嵌套 NER 是同一个「跨度枚举 + 打分」家族：<strong>先枚举所有候选结构，再逐个打分、全局选择</strong>。这个「枚举-打分-选择」范式在结构化预测里无处不在——理解它，就拿到了神经结构化建模的通票。</span>

## 6 评测：MUC、B³ 与 CEAF

指代消解的评测比 NER/关系更微妙——**边界模糊**（一个指称分到哪个簇、簇怎么划分，都有多种合理答案）。三个经典指标：

- **MUC 指标**：基于「正确识别链接（同指对）的数量」——简单但对「单元素簇」不惩罚。
- **B³（B-cubed）**：**对每个指称**算其簇的精确率/召回率，再平均——解决 MUC 的问题，但对「合并大簇」惩罚过重。
- **CEAF**：基于「簇与簇的最优匹配」——直接比较簇划分，直觉更清晰。

三个指标各有偏颇，**现代评测报告 MUC + B³ + CEAF 的平均（CoNLL 分数）**——单报一个指标会被质疑。<span class="marginnote">CoNLL-2012 共享任务规定：指代消解的成绩 = (MUC + B³ + CEAF) / 3，取三者平均。这是「没有完美指标，所以取平均」的务实妥协——理解每个指标的偏向（MUC 偏链接、B³ 偏指称、CEAF 偏簇），才能读懂分数差异。</span>

**经典数据**：**OntoNotes 5.0**（英语/中文/阿拉伯语，多体裁）——指代消解的事实基准；中文还有 **ACE 中文语料**与自建语料。

## 7 辨析｜易错点：四个常见坑

**辨析｜易错点：**

- **指代消解 ≠ 代词消解**：它管所有指称（实体、名词短语、代词），不只是「他/她」。把任务窄化为代词会漏掉「这位 CEO」这类名词短语同指。<span class="marginnote">用词提示：anaphora resolution（指代消歧）专指代词找先行词；coreference resolution（指代消解）是全景归簇。论文与系统先分清说的是哪个。</span>
- **性别/数一致性是「约束」不是「偏好」**：「他」指「苹果公司」不是「概率低」，而是**语法上不可能**——约束应该硬排除，不是软打分。
- **评测指标的偏向各不相同**：MUC 对「把一个簇分成两半」的召回惩罚不够；B³ 对「过度合并」惩罚重。跨系统比较要看**三个指标 + 平均**，别单看一个。
- **「新实体」判断是任务的一部分**：指称找不到先行词 → 自成一簇（新实体），不是「不处理」。漏判新实体会把簇切碎。

## 8 小结

- **指代消解**：把所有指向同一实体的指称归簇，是篇章级 IE 的起点。
- 指称三类：**命名实体 / 名词短语 / 代词**（汉语还有零形回指），难度递增。
- 建模：**mention-pair**（两两二分类）→ **mention-ranking**（排序选先行词）→ **端到端跨度模型**（枚举 + 打分 + 聚类）。
- 打分 $s(m,a)=\mathbf{h}_m^\top W\mathbf{h}_a+b$；硬约束排除 + 双线性打分排序。
- 关键信号：性别/数一致、句法约束、显著性。
- 评测：**MUC / B³ / CEAF** 三指标平均（CoNLL 分数）；数据：OntoNotes 5.0。
