## 为什么从量化基本原理开始

一个 70B 参数的模型，FP16 存储要 140 GB 显存——单张 A100（80 GB）根本放不下。但模型的权重真的需要 16 位精度吗？大量研究（以及量化在实践中取得的成功）表明，绝大多数权重值分布在很窄的区间里，用 8 位、4 位甚至更低精度表达，模型能力几乎不损失。**量化（quantization）**就是把「连续/高精度数值」映射到「有限位宽的离散数值」的过程，是部署大模型时省显存、提吞吐的第一手段。<span class="marginnote">本专题从 TensorRT-LLM 的量化支持一路走到这里，接下来量化篇会逐个展开 GPTQ、AWQ、SmoothQuant、FP8 等<strong>具体方案</strong>；本篇先把「量化是什么、误差从哪来」的地基打好。</span>

本篇讲量化的基本框架：线性量化的数学形式、对称/非对称的差别、round 与 clip 两大误差来源，以及为什么「选 scale 就是选误差」。

## 1 线性量化：从浮点到整数

**线性量化（linear quantization）**：用一层仿射映射把浮点数 $x$ 映射成整数 $q$，再在计算时反映射回来。基本形式是：

$$q = \text{round}\left(\frac{x}{s}\right) + z, \qquad \hat{x} = s \cdot (q - z)$$

其中 $s$ 是**缩放因子（scale）**，$z$ 是**零点（zero-point）**。$q$ 的取值被限制在一个整数范围（如 INT8 的 $[-128, 127]$）。<span class="marginnote">注意 <code>round</code>` 是<strong>逐值舍入</strong>，它引入的是不可恢复的量化误差；<code>clip</code>` 是把超出范围的数值硬切到边界。两者是量化的两大误差来源。</span>

当 $z = 0$ 时叫**对称量化**，映射是纯缩放，$q = \text{round}(x/s)$，反量化 $\hat{x} = s \cdot q$；当 $z \neq 0$ 时叫**非对称量化**，多了零点补偿。

**对称量化适合**数值以 0 为中心对称分布的数据——权重通常如此；**非对称量化适合**偏斜分布的数据——激活（如 ReLU 后的正数）通常如此。选择哪一种，本质是「用不用浪费的整数范围去换更细的步长」。

## 2 误差的解剖：round 与 clip

量化误差可以用一个分解看清来源。设浮点值 $x$ 落在 $[x_{\min}, x_{\max}]$ 之外的部分被 clip，之内被 round：

**Clip 误差**：超出 $[x_{\min}, x_{\max}]$ 的**离群值（outlier）**被强行切到边界。若离群值数量多、幅度大，误差爆炸。
**Round 误差**：范围内每个值被舍入到最近的量化格点，单点误差最多半个步长 $\Delta/2$，其中步长 $\Delta = s$（对称情形）。**步长越小（量化格点越密），round 误差越小**。

这两类误差是此消彼长的：把 $[x_{\min}, x_{\max}]$ 范围扩大以包住更多离群值，会让步长变大、round 误差变差；缩小范围，离群值的 clip 误差变差。**最优的 scale 是「让总误差最小」的平衡点**——这是所有量化校准算法的共同出发点。<span class="marginnote">校准（calibration）就是统计真实数据分布、选出一个让两类误差总和小化的 scale。不同算法（MinMax、百分位、MSE、KL 散度）本质是<strong>对「什么样的误差不可接受」的不同建模</strong>。</span>

## 3 对称 vs 非对称：选型与计算代价

**辨析｜易错点：对称量化「省算力」不是免费的。** 对称量化（$z=0$）让矩阵乘在整数域直接做：$(s_a q_a)(s_w q_w) = s_a s_w (q_a q_w)$，反量化只需最后乘一个标量 $s_a s_w$，计算路径最短。非对称量化多了零点项 $z_a$、$z_w$，反量化展开后出现交叉项：

$$x_a \cdot x_w = s_a s_w (q_a - z_a)(q_w - z_w) = s_a s_w (q_a q_w - z_a q_w - z_w q_a + z_a z_w)$$

多出来的项要么单独计算再合并，要么用更高阶的 kernel 处理，计算与内存开销都上升。<span class="marginnote">因此工程惯例是：<strong>权重用对称量化（分布本就近似对称），激活视分布决定</strong>；若激活也能对称量化（如经过某些归一化后），就优先对称，换更快的 kernel。</span>

用一张表总结两者的取舍：

| 维度 | 对称量化 | 非对称量化 |
| --- | --- | --- |
| 映射形式 | $q = \text{round}(x/s)$ | $q = \text{round}(x/s) + z$ |
| 零点 | $z = 0$，可省 | $z \neq 0$，需存储与计算 |
| 数值范围 | 全范围利用（对称分布最优） | 对偏斜分布更优 |
| 反量化 | 只乘一个 $s$ | 有零点交叉项 |
| 典型场景 | 权重（W8A8、W4A16） | 激活（ReLU 后非负） |
| 计算开销 | 低 | 高 |

## 4 公式解析：量化误差的数学表达

把一个量化器写成「clip + round + 反量化」的复合函数：

$$\hat{x} = s \cdot \text{clip}\left(\text{round}\left(\frac{x}{s}\right), q_{\min}, q_{\max}\right)$$

单点误差 $\epsilon(x) = \hat{x} - x$。对整个张量的平均误差用均方误差衡量：

$$\text{MSE} = \mathbb{E}\left[(\hat{x} - x)^2\right] = \mathbb{E}\left[\epsilon(x)^2\right]$$

- **第一步，拆 clip 部分**：对超出范围的 $x$，$\epsilon(x) = x_{\text{bound}} - x$，误差随离群幅度线性增长。**离群值越多，这部分越主导**。
- **第二步，拆 round 部分**：对范围内均匀分布的 $x$，round 误差近似在 $[-\Delta/2, \Delta/2]$ 均匀分布，其均方值为 $\Delta^2/12$（连续均匀分布的方差公式）。**误差正比于步长平方**——所以「scale 减半，误差降到 1/4」。
- **第三步，合成**：总 MSE ≈ clip 部分 + $s^2/12$（round 部分）。**这就是为什么所有校准算法都在「缩小 $s$ 以降低 round 误差」与「扩大范围以降低 clip 误差」之间权衡**——它们分别对应 $s$ 的两个作用方向。

把 $s$ 的选法公式化：对称量化最优步长近似为 $s^* = 2 \cdot \max|x| / 2^b$（$b$ 为位宽）时均匀覆盖，但实际常按分位数压缩范围以换更小的 round 误差——**用少量离群值的 clip 代价，换取绝大多数值更精细的量化**。

## 5 小结

- **线性量化 = clip + round + 缩放**：$q = \text{round}(x/s) + z$，反量化 $\hat{x} = s(q-z)$。
- **两大误差源**：clip 误差来自离群值被切断，round 误差来自格点化，最优 scale 平衡两者。
- **对称 vs 非对称**：对称省零点、计算最快，适合近似对称的权重；非对称适合偏斜的激活。
- **误差量化**：MSE ≈ clip 误差 + $s^2/12$，round 误差正比于步长平方，scale 减半误差降为 1/4。
- **校准算法就是选 scale 的策略**：MinMax、MSE、KL 散度是对「什么误差不可接受」的不同建模。
