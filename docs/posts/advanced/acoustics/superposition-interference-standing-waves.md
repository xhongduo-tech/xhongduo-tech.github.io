## 为什么从叠加谈起

声音世界里几乎不存在「单独一列波」：合唱团的歌声、城市的背景噪声、扬声器阵列的指向性，全都是多列波同时在场。线性波动方程赐予我们**叠加原理（superposition principle）**——若 $p_1$、$p_2$ 都是波动方程的解，则 $p_1 + p_2$ 也是解。于是任意复杂声场都可以拆成简单波的叠加来研究，再按相位关系逐点合成。叠加原理是声学「傅里叶分析」的合法性来源，也是干涉、驻波、衍射、阵列设计的共同起点。<span class="marginnote">叠加原理只在线性声学成立：小振幅下声波互不干扰，两列波可以「穿过」彼此而各自保持不变。大振幅时会出现非线性耦合（参量阵、谐波畸变），叠加原理失效——这正是超声医学与强声学的研究对象。</span>

## 1 两列同频同向波的合成

先看最简单的叠加：两列同频率、同方向传播的平面波

$$
p_1 = p_{01}\cos(\omega t - kx + \varphi_1), \qquad p_2 = p_{02}\cos(\omega t - kx + \varphi_2)
$$

利用三角恒等式，合成为

$$
p = p_0\cos(\omega t - kx + \varphi)
$$

其中合成振幅与相位满足

$$
p_0^2 = p_{01}^2 + p_{02}^2 + 2p_{01}p_{02}\cos\Delta\varphi, \qquad \Delta\varphi = \varphi_1 - \varphi_2
$$

**关键结论**：合成波的强弱完全由两波的**相位差 $\Delta\varphi$** 决定。

- 当 $\Delta\varphi = 0$（同相）：$p_0 = p_{01} + p_{02}$，**相长干涉**，振幅最大。
- 当 $\Delta\varphi = \pi$（反相）：$p_0 = |p_{01} - p_{02}|$，**相消干涉**；若两波等幅则完全抵消，$p_0 = 0$。<span class="marginnote">两列等幅反相声波相遇会「寂静无声」——这是主动降噪耳机（ANC）的原理：实时生成与外界噪声反相的声波，在耳道处相消。注意它只在局部（耳道内）成立，因为完全相消要求幅度匹配且相位精确，位置一变相位差就变。</span>

相位差 $\Delta\varphi$ 与传播距离差 $\Delta x$ 的关系是 $\Delta\varphi = k\Delta x = 2\pi\frac{\Delta x}{\lambda}$。因此**距离差是波长的整数倍则加强，半波长的奇数倍则减弱**。

## 2 干涉与拍

**辨析｜易错点：** 干涉（interference）是「同频波叠加后空间强弱分布固定」的现象；**拍（beats）**则是「两列频率略有不同的波叠加后振幅随时间周期性起伏」的现象。干涉是空间的，拍是时间的，二者不要混为一谈。

两列频率相近的波 $f_1$、$f_2$ 叠加，合成振幅按**拍频**

$$
f_b = |f_1 - f_2|
$$

周期性起伏。例如 440 Hz 与 443 Hz 的两个音叠加，会听到「嗡—嗡—」的拍，拍频 3 Hz。<span class="marginnote">调音师正是利用拍来校准乐器：当两音完全同频时拍消失。这一朴素原理也是许多声学测量方法的基础——如超声多普勒血流仪测出的频移，往往通过差拍转换成可听信号。</span>

## 3 驻波的产生与特征

当两列**等幅、同频、反方向**传播的波叠加时，产生**驻波（standing wave）**。取

$$
p = p_0\cos(\omega t - kx) + p_0\cos(\omega t + kx) = 2p_0\cos\omega t \cos kx
$$

这个结果有三层含义：

**空间结构固定**：$\cos kx$ 决定空间分布，波节（$p=0$）位于 $kx = (n+\frac{1}{2})\pi$，波腹（$|p|=2p_0$）位于 $kx = n\pi$。相邻波节间距 $\lambda/2$。

**时间振荡同步**：$\cos\omega t$ 决定时间因子，场中各点以相同频率、相同相位振荡——只是振幅不同。**驻波没有相位的传播**，「波」在这里并不「走」。

**能量不输运**：如上节所述，$\overline{pu} = 0$，净能流为零。<span class="marginnote">驻波的边界条件来源：在刚性壁面上 $\partial p/\partial n = 0$（声压取波腹），在自由面上 $p = 0$（声压取波节）。两端固定弦、闭管、开管都由此确定各自的驻波频率，这是下一节《管道声学》的基础。</span>

驻波的工程意义重大：管道里、房间里、测试箱里无处不在的「驻波峰谷」，会造成声场空间不均匀；阻抗管测材料、消声室设计都要处理驻波问题。

## 4 公式解析：$p = 2p_0\cos\omega t \cos kx$

这条驻波公式值得逐项拆解：

- **第一步，两列反向波的相加**：$\cos(\omega t - kx) + \cos(\omega t + kx)$，用和差化积公式 $\cos A + \cos B = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2}$，其中 $A = \omega t - kx$、$B = \omega t + kx$，于是得 $2\cos(\omega t)\cos(kx)$。
- **第二步，分离时间与空间**：结果被拆成「纯时间因子 $\cos\omega t$」与「纯空间因子 $\cos kx$」的乘积。这表示场中各点**同步振荡**，没有相位沿 $x$ 传播——这正是「驻」的含义。
- **第三步，读节点位置**：$kx = (n + \frac{1}{2})\pi$ 时 $\cos kx = 0$，即 $x = (n+\frac{1}{2})\frac{\lambda}{2}$，相邻节点相距 $\lambda/2$。波腹同理相距 $\lambda/2$。
- **第四步，与行波的对照**：行波 $p = p_0\cos(\omega t - kx)$ 中相位同时依赖 $t$ 与 $x$，所以等相位面沿 $x$ 运动；驻波两者分离，相位冻结在空间里。**判别行波还是驻波，就看成因能否分离为 $f(t)g(x)$**。

## 5 多列波叠加与「拍」的定量

若两列波频率略有不同 $k_1 = k + \Delta k/2$、$k_2 = k - \Delta k/2$，叠加为

$$
p = 2p_0\cos\left(\Delta\omega\, t - \Delta k\, x\right)\cos(\omega t - kx)
$$

其中 $\Delta\omega = \omega_1 - \omega_2$。整体看，它是一列**高频载波** $\cos(\omega t - kx)$，其振幅被一列低频包络 $\cos(\Delta\omega t - \Delta k x)$ 调制。固定空间某点，包络以拍频 $|\Delta\omega|/2\pi$ 起伏。<span class="marginnote">「载波 + 包络」的语言与通信工程同源：拍频分析、差频检测、幅度调制都是同一数学结构。声学里的拍、光学里的拍频干涉、通信里的混频，共用 $\cos A\cos B$ 恒等式。</span>

## 6 例题：两列波的合成与拍

（a）两列同频平面波在同一点分别产生 $p_1 = 60\ \mathrm{dB}$ 与 $p_2 = 60\ \mathrm{dB}$，相位差 $\Delta\varphi = 0$ 与 $\Delta\varphi = \pi$ 时合成声级各为多少？（b）频率 440 Hz 与 442 Hz 的两个纯音叠加，拍频多少？

**第一步，同相合成（$\Delta\varphi = 0$）**：声压幅值相加，$p_0 = 2p_{01}$，$L = 20\log_{10}(2p_{01}/p_{\mathrm{ref}}) = 60 + 6 = 66\ \mathrm{dB}$。**同相叠加 +6 dB**。
**第二步，反相合成（$\Delta\varphi = \pi$）**：等幅反相完全抵消，$p_0 = 0$，合成声级为 0（无声）。若幅度不等，则 $p_0 = |p_{01} - p_{02}|$。
**第三步，拍频**：$f_b = |f_1 - f_2| = |440 - 442| = 2\ \mathrm{Hz}$，每 0.5 s 一次「响—弱」周期。

$$
\Delta\varphi = 0: \ 66\ \mathrm{dB}, \qquad \Delta\varphi = \pi: \ 0\ \mathrm{dB}, \qquad f_b = 2\ \mathrm{Hz}
$$

**第四步，讨论**：66 dB 与「60 + 60 能量相加」的 63 dB 不同——63 dB 是**不相干叠加**（随机相位），66 dB 是**相干同相叠加**。区分「能量相加（+3 dB）」与「同相相干相加（+6 dB）」是声学工程的基本功。两列声波是否相干，取决于相位关系是否稳定：同一信号源分两路播放在同一点是同相相干；两个独立声源是随机相位，只能能量相加。

**工程延伸**：反相相消正是主动降噪（ANC）的物理基础，但注意它只在**一个点**严格成立——移动 1/4 波长，相位差变 $\pi/2$，相消失效。这就是 ANC 耳机「对固定位置效果好、头一偏效果差」的原因。

## 7 小结

- **叠加原理**在线性声学中成立：多列波的场是各自的线性叠加。
- 同频波合成强度取决于**相位差**：同相加强、反相减弱；等幅反相则完全抵消（ANC 的原理）。
- **干涉**是空间分布问题，**拍**是时间起伏问题，拍频 $f_b = |f_1 - f_2|$。
- 两列等幅反向波合成**驻波**：空间结构固定、各点同步振荡、净能流为零、相邻节点间距 $\lambda/2$。
- 判别行波还是驻波：看成因能否分离为 $f(t)g(x)$——能分离就是驻波，不能分离就是行波。
- 主动降噪（ANC）是反相相消的工程应用，但相消只在局部点成立：移动 1/4 波长，相位差变化，相消失效。
