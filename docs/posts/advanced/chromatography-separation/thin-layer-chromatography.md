## 为什么讲薄层色谱

在 HPLC 动辄数万、数十万造价的时代，有一个色谱方法依然靠着「一块板、一瓶溶剂、一盏紫外灯」活跃在每一个合成化学实验室的台面上——**薄层色谱（thin-layer chromatography, TLC）**。
它是**平面色谱（planar chromatography）**家族的代表：把固定相涂成一块薄板，样品点在板的下缘，溶剂靠毛细作用自己往上爬，组分被「画」成一排斑点。
没有泵、没有柱、没有昂贵的检测器，却能把分离的物理图像**直接画给你看**。

TLC 的价值不在「顶替 HPLC」，而在「便宜、直观、快、可通量」这四件事上：有机合成的每个反应是否完成、纯度够不够、该用多极性的溶剂体系分离——这些「三分钟要答案」的问题，TLC 一个回合就解决。
它还是制备色谱与柱色谱的**方法预研台**：在纸上板上试好展开剂，放大到柱子上才有的放矢。
<span class="marginnote">TLC 是最接近茨维特原始实验的现代形态：1903 年他正是看着色素在碳酸钙柱上「展开成带」，才给色谱命名「用颜色书写」。TLC 的每一块板都是那次实验的复刻。</span>

## 1 一块板上的色谱学：点样、展开、显色

TLC 的装置和操作都朴素到近乎天然：

- **薄层板（plate）**：玻璃、铝箔或塑料基材上均匀涂布一层固定相（常为**硅胶**，还有氧化铝、纤维素、键合相反相板），厚度约 0.2–0.25 mm。
- **点样**：用毛细管或微量注射器把样品点在距板底缘约 1 cm 的**起始线**上。点要**小、圆、浓度适中**——点太大扩散成片，浓度太高拖尾。
- **展开（development）**：把板竖直放入盛有展开剂的层析缸，液面高度低于起始线。展开剂靠**毛细作用**沿板面上行，把点上的组分「拉」着往上跑——组分在固定相吸附与流动相溶解之间反复分配，吸附强的走得慢、吸附弱的跑得快。
- **显色（detection）**：多数化合物无色，展开后用手段让它现形：**含荧光指示剂的板**在 254 nm 紫外灯下呈荧光背景、吸附紫外的组分呈暗斑；**碘蒸气**让不饱和化合物显黄棕色；**茚三酮**使氨基酸显蓝紫；还有各种喷雾显色剂与硫酸-乙醇碳化显色。

常用显色手段按对象快速对照：

| 显色手段 | 适用对象 | 现象 |
| --- | --- | --- |
| 254 nm 紫外（荧光板） | 含芳环 / 共轭体系 | 荧光背景上的暗斑 |
| 碘蒸气 | 不饱和键及多数有机物 | 黄棕色斑点（会褪色） |
| 茚三酮 | 氨基酸、胺类 | 蓝紫色 |
| 硫酸-乙醇加热 | 几乎一切有机物（碳化） | 棕黑色斑点 |
| 2,4-二硝基苯肼 | 醛、酮 | 橙黄色斑点 |

**TLC 出结果后，分离的「像」就直接印在板上**：几个斑点、斑点间距、有没有拖尾，一目了然。
这种可视化是柱色谱永远给不了的直觉。

**板的前处理与点样质量直接决定成败**：硅胶板吸湿后活性下降，使用前常在 110 °C 活化一段时间；
点样要「少量、小点、圆点」——每点通常只点 1–5 μL、斑点直径尽量压到 2 mm 以内，点太多样品会过载拖尾，点太大展开后扩散成片。

## 2 比移值 Rf：平面色谱的「保留时间」

平面色谱没有保留时间，改用**比移值（Rf, retardation factor）**描述组分的位置：

$$R_f = \frac{\text{组分斑点中心迁移的距离 } d_x}{\text{溶剂前沿迁移的距离 } d_f}$$

$R_f$ 无量纲、介于 0 与 1 之间。$R_f = 0$ 表示组分被固定相完全拖住、留在原点；
$R_f = 1$ 表示组分完全不保留、跟着溶剂前沿跑。经验上，$R_f$ 落在 **0.2–0.8** 之间分离效果最好——太大说明溶剂太强、组分都贴着前沿，太小说明溶剂太弱、组分挤在原点。
<span class="marginnote">$R_f$ 与柱色谱的容量因子 $k'$ 存在定量关系：$R_f = 1/(1+k')$。因此「调展开剂让 $R_f$ 落在 0.2–0.8」等价于「调洗脱强度让 $k'$ 落在合适窗口」——TLC 方法开发的经验完全能迁移到 HPLC 上。</span>
用溶剂强度逐步提高的展开剂系列（正己烷→乙酸乙酯→甲醇），观察斑点的移动速度，就能快速摸清「该用多强的流动相」——这正是 TLC 作为制备柱色谱预研台的方法学基础。

## 3 展开模式与定量：从半定量到 HPTLC

**上行展开**是最常用模式。**双向二维展开**（第一方向跑完后把板转 90°、换一种展开剂再跑）能把单维分不开的复杂样品（如多肽水解液、中药成分）在平面上铺开成「指纹」。
- 判断一个斑点是不是「一个纯组分」，常用**多重展开 + 显色组合**验证：换不同极性的展开剂，斑点不裂开，才说明不是共迁移。
- **定量**分三档：目视与标准品比色（半定量，准确度有限）、**薄层扫描（densitometry）**用仪器对斑点扫描吸光度积分定量、**高效薄层色谱（HPTLC）**用更细颗粒（5 μm）、更薄更均匀的板配合扫描仪，定量精度与 HPLC 已可比较。

**HPTLC 是 TLC 的「正规军」形态**：更细更均匀的颗粒、更严格控制的点样与展开、配合扫描仪与标准化显色流程，把定量精度做到与 HPLC 相当的同时，还保留「一块板同时跑几十个样品」的通量优势——中药多组分同时定量、制剂批次一致性比对，常常点名要它。

TLC 的经典应用分布：**中药质量控制与指纹图谱**（多国药典收载法定方法）、**合成反应的在线监测**（点一个反应液，几分钟看产物是否生成）、**原料药与制剂的快速纯度筛查**、以及**滥用药物与毒物的初步筛查**。
<span class="marginnote">TLC 的「低成本高通量」在中药质控里尤其珍贵：一块 20 cm 板上可以并列点十几个批次样品，一张照片就能横向比较它们的指纹图谱是否一致——这种「同板同批对比」的思路，天然适合「一致性」类检验。</span>

### 展开剂选择：一个系统化的「笨办法」

初学者面对「用什么展开剂」最容易抓瞎，其实有一套标准策略可循。
硅胶板是**正相吸附**模式，展开剂极性从弱到强大致可按：正己烷（极弱）→ 氯仿 → 乙酸乙酯 → 丙酮 → 乙醇 → 甲醇（强）。
系统化的做法是：

1. **先试中等极性**（如乙酸乙酯：正己烷 1:1），看所有斑点的 $R_f$ 落点；
2. **全部贴着前沿**（$R_f$ 接近 1）——溶剂太强，降低极性（减少乙酸乙酯比例、多加正己烷）；
3. **全部挤在原点**（$R_f$ 接近 0）——溶剂太弱，升高极性（加大甲醇或丙酮比例）；
4. **个别斑点拖尾**——样品可能有酸碱基团解离，在展开剂里加**少量乙酸或三乙胺**抑制解离；
5. **斑点间距不够**——微调二元比例（如 9:1 → 8:2），或改用三元混合溶剂精细调节。

**这套「看 $R_f$ 落点、对向调极性」的闭环，正是把 TLC 经验迁移到制备柱色谱与 HPLC 方法开发时最值钱的本事。**

## 4 公式解析：Rf 与展开剂强度

$R_f$ 看似只是一个「距离比」，实际浓缩了吸附色谱的平衡。
分四步拆：

- **第一步，度量两个距离**：$d_x$ 是组分从起始线到斑点中心的距离，$d_f$ 是溶剂前沿从起始线爬升的总距离。展开停止时，两者之差 $d_f - d_x$ 就是组分「被固定相扣住」的那段距离。
- **第二步，理解比值**：$R_f$ 是组分「实际走了多少」与「能走多远」之比，本质是组分在流动相中度过的时间比例。吸附越强，组分越多在固定相上「歇脚」，$R_f$ 越小。
- **第三步，联系容量因子**：由 $R_f = 1/(1+k')$，$k' = 0$ 时 $R_f = 1$，$k' \to \infty$ 时 $R_f \to 0$——与柱色谱无缝对应。
- **第四步，驱动方法开发**：想提高某组分的 $R_f$（让它跑快点），就提高展开剂极性（正相板上更强的溶剂与组分竞争吸附位点）；想降低就减弱极性。逐一换溶剂、看斑点位置，就是平面色谱的「条件优化」全流程。

**一句话：$R_f$ 是「组分在流动相里的时间比例」，也是吸附色谱分离度的第一读数。**

## 5 辨析｜易错点：薄层色谱的常见坑

- **$R_f$ 是「条件值」不是「常数」**：它随吸附剂活性、湿度、展开剂组成、温度、甚至层析缸的溶剂饱和程度而变。跨板比较必须**同板同条件**，或改用与标准品并点的相对值——单报一个孤立数字没有意义。
- **点样不能浸入展开剂**：起始线必须在展开剂液面**之上**，否则样品直接溶解流失，板上只剩一个空斑。
- **层析缸要预先饱和**：缸内壁贴滤纸、先让展开剂蒸气布满整个空间，再放入薄板。不饱和时边缘爬得快、中间慢，出现「边缘效应」，同一组分在不同水平位置 $R_f$ 不一致。
- **分离不佳先改展开剂，别怪板**：斑点挤在原点→溶剂太弱；都贴前沿→溶剂太强；拖尾→可能样品过载或展开剂需加少量酸/碱抑制解离。
- **目视定量误差可达一个数量级**：斑点大小与浓度不是线性关系，正式定量请用扫描仪或转 HPLC。
- **同板同批是铁律**：$R_f$、斑点的「长相」都随板批、湿度、展开批次漂移。做方法确认或定性比对时，必须把标准品与样品**点在同一个板上展开**，跨板比对的结论不成立。
- **展开完成后立即显色**：溶剂挥发后板面暴露在空气中，某些化合物会氧化或斑点扩散。显色要趁板还「新鲜」，并及时拍照存档。
- **溶剂与层析缸要「专用」**：展开剂纯度波动会直接改变 $R_f$。用同一批试剂、同一只缸、同一套显色流程做完一整轮比较实验，是 TLC 可重现的最低成本。

## 6 小结

- TLC 是**平面色谱**：薄板固定相 + 毛细作用展开 + 显色观察，便宜、直观、可并行，最接近色谱的原始形态。
- **比移值 $R_f$** 是平面色谱的核心参数，$R_f = 1/(1+k')$ 与柱色谱无缝衔接；$R_f$ 在 0.2–0.8 之间分离最佳。
- 三大本领：**反应监测、方法预研、中药指纹图谱**；定量可升级为 HPTLC + 薄层扫描。
- 展开剂选择是**「看落点、调极性」的闭环**：全贴前沿就降极性、挤在原点就升极性、拖尾就加酸碱——这套经验可直接迁移到柱色谱方法开发。
- 常见陷阱：$R_f$ 是条件值、缸要饱和、点样勿浸液、同板同批、定量要仪器。
