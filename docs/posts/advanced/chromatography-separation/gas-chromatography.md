## 为什么先讲气相色谱

色谱家族里有两条主线：**气相色谱（gas chromatography, GC）**以气体做流动相，**液相色谱（LC）**以液体做流动相。
气相色谱先讲，有三个理由。第一，它的分离机制最「干净」——气体作为流动相只负责搬运，几乎不与固定相、样品发生作用，分离的纯度全部来自固定相对组分的保留差异，最贴合上一篇建立的保留理论。
第二，它的速率理论应用最直接——载气流速、柱温的每一个参数都能在范第姆特方程的框架下得到合理解释。
第三，它在环境、食品、石化与法医分析中覆盖面极广：汽油馏分分析、食品农残筛查、兴奋剂检测、城市空气的挥发性有机物监测，GC 都是主力。
<span class="marginnote">气相色谱的核心前提是样品「能气化、热稳定」。这与下一篇的高效液相色谱形成分工：GC 管挥发性小分子，LC 管不挥发、热不稳定甚至生物大分子。选哪种方法，第一步先看样品能不能安全地变成气体。</span>

## 1 仪器的气路：把样品送进色谱柱

气相色谱仪的物理结构围绕一条**气路**展开，从上图（GC 系统示意图）可以看清每个部件的职责：

**载气钢瓶与压力/流速控制**：载气通常是高纯氮气（便宜）、氦气（扩散系数大、分离效率高、惰性）或氢气（柱效最好但有安全隐患）。载气纯度一般要求 99.999%，微量水氧会损坏色谱柱与检测器。
- **进样器**：用微量注射器（手动或自动进样器）把样品注入气化室。进样瞬间要求**快**，让样品以「塞子」形式进入柱头，避免峰展宽。高浓度样品用**分流进样**（split，让大部分样品随分流气体排出，避免过载），痕量分析用**不分流进样**（splitless，让全部样品进入色谱柱富集）。
- **柱温箱**：加热并精确控温（±0.1°C）。柱温决定分配系数，从而决定保留与分离度——这是 GC 里最关键的旋钮。
- **色谱柱**：分离的舞台，见下一节。
- **检测器**：把流出组分变成电信号，见第三节。
- **数据工作站**：记录信号、积分峰面积、计算保留时间，最终给出色谱图与定量结果。

**柱温是 GC 里最有操控力度的参数**。等温分析（恒温）适合沸点范围窄的样品；
样品沸点跨度过大时，用**程序升温（temperature programming）**：低沸点组分在低温段就出峰、峰形尖锐，随着温度逐步升高，高沸点组分依次被「追赶」出来。
这本质上是在用温度扫描替代手动调优容量因子 $k'$，让每个组分都恰好落在最佳的保留窗口内。

还有一条 GC 的「后门」技术值得记下——**衍生化（derivatization）**。
许多样品太极性、太不挥发（脂肪酸、糖、酚、多羟基化合物），直接进柱会吸附在固定相上、拖尾甚至出不了峰。
用化学试剂把活泼氢「封住」（如用硅烷化试剂把 $\ce{-OH}$、$\ce{-COOH}$ 变成三甲基硅醚/酯、或用甲醇-硫酸把脂肪酸酯化成甲酯），样品就变得挥发、稳定、可分离。
**衍生化把一批「本该属于 LC 的样品」重新拉回 GC 的高效轨道**，是 GC 方法开发的常备招式。

## 2 色谱柱：开管柱与固定相的选择

GC 色谱柱分两大类：**填充柱（packed column）**与**开管柱（open tubular column）**，后者俗称毛细管柱。
戈莱（M.J.E. Golay）1958 年提出的开管柱让 GC 的分辨率发生革命：内径仅 0.2–0.5 mm 的毛细管中空管内壁涂敷一层固定相液膜，**没有填充颗粒的涡流扩散项（$A$ 项）**，柱效从数千塔板跃升到数十万塔板。

**毛细管柱柱效高的第二重原因在内径**：管子越细，组分分子在径向扩散到管壁固定相所需的路径越短，传质阻力项 $C u$ 被大幅压缩；
配合细管带来的高线速，一根不足 30 m 的毛细管柱就能完成常规 GC 的全部分离任务，理论塔板数可达数十万。

按固定相的形态，开管柱又分三种：

- **WCOT（壁涂开管柱）**：内壁直接涂一层固定相液膜，最常用；
- **PLOT（多孔层开管柱）**：内壁沉积多孔吸附剂薄层，用于分离永久气体与低沸点烃；
- **SCOT（载体涂渍开管柱）**：先附着一层惰性载体再涂固定相，液膜更厚、容量更大，现已少见。

固定相的选择遵循一句口诀：**相似相溶——极性固定相拖住极性组分，非极性固定相拖住非极性组分。** GC 固定相以**聚硅氧烷（polysiloxane）**为骨架，用不同的侧基取代甲基来调节极性：

| 固定相 | 组成 | 极性 | 典型用途 |
| --- | --- | --- | --- |
| OV-1 / SE-30 | 100% 二甲基聚硅氧烷 | 非极性 | 烃类、一般非极性样品 |
| DB-5 / HP-5 | 5% 苯基-95% 二甲基 | 弱极性 | 最通用，农药、环境样品首选 |
| OV-17 / DB-17 | 50% 苯基-50% 二甲基 | 中极性 | 含芳环、极性基团化合物 |
| DB-WAX / Carbowax | 聚乙二醇（PEG） | 强极性 | 醇、醛、脂肪酸、溶剂残留 |

**同一种样品换固定相，出峰顺序都可能反转**：非极性柱上先出非极性组分，极性柱上先出极性组分。
选柱实质是在「用哪类分子优先被挽留」之间做权衡。此外固定相还必须满足：热稳定性好（工作温度上限内不流失）、化学惰性（不与样品反应、不吸附强极性样品造成拖尾）。

## 3 检测器：四大金刚

GC 的检测器按「通用还是选择」分成几类，其中最常用的是下面四种：

- **FID 氢火焰离子化检测器（flame ionization detector）**：载气与氢气混合在喷嘴处燃烧，有机物在火焰中离子化产生微电流。它对几乎全部含碳有机物响应，灵敏度高、线性范围宽，是 GC 的「标准件」。但**对水、氮气、二氧化碳等无机物无响应**——这既是优点（不怕水峰干扰）也是局限。
- **TCD 热导检测器（thermal conductivity detector）**：利用被测组分与载气热导率的差异。它是**通用型、非破坏性**检测器，能检测包括水、永久气体在内的所有物质，但灵敏度比 FID 低两个数量级。
- **ECD 电子捕获检测器（electron capture detector）**：载气（常用氮气）在放射源下电离产生电子，含电负性基团（卤素、硝基）的分子捕获电子，使基流下降产生负信号。它对有机氯农药、多氯联苯（PCB）极其灵敏（可测 pg 级），是痕量环境分析的主力。
- **NPD 氮磷检测器（nitrogen–phosphorus detector）**：对含氮、含磷化合物高选择、高灵敏，常用于农残与药物分析。

**选择检测器 = 先问「目标组分有什么特征」**：测烃类用 FID，测农药用 ECD 或 NPD，测水分、永久气体用 TCD，要「一次定性」则接质谱（见《色谱-质谱联用》一篇）。
<span class="marginnote">FID、ECD 的响应机理都与「燃烧/电离化学」相关，属于火焰原子光谱与质谱电离技术的近亲。若你学过第四级《原子光谱》，会发现 TCD 的「差示测量」思想与原子吸收中的背景扣除一脉相承。</span>

定量方法也有固定套路，三种最常见：**外标法**（先做标样浓度-峰面积标准曲线，再反查样品）、**内标法**（加一个性质相近、不与样品反应的标准物，用「样品峰/内标峰」面积比定量，消除进样量波动与基体干扰）、**面积归一化法**（各组分峰面积除以总面积，适合「样品基本全已知」的纯度分析）。
其中**内标法**是复杂基质 GC 定量的首选——进样器的瞬间进样量难以完全重现，内标把这种波动「除」掉了。
<span class="marginnote">内标法与 LC-MS 里用同位素内标校正基质效应是同一思想的两代版本：找一个「影子标准物」，让所有系统误差同时作用在样品峰与内标峰上，比值定量天然抵消系统误差。这是整个定量分析的通用哲学。</span>

## 4 公式解析：科瓦茨保留指数

定性分析（确定「这个峰是谁」）是 GC 的核心需求之一。**保留时间本身不可比**——它随柱长、流速、柱温变化；
需要一种与具体仪器条件无关的标尺。1958 年科瓦茨（E. Kovats）提出用正构烷烃作标尺，定义**保留指数（retention index）$I$**：

$$I = 100\,n + 100\,\frac{\lg t'_{R(x)} - \lg t'_{R(n)}}{\lg t'_{R(n+1)} - \lg t'_{R(n)}}$$

分四步拆解：

- **第一步，定标尺**：选一列正构烷烃（$n$-alkanes），把含 $n$ 个碳的正构烷烃的保留指数**人为定义为 $100n$**：正己烷 $I=600$、正庚烷 $I=700$……指数随碳数线性增长。
- **第二步，用调整保留时间**：公式里的 $t'_{R} = t_R - t_M$，剔除死时间，让指数只反映「与固定相的作用」。
- **第三步，对数插值**：目标物 X 的调整保留时间落在碳数为 $n$ 与 $n+1$ 两个正构烷烃之间。对 $\lg t'_R$ 做线性插值，把 X「安放」进烷烃的标尺里。比如 $I=634$，意思是 X 的保留行为恰好处于 $C_6$ 与 $C_7$ 之间偏 $C_6$ 的位置。
- **第四步，归一化到 0–100 单元**：所以保留指数 $I$ 实质是**「X 相当于含多少碳的正构烷烃」**。它只依赖固定相与柱温，与柱长、流速、载气种类基本无关，因此可以在文献间比对。

**保留指数是 GC 定性三要素之一**：先比保留指数（与文献值吻合 ±1–3 个指数单位），再用标准物质确认，最后（必要时）用质谱鉴定。
三者相互印证，才能给出可信的定性结论。

## 5 辨析｜易错点：GC 不是万能的

- **进样量不是越多越好**：进样过载会显著降低柱效、峰形变平顶或拖尾。分流进样正是为了把「该进柱的量」控制在线性范围内。
- **载气流速不是越快越好**：由范第姆特方程，存在最优流速。开管柱常用氢或氦气在高线速下工作（此时 $B/u$ 项已小、$C$ 项可接受），但盲目提速仍会牺牲柱效。
- **保留时间随柱温变化剧烈**：程序升温下同一化合物在不同实验的 $t_R$ 会漂移，正因如此才需要**保留指数**这个「柱温无关」的定性标尺。
- **峰面积与浓度并非天然成正比**：FID 的响应因子随化合物结构（含碳比例、杂原子）变化，定量必须用**内标法/外标法校正**，直接拿峰面积比浓度会引入系统性误差。
- **样品必须能安全气化**：热不稳定（如部分农药、糖类）或不挥发的盐类，直接进 GC 会在气化室或柱头分解、残留。这些样品属于液相色谱的领域。

## 6 小结

- GC 以惰性气体为流动相，结构是「钢瓶—进样器—柱温箱—检测器—工作站」的气路，适合**可挥发、热稳定**样品。
- 开管（毛细管）柱没有涡流扩散项，柱效可达数十万塔板；固定相选择遵循**相似相溶**，聚硅氧烷系列覆盖从非极到极性。
- 检测器按「通用/选择」配置：FID 测有机碳、TCD 通用、ECD 捕电子（农药/PCB）、NPD 测氮磷。
- **科瓦茨保留指数**用正构烷烃做标尺，得到与柱长、流速无关的定性参数。
- 程序升温让沸点跨度大的样品每个组分都落在最佳保留窗口；**衍生化**（硅烷化、酯化）能把极性、难挥发样品拉回 GC 的轨道。
- 定量三法：**外标、内标、面积归一化**；复杂基质首选内标法，用比值抵消进样波动。

在下一节，我们把流动相从气体换成高压液体，迎接分析化学里使用率最高的分离手段——**高效液相色谱 HPLC**，并看它如何用「泵、柱、检测器」三件套解决 GC 束手无策的难题。
