## 为什么从双稳态开始

前面我们分析的都是「稳态在哪里、响应多快」，隐含的假设是系统对同一输入给出同一输出。但生物界充满了「同样条件下，结果却不唯一」的经典戏码：乳糖诱导下，每个大肠杆菌细胞要么完全表达 Lac 蛋白、要么完全沉默，**几乎没有中间态**；噬菌体 λ 感染一个细胞后，要么进入裂解、要么进入溶原，各走各的路。

这种「一个系统，两种稳定状态」的现象叫**双稳态（bistability）**。<span class="marginnote">双稳态：bistability，系统在同一参数下有且仅有两个稳定的不动点，从哪个状态出发决定了最终留在哪个状态。</span>它的价值是**记忆**：过去发生过的刺激决定了系统现在站在哪个状态上，刺激撤走，状态依旧。记忆是发育分化、免疫记忆、以及所有「细胞做出不可逆决定」的动力学基础。

## 1 双稳态的两个要件

双稳态不是随便什么反馈都能造出来的，它需要两个条件同时成立：

**要件一：正反馈。** 记忆的本质是「自己维持自己」——高状态能自我强化为高状态。没有正反馈，系统就没有「惯性」，外界刺激一撤，状态立刻弹回。Alon 的结论很明确：**没有正反馈，就没有双稳态**（单基因无自激活、无相互激活的普通网络永远只有一个稳定态）。

**要件二：陡峭的输入函数。** 光有正反馈还不够，反馈必须「足够强」。数学上的表现是输入函数要足够陡，Hill 系数 $n>1$（协同性）。我们第 4 节用图形法证明：当 $n=1$ 时，无论参数怎么调，系统都只有唯一的稳定态。<span class="marginnote">直觉：平滑的输入函数意味着「自我强化很柔和」，浓度稍微涨一点、激活也只涨一点，最终被降解拉回到唯一的平衡；只有输入函数陡到像「开关」，正反馈才可能把它推过临界点、卡在另一个平衡。</span>

**一个反直觉的推论**：正反馈的方向并不重要，重要的是「自我维持」的循环。无论是自激活（X 激活 X）、双蛋白互激活（X 激活 Y、Y 激活 X），还是互抑制（X 抑制 Y、Y 抑制 X 的 toggle switch），只要构成正反馈环，双稳态的结构要件就满足了。Alon 证明：**单节点自激活、双节点互激活、双节点互抑制，都能产生双稳态**——正反馈是「环」，不是「某种特定的画法」。

要件的必要性与充分性值得分开记：正反馈是双稳态的**必要条件**（没有它一定无双稳），陡峭性则决定**充分性**的边界——$n=1$ 时无论反馈多强都无双稳，$n$ 越大双稳窗口越宽。对自激活，$n>1$ 且 $\beta/(\alpha K)$ 超过阈值，双稳态才出现。**两个要件缺一不可**。

## 2 公式解析：用图形法找稳态

把输入信号记为 $S$，正自动调控方程写成：

$$
\frac{dX}{dt} = S\,\beta\,\frac{X^n}{K^n + X^n} - \alpha X
$$

**稳态满足「生产 = 降解」**，即两条曲线相交：

$$
S\,\beta\,\frac{X^n}{K^n + X^n} = \alpha X
$$

三步读懂这张图：

- **第一步，画两条曲线**：左边生产项是 S 形的 Hill 曲线（从 0 出发、饱和到 $S\beta$），右边降解项 $\alpha X$ 是过原点的直线。
- **第二步，数交点**：直线与 S 形曲线可能交 1 次或 3 次。交点就是不动点；当 $n>1$ 且 $\beta/\alpha$ 落在合适区间时，会出现 3 个交点——低、中、高三个稳态。
- **第三步，判稳定性**：中间那个交点处，S 形曲线的斜率**大于**直线的斜率——扰动被正反馈放大，它是不稳定的；低、高两个交点处曲线斜率小于直线斜率，扰动被拉回，它们是稳定的。<span class="marginnote">稳定性判据正是第 4 篇用过的线性化：$dx/dt\approx(\text{曲线斜率}-\alpha)x$。斜率差为负则衰减（稳定），为正则发散（不稳定）——同一套工具，换一个图形。</span>

**于是双稳态的条件可以精确表述为：正反馈（有 S 形生产曲线）+ 足够陡（$n>1$）+ 生产强度与降解匹配（$\beta/\alpha$ 适中）**。$n$ 越大，双稳态存在的参数窗口越宽、开关越「硬」——这就是为什么真实生物开关普遍依赖高协同性的多亚基蛋白。

数值算例（$n=2$、$K=1$、$\alpha=1$）：当 $S\beta=3$ 时，生产曲线 $3X^2/(1+X^2)$ 与直线 $X$ 相交于 $X=0$、$X\approx0.38$、$X\approx2.62$ 三个点——中间交点处曲线斜率大于直线斜率、不稳定，两侧稳定，系统双稳。当 $S\beta$ 降到 1.2，方程只剩 $X=0$ 一个交点，双稳态消失。**双稳态的存在窗口是狭窄的**：$n=2$ 时要求 $\beta/\alpha>2$，这解释了为什么真实的基因开关都在精心调参数。

图形法还揭示了双稳态的「临界诞生」方式：当参数从无双稳区扫过临界值，一对稳定—不稳定交点会成对冒出（数学上叫**鞍结分岔**）。因此双稳态不是逐渐增强的中间过程，而是开关性的突然出现——这解释了为什么生物的「分化决定」往往是二元的、不可逆的。

## 3 滞后：记忆的动力学面孔

现在让输入信号 $S$ 缓慢变化，看系统状态怎么走。结果就是下图这张著名的滞后回线：

![双稳态的滞后回线](/images/systems-biology/positive-feedback-bistability-memory-1.svg)

**S 从 0 增大**：系统沿低分支走，$X^*$ 缓慢上升；直到 $S$ 越过跳变点 $S_A$，低状态消失，系统**猛地跳到高状态**。
- **S 从 1 减小**：系统沿高分支走，$X^*$ 缓慢下降；直到 $S$ 低于**另一个**跳变点 $S_B < S_A$，高状态消失，系统**跳回低状态**。

关键就在 **$S_A \neq S_B$**：两个方向上的跳变点不同，中间夹着一个「两条分支都稳定」的区间。在这个区间里，系统是低还是高，**取决于它以前经历过什么**——这就是滞回（hysteresis），也就是记忆的动力学定义。<span class="marginnote">滞后回线这个名字来自磁学：铁磁材料的外磁场与磁化强度之间也有同样的回线。你会在第四级《统计物理与相变》里再次遇见它——相变与双稳态共享同一个「对称破缺」的数学骨架。</span>

滞后回线的「宽度」$S_A-S_B$ 也是一个设计参数：宽度越大，记忆越「顽固」——需要更强的反向刺激才能把状态拨回去；宽度越小，状态越容易被翻转。在发育里，早期分化往往要求「窄滞后」的多轮可逆试探，终末分化则要求「宽滞后」的一锤定音。**滞后的宽度，就是记忆的强度**。

滞后回线也是双稳态的实验签名，但测量时要小心：输入信号的变化必须足够慢（准静态），否则系统的动力学延迟会把回线「人为加宽」。正确的做法是把信号以极慢速度来回扫描，记录状态沿上下两条分支走；若扫描太快，看到的回线是动力学伪影而非真正的记忆。**区分「真滞后」与「测量伪影」，靠的是扫描速度**。

## 4 生物案例：记忆无处不在

**乳糖操纵子（lac operon）**：乳糖存在时，诱导物使 Lac 阻遏物失活，Lac 基因开启；Lac 蛋白又负责把乳糖转运进细胞——乳糖浓度与 Lac 蛋白之间构成正反馈。结果是「全开」或「全关」两个状态，中间态几乎不存在。
- **噬菌体 λ 的裂解/溶原决定**：两个相互抑制的转录因子 CI 与 Cro 构成互作双稳态开关（toggle switch）——CI 高就是溶原（安静潜伏），Cro 高就是裂解（复制裂解）。这是正反馈双稳态最著名的基因开关。<span class="marginnote">toggle switch 后来被工程化用于合成生物学（Gardner, Cantor, Collins 2000）：两个抑制基因互抑，用诱导物就能把状态「拨」过去——记忆开关从此可以被人为设计与写入。</span>
**细胞分化**：发育中的细胞一旦做出「向某类型分化」的决定，往往通过正反馈把决定锁死，因为**不可逆正是分化所需要的性质**。

lac 操纵子的双稳态还有一个演化上的解释：乳糖这种底物，与其「半开半合」地浪费运输蛋白，不如全开或全关。全关时省下的蛋白可以投入别的生长，全开时能充分发酵乳糖。**双稳态把「要不要使用某种食物」变成了一道二值决策**——中间态在演化上既不省资源、也不快响应，于是被选择淘汰。这与第 13 篇《多目标最优性》里 lac 的成本—速度权衡是同一枚硬币的两面。

噬菌体 λ 的开关还展示了一个精妙细节：CI 与 Cro 的互抑制不是简单的「谁多谁赢」，CI 还会**激活自己**（正反馈），这让已建立的溶原状态极其稳定——CI 浓度稍有波动，自激活会把它拉回来。**互抑制给出「两选一」，正反馈给「选定的那个加上保险」**，两者叠加才是真正的记忆开关。

## 5 群体平均的陷阱

双稳态在单细胞层面清晰可见，但如果你测一群细胞的平均表达量，看到的却可能是「中间值」——那是 30% 细胞在高状态、70% 在低状态的**平均**，而不是真的存在中间状态。这是双稳态研究的方法论要点：区分「混合群体的平均」与「单个细胞的分布」。单细胞技术（第 2 篇）因此成为验证双稳态的关键工具——看的是双峰分布，而不是均值。

群体平均的陷阱在工程里也有对应：如果你用「报告基因的群体均值」来优化一个合成开关的参数，你会被均值骗过去——必须用单细胞直方图看双峰。<strong>凡是宣称「中间态」的结果，先怀疑是不是群体平均的产物</strong>，这是双稳态研究给所有实验工作者的第一条纪律。

值得记住的是，双峰之间的相对比例本身是信息：在给定刺激强度下，处于高状态的细胞比例 $p$ 反映了群体层面的「开关概率」。如果把 $p$ 对刺激强度作图，会得到一条陡峭的 S 形曲线——<strong>单细胞层面看「开关」，群体层面看「比例」</strong>，两者互补，共同描述同一个双稳态系统。这也解释了为什么动力学结论必须到单细胞层面去检验。

## 6 辨析｜易错点：双稳态 ≠ 延迟 ≠ 随机

**辨析｜易错点：** 三个概念常被混为一谈。**双稳态**是同一参数下有两个稳定不动点（决定论意义下的多稳态）；**延迟**只是时间上的拖后，系统最终仍收敛到唯一稳态；**随机性（噪声）**会让系统在状态间抖动，但不会自动产生「两个吸引子」。判定双稳态的标准动作是：做**单细胞剂量—响应实验**，检查是否存在**双峰分布**与**滞后回线**——两者同时出现，才能下双稳态的结论。

## 7 术语速查表

| 术语 | 一句话含义 |
| --- | --- |
| 双稳态 | 同一参数下有两个稳定不动点 |
| 正反馈 | 状态自我强化的环（自激活 / 互激活 / 互抑制） |
| Hill 系数 $n$ | 输入函数陡峭度，$n>1$ 才可能双稳 |
| 滞后回线 | 上下跳变点不同的响应曲线 |
| 记忆 | 状态依赖历史，刺激撤走状态保留 |
| toggle switch | 双蛋白互抑制开关 |
| 鞍结分岔 | 一对稳定—不稳定交点成对冒出的临界点 |

## 8 小结

- **双稳态**：同一参数下系统有两个稳定状态，由**正反馈 + 陡峭输入函数（$n>1$）**共同产生。
- 图形法：稳态 = 生产曲线与降解直线相交；中间交点为不稳定，两侧为稳定。
- **滞后回线**：上跳点 $S_A$ 与下跳点 $S_B$ 不同，系统状态依赖历史——这就是记忆。
- 经典案例：lac 操纵子、噬菌体 λ 的 CI/Cro 开关、细胞分化。
- 验证双稳态必须用**单细胞数据**看双峰分布与滞后回线，群体平均会掩盖真实状态。
- 双稳态在临界参数处「突然出现」（鞍结分岔），而非逐渐增强——分化决定因此是二元的。
- 滞后回线的宽度 = 记忆的强度；测量时扫描速度必须够慢，否则看到的是动力学伪影。

在下一节，我们走出「两个状态」的静态世界，进入「一直变」的动态世界：当负反馈配上延迟，稳态会失稳，系统开始永远不落地地振荡——**生物振荡器与负反馈**。
