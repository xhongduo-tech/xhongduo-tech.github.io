## 为什么从傅里叶开始

前面几节，我们一直在**时域**里打转：采样、分帧、能量、过零率。时域特征便宜直观，但它们对语音的本质信息——**「哪些频率上有多少能量」**——只有粗糙的旁敲侧击（比如过零率）。要真正看清元音靠什么区分、共振峰在哪儿、噪声是哪段频率，必须进入**频域**。

这趟旅程的起点，是你第一级就见过的东西：**傅里叶分析**。从《极限》里「把周期信号拆成无穷多个谐波」的傅里叶级数，到给非周期信号用的傅里叶变换，再到数字信号处理里的离散傅里叶变换（DFT），一路都是同一句话：**任何信号都能被理解为不同频率的正弦波按权重的叠加**。本节把它落到「可编程」的形式——DFT，再给它装上时间坐标——短时傅里叶变换（STFT），让傅里叶真正能处理「一直在变」的语音。<span class="marginnote">傅里叶分析贯穿「从极限到大模型」的几乎每一站：极限里它是幂级数之外的第二种无穷和，信号与系统里它定义频谱，深度学习中卷积定理、频域数据增强都直接用它。这一节相当于把这条主线接到语音上来。</span>

## 1 从傅里叶级数到离散傅里叶变换

先回顾级数。对周期信号 $x(t)$，傅里叶级数说它可以写成基频整数倍的正弦波之和。推广到非周期信号，求和变成积分，就是**傅里叶变换**：

$$X(\omega) = \int_{-\infty}^{+\infty} x(t)\, e^{-j\omega t}\, dt$$

但我们手里不是连续函数，而是一个**采样序列** $x(0), x(1), \dots, x(N-1)$。对有限长序列，把积分换成求和，就得到**离散时间傅里叶变换（DTFT）**：

$$X(e^{j\omega}) = \sum_{n=-\infty}^{+\infty} x(n)\, e^{-j\omega n}$$

注意 DTFT 里频率 $\omega$ 是**连续**的——它把一段序列映射到一整条连续频率轴。计算机没法表示连续轴，于是再进一步，只在这条轴上取 $N$ 个等间隔的采样点，这就是**离散傅里叶变换（DFT）**：

$$X(k) = \sum_{n=0}^{N-1} x(n)\, e^{-j 2\pi k n / N}, \qquad k = 0, 1, \dots, N-1$$

**一句话理清三者的关系：DFT 是 DTFT 在频域上的均匀采样，而 DTFT 是傅里叶变换的离散版本。** 语音处理里几乎不直接碰连续傅里叶变换，我们操作的都是 DFT——准确说，是它的快速实现 **FFT**。

## 2 公式解析：DFT 在算「信号里有多少频率 k」

$$
X(k) = \sum_{n=0}^{N-1} x(n)\, e^{-j 2\pi k n / N}
$$

- **第一步，读懂 $e^{-j 2\pi k n / N}$**：这是一支频率为「第 $k$ 个频点」的复正弦波，在时间采样点 $n$ 上的取值。频率不是用弧度而是用整数 $k$ 编码的——$k$ 每加 1，这支正弦波在一个帧长内多振荡一周。
- **第二步，相乘 $x(n) \cdot e^{-j 2\pi k n / N}$**：把信号与这支参考正弦波逐点相乘。相乘的语义是**相关**：如果信号里恰好含有这个频率的分量，乘积会「叠加得整齐」，反之则正负相消。
- **第三步，求和**：把所有 $n$ 上的乘积加起来。**和很大 ⟺ 信号里这个频率的分量强；和接近 0 ⟺ 信号里没有这个频率。** 于是 $X(k)$ 就是「信号中频率 $k$ 的强度」，是个复数，模长 $\lvert X(k)\rvert$ 是幅度，辐角是相位。
- **第四步，换算成物理频率**：第 $k$ 个频点对应的真实频率是

$$f_k = k \cdot \frac{f_s}{N}$$

以 16 kHz 采样、400 点一帧为例，$f_1 = 16\,000/400 = 40$ Hz——即**每个频点代表 40 Hz 宽的频带**，$k = 250$ 就是 10 kHz。<span class="marginnote">对实信号，$k = N/2$ 以上的频点与前半部分是共轭对称的（幅度相等），所以实际只用 $k = 0, \dots, N/2$，对应频率范围 $0 \sim f_s/2$——恰好是采样定理允许的带宽。你要是忘了为什么，回去翻《采样与量化：奈奎斯特定理与混叠》。</span>

## 3 频率分辨率与栅栏效应

DFT 有一个极其重要的工程参数：**频率分辨率**。相邻两个频点之间的间隔是

$$\Delta f = \frac{f_s}{N}$$

**帧越长（N 越大），频率分辨率越细；帧越短，频点越粗。** 这就是语音处理里帧长「不能随便选」的根本原因。

**辨析｜易错点：零填充（zero padding）不提高分辨率。** 有人以为给 400 点补零到 800 点，频谱就「更细」了。补零只是把 DTFT 曲线上的采样点加密——峰的位置看得更准（降低**栅栏效应**），但峰的宽度完全没变，因为真正决定分辨率的**有效窗长**还是 400 点。分辨率只由「窗内有多少真实数据」决定，补零是插值，不是信息。<span class="marginnote">栅栏效应：FFT 只看得到频点上的值，真正的谱峰可能恰好落在两个频点之间，像隔着栅栏看风景。零填充把栅栏加密，但风景本身（分辨率）不变。</span>

那帧长能无限加长吗？不能。语音是**非平稳**的，帧太长会把不同音的频谱混在一起平均掉——这就是下一节要讲的「时间—频率矛盾」。

## 4 STFT：给傅里叶装上时间坐标

DFT 一次只能处理一段固定信号，得到的是「整段平均」的频谱。可语音每个瞬间都在变：/a/ 和 /i/ 的频谱完全不同，一句话里没有「全局频谱」这回事。

解法很朴素：**既然我们早就把语音切成了帧，那就对每一帧分别做 DFT**，得到「每一时刻的频谱」。把窗的位置写进公式，就是**短时傅里叶变换（STFT）**：

$$X(m, k) = \sum_{n=0}^{N-1} x(n + mH)\, w(n)\, e^{-j 2\pi k n / N}$$

其中 $m$ 是帧序号，$H$ 是帧移（hop），$w(n)$ 是窗函数。$X(m,k)$ 是一个二维数组：一维是时间（帧），一维是频率（频点），值是该时刻该频率上的幅度——这就是「时间—频率表示」。

## 5 公式解析：STFT 的三重嵌套

$$
X(m, k) = \sum_{n=0}^{N-1} x(n + mH)\, w(n)\, e^{-j 2\pi k n / N}
$$

- **第一步，取帧 $x(n + mH)$**：帧移 $H$ 决定每隔多少样本取一帧。$H$ 越小，帧与帧重叠越多，时间轴越密——重叠通常取 50%–75%（$H = N/2$ 或 $N/4$）。
- **第二步，乘窗 $w(n)$**：把帧截出来还不够，还要用窗函数削边，抑制「截断造成的频谱泄漏」。这正是前面《分帧与加窗》那一节选窗的全部意义：矩形窗分辨率好但旁瓣大，汉明窗旁瓣小但主瓣略宽。
- **第三步，做 $N$ 点 DFT**：把加窗后的这一帧变换到频域，得到第 $m$ 帧的 $N$ 个频点。
- **第四步，移动 $m$ 重复**：窗滑过整段语音，每移动一次得到一个频谱列。把所有列并排放好，就是一个「时间—频率」的二维矩阵。

**核心代价：时间分辨率与频率分辨率此消彼长。** 帧长 $N$ 决定频率分辨率 $\Delta f = f_s/N$，同时窗口的时间跨度 $T_w = N/f_s$ 就是时间分辨率的下限。两者乘积

$$\Delta f \cdot T_w \approx 1$$

是常数——**你想把频率看得更细，就必须看更长时间窗内的信号，时间定位就更模糊；想精确定位某个瞬间，频率就只能看个大概。** 这是傅里叶分析的固有约束，不是实现问题，语音里称它为「时间—频率不确定关系」。<span class="marginnote">这个「乘积为常数」的约束，在物理上对应海森堡不确定性原理，在信号处理里是窗函数设计的根本出发点。窄带/宽带语谱图的分野（下一节），就是对这一矛盾的两端分别押注。</span>

## 6 用 STFT 初看语音

拿到 $X(m,k)$ 后，最常用的呈现是它的幅度平方或分贝值。先凭直觉看两个现象：

- **浊音帧**：频谱呈现「梳子状」——基频及其整数倍处出现等间隔的尖峰（谐波），尖峰间隔就是基频 $f_0$。
- **清音帧**：频谱平坦、杂乱，没有明显的等间隔尖峰，能量铺在中高频。

谐波尖峰的**外包络**隆起处，就是**共振峰**——元音的身份就藏在这里。下一节我们会把这些信息画成一张图来读。

STFT 的实现核心就三步：取帧、加窗、FFT。用 SciPy 可以一行完成，用 NumPy 也能看清每一步：

```python
import numpy as np

def my_stft(x, win, hop):
    """逐帧加窗做 FFT，返回 帧数 × 频点数 的幅度谱"""
    N, H = len(win), hop
    frames = np.lib.stride_tricks.sliding_window_view(x, N)[::H]  # 取帧（带重叠）
    X = np.fft.rfft(frames * win, axis=1)                          # 加窗 + 只取 0~fs/2
    return np.abs(X)

x = ...                                        # 16 kHz 的一段语音
win = np.hanning(400)                          # 25 ms 汉明窗
H = my_stft(x, win, hop=160)                   # 帧移 10 ms（60% 重叠）
```

`H` 的每一行是第 $m$ 帧的幅度谱（对应 $X(m,k)$ 取模），行与行之间相隔 10 ms。把它画成图——**这就是下一节的语谱图**。

## 7 小结

- **DFT**：有限长序列到离散频率的映射，$X(k) = \sum_n x(n)e^{-j2\pi kn/N}$；工程上用 FFT 高效实现。
- **DTFT 与 DFT**：前者频率连续、后者是其在 $N$ 个点上的采样；**零填充只插值、不提高分辨率**。
- **频率分辨率** $\Delta f = f_s/N$：帧越长，频点越细；但语音非平稳，帧不能无限长。
- **STFT**：对每一帧分别 DFT，得到时间—频率矩阵 $X(m,k)$；窗长决定时间/频率分辨率的权衡。
- **时间—频率矛盾**：$\Delta f \cdot T_w \approx 1$，不可兼得。

在下一节，我们把 STFT 的结果画成一张图——**语谱图（Spectrogram）**，学会像看照片一样读懂一段语音：共振峰、基频、清音噪声、爆破段，全部一目了然。
