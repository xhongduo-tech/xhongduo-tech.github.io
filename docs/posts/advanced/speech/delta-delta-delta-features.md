## 为什么从 Delta 特征开始

前几节我们得到的 MFCC、FBank、PLP 都是**静态特征**：每一帧被独立地压缩成一组系数。但语音是**运动**的——共振峰在滑移、基频在起伏、能量在起落。**关键信息往往不在某一帧的数值里，而在帧与帧之间的变化里。**

这就是 **Delta 特征（动态特征）** 存在的理由。一阶差分（Delta，记为 $\Delta$）刻画**特征值的变化速度**，二阶差分（Delta-Delta，记为 $\Delta\Delta$）刻画**变化速度的变化**——类比物理里的速度与加速度。<span class="marginnote">直觉类比：只看一帧 MFCC，你只能知道「此刻声道是什么形状」；加上 Delta，你才知道「声道正在往哪个方向变」；再加上 Delta-Delta，才知道「变化本身是在加速还是减速」。这恰恰对应语音中「过渡音」的信息——声母到韵母的过渡、塞音爆发瞬间的快速变化。</span>

MFCC 的标准用法是 **13 维静态 + 13 维 Delta + 13 维 Delta-Delta = 39 维**。为什么非要翻三倍维度？答案在下一节。

## 1 差分如何计算：从简单差到回归斜率

最朴素的 Delta 是相邻帧差分：

$$\Delta c_t = c_t - c_{t-1}$$

但相邻帧差分**对噪声极其敏感**：帧与帧之间本来就有随机的谱抖动，一差分把高频噪声放大了。实践中更常用的是**带窗的线性回归斜率**——用当前帧前后各 $L$ 帧，拟合一条直线，取斜率作为 Delta。这是由福田（Sadaoki Furui）在语音识别中推广的做法。

### 1.1 带窗回归公式

设 $c_t$ 是第 $t$ 帧的静态特征，取当前帧前后各 $L$ 帧（总窗长 $2L+1$），Delta 定义为：

$$
\Delta c_t = \frac{\sum_{\tau=1}^{L} \tau\, (c_{t+\tau} - c_{t-\tau})}{2 \sum_{\tau=1}^{L} \tau^2}
$$

其中 $L$ 常取 2，即用前后各 2 帧、共 5 帧来估计。

**辨析｜易错点：分子里的 $\tau$ 是权重，不是乘在时间上。** 这个公式的分子是「加权差的求和」：$\tau$ 越大，相隔越远的帧对斜率的贡献越大。分母 $2\sum \tau^2$ 是归一化常数，保证当数据严格落在一条直线上时，$\Delta c_t$ 恰等于该直线的斜率。<span class="marginnote">为什么不是简单平均？因为「简单平均相邻差」等价于对直线也能给出斜率，但估计方差大；按 $\tau$ 加权相当于最小二乘回归的斜率，在「帧间真有线性趋势」的假设下是更优的估计。公式里的 $2\sum\tau^2$ 正是最小二乘解的归一化因子。</span>

### 1.2 Delta-Delta

对 Delta 序列再套一次同样的公式，就得到二阶差分：

$$
\Delta\Delta c_t = \frac{\sum_{\tau=1}^{L} \tau\, (\Delta c_{t+\tau} - \Delta c_{t-\tau})}{2 \sum_{\tau=1}^{L} \tau^2}
$$

它刻画特征轨迹的**曲率**。比如基频 $f_0$ 在重音处的快速上升又回落，$\Delta\Delta$ 会在转折处出现明显响应。

## 2 公式解析：为什么加权回归优于简单差分

我们用一个具体例子感受公式。取 $L=2$，则：

$$\Delta c_t = \frac{1\cdot(c_{t+1}-c_{t-1}) + 2\cdot(c_{t+2}-c_{t-2})}{2\cdot(1+4)} = \frac{(c_{t+1}-c_{t-1}) + 2(c_{t+2}-c_{t-2})}{10}$$

逐步拆解：

- **第一步，看窗结构**：公式用到了 $c_{t-2}, c_{t-1}, c_{t+1}, c_{t+2}$ 四帧（不含当前帧 $c_t$）。**当前帧自身的值不进入 Delta**——Delta 描述的是「当前位置的切向趋势」，而不是位置本身。
- **第二步，看权重分配**：相距 1 帧的差权重为 1，相距 2 帧的差权重为 2。**相隔越远，权重越大**，这正是线性回归斜率的特征：远点对直线的斜率贡献更大。
- **第三步，看分母 10**：$2\sum_{\tau=1}^2 \tau^2 = 2(1+4)=10$。它的作用是**让 $\Delta$ 的量纲与 $c$ 一致**（都是「每帧的变化量」），并保证线性趋势下输出正好等于真实斜率。
- **第四步，理解对称性**：分子里 $c_{t+\tau} - c_{t-\tau}$ 是**反对称**的——时间反演（正着看变倒着看）会让 Delta 变号。这正是「速度」应有的性质：倒放语音，趋势反向。

**为什么这套加权比简单差分好？** 简单差分 $c_t - c_{t-1}$ 只用了两帧，估计方差大；带窗回归用了 $2L$ 帧，等价于先平滑再差分，**在噪声下更稳**。代价是引入 $L$ 帧延迟，这在流式系统里需要考虑。<span class="marginnote">延迟问题：真实流式识别里，算第 $t$ 帧的 Delta 需要看到 $t+L$ 帧，即未来数据。所以流式系统要么用因果窗（只用过去帧），要么接受 $L$ 帧的初始化延迟。这个「因果 vs 非因果」的取舍，在端到端流式识别（chunk-based）里还会反复出现。</span>

## 3 边界处理：首尾帧怎么办

窗函数要求前后各 $L$ 帧，但序列首尾没有那么多邻居。常见处理有三种：

1. **截断**：首尾各去掉 $L$ 帧，只输出中间部分。最干净，但特征长度变短，且丢失句首信息（句首常是重要的静音/清音边界）。
2. **补零**：对缺失的帧用零填充。实现简单，但会引入「假趋势」——首帧的 Delta 会被向零拉。
3. **镜像填充**：用边界帧镜像复制。比补零温和，但没有真实的未来信息。

**辨析｜易错点：首尾 Delta 是「合法的小值」还是「污染」？** 补零会让首帧 Delta 偏小且方向失真；对语音识别影响虽小，对端点检测、韵律分析等对首尾敏感的任务则要小心。**工程上推荐截断或镜像，并在标注特征长度时明确「有效区间」。**

## 4 从静态到动态：39 维特征怎么拼

实践中把静态与动态特征**沿特征维拼接**：

$$\mathbf{x}_t = \bigl[\, \mathbf{c}_t^{\mathsf{T}},\; \Delta\mathbf{c}_t^{\mathsf{T}},\; \Delta\Delta\mathbf{c}_t^{\mathsf{T}} \,\bigr]^{\mathsf{T}} \in \mathbb{R}^{39}$$

- 13 维 MFCC → 39 维标准特征（含 $C_0$ 与否因系统而异）。
- FBank（40 维）→ 120 维（40 + 40 + 40）。

**为什么值得把维度翻三倍？** 因为动态特征携带的**时间轨迹信息**对区分音素至关重要——辅音到元音的过渡、塞音的爆发、音调的升降，全靠帧间变化表达。**加入 Delta 通常能显著降低词错误率（WER），代价却只是维度翻倍。**<span class="marginnote">这也解释了为什么传统 GMM-HMM 系统几乎必用 39 维而非 13 维 MFCC。到端到端模型（RNN-T、Conformer）时代，网络内部的时间建模能力增强，有些系统不再显式拼接 Delta——但 log-Mel + Delta 的拼接仍是许多基线系统的默认配置。</span>

一个 Python 示意（用带窗回归计算 Delta）：

```python
import numpy as np

def delta(feat, L=2):
    """带窗线性回归计算 Delta 特征（Furui 1986）。
    feat: (T, D) 静态特征矩阵，返回同形状的 Delta 特征。
    """
    T, D = feat.shape
    out = np.zeros_like(feat, dtype=np.float64)
    denom = 2 * sum(tau ** 2 for tau in range(1, L + 1))   # 归一化常数
    for t in range(T):
        for tau in range(1, L + 1):
            # 边界夹取（等效镜像填充），避免越界
            idx_p = np.clip(t + tau, 0, T - 1)
            idx_m = np.clip(t - tau, 0, T - 1)
            out[t] += tau * (feat[idx_p] - feat[idx_m])
        out[t] /= denom
    return out
```

注意代码里用 **`np.clip`** 做了**边界夹取**（等效镜像填充），避免越界。真实库（如 **`librosa.feature.delta`**）还会提供不同的边界策略。

## 5 Delta 特征的局限与替代

**辨析｜易错点：Delta 不是「时间信息」的全部。** 它只捕捉**局部线性趋势**（$2L+1$ 帧窗口内），捕捉不了长程的韵律起伏（如整句语调的升降、停顿时长）。想要长程信息，要靠后面章节讲的**韵律特征**（基频曲线、能量包络、时长）或深度模型的注意力机制。

另一个需要注意的点：**Delta 对噪声其实敏感。** 带窗回归虽比简单差分稳，但它本质是高频增强——把「帧间差异」放大。在低信噪比环境下，Delta 特征携带的噪声可能比信号多。**因此有些降噪系统会对 Delta 特征单独做时域平滑，或在差分之前先对静态特征做 CMVN。**<span class="marginnote">这也解释了特征流水线的顺序智慧：通常先做倒谱均值方差归一化（CMVN），再算 Delta——否则信道偏移会被差分放大。具体顺序与细节，留给本专题《CMVN 与特征增强》那节。</span>

## 6 小结

- **Delta 特征 = 特征值的变化速度**，Delta-Delta = 变化速度的变化（类比速度与加速度）。
- **常用计算是带窗线性回归斜率**，窗长 $2L+1$（$L$ 常取 2），比简单相邻差分更抗噪。
- **当前帧自身不参与 Delta**：$\Delta c_t$ 用的是 $c_{t\pm1}, c_{t\pm2}$，描述趋势而非位置。
- **首尾需要边界处理**：截断、补零或镜像填充；对首尾敏感的任务要谨慎。
- **39 维 = 13 静态 + 13 Delta + 13 Delta-Delta**，是传统语音识别的事实标准；端到端模型逐渐不再显式拼接，但 Delta 仍是理解「把时间信息编码进特征」的关键一环。
