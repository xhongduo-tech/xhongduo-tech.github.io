## 为什么从临界频带开始

上一课我们看到了人耳的两条线索：基底膜把频率按对数铺开（Greenwood 函数），而强声会掩蔽弱声（掩蔽曲线）。这一课把这两条线索收拢成一个关键概念：**人耳的频率分辨率不是恒定的，而是随频率变化的**。

这个「不恒定」直接决定了一件事——**物理频率的尺子，在人耳里并不是直的**。把 100 Hz 到 200 Hz 的间隔，与 4000 Hz 到 4100 Hz 的间隔放在人耳里比，后者的「感知距离」要小得多。于是语音特征提取的整个思路被改写：**不要直接用物理频率，而要用「感知频率」的刻度去划分频带**。Mel 刻度与 Bark 刻度，就是人类为「感知频率」造出的两把尺子；而它们都是临界频带的衍生物。

这一课是通往 MFCC 与滤波器组特征的最后一级台阶，也是理解后面一切听觉特征（FBank、PLP）的钥匙。

## 1 临界频带：听觉的「频率分辨率」

**核心概念：临界频带（critical band）**——把一个人耳频率分辨率的基本单元，近似看作一个以某个中心频率为轴的**听觉滤波器**，这个滤波器的带宽就叫临界带宽。频率差小于一个临界带宽的两个声音，落在同一个听觉滤波器里，会被「捆绑」在一起处理。

临界频带是怎么测出来的？经典实验之一：让一个噪声带掩蔽一个纯音，逐步加宽噪声带（保持总声压不变）。当带宽小于某个值时，掩蔽量不变；一旦带宽超过某个临界值，掩蔽量开始增大。这个转折点对应的带宽，就是该中心频率处的**临界带宽**。

测量结果显示，临界带宽随中心频率明显变化：

- **低频段（< 500 Hz）**：临界带宽大约恒定在 100 Hz；
- **高频段（> 500 Hz）**：临界带宽约为中心频率的 20%（约 1/5 个八度）。

也就是说，人耳在 1 kHz 处的分辨率大约是 160 Hz，在 8 kHz 处则达到约 1.6 kHz。<span class="marginnote">直觉对照：一架钢琴的最低音（约 27 Hz）与相邻键相差约 1.6 Hz，人耳能分辨；但若把两个频率放到 8000 Hz 附近，差 1000 Hz 都可能被听成「同一个音高」。临界频带把这种「越往高频越粗」的分辨率，从现象变成了数值。</span>

把整个人耳范围（约 20 Hz–16 kHz）按临界带宽切分，能切出大约 **24 个临界带**。这个「24」不是巧合——它就是 Bark 刻度的总数。

## 2 Mel 刻度：以「感知音高」为标尺

1937 年，史蒂文斯（S. S. Stevens）、沃尔克曼（Volkmann）与纽曼（Newman）通过心理物理实验测出：人耳对音高的感知不是线性的，于是定义了一个新的音高单位——**mel**。

实验方法很朴素：让听者把一段频率分成两半——「听起来像是 2000 Hz 一半高的音，是多少 Hz？」结果发现，物理上的一半（比如 4000 Hz）并不是感知上的一半；感知上的一半要低得多。把大量这样的判断连起来，就得到「感知音高 vs 物理频率」的曲线，这就是 **Mel 刻度**。

Mel 刻度的定义锚点：**1000 Hz 的纯音被定义为 1000 mel**。给定物理频率 $f$（Hz），常用的换算公式是：

$$m = 2595\, \log_{10}\!\left(1 + \frac{f}{700}\right)$$

**重点：Mel 刻度在低频段近似线性、高频段近似对数。** 它是「把物理频率重排成感知频率」的第一把通用尺子，后来几乎所有的听觉特征（FBank、MFCC）都在用它。

## 3 Bark 刻度与 ERB

Mel 刻度来自「音高」的主观测量；Bark 刻度则直接来自**临界频带的生理测量**。茨维克（Zwicker，1961）把 24 个临界带依次编号，得到 **Bark 刻度**：1 Bark = 一个临界带。换算公式常用：

$$z(f) = 13\,\arctan(0.00076 f) + 3.5\,\arctan\!\left(\left(\frac{f}{7500}\right)^2\right)$$

其中 $f$ 是频率（Hz），$z$ 是 Bark 值（0–24）。

Mel 与 Bark 出自两条不同的实验路线（主观音高 vs 掩蔽带宽），但数值上惊人地接近——上图两条曲线几乎重合。<span class="marginnote">这不是巧合：临界带本质上也是基底膜上「约等于一个固定长度」的频率区间，而基底膜位置本来就近似频率的对数。音高感知、掩蔽带宽、基底膜位置，三者共同指向同一条「感知对数曲线」，只是测量入口不同。</span>

另一个常用的相关量是 **ERB（等价矩形带宽，Equivalent Rectangular Bandwidth）**，由 Glasberg 与 Moore（1990）给出：

$$ERB(f) = 24.7\,(4.37\, f_{kHz} + 1)\ \text{Hz}$$

ERB 与临界带宽含义相近（都是「听觉滤波器带宽」），但更贴合近年实验数据，在语音增强、助听器算法里使用更广。

**辨析｜易错点：** Mel 与 Bark 不是「同一个东西的两种写法」。Mel 回答「这个音听起来有多高」，Bark 回答「这个音占了多少个听觉滤波器」。两者数值相近，但来源与用途不同——Mel 主导特征提取（MFCC），Bark 主导掩蔽建模与响度计算。工程里可以混用，但要清楚自己在测哪一边。

## 4 公式解析：Mel 公式

把本课最重要的一条公式拆开：

$$m = 2595\, \log_{10}\!\left(1 + \frac{f}{700}\right)$$

- **第一步：为什么是「对数」。** 基底膜的位置大致是频率的对数（上一课 Greenwood 函数的反解），所以「感知音高」也近似频率的对数。Mel 公式里的 $\log_{10}$，正是把这一生理事实编码进去。高频段每翻一倍频率，mel 只增加约一个固定量。
- **第二步：为什么是「+1」与「700」。** $+1$ 保证 $f=0$ 时 $m=0$（零频率的音高为零），对数不出现负值；常数 700 决定曲线在低频段多快进入「对数区」——它是实验拟合出来的，让曲线在约 1 kHz 以下近似线性、以上近似对数。这是 2595 与 700 两个数的来路。
- **第三步：验证锚点。** 代入 $f=1000$：$m = 2595\log_{10}(1 + 1000/700) = 2595\log_{10}(2.4286) \approx 1000$。**1000 Hz 正好落在 1000 mel**——Mel 刻度的定义锚点被公式精确还原。代入 $f=700$：$m = 2595\log_{10}2 \approx 781$。
- **第四步：怎么用它。** 把物理频率换算成 mel 后，在 mel 轴上**均匀**划间隔，再映射回物理频率，就得到一组「感知均匀」的频带边界——低频处滤波器密而窄，高频处稀而宽。这正是下面 Mel 滤波器组的做法。

```python
import numpy as np

def hz_to_mel(f):
    """物理频率 → Mel 刻度：m = 2595·log10(1 + f/700)。"""
    return 2595 * np.log10(1 + f / 700)

def mel_to_hz(m):
    """Mel 刻度 → 物理频率（Mel 公式的反解）。"""
    return 700 * (10 ** (m / 2595) - 1)

# 在 mel 轴均匀取 26 个三角滤波器的边界，再映射回物理频率
n_mels, fmin, fmax, n_fft = 26, 0.0, 8000.0, 512
mel_points = hz_to_mel(np.linspace(fmin, fmax, n_mels + 2))
hz_points = mel_to_hz(mel_points)
bins = np.floor((n_fft + 1) * hz_points / fmax).astype(int)  # 对齐到 FFT bin
```

## 5 从刻度到特征：Mel 滤波器组（FBank / MFCC 的前奏）

临界频带与 Mel 刻度不是纸上谈兵，它们直接生成了语音识别里最经典的两种特征——**FBank** 与 **MFCC** 的前半段。

构造 **Mel 滤波器组**的流程是：

1. 把信号的频谱幅度 $|X(k)|$ 取出来；
2. 在 mel 轴上均匀放置 $M$（通常 26 或 40）个三角滤波器；
3. 把每个滤波器与频谱相乘、求和，得到该频带的能量。

$$E_j = \sum_{k} W_j(k)\, |X(k)|^2, \qquad j = 1, 2, \dots, M$$

其中 $W_j(k)$ 是第 $j$ 个三角滤波器在频点 $k$ 处的权重。因为滤波器在 mel 轴上等距，所以低频带窄而多、高频带宽而少——这与人耳临界频带完全一致。取对数后的 $M$ 维向量就是 **log-Mel（FBank）特征**；再做一次离散余弦变换（DCT）去掉维度间的相关性，就得到 **MFCC**。<span class="marginnote">MFCC 与 FBank 的完整推导分别对应本专题《梅尔频率倒谱系数（MFCC）完整流程》与《滤波器组特征（FBank）》两课。这里先立住一个核心直觉：<strong>「感知刻度 + 滤波器组」是所有听觉特征共同的骨架</strong>——Mel、Bark、ERB 只是三把略有出入的尺子。</span>

## 6 小结

- **临界频带**是人耳频率分辨率的单元：低频段约 100 Hz，高频段约为中心频率的 20%；全范围约 24 个临界带。
- **Mel 刻度**（音高感知）：$m = 2595\log_{10}(1 + f/700)$，锚点在 1000 Hz ≈ 1000 mel，低频近似线性、高频近似对数。
- **Bark 刻度**（临界带编号）：$z = 13\arctan(0.00076f) + 3.5\arctan((f/7500)^2)$，共 24 Bark；**ERB** 是等价矩形带宽，$ERB(f) = 24.7(4.37 f_{kHz}+1)$ Hz。
- Mel 与 Bark 数值相近但来源不同：一个测音高，一个测频带；工程上 Mel 主导特征提取，Bark 主导掩蔽/响度建模。
- **Mel 滤波器组**在 mel 轴均匀放置三角滤波器，输出 FBank，再经 DCT 得 MFCC——听觉特征由此起步。

在下一节，我们从「人怎么听」回到「机器怎么听」，把这一课的两把尺子收进第一套完整特征：**梅尔频率倒谱系数（MFCC）完整流程**。
