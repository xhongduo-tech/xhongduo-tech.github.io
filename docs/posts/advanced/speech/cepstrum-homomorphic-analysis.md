## 为什么从倒谱开始

上一节我们用 LPC 把声道包络「拟合成一条曲线」。这一节走另一条路，它来自一个更本质的观察：**语音 = 激励 × 声道（卷积）**。既然语音是卷积出来的，那能不能把它「反卷积」回激励和声道两半？倒谱（cepstrum）就是为回答这个问题而生的工具——它用一次取对数，把**卷积变成加法**，让「拆开语音」变成「在一条新轴上把两部分分开」。<span class="marginnote">「倒谱」一词是拆散 spectrum 重排出来的（spectrum → cepstrum），发明者把同样手法用在横轴上：频率 → 倒频率（quefrency），滤波 → 倒滤波（liftering）。这些「反着念」的造词是在提醒你：倒谱里的每个量都与谱分析一一对应，只是站到了「谱的对数再变换」这一层。</span>

倒谱分析的两个招牌应用，后面几节会反复用到：**一是估计谱包络**（把倒谱低段截回来就得到光滑包络，和 LPC 殊途同归）；**二是测基频**（浊音的倒谱在「倒频率 = 基音周期」处有一个尖峰，一找就能量出 $f_0$）。它还是理解「声道与声源」关系的第二把钥匙。

## 1 卷积，为什么难拆

时域里语音是卷积：

$$s(n) = e(n) * h(n)$$

其中 $e(n)$ 是声门激励，$h(n)$ 是声道冲激响应。「拆开」就是给定 $s(n)$，恢复 $e(n)$ 和 $h(n)$——这是**盲解卷积**，一般很难。但傅里叶变换给了我们一个台阶：时域卷积 = 频域乘积。

$$S(k) = E(k) \cdot H(k)$$

乘法比卷积好拆，但还不够——乘积里 $E$ 和 $H$ 是「缠在一起」的。**关键一步：取对数，乘积变成加和：**

$$\log \lvert S(k)\rvert = \log \lvert E(k)\rvert + \log \lvert H(k)\rvert$$

加和的两个部分，只要在「倒频率轴」上分得开，就能用一把窗（倒滤波器）把它们剪开。这就是**同态滤波（homomorphic filtering）**的核心思想：先在频域取对数把乘法变加法，再做一次反变换到一条新轴上去「物理隔离」。<span class="marginnote">「同态」指「保持运算结构」：同态解卷积把「卷积」这个运算映射成「加法」，按加法去线性处理，再映射回来。傅里叶变换本身也是同态——它把卷积映射成乘法。这类「换一个代数结构让问题变简单」的招数，你在第三级《抽象代数》里会正式学到，这里是它在信号处理里的第一次大规模应用。</span>

## 2 公式解析：倒谱的定义

**实数倒谱（real cepstrum）**的定义是「对数幅度谱的反傅里叶变换」：

$$c(n) = \frac{1}{2\pi} \int_{-\pi}^{\pi} \log \bigl\lvert S(e^{j\omega})\bigr\rvert\, e^{j\omega n}\, d\omega$$

离散地写就是：

$$c(n) = \frac{1}{N} \sum_{k=0}^{N-1} \log \lvert S(k)\rvert\, e^{j 2\pi k n / N}$$

逐步拆解：

- **第一步，取幅度谱 $\lvert S(k)\rvert$**：对语音帧做 DFT，取模，丢掉相位。**丢相位意味着这个变换不可逆**——实数倒谱只能告诉你「幅度结构」，不能恢复原始信号。
- **第二步，$\log$ 是「解卷积开关」**：因为 $\log(AB) = \log A + \log B$，声源与声道在取对数后彻底分离成两项。
- **第三步，反变换到倒频率轴**：对 $\log\lvert S(k)\rvert$ 再做一次 IDFT，得到 $c(n)$。横轴是 $n$，单位是「样本 / 秒」——**倒频率是时间单位，不是频率单位**。$n$ 大代表「对数谱里变化快」的分量。

为什么源与声道会落到倒频率轴的不同位置？**因为它们在频域里的「变化快慢」不同**：声道冲激响应 $h(n)$ 在时域里又短又光滑（只有几十个样本），它的对数谱是大尺度、慢变的隆起（包络），反变换后集中在 $c(n)$ 的低 $n$ 段；声门激励 $e(n)$ 对浊音是周期为 $T_0$ 的脉冲串，它的对数谱是**快变的梳状纹**（间隔 $1/T_0$），反变换后在 $n = T_0$ 处形成一个尖峰。<span class="marginnote">直觉类比：包络是「宏观地形」，谐波是「高频振动」。地形集中在倒频率的低段，振动集中在倒频率 = 周期的位置。倒谱就是把二者在地理上分开。</span>

## 3 同态滤波：用一把「倒滤波窗」剪开

知道了两部分在倒频率轴上的位置，分离就是剪一刀：

- **低时倒滤波（low-time liftering）**：只保留 $n$ 小的一段（如 $n \le 20$ 样本），其余置零，再正变换回去，就得到**光滑的谱包络**——等价于用平滑曲线穿过谐波梳，和 LPC 的包络殊途同归。
- **高时倒滤波（high-time liftering）**：只保留 $n \approx T_0$ 附近的一段，得到**激励部分**，能用于基频估计（倒谱法的基频峰就在这儿）。

**辨析｜易错点：倒谱峰在「倒频率 = 周期」处，不是「频率」处。** 一个基频 100 Hz 的浊音，它的倒谱尖峰在 $n = f_s/100$ 个样本处（16 kHz 采样下是 $n = 160$），对应**时间 $T_0 = 10$ ms**。读倒谱图时横轴是「时间」，尖峰的位置给的是**周期**，取倒数才是频率。方向搞反是最常见的错误。

## 4 复倒谱：想恢复信号，就得要相位

实数倒谱丢了相位，只能分析不能重建。要**可逆**的解卷积，需要**复倒谱（complex cepstrum）**：

$$\hat{s}(n) = \frac{1}{2\pi} \int_{-\pi}^{\pi} \log S(e^{j\omega})\, e^{j\omega n}\, d\omega$$

这里用的是**复对数** $\log S = \log\lvert S\rvert + j\arg S$，相位信息保留下来。复倒谱满足「卷积 → 加法」的严格同态关系，因此只要在复倒谱域做倒滤波、再逆变换，就能**真实还原**声源或声道信号——这正是**语音去混响、回声消除、乐音分离**里同态方法的理论根基。

但复倒谱有一个著名难点：**相位展开（phase unwrapping）**。<span class="marginnote">$\arg S$ 的主值限定在 $(-\pi, \pi]$，取对数后相位是「缠绕」的；要得到平滑的复倒谱必须把相位展开成连续曲线。实际信号的相位有无数种展开方式，选取不当会让复倒谱两端剧烈震荡。工程上常用「最小相位」假设绕开：假设 $S(z)$ 的全部零极点都在单位圆内，则 $\arg S$ 可由 $\log\lvert S\rvert$ 唯一确定（Hilbert 变换）。</span>这个坑让复倒谱在实时系统里不如实数倒谱常用。

一段 Python 代码，把一帧语音的实数倒谱算出来：

```python
import numpy as np

def real_cepstrum(frame):
    """实数倒谱：IDFT( log|DFT(frame)| )"""
    S = np.fft.rfft(frame)              # 幅度谱（只取 0~fs/2）
    logmag = np.log(np.abs(S) + 1e-12)  # 对数幅度
    return np.fft.irfft(logmag, n=len(frame))

cep = real_cepstrum(frame)
peak = np.argmax(cep[80:320]) + 80      # 在周期范围内找尖峰
f0 = fs / peak                          # 倒谱法基频
```

## 5 辨析与易错点

- **倒谱不是频谱**：横轴是倒频率（时间单位），别把「尖峰位置」当频率。倒谱的纵轴也没有明确的物理单位，只有相对大小。
- **实数倒谱不可逆**：丢了相位，只能分析幅度结构；要重建用复倒谱，但要处理相位展开。
- **源与包络不一定分得开**：倒谱分离的前提是两者在倒频率轴上**不重叠**。女声、童声基频高（$T_0$ 小），倒谱峰往原点靠，可能压进包络所在的低段——分离效果变差。<span class="marginnote">这也是倒谱法在低基频（男声、低音歌手）上表现最好的原因：基频低 → 周期长 → 峰离原点远 → 分离干净。</span>
- **加窗与噪声**：帧边缘加窗不充分时，对数谱的毛刺会污染倒谱低段；背景噪声抬高谱谷，让包络「变平」。预处理（去噪、加窗）对倒谱法格外重要。
- **倒谱法 vs LPC 的包络**：LPC 用参数模型（全极点）拟合，倒谱用非参数的平滑；LPC 对低阶共振峰稳，倒谱更忠实地保留谱细节，但对噪声更敏感。

## 6 小结

- **核心同构**：$s = e * h \;\Rightarrow\; \log\lvert S\rvert = \log\lvert E\rvert + \log\lvert H\rvert$——卷积变加法，是倒谱的全部秘密。
- **实数倒谱**：$c(n) = \mathrm{IDFT}\{\log\lvert S(k)\rvert\}$，横轴是时间（倒频率），低段 = 声道包络，$n = T_0$ 处的峰 = 基频。
- **同态滤波**：低时倒滤波得谱包络，高时倒滤波得激励；倒谱峰位置给的是**周期**，取倒数才是频率。
- **复倒谱**：保留相位、可逆，是去混响 / 分离的理论工具，但相位展开是工程难点。
- **局限**：源与包络重叠（高基频）时分离变差；对噪声敏感。
