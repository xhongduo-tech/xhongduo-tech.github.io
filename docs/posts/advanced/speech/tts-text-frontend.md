## 为什么从文本前端内部开始

上节建立了 TTS 的总体地图：前端把文字变成「发音计划」，后端把计划变成声音。本节钻进前端的四道工序——**文本归一化、分词、注音、韵律预测**。这四步每步都在回答「文字到底该怎么读」的一个侧面，任何一步出错，合成结果都会出戏：归一化把「10.5」读成「十点五」还是「十点五分」？分词把「研究生命起源」断成「研究 / 生命起源」还是「研究生 / 命起源」？注音把「高兴」的「兴」读 xīng 还是 xìng？韵律决定这句话是问句还是陈述句。

前端是**语言学与 NLP 的交汇点**：它把语言的音系、形态、句法知识编码成可执行的规则与模型。理解前端，才真正理解「合成先要会读」。

## 1 文本归一化：把非标准写法变成可发音形式

**文本归一化（text normalization, TN）**：把原始文本里的数字、日期、货币、缩写、符号等「非语言写法」转成「可发音的词语序列」。

| 原文 | 归一化结果 | 说明 |
| --- | --- | --- |
| `￥128.5` | 一百二十八元五角 | 货币 + 小数 |
| `2026-08-07` | 二零二六年八月七日 | 日期读法 |
| `Dr. Smith` | 史密斯博士 | 缩写展开 |
| `1/2` | 二分之一（分数）或 一月二日（日期） | 依赖上下文 |
| `10:30` | 十点三十分 | 时间读法 |

归一化是「歧义的重灾区」：`1/2` 是分数还是日期？`2020` 读「二零二零」还是「两千零二十」？`US` 读「you ess」还是「美国」？传统前端用**加权有限状态转换器（WFST）** 或规则 + 分类器解决；现代系统把「归一化」当成一个「文本到文本」的机器翻译任务，用 seq2seq 模型直接从「原始 → 归一化」学习。<span class="marginnote">归一化对 ASR 也重要：识别结果里的「一千两百元」在写成「1200 元」前要做反向归一化（denormalization）。语音系统里「写出来的」与「说出来的」常常是两套表示，前端管正向、ASR 管反向，是镜面对称的两兄弟。</span>

## 2 分词：先把字串切成词

**分词（word segmentation）**：把连续的字符序列切成「有意义的词」——因为发音、韵律都以「词」为基本单位。

中文没有天然空格，分词是必经步骤；英文虽有空格，但专名、复合词（`New York`、`ice-cream`）仍需词典与规则。中文分词的方法谱系：

- **词典最大匹配**：正向/逆向最大匹配，快但遇未登录词就断错。
- **统计分词（HMM/CRF）**：把分词当作序列标注，用「字在词首/词中/词尾」的标签建模——HMM 就是前几节学的那个 HMM。
- **神经分词（BiLSTM-CRF / BERT）**：当前主流，用上下文表征做标注，未登录词与歧义都大幅缓解。

**核心要点：分词错误直接传染后续步骤。** 分词错了，注音、韵律、声学建模全都跟着错——「研究生命起源」若切成「研究生 / 命起源」，合成出来就是一句「研究生命起源」的怪话。这也是前端每一步都「前向传播错误」的原因：**前端是错误放大链，第一步要特别稳。**<span class="marginnote">分词的另一个作用是给韵律预测提供「词汇边界」：词边界的停顿等级通常高于词内。传统韵律建模把「词边界信息」当作预测停顿的强特征，所以分词质量直接决定停顿预测质量。</span>

## 3 注音（G2P）：字词到音素序列

**注音 / 字形音素转换（grapheme-to-phoneme, G2P）**：把词转成音素序列（英文）或拼音 + 声调（中文）。这是前端最容易「一个错音毁整句」的环节。

**中文 G2P 的核心难点是多音字消歧**：约 10% 的常用字是多音字，上下文才能定音。传统方法靠规则表 + 词性 + 少量统计；现代方法用上下文模型——把句子喂给 BERT 之类模型，预测每个字的读音类别：

$$
P(\text{读音}_i \mid \text{上下文}) = \text{softmax}\big(W\, h_i + b\big)
$$

$h_i$ 是上下文编码器给第 $i$ 个字的表征——模型读到「银行」的「行」时，上下文里的「银」把它推向 háng 而非 xíng。<span class="marginnote">英文 G2P 的难点在「拼读不规则」：`tough`/`through`/`though` 拼写相似、读音迥异。传统靠词典兜底 + 规则预测 OOV；现代用序列到序列模型直接从拼写预测音素，连规则都省了。</span>

**英文 G2P 的公式视角**：给定拼写 $g_1 \dots g_K$，预测音素序列 $p_1 \dots p_M$（$M$ 可 ≠ $K$，因为「ough」一个字形片段对多个音素），本质是一个「长度不定的序列转换」——经典的 sequence-to-sequence 任务，用注意力编解码器做正合适。

## 4 韵律预测：标注停连与语调

**韵律（prosody）**：言语中的节奏、重音与语调模式。前端要预测三件事：

- **停连（pausing / break）**：哪里该停顿、停多长。常用 **ToBI 标注**的 Break Index（0–4 级）表示停顿等级——4 级是句子边界的大停顿，2 级是短语内小停顿。
- **重音（stress / accent）**：哪个词/音节重读。中文轻声（「的」「了」轻读）、英文词重音（`record` 名词重音在前、动词在后）都属此列。
- **语调（intonation）**：句尾升调还是降调——问句「你去吗？」末尾上扬，陈述句「你去。」末尾下降。语调由**基频（F0）曲线**体现。

传统韵律预测用**决策树 / HMM** 从「词性、词边界、句法、标点」预测 Break Index；现代方法把韵律预测「端到端化」——Tacotron 的注意力隐含了停连，FastSpeech 的时长预测器隐含了停顿长度。但「显式韵律」的价值仍在：**可控合成**（指定停连与重音）必须依赖显式前端标注。<span class="marginnote">韵律与语义深度绑定：「我没说他要来」五个字，重音落在「我」「没」「他」分别表达「别人说的」「我说的是没说」「不是你说」。前端要能预测这种「信息结构」，传统靠句法规则，现代靠神经语言模型——但「怎么把语义的轻重读出来」至今仍是 TTS 的研究前沿。</span>

## 5 公式解析：前端输出的完整表示

把四道工序连起来，前端最终输出一份「发音乐谱」，每一段大致长这样（中文例子）：

$$\text{前端输出} = \big[\, \text{拼音} + \text{声调},\; \text{Break Index},\; \text{停顿时长},\; \text{句调} \,\big]$$

以「今天是星期四。」为例，前端产出（示意）：

| 词 | 拼音（声调） | Break | 说明 |
| --- | --- | --- | --- |
| 今天 | `jīn tiān` | 2 | 词间小停顿 |
| 是 | `shì` | 2 | |
| 星期四 | `xīng qī sì` | 4 | 句末大停顿 |
| （句号） | — | 4 + 降调 | 句末语调 |

- **第一步，归一化**：句子无数字符号，直接通过。
- **第二步，分词**：「今天 / 是 / 星期四」——词边界确定。
- **第三步，注音**：每个字给出带声调拼音，多音字由上下文定音。
- **第四步，韵律**：词间 Break 2、句末 Break 4 + 降调，标注停顿与句调。

这份「乐谱」就是后端的输入——它把**一整句文字的无限歧义，压缩成一串确定性的、可发声的符号**。前端四道工序的每一道，都在把这个「压缩」做得更准。

**辨析｜易错点：前端处理的是「语言层」不是「声学层」。** 初学者常把「前端要读出停顿」误当成「前端要生成音频」——不，前端输出的是**符号标注**，停顿长短、语调曲线这些「物理量」由后端和声码器实现。前端决定「哪里停、升调降调」，后端决定「停多久、升多高」。

## 6 文本前端的工程实现与评测

前端在工程上「看着琐碎、做着踩坑」，值得单讲：

- **前端是一个「规则 + 模型」的混合系统**：归一化用 WFST/规则（确定性强）、分词注音用模型（鲁棒性强）、韵律预测用模型——**「确定性部分用规则、歧义部分用模型」**是前端的工程哲学。
- **前端的评测**：分词用 F1（对黄金分词）、G2P 用**字音准确率**、归一化用**归一化准确率**、韵律用 **Break Index 预测准确率**——**前端每道工序有独立评测**，不能只看「合成最终好不好」。
- **错误的影响范围**：前端错误是「**放大链**」——归一化错 → 分词错 → 注音错 → 声学错。**越靠前的错误影响越广**——所以前端要「优先保前面的准」。
- **多语言前端的复用**：中文前端（分词 + 多音字）与英文前端（G2P + 重音）结构同构但规则不同——**前端框架要「语言无关 + 语言配置」**，否则每种语言重写一遍。

**公式解析：G2P 的评估指标。**

$$
\text{PER} = \frac{S + D + I}{N_{\text{音素}}}, \qquad \text{音素错误率（与 WER 同构）}
$$

- **第一步，看三类错误**：S/D/I 是音素级替换/插入/删除——与 WER 的三类错误完全同构，只是单位从「词」换成「音素」。
- **第二步，看对比**：PER 是 G2P 系统的标准指标——「预测的音素串与标准音素串错多少」。
- **第三步，看语境**：中文 G2P 的重点是**多音字准确率**（PER 里多音字错误占大头）——除 PER 外要单独报「多音字正确率」。
- **第四步，看对下游的影响**：PER 高的前端会让 TTS「读错音」——**PER 是前端质量的体检，直接预告合成可懂度**。

**核心要点：前端工程 = 「规则/模型混合 + 逐工序评测 + 错误放大意识 + 语言无关框架」。** 前端看着「low-tech」，其实是「语言学 + 工程」的精细活。

## 7 小结

- **文本归一化**把数字、日期、缩写等非标准写法转成可发音形式，是歧义重灾区。
- **分词**把字串切成词，错误会逐级传染，是错误放大链的第一环。
- **注音（G2P）**把词转成音素/拼音，中文难点是多音字消歧（上下文模型），英文难点是拼读不规则。
- **韵律预测**输出停连（Break Index）、重音与语调（F0 形态），是自然度的灵魂。
- 前端四步输出「发音乐谱」；端到端把工序隐式化，但显式前端仍是可控合成的关键。
