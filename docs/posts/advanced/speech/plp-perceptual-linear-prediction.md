## 为什么从 PLP 开始

MFCC 和 FBank 的感知依据主要是**Mel 刻度**这一条心理声学曲线。本节换一个更彻底的思路：**感知线性预测（Perceptual Linear Prediction，PLP）**，由赫尔曼斯基（Hynek Hermansky）于 1990 年提出，它把人类听觉的**三条心理声学规律**——临界频带、等响曲线、强度—响度幂律——全部整合进特征提取，最后再用线性预测把谱包络压成一组系数。

PLP 的独特价值在于它体现了「**特征应该模仿人耳，而不是模仿数学上的便利**」这一思想。它与 LPC 的关系、与 MFCC 的差异，构成了一张理解「感知特征设计」的完整地图。**学完它，你会明白：特征工程的每一次选择，背后都是一条具体的生理或心理声学事实。**<span class="marginnote">PLP 一经提出就在噪声环境下的语音识别中展现出对 MFCC 的优势（尤其电话信道与加性噪声），它的变体 RASTA-PLP（相对谱 PLP）对信道失真更稳健。理解 PLP = 理解「把感知科学翻译成信号处理」的一次完整示范。</span>

## 1 三条心理声学规律

PLP 依次使用三条听觉规律，每条对应一个处理步骤。

### 1.1 临界频带（critical band）

人耳对频率的分辨不是线性的，而是以**临界频带**为单位。两个频率若落在同一临界频带内，在感知上会「互相干扰」；跨越临界频带才能被独立分辨。临界频带近似地用 **Bark 刻度**来刻画（见本专题《临界频带与 Mel 刻度、Bark 刻度》）。

PLP 用它做什么？**把功率谱按 Bark 刻度分成 17–18 个频带**，每个频带内做加权求和。这与 Mel 滤波器组「分箱」在精神上相同，但 Bark 刻度与 Mel 刻度是两种不同的经验刻度——Mel 来自音高感知实验，Bark 来自临界频带掩蔽实验。<span class="marginnote">工程上一个常用近似：把 Bark 带宽直接看成约 100 Hz（1 kHz 以下）或约 20% 的中心频率（1 kHz 以上）。PLP 原论文用「频率—Bark 转换」的解析式来构造三角滤波器，滤波器之间在 Bark 轴上等宽。</span>

### 1.2 等响曲线（equal-loudness contour）

人耳对不同频率的**灵敏度**不同：3–4 kHz 附近最灵敏，低频与极高频需要更大的声压级才能产生同等响度。等响曲线就是「不同频率要达到同样响度所需声压级」的等高线。

PLP 用它做什么？**对每个频带的能量乘一个等响加权系数 $E(\omega)$**，让 3 kHz 附近的频带被放大、两端被压低——模拟「人耳听到的响度」，而不是物理功率。

### 1.3 强度—响度幂律（power law）

响度与强度的关系不是线性的。实验表明：**主观响度近似正比于物理强度的 $1/3$ 次幂**（Stevens 幂律）。也就是说，把强度翻 8 倍，响度才翻倍。

PLP 用它做什么？**对加权后的谱做 $\lvert X \rvert^{0.33}$ 的立方根压缩**。这与 MFCC 里的 $\log$ 作用相似（压缩动态范围），但**来源不同**：$\log$ 是数学上的方便，立方根是心理物理学的实测规律。

## 2 公式解析：PLP 的核心变换链

PLP 的完整流程可以浓缩成一条「功率谱 → 感知谱」的变换链。设一帧语音的 DFT 为 $X(\omega)$，则 PLP 的感知谱 $P(\omega)$ 为：

$$
P(\omega) = \Bigl[\, W(\omega) \cdot \bigl\lvert X(\omega)\bigr\rvert^2 \,\Bigr]^{0.33}
$$

逐步拆解：

- **第一步，功率谱 $\lvert X(\omega)\rvert^2$**：取 DFT 后取模平方，得到物理功率。这是后续一切感知处理的对象。
- **第二步，临界频带加权 $W(\omega)$**：$W(\omega)$ 是 Bark 刻度滤波器组与等响加权 $E(\omega)$ 的复合。具体地说，先把功率谱经 Bark 滤波器组分成 17–18 个频带，再把每个频带能量乘以等响曲线系数。这一步把「物理谱」变成「人耳听到的分布」。
- **第三步，立方根 $\lvert\cdot\rvert^{0.33}$**：对每个频带能量做 $1/3$ 次幂，模拟强度—响度幂律。它压缩动态范围，同时让后续线性预测的处理更符合听觉特性。

得到感知谱 $P(\omega)$ 之后，PLP 再对它做一次**线性预测（LPC）**，取全极点模型的系数或由 LPC 系数变换出的**倒谱系数**，作为最终特征。<span class="marginnote">为什么用 LPC 而非 DCT？PLP 出生时 LPC 已是成熟的声道建模工具，而且全极点模型对谱包络的拟合自带平滑——它比 DCT 更贴合「声道冲激响应的谱形」这一物理解释。不过实践里，直接在感知谱上取 log 再走 DCT（即「感知版 FBank」）也常有，两者各有所长。</span>

## 3 PLP 的完整流水线

把上面三条规律按顺序串起来，PLP 提取的完整步骤是：

1. **频谱分析**：对语音帧做 DFT，取功率谱 $\lvert X(\omega)\rvert^2$。
2. **临界频带分析**：用 Bark 刻度把功率谱分成 $M \approx 17$–18 个频带，每个频带内加权求和，得到 $M$ 个临界频带能量。
3. **等响预加重**：对每个频带能量乘以等响曲线系数 $E(\omega)$（3 kHz 附近权重最大）。
4. **强度—响度变换**：对加权能量取 $0.33$ 次幂。
5. **线性预测**：把 $M$ 个感知能量当作一个「伪功率谱」，用 LPC（阶数 $p$，常取 12–18）拟合全极点模型。
6. **系数转换**：把 LPC 系数转成倒谱系数（即 LPCC），或直接取 LPC 系数。

一张小表对照 PLP 与 MFCC 的分工：

| 处理环节 | MFCC | PLP |
| --- | --- | --- |
| 频率刻度 | Mel 刻度 | Bark 刻度（临界频带） |
| 频带处理 | Mel 三角滤波器 | Bark 滤波器组 |
| 等响加权 | 无 | 有（$E(\omega)$） |
| 响度压缩 | $\log$ | 立方根 $^{0.33}$ |
| 包络提取 | DCT + 截断 | LPC 全极点模型 |
| 输出 | MFCC 系数 | PLP 系数（或 LPCC） |

**辨析｜易错点：PLP 不是「Mel 换 Bark 的 MFCC」。** 两者在四条轴线上都不同：刻度（Mel/Bark）、是否等响加权（无/有）、压缩方式（log/立方根）、包络提取（DCT/LPC）。**PLP 是一个独立的感知特征家族，而不是 MFCC 的微调。**

## 4 一个数值例子：感受 $^{0.33}$ 与 $\log$ 的差别

设某频带物理功率从 $1$ 变为 $1000$（差 30 dB）：

- 取对数：$\log 1 = 0$，$\log 1000 \approx 6.9$——变化被压成约 6.9 个单位。
- 取立方根：$1^{0.33} = 1$，$1000^{0.33} \approx 10$——变化被压成约 10 倍。

两者都压缩动态范围，但**形状不同**：$\log$ 对越大的值压得越狠，立方根相对更「宽容」、更接近人耳「响度与强度幂律」的实测关系。在噪声场景下，立方根对中等强度的信号更线性，有时比 $\log$ 更稳健。<span class="marginnote">这条「压缩函数形状」的细节常被忽略，但它直接影响特征对背景噪声的响应：$\log$ 会把低能量区域的噪声相对放大，立方根则相对抑制。RASTA-PLP 正是从这类观察出发，进一步对谱的时间轨迹做带通滤波。</span>

## 5 PLP 的工程实现与变体

一个简化的 PLP 提取示意：

```python
import numpy as np

def plp_frame(x, fs=16000, n_fft=512, order=12):
    X = np.abs(np.fft.rfft(x, n_fft)) ** 2      # 功率谱
    # 1. Bark 刻度临界频带加权（此处用占位近似，真实用 Bark 滤波器组）
    bark_bands = bark_filterbank(fs, n_fft)     # 返回 (n_bands, n_bins) 权重
    E = bark_bands @ X                          # 每个临界频带能量
    # 2. 等响加权
    E = E * equal_loudness(fs, n_fft)
    # 3. 强度—响度幂律
    P = E ** 0.33
    # 4. 对感知谱做 LPC（用自相关法求全极点系数）
    a = lpc_autocorrelation(P, order=order)     # 返回 LPC 系数
    return a
```

真正的实现里，`bark_filterbank`、`equal_loudness`、`lpc_autocorrelation` 各有成熟的数值公式。**注意等响加权应作用于功率谱（物理量），而立方根应在加权之后**——顺序错了，感知意义就乱了。

**工程上最著名的 PLP 变体是 RASTA-PLP**：在临界频带分析之后、等响加权之前，对每个频带能量的**时间序列**做带通滤波（约 2–20 Hz），把缓慢的信道漂移与快速的谱波动同时抑制。它对电话信道、麦克风增益的缓慢变化极稳健，是 PLP 家族里工程价值最高的一个。

**辨析｜易错点：PLP 对噪声鲁棒性的来源。** PLP 的优势常被笼统归给「感知建模」，其实更具体地来自三点：**等响加权**压低了人耳不敏感的高频噪声贡献；**立方根**比 $\log$ 对中等信号更线性；**LPC 全极点平滑**对谱中的毛刺天然免疫。理解这三个来源，比记住「PLP 抗噪」四个字有用得多。

## 6 小结

- **PLP = 临界频带（Bark）→ 等响加权 → 立方根幂律 → LPC**，是「心理声学 + 线性预测」的完整整合。
- **三条感知规律各司其职**：Bark 分频带、$E(\omega)$ 加权、$^{0.33}$ 压缩，分别对应频率分辨、灵敏度差异、响度幂律。
- **与 MFCC 的四点不同**：刻度（Mel/Bark）、等响加权（无/有）、压缩（log/立方根）、包络（DCT/LPC）。
- **变体 RASTA-PLP**：对频带能量时间轨迹做带通，抗信道漂移，是 PLP 家族最实用的分支。
- **抗噪不是玄学**：它来自等响加权、立方根与 LPC 平滑三个具体机制。
