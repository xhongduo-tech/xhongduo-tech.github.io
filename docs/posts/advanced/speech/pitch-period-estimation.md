## 为什么从基音估计开始

语谱图里，浊音段是一条条等间隔的横向细线；倒谱里，浊音在「倒频率 = 周期」处有一个尖峰。这两个现象背后是同一个量：**基频**——声带每秒振动的次数。**基音周期估计（pitch / f0 estimation）**就是把这个量精确测出来，它是一连串高级任务的入口：普通话的**声调**、句子的**语调**、说话人的身份、唱歌的音高、情绪的表达，全都写在基频曲线里。<span class="marginnote">普通话四声（阴平 55、阳平 35、上声 214、去声 51）就是四种基频「轮廓」，同一个音节 /ma/ 靠 f0 曲线区分「妈麻马骂」。你前面在《音素、音节与韵律》里见过这个说法，今天补上「机器怎么把这条曲线测出来」。</span>

测基频听起来简单——数一数声带振动几次不就行了？真做起来却是语音处理里最「老而弥坚」的难题之一：**噪声、共振峰、清浊切换、说错一个八度**，都会让算法给出荒谬的答案。本节先讲最经典的**自相关法**，再讲它的现代升级版 **YIN 算法**——后者至今仍是学术论文里的标准基线。

## 1 基频、基音周期与感知

物理量与感知量要分开：

**基频 $f_0$**：声带振动频率，声学量，单位 Hz。成年男性约 80–200 Hz，女性约 150–350 Hz，儿童可到 500 Hz。
**基音周期 $T_0 = 1/f_0$**：一次振动的时间。80 Hz 的男声 $T_0 = 12.5$ ms，300 Hz 的女声 $T_0 \approx 3.3$ ms。
**音高（pitch）**：人对基频的**主观感知**，与 $f_0$ 近似对数关系，还受响度、谐波结构影响（可在《响度、音高感知与等响曲线》里展开）。

估计的搜索范围通常取 $f_0 \in [60, 500]$ Hz，即 $T_0 \in [2, 16.7]$ ms。<span class="marginnote">范围上下限是工程约定：低过 60 Hz 接近次声、高过 500 Hz 一般是儿童或歌声；范围太宽会放大「倍频错误」（把 f0 听成 2f0 或 f0/2）的概率。</span>

**难在哪？** 一帧语音并不是完美的周期信号：声带振动每周期略有差异（抖动 jitter），声道共振峰会「打扮」谐波的幅度，背景噪声直接污染波形，清音帧根本没有周期却很像「弱周期的噪声」。所以基音估计的核心不是「找周期」，而是**在种种干扰下稳健地找周期**。

## 2 自相关法：看信号「隔多久与自己重复」

时域里最直接的思路：**对一段信号，把它平移 $\tau$ 个样本后与自己相乘求和**，如果 $\tau$ 恰好等于周期 $T_0$，平移后的波形与原波形对齐，乘积和达到峰值。

$$R(\tau) = \sum_{n=0}^{N-1-\tau} s(n)\, s(n+\tau)$$

$R(\tau)$ 叫**自相关函数**。对周期信号，它在 $\tau = 0, T_0, 2T_0, \dots$ 处都出现峰值，其中 $\tau = 0$ 处的 $R(0)$ 最大（信号与自己完全重合）。算法就是：**在合法的周期范围内，找 $R(\tau)$ 的第一个（或最大的）峰值，$f_0 = f_s / \tau_{\text{peak}}$。**

```python
import numpy as np

def autocorr_pitch(frame, fs, fmin=60, fmax=500):
    """自相关法基音估计：在合法周期范围内找最大峰。"""
    N = len(frame)
    tau_min = int(fs / fmax)            # 周期范围上限 f0∈[60,500]
    tau_max = int(fs / fmin)
    # 自相关 R(0..N-1)；np.correlate(full) 的中点即零延迟
    R = np.correlate(frame, frame, mode='full')[N - 1:]
    tau = tau_min + int(np.argmax(R[tau_min:tau_max + 1]))  # 从 tau_min 起找峰
    return fs / tau                     # f0 = fs / tau_peak（Hz）
```

这个朴素版本有几个著名毛病，都来自自相关的结构：

- **$\tau = 0$ 处恒为最大**：必须从 $\tau \ge \tau_{\min}$ 开始找，否则永远返回 $f_s/0$。
- **倍频陷阱（octave error）**：如果第 $2T_0$ 处的峰反而更高，算法会返回 $f_0/2$（低一个八度）。
- **共振峰污染**：声道共振可能在波形里制造出「比周期还明显」的次级周期，把峰带偏到共振峰频率上去。

## 3 公式解析：自相关峰为什么在周期处

$$
R(\tau) = \sum_{n} s(n)\, s(n+\tau)
$$

- **第一步，平移并逐点相乘**：$s(n+\tau)$ 是把信号往左平移 $\tau$ 个样本。两个波形逐点相乘，对齐的地方乘积为正、且大，错位的地方正负相抵。
- **第二步，求和**：和的大小衡量「平移 $\tau$ 后的信号与原信号有多像」。**平移一个周期，波形几乎原样重现，乘积和达到局部极大。**
- **第三步，归一化**：$\hat{R}(\tau) = R(\tau)/R(0)$，把幅度影响消除——响的帧 $R(0)$ 大、弱的帧 $R(0)$ 小，除以它之后才可比较。
- **第四步，找峰**：在合法周期范围 $[\tau_{\min}, \tau_{\max}]$ 内找最大峰，再用 $f_0 = f_s/\tau$ 换回频率。<span class="marginnote">注意方向：$\tau$ 是「样本数」时，峰在 $\tau \approx T_0 \cdot f_s$；先除以采样率得到秒，再取倒数得到频率。单位换算错位是这类代码里最常见的 bug。</span>

## 4 YIN：修复自相关的三大缺陷

2002 年，de Cheveigné 与 Kawahara 发表 YIN 算法，用**差函数**替代自相关，一举成为基音估计的现代标准。它针对自相关的三个缺陷逐一开刀：

**缺陷一：自相关在 $\tau = 0$ 恒最大，且峰值随 $\tau$ 缓慢衰减，容易误判。** YIN 改用**差函数**——不是算「像不像」，而是算「差多少」：

$$d(\tau) = \sum_{j=1}^{W} \bigl( x_j - x_{j+\tau} \bigr)^2$$

当 $\tau = T_0$ 时，$x_j \approx x_{j+T_0}$，差几乎为 0——**周期处是「谷」不是「峰」**，且 $d(0) = 0$ 是唯一的零点，不再有「$\tau = 0$ 恒最大」的干扰。

**缺陷二：$d(\tau)$ 随 $\tau$ 增大系统性增大**（窗内求和项减少，差被平均变小），谷会被「垫高」而失真。YIN 引入**累积均值归一化差函数（CMND）**：

$$d'(\tau) = \begin{cases} 1, & \tau = 0 \\ \dfrac{d(\tau)}{\dfrac{1}{\tau}\sum_{j=1}^{\tau} d(j)}, & \tau > 0 \end{cases}$$

把 $d(\tau)$ 除以「到 $\tau$ 为止的平均差」，抹平了随 $\tau$ 的单调衰减，让周期谷在整条曲线上都「显得深」。

**缺陷三：怎么挑谷？** YIN 分两步：先设一个绝对阈值（通常 $\theta = 0.1$），**找第一个低于阈值的谷**，再从它向下搜索局部最小。用「第一个」而非「最深」——因为「最深」常常是倍频陷阱（$2T_0$ 处更深）。<span class="marginnote">先阈值再局部最小的两段式是 YIN 的精华：阈值兜底「没有明确周期的帧别乱报」，局部最小保证精度。阈值太低会漏报浊音，太高会抓住噪声的假谷。</span>

最后用**抛物线插值**对谷的位置做亚样本精修，频率精度可达小数 Hz 量级。

## 5 公式解析：CMND 归一化在做什么

$$
d'(\tau) = \frac{d(\tau)}{(1/\tau)\sum_{j=1}^{\tau} d(j)}
$$

- **第一步，分子是原始差**：$d(\tau)$ 在周期处小、在别处大，但整体随 $\tau$ 衰减。
- **第二步，分母是「到目前平均差」**：$\frac{1}{\tau}\sum_{j=1}^{\tau} d(j)$ 是 $d(1), \dots, d(\tau)$ 的平均。它对大的 $\tau$ 更大，于是**分母随 $\tau$ 增大而增大，正好抵消分子的衰减趋势**。
- **第三步，比值让「相对深度」显形**：$d'(\tau)$ 表示「$\tau$ 处的差相对历史平均差有多小」。周期处 $d$ 极小，$d'$ 也极小；非周期处 $d'$ 接近 1。于是阈值比较在 $d'$ 上与 $\tau$ 无关，变得公平、可复现。

YIN 的完整流程代码（用 NumPy 即可）：

```python
import numpy as np

def yin(frame, fs, fmin=60, fmax=500, threshold=0.1):
    """YIN 算法：差函数 + CMND 归一化 + 阈值谷 + 抛物线插值。"""
    N = len(frame)
    tau_min, tau_max = int(fs / fmax), int(fs / fmin)

    # 差函数 d(tau) = sum_j (x_j - x_{j+tau})^2，周期处是谷
    d = np.zeros(N)
    for tau in range(1, tau_max + 1):
        d[tau] = ((frame[:-tau] - frame[tau:]) ** 2).sum()

    # CMND 归一化：d'(tau) = d(tau) / 平均差，抹平随 tau 的衰减
    d_cumsum = np.cumsum(d)
    d_prime = np.ones(N)
    d_prime[1:] = d[1:] * np.arange(1, N) / d_cumsum[1:]

    # 找第一个低于阈值的谷，再从它向下取局部最小
    tau_est = None
    for tau in range(tau_min, tau_max + 1):
        if d_prime[tau] < threshold:
            while tau + 1 <= tau_max and d_prime[tau + 1] < d_prime[tau]:
                tau += 1
            tau_est = tau
            break
    if tau_est is None:
        return 0.0                       # 无明确周期，判为清音

    # 抛物线插值做亚样本精修
    a, b, c = d_prime[tau_est - 1], d_prime[tau_est], d_prime[tau_est + 1]
    shift = 0.5 * (a - c) / (a - 2 * b + c)
    return fs / (tau_est + shift)        # f0（Hz）
```

## 6 辨析与易错点

- **倍频 / 半频错误是最主要的错误模式**：报告成 $f_0/2$（选到了 $2T_0$ 的谷）或 $2f_0$（选到了 $T_0/2$ 的假谷）。对策：用 YIN 的「第一个低于阈值」、限制搜索范围、对整条 f0 曲线做**中值平滑**。<span class="marginnote">工程经验：单帧估计必然有毛刺，拿 f0 曲线做 3–5 点的中值滤波能消掉大部分倍频跳变，代价是抹掉极短促的声调转折——语调分析要在保真与平滑之间取舍。</span>
- **帧长必须容纳至少两个周期**：80 Hz 男声周期 12.5 ms，20 ms 的帧只有不到两个周期，估计不稳。低音要加长窗（如 30–40 ms），代价是时间分辨率下降。
- **自相关峰 ≠ 一定要取最大**：取「最大」峰在共振峰强的元音上常翻车；YIN 用「第一个谷」规避。经验：**宁可取小周期（高 f0）方向的谷，也别取大周期方向的谷**——大周期谷更可能是倍频。
- **清浊不分**：清音帧没有基频，却可能因为噪声的弱周期性给出「假 f0」。**基音估计必须搭配清浊判断**（能量 + 过零率或周期性度量），浊音才报 f0。
- **倒谱法与自相关法**：倒谱法在频域算、对噪声鲁棒，但分辨率受帧长限制；自相关 / YIN 在时域算、速度快、分辨率高。生产系统常两者结合投票。

## 7 小结

- **基频 vs 音高**：$f_0$ 是声学量，音高是感知量；$T_0 = 1/f_0$，估计范围通常 60–500 Hz。
- **自相关法**：$R(\tau)$ 在 $\tau = T_0$ 处有峰，$f_0 = f_s/\tau$；缺陷是 $\tau = 0$ 恒大、倍频陷阱、共振峰污染。
- **YIN 算法**：差函数 $d(\tau)$（周期处是谷）→ CMND 归一化 $d'(\tau)$ 抹平衰减 → 绝对阈值 + 局部最小 → 抛物线插值，是现代基音估计的标准基线。
- **倍频错误是头号敌人**：限制范围、用「第一个谷」、中值平滑。
- **必须配清浊判断**：清音帧的 f0 是幻觉。
