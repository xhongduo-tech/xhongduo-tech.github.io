## 为什么从 HMM 填充词模型开始

在深度网络之前，KWS 的主流方法是**基于 HMM 的填充词模型（filler model）**——它把 KWS 变成一个「小规模语音识别」问题：把关键词建成 HMM 网络，再把「所有不是关键词的声音」建成一个或几个「垃圾（filler）模型」，用维特比解码在「关键词 ∪ 垃圾」的网络上找最优路径。如果最优路径穿过关键词 HMM，就唤醒。

这套方法看起来古老，却深刻体现了 KWS 的本质：**检测关键词 = 区分「关键词」与「非关键词」**。它的「垃圾模型」思想——显式建模「负类」——至今仍是深度 KWS 设计的参照（深度模型用「难负样本」学同一件事）。而且 HMM 方法**无需关键词的逐帧标注**，只用「关键词的发音词典 + 任意语音」就能建系统，这在数据稀缺时代价值巨大。

## 1 网络结构：关键词与垃圾的「竞技场」

HMM 填充词 KWS 的解码网络是一张**拼接图**：

- **关键词 HMM**：唤醒词的音素链（如「小 爱」→ `x iao` + `ai`），每个音素 3–5 状态，左到右拓扑。
- **垃圾模型（filler）**：一个（或多个）「能吸收任意语音」的 HMM——通常是一个**自环的全连接状态**（单垃圾），或**子词垃圾模型**（用音素集合的 HMM 拼成「任意音素」）。

解码网络的结构：

```text
   start
     │
     ├──────────►  filler（自环，吸收任意非关键词）──────────► end
     │                ▲
     │                └────── 可一直停留（“在垃圾里打转”）
     │
     └──────────►  x ──► iao ──► ai ──────────────────────► end
                      （关键词音素链，左到右拓扑）
```

从网络起点到终点，任一路径要么「一直在垃圾里打转」，要么「中途穿过关键词音素链」。**维特比解码**逐帧推进，输出最优路径——路径「是否经过关键词」就是「是否说了关键词」。

**核心概念：KWS 解码 = 在「关键词 vs 垃圾」的图上做序列判决。** 关键词路径的似然（L_kw）与垃圾路径的似然（L_filler）之比，就是检测分数。这个「比值判决」的思想——**不是问「这句话像不像关键词」，而是问「它比垃圾更像多少」**——是所有优秀 KWS 的共性。<span class="marginnote">垃圾模型的「质量」直接决定误唤醒：单垃圾状态太「宽松」（什么都吸），关键词的竞争对手太弱，误唤醒高；子词垃圾更「贴近真实语音」——用音素级 HMM 建模「任意音素串」，能吸收与关键词发音相近的非关键词，显著降低误唤醒。垃圾模型是「难负样本」的 HMM 版。</span>

## 2 公式解析：似然比判决

KWS 的判决分数用**似然比**：

$$
\text{Score} = \log P(O \mid \text{关键词路径}) - \log P(O \mid \text{垃圾路径}) \;\gtrless\; \tau
$$

逐步拆解：

- **第一步，看两个似然**：$P(O \mid \text{关键词路径})$ 是观测序列在「穿过关键词 HMM」假设下的概率；$P(O \mid \text{垃圾路径})$ 是「一直停在垃圾模型」假设下的概率。前者大说明「更像关键词」。
- **第二步，看取对数与相减**：对数域相减 = 概率比。Score > 0 说明关键词假设更优；与阈值 $\tau$ 比较决定是否唤醒。
- **第三步，看阈值的作用**：$\tau$ 控制「要多确定才唤醒」——与《KWS 系统框架》一节的阈值工作点同一逻辑：$\tau$ 高则漏唤醒多、误唤醒少。
- **第四步，看 HMM 打分**：两个似然都用**前向/维特比算法**在对应子图上计算。关键词路径可能有多条（一词多音、语速变化），维特比取其中最可能的——这自动处理了「关键词的不同说法」。

**核心结论：HMM 填充词 KWS = 「关键词 vs 垃圾」的维特比路径似然比。** 它不需要逐帧标注关键词，只需要关键词发音词典与任意负样本，就能得到鲁棒的检测分数——这是它的最大工程价值。

## 3 优点、局限与遗产

**优点**：

- **无需关键词逐帧标注**：只有「关键词音素序列 + 任意语音」即可训练（垃圾模型用通用语音/音素模型）。
- **鲁棒于说法变体**：HMM 的状态时长模型与维特比对齐，能吸收语速快慢、口音差异。
- **可解释**：检测分数的每个部分都可追溯（哪段音频激活了哪个音素）。

**局限**：

- **依赖发音词典**：关键词必须能转成音素序列，多音字、外来词、生造词难处理。
- **特征与模型陈旧**：MFCC + GMM 发射密度的区分力，远不如深度网络学的特征。
- **性能天花板**：对噪声、远场的鲁棒性不足。

**遗产**：HMM 填充词方法的核心遗产是**「显式负类建模」**——它教会 KWS 设计者「光知道关键词长什么样不够，还要知道'非关键词'长什么样」。深度 KWS（下一节）用「难负样本 + 序列模型」把同一思想现代化——垃圾模型变成了「训练数据里的负样本分布」，维特比似然比变成了「网络的置信度分数」。<span class="marginnote">Kaldi 的 `kws` 工具链正是 HMM 填充词方法的工业实现——至今仍在嵌入式与低资源场景使用。它也衍生出「基于置信度的 KWS」：先建一个通用声学模型 + 关键词 FST，解码出 lattice，再从 lattice 里搜「含关键词的路径」并算置信度——这是「关键词 FST 检索」路线，与 HMM 填充词一脉相承。</span>

**辨析｜易错点：填充词模型 ≠ 语言模型。** 填充词是「吸收非关键词语音的**声学**模型」（HMM 状态），语言模型是「约束词序列的**语言**概率」。KWS 不需要语言模型（它不管「下一个词是什么」），只需要垃圾模型管「非关键词怎么办」。混淆两者的标志：「KWS 要不要语言模型」——不要，但要填充词。

## 4 从 HMM 到深度：一句话的传承

HMM 填充词方法用「图搜索 + 似然比」做 KWS；深度方法用「网络 + 阈值」做 KWS。表面完全不同，骨子里继承了三样东西：

1. **检测 = 关键词 vs 负类**：垃圾模型 → 难负样本。
2. **序列建模**：HMM 状态序列 → 流式 CTC/RNN-T。
3. **阈值工作点**：似然比阈值 → 置信度阈值。

**核心要点：理解 HMM 填充词 KWS，是理解深度 KWS「在解决什么问题」的最佳入口。** 深度方法只是换了「特征的来源」与「打分的函数」，问题的结构——「区分关键词与非关键词、选阈值工作点」——五十年没变。

## 5 填充词 KWS 的实现细节

把填充词 KWS 落地，有一批「教科书少讲」的实现细节：

- **关键词 HMM 的状态数**：每个音素 3 状态是默认，但**短音素（爆破音）状态太多会「拖」**——工程上按音素长度自适应状态数。
- **垃圾模型的粒度**：单垃圾状态「太宽松」（误唤醒高），音素级垃圾「太贵」。折中：**子词垃圾**（把常见音素串建成垃圾 HMM，如 CVC 模式）——比单状态准、比全音素便宜。
- **停用词与近音词处理**：把**易混淆词**（与关键词近音）也建成「准关键词」垃圾模型——它们被「吸收」，不误唤醒。
- **解码的剪枝**：维特比在「关键词 ∪ 垃圾」大图上的计算，用**束剪枝**（只保留前若干路径）加速——实时 KWS 不能全图展开。

**公式解析：垃圾模型与误唤醒的关系。**

$$
P(\text{误唤醒}) \propto \frac{P(\text{近音词} \mid \text{关键词路径})}{P(\text{近音词} \mid \text{垃圾路径})}
$$

- **第一步，看分子**：近音词（如「小矮」）过关键词路径的概率——如果关键词路径「太宽松」，近音词也能高分穿过。
- **第二步，看分母**：近音词过垃圾路径的概率——垃圾模型「吸不吸得动」近音词。
- **第三步，看比值**：分子大、分母小 → 误唤醒高。**好的垃圾模型「吸得住」近音词（分母大），把误唤醒压下去**。
- **第四步，看工程手段**：把近音词显式建进垃圾模型（分母变大）或加「近音词惩罚」——「治误唤醒要从负类下手」。

**核心要点：填充词 KWS 的工程 = 「垃圾模型要够'懂'近音词」。** 关键词模型管「正」，垃圾模型管「负」——负类建模的质量决定误唤醒。

## 6 小结

- **HMM 填充词 KWS**把检测变成「关键词 HMM + 垃圾模型」图上的维特比解码。
- 判决用**似然比**：$\log P(\text{关键词路径}) - \log P(\text{垃圾路径}) > \tau$。
- 优点：无需关键词逐帧标注、鲁棒于说法变体、可解释；局限：依赖词典、特征陈旧。
- 遗产是「**显式负类建模**」思想，被深度 KWS 的「难负样本」继承。
- KWS 不需要语言模型，需要的是填充词（声学负类）——别混淆。

**附：关键概念速记**

- **HMM 填充词 KWS**：关键词 HMM + 垃圾模型（filler）在解码图上赛跑。
- **垃圾模型**：吸收「非关键词」——单状态（宽松）vs 子词（贴近真实语音）。
- **似然比判决**：$\log P(\text{关键词路径}) - \log P(\text{垃圾路径}) > \tau$——比「像不像」更准。
- **无需逐帧标注**：只要关键词音素序列 + 任意语音——数据稀缺时代的宝藏。
- **鲁棒于说法变体**：HMM 状态时长 + 维特比吸收语速/口音差异。
- **局限**：依赖发音词典、特征（MFCC/GMM）区分力有限。
- **遗产**：「显式负类建模」——深度 KWS 的「难负样本」是它的现代化。
- **关键词 FST 检索**：用通用声学模型 + 关键词 FST 在 lattice 上搜——同宗变体。

**延伸思考**：填充词方法的精髓是「**给负类一个名字**」——它把「不是关键词的一切」显式建模成垃圾模型，让检测变成「正负类之争」。这个「显式负类」的思想在深度时代被继承为「难负样本」，在分类任务中被继承为「负类采样」——**「认得出目标，先要认得清非目标」**，是检测类任务（KWS、声纹、异常检测）的通用法则。理解填充词模型，就理解了「为什么负类工程永远重要」。
