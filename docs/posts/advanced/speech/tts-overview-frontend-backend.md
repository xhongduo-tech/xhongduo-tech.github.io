## 为什么从语音合成概览开始

识别把声音变成文字，**语音合成（Text-to-Speech, TTS）**把文字变回声音。如果说 ASR 是「听懂」，TTS 就是「说出」。它看起来是识别的逆过程，但难点完全不同：识别是从连续的声学信号里**筛出**离散的文本；合成是从离散的文本里**造出**连续的、自然的、像人说话的声音。后者需要回答一连串「该怎么读」的问题——这串问题把 TTS 分成了两个分工清晰的半场：**前端文本分析**与**后端声学建模**。

几乎所有 TTS 系统——从 1980 年代的规则合成到今天的 VITS、语音大模型——都共享这个两段式骨架。先建立整体地图，再逐块深挖，是本专题「语音合成」大节的正确打开方式。

## 1 从文本到声音：两个半场的接力

一个文本句子变成声音，要经过一条流水线。传统 TTS 把它显式分成两段：

```
文本 "今天是星期四。"
   │  ① 前端文本分析（文本 → 语言层表征）
   ▼
音素序列 + 韵律标记 + 时长
   │  ② 后端声学建模（语言层 → 声学参数）
   ▼
声学特征（频谱、基频、时长）
   │  ③ 声码器（声学参数 → 波形）
   ▼
能播放的音频
```

**前端（text front-end）**：把「写出来的字」变成「该怎么说的符号」——这句话有几个词、每个字怎么发音、哪里该停顿、语调用升调还是降调。它管的是**语言学**问题。

**后端（back-end）**：把「语言符号」变成「声学参数」再到「波形」——每个音素的频谱长什么样、基频多高、持续多久，最终生成 PCM 音频。它管的是**声学与信号处理**问题。

**核心概念：前端与后端的分界是「语言表征」。** 前端输出的是「离散的、带注释的符号串」（音素 + 韵律 + 边界），后端吃的是这些符号。这条分界线在端到端模型里变得模糊（模型自己学语言表征），但理解它仍是看懂任何 TTS 系统的钥匙。<span class="marginnote">形象类比：前端像「播音员看稿」——先读明白文字、标注重音停连；后端像「声带与口腔」——把注好的稿子变成实际声音。前者决定「说什么、怎么说」，后者决定「声音听起来怎样」。</span>

## 2 前端文本分析：让机器「读懂」文字

前端把原始文本翻译成「发音计划」，包含四个层次：

- **文本归一化（text normalization）**：把非标准写法转成可发音形式——「￥128」→「一百二十八元」，「3.14」→「三点一四」，缩写「Ltd.」→「Limited」。这一步看似简单，却是前端最容易翻车的地方（数字、日期、单位的歧义无穷无尽）。
- **分词（word segmentation）**：中文需要把字串切成词，「今天是星期四」→「今天 / 是 / 星期四」；英文相对简单（按空格），但「New York」这样的多词专名仍需处理。
- **注音（grapheme-to-phoneme, G2P）**：把词转成音素序列。中文是「词 → 拼音 + 声调」，核心难题是**多音字消歧**（「银行」的「行」读 háng，「行走」的「行」读 xíng）；英文靠词典 + 规则 + 机器学习。<span class="marginnote">多音字消歧是中文前端最经典的难题：「重庆」是「chóng」不是「zhòng」，「人参」是「shēn」不是「cān」。现代做法用 BERT 之类上下文模型做「基于上下文的 G2P」——这本身就是一个 NLP 任务。</span>
- **韵律预测（prosody prediction）**：决定停连、重音、语调——哪里该停顿（停顿等级）、哪个词重读、句尾用升调还是降调。传统前端用规则（标点 → 停顿等级）+ 统计模型，现代用端到端模型直接学。

**核心要点：前端决定「可懂性与自然度的上限」。** 后端再强，前端把「一」字注错音、把停顿放错位置，合成结果也是错的。反过来，前端把韵律标记好，传统参数合成就能产出相当自然的语音——这正是「前端是灵魂」的说法由来。

## 3 后端声学建模与声码器：让符号发声

后端把前端的「发音计划」变成声音，也分三步：

- **时长建模（duration modeling）**：每个音素/音节说多久。传统用 HMM 的时长分布或回归模型；端到端里由注意力或专门的时长预测器完成。
- **声学参数预测（acoustic parameter prediction）**：给定音素序列 + 韵律 + 时长，预测每个时刻的声学特征——**频谱（如 MFCC、Mel 谱）、基频（F0）、能量**。传统参数合成用「声学模型」做这个预测，端到端模型（Tacotron 等）把这一步学进网络。
- **声码器（vocoder）**：把声学参数变回波形。传统声码器（如 STRAIGHT、WORLD）用信号处理方法重构；现代神经网络声码器（WaveNet、HiFi-GAN）把参数映射学成生成模型——声码器是整个后端的「最后一公里」，其质量直接决定听感。

**传统方法回顾的坐标**：拼接合成（把录音库里整段语音拼起来）与参数合成（用声学参数重建）是深度时代之前的两大流派——细节见《拼接合成与参数合成》一节。它们的分工本质与「前端 + 后端」一致：前端负责读稿，后端负责发音，区别只在后端是「拼现成的」还是「算新的」。

## 4 对比：传统两阶段与端到端单阶段

TTS 近十年最大的变化是「端到端化」，用一张对照表看清：

| 维度 | 传统两阶段（前端 + 后端 + 声码器） | 端到端（Tacotron/VITS 等） | 语音大模型 |
| --- | --- | --- | --- |
| 前端文本分析 | 显式规则 + 词典 + 统计模型 | 简化或学习化（仍保留基础注音） | 大模型统一处理文本 |
| 声学建模 | 独立声学模型预测参数 | 序列到序列学习频谱 | 离散 token 直接生成 |
| 声码器 | 传统或神经声码器 | 神经声码器 | 神经解码器 / 声码器 |
| 对齐 | 显式时长（HMM/前端韵律） | 注意力或显式时长 | 隐式，靠大模型 |
| 优点 | 可控、可解释、低数据量 | 自然、流畅、免人工标注 | 极自然、多说话人、多语言 |
| 缺点 | 拼接感、不自然 | 数据量大、时长不稳定 | 计算昂贵、可控性弱 |

**核心要点：端到端没有消灭「前端 + 后端」的分工，而是把分工从「显式模块」变成「隐式职责」。** Tacotron 的注意力在学「对齐」（前端职责），VITS 的 duration predictor 在学「时长」（后端职责），只是它们不再有名字、不再需要人工标注。<span class="marginnote">这就是为什么本专题仍要专门讲前端：端到端 TTS 的「文本处理」并没有消失，而是被压缩进模型；当你需要高可控性（指定停顿、指定重音）或低资源训练时，显式前端依然无可替代。</span>

## 5 评测与两大指标

TTS 质量的评价始终围绕两条线：

- **自然度（naturalness）**：像不像真人说话，主观评测用 **MOS（平均意见分）**，1–5 分，5 分最自然。
- **可懂度 / 相似度**：听没听清、像不像目标说话人，分别用**词/字错误率**与**说话人相似度 MOS**。

一套完整评测还要覆盖**稳定性**（同一句多遍合成是否一致）、**鲁棒性**（生僻词、数字、长句是否崩溃）。评测协议设计的细节见《语音增强与合成的评测协议设计》一节。对合成系统而言，「能读对」与「读得好听」同等重要——前端管前者，后端与声码器管后者。

## 6 TTS 系统设计的总体原则

从「系统设计」的高度回看整个 TTS，有几条贯穿始终的原则：

- **「语言层与声学层分离」是永恒的骨架**：无论传统三阶段还是端到端单模型，都要回答「说了什么」（语言层）与「怎么发声」（声学层）——只是分离的「显式/隐式」不同。理解这条分界，是读懂一切 TTS 的钥匙。
- **「可懂度先于自然度」**：一个读错字的自然系统比一个读对的机械系统更糟——前端（读得对不对）是底线，声学（读得好不好）是上限。
- **「可控性 vs 数据效率」的权衡**：显式前端可控（指定停连）但费人工；端到端省事但难干预——按产品需求选「可解释的贵方案」还是「黑箱的省方案」。
- **「数据质量 > 模型」**：TTS 的上限由「音频 + 文本」的对齐质量决定——清洗对齐比换更大模型更有效（这是 Tacotron 以来的铁律）。

**核心要点：TTS 设计 = 「语言/声学分界 + 可懂度底线 + 可控性取舍 + 数据质量优先」。** 四条原则解释了为什么「最先进的模型」也常常「输给一份干净的数据」。

**公式解析：TTS 系统的「误差链」。**

$$
\text{最终质量} \approx \min\big( \text{前端质量},\; \text{声学质量},\; \text{声码器质量} \big)
$$

- **第一步，看木桶效应**：TTS 质量 ≈ 三个环节的**最短板**——前端读错字、声学模型糊、声码器噪，任何一环崩，整体崩。
- **第二步，看诊断**：出问题时「定位短板」——读错字查前端、发闷查声学、刺耳查声码器。
- **第三步，看投资优先级**：**先补最短板**——而不是「最先进的地方」。这是 TTS 工程与学术品味的分歧：论文追「单环节 SOTA」，产品追「全链无短板」。
- **第四步，看端到端的例外**：VITS 类单模型把三环「融合」了——误差链变成「模型内部问题」，但「数据对齐」仍是最短板。

**核心要点：TTS 是「木桶系统」——质量由最短板决定，工程投资先补短板。**

## 7 小结

- TTS 流水线 = **前端文本分析**（归一化、分词、注音、韵律）+ **后端声学建模**（时长、频谱、基频）+ **声码器**（参数→波形）。
- 前端管「读得对不对」（语言学），后端管「声音好不好」（声学），分界是语言表征。
- 传统两阶段显式分工；端到端把分工隐式化，但职责仍在。
- 评测用 MOS（自然度）、WER（可懂度）、相似度 MOS（像不像），需兼顾稳定性与鲁棒性。
- 前端是「灵魂」，后端与声码器是「皮囊」，两者决定合成的上下限。
