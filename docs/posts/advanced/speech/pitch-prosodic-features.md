## 为什么从音高与韵律开始

前几节我们把每一帧语音压缩成了 MFCC、FBank、PLP，再加上 Delta 动态特征。这套特征回答的是「这一帧的声道形状是什么、正在怎么变」。但语音的意义不止藏在帧里——同一句话，用平调说出来是陈述，用升调说出来是疑问；汉语里「妈」「麻」「马」「骂」靠的是同一个音节的音高走向。这些信息统称**韵律（prosody）**，它跨越音段、横贯整句，是 MFCC 一类静态特征完全抓不到的。

**韵律特征（prosodic features）**：指音高、时长、能量三类超音段（suprasegmental）声学参数及其统计量，用以刻画语调、重音、停顿与情感色彩。<span class="marginnote">「超音段」是说这些信息不是某个音素本身带的，而是叠加在一串音素之上的整体走势。英语把重音、语调称为 prosody，汉语研究里常说「字调、语调、重音」——名字不同，声学本质相同。</span>

本专题已经在《基音周期估计》一节里得到了每帧的基频 $f_0$——那是音高特征的原料。本节要把这条 $f_0$ 曲线收拾成能进系统的特征流，再补上时长与能量，构成完整的韵律特征视图。

## 1 从基频到音高：一条 $f_0$ 曲线如何变成特征

### 1.1 物理量 $f_0$ 与知觉量音高

**基频（fundamental frequency, $f_0$）**：声带振动每秒振动的次数，是物理量，单位 Hz。**音高（pitch）**：人耳对 $f_0$ 的主观感知，是知觉量。两者关系近似对数——频率每翻一倍（一个八度），感觉上的音高差恒为「一个八度」。<span class="marginnote">这是韦伯—费希纳定律（Weber–Fechner law）的一例：许多知觉量与物理量成对数关系，响度、音高都如此。它正是前面《响度、音高感知与等响曲线》里 Mel 刻度、Bark 刻度出现的根源——把物理频率映射成知觉上等距的刻度。</span>

因此音高特征习惯在**对数域**处理，甚至转成**半音（semitone）**刻度，与音乐理论对齐：

$$n = 69 + 12\log_2 \frac{f_0}{440}$$

其中 440 Hz 对应 A4，半音数 $n$ 就是 MIDI 记谱号。$f_0$ 从 110 Hz 涨到 220 Hz，半音数恰好相差 12——**无论绝对频率多高，一个八度都是 12 个半音**，这正是对数刻度对音高知觉的忠实表达。这个半音刻度到《音乐信息检索》专题的 Chroma 特征时还会再次出现。

### 1.2 浊音段才有音高

基频来自声带振动，**只有浊音（voiced）段才有定义**；清音（unvoiced）段声带不振动，谈不上音高。所以音高特征的第一步是**浊音/清音判决（voicing decision）**：每一帧要么输出一个 $f_0$ 值，要么标记为「无音高」。<span class="marginnote">YIN、自相关等方法输出的是「周期估计 + 置信度」。工程上通常设阈值：置信度低于阈值就把该帧判为清音，$f_0$ 置为无效值（如 0 或 NaN），而不是硬给一个数值——硬给会在清浊交界处制造假跳变。</span>

**辨析｜易错点：$f_0$ 不是处处存在的连续曲线。** 把它画出来，浊音段是连续曲线，清音段是缺口。后续做统计（均值、斜率）前，要决定缺口怎么处理：插值、忽略，还是把「有/无音高」本身也作为一个特征。对汉语这种声调语言，清音段的比例直接影响感知，处理方式值得专门设计。

## 2 音高特征的工程细节：平滑、纠错与统计

原始 $f_0$ 曲线噪声大，直接进模型会引入抖动。三道常规工序：

1. **倍频纠错（octave error correction）**：自相关法常把 $f_0$ 估成真实值的 2 倍或 1/2。可用中值滤波或动态规划在时间轴上做平滑，抑制这种倍频跳变。
2. **平滑（smoothing）**：用 5 帧左右的中值滤波去掉孤立跳变点——中值滤波对「野点」比均值滤波稳健。
3. **对数化与归一化**：转 log 域后，说话人之间的音高水平差异主要落在均值上，可再做均值减除以消去说话人差异——这与下节 CMVN 的思想同源。

拿到干净的 $f_0(t)$ 后，根据任务粒度聚合特征：

| 粒度 | 典型统计量 | 用途 |
| --- | --- | --- |
| 帧级 | $f_0(t)$、浊音标志、一阶差分 | 声调建模、韵律声学模型输入 |
| 音节/词级 | 均值、中位数、极差、斜率、起止调型 | 声调识别、重音检测、情感 |
| 句级 | 全局均值、标准差、范围、句末升降、jitter | 说话人识别、情感、临床嗓音评估 |

## 3 韵律的三根支柱：音高、时长、能量

韵律不止音高。经典三分法把韵律拆成**音高（pitch）、时长（duration）、能量（intensity）**三根支柱：

| 韵律维度 | 声学对应 | 典型特征 |
| --- | --- | --- |
| 音高 | $f_0$ 曲线 | 均值、斜率、范围、句末调型、jitter |
| 时长 | 音段/音节时长、停顿 | 语速（音节/秒）、停顿时长、VOT、韵律边界 |
| 能量 | 幅度包络 | 均方根能量、峰值、shimmer、重音强度 |

**音高**承载**语调**与**声调**：汉语普通话四声就是四种 $f_0$ 走向——阴平高平、阳平中升、上声降升、去声高降。<span class="marginnote">世界上约 60%–70% 的语言是声调语言（tonal language），汉语、泰语、约鲁巴语都是。声调语言里音高走向直接决定词义，因此韵律特征对 ASR 的正确率影响显著——这也是中文识别系统特别重视 $f_0$ 特征的原因。</span>
- **时长**承载**节奏**与**边界**：语速快慢、停顿位置决定了句子的韵律短语边界，也影响断句理解。时长特征常取「音节时长的相对比例」而非绝对秒数，以消去语速差异。
- **能量**承载**重音**：重读音节往往能量更高、时长更长、$f_0$ 有峰。三者在句中常协同出现，所以很多系统把三路特征拼成一个**韵律特征向量**。

**辨析｜易错点：韵律特征是「相对的」，不是「绝对的」。** 同样的绝对时长、绝对 $f_0$，在不同说话人、不同语速下含义完全不同。所以跨说话人、跨语速的任务里，韵律特征几乎都要先归一化（相对时长、$f_0$ 的 z-score、能量比），否则系统学会的是说话人差异，而不是韵律差异。

## 4 公式解析：jitter——基音周期的逐周期抖动

**Jitter（基音抖动）**：相邻周期长度 $T_i$ 之间逐周期（cycle-to-cycle）的随机起伏，是音高特征家族里最精细的一个。它的局部定义（Praat 的标准算法之一）是：

$$Jitter_{local} = \frac{\dfrac{1}{N-1}\displaystyle\sum_{i=1}^{N-1}\left|T_i - T_{i+1}\right|}{\dfrac{1}{N}\displaystyle\sum_{i=1}^{N} T_i} \times 100\%$$

逐步拆解：

- **第一步，看分子**：$\frac{1}{N-1}\sum_{i=1}^{N-1}|T_i - T_{i+1}|$ 是**相邻周期差绝对值的平均**。周期长度 $T_i = 1/f_0$，相邻周期若完全规整，这一项为 0；声带振动越不稳定，这一项越大。
- **第二步，看分母**：$\frac{1}{N}\sum_{i=1}^N T_i$ 是**平均周期**。用平均周期做分母，把绝对抖动转换成**相对抖动百分比**，从而在不同基频（男声低、女声高）之间可比。
- **第三步，看 $\times 100\%$**：结果变成百分比。健康成人的 local jitter 通常在 **1% 以下**；嗓音障碍、情绪激动、某些疾病状态下 jitter 显著升高。<span class="marginnote">Jitter 与能量域的 shimmer（逐周期幅度抖动）是临床嗓音评估（如 Praat 声学分析、MDVP）的标配参数，也出现在说话人识别与情感识别里——它刻画的是声带振动本身的精细不稳定度。</span>
**第四步，理解定位**：jitter 是**短时、精细**的特征，与均值、斜率这类**长时**统计互补。一个完整韵律特征集往往「长短结合」：长时统计刻画语调走势，jitter/shimmer 刻画发声质量。

## 5 韵律特征如何进入语音系统

韵律特征不是被 MFCC 替代，而是**与 MFCC 等谱特征配合**：

**语音识别（ASR）**：汉语等声调语言中，把 $f_0$ 及其差分拼进特征向量（如 39 维 MFCC + 若干维音高），可显著降低声调易混音节（如「妈/马」）的混淆。<span class="marginnote">这也是传统 GMM-HMM 中文系统里常见的「F0 + Delta + Delta-Delta」拼接。到了端到端时代，Whisper 等模型不显式用 $f_0$，但对声调语言仍需大量数据来隐式学习音高走向。</span>
- **说话人识别**：说话人身份很大程度藏在音高水平与发声音质里——$f_0$ 均值、jitter 是经典说话人特征，见本专题《声纹识别与说话人技术》各节。
- **语音合成（TTS）**：TTS 前端要**预测**韵律（时长、$f_0$ 曲线），后端声码器要把预测的 $f_0$ 还原成波形；FastSpeech 2 显式建模时长与音高，正是「韵律从提取走向生成」的典型。
- **情感识别**：语调起伏程度、语速、能量峰是情感分类的高区分度特征，也与心理学里「副语言（paralanguage）」的研究一脉相承。

一个提取音高与韵律统计量的 Python 示意（用 `librosa.pyin` 估计 $f_0$）：

```python
import numpy as np
import librosa

def prosodic_features(y, fs):
    """提取音高与韵律统计量：f0 曲线 + 浊音比例 + 能量。"""
    # YIN 基音估计：f0（无音高处为 NaN）、浊音标志
    f0, voiced_flag, voiced_probs = librosa.pyin(
        y, fmin=60, fmax=500, sr=fs)

    f0_voiced = f0[~np.isnan(f0)]            # 只取浊音帧
    stats = {
        "f0_mean": np.mean(f0_voiced),       # 音高水平
        "f0_std": np.std(f0_voiced),         # 语调起伏程度
        "f0_range": np.max(f0_voiced) - np.min(f0_voiced),
        "voiced_ratio": np.mean(~np.isnan(f0)),  # 浊音段比例
        "rms": np.sqrt(np.mean(y ** 2)),     # 能量
    }
    return f0, stats
```

## 6 小结

- **音高（pitch）是知觉量，$f_0$ 是物理量**；音高特征应在对数/半音域处理，其对数本质由韦伯—费希纳律决定。
- **基频只在浊音段有定义**，音高特征的第一步是浊音/清音判决与倍频纠错。
- **韵律 = 音高 + 时长 + 能量**三根支柱，各有典型的帧级、音节级与句级统计量。
- **韵律特征是相对量**，跨说话人、跨语速时必须归一化，否则模型学到的是说话人差异。
- **jitter（基音抖动）** 用逐周期长度变化率刻画发声精细不稳定度，是临床嗓音与情感分析的重要参数。
