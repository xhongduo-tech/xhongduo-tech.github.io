## 为什么从 FBank 开始

上一节我们把 MFCC 的流水线走到了底。这一节讲一个「反其道而行」的选择：**FBank（FilterBank，滤波器组特征）**，又叫 **log-Mel Spectrogram（log-Mel 语谱图）**——它把 MFCC 流水线在 DCT 这一步**停下**，直接拿那 $M$ 个对数能量当特征。

为什么有人愿意放弃 MFCC 辛辛苦苦做的去相关与降维？答案藏在深度学习时代的一个观察里：**DCT 的去相关假设「特征各维应当独立」，这个假设只对高斯混合模型成立；对深层神经网络，冗余信息反而有用，网络自己就能学出相关性。**<span class="marginnote">FBank 在 2010 年代随 DNN-HMM 崛起而重新流行，如今是端到端语音识别（LAS、RNN-T、Conformer、Whisper）的默认前端。可以说，MFCC 是「统计模型时代」的特征，FBank 是「神经网络时代」的特征。</span>

这一节要回答三个问题：FBank 到底是什么、它和 MFCC 差在哪一步、以及为什么深度学习更喜欢它。

## 1 从语谱图到 FBank：只差一个 DCT

回顾 MFCC 流水线的后半段：

$$X(k) \xrightarrow{\text{Mel 滤波器组}} E_m \xrightarrow{\ \log\ } \log E_m \xrightarrow{\ \text{DCT}\ } C_c$$

FBank 特征就是**停在 $\log E_m$ 这一格**，把 $M$ 个对数能量直接排成向量：

$$\mathbf{x}_{\text{FBank}} = \bigl[\, \log E_1, \ \log E_2, \ \dots, \ \log E_M \,\bigr]$$

它跟语谱图有什么关系？**语谱图**是「时间 × 频率」的能量图（见《语谱图的生成与解读》），横轴时间、纵轴频率、颜色代表能量。**log-Mel 语谱图**就是把纵轴换成 Mel 频带、颜色取对数能量——它和 FBank 是同一个东西的两种呈现：一个是「每帧一个 $M$ 维向量」的数据视角，一个是「整句一张图」的图像视角。<span class="marginnote">在图像视角下，log-Mel 图天然是二维的（帧序 × Mel 频带），可以直接喂给二维卷积神经网络——这就是视觉模型（ViT、ConvNeXt 等）被应用到语音任务时的输入形式。FBank 与「log-Mel 图」在这里等价。</span>

**关键差别一句话：MFCC = FBank 的 DCT + 截断。** 其余每一步（预加重、分帧加窗、FFT、Mel 滤波器组、log）完全相同。

## 2 公式解析：为什么 log 之后还能直接当特征

FBank 的数学与 MFCC 前半段一模一样。我们把它写完整：

第 $m$ 个 Mel 滤波器的能量：

$$
E_m = \sum_{k=0}^{N/2} \lvert X_m(k)\rvert^2 H_m(k)
$$

对数能量：

$$
\log E_m = \log \sum_{k} \lvert X(k)\rvert^2 H_m(k)
$$

逐步拆解：

- **第一步，功率谱 $\lvert X(k)\rvert^2$**：对加窗后的一帧做 FFT 后取模平方。取平方而非取模，是因为能量（功率）在物理上可加，且与响度感知的映射更直接。
- **第二步，$H_m(k)$ 三角滤波器**：第 $m$ 个 Mel 三角滤波器在 Mel 轴上等宽。它把原始频谱「分箱」，每个箱子得到一个标量 $E_m$——这是**降采样**：从几百上千个 FFT 频点压成 $M$（20–40）个感知频带。
- **第三步，$\log$ 压缩**：把能量压成对数尺度。这一步同时做三件事——匹配人耳响度感知、把乘性信道增益变成加性偏移、稳定特征数值范围。

**为什么 $\log$ 之后不接 DCT 也能用？** 因为使用特征的方式变了。在 GMM 时代，特征喂给「各维独立的高斯分量」，相邻维高度相关会让协方差矩阵病态；而 DNN 的第一层线性变换 $W\mathbf{x} + \mathbf{b}$ **自己就能学出任意相关性**，冗余的相邻频带信息反而提供了更平滑的谱上下文。<span class="marginnote">直觉：MFCC 相当于「人先帮模型把信息压缩好再喂」；FBank 是「把原始感知谱原样喂给模型，让模型自己决定怎么压缩」。后者给模型更大的自由度，代价是输入维度更高、对数据量与正则化的要求也更高。</span>

## 3 FBank 与 MFCC 的实用对比

| 对比维度 | MFCC | FBank（log-Mel） |
| --- | --- | --- |
| 末尾处理 | DCT + 截断取前 13 个 | 保留全部 $M$ 个（20–40） |
| 维度 | 低（13–40） | 较高（40–80 甚至更多） |
| 维间相关性 | 已去相关、近似独立 | 高度相关（相邻频带平滑） |
| 抗噪性 | 截断丢掉了高频细节，天然去噪 | 保留全部细节，噪声也在 |
| 对 GMM | 友好（独立假设） | 不友好（协方差病态） |
| 对 DNN | 可用但冗余信息被提前丢掉 | 更常用，信息更全 |
| 跨系统可比性 | 曾是标准，各库差异小 | 依赖 Mel 滤波器组参数，差异大 |

这张表引出一个容易被忽视的结论：**MFCC 的「抗噪」部分来自截断，而截断也丢信息；FBank 保留信息，但把去噪的任务交给了后续的归一化与网络。** 没有绝对谁优谁劣，只有「匹配哪类模型」的问题。

**辨析｜易错点：FBank 的 Mel 滤波器个数 $M$ 不是越多越好。** 常见实现里 $M = 40$ 是 16 kHz 语音的常用值，$M = 80$ 常见于高性能系统。$M$ 太大，每个频带太窄，退化成「直接采样谱线」，Mel 刻度的平滑作用消失；$M$ 太小，频带太宽，会抹掉共振峰等关键结构。调 $M$ 时应同时检查共振峰是否还能在 log-Mel 图上分辨。<span class="marginnote">一个经验法则：$M$ 的数量级应与「你希望特征保留的频率分辨率 × 人耳灵敏度」匹配。对 8 kHz 电话语音，$M = 22$ 就够了；对 16 kHz 宽带语音，40–80 更合理。</span>

## 4 工程细节：从 FBank 到网络输入

把 FBank 特征喂给神经网络的常见做法：

1. **分帧加窗**：25 ms / 10 ms 帧移，与 MFCC 相同。
2. **FFT 与 Mel 滤波器组**：得到每帧 $M$ 维 log 能量。
3. **归一化**：常用**倒谱均值方差归一化（CMVN）**或均值减法（mean subtraction），对每维独立做，消除信道与说话人的加性偏移。这一节的细节放在本专题《CMVN 与特征增强》专门讲。
4. **拼接上下文**：DNN 时代常用「左右各 $\pm N$ 帧拼接」（如 11 帧），给网络时间上下文；端到端模型则常把整句 log-Mel 图直接输入，让注意力自己看。
5. **数据增强**：SpecAugment（对 log-Mel 图的频带/时间块做随机掩蔽）是当前主流——它直接作用在 FBank 上，而不是 MFCC 上。

一个小例子，把一帧变成 FBank：

```python
import numpy as np
import librosa

def fbank_frame(x, fs=16000, n_fft=512, n_mels=40):
    # x: 一帧语音（一维数组）
    S = np.abs(librosa.stft(x, n_fft=n_fft, hop_length=n_fft//2, win_length=n_fft))
    S = S ** 2  # 功率谱
    return librosa.filters.mel(sr=fs, n_fft=n_fft, n_mels=n_mels) @ S
```

注意 `librosa.stft` 默认返回复数谱，取模平方后乘 Mel 滤波器组。与 MFCC 的唯一差别是**省略了 `librosa.feature.mfcc` 内部的 DCT 步骤**——它等价于 `log(mel_spec)`。

## 5 为什么端到端时代 FBank 胜出

端到端语音识别（CTC、LAS、RNN-T、Conformer）几乎清一色用 log-Mel 输入，原因有三：

- **信息守恒**：端到端模型把「特征提取」也并入可训练范畴的一部分。MFCC 的 DCT 截断是**不可逆的有损压缩**，一旦截掉就再也找不回来；FBank 保留了全部 Mel 频带信息，网络可以自己决定用哪些。
- **卷积友好**：log-Mel 图的二维结构（时间 × 频带）可以直接走 2D 卷积，频率轴的「相邻关系」被卷积核天然利用。MFCC 的 13 维向量没有这种规则结构。
- **简化流程**：省去 DCT 与截断，整个前端就是「FFT + Mel + log」，实现简单、跨框架一致，也便于 SpecAugment 这类直接在特征图上做的增强。

**辨析｜易错点：「FBank 一定比 MFCC 好」是错的。** 在低资源、小模型、强统计假设（如 GMM、或需要与旧系统兼容）的场景，MFCC 的去相关与降维依然是优势。**选择特征的标准是「与后续模型的假设匹配」**，而不是「哪个更新」。<span class="marginnote">一个相关话题：有些工作把 MFCC 也「可微化」（如让 DCT 系数可学习），本质上是在 FBank 与 MFCC 之间找可训练的最佳折中。这说明两者不是对立，而是「手工压缩」与「交给模型压缩」的两个端点。</span>

## 6 小结

- **FBank = MFCC 去掉 DCT 与截断**：保留全部 $M$ 个 log-Mel 频带能量，维度更高、维间高度相关。
- **log-Mel 图与 FBank 是同一特征**：一个是数据视角（每帧向量），一个是图像视角（时间 × Mel 频带）。
- **与模型匹配**：MFCC 匹配 GMM 的独立假设；FBank 匹配 DNN 的学习能力——深度网络自己会处理相关性。
- **工程要点**：$M = 40$（16 kHz）是常用起点；归一化（CMVN）与 SpecAugment 都直接作用在 FBank 上。
- **不是更新就一定更好**：低资源 / 小模型 / 统计模型场景下 MFCC 仍占优。

在下一节，我们换一条感知特征路线：它不是从 Mel 刻度出发，而是把**临界频带、等响曲线、强度—响度幂律**整套心理声学搬进线性预测框架——**感知线性预测系数（PLP）**。
