## 为什么从线性预测开始

上一节的语谱图，把「共振峰」画成了横向暗带——你「看得出」F1、F2 大致在哪儿，却说不出它们精确在多少赫兹。工程师不能靠肉眼读数，需要**算法把「看起来是那儿」变成「精确地在那儿」**。线性预测分析（Linear Predictive Coding，LPC）正是把共振峰、谱包络变成数字的第一把数学手术刀。

LPC 的思想朴素得惊人：**语音信号是高度可预测的**。发一个元音时，声带每秒振动上百次，声道形状在几十毫秒内几乎不变，于是「下一个样本大概是什么」完全可以由「前面几个样本」推断出来。把这种推断写成线性方程，剩下的**预测误差**恰好就是声门激励，而用来预测的那组系数——**LPC 系数**——恰好编码了声道形状，也就是谱包络。<span class="marginnote">「用过去的样本预测未来的样本」在数学上叫自回归（AR）模型，时间序列分析、卡尔曼滤波、信号外推都用同一套语言。你在第二级《概率论》里学过的线性回归是「用别的变量预测这个变量」；LPC 是「用这个变量自己过去的样本来预测自己」——名字里的「自」就在这儿。</span>

LPC 在语音史上地位极高：它是 20 世纪 80 年代**语音编码**（GSM、LPC-10）的基石，是**共振峰估计**与**基音检测**的前置步骤，也是 MFCC 之前最主流的谱包络参数。今天它被神经网络抢了风头，但理解 LPC = 理解「声道是滤波器」这句话的全部含义——那是从「声音是波形」升级到「声音是系统的输出」的关键一跃。

## 1 从预测误差到声道滤波器

把话说成数学。设当前样本为 $s(n)$，用它前面的 $p$ 个样本做线性预测：

$$\hat{s}(n) = \sum_{k=1}^{p} a_k\, s(n-k)$$

预测误差（残差）是：

$$e(n) = s(n) - \hat{s}(n) = s(n) - \sum_{k=1}^{p} a_k\, s(n-k)$$

如果预测得好，$e(n)$ 就很小。把上式反过来写成「用 $e(n)$ 推出 $s(n)$」：

$$s(n) = \sum_{k=1}^{p} a_k\, s(n-k) + e(n)$$

**这就是一个全极点（all-pole）滤波器的时域方程**：当前样本 = 过去 $p$ 个样本的加权和 + 一个输入 $e(n)$。对它做 $z$ 变换，得传递函数

$$H(z) = \frac{1}{1 - \sum_{k=1}^{p} a_k z^{-k}} = \frac{1}{A(z)}$$

$H(z)$ 只有极点（分母为零的点），没有零点——这正是「声道 = 全极点滤波器」的由来。<span class="marginnote">为什么声道没有零点？把声道看成一段段截面积不同的管子，声波在管壁来回反射、驻波共振，数学上导出的传递函数只有极点。鼻音（/m/ /n/）因为鼻腔有旁路，会引入零点——这是全极点模型的先天缺陷，第 5 节再展开。</span>

回到声源—滤波器模型：语音 $s(n)$ 是**激励 $e(n)$ 经过声道滤波 $H(z)$ 的输出**。浊音时 $e(n)$ 是周期性的声门脉冲串（决定基频），清音时 $e(n)$ 是白噪声；而 $H(z)$ 的形状——也就是那组 $a_k$——决定共振峰。**LPC 的任务就是：从一段已知语音 $s(n)$ 里，把 $a_k$ 估计出来。**

## 2 公式解析：最小化预测误差，得到 Yule–Walker 方程

怎么判断「预测得好」？最朴素的标准是**均方误差最小**。在一帧内把预测误差的能量加起来：

$$E = \sum_{n} e(n)^2 = \sum_n \left( s(n) - \sum_{k=1}^{p} a_k\, s(n-k) \right)^2$$

要让 $E$ 最小，对每个 $a_j$ 求偏导并令其为 0。逐步拆解：

- **第一步，对 $a_j$ 求偏导**：由链式法则，

$$\frac{\partial E}{\partial a_j} = -2\sum_n e(n)\, s(n-j) = 0$$

即**误差与过去每一个样本正交**——这与线性回归里「残差与自变量正交」是同一个几何事实。<span class="marginnote">「残差与特征正交」是最小二乘的普适几何：最优解就是「把目标向量投影到特征张成的子空间上」的投影点。你在第二级《线性代数》里学的正交投影，在这里就是 LPC 的全部。</span>

- **第二步，整理成自相关形式**：把 $e(n) = s(n) - \sum_k a_k s(n-k)$ 代回并整理，得到

$$\sum_{k=1}^{p} a_k\, R(\lvert j-k\rvert) = R(j), \qquad j = 1, 2, \dots, p$$

其中 $R(i) = \sum_n s(n)\, s(n-i)$ 是语音帧的**自相关函数**。这组方程叫 **Yule–Walker 方程**（也叫法方程 / 正规方程）。

- **第三步，写成矩阵**：上式等价于 $\mathbf{R}\,\mathbf{a} = \mathbf{r}$，其中 $\mathbf{R}$ 的第 $i$ 行第 $j$ 列是 $R(\lvert i-j\rvert)$。**这种「只和对角线的距离有关」的矩阵叫 Toeplitz 矩阵**，正是它的特殊结构让求解能加速。

- **第四步，求激励增益**：解出 $a_k$ 后，激励的幅度（增益）$G$ 由残差能量决定：

$$G^2 = R(0) - \sum_{k=1}^{p} a_k\, R(k)$$

于是谱包络就是 $\lvert H(e^{j\omega})\rvert = G / \lvert A(e^{j\omega})\rvert$。

**为什么要费这么大劲？** 因为一旦有了 $a_k$，你就有了声道的**解析表达式**：把它在单位圆上求模，就得到一条光滑的谱包络曲线；把它求根，就得到共振峰（共振峰估计一节要用）。一条曲线顶得上几十个语谱图像素。

## 3 Levinson–Durbin：把解方程变成递推

直接解 $\mathbf{R}\mathbf{a}=\mathbf{r}$ 需要 $O(p^3)$ 的复杂度。但 Toeplitz 矩阵对称、且每条对角线上的值相等，**Levinson–Durbin 算法**利用这个结构把复杂度降到 $O(p^2)$，还能顺手得到一组额外参数：

- **反射系数 $k_i$**：声学上对应声道各段之间的反射，满足 $\lvert k_i\rvert \le 1$。**只要所有反射系数的绝对值都小于 1，滤波器就保证稳定**——这是自相关法最漂亮的副产品。
- **LPC 系数 $a_k$**：即全极点滤波器的分母系数。
- **面积函数（截面积比）**：由反射系数 $(1-k_i)/(1+k_i)$ 推出，直接对应声道各段的截面积——这就是「用 LPC 反演声道形状」的原理，也是后面共振峰估计、说话人识别的伏笔。

工程上阶数 $p$ 怎么选？经验法则：**$p \approx f_s/1000 + 2$**。8 kHz 电话语音取 $p \approx 10$，16 kHz 取 $p \approx 16$–18。<span class="marginnote">直觉：每 1 kHz 带宽大约能容纳一个共振峰（外加谱倾斜的补偿），所以阶数约等于 kHz 数再加一点余量。$p$ 太小包络太糊、$p$ 太大开始跟踪谐波细节——包络就「失去包络的意义」了。</span>

下面是一帧语音的 LPC 实现，自相关法 + Levinson–Durbin：

```python
import numpy as np

def lpc(frame, p):
    """自相关法求解 LPC 系数（Levinson-Durbin），返回 a 与增益 G"""
    N = len(frame)
    # 1) 自相关 R(0..p)：用 0-均值、加窗后的帧
    R = np.correlate(frame, frame, mode='full')[N-1 : N+p]
    # 2) Levinson-Durbin 递推
    a = np.zeros(p + 1); a[0] = 1.0
    E = R[0]
    for i in range(1, p + 1):
        acc = R[i] - a[1:i] @ R[i-1:0:-1]   # 第 i 步累加
        k = acc / E                          # 反射系数
        a[i] = k
        a[1:i] = a[1:i] - k * a[i-1:0:-1]   # 更新前 i-1 个系数
        E = (1 - k * k) * E                  # 更新残差能量
    return a, np.sqrt(E)

fs, p = 16000, 16                            # 16 kHz，16 阶
frame = np.hanning(400) * np.random.randn(400)  # 示意：一帧 25 ms
a, G = lpc(frame, p)
```

## 4 一张图看懂 LPC 做了什么

灰色竖线是浊音帧的**谐波梳**——基频 $f_0$ 及其整数倍处的能量尖峰，间隔 = $f_0$；红色平滑曲线是 **LPC 谱包络** $\lvert H(e^{j\omega})\rvert$，它不理会谐波的细碎起伏，只在**共振峰**处隆起。读图要点：**包络的峰 ≠ 谐波的峰**。谐波每隔 $f_0$ 就有一个，包络只在共振峰处隆起——LPC 要做的事，就是「对谐波取平滑」，把离散的尖峰抽象成一条连续曲线。

## 5 辨析与易错点

- **LPC 是全极点模型，装不下零点。** 鼻音、塞音爆破、以及 /r/ 这类带鼻腔旁路或反共振的声音，频谱里有「谷」（零点），全极点模型只能用极高的阶数去逼近，效果打折。<span class="marginnote">工程折中：普通语音分析把阶数从经验值加高 2–4 就能把鼻音应付过去；真正较真时会用极零（ARMA）模型，那就要解更复杂的方程了。</span>
- **谐波峰 ≠ 共振峰**：拿原始频谱找峰，找到的多半是谐波，不是共振峰。必须先得到包络再找峰——这正是 LPC 的价值，下一节共振峰估计会反复强调。
- **阶数 p 不是越大越好**：太大时包络开始「追着谐波跑」，共振峰位置被谐波结构带偏；太小则漏峰。经验法则只是起点，具体任务要试。
- **自相关法 vs 协方差法**：自相关法用窗内全部样本（窗外视为 0），保证 Toeplitz 结构、保证稳定，但帧边缘有窗口失真；协方差法不加窗、拟合更准，却可能给出不稳定的滤波器。**绝大多数语音任务用自相关法。**
- **LPC 系数 ≠ 共振峰参数**：$a_k$ 是滤波器分母系数，要先求根才能变成共振峰频率与带宽。别把系数直接当频率。

## 6 小结

- **线性预测**：$\hat{s}(n) = \sum a_k s(n-k)$，预测误差即激励；$s(n) = \sum a_k s(n-k) + e(n)$ 是全极点滤波器的时域方程。
- **谱包络**：$\lvert H(e^{j\omega})\rvert = G/\lvert A(e^{j\omega})\rvert$，LPC 系数编码声道（共振峰），残差编码激励（基频 / 清浊）。
- **求解**：均方误差最小化 → Yule–Walker 方程 → Toeplitz 矩阵；**Levinson–Durbin 递推 $O(p^2)$**，反射系数保证稳定。
- **阶数**：经验法则 $p \approx f_s/1000 + 2$；太大追谐波、太小漏峰。
- **先天限制**：全极点模型对鼻音等含零点的声音逼近不足。

在下一节，我们换一条完全不同的路估计谱包络——**倒谱分析**。它把「卷积」变成「加法」，在倒频率轴上把声门激励与声道包络一刀切开，顺带还能测出基频。
