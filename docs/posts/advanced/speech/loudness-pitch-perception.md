## 为什么从响度与音高开始

上一课我们把人耳的频率分辨率量化成了临界频带，又造出了 Mel 与 Bark 两把「感知尺子」。这一课补上感知地图上另外两个基本维度：**响度（loudness）**与**音高（pitch）**。

响度与音高是声音的两大「主观属性」。物理上，一个纯音只有两个客观量——频率与声压级；而人的主观体验却从中「长」出了至少两套心理量——音高与响度。**物理量与心理量之间隔着一条曲线**：100 Hz 的 60 dB 声，听起来比 1 kHz 的 60 dB 声轻得多；一个 6 kHz 的音调在 90 dB 下听起来会「变高」。这些「非线性」，正是等响曲线要讲的故事。

这一课是心理声学（psychoacoustics）的核心，也是后面一系列工程决定的依据：为什么噪声计要加权（dBA），为什么响度要归一化（LUFS），为什么 TTS 里要显式建模音高与能量。先从最朴素的问题出发：**一「响」到底是怎么度量出来的？**

## 1 响度：声压级是物理量，响度是心理量

### 声压级：物理世界的尺子

声音的「大小」首先是一个物理量。声波是空气压强的起伏，我们取它的均方根值与参考压强的比，定义为**声压级（Sound Pressure Level，SPL）**：

$$L_p = 20\,\log_{10}\frac{p_{rms}}{p_0}, \qquad p_0 = 20\,\mu\text{Pa}$$

$p_0 = 20\,\mu\text{Pa}$ 是人耳听阈附近的参考压强。注意这里用了对数：人耳能承受的最大声压与听阈相差约 $10^6$ 倍（120 dB），用线性刻度根本无法画下。<span class="marginnote">「用对数压缩巨大范围」这个思路你在第一级《指数与对数》与第三级《信息论》里反复见过：分贝、香农的信息量、mel 刻度，本质都是把物理范围压缩成感知均匀的标尺。</span>

### 响度：主观的「大小」

但**响度（loudness）**不是声压级。它定义为主观感受到的声音大小——「这个声音听起来有多响」。声压级翻一倍（+6 dB），响度远没有翻一倍；要让人感觉「响了一倍」，声压级通常要增加约 10 dB。

这条经验可以写成两条定律：

- **韦伯—费希纳定律（Weber–Fechner law）**：人能够分辨的最小强度变化，与刺激强度本身成正比。对响度，这个**差阈（JND）**在中频区约 0.5–1 dB。
- **史蒂文斯幂定律（Stevens' power law）**：费希纳的「对数律」只在中等强度附近近似成立；更精确的结论是，响度 $\psi$ 与声强 $I$ 之间是幂函数关系：

$$\psi = k\, I^{0.3}$$

指数 $0.3$ 意味着：声强增大 10 倍，响度只增大约 $10^{0.3} \approx 2$ 倍——这正是「响一倍需要 +10 dB」的数学来源。<span class="marginnote">幂定律是心理物理学最具代表性的成果之一：不同感觉通道的指数不同（响度 0.3、亮度 0.5、长度 1.0）。「感觉量的相对变化 ∝ 物理量的相对变化」这条曲线，也是第一级《导数》里「弹性」概念的生理解释。</span>

**重点：声压级是客观测量，响度是主观判断；两者之间不是线性的，而是幂函数。** 任何「给声音定大小」的算法，若直接用 dB 当响度用，都会在低频和高频处系统性失真。

## 2 音高感知：频率与音高的距离

音高（pitch）是「这个音听起来有多高」，它主要由基频决定，但**并不等于基频**。

- **差阈**：中频段人耳能分辨约 0.2%–0.3% 的频率差，即 1 kHz 处大约 2–3 Hz。低于约 1 kHz 时，差阈近似恒定（绝对 ~1–3 Hz）；更高频则接近比例恒定（相对 ~0.5%）。
- **mel 刻度的意义**：上一课的 Mel 刻度 $m = 2595\log_{10}(1+f/700)$，就是把「感知音高」锚定成可计算标尺——它的对数弯折，正对应着基底膜的对数铺开。
- **音高不只看频率**：同一频率的纯音，响度增大时音高会略微偏移（强度—音高效应）；两个相差很远的音若缺少基频，听者仍能「脑补」出基频（缺失基频现象，missing fundamental）。后者说明音高是大脑的计算结果，不是耳蜗的直接输出。

**辨析｜易错点：** 频率是客观物理量（Hz），音高是主观心理量（mel、音分）。「一个 440 Hz 的音」和「听起来是 A4 的音」不是一回事——谐波丰富的声源即使滤掉 440 Hz 基频，听感音高仍可能是 A4。语音识别里的基频提取（Pitch / F0）测的是物理基频，而韵律建模要的是听感音高，两者之间的桥梁正是这一课的心理声学。

## 3 等响度曲线：响度与频率的纠缠

响度既依赖声压级，也依赖频率——这就是**等响度曲线（equal-loudness contours）**存在的原因。

**核心概念：响度级（loudness level）**，单位 **phon**——把一个声音的响度，用「与之等响的 1 kHz 纯音的声压级」来表示。1 kHz 的 40 dB 音，其响度级就是 40 phon。这样，每个声音都得到一个与频率无关的「响度级」数值。

把不同频率下「听起来一样响」的声压级连成线，就得到等响度曲线：

![等响度曲线：同一条曲线上的声音听感一样响](/images/speech/loudness-pitch-perception-1.svg)

读这张图有三个要点：

- **曲线整体向右下倾斜、两端翘起**：要发出同样响度的声音，低频（<500 Hz）和高频（>5 kHz）需要远高于中频的声压级。20 Hz 处要达到 40 phon，需要约 110 dB；而在 1 kHz 只需 40 dB。
- **人耳对 2–4 kHz 最敏感**：听阈（最下面一条 0 phon 曲线）在 3–4 kHz 处反而低于 0 dB——这一点与耳道共振、外耳放大（约 10 dB）一致，我们在《人耳听觉系统》一课讲过。
- **曲线不是等距的**：低频段曲线之间挤在一起，说明低频处「加 10 dB 才响一倍」；中频段较疏，响度随 dB 增长更快。**响度—dB 的关系随频率变化，这正是幂定律在不同频段上指数不同的体现。**

**辨析｜易错点：** phon 与 sone 是两套尺子。**phon 是响度级**——与 1 kHz 参考音比较出来的「等同响度」；**sone 是响度**——1 sone 定义为 40 phon，响度翻倍则 sone 翻倍。phon 是「序数尺」，告诉你哪个响；sone 是「比率尺」，告诉你响几倍。工程里「响度归一化」用的是后者。

## 4 公式解析：sone 与 phon 的换算

把「响度翻倍」这件直觉，写成精确公式：

$$S = 2^{(P - 40)/10}, \qquad (P \ge 40\ \text{phon})$$

其中 $P$ 是响度级（phon），$S$ 是响度（sone）。<span class="marginnote">注意 $P<40$ phon 时这条公式不再适用，低响度区用的是另一条指数曲线 $S = (P/40)^{2.86}$。教材给这条上限式，是因为语音、音乐的响度归一化基本都发生在 40 phon 以上。</span>分四步拆开：

**第一步：锚点 $P=40$。** 1 sone 被定义为 40 phon 的响度。把 $P=40$ 代入：$S = 2^{(40-40)/10} = 2^0 = 1$，恰好还原定义。锚点让这条曲线从「1 sone ↔ 40 phon」出发。
**第二步：底数 2 与「每 10 phon 翻倍」。** 指数 $(P-40)/10$ 表明：$P$ 每增加 10，指数增加 1，$S$ 就乘以 2。**10 phon 的响度差 ≈ 感觉响一倍**——这正好对应前面「+10 dB 响一倍」的经验，也与史蒂文斯幂定律的指数 0.3 自洽（10 dB ≈ 声强 ×10，$10^{0.3}\approx 2$）。
**第三步：为什么是指数式。** 幂定律 $\psi = kI^{0.3}$ 取对数后，响度级的 dB 值与 $\log_2 S$ 成正比；把比例系数归一化到「每 10 phon 翻倍」，就得到这条以 2 为底的指数。**「线性感觉」是「对数物理」的镜像**——这正是心理物理学的核心心法。
**第四步：数值验证。** $P=50$：$S=2^1=2$ sone（响一倍）；$P=60$：$S=2^2=4$ sone；$P=80$：$S=2^4=16$ sone。反过来，$S$ 翻倍 $\Rightarrow$ $P$ 增加 10 phon。

用 Python 写这两个换算，就是一行函数：

```python
from math import log2

def phon_to_sone(P):
    """响度级（phon）→ 响度（sone）：每 +10 phon 响度翻倍。"""
    return 2 ** ((P - 40) / 10)          # 仅对 P ≥ 40 phon 有效

def sone_to_phon(S):
    """响度（sone）→ 响度级（phon）：1 sone = 40 phon。"""
    return 40 + 10 * log2(S) if S > 0 else 0.0
```

## 5 从感知到工程：计权、响度归一化与特征

等响度曲线不是课本里的装饰，它直接塑造了三个工程惯例：

**频率计权（A / C weighting）**：声级计测出的 dB 不能直接当响度用——同样 80 dB，1 kHz 比 100 Hz 响得多。于是有了计权曲线：**dBA** 近似 40 phon 等响曲线的反形，**dBC** 近似 100 phon 曲线。今天几乎所有环境噪声法规、音频设备指标都标 dBA，正是因为它更接近「人实际觉得多吵」。<span class="marginnote">dBA 曲线的反形与上图 40 phon 曲线几乎重合——这就是我在图里把 40 phon 用红色虚线标出的原因。数字音频里若想「如实反映响度」，就要用 dBA 而非裸 dB。</span>
- **响度归一化（Loudness Normalization）**：流媒体与广电用 **LUFS**（Loudness Units Full Scale，1 LU ≈ 1 dB）对整段内容做响度归一，YouTube、Spotify、Netflix 各有一套目标值。它不是峰值归一，而是基于「人感知的响度」——本质上是把等响曲线与 sone 模型工程化。
- **语音特征与韵律建模**：基频（F0）与短时能量是 TTS 韵律、情感合成的直接输入；现代语音大模型预测音高与能量时，也多把目标映射到感知空间而非物理空间。到《音高（Pitch）与韵律特征的提取》一课，我们会把 F0 提取与这一课的感知标尺接上。

**重点：等响曲线告诉我们，任何「用 dB 当响度」的简化都会失真；工程上要么加权，要么做感知归一。** 这是心理声学「从实验曲线到生产标准」的标准路径，也是后面音频编解码器（MP3/AAC/EnCodec）把「感知损失」写进目标函数的伏笔。

## 6 小结

- **响度**是主观量：与声压级成幂函数关系（$\psi = kI^{0.3}$），「响一倍」约需 +10 dB；韦伯—费希纳定律给出差阈约 0.5–1 dB。
- **音高**也非频率：差阈在中频约 0.2%–0.3%；Mel 刻度把感知音高标量化；强度与缺失基频都会改变音高感知。
- **等响度曲线**（ISO 226）：同一曲线上声音「听感等响」；低频、高频需要更大的声压级，人耳对 2–4 kHz 最敏感（听阈低于 0 dB）。
- **phon 是响度级、sone 是响度**：$S = 2^{(P-40)/10}$，1 sone = 40 phon，响度翻倍 = +10 phon。
- 工程落地：**dBA/dBC 计权**近似等响曲线的反形，**LUFS** 做感知响度归一，F0 与能量特征直接服务 TTS 韵律。
