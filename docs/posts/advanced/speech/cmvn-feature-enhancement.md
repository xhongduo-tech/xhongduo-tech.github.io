## 为什么从 CMVN 开始

同一个「你好」，用手机录、用麦克风录、隔着听筒录，得到的 MFCC 会明显不同——**说话人没变，信道变了**。语音系统在实验室数据上表现良好，一到真实环境就退化，很大一部分原因就是这种**信道失配（channel mismatch）**。

本专题此前的特征提取都在「把一帧语音变成一组系数」。CMVN 要解决的是这些系数的**分布漂移**：把每个倒谱维度的均值和方差规整到标准形态，抹掉信道与说话人带来的整体偏移。<span class="marginnote">上一节《Delta 特征》已经预告过顺序问题：先 CMVN、再算 Delta，否则信道偏移会被差分放大。特征归一化是特征流水线的收尾工序，也是传统 GMM-HMM 系统几乎必做的标准操作。</span>

## 1 信道失真如何污染特征：卷积变成加法

设干净语音为 $x(t)$，信道（麦克风、房间、传输线路）的冲激响应为 $h(t)$，则采集到的信号是

$$y(t) = x(t) \ast h(t)$$

线性时不变信道是**卷积**。时域卷积对应频域相乘：

$$Y(f) = X(f)\, H(f)$$

取对数后相乘变相加：

$$\log|Y(f)| = \log|X(f)| + \log|H(f)|$$

再回到倒谱域（见本专题《倒谱分析：同态滤波与复倒谱》），每帧特征向量就变成了「干净语音的倒谱 + 一个由信道决定的**常数偏移向量**」：

$$\mathbf{c}_y = \mathbf{c}_x + \mathbf{c}_h$$

这个 $\mathbf{c}_h$ 在同一信道内近似恒定，跨信道则不同——它正是让特征分布「漂移」的元凶。<span class="marginnote">这就是同态滤波（homomorphic filtering）的智慧：把卷积关系通过对数变换拆成加法关系，再在加性域里处理。倒谱域里信道是「慢变的加性分量」，所以减去均值就能把它消掉——这是 CMS 的基本思想。</span>

## 2 倒谱均值方差归一化的数学

**倒谱均值减除（CMS，Cepstral Mean Subtraction）**：对每个倒谱维度，减去该维度在整个句子上的均值，消去静态信道偏移 $\mathbf{c}_h$。

**倒谱均值方差归一化（CMVN）**：在 CMS 基础上再除以标准差，进一步消除增益（音量）差异带来的尺度漂移：

$$\hat{c}_m(t) = \frac{c_m(t) - \mu_m}{\sigma_m}$$

其中 $m$ 是倒谱维度下标（$m = 0,\dots,M-1$），$\mu_m = \frac{1}{T}\sum_{t=1}^{T} c_m(t)$ 是第 $m$ 维在时间上的均值，$\sigma_m$ 是对应的标准差。

**辨析｜易错点：CMVN 是「逐维度、跨时间」的归一化，不是「跨维度」的归一化。** 它是把每个倒谱系数在**时间轴**上拉成零均值单位方差，而不是把同一帧内不同维度相互标准化。方向弄反，特征的信息结构就被破坏了。这套「逐维 z-score」与统计学里的标准化同源，见第二级《概率论与数理统计》。

## 3 公式解析：为什么 CMVN 恰好消掉信道

把上一节的结论带进归一化公式，逐项看它做了什么：

$$\hat{c}_m(t) = \frac{\big(c_{x,m}(t) + c_{h,m}\big) - \dfrac{1}{T}\sum_{\tau}\big(c_{x,m}(\tau) + c_{h,m}\big)}{\sigma_m}$$

- **第一步，代入信道模型**：第 $m$ 维的观测 $c_m(t)$ 被拆成干净分量 $c_{x,m}(t)$ 与信道分量 $c_{h,m}$。信道分量**不随 $t$ 变**。
- **第二步，看均值**：$\frac{1}{T}\sum_\tau (c_{x,m}(\tau) + c_{h,m}) = \overline{c_{x,m}} + c_{h,m}$——求和中信道项恰好是常数 $c_{h,m}$，被完整提出。
- **第三步，相减**：$\hat{c}_m(t) = \frac{c_{x,m}(t) - \overline{c_{x,m}}}{\sigma_m}$——**信道项 $c_{h,m}$ 在分子里被消掉了**，剩下的全是干净语音的起伏。
- **第四步，看局限**：这个推导依赖两个假设——信道是**时不变**的（$c_{h,m}$ 恒定）且以**加性**方式进入倒谱（卷积 → 加法）。**加性噪声、混响、时变信道都不满足**，CMVN 对它们无能为力。

**CMVN 消掉的是「加性常数偏移与增益」，不是「噪声」**——这是它最容易被误解的地方。

## 4 工程实现：离线、在线与滑窗

CMVN 的实现按统计量取自哪里分为几档：

- **整句级（utterance-level，离线）**：把一整句的均值、方差算好再归一化。最稳，但需要整句说完才能处理；句子太短时统计量不可靠。
- **说话人级（speaker-level）**：对一个说话人的全部音频统计。适合会话语料，能吸收说话人的固有音色差异。
- **滑窗（sliding window，在线）**：只统计当前帧前后各 $L$ 帧的局部均值方差。用于流式识别；窗越短越能跟踪慢变信道，但统计量噪声越大。
- **因果窗（causal window）**：只用过去帧统计，适合严格流式场景；代价是句子开头若干帧统计不准。

一个 numpy 示意（整句级 + 滑窗）：

```python
import numpy as np

# feat: shape (T, D)，T 为帧数，D 为倒谱维数
def cmvn_utterance(feat, eps=1e-10):
    """整句级 CMVN：逐维减均值、除标准差。"""
    mu = feat.mean(axis=0)
    sigma = feat.std(axis=0) + eps
    return (feat - mu) / sigma

def cmvn_sliding(feat, L=25, eps=1e-10):
    """滑窗 CMVN：只统计当前帧前后各 L 帧的局部均值方差。"""
    T, D = feat.shape
    out = np.zeros_like(feat, dtype=np.float64)
    for t in range(T):
        lo, hi = max(0, t - L), min(T, t + L + 1)
        win = feat[lo:hi]
        out[t] = (feat[t] - win.mean(axis=0)) / (win.std(axis=0) + eps)
    return out

feat = cmvn_utterance(feat)   # 整句级：离线批处理
# feat = cmvn_sliding(feat)   # 滑窗：流式识别用
```

**辨析｜易错点：CMVN 之后别忘重算 Delta。** 特征流水线的正确顺序是「静态特征 → CMVN → 再算 Delta」。如果先算 Delta 再做 CMVN，Delta 里携带的「均值漂移」信息会被错误地归零；反过来，先归一化再差分，才能让 Delta 反映归一化后的纯净动态。

## 5 特征增强的边界：CMVN 之外还有什么

CMVN 是**最便宜的鲁棒化手段**，但它只处理静态加性信道。真实环境里剩下的失配要靠更进阶的**特征增强 / 自适应**：

- **VTLN（声道长度归一化）**：不同说话人声道长短不同，共振峰位置整体缩放。VTLN 用频率轴伸缩（一个标量因子 $\alpha$）把不同说话人的谱对齐，作用在特征提取阶段。<span class="marginnote">$\alpha$ 通常用网格搜索：对每个候选 $\alpha$ 做一次谱变换，选使识别似然最大的那个。它是「说话人自适应」家族里最简单的一员。</span>
- **fMLLR / CMLLR（特征空间最大似然线性回归）**：学一个线性变换 $\mathbf{A}$、$\mathbf{b}$，把特征 $\mathbf{x}$ 映成 $\mathbf{A}\mathbf{x}+\mathbf{b}$，使在自适应数据上的似然最大。这是比 CMVN 更一般的「均值/方差线性规整」。
- **加性噪声**：谱减法、维纳滤波（见本专题《语音增强与降噪》各节）在特征提取前先把噪声减掉——CMVN 帮不了加性噪声，因为噪声不是常数偏移。
- **神经特征增强**：让神经网络（如语音增强模型）在特征域直接输出干净特征，是端到端时代的替代方案。

**辨析｜易错点：CMVN 不是万能的，也不总是最优。** 对**短句**（统计量不足）、**情感/韵律敏感任务**（归一化可能抹掉说话人的整体音高水平）、**多说话人快速切换**（统计窗口混入他人语音），CMVN 需要谨慎使用或调整窗口。它换来的是「跨信道的稳定性」，代价是「损失一部分说话人/情感/韵律的绝对信息」——取舍取决于任务。

## 6 小结

- **信道是卷积、频域相乘、倒谱域相加**：同一信道下信道分量近似常数，这是 CMVN 能消掉它的数学根源。
- **CMS 减均值、CMVN 再除方差**：一个消静态信道偏移，一个再消增益差异；都是**逐维度、跨时间**的归一化。
- **正确流水线顺序**：静态特征 → CMVN → 再算 Delta。
- **实现分三档**：整句级、说话人级、滑窗（含因果窗）；流式系统用滑窗，短句要当心统计量不可靠。
- **CMVN 只对付静态加性信道**；加性噪声、混响、说话人声道差异要靠 VTLN、fMLLR、谱减法与神经增强。
