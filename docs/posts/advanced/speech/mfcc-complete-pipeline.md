## 为什么从 MFCC 开始

上一节我们见过了**倒谱**：对幅度谱取对数再反变换，就能把声源与声道在倒频率轴上分开。这一节要把这条思路推进到底——**MFCC（Mel-Frequency Cepstral Coefficients，梅尔频率倒谱系数）**是语音识别史上使用最广的特征，它把前面学过的三样东西拧成一条流水线：**分帧加窗**（短时平稳）、**Mel 刻度**（人耳感知）、**倒谱**（声道包络）。<span class="marginnote">MFCC 由戴维斯（Steven Davis）与默梅尔斯坦（Paul Mermelstein）于 1980 年提出，此后近四十年一直是自动语音识别（ASR）的特征标准。今天即使端到端大模型改用 log-Mel 图直接喂网络，MFCC 依然是理解「人耳感知如何被编码进特征」的最佳入口。</span>

理解 MFCC 的完整流程，等于把「语音信号 → 机器可算的数字」这条翻译链路从头到尾走了一遍。它既是本专题「听觉特征提取」章的核心，也为后面 GMM-HMM、DNN-HMM 乃至端到端识别提供统一的特征语言。

## 1 一条八步流水线

MFCC 的提取是一条固定的流水线。我们用一张总图把它记住，再逐段拆解。

![MFCC 提取流水线：预加重 → 分帧加窗 → FFT → Mel 滤波器组 → log → DCT 截断](/images/speech/mfcc-complete-pipeline-1.svg)

整条链路的八步是：

1. **预加重**：语音高频段能量衰减更快，用一个一阶高通滤波器 $H(z) = 1 - a z^{-1}$（$a$ 常取 0.97）把高频抬起来，便于后续均匀分析。
2. **分帧加窗**：把语音切成 20–30 ms 的短帧，相邻帧重叠 10 ms，每帧乘汉明窗抑制频谱泄漏。这是《分帧与加窗》那节的内容。
3. **FFT 求幅度谱**：对每帧做离散傅里叶变换，得到幅度谱 $\lvert X(k)\rvert$。
4. **Mel 滤波器组**：用一组三角滤波器把幅度谱按 Mel 刻度分成 $M$ 个频带，每个频带求和得到一个能量 $E_m$。
5. **取对数**：对每个能量取 $\log$，压缩动态范围，模拟人耳响度的对数感知。
6. **DCT**：对 $M$ 个对数能量做离散余弦变换，取前 $K$ 个系数。
7. **动态特征**（可选）：拼接一阶、二阶差分（Delta、Delta-Delta）。
8. **归一化**（可选）：倒谱均值方差归一化（CMVN）。

前四步我们已经全部学过，这一节的**新知识集中在第 4–6 步**：Mel 滤波器组如何构造、为什么取对数、为什么用 DCT 而不是 IDFT、为什么只留前十几个系数。

## 2 Mel 滤波器组：把频率轴弯成人耳的形状

MFCC 与前一节「普通倒谱」的第一个区别，就是它不用原始频率轴，而用 **Mel 刻度**。人耳对频率的感知不是线性的：**在 1000 Hz 以下近似线性，1000 Hz 以上近似对数**——两个频率相隔同样多的赫兹，在音高感知上未必相等。<span class="marginnote">Mel 刻度是在心理声学实验里测出来的：让听者判断「哪个音高是另一个的两倍」，把这种主观的倍频关系映射到数值轴上。它回答的是「人觉得频率翻倍，需要物理频率涨多少」。</span>

把赫兹频率 $f$ 换成 Mel 频率的最常用公式（O'Shaughnessy 形式）是：

$$m = 2595 \log_{10}\left(1 + \frac{f}{700}\right)$$

**Mel 滤波器组（mel filterbank）**就是沿着这条刻度均匀地摆 $M$ 个三角形滤波器：在 Mel 轴上是等间距的，映射回赫兹轴后，低频处窄、高频处宽。第 $m$ 个三角滤波器在频率轴上定义为：

$$
H_m(k) = \begin{cases}
0 & k < f(m-1) \\
\dfrac{k - f(m-1)}{f(m) - f(m-1)} & f(m-1) \le k \le f(m) \\[6pt]
\dfrac{f(m+1) - k}{f(m+1) - f(m)} & f(m) \le k \le f(m+1) \\[6pt]
0 & k > f(m+1)
\end{cases}
$$

其中 $f(m)$ 是第 $m$ 个滤波器的中心频率（以 FFT 频点序号计），相邻两个中心频率与当前中心构成三角形的底边。每个滤波器对幅度谱加权求和，得到该频带的**能量**。$M$ 的典型值是 22–40。<span class="marginnote">为什么要「加权求和」而不是直接取一条谱线？因为单条谱线是谐波梳上的一根齿，跳动剧烈；一个频带内的总能量才稳定地反映「这个感知频段有多大响动」，对基频谐波位置的微移不敏感。</span>

## 3 公式解析：MFCC 的完整定义

把第 2–6 步合起来，MFCC 系数可以写成一条完整公式。设一帧加窗后的语音为 $x(n)$，其 DFT 为 $X(k)$，第 $m$ 个 Mel 滤波器的能量为 $E_m$，则第 $c$ 个 MFCC 系数为：

$$
C_c = \sum_{m=1}^{M} \log E_m \cdot \cos\left( c \cdot \frac{\pi (m - \tfrac12)}{M} \right), \qquad c = 0, 1, \dots, K-1
$$

其中 $E_m = \sum_{k} \lvert X(k)\rvert^2 H_m(k)$，或常用幅度谱的平方近似。逐项拆解：

- **第一步，看懂 $E_m$**：$E_m$ 是第 $m$ 个 Mel 频带里的**谱能量**。把幅度谱乘上三角滤波器 $H_m(k)$ 再对全部频点求和，得到这个频带的加权能量。$M$ 个 $E_m$ 排成一列，就得到 log-Mel 特征（下一节的主角）。
- **第二步，$\log E_m$ 是感知开关**：能量动态范围可能差几个数量级，$\log$ 把它压成可比较的尺度，同时对应人耳「响度近似与能量对数成正比」的感知特性。取对数还让「乘法性的信道增益」变成「加法性的偏移」，为后续 CMVN 埋下伏笔。
- **第三步，$\cos$ 项是 DCT 的基**：$\cos\left(c \cdot \frac{\pi(m-\tfrac12)}{M}\right)$ 是**离散余弦变换（DCT）**第 $c$ 个基函数在 $m$ 处的取值。对 $M$ 个 $\log E_m$ 做 DCT，得到 $M$ 个系数 $C_0, C_1, \dots, C_{M-1}$。
- **第四步，只取前 $K$ 个**：$K$ 通常取 12–13。**低阶系数对应谱包络的宏观形状（慢变部分），高阶系数对应快速起伏的细节**——后者受噪声与谐波影响大、判别价值低，于是果断截断。

**为什么用 DCT 而不是 IDFT？** 关键原因有三：其一，DCT 的输出是**实数**，而 IDFT 会给出复数；其二，DCT 的基函数是实偶对称的余弦，对「对数能量谱」这类平滑信号能量集中度更好；其三，MFCC 取的是**幅度**谱的倒谱，相位已丢，用 IDFT 反而没有额外信息，而 DCT 能起到**去相关（decorrelation）**作用——把相邻 Mel 频带间的冗余压缩进少数系数。**这一去相关特性，正是后面 GMM-HMM 假定「特征各维近似独立」能勉强成立的原因。**<span class="marginnote">去相关的直观理解：相邻 Mel 频带的能量本来就高度相关（谱是平滑的），直接建模等于重复计数；DCT 像主成分分析一样把能量沿「最分散的方向」重排，让各维尽量独立。这就是为什么 DNN 时代有些系统反而丢掉 DCT、直接用 log-Mel——网络自己有能力处理相关性。</span>

## 4 一帧数据在手里长什么样

把流程落到代码上，一帧 25 ms、16 kHz 采样的语音（400 点）会变成 13 个 MFCC 系数。用 Python 走一遍最核心的几步：

```python
import numpy as np
from scipy.fft import dct

# 帧长 400 点（25 ms @ 16 kHz），帧移 160 点（10 ms）
frame = signal[i : i + 400] * np.hamming(400)    # 2. 分帧加窗
X = np.abs(np.fft.rfft(frame))                   # 3. FFT 幅度谱
E = mel_filterbank @ (X ** 2)                    # 4. Mel 滤波器组（功率谱）
logE = np.log(E + 1e-10)                         # 5. 取对数，防 log(0)
mfcc = dct(logE, type=2, norm="ortho")[:13]      # 6. DCT 截断，取前 13 个系数
```

注意第 5 步的 `+ 1e-10`：**谱能量可能为 0，直接取对数会得到 $-\infty$**，加一个极小常数既防止数值下溢，又给了一个下限。这是实现 MFCC 最常见的坑之一。

## 5 辨析｜易错点

- **易错点：把 Mel 滤波器组做到幅度谱还是功率谱上？** 经典 MFCC 用**功率谱** $\lvert X\rvert^2$ 加 Mel 滤波器，能量 $E_m$ 是功率能量；也有实现用幅度谱。两者差一个平方，取对数后只差常数倍，DCT 是线性变换，因此**对最终系数只有整体缩放与直流偏移的影响**，一般不影响识别。混用不会出错，但要在论文里说清楚。
- **易错点：$C_0$ 该不该留？** $C_0$ 是所有 $\log E_m$ 的平均，反映帧总能量。帧能量本身受说话人距离、麦克风增益影响大，很多系统会**丢弃 $C_0$**（或单独做归一化），避免识别偏向音量大的说话人。
- **辨析｜倒谱法基频 vs MFCC 的倒谱：** 上一节倒谱法在 $n = T_0$ 处找尖峰测基频，用的是**整段倒谱**；MFCC 只取前 13 个系数，**根本看不到 $T_0$ 那么远的高时位置**——它保留的是「声道包络」这一段，丢弃了「声源激励」那一段。这正是 MFCC 能忽略基频差异、专注音色的原因。
- **易错点：MFCC 不是「语音的全部信息」。** 它丢了相位、丢了高时倒谱（激励细节）、丢了超帧级韵律。后面会看到，韵律信息要靠另外的 Pitch 与能量特征来补。**MFCC 是一个「为音色与声道调制的音素识别优化」的损失压缩**，不是无损表示。

## 6 小结

- **MFCC = 预加重 → 分帧加窗 → FFT → Mel 滤波器组 → log → DCT 截断**，把一帧语音压缩成 12–13 个实数系数。
- **Mel 滤波器组**在 Mel 轴等间距、赫兹轴不等宽，是对「人耳对数频率感知」的工程近似。
- **log** 压缩动态范围、对应响度感知，并让信道增益从乘法变成加法。
- **DCT** 提供实数、能量集中、去相关三重好处；**只取低阶系数**等价于只保留声道包络、丢弃激励与噪声细节。
- **MFCC 不是无损特征**：它丢弃相位、高时倒谱与帧能量，是为「区分音素」而做的有损压缩。
