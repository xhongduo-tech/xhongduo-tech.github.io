## 为什么从预处理开始

上一课我们得到了一串 16 kHz、16 bit 的数字语音。但这串数字还不能直接送去分帧、做 FFT——它带着两个「先天毛病」：**频谱整体向低频倾斜**（高频能量被压得很低），以及**可能带有一个直流偏置**（波形整体上移）。如果不处理，这两个毛病会一路传染给后面的所有特征。

这一课讲两行代码就能完成的**预加重（pre-emphasis）**与**直流分量去除（DC removal）**。它们是最不起眼的预处理，却决定了后续频谱分析的质量——也是「从极限到大模型」里反复出现的那个原则的第一次实践：**先建模信号的统计结构，再决定怎么处理它**。

## 1 语音频谱的天然下降趋势

先看第一个毛病。把一段语音的长期平均频谱画出来，会发现它**不是平的**：从低频到高频，能量整体以大约 **−6 dB/倍频程**（每翻一倍频率，下降约 6 dB）的速度衰减。<span class="marginnote">倍频程（octave）：频率翻一倍。−6 dB/oct ≈ −20 dB/十倍频程（decade）。这是口语长期平均谱的典型包络，不同音素会有起伏，但总趋势一致。</span>

这个下降不是「语音天生这样」，而是**声源—滤波器模型**三个环节共同作用的结果：

- **声门声源谱**：声门脉冲序列的频谱以约 −12 dB/oct 衰减；
- **唇辐射**：嘴唇处的声辐射特性给高频一个约 +6 dB/oct 的提升；
- **净效果**：$-12 + 6 = -6$ dB/oct，叠加声道共振峰之后，就是整段语音的频谱包络。

**核心概念：预加重（pre-emphasis）**——用一个高通滤波器，把语音高频段被天然压低的那部分再抬回来，让频谱**整体变平**。

为什么必须把它弄平？有两个工程理由：

1. **数值与信噪比**：高频分量幅度小，在定长比特（尤其定点 DSP）里容易被量化噪声淹没；做 FFT 时，低频的大值会主导频谱，高频细节（摩擦音、辅音的爆发段）几乎看不见。
2. **特征的一致性**：同样的语音，换个麦克风或距离，频谱整体斜率会变。预加重把「低频占优」的天然趋势先去掉，让后续特征更多反映声道形状（音素），而不是录音设备的频率响应。

## 2 预加重滤波器

预加重就是一行差分方程：

$$y[n] = x[n] - a\,x[n-1], \qquad a \approx 0.95\text{–}0.97$$

它是一阶**高通/差分滤波器**。直觉上：它把「相邻样本的差」取出来——信号变化慢的地方（低频）输出小，变化快的地方（高频）输出大，于是高频被相对放大。

系数 $a$ 通常取 0.95–0.97（HTK、Kaldi、librosa 的默认值都是 0.97）。$a$ 越接近 1，高通作用越强、低频压得越狠。$a$ 不能取 1，否则在奈奎斯特频率处增益为 2、在直流处增益为 0，会把高频噪声也一起抬上天。

**重点：预加重的传递函数是 $H(z) = 1 - az^{-1}$，一个单零点滤波器。** 它同时做了一件好事——在 0 Hz 处增益只有 $1-a \approx 0.03$，几乎把直流分量也一并滤掉了。这为我们下一节省了一半功夫。

## 3 直流分量去除

### 直流偏置从哪来

**直流分量（DC component）**是信号里的 0 Hz 分量，表现为波形整体上下平移了一个常数。来源几乎全是硬件：ADC 的参考电压偏移、放大器的直流偏置、声卡与麦克风的电气特性。语音本身几乎没有直流——声波是围绕大气压的振动，长时间平均应趋近于 0。

直流偏置为什么有害？三个原因：

- **0 Hz 处一座「大山」**：FFT 后第 0 个频点（直流）会被顶得极高，而 FFT 的泄漏效应会让这座山向邻近低频频点蔓延，污染低频段。
- **能量与 VAD 失真**：短时能量是「平方和」，一个常数偏置会恒定贡献能量，让静音段被误判成有语音，破坏端点检测（VAD）。
- **非线性放大的隐患**：后续若经过压缩、限幅等非线性处理，偏置会改变工作点，造成不对称削波。

### 怎么去除

方法一：**减均值**。把整段（或每帧）信号减去其均值，是最直接的直流消除：

$$x_{ac}[n] = x[n] - \frac{1}{N}\sum_{k=0}^{N-1} x[k]$$

方法二：**直流阻塞滤波器（DC blocker）**。用一个截止频率极低（约 1–10 Hz）的高通滤波器，只滤直流、不动语音：

$$y[n] = x[n] - x[n-1] + \alpha\, y[n-1], \qquad \alpha \approx 0.995\text{–}0.999$$

**辨析｜易错点：** 减均值是「一次性全局校正」，适合离线处理；直流阻塞滤波器是「逐样本递归」，适合实时流式处理。两者都能去掉常数偏置，但**都不能去掉缓变的基线漂移**（低频干扰，如麦克风爆音、电源哼声）——那是低频噪声问题，属于后面语音增强的范畴。另外注意：减均值要去减「语音段的均值」而不是「整段含静音的均值」，否则静音段的偏置会被误当成语音均值。

## 4 公式解析：预加重滤波器的频率响应

把预加重「到底抬了多少」算清楚。对 $y[n] = x[n] - a\,x[n-1]$ 做 $\mathcal{Z}$ 变换：

$$H(z) = 1 - a\,z^{-1}$$

沿单位圆 $z = e^{j\omega}$ 求幅频响应（$\omega$ 是数字角频率，$\omega = 2\pi f / f_s$）：

$$|H(e^{j\omega})| = \sqrt{1 + a^2 - 2a\cos\omega}$$

- **第一步：验证两端极限。** 直流处 $\omega = 0$，$\cos 0 = 1$，$|H| = \sqrt{(1-a)^2} = 1 - a$；奈奎斯特处 $\omega = \pi$，$\cos\pi = -1$，$|H| = \sqrt{(1+a)^2} = 1 + a$。**滤波器在直流几乎堵死、在奈奎斯特几乎放行**，这正是高通。
- **第二步：算总提升量。** 从直流到奈奎斯特的总提升：

$$\text{Boost} = 20\log_{10}\frac{1+a}{1-a}\ \text{dB}$$

代入 $a = 0.97$：$20\log_{10}(1.97/0.03) = 20\log_{10}65.7 \approx 36$ dB。**这就是预加重能「补回来」的动态范围**——恰好人耳/语音在 20 Hz–20 kHz 上的天然落差。
- **第三步：与 −6 dB/oct 对照。** 在 $\omega$ 较小时，$\cos\omega \approx 1 - \omega^2/2$，幅频近似 $|H| \approx \sqrt{(1-a)^2 + a\omega^2}$。当 $\omega$ 从很小处增长，$|H|$ 以约 6 dB/oct 的斜率爬升——**预加重的斜率与语音天然下降的 −6 dB/oct 正好互补**，叠加后频谱整体趋于平坦。这是「$a \approx 0.95–0.97$」这个数值的由来。
- **第四步：别把 36 dB 全用满。** 真实语音的频谱在 4 kHz 以上还有共振峰与唇辐射细节，若 $a$ 太接近 1，高频噪声（麦克风本底、量化噪声）也会被同步放大。所以实践中 $a$ 停在 0.97 而不是 0.999——**预加重要的是「铺平语音」，不是「放大噪声」**。

```python
import numpy as np

def pre_emphasis(x: np.ndarray, a: float = 0.97) -> np.ndarray:
    """一阶预加重：y[n] = x[n] - a·x[n-1]。"""
    y = np.empty_like(x)
    y[0] = x[0]
    y[1:] = x[1:] - a * x[:-1]
    return y

# 频率响应验证：直流增益 vs 奈奎斯特增益
a = 0.97
print("DC 增益 (dB):", 20*np.log10(1-a))
print("奈奎斯特增益 (dB):", 20*np.log10(1+a))
print("总提升 (dB):", 20*np.log10((1+a)/(1-a)))
```

## 5 在流水线中的位置与注意事项

预处理在完整流水线里的位置是：

$$x[n] \xrightarrow{\text{DC 去除}} \xrightarrow{\text{预加重}} \xrightarrow{\text{分帧}} \xrightarrow{\text{加窗}} \xrightarrow{\text{FFT}} \text{频谱/特征}$$

几个实践细节：

- **顺序**：DC 去除通常最先做；预加重在分帧**之前**对整个波形做（HTK、Kaldi、librosa 都是这个约定），因为滤波器是递归的，跨帧连续处理更干净。有的实现把预加重放到分帧后逐帧做，结果略有差别但工程上可接受。<span class="marginnote">Kaldi 与 librosa 的默认预加重系数同为 0.97，且都作用在全波形上。做研究复现时，预加重「有没有做、系数多少、放在哪一步」都可能影响最终 WER 零点几个点——这些细节常写进论文的「front-end」小节。</span>
- **合成要反着来：去加重（de-emphasis）**。语音合成（TTS）生成波形时，要把预加重的影响**还原**，恢复自然的 −6 dB/oct 频谱形状。去加重是预加重的逆滤波：$y[n] = x[n] + a\,y[n-1]$。**预加重只存在于分析与特征侧，波形重建时必须去掉。** 这是初学最容易漏的一步。<span class="marginnote">去加重是一个极点滤波器 $H(z) = 1/(1 - az^{-1})$，恰为预加重零点的逆。参看本专题《语音合成系统概览》一课中「分析—合成」的对称结构。</span>
- **可学习前端里它们还在吗**：现代端到端模型（如 wav2vec 2.0、Whisper）的输入端不再显式预加重，但卷积前端第一个滤波器组学出来的东西，往往就近似一个高通/带通滤波器组——**手写预加重「消失」的方式，是被网络自动重新发明**。这与第一课「声源—滤波器模型」到深度模型的关系一脉相承。

## 6 小结

- 语音长期平均谱以约 **−6 dB/oct** 下降，来源是声门谱（−12 dB/oct）与唇辐射（+6 dB/oct）的叠加。
- **预加重** $y[n] = x[n] - a\,x[n-1]$（$a \approx 0.97$）用高通把高频抬平，改善数值条件与特征一致性；其频率响应 $|H| = \sqrt{1+a^2-2a\cos\omega}$，总提升约 $20\log_{10}\frac{1+a}{1-a} \approx 36$ dB。
- **直流分量**来自硬件偏置，会污染低频与能量/VAD；用**减均值**或**直流阻塞滤波器** $y[n] = x[n]-x[n-1]+\alpha y[n-1]$ 去除。
- 预加重在 0 Hz 处增益仅 $1-a$，顺带承担了部分直流去除；但**缓变基线漂移**属于低频噪声，需交给语音增强。
- 合成侧必须用**去加重** $y[n] = x[n] + a\,y[n-1]$ 还原频谱；可学习前端则把这两步「重新发明」为第一个卷积层。
