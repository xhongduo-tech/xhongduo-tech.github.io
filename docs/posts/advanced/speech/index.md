# 语音技术

语音技术是让机器听懂、说出和理解人类声音的技术体系，涵盖从声学信号处理到端到端深度学习模型，再到语音大模型的完整链路。本篇按经典教材《语音信号处理》《Spoken Language Processing》及主流课程体系梳理全部选题。
