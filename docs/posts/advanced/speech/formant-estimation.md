## 为什么从共振峰开始

元音靠什么区分？/i/ 和 /a/ 说同一个调子，你怎么知道人家发的是哪个音？答案全在**共振峰（formant）**里——声道的一组谐振频率，决定了元音的「音色」。语谱图里它们是横向暗带，LPC 里它们是谱包络的峰，而本节要把它们变成**精确到 Hz 的数字**，并估计出每个峰的**带宽**。

共振峰估计是语音技术的一个枢纽：往前看，它是**声道形状的逆向测量**（从共振峰反推舌位、唇形，这是发音研究的核心手段）；往后看，它直接喂给 MFCC 之外的「共振峰特征」、声学语音学的元音分析、以及说话人识别里的声道个性。<span class="marginnote">共振峰与声道形状的对应，是语音学里最漂亮的「逆向工程」：元音 /i/ 舌位高前、/a/ 舌位低、/u/ 舌位高后，每种姿态对应一组特有的 F1、F2。前面《语音的声学分类：元音、辅音与协同发音》讲的发音动作，本节落到可测量的数字上。</span>

## 1 共振峰是什么：声道的谐振

发元音时，声带产生的激励是「宽带」的，但声道这个管子只允许某些频率的能量共振放大。**共振峰就是声道传递函数的谐振峰**，频率从低到高记为 $F_1, F_2, F_3, \dots$。每个峰除了位置（频率），还有**带宽（bandwidth）**——峰越尖，带宽越窄，声音越「纯」。

共振峰的物理来源：声道是一根形状可变的声学管。管内声波的反射与驻波，决定了哪些频率被放大。粗略估计，**声道越长，共振峰越低**——这就是为什么成年男性（声道约 17 cm）的共振峰整体比女性、儿童的低。<span class="marginnote">对长度 $L$ 的均匀直管，$\lambda_n = 2L/n$ 的驻波关系给出 $F_n \approx n\,c/(2L)$（$c \approx 350$ m/s 是声道内声速；真实声道是「双端」与「单端」的混合，数值略有出入）。$L = 17$ cm 时一阶约 500 Hz——和中性元音 /ə/ 的 F1 量级一致。这个简单公式是「声道长度 → 共振峰位置」的第一直觉。</span>

最经典的对应关系（以普通话三大元音为例，与语谱图一节的表格一致）：

| 元音 | F1（约） | F2（约） | 舌位 |
| --- | --- | --- | --- |
| /a/ | 800 Hz | 1200 Hz | 低、前 |
| /i/ | 280 Hz | 2360 Hz | 高、前 |
| /u/ | 350 Hz | 600 Hz | 高、后 |

规律：**F1 主要反映舌位高低（下巴开合），F2 主要反映舌位前后**。舌位抬高，F1 下降；舌位前移，F2 上升。F1–F2 平面就是元音地图，不同语言的元音系统都在这张地图上取点。

## 2 谱包络峰值拾取：最直观的方法

最朴素的做法是**先得到谱包络，再找局部极大**：

1. 对语音帧做 STFT，得到幅度谱。
2. 用 LPC 或倒谱平滑得到**包络**（不是原始谱！）。
3. 在包络上找前 3–4 个局部极大，记录频率与高度。

```python
import numpy as np
from scipy.signal import find_peaks

# x: 一帧浊音；fs: 采样率；a: LPC 系数（见《线性预测分析》一节）
N = len(x)
A = np.fft.rfft(np.r_[1, -a], n=N)            # A(z) = 1 - Σ a_k z^{-k} 的频谱
envelope = 1.0 / np.abs(A)                    # 全极点谱包络 |1/A|
freq = np.arange(len(envelope)) * fs / N      # 每个频点对应的 Hz

peaks, _ = find_peaks(envelope, distance=N//500)  # 约 500 Hz 内只留一个峰
F = freq[peaks][:4]                           # 前 4 个峰 → F1, F2, F3, F4
```

**辨析｜易错点：峰值拾取必须在「包络」上做，不能在原始谱上做。** 原始谱里每个谐波都是个尖峰，直接找峰找出来的是基频及谐波，不是共振峰。判断标准很简单：**找出的峰间隔是否约等于 $f_0$？是 → 你找到的是谐波。** 先包络、后找峰，是这一方法唯一正确的顺序。<span class="marginnote">峰数怎么定？成年男性的 F1–F4 大约在 0.5、1.5、2.5、3.5 kHz 附近。一般取前 3–4 个峰做元音分析，够用；F3 以上受发声方式影响大，很少用于元音识别。</span>

峰值拾取的优点是**简单、可解释**；缺点是**对噪声敏感**，而且包络平滑方式（LPC 阶数、倒谱截断点）会直接影响峰的位置。

## 3 LPC 求根法：从滤波器极点算共振峰

上一节我们讲过，LPC 用全极点滤波器 $H(z) = G/A(z)$ 拟合声道，$A(z) = 1 - \sum_{k=1}^{p} a_k z^{-k}$。**共振峰就藏在 $A(z)$ 的根里**：$A(z) = 0$ 的复根（在单位圆内）两两共轭，每一对共轭根对应一个共振峰。

设一对共轭根 $z = r e^{\pm j\omega}$（$r < 1$），则：

$$F = \frac{\omega}{2\pi}\, f_s, \qquad \mathrm{BW} = -\frac{f_s}{\pi}\, \ln r$$

<span class="marginnote">直觉：复根 $r e^{j\omega}$ 的辐角 $\omega$ 决定谐振频率，模长 $r$ 决定阻尼——$r$ 越接近 1，衰减越慢、峰越尖、带宽越窄；$r$ 太小则峰被抹平甚至消失。</span>

## 4 公式解析：从复根读出频率与带宽

$$
z = r\, e^{j\omega}, \qquad F = \frac{\omega}{2\pi}\, f_s, \qquad \mathrm{BW} = -\frac{f_s}{\pi}\, \ln r
$$

- **第一步，找根**：求 $A(z) = 0$。复根必然共轭成对，每对贡献一个共振峰；实根贡献「谱倾斜」，不对应峰。
- **第二步，辐角 → 频率**：根在单位圆上的角度 $\omega$ 是**归一化角频率**（$0 \sim \pi$ 对应 $0 \sim f_s/2$）。换算 $F = \omega f_s / (2\pi)$。例如 16 kHz 采样、$\omega = 0.2\pi$，则 $F = 0.2\pi \times 16000/(2\pi) = 1600$ Hz。
- **第三步，模长 → 带宽**：根距单位圆越近，峰越尖。精确关系 $\mathrm{BW} = -f_s \ln r / \pi$。例如 $r = 0.98$、$f_s = 16$ kHz，则 $\mathrm{BW} \approx -16000 \times (-0.0202)/\pi \approx 103$ Hz——典型的 F2 带宽量级。
- **第四步，筛选**：丢弃 $r$ 太小（带宽过大、峰消失）和频率越界（$> f_s/2$）的根，剩下的按频率排序得到 $F_1, F_2, \dots$。

实现用 NumPy 的求根即可：

```python
import numpy as np

# a: LPC 系数（不含首项 1）；fs: 采样率
roots = np.roots(np.r_[1, -a])                 # 求 A(z) = 0 的根
roots = roots[np.abs(roots) < 1.0]            # 只留单位圆内的根（稳定极点）

angles = np.abs(np.angle(roots))              # 辐角 ω ∈ [0, π]
radii  = np.abs(roots)                        # 模长 r

F  = angles * fs / (2 * np.pi)                # 共振峰频率（Hz）
BW = -fs / np.pi * np.log(radii)              # 共振峰带宽（Hz）

order = np.argsort(F)
F, BW = F[order], BW[order]                   # 升序排列：F1, F2, ...
```

**辨析｜易错点：LPC 阶数决定「能看见几个峰」。** 每对共轭根给出一个峰，$p$ 阶多项式最多给出约 $p/2$ 个峰。经验法则 $p \approx f_s/1000 + 2$ 就是为了「刚好」覆盖 0 到 $f_s/2$ 里的共振峰数——$p$ 太大，多余极点会生成**伪峰（spurious peak）**，$p$ 太小则漏峰。伪峰没有声学意义，是「模型过拟合」的表现。

## 5 方法三：倒谱平滑与动态跟踪

- **倒谱平滑法**：对帧做实数倒谱，保留低倒频率段（$n \le 20$ 左右）后反变换，得到光滑包络，再做峰值拾取。与 LPC 相比它不假设全极点模型，对鼻音更友好，但包络平滑程度要靠截断点手工调。
- **动态跟踪（tracking）**：单帧估计是「快照」，容易在帧与帧之间跳变。生产系统会把整个句子的共振峰作为一条**时间轨迹**来跟踪，利用「共振峰移动是连续的」这一先验：下一帧的 $F_2$ 一定离上一帧的 $F_2$ 不远，于是用动态规划在候选峰之间挑「最平滑的路径」。这也是「共振峰转移」（塞音后的 F2 滑向目标元音）能被忠实还原的关键。

## 6 辨析与易错点

- **谐波 ≠ 共振峰**：再强调一遍，找峰要在包络上做。用原始谱找峰、间隔约等于 $f_0$，就是找错了。
- **LPC 阶数双刃剑**：阶数过低漏峰，过高出伪峰。可以扫几个 $p$ 看哪个「稳定」——共振峰对 $p$ 不敏感才是真峰。
- **高频与高基频**：女声、童声基频高，谐波间隔大，包络上的「采样点」稀，LPC 估计带宽的方差变大；F1 可能落进谐波间隙。这是声道参数提取的系统性难点。<span class="marginnote">工程上对女声常加大帧长、降低 LPC 阶数，或在倒谱域先做包络再求峰，来缓解谐波稀疏带来的抖动。</span>
- **带宽比频率更难估**：频率由辐角决定（稳健），带宽由模长决定（对噪声和窗敏感）。**报告共振峰时务必注明带宽的可信度**——很多研究的 F1/F2 是可靠的，F3、带宽则存疑。
- **上下文与协同发音**：共振峰是「上下文相关」的，同一个 /a/ 在不同词里 F1、F2 会移动几十 Hz。做元音识别时要容忍这种变异性，或显式建模（如轨迹模型）。

## 7 小结

- **共振峰**：声道谐振峰，$F_1, F_2, F_3$ 决定元音音色；F1 ↔ 舌位高低，F2 ↔ 舌位前后。
- **峰值拾取**：先包络（LPC / 倒谱）后找峰，绝不能直接在原始谱上找。
- **LPC 求根**：$A(z) = 0$ 的复根 → $F = \omega f_s/(2\pi)$，$\mathrm{BW} = -f_s \ln r/\pi$；阶数 $p$ 控制「能看见几个峰」。
- **倒谱平滑**：非参数化包络，对鼻音更友好。
- **动态跟踪**：利用共振峰移动的连续性，把「快照」连成「轨迹」，是工程落地的关键。
- **三大坑**：谐波 ≠ 共振峰、带宽难估、女声 / 童声谐波稀疏。
