## 为什么从数字化开始

前三课都在「人」这边：发声、分类、听觉感知。从这一课起，机器正式登场。语音要交给计算机处理，第一步是把连续的声音波形变成一串数字——这个转换叫**模数转换（ADC）**，由**采样（sampling）**与**量化（quantization）**两步组成。

这一步看似朴素，却是整个语音信号处理的入口。一个看似不起眼的工程选择——「采样率用 8 kHz 还是 16 kHz」「量化用 8 bit 还是 16 bit」——决定了你能看到的频率上限、信噪比天花板，乃至后面一切特征提取的行为。<span class="marginnote">这也呼应网站标题「从极限到大模型」：采样定理是「用可数个点表示连续函数」的精确数学，而傅里叶分析、滤波器组、甚至神经网络的频域结构全都建筑在这第一步之上。</span>

更重要的是，数字化藏着两个反直觉的坑：**欠采样会让高频伪装成低频（混叠）**，**量化精度不足会让信号变成「噪声」**。看懂这两个坑，你就不会再被设备参数表上的数字忽悠。

## 1 采样：把连续波形变成离散序列

### 采样与采样率

设原始语音是连续信号 $x(t)$，以时间间隔 $T$ 取值，得到离散序列：

$$x[n] = x(nT), \qquad f_s = \frac{1}{T}$$

$f_s$ 是**采样率（sampling rate）**，单位 Hz（每秒采样数）。理想采样在频域上的效果非常优美：**采样后信号的频谱，是原频谱以 $f_s$ 为周期无限复制的结果**——原频谱的一个「副本」被平移到 $0, \pm f_s, \pm 2f_s, \dots$ 各处。这个性质是整个数字信号处理的支点。

### 奈奎斯特定理：无损重建的条件

**核心概念：奈奎斯特—香农采样定理（Nyquist–Shannon sampling theorem）**——若信号最高频率为 $f_{max}$，只要采样率满足

$$f_s > 2\,f_{max}$$

就可以从采样序列**精确重建**原始连续信号（通过理想低通滤波）。$f_s / 2$ 称为**奈奎斯特频率（Nyquist frequency）**，它是数字化信号能表示的频率上限；$2 f_{max}$ 称为**奈奎斯特率（Nyquist rate）**。

**重点：采样率决定了「可见」的频率上限，即奈奎斯特频率 $f_s/2$。** 高于它的频率不是「被丢掉」，而是会「变成」低于它的假频率——这就是下一节的混叠。

语音的带宽是多少？电话话音约 300–3400 Hz，所以电话系统用 8 kHz 采样；宽带语音与语音识别常用 16 kHz（覆盖到 8 kHz）；音乐/音频用 44.1 或 48 kHz（覆盖到 20 kHz+）。<span class="marginnote">「最高频率」是带宽的一半还是全程？对实信号，频谱关于 0 对称，最高频率指正频段的上限。若信号不是带限的（理论上不可能完全带限），就需要先用抗混叠滤波器把它变成带限信号——这正是 ADC 前端总有一颗模拟低通滤波器的原因。</span>

## 2 混叠：欠采样的代价

当 $f_s < 2 f_{max}$ 时，频谱副本互相重叠，重叠部分无法区分——高频分量被「折返」进 $[0, f_s/2]$，变成一条**错误的低频假分量**。这就是**混叠（aliasing）**。

![欠采样导致频谱折返：高频分量伪装成低频假分量](/images/speech/sampling-quantization-nyquist-1.svg)

**核心概念：混叠（aliasing）**——采样率不足时，高于 $f_s/2$ 的真实频率 $f_0$ 会被镜像折返到 $f_a = f_s - f_0$（当 $f_0 \in (f_s/2, f_s)$）。折返后的 $f_a$ 落在可见频段内，与真实存在的信号混在一起，无法再区分。

直觉例子：用 8 kHz 采样一个 6 kHz 的纯音。6 kHz 高于奈奎斯特频率 4 kHz，折返后得到 $f_a = 8000 - 6000 = 2000$ Hz——采样序列看起来就是一个 2 kHz 的音。**你的麦克风把一个 6 kHz 的声波，记录成了 2 kHz**。<span class="marginnote">物理直觉：车轮反转。电影里马车轮子向后转，是因为每秒 24 帧的「采样率」赶不上轮辐转动的频率——人眼把高频的轮辐运动折返成了反向的低频运动。混叠是同一现象。</span>

**辨析｜易错点：** 混叠不是「高频被过滤掉了」，而是「高频被伪装成低频并添加进信号」。一旦进入数字域，混叠就**无法修复**——你只知道采样后的序列，并不知道里面哪个成分是真实的、哪个是折返出来的。所以必须在采样之前动手：**抗混叠滤波器（anti-aliasing filter）**，一颗截止频率为 $f_s/2$ 的低通滤波器，先把高于奈奎斯特频率的能量压掉，再进 ADC。先滤波、后采样，顺序不可颠倒。

## 3 量化：把幅度变成有限个等级

采样把时间离散化，量化把幅度离散化。模拟信号的幅度是连续的，而数字信号只能用有限个二进制数表示。**量化（quantization）**就是按等级把连续幅度就近取整。

- **均匀量化**：把满量程范围分成 $2^B$ 个等宽区间，步长 $\Delta = \text{满量程}/2^B$。$B$ 是**位深（bit depth）**。
- **量化误差**：每个样本的误差 $e[n]$ 落在 $[-\Delta/2, +\Delta/2]$，近似均匀分布，方差 $\Delta^2 / 12$。误差会表现为叠加在信号上的噪声，称为**量化噪声**。

量化误差像一个恒定功率的噪声源。于是自然要问：信号功率相对量化噪声功率有多少？答案是一条在工程里被反复背诵的公式——**信量化噪声比（SQNR）**：

$$\text{SQNR}_{\text{dB}} = 6.02\,B + 1.76\ \text{dB}$$

这是对满幅正弦波的理论上限：每增加 1 bit，信噪比提高约 6 dB；16 bit 约 98 dB，24 bit 约 146 dB。电话 8 bit（μ 律）的有效动态范围约 38–40 dB。<span class="marginnote">「每 bit ≈ 6 dB」的来历：1 bit 让量化等级翻倍，等价于把噪声幅度减半，功率减为 1/4，即 −6.02 dB 噪声、+6.02 dB 信噪比。6.02 = 20·log10(2)。</span>

### 对数量化：μ 律与 A 律

语音信号的幅度分布极不均匀——小幅度（静音间隙、轻声）出现概率极高，大幅度（响元音）出现概率低。均匀量化把等级平均分配，小幅度部分严重「亏欠」精度。解决之道是**对数量化**：幅度小时等级密，幅度大时等级疏。

电话系统因此采用**压扩（companding）**：**μ 律**（北美、日本）与 **A 律**（欧洲），用 8 bit 实现等效约 12–13 bit 均匀量化的动态范围，采样率 8 kHz，合 64 kbps——这就是著名的 G.711 编码。<span class="marginnote">压扩的「对数」，与上一课响度的幂定律、mel 刻度的对数，是同一个思想在不同域里的反复出现：<strong>人的感知与语音的统计都偏向小值，于是把标尺在低端加密。</strong></span>

**辨析｜易错点：** 采样与量化是两步，各错各的。采样率不够 → 混叠（频谱失真，无法修复）；位深不够 → 量化噪声（幅度失真，可用 dither 部分缓解）。两者都直接影响后续特征，但一个修在采样前（抗混叠滤波），一个修在量化时（更多 bit 或对数压扩）。

## 4 公式解析：SQNR = 6.02B + 1.76 dB

这条公式几乎出现在每一份 ADC 数据手册里，值得完整拆一遍：

$$\text{SQNR}_{\text{dB}} = 10\log_{10}\frac{P_{signal}}{P_{noise}} = 10\log_{10}\left(\frac{3}{2}\,2^{2B}\right) = 6.02\,B + 1.76$$

- **第一步：量化噪声功率。** 均匀量化误差在 $[-\Delta/2, \Delta/2]$ 上近似均匀分布，其方差为 $\Delta^2 / 12$。步长 $\Delta = V_{FS}/2^B$（$V_{FS}$ 是满量程电压），故噪声功率 $P_n = V_{FS}^2/(12 \cdot 2^{2B})$。
- **第二步：满幅正弦的信号功率。** 设正弦峰值为 $V_{FS}/2$（满幅不削顶），其功率 $P_s = (V_{FS}/2)^2 / 2 = V_{FS}^2 / 8$。
- **第三步：取比值。** $P_s / P_n = (V_{FS}^2/8) / (V_{FS}^2/(12 \cdot 2^{2B})) = \frac{12}{8}\,2^{2B} = \frac{3}{2}\,2^{2B}$。
- **第四步：转成 dB。** $10\log_{10}(1.5) + 20B\log_{10}(2) \approx 1.76 + 6.02B$。**每加 1 bit，信噪比 +6.02 dB**；常数 1.76 来自「满幅正弦」这个参考信号的峰均功率比。

```python
import math

def sqnr_db(bits: int) -> float:
    """满幅正弦的量化信噪比 (dB)。"""
    return 6.02 * bits + 1.76

for b in [8, 12, 16, 24]:
    print(f"{b:2d} bit -> SQNR ≈ {sqnr_db(b):6.1f} dB")
```

## 5 语音数字化的工程现实

采样率与位深的组合，构成了语音系统的「分辨率宪法」，不同场景各有一套约定俗成：

| 场景 | 采样率 | 位深 | 说明 |
| --- | --- | --- | --- |
| 电话 PSTN（G.711） | 8 kHz | 8 bit μ/A 律 | 带宽 300–3400 Hz，64 kbps |
| 宽带语音 / VoIP | 16 kHz | 16 bit 线性 PCM | 语音识别前端的主流 |
| CD 音频 | 44.1 kHz | 16 bit | 覆盖 20 kHz 人耳上限 |
| 专业音频 / 影视 | 48 kHz | 24 bit | 留足动态余量 |

对语音识别与语音大模型而言，**16 kHz、16 bit 线性 PCM** 是事实标准：16 kHz 覆盖到 8 kHz，足以容纳汉语/英语辅音的多数高频能量；16 bit 的 98 dB 动态范围也远高于实际语音的动态范围，量化噪声几乎不可闻。<span class="marginnote">现代端到端模型并不直接用原始采样，但「分辨率宪法」决定了模型的输入上限：用 8 kHz 录的数据，再强的模型也找不回 3.4 kHz 以上被抗混叠滤波器滤掉的信息——数据采集时的采样率，是信息论的硬边界。</span>

深度学习时代还有一个微妙之处：可学习前端（如 LEAF、SincNet）试图把「滤波—采样—压缩」整条感知链换成可训练参数，但底层的奈奎斯特约束不会消失——**不管前端学不学，采样率仍然框死了信息带宽**。这提醒我们：经典信号处理给出的不是「过时的老方法」，而是「所有方法都必须遵守的物理边界」。

## 6 小结

- **采样**把时间离散化：$x[n] = x(nT)$；采样后频谱是原频谱以 $f_s$ 为周期的复制。
- **奈奎斯特—香农定理**：$f_s > 2 f_{max}$ 才能无损重建；奈奎斯特频率 $f_s/2$ 是可见频率上限。
- **混叠**：欠采样时高于 $f_s/2$ 的分量折返成 $f_a = f_s - f_0$ 的假分量，且无法事后修复——必须用**抗混叠滤波器**在采样前压掉。
- **量化**把幅度离散化：均匀量化噪声功率 $\Delta^2/12$，**SQNR ≈ 6.02B + 1.76 dB**。
- **对数量化**（μ 律 / A 律）贴合语音幅度分布，8 bit 电话实现约 12–13 bit 均匀量化动态范围。
- 语音识别/语音大模型的事实标准：**16 kHz、16 bit 线性 PCM**；采样率是信息论的硬边界，可学习前端也无法绕过。
