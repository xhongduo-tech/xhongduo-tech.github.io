## 为什么从短时能量开始

上一节我们完成了两件基础工作：**采样量化**把连续语音变成数字序列，**分帧加窗**把长序列切成一段段可以假设「短时平稳」的帧。帧有了，下一步自然要问：**这一帧到底是什么？** 是说话还是没说话？是浊音还是清音？

本节的回答工具是两个最廉价的**时域特征**——**短时能量（short-time energy）**与**短时过零率（short-time zero-crossing rate, ZCR）**。它们各自只需要一次乘加与一次比较，却已经能回答上面问题的大部分场景。它们是整条语音处理流水线里最先被算出来的量：下一节**端点检测**以它们为输入，后面的**基音周期估计**、**共振峰提取**也都沿用「对每一帧算一个量」的短时分析框架。可以先记住一句话：**把「一整段语音」降维成「一串逐帧数字」的动作，叫作短时分析**，本节的能量与过零率就是它的第一击。

## 1 短时能量：一帧的「响度」

语音的响度取决于振幅，而振幅的平方正比于声波携带的功率。所以对第 $m$ 帧，最自然的能量定义是帧内所有采样点的平方和：

$$E_m = \sum_{n=0}^{N-1} \big[\, x_m(n) \,\big]^2$$

其中 $x_m(n)$ 是第 $m$ 帧的第 $n$ 个采样点，$N$ 是帧长。**浊音（元音）的声带振动产生大幅值、周期性的波形，能量高；清音（擦音）是气流湍流噪声，幅值小得多，能量低；静音段能量最低。** 只凭这一个数，就已经能区分「响亮」与「安静」了。

把加窗写进来，短时能量还有另一种等价形式——它其实是一个**滑动滤波器**：

$$E_m = \sum_{n=-\infty}^{+\infty} x^2(n)\, w^2(n - m)$$

这里 $x(n)$ 是整段信号，$w(n)$ 是窗函数。<span class="marginnote">上式本质是「先对信号逐点平方，再用 $w^2$ 的翻转版做滑窗滤波」。你在第一级《极限》与《信号与系统》里学过的卷积，又一次换了件马甲出场——短时能量就是 $x^2$ 与 $w^2$ 的卷积。回头想想那个「滑窗求和」的图像，这一整章都能串起来。</span>

### 为什么不直接用平方和？

平方运算会**放大大幅值采样点、压制小幅值采样点**——一帧里只要有几个大振幅的样本，能量值就几乎被它们主导，而这恰恰放大了噪声的干扰。因此工程上常用**短时平均幅度（short-time magnitude）**作为更稳的替代：

$$M_m = \sum_{n=0}^{N-1} \big|\, x_m(n) \,\big|$$

它和能量讲的是同一个故事（响度），但对幅值的「权重」更温和。**判断用哪个：需要区分度更高、更接近功率语义用平方和；需要抗噪更稳、计算更简单用幅度和。** 端点检测的教科书版本多用后者。

## 2 公式解析：短时能量是「加窗平方和的滑窗滤波」

把带窗形式拆成三步：

$$
E_m = \sum_{n=-\infty}^{+\infty} x^2(n)\, w^2(n - m)
$$

- **第一步，逐点平方**：把第 $n$ 个采样点的瞬时功率 $x^2(n)$ 算出来。物理依据是声波功率正比于振幅平方。
- **第二步，逐点加窗**：$w^2(n-m)$ 只让「以 $m$ 为中心的帧」内的点进来参与求和，窗外自动衰减到 0。为什么是 $w^2$ 而不是 $w$？因为先平方、再乘窗，等价于「加窗后的信号再平方」——窗函数被平方后形状略收窄，但语义不变。<span class="marginnote">窗函数平方还是立方，影响的只是包络形状的细微差别。真正决定「这帧有多长」的是窗的有效宽度，也就是你上一节选矩形窗还是汉明窗时操心的事。</span>
- **第三步，求和**：把窗口内的瞬时功率累加。累加结果 $E_m$ 就是第 $m$ 帧的短时能量。

逐帧移动 $m$（每次移动一帧移），就得到一条**能量包络曲线**。语音的起止、清浊、轻重，在这条曲线上都有可读的起伏——这正是下一节端点检测要利用的。

## 3 短时过零率：一帧的「频率感」

能量回答了「响不响」，却答不了「低还是高」。**频率信息不必等到傅里叶变换，一个简单的统计量——过零率——就能粗略捕捉**。

**短时过零率（ZCR）**：一帧内信号**穿越零电平的次数**。先定义符号函数

$$\operatorname{sgn}[x] = \begin{cases} 1, & x > 0 \\ -1, & x < 0 \end{cases}$$

于是第 $m$ 帧的过零率为

$$Z_m = \frac{1}{2} \sum_{n=0}^{N-1} \big|\, \operatorname{sgn}[x_m(n)] - \operatorname{sgn}[x_m(n-1)] \,\big|$$

直觉在于：**频率越高的信号，正负交替越快，单位时间穿过零轴的次数就越多**。正弦波每振荡一个周期穿过零轴两次，所以 ZCR 大致正比于主频率。由此得到语音里最有用的一条经验规律：

- **浊音**：声带振动基频低（男声约 80–180 Hz），波形以低频为主，**ZCR 低**。
- **清音**：气流噪声能量集中在中高频，波形细碎，**ZCR 高**。
- **静音**：幅值近零，ZCR 由背景噪声决定，通常介于两者之间且随机。

## 4 公式解析：过零率数的是「变号次数」

把 ZCR 公式逐步拆开：

$$
Z_m = \frac{1}{2} \sum_{n=0}^{N-1} \big|\, \operatorname{sgn}[x_m(n)] - \operatorname{sgn}[x_m(n-1)] \,\big|
$$

- **第一步，符号化**：$\operatorname{sgn}$ 把每个采样点压成 $+1$ 或 $-1$，只保留「正负」这个信息，丢掉幅值。这是有意为之——我们要数的只是「变号」，不是「变了多少」。
- **第二步，相邻差分**：$\operatorname{sgn}[x(n)] - \operatorname{sgn}[x(n-1)]$。相邻两点同号时为 0；异号时为 $\pm 2$。<span class="marginnote">「变号」＝信号穿越了零电平。之所以这样实现而不是直接数「采样点等于 0」，是因为离散信号很少恰好采到 0，必须靠相邻两点异号来判定穿越。</span>
- **第三步，取绝对值**：$\big| \cdot \big|$ 把 $\pm 2$ 统一成 $2$，即「这一次穿越贡献 2」。
- **第四步，乘以 $1/2$ 并求和**：每一处真正的穿越贡献 $2 \times \frac{1}{2} = 1$，求和后就是帧内穿越零轴的次数 $Z_m$。

**辨析｜易错点：** 不同教材对 ZCR 的定义有两处不一致，务必看清。其一，有没有 $\frac{1}{2}$——没有的话数值正好是穿越次数的两倍；其二，要不要除以帧长 $N$ 或换算成「每秒次数」——不除时它随帧长缩放，换采样率或换帧长后，阈值必须跟着重调。**ZCR 的绝对值在不同参数下没有可比性，可比的是同参数下的相对大小**——清音高、浊音低这一排序才是不变的。

把两个特征亲手算一遍，就是几行 NumPy 的事：

```python
import numpy as np

def short_time_features(x, frame_len=400, hop=160):
    """逐帧计算短时能量与短时过零率"""
    n_frames = 1 + (len(x) - frame_len) // hop
    E, Z = [], []
    for m in range(n_frames):
        seg = x[m*hop : m*hop + frame_len]
        E.append(np.sum(seg**2))                       # 短时能量：平方和
        sign = np.sign(seg)
        Z.append(0.5*np.sum(np.abs(np.diff(sign))))    # 短时过零率：变号次数
    return np.array(E), np.array(Z)
```

对一段「静音—清音—浊音—静音」的录音跑一遍，你会看到能量在浊音段冲高、过零率在清音段冲高——两张曲线合起来，正好拼出下一节端点检测的输入。

## 5 浊音、清音与静音的判别

把两个特征合起来，语音里三种典型区域的画像就清楚了：

| 区域 | 短时能量 | 短时过零率 | 物理来源 |
| --- | --- | --- | --- |
| 浊音（元音 / 浊辅音） | 高 | 低 | 声带周期性振动，低频强信号 |
| 清音（擦音 / 塞音送气段） | 低 | 高 | 气流湍流，中高频噪声 |
| 静音 / 背景噪声 | 最低 | 随机 | 无规则振动结构 |

**只看能量，浊音和静音分得开，但清音会跟静音混在一起；只看过零率，浊音和清音分得开，但清音又会跟噪声纠缠。** 这正是下一节端点检测要用「能量 + 过零率」双门限的原因：先用能量定出语音的大致地盘，再用过零率把地盘边界上那些「被清音撑出来的角落」补回来。

## 6 辨析与易错点：直流、窗长与门限

- **直流分量会让过零率全面失真。** 信号里只要混进一个正的直流偏置，波形整体被抬高，几乎所有采样点都落在零轴上方，「变号」变少甚至消失，ZCR 严重偏低。<span class="marginnote">还记得前面的《预加重与直流分量去除》吗？去直流、预加重这两步预处理，在算过零率之前几乎是强制性的——这正是那一节「先预处理再分析」顺序的实际意义。</span>
- **窗长决定能量包络的平滑度。** 窗太短，能量曲线抖动剧烈、毛刺多；窗太长，能量曲线被抹平，语音的起止边界变模糊。常用 20–30 ms 帧长是「时间分辨率」与「频率分辨率」折中的结果，下一节讨论语谱图时这个矛盾会以更尖锐的形式再出现。
- **平方和与幅度和的取舍要记住。** 前面说过，平方放大噪声敏感度，幅度和更稳。在噪声较大的录音里做端点检测，优先用幅度和。
- **门限不能写死。** 有人把「能量 > 某固定常数」当作说话标准，这是最常见的错误——不同麦克风、不同音量、不同人，能量尺度天差地别。门限必须**相对当前录音的噪声底自适应**，这正是下一节的主题。

## 7 小结

- **短时分析**：对每一帧算一个数的降维操作，是语音处理最基本的工作范式。
- **短时能量** $E_m = \sum_n x_m^2(n)$：衡量一帧的响度；等价于 $x^2$ 与 $w^2$ 的滑窗卷积。
- **短时平均幅度** $M_m = \sum_n |x_m(n)|$：平方和的抗噪替代，工程上常用。
- **短时过零率** $Z_m$：数一帧内穿越零轴的次数，粗略反映频率高低——浊音低、清音高。
- **联合判别**：能量分「响/静」，过零率分「高/低」，合起来才能可靠区分浊音、清音与静音。

在下一节，我们将用这两把尺子回答一个实际工程问题：**一段录音从第几帧开始、到第几帧结束才算「有人在说话」？** 这就是端点检测（VAD）。
