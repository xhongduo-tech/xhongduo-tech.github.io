## 为什么从人耳开始

前两课都在讲「人怎么发声」，这一课转向另一半：**人怎么听**。你可能会问：机器没有耳朵，为什么要研究人耳？答案藏在语音技术的一个基本立场里——**所有语音算法的成败，最终都要由人耳来裁判**。识别准不准，人要听；合成像不像人，人要听；压缩后音质损没损，还是要人听。

更重要的是，**人耳并不是一部忠实的录音机**。它是一个有频率分辨率、有动态范围、甚至会被「骗」的感知器官。它只对声音的某些部分敏感，会自动忽略另一些部分。理解人耳的这些「不忠」，你才能真正看懂后面几乎每一个听觉特征——临界频带、Mel 刻度、掩蔽模型——它们全部是人耳「不忠」的数学化。这一课就是这些刻度的生理地基。

## 1 耳朵的三级流水线

人耳可以看作一条三级流水线：**外耳、中耳、内耳**。它们的分工是：收集声波、放大压力、把机械振动变成神经信号。

- **外耳——耳廓与耳道**：耳廓帮助定位声源；耳道是一根长约 2.5 cm 的管子，它对约 2–4 kHz 的频段有天然共振放大（约 10 dB）。这就是为什么人耳对这一段最敏感——人类语音和婴儿啼哭的能量也恰好集中在这里。<span class="marginnote">衔接第一级《基础物理》「机械振动与机械波」：耳道对 2–4 kHz 的放大是「驻波共振」——管子长度约为该频段四分之一波长，与上一课声道共振峰 $F_1 \approx c/4L$ 是同一个物理原理。</span>
- **中耳——鼓膜与听小骨**：声波在空气中传播，而内耳充满液体，直接传导会在「空气—液体」界面反射掉约 99% 的能量。中耳的鼓膜与听小骨（锤骨、砧骨、镫骨）构成一个**阻抗匹配器**：鼓膜面积大、镫骨底板面积小，压力被放大，补偿了界面损失（约 25–30 dB）。没有这个「变压器」，人类几乎听不见水里的声音。
- **内耳——耳蜗（cochlea）**：一根卷成螺旋的骨管，内部是基底膜与毛细胞。镫骨敲击卵圆窗，在耳蜗液体里激起行波；基底膜上的毛细胞把机械振动转成电信号，再由听神经送往大脑。

**重点：外耳负责「收」，中耳负责「匹配」，内耳负责「换能」。** 三级里任何一级出问题都会致聋——传导性聋（外耳/中耳）与感音神经性聋（内耳/听神经）的区分，就来自这条流水线。

## 2 基底膜：一根按频率排队的琴弦

耳蜗里最关键的结构是**基底膜（basilar membrane）**。它像一根从蜗底到蜗顶渐变的「琴弦」：靠近卵圆窗（蜗底）的一段又窄又硬，靠近蜗顶的一段又宽又软。

当行波沿基底膜传播时，不同频率的波会在不同位置激起最大振幅：

- **高频**在蜗底（靠近卵圆窗）激起峰值；
- **低频**一路传到蜗顶（远离卵圆窗）才达到峰值。

于是基底膜天然实现了一个**频率—位置映射（tonotopy）**：每个位置「偏爱」某个特征频率，就像钢琴键盘上每个键有一个固定音高。这一映射是听神经编码频率的物理基础，也是后面所有「频带划分」的生理原型——**临界频带、Bark 刻度、Mel 滤波器组，本质上都是在用不同方式逼近基底膜这张「键盘」。**

毛细胞把振动转成听神经的放电，编码是双重的：**放电速率编码强度，放电发生的「位置」编码频率**。位置信息与速率信息并行传递，这正是「既听得出音高、又听得出响度」的生理基础。

基底膜的分辨率有限：两个频率若在膜上激发的峰值位置离得太近，就会「糊」在一起，无法分辨。这引出了听觉的**频率分辨率**概念，我们下一课会把它量化成临界频带。

## 3 同时掩蔽：强声吃掉弱声

现在进入本课的核心现象：**掩蔽（masking）**。

**核心概念：掩蔽（masking）**——一个声音（掩蔽音，masker）的存在，会抬高另一个声音（被掩蔽音）的听阈，使它变得难以听见。注意关键词：**掩蔽抬高的是「听阈」，不是直接「盖住」声音**。被掩蔽音并没有消失，只是它的响度被感知地压低了。

![同时掩蔽：掩蔽音抬高听阈并向上扩散](/images/speech/auditory-masking-1.svg)

同时掩蔽有几个重要的性质：

- **频域邻近性**：掩蔽音对被掩蔽音的影响，随两者的频率差增大而迅速减弱；在同一个临界频带内，掩蔽最强。
- **掩蔽向上扩散（upward spread of masking）**：低频掩蔽音能轻易掩蔽高频声，而高频掩蔽音几乎掩蔽不了低频声。原因与基底膜行波的方向有关——低频行波会经过高频区所在的位置，而高频行波传不到低频区。
- **强度依赖**：掩蔽音越强，听阈抬高越多；掩蔽音比被掩蔽音低约 6 dB 时，掩蔽通常还不明显。

**辨析｜易错点：** 掩蔽不是「音量大战」——不是强声把弱声「盖住」这么简单。掩蔽是**感知阈值的变化**：在一个强 1 kHz 音旁边，一个 50 dB 的 1.2 kHz 纯音可能完全听不见，但同一纯音如果单独出现，30 dB 就能听见。**被掩蔽的并不是声波，而是「听见」这个动作本身。** 也正因如此，掩蔽无法用简单的频谱相减来模拟，必须建立感知模型。

掩蔽的频域形状与临界频带直接相关：被掩蔽音与掩蔽音落在同一个临界带内时，掩蔽最有效；跨越临界带后，掩蔽量随频率差快速衰减。**掩蔽曲线本质上就是一张「临界带邻近度」的函数**——这也是为什么下一课的临界频带会成为一切掩蔽模型的骨架。

## 4 时间掩蔽：听觉的「余晖」与「先声」

掩蔽不只发生在同一时刻，还跨越时间：

- **前向掩蔽（forward masking）**：强声结束后的一小段时间（最长约 200 ms）内，紧随其后的弱声依然听不清；
- **后向掩蔽（backward masking）**：更反直觉——一个强声甚至能掩蔽它**之前** 5–50 ms 内出现的弱声，仿佛「未来盖住了过去」。

时间掩蔽解释了日常体验里许多「听不清」：单词的响亮部分会让紧随其后的轻辅音「消失」；两个音在时间上挨得越近，互相掩蔽越强。对语音处理，它提醒我们：**感知不是逐帧独立发生的**，相邻时间段会互相影响——这也为后面语音增强里「利用前后帧信息」的算法提供了感知上的理由。

时间掩蔽的时长与掩蔽音强度有关：掩蔽音越强，前向掩蔽持续越久；高频掩蔽音的前向掩蔽通常比低频更短。这些数值规律后来被写进心理声学模型，直接影响音频编码中「前后文依赖」的比特分配。

## 5 公式解析：Greenwood 位置—频率映射

把基底膜的 tonotopy 写成一个精确的公式，是听觉建模的经典结果——**Greenwood 函数**（1961，由大量动物与人耳数据拟合）：

$$f(x) = A\left(10^{\alpha x} - 1\right), \qquad A = 165.4,\ \alpha = 0.06$$

其中 $f$ 是频率（Hz），$x$ 是基底膜上距蜗顶（apex）的距离（mm）。

- **第一步：为什么是「单调上升」。** 行波峰值位置 $x$ 随频率 $f$ 单调移动：$f$ 越大，峰值越靠近蜗底（$x$ 大）。公式给出的是反过来：距蜗顶 $x$ 毫米处，特征频率是多少。
- **第二步：为什么有「减 1」。** 当 $x \to 0$（蜗顶），$10^{\alpha x} \to 1$，于是 $f \to 0$——蜗顶的极限特征频率趋近 0 Hz。这个「−1」保证低频端的边界条件成立，而不是简单地从 0 起步的指数。
- **第三步：代入验证量级。** $x = 10$ mm：$f = 165.4(10^{0.6}-1) = 165.4 \times 2.98 \approx 493$ Hz；$x = 25$ mm：$f \approx 5061$ Hz；$x = 35$ mm：$f \approx 20655$ Hz，逼近 20 kHz。**约 35 mm 长的基底膜，恰好铺开了 20 Hz–20 kHz 这十个八度**——人耳的频率范围与解剖尺寸在这里自洽。
- **第四步：对数结构的深远意义。** 从公式反解 $x = \frac{1}{\alpha}\log_{10}(f/A + 1)$：**位置 $x$ 大致是频率的对数**。频率翻倍（一个八度）在基底膜上对应近似相等的距离。这就是为什么人耳主观音高「近似对数」，也预告了下一课的 Mel 刻度——它正是要把这条「对数化的频率」变成可计算的标尺。

```python
import numpy as np

def greenwood(x_mm):
    """基底膜距蜗顶 x 毫米处的特征频率（Hz）。"""
    return 165.4 * (10 ** (0.06 * x_mm) - 1)

for x in [0, 10, 20, 25, 30, 35]:
    print(f"{x:3d} mm -> {greenwood(x):8.1f} Hz")
```

## 6 从心理声学到音频编码

人耳的「不忠」不只是生理学趣闻，它直接催生了一个巨大的工程领域——**心理声学编码（psychoacoustic coding）**。

MP3、AAC 等有损编码的核心思想是：**把超过掩蔽阈值的量化噪声藏进掩蔽音的阴影里**。编码器逐帧计算掩蔽阈值，凡是被掩蔽的部分，就允许用更粗的量化（更少的比特）甚至直接丢弃——反正人耳听不见。这就是为什么 MP3 能把 CD 音质压缩到十分之一，听感却几乎无损。<span class="marginnote">这条「感知冗余」的思路一路延伸：到语音大模型时代，SoundStream、EnCodec 等神经编解码器在端到端压缩波形时，也把「听感损失」写进损失函数里——只不过把「人耳掩蔽曲线」换成了可学习的判别器。参见本专题《音频神经编解码器》一课。</span>

反过来，语音增强与降噪也在利用掩蔽：目标是**把噪声压到掩蔽阈值以下**，而不是把噪声完全消干净——因为「听不见」和「不存在」在感知上是等价的，前者往往更省力、失真更小。

现代语音增强算法更进一步：把掩蔽阈值当作**停止条件**——如果残留噪声已经落在掩蔽阈值以下，算法就认为任务完成，不再继续压噪，从而避免「压噪压出音乐噪声」的副作用。

## 7 小结

- 人耳是**外耳（收集）、中耳（阻抗匹配）、内耳（换能）**三级流水线；中耳补偿约 25–30 dB 的界面损失。
- 基底膜实现**频率—位置映射（tonotopy）**，高频靠蜗底、低频靠蜗顶；Greenwood 函数 $f = 165.4(10^{0.06x}-1)$ 精确描述这一映射。
- **掩蔽**是「听阈被抬高」而非「声音被盖住」；同时掩蔽在临界频带内最强，且**向上扩散**（低频掩蔽高频容易）。
- **时间掩蔽**让强声的前后各约几十到几百毫秒内的弱声变难听见，说明感知不是逐帧独立的。
- 心理声学编码把量化噪声藏进掩蔽阴影，是 MP3/AAC 乃至神经编解码器的共同基石。
- 基底膜的「对数铺开」直接预示了 Mel 与 Bark 刻度——下一课我们将把物理频率重排成感知标尺。

在下一节，我们把人耳的频率分辨率精确量化：**临界频带与 Mel 刻度、Bark 刻度**——从「基底膜有多少个位置」到「频率该按什么标尺重排」，这是通向 MFCC 与滤波器组特征的最后一级台阶。
