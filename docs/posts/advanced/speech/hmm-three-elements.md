## 为什么从 HMM 开始

前面整整两章，我们都在做**特征工程**：把一帧语音变成 MFCC、FBank，再归一化、拼上动态与韵律特征。但识别语音的最终目标不是「描述每一帧」，而是「从一长串帧里猜出说话人想说什么」。帧与帧不是孤立的——「你好」两个字各有声学形态，合在一起还有**时间顺序**。要建模这种「随时间演化的序列」，需要第一个真正的序列模型：**隐马尔可夫模型（HMM）**。

HMM 统治语音识别声学模型长达三十年，直到 2010 年代中期才被深度模型取代。但它的三大件——**状态、转移、发射**——以及围绕它发展出的前向/维特比/EM 算法，是所有现代序列模型的共同基因。看懂 HMM，是看懂 CTC、RNN-T、Transformer 声学模型在解决什么问题的前提。<span class="marginnote">这条线索会在《端到端语音识别》各节反复出现：CTC 本质上是「对 HMM 对齐假设的简化」，注意力机制则是「软性的、数据驱动的对齐」。「隐藏状态 + 观测」这个框架，是整个 ASR 序列建模的源头。</span>

## 1 马尔可夫链：可见的随机序列

**马尔可夫链（Markov chain）**：一列随机状态 $q_1, q_2, \dots$，满足**马尔可夫性（Markov property）**——下一状态只依赖当前状态，与更早的历史无关：

$$P(q_t \mid q_1, \dots, q_{t-1}) = P(q_t \mid q_{t-1})$$

这就是「**一阶**」的含义：记忆长度为 1。一个马尔可夫链由两样东西完全刻画：**状态集合** $S = \{s_1, \dots, s_N\}$ 与**转移概率矩阵（transition matrix）** $\mathbf{A} = [a_{ij}]$，其中 $a_{ij} = P(q_t = s_j \mid q_{t-1} = s_i)$。

举个最简单的例子：只分「晴」「雨」两种状态，转移矩阵是

$$\mathbf{A} = \begin{pmatrix} 0.8 & 0.2 \\ 0.3 & 0.7 \end{pmatrix}$$

含义是：今天晴，明天 80% 概率仍晴、20% 转雨；今天雨，明天 30% 转晴、70% 仍雨。**给定 $\mathbf{A}$ 和初始分布，就能生成一整条天气序列**，也能计算任意一条序列出现的概率。<span class="marginnote">马尔可夫链无处不在：语言模型里的 <strong>bigram</strong> 就是对词序列做一阶马尔可夫假设——「下一个词只依赖上一个词」。HMM 是马尔可夫链的「藏起状态」版本；到第二级《离散数学》与《随机过程》课程里，你还会在马尔可夫链的极限分布、MCMC 采样中再次遇见它。</span>

## 2 隐马尔可夫模型：状态藏起来了

马尔可夫链假设状态**直接可见**——天气序列本身能被观测。但语音不是：说话人的**音素序列**（状态）我们看不到，能看到的只有**声学特征帧**（观测）。于是把马尔可夫链升级成**隐马尔可夫模型**：

**隐马尔可夫模型（HMM）**：一个双随机过程——一条**不可见的**状态序列 $Q = q_1, \dots, q_T$ 按 $\mathbf{A}$ 演化，每个状态 $q_t$ 按发射分布（emission distribution）$b_{q_t}(\cdot)$ 产生一个可见的观测 $o_t$。我们观察到的是 $O = o_1, \dots, o_T$，状态序列从未直接给出。

语音解释：**状态 ≈ 音素（或音素的子状态），观测 ≈ 特征帧（MFCC）。** 你听到的是连续的帧，音素是藏在帧背后的「真凶」。<span class="marginnote">「隐」就隐在这里：状态序列不可观测，只能从观测里反推。这和海森堡那句话神似——我们不能直接「看到」音素，只能通过观测（特征帧）去推测它。这也是为什么机器翻译里把 HMM 对齐叫「隐对齐」。</span>

## 3 HMM 的三要素：$\lambda = (\mathbf{A}, \mathbf{B}, \boldsymbol{\pi})$

一个 HMM 由**三要素**完整刻画，记作 $\lambda$：

- **状态转移矩阵 $\mathbf{A}$**：$a_{ij} = P(q_{t+1} = s_j \mid q_t = s_i)$，刻画**状态如何随时间演化**——对应语音里「上一个音素/状态到下一个音素/状态」的概率。
- **发射分布 $\mathbf{B}$**：$b_j(o_t) = P(o_t \mid q_t = s_j)$，刻画**每个状态如何产生观测**——对应「这个音素听起来像什么」。离散 HMM 用发射概率表，连续 HMM 用高斯混合模型（GMM，见《高斯混合模型与连续密度 HMM》一节）。
- **初始状态分布 $\boldsymbol{\pi}$**：$\pi_i = P(q_1 = s_i)$，刻画**序列开头的状态分布**——对应句子开头的第一个音素。

**核心概念：三要素 = 转移 + 发射 + 初始。** 知道 $\lambda$，就完全确定了 HMM 的行为：既能按它生成观测序列，也能反过来对任意观测序列打分。

## 4 公式解析：一条路径的联合概率

HMM 最基本的一条式子：给定 $\lambda$，**一条状态路径 $Q$ 与观测序列 $O$ 同时发生的联合概率**是

$$
P(O, Q \mid \lambda) = \pi_{q_1}\, b_{q_1}(o_1) \prod_{t=2}^{T} a_{q_{t-1},\, q_t}\, b_{q_t}(o_t)
$$

逐步拆解：

- **第一步，读整体结构**：概率是一串**乘积**。每一项对应序列里的一步，整条式子就是「沿着时间轴，把每一步的概率连乘起来」。
- **第二步，看首项**：$\pi_{q_1}$ 是初始状态概率，$b_{q_1}(o_1)$ 是第一个状态产生第一个观测的概率——两件事都发生在 $t=1$。
- **第三步，看连乘号**：对 $t = 2, \dots, T$，每步两项：$a_{q_{t-1}, q_t}$ 是**从上一步状态转到本步状态**的转移概率，$b_{q_t}(o_t)$ 是**本步状态产生本步观测**的发射概率。
- **第四步，理解「给定路径」**：路径 $Q$ 是具体的（如「晴晴雨雨」），所以概率是**一条路径一个数**。但我们不知道真正的 $Q$，观测到的只有 $O$——要得到 $P(O \mid \lambda)$，必须**把所有可能的路径加起来**：

$$P(O \mid \lambda) = \sum_{\text{所有 } Q} P(O, Q \mid \lambda)$$

状态数 $N$、时长 $T$，路径总数是 $N^T$——指数爆炸。直接求和完全不可行，这正是下一节**前向算法**要解决的问题。

**辨析｜易错点：区分「一条路径的概率」与「观测序列的概率」。** $P(O, Q \mid \lambda)$ 是路径已知时的联合概率；$P(O \mid \lambda)$ 是「只看观测、状态全隐藏」的边际概率。语音识别里，训练和评分用的是后者；而对齐（猜最可能的状态序列）用的是另一条式子——这个区别是整个 HMM 三大问题的分水岭。

## 5 左到右 HMM：为什么它适合语音

通用 HMM 允许任意状态间转移（全连接拓扑）。但语音有一个天然约束：**音素只能按时间往前推进**，不能倒流。因此语音用**左到右（left-to-right）拓扑**：

- 状态编号 $1, 2, \dots, N$，只允许 $a_{ij}$ 在 $j \ge i$ 时非零——**状态只能停留或前进，不能后退**。
- 自环 $a_{ii}$ 控制「在这个状态停留多久」，从而**隐式建模音素时长**。
- 每个音素常用 3–5 个状态（Bakis 模型）建模其「起—中—收」三段，对应音素内部声学形态的演变。<span class="marginnote">自环概率 $a_{ii}$ 与音素时长分布直接相关：停留 $d$ 帧再离开的概率约正比于 $a_{ii}^{d}$，呈几何分布。真实音素时长更接近对数正态分布——这是 HMM 时长建模的先天局限，也催生了后续的显式时长模型（如 FastSpeech 的时长预测器）。</span>

这套左到右结构之所以能工作，依赖 HMM 的两个**基本假设**：

- **一阶马尔可夫假设**：下一状态只依赖当前状态，与更早历史无关——这是马尔可夫链的定义本身。
- **观测独立性假设**：观测 $o_t$ 只由当前状态 $q_t$ 决定，与其它观测和状态无关——正是前向递推里「只乘当前发射概率」的依据。

真实语音两处都不严格成立：**协同发音**让前一音素影响后一音素的声学形态（见《音素、音节与韵律》一节），相邻帧的特征也高度相关。HMM 靠「状态内部的自环」与「特征里显式拼接 Delta」来部分补救——自环吸收短期时间结构，Delta 给观测补上帧间动态信息。**明白这两条假设在哪成立、在哪被违背，是理解后续一切序列模型（CTC、Transformer）改进动机的钥匙。**

一个生成观测序列的 Python 示意（感受「状态藏起来」）：

```python
import numpy as np

# 3 状态左到右 HMM 的三要素
A = np.array([[0.6, 0.4, 0.0],
              [0.0, 0.6, 0.4],
              [0.0, 0.0, 1.0]])        # 只留自环与前向
pi = np.array([1.0, 0.0, 0.0])         # 必从状态 1 开始
mu = np.array([0.0, 2.0, 4.0])         # 每状态的发射均值
sigma = np.ones(3)

T = 10
states, obs = [], []
q = np.random.choice(3, p=pi)
for _ in range(T):
    states.append(q)
    obs.append(np.random.normal(mu[q], sigma[q]))
    q = np.random.choice(3, p=A[q])    # 依 A 转移到下一状态
```

运行几遍你会发现：观测值大致沿「低 → 中 → 高」爬升，但每一步都带噪声——**你只能看到 obs，看不到 states**，这正是「隐」的直观体验。

## 6 小结

- **马尔可夫性**：$P(q_t \mid q_{t-1}, \dots) = P(q_t \mid q_{t-1})$，一阶记忆；bigram 语言模型是它的特例。
- **HMM 是双随机过程**：不可见的状态序列按 $\mathbf{A}$ 演化，每个状态按 $\mathbf{B}$ 发射一个可见观测；语音里状态≈音素、观测≈特征帧。
- **三要素 $\lambda = (\mathbf{A}, \mathbf{B}, \boldsymbol{\pi})$**：转移矩阵、发射分布、初始分布，完整刻画模型。
- **联合概率 $P(O, Q \mid \lambda)$ 是沿时间轴的连乘**；$P(O \mid \lambda)$ 要对 $N^T$ 条路径求和，直接算不可行。
- **语音用左到右拓扑**：状态只能前进，自环隐式建模音素时长。

在下一节，我们将回答 HMM 的经典三大问题：**已知模型给观测打分（评估）、反推最可能状态序列（解码）、从数据估计三要素（学习）**。
