## 为什么从 i-vector 开始

在深度表征出现之前，说话人识别的黄金标准是 **i-vector**（2011，Dehak 等人）。它把「整段语音」压成一个**低维向量**——像「声纹的浓缩液」——然后配 **PLDA** 打分。i-vector 时代统治声纹识别近十年，直到 x-vector 出现，但它留下的数学框架（因子分析、信道补偿、概率打分）至今仍是说话人建模的「语法」，深度嵌入只是换了「词汇」。

理解 i-vector 有双重价值：第一，它是「把高维声学空间压成低维身份向量」这一思想的第一个系统实现，深刻影响了后续一切嵌入方法；第二，它的 PLDA 打分逻辑（说话人内/间方差建模）今天仍被用于深度嵌入的校准。

## 1 从 GMM-UBM 到 i-vector：一个向量替身

在 i-vector 之前，主流是 **GMM-UBM**：每个说话人建一个 GMM，语音对 GMM 的**充分统计量**（均值的偏移）拼成一个高维的「超向量（supervector）」，再算相似度。超向量维度巨大（如 1024 个高斯 × 40 维 = 40960 维），冗余且易受信道影响。

i-vector 的洞察：超向量虽高维，但说话人差异其实躺在**一个低维子空间**里。于是把超向量建模成：

$$\mathbf{M} = \mathbf{m} + \mathbf{T} \mathbf{w}$$

- $\mathbf{M}$：某段语音的（超向量空间里的）模型。
- $\mathbf{m}$：通用均值超向量（UBM 的均值）。
- $\mathbf{T}$：**总变化子空间（total variability subspace）**——一个全局线性子空间，既含说话人差异、也含信道差异（因此叫「总变化」）。
- $\mathbf{w}$：**i-vector**——该语音在这个子空间上的坐标（低维，如 400–600 维）。

**核心概念：i-vector = 语音在「变化子空间」上的投影坐标。** 它把「这段语音所有可变的信息」（说话人 + 信道 + 环境）统一压成一个向量。相比超向量，维度从几万降到几百，且经过子空间去噪——是「信息压缩」的胜利。<span class="marginnote">为什么「总变化」而不分说话人/信道两个子空间？早期 JFA（联合因子分析）把说话人与信道分开建模，但实践中分离不干净。Dehak 的洞见：先不区分，统一用一个子空间装所有变化，等向量提取出来再用 PLDA/长度归一化做信道补偿——「先压缩、后分离」反而更好用。这是工程上「先做再做对」的典型智慧。</span>

## 2 公式解析：i-vector 提取

给定一段语音的充分统计量（零阶统计量 $N$、一阶统计量 $F$），i-vector 是**后验分布的均值**：

$$\mathbf{w} = \left( \mathbf{I} + \mathbf{T}^\top \mathbf{\Sigma}^{-1} N(\mathbf{x}) \mathbf{T} \right)^{-1} \mathbf{T}^\top \mathbf{\Sigma}^{-1} \tilde{\mathbf{F}}(\mathbf{x})$$

逐步拆解：

- **第一步，看输入统计量**：$N(\mathbf{x})$ 是「每帧对每个高斯分量的归属度」（零阶），$\tilde{\mathbf{F}}(\mathbf{x})$ 是「每个分量的均值偏移」（一阶）——它们汇总了整段语音的信息。
- **第二步，看 $\mathbf{T}$ 与 $\mathbf{\Sigma}$**：$\mathbf{T}$ 是总变化子空间，$\mathbf{\Sigma}$ 是 UBM 的协方差。式子用「子空间 + 协方差」把统计量「投影」到低维。
- **第三步，看后验均值的意义**：$\mathbf{w}$ 不是把统计量硬投影，而是**贝叶斯后验**——在「说话人变化服从先验（低维高斯）」的假设下，估计最可能的坐标。正则项 $\mathbf{I}$ 把坐标「拉向零」，抑制短语音的过度估计。
- **第四步，看长度归一化**：提取后通常做**长度归一化（length normalization）**，把 i-vector 单位化，减小「语音越长向量范数越大」的偏置——让打分更公平。

**核心结论：i-vector 是「贝叶斯压缩」——在子空间假设下把高维统计量压成低维坐标，并自带长度正则。** 这一步把「说话人建模」变成「向量空间里的几何问题」：相似度就变成了「向量距离」。

## 3 PLDA：概率线性判别分析打分

有了 i-vector，问题变成「两个向量（注册 vs 验证）有多像」。朴素余弦相似度简单，但没利用「哪些方向的差异更像同一人」。**PLDA（Probabilistic Linear Discriminant Analysis）** 用一个生成模型显式分解 i-vector 的方差：

$$\mathbf{w} = \boldsymbol{\mu} + \mathbf{F} \mathbf{y} + \boldsymbol{\epsilon}$$

- $\boldsymbol{\mu}$：全体 i-vector 的均值。
- $\mathbf{F}\mathbf{y}$：**说话人因子**——$\mathbf{y}$ 是该说话人的「身份潜变量」，跨语音共享，解释「同一人为何像」。
- $\boldsymbol{\epsilon}$：**残差（信道/噪声）**——每次语音特有的变化。

PLDA 打分：给定注册 i-vector $w_1$ 与验证 $w_2$，计算「它们是同一人（共享 $\mathbf{y}$）」与「不同人（各自 $\mathbf{y}$）」两种假设下的似然比：

$$
\text{Score}(w_1, w_2) = \log \frac{P(w_1, w_2 \mid \text{同一说话人})}{P(w_1, w_2 \mid \text{不同说话人})}
$$

- **第一步，看两个假设**：同一人假设下，$w_1, w_2$ 共享同一个 $\mathbf{y}$；不同人假设下各用各的 $\mathbf{y}$。PLDA 已训练出 $\mathbf{F}$、$\boldsymbol{\epsilon}$ 的参数，可精确计算两个概率。
- **第二步，看判别力来源**：若 $\mathbf{y}$ 的方差远大于 $\boldsymbol{\epsilon}$（说话人差异 >> 信道差异），同一人的两个向量「共享因子」带来的相似度就很明显——打分高。若信道噪声大，打分被稀释。
- **第三步，看与余弦相似度的关系**：余弦是「无监督几何」，PLDA 是「监督概率」——它用训练数据学会了「哪些方向是说话人方向」，打分更准。这也是为什么 i-vector 时代「PLDA 是标配」。

**核心要点：PLDA = 用生成模型给相似度「加权」。** 它不只问「向量近不近」，还问「近的方向对不对」——把说话人方差与信道方差分开建模，是「信道补偿」的统计实现。<span class="marginnote">PLDA 的「说话人因子 + 残差」分解与因子分析、随机效应模型同族——本质是「多层方差成分分析」。它也是后面 x-vector 时代「余弦打分」的对照组：深度嵌入普遍用余弦而非 PLDA（嵌入已经过判别训练），但「校准（calibration）」仍借 PLDA 的思路——用 PLDA 打分做分数校准，让相似度可比阈值。</span>

## 4 i-vector 的遗产与局限

i-vector + PLDA 统治了 2011–2018 年的说话人识别，它的遗产清晰可辨：

**「整段语音 → 一个向量」的范式**：x-vector、ECAPA 都继承「说话人嵌入」的表述，只是提取器从因子分析换成 DNN。
**信道补偿思想**：总变化空间、长度归一化、PLDA 残差——这些「减掉非身份变化」的技术，在深度时代演化为「归一化 + 数据增强」。
**局限**：i-vector 的 $\mathbf{T}$ 是**线性**子空间，而说话人差异含大量**非线性**——短语音（几秒）时 i-vector 估计不稳，长尾口音难建模。DNN 嵌入用非线性映射弥补了这些短板。<span class="marginnote">i-vector 在「短语音」上的缺陷尤其致命：3 秒语音的后验估计方差巨大，PLDA 打分虚高。深度方法（x-vector）用「统计池化」聚合帧级特征，短语音表现显著更好——这是 i-vector 被取代的最实际原因。</span>

**辨析｜易错点：i-vector 不是「对每帧特征取平均」。** 初学者常以为「i-vector = 平均特征向量」。不对——i-vector 是「把 GMM 充分统计量投影到总变化子空间」的后验坐标，它利用**整个 GMM 的分布结构**与**全局训练数据**，远非简单平均。这种「从帧级特征 → 分布统计 → 子空间坐标」的三级压缩，正是统计说话人建模的精髓。

## 5 i-vector 的实操流程

用 i-vector + PLDA 搭一套声纹系统，有标准的实操流水线（Kaldi 是其经典实现）：

1. **特征**：MFCC（20–40 维）+ 说话人级均值归一化（CMVN）。
2. **UBM 训练**：用大量「通用语音」训一个 GMM（如 1024 高斯）——这是「通用人群」的声学模型。
3. **充分统计量**：每段语音对 UBM 算零阶/一阶统计量。
4. **T 矩阵训练**：在大量说话人的统计量上训总变化子空间 $\mathbf{T}$（EM 迭代）。
5. **i-vector 提取 + 长度归一化**。
6. **PLDA 训练 + 打分**：在开发集上训 PLDA，对「注册 vs 验证」打分。

**公式解析：UBM 的「背景模型」角色。**

$$
\text{LLR} \approx \log P(x \mid \text{GMM}_{\text{说话人}}) - \log P(x \mid \text{GMM}_{\text{UBM}})
$$

- **第一步，看分子**：$P(x \mid GMM_{\text{说话人}})$ 是「张三的 GMM 解释这段语音的概率」——针对张三建模。
- **第二步，看分母**：$P(x \mid GMM_{\text{UBM}})$ 是「通用模型解释的概率」——「谁都像」的背景。
- **第三步，看比值含义**：LLR 回答「张三比'普通人'更能解释这段语音多少倍」——**UBM 是「普通人」的基线，说话人 GMM 是「张三」的偏移**。
- **第四步，看工程优势**：UBM 只需训一次；每个说话人的 GMM 从 UBM **自适应（MAP）** 而来，只需该人少量语音——「一次通用 + 每次自适应」是 i-vector 时代的省钱核心。

**核心要点：i-vector 的实操 = 「UBM 打底 + 子空间压缩 + PLDA 打分」的流水线。** 它训练便宜、可解释、无 GPU 也能跑——这是它长期服役的原因，也是理解「背景模型」这一核心概念的入口。

## 6 小结

- **i-vector** 把整段语音压成低维向量：$\mathbf{M} = \mathbf{m} + \mathbf{T}\mathbf{w}$，$\mathbf{w}$ 是总变化子空间坐标。
- 提取是**贝叶斯后验均值**，配合长度归一化减小时长偏置。
- **PLDA** 用「说话人因子 + 残差」分解向量，用似然比打分，是 i-vector 时代的标配。
- 信道补偿（总变化、长度归一化、PLDA 残差）是传统方法的灵魂。
- 局限是**线性子空间**与**短语音不稳定**，被深度嵌入（x-vector）取代，但范式与补偿思想被继承。

**附：关键概念速记**

- **i-vector** = 总变化子空间 $\mathbf{T}$ 上的坐标——「整段语音 → 低维向量」。
- **总变化**：说话人 + 信道统一建模——「先压缩、后分离」。
- **贝叶斯压缩**：$\mathbf{w} = (\mathbf{I} + \mathbf{T}^\top \Sigma^{-1} N \mathbf{T})^{-1} \mathbf{T}^\top \Sigma^{-1} \tilde{\mathbf{F}}$——后验均值 + 长度正则。
- **UBM**：通用背景模型——「普通人」的声学基线，说话人 GMM 从它自适应。
- **PLDA**：说话人因子 + 残差分解——「近的方向对不对」的概率打分。
- **长度归一化**：减小「语音越长范数越大」的偏置。
- **信道补偿**：总变化、长度归一化、PLDA 残差——「减掉非身份变化」。
- **局限**：线性子空间、短语音不稳——被深度嵌入取代，但范式被继承。

**延伸思考**：i-vector 的「总变化子空间」是「**降维即建模**」的范例——它假设「语音的全部变化躺在低维子空间里」，把高维统计量投影上去就得到身份向量。这个「子空间假设」虽然线性、粗糙，却深刻影响了后续一切嵌入方法（x-vector 只是把「线性投影」换成「非线性网络」）。**「假设低维结构、再验证」是统计建模的方法论**——先信「声音可压缩」，再让数据告诉你「怎么压」。
