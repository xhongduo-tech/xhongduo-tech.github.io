## 为什么从端点检测开始

上一节我们得到了逐帧的**短时能量**与**短时过零率**两把尺子。它们最直接的应用，就是回答一个几乎所有语音系统都要先回答的问题：**这段录音里，真正「有人在说话」的是哪一段？** 从哪里开始、到哪里结束？这个问题叫**端点检测（endpoint detection）**，英文更常用它的别名 **VAD（Voice Activity Detection，语音活动检测）**。<span class="marginnote">VAD 这个名字在通信、降噪、唤醒词领域更常见——它不只是 ASR 的预处理，还是双工通话里省电、降噪里估计噪声、唤醒里「一直听」的开关。整个语音交互链路里它无处不在。</span>

别小看这一步。**识别器算得再聪明，如果连语音的边界都定错了，后面的结果一定是错的**——多算进来的噪声会变成幻觉词，少算进去的尾音会吃掉词尾。本节先讲经典的能量法（双门限），再讲模型法（GMM / 深度网络），让你看到「手工规则」与「数据驱动」两条路径各自的代价与收益。

## 1 问题定义：端点检测在找什么

把一段录音按帧处理，端点检测要做的是给**每一帧打一个标签**：语音（speech）还是非语音（non-speech / silence）。语音段的第一个语音帧是**起点（onset）**，最后一个语音帧是**终点（offset）**。

难点有三：

1. **噪声**。录音很少有绝对安静的环境，噪声的能量随时在变。
2. **清音边界**。词首词尾往往是轻弱清音（/s/、/f/、/h/），能量接近噪声，极易被吞掉。
3. **停顿**。一句话内部的停顿、换气，能量会跌下来，却仍是语音段的一部分。

一套好的端点检测，必须同时应对这三件事。经典的双门限法，正是为它们逐一设计了应对机制。

## 2 能量法：双门限端点检测

**核心思想：用一个门限判断「响不响」，用一个更低的门限确认「接近语音」，用过零率修补「清音尾巴」。**

记第 $m$ 帧的短时能量为 $E_m$、短时过零率为 $Z_m$。双门限法的经典流程是：

1. **取噪声参考**。取录音前 $K$ 帧（假设静音），算它们的平均能量 $\bar E$ 与平均过零率 $\bar Z$，作为当前录音的「噪声底」。
2. **设三个门限**。能量高门限 $T_H$、能量低门限 $T_L$、过零率高门限 $Z_T$。
3. **高门限初检**。所有满足 $E_m > T_H$ 的帧构成「必为语音」的核心段。
4. **低门限扩张**。从每个核心段向两端扩展，只要 $E_m > T_L$ 就并入语音段。
5. **过零率补隙**。两个语音段之间若有能量跌破 $T_L$ 的短间隙，检查间隙内是否出现过零率 $Z_m > Z_T$ 的帧——若有，说明间隙里是清音（比如「是」的 /sh/ 尾），把两段拼接起来。

这样一套规则，恰好对应前面说的三个难点：噪声底自适应 → 抗噪声；低门限 + 过零率 → 保清音边界；间隙拼接 → 容停顿。

## 3 公式解析：双门限为什么「先高后低」

门限怎么定，是双门限法的灵魂。一种常见的自适应设定是：

$$
\bar E = \frac{1}{K}\sum_{m=1}^{K} E_m, \qquad
T_H = \mu\, \bar E, \qquad
T_L = \lambda\, \bar E, \qquad 1 < \lambda < \mu
$$

其中 $\mu$ 常取 2–3，$\lambda$ 常取 1.1–1.5；过零率门限常用 $Z_T = \eta\, \bar Z$，$\eta$ 取 2–3。<span class="marginnote">这里 $\bar E$、$\bar Z$ 是「当前录音自己的噪声底」——这是自适应门限的全部秘密：门限跟着这段录音走，而不是一个写死的全局常数。换麦克风、换环境都不用改代码，重新估一遍噪声底即可。</span>

逐步拆解：

- **第一步，估计噪声底 $\bar E$、$\bar Z$**：取录音最开头的 $K$ 帧。这一步的隐含假设是**录音从静音开始**——如果开头就在说话，噪声底会被污染，整个检测都会偏。所以工程上要么要求录音前留一段静音，要么用更稳的噪声估计（如分位数）。
- **第二步，定高门限 $T_H$**：噪声底的 $\mu$ 倍。「比环境响 2–3 倍」才敢说一定在说话，这一步宁可漏检也不误检——**高门限的使命是找到最可靠的语音核心**。
- **第三步，定低门限 $T_L$**：只比噪声底高一点点。「比环境稍微响」就当作候选语音，把它吸收进来——**低门限的使命是尽量不丢边界**。
- **第四步，决策顺序**：先高后低。**为什么必须先高后低？** 如果只用一个低门限，任何一段噪声的波动都可能超过 $T_L$，全被误判为语音；先让高门限圈定「绝对可信」的区域，再从那里向外扩张，等于给「低门限吸收」限定了起点，误判空间小得多。<span class="marginnote">「先保守圈定核心，再向外温和扩张」的思路，在图像分割（先找到确定的种子再区域生长）、聚类算法里都能看到同一手法的变体——这是「由可信处出发」的通用方法论。</span>

把这段逻辑写成伪代码，一目了然：

```python
def double_threshold_vad(energy, zcr, mu=2.5, lam=1.3, eta=2.5, K=10):
    Ebar = mean(energy[:K])          # 噪声底能量
    Zbar = mean(zcr[:K])             # 噪声底过零率
    TH, TL, ZT = mu*Ebar, lam*Ebar, eta*Zbar
    n = len(energy)
    # 第 3 步：高门限找核心段
    core = [E > TH for E in energy]
    speech = core[:]                 # 标记语音帧
    # 第 4 步：从核心段向两端扩张（这里以向右扩张为例）
    for i in range(n - 1):
        if core[i] and not speech[i+1] and energy[i+1] > TL:
            speech[i+1] = True
    # 第 5 步：过零率补隙（简化示意）
    for i in range(1, n - 1):
        if not speech[i] and speech[i-1] and speech[i+1]:
            if zcr[i] > ZT:          # 间隙里是清音 → 拼回语音段
                speech[i] = True
    return speech
```

真实工程实现会双向扩张、按间隙长度限制拼接，并加最小语音段长度过滤，但骨架就是上面这五步。

## 4 模型法：从 GMM 到深度网络

双门限法快、省、可解释，但它把「语音/非语音」这一判别压成了几条手工规则，在噪声复杂时不够稳。**模型法的思路是：与其手写规则，不如让统计模型去学「语音长什么样」**。

### GMM 方法

对每一帧提取特征（如 log 能量、若干频带能量），为**语音类**与**非语音类**各建一个**高斯混合模型（GMM）**，分别给出「这一帧属于本类」的概率，帧被判给概率更大的一类：

$$\hat{y}_m = \arg\max_{c \in \{\text{语音}, \text{非语音}\}} \; p_c(\mathbf{x}_m)$$

GMM 的本质是「用若干个高斯分布叠起来逼近任意分布」，这背后是第二级《概率论与数理统计》里极大似然估计与 EM 算法——**模型法是概率论在语音系统里的第一次正面出场**。著名的 WebRTC VAD 就是 GMM 路线：用 6 个频带的 log 能量做特征，对语音/非语音各维护一个 GMM，并随每帧结果**在线更新噪声模型**，让门限永远跟着环境走。

### 深度网络方法

数据充足时，直接训练一个分类网络（RNN、CNN 或 Transformer），输入**多帧**的特征窗口，输出帧级的语音概率。好处是能建模时序上下文（语音不会孤立出现），误检率远低于规则法；代价是需要成规模的标注数据与算力。现代端到端 ASR 常把 DNN-VAD 作为前端，与识别模型联合使用。<span class="marginnote">DNN-VAD 是后面「关键词唤醒」和「流式识别」的共同底座。到语音大模型那章你还会看到，端到端模型干脆把 VAD 也学进网络内部——VAD 从「前置模块」变成了「模型隐式能力」。</span>

## 5 辨析与易错点

- **「先高后低」的顺序不能颠倒。** 只用低门限会误把噪声波动当语音；只用高门限会把清音头尾全部丢掉。双门限的意义在于**两个门限各管一段**。
- **噪声参考帧必须干净。** 取前 $K$ 帧假设静音，是双门限法最脆弱的假设。开头有音乐、有人声、有瞬态冲击时，噪声底估计失真，建议换成对整段能量取分位数（如 10% 分位）来估计噪声底。
- **过零率门限只在「间隙」里起作用，不能全局滥用。** 若全局用 $Z_m > Z_T$ 判语音，清音的强噪声背景会全部误判。ZCR 是**修补**工具，不是**主判**工具。
- **短帧长会漏掉塞音。** 塞音（/b/ /d/ /g/）的爆破段只有 5–20 ms，帧长 25 ms 时可能被平均掉。需要精确起点时，考虑更细的帧或在该段做子帧分析。
- **门限系数与采样率/帧长耦合。** 上一节讲过 ZCR 随帧长缩放，这里的 $Z_T$ 也一样——换参数后系数要重新标定，别照抄论文里的常数。

## 6 小结

- **端点检测 / VAD**：给每帧打「语音/非语音」标签，是 ASR、唤醒、降噪、通信的共同前置。
- **双门限法**：高门限圈核心 → 低门限扩边界 → 过零率补清音间隙；门限由当前录音的噪声底自适应估计。
- **模型法**：GMM 用概率判别（WebRTC VAD），DNN 用数据学习时序判别，更强但更重。
- **工程要点**：先高后低、噪声底要干净、ZCR 只做修补、参数随采样率重标定。
