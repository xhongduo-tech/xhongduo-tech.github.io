## 为什么从情感与风格合成开始

上节的音色克隆解决「谁在说」，本节解决「怎么说」。同一句「你来了」——高兴地说、生气地说、疑问地说，F0 曲线、语速、音质完全不同。机器如果只会一种平板语调，合成再「像人」，听起来也像念稿的机器人。**情感与风格可控的语音合成（expressive / controllable TTS）** 的目标：让合成语音带情绪、带风格，而且**风格可控**——用户说「这句话要高兴一点」，系统就真的「高兴一点」。

这比音色克隆更难，因为**风格比音色更隐晦**：音色是「稳定身份」，风格是「逐句变化的表达」；音色靠一个向量就能大体框住，风格却要在**时间轴上展开**（这一句是渐强的、那一句是带尾音的）。于是风格建模发展出「显式标签」与「参考音频」两条路线。

## 1 情感的声学坐标：风格在信号里长什么样

要控制风格，先要知道风格「在哪」——它落在声学信号的哪些维度上。情感语音学研究给出四个关键坐标：

- **基频（F0）**：高兴时 F0 整体抬高、起伏大；悲伤时 F0 压低、平坦。
- **语速（speaking rate）**：兴奋时快，沮丧时慢，紧张时还可能「抢拍」。
- **能量（energy）**：愤怒时能量大、爆发强；温柔时能量小、起伏缓。
- **嗓音质量（voice quality）**：气声（whisper）、紧喉（pressed）、嘎裂（creaky）——同一音高下不同的「质感」。

这些正是 FastSpeech 2「方差适配器」显式建模的 F0、能量、时长——**显式建模韵律，是风格可控的物理基础**。只要这三个量可被外部干预，情感就在「可调」的射程内。<span class="marginnote">注意「情感」与「风格」的粒度差异：情感（emotion）是离散的、有标签的（高兴/悲伤/愤怒）；风格（style）是连续的、多维的（正式、随和、带口音、播音腔）。两者在技术上高度重叠——都要建模「韵律 + 音质」的变体，只是控制信号的形式不同（标签 vs 向量）。</span>

## 2 显式控制：情感标签与强度旋钮

最简单直接的控制是**用标签做条件**。训练数据里给每句标注情感（如 ESD、MELD 数据集），模型学「情感标签 → 韵律模式」：

$$p(y \mid \text{文本}, e_{\text{emo}}, \alpha)$$

- $e_{\text{emo}}$：情感条件（如 one-hot「高兴」），注入方式与说话人嵌入相同（拼接/FiLM）。
- $\alpha$：**情感强度**——一个连续标量，控制「高兴的程度」。训练时对同一情感句子采样不同强度，模型学「强度 → 情感浓度」。

**公式解析：情感条件注入。** 在 FastSpeech 2 式框架里，情感向量 $e_{\text{emo}}$ 与说话人向量 $e_{\text{spk}}$ 一起注入方差适配器与频谱生成器：

$$
\hat{F0} = \text{F0Predictor}(h_i, e_{\text{emo}}, e_{\text{spk}}), \qquad \hat{d}_i = \text{DurationPredictor}(h_i, e_{\text{emo}})
$$

- **第一步，看条件进入的位置**：情感不仅影响频谱，更直接影响 **F0 与时长**——高兴的「你好」F0 高、时长稍长。所以情感条件要注入「预测韵律」的模块，而非只在最终频谱层。
- **第二步，看说话人与情感的叠加**：$e_{\text{emo}}$ 与 $e_{\text{spk}}$ 并排进入——一个管「谁在说」，一个管「什么情绪」，互不干扰。这正是「音色与风格解耦」的实践：**说话人条件决定声音长相，情感条件决定说话方式。**
- **第三步，看强度 $\alpha$ 的用法**：把 one-hot 情感乘上强度标量（或把强度编码进嵌入），模型输出「不同程度的情绪表达」。推理时调 $\alpha$ 就是「旋转情感浓度旋钮」。

**核心要点：显式标签控制「可解释但粗」。** 「高兴」这个标签在真实语音里能对应无数种高兴（开怀大笑 vs 抿嘴一笑），one-hot 只能表达「平均的高兴」。想要更细、更自然，需要参考式控制。

## 3 参考式控制：让模型「模仿」一段风格

参考式风格合成不用标签，而是**从一段参考语音里提取风格**，让合成结果「跟它学」。经典方案是 **GST（Global Style Token）**：

1. **参考编码器**：把参考语音压成一个风格嵌入向量 $g$。
2. **token 词典**：模型学一组「基础风格 token」$T_1, \dots, T_N$（如「轻快」「沉稳」「上扬」），参考嵌入 $g$ 与这些 token 算注意力权重，加权组合出「风格向量」。
3. **注入**：风格向量注入解码器，让合成跟着参考走。

$$
g = \sum_{k} \underbrace{\frac{\exp(\text{score}(e_{\text{ref}}, T_k))}{\sum_j \exp(\text{score}(e_{\text{ref}}, T_j))}}_{\text{风格 token 权重}}\, T_k
$$

逐步拆解：

- **第一步，看参考编码**：$e_{\text{ref}}$ 是参考语音的风格嵌入——捕捉「这段话的语气、节奏、音色倾向」。
- **第二步，看 token 注意力**：模型维护一组可学习的风格 token $T_k$，$e_{\text{ref}}$ 与每个 token 算相似度、softmax 成权重——参考风格被解释成「几个基础风格的组合」。
- **第三步，看加权组合**：$g$ 是 token 的凸组合——「6 分轻快 + 3 分沉稳 + 1 分上扬」这种可解释的混合。
- **第四步，理解可解释性红利**：token 是**离散的、可插拔的**——你可以跳过参考音频，直接指定「token 3 权重拉满」，实现「不用参考的纯指定风格」。这正是 GST「既参考又可控」的两用性。

**核心要点：参考式控制「细但依赖参考」。** 它不需要标签（省标注成本），能表达标签表达不出的细微风格；但「像不像参考」取决于参考质量，且提取的风格与文本内容的耦合（参考说「吃饭」提取的风格用于合成「开会」）可能错位——这被称为「风格—内容纠缠」。<span class="marginnote">GST 的 token 注意力是「软组合」，更有可解释性的变体是「离散选择」（hard selection，从 token 里挑一个）。软组合灵活但不可解释，硬选择可控但粗糙——两者之争与说话人嵌入「全局 vs 逐句」的分歧同构：<strong>信息量 vs 可控性，永远是风格建模的轴</strong>。</span>

## 4 从 GST 到语音大模型：风格的「隐式化」

风格控制的演进，是「显式标注 → 参考提取 → 隐式大模型」的连续光谱：

- **显式标签**（情感分类器 / 人工标注）：可解释、易控制，但粗。
- **参考提取**（GST / 参考注意力）：细、自然，但依赖参考且与内容纠缠。
- **语音大模型**（VALL-E、GPT-4o 语音）：**不显式建模风格**，直接把「参考音频 + 文本」作为 prompt 条件，模型从上下文里隐式提取风格。风格不再是「模块」，而是「上下文推理」的副产品。

**辨析｜易错点：「可控」不等于「真实」。** 显式标签控制的合成常常「情绪到位但做作」——因为真实情感在时间轴上是**动态演化**的（前句平静、句末爆发），而标签是整句一个常量。现代研究转向「逐句、逐片段」的风格控制（细粒度情感曲线），或在推理时用「风格插值」让情感渐变。**想要既自然又可控制，就必须在「时间分辨率」上做文章，而不是只换一个全局标签。**

## 5 风格合成的评测与数据

风格/情感合成是「最难评」的 TTS 子方向——评测设计要格外小心：

- **多维度 MOS**：不只「自然度」，还要「情感正确性」（情绪表达对不对）、「风格强度」（表达够不够味）、「可控性」（调强度旋钮是否真的变强）。**单报一个 MOS 是「盲人摸象」。**
- **ABX 偏好**：两系统「哪个更有表现力」——ABX 比绝对打分更能反映「表现力差异」。
- **客观代理**：F0 统计（起伏幅度）、语速（时长）、能量动态范围——用声学统计辅助验证「风格差异确实存在」。
- **数据**：风格标注贵——用**多参考 + 弱标注**（每句标注情绪类别，不标强度）降低标注成本；或从「自然对话」里自动聚类风格。

**公式解析：风格强度的客观代理。**

$$
\Delta_{\text{style}} = \text{std}(\text{F0}_{\text{合成}}) - \text{std}(\text{F0}_{\text{基线}})
$$

- **第一步，看 F0 起伏**：$\text{std}(\text{F0})$ 是基频的标准差——「语调起伏多大」。高兴时 F0 起伏大、平淡时小。
- **第二步，看相对变化**：$\Delta_{\text{style}}$ 是「风格化合成」相对「平淡基线」的起伏增量——**增量 > 0 说明风格强度确实加了**。
- **第三步，看多指标**：F0 起伏 + 语速 + 能量动态三者的相对变化，共同刻画「风格差异的方向」。
- **第四步，看局限**：声学统计是「风格的表征」，不是「风格的质量」——**客观代理确认「变了」，主观 MOS 确认「变好/变对」**。

**核心要点：风格合成评测 = 「多维 MOS + ABX 偏好 + 声学统计代理」的组合。** 缺了「情感正确性」维度，一个「自然但情绪全错」的系统会被误判为优秀。

## 6 小结

- 情感/风格落在 **F0、语速、能量、嗓音质量** 四个声学坐标上，显式建模它们是可控制的基础。
- **显式标签控制**用情感条件 + 强度旋钮，可解释但粗；条件要注入 F0/时长预测模块。
- **参考式控制（GST）**从参考语音提取风格、以 token 组合表达，细但依赖参考、存在内容纠缠。
- 演进方向是「显式 → 参考 → 大模型隐式」，风格从「模块」变成「上下文」。
- 「自然」与「可控」的平衡在时间分辨率——逐片段风格是前沿。

**附：关键概念速记**

- **情感/风格在声学坐标上**：F0（音高起伏）、语速、能量、嗓音质量——四个旋钮。
- **显式标签控制**：情感条件 + 强度标量——可解释但「粗」（一个标签一种「平均」情绪）。
- **参考式控制（GST）**：参考音频 → 风格嵌入 → token 加权组合——细但依赖参考。
- **情感条件要注入韵律模块**：F0/时长预测器——不只频谱层。
- **音色与风格解耦**：说话人条件管「谁在说」，情感条件管「怎么说」。
- **风格—内容纠缠**：参考风格与参考内容耦合——「学风格却带进内容」。
- **时间分辨率**：真实情感动态演化，整句一个标签太粗——逐片段风格是前沿。
- **演进**：显式标签 → 参考提取 → 大模型隐式（风格成为上下文推理副产品）。

**延伸思考**：情感合成的「粗与细」之争，本质是「标签的信息量」问题——**离散标签（高兴）信息量低，连续参考（一段高兴的语音）信息量高，大模型上下文信息量最高**。这揭示了「可控性」与「信息量」的正相关与悖论：**给的信息越多，越自然；给的信息越少，越可控**。GST 的 token 组合试图两全——「少而可解释的 token，组合出丰富的风格」。找到「信息量与可控性的最优平衡」，是风格合成的核心课题。
