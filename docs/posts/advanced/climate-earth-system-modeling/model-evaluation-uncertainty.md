## 为什么从评估开始

造了模式、跑完实验、汇入 CMIP、降尺度到区域——最后一道工序是**质检**：这台模式到底有多可信？它的每个结论应该挂上多大的问号？这就是**模式评估（model evaluation）**与**不确定度（uncertainty）**的战场。评估不是「过不过关」的二元判断，而是**给模式的每类输出建立一份信用档案**：它在海温上可信、在云上可疑，在气候均值上稳、在极端事件上虚。<span class="marginnote">本专题到这里形成了一个完整闭环：谱系→部件→耦合→漂移→实验→CMIP→降尺度→评估。评估既是终点质检，也是下一轮模式发展的起点——好模式是在评估与改进的循环里长出来的。</span>

评估还有一个与方法同样重要的面向：**它是一件社会性活动**。模式评估结果进入 IPCC 报告、影响政策判断，因此评估标准必须透明、可复现、可质疑。这也是为什么 CMIP 公开档案、诊断工具包与评估协议被如此郑重对待——评估的可信度，最终来自社区的共同监督，而非任何单个研究者的「打分」。

## 1 验证、检验与评估：三个词的层次

Goosse 把模式评价拆成三个层次，先厘清概念：

**验证（verification）**：检查**数值求解是否正确**——方程有没有解对、能量是否守恒、代码有没有 bug。它回答「模式是否忠实地执行了自己宣称的物理」。**检验（testing）**：在受控情形下检查模式行为是否符合预期——理想化实验、单柱模式对标、能量守恒监测。**验证与评估（validation/evaluation）**：把模式输出**与观测比较**，回答「模式是否再现了真实世界的特征」。<span class="marginnote">一个常被引用的区分：验证问「我们是否把方程造对了」（Did we build the equations right?），评估问「我们是否造了正确的方程」（Did we build the right equations?）。前者是数学与数值问题，后者是物理与科学问题。</span>

三个层次缺一不可：一个能通过验证（数值精确）却评估很差（气候态失真）的模式，说明物理或参数化错了；一个评估很好却验证失败的模式，说明好结果可能来自幸运的误差抵消——后者尤其危险。

## 2 评估指标：怎么给模式打分

**评估指标（performance metric）**：把模式与观测的差距压缩成一个数的统计量。最常用的几类：

**均方根误差（RMSE）**：逐格点（或逐时次）比较模式与观测的偏差，平方、平均、开方。RMSE 对大量级误差敏感，是气候场的标配指标。**空间相关**：模式场的空间分布与观测场的相关——衡量「形状」对不对，对绝对大小不敏感。**泰勒图（Taylor diagram）**：把模式场的**空间相关、标准差比、RMSE**三者在同一张图上画出——一眼看出一台模式在哪类场上强、在哪类场上弱。<span class="marginnote">泰勒图是模式评估的「体检报告」：横轴纵轴标标准差之比，弧线标相关，距离原点越近越好。读图要诀：相关高但标准差比偏离 1，说明「位置对但幅度错」；相关低则「结构都错了」。</span>

**过程导向评估（process-oriented evaluation）**：不只是对输出场打分，而是检查**关键物理过程**是否被正确再现——如 ENSO 的周期与振幅、云对季节循环的响应、土壤湿度对降水的记忆。过程对了，外推未来才可信；只对气候均值，可能只是误差抵消的产物。

**基准试验（benchmark）**：如 DECK 里的 `piControl` 与 `historical`——前者检验模式平衡态与内部变率，后者检验对历史强迫的响应。模式评估社区还维护标准数据集（如 CMIP 诊断包），让评估自动化、可比较。

## 3 不确定度的四个来源

一个气候预测的不确定度，可分解为四类来源，它们的相对大小随预报提前期变化：

**内部变率（internal variability）**：气候系统自身的随机涨落（ENSO、北大西洋涛动、十年际振荡）。同一强迫下，不同初值跑出不同路径。**模式不确定度（model uncertainty）**：不同模式对同一强迫给出不同响应——来自结构差异与参数差异。**情景不确定度（scenario uncertainty）**：未来排放路径本身不确定——SSP1-1.9 与 SSP5-8.5 的强迫差一个量级。**初始条件不确定度**：对季节—年际预报（S2S）与十年预报尤其重要；对长期气候预测，初始条件的影响随时间衰减。<span class="marginnote">一条著名的「不确定性曲线」：近几十年的预测，内部变率主导；几十年到百年尺度，情景不确定度上升为主导；而模式不确定度在中期占比可观。CMIP 模式集合的散布，混叠了内部变率与模式不确定度——用多初值集合（每个模式多跑几次）才能把它们拆开。</span>

**不可减小的部分**：内部变率本质不可预报（混沌），情景不确定度取决于人类社会选择——这两类无法靠改进模式消除；只有**模式不确定度**是科学努力可以压缩的。这正是评估与模式发展的意义所在。

四类不确定度还有一个实践上的分离技巧：靠**实验设计**把它们拆开。同一模式跑多初值集合，看到的是内部变率；同情景跑多模式，看到的是内部变率 + 模式不确定度；同一模式跑多情景，看到的是情景不确定度。把这几类实验交叉起来，就能把「预测区间」拆成可诊断的各成分——这正是 CMIP 强调「每模式多初值、每情景多模式」的原因，也是《初始漂移》里「站稳后做实验」的延续。

评估还有一个与「打分」同样重要的维度：**时空尺度依赖**。一台模式在月平均气候场上得分高，不代表它在极端事件、年代际变率或区域细节上同样可靠；在热带得分高，不代表高纬可信。因此现代评估体系要求**分尺度、分区域、分变量类型**给出能力画像——一份诚实的评估报告不是「这台模式 87 分」，而是一张「哪些量、哪些区域、哪些尺度可信，哪些存疑」的明细表。这种「画像式评估」正是 IPCC 判断证据强度时的底层方法。

## 4 公式解析：RMSE——把差距压成一个数

模式评估最常用的指标是均方根误差：

$$
\mathrm{RMSE} = \sqrt{\frac{1}{N}\sum_{i=1}^{N}\left(M_i - O_i\right)^2}
$$

逐项拆解：

- **第一步，看 $M_i$ 与 $O_i$**：第 $i$ 个格点（或时次）的模式值与观测值。评估的第一步是**配准**——网格对齐、单位统一、气候平均时段一致，任何配准错误都会污染指标。
- **第二步，看平方**：先求差再平方，两个作用——**消除符号**（正负偏差不互相抵消）与**惩罚大误差**（误差越大权重越大）。
- **第三步，看平均与开方**：对 $N$ 个点平均，再开方回到原量纲。开方让指标「回到物理单位」：一个温度场的 RMSE = 1.5 K，可以直接读出「模式与观测平均差约 1.5 K」。
- **第四步，看 RMSE 的盲区**：RMSE 是单个数，掩盖了误差的空间结构——热带偏差 2 K 与高纬偏差 2 K 有完全不同的物理含义。因此评估从不只用 RMSE 一个数，而是**RMSE + 空间相关 + 泰勒图 + 过程诊断**组合使用。

## 5 新前沿：涌现约束

评估的最新方向是寻找**涌现约束（emergent constraint）**：在模式集合里发现一条**当前气候的可观测量**与**未来预测量**之间的稳健统计关系，从而用观测去压缩未来的不确定度。经典例子：**高纬云对气溶胶的敏感度**、**北半球雪盖季节循环的振幅与未来变暖**、**云反馈与模式当前云辐射效应的关系**。<span class="marginnote">涌现约束的思路是「用现在约束未来」：如果模拟现在气候更准的模式，系统性地给出更窄的未来区间，那就该给它们更高的权重。它把评估从「事后打分」变成「事前加权」，是模式评估从描述走向预测的关键一步。</span>当然，涌现约束也需警惕——两条变量的相关可能只是巧合或共同受第三变量驱动，稳健性检验（不同模式集、不同时段）必不可少。

## 6 核心概念速查表

把模式评估与不确定度的术语对照列出：

| 术语 | 回答的问题 | 一句话本质 |
| --- | --- | --- |
| 验证（verification） | 方程解对了吗？ | 数值正确性、守恒、无 bug |
| 检验（testing） | 受控情形行为对吗？ | 理想化实验、单柱对标、能量守恒监测 |
| 评估（evaluation） | 模式再现真实了吗？ | 模式输出与观测比较 |
| RMSE | 差距多大？ | $\sqrt{\frac1N\sum(M_i-O_i)^2}$ |
| 空间相关 | 空间结构对吗？ | 模式场与观测场的空间相关系数 |
| 泰勒图 | 多指标一图看 | 相关+标准差比+RMSE 三合一 |
| 过程导向评估 | 过程对吗？ | 检查 ENSO、云、土壤湿度的物理过程 |
| 基准试验 | 有没有标准考卷？ | DECK 等标准实验 + 诊断数据集 |
| 内部变率 | 随机性有多大？ | ENSO、涛动等自身涨落 |
| 模式不确定度 | 模式间差多少？ | 结构/参数差异导致的响应分歧 |
| 情景不确定度 | 未来走哪条路？ | 排放路径本身不确定 |
| 涌现约束 | 现在能约束未来吗？ | 当前可观测量—未来预测量稳健关系 |

## 7 易错辨析

**辨析｜易错点 1：「模式对当前气候拟合得好，预测就可靠」**：拟合好是必要非充分条件——好的当前拟合可能来自误差抵消，也可能不反映模式的响应能力。**评估的核心是「过程对」，而不只是「输出像」**；这正是过程导向评估存在的理由。

**辨析｜易错点 2：「RMSE 越小模式越好」**：RMSE 掩盖误差的空间/时间结构，且对极端值敏感。一个在热带和高纬各偏 2 K 的模式，与一个只在某盆地偏 2 K 的模式 RMSE 可能相同，物理含义却完全不同。**单指标排名是评估的陷阱**。

**辨析｜易错点 3：「内部变率能被更好的模式消除」**：内部变率来自系统的混沌本质，**无法靠改进模式消除**，只能靠多初值集合来刻画。区分「内部变率」与「模式不确定度」必须用多初值 × 多模式的双重集合——单集合会混叠两者。

**辨析｜易错点 4：「涌现约束找到了就能用」**：涌现约束可能只是巧合或共同受第三变量驱动。可靠的使用要求**跨模式集、跨时段稳健**，且给出可检验的物理机制。**相关 ≠ 因果**，是涌现约束最需要警惕的陷阱。

## 8 数值案例：手算一次 RMSE

用三个格点的温度场演示 RMSE 的「惩罚大误差」特性。设观测为 $[14,\ 15,\ 16]$°C：

- 模式 A：$[13,\ 16,\ 15]$°C，偏差 $[-1,+1,-1]$，RMSE$=\sqrt{(1+1+1)/3}\approx1.0$ K。
- 模式 B：$[13,\ 15,\ 15]$°C，偏差 $[-1,0,-1]$，RMSE$\approx0.82$ K——平均误差更小，确实更好。
- 模式 C：$[11,\ 15,\ 17]$°C，平均偏差为 0，但 RMSE$=\sqrt{(9+0+1)/3}\approx1.8$ K——**平均偏差为零却得分最差**，因为它把 2 K 的误差集中在一个点。RMSE 惩罚大误差的特性，让「平均不错」的伪装无所遁形。

这个例子还暴露 RMSE 的另一面：它对**误差的空间位置不敏感**。模式 C 与模式 A 的 RMSE 反映的都是误差量级，却都看不出「偏差集中在哪个区域」——而热带 2 K 与高纬 2 K 的物理含义完全不同。

这正是为什么评估必须配空间相关与泰勒图：前者补上「结构对不对」，后者把相关、变率比与 RMSE 压进同一张图。**评估工具箱存在的意义，就是让「一个数」无法替「一幅画像」说话**——任何把模式质量压成单分值的做法，都是在丢弃空间结构信息。

## 9 小结

- 评估三层次：**验证**（方程解对了吗）、**检验**（受控行为对吗）、**评估**（模式再现真实了吗）。
- 指标用组合：**RMSE + 空间相关 + 泰勒图 + 过程导向评估**，单指标排名是陷阱。
- 不确定度四来源：**内部变率、模式不确定度、情景不确定度、初始条件**；只有模式不确定度可被科学压缩。
- **过程导向评估**看关键物理过程是否被再现，胜过只看输出像不像。
- **涌现约束**用「现在约束未来」，把评估从事后打分变成事前加权。
- **验证与评估之别**：验证问「方程造对了吗」，评估问「造对方程了吗」——前者数值、后者物理。
- **画像式评估**：评估不是单分，而是「哪些量、哪些区域、哪些尺度可信，哪些存疑」的明细表。
