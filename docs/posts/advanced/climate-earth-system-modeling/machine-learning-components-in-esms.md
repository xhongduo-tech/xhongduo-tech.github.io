## 为什么从机器学习组件开始

前面十三篇描述的是一个「纯物理」的世界：所有过程要么被解析求解，要么被参数化。但参数化——那些用可解变量估计次网格过程的经验公式——恰恰是前几篇反复遇到的最大不确定来源（云反馈、对流、混合）。**机器学习（ML）的闯入，就是为这些「公式写不出来、数据却很多」的过程提供第三条路**：不写公式，直接从高分辨率模拟或观测中学习映射。这一篇回答三个问题：ML 在地球系统模式里扮演哪几种角色、能补什么不能补什么、以及为什么说它是「最后一个组件」而非「万能钥匙」。<span class="marginnote">本篇把「从极限到大模型」的主线接回气候科学：地球系统模式本身，正在成为大模型与科学计算交会的试验场。理解它，也是理解整个网站主线如何延伸到物理世界。</span>

把 ML 放进 ESM，先要回答一个哲学问题：**数据驱动的方法凭什么能被信任去外推未来气候？** 物理模式的可信来自方程本身的普适性——方程在任何状态都成立；ML 的可信则来自训练数据覆盖的范围。气候预测恰恰要求模型在「没见过的未来」里工作。理解这个张力，才能理解后文为什么 ML 组件的嵌入总在「物理约束」与「数据容量」之间寻找平衡。

另一个背景是「数据从哪里来」：学习式参数化的训练数据来自云解析模式，仿真代理的数据来自 ESM 自己，偏差校正的数据来自观测——**数据源不同，ML 组件的可信边界就不同**。读本篇时请随身携带这个「数据源→边界」的映射：它决定了每一种 ML 组件能回答什么问题、不能回答什么问题。

## 1 三个角色：替换、仿真、校正

ML 在 ESM 里的应用可以归成三大类：

**学习式参数化（learned parameterization）**：训练一个神经网络，让它**替代某个次网格参数化方案**。训练数据来自**云解析模式（storm-resolving）或大涡模拟（LES）**——这些高分辨率模式把云与对流显式算出来，代价是贵到无法全球长跑，但可以作为「虚拟观测」供 ML 学习。学好后，把网络嵌入 GCM，替换原参数化。**目标是把「贵的高分辨物理」压进「便宜的神经网络」里**。<span class="marginnote">这是最「深入」的角色：它不是给模式加个后处理，而是替换模式内部的物理模块。社区里一个标志性进展是 2022 年用云解析数据训练的神经网络对流参数化成功跑起长期气候模拟——但它也暴露出稳定性难题（见下文）。</span>

**仿真代理（emulation / surrogate）**：训练一个模型**模拟 ESM 本身**的输入—输出关系，用于需要大量重复跑模式的场景——多情景扫描、参数优化、快速评估。这类「模式替身」可以把一次 ESM 实验从数十万核时压缩到秒级，代价是只在你训练过的范围里可信。

**偏差校正与降尺度后处理**：用 ML 学习模式偏差的统计规律，直接校正模式输出；或学习大尺度到局地的映射，做统计降尺度（见《降尺度》一篇）——这是门槛最低、落地最快的一类。

三类角色的「成熟度」也各不相同：偏差校正与降尺度已进入业务应用；仿真代理在多情景扫描里快速铺开，但只在你训练过的状态范围里可信；学习式参数化最具颠覆性，也最难站稳——它把最不确定的次网格物理交给一个黑箱，评估与稳定性的压力全部压在这一类上。

## 2 混合建模：物理在前，ML 补缝

最稳健的嵌入方式是**混合建模（hybrid modeling）**：不把物理扔给 ML，而是让 **ML 只负责「物理公式没写全」的那部分**——用神经网络学习参数化误差的残差，把它作为校正项加到物理趋势上。这样做的好处是：**已知的守恒律、波动、平流仍由物理求解器保证**，ML 只补那些次网格的净效应，系统的稳定性与可解释性都大幅提升。<span class="marginnote">混合建模的哲学是「各干各的强项」：物理求解器擅长确定性、守恒与泛化，神经网络擅长拟合复杂非线性映射。把 NN 塞进物理趋势的残差里，比让 NN 独挑大梁更容易守住数值底线。</span>

训练时最常用的监督信号是**残差目标**：用高分辨率模式算出的总趋势，减去粗分辨率模式物理求解器算出的趋势，差值（即参数化应贡献的部分）就是网络的训练目标。更前沿的做法是**可微（differentiable）训练**：让梯度穿过整个模式，直接优化长期气候统计量（如海温的均方根误差），而非单步趋势——这让网络学会的不是「单步像」，而是「气候态准」。

## 3 公式解析：混合模型的趋势方程

把「物理 + ML 校正」写成一条方程，就是混合建模的内核：

$$
\frac{\mathrm{d}X}{\mathrm{d}t} = \underbrace{F_{phys}(X)}_{\text{已知物理}} + \underbrace{\mathrm{NN}(X; \theta)}_{\text{学习到的补丁}}
$$

逐项拆解：

- **第一步，看 $X$**：模式状态向量——风、温、湿、化学物种等在网格点上的集合。ML 组件与物理求解器处理的是**同一个 $X$**，只是计算方式不同。
- **第二步，看 $F_{phys}(X)$**：由物理求解器给出的趋势——平流、气压梯度、科里奥利力、已解析的波动。它保证方程组的基本动力学与守恒性质不被破坏。
- **第三步，看 $\mathrm{NN}(X; \theta)$**：神经网络给出的趋势，$\theta$ 是训练得到的权重。它学的是「次网格过程的净效应」——对流的加热与水汽输送、湍流混合、云辐射的反馈。
- **第四步，看训练目标**：残差监督时，用 $\mathrm{d}X/\mathrm{d}t \big|_{HR} - F_{phys}(X)$ 作标签——高分辨模式的总趋势减去物理求解器趋势，正好是参数化应贡献的部分。**训练好之后，这个网络就在 GCM 的每个格点、每个时间步上实时计算**，替代原参数化。

## 4 四条红线：稳定、守恒、泛化、可解释

ML 组件入 ESM 并非畅通无阻，四条红线决定了它能不能真正上岗：

**数值稳定性**：神经网络是强非线性函数，训练好的网络在训练分布内很好，可一旦状态漂出训练范围，输出可能失控，在长期积分中放大成**数值爆炸**。社区对稳定性有专门对策：输入限幅、加守恒投影、训练时注入噪声、显式约束输出范围。<span class="marginnote">一个生动的教训：早期 ML 对流参数化往往在几千个时间步内「炸掉」，因为训练数据（单步）与推理场景（循环数百万步）的分布漂移不一致。稳定性不是锦上添花，而是入场券。</span>

**守恒性**：物理模式精确守恒能量、质量与水。NN 的残差项天然破坏守恒——需要一个守恒修正层把 ML 趋势投影回守恒流形。**泛化性**：训练数据是「当前气候」的高分辨率模拟，而预测的是「温室气体翻倍」的未来——**训练分布之外的泛化是 ML 参数化最大的科学风险**。物理参数化虽糙，但对 $CO_2$ 加倍仍能给出合理响应；ML 则可能把未来状态当作「没见过的新世界」乱猜。**可解释与信任**：科学用户需要理解「为什么这个模式这么响应」——ML 模块必须配套可解释性工具与严格的评估（接上一篇的评估框架），才能赢得模式评估社区的信任。<span class="marginnote">泛化问题直接呼应统计降尺度的「平稳性假设」：两者都假设「学到的关系在未来成立」。ML 参数化试图用「把物理学进去」来缓解这一点，但严格地说，它只是把假设从「显式」变成了「隐式」。</span>

## 5 评估 ML 组件：沿用上一把尺子

ML 组件上线后，评估不能只看「离线误差」——它在训练数据上拟合多好，与它在长期耦合积分里表现多好，是两件事。社区的标准做法是分两层验证：**离线（offline）**评估单步或短期预测的误差与物理一致性（如输出是否落在物理合理范围）；**在线（online）**评估把 ML 组件装回 ESM 跑长期积分，检查气候态、变率与守恒是否被破坏。<span class="marginnote">「离线好、在线炸」是 ML 参数化的经典翻车模式——单步拟合再好，循环数百万步后误差也会在非线性系统里放大。因此<strong>在线评估是 ML 组件上岗的必经关卡</strong>，这与前一篇「评估模式」的框架完全同构。</span>

从「从极限到大模型」的主线看，ML 气候组件还有一层方法论意味：它演示了「物理先验 + 数据学习」的合流——不是用数据取代物理，而是用数据填补物理公式的空白。这与大模型时代「把世界知识压缩进权重」不同：气候模式必须保留守恒律与可解释性，因此 ML 在这里是「补丁」而非「替代」。理解这套「以物理为主、以 ML 补缝」的架构原则，也就能理解为什么气候 ML 社区的共识是把**可解释、守恒、在线稳定**当作第一性要求——它们在气候之外的许多科学计算里同样成立。

## 6 核心概念速查表

把 ML 组件的角色与关键概念对照列出：

| 术语 | 回答的问题 | 一句话本质 |
| --- | --- | --- |
| 学习式参数化 | 次网格过程能学吗？ | 用神经网络替换某个参数化方案 |
| 仿真代理 | 昂贵模式能替身吗？ | 学习 ESM 输入—输出，秒级复跑 |
| 偏差校正 | 模式偏差能学吗？ | 学习偏差规律，直接校正输出 |
| 混合建模 | 物理和 ML 怎么搭？ | 物理解已知部分，ML 补残差 |
| 残差训练 | 网络学什么目标？ | 高分辨趋势 − 物理求解器趋势 |
| 可微训练 | 怎么学长期气候态？ | 梯度穿过模式，优化气候统计量 |
| 数值稳定性 | 为什么几千步就炸？ | 训练分布与推理循环分布漂移 |
| 守恒投影 | 守恒被破坏怎么办？ | 把 ML 趋势投影回守恒流形 |
| 泛化 | 未来气候能信吗？ | 训练分布之外的外推能力 |
| 离线/在线评估 | 怎么验证上岗？ | 单步误差 vs 长期积分稳定性 |

## 7 易错辨析

**辨析｜易错点 1：「ML 参数化训练得好就一定能长期跑」**：单步损失降到极小，不代表循环数百万步不炸——推理时的状态会漂出训练分布，误差在非线性系统里指数放大。**在线稳定性是独立于离线精度的入场券**。

**辨析｜易错点 2：「ML 能学守恒律，不用写方程」**：神经网络默认不守恒——它拟合的是输入输出关系，能量、质量守恒需要**显式施加**（守恒投影、限幅、结构约束）。声称「让网络自己学守恒」目前只是理想，不是可交付的物理保障。

**辨析｜易错点 3：「ML 组件会取代物理模式」**：当前的主流不是取代，而是**增强**——物理求解器继续保证守恒、波动与可解释性，ML 只补参数化残差。全数据驱动的「模式」（如 GraphCast）在短期预报上亮眼，但对百年气候的外推与物理解释仍存疑。

**辨析｜易错点 4：「训练数据越多，泛化越好」**：对气候预测，训练数据是「当前/历史气候的高分辨模拟」，而目标是温室气体加倍后的未来。**分布外（out-of-distribution）泛化不能靠加数据解决**——把物理约束与不确定性量化织进模型，比单纯堆数据更本质。

**辨析｜易错点 5：「ML 组件能完全替代评估流程」**：ML 组件只是把「参数化不确定性」换成了「学习与泛化不确定性」，评估环节不但不能省，反而更复杂——它要同时检验离线精度、在线稳定性、守恒性与分布外泛化。**ML 没有让评估变简单，只是让评估换了一套问题**。

## 8 数值案例：残差到底学走了什么

用一组示意数字演示混合建模的残差目标。设粗网格模式在一个时间步里：

- 物理求解器给温度趋势 $F_{phys}=+1.5$ K/天（辐射冷却与平流之和）。
- 高分辨率参考（如云解析模式）给同一状态的总趋势 $+2.3$ K/天。
- 残差 $+0.8$ K/天，就是参数化应贡献的部分——对流潜热释放的加热。

训练时神经网络以 $+0.8$ K/天为标签去拟合；上线后它每步给物理趋势补上这 $+0.8$ K/天。**注意：网络学的是「总趋势 − 物理趋势」的差，而不是总趋势本身**——这样物理求解器仍在主导平流与守恒，网络只负责补缝。

这个分工也说明了泛化风险的落点：若未来对流行为改变，网络必须在训练分布之外给出合理的残差。**物理约束与保守设计，比单步拟合精度更能决定它的上限**——这也是可微训练与守恒投影在社区里被反复强调的原因。

## 9 小结

- ML 在 ESM 里扮三类角色：**学习式参数化**（替换内部物理模块）、**仿真代理**（替身，快速跑大量实验）、**偏差校正/降尺度**（后处理）。
- **混合建模**让 ML 只补物理公式的残差，物理求解器守住守恒与波动——是目前最稳健的嵌入方式。
- 混合模型的趋势方程 $\frac{\mathrm{d}X}{\mathrm{d}t} = F_{phys}(X) + \mathrm{NN}(X;\theta)$ 让 ML 只补物理公式的残差，物理求解器守住守恒与波动。
- 四条红线决定 ML 组件能否上岗：**稳定、守恒、泛化、可解释**；在线评估是入场券。
- 数据源决定可信边界：云解析模拟学参数化、ESM 自产数据学代理、观测学偏差校正。
- 离线误差小不等于在线能跑：循环数百万步后的分布漂移，让「离线好、在线炸」成为经典翻车模式。

在下一节，我们将离开这台整机，回看走过的全部路程——从 EBM 到 ESM、从单模式到 CMIP 集合、再到今天的 ML 组件。「以物理为主、以学习补缝」既是本专题的最后一课，也把「从极限到大模型」的主线接回了气候科学。
