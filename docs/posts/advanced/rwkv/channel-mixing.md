## 为什么从通道混合开始

时间混合解决了"沿时间方向混合信息"，但一个 token 表示内部的不同**通道**（维度）之间，也需要被非线性地重新组合——这正是前馈网络（FFN）在 Transformer 里的角色。RWKV 的**通道混合（Channel Mixing）**就是它的 FFN，负责在通道维上做"特征变换"。它看起来是时间混合的"表亲"：同样的 Time Shift、同样的 Receptance 门控，但激活函数换成了 **Squared ReLU**（平方 ReLU），并且值投影被挪到了激活之后。<span class="marginnote">Transformer 残差块是「多头注意力 + FFN」交替，两者都作用于同一个 token 表示。RWKV 与之对仗：时间混合（对应注意力，混合时间方向）+ 通道混合（对应 FFN，混合通道方向）。「时间」与「通道」两个维度被分开处理，正是架构名 Time/Channel Mixing 的由来。</span>

## 1 前馈网络的职责：逐位置的特征重组合

Transformer 里，注意力负责"token 之间"的信息交换，FFN 负责"token 内部"的表示变换。FFN 的形式是

$$
\mathrm{FFN}(x) = W_2\, \sigma(W_1 x + b_1) + b_2
$$

它先把维度从 $C$ 扩到 $4C$（激活），再压回 $C$。为什么需要它？注意力本质是**加权求和**，线性组合不会改变特征的"形状"——如果没有 FFN，多层注意力堆叠起来仍然只是浅层的线性变换。FFN 提供了**逐位置的、非线性**的通道重组合，让模型在每个 token 处有能力"重新理解"自己携带的信息。实验早已证明，Transformer 里 FFN 的参数与作用都举足轻重。

通道混合要完成的就是这个职责，但它在两个细节上偏离了标准 FFN：**输入先做 Time Shift**（把上一时刻的表示也带进来），**激活用平方 ReLU**。

FFN 的"先扩维再压缩"结构也是有讲究的：$4C$ 的中间宽度给每个位置足够的"工作空间"去组合特征，再压回 $C$ 与残差流汇合。通道混合保留了这一结构骨架，只是把"激活 + 投影"的次序、以及门控的方式重新设计了一遍——骨架还是那个骨架，零件换成了 RWKV 的零件。

## 2 公式解析：通道混合的计算链

通道混合的完整计算如下（记号与时间混合一致，$x_t$ 为当前 token 表示）：

$$
\begin{aligned}
\mathbf r_t &= W_r\,(\mu_r \odot x_t + (1-\mu_r)\odot x_{t-1}) \\
\mathbf k_t &= W_k\,(\mu_k \odot x_t + (1-\mu_k)\odot x_{t-1}) \\
\mathbf x'_t &= \sigma(\mathbf r_t) \odot \big(W_v \cdot \max(\mathbf k_t, 0)^2\big)
\end{aligned}
$$

**四步拆解：**

- **第一步，移位**：与时间混合相同，$\mu \odot x_t + (1-\mu)\odot x_{t-1}$。这里的移位让 FFN 也能"看见"上一时刻——也就是说，连特征变换都带上了时间记忆。
- **第二步，两组投影**：$r_t$（接受度门控）与 $k_t$（被激活的对象）。这里**只有两组**投影，没有值投影——因为"值"不再来自输入，而是来自对 $k_t$ 做非线性变换的结果。
- **第三步，平方 ReLU**：$\max(k_t, 0)^2$ 逐元素取"先夹到非负，再平方"。这是通道混合与前馈网络最本质的区别（见下节）。
- **第四步，门控 + 输出投影**：$\sigma(r_t)$ 逐元素缩放激活结果，再由 $W_v$ 投影回输出维度 $x'_t$。注意 $W_v$ 作用在**激活之后**，这与时间混合（$v$ 在 WKV 之前投影）的次序恰好相反。

## 3 为什么用平方 ReLU

标准 FFN 用 GELU 或 ReLU；RWKV 的通道混合选择 **Squared ReLU**：$\max(x, 0)^2$。这个选择来自 Primer 的工作——Primer 论文（So et al.，2021）发现，把 FFN 的激活从 GELU 换成平方 ReLU，可以在几乎不增加参数的情况下显著提升训练效率。<span class="marginnote">Primer（"Primer: Searching for Efficient Transformers for Language Modeling"）用进化搜索找到了若干"建筑砖块"，Squared ReLU 是其中最出名的：它只用一行代码改动，就在多任务上带来稳定的收益。RWKV 吸收了这一发现。</span>

平方 ReLU 相比 ReLU 好在哪？可以从两点看：

**更强的非线性**：$x^2$ 是凸函数，在正半轴上把大的激活放大得更快（$x^2$ 在 $x>1$ 时增长快于 $x$），给特征变换更强的"区分度"。
- **导数的连续性**：$x^2$ 的导数 $2x$ 在 $x=0$ 处连续，而 ReLU 的导数在 0 处是跳变的。连续导数让梯度在 0 附近更平稳，训练更稳定。

一句话：**平方 ReLU = 便宜、稳定、更强的非线性**，是 RWKV 在"无注意力"架构里压缩表达损失的一个实用杠杆。

从实现角度看，平方 ReLU 还带来工程上的便利：它不需要像 GELU 那样调 erf 近似，也不像 SiLU 那样先算 sigmoid 再相乘，一行 `square(relu(x))` 就完成，数值行为完全可预测。在大规模训练里，这种"少一个分支、少一次近似"的确定性，本身就是稳定性收益。

平方 ReLU 对**负值**的处理也值得留意：$\max(x,0)^2$ 在 $x < 0$ 时输出恒为 0（与 ReLU 相同的稀疏激活），但正半轴的二次增长赋予了它 ReLU 没有的"梯度放大"——$x=2$ 处的导数是 $x=1$ 处导数的两倍，越强的激活梯度越陡，模型更容易放大已经强烈的特征。

## 4 时间混合与通道混合的配合

一个 RWKV 残差块里，两个模块各司其职，交替堆叠：

| | 时间混合 Time Mixing | 通道混合 Channel Mixing |
| --- | --- | --- |
| 对应 Transformer | 多头自注意力 | 前馈网络 FFN |
| 混合的方向 | 时间（token 之间） | 通道（特征内部） |
| 投影 | $r, k, v$ 三组 | $r, k$ 两组 + 输出 $W_v$ |
| 聚合方式 | WKV 加权求和 | 无聚合（逐位置） |
| 激活函数 | 无（sigmoid 只做门控） | Squared ReLU |
| 复杂度 | $O(T C^2)$（线性于 $T$） | $O(T C^2)$（逐 token） |

两个模块**共享同一套设计语言**：都先 Time Shift，再用 $r$ 门控输出。这并非巧合——统一的模式让实现与调参都更简单，也让梯度在深层的传播更规整。由于两个模块都是"逐 token 计算 + 常数状态"，整个 RWKV 块的推理代价与序列长度无关。<span class="marginnote">注意通道混合没有跨 token 的聚合——它是逐位置计算的，复杂度本就 $O(T)$。真正让 RWKV 成为「线性注意力」的是时间混合里的 WKV；通道混合的作用是补足通道维的表达能力。两者缺一不可。</span>

这个分工也解释了为什么两个模块能共用同一套初始化策略：它们都只是"线性投影 + 门控 + 激活"的堆叠，没有注意力那种位置相关的特殊结构，对初始化的敏感性更低——这是 RWKV 在大规模训练里好调参的一个隐藏优点。再补一个量级直觉：Transformer 里 FFN 通常占模型参数的三分之二左右；RWKV 的通道混合同样承载了大部分可训练参数。**决定模型"聪明程度"的，很多时候不是注意力机制本身，而是这些逐位置的非线性变换。**

### 一个具体的数值例子

用一个二维的小例子把整个链条走一遍，感受每个部件在做什么。设 $x_t = (1, 0)$，$x_{t-1} = (0, 1)$，$\mu_k = (0.5, 0.5)$：

1. **移位**：$\mu_k \odot x_t + (1-\mu_k) \odot x_{t-1} = (0.5, 0.5) + (0, 0.5) = (0.5, 1)$——两个时刻的信息各取一半。
2. **投影（设 $W_k$ 为单位阵）**：$k_t = (0.5, 1)$。
3. **平方 ReLU**：$\max(k_t, 0)^2 = (0.25, 1)$——注意第一个分量从 $0.5$ 缩到 $0.25$，第二个分量不变；这就是 $x^2$ 的"非线性重排"：小于 1 的激活被压低，大于 1 的（若存在）会被放大。
4. **门控（设 $\sigma(r_t) = (0.9, 0.1)$）**：逐元素相乘得 $(0.225, 0.1)$——模型通过 $r$ 决定"这条通道的信息要不要放行"。
5. **输出投影 $W_v$**：把上面的结果线性重组合，送回残差流。

这个例子说明通道混合的每一步都不是多余的：移位带来时间视角，平方 ReLU 做非线性重排，门控做选择性放行，$W_v$ 做通道间混合。**四个环节缺一，表达力都会打折。**

### 易错点辨析：$W_v$ 的位置不能记反

**辨析｜易错点：** 通道混合里 $W_v$ 作用在**激活之后**（$W_v \cdot \max(k,0)^2$），而时间混合里 $v$ 投影在**聚合之前**。这个次序差异常被记混，但它是结构性的：

- 时间混合需要 $v$ 参与 WKV 的**加权求和**，所以 $v$ 必须在求和前投影好——"内容先定型，再进混合池"。
- 通道混合没有求和，只有"激活 + 投影"，$W_v$ 放在激活后等价于"把非线性变换的结果再线性重组合"，表达力更强。

如果把 $W_v$ 提前到激活前，$W_v \cdot \max(k,0)^2$ 就变成了 $\max(W_v k, 0)^2$ 之类（若还保持平方在外），会改变可学习函数类。**次序是设计的一部分，不是实现细节。**

## 5 小结

- 通道混合是 RWKV 的 **FFN**，负责逐位置的非线性通道重组合。
- 它与时间混合共享设计：**Time Shift 输入 + Receptance 门控输出**。
- 激活函数用 **Squared ReLU**：$\max(x, 0)^2$，来自 Primer，比 ReLU 更"有区分度"、导数更平稳。
- 次序细节：$W_v$ 作用在激活**之后**（时间混合中 $v$ 在聚合之前投影）。
- 两个混合模块交替堆叠，都是逐 token 计算，共同保证推理代价与序列长度无关。
- 通道混合的职责是"通道维的表达"，时间混合的职责是"时间维的聚合"，二者互补、缺一不可。
- 平方 ReLU 的稀疏负半轴 + 二次正半轴，让它同时具备 ReLU 的稀疏性与更强的梯度放大。
- 与时间混合共享"移位 + 门控"设计语言，可复用同一套初始化与调参策略。
- 数值例子：$k=(0.5, 1)$ 经平方 ReLU 变 $(0.25, 1)$——小于 1 的激活被压低，这正是二次函数的特性。
- 次序记忆法：时间混合"先投影再聚合"（$v$ 在 WKV 前），通道混合"先激活再投影"（$W_v$ 在平方后）——两个次序互为镜像。

在下一节，我们终于要正面解剖整个 RWKV 的心脏：**WKV 算子与并行训练**——闭式求和怎么写成递推、递推又怎么在训练时并行化。
