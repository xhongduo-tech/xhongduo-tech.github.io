## 为什么从 WKV 算子开始

前四篇铺垫了一条线：线性注意力 → 时间混合 → 通道混合，RWKV 的每个模块都围绕同一个核心——**WKV 算子**。它同时是注意力机制的替代品（第 2 篇）、时间混合的核心计算（第 3 篇）、以及"训练像 Transformer、推理像 RNN"这句话的物理载体（第 1 篇）。本篇正面解剖这个算子：闭式求和长什么样、怎么改写成 O(1) 的递推、递推又怎么在训练时并行化。理解 WKV，就等于理解了 RWKV 全部的"魔法"来源。<span class="marginnote">WKV 三个字母对应 Weight（权重/衰减）、Key（键）、Value（值）——它是"对值做带权求和"，权重由键与可训练的时间衰减共同决定。这个名字暗示了它的血统：注意力家族（Q/K/V）的一员，只是没有了 Query。</span>

## 1 WKV 算子的定义

设第 $t$ 个 token 经过投影得到键 $k_t$ 与值 $v_t$（都是 $C$ 维向量）。WKV 算子输出一个 $C$ 维向量 $\mathrm{wkv}_t$，定义为对所有历史位置**归一化、带指数衰减的加权求和**：

$$
\mathrm{wkv}_t =
\frac{\displaystyle\sum_{i=1}^{t-1} e^{-(t-1-i)\,w + k_i} \odot v_i + e^{u + k_t} \odot v_t}
{\displaystyle\sum_{i=1}^{t-1} e^{-(t-1-i)\,w + k_i} + e^{u + k_t}}
$$

其中：

- $w \in \mathbb{R}^{C}$：**逐通道**的可训练时间衰减向量，$e^{-(t-1-i)w}$ 表示位置 $i$ 的信息传到位置 $t$ 时被衰减了多少（逐元素指数）。
- $u \in \mathbb{R}^{C}$：可训练的"当前 token 奖励"向量，只作用于 $i = t$ 那一项。
- $k_i$ 在指数里出现，意味着**键被指数化**（实现中直接算 $\exp(k_i)$），它决定了"这个历史 token 值不值得被读取"。
- $\odot$ 为逐元素乘法，分子分母都是逐元素计算的，最后做逐元素除法。

把这条式子和 softmax 注意力对照：softmax 是"对分数矩阵做指数归一化"；WKV 是"对衰减指数与键指数求和再归一化"。**二者都是"对值做归一化加权求和"，区别只在权重的来源**——一个来自两两查询，一个来自"距离 × 键"。

从计算形态看，这个对照更尖锐：注意力是"先建 $T \times T$ 权重矩阵再乘 $V$"，WKV 是"把权重写成键指数 × 距离衰减的乘积形式，让求和可以被状态承接"。一个是"先建矩阵再求和"，一个是"边递推边求和"——后者的求和顺序可以被交换，这正是线性复杂度的来源。

更本质地看，WKV 把"注意力权重"从一张稠密的 $T \times T$ 矩阵，替换成了一张逐通道的"衰减 + 键指数"的隐式表——矩阵消失了，但"谁重要"的信息没有被丢弃，只是换了存储方式：前者存的是显式两两分数，后者存的是可训练的"距离折价率"。

## 2 公式解析：闭式如何读

逐项拆解这条闭式，四个要点：

- **第一项（过去）**：$\sum_{i=1}^{t-1} e^{-(t-1-i)w + k_i} \odot v_i$。位置 $i$ 的值 $v_i$ 权重为 $e^{k_i} \cdot e^{-(t-1-i)w}$——**内容分 $e^{k_i}$ × 距离分 $e^{-(t-1-i)w}$**。距离越远（$t-1-i$ 越大），衰减越强；$w$ 越大，衰减越快。
- **第二项（当前）**：$e^{u+k_t} \odot v_t$。当前 token 不经过距离衰减，而是用可训练向量 $u$ 单独"奖励"。这给模型自由：当前 token 对自己的贡献可以独立于历史衰减而调节（第 6 篇详述）。
- **分母**：与分子同构，但只累加权重、不含 $v$。它的存在使 $\mathrm{wkv}_t$ 成为**加权平均**（所有权重之和为 1 的归一化），避免输出尺度随序列增长而膨胀。
- **逐元素语义**：所有运算都是逐通道的。第 $c$ 个通道有自己独立的衰减 $w_c$、奖励 $u_c$、键指数 $e^{k_{i,c}}$——**每个通道是一个独立的小型"记忆系统"**。

这里有个容易看花眼的地方：$e^{u + k_t}$ 是标量 $u$ 广播到向量 $k_t$ 上逐元素相加，再逐元素取指数；$e^{-(t-1-i)w}$ 里的 $w$ 是向量。整条式子从头到尾都是逐元素运算，唯一的矩阵运算发生在投影层——这保证了 WKV 本身是"轻量"的逐元素算子，可以交给高度优化的逐元素 kernel。

## 3 推理模式：线性递推与 O(1) 状态

闭式要求对 $t$ 项求和，直接算仍是 $O(T)$ 每步。但 WKV 的关键性质是：**这个和可以增量维护**。定义两个状态向量 $a_t, b_t$：

$$
a_t = e^{-w} \odot a_{t-1} + e^{k_t} \odot v_t, \qquad b_t = e^{-w} \odot b_{t-1} + e^{k_t}, \qquad a_0 = b_0 = 0
$$

于是输出可以写作：

$$
\mathrm{wkv}_t = \frac{a_{t-1} + e^{u+k_t} \odot v_t}{b_{t-1} + e^{u+k_t}}
$$

**推理时只维护 $(a_t, b_t)$ 两个定长向量**，每来一个新 token，先算输出，再 O(1) 更新状态——不随序列长度增长，这就是 RNN 式的恒定记忆。$a_t$ 相当于"衰减累积的值"，$b_t$ 相当于"衰减累积的归一化系数"。<span class="marginnote">可以验证：展开递推，$a_{t-1} = \sum_{i=1}^{t-1} e^{-(t-1-i)w + k_i} \odot v_i$，正好是闭式里的历史项。递推与闭式是同一件事的两种写法——这就是第 2 篇讲的「先压缩历史成状态，再读状态」。</span>

注意这个除法是**逐元素**的（$\oslash$）：第 $c$ 个通道用自己的分子除以自己的分母，互不干扰。这保证了每个通道的归一化是独立完成的——有的通道可以保持很长的记忆（衰减慢、分母积累大），有的通道专注近期（衰减快、分母几乎等于当前项），各通道的"平均池"各归各的。

## 4 训练模式：并行扫描

推理时沿时间递推没问题；但**训练时序列是完整的，我们希望并行**。经典 RNN 做不到，因为递推里有 tanh 非线性；WKV 的递推里**只有线性运算**（乘衰减、加新项）——非线性（sigmoid 门控、平方 ReLU）全部在递推之外。线性递推满足**结合律**，因此可以用**并行扫描（associative scan）**把 $T$ 步串行摊平成 $O(\log T)$ 层并行。

并行扫描的思路：把递推的每一步看成"把旧状态变换到新状态"的仿射函数 $s \mapsto e^{-w} \odot s + x_t$。两个这样的变换可以**复合**成一个大变换，而复合是结合的——于是可以把 $T$ 个变换两两合并、层层归约，像二叉树一样在 $\log_2 T$ 轮内算出所有前缀状态。<span class="marginnote">并行扫描（parallel scan / Blelloch scan）是 GPU 编程的经典算法，也是 S4、Mamba 等状态空间模型能并行训练的同款数学。RWKV 与它们殊途同归：线性递推 → 结合律 → 并行。这个连接在第四级《AI 基础设施》与《状态空间模型》专题里还会再遇到。</span>

实际的 RWKV-4 训练核函数采取更直接的并行策略：**一个线程负责一个通道**，沿时间 $t$ 串行循环，同时上千个通道（维度 $C$ 可达 4096–5120）在 GPU 上并行执行。这样"时间上串行、通道上并行"，配合 batch 维度，训练吞吐与同规模、带高效注意力的 Transformer 相当——论文报告的训练效率正是来自这条路径。

从理论复杂度看，并行扫描还能进一步把"串行深度"从 $T$ 压到 $O(\log T)$。虽然 GPU 的实际吞吐还受内存带宽与 kernel 启动开销制约，但**渐进层面的可并行性**决定了：RWKV 的训练可以沿序列方向扩展，而不至于像经典 RNN 那样退化为逐时刻的硬串行。这解释了为什么论文能直接复用 Transformer 的成熟训练框架（数据并行、梯度累积、混合精度），而不是为时间依赖另写一套调度。

### 手算一遍：递推与闭式殊途同归

用一个单通道（标量）的例子，验证递推和闭式确实是同一回事。设 $w = 0.1$，$u = 0.5$，三个时间步的键值对为：$k = (0.2, -0.3, 0.4)$，$v = (1, 2, 0.5)$。

- **$t=1$**：$a_0 = b_0 = 0$，于是 $\mathrm{wkv}_1 = \dfrac{0 + e^{0.5+0.2} \times 1}{0 + e^{0.5+0.2}} = 1$。没有历史时，模型只能读到自己的值。
- **$t=2$**：先更新状态 $a_1 = e^{-0.1} \times 0 + e^{0.2} \times 1 \approx 1.22$，$b_1 \approx 1.22$；再算 $\mathrm{wkv}_2 = \dfrac{1.22 + e^{0.2} \times 2}{1.22 + e^{0.2}} \approx 1.5$——此时历史与当前按"键指数"平分秋色。
- **$t=3$**：$a_2 \approx 2.59$，$b_2 \approx 1.85$；$\mathrm{wkv}_3 = \dfrac{2.59 + e^{0.9} \times 0.5}{1.85 + e^{0.9}} \approx 0.89$。

用闭式核对 $t=3$：分子 $= e^{-0.1 + 0.2}\times 1 + e^{-0.3} \times 2 + e^{0.9} \times 0.5 \approx 3.82$，分母 $= e^{0.1} + e^{-0.3} + e^{0.9} \approx 4.31$，比值 $\approx 0.89$。**递推一步步滚出来的结果，与闭式一次性算出的结果完全一致**——这就是第 2 篇"两种写法，同一个数学"的具体验证。

### 易错点辨析：$u$ 只属于当前 token

**辨析｜易错点：** 闭式里 $u$ 只出现在 $i = t$ 那一项，这是许多初学者实现 WKV 时出错的地方。

- 如果把 $u$ 也加进状态递推（比如写成 $a_t = e^{-w}\odot a_{t-1} + e^{u+k_t}\odot v_t$），那么展开后**过去的每个 token 都会带一份 $u$ 奖励**，$u$ 就从"当前 token 的特权"变成了"全体 token 的固定增益"——它退化为一个无意义的全局常数，模型的表达力反而下降。
- 正确的分工是：**状态里存"无 $u$"的累计**，输出时才临时给当前 token 加 $u$。这也是官方核函数里"先算输出、再更新状态"的顺序的由来。

## 6 小结

- **WKV 闭式**：对历史值的归一化、指数衰减加权和；权重 = 键指数 $e^{k_i}$ × 距离衰减 $e^{-(t-1-i)w}$，当前 token 用 $u$ 单独奖励。
- **可写为线性递推**：$a_t = e^{-w}\odot a_{t-1} + e^{k_t}\odot v_t$，推理只维护定长状态，O(1) 每步。
- **线性递推 → 结合律 → 并行扫描**：训练时可用 $O(\log T)$ 深度并行，这是 RNN 不具备、RWKV 独有的优势。
- 实际训练核函数走"通道并行、时间串行"路线，吞吐与高效 Transformer 相当。
- 闭式与递推是同一数学的两种视图，对应第 2 篇"先建状态再读状态"的线性注意力原理。
- 训练核函数走"通道并行 + 时间串行"的工程路线，理论上的并行扫描则保证了渐进层面的可并行性。
- WKV 是逐元素算子，唯一矩阵运算在投影层，可交给高度优化的逐元素 kernel。
- $u$ 只属于当前 token，状态里存"无 $u$"的累计——实现顺序"先算输出再更新状态"由此而来。
- 手算验证：$t=3$ 时递推与闭式都给出 $\mathrm{wkv}_3 \approx 0.89$，两种写法殊途同归。
