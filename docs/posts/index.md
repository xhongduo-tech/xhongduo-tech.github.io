# 博文总览

博文按**九级递进**组织：先打牢数理与自然科学基础，再进阶到大学数理与计算机科学、AI 前沿，随后向生命健康、工程技术、人文艺术、社会科学与交叉前沿全面展开。每个学科对标权威教材，写完一本教材即学完一门学科。完整分级方案见仓库 `CURRICULUM.md`。
