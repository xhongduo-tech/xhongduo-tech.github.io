## 为什么从整除、单位与相伴元开始

「$a$ 整除 $b$」在整数里人人会用，但要在**任意整环**里做分解理论，必须先精确定义三件事：**整除**、**单位**（可逆元）与**相伴元**（差一个单位倍）。这三者构成分解语言的语法——正如「素数」在整数里的地位取决于「±1 是单位」，一般整环里「谁是不可约的」取决于「谁是单位」。

相伴元尤其关键：它回答「哪些分解算同一个」——$2 \cdot 3$ 与 $(-2)(-3)$ 是同一个分解（因为 $-1$ 是单位）。理解「单位修饰」如何影响「整除/相伴/不可约」的定义，是踏入唯一分解整环（UFD）理论的第一步。本节把这三个概念的精确关系讲透。

## 1 整除的定义

**整除（divisibility）**：设 $R$ 是整环，$a, b \in R$。若存在 $c \in R$ 使 $b = ac$，则称 $a$ **整除** $b$（$a$ 是 $b$ 的因子），记作 $a \mid b$；否则记作 $a \nmid b$。

**整除的基本性质**（与整数完全平行）：
- $a \mid a$（自反，取 $c = 1$）；$a \mid 0$（取 $c = 0$）；
- $a \mid b$ 且 $b \mid c$ ⟹ $a \mid c$（传递）；
- $a \mid b$ 且 $a \mid c$ ⟹ $a \mid (b \pm c)$；
- $a \mid b$ 且 $a \mid c$ ⟹ $a \mid bc$；
- **任何元整除单位**：$a \mid 1$ 当且仅当 $a$ 是单位。<span class="marginnote">整除的传递性、线性性在 $\mathbb{Z}$、$F[x]$、$\mathbb{Z}[i]$ 等任意整环里都成立——它们只依赖「乘法结合 + 分配」。在 $\mathbb{Z}$ 里 $a \mid b$ 常说「$a$ 是 $b$ 的因数」；在 $F[x]$ 里「$f$ 整除 $g$」即「$f$ 是 $g$ 的因子」。这套语言是唯一分解理论的日常用语。</span>

**例：**
$\mathbb{Z}$：$2 \mid 6$（$6 = 2 \cdot 3$），$3 \mid 15$；
$\mathbb{R}[x]$：$x - 1 \mid x^2 - 1$（$x^2 - 1 = (x-1)(x+1)$）；
$\mathbb{Z}$：$4 \nmid 6$（不存在整数 $c$ 使 $4c = 6$）。

## 2 单位与相伴元

**单位（unit）**：可逆元（第七篇）：$u$ 是单位 ⟺ 存在 $u^{-1}$ 使 $uu^{-1} = 1$。单位的全体 $R^\times$ 是乘法群。

**相伴元（associate）**：设 $a, b \in R$。若存在单位 $u$ 使 $b = au$（或 $a = bu$），则称 $a$ 与 $b$ **相伴**，记作 $a \sim b$。

**定理（相伴的等价刻画）：** $a \sim b$ ⟺ $a \mid b$ 且 $b \mid a$。

若 $a \sim b$（$b = au$，$u$ 单位），则 $a \mid b$（直接）且 $b \mid a$（$a = bu^{-1}$）；
若 $a \mid b$ 且 $b \mid a$，则 $b = ac$、$a = bd$，$b = bdc$，消去 $b \ne 0$ 得 $dc = 1$，$c$ 是单位，$a \sim b$。$\blacksquare$<span class="marginnote">「相伴 ⟺ 互相整除」是整环里的关键：它让「互相整除」这个关系有了名字。注意「$a \mid b$ 且 $b \mid a$」需要整环性来消去（$b \ne 0$ 时 $dc = 1$）。在 $\mathbb{Z}$ 里相伴元是「差一个 ±1」：$2 \sim -2$；在 $F[x]$ 里相伴元是「差一个非零常数」：$f \sim cf$（$c \in F^\times$）。</span>

**相伴是等价关系**（自反、对称、传递），把整环元素分成相伴类。

**例：**
$\mathbb{Z}$：$2 \sim -2$，$3 \sim -3$；$2 \not\sim 3$；
$\mathbb{R}[x]$：$x^2 - 1 \sim 2(x^2 - 1)$（差非零常数倍）；$x - 1 \sim 3x - 3$；
$\mathbb{Z}[i]$：$1 + i \sim 1 - i$（$(1-i) = i(1+i)$？$(1+i) \cdot i = i - 1 = -(1 - i)$……需检查：$(1+i)i = -1 + i$，而 $-(1-i) = -1 + i$，故 $1-i = (1+i)(-i)$，$-i$ 是单位，$1 + i \sim 1 - i$）。

## 3 为什么相伴元重要：分解的「同一性」

分解理论里，相伴元决定「什么算同一个分解」。

**例（整数）**：$6 = 2 \cdot 3 = (-2) \cdot (-3)$。这两个分解**算同一个**，因为 $2 \sim -2$、$3 \sim -3$——差一个单位倍，本质上相同。素数的唯一分解定理说「分解唯一」，指的就是「不计次序与相伴」的唯一。

**例（多项式）**：$x^2 - 1 = (x-1)(x+1) = (2x - 2)(\tfrac12 x + \tfrac12)$——同一个分解（$x - 1 \sim 2x - 2$）。

**不可约（irreducible）**（下一篇的主角）：$r$ 不可约 ⟺ $r$ 非零非单位，且 $r = ab$ 推出 $a$ 或 $b$ 是单位。**相伴类的选择不影响不可约性**：$r$ 不可约 ⟺ $ur$ 不可约（$u$ 单位）。所以在 $\mathbb{Z}$ 里「素数的相伴类」是 $\{\pm p\}$，在 $F[x]$ 里「不可约多项式的相伴类」是非零常数倍的全体。<span class="marginnote">「不可约性与相伴类」：$x^2 + 1$ 在 $\mathbb{R}[x]$ 里不可约，$3(x^2+1)$ 也不可约（$3$ 是单位倍）。所以分解理论里通常「固定一个代表」来谈——$\mathbb{Z}$ 里取正素数，$F[x]$ 里取<strong>首一多项式</strong>（首项系数为 1），$\mathbb{Z}$ 里取正整数。选代表让「唯一分解」可以精确陈述。</span>

**规范代表（canonical representative）**：为每个相伴类挑一个「标准元」：
$\mathbb{Z}$：取正的（如 $p > 0$）；
$F[x]$：取**首一**的（首项系数为 1，如 $x^2 + 1$）；
$\mathbb{Z}[i]$：暂无简单规范（需按象限/范数取）。

## 4 公式解析：a ∼ b ⟺ a|b 且 b|a

把「相伴 = 互相整除」这条等价关系的证明拆透，它是分解语言的核心。

**第一步，方向（⟹）。** $b = au$（$u$ 单位）：$a \mid b$（$c = u$）；$a = bu^{-1}$：$b \mid a$。互相整除成立。

**第二步，方向（⟸）。** 设 $b = ac$、$a = bd$。代入得 $b = (bd)c = b(dc)$。若 $b \ne 0$，整环消去律给出 $dc = 1$，$c$ 是单位，故 $b = ac$ 中 $c$ 为单位，$a \sim b$。

**第三步，$b = 0$ 的特殊情形。** 若 $b = 0$，则 $a \mid b$ 平凡；$b \mid a$ 即 $0 \mid a$，要求 $a = 0 \cdot c = 0$，故 $a = 0$。此时 $0 \sim 0$ 平凡成立。所以定理对 $0$ 也自洽（只有 $0 \sim 0$）。

**第四步，为什么需要整环。** 消去 $b$ 依赖「无零因子」：非整环里 $dc = 1$ 不一定能推出 $c$ 是单位（可能 $dc = 1$ 但 $c$ 只是「单侧可逆」）。整环性保证「左逆 = 右逆 = 可逆」，让「互相整除 ⟺ 相伴」干净成立。

## 5 例子：在 Z 与 F[x] 中识别相伴元

把相伴概念在最重要的整环上反复练手。

**$\mathbb{Z}$：** $R^\times = \{ 1, -1 \}$。相伴元 = 差一个符号：$5 \sim -5$、$12 \sim -12$。每个相伴类 $\{ n, -n \}$，规范代表取正数。

**$F[x]$：** $F^\times = F \setminus \{ 0 \}$（非零常数）。相伴元 = 差一个非零常数倍：$f \sim cf$（$c \ne 0$）。每个相伴类「所有非零常数倍」，规范代表取首一多项式。$x^2 + 1 \sim 2x^2 + 2 \sim -\pi x^2 - \pi$——同一个「首一不可约类」。

**$\mathbb{Z}[i]$：** $R^\times = \{ 1, -1, i, -i \}$（四个单位）。$1 + i \sim 1 - i \sim -1 + i \sim -1 - i$（乘 $i$、$-1$ 等）——四个高斯整数在同一相伴类。<span class="marginnote">$\mathbb{Z}[i]$ 有四个单位，所以每个相伴类含 4 个元素（除以范数为 1 的高斯整数）。「选代表」不如 $\mathbb{Z}$、$F[x]$ 自然，这提示：相伴结构随环变，UFD 理论里「选规范代表」只是便利，不是必需——唯一分解可以「不计相伴」来陈述。</span>

## 6 小结

- **整除** $a \mid b$：$b = ac$；自反、传递、线性。
- **单位**：可逆元；$R^\times$ 是乘法群；$a \mid 1 \iff a$ 是单位。
- **相伴** $a \sim b$：差一个单位倍；⟺ $a \mid b$ 且 $b \mid a$。
- **不可约性的相伴不变性**：$r$ 不可约 ⟺ $ur$ 不可约。
- **规范代表**：$\mathbb{Z}$ 取正、$F[x]$ 取首一；让「唯一分解」可精确陈述。

在下一节，我们定义分解理论的主角：**不可约元与素元**。它们分别对应「拆不开的因子」与「素数式性质」，而两者的关系正是 UFD 的核心。
