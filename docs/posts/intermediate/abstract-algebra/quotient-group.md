## 为什么从商群开始

上一节我们证明了：正规子群 $N$ 恰好是「陪集乘法良定义」的条件。这一节兑现承诺——把陪集集合 $G/N$ 装进一个群结构，得到**商群（quotient group）**。

商群的思想是群论最伟大的飞跃之一：**把群中的一大块（一个正规子群及其陪集）「压缩成一个点」，得到一个更小的群，而这个更小的群仍然忠实记录了原群的部分结构。** 同余类 $\mathbb{Z}_n = \mathbb{Z} / n\mathbb{Z}$ 就是商群最早也最直观的例子——「模 $n$ 取余」就是把 $n\mathbb{Z}$ 压成一个点。商群是理解「宏观与微观」的第一座数学桥梁：宏观层面的运算，精确反映微观结构的「折叠方式」。第四篇接下来的同态基本定理、以及第十一篇的 Galois 理论，全部建立在商群的引擎之上。

## 1 商群的定义

**商群（quotient group）**：设 $N \trianglelefteq G$，定义陪集集合

$$
G / N = \{ aN \mid a \in G \}
$$

并在其上定义乘法 $(aN)(bN) = abN$。由正规子群的等价条件 5，这个乘法良定义，且 $G/N$ 在此乘法下构成一个群，称为 $G$ 关于 $N$ 的商群。

**验证 $G/N$ 是群**：单位元是 $N = eN$（$(aN)(eN) = aeN = aN$）；逆元是 $(aN)^{-1} = a^{-1}N$（$(aN)(a^{-1}N) = aa^{-1}N = N$）；结合律继承自 $G$（$(aN)(bN)(cN) = (ab)N \cdot cN = abcN$，与结合顺序无关）。全部群公理只需「陪集乘法良定义」这一步支撑——这就是正规性的意义所在。<span class="marginnote">商群的「商」字取自「除法」的意象：$|G/N| = |G| / |N|$（有限时），把 $G$ 的「大小」除以 $N$ 的「大小」。$G/N$ 的元素是 $N$ 的陪集，$|G/N| = [G : N]$——商群的大小就是指标。</span>

**例：** $\mathbb{Z} / n\mathbb{Z} = \mathbb{Z}_n$。陪集 $k + n\mathbb{Z}$ 就是同余类 $[k]$，乘法（加法）$(a + n\mathbb{Z}) + (b + n\mathbb{Z}) = (a+b) + n\mathbb{Z}$ 正是模 $n$ 加法。**商群 $G/N$ 统一了「同余」与「陪集」两种语言。** 同样地，$S_3 / A_3 \cong \mathbb{Z}_2$（两个陪集：偶置换块、奇置换块），$S_n / A_n \cong \mathbb{Z}_2$ 对一切 $n \ge 2$。

## 2 自然同态：从 G 到 G/N 的投影

商群最有用的附属品是**自然同态（natural homomorphism）**：

$$
\pi : G \to G / N, \qquad \pi(a) = aN
$$

**定理：** $\pi$ 是满射群同态，且 $\ker \pi = N$。

- 同态性：$\pi(ab) = abN = (aN)(bN) = \pi(a)\pi(b)$，良定义性再次登场；
- 满射性：每个陪集 $aN$ 都是 $\pi(a)$ 的像；
- 核：$\pi(a) = N \iff aN = N \iff a \in N$（陪集相等条件），故 $\ker \pi = N$。<span class="marginnote">自然同态把每个元素「投影」到它所在的陪集上。想象把群 $G$ 的每片陪集「拍扁」成一个点，$\pi$ 就是这个拍扁过程的数学实现。$\ker \pi = N$ 说明：被拍扁到单位元的，恰好是 $N$ 自己——商群的「零纤维」就是正规子群 $N$。</span>

这条定理补完了上一节等价条件 4 的最后一环：**每个正规子群 $N$ 都「是」自然同态 $\pi : G \to G/N$ 的核。**「核 ⟺ 正规」的双向对应至此闭环。

**例：** $\mathbb{Z} \to \mathbb{Z}_n$，$k \mapsto k \bmod n$ 是自然同态，核为 $n\mathbb{Z}$；$\mathrm{sgn} : S_n \to \{\pm 1\}$ 的自然同态对应商群 $S_n / A_n$。

## 3 商群能做什么：压缩信息，提炼结构

商群的价值在于「用粗粒度看群」。同一个群，取不同的正规子群做商，看到的是不同分辨率的图景。

- **$G/\{e\} \cong G$**：最细，什么都不压；
- **$G/G \cong \{e\}$**：最粗，压成一个点；
- **$G/Z(G)$**：压缩中心后，剩余的是「不可交换的核心」。著名的例子：$G/Z(G)$ 循环 $\Rightarrow G$ 交换；$D_4 / Z(D_4) \cong \mathbb{Z}_2 \times \mathbb{Z}_2$。<span class="marginnote">「$G/Z(G)$ 循环 ⟹ $G$ 交换」是一条精致的小定理：若 $G/Z(G)$ 由单个陪集 $aZ(G)$ 生成，则每个 $g = a^k z$，两个元素 $a^k z_1$ 与 $a^l z_2$ 相乘时 $z$ 部分自由换位，$a^k a^l = a^{k+l}$ 也可换位，于是 $G$ 交换。它常用来证明「$p^2$ 阶群必交换」（第五篇 p 群的内容）。</span>
- **$G/[G,G]$**（换位子群的商）：称为 $G$ 的**交换化（abelianization）**，把群压成最大的交换商群。这是「测度不可交换程度」的经典工具。

**例：** $S_3$ 的交换化 $S_3 / [S_3, S_3] = S_3 / A_3 \cong \mathbb{Z}_2$——$S_3$ 最接近的交换群是二阶循环群；$A_5$ 的交换化是 $\{e\}$，因为 $A_5$ 单且非交换，「压不出任何非平凡的交换商」。

## 4 公式解析：商群如何「继承」运算

商群的一切都浓缩在「陪集乘法良定义」这一条里。把它彻底拆开。

- **第一步，最朴素的期望。** 我们希望「先乘代表元、再投影」等于「先投影、再乘」：$\pi(ab) = \pi(a)\pi(b)$。这要求 $abN = (aN)(bN)$，即陪集乘法的结果 $abN$ 只由陪集 $aN, bN$ 决定。

- **第二步，良定义性的陷阱。** 若换代表元 $aN = a'N$（即 $a^{-1}a' \in N$），$bN = b'N$，必须保证 $abN = a'b'N$。没有正规性时这一步会失败——非正规的 $H$ 上，同一组陪集换代表元后乘积可能落进不同陪集。

- **第三步，正规性如何挽救。** 上一节的推导显示：$a'b' = an_1 bn_2 = ab (b^{-1} n_1 b) n_2$，其中 $b^{-1}n_1b \in N$（$N$ 正规）。于是 $a'b' \in abN$，$abN = a'b'N$。**正规性把「混入的代表元」翻译回 $N$ 内部**，让乘法结果稳定。

- **第四步，哲学。** 商群的定义其实是在说：**只要被压缩的块足够「对称」（正规），压缩后的世界依然有序。** 这像模算术、像图像的分辨率、像把地球压成地图——压缩掉一层细节，剩下的结构依旧自治。第十一篇 Galois 理论将展示：正规扩张的子域对应正规子群，商群是「外层对称」的精确度量。

## 5 例子：D4 的商群全景

把二面体群 $D_4$（正方形的对称群，8 阶）的商群逐个算出来，商群的概念就彻底落地。$D_4 = \langle r, s \mid r^4 = s^2 = e, srs = r^{-1} \rangle$（$r$ 旋转、$s$ 翻转）。

- **$Z(D_4) = \{ e, r^2 \}$**：中心只有恒等与 180° 旋转。$D_4 / Z(D_4)$ 有 $8/2 = 4$ 个元素，且是 4 阶群——具体地 $D_4/Z(D_4) \cong \mathbb{Z}_2 \times \mathbb{Z}_2$（克莱因四元群）。
- **换位子群 $[D_4, D_4] = \{ e, r^2 \} = Z(D_4)$**：交换化 $D_4 / [D_4, D_4] \cong \mathbb{Z}_2 \times \mathbb{Z}_2$，说明 $D_4$ 的不可交换性恰好集中在 $r^2$ 上。<span class="marginnote">$D_4$ 的交换化是 $\mathbb{Z}_2 \times \mathbb{Z}_2$ 而非 $\mathbb{Z}_4$：因为 $s$ 与 $r$ 在交换化里都变成二阶元素且互相独立，得到「两个独立的翻转」。交换化把「旋转+翻转」的混合结构拆成纯交换的组件——这正是第六篇直积分解的雏形。</span>
- **子群 $\langle r \rangle = \mathbb{Z}_4$**：指标 2 故正规，$D_4 / \langle r \rangle \cong \mathbb{Z}_2$（$r$ 旋转块 vs $sr$ 翻转块）。

三个商群对应三种「看 $D_4$ 的分辨率」：最粗看成一个点，中等看成 $\mathbb{Z}_2$，较细看成克莱因四元群——**同一个群，不同的正规子群给出不同的宏观图景**。这就是商群「压缩」的本质。

## 6 小结

- **商群** $G/N$：陪集集合 + 良定义乘法；$|G/N| = [G:N] = |G|/|N|$（有限）。
- **自然同态** $\pi(a) = aN$：满同态，$\ker \pi = N$；正规子群恰是自然同态的核。
- **商群 = 压缩**：$G/\{e\} \cong G$，$G/G \cong \{e\}$；交换化 $G/[G,G]$ 是最大交换商。
- **良定义性**是商群的全部关键：正规性保证代表元可安全更换。
- 例：$\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}_n$，$S_n/A_n \cong \mathbb{Z}_2$，$D_4/Z(D_4) \cong \mathbb{Z}_2 \times \mathbb{Z}_2$。

在下一节，我们把商群与同态彻底打通：**群同态基本定理**。它断言 $G/\ker f \cong \operatorname{Im} f$——每一个同态的像，都是原群「压掉核」后的商群。这是群论里最漂亮的等式之一。
