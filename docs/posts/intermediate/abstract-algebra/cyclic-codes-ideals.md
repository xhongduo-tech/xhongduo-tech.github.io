## 为什么从循环码与理想开始

上一节的线性码是「任意向量子空间」，这一节给码加上一个漂亮的结构：**循环性**——码字循环移位仍是码字。**循环码（cyclic code）**是编码理论最重要的码类之一（BCH、Reed-Solomon 都是循环码），而它的代数本质是**多项式环 $\mathbb{F}_q[x]/\langle x^n - 1 \rangle$ 里的理想**。

这条「循环码 = 理想」的对应是本专题环论与编码理论的最后握手：码字 = 多项式、循环移位 = 乘 $x$、码 = 理想 = 主理想（由生成多项式决定）。理解循环码，你就同时理解了「理想」在真实工程中的形态——**第八篇的抽象理想，在纠错码里是看得见摸得着的**。本节把循环码的定义、多项式翻译、生成多项式与 BCH/Reed-Solomon 讲透。

## 1 循环码的定义与多项式翻译

**循环码（cyclic code）**：$[n, k]$ 线性码 $C \subseteq \mathbb{F}_q^n$ 称为循环码，若码字循环移位后仍是码字：

$$
(c_0, c_1, \dots, c_{n-1}) \in C \Longrightarrow (c_{n-1}, c_0, c_1, \dots, c_{n-2}) \in C
$$

**多项式翻译**：把码字 $(c_0, \dots, c_{n-1})$ 对应多项式 $c(x) = c_0 + c_1 x + \cdots + c_{n-1} x^{n-1}$。循环移位对应「乘 $x$ 模 $x^n - 1$」：

$$
x \cdot c(x) = c_{n-1} + c_0 x + \cdots + c_{n-2} x^{n-1} \pmod{x^n - 1}
$$

（因为 $x^n \equiv 1$，最高次项滚回常数项。）**循环移位 = 模 $x^n - 1$ 乘 $x$**。<span class="marginnote">「循环移位 = 乘 $x$ 模 $x^n - 1$」是循环码的代数核心：把「位移」翻译成「多项式乘法」，循环性变成「乘 $x$ 不离开 $C$」。于是码 $C$ 在「乘 $x$」下封闭，而乘任意多项式 = 多次乘 $x$ 的组合——$C$ 对「乘任意多项式」都封闭。这正是「理想」的定义：<strong>循环码 = 对环元素乘法封闭的加法子群 = 理想</strong>。</span>

## 2 循环码 = 多项式环中的理想

**定理（循环码与理想）：** 循环码 $C$（长度 $n$）恰好对应环 $R_n = \mathbb{F}_q[x] / \langle x^n - 1 \rangle$ 中的理想。

**证明（要点）：**
- 码字 ↔ 多项式同余类（$R_n$ 的元素）；
- 循环性 ⟹ $C$ 对乘 $x$ 封闭 ⟹ 对乘任意多项式封闭（理想性质）；
- 反之理想的封闭性 ⟹ 循环性。$\blacksquare$

**生成多项式（generator polynomial）**：$R_n = \mathbb{F}_q[x]/\langle x^n - 1\rangle$ 是 PID 的商，其理想都是主理想。循环码 $C$ 由唯一的**生成多项式** $g(x)$ 生成：

$$
C = \langle g(x) \rangle = \{ g(x) f(x) \bmod (x^n - 1) \}
$$

其中 $g(x) \mid (x^n - 1)$（$g$ 整除 $x^n - 1$），且 $C$ 的维数 $k = n - \deg g$。<span class="marginnote">「循环码 = 主理想 = $\langle g \rangle$」是第八篇主理想整环理论在编码里的落地：$R_n$ 里的理想全由一个多项式生成，于是每个循环码由它的生成多项式 $g(x)$ 完全决定。<strong>设计循环码 = 选 $g(x)$（$x^n - 1$ 的因子）</strong>——码的维数、距离、纠错能力全部由 $g$ 读出。这是「理想」概念最具体的工程形态。</span>

**例：Hamming [7,4] 码**：$x^7 - 1 = (x^3 + x + 1)(x^3 + x^2 + 1)(x + 1)$ 在 $\mathbb{F}_2$ 上分解。取生成多项式 $g(x) = x^3 + x + 1$（3 次），得 $[7, 4]$ 循环码（$k = 7 - 3 = 4$，$d = 3$）——**Hamming [7,4] 码就是生成多项式 $x^3 + x + 1$ 的循环码**。

## 3 校验多项式与编码

循环码的编码与校验都有多项式形态。

**校验多项式（parity-check polynomial）**：$h(x) = (x^n - 1) / g(x)$（$g$ 的补因子）。校验方程：

$$
c(x) h(x) \equiv 0 \pmod{x^n - 1}
$$

对一切码字 $c(x)$ 成立（$c = gf$，$ch = gfh \equiv 0$）。

**系统编码**：信息多项式 $m(x)$（次数 < $k$），码字

$$
c(x) = x^{n-k} m(x) - r(x)
$$

其中 $r(x) = x^{n-k} m(x) \bmod g(x)$（余数）。则 $c \equiv 0 \pmod g$（$c$ 是码字），且 $c$ 的高 $k$ 位就是信息、低 $n-k$ 位是校验。<span class="marginnote">系统编码用「带余除法」做：信息左移 $n-k$ 位（乘 $x^{n-k}$），模 $g$ 取余数作校验位。这正是第九篇「$F[x]$ 是欧氏环、可做带余除法」的编码应用。<strong>「$F[x]$ 的欧氏性」让循环码的编码、校验、纠错全部可计算</strong>——没有带余除法，循环码无从谈起。</span>

## 4 BCH 码与 Reed-Solomon 码

循环码族里最重要的是能纠多位的**BCH 码**与**Reed-Solomon（RS）码**。

**BCH 码（Bose–Chaudhuri–Hocquenghem）**：选 $g(x)$ 为「连续幂次根」的最小多项式之积，保证设计距离 $d$。构造：在扩域 $\mathbb{F}_{q^m}$ 中取本原元 $\alpha$，$g(x)$ 是 $\alpha, \alpha^2, \dots, \alpha^{d-1}$ 的最小多项式的最小公倍式。**BCH 码可设计任意纠错能力 $t$，$d \ge 2t + 1$。**

**Reed-Solomon 码**：$[n, k]$ RS 码（$n = q - 1$），生成多项式

$$
g(x) = (x - \alpha^b)(x - \alpha^{b+1}) \cdots (x - \alpha^{b+d-2})
$$

RS 码达到 Singleton 界 $k + d = n + 1$（**MDS 码，最优距离**），是 CD、QR 码、卫星通信的标准纠错码。<span class="marginnote">RS 码的生成多项式 $g(x) = \prod (x - \alpha^i)$（连续幂次的根）保证「任意 $d - 1$ 个位置的错误都能被检测」——这来自「多项式在 $d-1$ 个点取值唯一确定插值」的代数事实（RS 码本质是「对多项式取值编码」）。<strong>RS 码 = 「多项式插值」的编码形态</strong>，其代数骨架是有限域 $\mathbb{F}_q$ 上的多项式理论——第九篇与第十篇在这里合流。</span>

**应用**：CD/DVD（RS + 交叉）、QR 码（RS）、深空通信（RS + 卷积）、5G（极化码与 LDPC 之外 RS 仍在）。

## 5 公式解析：C = ⟨g⟩ 的理想机制

把「循环码 = 主理想」从机制上拆透，它是本专题环论与编码理论的最后握手。

- **第一步，码就是理想。** 循环码 $C$ 在乘 $x$ 下封闭（循环性），而 $R_n$ 里「乘任意多项式」= 多次乘 $x$ 的线性组合，故 $C$ 对「乘任意 $R_n$ 元素」封闭——$C$ 是 $R_n$ 的理想。

- **第二步，理想 = 主理想。** $R_n = \mathbb{F}_q[x]/\langle x^n - 1\rangle$ 是「域上多项式环的商」，其理想都是主理想（PID 的商的理想仍是主的）。存在生成元 $g(x)$：$C = \langle g \rangle$。

- **第三步，$g$ 整除 $x^n - 1$。** 因为 $\langle g \rangle \subseteq R_n$ 需要 $g$ 生成的理想不越界，等价于 $g \mid (x^n - 1)$（$x^n - 1$ 在 $\langle g\rangle$ 里）。

- **第四步，维数公式。** $\dim C = \deg(x^n - 1) - \deg g = n - \deg g$。$\blacksquare$ **设计循环码 = 在 $x^n - 1$ 的因子里选 $g$**——整除理论（第九篇）直接变成编码设计。

## 6 对照速查：循环码的设计清单

把循环码的设计要素排成一张表，选参数时按图索骥。

| 要素 | 记号 | 说明 |
| --- | --- | --- |
| 码长 | $n$ | 码字长度；$x^n - 1$ 的分解场地 |
| 生成多项式 | $g(x)$ | $g \mid (x^n - 1)$，决定一切 |
| 维数 | $k = n - \deg g$ | 信息位数 |
| 校验多项式 | $h(x) = (x^n-1)/g$ | 校验方程 $c h \equiv 0$ |
| 设计距离 | $d$ | BCH 用连续幂次根保证 $d \ge 2t+1$ |

**数值算例：设计 $[7,4]$ 循环码。** $x^7 - 1$ 在 $\mathbb{F}_2$ 上分解为 $(x^3+x+1)(x^3+x^2+1)(x+1)$。选 $g = x^3 + x + 1$（3 次），$k = 7 - 3 = 4$，维数 4；码是 $\langle g\rangle$，$d = 3$（Hamming [7,4] 码）。选 $g = x^3 + x^2 + 1$ 得到另一个 $[7,4]$ 循环码——同一码长可有多个生成多项式，对应不同码。<span class="marginnote">「设计循环码 = 在 $x^n - 1$ 的因子里挑 $g$」把编码设计变成一次多项式分解（第九篇）：不同的因子给出不同的 $[n,k]$ 码，而 $x^n - 1$ 的分解在 $\mathbb{F}_q$ 上由「$q$ 阶本原单位根」的结构决定。BCH/RS 码正是「挑 $g$ 让根落在连续幂次」的优化——理想理论在工程里落地生根。</span>

**一句话记法**：循环码 = $R_n$ 里的理想 = 主理想 $\langle g \rangle$；移位 = 乘 $x$ 模 $x^n - 1$；$g \mid x^n - 1$、$k = n - \deg g$；BCH/RS 用连续幂次根保距离——第八篇的理想在纠错码里变得看得见。

## 7 小结

- **循环码**：循环移位保持码字；码字 = 多项式，移位 = 乘 $x$ 模 $x^n - 1$。
- **循环码 = 理想**：$C$ 是 $R_n = \mathbb{F}_q[x]/\langle x^n-1\rangle$ 的理想 = 主理想 $\langle g(x)\rangle$。
- **生成多项式** $g \mid (x^n - 1)$：$k = n - \deg g$；校验多项式 $h = (x^n-1)/g$。
- **系统编码**：信息左移、模 $g$ 取余数作校验（带余除法）。
- **BCH/RS 码**：连续幂次根的生成多项式，RS 达到 Singleton 界（MDS），是 CD/QR 的标准纠错码。
