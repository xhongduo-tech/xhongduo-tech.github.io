## 为什么从伽罗瓦理论开始

从四次方程求根公式发现（1545 年）到伽罗瓦做出最终裁决（1830 年前后），数学家们花了近三百年在五次方程上撞墙。阿贝尔证明了「一般五次方程没有根式解」（1824），但**为什么**没有，只有伽罗瓦给出了结构性的答案——他用群的语言回答了方程的求解问题。

伽罗瓦的洞见：给方程 $f$ 装上它的**对称群**——根之间的置换里，那些「保持根之间全部代数关系」的置换构成 Galois 群。然后他证明了一条惊天动地的对应：**方程的域扩张子域结构与 Galois 群子群结构一一对应**。能不能用根式求解，就变成一个纯群论问题：群可不可解。本篇把《域的自同构与 Galois 群》到《尺规作图》五篇的线索收拢，登上全专题的最高峰。

## 1 域的自同构与 Galois 群

**域自同构（automorphism）**：$E$ 到自身的域同构（保加、保乘、保 $1$）。**自同构群** $\mathrm{Aut}(E)$ 是其全体，构成群。

**Galois 群（Galois group）**：设 $E/F$ 是域扩张，固定 $F$ 不动的自同构全体

$$
\mathrm{Gal}(E/F) = \{\sigma \in \mathrm{Aut}(E) : \sigma(a) = a \text{ 对一切 } a \in F\}
$$

是 $\mathrm{Aut}(E)$ 的子群。例如 $\mathrm{Gal}(\mathbb{C}/\mathbb{R}) = \{1, \text{共轭}\}$（二阶循环群）；$\mathrm{Gal}(\mathbb{Q}(\sqrt{2})/\mathbb{Q})$ 也恰为二阶——$\sqrt{2} \mapsto \pm\sqrt{2}$ 的两种「对称」。

<span class="marginnote">伽罗瓦群度量的是「扩张有多少对称」。$\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 只有恒等自同构（另外两个根是复数，$\sqrt[3]{2}$ 无处可去）——它「几乎没对称」，这正是它不正规、不能根式推进的原因。对称越多，结构越丰富，理论越好用。</span>

## 2 伽罗瓦对应：群与域的桥梁

定义**固定域（fixed field）**：对子群 $G \le \mathrm{Gal}(E/F)$，$E^G = \{x \in E : \sigma(x) = x \text{ 对一切 } \sigma \in G\}$ 是中间域。

于是有两条互逆的「旅行」：

$$
\underbrace{\text{子群 } H}_{\text{群的世界}} \;\xrightarrow{\;E^H\;}\; \underbrace{\text{中间域 } K}_{\text{域的世界}} \;\xrightarrow{\;\mathrm{Gal}(E/K)\;}\; \text{子群}
$$

**伽罗瓦扩张（Galois extension）**：$E/F$ 有限、可分、正规——等价地，$E$ 是某个可分多项式在 $F$ 上的分裂域，且 $E^{\mathrm{Gal}(E/F)} = F$（固定域回到 $F$ 自身）。

对伽罗瓦扩张，上述两条旅行**互为逆映射**：从子群出发到中间域再回到子群，恰好返回起点；从中间域出发同理。这一一对应就是**伽罗瓦对应（Galois correspondence）**。

## 3 Galois 理论基本定理

**Galois 理论基本定理**：设 $E/F$ 是有限伽罗瓦扩张，则

1. **一一对应**：$\mathrm{Gal}(E/F)$ 的子群与 $E$ 与 $F$ 之间的中间域之间存在反序一一对应：
   $H \mapsto E^H$，$K \mapsto \mathrm{Gal}(E/K)$；
2. **次数匹配**：$[E : E^H] = |H|$，$[E^H : F] = [\mathrm{Gal}(E/F) : H]$；
3. **正规性传递**：$E^H/F$ 是伽罗瓦扩张当且仅当 $H \unlhd \mathrm{Gal}(E/F)$，此时 $\mathrm{Gal}(E^H/F) \cong \mathrm{Gal}(E/F)/H$。

**核心对比表**：把群论词汇表与域论词汇表并排看，整个定理一目了然：

| 群的世界（$\mathrm{Gal}(E/F)$） | 域的世界（$E/F$ 的中间域） |
| --- | --- |
| 子群 $H$ | 中间域 $E^H$ |
| 正规子群 $H$ | 正规扩张 $E^H/F$ |
| 商群 $G/H$ | 伽罗瓦群 $\mathrm{Gal}(E^H/F)$ |
| 阶 $|H|$ | 扩张次数 $[E : E^H]$ |

这张表是整个 Galois 理论的总纲——**群的代数问题与域的代数问题互相翻译，哪个好算就算哪个。**<span class="marginnote">一个直观的检验：$E = \mathbb{Q}(\sqrt{2}, \sqrt{3})$，$\mathrm{Gal}(E/\mathbb{Q})$ 是克莱因四元群 $V_4$（四个自同构由 $\sqrt{2} \mapsto \pm\sqrt{2}$、$\sqrt{3} \mapsto \pm\sqrt{3}$ 独立给出）。它的三个二阶子群对应三个中间域 $\mathbb{Q}(\sqrt{2})$、$\mathbb{Q}(\sqrt{3})$、$\mathbb{Q}(\sqrt{6})$——每个都正规，因为 $V_4$ 阿贝尔、一切子群正规。对应关系严丝合缝。</span>

## 4 公式解析：伽罗瓦群的规模受扩张次数限制

$$
|\mathrm{Gal}(E/F)| \le [E : F], \qquad \text{有限伽罗瓦扩张时取等号：} |\mathrm{Gal}(E/F)| = [E:F]
$$

- **第一步，盯住单扩张**：$E = F(\alpha)$（$E/F$ 有限时可由有限次单扩张拼成）。$\alpha$ 的像 $\sigma(\alpha)$ 必须是 $\alpha$ 的极小多项式 $m_\alpha$ 的根（自同构保持代数关系：$m_\alpha(\sigma(\alpha)) = \sigma(m_\alpha(\alpha)) = \sigma(0) = 0$）。
- **第二步，数选择**：$\sigma$ 由 $\sigma(\alpha)$ 完全确定，而 $\sigma(\alpha)$ 至多 $d = [F(\alpha):F]$ 种取法（$m_\alpha$ 至多有 $d$ 个根），故 $|\mathrm{Gal}(E/F)| \le [E:F]$。
- **第三步，取等的条件**：等号要求「根的选择足够多」——$m_\alpha$ 的所有根都还在 $E$ 里（分裂域性质）且无重根（可分性）。这正是伽罗瓦扩张的定义，于是基本定理第 2 条 $|\mathrm{Gal}(E/F)| = [E:F]$ 成立。

**这条公式的启示：** 不等式 $|\mathrm{Gal}| \le [E:F]$ 是「对称不能超过体积」的精确表述；取等条件则把「可分 + 分裂」这两条温和的条件翻译成「对称与体积相等」——**伽罗瓦扩张就是「对称恰好填满体积」的扩张**。

## 5 根式可解性与五次方程不可解

**根式扩张（radical extension）**：逐步添加开方根 $\sqrt[n]{a}$ 得到的扩张链。**方程根式可解**：存在根式扩张链，使 $f$ 的分裂域落进某一步里。

伽罗瓦给出的判据干净利落：

**定理**：$f$ 可用根式求解，当且仅当 $f$ 的 Galois 群**可解（solvable）**——即存在正规子群链，使每一步商群都是阿贝尔群（循环群）。

于是五次方程的故事变成一条纯群论的不等式链：

$$
A_n \text{（$n\ge 5$ 时单群，不可解）} \;\Rightarrow\; S_n \text{ 不可解} \;\Rightarrow\; \text{一般五次方程} \;x^5 - ax - b = 0 \text{ 的 Galois 群 } S_5 \text{ 不可解} \;\Rightarrow\; \text{无根式解}
$$

**辨析｜易错点：** 「五次方程无根式解」说的是**一般**五次方程——特定方程仍可能有根式解。$x^5 - 1 = 0$ 的根是五次单位根，当然能用根式写出来；$x^5 - x - 1 = 0$ 的 Galois 群是 $S_5$，才是真正「解不动」的代表。**可解性是对 Galois 群说的，不是对次数说的。**

## 6 尺规作图三大难题

Galois 理论顺手裁决了折磨希腊人两千年的三大作图难题。关键是两条次数限制：

**可作图点** $\Leftrightarrow$ 其坐标落在由 $\mathbb{Q}$ 逐次做二次扩张得到的域中，故一切可作图数的次数必须是 $2$ 的幂。

- **倍立方**：作 $\sqrt[3]{2}$，其极小多项式 $x^3 - 2$ 次数为 3，非 2 的幂——不可作；
- **三等分角**：$60^\circ$ 三等分需作 $\cos 20^\circ$，其极小多项式次数为 3——不可作；
- **化圆为方**：作 $\sqrt{\pi}$，$\pi$ 是超越数，次数无限——不可作。

可作正 $n$ 边形的条件是 $n = 2^k p_1 \cdots p_r$，各 $p_i$ 是费马素数（如 3, 5, 17, 257）——高斯在 1796 年发现正 17 边形可作时，用的正是这套「次数是 2 的幂」的思想，比 Galois 理论早了几十年。

## 7 小结

- **Galois 群** $\mathrm{Gal}(E/F)$：固定 $F$ 的 $E$ 的自同构群；$|\mathrm{Gal}(E/F)| \le [E:F]$。
- **伽罗瓦扩张**：有限 + 可分 + 正规，等价于「对称填满体积」。
- **基本定理**：子群与中间域反序一一对应；正规子群 ⟷ 正规扩张；商群 ⟷ 伽罗瓦群。
- **根式可解 ⟺ Galois 群可解**；$S_n$（$n\ge 5$）不可解 ⟹ 一般五次方程无根式解。
- **三大作图难题**：倍立方、三等分角、化圆为方全部不可作——原因统一为「次数不是 2 的幂」或超越。
- 伽罗瓦理论把方程问题翻译成群论问题，是「结构主义」的终极胜利。
