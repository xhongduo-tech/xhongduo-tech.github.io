## 为什么从可分扩张与正规扩张开始

Galois 理论研究的扩张（Galois 扩张）需要两个前提条件：**可分性（separable）**——多项式没有重根、每个不可约因子能「干净地」分裂；**正规性（normal）**——一个根进来，它的全部「兄弟根」都跟着进来（分裂域性质）。

这两个性质在特征 0 自动成立（所以 $\mathbb{Q}$ 上的 Galois 理论最顺滑），但在特征 $p$ 里会出现奇特的「不完美」现象（如 $x^p - t$ 的根不可分）。理解可分与正规，是第十一篇 Galois 对应成立的前提。本节把可分多项式、可分扩张、正规扩张的定义与关键定理讲透。

## 1 可分多项式与重根

**可分多项式（separable polynomial）**：设 $f \in F[x]$ 非常数。若 $f$ 在其分裂域中无重根，则称 $f$ 是**可分多项式**；否则（有重根）称不可分。

**重根的判定（导数）：** $a$ 是 $f$ 的重根 ⟺ $f(a) = f'(a) = 0$（$f'$ 是形式导数）。故 $f$ 可分 ⟺ $f$ 与 $f'$ 互素（gcd 是常数）。

**例：**
- $x^2 - 2$ 在 $\mathbb{Q}$ 上可分（根 $\pm\sqrt2$ 不同）；
- $(x-1)^2$ 可分吗？——不是（重根 $1$）；但它在 $\mathbb{Q}[x]$ 里本就不是不可约的。**可分性对不可约多项式最关键**：不可约多项式是否可分决定扩张是否「干净」。<span class="marginnote">「不可约多项式是否可分」是特征敏感的问题。特征 0 里一切不可约多项式都可分（$f'$ 的次数比 $f$ 低，不可约的 $f$ 若整除 $f'$ 则 $f' = 0$，特征 0 下 $f' = 0$ 只可能 $f$ 是常数，矛盾）。但在特征 $p$ 里，$f = x^p - t$（$t$ 超越）满足 $f' = px^{p-1} = 0$（特征 $p$ 时 $p = 0$）——不可约却有重根。<strong>可分性在特征 $p$ 里才是一个真问题。</strong></span>

## 2 可分扩张与可分元

**可分元（separable element）**：$a$ 是 $F$ 上的代数元，若 $a$ 的最小多项式在 $F$ 上可分，则称 $a$ 是 $F$ 上的**可分元**。

**可分扩张（separable extension）**：若 $E/F$ 的每个元素都是可分元，则称 $E/F$ 是**可分扩张**。

**定理（特征 0 自动可分）：** 特征 0 的域上的任何代数扩张都是可分扩张。

**证明：** 特征 0 里一切不可约多项式可分（上边注记），故每个代数元的最小多项式可分，每个元素可分。$\blacksquare$——**在 $\mathbb{Q}$、$\mathbb{R}$、$\mathbb{C}$ 的世界里，可分性免费。**<span class="marginnote">特征 0 免费可分是「教科书默认顺滑」的原因：大多数 Galois 理论教材先在特征 0（或 $\mathbb{Q}$ 上）讲，那时可分性自动成立，不必每次检查。特征 $p$ 才出现真正的麻烦：$x^p - t$ 的根「不可分」，$F(t^{1/p})/F(t)$ 不是可分扩张。<strong>「可分性」是特征 $p$ 特有的关卡</strong>——这也是为什么有限域理论（$\mathbb{F}_{p^n}$）总要先处理「可分 vs 不可分」。</span>

**例（特征 $p$ 的不可分元）：** $F = \mathbb{F}_p(t)$（有理函数域），$a = t^{1/p}$（$x^p - t$ 的根）。$x^p - t = (x - t^{1/p})^p$ 在 $F(a)$ 中只有一个根 $t^{1/p}$（重数 $p$），$a$ 不可分。$F(a)/F$ 是不可分扩张（**纯不可分扩张**的例子）。

## 3 正规扩张：根的全家福

**正规扩张（normal extension）**：设 $E/F$ 是代数扩张。若 $E$ 中每个「$F$ 上不可约多项式 $f$」只要有一个根在 $E$ 里，$f$ 就在 $E$ 中完全分裂（全部根都在 $E$ 里），则称 $E/F$ 是**正规扩张**。

**等价刻画：** $E/F$ 是有限正规扩张 ⟺ $E$ 是某个 $f \in F[x]$ 的分裂域。

- 若 $E$ 是 $f$ 的分裂域，取 $g$ 不可约、有根 $\alpha \in E$；$\alpha$ 是 $f$ 的根（在分裂域里），$g$ 与 $f$ 有公共根 $\alpha$，$g$ 整除 $f$，$g$ 在 $E$ 中分裂；
- 反之若 $E/F$ 正规且有限，$E = F(a_1, \dots, a_n)$，取 $f$ = 各 $a_i$ 的最小多项式之积，$E$ 是 $f$ 的分裂域。$\blacksquare$<span class="marginnote">正规性 = 「一个根进来，全部兄弟根都进来」。$\mathbb{Q}(\sqrt[3]2)/\mathbb{Q}$ <strong>不是</strong>正规扩张：$x^3 - 2$ 有根 $\sqrt[3]2 \in \mathbb{Q}(\sqrt[3]2)$，但另外两个根 $\omega\sqrt[3]2$、$\omega^2\sqrt[3]2$ 不在里面（它们含 $\omega$）。而分裂域 $\mathbb{Q}(\sqrt[3]2, \omega)/\mathbb{Q}$ 是正规的。「正规 = 分裂域」这条等价是 Galois 对应成立的半边。</span>

**例：**
- $\mathbb{Q}(\sqrt2)/\mathbb{Q}$ 正规（$x^2-2$ 分裂域）；
- $\mathbb{Q}(\sqrt[3]2)/\mathbb{Q}$ **不正规**（另两根缺失）；
- $\mathbb{C}/\mathbb{R}$ 正规（$x^2 + 1$ 分裂域）。

## 4 公式解析：Galois 扩张 = 可分 + 正规

把「Galois 扩张」的定义从机制上拆透，它是第十一篇的总纲。

**定义（Galois 扩张）：** 有限可分正规扩张 $E/F$ 称为 **Galois 扩张**。等价地，$E$ 是「某个可分多项式在 $F$ 上的分裂域」。

- **第一步，为什么需要可分。** 可分保证「根的数目 = 多项式的次数」（无重根），根的置换才有 $n$ 个「身份分明」的对象可以置换。若根有重根，置换无从谈起。

- **第二步，为什么需要正规。** 正规保证「根的全家都在 $E$ 里」，Galois 群（$E$ 保持 $F$ 的自同构）才能作用于**全部**根。

- **第三步，合起来。** $E$ 是某个可分多项式 $f$ 的分裂域：$f$ 的根 $\alpha_1, \dots, \alpha_n$ 全部在 $E$ 里（正规），各不相同（可分），$E$ 由它们生成（分裂域）。于是「$E$ 保持 $F$ 的自同构」=「对根集合的置换」——**Galois 群嵌入 $S_n$**。

- **第四步，特征 0 的简化。** 特征 0 时可分自动，Galois 扩张 = 正规扩张 = 分裂域。$\mathbb{Q}$ 上的 Galois 理论因此不用操心可分性——**「$\mathbb{Q}$ 上分裂域」就是 Galois 扩张**。

## 5 例子：可分与正规的矩阵

把可分/正规的四种组合在具体扩张上对号入座。

| 扩张 | 可分？ | 正规？ | 类型 |
| --- | --- | --- | --- |
| $\mathbb{Q}(\sqrt2)/\mathbb{Q}$ | ✓ | ✓ | Galois |
| $\mathbb{Q}(\sqrt[3]2)/\mathbb{Q}$ | ✓ | ✗ | 可分非正规 |
| $\mathbb{Q}(\sqrt[3]2, \omega)/\mathbb{Q}$ | ✓ | ✓ | Galois（$x^3-2$ 分裂域） |
| $\mathbb{F}_p(t^{1/p})/\mathbb{F}_p(t)$ | ✗ | ✗ | 不可分非正规（纯不可分） |
| $\mathbb{F}_{p^n}/\mathbb{F}_p$ | ✓ | ✓ | Galois（有限域） |

**观察**：可分性在特征 0 全真，正规性则要看「根是否齐全」。**Galois 扩张是「可分 + 正规」的交集**——特征 0 下就是「分裂域」；特征 $p$ 下还需排除纯不可分的情形。<span class="marginnote">有限域 $\mathbb{F}_{p^n}/\mathbb{F}_p$ 是「最干净的 Galois 扩张」：可分（$x^{p^n} - x$ 无重根）、正规（是它的分裂域）、Galois 群是 $n$ 阶循环群（Frobenius 自同构生成）。下一篇《有限域》与第十一篇 Galois 理论将以它为样板。</span>

## 6 小结

- **可分多项式**：无重根；$f$ 与 $f'$ 互素；特征 0 时一切不可约多项式可分。
- **可分扩张**：每个元素都可分；特征 0 自动成立，特征 $p$ 里 $x^p - t$ 是反例。
- **正规扩张**：一个根进来全家根进来；有限正规 ⟺ 分裂域。
- **Galois 扩张 = 可分 + 正规** = 某个可分多项式的分裂域。
- $\mathbb{Q}(\sqrt[3]2)/\mathbb{Q}$ 可分但非正规；$\mathbb{F}_{p^n}/\mathbb{F}_p$ 是完美的 Galois 扩张。

在下一节，我们构造并分类有限域：**有限域（伽罗瓦域）的存在唯一性与结构**。$\mathbb{F}_{p^n}$ 的存在性、唯一性与 Galois 群，是有限域理论的王冠。
