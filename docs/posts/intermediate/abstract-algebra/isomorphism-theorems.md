## 为什么从同构定理开始

上一节的群同态基本定理 $G/\ker f \cong \operatorname{Im} f$ 常被称为**第一同构定理**。但它不是孤立的一条——它有两个兄弟：**第二同构定理**处理「子群与正规子群之间的商如何互算」，**第三同构定理（对应定理）**处理「商群的子群与原群的子群如何一一对应」。

三条定理合在一起，构成群论里最像「算术」的一块：商群之间的等式可以像分数一样相消、通分。**同构定理的价值是「换算自由」**：一个看起来陌生的商群，总能改写成熟悉的形状。本节把三条定理的陈述、证明、与相互联系一次讲清，并展示它们在有限群分类与子群格分析中的实际威力。

## 1 回顾与总览：三条定理各管一件事

先摆出三兄弟的全貌，再逐个拆解。

**定理（第一同构定理 / First Isomorphism Theorem）：** $f : G \to H$ 同态 ⟹ $G/\ker f \cong \operatorname{Im} f$。（上一节已证。）

**定理（第二同构定理 / Second Isomorphism Theorem）：** 设 $H \le G$，$N \trianglelefteq G$，则

$$
HN / N \ \cong \ H / (H \cap N)
$$

直观版：**「$H$ 与 $N$ 合并后再压掉 $N$」等于「$H$ 压掉它与 $N$ 的交」。** 像约分：左边分子分母同乘 $N$ 的效果，被右边「交」出来。

**定理（第三同构定理 / Third Isomorphism Theorem）：** 设 $N \trianglelefteq G$，$N \le K \trianglelefteq G$，则

$$
(G / N) \big/ (K / N) \ \cong \ G / K
$$

直观版：**「先压 $N$ 再压 $K/N$」等于「一步压 $K$」。** 像分数的连续相消：$\frac{G/N}{K/N} = \frac{G}{K}$。<span class="marginnote">把第三同构定理写成「分数」形式格外好记：$(G/N) / (K/N) = G/K$，分子分母同时「除以 $N$」可以相消。同构定理之所以被比作「群的算术」，正是因为这些相消、约分规则和分数的运算法则几乎一模一样——当然，这里的「除以」都要按正规子群与商群理解。</span>

## 2 第二同构定理：HN/N ≅ H/(H∩N)

**证明：** 取映射 $f : H \to HN/N$，$f(h) = hN$。验证：

**$f$ 是同态**：$f(h_1h_2) = h_1h_2N = (h_1N)(h_2N) = f(h_1)f(h_2)$；
**$f$ 是满射**：$HN/N$ 中任意元素 $(hn)N = hN = f(h)$（$hnN = hN$ 因为 $n \in N$），所以每个陪集都来自某个 $h$；
**$\ker f$**：$f(h) = N \iff hN = N \iff h \in N$，故 $\ker f = H \cap N$。

由第一同构定理，$H / (H \cap N) \cong HN/N$。$\blacksquare$<span class="marginnote">证明又一次是「构造满同态 + 套第一同构定理」的流水线。核心是 $hnN = hN$ 这一步：$N$ 的元素混进陪集不改变陪集（因为 $nN = N$），这让 $f$ 天然满射。第二同构定理也可以读成：<strong>「$HN$ 里的 $N$ 分量可以被吸收掉」</strong>。</span>

**例：** 取 $G = S_3$，$N = A_3$，$H = \langle (1\ 2) \rangle$。则 $HN = S_3$（$H$ 与 $N$ 合起来生成整个 $S_3$），$H \cap N = \{e\}$。第二同构定理给出 $S_3/A_3 \cong \langle (1\ 2) \rangle / \{e\} \cong \mathbb{Z}_2$——两个视角都得到同一个答案：$\mathbb{Z}_2$。

**辨析｜易错点：** 第二同构定理要求 $N$ 正规（在 $G$ 中），$H$ 只要求是子群。$HN$ 是子群这件事本身要依赖 $N$ 正规（或 $HN = NH$）；若 $N$ 不正规，$HN$ 甚至不一定是子群。使用时先检查「谁是正规的」。

## 3 第三同构定理：(G/N)/(K/N) ≅ G/K

**证明：** 设 $\pi : G \to G/K$ 是自然同态。考虑复合 $\pi \circ \pi_N$ 的路径，或用「穿过商」的语言：定义

$$
\varphi : G/N \to G/K, \qquad \varphi(gN) = gK
$$

- **良定义**：若 $g_1N = g_2N$，则 $g_1^{-1}g_2 \in N \le K$，故 $g_1K = g_2K$；$\varphi$ 无歧义。
- **满同态**：满射显然；同态性 $\varphi(g_1N \cdot g_2N) = \varphi(g_1g_2N) = g_1g_2K = (g_1K)(g_2K)$。
- **核**：$\varphi(gN) = K \iff gK = K \iff g \in K$，故 $\ker \varphi = \{ gN \mid g \in K \} = K/N$。

由第一同构定理 $(G/N)/(K/N) \cong G/K$。$\blacksquare$<span class="marginnote">第三同构定理的证明每一步都是「把问题翻译到更粗的商群上」：$\varphi$ 把 $G/N$ 里的元素（$N$ 的陪集）再压一次，压成 $K$ 的陪集。核 $K/N$ 正是「$G/N$ 里落在 $K$ 中的那些陪集」——先压 $N$、再压一层，等于一步压 $K$。</span>

**例：** 取 $G = \mathbb{Z}$，$N = 6\mathbb{Z}$，$K = 2\mathbb{Z}$（$6\mathbb{Z} \le 2\mathbb{Z} \le \mathbb{Z}$）。第三同构定理给出

$$
(\mathbb{Z}/6\mathbb{Z}) \big/ (2\mathbb{Z}/6\mathbb{Z}) \cong \mathbb{Z}/2\mathbb{Z}
$$

即 $\mathbb{Z}_6 / \{0, 2, 4\} \cong \mathbb{Z}_2$——「模 6 再模 2」与「直接模 2」殊途同归。

## 4 第三同构定理的子群对应版本（对应定理）

第三同构定理还有一个姊妹版本，刻画「商群的子群长什么样」，在有限群分类与伽罗瓦理论（第十一篇）中反复使用。

**定理（对应定理 / Correspondence Theorem）：** 设 $N \trianglelefteq G$。映射 $K \mapsto K/N$ 建立了「$G$ 中包含 $N$ 的子群」与「$G/N$ 的全部子群」之间的一一对应，且保持包含关系与指数：

$$
K \le L \iff K/N \le L/N, \qquad [L : K] = [L/N : K/N]
$$

**例：** $G = \mathbb{Z}$，$N = n\mathbb{Z}$。包含 $n\mathbb{Z}$ 的子群是 $d\mathbb{Z}$ 其中 $d \mid n$（第三篇），对应到 $\mathbb{Z}_n = \mathbb{Z}/n\mathbb{Z}$ 的子群 $\langle \bar{d} \rangle$——这正坐实了「$\mathbb{Z}_n$ 的子群按 $n$ 的因子排列」这一结论。**对应定理把「循环群子群结构」升级成一般定理：商的子群 = 原群的「中间层」。**<span class="marginnote">对应定理是「分层」语言：群 $G$ 的顶层结构 $G/N$ 的每一层，都对应 $G$ 里夹在 $N$ 与 $G$ 之间的某一层。伽罗瓦理论里，这个对应升级为「Galois 群子群 ↔ 中间域」的华丽双向对应——那是第十一篇的高潮。</span>

**特别地**，$G/N$ 没有非平凡子群 ⟺ $N$ 是 $G$ 的**极大正规子群**。这为「单群」提供了一种等价描述：$G$ 单 ⟺ $G$ 除了 $\{e\}$、$G$ 外无正规子群 ⟺ 一切同态要么嵌入要么压成一点。单群的语言在有限单群分类与 Galois 理论中都是高频出现。

## 5 公式解析：三个定理的「家族相似性」

把三条定理放在一起，能看出一个共同模板：**「商掉某个东西」与「同构」之间的换算。**

- **第一同构定理：** $G/\ker f \cong \operatorname{Im} f$。模板：同态的商 = 像。
- **第二同构定理：** $HN/N \cong H/(H \cap N)$。模板：先并再商 = 商后再并（约分）。
- **第三同构定理：** $(G/N)/(K/N) \cong G/K$。模板：连续商 = 一次大商（相消）。

**共同的证明骨架**（以第三同构定理为例拆解）：

- **第一步，找对「商」的映射。** 从 $G/N$ 打到 $G/K$ 的自然候选是「再压一层」：$\varphi(gN) = gK$。这一步的关键是意识到 $K/N$ 恰是 $G/N$ 的一个子群（由对应定理或直接验证）。

- **第二步，验证良定义。** $g_1^{-1}g_2 \in N \subseteq K$，所以「按 $N$ 分在同一组」的元素，「按 $K$ 分」也必然在同一组——压缩相容。**嵌套正规子群 $N \le K$ 让「先细压后粗压」不冲突**。

- **第三步，算核。** $\ker \varphi = \{ gN : g \in K \} = K/N$。于是 $\varphi$ 的核正是「$G/N$ 中来自 $K$ 的部分」。

- **第四步，套第一同构定理。** $(G/N)/(K/N) \cong G/K$。$\blacksquare$ 三个定理共享「构造满同态 → 算核 → 套第一同构定理」的流水线，区别只在映射的选取——**第一同构定理是发动机，第二、第三是它的两个配件。**

## 6 小结

- **第一同构定理**：$G/\ker f \cong \operatorname{Im} f$——发动机。
- **第二同构定理**：$HN/N \cong H/(H\cap N)$，$H \le G$、$N \trianglelefteq G$；「并后商 = 商后交」。
- **第三同构定理**：$(G/N)/(K/N) \cong G/K$，$N \le K \trianglelefteq G$；「连续商 = 一次商」。
- **对应定理**：$K \mapsto K/N$ 是「含 $N$ 子群」与「$G/N$ 子群」的双射，保持包含与指数。
- 三兄弟共用模板：构造满同态 → 算核 → 套第一同构定理。

在下一节，我们进入有限群理论最有力的工具：**群在集合上的作用（Group Action）**。群作用把「群」与「它所作用的对象」绑在一起，轨道、稳定子、不动点在此汇成体系，西罗定理的大门即将打开。
