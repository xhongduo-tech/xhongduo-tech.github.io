## 为什么从带余除法开始

整数的除法有「商和余数」，多项式在域上的除法也有：**带余除法（division algorithm）**。它说：$F$ 是域时，$F[x]$ 里任意 $f$ 除以非零 $g$，都有唯一的 $q, r$ 使 $f = gq + r$ 且 $\deg r < \deg g$。

这条定理是 $F[x]$ 的「欧氏环属性」的来源——它让 $F[x]$ 拥有与 $\mathbb{Z}$ 平行的全套分解理论（整除、不可约、UFD/PID）。它还直接给出**因子定理**：$f(a) = 0 \iff x - a \mid f$，以及「$F$ 上 $n$ 次多项式至多有 $n$ 个根」。本节把带余除法的过程、唯一性、综合除法（计算技巧）与三大推论讲透。

## 1 带余除法的定理

**定理（带余除法 / Division Algorithm）：** 设 $F$ 是域，$f, g \in F[x]$，$g \ne 0$。则存在唯一的多项式 $q, r \in F[x]$ 使

$$
f = gq + r, \qquad \deg r < \deg g \ (\text{或 } r = 0)
$$

$q$ 称为**商**，$r$ 称为**余数**。

**存在性（过程）：** 若 $\deg f < \deg g$，取 $q = 0$、$r = f$。否则设 $f$ 首项 $a x^n$、$g$ 首项 $b x^m$（$n \ge m$），做「消首项」：

$$
f_1 = f - \frac{a}{b} x^{n-m} g
$$

$f_1$ 的次数 < $n$（首项被消）。对 $f_1$ 递归套用，次数严格递减，有限步后次数 < $\deg g$，得 $r$。把减去的部分累加成 $q$。$\blacksquare$<span class="marginnote">带余除法的过程就是「长除法」：每次用 $\frac{a}{b}x^{n-m} g$ 消掉 $f$ 的最高次项。关键是系数 $\frac{a}{b}$——它需要 $F$ 是<strong>域</strong>（$b \ne 0$ 可逆）。若系数环只是整环（如 $\mathbb{Z}$），除以首项系数不一定可行，带余除法只在「首项系数可逆」时成立。这就是 $F[x]$ 与 $\mathbb{Z}[x]$ 的本质差别。</span>

**唯一性：** 若 $f = gq + r = gq' + r'$（$\deg r, \deg r' < \deg g$），则 $g(q - q') = r' - r$。若 $q \ne q'$，$\deg g + \deg(q-q') = \deg(r'-r) < \deg g$，矛盾；故 $q = q'$、$r = r'$。

## 2 例：手算一次带余除法

**例：** $F = \mathbb{Q}$，$f = 2x^3 + 3x^2 + 1$，$g = x^2 + 1$。

- 首项：$2x^3$ 除以 $x^2$ 得 $2x$。$f - 2x(x^2 + 1) = 2x^3 + 3x^2 + 1 - 2x^3 - 2x = 3x^2 - 2x + 1$。
- 首项：$3x^2$ 除以 $x^2$ 得 $3$。$(3x^2 - 2x + 1) - 3(x^2 + 1) = -2x - 2$。
- 余数 $-2x - 2$ 次数 < 2，停止。

所以 $q = 2x + 3$，$r = -2x - 2$，验证：$(x^2 + 1)(2x + 3) + (-2x - 2) = 2x^3 + 3x^2 + 2x + 3 - 2x - 2 = 2x^3 + 3x^2 + 1 = f$。$\checkmark$

## 3 因子定理与根定理

带余除法的第一波收获是「根」的理论。

**定理（因子定理 / Factor Theorem）：** 设 $F$ 是域，$f \in F[x]$，$a \in F$。则

$$
f(a) = 0 \iff x - a \mid f
$$

**证明：** 带余除法：$f = (x - a)q + r$，$\deg r < 1$，故 $r$ 是常数。代入 $x = a$：$f(a) = (a - a)q(a) + r = r$。于是 $f(a) = 0 \iff r = 0 \iff f$ 被 $x - a$ 整除。$\blacksquare$<span class="marginnote">因子定理的证明只用了「余数是常数 + 代入消去」两件事。它把「$a$ 是根」翻译成「$x - a$ 是因子」——代数与方程的第一次正式握手。中学生就知道的「试根法」（试出根就提一个因子），背后的定理就是它。</span>

**定理（根数上界）：** 域 $F$ 上非零 $n$ 次多项式在 $F$ 中至多有 $n$ 个根。

**证明（归纳）：** $n = 0$ 平凡。设 $f$ 有根 $a_1$，因子定理 $f = (x - a_1) f_1$。$f$ 的其他根不能是 $a_1$，都是 $f_1$ 的根；$f_1$ 次数 $n - 1$，归纳。$\blacksquare$

**推论：** 若 $f, g$ 次数 ≤ $n$ 且在 ≥ $n+1$ 个点上取值相同，则 $f = g$（$f - g$ 有太多根）。这解释了有限域上「多项式函数相同 ⟹ 多项式相同」（当次数 < 域大小时），但次数大时可能失真（$\mathbb{F}_2$ 上 $x^2 = x$ 作为函数）。

## 4 公式解析：综合除法的机械过程

带余除法除以一次多项式 $(x - a)$ 时，可以大幅简化成**综合除法（synthetic division）**。

**例：** $f = 2x^3 - 3x^2 + 4x - 5$ 除以 $x - 2$。

- **第一步，列系数表。** 按降次写系数 $[2, -3, 4, -5]$，把 $a = 2$ 放左侧（注意 $x - a$ 中 $a$ 的符号：除以 $x - 2$ 用 $a = 2$）。

- **第二步，下行。** 首系数 $2$ 直接抄下；$2 \times 2 = 4$ 加到 $-3$ 上得 $1$；$1 \times 2 = 2$ 加到 $4$ 上得 $6$；$6 \times 2 = 12$ 加到 $-5$ 上得 $7$。

$$
\begin{array}{c|cccc} 2 & 2 & -3 & 4 & -5 \\ & & 4 & 2 & 12 \\ \hline & 2 & 1 & 6 & 7 \end{array}
$$

- **第三步，读出结果。** 最后一行除末项外是商系数：$q = 2x^2 + x + 6$，末项 $7$ 是余数。验证：$f = (x - 2)(2x^2 + x + 6) + 7$。$\checkmark$

- **第四步，为什么省力。** 综合除法把「消首项」的除法变成「乘法 + 加法」的迭代：每个步骤都是「上一行 × $a$ + 本系数」。它直接输出 $f(a)$ 作为余数——**综合除法同时算「除法」与「函数值」**，在数值计算（Horner 算法）与多项式求值里效率极高。

## 5 例：带余除法在结构里的角色

带余除法不只是计算技巧，它是 $F[x]$ 一系列结构定理的引擎。

- **求值同态的核**：$\ker \varphi_a = \langle x - a \rangle$（$f(a) = 0 \iff x - a \mid f$，因子定理）；
- **$F[x]$ 是欧氏环**：次数 $\deg$ 充当欧氏函数，带余除法正是欧氏算法——第九篇《欧氏整环》将说明 $F[x]$ 与 $\mathbb{Z}$ 同属一族；
- **$F[x]$ 是 PID**：任何理想由「最小次数非零元素」生成（带余除法保证「余数次数更小」的矛盾）；<span class="marginnote">「$F[x]$ 是 PID」的证明与「$\mathbb{Z}$ 是 PID」完全平行：取理想 $I$ 中最小次数的 $g$，任意 $f \in I$ 做带余除法 $f = gq + r$，若 $r \ne 0$ 则 $\deg r < \deg g$ 且 $r = f - gq \in I$，与 $g$ 最小矛盾，故 $r = 0$，$f \in \langle g\rangle$。<strong>「取最小次数元素 + 带余除法矛盾」是 PID 证明的标准两件套。</strong></span>
- **中国剩余定理在 $F[x]$**：$\langle x - a_i \rangle$ 互素时 $F[x]/\langle \prod(x - a_i)\rangle \cong F^k$（插值）。

## 6 对照速查：带余除法的三大推论

把带余除法的直接果实排成一张表，每一条都是 $F[x]$ 结构理论的钥匙。

| 推论 | 陈述 | 用途 |
| --- | --- | --- |
| 因子定理 | $f(a) = 0 \iff x - a \mid f$ | 试根提因子 |
| 根数上界 | $n$ 次多项式至多 $n$ 个根 | 插值唯一性、恒等判定 |
| 欧氏环性 | $F[x]$ 是欧氏环（次数为欧氏函数） | 欧氏算法、gcd、PID |
| 求值核 | $\ker \varphi_a = \langle x - a \rangle$ | 商环、中国剩余定理 |

**数值算例：用综合除法求 $f(3)$（Horner 求值）。** $f = 2x^3 - 3x^2 + 4x - 5$，除以 $x - 3$：系数 $[2, -3, 4, -5]$，$a = 3$。$2$ 抄下；$2 \times 3 = 6$ 加到 $-3$ 得 $3$；$3 \times 3 = 9$ 加到 $4$ 得 $13$；$13 \times 3 = 39$ 加到 $-5$ 得 $34$。余数 $34 = f(3)$。验证：$2(27) - 3(9) + 4(3) - 5 = 54 - 27 + 12 - 5 = 34$。$\checkmark$<span class="marginnote">综合除法同时是「除法机」与「求值机」：除以 $x - a$ 的余数恰是 $f(a)$。这条「余数定理」让 Horner 算法成为数值计算里最高效的多项式求值方式——每次只做一次乘法一次加法，$n$ 次多项式 $O(n)$ 步求值。综合除法 = 因子定理 + 求值的合体。</span>

**易错辨析｜带余除法需要「首项系数可逆」。** $F$ 是域时一切非零系数可逆，$F[x]$ 带余除法畅通。但 $\mathbb{Z}[x]$ 里 $2x$ 除以 $x^2$ 就不行（首项系数 $1$ 无法被 $2$ 除尽）——$\mathbb{Z}[x]$ 不是欧氏环（次数函数不够）。「带余除法」与「系数环是域」是绑定的：换成整环，除法就残缺。

**一句话记法**：带余除法 = $F[x]$ 的引擎；因子定理管根、次数管上界、欧氏性管结构；综合除法 = 又快又准的算盘。

## 7 小结

- **带余除法**：$f = gq + r$，$\deg r < \deg g$，$q, r$ 唯一；需要 $F$ 是域。
- **过程**：逐次「消首项」，次数严格递减；唯一性靠次数矛盾。
- **因子定理**：$f(a) = 0 \iff x - a \mid f$；$n$ 次多项式至多 $n$ 个根。
- **综合除法**：除以 $x - a$ 的快速表算，商系数 + 余数（即 $f(a)$）一次得到。
- **结构角色**：$F[x]$ 是欧氏环、PID；求值同态核 = $\langle x - a \rangle$；插值 = 多项式 CRT。

在下一节，我们开始整环的分解语言：**整除、单位与相伴元**。这些概念是「唯一分解」的地基，把整数的整除性抽象到任意整环。
