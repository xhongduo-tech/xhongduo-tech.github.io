## 为什么从单位元、可逆元与零因子开始

环的乘法比加法「弱」，弱在哪？两个现象：**可逆元**（乘法有逆的元素）只是少数，**零因子**（乘出零却本身非零的元素）却不请自来。一个环的性质，很大程度上由「谁可逆、谁作孽」决定。

这一对概念是环论与数论的分水岭：整数环里可逆元只有 $\pm 1$、无零因子；模 $n$ 环里可逆元由 $\gcd$ 判定、零因子由合数造成；矩阵环里可逆元是 $GL_n$、零因子遍地。理解「可逆元构成乘法群、零因子使消去律失效」这两条主线，就能读懂环的「算术地形」。本节把单位元、可逆元、零因子、可逆元群 $R^\times$ 讲透，并给出它们在整环/域判定中的角色。

## 1 可逆元与单位群

**可逆元（unit）**：设 $R$ 是含幺环，$u \in R$。若存在 $v \in R$ 使 $uv = vu = 1_R$，则称 $u$ 是**可逆元**（unit），$v$ 称为 $u$ 的逆元，记作 $v = u^{-1}$。

**定理（单位群）：** $R$ 的全体可逆元在乘法下构成一个群，记作 $R^\times$（或 $U(R)$）。

验证：可逆元之积可逆（$(uv)^{-1} = v^{-1}u^{-1}$）、可逆元之逆可逆、$1_R$ 可逆——三条群公理俱备。**$R^\times$ 是「乘法的精华」**：它是在 $R$ 里能自由除法的最大子集。<span class="marginnote">记号 $R^\times$ 与「零去心」的记号（如 $\mathbb{R}^\ast$）含义一致：$R^\times$ 就是「$R$ 中可逆的部分」。在域 $F$ 上 $F^\times = F \setminus \{0\}$（域的每个非零元可逆）；但在一般环上 $R^\times \subsetneq R \setminus \{0\}$——中间被零因子挤掉了。</span>

**例：**
$\mathbb{Z}^\times = \{ 1, -1 \}$（整数里只有 $\pm 1$ 可逆）；
$\mathbb{Z}_n^\times = \{ \bar k \mid \gcd(k, n) = 1 \}$——模 $n$ 可逆元恰是与 $n$ 互素的剩余类，$|\mathbb{Z}_n^\times| = \varphi(n)$（欧拉函数）；
$M_n(\mathbb{R})^\times = GL_n(\mathbb{R})$（可逆矩阵）；
域 $F$ 上 $F^\times = F \setminus \{0\}$。

**可逆元的「gcd 判定」**（$\mathbb{Z}_n$ 情形的证明）：$\bar k$ 可逆 ⟺ 存在 $l$ 使 $kl \equiv 1 \pmod n$ ⟺ $\gcd(k, n) = 1$（裴蜀定理：$\gcd(k,n) = 1$ 时存在 $kl + mn = 1$）。这是数论与环论交会的第一处——**可逆性 = 互素性**。

## 2 零因子：乘法的「崩坏」

**零因子（zero divisor）**：设 $R$ 是含幺环。非零元素 $a$ 称为**零因子**，若存在非零 $b$ 使 $ab = 0$ 或 $ba = 0$。左零因子与右零因子之分：$ab = 0$（$b \ne 0$）时 $a$ 是左零因子；$ba = 0$ 时 $a$ 是右零因子。交换环里左右不分。<span class="marginnote">零因子的名字来自「相乘得零」：两个非零元素一碰，竟磨出 $0$。$2$ 与 $3$ 在 $\mathbb{Z}_6$ 里是零因子（$2 \cdot 3 = 6 \equiv 0$）；矩阵 $A = \begin{pmatrix}1&0\\0&0\end{pmatrix}$ 是 $M_2(\mathbb{R})$ 的零因子（$A \cdot \begin{pmatrix}0&0\\0&1\end{pmatrix} = 0$）。零因子是「乘法崩坏」的源头。</span>

**零因子与消去律**：**环里乘法消去律成立 ⟺ 环无零因子。**
若 $ab = ac$ 且 $a \ne 0$，则 $a(b - c) = 0$；无零因子时 $b - c = 0$，$b = c$；
反之若 $a$ 是零因子（$ab = 0$，$b \ne 0$），则 $ab = a \cdot 0$ 但 $b \ne 0$——消去律失败。

所以「$\mathbb{Z}_6$ 里 $2 \cdot 3 = 2 \cdot 0$ 却不消去」正是零因子在作祟。<span class="marginnote">消去律 ⟺ 无零因子是环论的一等定理：它把「乘法能不能约」这个算术问题翻译成「有没有零因子」这个结构问题。整数、多项式、域上消去律畅通，因为它们都无零因子；模合数环、矩阵环则消去律处处失效。判断一个环「好不好用」，先看零因子。</span>

**例：**
$\mathbb{Z}$ 无零因子；$\mathbb{Z}_p$（$p$ 素数）无零因子；$\mathbb{Z}_n$（$n$ 合数）有零因子；
$M_n(\mathbb{R})$（$n \ge 2$）有零因子；
函数环 $\mathcal{F}(\mathbb{R}, \mathbb{R})$ 有零因子（两个函数支集不交时乘积恒为 0）。

## 3 可逆元与零因子的对立

可逆元与零因子是「两个不相容的阵营」。

**定理：** 可逆元不可能是零因子。

证明：若 $u$ 可逆且 $ub = 0$，则 $b = u^{-1}(ub) = u^{-1} \cdot 0 = 0$，故 $b = 0$——$u$ 不可能是（左）零因子。$\blacksquare$

于是每个含幺环的 $R \setminus \{0\}$ 被分成三派：**可逆元**（乘法畅通）、**零因子**（乘法崩坏）、**既不可逆也不为零因子**的元素（如 $\mathbb{Z}$ 里的 $2$——不可逆但也不是零因子）。<span class="marginnote">$\mathbb{Z}$ 里的 $2$ 是「中间派」的样板：它不是零因子（$2b = 0 \Rightarrow b = 0$），也不可逆（$2^{-1} \notin \mathbb{Z}$）。在域里中间派不存在（非零即可逆）；在 $\mathbb{Z}_6$ 里中间派也不存在（$1,5$ 可逆，$2,3,4$ 是零因子）。「三派共存」是 $\mathbb{Z}$ 这类「非域的整环」的特色。</span>

**定理（有限环里的两分法）：** 有限含幺环 $R$ 中，**非零元素要么可逆、要么是零因子**——没有中间派。

证明：固定 $a \ne 0$，考虑映射 $x \mapsto ax$（左乘）。若 $a$ 不是左零因子，则 $x \mapsto ax$ 是单射（$ax = ay \Rightarrow a(x-y) = 0 \Rightarrow x = y$），有限集上单射即满射，故存在 $u$ 使 $au = 1$；再考虑 $x \mapsto xa$ 得 $va = 1$，可逆性随之。$\blacksquare$

**推论：** 有限整环必是域。这是环论最优雅的定理之一：**有限 + 无零因子 ⟹ 每个非零元可逆 ⟹ 域。** $\mathbb{Z}_p$ 因此是域，而 $\mathbb{Q}, \mathbb{R}, \mathbb{C}$ 是无限的域。

## 4 公式解析：Z_n 里的可逆元与零因子

把可逆元与零因子放到模 $n$ 环 $\mathbb{Z}_n$ 里算清楚，全部概念一次落地。

**定理：** 在 $\mathbb{Z}_n$ 中：

1. $\bar k$ 可逆 ⟺ $\gcd(k, n) = 1$；
2. $\bar k$（$k \ne 0$）是零因子 ⟺ $\gcd(k, n) > 1$。

**第一步，可逆 ⟺ 互素。** $\bar k$ 可逆 ⟺ 存在 $l$ 使 $kl \equiv 1 \pmod n$ ⟺ $\gcd(k, n) \mid 1$ ⟺ $\gcd(k, n) = 1$。裴蜀定理把「同余方程 $kx \equiv 1$ 有解」翻译成「互素」——数论与环论的握手。

**第二步，零因子 ⟺ 不互素。** 若 $g = \gcd(k, n) > 1$，令 $k' = k/g$、$n' = n/g$（$n' < n$，非零），则 $\bar k \cdot \bar{n'} = \overline{k n'} = \overline{k \cdot \frac{n}{g}} = \overline{n \cdot \frac{k}{g}} = \bar 0$（模 $n$），故 $\bar k$ 是零因子。反之若 $\bar k$ 可逆则不可能为零因子。**有限环的两分法在 $\mathbb{Z}_n$ 上精确兑现。**

**第三步，统计。** $|\mathbb{Z}_n^\times| = \varphi(n)$（互素类个数）；零因子个数 $= n - \varphi(n) - 1$（去掉 0 与可逆元）。

**第四步，实例。** $\mathbb{Z}_6$：可逆元 $\{1, 5\}$（$\varphi(6) = 2$），零因子 $\{2, 3, 4\}$（$2\cdot 3 = 0$、$4 \cdot 3 = 0$）。$\mathbb{Z}_7$（$7$ 素数）：可逆元 $\{1,2,3,4,5,6\}$（全部非零元，域！），零因子无——$\mathbb{Z}_7$ 是域。

## 5 可逆元与零因子在「环的层级」里的角色

把可逆元与零因子装回「环 → 整环 → 域」的升级链，它们正是分级的判据。

| 环的层级 | 可逆元情况 | 零因子情况 | 判据要点 |
| --- | --- | --- | --- |
| 环 | 可能极少 | 可能很多 | — |
| 含幺环 | $1_R$ 至少可逆 | 可能有 | — |
| 整环 | 可能有多个 | **无** | 无零因子是核心 |
| 域 | 全部非零元可逆 | 无 | 可逆性全开 |
| 除环 | 全部非零元可逆（可不交换） | 无 | 可逆性全开但不交换 |

**整环（integral domain）**：交换含幺环且无零因子。**域**：每个非零元可逆的环（交换时 = 整环 + 全可逆）。**除环（division ring）**：非零元全可逆但不要求交换。<span class="marginnote">升级链的判定：整环「卡死零因子」，域/除环「打开全部可逆」。四元数 $\mathbb{H}$ 是除环非域的经典例子（非交换但每个非零元可逆）。下一节《整环、除环与域》将系统讲清这三个层级——可逆元与零因子是分级的全部判据。</span>

**应用（密码学伏笔）**：RSA 的加密/解密依赖 $\mathbb{Z}_{\varphi(n)}$ 与 $\mathbb{Z}_n^\times$ 的结构（第十二篇）；有限域 $\mathbb{F}_{2^8}$ 里 AES 的字节运算要求每个非零字节可逆（S-box 计算零因子不可逆）。可逆元的分布 = 密码系统的安全性基础。

## 6 对照速查：可逆元与零因子的分布

把「可逆 / 零因子 / 中间派」在几个环里的分布排成一张总表。

| 环 | 可逆元 | 零因子 | 中间派 |
| --- | --- | --- | --- |
| $\mathbb{Z}$ | $\pm 1$ | 无 | 有（$2$） |
| $\mathbb{Z}_p$（素数） | 全部非零元 | 无 | 无 |
| $\mathbb{Z}_6$ | $\{1, 5\}$ | $\{2, 3, 4\}$ | 无 |
| $M_2(\mathbb{R})$ | $GL_2$ | 有（秩 1 矩阵） | 有 |
| 域 $F$ | $F^\times$ | 无 | 无 |

**数值算例：$\mathbb{Z}_9$ 里的可逆元与零因子。** $\mathbb{Z}_9^\times = \{\bar k \mid \gcd(k, 9) = 1\} = \{1, 2, 4, 5, 7, 8\}$，共 $\varphi(9) = 6$ 个。零因子：$\gcd(k, 9) > 1$ 的非零 $k$，即 $3, 6$（$3 \cdot 3 = 9 \equiv 0$、$6 \cdot 6 = 36 \equiv 0$）。有限环两分法核对：$6 + 2 + 1 = 9$。$\checkmark$<span class="marginnote">「$|\mathbb{Z}_n^\times| = \varphi(n)$」把可逆元计数交给欧拉函数；零因子恰好补上「不互素」的那部分。RSA 加密选 $e$ 与 $\varphi(n)$ 互素、用扩展欧几里得求 $d$——可逆元理论正是 RSA 的全部代数骨架（第十二篇）。</span>

**一句话记法**：可逆元 = 乘法的精华（$R^\times$ 是群）；零因子 = 乘法的崩坏（消去律失效）；有限环里非零元非可逆即零因子；「可逆 ⟺ 互素」在 $\mathbb{Z}_n$ 里精确成立。

## 7 小结

- **可逆元** $u$：存在 $u^{-1}$ 使 $uu^{-1} = 1$；全体构成单位群 $R^\times$。
- **零因子** $a$：存在 $b \ne 0$ 使 $ab = 0$；零因子使消去律失效。
- **消去律 ⟺ 无零因子**；可逆元不可能是零因子。
- **有限环两分法**：非零元素要么可逆要么是零因子 ⟹ 有限整环是域。
- **$\mathbb{Z}_n$**：$\bar k$ 可逆 ⟺ $\gcd(k,n)=1$，零因子 ⟺ $\gcd(k,n)>1$；$|\mathbb{Z}_n^\times| = \varphi(n)$。
- 可逆元/零因子是「环 → 整环 → 域」分级的关键判据。

在下一节，我们把分级判据组装成三个重要的环类：**整环、除环（体）与域**。这三个层级是环论地图上的主干道，也是通往多项式分解与域扩张理论的必经之路。
