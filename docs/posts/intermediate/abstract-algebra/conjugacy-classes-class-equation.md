## 为什么从共轭类与类方程开始

第二篇我们初识共轭类，第五篇的群作用给共轭提供了完整框架：**共轭就是 $G$ 在自身上的作用**，共轭类就是它的轨道，中心化子就是稳定子，中心元素就是单点轨道。现在把这些观察用轨道-稳定子定理武装起来，得到有限群理论第一台「显微镜」——**类方程（class equation）**：

$$
|G| = |Z(G)| + \sum_{i} [G : C_G(a_i)]
$$

类方程把群的阶按「不可交换的程度」分解成精确的小块。它看似只是计数，却是有限群分析的中枢：**$p$ 群必有非平凡中心**、**$p^2$ 阶群必交换**、**$pq$ 阶群的结构**、西罗定理的若干步，全都从类方程「榨」出来。本节把类方程的推导、用法与典型计算彻底讲透。

## 1 从群作用到类方程

把轨道-稳定子定理装进「共轭作用」这个具体舞台。

**共轭作用**：$G$ 作用在 $X = G$（自身）上，$g \cdot x = gxg^{-1}$。于是：
- **轨道** $G \cdot x = \{ gxg^{-1} \} = \mathrm{cl}(x)$——共轭类；
- **稳定子** $G_x = \{ g \mid gxg^{-1} = x \} = \{ g \mid gx = xg \} = C_G(x)$——中心化子；
- **不动点** $X^g = \{ x \mid gxg^{-1} = x \} = C_G(g)$——中心化子是「不动点集」。

轨道-稳定子定理给出 $|\mathrm{cl}(x)| = [G : C_G(x)]$——**共轭类大小 = 中心化子的指标**。<span class="marginnote">这是「中心化子 ↔ 共轭类」的精确对偶：中心化子越大（越多人能跟 $x$ 对易），共轭类越小（$x$ 越难被搬动）。极端时 $x \in Z(G)$，中心化子就是整个 $G$，共轭类缩成单点。第二篇的直觉「中心 = 自成一类的元素」，现在有了完整的机制。</span>

**定理（类方程）：** 设 $G$ 是有限群，$a_1, \dots, a_k$ 取遍所有非中心共轭类的代表元，则

$$
|G| = |Z(G)| + \sum_{i=1}^{k} [G : C_G(a_i)]
$$

**证明：** 共轭类剖分 $G$（等价类），故 $|G| = \sum_{\text{类}} |\mathrm{cl}(x)|$。把「单点类」单独提出（单点类恰来自 $Z(G)$），其余用 $|\mathrm{cl}(a_i)| = [G : C_G(a_i)]$ 代入即得。$\blacksquare$

## 2 类方程的第一个果实：p 群有非平凡中心

**定理：** 若 $|G| = p^n$（$p$ 素数，$n \ge 1$），则 $Z(G) \neq \{e\}$。

**证明：** 类方程逐项模 $p$。左端 $|G| = p^n \equiv 0 \pmod p$；对每个非中心类，$|\mathrm{cl}(a_i)| = [G : C_G(a_i)]$ 是 $>1$ 的 $p$-幂（因为 $C_G(a_i)$ 真包含于 $G$ 时指标是 $p$ 的幂），故 $[G : C_G(a_i)] \equiv 0 \pmod p$。于是 $|Z(G)| \equiv 0 \pmod p$。而 $|Z(G)| \ge 1$（至少含 $e$），故 $|Z(G)| \ge p$，$Z(G) \neq \{e\}$。$\blacksquare$<span class="marginnote">这条定理是「模 $p$ 计数」的教科书示范：类方程两边模 $p$，非中心类全消失（都是 $p$ 的倍数），只剩下 $|Z(G)|$ 必须被 $p$ 整除。$p$ 群的非平凡中心是整个 $p$-群理论（下一节）的立足点——没有它，$p$ 群的归纳结构无从谈起。</span>

**推论：** $p^2$ 阶群是交换群。证明：$|Z(G)| \ge p$。若 $|Z(G)| = p^2$ 则 $G = Z(G)$ 交换；若 $|Z(G)| = p$，则 $G/Z(G)$ 是 $p$ 阶群故循环，由「$G/Z(G)$ 循环 ⟹ $G$ 交换」（第四篇），仍得 $G$ 交换。$\blacksquare$ 于是**所有 $p^2$ 阶群只有两种**：$\mathbb{Z}_{p^2}$ 与 $\mathbb{Z}_p \times \mathbb{Z}_p$。

## 3 类方程的计算：S3、D4 与 Q8

把类方程在几个具体群上完整算一遍。

**$S_3$**（6 阶）：共轭类 $\{e\}$、$\{(12),(13),(23)\}$、$\{(123),(132)\}$。$Z(S_3) = \{e\}$，类方程：

$$
6 = 1 + [S_3 : C_{S_3}((12))] + [S_3 : C_{S_3}((123))] = 1 + 3 + 2
$$

其中 $C_{S_3}((12)) = \{e, (12)\}$（阶 2，指标 3），$C_{S_3}((123)) = A_3$（阶 3，指标 2）。$\checkmark$<span class="marginnote">$S_3$ 的类方程 $6 = 1+3+2$ 是最小非交换群的「身份证」。注意类方程里的每一项都整除 $6$——这是轨道-稳定子定理的保证。读 $S_3$ 的类方程就像读它的「分子结构」：一个不可交换中心（1）、一对三胞胎对换（3）、一对孪生三循环（2）。</span>

**$D_4$**（8 阶）：$Z(D_4) = \{ e, r^2 \}$。共轭类：$\{e\}$、$\{r^2\}$、$\{r, r^3\}$、$\{s, sr^2\}$、$\{sr, sr^3\}$。类方程：

$$
8 = 2 + 2 + 2 + 2
$$

（除中心两个单点类外，四个类各含 2 个元素。）$\checkmark$

**$Q_8$**（四元数群，8 阶）：$Z(Q_8) = \{1, -1\}$。共轭类：$\{1\}$、$\{-1\}$、$\{i, -i\}$、$\{j, -j\}$、$\{k, -k\}$。类方程与 $D_4$ 同为 $8 = 2 + 2 + 2 + 2$——**$D_4$ 与 $Q_8$ 有相同的类方程，却不同构**（$Q_8$ 恰有一个二阶元素 $-1$，$D_4$ 有 5 个二阶元素）。**类方程不是同构不变量**，它是粗粒度指纹，同类方程可以来自不同群。

## 4 公式解析：类方程的两个「方向」

类方程既可以从「已知共轭类」反推群结构，也可以从「群结构」推算共轭类。拆开两个方向。

- **方向一（分解）：已知群，切共轭类。** 步骤：① 找 $Z(G)$；② 把非中心元素按共轭分组，取代表元 $a_i$；③ 对每个 $a_i$ 算中心化子 $C_G(a_i)$ 的大小；④ 代入 $|G| = |Z(G)| + \sum [G : C_G(a_i)]$ 验证。**类方程是「已知群后校验分类」的工具。**

- **方向二（约束）：已知阶，推结构。** 步骤：① 类方程模 $p$ 消去非中心项，得 $|Z(G)|$ 的整除信息；② 结合拉格朗日定理约束 $|Z(G)|$ 的可能值；③ 由 $Z(G)$ 的大小反推 $G$ 的可交换性。**类方程是「只知道阶时推断群结构」的约束器。**

- **关键数学**：每一项 $[G : C_G(a_i)] > 1$ 且整除 $|G|$；$|Z(G)|$ 是「单点类」的个数。类方程本质上是「把 $|G|$ 按 $>1$ 与 $=1$ 两类共轭类分开加」。

- **局限**：类方程携带的信息是「共轭类大小的分布」，不含「元素彼此如何乘积」——所以 $D_4$ 与 $Q_8$ 共享同一类方程。要更细的区分，需要下一节的 $p$-群结构、西罗定理与表示论（特征标表）。

## 5 应用：pq 阶群的中心

类方程的经典应用：**若 $|G| = pq$（$p < q$ 为素数），则 $Z(G) \neq \{e\}$ 或 $G$ 交换**，且更精确的结论由西罗定理（第六节）给出。

用类方程先看一步：$|Z(G)|$ 是 $pq$ 的因子（拉格朗日），且不能等于 $1$ 吗？考虑类方程 $pq = |Z(G)| + \sum [G : C_G(a_i)]$，每个 $[G:C_G(a_i)]$ 是 $p$ 或 $q$（因为 $>1$ 且整除 $pq$）。若 $|Z(G)| = 1$，则 $pq - 1$ 必须写成若干 $p$ 与 $q$ 的和——这常常不可能（比如 $pq$ 为奇时，$pq - 1$ 为偶，但每项是奇数或素数……需细致讨论），于是 $Z(G) \neq \{e\}$ 往往成立。<span class="marginnote">这里仅展示「类方程约束中心」的思路，精确的 $pq$ 阶群分类要等西罗定理：$p \nmid (q-1)$ 时 $G \cong \mathbb{Z}_{pq}$；$p \mid (q-1)$ 时还多一个非交换的「半直积」型群。类方程负责「先逼出非平凡中心」，西罗定理负责「再定出完整结构」——两道工序衔接。</span>

## 6 小结

- **共轭 = 共轭作用**：共轭类 = 轨道，$C_G(x)$ = 稳定子 = 不动点集；$|\mathrm{cl}(x)| = [G : C_G(x)]$。
- **类方程**：$|G| = |Z(G)| + \sum_i [G : C_G(a_i)]$，$a_i$ 取遍非中心类代表元。
- **$p$ 群有非平凡中心**：类方程模 $p$ 的经典应用；$p^2$ 阶群必交换。
- **类方程不是不变量**：$D_4$ 与 $Q_8$ 同类方程却不同构。
- **两个用法**：已知群做校验，只知道阶做约束。

在下一节，我们深入「中心不平凡」的那一族：**p 群的结构**。$p$ 群是有限群理论的基本砖块，其内部结构由中心一层层搭起，也是西罗定理证明的跳板。
