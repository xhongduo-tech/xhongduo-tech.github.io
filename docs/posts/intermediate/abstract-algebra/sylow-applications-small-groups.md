## 为什么从小阶群分类开始

分类是抽象代数「不变量纲领」的兑现：把一族对象按同构类归好，给每个类挑代表。第六篇将分类「有限生成阿贝尔群」，本节先用西罗定理武装自己，把**小阶有限群**（阶在 60 以下）逐步归入已知类。这是一场「用工具收编混沌」的实战演习——每个结论都不靠枚举，而靠西罗计数的几个固定招式。

掌握了这套招式，你会看到：$pq$ 阶群、$p^2q$ 阶群、$p^3$ 阶群……如何被逐一定死，而「60 阶单群 = $A_5$」这类更深的分类又是如何起步的。本节的目标不是背结论，而是掌握**招式**——「找西罗子群 → 用计数逼唯一 → 建正规子群 → 作商 → 归纳」。

## 1 招式一：西罗计数五步法

所有小阶群分类共享一套五步流程。

1. **分解阶**：$|G| = p_1^{m_1} p_2^{m_2} \cdots$，对每个素数幂 $p_i^{m_i}$ 找西罗 $p_i$-子群；
2. **算候选**：用 $n_{p_i} \mid r_i$ 且 $n_{p_i} \equiv 1 \pmod{p_i}$ 列出 $n_{p_i}$ 的候选值；
3. **元素计数**：不同素数的西罗子群交为 $\{e\}$，用元素计数（$|G|$ 被各种子群瓜分）制造矛盾或逼出唯一；
4. **逼唯一得正规**：$n_p = 1$ ⟹ $P \trianglelefteq G$；
5. **作商归纳**：$P$ 正规后，$G/P$ 或 $G$ 的直积/半直积结构浮出。

**例（$pq$ 阶群，$p < q$）：** 西罗 $q$-子群：$n_q \mid p$ 且 $n_q \equiv 1 \pmod q$。因 $n_q \in \{1, p\}$ 且 $p < q$ 时 $p \not\equiv 1 \pmod q$，故 $n_q = 1$——西罗 $q$-子群 $Q \trianglelefteq G$。<span class="marginnote">「$p < q$ 逼出 $n_q = 1$」是西罗计数最常用的一击：$n_q$ 只可能是 $1$ 或 $p$，而 $p < q$ 时 $p \equiv 1 \pmod q$ 不可能，所以只能是 $1$。比 $q$ 小的数里根本没有「模 $q$ 余 1」的非平凡选项——小素数在模大素数时很难凑出同余。</span>

于是 $G$ 有正规的 $q$ 阶子群 $Q$。设 $P$ 是西罗 $p$-子群（$p$ 阶）。若 $p \nmid (q-1)$，则 $n_p = 1$（$n_p \mid q$ 且 $n_p \equiv 1 \pmod p$，唯一可行是 $n_p = 1$），$P \trianglelefteq G$，$G \cong P \times Q \cong \mathbb{Z}_p \times \mathbb{Z}_q \cong \mathbb{Z}_{pq}$（交换）；若 $p \mid (q-1)$，则存在非交换的 $G \cong \mathbb{Z}_q \rtimes \mathbb{Z}_p$（半直积），由 $1 \le p \mid (q-1)$ 时的非平凡同态 $P \to \mathrm{Aut}(Q) \cong \mathbb{Z}_{q-1}$ 给出。<span class="marginnote">半直积 $\mathbb{Z}_q \rtimes \mathbb{Z}_p$ 是「交换直积」的推广：$Q$ 正规、$P$ 通过自同构作用于 $Q$。$p \mid (q-1)$ 时存在「真作用」，于是出现非交换群。半直积概念在第六篇直积一节会系统化——这里先睹为快。</span>

**结论：** $pq$ 阶群（$p<q$）要么交换 $\cong \mathbb{Z}_{pq}$（当 $p \nmid q-1$），要么 $\cong \mathbb{Z}_q \rtimes \mathbb{Z}_p$（当 $p \mid q-1$）。例如 15 = 3·5：$3 \nmid 4$，故 15 阶群只有 $\mathbb{Z}_{15}$；21 = 3·7：$3 \mid 6$，故除 $\mathbb{Z}_{21}$ 外还有一个非交换的 21 阶群。

## 2 招式二：元素计数与 p^2 q 阶群

当西罗计数不能直接逼出唯一时，元素计数登场。

**例（$p^2 q$ 阶群的第一击）：** 设 $|G| = p^2 q$，$p, q$ 素数。考察西罗 $p$-子群（$p^2$ 阶）与西罗 $q$-子群（$q$ 阶）。$n_q \mid p^2$ 且 $n_q \equiv 1 \pmod q$。若 $n_q = p^2$（全部候选都取到），则 $p^2$ 个 $q$-子群两两交为 $\{e\}$，贡献 $1 + p^2(q-1)$ 个元素。若这个数超过 $|G| = p^2 q$，则矛盾——例如 $p^2(q-1) + 1 > p^2 q$ 当 $p^2 > 1$，故 $n_q = p^2$ 时剩下的元素少于 $p^2$，无法容纳西罗 $p$-子群（$p^2$ 个元素），矛盾。<span class="marginnote">「$q$-子群贡献 $1 + n_q(q-1)$ 个元素」的计数是西罗实战的标准动作：不同素数的西罗子群只交在单位元，所以它们占用的元素可以精确相加。一旦总和超载，就说明候选值不可能——这是「不靠构造、纯靠数数」逼出结构。</span>

**经典结论（部分）：** 若 $|G| = p^2 q$ 且 $p < q$，则 $G$ 有正规的西罗 $q$-子群（故 $G$ 可解，非单）。一般地，**西罗计数可以证明：阶为 $p^2 q$、$p q r$（互异素数）等形态的群都不可能是单群**（总有一个西罗子群被迫正规）。这引向分类学的一个重要观察：单群的阶极其受限。

## 3 招式三：60 阶与 A5 的独特性

小阶群分类最著名的里程碑：**60 阶单群是 $A_5$**（在同构意义下唯一）。这个结论是「无 60 阶其他单群」的证明，也是有限单群分类的第一次真正的攻坚战。它的骨架依赖西罗计数 + 更深的论证。

- $|G| = 60 = 2^2 \cdot 3 \cdot 5$。西罗计数：$n_5 \mid 12$ 且 $n_5 \equiv 1 \pmod 5$，$n_5 \in \{1, 6\}$；$n_3 \mid 20$ 且 $n_3 \equiv 1 \pmod 3$，$n_3 \in \{1, 4, 10\}$；$n_2 \mid 15$ 且 $n_2 \equiv 1 \pmod 2$，$n_2 \in \{1, 3, 5, 15\}$。
- 若 $G$ 是单群，则 $n_5 \ne 1$（唯一 ⟹ 正规），故 $n_5 = 6$；同理 $n_3 \ne 1$、$n_2 \ne 1$。
- $n_5 = 6$ 给出同态 $G \to S_6$（作用在西罗 5-子群上），单性保证它嵌入（核为正规子群，只能是 $\{e\}$）。进一步的分析把 $G$ 逼成 $A_5$。<span class="marginnote">「$n_5 = 6$ 给同态 $G \to S_6$，单性保证单射」是「用西罗计数 + 单性 + 作用」联合破案的标准手法。60 阶单群 = $A_5$ 的证明是这个手法最著名的案例——它同时是有限单群分类的「第一滴血」，也是伽罗瓦论证「五次方程不可解」所需的全部群论。</span>

这个里程碑揭示了西罗定理的极限与补充：西罗计数把候选压缩，但要完成分类还常需配合「作用在陪集/共轭类上的同态」「单性论证」「$p$-群结构的归纳」。小阶群分类因此是群论全套工具的合奏。

## 4 公式解析：不同素数的西罗子群交为 {e}

元素计数依赖的这条引理虽小，却是「超载论证」的基石。

**引理：** 若 $P, Q$ 是 $G$ 的不同素数的西罗子群（$P$ 是 $p$-子群、$Q$ 是 $q$-子群，$p \ne q$），则 $P \cap Q = \{e\}$。

- **第一步，交的阶。** $P \cap Q$ 同时是 $P$ 的子群（阶为 $p$ 的幂）与 $Q$ 的子群（阶为 $q$ 的幂），故 $|P \cap Q|$ 同时整除 $p^m$ 与 $q^{m'}$。

- **第二步，整除的唯一性。** 互异素数幂的最大公约数是 1，故 $|P \cap Q| = 1$，$P \cap Q = \{e\}$。$\checkmark$

- **第三步，计数后果。** $n_q$ 个 $q$-西罗子群两两只在 $e$ 处相交，贡献的元素数是 $1 + n_q(q - 1)$（每个 $q$-西罗子群贡献 $q$ 个元素，共享单位元）。这个数必须 ≤ $|G|$，超了就矛盾——**这就是所有「超载论证」的发动机。**

- **第四步，慎用条件。** 引理要求「不同素数」。两个 $p$-西罗子群可能交在非平凡的 $p$-子群（如 $S_3$ 的两个二阶子群交为 $\{e\}$ 只是巧合；$A_4$ 的 $2$-西罗子群 $V_4$ 与另一 2-子群可能相交）。**只有「不同素数」才能保证「交为 $\{e\}$」，计数时不能混淆。**

## 5 一张表：低阶群分类速览

把已学的分类收进一张速查表（以下均在同构意义下）：

| 阶 | 群的结构 |
| --- | --- |
| $p$（素数） | $\mathbb{Z}_p$（唯一） |
| $p^2$ | $\mathbb{Z}_{p^2}$、$\mathbb{Z}_p\times\mathbb{Z}_p$（两种） |
| $pq$（$p<q$，$p\nmid q-1$） | $\mathbb{Z}_{pq}$（唯一） |
| $pq$（$p<q$，$p\mid q-1$） | $\mathbb{Z}_{pq}$、$\mathbb{Z}_q\rtimes\mathbb{Z}_p$（两种） |
| $8 = 2^3$ | $\mathbb{Z}_8$、$\mathbb{Z}_4\times\mathbb{Z}_2$、$\mathbb{Z}_2^3$、$D_4$、$Q_8$（五种） |
| $p^3$（$p$ 奇） | 三种交换 + 两种非交换（Heisenberg 型、$\mathbb{Z}_{p^2}\rtimes\mathbb{Z}_p$） |
| $12$ | 五种（含 $A_4$、$D_{12}$、$\mathbb{Z}_3\rtimes\mathbb{Z}_4$ 等） |
| $60$ | 十三种，其中唯一的单群是 $A_5$ |

这些表格不是死记硬背的对象，而是「西罗计数招式」的成果展示。对每个阶，都可以用第 1 节的五步法重新推出来。<span class="marginnote">低阶群分类还有一个「宏观事实」：12 阶以下的群全是可解群，$A_5$ 是最小的非交换单群（60 阶）。「最小单群是 $A_5$」与「五次方程不可解」在伽罗瓦理论里互为因果——第六节 Galois 理论初步将把这些线索收拢。</span>

## 6 小结

- **五步法**：分解阶 → 列候选 → 元素计数 → 逼唯一得正规 → 作商归纳。
- **$pq$ 阶群**：$p \nmid q-1$ 时唯一 $\mathbb{Z}_{pq}$；$p \mid q-1$ 时另有 $\mathbb{Z}_q\rtimes\mathbb{Z}_p$。
- **不同素数西罗子群交为 $\{e\}$**：超载论证的基石，元素计数全靠它。
- **60 阶单群 = $A_5$**：西罗计数 + 单性 + 作用的联合案例。
- 低阶群分类是「招式」而非「清单」，可随时用五步法重新推导。

在下一节，我们转向另一族可被完全分类的群：**群的外直积与内直积**。直积是把小群「乘」成大群的装配操作，第六篇有限生成阿贝尔群的分类正是直积分解的成果。
