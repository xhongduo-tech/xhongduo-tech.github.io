## 为什么从整环与因子分解开始

上篇《环论基础》讲完了环、理想、商环的通用框架。本篇进入一个更具体的舞台：**整环里的因式分解**。为什么这件事值得专开一篇？因为「把数分解成素因子」是人类最早、最深的算术直觉——$60 = 2^2 \times 3 \times 5$，小学就会。但「唯一分解」并非天经地义：在 $\mathbb{Z}[\sqrt{-5}]$ 里 $6 = 2 \times 3 = (1+\sqrt{-5})(1-\sqrt{-5})$，两种分解都「到底」了却彼此不同。

于是有了一个问题：什么样的整环里，素因子分解唯一？答案被三个概念层层收紧——**欧氏整环（ED）⊂ 主理想整环（PID）⊂ 唯一分解整环（UFD）**。本篇把《整除、单位与相伴元》到《欧氏整环》六篇的线索收拢，画清这条包含链。

## 1 整除、单位与相伴：先定词汇

**整除**：$a \mid b$ 当且仅当存在 $c$ 使 $b = ac$。

**单位（unit）**：有乘法逆元的元素。$u$ 是单位当且仅当 $u \mid 1$。$\mathbb{Z}$ 的单位只有 $\pm 1$；$\mathbb{Z}[i]$ 的单位是 $\pm 1, \pm i$；多项式环 $F[x]$（$F$ 为域）的单位恰为非零常数多项式。

**相伴（associate）**：$a$ 与 $b$ 相伴，记 $a \sim b$，当且仅当 $a = ub$，$u$ 为单位。相伴元在分解里视为「同一个东西」，只差一个单位——$\pm 6$ 在 $\mathbb{Z}$ 里相伴。

用 $\mathbb{Z}$ 练手：$2$ 整除 $6$（$6 = 2 \times 3$）；单位是 $\pm 1$；$6$ 与 $-6$ 相伴；$2$、$3$ 不可约（也即素）。这些看似平凡的概念到了 $\mathbb{Z}[i]$ 里立刻鲜活：$1+i$ 可约还是不可约？因为 $1 + i = i(1 - i)$ 且 $i$ 是单位、$1-i$ 不是单位，还需细看——**分解的谜题就在「单位」这张看不见的网里展开**。

事实上 $\mathbb{Z}[i]$ 中 $1+i$ 是不可约的：设 $1+i = zw$，取范数得 $2 = N(z)N(w)$，$N(z), N(w)$ 都是非负整数，故其一为 $1$，即 $z$ 或 $w$ 是单位。**范数 $N$ 是把整环问题翻译成整数问题的桥梁**——这在 $\mathbb{Z}[i]$ 的整个分解理论里反复出现。

<span class="marginnote">单位与相伴的定义必须放在分解理论之前，否则「唯一」无从谈起：$12 = 2\cdot 6 = (-2)\cdot(-6)$，若把单位因子也算进去就永远不唯一。约定「差一个单位的分解算同一种」，唯一性才成为可证的性质。</span>

## 2 不可约元与素元：两个「质」的概念

**不可约元（irreducible）**：非零非单位 $p$，若 $p = ab$ 则 $a$ 或 $b$ 是单位。直觉：**再也拆不动了**。

**素元（prime）**：非零非单位 $p$，若 $p \mid ab$ 则 $p \mid a$ 或 $p \mid b$。直觉：**能分解「因子中的因子」**。

两者在整环里一般不等价（素元必不可约，反之不然）；在 UFD 里它们重合。这是整环理论最重要的一条辨析线：

找反例的目光要看向「次幂环」。经典例证：在环 $A = \mathbb{Z}[\sqrt{-5}]$ 中，$3$ 是不可约元却不是素元——$3 \mid (1+\sqrt{-5})(1-\sqrt{-5}) = 6$，但 $3$ 不整除任何一个因子。**「不可约却非素」正是唯一分解失败的精确信号**，$A$ 也因此不是 UFD。

| 性质 | 不可约元 | 素元 |
| --- | --- | --- |
| 定义 | 拆不动（$p = ab \Rightarrow$ 某因子为单位） | 能分因（$p\mid ab \Rightarrow p\mid a$ 或 $p\mid b$） |
| 在 $\mathbb{Z}$ | 素数 | 素数（两者重合） |
| 在 UFD | 与素元重合 | 与不可约元重合 |
| 在一般整环 | 未必素 | 必不可约 |

## 3 三个环的「理想国」

**唯一分解整环（UFD）**：每个非零非单位元都能分解为不可约元的乘积，且分解唯一（差单位与次序）。**主理想整环（PID）**：每个理想都是主理想 $\langle a \rangle$。**欧氏整环（ED）**：存在「度数」函数 $d$ 使带余除法成立：对任意 $a \ne 0, b$，存在 $q, r$ 使 $b = aq + r$ 且 $d(r) < d(a)$（或 $r = 0$）。

<span class="marginnote">三种「整环等级」的学名分别是 Euclidean Domain、Principal Ideal Domain、Unique Factorization Domain。英文缩写 ED、PID、UFD 在国际文献里几乎是黑话级别的高频词，值得直接记住。</span>

**欧几里得算法是 ED 的灵魂**：反复带余除法求最大公因子，且能把公因子写成整系数线性组合。这是「整除性理论」在所有 ED（$\mathbb{Z}$、$F[x]$、$\mathbb{Z}[i]$）里通用化的原因。以 $\mathbb{Z}$ 的 $5$ 与 $13$ 为例：$13 = 2\cdot 5 + 3$，$5 = 1\cdot 3 + 2$，$3 = 1\cdot 2 + 1$，回代得 $1 = 5\cdot(-5) + 13\cdot 2$——这就是辗转相除法与贝祖等式的真身。

## 4 核心对比表：ED ⟹ PID ⟹ UFD

三层包含关系及其反例，是整篇的核心对比表：

| 环类 | 定义 | 蕴含 | 反例 |
| --- | --- | --- | --- |
| 欧氏整环 ED | 带余除法 + 度数 | ED ⟹ PID | — |
| 主理想整环 PID | 每理想主生成 | PID ⟹ UFD | $\mathbb{Z}[\frac{1+\sqrt{-19}}{2}]$（PID 非 ED） |
| 唯一分解整环 UFD | 分解唯一 | UFD ⊇ 更宽 | $\mathbb{Z}[x]$（UFD 非 PID）、$\mathbb{Z}[\sqrt{-5}]$（连 UFD 都不是） |

链条直观：带余除法太强，主理想次之，唯一分解最弱但也最常用。**记忆顺序：能带余除法 ⟹ 理想都主生成 ⟹ 分解唯一。**

三个概念还各自对应一种「有限性保障」：ED 靠度数下降，PID 靠理想升链终止，UFD 靠分解长度的有限性。**同一套「不断下降必然终止」的论证，在三个层面上反复兑现**——这正是下一节《模论初步》里自由模与诺特性的先声。

值得停下来体会的是三条反例背后的层次：$\mathbb{Z}[x]$ 是 UFD 却非 PID——理想 $\langle 2, x \rangle$（由 $2$ 与 $x$ 共同生成）不是主理想；$\mathbb{Z}[\sqrt{-5}]$ 连 UFD 都不是；而 $\mathbb{Z}[\frac{1+\sqrt{-19}}{2}]$ 是 PID 却非 ED——**它是「主理想但不带余除法」的著名例子，证明了 ED 是 PID 的真子类**。这三块反例像三把刻度尺，标出了每个概念的真实边界。

## 5 公式解析：欧氏整环必为主理想整环

$$
\text{ED} \;\Longrightarrow\; \text{PID}: \quad \text{取理想 } I \text{ 中度数最小的非零元 } a, \text{ 则 } I = \langle a \rangle
$$

- **第一步，选最小度**：$I$ 非零，取其中度数 $d(a)$ 最小的非零元 $a$——$a$ 是「最小的钉子」。
- **第二步，任意取 $b \in I$**：用带余除法写 $b = aq + r$，$d(r) < d(a)$ 或 $r = 0$。
- **第三步，反证排除 $r \ne 0$**：$r = b - aq$，而 $I$ 是理想、$b, aq \in I$，故 $r \in I$；若 $r \ne 0$，则 $r$ 是 $I$ 中度数比 $a$ 更小的非零元，与 $a$ 的最小性矛盾。故 $r = 0$，$b = aq \in \langle a \rangle$。
- **第四步，收尾**：$I \subseteq \langle a \rangle$ 已得，$\langle a \rangle \subseteq I$ 由理想性质给出，故 $I = \langle a \rangle$。$\blacksquare$

**这条证明的启示：** 「度数最小」就是最小性原理（良序原理）在环论里的化身。欧氏整环之所以强，正是因为**带余除法提供了一条「不断变小」的下降通道**——它同时是最大公因子算法的引擎。

再往下一层：$PID \Rightarrow UFD$ 的证明用「理想升链终止」取代「度数下降」——主理想链 $\langle a_1 \rangle \subseteq \langle a_2 \rangle \subseteq \cdots$ 若无限上升，则其并集仍是主理想 $\langle a \rangle$，于是 $a$ 必落在某一项里，链被迫终止。**这一手「有限性论证」正是下一篇《模论初步》与更后面的诺特环理论的核心武器**——先在这里打个照面。

## 6 三座标志性环

- **$\mathbb{Z}$**：欧氏整环（度数取绝对值 $|a|$）；$1$ 和 $-1$ 是单位；不可约元即素数。
- **$F[x]$**：域上多项式环是欧氏整环（度数取多项式的次数 $\deg$）；$F$ 为域时 $F[x]$ 里唯一分解成立——这正是《多项式的带余除法》与《艾森斯坦判别法》能在其中大展身手的前提。
- **$\mathbb{Z}[x]$**：UFD 但非 PID——理想 $\langle 2, x \rangle$ 非主理想；它是「多项式使分解保持、却丢失主理想性」的标本。
- **高斯整环 $\mathbb{Z}[i] = \{a + bi\}$**：欧氏整环，度数取范数 $N(a+bi) = a^2 + b^2$。费马平方和定理——素数 $p \equiv 1 \pmod 4$ 可写成两平方和——正是用 $\mathbb{Z}[i]$ 里的唯一分解证明的。
- **$\mathbb{Z}[\sqrt{-5}]$**：不是 UFD，因 $6 = 2 \cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5})$ 两种分解互不相伴。

这四个例子排在一起就是一部「分解史」：$\mathbb{Z}$ 是原型，$F[x]$ 与 $\mathbb{Z}[i]$ 是好孩子，$\mathbb{Z}[\sqrt{-5}]$ 是警告牌——**唯一分解不是白送的，需要结构条件去保障。**

分解理论还有一个通向代数的自然延伸：既然 ED ⟹ PID ⟹ UFD，那么反过来「补洞」的工作就交给了多项式——$\mathbb{Z}[x]$ 虽是 UFD 却非 PID，但当 $R$ 是 UFD 时 $R[x]$ 仍是 UFD（高斯引理，§9.8）。**高斯引理正是「UFD 的完备性」：分解性质在添变量后依然保持**，这为多元多项式环的因式分解打下了根基。

## 7 小结

- **词汇**：整除、单位（$u\mid 1$）、相伴（$a \sim ub$）；唯一性须先「差单位」约定。
- **两个「质」**：不可约元=拆不动，素元=能分因；一般整环里素元必不可约，反之不真，UFD 里两者重合。
- **三层包含**：ED ⟹ PID ⟹ UFD；反例：$\mathbb{Z}[x]$ 是 UFD 非 PID，$\mathbb{Z}[\frac{1+\sqrt{-19}}{2}]$ 是 PID 非 ED。
- ED 的灵魂是带余除法 + 度数最小性；欧几里得算法在 $\mathbb{Z}$、$F[x]$、$\mathbb{Z}[i]$ 通用。
- 高斯整环上的唯一分解证明了费马两平方和定理。
- 唯一分解需要结构保障：$\mathbb{Z}[\sqrt{-5}]$ 的 $6$ 给出两种分解，警告性质不可想当然。
- 欧几里得算法同时给出最大公因子与贝祖等式（线性组合表示），是 ED 的实用名片。
- PID 非 ED 的经典例证是 $\mathbb{Z}[\frac{1+\sqrt{-19}}{2}]$；UFD 非 PID 的例证是 $\mathbb{Z}[x]$。
- 高斯引理保证 UFD 的多项式环仍是 UFD——分解性质在添变量后保持。
- 关键词对照：ED（带余除法+度数）、PID（理想主生成）、UFD（分解唯一），三者顺序由强到弱。
- 判断一个环「好在哪一级」，先问：能带余除法吗？理想都主生成吗？分解唯一吗？逐级退让。
- 无穷多素数的古典证明在 $\mathbb{Z}$ 上是显式的；到了 $\mathbb{Z}[i]$、$F[x]$，同一套「有限性」思想换装再战。

在下一节，我们将离开「环内分解」，进入全新的舞台：**域扩张**——把域装进更大的域里，用扩张次数、代数与超越、分裂域这些工具，为最后登顶 Galois 理论铺路。
