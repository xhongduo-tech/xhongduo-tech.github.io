## 为什么从整环、除环与域开始

上一节我们把「可逆元」与「零因子」作为两条判据，这一节用它们给环分层：**整环**（无零因子的交换含幺环）、**除环**（非零元全可逆但不要求交换）、**域**（交换的除环）。这三个层级构成环论地图的主干道——数论住在整环里，解方程住在域里，四元数住在除环里。

域尤其重要：它是「能自由做加减乘除」的最小舞台，也是第十篇域扩张与第十一篇 Galois 理论的全部地基。理解「整环 → 域」的升级（以及除环这条岔路），就理解了环论里「什么样的结构能撑起除法」。本节把三个层级、它们的判定、有限与无限的经典例子一次讲透。

## 1 三个层级的定义与关系

**整环（integral domain）**：交换、含幺、无零因子的环。记号常写 $D$ 或 $R$。

**除环（division ring / skew field）**：每个非零元都可逆的环（不一定交换）。「体」是中国传统译名。

**域（field）**：交换的除环（即每个非零元可逆且乘法交换）。

**关系一览：**

$$
\text{域} \ \subset\ \text{整环} \ \subset\ \text{交换含幺环} \ \subset\ \text{环}
$$

$$
\text{域} \ \subset\ \text{除环} \ \subset\ \text{含幺环}
$$

**域 = 整环 ∩ 除环**（交换 ∩ 全可逆）。<span class="marginnote">包含关系图：整环在「无零因子」上卡住，除环在「全可逆」上卡住，二者在「域」处重合。最著名的「非域整环」是 $\mathbb{Z}$（无零因子但只有 $\pm 1$ 可逆）；最著名的「非交换除环」是四元数 $\mathbb{H}$（每个非零元可逆但不交换）。域是两者的交集。</span>

**例：**
**整环**：$\mathbb{Z}$、$\mathbb{Z}[x]$、$\mathbb{Z}[i]$（高斯整数）、$\mathbb{Z}_p$（$p$ 素数）；
**除环（非交换）**：四元数体 $\mathbb{H}$（哈密顿）；
**域**：$\mathbb{Q}$、$\mathbb{R}$、$\mathbb{C}$、$\mathbb{Z}_p$（$p$ 素数）、$\mathbb{F}_q$（有限域，第十篇）；
**既非整环也非除环**：$M_n(\mathbb{R})$（有零因子、非交换）、$\mathbb{Z}_n$（$n$ 合数，有零因子）。

## 2 关键定理：有限整环是域

上一节的「有限环两分法」升级为环论最美的定理之一。

**定理（Wedderburn 小定理的有限版 / 有限整环是域）：** 有限整环必是域。

**证明**：$R$ 有限且无零因子。任取 $a \ne 0$，左乘映射 $x \mapsto ax$ 是单射（$ax = ay \Rightarrow a(x-y) = 0 \Rightarrow x = y$，因无零因子）。有限集上的单射是满射，故存在 $b$ 使 $ab = 1$——$a$ 有左逆。同理 $a$ 有右逆，$a$ 可逆。故每个非零元可逆，$R$ 是域。$\blacksquare$<span class="marginnote">这条定理把「无零因子」在有限情形下直接升格为「全可逆」——有限性让单射自动变成满射。它解释了两件事：$\mathbb{Z}_p$ 是域（有限整环），且有限整环只有域一种形态；它也是 Wedderburn 小定理（「有限除环是域」）的弱化——有限除环自动交换，这是更深刻的结果。</span>

**推论：** 有限整环 $\mathbb{Z}_p$（$p$ 素数）是域；$\mathbb{Z}_n$（$n$ 合数）不是整环也不是域（有零因子）。**「模素数 = 域」是数论与环论的第一次大合流**——有限域 $\mathbb{F}_p = \mathbb{Z}_p$ 因此成为第十篇的主角之一。

## 3 整环的特征与商域：从整环造出域

整环虽然不保证可逆，但可以**扩大**成域——这是「从整环造出除法」的标准工序。

**商域（field of fractions）**：设 $D$ 是整环。在 $D \times (D \setminus \{0\})$ 上定义等价关系 $(a, b) \sim (c, d) \iff ad = bc$，商集配上分数运算构成一个域 $\operatorname{Frac}(D)$，其中元素记为 $a/b$（$b \ne 0$）。

$\operatorname{Frac}(\mathbb{Z}) = \mathbb{Q}$（整数造出有理数）；
$\operatorname{Frac}(\mathbb{Z}[x]) = \mathbb{Q}(x)$（有理函数域）；
$\operatorname{Frac}(\mathbb{Z}[i]) = \mathbb{Q}(i)$（高斯有理数）。

**商域是「包含 $D$ 的最小域」**：任何包含 $D$ 的域都含 $\operatorname{Frac}(D)$。这个「由整环自由造域」的构造，是第十篇域扩张「素域」的先声。<span class="marginnote">商域的构造模仿分数：$(a,b)$ 就是「$a$ 除以 $b$」，等价关系 $(a,b)\sim(c,d) \iff ad = bc$ 就是「交叉相乘相等」，运算 $a/b + c/d = (ad+bc)/(bd)$、$(a/b)(c/d) = ac/bd$ 就是分数四则。整数造有理数的过程被抽象成「任意整环造它的商域」——这是「类比」升格为「定理」的典范。</span>

**辨析｜易错点：** 商域要求 $D$ 是**整环**（无零因子）。若 $D$ 有零因子，$ad = bc$ 的等价关系会退化（不同分子可能等价），构造出的不是域。所以「造商域」这道工序只对整环开放——又一次，零因子挡在通往域的路上。

## 4 公式解析：a ≠ 0 可逆 ⟺ 无零因子（在有限环上）

把「有限整环是域」的证明浓缩成一条核心推导。

**第一步，无零因子的代数形式。** 「$R$ 无零因子」⟺ 对一切 $a \ne 0$，$ax = 0 \Rightarrow x = 0$ ⟺ 左乘映射 $L_a : x \mapsto ax$ 是单射。

**第二步，有限性把单射变满射。** $R$ 有限，$L_a : R \to R$ 是单射的自映射，故是满射。于是存在 $b$ 使 $L_a(b) = ab = 1$，$a$ 有左逆。对称地 $a$ 有右逆。

**第三步，左逆 = 右逆。** 若 $ab = 1$、$ca = 1$，则 $c = c(ab) = (ca)b = b$，故 $a^{-1} = b = c$ 是唯一逆。$a$ 可逆。

**第四步，结论。** 每个非零元可逆，$R$ 是域。$\blacksquare$ 这条推导的「机关」是有限性：**无穷时单射不必满射**（$n \mapsto 2n$ 是 $\mathbb{Z} \to \mathbb{Z}$ 的单射非满射），所以 $\mathbb{Z}$ 虽是整环却不全可逆——「有限整环是域」完全依赖有限性。

## 5 四元数与除环：非交换的世界

除环的存在说明「非零元全可逆」并不需要交换。**四元数体 $\mathbb{H}$** 是最经典的例子。

**四元数**：$\mathbb{H} = \{ a + bi + cj + dk \mid a, b, c, d \in \mathbb{R} \}$，其中 $i^2 = j^2 = k^2 = ijk = -1$，且 $ij = -ji$、$jk = -kj$、$ki = -ik$。

**定理：** $\mathbb{H}$ 是除环但不是域。

非交换：$ij = k \ne -k = ji$；
每个非零元可逆：定义共轭 $\bar{q} = a - bi - cj - dk$，范数 $N(q) = q\bar q = a^2 + b^2 + c^2 + d^2 > 0$，则 $q^{-1} = \bar q / N(q)$——**每个非零四元数都有逆**。<span class="marginnote">四元数的逆元由范数给出：$q^{-1} = \bar q/N(q)$，像复数除法一样「共轭除以模方」。$N(q) > 0$ 保证任何非零 $q$ 都可逆。四元数体的发现（哈密顿，1843）是「除法可以离开交换律」的宣言，也是三维/四维旋转表示论的基石，与《线性代数》和《量子力学》中的旋转描述直接相关。</span>

**推论：** 有限除环必是域（Wedderburn 小定理）——所以四元数这种「非交换除环」**只可能是无穷的**。有限时「全可逆」自动逼出「交换」，这是有限环世界的又一条奇特法则。

## 6 小结

- **整环**：交换含幺无零因子；**除环**：非零元全可逆（可非交换）；**域** = 交换的除环 = 整环 ∩ 除环。
- **有限整环是域**：有限性让「无零因子 ⟹ 全可逆」；$\mathbb{Z}_p$ 因此是域。
- **商域**：任何整环可扩展为 $\operatorname{Frac}(D)$（如 $\operatorname{Frac}(\mathbb{Z}) = \mathbb{Q}$），是包含它的最小域。
- **四元数 $\mathbb{H}$**：非交换除环的样板，$q^{-1} = \bar q / N(q)$；有限除环必是域。
- 整环、除环、域是环论地图的主干道，通往多项式分解与域扩张。

在下一节，我们进入第七篇的收尾：**环的特征（Characteristic）**。特征测量环里「多少个 1 相加等于 0」，它是有限域分类与域扩张理论的一把尺子。
