## 为什么从椭圆曲线开始

上一节的离散对数在 $\mathbb{Z}_p^\times$ 上工作，但现代公钥密码的前沿是**椭圆曲线密码（ECC）**：把 DLP 搬到「椭圆曲线点构成的群」上。椭圆曲线的点通过「弦切法」构成一个**阿贝尔群**，在这个群上的离散对数问题（ECDLP）**没有已知的亚指数算法**——比 $\mathbb{Z}_p^\times$ 上的 DLP 更硬，因此同样安全强度下密钥可以短得多（256 位 vs 3072 位）。

椭圆曲线群是「几何对象自然成群」的典范：一条三次曲线 + 无穷远点 + 弦切运算 = 一个交换群。理解它的群结构（群律、阶、循环性），是理解 ECC、ECDH、ECDSA 的全部前提。本节把椭圆曲线的群律、有限域上的结构与应用讲透。

## 1 椭圆曲线的群律

**椭圆曲线（elliptic curve）**：设 $F$ 是域（$F = \mathbb{F}_p$ 或 $\mathbb{F}_{p^n}$），椭圆曲线是

$$
E : y^2 = x^3 + ax + b
$$

（$4a^3 + 27b^2 \ne 0$，保证无奇点），连同**无穷远点** $\mathcal{O}$。

**群律（弦切法）**：在 $E$ 的点集上定义加法：

- **弦法（两点相加）**：$P + Q$：过 $P, Q$ 作直线，交曲线于第三点 $R$，则 $P + Q = -R$（$R$ 关于 $x$ 轴的镜像）；
- **切法（自加）**：$P + P$：过 $P$ 的切线交曲线于 $R$，则 $P + P = -R$；
- **无穷远点**：$\mathcal{O}$ 是单位元（$P + \mathcal{O} = P$），$-P$ 是 $P$ 关于 $x$ 轴的镜像。

**定理：** 上述运算让椭圆曲线 $E$ 的点集构成一个**阿贝尔群**（交换群）。<span class="marginnote">「弦切法」的几何直觉：$P + Q + R = \mathcal{O}$ 当且仅当 $P, Q, R$ 共线（三次曲线与直线交三点）。于是加法「$P + Q = -R$」把「三点共线」翻译成群律。$R$ 的镜像 $-R$ 让「共线」变成「和为 $\mathcal{O}$」。<strong>一条几何性质（三点共线）定义了整个群结构</strong>——群论与代数几何在此交汇。</span>

**例（$\mathbb{F}_p$ 上的小曲线）**：$E : y^2 = x^3 + x$ 在 $\mathbb{F}_5$ 上：点 $(0, 0)$、$(1, \sqrt2?)$——$\mathbb{F}_5$ 中 $1^3 + 1 = 2$，$y^2 = 2$ 有解？$2, 3$ 的平方 $4, 4$——需逐个检查 $x = 0,1,2,3,4$ 的 $x^3 + x$ 是否为平方数，收集所有点 + $\mathcal{O}$。群阶 $|E(\mathbb{F}_5)|$ 由 Hasse 定理约束（见下）。

## 2 有限域上的椭圆曲线群

在有限域 $\mathbb{F}_p$ 上，椭圆曲线群 $E(\mathbb{F}_p)$ 是有限阿贝尔群。

**定理（Hasse 界）**：$|E(\mathbb{F}_p)| = p + 1 - t$，其中 $|t| \le 2\sqrt{p}$（Hasse 定理）。即**点群的阶大致是 $p + 1$**，偏离不超过 $2\sqrt{p}$。

**群结构**：$E(\mathbb{F}_p)$ 是有限阿贝尔群（第六篇分类：循环群或两个循环群的直积）。由有限阿贝尔群基本定理，$E(\mathbb{F}_p) \cong \mathbb{Z}_{n_1} \times \mathbb{Z}_{n_2}$（$n_2 \mid n_1$ 或素数幂分量）。**多数情况 $E(\mathbb{F}_p)$ 是循环群**（或接近循环），取一个「大阶点」$P$ 作为生成元。<span class="marginnote">Hasse 界把点群的大小钉在 $p + 1$ 附近，这是 ECC 选参数（$p$ 的位数）的依据：$p$ 越大点群越大，DLP 越难。点群的阶 $N = |E(\mathbb{F}_p)|$ 也必须有大素因子（防 Pohlig-Hellman 对 ECDLP 的推广），通常选 $N$ 为素数或「近素数」。</span>

**ECDLP（椭圆曲线离散对数问题）**：给定 $P, Q = [k]P$（$[k]P$ 是 $P$ 自加 $k$ 次），求 $k$。**没有已知的亚指数算法**——比 $\mathbb{Z}_p^\times$ 上的 DLP（有指数演算）更硬。**这是 ECC「密钥更短」的根本原因。**

## 3 ECDH 与 ECDSA：ECC 的实际应用

**ECDH（椭圆曲线 Diffie-Hellman）**：在 $E(\mathbb{F}_p)$ 上选基点 $G$（大阶）：
1. 爱丽丝选 $a$，发 $A = [a]G$；鲍勃选 $b$，发 $B = [b]G$；
2. 共享密钥 $K = [a]B = [a b]G = [b]A = [b a]G$。

与经典 DH 的代数完全平行（$[a][b]G = [ab]G$），只是「乘法」换成「点的数乘 $[k]P$」。

**ECDSA（椭圆曲线签名算法）**：签名 = 用私钥 $d$（$Q = [d]G$）在「点的数乘」上做一次性随机数 $k$ 的代数，验证 = 用公钥 $Q$ 检查等式。**安全靠 ECDLP**：由 $Q = [d]G$ 求 $d$ 难。<span class="marginnote">ECDH 与经典 DH 的对照：$\mathbb{Z}_p^\times$ 里是「$g^a$」，椭圆曲线里是「$[a]G$」。数乘 $[k]P$ 用「双倍-加」（类比平方-乘）$O(\log k)$ 步算完。ECC 的全部代数结构——阿贝尔群、数乘、DLP——都是本专题学过的群论的直接应用。</span>

**参数对比**（同等安全强度）：

| 安全级别 | RSA 密钥 | ECC 密钥 |
| --- | --- | --- |
| 80 位 | 1024 位 | 160 位 |
| 112 位 | 2048 位 | 224 位 |
| 128 位 | 3072 位 | 256 位 |
| 256 位 | 15360 位 | 512 位 |

**ECC 以短密钥提供同等安全**——带宽、存储、功耗全面占优，是移动端与区块链（比特币、以太坊的 secp256k1）的首选。

## 4 公式解析：数乘 [k]P 的双倍-加算法

ECC 的一切计算都围绕「点的数乘 $[k]P$」，把它的高效算法拆透。

- **第一步，问题。** $[k]P = \underbrace{P + P + \cdots + P}_{k}$，朴素逐加需 $k-1$ 次点加（天文数字）。需要用「双倍-加」把 $k$ 的加法拆成「翻倍 + 加」。

- **第二步，二进制分解。** $k = \sum b_i 2^i$（$b_i \in \{0,1\}$）。$[k]P = \sum_{b_i = 1} [2^i]P$。

- **第三步，迭代（从左到右）**：
  - 从 $R = \mathcal{O}$ 开始；
  - 每位：$R \leftarrow [2]R$（翻倍），若 $b_i = 1$ 则 $R \leftarrow R + P$（加）；
  - 结束得 $R = [k]P$。

- **第四步，代价**。约 $\log_2 k$ 次翻倍 + $\frac12\log_2 k$ 次加点——**多项式时间**。$\blacksquare$ 数乘「易算」，ECDLP「难求」，这就是 ECC 的全部不对称。

## 5 例子：小椭圆曲线的完整计算

在一个小例子上把椭圆曲线群律完整走一遍，消除神秘感。

**例：$E : y^2 = x^3 + x + 1$ 在 $\mathbb{F}_5$ 上。** 检查 $x = 0, 1, 2, 3, 4$ 的 $x^3 + x + 1$ 是否为 $\mathbb{F}_5$ 的平方：
- $x = 0$：$1 = 1^2$ ⟹ $y = \pm 1$ ⟹ 点 $(0,1), (0,4)$；
- $x = 1$：$3$，平方？$1^2=1, 2^2=4, 3^2=4, 4^2=1$——3 不是平方，无点；
- $x = 2$：$8+2+1 = 11 \equiv 1$ ⟹ $y = \pm 1$ ⟹ $(2,1), (2,4)$；
- $x = 3$：$27+3+1 = 31 \equiv 1$ ⟹ $(3,1), (3,4)$；
- $x = 4$：$64+4+1 = 69 \equiv 4 = 2^2$ ⟹ $(4,2), (4,3)$。

加上 $\mathcal{O}$，$|E(\mathbb{F}_5)| = 1 + 6 = 7$。**Hasse 界**：$|t| \le 2\sqrt5 \approx 4.47$，$|E| = 5 + 1 - t = 7$ ⟹ $t = -1$，满足。**7 是素数，$E(\mathbb{F}_5)$ 是 7 阶循环群**（任何非 $\mathcal{O}$ 点都是生成元）。$\checkmark$<span class="marginnote">这个小例子展示了 ECC 的全部要素：枚举点（解 $y^2$）、Hasse 界验证、群阶是素数（大素因子 = 抗 Pohlig-Hellman）、循环群结构。$|E(\mathbb{F}_5)| = 7$ 是素数，故 ECDLP 在此群上「满难度」。实际 ECC 用 $p$ 约 256 位、$|E(\mathbb{F}_p)|$ 为大素数（如 secp256k1），是这个小例子的巨大化。</span>

## 6 小结

- **椭圆曲线群**：$E: y^2 = x^3 + ax + b$ + $\mathcal{O}$，弦切法成群（阿贝尔）。
- **Hasse 界**：$|E(\mathbb{F}_p)| \approx p + 1$（偏差 ≤ $2\sqrt p$）；群是有限阿贝尔群。
- **ECDLP**：$[k]P$ 易算、$k$ 难求；无亚指数算法 ⟹ 密钥更短。
- **ECDH/ECDSA**：与经典 DH 代数平行（$[a][b]G = [ab]G$），安全靠 ECDLP。
- **双倍-加算法**：数乘 $O(\log k)$；ECC 用 256 位达到 RSA 3072 位的安全。

在下一节，我们从密码学转向编码理论：**线性码：生成矩阵与校验矩阵**。纠错码的代数骨架，是有限域上的向量空间与线性映射。
