## 为什么从有限域运算与 AES 开始

上一节画了地图，这一节钻进 AES（高级加密标准）的引擎舱：**AES 的每个字节都活在有限域 $\mathbb{F}_{2^8}$ 里**，其加法是异或、乘法是「模不可约多项式的多项式乘法」。这套运算的完整机制，正是第十篇「$\mathbb{F}_{p^n} = \mathbb{F}_p[x]/\langle f\rangle$」的工业级应用。

理解 AES 的字节运算，你就真正理解了三件事：**为什么商环 $F[x]/\langle f\rangle$（$f$ 不可约）能造出可逆算术齐全的域**、**为什么 AES 选 $\mathbb{F}_{2^8}$ 而非 $\mathbb{Z}_{256}$**、**S-box 的求逆为什么是安全的非线性源**。本节把 $\mathbb{F}_{2^8}$ 的加法、乘法、逆元与 S-box 讲透。

## 1 字节 = F_{2^8} 的元素

**AES 的域**：$\mathbb{F}_{2^8} = \mathbb{F}_2[x] / \langle m(x) \rangle$，其中不可约多项式

$$
m(x) = x^8 + x^4 + x^3 + x + 1
$$

（$\mathbb{F}_2$ 上不可约，被 AES 选定为约化多项式）。

**字节表示**：一个字节 $b_7 b_6 \cdots b_1 b_0$（8 个比特）对应 $\mathbb{F}_2$ 上的多项式

$$
b_7 x^7 + b_6 x^6 + \cdots + b_1 x + b_0
$$

例如 $x^6 + x^4 + x^2 + x + 1$（二进制 $\mathbb{F}_{2^8}$）= $x^6 + x^4 + x^2 + x + 1$。**「字节」与「次数 < 8 的多项式」一一对应**——AES 的世界里，每个字节就是 $\mathbb{F}_{2^8}$ 的一个元素。<span class="marginnote">字节 ↔ 多项式的对应让「算术」有了具体形态：加法是「异或」（$\mathbb{F}_2$ 里加 = 异或），乘法是「多项式相乘模 $m(x)$」。AES 选 $x^8 + x^4 + x^3 + x + 1$ 是因为它在 $\mathbb{F}_2$ 上不可约（保证 $\mathbb{F}_{2^8}$ 是域），且是「最小的」八次不可约多项式之一，让约化高效。</span>

## 2 加法 = 异或

**字节加法**：$\mathbb{F}_2$ 中 $1 + 1 = 0$，故多项式相加就是**逐位异或**：

$$
(x^6 + x^4 + x^2 + x + 1) + (x^7 + x^4 + x + 1) = x^7 + x^6 + x^2
$$

（同幂次系数异或：$1+1 = 0$ 抵消）。**AES 的加法就是 XOR**，这是 $\mathbb{F}_2$ 算术的直接结果——「加」在二进制世界里最便宜。

**减法 = 加法**：$\mathbb{F}_2$ 里 $a - b = a + b$（$1 = -1$），所以减法也是异或。**在 $\mathbb{F}_{2^8}$ 里，加、减、异或是同一件事**——这是特征 2 域的标志性简化。<span class="marginnote">特征 2 的「减法 = 加法」在 AES 里大放异彩：XOR 同时充当加减，硬件实现极简。这也呼应第七篇「特征」的内容——特征 $p$ 的域有特征 0 没有的算术捷径（$(a+b)^p = a^p+b^p$ 在 AES 里表现为「字节加 = 异或」）。</span>

## 3 乘法 = 模 m(x) 的多项式乘法

**字节乘法**：两个字节对应的多项式相乘，再模 $m(x)$ 约化（把次数 ≥ 8 的部分用 $m(x) = 0$ 化简）。

**例：$0x57 \cdot 0x83$。** $0x57$ = $x^6 + x^4 + x^2 + x + 1$，$0x83$ = $x^7 + x + 1$。

**相乘**：$(x^6+x^4+x^2+x+1)(x^7+x+1) = x^{13} + x^{11} + x^9 + x^8 + x^7 + x^7 + x^5 + x^3 + x^2 + x + x^6 + x^4 + x^2 + x + 1$（展开合并）
  $= x^{13} + x^{11} + x^9 + x^8 + x^6 + x^5 + x^4 + x^3 + 1$；
**约化**：用 $x^8 = x^4 + x^3 + x + 1$（由 $m(x) = 0$）反复降次，最终得次数 < 8 的多项式 $x^7 + x^6 + 1$（即 $x^8 = x^4 + x^3 + x + 1$）。

**约化的机制**：$x^8 + x^4 + x^3 + x + 1 = 0$ ⟹ $x^8 = x^4 + x^3 + x + 1$，所以任何 $x^k$（$k \ge 8$）都能用这个等式降次。**模 $m(x)$ 就是「把 $x^8$ 换成 $x^4+x^3+x+1$」的反复代换**。<span class="marginnote">AES 的乘法实现常用「xtime」技巧：乘以 $x$（左移一位）后，若溢出第 8 位则异或 $m(x)$ 的低字节 $x^8$。这是「模不可约多项式」在字节算术里的最简实现——每次乘 $x$ 都是一次「左移 + 条件约化」，与多项式除法完全一致。</span>

**乘法单位元**：$\mathbb{F}_{2^8}$（多项式 $1$）。每个非零字节都有乘法逆（$\mathbb{F}_{2^8}$ 是域）。

## 4 逆元与 S-box：求逆的威力

**逆元的计算**：$\mathbb{F}_{2^8}$ 中 $a^{-1}$ 可用**扩展欧几里得算法**（欧氏环上求互素组合）或**费马小定理** $a^{-1} = a^{254}$（$a^{255} = 1$，因为 $\mathbb{F}_{2^8}^\times$ 是 255 阶循环群）。<span class="marginnote">「$a^{-1} = a^{254}$」来自 $\mathbb{F}_{2^8}^\times$ 是 $255 = 2^8 - 1$ 阶循环群：$a^{255} = 1$（拉格朗日/费马小定理），$a^{-1} = a^{254}$。求逆可以「用幂算」——在密码实现里常用预计算表（S-box 表）加速。这也再次体现「有限域乘法群是循环群」（第十篇）的实用价值。</span>

**S-box 的构造**（AES 的非线性替换表）：
1. 输入字节 $b$ 在 $\mathbb{F}_{2^8}$ 中求逆 $b^{-1}$（$b^{-1}$ 映自身）；
2. 对 $b^{-1}$ 做一次 $\mathbb{F}_2$ 上的**仿射变换** $b' = A b^{-1} \oplus c$（矩阵乘法 + 常量异或）。

**为什么 S-box 要「求逆」**：$b \mapsto b^{-1}$ 是有限域上的**高度非线性**函数（若它是线性的，差分分析会轻松破译）。**「域上的求逆」是安全非线性的天然来源**——这正是 AES 选择有限域的根本原因。

## 5 公式解析：a^{-1} = a^{254} 在 F_{2^8} 中

把「用费马小定理求逆」的机制拆透，它是 AES S-box 的计算引擎。

- **第一步，乘法群的阶。** $\mathbb{F}_{2^8}^\times$（去掉 0）有 $255 = 2^8 - 1$ 个元素，是循环群（有限域乘法群循环）。

- **第二步，费马小定理。** 对 $a \ne 0$，$a^{255} = 1$（拉格朗日：群阶 255 整除每个元素的阶，$a^{255} = 1$）。

- **第三步，变形。** $a^{255} = a \cdot a^{254} = 1$，故 $a^{-1} = a^{254}$。

- **第四步，计算。** 用「平方-乘」算法算 $a^{254}$（254 次幂 = 7 次平方 + 若干乘法，约 $O(\log 254)$ 步），或用扩展欧几里得直接求逆。$\blacksquare$ **求逆在有限域里是「算得动」的**——这正是「域保证可逆」的计算化版本。

## 6 小结

- **AES 的域**：$\mathbb{F}_{2^8} = \mathbb{F}_2[x]/\langle x^8 + x^4 + x^3 + x + 1\rangle$；字节 = 次数 < 8 的多项式。
- **加法** = XOR（$\mathbb{F}_2$ 里加即异或）；**减法 = 加法**（特征 2）。
- **乘法** = 多项式相乘模 $m(x)$（$x^8 = x^4 + x^3 + x + 1$ 反复代换）。
- **逆元**：$a^{-1} = a^{254}$（费马小定理）或扩展欧几里得；S-box = 求逆 + 仿射变换。
- AES 选有限域是为了「非零字节全可逆」，S-box 的求逆是安全非线性的来源。
