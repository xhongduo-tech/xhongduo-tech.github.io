# 分配格的 Birkhoff 表示定理

## 为什么从表示定理开始

前两节我们学会了「判断一个格是否分配」，但还没回答：**分配格到底长什么样？**
Birkhoff 表示定理给出了一个斩钉截铁的答案：**每个有限分配格，都同构于
某个偏序集 $P$ 的全体下集所构成的格 $\mathcal{O}(P)$**（按包含序，
$\vee = \cup$，$\wedge = \cap$）。也就是说，分配格**不外乎**
「集合族 + 并交」。这个定理的价值是双重的：一方面它把抽象的分配格
还原成看得见摸得着的集合；另一方面它揭示了「**并不可约元**」作为格的
「素数」的地位——每个元素都是若干不可再分的「原子构件」的并。
它是 Stone 对偶的有限雏形，也是理解布尔代数表示理论的必经之路。

## 1 并不可约元：格的素数

设 $L$ 是格，$a \in L$。若 $a$ 不能写成两个**严格更小**元素的并——
即对一切 $x, y$：

$$a = x \vee y \ \Longrightarrow\ x = a \ \text{或}\ y = a$$

则称 $a$ 是**并不可约元（join-irreducible element）**。
<span class="marginnote">「不可约」的直觉来自素数：素数不能分解成两个真因子的积。「并不可约」就是「不能分解成两个真元素的并」。在幂集格里，并不可约元恰是单点集 $\{x\}$（$S = T \cup U$ 时 $S$ 是单点 ⟹ $S = T$ 或 $S = U$）；在整除格里，并不可约元恰是素数幂 $p^k$。</span>

**辨析｜易错点：** 并不可约元 ≠ 原子。原子覆盖 $0$，并不可约元只要求
「不能由两个更小的并出」。原子必是不可约的（$x, y \lt  a$ 且 $a$ 原子 ⟹
$x = 0$ 或 $y = 0$，而 $0 \vee 0 = 0 \ne a$），但反之不然：
$p^2$ 在整除格里是不可约元（不能拆成两个真因子的 lcm）却不是原子
（$p \prec p^2$）。**不可约是「拆不开」，原子是「刚从 0 长出来」，二者不同。**

记 $J(L)$ 为 $L$ 的全体并不可约元的集合，按 $L$ 的序成为一个偏序集。
有限分配格中，$0$ 有时被约定包含在 $J(L)$ 中（记 $\hat{J}(L)$），
以便处理空并。

## 2 分解定理：每个元素都是不可约元的并

**定理**：有限分配格 $L$ 中，每个元素 $a$ 都能唯一地写成若干并不可约元的并：

$$a = \bigvee_{j \in D_a} j, \qquad D_a = \{ j \in J(L) : j \le a \}$$

- **第一步，读唯一性**：$a$ 恰好是「所有 $\le a$ 的并不可约元」的并。
  $D_a$ 是 $J(L)$ 的一个**下集**（$j \le a$ 且 $j' \le j$ ⟹ $j' \le a$），
  所以 $a$ 对应唯一的下集 $D_a$。
- **第二步，读存在性**：为什么每个 $a$ 都是不可约元的并？若 $a$ 可约，
  $a = x \vee y$（$x, y \lt  a$）；把 $x, y$ 继续分解，有限性保证递归终止于不可约元。
- **第三步，读几何**：$D_a$ 是 $J(L)$ 的下集，而 $J(L)$ 的下集恰好构成
  一个格 $\mathcal{O}(J(L))$——这就是表示定理的舞台。

**关键断言**：$a \mapsto D_a = \{j \in J(L) : j \le a\}$ 是**格同构**
$L \to \mathcal{O}(J(L))$。它把 $a$ 映成「$a$ 之下所有不可约元」，
把格翻译成下集。

## 3 Birkhoff 表示定理

**定理（Birkhoff 表示定理）**：设 $L$ 是有限分配格。则

$$L \cong \mathcal{O}(J(L))$$

即 $L$ 同构于它的并不可约元偏序集 $J(L)$ 的全体下集（按包含序）所构成的格。
<span class="marginnote">反过来也是真的：<strong>任何偏序集 $P$ 的下集格 $\mathcal{O}(P)$ 都是分配格</strong>（$\cup, \cap$ 天然分配），且 $J(\mathcal{O}(P)) \cong P$。于是「有限分配格」与「有限偏序集」在两个方向上互相翻译，构成一个反变等价（对偶）。这是 Stone 对偶在有限维的完整预览。</span>

**公式化的表示映射**：

$$\varphi : L \to \mathcal{O}(J(L)), \qquad \varphi(a) = \{ j \in J(L) : j \le a \}$$

- **第一步，读同构**：$\varphi$ 是满射（任何下集 $D$ 都是 $\bigvee_{j \in D} j$
  的像），单射（$a \ne b$ 则 $\varphi(a) \ne \varphi(b)$，因
  $a = \bigvee \varphi(a)$ 由 $\varphi(a)$ 唯一决定）。
- **第二步，读保运算**：$\varphi(a \wedge b) = \varphi(a) \cap \varphi(b)$
  （$j \le a \wedge b \iff j \le a$ 且 $j \le b$）；
  $\varphi(a \vee b) = \varphi(a) \cup \varphi(b)$ 由并不可约元的「素性」——
  在分配格中，$j \le a \vee b$ 当且仅当 $j \le a$ 或 $j \le b$
  （这是分配格独有的「素性」，模格中不成立）。
- **第三步，读反变**：$J$ 与 $\mathcal{O}$ 是反变的：保序映射 $P \to Q$
  诱导反序映射 $\mathcal{O}(Q) \to \mathcal{O}(P)$（取原像下集）。
  **分配格的表示定理本质上是「有限偏序集」与「有限分配格」之间的
  Stone 对偶**，方向在映射层面反转。

## 4 实例：30 的因子格与它的「骨架」

$L = \{1,2,3,5,6,10,15,30\}$（整除序）是有限分配格。求 $J(L)$：

- 并不可约元：$2, 3, 5$（素数，不能拆成两个真因子之 lcm）；
  $6 = \operatorname{lcm}(2,3)$ 可约，$10, 15$ 可约，$30$ 可约，$1$ 按约定排除。
- 于是 $J(L) = \{2,3,5\}$，按整除序**两两不可比**（没有 $2 \mid 3$ 等）。
- $\mathcal{O}(J(L))$ = $\{2,3,5\}$ 的全体下集 = $\emptyset, \{2\}, \{3\},
  \{5\}, \{2,3\}, \{2,5\}, \{3,5\}, \{2,3,5\}$，共 8 个——恰好对应 $L$
  的 8 个元素！

对应关系：$6 \leftrightarrow \{2,3\}$（所有 $\le 6$ 的素数），
$30 \leftrightarrow \{2,3,5\}$，$1 \leftrightarrow \emptyset$。
<span class="marginnote">这张对应表揭示了分配格的「密度密码」：元素个数 = $J(L)$ 的下集个数。整数 $n$ 的因子格同构于「$n$ 的素数幂因子」的幂集格——例如 30 的因子格 ≅ $\mathcal{P}(\{2,3,5\})$，因为 30 无平方因子。若 $n$ 有平方因子（如 12），因子格就比幂集格复杂，但仍是某个更小偏序集的下集格。</span>

## 5 推论与应用

**基数刻画**：有限分配格的元素数 = 其不可约元偏序集的下集数。
  这个看似计数的小结果，在枚举组合里非常有用。
**自由分配格**：$n$ 个生成元的自由分配格 = $\mathcal{O}(\mathbf{2}^{n})$
  的某个商——表示定理把「自由」问题转化为「数下集」问题。
  <span class="marginnote">自由分配格 $\operatorname{FDist}(3)$ 有 20 个元素，是「三元素反链的下集数」相关的一个著名例子；表示定理让这类计数变成纯组合学。</span>
**有限 Stone 对偶**：$J$ 把分配格映到偏序集，$\mathcal{O}$ 把偏序集映回分配格，
  二者互逆（自然同构意义下）。这是下一节布尔代数与后面 Stone 对偶的有限样板。
**每个有限分配格都是有限布尔格的子格**：因为 $\mathcal{O}(P) \subseteq \mathcal{P}(P)$
  且 $\mathcal{P}(P)$ 是布尔格。

## 6 表示定理的实战：从分配格找回偏序集

Birkhoff 表示定理不仅告诉你「有限分配格 = 下集格」，还给了你一套
**具体找回 $J(L)$ 的算法**。这在手算小例子时极其有用。

**算法：从分配格 $L$ 提取 $J(L)$**。

- **第一步，找并不可约元**：扫描 $L$ 的所有元素，对每个 $a$，检查是否存在
  $x, y \lt  a$ 使 $a = x \vee y$。若不存在，$a$ 是并不可约元。在哈斯图上，
  并不可约元是「恰有一个下覆盖」的元素（正好一条边从下面伸进来）。
- **第二步，给 $J(L)$ 排序**：按 $L$ 的序诱导的偏序排列这些不可约元。
- **第三步，验证表示**：对每个 $a$，收集 $D_a = \{j \in J(L) : j \le a\}$，
  检查 $a \mapsto D_a$ 是否双射且保 $\vee, \wedge$。

**例（$L = \{1,2,3,6,9,18\}$ 整除格）**：$18 = 2 \cdot 3^2$，
因子是 $\{1,2,3,6,9,18\}$。

- 并不可约元：$2, 3, 9$？检查——$2$ 不能写成两个真因子的 lcm（真因子只有 1），
  不可约；$3$ 同理不可约；$9 = \operatorname{lcm}(3,3)$ 而 $3 \lt  9$，$3 \neq 9$，
  故 $9$ **可约**。$6 = \operatorname{lcm}(2,3)$ 可约。
  故 $J(L) = \{2, 3\}$（$1$ 按约定排除，或作为「空并」单位元）。
- $J(L)$ 按整除序：$2 \parallel 3$（不可比），反链。
- $\mathcal{O}(J(L))$ = $\{\emptyset, \{2\}, \{3\}, \{2,3\}\}$，4 个下集，
  恰好对应 $L$ 的 4 个元素：$1 \leftrightarrow \emptyset$，
  $2 \leftrightarrow \{2\}$，$3 \leftrightarrow \{3\}$，
  $6 \leftrightarrow \{2,3\}$。

**等等——$L$ 有 6 个元素 $\{1,2,3,6,9,18\}$，怎么只得到 4 个下集？**
检查：$9$ 与 $18$ 去哪了？$9$ 的 $D_9 = \{j \le 9\} = \{3\}$（$2 \nmid 9$），
$18$ 的 $D_{18} = \{2, 3\}$。所以 $9 \leftrightarrow \{3\}$ 与
$3 \leftrightarrow \{3\}$ 撞车了！——**矛盾**。

**不矛盾**——因为 $L$ **根本不是分配格**！检查分配律：
$3 \wedge (2 \vee 9) = 3 \wedge 18 = 3$，而 $(3 \wedge 2) \vee (3 \wedge 9) =
1 \vee 9 = 9$——**$3 \ne 9$，分配律失败**！$L$ 含 $N_5$ 子格
（$1 \lt  3 \lt  9 \lt  18$ 与旁点 $2$ 构成五角），所以 $L$ 不是分配格，
Birkhoff 表示定理**不适用**。
<span class="marginnote">这个「反例演练」极具教学价值：<strong>Birkhoff 表示定理的前提「$L$ 有限分配」不能省略</strong>。一旦 $L$ 不分配（如含 $N_5$），「$a \mapsto \{j \le a\}$」就不再是单射——两个元素可以有相同的不可约元下方集。而 $L$ 不分配时，并不可约元的「素性」（$j \le a \vee b \Rightarrow j \le a$ 或 $j \le b$）也失效，表示映射连同态都不是。判断「能不能用表示定理」，先验证分配性。</span>

**正确的例**：把 $L$ 换成 $L' = \{1,2,3,6\}$（$6 = 2\cdot3$ 无平方因子），
$J(L') = \{2,3\}$，$L' \cong \mathcal{O}(\{2,3\})$（反链的下集格 =
4 元素菱形），完美对应。**无平方因子的整除格才是分配格。**

## 7 小结

- **并不可约元**：不能写成两个更小元素之并；有限分配格里它是「素数」，
  原子是特例。
- 每个元素唯一地等于「所有 $\le$ 它的不可约元」的并。
- **Birkhoff 表示定理**：$L \cong \mathcal{O}(J(L))$——
  有限分配格 = 某偏序集的下集格。
- 表示映射 $a \mapsto \{j \le a\}$ 保 $\vee, \wedge$，且 $J$ 与 $\mathcal{O}$
