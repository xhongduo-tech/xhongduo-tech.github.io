## 为什么从偏序开始

前面我们学过集合，也学过「集合与集合之间的包含关系」。
把 `⊆` 单独拎出来审视，会发现它满足三条十分自然的性质：
任何集合都包含自己、互相包含的两个集合相等、包含关系可以传递。
**这三条性质恰好刻画出数学中「顺序」二字最抽象、最一般的内涵**，
把满足它们的二元关系称为**偏序（partial order）**。
从偏序出发，我们就能把「谁先谁后」「谁大谁小」「谁包含谁」这类
遍布数学与计算机科学的问题，统一放进一个叫**偏序集**的框架里——
这正是格论的起点，也是大模型里注意力权重的偏序、数据库里的外键层级、
类型系统里的子类型关系所共享的抽象骨架。

## 1 从关系谈到偏序

集合 $A$ 上的**二元关系（binary relation）**，就是 $A \times A$ 的一个子集 $R$。
若有序对 $(a, b) \in R$，记作 $a\,R\,b$，读作「$a$ 与 $b$ 有关系 $R$」。
<span class="marginnote">关系是函数的推广：函数要求每个 $a$ 恰好对应一个 $b$，关系则没有这个限制。「$\le$」「$\subseteq$」「$\mid$（整除）」都是关系的实例。</span>

在全体关系里，有一类格外重要，它同时满足三条性质：

**自反性（reflexivity）**：对一切 $a$，都有 $a \le a$。
**反对称性（antisymmetry）**：若 $a \le b$ 且 $b \le a$，则 $a = b$。
**传递性（transitivity）**：若 $a \le b$ 且 $b \le c$，则 $a \le c$。

同时满足这三条性质的二元关系，称为 $A$ 上的一个**偏序（partial order）**，
记作 $\le$；配上偏序的集合 $(A, \le)$ 叫作**偏序集（poset）**。
这里的「偏」字点出它与全序的关键差别：**并不是任意两个元素都可比**——
有的元素之间根本没有先后关系。
<span class="marginnote">注意反对称性里是「若两者互相 $\le$ 才相等」，而不是「任意两个都可比」。可比性（comparable）是另一回事：$a$ 与 $b$ 可比当且仅当 $a \le b$ 或 $b \le a$。</span>

**辨析｜易错点：** 反对称性与「不可比」是两回事。
$\{1, 2\}$ 与 $\{2, 3\}$ 在包含序下互不包含、不可比，
但这不影响反对称性成立——反对称性只约束「两个方向都成立」的情形。
初学者常误以为偏序要求任意两元素都能比大小，那是**全序**（见后文）的要求。

## 2 三个核心例子与它们的几何直觉

偏序最密集地出现在三类结构中，值得并列记住：

**自然数的通常序** $(\mathbb{N}, \le)$：任意两个自然数都可比，
  这是一个全序。$5 \le 7$，$7 \nleq 5$。
**幂集上的包含序** $(\mathcal{P}(X), \subseteq)$：$X$ 的所有子集按包含关系
  排成偏序。当 $X = \{1,2,3\}$ 时，$\{1\} \subseteq \{1,2\}$，
  但 $\{1,2\}$ 与 $\{2,3\}$ 不可比。
- **正整数上的整除序** $(\mathbb{N}^+, \mid)$：$a \mid b$ 表示 $a$ 整除 $b$。
  $2 \mid 6$，但 $2$ 与 $3$ 不可比。

这三个例子看似不同，却共享同一条结构：
**「小」的元素在下方，「大」的元素在上方，可比元素之间有连线。**
把这种直觉精确画出来，就得到哈斯图。

## 3 覆盖与哈斯图

在偏序集 $(A, \le)$ 中，若 $a \lt  b$（即 $a \le b$ 且 $a \neq b$）
且不存在 $c$ 使得 $a \lt  c \lt  b$，则称 **$a$ 被 $b$ 覆盖（covers）**，
记作 $a \prec b$。
<span class="marginnote">覆盖关系是偏序的「最小增量」：$b$ 是 $a$ 的紧邻上方元素。在整数序 $(\mathbb{Z}, \le)$ 中，$3 \prec 4$ 成立，因为中间没有整数了。</span>

**哈斯图（Hasse diagram）**就是把偏序集画成图的办法：
每个元素画成一个点，若 $a \prec b$ 则在两点间连一条线，并把 $b$ 画在 $a$ 的正上方。
传递关系不再重复画线——因为从 $a$ 沿覆盖线逐级上升到 $b$ 已经隐含了 $a \le b$。

![30 的正因子按整除关系排成的哈斯图，底层为 1，顶层为 30，中间两级分别为素数与其两两乘积](/images/lattice-theory-and-order-theory/partial-order-and-hasse-diagrams-1.svg)

以 30 的正因子集 $\{1,2,3,5,6,10,15,30\}$ 按整除序为例：
$1$ 在底层，素数 $2,3,5$ 覆盖它；$6 = 2\cdot 3$、$10 = 2\cdot 5$、
$15 = 3\cdot 5$ 各被两个素因子覆盖；$30$ 位于顶层，覆盖 $6,10,15$。
图中不画 $1 \le 30$ 的线，因为沿覆盖链 $1 \prec 2 \prec 6 \prec 30$
已经能读出它。

**辨析｜易错点：** 哈斯图只画覆盖关系，不画一切可由传递性推出的关系。
若把 $a \le b$ 全部连线，图会布满冗余斜线，结构信息反而被淹没。
判断一张图是不是哈斯图，就看「两点间有边当且仅当覆盖」。

## 4 公式解析：覆盖的判定

覆盖关系看起来简单，实际判定时容易被「中间元素」迷惑，这里用形式化定义拆解一次：

$$a \prec b \iff a \lt  b \ \text{且} \ \nexists\, c\ (a \lt  c \lt  b)$$

- **第一步，读箭头**：$a \prec b$ 读作「$a$ 被 $b$ 覆盖」，
  它是严格不等 $a \lt  b$ 加上「中间无人」的复合条件。
- **第二步，拆前半**：$a \lt  b$ 排除 $a = b$，保证覆盖发生在两个不同元素之间。
- **第三步，拆后半**：$\nexists\, c\,(a \lt  c \lt  b)$ 是说不存在任何中间元素
  严格夹在 $a$ 与 $b$ 之间。注意 $c$ 的量词是全称否定的存在——
  只要找出一个中间元素，覆盖就不成立。
- **第四步，整体直觉**：$b$ 是「从 $a$ 往上走第一步就能到达」的元素，
  中间不停站。在整除序里，$2 \prec 6$ 成立（中间没有真因子），
  但 $2 \not\prec 30$，因为 $6$ 夹在中间。

## 5 从偏序到更大的图景

偏序集在数学里遍地都是：数系按大小、集合按包含、群按子群关系、
拓扑空间按开集包含、代数结构按商关系，全部是偏序。
计算机科学里，类型系统的子类型关系、程序依赖图的拓扑序、
分布式系统里的因果序（happens-before），也全都是偏序的化身。
<span class="marginnote">偏序还直接通向「极限」：我们会在第2篇看到，格就是「任意有限子集都有上确界与下确界」的偏序集，而完整地求确界的过程，正是极限思想的离散化投影。</span>
哈斯图则给了我们一双「看见抽象结构」的眼睛——这正是数学家审视无穷结构的起点。

## 6 动手画哈斯图：从关系表到分层图

把「元素 + 关系表」翻译成哈斯图，是掌握偏序的第一步，也是最容易出错的环节。
以 $\{1,2,3\}$ 的幂集 $\mathcal{P}(\{1,2,3\})$ 按包含序为例，完整画法分四步：

- **第一步，列元素并按层归类**：$2^3 = 8$ 个子集按基数分层——
  第 0 层 $\emptyset$，第 1 层 $\{1\}, \{2\}, \{3\}$，
  第 2 层 $\{1,2\}, \{1,3\}, \{2,3\}$，第 3 层 $\{1,2,3\}$。
  基数相同的元素画在同一水平线上。
- **第二步，画覆盖边**：仅当「差一个元素」时画线。
  $\emptyset \prec \{1\}$ 画线；$\emptyset \not\prec \{1,2\}$ 不画，
  因为 $\{1\}$（或 $\{2\}$）夹在中间。
- **第三步，核验传递可达**：每个包含关系都必须能沿覆盖边「走通」。
  $\{1\} \subseteq \{1,2,3\}$ 不必画线——沿 $\{1\} \to \{1,2\} \to \{1,2,3\}$
  三步可达。
- **第四步，复查反例**：若发现两个点之间既有直连边又能绕道，
  说明那条边不是覆盖边，图画错了。哈斯图里每条边都必须是覆盖边，
  一条不多、一条不少。

**辨析｜易错点：** 「同层」与「不可比」是两回事。
$\{1\}$ 与 $\{2\}$ 同层且不可比；但「同层」只是画图时按基数归类的习惯，
并非序性质的来源。判断不可比永远回到定义：$x \nleq y$ 且 $y \nleq x$。

还有一个实用的检查技巧：**把关系表里每一对「可比」都划掉**，
剩下的不可比对必须恰好在图上「没有通路」。
用这个技巧检查上面的幂集图：$\{1\}$ 与 $\{2,3\}$ 不可比，
图上确实既无直连也无通路——因为它们不在同一条覆盖链上。

**辨析｜易错点：** 画图时常见的另一个陷阱是把「极大元」当「最大元」。
在上述 8 元素的幂集格里，$\{1,2,3\}$ 既是唯一极大元也是最大元；
但若删掉它，剩下的 7 个子集中 $\{1,2\}, \{1,3\}, \{2,3\}$
都是极大元，却没有最大元。哈斯图的「顶层」往往有好几个点——
它们都是极大元，但最大元至多一个。这一点在第2篇第2节还会详细辨析。

## 7 小结

- **偏序** = 自反 + 反对称 + 传递的二元关系；**偏序集**是配上偏序的集合。
- 偏序不要求任意两元素可比；「可比」与「不可比」是基本区分，
  **全序**才是「任意两元素都可比」的偏序。
- 经典例子：$(\mathbb{N}, \le)$、$(\mathcal{P}(X), \subseteq)$、
  $(\mathbb{N}^+, \mid)$。
- **覆盖** $a \prec b$：$a \lt  b$
