## 为什么从结构定理开始

复习的第六站，回到「格的整体如何被理解」的问题。前几讲我们看清了
单个格的内部：它的并、交、补。但真正理解一个结构，还需要知道——
**它能被分解成什么、谁能保持它、谁能折叠它**。答案由三件工具给出：
**理想与滤子**（格内部的「向下/向上封闭」块）、**同态**（保持运算的映射）、
**同余关系**（把格折叠成商格的等价关系）。三者合在一起，构成格的
**结构定理**：第一同构定理、第二同构定理、以及「同余关系 ↔ 商格」
的一一对应。在分配格中，这套理论还进一步化简——同余关系与理想之间
存在漂亮的双射，这正是 Birkhoff《Lattice Theory》第4章的核心内容。
今天的复习，把「结构」这条线一次理清。

## 1 理想与滤子：格的「向下封闭」块

**理想（ideal）**：格 $L$ 的非空子集 $I$，满足

- **向下封闭**：$a \in I$ 且 $b \le a$ 蕴含 $b \in I$；
- **有限并封闭**：$a, b \in I$ 蕴含 $a \vee b \in I$。

**滤子（filter）** 是对偶概念：**向上封闭** + 有限**交**封闭。
<span class="marginnote">记忆：理想是「往下收」，滤子是「往上扬」——理想像「沉淀物」聚在底部，滤子像「旗帜」飘在顶部。在布尔代数中，理想与滤子经补运算互相对应：$I$ 是理想当且仅当 $\{\neg a : a \in I\}$ 是滤子。</span>

**辨析｜易错点：** 理想需要「有限并封闭」，不是任意并。在分配格中，
「向下封闭 + 有限并封闭」可以等价表述为「对任意 $a, b$，$a \vee b \in I$
当且仅当 $a, b \in I$」。**空集不是理想**（约定上有时把空理想也允许，
但通常要求非空）。

**例**：整数格 $(\mathbb{N}^+, \mid)$ 中，固定 $n$，整除 $n$ 的因子集
$\{d : d \mid n\}$ 是理想（向下封闭且对 lcm 封闭）；
整除 $n$ 的倍数集 $\{m : n \mid m\}$ 是滤子。幂集格 $\mathcal{P}(X)$ 中，
固定子集 $Y$，「$Y$ 的子集族」是理想，「含 $Y$ 的超集族」是滤子。

## 2 素理想与主理想：两种极端块

按生成与素性，理想有两条重要的分类线：

- **主理想（principal ideal）**：$\downarrow a = \{ x : x \le a \}$——
  由一个元素向下生成。**素理想（prime ideal）**：若 $a \wedge b \in P$，
  则 $a \in P$ 或 $b \in P$。素理想是「能判别每个交落在哪边」的理想。
- 在分配格中，极大理想是素理想（对偶地，极大滤子 = 超滤子）。
  有限分配格中，素理想恰好是「不可约元的下方」——这正是
  Birkhoff 表示定理（第3篇）里素理想作为骨架的原因。

<span class="marginnote">素理想是把「交运算」当作「与」的判别器：$a \wedge b \in P$ 就像「$a$ 且 $b$ 为真」——它要求至少一个因子在 $P$ 里。这个「素」字与整环里的素理想同出一辙，都是「不可再分解」的块。</span>

**辨析｜易错点：** 主理想「向下封闭」自动成立，但要验证并封闭；
素理想一定不含 $\top$（若 $L$ 有界），而极大理想在分配格中自动是素的。
**「素」是更强的性质，「极大」在分配格中蕴含「素」，反之不然。**

## 3 同余关系与商格：折叠的规则

**同余关系（congruence）**：格 $L$ 上的等价关系 $\theta$，且
**保运算**——$a \equiv b \pmod{\theta}$ 且 $c \equiv d \pmod{\theta}$
蕴含 $a \vee c \equiv b \vee d$、$a \wedge c \equiv b \wedge d$。

**商格（quotient lattice）** $L / \theta$：等价类 $[a]_\theta$ 的集合，
配上 $[a] \vee [b] = [a \vee b]$、$[a] \wedge [b] = [a \wedge b]$。
同余关系的保运算性保证商格运算良定义。

**辨析｜易错点：** 不是每个等价关系都是同余关系——必须**保 $\vee$ 与
$\wedge$**。把「$a \equiv b$」理解成「$a$ 与 $b$ 可以无差别地互相替换」，
保运算性就是说「替换在两边的运算下合法」。验证同余关系，永远要查
两类封闭性。

**定理（同余 ↔ 商格对应）**：$L$ 的全体同余关系构成一个格
$\operatorname{Con}(L)$（按包含），映射 $\theta \mapsto L / \theta$
建立「同余关系」与「商格」之间的一一对应。商格的同余关系又对应
原格的「更大的同余关系」——**这构成格的第二同构定理的骨架**。

## 4 公式解析：同态的第一同构定理

格同态的核——「被压到同一类的元素」——用同余关系而不是集合来定义，
这是格与群/环的核概念最本质的差别：

$$\ker f = \{ (a, b) \in L \times L : f(a) = f(b) \} \quad \text{是 } L \text{ 上的同余关系}$$

- **第一步，读等价性**：$f(a) = f(b)$ 显然是等价关系；
  保运算性来自 $f(a \vee c) = f(a) \vee f(c) = f(b) \vee f(d) = f(b \vee d)$。
  所以**每个同态的核都是同余关系**。
- **第二步，读商格**：$L / \ker f$ 的元素是「$f$ 拉平的类」；
  $f$ 在商格上诱导出一个**单射**同态 $\bar f : L / \ker f \to M$。
- **第三步，读第一同构定理**：$\bar f$ 的像恰是 $f(L)$，故

$$L / \ker f \ \cong \ f(L)$$

- **第四步，读直觉**：**同态折叠 = 商格；单射 = 同构到像**。
  这与群论、环论的第一同构定理完全平行，只是「核」由子集换成了
  同余关系——这是格论结构理论的第一个关键转向。

**辨析｜易错点：** 群同态的核是正规子群，环同态的核是理想；**格的
同态核是同余关系**，不是理想。为什么？因为格同态只「保运算」，
不要求「逆映射保序」——把「等价类」作为原子对象，正好编码了
同态丢失的全部信息。

## 5 核心对比表：理想、滤子、同余、商格

| 概念 | 定义核心 | 扮演的角色 | 与同态的关系 |
| --- | --- | --- | --- |
| 理想 | 向下封闭 + 有限并 | 格的「向下块」 | 分配格中充当「核的替身」 |
| 滤子 | 向上封闭 + 有限交 | 格的「向上块」 | 素滤子 ↔ 同态到 2 元格 |
| 同余关系 | 等价 + 保 $\vee, \wedge$ | 折叠规则 | **真核**（$\ker f$） |
| 商格 | $L/\theta$ | 折叠后的格 | 第一同构定理 $L/\ker f \cong f(L)$ |

<span class="marginnote">为什么分配格中「理想」能充当「核的替身」？因为在分配格中，同余关系与理想存在一一对应：$\theta \mapsto [\bot]_\theta$（含 $\bot$ 的等价类）是理想，逆方向由「$a \equiv b \iff a \wedge b$ 与 $a \vee b$ 的某种结合落入理想」恢复。这条对应是 Birkhoff 第4章的核心，也是「格的理想理论」如此有用的原因。</span>

## 6 结构定理的应用：把格拆开看

- **商格刻画**：设 $L$ 是完全格，$f : L \to L$ 保序，则 $\operatorname{Fix}(f)$
  是 $L$ 的**完全子格**（Knaster–Tarski 的直接推论）——不动点结构是
  原格结构的「保留区」。
- **理想格**：$L$ 的全体理想按包含构成格 $\mathcal{I}(L)$；映射
  $a \mapsto \downarrow a$ 是嵌入 $L \hookrightarrow \mathcal{I}(L)$，
  且 $\mathcal{I}(L)$ 是完全格——**理想完备化**为不完全格补上确界，
  这正是 Dedekind–MacNeille 完备化的直观。
- **同余格**：$\operatorname{Con}(L)$ 是 $L$ 上的**完全格**（交 = 逐点交，
  并 = 生成），且 $\operatorname{Con}(L)$ 是模格——这是
  《同余格与泛代数》一节的预告：格的同余格总是模格，分配格的同余格
  还是分配格。
- **素数分解**：有限分配格中，每个元素 = 其下素理想的「交的补」；
  素理想给出元素分解，这是 Birkhoff 表示定理的机制。

**综合练习**：设 $L$ 是链 $\{0 \lt 1 \lt 2\}$，$f : L \to \{0, 1\}$
由 $f(0) = f(1) = 0$、$f(2) = 1$ 定义。验证 $f$ 是格同态；
计算 $\ker f$；写出商格 $L/\ker f$；验证 $L/\ker f \cong \{0, 1\}$。
**一个同态，把三元素链折成了两元素链——结构定理记录了这个折叠的全部信息。**

## 7 小结

- **理想** = 向下封闭 + 有限并；**滤子** = 向上封闭 + 有限交；
  主理想 $\downarrow a$、素理想、极大理想（分配格中自动素）。
- **同余关系** = 保运算的等价关系；**商格** $L/\theta$ 是折叠结果。
- **格同态的核是同余关系**（不是子集），第一同构定理
  $L/\ker f \cong f(L)$。
- 分配格中同余关系与理想一一对应（含 $\bot$ 的等价类 ↔ 理想）。
- 理想格、同余格都是完全格；同余格还是模格——结构定理通向泛代数。

在下一节，我们将看见结构理论在应用中的壮丽展开：**伽罗瓦联络
（形式概念分析初步）**——对象与属性之间的双向对应，如何长成概念格。
