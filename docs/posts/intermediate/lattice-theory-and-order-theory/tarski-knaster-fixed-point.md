## 为什么从不动点定理开始

「求一个方程的解 $x = f(x)$」是数学最古老的动作，而格论把它变成了
最普适的存在定理。**Tarski–Knaster 定理**说：完全格上任意保序自映射的
不动点不仅存在，而且**不动点的全体自身构成一个完全格**。
这比「存在一个解」强得多——它给出了最小不动点与最大不动点，
还给出了计算不动点的机械流程。这个定理横跨数学、计算机科学与博弈论：
程序递归的语义、数据流分析、Cantor–Bernstein 定理、Nash 均衡的存在性，
全都在这个格论框架下获得统一证明。它是完全格理论「投产」的第一站。

## 1 定理陈述：不动点做成一个格

**Tarski–Knaster 不动点定理**：设 $L$ 是完全格，$f : L \to L$ 是保序映射。
则 $f$ 的不动点集合

$$\operatorname{Fix}(f) = \{ x \in L : f(x) = x \}$$

**非空**，且按 $L$ 的序构成一个**完全格**。特别地，最小不动点与最大不动点
分别为

$$\mu f = \bigwedge \{ x \in L : f(x) \le x \}, \qquad \nu f = \bigvee \{ x \in L : x \le f(x) \}$$

- **第一步，读最小不动点**：$\mu f$ 是所有「$f(x) \le x$」
  （即 $f$ 把 $x$ 压下去或压平）的元素的下确界。
  这类元素必存在（$\top$ 总满足 $f(\top) \le \top$），
  下确界也在完全格中存在。
- **第二步，验它是不动点**：需要证明 $f(\mu f) = \mu f$。由 $f$ 保序，
  $f(\mu f) \le \bigwedge \{ f(x) : f(x) \le x \} \le \mu f$；
  反向再用 $f(\mu f) \le \mu f$ 推 $f(\mu f) \in \{x : f(x) \le x\}$，
  从而 $\mu f \le f(\mu f)$。两头夹即等号。
- **第三步，读完全性**：不动点全体的确界、下确界仍是「不动点」吗？——
  不直接是，需证对任意不动点族 $S$，$\bigvee S$ 仍是 $\mu$（或 $\nu$）的变体。
  Tarski 的证明用「把 $f$ 限制在 $[\bigvee S, \top]$ 上再取最小不动点」的
  递归技巧，得到 $\bigvee S$ 本身是 $f$ 的不动点。
  这一步是整个定理「完全格」结论的精华。
  <span class="marginnote">Knaster 在 1928 年（研究 Cantor–Bernstein 定理时）先证明了「不动点存在且全体构成完全格」的核心事实，Tarski 在 1955 年给出系统表述，故得名 Tarski–Knaster。有些人把「不动点非空」叫 Knaster 定理，把「不动点成完全格」叫 Tarski 定理。</span>

## 2 证明的骨架：一次代入，两头夹

证明核心其实只有一步妙棋：**取集合 $A = \{x \in L : f(x) \le x\}$，
令 $a = \bigwedge A$。** 为什么 $a$ 是不动点？

$f$ 保序，故对每个 $x \in A$，$f(a) \le f(x) \le x$，
  从而 $f(a)$ 是 $A$ 的下界，得 $f(a) \le a$。
由 $f(a) \le a$ 再次保序得 $f(f(a)) \le f(a)$，即 $f(a) \in A$，
  于是 $a = \bigwedge A \le f(a)$。
- 合并得 $f(a) = a$。
  <span class="marginnote">「$f(a) \in A$ 所以 $a \le f(a)$」是这套证明最灵巧的一跳：一旦 $f(a)$ 也落入 $A$，最小下界就把它夹住。这一跳不需要连续性、不需要紧致性——纯粹是序结构白送的结果。</span>

**辨析｜易错点：** 定理**不需要** $f$ 连续、不需要 $L$ 有限、不需要 $f$ 单射——
只需「保序」与「完全格」。这与分析里的压缩映射不动点定理
（需要度量与收缩条件）形成鲜明对比：一个靠「序」、一个靠「距离」，
二者互补而不互斥。把「保序」误记成「连续」是最常见的错位。

## 3 计算不动点：从 $\bot$ 向上迭代

存在性之外，Tarski 定理还给出求**最小不动点**的直觉流程。
当 $L$ 满足一定条件时，从 $\bot$ 出发反复应用 $f$：

$$\bot \le f(\bot) \le f^{2}(\bot) \le f^{3}(\bot) \le \cdots \longrightarrow \mu f$$

序列的每个下一项都 $\ge$ 上一项（因为 $\bot \le f(\bot)$ 且 $f$ 保序），
形成一个递增链；若它「停住」（到达某步后 $f^{n+1}(\bot) = f^{n}(\bot)$），
就命中了最小不动点。在有限格中这必然停机。
<span class="marginnote">这个「从底向上迭代到固定点」正是程序分析（数据流分析、抽象解释）的引擎：把程序状态抽象成格，把语义算子当作 $f$，反复迭代到收敛，就是静态分析器的输出。</span>

若把起点换成 $\top$、方向反过来，得到从 $\top$ 递减的序列，
收敛到最大不动点 $\nu f$。程序语义学里：**最小不动点**刻画
「有限时间内可达」的递归结果，**最大不动点**刻画「可以无限持续」的行为
（如活锁、无穷流）——两个不动点编码了两种不同的递归直觉。

## 4 公式解析：为什么「$\bigwedge \{x : f(x) \le x\}$」是最小不动点

把最小不动点公式与「最小元 $\bot$」对照，能看出一种对偶的美：

$$\mu f = \bigwedge \{ x : f(x) \le x \}, \qquad \bot = \bigwedge L = \bigwedge \{ x : \text{无条件} \}$$

- **第一步，看结构**：$\mu f$ 与 $\bot$ 同形——都是「某个集合的下确界」。
  区别只在条件：$\bot$ 的下确界集合是全体 $L$，$\mu f$ 的则是
  「被 $f$ 压住的元素」子集。
- **第二步，看直觉**：$\bot$ 是最小的元素；$\mu f$ 是最小的
  「$f$-准固定点」（满足 $f(x) \le x$）。在 $f$ 迭代下，从 $\bot$ 出发的
  轨道不断上升，第一次「咬合」（$f(x) = x$）就发生在 $\mu f$ 处。
- **第三步，看对偶**：$\nu f = \bigvee \{ x : x \le f(x) \}$ 是
  「$x$ 被 $f$ 拉上去」的元素的**最大**上确界——与 $\mu f$ 完全对偶。
  两个公式合起来是「最小/最大不动点」这对孪生概念的标准记法。

## 5 应用：从集合论到博弈论

- **Cantor–Bernstein–Schröder 定理**：若存在单射 $A \to B$ 与单射 $B \to A$，
  则存在双射。证明用「不对等补集」构造一个幂集格上的保序映射，
  不动点就是「完美配对」的分界集。
  <span class="marginnote">Tarski 本人就以此定理为动机。这个古典集合论定理的不动点证明，比任何手工构造都干净。</span>
**程序语义学**：递归方程 $F = \lambda x.\ \text{if}\ \ldots\ \text{then}\ F(x)\ \ldots$
  的语义是某个完全格（如 Scott 域）上的最小不动点。
  这正是第4篇 Domain 理论的核心技术。
**数据流分析**：可达性、活跃变量等分析，把格当作「事实集合」，
  迭代算子直到不动点。
- **博弈论**：Kakutani 不动点定理与 Nash 均衡存在性，虽属拓扑不动点传统，
  但其「格不动点」版本同样成立，用于某些离散博弈。

## 6 从 Knaster 到 Kleene：两种不动点的对比

Tarski 定理保证「不动点存在且成完全格」，但它没有给出**计算**不动点的方法。
在实际应用中，我们常常需要显式地逼近不动点，这就要用 **Kleene 迭代定理**
（它将在第4篇 Domain 理论中完整登场）。

**Kleene 定理（预备版）**：设 $L$ 是完全格，$f : L \to L$ 保序，
且从 $\bot$ 出发的迭代序列 $f^n(\bot)$ 是递增的（这由 $\bot \le f(\bot)$
与 $f$ 保序自动保证）。若这个序列「收敛」——即存在 $n$ 使
$f^{n+1}(\bot) = f^n(\bot)$——则 $f^n(\bot)$ 是 $f$ 的最小不动点。

**对比**：

| 定理 | 条件 | 结论 | 计算性 |
| --- | --- | --- | --- |
| Tarski | 完全格 + 保序 | 不动点非空、成完全格 | 非构造性 |
| Kleene | 完全格 + 保序 + 迭代收敛 | 最小不动点 = 迭代极限 | 可计算逼近 |

**辨析｜易错点：** Tarski 的「存在性」不需要任何收敛条件，
Kleene 的「计算性」需要迭代真的停下（或取无穷极限）。
在有限格中，从 $\bot$ 出发的迭代必然在有限步收敛；
在无限格中可能无限逼近——此时最小不动点是「有向并」$\bigvee_n f^n(\bot)$
（需要第24节的有向并概念）。

**应用：程序的数据流分析**。编译器分析「哪些变量可达」「哪些表达式活跃」时，
格 = 「事实集合」（幂集格），语义算子 = 保序映射，
算法 = 从 $\bot$（空事实）反复迭代到不动点。
**每个静态分析器都是 Knaster–Tarski 定理的一个实例**——
理解不动点定理，等于理解编译器背后的数学。

**练习**：设 $L = \mathcal{P}(\{1,2,3\})$，$f(S) = S \cup \{1\}$
（把 1 加进集合）。求 $f$ 的所有不动点；从 $\bot = \emptyset$ 出发迭代，
几步行到最小不动点？（答案：不动点 = 含 1 的子集；
$\emptyset \to \{1\}$ 一步即停，最小不动点 $\{1\}$。）
<span class="marginnote">这个例子虽小，却完整演示了「迭代收敛到不动点」的全部机制：$f$ 单调地把 1「注入」集合，从空集出发，一步到位。真实编译器里的数据流分析，就是把这种小格换成包含上万变量的大型幂集格，机制一模一样。</span>

## 7 小结

- **Tarski–Knaster 定理**：完全格上保序自映射的不动点非空，且构成完全格。
- 最小/最大不动点由 $\mu f = \bigwedge\{x : f(x) \le x\}$ 与
  $\nu f = \bigvee\{x : x \le f(x)\}$ 给出。
- 证明精髓：取「$f(x) \le x$
