## 为什么从代数格开始

完全格已经「所有确界都在」，但结构太大太抽象。
为了给计算机科学的**指称语义（denotational semantics）**提供精确模型，
Dana Scott 在 1970 年代引入了一类「好脾气」的完全格：**代数格（algebraic
lattice）**与**连续格（continuous lattice）**。它们的核心想法是
「**由有限信息生成无限对象**」：每个元素都能写成它之下若干「紧致元」
（有限信息）的有向并。就像实数由有理数逼近、程序输出由有限步计算逼近，
代数格把「逼近」这个词代数化、格论化。这一节是 Domain 理论的序理论地基，
也是本专题通往「计算机科学里的序」的桥头堡。
<span class="marginnote">Scott 的动机是给 λ-演算找一个不动点语义：递归程序需要「不断迭代到极限」的模型。他发现完全格 + 有向并 + 紧致元恰好满足一切需要——连续格理论由此诞生，并直接催生了 Domain 理论这一整支学科。</span>

## 1 有向并：偏序集的「极限」

在偏序集里，序列 $a_1 \le a_2 \le \cdots$ 的「极限」应该是什么？
答案是**有向集（directed set）的并**。非空子集 $D \subseteq P$ 若任意两元素
都有上界在 $D$ 中（$x, y \in D \Rightarrow \exists z \in D,\ x \le z \ge y$），
则 $D$ 是**有向集**。它的上确界 $\bigvee D$ 称为**有向并（directed join）**。

有向并是「一致逼近」：有向集里的元素互相协调地朝一个目标聚拢。
$[0, 1)$ 中的序列 $1 - \tfrac1n$ 是有向集，其有向并是 $1$——
**有向并就是格论里的极限**。
<span class="marginnote">注意有向集不必是全序：一个「有公共上界」的任意族也构成有向集。有向并的地位类比数学分析的序列极限，但它不需要度量——只需要序。Scott 连续性（下节）就是「保极限（有向并）」的映射。</span>

## 2 紧致元：有限信息的化身

设 $L$ 是完全格，$c \in L$。若对**任意有向集** $D$：

$$c \le \bigvee D \ \Longrightarrow\ \exists\, d \in D,\ c \le d$$

则称 $c$ 是**紧致元（compact element）**。
<span class="marginnote">紧致元的直觉：<strong>一旦 $c$ 被一个「极限」覆盖，它早就被极限里的某一项覆盖。</strong> $c$ 是「有限的」——它对一切逼近过程都「提前命中」。在幂集 $\mathcal{P}(X)$ 里，紧致元恰是有限集；在环的理想格里，紧致元恰是有限生成理想。这也是「紧致」一词的来历：$c \le \bigvee D$ 时总能「有限步」抓到证据 $d$。</span>

**辨析｜易错点：** 紧致元不是「紧拓扑空间」的元素，但概念同源——
都是「无限覆盖可约化为有限子覆盖」的抽象。判定紧致性时，
**必须对一切有向集**验证，不能只看全序序列。$\mathbb{R}$ 作为完全格
（加 $\pm\infty$）里，唯一紧致元是 $\bot$，因为任何非最小实数的
「下方有向逼近」都能绕开它。

## 3 代数格：紧致元生成一切

**代数格（algebraic lattice）**是完全格 $L$，使得**每个元素都是有向并**：

$$\forall\, x \in L,\quad x = \bigvee \{ c \in K(L) : c \le x \}$$

其中 $K(L)$ 是 $L$ 的全体紧致元。直觉：**每个元素都能被它下方紧致元的
有向并「算出来」**——无限对象由有限近似构成。
<span class="marginnote">幂集 $\mathcal{P}(X)$ 是代数格：$S = \bigcup\{F : F \subseteq S, F \text{ 有限}\}$，紧致元 = 有限集。环 $R$ 的理想格 $\operatorname{Id}(R)$ 是代数格：每个理想 = 所有包含于它的有限生成理想之并。子群格也是代数格。</span>

**定理（代数格的刻画）**：完全格 $L$ 是代数格 ⟺ $L$ 同构于某个
「代数闭包算子」的闭元格，即 $L \cong P_c$，其中 $c$ 是幂集
$\mathcal{P}(X)$ 上的闭包算子、且对一切 $x$，$c(x) = \bigcup\{c(F) : F \subseteq x \text{ 有限}\}$
（代数闭包算子）。
<span class="marginnote">这条刻画把代数格拉回第1篇的闭包算子：代数格正是「代数闭包算子的闭元格」。而「代数闭包算子」的典型例子正是「生成」类操作——张成子空间、生成子群、生成理想。<strong>代数 = 有限生成近似</strong>，这条线从泛代数一路贯到域论。</span>

## 4 公式解析：紧致元的判定

把紧致元的定义展开成「有限覆盖」式：

$$c \le \bigvee D \iff \exists\, d \in D,\ c \le d \qquad (\text{对一切有向 } D)$$

- **第一步，读「⟸」**：若 $c \le d$ 且 $d \in D$，则 $d \le \bigvee D$，
  故 $c \le \bigvee D$。这个方向恒真——「被某一项盖住」当然推出「被并盖住」。
- **第二步，读「⟹」**：$c \le \bigvee D$ 时，要求「提前命中」——
  $c$ 不能只靠无限多项合力盖住，必须有一项单独盖住。
  **紧致性把「无限协作」排除在外**：$c$ 太「小」（有限），扛不起无限联盟。
- **第三步，读例子**：在 $\mathcal{P}(\mathbb{N})$ 中，$c = \{5\}$：
  $c \subseteq \bigcup D$ 时（$D$ 有向，按包含），必有某个 $d \in D$ 含 $5$，
  故 $\{5\}$ 紧致。而 $c = \mathbb{N}$：$D = \{\{0,1,\dots,n\}\}$ 的有向并是
  $\mathbb{N}$，但没有单个 $d$ 含全部 $\mathbb{N}$，故 $\mathbb{N}$ 不紧致。
  **有限 ⇔ 紧致**，一目了然。
- **第四步，读哲学**：紧致元是「信息量有限的元素」。代数格断言
  「每个元素的信息 = 它的全部有限片段的信息之极限」——这与实数的
  「每个实数 = 有理数序列的极限」异曲同工，只是用序代替了度量。

## 5 连续格与 way-below 关系

代数格要求「紧致元」存在且生成一切。**连续格（continuous lattice）**
放宽到更一般的**way-below 关系（way-below relation）** $x \ll y$：
对一切有向集 $D$，

$$y \le \bigvee D \ \Longrightarrow\ \exists\, d \in D,\ x \le d$$

（直观：$x$「远远小于」$y$，只要 $y$ 被一个极限覆盖，$x$ 就被其中某一项覆盖。）
**连续格**是完全格 $L$，使得每个元素都是「way-below 于它」的元素的有向并：

$$\forall\, y,\quad y = \bigvee \{ x : x \ll y \}$$

<span class="marginnote">紧致元与 way-below 的区别：$c \ll c$ 时 $c$ 是紧致元；而 $x \ll y$ 允许 $x$ 比 $y$ 小得多、不是「自身就够」。连续格比代数格宽泛——它不要求存在「可数」的紧致元底座，只要求「层层逼近」的关系足够丰富。实数轴 $[0,1]$ 作为完全格是连续格但不是代数格（紧致元只有 $0$），因为 $x \ll y$ 在 $x \lt  y$ 时处处成立。</span>

**连续映射（Scott 连续）**：$f$ 保有向并，即 $f(\bigvee D) = \bigvee f(D)$。
Scott 连续映射正是「保极限」的映射——连续格与 Scott 连续映射构成
Domain 理论的主角范畴。

## 6 从格论到程序设计

**指称语义**：递归程序 $P$ 的语义被定义为「语义泛函 $f$ 的最小不动点
  $\mu f$」；$f$ 作用在某个（代数/连续）格上，从 $\bot$ 出发迭代到不动点——
  正是 Tarski 定理 + 有向并逼近的组合。
  <span class="marginnote">一段递归函数 `fact = λn. if n=0 then 1 else n*fact(n-1)` 的语义，就是某个定义域格上的最小不动点。Scott 用连续格证明了这类「方程」总有解，且解可由「有限步计算的极限」逼近——这是现代编程语言语义学的基石。</span>
**抽象解释**：程序分析的抽象域（区间、常量、形状）是代数格；具体语义与
  抽象语义之间的 Galois 联络（第23节）给出「抽象是具体的保真压缩」。
**数据流分析**：第11节已见——格上的迭代到不动点。代数格的紧致元保证
  迭代在有限步内收敛到不动点。
- **拓扑联系**：连续格带一个自然的 Scott 拓扑（开集 = 上集 + 某种
  「有向并可达」条件）；连续格理论因此与拓扑、domain 的拓扑表示密切交织。

## 7 实操：代数格的紧致元识别与 Domain 编程

代数格的理论再漂亮，落地到具体对象还需要「认得紧致元」。
这里给出最常见的几个代数格的紧致元清单：

| 格 | 紧致元 | 为什么 |
| --- | --- | --- |
| $\mathcal{P}(X)$ | 有限集 | $S \subseteq \bigcup D$ 时有限 $S$ 落在某个 $d$ 里 |
| 理想格 $\operatorname{Id}(R)$ | 有限生成理想 | $I \subseteq \bigvee$ 时生成元有限个，落在某理想 |
| 子群格 | 有限生成子群 | 同理，有限生成 = 紧致 |
| $[0,1]$ | 只有 $\{0\}$ | 开区间逼近绕开一切非零元素 |
| $\mathcal{P}_{\mathrm{fin}}(\mathbb{N})$ 的下闭包 | 有限子集 | 幂集的「有限版本」 |

**辨析｜易错点：** $[0,1]$ 作为完全格**不是**代数格（紧致元只有 $0$，
无法生成 $0.5$），但它是**连续格**（$x \ll y$ 对 $x \lt  y$ 处处成立）。
所以「代数格 ⊂ 连续格」严格成立——**紧致元太稀有时，way-below 关系仍能
保证逼近**。识别一个格是代数还是连续，就数紧致元够不够「多」。

**Domain 理论里为什么必须用有向并**：程序的语义需要一个「一致性」概念——
一堆信息片段必须互相协调才能并起来。有向集正是「互相协调的片段族」：
任意两个片段都被某个更大的片段包含。**任意的并（如把两个冲突事实并起来）
没有意义，有向并才有**——这是 Domain 与一般完全格的分水岭。

**递归语义的完整流程**（把前面所有概念串起来）：

1. 定义语义域 $D$（如「整数流」的 dcpo，$\bot$ = 空流）。
2. 定义语义泛函 $f : D \to D$（递归方程的右端），证明它 Scott 连续。
3. 由 Kleene 定理，最小不动点 $\mu f = \bigvee_n f^n(\bot)$ 是递归方程的解。
4. 若要「可计算」，要求 $D$ 是代数格（紧致元 = 有限信息），则每个
   $f^n(\bot)$ 都是「有限步计算结果」——程序可被有限逼近。
   <span class="marginnote">这套「域 + 连续 + 最小不动点 + 紧致逼近」四件套，是 Dana Scott 在 1969 年给 $\lambda$-演算找到数学模型后确立的范式。它回答了「递归程序为什么有数学意义」——因为在域上，递归 = 最小不动点 = 有限近似的极限。</span>

**练习**：设 $D$ 是「自然数流」域（元素是有限或无限的自然数序列，
$\le$ = 前缀序，$\bot$ = 空序列）。验证 $D$ 是有向完备的；指出哪些元素是
紧致元。（答案：有限序列是紧致元；无限序列不是。）再定义「过滤偶数」算子
$f$，验证 $f$ Scott 连续。

## 8 小结

- **有向并** = 格论的极限；有向集是「互相协调聚拢」的族。
- **紧致元**：$c \le \bigvee D \Rightarrow \exists d,\ c \le d$；
  有限集、有限生成理想都是紧致元。
- **代数格**：每元素 = 下方紧致元的有向并；等价于代数闭包算子的闭元格。
- **way-below 关系 $x \ll y$
