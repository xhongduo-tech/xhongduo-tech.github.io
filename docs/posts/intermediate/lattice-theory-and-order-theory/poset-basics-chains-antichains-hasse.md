## 为什么从偏序集基础开始

本专题的前四篇系统走完了格论的全程：从偏序集、格、分配格、布尔代数，
到 Galois 联络、Stone 对偶与 Domain 理论。现在进入第5篇，我们把全部知识
重新折叠成一份「复习精讲」。折叠的第一站，是最基础的**偏序集**——
一切秩序结构的起点。复习不是抄一遍定义，而是要回答一个更尖锐的问题：
**给定一张哈斯图，你能立刻说出它的链、反链、高度与宽度吗？**
这正是本篇要训练的能力。链与反链是一张序结构里「最整齐」与「最散乱」
的两极，Dilworth 与 Mirsky 两条定理用两条等式把它们锁死，
而哈斯图则给了我们一双直接「看见」它们的眼睛。
这份基础能力将支撑后面每一讲的直觉：格里的链、分配格里的素理想、
布尔代数里的原子，全都长在这片土壤上。

## 1 三公理回顾：偏序的判定

**偏序（partial order）**是一个集合 $P$ 上的二元关系 $\le$，
满足对一切 $a, b, c \in P$ 三条公理：

- **自反性（reflexivity）**：$a \le a$；
- **反对称性（antisymmetry）**：$a \le b$ 且 $b \le a$ 蕴含 $a = b$；
- **传递性（transitivity）**：$a \le b$ 且 $b \le c$ 蕴含 $a \le c$。

配上偏序的集合 $(P, \le)$ 称为**偏序集（poset）**。
<span class="marginnote">判定一个关系是不是偏序，只需逐条验证三公理。最常见的错误是把「可比」与「有序」混为一谈：偏序只约束「两个方向都成立」的情形，从不要求任意两元素都比大小——那是全序的要求。</span>

**辨析｜易错点：** 偏序的「偏」字是关键。$(\mathbb{N}, \le)$ 中任意两数可比，
是全序；而 $(\mathcal{P}(\{1,2,3\}), \subseteq)$ 中 $\{1,2\}$ 与 $\{2,3\}$
互不包含，**不可比**——它只是偏序。可比性（comparability）与偏序本身
是两个独立概念，判断一张图是不是哈斯图时最容易在这里出错。

## 2 链、反链与哈斯图上的几何直觉

偏序集内部有两类最基本的「组织」：

**链（chain）**：两两可比的子集 $C$——排成一条纵向的「纵队」。
**反链（antichain）**：任意两个不同元素都不可比的子集 $A$——散成一片「横队」。

单元素集既是链也是反链；空集按约定两者都是。
<span class="marginnote">在幂集格 $\mathcal{P}(X)$ 中，链是「逐层递增的子集序列」，反链是「两两互不包含的子集族」——后者正是组合数学里的 Sperner 族。</span>

**阅读哈斯图的三条口诀**：

- **纵向看链**：沿边从下往上走，每一步都可比，走出一条链。
- **横向看反链**：同一层（同基数或同秩）的点，往往两两不可比，构成反链。
- **传递闭包**：图里没画出来的边（如 $a \le c$ 但中间隔着 $b$），
  沿覆盖边仍能走通——判定可比永远回到定义，而非「图上有没有线」。

**辨析｜易错点：** 「同层」与「不可比」不是一回事。按基数分层只是画图的
排版习惯；判断不可比永远要问：$x \le y$ 与 $y \le x$ 是否都不成立。
同一层里两个点也可能可比（例如被并列但基数相同），只是通常不会画成同层。

## 3 高度与宽度：两个极端量

偏序集的两个最重要的标量，刻画了它的「长短」与「胖瘦」：

$$\operatorname{height}(P) = \max\{|C| : C \text{ 是 } P \text{ 的链}\}, \qquad \operatorname{width}(P) = \max\{|A| : A \text{ 是 } P \text{ 的反链}\}$$

- **高度（height）**：最长链的元素个数，衡量偏序集「多深」。
- **宽度（width）**：最大反链的大小，衡量偏序集「多宽」。

例：布尔格 $B_n = (\mathcal{P}(\{1,\dots,n\}), \subseteq)$ 的高度是 $n+1$
（一条从 $\emptyset$ 到全集的链），宽度由**Sperner 定理**给出。

**定理（Sperner, 1928）**：$\mathcal{P}(\{1,\dots,n\})$ 中最大的反链
（即两两互不包含的子集族）大小为中间层的组合数：

$$\operatorname{width}(B_n) = \binom{n}{\lfloor n/2 \rfloor}$$

对 $n = 3$，宽度为 $\binom{3}{1} = 3$——三个单点集（或三个双点集）
构成最大反链，这在本专题《链、反链与 Dilworth 定理》一节已亲手验证过。
<span class="marginnote">Sperner 定理是「宽度」思想的第一朵花：它断言布尔格最「胖」的一层在中间。抽屉原理式的证明靠「把每个子集对应到一条对称链」的 LYM 不等式（Lubell–Yamamoto–Meshalkin），是现代极值组合的经典入口。</span>

## 4 公式解析：Erdős–Szekeres 与宽度的下界

高度与宽度联起来，给出一个「面积」式的下界。设 $P$ 有 $N$ 个元素，
则每条链至多含 $\operatorname{height}(P)$ 个元素，而一个元素至多属于
一条链——于是要把 $N$ 个元素塞进 $h$ 条链，宽度必须足够大：

$$w(P) \ge \left\lceil \frac{N}{\operatorname{height}(P)} \right\rceil$$

- **第一步，读链划分**：把 $P$ 划分为 $\operatorname{cover}(P)$ 条互不相交的链。
  每条链长 $\le h = \operatorname{height}(P)$，故 $N \le \operatorname{cover}(P) \cdot h$，
  得 $\operatorname{cover}(P) \ge \lceil N / h \rceil$。
- **第二步，读 Dilworth**：Dilworth 定理说 $\operatorname{cover}(P) = w(P)$，
  代入即得 $w(P) \ge \lceil N / h \rceil$。这个「宽度 ≥ 面积/高度」的式子，
  是极值组合里大量下界估计的模板。
- **第三步，读推论（Erdős–Szekeres）**：把序列 $(a_1, \dots, a_N)$ 上的
  有序对 $(i, a_i)$ 按「$i \lt j$ 且 $a_i \lt a_j$」排成偏序，
  链 = 递增子序列，反链 = 递减子序列。若最长递增子序列长 $< p$、
  最长递减子序列长 $< q$，则高度 $< p$、宽度 $< q$，于是
  $N \le (p-1)(q-1)$。**任何长度 $(p-1)(q-1)+1$ 的序列，必有长度 $p$
  的递增子序列或长度 $q$ 的递减子序列**——这就是著名的
  Erdős–Szekeres 定理，它只是 Dilworth 定理的一句话推论。

**辨析｜易错点：** 上式的等号不一定取到。$w(P) \ge \lceil N/h \rceil$
是最差情形下的「必然存在反链」的保证，它说明**大而矮**的偏序集
必然很宽——这正是抽屉原理在序结构上的化身。

## 5 对偶的双镜：Dilworth 与 Mirsky 并列

把「链」与「反链」对调，两张镜子照出同一个偏序集：

- **Dilworth 定理**：最小链覆盖数 $=$ 宽度
  $\operatorname{cover}(P) = w(P)$。
- **Mirsky 定理**：最小反链覆盖数 $=$ 高度。

**宽度 ↔ 最小链覆盖，高度 ↔ 最小反链覆盖**：二者互为对偶，
一个是深度结果（Dilworth 的证明不平凡，需归纳或 König 匹配定理），
另一个是浅层观察（Mirsky 只需按最长链分层）。
<span class="marginnote">对偶原则在这里显灵：把「链」换成「反链」、把「上确界」换成「下确界」，一个真命题通常对偶成另一个真命题。本专题所有结构定理几乎都能成对出现，Dilworth–Mirsky 是最早也是最可爱的一对。</span>

**辨析｜易错点：** Dilworth 与 Mirsky 结论不同、证明难度也完全不同。
「高度 = 最小反链覆盖」的 Mirsky 定理证明平凡，而「宽度 = 最小链覆盖」
的 Dilworth 定理则需要真正的工作。把两者张冠李戴是复习时最常见的事故。

## 6 复习题：从哈斯图读出四项指标

用一张具体的哈斯图收束复习。设 $P$ 是 $\{a,b,c\}$ 的幂集去掉
$\emptyset$ 与 $\{a,b,c\}$ 后的六个中间子集，按包含序排列：

- **第一步，求链**：$\{a\} \subseteq \{a,b\}$ 是 2 元链，没有更长的，
  故高度 $h = 2$。
- **第二步，求反链**：三个单点集 $\{a\}, \{b\}, \{c\}$ 两两不可比，
  构成 3 元反链，宽度 $w \ge 3$。
- **第三步，求链覆盖**：用 3 条链覆盖全部 6 个元素——
  $\{a\} \subseteq \{a,b\}$、$\{b\} \subseteq \{b,c\}$、$\{c\} \subseteq \{a,c\}$。
  由 Dilworth 定理，最小链覆盖 $= w = 3$。
- **第四步，核对面积**：$N = 6$，$w \ge \lceil 6/2 \rceil = 3$，
  下界恰好达到。高度与宽度在这张小图上精确对偶。

**综合练习**：把 $P$ 换成完整布尔格 $B_3$（8 个元素）。它的高度是 4
（$\emptyset$ 到 $\{a,b,c\}$ 的整条链），宽度由 Sperner 定理为
$\binom{3}{1} = 3$，Dilworth 给出最小链覆盖数 3——把 $B_3$ 切成
3 条长度为 4、2、2 的链。**看得到高度与宽度，就看得懂一张哈斯图。**

## 7 小结

- **偏序** = 自反 + 反对称 + 传递；可比性与偏序是两个概念，
  **全序**是「任意两元素可比」的特殊偏序。
- **链** = 两两可比，**反链** = 两两不可比；高度 = 最长链长，
  宽度 = 最大反链大小。
- **Dilworth**：最小链覆盖 $=$ 宽度；**Mirsky**：最小反链覆盖 $=$ 高度。
- **Sperner**：$B_n$ 的宽度是 $\binom{n}{\lfloor n/2 \rfloor}$；
  Erdős–Szekeres 是 Dilworth 的一句话推论。
- 哈斯图是读结构的两只眼睛：纵向看链、横向看反链、传递闭包补全可比。
