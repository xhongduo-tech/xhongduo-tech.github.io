## 为什么从闭包算子开始

「取闭包」是数学里最频繁的隐性操作：线性代数里张成子空间、
拓扑学里取闭包、代数里生成子群、关系数据库里求传递闭包——
它们共享同一条规则：**任给一个集合，把它「撑满」成一个更完整、更闭合的对象，
并且撑一次就够**。序理论把这条规则抽象成**闭包算子**，并发现了一个惊人的
对偶事实：**闭包算子的全部信息，等价于它不动点（闭元）所构成的一个完全格**。
这一节因此既是第1篇的收官，又是第2篇「完全格」与第4篇「Galois 联络」的
直接跳板——Galois 联络两端各取一次闭包，恰是闭包算子的标准来源。

## 1 闭包算子：三条公理

设 $(P, \le)$ 是偏序集，映射 $c : P \to P$ 若满足下列三条，
则称 $c$ 是 $P$ 上的**闭包算子（closure operator）**：

- **扩张性（extensive）**：$x \le c(x)$；
- **单调性（monotone）**：$x \le y \Rightarrow c(x) \le c(y)$；
- **幂等性（idempotent）**：$c(c(x)) = c(x)$。

<span class="marginnote">三条公理各有分工：扩张性保证「只增不减」，单调性保证「保序」，幂等性保证「一次成型」。缺失任何一条都会破坏「闭包」的直觉。比如「内点算子」满足单调与幂等但不扩张（$c(x) \le x$），它叫<strong>内部算子</strong>，是闭包的对偶。</span>

**辨析｜易错点：** 闭包算子不要求 $c(x)$ 与 $x$ 的关系是「$x$ 到 $c(x)$
可比较」之外更多的东西——$c(x)$ 是 $P$ 中的普通元素。
它把 $x$ 映到一个「更大的闭合对象」，这个对象本身也可能是某个 $y$ 的闭包。

## 2 处处可见的闭包算子

- **向量空间的张成**：$P = \{\text{所有子空间}\}$ 按包含序，
  $c(S) = \operatorname{span}(S)$ 是闭包算子。扩张性：$S \subseteq \operatorname{span}(S)$；
  幂等性：张成的张成仍是张成。
- **拓扑闭包**：$P = \mathcal{P}(X)$，$c(A) = \overline{A}$
  是拓扑意义下的闭包——这也是「闭包」一词的原始出处。
- **群的生成**：$P = \{\text{所有子群}\}$，$c(H)$ 是包含 $H$ 的最小子群。
- **传递闭包**：$P = \mathcal{P}(X \times X)$ 按包含序，$c(R)$ 是包含关系 $R$
  的最小传递关系。
- **代数闭包**：有理数域的代数闭包 $\overline{\mathbb{Q}}$，
  或对任意域取其代数闭包。

每个闭包算子都对应一个核心概念：**闭元（closed element）**——
满足 $c(x) = x$ 的元素。拓扑闭包下的闭元是闭集，张成下的闭元是子空间，
传递闭包下的闭元是传递关系。

## 3 闭元构成完全格：本节主角

**定理**：若 $c$ 是偏序集 $P$ 上的闭包算子，令
$P_c = \{x \in P : c(x) = x\}$ 为全体闭元，则 $(P_c, \le)$ 是一个**完全格**。

对任意子集 $S \subseteq P_c$，需要给出确界。关键观察：$P_c$ 中元素的
**下确界与 $P$ 中的下确界一致**（因为闭元的交仍是闭元），而
**上确界必须经过闭包修正**：

$$\bigwedge_{P_c} S = \bigwedge_P S, \qquad \bigvee_{P_c} S = c\Big(\bigvee_P S\Big)$$

- **第一步，读下确界**：$S$ 的下界集合 $S^{l}$ 中若有最大者，它天然是闭元吗？
  严格论证靠「闭元的交仍是闭元」：闭元族的下确界（即交集）仍是闭元。
- **第二步，读上确界**：$\bigvee_P S$ 可能不是闭元，但把它闭包化
  $c(\bigvee_P S)$ 后，它是 $S$ 的**最小闭上界**——这正是 $P_c$ 中的上确界。
  闭包扮演了「撑满」的角色。
- **第三步，读结论**：$P_c$ 的任意子集都有确界（在 $P_c$ 内），故 $P_c$ 是完全格。
  <span class="marginnote">「闭元的交仍是闭元，闭元的并不必闭」是闭包理论的招牌事实：拓扑闭集的可数并不必是闭集，传递关系的并不必传递。这解释了为什么格论要区分交与并——它们对闭包的行为不对称。</span>

## 4 公式解析：闭包算子 ⇄ 完全格的对应

闭包算子与完全格之间存在**一一对应**，这是本节最深刻的结论：

$$c \longleftrightarrow P_c, \qquad \text{给定完全格 } L,\ c_L(x) = \bigwedge \{ y \in L : x \le y \}$$

- **第一步，算子 → 格**：$c$ 的所有闭元 $P_c$ 构成完全格（上节定理），方向一成立。
- **第二步，格 → 算子**：给定完全格 $L$（嵌在某个偏序集 $P$ 中），定义
  $c_L(x)$ 为「所有含 $x$ 的 $L$ 元素的下确界」——把 $x$ 撑成 $L$ 中最小的上界。
- **第三步，验等价**：$c_L$ 是闭包算子（扩张：$x \le c_L(x)$ 由下确界定义保证；
  幂等：$c_L(c_L(x))$ 仍是同样的最小 $L$-上界），且 $c_L$ 的闭元恰好是 $L$ 本身。
- **第四步，读意义**：**完全格与闭包算子不过是同一结构的两副面孔。**
  任何一个完全格都能被嵌入某个大偏序集（如幂集）并作为闭包算子的不动点集合
  现形——这为 Dedekind–MacNeille 完备化（第2篇）与代数格的紧致元理论（第4篇）
  埋下伏笔。

## 5 例：从 Galois 联络到闭包算子

闭包算子最常见的来源是**一对反序映射的复合**。若 $R \subseteq X \times Y$ 是关系，
定义两个方向映射：

$$x^{\uparrow} = \{ y \in Y : (x,y) \in R \}, \qquad y^{\downarrow} = \{ x \in X : (x,y) \in R \}$$

则复合 $c(X') = (X'^{\uparrow})^{\downarrow}$ 是 $\mathcal{P}(X)$ 上的闭包算子：
从 $X'$ 出发，「所有与 $X'$ 全部相关的 $y$」再「所有与这些 $y$ 全部相关的 $x$」——
两次对偶筛选后，剩下的正是与 $X'$ 「互相绑定」的闭元素。
<span class="marginnote">经典实例：$X$ = 多项式方程组，$Y$ = 点集，$R$ = 「多项式在点处为零」。$X'$ 的闭包是「由 $X'$ 生成的理想所定义的所有零点」；而 $(X'^{\uparrow})^{\downarrow}$ 的闭包正是这个理想对应代数簇的「径向闭包」。这套机制在第4篇 Galois 联络一节将被系统化。</span>

## 6 闭包算子的典型构造：三种来源

闭包算子从哪来？除了直接定义，有三种系统化的构造方法，值得记住：

**来源一：一对反序映射复合**。$f : P \to Q$、$g : Q \to P$ 都是反序映射且
$x \le g(f(x))$、$y \le f(g(y))$ 时，$c = g \circ f$ 是 $P$ 上的闭包算子
（第5节已见，Galois 联络的标准产物）。代数几何里「理想 → 零点集 → 理想」
就是这种复合。

**来源二：族并的「最小封闭超集」**。设 $\mathcal{F}$ 是 $P$ 的一族
「封闭对象」（如全部子空间、全部子群），对任意 $x$，定义

$$c(x) = \bigwedge \{ y \in \mathcal{F} : x \le y \}$$

即「包含 $x$ 的最小封闭对象」。$\mathcal{F}$ 若对「任意族的下确界」封闭
（如子空间的任意交仍是子空间），则 $c$ 是良定义的闭包算子。
**张成、生成子群、传递闭包全部是这个模式**：取「包含给定物的最小封闭超集」。

**来源三：反复施加「基本运算」直到封闭**。关系 $R$ 的传递闭包可以这样构造：
$R^{+} = R \cup R^2 \cup R^3 \cup \cdots$（不断复合自身）。
这个「迭代到不动点」的思路正是 Tarski 不动点定理（第2篇）的先声——
闭包算子与不动点定理在此汇合。

**辨析｜易错点：** 来源二要求「封闭对象的任意下确界仍封闭」。
拓扑闭集的**任意交**是闭集（成立），所以闭包良定义；但若 $\mathcal{F}$
只对有限下确界封闭（如「有限维子空间」族），来源二的 $c(x)$ 可能不落在
$\mathcal{F}$ 内，需要「取极限」——这正是「代数格里的紧致元」要处理的情形（第4篇）。

**实例：整数的「平方因子核」**。在 $\mathbb{N}^{+}$ 上定义 $c(n)$ =
「$n$ 的所有质因子各取一次」即 $n$ 的无平方因子核。验证：$n \le c(n)$？不——
$c(n)$ 通常比 $n$ 小（如 $c(12) = 6$）。这不是闭包算子（不扩张）。
