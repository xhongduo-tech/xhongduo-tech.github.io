## 为什么从量子逻辑开始

第20节我们初遇正交模格（OML），知道它是希尔伯特空间闭子空间格的逻辑。
现在我们把这段纲领完整展开：**量子逻辑（quantum logic）**是 Birkhoff 与
von Neumann 在 1936 年那篇划时代论文《量子力学的逻辑》中提出的主张——
**量子系统的事件不满足分配律，因而不能用布尔逻辑描述**。这个主张引发了
物理、数学、哲学三方近一个世纪的争论：Gleason 定理给出 OML 上的概率测度，
Kochen–Specker 定理证明「隐变量」不可能，von Neumann 代数把 OML 拉进
算子代数。本节把量子逻辑的格论基础、结构定理与测量理论串成一条线，
展示格论如何直接参与量子物理的基础建设。
<span class="marginnote">「从极限到大模型」的读者此时已站在数学与物理的交叉路口：正交模格是「格论（纯序结构）」与「量子力学（物理理论）」之间最短的桥。量子计算的逻辑门、投影测量的数学结构，都住在这座桥上。</span>

## 1 量子逻辑的诞生：一个反例撼动布尔教条

经典物理的命题（「粒子在区域 $A$ 内」）构成布尔代数——分配律无条件成立，
$P \wedge (Q \vee R) = (P \wedge Q) \vee (P \wedge R)$。Birkhoff 与 von Neumann
指出：**在量子力学中这个分配律失败**。

设 $H = \mathbb{C}^2$，取三个一维子空间 $A = \operatorname{span}(e_1)$、
$B = \operatorname{span}(e_2)$、$C = \operatorname{span}(e_1 + e_2)$。
用闭子空间格计算：

$B \vee C$ = 张成 $e_2$ 与 $e_1 + e_2$ 的二维空间 = $H$
  （因为 $e_1, e_2$ 可被线性组合出）。于是 $A \wedge (B \vee C) = A \wedge H = A$。
$A \wedge B = \{0\}$，$A \wedge C = \{0\}$，故
  $(A \wedge B) \vee (A \wedge C) = \{0\} \vee \{0\} = \{0\}$。
- $A \ne \{0\}$，分配律失败。
  <span class="marginnote">物理含义：量子命题「系统在 $A$ 中」与「在 $B$ 中或 $C$ 中」不能简单分配——因为 $B$ 与 $C$ 的「或」对应的是「张成空间」$H$，而「系统在 $H$ 中」与「在 $A$ 中」的合取并不等于两个分别合取的并。<strong>不相容观测量的存在是分配律失效的物理根源。</strong></span>

**结论**：量子事件的格不是布尔代数，而是正交模格——这就是量子逻辑的出发点。

## 2 闭子空间格：OML 的旗舰模型

设 $H$ 是复希尔伯特空间，$\mathcal{C}(H)$ 是闭子空间格。第20节已证它是 OML：

$$S \vee T = \overline{S + T}, \qquad S \wedge T = S \cap T, \qquad S^{\perp} = \text{正交补}$$

物理翻译：**事件 = 闭子空间，命题否定 = 正交补，合取 = 交，
析取 = 闭线性包**。量子测量「投影到 $S$」对应事件「状态在 $S$ 中」——
投影算子 $P_S$ 与闭子空间 $S$ 一一对应。

**辨析｜易错点：** 量子逻辑的析取 $\vee$ 是「张成 + 取闭包」，
**不是**集合的并。$B \vee C$ 比 $B \cup C$ 大得多（包含所有叠加态）。
这正是「叠加原理」的格论形态：量子或 = 可以取任意线性组合，
而非「非此即彼」。把量子析取误当集合并，是理解量子逻辑的第一道坎。

## 3 OML 的结构：中心、可交换与覆盖律

正交模格不仅有公理，还有精细的结构。两个元素 $a, b$ 若
$a = (a \wedge b) \vee (a \wedge b^{\perp})$，则称它们**可交换（commute）**——
直觉上「同时可测」。OML 的**中心（center）**是「与一切元素可交换」的元素集合，
它构成一个布尔代数。
<span class="marginnote">中心 = 「经典核」：与所有量子事件都不冲突的事件构成一个布尔代数（经典部分）。量子系统的「经典碎片」就住在中心里。von Neumann 代数理论里中心更是核心对象（因子的定义）。</span>

**覆盖律（covering law）**：在 $\mathcal{C}(H)$ 中，若 $a \prec b$
（$a$ 被 $b$ 覆盖，即无中间元素），则对任何 $c \ge a$，$c \wedge b$
也覆盖 $a$ 或等于 $a$。覆盖律在 $\mathcal{C}(H)$ 中成立（由 Hilbert 空间的
正交分解），它是量子逻辑区别于一般 OML 的「几何性」标志。

$$a \prec b, \ a \le c \ \Longrightarrow\ a \prec (b \wedge c) \ \text{或}\ a = b \wedge c$$

**Mackey 纲领**：能否从「事件的 OML + 概率测度公理」推出希尔伯特空间结构？
Mackey 提出公理系统，Gleason 部分回答，但完整还原至今未竟——
这是量子逻辑的「圣杯问题」。
<span class="marginnote">覆盖律的作用是「钦定」希尔伯特空间：加上覆盖律与一定条件，OML 才能被「协调化」成投影格。Greechie 图构造了大量不满足覆盖律的 OML 反例——说明量子逻辑比希尔伯特空间更宽，也说明覆盖律是「几何性」的精确表达。</span>

## 4 公式解析：Gleason 定理——OML 上的概率

量子测量的概率理论由 **Gleason 定理**奠基（1957）：设 $\dim H \ge 3$，
$\mu : \mathcal{C}(H) \to [0,1]$ 是可数可加的测度（$\mu(H) = 1$，
$\mu(S \oplus T) = \mu(S) + \mu(T)$ 对正交 $S, T$）。则存在**密度算子** $\rho$
使

$$\mu(S) = \operatorname{tr}(\rho P_S), \qquad \forall\, S \in \mathcal{C}(H)$$

- **第一步，读内容**：每个「格上的概率测度」都来自一个量子态（密度算子）
  $\rho$。$\mu(S)$ 是「系统处于状态 $\rho$ 时测得事件 $S$ 的概率」，
  即投影测量 $\operatorname{tr}(\rho P_S)$。
- **第二步，读惊讶**：Gleason 的证明极其非平凡——它把「格上的可加测度」
  完全分类，且 $\dim H \ge 3$ 是**必须**的（$\dim H = 2$ 时反例存在）。
  **从 OML 的「逻辑结构」自动推出「量子态的 Born 规则」**，
  这是量子逻辑最深的胜利。
- **第三步，读推论**：$\mu$ 对**正交**子空间可加，但对非正交的 $S, T$，
  $\mu(S \vee T)$ **不等于** $\mu(S) + \mu(T) - \mu(S \cap T)$——
  量子概率**不是**经典概率（不满足「互斥可加」的布尔式）。
  这正是「量子测量与经典概率根本不同」的数学陈述。
  <span class="marginnote">经典概率在布尔代数上定义，量子概率在 OML 上定义。Gleason 定理说明：量子概率看似怪异，却完全由「格 + 可加性」唯一决定。量子信息里的 Born 规则、投影测量、密度矩阵，全部坐落在 Gleason 定理的地基上。</span>

## 5 Kochen–Specker 定理：隐变量之死

**Kochen–Specker 定理（1967）**：在 $\dim H \ge 3$ 的希尔伯特空间中，
**不存在**把每个投影 $P_S$ 赋值为 $0/1$、且满足「对正交分解
$\sum P_{S_i} = I$ 恰有一个为 1」的函数 $v$（全局赋值）。

$$\nexists\, v : \mathcal{C}(H) \to \{0,1\}, \quad v \text{ 尊重正交分解}$$

- **直觉**：如果量子系统存在「隐藏的真实值」（每个投影在测量前就有确定答案），
  就该存在这样的 $v$。Kochen–Specker 证明 $v$ 不存在——
  **真实值不存在，测量创造结果**。
- **与 Bell 不等式的区别**：Bell 否定「局域隐变量」，
  Kochen–Specker 否定「任何与 OML 正交结构一致的隐变量」——
  后者不需要纠缠态，纯靠格论结构。
  <span class="marginnote">Kochen–Specker 的证明是组合的：用有限多个方向构造「不可赋值的 0/1 图案」，把 $\mathcal{C}(\mathbb{R}^3)$ 的正交结构做成一个「无解拼图」。它是量子逻辑对「实在论」最尖锐的格论一击，也是量子计算的「非经典性」的数学根源。</span>

## 6 现代图景与应用

**von Neumann 代数**：von Neumann 代数 $M$ 的**投影格**
  $\operatorname{Proj}(M)$ 是正交模格。若 $M$ 是因子（中心平凡），
  $\operatorname{Proj}(M)$ 是「不可分解」的 OML——量子逻辑与算子代数
  在这一点汇合。
  <span class="marginnote">von Neumann 代数的投影格正是「有补模格」的量子版本；Murray–von Neumann 的分类（I 型、II 型、III 型因子）本质上是投影格分类。量子逻辑于是成为算子代数理论的一条腿。</span>
**量子信息**：量子位的纯态 = 一维子空间，测量 = 投影，
  纠缠 = 张量积下的非乘积子空间。量子逻辑的 OML 语言直接支撑量子计算的
  形式化。
**哲学争论**：量子逻辑是否「真正的逻辑」至今有争议
  （Putnam 曾主张，后撤回；Dummett、Quine 各有立场）。但作为**代数结构**，
  OML 的数学地位无可动摇。

## 7 练习与深化：OML 的结构检验

正交模格的学习需要「动手摸结构」。这里给出一组由浅入深的练习。

**练习一（基本判定）**：$\mathcal{C}(\mathbb{C}^2)$（复二维希尔伯特空间的
闭子空间格）有几个元素？画出它的哈斯图。

解：$\mathbb{C}^2$ 的闭子空间有 $\{0\}$、$\mathbb{C}^2$、以及全体一维子空间
（过原点的直线，无穷多个）。所以 $\mathcal{C}(\mathbb{C}^2)$ 是「底 $\{0\}$、
顶 $\mathbb{C}^2$、中间无穷多条互不可比直线」的格。它不是分配格
（中间任取三条直线就构成 $M_3$ 子格），但仍是 OML。
<span class="marginnote">$\mathcal{C}(\mathbb{C}^2)$ 是「无穷 $M_3$」——中间层有不可数多条直线。这个格极其简单却充满量子性：任意两条不平行不正交的直线不可交换。量子位的所有纯态（布洛赫球上的点）都住在这一层。</span>

**练习二（覆盖律验证）**：在 $\mathcal{C}(\mathbb{C}^2)$ 中，
$a = \{0\} \prec b$（任何一维子空间覆盖 $\{0\}$）。取 $c \ge a$
（$c$ 是一维子空间或 $\mathbb{C}^2$），验证覆盖律：$a \prec b \wedge c$
或 $a = b \wedge c$。

解：若 $c = \mathbb{C}^2$，则 $b \wedge c = b$，$a \prec b$ 成立；
若 $c$ 是一维子空间，则 $b \wedge c = \{0\}$（若 $b \ne c$）或
$b \wedge c = b$（若 $b = c$）。前者 $a = b \wedge c = \{0\}$，
后者 $a \prec b$。**覆盖律成立**——$\mathcal{C}(\mathbb{C}^2)$ 是「好」的 OML。

**练习三（反例构造）**：构造一个不满足覆盖律的 OML。

解：把 $M_3$ 的中间层「加厚」或用 Greechie 图方法。Greechie 图给出的
「环状 OML」就是经典的反例家族。
<span class="marginnote">Greechie 图（1971）用图来表示 OML 的原子结构：节点 = 原子，超图块 = 正交基。大量「无覆盖律」的 OML 反例由此构造，它们揭示了量子逻辑比希尔伯特空间更广——<strong>不是每个 OML 都能住进某个 Hilbert 空间</strong>。这也是 Mackey 纲领至今未竟的深层原因。</span>

**练习四（中心提取）**：在 $\mathcal{C}(\mathbb{C}^2)$ 中求中心。

解：中心 = 与一切元素可交换的元素 = $\{0, \mathbb{C}^2\}$。两个平凡元素，
因为任何非平凡直线都与「倾斜直线」不可交换。**中心的布尔性**：
$\{0, \mathbb{C}^2\}$ 是两元素布尔代数——量子系统的经典部分只有「平凡信息」。

**练习五（量子信息翻译）**：用 OML 语言描述「贝尔态」
$\frac{1}{\sqrt2}(|00\rangle + |11\rangle)$ 在 $\mathbb{C}^2 \otimes \mathbb{C}^2$
中的一维子空间 $B$，及其正交补 $B^{\perp}$。指出 $B$ 与「乘积态子空间」
$S_1 = \operatorname{span}(|00\rangle)$ 是否可交换。

解：$B$ 与 $S_1$ 既不平行也不正交（$\langle B, S_1 \rangle = 1/\sqrt2 \ne 0, 1$），
故**不可交换**——贝尔态与乘积态是「不相容」的量子事件。纠缠的格论表达
就是「不可交换」。

## 8 小结

- **量子逻辑** = Birkhoff–von Neumann 纲领：量子事件格是 OML 而非布尔代数；
  $\mathbb{C}^2$ 三子空间反例轰出分配律。
- 闭子空间格 $(\mathcal{C}(H), \subseteq, ^{\perp})$ 是旗舰模型；
  析取 = 闭线性包（叠加原理），中心 = 经典核。
- **覆盖律**刻画「几何性」，Mackey 纲领尝试从格公理还原 Hilbert 空间。
- **Gleason 定理**：OML 上的可加测度 = 密度算子的 Born 规则；
  $\dim H \ge 3$
