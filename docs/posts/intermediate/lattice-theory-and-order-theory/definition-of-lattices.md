## 为什么从格的定义开始

前几节我们看到，确界与闭包算子不断把偏序结构「代数化」：$\cup$ 与 $\cap$、
$\operatorname{lcm}$ 与 $\gcd$、张成与交集，形形色色的运算都长得一模一样。
现在到了收网的时刻：**凡是一个偏序集任意两元素都有上确界与下确界，
它就是一个格（lattice）**。格最迷人的地方在于它的**双重身份**：
它既是一个序结构，又是一个代数结构（带 $\vee$ 与 $\wedge$ 两个二元运算）。
这两种观点互相翻译，正是「序 ↔ 代数」这一格论主旋律的开场白，
也预告了后面对分配格、布尔代数的全部研究。

## 1 序观点：两两都有确界的偏序集

**格（lattice）**是一个偏序集 $(L, \le)$，其中任意两个元素 $a, b$
都有上确界与下确界。记

$$a \vee b = \sup\{a, b\} \quad (\text{读作「$a$ 并 $b$」，join}), \qquad a \wedge b = \inf\{a, b\} \quad (\text{读作「$a$ 交 $b$」，meet})$$

由确界的唯一性，$\vee$ 与 $\wedge$ 都是 $L$ 上的**二元运算**。
$\vee$ 称为**并运算（join）**，$\wedge$ 称为**交运算（meet）**。
<span class="marginnote">符号约定：许多文献把并记作 $\cup$、交记作 $\cap$，或把并写作 $+$、交写作 $\cdot$（尤其是模格与布尔代数里）。本专题统一用 $\vee, \wedge$。注意「并」是求「最小上界」，与集合的并 $\cup$ 对应但不完全相同。</span>

**辨析｜易错点：** 格要求「**任意两元素**」有确界，不是「任意子集」。
一旦放宽到任意子集，就是**完全格**（下节）。偏序集如「树的祖先-后代关系」
就不是格——两个叶子没有公共后代（下确界）或公共祖先的上确界。

## 2 代数观点：一组运算四条律

换个角度，把 $\vee, \wedge$ 当作**原始运算**。若集合 $L$ 上定义了
$\vee, \wedge : L \times L \to L$，满足对一切 $a, b, c \in L$：

**幂等律**：$a \vee a = a,\ a \wedge a = a$；
**交换律**：$a \vee b = b \vee a,\ a \wedge b = b \wedge a$；
**结合律**：$(a \vee b) \vee c = a \vee (b \vee c),\ (a \wedge b) \wedge c = a \wedge (b \wedge c)$；
**吸收律**：$a \vee (a \wedge b) = a,\ a \wedge (a \vee b) = a$。

则称 $(L, \vee, \wedge)$ 是一个**格**（代数意义）。四条律里，前三条平平无奇
（幂等、交换、结合），**吸收律是格的灵魂**——它把 $\vee$ 与 $\wedge$ 绑在一起，
让两个运算互相「消化」对方，而非各自为政。

## 3 两种定义殊途同归

**定理**：序意义下的格与代数意义下的格是同一概念。

**序 → 代数**：由 $\sup$、$\inf$ 定义的 $\vee, \wedge$ 满足全部四条律。
  吸收律 $a \vee (a \wedge b) = a$ 的证明：因为 $a \wedge b \le a$，所以 $a$
  是 $\{a, a \wedge b\}$ 的上界，且任何上界都 $\ge a$，故 $\sup = a$。
**代数 → 序**：由吸收律可先定义 $a \le b \iff a \wedge b = a$
  （等价地 $a \vee b = b$），证明它是偏序，且 $\vee, \wedge$ 恰为此序下的确界。
  <span class="marginnote">「$a \le b \iff a \wedge b = a$」这条翻译规则，把序完全编码进运算：在集合格中它就是「$a \subseteq b \iff a \cap b = a$」，在整除格中就是「$a \mid b \iff \gcd(a,b) = a$」。以后我们在代数视角下做运算、在序视角下画哈斯图，随心切换。</span>

这个双向翻译意味着：**一切序性质都能被翻译成代数等式，反之亦然**。
格论于是获得双倍的火力——这是分配格、模格、布尔代数全部理论的立足点。

## 4 公式解析：吸收律为什么能消化运算

吸收律看起来「废话」，实则蕴含序结构。拆解 $a \vee (a \wedge b) = a$：

$$a \vee (a \wedge b) = \sup\{ a, \inf\{a, b\} \}$$

- **第一步，看内层**：$\inf\{a, b\} \le a$ 永远成立——
  下确界不超过任一成员。
- **第二步，看外层**：求 $\{a, \inf\{a,b\}\}$ 的上确界，其中 $a$ 本身
  已是最大成员，上确界自然是 $a$。
- **第三步，读本质**：吸收律等价于「$a \wedge b \le a$」，而后者正是序定义里
  「$\inf$ 是下界」的直接翻版。**吸收律不是多余的技巧，而是「$\wedge$
  确实小于等于被交元素」这一序事实的代数封装。** 没有吸收律，$\vee$ 与 $\wedge$
  只是两个互不相关的半格，合不成一个格。

## 5 例子与反例：格无处不在

- **幂集格 $(\mathcal{P}(X), \subseteq)$**：$\vee = \cup$，$\wedge = \cap$，是格。
- **整除格 $(\mathbb{N}^+, \mid)$**：$\vee = \operatorname{lcm}$，
  $\wedge = \gcd$，是格。
- **任何全序集**都是格：$a \vee b = \max(a,b)$，$a \wedge b = \min(a,b)$。
- **反例：$n$ 元集 $X$，其中 $n \ge 3$ 的全部子集的「真子集」**——
  $\{1,2\}$ 与 $\{2,3\}$ 的并 $\{1,2,3\}$ 不在集合里，不是格。
- **反例：数论里的「整除但只含无平方因子数」**——$2$ 与 $3$ 的最小公倍数是
  $6$（无平方因子），可 $4$ 与 $6$ 的 gcd 是 $2$、lcm 是 $12$（有平方因子 $4$），
  若集合不含 12 则不是格。

**辨析｜易错点：** 子群格（一个群的全部子群按包含）**不是**格：
两个子群的并集一般不是子群。读者常凭「群的交是子群」误以为子群构成格——
交确实是子群，但并的「最小上界」需要用「由两个子群生成的子群」
$\langle H_1, H_2 \rangle$ 充当，并非集合意义的并。
**格的并运算不必是集合并**，这是初学最需要警惕的地方。
<span class="marginnote">子群格确实构成一个格，只是其并运算 $\vee$ 是「生成的子群」而非集合的并。这个例子说明：格论的 $\vee$ 是「序意义的最小上界」，具体到不同实例里实现方式各不相同——把 $\vee$ 误读成集合并，是入门最常见的认知偏差。</span>

## 6 半格与格的「零件观」

在格的两种定义之间，其实还藏着两个中间结构：**半格（semilattice）**。
若只保留 $\vee$（并）运算并满足幂等、交换、结合，则 $(L, \vee)$
是**并半格（join-semilattice）**；只保留 $\wedge$ 则是对偶的**交半格（meet-semilattice）**。

**核心事实**：并半格上由「$a \le b \iff a \vee b = b$」定义出一个偏序，
且在这个序下 $a \vee b$ 恰是 $\{a,b\}$ 的上确界——但**下确界不一定存在**。
格 = 并半格 + 交半格 + 吸收律把它们焊在一起。

**辨析｜易错点：** 格不是「两个半格随便拼」。若 $L$ 上同时有 $\vee$ 与 $\wedge$
两个半格结构，但吸收律不成立，它们可能对应**不同的**偏序。检查：$\vee$ 定义的序
（$a \le_\vee b \iff a \vee b = b$）与 $\wedge$ 定义的序
（$a \le_\wedge b \iff a \wedge b = a$）必须一致，才是一个格。
**吸收律正是「两套序重合」的保证**——没有吸收律，$\vee$ 与 $\wedge$ 各说各话。

**为什么要关心半格**：许多自然结构只是半格而非格。例如，「全体非空子集的族
按包含」是交半格（交存在）但不是并半格（并不封闭）；逻辑里「合取」单独构成
一个交半格。**判定「是不是格」的第一步，往往是先问「是不是两个半格且序一致」。**

**用哈斯图检验吸收律**：在哈斯图上，吸收律 $a \vee (a \wedge b) = a$ 的意思是
「先取 $a$ 与 $b$ 的公共部分（下方），再取它与 $a$ 的上确界，回到 $a$」。
读者可以拿 $M_3$（菱形，第3篇的主角）验证：$a \vee (a \wedge b) = a \vee 0 = a$
成立——吸收律对 $M_3$ 成立，但分配律对它失败。
**吸收律是「格」的门槛，分配律是「好格」的门槛**，二者不可混谈。
<span class="marginnote">这个区分非常关键：$M_3$ 是格（吸收律成立）、模格、有补格，但不是分配格、不是布尔代数。后面第3篇会用 $M_3$ 与 $N_5$ 两个「五元素小怪胎」完全刻画分配性。今天的格定义，就是为这些精细分类打地基。</span>

**动手验证**：验证 $(\mathcal{P}(X), \cup, \cap)$ 是格（三条律逐条检查），
并验证整除格 $(\mathbb{N}^{+}, \operatorname{lcm}, \gcd)$ 满足吸收律
$\operatorname{lcm}(a, \gcd(a,b)) = a$——后者用素因子分解一眼看清。

## 7 小结

- **格（序观点）**：任意两元素都有 $\vee$（上确界）与 $\wedge$（下确界）的偏序集。
- **格（代数观点）**：带 $\vee, \wedge$ 运算、满足幂等/交换/结合/吸收四律的集合；
  **吸收律**是联结两运算的枢纽。
- 两种观点互相翻译：$a \le b \iff a \wedge b = a \iff a \vee b = b$。
