# 分配格与模格

## 为什么从分配格开始

到目前为止，格的公理只有幂等、交换、结合、吸收四条，
$(\mathbb{N}^+, \mid)$ 与 $(\mathcal{P}(X), \subseteq)$ 都满足，
连「异类」子群格也满足。但不同格之间仍有巨大差异：
集合的 $\cap$ 对 $\cup$ 满足分配律，而「子群生成」就不满足。
**分配律（distributive law）把「行为良好的格」从「任意格」中切分出来**，
是格论第一次真正的分类。模格则是分配律的温和版本——
它不足以让结构完全「透明」，却恰好覆盖了群、模、几何里大量自然出现的格。
理解「分配 ⊂ 模 ⊂ 格」这个包含链，是读遍格论的入场券。

## 1 分配格：交与并互相透明

格 $L$ 若对一切 $a, b, c \in L$ 满足**分配律**

$$a \wedge (b \vee c) = (a \wedge b) \vee (a \wedge c)$$

则称 $L$ 是**分配格（distributive lattice）**。在格中，这条分配律自动蕴含
对偶版本 $a \vee (b \wedge c) = (a \vee b) \wedge (a \vee c)$，
所以只需验证一条。

**辨析｜易错点：** 分配律只在格中才是「一条顶两条」；离开吸收律，
两个分配律不等价。更重要的是：**格的分配律不是自动成立的**。
$\mathcal{P}(X)$ 满足分配律（$\cap, \cup$ 的标准分配律），
但下面要见的 $M_3$ 与 $N_5$ 都不满足——所以「分配」是真条件，不是冗余公理。
<span class="marginnote">「分配」一词来自算术：$a \times (b + c) = ab + ac$。格论里 $\wedge$ 对 $\vee$ 分配，正是乘法对加法分配的抽象化。它意味着 $\wedge$ 可以「逐项作用」进括号，没有先算哪边的顾虑。</span>

**分配格的自然例子**：任何全序集（取 $\max, \min$）、幂集格
$(\mathcal{P}(X), \subseteq)$、整除格 $(\mathbb{N}^+, \mid)$
（$\gcd$ 与 $\operatorname{lcm}$ 满足分配律）。

## 2 模格：带条件的分配

分配律的温和版是**模律（modular law）**：对一切 $a, b, c \in L$，
若 $a \le c$，则

$$a \vee (b \wedge c) = (a \vee b) \wedge c$$

满足模律的格叫**模格（modular lattice）**。
<span class="marginnote">模律在 $a \le c$ 的条件下给出「把 $b$ 分配进括号」的自由。注意不等号方向的差别：$a \vee (b \wedge c) \le (a \vee b) \wedge c$ 在任意格中都成立（只需单调性），模律断言在 $a \le c$ 时反向也成立。</span>

**为什么需要 $a \le c$？** 拆开看：

$$a \vee (b \wedge c) \le (a \vee b) \wedge c \quad \text{（恒成立：左边两项分别 $\le$ 右边两项）}$$

模律要求的反向 $(a \vee b) \wedge c \le a \vee (b \wedge c)$，
在 $a \le c$ 时成立。若去掉条件，这个反向对一般格可能失败——
而分配格则对一切 $a,b,c$ 都成立。**于是分配 ⟹ 模**（模律的 $a \le c$ 条件
可由分配律无条件推出）。

## 3 模格的舞台：子群格与几何

模格绝不是书斋构造，它遍布代数：

- **子群格**：任意群 $G$ 的全体子群按包含构成**模格**（Dedekind 首先观察到）。
  这是模律最著名的来源——「Dedekind 模律」正是他在研究子群格时发现的。
- **模的子模格**：环上的模 $M$ 的全体子模按包含是模格，且子模格之间
  满足精确的模律（模论里子模格的模律是「同构定理」的序版本）。
- **射影几何**：射影空间中线性子空间的格是模格——这正是
  「射影几何是模格几何」的 Birkhoff 纲领的核心，也是格论向几何学输出的桥梁。
  <span class="marginnote">Birkhoff 的著名主张：射影几何可以完全由「子空间格」来研究，而「德萨格定理」「帕普斯定理」等都可以表述为子空间格的代数性质。模格因此是连接离散代数与连续几何的格论枢纽。</span>

**辨析｜易错点：** 子群格是模格，但**不是分配格**。取四元群 $V_4$
（克莱因四元群），它的子群格包含两个不同的一阶子群 $\langle a \rangle,
\langle b \rangle$：$\langle a \rangle \vee \langle b \rangle = V_4$，
但 $\langle a \rangle \cap \langle b \rangle = \{e\}$，分配律会失败。
**「模但不分配」是常态而非例外。**

## 4 公式解析：模律等价于「无非分配五角」

为什么分配格之外，模格还特别值得研究？因为**模律等价于一个禁令**：
不含 $N_5$（五角格）作为子格。先定义两个著名的「最小反例」：

- **$M_3$（菱形格）**：$\{0, a, b, c, 1\}$，其中 $a, b, c$ 两两不可比，
  $0 \lt  a, b, c \lt  1$。$M_3$ 是模格但**不是**分配格
  （$a \wedge (b \vee c) = a \wedge 1 = a$，而
  $(a \wedge b) \vee (a \wedge c) = 0 \vee 0 = 0$）。
- **$N_5$（五角格）**：$\{0, a, b, c, 1\}$ 其中 $0 \lt  a \lt  c \lt  1$ 与
  $0 \lt  b \lt  1$，且 $b$ 与 $a, c$ 不可比。$N_5$ **不是**模格。

$$M_3:\ \text{中排三点互不可比},\qquad N_5:\ \text{一条链 } 0<a<c\lt 1 \text{ 外加旁点 } b$$

- **第一步，读 $M_3$**：$M_3$ 中所有 $a \le c$ 情形下模律成立
  （因为三元素彼此平级），故 $M_3$ 是模格；分配律因「$a$ 与 $b,c$ 纠缠」失败。
- **第二步，读 $N_5$**：$N_5$ 中取 $a \le c$：
  $a \vee (b \wedge c) = a \vee 0 = a$，而 $(a \vee b) \wedge c = 1 \wedge c = c
  \neq a$，模律失败。
- **第三步，读分类**：**Birkhoff 定理**：格 $L$ 是分配格 ⟺ $L$ **不含有**
  $M_3$ 与 $N_5$ 作为子格；$L$ 是模格 ⟺ $L$ 不含 $N_5$ 作为子格。
  **分配 = 禁 $M_3$ 禁 $N_5$；模 = 只禁 $N_5$。**
  <span class="marginnote">这是格论最有名的「禁止子格」判据：两个五元素的小怪胎完全决定了分配性与模性。下一节「分配格的判据与 Dedekind 定理」将把这条判据推进为更精细的刻画。直觉上，$M_3$ 与 $N_5$ 是「最小不可分配/不可模的杂质」，格里只要混进其中一个，好性质就崩了。</span>

## 5 分配格的结构预告

分配格之所以重要，是因为它们有一个漂亮的表示定理（下一节与后文将逐步展开）：
**每个有限分配格都同构于某个集合的幂集格的子格**——更精确地说，
都同构于一个「集合域」（某些子集族按 $\cup, \cap$）。
这条定理把抽象的分配格还原成「集合的并交」，让布尔代数、Heyting 代数
乃至 Stone 对偶都有了共同的底座。

## 6 从模格到分配格：四步验证法

实际判断一个格是模格还是分配格，有一套系统的验证流程。设 $L$ 是有 0、1 的有限格：

**第一步，画哈斯图**：先画出 $L$ 的哈斯图，标注覆盖关系。
**第二步，找「不可比对」**：模律只对 $a \le c$ 的三元组有约束力，
  分配律对一切三元组。从图中找出所有「$a \le c$」的覆盖链，
  逐一测试模律：$a \vee (b \wedge c) = (a \vee b) \wedge c$。
- **第三步，找 $M_3$ 与 $N_5$ 子格**：用 Birkhoff 判据——扫遍五元子集，
  检查是否运算封闭且同构于 $M_3$ 或 $N_5$。找到 $M_3$ ⇒ 不分配；
  找到 $N_5$ ⇒ 不模。
- **第四步，给出结论**：无 $N_5$ ⇒ 模；无 $M_3$ 且无 $N_5$ ⇒ 分配。

**例**：$L = \mathcal{P}(\{1,2,3\})$ 幂集格（28 个元素）显然分配（并交分配），
验证第 3 步：找不到 $M_3$ 或 $N_5$ 子格（幂集格没有「异类」子格）。

**例**：子群格 $\operatorname{Sub}(V_4)$（克莱因四元群 $V_4 = \{e, a, b, ab\}$）。
它的元素是 5 个子群 $\{e\}, \langle a\rangle, \langle b\rangle, \langle ab\rangle,
V_4$，按包含序恰好是 $M_3$！因此 $\operatorname{Sub}(V_4)$ 是模格但**不是**分配格。
<span class="marginnote">$V_4$ 的子群格正好是 $M_3$ 这件事极具教育意义：三个一阶子群两两不可比、交为 $\{e\}$、并为 $V_4$。它说明「群的结构」直接决定了「子群格的形状」——这也是第4篇「同余格」研究为什么把群与格绑在一起。</span>

**分配格与模格的「加减」直觉**：在分配格里，「先并后交」与「先交后并」
可以随意交换顺序——运算像线性代数里的多项式一样可展开。在模格里，
只有「$a \le c$」条件下才能安全地「展开」。所以模律常被写作
「**带条件分配律**」：给分配律加一个前提 $a \le c$，就是模律。

**模格里的维度公式**：在子空间格中，模律对应维度公式
$\dim(A + B) = \dim A + \dim B - \dim(A \cap B)$。检查：令 $a = A \subseteq c = C$，
模律 $A + (B \cap C) = (A + B) \cap C$ 两边取维度，
正是「交与和的维度关系」。**模律 = 维度公式的格论版本**——
这解释了为什么射影几何的子空间格是模格。

## 7 小结

- **分配格**：$a \wedge (b \vee c) = (a \wedge b) \vee (a \wedge c)$
  （一条自动推出对偶）；幂集格、全序、整除格都分配。
- **模格**：$a \le c \Rightarrow a \vee (b \wedge c) = (a \vee b) \wedge c$；
  子群格、子模格、射影几何子空间格都是模格。
- 分配 ⟹ 模，反向不成立；$M_3$ 模而不分配，$N_5$ 连模都不满足。
- **Birkhoff 判据**：分配 ⟺ 禁 $M_3, N_5$；模 ⟺ 禁 $N_5$。
- 分配格是「集合域」的化身，是布尔代数与对偶理论的地基。
