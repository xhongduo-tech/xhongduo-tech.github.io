## 为什么从正交模格开始

布尔代数的 Stone 表示定理太完美了，完美到令人怀疑：**宇宙里的一切「逻辑」
都是布尔的吗？** 1936 年，Birkhoff 与 von Neumann 在《量子力学的逻辑》中
给出了惊世回答：**不是**。量子系统的事件（希尔伯特空间的闭子空间）构成的格
不是分配格，不满足布尔逻辑的分配律，但满足一条更弱的「正交模律」。
这个发现打开了量子逻辑与正交模格（orthomodular lattice, OML）的大门。
正交模格是有补格中「补元行为端正」的那一类——补元对合、反序，
但分配律缺席。理解 OML，是理解量子测量、投影算子与「量子信息」的格论入口，
也是本专题「从极限到大模型」叙事里最前沿的一段。

## 1 有补格：补元存在但未必唯一

**有补格（complemented lattice）**：有界格 $L$ 中每个元素至少有一个补元
（$a \vee b = 1$ 且 $a \wedge b = 0$）。有补格的补元可以**不唯一**——
$M_3$ 就是有补格，中间三元素互为补元，补元不唯一。
<span class="marginnote">补元唯一 ⟺ 分配（在格中）。于是：布尔代数 = 有补 + 分配 = 补元唯一。有补格是布尔代数的「去分配」版本，允许补元成对、成组地存在。加加减减依旧可行，但「减法结果」不再唯一。</span>

**辨析｜易错点：** 有补格未必有「正交补」概念——它只保证补元存在。
要谈「正交」，需要补元满足额外的结构公理（对合、反序）。
「有补」与「正交补」是两级台阶，不要混为一谈。

## 2 正交补：补元中的「好公民」

在格 $L$ 上定义一个一元运算 $a \mapsto a^{\perp}$，若满足：

**对合**：$a^{\perp\perp} = a$；
**反序**：$a \le b \Rightarrow b^{\perp} \le a^{\perp}$；
**并交互补**：$a \vee a^{\perp} = 1$，$a \wedge a^{\perp} = 0$。

则 $^{\perp}$ 是 $L$ 上的**正交补（orthocomplementation）**，
$(L, \vee, \wedge, ^{\perp}, 0, 1)$ 称为**正交补格（orthocomplemented lattice）**。
<span class="marginnote">对合 + 反序 + 互补，三条公理把「取补」约束成布尔代数的 $\neg$ 的推广。幂集代数 $(\mathcal{P}(X), \complement)$ 是正交补格；希尔伯特空间的闭子空间按「正交补」$S^{\perp}$ 也是。正交补不一定唯一（在非分配格中可能多种选择），但一旦选定，结构就固定下来。</span>

**辨析｜易错点：** 正交补**不要求分配律**。$a^{\perp}$ 与 $b^{\perp}$ 的
「并」仍可能与预期偏离；De Morgan 律 $a^{\perp} \vee b^{\perp} = (a \wedge b)^{\perp}$
在正交补格中**不一定成立**——它只在布尔代数（或满足更强条件的 OML）中成立。
用集合补的直觉去套正交补，会在非分配格中翻车。

## 3 正交模律：量子力学的格律

**正交模格（orthomodular lattice, OML）**是正交补格
$(L, \vee, \wedge, ^{\perp}, 0, 1)$，满足**正交模律**：

$$a \le b \ \Longrightarrow\ b = a \vee (b \wedge a^{\perp})$$

- **第一步，读几何**：$a \le b$ 时，$b$ 可以「分解」成 $a$ 与
  「$b$ 中 $a$ 的正交部分」$b \wedge a^{\perp}$ 的并。
  这是「勾股分解」的格论版：向量 $b$ 在子空间 $a$ 上的投影 $a$
  加上垂直分量 $b \wedge a^{\perp}$，恰好还原 $b$。
- **第二步，读与模律的区别**：模律是 $a \le c \Rightarrow a \vee (b \wedge c) =
  (a \vee b) \wedge c$；正交模律是 $a \le b \Rightarrow b = a \vee (b \wedge a^{\perp})$。
  后者把模律中的任意 $c$ 换成了「正交补部分」$b \wedge a^{\perp}$。
  **正交模律弱于分配律，也弱于（在无分配正交补下）模律，却恰好盖住量子力学的
  全部需要。**
  <span class="marginnote">关键推论：若 $a \le b$ 且 $b \wedge a^{\perp} = 0$，则 $a = b$。这是「正交补足够丰富」的表达——一个子空间若在 $b$ 内且无 $b$ 内的正交补，就只能是 $b$ 自己。它与「$a \le b$、$a^{\perp} \le b^{\perp}$ 时 $a = b$」等价。</span>
- **第三步，读逻辑**：OML 对合律 + 反序 + 互补，但不保证 $a \vee (b \wedge a^{\perp})$
  之类表达式的交换律「完全」——它给出一种「非分配但仍有结构」的逻辑。

## 4 公式解析：闭子空间格为何是 OML

设 $H$ 是希尔伯特空间，$\mathcal{C}(H)$ 是全体闭子空间按包含构成的格，
$^{\perp}$ 是正交补。**定理**：$(\mathcal{C}(H), \subseteq, ^{\perp})$
是**正交模格**，但不是布尔代数（$\dim H \ge 2$ 时）。

$$S \le T \ \Longleftrightarrow\ S \subseteq T, \qquad S^{\perp} = \{x \in H : \langle x, y \rangle = 0,\ \forall y \in S\}$$

- **第一步，验格**：闭子空间的交是闭子空间，但并要用「闭线性包」
  $\overline{S + T}$。于是 $S \vee T = \overline{S + T}$——
  **并不是集合的并**，这再次提醒我们格运算的抽象性。
- **第二步，验正交补**：$S^{\perp\perp} = S$（对闭子空间成立，
  这是 Hilbert 空间双正交定理）；$S \subseteq T \Rightarrow T^{\perp} \subseteq S^{\perp}$；
  $S \cap S^{\perp} = \{0\}$，$\overline{S + S^{\perp}} = H$。
  三条全部成立，$^{\perp}$ 是正交补。
- **第三步，验正交模律**：对 $S \subseteq T$，需要证
  $T = \overline{S + (T \cap S^{\perp})}$。取 $t \in T$，把它分解为
  $t = \operatorname{proj}_S t + (t - \operatorname{proj}_S t)$，第二项在
  $T \cap S^{\perp}$（因为 $t \in T$ 且投影差正交于 $S$），第一项在 $S$，
  合起来在右边。反向包含平凡。**正交模律就是投影分解定理的格论重述。**
  <span class="marginnote">$\dim H \ge 2$ 时，$\mathcal{C}(H)$ 含 $M_3$ 子格（三个互不正交的二维子空间可构造），故非分配、非布尔。量子力学的「不相容观察量」正对应这个非分配性——不能同时断言「$A$ 且 $B$」与「$B$ 且 $A$」的合取交换。</span>
**第四步，读物理**：闭子空间 = 量子命题（「系统状态落在子空间内」），
  正交补 = 命题否定，$\vee$ = 量子或，$\wedge$ = 量子与。
  **量子逻辑 = 正交模格**：这就是 Birkhoff–von Neumann 纲领的核心断言。

## 5 核心对比：布尔代数与正交模格

| 性质 | 布尔代数 | 正交模格 |
| --- | --- | --- |
| 分配律 | ✅ | ❌ |
| 补元唯一 | ✅ | 不一定（但补为给定正交补） |
| 对合 + 反序 | ✅（$\neg$） | ✅（$^{\perp}$） |
| De Morgan 律 | ✅ | 不一定 |
| 正交模律 | ✅（自动） | ✅（公理） |
| 代表模型 | 幂集 / 布尔环 | 闭子空间格 / 投影代数 |

<span class="marginnote">这张表是「布尔逻辑 → 量子逻辑」的演进路线图。量子信息科学（量子计算、量子测量）里，投影算子 $P_S$ 对应闭子空间 $S$，正交补对应 $I - P_S$，正交模律对应投影分解 $P_T = P_S + P_{T \cap S^{\perp}}$（对 $S \subseteq T$）。OML 是量子理论对格论的「原生贡献」。</span>

## 6 投影算子与量子测量的格论语言

正交模格不只是抽象结构——它是量子测量最直接的数学语言。
本节把 OML 的每个概念翻译成量子信息里的对象。

**闭子空间 ↔ 投影算子**：闭子空间 $S$ 与正交投影算子 $P_S$ 一一对应。
格的运算翻译成算子运算：

| OML 概念 | 量子信息对象 |
| --- | --- |
| 事件 $S$ | 投影 $P_S$ |
| 否定 $S^{\perp}$ | 补投影 $I - P_S$ |
| 合取 $S \wedge T$ | 投影 $P_{S \cap T}$（注意 $P_S P_T$ 一般不是投影！） |
| 析取 $S \vee T$ | 投影 $P_{\overline{S+T}}$ |
| $S \le T$ | $P_S \le P_T$（算子序） |

**辨析｜易错点：** 投影算子的乘积 $P_S P_T$ **一般不是投影**——
两个投影的积是投影当且仅当 $P_S P_T = P_T P_S$（两投影交换），
而交换 ⟺ 两个子空间「兼容」（$S$ 与 $T$ 在正交模格意义下可交换）。
**「先测 $S$ 再测 $T$」与「先测 $T$ 再测 $S$」结果不同，
正是量子测量顺序敏感性的格论表达。**
<span class="marginnote">两个不相容可观测量的投影不交换——这是海森堡不确定性的代数根源。OML 里 $S$ 与 $T$ 的「可交换性」条件 $S = (S \wedge T) \vee (S \wedge T^{\perp})$ 正是「$P_S, P_T$ 可交换」的格论翻译。量子信息的教科书里「测量不可交换」，在 OML 语言里就是「格中元素不交换」。</span>

**可交换性判定**：$S$ 与 $T$ 可交换 ⟺ $S = (S \wedge T) \vee (S \wedge T^{\perp})$。
在 $\mathbb{C}^2$ 里，一维子空间 $S = \operatorname{span}(v)$ 与
$T = \operatorname{span}(w)$ 可交换 ⟺ $v$ 与 $w$ 平行或正交。
**两个「倾斜」的一维子空间不可交换——量子逻辑对
「非正交即平行」之外的一切说「不兼容」。**

**测量 = 格上的条件作用**：量子测量「先测得 $S$ 发生，再问 $T$」对应
「条件化投影」$P_{S} P_{T} P_{S}$；「$S$ 发生后系统状态」落在 $S$ 与
当前状态的「交集投影」上。整套测量理论都写在 OML 的格运算里。

**从 OML 回到布尔**：若限制在「互相可交换」的事件子格上
（它们构成一个布尔子代数），量子测量退化为经典测量——布尔逻辑恢复。
**经典部分 = OML 中某个布尔子格**，这正是第3节「中心」概念的物理意义：
中心里的命题构成经典子系统。
<span class="marginnote">这个观察对量子计算有直接意义：量子程序的「经典控制流」部分运行在布尔子格上，只有「量子门」部分跨越到 OML 的非布尔区域。混合了经典与量子计算的体系（量子电路 + 经典控制），在格论里就是「布尔子格 × OML 张量积」的结构。</span>

## 7 小结

- **有补格**：每元素至少一补，补元可多；补元唯一 ⟺ 分配。
- **正交补格**：补元对合、反序、互补；是布尔 $\neg$ 的推广，De Morgan 律不再自动。
- **正交模格（OML）**：正交补格 + 正交模律 $a \le b \Rightarrow b = a \vee (b \wedge a^{\perp})$
