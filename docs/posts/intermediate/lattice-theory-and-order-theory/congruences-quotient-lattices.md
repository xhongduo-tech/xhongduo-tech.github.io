## 为什么从同余关系开始

群有正规子群、环有理想，它们的「商结构」都是把某类等价元素粘合成一个点。
格作为代数结构，自然也要回答：**哪些元素可以「合理地」粘在一起？**
答案不是任意的等价关系，而是与 $\vee, \wedge$ 兼容的等价关系——
**同余关系（congruence）**。同余关系刻画「哪些差异可以忽略」，
商格 $L / \theta$ 则是「忽略差异后的粗格」。
它是格同态理论的另一半：**每个同态的核是同余，每个同余也给出一个同态**——
这是同态基本定理在格论中的翻版，也是泛代数（第4篇）思想的先声。

## 1 同余关系：与运算兼容的等价

设 $L$ 是格，$\theta$ 是 $L$ 上的等价关系。若 $\theta$ 与 $\vee, \wedge$
**兼容**——即对一切 $a, b, c, d \in L$：

$$a \sim_\theta b \ \text{且}\ c \sim_\theta d \ \Longrightarrow\ a \vee c \sim_\theta b \vee d \ \text{且}\ a \wedge c \sim_\theta b \wedge d$$

则称 $\theta$ 是 $L$ 上的**同余关系（congruence relation）**。
<span class="marginnote">「兼容」的口诀：<strong>等量替换保持运算</strong>——把参与运算的元素换成它的等价代表，结果仍等价。这与解方程时的「同解变形」是同一个原则：对两边同时做同样的事，相等关系不变。</span>

由于 $L$ 同时是序结构，同余关系还能等价地表述为：同余类必是凸子格，
且同余关系由「对」$(a, b)$ 生成。一个同余关系 $\theta$ 的等价类
$[a]_\theta = \{x : x \sim a\}$ 称为**同余类（congruence class）**。

**辨析｜易错点：** 同余关系**不是**任意等价关系。两个元素等价意味着
「在一切 $\vee, \wedge$ 运算下行为一致」，因此同余类必须对运算封闭且「凸」
（夹在类内两点之间的一切点都在类内）。普通等价关系如「模 2 奇偶」
在整数格 $(\mathbb{Z}, \vee = \max, \wedge = \min)$ 上**是**同余吗？
$1 \equiv 2$ 且 $3 \equiv 4$，但 $1 \wedge 3 = 1$、$2 \wedge 4 = 2$，
$1 \not\equiv 2$——不兼容，故不是同余。

## 2 商格：把同余类粘成点

给定同余关系 $\theta$，全体同余类构成集合 $L / \theta = \{[a]_\theta : a \in L\}$。
在其上定义运算：

$$[a]_\theta \vee [b]_\theta = [a \vee b]_\theta, \qquad [a]_\theta \wedge [b]_\theta = [a \wedge b]_\theta$$

兼容性保证运算**良定义**（与代表元的选取无关）。于是 $(L/\theta, \vee, \wedge)$
是一个格，称为 $L$ 关于 $\theta$ 的**商格（quotient lattice）**。
<span class="marginnote">良定义（well-defined）是商结构的关键检验：若 $a \sim a'$ 而 $[a \vee b]$ 与 $[a' \vee b]$ 不同，运算就「摔坏了」。同余条件正是为了守住这一关。</span>

商格自带一个自然的满同态——**自然映射（natural map）**：

$$\pi : L \to L/\theta, \qquad \pi(a) = [a]_\theta$$

$\pi$ 显然保 $\vee, \wedge$，且是满射。商格的直觉：把「同一个同余类」压成一个点，
原格中的覆盖结构被压缩，但运算律原封不动。

## 3 同态的核与同态基本定理

同余关系与同态之间存在一一对应，这是本节的核心定理。

**同态的核（kernel）**：若 $f : L \to K$ 是格同态，定义 $a \sim_f b \iff f(a) = f(b)$。
$\ker f$ 是 $L$ 上的同余关系，且 $f$ 通过商格分解为

$$L \xrightarrow{\ \pi\ } L/\ker f \xrightarrow{\ \bar{f}\ } K, \qquad \bar{f}([a]) = f(a)$$

**同态基本定理（First Isomorphism Theorem）**：$\bar{f}$ 是**格嵌入**；
若 $f$ 是满同态，则 $L/\ker f \cong K$。
<span class="marginnote">这套「核 → 商 → 嵌入」三段论在群（正规子群）、环（理想）、模（子模）里完全平行。格论的版本把「核」从「子结构」换成了「等价关系」，这正是泛代数（universal algebra）的统一视角：同余关系才是「核」的普适化身。</span>

**第一步，验核是同余**：$f(a) = f(b)$ 且 $f(c) = f(d)$，则
  $f(a \vee c) = f(a) \vee f(c) = f(b) \vee f(d) = f(b \vee d)$，兼容成立。
**第二步，验分解**：$\bar{f}([a] \vee [b]) = \bar{f}([a \vee b]) = f(a \vee b) =
  f(a) \vee f(b) = \bar{f}([a]) \vee \bar{f}([b])$，同态成立。
- **第三步，验嵌入**：$\bar{f}([a]) = \bar{f}([b])$ 当且仅当 $f(a) = f(b)$
  当且仅当 $[a] = [b]$，单射得证。
  <span class="marginnote">同态基本定理的格论版几乎不用动脑——所有检验都只是「把定义代进去」。它的价值不在证明，而在概念：商格 = 同态的「可辨识形象」。这也是为什么研究格的结构，本质上就是研究它的同余格。</span>

## 4 公式解析：$\theta_a$ 生成的同余

任何一对「想粘在一起」的元素 $(a, b)$ 都能生成一个同余关系。$L$ 上所有
同余关系按「$\theta_1 \subseteq \theta_2$（后者更粗）」构成一个完全格，
记作 $\operatorname{Con}(L)$，称为 $L$ 的**同余格（congruence lattice）**：

$$\operatorname{Con}(L) = \{ \theta : \theta \text{ 是 } L \text{ 上的同余} \}, \qquad \bigvee_i \theta_i = \text{生成所有 } \theta_i \text{ 的最小同余}$$

- **第一步，读结构**：同余关系的集合按包含序构成完全格——
  任意族同余的「交」（逐点交）仍是同余，「并」则需要用生成闭包。
- **第二步，读最小/最大**：恒等关系 $\Delta$（只有 $a \sim a$）是最小元；
  全关系 $\nabla$（一切元素等价，商格退化成一个点）是最大元。
- **第三步，读意义**：$\operatorname{Con}(L)$ 本身是格论研究的重要对象
  （第4篇「同余格与泛代数」专论）。一个格 $L$ 的性质，往往由它的同余格
  $\operatorname{Con}(L)$ 反映；例如 $L$ 分配 ⟺ $\operatorname{Con}(L)$ 分配。

## 5 应用：粘合就是抽象

同余关系在数学与计算机科学里都是「抽象化」的引擎：

- **集合格** $(\mathcal{P}(X), \subseteq)$ 上，按「对称差为有限集」粘合，
  商格给出「几乎处处相等的子集」——测度论的「a.e. 相等」正是这类商结构的化身。
- **程序语义**：程序状态按「可观察行为等价」粘合，商格给出程序的抽象语义——
  与 Tarski 不动点结合，构成抽象解释的理论基础。
  <span class="marginnote">数据流分析里「某变量一定是 0」与「某变量非 0」等抽象事实，正是把具体状态按抽象同余粘合后得到的小格。商结构 + 不动点 = 抽象解释，这是格论对编译器最直接的贡献。</span>
**代数分类**：同余关系是泛代数的统一「核」，把群、环、格的商理论收进同一框架。

## 6 同余关系的判定与操作

同余关系是「可粘合的等价」，如何判定一个等价关系是不是同余？又如何操作它？

**判定三连**：

1. **验兼容**：对每对等价「$a \sim b$、$c \sim d$」，检查
   $a \vee c \sim b \vee d$ 与 $a \wedge c \sim b \wedge d$。
2. **验凸性与子格性**：同余类必是凸子格。若某个等价类不是凸子格
   （比如夹在类内两点之间的点不在类内），则该等价关系不是同余。
3. **验保运算**：直接等价地「$a \sim b$ 当且仅当 $f(a) = f(b)$」
   若 $f$ 是同态，则 $\sim$ 是同余（第3节的核）——反向也成立，
   故同余 = 某同态的核。

**生成同余**：给定一组「想粘合的对」$(a_i, b_i)$，它们生成的最小同余 $\theta$
是所有包含这些对的同余的交。构造：先在等价关系的意义下取传递闭包，
再「运算兼容闭包」——反复要求「若 $x \sim y$ 则 $x \vee z \sim y \vee z$、
$x \wedge z \sim y \wedge z$」直到不再产生新对。

**例**：在格 $L = \mathcal{P}(\{1,2\})$（4 元素菱形）上，粘合 $\{1\}$ 与 $\{2\}$。
生成同余必然把它们也粘合 $\emptyset$ 与 $\{1,2\}$ 吗？检验：
$\{1\} \sim \{2\}$ 时，$\{1\} \vee \{2\} = \{1,2\} \sim \{2\} \vee \{2\} = \{2\}$，
且 $\{1\} \wedge \{2\} = \emptyset \sim \{2\} \wedge \{2\} = \{2\}$——
于是 $\emptyset \sim \{2\}$、$\{1,2\} \sim \{2\}$，
传递闭包把四个元素全粘成一个类。商格退化为单点格。
<span class="marginnote">这个例子说明：<strong>粘合一个对，可能「连锁反应」粘合成一大片</strong>。在幂集格里粘合两个不可比元素，往往把整个格压成一个点。理解「生成同余的传播力」，是设计商结构时的关键直觉——它告诉你要小心选择粘合的对。</span>

**同余格的操作**：$\operatorname{Con}(L)$ 的 $\wedge$ 是逐点交
（两个同余的「同时成立」），$\vee$ 是生成（传递 + 兼容闭包）。
$\operatorname{Con}(L)$ 因此通常比 $L$ 本身复杂得多——研究
「哪个格的同余格是分配格/模格」正是第4篇泛代数的主角。

**辨析｜易错点：** 两个同余的交**总是同余**（等价关系交仍是等价关系，
兼容性对交保持），但两个同余的**并集一般不是同余**——并集是等价关系吗？
不是，缺少传递性。所以 $\operatorname{Con}(L)$ 的 $\vee$ 必须用「生成的」
而非「并集的」，这正是它「较复杂」的原因。

## 7 小结

- **同余关系** = 与 $\vee, \wedge$ 兼容的等价关系；等量替换保持运算。
- **商格** $L/\theta$ = 同余类的格；自然映射 $\pi$ 是满同态。
- 同态**核**是同余，同态基本定理给出 $L/\ker f \cong \operatorname{im} f$（满同态时）。
- **同余格** $\operatorname{Con}(L)$ 是 $L$ 上全体同余构成的完全格；$\Delta \le \theta \le \nabla$
