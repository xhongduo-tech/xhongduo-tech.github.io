## 为什么从同余格与泛代数开始

我们在格里已经见过同余关系（第12节），但同余关系并非格的专利：
**群的正规子群、环的理想、模的子模，全部是同余关系的特殊化身**。
把这些统一起来的学科叫**泛代数（universal algebra）**——它研究
「任意带运算的集合」的公共理论。泛代数的核心对象之一是**同余格
$\operatorname{Con}(A)$**：一个代数 $A$ 的全体同余关系构成的完全格。
同余格的结构反过来刻画代数本身——**一个格 $L$ 的同余格
$\operatorname{Con}(L)$ 必是分配格**（Funayama–Nakayama），
而群的同余格（= 正规子群格）是模格。同余格由此成为「代数的 X 光片」：
读它，就能推断代数的深层性质。
<span class="marginnote">这一节把全书散落的线索——同余、商结构、理想、簇——收拢进泛代数的统一框架，并用 Birkhoff 的 HSP 定理与 Jónsson 引理揭示「同余格的性质决定变种结构」这一泛代数主旋律。</span>

## 1 泛代数：带运算的集合

**代数（algebra）** $\mathbf{A} = (A, F)$ 是一个集合 $A$ 配上若干运算 $F$
（每个运算 $f : A^{n} \to A$ 有固定元数）。群是二元运算 $\cdot$、
一元逆 $^{-1}$、零元 $e$ 的代数；环是加乘两种二元运算加常数的代数；
格是 $\vee, \wedge$ 两个二元运算的代数。
<span class="marginnote">泛代数不关心「具体是哪种运算」，只关心「等式公理」：一个<strong>簇（variety）</strong>就是由一组恒等式（等式公理）定义的全部代数，如群簇、环簇、格簇、布尔代数簇。泛代数的定理同时适用于所有这些簇。</span>

**同余关系（congruence）**：$A$ 上的等价关系 $\theta$，若对每个运算 $f$，
$a_i \sim_\theta b_i$ 对一切 $i$ 蕴含 $f(a_1, \dots, a_n) \sim_\theta f(b_1, \dots, b_n)$——
即「等量替换保持每个运算」。这正是第12节格同余的推广：同余 = 与所有运算
兼容的等价关系。
<span class="marginnote">经典对应：群的同余关系 ⟺ 正规子群（$a \sim b \iff ab^{-1} \in N$）；环的同余 ⟺ 理想；模的同余 ⟺ 子模；格/分配格的同余就是第12节的格同余。<strong>正规子群、理想、同余，三词一义</strong>——这就是泛代数最大的统一。</span>

## 2 同余格：$\operatorname{Con}(\mathbf{A})$

设 $\mathbf{A}$ 是代数，全体同余关系 $\operatorname{Con}(\mathbf{A})$
按包含序构成一个**完全格**，称为 $\mathbf{A}$ 的**同余格（congruence lattice）**。

$$\operatorname{Con}(\mathbf{A}) = \{ \theta : \theta \text{ 是 } \mathbf{A} \text{ 的同余} \}, \qquad \bigwedge \Theta = \bigcap \Theta, \qquad \bigvee \Theta = \text{生成所有 } \theta \in \Theta \text{ 的同余}$$

同余格有最小元 $\Delta$（恒等关系）与最大元 $\nabla$（全关系）。
商代数 $\mathbf{A}/\theta$ 对应 $\theta$ 下的等价类代数——
同余格记录着「$\mathbf{A}$ 能切出哪些商」。

**辨析｜易错点：** 同余格是**完全格**，但不保证分配或模。
不同簇的同余格满足不同性质：群簇的同余格（正规子群格）是**模格**
但一般不分配；格簇的同余格是**分配格**（下节）；
而有些簇的同余格可以是任意完全格（没有额外约束）。

## 3 Funayama–Nakayama 定理：格同余格必分配

**Funayama–Nakayama 定理（1942）**：对**任何**格 $L$（不必分配），
它的同余格 $\operatorname{Con}(L)$ 都是**分配格**。

$$\forall\, L,\quad \operatorname{Con}(L) \text{ 是分配格}$$

**直觉**：同余关系的「并」与「交」在格上特别温顺。证明核心是：
$L$ 的同余可看作「$L$ 上的某种凸等价」，而这些等价关系的并交满足分配律。
反过来说，**不是每个分配格都能作为某个格的同余格出现**——哪些分配格是
「格同余格」正是同余格表示理论的活跃课题。
<span class="marginnote">对比：群簇的同余格是模格（正规子群格模），格簇的同余格是分配格。<strong>「同余格是分配的还是模的」这一差别，把格论与群论的根本差异暴露无遗。</strong> 格与群虽然都是代数，但它们的「商结构形态」完全不同。</span>

## 4 公式解析：同余可交换与 Mal'cev 条件

同余格的性质常由「同余运算的交换性」刻画。两个同余 $\theta, \psi$
**可交换（permutable）**，若 $\theta \circ \psi = \psi \circ \theta$
（关系复合可交换）：

$$\theta \circ \psi = \{(x,z) : \exists y,\ x \sim_\theta y \sim_\psi z\} = \{(x,z) : \exists y,\ x \sim_\psi y \sim_\theta z\} = \psi \circ \theta$$

- **第一步，读定义**：$\theta \circ \psi$ 是「先 $\theta$ 一步再 $\psi$ 一步」，
  $\psi \circ \theta$ 是「先 $\psi$ 再 $\theta$」。可交换性说两条路径殊途同归。
- **第二步，读意义**：可交换同余的商 $\mathbf{A}/(\theta \vee \psi)$ 可以用
  「二步跳」显式构造，同态基本定理的叙述最漂亮。
- **第三步，读 Mal'cev 条件**：**Mal'cev 定理**：簇 $\mathcal{V}$ 的所有同余
  都可交换 ⟺ $\mathcal{V}$ 中存在三元项 $p(x,y,z)$ 满足 $p(x,x,z) = z$
  且 $p(x,z,z) = x$。群的 $p(x,y,z) = xy^{-1}z$ 就是这样的项。
  <span class="marginnote">Mal'cev 条件是一大类「可判别性质」的代表：簇的许多性质（同余可交换、同余分配、同余模）都等价于某个「等式条件」的存在，后者只依赖「某个项存在」。这是泛代数最深刻的洞察之一：代数性质 ⟺ 项条件。</span>
- **第四步，读格/群对比**：**群簇**同余可交换（$xy^{-1}z$ 见证），同余格模；
  **格簇**同余**不**可交换（格没有 Mal'cev 项），但同余格分配。
  两个簇在同余行为上分道扬镳。

## 5 Birkhoff 的簇定理与直不可约

**Birkhoff HSP 定理（1935）**：非空代数类 $\mathcal{K}$ 是一个簇
（由恒等式定义）⟺ $\mathcal{K}$ 对**同态像（H）、子代数（S）、直积（P）**封闭。

$$\mathcal{K} \text{ 是簇} \iff \mathcal{K} = \mathbb{H}\mathbb{S}\mathbb{P}(\mathcal{K})$$

**Birkhoff 直不可约定理**：每个代数都是它的**直不可约（subdirectly
irreducible）**商的子直积。直不可约代数是有「唯一的最小非平凡同余」的代数——
它们是「原子的构件」，所有代数都能从它们「组装」出来。
<span class="marginnote">直觉：直不可约代数 = 有一个「最小缺口」的代数。Birkhoff 定理说每个代数都能嵌入它的直不可约商的直积——这就像「每个数能分解为素数的乘积」：直不可约商是代数的「素数」。分配格表示定理（Birkhoff 第17节）正是子直分解在格上的体现。</span>

## 6 应用：同余格作为分类工具

**Jónsson 引理**：若 $\mathcal{V}$ 是**同余分配**的簇（所有成员的同余格
  都分配），则 $\mathcal{V}$ 的生成元簇有清晰描述——它是「直不可约生成元」
  的有限子直积。这给出分配格簇、布尔代数簇的结构分类。
  <span class="marginnote">Jónsson 引理是「同余分配簇 = 好分类的簇」这一纲领的发动机：只要簇的同余格分配，它的子簇格、直不可约元都有漂亮刻画。格簇、Heyting 代数簇、BCK 代数簇都在此列。</span>
**子簇格**：一个簇的全部子簇（子变种）按包含构成一个格。Birkhoff 定理
  使这个格成为「用恒等式定义的全部代数类」的谱系——布尔代数簇的各个子簇，
  恰好对应各种「补充律」的强弱谱。
**同余格表示问题**：给定一个完全格 $C$，是否存在代数 $\mathbf{A}$ 使
  $\operatorname{Con}(\mathbf{A}) \cong C$？对格而言答案是：$C$ 分配才可能；
  反之「每个分配完全格都是某个格的同余格」（有构造定理）。
  这是泛代数与格论交界处的著名问题。

## 7 实战：群、环、格的同余格对照

同余格是「代数的 X 光片」，不同代数的同余格形态天差地别。把三大经典代数并列：

| 代数 $\mathbf{A}$ | 同余 ⟺ | 同余格 $\operatorname{Con}(\mathbf{A})$ |
| --- | --- | --- |
| 群 $G$ | 正规子群 | 模格（正规子群格） |
| 环 $R$ | 理想 | 模格（理想格） |
| 格 $L$ | 格同余 | **分配格**（Funayama–Nakayama） |
| 布尔代数 $B$ | 理想/滤子 | 布尔代数（补对称） |
| 模 $M$ | 子模 | 模格（子模格） |

**辨析｜易错点：** 「同余 = 正规子群」是一一对应但**不是同构**：
正规子群格（按包含）与同余格（按关系包含）确实是同构的格——
映射 $N \mapsto \{(a,b) : ab^{-1} \in N\}$ 保并交。但「同余 = 理想」在环上
同样成立。**看到「正规子群/理想/子模」，就可以在脑海里把它替换成「同余」**——
泛代数就是这样消除「貌似不同的结构」的。

**为什么格的同余格分配而群的模**：

- 群的同余（正规子群）对「合成」$N_1 N_2$ 与「交」满足模律
  （子群乘积与交的 Dedekind 模律）。
- 格的同余对「生成」与「交」满足分配律——格运算 $\vee, \wedge$ 的
  「双分配」性质使得同余的交并特别温顺。

**用同余格读代数结构**：$\operatorname{Con}(\mathbf{A})$ 的元数揭示了
$\mathbf{A}$ 的「商结构丰富程度」。$\operatorname{Con}(\mathbf{A}) =
\{\Delta, \nabla\}$（只有两个元）的代数叫**简单代数（simple algebra）**——
没有非平凡商。有限简单群（如 $A_n$）在群分类中的地位，正是「同余格极简」的体现。

**Mal'cev 条件的实战**：判断一个簇是否「同余可交换」，只需找一个三项 $p$。
群的 $p(x,y,z) = xy^{-1}z$；环的 $p = x - y + z$；而格**没有**这样的项——
所以格簇同余不可交换。**证明「格簇同余不可交换」可以用
「同余可交换 ⟹ 有 Mal'cev 项」的定理**，而格不满足任何
$p(x,x,z) = z, p(x,z,z) = x$ 的恒等式。
<span class="marginnote">格没有 Mal'cev 项这件事本身就是一个深刻结论：它说明格的同余运算「不可交换」，进而格的「商」操作不如群环那样「平坦」。这也间接解释了为什么格论里「同余格」的分配性如此珍贵——那是格独有的恩赐。</span>

**应用：Jónsson 引理的一句话版**。若簇 $\mathcal{V}$ 同余分配，则
$\mathcal{V}$ 的子簇格有清晰的生成结构。格簇、Heyting 代数簇都同余分配，
所以它们的分类都「说得清」。**「同余分配」=「结构可控」**——
这是泛代数给格论的回赠。

## 8 小结

- **泛代数** = 带运算集合的公共理论；**同余** = 与一切运算兼容的等价关系；
  正规子群、理想、同余同义。
- **同余格 $\operatorname{Con}(\mathbf{A})$**：完全格；记录 $\mathbf{A}$ 的一切商结构。
- **Funayama–Nakayama**：格的同余格必分配；群的同余格（正规子群格）模。
- **Mal'cev 条件**：簇性质 ⟺ 项条件；同余可交换由
  $p(x,x,z)=z,\ p(x,z,z)=x$
