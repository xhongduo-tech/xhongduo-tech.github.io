## 为什么从两种定义的等价性开始

第5篇复习的第二站，回到格的定义。偏序集本身没有运算，而**格（lattice）**
是第一个「长出运算」的偏序结构：每两个元素都有上确界与下确界。
于是格天然拥有两张面孔——一张是**序**的（每两元素有确界），一张是**代数**的
（带 $\vee$ 与 $\wedge$ 两个二元运算、满足四条律）。这两张面孔看似不同，
实则是同一个概念的两种写法。**理解「两种定义为什么等价」，是整个格论
「序 ↔ 代数」主旋律的第一课**：后面的分配格、布尔代数、同态定理，
全都建立在这条双向翻译的桥梁上。今天的复习，就是要亲手把这座桥
从两个方向各砌一遍，并把两组公理的强度关系彻底看清。

## 1 序定义：每两元素都有确界的偏序集

**格（序意义）**：一个偏序集 $(L, \le)$，其中任意两个元素 $a, b$
都有上确界与下确界。记

$$a \vee b = \sup\{a, b\} \quad (\text{并, join}), \qquad a \wedge b = \inf\{a, b\} \quad (\text{交, meet})$$

由确界的唯一性，$\vee$ 与 $\wedge$ 自动成为 $L$ 上的二元运算。
<span class="marginnote">符号：有些文献用 $\cup, \cap$ 或 $+, \cdot$ 记并与交。本专题统一 $\vee, \wedge$。记住：格的「并」是「最小上界」，具体到不同实例实现各异——幂集格中是集合并，整除格中是 lcm，子群格中是「生成的子群」。</span>

**辨析｜易错点：** 格只要求「任意**两**元素」有确界，不要求「任意子集」。
放宽到任意子集就是**完全格**（下一讲）。两片叶子组成的偏序集（如一棵
非平凡的树按祖先序）不是格——两个叶子既无下确界也无上确界。

## 2 代数定义：一组运算四条律

**格（代数意义）**：集合 $L$ 上定义了两个二元运算
$\vee, \wedge : L \times L \to L$，满足对一切 $a, b, c \in L$：

- **幂等律**：$a \vee a = a$，$a \wedge a = a$；
- **交换律**：$a \vee b = b \vee a$，$a \wedge b = b \wedge a$；
- **结合律**：$(a \vee b) \vee c = a \vee (b \vee c)$，$(a \wedge b) \wedge c = a \wedge (b \wedge c)$；
- **吸收律**：$a \vee (a \wedge b) = a$，$a \wedge (a \vee b) = a$。

四条律里，幂等、交换、结合描述的是「每个运算自身的行为」，而
**吸收律是把两个运算焊在一起的铆钉**——没有它，$\vee$ 与 $\wedge$
只是两个互不相干的半格，合不成一个格。

**辨析｜易错点：** 吸收律可以推出幂等律：$a \vee a = a \vee (a \wedge (a \vee a))$
这条路不直接，但只需令 $b = a \vee a$ 代入 $a \wedge (a \vee b) = a$ 便能推出
幂等。**四个条件并非全部独立**，吸收律是最强、最关键的一条。

## 3 两种定义的等价性：双向砌桥

**定理**：序意义下的格与代数意义下的格是同一个概念。

**方向一（序 → 代数）**：由 $\sup, \inf$ 定义的 $\vee, \wedge$ 满足四条律。
交换律与结合律来自确界的唯一性；吸收律 $a \vee (a \wedge b) = a$ 的证明：
因为 $a \wedge b \le a$，所以 $a$ 是 $\{a, a \wedge b\}$ 的上界，而任何上界
都 $\ge a$，故 $\sup\{a, a \wedge b\} = a$。

**方向二（代数 → 序）**：这是更不平凡的方向。先定义

$$a \le b \iff a \wedge b = a \qquad (\text{等价地 } a \vee b = b)$$

- **第一步，证明 $\le$ 是偏序**：自反性由幂等律 $a \wedge a = a$；
  反对称性由「$a \wedge b = a$ 且 $b \wedge a = b$」（交换律）推 $a = b$；
  传递性需用结合律：若 $a \wedge b = a$、$b \wedge c = b$，则
  $a \wedge c = (a \wedge b) \wedge c = a \wedge (b \wedge c) = a \wedge b = a$。
- **第二步，证明 $\vee, \wedge$ 恰为此序下的确界**：由吸收律，
  $a \wedge (a \vee b) = a$ 即 $a \le a \vee b$，同理 $b \le a \vee b$，
  故 $a \vee b$ 是上界；若 $a \le c$ 且 $b \le c$（即 $a \wedge c = a$、
  $b \wedge c = b$），则 $(a \vee b) \wedge c = (a \wedge c) \vee (b \wedge c)$
  ——这一步要用到下面第4节验证的**半格分配律**（在格中可证明）——
  得 $(a \vee b) \wedge c = a \vee b$，即 $a \vee b \le c$，
  所以 $a \vee b$ 是最小上界。$\wedge$ 对偶同理。

<span class="marginnote">方向二是整座桥梁的精髓：它表明「运算」能够<strong>重建</strong>出「序」。关键翻译规则「$a \le b \iff a \wedge b = a$」在幂集格中是「$a \subseteq b \iff a \cap b = a$」，在整除格中是「$a \mid b \iff \gcd(a,b) = a$」——同一句话，三种实例。</span>

## 4 公式解析：半格分配律——等价性证明中的隐藏引理

方向二里用到了一条中间引理，它值得单独拆解：

$$a \vee (b \wedge c) = (a \vee b) \wedge (a \vee c) \qquad \text{（在任意格中成立！）}$$

这条式子看起来像分配律，但它**在任意格中都真**——这正是它与真正分配律
（$a \wedge (b \vee c) = (a \wedge b) \vee (a \wedge c)$）的区别所在：

- **第一步，读方向 $\le$**：$a \le a \vee b$ 且 $a \le a \vee c$，故
  $a \le (a \vee b) \wedge (a \vee c)$；又 $b \wedge c \le b \le a \vee b$
  且 $b \wedge c \le c \le a \vee c$，故 $b \wedge c \le (a \vee b) \wedge (a \vee c)$。
  于是 $a \vee (b \wedge c) \le (a \vee b) \wedge (a \vee c)$。
- **第二步，读方向 $\ge$**：由序 → 代数方向已证 $\vee$ 满足
  交换、结合、吸收，用代数律倒推：
  $(a \vee b) \wedge (a \vee c) = a \vee ((a \vee b) \wedge c)$（吸收）
  $\le a \vee (b \wedge c)$ 需要仔细验证——完整的代数证明可见
  Birkhoff《Lattice Theory》第1章引理。
- **第三步，读直觉**：$a$ 是「公共因子」，把它从括号里「提出来」
  不受另一侧运算的干扰。**这条弱分配律（distributive inequality）
  在一切格中都成立，而真正的分配律只在一部分格里成立**——
  下一讲《分配格与模格》的判据，正是围绕这两者的差距展开的。

## 5 序与代数的互译：一张对照表

两种定义用两套语言描述同一对象，熟练互译是格论的基本功：

| 概念 | 序语言 | 代数语言 |
| --- | --- | --- |
| 序关系 | $a \le b$ | $a \wedge b = a$（或 $a \vee b = b$） |
| 并（join） | $a \vee b = \sup\{a,b\}$ | 满足吸收律的二元运算 |
| 交（meet） | $a \wedge b = \inf\{a,b\}$ | 满足吸收律的二元运算 |
| 同态 | 保序映射 | 保 $\vee, \wedge$ 的映射 |
| 子结构 | 含确界的子偏序集 | 对 $\vee, \wedge$ 封闭的子集 |
| 有界 | 有最小元 $\bot$、最大元 $\top$ | $\bot \vee a = a$，$\top \wedge a = a$ |

<span class="marginnote">这套对照表是整个专题的「翻译词典」：一旦你学会在两种语言之间切换，分配格的等式、模格的等价刻画、布尔代数的补运算就都有了双倍的证明火力——序里的直觉 + 代数里的计算。</span>

## 6 基本性质与半格视角

格的若干基本性质在复习中值得一次性点齐：

- **有界格（bounded lattice）**：若 $L$ 有最小元 $\bot$ 与最大元 $\top$，
  则称 $L$ 是有界的。有限格必有界（取一切元素的确界）；
  幂集格、整除格 $(\mathbb{N}^+, \mid)$（无 $\top$！）则未必都有界。
- **格同态**：保 $\vee$ 与 $\wedge$ 的映射。格同构 = 双射同态；
  在序语言下，格同构恰好是「保序 + 反射序」的双射。
- **子格**：对 $\vee, \wedge$ 封闭的子集。注意**子格与序子偏序集不同**：
  两个元素在子格中的并，必须等于它们在全格中的并。

**半格视角**：只保留 $\vee$（满足幂等、交换、结合）得到**并半格**，
只保留 $\wedge$ 得到**交半格**。格 = 并半格 + 交半格 + 吸收律把它们
焊在一起。若两个半格各说各话（吸收律不成立），它们可能定义出**不同的**序，
就不构成格。**判断「是不是格」的第一步，永远是问「两个半格定义的序
是否一致」。**

**辨析｜易错点：** 子群格是格，但它的并运算「$\vee$」是「由两子群生成的
子群」$\langle H_1, H_2 \rangle$，不是集合的并。把格的 $\vee$ 想成集合并，
是最常见的认知偏差——**格的并是「序意义的最小上界」，具体实现因结构而异**。

## 7 小结

- **序定义**：每两元素都有 $\sup$ 与 $\inf$ 的偏序集；
  **代数定义**：带 $\vee, \wedge$、满足幂等/交换/结合/吸收四律的集合。
- 两种定义互相翻译，核心规则：$a \le b \iff a \wedge b = a \iff a \vee b = b$。
- **吸收律**是联结两个半格的铆钉；**半格分配律**在任意格中成立，
  真正的分配律只在分配格中成立。
- 有界格、格同态、子格、半格视角是进一步研究的基本零件。
- 幂集格、整除格、任何全序集都是格；「$\vee$ = 集合并」是普遍误区。

在下一节，我们将把格放上网格：**完全格与不动点定理（Knaster–Tarski）**——
任意子集都有确界，以及它带来的不动点丰收。
