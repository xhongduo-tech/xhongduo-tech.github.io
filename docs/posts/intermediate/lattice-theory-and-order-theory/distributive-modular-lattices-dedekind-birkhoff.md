## 为什么从分配格的判据开始

复习的第四站，回到格论最漂亮的分类定理。上一讲我们见过一条
**半格分配律**：$a \vee (b \wedge c) \le (a \vee b) \wedge (a \vee c)$
在任意格中都成立。真正的**分配律**要求两边相等，而它**不是**普遍成立的——
这正是格论的一道分水岭。**分配格（distributive lattice）**与更弱的
**模格（modular lattice）**，是格论里最重要的两个「好格」类别，
而刻画它们的判据优美得惊人：一个格是分配格，当且仅当它**不含**两个
五元素小怪胎——$N_5$（五角形）与 $M_3$（菱形）——作为子格；
一个格是模格，当且仅当它**不含** $N_5$。这个 Dedekind–Birkhoff 判据
把「某个等式是否成立」翻译成「某张哈斯图是否出现」，把代数问题
变成看图说话。今天的复习，就围绕这张判据图展开。

## 1 分配律与模律：两条刻划「好格」的等式

**分配格（distributive lattice）**：格 $L$ 满足对一切 $a, b, c$：

$$a \wedge (b \vee c) = (a \wedge b) \vee (a \wedge c)$$

（对偶等式 $a \vee (b \wedge c) = (a \vee b) \wedge (a \vee c)$ 可由此推出，
故只需验一条。）幂集格、整除格、任何链都是分配格。

**模格（modular lattice）**：格 $L$ 满足对一切满足 $a \le c$ 的 $a, b, c$：

$$a \vee (b \wedge c) = (a \vee b) \wedge c \qquad \text{（模律）}$$

**辨析｜易错点：** 分配格 ⟹ 模格（模律是分配律在 $a \le c$ 条件下的
特化），但模格不一定分配。分配律是「无条件的等式」，模律是「有前提
$a \le c$ 的等式」——前提越弱，适用范围越宽。**分配格 ⊆ 模格 ⊆ 格**，
三层的包含是严格的。

## 2 两个五元素小怪胎：N5 与 M3

刻画分配性的主角，是两个只有五个元素的格：

**$N_5$（五角形, pentagon）**：元素 $0, a, b, c, 1$，覆盖关系为
$0 \prec a \prec b \prec 1$ 与 $0 \prec c \prec 1$——一条链上
「挂」了一个中间元素 $c$。$N_5$ 是模律的破坏者：取 $a \le b$，
$a \vee (c \wedge b) = a \vee 0 = a$，而 $(a \vee c) \wedge b = 1 \wedge b = b$，
不相等。

**$M_3$（菱形, diamond）**：元素 $0, a, b, c, 1$，覆盖关系为
$0 \prec a, b, c \prec 1$——三个互不可比的元素夹在顶底之间。
$M_3$ 是分配律的破坏者：$a \wedge (b \vee c) = a \wedge 1 = a$，
而 $(a \wedge b) \vee (a \wedge c) = 0 \vee 0 = 0$，不相等。
但 $M_3$ 是模格（无 $N_5$ 子格）。

<span class="marginnote">记忆法：$N_5$ 是「五角大楼」、$M_3$ 是「菱形」。$N_5$ 破坏模律（也因此破坏分配律），$M_3$ 只破坏分配律、仍满足模律。凡看到「某等式不成立」的格，多半能在这两个小怪胎里找到它的「投影」。</span>

## 3 公式解析：模律的等价形式

模律看起来不对称（条件 $a \le c$ 打破了 $a$ 与 $c$ 的对称），
但它有一个对等价的、对称的替身——**「不具 N5 子格」正是模律的
几何翻译**：

$$a \le c \ \Rightarrow\ a \vee (b \wedge c) = (a \vee b) \wedge c$$

- **第一步，读方向 $\le$**：这是**无条件**成立的。由 $a \le c$ 得
  $a \le (a \vee b) \wedge c$；又 $b \wedge c \le b$ 且 $b \wedge c \le c$，
  故 $b \wedge c \le (a \vee b) \wedge c$。于是
  $a \vee (b \wedge c) \le (a \vee b) \wedge c$。
- **第二步，读等号**：模律要求反向不等式也成立——而反向不等式的
  失败，恰好刻画出 $N_5$ 的形态：沿着 $a \le c$ 却出现
  $a \vee (b \wedge c) \lt (a \vee b) \wedge c$，正是「$b$ 挂到了
  错的位置」。
- **第三步，读直觉**：模律说的是「把 $b$ 与 $c$ 的交先并上 $a$，
  与先把 $a$ 并上 $b$ 再与 $c$ 交」，在 $a \le c$ 时结果一致。
  **模格里的序结构「不会出现五角形陷阱」**：夹在 $a$ 与 $c$ 之间的
  元素 $b$ 不会同时制造两个层次。
- **第四步，读对偶**：模律自对偶（它自己蕴含对偶形式），这也是
  为什么「模」是比「分配」更宽、更稳定的结构——分配律不自对偶，
  模律对偶闭合。

## 4 核心对比表：Dedekind–Birkhoff 判据

两个判据并排，就是本次复习的核心表格：

| 判定对象 | 特征子格 | 判据（Dedekind, 1900） | 等价形式 |
| --- | --- | --- | --- |
| 模格 | $N_5$（五角形） | 不含 $N_5$ 子格 | 模律 $a \le c \Rightarrow a \vee (b \wedge c) = (a \vee b) \wedge c$ |
| 分配格 | $N_5$ 与 $M_3$（五角形与菱形） | 不含 $N_5$ 也不含 $M_3$ 子格 | 分配律 $a \wedge (b \vee c) = (a \wedge b) \vee (a \wedge c)$ |

<span class="marginnote">戴德金（Richard Dedekind）1900 年率先证明 $N_5$、$M_3$ 的判据；伯克霍夫（Garrett Birkhoff）在《Lattice Theory》中系统整理并给出严谨证明。判据的意义：把「等式对所有元素成立」这种<strong>无穷验证</strong>，压缩为「检查有限张图」的<strong>有限检查</strong>。</span>

**Birkhoff 的进一步观察**：分配格判据还可以再压成——$L$ 分配
当且仅当 $L$ 不含 $M_3$ 或 $N_5$；模格判据则只需 $N_5$。此外，
**有限分配格**还有更精细的结构：它们恰好是「以素理想/不可约元为骨架」
的格，这在《分配格的 Birkhoff 表示定理》一节已经展开。

**辨析｜易错点：** 判据说的是「**子格**」而非「子偏序集」。$L$ 不含
$N_5$ **子格**要求：$N_5$ 的五个元素必须在 $L$ 中且**它们的并/交在 $L$ 中
与 $N_5$ 中的一致**。仅「哈斯图上没有五角形图案」不够——还要确认
运算封闭。验证时通常的做法：找五个元素，逐一核对它们之间的并与交
确实等于 $N_5$ 中的并与交。

## 5 证明思路：为什么「无 N5/M3」就分配

判据的充分性（不含怪胎 ⟹ 等式成立）是核心难点，思路有三条：

- **思路一（构造/插入）**：假设分配律失败，即存在 $a, b, c$ 使
  $x = a \wedge (b \vee c) \neq (a \wedge b) \vee (a \wedge c) = y$。
  从 $x \neq y$ 出发，用序关系逐步「挤出」五个元素：
  $0 = (x \wedge a) \vee (x \wedge b) \vee (x \wedge c)$ 等一串组合，
  恰好拼出一个 $M_3$ 或 $N_5$ 的复制品。
- **思路二（商格）**：用同余关系把「分配律失败」的格压缩，
  压缩后的商格仍分配律失败，但更小；不断压缩最终落在 $M_3$ 或 $N_5$ 上。
- **思路三（Birkhoff 的函数视角）**：分配格同构于某个环上的函数格，
  由此分配律自动成立。

<span class="marginnote">思路一是教科书标准路线：它把「一个等式失败」翻译成「五个元素被结构逼迫到特定位置」。整个判据的证明其实是在说——<strong>五角形与菱形不是「反例」，而是「分配律失败的原子形态」</strong>：任何失败都包含它们。</span>

**推论（有限分配格的结构）**：有限分配格 $L$ 的元素恰由「$\to$ 素理想」
系统刻画，且 $L \cong$ 其素理想族的某种「生成格」。这是下一讲
《布尔代数与表示定理》与《Stone 表示定理》的桥梁。

## 6 判定流程与动手练习

给出一张哈斯图，判定它是否分配/模，按三步走：

1. **数元素**：少于 5 个元素的格自动分配（没有足够的空间装下
   $N_5$ 或 $M_3$）。
2. **找 $N_5$**：检查是否存在一条 4 元素链 $0 \prec a \prec b \prec 1$
   外加一个「挂在 $0$ 与 $1$ 之间」的元素 $c$（$0 \prec c \prec 1$）。
   有则非模（也非分配）。
3. **找 $M_3$**：若已通过 $N_5$ 检查，再看是否存在三个互不可比元素
   $a, b, c$ 共同夹在 $0$ 与 $1$ 之间（$0 \prec a, b, c \prec 1$）。
   有则非分配（但仍是模格）。

**练习**：判定下列格——(a) 幂集格 $\mathcal{P}(\{1,2,3\})$：分配
（经典分配格）；(b) 子群格（$V_4$ 的三个二阶子群 + 平凡子群）：不分配
（含 $M_3$）；(c) 五元素链：分配（链都是分配格）；(d) $N_5$ 自身：非模非分配。
<span class="marginnote">练习答案：$V_4$（克莱因四元群）的子群格恰是 $M_3$——三个 2 阶子群互不可比，夹在平凡子群与 $V_4$ 之间。这个「群论长出的菱形」是模格不分配的最经典例子。</span>

**为什么模格在代数里更重要**：子群格、子空间格、正规子群格都是**模格**
（多数非分配）。模格是「代数结构的格」的天然家园，分配格则是
「序/逻辑结构的格」的天然家园。**判据不只分类，还揭示了两种
数学世界的分工。**

## 7 小结

- **分配律** $a \wedge (b \vee c) = (a \wedge b) \vee (a \wedge c)$，
  **模律** $a \le c \Rightarrow a \vee (b \wedge c) = (a \vee b) \wedge c$；
  分配 ⟹ 模，包含严格。
- **判据（Dedekind–Birkhoff）**：模格 ⟺ 不含 $N_5$ 子格；
  分配格 ⟺ 不含 $N_5$ 也不含 $M_3$ 子格。
- $N_5$ = 五角形（破坏模律），$M_3$ = 菱形（只破坏分配律，仍模）。
- 判定三步：数元素 → 找 $N_5$ → 找 $M_3$。
- 子群格、子空间格是模格；幂集格、链是分配格——两类数学世界分工。
