## 为什么从完全格复习不动点

复习的第三站，把「完全格」与「不动点」合并成一次聚焦：
**完全格的存在价值，几乎全在不动点定理里兑现**。上一讲我们认识了
「每两元素有确界」的格；完全格（complete lattice）把这个条件一口气
放宽到**任意子集**。这个看似简单的升级，立刻换来一座金矿——
**Knaster–Tarski 定理**：完全格上任意保序自映射都有不动点，
且不动点的全体构成一个完全格。递归程序的语义、数据流分析的收敛、
Cantor–Bernstein 定理的证明、博弈论中均衡的存在性，全都可以
装进这个框架。今天的复习要把定理陈述、证明骨架、计算流程
与「不动点三定理」的对比一次讲透——这是格论向计算机科学
交出的最重要的一张入场券。

## 1 完全格：确界一网打尽

**完全格**：偏序集 $L$ 中，**任意子集** $S$（含空集、含 $L$ 自身）
都有上确界与下确界：

$$\forall\, S \subseteq L, \quad \bigvee S \ \text{与} \ \bigwedge S \ \text{都存在}$$

由空集与全集两种特殊情况立即得到：**完全格必有最小元
$\bot = \bigvee \emptyset = \bigwedge L$ 与最大元
$\top = \bigwedge \emptyset = \bigvee L$**。
<span class="marginnote">为什么 $\bigwedge \emptyset$ 是最大元？空集的一切元素都是它的「下界」，这些下界的全体是 $L$，其最大者即 $\top$。两个「空确界」是初学最容易忽略的角落，却是证明完全格必有界的关键。</span>

**辨析｜易错点：** 完全格的要求包括**无穷子集**。有限格自动完全（有限种子集
逐对取确界即可）；但无限格 $(\mathbb{R}, \le)$ 不是完全格——$\mathbb{R}$
自身无上界。旗舰例子是幂集 $(\mathcal{P}(X), \subseteq)$：
$\bigvee S = \bigcup S$、$\bigwedge S = \bigcap S$ 对任意子集族成立。
闭集族、子空间格、$[0,1]$ 也都是完全格。

## 2 定理陈述：不动点做成一个格

**Knaster–Tarski 不动点定理**：设 $L$ 是完全格，$f : L \to L$ 保序。
则 $f$ 的不动点集合

$$\operatorname{Fix}(f) = \{ x \in L : f(x) = x \}$$

**非空**，且按 $L$ 的序构成一个**完全格**。特别地，最小不动点与
最大不动点分别为

$$\mu f = \bigwedge \{ x \in L : f(x) \le x \}, \qquad \nu f = \bigvee \{ x \in L : x \le f(x) \}$$

- **第一步，读最小不动点**：$\mu f$ 是所有「$f(x) \le x$」（$f$ 把 $x$
  压住）的元素的下确界。这样的元素必存在——$\top$ 总满足
  $f(\top) \le \top$；且下确界在完全格中存在。
- **第二步，验它是不动点**：$f$ 保序给出 $f(\mu f) \le \bigwedge f(\{x : f(x) \le x\})
  \le \mu f$；又由 $f(\mu f) \le \mu f$ 得 $f(\mu f)$ 也属于
  $\{x : f(x) \le x\}$，故 $\mu f \le f(\mu f)$。两头夹即 $f(\mu f) = \mu f$。
- **第三步，读完全性**：定理最深刻的结论是 $\operatorname{Fix}(f)$ 自身
  是**完全格**——不动点族的任意确界（用「把 $f$ 限制到适当区间再取
  最小不动点」的递归技巧证明）仍是不动点。**不动点不只是「有」，
  而是「组织成了一个完整的秩序结构」。**

<span class="marginnote">历史：Knaster 1928 年在研究 Cantor–Bernstein 定理时先证明「不动点存在且成完全格」，Tarski 1955 年系统表述。有人把「存在性」叫 Knaster 定理，把「成完全格」叫 Tarski 定理。</span>

## 3 证明的骨架：一次代入，两头夹

证明核心只有一步妙棋：**取 $A = \{x : f(x) \le x\}$，令 $a = \bigwedge A$**。

- **第一步**：对每个 $x \in A$，$f$ 保序给出 $f(a) \le f(x) \le x$，
  故 $f(a)$ 是 $A$ 的下界，得 $f(a) \le a$。
- **第二步**：由 $f(a) \le a$ 再保序得 $f(f(a)) \le f(a)$，
  即 $f(a) \in A$。于是 $a = \bigwedge A \le f(a)$。
- **第三步**：合并得 $f(a) = a$。

<span class="marginnote">「$f(a) \in A$ 所以 $a \le f(a)$」是整套证明最灵巧的一跳：一旦 $f(a)$ 也落入 $A$，最小下界就把它夹住。这一跳不依赖连续性、紧致性或有限性——纯序结构白送的结果。</span>

**辨析｜易错点：** 定理**不需要** $f$ 连续、不需要 $L$ 有限、不需要
$f$ 单射——只要「保序 + 完全格」。这与分析里的**压缩映射不动点定理**
（需要度量与收缩条件）形成鲜明对比：一个靠「序」，一个靠「距离」，
互补而不互斥。把「保序」误记成「连续」是最常见的错位。

## 4 公式解析：从 $\bot$ 迭代到最小不动点

存在性之外，Knaster–Tarski 定理还指引出计算最小不动点的流程。
当 $L$ 有限（或迭代收敛）时，从 $\bot$ 出发反复应用 $f$：

$$\bot \le f(\bot) \le f^{2}(\bot) \le f^{3}(\bot) \le \cdots \longrightarrow \mu f$$

- **第一步，读递增**：$\bot \le f(\bot)$（$\bot$ 最小）且 $f$ 保序，
  归纳得 $f^n(\bot) \le f^{n+1}(\bot)$——序列单调不减。
- **第二步，读停机**：在有限格中，递增链必在某步停住：
  存在 $n$ 使 $f^{n+1}(\bot) = f^n(\bot)$，停住点就是不动点。
- **第三步，读最小性**：任何不动点 $x$ 满足 $\bot \le x$，归纳得
  $f^n(\bot) \le x$ 对一切 $n$，故停住点 $\le$ 一切不动点——最小不动点。
- **第四步，读对偶**：把起点换成 $\top$、方向反转，得到从 $\top$ 递减的
  序列，收敛到最大不动点 $\nu f$。**最小不动点编码「有限时间内可达成」的
  递归结果，最大不动点编码「可无限持续」的行为（活锁、无穷流）**——
  这一对孪生不动点在程序语义学里扮演两个互补的角色。

**例**：$L = \mathcal{P}(\{1,2,3\})$，$f(S) = S \cup \{1\}$。
从 $\bot = \emptyset$ 出发：$f(\emptyset) = \{1\}$，一步即停，
最小不动点 $\{1\}$；最大不动点 $\nu f = \{1\}$（含 1 的最小集即 $\{1\}$）。
**一步迭代到不动点，机制与真实编译器里的数据流分析一模一样。**

## 5 不动点三定理对比

「求不动点」的定理不止一个，把它们的适用条件并排看，才能避免张冠李戴：

| 定理 | 空间 | 映射条件 | 结论 | 计算性 |
| --- | --- | --- | --- | --- |
| Knaster–Tarski | 完全格 | 保序 | 不动点非空且成完全格 | 非构造性 |
| Kleene 迭代 | 完全格 / dcpo | Scott 连续 | 最小不动点 = $\bigvee_n f^n(\bot)$ | 可计算逼近 |
| Banach 压缩 | 完备度量空间 | 压缩（Lipschitz $< 1$） | 唯一不动点 | 迭代收敛 |

<span class="marginnote">三足鼎立：Tarski 靠「序」、Kleene 靠「连续 + 迭代」、Banach 靠「距离」。Tarski 给存在性、Kleene 给可计算逼近、Banach 给唯一性——三种工具各自回答「不动点」问题的不同侧面，在程序语义、数值分析、博弈论中各自称王。</span>

**辨析｜易错点：** Tarski 的结论是「存在 + 成格」但不给出构造方法；
Kleene 定理（完整版在第4篇 Domain 理论）额外要求 $f$ 保**有向并**
且迭代序列作为有向并收敛。在有限格中两者皆可达：Tarski 保证存在，
从 $\bot$ 迭代必然停机得到它。**「存在性」与「计算性」是两个层面的问题，
两个定理分别回答。**

## 6 应用巡礼：从集合论到程序分析

- **Cantor–Bernstein–Schröder 定理**：若存在单射 $A \to B$ 与单射
  $B \to A$，则存在双射。证明在 $\mathcal{P}(A)$ 上构造保序映射，
  不动点就是「完美配对」的分界集——Knaster 正是为此发明了不动点方法。
- **程序语义学**：递归方程 $F = \lambda x.\ \text{if}\ \ldots\ \text{then}\ F(x)\ \ldots$
  的语义 = Scott 域上的最小不动点（第4篇 Domain 理论的引擎）。
- **数据流分析**：可达性、活跃变量等静态分析，把格当作「事实集合」，
  把语义算子当作保序映射，从 $\bot$ 迭代到不动点——
  **每个静态分析器都是 Knaster–Tarski 定理的一个实例**。
- **博弈论**：Nash 均衡的存在性虽属拓扑传统，其离散版本同样可用
  格不动点表述。

**综合练习**：设 $L$ 是「全体闭区间 $[l,u] \subseteq [0,1]$」按包含构成的格
（含空区间为 $\bot$），$f([l,u]) = [(l+u)/3, (2l+u)/3]$（把区间映射到
其左三分之一）。验证 $f$ 保序；从 $\bot$ 出发迭代，观察区间如何
收缩逼近最小不动点。**看见了吗？——完全格的每个角落，都住着不动点。**

## 7 小结

- **完全格** = 任意子集都有确界的偏序集，必有 $\bot, \top$；幂集、
  闭集族、$[0,1]$ 是旗舰例子。
- **Knaster–Tarski**：完全格上保序自映射的不动点非空且成完全格；
  $\mu f = \bigwedge\{x : f(x) \le x\}$，$\nu f = \bigvee\{x : x \le f(x)\}$。
- 证明精髓：「$f(a) \in A$ 所以 $a \le f(a)$」——一次代入，两头夹。
- 从 $\bot$ 迭代收敛到最小不动点，从 $\top$ 迭代收敛到最大不动点。
- 与 Kleene（可计算）、Banach（唯一性）并称不动点三定理，适用条件各异。

在下一节，我们将给格装上「好格」的门槛：**分配格与模格
（Dedekind/Birkhoff 判据）**——两个五元素小怪胎如何完全刻画分配性。
