## 为什么从周期性收尾第二篇

从氢到稀有气体，我们逐族走完了 s 区与 p 区。现在到了"回头看"的时刻：**把散落在各族的规律拼成一张完整的地图**。这一章综合讨论元素性质的周期性、次级周期性、对角线关系与元素的地球化学分布——它回答一个终极问题：**给你一个从未学过的元素，你能否仅凭它在周期表的位置就预言它的化学？** 这正是化学"科学"而非"记忆"的体现。学完本章，第二篇"s 区与 p 区元素化学"才算真正闭环，也为第三篇 d 区与 f 区（过渡金属与镧系锕系）提供参照系——因为过渡金属的周期性，将出现 p 区没有的新逻辑（d 电子数、晶体场效应）。

## 1 元素性质的"主对角线"规律

元素性质随原子序数周期性变化，但细看有两条最重要的空间规律：

**横向（同周期）**：从左到右，$Z_{\text{eff}}$ 增大 → 半径减小、电离能增大、电负性增大、金属性减弱、非金属性增强。这条我们已经反复使用。

**纵向（同族）**：从上到下，能层增多 → 半径增大、电离能减小、电负性减小、金属性增强。

**对角方向**：横向"减弱金属性"与纵向"增强金属性"互相抵消，于是**周期表左下角金属性最强（$\ce{Cs}$、$\ce{Fr}$），右上角非金属性最强（$\ce{F}$）**——金属性沿主对角线渐变。这条"主对角线"是预测元素性质最粗但最稳的标尺。<span class="marginnote">锂在碱金属中"最小、最不活泼、共价性最强"，正是因为它偏离"典型碱金属"最远；铯则是碱金属的"典型代表"。元素的"典型性"可以在周期表上用距对角线区域的远近读出。</span>

## 2 对角线规则：斜向的"同族"效应

周期表中，**第二周期元素与其右下方第三周期元素**（如 $\ce{Li}$ 与 $\ce{Mg}$）常表现出异常相似的性质，称为**对角线规则（diagonal relationship）**。经典三对：

- **$\ce{Li}$ 与 $\ce{Mg}$**：都较硬、熔沸点较高（同族中最高）；氟化物、碳酸盐、磷酸盐都难溶；氢氧化物受热分解；都能直接与 $\ce{N2}$ 反应生成氮化物（$\ce{Li3N}$、$\ce{Mg3N2}$）——这是碱金属中独有的。
- **$\ce{Be}$ 与 $\ce{Al}$**：都是两性金属，能溶于强碱；氧化物、氢氧化物都是两性；氯化物都是共价型、易升华、溶于有机溶剂；氟化物都稳定而氯化物水解。
- **$\ce{B}$ 与 $\ce{Si}$**：都是缺电子非金属，硼烷与硅烷都易水解、在空气中自燃；氧化物都是酸性氧化物（$\ce{B2O3}$、$\ce{SiO2}$）。

**对角线规则的根源**：**离子势（ionic potential）$\phi = Z/r$**（电荷与半径之比）。$\ce{Li+}$（半径 0.76 Å）与 $\ce{Mg^2+}$（半径 0.72 Å）的 $Z/r$ 相近，都是"小半径高电荷"，极化力、共价倾向、水解性因此相似。<span class="marginnote">$\ce{Li+}$ 半径 0.76 Å、$\ce{Mg^2+}$ 半径 0.72 Å——一对对角线元素的离子半径几乎相同，而电荷差一倍。<strong>离子势 $\phi = Z/r$ 是预测"两性、水解、共价性"的浓缩指标</strong>：$\phi$ 大致相同时，离子行为相似。这是《元素性质周期性》最精炼的"杠杆"。</span>

**辨析｜易错点：** 对角线规则不是"对角线上的所有元素都相似"，而是**特定几对**（Li-Mg、Be-Al、B-Si）因离子势巧合相似。不要把它泛化成"左上右下都相似"——那是主对角线金属性渐变，与对角线规则是两回事。

## 3 次级周期性：不是所有渐变都平滑

同族元素性质向下并非均匀渐变，往往在**第三周期与第四周期之间、以及第四周期与第五周期之间**出现跳跃，称为**次级周期性（secondary periodicity）**。

最著名的例子：**惰性电子对效应**在第 VA 族表现为 $\ce{Bi}$ 的 $+3$ 态异常稳定、$\ce{Bi^5+}$ 几乎不存在；在第 IVA 族表现为 $\ce{Pb^2+}$ 稳定、$\ce{Pb^4+}$ 氧化性强；在第 IIIA 族表现为 $\ce{Tl+}$ 稳定、$\ce{Tl^3+}$ 氧化性强。根源是 4f 与 5d 电子对 6s 电子的屏蔽差、6s 轨道能量骤降——**镧系收缩**的直接后果。

**镧系收缩（lanthanide contraction）**：镧系元素（$\ce{La}$–$\ce{Lu}$）的原子半径随原子序数缓慢减小（4f 电子屏蔽差，$Z_{\text{eff}}$ 增大），导致从 $\ce{La}$ 到 $\ce{Lu}$ 半径收缩约 0.2 Å。这带来两个连锁后果：

- $\ce{Zr}$ 与 $\ce{Hf}$、$\ce{Nb}$ 与 $\ce{Ta}$、$\ce{Mo}$ 与 $\ce{W}$ 的半径几乎相同，化学性质极难分离——这是第三篇《过渡金属通性》的重要伏笔。
- 第六周期 p 区元素的 6s² 惰性对效应增强（镧系收缩使 6s 更紧），$+2$ 态稳定。

**次级周期性的表现**：同族第三、四周期元素差异大（如 $\ce{Cl}$ 与 $\ce{Br}$ 的差异大于 $\ce{Br}$ 与 $\ce{I}$），第四、五周期差异大（如 $\ce{Sr}$ 与 $\ce{Ba}$ 差异大于 $\ce{Ba}$ 与 $\ce{Ra}$）——**性质曲线不是平滑直线，而是"阶梯"**。

## 4 电负性与氧化态的周期规律

**电负性**在周期表中的分布我们已经熟悉：同周期递增、同族递减、F 最大。但要注意**电负性的"拐点"**：

- 第 IIIA 族的 $\ce{Al}$ 与第 IVA 族的 $\ce{Si}$ 之间电负性"反常"增大——因为 $\ce{B}$、$\ce{Si}$ 都是缺电子元素，亲电性强。
- 电负性差异是判断**键型、极性、酸碱性**的总开关。

**最高氧化态**的周期规律：

- 主族元素最高正价 = 族序数（$\ce{Na}$ +1、$\ce{Mg}$ +2、$\ce{Al}$ +3、$\ce{Si}$ +4、$\ce{P}$ +5、$\ce{S}$ +6、$\ce{Cl}$ +7）。
- 第 2 周期元素（$\ce{O}$、$\ce{F}$）无最高正价（氧无 $+6$、氟无正价）——因无 d 轨道。
- 过渡金属的最高氧化态从 IIIB 族到 VIIB 族递增（$\ce{Mn}$ +7、$\ce{Ru}$ +8），VIII 族后下降——见《过渡金属通性》。

**含氧酸的酸性规律**（鲍林规则）：含氧酸的酸性随中心原子氧化态升高而增强：

- $\ce{HClO < HClO2 < HClO3 < HClO4}$（Cl 从 +1 到 +7，酸性递增）。
- 非羟基氧越多，酸性越强：$\ce{HClO4}$ 的强酸性源于三个非羟基氧把电子拉离 $\ce{O-H}$ 键。

## 5 公式解析：离子势与对角线规则

对角线规则的核心量化工具是离子势：

$$
\phi = \frac{Z}{r}
$$

- $Z$：离子电荷数（绝对值）。
- $r$：离子半径（常用有效离子半径，单位 Å 或 pm）。
- $\phi$：单位半径上的电荷密度，衡量离子的极化力。

拆解三步：

- **第一步，理解物理意义**：$\phi$ 大 = 离子"小而电荷高"，极化力强 → 共价性、水解性、两性增强；$\phi$ 小 = "大而电荷低"，离子性强 → 碱性氧化物倾向。
- **第二步，算对角线对**：$\ce{Li+}$：$\phi = 1/0.76 = 1.32$；$\ce{Mg^2+}$：$\phi = 2/0.72 = 2.78$。两值相近（同数量级），所以两者离子行为相似。
- **第三步，预测两性**：$\ce{Be^2+}$：$\phi = 2/0.45 = 4.4$；$\ce{Al^3+}$：$\phi = 3/0.54 = 5.6$——都是中高 $\phi$，落在"两性区"，故 $\ce{Be(OH)2}$ 与 $\ce{Al(OH)3}$ 都是两性氢氧化物。**离子势把"两性"从记忆变成计算**：$\phi$ 约在 2–7 之间的离子，氢氧化物倾向两性。

**这是无机化学"结构-性质"思想的浓缩**：一个离子电荷与半径的简单比值，就能预言它在周期表中的"性格"。

## 6 地球化学分布与"元素丰度"

元素性质的周期性也反映在**地壳与海洋的元素丰度**上：

- 地壳前五：$\ce{O}$（49%）、$\ce{Si}$（26%）、$\ce{Al}$（7.5%）、$\ce{Fe}$（4.7%）、$\ce{Ca}$（3.4%）——**轻元素、偶数原子序数元素更丰**（奥多-哈金斯规则：原子序数为偶数的元素丰度高）。
- 海洋以 $\ce{Cl-}$、$\ce{Na+}$ 为主。
- 大气以 $\ce{N2}$、$\ce{O2}$ 为主，稀有气体按质量分数 $\ce{Ar > Ne > He > Kr > Xe}$。

元素丰度受核合成过程决定（恒星核合成中，铁是聚变与裂变能量的分界），这已经通向《天体物理》与《地球系统科学》——无机化学的元素地图，最终由宇宙的核物理书写。<span class="marginnote">奥多-哈金斯规则背后是核物理学：偶数质子数的原子核更稳定，因此核合成更倾向产生它们。化学元素的"库存清单"，其实是一张宇宙核合成的资产负债表。</span>

### 拓展：鲍林规则的两点补充

含氧酸强度除了"氧化态越高越强"（正文），鲍林规则还给出两条定量补充：

- **酸性规律**：含氧酸 $pK_a \approx 8 - 5m$，其中 $m$ 为非羟基氧的数目。$\ce{HClO4}$ 有 3 个非羟基氧，$pK_a \approx 8 - 15 = -7$（极强酸）；$\ce{H3PO4}$ 无非羟基氧（结构 $\ce{PO(OH)3}$），$pK_a \approx 8$。
- **碱性规律**：碱性强弱取决于"给 $\ce{OH-}$ 的能力"，与金属的电负性相关——电负性小（金属性强）→ 碱性氧化物强碱，电负性大 → 酸性氧化物。

这些规则让"含氧酸强度"从记忆表变成可以推算的规律，是元素周期律在酸碱化学中的定量延伸（连接《酸碱理论》）。

## 7 小结

- 元素金属性沿**主对角线**渐变：左下金属性最强，右上非金属性最强。
- **对角线规则**（$\ce{Li}$-$\ce{Mg}$、$\ce{Be}$-$\ce{Al}$、$\ce{B}$-$\ce{Si}$）源于离子势 $\phi = Z/r$ 相近。
- **次级周期性**：同族性质不是平滑递减，三四周期、四五周期之间有明显跳跃。
- **镧系收缩**使第六周期元素半径异常、6s² 惰性对效应增强，也造成 $\ce{Zr/Hf}$、$\ce{Nb/Ta}$ 难分离。
- 主族最高正价 = 族序数，但第 2 周期元素（$\ce{O}$、$\ce{F}$）无最高正价。
- 含氧酸酸性随中心原子氧化态升高而增强（$\ce{HClO < HClO2 < HClO3 < HClO4}$）。
- 元素丰度遵循偶数原子序数规则，根源在宇宙核合成。
