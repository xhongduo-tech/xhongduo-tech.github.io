## 为什么从原子结构开始

无机化学研究的对象是**除碳氢化合物及其衍生物之外的全部元素及其化合物**。要理解一百多种元素为何有迥异的脾气——钠遇水即燃而黄金千年不锈、氟是极端的氧化剂而氦是惰性气体——都必须回到同一个起点：**原子内部的电子排布**。上一级《化学》已经学过原子由质子、中子、电子构成，也见过氢原子光谱的离散谱线；本章要把"电子在原子中如何分布"从描述推进到定量，并回答一个贯穿全学科的问题：**元素周期律为什么是周期性的？** 这份周期性不是被"发明"的，而是被量子力学**推导**出来的。学完本章，你将拥有解读整张周期表的第一个理论框架。

## 1 四个量子数与电子的"地址"

经典物理学无法解释一个核心事实：**为什么电子不坠入原子核？** 卢瑟福的核式模型里，绕核转动的电子持续加速，按经典电动力学必然辐射能量、在极短时间内坠毁。玻尔用"定态"假设强行修补，却解释不了多电子原子。真正的答案来自**量子力学**：电子没有确定的轨道，只有概率云，由四个量子数描述。

**主量子数 $n$**：决定电子所处的**能层**（电子层），$n = 1, 2, 3, \cdots$，对应 K、L、M、N 层。$n$ 越大，电子平均离核越远、能量越高。<span class="marginnote">能层不是行星轨道，而是能量的分层；$n$ 越大能量越高的结论在多电子原子中会遇到"能级交错"的例外，这正是后面周期表第四周期先排钾再排钙的原因。</span>

**角量子数 $l$**：决定电子云的**形状**（能级/亚层），$l = 0, 1, 2, \cdots, n-1$，分别记作 $s, p, d, f$。$s$ 轨道是球形，$p$ 轨道是哑铃形，$d$ 轨道是四瓣梅花形。

**磁量子数 $m$**：决定轨道在空间的**取向**，$m = -l, \cdots, 0, \cdots, +l$，共 $2l+1$ 个取值。$s$ 只有一个取向，$p$ 有三个（$p_x, p_y, p_z$），$d$ 有五个。

**自旋量子数 $m_s$**：取 $+\frac{1}{2}$ 或 $-\frac{1}{2}$，表示电子自旋的两个方向，通常用上下箭头 $\uparrow\downarrow$ 表示。

一个确定的 $(n, l, m, m_s)$ 四元组唯一对应**一个电子**。用"地址"作类比：$n$ 是城市、$l$ 是街区、$m$ 是门牌号、$m_s$ 是楼层——四个坐标锁定了电子的全部状态。第 $n$ 能层最多容纳 $2n^2$ 个电子，这一数字来自 $l$ 与 $m$ 的计数：$\sum_{l=0}^{n-1} 2(2l+1) = 2n^2$。

## 2 排布三原则与构造原理

电子填充不是随意的，而是受三条铁律约束：

**泡利不相容原理（Pauli exclusion principle）**：同一原子中，不可能有两个电子处于完全相同的量子态。换句话说，每个原子轨道最多容纳**两个自旋相反的电子**。<span class="marginnote">泡利原理是"全同粒子"性质的后果：电子不可区分，因而交换两个电子的波函数必须变号，直接推出同一轨道不能容纳第三个电子。它在化学里的作用是把每一层"填满"——决定周期表的行宽。</span>

**能量最低原理**：电子优先占据能量最低的轨道，使原子处于基态。

**洪特规则（Hund's rule）**：同一能级的多个轨道（如三个 $2p$ 轨道），电子先**单独占据**且自旋平行，然后才成对。

据此，电子按**构造原理（Aufbau principle）**依次填入，填充顺序为：

$$1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p \cdots$$

这里出现了一个关键现象：**能级交错**——$4s$ 的能量低于 $3d$，所以钾（$Z=19$）的最后一个电子进入 $4s$ 而非 $3d$。这也是为什么第四周期从钾开始，而不是把 $3d$ 填满才开始第四周期。

## 3 元素周期律的量子根源

元素按核电荷数排列，性质呈现周期性——这个经验规律在今天可以严格推导。周期的本质是**能层的开启**：每当一个新主量子数 $n$ 开始填充，就开启一个新周期。所以：

- **第 1 周期**：只填 $1s$，2 个元素（$2n^2 = 2$）。
- **第 2、3 周期**：填 $s + p$，各 8 个元素。
- **第 4、5 周期**：填 $s + d + p$，各 18 个元素。
- **第 6、7 周期**：填 $s + f + d + p$，各 32 个元素。

每行元素个数恰等于该能层可容纳电子数 $2n^2$ 的一部分——**周期表的一行，就是一套能级被填满的过程**。同族元素价电子构型相同（如碱金属都是 $ns^1$），因此化学性质相似。**周期律不是元素列表的巧合，而是电子排布逐层重复的直接投影。**

**价电子构型**是打开元素化学的钥匙：主族元素的价电子是 $ns + np$，过渡金属是 $(n-1)d + ns$。$ns^1$ 的碱金属极易失去一个电子成 $+1$ 价；$ns^2np^5$ 的卤素极易获得一个电子成 $-1$ 价。周期表左边富电子给、右边缺电子拿，中间过渡金属则灵活多变。

**辨析｜易错点：** 许多人以为"电子先填满 $3d$ 再填 $4s$"。实际上书写电子构型时把 $3d$ 写在 $4s$ 前（如 $\ce{Sc: [Ar] 3d^1 4s^2}$），但电离时**先失去的是 $4s$ 电子**。失去顺序与填充顺序相反，因为填充时 $4s$ 能量低，失去时（外层裸露后）$4s$ 反而更易被剥离。过渡金属常见 $+2$ 价就源于此。<span class="marginnote">同理，$\ce{Cr}$ 的构型是 $3d^5 4s^1$ 而非 $3d^4 4s^2$、$\ce{Cu}$ 是 $3d^{10} 4s^1$ 而非 $3d^9 4s^2$——半满与全满的 $d$ 亚层额外稳定，这是洪特规则的特例。</span>

## 4 公式解析：由有效核电荷看周期性

周期性规律可以用一个简洁公式统一解释，那就是**有效核电荷（effective nuclear charge）**：

$$
Z_{\text{eff}} = Z - \sigma
$$

- $Z$：核电荷数（原子序数）。
- $\sigma$：**屏蔽常数**，内层电子对外层电子"遮挡"核电荷的量。
- $Z_{\text{eff}}$：外层电子实际感受到的核电荷。

拆解三步：

- **第一步，理解屏蔽**：内层电子介于核与外层电子之间，抵消了部分核的吸引。越靠内的电子层，屏蔽效果越强。
- **第二步，理解同族变化**：同族元素向下，$n$ 增大，内层电子数增多，$\sigma$ 增大；但新增的核电荷也增多。净效果是 $Z_{\text{eff}}$ 基本持平（主族）或略增（过渡金属），所以金属性向下增强。
- **第三步，理解同周期变化**：同一周期从左到右，$n$ 相同但 $Z$ 逐个增加，而新增电子填在同一能层、屏蔽不完全，$\sigma$ 增加得少，故 $Z_{\text{eff}}$ **明显增大**——核对外层电子的束缚越来越紧，于是原子半径减小、电离能增大、金属性减弱。

这解释了周期表左上到右下金属性变化的"主对角线"规律：金属性最强的铯（$\ce{Cs}$）在最左下角，非金属性最强的氟（$\ce{F}$）在最右上角。**屏蔽效应与有效核电荷，是把"元素性质"这个宏观事实翻译成微观机制的第一座桥。**

## 5 四个基本性质及其周期变化

**原子半径**：同周期从左到右递减（$Z_{\text{eff}}$ 增大），同族从上到下递增（能层增多）。

**第一电离能 $I_1$**：气态原子失去一个电子所需的最低能量。同周期大致递增，但有**反常**：第 IIA 族（如 $\ce{Be}$）与第 VA 族（如 $\ce{N}$）偏高。原因是 $ns^2$ 全满与 $np^3$ 半满构型特别稳定，失去电子要破坏这种稳定。$I_1$ 的反常是考试与理解的双重重点。

**电子亲和能**：气态原子获得一个电子释放的能量。卤素最易得电子，$E_A$ 最大；第 IIA 族与稀有气体很小甚至为负（$s^2$ 与 $p^6$ 构型稳定，不倾向得电子）。

**电负性（electronegativity）**：分子中原子吸引成键电子的能力。常用**鲍林标度**，氟取最高值 3.98。电负性差是判断键型的判据：差值 $> 1.7$ 倾向离子键，$< 1.7$ 倾向共价键。

**辨析｜易错点：** 电负性与电离能不是一回事。电离能描述**孤立原子**失去电子的难易，电负性描述**分子中**吸引电子的能力。$\ce{H}$ 的电离能（1312 kJ/mol）比 $\ce{F}$（1681 kJ/mol）低，但电负性（2.20）却明显低于氟（3.98），两者变化趋势大体一致但不可混用。<span class="marginnote">电负性的另一个常用标度是密立根标度：$\chi = (I + E_A)/2$，即电离能与电子亲和能的算术平均。它在物理图像上更直接：吸引电子的能力强，就是"既难失去又易得到"。</span>

### 拓展：电子亲和能的细节与光谱项

原子的周期性还可以从两个进阶角度观察：

- **电子亲和能的"锯齿"**：电子亲和能曲线比电离能更锯齿——$\ce{Cl}$（$3p^5$）得电子成 $3p^6$ 全满，亲和能大；$\ce{F}$（$2p^5$）虽然电负性最强，但半径小、电子云密集，新增电子受排斥，电子亲和能反而小于 $\ce{Cl}$。**"电负性最大"不等于"最易得电子"**，这是易错点。
- **光谱项（term symbol）**：多电子原子的能级由 $L$、$S$、$J$ 三个量子数描述（光谱项 $^{2S+1}L_J$）。洪特规则可由此精确表述：总自旋 $S$ 最大、总轨道角动量 $L$ 最大、$J$ 按壳层半满取最小或最大。$\ce{Fe^3+}$（$d^5$）的基态光谱项是 $^6S_{5/2}$，六重态意味着 5 个未成对电子。

**这些细节通向《结构化学》与《量子化学》**：光谱项解释原子光谱的精细结构，是理解 d-f 区元素光谱性质（颜色、磁性）的理论起点。

### 拓展：原子光谱：电子排布的实验证据

氢原子光谱的巴尔末系等分立谱线，是电子能级量子化的直接证据：电子在能级间跃迁发射特定波长的光子（$E = h\nu$）。钠的黄色双线（589.0/589.6 nm）来自 $3p \to 3s$ 跃迁的精细结构——光谱分析由此成为鉴定元素与测定电子结构的实验基础，通向《结构化学》与《分析化学》。

## 6 小结

- 四个量子数 $(n, l, m, m_s)$ 完整描述一个电子；第 $n$ 能层最多容纳 $2n^2$ 个电子。
- 电子排布遵循**泡利不相容原理、能量最低原理、洪特规则**；构造原理中存在**能级交错**（$4s < 3d$）。
- 周期表的**每一行对应一套能级的填充**，周期数由主量子数决定——这是周期律的量子根源。
- 有效核电荷 $Z_{\text{eff}} = Z - \sigma$ 统一解释了半径、电离能、电负性的周期变化。
- 第一电离能存在 IIA、VA 的"平台"反常，源于全满/半满构型的稳定性。
- 电负性与电离能描述不同情境下的电子行为，不可混用。
