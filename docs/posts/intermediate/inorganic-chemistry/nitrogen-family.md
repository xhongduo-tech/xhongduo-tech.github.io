## 为什么从氮族开始

氮族元素（第 VA 族：$\ce{N, P, As, Sb, Bi}$）是无机化学 p 区最"戏多"的一族。氮的大气占 78%，却是出了名的"惰性"——$\ce{N2}$ 的三键键能高达 946 kJ/mol，是全化学最难断裂的键之一，这使固氮成为近代化学最艰难的攻关（哈伯-博施法养活了全球一半人口）；磷有白磷、红磷、黑磷三种同素异形体，白磷自燃、红磷做火柴、磷酸滋养作物。从肥料、炸药到农药、半导体（砷化镓），氮族化学渗透现代生活的每一个角落。学完本章，你将理解"键能决定惰性""氧化态多样性"这两大主题在 p 区如何上演。

## 1 氮：大气中的"惰性气体"

氮原子价电子构型 $2s^22p^3$，三个未成对电子。两个氮原子形成**三键** $\ce{N#N}$，键能 946 kJ/mol——单键、双键、三键中，$\ce{N2}$ 的三键是化学键能的天花板之一。这使得氮气：

- **化学性质极不活泼**：常温几乎不与任何物质反应，曾被称为"惰气"。
- 只有在高温、放电或催化剂条件下才参与反应：$\ce{N2 + O2 -> 2NO}$（雷雨天的闪电固氮）、$\ce{N2 + 3H2 -> 2NH3}$（合成氨）。<span class="marginnote">$\ce{N2}$ 的三键键能（946）比 $\ce{C≡C}$（约 837）还高，所以氮气比乙炔"稳"得多。<strong>断裂三键的高昂代价，就是大气氮"无动于衷"的热力学根源</strong>——它能量很低，但拆开它的门槛也极高。</span>

**氮的氧化态谱系**：从 $-3$（$\ce{NH3}$）到 $+5$（$\ce{HNO3}$），氮几乎涵盖了所有整数氧化态，每一种都有代表化合物，构成一个完整的"氮的氧化还原阶梯"：

| 氧化态 | 代表物 | 性质 |
| --- | --- | --- |
| $-3$ | $\ce{NH3}$ | 还原性，碱性 |
| $-2$ | $\ce{N2H4}$ 联氨 | 强还原剂（火箭燃料） |
| $0$ | $\ce{N2}$ | 惰性 |
| $+1$ | $\ce{N2O}$ | 笑气，麻醉剂 |
| $+2$ | $\ce{NO}$ | 无色，遇氧变棕 |
| $+3$ | $\ce{HNO2}$ 亚硝酸 | 既有氧化性又有还原性 |
| $+4$ | $\ce{NO2}$ | 红棕色，毒性 |
| $+5$ | $\ce{HNO3}$ | 强氧化性酸 |

**辨析｜易错点：** 氮的中间氧化态（$+1$、$+2$、$+3$、$+4$）的化合物既有氧化性又有还原性，能发生**歧化**与**归中**反应。例如 $\ce{NO2}$ 溶于水歧化：$3\ce{NO2 + H2O -> 2HNO3 + NO}$——$+4$ 的氮一部分升到 $+5$、一部分降到 $+2$。判断中间价态化合物的反应，先找它相邻的氧化态。

## 2 氨与铵盐

**氨 $\ce{NH3}$**：无色、有刺激性气味的气体，极易溶于水（1 体积水溶约 700 体积氨），水溶液呈弱碱性。<span class="marginnote">氨极易溶是因为它能与水形成氢键。氨水的碱性来自 $\ce{NH3 + H2O <=> NH3·H2O <=> NH4+ + OH-}$——这是唯一的弱碱，也是《酸碱理论》中"$\ce{NH3}$ 是布朗斯特碱而非阿伦尼乌斯碱"的现场版。</span>

**氨的制备**：
- 实验室：$\ce{2NH4Cl + Ca(OH)2 \xrightarrow{\Delta} 2NH3 ^ + CaCl2 + 2H2O}$，用碱石灰干燥、向下排空气收集（氨比空气轻）。
- 工业：**哈伯-博施法**（Haber–Bosch）：$\ce{N2 + 3H2 \rightleftharpoons 2NH3}$（铁催化剂，400–500 °C，20–50 MPa）。这是 1918 年诺贝尔化学奖成果，解决了"从空气取氮"的世界难题，直接支撑了现代农业的氮肥供应。

**铵盐**：铵根 $\ce{NH4+}$ 与酸根形成的盐，都是易溶、易分解的白色晶体。**铵盐受热分解**是它最鲜明的特征：

$$\ce{NH4Cl \xrightarrow{\Delta} NH3 ^ + HCl ^}$$

$$\ce{NH4HCO3 \xrightarrow{\Delta} NH3 ^ + CO2 ^ + H2O}$$

**铵态氮肥**（$\ce{NH4Cl}$、$\ce{NH4NO3}$、$\ce{(NH4)2SO4}$）是农业主力氮肥。**检验铵根**：加碱加热，放出能使湿润红色石蕊试纸变蓝的气体（$\ce{NH3}$）。

## 3 硝酸与硝酸盐

**硝酸 $\ce{HNO3}$**：最重要的无机强酸之一，具有**强酸性 + 强氧化性 + 不稳定性**三重性格。

- **强氧化性**：浓硝酸与稀硝酸都能氧化金属，产物不同：
  - 浓硝酸（与 $\ce{Cu}$）：$\ce{Cu + 4HNO3(浓) -> Cu(NO3)2 + 2NO2 ^ + 2H2O}$
  - 稀硝酸（与 $\ce{Cu}$）：$3\ce{Cu + 8HNO3(稀) -> 3Cu(NO3)2 + 2NO ^ + 4H2O}$
  - **浓硝酸生成 $\ce{NO2}$（棕红），稀硝酸生成 $\ce{NO}$（无色）**——产物由硝酸浓度决定，因为硝酸还原产物按浓度递降：$\ce{NO2 -> NO -> N2O -> N2 -> NH4+}$。<span class="marginnote">记忆：硝酸浓度越高，还原产物中氮的氧化态越高。浓硝酸得 $\ce{NO2}$（$+4$），稀硝酸得 $\ce{NO}$（$+2$），极稀硝酸甚至生成 $\ce{NH4+}$（$-3$）。"越稀还原越狠"是硝酸化学最反直觉又最常考的规律。</span>
- **不稳定性**：见光或受热分解：$4\ce{HNO3 \xrightarrow{\text{光/热}} 4NO2 + O2 + 2H2O}$——浓硝酸久置变黄就是分解出的 $\ce{NO2}$ 溶入所致，所以硝酸要**棕色瓶避光保存**。
- **钝化**：浓硝酸使 $\ce{Fe}$、$\ce{Al}$ 表面生成致密氧化膜而"钝化"，因此浓硝酸可用铁罐储运。

**硝酸盐**：全部易溶于水，受热分解放出 $\ce{O2}$，是强氧化剂。**硝酸钾 $\ce{KNO3}$** 是黑火药（硝酸钾+木炭+硫磺）的氧化剂；**硝酸铵 $\ce{NH4NO3}$** 是高效氮肥，但也因爆炸性成为"危险化肥"（天津港事故的教训）。

**磷的氧化物与含氧酸**：磷的燃烧产物是**五氧化二磷 $\ce{P2O5}$**（吸水性强，常用干燥剂）与三氧化二磷。磷酸 $\ce{H3PO4}$ 是不挥发的三元中强酸，用于磷肥（磷酸盐）、食品添加剂（磷酸、磷酸盐）、水处理。

## 4 磷的同素异形体与含氧酸

**白磷（黄磷）$\ce{P4}$**：正四面体分子，剧毒，燃点极低（约 40 °C），在空气中**自燃**，须保存在水中。白磷分子中 $\ce{P-P-P}$ 键角 60°，张力大，所以白磷异常活泼。
**红磷**：白磷隔绝空气加热转化，无毒、稳定得多，是火柴盒侧面的发火材料。
**黑磷**：层状结构，最稳定，具有类似石墨的性质，近年成为二维材料的研究热点。<span class="marginnote">白磷与红磷是"同一元素不同命运"的又一个注脚：白磷自燃、红磷安全。白磷曾在战场上用作燃烧武器，红磷则是火柴的功臣——同素异形体的安全性差异，是化学史与军事史的共同素材。</span>

**磷的含氧酸**：正磷酸 $\ce{H3PO4}$、亚磷酸 $\ce{H3PO3}$（二元酸）、次磷酸 $\ce{H3PO2}$（一元酸）。含氧酸中不与氧相连的"$\ce{H}$"才有酸性——$\ce{H3PO3}$ 的结构是 $\ce{HP(O)(OH)2}$，只有两个 $\ce{OH}$ 上的氢可电离。

**磷肥**：磷是植物三大营养元素（N、P、K）之一。**磷灰石 $\ce{Ca3(PO4)2}$** 不溶于水，须用硫酸处理成可溶的**过磷酸钙** $\ce{Ca(H2PO4)2}$ 才能被作物吸收。磷的循环在《生物无机化学》与《生态学》中会再遇。

## 5 公式解析：哈伯-博施法为何要高温高压

合成氨是勒夏特列原理与动力学权衡的教科书案例，用前面学过的公式拆解：

$$
\ce{N2 + 3H2 \rightleftharpoons 2NH3}, \qquad \Delta H = -92\ \text{kJ/mol}
$$

**第一步，看热力学（勒夏特列）**：放热反应（$\Delta H < 0$），低温利于 $\ce{NH3}$；4 mol 气体变 2 mol，高压利于生成。所以理论上温度越低、压强越高越好。
**第二步，看动力学（速率）**：$\ce{N2}$ 三键太难断，低温下反应极慢，几乎无工业价值。必须升温提速——但升温使平衡逆向移动，转化率下降。
**第三步，折中**：工业选 400–500 °C、20–50 MPa、铁催化剂——高温保速率、高压保转化率、催化剂降低活化能。产物氨及时液化分离，使平衡持续右移。**这是热力学、动力学、工程经济三者的三角平衡**，也是"化学原理"章节所有工具的一次总动员。

### 拓展：氮循环与农业的代价

氮的化学循环连接大气、土壤与生命，是人类世最深刻的化学足迹之一：

- **固氮**：天然固氮（雷电、豆科根瘤菌的固氮酶）+ 人工固氮（哈伯-博施法）。人工固氮让粮食产量翻倍，养活了全球人口。
- **硝化与反硝化**：土壤微生物把 $\ce{NH4+}$ 氧化为 $\ce{NO3-}$（硝化），又把 $\ce{NO3-}$ 还原为 $\ce{N2}$（反硝化）——构成氮的闭合循环。
- **氮肥过量的代价**：过量 $\ce{NO3-}$ 随水流失 → 湖泊、近海富营养化（藻华、赤潮、死区）；过量施用还产生温室气体 $\ce{N2O}$（笑气，也是臭氧消耗物）。
- **氮氧化物污染**：燃烧产生 $\ce{NO_x}$ 导致酸雨与光化学烟雾，需 SCR 脱硝治理（《钛钒铬锰》）。

**化学视角**：氮在 $-3$（$\ce{NH3}$）与 $+5$（$\ce{NO3-}$）之间循环，每一步都是微生物或工业催化的氧化还原——**氮循环的本质，是氮元素的"氧化还原大循环"**。

### 拓展：肼与叠氮化物

氮的低价化合物是能量密集的化学：

- 肼 $\ce{N2H4}$（氮 $+2$ 价）：$\ce{N-N}$ 键弱、燃烧放热巨大，是火箭推进剂（联氨/UDMH）；肼燃料电池也有应用。
- 叠氮化钠 $\ce{NaN3}$：受热剧烈分解释放 $\ce{N2}$（$2\ce{NaN3 -> 2Na + 3N2}$），是汽车安全气囊的气体发生器——"瞬间产气"靠的就是 $\ce{N2}$ 的稳定与叠氮的高能。

**启示**：氮的 $+1$ 到 $-2$ 低价化合物（$\ce{N2O}$、$\ce{N2H4}$、$\ce{N3-}$）大多是高能物质——$\ce{N2}$ 越稳定，生成它的反应越猛烈。

## 6 小结

- $\ce{N2}$ 三键键能 946 kJ/mol，是氮"惰性"的热力学根源；氮有 $-3$ 到 $+5$ 的完整氧化态谱系。
- 中间价态氮化合物能歧化与归中，$\ce{NO2}$ 溶于水歧化生成 $\ce{HNO3}$ 与 $\ce{NO}$。
- 氨是唯一常见弱碱，极易溶于水；铵盐受热分解、加碱放氨，是检验 $\ce{NH4+}$ 的依据。
- 硝酸具有强酸、强氧化、不稳定性；**越稀还原越狠**（浓硝酸得 $\ce{NO2}$、稀硝酸得 $\ce{NO}$）。
- 白磷自燃、红磷稳定、黑磷最稳定；磷肥需把不溶的磷酸钙转化为可溶的过磷酸钙。
- 合成氨是勒夏特列原理与速率学的折中：高温保速率、高压保转化率、催化剂保现实。
