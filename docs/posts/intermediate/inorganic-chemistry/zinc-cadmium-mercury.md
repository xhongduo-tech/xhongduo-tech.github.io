## 为什么从锌镉汞开始

锌、镉、汞（IIB 族）是第四周期 d 区的收尾，也是过渡金属与主族之间的"过渡"。它们的价电子构型 $(n-1)d^{10}ns^2$——**d 轨道全满**，这使它们不再是"典型过渡金属"：几乎没有变价（锌、镉只有 $+2$，汞有 $+1$ 与 $+2$）、离子无色、配合物无 d-d 跃迁颜色。但这一族的特色同样鲜明：**锌**是电化学与生命的双料明星（干电池负极、锌指蛋白、人体必需元素），**镉**是毒性金属的警示，**汞**是常温下唯一的液态金属、也是最著名的环境毒物。学完本章，你将理解"d$^{10}$ 意味着什么"，以及"元素周期表末端"如何用反常书写传奇。

## 1 锌：钢铁的守护者与电池的负极

**锌 $\ce{Zn}$**：$3d^{10}4s^2$，蓝白色金属，活泼性中等（比铁活泼）。**锌的化学核心是两个"牺牲"**：

**牺牲阳极（阴极保护）**：锌比铁活泼，当铁器镀锌或与锌连接时，锌先被氧化（牺牲自己），保护钢铁不被腐蚀——这是**镀锌铁皮（白铁皮）**、轮船船体牺牲阳极的原理。<span class="marginnote">镀锌铁皮划破后，露出的铁仍受保护：锌作负极被腐蚀，铁作正极被保护（$E^\ominus(\ce{Zn^2+/Zn}) = -0.76$ V < $E^\ominus(\ce{Fe^2+/Fe}) = -0.44$ V）。对比镀锡铁皮（马口铁）划破后铁反而加速生锈——锡比铁不活泼，铁成了被牺牲的负极。<strong>保护与否，看谁更活泼</strong>。</span>

**锌与酸碱反应**：锌是两性金属（同铝），既溶于酸又溶于强碱：

$$\ce{Zn + 2HCl -> ZnCl2 + H2 ^}, \qquad \ce{Zn + 2NaOH + 2H2O -> Na2[Zn(OH)4] + H2 ^}$$

**锌的化合物**：

- $\ce{ZnO}$（锌白）：两性氧化物，白色颜料、防晒霜成分（紫外线吸收）、橡胶添加剂。
- $\ce{ZnS}$：荧光材料（硫化锌加微量活化剂发光，夜光表盘、屏幕荧光粉）。
- $\ce{Zn^2+}$（$d^{10}$）无色，常形成四面体配合物 $\ce{[Zn(NH3)4]^2+}$、$\ce{[Zn(CN)4]^2-}$。

**锌在电化学**：**锌锰干电池**（勒克朗谢电池）负极为锌筒：$\ce{Zn -> Zn^2+ + 2e-}$；锌-空气电池、锌银电池都是经典体系（见《电化学与储能》）。

**锌在生命**：**锌是人体必需微量元素**（含量第二，仅次于铁），是 300 多种酶的辅因子——**锌指蛋白**是基因调控的经典结构（$\ce{Zn^2+}$ 配位在组氨酸/半胱氨酸之间"掐住"DNA），见《生物无机化学》与《分子生物学》。缺锌影响生长发育与免疫功能。

## 2 镉：工业重要、环境有害

**镉 $\ce{Cd}$**：$4d^{10}5s^2$，与锌性质相似但活泼性略低。镉的化合物以 $+2$ 为主：

- **$\ce{CdS}$**（镉黄）：黄色颜料、光电材料（硒化镉 $\ce{CdSe}$ 量子点）。
- **镍镉电池（$\ce{Ni-Cd}$）**：曾经的主流充电电池，有"记忆效应"，因镉的毒性正被镍氢、锂电取代。
- 镉在半导体（碲化镉 $\ce{CdTe}$ 薄膜太阳能电池）中的应用。<span class="marginnote">$\ce{CdTe}$ 薄膜太阳能电池是目前成本最低的薄膜光伏技术之一，但镉的毒性使废弃回收成为环保课题——"高效"与"安全"的权衡，在新能源材料中反复出现。</span>

**镉的毒性**：镉是**累积性毒物**，半衰期长达 10–30 年，主要损害肾脏与骨骼（"痛痛病"——日本富山镉污染导致骨软化病）。**镉的化学性质与锌相似，这使它能在体内"冒充"锌**——这是"化学相似性导致生物毒性"的经典案例，也是《生物无机化学》的警示：元素周期表上的邻居，在生命体里可能是"替身刺客"。

## 3 汞：液态金属的独特化学

**汞 $\ce{Hg}$**：$5d^{10}6s^2$，**常温下唯一的液态金属**（熔点 -38.8 °C）。汞的液态源于其特殊的相对论效应：6s 电子受相对论收缩、6s 惰性电子对效应极强，使 Hg–Hg 金属键弱、熔沸点低。<span class="marginnote">汞的液态是<strong>相对论效应</strong>的直接体现：6s 电子以接近光速的 60% 运动、轨道收缩、惰性对效应增强，削弱了金属键。汞因此"不肯"以强金属键凝结成固体——这是周期表里罕见的"相对论化学"案例，在《量子化学》与《结构化学》中会展开。</span>

**汞的两种氧化态**：$+1$（亚汞 $\ce{Hg2^2+}$，二聚离子）与 $+2$（汞）。

- $\ce{Hg2^2+}$：两个汞原子由一对共用电子连接（$\ce{Hg-Hg}$ 键），所以 $+1$ 价汞是"一对"，$\ce{Hg2Cl2}$（甘汞）中汞为 $+1$ 价但以二聚体形式存在。
- **$\ce{Hg^2+}$ 与 $\ce{Hg2^2+}$ 的平衡**：$\ce{Hg + Hg^2+ <=> Hg2^2+}$——汞单质能把 $\ce{Hg^2+}$ 还原为 $\ce{Hg2^2+}$。

**汞的化合物**：

- $\ce{HgS}$（朱砂/辰砂）：红色，最稳定的汞矿，炼丹术与朱红颜料的原料。
- $\ce{HgCl2}$（升汞）：剧毒，消毒剂；$\ce{Hg2Cl2}$（甘汞）：轻泻剂。
- 有机汞（甲基汞 $\ce{CH3Hg+}$）：**比无机汞毒性强得多**，是水俣病的元凶——工业汞排入水体后被微生物甲基化，沿食物链富集。

**汞的环境与安全**：汞是**全球性污染物**（可大气长距离迁移），"汞的排放与治理"是《环境科学与工程》的重要议题（《水俣公约》控制汞的全球使用）。**汞洒落处理**：不能直接擦，要用硫磺粉覆盖（$\ce{Hg + S -> HgS}$）或锌粉，防止汞蒸气吸入中毒。

## 4 d$^{10}$ 化学：为什么它们不是"典型过渡金属"

IIB 族被称为"准过渡金属"，因为 $d^{10}$ 全满的 d 壳层使它们丧失了过渡金属的三大特征：

| 特征 | 典型过渡金属 | 锌镉汞 |
| --- | --- | --- |
| 变价 | 多变（$d^{1-9}$） | 几乎仅 $+2$（汞还有 $+1$） |
| 离子颜色 | 有色（d-d 跃迁） | 无色（无 d 电子跃迁） |
| 配位 | 强、可变（晶体场效应） | 中等、四面体为主（$d^{10}$ 无晶体场稳定化能） |
| 催化 | 空 d 轨道催化 | 催化活性弱 |

**$d^{10}$ 无晶体场稳定化能（CFSE）**：晶体场劈裂对 $d^{10}$ 不产生净稳定化（全满轨道无论劈裂与否总能量相同），所以 $\ce{Zn^2+}$ 的配位几何主要由静电与空间因素决定——倾向四面体（配体少、斥力小）而非八面体。这为下一章《配位场理论与晶体场理论》埋下伏笔：**CFSE 是过渡金属配位化学的发动机，而 $d^{10}$ 恰好没有这台发动机**。

## 5 公式解析：汞的相对论惰性

汞的"液态 + 惰性电子对 + 亚汞二聚"可以用相对论效应统一解释，其量化核心是 6s 轨道的相对论收缩能：

$$
\Delta E_{\text{rel}} \approx -\frac{Z^4 \alpha^2}{2n^3} \cdot 13.6\ \text{eV}
$$

- $Z$：核电荷数。
- $\alpha \approx 1/137$：精细结构常数。
- $n = 6$：主量子数。

拆解三步：

- **第一步，看 $Z^4$ 放大**：相对论效应随核电荷的四次方增长，所以只在重元素（$Z$ 大）显著。汞 $Z = 80$，$\Delta E_{\text{rel}}$ 大到可观。
- **第二步，看 6s 收缩后果**：6s 轨道能量降低、半径收缩，6s 电子"抱紧"原子核——这就是**6s 惰性电子对效应**的量子根源。汞的 $+1$ 态（失去 6p 电子保留 6s² 对）因此异常稳定。
- **第三步，解释宏观性质**：6s 电子惰性 → 汞难失电子、金属键弱 → 熔点低（液态）、化学不活泼（只与强氧化剂反应）。**一束 6s 轨道的相对论收缩，解释了汞的全部"反常"。**

### 拓展：锌的冶金

锌的提取是无机冶金与电化学结合的范例：

- **焙烧**：闪锌矿 $\ce{ZnS}$ 在沸腾炉中氧化：$2\ce{ZnS + 3O2 -> 2ZnO + 2SO2}$（$\ce{SO2}$ 回收制硫酸）。
- **还原或电解**：
  - 火法（蒸馏法）：$\ce{ZnO + C -> Zn + CO}$，锌沸点低（907 °C），蒸馏收集——但能耗高、纯度一般。
  - 湿法（电解法）：$\ce{ZnO}$ 溶于稀硫酸得 $\ce{ZnSO4}$ 溶液，电解沉积得纯锌：$2\ce{ZnSO4 + 2H2O -> 2Zn + O2 + 2H2SO4}$——阴极析锌、阳极放氧，电解液循环使用。
- **用途链条**：镀锌（白铁皮）、锌合金（压铸件）、锌锰干电池负极、牺牲阳极（海水设施）、锌在人体（锌指蛋白，见《生物无机化学》）。

**亮点**：湿法炼锌把"冶金"与"电化学"合而为一——电解既提纯金属又循环酸液，是无机化学"过程工业"的缩影。

## 6 小结

- 锌 $3d^{10}4s^2$，比铁活泼，能牺牲阳极保护钢铁（镀锌铁皮）；也是两性金属。
- 锌是 300 多种酶的辅因子，锌指蛋白是基因调控经典结构；$\ce{ZnS}$ 是荧光材料。
- 镉与锌化学相似故能在体内"冒充"锌，是累积性毒物（痛痛病、镍镉电池的环保问题）。
- 汞是常温唯一液态金属，源于 6s 相对论收缩；有 $\ce{Hg2^2+}$（$+1$ 二聚）与 $\ce{Hg^2+}$ 两种价态。
- 甲基汞毒性极强，水俣病是环境化学的警钟；汞洒落要用硫磺处理。
- $d^{10}$ 无 CFSE，使锌镉汞丧失过渡金属的变价、颜色、催化特征，是"准过渡金属"。
