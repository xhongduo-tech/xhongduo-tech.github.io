## 为什么从碳族开始

碳族元素（第 IVA 族：$\ce{C, Si, Ge, Sn, Pb}$）是周期表里"性格最分裂"的一族：碳是非金属，硅是准金属（半导体），锡和铅是金属。这一族与人类文明绑定最深——**碳**是有机化学与生命的基础（在《有机化学》专题中全面展开），**硅**是芯片与信息时代的地基，**锡与铅**伴随了青铜时代与工业时代的铅酸电池。本章站在无机化学的角度看碳的"另一半"（碳的氧化物、碳酸盐、碳化物）与硅的庞大矿物化学，理解"同族元素从非金属到金属的过渡"如何在碳族身上淋漓尽致地呈现。学完本章，你将对第四周期以后的"惰性电子对效应"建立第一个直观印象。

## 1 碳：同素异形体的展览馆

碳有丰富的**同素异形体**，它们结构不同、命运迥异：

- **金刚石**：$sp^3$ 杂化，每个 C 与 4 个 C 成键，三维骨架。最硬的天然物质，不导电，透明。
- **石墨**：$sp^2$ 杂化，层状结构，层内六元环、层间范德华力。软、导电、润滑——铅笔、电极、润滑剂。
- **富勒烯 $\ce{C60}$**（足球烯）：笼状分子，60 个碳组成二十面体，1996 年诺贝尔化学奖。
- **碳纳米管**：石墨层卷成圆柱，强度极高、导电性好。
- **石墨烯**：单层石墨，2010 年诺贝尔物理学奖。强度是钢的百倍，导电性极佳。

**辨析｜易错点：** 金刚石与石墨同为碳单质，但熔点、硬度、导电性天差地别——**结构决定性质**。金刚石的熔点比石墨略高（都是极高），但石墨在层内导电、层间绝缘，是**各向异性**导体。判断同素异形体性质时，先想它的晶体结构（见《晶体结构》）。

碳的化合物中，**碳的氧化物**是无机化学的主角：

- **一氧化碳 $\ce{CO}$**：无色无味、剧毒，与血红蛋白结合力比氧强约 200 倍，导致缺氧窒息。是冶金还原剂（$\ce{Fe2O3 + 3CO -> 2Fe + 3CO2}$），燃料（水煤气含 $\ce{CO}$）。
- **二氧化碳 $\ce{CO2}$**：温室气体，固体干冰升华吸热作制冷剂，工业上合成尿素、纯碱。<span class="marginnote">$\ce{CO}$ 中碳的氧化数是 $+2$（中间价态），所以它既有还原性（被氧化成 $\ce{CO2}$）又有氧化性（与 $\ce{H2}$ 反应生成甲醇）。<strong>低价态的氧化物往往自带还原性</strong>，这条规律贯穿 p 区元素化学。</span>

**碳酸与碳酸盐**：$\ce{H2CO3}$ 是弱酸，只存在于稀溶液（$\ce{CO2}$ 溶于水）。碳酸盐中碱金属盐易溶，其他大多难溶。碳酸盐与酸反应放出 $\ce{CO2}$（检验：通入澄清石灰水变浑浊）——这是《分析化学》鉴定 $\ce{CO3^2-}$ 的基本方法。

## 2 硅：地壳的骨骼、芯片的灵魂

**硅 $\ce{Si}$** 是地壳中含量第二的元素（约 27%，仅次于氧），以二氧化硅与硅酸盐的形式存在。单质硅是**半导体**——电导率介于金属与绝缘体之间，且随温度升高而增大（与金属相反）。

**二氧化硅 $\ce{SiO2}$**：原子晶体，每个 Si 与 4 个 O、每个 O 与 2 个 Si 相连，形成三维骨架。天然存在为石英、水晶、玛瑙。用途：光导纤维、石英玻璃、制硅的原料。<span class="marginnote">$\ce{SiO2}$ 与 $\ce{CO2}$ 结构截然不同：$\ce{CO2}$ 是直线形小分子气体，$\ce{SiO2}$ 是原子晶体固体。原因：碳半径小能形成稳定的 $\ce{C=O}$ 双键，而硅半径大、$3p$ 轨道重叠差，倾向单键连接成网。<strong>第二周期元素的双键能力强于第三周期</strong>，这是 p 区化学的重要规律。</span>

**硅酸盐**：地壳的主体，如长石、云母、黏土。硅酸盐结构的基础是**硅氧四面体 $\ce{SiO4^4-}$**，它们可以共顶点连接成岛状、链状、层状、骨架状结构——这是《晶体结构》的又一应用。

**硅的制备**：$\ce{SiO2 + 2C -> Si + 2CO}$（粗硅），再经 $\ce{SiCl4}$ 精馏、$\ce{H2}$ 还原制得高纯硅。高纯硅是芯片的原料——从沙子到芯片，碳族化学支撑了信息时代。<span class="marginnote">硅与碳同族，但$\ce{SiO2}$ 是原子晶体（熔点 1650 °C），$\ce{CO2}$ 是分子晶体（升华点 -78 °C）——<strong>同族氧化物的结构可以天差地别</strong>。这也是"硅基生命"设想的化学障碍：硅不能形成像碳那样的链状骨架与双键。</span>

**硅的"异常"亲氧性**：$\ce{Si-H}$ 键远不如 $\ce{C-H}$ 稳定，硅烷 $\ce{SiH4}$ 在空气中自燃；而 $\ce{Si-O}$ 键极强。所以自然界硅全部以氧化物/硅酸盐存在，没有像碳那样的有机硅"生命化学"。

## 3 锡与铅：惰性电子对效应

$\ce{Sn}$ 与 $\ce{Pb}$ 是碳族最下方的两个金属元素，它们共同展现了 p 区下部的**惰性电子对效应（inert pair effect）**：$ns^2$ 电子对不易参与成键，导致：

- 第 IVA 族元素有 $+4$ 与 $+2$ 两种氧化态，向下 **$+2$ 态越来越稳定**。$\ce{Sn^2+}$ 是还原剂（易被氧化为 $\ce{Sn^4+}$），$\ce{Pb^2+}$ 却稳定（$\ce{Pb^4+}$ 氧化性强、不稳定）。
- 碳、硅几乎只有 $+4$ 态，锗有 $+2$、$+4$，锡、铅以 $+2$、$+4$ 并存且 $+2$ 向下增强。

**锡 $\ce{Sn}$**：银白色金属，熔点低。用途：镀锡铁皮（马口铁）、焊锡（锡铅合金）、青铜（铜锡合金，人类第一个合金时代）。**白锡**在低温（<13 °C）会转变成粉末状的**灰锡**——"锡疫"曾毁掉过拿破仑军服的锡扣。

**铅 $\ce{Pb}$**：密度大（11.34 g/cm³）、耐腐蚀。用途：铅酸电池（$\ce{Pb}$ 与 $\ce{PbO2}$ 作电极）、防辐射屏蔽、铅字合金。铅及其化合物**有毒**——铅中毒损伤神经系统，含铅汽油已被淘汰。<span class="marginnote">$\ce{Pb(NO3)2}$、$\ce{Pb(CH3COO)2}$ 可溶，多数铅盐难溶（$\ce{PbSO4}$、$\ce{PbCrO4}$）。铅的毒性使"无铅化"（无铅焊料、无铅汽油）成为现代工业标准——化学进步的同时也在为过去的"方便"还债。</span>

**铅酸电池**：

$$\ce{Pb + PbO2 + 2H2SO4 \rightleftharpoons 2PbSO4 + 2H2O}$$

放电时负极 $\ce{Pb}$ 氧化、正极 $\ce{PbO2}$ 还原，两极都生成 $\ce{PbSO4}$（可逆沉淀），充电时逆向进行。这是最经典的**可充电电池**，汽车蓄电池至今仍用它——无机化学在储能中的开篇，详见《电化学与储能》专题。

## 4 碳化硅与碳化物

**碳化硅 $\ce{SiC}$**（金刚砂）：$\ce{SiO2 + 3C \xrightarrow{\text{高温}} SiC + 2CO}$，硬度仅次于金刚石，作磨料、高温耐火材料。$\ce{SiC}$ 与金刚石同构（都是四面体骨架），但 Si–C 键稍弱。

**金属碳化物**：碳与金属（如 $\ce{Ca}$、$\ce{Al}$）高温生成，如电石 $\ce{CaC2}$（$\ce{CaC2 + 2H2O -> C2H2 + Ca(OH)2}$，是乙炔气焊气的来源）、碳化钨 $\ce{WC}$（硬质合金，刀具）。

## 5 公式解析：铅酸电池的电动势

铅酸电池的化学反应涉及 $\ce{Pb}$ 的 $+2/+4$ 氧化态与 $\ce{SO4^2-}$ 的沉淀平衡，其电动势可从标准电极电势与能斯特方程推算。

放电总反应与半反应：

$$
\ce{Pb + PbO2 + 4H+ + 2SO4^2- -> 2PbSO4 + 2H2O}
$$

负极（氧化）：$\ce{Pb + SO4^2- -> PbSO4 + 2e-}$，$E^\ominus = -0.36$ V；
正极（还原）：$\ce{PbO2 + SO4^2- + 4H+ + 2e- -> PbSO4 + 2H2O}$，$E^\ominus = +1.69$ V。

拆解三步：

- **第一步，算标准电动势**：$\Delta E^\ominus = 1.69 - (-0.36) = 2.05$ V——铅酸电池单格电压约 2 V，6 格串联成 12 V 汽车电瓶。
- **第二步，看能斯特修正**：电动势与 $[\ce{H+}]$ 有关：$E \propto E^\ominus - \frac{0.0592}{2}\lg\frac{1}{[\ce{H+}]^4[\ce{SO4^2-}]^2}$。放电时硫酸被消耗，$[\ce{H+}]$ 下降，电动势随之下降——**测电压/比重就能判断电量**，这就是铅酸电池"看硫酸浓度知电量"的原理。
- **第三步，看可逆性**：充电时反应逆向，$\ce{PbSO4}$ 重新转化为 $\ce{Pb}$ 与 $\ce{PbO2}$。**沉淀的生成与溶解是铅酸电池可逆循环的化学枢纽**——它的可充放性本质上来自 $\ce{PbSO4}$ 的可逆沉淀平衡。

### 拓展：碳捕集、利用与封存（CCUS）

碳族化学在碳中和时代的核心应用是碳捕集利用与封存：

- **胺法吸收**：有机胺（如乙醇胺）溶液吸收 $\ce{CO2}$ 生成氨基甲酸盐，加热解析 $\ce{CO2}$——捕集电厂烟气 $\ce{CO2}$ 的主流化学路线。
- **钙循环（钙基吸附剂）**：$\ce{CaO + CO2 <=> CaCO3}$ 的循环——高温吸附、高温再生（《碱土金属》的石灰循环在碳中和中重生）。
- **$\ce{CO2}$ 加氢利用**：$\ce{CO2 + 3H2 -> CH3OH + H2O}$（合成甲醇）、$\ce{CO2 + 4H2 -> CH4 + 2H2O}$（甲烷化，萨巴蒂埃反应）——把 $\ce{CO2}$ 变成燃料与化工原料。
- **干重整**：$\ce{CH4 + CO2 -> 2CO + 2H2}$，把两种温室气体一并转化为合成气。

**化学视角**：$\ce{CO2}$ 中碳是 $+4$ 价（最高氧化态），利用 $\ce{CO2}$ 必须把它**还原**——催化剂（铜基、镍基）是让碳"走下氧化数阶梯"的推手。碳循环的化学本质，是让碳在 $-4$ 与 $+4$ 之间循环往返。

### 拓展：石墨与石墨烯的结构细节

石墨层内 $\ce{C-C}$ 键长 1.42 Å（比金刚石 1.54 Å 短，有部分双键成分），层间距 3.35 Å（范德华力）。石墨导电沿层内方向（平面内），垂直方向差——各向异性。石墨烯（2010 年诺贝尔物理学奖）是单层石墨，强度理论值约 130 GPa（钢的百倍）、载流子迁移率极高，是"二维材料"的开端；碳纳米管可视为石墨烯卷成的圆柱。

### 拓展：碳的"氧化还原"主线

把碳族各章串起来的一条主线是碳的氧化数阶梯：

- $-4$：甲烷 $\ce{CH4}$（燃料）→ $0$：金刚石/石墨/$\ce{CO}$ 中碳（$\ce{CO}$ 为 $+2$）→ $+2$：$\ce{CO}$ → $+4$：$\ce{CO2}$、碳酸盐。
- $\ce{CO}$（$+2$）介于中间，既是还原剂（炼铁）又能在特定条件下被还原（$\ce{CO + H2 -> CH3OH}$）。
- **"碳的氧化还原阶梯"对应着能源化学**：燃烧（$-4 \to +4$）放出能量；$\ce{CO2}$ 还原（$+4 \to$ 低碳）需要输入能量——碳的每一级升降，都是能量与化学的换算。

**一句话**：从天然气到钻石再到 $\ce{CO2}$，碳的氧化态贯穿能源、材料与气候——这是整个碳族化学的隐形骨架。

## 6 小结

- 碳的同素异形体（金刚石、石墨、富勒烯、碳纳米管、石墨烯）结构不同、性质迥异，**结构决定性质**。
- $\ce{CO}$ 剧毒但也是冶金还原剂；$\ce{CO2}$ 是温室气体与化工原料。
- 硅是半导体，$\ce{SiO2}$ 是原子晶体（与分子晶体 $\ce{CO2}$ 截然不同），硅酸盐以硅氧四面体为基元。
- 硅不能像碳那样形成稳定双键与长链，硅烷自燃而硅酸盐极稳定。
- **惰性电子对效应**使第 IVA 族向下 $+2$ 态更稳定：$\ce{Sn^2+}$ 还原性强，$\ce{Pb^2+}$ 稳定。
- 铅酸电池靠 $\ce{Pb/PbO2}$ 与 $\ce{PbSO4}$ 的可逆沉淀实现充放电，是经典可充电电池。
