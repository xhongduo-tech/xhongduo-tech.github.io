## 为什么从晶体场理论开始

《配合物基础》与《配位化学：结构与异构》告诉我们配合物"是什么样"，这一章要解释配合物"为什么这样"——**为什么 $\ce{[Ti(H2O)6]^3+}$ 是紫色？为什么 $\ce{[Fe(CN)6]^4-}$ 无磁性而 $\ce{[Fe(H2O)6]^2+}$ 有磁性？为什么强场配体让 $\ce{Ni^2+}$ 从四面体变平面正方形？** 答案都藏在**晶体场理论（CFT, Crystal Field Theory）** 里。这个理论极其简单：配体是"负电荷点"，它们靠近中心离子时，d 轨道的能量不再相等，**劈裂（splitting）** 成两组——这个劈裂能量差 $\Delta$ 决定了配合物的颜色、磁性、几何与稳定性。学完本章，"配合物的颜色和磁性"将不再是背诵，而是可计算的推断；下一章《配合物的反应与稳定性》将在此基础上的动力学与热力学故事。

## 1 八面体场中的 d 轨道劈裂

五个 d 轨道形状不同，空间取向也不同：$d_{x^2-y^2}$ 与 $d_{z^2}$ 的电子云沿**坐标轴**方向伸展，$d_{xy}, d_{xz}, d_{yz}$ 沿坐标轴**之间**（45°）方向伸展。

在**八面体配合物**中，六个配体从 $\pm x, \pm y, \pm z$ 六个方向靠近中心离子：

- 沿轴方向的 $d_{x^2-y^2}$、$d_{z^2}$ 与配体**正对**，电子云被强烈排斥 → 能量升高。
- 轴间方向的 $d_{xy}, d_{xz}, d_{yz}$ 避开配体，受排斥小 → 能量较低。

于是五重简并的 d 轨道劈裂成两组：

- 能量较高的两组：$e_g$（$d_{x^2-y^2}, d_{z^2}$，二重简并）。
- 能量较低的三组：$t_{2g}$（$d_{xy}, d_{xz}, d_{yz}$，三重简并）。

**劈裂能** $\Delta_o$（八面体场）就是 $e_g$ 与 $t_{2g}$ 的能量差。按"重心不变"原则（所有 d 电子总能量在劈裂前后不变），$e_g$ 比重心高 $+3/5\Delta_o$，$t_{2g}$ 比重心低 $-2/5\Delta_o$。<span class="marginnote">"重心不变"是晶体场理论的记账规则：劈裂只是重新分配能量，5 个 d 轨道的平均能量保持不变。$e_g$ 上移 $\frac{3}{5}\Delta_o$、$t_{2g}$ 下移 $\frac{2}{5}\Delta_o$，总量恰好守恒——这保证理论的能量计算前后自洽。</span>

## 2 晶体场稳定化能（CFSE）

d 电子填充进劈裂后的轨道，比在"未劈裂的球形场"中多出来的稳定化能量称为**晶体场稳定化能（CFSE, Crystal Field Stabilization Energy）**：

$$
\text{CFSE} = \left(-\frac{2}{5}\Delta_o\right) n_{t_{2g}} + \left(+\frac{3}{5}\Delta_o\right) n_{e_g} + P(\text{成对能修正})
$$

- $n_{t_{2g}}, n_{e_g}$：分别填入 $t_{2g}$ 与 $e_g$ 的电子数。
- $P$：电子成对所需额外能量（克服洪特规则的自旋配对代价）。

**高自旋与低自旋**：$d^4$–$d^7$ 的电子有两种填充方式，由 $\Delta_o$ 与 $P$ 的相对大小决定：

- **$\Delta_o > P$（强场配体，如 $\ce{CN-}$、$\ce{CO}$）**：电子先填满 $t_{2g}$ 再进 $e_g$，成对多、自旋少 → **低自旋（low spin）**。
- **$\Delta_o < P$（弱场配体，如 $\ce{H2O}$、$\ce{F-}$、$\ce{Cl-}$）**：电子按洪特规则尽量分散 → **高自旋（high spin）**。

$d^5$ 的例子：弱场 $\ce{[Fe(H2O)6]^3+}$ 高自旋（5 个单电子，磁性最强），强场 $\ce{[Fe(CN)6]^3-}$ 低自旋（1 个单电子，磁性弱）。**磁性由此而来**：未成对电子数 = 磁矩的决定因素。配合物的颜色也由 $\Delta_o$ 决定：电子吸收能量 $\Delta_o$ 的光子从 $t_{2g}$ 跃迁到 $e_g$（d-d 跃迁），吸收的补色就是配合物颜色（见《过渡金属通性》）。

## 3 光谱化学序列与配体场强度

不同配体造成的劈裂能 $\Delta$ 不同，按 $\Delta$ 从小到大的顺序排列就是**光谱化学序列（spectrochemical series）**：

$$\ce{I- < Br- < Cl- < F- < OH- < H2O < NCS- < NH3 < en < CN- < CO}$$

- 左端（$\ce{I-}$、$\ce{Br-}$、$\ce{Cl-}$）是**弱场配体**，$\Delta$ 小 → 高自旋。
- 右端（$\ce{CN-}$、$\ce{CO}$）是**强场配体**，$\Delta$ 大 → 低自旋。
- $\ce{H2O}$ 与 $\ce{F-}$ 交界附近属中等。

**为什么配体强弱不同？** 晶体场理论把配体当纯负电荷点，解释不了光谱化学序列的细节；**配位场理论（LFT）/分子轨道理论**补上共价成分：强场配体（$\ce{CN-}$、$\ce{CO}$）既有 σ 给电子又有 **π 反馈键**（金属 d 电子反馈给配体的空 π 轨道），进一步加大劈裂。<span class="marginnote">$\ce{CO}$ 是"π 酸配体"：它既给孤对电子给金属（σ 配位），又接受金属 d 电子的反馈（π 反馈）。反馈键使 M–CO 键更强、$\Delta$ 更大——这解释了为什么 $\ce{CO}$ 在光谱化学序列最右端，也预告了《配合物的反应与稳定性》中的"反位效应"。</span>

## 4 四面体场与平面正方形场

**四面体场**：四个配体占据立方体对角顶点，不与任何 d 轨道正对。劈裂方向与八面体相反且小得多：

$$t_2 \ (d_{xy}, d_{xz}, d_{yz}) \ \text{高}, \qquad e \ (d_{x^2-y^2}, d_{z^2}) \ \text{低}$$

$$\Delta_t \approx \frac{4}{9}\Delta_o$$

四面体场劈裂能只有八面体的约 4/9，且 $t_2$ 高、$e$ 低（与八面体场相反）。因为 $\Delta_t$ 小，四面体配合物几乎**全部高自旋**——这就是 $d^{10}$ 的 $\ce{Zn^2+}$、$\ce{Cd^2+}$ 总是四面体且无色的原因（$d^{10}$ 任何场都无 CFSE）。

**平面正方形场**：可以看作"八面体沿 z 轴拉长"直至两个 z 配体移走。劈裂后最高轨道是 $d_{x^2-y^2}$，$d^8$ 金属（$\ce{Pt^2+}$、$\ce{Ni^2+}$ 强场）电子全部配对填在低能轨道，只留 $d_{x^2-y^2}$ 空——**$d^8$ 平面正方形的稳定性正来自这种"强场低自旋"的特别收益**。<span class="marginnote">$d^8$ 在平面正方形场中的 CFSE 特别大（相比八面体场多约 1.2$\Delta_o$），所以 $\ce{Pt^2+}$、$\ce{Au^3+}$ 的 4 配位配合物几乎总是平面正方形（顺铂、$\ce{[AuCl4]-}$）。强场 + $d^8$ = 平面正方形——这是《配位化学：结构与异构》里"墙头草 $\ce{Ni^2+}$"的定量答案。</span>

## 5 公式解析：磁矩与未成对电子数

晶体场理论最实用的产出之一：由磁矩推断配合物的电子构型。磁矩公式（只考虑自旋）：

$$
\mu = \sqrt{n(n+2)} \ \text{BM}
$$

- $\mu$：磁矩（玻尔磁子 BM）。
- $n$：未成对电子数。

拆解三步：

- **第一步，测磁矩**：实验测得配合物的 $\mu$。
- **第二步，反推 $n$**：代入公式解出未成对电子数。例如 $\mu = 4.90$ BM → $\sqrt{n(n+2)} = 4.90$ → $n = 4$。
- **第三步，判断高/低自旋**：$d^6$ 配合物若 $n = 4$ → 高自旋（$\ce{[Fe(H2O)6]^2+}$）；若 $n = 0$（$\mu = 0$）→ 低自旋（$\ce{[Fe(CN)6]^4-}$）。**磁性测量是判断配位场强弱与电子构型的实验钥匙**。

顺磁性（有未成对电子）与反磁性（无未成对电子）由此区分：$\ce{O2}$ 的顺磁性是分子轨道理论的地标（见《分子结构与VSEPR》），配合物的磁性则是晶体场理论的地标——两套理论在"磁性"上殊途同归。

### 拓展：Jahn–Teller 效应与八面体畸变

晶体场理论的又一天花板是解释"为什么有些八面体配合物不是正八面体"：

- **Jahn–Teller 定理**：非线性分子若电子构型存在简并态（如 $d^9$ 的 $\ce{Cu^2+}$），必然发生畸变以消除简并、降低能量。
- **$d^9$ 的 $\ce{Cu^2+}$**：八面体中 $e_g$ 轨道有一个电子（$d_{x^2-y^2}$ 或 $d_{z^2}$ 占据不均），配体沿 z 轴拉长形成"拉长八面体"，赤道四个 $\ce{Cu-L}$ 键缩短、轴向两键拉长——$\ce{[Cu(H2O)6]^2+}$ 实际是拉长八面体。
- **宏观后果**：$\ce{Cu^2+}$ 配合物的光谱出现宽化吸收带；$\ce{CuCl2}$、$\ce{CuF2}$ 的层状结构也是 Jahn–Teller 畸变的结果；$\ce{Mn^3+}$（$d^4$）同样显著畸变。
- **Jahn–Teller 活性构型**：高自旋 $d^4$、$d^7$ 与低自旋 $d^7$、$d^9$ 都倾向畸变。

**启示**：配合物"理想几何"是教材模型，真实结构总是能量最低的妥协——Jahn–Teller 效应提醒我们：**对称性破缺本身就是化学的一部分**。

### 拓展：配合物颜色的"补色"判读

配合物吸收 $\Delta_o$ 对应的光子，显示的是**补色**：$\ce{[Ti(H2O)6]^3+}$ 吸收绿黄光（约 500 nm），显示紫红色；$\ce{[Cu(H2O)4]^2+}$ 吸收红光（约 800 nm 附近宽吸收），显示蓝色。**颜色 = 吸收的补色**——记光谱色序（红橙黄绿蓝紫），吸收哪一段就看相对的那一段。

## 6 小结

- 八面体场中 d 轨道劈裂为 $e_g$（高）与 $t_{2g}$（低），劈裂能 $\Delta_o$ 由配体决定。
- **CFSE** 是 d 电子填入劈裂轨道的净稳定化能，$\Delta_o$ 与成对能 $P$ 的相对大小决定高/低自旋。
- 强场配体（$\ce{CN-}$、$\ce{CO}$）低自旋，弱场配体（$\ce{I-}$、$\ce{Br-}$、$\ce{H2O}$）高自旋；光谱化学序列排序配体场强度。
- 配合物颜色来自 d-d 跃迁（吸收 $\Delta$ 光子），磁性来自未成对电子数。
- 四面体场 $\Delta_t \approx 4/9\Delta_o$、几乎全高自旋；平面正方形场特别稳定 $d^8$ 强场配合物。
- 磁矩公式 $\mu = \sqrt{n(n+2)}$ 把实验磁性与电子构型相连。
