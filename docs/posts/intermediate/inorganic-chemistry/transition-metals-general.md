## 为什么从过渡金属开始

完成了 s 区与 p 区（第二篇），我们进入周期表的中部——**d 区过渡金属**。这些元素（第 3–12 族，价电子 $(n-1)d^{1-10}ns^{1-2}$）占据了周期表的主体，也是现代文明的材料与催化核心：铁让桥梁站立、铜让电流奔跑、钛让人飞上天、铂让汽车尾气变干净。过渡金属与主族金属的化学有根本区别——它们**多变价、有颜色、易配位、善催化**，这四大天赋全部源于 d 电子。本章是第三篇的"总纲"：先建立过渡金属通性的全景，后续各章再逐一展开铁系、钛钒铬锰、铜银金、锌镉汞。学完本章，你将理解 d 区化学与 p 区化学的"新语法"。

## 1 过渡金属的电子构型与"三同一"

过渡金属的价电子 $(n-1)d^{1-10}ns^{1-2}$（钯例外，$4d^{10}$）。它们的共同特征可概括为"三同一"：

- **同周期 d 轨道逐步填充**：从 $\ce{Sc}$（$3d^1$）到 $\ce{Zn}$（$3d^{10}$），原子半径变化很小（镧系收缩类似，但 d 区收缩幅度小）。
- **同一族纵向相似**：第四、五周期差异大，第五、六周期因**镧系收缩**高度相似（$\ce{Zr/Hf}$、$\ce{Nb/Ta}$、$\ce{Mo/W}$ 半径几乎相同、化学难分）。
- **同一元素多种氧化态**：过渡金属普遍有多种价态，且相邻价态间变化平缓（差 1）。

**多氧化态的根源**：$(n-1)d$ 与 $ns$ 轨道能量接近，失去不同数目电子所需的能量差异不大。例如 $\ce{Mn}$ 有 $+2, +3, +4, +6, +7$ 等全部常见价态。<span class="marginnote">对比主族：主族元素氧化态要么固定（$\ce{Na}$ 只有 $+1$）要么跳变（$\ce{Sn}$ 的 $+2/+4$、$\ce{Tl}$ 的 $+1/+3$，惰性电子对）。过渡金属却是一架"连续价态电梯"——这正是 d 电子参与成键的直接后果。</span>

**最高氧化态规律**：IIIB–VIIB 族最高氧化态 = 族序数（$\ce{Mn}$ +7），到 VIII 族（$\ce{Fe, Co, Ni}$）后下降（$\ce{Fe}$ 最高 +6、$\ce{Co}$ +4、$\ce{Ni}$ +4），IB（$\ce{Cu}$ +3）、IIB（$\ce{Zn}$ +2）更低——最高价态呈"山形"：**中部最高、两端降低**。

## 2 四大天赋之一：变价与氧化还原

过渡金属的多种氧化态使它们成为**氧化还原反应的多面手**。判断一个过渡金属离子能否发生氧化还原，看两个标准：

- 中间价态（如 $\ce{Fe^2+}$、$\ce{Cr^3+}$）既能被氧化又能被还原。
- 最高价态（如 $\ce{Cr2O7^2-}$ 中 $\ce{Cr}$ +6、$\ce{MnO4-}$ 中 $\ce{Mn}$ +7）只作氧化剂；最低价态只作还原剂。

**氧化性的周期规律**：同一过渡金属的高价态氧阴离子（$\ce{MnO4-}$、$\ce{Cr2O7^2-}$）都是强氧化剂，其氧化性随 pH 改变（酸性增强）。$\ce{KMnO4}$ 与 $\ce{K2Cr2O7}$ 是《分析化学》的两种经典氧化还原滴定剂。

## 3 四大天赋之二：离子的颜色

过渡金属离子大多**有颜色**，而主族金属离子（$\ce{Na+}$、$\ce{K+}$、$\ce{Ca^2+}$）无色。颜色的根源是 **d-d 跃迁**：d 轨道在配体场中劈裂（见《配位场理论与晶体场理论》），电子在劈裂的 d 轨道之间跃迁吸收可见光，补色光透出。

| 水合离子 | 颜色 | 电子构型 |
| --- | --- | --- |
| $\ce{Ti^3+}$ | 紫红 | $d^1$ |
| $\ce{V^3+}$ | 绿 | $d^2$ |
| $\ce{Cr^3+}$ | 紫/绿 | $d^3$ |
| $\ce{Mn^2+}$ | 浅粉 | $d^5$ |
| $\ce{Fe^3+}$ | 黄/浅紫 | $d^5$ |
| $\ce{Co^2+}$ | 粉红 | $d^7$ |
| $\ce{Ni^2+}$ | 绿 | $d^8$ |
| $\ce{Cu^2+}$ | 蓝 | $d^9$ |
| $\ce{Zn^2+}$ | 无色 | $d^{10}$ |

**辨析｜易错点：** $d^0$（$\ce{Ti^4+}$、$\ce{Sc^3+}$）与 $d^{10}$（$\ce{Zn^2+}$、$\ce{Cu+}$、$\ce{Ag+}$）的离子**无色**——因为没有可跃迁的 d 电子（$d^0$ 无电子可跃迁，$d^{10}$ 轨道全满无可跃迁的空轨道）。但 $\ce{Cu+}$ 与 $\ce{Ag+}$ 的化合物可有颜色（如 $\ce{Cu2O}$ 砖红），那是电荷转移跃迁而非 d-d 跃迁。<span class="marginnote">"无色"判据：$d^0$ 与 $d^{10}$ 无色，其余大多有色。这解释了为何 $\ce{CuSO4}$ 溶液是蓝色而 $\ce{ZnSO4}$ 溶液无色——一个 $d^9$、一个 $d^{10}$，命运的差距只差一个 d 电子。</span>

## 4 四大天赋之三：配位能力

过渡金属是最强的**配位中心**：它们电荷高、半径小、d 轨道与配体轨道能量匹配，极易与配体形成配合物（见《配合物基础》）。这带来三个重要后果：

- 过渡金属离子在水溶液中大多以**水合离子**存在（$\ce{[Cu(H2O)4]^2+}$），颜色即水合离子的颜色。
- 过渡金属能形成**多种氧化态 + 多种配位数 + 多种几何**的配合物，是配位化学的主角。
- 过渡金属配合物与**晶体场/配位场理论**紧密相连（下一章），颜色、磁性、稳定性都由 d 轨道与配体场的相互作用决定。

**配位数**常见 4（四面体/平面正方形）与 6（八面体），与主族 VSEPR 的预测不同——d 区中心离子用晶体场理论解释更可靠。

## 5 四大天赋之四：催化性能

过渡金属及其化合物是**工业催化的绝对主力**，因为：

- 具有空的 d 轨道与可变的 d 电子数，能**吸附反应物**、临时成键、降低活化能。
- 多种氧化态使它们能**交替得失电子**，充当电子转移的"中转站"。

经典案例：

- **铁**：合成氨的催化剂（$\ce{N2 + 3H2 -> 2NH3}$，见《氮族元素》）。
- **钒**：接触法制硫酸的催化剂（$\ce{V2O5}$，$\ce{SO2}$ 氧化）。
- **铂**：汽车尾气三元催化（CO、碳氢、$\ce{NO_x}$ 净化）。
- **钯/镍**：加氢反应催化剂（$\ce{Pd/C}$、雷尼镍）。
- **锰/钴**：催化氧化反应。

催化剂的高选择性让过渡金属成为**手性合成、药物制造**的基石——详见《无机化学在能源与催化中的应用》。<span class="marginnote">过渡金属催化的统一机制：反应物吸附在金属表面或与金属中心配位，d 电子轨道与反应物轨道重叠，把反应从"高能垒一步"变成"低能垒多步"。酶的金属活性中心（血红素铁、维生素 $\ce{B12}$ 钴）是同一原理的生物学版本，见《生物无机化学》。</span>

## 6 公式解析：d 电子计数与最高氧化态

过渡金属化学的第一个基本功是**数 d 电子**，用配位化学里的标准公式：

$$
d^n = Z - (\text{氧化态}) - (\text{s 电子数})
$$

对中性原子（氧化态 0），价电子构型 $(n-1)d^x ns^y$ 的 d 电子数就是 $x$。对离子：

- $\ce{Fe^3+}$：$\ce{Fe}$ 价电子 $3d^64s^2$，失 3 个电子先失 $4s^2$ 再失一个 $3d$ → $d^5$。
- $\ce{Mn^2+}$：$3d^54s^2$ 失 2 → $d^5$。
- $\ce{Cu^2+}$：$3d^{10}4s^1$ 失 2 → 先失 $4s^1$ 再失一个 $3d$ → $d^9$。

拆解三步：

- **第一步，先失 $ns$ 后失 $(n-1)d$**：电离时外层 $ns$ 电子先失（与《原子结构》中"失去顺序与填充顺序相反"一致）。
- **第二步，数剩余 d 电子**：$d^n$ 直接决定颜色、磁性（未成对 d 电子数）与晶体场性质。
- **第三步，算最高氧化态**：过渡金属最高正价 = 全部 $ns$ + $(n-1)d$ 电子数（对 IIIB–VIIB）。$\ce{Mn}$：$4s^2 + 3d^5 = 7$ → $\ce{KMnO4}$ 中 +7。$\ce{Cr}$：$4s^1 + 3d^5 = 6$ → $\ce{Cr2O7^2-}$ 中 +6。

**$d^n$ 计数是配位化学一切讨论的起点**——下一章晶体场理论的"$d^1$、$d^5$、$d^9$"全都从这里来。

### 拓展：过渡金属与配位饱和

"配位饱和"提醒我们：过渡金属离子的最高配位数受 d 轨道与空间限制——第一过渡系常见 6，第二、三过渡系可达 8（$\ce{[Mo(CN)8]^4-}$）；而低配位数（2、3）只出现在 $d^{10}$（$\ce{Ag+}$、$\ce{Au+}$）等"软而大"的中心。配位数本身就是电子结构（CFSE）与空间位阻的折中——具体判据见《配位场理论与晶体场理论》。

## 7 小结

- 过渡金属价电子 $(n-1)d^{1-10}ns^{1-2}$，同一族纵向因镧系收缩而高度相似。
- **多氧化态**：相邻价态差 1，最高氧化态呈"山形"（VIIB 族 $\ce{Mn}$ 最高 +7）。
- **颜色**：$d^1$–$d^9$ 离子因 d-d 跃迁有色，$d^0$ 与 $d^{10}$ 无色。
- **配位能力**：过渡金属是配位化学主角，配合物颜色、磁性由配位场决定。
- **催化性能**：空 d 轨道 + 多变价使过渡金属成为工业催化主力。
- $d^n$ 计数（先失 $ns$ 后失 $(n-1)d$）是过渡金属化学的基本功。

在下一节，我们将聚焦铁、钴、镍——**铁系元素**，看"钢的骨架、磁的海洋、催化的车间"如何由这三个第八族兄弟撑起。
