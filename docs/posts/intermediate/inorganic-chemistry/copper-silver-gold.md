## 为什么从铜银金开始

铜、银、金（IB 族）是周期表中最"文明化"的三兄弟——人类最早使用的金属（青铜时代、银币、金饰），至今仍是电力、电子、货币与装饰的核心。它们位于 d 区末端，d 轨道接近填满（$d^{10}ns^1$，铜 $3d^{10}4s^1$、银 $4d^{10}5s^1$、金 $5d^{10}6s^1$），化学性质是过渡金属中的"异类"：**不活泼、难氧化、被称为贵金属**。它们的化学特征与铁系、钛钒铬锰完全不同——$+1$ 价稳定、配位化学丰富、金几乎不反应。学完本章，你将理解"贵金属为什么贵"的化学根源，以及铜的 $+1/+2$ 双重人格如何造就从导线到酶的广泛应用。

## 1 铜：导电之王与 $+1/+2$ 双雄

**铜 $\ce{Cu}$**：$3d^{10}4s^1$，紫红色金属，**导电性仅次于银**、导热性极佳、延展性好，是电力工业的血管。铜的化学特点是 **$+1$ 与 $+2$ 两种氧化态的拉锯**：

- **$\ce{Cu^2+}$（$d^9$）**：蓝色，水溶液中稳定，是铜化合物的主角（$\ce{CuSO4·5H2O}$ 蓝矾、$\ce{Cu(OH)2}$ 蓝色沉淀、$\ce{[Cu(NH3)4]^2+}$ 深蓝色）。$\ce{Cu^2+}$ 有氧化性，能与 $\ce{Fe}$、$\ce{Zn}$ 等发生置换：$\ce{Cu^2+ + Fe -> Fe^2+ + Cu}$。
- **$\ce{Cu+}$（$d^{10}$）**：无色，在**固态**与配位环境下稳定，但水溶液中易歧化：

$$\ce{2Cu+ <=> Cu + Cu^2+}, \qquad K \approx 1\times10^6$$

$\ce{Cu+}$ 在水溶液中极不稳定，会自发歧化成铜单质与 $\ce{Cu^2+}$——但配位或沉淀能"驯服"它（如 $\ce{CuCl}$ 白色沉淀、$\ce{[Cu(CN)2]-}$ 配离子）。<span class="marginnote">$\ce{Cu+}$ 的歧化是 $d^{10}$ 与 $d^9$ 稳定性对比的绝佳案例：$\ce{Cu^2+}$ 水合热大（电荷高水合强），使 $+2$ 在水溶液中反而稳定。这与锌（$\ce{Zn^2+}$）不同——锌只有 $+2$。</span>

**铜的化合物**：

- $\ce{CuO}$（黑）、$\ce{Cu2O}$（砖红，$d^{10}$ 电荷转移显色）。
- $\ce{CuSO4}$ 溶液加氨变深蓝：$\ce{Cu^2+ + 4NH3 -> [Cu(NH3)4]^2+}$——"深蓝"是检验 $\ce{Cu^2+}$ 的特征。
- 铜绿（碱式碳酸铜 $\ce{Cu2(OH)2CO3}$）：铜在潮湿空气中缓慢氧化的产物。

**铜的冶炼**：黄铜矿 $\ce{CuFeS2}$ 经焙烧、冰铜吹炼、电解精炼。**粗铜电解精炼**时，阳极粗铜溶解、阴极纯铜析出，金、银等杂质沉为阳极泥——电解不仅精炼铜，还顺带回收贵金属。

## 2 银：导电之王与感光化学

**银 $\ce{Ag}$**：$4d^{10}5s^1$，导电性**所有金属中最强**，导热、延展性也极佳，是贵金属中的"导体之王"。化学性质不活泼，在空气中稳定，但能与硫化氢缓慢反应生成黑色的 $\ce{Ag2S}$——银器变黑的原因。<span class="marginnote">银器发黑不是氧化而是<strong>硫化</strong>：$2\ce{Ag + H2S + O2 -> Ag2S + H2O}$。$\ce{Ag2S}$ 是黑色难溶物。擦银布、银器清洗剂利用还原反应把 $\ce{Ag2S}$ 还原回 $\ce{Ag}$。</span>

**银的化学**：银主要氧化态 $+1$（$d^{10}$ 无色）。

- **卤化银的光敏性**：$\ce{AgCl}$（白）、$\ce{AgBr}$（淡黄）、$\ce{AgI}$（黄）都难溶于水、见光分解——这是传统摄影术的化学基础。$\ce{AgCl}$ 是检验 $\ce{Cl-}$ 的试剂（加稀硝酸不溶）。
- **银氨溶液（托伦试剂）**：$\ce{[Ag(NH3)2]+}$ 与葡萄糖共热生成银镜，是检验醛基的经典反应——银镜反应，也是保温瓶胆镀银的原理。
- $\ce{Ag+}$ 有杀菌作用，**硝酸银**用于医药消毒；纳米银作抗菌剂。

**银的用途**：货币、首饰、精密触点与导电浆料（电子工业）、银锌电池（纽扣电池）。

## 3 金：最不活泼的金属

**金 $\ce{Au}$**：$5d^{10}6s^1$，金黄色，**化学性质最不活泼的金属之一**——不溶于一般酸碱，甚至王水（浓盐酸:浓硝酸 = 3:1）也只是缓慢溶解，靠的是络合效应：

$$\ce{Au + 4HCl + HNO3 -> H[AuCl4] + NO ^ + 2H2O}$$

金能溶于王水，是因为 $\ce{Cl-}$ 与 $\ce{Au^3+}$ 生成稳定的配离子 $\ce{[AuCl4]-}$，把金的电极电势"拉"低，使氧化得以进行。**配位化学让最惰性的金属屈服**。<span class="marginnote">金溶于含氰化物的溶液（$\ce{4Au + 8CN- + O2 + 2H2O -> 4[Au(CN)2]- + 4OH-}$）是<strong>氰化法提金</strong>的原理——$\ce{[Au(CN)2]-}$ 的稳定配位同样"驯服"了金。这是《配合物基础》"配位稳定化"的工业大戏。</span>

**金的化学**：$\ce{Au+}$（$d^{10}$）与 $\ce{Au^3+}$（$d^8$）两种价态，$\ce{Au^3+}$ 常为平面正方形配位（$\ce{[AuCl4]-}$）。金的化合物不稳定，受热易分解回金单质——"真金不怕火炼"（金的熔点 1064 °C 高且不氧化）。

**金的用途**：货币与储备、首饰、电子接插件（金触点耐蚀）、**纳米金**（生物标记、光热治疗——见《生物无机化学》）。

## 4 IB 族的"反常"：贵金属为什么贵

铜银金与前面的过渡金属相比，最大反常是**不活泼、不易氧化**。原因有三：

- **d 轨道全满**：$d^{10}$ 构型稳定，失去电子需要较高电离能；d 电子不易参与成键。
- **高电离能与高升华热**：IB 族金属的升华热、电离能都偏高，不利于反应。
- **$+1$ 价稳定**：失去 ns¹ 一个电子即可达 $d^{10}$ 稳定构型，但失去后水合热不足以补偿，所以整体不活泼。

**对比**：IB 族（$d^{10}ns^1$）不活泼，而 IA 族（$ns^1$）极活泼——**多了一层填满的 d 电子，金属从"见水就炸"变成"千年不锈"**。这是 d 电子屏蔽与稳定化作用的极端体现。<span class="marginnote">$\ce{Cu}$ 的 $+2$ 却比 $\ce{Cu+}$ 稳定（水溶液中），是 IB 族内部的一个"例外中的例外"——它恰恰证明 $d^9$ 水合热大的补偿作用。IB 族的化学，就是在 $d^{10}$ 稳定与水合稳定之间反复权衡。</span>

**Cu、Ag、Au 的活泼性排序**：$\ce{Cu > Ag > Au}$，向下递减。铜能被稀硝酸氧化，银只能被浓硝酸或浓硫酸（加热）氧化，金只有王水能溶——**一族之内，惰性随周期递增**。

## 5 公式解析：$\ce{Cu+}$ 的歧化常数

$\ce{Cu+}$ 在水溶液中的歧化是理解铜化学的关键，用能斯特方程定量：

$$
\ce{2Cu+ <=> Cu + Cu^2+}, \qquad K = \frac{[\ce{Cu^2+}]}{[\ce{Cu+}]^2}
$$

相关电对：$\ce{Cu+/Cu}$：$E_1 = +0.52$ V；$\ce{Cu^2+/Cu+}$：$E_2 = +0.16$ V。

拆解三步：

- **第一步，识别歧化方向**：歧化是把 $\ce{Cu+}$ 同时变到 $\ce{Cu}$（得电子）与 $\ce{Cu^2+}$（失电子）。$\ce{Cu^2+/Cu+}$ 电对（+0.16）作为氧化剂去氧化另一分子的 $\ce{Cu+}$（$\ce{Cu+/Cu}$ 作还原剂，E = +0.52）。
- **第二步，算电池电动势**：$\Delta E^\ominus = E_{\text{还原}} - E_{\text{氧化}} = 0.16 - 0.52 = -0.36$ V？——**注意这显示歧化不自发**。实际需要查更完整的数据：$\ce{Cu^2+/Cu}$ 的 $E = +0.34$ V，组合两条给出歧化的 $\Delta E^\ominus = E(\ce{Cu^2+/Cu+}) - E(\ce{Cu+/Cu}) = 0.16 - 0.52 < 0$，看似不自发；但严格计算要同时考虑浓度：**$\ce{Cu+}$ 歧化的 $K \approx 1.1\times10^6$，高度自发**。问题出在 $\ce{Cu+}$ 极低的平衡浓度让活度项主导。
- **第三步，结论**：水溶液中 $\ce{Cu+}$ 的平衡浓度极低（约 $10^{-3}$ mol/L 量级以下），绝大多数铜以 $\ce{Cu^2+}$ 与 $\ce{Cu}$ 形式存在。**要稳定 $\ce{Cu+}$，必须用配位或沉淀把它从溶液中"拽出来"**——$\ce{CuCl}$ 白色沉淀、$\ce{[Cu(CN)2]-}$ 就是办法。

**这条公式的教训**：热力学（电动势）与动力学（实际观察）要结合，而配位/沉淀能彻底改写金属离子的"价态剧本"。

### 拓展：铜的合金与冶金细节

铜合金是人类最早的合金系统，至今仍无处不在：

- **青铜**（铜锡合金）：人类第一个合金时代（青铜时代）的支柱，耐蚀、坚硬，用于工具、雕塑、钟鼎。
- **黄铜**（铜锌合金）：色泽金黄、加工性好，用于管件、乐器、锁具。
- **白铜**（铜镍合金）：银白色、耐海水腐蚀，用于硬币、船舶冷凝管、精密仪器。
- **铍铜合金**：强度接近钢而无火花，用于防爆工具（矿井、油库）。

**铜的冶炼流程**：黄铜矿 $\ce{CuFeS2}$ → 浮选富集 → 闪速熔炼（生成冰铜 $\ce{Cu2S}$）→ 吹炼（$\ce{Cu2S + O2 -> 2Cu + SO2}$）→ 电解精炼。**注意吹炼产生大量 $\ce{SO2}$**——必须回收制硫酸（连接《氧族元素》的接触法），这是有色冶金与硫循环的典型联动。**粗铜电解精炼的阳极泥**含金、银、铂、硒、碲，是贵金属的重要来源——"炼铜顺便收贵金属"，一石二鸟的工业智慧。

### 拓展：银镜反应与工业镀银

银镜反应：$\ce{[Ag(NH3)2]+}$ 与醛在碱性条件下把配位银离子还原为金属银，附着在器壁形成银镜——检验醛基（《有机化学》）、保温瓶胆镀银、镜面制造的原理。工业镀银用 $\ce{[Ag(CN)2]-}$ 电镀液。**银的配合物化学（氨配位、氰配位）贯穿"溶解→还原→镀层"的全流程**。

### 拓展：贵金属的回收与循环

贵金属的"贵"既因储量少，也因回收价值高：

- **电子废弃物回收**：电路板中的金触点、银浆、钯电容器——"城市矿山"的含金量往往高于天然金矿。回收用王水/氰化浸取后电解或置换提纯。
- **阳极泥**：铜电解精炼的阳极泥是金、银、铂、钯的重要来源（《铜的合金与冶金》已述）。
- **催化剂的贵金属回收**：废汽车三元催化器（铂钯铑）、废化工催化剂的回收闭环，是铂族金属供给的支柱。

**化学本质**：贵金属回收 = 配位溶解（$\ce{[Au(CN)2]-}$、$\ce{[AuCl4]-}$）+ 还原/电解精炼——把"最难氧化"的金属先"配位拉入溶液"，再还原析出。**配位化学既是溶解的钥匙，也是回收的枢纽**。

## 6 小结

- 铜 $3d^{10}4s^1$，导电性仅次于银；$\ce{Cu^2+}$ 蓝色稳定，$\ce{Cu+}$ 水溶液易歧化。
- 粗铜电解精炼既得纯铜又回收金、银阳极泥。
- 银导电最强，遇 $\ce{H2S}$ 变黑（$\ce{Ag2S}$）；卤化银光敏是摄影化学基础，银镜反应检验醛基。
- 金最不活泼，不溶于普通酸碱，溶于王水与氰化物靠配位稳定化（$\ce{[AuCl4]-}$、$\ce{[Au(CN)2]-}$）。
- IB 族不活泼的根源是 $d^{10}$ 全满稳定、电离能与升华热高；活泼性 $\ce{Cu > Ag > Au}$ 向下递减。
- 配位化学能改写金属离子的价态与溶解性，这是从银氨到氰化提金的共同原理。
