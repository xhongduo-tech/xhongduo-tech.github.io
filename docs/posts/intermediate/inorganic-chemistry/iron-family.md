## 为什么从铁系开始

铁系元素（$\ce{Fe, Co, Ni}$，第四周期 VIII 族）是过渡金属中与人类命运绑定最紧的三兄弟。铁是钢铁工业的心脏、地球地核的构成、血红蛋白的载氧中心；钴是维生素 $\ce{B12}$ 与高温合金的钥匙；镍是硬币与不锈钢的灵魂。三者同周期、d 电子数依次增加（$d^6, d^7, d^8$），化学性质既相似又递变——铁以 $+2/+3$ 为主、钴 $+2$ 稳定、镍几乎只有 $+2$，这是"多氧化态向下收窄"的典型。学完本章，你将理解为什么铁锈蚀、钴坚韧、镍耐蚀，以及铁的三位一体（金属铁、亚铁、铁）如何在工业、生命与医学中扮演截然不同的角色。

## 1 铁的单质与冶炼

**铁 $\ce{Fe}$**：银白色（粉末黑色）金属，地壳第四丰富的元素，也是使用量最大的金属。**铁的冶炼（高炉炼铁）**：

$$\ce{Fe2O3 + 3CO -> 2Fe + 3CO2}$$

高炉中：焦炭燃烧提供热量并生成还原剂 $\ce{CO}$；铁矿石（赤铁矿 $\ce{Fe2O3}$、磁铁矿 $\ce{Fe3O4}$、菱铁矿 $\ce{FeCO3}$）被逐级还原；石灰石作造渣剂除去脉石（$\ce{CaCO3 -> CaO + CO2}$，$\ce{CaO + SiO2 -> CaSiO3}$ 炉渣）。产物是**生铁**（含碳 2–4.3%，硬而脆）。生铁经**炼钢**（吹氧除碳、脱硫磷）得**钢**（含碳 <2%，韧而强）。<span class="marginnote">钢铁的性能由碳含量调控：生铁硬脆、低碳钢可焊可锻、高碳钢硬而耐磨。加入铬、镍、钒等合金元素则得合金钢——不锈钢（铬 >12%）靠表面致密 $\ce{Cr2O3}$ 膜抗蚀，与铝的钝化同源。</span>

**铁的物理与化学性质**：

- 有铁磁性（能被磁化），是传统磁体的核心（$\ce{Fe3O4}$ 磁铁矿、钢制永磁体）。
- 化学活泼性中等：与稀酸反应放出 $\ce{H2}$；与 $\ce{Cl2}$、$\ce{S}$ 反应生成 $\ce{FeCl3}$、$\ce{FeS}$（注意与卤素生成高价、与硫生成低价）。
- **常温下浓硫酸、浓硝酸使铁钝化**——铁制容器可储运浓酸。

## 2 铁的化合物：$+2$ 与 $+3$ 的世界

**亚铁（$\ce{Fe^2+}$，$d^6$）** 与 **铁（$\ce{Fe^3+}$，$d^5$）** 是铁化学的两大主角。

**亚铁化合物**：$\ce{FeSO4·7H2O}$（绿矾）浅绿色，是还原剂（$\ce{Fe^2+}$ 易被氧化成 $\ce{Fe^3+}$），作补铁剂、还原剂、净水混凝剂。$\ce{Fe(OH)2}$ 白色，在空气中迅速被氧化：白色 → 灰绿 → 红褐色（$\ce{Fe(OH)3}$）。

**铁化合物**：$\ce{FeCl3}$ 棕黄色，用于刻蚀电路板（$2\ce{Fe^3+ + Cu -> 2Fe^2+ + Cu^2+}$）——这是印刷电路板制造的核心反应。$\ce{Fe(OH)3}$ 红褐色沉淀，胶体可用于净水（吸附悬浮物）。

**$\ce{Fe^2+}$ 与 $\ce{Fe^3+}$ 的鉴别**：

- 加 $\ce{KSCN}$（硫氰化钾）：$\ce{Fe^3+ + SCN- -> [Fe(SCN)]^2+}$ 血红色（检验 $\ce{Fe^3+}$ 的特征反应）；$\ce{Fe^2+}$ 不变色。
- 加 $\ce{NaOH}$：$\ce{Fe^3+}$ 立即生成红褐色沉淀，$\ce{Fe^2+}$ 生成白色沉淀后变灰绿再变红褐。
- 加 $\ce{K3[Fe(CN)6]}$（铁氰化钾，赤血盐）：$\ce{Fe^2+}$ 生成蓝色沉淀（滕氏蓝）；$\ce{Fe^3+}$ 与 $\ce{K4[Fe(CN)6]}$（亚铁氰化钾，黄血盐）生成蓝色沉淀（普鲁士蓝）。<span class="marginnote">$\ce{Fe3[Fe(CN)6]2}$（滕氏蓝）与 $\ce{Fe4[Fe(CN)6]3}$（普鲁士蓝）都是深蓝色沉淀，化学式不同但结构相关。这个细节在《分析化学》离子鉴定中常考，也是"蓝色墨水"的历史来源。</span>

**辨析｜易错点：** $\ce{Fe^2+}$ 溶液久置会因氧化变质（$\ce{Fe^2+ -> Fe^3+}$），所以保存亚铁盐溶液要**加铁钉防氧化**（$\ce{Fe + 2Fe^3+ -> 3Fe^2+}$）并酸化。判断"亚铁溶液是否变质"，用 $\ce{KSCN}$ 检验有无 $\ce{Fe^3+}$。

## 3 铁在生命与医学中

铁是**必需微量元素**，成年人体含铁约 4–5 g，其中约 70% 在血红蛋白中。血红蛋白的活性中心是**血红素（heme）**——一个 $\ce{Fe^2+}$ 配位在卟啉环中心，能与 $\ce{O2}$ 可逆结合：$\ce{Fe^2+ + O2 <=> Fe^2+-O2}$。<span class="marginnote">$\ce{CO}$ 与 $\ce{Fe^2+}$ 的结合力比 $\ce{O2}$ 强约 200 倍，且 $\ce{CO}$ 一旦结合就难解离——一氧化碳中毒的分子机制正是"占据氧的座位"。这也是《氮族元素》里 $\ce{CO}$ 剧毒的本质。</span>

**缺铁性贫血**：$\ce{Fe^2+}$ 摄入不足导致血红蛋白合成障碍，补铁剂（硫酸亚铁、富马酸亚铁）是最常见的膳食补充剂。**铁代谢紊乱**（血色素沉着症）则导致铁在器官沉积中毒——"铁多铁少都是病"，这是《生物无机化学》与《基础医学》的交叉点。

## 4 钴与镍：坚韧的邻居

**钴 $\ce{Co}$**：$d^7$，以 $+2$（$\ce{Co^2+}$ 粉红）与 $+3$（$\ce{Co^3+}$ 稳定，尤其在氨配合物中）为主。

- $\ce{Co^2+}$ 与 $\ce{Co^3+}$ 都是优良的配位中心，$\ce{[Co(NH3)6]^3+}$ 极稳定——配位化学经典教材的主角，见《配位化学：结构与异构》。
- **维生素 $\ce{B12}$（钴胺素）**：含钴的复杂配合物，是唯一含金属元素的维生素，参与红细胞生成与神经功能。$\ce{Co^3+}$ 被配位在咕啉环中心。
- 钴基高温合金：喷气发动机涡轮叶片的材料（耐 1000 °C 以上）。

**镍 $\ce{Ni}$**：$d^8$，几乎只有 $+2$ 价（$\ce{Ni^2+}$ 绿色），配位数多为 4（四面体或平面正方形）或 6。

- **雷尼镍**：多孔镍催化剂，有机加氢反应的主力。
- **镍铬合金**（镍铬丝）：电热丝（电炉、电吹风）。
- **镍氢电池、镍镉电池**：曾经的便携电源主力，见《电化学与储能》。
- 不锈钢含镍提高韧性。

**三兄弟的氧化态收窄**：$\ce{Fe}$（$+2/+3$）→ $\ce{Co}$（$+2$ 为主，$+3$ 配位稳定）→ $\ce{Ni}$（几乎仅 $+2$）。原因是 d 电子增多、d 轨道逐渐填满，再失电子越来越难——这印证了《过渡金属通性》中"最高氧化态 VIII 族后下降"的规律。

## 5 公式解析：血红素的配位几何

血红素的结构是配位化学与生命化学的交汇点，可用配合物知识拆解：

$$
\ce{Fe^2+} + \ce{卟啉环(P^{2-})} + \ce{轴向配体(L)} \to \ce{[Fe(P)L]}
$$

- $\ce{Fe^2+}$：$d^6$，配位数 6，八面体场。
- 卟啉环：四齿配体（4 个吡咯氮提供 4 个配位原子），占据八面体的**赤道面**四个位置。
- 轴向配体 $L$：上面是组氨酸的咪唑氮，下面结合 $\ce{O2}$（或 $\ce{CO}$、$\ce{CN-}$）——即"第五、第六配位位置"。

拆解三步：

- **第一步，数配位数**：4（卟啉氮）+ 2（轴向配体）= 6，八面体几何。
- **第二步，看 $d^6$ 与自旋**：$\ce{Fe^2+}$ 在八面体场中 $d^6$，配体场弱时高自旋、强时低自旋——$\ce{O2}$ 结合前后自旋态变化正是血红素"磁性开关"的分子起源（脱氧血红素高自旋、氧合后低自旋）。
- **第三步，理解可逆性**：$\ce{Fe^2+}$ 与 $\ce{O2}$ 的结合不改变氧化态（不是氧化为 $\ce{Fe^3+}$），而是配位加合——所以能可逆地"装氧、卸氧"。**$\ce{CO}$ 的悲剧在于它比 $\ce{O2}$ 结合更牢且难解离**。

**这是整个《配位化学》知识在生命中的一次实地检阅**：配位数、几何、d 电子、自旋态，全部浓缩在一个负责呼吸的分子里。

### 拓展：不锈钢与合金钢的世界

钢的魔法在于"合金化"——在铁碳基础上添加元素，重塑微观结构：

- **奥氏体不锈钢（304、316）**：含 $\ce{Cr}$ 18%、$\ce{Ni}$ 8% 左右，奥氏体组织（面心立方），无磁性、韧性好、耐蚀。316 加钼、镍更多，抗氯离子点蚀，用于海洋与医疗。
- **铁素体与马氏体不锈钢**：以 $\ce{Cr}$ 为主，有磁性、硬度高，用于刀具、餐具。
- **工具钢**：加钨（高速钢）、钒、钼，高温下保持硬度——切削机床的刀尖。
- **高锰钢**：$\ce{Mn}$ 12% 以上，表面受力即硬化（加工硬化），耐磨，用于铁路道岔、破碎机颚板。
- **电工钢（硅钢）**：加硅 3% 左右，导磁性能优，变压器铁芯。

**化学原理**：$\ce{Cr}$ 在不锈钢表面生成致密 $\ce{Cr2O3}$ 钝化膜（《钛钒铬锰》），这是"不锈"的本质；$\ce{Ni}$ 稳定奥氏体结构，赋予韧性与可焊性；碳含量与热处理（淬火/回火）控制马氏体转变，决定硬度与韧性。**钢铁的世界 = 铁碳相图 + 合金元素 + 热处理工艺三者的协同**。

### 拓展：铁的氧化物与矿物

铁的氧化物构成完整色阶：$\ce{FeO}$（黑）、$\ce{Fe3O4}$（磁铁矿，黑，铁磁性）、$\ce{Fe2O3}$（红，赤铁矿/铁锈主成分，红棕色颜料）。$\ce{Fe3O4}$ 可看作 $\ce{FeO·Fe2O3}$（含 $\ce{Fe^2+}$ 与 $\ce{Fe^3+}$）。红土、赭石、锈迹都是铁的氧化物的颜色——**铁的颜色即地球的颜色**，通向《地质学》与《地球系统科学》。

### 拓展：铁碳相图一瞥

钢铁性能的钥匙是铁碳相图——铁与碳在不同温度下的相态图：

- **奥氏体（γ-Fe，fcc）**：高温相，碳固溶度高（最多约 2%），塑韧性好，是锻造与热处理的起始相。
- **铁素体（α-Fe，bcc）**：低温相，碳固溶度极低（<0.02%），软而韧。
- **渗碳体 $\ce{Fe3C}$**：碳的化合物相，硬而脆。
- **共析转变**：0.77% C 的奥氏体在 727 °C 同时析出铁素体+渗碳体的层状混合物（珠光体）——热处理（淬火得马氏体、回火调韧性）都围绕这条共析线展开。

**一句话**：钢的"钢性"（硬度、韧性、可焊性）不是铁的单一属性，而是铁与碳在相图上的"相变工程"——碳含量与热处理共同谱写了钢铁的性能史。

## 6 小结

- 铁是使用量最大的金属，高炉炼铁用 $\ce{CO}$ 还原铁矿石，生铁→炼钢→钢。
- $\ce{Fe^2+}$（还原性）与 $\ce{Fe^3+}$（氧化性）构成铁化学两大主角，用 $\ce{KSCN}$、$\ce{NaOH}$、铁氰化钾鉴别。
- 亚铁溶液易氧化变质，保存须加铁钉防氧化并酸化。
- 血红蛋白的活性中心是含 $\ce{Fe^2+}$ 的血红素，$\ce{CO}$ 比 $\ce{O2}$ 结合更强导致中毒。
- 钴以 $+2/+3$ 为主，维生素 $\ce{B12}$ 是含钴配合物；镍几乎只有 $+2$ 价，是加氢催化剂与合金材料。
- 铁钴镍氧化态依次收窄，印证过渡金属 VIII 族后最高价态下降。
