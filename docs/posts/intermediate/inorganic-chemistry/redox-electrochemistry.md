## 为什么从氧化还原开始

上一章的酸碱反应转移的是**质子**，本章的反应转移的是**电子**——**氧化还原反应（redox）**。它是自然界能量流动的底层语言：光合作用把水氧化、电池把化学能变电能、钢铁锈蚀是铁被氧化、人体的呼吸链每一步都是电子传递。无机化学里有两大反应类型贯穿始终——酸碱反应与氧化还原反应，前者管"质子去哪"，后者管"电子去哪"。本章先建立氧化数、氧化剂/还原剂的判别体系，再引出能斯特方程，把反应方向与能量连起来，为后续元素化学的每一族"氧化还原图景"提供统一的定量框架。

## 1 氧化数：电子的"记账本"

**氧化数（氧化态, oxidation state）** 是人为规定的一套电荷分配规则，用来追踪电子转移。它不是真实电荷，而是"假想电荷"——假设电子完全归电负性大的原子所有。

规则要点：

- 单质中元素氧化数为 0。
- 单原子离子氧化数等于其电荷。
- $\ce{O}$ 一般为 $-2$，过氧化物中为 $-1$（如 $\ce{H2O2}$），与 $\ce{F}$ 结合时为 $+2$。
- $\ce{H}$ 一般为 $+1$，金属氢化物中为 $-1$（如 $\ce{NaH}$）。
- 分子中所有原子氧化数之和为 0，离子为电荷数。

**氧化（oxidation）**：氧化数升高（失去电子）；**还原（reduction）**：氧化数降低（得到电子）。**氧化剂**被还原（自身得电子），**还原剂**被氧化（自身失电子）。

**辨析｜易错点：** 氧化数升高的是**还原剂**，降低的是**氧化剂**——"氧化剂被还原、还原剂被氧化"这两句话最容易绕晕。记口诀："升失氧还，降得还氧"：氧化数升高→失电子→被氧化→作还原剂；降低→得电子→被还原→作氧化剂。$\ce{Fe2O3 + 3CO -> 2Fe + 3CO2}$ 中 C 由 $+2$ 升到 $+4$，$\ce{CO}$ 是还原剂。

## 2 配平氧化还原反应

氧化还原配平有两种方法：**氧化数法**与**离子-电子法（半反应法）**。离子-电子法更系统，尤其适合水溶液反应：

**第一步**：拆成两个半反应（氧化半反应与还原半反应）。
**第二步**：分别配平原子——酸性介质用 $\ce{H+}$ 与 $\ce{H2O}$ 配平 O、H；碱性介质用 $\ce{OH-}$ 与 $\ce{H2O}$。
**第三步**：配平电荷（加电子）。
**第四步**：按电子数相等的原则合并两个半反应。

例：酸性介质中 $\ce{MnO4-}$ 氧化 $\ce{Fe^2+}$：

$$\ce{MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O}$$
$$\ce{Fe^2+ -> Fe^3+ + e-}$$

电子数相等需 $\ce{Fe^2+}$ 半反应 ×5，合并：

$$\ce{MnO4- + 5Fe^2+ + 8H+ -> Mn^2+ + 5Fe^3+ + 4H2O}$$

酸性介质中平衡电荷用 $\ce{H+}$，碱性介质用 $\ce{OH-}$——**介质不同，配平产物不同**。$\ce{MnO4-}$ 在酸性介质中被还原为 $\ce{Mn^2+}$（无色），在中性或弱碱性为 $\ce{MnO2}$（棕黑沉淀），在强碱性为 $\ce{MnO4^2-}$（绿色）。介质决定产物，这是高锰酸钾氧化性的经典考点。<span class="marginnote">$\ce{MnO4-}$ 是紫红色的，当它被还原褪色时，常被用作"自指示剂"——滴定的终点就是紫色恰好消失的瞬间。这一个细节把氧化还原与《分析化学》的滴定连起来了。</span>

## 3 电极电势与标准电极电势

氧化还原反应能否自发进行，取决于得失电子的倾向，用**电极电势**定量刻画。把电极（金属与它的盐溶液）与标准氢电极（SHE）组成原电池，测得的电动势就是该电极的**标准电极电势 $E^\ominus$**。规定 SHE 的 $E^\ominus(\ce{H+/H2}) = 0$ V。

$E^\ominus$ 越大，该电对**越易得电子**（氧化态越易被还原），氧化能力越强。
标准状态下，$E^\ominus$ 大的电对作正极（被还原），小的作负极（被氧化）。
**电池电动势** $\Delta E^\ominus = E^\ominus_{\text{正极}} - E^\ominus_{\text{负极}}$，$\Delta E^\ominus > 0$ 时反应自发。

常用标准电极电势（$E^\ominus$，V）：$\ce{F2/F-} = +2.87$、$\ce{Cl2/Cl-} = +1.36$、$\ce{O2/OH-} = +0.40$、$\ce{Cu^2+/Cu} = +0.34$、$\ce{H+/H2} = 0$、$\ce{Zn^2+/Zn} = -0.76$、$\ce{Li+/Li} = -3.05$。<span class="marginnote">氟是已知最强的氧化剂（$+2.87$ V），锂是已知最强的还原剂（$-3.05$ V）——这个数据解释了为什么锂电池能量密度高：锂极容易失去电子。也是元素化学里"氟氧化性最强"的理论依据。</span>

**电化学系列（活性顺序）**：金属的电极电势排序就是金属活动性顺序的理论版。$\ce{K > Ca > Na > Mg > Al > Zn > Fe > Sn > Pb > H > Cu > Hg > Ag > Pt > Au}$，前面的金属能把后面的从其盐溶液中置换出来。

## 4 公式解析：能斯特方程

实际浓度（非标准状态）下的电极电势由**能斯特方程（Nernst equation）** 给出：

$$
E = E^\ominus - \frac{RT}{nF}\ln Q = E^\ominus - \frac{0.0592}{n}\lg Q \quad (25\ \text{°C})
$$

- $E^\ominus$：标准电极电势。
- $R$：气体常数（8.314 J/(mol·K)），$T$：热力学温度。
- $n$：电极反应转移的电子数。
- $F$：法拉第常数（96485 C/mol）。
- $Q$：反应商（产物浓度/反应物浓度的幂次组合）。
- 25 °C 时 $2.303RT/F = 0.0592$ V，于是自然对数换成常用对数。

拆解三步：

- **第一步，看系数来源**：$RT/(nF)$ 中的 $n$ 说明电极电势对电子数敏感——转移电子越多，电势对浓度变化的"响应"越弱。
- **第二步，看 $Q$ 的写法**：$Q = [\text{还原产物}]/[\text{氧化态物种}]$ 按半反应的化学计量数取幂。氧化态浓度升高，$Q$ 增大，$\lg Q$ 增大，$E$ 减小——**氧化剂浓度越稀，氧化能力越弱**。
- **第三步，判断反应方向**：把两个电极的 $E$ 分别算出来，$E_{\text{正}} - E_{\text{负}} > 0$ 则反应向书写方向进行。**能斯特方程是把"浓度变化"翻译成"反应方向变化"的定量桥。**

应用例：$\ce{Cu^2+ + Zn -> Cu + Zn^2+}$ 的标准电动势 $\Delta E^\ominus = 0.34 - (-0.76) = 1.10$ V > 0，自发。若增大 $[\ce{Cu^2+}]$，电动势上升，反应更有利。

## 5 原电池与电解池

**原电池（galvanic cell）**：自发反应产生电流。锌-铜原电池（丹尼尔电池）中，锌极被氧化（负极），电子经外电路流向铜极（正极），$\ce{Cu^2+}$ 被还原。盐桥维持电荷平衡。

**电解池（electrolytic cell）**：外部电源驱动非自发反应。电解熔融 $\ce{NaCl}$ 得金属钠，电解 $\ce{NaCl}$ 水溶液得 $\ce{NaOH}$、$\ce{H2}$ 与 $\ce{Cl2}$——电解是工业制备活泼金属（$\ce{Na}$、$\ce{Mg}$、$\ce{Al}$）的主要途径。电解 $K$ 盐活泼金属时的"放电顺序"由电极电势决定。

**辨析｜易错点：** 原电池与电解池的"正负极"容易搞混。原电池：负极=氧化（失电子）、正极=还原（得电子），靠自发反应推动；电解池：阳极=氧化、阴极=还原，靠外部电源推动。记住**氧化总是发生在阳极或负极之外的"失电子端"**——更稳妥的记忆：无论什么池，**阳极 = 氧化（Anode = Oxidation），阴极 = 还原（Cathode = Reduction）**。<span class="marginnote">"An ox"助记：Anode 对应 Oxidation，Cathode 对应 Reduction。原电池中阳极为负极，电解池中阳极为正极——两极角色随池型互换，但"阳极氧化、阴极还原"永远不变。</span>

### 拓展：金属的电化学腐蚀与防护

腐蚀是氧化还原反应最"昂贵"的一面——全球每年因腐蚀损失约 GDP 的 3%，防护化学因此重要：

- **吸氧腐蚀（中性/弱酸性）**：铁在大气中主要发生吸氧腐蚀——负极 $\ce{Fe -> Fe^2+ + 2e-}$，正极 $\ce{O2 + 2H2O + 4e- -> 4OH-}$，总反应 $2\ce{Fe + O2 + 2H2O -> 2Fe(OH)2}$，再氧化成铁锈。
- **析氢腐蚀（强酸性）**：正极是 $\ce{2H+ + 2e- -> H2}$，多见于酸性环境（酸雨地区）。
- **电化学腐蚀比化学腐蚀更普遍**：钢铁在潮湿处形成微电池，杂质（碳）作阴极、铁作阳极被腐蚀。
- **防护策略**：表面覆盖（油漆、镀锌、镀铬）、牺牲阳极保护（锌块连船体，见《锌镉汞》）、外加电流阴极保护、缓蚀剂（吸附成膜减缓腐蚀）。

**化学本质**：腐蚀 = 金属被氧化的自发原电池反应。**控制腐蚀 = 控制金属的电极电势与表面钝化**——电化学知识直接转化为工程安全。

### 拓展：标准电极电势表的使用

查表时注意：(1) 表中数值是**还原电位**（$E^\ominus(\ce{氧化态/还原态})$），越正越易被还原；(2) 电位是强度量、与方程系数无关，$\ce{Fe^3+ + e- -> Fe^2+}$ 与 $2\ce{Fe^3+ + 2e- -> 2Fe^2+}$ 的 $E^\ominus$ 相同；(3) 使用前先确认介质（酸性/碱性）——不同介质同一电对的 $E^\ominus$ 不同。**电极电势表是氧化还原的"词典"，查对词条才能组出正确的句子**。

## 6 小结

- **氧化数**是追踪电子转移的记账系统，氧化数升=被氧化=还原剂，降=被还原=氧化剂。
- 氧化还原配平用**半反应法**，注意介质（酸性用 $\ce{H+}$，碱性用 $\ce{OH-}$）决定产物。
- **标准电极电势 $E^\ominus$** 衡量氧化还原能力，电池电动势 $\Delta E^\ominus = E_+ - E_-$ 判自发。
- **能斯特方程**把浓度效应计入电势，$E$ 随氧化态浓度升高而降低。
- 原电池靠自发反应发电，电解池靠外电源驱动非自发反应，**阳极氧化、阴极还原**恒成立。
