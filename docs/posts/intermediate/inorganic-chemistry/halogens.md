## 为什么从卤素开始

卤素（第 VIIA 族：$\ce{F, Cl, Br, I, At}$）是 p 区元素化学的压轴章节。它们是**氧化性最强的非金属族**，价电子构型 $ns^2np^5$，只差一个电子就达到八隅体，因此"虎视眈眈"地想夺取一个电子。从氟（最强氧化剂，$E^\ominus(\ce{F2/F-}) = +2.87$ V）到碘（$+0.54$ V），氧化性沿族向下递减——这是周期律第一次以"家族梯度"的形式直观呈现。卤素的应用横跨生活（食盐、漂白、消毒）与工业（氯碱工业、氟塑料、卤代烃），其氧化还原行为是《氧化还原与电化学》最好的实战检验场。学完本章，你将对"同族性质渐变"有最完整的感性认识，并能熟练运用卤素单质置换顺序。

## 1 卤素单质的通性

卤素单质（$\ce{F2}$ 气、$\ce{Cl2}$ 气、$\ce{Br2}$ 液、$\ce{I2}$ 固）物理性质随分子量增大而规律变化：颜色加深（淡黄 → 黄绿 → 红棕 → 紫黑）、密度增大、熔沸点升高（分子间范德华力随分子量增大）。

**化学通性**：都极易得一个电子成 $-1$ 价卤离子，都是强氧化剂，氧化性排序：

$$\ce{F2 > Cl2 > Br2 > I2}$$

**置换反应**（活泼卤素置换不活泼的）：

$$\ce{Cl2 + 2NaBr -> 2NaCl + Br2}, \qquad \ce{Cl2 + 2KI -> 2KCl + I2}, \qquad \ce{Br2 + 2KI -> 2KBr + I2}$$

**辨析｜易错点：** $\ce{Cl2}$ 能置换 $\ce{Br-}$、$\ce{I-}$，$\ce{Br2}$ 只能置换 $\ce{I-}$ 不能置换 $\ce{Cl-}$——置换顺序即氧化性顺序。但注意：$\ce{F2}$ 与水的反应太剧烈（$2\ce{F2 + 2H2O -> 4HF + O2}$），不能在水溶液中进行置换，所以"氟置换其他卤素"只存在于气态。

**卤素与水的反应**分两类：

- $\ce{Cl2}$、$\ce{Br2}$、$\ce{I2}$（歧化，见氯）：$\ce{X2 + H2O <=> HX + HXO}$。
- $\ce{F2}$（剧烈氧化水）：$2\ce{F2 + 2H2O -> 4HF + O2}$——氟的氧化性连水都"保护"不了氢。

## 2 氯：工业与生活的双面手

**氯气 $\ce{Cl2}$**：黄绿色、刺激性气味、有毒气体（密度比空气大）。**制取**：实验室用浓盐酸与二氧化锰加热：

$$\ce{MnO2 + 4HCl(浓) \xrightarrow{\Delta} MnCl2 + Cl2 ^ + 2H2O}$$

**与水的歧化反应**是氯化学的核心：

$$\ce{Cl2 + H2O <=> HCl + HClO}$$

$\ce{Cl}$ 从 0 歧化为 $-1$（$\ce{HCl}$）与 $+1$（$\ce{HClO}$ 次氯酸）。$\ce{HClO}$ 具有强氧化性、能杀菌消毒、漂白，这就是**氯水**消毒漂白的原理。**氯水中有 3 种分子（$\ce{Cl2}$、$\ce{HClO}$、$\ce{H2O}$）与 4 种离子（$\ce{H+}$、$\ce{Cl-}$、$\ce{ClO-}$、$\ce{OH-}$）**——判断氯水成分是经典考点。<span class="marginnote">新制氯水含大量 $\ce{Cl2}$ 与 $\ce{HClO}$，久置氯水见光后 $\ce{HClO}$ 分解（$2\ce{HClO \xrightarrow{光} 2HCl + O2}$）变成稀盐酸，漂白能力消失。所以氯水要避光现配现用。</span>

**氯气与碱反应**：$2\ce{NaOH + Cl2 -> NaCl + NaClO + H2O}$——漂白液（次氯酸钠溶液）；$\ce{2Ca(OH)2 + 2Cl2 -> Ca(ClO)2 + CaCl2 + 2H2O}$——**漂白粉**（次氯酸钙）。漂白粉有效成分是 $\ce{Ca(ClO)2}$，久置失效因吸收 $\ce{CO2}$ 与水分解放出 $\ce{HClO}$。

**氯碱工业**：电解饱和食盐水：

$$2\ce{NaCl + 2H2O \xrightarrow{\text{电解}} 2NaOH + H2 ^ + Cl2 ^}$$

同时得到烧碱、氯气、氢气三大产品，是基础化工的支柱。氯气用于消毒自来水、合成 $\ce{HCl}$ 与塑料（PVC）。

## 3 氯化氢与盐酸

**氯化氢 $\ce{HCl}$**：无色有刺激性气味气体，极易溶于水（1 体积水溶约 500 体积），水溶液是**盐酸**。盐酸是三大强酸之一，不挥发性酸（高沸点）、无氧化性（稀盐酸），工业用途极广（除锈、氯化物制备、胃液成分助消化）。<span class="marginnote">氯化氢在潮湿空气中形成白雾（吸收水汽成盐酸小液滴），"白雾"而非"白烟"——雾是液体小液滴、烟是固体小颗粒，这是审题陷阱。</span>

**检验 $\ce{Cl-}$**：加 $\ce{AgNO3}$ 溶液生成白色 $\ce{AgCl}$ 沉淀，再加稀硝酸不溶解。**注意先加稀硝酸排除 $\ce{CO3^2-}$、$\ce{SO4^2-}$ 等干扰离子**——这是《分析化学》离子鉴定第一课。

## 4 溴与碘：从海洋到医药

**溴 $\ce{Br2}$**：红棕色液体，易挥发（棕红色蒸气），是常温下唯一的液态非金属单质。工业从海水中提取（溴离子被氯气置换）。溴用于感光材料（溴化银 $\ce{AgBr}$）、阻燃剂。

**碘 $\ce{I2}$**：紫黑色固体，受热直接升华（紫黑色蒸气）。**碘遇淀粉变蓝**——检验碘的特征反应。碘的氧化性最弱，与 $\ce{Fe}$ 反应只生成 $\ce{FeI2}$（$\ce{Fe}$ 被氧化到 $+2$），而氯溴与铁反应生成 $\ce{FeX3}$（$+3$）。<span class="marginnote">卤素氧化性递减的又一证据：$\ce{Cl2}$、$\ce{Br2}$ 能把铁氧化到 $+3$，$\ce{I2}$ 只能到 $+2$。氧化剂越强，被氧化元素价态越高——这条规律贯穿金属与卤素的反应。</span>

**碘是生命元素**：甲状腺激素的核心成分是碘。缺碘导致甲状腺肿大，食盐加碘（碘酸钾 $\ce{KIO3}$）是世界卫生组织的公共健康方案。海带是天然的富碘食物。

**卤素互化物与多卤化物**：如 $\ce{BrF3}$、$\ce{ICl}$，氧化性介于两元素之间，常作温和氧化剂。

## 5 氟的特殊性与氟化学

**氟 $\ce{F}$**：电负性最大的元素（鲍林标度 3.98），氧化性最强，与几乎所有元素（除 $\ce{He}$、$\ce{Ne}$、$\ce{Ar}$）直接化合。特殊性：

$\ce{F2}$ 是最强氧化剂，$E^\ominus = +2.87$ V，能氧化水、甚至氧化稀有气体（$\ce{Xe + 2F2 -> XeF4}$）。
**氢氟酸 $\ce{HF}$**：弱酸（因 F-H 键强、氢键强，电离度小），却能**腐蚀玻璃**：$\ce{SiO2 + 4HF -> SiF4 ^ + 2H2O}$——用于玻璃刻蚀、制造氟化物。<span class="marginnote">$\ce{HF}$ 的"弱酸腐蚀玻璃"是反差最大的考点：它酸性弱但腐蚀性强，因为对硅氧骨架的侵蚀不靠酸性而靠 $\ce{F-}$ 对 $\ce{Si}$ 的强亲和力。储运 $\ce{HF}$ 只能用塑料容器。</span>
- **氟与碳的化合物极稳定**：聚四氟乙烯（特氟龙 $\ce{(CF2-CF2)_n}$）耐腐蚀、耐高温、不粘，是"塑料王"；氟利昂（氯氟烃）曾作制冷剂，因破坏臭氧层被淘汰。
- 氟化物用于牙膏防龋齿（$\ce{NaF}$ 与羟基磷酸钙反应生成抗酸的氟磷酸钙）。

## 6 公式解析：卤素的歧化反应

卤素与水、碱的反应是歧化反应的标准模板。以氯气与水的歧化为例：

$$
\ce{Cl2 + H2O <=> HCl + HClO}
$$

$\ce{Cl}$ 的氧化数从 0 变为 $-1$ 与 $+1$，是典型的**同一元素自身氧化还原**（歧化）。用电子守恒分析：

**第一步，写两个半反应**：

还原（$\ce{Cl}$ 得电子）：$\ce{Cl2 + 2e- -> 2Cl-}$（0 → $-1$，降 1，每个 $\ce{Cl2}$ 得 2 个电子）；
氧化（$\ce{Cl}$ 失电子）：$\ce{Cl2 + 4OH- - 2e- -> 2ClO- + 2H2O}$（0 → $+1$，升 1，每个 $\ce{Cl2}$ 失 2 个电子）。

**第二步，电子守恒合并**：氧化数与还原数必须相等（得失电子数相同），两半反应各取一份合并。

**第三步，生成物与介质**：在酸性/中性水中歧化产物是 $\ce{HCl + HClO}$；在碱性溶液中产物是 $\ce{Cl- + ClO-}$（如漂白液 $\ce{NaCl + NaClO}$）。**介质决定歧化产物的存在形态**——同一反应，酸碱介质不同，产物书写不同。

**为什么卤素能歧化而氟不能**：歧化需要中间价态——氯的 0 态介于 $-1$ 与 $+1$ 之间。氟只有 $-1$ 价一个稳定态（无正价），0 态是最高可能氧化数区域，只能被还原、不能歧化，所以氟与水只发生氧化反应。**歧化的前提是元素存在可及的中间价态**。

### 拓展：卤素的检测与应用小结

- **$\ce{Cl-}$ 检验**：$\ce{AgNO3}$ 生成白色 $\ce{AgCl}$ 沉淀、加稀硝酸不溶；先酸化排除 $\ce{CO3^2-}$、$\ce{SO4^2-}$ 干扰。
- **$\ce{Br-}$、$\ce{I-}$ 检验**：$\ce{AgBr}$ 淡黄色、$\ce{AgI}$ 黄色沉淀；或氯水萃取——$\ce{Br2}$ 使 $\ce{CCl4}$ 层橙红、$\ce{I2}$ 使 $\ce{CCl4}$ 层紫红。
- **应用小结**：$\ce{F2}$ 氟塑料与牙膏、$\ce{Cl2}$ 消毒与 PVC、$\ce{Br2}$ 感光与阻燃、$\ce{I2}$ 消毒与甲状腺。

一句话：卤素的检测与应用，处处体现"氧化性递减 + 沉淀颜色差异"两条主线。

## 7 小结

- 卤素单质氧化性排序 $\ce{F2 > Cl2 > Br2 > I2}$，置换反应依此顺序。
- 氯与水、碱歧化生成 $\ce{HClO}$，这是氯水消毒漂白与漂白粉的原理。
- 氯碱工业电解食盐水同时制得 $\ce{NaOH}$、$\ce{H2}$、$\ce{Cl2}$ 三大产品。
- 溴是常温唯一液态非金属，碘遇淀粉变蓝、是甲状腺必需元素。
- 氟电负性最强、氧化性最强，$\ce{HF}$ 弱酸却能腐蚀玻璃，特氟龙极稳定。
- 卤素歧化需中间价态，介质决定产物；氟无正价故只氧化不歧化。
