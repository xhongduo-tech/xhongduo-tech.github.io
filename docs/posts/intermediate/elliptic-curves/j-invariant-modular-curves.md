## 为什么从 j-不变量开始

第 10 篇我们造出了模形式的「种子」$G_4, G_6$ 与「唯一尖点形式」$\Delta$。把它们组合起来，会得到一个权 0 的函数——$j$-不变量。它的伟大之处在于：**$j$ 把「椭圆曲线的同构类」和「模群作用下的格」一一对应起来**，于是「曲线有多少种」变成了「一个黎曼球面上的取值」。而带上 level 结构后，同样的分类思想把曲线族组织成**模曲线** $X_0(N), X_1(N)$——它们是「参数化一切带额外结构的椭圆曲线的空间」。<span class="marginnote">「曲线族如何被参数化」是 19 世纪黎曼的洞见：亏格 1 的曲线族被一个参数（$j$）控制；亏格 ≥ 2 的曲线族参数更多（模空间维数 $3g-3$）。$j$-不变量就是「亏格 1 模空间」的坐标——它是整个代数几何里最古老的模空间。</span>本节主题：$j$ 的定义与模函数身份、基本域、模曲线的定义与亏格公式。

## 1 j-不变量：曲线的身份号

### 定义

用第 2 篇的不变量 $c_4, c_6, \Delta$（$E: y^2 = x^3 + Ax + B$ 时 $c_4 = -48A$，$c_6 = -864B$，$\Delta = -16(4A^3+27B^2)$）定义

$$j(E) = 1728\,\frac{c_4^3}{\Delta}$$

（在 $y^2 = x^3 + Ax + B$ 坐标下即 $j = 1728\cdot 4A^3/(4A^3 + 27B^2)$。）<span class="marginnote">常数 $1728 = 12^3$ 的出现是为了让「尖点处归一化」：$j$ 在 $\infty$ 处的主项是 $q^{-1}$，而 $1728$ 保证 $j(i) = 1728$（$y^2 = x^3 + x$ 的 $j$）与 $j(\omega) = 0$（$y^2 = x^3 + 1$ 的 $j$）这两个「对称点」有干净值。它是一个「规范化常数」，不是自然常数。</span>

### 核心定理：同构的分类

**定理**：两个定义在代数闭域上的椭圆曲线 $E_1, E_2$ 同构 $\iff$ $j(E_1) = j(E_2)$。

**重点：$j$ 是「同构类的完整不变量」**——它完全决定曲线的「几何身份」。$j = 0$ 对应「六次对称」（$y^2=x^3+1$，自同构群 $\mathbb{Z}/6$），$j = 1728$ 对应「四次对称」（$y^2=x^3+x$，自同构群 $\mathbb{Z}/4$），其余 $j$ 值自同构群为 $\mathbb{Z}/2$。

**辨析｜易错点：** 同构 $\neq$ 同构类里的「方程相同」。**$j$ 相同只保证「相差一个坐标变换」，不保证方程逐项一致**——$y^2 = x^3 - x$ 与 $y^2 = x^3 - 36x$ 都是 $j = 1728$，但它们由伸缩变换联系，不是同一方程。在 $\mathbb{Q}$ 上，$j$ 相同还意味着「可能是同构（有理数上）」或「只是几何同构」（需要判别二次扭）——**$j$ 是几何不变量，不是算术不变量**。

## 2 基本域与 j 的模函数身份

### 模群作用与基本域

$SL_2(\mathbb{Z})$ 作用在上半平面。**基本域（fundamental domain）** 是「每个轨道恰好取一个代表元」的区域：

$$\mathcal{F} = \left\{ \tau \in \mathfrak{h} : |\tau| \geq 1,\ |\mathrm{Re}\,\tau| \leq \frac12 \right\}$$

每个格等价类在 $\mathcal{F}$ 中恰有一个代表元（边界上的点需按「粘合规则」取一个）。<span class="marginnote">基本域是「模群的版图」：它把无限的 $\mathfrak{h}$ 压缩成一个「带围栏的六边形块」。$SL_2(\mathbb{Z})$ 由两个变换生成：$T: \tau \to \tau + 1$（平移）与 $S: \tau \to -1/\tau$（倒置）。正是 $T$ 生成了「$q$-展开」的周期性，$S$ 生成了「尖点」的结构。</span>

### j 是模函数

$j(\tau)$ 满足 $j(\gamma\tau) = j(\tau)$（权 0），且在 $\mathcal{F}$ 的边界上「对称地」取值。**j 是模函数（权 0 的模形式），它把商空间 $\mathfrak{h}/SL_2(\mathbb{Z})$ 映到黎曼球面 $\mathbb{P}^1$，并且是双全纯的（同构）**：

$$\mathfrak{h}\big/SL_2(\mathbb{Z}) \xrightarrow{\ \sim\ } \mathbb{P}^1, \qquad \tau \mapsto j(\tau)$$

这是「亏格 1 曲线族的模空间 = 一条亏格 0 的曲线」的精确陈述。

## 3 模曲线：带 level 的曲线族

### 为什么要 level 结构

只凭 $j$ 无法区分「带额外结构的曲线」。模性定理（第 17 篇）需要知道「挠点」的排列，于是引入**level 结构**：对整数 $N$，考虑

$$\Gamma_0(N) = \left\{ \begin{pmatrix} a&b\\c&d\end{pmatrix} \in SL_2(\mathbb{Z}) : c \equiv 0 \pmod{N} \right\}$$

它是「$c$ 被 $N$ 整除」的模群子群。**模曲线（modular curve）** $X_0(N) = \mathfrak{h}/\Gamma_0(N) \cup \{\text{尖点}\}$ 是「复结构 + 一个 $N$-级点（$N$-挠循环子群）」的椭圆曲线族的分类空间。<span class="marginnote">直观地：$X_0(N)$ 上的每个点 = 一条椭圆曲线 + 一个「$N$-挠循环子群」。$X_1(N)$ 类似但记录「$N$-挠点本身」。这些曲线承载了「同源图」的全部信息——第 14 篇的同源与对偶同源，本质上是「$X_0(N)$ 上的点的对应」。模性定理说「每条 $\mathbb{Q}$ 上的椭圆曲线对应 $X_0(N)$ 的一个点」，就是「带 level 的曲线族」的算术化。</span>

### 亏格公式

$X_0(N)$ 的亏格可由公式计算（$N$ 是素数 $p$ 时最简单）：

$$g\big(X_0(p)\big) = \left\lfloor \frac{p+1}{12} \right\rfloor + \text{校正项}$$

对一般 $N$ 的亏格公式是经典组合式。**重点：$g(X_0(N))$ 增长得大约 $N/12$，$N$ 越大曲线越「复杂」**。Mazur 定理（第 7 篇）「$E(\mathbb{Q})$ 的挠子群只有 15 种」正是「当 $N$ 超过 12 时 $X_0(N)$ 的亏格 ≥ 1，不再有无穷多个有理点」的推论。<span class="marginnote">这条「几何→算术」的通道是 Mazur 证明的骨架：$X_0(N)$ 亏格 ≥ 1 时有理点有限（Faltings），于是「$N$-挠循环子群的存在」被限制在小 $N$ 上。一个「算亏格」的公式，终结了「挠点形状」的搜索。这是模曲线威力的一次完整展示。</span>

## 4 公式解析：$j = 1728\,G_4^3/\Delta$ 的三重身份

把 $j$ 的表达式当作「三层翻译」逐层拆解。

$$
j = 1728\,\frac{G_4^3}{\Delta} = q^{-1} + 744 + 196884\,q + \cdots
$$

- **第一步，模形式层**：$G_4$ 权 4，$G_4^3$ 权 12；$\Delta$ 权 12。相除后权为 0——**$j$ 是权 0 的模函数**，对 $SL_2(\mathbb{Z})$ 不变。分子分母同为权 12，比例系数 1728 是「归一化」。
- **第二步，几何层**：$G_4(\tau)$ 编码「格的二次矩」，$\Delta(\tau)$ 编码「格的判别式」。$j$ 把「格 $(\tau)$」映到「一条曲线的身份」。**$j$ 不依赖于「如何选取格」**——换基即 $SL_2(\mathbb{Z})$ 作用，而 $j$ 对之不变——这正是「身份号」的几何含义。
- **第三步，$q$-展开层**：代入 $E_4 = 1 + 240\sum\sigma_3(n)q^n$、$\Delta = q - 24q^2 + \cdots$ 并展开，得到 $q^{-1} + 744 + 196884q + \cdots$。**主项 $q^{-1}$ 说明「格退化时 $j \to \infty$」**（尖点 = 退化的曲线）。常数项 744 与第 9 篇的「Ramanujan 常数」同源。
- **第四步，信息量的比较**：$j$ 只有一个自由参数（一个复数），而曲线族的「形状自由度」也正好是一个——**一个参数分类一条亏格 1 曲线族**。亏格 2 则需要 3 个参数，亏格 3 需要 6 个…… $3g-3$。这印证了「亏格决定参数个数」的普适律。

## 5 模曲线的算术意义

- **Hecke 对应**：$X_0(N)$ 上的 Hecke 算子（第 12 篇）来自「$p$-同源的对应」——**同源图编码在模曲线的对应里**，这是「模性 ↔ 同源」的关键桥梁。
- **有理点与算术**：$X_0(N)(\mathbb{Q})$ 的点给出「$\mathbb{Q}$ 上的带 level 椭圆曲线」。模性定理断言「每条 $E/\mathbb{Q}$ 都是某 $X_0(N)$ 的点」——**模曲线是「椭圆曲线的字典」，而 $j$ 是「词条」**。
- **CM 点**：CM 曲线的 $j$ 是代数整数（第 9 篇），它们在 $X_0(N)$ 上的像称为 **Heegner 点**，是现代计算 BSD 特殊值（第 16 篇）的核心工具。

### 补充：$X_0(p)$ 亏格公式的两个实例

对素数 $p$，$X_0(p)$ 的亏格有显式公式（用 Kronecker 符号）：

$$g\big(X_0(p)\big) = \frac{p+1}{12} - \frac14\Big(1 + \Big(\tfrac{-4}{p}\Big)\Big) - \frac13\Big(1 + \Big(\tfrac{-3}{p}\Big)\Big)$$

（取整由「$p+1$ 的整除性 + 两个校正项」自动处理。）

**$p = 11$**：$\big(\frac{-4}{11}\big) = \big(\frac{-1}{11}\big)\cdot 1 = -1$（$11 \equiv 3 \pmod 4$），第一校正项为 0；$\big(\frac{-3}{11}\big) = \big(\frac{-1}{11}\big)\big(\frac{3}{11}\big) = (-1)\cdot 1 = -1$（$11 \equiv -1 \pmod{12}$，故 $(3/11)=1$），第二校正项为 0。于是

$$g\big(X_0(11)\big) = \frac{12}{12} - 0 - 0 = 1$$

**$p = 37$**：$\big(\frac{-4}{37}\big) = 1$（$37 \equiv 1 \pmod 4$），$\big(\frac{-3}{37}\big) = 1$（$37 \equiv 1 \pmod{12}$），于是

$$g\big(X_0(37)\big) = \frac{38}{12} - \frac12 - \frac23 = 2$$

**两条结论**：其一，$X_0(11)$ 亏格 1，本身就是一条椭圆曲线（导子 11）——它是「模曲线自身是椭圆曲线」的经典例子，也是第 17 篇模性定理的可验证样板；其二，亏格随 $p$ 以约 $p/12$ 的速度增长，「小 $p$ 亏格 0」才允许 $X_0(p)$ 上有无穷多个有理点——这正是 Mazur 定理「$N$ 最多到 12（外加 $2m$ 型）」的几何根源。

## 6 小结

- **$j = 1728\,c_4^3/\Delta$ 是完全同构不变量**：两曲线同构 $\iff$ $j$ 相等；$j=0, 1728$ 是特殊的对称点。
- $j$ 是**模函数**（权 0），它把 $\mathfrak{h}/SL_2(\mathbb{Z})$ 双全纯地映到 $\mathbb{P}^1$。
- **模曲线** $X_0(N)$ 分类「椭圆曲线 + $N$-级循环子群」，是模性定理与同源理论的几何舞台。
- 亏格公式 $g(X_0(N)) \approx N/12$ 把「几何复杂度」与「算术有限性」挂钩（Mazur 定理的引擎）。
- 从 $j$ 到 Heegner 点：一个不变量贯穿几何、算术与解析三条主线。
