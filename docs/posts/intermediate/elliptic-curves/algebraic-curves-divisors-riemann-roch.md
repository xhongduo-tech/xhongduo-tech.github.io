## 为什么从代数曲线开始

椭圆曲线是一切数论几何的对象之王，但「王座」之下必须先有地基：**代数曲线**。椭圆曲线本身正是一条亏格为 1 的光滑射影代数曲线，它上面的加法结构、L-函数、模形式，全部都是「曲线」这个几何对象的算术投影<span class="marginnote">「算术投影」不是一个专业术语，而是本文的一句私房话：几何对象放在不同数域上观察，会露出完全不同的算术面孔——这正是 Silverman 全书「算术化」的起点。</span>。本节作为整个专题的第一次行军，只做一件事：把「曲线上的函数能长成什么样」这个问题用**除子（divisor）**这个工具彻底算清楚，而答案就是 Riemann-Roch 定理。它是整座椭圆曲线大厦的承重墙——Mordell-Weil 定理、Weil 配对、BSD 猜想，每一处都绕不开它。<span class="marginnote">这套语言源自十九世纪黎曼与罗赫（Gustav Roch）的时代；我们在此按 Silverman《椭圆曲线的算术》第 II 章的现代代数几何语言重述。</span>

## 1 射影平面与曲线

### 为什么必须是射影的

中学里曲线是「$y^2 = x^3 + Ax + B$ 这样的平面图像」。但若要给曲线赋予良好的算术性质，必须把它放进**射影平面** $\mathbb{P}^2$：即 $\mathbb{A}^3 \setminus \{0\}$ 中「相差非零常数倍的全体」——等价类 $[X : Y : Z]$，其中 $(X,Y,Z) \neq (0,0,0)$，且 $(X,Y,Z) \sim (\lambda X, \lambda Y, \lambda Z)$。

**关键动机**：射影平面里，两条直线总是相交（即使在无穷远），Bezout 定理才有干净的陈述。一条次数为 $d$ 的平面曲线由齐次多项式 $F(X,Y,Z) = 0$ 给出，而无穷远点恰好落在 $Z = 0$ 的「地平线」上。<span class="marginnote">射影平面之所以重要，是因为它补齐了「无穷远」这个我们看不见的成员：椭圆曲线真正重要的点——加法群中的单位元 $O$——正是那个藏在 $Z=0$ 地平线上的无穷远点。把 $O$ 收进来，曲线才「闭合」为紧致黎曼面，Riemann-Roch 才能起作用。</span>

### 函数域与光滑性

一条曲线 $C$ 上的**有理函数**是 $k(X,Y,Z)$ 中分母不恒为零的商，限制到 $C$ 上所得；全体这样的函数构成一个域 $k(C)$，叫 **函数域（function field）**。它是曲线的算术心脏：

**曲线 $C$ 是光滑（非奇异）的**，当且仅当在每个点上，三个偏导 $\partial F/\partial X,\ \partial F/\partial Y,\ \partial F/\partial Z$ 不全为零。<span class="marginnote">「光滑」的直观是：曲线上每点都有唯一切线。奇点（尖点、结点）会把曲线变成另一类对象——比如尖点曲线 $y^2=x^3$ 的算术行为与椭圆曲线截然不同，后面讲 Weierstrass 方程时会专门辨析。</span>一个经典事实是：**光滑射影曲线 $\leftrightarrow$ 紧致黎曼面 $\leftrightarrow$ 函数域**，三者互为翻译。亏格（genus）$g$ 就藏在函数域里，Riemann-Roch 正是它的「探测器」。

## 2 除子：把点涂成加权和

### 除子的定义

设 $C$ 是亏格为 $g$ 的光滑射影曲线。一个**除子（divisor）** $D$ 是 $C$ 上形式有限整系数线性组合：

$$D = \sum_{P \in C} n_P [P], \qquad n_P \in \mathbb{Z}, \text{ 仅有限多个非零}$$

它的**次数**定义为 $\deg D = \sum_P n_P$。<span class="marginnote">把除子想象成「在点上的计分牌」：正系数记「极点配额」，负系数记「零点配额」，没出现的点系数为 0。它把几何对象上的点转化为可代数运算的纯组合对象。</span>

每个非零有理函数 $f \in k(C)^*$ 都给出一个除子

$$\operatorname{div}(f) = \sum_P \operatorname{ord}_P(f)\,[P]$$

其中 $\operatorname{ord}_P(f)$ 是 $f$ 在点 $P$ 处的零/极重数（零点为正，极点为负）。这样的除子称为**主除子（principal divisor）**，全体主除子构成一个加法子群 $\mathrm{Prin}(C)$。

**核心结论（次数定理）**：$\deg \operatorname{div}(f) = 0$——函数零点总数等于极点总数。这是「有理函数在紧致曲面上值域的平衡律」，也是 Riemann-Roch 的先行曲。

### 除子类群

把「相差一个主除子」的两个除子看成同一个，商群

$$\mathrm{Pic}^0(C) = \{\text{次数为 } 0 \text{ 的除子}\} \big/ \mathrm{Prin}(C)$$

叫做 **Picard 群 / 除子类群**。<span class="marginnote"><strong>Picard 群</strong>这个名字同时指向两位先驱：Émile Picard 给出了椭圆曲线除子类群的参数化，而这套「模函数取商」的思想正是 Jacobi 与 Abel 时代曲线积分理论的代数化。对椭圆曲线，$\mathrm{Pic}^0(E) \cong E(k)$——除子的世界与点本身的世界合流了，这正是第三篇「几何加法」背后的代数真相。</span>对椭圆曲线，Picard 群与曲线点集同构，这一事实把「几何上的点」和「代数上的除子」焊接在一起。

## 3 Riemann-Roch 定理

### 线丛的语言

给定除子 $D = \sum n_P[P]$，定义**Riemann-Roch 空间**为

$$L(D) = \big\{ f \in k(C)^* : \operatorname{div}(f) + D \geq 0 \big\} \cup \{0\}$$

直觉：$L(D)$ 是「在 $D$ 的负系数点（零点配额）处允许有多好极点」的函数全体。它是个有限维向量空间，记 $\ell(D) = \dim_k L(D)$。

**定理（Riemann-Roch）**：设 $K$ 是**典范除子（canonical divisor）**——即全纯微分形式空间的任何非零元素对应的除子，则对任意除子 $D$ 有

$$\ell(D) - \ell(K - D) = \deg D + 1 - g$$

其中 $g$ 是曲线的亏格。<span class="marginnote">这是整个代数几何里最值得被记住的一条定理之一。左端两个空间维数的差，右端是两个纯数：次数与亏格。它把一个看似高深的「函数空间有多大」问题，降维成了一个小学算术问题。</span>

**辨析｜易错点：** 初学者常把公式记成 $\ell(D) = \deg D + 1 - g$ 而漏掉 $\ell(K-D)$。这第二项才是定理的「灵魂」：它精确描述了误差——当 $D$ 的次数很大时第二项消失（此时 $K-D$ 次数为负，$L(K-D) = 0$），而当 $D$ 很小时第二项由对偶性补足。**漏掉 $\ell(K-D)$，你就把定理从「精确恒等式」降格成了「渐进近似」，这在正数域上是灾难性的。**

### 亏格与微分

取 $D = 0$，Riemann-Roch 给出 $\ell(K) = g$：**亏格就是全纯微分的维数**，也就是曲线这个黎曼面的「洞」的个数。这条恒等式是几何直觉进入算术的入口。

## 4 公式解析：$L(D)$ 的维度怎么算

用一条具体的椭圆曲线走一遍，把抽象公式变成能上手算的算法。

$$
E:\ y^2 = x^3 + Ax + B,\qquad P = [0:1:0]\text{ 是唯一无穷远点}
$$

- **第一步，认点**：$E$ 是亏格 $g=1$ 的光滑射影曲线，除子在 $E$ 上是「有限个点的整数线性组合」。
- **第二步，取 $D = 2[P]$**：$L(2[P])$ 由「在 $P$ 处至多二重极点、其他点全正则」的函数构成。$x$ 有双重极点 $[x] \sim 2[P]$，$y$ 有三重极点 $[y] \sim 3[P]$，常数 1 无极点。因此 $L(2[P]) = \mathrm{span}\{1, x\}$，$\ell(2[P]) = 2$。
- **第三步，核对公式**：$\deg D = 2$，$g = 1$。因为 $\deg(K) = 2g - 2 = 0$，且 $K - 2[P]$ 的次数为负，故 $\ell(K - 2[P]) = 0$。于是
$$\ell(2[P]) - 0 = 2 + 1 - 1 = 2 \quad \checkmark$$
- **第四步，观察规律**：$\ell(n[P])$ 随 $n$ 的序列是 $1, 1, 2, 3, 4, \dots$——从 $n=2$ 开始每加一个 $P$ 维度就加一，唯独 $n=0, 1$ 卡住不动。这个「卡住的两格」正是亏格 $g=1$ 的指纹：**对椭圆曲线，缺口大小恒等于亏格**。它告诉我们为什么椭圆曲线能塞进 $\mathbb{P}^2$ 且方程只有三项——$x,y$ 的极点阶数 $2,3$ 与 $g=1$ 精确匹配。

## 5 Riemann-Roch 在椭圆曲线上的三条金牌推论

- **推论一（嵌入）**：$\ell(n[P]) = n$ 对一切 $n \geq 1$ 成立，$n = 2,3$ 的函数给出 $x,y$，从而 $E$ 可写进 $\mathbb{P}^2$ 成为三次曲线——**亏格 1 的曲线自动是三次平面曲线**。
- **推论二（Picard）**：$\mathrm{Pic}^0(E) \cong E(k)$，映射 $[P] - [O] \mapsto P$ 是群同构。**除子的商群与点本身「长得一模一样」**，这让「点的加法」等价于「除子的加法」。
- **推论三（加法器）**：对任意两个点 $P,Q$，除子 $[P] + [Q]$ 与 $[P+Q] + [O]$ 差一个主除子。它直接给出几何加法的正确性证明——**第三篇《椭圆曲线上的几何加法》的全部内容，其实是本节的推论**。<span class="marginnote">这三个推论把「曲线几何」「函数代数」「群结构」捏成一个整体。理解了第三条，你就理解了为什么「三点共线」能定义群律：因为三次曲线与直线交于三点，这三点对应的除子恰好是一个主除子。</span>

### 补充：典范除子——「微分」的字典

Riemann-Roch 里的 $K$ 不是凭空出现的，它是「微分的除子」：对任意亚纯微分 $\omega$（局部坐标下写成 $\omega = g(z)\,dz$），定义

$$\operatorname{div}(\omega) = \sum_P \operatorname{ord}_P(\omega)\,[P], \qquad \operatorname{ord}_P(g\,dz) = \operatorname{ord}_P(g) + \epsilon_P$$

其中 $\epsilon_P$ 是「$dz$ 在 $P$ 处的极点贡献」。**定理：对任意非零微分 $\omega$，$\deg\operatorname{div}(\omega) = 2g - 2$**——这是 Riemann-Hurwitz 公式的微分版本，亏格在这里第一次以「次数」的面目出现。

对椭圆曲线 $g = 1$，$2g - 2 = 0$，一切微分的除子次数为 0。具体地，$E: y^2 = x^3 + Ax + B$ 上的不变量微分

$$\omega = \frac{dx}{2y + a_1 x + a_3} = \frac{dx}{2y}$$

处处无零无极点，$\operatorname{div}(\omega) = 0$——所以「$K$ 是次数为 0 的除子」在椭圆曲线上是字面为真的。全纯微分构成的空间 $L(K)$ 恰好是 $\mathbb{C}\cdot\omega$，一维，与 $\ell(K) = g = 1$ 吻合。

**这条字典的深意**：模曲线 $X_0(N)$ 上的全纯微分恰是**权 2 的尖点形式**——「微分」与「模形式」的首次相遇就藏在这个定义里。第 10 篇的 $S_2(\Gamma_0(N))$ 就是「$X_0(N)$ 上的全纯微分空间」，而 Riemann-Roch 正是数它的维数的工具。

## 6 小结

- 椭圆曲线的正确舞台是**射影平面**，无穷远点 $[0:1:0]$ 是加法群的单位元。
- **除子**是点的有限整系数组合，次数定理说主除子的次数为 0；**Picard 群**是次数零除子模主除子。
- **Riemann-Roch 定理** $\ell(D) - \ell(K-D) = \deg D + 1 - g$ 把函数空间维度降维成次数与亏格的算术。
- **亏格 = 全纯微分维数**，椭圆曲线亏格 $g=1$，故它是三次平面曲线。
- **$\mathrm{Pic}^0(E) \cong E$**：除子的世界与点的世界重合，几何加法的正确性来自 Riemann-Roch。

在下一节，我们将正式把曲线写成 **Weierstrass 方程** $y^2 = x^3 + Ax + B$，并把「三点共线」翻译成一个真正满足结合律的群律——这是椭圆曲线第一次以「群」的完整姿态登场。
