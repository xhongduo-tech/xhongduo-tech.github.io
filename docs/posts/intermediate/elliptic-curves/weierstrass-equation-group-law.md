## 为什么从 Weierstrass 方程开始

上一篇我们用 Riemann-Roch 证明了亏格 1 的曲线自动是三次平面曲线。但要真正上手算，我们需要一个**统一标准方程**。Weierstrass 方程就是这份合同：它把所有椭圆曲线「装进」同一个模具，让加法的公式、约化的理论、L-函数都有了共同的坐标起点。<span class="marginnote">这个名字致敬 Karl Weierstrass：他在 19 世纪证明 $\wp$-函数满足一个形如 $(\wp')^2 = 4\wp^3 - g_2\wp - g_3$ 的微分方程——方程里藏着一个密码，今天这个专题的每一篇都在破译它。</span>本节的任务：从一般三次式归约到标准形，并完整写出那个著名的「弦与切线」群律，证明它满足结合律。

## 1 从三次曲线到 Weierstrass 标准形

### 一般形式

椭圆曲线 $E$ 定义在特征 $\neq 2,3$ 的域 $k$ 上时，可化为标准 **Weierstrass 方程（Weierstrass equation）**：

$$E: \quad y^2 = x^3 + Ax + B, \qquad A, B \in k$$

它的射影化是齐次式 $Y^2 Z = X^3 + AXZ^2 + BZ^3$，唯一的无穷远点是 $O = [0:1:0]$。<span class="marginnote">为什么能化成这样？因为坐标变换自由度足够：用 $x \leftarrow x' + $ 平移、$y \leftarrow y' + $ 缩放，把一般三次式的 $x^2$ 项消掉、把 $xy$ 项消掉，只留 $x^3, xy^2, y^2, x, y$ 六项，再归一化系数。Silverman 第 III 章给出完整过程——这是一次纯代数的「配方」，类似把一元二次式配方成标准形。</span>

### 判别式与光滑性

定义两个基本不变量：

$$\Delta = -16\,(4A^3 + 27B^2), \qquad j = -1728 \cdot \frac{4A^3}{4A^3 + 27B^2}$$

**重点：$E$ 光滑（非奇异）当且仅当 $\Delta \neq 0$。** 判别式是这条曲线的「体检指标」：它不为零，则曲线处处有切线，可做群律；它为 0，则出现尖点或结点，对象就「病了」。

**辨析｜易错点：** $\Delta$ 为零意味着什么？- 当 $4A^3 + 27B^2 = 0$ 且 $A \neq 0$：曲线在 $(x, y) = (3B/A, 0)$ 处有一个**结点（node）**，两条切线，判别式为 0，但曲线仍「半光滑」；- 当 $A = B = 0$（即 $y^2 = x^3$）：在 $(0,0)$ 处出现**尖点（cusp）**，一条切线，更严重。**二者都不能承载群律**——因为群律要求「直线与三次曲线恒交于三点」，而尖点曲线上交点计数会失真。这是初学阶段最常栽的坑：看到 $y^2=x^3$ 就当成椭圆曲线。

## 2 群律的构造：弦与切线

### 几何规则

在光滑三次曲线上定义加法，规则只有一句话：**不共线的三点、或其连线的构造，决定了和。**

设 $P, Q$ 是 $E(k)$ 上两点（允许 $P=Q$ 或 $P=O$）：

- **弦规则（$P \neq Q$）**：过 $P,Q$ 的直线与 $E$ 交于第三点 $R$（由 Bezout，次数为 3 的曲线与直线恰有 3 个交点，计重数）。定义 $P + Q$ 为 $R$ 关于 $x$-轴的反射点 $-R$。
- **切线规则（$P = Q$）**：$P+P$ 用 $P$ 处切线替代弦，切线与 $E$ 交于 $R$，定义 $2P$ 为 $-R$。
- **与无穷远点**：$O$ 是单位元，$P + O = P$；且 $P + (-P) = O$，其中 $-P$ 是 $P$ 关于 $x$-轴的反射。<span class="marginnote">为什么反射点不参与「交点计数」的加法？因为三次方程 $f(x,y)=0$ 与直线的交点中，$y$ 方向的三次根与反射一一对应。把反射后的点记为和，恰好保证了 $P + (-P) = O$——唯一需要引入无穷远点的场合。</span>

这套规则给出一个**阿贝尔群**：单位元 $O$，逆元 $-P$，交换律来自「同一根弦」，而**结合律需要证明**——它不平凡，是整个构造最深的性质。

### 坐标公式

把几何规则翻译成坐标，就是初中代数水平的机械化公式。设 $P_1 = (x_1, y_1), P_2 = (x_2, y_2)$：

- 若 $x_1 = x_2$ 且 $y_1 = -y_2$（或 $P_2 = O$），则 $P_1 + P_2 = O$；
- 否则记
$$\lambda = \begin{cases} \dfrac{y_2 - y_1}{x_2 - x_1} & (P_1 \neq P_2) \\[8pt] \dfrac{3x_1^2 + A}{2y_1} & (P_1 = P_2) \end{cases}$$
则
$$x_3 = \lambda^2 - x_1 - x_2, \qquad y_3 = \lambda(x_1 - x_3) - y_1$$

**辨析｜易错点：** 切线情形分母 $2y_1$——若 $y_1 = 0$ 则 $\lambda$ 无定义，此时点 $P_1$ 满足 $P_1 + P_1 = O$（2-挠点）。初学者常忘掉这个「垂直切线」特例：**$2P = O$ 当且仅当 $y = 0$，曲线上的四个 2-挠点正是 $O$ 与三个 $y=0$ 的横坐标点**。

## 3 结合律的三种证明视角

为什么弦与切线法给出的运算满足结合律？这是椭圆曲线加法的「隐藏定理」，Silverman 用三种语言给出证明：

1. **Riemann-Roch 视角（最本质）**：上一篇已埋下伏笔——$[P]+[Q]$ 与 $[P+Q]+[O]$ 差一个主除子。对三个点，$(P+Q)+R$ 与 $P+(Q+R)$ 对应同一个除子类，而 Picard 群是交换群，故结合律是「除子类群的交换性」在点语言下的回响。<span class="marginnote">这是最深刻的解释：<strong>群律的每一步其实发生在 $\mathrm{Pic}^0(E)$ 里，点只是除子类群的参数化</strong>。几何加法之所以成立，是因为除子类群天生是阿贝尔群。</span>
2. **解析视角**：用复分析，$E(\mathbb{C}) \cong \mathbb{C}/\Lambda$ 是环面，加法就是复数的加法，结合律自动成立——这在第 15 篇《复结构与一致化》正式展开。
3. **纯代数视角**：直接对坐标公式做计算——两个分式加一个恒等式，暴力展开后所有交叉项抵消。这是「丑但可靠」的证明，也是计算机代数验证群律的标准方式。

## 4 公式解析：切线斜率 $\lambda$

在群律中，几乎一切的算术复杂度都浓缩在这一个量里。

$$
\lambda = \frac{3x_1^2 + A}{2y_1} \qquad (P_1 = P_2)
$$

- **第一步，来源**：$2P$ 的弦退化为切线，斜率等于曲线 $y = \pm\sqrt{x^3+Ax+B}$ 在 $P_1$ 处的导数。隐式求导：$2y\,y' = 3x^2 + A$，故 $y' = (3x^2 + A)/(2y)$——分子恰是 $3x_1^2 + A$。
- **第二步，几何意义**：$\lambda$ 是切线的斜率，因此切点 $P_1$ 是一个「二重交点」：直线与 $E$ 在 $P_1$ 处相切，再与 $E$ 交于另一个点 $R$。由于是相切，Bezout 计数里 $P_1$ 计了 2 次。
- **第三步，算术意义**：$\lambda$ 的分母 $2y_1$ 蕴含了「病态检测」——若 $y_1 = 0$，斜率无限大，切线与曲线在无穷远相交，于是 $2P_1 = O$。**$y_1 = 0$ 恰好是 $x_1^3 + Ax_1 + B = 0$ 的根，至多 3 个，对应 3 个非平凡 2-挠点。**
- **第四步，域敏感度**：当 $k$ 是有限域 $\mathbb{F}_q$，$2y_1$ 可能为 0 模 $q$ 而 $y_1 \neq 0$ 在有理数意义下——这导致 $E(\mathbb{F}_q)$ 的奇偶性问题，直接影响密码学中点的阶。**群律公式在有限域上「更危险」，因为除零的发生更频繁**——这是密码学界每年论文不断的根源之一。

## 5 简并 Weierstrass 方程与一般域

- **特征 2 或 3 的情形**：$x^2$ 与 $xy$ 项无法用同样的配方消去，标准形换成
$$E:\ y^2 + a_1xy + a_3y = x^3 + a_2x^2 + a_4x + a_6$$
这称为**一般（长）Weierstrass 方程**，它在特征 2 的域上无可避免。<span class="marginnote">历史上这六个系数 $a_1,\dots,a_6$ 是 Silverman 全书的标准记号；下标 1,2,3,4,6 对应「$x,y$ 的次数」——$a_1$ 跟着 $xy$（总次数 2+1=3? 不，是按加权齐次：$\deg x = 2, \deg y = 3$，故 $xy$ 的权是 $5$，而记 $a_1$ 表示它「少了一项」——细节见 Silverman §III.1。这里是历届读者最常迷路的记号陷阱。</span>
- **$\mathbb{Q}$ 上的积分性**：对 $E(\mathbb{Q})$ 的算术理论，总可把 $A,B$ 取成整数，且 $A,B$ 的整数性在约化理论里至关重要——第 6 篇《约化理论》会看到，判别式的素因子精确刻画约化类型。

### 补充：一次完整的群律手算——$y^2 = x^3 + 1$ 上的 6-挠循环

纸上演算永远比公式更让人安心。取 $E: y^2 = x^3 + 1$（$\mathbb{Q}$ 上），验证群律公式在三个点上的全部情形。

**弦情形**：$P = (0,1)$，$Q = (2,3)$。$\lambda = \frac{3-1}{2-0} = 1$，于是

$$x_{P+Q} = 1^2 - 0 - 2 = -1, \qquad y_{P+Q} = 1\cdot(0 - (-1)) - 1 = 0$$

所以 $P + Q = (-1, 0)$——它落在 $x$-轴上，是一个 2-挠点。

**切线情形**：在 $P = (0,1)$ 处，$\lambda = \frac{3\cdot 0^2}{2\cdot 1} = 0$（切线水平），于是 $2P = (0, -1)$，恰为 $-P$。这说明 $P$ 是 3-挠点。

**综合**：$Q = (2,3)$ 的阶是多少？$2Q = (0,1) = P$，$3Q = P + Q = (-1,0)$，$6Q = 2\cdot 3Q = 2\cdot(-1,0) = O$（$y=0$ 处切线竖直）——**$Q$ 是 6-挠点，$E(\mathbb{Q}) \supseteq \mathbb{Z}/6$**。事实上 $E(\mathbb{Q}) \cong \mathbb{Z}/6$（Mazur 名单中的一个成员）。

**三个观察**：其一，全部运算留在 $\mathbb{Q}$ 中——「群律不离开数域」在手指间得到验证；其二，退化情形（$y=0$、$-P$、竖直线）逐一登场，全靠回到公式而非几何直觉；其三，一个 6 阶循环的完整生命周期，只用了小学级别的算术。若读者把这组计算推广到有限域 $\mathbb{F}_p$ 上（把除法换成「乘以模 $p$ 的逆元」），就得到密码学里真正使用的「标量乘法」——**群律公式在哪，密码学就在哪**。

顺带一提，这个例子还展示了**拐点**的几何：$(0,1)$ 是曲线的拐点（切线三重相切），而拐点在群律下恰是 3-挠点——**「三重切线的点」与「$3P = O$ 的点」是同一件事**。这条观察在判断挠点时能省下不少计算。

## 6 小结

- 椭圆曲线的**标准形**是 $y^2 = x^3 + Ax + B$，光滑性等价于判别式 $\Delta = -16(4A^3 + 27B^2) \neq 0$。
- **群律**由「弦与切线」定义：三点共线的第三点反射即为和，$O$ 是单位元，$-P$ 是 $x$-轴反射。
- 群律满足结合律，最本质的证明来自**除子类群**；坐标公式机械化但要注意除零陷阱。
- $j$-不变量 $j = -1728\cdot 4A^3/\Delta$ 是同构不变量——下一节还会反复用到。
- 特征 2、3 的域需要**长 Weierstrass 方程**，记号陷阱要多加小心。

在下一节，我们将从「弦与切线」的规则走向它的几何直觉：**椭圆曲线上的几何加法**——为什么这条曲线恰好允许这样美丽的构造，以及它与圆、与代数的关系。
