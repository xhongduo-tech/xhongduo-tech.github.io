## 为什么从形式群开始

椭圆曲线的群律是**整体**的构造：它活在射影平面上，跨域通用。但算术问题常常是**局部**的——一个素数 $p$ 之下，点靠得有多近？挠点的阶在 $p$-进意义下多大？回答这类问题，需要一个「用幂级数把群律展开到无穷原点附近」的显微镜：**形式群（formal group）**。<span class="marginnote">「形式」二字在代数几何里指「只按幂级数的形式运算，不关心收敛性」：我们对手上的级数既不做收敛半径分析，也不要求它代表真函数，只要运算规则自洽。这是 1950 年代 Bochner、Lazard 与 Honda 发展起来的机器，Silverman 第 IV 章是教科书级的标准阐述。</span>本节建立三条主线：形式群律的定义、椭圆曲线的形式群如何来自群律在 $O$ 附近的展开、以及**形式对数（formal logarithm）**这把「局部尺子」如何度量点的阶。

## 1 形式群律：把群运算写进幂级数

### 定义

设 $R$ 是（交换）环。$R$ 上的**一维形式群律（one-dimensional formal group law）**是二元幂级数

$$F(X, Y) = X + Y + \text{（次数 } \geq 2 \text{ 的项）} \in R[[X, Y]]$$

满足三组公理（对应群的三条性质）：

- **结合律**：$F(F(X,Y),Z) = F(X, F(Y,Z))$；
- **单位元**：$F(X, 0) = X = F(0, X)$；
- **逆元**：存在 $i(X) \in R[[X]]$ 使 $F(X, i(X)) = 0$。<span class="marginnote">单位元与逆元的公理可以组合改写：因为 $F = X + Y + O(2)$，单位元 0 是明显的，逆元由 $i(X) = -X + O(2)$ 唯一确定——所以「形式群」本质上只剩结合律这一条深约束。结合律是「系数之间无穷多个多项式方程」，让它在所有环 $R$ 上都成立时，$F$ 的结构会非常受限。</span>

两个典型例子：加法形式群 $\widehat{\mathbb{G}}_a(X,Y) = X + Y$，乘法形式群 $\widehat{\mathbb{G}}_m(X,Y) = X + Y + XY$。

**辨析｜易错点：** 形式群律的系数**只保证到一阶线性项** $X + Y$。初学时常误以为 $F(X,Y)$ 就是「坐标加法」，但它实际描述的是「在原点附近、忽略高阶项之后的局部加法」——每一项高次系数都编码了曲线在该点的曲率信息。**它不是近似，而是精确的幂级数恒等式；「近似」的错觉来自级数只展开到低阶时。**

### 形式对数与形式指数

给定形式群 $F$，若有系数在 $R \otimes \mathbb{Q}$ 中的幂级数

$$f(T) = T + O(T^2), \qquad f(F(X,Y)) = f(X) + f(Y)$$

则 $f$ 称为 $F$ 的**形式对数（formal logarithm）**；其形式逆 $g = f^{-1}$ 称为**形式指数（formal exponential）**，满足 $g(x+y) = F(g(x), g(y))$。<span class="marginnote">形式对数把「椭圆曲线的局部加法」翻译成「普通的加法」——这正是复分析里对数函数的代数类比：对数把乘法变成加法，形式对数把形式群变成加法形式群。Silverman 第 IV 章证明：<strong>只要特征为 0，形式对数一定存在且唯一</strong>；在特征 $p$ 下它可能不存在（障碍由 Hasse 不变量度量）。</span>

## 2 椭圆曲线的形式群：在无穷远点附近展开

### 局部坐标

椭圆曲线 $E: y^2 = x^3 + Ax + B$ 的无穷远点 $O$ 处，坐标 $z = -x/y$ 是一个**一致化参数**（局部坐标）。在 $z$ 里，曲线上靠近 $O$ 的点可以写成

$$w(z) = z^3 \cdot (1 + a_1 z + a_2 z^2 + \cdots)$$

即 $y = 1/w$ 由 $z$ 的幂级数表达。<span class="marginnote">为什么 $z = -x/y$ 在 $O$ 处是局部坐标？因为 $x$ 在 $O$ 有二重极点、$y$ 有三重极点，比值 $x/y$ 的极点阶数为 $2-3 = -1$，即 $z$ 在 $O$ 处有一阶零点——零点的阶数为 1，正是「一致化参数」的定义。这一小段「权数」计算与第一篇 Riemann-Roch 的记号体系一脉相承。</span>

### 群律的幂级数化

把几何加法公式代入 $z$ 坐标，得到椭圆曲线的**形式群律**

$$\widehat{E}(z_1, z_2) \in \mathbb{Z}[A, B][[z_1, z_2]]$$

它是 $z_1 + z_2$ 加上高次项的形式幂级数，**系数是 $A, B$ 的整数多项式**。这是一条了不起的「整性」性质：虽然群律公式里出现除法（斜率 $\lambda$ 的分母），但在好的坐标下展开后，除法全部消失了。

**重点：形式群律的系数属于 $\mathbb{Z}[A,B]$** ——这意味着无论把曲线约化到哪个有限域 $\mathbb{F}_p$，这个幂级数都能「降下去」，从而在约化曲线 $E/\mathbb{F}_p$ 上也能谈论「原点附近的局部加法」。这是第 6 篇约化理论里 $p$-进挠点的语言基础。

## 3 形式群如何度量点：$p$-进挠点的尺子

### 基本工具：$p$-进赋值

把一切放在 $p$-进数域 $\mathbb{Q}_p$ 上看，整数环为 $\mathbb{Z}_p$。对 $z \in p\mathbb{Z}_p$，定义其**赋值** $v_p(z)$ =「$z$ 被 $p$ 整除的次数」。形式群在 $p\mathbb{Z}_p$ 上有「收敛」的含义：把 $z$ 代进幂级数，只要取收敛半径内的值，$\widehat{E}(z_1, z_2)$ 就给出 $\mathbb{Z}_p$ 中一个元素。<span class="marginnote">这里「收敛」与第 4 节说的「形式（不关心收敛）」并不矛盾：形式群律本身是代数对象；但当我们在 $p$-进域上把它当函数用时，收敛性给出 $p\mathbb{Z}_p$ 上的真群结构。两种视角共享同一幂级数，是「算术的代数面与解析面」的一次合流。</span>

设 $z_0 = 0, z_{n+1} = \widehat{E}(z_n, z_0')$ 表示把 $z_0$ 与自己加 $n$ 次的结果（记作 $[n](z_0)$）。**形式群乘法** $[n](T)$ 是另一个幂级数，满足 $[n] \circ [m] = [nm]$。

### 关键引理

设 $p$ 是素数，$z \in p\mathbb{Z}_p$ 非零。记 $\nu = v_p(z)$。若 $z$ 是 $p^n$-挠元（$[p^n](z) = 0$），则

$$\nu \leq \frac{1}{p^{n-1}(p-1)} \cdot v_p(\text{判别式相关量}) \quad \text{（上界形式）}$$

而在好的情形（$E$ 有**好的约化**，见第 6 篇）下，$z \neq 0$ 是 $p^n$-挠元的**充要条件**是 $v_p(z) = \frac{1}{p^{n-1}(p-1)}$。<span class="marginnote">这条「赋值等于某分数」的结论被称为形式群的核心引理（Silverman IV.6 引理 6.1、6.2）。它的意义是：$p$-进挠点的阶被「离原点多远」精确控制——近到一定程度必然被 $p$ 杀死，这正是「局部衡量整体」的范例。它与后面第 7 篇 Nagell-Lutz 定理互为局部/整体表兄弟。</span>

### 与形式对数的关系

在特征 0 情形，形式对数把加法变成普通加法：$f(\widehat{E}(X,Y)) = f(X) + f(Y)$，于是 $f([n](z)) = n f(z)$。若 $[p^n](z) = 0$，则 $p^n f(z) = 0$，结合赋值性质可推出 $f(z)$ 的赋值必为 $p^{-n}(p-1)^{-1}$ 型——**形式对数把「$z$ 是 $p^n$-挠元」翻译成「$f(z)$ 的 $p$-进阶恰好是某个分数」**，这是理解 $p$-进挠点结构的钥匙。

## 4 公式解析：椭圆曲线的形式对数

用 $E: y^2 = x^3 + Ax + B$（$A,B \in \mathbb{Z}$，$\Delta \neq 0$）实际算一遍形式对数的前几项。

$$
f(T) = T + \frac{1}{2}a_1 T^2 + \frac{1}{3}\left(a_1^2 + a_2\right) T^3 + \cdots
$$

（在标准形 $a_1 = a_2 = 0$ 时，$f(T) = T - \frac{1}{5}\cdot\frac{A}{1} T^5 + O(T^7)$，首项更简洁。）

- **第一步，起点**：形式对数要求 $f(T) = T + O(T^2)$ 且把 $\widehat{E}$ 变成普通加法。逐次比较系数：因为 $\widehat{E}(X,Y)$ 的二次项是 $X^2 + XY + Y^2$ 的某整数倍，取 $f(T) = T + cT^2$ 代入 $f(\widehat{E}) = f(X) + f(Y)$，比较 $T^2$ 项即可解出 $c$——这就是一般公式里「$\frac{1}{2}a_1$」的来源。
- **第二步，为什么系数分母开始出现**：解线性方程组时会出现「除以整数」：系数里的 $1/2, 1/3$ 表明形式对数在**整数环上并不存在**，只存在于 $\mathbb{Q}$ 上（分母是特征 0 的记号）。这与「形式群律系数在 $\mathbb{Z}$ 上」形成对照：**群律在整环上就存在，对数要到有理数域上才有**。
- **第三步，标准形下的形态**：当 $A = B$ 为整数的 $y^2 = x^3 + Ax + B$，$a_1 = a_2 = 0$，形式对数首项后第一个非零项是 $T^5$ 项，系数为 $-A/5$。这个「$T^5$ 的消失」不是巧合——它是曲线在 $O$ 处「局部坐标规范化」的产物，而系数 $-A/5$ 将出现在第 10 篇 Eisenstein 级数的展开系数 $E_2, E_4$ 附近。
- **第四步，物理解读**：形式对数告诉我们「在无穷远点附近，椭圆曲线看起来就像加法群」——但要在对数坐标里看。**$z$ 与 $f(z)$ 的关系，就是曲线局部「拉直」的变换**。它是复分析里 $E(\mathbb{C}) \cong \mathbb{C}/\Lambda$ 的局部版（第 15 篇）：整体的一致化对应全局 $\wp$-函数，局部的一致化对应这里的形式对数。

## 5 形式群在算术中的三大应用

- **$p$-adic 挠点分类**：$E[p^n]$ 在好的约化下的大小与结构，可由形式群在 $p\mathbb{Z}_p$ 上的核刻画（第 6 篇展开）。
- **Mordell-Weil 高度理论**：Silverman 对高度函数的构造中，形式群给出「局部高度」在无穷远点附近的精确渐近，是第 7 篇 descent 论证的组成部分。
- **BSD 与 zeta 数据的局部项**：Tamagawa 数与 $L$-函数的局部因子都依赖约化类型，而约化类型的判断（第 6 篇）经常先落到形式群上观察——**形式群是「约化理论」这座建筑的底层砖**。<span class="marginnote">一个直观的总结：形式群把「椭圆曲线在素数 $p$ 处的局部行为」浓缩成一串整系数幂级数；算术问题只要落到 $p$ 上，就能用这串级数无穷地精确逼近。</span>

### 补充：Hasse 不变量——特征 $p$ 下形式对数的「生死开关」

特征 0 中形式对数 $f$ 存在且唯一；特征 $p$ 却可能「死掉」。障碍由 **Hasse 不变量**度量：对标准形 $E: y^2 = x^3 + Ax + B$ 于 $\mathbb{F}_p$，定义 $H \in \mathbb{F}_p$ 为 $(x^3 + Ax + B)^{(p-1)/2}$ 中 $x^{p-1}$ 项的系数。

- $H \neq 0$：$E$ 是 **ordinary**，形式群的高度为 1，形式对数存在（但系数含 $1/p$ 类分母，需在适当截断意义下理解）；
- $H = 0$：$E$ 是 **supersingular**，形式群的高度为 2，形式对数「卡死」。

这条区分不是书斋里的细节：它直接决定 $E(\mathbb{F}_{p^n})$ 中 $p$-挠点的形状、Weil 配对（第 14 篇）的退化程度，以及密码学中「配对能否有效计算」。**「形式对数存不存在」在特征 $p$ 下变成了一道判断题——答案由曲线在 $p$ 处的「几何性格」给出。**

## 6 小结

- **形式群律**是「原点附近的局部加法」，系数可定义在任何环上；椭圆曲线的形式群 $\widehat{E}$ 系数在 $\mathbb{Z}[A,B]$ 中。
- **形式对数** $f$ 把 $\widehat{E}$ 变成普通加法，特征 0 下存在且唯一，但系数含分母。
- $p$-进挠元被**赋值上界**约束：$[p^n](z) = 0 \Rightarrow v_p(z) \leq \frac{1}{p^{n-1}(p-1)}$（好的约化下取等号）。
- 形式群是**约化理论、高度理论、BSD 局部项**的公共底层工具。
- 局部坐标 $z = -x/y$ 是进入形式群的入口，它本身是「极点阶数相减」的 Riemann-Roch 计算。

在下一节，我们将带着这把「局部尺子」来到有限域：**有限域上的椭圆曲线**——Hasse 界、Frobenius 与 zeta 函数，为什么 $E(\mathbb{F}_q)$ 的点的个数总是「夹在」$q+1 \pm 2\sqrt{q}$ 之间。
