## 为什么从几何加法开始

上一节我们把群律的坐标公式摆上了桌面，但公式背后的**直觉**还藏着：为什么「三点共线再取反射」会给出一个阿贝尔群？这一节我们不搬公式，只画图。用几何直观把加法看穿，是理解椭圆曲线一切算术的开始——因为当你问「$P + Q$ 到底在哪」时，答案从来不是代数，而是几何：**它在第三交点关于 $x$ 轴的反射处**。<span class="marginnote">这套「弦与切线」规则的历史可以追溯到 Newton 与 Diophantus：古人用「过两已知点作弦、找第三个交点」来构造三次方程的新有理数解——他们当时并不知道自己在定义群律。</span>本节还会把圆上的乘法与椭圆曲线上的加法做对比，说明「为什么三次曲线恰好够用」。

## 1 圆上的乘法：一次预演

在给出椭圆曲线加法之前，先看一个更古老的例子。单位圆 $x^2 + y^2 = 1$ 上，如何定义「两点相加」？

- **圆上的弦法则**：过单位圆上两点 $P, Q$ 的直线与圆交于两点 $P, Q$ 本身——不是三点。所以「弦法」在圆上只能给出 $P$ 与 $Q$ 的另一个交点是 $P,Q$ 本身，无法产生「第三点」。
- **圆上的乘法则**：用**过其中一点的直径的平行线**投影，把圆与实轴对应，$P$ 对应角度 $\theta_P$，则 $P + Q$ 对应 $\theta_P + \theta_Q$，即
$$\cos(\theta_1 + \theta_2) = \cos\theta_1 \cos\theta_2 - \sin\theta_1\sin\theta_2$$
于是圆上的加法退化为角度的加法，是 $(\mathbb{R}/2\pi\mathbb{Z}, +)$——本质上就是复平面上乘法群的复指数。

**关键对比**：圆是二次曲线，二次曲线与直线只有 2 个交点，够不着「第三点反射」的戏法；**椭圆曲线是三次曲线，直线与它恒有 3 个交点（计重数），第三点才是加法的主角。** 这就是「为什么是三次」的几何答案。

**辨析｜易错点：** 有人问「能不能把 $P + Q$ 定义成 $R$ 本身而不反射？」不能。若 $P+Q = R$，则当 $P = Q$ 时 $2P$ 也恰是切线切点，但这样 $P + (-P)$ 就无法等于「无穷远」——没有单位元，就不成群。**反射的那一步是整个构造里「取逆元」的几何化身，一步都不能省。**

## 2 弦与切线：三步构造

设 $E: y^2 = x^3 + Ax + B$ 是光滑三次曲线，$P, Q \in E(k)$。几何加法的完整剧本如下：

**第一步（弦）**：若 $P \neq Q$，作过 $P, Q$ 的直线 $L$。由 Bezout 定理，$L$ 与 $E$ 相交于三个点（计重数）。由于 $P, Q$ 已知，第三个交点记为 $R$。

**第二步（切线）**：若 $P = Q$，用 $P$ 处的切线替代弦。切线与 $E$ 在 $P$ 处二重相切，再交于第三点 $R$。<span class="marginnote">切线的处理可以统一写成「过 $P$ 的直线以 $P$ 为重交点」：$P \neq Q$ 是「两点定弦」，$P = Q$ 是「一点定切线」。把「重数」概念引进来后，两种情形共用同一套语言——这正是代数几何的威力。</span>

**第三步（反射）**：过 $R$ 作关于 $x$-轴的反射，得 $R' = -R$，定义

$$P + Q := R' = -R$$

单位元是无穷远点 $O = [0:1:0]$：$P + O = P$；而 $P + (-P) = O$ 正是「$P$ 与 $-P$ 的弦是竖直直线」，它在无穷远处与 $E$ 相交。<span class="marginnote">为什么「竖直弦」相交于无穷远？因为竖直直线 $x = c$ 在射影化下是 $X = cZ$，它过 $[0:1:0]$。三次方程 $y^2 = c^3 + Ac + B$ 在 $y$ 上只有两个有限根 $\pm y$，第三个根正是 $Z = 0$ 上的无穷远点——这就是「$P + (-P) = O$」的精确证明。</span>

**重点：** 图里那条虚线就是「反射」步骤——**$R$ 与 $P+Q$ 关于 $x$-轴对称**，这正是「取逆元」的几何含义。整个加法过程可以概括为一句口诀：**「过两点作弦，找第三点，翻个面」**。

## 4 为什么结合律的直觉在图中「看不见」

弦与切线法的交换律一目了然，但结合律 $(P+Q)+R = P+(Q+R)$ 在图里几乎是隐形的。原因：**结合律本质上是关于「多个弦交点的重合」的深层事实，一次只画一个弦永远看不出来。**

几何直觉可以这样给出：把三次曲线想象成由「直线系」编织出来的对象——曲线 $E$ 上任意三个共线的点 $A, B, C$ 满足「除子 $[A]+[B]+[C]$ 是一个主除子」<span class="marginnote">这是第一篇《除子与 Riemann-Roch》的核心推论：三次曲线与直线交于三点，三点对应的除子恰是某函数 $l$ 的除子。三次性在此再一次成为主角。</span>。于是可以证明：两个「三点共线」构造复合后，无论以什么次序做，得到的点都对应同一个除子类，而除子类群是交换群。**结合律是「群」的最后一根支柱，它的证明不在图里，而在 Riemann-Roch 里**——这也再次说明为什么第一篇是整座大厦的地基。

**辨析｜易错点：** 尝试用「结合律的图」验证时，最常见的错误是取 $P=Q$ 或 $Q=R$ 等退化情形而不处理重数。例如 $(P+P)+P$ 需要用到「过 $2P$ 与 $P$ 的弦」，而这条弦在 $P$ 处的重数是 2；若不按重数计数，第三交点会算错。**退化情形（相等点、互逆点、y=0 点）必须回到坐标公式逐一核对**——几何直觉在这里会骗人。

## 5 公式解析：几何加法的坐标化

把「弦与切线」翻译成坐标公式，只需两个变量：弦的斜率 $\lambda$ 与弦方程。

$$
x_{P+Q} = \lambda^2 - x_P - x_Q, \qquad y_{P+Q} = \lambda(x_P - x_{P+Q}) - y_P
$$

- **第一步，为什么 $x_{P+Q} = \lambda^2 - x_P - x_Q$**：弦直线 $y = \lambda x + \nu$ 代入三次方程得 $(\lambda x + \nu)^2 = x^3 + Ax + B$，即 $x^3 - \lambda^2 x^2 + \cdots = 0$。三个根是 $x_P, x_Q, x_R$，由韦达定理，$x_P + x_Q + x_R = \lambda^2$。故 $x_R = \lambda^2 - x_P - x_Q$。**反射不改变 $x$ 坐标**，于是 $x_{P+Q} = x_R$。
- **第二步，为什么 $y_{P+Q} = \lambda(x_P - x_{P+Q}) - y_P$**：$R$ 在直线上，$y_R = \lambda x_R + \nu$，而 $\nu = y_P - \lambda x_P$。反射改变 $y$ 的符号，故 $y_{P+Q} = -y_R = \lambda(x_P - x_R) - y_P$。
- **第三步，$\lambda$ 的两张面孔**：弦斜率为 $\lambda = (y_Q - y_P)/(x_Q - x_P)$；切线斜率为 $\lambda = (3x_P^2 + A)/(2y_P)$。前者来自定义，后者来自隐式求导——**切线情形是弦情形的极限**，$Q \to P$ 时二者合一。
- **第四步，一个算术彩蛋**：这套公式只用了 $+,-,\times,/$ 四种运算。因此**只要 $P, Q$ 的坐标属于一个域 $k$，$P+Q$ 的坐标也属于 $k$**。这就是椭圆曲线群律「不离开数域」的算术特性——也是第 5 篇《有限域上的椭圆曲线》里「$E(\mathbb{F}_q)$ 是有限群」的根本原因。

### 补充：一张图之外的「三重奏」——同一曲线的三种加法

把「弦」「切线」「逆元」三种几何情形放在同一条曲线 $y^2 = x^3 + 1$ 上逐一重演，让图与公式互相校验。

**弦（$P \neq Q$）**：$P = (0,1)$，$Q = (2,3)$。斜率 $\lambda = 1$，第三交点 $R$ 的坐标为 $x_R = 1 - 0 - 2 = -1$，$y_R = 1\cdot(0-(-1))-1 = 0$。弦 $PQ$ 穿过 $x$-轴于点 $(-1,0)$，反射后仍在 $x$-轴上——于是 $P + Q = (-1,0)$。

**切线（$P = Q$）**：在 $P = (0,1)$ 处，$y^2 = x^3 + 1$ 的切线斜率为 $\lambda = 3x^2/2y = 0$，切线是水平的 $y = 1$。它与曲线在 $P$ 处二重相切、在 $x = 0$ 处三重相交（$x^3 + 1 = 1 \Rightarrow x = 0$），第三交点 $R = (0,1) = P$ 又回到自身——这正是「$3P = O$」的几何画面：**$P$ 是一个拐点（inflection point），而拐点必为 3-挠点**。

**逆元（$P + (-P) = O$）**：$P = (0,1)$ 的逆元是 $-P = (0,-1)$；过二者的弦是竖直线 $x = 0$，在有限平面内不再相交，第三交点落在无穷远点 $O$——这就是「竖直弦收于 $O$」的几何翻译。

**三个情形在坐标公式里的「统一」**：弦与切线的差异只在斜率 $\lambda$ 的取值；竖直线对应「分母 $x_2 - x_1$ 或 $y_1$ 为 0」的除零；反射对应「$y \to -y$」。图告诉你去哪找答案，公式告诉你如何精确执行。

| 情形 | 几何操作 | 坐标公式 | 退化风险 |
| --- | --- | --- | --- |
| $P \neq Q$ | 过 $P,Q$ 作弦，取第三交点 $R$ | $\lambda = (y_2-y_1)/(x_2-x_1)$ | $x_1 = x_2$（竖直） |
| $P = Q$ | 过 $P$ 作切线，取第三交点 $R$ | $\lambda = (3x_1^2+A)/(2y_1)$ | $y_1 = 0$（切线竖直） |
| $P = -Q$ | 竖直线收于无穷远 | $P + (-P) = O$ | 「第三点」就是 $O$ |

这张表是本节全部内容的「压缩文件」：三种几何、三套公式、三个除零陷阱。**把它背下来，就等于把「几何加法」背下来了。**

**辨析｜易错点（补）**：示意图里 $P, Q$ 都在卵形分支的上半支，弦是「同侧两点」，第三点落在右支——这与许多教材「$P, Q$ 分居卵形上下」的配图不同，但**两种情形都合法**。关键只在于「第三交点存在且唯一」；至于它落在哪条分支，取决于具体点对。真正会出错的是把「第三交点」误当成「$P+Q$」本身而忘了反射。

### 一点历史旁白：Diophantus 早在「群律」之前

这套「过两点作弦找第三点」的操作，早在群的概念诞生之前一千六百年就被 Diophantus 用过：解三次方程 $y^2 = x^3 + Ax + B$ 的有理点时，已知两个有理点 $P, Q$，过它们的直线与曲线交于第三个有理点——因为直线方程与三次方程联立后的三次方程，有两个已知有理根，第三个根（由韦达定理）必为有理。**「有理点闭包」是丢番图几何的第一条定理，而它几乎不需要任何现代语言。**

牛顿在 17 世纪把同一方法写成「切线法」（用切线从已知有理点造出新的有理点），后人称为「弦切线法」。只是他们都没有想到：把「第三交点反射回去」会得到一个群律——这一步要等到 20 世纪、等到「点的集合 = 除子类群」（第 1 篇）的现代视角才被看穿。**数学的进步，往往是把古人「用过的把戏」重新命名为「对象的结构」。**

### 收束：图与公式的分工

最后把「图」与「代数」的边界划清楚：示意图负责**找答案的方向**，坐标公式负责**精确执行**。二者都不完整——图会骗人（退化情形），公式会失明（看不出结构）。**好的算术家两者并用：用图想，用公式算。**

这套「几何直觉 + 代数公式」的双轨法，会在本专题反复出现：第 5 篇有限域上数点靠它，第 15 篇复环面上一致化靠它，第 17 篇模性定理对表还是靠它。**「先看图、再算数」不是偷懒，而是算数几何的基本工作方式。**

（若读者想把示意图里的每一步在纸上重画一遍，只需记住三条规则：弦取第三点、切线取第三点、反射取逆元——其余全是这两条规则在具体坐标上的展开。）

## 6 小结

- 椭圆曲线的几何加法=**弦（或切线）+ 第三交点 + 反射**；反射正是「取逆元」。
- 三次性（Bezout：直线与三次曲线恒有三交点）是整套构造存在的**几何理由**；圆是二次的，做不了这件事。
- 结合律无法从单张图中看出，其证明在**除子类群与 Riemann-Roch** 中，交换律才在图中显而易见。
- 坐标公式只有 $\lambda$ 与韦达定理，四则运算封闭 ⇒ **群律不离开数域**。
- 退化情形（$P=Q$、$y=0$、$P=-Q$）必须回到公式，几何直觉会误导。

在下一节，我们将把目光从「点」转向「点附近的无穷小世界」——**形式群与形式对数**：为什么每条椭圆曲线都自带一个「局部对数」，而它又是如何成为 $p$-进算术里衡量挠点阶的尺子的。
