## 为什么从分类体系开始

前面五课我们学会了「推树」：从矩阵到简约、从搜索到自举。但树不是终点——系统的最终产品是**分类体系**：那张博物馆名录、教科书目录、数据库 taxonomy 树。这一课处理从树到体系的转换：**树的哪个分支能成为「科」？林奈的七个等级还够用吗？三个学派吵了一百年，最后赢的是谁？**

它也是本专题第一课「分类是系统学三大任务之一」的兑现时刻——把第 5 篇「只有单系合法」的判据，翻译成一棵完整的、可发表的分类树。

## 1 分类的三个学派

20 世纪下半叶，系统学界关于「怎么分类」分裂成三派：

**数值分类学 / 表型学派（phenetics）**（Sneath & Sokal, 1973）：主张放弃「祖先」这种不可观测的概念，只按**总体相似度**聚类，产出**表型图（phenogram）**。优点是可重复、客观化；缺点是相似度里混着大量祖征，聚出的类群常与演化无关——今天已基本退出主流，但它的量化思想（距离、聚类）滋养了整个领域。

**演化分类学（evolutionary classification）**（Mayr, Simpson）：承认谱系，但允许「**等级（grade）**」——即并系类群。他们认为分类要同时考虑「谱系」与「生态适应水平」，于是传统的「爬行动物」（并系）可以保留。<span class="marginnote">演化分类学家的经典辩护是「分类首先是方便实用」；支序学派的回应是「如果分类不能反映谱系，它就什么都不是」——两派之争正是第 2 篇「范式之争」的具体化。</span>

**支序分类学（cladistics）**（Hennig）：只有**单系**类群可以被命名与排序。分类体系 = 树的「剪枝」：每一个正式类群对应树上一个单系分支（clade）。

| 学派 | 分组判据 | 并系允许？ | 类群与谱系关系 |
| --- | --- | --- | --- |
| 表型学派 | 总体相似度 | 不关心 | 无关（可能复系） |
| 演化分类学 | 谱系 + 等级 | 允许 | 部分对应 |
| 支序分类学 | 谱系（单系） | 禁止 | 一一对应 |

今日的共识旗帜鲜明：**分类应与谱系一致，并系是待修正的残留**。

## 2 林奈等级体系与秩的问题

林奈体系用**阶元（rank）**组织类群：界（kingdom）→ 门（phylum）→ 纲（class）→ 目（order）→ 科（family）→ 属（genus）→ 种（species），中间还能加亚目、亚科等层级。阶元是**等级槽**，类群是**放进槽里的实体**——这是上一课「阶元 ≠ 类群」的完整面貌。

林奈体系沿用两百年，但现代谱系暴露了它的三大毛病：

1. **秩是相对的**：「目」在昆虫里和哺乳类里的「大小」毫无可比性——秩不代表任何演化含义；
2. **秩爆炸**：物种多了，为保持「整洁」不断插秩，出现「超科」「下纲」等二十余级；
3. **并系残留**：历史遗留的并系类群（如「爬行动物」）与新谱系矛盾，又因名称权威难以废除。

### 等级体系的现代修剪

面对三大毛病，主流实践不是推倒林奈体系，而是「修剪」：**能保留的等级尽量保留，把并系类群逐步拆解成单系**。一个常见的中间态是「加括号的并系」——例如「爬行动物（不含鸟类）」在教材里被标注为并系，同时补一句「鸟类是恐龙的后代」。数据库分类（NCBI、GBIF）则用 in-part 标记与「地位未定（incertae sedis）」处理无法确定的挂靠。这套务实策略说明：**分类体系的演化是渐变而非革命**——但演化的方向始终是「向单系靠拢」。

### 辨析｜易错点

**「门」不比「纲」更高级、更正确。** 秩只是标签，演化含义全在拓扑上。两只亲缘更近的动物可以一个在「纲」一个在「目」——秩的位置取决于整个分类的排版，不反映亲缘远近。初学最深的执念就是把「等级更高」读成「演化更进步」。

## 3 以单系为纲：支序分类

支序分类学把树「翻译」成体系的规则很干净：

**每个可命名类群 = 树上一个单系分支**；
- **姐妹群（sister groups）**获得并列的秩（如两个姐妹科的秩同为科）；
- 若一个类群要升为「科」，其姐妹群也应相应处理——**同级归并**。

实践中最著名的例子：把鸟类放进恐龙/爬行类系统后，传统「爬行动物（Reptilia）」若不包含鸟类就是并系。于是现代系统给出**冠群（crown group）**与**干群（stem group）**的概念：**冠群** = 现生成员的最晚共同祖先及其全部后代；**干群** = 从类群分化起点到冠群之间的「主干」化石类群。化石被安放在干群位置，分类体系随之扩展。<span class="marginnote">「鸟类是恐龙的一支」不是比喻，而是支序分类的直接推论：鸟纲的姊妹是兽脚类恐龙群。教科书目录的「恐龙 ≠ 鸟类」正是并系在作祟。</span>

## 4 PhyloCode：挣脱林奈的秩

既然秩是标签，为何不干脆取消秩？**PhyloCode**（《系统发育命名法规》，Cantino & de Queiroz 推动）正是这个极端方案：名称直接绑定**分支**，用三种方式定义：

- **节点式（node-based）**：如「Pan-Aves = 麻雀与鳄鱼的最晚共同祖先及其全部后代」；
- **分支式（branch-based）**：如「Aves = 麻雀（Anseriformes 侧）相对于鳄鱼更近的全部后代」；
- **衍征式（apomorphy-based）**：如「Aves = 拥有羽毛这一衍征的首个类群及其全部后代」。

PhyloCode 的激进在于：**名称没有固定等级**，类群可以嵌套在任何深度。它至今未被主流法规采纳，但它的核心主张——**名称该指向谱系，而不是秩**——已经渗透进主流分类的日常写作。

值得注意的是，PhyloCode 的支持者并未废除林奈的种名——**种名仍然保留双名形式**，废除的只是「种名必须挂在一个固定等级上」这层约束。这意味着两套体系在未来很长时间会并行共存：林奈体系负责稳定与档案，PhyloCode 负责表达纯谱系关系。

## 5 从支序图到分类方案：一个完整的例子

把理论走一遍。设支序图给出拓扑：外群 O，内群中 B 与 C 先分家，再与 A 联合。则合法分类是：

- 单系类群 {A, B, C} 可命名为属/亚科/任何秩；
- 单系类群 {B, C} 可再命名一个属/亚科；
- **{A, B}、{A, C} 是非法的**（A 是旁支，{A,B} 不包含 C 的祖先分支）——它们在树上不构成一个连续分支。

可见**分类是对树的「无损重排」**：合法类群恰好是树上所有的连续分支。这也是为什么现代数据库（如 NCBI Taxonomy）的「物种树」栏目本质上就是一棵标注了全部合法分支的支序树。

### 分类与数据库：从论文到 API

现代分类学不再只活在纸面名录上。NCBI Taxonomy、GBIF、COL（生命目录）把分类树做成可检索的数据结构：每个节点带 **taxid / 学名 / 等级 / 上级类群** 四个字段，嵌套关系就是树上父子边。这带来的一个好处是「分类变更可追溯」——当某个并系被拆解时，数据库保留旧名的 synonym 链接。**于是分类体系第一次获得了版本控制**：你可以像读 git log 一样查「这个学名在 2005 年之前属于哪个类群」。这与「命名法提供稳定名称、数据库提供变更历史」形成互补，正是第 13 篇「名字稳定」原则的技术化。从「命名 + 分类」到「数据库 API」的跃迁，也解释了为什么现代分类学岗位越来越多地出现在生物信息学部门——**分类体系正在成为可编程的基础设施**。

## 6 实例：人科的谱系分类

用一个与我们自身相关的例子把「树 → 分类」走一遍。现代分子系统学给出灵长类的核心拓扑：人类（*Homo\*）、黑猩猩（*Pan\*）、大猩猩（*Gorilla\*）、猩猩（*Pongo\*）构成一个单系群，其内部关系为 (猩猩, (大猩猩, (黑猩猩, 人)))。

支序分类据此重排：

- 四个属连同其祖先构成**人科 Hominidae**；
- 去掉猩猩（亚科 Ponginae）后的单系群是**人亚科 Homininae**（大猩猩 + 黑猩猩 + 人）；
- 再去掉大猩猩后的单系群是**人族 Hominini**（黑猩猩 + 人）；
- 传统把「人科」只给人类（Hominidae = 人属）的做法被推翻——因为那样人科就是并系。

这套分类的直接推论震撼但严谨：**「黑猩猩」与「人类」的亲缘关系，比它们各自与「大猩猩」更近。** 放在 1960 年代这是异端，如今是中学教科书的常识——它是「分类必须跟随谱系」这场范式革命最生动的纪念碑。

同时注意秩的使用：树上一共有四个嵌套单系（科、亚科、族、属），正好填进林奈的秩——**秩没有内在意义，但谱系有；秩只是给谱系贴上「科/亚科/族」的标签。**

## 7 小结

- 三大分类学派：**表型**（总体相似度）、**演化**（谱系 + 等级，容忍并系）、**支序**（只认单系）——最终共识是分类与谱系一致。
- 林奈**秩**体系的三大毛病：秩无演化含义、秩爆炸、并系残留。
- 支序分类规则：**每个类群 = 一个单系分支**；姐妹群同秩；化石进入**干群**或**冠群**。
- **PhyloCode** 用节点/分支/衍征三种定义把名称直接绑定到谱系，主张去秩化。
- 合法分类 = 树的连续分支集合；**{A,B} 这类跨越分支的集合在谱系上非法**。
- **PhyloCode** 用节点/分支/衍征定义名称，但保留双名制——两套体系将长期并存。
- **分类数据库**给分类体系装上版本控制，学名变更可全程追溯。

在下一节，数据源要换了：从形态描述进入**分子序列**。当数据是四字母的 DNA 字符串时，同源如何建立、距离如何校正、似然如何计算——这就是**分子系统学方法**。
