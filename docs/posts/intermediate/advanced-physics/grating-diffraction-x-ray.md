## 为什么从光栅衍射开始

光谱仪的核心是**衍射光栅（diffraction grating）**——一排等间距的平行狭缝。它把复合光分解成又细又亮的谱线，用于测量光谱、分析物质成分。光栅方程 $d\sin\theta = k\lambda$ 简单得惊人，却支撑起整个光谱学。而 X 射线衍射则是光栅思想的「晶体版」：晶体中原子的周期性排列就是天然的「三维光栅」，劳厄、布拉格父子用它测出晶体结构——现代材料科学、分子生物学的基石。这一节把光栅衍射与布拉格公式讲透。

## 1 光栅及其分类

**光栅（grating）**：大量等宽、等间距的平行狭缝（或刻线）。缝宽 $a$、缝间距（光栅常数）$d$。

- **透射光栅**：光透过平行狭缝（玻璃上刻线）；
- **反射光栅**：光从刻槽表面反射（CD、DVD 表面的彩虹就是反射光栅衍射）。

**光栅常数** $d$：相邻两缝中心的距离，$d = a + b$（缝宽 + 遮光宽）。典型光栅每毫米有几百到上千条刻线，$d$ 为微米量级。

**重点：光栅是「多缝干涉 + 单缝衍射」的复合图样——多缝干涉决定主极大的位置，单缝衍射调制其强度。** 完整图样 = 干涉因子 × 衍射因子。

## 2 光栅方程

平行光垂直入射光栅，相邻缝到屏上 $\theta$ 方向的光程差为 $d\sin\theta$。**主极大（明纹）条件**：

$$d\sin\theta = k\lambda \quad (k = 0, \pm1, \pm2, \dots)$$

$k$ 叫**谱线级次**。$k = 0$ 是零级（中央，白光时无色）；$k = \pm1$ 是一级谱……

**重点：光栅方程 $d\sin\theta = k\lambda$——主极大的位置由光栅常数与波长决定。** 不同波长在同级谱线上按 $\theta$ 分开——这就是光栅的分光原理。$\theta$ 越大、$k$ 越高，色散越强。<span class="marginnote">「缺级现象」：当多缝干涉的某级主极大恰好落在单缝衍射的暗纹上时，该级消失。缺级条件：$d/a = k/k'$（整数比）。例如 $d = 3a$ 时，$k = 3, 6, \dots$ 级缺失——图样里这些位置是暗的。</span>

**辨析｜易错点：**光栅方程与单缝暗纹条件 $a\sin\theta = k\lambda$ 形式相似但物理不同：光栅方程看**缝间距 $d$**（多缝干涉主极大），单缝暗纹看**缝宽 $a$**（单缝衍射暗纹）。做题先分清是「光栅主极大」还是「单缝暗纹」，别把 $d$ 与 $a$ 混用。

## 3 光栅光谱与分辨本领

光栅把复色光展开成**光栅光谱**：同一级次内，不同波长按 $\theta$ 依次排开（紫光在内、红光在外）。

**光栅的分辨本领**：能分辨的最小波长差：

$$R = \frac{\lambda}{\Delta\lambda} = kN$$

其中 $N$ 是光栅总缝数、$k$ 是级次。

**重点：光栅分辨本领 $R = kN$——缝数越多、级次越高，分辨本领越大。** 这是光栅优于三棱镜的关键：棱镜靠色散（材料），光栅靠干涉（缝数），光栅可做得分辨本领极高。天文光谱仪用光栅分辨原子谱线的细微结构。<span class="marginnote">「$R = kN$」的含义：分辨本领 = 级次 × 缝数。一万条缝的一级光谱能分辨 $\Delta\lambda = \lambda/10^4$——约 0.05 nm 的谱线差。钠双线（589.0/589.6 nm）需要 $R \approx 1000$，小光栅即可分辨。这正是光栅分光能力的来源。</span>

## 4 公式解析：光栅光谱的计算

光栅常数 $d = 2\times10^{-6}\ \text{m}$（500 线/mm），用 $\lambda = 500\ \text{nm}$ 的平行光垂直入射。求能看到的最高级次与 $k = 1$ 级对应的衍射角。

$$
d\sin\theta = k\lambda \quad\Longrightarrow\quad k_{\max} = \left\lfloor\frac{d}{\lambda}\right\rfloor = \frac{2\times10^{-6}}{500\times10^{-9}} = 4
$$

- **第一步，写光栅方程**：$d\sin\theta = k\lambda$，$\sin\theta = k\lambda/d$。
- **第二步，求最大级次**：$\sin\theta \le 1$，$k_{\max} = \lfloor d/\lambda \rfloor = 4$——最多看到第 4 级谱线（$k = \pm4$）。
- **第三步，求 $k = 1$ 的衍射角**：$\sin\theta = \frac{500\times10^{-9}}{2\times10^{-6}} = 0.25$，$\theta \approx 14.5°$。
- **第四步，解读**：$k = 4$ 时 $\sin\theta = 1$，$\theta = 90°$——极限位置；$k = 4$ 刚好在掠射方向。级次越高、衍射角越大，谱线越靠外。

**辨析｜易错点：**光栅能看到的级次有限：$\sin\theta \le 1$ 决定了 $k_{\max} = \lfloor d/\lambda \rfloor$。若 $d < \lambda$，则只有 $k = 0$ 级（无分光能力）——光栅常数必须大于波长才有高阶谱。题中「求最多看到几级」先算 $d/\lambda$ 取整。

## 5 X 射线衍射与布拉格公式

X 射线波长极短（约 0.1 nm），与晶体中原子间距同量级——晶体就是 X 射线的天然三维光栅。

**布拉格公式（Bragg's law）**：X 射线以掠射角 $\theta$（与晶面夹角）射向晶面间距 $d$ 的晶体，相邻晶面反射光的光程差 $2d\sin\theta$，主极大条件：

$$2d\sin\theta = n\lambda \quad (n = 1, 2, 3, \dots)$$

**重点：布拉格公式 $2d\sin\theta = n\lambda$——X 射线衍射测晶体结构的核心。** 已知 $\lambda$ 与 $\theta$，可测晶面间距 $d$（测晶体结构）；已知 $d$ 与 $\theta$，可测 $\lambda$（X 射线光谱）。<span class="marginnote">布拉格父子（W.H. Bragg & W.L. Bragg，1915 年诺贝尔奖）把 X 射线衍射发展为结构分析工具。DNA 双螺旋结构正是靠 X 射线衍射照片（富兰克林）推断出来的——沃森与克里克据此建立 DNA 模型。X 射线衍射是现代材料科学、晶体学、结构生物学的基石。</span>

**辨析｜易错点：**布拉格公式中的 $\theta$ 是**掠射角**（X 射线与晶面的夹角），不是入射角（与法线夹角）。光栅方程用与法线的角，布拉格公式用与晶面的角——角度基准不同，别混。

## 6 小结

- **光栅**：等宽等距平行缝；光栅常数 $d$。
- **光栅方程**：$d\sin\theta = k\lambda$——主极大位置；白光展开成光谱。
- 图样 = 多缝干涉 × 单缝衍射；缺级：$d/a$ 为整数比时对应级次消失。
- **分辨本领**：$R = kN$——缝数越多、级次越高，分辨越强（优于棱镜）。
- 最大级次：$k_{\max} = \lfloor d/\lambda \rfloor$。
- **X 射线衍射**：布拉格公式 $2d\sin\theta = n\lambda$，测晶体结构与波长。
