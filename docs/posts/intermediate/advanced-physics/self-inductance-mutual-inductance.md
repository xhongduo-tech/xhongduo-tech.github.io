# 自感与互感

<div class="epigraph">

## 为什么从自感开始

电磁感应的「原因」不只来自外部磁铁，线圈自己的电流也产生磁场、穿过自身。电流变化 → 自身磁通变化 → 感应电动势阻碍电流变化——这是**自感（self-inductance）**。两线圈之间互相感应——这是**互感（mutual inductance）**。自感让电感器像「电惯性」：电流不能突变，是滤波、储能、谐振电路的核心；互感则是变压器的心脏。这一节定义电感、推导长直螺线管的自感系数，并建立磁场能量与电感的联系。

## 1 自感

**自感现象**：线圈中电流变化引起自身磁通量变化，从而在线圈中产生感应电动势（自感电动势）的现象。

定义**自感系数（self-inductance）** $L$：

$$\Psi = LI, \qquad \mathcal{E}_L = -\frac{\mathrm{d}\Psi}{\mathrm{d}t} = -L\frac{\mathrm{d}I}{\mathrm{d}t}$$

单位：亨利（H），$1\ \text{H} = 1\ \text{V·s/A}$。<span class="marginnote">自感系数 $L$ 只由线圈的几何结构（匝数、形状、尺寸）与磁介质决定，与电流无关——正如电容 $C$ 只由几何与介质决定。$L$ 越大，「电惯性」越强，电流越难突变。</span>

**重点：自感电动势 $L\,\mathrm{d}I/\mathrm{d}t$ 阻碍电流变化。** 电流增大时自感电动势与电流反向（阻碍增大），电流减小时同向（阻碍减小）。所以含电感的电路里电流不能突变——断开开关瞬间，电感努力维持电流，产生很大的反向电动势（火花、电击的来源）。

## 2 长直螺线管的自感

长直螺线管（长度 $l$、面积 $S$、匝数 $N$、电流 $I$，管内磁场 $B = \mu_0 nI$，$n = N/l$）：

$$\Psi = NBS = N\mu_0 nIS = \mu_0 n^2 Sl\cdot I \quad\Longrightarrow\quad L = \frac{\Psi}{I} = \mu_0 n^2 Sl$$

**自感系数 $L = \mu_0n^2V$**（$V = Sl$ 为螺线管体积）——正比于单位长度匝数平方与体积。匝数越密、体积越大，电感越大。<span class="marginnote">这个公式体现「电感 ∝ 匝数平方」：$B \propto n$（匝密场强）、$\Psi = NBS \propto n\cdot n = n^2$。填铁芯后 $L = \mu_r\mu_0n^2V$，磁导率越大电感越大——变压器铁芯用高磁导率材料的原因。</span>

## 3 互感

**互感（mutual inductance）**：一个线圈中电流变化，在另一线圈中产生感应电动势的现象。

线圈 1 的电流 $I_1$ 在线圈 2 中产生的磁链 $\Psi_{21} = M_{21}I_1$，互感电动势：

$$\mathcal{E}_2 = -M_{21}\frac{\mathrm{d}I_1}{\mathrm{d}t}$$

**互感系数** $M_{21} = M_{12} = M$（互易性）只由两线圈几何与介质决定。单位同为亨利 H。

**重点：互感是变压器的原理。** 原线圈电流变化，通过互感在副线圈感应电动势；改变匝数比即改变电压比 $U_2/U_1 = N_2/N_1$。<span class="marginnote">互感现象无处不在：变压器（电力输送）、无线充电、手机感应、杂散耦合（电磁干扰）。两个线圈的互感体现「磁耦合」——它们通过公共磁通「对话」。耦合系数 $k = M/\sqrt{L_1L_2}$ 衡量耦合强弱（0 无耦合，1 完全耦合）。</span>

## 4 公式解析：自感电动势与 RL 电路

含电阻 $R$ 与电感 $L$ 的 RL 电路接上电源，电流增长满足：

$$
L\frac{\mathrm{d}I}{\mathrm{d}t} + RI = \mathcal{E} \quad\Longrightarrow\quad I(t) = \frac{\mathcal{E}}{R}\left(1 - e^{-t/\tau}\right), \quad \tau = \frac{L}{R}
$$

- **第一步，列回路方程**：电源电动势 = 电阻压降 + 电感压降，$L\frac{\mathrm{d}I}{\mathrm{d}t} + RI = \mathcal{E}$。
- **第二步，解方程**：一阶线性微分方程，解为 $I = \frac{\mathcal{E}}{R}(1-e^{-t/\tau})$。
- **第三步，读时间常数**：$\tau = L/R$——电流上升到稳态的 $1 - 1/e \approx 63\%$ 所需时间。
- **第四步，体会「惯性」**：$t = 0$ 时电流从零开始缓慢上升（电感阻碍），$t \to \infty$ 时电流趋于 $\mathcal{E}/R$（电感「短路」成导线）。开关断开时电流也不会骤降为零，而是指数衰减。

**辨析｜易错点：**「电感对直流是短路、对变化电流是阻碍」——稳态直流下 $\mathrm{d}I/\mathrm{d}t = 0$，自感电动势为零，电感像一段导线；只有电流变化时电感才「起作用」。这与电容相反：电容隔直流、通交流。RL 与 RC 电路的时间常数 $\tau = L/R$、$\tau = RC$ 分别是「惯性」与「惰性」的时间尺度。

## 5 磁场的能量

电感储存磁场能量。电流从 0 增至 $I$ 的过程中，电源克服自感电动势做功，储存在磁场中：

$$W_m = \int_0^I Li\,\mathrm{d}i = \frac{1}{2}LI^2$$

**重点：电感储能 $W_m = \frac{1}{2}LI^2$，与电容储能 $\frac{1}{2}CU^2$、动能 $\frac{1}{2}mv^2$ 同构。** 磁场能量密度（长螺线管 $L = \mu_0n^2V$、$B = \mu_0nI$）：

$$w_m = \frac{W_m}{V} = \frac{B^2}{2\mu_0}$$

**磁场能量密度 $w_m = B^2/(2\mu_0)$**——与电场能量密度 $\frac{1}{2}\varepsilon E^2$ 对称，正比于场强平方。<span class="marginnote">「电场储能 $\frac{1}{2}\varepsilon E^2$、磁场储能 $B^2/(2\mu_0)$」是电磁场能量的两半。电磁波同时携带电场与磁场能量，总能量密度 $w = \frac{1}{2}\varepsilon E^2 + \frac{1}{2}B^2/\mu$——第十四章电磁波与第二十一章坡印廷矢量的基础。</span>

## 6 数值算例：螺线管电感与 RL 时间常数

长直螺线管，$l = 0.20\ \mathrm{m}$、$S = 2.0\times10^{-3}\ \mathrm{m^2}$、匝数 $N = 500$。求自感系数；若接入 $R = 4.0\ \Omega$ 的电阻，求时间常数。

$$

n = \frac{N}{l} = 2500\ \mathrm{m^{-1}}, \qquad L = \mu_0n^2Sl = 4\pi\times10^{-7}\times2500^2\times2.0\times10^{-3}\times0.20

$$

- **第一步，算匝密度**：$n = 500/0.20 = 2500\ \mathrm{m^{-1}}$。
- **第二步，算电感**：$L = \mu_0n^2V = 4\pi\times10^{-7}\times6.25\times10^6\times4.0\times10^{-4} \approx 3.14\times10^{-3}\ \mathrm{H} = 3.1\ \mathrm{mH}$。
- **第三步，算时间常数**：$\tau = L/R = 3.14\times10^{-3}/4.0 \approx 7.9\times10^{-4}\ \mathrm{s} \approx 0.79\ \mathrm{ms}$。
- **第四步，解读**：电流达到稳态值的 63% 需约 0.79 ms——毫秒量级的时间常数，正好是滤波器、开关电源里常见的量级。改变匝数（$L \propto n^2$）或体积，就能调电感的大小。<span class="marginnote">「$L \propto n^2$ 的工程含义」：匝数翻倍，电感变 4 倍——但要付出更多铜线、更大体积与更大寄生电容。电感设计常在「大电感 vs 小体积」间权衡；高频开关电源里常用铁氧体磁芯 + 少匝数获得大电感。计算时先统一单位（cm² → m²），$L$ 的单位是亨利（H），毫亨（mH）= $10^{-3}$ H。</span>

## 7 变压器的互感原理与能量

变压器由绕在同一铁芯上的原、副线圈构成，靠互感工作：

$$

\frac{U_2}{U_1} = \frac{N_2}{N_1} \quad\text{（理想变压器）}, \qquad I_1U_1 = I_2U_2

$$

- **第一步，写电压比**：理想变压器 $U_2/U_1 = N_2/N_1$——匝数比决定电压比。
- **第二步，写功率守恒**：$I_1U_1 = I_2U_2$——理想变压器不耗能，升压必降流。
- **第三步，读互感原理**：原线圈电流变化 → 铁芯磁通变化 → 副线圈感应电动势——这就是互感的工程化身。
- **第四步，体会**：铁芯用高磁导率材料增强耦合（$k \to 1$）；升压变压器副线圈匝数多、电流小，降压反之——电力输送用高压降低电流损耗，全依赖变压器的互感原理。<span class="marginnote">变压器的「只变电压电流、不变功率频率」特性，让它成为电力系统的中枢：电厂升压到 500 kV 输电、降压到 220 V 入户，中间经历多次变压。没有互感原理，就没有现代电网。耦合系数 $k = M/\sqrt{L_1L_2}$ 越接近 1，漏磁越少、效率越高——铁芯的作用就是把两线圈的磁通锁在一起。</span>

**辨析｜易错点：**自感与互感的区别：自感是「自己的电流影响自己」（$L$），互感是「一线圈电流影响另一线圈」（$M$）。判断用哪个：看电动势的「源」是本线圈电流还是他线圈电流。变压器中既有自感（每线圈对自身）也有互感（线圈之间），但能量传输靠的是互感。区分「磁链 $\Psi = LI$」与「感应电动势 $\mathcal{E} = -L\mathrm{d}I/\mathrm{d}t$」——前者描述关系、后者描述变化率。

## 8 术语速查表

| 术语 | 公式 | 要点 |
| --- | --- | --- |
| 自感 | $\mathcal{E}_L = -L\,\mathrm{d}I/\mathrm{d}t$ | 阻碍自身电流变化 |
| 互感 | $\mathcal{E}_2 = -M\,\mathrm{d}I_1/\mathrm{d}t$ | 线圈间耦合 |
| 螺线管电感 | $L = \mu_0n^2V$ | ∝ 匝数平方 |
| RL 时间常数 | $\tau = L/R$ | 电流变化尺度 |
| 电感储能 | $W_m = \frac12 LI^2$ | 磁场能量 |
| 磁场能量密度 | $w_m = B^2/(2\mu_0)$ | 正比场强平方 |

自感与互感把「电磁感应」从「外部磁铁」推广到「电流自己的磁场」：自感是电惯性、互感是磁耦合。电感储能 $\frac12 LI^2$ 与磁场能量密度 $B^2/2\mu_0$ 让磁场的能量有了定量表述——也完成了「电场储能 ↔ 磁场储能」的对称图景。下一节我们研究磁场的能量与电路应用——**磁场的能量**。

## 9 小结

- **自感**：$L$，$\mathcal{E}_L = -L\,\mathrm{d}I/\mathrm{d}t$，阻碍电流变化；单位亨利 H。
- 长直螺线管：$L = \mu_0n^2V$，正比于匝数平方与体积。
- **互感**：$\mathcal{E}_2 = -M\,\mathrm{d}I_1/\mathrm{d}t$；变压器、无线充电的原理。
- RL 电路：$I = \frac{\mathcal{E}}{R}(1-e^{-t/\tau})$，$\tau = L/R$——电感是「电惯性」。
- **电感储能**：$W_m = \frac{1}{2}LI^2$；磁场能量密度 $w_m = B^2/(2\mu_0)$。

在下一节，我们研究磁场的能量与电路应用——**磁场的能量**（涡电流与电磁阻尼也在下一节，先看磁能）。
