## 为什么从薛定谔方程开始

波函数 $\psi$ 如何随时间演化？量子力学的「牛顿第二定律」就是**薛定谔方程（Schrödinger equation）**。它是量子力学的基本方程，地位等同经典力学的 $F = ma$。对于能量不随时间变化的系统（定态），方程简化为**定态薛定谔方程**——一个本征值方程，其解给出分立的能级与对应的定态波函数。这一节从薛定谔方程的形式、定态的条件、到求解的思路讲透，为后面三个具体模型（势阱、势垒、氢原子）铺路。

## 1 含时薛定谔方程

**含时薛定谔方程（time-dependent Schrödinger equation）**：

$$i\hbar\frac{\partial\psi(\boldsymbol{r}, t)}{\partial t} = \left[-\frac{\hbar^2}{2m}\nabla^2 + V(\boldsymbol{r}, t)\right]\psi(\boldsymbol{r}, t)$$

方括号里是**哈密顿算符** $\hat{H} = -\frac{\hbar^2}{2m}\nabla^2 + V$（动能算符 + 势能）。方程是线性的（叠加原理成立）、一阶时间导数（初态决定演化）。

**重点：薛定谔方程是量子力学的基本方程——给定额初态 $\psi(\boldsymbol{r}, 0)$，它确定波函数以后的一切演化。** 它的地位与 $F = ma$ 在经典力学中相当；但它是一阶的（时间）、线性的（叠加），描述的是**概率幅**的演化，不是粒子的轨迹。

## 2 定态薛定谔方程

若势能 $V$ 不随时间变化（$V = V(\boldsymbol{r})$），用**分离变量法**令 $\psi(\boldsymbol{r}, t) = \phi(\boldsymbol{r})T(t)$，代入方程可得：

$$T(t) = e^{-iEt/\hbar}, \qquad \hat{H}\phi(\boldsymbol{r}) = E\phi(\boldsymbol{r})$$

后者即**定态薛定谔方程（time-independent Schrödinger equation）**，一维形式：

$$-\frac{\hbar^2}{2m}\frac{\mathrm{d}^2\psi}{\mathrm{d}x^2} + V(x)\psi = E\psi$$

**定态（stationary state）**：能量 $E$ 确定的态，波函数 $\psi(x, t) = \phi(x)e^{-iEt/\hbar}$，概率密度 $|\psi|^2 = |\phi|^2$ **不随时间变化**。

**重点：定态薛定谔方程是本征值方程——给定势能 $V$，解出能量本征值 $E$（分立能级）与本征函数 $\phi$（定态波函数）。** 「束缚态」给出分立能级（如原子、势阱），「自由态」给出连续能谱。量子力学求解问题 = 解定态薛定谔方程。<span class="marginnote">「定态」的含义：能量确定、概率分布不随时间变化的状态。原子在定态中「稳态」存在（不辐射），对应玻尔的定态假设——量子力学用波函数的驻波结构自然给出了玻尔假设的物理基础。$\psi = \phi e^{-iEt/\hbar}$ 的相位在旋转，但 $|\psi|^2$ 不变——就像驻波的振幅不变。</span>

## 3 求解定态薛定谔方程的思路

解定态薛定谔方程的一般步骤：

1. **分区域**：按势能 $V(x)$ 的形式把空间分成若干区域；
2. **写方程**：每个区域写出定态方程（$V$ 不同，方程形式不同）；
3. **求解**：解出各区域的通解（指数/三角函数形式，取决于 $E$ 与 $V$ 的大小关系）；
4. **衔接条件**：波函数及其导数在区域边界连续（$V$ 有限时）；
5. **边界条件**：束缚态要求 $|\psi| \to 0$（$x \to \pm\infty$）；
6. **量子化**：边界条件使 $E$ 只能取特定值——能级量子化由此而来。

**重点：能级量子化来自「边界条件」——束缚波函数必须在无穷远趋于零，这个条件让 $E$ 只取分立值。** 与弦的驻波（两端固定 → 特定频率）完全同构。束缚越强（势阱越深越窄），能级越离散。<span class="marginnote">「束缚 → 量子化」是量子力学的普遍规律：只要粒子被势能束缚在一个有限区域，它的能量就是离散的（势阱、谐振子、原子）。自由粒子（无束缚）能量连续。这与第七章「两端固定弦的驻波频率离散」、以及声学/光学的「边界条件决定本征频率」是同一个数学结构——谐振子的量子版本。</span>

## 4 公式解析：定态方程的物理结构

定态薛定谔方程的一维形式改写为「动能 = 总能 - 势能」的视角：

$$
-\frac{\hbar^2}{2m}\frac{\mathrm{d}^2\psi}{\mathrm{d}x^2} = (E - V)\psi
$$

- **第一步，移项**：把 $V\psi$ 移到右边：$-\frac{\hbar^2}{2m}\psi'' = (E - V)\psi$。
- **第二步，解读左边**：$\psi''$（二阶导数）描述波函数的「弯曲程度」；系数 $-\hbar^2/(2m)$ 使弯曲与动能对应。
- **第三步，解读右边**：$E - V$ 是动能（总能减势能）。$E > V$ 时右边为正，$\psi''$ 与 $\psi$ 异号 → 振荡解（三角函数，经典可到达区）；$E < V$ 时 $\psi''$ 与 $\psi$ 同号 → 指数解（经典禁戒区，隧穿的伏笔）。
- **第四步，直觉**：粒子能量高于势垒则波函数振荡（经典区），低于势垒则指数衰减（量子区仍有概率）——这是下一节势垒与隧穿的核心。

**辨析｜易错点：**定态薛定谔方程里 $E$ 是待求的本征值，$V$ 是给定的势能函数。「$E > V$ 振荡、$E < V$ 指数」是判断波函数形式的第一依据。解束缚态时，能量 $E$ 必须小于无穷远处的势能（束缚条件），否则是散射态。

## 5 定态薛定谔方程的地位

- **氢原子**：解中心力场中的定态方程，得到能级 $E_n = -13.6/n^2$ eV（与玻尔结果一致，图像全新）——第 106 节；
- **势阱/势垒**：一维无限深势阱（能级量子化）、谐振子（等间距能级）、势垒隧穿——第 104、105 节；
- **量子力学的数学框架**：定态方程的本征值问题在第二十三章系统展开（算符、本征态、微扰）。

<span class="marginnote">「薛定谔方程给出的一切与实验吻合」是它被接受的最终原因：氢原子能级、谐振子、隧穿、散射截面——全部正确。薛定谔自己一度困惑波函数的物理意义（以为是真实电荷云），玻恩的概率诠释（上节）补上了最后的拼图。方程 + 统计诠释 = 完整的量子力学。</span>

## 6 数值算例：定态的能量与概率

粒子在一维无限深方势阱（宽 $L$）中处于第 $n$ 个定态，能量 $E_n = \frac{n^2\pi^2\hbar^2}{2mL^2}$，波函数 $\psi_n = \sqrt{\frac{2}{L}}\sin\frac{n\pi x}{L}$。求基态能量与概率分布。

$$

E_1 = \frac{\pi^2\hbar^2}{2mL^2}, \qquad |\psi_1|^2 = \frac{2}{L}\sin^2\frac{\pi x}{L}

$$

- **第一步，写定态能量**：$E_n \propto n^2$——能级随 $n$ 平方增长（与谐振子 $E \propto n$ 不同）。
- **第二步，写概率密度**：$|\psi_n|^2$ 是位置的函数，不随时间变——定态概率静止。
- **第三步，读基态**：$n = 1$ 时概率密度在阱中央最大、两端为零——粒子最可能在中间。
- **第四步，解读**：定态波函数的驻波结构（$\sin n\pi x/L$）给出「量子化能级 + 概率分布」——能量离散来自边界条件（阱壁处 $\psi = 0$），概率分布来自波函数模方。<span class="marginnote">「定态与测量」：粒子处于定态时，能量确定（$E_n$ 单值），但位置不确定（$|\psi_n|^2$ 有分布）——能量确定与位置确定不兼容（不对易算符）。测量位置会塌缩波函数，破坏定态。这正是测量改变状态的量子力学日常：定态是测量能量后的稳态，测量位置会把它打乱。</span>

## 7 薛定谔方程的数学性质

薛定谔方程的数学结构决定了量子力学的许多特征：

- **线性**：方程对 $\psi$ 线性 ⟹ 叠加原理成立（两个解的和还是解）；
- **一阶时间导数**：$\partial\psi/\partial t$ 一阶 ⟹ 初态唯一确定后续演化（确定性演化、概率性测量）；
- **厄米性**：哈密顿算符 $\hat{H}$ 是厄米算符 ⟹ 能量本征值实数、时间演化是酉的（概率守恒）；
- **可分性**：$V = V(x) + V(y) + V(z)$ 时方程可分离变量 ⟹ 多维问题化为一维（三维势阱、谐振子）。

**重点：薛定谔方程的「线性 + 一阶 + 厄米」三性质——叠加原理、确定性演化、概率守恒。** 这些数学性质不是偶然，它们保证了量子力学的自洽性：线性保证叠加、一阶保证因果、厄米保证概率。<span class="marginnote">「薛定谔 vs 扩散方程」：薛定谔方程 $i\hbar\partial_t\psi = \hat{H}\psi$ 与扩散方程形似（都一阶时间），但 $i$ 是关键区别——薛定谔方程是波方程（振荡、可逆、概率守恒），扩散方程是耗散方程（衰减、不可逆）。这个 $i$ 让薛定谔方程保持概率守恒（$|\psi|^2$ 积分不随时间变），是量子力学可逆性的数学根源。</span>

**辨析｜易错点：**定态方程的解不是「全部解」——含时方程的一般解是定态解的叠加 $\psi(x,t) = \sum_n c_n\phi_n(x)e^{-iE_nt/\hbar}$。定态只是「能量确定」的特殊解；叠加态（非定态）的概率分布随时间演化。做题时先分清：求定态给能量本征函数，求一般态要叠加定态。

## 9 小结

- **含时薛定谔方程**：$i\hbar\frac{\partial\psi}{\partial t} = \hat{H}\psi$——量子力学基本方程，线性、一阶。
- **定态薛定谔方程**：$\hat{H}\phi = E\phi$，一维 $-\frac{\hbar^2}{2m}\psi'' + V\psi = E\psi$。
- 定态：能量确定、概率密度不随时间变化；$\psi = \phi e^{-iEt/\hbar}$。
- 求解六步：分区 → 写方程 → 求解 → 衔接 → 边界 → 量子化。
- **能级量子化来自边界条件**（束缚态波函数无穷远为零）——与驻波同构。
- $E > V$ 振荡（经典区）、$E < V$ 指数（量子区）——隧穿的伏笔。
