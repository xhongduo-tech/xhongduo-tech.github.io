## 为什么从等厚干涉开始

上一节提到薄膜干涉分等倾与等厚两种。**等厚干涉**是工程上最常用的：当入射光平行（通常垂直入射），干涉条纹只由薄膜厚度决定——同一条纹对应同一厚度。两种经典装置——**劈尖（wedge）**与**牛顿环（Newton's rings）**——把「薄膜厚度」变成「可测量的条纹」，用于检测光学表面平整度、测量波长、测量微小厚度。这一节把劈尖与牛顿环的原理、条纹公式与工程应用讲透。

## 1 等厚干涉的一般原理

两片玻璃间夹一个楔形空气层（或牛顿环的球面-平面间隙），平行光垂直入射。空气膜上下表面反射的两束光干涉，光程差：

$$\delta = 2ne + \frac{\lambda}{2}$$

其中 $n$ 是膜介质折射率（空气 $n = 1$）、$e$ 是膜厚，$\frac{\lambda}{2}$ 是半波损失（空气-玻璃，上表面反射有半波损失、下表面无）。

**重点：垂直入射 + 等厚膜时，光程差只由膜厚 $e$ 决定——同一条纹上的点对应相同的膜厚，这叫等厚条纹。** 明纹：$2ne + \frac{\lambda}{2} = k\lambda$；暗纹：$2ne + \frac{\lambda}{2} = (2k+1)\frac{\lambda}{2}$。相邻明纹（或暗纹）对应的膜厚差 $\Delta e = \lambda/(2n)$。

**辨析｜易错点：半波损失的判断。** 光从光疏介质（折射率小）射向光密介质（折射率大）反射时，相位突变 $\pi$（半波损失）；反之无。空气膜（$n = 1$）上下都是玻璃（$n \approx 1.5$）：上表面（空气→玻璃）有半波损失，下表面（玻璃→空气）无——所以光程差补 $\lambda/2$。**若膜介质折射率介于两玻璃之间（如油膜夹在玻璃间），上下表面半波损失情况反转，判断要重新做。**

## 2 劈尖干涉

**劈尖（wedge）**：两片平面玻璃在一端接触、另一端垫一个微小厚度，中间形成楔形空气层。

垂直入射光在楔形空气层上下表面反射干涉，形成平行于棱边的等距直条纹（等厚线）。

**相邻条纹间距 $l$** 与楔角 $\theta$ 的关系：

$$l = \frac{\lambda}{2n\theta}$$

（空气 $n = 1$：$l = \lambda/(2\theta)$）因为相邻条纹膜厚差 $\lambda/2$，而膜厚沿劈尖变化率由楔角决定：$\Delta e = l\cdot\theta$。<span class="marginnote">「条纹间距 = 波长/(2×楔角)」是劈尖的核心公式：楔角越小，条纹越宽；波长越大，条纹越宽。劈尖尖端（$e = 0$）处，光程差 $\delta = \lambda/2$（半波损失），是暗纹——劈尖尖端的棱边总是暗的，这是判断「有没有半波损失」的实验证据。</span>

**辨析｜易错点：**劈尖尖端是暗纹还是明纹？空气楔尖端 $e = 0$，光程差 $= \lambda/2$（半波损失），是暗纹。若两玻璃间不是空气而是折射率介于玻璃之间的膜（如油），半波损失情况可能变化——但「空气楔尖端暗纹」是标准结论。条纹间距公式 $l = \lambda/(2n\theta)$ 中 $\theta$ 很小，用弧度。

**数值算例（劈尖测薄片厚度）**：两平玻璃一端接触、另一端垫一薄片，钠光（$\lambda = 589$ nm）垂直入射，测得相邻暗纹间距 $l = 2.0$ mm，玻璃长度 $L = 10$ cm。由 $l = \lambda/(2\theta)$ 得楔角 $\theta = \lambda/(2l) = 589\times10^{-9}/(2\times2.0\times10^{-3}) \approx 1.47\times10^{-4}$ rad。薄片厚度 $h = L\tan\theta \approx L\theta = 0.1\times1.47\times10^{-4} \approx 1.47\times10^{-5}$ m ≈ 15 μm。**「量条纹间距 → 算楔角 → 得薄片厚度」是劈尖测量微小厚度的标准流程**，精度达波长量级。

## 3 牛顿环

**牛顿环（Newton's rings）**：一个曲率半径很大的凸透镜放在平面玻璃上，透镜与平板间形成厚度不均匀的圆环状空气膜。

垂直入射光干涉，形成以接触点为中心的同心圆环（等厚条纹）。**接触点处膜厚为零，光程差 $\lambda/2$（半波损失），是暗斑。**

半径 $r$ 处膜厚 $e$ 与透镜曲率半径 $R$ 的关系：$e = \frac{r^2}{2R}$（几何关系，$r \ll R$ 时）。暗纹条件 $2e + \lambda/2 = (2k+1)\lambda/2$，即 $2e = k\lambda$，代入得：

**第 $k$ 级暗环半径**：

$$r_k = \sqrt{kR\lambda}$$

**第 $k$ 级明环半径**：$r_k = \sqrt{(2k-1)R\lambda/2}$。

**重点：牛顿环暗环半径 $r_k = \sqrt{kR\lambda}$——正比于 $\sqrt{k}$，环越向外越密。** 这是牛顿环最显著的特征：不是等间距的圆环，而是「内疏外密」的同心环。由 $r_k$ 与 $k$ 的关系可测透镜曲率半径 $R$ 或波长 $\lambda$。<span class="marginnote">牛顿环是牛顿亲手做的实验（虽然他用的是「光微粒说」的解释）。「内疏外密」的根源：膜厚随半径按 $e = r^2/(2R)$ 变化，是抛物线而非线性——等厚线（圆环）的半径随 $\sqrt{k}$ 增长，间距越来越小。</span>

**数值算例（牛顿环测波长）**：曲率半径 $R = 2$ m 的透镜，测得第 5 级暗环半径 $r_5 = 2.4$ mm。由 $r_k^2 = kR\lambda$ 得 $\lambda = r_5^2/(5R) = (2.4\times10^{-3})^2/(5\times2) = 5.76\times10^{-7}$ m = 576 nm——绿光。**牛顿环既测 $R$ 又测 $\lambda$，是「用一个已知量换另一个未知量」的典型**。若透镜受压变形（接触点不再是理想点），中心暗斑会变成圆斑或亮斑，测量基准要相应修正。

## 4 公式解析：牛顿环测曲率半径

用钠光（$\lambda = 589$ nm）做牛顿环实验，测得第 10 级暗环半径 $r_{10} = 4.2\ \text{mm}$。求透镜曲率半径 $R$。

$$
R = \frac{r_k^2}{k\lambda} = \frac{(4.2\times10^{-3})^2}{10\times589\times10^{-9}}
$$

- **第一步，写暗环公式**：$r_k = \sqrt{kR\lambda}$，反解 $R = r_k^2/(k\lambda)$。
- **第二步，代入**：$R = \frac{(4.2\times10^{-3})^2}{10\times589\times10^{-9}} = \frac{1.76\times10^{-5}}{5.89\times10^{-6}} \approx 2.99\ \text{m}$。
- **第三步，解读**：曲率半径约 3 m——符合「大曲率半径凸透镜」的实验设定。
- **第四步，检验**：$r_{10} = \sqrt{10\times3\times589\times10^{-9}} = \sqrt{1.77\times10^{-5}} \approx 4.2\ \text{mm}$，与数据一致。

**辨析｜易错点：**牛顿环中「$k$ 从哪一级数起」要小心。中心接触点为暗斑，对应 $k = 0$ 级暗环（$r_0 = 0$）。若透镜与平板间有灰尘（接触不完美），中心可能不是暗斑而是亮斑，需修正膜厚基准。此外，明环公式带 $\frac{1}{2}$ 因子（$r_k = \sqrt{(2k-1)R\lambda/2}$），明暗公式别混。

## 5 等厚干涉的应用

- **光学表面检测**：标准平晶与被检表面构成劈尖，干涉条纹的平直度反映表面平整度——条纹弯曲说明表面有凹凸（检测精度达波长量级）；
- **微小厚度测量**：测量薄膜厚度、镀膜厚度（由条纹移动数反推厚度差）；
- **测折射率**：劈尖中换介质，条纹间距变化反映折射率；
- **测波长 / 曲率半径**：牛顿环的经典应用；
- **干涉显微镜**：利用等厚干涉放大表面形貌。

<span class="marginnote">「条纹弯曲判断凹凸」是光学检测的经典考题：若待检表面在某处凸起，该处膜厚变薄，等厚线向劈尖尖端（膜薄方向）弯曲。判断口诀：凸起处条纹向薄侧弯，凹陷处向厚侧弯。工业上透镜加工用牛顿环检验球面曲率是否合格——「牛顿环均匀」意味着曲率完美。</span>

## 6 等倾干涉与等厚干涉的对照

**辨析｜易错点：等倾 vs 等厚的区别。** 薄膜干涉分两类：

| 对比项 | 等倾干涉 | 等厚干涉 |
| --- | --- | --- |
| 入射光 | 扩展光源 | 平行光（垂直入射） |
| 光程差取决于 | 入射角 | 膜厚 |
| 条纹形状 | 同心圆环（均匀膜） | 等厚线（劈尖直条纹、牛顿环圆环） |
| 典型装置 | 平行平面膜、迈克耳孙 | 劈尖、牛顿环 |

**重点：等厚干涉的「同一条纹 = 同一厚度」让条纹直接映射膜厚分布——这是表面检测、厚度测量的基础。** 等倾干涉则对应「同一条纹 = 同一角度」。两类干涉都是「薄膜干涉光程差」公式的不同取值方式，理解这个统一，就掌握了第十六章薄膜干涉的全貌。<span class="marginnote">「从等厚干涉到迈克耳孙」：迈克耳孙干涉仪可视为「等倾/等厚可切换」的可调薄膜——移动反射镜改变等效膜厚，条纹移动数就是镜移动量（精度达波长量级）。下一节迈克耳孙干涉仪把等厚干涉的「条纹计数测位移」思想发挥到极致。</span>

## 7 小结

- **等厚干涉**：垂直入射平行光，光程差 $= 2ne + \lambda/2$，条纹由膜厚决定。
- **劈尖**：相邻条纹间距 $l = \lambda/(2n\theta)$；尖端（$e=0$）因半波损失为暗纹。
- **牛顿环**：同心圆环，暗环 $r_k = \sqrt{kR\lambda}$，明环 $r_k = \sqrt{(2k-1)R\lambda/2}$；中心暗斑；内疏外密。
- **半波损失判断**：光疏→光密反射有 $\pi$ 相位突变；膜介质折射率介于两侧时需重判。
- **数值流程**：劈尖量间距算楔角得厚度；牛顿环由 $r_k$ 测 $R$ 或 $\lambda$。
- 应用：表面平整度检测、微小厚度/折射率测量、测波长与曲率半径。
- 条纹弯曲判凹凸：凸起弯向薄侧、凹陷弯向厚侧。
- **等倾 vs 等厚**：等倾看角度（扩展光源）、等厚看厚度（垂直平行光）——两类干涉统一。
- **数值要点**：劈尖 $l = \lambda/(2n\theta)$ 量楔角测厚度；牛顿环 $r_k^2 = kR\lambda$ 测 $R$ 或 $\lambda$。
- **接触点判据**：空气楔尖端/牛顿环中心因半波损失为暗——「有无半波损失」的实验证据。
- **测量思想**：把「膜厚/楔角/曲率半径」映射为「可数的条纹」——用光波长作尺子。
- **条纹计数**：移动一条条纹 ≈ 膜厚变化 $\lambda/2$——波长量级的高灵敏度测量基础。
