# 电场与电场强度

<div class="epigraph">

## 为什么从电场开始

库仑定律把「电荷之间的力」描述得很清楚，但它隐含一个疑问：两个相距遥远的电荷，它们之间没有接触，力是怎么「传到」的？法拉第给出了革命性的回答：电荷不直接相互作用，而是在周围空间激发**电场（electric field）**，电场再对其他电荷施力。这个「场」的观念看似只是换了种说法，却是物理学的分水岭——场是独立存在的物理实在，携带能量与动量，光本身也是电磁场（第十四章）。这一节我们定义电场与电场强度，学会计算点电荷与点电荷系的电场。

## 1 电场与电场强度

**电场（electric field）**：存在于电荷周围空间、对置于其中的电荷施加力的特殊物质。电场是客观存在的，不依赖是否放入了试探电荷。

用**试探电荷** $q_0$（带电量足够小、不扰动原电场）来探测电场，定义**电场强度（electric field strength）**：

$$\boldsymbol{E} = \frac{\boldsymbol{F}}{q_0}$$

单位 $\text{N/C}$（与 $\text{V/m}$ 等价）。电场强度是矢量，方向与正试探电荷受力方向一致。<span class="marginnote">「试探电荷」是个理想化工具：它足够小，不会改变待测电场。用「单位正电荷受到的力」定义电场，电场强度就只由源电荷与位置决定，与试探电荷无关——这正是把「力」提炼成「场」的意义。</span>

**重点：电场强度是场的属性，与试探电荷无关。** $\boldsymbol{E}$ 由源电荷分布与空间位置决定；放不放试探电荷、放多大的试探电荷，$\boldsymbol{E}$ 都在那里。公式 $\boldsymbol{E} = \boldsymbol{F}/q_0$ 是「测量」定义，不是「产生」定义。

## 2 点电荷的电场

由库仑定律，点电荷 $q$ 在距离 $r$ 处产生的场强：

$$E = \frac{1}{4\pi\varepsilon_0}\frac{q}{r^2}$$

方向：$q > 0$ 时沿径向向外，$q < 0$ 时沿径向指向电荷。

**辨析｜易错点：**场强公式与库仑定律形式相似，但物理不同——库仑定律是两个电荷间的**力**，场强公式是单个电荷在空间中产生的**场**。场强 $E = kq/r^2$ 与试探电荷无关；受力 $F = q_0E$ 才与试探电荷有关。考试中「$E$ 与 $q$ 成正比、与 $r^2$ 成反比」是对点电荷场源的描述，不是对「某点的场强」的普适描述。

## 3 场强叠加原理

**场强叠加原理**：多个电荷在空间某点产生的总场强，等于各电荷单独产生的场强的矢量和：

$$\boldsymbol{E} = \sum_i \boldsymbol{E}_i = \frac{1}{4\pi\varepsilon_0}\sum_i\frac{q_i}{r_i^2}\hat{\boldsymbol{r}}_i$$

这是库仑力叠加原理的直接推论（场强 = 力 ÷ 试探电荷，除以同一常数不影响叠加）。<span class="marginnote">叠加原理是「拆-算-合」的经典套路：复杂电荷系统（偶极子、线电荷、连续分布）的场强，都是先分解成点电荷，再矢量求和（连续分布则积分）。这个思路贯穿整个静电学，下一节《连续带电体电场强度的计算》就是它的积分版本。</span>

## 4 公式解析：电偶极子中垂线上的场强

两个等量异号点电荷 $+q$、$-q$ 相距 $2a$（构成**电偶极子**），求中垂线上距中心 $r$ 处的场强。

$$
E = \frac{1}{4\pi\varepsilon_0}\frac{q}{\left(r^2 + a^2\right)^{3/2}}\cdot a \quad\xrightarrow{r \gg a}\quad E \approx \frac{1}{4\pi\varepsilon_0}\frac{p}{r^3}
$$

- **第一步，对称性分析**：中垂线上两点电荷到场点的距离相同（$\sqrt{r^2+a^2}$），场强大小相同；方向分别沿各自连线，其竖直分量（沿中垂线方向）互相抵消。
- **第二步，取水平分量**：每个电荷的场强水平分量为 $E_1\cos\theta$，$\cos\theta = \frac{a}{\sqrt{r^2+a^2}}$，方向相同，总场强 $E = 2E_1\cos\theta$。
- **第三步，代入**：$E = 2\cdot\frac{kq}{r^2+a^2}\cdot\frac{a}{\sqrt{r^2+a^2}} = \frac{2kqa}{(r^2+a^2)^{3/2}}$。
- **第四步，远场近似**：引入**电偶极矩** $p = 2qa$，$r \gg a$ 时 $E \approx \frac{1}{4\pi\varepsilon_0}\frac{p}{r^3}$——偶极子远场按 $1/r^3$ 衰减，比点电荷（$1/r^2$）更快，因为正负电荷的场在远处部分抵消。

**重点：电偶极子远场 $E \propto p/r^3$，净电荷为零但仍有场。** 许多分子（水、氨）是电偶极子，它们之间的相互作用与 $p$ 直接相关——这是理解分子间作用力（范德瓦尔斯力）、介质极化（第十一章）的起点。

## 5 电场线

**电场线（electric field lines）**：形象描述电场分布的曲线，其上每一点的切线方向与该点场强方向一致。

电场线的基本性质：

- 始于正电荷，终止于负电荷（或延伸到无穷远），不在无电荷处中断；
- 电场线不相交（每点场强方向唯一）；
- 电场线的疏密表示场强大小（密处场强大）；
- 电场线是假想的描述工具，不是真实存在的物理线。

<span class="marginnote">法拉第用「力线」可视化电场，虽然后来我们知道它只是描述工具，但电场线的思想直接催生了「场」的概念。平行板间的均匀电场对应均匀分布的平行电场线；点电荷对应辐射状电场线。电荷与场的相互作用（静电平衡、屏蔽）在电场线图像里会非常直观。</span>

**辨析｜易错点：**电场线不是「电荷运动的轨迹」。只在均匀电场且电荷初速度沿场线时，轨迹才与电场线重合。带电粒子在电场中的轨迹由受力与初速度共同决定，一般曲线并不沿电场线——「电场线 ≠ 运动轨迹」是电场图像题的高频陷阱。

## 6 数值算例：两个点电荷的场强叠加

在 $x$ 轴上 $x_1 = -0.1\ \mathrm{m}$ 处放 $q_1 = +4\times10^{-9}\ \mathrm{C}$，$x_2 = +0.1\ \mathrm{m}$ 处放 $q_2 = -4\times10^{-9}\ \mathrm{C}$。求原点处的场强。

$$

E_1 = \frac{kq_1}{r_1^2} = \frac{9\times10^9\times4\times10^{-9}}{0.01} = 3600\ \mathrm{N/C}\ \text{（沿 } +x\text{）}, \qquad E_2 = \frac{k|q_2|}{r_2^2} = 3600\ \mathrm{N/C}\ \text{（沿 } +x\text{）}

$$

- **第一步，算 $q_1$ 在原点产生的场**：$E_1 = kq_1/r_1^2 = 3600$ N/C，方向沿 $+x$（正电荷径向向外）。
- **第二步，算 $q_2$ 在原点产生的场**：$|E_2| = 3600$ N/C，方向沿 $+x$（负电荷场指向电荷，即指向 $+x$）。
- **第三步，矢量叠加**：两场同向，$E = E_1 + E_2 = 7200$ N/C，方向 $+x$。
- **第四步，解读**：这是电偶极子的中点情形（两电荷在原点两侧）——场强叠加原理把「两个电荷」拆成「两个单电荷场」，再矢量和。对称位置、等大电荷时计算尤其简单。<span class="marginnote">「为什么负电荷的场方向指向它自己」：场强定义用正试探电荷，正电荷受斥力（场向外）、负电荷受引力（场向内）——所以正电荷的场向外、负电荷的场指向自身。判断方向时先定试探电荷（正）的受力方向即可。叠加时务必用矢量（分量）而非代数求和。</span>

## 7 电场与引力场的类比

电场与引力场结构高度相似，值得对照记忆：

| 比较项 | 电场 | 引力场 |
| --- | --- | --- |
| 源 | 电荷 $q$ | 质量 $m$ |
| 场强 | $\boldsymbol{E} = \frac{1}{4\pi\varepsilon_0}\frac{q}{r^2}\hat{\boldsymbol{r}}$ | $\boldsymbol{g} = -G\frac{m}{r^2}\hat{\boldsymbol{r}}$ |
| 力 | $\boldsymbol{F} = q\boldsymbol{E}$ | $\boldsymbol{F} = m\boldsymbol{g}$ |
| 势 | $V = \frac{1}{4\pi\varepsilon_0}\frac{q}{r}$ | $\phi = -G\frac{m}{r}$ |
| 叠加 | 场强叠加 | 场强叠加 |

**重点：电场与引力场共享同一套「场 + 叠加」结构，只是源不同、方向不同（电荷可正可负、质量恒正）。** 引力场只有吸引（质量恒正）、电场可吸引可排斥（电荷有正负）——所以电场有电偶极子、引力场没有引力偶极子；电场的正负电荷可中和，引力的质量不能抵消。这个类比让静电学的许多结论可以迁移到引力（如高斯定理）。<span class="marginnote">「从静电场到引力场」：高斯定理、场强叠加、势能方法在引力场中同样成立（用 $G$ 换 $1/4\pi\varepsilon_0$、$m$ 换 $q$）。第七篇广义相对论把引力重新理解为时空弯曲——但在经典框架下，「电场与引力场同构」是理解两者最省力的捷径。这个类比也是「场」概念统一物理的第一步。</span>

**辨析｜易错点：**电场强度 $E = kq/r^2$ 与库仑力 $F = kq_1q_2/r^2$ 的区分：$E$ 描述场、$F$ 描述相互作用；$F = q_0E$。判断方向时，电场方向与正电荷受力一致；引力场方向与质量受力（引力）一致但指向大质量。单位不同：电场 $\mathrm{N/C}$（或 $\mathrm{V/m}$）、引力场 $\mathrm{N/kg}$（即 $\mathrm{m/s^2}$）。

## 8 术语速查表

| 术语 | 公式 | 要点 |
| --- | --- | --- |
| 电场 | 电荷周围的空间 | 场的物理实在 |
| 电场强度 | $\boldsymbol{E} = \boldsymbol{F}/q_0$ | 与试探电荷无关 |
| 点电荷场 | $E = kq/r^2$ | 径向、$1/r^2$ |
| 叠加原理 | $\boldsymbol{E} = \sum\boldsymbol{E}_i$ | 矢量求和 |
| 电偶极矩 | $p = ql$ | 远场 $E \propto p/r^3$ |
| 电场线 | 切线 = 方向 | 不是运动轨迹 |

电场是电荷之间相互作用的「媒介」：电荷激发场、场对其他电荷施力。电场强度 $\boldsymbol{E} = \boldsymbol{F}/q_0$、点电荷场 $E = kq/r^2$、叠加原理，是静电学的三块基石；电偶极子与电场线则给出场的结构与可视化。下一节我们把点电荷的求和推广到积分——计算**连续带电体电场强度**。

## 9 小结

- **电场**：电荷周围空间存在的特殊物质，对试探电荷施力；是独立物理实在。
- **电场强度**：$\boldsymbol{E} = \boldsymbol{F}/q_0$，矢量，只由源电荷与位置决定。
- 点电荷场强：$E = kq/r^2$，正电荷径向向外、负电荷指向电荷。
- **场强叠加原理**：$\boldsymbol{E} = \sum\boldsymbol{E}_i$，复杂系统先拆后算。
- 电偶极子远场 $E \propto p/r^3$；电场线描述场分布（切线 = 方向、疏密 = 大小），不是运动轨迹。
