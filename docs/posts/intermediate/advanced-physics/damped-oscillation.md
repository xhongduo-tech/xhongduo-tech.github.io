# 阻尼振动

## 为什么从阻尼振动开始

前三节的简谐振动是理想化的：没有阻力、能量守恒、永不停歇。但真实的振动系统总有能量损失——空气阻力、摩擦力、内耗。拨动的琴弦终会静默，钟摆终会停摆。**阻尼振动（damped oscillation）**研究这种「带摩擦」的振动：振幅随时间指数衰减，能量逐渐耗散。它既解释了现实的振动为何不会永远持续，也引出一个重要的工程问题——如何控制阻尼：太强则系统「拖死」不振，太弱则衰减太慢。下一节的受迫振动与共振，正是在阻尼的基础上引入外部驱动力。

## 1 阻尼振动的运动方程

考虑轻弹簧振子受与速度成正比的阻力 $F_r = -\gamma v$（黏性阻力），运动方程：

$$m\frac{\mathrm{d}^2x}{\mathrm{d}t^2} = -kx - \gamma\frac{\mathrm{d}x}{\mathrm{d}t}$$

令 $\omega_0^2 = \frac{k}{m}$、$2\beta = \frac{\gamma}{m}$，其中 $\beta$ 叫**阻尼系数（damping coefficient）**，方程化为：

$$\frac{\mathrm{d}^2x}{\mathrm{d}t^2} + 2\beta\frac{\mathrm{d}x}{\mathrm{d}t} + \omega_0^2 x = 0$$

解的形式取决于阻尼的大小，分三种情况——这是阻尼振动最核心的分类。<span class="marginnote">阻力取 $- \gamma v$ 是「线性阻尼」模型：阻力与速度成正比。空气阻力在低速时近似如此，但高速时变为与 $v^2$ 成正比（湍流阻力），那是非线性问题，不在本课程范围。</span>

## 2 三种阻尼状态

设 $\beta$ 与 $\omega_0$ 的相对大小决定解的行为：

### 欠阻尼（$\beta < \omega_0$）

解为振幅指数衰减的振动：

$$x = A_0e^{-\beta t}\cos(\omega' t + \varphi), \qquad \omega' = \sqrt{\omega_0^2 - \beta^2}$$

系统仍然来回振动，但振幅按 $A_0e^{-\beta t}$ 指数衰减。**阻尼振动的周期比无阻尼时略长**（$\omega' < \omega_0$）。

**对数减缩（logarithmic decrement）**：相邻两个同方向振幅之比的对数，衡量衰减快慢：

$$\Lambda = \ln\frac{A_n}{A_{n+1}} = \beta T$$

<span class="marginnote">对数减缩是实验测量阻尼的标尺：连续记录第 $n$ 次与第 $n+1$ 次的振幅，取对数即得 $\Lambda$，再除以周期得 $\beta$。弦乐器的琴弦、音叉的「余音」长短，都由阻尼大小决定。</span>

### 临界阻尼（$\beta = \omega_0$）

系统恰好不振动，以最快的速度回到平衡位置（无过冲）。这是**临界阻尼（critical damping）**。

### 过阻尼（$\beta > \omega_0$）

系统缓慢地回到平衡位置，不振动，比临界阻尼更慢。

**重点：临界阻尼是「最快回到平衡且不振荡」的分界。** 这个性质有重大工程价值：汽车减震器、电梯缓冲、仪表指针都要调到临界阻尼附近——阻尼太小会来回摆动（指针晃悠），阻尼太大会反应迟钝，临界阻尼刚好「一次到位」。

## 3 阻尼振动的能量

阻尼力做负功，系统机械能不断耗散。对欠阻尼振动，总能量按指数衰减：

$$E(t) = E_0e^{-2\beta t}$$

其中 $E_0 = \frac{1}{2}kA_0^2$ 是初始能量。<span class="marginnote">能量的衰减速率是振幅衰减速率的两倍（$2\beta$ 对 $\beta$）：因为能量正比于振幅平方。若振幅每周期衰减 1%，能量每周期约衰减 2%。耗散掉的机械能转化为内能（热），这是第五章黏性耗散思想的延续，也是热力学第二定律在振动中的体现。</span>

**辨析｜易错点：**「阻尼振动的周期比无阻尼周期大」容易记反。直觉上阻力拖慢运动，所以周期变长、频率变小，正确方向是 $\omega' = \sqrt{\omega_0^2-\beta^2} < \omega_0$。另外，**振幅衰减是指数的，不是线性的**——每过一个「时间常数 $\tau = 1/\beta$」，振幅缩为原来的 $e^{-1} \approx 37\%$，永远到不了零，只是无限趋近。

## 4 公式解析：欠阻尼振动的时间常数

一个欠阻尼弹簧振子，$m = 1\ \text{kg}$，$k = 100\ \text{N/m}$，阻力系数 $\gamma = 2\ \text{kg/s}$。求阻尼系数 $\beta$、阻尼振动的角频率 $\omega'$，以及振幅衰减到初始值 $1\%$ 所需的时间。

$$
\beta = \frac{\gamma}{2m} = \frac{2}{2\times1} = 1\ \text{s}^{-1}, \qquad \omega' = \sqrt{\omega_0^2 - \beta^2} = \sqrt{100 - 1} \approx 9.95\ \text{rad/s}
$$

- **第一步，求 $\beta$**：$\beta = \gamma/(2m) = 1\ \text{s}^{-1}$；固有角频率 $\omega_0 = \sqrt{k/m} = 10\ \text{rad/s}$。
- **第二步，判断阻尼类型**：$\beta = 1 < \omega_0 = 10$，欠阻尼，系统会振动。
- **第三步，求阻尼振动角频率**：$\omega' = \sqrt{\omega_0^2-\beta^2} = \sqrt{99} \approx 9.95$ rad/s，比 $\omega_0$ 略小。
- **第四步，求衰减时间**：振幅满足 $A(t) = A_0e^{-\beta t}$，令 $e^{-\beta t} = 0.01$，$\beta t = \ln 100 \approx 4.6$，$t \approx 4.6$ s。

**重点：衰减到 1% 的时间只由 $\beta$ 决定，与振幅大小无关。** 衰减时间 $t = \ln(A_0/A)/\beta$ 是对数关系——把振幅缩小 100 倍，需要约 4.6 个时间常数，与初始振幅无关，这是指数衰减的普遍规律。

## 5 阻尼对振动的影响小结

| 阻尼状态 | 条件 | 运动形态 | 回到平衡的速度 |
| --- | --- | --- | --- |
| 欠阻尼 | $\beta < \omega_0$ | 振幅指数衰减的振动 | 振动中逐渐衰减 |
| 临界阻尼 | $\beta = \omega_0$ | 不振动，单调回稳 | 最快且无过冲 |
| 过阻尼 | $\beta > \omega_0$ | 不振动，缓慢回稳 | 慢 |

<span class="marginnote">这张表也是控制理论的雏形：系统的「阻尼比」决定响应是振荡收敛还是单调收敛。从减震器到电气仪表，从生物体的摆动回稳到电网的振荡抑制，「临界阻尼最优」是一条跨领域的工程原则。</span>

## 6 小结

- **阻尼振动方程**：$\ddot{x} + 2\beta\dot{x} + \omega_0^2x = 0$，$\beta = \gamma/(2m)$。
- 欠阻尼：$x = A_0e^{-\beta t}\cos(\omega't+\varphi)$，$\omega' = \sqrt{\omega_0^2-\beta^2}$；临界阻尼与过阻尼不振动。
- 对数减缩 $\Lambda = \beta T$ 用于实验测量阻尼。
- 能量 $E = E_0e^{-2\beta t}$ 指数衰减；衰减速率是振幅衰减速率的两倍。
- 临界阻尼「最快回稳不振荡」，是减震器、仪表指针的设计目标。

在下一节，我们给阻尼振子加上一个持续的外部驱动力，研究**受迫振动与共振**——振幅如何被驱动频率放大到惊人的程度。
