## 为什么从微分形式开始

第 71 节我们写出了麦克斯韦方程组的积分形式——它描述「通量/环流」的整体性质。电动力学需要**微分形式**：用**散度（divergence）**与**旋度（curl）**表达场在每一点的局域规律。微分形式是电磁场理论的标准语言——它让「场如何由源激发」「场如何相互转化」变成一组偏微分方程，也是电磁波方程（第 69 节）推导的基础。这一节建立微分算子，把积分形式改写为微分形式。<span class="marginnote">「积分 → 微分」不是绕圈子，而是换一副更精细的眼镜：积分形式像用「整块地皮的账」描述土地，微分形式像用「每一平方米的土壤」描述土地——信息等价，但后者才能描述逐点变化。电动力学几乎所有后续工作（电磁波、辐射、边值问题、数值计算）都站在这四个微分方程上。</span>

## 1 散度、旋度与高斯、斯托克斯定理

**散度（divergence）**：$\nabla\cdot\boldsymbol{F} = \frac{\partial F_x}{\partial x} + \frac{\partial F_y}{\partial y} + \frac{\partial F_z}{\partial z}$——度量场的「源」强度（单位体积的通量）。

**旋度（curl）**：$\nabla\times\boldsymbol{F}$——度量场的「涡旋」强度（单位面积的环流）。

**高斯定理（散度定理）**：$\oint_S\boldsymbol{F}\cdot\mathrm{d}\boldsymbol{S} = \int_V\nabla\cdot\boldsymbol{F}\,\mathrm{d}V$——通量 = 散度体积分。

**斯托克斯定理**：$\oint_L\boldsymbol{F}\cdot\mathrm{d}\boldsymbol{l} = \int_S(\nabla\times\boldsymbol{F})\cdot\mathrm{d}\boldsymbol{S}$——环流 = 旋度面积分。

**重点：高斯定理与斯托克斯定理把「积分（整体）」与「微分（局域）」连接起来——积分形式的麦克斯韦方程组经它们可改写为微分形式。** 这两个定理是矢量分析的核心工具：通量对应散度、环流对应旋度。

一个具体的散度计算：$\boldsymbol{F} = (x^2, 3y, z)$，则 $\nabla\cdot\boldsymbol{F} = 2x + 3 + 1 = 2x + 4$——散度随位置变化，说明「源的密度」各处不同。对 $\boldsymbol{F} = (y, -x, 0)$（绕 $z$ 轴的旋转场），$\nabla\cdot\boldsymbol{F} = 0$（无源）但 $\nabla\times\boldsymbol{F} = (0, 0, -2) \neq 0$（有涡旋）——散度看源、旋度看涡，两个算子各管一件事。

**辨析｜易错点：**散度与旋度是「局域量」：散度描述场在某点附近的「涌出或汇入」，旋度描述场在某点附近的「旋转」。$\nabla\cdot\boldsymbol{F} = 0$ 表示该点无源，$\nabla\times\boldsymbol{F} = 0$ 表示该点无旋——两者独立，可以同时为零、同时非零、或一零一非零。判断场是「源场」「涡旋场」还是「两者皆有」，就看散度与旋度各自是否为零。

这三个算子（梯度、散度、旋度）是矢量分析的全部「微分装备」，与「从极限到大模型」主线里的多元微积分直接衔接：梯度是方向导数的推广、散度与旋度是微元法在矢量场上的应用。第一级学过的「微分 → 积分」思想，在这里升级为「梯度/散度/旋度 → 线/面/体积分」的矢量微积分——数学与物理的又一次精确对应。

## 2 麦克斯韦方程组的微分形式

用高斯与斯托克斯定理，把积分形式（第 71 节）改写为微分形式：

**① 电场高斯定理**（电场的源是电荷）：

$$\nabla\cdot\boldsymbol{D} = \rho_f$$

**② 磁场高斯定理**（无磁单极子）：

$$\nabla\cdot\boldsymbol{B} = 0$$

**③ 法拉第定律**（变化磁场产生电场）：

$$\nabla\times\boldsymbol{E} = -\frac{\partial\boldsymbol{B}}{\partial t}$$

**④ 安培-麦克斯韦定律**（电流与变化电场产生磁场）：

$$\nabla\times\boldsymbol{H} = \boldsymbol{j}_f + \frac{\partial\boldsymbol{D}}{\partial t}$$

其中 $\rho_f$ 是自由电荷密度、$\boldsymbol{j}_f$ 是传导电流密度。

**重点：微分形式把「积分 = 总量」变为「散度/旋度 = 每一点的源」。** ① 说「电场散度 = 电荷密度」（电荷是电场的源）、② 说「磁场散度恒为零」（无磁荷）、③ 说「电场旋度 = −磁场变化率」（变化磁场生电场）、④ 说「磁场旋度 = 电流 + 变化电场」（电流与位移电流生磁场）。<span class="marginnote">「微分形式 vs 积分形式」：积分形式看「整体通量/环流」，微分形式看「局域散度/旋度」。两者由高斯/斯托克斯定理等价——同一物理的两种表述。微分形式是偏微分方程组，更适合作为场论的出发点（边界条件、电磁波、辐射都从微分形式推导）。</span>

把积分与微分对照着读更清楚：积分形式说「穿过这个球面的总通量等于面内总电荷」，微分形式说「这一点上散度等于电荷密度」。把积分形式的高斯面缩到无穷小，就得到微分形式——这就是「整体 → 局域」的精确含义。同样的对应也适用于磁场：积分形式「磁通量恒为零」对应微分形式「磁散度恒为零」，两个都是「无磁单极子」的表述。

**辨析｜易错点：**微分形式中的 $\rho_f$ 与 $\boldsymbol{j}_f$ 是**自由**电荷/电流密度——束缚电荷（极化）与磁化电流已经被吸收进 $\boldsymbol{D}$ 与 $\boldsymbol{H}$ 的定义（见《电介质的极化》与《磁介质的磁化》）。若直接写 $\nabla\cdot\boldsymbol{E} = \rho/\varepsilon_0$，右边的 $\rho$ 是总电荷（含束缚电荷），容易算重。先用 $\boldsymbol{D}$、$\boldsymbol{H}$ 写方程、再代介质方程，是微分形式的标准操作。

四个微分方程合起来的信息量与积分形式完全等价，但表达更「紧凑」：全部电磁现象（静电、静磁、感应、电磁波）都浓缩在四个局域方程里。可以说，微分形式是「电磁学的第一原理」——任何一个电磁场问题，最终都可以归结为这四个方程在给定边界条件下的解。

## 3 公式解析：由电荷分布求场（微分形式的使用）

已知电荷密度 $\rho(x, y, z)$，用微分形式说明如何求电场。

$$
\nabla\cdot\boldsymbol{E} = \frac{\rho}{\varepsilon_0} \quad\text{（真空）}, \qquad \nabla\times\boldsymbol{E} = 0 \quad\text{（静电场无旋）}
$$

- **第一步，静电场两个方程**：$\nabla\cdot\boldsymbol{E} = \rho/\varepsilon_0$（源方程）、$\nabla\times\boldsymbol{E} = 0$（无旋，静电场保守）。
- **第二步，无旋 ⟹ 有势**：$\nabla\times\boldsymbol{E} = 0$ ⟹ 存在标势 $\phi$ 使 $\boldsymbol{E} = -\nabla\phi$（静电势）。
- **第三步，代入源方程**：$\nabla\cdot(-\nabla\phi) = \rho/\varepsilon_0$ ⟹ $\nabla^2\phi = -\rho/\varepsilon_0$——**泊松方程**。
- **第四步，求解**：给定电荷分布，解泊松方程得电势，再取梯度得电场——静电学的微分形式路线。

**辨析｜易错点：**「无旋场必有势」的严格条件（单连通区域）与「静电场无旋」的适用边界（静电场、无变化磁场）要清楚。$\nabla\times\boldsymbol{E} = 0$ 只在静电场成立；有变化磁场时（方程③）电场有旋、不能再定义电势。

用泊松方程解一个经典问题：均匀带电球体（半径 $R$、电荷密度 $\rho$）。球外 $\rho = 0$，泊松方程退化为拉普拉斯方程 $\nabla^2\phi = 0$，球对称解 $\phi = C/r$，由球面边界条件定 $C$，得 $\boldsymbol{E} = Q/(4\pi\varepsilon_0r^2)\hat{r}$——与高斯定理的积分结果一致。这说明微分形式与积分形式殊途同归：一个从局部方程出发、一个从整体通量出发，解的物理完全一样。球内则直接积分泊松方程，得到 $E = Qr/(4\pi\varepsilon_0R^3)$ 的线性增长——与第 63 节高斯定理的结论完全吻合。

## 4 微分形式与边值问题

微分形式的麦克斯韦方程组配合**边界条件**（第 120 节），构成电磁场的边值问题——电动力学的核心求解框架：

- 介质分界面两侧场量的关系由边界条件给出（由积分形式在界面取薄盒/窄环推出）；
- 典型边值问题：导体腔、波导、谐振腔——解微分方程 + 边界条件。

**重点：微分形式 + 边界条件 = 电磁场边值问题的标准框架。** 解方程 $\nabla^2\phi = -\rho/\varepsilon_0$（泊松）或波动方程，配合界面条件（$\boldsymbol{D}$、$\boldsymbol{B}$ 法向分量与 $\boldsymbol{E}$、$\boldsymbol{H}$ 切向分量的连续/跳变），得到唯一解（唯一性定理，第 121 节）。

边界条件的数值例子：两种介质分界面，若无自由面电荷与面电流，则 $\boldsymbol{D}$ 的法向分量连续（$D_{1n} = D_{2n}$）、$\boldsymbol{E}$ 的切向分量连续（$E_{1t} = E_{2t}$）。代入 $\boldsymbol{D} = \varepsilon\boldsymbol{E}$，可得场的方向在界面的折射规律：$\tan\theta_1/\tan\theta_2 = \varepsilon_1/\varepsilon_2$——电场线穿过界面会「弯折」，这是光在介质界面折射的静电场版，也为几何光学提供了物理根源。

边值问题的工程舞台——波导与谐振腔：金属波导的边界条件要求切向 $\boldsymbol{E} = 0$，由此解出的电磁场呈离散的模式（TE、TM 模式），每种模式有截止频率。这正是微波工程里「波导只能传播高于截止频率的波」的物理根源。从麦克斯韦微分方程 + 金属边界条件出发，一套方程推出整个微波器件的理论——边值问题的威力尽在于此。

<span class="marginnote">「从积分到微分再到求解」是电动力学的标准路线：先写微分方程组（局域规律），再补边界条件（界面行为），最后解偏微分方程（具体问题）。第 121 节唯一性定理保证「解是唯一的」——边值问题的理论根基。这条路线也呼应第二十二章统计物理中「微分方程 + 边界条件」的求解模式。</span>

## 5 微分形式的意义

**局域性**：方程在每一点成立，描述场与源的局域关系——比积分形式更「精细」；
**偏微分方程组**：是电磁波的波动方程、静电场泊松方程、磁场的矢量方程的统一出发点；
**规范场论的起点**：麦克斯韦方程组的微分形式（协变形式）是狭义相对论与量子电动力学的基础；
**数值计算**：FDTD（时域有限差分）、有限元等电磁场数值方法都从微分形式离散化。

**重点：微分形式是电磁场理论的标准语言——它让麦克斯韦方程组成为一组局域的偏微分方程，是电磁波、辐射、边值问题的共同出发点。** 从第 71 节的「四个积分方程」到本节的「四个微分方程」，电磁学的数学语言完成了从「整体」到「局域」的升级。<span class="marginnote">「协变形式」预告：麦克斯韦方程组可以用四维时空语言写成高度对称的形式（$\partial_\mu F^{\mu\nu} = \mu_0J^\nu$）——在狭义相对论（第 17 章）下电磁场是「四维张量」，电场与磁场是同一张量的不同分量（随参考系互相转化）。这是电动力学的最高观点，也是电弱统一（第 112 节）的出发点。</span>

### 矢量算子速查

| 算子 | 定义 | 物理含义 | 对应积分 |
| --- | --- | --- | --- |
| 梯度 $\nabla\phi$ | $\left(\frac{\partial\phi}{\partial x},\frac{\partial\phi}{\partial y},\frac{\partial\phi}{\partial z}\right)$ | 标量场变化最快的方向 | 电势 → 电场 |
| 散度 $\nabla\cdot\boldsymbol{F}$ | $\frac{\partial F_x}{\partial x}+\frac{\partial F_y}{\partial y}+\frac{\partial F_z}{\partial z}$ | 源强度 | 高斯定理 |
| 旋度 $\nabla\times\boldsymbol{F}$ | 行列式展开 | 涡旋强度 | 斯托克斯定理 |
| 拉普拉斯 $\nabla^2\phi$ | $\nabla\cdot\nabla\phi$ | 二阶源（泊松方程） | —— |

数值方法的例子值得一句：FDTD（时域有限差分）把 $\nabla\times\boldsymbol{E} = -\partial\boldsymbol{B}/\partial t$ 与 $\nabla\times\boldsymbol{H} = \partial\boldsymbol{D}/\partial t$ 直接离散成网格上的差分格式，交替更新电场与磁场，模拟电磁波在复杂结构（天线、芯片、人体组织）中的传播——手机天线设计、雷达隐身分析、无线充电效率计算，都是微分形式的麦克斯韦方程在计算机上的「数值解」。理解微分形式，就理解了这些工业软件的数学内核。

② $\nabla\cdot\boldsymbol{B} = 0$ 还有一层深刻含义：磁场是「无源场」，磁力线永不中断、永远闭合。这直接排除了「磁单极子」的存在——目前所有实验都未发现自由磁荷。若某天发现磁单极子，麦克斯韦方程组要加一项、电磁理论将改写——这正是「一个方程否决一类粒子」的威力，也是规范场论里磁单极问题长期活跃的原因。

## 6 小结

- **微分算子**：散度 $\nabla\cdot$（源）、旋度 $\nabla\times$（涡旋）；高斯/斯托克斯定理连接积分与微分。
- **麦克斯韦方程组（微分形式）**：$\nabla\cdot\boldsymbol{D} = \rho_f$、$\nabla\cdot\boldsymbol{B} = 0$、$\nabla\times\boldsymbol{E} = -\partial\boldsymbol{B}/\partial t$、$\nabla\times\boldsymbol{H} = \boldsymbol{j}_f + \partial\boldsymbol{D}/\partial t$。
- 静电场：$\nabla\times\boldsymbol{E} = 0$ ⟹ $\boldsymbol{E} = -\nabla\phi$ ⟹ 泊松方程 $\nabla^2\phi = -\rho/\varepsilon_0$。
- **微分形式 + 边界条件 = 边值问题**（唯一性定理保证解唯一）。
- 微分形式是电磁波、辐射、数值方法、相对论协变形式的出发点。
