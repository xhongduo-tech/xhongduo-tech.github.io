## 为什么从机械能守恒开始

前三节我们分别建立了动能定理、定义了势能、区分了保守力与非保守力。现在到了把它们织成一张网的时候：**把「外力」与「非保守内力」做的功都剥离掉，剩下的保守力内部做功不改变系统的机械能**——这就是机械能守恒定律。它是能量守恒定律在力学领域的第一个具体形态，也是「从极限到大模型」主线里反复出现的思维模式：找到一个在演化中不变的量，用它来约束整个系统。<span class="marginnote">把机械能守恒放在更大图景里看：它是「守恒律」家族的第一员。动量守恒（空间平移对称）、角动量守恒（旋转对称）、机械能守恒（时间平移对称）——诺特定理把这套「对称性 ↔ 守恒量」的联系上升为物理学的普遍原则。机械能守恒背后的「时间平移对称」直觉是：物理定律今天与明天相同，所以能量守恒。</span>

## 1 功能原理

把质点系中所有力做功按性质分类：保守力做的功为 $W_{\text{保守}}$，非保守力做的功为 $W_{\text{非保守}}$。由质点系动能定理，合外力与合内力做的总功等于动能增量：

$$W_{\text{外}} + W_{\text{内}} = \Delta E_k$$

将内力中保守力部分移到左边，利用 $W_{\text{保守}} = -\Delta E_p$，得到**功能原理（work-energy principle for a system）**：

$$W_{\text{外}} + W_{\text{非保守}} = \Delta E_k + \Delta E_p = \Delta E$$

其中 $E = E_k + E_p$ 是系统的**机械能（mechanical energy）**。<span class="marginnote">功能原理与动能定理是同一件事的两个视角：动能定理把保守力做功也算进去（得到动能变化），功能原理把保守力做功吸收进势能（得到机械能变化）。解同一道题，两条路都能走通。</span>

功能原理的物理图像很清晰：**外力与非保守内力做的功，是系统机械能增减的唯二渠道**。重力、弹力这类保守力只是在动能与势能之间搬运能量，总量不变。

**辨析｜易错点：**动能定理里的 $W_{\text{内}}$ 与功能原理里的 $W_{\text{非保守}}$ 容易混淆。动能定理对质点系成立，内力的功（无论保守与否）都会改变总动能；功能原理把保守内力做功「吸收」进势能，剩下的非保守内力做功才改变机械能。写功能原理时，保守内力（如弹簧连接的两物体）的功一律不再单独出现——它已经藏在 $\Delta E_p$ 里了。

势能零点的选取是自由的，但一旦选定，同一问题里就要一致：物体从 $h_1$ 移到 $h_2$，无论零点取地面还是取桌面，$E_p$ 的变化量 $mg(h_2 - h_1)$ 都一样——机械能守恒式的两边各加一个常数，抵消后不变。初学常纠结「零点选哪」，其实只要全程一致，答案不依赖零点。

### 常见能量形式速查

| 能量形式 | 表达式 | 备注 |
| --- | --- | --- |
| 平动动能 | $\frac{1}{2}mv^2$ | 速度的函数 |
| 重力势能 | $mgh$ | 需选零点 |
| 弹性势能 | $\frac{1}{2}kx^2$ | 弹簧形变量 |
| 引力势能 | $-GMm/r$ | 取无穷远为零 |
| 转动动能 | $\frac{1}{2}J\omega^2$ | 见第四章刚体 |

机械能 = 动能 + 各类势能之和。选零点时重力势能取「某高度」、弹性势能取「自然长度」、引力势能取「无穷远」——不同势能的零点约定不同，但机械能守恒要求**统一在同一体系内**。

## 2 机械能守恒定律

若系统不受外力、且没有非保守内力做功（或二者做功之和为零），即 $W_{\text{外}} + W_{\text{非保守}} = 0$，则由功能原理得：

$$E = E_k + E_p = \text{常量}$$

**机械能守恒定律（conservation of mechanical energy）：在只有保守力做功的系统中，动能与势能相互转化，但总机械能保持不变。**

表述为最常见的可操作形式：

$$\frac{1}{2}mv_1^2 + E_{p1} = \frac{1}{2}mv_2^2 + E_{p2}$$

**重点：机械能守恒的条件是「只有保守力做功」或「非保守力不做功」，而不是「没有力」或「没有摩擦」。** 一个物体在光滑曲面上下滑，重力做功但机械能守恒；若曲面粗糙，摩擦力做负功，机械能就减少。判断守恒，就看有没有非保守力做功。

数值检验守恒：$m = 2\ \text{kg}$ 的球从 $h = 5\ \text{m}$ 自由下落，最高点 $E_p = mgh = 98\ \text{J}$、$E_k = 0$；落地瞬间 $E_k = \frac{1}{2}mv^2 = 98\ \text{J}$、$E_p = 0$。全程 $E_k + E_p = 98\ \text{J}$ 恒定，但动能与势能的比例随时间不断变化——守恒的是「总量」，不是「各项」。若中途遇到空气阻力，阻力做负功，落地动能就小于 98 J，机械能不守恒——但总能量（动能 + 势能 + 内能）仍然守恒。机械能不守恒不等于能量不守恒：摩擦消耗的机械能变成了内能，把「系统 + 环境」看成一个整体，就得到更普适的能量守恒定律（热力学第一定律）。机械能守恒只是能量守恒在「纯保守力」限制下的特例。

把能量方法与牛顿第二定律对照：牛顿方法要对每一瞬间的力与加速度建立方程（常需解微分方程），能量方法只需初末两个状态。遇到变力（弹簧、曲面支持力）时，牛顿方法每一步都要知道力的表达式，能量方法完全绕开——这是「从极限到大模型」里反复出现的主题：找到不变量，比穷举每一步更强大。

## 3 机械能守恒的应用：单摆与自由落体

单摆是机械能守恒的教科书案例。摆球从最高点（$\theta = \theta_0$，速度为 0）摆到最低点（$\theta = 0$），取最低点为势能零点：

$$\frac{1}{2}mv^2 = mgl(1 - \cos\theta_0)$$

由此立刻得到最低点速率 $v = \sqrt{2gl(1-\cos\theta_0)}$。整个过程绳子的拉力始终沿绳，与位移垂直，不做功；只有重力做功，机械能守恒。

<span class="marginnote">解题口诀：守恒问题先问「有没有非保守力做功」；若没有，就写下「初态机械能 = 末态机械能」，并选好势能零点。很多题的难点根本不在计算，而在<strong>想清楚哪些力做功、机械能守不守恒</strong>。</span>

再如自由落体：物体从 $h_1$ 落到 $h_2$，由守恒得 $v_2^2 - v_1^2 = 2g(h_1 - h_2)$，与运动学结论一致——但这里没有用到任何运动学公式，纯粹由能量关系推出，展示了能量方法的简洁。

单摆数值：摆长 $l = 1\ \text{m}$，从 $\theta_0 = 60^\circ$ 摆下，最低点速率 $v = \sqrt{2gl(1-\cos 60^\circ)} = \sqrt{2\times9.8\times1\times0.5} \approx 3.13\ \text{m/s}$；若从 $90^\circ$ 摆下，$v = \sqrt{2gl} \approx 4.43\ \text{m/s}$。摆幅越大，最低点越快——但绳子拉力在最低点 $T = mg + mv^2/l$ 也随之增大，摆幅过大可能拉断绳子。单摆还有一个值得体会的点：一个周期内动能与势能各完成两次「交接」，把单摆换成弹簧振子（弹性势能），图像完全同构——重力势能/弹性势能只是「势能仓库」的不同形态，机械能守恒对它们一视同仁。

过山车算例：车从高 $h = 20\ \text{m}$ 的坡顶静止出发，忽略摩擦，到谷底速度 $v = \sqrt{2gh} = \sqrt{2\times9.8\times20} \approx 19.8\ \text{m/s}$（约 71 km/h）。若轨道有摩擦，实际速度会小于此值——能量方法给出的是「上限速度」，实际速度 = 上限 − 摩擦损耗。这个「先用守恒估上限、再扣损耗」的思路在工程估算是标准动作。

## 4 公式解析：光滑斜面与竖直圆环

一道经典题：小球从光滑圆环内侧最高点由静止释放，求在最低点的速度与对轨道的压力。最低点速率由机械能守恒给出：

$$
\frac{1}{2}mv^2 = mg \cdot 2R
$$

- **第一步，判守恒**：圆环光滑，支持力始终沿半径（与速度垂直）不做功，只有重力做功，机械能守恒。
- **第二步，选零点**：取最低点 $B$ 为势能零点，最高点 $A$ 高度为 $2R$，初态 $E_A = mg\cdot 2R$，末态 $E_B = \frac{1}{2}mv^2$。
- **第三步，解速度**：$v = \sqrt{4gR}$。
- **第四步，补受力分析求压力**：在最低点，向心力由支持力与重力的合力提供：$N - mg = m\frac{v^2}{R}$，代入得 $N = mg + m\frac{4gR}{R} = 5mg$——**对轨道的压力是重力的 5 倍**。

这个「5 倍」是圆环问题的经典答案，也示范了能量方法与牛顿第二定律如何配合：**机械能守恒给出速度，动力学方程给出力**。「压力是重力的 5 倍」的物理含义值得展开：最低点处，重力向下、支持力向上，向心力由 $N - mg$ 提供。$v = \sqrt{4gR}$ 意味着向心力需求 $mv^2/R = 4mg$，加上自身重力，$N = 5mg$。这个「加速度需求 + 重力」的叠加结构，在圆周运动的任何最低点都成立。

把圆环问题改成「小球从圆环外某高度滑下，恰能通过最高点」：最高点所需最小速度满足 $mg = mv^2/R$（重力恰作向心力），$v = \sqrt{gR}$；由守恒，从高度 $h$ 出发，$mgh = \frac{1}{2}mv^2 + mg\cdot2R$，代入得 $h = \frac{1}{2}R + 2R = 2.5R$。这个「恰能过最高点」的高度 $2.5R$ 是圆环问题的另一个经典结论——先判临界条件，再能量，再动力学，三步层层递进。

## 5 机械能守恒与动量守恒的适用区分

两条守恒律常常被放到同一道题里，判断用哪条是解题的第一关键：

| 判据 | 机械能守恒 | 动量守恒 |
| --- | --- | --- |
| 守恒量 | 标量（机械能） | 矢量（动量） |
| 条件 | 只有保守力做功 | 合外力为零 |
| 关注 | 速度大小、高度、能量转化 | 速度方向、相互作用、质心 |
| 典型场景 | 自由落体、单摆、光滑轨道 | 碰撞、爆炸、反冲 |

**辨析｜易错点：**两球碰撞时，若碰撞是完全非弹性的，系统**动量守恒但机械能不守恒**（动能部分转化为内能）；若桌面粗糙，物体在水平面上滑行，**机械能不守恒（摩擦力做功）但水平方向可能动量守恒**（若竖直方向受力平衡）。两个守恒律完全独立，必须分别判断。<span class="marginnote">很多人以为「动量守恒的碰撞机械能也守恒」——这是最典型的误区。弹性碰撞才同时满足两者；非弹性碰撞只满足动量守恒。下一节《碰撞》专门展开。</span>

能量方法还有一个被低估的好处：它天然处理「整段过程」而非「某个瞬间」。用牛顿第二定律逐点分析变力运动往往要解微分方程，而机械能守恒只要求初末两个状态——这也是为什么抛体、单摆、过山车这类问题，能量方法几乎总是更简洁。判断力做功、盯住初末状态，两步就出结果。

混合算例把两类守恒律接起来：质量 $m$ 的小球从 $h$ 处沿粗糙斜面滑下，斜面长 $l$、倾角 $\alpha$、摩擦系数 $\mu$，到水平面后与静止小球完全非弹性碰撞。第一步，斜面段：摩擦力做功 $W_f = -\mu mg\cos\alpha\cdot l$，机械能不守恒，用功能原理 $\frac{1}{2}mv_1^2 = mgh - \mu mg l\cos\alpha$ 求到水平面的速度；第二步，碰撞：动量守恒求共同速度，动能损失 $= \frac{1}{2}mv_1^2 - \frac{1}{2}(2m)v_{\text{共}}^2$。一段「守恒 → 不守恒 → 守恒」的接力，正考验两类守恒律的判据。

## 6 小结

- **功能原理**：$W_{\text{外}} + W_{\text{非保守}} = \Delta E$，外力与非保守内力的功是机械能增减的唯二渠道。
- **机械能守恒**：只有保守力做功时，$E_k + E_p = \text{常量}$；判断条件是「有没有非保守力做功」。
- 解题套路：判守恒 → 选势能零点 → 列「初态 = 末态」→ 必要时配合牛顿第二定律求力。
- 能量方法只关心初末状态，天然绕过复杂的力与加速度分析，是力学中最强大的工具之一。
- 机械能守恒是「能量守恒」在力学中的体现；其背后是时间平移对称性，与动量守恒背后的空间平移对称性遥相呼应。

在下一节，我们将应用动量守恒与动能分析，系统研究**碰撞**问题——从完全弹性碰撞到完全非弹性碰撞，看看能量在碰撞中如何被「分配」与「损耗」。
