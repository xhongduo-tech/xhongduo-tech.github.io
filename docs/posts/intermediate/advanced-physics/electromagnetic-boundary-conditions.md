## 为什么从边值关系开始

电磁场穿过两种介质的界面时，微分形式的麦克斯韦方程组在界面处「失效」（场量可能不连续）。解决之道是**边值关系（boundary conditions）**：从积分形式出发，在界面处取「薄盒」与「窄环」，推出场量法向与切向分量的连接条件。边值关系是解边值问题（反射折射、波导、导体腔）的前提——没有它，微分方程在界面处无法衔接。这一节推导并记住四组边值关系。

## 1 法向分量的边值关系

取跨界面的薄盒（高 $\delta \to 0$），用高斯定理 $\oint\boldsymbol{D}\cdot\mathrm{d}\boldsymbol{S} = \sum q_{\text{自由}}$：

$$\boldsymbol{n}\cdot(\boldsymbol{D}_2 - \boldsymbol{D}_1) = \sigma_f$$

**电位移矢量的法向分量跳变等于自由电荷面密度。** 对磁场高斯定理 $\oint\boldsymbol{B}\cdot\mathrm{d}\boldsymbol{S} = 0$：

$$\boldsymbol{n}\cdot(\boldsymbol{B}_2 - \boldsymbol{B}_1) = 0$$

**磁感应强度的法向分量连续。**

**重点：$\boldsymbol{D}$ 法向分量跳变（跳变量 = 自由面电荷 $\sigma_f$）、$\boldsymbol{B}$ 法向分量连续。** 界面上没有自由电荷时，$\boldsymbol{D}$ 法向连续；$\boldsymbol{B}$ 法向永远连续（无磁荷）。

## 2 切向分量的边值关系

取跨界面的窄环（宽 $\delta \to 0$），用安培环路定理 $\oint\boldsymbol{H}\cdot\mathrm{d}\boldsymbol{l} = \sum I_{\text{传导}}$：

$$\boldsymbol{n}\times(\boldsymbol{H}_2 - \boldsymbol{H}_1) = \boldsymbol{K}_f$$

**磁场强度的切向分量跳变等于传导电流面密度。** 对法拉第定律 $\oint\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{l} = -\mathrm{d}\Phi/\mathrm{d}t$（无面磁荷时）：

$$\boldsymbol{n}\times(\boldsymbol{E}_2 - \boldsymbol{E}_1) = 0$$

**电场强度的切向分量连续。**

**重点：$\boldsymbol{H}$ 切向跳变（跳变量 = 面电流 $\boldsymbol{K}_f$）、$\boldsymbol{E}$ 切向连续。** 无传导面电流时 $\boldsymbol{H}$ 切向连续；$\boldsymbol{E}$ 切向永远连续（静电场无旋 + 感应电场也满足）。

**四组边值关系总表**：

| 场量 | 分量 | 关系 | 条件 |
| --- | --- | --- | --- |
| $\boldsymbol{D}$ | 法向 | $D_{2n} - D_{1n} = \sigma_f$ | 跳变量 = 自由面电荷 |
| $\boldsymbol{B}$ | 法向 | $B_{2n} - B_{1n} = 0$ | 连续（无磁荷） |
| $\boldsymbol{H}$ | 切向 | $\boldsymbol{n}\times(\boldsymbol{H}_2 - \boldsymbol{H}_1) = \boldsymbol{K}_f$ | 跳变量 = 传导面电流 |
| $\boldsymbol{E}$ | 切向 | $\boldsymbol{n}\times(\boldsymbol{E}_2 - \boldsymbol{E}_1) = 0$ | 连续 |

**辨析｜易错点：为什么 $\boldsymbol{B}$ 法向永远连续、而 $\boldsymbol{D}$ 法向可跳变？** 根源在「有无对应电荷」：磁场无磁单极（$\nabla\cdot\boldsymbol{B} = 0$），界面处无「面磁荷」，$\boldsymbol{B}$ 法向必连续；电场有自由电荷，界面上的自由电荷面密度正是 $\boldsymbol{D}$ 法向跳变的量。**「源是什么，跳变量就是什么」——这是记住边界条件的钥匙。**

## 3 公式解析：导体表面的边界条件

理想导体表面（电场为零）与真空的边界条件。

$$
E_t = 0, \qquad D_n = \sigma_f, \qquad B_n = 0, \qquad H_t = K_f
$$

- **第一步，导体内场为零**：理想导体内部 $\boldsymbol{E} = 0$、$\boldsymbol{B} = 0$（静电平衡/良导体近似）。
- **第二步，电场切向连续**：$E_t(\text{真空}) = E_t(\text{导体}) = 0$——导体表面电场垂直于表面。
- **第三步，电位移法向跳变**：$D_n = \sigma_f$——表面电荷密度等于电位移法向分量。
- **第四步，磁场**：$B_n = 0$（法向连续），$H_t = K_f$（切向跳变 = 面电流）——导体表面磁场平行表面。这些条件是波导、谐振腔、天线分析的基础。

**辨析｜易错点：**四组边界条件的「连续/跳变」对照容易记混：**$\boldsymbol{E}$ 切向连续、$\boldsymbol{D}$ 法向跳变（自由电荷）、$\boldsymbol{H}$ 切向跳变（面电流）、$\boldsymbol{B}$ 法向连续**。记忆法：切向看 $\boldsymbol{E}$（连续）、$\boldsymbol{H}$（跳变）；法向看 $\boldsymbol{D}$（跳变）、$\boldsymbol{B}$（连续）。无自由面电荷/面电流时，四者都连续。

## 4 边值关系与反射折射

平面电磁波在介质界面上的反射与折射，由边值关系（$\boldsymbol{E}$、$\boldsymbol{H}$ 切向连续）决定：

- **反射定律**：入射角 = 反射角；
- **折射定律（斯涅耳）**：$n_1\sin\theta_i = n_2\sin\theta_t$；
- **菲涅耳公式**：由边值关系推出反射/透射系数（振幅比）——偏振依赖（s 与 p 偏振不同）；
- **布儒斯特角**：反射光完全偏振的角度（第 87 节）——由菲涅耳公式推出。

**重点：反射、折射定律与菲涅耳公式全部由边值关系推出——界面是电磁波「分道扬镳」的场所。** 边值关系不仅是静态场的问题，更是波动光学（第十六章）与电磁波传播（第 124 节）的基础。<span class="marginnote">「边值关系连接电磁学与光学」：几何光学的反射/折射定律、波动光学的菲涅耳系数、布儒斯特角，本质都是「$\boldsymbol{E}$、$\boldsymbol{H}$ 切向分量连续」的推论。光学从「经验定律」变成「麦克斯韦方程组的推论」——这是电动力学统一光学的高光时刻，与第 69 节「光是电磁波」呼应。</span>

**数值算例（垂直入射的透射率）**：平面电磁波从空气垂直入射到折射率 $n = 1.5$ 的玻璃。由边值关系推出的菲涅耳公式给出振幅透射系数 $t = 2n_1/(n_1 + n_2) = 2/(1+1.5) = 0.8$，强度透射率 $T = 4n_1n_2/(n_1+n_2)^2 = 4\times1\times1.5/2.5^2 = 0.96$——**96% 的能量透入玻璃，只有约 4% 反射**。这就是玻璃窗「透明」的定量解释：垂直入射时反射很少，折射率越接近反射越少。给镜片涂增透膜，正是让薄膜两面的反射光干涉相消、进一步提高透射率（下一节薄膜干涉的工程应用）。

## 5 边值关系的物理意义

**衔接微分方程**：边值问题（微分方程 + 界面条件）在界面处有唯一解（配合唯一性定理）；
**静电场问题**：导体表面的边值关系（$E_t = 0$、$D_n = \sigma$）是镜像法（下节）的基础；
**波导与谐振腔**：金属壁的边界条件决定电磁场的模式（本征解）；
**天线与辐射**：辐射场在源表面的行为由边值关系衔接。

**重点：边值关系是「微分方程在界面处的补充规则」——它让麦克斯韦方程组能跨介质求解，是边值问题、反射折射、波导模式的共同基础。** 没有边值关系，场在界面处「接不上」；有了它，整个电磁场（不同介质中的解）在界面处光滑衔接。

**边值关系与介质描述**：边值关系中出现的 $\boldsymbol{D}$、$\boldsymbol{H}$ 是「介质中场量」，$\boldsymbol{E}$、$\boldsymbol{B}$ 是「基本场量」——两组场量的边界行为不同，正是介质描述（电位移、磁场强度）在界面处的体现。求解介质界面的电磁问题时，四组关系一起用：法向用 $\boldsymbol{D}$、$\boldsymbol{B}$，切向用 $\boldsymbol{E}$、$\boldsymbol{H}$——「法向看 D、B，切向看 E、H」是完整流程。

<span class="marginnote">「边值关系 → 本征模式」：波导、谐振腔中，金属壁的边界条件（$E_t = 0$）使电磁场只能取特定的模式（类似量子力学的束缚态）——电磁波被「关」在腔里也量子化。这与第 103 节「边界条件 → 量子化」是同一个数学结构，展示了「边界决定模式」的普适规律。</span>

## 6 边值关系的推导方法：薄盒与窄环

**辨析｜易错点：边值关系怎么来的？** 核心方法是「在界面处取极限」：

- **法向（薄盒法）**：取高 $\delta \to 0$ 的扁盒跨界面，用高斯定理——盒的侧面积趋零、只有两个底面贡献，得 $\boldsymbol{D}$、$\boldsymbol{B}$ 法向关系；
- **切向（窄环法）**：取宽 $\delta \to 0$ 的窄环跨界面，用环路定理——环的短边趋零、只有长边贡献，得 $\boldsymbol{E}$、$\boldsymbol{H}$ 切向关系。

**重点：边值关系是「积分形式麦克斯韦方程在界面上的极限」——薄盒管法向、窄环管切向。** 掌握这个方法，遇到新的界面（超导边界、磁介质边界、导电介质界面）就能自行推导，不必死记每个公式。<span class="marginnote">「从边界条件到本征问题」：波导、谐振腔、光纤中的模式（TE、TM、TEM）都由「金属壁或介质界面的边值关系 + 亥姆霍兹方程」共同决定——边界条件选择允许的模式，正如薛定谔方程 + 边界条件给出量子能级。「边界决定模式」是波动系统（电磁、声学、量子）的统一规律。</span>

## 7 小结

- **法向分量**：$\boldsymbol{D}$ 法向跳变（$= \sigma_f$）、$\boldsymbol{B}$ 法向连续。
- **切向分量**：$\boldsymbol{H}$ 切向跳变（$= \boldsymbol{K}_f$）、$\boldsymbol{E}$ 切向连续。
- 记忆：切向 $\boldsymbol{E}$ 连续、$\boldsymbol{H}$ 跳变；法向 $\boldsymbol{D}$ 跳变、$\boldsymbol{B}$ 连续；「源是什么、跳变量就是什么」。
- 理想导体表面：$E_t = 0$、$D_n = \sigma$、$B_n = 0$、$H_t = K_f$。
- **推导方法**：薄盒管法向、窄环管切向——积分形式方程的界面极限。
- 边值关系推出反射/折射定律、菲涅耳公式、布儒斯特角——光学统一进电动力学。
- **垂直入射透射率**：$T = 4n_1n_2/(n_1+n_2)^2$（玻璃约 96%）——增透膜的物理依据。
