## 为什么从受迫振动开始

阻尼振动回答了「振动为什么停下」，但现实里许多振动是**被持续驱动**的：音箱纸盆被电信号驱动、桥梁被风驱动、原子被光驱动、你的耳膜被声波驱动。**受迫振动（forced oscillation）**研究振子在阻尼之外还受周期驱动力的行为。它最引人注目的现象是**共振（resonance）**：当驱动频率接近固有频率时，振幅被放大到远超平时。共振既是破坏性的（塔科马大桥崩塌、军队过桥的步调控制），也是建设性的（收音机选台、微波炉加热、MRI 成像）——理解它的物理，就理解了能量如何在「对的时间」注入系统。

## 1 受迫振动的运动方程

在阻尼振子基础上加周期性驱动力 $F_0\cos\omega t$：

$$m\frac{\mathrm{d}^2x}{\mathrm{d}t^2} = -kx - \gamma\frac{\mathrm{d}x}{\mathrm{d}t} + F_0\cos\omega t$$

即 $\ddot{x} + 2\beta\dot{x} + \omega_0^2x = f_0\cos\omega t$，其中 $f_0 = F_0/m$。<span class="marginnote">这里 $\omega$ 是驱动频率（由外部决定），$\omega_0$ 是固有频率（由系统决定）——两个频率同时在场，这是受迫振动一切丰富现象的来源。</span>

方程的通解有两部分：**暂态解**（衰减的阻尼振动，随时间消失）与**稳态解**（以驱动频率振动的定常振动）。经过足够长时间，暂态消失，系统以驱动频率 $\omega$ 稳定振动：

$$x = A\cos(\omega t + \phi)$$

**重点：稳态受迫振动的频率等于驱动频率，而不是固有频率。** 系统被驱动「同频共振」，幅度与相位则由系统参数（$\omega_0, \beta$）与驱动频率共同决定。这与自由振动「按固有频率振动」形成鲜明对照——受迫振动「身不由己」地跟着驱动走。

## 2 稳态振幅与相位

稳态振幅为：

$$A = \frac{f_0}{\sqrt{(\omega_0^2 - \omega^2)^2 + 4\beta^2\omega^2}}$$

相位 $\phi$（位移落后于驱动力的相位）满足：

$$\tan\phi = \frac{2\beta\omega}{\omega_0^2 - \omega^2}$$

三个极端情形：

- **低频驱动**（$\omega \to 0$）：$A \to f_0/\omega_0^2 = F_0/k$——相当于静力拉伸弹簧的位移。
- **高频驱动**（$\omega \to \infty$）：$A \to 0$——驱动太快，系统来不及响应。
- **驱动频率等于固有频率附近**（$\omega \approx \omega_0$）：振幅达到峰值——**共振**。<span class="marginnote">当 $\omega = \omega_0$ 时，$A = f_0/(2\beta\omega_0)$，振幅与阻尼系数成反比。阻尼越小，共振峰值越高、峰越尖锐；无阻尼时振幅趋于无穷——理想化的数学发散，现实中总有限制（线性近似失效、能量耗散不可忽略）。</span>

## 3 共振：能量注入的物理

**共振（resonance）**：驱动频率等于固有频率时，受迫振动振幅达到极大的现象。

共振的物理本质是**能量注入的相位匹配**：当驱动频率等于固有频率，驱动力始终与速度同相，**每个周期驱动力都做正功**，能量不断注入，直到与阻尼耗散平衡，振幅稳定在峰值。

**辨析｜易错点：**共振时振幅最大，但「振幅无穷大」只在无阻尼时成立。实际系统都有阻尼，共振振幅有限。另一个误区：共振发生在 $\omega = \omega_0$，**不是** $\omega \approx \omega_0(1-\dots)$ 之类——严格说振幅峰值在 $\omega = \sqrt{\omega_0^2-2\beta^2}$，但当阻尼小时非常接近 $\omega_0$，课程中按 $\omega = \omega_0$ 处理即可。

### 共振的破坏与利用

**破坏**：1940 年美国塔科马海峡大桥在风中扭振坍塌——风产生的周期性涡旋脱落频率恰好接近桥梁固有频率，共振放大导致结构破坏。<span class="marginnote">塔科马大桥是工程史上的著名案例：一座新桥在中等风速下发生大幅扭摆，最终垮塌。此后桥梁设计都要避开风致共振频率，士兵过桥也要「便步走」以免步频引发共振。共振是工程师的「必修敬畏」。</span>
- **利用**：收音机通过调节可变电容改变固有频率，与目标电台的载波频率「对上」，共振选出该台；微波炉用 2.45 GHz 的微波共振加热水分子；核磁共振（MRI）用射频场共振激励原子核自旋；吉他琴体放大琴弦的共振频率。

## 4 公式解析：共振振幅

一个受迫振子，$m = 0.2\ \text{kg}$，$k = 80\ \text{N/m}$，阻尼系数 $\gamma = 0.4\ \text{kg/s}$，驱动力幅值 $F_0 = 2.0\ \text{N}$。求固有频率与共振时振幅。

$$
\omega_0 = \sqrt{\frac{k}{m}} = \sqrt{\frac{80}{0.2}} = 20\ \text{rad/s}, \qquad A_{\text{res}} = \frac{F_0}{\gamma\omega_0} = \frac{2.0}{0.4\times20} = 0.25\ \text{m}
$$

- **第一步，求固有角频率**：$\omega_0 = \sqrt{k/m} = 20$ rad/s（约 3.2 Hz）。
- **第二步，求阻尼系数 $\beta$**：$\beta = \gamma/(2m) = 0.4/(0.4) = 1\ \text{s}^{-1}$，远小于 $\omega_0$，欠阻尼，共振峰尖锐。
- **第三步，算共振振幅**：共振时 $A = f_0/(2\beta\omega_0) = \frac{F_0/m}{2\beta\omega_0} = \frac{F_0}{\gamma\omega_0} = \frac{2.0}{0.4\times20} = 0.25\ \text{m}$。
- **第四步，对比静力位移**：若驱动力作为静力，位移只有 $F_0/k = 2/80 = 0.025$ m——**共振把位移放大了 10 倍**，能量放大了 100 倍。这就是共振的「能量聚焦」威力。

## 5 共振曲线与品质因数

以 $\omega/\omega_0$ 为横轴、$A$ 为纵轴画共振曲线：峰值出现在 $\omega/\omega_0 = 1$ 附近，阻尼越小峰越高越窄。曲线的尖锐程度用**品质因数（Q 值）**描述：

$$Q = \frac{\omega_0}{2\beta}$$

Q 值大的系统共振峰尖锐（选频性好，如石英晶体、微波腔），Q 值小的系统峰宽而矮（响应平坦，如减震器）。<span class="marginnote">Q 值还有能量解释：$Q = 2\pi\times$（系统存储能量 / 每周期耗散能量）。高 Q 意味着能量存储远大于损耗——钟摆、音叉、激光腔都是高 Q 系统，靠微小的能量输入维持长时间振动。</span>

## 6 小结

- **受迫振动**：$\ddot{x} + 2\beta\dot{x} + \omega_0^2x = f_0\cos\omega t$；稳态频率 = 驱动频率。
- 稳态振幅 $A = \dfrac{f_0}{\sqrt{(\omega_0^2-\omega^2)^2 + 4\beta^2\omega^2}}$，相位 $\tan\phi = \dfrac{2\beta\omega}{\omega_0^2-\omega^2}$。
- **共振**：$\omega = \omega_0$ 时振幅最大，$A_{\text{res}} = \dfrac{F_0}{\gamma\omega_0}$，与阻尼成反比。
- 共振 = 驱动力与速度同相、每周期做正功的能量注入。
- Q 值 $Q = \omega_0/(2\beta)$ 刻画共振峰尖锐程度；破坏（塔科马桥）与利用（收音机、微波炉）并存。
