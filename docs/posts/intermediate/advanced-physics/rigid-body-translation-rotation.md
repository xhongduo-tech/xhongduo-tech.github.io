# 刚体的平动与定轴转动

<div class="epigraph">
<p>运动的研究被分成两个部分：一个物体整体位置的改变，和一个物体各部分相对位置的改变。前者叫平动，后者叫转动。</p>

## 为什么从刚体开始

前五节我们研究的对象都可以理想化为「质点」——只有质量、没有大小。但现实世界里，车轮、飞轮、地球、陀螺这些物体，形状和大小恰恰是问题的核心。**刚体（rigid body）**是质点之后最重要的力学模型：它的任意两点之间的距离保持不变的物体。刚体不可能是「完全刚性」的，但作为第一近似，它让我们能用很少的几个量（一个质心坐标、一个转动角度）描述极大的物体，也让「转动」这个全新的运动形式登上舞台。这一节先建立刚体运动学的语言。

## 1 刚体模型与两种基本运动

**刚体（rigid body）**：在运动过程中，任意两质点间距离保持不变的物体。刚体是「不变形」的理想化模型，真实物体在外力下的形变在下一章《流体》与材料科学中再讨论。

刚体最一般的运动可以分解为**平动**与**转动**的组合：

- **平动（translation）**：刚体内任意一条直线在运动过程中保持与自身平行。平动时刚体内所有质点的位移、速度、加速度都相同，因此**一个质点的运动就代表整个刚体的运动**，可以用质心（重心）来代表。<span class="marginnote">平动并不要求「沿直线」——列车车厢沿弯道前进、电梯上下、跳水运动员在空中翻身时身体整体平移的瞬间，都是平动。平动的判据是「任意直线保持平行」，而非「轨迹是直线」。</span>
- **转动（rotation）**：刚体上各质点都绕同一直线作圆周运动，这条直线叫**转轴**。若转轴固定不动，称为**定轴转动（rotation about a fixed axis）**——本章的主角。

**重点：刚体的自由度。** 描述一个自由刚体的空间位置需要 6 个独立坐标（质心 3 个 + 转动方位 3 个）；定轴转动则只需 1 个坐标（转角 $\theta$）——因为转轴固定后，刚体只剩「转了多少角度」一个自由度。

**数值算例（转动物体的自由度）**：开瓶的瓶盖（绕自身轴转动）——1 自由度；直升机螺旋桨（绕自身轴 + 随机体平动）——1 转动 + 3 平动自由度；陀螺（定点转动）——3 自由度（用欧拉角描述）。**「自由刚体 6 自由度、定轴转动 1 自由度」是最常考的自由度结论**——做题先判断「转轴是否固定」，再决定用 1 个还是 6 个坐标。

## 2 定轴转动的角量描述

定轴转动用**角量**描述，与质点的线量一一对应：

| 线量（质点） | 角量（刚体） |
| --- | --- |
| 位移 $x$ | 角位移 $\theta$ |
| 速度 $v$ | 角速度 $\omega = \dfrac{\mathrm{d}\theta}{\mathrm{d}t}$ |
| 加速度 $a$ | 角加速度 $\alpha = \dfrac{\mathrm{d}\omega}{\mathrm{d}t}$ |

单位分别为弧度（rad）、弧度每秒（rad/s）、弧度每二次方秒（rad/s²）。引入角量后，定轴转动的运动学方程与质点一维运动完全同构：

$$\theta(t) = \theta_0 + \omega_0 t + \frac{1}{2}\alpha t^2, \qquad \omega = \omega_0 + \alpha t, \qquad \omega^2 - \omega_0^2 = 2\alpha(\theta - \theta_0)$$

这三条公式与匀变速直线运动的公式在结构上一一对应，只是把 $x \to \theta$、$v \to \omega$、$a \to \alpha$。**学会「线量 ↔ 角量」的类比，是学转动最快的捷径。**<span class="marginnote">角速度是矢量，方向沿转轴，由右手螺旋定则确定：右手四指沿转动方向弯曲，拇指所指即 $\boldsymbol{\omega}$ 方向。这个约定在第四章处理角动量、进动时至关重要。</span>

## 3 角量与线量的关系

刚体上距转轴 $r$ 处的质点，其线速度与角速度的关系为：

$$v = \omega r$$

它的切向加速度与法向（向心）加速度分别为：

$$a_t = \alpha r, \qquad a_n = \omega^2 r$$

这三个关系式是连接「刚体整体的角量」与「刚体上某点的线量」的桥梁。<span class="marginnote">向心加速度 $a_n = \omega^2 r$ 正比于半径，而切向加速度 $a_t = \alpha r$ 也正比于半径——这意味着离轴越远的点，运动得「越快」、被「甩」得越厉害。搅拌咖啡时远离中心的液面被甩起来，就是这个道理。</span>

**辨析｜易错点：** 定轴转动时，刚体上各质点的**角速度相同，但线速度不同**（$v = \omega r$ 随 $r$ 变化）。若误以为「整个刚体速度相同」，就会在皮带传动、齿轮啮合问题中出错：齿轮啮合处线速度相等，角速度与半径成反比 $\omega_1 r_1 = \omega_2 r_2$。

**数值算例（皮带传动）**：两个皮带轮，主动轮半径 $r_1 = 0.2$ m、转速 $n_1 = 600$ r/min（角速度 $\omega_1 = 2\pi n_1/60 = 20\pi \approx 62.8$ rad/s）。皮带不打滑时两轮边缘线速度相等：$\omega_1r_1 = \omega_2r_2$。若从动轮 $r_2 = 0.4$ m，则 $\omega_2 = \omega_1r_1/r_2 = 62.8\times0.2/0.4 = 31.4$ rad/s（$n_2 = 300$ r/min）——**半径大一倍、转速减半**。自行车变速正是靠改变链轮半径组合来改变后轮角速度。

## 4 公式解析：从角加速度到运动规律

一台飞轮从静止开始以 $\alpha = 2.0\ \text{rad/s}^2$ 匀加速转动，求 5 秒末的角速度、角位移与边缘一点的线速度（半径 $R = 0.5$ m）。

$$
\omega = \alpha t = 2.0 \times 5 = 10\ \text{rad/s}
$$

- **第一步，选公式**：角加速度恒定，套用匀角加速运动公式 $\omega = \omega_0 + \alpha t$，初角速度 $\omega_0 = 0$。
- **第二步，算角位移**：$\theta = \frac{1}{2}\alpha t^2 = \frac{1}{2}\times 2.0\times 25 = 25$ rad，约合 $\frac{25}{2\pi}\approx 4.0$ 圈。
- **第三步，算边缘线速度**：$v = \omega R = 10\times 0.5 = 5.0\ \text{m/s}$。
- **第四步，理解单位换算**：1 圈 = $2\pi$ rad，rad 是无量纲的「角度数」，故角速度的量纲实际是 $\text{s}^{-1}$；角量与线量的换算里永远带着半径 $r$。

整个例题示范了「三个角量方程 + 两个线角关系」的完整工具箱：**已知角加速度，一步步推出刚体的整体运动与任一点的线运动**。

## 5 刚体运动的叠加

一般平面运动中，刚体同时做平动与转动。处理方法是**分解叠加**：取质心 $C$ 为参考点，刚体上任一点 $P$ 的速度为质心平动速度与绕质心转动速度的叠加：

$$\boldsymbol{v}_P = \boldsymbol{v}_C + \boldsymbol{\omega} \times \boldsymbol{r}_{CP}$$

其中 $\boldsymbol{r}_{CP}$ 是 $P$ 相对质心的位矢。<span class="marginnote">「任何刚体运动都可分解为平动 + 转动」是欧拉与沙勒（Chasles）建立的定理。滚动的轮子就是典型：轮心平动、轮缘绕轮心转动，二者的合成使地面接触点瞬时静止——这个「纯滚动」话题将在第四章《刚体的平面平行运动》展开。</span>

**辨析｜易错点：转轴的选择是任意的，但质心是「最方便」的参考点。** 分解定理说「任何刚体运动都能分解成平动 + 转动」；选质心为参考点时，平动部分恰好是「质心的运动」、转动部分与「绕质心转动」对应——这是质心参考系的优势（第五章动量、角动量会再遇到）。选其他点分解也行，只是平动与转动耦合得更复杂。**记不住「质心优先」的原则，叠加公式就不知道该以哪点为参考。**

## 6 角速度的矢量性与角量描述的统一

**辨析｜易错点：为什么角量「够用」？** 定轴转动只需一个转角 $\theta$ 就能描述（转轴固定），所以用标量角量就够。但更一般的转动（转轴方向可变，如陀螺进动、地球自转轴进动）需要**角速度矢量** $\boldsymbol{\omega}$ 与**角加速度矢量** $\boldsymbol{\alpha}$——它们的方向沿转轴、按右手定则，可能随时间改变方向。

**转动与平动的「语言对照表」**：

| 平动 | 转动 |
| --- | --- |
| 位移 $x$ | 角位移 $\theta$ |
| 速度 $v$ | 角速度 $\omega$ |
| 加速度 $a$ | 角加速度 $\alpha$ |
| 质量 $m$ | 转动惯量 $J$（下节） |
| 力 $F$ | 力矩 $M$（下节） |
| 动量 $p = mv$ | 角动量 $L = J\omega$（第四章） |

**重点：转动学与平动学「同构」——学会一条，另一条只是换符号。** 这个对照表在第四章后续（力矩、转动惯量、角动量）反复出现；角动量守恒（花样滑冰收臂加速旋转）正是这套语言最精彩的应用。<span class="marginnote">「转动语言在现代物理」：角速度矢量在刚体力学、陀螺仪（导航）、地球自转（进动与章动）、以及量子力学角动量中一以贯之。本博客的刚体力学与天文类专题会把刚体三维转动（欧拉角、惯性张量）、地球自转的进动讲全；力学主线从这里铺向更深处。</span>

## 7 小结

- **刚体**：任意两点距离不变的理想模型；运动分解为平动 + 转动。
- **平动**：任意直线保持平行，全刚体各点运动相同；**转动**：各点绕轴作圆周运动。
- 定轴转动用角量描述：$\theta, \omega, \alpha$；三条匀角加速公式与匀变速直线运动同构。
- 线角关系：$v = \omega r$，$a_t = \alpha r$，$a_n = \omega^2 r$；同轴上角速度相同、线速度不同。
- **自由度**：自由刚体 6 自由度、定轴转动 1 自由度；先判转轴是否固定再定坐标数。
- **传动应用**：皮带/齿轮啮合处线速度相等，角速度与半径成反比 $\omega_1r_1 = \omega_2r_2$。
- 刚体运动叠加：$\boldsymbol{v}_P = \boldsymbol{v}_C + \boldsymbol{\omega}\times\boldsymbol{r}_{CP}$（以质心为参考最方便）。
- 转动与平动语言同构：$m \leftrightarrow J$、$F \leftrightarrow M$、$p \leftrightarrow L$。
- 角速度是矢量（方向沿转轴、右手定则），一般的转动需用矢量角量描述。
