## 为什么从哈密顿正则方程开始

拉格朗日方程是 $s$ 个二阶微分方程（关于 $q, \dot{q}$）。哈密顿把它改写为 $2s$ 个一阶微分方程（关于 $q, p$），并引入**哈密顿量** $H$——通常就是总能量 $T + V$。这个「相空间」表述更对称（坐标与动量地位平等），是统计力学（相空间、系综）、量子力学（算符、薛定谔方程）与混沌理论（相图）的共同起点。这一节推导哈密顿正则方程，理解哈密顿量的意义。

## 1 广义动量与哈密顿量

**广义动量（generalized momentum）**：拉格朗日量对广义速度的偏导：

$$p_j = \frac{\partial L}{\partial\dot{q}_j}$$

**哈密顿量（Hamiltonian）**：$H(q, p, t) = \sum_j p_j\dot{q}_j - L$，用 $(q, p)$ 表示（消去 $\dot{q}$）。

对常见的「动能 - 势能」系统（$L = T - V$，$T$ 是 $\dot{q}$ 的二次齐次式）：

$$H = T + V$$

**哈密顿量通常等于系统的总能量。** 广义动量：对直角坐标，$p_x = m\dot{x}$（普通动量）；对角度坐标，$p_\theta = \frac{\partial L}{\partial\dot{\theta}}$（角动量）——广义动量是「广义坐标的共轭动量」。

**重点：哈密顿量 $H = T + V$（总能量），用广义坐标与广义动量 $(q, p)$ 表达。** 从拉格朗日量 $L = T - V$ 出发，通过勒让德变换得到哈密顿量——把「速度语言」换成「动量语言」。<span class="marginnote">「勒让德变换」：$H = p\dot{q} - L$，把函数从 $L(q,\dot{q})$ 换成 $H(q,p)$。这是热力学中「从内能换到自由能」的同一个数学工具（第二十二章）。哈密顿量的物理意义——总能量——在 $L = T - V$、$T$ 为速度二次型的标准情形下成立。</span>

## 2 哈密顿正则方程

由哈密顿量 $H(q, p, t)$ 对 $q_j$、$p_j$ 独立变分，得到**哈密顿正则方程（Hamilton's canonical equations）**：

$$\dot{q}_j = \frac{\partial H}{\partial p_j}, \qquad \dot{p}_j = -\frac{\partial H}{\partial q_j}, \qquad j = 1, 2, \dots, s$$

**重点：哈密顿正则方程是 $2s$ 个一阶方程——$\dot{q}$ 由 $H$ 对 $p$ 求导、$\dot{p}$ 由 $H$ 对 $q$ 求导（带负号）。** 结构对称、形式优美：$(q, p)$ 地位平等。与拉格朗日（$s$ 个二阶方程）等价，但一阶形式更适合数值积分、几何（相空间流）与量子化。<span class="marginnote">正则方程的对称性：$q$ 与 $p$ 通过哈密顿量互为「驱动」——$H$ 对 $p$ 的导给出 $\dot{q}$，对 $q$ 的导（负号）给出 $\dot{p}$。这个「辛结构」是经典力学与量子力学共享的数学骨架（泊松括号、对易子，第 118 节）。相空间中系统的运动是哈密顿量定义的一个「流」——能量守恒使流沿等能面流动。</span>

## 3 公式解析：谐振子的正则方程

用哈密顿正则方程求一维谐振子（质量 $m$、劲度系数 $k$）的运动方程。

$$
H = \frac{p^2}{2m} + \frac{1}{2}kx^2
$$

- **第一步，写哈密顿量**：$H = \frac{p^2}{2m} + \frac{1}{2}kx^2$（动能 + 弹性势能，用 $(x, p)$ 表达）。
- **第二步，第一个正则方程**：$\dot{x} = \frac{\partial H}{\partial p} = \frac{p}{m}$——动量与速度的关系。
- **第三步，第二个正则方程**：$\dot{p} = -\frac{\partial H}{\partial x} = -kx$——动量变化率等于力。
- **第四步，合并**：对 $\dot{x} = p/m$ 求导，$\ddot{x} = \dot{p}/m = -kx/m$，即 $m\ddot{x} + kx = 0$——谐振子运动方程。正则方程还原了牛顿方程。

**辨析｜易错点：**正则方程里「$H$ 对 $q$ 求偏导时把 $p$ 当常数、对 $p$ 求偏导时把 $q$ 当常数」——$(q, p)$ 是独立变量。写 $H$ 时必须消去 $\dot{q}$（用 $p$ 表示），否则求导会错。$\dot{p} = -\partial H/\partial q$ 的负号是「广义力 = −势能梯度」的推广。

## 4 哈密顿量的守恒

由哈密顿量对时间的全导数：

$$\frac{\mathrm{d}H}{\mathrm{d}t} = \sum_j\left(\frac{\partial H}{\partial q_j}\dot{q}_j + \frac{\partial H}{\partial p_j}\dot{p}_j\right) + \frac{\partial H}{\partial t} = \frac{\partial H}{\partial t}$$

（用正则方程代入，前两项抵消。）

- 若 $H$ 不显含时间（$\partial H/\partial t = 0$）：$H$ 守恒——**能量守恒**；
- 若 $H$ 不显含某坐标 $q_j$（$\partial H/\partial q_j = 0$）：$p_j$ 守恒——**循环坐标**（对应动量守恒/角动量守恒）。

**重点：哈密顿量的守恒性直接给出能量守恒（$H$ 不显含 $t$）与循环坐标的守恒动量（$\partial H/\partial q_j = 0$ ⟹ $p_j$ 守恒）。** 守恒律在哈密顿框架下变得「透明」：不显含时间的量自动守恒。这是「对称性 → 守恒律」的一个侧面（诺特定理，第 117 节）。<span class="marginnote">「循环坐标」：若 $H$ 不含某坐标 $q_j$，则对应的动量 $p_j$ 是常数——坐标「循环」不影响 $H$，动量守恒。例：中心力场中 $H$ 不含角度 $\phi$，角动量 $p_\phi$ 守恒；自由粒子 $H$ 不含坐标，动量守恒。守恒律从「推导」变成「看出来的」——这是哈密顿表述的优雅之处。</span>

## 5 哈密顿力学的意义

**相空间**：$(q_1,\dots,q_s, p_1,\dots,p_s)$ 构成 $2s$ 维相空间——系统的状态是相空间一个点，运动是相空间一条轨迹；
**统计力学**：相空间体积（刘维尔定理）是统计力学系综理论的基石（第二十二章）；
**量子力学**：正则量子化把 $q$、$p$ 变成算符、泊松括号变成对易子——哈密顿算符 $\hat{H}$ 进入薛定谔方程（第二十三章）；
**混沌理论**：哈密顿系统的相图（能量面）是研究可积性、混沌的框架。

**重点：哈密顿力学是连接经典与量子的桥梁——正则量子化（$p \to -i\hbar\partial/\partial q$）从哈密顿量出发。** 薛定谔方程 $i\hbar\frac{\partial\psi}{\partial t} = \hat{H}\psi$ 中出现的正是哈密顿算符。经典哈密顿量与量子哈密顿量形式相同，只是把 $p$ 换成算符——「经典力学的骨架，量子力学的肉身」。<span class="marginnote">「从哈密顿到量子」：正则量子化的规则是「经典泊松括号 $\{q, p\} = 1$ → 量子对易子 $[\hat{q}, \hat{p}] = i\hbar$」。这个「量子化」程序让经典力学成为量子力学的 $h \to 0$ 极限。第二十三章《量子力学》将正式走这条路——分析力学不是「古典家具」，而是现代物理的活语言。</span>

## 6 数值算例：相空间中的谐振子轨迹

谐振子 $H = \frac{p^2}{2m} + \frac12 m\omega^2x^2$。验证能量守恒并在相空间画出轨迹。

$$

\frac{p^2}{2m} + \frac{1}{2}m\omega^2x^2 = E = \text{常量} \quad\Longrightarrow\quad \frac{x^2}{2E/(m\omega^2)} + \frac{p^2}{2mE} = 1

$$

- **第一步，写哈密顿量**：$H = p^2/2m + \frac12 m\omega^2x^2$（用 $k = m\omega^2$）。
- **第二步，定能量面**：$E$ 固定时，方程 $p^2/(2mE) + x^2/(2E/m\omega^2) = 1$ 是相空间中的椭圆。
- **第三步，读运动**：系统沿椭圆运动，椭圆半轴 $a_x = \sqrt{2E/(m\omega^2)}$、$a_p = \sqrt{2mE}$——能量越大，椭圆越大。
- **第四步，解读**：谐振子在相空间的轨迹是椭圆（能量守恒把轨迹限制在等能面上）。相空间轨迹是封闭曲线——谐振子是周期运动、可积系统。<span class="marginnote">「相空间与混沌」：可积系统（谐振子、二体问题）的相轨迹是规则曲线（椭圆、环面）；混沌系统（三体、双摆）的相轨迹混乱地铺满能量面。相空间图是判断可积 vs 混沌的标准工具。统计力学（第二十二章）讨论的是相轨迹遍历能量面的情形——这个相空间语言贯穿经典力学到统计物理。</span>

## 7 正则变换与守恒量的进一步视角

哈密顿量在正则变换下的行为是哈密顿力学的核心结构：

- **正则变换保持正则方程形式**：$(q,p) \to (Q,P)$ 使新哈密顿量 $K$ 满足同样的正则方程——坐标选择的自由被保留；
- **守恒量的几何意义**：守恒量 $f$ 在相空间中定义了一个「曲面」，系统轨迹永远停留在 $f = \text{常量}$ 的曲面上——守恒律 = 轨迹被限制在低维流形上；
- **能量曲面**：$H = E$ 是 $2s-1$ 维曲面，系统运动被限制其上（可积时是环面）。

**重点：守恒量在相空间中「切出」低维流形——守恒律越多，轨迹被限制得越「瘦」。** 可积系统（$s$ 个独立守恒量）的轨迹被限制在 $s$ 维环面上；混沌系统守恒量少，轨迹填满整个能量面。这个「守恒量 → 相空间流形」的视角，是理解可积性、混沌与统计力学过渡的关键。<span class="marginnote">「从可积到混沌」：$s$ 个自由度的可积系统有 $s$ 个守恒量（轨迹在 $s$ 维环面上）、混沌系统只有能量守恒（轨迹布满 $2s-1$ 维能量面）。哈密顿力学最深刻的现代主题——KAM 定理、混沌、遍历性——都从这个「守恒量切流形」的图像出发。统计力学假设的等概率（第二十二章），本质是轨迹遍历能量面的近似。</span>

**辨析｜易错点：**哈密顿量与拉格朗日量的对应：$p = \partial L/\partial\dot{q}$、$H = p\dot{q} - L$。正则方程的符号（$\dot{p} = -\partial H/\partial q$）容易记错——$q$ 的演化看 $H$ 对 $p$、$p$ 的演化看 $H$ 对 $q$ 带负号。写 $H$ 时先确认已经用 $p$ 消去了 $\dot{q}$。

## 8 术语速查表

| 术语 | 公式 | 要点 |
| --- | --- | --- |
| 广义动量 | $p_j = \partial L/\partial\dot{q}_j$ | 共轭动量 |
| 哈密顿量 | $H = \sum p_j\dot{q}_j - L = T + V$ | 总能量 |
| 正则方程 | $\dot q_j = \partial H/\partial p_j$，$\dot p_j = -\partial H/\partial q_j$ | 2s 个一阶方程 |
| 相空间 | $(q, p)$ 空间 | 状态点 + 轨迹 |
| 能量守恒 | $H$ 不显含 $t$ | $\mathrm{d}H/\mathrm{d}t = 0$ |
| 循环坐标 | $\partial H/\partial q_j = 0$ | $p_j$ 守恒 |

哈密顿正则方程把力学改写为「坐标 + 动量」的对称表述：$2s$ 个一阶方程、哈密顿量即总能量、相空间轨迹描述运动。它让守恒律「看」出来、让相空间成为几何舞台，也直接通向统计力学与量子力学的正则量子化。下一节我们研究力学的极值原理——**哈密顿原理与最小作用量原理**。

## 9 小结

- **广义动量**：$p_j = \frac{\partial L}{\partial\dot{q}_j}$；**哈密顿量**：$H = \sum p_j\dot{q}_j - L = T + V$（通常为总能量）。
- **哈密顿正则方程**：$\dot{q}_j = \frac{\partial H}{\partial p_j}$，$\dot{p}_j = -\frac{\partial H}{\partial q_j}$——$2s$ 个一阶方程。
- $H$ 不显含 $t$ ⟹ 能量守恒；$H$ 不含 $q_j$ ⟹ $p_j$ 守恒（循环坐标）。
- **相空间**：$(q, p)$ 构成 $2s$ 维空间，运动是相轨迹。
- 哈密顿力学是统计力学、量子力学（正则量子化）、混沌理论的基础。
