## 为什么从无限深势阱开始

一维无限深方势阱是量子力学的「入门模型」——粒子被限制在 $0 < x < a$ 的区间内，阱外势能无穷大。它虽然简单，却展示量子力学的全部核心特征：**能级量子化、零点能、波函数的驻波结构、概率分布的节点**。它是理解量子点的物理基础，也是通往谐振子、氢原子的第一个阶梯。这一节完整求解无限深势阱，逐条读出它的量子性质。

## 1 模型的设定

**一维无限深方势阱（infinite square well）**：

$$V(x) = \begin{cases} 0, & 0 < x < a \\ \infty, & x \le 0 \text{ 或 } x \ge a \end{cases}$$

- 阱内（$0 < x < a$）：势能为零，粒子自由运动；
- 阱外（$x \le 0$ 或 $x \ge a$）：势能无穷大，粒子不能存在（$\psi = 0$）。

**重点：无限深势阱的边界条件——波函数在阱壁处必须为零（$\psi(0) = \psi(a) = 0$）。** 因为势能无穷大，粒子不可能进入阱外，波函数在阱壁处连续 → 为零。这个边界条件与「两端固定的弦」完全相同——量子化由此而来。<span class="marginnote">物理实现：量子点（纳米半导体）、原子核内的核子、被困在电磁场中的离子——凡是「粒子被强力限制在微小区域」的系统，都可以近似为势阱。无限深势阱是理想化（真实势阱有限深），但它抓住了量子化的本质。</span>

## 2 求解定态方程

阱内（$V = 0$）定态薛定谔方程：

$$-\frac{\hbar^2}{2m}\frac{\mathrm{d}^2\psi}{\mathrm{d}x^2} = E\psi \quad\Longrightarrow\quad \frac{\mathrm{d}^2\psi}{\mathrm{d}x^2} = -k^2\psi, \quad k = \sqrt{\frac{2mE}{\hbar^2}}$$

通解：$\psi(x) = A\sin(kx) + B\cos(kx)$。由 $\psi(0) = 0$ 得 $B = 0$；由 $\psi(a) = 0$ 得 $\sin(ka) = 0$：

$$k_n a = n\pi \quad\Longrightarrow\quad k_n = \frac{n\pi}{a}, \quad n = 1, 2, 3, \dots$$

**能级**：

$$E_n = \frac{\hbar^2k_n^2}{2m} = \frac{n^2\pi^2\hbar^2}{2ma^2} = \frac{n^2h^2}{8ma^2}$$

**波函数**（归一化后）：

$$\psi_n(x) = \sqrt{\frac{2}{a}}\sin\left(\frac{n\pi x}{a}\right)$$

**重点：无限深势阱的能级 $E_n = \frac{n^2\pi^2\hbar^2}{2ma^2}$——能量量子化为 $n^2$ 的倍数，基态 $n = 1$。** 能级间隔随 $n$ 增大而增大（$E_{n+1} - E_n \propto (2n+1)$），这与氢原子的 $1/n^2$（间隔递减）不同——势阱的能级「越往高越稀疏」反了，势阱是「越往高越密」？不——$E_n \propto n^2$，间隔 $\propto 2n+1$ 递增，越往高越疏。而氢原子 $E_n \propto -1/n^2$，间隔递减（越往高越密）。

**辨析｜易错点：**势阱能级 $E_n \propto n^2$ 与氢原子 $E_n \propto -1/n^2$ 的「疏密趋势」相反：势阱越高能级越疏（间隔 $\propto n$），氢原子越高越密（间隔 $\propto 1/n^3$）。别把两者混为一谈——势阱是「硬束缚」（箱），氢原子是「软束缚」（库仑），势能形状决定能级结构。

## 3 公式解析：基态能量与零点能

阱宽 $a = 0.1\ \text{nm}$（原子尺度），电子在阱中，求基态能量。

$$
E_1 = \frac{\pi^2\hbar^2}{2ma^2} = \frac{\pi^2(1.05\times10^{-34})^2}{2\times9.1\times10^{-31}\times(10^{-10})^2}
$$

- **第一步，写基态能量公式**：$E_1 = \pi^2\hbar^2/(2ma^2)$。
- **第二步，代入**：$E_1 = \frac{9.87\times1.1\times10^{-68}}{2\times9.1\times10^{-31}\times10^{-20}} = \frac{1.09\times10^{-67}}{1.82\times10^{-50}} \approx 6\times10^{-18}\ \text{J} \approx 38\ \text{eV}$。
- **第三步，解读**：基态能量不为零（约 38 eV）——**零点能**：束缚粒子不可能静止（不确定关系），最小能量由阱宽决定。
- **第四步，体会**：阱越窄（$a$ 小）能量越高——压缩粒子需要能量。这就是为什么量子点越小、发光波长越短（能级差大、光子能量高）。

## 4 波函数与概率分布

各能级的波函数与概率密度：

- $\psi_n(x) = \sqrt{2/a}\sin(n\pi x/a)$：正弦驻波，$n$ 越大节点越多（$n-1$ 个节点）；
- 概率密度 $|\psi_n|^2 = \frac{2}{a}\sin^2(n\pi x/a)$；
- $n = 1$（基态）：概率在阱中央最大；
- $n = 2$：中央是节点（概率为零），两侧各一个峰——粒子「讨厌」中央。

**重点：量子概率分布与经典完全不同。** 经典粒子在阱中各处概率均等（来回反射）；量子粒子基态在中央最可能、激发态有节点（某些位置概率为零）。$n \to \infty$ 时 $|\psi_n|^2$ 的振荡平均趋近经典均匀分布——**对应原理**：大量子数下量子力学回归经典。<span class="marginnote">「对应原理」：量子结果在 $n \to \infty$（或 $h \to 0$）时回归经典。势阱的高激发态概率密度振荡极快，平均值趋近经典均匀分布。这个「量子 → 经典」的极限，是量子力学自洽性的保证，也是「从极限到大模型」中「极限」二字的又一次体现——量子物理以经典为极限。</span>

## 5 无限深势阱的物理意义

**能级量子化的原型**：束缚 → 分立能级；驻波条件 $ka = n\pi$ 与弦振动同构；
**零点能**：基态能量不为零，来源于不确定关系——束缚粒子必有最小动能；
**量子点**：纳米尺度半导体「人造原子」，电子被三维势阱限制，能级分立、发光波长可调；
**粒子数/量子阱激光器**：利用量子阱的能级分立性提高效率；
**教学意义**：无限深势阱是第一个「能完全求解」的量子模型，展示了从方程到能级、波函数、概率分布、对应原理的完整链条。

<span class="marginnote">量子点被称为「人造原子」：它的能级分立（像原子），但能级结构可以通过尺寸「调音」——量子点越小，能级差越大，发光波长越短。量子点显示、生物标记、单光子源都基于此。从抽象的一维势阱到现实的纳米技术，量子力学的模型直接变成工程工具。</span>

## 6 小结

- **无限深势阱**：$V = 0$（$0<x<a$），$V = \infty$（阱外）；边界条件 $\psi(0) = \psi(a) = 0$。
- **能级**：$E_n = \frac{n^2\pi^2\hbar^2}{2ma^2} = \frac{n^2h^2}{8ma^2}$；基态 $n = 1$ 能量不为零（零点能）。
- **波函数**：$\psi_n = \sqrt{2/a}\sin(n\pi x/a)$，$n-1$ 个节点。
- 概率分布：量子与经典不同（节点、中央峰）；$n \to \infty$ 回归经典（对应原理）。
- 势阱能级越往高越疏（$E_n \propto n^2$），与氢原子（$1/n^2$）相反。
- 应用：量子点、量子阱激光器、「人造原子」。
