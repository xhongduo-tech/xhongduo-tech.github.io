## 为什么从薄透镜开始

上一节的球面镜靠反射成像，而实际光学仪器的主角是**透镜（lens）**——靠折射成像的透明元件。眼镜校正视力、相机捕捉画面、显微镜看微观、望远镜观星空，全建立在透镜成像之上。**薄透镜**是透镜的理想化：厚度远小于曲率半径与焦距，光在其中只发生一次「等效折射」。这一节推导并掌握薄透镜成像公式——近轴光学最核心、应用最广的工具。

## 1 薄透镜的基本概念

**薄透镜（thin lens）**：由两个球面组成的透明元件，厚度远小于焦距，光通过时近似只在透镜平面处发生一次偏折。

**透镜分类**：

- **凸透镜（会聚透镜，convex / converging）**：中间厚、边缘薄，光经折射后会聚；焦距 $f > 0$；
- **凹透镜（发散透镜，concave / diverging）**：中间薄、边缘厚，光经折射后发散；焦距 $f < 0$。

**基本要素**：光心 O（透镜中心）、主光轴、焦点 F（平行光会聚/发散的虚焦点）、焦距 $f$。

**重点：凸透镜会聚（$f > 0$）、凹透镜发散（$f < 0$）。** 焦距的正负是判断透镜类型与成像性质的第一关键。眼镜的近视镜片是凹透镜（发散，$f < 0$），远视/老花镜片是凸透镜（会聚，$f > 0$）。

## 2 薄透镜成像公式

**薄透镜成像公式**（高斯公式，近轴近似）：

$$\frac{1}{s} + \frac{1}{s'} = \frac{1}{f}$$

符号约定：物距 $s > 0$（实物在透镜前）；实像 $s' > 0$、虚像 $s' < 0$；凸透镜 $f > 0$、凹透镜 $f < 0$。

**横向放大率**：

$$m = -\frac{s'}{s}$$

$m < 0$ 倒立、$m > 0$ 正立；$|m| > 1$ 放大、$|m| < 1$ 缩小。

**透镜的焦度（光焦度）**：$D = 1/f$，单位屈光度（$1\ \text{m}^{-1}$）。眼镜的度数 = $100\times$屈光度（凸透镜为正、凹透镜为负）。<span class="marginnote">「300 度近视眼镜」= $-3.00$ D = 焦距 $f = -1/3$ m 的凹透镜。光焦度是「会聚能力」的度量：焦距越短，会聚能力越强。眼科配镜就是选合适光焦度的透镜来校正屈光不正。</span>

## 3 凸透镜的成像规律

凸透镜（$f > 0$）按物距分为五种情形：

| 物距 | 像的性质 | 应用 |
| --- | --- | --- |
| $s \to \infty$ | 实像，$s' = f$，缩为一点 | 太阳灶、聚光 |
| $s > 2f$ | 倒立缩小实像 | 照相机 |
| $s = 2f$ | 倒立等大实像 | 测焦距 |
| $2f > s > f$ | 倒立放大实像 | 幻灯机、投影仪 |
| $s < f$ | 正立放大虚像 | 放大镜 |

**重点：凸透镜物距从远到近，像从「缩小实像」逐渐过渡到「放大虚像」，分界点在 $s = f$（不成像、平行光出射）与 $s = 2f$（等大）。** 记忆链条：无穷远 → 焦点上成像 → $2f$ 处等大 → $f$ 处发散 → 小于 $f$ 成虚像。<span class="marginnote">「$s = 2f$ 等大实像」是测焦距的经典方法：物体与屏都在 $2f$ 处时，像与物等大，此时物屏距离 $= 4f$，可反推焦距。相机、投影、放大镜的参数设计都以这些区间为基准。</span>

## 4 公式解析：放大镜

用焦距 $f = 10\ \text{cm}$ 的凸透镜当放大镜，物体放在 $s = 6\ \text{cm}$ 处。求像的位置与放大率。

$$
\frac{1}{s'} = \frac{1}{f} - \frac{1}{s} = \frac{1}{10} - \frac{1}{6} = -\frac{1}{15} \quad\Longrightarrow\quad s' = -15\ \text{cm}
$$

- **第一步，写公式**：$\frac{1}{s} + \frac{1}{s'} = \frac{1}{f}$。
- **第二步，解像距**：$\frac{1}{s'} = \frac{1}{10} - \frac{1}{6} = -\frac{1}{15}$，$s' = -15$ cm——负号表示虚像（在透镜同侧）。
- **第三步，求放大率**：$m = -s'/s = -(-15)/6 = 2.5$——正立、放大 2.5 倍。
- **第四步，验证**：$s = 6 < f = 10$，符合「正立放大虚像」区间；虚像在物体同侧、距离 15 cm，眼睛透过透镜看到放大的虚像。

**辨析｜易错点：**虚像的像距为负，放大率 $m = -s'/s$ 仍为正（正立像）。若忘记 $s'$ 的负号，$m$ 会算成负（误判倒立）。**「虚像正立」是恒成立的规律**：实像必倒立、虚像必正立（单个透镜）。用这个规律检查计算结果，能立刻发现符号错误。

## 5 薄透镜的作图法

薄透镜成像的三条特殊光线：

1. **平行主光轴的光线** → 折射后过焦点 $F'$（凸透镜）或反向延长线过焦点（凹透镜）；
2. **过光心 O 的光线** → 方向不变（薄透镜近似，光心处厚度忽略）；
3. **过焦点 F 的光线** → 折射后平行主光轴。

取任意两条求交点即像点。<span class="marginnote">凹透镜作图时，「反向延长线会聚」的焦点与像都要画虚线。作图时注意凸透镜两条焦点在两侧、凹透镜两条「虚焦点」也在两侧——光经过透镜后向焦点方向偏折（凸会聚、凹发散）。</span>

## 6 小结

- **薄透镜**：凸（$f > 0$，会聚）、凹（$f < 0$，发散）。
- **成像公式**：$\frac{1}{s} + \frac{1}{s'} = \frac{1}{f}$；放大率 $m = -s'/s$。
- 符号法则：实像 $s' > 0$、虚像 $s' < 0$；实像倒立、虚像正立。
- 凸透镜五区间成像：远处缩小实像 → $2f$ 等大 → 放大实像 → $f$ 发散 → 放大虚像。
- 焦度 $D = 1/f$（屈光度），眼镜度数 $= 100D$。
- 作图法：三条特殊光线取两条定像点。
