## 为什么从转动惯量开始

上一节我们把「力 → 力矩」，「质量 → 转动惯量」，「加速度 → 角加速度」一一对应起来。其中转动惯量 $J$ 是一个全新的量：它不像质量那样只是一个数，而是**依赖质量如何绕轴分布**。同样 1 kg 的铁块，做成实心球绕中心转和做成哑铃绕中点转，转动惯量天差地别。这一节解决两个问题：第一，如何从物体的几何形状与质量分布算出 $J$；第二，转轴平行移动时 $J$ 如何变——这正是**平行轴定理**的用武之地。<span class="marginnote">转动惯量为什么是「平方」而不是「一次方」？因为转动惯量度量的是「质量 × 速度」的角动量贡献，而角速度相同时，离轴越远的质元线速度越大（$v = \omega r$），其动量贡献按 $r$ 放大，角动量再乘一个 $r$——于是 $r^2$。这个「平方」来自线速度与力臂的双重放大。</span>

## 1 转动惯量的定义与物理意义

**转动惯量（moment of inertia）**：刚体各质元质量与到转轴距离平方乘积的总和，是刚体转动惯性的量度。

$$J = \sum_i m_i r_i^2 \quad \text{（离散质点系）}, \qquad J = \int r^2\,\mathrm{d}m \quad \text{（连续体）}$$

物理意义有三个层次：

- **惯性量度**：$J$ 越大，同样力矩下角加速度越小，越难改变转动状态。
- **几何量**：$J$ 不仅由质量决定，还由**质量相对转轴的分布**决定；同样的物体，转轴位置不同，$J$ 不同。<span class="marginnote">把物体想象成绕轴旋转的「质量云」：离轴远的云朵对 $J$ 的贡献按距离平方放大。所以自行车轮辐条集中在边缘，就是为了用尽可能少的材料获得尽量大的 $J$，让轮子转起来更稳。</span>
- **积分量**：对连续体，计算 $J$ 的关键是写出 $\mathrm{d}m = \rho\,\mathrm{d}V$（$\rho$ 为体密度），再选择适当坐标系积分。

一个数值让「分布决定惯性」落地：同样的 1 kg、半径 0.5 m 的材料，做成圆环 $J = mR^2 = 0.25\ \text{kg·m}^2$，做成实心圆盘 $J = \frac{1}{2}mR^2 = 0.125\ \text{kg·m}^2$——圆环的转动惯量是圆盘的两倍。用同样的力矩推动，圆环的角加速度只有圆盘的一半：质量一样，转起来的「劲头」却差一倍。

**辨析｜易错点：**「同一物体转动惯量是常数」是常见误解。转动惯量依赖**转轴**：同一根杆绕中点、绕端点、绕垂直于杆的轴，$J$ 各不相同。说「某物体的转动惯量」必须同时指明转轴——没有转轴，$J$ 无意义。这与质量「一个物体一个质量」完全不同，是转动独有的「轴依赖」。

## 2 常见刚体的转动惯量

几个必须背下来的基本结果（均绕过质心的对称轴）：

| 刚体 | 转轴 | 转动惯量 |
| --- | --- | --- |
| 细圆环，质量 $m$、半径 $R$ | 过环心垂直于环面 | $mR^2$ |
| 均质圆盘，质量 $m$、半径 $R$ | 过盘心垂直于盘面 | $\frac{1}{2}mR^2$ |
| 实心球，质量 $m$、半径 $R$ | 过球心 | $\frac{2}{5}mR^2$ |
| 细长杆，质量 $m$、长 $l$ | 过中点垂直于杆 | $\frac{1}{12}ml^2$ |
| 细长杆，质量 $m$、长 $l$ | 过端点垂直于杆 | $\frac{1}{3}ml^2$ |

记忆方法：**质量铺得越开（离轴越远），$J$ 越大。** 同样的质量与半径，圆环（全部质量在边缘）的 $J = mR^2$ 最大，实心圆盘次之，实心球最小。而杆绕端点比绕中点大 4 倍——因为端点转动时，整根杆都被「甩」得离轴更远。

一个组合算例：半径 $R = 0.2\ \text{m}$、质量 $m = 2\ \text{kg}$ 的实心圆盘，绕盘心轴 $J = \frac{1}{2}mR^2 = 0.5\times2\times0.04 = 0.04\ \text{kg·m}^2$；若在盘边缘附加 $0.5\ \text{kg}$ 的质点，新 $J = 0.04 + 0.5\times0.2^2 = 0.06\ \text{kg·m}^2$——边缘那一点质量贡献了总惯性的三分之一。工程上「把质量往边缘放」就能显著加大惯性（飞轮、轮辋），就是这个原理：飞轮储存能量靠的正是「质量在边缘、$J$ 大」。

## 3 平行轴定理与垂直轴定理

### 平行轴定理

若刚体对过质心 $C$ 的轴的转动惯量为 $J_C$，则对与它平行、相距 $d$ 的轴的转动惯量为：

$$J = J_C + md^2$$

**重点：平行轴定理说的是「在质心轴的基础上加上 $md^2$」，而非另起炉灶。** 杆绕端点：$J = \frac{1}{12}ml^2 + m\left(\frac{l}{2}\right)^2 = \frac{1}{3}ml^2$，与表格一致。定理的物理意义：把质量「搬离」质心轴一段距离，相当于整体惯性增加了一个「距离平方 × 总质量」的贡献。<span class="marginnote">平行轴定理要求 $J_C$ 必须是「过质心且平行」的轴的转动惯量——轴与轴之间必须平行，且其中之一过质心。$d$ 是两平行轴之间的垂直距离。</span>

平行轴定理的物理解释：把刚体「拆」成质心处的一个质点（质量 $m$）加上绕质心的转动。质心绕新轴做圆周运动，其惯性贡献正是 $md^2$；质心自身的转动贡献是 $J_C$——两者相加即得。这个「质心平动 + 绕质心转动」的分解，也是刚体平面运动总动能 $E_k = \frac{1}{2}mv_C^2 + \frac{1}{2}J_C\omega^2$ 的思路来源，下一章会用到。

平行轴定理的数值检验：均匀细杆质量 $m = 3\ \text{kg}$、长 $l = 2\ \text{m}$，过中点轴 $J_C = \frac{1}{12}ml^2 = \frac{1}{12}\times3\times4 = 1\ \text{kg·m}^2$；过端点轴 $J = J_C + m(l/2)^2 = 1 + 3\times1 = 4\ \text{kg·m}^2 = \frac{1}{3}ml^2$——与表格一致。$md^2$ 这一项贡献了 3 个单位，占总惯性的四分之三：「搬离质心」的效果远大于杆自身的转动惯性。

### 垂直轴定理（薄板）

对薄平板，若 $z$ 轴垂直于板面，$x$、$y$ 轴在板面内且三轴交于一点 $O$，则：

$$J_z = J_x + J_y$$

例如均质圆盘：$J_z = \frac{1}{2}mR^2$，由对称性 $J_x = J_y$，得直径轴的转动惯量 $J_x = J_y = \frac{1}{4}mR^2$。垂直轴定理只适用于薄板，且三轴必须共点。

## 4 公式解析：从定义积分算出圆盘的转动惯量

以均质圆盘为例，展示 $J = \int r^2\,\mathrm{d}m$ 的完整计算过程。设圆盘质量 $m$、半径 $R$、面密度 $\sigma = \frac{m}{\pi R^2}$，求过盘心垂直盘面的转动惯量。

$$
J = \int_0^R r^2\,\sigma\cdot 2\pi r\,\mathrm{d}r = 2\pi\sigma\int_0^R r^3\,\mathrm{d}r = 2\pi\sigma\cdot\frac{R^4}{4} = \frac{1}{2}mR^2
$$

- **第一步，写面元质量**：取半径 $r$、宽 $\mathrm{d}r$ 的圆环，面积 $2\pi r\,\mathrm{d}r$，质量 $\mathrm{d}m = \sigma\cdot 2\pi r\,\mathrm{d}r$。
- **第二步，写该圆环对 $J$ 的贡献**：圆环上各质元到轴距离都是 $r$，贡献 $r^2\,\mathrm{d}m = r^2\sigma\cdot 2\pi r\,\mathrm{d}r$。
- **第三步，积分**：$r$ 从 $0$ 到 $R$，$\int_0^R r^3\,\mathrm{d}r = \frac{R^4}{4}$。
- **第四步，代回密度**：$\sigma = \frac{m}{\pi R^2}$，得 $J = 2\pi\cdot\frac{m}{\pi R^2}\cdot\frac{R^4}{4} = \frac{1}{2}mR^2$。

**辨析｜易错点：**计算转动惯量最常犯的错是「把圆环当圆盘」或「把 $r$ 当常数」。$r$ 是质元到转轴的垂直距离，在积分里必须随位置变化。另一个易错点是**忘记密度的量纲**：二维薄板用面密度，三维刚体用体密度，一维细杆用线密度——用错了密度，结果差一个长度量纲。

再演示一遍细杆的积分：均质细杆质量 $m$、长 $l$、线密度 $\lambda = m/l$，绕过端点垂直于杆的轴。取距端点 $x$ 处长度微元 $\mathrm{d}x$，质量 $\mathrm{d}m = \lambda\,\mathrm{d}x$，到轴距离 $x$，则 $J = \int_0^l x^2\lambda\,\mathrm{d}x = \lambda l^3/3 = \frac{1}{3}ml^2$。若绕中点轴，积分范围改为 $-l/2$ 到 $l/2$，得 $\frac{1}{12}ml^2$——同一根杆，轴挪到端点，$J$ 变 4 倍，与平行轴定理互相印证。

### 积分的四步模板

1. **定密度**：体密度 $\rho$、面密度 $\sigma$ 或线密度 $\lambda$，写 $\mathrm{d}m = \rho\,\mathrm{d}V$；
2. **选微元**：按对称性把 $\mathrm{d}m$ 写成坐标的函数（圆环、薄壳、小段）；
3. **写距离**：把微元到转轴的垂直距离 $r$ 用坐标表示；
4. **积分**：$J = \int r^2\,\mathrm{d}m$，积分限覆盖整个物体。

四步里「第二步选微元」决定成败：圆盘选圆环、球选薄壳、杆选小段——微元选得好，积分就是一个简单多项式。

## 5 转动惯量的计算策略

计算 $J$ 的通用策略，按优先级排列：

1. **查表 + 平行轴定理**：能拆成「已知刚体 + 平移轴」的，绝不从头积分。
2. **组合法**：把刚体拆成几个已知部分（如圆盘挖孔 = 大圆盘 − 小圆盘），各部分 $J$ 相加减。注意挖空时**减去的也是转动的贡献**：$J = J_{\text{大}} - J_{\text{小}}$。
3. **对称性 + 垂直轴定理**：薄板找直径轴，利用 $J_z = J_x + J_y$ 与对称性。
4. **直接积分**：写 $\mathrm{d}m = \rho\,\mathrm{d}V$，按形状选坐标（圆盘用极坐标、球用球坐标）。

<span class="marginnote">「大减空」的组合法在工程中极常用：飞轮上开减重孔后，其转动惯量精确等于实心飞轮减去孔洞的贡献。计算时每一部分都要统一到同一转轴，不能混用不同轴的 $J$。</span>

组合法数值：半径 $R = 0.1\ \text{m}$、质量 $m = 1\ \text{kg}$ 的圆盘，中心挖去半径 $R/2 = 0.05\ \text{m}$ 的孔。实心盘 $J_{\text{大}} = \frac{1}{2}mR^2 = 0.005$；孔的质量 $m_{\text{小}} = m\cdot\frac{(R/2)^2}{R^2} = m/4 = 0.25\ \text{kg}$，其贡献 $J_{\text{小}} = \frac{1}{2}m_{\text{小}}(R/2)^2 = 0.5\times0.25\times0.0025 = 3.125\times10^{-4}$；挖孔后 $J = J_{\text{大}} - J_{\text{小}} \approx 4.69\times10^{-3}\ \text{kg·m}^2$。注意孔心与盘心重合，没有 $md^2$ 项——「减去的必须是绕同一轴的贡献」，每部分先统一到目标轴再相加减，是组合法不出错的保证。

**辨析｜易错点：**组合法中「减」的必须是绕同一轴的贡献。把圆盘挖孔，孔的部分对盘心轴的 $J$ 是 $\frac{1}{2}m_{\text{孔}}r_{\text{孔}}^2$（孔心即盘心），而不是用平行轴定理把它「挪走」——孔心与盘心重合时 $md^2 = 0$。若孔心不在盘心（偏心孔），则要先算孔自身对孔心的 $J$、再用平行轴定理搬到盘心轴，然后相减。先统一到目标轴，再加减。

实战算例收尾：半径 $R = 0.3\ \text{m}$、质量 $m = 4\ \text{kg}$ 的实心球（$J = \frac{2}{5}mR^2$）受 $M = 2\ \text{N·m}$ 的力矩，角加速度 $\alpha = M/J = 2/(0.4\times4\times0.09) = 2/0.144 \approx 13.9\ \text{rad/s}^2$。若换成同样质量的圆环（$J = mR^2 = 0.36$），$\alpha = 2/0.36 \approx 5.6\ \text{rad/s}^2$——质量分布越散，同样的力矩「转得越慢」。这就是「转动惯量是转动惯性」的直观演示。

## 6 小结

- **转动惯量**：$J = \sum m_i r_i^2$（或 $\int r^2\,\mathrm{d}m$），量度转动惯性，依赖质量相对转轴的分布。
- **常见结果**：圆环 $mR^2$、圆盘 $\frac{1}{2}mR^2$、实心球 $\frac{2}{5}mR^2$、杆过中点 $\frac{1}{12}ml^2$、杆过端点 $\frac{1}{3}ml^2$。
- **平行轴定理**：$J = J_C + md^2$；**垂直轴定理**（薄板）：$J_z = J_x + J_y$。
- 计算策略：查表 → 平行轴/组合 → 对称性 → 积分；密度选择与坐标选择是计算的关键。

在下一节，我们将引入转动的「动量」——**角动量**，并看到它在没有外力矩时的守恒定律，如何解释花样滑冰、陀螺与行星的运动。
