## 为什么从电荷开始

从这一章起，我们进入电磁学的世界。静电力与万有引力「长得很像」，都是平方反比力，但电荷有个关键区别：电荷有正负、可以分离与转移。**电荷**是电磁学的第一个概念，**库仑定律**是它的第一条定量规律——它给出了两个静止点电荷之间作用力的大小与方向。库仑定律不只是静电场的起点，它还与万有引力定律一起，构成了人类对「超距作用」的第一次定量理解。这一节把电荷的性质与库仑定律讲透，为后面的电场、高斯定理铺路。

## 1 电荷的基本性质

**电荷（electric charge）**：物质的一种基本属性，带电体之间的相互作用由此产生。

**电荷守恒定律（conservation of charge）**：在一个与外界无电荷交换的系统中，电荷的代数和恒定不变。摩擦起电只是电荷的转移（一个物体得电子带负电，另一个失电子带正电），不会创造或消灭电荷。<span class="marginnote">电荷守恒是物理学最基本的守恒律之一，在微观世界同样成立：任何粒子反应前后的总电荷量不变。这与动量、能量守恒一样是「绝对」的定律。</span>

**电荷的量子性（quantization）**：任何带电体的电荷量都是**元电荷** $e$ 的整数倍：

$$q = ne, \qquad e = 1.602\times10^{-19}\ \text{C}$$

元电荷由密立根油滴实验测定——油滴带电量总是某个最小单位的整数倍。夸克带有 $\pm\frac{1}{3}e$、$\pm\frac{2}{3}e$ 的分数电荷，但自由夸克不存在（色禁闭），所以宏观电荷仍遵守量子化。<span class="marginnote">元电荷 $e$ 也是微观世界的「基本筹码」：原子、电子、质子的电量都以 $e$ 为单位。第二十二章量子统计中粒子的电荷量子化、以及第十八章的电子结构，都依赖这个基本常数。</span>

## 2 库仑定律

**库仑定律（Coulomb's law）**：真空中两个静止**点电荷** $q_1$、$q_2$ 之间的相互作用力，大小与电量乘积成正比、与距离平方成反比：

$$F = k\frac{q_1 q_2}{r^2} = \frac{1}{4\pi\varepsilon_0}\frac{q_1 q_2}{r^2}$$

其中 $k = 9.0\times10^9\ \text{N·m}^2/\text{C}^2$ 是静电力常量，$\varepsilon_0 = 8.85\times10^{-12}\ \text{C}^2/(\text{N·m}^2)$ 是**真空介电常数（真空电容率）**。

方向：同号相斥、异号相吸，沿两电荷连线。<span class="marginnote">$\varepsilon_0$ 出现在分母 $4\pi$ 里，是国际单位制「有理化」的结果：把 $4\pi$ 放进库仑定律，后面高斯定理、电容公式里就没有 $4\pi$ 了。这个「系数处理」虽然一开始让人困惑，却让整个电磁学公式更整洁。</span>

**点电荷（point charge）**：带电体的几何尺寸远小于间距时的理想模型——与质点是同一个理想化思想。

## 3 库仑定律的矢量形式

库仑定律写成矢量形式，$\boldsymbol{F}_{12}$ 表示 $q_1$ 对 $q_2$ 的力：

$$\boldsymbol{F}_{12} = \frac{1}{4\pi\varepsilon_0}\frac{q_1 q_2}{r^2}\hat{\boldsymbol{r}}_{12}$$

$\hat{\boldsymbol{r}}_{12}$ 是从 $q_1$ 指向 $q_2$ 的单位矢量。$q_1 q_2 > 0$（同号）时力沿 $\hat{\boldsymbol{r}}_{12}$（斥力），$q_1 q_2 < 0$（异号）时力反向（引力）。

**力的叠加原理**：多个电荷对一个电荷的总作用力，等于各电荷单独作用力的矢量和。静电力满足叠加原理，这使复杂电荷系统的计算成为可能。<span class="marginnote">叠加原理是电磁学的基本工作方式：点电荷之间的力互不影响，可以逐对相加。计算三个以上电荷的受力，就是「拆成两两、逐个矢量相加」——电磁学一切求和、积分（连续带电体）都建立在它之上。</span>

## 4 公式解析：库仑定律的数值计算

两个点电荷 $q_1 = 2.0\times10^{-6}$ C、$q_2 = -3.0\times10^{-6}$ C，相距 $r = 0.10$ m（真空）。求相互作用力。

$$
F = \frac{1}{4\pi\varepsilon_0}\frac{|q_1 q_2|}{r^2} = 9.0\times10^9\times\frac{2.0\times10^{-6}\times3.0\times10^{-6}}{(0.10)^2}
$$

- **第一步，写公式**：$F = k\frac{|q_1q_2|}{r^2}$，取电量绝对值算力的大小。
- **第二步，代入**：$F = 9.0\times10^9\times\frac{6.0\times10^{-12}}{0.01} = 9.0\times10^9\times6.0\times10^{-10} = 5.4\ \text{N}$。
- **第三步，定方向**：$q_1$ 正、$q_2$ 负，异号相吸，力沿连线指向对方。
- **第四步，量级感受**：两个微库仑量级的电荷相距 10 cm，力就有 5.4 N——静电力的强度在宏观上是巨大的，这也是摩擦起电的梳子能吸起纸屑的原因。

## 5 库仑定律与万有引力定律的对照

两条平方反比定律并排看：

| 比较项 | 万有引力 | 库仑力 |
| --- | --- | --- |
| 公式 | $F = G\frac{m_1m_2}{r^2}$ | $F = k\frac{q_1q_2}{r^2}$ |
| 常量 | $G = 6.67\times10^{-11}$ | $k = 9.0\times10^9$ |
| 电荷/质量 | 质量恒正 | 电荷有正负 |
| 方向 | 恒为引力 | 同号斥、异号吸 |
| 强度 | 极弱 | 强得多（约 $10^{39}$ 倍于引力，对电子） |

**重点：静电力比引力强得多。** 电子与质子间的静电力约为引力的 $10^{39}$ 倍——所以原子结构由电磁力主导，引力只在行星尺度（天体）才显现。这也解释了为什么「称重量」用引力，而「拽走毛衣上的静电」用电磁力。<span class="marginnote">这个强度悬殊决定了一切：原子的电子被电磁力束缚（引力完全忽略不计），分子、晶体、生命结构都由电磁力搭建；引力只在质量巨大（行星、恒星）时成为主角。四条基本相互作用（第十九章）的强度层次在此初见。</span>

## 6 数值算例：三个电荷的合力

$q_1 = +2\times10^{-9}$ C 在原点，$q_2 = +3\times10^{-9}$ C 在 $(0.1, 0)$ m，$q_3 = -4\times10^{-9}$ C 在 $(0, 0.1)$ m。求 $q_1$ 受到的合力。

$$

F_{12} = k\frac{q_1q_2}{r^2} = 9\times10^9\times\frac{6\times10^{-18}}{0.01} = 5.4\times10^{-6}\ \mathrm{N}\ \text{（沿 } -x\text{）}, \qquad F_{13} = 9\times10^9\times\frac{8\times10^{-18}}{0.01} = 7.2\times10^{-6}\ \mathrm{N}\ \text{（沿 } +y\text{）}

$$

- **第一步，算 $q_2$ 对 $q_1$ 的力**：同号相斥，$F_{12} = 5.4\times10^{-6}$ N 沿 $-x$。
- **第二步，算 $q_3$ 对 $q_1$ 的力**：异号相吸，$F_{13} = 7.2\times10^{-6}$ N 沿 $+y$。
- **第三步，矢量合成**：两力垂直，$F = \sqrt{F_{12}^2 + F_{13}^2} = \sqrt{(5.4)^2 + (7.2)^2}\times10^{-6} = 9.0\times10^{-6}$ N。
- **第四步，解读**：叠加原理把「三电荷问题」拆成「两对两电荷」，逐对算力再矢量相加。静电力叠加是电磁学计算的基础——这也是「点电荷 + 叠加」思想在后续电场、连续带电体中的延续。<span class="marginnote">「叠加原理的适用范围」：静电力叠加成立的前提是「电荷分布互不影响」——各点电荷的场独立存在、可逐对相加。这与万有引力叠加、以及后面电场强度叠加完全一致。叠加原理让复杂电荷系统 = 点电荷之和，是电磁学最常用、也最强大的简化工具。</span>

## 7 库仑定律的实验与历史

库仑定律不是「拍脑袋」的公式，它有严格的实验基础：

- **库仑扭秤（1785）**：库仑用扭秤直接测量两带电小球间的力，验证力与距离平方成反比（$F \propto 1/r^2$）、与电量乘积成正比；
- **卡文迪许的引力实验（1798）**：用同一套扭秤思想测量万有引力常量——两条平方反比定律的「同源」不是巧合；
- **现代验证**：精密实验把 $1/r^2$ 的指数确定到 $2 \pm 10^{-16}$——库仑定律在极大与极小距离都严格成立（光子静质量的实验约束也来自它）。

**重点：库仑定律是「平方反比」的实验定律——其精度是现代物理最严格的定律之一，也约束着光子质量。** 若 $1/r^2$ 有偏差，高斯定理、麦克斯韦方程、电磁波的推导都会崩坏——库仑定律是电磁学大厦的第一块砖。<span class="marginnote">「库仑定律与光子质量」：若光子有微小质量，库仑力就不再是严格的平方反比（会带指数衰减因子）。实验测到库仑定律在太阳系尺度仍精确成立，从而把光子质量上限定为约 $10^{-18}$ eV——库仑定律不仅是起始定律，也是现代物理（规范理论）的检验场。</span>

**辨析｜易错点：**库仑定律适用于「真空中两个静止点电荷」——介质中要除以介电常数（$\varepsilon$ 替换 $\varepsilon_0$）、运动电荷要加磁场修正、非点电荷要积分。题目「能否用库仑定律」先确认：点电荷、真空、静止（或低速）。三个条件缺一不可。

## 8 术语速查表

| 术语 | 公式 | 要点 |
| --- | --- | --- |
| 电荷 | $q$ | 基本属性、有正负 |
| 电荷守恒 | $\sum q = \text{常量}$ | 绝对定律 |
| 元电荷 | $e = 1.6\times10^{-19}$ C | 电荷量子化 |
| 库仑定律 | $F = kq_1q_2/r^2$ | 平方反比 |
| 静电力常量 | $k = 9\times10^9$ N·m²/C² | $= 1/(4\pi\varepsilon_0)$ |
| 叠加原理 | $\boldsymbol{F} = \sum\boldsymbol{F}_i$ | 逐对矢量相加 |

电荷与库仑定律是电磁学的起点：电荷守恒与量子化定义「电荷是什么」，库仑定律给出「电荷之间的力」，叠加原理让复杂系统可算。库仑定律的平方反比形式是整个电磁学（高斯定理、麦克斯韦方程）的基石。下一节我们从「电荷之间的力」升级为「场的概念」——**电场与电场强度**。

## 9 小结

- **电荷**：基本属性，有正负；**电荷守恒**、**电荷量子化**（$q = ne$，$e = 1.6\times10^{-19}$ C）。
- **库仑定律**：$F = k\frac{q_1q_2}{r^2} = \frac{1}{4\pi\varepsilon_0}\frac{q_1q_2}{r^2}$，同号斥、异号吸，点电荷适用。
- 静电力满足**叠加原理**，多个电荷逐对矢量相加。
- 库仑定律与万有引力同型，但电磁力强于引力约 $10^{39}$ 倍，主导微观世界。
- 点电荷是质点模型的电磁对应，理想化的第一步。
