# 原子核的放射性衰变

<div class="epigraph">
<p>不稳定的核会自发蜕变，放出粒子与射线——这种「核的不安分」，既是辐射的危害，也是医学与能源的工具。</p>

## 为什么从放射性衰变开始

1896 年贝克勒尔发现铀的放射性，人类第一次触碰原子核的「自发变化」。**放射性衰变（radioactive decay）**是不稳定核自发转变为其他核、放出粒子与射线的过程。三种主要衰变（α、β、γ）各有机制与规律，而衰变遵循的**指数衰变定律**是核物理、考古测年（碳-14）、医学诊断（PET、放疗）的共同数学基础。这一节讲透三种衰变、衰变定律与半衰期的应用。

## 1 三种主要衰变

### α 衰变

核放出 α 粒子（$^4_2\text{He}$ 核，2 质子 + 2 中子）：

$$^{A}_{Z}X \to ^{A-4}_{Z-2}Y + ^{4}_{2}\text{He}$$

- 原子序数减 2、质量数减 4；
- α 粒子重、带正电、穿透力弱（一张纸可挡），电离能力强；
- 机制：α 粒子靠量子隧穿（第 105 节）逃出核力势阱。

### β 衰变

核内中子转化为质子（或反之），放出电子（β⁻）或正电子（β⁺）：

$$^{A}_{Z}X \to ^{A}_{Z+1}Y + e^{-} + \bar{\nu}_e \quad (\beta^-)$$

- 原子序数改变 1、质量数不变；
- β 粒子（电子）穿透力中等（铝板可挡）；
- **中微子（$\nu$）**：β 衰变还放出（反）中微子——带走部分能量（能量连续分布的来源）。

### γ 衰变

核从激发态跃迁到较低能态，放出**γ 光子**（高能电磁波）：

$$^{A}_{Z}X^* \to ^{A}_{Z}X + \gamma$$

- 原子序数、质量数都不变（只是核能级变化）；
- γ 射线穿透力最强（铅板才可挡），电离能力弱；
- 常伴随 α、β 衰变（子核常处于激发态）。

**重点：三种衰变的规律——α 减 4 减 2、β 不变质量数变序数、γ 只放光子。** 衰变遵守电荷守恒、质量数守恒、能量守恒（α、β 的剩余能量被反冲核、中微子、γ 带走）。<span class="marginnote">「穿透力 vs 电离能力」：α 重而慢、电离强、穿透弱（纸）；β 轻而快、电离中、穿透中（铝）；γ 无质量、电离弱、穿透强（铅）。这个「越重越电离、越轻越穿透」的规律是辐射防护设计的基础——防护 α 用纸、β 用铝、γ 用铅。</span>

## 2 衰变定律

放射性衰变是统计规律：单位时间衰变的核数与现存核数成正比：

$$\frac{\mathrm{d}N}{\mathrm{d}t} = -\lambda N$$

解为**指数衰变定律**：

$$N = N_0e^{-\lambda t}$$

其中 $\lambda$ 是**衰变常数**（单位时间衰变概率）。

**半衰期（half-life）** $T_{1/2}$：核数衰变到一半所需时间：

$$T_{1/2} = \frac{\ln 2}{\lambda} = \frac{0.693}{\lambda}$$

**平均寿命**：$\tau = 1/\lambda$，$T_{1/2} = \tau\ln 2$。

**重点：放射性衰变遵循指数定律 $N = N_0e^{-\lambda t}$，半衰期 $T_{1/2} = \ln 2/\lambda$——与初始核数无关、是核素的固有属性。** 每个放射性核素有固定的半衰期（从 $10^{-6}$ s 到 $10^{10}$ 年不等），这是测年与医学成像的依据。<span class="marginnote">「半衰期与核数无关」是衰变定律的要点：无论现在有多少核，再过 $T_{1/2}$ 就剩一半。所以无法预知「某个核何时衰变」（单个核随机），但大量核的集体行为精确服从指数律——这是「统计规律」的典型：个体随机、集体确定（与气体分子速率分布同构）。</span>

## 3 放射性强度的单位

**活度（activity）**：单位时间衰变的核数：

$$A = \lambda N = A_0e^{-\lambda t}$$

- **贝可（Bq）**：$1\ \text{Bq} = 1$ 次衰变/秒；
- **居里（Ci）**：$1\ \text{Ci} = 3.7\times10^{10}$ Bq（镭的活度，历史单位）。

**辨析｜易错点：**「活度」与「核数」都要注意随时间指数衰减：$A = A_0e^{-\lambda t}$。半衰期对应的活度也减半。计算「经过 n 个半衰期后剩多少」：$N = N_0/2^n$（用半衰期）或 $N = N_0e^{-\lambda t}$（用衰变常数）——两条路等价，审题看给的是 $T_{1/2}$ 还是 $\lambda$。

## 4 公式解析：碳-14 测年

碳-14 的半衰期 $T_{1/2} = 5730$ 年。一具古生物遗骸中碳-14 的活度为新鲜样品的 $12.5\%$（即 $1/8$）。估算其年代。

$$
\frac{N}{N_0} = \frac{1}{8} = \left(\frac{1}{2}\right)^3 \quad\Longrightarrow\quad t = 3T_{1/2} = 17190\ \text{年}
$$

- **第一步，用半衰期法**：$N/N_0 = 1/8 = (1/2)^3$——经过 3 个半衰期。
- **第二步，算年代**：$t = 3\times5730 = 17190$ 年 ≈ 1.7 万年。
- **第三步，或衰变常数法**：$\lambda = \ln2/T_{1/2} = 0.693/5730 = 1.21\times10^{-4}$/年，$t = \frac{\ln(N_0/N)}{\lambda} = \frac{\ln 8}{1.21\times10^{-4}} \approx 17190$ 年。
- **第四步，解读**：碳-14 测年原理——生物活着时吸收的碳-14 与大气平衡，死后不再补充、按半衰期衰减；测残留比例反推死亡时间。碳-14 测年上限约 5 万年（更久则残留太少难测）。

## 5 放射性衰变的应用

- **测年**：碳-14（考古）、铀-铅、钾-氩（地质）、宇宙线暴露测年；
- **医学**：放疗（γ、电子束杀癌细胞）、PET 扫描（正电子发射）、放射性示踪（$^{131}$I 甲状腺）；
- **能源与工业**：核电站（裂变，下节）、辐射灭菌、无损检测（γ 探伤）；
- **辐射防护**：屏蔽（α 纸、β 铝、γ 铅）、剂量控制、安全标准。

<span class="marginnote">「辐射剂量」的单位：吸收剂量 Gy（戈瑞，J/kg）、当量剂量 Sv（西弗，考虑生物效应）。天然本底辐射约 2–3 mSv/年，一次 CT 约 10 mSv。辐射防护三原则——时间（缩短照射）、距离（远离源）、屏蔽（隔挡）——都源于「穿透力 vs 电离能力」的物理。衰变的知识从实验室走向医学、能源与安全政策。</span>

## 6 小结

- **α 衰变**：放 $^4_2\text{He}$，$Z$ 减 2、$A$ 减 4；穿透弱、电离强。
- **β 衰变**：中子↔质子，放电子（+中微子），$Z$ 变 1、$A$ 不变。
- **γ 衰变**：核能级跃迁放光子；穿透强、电离弱。
- **衰变定律**：$N = N_0e^{-\lambda t}$；半衰期 $T_{1/2} = \ln2/\lambda$，与核数无关。
- **活度**：$A = \lambda N$，单位 Bq（或 Ci）。
- 应用：碳-14 测年、放疗、PET、示踪、辐射防护。
