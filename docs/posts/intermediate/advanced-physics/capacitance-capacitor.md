## 为什么从电容开始

电容器是电子世界的「能量仓库」：手机里的电容、相机闪光灯、收音机调谐、甚至记忆电路都靠它。它的定义极简——**电容（capacitance）**是电荷量与电压之比 $C = Q/U$——但背后的物理是静电平衡、电场能量与电介质的交汇点。这一节我们理解电容的物理含义、学会计算平行板电容器、掌握电容器的串并联，为下一节《电介质的极化》与后续电路理论打好基础。

## 1 电容的概念

**电容器（capacitor）**：由两个相互绝缘的导体（极板）组成的器件，用于储存电荷与电场能量。

对孤立导体，电量 $Q$ 与电势 $V$ 成正比；对电容器，一个极板带 $+Q$、另一个带 $-Q$，极板间电压 $U$。定义**电容（capacitance）**：

$$C = \frac{Q}{U}$$

单位：法拉（F），$1\ \text{F} = 1\ \text{C/V}$。<span class="marginnote">法拉单位太大，实用电容多为微法（$\mu\text{F}$）、纳法（nF）、皮法（pF）：$1\ \mu\text{F} = 10^{-6}\ \text{F}$，$1\ \text{pF} = 10^{-12}\ \text{F}$。电容的物理意义是「单位电压能储存多少电荷」——容量越大，同一电压下储存的电荷越多。</span>

**重点：电容是电容器的固有属性，只由几何形状、尺寸与介质决定，与是否带电无关。** $C = Q/U$ 是「测量定义」，电容值是「结构属性」。改变 $Q$ 不会改变 $C$，只会按比例改变 $U$。

## 2 平行板电容器的电容

平行板电容器：两板面积 $S$、间距 $d$、板间为真空（或介质 $\varepsilon_r$）。板间是匀强电场 $E = \sigma/\varepsilon_0$，电压 $U = Ed = \sigma d/\varepsilon_0$，由 $Q = \sigma S$ 得：

$$C = \frac{Q}{U} = \frac{\sigma S}{\sigma d/\varepsilon_0} = \frac{\varepsilon_0 S}{d}$$

**重点：平行板电容 $C = \frac{\varepsilon_0 S}{d}$——正比于板面积、反比于板间距。** 板越大、间距越小，电容越大。<span class="marginnote">直觉：板面积大，能容纳更多电荷（同样电压）；间距小，电场更强、同样的 $Q$ 产生更大 $U$ 差，但电压小反而「效率」高。填充电介质后 $C = \varepsilon_r\varepsilon_0S/d$，电容增大 $\varepsilon_r$ 倍——这是下一节介质极化的直接结果。</span>

## 3 电容器的串并联

### 并联

各电容器两端电压相同，总电荷等于各电容电荷之和：

$$C_{\text{并}} = C_1 + C_2 + \cdots$$

并联增大电容，像「把水池并排，总容量相加」。

### 串联

各电容器电荷相同，总电压等于各电压之和（$U = Q/C$）：

$$\frac{1}{C_{\text{串}}} = \frac{1}{C_1} + \frac{1}{C_2} + \cdots$$

串联减小电容（总电容小于最小者），但能承受更高电压——因为电压分配到各个电容上。

**辨析｜易错点：**串并联公式与电阻恰好相反：电阻并联 $1/R = \sum 1/R_i$，电容并联 $C = \sum C_i$；电阻串联 $R = \sum R_i$，电容串联 $1/C = \sum 1/C_i$。**电容串并联公式与电阻是「对偶」的**，别记反。判断口诀：并联是「同极相连、电压相同」→ 容量相加；串联是「首尾相接、电荷相同」→ 容量的倒数相加。

## 4 公式解析：平行板电容的数值计算

一个平行板电容器，极板面积 $S = 100\ \text{cm}^2$，间距 $d = 0.5\ \text{mm}$，真空。求电容；若充电到 $U = 100\ \text{V}$，求极板电荷。

$$
C = \frac{\varepsilon_0S}{d} = \frac{8.85\times10^{-12}\times100\times10^{-4}}{0.5\times10^{-3}}
$$

- **第一步，单位换算**：$S = 100\ \text{cm}^2 = 10^{-2}\ \text{m}^2$，$d = 0.5\ \text{mm} = 5\times10^{-4}\ \text{m}$。
- **第二步，求电容**：$C = \frac{8.85\times10^{-12}\times10^{-2}}{5\times10^{-4}} = 1.77\times10^{-10}\ \text{F} = 177\ \text{pF}$。
- **第三步，求电荷**：$Q = CU = 1.77\times10^{-10}\times100 = 1.77\times10^{-8}\ \text{C}$。
- **第四步，体会量级**：177 pF 的电容器在 100 V 下只存 $1.77\times10^{-8}$ C——静电电荷宏观上很小，这也是静电储能的局限（大能量要靠高电压）。

## 5 电容器的储能

电容器充电后储存电场能量。充电过程中，电荷从 $0$ 到 $Q$ 逐渐积累，每一微小电荷 $\mathrm{d}q$ 需要做的功为 $V\,\mathrm{d}q = (q/C)\,\mathrm{d}q$，积分得：

$$W = \frac{Q^2}{2C} = \frac{1}{2}CU^2 = \frac{1}{2}QU$$

**重点：电容器储能 $W = \frac{1}{2}CU^2$，正比于电压平方。** 这个 $\frac{1}{2}$ 是「从零开始累积」的平均因子。相机闪光灯正是靠电容瞬间释放储存的能量；而 $W \propto U^2$ 意味着高电压下储能急剧增长——这也是高压电容器体积大、要求高的原因。<span class="marginnote">电容储能公式 $\frac{1}{2}CU^2$ 与弹簧势能 $\frac{1}{2}kx^2$、电感储能 $\frac{1}{2}LI^2$ 形式同构——「力学 ↔ 电学」的类比再次出现：$C$ 对应 $1/k$，$U$ 对应 $x$。这是贯穿电磁学与力学的「形式统一」的又一例证。</span>

## 6 小结

- **电容**：$C = Q/U$，单位法拉 F；是电容器的固有属性（几何 + 介质决定）。
- **平行板电容**：$C = \varepsilon_0S/d$（真空），填介质 $C = \varepsilon_r\varepsilon_0S/d$。
- **串并联**：并联 $C = \sum C_i$（增大），串联 $1/C = \sum 1/C_i$（耐压、减小）——与电阻公式对偶。
- **储能**：$W = \frac{1}{2}CU^2 = \frac{Q^2}{2C}$，正比于电压平方。
- 电容是「电的能量仓库」，在电路、滤波、储能、调谐中无处不在。
