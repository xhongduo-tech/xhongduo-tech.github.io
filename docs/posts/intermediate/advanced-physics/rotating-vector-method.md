## 为什么从旋转矢量法开始

上一节我们用解析式 $x = A\cos(\omega t+\varphi)$ 描述简谐振动，一切都准确，但「相位」「初相」「相位差」这些概念在代数式里显得抽象。这一节引入一个漂亮的几何工具——**旋转矢量法（rotating vector / phasor）**：把简谐振动想象成一个**匀速旋转的矢量的投影**。这一看，振幅、角频率、相位全部有了直观的几何含义；更重要的是，后面两个简谐振动的**合成**问题，用旋转矢量只需做矢量加法，比三角恒等变换直观得多。这个思想在光学干涉、交流电路、信号处理里被反复使用——今天埋下这颗种子。

## 1 旋转矢量与简谐振动的对应

在 $x$ 轴上取投影：一矢量 $\boldsymbol{A}$ 以角速度 $\omega$ 逆时针匀速旋转，初始时刻与 $x$ 轴夹角为 $\varphi$，则它在 $x$ 轴上的投影为：

$$x = A\cos(\omega t + \varphi)$$

**这就是简谐振动。** 旋转矢量法把代数式翻译成几何：

- **矢量长度** $A$ = 振幅；
- **旋转角速度** $\omega$ = 角频率（恒定）；
- **旋转矢量与 $x$ 轴的夹角** $\omega t + \varphi$ = 相位；
- **$t = 0$ 时刻的夹角** $\varphi$ = 初相；
- **投影** = 位移 $x$。

<span class="marginnote">对应关系还可以推广到速度与加速度：速度矢量是旋转矢量端点速度的投影，加速度是向心加速度的投影。于是「位移、速度、加速度」三个量的相位关系在旋转矢量图里一眼可见——速度投影比位移投影提前四分之一圈。</span>

**重点：旋转矢量本身不是真实存在的物理量，它是「思维工具」。** 振动确实发生在一条直线上，但借助匀速圆周运动这个「虚拟运动」，我们能直接读出相位、判断运动方向、预测将来时刻的状态。工程上把这个思想实体化为「相量（phasor）」用于交流电路分析——同一套语言。

**为什么这个「圆周投影」是可行的？**因为简谐振动 $x = A\cos(\omega t+\varphi)$ 的数学结构，与匀速圆周运动的 $x$ 坐标完全相同：匀速圆周运动在 $x$ 轴的坐标恰是 $A\cos(\omega t+\varphi)$，其中 $A$ 是半径、$\omega$ 是角速度。所以「投影」不是近似，而是**精确的等价**——这正是旋转矢量法能用来解题的根基。只要记住「半径 = 振幅、角速度 = 角频率、角度 = 相位」三对对应，任何一个简谐振动问题都可以先翻译成一张图。

## 2 用旋转矢量读运动状态

给定旋转矢量，任意时刻 $t$ 的振动状态由三点读出：

1. **位移**：矢量在 $x$ 轴的投影。
2. **速度方向**：矢量端点绕行，投影沿 $x$ 增大方向移动（上半圆）或减小方向移动（下半圆）——对应速度正负。
3. **加速度**：恒指向 $x$ 轴负方向（投影的向心加速度在 $x$ 轴投影）。

**辨析｜易错点：**速度的方向判断是旋转矢量法的高频失分点。物体位于 $x$ 轴上方（投影为正）时，端点绕行若处在「向上走」的那一半（相位角在 $0 \sim \pi$ 之间增大），投影在增大，速度为正；反之投影减小，速度为负。**绝不能只凭位移的符号判断速度方向**——同一位置可以有正、负两种速度，这正是初相确定时需要补充信息的根本原因。

**振动三量的相位关系**

| 物理量 | 表达式 | 相对位移的相位 |
| --- | --- | --- |
| 位移 $x$ | $A\cos(\omega t+\varphi)$ | 基准 |
| 速度 $v$ | $-\omega A\sin(\omega t+\varphi) = \omega A\cos(\omega t+\varphi+\frac{\pi}{2})$ | 超前 $\pi/2$ |
| 加速度 $a$ | $-\omega^2 A\cos(\omega t+\varphi) = \omega^2 A\cos(\omega t+\varphi+\pi)$ | 超前 $\pi$ |

速度比位移超前四分之一周期，加速度与位移正好反相。这张表是「谁先到极值」这类问题的通用答案，也可以直接从旋转矢量端点速度、向心加速度的投影读出来。

**算例：** 已知 $x = 4\cos(2t+\frac{\pi}{3})$（SI 单位），求 $t = \frac{\pi}{6}$ s 时的位移与速度方向。相位 $\omega t+\varphi = 2\times\frac{\pi}{6}+\frac{\pi}{3} = \frac{2\pi}{3}$，位移 $x = 4\cos\frac{2\pi}{3} = -2$ m。此刻旋转矢量在上半圆且相位仍在增大，投影继续沿负方向减小，故速度 < 0。反过来，若只告诉你「位移是 -2 m」，速度方向无法唯一确定——单点位移不携带初相信息，这正是旋转矢量「必须配速度方向」的原因。

这个算例还展示了一般的解题技巧：把 $x = A\cos(\omega t+\varphi)$ 的系数「翻译」成旋转矢量（长度 $A$、初角 $\varphi$、转速 $\omega$），任何「给定 $t$ 求状态」的题都可以先画矢量再投影——图比代数更容易暴露符号错误。

## 3 用旋转矢量确定初相

上一节我们遇到「由初位移确定初相有两个候选值」的问题。用旋转矢量法，可以一次性画图解决：

**第一步**：画 $x$ 轴，标出 $x_0$ 的位置；
**第二步**：过 $x_0$ 作垂直于 $x$ 轴的直线，与以 $A$ 为半径的圆交于两点——这是 $t=0$ 时刻旋转矢量端点的两个可能位置；
**第三步**：用「初速度方向」（端点应朝哪个方向绕）剔除错误的一个，剩下的夹角即初相 $\varphi$。

<span class="marginnote">这个几何方法比代数方法更不容易错：你直接「看见」了为什么有两个候选相位、为什么速度符号能剔除一个。画图时注意规定角度正方向为逆时针、从 $x$ 轴正方向算起。</span>

## 4 公式解析：旋转矢量求时间间隔

一质点做振幅 $A$、周期 $T$ 的简谐振动，求它从 $x = A$ 第一次运动到 $x = A/2$ 所需的时间。

$$
\omega t = \frac{\pi}{3} \quad\Longrightarrow\quad t = \frac{\pi/3}{2\pi/T} = \frac{T}{6}
$$

- **第一步，画旋转矢量图**：$x = A$ 对应旋转矢量沿 $x$ 轴正方向（相位 $0$）；$x = A/2$ 对应旋转矢量与 $x$ 轴夹角 $\pm\frac{\pi}{3}$。
- **第二步，选正确分支**：从 $x=A$ 向 $x = A/2$ 运动，方向是相位增大（逆时针），故取 $+\frac{\pi}{3}$ 那条。
- **第三步，算相位增量对应的时间**：相位从 $0$ 增至 $\frac{\pi}{3}$，耗时 $\Delta t = \frac{\pi/3}{\omega} = \frac{T}{6}$。
- **第四步，验证直觉**：全周期 $T$ 对应 $2\pi$ 相位，$\pi/3$ 是 $2\pi$ 的六分之一，所以耗时是周期的六分之一。用旋转矢量，这类题几乎可以「目测」出来，无需解反三角函数。

**重点：时间之比 = 相位之比。** 旋转矢量匀速旋转，相位均匀增加，所以「从某相位到某相位的时间」就是「相位差 ÷ 角频率」。一切「求时间」的简谐振动题，本质都是在问「旋转矢量转过多大角度」。

**拓展：从一维到二维。**若把旋转矢量法推广到两个互相垂直的方向（$x$ 与 $y$ 都是简谐振动），端点轨迹不再是直线投影，而是一般是椭圆——这就是**李萨如（Lissajous）图形**：两方向频率相同则轨迹为椭圆（或直线/圆），频率成整数比则出现闭合花样。示波器正是用李萨如图形来精确比较两个信号的频率比。从「一根轴上的投影」到「二维轨迹」，旋转矢量的几何威力进一步显现。

## 5 旋转矢量法在合成问题中的预告

两个同方向、同频率的简谐振动 $x_1 = A_1\cos(\omega t+\varphi_1)$、$x_2 = A_2\cos(\omega t+\varphi_2)$ 合成时，结果仍是同频率的简谐振动：

$$x = x_1 + x_2 = A\cos(\omega t + \varphi)$$

其中合成振幅与初相由平行四边形法则得到：

$$A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos(\varphi_2-\varphi_1)}$$

- 相位差 $\Delta\varphi = 0$（同相）：$A = A_1 + A_2$，加强；
- 相位差 $\Delta\varphi = \pi$（反相）：$A = |A_1 - A_2|$，减弱。

<span class="marginnote">旋转矢量法让「同相加强、反相减弱」变成一眼可见的几何事实：两个矢量同向就相加，反向就相减。这个「相位差决定干涉结果」的模式，是第七章《机械波》干涉、第十六章《波动光学》杨氏双缝干涉的共同内核。</span>

**辨析｜易错点：旋转矢量法的适用范围。**旋转矢量法只能直观处理**同频率**振动之间的比较与合成——不同频率的振动，两个矢量的相对位置每时每刻都在变，「画一张静止的图」的直观就失效了，需要拍频、李萨如（Lissajous）图形等新工具（见第七章）。做题前先确认「是否同频率」，再决定能不能用矢量合成；把旋转矢量法硬套到不同频率问题上，是常见的错误路径。

**相量法：旋转矢量思想的工程落地。**交流电路里，电阻、电感、电容上电压电流的相位关系分别相差 $0$、$\frac{\pi}{2}$、$-\frac{\pi}{2}$，把它们画成旋转矢量（工程上叫**相量，phasor**）后，求总电压电流只需做矢量加减。等你学到第三级《交流电》时会再次遇见这套「画矢量图解题」的方法——同一棵几何树的另一根枝。

## 6 小结

- **旋转矢量法**：简谐振动 = 匀速圆周运动在直径上的投影；矢量长度、角速度、夹角分别对应振幅、角频率、相位。
- 用旋转矢量可直观读出：位移、速度方向、加速度、初相，以及任意时刻的状态。
- 确定初相：几何画图比代数解更不易错，速度符号用于剔除候选解。
- 求时间：时间之比 = 相位之比，$\Delta t = \Delta\varphi/\omega$。
- 同频振动合成的振幅公式 $A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos\Delta\varphi}$ 为波的干涉埋下伏笔。
- 相量法（phasor）是旋转矢量在交流电路里的工程化，画矢量图解题的思路从振动一路通到电磁学。
