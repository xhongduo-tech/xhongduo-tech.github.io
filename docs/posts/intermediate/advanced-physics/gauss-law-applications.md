# 高斯定理及其应用

<div class="epigraph">
<p>穿过一个闭合曲面的电通量，只由曲面内的电荷决定——高斯定理用一句话，把电荷与场连成了整体。</p>
<footer>—— 卡尔 · 弗里德里希 · 高斯（Carl Friedrich Gauss）</footer>
</div>

<div class="article-byline">

## 为什么从高斯定理开始

上一节的微元法虽然通用，但遇到对称性好的电荷分布（球、无限长线、无限大面）时显得笨重。**高斯定理（Gauss' law）**提供了一条优雅的捷径：电通量穿过闭合曲面的总量只由曲面内包围的电荷决定。它的强大之处在于：当电荷分布具有**高度对称性**时，可以直接从通量反推场强，几乎不用积分。这条定理也是麦克斯韦方程组的第一个方程（积分形式），是整个电磁学的支柱之一。<span class="marginnote">高斯定理还可以从「电场线」的视角直观理解：电荷是电场线的源头，每单位电荷（除以 $\varepsilon_0$）发出固定数目的电场线；闭合曲面「数」的正是穿过的条数，条数只由曲面内的源决定——这为后面第十四章麦克斯韦方程组里 $\nabla\cdot\boldsymbol{E} = \rho/\varepsilon_0$ 的微分形式埋下伏笔。</span>

高斯定理属于一类更广的数学语言——**通量与散度**。把闭合曲面缩到无穷小，通量积分就过渡到散度 $\nabla\cdot\boldsymbol{E}$（第十四章的微分形式）；把闭合曲面换成开放曲面，就过渡到环量与旋度。静电场的高斯定理正是「微积分三大关系」里第一块拼图，后面磁场的「无源」方程 $\oint\boldsymbol{B}\cdot\mathrm{d}\boldsymbol{S} = 0$ 与它形成漂亮的对比：电场线有起点终点（源电荷），磁场线却永远闭合。

## 1 电通量

**电通量（electric flux）**：穿过某曲面的电场线总数，定义为场强在曲面上的面积分：

$$\Phi_E = \oint_S \boldsymbol{E}\cdot\mathrm{d}\boldsymbol{S}$$

对闭合曲面，取外法线方向为正。<span class="marginnote">「电通量 = 电场线穿过曲面的条数」是直观理解：电场线密（$E$ 大）、面积大，通量就大；场线与曲面平行（夹角 90°）时通量为零。通量是标量，可正可负——向外为正、向内为负。</span>

**辨析｜易错点：**$\mathrm{d}\boldsymbol{S}$ 是**有方向的面积元**，方向取外法线。计算 $\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{S}$ 时，夹角 $\theta$ 的余弦决定贡献正负：场线与外法线同向（$0^\circ < \theta < 90^\circ$）贡献为正，反向（$90^\circ < \theta < 180^\circ$）贡献为负，垂直（$\theta = 90^\circ$）贡献为零。初学时最常见的错误是把面积当作标量直接相乘，忘了法线方向——这会导致球面通量正负全错。

## 2 高斯定理

**高斯定理**：真空中，通过任意闭合曲面的电通量，等于该曲面内包围电荷的代数和除以 $\varepsilon_0$：

$$\oint_S \boldsymbol{E}\cdot\mathrm{d}\boldsymbol{S} = \frac{\sum q_{\text{内}}}{\varepsilon_0}$$

**重点：高斯定理的普适性。** 它对任意闭合曲面、任意电荷分布都成立（静电场中），但只有电荷分布具有对称性（球对称、轴对称、面对称）时，才能用高斯定理**求出**场强。高斯定理是「通量与电荷」的全局关系，而点电荷场强是它的特例（以点电荷为中心取球面）。<span class="marginnote">高斯定理的证明思路：点电荷的场强 $E = q/(4\pi\varepsilon_0 r^2)$ 乘以球面积 $4\pi r^2$ 恰好抵消 $r^2$，得 $\Phi = q/\varepsilon_0$。任意曲面可看作球面的变形——通量不变，因为电场线「穿过曲面的条数」只由源电荷决定。电荷在曲面外时，进入与穿出的场线数相等，通量为零。</span>

**辨析｜易错点：**高斯定理中的 $\boldsymbol{E}$ 是曲面上**所有**电荷（含曲面外电荷）产生的总场强；而等式右边只计入**曲面内**电荷。曲面外的电荷不影响通量，但影响曲面上的场强分布——这是「通量」与「场强」的核心区别。例如两平行带电平面之间，任取一个只包住其中一面的高斯盒，通量公式右边只写这一面的电荷，但左边 $\boldsymbol{E}$ 却是两面的叠加场。

**补充｜本质：**高斯定理是库仑定律 $1/r^2$ 平方反比律的直接推论。若静电力不是平方反比（例如 $1/r^3$），通量就不等于面内电荷除以 $\varepsilon_0$，高斯定理会失效。反过来，实验上验证高斯定理成立，也就间接验证了平方反比律——这正是电磁学史上「平方反比精确性」实验（如卡文迪什实验）的逻辑基础。平方反比还有一个漂亮的结果：电荷发出的电场线永不终止在真空，只在电荷处开始或结束。

## 3 用高斯定理求场强的步骤

用高斯定理求对称场强，遵循「选面 → 对称 → 通量 → 反推」四步：

1. **分析对称性**：判断场强方向与大小随位置的分布规律（球对称沿径向、面对称垂直平面等）；
2. **选高斯面**：选取与场强方向垂直或平行的对称闭合曲面（球面、圆柱面、盒面），使 $\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{S}$ 简化；
3. **算通量**：$E\oint\mathrm{d}S = E\cdot(\text{面积})$（对称性使 $E$ 可提出积分号）；
4. **反推场强**：$E\cdot S_{\text{总}} = \sum q_{\text{内}}/\varepsilon_0$，解出 $E$。

<span class="marginnote">「选对高斯面」是高斯定理应用的全部艺术：球对称选同心球面、无限长线选同轴圆柱面、无限大面选跨平面的圆柱盒。高斯面必须让场强在面上「要么垂直恒定、要么为零分量」，否则 $E$ 提不出积分号，定理就退化成一句空话。</span>

## 4 公式解析：均匀带电球体的场强

半径为 $R$、总电量 $Q$ 的均匀带电球体，求球内（$r < R$）与球外（$r > R$）的场强。

**球外**（$r > R$，高斯面取半径 $r$ 的同心球面）：

$$
\oint\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{S} = E\cdot4\pi r^2 = \frac{Q}{\varepsilon_0} \quad\Longrightarrow\quad E = \frac{1}{4\pi\varepsilon_0}\frac{Q}{r^2}
$$

- **第一步，选高斯面**：球对称，取同心球面，面上 $E$ 恒定且沿径向，$E\oint\mathrm{d}S = E\cdot4\pi r^2$。
- **第二步，算曲面内电荷**：球外 $r > R$，内电荷 $= Q$。
- **第三步，解出场强**：$E = Q/(4\pi\varepsilon_0 r^2)$——**球外与点电荷场强相同**。

**球内**（$r < R$，电荷密度 $\rho = \frac{Q}{4\pi R^3/3}$）：

$$
\sum q_{\text{内}} = \rho\cdot\frac{4}{3}\pi r^3 = Q\frac{r^3}{R^3} \quad\Longrightarrow\quad E = \frac{Qr}{4\pi\varepsilon_0 R^3}
$$

- **第一步，算曲面内电荷**：高斯面内只有半径 $r$ 的部分球体，电荷按体积比 $Q r^3/R^3$。
- **第二步，代通量公式**：$E\cdot4\pi r^2 = \frac{Qr^3/R^3}{\varepsilon_0}$。
- **第三步，解出**：$E = \frac{Qr}{4\pi\varepsilon_0 R^3}$——**球内场强与 $r$ 成正比**（线性增长），球心处为零。
- **第四步，衔接**：$r = R$ 处两式相等（$E = Q/(4\pi\varepsilon_0R^2)$），场强连续；球外按 $1/r^2$ 衰减，球内线性增长。

**重点：球内 $E \propto r$、球外 $E \propto 1/r^2$，球心场强为零。** 这是高斯定理最经典的成果，也是带电球壳/球体的标准答案。对比：均匀带电球壳（电荷只在表面）在球内场强为零——「空腔内无场」是静电屏蔽的雏形（第十一章）。<span class="marginnote">「球内场强线性增长」可以这样想：球心处四周电荷对称，任何方向的贡献都被抵消，场强为零；越靠近表面，高斯面内包住的电荷越多（按 $r^3$ 增长），而表面积按 $r^2$ 增长，两者之比就是 $r$。这个「内部线性、外部平方反比」的图像，与引力场中均匀密度球体的结论完全同构。</span>

### 均匀带电球壳与均匀带电球体的对比

| 带电体 | 球内（$r < R$） | 球外（$r > R$） |
| --- | --- | --- |
| 均匀带电球体 | $E = \dfrac{Qr}{4\pi\varepsilon_0R^3}$（线性增长） | $E = \dfrac{Q}{4\pi\varepsilon_0r^2}$ |
| 均匀带电球壳 | $E = 0$ | $E = \dfrac{Q}{4\pi\varepsilon_0r^2}$ |

**重点：球壳「空腔内无场」是静电屏蔽（第十一章）的直接前提。** 两者的区别全在「电荷是否充满球体内部」：球体电荷按体积分布，内部高斯面能包住电荷；球壳电荷只在表面，内部高斯面包不住任何电荷，通量为零，故场强为零。这个对比也解释了导体带电后电荷为何全部分布在外表面——导体内部若存在电场，自由电子会一直运动到表面，把内部电场抵消（静电平衡）。

## 5 高斯定理的应用小结

| 电荷分布 | 对称性 | 高斯面 | 结果 |
| --- | --- | --- | --- |
| 点电荷 | 球对称 | 同心球面 | $E = \frac{Q}{4\pi\varepsilon_0r^2}$ |
| 均匀带电球体 | 球对称 | 同心球面 | 内 $E \propto r$，外 $E \propto 1/r^2$ |
| 无限长均匀带电直线 | 轴对称 | 同轴圆柱面 | $E = \frac{\lambda}{2\pi\varepsilon_0r}$ |
| 无限大均匀带电平面 | 面对称 | 圆柱盒 | $E = \frac{\sigma}{2\varepsilon_0}$ |

**重点：高斯定理的强大在于「四两拨千斤」——用全局的通量关系绕过积分细节。** 但必须牢记它的适用前提：对称性足够好，使 $\boldsymbol{E}$ 能从通量积分中提出。对称性差时（如任意形状带电体），还是老老实实回到上一节的微元法。<span class="marginnote">无限长线的场强 $E = \lambda/(2\pi\varepsilon_0 r)$ 是轴对称的经典结果（同轴圆柱高斯面），它与点电荷的 $1/r^2$ 不同——是 $1/r$。一维分布、二维分布的场强衰减规律各不相同，这是「维度决定衰减」的物理直觉，也呼应电磁波与引力在低维空间的标度行为。</span>

**辨析｜易错点：**「无限长」「无限大」是理想化假设，但结论有实用意义。有限长带电直线靠近中段处，场强仍近似 $E = \lambda/(2\pi\varepsilon_0 r)$，偏离两端时才明显失效。同理，离有限大带电平面足够近、且远离边缘的区域，场强近似常数 $\sigma/(2\varepsilon_0)$——这就是平行板电容器内部「近似均匀场」的来源，也正是下一节电容与能量计算能用简单公式的前提。

### 算例：平行板电容器内部的均匀场

两片相距 $d = 1\ \text{cm}$ 的无限大带电平面，面电荷密度均为 $\sigma = 8.85\times10^{-9}\ \text{C/m}^2$，一正一负。

- **单面场强**：每片单独产生 $E_1 = \sigma/(2\varepsilon_0) = 500\ \text{V/m}$；
- **板间叠加**：两片场强同向，$E = 2E_1 = \sigma/\varepsilon_0 = 1000\ \text{V/m}$；
- **板外抵消**：两片场强反向，板外 $E = 0$——「均匀场只在板内」；
- **电压**：$U = Ed = 1000\times0.01 = 10\ \text{V}$；
- **结论**：这正是下一节电容 $C = Q/U$ 计算的基本出发点，也是第十一章平行板电容器公式的推导核心。

**辨析｜易错点：**「无限大平面场强不随距离衰减」常被误记。直觉会以为「离得越远场越弱」，但对无限大平面，远处看到的「面元贡献」依然无限多，各方向贡献叠加后恰好抵消掉距离因素，场强保持恒定。有限大平板的边缘效应则会让场强不均匀——那已超出高斯定理能精确处理的范围。

**旁白｜引力类比：**高斯定理在引力场中有完全同构的形式：$\oint\boldsymbol{g}\cdot\mathrm{d}\boldsymbol{S} = -4\pi GM_{\text{内}}$。均匀密度球体内引力随深度线性减小、球外按 $1/r^2$ 衰减，与带电球体完全平行——这正是均匀密度地球内「越深越轻」（如矿井底部）的物理来源，也把静电与万有引力统一到同一套「通量」数学框架。

## 6 小结

- **电通量**：$\Phi_E = \oint\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{S}$，电场线穿过闭合曲面的总数。
- **高斯定理**：$\oint\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{S} = \sum q_{\text{内}}/\varepsilon_0$，普适成立。
- 用高斯定理解题的前提：高度对称性（球、轴、面）；四步法「选面→对称→通量→反推」。
- 均匀带电球体：内 $E = Qr/(4\pi\varepsilon_0R^3)$、外 $E = Q/(4\pi\varepsilon_0r^2)$。
- 常见结果：点电荷 $1/r^2$、无限长线 $1/r$、无限大面常量。
- 高斯定理是麦克斯韦方程组第一方程的积分形式（第十四章）。
