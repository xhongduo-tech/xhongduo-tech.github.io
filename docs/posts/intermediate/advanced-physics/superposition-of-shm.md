# 简谐振动的合成

## 为什么从振动合成开始

一个质点可能同时参与多个振动：耳朵里的鼓膜同时收到许多声音，桥面同时承受风与车流的扰动，两个波源同时激起水面波纹。振动合成（叠加）研究「多个振动同时作用于一点时，合运动是什么」。这是波的叠加原理在振动层面的先声——第七章《机械波》的干涉、第十六章《波动光学》的相干叠加，全都建立在这节的基础上。我们重点研究两种情形：**同方向、同频率**的合成（结果仍为简谐振动）与**同方向、不同频率**的合成（出现拍）。

## 1 叠加原理

**振动叠加原理**：质点同时参与多个简谐振动时，合位移等于各分振动位移的矢量和（同方向则代数和）。

$$x = x_1 + x_2$$

叠加原理成立的前提是**线性性**——回复力与位移成正比（$F = -kx$）。线性系统里「和」仍然是系统的解，这叫**线性叠加原理**。<span class="marginnote">叠加原理是物理学最深刻的简约之美：复杂的运动 = 简单运动的叠加。傅里叶分析正是这个思想的极端形式——任何周期信号都能拆成无数简谐振动的叠加。这个观念从振动出发，贯穿波动、电磁学、量子力学。</span>

**辨析｜易错点：**叠加原理只对线性系统严格成立。若回复力不再是线性的（大振幅单摆、非线性弹簧），「和的解」不再成立，会出现谐波、分频等新现象。我们课程里的振动、波、电磁波都在线性范围内，这是叠加原理可靠的前提。

## 2 同方向、同频率简谐振动的合成

设两个同方向、同频率的简谐振动 $x_1 = A_1\cos(\omega t+\varphi_1)$、$x_2 = A_2\cos(\omega t+\varphi_2)$，合振动仍为同频率的简谐振动：

$$x = A\cos(\omega t + \varphi)$$

用旋转矢量法（上节铺垫）可以瞬间得出合振幅与初相：

$$A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos(\varphi_2-\varphi_1)}, \qquad \tan\varphi = \frac{A_1\sin\varphi_1 + A_2\sin\varphi_2}{A_1\cos\varphi_1 + A_2\cos\varphi_2}$$

**重点：合振幅由相位差 $\Delta\varphi = \varphi_2 - \varphi_1$ 唯一决定。** 两个极限情形：

- **同相**（$\Delta\varphi = 2n\pi$）：$A = A_1 + A_2$，振动加强；
- **反相**（$\Delta\varphi = (2n+1)\pi$）：$A = |A_1 - A_2|$，振动减弱。

<span class="marginnote">「同相加强、反相减弱」是干涉的灵魂。注意：振幅相同的两反相振动合振幅为零——完全抵消。这是主动降噪耳机的基本原理：产生一个与噪声反相的声波，让它们在耳朵处抵消。</span>

## 3 同方向、不同频率：拍

两个同方向、频率相近（$\omega_1 \approx \omega_2$）的简谐振动合成，得到振幅周期性变化的**拍（beat）**现象。

设 $A_1 = A_2 = A$，合振动可写为：

$$x = 2A\cos\left(\frac{\omega_2-\omega_1}{2}t + \frac{\varphi_2-\varphi_1}{2}\right)\cos\left(\frac{\omega_2+\omega_1}{2}t + \frac{\varphi_2+\varphi_1}{2}\right)$$

- **快变因子** $\cos\frac{\omega_1+\omega_2}{2}t$：频率为两频率平均值，决定「振动本身」的快慢；
- **慢变因子** $\cos\frac{\omega_2-\omega_1}{2}t$：频率为两频率差的一半，像「包络」一样调制振幅——振幅随时间慢变。

**拍频**等于两频率之差：

$$\nu_{\text{拍}} = |\nu_2 - \nu_1|$$

声音的「呜呜」强弱起伏就是拍。听调音师调音：当两根弦频率逐渐接近，拍的起伏越来越慢，直到拍消失（频率相等）——用拍频调准音，精确又直观。<span class="marginnote">拍是「差频」现象，广泛用于测量、雷达测速、通信中的外差接收。两列频率相近的波叠加产生的「拍」与「差频」，与光学里的拍频干涉、量子力学里的量子拍异曲同工。</span>

## 4 公式解析：反相振动叠加

两个振幅相同、相位差 $\pi$ 的简谐振动合成，求合振幅。

$$
A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos\pi} = \sqrt{A^2 + A^2 - 2A^2} = 0
$$

- **第一步，写公式**：合振幅 $A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos\Delta\varphi}$。
- **第二步，代入反相**：$\Delta\varphi = \pi$，$\cos\pi = -1$，$A_1 = A_2 = A$。
- **第三步，计算**：$A = \sqrt{A^2 + A^2 - 2A^2} = 0$。
- **第四步，几何理解**：两个旋转矢量方向相反、长度相等，矢量和为零——合振动完全消失。

**辨析｜易错点：**合振幅是「矢量合成」，不是「代数相加」。初学者常写 $A = A_1 + A_2$（忘记相位差），或 $A = |A_1 - A_2|$（只记得反相）。正确做法永远是代入完整公式或画旋转矢量图。另外，「相位差为 $\pi$」与「相位差为 $2\pi$」完全不同：前者反相抵消，后者同相加强。

## 5 相互垂直的简谐振动合成：李萨如曲线

两个**方向互相垂直**、同频率的简谐振动合成时，质点的轨迹由两个分振动共同决定。消去时间 $t$ 可得轨迹方程；当频率之比为有理数时，轨迹闭合，称为**李萨如曲线（Lissajous figure）**。<span class="marginnote">李萨如曲线的形状由两分振动的频率比与相位差决定。示波器上显示李萨如图形，可以用来精确测量未知信号的频率——两个频率不成整数比时，图形不闭合、飘动，正是判断频率比的方法。</span>

**重点：垂直振动的合成结果一般不是简谐振动，而是一条平面曲线。** 相位差为 $0$ 时轨迹是直线，为 $\pi/2$ 时是椭圆（等振幅时为圆），其他相位差是一般椭圆——这就是「偏振」的数学雏形，到波动光学的偏振章节我们会看到光在垂直方向的分量合成。

## 6 小结

- **叠加原理**：线性系统中合位移 = 分位移之和；是傅里叶分析、波的干涉的哲学基础。
- **同方向同频率合成**：$A = \sqrt{A_1^2+A_2^2+2A_1A_2\cos\Delta\varphi}$；同相加强、反相减弱。
- **拍**：频率相近的振动合成，振幅慢变，拍频 $\nu_{\text{拍}} = |\nu_2-\nu_1|$；用于调音、测频。
- 垂直方向合成得李萨如曲线，是偏振与示波器测频的基础。
- 反相、等幅叠加完全抵消——主动降噪的原理。

在下一节，我们给简谐振动加上「阻力」与「驱动力」，研究**阻尼振动**与**受迫振动、共振**——从理想的无耗散世界回到现实。
