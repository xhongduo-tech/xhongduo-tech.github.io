## 为什么从中心力场开始

上一节提到氢原子需要角动量算符，这一节系统地研究**中心力场（central force field）**：势能只依赖到原点的距离 $V(r)$（库仑、谐振子、万有引力）。中心力场的核心结构：**角动量守恒**（$[\hat{L}, \hat{H}] = 0$）使问题分离为「径向 + 角度」两部分，角度部分由球谐函数（角动量本征态）描述，径向部分化为「等效一维方程」。氢原子（库仑场）是中心力场的标准解。这一节建立角动量算符与本征值，概述中心力场求解。

## 1 角动量算符

**轨道角动量算符**：$\hat{\boldsymbol{L}} = \hat{\boldsymbol{r}}\times\hat{\boldsymbol{p}}$，分量：

$$\hat{L}_x = \hat{y}\hat{p}_z - \hat{z}\hat{p}_y = -i\hbar\left(y\frac{\partial}{\partial z} - z\frac{\partial}{\partial y}\right), \qquad \text{（循环）}$$

**对易关系**：

$$[\hat{L}_x, \hat{L}_y] = i\hbar\hat{L}_z, \quad [\hat{L}_y, \hat{L}_z] = i\hbar\hat{L}_x, \quad [\hat{L}_z, \hat{L}_x] = i\hbar\hat{L}_y, \qquad [\hat{L}^2, \hat{L}_z] = 0$$

**重点：角动量分量互不对易（$[\hat{L}_x,\hat{L}_y] = i\hbar\hat{L}_z$），但 $\hat{L}^2$ 与各分量对易。** 因此可以同时确定 $L^2$ 与一个分量（通常 $L_z$），但不能同时确定两个分量。$\hat{L}^2$ 与 $\hat{L}_z$ 构成「共同本征态完全集」——角动量的大小与一个方向分量可以同时确定，但方向的其他分量不确定（角动量矢量「模糊地指向」）。<span class="marginnote">「角动量方向的量子模糊」：$L^2 = l(l+1)\hbar^2$ 与 $L_z = m\hbar$ 可同时确定，但 $L_x$、$L_y$ 不确定——角动量矢量像「倾斜的陀螺」，绕 $z$ 轴进动、方向不确定。这与经典角动量（方向完全确定）本质不同：量子角动量只有「大小 + 一个方向分量」确定。</span>

## 2 角动量本征值

**角动量本征值**：

$$\hat{L}^2 Y_{lm} = l(l+1)\hbar^2Y_{lm}, \qquad \hat{L}_z Y_{lm} = m\hbar Y_{lm}$$

其中 $l = 0, 1, 2, \dots$（角量子数）、$m = -l, \dots, l$（磁量子数，$2l+1$ 个），$Y_{lm}$ 是**球谐函数（spherical harmonics）**——角度本征函数。

**球谐函数**：$Y_{lm}(\theta, \phi)$ 是 $\theta$、$\phi$ 的函数（勒让德多项式/连带勒让德 + $e^{im\phi}$），正交归一、完备。

**重点：角动量本征值 $L^2 = l(l+1)\hbar^2$、$L_z = m\hbar$，本征函数是球谐函数 $Y_{lm}$。** 量子化的角动量大小不是 $l\hbar$ 而是 $\sqrt{l(l+1)}\hbar$（第 106 节已预告）；$m$ 取 $2l+1$ 个值——空间量子化（方向离散）。<span class="marginnote">「$l(l+1)$ 不是 $l^2$」：经典角动量 $L = l\hbar$ 是玻尔的近似；量子力学严格结果是 $L = \sqrt{l(l+1)}\hbar$。$l = 1$ 时 $L = \sqrt{2}\hbar$（不是 $\hbar$）。$m$ 从 $-l$ 到 $l$ 共 $2l+1$ 个方向——「空间量子化」使角动量矢量只能取特定倾斜角（斯特恩-盖拉赫实验的直接解释）。</span>

## 3 中心力场问题的分离变量

中心力场 $V(r)$ 中，定态薛定谔方程在球坐标分离变量：

$$\psi(r, \theta, \phi) = R(r)Y_{lm}(\theta, \phi)$$

径向方程（令 $u(r) = rR(r)$）：

$$-\frac{\hbar^2}{2m}\frac{\mathrm{d}^2u}{\mathrm{d}r^2} + \left[V(r) + \frac{l(l+1)\hbar^2}{2mr^2}\right]u = Eu$$

**重点：中心力场分离为「径向方程（$u$）+ 角度本征函数（$Y_{lm}$）」——角度部分由角动量决定，径向部分是「等效一维方程」。** 有效势 $V_{\text{eff}} = V(r) + \frac{l(l+1)\hbar^2}{2mr^2}$ 含**离心势垒**（$l \neq 0$ 时阻止粒子靠近原点）——这是角动量在径向方程中的表现。<span class="marginnote">「离心势垒」：$\frac{l(l+1)\hbar^2}{2mr^2}$ 随 $r \to 0$ 发散（$l \neq 0$）——有角动量的粒子不能到达原点（经典对应：角动量守恒使 $L = mrv$，$r \to 0$ 时 $v \to \infty$ 不可能）。$s$ 态（$l = 0$）无离心势垒，波函数可在原点非零——这是「电子在核内概率」等问题的关键。</span>

## 4 公式解析：氢原子的径向方程

氢原子（库仑势 $V = -\frac{e^2}{4\pi\varepsilon_0r}$），基态（$n=1, l=0$）径向波函数 $R_{10} = 2(\frac{1}{a_0})^{3/2}e^{-r/a_0}$。验证它满足径向方程。

$$
u(r) = rR_{10} = 2\left(\frac{1}{a_0}\right)^{3/2}re^{-r/a_0}
$$

- **第一步，写径向方程（$l = 0$，无离心项）**：$-\frac{\hbar^2}{2m}u'' - \frac{e^2}{4\pi\varepsilon_0r}u = Eu$。
- **第二步，代入 $u = Cr e^{-r/a_0}$**：$u' = C(1 - r/a_0)e^{-r/a_0}$、$u'' = C(-\frac{2}{a_0} + \frac{r}{a_0^2})e^{-r/a_0}$。
- **第三步，代入方程并整理**：利用玻尔半径 $a_0 = \frac{4\pi\varepsilon_0\hbar^2}{me^2}$，可得 $E = -\frac{me^4}{32\pi^2\varepsilon_0^2\hbar^2} = -13.6\ \text{eV}$——基态能量。
- **第四步，解读**：基态波函数 $e^{-r/a_0}$ 是指数衰减（束缚态）；$R_{10}$ 归一化 $\int_0^\infty|R|^2r^2\mathrm{d}r = 1$。氢原子基态是中心力场问题的最简解。

**辨析｜易错点：**径向波函数 $R(r)$ 与「含 $r^2$ 的体积元」配合（概率 $= |R|^2r^2\mathrm{d}r$）；定义 $u = rR$ 使径向方程形如「一维薛定谔方程」但注意 $r \ge 0$ 边界条件（$u(0) = 0$ 除 $l=0$ 外）。球谐函数 $Y_{lm}$ 的归一化与正交性是角度积分的工具——计算概率时别忘了 $r^2\sin\theta$ 的球坐标体积元。

## 5 中心力场的意义

- **氢原子**：库仑场 + 角动量 → 能级 $E_n = -13.6/n^2$ eV、量子数 $(n, l, m)$（第 106 节）；
- **谐振子（各向同性）**：三维谐振子，能级简并结构；
- **万有引力场**：量子化的束缚态（类比行星轨道，但离散）；
- **转动惯量与分子转动**：双原子分子转动能级 $E_l = \frac{l(l+1)\hbar^2}{2I}$——分子光谱的转动结构。

**重点：中心力场是量子力学最重要的可解问题族——氢原子、谐振子、分子转动都是其应用，角动量量子化贯穿其中。** 角动量守恒（$[\hat{L}, \hat{H}] = 0$）使问题可分离，球谐函数给出角度结构，径向方程给出能级。<span class="marginnote">「角动量在原子物理的统治地位」：$l$ 决定轨道形状与角动量、$m$ 决定方向、选择定则 $\Delta l = \pm1$（偶极辐射）决定光谱——原子光谱的整个结构由角动量量子化支配。从氢原子到复杂原子的壳层，从分子转动到核自旋，角动量算符是量子力学的通用钥匙。</span>

## 6 小结

- **角动量算符**：$\hat{\boldsymbol{L}} = \hat{\boldsymbol{r}}\times\hat{\boldsymbol{p}}$；$[\hat{L}_x,\hat{L}_y] = i\hbar\hat{L}_z$、$[\hat{L}^2,\hat{L}_z] = 0$。
- **本征值**：$L^2 = l(l+1)\hbar^2$、$L_z = m\hbar$（$m = -l,\dots,l$）；本征函数是球谐函数 $Y_{lm}$。
- 中心力场分离变量：$\psi = R(r)Y_{lm}$；径向方程含离心势垒 $\frac{l(l+1)\hbar^2}{2mr^2}$。
- 氢原子是库仑场 + 角动量的解；分子转动 $E_l = \frac{l(l+1)\hbar^2}{2I}$。
- 角动量量子化 + 选择定则支配原子光谱。
