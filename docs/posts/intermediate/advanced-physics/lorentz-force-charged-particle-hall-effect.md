## 为什么从洛伦兹力开始

磁场对电流施力，而电流是运动电荷——归根结底，磁场对**运动电荷**施力。这条力就是**洛伦兹力（Lorentz force）**，它是磁场最基本的相互作用。带电粒子在磁场中不做功、只改变方向，于是走出圆弧或螺旋线——这个运动是回旋加速器、质谱仪、显像管、极光、乃至宇宙射线探测的全部原理。而**霍尔效应**把洛伦兹力应用到导体，用磁场测量电荷与磁场，是传感器的基石。这一节把洛伦兹力与粒子运动讲透。

## 1 洛伦兹力

**洛伦兹力（Lorentz force）**：电荷 $q$ 以速度 $\boldsymbol{v}$ 在磁场 $\boldsymbol{B}$ 中运动所受的力：

$$\boldsymbol{F} = q\boldsymbol{v}\times\boldsymbol{B}$$

大小为 $F = qvB\sin\theta$（$\theta$ 为 $\boldsymbol{v}$ 与 $\boldsymbol{B}$ 的夹角），方向由右手定则（$q > 0$）或左手定则判断。若还有电场，总力为：

$$\boldsymbol{F} = q\boldsymbol{E} + q\boldsymbol{v}\times\boldsymbol{B}$$

**重点：洛伦兹力永远垂直于速度，不做功，只改变运动方向。** 这一点让带电粒子在匀强磁场中的运动成为「圆周运动」问题——磁力充当向心力，速度大小不变。<span class="marginnote">洛伦兹力不做功，但能改变动量方向。这是磁场「只负责拐弯」的本质：它不增加粒子的能量，加速粒子要靠电场（回旋加速器里电场加速、磁场偏转）。这个分工是加速器设计的核心思想。</span>

## 2 带电粒子在匀强磁场中的运动

设 $\boldsymbol{v} \perp \boldsymbol{B}$：洛伦兹力提供向心力 $qvB = \frac{mv^2}{R}$，得**回旋半径**：

$$R = \frac{mv}{qB}$$

周期与回旋角速度：

$$T = \frac{2\pi m}{qB}, \qquad \omega = \frac{qB}{m}$$

**重点：回旋周期 $T = 2\pi m/(qB)$ 与速度、半径无关！** 粒子转一圈的时间只由质量、电荷与磁场决定。这是回旋加速器的核心原理：磁场把粒子约束在圆形轨道上，电场在每个半圈加速——周期恒定，粒子越转越快、轨道半径越来越大。

**辨析｜易错点：**若 $\boldsymbol{v}$ 与 $\boldsymbol{B}$ 有夹角（不是垂直），粒子做**螺旋运动**：平行磁场方向的分量 $v_\parallel$ 匀速（不受力），垂直分量 $v_\perp$ 圆周运动，合起来是沿磁场方向前进的螺旋线。半径 $R = mv_\perp/(qB)$、螺距 $h = v_\parallel T$。太阳风粒子沿地球磁力线螺旋运动并在两极沉降——极光的来源。

## 3 公式解析：回旋加速器

回旋加速器：磁场 $B$ 中两个 D 形盒，电场在间隙加速。若质子（$m = 1.67\times10^{-27}$ kg，$q = 1.6\times10^{-19}$ C）在 $B = 1.0$ T 的磁场中做回旋运动，求周期。

$$
T = \frac{2\pi m}{qB} = \frac{2\pi\times1.67\times10^{-27}}{1.6\times10^{-19}\times1.0}
$$

- **第一步，写周期公式**：$T = 2\pi m/(qB)$。
- **第二步，代入**：$T = \frac{2\pi\times1.67\times10^{-27}}{1.6\times10^{-19}\times1.0} \approx 6.6\times10^{-8}\ \text{s}$。
- **第三步，算频率**：$\nu = 1/T \approx 1.5\times10^7\ \text{Hz}$（15 MHz）——电场需以这个频率同步换向。
- **第四步，体会**：周期与速度无关，所以只要电场频率固定，粒子就能持续加速。回旋加速器的极限来自相对论效应（速度接近光速时质量增大、周期变长，同步加速器由此而生）。

## 4 霍尔效应

**霍尔效应（Hall effect）**：载流导体（或半导体）放入垂直于电流的磁场中，在垂直于电流与磁场的第三方向上出现电压。

设导体宽 $b$、厚 $d$，电流 $I$，磁场 $B$（垂直板面），载流子浓度 $n$、电荷 $q$。洛伦兹力 $qvB$ 使载流子横向偏转、在侧面积累电荷，建立霍尔电场 $E_H$，平衡时 $qE_H = qv_dB$：

$$U_H = E_H b = v_d Bb = \frac{IB}{nqd}$$

**霍尔电压（Hall voltage）**：$U_H = \frac{IB}{nqd}$。<span class="marginnote">霍尔效应的应用：① 测磁场（霍尔传感器，手机里的霍尔开关）；② 判定载流子符号——霍尔电压的正负区分电子导电（n 型）与空穴导电（p 型）；③ 测载流子浓度。半导体霍尔器件灵敏度远高于金属，是磁传感器的标准件。</span>

**重点：霍尔电压正比于 $IB$、反比于载流子浓度与厚度。** 载流子浓度越小、霍尔电压越大——所以半导体比金属更适合做霍尔传感器（金属载流子浓度太大，$U_H$ 极微小）。

**辨析｜易错点：**判断霍尔电压的正负极，关键在于确定**载流子的实际速度方向**。对电子导电，电子运动方向与电流方向相反，洛伦兹力方向要按「电子速度 × B」算，积累在侧面的电荷符号与「正载流子假设」相反——这正是霍尔效应能区分正负载流子的原因。做题时先画电流方向、再确定载流子速度方向。

## 5 洛伦兹力与磁场应用总览

| 应用 | 原理 | 关键公式 |
| --- | --- | --- |
| 回旋加速器 | 磁场偏转 + 电场加速 | $T = 2\pi m/(qB)$ |
| 质谱仪 | 速度选择器 + 偏转半径测质荷比 | $R = mv/(qB)$ |
| 霍尔传感器 | 霍尔电压测磁场/载流子 | $U_H = IB/(nqd)$ |
| 显像管/CRT | 磁场偏转电子束 | $\boldsymbol{F} = q\boldsymbol{v}\times\boldsymbol{B}$ |
| 极光 | 带电粒子沿磁力线螺旋沉降 | $R = mv_\perp/(qB)$ |

<span class="marginnote">质谱仪是质荷比（$m/q$）测量之王：同一磁场中不同质荷比的离子回旋半径不同，按半径分开——这是化学、生物、医学里鉴定分子的核心技术。磁约束（托卡马克）也靠洛伦兹力把等离子体「关」在磁力线环里，是可控核聚变的候选方案。</span>

## 6 小结

- **洛伦兹力**：$\boldsymbol{F} = q\boldsymbol{v}\times\boldsymbol{B}$，垂直速度、不做功、只改变方向。
- 匀强磁场中：垂直入射做圆周运动，$R = mv/(qB)$，$T = 2\pi m/(qB)$（与速度无关）。
- 斜入射：螺旋运动，半径 $R = mv_\perp/(qB)$、螺距 $h = v_\parallel T$。
- **霍尔效应**：$U_H = IB/(nqd)$，可测磁场、判载流子符号、测浓度。
- 回旋加速器、质谱仪、极光、霍尔传感器——洛伦兹力的工程与天文应用。
