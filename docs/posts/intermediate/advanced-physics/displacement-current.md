## 为什么从位移电流开始

到第十三章为止，我们有了：静电场（高斯定理 + 环路定理）、静磁场（磁高斯定理 + 安培环路定理）、法拉第定律（变化磁场 → 电场）。但麦克斯韦发现一个漏洞：**安培环路定理在电容器充电时不成立**——电流穿过环绕导线的一个曲面，却不穿过「穿过电容器极板间」的曲面，环流矛盾。麦克斯韦的天才补丁：**变化的电场等效于一种电流——位移电流**。这一笔补丁，让「变化的电场 → 磁场」与「变化的磁场 → 电场」完全对称，电磁波由此而生。位移电流是麦克斯韦方程组的点睛之笔。

## 1 安培环路定理的困难

对安培环路定理 $\oint\boldsymbol{B}\cdot\mathrm{d}\boldsymbol{l} = \mu_0\sum I$，取一个「张在回路上的曲面」。电容器充电时：

- 取曲面 $S_1$（穿过导线）：环流 $= \mu_0 I$（电流穿过）；
- 取曲面 $S_2$（穿过电容器极板间）：环流 $= 0$（没有电流穿过极板间）。

**同一个回路，不同曲面得到不同结果——安培环路定理自相矛盾！**<span class="marginnote">这个矛盾暴露了安培环路定理的适用范围：它只对「电流连续」的传导电流成立，而电容器充电时电流在极板处「中断」了。麦克斯韦的解决方案是承认一种新的「电流」在极板间延续——位移电流。</span>

## 2 位移电流的引入

电容器充电时，极板间电场随时间变化。极板上自由电荷 $q = CU = \varepsilon_0SE$，电荷面密度 $\sigma = \varepsilon_0E$。充电电流（传导电流）等于极板电荷变化率：

$$I = \frac{\mathrm{d}q}{\mathrm{d}t} = \varepsilon_0 S\frac{\mathrm{d}E}{\mathrm{d}t}$$

定义**位移电流（displacement current）**：极板间的电场变化等效的电流：

$$I_d = \varepsilon_0 S\frac{\mathrm{d}E}{\mathrm{d}t} = \varepsilon_0\frac{\mathrm{d}\Phi_E}{\mathrm{d}t}$$

其中 $\Phi_E = SE$ 是极板间的电通量。位移电流等于传导电流，电流在电容器处「延续」了。

**全电流（total current）**：传导电流与位移电流之和 $I_{\text{全}} = I_c + I_d$。麦克斯韦的假设：**磁场由全电流激发**。

## 3 位移电流与传导电流的对照

| 比较项 | 传导电流 | 位移电流 |
| --- | --- | --- |
| 来源 | 电荷定向运动 | 电场（电位移）随时间变化 |
| 存在介质 | 导体 | 任何有变化电场的地方（真空中也行） |
| 产生热效应 | 焦耳热 | 无焦耳热（真空中） |
| 产生磁场 | 是 | 是（等效电流） |
| 连续性 | 在极板处中断 | 在极板间延续 |

**重点：位移电流与传导电流只在「产生磁场」这一点上等效。** 位移电流不是真实电荷流动（不产生焦耳热、不受洛伦兹力），它是「变化的电场产生磁场」的另一种说法。真空中没有传导电流，但变化的电场（位移电流）同样激发磁场——这为电磁波在真空中传播提供了可能。<span class="marginnote">「位移电流」名字里的「位移」来自历史：麦克斯韦当年用机械以太的位移解释，如今我们知道它只是「电位移随时间变化」：$I_d = \mathrm{d}\Phi_D/\mathrm{d}t$，$\Phi_D$ 是电位移通量。这个名字是历史遗留，物理本质是「变化电场」。</span>

## 4 公式解析：电容器极板间的位移电流

平行板电容器，极板面积 $S = 0.01\ \text{m}^2$，充电电流 $I = 2\ \text{A}$。求极板间位移电流与电场变化率。

$$
I_d = I = 2\ \text{A}, \qquad \frac{\mathrm{d}E}{\mathrm{d}t} = \frac{I_d}{\varepsilon_0S} = \frac{2}{8.85\times10^{-12}\times0.01}
$$

- **第一步，位移电流等于传导电流**：全电流连续，$I_d = I = 2$ A。
- **第二步，反解电场变化率**：$I_d = \varepsilon_0S\frac{\mathrm{d}E}{\mathrm{d}t}$，$\frac{\mathrm{d}E}{\mathrm{d}t} = \frac{2}{8.85\times10^{-12}\times0.01} \approx 2.26\times10^{13}\ \text{V/(m·s)}$。
- **第三步，体会量级**：电场变化率极大——因为 $\varepsilon_0$ 极小，普通充电电流对应的电场变化率就高达 $10^{13}$ 量级。
- **第四步，验证**：极板间有磁场（安培环路定理的全电流版本）——变化的电场产生磁场，这就是电磁波「场生场」的雏形。

**辨析｜易错点：**位移电流的大小与「电场变化快慢」成正比，与电场本身大小无关。恒定电场（$\mathrm{d}E/\mathrm{d}t = 0$）无位移电流；交变电场才有位移电流。判断位移电流是否存在，看「电场是否在变化」。

## 5 位移电流的意义

位移电流的引入带来两个革命性后果：

1. **安培环路定理被修正**：$\oint\boldsymbol{B}\cdot\mathrm{d}\boldsymbol{l} = \mu_0(I_c + I_d)$，磁场由全电流激发——「变化的电场产生磁场」。
2. **电磁波的可能性**：变化的电场（位移电流）产生磁场，变化的磁场又产生电场（法拉第定律），两者互相激发、脱离电荷以波的形式传播——电磁波。

<span class="marginnote">麦克斯韦从位移电流推出电磁波，并预言其速度为 $c = 1/\sqrt{\mu_0\varepsilon_0} \approx 3\times10^8$ m/s——与光速一致！他写道「光是一种电磁波」。这个统一，与牛顿统一天上地下、爱因斯坦统一时空并称物理学最伟大的统一之一。位移电流是这一切的枢纽。</span>

## 6 数值算例：电磁波中的位移电流密度

频率 $f = 100\ \mathrm{MHz}$ 的平面电磁波，电场振幅 $E_0 = 100\ \mathrm{V/m}$，真空中传播。求位移电流密度振幅。

$$

J_d = \varepsilon_0\frac{\partial E}{\partial t} = \varepsilon_0\omega E_0 = 8.85\times10^{-12}\times2\pi\times10^8\times100

$$

- **第一步，写位移电流密度**：$J_d = \varepsilon_0\,\partial E/\partial t$。
- **第二步，代时间导数**：$E = E_0\cos(\omega t - kx)$，$\partial E/\partial t = -\omega E_0\sin(\omega t - kx)$，振幅 $\omega E_0$。
- **第三步，代入**：$J_{d,0} = 8.85\times10^{-12}\times6.28\times10^8\times100 \approx 0.56\ \mathrm{A/m^2}$。
- **第四步，解读**：这个位移电流密度虽然不大，但正是它（与传导电流一起）激发磁场，维持电磁波自持传播。真空中没有电荷流动，全靠「变化电场 → 位移电流 → 磁场 → 变化磁场 → 电场」的循环。<span class="marginnote">「位移电流的磁效应可以计算」：用安培环路定理（全电流版），由位移电流分布可以求它激发的磁场——这正是电磁波里 $\boldsymbol{E}$ 与 $\boldsymbol{B}$ 互相感生的定量基础。频率越高，$\omega E_0$ 越大，位移电流越显著。</span>

## 7 位移电流与电流连续性

位移电流的引入让「电流连续性」在电容器处得到满足：

$$

\oint_S \boldsymbol{J}_{\text{全}}\cdot\mathrm{d}\boldsymbol{S} = 0, \qquad \boldsymbol{J}_{\text{全}} = \boldsymbol{J}_c + \frac{\partial\boldsymbol{D}}{\partial t}

$$

- **第一步，读方程**：闭合曲面内全电流（传导 + 位移）的通量为零——电流不再中断。
- **第二步，看电荷守恒**：$\nabla\cdot\boldsymbol{J}_c + \frac{\partial\rho}{\partial t} = 0$（电荷守恒）与高斯定理联立，恰好保证位移电流项补齐连续性。
- **第三步，体会统一**：位移电流不是「发明」来凑数的——它由高斯定理与电荷守恒必然推出，麦克斯韦只是把数学上必要的项补进了安培环路定理。<span class="marginnote">这个推导是理论物理「由对称性/守恒律推出新物理」的范例：电荷守恒（电荷连续性方程）要求磁场方程必须含位移电流项。麦克斯韦方程组四条的「一致性」（散度方程与旋度方程相容）本身就是一个约束——这正是第二十一章微分形式要展现的数学美。</span>

**辨析｜易错点：**位移电流的方向与电场变化率同向（$\partial\boldsymbol{D}/\partial t$），充电时极板间位移电流方向与传导电流一致（都流向极板）、放电时相反。画方向时先定电场变化方向，再定位移电流方向——别和「电流方向 = 正电荷流动方向」的直觉混淆。

位移电流是麦克斯韦方程组的点睛之笔：它让「变化电场 → 磁场」与「变化磁场 → 电场」对称，让电流在电容器处延续，也让电磁波得以存在。麦克斯韦由此预言「光即电磁波」——电磁学的统一在此完成。下一节我们把所有规律合并成**麦克斯韦方程组的积分形式**。

## 9 小结

- **安培环路定理的矛盾**：电容器极板间无传导电流，环流随曲面选择不同而矛盾。
- **位移电流**：$I_d = \varepsilon_0\frac{\mathrm{d}\Phi_E}{\mathrm{d}t} = S\varepsilon_0\frac{\mathrm{d}E}{\mathrm{d}t}$——变化的电场等效电流。
- 全电流 = 传导电流 + 位移电流，在电路中处处连续。
- 位移电流与传导电流只在「激发磁场」上等效，不产生焦耳热。
- 位移电流 ⇒「变化电场产生磁场」⇒ 电磁波的可能性 ⇒ 光即电磁波。
