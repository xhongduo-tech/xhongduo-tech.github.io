# 角动量与角动量守恒定律

<div class="epigraph">

## 为什么从角动量开始

平动里有动量 $mv$，转动里就有一个对应的量——**角动量**。它不仅是转动定律 $M = J\alpha$ 的「动量版本」，更是一个独立于动量、甚至比动量更基本的守恒量。原子里的电子、地球的自转、花样滑冰运动员的旋转、陀螺的进动，背后都是角动量守恒。更有意思的是，角动量在微观世界是**量子化**的——这正是第十八章《量子物理基础》里「轨道角动量量子数」的来历。这一节我们建立角动量的概念，并把它推到守恒定律的高度。

## 1 角动量的定义

质量为 $m$、速度 $\boldsymbol{v}$ 的质点，相对参考点 $O$ 的位矢为 $\boldsymbol{r}$，其**角动量（angular momentum）**定义为：

$$\boldsymbol{L} = \boldsymbol{r} \times \boldsymbol{p} = \boldsymbol{r} \times m\boldsymbol{v}$$

大小为 $L = mvr\sin\theta$，其中 $\theta$ 是 $\boldsymbol{r}$ 与 $\boldsymbol{v}$ 的夹角；方向由右手螺旋定则给出。<span class="marginnote">角动量与动量一样是矢量，但它依赖参考点的选择——同一个质点，相对不同参考点的角动量不同。选参考点时要先想清楚：是相对哪一点。</span>

对做定轴转动的刚体，刚体上各质点的角动量之和可简化为：

$$L = J\omega$$

这是转动版的「$p = mv$」。角动量定理（转动版动量定理）：**合外力矩等于角动量的变化率**：

$$\boldsymbol{M} = \frac{\mathrm{d}\boldsymbol{L}}{\mathrm{d}t}$$

当 $J$ 恒定（刚体形状不变）时，由 $L = J\omega$ 立刻回到 $M = J\alpha$；但当 $J$ 可以变化（如运动员收手臂）时，角动量定理比 $M = J\alpha$ 更一般。

## 2 角动量守恒定律

若刚体（或系统）所受合外力矩为零，即 $\boldsymbol{M} = \mathbf{0}$，则：

$$\boldsymbol{L} = J\omega = \text{常量}$$

**角动量守恒定律（conservation of angular momentum）：系统所受合外力矩为零时，系统的总角动量保持不变。**

**重点：角动量守恒允许 $J$ 与 $\omega$ 互相补偿。** 这一点与动量守恒有本质区别——质量 $m$ 不会变，但转动惯量 $J$ 会因质量分布的改变而变化。$J$ 减小，$\omega$ 就增大，乘积 $J\omega$ 不变：

$$J_1\omega_1 = J_2\omega_2$$

花样滑冰运动员旋转时收回手臂（$J$ 减小），转速 $\omega$ 自动增大；展开手臂（$J$ 增大），转速变慢——不需要任何外力矩，这就是角动量守恒最直观的演示。<span class="marginnote">跳水运动员腾空后抱紧身体快速翻腾、落地前展开身体减速，也是同一原理。猫在下落中靠「扭动身体」调整姿态，本质上也是在利用角动量守恒（全身角动量为零，身体各部分反向转动）。</span>

## 3 角动量守恒的典型应用

### 开普勒第二定律与行星运动

行星绕太阳运动，引力是**有心力**（方向总指向太阳），对太阳的力矩恒为零，因此行星对太阳的角动量守恒。角动量守恒等价于**掠面速度恒定**——行星与太阳的连线在相等时间内扫过相等的面积，这正是开普勒第二定律。<span class="marginnote">角动量守恒把开普勒第二定律从「经验规律」提升为「牛顿力学 + 角动量守恒的必然结论」；也解释了行星近日点快、远日点慢——距太阳近时 $r$ 小，速度 $v$ 必须大才能保持 $L = mvr$ 不变。</span>

### 陀螺的定向

快速旋转的陀螺（如陀螺仪）角动量很大，外界的微小干扰力矩难以在短时间内改变它，因此**自转轴在空间中保持方向稳定**。这是惯性导航系统的原理基础：卫星、飞机、潜艇都用高速旋转的陀螺仪来感知姿态。

### 地球自转与质量的重新分布

地球是自转角动量巨大的系统。当发生大规模质量迁移（如地震改变质量分布）时，地球自转轴或自转速度会有微小的变化——这正是地球自转速度「±毫秒级」波动的部分原因。

## 4 公式解析：从角动量定理到开普勒第二定律

证明「角动量守恒 $\Rightarrow$ 掠面速度恒定」。设行星位矢 $\boldsymbol{r}$、速度 $\boldsymbol{v}$，在 $\mathrm{d}t$ 内扫过的面积为 $dA$：

$$
\frac{\mathrm{d}A}{\mathrm{d}t} = \frac{1}{2}\lvert\boldsymbol{r}\times\boldsymbol{v}\rvert = \frac{L}{2m}
$$

- **第一步，写掠面元**：$\mathrm{d}t$ 内行星位移 $\boldsymbol{v}\,\mathrm{d}t$，扫过的三角形面积 $\mathrm{d}A = \frac{1}{2}\lvert\boldsymbol{r}\times\boldsymbol{v}\,\mathrm{d}t\rvert$。
- **第二步，引入角动量**：$L = \lvert\boldsymbol{r}\times m\boldsymbol{v}\rvert$，故 $\frac{\mathrm{d}A}{\mathrm{d}t} = \frac{L}{2m}$。
- **第三步，用守恒**：有心力对太阳的力矩为零，$L$ 守恒。
- **第四步，结论**：$\frac{\mathrm{d}A}{\mathrm{d}t}$ 为常量，即掠面速度恒定。

整个证明的关键步骤是**把「面积扫过」翻译成「叉积」，再把「叉积」翻译成「角动量」**——几何事实与力学守恒律由此接通。

## 5 角动量与动量的对照

| 比较项 | 动量 | 角动量 |
| --- | --- | --- |
| 定义 | $\boldsymbol{p} = m\boldsymbol{v}$ | $\boldsymbol{L} = \boldsymbol{r}\times\boldsymbol{p}$ |
| 守恒条件 | 合外力为零 | 合外力矩为零 |
| 与参考点关系 | 无关 | 依赖参考点 |
| 转动惯量角色 | 质量恒定 | $J$ 可变，$\omega$ 可补偿 |
| 微观意义 | — | 量子化：$\hbar$ 的整数倍 |

**辨析｜易错点：**「外力为零」与「外力矩为零」是不同条件。外力为零必然外力矩为零（合力为零则对任何点的力矩和为零），但外力矩为零不要求外力为零——**有心力**就是最好的例子：引力不为零，但对力心力矩为零。所以在行星问题里，动量不守恒（力不为零），角动量却守恒（力矩为零）。

## 6 小结

- **角动量**：$\boldsymbol{L} = \boldsymbol{r}\times\boldsymbol{p}$，定轴转动简化为 $L = J\omega$；依赖参考点。
- **角动量定理**：$\boldsymbol{M} = \dfrac{\mathrm{d}\boldsymbol{L}}{\mathrm{d}t}$。
- **角动量守恒**：合外力矩为零时 $J\omega = \text{常量}$；$J$ 与 $\omega$ 可互补，是转动问题独有的「动态」守恒。
- 应用：开普勒第二定律（掠面速度恒定）、花样滑冰/跳水、陀螺定向、地球自转。
- 角动量在微观世界量子化，是第十八章「轨道角动量量子数」的伏笔。
