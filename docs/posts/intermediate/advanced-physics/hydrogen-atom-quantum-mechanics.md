## 为什么从氢原子的量子描述开始

玻尔模型（第 99 节）用「轨道」描述了氢原子，但它无法解释更复杂的原子与光谱细节。量子力学用**薛定谔方程**求解氢原子——结果给出三个量子数（$n$、$l$、$m$）刻画的定态波函数，能级 $E_n = -13.6/n^2$ eV 与玻尔一致，但「轨道」被「电子云」取代。这一节概述氢原子的量子力学求解：从库仑势出发的薛定谔方程、三个量子数的物理意义、电子云与轨道角动量。它是理解元素周期表与化学键的基础。

## 1 氢原子的薛定谔方程

氢原子：电子在库仑势中运动：

$$V(r) = -\frac{e^2}{4\pi\varepsilon_0 r}$$

三维定态薛定谔方程在**球坐标**中求解（$V$ 是球对称的）。用分离变量 $\psi(r, \theta, \phi) = R(r)\Theta(\theta)\Phi(\phi)$，方程自然分解为径向与角度两部分。

**重点：氢原子的求解在球坐标中进行——球对称势能导致波函数分解为径向 $R(r)$ 与角度（$\Theta\Phi$）部分。** 分离变量 + 三个量子数（对应三个自由度 $r, \theta, \phi$）是三维束缚问题的标准结构。

## 2 三个量子数

氢原子定态由三个量子数刻画：

- **主量子数 $n$**：$n = 1, 2, 3, \dots$，决定能量 $E_n = -\frac{13.6\ \text{eV}}{n^2}$；
- **角量子数 $l$**：$l = 0, 1, \dots, n-1$，决定轨道角动量大小 $L = \sqrt{l(l+1)}\hbar$（对应 s、p、d、f 轨道）；
- **磁量子数 $m_l$**：$m_l = -l, -l+1, \dots, l$，决定角动量方向的 $z$ 分量 $L_z = m_l\hbar$。

**重点：氢原子由三个量子数 $(n, l, m_l)$ 刻画——$n$ 定能量、$l$ 定角动量大小、$m_l$ 定角动量方向。** 角动量 $L = \sqrt{l(l+1)}\hbar$ 不是 $l\hbar$（玻尔的 $n\hbar$ 也是近似），方向由 $m_l$ 量子化。$n$ 相同时 $l$ 取 $0$ 到 $n-1$，所以能级简并（同一能量多个状态）。<span class="marginnote">「角动量量子化」的图像：轨道角动量只能取 $L = \sqrt{l(l+1)}\hbar$，方向（$z$ 分量）只能取 $m_l\hbar$——角动量矢量像「倾斜的陀螺」，方向被量子化但可以「进动」。s 轨道（$l = 0$）角动量为零（不是玻尔的圆周运动），p（$l = 1$）、d（$l = 2$）轨道各有角动量。这套量子数在第二十三章（角动量算符）会严格推导。</span>

## 3 电子云与概率密度

波函数 $\psi_{nlm}$ 的模方 $|\psi|^2$ 给出电子的概率密度分布——**电子云（electron cloud）**。

**基态**（$1s$，$n=1,l=0$）：球对称，概率密度在核附近最大，随距离指数衰减；
**s 轨道**（$l=0$）：球对称，无角动量；
**p 轨道**（$l=1$）：哑铃状（沿某轴分布）；
**径向概率**：电子距核 $r$ 处球壳内的概率 $P(r)\mathrm{d}r = 4\pi r^2|R|^2\mathrm{d}r$，峰值在玻尔半径附近。

**重点：电子云是「概率分布」不是「轨道」——电子在原子内各处的概率由 $|\psi|^2$ 描述。** 基态电子的最概然半径恰为玻尔半径 $r_1 = 0.053$ nm（与玻尔模型巧合），但电子不是「在轨道上转」，而是「以概率弥漫」。这个「云」的图像是量子力学对原子的根本改造。<span class="marginnote">「最概然半径 = 玻尔半径」的巧合让量子力学与玻尔模型在数值上一致（能量、半径量级），但物理图像完全不同：玻尔说「电子沿轨道转」，量子力学说「电子概率在 $r_1$ 附近最大」。实验（如电子散射、STM）验证的是「云」的图像。化学键（共价键）正是两个原子电子云重叠的结果。</span>

## 4 公式解析：氢原子能级与简并

$n = 2$ 时氢原子有多少个状态？能量是多少？

$$
E_2 = -\frac{13.6}{2^2} = -3.4\ \text{eV}, \qquad \text{状态数} = \sum_{l=0}^{n-1}(2l+1) = 1 + 3 = 4
$$

- **第一步，算能量**：$E_2 = -13.6/4 = -3.4$ eV——第一激发态。
- **第二步，数状态**：$n = 2$，$l$ 可取 0（1 个 $m$：$m_l = 0$）与 1（3 个 $m$：$m_l = -1, 0, 1$），共 $1 + 3 = 4$ 个状态。
- **第三步，解读简并**：4 个状态能量相同（都是 $-3.4$ eV）——能级简并度为 4。一般地，$n$ 能级的简并度 $= n^2$。
- **第四步，扩展**：加上自旋（下节），每个状态又有 2 个自旋方向——$n$ 能级总状态数为 $2n^2$。

**辨析｜易错点：**三个量子数的取值规则别记错：$l = 0, 1, \dots, n-1$；$m_l = -l, \dots, l$（共 $2l+1$ 个）。$n$ 能级简并度 $n^2$（含角动量方向）；加上自旋后 $2n^2$。光谱记号：$l = 0, 1, 2, 3$ 对应 s、p、d、f（来历：光谱的 sharp、principal、diffuse、fundamental）。

## 5 氢原子量子描述的成就

- **能级与光谱**：精确给出 $E_n = -13.6/n^2$ eV 与里德伯公式（与实验一致）；
- **轨道角动量**：$L = \sqrt{l(l+1)}\hbar$ 解释光谱的精细结构（配合自旋）；
- **电子云**：为化学键、原子半径、元素周期表提供量子基础；
- **辐射跃迁选择定则**：$\Delta l = \pm1$（角动量守恒要求）——解释哪些跃迁「允许」；
- **与玻尔模型对照**：能量、半径数值一致，但「轨道」被「概率云」取代。

**重点：量子力学对氢原子的描述——能级与玻尔一致，但波函数给出电子云、量子数与选择定则，能解释玻尔无法解释的光谱细节。** 氢原子是唯一能精确求解的多体问题（两个质点），多电子原子需近似方法（哈特里-福克等）——但氢原子确立的量子数语言（$n, l, m$）沿用至今，是元素周期表的骨架。<span class="marginnote">「氢原子是量子力学的试金石」：薛定谔方程对氢原子的精确解验证了整套量子力学。多电子原子的能级结构虽需近似，但都是「氢原子的量子数 + 电子相互作用修正」。从氢原子出发，元素周期表、化学键、光谱学、乃至整个化学与材料科学都有了量子基础。</span>

## 6 数值算例：氢原子的跃迁与光谱线

氢原子从 $n = 3$ 跃迁到 $n = 2$，求放出光子的能量、频率与波长。

$$

\Delta E = E_3 - E_2 = -1.51 - (-3.40) = 1.89\ \mathrm{eV}, \qquad \lambda = \frac{hc}{\Delta E} = \frac{1240\ \mathrm{eV·nm}}{1.89\ \mathrm{eV}} \approx 656\ \mathrm{nm}

$$

- **第一步，写能级**：$E_3 = -13.6/9 \approx -1.51$ eV，$E_2 = -3.40$ eV。
- **第二步，算跃迁能**：$\Delta E = E_3 - E_2 = 1.89$ eV。
- **第三步，算波长**：$hc \approx 1240\ \mathrm{eV·nm}$，$\lambda \approx 656$ nm——红色光，这正是氢原子巴耳末系 Hα 线。
- **第四步，解读**：656 nm 的红色谱线是天文观测中氢的「指纹」——银河系中红色发射区、太阳光谱中的吸收线，都来自这个跃迁。能级差决定光子能量，这是光谱学的基本原理。<span class="marginnote">里德伯公式 $1/\lambda = R(1/n_1^2 - 1/n_2^2)$ 与量子力学的能级公式完全等价：量子力学给出的 $E_n = -13.6/n^2$ eV 已蕴含里德伯常数 $R \approx 1.097\times10^7\ \mathrm{m^{-1}}$。量子力学与十九世纪光谱学经验的吻合，是它被接受的关键证据。</span>

## 7 径向分布与角分布：电子云的立体图像

电子云不仅要看「离核多远」，还要看「朝哪个方向」。把概率密度分解为径向与角度两部分：

$$

P(r)\,\mathrm{d}r \propto 4\pi r^2 |R_{nl}(r)|^2\,\mathrm{d}r, \qquad \text{角度部分由} |Y_{lm}(\theta,\phi)|^2 \text{决定}

$$

- **第一步，读径向分布**：$4\pi r^2|R|^2$ 是「半径 $r$ 处球壳内的概率」——基态 $1s$ 的峰值在玻尔半径处，但平均半径（期望值）是 $1.5$ 倍玻尔半径。
- **第二步，读角分布**：s 轨道（$l=0$）各向同性；p 轨道（$l=1$）沿 $z$ 轴呈哑铃形；d 轨道（$l=2$）有四叶草形等复杂分布。
- **第三步，体会**：「电子云」是立体的概率密度，不是平面图。化学键的方向性（sp³、sp²、sp 杂化）正源于角分布——这是量子力学对化学的馈赠。<span class="marginnote">「径向期望值」与「最概然半径」不同：$1s$ 的最概然半径是 $r_1$（概率密度最大处），而平均半径 $\langle r\rangle = 1.5r_1$——因为概率分布在 $r_1$ 之外还有长尾。做「电子离核多远」的题要先分清问的是哪个量。</span>

氢原子是量子力学唯一能精确求解的真实系统：三个量子数、电子云、能级与光谱，把「波函数」从数学工具变成对原子的定量描述。它确立的语言（$n,l,m$ 与自旋）支撑起整个元素周期表与化学。下一节我们研究电子的内禀角动量——**电子自旋与原子的壳层结构**。

## 9 小结

- **氢原子薛定谔方程**：球坐标求解库仑势，波函数 $\psi = R(r)\Theta(\theta)\Phi(\phi)$。
- **三个量子数**：$n$（能量）、$l$（角动量大小 $L = \sqrt{l(l+1)}\hbar$）、$m_l$（方向 $L_z = m_l\hbar$）。
- **能级**：$E_n = -13.6/n^2$ eV，$n$ 能级简并度 $n^2$（加自旋 $2n^2$）。
- **电子云**：$|\psi|^2$ 概率分布；s 球对称、p 哑铃；最概然半径 = 玻尔半径。
- 轨道角动量量子化、选择定则（$\Delta l = \pm1$）——解释光谱细节。
- 氢原子是量子力学的精确解与化学周期律的量子基础。
