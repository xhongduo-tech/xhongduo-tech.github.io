## 为什么从受力分析开始

上一节我们把重力、弹力、摩擦力三种「力」认了个全。但认得清，不等于用得好。现实问题里，一个物体往往同时受好几个力：放在斜面上的木块，受重力、斜面支持力、摩擦力，可能还有绳子拉力、外力推它。**牛顿第二定律 $\vec{F} = m\vec{a}$ 是一句很短的式子，难的是左边的 $\vec{F}$ 怎么取**——把哪个物体隔离出来、画全它受的每一个力、再正确地分解到坐标轴上。

受力分析（free-body diagram，简称 FBD）就是把「物理图景」翻译成「数学方程」的翻译机。这一节我们把这台机器完整拆开：从方法论到三步流水线，再到斜面、超重失重、连接体三个必考战场。学完这一节，你才真正「会」用牛顿定律，而不是「知道」牛顿定律。<span class="marginnote">受力分析是全力学的地基：动量的冲量、能量的功、刚体的力矩、流体的压力，全部建立在「先画清受力」之上。这里偷的懒，后面每个章节都会加倍偿还。</span>

## 1 受力分析：隔离法的三条纪律

**隔离法（isolation method）**：把研究对象从周围的物体中「孤立」出来，只画外界对它施加的力，不画它对外界施加的力。

**受力分析三条纪律：**

- **只画「别人给我的力」**。牛顿第三定律告诉我们力的作用是相互的，但受力图里只能出现「作用在研究对象上」的力。你推箱子，箱子的受力图里有你的推力，你手的受力图里才有箱子的反推力——不能把反作用力画到同一个图上。
- **按「重力 → 接触力」的顺序查漏**。先画重力（一定有），再找所有与它接触的物体，逐个判断弹力与摩擦力是否存在。这个顺序保证不遗漏。
- **不凭空创造力，也不凭感觉删力**。每个力必须有「施力物体」。没有施力物体的力，一定是画错了。<span class="marginnote">「没有施力物体的力」是受力分析里最常见的错误来源。离心力、惯性力都出现在非惯性系中，处理地面参考系问题时要坚决排除——这正是下一节《非惯性系与惯性力》的内容。</span>

## 2 牛顿定律应用的「三步流水线」

**第一步：选对象，做隔离。** 把研究对象看成一个质点，必要时把多个物体分别隔离（连接体问题）。

**第二步：画受力图，建坐标系。** 画出全部外力，建立合适的坐标系。原则是**让尽可能多的力落在坐标轴上**——斜面上沿斜面建轴，竖直问题竖直建轴。

**第三步：列方程。** 对每个坐标轴写出牛顿第二定律的分量式：

$$\sum F_x = m a_x, \qquad \sum F_y = m a_y$$

再加上运动学关系（如绳不可伸长、连接体加速度相同）联立求解。<span class="marginnote">注意 $a$ 的方向通常事先未知，可以先假设一个正方向；若解出 $a < 0$，说明实际加速度与假设方向相反，修正方向即可，不必推翻重做。</span>

## 3 斜面：动力学的第一个标准战场

质量为 $m$ 的木块沿倾角 $\theta$ 的粗糙斜面下滑，受三个力：重力 $mg$ 竖直向下、支持力 $N$ 垂直于斜面、滑动摩擦力 $f_k$ 沿斜面向上。

**建轴**：$x$ 轴沿斜面向下，$y$ 轴垂直斜面向上。重力需要分解：

- $x$ 轴分量：$mg\sin\theta$（沿斜面下滑方向）
- $y$ 轴分量：$mg\cos\theta$（垂直于斜面向下）

**列方程**：

$$N - mg\cos\theta = 0 \quad\Rightarrow\quad N = mg\cos\theta$$

$$mg\sin\theta - f_k = ma \quad\Rightarrow\quad mg\sin\theta - \mu_k mg\cos\theta = ma$$

$$a = g(\sin\theta - \mu_k \cos\theta)$$

三个结论值得记住：

- 若 $\mu_k = 0$（光滑），$a = g\sin\theta$——只与倾角有关，与质量无关。伽利略的斜面实验正是靠这一点「消去质量」研究自由落体。
- 若 $\tan\theta > \mu_k$，$a > 0$，物体加速下滑。
- 若 $\tan\theta = \mu_k$，$a = 0$，物体匀速下滑。<span class="marginnote">临界条件 $\tan\theta = \mu$ 是「刚好匀速 / 刚好要动」的分界，这类「临界问题」在传送带、板块模型里反复出现，本质都是受力恰好平衡。</span>

## 4 超重与失重：电梯里的「体重变化」

人在竖直电梯里，人受两个力：重力 $mg$ 向下、地板支持力 $N$ 向上。取向上为正：

$$N - mg = ma \quad\Rightarrow\quad N = m(g + a)$$

**$N$ 是人对地板的压力的反作用力的反力**，而体重秤显示的就是这个压力 $N$。于是：

- **加速上升 / 减速下降**（$a > 0$）：$N > mg$，视重 > 实重，**超重**。
- **加速下降 / 减速上升**（$a < 0$）：$N < mg$，视重 < 实重，**失重**。
- **自由下落**（$a = -g$）：$N = 0$，完全失重，秤读数为零。

**辨析｜易错点：** 超重失重看的是**加速度方向**，不是速度方向。电梯加速上升和减速下降，速度方向相反，但加速度都向上，都是超重。失重不等于失去重力——人受到的重力始终是 $mg$，变的只是支持力 $N$。完全失重时人依然受重力，只是「感觉不到」。

## 5 连接体：多物体的隔离与整体

两个物体用轻绳相连、在光滑水平面上被力 $F$ 拉动。这类问题有两把钥匙：

- **整体法**：把两个物体看成整体，内力（绳的张力）互消，直接求整体加速度 $a = F/(m_1 + m_2)$。
- **隔离法**：把其中一个物体隔离，求出它受的合力，进而求内力（绳的张力）。

**核心要义：先用整体求加速度，再用隔离求内力。** 内力是「切不开的绳子」，只有隔离才能看见。<span class="marginnote">整体法成立的依据是牛顿第三定律：内力总是成对出现、大小相等方向相反，对整体求合力时自动抵消。这是「系统」思想的第一次登场，到《动量守恒》一章它会被推到极致——内力无法改变系统总动量。</span>

## 6 公式解析：$N = mg\cos\theta$ 里的量纲与极限

我们拆解斜面问题的关键式子 $N = mg\cos\theta$。

**第一步，量纲检查**：

$$[N] = [m][g] = \mathrm{M} \cdot \mathrm{L \cdot T^{-2}} = \mathrm{M \cdot L \cdot T^{-2}}$$

与力的量纲一致，正确。注意 $\cos\theta$ 无量纲，它只改变力沿方向的分量大小，不改变力的量纲。

**第二步，极限检验（这是比量纲更强的检查）**。令 $\theta = 0$（水平面）：

$$N = mg\cos 0 = mg$$

回到「水平面上支持力等于重力」的常识，正确。令 $\theta = 90°$（竖直墙）：

$$N = mg\cos 90° = 0$$

物体「贴」在竖直墙上时，墙给它的支持力为零——重力方向与墙面平行，墙面无法提供竖直方向的支持，直觉吻合。**一个公式若在极端情形下给出的答案违背常识，那它一定写错了。**

**第三步，$mg\cos\theta$ 的几何含义**。重力分解时，沿 $y$ 轴的分量是 $mg$ 乘以「$mg$ 与 $y$ 轴夹角的余弦」。建轴不同，同一个力的分量表达式就不同，但分解出的力矢量之和恒等于原力——这是矢量分解的平行四边形法则在保证。<span class="marginnote">矢量分解的正确性，最终要落到《线性代数》里「一个矢量在正交基下的坐标」：斜面的两个正交轴就是一组基，$mg\sin\theta$、$mg\cos\theta$ 正是重力在这组基下的坐标。</span>

## 7 小结

- **受力分析**用隔离法：只画外界对研究对象的作用力，按「重力 → 接触力」查漏。
- **三步流水线**：选对象隔离 → 画力图建系 → 列分量方程联立。
- 斜面上 $N = mg\cos\theta$，$a = g(\sin\theta - \mu_k\cos\theta)$；临界条件 $\tan\theta = \mu$。
- **超重失重看加速度方向**而非速度方向；完全失重时仍受重力，只是 $N = 0$。
- **连接体**：整体法求加速度，隔离法求内力。

在下一节，我们将走出地面参考系，进入一个「牛顿定律不再成立」的世界——**非惯性系与惯性力**。
