## 为什么从微扰理论开始

氢原子能精确求解，但真实系统几乎都有「额外的小扰动」：外电场、外磁场、电子间相互作用、相对论修正……**定态微扰理论（stationary perturbation theory）**处理「哈密顿量 $H = H_0 + H'$，其中 $H_0$ 可精确求解、$H'$（微扰）很小」的问题：把能量与波函数按微扰强度展开，逐级修正。它是量子力学最常用的近似工具——氢原子的精细结构（相对论修正 + 自旋轨道耦合）、塞曼效应（外磁场）、斯塔克效应（外电场）、氦原子近似解都靠它。这一节推导非简并定态微扰，简介简并微扰。

## 1 定态微扰的基本设定

**定态微扰**：哈密顿量分解为可解部分 + 小扰动：

$$\hat{H} = \hat{H}_0 + \hat{H}'$$

其中 $\hat{H}_0$ 的本征问题已知：$\hat{H}_0|n^{(0)}\rangle = E_n^{(0)}|n^{(0)}\rangle$；$\hat{H}'$ 是「小」扰动（$H'$ 的矩阵元远小于能级间隔）。

**微扰展开**：把能量与态按小参数 $\lambda$ 展开：

$$E_n = E_n^{(0)} + E_n^{(1)} + E_n^{(2)} + \cdots, \qquad |n\rangle = |n^{(0)}\rangle + |n^{(1)}\rangle + \cdots$$

**重点：定态微扰——把能量与态按微扰强度展开，$E_n^{(0)}$ 是零级、$E_n^{(1)}$ 是一级修正……** 微扰越小、级数收敛越快。计算目标通常是「一级能量修正」与「二级能量修正」、一级态修正。

## 2 非简并微扰的能量修正

**一级能量修正**：微扰在零级态上的期望值：

$$E_n^{(1)} = \langle n^{(0)}|\hat{H}'|n^{(0)}\rangle$$

**二级能量修正**：

$$E_n^{(2)} = \sum_{m \neq n}\frac{|\langle m^{(0)}|\hat{H}'|n^{(0)}\rangle|^2}{E_n^{(0)} - E_m^{(0)}}$$

**一级态修正**：

$$|n^{(1)}\rangle = \sum_{m\neq n}\frac{\langle m^{(0)}|\hat{H}'|n^{(0)}\rangle}{E_n^{(0)} - E_m^{(0)}}|m^{(0)}\rangle$$

**重点：一级能量修正 = 微扰的期望值；二级能量修正 = 微扰矩阵元的平方除以能级差。** 一级修正直接、常用（能级移动）；二级修正总是降低基态能量（分母为负）。态修正把微扰「混合」进其他零级态。

## 3 公式解析：一维谐振子的一级微扰

一维谐振子（$\hat{H}_0 = \frac{\hat{p}^2}{2m} + \frac{1}{2}m\omega^2x^2$）加微扰 $\hat{H}' = \lambda x^4$。求基态能量的一级修正。

$$
E_0^{(1)} = \langle 0|\lambda x^4|0\rangle = \lambda\langle 0|x^4|0\rangle
$$

- **第一步，写一级修正**：$E_0^{(1)} = \langle 0|\hat{H}'|0\rangle = \lambda\langle 0|x^4|0\rangle$。
- **第二步，用升降算符**：$x = \sqrt{\frac{\hbar}{2m\omega}}(\hat{a} + \hat{a}^\dagger)$。$x^4$ 展开后，只有「升降各两次」的项对 $\langle 0|\cdots|0\rangle$ 有贡献（其他项给零）。
- **第三步，算期望值**：$\langle 0|x^4|0\rangle = \left(\frac{\hbar}{2m\omega}\right)^2[(\sqrt{2})^2 + 1\cdot...] = \frac{3\hbar^2}{4m^2\omega^2}$（含 $\langle 0|\hat{a}^2\hat{a}^{\dagger 2}|0\rangle = 2$、$\langle 0|\hat{a}\hat{a}\hat{a}^\dagger\hat{a}^\dagger|0\rangle = 1$ 等贡献）。
- **第四步，结果**：$E_0^{(1)} = \frac{3\lambda\hbar^2}{4m^2\omega^2}$——正的一级修正（$x^4$ 微扰抬高能量）。

**辨析｜易错点：**一级修正只要求「微扰的期望值」（对角元）；若对角元为零，需看二级修正。二级修正分母是「能级差」——简并时（$E_n^{(0)} = E_m^{(0)}$）分母为零、公式失效，需用简并微扰。矩阵元 $\langle m|H'|n\rangle$ 的计算是微扰的核心工作（常借助升降算符、对称性简化）。

## 4 简并微扰

若零级能级简并，非简并微扰公式失效（分母为零）。**简并微扰**：在简并子空间内对角化微扰：

- 把 $H'$ 在简并子空间（$E_n^{(0)}$ 对应的 $f$ 个简并态）中写成矩阵；
- 对角化该矩阵，本征值 = 一级能量修正（分裂）；
- 本征矢 = 正确的零级态（「好量子态」）。

**重点：简并微扰——在简并子空间内对角化微扰矩阵，得到能级分裂与正确的零级态。** 微扰「打破简并」：原本能量相同的简并态在微扰下分裂。选择正确的零级基（使 $H'$ 对角化）是简并微扰的关键——这通常由对称性确定（如外磁场下选 $|nlm\rangle$，$H'$ 对角）。<span class="marginnote">「简并微扰的物理」：外磁场（塞曼效应）使氢原子 $m$ 简并的能级分裂成 $2l+1$ 条；外电场（斯塔克效应）使 $l$ 简并部分解除。微扰「选择」了正确的零级态——微扰与简并态的耦合方式决定了分裂图样。简并微扰的矩阵对角化是「对称性破缺」的量子版本。</span>

## 5 定态微扰的应用

- **塞曼效应**：外磁场 $H' = -\boldsymbol{\mu}\cdot\boldsymbol{B}$——能级分裂（正常/反常塞曼，含自旋）；
- **斯塔克效应**：外电场 $H' = -eEz$——能级移动与分裂；
- **氢原子精细结构**：相对论动能修正 + 自旋-轨道耦合（微扰）——能级分裂成精细结构；
- **氦原子**：电子-电子库仑排斥作为微扰（零级：两个独立类氢轨道）；
- **原子与分子物理**：外场、内相互作用的标准处理。

**重点：定态微扰是量子力学的「万用近似」——外场效应、相对论修正、粒子间相互作用都作为微扰处理。** 氢原子精细结构、塞曼/斯塔克效应、氦原子……真实系统的「小偏离」都用微扰计算。微扰理论把「解不出来的问题」变成「可解问题的系统修正」。<span class="marginnote">「微扰 vs 变分」：微扰要求「小偏离」与「已知零级解」；变分法（另类近似）不要求小偏离，用试探波函数优化。两者互补——微扰处理「小扰动」、变分处理「一般近似」。量子化学、固体物理大量依赖这两种近似方法。</span>

## 6 小结

- **定态微扰**：$\hat{H} = \hat{H}_0 + \hat{H}'$，能量/态按微扰展开。
- **一级能量修正**：$E_n^{(1)} = \langle n^{(0)}|H'|n^{(0)}\rangle$（期望值）。
- **二级能量修正**：$E_n^{(2)} = \sum_{m\neq n}\frac{|\langle m|H'|n\rangle|^2}{E_n^{(0)}-E_m^{(0)}}$。
- **简并微扰**：在简并子空间对角化 $H'$——能级分裂、选好零级态。
- 应用：塞曼/斯塔克效应、氢原子精细结构、氦原子、外场效应。
