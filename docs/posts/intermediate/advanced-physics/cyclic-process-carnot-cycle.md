## 为什么从循环过程开始

任何实际的动力装置——蒸汽机、内燃机、燃气轮机——都不能只做「一次性」膨胀，它们必须**循环**：工作物质回到初始状态，才能周而复始地对外做功。循环过程是热力学第一定律最丰富的应用场，而其中最重要的是**卡诺循环（Carnot cycle）**：它由两个等温、两个绝热过程组成，给出了热机效率的**理论上限**。卡诺的研究（1824 年）在热力学第一定律确立之前就完成了，其深邃之处在于：它不问「能做多少功」，而问「效率最多能有多高」——这个问题最终引出热力学第二定律。

## 1 循环过程与热机效率

**循环过程（cyclic process）**：系统经历一系列状态变化后回到初始状态的过程。循环一周，状态量复原：

$$\Delta U = 0, \qquad Q_{\text{net}} = W_{\text{net}}$$

在 $p$–$V$ 图上，循环围成闭合曲线，**曲线面积 = 净功**。

- **热机（顺时针循环）**：从高温热源吸热 $Q_1$，向低温热源放热 $Q_2$，对外做功 $W = Q_1 - Q_2$（注意 $Q_2$ 取绝对值）。
- **制冷机（逆时针循环）**：消耗外界功，从低温热源吸热 $Q_2$，向高温热源放热 $Q_1 = Q_2 + W$。

**热机效率（efficiency）**：输出的有用功与吸入热量之比：

$$\eta = \frac{W}{Q_1} = \frac{Q_1 - Q_2}{Q_1} = 1 - \frac{Q_2}{Q_1}$$

**制冷系数（coefficient of performance）**：$e = \frac{Q_2}{W} = \frac{Q_2}{Q_1 - Q_2}$。

<span class="marginnote">「效率」问的是「吸进来的热有多少变成了功」；它永远小于 1（因为 $Q_2 > 0$ 不可避免）。制冷系数可以大于 1——搬运热比做功更「划算」，冰箱移走的热量可以数倍于耗电。</span>

## 2 卡诺循环

**卡诺循环（Carnot cycle）**：由两个等温过程与两个绝热过程组成的理想循环：

1. **等温膨胀**（$T_1$）：从高温热源吸热 $Q_1$，对外做功；
2. **绝热膨胀**：温度降到 $T_2$，内能减少；
3. **等温压缩**（$T_2$）：向低温热源放热 $Q_2$；
4. **绝热压缩**：温度升回 $T_1$，回到初始状态。

在 $p$–$V$ 图上，卡诺循环由两条等温线与两条绝热线围成。<span class="marginnote">卡诺循环的可逆性：四个过程都是准静态 + 无耗散，因此整个循环可逆——正转是热机，反转是制冷机，效率相同。卡诺正是用「可逆」这把钥匙锁定了效率上限。</span>

## 3 卡诺热机效率

对卡诺循环，等温吸热与放热：

$$Q_1 = \nu RT_1\ln\frac{V_2}{V_1}, \qquad Q_2 = \nu RT_2\ln\frac{V_3}{V_4}$$

由两条绝热线的关系 $T_1V_2^{\gamma-1} = T_2V_3^{\gamma-1}$ 与 $T_1V_1^{\gamma-1} = T_2V_4^{\gamma-1}$ 可推出 $V_2/V_1 = V_3/V_4$，于是：

$$\eta_C = 1 - \frac{Q_2}{Q_1} = 1 - \frac{T_2}{T_1}$$

**卡诺定理（Carnot's theorem）**：工作在两个恒定热源之间的热机，效率不超过卡诺机效率；**卡诺机（可逆机）效率只由两热源温度决定**：

$$\eta_C = 1 - \frac{T_2}{T_1}$$

<span class="marginnote">「效率只由温度比决定」是卡诺定理最惊人的结论：不管你用什么工作物质（理想气体、蒸汽、空气），只要热源温度是 $T_1$、$T_2$，可逆热机的效率就是 $1 - T_2/T_1$。提高效率只有两条路：提高高温热源温度、降低低温热源温度。</span>

**重点：卡诺效率是理想极限，实际热机都达不到。** 例如：$T_1 = 600$ K、$T_2 = 300$ K 的卡诺效率 $\eta_C = 0.5$，实际内燃机效率通常 30–40%。原因是不可逆因素（摩擦、有限温差传热、非准静态）。

## 4 公式解析：卡诺热机计算

一卡诺热机工作于 $T_1 = 500$ K 与 $T_2 = 300$ K 之间，每循环从高温热源吸热 $Q_1 = 1000$ J，求效率、对外做的功与向低温热源放的热。

$$
\eta_C = 1 - \frac{T_2}{T_1} = 1 - \frac{300}{500} = 0.40
$$

- **第一步，求效率**：$\eta_C = 1 - 300/500 = 0.40 = 40\%$。
- **第二步，求功**：$W = \eta_C Q_1 = 0.40\times1000 = 400\ \text{J}$。
- **第三步，求放热**：$Q_2 = Q_1 - W = 1000 - 400 = 600\ \text{J}$。
- **第四步，校验**：$Q_2/Q_1 = 600/1000 = 0.6 = T_2/T_1$，与卡诺循环关系一致——放热与吸热之比等于低温与高温之比。

**辨析｜易错点：**卡诺效率公式里的温度**必须用热力学温标（K）**，不能用摄氏温度。若把 500 K 写成 227℃、300 K 写成 27℃，直接相除会得到 $1 - 27/227 \approx 0.88$——错误的答案。效率 $1 - T_2/T_1$ 依赖的是温度**比**，只有绝对温标下比值才有物理意义。

## 5 制冷机与卡诺逆循环

卡诺循环反向运行就是**卡诺制冷机**：从低温热源吸热 $Q_2$，消耗功 $W$，向高温热源放热 $Q_1 = Q_2 + W$。其**制冷系数**：

$$e_C = \frac{Q_2}{W} = \frac{T_2}{T_1 - T_2}$$

- 两热源温差越小，制冷系数越大（越「省电」）；
- 冰箱内外的温差越大，搬热越费劲——这就是为什么冰箱门关严、环境温度低时更省电。<span class="marginnote">卡诺制冷机的效率上限同样由温度决定。空调、冰箱的实际性能用「能效比」衡量，越接近卡诺值越理想。家用空调制冷系数通常在 3–5 之间，意味着搬走的室内热量是耗电的 3–5 倍。</span>

## 6 小结

- **循环过程**：$\Delta U = 0$，$Q_{\text{net}} = W_{\text{net}}$；$p$–$V$ 图闭合面积 = 净功。
- 热机效率 $\eta = 1 - Q_2/Q_1$；制冷系数 $e = Q_2/W$。
- **卡诺循环**：两等温 + 两绝热；可逆循环。
- **卡诺效率**：$\eta_C = 1 - T_2/T_1$，只由两热源温度决定，是热机效率的理论上限。
- 卡诺制冷系数 $e_C = T_2/(T_1 - T_2)$；温度必须用热力学温标。
- 卡诺定理引出第二定律：效率上限的存在，暗示「热量不能完全转化为功」。
