# 氢原子光谱的规律与玻尔理论

<div class="epigraph">
<p>氢原子只发出几条确定波长的光——像一台只能弹出几个音的琴。玻尔用「轨道量子化」解释了这张谱，也把量子带进了原子。</p>

## 为什么从氢原子光谱开始

氢原子的发射光谱不是连续的，而是由若干条离散的谱线组成——氢原子只能发出特定波长的光。这个「离散性」是经典物理无法解释的（经典理论允许任意频率的辐射）。1913 年玻尔把普朗克/爱因斯坦的量子化思想用于原子结构，提出**玻尔理论**：电子只能在特定轨道上运动，轨道间跃迁发射/吸收光子。玻尔理论虽然被后来的量子力学取代，但它第一次正确给出氢原子能级与光谱，是量子原子论的里程碑。这一节推导氢原子光谱规律与玻尔模型。<span class="marginnote">学习玻尔理论的最好心态：把它当作「通往量子力学的脚手架」。它的结论（能级 $E_n = -13.6/n^2$ eV）被量子力学原样保留，但它的物理图像（电子沿轨道转圈）被彻底抛弃。看懂「哪些留下、哪些被推翻」，比记住模型本身更有价值。</span>

## 1 氢原子光谱的规律

氢原子光谱在可见光区有几条分立谱线（巴耳末系）。里德伯总结出**里德伯公式**：

$$\frac{1}{\lambda} = R_H\left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right), \qquad R_H = 1.097\times10^7\ \text{m}^{-1}$$

$n_1 = 1, 2, 3, \dots$（固定），$n_2 = n_1+1, n_1+2, \dots$。谱线系：

- **莱曼系**（$n_1 = 1$）：紫外区；
- **巴耳末系**（$n_1 = 2$）：可见光区；
- **帕邢系**（$n_1 = 3$）：红外区。

**重点：氢原子光谱由里德伯公式描述——谱线波长满足 $\frac{1}{\lambda} = R_H(\frac{1}{n_1^2}-\frac{1}{n_2^2})$，谱线分立而非连续。** 这个「离散谱」是量子化的直接证据——原子只能吸收/发射特定波长的光。<span class="marginnote">里德伯公式的美：一组合谱线可以用 $n_1$、$n_2$ 两个整数简洁描述。$n_1$ 固定给出一组谱线系（向同一终态跃迁），$n_2$ 变化给出系内各条线。光谱线的「整数规律」强烈暗示原子内部存在离散的能级——这是玻尔理论的实验基础。</span>

### 氢原子谱线系速记

| 谱线系 | $n_1$（终态） | 波区 | 例子 |
| --- | --- | --- | --- |
| 莱曼系 | 1 | 紫外 | $n_2 = 2$ → 121.6 nm |
| 巴耳末系 | 2 | 可见 | $n_2 = 3$ → 656 nm（Hα） |
| 帕邢系 | 3 | 红外 | $n_2 = 4$ → 1875 nm |
| 布喇开系 | 4 | 远红外 | $n_2 = 5$ |

越往高能（$n_2$ 越大）谱线越密，最终趋于连续极限（$n_2 \to \infty$）——对应电离阈值。这张表背下来，任何「判断谱线属于哪个系、落在哪个波段」的题都能秒答。

## 2 玻尔模型的基本假设

玻尔提出三个假设：

**假设一（定态假设）**：电子只能在某些特定的圆形轨道（定态）上运动，这些轨道上电子不辐射电磁波，原子处于稳定状态（定态）。定态的能量是离散的：$E_1, E_2, E_3, \dots$。

**假设二（频率条件）**：原子从一个定态跃迁到另一个定态时，发射或吸收一个光子，光子能量等于两定态能量之差：

$$h\nu = E_{n_2} - E_{n_1}$$

**假设三（角动量量子化）**：电子轨道角动量只能取 $\hbar$ 的整数倍：

$$L = mvr = n\hbar, \qquad \hbar = \frac{h}{2\pi}, \quad n = 1, 2, 3, \dots$$

**重点：玻尔的三假设——定态（不辐射）、频率条件（$h\nu = \Delta E$）、角动量量子化（$L = n\hbar$）——把量子化引入原子结构。** 前两条给出能级跃迁的图像，第三条给出轨道/能级的量子化条件。<span class="marginnote">「为什么电子在轨道上不辐射？」经典电磁学里加速运动的电荷会辐射，电子绕核运动是加速的，按经典物理会不断辐射、坠落原子核——原子瞬间坍缩。玻尔的定态假设「禁止」了这个坍缩，虽然物理上「为什么」要到量子力学（波函数、驻波条件）才说清。玻尔模型是「半经典半量子」的过渡理论。</span>

## 3 氢原子的能级

由角动量量子化 $mvr = n\hbar$ 与库仑力提供向心力 $\frac{e^2}{4\pi\varepsilon_0r^2} = \frac{mv^2}{r}$ 联立，可得：

**轨道半径**：$r_n = n^2r_1$，$r_1 = \frac{4\pi\varepsilon_0\hbar^2}{me^2} = 0.053\ \text{nm}$（玻尔半径）。

**能级**：

$$E_n = -\frac{13.6\ \text{eV}}{n^2}, \qquad n = 1, 2, 3, \dots$$

- $n = 1$ 基态：$E_1 = -13.6$ eV（最低能量，最稳定）；
- $n = 2, 3, \dots$ 激发态：$E_n = -13.6/n^2$ eV；
- $n \to \infty$：$E_\infty = 0$（电离阈值）。

**重点：氢原子能级 $E_n = -13.6\ \text{eV}/n^2$——负值表示束缚态，基态 $-13.6$ eV，能级间隔随 $n$ 增大而减小。** 电离能（把基态电子移走）为 13.6 eV。能级间距越到高能越密，趋于连续——对应经典极限。

能级间隔的规律可以量化：$\Delta E = E_{n+1}-E_n = 13.6\left(\frac{1}{n^2} - \frac{1}{(n+1)^2}\right)$ eV。$n=1\to2$ 间隔 10.2 eV（对应 121.6 nm 紫外），$n=2\to3$ 间隔 1.89 eV（对应 656 nm 红光），$n=5\to6$ 间隔仅约 0.17 eV。能级越高越密、相邻跃迁能量越小、波长越长——这就是谱线系「越靠里越密」的根源。把基态电子从 $n=1$ 直接电离到 $n=\infty$ 需要 13.6 eV，这正是氢的电离能实验值。

## 4 公式解析：氢原子谱线波长

计算氢原子巴耳末系（$n_1 = 2$）中 $n_2 = 3$ 的谱线（Hα）波长。

$$
\frac{1}{\lambda} = R_H\left(\frac{1}{2^2} - \frac{1}{3^2}\right) = 1.097\times10^7\times\left(\frac{1}{4} - \frac{1}{9}\right)
$$

- **第一步，写里德伯公式**：$\frac{1}{\lambda} = R_H(\frac{1}{n_1^2}-\frac{1}{n_2^2})$。
- **第二步，代入 $n_1 = 2$、$n_2 = 3$**：$\frac{1}{\lambda} = 1.097\times10^7\times(0.25 - 0.111) = 1.097\times10^7\times0.139 = 1.52\times10^6\ \text{m}^{-1}$。
- **第三步，求波长**：$\lambda = 1/(1.52\times10^6) = 6.56\times10^{-7}$ m = 656 nm——红光（Hα 线）。
- **第四步，用能级验证**：$E_3 - E_2 = -13.6(1/9 - 1/4) = 13.6\times0.139 = 1.89$ eV，$\lambda = hc/\Delta E = \frac{1240\ \text{eV·nm}}{1.89} = 656$ nm——一致。

**辨析｜易错点：**里德伯公式的 $n_1$、$n_2$ 位置别写反：$\frac{1}{n_1^2}$ 是小值（终态）、$\frac{1}{n_2^2}$ 是大值（初态），差值恒为正（发射）。判断谱线系先定 $n_1$（巴耳末 $n_1 = 2$ 可见光、莱曼 $n_1 = 1$ 紫外）。能级公式 $E_n = -13.6/n^2$ 的负号别丢——束缚能是负的。

再算一条莱曼系（$n_1 = 1$、$n_2 = 2$）谱线：$\frac{1}{\lambda} = R_H(1 - \frac{1}{4}) = 1.097\times10^7\times0.75$，$\lambda \approx 121.6$ nm——紫外区。这条 Lyman-α 线正是天文学里探测星际介质中性氢的经典「示踪线」：星系间的氢云吸收 121.6 nm 光子，留下特征吸收线。从实验室光谱到天文观测，里德伯公式都是同一张谱。

## 5 玻尔理论的成就与局限

**成就**：

- 正确预言氢原子光谱（里德伯公式）、玻尔半径、电离能；
- 首次把量子化引入原子结构，解释原子稳定性与离散光谱；
- 为量子力学提供了「能级」「跃迁」的核心概念。

**局限**：

- 只对氢原子（单电子）精确；氦、多电子原子光谱无法解释；
- 无法解释谱线强度、精细结构、塞曼效应；
- 轨道概念被量子力学否定（电子不是「沿轨道运动」，而是概率云）。

**重点：玻尔理论是「半经典」过渡理论——用经典轨道 + 人为量子化条件，正确给出氢原子能级，但缺乏自洽的物理基础。** 它由薛定谔方程（第 103 节）的量子力学取代：电子由波函数描述，能级是波动方程的边界条件自然给出的。<span class="marginnote">玻尔理论的贡献是「能级」思想，局限是「轨道」图像。量子力学保留能级、抛弃轨道：电子在原子中由波函数 $\psi$ 描述，氢原子能级 $E_n = -13.6/n^2$ eV 从薛定谔方程精确解再次得出（结果相同，图像全新）。玻尔是「量子原子论」的开路人，量子力学是他的继承者与超越者。</span>

玻尔理论的「能级」思想还直接通向光谱学的应用：把谱线当成能级之间的「阶梯」，通过测量发射/吸收谱线的波长，反推原子的能级结构——这就是光谱分析的方法论。天文上靠它测定恒星大气成分、宇宙学靠它测量星系红移（第十七章）。一张小小的分立谱，承载着从原子物理到宇宙学的整条线索。

## 6 小结

- **氢原子光谱**：分立谱线，里德伯公式 $\frac{1}{\lambda} = R_H(\frac{1}{n_1^2}-\frac{1}{n_2^2})$；莱曼、巴耳末、帕邢系。
- **玻尔三假设**：定态（不辐射）、频率条件 $h\nu = \Delta E$、角动量量子化 $L = n\hbar$。
- **能级**：$E_n = -13.6\ \text{eV}/n^2$，基态 $-13.6$ eV，电离能 13.6 eV。
- 轨道半径 $r_n = n^2r_1$，玻尔半径 $r_1 = 0.053$ nm。
- 成就：氢原子光谱/电离能；局限：仅单电子、无强度/精细结构——被量子力学取代。
