## 为什么从电磁波的产生开始

麦克斯韦方程组预言电磁波后，赫兹在 1888 年用火花放电实验产生并检测到了电磁波，验证了预言，也开启了无线电时代。电磁波是「变化的电场与变化的磁场互相激发、脱离源以波的形式传播」的物理实在。这一节研究电磁波如何产生、它的基本性质（横波、电场磁场垂直、同相、速度光速、携带能量），这些性质是理解光、无线电、微波、X 射线的统一框架。<span class="marginnote">把「电磁波」三个字换成「光」，这一节的全部内容都仍然成立——因为光就是电磁波。第一级《光学》里学过的折射、干涉、衍射，以及后续相对论里「光速不变」，都建立在本节「电磁波以光速传播、无需介质」这一条之上。从无线电到 γ 射线，唯一差别是频率与波长。</span>

## 1 电磁波的产生

**电磁波（electromagnetic wave）**：变化的电磁场在空间中以波的形式传播。

产生条件：**电荷做加速运动**（或交变电流）。加速的电荷产生变化的电场，变化的电场产生磁场（位移电流），变化的磁场又产生电场——两者互相激发，脱离源以波速 $c$ 向外传播。

- **振荡电偶极子**：电荷做简谐振动，产生的电磁波是最基本的辐射模型（电偶极辐射）；
- **交变电流（天线）**：LC 振荡电路的高频电流通过天线辐射电磁波；
- **加速电子**：同步辐射、韧致辐射（X 射线）。

为什么匀速电荷不辐射而加速电荷辐射？可以这样想：匀速运动的电荷其电场线「跟着电荷走」，观察者在远处看到的场是准静态的；一旦电荷加速，电场线发生「弯折」并向外以光速传播，这个弯折以波的形式离开电荷，就构成了辐射。静电场按 $1/r^2$ 衰减，而辐射场按 $1/r$ 衰减——所以离开源足够远之后，辐射场占主导，这正对应着「天线把能量送走」的本质。

<span class="marginnote">赫兹实验：火花放电（快速振动的电荷）产生电磁波，远处的环形天线接收，检测到火花——电磁波被「亲手」捕捉。从此，无线电、电视、手机、Wi-Fi 都是「赫兹的孩子」。注意：<strong>匀速运动的电荷不辐射电磁波</strong>，只有加速运动才辐射。</span>

**重点：电磁波传播不需要介质，能在真空中传播。** 这与机械波（声波、水波）本质不同——机械波靠介质传播，电磁波靠「场生场」自持传播。太阳光穿过真空到达地球，就是电磁波无需介质的明证。

## 2 平面电磁波的基本性质

真空中沿 $x$ 方向传播的平面电磁波：

$$\boldsymbol{E} = E_0\cos(\omega t - kx)\hat{\boldsymbol{j}}, \qquad \boldsymbol{B} = B_0\cos(\omega t - kx)\hat{\boldsymbol{k}}$$

基本性质：

1. **横波**：电场与磁场都垂直于传播方向；
2. **互相垂直**：$\boldsymbol{E} \perp \boldsymbol{B}$，且都与传播方向垂直（$\boldsymbol{E}\times\boldsymbol{B}$ 沿传播方向）；
3. **同相**：$\boldsymbol{E}$ 与 $\boldsymbol{B}$ 同时达到最大、同时为零；
4. **振幅关系**：$E_0 = cB_0$（$\boldsymbol{E}$ 与 $\boldsymbol{B}$ 的大小比值等于光速）；
5. **波速**：$v = c/\sqrt{\varepsilon_r\mu_r}$，真空中 $v = c$。

<span class="marginnote">「$E$ 与 $B$ 同相」值得强调：电磁波中电场与磁场步调一致（不像 LC 振荡里 $U$ 与 $I$ 相位差 $\pi/2$）。$E_0 = cB_0$ 说明电场「主导」磁场（数值上 $E$ 比 $B$ 大 $c$ 倍）。这个关系是电磁波区别于静场的重要特征。</span>

**重点：电磁波中 $\boldsymbol{E} \perp \boldsymbol{B}$ 且都与传播方向垂直，$\boldsymbol{E}\times\boldsymbol{B}$ 指向传播方向。** 这是「右手螺旋」关系：电磁波是横波，电场与磁场在垂直于传播方向的平面内互相垂直地振动。

### 极化

既然电场振动方向垂直于传播方向，振动方向可以沿不同取向——这引出一个新的自由度：**极化（偏振）**。若 $\boldsymbol{E}$ 始终沿固定方向振动，称线极化；若 $\boldsymbol{E}$ 的端点画圆，称圆极化。阳光是多种极化方向的混合（非极化），而偏振片、偏光太阳镜正是利用「只让某一方向振动通过」的原理来过滤眩光。极化现象是「光是横波」的直接证据——纵波（如声波）没有极化可言。

极化还有一个工程意义：通信中可以用极化来「复用」信道——同一频率下，水平极化和垂直极化的信号互不干扰，卫星与地面之间、微波中继里都靠这个技巧成倍提升容量。理解「极化是独立于频率的又一个自由度」，就明白为什么微波工程如此重视天线极化方向的一致性——收发极化不匹配时，信号会损失大半。

| 比较项 | 机械波 | 电磁波 |
| --- | --- | --- |
| 介质 | 需要介质（声、水、绳） | 无需介质，真空可传 |
| 横波/纵波 | 可横可纵 | 只能横波 |
| 传播速度 | 由介质性质决定 | 真空中恒为 $c$ |
| 携带的物理量 | 介质位移/压强 | 电场 $\boldsymbol{E}$ 与磁场 $\boldsymbol{B}$ |

## 3 电磁波的能量与坡印廷矢量

电磁波携带能量。电场与磁场能量密度之和：

$$w = \frac{1}{2}\varepsilon E^2 + \frac{1}{2}\frac{B^2}{\mu}$$

利用 $E_0 = cB_0$ 与 $c = 1/\sqrt{\mu\varepsilon}$，可得电场与磁场能量各占一半：$w = \varepsilon E^2$。

能量传播用**坡印廷矢量（Poynting vector）**描述（单位时间通过单位面积的能量流）：

$$\boldsymbol{S} = \frac{1}{\mu_0}\boldsymbol{E}\times\boldsymbol{B}$$

$\boldsymbol{S}$ 的方向是能量传播方向（即波的传播方向），大小是能流密度。对平面电磁波：

$$S = \frac{E_0B_0}{\mu_0} = \frac{E_0^2}{\mu_0 c} = \varepsilon_0 c E_0^2$$

平均能流密度（波的强度）：$\bar{S} = \frac{1}{2}\varepsilon_0cE_0^2$——正比于电场振幅平方。<span class="marginnote">「能量 ∝ 振幅平方」再次出现：光强正比于 $E_0^2$。这个公式是辐射强度、天线功率、光照度的定量基础。坡印廷矢量是第二十一章《电磁场的能量、动量与坡印廷矢量》的主角，这里先给结论。</span>

## 4 公式解析：电磁波的振幅关系

一平面电磁波在真空中传播，电场振幅 $E_0 = 300\ \text{V/m}$。求磁场振幅与平均能流密度。

$$
B_0 = \frac{E_0}{c} = \frac{300}{3\times10^8} = 1.0\times10^{-6}\ \text{T}
$$

- **第一步，写振幅关系**：$E_0 = cB_0$，$B_0 = E_0/c$。
- **第二步，代入**：$B_0 = 300/(3\times10^8) = 1.0\times10^{-6}\ \text{T}$——电场 300 V/m 对应磁场仅 1 微特斯拉，数值上电场远大于磁场。
- **第三步，求平均能流**：$\bar{S} = \frac{1}{2}\varepsilon_0cE_0^2 = \frac{1}{2}\times8.85\times10^{-12}\times3\times10^8\times9\times10^4 \approx 119\ \text{W/m}^2$。
- **第四步，对比**：119 W/m² 大约相当于正午太阳光强（约 1000 W/m²）的十分之一——可见光的电场振幅更大。

**辨析｜易错点：**电磁波的能量密度与强度要用「振幅」计算，而平均强度带 $\frac{1}{2}$ 因子（余弦平方的平均值）。瞬时强度随时间振荡，平均强度是时间平均值——题目说「平均光强」「能流密度」时用 $\frac{1}{2}$ 版本。

## 5 电磁波的动量与辐射压

电磁波不仅携带能量，还携带动量。单位体积电磁场的动量密度与能量密度相关，电磁波打到物体表面产生**辐射压（radiation pressure）**：

$$p = \frac{I}{c} \quad \text{（完全吸收）}, \qquad p = \frac{2I}{c} \quad \text{（完全反射）}$$

<span class="marginnote">辐射压虽小（正午阳光约 $4\times10^{-6}$ Pa），却是「太阳帆」推进航天器的物理基础，也是彗星尾巴被太阳风吹开的机制之一。电磁波携带动量还意味着「光压」在微观上表现为光子动量——这通向第十八章的波粒二象性。</span>

一个量级估计：太阳常数约 $I = 1361\ \text{W/m}^2$（地球处），若被完全反射，辐射压 $p = 2I/c \approx 9\times10^{-6}\ \text{Pa}$。一面边长 100 m 的太阳帆面积 $10^4\ \text{m}^2$，受到的推力约 $9\times10^{-2}\ \text{N}$——虽然只够托起约 9 克，但在无阻力的太空中持续加速几年，足以让飞船获得每秒数十公里的速度。这就是「靠光推进」的可行性的数量级依据。

**重点：电磁波携带能量与动量，能对物体施压——进一步证明场是物理实在。** 不只是「数学描述」，电磁场携带真实的能量、动量，通过辐射压与物质交换动量。这个「场的实在性」观念在相对论与量子场论中到达极致。

## 6 小结

- **产生**：电荷做加速运动（振荡电偶极子、交变电流）辐射电磁波；匀速电荷不辐射。
- 传播无需介质（真空可传）；赫兹实验验证。
- **基本性质**：横波、$\boldsymbol{E}\perp\boldsymbol{B}$、同相、$E_0 = cB_0$、波速 $c = 1/\sqrt{\mu_0\varepsilon_0}$。
- **能量**：能量密度 $w = \varepsilon E^2$；坡印廷矢量 $\boldsymbol{S} = \boldsymbol{E}\times\boldsymbol{B}/\mu_0$；强度 $\propto E_0^2$。
- **动量**：辐射压 $p = I/c$（吸收）或 $2I/c$（反射）。
