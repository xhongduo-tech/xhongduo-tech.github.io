# 伯努利方程及其应用

<div class="epigraph">
<p>伯努利方程是流体动力学的能量守恒：静止压强、动压强与高度压强，三项之和在一条流线上保持不变。</p>
<footer>—— 丹尼尔 · 伯努利（Daniel Bernoulli）《流体动力学》（Hydrodynamica），1738</footer>
</div>

<div class="article-byline">

## 为什么从伯努利方程开始

上一节的连续性方程告诉我们流体「流得有多快」由管道的粗细决定，但它没有解释为什么流速变化会伴随压强变化。伯努利方程补上这关键一环：它把**压强、流速与高度**联系在一条方程里，本质上是「流体版的机械能守恒」。机翼为什么能产生升力、喷雾器为什么能把药水吸上来、为什么高铁站台要画黄色安全线、为什么船不能靠得太近——这些看似无关的现象，全都是伯努利方程在不同场景下的面孔。

## 1 伯努利方程的推导

在理想流体的定常流动中，取流管中一段流体，考察它从截面 1 运动到截面 2 时的能量变化。由机械能守恒（理想流体无黏性，无耗散），可得**伯努利方程（Bernoulli's equation）**：

$$p_1 + \frac{1}{2}\rho v_1^2 + \rho g h_1 = p_2 + \frac{1}{2}\rho v_2^2 + \rho g h_2$$

更常用的是「沿同一条流线」的形式：

$$p + \frac{1}{2}\rho v^2 + \rho gh = \text{常量}$$

三项各有名字：

- $p$：**静压强**（压强本身）；
- $\frac{1}{2}\rho v^2$：**动压强**（与流速相关的「速度压强」）；
- $\rho gh$：**高度压强**（与位置高度相关的「重力项」）。

**重点：伯努利方程是能量守恒，不是动量守恒。** 它说的是单位体积流体的「压力能 + 动能 + 重力势能」之和沿流线不变。理想流体的无黏性假设保证了没有能量耗散，机械能守恒才成立。<span class="marginnote">推导的直观图像：截面 1 的流体被后方压强推动做功 $p_1 S_1 v_1\Delta t$，到达截面 2 时反抗前方压强做功 $p_2 S_2 v_2\Delta t$；净功等于流体动能的增量加上重力势能的增量，整理即得伯努利方程。</span>

## 2 水平管中的伯努利：流速大处压强小

若管道水平（$h_1 = h_2$），伯努利方程简化为：

$$p + \frac{1}{2}\rho v^2 = \text{常量}$$

于是**流速大处压强小，流速小处压强大**。这是伯努利方程最广为人知的推论。<span class="marginnote">「流速大、压强小」常被误读为「流速大、压强小，所以物体会被吸过去」。严谨地说，是「压强差产生指向低压区的力」。机翼升力、火车站的黄线、两船相吸，都由这个压强差主导。</span>

三个最经典的例子：

- **机翼升力**：机翼上表面曲率大、流线密、流速快，压强小；下表面流速慢、压强大。上下压强差产生向上的升力。严格说机翼升力还涉及环流、攻角等复杂因素，但「上快下慢、上低下高」是入门解释。
- **水流射流**：水从水龙头窄口喷出时加速变细（连续性），压强降为大气压；下落过程中流束进一步变细。
- **喷雾器**：高速气流从细口喷出，出口处压强降低，低于瓶中液面的压强，药水被「吸」上来到气流中雾化——这个「吸」正是低压区的吸引。

## 3 高度项：托里拆利定理与虹吸

当流速不变（或近似为零）时，伯努利方程退化为流体静力学 $p = p_0 + \rho gh$。若流体从容器侧壁小孔流出，用伯努利方程可得**托里拆利定理（Torricelli's theorem）**：

$$v = \sqrt{2gh}$$

即小孔流出速度等于液体**自由下落同样高度**的速度。<span class="marginnote">推导：取液面（$v \approx 0$，压强为大气压）与小孔（压强也为大气压）两点写伯努利方程，压强项抵消，剩下 $\frac{1}{2}\rho v^2 = \rho gh$，解得 $v = \sqrt{2gh}$。这就是「水从桶底破洞喷出的速度由液面高度决定」的物理依据。</span>

**虹吸**：用一根管子把高处容器里的液体引到低处。液体在管内上升段也能流动，是因为液面高度差提供的压强足以克服上升段的压强差——伯努利方程（沿流线）与连续性方程共同决定了虹吸的流速。

**辨析｜易错点：**伯努利方程沿**同一条流线**成立，不同流线的常量可能不同。把两个任意点的压强、速度直接套进一条伯努利方程是不对的——要先确认两点在同一流线上（或流线从同一点分出）。此外，方程的前提是定常、无黏、不可压缩；流速过大进入湍流、或管道有弯头涡旋时，方程需要修正。

## 4 公式解析：文丘里管的流速测量

文丘里管利用「窄处流速大、压强小」测量流量。设主管截面积 $S_1$，窄颈截面积 $S_2$，两处压强差由 U 形管测出为 $\Delta p = p_1 - p_2$。求主管流速 $v_1$。

$$
v_1 = S_2\sqrt{\frac{2\Delta p}{\rho(S_1^2 - S_2^2)}}
$$

- **第一步，写伯努利方程**：水平管，$h_1 = h_2$，$p_1 + \frac{1}{2}\rho v_1^2 = p_2 + \frac{1}{2}\rho v_2^2$。
- **第二步，写连续性方程**：$S_1v_1 = S_2v_2$，即 $v_2 = \frac{S_1}{S_2}v_1$。
- **第三步，联立消去 $v_2$**：代入得 $p_1 - p_2 = \frac{1}{2}\rho v_1^2\left(\frac{S_1^2}{S_2^2} - 1\right)$。
- **第四步，解出 $v_1$**：整理即得 $v_1 = S_2\sqrt{\frac{2\Delta p}{\rho(S_1^2 - S_2^2)}}$，再乘 $S_1$ 即体积流量。

整个方法的关键是**用伯努利方程（能量）把「测不到的流速」换算成「测得到的压强差」**——流体力学实验与工程仪表的经典思路。

## 5 伯努利方程与能量守恒的对照

| 比较项 | 固体机械能守恒 | 伯努利方程 |
| --- | --- | --- |
| 守恒量 | 单位质量机械能 | 单位体积机械能 |
| 动能项 | $\frac{1}{2}mv^2$ | $\frac{1}{2}\rho v^2$ |
| 势能项 | $mgh$ | $\rho gh$ |
| 新增项 | — | 压强 $p$（压力能） |
| 适用前提 | 只有保守力做功 | 定常、无黏、不可压缩 |

**重点：压强 $p$ 扮演「压力能密度」的角色，是流体独有的能量形式。** 流体的能量包含三种形态——压力能、动能、重力势能——三者在流动中互相转化，总量守恒。这与机械能守恒「动能 ↔ 势能」的转化是同一思想在流体中的推广。

## 6 数值算例：大水箱侧壁小孔的出流

一个水箱水深 $h = 1.25\ \text{m}$，在侧壁底部开一小孔。求孔的出流速度。

$v = \sqrt{2gh} = \sqrt{2\times9.8\times1.25} = \sqrt{24.5} \approx 4.95\ \text{m/s}$

这个速度相当于水从 $1.25\ \text{m}$ 高处自由落体的末速度——与直觉一致：小孔出水像「自由落体的水平版」。若水箱直径 $D = 1\ \text{m}$（截面积 $S_1 \approx 0.785\ \text{m}^2$），小孔直径 $d = 2\ \text{cm}$（$S_2 \approx 3.14\times10^{-4}\ \text{m}^2$），体积流量 $Q = S_2v \approx 1.55\times10^{-3}\ \text{m}^3/\text{s}$，即每秒流出约 1.55 升水。

**辨析｜易错点：**「$v = \sqrt{2gh}$ 用 $h$ 而不用实际水柱长度」常被误解。$h$ 是**液面与小孔的高度差**，而不是小孔上方水柱的长度——虽然数值相同，但物理含义是「把重力势能 $\rho gh$ 全部转化为动能 $\frac{1}{2}\rho v^2$」。若液面本身也在下降（排水过程），则还要用连续性方程把「液面下降」与「孔口出流」耦合起来，得到 $h$ 随时间的指数衰减。

<span class="marginnote">伯努利方程还有一个工程上的极致推论——<strong>滞止压强（stagnation pressure）</strong>：当流速被完全挡住（$v \to 0$）时，$p_0 = p + \frac{1}{2}\rho v^2$ 达到最大。皮托管（Pitot tube）正是测量「动压 + 静压」来反推飞机空速的仪器，航空航天里无处不在。</span>

## 7 术语速查

- **流线（streamline）**：某时刻处处与速度方向相切的曲线，定常流动中流线不随时间变化。
- **流管**：由一簇流线围成的管状区域，理想流体在流管中满足连续性方程。
- **定常流动**：流速、压强等场量不随时间变化（但可随位置变化）的流动。
- **理想流体**：不可压缩且无黏性的流体，是伯努利方程成立的前提。
- **滞止压强**：流体被滞止（$v = 0$）处的压强 $p_0 = p + \frac{1}{2}\rho v^2$。

## 8 小结

- **伯努利方程**：$p + \frac{1}{2}\rho v^2 + \rho gh = \text{常量}$，沿同一条流线成立，本质是单位体积流体的能量守恒。
- 三项能量：静压强 $p$、动压强 $\frac{1}{2}\rho v^2$、高度压强 $\rho gh$。
- 水平管推论：流速大处压强小——机翼升力、喷雾器、安全线都源于此。
- 托里拆利定理 $v = \sqrt{2gh}$：小孔出流速度等于自由落体同高度的速度。
- 文丘里管把流速换算成压强差来测量，是能量守恒思想的工程化。
- 适用前提：定常、无黏、不可压缩、沿同一流线。

在下一节，我们松开「无黏性」这个理想化假设，看看真实流体的**黏性流动**——为什么蜂蜜流得慢、为什么小球在水中下落有极限速度（斯托克斯定律）。
