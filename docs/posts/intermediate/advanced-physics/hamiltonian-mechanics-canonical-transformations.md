## 为什么从哈密顿力学开始

拉格朗日力学把力学写成「$s$ 条二阶微分方程」，哈密顿力学则用一次**勒让德变换**把它改写为「$2s$ 条一阶方程」，并把「位置与速度」换成一对象征性的新变量——坐标 $q_j$ 与动量 $p_j$。这看起来只是重写，实则是一次根本的升维：运动不再是一段时间的演化，而是**相空间（phase space）里的一条几何轨迹**；守恒量、对称性、甚至量子化，全部在这个几何图景里获得新的意义。量子力学里 $[\hat q, \hat p] = i\hbar$ 的正则对易关系、海森堡方程的演化形式，都是哈密顿语言的原样继承。这一节把相空间、正则方程、泊松括号与作用量原理一次讲透。

## 1 相空间：力学变成几何学

先定义哈密顿量。**哈密顿量（Hamiltonian）$H$**：由拉格朗日量 $L(q, \dot q, t)$ 作勒让德变换得到，$H = \sum_j p_j\dot q_j - L$，其中**广义动量** $p_j = \partial L/\partial\dot q_j$。<span class="marginnote"><strong>勒让德变换的直觉</strong>：把函数从「以 $\dot q$ 为自变量」切换到「以 $p$ 为自变量」，信息不增不减——斜率与截距互相对应。热力学里 $F = U - TS$、$G = H - TS$ 是同一套变换，所以 $H$ 的记号在哈密顿力学与热力学里同源。</span>对最常见的「动能减势能、约束定常」系统，$H = T + V$——总机械能。

**相空间（phase space）**：以 $2s$ 个独立变量 $(q_1,\dots,q_s; p_1,\dots,p_s)$ 为坐标构成的 $2s$ 维空间。系统在任一瞬时的状态是相空间里**一个点**（代表点），系统的运动是相空间里**一条曲线**。相空间的体积元 $\mathrm{d}\Gamma = \mathrm{d}q_1\cdots\mathrm{d}q_s\,\mathrm{d}p_1\cdots\mathrm{d}p_s$ 在哈密顿流下守恒——这就是刘维尔定理，是统计力学的基石。<span class="marginnote"><strong>为什么相空间如此重要</strong>：经典统计力学把「系统状态」当成相空间里的概率分布，玻尔兹曼方程、系综理论全都建立在相空间语言上；而量子力学把「相空间的一个点」推广为「希尔伯特空间的一个态矢」——两条现代物理主线都从这里出发。见前文《系综理论初步》。</span>

## 2 哈密顿正则方程

把 $H$ 看成 $q$ 与 $p$ 的独立函数，运动规律由**哈密顿正则方程（Hamilton's canonical equations）**给出：

$$
\dot q_j = \frac{\partial H}{\partial p_j}, \qquad \dot p_j = -\frac{\partial H}{\partial q_j}, \qquad j = 1, 2, \dots, s
$$

**重点：正则方程把 $2s$ 个一阶方程写成完全对称的形式——坐标的演化由 $H$ 对动量的偏导决定，动量的演化由 $H$ 对坐标的偏导决定。** 这是物理里最优雅的一对方程：任何不显含时间的力学量 $F(q,p)$，其时间导数都是 $F$ 与 $H$ 的泊松括号（下一节），而 $H$ 本身沿运动轨迹守恒。

**数值算例（谐振子）**：$H = \frac{p^2}{2m} + \frac{1}{2}kq^2$。正则方程给出 $\dot q = p/m$、$\dot p = -kq$，消去 $p$ 得 $\ddot q + (k/m)q = 0$——角频率 $\omega = \sqrt{k/m}$。在相空间里，轨迹是椭圆 $p^2/(2mH) + q^2/(2H/k) = 1$，代表点沿椭圆匀速流转，正是「能量面上的闭轨」。

## 3 泊松括号

正则变量最重要的代数结构是泊松括号。**泊松括号（Poisson bracket）**：

$$
\{F, G\} = \sum_{j=1}^{s}\left(\frac{\partial F}{\partial q_j}\frac{\partial G}{\partial p_j} - \frac{\partial F}{\partial p_j}\frac{\partial G}{\partial q_j}\right)
$$

泊松括号给出两条基本性质：**基本泊松括号** $\{q_j, p_k\} = \delta_{jk}$、$\{q_j, q_k\} = \{p_j, p_k\} = 0$；以及任意力学量的演化定律 $\dot F = \{F, H\}$。<span class="marginnote"><strong>泊松括号与量子对易子</strong>：狄拉克把经典泊松括号与量子对易子对应起来：$\{\cdot,\cdot\}_{\text{经典}} \to \frac{1}{i\hbar}[\cdot,\cdot]_{\text{量子}}$。于是 $\{q,p\}=1$ 对应 $[\hat q,\hat p]=i\hbar$——量子力学的测不准关系，本质上是经典泊松结构的量子版。见前文《算符与力学量的平均值》。</span>

**重点：泊松括号是守恒量的「探测器」——$\{F, H\}=0$ 当且仅当 $F$ 是运动常量。** 与拉格朗日框架里的循环坐标判据（$\partial L/\partial q_j=0$）相比，泊松括号把守恒律完全代数化：不需要解方程，只做括号运算。<span class="marginnote">角动量三分量满足 $\{L_x, L_y\}=L_z$ 及循环置换——这一组代数关系直接预言了量子力学角动量算符的对易关系与量子化规则，也是后面《中心力场与角动量》一篇的代数入口。</span>

## 4 公式解析：正则变换与生成函数

正则方程的形式（$\dot q = \partial H/\partial p$、$\dot p = -\partial H/\partial q$）在哪些坐标变换下保持不变？**正则变换（canonical transformation）**：从 $(q,p)$ 到 $(Q,P)$ 的坐标变换，若保持正则方程形式不变、且存在函数 $K(Q,P,t)$ 使新方程 $\dot Q = \partial K/\partial P$、$\dot P = -\partial K/\partial Q$ 成立，就叫正则变换。核心工具是**生成函数（generating function）**。

以第一类生成函数 $F_1(q, Q, t)$ 为例，变换由条件「新旧拉格朗日量相差一个全导数」导出：

$$
p_j = \frac{\partial F_1}{\partial q_j}, \qquad P_j = -\frac{\partial F_1}{\partial Q_j}, \qquad K = H + \frac{\partial F_1}{\partial t}
$$

- **第一步，读懂条件**：正则变换要求新旧系统的变分原理给出同一运动轨迹，故新旧拉格朗日量至多相差一个全时间导数 $\frac{\mathrm{d}F_1}{\mathrm{d}t}$。
- **第二步，写出联系**：$\sum p_j\dot q_j - H = \sum P_j\dot Q_j - K + \frac{\mathrm{d}F_1}{\mathrm{d}t}$，比较 $\dot q$、$\dot Q$ 的系数即得上面三式。
- **第三步，体会用途**：选择一个 $F_1$，使新哈密顿量 $K$ 只含 $Q$ 不含 $P$（或反之），则对应动量守恒——**正则变换就是「找守恒量」的机器**。
- **第四步，极限情形**：取 $F_1 = \sum_j q_j Q_j$ 得平凡恒等变换；取 $F_1 = \sum_j q_j P_j$ 得坐标动量互换——三种生成函数 $F_1, F_2, F_3, F_4$ 覆盖了所有常见变换。<span class="marginnote">正则变换在量子力学里的对应是么正变换：量子态在表象间变换、薛定谔方程在绘景间转换，都与经典正则变换同构（见《薛定谔绘景与海森堡绘景》）。李群与李代数的指数映射，也以「无穷小正则变换」的形式在此登场。</span>

## 5 哈密顿-雅可比方程与最小作用量原理

若选择生成函数使新哈密顿量 $K \equiv 0$，则所有新坐标都成常数——问题被「解完」。设主函数 $S$，哈密顿-雅可比方程：

$$
H\left(q_j, \frac{\partial S}{\partial q_j}, t\right) + \frac{\partial S}{\partial t} = 0
$$

这是偏微分方程而非常微分方程，但它把「解运动方程」转化为「解一个由 $H$ 决定的一阶 PDE」，并且 $S$ 正是**作用量**——沿真实轨迹的作用量泛函 $S = \int L\,\mathrm{d}t$。<span class="marginnote"><strong>最小作用量原理</strong>：哈密顿原理断言真实轨迹使作用量 $S = \int_{t_1}^{t_2} L\,\mathrm{d}t$ 取极值（实际为稳定值）。从它可以推出拉格朗日方程、再由勒让德变换推出正则方程——三套表述（拉格朗日、哈密顿、哈密顿-雅可比）是同一条变分原理的三个投影。量子力学的路径积分正是把「$S$ 取极值」推广为「所有路径按 $e^{iS/\hbar}$ 叠加」。</span>

**重点：哈密顿-雅可比方程把力学彻底几何化——粒子的轨迹是作用量场 $S$ 的波前族的正交曲线，与几何光学里「费马原理 ↔ 波动方程」的关系完全平行。** 玻恩与薛定谔正是从这条类比出发，把 $S$ 看作波相位、导出了薛定谔方程——哈密顿力学是量子力学的直接孵化器。<span class="marginnote"><strong>数值算例（自由粒子）</strong>：自由粒子 $H=p^2/2m$，哈密顿-雅可比方程 $\frac{1}{2m}(\partial S/\partial x)^2 + \partial S/\partial t = 0$，得 $S = px - (p^2/2m)t$——正是平面波 $e^{i(kx - \omega t)}$ 的相位结构。经典作用量与量子相位的一一对应，在这一例上完全显形。</span>

## 6 数值算例：开普勒问题的哈密顿处理

把行星运动（质量 $m$、引力势 $V = -GMm/r$）用哈密顿语言写一遍，正则是相空间方法的典型示范。极坐标下 $H = \frac{p_r^2}{2m} + \frac{p_\phi^2}{2mr^2} - \frac{GMm}{r}$，其中 $p_\phi = mr^2\dot\phi$ 是角动量。

- **第一步，找守恒量**：$H$ 不含 $\phi$，故 $\dot p_\phi = -\partial H/\partial\phi = 0$，角动量 $L = p_\phi$ 守恒——这就是循环坐标的哈密顿版。
- **第二步，有效势**：径向运动等价于在有效势 $V_{\text{eff}} = \frac{L^2}{2mr^2} - \frac{GMm}{r}$ 中运动——「离心势垒」项自动从动能里长出来。
- **第三步，轨道方程**：由 $\dot\phi = \partial H/\partial p_\phi = L/mr^2$ 与径向方程联立，消去时间得轨道 $r(\phi) = \frac{p}{1 + e\cos\phi}$——圆锥曲线族，$e<1$ 为椭圆、$e=1$ 为抛物线、$e>1$ 为双曲线。
- **第四步，体会**：整个开普勒问题只需「写 $H$ → 找循环坐标 → 解有效势」，无需解牛顿方程——相空间方法把天体力学变成几个标准步骤。<span class="marginnote"><strong>与量子力学的平行</strong>：氢原子（库仑势）的量子解与开普勒问题共用同一个有效势图景：离心势垒对应角动量量子数 $l$，径向方程解出主量子数 $n$。见《氢原子的量子力学描述》。经典轨道形状的序列与量子能级的序列，是同一张有效势图的两副面孔。</span>

## 7 术语速查表

| 术语 | 公式 | 要点 |
| --- | --- | --- |
| 哈密顿量 | $H = \sum p_j\dot q_j - L$ | 定常约束下 $= T + V$ |
| 广义动量 | $p_j = \partial L/\partial \dot q_j$ | 不一定是 $m\dot q$ |
| 正则方程 | $\dot q_j = \partial H/\partial p_j$，$\dot p_j = -\partial H/\partial q_j$ | $2s$ 条一阶方程 |
| 泊松括号 | $\{F,G\} = \sum(\frac{\partial F}{\partial q_j}\frac{\partial G}{\partial p_j} - \frac{\partial F}{\partial p_j}\frac{\partial G}{\partial q_j})$ | $\{q_j,p_k\}=\delta_{jk}$ |
| 正则变换 | $p_j = \frac{\partial F_1}{\partial q_j}$，$P_j = -\frac{\partial F_1}{\partial Q_j}$ | 生成函数保形式 |
| 哈密顿-雅可比方程 | $H(q, \partial S/\partial q, t) + \partial S/\partial t = 0$ | $S$ 即作用量 |

## 8 核心对比表：拉格朗日 vs 哈密顿

| 维度 | 拉格朗日力学 | 哈密顿力学 |
| --- | --- | --- |
| 独立变量 | $(q_j, \dot q_j)$，$s$ 个二阶方程 | $(q_j, p_j)$，$2s$ 个一阶方程 |
| 基本函数 | $L = T - V$ | $H = \sum p_j\dot q_j - L$（勒让德变换） |
| 演化方程 | 拉格朗日方程 | 正则方程 + $\dot F = \{F, H\}$ |
| 空间 | 位形空间 + 速度 | 相空间（$2s$ 维） |
| 守恒判据 | 循环坐标 $\partial L/\partial q_j = 0$ | 泊松括号 $\{F, H\} = 0$ |
| 量子对应 | 路径积分振幅 $\propto e^{iS/\hbar}$ | 对易关系 $[\hat q,\hat p] = i\hbar$ |
| 最强工具 | 对称性 → 守恒（诺特定理） | 正则变换 → 找可积变量 |

**重点：哈密顿力学的相空间几何、泊松代数与正则变换，直接孕育了量子力学与统计力学——它是「经典力学 → 现代物理」的中转站。** 相空间体积守恒（刘维尔）给统计力学的系综理论提供几何基础，对易关系给出量子化规则，正则变换给出绘景理论。<span class="marginnote"><strong>与「从极限到大模型」主线的连接</strong>：机器学习的哈密顿蒙特卡洛（Hamiltonian Monte Carlo）方法，正是把「在相空间里按哈密顿流采样」用于高维概率分布的采样；最优控制里的庞特里亚金原理也是哈密顿框架的现代继承——分析力学在现代计算科学里生机勃勃。</span>

## 9 小结

- **哈密顿量** $H = \sum p_j\dot q_j - L$，定常约束下 $H = T + V$（总能量）。
- **相空间**是 $2s$ 维状态空间，运动是其中的几何轨迹；刘维尔定理保证相空间体积守恒。
- **正则方程** $\dot q_j = \partial H/\partial p_j$、$\dot p_j = -\partial H/\partial q_j$，把力学写成 $2s$ 条一阶方程。
- **泊松括号** $\{F,G\}$ 给出守恒判据 $\{F,H\}=0$，并直接对应量子对易子。
- **正则变换**由生成函数生成，保持方程形式，是「找守恒量、化简问题」的机器。
- **哈密顿-雅可比方程**把力学化为作用量场的波前几何，是薛定谔方程的出生证。
