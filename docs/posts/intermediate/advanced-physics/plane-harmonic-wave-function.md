## 为什么从波函数开始

上一节我们从图像上认识了波，但「波形沿着介质传播」到底是怎么被数学描述的？这一节给出答案：**波函数（wave function）**——它把「位移」写成「位置 $x$ 与时间 $t$」两个变量的函数。与简谐振动的函数只有时间一个变量不同，波函数要同时回答两个问题：某一时刻，介质各点在什么位置（波形图）；某一点，各时刻它在什么位置（振动图）。**平面简谐波**是最基本的波，它的波函数是一切波动问题的起点。

## 1 平面简谐波的概念

**平面简谐波（plane harmonic wave）**：波面为平面、且介质中各质点做同频率简谐振动的波。它是简谐振动在空间中的「平移」。

设波沿 $+x$ 方向以波速 $u$ 传播，原点 $O$ 处质点的振动为：

$$y_O = A\cos(\omega t + \varphi_0)$$

考察 $x$ 处的质点：它的振动与原点相同，只是**相位落后**——因为振动从原点传到 $x$ 需要时间 $t_0 = x/u$。因此 $x$ 处质点的位移是原点的振动「延迟」了 $t_0$：

$$y(x,t) = A\cos\left[\omega\left(t - \frac{x}{u}\right) + \varphi_0\right]$$

<span class="marginnote">「沿 $+x$ 传播 ⇒ 相位落后 $x/u$」是波函数的灵魂。想象一排人依次站起：后面的人总是比前面的人晚一点动作——波的传播就是相位依次滞后的链条。</span>

## 2 波函数的多种写法

利用 $\omega = 2\pi\nu$、$u = \lambda\nu$、$k = 2\pi/\lambda$（角波数），波函数可写成等价形式：

$$y(x,t) = A\cos(\omega t - kx + \varphi_0) = A\cos\left[2\pi\left(\frac{t}{T} - \frac{x}{\lambda}\right) + \varphi_0\right]$$

四种写法选用哪种，取决于题目给的条件：给周期用 $t/T$ 形式，给波长用 $x/\lambda$ 形式，给角频率与波数用 $\omega t - kx$ 形式。<span class="marginnote">注意 $kx$ 项前的负号对应「沿 $+x$ 传播」；若波沿 $-x$ 传播，相位为 $\omega t + kx$。符号判断是写波函数的第一道关口——先看传播方向，再定 $kx$ 的符号。</span>

**辨析｜易错点：**「波形向右移动」与「相位 $kx$ 前是负号」的对应容易记混。检验方法：固定时刻 $t_0$，波函数是 $x$ 的余弦函数，$x$ 增大时相位 $\omega t_0 - kx$ 减小——峰值位置向 $+x$ 移动，即波向右传播。用这个检验，符号就永远不会错。

## 3 波函数的物理意义：双重视角

波函数 $y(x,t)$ 是两个变量的函数，固定一个变量就得到两种图：

**固定 $t$（波形图）**：$y(x)$ 是 $x$ 的余弦函数——**某一时刻介质的「快照」**，相邻波峰间距为波长 $\lambda$。
**固定 $x$（振动图）**：$y(t)$ 是 $t$ 的余弦函数——**某一点的「心电图」**，相邻振动状态重复的时间间隔为周期 $T$。

**重点：波形图与振动图是同一波函数的两个切面。** 波形图横轴是位置，看「空间分布」；振动图横轴是时间，看「时间演化」。读图题最容易错的就是混淆两者：波形图看波长，振动图看周期，横轴单位分别是米与秒。

<span class="marginnote">从波形图求某点的振动方向，用「波形推进法」：把波形整体向传播方向平移一小段，看该点如何移动。若波向右传播，某点随波形右移而上升，则该点速度向上（为正）。这是下一节「已知波形求振动方向」的标准操作。</span>

## 4 公式解析：由振动方程写波函数

已知波速 $u = 20\ \text{m/s}$，原点处振动 $y_O = 0.05\cos(10\pi t)\ \text{m}$，波沿 $+x$ 传播。求波函数、波长与 $x = 5\ \text{m}$ 处的振动方程。

$$
y(x,t) = 0.05\cos\left[10\pi\left(t - \frac{x}{20}\right)\right] = 0.05\cos(10\pi t - 0.5\pi x)\ \text{m}
$$

- **第一步，写一般形式**：$y = A\cos[\omega(t - x/u) + \varphi_0]$。已知 $A = 0.05$ m，$\omega = 10\pi$ rad/s，$u = 20$ m/s，$\varphi_0 = 0$。
- **第二步，代入化简**：$y = 0.05\cos[10\pi(t - x/20)] = 0.05\cos(10\pi t - \frac{\pi}{2}x)$。这里 $k = \omega/u = 10\pi/20 = \pi/2$ m⁻¹。
- **第三步，求波长**：$\lambda = 2\pi/k = 2\pi/(\pi/2) = 4$ m；或 $\lambda = uT = u\cdot 2\pi/\omega = 20\times0.2 = 4$ m。
- **第四步，代入 $x = 5$**：$y(5,t) = 0.05\cos(10\pi t - 2.5\pi) = 0.05\cos(10\pi t - 0.5\pi)$——该点的振动比原点落后 $\pi/2$ 相位，即滞后 $T/4$。

**重点：波函数求值就是「把 $x$ 代入」。** 求某点振动，固定 $x$；求某时刻波形，固定 $t$。两者都要能快速从一般形式里读出振幅、频率、波长、初相。

## 5 波速、波长与频率的关系回顾

波函数把上一节的四个特征量统一起来：$u = \lambda\nu = \omega/k$。一条波有三个量的「三角关系」：

- **$u$（波速）**：由介质决定，波进入新介质不变频率、改变波长与波速；
- **$\nu$（频率）**：由波源决定，恒定；
- **$\lambda$（波长）**：$= u/\nu$，随介质变。

<span class="marginnote">这道「频率不变、波长随介质变」的题在声学与光学反复出现：声音从空气进入水中，频率不变（还是那个音调），但声速变大、波长变长。光的折射也类似——频率决定颜色，进入介质后频率不变、波长改变，这就是第十六章讨论折射时「颜色不变」的根源。</span>

## 6 数值算例：由波形图反推波函数

一列沿 $+x$ 传播的波，$t = 0$ 时刻的波形满足 $y(x,0) = 0.1\cos(\frac{\pi}{2}x)$ m，波速 $u = 4\ \mathrm{m/s}$。求波函数与频率。

$$

y(x,t) = 0.1\cos\left(\omega t - \frac{\pi}{2}x\right), \qquad k = \frac{\pi}{2}\ \mathrm{m^{-1}}, \quad \omega = ku = \frac{\pi}{2}\times4 = 2\pi\ \mathrm{rad/s}, \quad \nu = 1\ \mathrm{Hz}

$$

- **第一步，读波数**：$t=0$ 波形 $y = 0.1\cos(kx)$，$k = \pi/2$ m⁻¹。
- **第二步，算波长**：$\lambda = 2\pi/k = 4$ m——与 $u = 4$ m/s 配合，频率 $= u/\lambda = 1$ Hz。
- **第三步，写波函数**：沿 $+x$ 传播，$y = 0.1\cos(\omega t - kx)$，$\omega = 2\pi\nu = 2\pi$。
- **第四步，解读**：一个完整的波函数需要「波形（$k$）+ 波速（$u$）+ 传播方向（符号）」三件事——给了波形与波速，其余全部可求。$u = \omega/k$ 是波速的又一种写法。<span class="marginnote">「波函数的信息量」：振幅 $A$、波数 $k$、角频率 $\omega$、初相 $\varphi_0$ 四个参数完全确定一列平面简谐波。其中 $k$ 由波形（空间）读、$\omega$ 由振动（时间）读、$u = \omega/k$ 连接两者。给任何「波形 + 波速」或「振动 + 波长」的组合，都能补全整个波函数。</span>

## 7 波函数的叠加与相位差

两列同方向传播的波在空间相遇，按叠加原理合成为位移之和：

$$

y = y_1 + y_2 = A_1\cos(\omega t - kx) + A_2\cos(\omega t - kx + \Delta\varphi)

$$

- **第一步，写两列波**：同频率、同方向，相位差 $\Delta\varphi$。
- **第二步，同相合成**：$\Delta\varphi = 0$ 时 $y = (A_1 + A_2)\cos(\omega t - kx)$——加强。
- **第三步，反相合成**：$\Delta\varphi = \pi$ 时 $y = (A_1 - A_2)\cos(\omega t - kx)$——减弱。
- **第四步，预告**：这个「相位差决定叠加结果」正是干涉（下一节）的核心——两列波的相位差来自路程差 $\Delta\varphi = k\Delta x$。<span class="marginnote">「相位差 → 路程差」是波动光学的基础：$\Delta\varphi = k\Delta x = 2\pi\Delta x/\lambda$。两列波从不同路径到达同一点，光程差 $\Delta x$ 决定相位差，相位差决定加强还是减弱——下一节波的叠加与干涉、以及第十六章双缝干涉，全都建立在这个 $2\pi\Delta x/\lambda$ 上。波函数在这里埋下了干涉的全部伏笔。</span>

**辨析｜易错点：**波函数中「$x$ 固定则相位随时间变、$t$ 固定则相位随位置变」——初相 $\varphi_0$ 是 $t=0$、$x=0$ 时的相位，不代表某点的相位。求两点间的相位差：$\Delta\varphi = k\Delta x$（沿传播方向，后点落后）。写波函数时，传播方向、初相、$k$ 与 $\omega$ 的取值互相牵连，先定传播方向再写 $\pm kx$。

## 8 术语速查表

| 术语 | 公式 | 要点 |
| --- | --- | --- |
| 平面简谐波 | $y = A\cos(\omega t - kx + \varphi_0)$ | 基本波函数 |
| 波数 | $k = 2\pi/\lambda$ | 空间频率 |
| 波速 | $u = \lambda\nu = \omega/k$ | 由介质决定 |
| 波形图 | 固定 $t$ | 看波长 |
| 振动图 | 固定 $x$ | 看周期 |
| 相位差 | $\Delta\varphi = k\Delta x$ | 干涉的伏笔 |

平面简谐波的波函数把「波」变成两个变量的函数：固定 $t$ 看波形、固定 $x$ 看振动，$u = \lambda\nu = \omega/k$ 连接空间与时间。波函数的相位结构（$\omega t - kx$）与相位差（$k\Delta x$）是理解能量、叠加与干涉的钥匙。下一节我们从波的形式转向波的携带物——**波的能量与能流密度**。

## 9 小结

- **平面简谐波**：波面为平面，各质点同频简谐振动；波函数是两个变量的函数。
- 波函数 $y = A\cos[\omega(t - x/u) + \varphi_0]$，可改写为 $\omega t - kx$、$t/T - x/\lambda$ 等形式。
- 沿 $+x$ 传播：相位落后，$kx$ 前取负号；沿 $-x$ 传播取正号。
- 波形图（固定 $t$，看波长）与振动图（固定 $x$，看周期）是同一波函数的两个切面。
- $u = \lambda\nu = \omega/k$；波速由介质定、频率由波源定、波长是二者之比。
