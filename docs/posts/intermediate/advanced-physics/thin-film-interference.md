## 为什么从薄膜干涉开始

为什么肥皂泡会闪着彩虹般的颜色？为什么水面浮着的一层油膜五彩斑斓？答案是**薄膜干涉（thin-film interference）**：光在薄膜上下表面反射，两束反射光相干叠加。这是「分振幅」干涉的典型——同一束光在界面上分成反射与透射两路，反射光路上光程差决定明暗。薄膜干涉不仅是日常色彩的原理，更是增透膜、增反膜（光学镜头）、干涉滤光片的核心技术。这一节推导薄膜干涉的光程差公式，掌握等倾与等厚两种类型。

## 1 薄膜干涉的形成

一束光射到折射率 $n$、厚度 $e$ 的薄膜上，在上下两个表面各发生一次反射与折射。上表面反射光（光线 1）与下表面反射光（光线 2）来自同一束光（同一波列），是相干光，相遇后干涉。

**薄膜干涉的两种类型**：

- **等倾干涉**：薄膜厚度均匀，干涉条纹由入射角决定（同一倾角同一明暗）；
- **等厚干涉**：入射角固定（平行光垂直入射），干涉条纹由薄膜厚度决定（同一条纹对应等厚度）。

<span class="marginnote">肥皂泡厚度不均匀——不同位置的薄膜厚度不同，同一角度下不同厚度处反射光干涉结果不同，加上白光各色波长的明暗条件不同，就呈现出流动的彩色。油膜同理。薄膜干涉是「看得见的波长测量」——条纹分布直接反映膜厚。</span>

## 2 薄膜干涉的光程差

考虑厚度 $e$、折射率 $n$ 的薄膜，周围介质折射率 $n_0$。平行光以入射角 $i$ 射入，折射角 $r$。上下表面两反射光的光程差（含半波损失）：

$$\delta = 2ne\cos r + \frac{\lambda}{2}$$

其中 $2ne\cos r$ 是几何光程差（下表面反射光多走的路程，折算光程），$\frac{\lambda}{2}$ 是**半波损失**（若存在）。

**重点：半波损失的处理是关键——数「几次反射有半波损失」。** 光从光疏到光密反射有半波损失（加 $\lambda/2$）。若上表面与下表面的反射都有（或都没有）半波损失，附加项抵消；若只有一个有，则附加 $\lambda/2$。<span class="marginnote">典型情形：薄膜在空气（$n_0 = 1$）中，$n > 1$。上表面：空气→膜（光疏→光密），有半波损失；下表面：膜→空气（光密→光疏），无半波损失。所以总共附加一个 $\lambda/2$。若薄膜夹在玻璃中间（两表面都从光疏到光密或都从光密到光疏），附加项抵消。</span>

## 3 垂直入射的薄膜干涉

垂直入射（$r = 0$，$\cos r = 1$），光程差简化为：

$$\delta = 2ne + \frac{\lambda}{2}$$

**明纹**：$2ne + \frac{\lambda}{2} = k\lambda$ → $2ne = (2k-1)\frac{\lambda}{2}$（膜厚为 $\lambda/4$ 的奇数倍）；
**暗纹**：$2ne + \frac{\lambda}{2} = (2k+1)\frac{\lambda}{2}$ → $2ne = k\lambda$（膜厚为 $\lambda/2$ 的整数倍）。

**重点：垂直入射时，薄膜的明暗由膜厚决定：膜厚 $= \frac{\lambda}{4}$ 的奇数倍是增反（亮），$\frac{\lambda}{2}$ 的整数倍是减弱（暗）。** 这就是增透膜/增反膜的设计依据。

### 增透膜与增反膜

- **增透膜**：让某波长反射最弱（暗纹），该波长透射最强。膜厚取 $ne = \frac{\lambda}{4}$（最小厚度）——此时上下表面反射光反相抵消，反射减弱、透射增强。相机镜头上的紫色反光正是增透膜残留的反射。
- **增反膜**：让某波长反射最强（明纹），膜厚取 $ne = \frac{\lambda}{2}$。

<span class="marginnote">增透膜设计的易错点就在「数半波损失」：对「空气-膜-玻璃」系统，上表面与下表面反射都有半波损失，两项抵消，光程差 $\delta = 2ne$，无附加项。反射最弱（增透）需 $\delta = \lambda/2$，故 $ne = \lambda/4$。若膜悬在空气中（仅一表面有半波损失），附加项 $\lambda/2$ 要保留，结论随之改变——必须先定介质次序，再数半波损失。</span>

**辨析｜易错点：增透膜的膜厚到底是 $\lambda/4$ 还是别的？** 关键看半波损失的数法。对「空气-膜-玻璃」系统：上表面（空气→膜）有半波损失，下表面（膜→玻璃，$n_{\text{玻璃}} > n_{\text{膜}}$）也有半波损失——两个半波损失抵消！光程差 $\delta = 2ne$，无附加项。要反射最弱（暗）：$2ne = \lambda/2$，即 $ne = \lambda/4$。**所以增透膜取 $ne = \lambda/4$ 的前提是「膜上下表面反射都有半波损失」（膜夹在两层更密介质之间）。** 题目先确认介质次序，再数半波损失——这是薄膜干涉最易失分之处。

## 4 公式解析：增透膜厚度

在玻璃（$n_g = 1.5$）上镀 $MgF_2$ 增透膜（$n = 1.38$），要增透波长 $\lambda = 550\ \text{nm}$（真空中）的光。求最小膜厚。

$$
ne = \frac{\lambda}{4} \quad\Longrightarrow\quad e = \frac{\lambda}{4n} = \frac{550}{4\times1.38}
$$

- **第一步，确认介质次序**：空气（1）→ 膜（1.38）→ 玻璃（1.5）。上表面反射：1→1.38，光疏→光密，有半波损失；下表面反射：1.38→1.5，光疏→光密，有半波损失——两个半波损失抵消。
- **第二步，写光程差**：$\delta = 2ne$（无附加项）。
- **第三步，求反射最弱条件**：$\delta = 2ne = \frac{\lambda}{2}$（最小膜厚对应第一级暗纹）。
- **第四步，解膜厚**：$e = \frac{\lambda}{4n} = \frac{550}{4\times1.38} \approx 99.6\ \text{nm} \approx 0.1\ \mu\text{m}$——镀膜厚度约 100 nm。

**辨析｜易错点：**公式里 $\lambda$ 是真空（或空气）中的波长，光在膜中的波长是 $\lambda/n$。光程 $ne$ 已把「膜中波长」折算成真空波长，所以膜厚公式直接带真空波长。审题时看清 $\lambda$ 是哪个介质的波长。

## 5 薄膜干涉的应用

- **增透膜 / 增反膜**：镜头镀膜减少反射（增透）、激光镜面增强反射（增反）；
- **干涉滤光片**：让特定波长透过/反射，用于光谱分析；
- **薄膜测厚**：由干涉条纹测量薄膜厚度（半导体工艺、光学镀膜质量控制）；
- **油膜/肥皂泡色彩**：白光中的自然薄膜干涉。

<span class="marginnote">薄膜干涉是「波长量级的厚度」才能观测到的现象：膜厚必须是波长的量级（几百纳米），否则光程差太大、相干性丧失。这也解释了为什么只有极薄的膜（肥皂泡、油膜、镀膜）才显色——厚膜的反射光已不相干。</span>

## 6 小结

- **薄膜干涉**：同一束光在薄膜上下表面反射，两反射光相干叠加（分振幅）。
- 光程差：$\delta = 2ne\cos r + \frac{\lambda}{2}$（半波损失项视介质次序而定）。
- 垂直入射：$\delta = 2ne + \frac{\lambda}{2}$；明暗由膜厚决定。
- **半波损失**：光疏→光密反射加 $\lambda/2$；两个表面都有或都没有则抵消。
- 增透膜 $ne = \lambda/4$（两表面均有半波损失时）；增反膜 $ne = \lambda/2$。
- 应用：镜头镀膜、干涉滤光片、薄膜测厚、肥皂泡色彩。
