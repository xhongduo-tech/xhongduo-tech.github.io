# 夸克模型与粒子物理标准模型初步

<div class="epigraph">

## 为什么从标准模型开始

20 世纪 60 年代，盖尔曼提出**夸克模型**，把上百种强子还原为几种夸克的组合——粒子物理从「动物园」变成了「化学」。在此基础上发展出的**粒子物理标准模型（Standard Model）**，把 12 种费米子 + 玻色子 + 希格斯机制装进一套量子场论框架，是迄今最成功的物理理论：每一项预言都被实验证实（包括 2012 年发现的希格斯玻色子）。这一节概述夸克模型与标准模型的基本框架，并讨论它的边界。

## 1 夸克模型

**夸克模型（quark model）**：强子由更基本的夸克组成。

- **夸克有 6 味**：u、d、c、s、t、b，带分数电荷（u/c/t 为 $+2/3e$，d/s/b 为 $-1/3e$）；
- **重子** = 3 个夸克（质子 uud、中子 udd）；
- **介子** = 夸克 + 反夸克（π⁺ = $u\bar{d}$）；
- **反夸克**：反粒子，电荷反号。

**重要对称性（SU(3) 味对称）**：u、d、s 三种夸克在强相互作用下近似对称（质量相近），把强子按「夸克内容」分类——盖尔曼的「八重法」预言了 Ω⁻ 粒子的存在与质量，被实验证实。

**重点：夸克模型把强子还原为夸克组合——重子（3 夸克）、介子（夸克-反夸克），电荷与量子数由夸克含量决定。** 夸克模型的成功预言（Ω⁻）让「夸克是真实粒子」被接受——尽管夸克从未被单独观测到（色禁闭）。<span class="marginnote">「色禁闭」：夸克带「色荷」（红、绿、蓝），强相互作用随距离增大而增强（不像电磁力减弱），所以夸克永远无法被分离出来——只能在强子内。高能碰撞中「裸夸克」会立即「强子化」成喷射（jet）的强子。色禁闭是量子色动力学（QCD）的核心谜题。</span>

## 2 标准模型的粒子清单

**标准模型（Standard Model）**的基本粒子：

**费米子（物质，12 种）**：

| 代 | 夸克（电荷） | 轻子（电荷） |
| --- | --- | --- |
| 第一代 | u（$+\frac{2}{3}$）、d（$-\frac{1}{3}$） | e（$-1$）、$\nu_e$（0） |
| 第二代 | c、s | μ、$\nu_\mu$ |
| 第三代 | t、b | τ、$\nu_\tau$ |

**玻色子（相互作用，5 种）**：光子（电磁）、胶子（强力，8 种）、W±/Z⁰（弱力）、**希格斯玻色子**（质量起源）。

**重点：标准模型 = 12 种费米子（3 代 × 4）+ 规范玻色子 + 希格斯玻色子——全部已知基本粒子。** 费米子构成物质、玻色子传递相互作用、希格斯玻色子赋予粒子质量。<span class="marginnote">「3 代费米子的结构」是标准模型的模板：每代 2 夸克 + 2 轻子，质量逐代增大（u < c < t 等）。为什么要 3 代？标准模型不回答——但宇宙学要求恰好 3 代（否则氦丰度不对）。这个「巧合」暗示标准模型之上还有更深的理论。</span>

## 3 希格斯机制

**希格斯机制（Higgs mechanism）**：粒子通过希格斯场获得质量。

- 整个宇宙充满**希格斯场**；
- 粒子与希格斯场相互作用（耦合）获得质量——耦合越强、质量越大；
- 希格斯场的量子激发就是**希格斯玻色子**（2012 年 LHC 发现，2013 年诺贝尔奖）。

**重点：希格斯机制解释「质量从哪来」——粒子通过与希格斯场耦合获得质量。** 光子不与希格斯场耦合（质量为零）；W/Z 玻色子强耦合（质量很大）；顶夸克耦合最强（质量最大）。希格斯玻色子的发现补齐了标准模型的最后一块拼图。

**辨析｜易错点：**「希格斯场给粒子质量」不是说「所有质量都来自希格斯」——质子等强子的质量约 99% 来自夸克的动能与胶子的能量（$E = mc^2$），只有约 1% 来自夸克自身的希格斯耦合质量。希格斯机制解释的是「基本粒子（夸克、轻子、W/Z）的裸质量」，复合粒子（强子）的质量另有来源。

## 4 标准模型的验证与预言

标准模型的预测与实验高度吻合：

- **W/Z 玻色子**（1983，CERN）；
- **顶夸克**（1995，费米实验室）；
- **希格斯玻色子**（2012，LHC）；
- 精细测量：电弱参数、反常磁矩（电子 $g-2$）、强耦合常数——都在极高精度上与标准模型一致。

**重点：标准模型是「迄今最精确的物理理论」——每一个粒子都被预言并被发现，每个数值预言都被实验证实。** 它是量子场论的典范：用规范对称性 + 希格斯机制统一了电磁、弱、强三种相互作用（引力除外）。

## 5 标准模型的局限与未来

标准模型并非终点：

- **不含引力**：引力无法纳入标准模型框架（需量子引力）；
- **暗物质/暗能量**：宇宙的 95% 是暗物质（27%）与暗能量（68%），标准模型完全不包含；
- **中微子质量**：标准模型预言中微子质量为零，实验却发现有微小质量（中微子振荡）；
- **物质-反物质不对称**：标准模型无法解释宇宙为何物质多于反物质；
- **三代结构的由来**：为何三代、质量为何如此，标准模型不解释。

<span class="marginnote">「标准模型的边界」也是新物理的入口：LHC 正在寻找超越标准模型的信号（超对称、额外维度、暗物质粒子）；中微子质量、暗物质、引力统一都是当代粒子物理与宇宙学的核心问题。标准模型不是终点，而是「已知的边界」——「从极限到大模型」的知识版图，在标准模型处既到达顶峰也望向未知。</span>

## 6 小结

- **夸克模型**：强子 = 夸克组合（重子 3 夸克、介子夸克-反夸克）；6 味夸克带分数电荷；色禁闭使夸克不单独存在。
- **标准模型**：12 种费米子（3 代）+ 规范玻色子（光子、胶子、W/Z）+ 希格斯玻色子。
- **希格斯机制**：粒子通过与希格斯场耦合获得质量；希格斯玻色子 2012 年发现。
- 标准模型预言全部被证实——最精确的物理理论（电磁 + 弱 + 强统一）。
- 局限：无引力、无暗物质/暗能量、中微子质量等——超越标准模型是当代前沿。
