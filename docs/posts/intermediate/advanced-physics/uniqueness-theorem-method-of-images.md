## 为什么从唯一性定理开始

静电边值问题：给定电荷分布与边界条件，求区域内的电势。这类问题通常很难直接解（泊松方程 + 复杂边界）。**唯一性定理**给出理论保障：满足边界条件的解是唯一的。有了它，我们可以**猜**一个解——只要它满足方程与边界条件，就一定是正确答案。**镜像法（method of images）**就是「猜解」的艺术：用假想的镜像电荷替代导体边界，把边值问题化为「无边界」的点电荷问题。这一节讲透唯一性定理与镜像法。

## 1 唯一性定理

**静电场的唯一性定理**：在给定区域内，若电荷分布已知，且边界上的电势（第一类边界条件，Dirichlet）或电势的法向导数（第二类边界条件，Neumann）已知，则区域内的电势唯一确定（至多差一个常数）。

**证明思路**：设有两个解 $\phi_1$、$\phi_2$，令 $\phi = \phi_1 - \phi_2$。$\phi$ 满足拉普拉斯方程 $\nabla^2\phi = 0$（边界上 $\phi = 0$ 或 $\partial\phi/\partial n = 0$）。利用格林第一恒等式：$\int_V\phi\nabla^2\phi\,\mathrm{d}V = \int_S\phi\frac{\partial\phi}{\partial n}\mathrm{d}S - \int_V|\nabla\phi|^2\mathrm{d}V$。左边为零（拉普拉斯），面积分为零（边界条件），故 $\int|\nabla\phi|^2\mathrm{d}V = 0$ ⟹ $\nabla\phi = 0$ ⟹ $\phi$ 为常数；配合边界条件得 $\phi = 0$——两解相同。

**重点：唯一性定理保证「满足边界条件的解只有一个」——这是所有猜解方法的理论依据。** 只要猜出的解满足泊松方程 + 边界条件，它就不可能是「错的另一个解」。<span class="marginnote">「唯一性定理解放了猜解」：镜像法、分离变量法、保角变换……所有「猜一个合适形式的解」的方法，都靠唯一性定理兜底——猜对了形式、验证了边界条件，答案就是真的。这就像「考卷只要答对就给分」：唯一性定理保证没有「答对但给错分」的可能。</span>

## 2 镜像法的基本思想

**镜像法（method of images）**：用一个（或多个）假想的**镜像电荷（image charge）**替代导体（或介质）边界对场的效应，使边值问题退化为「自由空间中的点电荷问题」。

**核心步骤**：

1. **判定**：问题含导体（或接地平面、球面），边界条件是等势面；
2. **放镜像电荷**：在导体「另一侧」放假想电荷，使它与真实电荷在边界处产生的合电势满足边界条件（导体表面等势/接地电势为零）；
3. **求解**：在真实电荷区域内，用「真实电荷 + 镜像电荷」的库仑叠加求电势/场；
4. **注意**：镜像电荷是假想的，只存在于「边界另一侧」的区域（它不在真实求解区域内）。

**重点：镜像法的核心——用边界另一侧的假想电荷「复现」边界条件，从而把问题变成自由空间的点电荷叠加。** 镜像电荷的位置与电量由边界条件确定（不是任意猜），关键要求「边界面上合电势满足边界条件」。

## 3 典型例子：接地导体平面上方的点电荷

点电荷 $q$ 距无限大接地导体平面 $d$。用镜像法求解。

**镜像设置**：在平面另一侧、距平面 $d$ 处放镜像电荷 $-q$（关于平面对称）。

**验证**：在导体平面上任一点，真实电荷与镜像电荷到场点距离相等（对称性），电势 $V = \frac{q}{4\pi\varepsilon_0r} + \frac{-q}{4\pi\varepsilon_0r} = 0$——满足接地平面电势为零的边界条件。唯一性定理保证这是正确解。

上半空间的电势：$V = \frac{q}{4\pi\varepsilon_0}\left(\frac{1}{r_+} - \frac{1}{r_-}\right)$（$r_\pm$ 到场点距离）；
导体表面的感应电荷面密度：$\sigma = -\frac{qd}{2\pi(x^2+y^2+d^2)^{3/2}}$；
**电荷与导体的吸引力**：等于电荷与镜像电荷间的库仑力 $F = \frac{q^2}{16\pi\varepsilon_0d^2}$（注意不是 $q^2/4d^2$ 的完整库仑，因为距离是 $2d$）。

**重点：接地平面的点电荷问题——镜像电荷 $-q$ 放在对称位置，边界条件（平面等势为零）自动满足。** 这是镜像法最经典的例子，也是「静电感应」问题的标准解。<span class="marginnote">「为什么用 $-q$ 和对称位置？」因为在平面上任一点，真实电荷与镜像电荷的距离总是相等（对称），只要电量等大反号，电势就抵消为零。镜像法的艺术在于「放多少、放哪」——由边界条件反推。平面（对称）、球面（按比例）、柱面（复杂）各有镜像规则。</span>

## 4 公式解析：镜像电荷与作用力

点电荷 $q = 1.0\times10^{-9}$ C 距接地导体平面 $d = 0.1$ m。求电荷所受的吸引力。

$$
F = \frac{q^2}{16\pi\varepsilon_0d^2} = \frac{(10^{-9})^2}{16\pi\times8.85\times10^{-12}\times(0.1)^2}
$$

- **第一步，写镜像设置**：镜像电荷 $-q$ 在平面另一侧距平面 $d$，真实电荷与镜像电荷相距 $2d$。
- **第二步，写库仑力**：$F = \frac{1}{4\pi\varepsilon_0}\frac{q^2}{(2d)^2} = \frac{q^2}{16\pi\varepsilon_0d^2}$。
- **第三步，代入**：$F = \frac{10^{-18}}{16\pi\times8.85\times10^{-12}\times0.01} = \frac{10^{-18}}{4.45\times10^{-12}} \approx 2.25\times10^{-7}\ \text{N}$。
- **第四步，解读**：吸引力约 $2.25\times10^{-7}$ N——电荷被「吸」向导体平面。这个力来自静电感应（电荷与感应电荷的吸引），镜像法把它化为「与镜像电荷的库仑力」。

**辨析｜易错点：**镜像电荷与真实电荷的距离是 $2d$（穿过平面），不是 $d$。镜像电荷是假想的（在真实求解区域外），计算上半空间场时用「真实 + 镜像」叠加，但**不能**在导体内部（下半空间）使用这个解（那里场为零或由导体决定）。镜像法的「电荷守恒」检查：感应电荷总量 $= -q$（验证积分）。

## 5 镜像法的应用与推广

- **接地导体平面 + 点电荷/线电荷**：镜像电荷等大反号、对称放置；
- **接地导体球 + 点电荷**：镜像电荷在球内特定位置，电量与球半径有关（$q' = -\frac{R}{d}q$，位置 $\frac{R^2}{d}$）——球面等势；
- **绝缘导体球（非接地）**：额外加一个球心电荷使总电荷正确；
- **导体平面 + 电偶极子**、**两个导体平面（直角）**：多个镜像电荷（角反射器）；
- **介质界面**：用镜像电荷处理两种介质的反射/透射。

<span class="marginnote">「镜像法的精神」：与其直接解带复杂边界的偏微分方程，不如用对称的假想源「构造」出满足边界的解——这是「猜解 + 唯一性定理」的典范。它体现了电动力学的实用智慧：问题往往有「巧解」，关键是找到合适的坐标与假想源。这种「构造解」的思想在量子力学（试探波函数）、热传导（镜像热源）中同样常见。</span>

## 6 小结

- **唯一性定理**：给定电荷分布与边界条件，电势唯一确定——猜解方法的理论依据。
- **镜像法**：用假想镜像电荷替代导体边界，把边值问题化为自由空间点电荷叠加。
- 接地平面 + 点电荷：镜像电荷 $-q$ 对称放置，平面等势为零自动满足。
- 作用力：$F = q^2/(16\pi\varepsilon_0d^2)$（等效库仑力，距离 $2d$）。
- 推广：导体球（$q' = -Rq/d$）、直角平面、介质界面。
