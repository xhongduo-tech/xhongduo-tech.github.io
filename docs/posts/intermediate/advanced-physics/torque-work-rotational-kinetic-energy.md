# 力矩做功与刚体定轴转动的动能

<div class="epigraph">

## 为什么从转动动能开始

平动的能量图景我们已经非常熟悉：力做功改变动能，保守力做功与势能挂钩，机械能守恒。转动完全可以平行移植这套图景，只要把「力 → 力矩」、「位移 → 角位移」、「质量 → 转动惯量」替换进去。转动动能 $E_k = \frac{1}{2}J\omega^2$ 与平动动能 $\frac{1}{2}mv^2$ 形式完全对应，力矩做功 $W = M\Delta\theta$ 与 $F\Delta x$ 完全对应。这一节把转动的能量体系建立起来，并把它与平动能量合流——这正是下一节《刚体的平面平行运动与纯滚动》里「滚下斜坡」问题的基础。

## 1 转动动能

绕定轴转动的刚体，各质元速度 $v_i = \omega r_i$，其动能之和为：

$$E_k = \sum_i \frac{1}{2}m_i v_i^2 = \frac{1}{2}\left(\sum_i m_i r_i^2\right)\omega^2 = \frac{1}{2}J\omega^2$$

**转动动能（rotational kinetic energy）**：$E_k = \frac{1}{2}J\omega^2$，与平动动能 $\frac{1}{2}mv^2$ 形式同构，其中 $J$ 扮演「转动质量」，$\omega$ 扮演「转动速度」。<span class="marginnote">这条公式说明：同样的角速度，转动惯量大的刚体携带更多动能——质量分布在边缘的飞轮（$J$ 大）比实心圆盘更能「储能」。飞轮储能装置正是利用这一点，把能量以转动动能的形式储存起来。</span>

## 2 力矩的功

力做功是 $W = \int \boldsymbol{F}\cdot\mathrm{d}\boldsymbol{s}$。对定轴转动，力的作用点沿圆弧运动，位移 $\mathrm{d}s = r\,\mathrm{d}\theta$，力沿切向的分量做正功：

$$W = \int F_t\,\mathrm{d}s = \int F_t \cdot r\,\mathrm{d}\theta = \int M\,\mathrm{d}\theta$$

其中 $M = F_t r$ 正是力矩。<span class="marginnote">力矩的功 $W = \int M\,\mathrm{d}\theta$：角位移相当于转动的「位移」，力矩相当于转动的「力」。若力矩恒定，则 $W = M\Delta\theta$。</span>

**重点：力沿径向的分量对转动不做功。** 只有力的切向分量（产生力矩）做功；沿半径方向的力要么产生形变（对刚体无意义），要么只是约束力——这解释了为什么向心力、绳的拉力、光滑轨道支持力在转动问题中都不做功。

## 3 转动的动能定理

把 $M = J\alpha$ 与 $W = \int M\,\mathrm{d}\theta$ 结合，可得到**转动的动能定理**：

$$W_{\text{合}} = \int M\,\mathrm{d}\theta = \frac{1}{2}J\omega_2^2 - \frac{1}{2}J\omega_1^2$$

推导：$M = J\alpha = J\dfrac{\mathrm{d}\omega}{\mathrm{d}t} = J\dfrac{\mathrm{d}\omega}{\mathrm{d}\theta}\cdot\omega$，故 $\int M\,\mathrm{d}\theta = \int J\omega\,\mathrm{d}\omega = \frac{1}{2}J\omega^2\big|_1^2$。

**转动的动能定理：合外力矩对刚体做的功，等于转动动能的增量。** 它与平动动能定理 $W = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$ 形式一致。刚体定轴转动中的能量问题，全部落在这条定理上：先算力矩做功，再看转动动能变化。

<span class="marginnote">转动动能定理同样有「力矩做正功 → 动能增加；做负功 → 动能减少」的直觉。制动器、飞轮刹车，本质上都是外力矩做负功，把转动动能耗散掉。</span>

## 4 公式解析：飞轮的储能

一个飞轮以角速度 $\omega$ 转动，转动惯量 $J$，求它能储存多少转动动能，以及以恒定功率 $P$ 输出时能供能多久。

$$
E_k = \frac{1}{2}J\omega^2
$$

- **第一步，写转动动能**：$E_k = \frac{1}{2}J\omega^2$。飞轮的 $J = \frac{1}{2}mR^2$（均质圆盘），故 $E_k = \frac{1}{4}mR^2\omega^2$。
- **第二步，代入数据**：设 $m = 100\ \text{kg}$，$R = 1.0\ \text{m}$，$\omega = 100\ \text{rad/s}$（约 955 转/分），则 $E_k = \frac{1}{4}\times100\times1^2\times10^4 = 2.5\times10^5\ \text{J}$。
- **第三步，算可持续时间**：若以 $P = 10\ \text{kW}$ 恒定功率输出（忽略损耗），$t = E_k/P = 2.5\times10^5/10^4 = 25\ \text{s}$。
- **第四步，体会物理**：转动动能随 $\omega^2$ 增长，提高转速比增大质量更划算；这也是飞轮储能、电动汽车动能回收的物理基础。

**辨析｜易错点：**「力矩做的功」不等于「力做的功」。一个力可能同时有平动效果与转动效果：例如斜拉绳子拉动轮子时，力的水平分量既使轮轴平动（若可动），又通过力矩使轮转动。计算时必须分开：平动看 $\int F\cos\theta\,\mathrm{d}s$，转动看 $\int M\,\mathrm{d}\theta$，两者不能混用同一套功。

## 5 转动能量与平动能量的对照

| 比较项 | 平动 | 转动 |
| --- | --- | --- |
| 动能 | $\frac{1}{2}mv^2$ | $\frac{1}{2}J\omega^2$ |
| 功 | $W = \int F\,\mathrm{d}s$ | $W = \int M\,\mathrm{d}\theta$ |
| 动能定理 | $W = \Delta(\frac{1}{2}mv^2)$ | $W = \Delta(\frac{1}{2}J\omega^2)$ |
| 功率 | $P = Fv$ | $P = M\omega$ |
| 保守性 | 保守力 → 势能 | 保守力矩 → 重力转动势能等 |

这张表再次印证「平动 ↔ 转动」的完整对应。特别地，**功率的转动形式 $P = M\omega$** 在电机、发动机问题中极常用：电机输出力矩 $M$、角速度 $\omega$，则机械功率 $P = M\omega$。

## 6 小结

- **转动动能**：$E_k = \frac{1}{2}J\omega^2$，与平动动能同构。
- **力矩做功**：$W = \int M\,\mathrm{d}\theta$，只有切向力分量做功，径向分量（向心力、拉力）不做功。
- **转动动能定理**：$W_{\text{合}} = \frac{1}{2}J\omega_2^2 - \frac{1}{2}J\omega_1^2$。
- **转动功率**：$P = M\omega$，电机与发动机问题的核心关系。
- 平动与转动的能量体系完全平行，「力 ↔ 力矩、位移 ↔ 角位移、质量 ↔ 转动惯量」是贯穿始终的类比线索。

在下一节，我们将把平动与转动合在一起，研究车轮、圆筒滚下斜坡这类**刚体的平面平行运动与纯滚动**问题——那里动能定理要同时计入平动与转动两部分。
