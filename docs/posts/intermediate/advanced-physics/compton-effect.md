# 康普顿效应

<div class="epigraph">

## 为什么从康普顿效应开始

光电效应证明光子有**能量**，但「光有粒子性」还差最后一块拼图：光子是否有**动量**？1923 年康普顿用 X 射线散射实验给出了答案——X 射线被电子散射后波长变长，这个「康普顿位移」只能用「光子与电子像台球一样碰撞」来解释。康普顿效应把光子当成有动量（$p = h/\lambda$）的粒子来处理，是光的粒子性最直接的证据，也是能量守恒与动量守恒在微观世界的教科书演示。这一节推导康普顿散射的波长位移公式。

## 1 康普顿散射实验

**康普顿效应（Compton effect）**：X 射线（高能光子）与物质中的自由电子碰撞散射后，散射 X 射线的波长比入射光长（能量降低）。

实验事实：

- 散射 X 射线波长变长（能量变小）；
- **波长位移 $\Delta\lambda = \lambda' - \lambda$ 只与散射角 $\theta$ 有关，与入射波长和散射物质无关**；
- 同一散射角下，还有一波长不变的散射光（与原子整体碰撞，质量大，波长几乎不变）。

**重点：康普顿位移 $\Delta\lambda$ 只由散射角决定，与入射波长、散射物质无关——这是粒子碰撞的特征。** 波长随散射角增大而增大（能量损失越多）。<span class="marginnote">经典波动论的解释失败：波被电子散射（汤姆孙散射）时，电子被驱动做受迫振动再辐射，频率与入射波相同——波长不变。实验却观测到波长变长。只有「光子-电子弹性碰撞」的粒子模型能解释：光子把一部分能量和动量交给电子，自己能量降低、波长变长。</span>

## 2 康普顿位移公式的推导

把光子当成粒子：光子能量 $E = h\nu$、动量 $p = h\nu/c = h/\lambda$，与静止电子（静质量 $m_0$）发生弹性碰撞。

由**能量守恒**与**动量守恒**：

- 能量：$h\nu + m_0c^2 = h\nu' + \sqrt{p_e^2c^2 + m_0^2c^4}$
- 动量（分量）：$h\nu/c = \frac{h\nu'}{c}\cos\theta + p_e\cos\phi$，$0 = \frac{h\nu'}{c}\sin\theta - p_e\sin\phi$

联立消去电子动量 $p_e$ 与散射角 $\phi$，得到**康普顿散射公式**：

$$\Delta\lambda = \lambda' - \lambda = \frac{h}{m_0c}(1 - \cos\theta)$$

**康普顿波长（Compton wavelength）**：$\lambda_C = \frac{h}{m_0c} = 2.43\times10^{-12}\ \text{m}$。

**重点：康普顿位移 $\Delta\lambda = \lambda_C(1-\cos\theta)$——正比于康普顿波长与 $(1-\cos\theta)$。** $\theta = 0$ 时位移为零（直穿），$\theta = 180°$（反散射）时位移最大（$2\lambda_C$）。康普顿波长 $\lambda_C = h/(m_0c)$ 是电子尺度的量子波长标尺。

**辨析｜易错点：**康普顿位移 $\Delta\lambda$ 是**波长**的变化（约 $10^{-12}$ m 量级），不是频率变化。对可见光，$\lambda \approx 500$ nm 远大于 $\lambda_C \approx 0.0024$ nm，相对位移极小（几乎测不到）；对 X 射线（$\lambda$ 接近 $\lambda_C$），位移显著——所以康普顿效应必须在 X 射线波段观察。判断「是否显著」看波长与康普顿波长的相对大小。

## 3 康普顿散射的物理图像

康普顿散射是「光子-电子弹性碰撞」：

- 入射光子能量 $h\nu$、动量 $h/\lambda$；
- 碰撞后光子以 $\theta$ 角散射（能量 $h\nu'$ 降低）、电子以 $\phi$ 角反冲（获得动能与动量）；
- 能量守恒、动量守恒精确成立——量子过程也遵守守恒律。

**重点：康普顿效应把光子当成有能量和动量的「粒子」来处理，守恒律精确成立——这是光的粒子性的最直接证据。** 光电效应只用了能量守恒（光子能量打电子），康普顿效应同时用能量与动量守恒（光子与电子弹性碰撞）——「光有动量」由此确立。<span class="marginnote">康普顿波长 $\lambda_C = h/(m_0c) \approx 0.00243$ nm 是基本常数，代表「光子动量与电子质量相当的波长标尺」。X 射线波长接近 $\lambda_C$ 时，光子与电子的碰撞效应显著；可见光波长远大于 $\lambda_C$，光子的动量太小，康普顿效应可忽略。这个「波长标尺」思想在物质波（德布罗意波长）中会再次出现。</span>

## 4 公式解析：康普顿位移的计算

X 射线波长 $\lambda = 0.1\ \text{nm}$ 被电子散射，散射角 $\theta = 90°$。求波长位移与散射光子能量。

$$
\Delta\lambda = \frac{h}{m_0c}(1 - \cos90°) = \lambda_C(1 - 0) = 2.43\times10^{-12}\ \text{m}
$$

- **第一步，写康普顿公式**：$\Delta\lambda = \lambda_C(1-\cos\theta)$，$\theta = 90°$ 时 $\cos\theta = 0$。
- **第二步，代入**：$\Delta\lambda = 2.43\times10^{-12}$ m = 0.00243 nm。
- **第三步，求散射光子能量**：$\lambda' = \lambda + \Delta\lambda = 0.1 + 0.00243 = 0.10243$ nm；入射光子能量 $E = hc/\lambda \approx 12.4$ keV，散射光子 $E' \approx 12.1$ keV。
- **第四步，解读**：光子能量损失约 0.3 keV（约 2.4%），损失的能量给了电子（反冲电子的动能）。波长位移虽小，但对 X 射线相对显著（约 2.4%）。

## 5 康普顿效应的应用与意义

- **医学与材料**：康普顿散射是 X 射线与物质相互作用的主要方式之一（诊断、辐射剂量评估）；
- **天文学**：逆康普顿散射（低能光子被高能电子散射获得能量）——宇宙微波背景辐射被星系团热电子散射（苏尼亚耶夫-泽尔多维奇效应），用于测星系团；X 射线天文学；
- **粒子探测**：康普顿相机/望远镜成像原理；
- **理论意义**：确立光子动量 $p = h/\lambda$，光的粒子性铁证，推动波粒二象性（第 100 节）与量子电动力学。

<span class="marginnote">「光子动量 $p = h/\lambda$」与「物质波 $\lambda = h/p$」（德布罗意，下下节）是同一个关系的两面：光有粒子动量，物质有波波长。康普顿效应确立了光子的动量，德布罗意把它推广到物质——波粒二象性的完整图景由此闭合。这个「对称的推广」是 20 世纪物理最美的思想跃迁之一。</span>

## 6 对照表：光电效应与康普顿效应

两者都是「光表现出粒子性」的实验证据，但层次不同：

| 比较项 | 光电效应 | 康普顿效应 |
| --- | --- | --- |
| 光子与谁的相互作用 | 束缚电子 | 自由（或弱束缚）电子 |
| 用了哪条守恒律 | 能量守恒 | 能量 + 动量守恒 |
| 关键结论 | 光子有能量 $E = h\nu$ | 光子有动量 $p = h/\lambda$ |
| 观测效应 | 电子逸出 | 散射光波长变长 |
| 经典理论可否解释 | 否（需爱因斯坦光子） | 否（汤姆孙散射预言波长不变） |

**辨析｜易错点：**两效应的区分常考：光电效应中光子能量整个交给电子（电子克服逸出功逃逸），康普顿效应中光子与电子「碰撞」后**并没有消失**，只是改变方向、降低能量。判断「谁更直接证明光有动量」——康普顿，因为它同时动用了动量守恒。

## 7 数值算例：反冲电子的能量

沿用第 4 节的算例：$\lambda = 0.1\ \text{nm}$、$\theta = 90°$。入射光子能量 $E = hc/\lambda \approx 12.4$ keV，散射光子 $E' = hc/\lambda' \approx 12.1$ keV，反冲电子获得动能：

$$E_e = E - E' = 12.4 - 12.1 = 0.3\ \text{keV}$$

约占总能量的 2.4%。进一步，反冲电子的动量可由动量守恒矢量图求出——入射光子动量沿 $x$ 轴，散射光子动量偏转 $90°$，电子的动量就是两者的矢量差，方向角 $\phi$ 满足 $\tan\phi = \dfrac{\sin\theta}{\lambda/\lambda' - \cos\theta}$。这就是「粒子碰撞」的完整图景：能量给了电子一部分，动量方向也如实转移。

<span class="marginnote">逆康普顿散射（inverse Compton scattering）是把康普顿机制反过来：低能光子撞上高能电子，光子被「踢」向更高能量。银河系里的宇宙微波背景光子被星系团热电子反复散射，波长移向 X 射线——这正是天文学家探测星系团气体温度的利器（苏尼亚耶夫-泽尔多维奇效应）。</span>

## 8 术语速查

- **康普顿波长 $\lambda_C$**：$h/(m_0c) \approx 2.43$ pm，衡量光子动量与电子质量相当的波长标尺。
- **汤姆孙散射**：经典理论下电子受迫振动再辐射的散射，预言波长不变。
- **反冲电子**：康普顿散射中获得能量与动量的电子。
- **逆康普顿散射**：低能光子被高能电子散射而获得能量的过程。
- **波长位移 $\Delta\lambda$**：散射前后光子波长的差，只与散射角有关。

## 9 小结

- **康普顿效应**：X 射线被自由电子散射，波长变长；位移只与散射角有关。
- **康普顿散射公式**：$\Delta\lambda = \frac{h}{m_0c}(1-\cos\theta)$；康普顿波长 $\lambda_C = h/(m_0c) \approx 2.43$ pm。
- 光子当作有能量、动量的粒子弹性碰撞电子；能量、动量守恒精确成立。
- 位移在 $\theta = 180°$ 最大（$2\lambda_C$），与入射波长无关；可见光下相对位移可忽略。
- 意义：光的粒子性铁证、确立光子动量 $p = h/\lambda$、催生波粒二象性。
