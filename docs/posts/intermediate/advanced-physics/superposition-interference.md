## 为什么从波的叠加开始

两列波在同一介质中相遇，会发生什么？如果波像台球一样「碰撞」，结果将无比复杂；但实际观察告诉我们：**两列波相遇后各自保持原样继续传播**，相遇处只是位移相加。这就是**波的叠加原理（superposition principle）**。当两列波频率相同、相位差恒定，叠加的结果不是一团乱麻，而是**稳定的强弱相间图样**——**干涉（interference）**。干涉是波动最独特的标志：声波的拍、水波的加强线、光的明暗条纹，全由此而来。机械波的干涉做好了，第十六章光学干涉就能轻装上阵。

## 1 波的叠加原理

**波的叠加原理**：几列波在同一介质中传播时，各自保持原有的特性（频率、波长、振幅、振动方向）独立传播；在相遇区域，任一质点的位移等于各列波单独引起的位移的矢量和。

$$y = y_1 + y_2$$

<span class="marginnote">「独立传播 + 位移相加」是线性波的签名。它意味着波与波之间不互相消耗、不产生新波——这与粒子碰撞截然不同。日常例证：嘈杂房间里能同时听清多人的声音，每道声音各自完整地传到耳中，就是叠加原理在起作用。</span>

**重点：叠加原理是近似，不是绝对真理。** 它的前提是介质对波的响应是线性的（位移小、形变在弹性范围）。振幅过大（如爆炸冲击波）时线性失效，会出现谐波、混频等非线性效应——那是物理学的另一片天地。课程范围内的波都满足线性条件。

## 2 相干条件与相干波

两列波叠加要产生**稳定的**干涉图样，必须满足**相干条件（conditions for coherence）**：

1. **频率相同**；
2. **振动方向相同**（或近似）；
3. **相位差恒定**（不随时间随机变化）。

满足这三个条件的波叫**相干波（coherent waves）**，其波源叫相干波源。若频率不同或相位差随机漂移，叠加只是强度相加，无稳定图样——这叫**非相干叠加**。

**辨析｜易错点：**「相位差恒定」是相干的核心。普通两个灯泡、两支蜡烛发出的光不满足相位差恒定，所以叠加不出明暗条纹；而同一光源分出的两束光（如双缝）相位差恒定，能干涉。光学的相干条件比机械波苛刻得多，第十六章再展开。

## 3 干涉加强、减弱条件

两相干波源 $S_1$、$S_2$ 在空间某点 $P$ 激起两列波，波程分别为 $r_1$、$r_2$，相位差：

$$\Delta\varphi = \frac{2\pi}{\lambda}(r_2 - r_1) + (\varphi_{20} - \varphi_{10})$$

若两波源初相相同（$\varphi_{20} = \varphi_{10}$），相位差只由**波程差** $\delta = r_2 - r_1$ 决定：

- **加强（相长干涉）**：$\delta = \pm k\lambda$（$k = 0,1,2,\dots$），$\Delta\varphi = 2k\pi$，合振幅 $A = A_1 + A_2$；
- **减弱（相消干涉）**：$\delta = \pm(2k+1)\frac{\lambda}{2}$，$\Delta\varphi = (2k+1)\pi$，合振幅 $A = |A_1 - A_2|$。

<span class="marginnote">「波程差 = 整数倍波长加强、半整数倍波长减弱」——这是干涉问题唯一需要记的核心判据。它从「相位差决定合振幅」的旋转矢量合成直接而来（第六章）。机械波干涉、双缝干涉、薄膜干涉全部共享这条判据。</span>

**重点：加强减弱看波程差，不看路程和。** 两列波从波源到观察点的距离差（波程差）才是决定相位差的关键。初相相同的两个波源，波程差每差一个波长，相位差就多 $2\pi$——振幅回摆一次加强。

## 4 公式解析：两个波源的干涉

两个同相波源 $S_1$、$S_2$ 相距 $d = 6\lambda$，在连线上 $S_1$ 外侧距 $S_1$ 为 $x$ 处取一点 $P$，求 $P$ 处干涉是加强还是减弱。

$$
\delta = r_2 - r_1 = (d + x) - x = d = 6\lambda
$$

- **第一步，写波程差**：$r_1 = x$，$r_2 = x + d$，$\delta = d = 6\lambda$。
- **第二步，判断**：$\delta = 6\lambda = k\lambda$，$k = 6$ 为整数，满足加强条件。
- **第三步，推广结论**：连线上波源外侧任意点，波程差恒等于 $d$——若 $d$ 为波长的整数倍，外侧处处加强；若为半整数倍，处处减弱。
- **第四步，体会**：这就是为什么两个同相波源连线的延长线上，会整段出现加强或减弱——干涉图样是空间里「波程差 = 常量」的等高线。

## 5 干涉的能量与强度分布

干涉区域的总能量守恒，但空间分布被重排：加强点强度大于两列波强度之和不可能？——不，干涉是**能量的空间重排**。对等振幅相干波，合强度：

$$I = I_1 + I_2 + 2\sqrt{I_1I_2}\cos\Delta\varphi$$

- 加强点：$I_{\max} = 4I_0$（$I_0$ 为单列波强度）——四倍而非两倍；
- 减弱点：$I_{\min} = 0$——完全抵消；
- 平均：$\overline{I} = 2I_0$——正好等于两列波强度之和。

**重点：干涉不违反能量守恒，它把能量「重新分配」。** 加强点强度的四倍来源于减弱点强度的为零，空间平均强度恰为各波强度之和。这个「干涉重排能量」的思想，在光学（第十六章）、乃至量子力学的概率干涉中一脉相承。<span class="marginnote">「平均不变、分布重排」是干涉最深刻的性质。量子力学里电子的双缝干涉同样如此：概率密度被重新分布，但总概率守恒。这个类比贯穿到第十八章波函数统计诠释。</span>

## 6 小结

- **叠加原理**：线性波独立传播、位移相加；成立前提是介质线性响应。
- **相干条件**：频率相同、振动方向相同、相位差恒定。
- 干涉判据（同相波源）：波程差 $\delta = k\lambda$ 加强，$\delta = (2k+1)\lambda/2$ 减弱。
- 合强度 $I = I_1 + I_2 + 2\sqrt{I_1I_2}\cos\Delta\varphi$；加强点 $4I_0$、减弱点 $0$、平均 $2I_0$。
- 干涉是能量空间重排，不违反能量守恒；与量子概率干涉同源。
