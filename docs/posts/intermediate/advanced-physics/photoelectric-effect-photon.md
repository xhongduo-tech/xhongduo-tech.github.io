## 为什么从光电效应开始

1887 年赫兹发现光照射金属表面会打出电子（光电效应），但它的实验规律处处与经典波动论矛盾。1905 年，爱因斯坦把普朗克的能量子思想推广到**光本身**：光由一个个**光子（photon）**组成，每个光子能量 $E = h\nu$。这个假说不仅完美解释光电效应，还第一次明确宣告光具有粒子性——为「波粒二象性」（第 100 节）奠基。光电效应也催生了太阳能电池、光电探测器、数码相机等无数技术。这一节讲透光电效应的规律与光子理论的解释。

## 1 光电效应的实验规律

**光电效应（photoelectric effect）**：光照射金属表面，金属中的电子吸收足够能量后逸出表面的现象。逸出的电子叫**光电子**，形成的电流叫光电流。

实验规律（四条）：

1. **饱和光电流正比于入射光强**（单位时间逸出电子数 ∝ 光强）；
2. **光电子最大初动能与光强无关，只与频率有关**——频率越高，初动能越大；
3. **存在截止频率（红限）$\nu_0$**：入射光频率低于 $\nu_0$ 时，无论光多强、照射多久，都不产生光电子；
4. **光电效应是瞬时的**：光照后立即产生光电子（延迟时间 < $10^{-9}$ s）。

<span class="marginnote">经典波动论的三条矛盾：① 光强代表能量，应该光越强电子动能越大——但实验说初动能与光强无关；② 波的能量是连续的、可积累的，低频率光照久应该能打出电子——但低于截止频率永远打不出；③ 能量积累需要时间，应该有延迟——但光电效应瞬时发生。经典理论对这三条完全无法解释。</span>

**重点：光电效应最反经典的三条规律——初动能与频率有关（非光强）、存在截止频率、瞬时响应。** 它们是光的粒子性的直接证据。

## 2 爱因斯坦光子理论

1905 年爱因斯坦提出：**光由光子（quantum of light / photon）组成，每个光子能量：**

$$E = h\nu$$

光照射金属时，一个光子被一个电子**一次性地**吸收，光子能量 $h\nu$ 一部分用于克服逸出功 $A$（电子脱离金属所需的最小功），剩余部分成为光电子的最大初动能。

**爱因斯坦光电效应方程**：

$$\frac{1}{2}mv_{\max}^2 = h\nu - A$$

其中 $A$ 是**逸出功（work function）**，由金属决定。

**重点：光电效应方程 $\frac{1}{2}mv_{\max}^2 = h\nu - A$——每个光子一次给电子 $h\nu$ 的能量，与光强无关。** 光强只决定光子**数量**（从而决定光电子数量/光电流），不决定单个光子能量（初动能）。这解释了「初动能看频率、光电流看光强」的实验规律。<span class="marginnote">「一个光子一次打出一个电子」是光电效应的核心图景：光子像「子弹」，一次碰撞交出一整份能量 $h\nu$。低于截止频率时 $h\nu < A$，光子能量不够逸出功，打不出电子——无论多少光子（多强光）都不行。这正是「光强无关」与「截止频率」的由来。</span>

**辨析｜易错点：光强、光子数与频率三者的关系。**一束光的光强（功率）$I = N\cdot h\nu$，其中 $N$ 是单位时间的光子数。增大光强可能是「增多光子数」，也可能是「提高频率」——前者增大光电流，后者增大光电子初动能。审题先分清题目调的是 $N$ 还是 $\nu$，再决定答案朝哪个方向：**光强是「数量×单价」的乘积，频率是「单价」，光子数是「数量」。**

## 3 截止频率与逸出功

由光电效应方程，当 $h\nu = A$ 时初动能为零——这就是**截止频率（红限）**：

$$\nu_0 = \frac{A}{h}$$

对应截止波长：$\lambda_0 = \frac{hc}{A}$。

**重点：截止频率 $\nu_0 = A/h$——频率低于 $\nu_0$ 的光无法产生光电子。** 逸出功 $A$ 越大，截止频率越高。不同金属的逸出功不同（铯约 1.9 eV、银约 4.7 eV），所以有些金属对可见光敏感（低逸出功）、有些只在紫外下才有光电效应。<span class="marginnote">逸出功的量级：金属的 $A$ 约 1–5 eV。对应截止频率在可见光-紫外区间。光电效应是「光子与单电子的能量交接」——这个「一锤子买卖」与经典波（能量连续分摊给所有电子）的本质区别，是理解光的粒子性的关键。</span>

**常见金属的逸出功与截止频率**

| 金属 | 逸出功 $A$（eV） | 截止频率 $\nu_0 = A/h$（×$10^{14}$ Hz） |
| --- | --- | --- |
| 铯 Cs | 1.9 | 4.6 |
| 钾 K | 2.2 | 5.3 |
| 钠 Na | 2.3 | 5.5 |
| 锌 Zn | 4.3 | 10.4 |
| 银 Ag | 4.7 | 11.4 |

银的截止频率在紫外区，所以银对可见光不敏感；铯的截止频率在红光区，对可见光敏感——这正是老式光电管阴极用碱金属（铯、钾）的原因。

## 4 公式解析：光电效应的计算

铯的逸出功 $A = 1.9\ \text{eV}$，用 $\lambda = 400\ \text{nm}$ 的紫光照射。求光子的能量、光电子的最大初动能与铯的截止频率。

$$
E = h\nu = \frac{hc}{\lambda} = \frac{6.63\times10^{-34}\times3\times10^8}{400\times10^{-9}} \approx 5\times10^{-19}\ \text{J} = 3.1\ \text{eV}
$$

- **第一步，算光子能量**：$E = hc/\lambda = 3.1$ eV（1 eV = $1.6\times10^{-19}$ J）。
- **第二步，写光电效应方程**：$\frac{1}{2}mv_{\max}^2 = E - A = 3.1 - 1.9 = 1.2\ \text{eV}$。
- **第三步，求截止频率**：$\nu_0 = A/h = \frac{1.9\times1.6\times10^{-19}}{6.63\times10^{-34}} \approx 4.6\times10^{14}\ \text{Hz}$——对应波长约 650 nm（红光区），低于此频率的光（红橙光）打不出铯的光电子。
- **第四步，解读**：紫光（400 nm）能量 3.1 eV > 逸出功 1.9 eV，打出电子（动能为 1.2 eV）；红光（700 nm，约 1.8 eV）能量低于逸出功，无光电子。

**算例：求光电子速度。**承接上例（铯，$A = 1.9$ eV，$\lambda = 400$ nm），光电子最大初动能 1.2 eV = $1.92\times10^{-19}$ J，由 $\frac{1}{2}mv^2 = E_k$ 得：

$$v = \sqrt{\frac{2E_k}{m}} = \sqrt{\frac{2\times1.92\times10^{-19}}{9.1\times10^{-31}}} \approx 6.5\times10^5\ \text{m/s}$$

约为光速的 0.2%。电子带着这个速度飞向集电极形成光电流——「光子给能量、电子跑路」的完整链条就此闭环。

**辨析｜易错点：**「光子能量」与「光电子动能」是两个量：光子能量 $h\nu$ 是入射能量，光电子最大初动能 $= h\nu - A$（扣掉逸出功）。题目问「最大初动能」一定要减 $A$；问「光子能量」直接用 $h\nu$ 或 $hc/\lambda$。单位 eV 与 J 的换算（1 eV = $1.6\times10^{-19}$ J）是高频错误源。

## 5 光电效应的应用

- **太阳能电池（光伏效应）**：光子打出的电子-空穴对被电场分离，产生电流——光伏发电；
- **光电二极管/光电管**：光信号 → 电信号，用于自动门、照度计、光通信接收；
- **数码相机/CCD/CMOS**：每个像素是一个微型光电探测器，光子转化为电荷；
- **光电倍增管**：微弱光信号放大，用于天文、医疗、粒子探测；
- **光电子能谱**：测量光电子动能推断材料电子结构（分析化学与表面科学）。

**经典波动论 vs 光子理论对照**

| 实验规律 | 经典波动论预言 | 光子理论解释 |
| --- | --- | --- |
| 初动能与光强无关 | 错（预言光强越大动能越大） | 对（光子能量 $h\nu$ 与光强无关） |
| 存在截止频率 | 错（预言任意频率累积能量都能逸出） | 对（$h\nu < A$ 打不出电子） |
| 瞬时响应 | 错（预言能量积累有延迟） | 对（光子一次交接，瞬时） |

这张表把「为什么光电效应是光的粒子性铁证」压缩成三行：经典波动论对三条规律全错，光子理论全对。

<span class="marginnote">「光电效应 ÷ 光伏效应」：光电效应是「光子打出电子」，光伏效应是「光子激发电子-空穴对并分离」——物理同源（光子激发电子），工程实现不同。太阳能电池的光谱响应由半导体带隙决定（类似逸出功的角色）。现代光伏产业把「爱因斯坦 1905 年的论文」变成了万亿瓦级的清洁能源——基础物理到技术的惊人转化。</span>

## 6 小结

- **光电效应**：光照射金属打出光电子；光电流 ∝ 光强、初动能与频率有关、有截止频率、瞬时发生。
- **光子理论**：光由光子组成，$E = h\nu$；一个光子一次性被一个电子吸收。
- **光电效应方程**：$\frac{1}{2}mv_{\max}^2 = h\nu - A$。
- **截止频率**：$\nu_0 = A/h$——低于它无光电子，与光强无关。
- 光强决定光子数量（光电流），频率决定光子能量（初动能）。
- 应用：太阳能电池、光电探测器、CCD、光电倍增管。
