## 为什么从平面平行运动开始

此前我们处理的是两种极端：纯平动（整个刚体一起移动）和定轴转动（转轴固定）。但日常里最常遇到的刚体运动——车轮在路上滚、圆筒滚下斜坡、汽车过弯——是两者**同时发生**的：轮子在转，轮轴也在前进。这种运动叫**平面平行运动（plane motion）**。它有一个精妙的特征：当刚体在表面上「纯滚动」时，接触点瞬时静止，于是「滑动摩擦」变成了「静摩擦」，摩擦力不做功。理解这一点，是解开无数滚动问题的钥匙。

## 1 平面平行运动的分解

**平面平行运动**：刚体上所有点都在平行于某一固定平面的平面内运动。任一瞬时，它都可以分解为**随质心的平动**与**绕质心轴的转动**。

对刚体上任一点 $P$，速度为：

$$\boldsymbol{v}_P = \boldsymbol{v}_C + \boldsymbol{\omega}\times\boldsymbol{r}_{CP}$$

即质心平动速度与绕质心转动速度的矢量叠加。<span class="marginnote">「平面平行运动 = 质心平动 + 绕质心转动」是沙勒定理（Chasles' theorem）的平面特例。质心作为参考点是关键选择：它让「平动部分」和「转动部分」的能量、动量可以干净地相加而不纠缠。</span>

### 动能与动力学方程

平面平行运动的动能由两部分组成：

$$E_k = \frac{1}{2}mv_C^2 + \frac{1}{2}J_C\omega^2$$

其中 $J_C$ 是绕质心轴的转动惯量。动力学方程也分为两组：质心平动用牛顿第二定律，绕质心转动用转动定律：

$$ma_C = \sum \boldsymbol{F}, \qquad J_C\alpha = \sum M_C$$

**重点：绕质心的转动方程成立，与质心的运动无关。** 这是刚体力学的核心结论——质心像「独立」的质点一样运动，而绕质心的转动则像一个独立的定轴转动。两组方程互相独立、互不干扰，这是刚体力学最优雅的结构。

## 2 纯滚动的条件

**纯滚动（pure rolling / rolling without slipping）**：刚体与支撑面接触点相对地面瞬时静止，没有相对滑动。

纯滚动的运动学条件是：**质心平动速度等于转动速度的切向分量**：

$$v_C = \omega R$$

对时间求导得：$a_C = \alpha R$。<span class="marginnote">直觉理解：轮子滚一圈，质心前进 $2\pi R$。于是 $\omega = v_C/R$ 是纯滚动最核心的约束——它把「转动角速度」与「质心平动速度」绑定成一个量，自由度少了一个。</span>

若 $v_C > \omega R$ 或 $v_C < \omega R$，轮子就在「打滑」：前者是急刹车时车轮抱死滑行，后者是起步时车轮空转。**纯滚动时接触点处是静摩擦（不做功），一旦打滑就变成滑动摩擦（做负功、耗能）。**

**辨析｜易错点：静摩擦力方向不能凭空假设。**滚下斜坡时静摩擦力沿斜面**向上**——它给质心提供减速力、给转动提供加速力矩；但汽车驱动轮在牵引下前进时，静摩擦力方向**向前**（它推动车子前进）。同一个「静摩擦力」，方向取决于运动状态与受力安排，必须由动力学方程解出，而不是先入为主地假定。

## 3 纯滚动物体的能量问题

滚下斜面的圆柱是最经典的例子。圆柱质量 $m$、半径 $R$、绕质心转动惯量 $J_C = \frac{1}{2}mR^2$，从斜面顶无初速纯滚动，滚下高度 $h$。由机械能守恒：

$$mgh = \frac{1}{2}mv_C^2 + \frac{1}{2}J_C\omega^2$$

结合纯滚动约束 $v_C = \omega R$ 与 $J_C = \frac{1}{2}mR^2$：

$$mgh = \frac{1}{2}mv_C^2 + \frac{1}{2}\cdot\frac{1}{2}mR^2\cdot\frac{v_C^2}{R^2} = \frac{1}{2}mv_C^2 + \frac{1}{4}mv_C^2 = \frac{3}{4}mv_C^2$$

解得 $v_C = \sqrt{\frac{4}{3}gh}$。<span class="marginnote">对比：若同一圆柱光滑滑下（不滚），$v = \sqrt{2gh}$。滚动比分位移更快到达底部——因为一部分重力势能转化为转动动能。转动惯量越大，分配到转动的能量越多，质心速度越慢。实心球、圆筒、圆环滚下同一斜面，快慢不同：实心球最快，圆环最慢。</span>

**算例：** 一实心圆柱从 $h = 1.5$ m 的斜面顶无初速纯滚动滚下，求底部质心速度。$v_C = \sqrt{\frac{4}{3}gh} = \sqrt{\frac{4}{3}\times9.8\times1.5} \approx \sqrt{19.6} \approx 4.4$ m/s。对比同一圆柱光滑滑下，$v = \sqrt{2gh} \approx 5.4$ m/s——滚动慢一些，但接触点无滑动、不发热，能量全部留在可回收的平动与转动里，这正是车轮设计的着眼点。

**不同形状滚下同一斜面的末速度**

| 形状 | 绕质心转动惯量 $J_C$ | 质心末速度 $v_C = \sqrt{\dfrac{2gh}{1 + J_C/(mR^2)}}$ |
| --- | --- | --- |
| 实心球 | $\frac{2}{5}mR^2$ | $\sqrt{\frac{10}{7}gh}$ |
| 实心圆柱 | $\frac{1}{2}mR^2$ | $\sqrt{\frac{4}{3}gh}$ |
| 薄壁圆筒 | $mR^2$ | $\sqrt{gh}$ |

比值 $J_C/(mR^2)$ 越大，分配到转动的能量越多、质心越慢。薄壁圆筒把质量都放在轮缘，所以最慢；实心球质量靠中心，最快——这就是「为什么同高度滚下来，球总赢圆柱、圆柱总赢圆筒」。

**重点：为什么摩擦力没做功？** 纯滚动时接触点瞬时静止，静摩擦力的作用点没有位移，所以静摩擦力不做功——重力势能全部转化为平动动能与转动动能之和，机械能守恒成立。一旦进入滑动状态，滑动摩擦力做负功，机械能守恒就不成立了。

## 4 公式解析：滚下斜面的加速度

用力学方法（而非能量方法）重做滚下斜面问题，求质心加速度。设斜角 $\theta$，静摩擦力 $f$ 沿斜面向上。

$$
mg\sin\theta - f = ma_C, \qquad fR = J_C\alpha, \qquad a_C = \alpha R
$$

- **第一步，质心平动方程**：沿斜面方向，重力分量 $mg\sin\theta$ 向下，静摩擦 $f$ 向上，$mg\sin\theta - f = ma_C$。
- **第二步，转动方程**：静摩擦力对质心的力矩为 $fR$，由转动定律 $fR = J_C\alpha$。
- **第三步，纯滚动约束**：$a_C = \alpha R$，把 $\alpha$ 换成 $a_C/R$。
- **第四步，联立消去 $f$**：代入 $J_C = \frac{1}{2}mR^2$，得 $f = \frac{J_C a_C}{R^2} = \frac{1}{2}ma_C$，于是 $mg\sin\theta - \frac{1}{2}ma_C = ma_C$，解得 $a_C = \frac{2}{3}g\sin\theta$。

**辨析｜易错点：**纯滚动问题里最常犯的错是「把静摩擦力当成滑动摩擦力来求」。静摩擦力的大小由动力学方程决定（这里 $f = \frac{1}{2}ma_C = \frac{1}{3}mg\sin\theta$），而非 $\mu N$；只有在打滑时 $f$ 才等于 $\mu N$。另一常见错误是忘记「纯滚动约束 $a_C = \alpha R$」是第四个独立方程，少一个约束方程就会解不出。

还有一个隐含假设：斜面必须足够粗糙以维持纯滚动。若所需静摩擦超过了最大静摩擦 $\mu_sN$，轮子就会打滑，此时 $v_C > \omega R$、能量解失效，必须退回滑动摩擦。判断「能否纯滚动」的标准，就是比较「动力学解出的 $f$」与「$\mu_sN$」的大小。

## 5 纯滚动的能量解法与力学解法对照

| 方法 | 优点 | 缺点 |
| --- | --- | --- |
| 能量法（机械能守恒） | 无需算摩擦力，直接得末态速度 | 得不到加速度、摩擦力 |
| 力学法（质心平动 + 转动） | 得加速度、摩擦力、各约束力 | 方程多、代数繁琐 |

**重点：求速度用能量法，求加速度与摩擦力用力学法。** 两类方法各有分工，配合使用是解刚体平面运动问题的标准姿势。能量法里「静摩擦不做功」是机械能守恒成立的前提，力学法里「$a_C = \alpha R$」是纯滚动的运动学锁链，两者互为补充。

工程上，火车轮与钢轨靠「踏面锥度」的几何设计自动维持纯滚动——左右轮踏面做成微锥形，弯道时外轮滚大半径、内轮滚小半径，无需滑移就能转向。这是「纯滚动约束」在轮轨系统里最精妙的工程落地。

## 6 小结

- **平面平行运动** = 质心平动 + 绕质心转动；$E_k = \frac{1}{2}mv_C^2 + \frac{1}{2}J_C\omega^2$。
- 动力学两组方程独立：$ma_C = \sum F$、$J_C\alpha = \sum M_C$。
- **纯滚动**：$v_C = \omega R$、$a_C = \alpha R$；接触点瞬时静止，静摩擦不做功。
- 滚下斜面：$v_C = \sqrt{\frac{4}{3}gh}$（实心圆柱），转动惯量越大质心越慢。
- 能量法求速度、力学法求力与加速度；打滑时摩擦做负功，机械能不守恒。
- 静摩擦方向由动力学方程解出、不能凭空假设；能否纯滚动要看所需静摩擦是否超过最大静摩擦。
