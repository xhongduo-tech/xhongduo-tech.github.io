# 简谐振动的运动学描述

<div class="epigraph">

## 为什么从简谐振动开始

力学研究到第五章，我们处理的都是「单向」的运动：抛体、圆周、流动。但从钟摆到琴弦，从地震波到交流电，从分子的热振动到光的电磁振荡，世界充满了**周期性的往复运动**——振动。而在所有振动中，**简谐振动（simple harmonic motion）**是最基本的一种：它的位移是时间的正弦（或余弦）函数。它之所以重要，一方面因为弹簧振子、单摆小角度摆动、LC 振荡都是简谐振动；另一方面因为**任意复杂的周期性振动都可以分解为一系列简谐振动的叠加**——这正是下一章《机械波》与傅里叶思想的伏笔。

## 1 简谐振动的动力学定义

考虑轻弹簧（劲度系数 $k$）连着一个质量 $m$ 的滑块，在光滑水平面上振动。取平衡位置为原点 $O$，滑块偏离原点的位移为 $x$。由胡克定律，弹力 $F = -kx$ 与位移方向相反，代入牛顿第二定律：

$$m\frac{\mathrm{d}^2x}{\mathrm{d}t^2} = -kx \quad\Longrightarrow\quad \frac{\mathrm{d}^2x}{\mathrm{d}t^2} + \frac{k}{m}x = 0$$

令 $\omega_0^2 = \frac{k}{m}$，得到简谐振动的微分方程：

$$\frac{\mathrm{d}^2x}{\mathrm{d}t^2} + \omega_0^2 x = 0$$

**简谐振动（SHM）**：回复力与位移成正比且反向（$F = -kx$）的运动。<span class="marginnote">「回复力」是指向平衡位置的力，总想把物体拉回平衡点。$F = -kx$ 是简谐振动的动力学特征：力与位移成线性、方向相反。这个「线性回复力」一旦成立，运动必然是正弦/余弦型的。</span>

微分方程的解是：

$$x = A\cos(\omega_0 t + \varphi)$$

其中 $A$ 是**振幅**，$\omega_0$ 是**角频率**（固有角频率），$\varphi$ 是**初相**。

## 2 简谐振动的三个特征量

描述一次简谐振动需要三个量：

- **振幅 $A$（amplitude）**：离开平衡位置的最大位移，恒为正值，由初始能量决定。
- **角频率 $\omega_0$（angular frequency）**：由系统自身性质（$k$ 与 $m$）决定，$\omega_0 = \sqrt{k/m}$，与振幅无关。
- **初相 $\varphi$（initial phase）**：决定 $t = 0$ 时刻物体在何处、朝哪个方向运动。

由角频率派生**周期**与**频率**：

$$T = \frac{2\pi}{\omega_0} = 2\pi\sqrt{\frac{m}{k}}, \qquad \nu = \frac{1}{T} = \frac{1}{2\pi}\sqrt{\frac{k}{m}}$$

**重点：固有角频率 $\omega_0$ 只由系统本身决定，与振幅、初始条件无关。** 弹簧硬（$k$ 大）、质量轻（$m$ 小），振动就快。无论你把弹簧拉得多远释放，振动的「节拍」都一样——这是简谐振动的等时性，也是摆钟走时准确的前提。<span class="marginnote">单摆在小角度下也近似简谐振动：$T = 2\pi\sqrt{l/g}$。伽利略据教堂吊灯摆动提出「摆的等时性」，惠更斯据此发明摆钟——简谐振动从一开始就与计时紧密相连。</span>

## 3 位移、速度与加速度的关系

由 $x = A\cos(\omega_0 t + \varphi)$ 对时间求导：

$$\begin{aligned}
v &= \frac{\mathrm{d}x}{\mathrm{d}t} = -A\omega_0\sin(\omega_0 t + \varphi) = A\omega_0\cos\left(\omega_0 t + \varphi + \frac{\pi}{2}\right) \\
a &= \frac{\mathrm{d}^2x}{\mathrm{d}t^2} = -A\omega_0^2\cos(\omega_0 t + \varphi) = -\omega_0^2 x
\end{aligned}$$

三个重要特征：

- **速度比位移领先 $\pi/2$，加速度比位移领先 $\pi$**（即与位移反向）。位移最大时速度为零、加速度最大（指向平衡位置）；位移为零（过平衡位置）时速度最大、加速度为零。
- 速度幅值 $v_{\max} = A\omega_0$，加速度幅值 $a_{\max} = A\omega_0^2$。
- 加速度始终与位移**方向相反**，这是「回复」性质的直接体现。<span class="marginnote">记住这个相位关系，很多简谐振动图像题就能直接读出：位移最大处速度为零、加速度最大；平衡位置速度最大、加速度为零。相当于「位移、速度、加速度」三个波形依次错开四分之一周期。</span>

## 4 公式解析：由初始条件确定运动方程

做简谐振动的物体，$t = 0$ 时位移 $x_0 = A/2$，速度为正，角频率 $\omega_0$ 已知。求初相 $\varphi$ 并写出运动方程。

$$
x = A\cos(\omega_0 t + \varphi), \qquad v = -A\omega_0\sin(\omega_0 t + \varphi)
$$

- **第一步，代入初位移**：$x(0) = A\cos\varphi = A/2$，得 $\cos\varphi = 1/2$，$\varphi = \pm\frac{\pi}{3}$——两个候选值。
- **第二步，用初速度定号**：$v(0) = -A\omega_0\sin\varphi$。速度为正，故 $\sin\varphi < 0$，取 $\varphi = -\frac{\pi}{3}$。
- **第三步，写出运动方程**：$x = A\cos\left(\omega_0 t - \frac{\pi}{3}\right)$。
- **第四步，检验图像直觉**：$t=0$ 时物体在 $A/2$ 处且正向运动（向 $x$ 增大方向移动），与 $\varphi = -\pi/3$ 对应的余弦曲线吻合。

**辨析｜易错点：**「由初位移定 $\varphi$」只能得到「模」，必须再用初速度（或加速度）的符号剔除错误的解。这是初相确定中的经典陷阱——只用了 $x_0$ 而忽略 $v_0$ 的符号，会得到两个相位相差 $\pi$ 的错误答案。

## 5 简谐振动的图像与能量视角

$x$–$t$ 图像是一条余弦（或正弦）曲线：在 $x = A$ 与 $x = -A$ 之间往复，过平衡位置时斜率最陡（速度最大）。从能量看：

$$E = \frac{1}{2}kA^2 = \frac{1}{2}mv^2 + \frac{1}{2}kx^2$$

总机械能守恒，且正比于振幅平方。振动过程中动能与弹性势能不断转化：平衡位置动能最大、势能为零；端点处动能为零、势能最大。<span class="marginnote">振动能量与振幅平方成正比 $E \propto A^2$，这是一个重要事实：声音的响度、光的强度、波的能流密度，背后都是「振幅的平方」——这一结论在第七章《机械波》会再次出现。</span>

**重点：简谐振动是「运动学特征」与「能量特征」的统一。** 运动学上满足 $x = A\cos(\omega t+\varphi)$，动力学上满足 $F = -kx$，能量上满足 $E = \frac{1}{2}kA^2$——三条线索指向同一种运动，任一条成立即可判断简谐振动。

## 6 小结

- **简谐振动**：线性回复力 $F = -kx$ 决定的运动，$x = A\cos(\omega_0 t+\varphi)$。
- 微分方程：$\ddot{x} + \omega_0^2 x = 0$，$\omega_0 = \sqrt{k/m}$；周期 $T = 2\pi\sqrt{m/k}$。
- 特征量：振幅 $A$（初能量）、角频率 $\omega_0$（系统固有）、初相 $\varphi$（初始条件）。
- 位移、速度、加速度相位依次差 $\pi/2$；$v_{\max} = A\omega_0$，$a_{\max} = A\omega_0^2$。
- 能量：$E = \frac{1}{2}kA^2$ 守恒，动能与势能往复转化。
- 单摆小角度 $T = 2\pi\sqrt{l/g}$，是摆钟计时的物理基础。
