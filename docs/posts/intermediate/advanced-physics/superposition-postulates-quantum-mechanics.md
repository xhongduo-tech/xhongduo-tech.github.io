## 为什么从基本假设开始

第十八章我们接触了量子力学的现象（波粒二象性、波函数、薛定谔方程），但还没有把它整理成自洽的公理体系。这一节把量子力学提炼为**几条基本假设**——从「态的描述」到「力学量的算符」到「测量与演化」——构成完整框架。**态叠加原理**是其中最核心的一条：量子态可以叠加，叠加产生干涉。这一节为后续的算符、本征值、微扰、绘景打下公理基础。

## 1 量子力学的基本假设

量子力学的公理化表述包含五条基本假设：

**假设一（态的描述）**：量子系统的状态由希尔伯特空间中的**态矢量** $|\psi\rangle$（或波函数 $\psi$）完全描述。

**假设二（力学量的算符）**：每个可观测力学量 $A$ 对应一个**厄米算符** $\hat{A}$（本征值为实数）。

**假设三（测量与本征值）**：测量力学量 $A$，只能得到 $\hat{A}$ 的本征值；测量后系统塌缩到对应的本征态。

**假设四（演化）**：态矢量的时间演化由薛定谔方程 $i\hbar\frac{\partial|\psi\rangle}{\partial t} = \hat{H}|\psi\rangle$ 决定。

**假设五（概率诠释）**：系统处于态 $|\psi\rangle$ 时，测量 $A$ 得到本征值 $a_n$ 的概率 $= |\langle a_n|\psi\rangle|^2$（玻恩规则）。

**重点：量子力学的五条假设——态矢量描述、算符对应、测量塌缩、薛定谔演化、玻恩概率。** 它们构成量子力学的公理体系：态（假设一）、力学量（假设二）、测量（假设三、五）、演化（假设四）。<span class="marginnote">「假设的层次」：前两条定义「数学结构」（希尔伯特空间 + 算符），三、五定义「测量规则」（本征值 + 概率），四定义「时间演化」。测量塌缩（假设三）是量子力学最受争议的部分——它与薛定谔演化（假设四）的张力（测量问题）至今是量子力学基础的开放问题。</span>

## 2 态叠加原理

**态叠加原理（superposition principle）**：若 $|\psi_1\rangle$、$|\psi_2\rangle$ 是系统的可能状态，则任意线性叠加 $|\psi\rangle = c_1|\psi_1\rangle + c_2|\psi_2\rangle$ 也是系统的可能状态。

叠加是**态矢量**的叠加（概率幅相加），不是概率相加；
测量时概率 $|\langle a|\psi\rangle|^2 = |c_1\langle a|\psi_1\rangle + c_2\langle a|\psi_2\rangle|^2$ 含**干涉项**；
干涉项 $2\text{Re}(c_1c_2^*\langle a|\psi_1\rangle^*\langle a|\psi_2\rangle)$ 是量子干涉的代数来源。

**重点：态叠加原理——量子态可叠加，叠加的后果是概率幅的干涉（不是概率的简单相加）。** 这是量子力学与经典概率的本质区别：经典混合态（概率相加）vs 量子叠加态（幅度相加、产生干涉）。双缝实验、薛定谔的猫、量子比特都建立在态叠加之上。<span class="marginnote">「叠加 vs 混合」：量子叠加态 $|\psi\rangle = c_1|\psi_1\rangle + c_2|\psi_2\rangle$（相干，可干涉）与经典混合（各态按概率 $|c_1|^2$、$|c_2|^2$ 混合，无干涉）完全不同。干涉项的存在是量子信息的资源——量子比特（qubit）正是一个二能级叠加态，量子计算的威力来自叠加与纠缠。</span>

**叠加态与混合态的对照表**：

| 对比项 | 量子叠加态 | 经典混合态 |
| --- | --- | --- |
| 数学描述 | 态矢量 $c_1\|\psi_1\rangle + c_2\|\psi_2\rangle$ | 概率分布 $(p_1, p_2)$ |
| 概率规则 | 幅相加后取模方，含交叉项 | 概率直接相加，无交叉项 |
| 是否相干 | 相干（有确定相对相位） | 不相干（相位信息已丢失） |
| 物理例子 | 双缝干涉、量子比特 | 抛硬币、经典统计 |
| 测量表现 | 干涉条纹随相对相位移动 | 无干涉、强度简单叠加 |

**辨析｜易错点：**对叠加态测量 $A$，得到本征值 $a_n$ 的概率是 $|\langle a_n|\psi\rangle|^2 = |c_1\langle a_n|\psi_1\rangle + c_2\langle a_n|\psi_2\rangle|^2$；而对混合态（以概率 $p_1$ 处于 $|\psi_1\rangle$、$p_2$ 处于 $|\psi_2\rangle$），概率是 $p_1|\langle a_n|\psi_1\rangle|^2 + p_2|\langle a_n|\psi_2\rangle|^2$。两者相差一个交叉项 $2\text{Re}(c_1c_2^*\langle a_n|\psi_1\rangle^*\langle a_n|\psi_2\rangle)$——这正是「相干」与「不相干」的差别，也是理解量子退相干（decoherence）的第一步。<span class="marginnote">退相干：环境把量子叠加态「降解」为经典混合态的过程——叠加项被环境噪声平均掉。它解释了为什么宏观物体不显示量子干涉，也是量子计算必须克服的核心障碍（纠错码由此而生）。</span>

## 3 公式解析：叠加态的测量概率

粒子处于叠加态 $|\psi\rangle = \frac{1}{\sqrt{2}}|\psi_1\rangle + \frac{1}{\sqrt{2}}|\psi_2\rangle$（$|\psi_1\rangle$、$|\psi_2\rangle$ 是能量 $E_1$、$E_2$ 的本征态）。求测量能量的可能值与概率。

$$
P(E_1) = |\langle\psi_1|\psi\rangle|^2 = \left|\frac{1}{\sqrt{2}}\right|^2 = \frac{1}{2}, \qquad P(E_2) = \frac{1}{2}
$$

- **第一步，写展开系数**：$|\psi\rangle = c_1|\psi_1\rangle + c_2|\psi_2\rangle$，$c_1 = c_2 = 1/\sqrt{2}$。
- **第二步，算概率**：$P(E_1) = |c_1|^2 = 1/2$，$P(E_2) = |c_2|^2 = 1/2$。
- **第三步，归一化检查**：$|c_1|^2 + |c_2|^2 = 1$——概率之和为 1（态已归一化）。
- **第四步，解读**：测量能量只有两种可能（$E_1$ 或 $E_2$），各 1/2 概率——测量「塌缩」到其中一个本征态。叠加态本身没有确定能量，只有「测量后才确定」。

**辨析｜易错点：**叠加态的「测量前」没有确定值——只有测量才「挑出」一个本征值（测量塌缩）。概率由展开系数的模方 $|c_n|^2$ 给出；系数的模方之和必须为 1（归一化）。「叠加态的平均值」是 $\langle\psi|\hat{H}|\psi\rangle$（期望值），与「单次测量结果」不同——测量结果必是本征值，多次测量的统计平均才是期望值。

## 4 量子态与希尔伯特空间

量子态构成**希尔伯特空间（Hilbert space）**：

- 态矢量 $|\psi\rangle$：希尔伯特空间的元素（平方可积函数/列向量）；
- 内积 $\langle\phi|\psi\rangle$：态之间的「重叠」（概率幅）；
- 厄米算符 $\hat{A}$：本征值实数、本征态正交归一；
- 完备性：任意态可展开为某一组本征态 $\sum_n|c_n|^2 = 1$。

**重点：量子态的数学舞台是希尔伯特空间——态矢量、内积、厄米算符、完备性展开构成量子力学的数学语言。** 这是量子力学与经典力学的数学分野：经典在相空间（连续坐标动量），量子在希尔伯特空间（态矢量 + 算符）。<span class="marginnote">「从波函数到态矢量」：波函数 $\psi(x) = \langle x|\psi\rangle$ 是态矢量在位置基下的分量；动量波函数 $\tilde{\psi}(p) = \langle p|\psi\rangle$ 是动量基下的分量——同一个态的不同「坐标表示」。狄拉克符号 $|\psi\rangle$、$\langle\phi|$（bra-ket）是量子力学的通用语言，第二级《线性代数》与《泛函分析》提供数学基础。</span>

**量子力学关键术语速查表**：

| 术语 | 记号 | 一句话含义 |
| --- | --- | --- |
| 态矢量 | $\|\psi\rangle$ | 系统状态的完整描述（希尔伯特空间元素） |
| 内积 | $\langle\phi\|\psi\rangle$ | 两态重叠的概率幅 |
| 厄米算符 | $\hat{A} = \hat{A}^\dagger$ | 可观测量对应的算符（本征值为实数） |
| 本征方程 | $\hat{A}\|a_n\rangle = a_n\|a_n\rangle$ | 测量可能结果与本征态的联系 |
| 期望值 | $\langle\hat{A}\rangle = \langle\psi\|\hat{A}\|\psi\rangle$ | 多次测量的统计平均 |
| 密度矩阵 | $\hat{\rho} = \sum_i p_i\|\psi_i\rangle\langle\psi_i\|$ | 纯态与混合态的通用描述 |
| 对易子 | $[\hat{A}, \hat{B}] = \hat{A}\hat{B} - \hat{B}\hat{A}$ | 两算符可否同时取确定值 |

**重点：密度矩阵是态矢量的一般化**——纯态对应 $\hat{\rho} = |\psi\rangle\langle\psi|$，混合态是纯态的凸组合 $\hat{\rho} = \sum_i p_i|\psi_i\rangle\langle\psi_i|$。判据是 $\text{Tr}\,\hat{\rho}^2 = 1$ 为纯态、$< 1$ 为混合态。<span class="marginnote">密度矩阵在量子信息中地位极高：约化密度矩阵（对纠缠系统的一部分求迹）给出子系统的有效状态，纠缠度量（冯诺依曼熵 $S = -\text{Tr}(\hat{\rho}\ln\hat{\rho})$）也以它为原料。到量子计算与量子信息课程中，密度矩阵是与态矢量并驾齐驱的基本工具。</span>

## 5 基本假设的地位与意义

**统一性**：五条假设统一了第十八章的全部量子现象（波函数、薛定谔方程、测量、叠加）；
**预测性**：给定哈密顿量（假设四的 $\hat{H}$），理论上可计算一切可观测量的概率分布；
**非决定性**：测量结果是随机的（概率由玻恩规则给出）——量子力学的内禀随机性；
**对应原理**：$\hbar \to 0$ 时量子力学回归经典（波包 → 轨道、对易子 → 泊松括号）。

**重点：五条基本假设是量子力学的完整公理体系——从态到测量到演化，量子力学的全部预测都由它们推出。** 量子力学的成功在于：这个看似抽象的公理体系，对原子、分子、固体、激光、半导体的一切预测都与实验吻合。<span class="marginnote">「量子力学的解释问题」：五条假设中有两条（测量塌缩、玻恩概率）涉及「测量」——测量的瞬间发生了什么？哥本哈根诠释（测量塌缩）、多世界诠释（所有结果都发生）、隐变量理论（贝尔不等式排除局域隐变量）……量子力学基础至今是活跃研究领域。「从极限到大模型」走到这里，既到达现代物理的技术巅峰，也站在诠释分歧的哲学前沿。</span>

**五条假设的「地图」**：如果把量子力学比作一座城市，假设一、二定义「地图的纸张与坐标」（态与算符的数学结构），假设三、五定义「如何在城市中定位与读数」（测量规则），假设四定义「城市如何随时间变化」（演化规律）。掌握这张地图，后续的一切——氢原子、自旋、微扰、散射、二次量子化——都只是在不同街区里使用同一套规则，并不需要再发明新的公理。

**数值实例**：取一个自旋 1/2 粒子处于态 $|\psi\rangle = \frac{\sqrt{3}}{2}|\uparrow\rangle + \frac{1}{2}|\downarrow\rangle$。沿 $z$ 轴测自旋，得 $+\hbar/2$ 的概率为 $(\sqrt{3}/2)^2 = 3/4$，得 $-\hbar/2$ 的概率为 $(1/2)^2 = 1/4$，两者之和为 1（归一化）。若改沿 $x$ 轴测量，则需先把 $|\psi\rangle$ 在 $|+\rangle_x = (|\uparrow\rangle + |\downarrow\rangle)/\sqrt{2}$ 基下展开——这正是下一节「算符与力学量的平均值」要系统化的内容：同一态在不同测量基下的表现。

## 6 小结

- **五条基本假设**：态矢量描述、力学量算符、测量本征值 + 塌缩、薛定谔演化、玻恩概率。
- **态叠加原理**：$|\psi\rangle = c_1|\psi_1\rangle + c_2|\psi_2\rangle$；概率幅叠加产生干涉（非概率相加）。
- 测量概率 $P(a_n) = |\langle a_n|\psi\rangle|^2$；测量后塌缩到本征态。
- **希尔伯特空间**：态矢量 + 内积 + 厄米算符 + 完备性——量子力学的数学舞台。
- **叠加态 vs 混合态**：相干（含干涉项）vs 不相干；密度矩阵统一描述，判据 $\text{Tr}\,\hat{\rho}^2$。
- **密度矩阵**：$\hat{\rho} = \sum_i p_i|\psi_i\rangle\langle\psi_i|$，量子信息中与态矢量并驾齐驱。
- 对应原理：$\hbar \to 0$ 回归经典；测量问题是量子力学基础的开放问题。
