## 为什么从应用开始

十篇理论讲完，是时候把全部工具装进真实世界了。反问题最活跃的两个战场，恰好代表两种不同的「病」：**医学成像**里，我们要「看见身体里面」（人体是散射/衰减介质，探测器在外围）；**地球物理反演**里，我们要「看见地球里面」（源在地表之下，探测器在地表）。前者强调精度与安全（剂量），后者强调尺度与不确定性（地下几十公里、数据稀疏）。<span class="marginnote">选择这两个领域还有一个理由：它们各自把本专题的某一块用到了极致——医学成像把「先验设计」与「快速迭代」用到极致，地球物理把「参数选择」「非线性」与「不确定性量化」用到极致。对照着读，比单独读任何一个都更能看清工具的全貌。</span>

把应用放在最后还有一层教学上的用意：它是一次「总复习」。每读到一种方法的名字——TV、MCMC、FWI、L 曲线——你都能在头脑里把它定位回前几篇的某一块。读完这一节，前面十篇不再是孤立的公式，而是同一座建筑的不同房间。

（本节的例子刻意横跨「线性/非线性、便宜/昂贵、数据海量/数据稀疏」的全部象限，就是为了让每一种方法都有它的舞台。）

## 1 医学成像：从 CT 到 MRI 的反问题矩阵

医学成像是一族反问题的集合，每一条都对应一个「正问题 + 数据 + 先验」的组合：

| 模态 | 正问题 | 数据 | 常用正则化 |
| --- | --- | --- | --- |
| X 射线 CT | Radon 变换 | 投影（正弦图） | FBP、TV、迭代重建 |
| MRI | 傅里叶变换（k 空间采样） | k 空间样本 | $\ell_1$ + wavelet、TV、低秩 |
| 超声 | 波散射/反射 | 回波 B 超 | 波束成形（延迟叠加） |
| PET | Radon 变换 + 衰减校正 | 符合计数 | 泊松似然 + 光滑先验 |
| 光学相干断层 | 低相干干涉 | 干涉信号 | 谱整形、去卷积 |

表格里有几个值得展开的点。**MRI** 的正问题是「欠采样 k 空间」：病人在扫描仪里躺得越久，k 空间采得越满、图像越好；但躺久不舒服、运动伪影多。于是「少采样 + 强先验重建」成为刚需——这正是**压缩感知 MRI**：随机欠采样 k 空间，配 wavelet/TV 稀疏先验，用少数采样重建全图像。前几篇的 $\ell_1$ 理论在这里直接兑现成「扫描时间减半」。<span class="marginnote">MRI 与 CT 的反问题形态不同：CT 的算子是 Radon 变换（角度欠采样病态），MRI 的算子近似傅里叶（k 空间欠采样病态）。但两者共享同一套药方：稀疏先验 + 迭代重建 + 参数选择。这也是为什么医学影像界如今把「稀疏重建」「低秩重建」当基础设施用。</span>

**超声成像**则代表了另一类「正问题太贵」的情形：正演要解波动方程，数据是回波，反演目标从「图像」到「弹性参数」。传统 B 超用延迟叠加波束成形（本质是一次快速「反投影」），而弹性成像、全波形超声要走上逆散射的路——非线性、贵、但信息量大得多。

最后别忽略医学成像里「正问题建模」本身就是一门手艺：CT 要建射线几何与多色光谱硬化模型，MRI 要建 k 空间采样轨迹与线圈灵敏度，PET 要做衰减校正与散射估计。**医学成像的每一次进步，一半靠新反演算法，一半靠更准的正问题模型**——这正好呼应第 5 节要讲的「翻车第一源」。

## 2 地球物理反演：看不见的地球

地球物理反演的舞台更大、数据更稀疏、先验更不确定。几个经典成员：

**地震走时层析（travel-time tomography）**：地震波从震源传到台站，走时 = 沿射线路径的速度倒数积分。反演目标：地下速度模型。正问题（射线追踪）比医学成像贵一个量级，数据（台站、震源）稀疏且分布不均。<span class="marginnote">走时层析的经典方法就是「代数重建 + 光滑正则化」：把地下离散成网格、射线穿过网格求和，形成稀疏矩阵 $Ax = y$，再用带光滑约束的最小二乘求解。几十年来它一直是全球地震学的主力工具——你的手机震动预警、断层带成像，背后都是这条流水线。</span>

**全波形反演（FWI，full-waveform inversion）**：只利用走时是浪费——波形里还有振幅、相位、绕射信息。FWI 直接反演波动方程：正问题解波场，反演用梯度类迭代（伴随方法算梯度），正则化用 Tikhonov 或 TV，参数选择用偏差原理或 L 曲线。它是逆散射思想（本专题第 9 篇）在地球物理的最大落地，也是目前计算量最惊人的反问题之一——一次三维 FWI 在超算上跑数周。

FWI 的梯度用**伴随方法**计算：把波场向前传播，再把残差反向传播（时间反演），两者逐点的内积就是目标函数对每个网格慢度的梯度——这正是逆散射里 $F'(m)^*$ 的「时间反演」物理解释。梯度拿到后配 L-BFGS 等拟牛顿步与 TV/Tikhonov 正则化，迭代到残差降到噪声水平；其中**多尺度策略（先低频后高频）**是 FWI 能逃离局部极值的关键工程诀窍。

**重力/磁力反演**：数据是地表的重力异常（天然就是 Radon 型的体积积分），反演地下密度。这类反问题的病态性特别极端（深度方向信息指数衰减），几乎完全依赖先验（层状模型、地质约束）——它是「先验决定成败」的极端案例。

这三类地球物理反问题还能拼成一张更大的图：走时层析给大尺度速度结构，FWI 给小尺度精细结构，重磁给密度与磁化率约束——把多个模态的数据**联合反演（joint inversion）**，用「同一套地下参数要同时解释多种数据」来压缩不确定性，是当前地球物理的前沿方向，也与贝叶斯多模态建模一脉相承。

这些反演成果不是学术玩具：走时层析出的速度模型直接用于地震预警系统的定位与震级估计，重磁反演指引矿产与油气勘探的钻井选址，FWI 是海洋油气勘探（OBN 采集）的工业标配。**反问题在真实世界的回报，是每一次更准的定位、更少的空钻、更稳的结构评估**——这也是这个专题值得学到底的原因。

## 3 公式解析：走时层析的最小二乘-正则化解剖

走时层析是理解「离散化后的反问题」最好的入门模型：它麻雀虽小、五脏俱全——病态、正则化、参数选择、不确定性，一个都不少，而且每一环都能用纸笔算出来。用一个最小的模型把工具链走一遍：设地下被分成 $n$ 个网格单元，第 $j$ 个单元的慢度（速度倒数）为 $s_j$。第 $i$ 条射线的走时是它穿过各单元长度的加权和

$$t_i = \sum_{j} l_{ij}\, s_j$$

写成矩阵形式 $t = Ls$，$L$ 的第 $(i,j)$ 元是第 $i$ 条射线在第 $j$ 个单元内的路径长度——**一条射线一行，一个单元一列**。反演目标：由走时 $t$ 求慢度 $s$。

拆解这条流水线：

- **第一步，看离散化的病态**：$L$ 是稀疏的（射线只穿过少数单元），且单元越大越稀疏；深层单元几乎没有射线穿过，对应 $L$ 的列近似为零——**深层慢度几乎不可观测**。这正是「值域不闭/零空间非零」的离散版。
- **第二步，加正则化**：最小二乘解在深层会爆炸，于是加光滑正则化 $\min_s \lVert Ls - t\rVert^2 + \alpha \lVert Ds\rVert^2$（$D$ 差分算子），或 TV 版 $\alpha\operatorname{TV}(s)$ 保留层状结构——**不同先验给出不同地球**。
- **第三步，选参数**：用偏差原理（知道走时噪声）或 L 曲线（不知道）定 $\alpha$；对迭代法，用「残差降到噪声水平」定步数。
- **第四步，看输出**：点估计给速度模型，贝叶斯版本给后验——每个深度上的速度区间、两条断层之间的相关性，全在协方差里。<span class="marginnote">这一步是地球物理与医学成像最不同的地方：医学影像的「答案」是给医生看的图，地球物理的「答案」是给决策用的数字（钻井打在哪、储量多少）。决策需要的不只是最优解，更是「这个解有多靠谱」——贝叶斯不确定性量化在这里从锦上添花变成刚需。</span>

一个两网格数值例子把「深层不可观测」量化：设地下两个单元，慢度 $s = (s_1, s_2)$，两条射线：射线 1 只穿单元 1（$l_{11} = 1, l_{12} = 0$），射线 2 同时穿过两单元（$l_{21} = 1, l_{22} = 0.5$）。测量 $t = (1.0, 1.25)$，解得 $s_1 = 1.0$、$s_2 = 0.5$，唯一。但若单元 2 只有一条很短的射线穿过（$l_{22} = 0.1$），则 $s_2 = 2.5$——对 $t$ 的 1% 噪声会把 $s_2$ 放大 10 倍。**深层单元射线越短、信息越弱、病态越重**。

## 4 两个领域的方法论对照

把医学成像与地球物理反演并排，能看清反问题方法论的全部维度：

| 维度 | 医学成像 | 地球物理反演 |
| --- | --- | --- |
| 尺度 | $10^8$–$10^9$ 像素/体素 | $10^4$–$10^7$ 网格/参数 |
| 数据 | 海量、规则、可控 | 稀疏、不规则、不可重复 |
| 正问题 | 便宜（Radon/FFT）或中等 | 贵（波动方程/射线追踪） |
| 噪声 | 可控（剂量可调） | 不可控（地脉动、台站质量） |
| 先验 | 图像结构（TV、稀疏、低秩） | 地质模型、层状、物理约束 |
| 不确定性的角色 | 重要（病灶边界） | 关键（储量、断层风险） |

这个对照表本身就是一个「方法选择器」：数据多、正问题便宜 → 迭代重建 + 稀疏先验；数据少、正问题贵、决策风险高 → 贝叶斯 + MCMC/变分 + 不确定性报告。<span class="marginnote">还有一条值得记住的产业事实：医学成像的方法成熟度远高于地球物理——因为医学的数据可大量生成、可做金标准验证（用 CT 与病理对照），而地球内部永远无法「开箱验证」。数据与验证的可得性，决定了方法论能达到的高度。</span>

两领域还有一个镜像般的演化：医学成像从「解析」（FBP）走向「迭代 + 先验」，地球物理则从「迭代」（射线层析）走向「全波形 + 贝叶斯」。方向上都在往「用更强的正问题与更完整的先验」收敛——这也解释了为什么两个领域的软件栈越来越像：**同一个反问题内核，不同的物理外壳**。

方法之外，工程基础设施也在决定边界：医学影像的迭代重建要在 GPU 上做到实时（手术导航、介入引导），地球物理的 FWI 要在超算上按周计。同一个 Tikhonov 公式，在医学里是毫秒级的 CUDA kernel，在地球物理里是数周的 MPI 任务——**解法一样，「解法的时间预算」天差地别**，而这决定了最终选什么算法实现。

## 5 辨析：应用反问题最常翻车的三个地方

**辨析｜易错点：** 从两个领域无数失败的案例里，能提炼出三个高频事故点：

- **正问题模型错误**：射线不是直线、波不是单频、忽略衰减校正——正问题错，反演结果全错。**反问题里最大的误差源往往是正问题，而不是反演算法**。FWI 学到的第一课就是「射线近似在高频走时里够用，在波形里远远不够」。
- **参数选择失当**：照抄论文里的 $\alpha$、固定迭代步数、用统一的噪声水平——每个领域的问题都有各自的病态谱，参数必须现场定。前几篇的参数选择工具，就是为「现场定」准备的。
- **把不确定性问题压成点估计**：只给一个速度模型、一张重建图，不给置信区间——对医学或许勉强够用，对地质决策是危险的。**后验不是装饰，是答案的一部分**。

还有一个潜藏的事故源：**数据与解的错配**。医学影像的「分辨率」、地球物理的「反演深度」，经常被报告得比物理信息天花板更乐观——因为点估计 + 光滑先验会把「不可知」伪装成「平滑的已知」。诚实报告「这个深度以下其实什么也看不见」，比给出一个漂亮但不确定的模型更有价值。

把三个事故源合起来看，它们指向同一条教训：**应用反问题失败，几乎从不因为算法不够花哨，而因为模型、数据与问题三者之间错配**。把正问题建准、把参数选对、把不确定性讲清——做到这三条，朴素的方法也够用；缺任一条，再复杂的算法也会翻车。

## 6 反问题方法论的决策清单

把十篇理论压成一张「先回答、再选方法」的检查单，是应用前最好的收尾。每问一行，都对应前面某几篇的工具：

- **正问题贵还是便宜？** 便宜（Radon、FFT、稀疏矩阵）→ FBP 或直接迭代重建；贵（波动方程、射线追踪）→ 先想清楚全波形是否必要，还是走时层析就够。
- **数据多还是少？** 海量 → 迭代 + 稀疏/低秩先验，GPU 实时；稀疏 → 贝叶斯 + 后验分布，把不确定性写进决策。
- **噪声水平知道吗？** 知道 → 偏差原理定 $\alpha$；不知道 → L 曲线/GCV 粗扫、再微调。
- **解是给图还是给决策？** 给医生看图 → TV/稀疏先验保边缘、速度优先；给钻井与储量决策 → 区间比点估计更重要，慢一点也值得。
- **线性还是非线性？** 线性 → Tikhonov/TSVD/迭代全套；非线性 → Gauss–Newton 型正则化迭代 + 多尺度策略 + 好初值。

这套清单与其说是算法手册，不如说是「问题建模」的检查单：前四行问的都是「你到底要什么」，只有最后一行在问「用什么数学」。把问题问准，朴素的方法也够用；问不准，再花哨的算法也会翻车。

## 7 小结

- 医学成像与地球物理反演是反问题的两大战场：前者数据海量、先验强、迭代重建为主；后者数据稀疏、正问题贵、不确定性量化是刚需。
- MRI 压缩感知 = 随机欠采样 + 稀疏先验 + 迭代重建，直接把理论兑现成扫描时间减半。
- 走时层析 $t = Ls$：一条射线一行、一个单元一列；深层单元射线短、信息弱、病态重，先验与正则化决定「看到哪种地球」。
- FWI 用伴随方法算梯度、配多尺度策略逃局部极值，是逆散射思想在地球物理的最大落地。
- 医学成像数据可验证、方法成熟度高；地球内部无法「开箱验证」，不确定性量化从锦上添花变成刚需。
- 应用反问题翻车三源：正问题模型错误、参数选择失当、把不确定性压成点估计——先建准、选对、讲清，朴素方法也够用。

十篇反问题从 Hadamard 适定性一路走到这里，工具与场景终于闭环。下一步，把这套「数据 + 先验 + 不确定性」的语言带进统计学习与机器学习——你会发现那里的 Lasso、dropout、扩散模型的去噪，都只是同一套先验设计语言的方言。
