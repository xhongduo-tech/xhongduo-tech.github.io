## 为什么从过渡金属碳-碳键形成开始

上一章的催化原理在此落地为最有力的形态：**过渡金属催化的交叉偶联**——让两个原本惰性的片段（芳卤与有机金属、烯烃等）在钯等金属的调度下精准成键。Heck、Suzuki、Negishi 三大偶联反应因其实用性共获 2010 年诺贝尔化学奖。<span class="marginnote">制药工业里超过一半的碳-碳键形成依赖钯催化偶联。从抗癌药到柔性屏材料的单体，过渡金属催化是「把分子蓝图变成分子实体」的现代核心手段。</span>本章建立有机金属化学的基础（氧化态、d 电子数、18 电子规则），并剖析氧化加成、迁移插入、还原消除等基元反应如何组装成催化循环。

## 1 有机金属化学的语法：氧化态与 d 电子

理解金属催化的第一步是给金属「记账」：记氧化态与 d 电子数。

**氧化态（oxidation state）**：把 M-X 键的电子都分给 X，M 的剩余电子数即 d 电子数。对第八族金属（如 Pd），常见的氧化态是 0 与 +2。<span class="marginnote">氧化态不是物理电荷，而是「电子记账方式」：$\ce{Pd(0)}$ 与 $\ce{Pd(II)}$ 的区别决定了它配位数、反应活性的取向。把氧化态想成金属的「身份等级」，催化循环里金属在 0 与 +2 之间上下班。</span>

**18 电子规则**：稳定的有机金属络合物的价电子总数（金属 d 电子 + 配体提供电子）倾向达到 18——对应惰性气体的电子排布。16 电子的物种（如 $\ce{Pd(0)L2}$）缺电子、活泼，恰是催化循环的活性中间体。<span class="marginnote">18 电子规则是有机金属化学的「八隅体」：饱和的 18 电子络合物稳定、安静，16 电子络合物「饥饿」、渴望配位。催化循环的活性物种几乎都是 16 电子——饥饿才有动力。</span>

## 2 基元反应四件套

金属催化的催化循环由少数几个**基元反应（elementary steps）**反复组合而成，四件套即可覆盖绝大多数偶联：

**氧化加成（oxidative addition）**：金属插入 $\ce{R-X}$ 键，氧化态升高 2、配位数增加 2。金属越富电子（低氧化态、给电子配体），氧化加成越快——富电子金属更愿「付出」电子密度。

**迁移插入（migratory insertion）**：一个配体插入金属-碳键之间。如 $\ce{CO}$ 插入 $\ce{Pd-CH3}$，形成酰基钯物种。

**β-氢消除（β-hydride elimination）**：金属-烷基键旁的 β-H 转移到金属，生成金属氢化物与烯烃——这是烯烃与金属反应的逆过程，也是 Heck 反应里使中间体再生钯的关键步。

**还原消除（reductive elimination）**：两个配体偶联成新键离开金属，氧化态降低 2、配位数减少 2。还原消除是碳-碳键形成的「临门一脚」：$\ce{Pd(R)(R') -> Pd(0) + R-R'}$。<span class="marginnote">还原消除需要两个配体<strong>顺式（cis）</strong>排列才便于偶联——几何要求再次登场。这条「顺式要求」是理解配体如何控制偶联产物立体化学的关键。</span>

## 3 三大偶联的催化循环

把四件套按不同顺序编排，就得到不同偶联反应：

**Suzuki 偶联（Suzuki coupling）**：芳卤 + 硼酸 → 联芳。循环：氧化加成（$\ce{Ar-X}$）→ 转金属化（硼酸把芳基递给钯，交换 $\ce{X}$）→ 还原消除（联芳 + 再生 $\ce{Pd(0)}$）。<span class="marginnote">Suzuki 反应亲和的硼酸稳定、对官能团宽容、条件温和，是制药工业最常用的偶联。它的步骤里有一步特殊的<strong>转金属化（transmetalation）</strong>——把硼上的芳基「换」到钯上，是 Suzuki 与 Heck 的最大区别。</span>

**Heck 反应（Heck reaction）**：芳卤 + 烯烃 → 取代烯烃。循环：氧化加成 → 烯烃配位与迁移插入 → β-氢消除 → 碱再生钯。β-氢消除给出烯烃产物，是 Heck 的标志。

**Negishi 偶联**：芳卤 + 有机锌 → 偶联产物，与 Suzuki 类似但转金属化用锌试剂。选择何种偶联，取决于可得的有机金属试剂的稳定性与兼容性。

## 4 配体设计：调控选择性的旋钮

催化循环每一步的速率与选择性都受**配体（ligand）**调控。配体的两大角色：

**电子效应**：富电子、大位阻的膦配体（如叔丁基膦）加速氧化加成（金属更富电子）并促进还原消除（两个大配体拥挤、把反应物挤出去偶联）。**位阻效应**：大位阻配体迫使底物取向，控制区域与立体选择性。

**配体的经典参数**：锥角（Tolman 锥角）度量位阻，σ 给电子能力度量电子丰度。设计配体就是在「电子够富」与「位阻够挤」之间找平衡。<span class="marginnote">配体是催化的「编程界面」：同一种钯、换一套配体，反应可以从无选择性变成高度选择性。现代催化研究很大程度是配体筛选的艺术——这与其说玄学，不如说是在系统调节电子与空间两个自由度。</span>

## 5 公式解析：氧化还原平衡与催化循环

催化循环是一个**氧化还原能量学**的闭合回路：金属在氧化态间往返，而每一步基元反应都有对应的电子数守恒：

$$\ce{Pd(0)L2 + R-X ->[氧化加成] Pd(II)(R)(X)L2 ->[还原消除] Pd(0)L2 + R-R'}$$

拆解这条「循环守恒」：

- **第一步，盯住电子账**：氧化加成把 $\ce{Pd(0)}$ 变 $\ce{Pd(II)}$（d 电子数减 2、配位数加 2），还原消除把 $\ce{Pd(II)}$ 送回 $\ce{Pd(0)}$。两进两出，金属回到起点——**催化循环要求金属的氧化态/配位数在每个循环后完全复原**，这是「催化剂不消耗」的分子层面含义。
- **第二步，看基元反应配对**：氧化加成把惰性的 $\ce{R-X}$ 变成活泼的 $\ce{Pd-R}$（亲电片段激活）；转金属化把有机金属片段搬上钯；还原消除把两个片段缝成 $\ce{R-R'}$（碳-碳键诞生）。三个步骤各司其职，组成「激活 → 搬运 → 缝合」的生产线。
- **第三步，评估驱动力**：循环是否可行取决于每一步的能垒与热力学。富电子金属利于氧化加成，顺式排列利于还原消除，β-氢消除需要空配位点——每个「利于」都是一条设计指导，组合起来就是完整的催化剂理性设计。

### 配体的电子与空间参数

配体筛选是过渡金属催化的日常，掌握两个经典参数就能入门：

**Tolman 锥角（cone angle）**：从金属中心看，配体覆盖的立体角——度量位阻。叔丁基膦锥角大（约 $182^\circ$）、位阻大；三甲基膦锥角小（约 $118^\circ$）。**σ 给电子能力**：度量配体向金属输送电子密度的能力，常用配体置换反应或光谱（CO 伸缩频率）间接测定。

位阻与电子经常联动：大位阻配体往往也更富电子（如富电子的烷基膦），两者叠加决定了金属中心的反应活性与选择性。<span class="marginnote">「锥角 × 给电子能力」二维参数空间，就是配体设计的画布。现代高通量筛选把这两个参数扫成网格，快速找出最优配体——从手调到自动化，配体工程仍在进化。</span>

### 交叉偶联在制药工业的地位

交叉偶联对制药工业的影响难以估量：联芳基结构广泛存在于药物骨架，而 Suzuki 偶联几乎成了联芳键的「标准装配线」。**规模**：临床前药物合成中交叉偶联占比极高。**优势**：条件温和、官能团兼容广、对水和空气相对稳定。**挑战**：钯残留必须控制在极低水平（药品监管要求），促使「低钯催化」与金属清除技术的开发。

从 HeLa 细胞到抗癌药，交叉偶联把「分子蓝图」变成「可口服的药片」，是过渡金属催化最贴近民生的一面。<span class="marginnote">2001、2005、2010 年三个诺奖（不对称氢化、烯烃复分解、交叉偶联）都颁给过渡金属催化，足见这一领域的深远影响。制药、农化、材料——过渡金属催化是现代分子工业的底座。</span>

### 从实验室到工业：催化条件的放大

小试优化出的偶联条件放大到工业釜中，常遇到新问题：**传热与传质**（放热反应在工业尺度更难控制）、**氧气与水敏**（工业化难以全程无氧）、**金属负载与成本**（钯昂贵，追求低负载）。物理有机化学的动力学与热力学工具在此再次登场：理解决速步与失活路径，才能设计出放大后依然稳健的工艺。

### 有机金属化学的配体场视角

过渡金属的反应性最终由**配体场（ligand field）**决定：配体分裂 d 轨道能级，决定金属的电子构型、自旋态与配位几何。
