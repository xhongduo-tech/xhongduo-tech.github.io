## 为什么必须回答「场的能量在哪」

电场能对电荷做功，这是常识；但能量到底储存在哪里？「在电荷上」还是「在电荷之间的空间里」？上一节我们接受了「场是真实存在的物理实体」，那么场就应当像一切实体一样携带能量与动量。这一节把麦克斯韦方程组翻译成**能量守恒律**与**动量守恒律**，并得到两个将贯穿全书的量：**能量密度**和**能流密度（坡印亭矢量）**。<span class="marginnote">「能量储存在场里」在电磁波身上体现得最直观：太阳辐射穿越 1.5 亿公里真空把能量送到地球，中间没有导线、没有物质——只有电磁场自己。光压（辐射压）正是电磁场携带动量的直接证据，光帆航天器就是靠它推进的。</span>

## 1 电磁场的能量密度与坡印亭矢量

对麦克斯韦方程组做代数运算（点乘 $\mathbf{E}$ 与 $\mathbf{H}$ 后相加），可推导出**坡印亭定理（Poynting's theorem）**：

$$\frac{\partial w}{\partial t} + \nabla\cdot\mathbf{S} = -\mathbf{J}\cdot\mathbf{E}$$

其中：

- **电磁场能量密度** $w = \dfrac{1}{2}(\mathbf{E}\cdot\mathbf{D} + \mathbf{B}\cdot\mathbf{H})$，单位 $\mathrm{J/m^3}$。真空中为 $w = \dfrac{\varepsilon_0 E^2}{2} + \dfrac{B^2}{2\mu_0}$。
- **坡印亭矢量** $\mathbf{S} = \mathbf{E}\times\mathbf{H}$，单位 $\mathrm{W/m^2}$，表示能量流动的**方向与速率**（单位时间垂直穿过单位面积的能量）。
- 右端 $-\mathbf{J}\cdot\mathbf{E}$ 是电源对电荷做的功率密度——能量从电磁场转化为电荷的机械能（焦耳热）。

坡印亭定理就是电磁场版本的**能量守恒定律**：区域中场能的增长率 + 流出的能流 = 电源对电荷做的功率。<span class="marginnote">坡印亭定理的三个来源——麦克斯韦方程组 + 矢量的散度定理 + 场能定义——缺一不可。它把「场能密度」与「能流」这两个看似定义随意的量，通过守恒律锁定为物理实体：无论你怎么重新定义，只要守恒律成立，$w$ 与 $\mathbf{S}$ 就被唯一确定（差一个总散度项）。</span>

**辨析｜易错点：** 坡印亭矢量的大小不是「总能量流动」的唯一描述——因为对任意矢量 $\mathbf{f}$，把 $\mathbf{S}$ 换成 $\mathbf{S} + \nabla\times\mathbf{f}$ 不改变 $\oint \mathbf{S}\cdot\mathrm{d}\mathbf{S}$。物理上可观测的是能流的**通量**（穿过闭合面的净能量）而非逐点值。此外，静电场与静磁场叠加的能流可能不为零，却并不真正「流动」——例如恒稳电场与恒稳磁场垂直时，$\mathbf{E}\times\mathbf{H}\neq 0$ 但闭合面净能流为零。

## 2 静电场的能量

静电场储存的能量可由电场强度表出。对电荷分布，静电能的两套等价表达式：

$$W_e = \frac{1}{2}\int \rho\varphi\,\mathrm{d}V = \frac{\varepsilon_0}{2}\int E^2\,\mathrm{d}V$$

第一式把能量归于电荷，第二式把能量归于场——两者数值相同，但哲学含义不同。场论的观点（第二式）认为能量储存在电场所在的空间中，这在时变场中成为唯一正确的观点（因为能量需要时间才能传播到电荷处）。<span class="marginnote">两式的等价性依赖分部积分与 $\nabla^2\varphi = -\rho/\varepsilon_0$，但有一个陷阱：第一式积分区域只要覆盖所有电荷即可；第二式必须对全空间积分。若只对有限区域积分，两式差一个边界项——这正是「能量归于电荷」与「能量归于场」的分歧在数学上的显现。</span>

**典型结果**：孤立导体球（半径 $R$，电荷 $q$）静电能 $W = \dfrac{q^2}{8\pi\varepsilon_0 R}$；平行板电容器储存能量 $W = \dfrac{Q^2}{2C} = \dfrac{1}{2}CU^2$，其中 $C$ 是电容。

## 3 电磁场的动量与光压

电场与磁场垂直相交的电磁波，不仅携带能量，还携带动量。由麦克斯韦方程组的对称性可导出**动量密度**：

$$\mathbf{g} = \varepsilon_0\mu_0\,\mathbf{S} = \frac{\mathbf{S}}{c^2}$$

即单位体积电磁场携带的动量。对沿 $z$ 传播的平面波，动量密度沿传播方向。电磁波打到物体表面，动量转移产生**辐射压（radiation pressure）**。对完全吸收的表面，压强 $P = \dfrac{I}{c}$；对完全反射表面，$P = \dfrac{2I}{c}$，其中 $I = |\mathbf{S}|$ 是平均能流密度（光强）。<span class="marginnote">太阳光在地球轨道附近的光强约 $1361\ \mathrm{W/m^2}$（太阳常数），光压约 $4.5\ \mu\mathrm{Pa}$——大约是标准大气压的二十亿分之一，平常几乎无感。但宇宙尺度的光压足够推动彗尾，光帆探测器（如 2019 年的 LightSail 2）已用太阳光压实现轨道调整。</span>

**辨析｜易错点：** 电磁波的动量方向沿传播方向，且 $p = E/c$（能量除以光速），这与质能关系 $E = mc^2$ 结合可得电磁波的有效「动质量」$m = E/c^2$——但这不意味着光子有静止质量。光子静止质量严格为零，其动量完全来自运动本身。

## 4 公式解析：坡印亭定理的推导骨架

坡印亭定理是本节的核心，其推导本身就是一个重要训练。骨架如下：

**第一步，法拉第定律点乘 $\mathbf{H}$**：$\mathbf{H}\cdot(\nabla\times\mathbf{E}) = -\mathbf{H}\cdot\partial\mathbf{B}/\partial t$。利用恒等式 $\nabla\cdot(\mathbf{E}\times\mathbf{H}) = \mathbf{H}\cdot(\nabla\times\mathbf{E}) - \mathbf{E}\cdot(\nabla\times\mathbf{H})$，把左端换成「$\nabla\cdot\mathbf{S}$ 减去另一个旋度项」。
**第二步，安培-麦克斯韦定律点乘 $\mathbf{E}$**：$\mathbf{E}\cdot(\nabla\times\mathbf{H}) = \mathbf{E}\cdot\mathbf{J} + \mathbf{E}\cdot\partial\mathbf{D}/\partial t$。这个等式把「电流功率」与「电场时间变化率」联系起来。
**第三步，合并**：两式相减，左边凑出 $\nabla\cdot(\mathbf{E}\times\mathbf{H}) = \nabla\cdot\mathbf{S}$；右边的时间变化项组合成 $\dfrac{\partial}{\partial t}\left(\dfrac{1}{2}\mathbf{E}\cdot\mathbf{D} + \dfrac{1}{2}\mathbf{B}\cdot\mathbf{H}\right)$。移项即得坡印亭定理。核心诀窍是**用 $\mathbf{E}$ 和 $\mathbf{H}$ 分别点乘两个旋度方程再相减**，让含时间导数的项恰好组合成能量密度的导数。<span class="marginnote">这种「点乘求能量方程」的手法是场论的标准动作，在流体力学、弹性力学里同样出现——对运动方程点乘速度，就得能量守恒。物理中守恒律几乎都来自「对场方程做内积」这一操作。</span>

## 5 能量、动量守恒与全书的地位

坡印亭定理揭示的图景在后续各篇反复被调用：

- **静电场篇**：静电能公式用于计算电容储能、以及带电体的相互作用能。
- **静磁场篇**：磁场能量密度 $B^2/2\mu_0$ 用于电感储能、磁化过程。
- **辐射篇**：偶极辐射功率由坡印亭矢量对球面积分求出（李纳-维谢尔公式、偶极辐射功率公式的推导都从这里出发）。
- **相对论篇**：场的能量-动量张量是电磁场在洛伦兹变换下统一描述的基础——能量与动量是同一个四矢量的分量。

## 6 三个能流例子：能量到底怎么走

坡印亭矢量 $\mathbf{S} = \mathbf{E}\times\mathbf{H}$ 常给出反直觉的答案。三个例子帮你建立「能量由场传输」的正确图像。

**例一：直流电路的能量传输。** 一根载流直导线旁放一平行导线构成回路，两线之间的电场（由电位差产生）与磁场（由电流产生）处处垂直，坡印亭矢量沿两线之间的空间指向负载——**能量不是「顺着导线流」的，而是从电源出发、经由导线周围的电磁场横穿空间到达负载**。导线只是引导能量场的「轨道」。这个结论让「能量在导线里走」的日常直觉彻底修正。

**例二：电容器充电的能流。** 平行板电容器充电过程中，板间电场增大，位移电流产生环绕磁场，$\mathbf{E}\times\mathbf{H}$ 指向电容内部——**能量从外部空间「涌入」电容，储存在两极板之间的电场里**。放电时能流反向，能量流出。

**例三：电磁波的能量运输。** 平面电磁波中 $\mathbf{E}\perp\mathbf{B}$，$\mathbf{S}$ 沿传播方向，平均值 $\langle S\rangle = \frac{1}{2}\sqrt{\varepsilon/\mu}E_0^2$。太阳光能流约 $1361\ \mathrm{W/m^2}$，全部以电磁场的形式穿越真空——**没有坡印亭矢量，就无法理解太阳的能量如何到达地球**。

**辨析｜易错点：** 坡印亭矢量 $\mathbf{E}\times\mathbf{H}$ 中用的是 $\mathbf{H}$（磁场强度）而非 $\mathbf{B}$，真空中 $\mathbf{H} = \mathbf{B}/\mu_0$ 二者只差常数；但介质中 $\mathbf{H} = \mathbf{B}/\mu$，用错会差一个 $\mu_r$。另外，静电场与静磁场同时存在时 $\mathbf{E}\times\mathbf{H}$ 可能不为零（如通电导线旁有静电电荷），但它不代表「真实的能流」——只有闭合面积分的净能流才是可观测的能量输运。

**能量与动量的洛伦兹变换视角**：电磁场的能量密度与动量密度在相对论下并非独立——它们组合成四维的**能量-动量张量**。换参考系时，能量与动量会互相转化（就像电场与磁场互相转化）。一束电磁波在不同参考系中「能量密度」不同，但「$w^2 - c^2|\mathbf{g}|^2$」这类组合保持洛伦兹不变。这为《电磁场变换与狭义相对论》一节预留了接口——**能量与动量不是两样东西，而是同一守恒流的时间与空间分量**。

**一个日常检验：太阳帆能飞吗？** 太阳光在地球轨道能流 $1361\ \mathrm{W/m^2}$，对理想反射面光压 $P = 2I/c \approx 9\ \mu\mathrm{Pa}$。一个 $100\ \mathrm{m^2}$ 的太阳帆受力约 $0.9\ \mathrm{mN}$，对一个 $50\ \mathrm{kg}$ 的探测器加速度约 $1.8\times10^{-5}\ \mathrm{m/s^2}$——很小，但持续数月就能累积出可观速度（这是光压推进的原理）。**「动量密度 $g = S/c^2$」不是理论花边，而是航天工程正在用的推进力**。

**光压的完整计算**：平面波动量密度 $g = S/c^2$，每秒打到单位面积上的动量通量为 $gc = S/c$。吸收面把这份动量全部收下，压强 $P = I/c$；反射面把动量「弹回去」，动量变化翻倍，压强 $P = 2I/c$：

$$
P_{\text{吸收}} = \frac{I}{c}, \qquad P_{\text{反射}} = \frac{2I}{c}
$$

**应用——光帆推进**：太阳常数 $1361\ \mathrm{W/m^2}$，理想反射帆压强约 $9\ \mu\mathrm{Pa}$。一个 $100\ \mathrm{m^2}$ 的帆受力约 $0.9\ \mathrm{mN}$。看似微小，但光压持续不断，数月累积的速度增量可观——这正是 NASA「LightSail 2」（2019）验证的光帆推进原理。

**从坡印亭定理到动量守恒**：对麦克斯韦方程组做矢量运算，可得到动量守恒的微分形式：

$$
\begin{aligned}
\frac{\partial \mathbf{g}}{\partial t} + \nabla\cdot\mathbf{T} &= -\rho\mathbf{E} - \mathbf{J}\times\mathbf{B} \\
&= -\mathbf{f}
\end{aligned}
$$

其中 $\mathbf{T}$ 是麦克斯韦应力张量，$\mathbf{f}$ 是电磁力密度。**「场的动量密度变化率 + 动量流散度 = 场对电荷的反作用力」**——这正是牛顿第三定律在「场-电荷」系统中的表述：电荷被场推，场也被电荷反推。

**辨析｜易错点：** ① 光压公式里的 $I$ 是平均能流密度，不是瞬时值。② 对部分反射面，压强 $P = \dfrac{I}{c}(1 + R)$，$R$ 为反射率。③ 辐射压虽小，却是天体物理的关键机制——恒星内部靠辐射压对抗引力坍缩，理解恒星结构离不开它。

**坡印亭矢量与「能量守恒」的完整闭环**：坡印亭定理 $\dfrac{\partial w}{\partial t} + \nabla\cdot\mathbf{S} = -\mathbf{J}\cdot\mathbf{E}$ 是整个电磁能量学说的总纲——它把「场能变化」「能流」「电荷做功」三者锁进一条守恒律。**与流体力学、弹性力学的守恒方程同构**：$\partial(\text{密度})/\partial t + \nabla\cdot(\text{流}) = (\text{源/汇})$ 是连续介质物理的通用模板。理解坡印亭定理，就理解了「守恒律」这一类方程的通用结构。

## 7 小结

- **能量密度** $w = \dfrac{1}{2}(\mathbf{E}\cdot\mathbf{D} + \mathbf{B}\cdot\mathbf{H})$，真空中 $w = \dfrac{\varepsilon_0 E^2}{2} + \dfrac{B^2}{2\mu_0}$。
- **坡印亭矢量** $\mathbf{S} = \mathbf{E}\times\mathbf{H}$：能流的方向与速率。
- **坡印亭定理** $\dfrac{\partial w}{\partial t} + \nabla\cdot\mathbf{S} = -\mathbf{J}\cdot\mathbf{E}$——电磁场的能量守恒律。
- **动量密度** $\mathbf{g} = \mathbf{S}/c^2$；辐射压对吸收面 $P = I/c$，反射面 $P = 2I/c$。
- 静电能的两套表达式：归于电荷 $W = \frac{1}{2}\int\rho\varphi\,\mathrm{d}V$ 与归于场 $W = \frac{\varepsilon_0}{2}\int E^2\,\mathrm{d}V$。
