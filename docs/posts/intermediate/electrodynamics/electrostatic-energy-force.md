## 为什么「力的计算」要绕道能量

静电场对电荷的力，最直接的办法是用库仑定律或洛伦兹力积分。但工程里真正难算的问题——导体板之间的吸引力、电介质在非均匀场中的受力、微型机电系统（MEMS）的静电驱动——往往不知道感应电荷分布，直接算力很麻烦。而**能量法**提供一条捷径：先算系统的静电能量 $W$，再对广义坐标求导得到广义力。这个「虚功原理」把「求力」转化为「求能量对位移的变化率」，常常能把复杂积分化成简单微分。<span class="marginnote">虚功原理在力学中早已成熟：广义力 $F = -\partial V/\partial q$。把它搬到静电学，关键是要分清系统处于「恒电荷」还是「恒电势」状态——两者对应不同的能量函数与不同的力的表达式。这个区分是整个能量法最容易出错的地方。</span>

## 1 静电能量的两种再表述

回顾《电磁场的能量与动量》：静电能量为 $W_e = \frac{\varepsilon_0}{2}\int E^2\,\mathrm{d}V$。对于**带电导体系统**，还有更便于应用的形式。设 $n$ 个导体分别带电荷 $Q_i$、电势 $V_i$，系统能量为

$$W = \frac{1}{2}\sum_{i=1}^{n} Q_i V_i$$

对单个孤立导体 $W = \frac{1}{2}QV = \frac{Q^2}{2C}$，其中 $C = Q/V$ 是**电容（capacitance）**。<span class="marginnote">对平行板电容器，$C = \varepsilon_0 A/d$，能量 $W = Q^2 d/(2\varepsilon_0 A)$。这个式子直接预示：板距 $d$ 增大时能量增大，且增大速率与板间引力一致——能量法是求板间引力的最快路线。</span>

**电容器的能量与两板受力**：平行板电容器（面积 $A$、间距 $d$、带电荷 $Q$）两板之间的引力可通过两种途径求，得到相同结果：

- 恒电荷：$F = -\left.\dfrac{\partial W}{\partial d}\right|_Q = -\dfrac{Q^2}{2\varepsilon_0 A}$（负号表示能量随 $d$ 增大而增大，力指向减小 $d$——引力）。
- 恒电势：$F = +\left.\dfrac{\partial W}{\partial d}\right|_V = +\dfrac{\varepsilon_0 A V^2}{2d^2}$。

两式表面上差一个正负号，物理上却是同一种力——区别来自能量函数的选取（见下节公式解析）。

## 2 虚功原理：从能量求力

设系统静电能 $W$ 是广义坐标 $\xi$（如板距、转角）的函数。广义力 $F_\xi$ 的两种表达式：

- **恒电荷情形**（与电源断开，$Q$ 恒定）：$F_\xi = -\left.\dfrac{\partial W}{\partial \xi}\right|_Q$。系统隔离，能量减少的方向就是受力方向（力学中 $F = -\mathrm{d}V/\mathrm{d}x$ 的同款）。
- **恒电势情形**（接在电池上，$V$ 恒定）：$F_\xi = +\left.\dfrac{\partial W}{\partial \xi}\right|_V$。此时电池会向系统提供能量，系统能量的增加不等于外功，符号反过来。

**为什么恒电势时符号为正？** 恒 $V$ 下给电容器充入电荷，电池做功；静电力的功 + 电池功 = 系统能量增量。经过简单的能量平衡，得到「力 = 正的能量导数」。<span class="marginnote">两套情形的物理解读：恒电荷是「孤立系统」，能量守恒地转化为机械功；恒电势是「与电源耦合的系统」，电池是能量泵。机电类比：恒电荷像「弹簧」，恒电势像「被恒力源拉着的弹簧」。记住「$Q$ 恒定用负号、$V$ 恒定用正号」这个口诀，能省去每次重推的麻烦。</span>

**辨析｜易错点：** 千万不要把「$F = -\partial W/\partial \xi$」直接套到恒电势情形——那会得到错误的符号、甚至错误的物理（把引力算成斥力）。先确认系统是孤立（恒 $Q$）还是接电源（恒 $V$），再选公式。若拿不准，从能量平衡重新推导一次。

## 3 静电场的张力与压强

把能量法用到「场本身」上，会得到一个优美的结论：静电场对物体表面的作用可以用**麦克斯韦张力**描述。例如，导体表面单位面积受到的静电力为

$$p = \frac{\sigma^2}{2\varepsilon_0} = \frac{1}{2}\varepsilon_0 E^2$$

这是**静电压强（electrostatic pressure）**——方向垂直于导体表面向外（导体表面电荷被「排斥」出表面）。<span class="marginnote">这个压强定量地解释了「静电吸尘」「静电复印」的力从哪来：电荷集中在表面，表面处的电场张力把它们压向导体。闪电球、静电吸附膜、以及 MEMS 中「pull-in 失稳」现象的根源都在这条公式里。</span>

**MEMS 的 pull-in 失稳**：平行板静电执行器中，板间电压驱动可动板靠近。静电力 $\propto V^2/d^2$ 随距离缩短急剧增大，而机械弹簧回复力 $\propto k(d_0 - d)$ 线性增大。当电压超过阈值 $V_{\text{pi}} = \sqrt{8kd_0^3/(27\varepsilon_0 A)}$ 时，静电力在平衡点附近的增长快于弹簧力，系统失稳——可动板「吸合」到固定板。这是静电力与机械弹力的经典竞赛，工程上必须考虑。

## 4 公式解析：为什么恒 $V$ 与恒 $Q$ 的力公式差符号

以平行板电容器为例，这是整个能量法最值得深挖的细节。

- **第一步，写能量**：$W(Q, d) = \dfrac{Q^2 d}{2\varepsilon_0 A}$（用 $Q$ 表达）或 $W(V, d) = \dfrac{\varepsilon_0 A V^2}{2d}$（用 $V$ 表达）。
- **第二步，恒 $Q$ 求导**：板移动 $\mathrm{d}d$，电源不参与。外功 $\mathrm{d}W_{\text{ext}} = F\,\mathrm{d}d$（克服静电力），全部转化为能量增量 $\mathrm{d}W$。由能量守恒 $F\,\mathrm{d}d = \mathrm{d}W$，即 $F = \partial W/\partial d|_Q$。但注意能量增加时力做负功——把「力」定义为「系统对外做功的能力」，就有 $F = -\partial W/\partial d|_Q$。<span class="marginnote">符号约定是能量法唯一的麻烦：力学里势能减少的方向是力的方向（$F = -\mathrm{d}V/\mathrm{d}x$），恒 $Q$ 情形与力学一致；恒 $V$ 情形因为电池向系统注入能量 $\mathrm{d}W_{\text{battery}} = V\,\mathrm{d}Q$，能量平衡多了一项，力反而等于正的能量导数。把「谁在做功、谁在吸收能量」画出来，符号自然就对了。</span>
- **第三步，恒 $V$ 求导**：电压恒定，电荷随距离变化（$Q = CV$ 变小）。电池注入能量 $V\,\mathrm{d}Q$，系统能量变化 $\mathrm{d}W$，静电力做功 $F\,\mathrm{d}d$。能量平衡 $V\,\mathrm{d}Q = \mathrm{d}W + F\,\mathrm{d}d$（电池能量 = 系统增量 + 对外做功）。代入 $W = \frac{1}{2}QV$ 与 $\mathrm{d}Q = Q\mathrm{d}C/C$，整理得 $F = \frac{1}{2}V^2\mathrm{d}C/\mathrm{d}d = +\partial W/\partial d|_V$。数值上，两种方法给出**完全相同**的力 $F = Q^2/(2\varepsilon_0 A)$。

## 5 虚功原理的推广应用

虚功原理不止用于平板：把广义坐标换成**角度**，可得力矩 $M = -\partial W/\partial\theta$；把「力」换成「应力」，可用于电介质中的受力分析。几个典型应用：

- **带电体系的库仑能量**：点电荷系 $W = \frac{1}{2}\sum_{i\neq j}\dfrac{q_i q_j}{4\pi\varepsilon_0 r_{ij}}$——相互作用能等于「逐个把电荷从无穷远搬来」做的功。
- **电偶极子在电场中的能量与力矩**：$\mathbf{\tau} = \mathbf{p}\times\mathbf{E}$，能量 $W = -\mathbf{p}\cdot\mathbf{E}$——偶极子转向电场方向。
- **电介质受力**：非均匀电场对电介质的力 $F = \frac{1}{2}\varepsilon_0(\varepsilon_r - 1)\nabla E^2$ 方向指向场强增大处——这解释了为什么绝缘棒会被带电体吸引。

**辨析｜易错点：** 点电荷系的能量公式 $\frac{1}{2}\sum q_i q_j/(4\pi\varepsilon_0 r_{ij})$ 中的 $\frac{1}{2}$ 因子来自「两两作用被数了两次」，**不能**用于计算单个点电荷的自能（自能发散）。用「把电荷逐个搬来」的方式重推，就能理解 $\frac{1}{2}$ 的来源。

## 6 虚功原理的完整例题：静电执行器

把「恒 $Q$ / 恒 $V$」两种情形放到一个真实的微机电系统（MEMS）例子里，能量法才算真正上手。

**问题**：平行板静电执行器，固定板与可动板间距 $d_0$，可动板连有弹簧（劲度系数 $k$），两板面积 $A$。在可动板上加电压 $V$ 后，板被吸引移动距离 $x$，求平衡位置。

**第一步，写能量。** 板距变为 $d = d_0 - x$，电容 $C = \dfrac{\varepsilon_0 A}{d}$。恒压电源情形，能量用 $V$ 表达：$W = \frac{1}{2}CV^2 = \dfrac{\varepsilon_0 A V^2}{2(d_0 - x)}$。

**第二步，用虚功原理求静电力。** 恒 $V$ 情形用正号公式：

$$F_{\text{el}} = +\frac{\partial W}{\partial x} = \frac{\varepsilon_0 A V^2}{2(d_0 - x)^2}$$

注意力随距离缩短按 $1/(d_0-x)^2$ 增大——**距离越近，静电吸力增长越陡**。

**第三步，与弹簧力平衡。** 弹簧回复力 $F_s = kx$（线性），静电力 $F_{\text{el}} \propto 1/(d_0-x)^2$（非线性）。平衡条件 $F_{\text{el}} = F_s$ 是一个三次方程，并非总有稳定解。

**第四步，发现 pull-in 失稳。** 把两条力曲线画出来：低电压时二者有一个稳定交点（平衡点）；电压超过阈值 $V_{\text{pi}} = \sqrt{\dfrac{8kd_0^3}{27\varepsilon_0 A}}$ 后，在某个临界距离处静电力的增长斜率超过弹簧，平衡消失，可动板「吸合」到固定板——**这就是 MEMS 中最经典的 pull-in 现象**。工程上设计执行器必须让工作点远离 $x = d_0/3$ 的失稳边界。

**辨析｜易错点：** 这个例子最容易错的两处：一是恒 $V$ 情形误用负号公式得到斥力；二是把「静电力 = 弹簧力」直接当成答案，忽略了稳定性判断。**能量法的完整输出是「力 + 稳定性」：先求力，再看平衡是否稳定。**

**静电能量三种表述的对照表**：把能量问题按「对象」分类，是避免公式混淆的最快途径。

| 对象 | 能量表达式 | 适用场景 |
| --- | --- | --- |
| 点电荷系 | $W = \dfrac{1}{2}\sum_{i\neq j}\dfrac{q_iq_j}{4\pi\varepsilon_0 r_{ij}}$ | 少数分立电荷的相互作用能 |
| 连续电荷分布 | $W = \dfrac{1}{2}\int\rho\varphi\,\mathrm{d}V$ | 已知电荷与电势分布 |
| 场能形式 | $W = \dfrac{\varepsilon_0}{2}\int E^2\,\mathrm{d}V$ | 对全空间积分，场论观点 |
| 带电导体系 | $W = \dfrac{1}{2}\sum Q_iV_i$ | 导体系统，配合电容矩阵 |

**辨析｜易错点：** 前三式在「电荷分布固定」时数值相等，但**自能**问题上有分歧：点电荷系的 $\frac{1}{2}\sum_{i\neq j}$ 明确排除了 $i = j$ 的自能（避免发散）；场能形式 $\int E^2$ 对点电荷必然发散（$E^2 \sim 1/r^4$ 在 $r\to 0$ 处积分发散）。**「能量放在电荷上」与「能量放在场上」不只是哲学之争，它决定你算出的能量是有限的还是发散的**——经典理论里点电荷自能发散，这个困难要量子电动力学的重整化才能妥善处理。

**电容与能量的系统视角**：把能量写成电容语言 $W = \frac{1}{2}CV^2 = \frac{Q^2}{2C}$，是电路分析最常用的形式。**电容是「储存电场能量的能力」的度量**：同样的电压，电容越大储能越多。对平行板 $C = \varepsilon A/d$，能量 $W = \frac{1}{2}\varepsilon E^2\cdot Ad$——能量密度 $\times$ 体积，与场能密度 $\frac{1}{2}\varepsilon E^2$ 完全一致。**「电路里的电容储能」与「场论里的电场储能」是同一回事的两种语言。**

**静电力与电场线的张力图像**：法拉第的力线图像认为电场线像「拉紧的橡皮筋」——沿力线方向有张力、垂直于力线方向有压力。静电压强 $p = \frac{1}{2}\varepsilon_0 E^2$ 正是「橡皮筋」张力的定量表述：**两异号电荷之间的电场线像橡皮筋一样把它们拉近，同号电荷之间的电场线像被压缩的弹簧把它们推开**。这个图像在理解静电吸引、以及麦克斯韦应力张量时极其有用。

**辨析｜易错点：** ① 静电压强 $p = \frac{1}{2}\varepsilon_0 E^2$ 中用的是导体表面**外侧**的场（内侧场为零），若混用两侧场会差 2 倍。② 「电场线像橡皮筋」是启发式图像，不可过度外推——它描述的张力/压力由麦克斯韦应力张量严格给出，形象类比只用于直觉。

## 7 小结

- 带电导体系统能量 $W = \frac{1}{2}\sum Q_i V_i$；电容 $C = Q/V$，能量 $W = Q^2/2C$。
- **虚功原理**：恒 $Q$ 时 $F = -\partial W/\partial\xi$；恒 $V$ 时 $F = +\partial W/\partial\xi$——符号由电源是否参与决定。
- **静电压强** $p = \sigma^2/2\varepsilon_0 = \varepsilon_0 E^2/2$，垂直于导体表面向外。
- 电偶极子能量 $W = -\mathbf{p}\cdot\mathbf{E}$，力矩 $\mathbf{\tau} = \mathbf{p}\times\mathbf{E}$。
- MEMS pull-in 失稳是静电力与弹簧力竞争的典型结果。

在下一节，我们把「真空中的静电学」推广到「有物质的静电学」：电介质如何响应电场、极化电荷如何产生、$\mathbf{D}$ 与 $\mathbf{E}$ 的关系——**电介质中的静电场**。
