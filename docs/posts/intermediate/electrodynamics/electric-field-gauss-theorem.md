## 为什么先定义场，再谈力

上一节我们用库仑定律算「两个电荷之间的力」，但力学里更彻底的问题是：当试探电荷 $\mathrm{q}$ 被放到某个位置，是谁在推它？法拉第的回答是：电荷在空间中建立了一种看不见的物理实体——**电场**，其他电荷感受到的力，其实是这个场的作用。<span class="marginnote">场的观念是物理学的一次范式跃迁：从「超距作用」（两个电荷隔空施力）转向「局域作用」（场携带能量与动量，以有限速度传播）。这个转向在电磁波被发现后得到决定性验证——场不再是数学脚手架，而是可传播、可携带能量的真实存在。</span>

## 1 电场强度的定义

**电场强度（electric field）**：单位试探电荷在电场中所受的力。定义为

$$\mathbf{E}(\mathbf{r}) = \lim_{q_0 \to 0} \frac{\mathbf{F}(\mathbf{r})}{q_0}$$

试探电荷 $q_0$ 必须取得足够小，以免它自身的场干扰源电荷分布。电场强度只与源电荷有关，与试探电荷无关，是空间位置 $\mathbf{r}$ 的函数——这就是**场**的含义：空间每一点都配一个矢量。<span class="marginnote">「试探电荷趋于零」是一个理想化过程：真实测量总有个有限大小的探针，物理学家用极限来刻画「测得的场不受测量干扰」这一要求，与数学中导数的定义同构。</span>

由库仑定律，点电荷 $q$ 在距离 $r$ 处产生的电场为

$$\mathbf{E}(\mathbf{r}) = \frac{1}{4\pi\varepsilon_0}\frac{q}{r^2}\hat{\mathbf{r}}$$

它是从点电荷发出的径向场，大小随 $1/r^2$ 衰减。叠加原理对场同样成立：**多个电荷的总场等于各自产生场的矢量叠加**，这使任意电荷分布的电场都可以用积分写出：

$$\mathbf{E}(\mathbf{r}) = \frac{1}{4\pi\varepsilon_0}\int \frac{\rho(\mathbf{r}')(\mathbf{r}-\mathbf{r}')}{|\mathbf{r}-\mathbf{r}'|^3}\,\mathrm{d}V'$$

## 2 电场线与通量

**电场线（field line）**：一族有向曲线，其上每一点的切线方向与该点电场方向一致，线的疏密代表场强大小。电场线有几条重要性质：

- 从正电荷出发，终止于负电荷；不会在无电荷处中断。
- 两条电场线不相交——若相交，交点处场的方向就不唯一。
- 电场线的密度与场强成正比。

<span class="marginnote">「电场线密度正比于场强」看似只是绘图约定，实则是通量概念的直觉来源：穿过某个面的电场线总数，正比于该面上的场强通量。法拉第正是靠「力线」的图景提出了通量思想。</span>

**电通量（electric flux）**：穿过曲面的电场线总数。对任意曲面 $S$，通量定义为面积分

$$\Phi_E = \int_S \mathbf{E}\cdot\mathrm{d}\mathbf{S}$$

其中 $\mathrm{d}\mathbf{S}$ 是面积元矢量，方向取曲面法向。通量可正可负：电场从曲面内侧穿向外侧为正，反之为负。

## 3 高斯定理

**高斯定理（Gauss's law）**：穿过任意闭合曲面的电通量，等于曲面内电荷的代数和除以 $\varepsilon_0$：

$$\oint_S \mathbf{E}\cdot\mathrm{d}\mathbf{S} = \frac{1}{\varepsilon_0} \sum_i q_i = \frac{1}{\varepsilon_0}\iiint_V \rho\,\mathrm{d}V$$

这是库仑定律 + 叠加原理的直接推论，但它的信息量远大于库仑定律本身。三个关键事实藏在里面：

- **与面内电荷分布无关**：不论电荷在面内怎么摆，通量只取决于总电荷。把电荷在面内挪动，通量不变——这是「通量是整体量、场是局域量」的体现。
- **面外电荷对通量零贡献**：面外电荷的场线「穿进去又穿出来」，净通量为零。所以高斯定理只数面内的电荷。
- **不对称性**：球面对称的场穿球面通量是 $4\pi r^2 E$，令其等于 $q/\varepsilon_0$ 立刻解得 $E = q/(4\pi\varepsilon_0 r^2)$——你看，平方反比又一次出现，这正是上一节埋下的伏笔。<span class="marginnote">反过来，若库仑定律的指数不是 2，高斯定理就不成立。1785 年后人们反复用更精密的实验检验 $1/r^{2+\delta}$ 中的 $\delta$，目前给出 $|\delta| < 10^{-16}$，平方反比是自然界最高精度的定律之一。</span>

利用高斯定理可以求解**高度对称**电荷分布的电场，其步骤是一套固定套路：

1. 判断对称性（球对称、柱对称、面对称）；
2. 取合适的高斯面，使面上 $\mathbf{E}$ 的大小恒定、方向与法向平行；
3. 计算通量 $\oint \mathbf{E}\cdot\mathrm{d}\mathbf{S}$，与面内电荷比对，解出 $\mathbf{E}$。

**典型结果**（读者应能独立推出）：

| 电荷分布 | 高斯面 | 场强 |
| --- | --- | --- |
| 均匀带电球壳（半径 $R$，总电荷 $q$） | 同心球面 | 球内 $E = 0$；球外 $E = \dfrac{q}{4\pi\varepsilon_0 r^2}$ |
| 均匀带电球体（半径 $R$，体密度 $\rho$） | 同心球面 | 球内 $E = \dfrac{\rho r}{3\varepsilon_0}$；球外同点电荷 |
| 无限长直线（线密度 $\lambda$） | 同轴圆柱面 | $E = \dfrac{\lambda}{2\pi\varepsilon_0 r}$ |
| 无限大平面（面密度 $\sigma$） | 贯通的柱面 | $E = \dfrac{\sigma}{2\varepsilon_0}$，方向垂直平面 |

**辨析｜易错点：** 球壳内 $E = 0$ 常被误解为「高斯面内没有电荷所以场为零」。准确的说法是「通量为零」——由于球对称性，通量为零唯一地推出场为零。若缺乏对称性，面内无电荷并不能推出面上场强处处为零。高斯定理是**通量**定理，不是**场强**定理，这一点最容易被初学忽略。

## 4 公式解析：高斯定理的微分形式

用高斯散度定理把面积分化为体积分，可把高斯定理从积分形式改写为**微分形式**：

$$\oint_S \mathbf{E}\cdot\mathrm{d}\mathbf{S} = \iiint_V (\nabla\cdot\mathbf{E})\,\mathrm{d}V = \frac{1}{\varepsilon_0}\iiint_V \rho\,\mathrm{d}V$$

- **第一步，拆散度**：左边面积分化为 $\iiint_V \nabla\cdot\mathbf{E}\,\mathrm{d}V$。这一步依赖散度定理——它把「穿过边界的总流量」等价为「内部每一点的源密度之和」。
- **第二步，比对体积分**：右边也是体积分。两边对任意体积 $V$ 都成立，被积函数必须逐点相等，于是得：
  $$\nabla\cdot\mathbf{E} = \frac{\rho}{\varepsilon_0}$$
- **第三步，读懂局域性**：这个方程说的是「电场在某点的散度 = 该点的电荷密度」。散度是场的「源」的度量——电荷就是电场的源（source），电荷为零处散度为零（但不代表场为零！）。<span class="marginnote">注意散度为零 ≠ 场为零：例如匀强电场 $\mathbf{E} = E_0\hat{\mathbf{x}}$ 处处散度为零，但它不是零场。散度只刻画「流出/流入」，刻画不了「旋绕」，后者要等旋度出场，见《静电场环路定理与电势》。</span>

微分形式的高斯定理是麦克斯韦方程组的第一条，也是四条中最直白的一条：**电荷是电场的源**。

## 5 高斯定理应用的三个经典陷阱

高斯定理威力巨大，但用错它的方式也极其典型。把三个高频错误单独拎出来，避免在作业与考试里重蹈覆辙。

**陷阱一：把「面内无电荷」当成「面上场为零」。** 高斯定理只约束通量。一个不带电的空心导体球腔外有电荷时，腔内任意高斯面包围的电荷为零、通量为零，但腔内电场并非处处为零——它是外场在该区域的净效应。只有当对称性（如球对称）保证「通量为零 ⇒ 各点径向场为零」时，才能推出 $E = 0$。**高斯定理是通量定理，不是场强定理。**

**陷阱二：对称性判断失误。** 高斯定理能解场的对称分布只有三类：球对称、柱对称（无限长）、面对称（无限大）。有限长直导线、有限大带电平面**没有**足够对称性，强行套高斯定理会得到错误结果。**「先判对称性，再选高斯面」的顺序不能颠倒。**

**陷阱三：高斯面的取法不合规。** 高斯面必须是闭合曲面，且面上要么场强恒定、要么场强为零，要么场强方向与法向垂直——否则 $\oint\mathbf{E}\cdot\mathrm{d}\mathbf{S}$ 无法化简。很多初学者选「半闭合」的面或让面上场强不均匀，积分根本算不出来。**选高斯面的口诀：让场要么穿面均匀、要么不穿面。**

**一个自检例子：** 无限长均匀带电直线，取半径为 $r$、长度为 $l$ 的同轴圆柱面。侧面通量 $E\cdot 2\pi rl$，上下底面通量为零（场沿径向、垂直于底面法向），面内电荷 $\lambda l$。于是 $E = \dfrac{\lambda}{2\pi\varepsilon_0 r}$——每一步都在验证「对称性 → 高斯面 → 化简」的套路。**把这个例子完整做一遍，比背十道题更有效。**

**电场线的密度与通量的关系**：为什么「电场线密度正比于场强」是合理的？因为从电荷 $q$ 出发的电场线总数正比于 $q$（约定每单位电荷发出固定数量的线），而穿过半径 $r$ 球面的线数不变、球面积 $\propto r^2$，故面密度 $\propto 1/r^2$——**与库仑定律的平方反比自动一致**。电场线的疏密不是「画图的美化」，它本身就是「场强按 $1/r^2$ 衰减」的可视化。

**微分形式的对称性检验**：$\nabla\cdot\mathbf{E} = \rho/\varepsilon_0$ 作为麦克斯韦方程组第一条，它的「局域性」值得强调——**某点的电场散度只由该点的电荷密度决定，与远处的电荷无关**。这来自库仑定律的平方反比：远处电荷的贡献在散度运算下被消掉。**「局域性」是场论区别于超距作用理论的核心特征**，也是麦克斯韦方程组能写成微分方程的基础。

**从高斯定理到库仑定律的反向推导**：高斯定理与库仑定律在静电场中互为充要条件（球对称情形下）。给定 $\nabla\cdot\mathbf{E} = \rho/\varepsilon_0$，对球对称的点电荷分布取球高斯面，立刻反推出 $\mathbf{E} = \dfrac{q}{4\pi\varepsilon_0 r^2}\hat{\mathbf{r}}$——**一条微分方程 + 对称性，就还原出平方反比定律**。这种「微分方程 + 对称性 ⇒ 具体定律」的路线，正是理论物理最常用的推理模式。

## 6 小结

- **电场强度** $\mathbf{E} = \lim_{q_0\to 0}\mathbf{F}/q_0$，是空间位置的矢量函数，与试探电荷无关。
- 点电荷场 $\mathbf{E} = \dfrac{1}{4\pi\varepsilon_0}\dfrac{q}{r^2}\hat{\mathbf{r}}$；任意分布由叠加积分给出。
- **通量** $\Phi_E = \int_S \mathbf{E}\cdot\mathrm{d}\mathbf{S}$ 刻画穿过曲面的「电场线总数」。
- **高斯定理**：闭合面通量 $= q_{\text{内}}/\varepsilon_0$；微分形式 $\nabla\cdot\mathbf{E} = \rho/\varepsilon_0$。
- 高斯定理只在**高度对称**时能直接解出场强，其本质是通量定理而非场强定理。
