## 为什么磁场要单独建一套理论

上一节的静电场无旋，所以存在标量势。但自然界还有另一类场：**磁场**。它由运动电荷（电流）产生，作用在运动电荷上。最关键的区别是：磁场**有旋而无源**——磁感线永远闭合，找不到磁荷。这一节的安培环路定理，就是「磁场版本的高斯定理」，但它多了一个微妙之处：**环量与电流有关，而电流本身又依赖参考系**。这个微妙之处将在麦克斯韦方程组那一节引爆一场革命。<span class="marginnote">「找不到磁单极子」是电磁理论最深的谜之一。若存在孤立磁荷，电磁场方程会变得完全对称（对偶对称），量子理论也会给出电荷必须量子化的自然解释。狄拉克早在 1931 年就预言了磁单极子，但至今实验仍一无所获。</span>

## 1 磁场与毕奥-萨伐尔定律

**磁感应强度（magnetic flux density）$\mathbf{B}$**：描述磁场强弱的矢量场，单位特斯拉（T）。它对运动电荷施加**洛伦兹力**：

$$\mathbf{F} = q\mathbf{v}\times\mathbf{B}$$

力的方向垂直于 $\mathbf{v}$ 与 $\mathbf{B}$ 决定的平面，故洛伦兹力不做功，只改变电荷运动方向。

电流元 $\mathrm{d}\mathbf{l}$ 中通有电流 $I$，它在空间某点产生的磁场由**毕奥-萨伐尔定律（Biot-Savart law）**给出：

$$\mathrm{d}\mathbf{B} = \frac{\mu_0 I}{4\pi}\frac{\mathrm{d}\mathbf{l}\times\hat{\mathbf{r}}}{r^2}$$

其中 $\mu_0 = 4\pi\times 10^{-7}\ \mathrm{T\cdot m/A}$ 是真空磁导率，$\mathbf{r}$ 从电流元指向场点。<span class="marginnote">注意毕奥-萨伐尔定律里的叉乘 $\mathrm{d}\mathbf{l}\times\hat{\mathbf{r}}$：方向由右手定则决定，这正是磁场区别于电场的本质——电场平行于 $\hat{\mathbf{r}}$（沿径线），磁场垂直于 $\hat{\mathbf{r}}$（绕径线转）。「磁场是环状的」由此而来。</span>

对体分布电流密度 $\mathbf{J}$，总磁场的积分形式为

$$\mathbf{B}(\mathbf{r}) = \frac{\mu_0}{4\pi}\int \frac{\mathbf{J}(\mathbf{r}')\times(\mathbf{r}-\mathbf{r}')}{|\mathbf{r}-\mathbf{r}'|^3}\,\mathrm{d}V'$$

**典型结果**：无限长直导线（电流 $I$）在距离 $r$ 处产生 $B = \dfrac{\mu_0 I}{2\pi r}$，磁场线是以导线为轴的同心圆；圆电流轴线上磁场 $B = \dfrac{\mu_0 I R^2}{2(R^2 + z^2)^{3/2}}$，圆心处 $B = \dfrac{\mu_0 I}{2R}$。

## 2 磁场的无源性：$\nabla\cdot\mathbf{B} = 0$

与电场不同，磁场的一个重要性质是**无源**：不存在「磁荷」来发出磁感线，磁感线永远闭合。

$$\nabla\cdot\mathbf{B} = 0$$

积分形式为 $\oint_S \mathbf{B}\cdot\mathrm{d}\mathbf{S} = 0$——穿过任意闭合面的净磁通恒为零。这对应于「高斯磁定律」，是麦克斯韦方程组第二条。<span class="marginnote">「无源」的直接推论：磁感线不能像电场线那样从正极出发到负极终止，只能自己闭合或延伸到无穷远。这也是磁通量 $\Phi = \int \mathbf{B}\cdot\mathrm{d}\mathbf{S}$ 这个「穿过线圈的磁力线数」能用来定义感应电动势的前提——我们会在法拉第定律那一节看到它。</span>

## 3 安培环路定理

**安培环路定理（Ampere's circuital law）**：磁感应强度沿任意闭合回路的环量，等于穿过该回路的电流（代数）和乘以 $\mu_0$：

$$\oint_L \mathbf{B}\cdot\mathrm{d}\mathbf{l} = \mu_0 \sum_i I_i = \mu_0 \iint_S \mathbf{J}\cdot\mathrm{d}\mathbf{S}$$

其中电流的正负由右手定则与回路绕向的关系决定。微分形式由斯托克斯定理得到：

$$\nabla\times\mathbf{B} = \mu_0\mathbf{J}$$

它说明**电流是磁场的旋度源（涡旋源）**：有电流的地方磁场有旋。<span class="marginnote">把电场与磁场摆在一起看：$\nabla\cdot\mathbf{E} = \rho/\varepsilon_0$（电荷是散度源）、$\nabla\times\mathbf{B} = \mu_0\mathbf{J}$（电流是旋度源）。静电场无旋，静磁场无源——两者的数学形象正好互补。</span>

与高斯定理对应，安培环路定理在**高度对称**的电流分布下可直接解出磁场，套路完全相同：选安培环路 → 使环上 $B$ 大小恒定、方向与路径相切 → 算环量与穿过的电流比对。

**典型结果**（读者应能独立推出）：

| 电流分布 | 安培环路 | 磁感应强度 |
| --- | --- | --- |
| 无限长直导线（电流 $I$） | 同心圆 | $B = \dfrac{\mu_0 I}{2\pi r}$ |
| 无限长螺线管（$n$ 匝/米，电流 $I$） | 矩形回路 | 管内 $B = \mu_0 n I$，管外约 0 |
| 无限长圆柱导体（均匀 $\mathbf{J}$） | 同心圆 | 体内 $B = \dfrac{\mu_0 J r}{2}$；体外同导线 |

**辨析｜易错点：** 与高斯定理同理，安培环路定理是**环量**定理。穿过环路的电流为零，只能推出环量为零，推不出环上 $\mathbf{B}$ 处处为零——例如直导线外任取一个不套住导线的圆，环上 $B \neq 0$ 但环量为零。只有当对称性把「环量为零」升级为「每点切向分量为零」时，才能解出场。

## 4 公式解析：毕奥-萨伐尔定律的三层结构

这条公式比库仑定律多一个叉乘，是全篇的难点。拆开看：

**第一步，分子 $\mathrm{d}\mathbf{l}\times\hat{\mathbf{r}}$**：叉乘给出方向——垂直于电流方向与到场方向。这解释了为什么磁感线是「绕」着电流转的圈。电流元 $\mathrm{d}\mathbf{l}$ 沿电流方向，$\hat{\mathbf{r}}$ 指向场点，二者垂直时磁场最强（叉乘最大），平行时为零（直导线延长线上的磁场为零）。
**第二步，分母 $r^2$**：与库仑定律相同的平方反比。磁场也遵守平方反比，因此安培环路定理、以及磁场的许多整体性质与静电场高度平行。
**第三步，系数 $\mu_0/4\pi$**：与 $1/4\pi\varepsilon_0$ 对称的约定。两者的乘积满足 $c^2 = 1/(\varepsilon_0\mu_0)$，其中 $c \approx 3\times10^8\ \mathrm{m/s}$——这个不起眼的关系在麦克斯韦那里将揭示**光就是电磁波**。<span class="marginnote">$c^2 = 1/(\varepsilon_0\mu_0)$ 在 1856 年就被韦伯与科尔劳施测出与光速接近，但直到麦克斯韦 1861 年修正位移电流后才获得理论意义。这是「实验数据早已躺在那，理论范式缺席」的经典案例。</span>

## 5 从磁场到矢势：下一章的伏笔

由 $\nabla\cdot\mathbf{B} = 0$ 与「散度为零的场可以写成某矢量场的旋度」（亥姆霍兹分解），存在**磁矢势（vector potential）$\mathbf{A}$**：

$$\mathbf{B} = \nabla\times\mathbf{A}$$

矢势的引入让磁场方程自动满足无源条件。它与标势 $\varphi$ 一起构成电磁场的双势描述。矢势具有**规范自由度**——$\mathbf{A}$ 加一个标量函数的梯度不改变 $\mathbf{B}$，这一自由度将贯穿整个电动力学（见《磁场与矢势》一节）。<span class="marginnote">「无源→存在矢势」与「无旋→存在标势」是矢量分析的一对姊妹定理。它们让四大力学的静场问题都归结为解势函数的边值问题——学完本节，你已经掌握了这一整套势语言的钥匙。</span>

## 6 磁场计算的两种风格与一个检验

磁场计算有两条互补路线：毕奥-萨伐尔定律（积分，普适但繁重）与安培环路定理（只需对称性，快捷但受限）。把它们放到同一个例子里对比。

**例：无限长直导线的磁场，两种算法。** 用毕奥-萨伐尔定律：电流元 $\mathrm{d}l$ 到场点的距离 $r$、夹角 $\theta$，积分得 $B = \dfrac{\mu_0 I}{2\pi r}$——需要对角度积分，过程约五六步。用安培环路定理：取半径 $r$ 的同心圆，$B\cdot 2\pi r = \mu_0 I$，一步得同解。**对称性够时，环路定理永远更快；对称性不够（如有限长导线、任意形状线圈），只能回到毕奥-萨伐尔积分。**

**磁场方向的判断要单独训练。** 右手定则的正确用法：右手四指沿电流方向弯曲，拇指指向 $\mathrm{d}\mathbf{l}$，则磁感线沿四指弯曲方向环绕。或更直接：四指沿 $\mathrm{d}\mathbf{l}\times\hat{\mathbf{r}}$ 的方向旋转。**叉乘方向判断错误是磁场题的第一失分点——建议每个方向问题都画一遍 $\mathrm{d}\mathbf{l}$、$\hat{\mathbf{r}}$、$\mathrm{d}\mathbf{B}$ 三矢量图再作答。**

**检验工具：单位与极限。** 任何磁场公式都应通过两关检验：量纲关（$B$ 单位是特斯拉，$\mu_0 I / r$ 的量纲为 $\mathrm{T}$）与极限关（$r \to \infty$ 时场趋于零、$r \to 0$ 时场发散——发散方式对导线是 $1/r$、对点偶极是 $1/r^3$）。**「算完先做两个检验」的习惯，能把公式记错率降一半。**

**辨析｜易错点：** 安培环路定理里的电流必须是「穿过回路所张任意曲面的电流」且带符号（右手定则与回路绕向决定正负）。同一个回路，若你选不同的张曲面，穿过曲面的电流必须相同——这正是「位移电流」登场前安培定理在时变场里暴露矛盾的地方（见麦克斯韦方程组一节）。

**安培定义与电流单位**：两条平行无限长直导线通有相同电流，相距 $1\ \mathrm{m}$，每米受力 $2\times10^{-7}\ \mathrm{N}$ 时，导线中的电流定义为 $1$ 安培。这个定义直接来自平行导线的磁场公式 $F/l = \dfrac{\mu_0 I_1I_2}{2\pi d}$ 与 $\mu_0 = 4\pi\times10^{-7}$ 的约定。**「安培」这个单位本身就是安培环路定理 + 毕奥-萨伐尔定律的应用**——物理单位与物理定律在这里互相咬合。

**磁场对电流的力：电流天平与电机**。通电导体在磁场中受力 $\mathrm{d}\mathbf{F} = I\,\mathrm{d}\mathbf{l}\times\mathbf{B}$，这是洛伦兹力的宏观形式。直流电机的转动力矩、扬声器音圈的运动、电流天平测安培，全都建立在「磁场对载流导线施力」这个事实上。**「电荷受洛伦兹力」的微观描述与「导线受安培力」的宏观描述，是同一个物理的两层语言。**

**辨析｜易错点：** $\mathrm{d}\mathbf{F} = I\,\mathrm{d}\mathbf{l}\times\mathbf{B}$ 中力的方向由叉乘决定，垂直于电流与磁场构成的平面——**「左手定则」与「右手定则」之争**本质是叉乘方向与约定习惯的问题。判断时先写 $\mathrm{d}\mathbf{l}\times\mathbf{B}$ 的叉乘方向（用右手定则），比记口诀可靠。

**磁场与电场的对偶对照**：把静电场与静磁场的基本关系摆在一起，能看到近乎完美的对偶结构：

| 概念 | 静电场 | 静磁场 |
| --- | --- | --- |
| 源 | 电荷 $\rho$ | 电流 $\mathbf{J}$ |
| 基本定律 | 库仑定律 | 毕奥-萨伐尔定律 |
| 通量定理 | $\oint\mathbf{E}\cdot\mathrm{d}\mathbf{S} = q/\varepsilon_0$ | $\oint\mathbf{B}\cdot\mathrm{d}\mathbf{S} = 0$ |
| 环量定理 | $\oint\mathbf{E}\cdot\mathrm{d}\mathbf{l} = 0$ | $\oint\mathbf{B}\cdot\mathrm{d}\mathbf{l} = \mu_0 I$ |
| 势 | 标量势 $\varphi$ | 矢势 $\mathbf{A}$ |

**这张表的「破绽」正是物理的核心**：静电场有散度源（电荷）、无旋度源（无旋）；静磁场有旋度源（电流）、无散度源（无磁荷）。**「电学有单极子、磁学没有」是电与磁唯一的本质不对称**——它决定了为什么电场用标势、磁场用矢势。

**辨析｜易错点：** ① 毕奥-萨伐尔定律与库仑定律虽都是平方反比，但前者带叉乘、是「力」的源（旋度型），后者不带叉乘、是「散度」的源——**同样的 $1/r^2$，方向结构完全不同**。② 「磁场是相对论下的电场」这一说法，到狭义相对论章节才严格成立；在静磁框架内把 $\mathbf{B}$ 当作独立实体来计算并无问题。

## 7 小结

- **毕奥-萨伐尔定律** $\mathrm{d}\mathbf{B} = \dfrac{\mu_0 I}{4\pi}\dfrac{\mathrm{d}\mathbf{l}\times\hat{\mathbf{r}}}{r^2}$：电流元产生环状磁场。
- **洛伦兹力** $\mathbf{F} = q\mathbf{v}\times\mathbf{B}$：磁场只改变电荷运动方向，不做功。
- 磁场**无源**：$\nabla\cdot\mathbf{B} = 0$，磁感线闭合，无磁单极子。
- **安培环路定理** $\oint\mathbf{B}\cdot\mathrm{d}\mathbf{l} = \mu_0 I_{\text{内}}$，微分形式 $\nabla\times\mathbf{B} = \mu_0\mathbf{J}$。
- $\varepsilon_0\mu_0 = 1/c^2$——这个恒等式预告了电磁波的存在。
