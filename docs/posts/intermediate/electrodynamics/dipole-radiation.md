# 电磁波的辐射（偶极辐射）

## 为什么「静态电荷」与「辐射」隔着一条加速

电荷静止，产生静电场；电荷匀速运动，产生随行磁场——但都不辐射。**只有加速运动的电荷才辐射电磁波**。这一节从推迟势出发，研究最简单的辐射源——**振荡电偶极子**，得到辐射场、辐射功率与角分布。这不仅是天线的物理基础，也是「场从源上剥离开、携带能量飞走」的最干净例证。<span class="marginnote">「加速才辐射」的直觉来自场的滞后：电荷加速时，远处的场还停留在「旧的匀速状态」，新旧场的「错位」就形成向外传播的扰动——电磁波。电荷匀速运动不辐射，是因为它的场能「跟着走」；只有加速度才能撕裂场的「同步」。</span>

## 1 推迟势：辐射的出发点

时变源的势不能再用「瞬时的库仑/毕奥-萨伐尔积分」，因为场的传播需要时间。**推迟势（retarded potential）**为

$$\varphi(\mathbf{r},t) = \frac{1}{4\pi\varepsilon_0}\int\frac{\rho(\mathbf{r}', t_r)}{R}\,\mathrm{d}V', \qquad \mathbf{A}(\mathbf{r},t) = \frac{\mu_0}{4\pi}\int\frac{\mathbf{J}(\mathbf{r}', t_r)}{R}\,\mathrm{d}V'$$

其中 **$t_r = t - R/c$ 是推迟时间**，$R = |\mathbf{r}-\mathbf{r}'|$ 是源到场点的距离。物理含义：**t 时刻场点「看到」的是源在更早时刻 $t_r$ 的状态**——场以速度 $c$ 传播，信息需要时间赶到。<span class="marginnote">推迟势是「光速有限」的必然结果：没有「瞬时超距」，一切都是「过去的源」在说话。这也是为什么「太阳光到地球是 8 分钟前离开太阳的」。把 $t_r = t - R/c$ 换成 $t$（忽略滞后）就退回静态公式——辐射正是推迟效应的产物。</span>

**辨析｜易错点：** 推迟势中的 $\rho(\mathbf{r}', t_r)$ 与 $\mathbf{J}(\mathbf{r}', t_r)$ 是在**推迟时刻**取值的——被积函数里藏着一个 $t$ 的依赖，不能简单地「先积分再代 $t$」。严格推导要用 $\delta$ 函数把推迟条件写进积分。这是时变电磁场与静态场最本质的差别。

## 2 振荡电偶极子的辐射场

**模型**：电偶极矩 $\mathbf{p}(t) = p_0\cos\omega t\,\hat{\mathbf{z}}$（两个等量异号电荷以角频率 $\omega$ 振荡）。它的辐射由矢势主导。辐射区（远场，$r \gg \lambda$、$r \gg d$）的推迟矢势可解为

$$\widetilde{\mathbf{A}}(\mathbf{r}) = \frac{\mu_0}{4\pi}\frac{-i\omega\mathbf{p}_0}{r}e^{ikr}$$

其中 $k = \omega/c$。取旋度得磁场，再用法拉第定律得电场，远场结果：

$$\widetilde{\mathbf{B}} = -\frac{\mu_0\omega^2 p_0}{4\pi c}\frac{\sin\theta}{r}e^{ikr}\,\hat{\boldsymbol{\phi}}, \qquad \widetilde{\mathbf{E}} = c\,\widetilde{\mathbf{B}}\times\hat{\mathbf{r}}$$

辐射场的结构特征：

- **球面波**：场强 $\propto 1/r$ 衰减（不是静场的 $1/r^2$！）——能流密度 $|\mathbf{S}| \propto 1/r^2$，穿过球面的总功率与 $r$ 无关，能量真的「飞走了」。
- **横波**：$\mathbf{E}$、$\mathbf{B}$ 都垂直于传播方向 $\hat{\mathbf{r}}$，且 $\mathbf{E} = c\mathbf{B}\times\hat{\mathbf{r}}$（与平面波同构）。
- **角分布**：场强 $\propto \sin\theta$，沿偶极矩方向（$\theta = 0$）无辐射，垂直方向（$\theta = \pi/2$）最强——偶极子的辐射有「方向性」。<span class="marginnote">为什么沿偶极方向不辐射？因为辐射是横波：沿偶极轴方向看，源是「沿视线方向的振荡」，没有横向分量可辐射。这个「纵向上看不到横辐射」的道理，是所有天线方向图设计的直觉基础。</span>

## 3 辐射功率：拉莫尔公式

**时间平均辐射功率**由坡印亭矢量对球面积分得到：

$$\langle P \rangle = \int \langle \mathbf{S} \rangle\cdot\mathrm{d}\mathbf{S} = \frac{\mu_0 p_0^2\omega^4}{12\pi c}$$

这是**偶极辐射的功率公式**。用加速电荷的语言改写：单个电荷 $q$ 以加速度 $a(t)$ 振荡（偶极矩 $p_0 = q a_0/\omega^2$ 的关系代入），得**拉莫尔公式（Larmor formula）**：

$$P = \frac{q^2 a^2}{6\pi\varepsilon_0 c^3}$$

**辨析｜易错点：** 辐射功率正比于**加速度平方**（$\omega^4 p_0^2 \propto a^2$），不是速度平方。匀速运动（$a = 0$）不辐射；匀加速辐射。而且 $\omega^4$ 依赖极强——低频振荡几乎不辐射（这就是为什么输电线（50 Hz）的辐射损耗可忽略，而 GHz 频段的射频天线轻松辐射）。<span class="marginnote">$\omega^4$ 依赖的后果：蓝光（高频）比红光（低频）被大气散射更强——瑞利散射定律「散射强度 ∝ $1/\lambda^4$」正来自偶极辐射的 $\omega^4$ 因子。天空为什么蓝、夕阳为什么红，都可以从这一节推出。</span>

**角分布**：微分辐射功率 $\dfrac{\mathrm{d}P}{\mathrm{d}\Omega} = \dfrac{\mu_0 p_0^2\omega^4}{32\pi^2 c}\sin^2\theta$——「8 字形」方向图，垂直方向最强。

## 4 公式解析：为什么辐射场按 $1/r$ 衰减而非 $1/r^2$

这是全节最反直觉、也最关键的一点：

- **第一步，回顾静态场**：静电场 $E \propto 1/r^2$，穿过大球面的通量 $\int E\cdot\mathrm{d}S \propto (1/r^2)\cdot r^2 = \text{常数}$——总能量静止不动，无辐射。静态场的能量「锁」在源附近。
- **第二步，看推迟势的结构**：辐射区矢势 $\widetilde{\mathbf{A}} \propto \dfrac{p_0}{r}e^{ikr}$。取旋度 $\nabla\times\widetilde{\mathbf{A}}$ 时，作用在 $e^{ikr}/r$ 上有两类项：作用在 $1/r$ 得 $\propto 1/r^2$（近场、静态型），作用在 $e^{ikr}$ 得 $\propto ik(1/r)$（远场、辐射型）。**辐射场正是「梯度打在相位因子 $e^{ikr}$ 上」产出的那一项**，比静态项慢一个 $r$ 量级。<span class="marginnote">也就是说：推迟势的相位因子 $e^{ikr}$ 是辐射的发动机。没有相位因子（静态源），一切场都按 $1/r^2$ 衰减；有了随距离变化的相位，旋度就能「多扣」出一个 $1/r$ 的辐射项。这个「相位因子 → $1/r$ 场」的结构，是所有辐射问题的共同骨架。</span>
- **第三步，能量论证**：能流 $|\langle\mathbf{S}\rangle| \propto E^2 \propto 1/r^2$。对半径 $r$ 的球面积分，$P = \int\langle S\rangle\,\mathrm{d}A \propto (1/r^2)\cdot 4\pi r^2 = \text{常数}$——**总辐射功率与 $r$ 无关**，能量离开源永不回头。这正是「辐射」的定义：功率独立于观测距离，源源不断地把源的能量带走。

## 5 辐射场与近场、天线

**分区**：偶极子周围分为近场区（$r \ll \lambda$，准静态场、$1/r^2$ 与 $1/r^3$ 主导，能量在源与场之间振荡）与远场区（$r \gg \lambda$，辐射场 $1/r$ 主导，能量外流）。过渡区约在 $r \sim \lambda/2\pi$。<span class="marginnote">近场/远场的分界是波长尺度：频率越低、波长越长，近场区越大。这也解释了为什么低频信号（长波）的天线必须很大——天线需要把近场区「撑开」才能有效辐射。50 Hz 电力信号波长 6000 km，几乎不可能辐射，反而成了输电的优点。</span>

**天线的视角**：天线是一根导线中的振荡电流，可视为无穷多个偶极子的叠加。半波偶极子天线的辐射方向图、增益、输入阻抗，全部从偶极辐射出发计算。天线设计的基本问题——「如何让电流分布的辐射叠加同相增强」——是偶极辐射理论在工程上的直接延伸。

## 6 偶极辐射的完整计算：辐射电阻

把偶极辐射公式用到天线设计里，看看「能量真的飞走了」如何变成工程参数。

**问题**：一短偶极子天线，长度 $l$，电流峰值 $I_0$，工作频率 $\omega$。求其辐射电阻。

**第一步，写偶极矩。** 短偶极子可近似为电流均匀分布，偶极矩 $\mathbf{p} = q\mathbf{d}$ 与电流的关系：$p_0 = \dfrac{I_0 l}{\omega}$（因为 $I = \mathrm{d}q/\mathrm{d}t = -i\omega q$，幅度关系 $q_0 = I_0/\omega$，偶极矩 $p_0 = q_0 l$）。

**第二步，代辐射功率。** 时间平均辐射功率

$$\langle P \rangle = \frac{\mu_0 p_0^2\omega^4}{12\pi c} = \frac{\mu_0 I_0^2 l^2\omega^2}{12\pi c} = \frac{\mu_0 I_0^2 l^2}{12\pi c}\left(\frac{2\pi c}{\lambda}\right)^2 = \frac{\pi}{3}\sqrt{\frac{\mu_0}{\varepsilon_0}}\left(\frac{l}{\lambda}\right)^2 I_0^2$$

**第三步，定义辐射电阻**。把辐射功率写成「像电阻耗散」的形式 $\langle P\rangle = \frac{1}{2}R_r I_0^2$：

$$R_r = \frac{2\pi}{3}\sqrt{\frac{\mu_0}{\varepsilon_0}}\left(\frac{l}{\lambda}\right)^2 = 80\pi^2\left(\frac{l}{\lambda}\right)^2\ \Omega$$

其中 $\sqrt{\mu_0/\varepsilon_0} \approx 377\ \Omega$ 是自由空间波阻抗。**辐射电阻正比于 $(l/\lambda)^2$**——天线长度远小于波长时辐射电阻极小（$l = \lambda/10$ 时 $R_r \approx 8\ \Omega$），大部分功率耗散在导体电阻上，辐射效率低。**这就是为什么天线要设计成 $\lambda/4$、$\lambda/2$ 量级**——短天线不好用，根本原因在 $(l/\lambda)^2$ 因子。

**辐射电阻的物理意义**：它把「场带走的功率」等价成一个电阻的焦耳热。**「天线把功率辐射出去」与「电阻把功率变成热」在电路模型里不可区分**——这是「辐射电阻」概念能成立的原因，也是天线工程师用电路语言思考辐射的基础。

**辨析｜易错点：** ① $p_0 = I_0 l/\omega$ 的推导依赖「短偶极子电流均匀」的近似，长天线电流沿线分布，需积分。② 辐射电阻 $R_r$ 与欧姆损耗电阻 $R_{\text{ohm}}$ 是两个不同的量，天线效率 $\eta = \dfrac{R_r}{R_r + R_{\text{ohm}}}$——**低效天线往往是 $R_{\text{ohm}}$ 太大，而不是 $R_r$ 太小**。③ 偶极辐射功率 $\propto \omega^4$ 意味着低频辐射极弱——50 Hz 输电线几乎不辐射，就是这个因子在起作用。

**近场与远场的能量命运**：近场区（$r \ll \lambda$）的能量在源与场之间**往返振荡**，不向外传播——这是「无功功率」；远场区（$r \gg \lambda$）的能量**单向流出**——这是「有功功率」。两者的分界在 $\sim\lambda/2\pi$ 处。**「天线是否辐射」取决于近场与远场的相对大小**：波长极短（微波）时近场区很小，天线附近就是辐射区；波长极长（低频）时近场区巨大，源的大部分能量都在「原地振荡」而不是「飞走」——这正是低频天线辐射效率低的深层原因。

**偶极辐射角分布的积分检验**：辐射功率由角分布积分得到：

$$\langle P \rangle = \int_0^\pi \frac{\mu_0 p_0^2\omega^4}{32\pi^2 c}\sin^2\theta\cdot 2\pi\sin\theta\,\mathrm{d}\theta = \frac{\mu_0 p_0^2\omega^4}{32\pi c}\int_0^\pi\sin^3\theta\,\mathrm{d}\theta$$

利用 $\int_0^\pi\sin^3\theta\,\mathrm{d}\theta = \dfrac{4}{3}$，得 $\langle P\rangle = \dfrac{\mu_0 p_0^2\omega^4}{32\pi c}\cdot\dfrac{4}{3} = \dfrac{\mu_0 p_0^2\omega^4}{12\pi c}$——与前面的结果一致。**「从角分布积分出总功率」是辐射问题的标准收尾动作**，它同时检验了角分布公式与功率公式。

**推迟势的 $\delta$-函数推导**：推迟势不是「猜出来的」，而是解非齐次波动方程得到的。时变源的势满足

$$
\nabla^2\varphi - \frac{1}{c^2}\frac{\partial^2\varphi}{\partial t^2} = -\frac{\rho}{\varepsilon_0}
$$

其格林函数（推迟格林函数）为

$$
G(\mathbf{r},t;\mathbf{r}',t') = \frac{1}{4\pi\varepsilon_0}\frac{\delta(t' - t + R/c)}{R}
$$

**推迟格林函数把「过去的光锥」上的源贡献积分起来**——这正是「势由推迟时刻的源决定」的数学来源。偶极辐射的所有结果都可以从这里系统推出，推迟格林函数是辐射理论的统一起点。

**偶极辐射与天线方向图**：偶极辐射的 $\sin^2\theta$ 角分布在工程里对应天线的方向图——沿偶极轴方向辐射为零、垂直方向最强。**「8 字形」方向图是偶极子天线的标志**，而阵列天线正是通过排列多个偶极子、利用干涉把辐射「压」到特定方向——相控阵雷达、基站天线阵列的物理基础就是偶极辐射 + 干涉叠加。

**辨析｜易错点：** ① 推迟格林函数中的 $\delta(t' - t + R/c)$ 表示「只有在过去光锥上、且提前 $R/c$ 时刻的源才贡献」——用「超前格林函数」（$t' - t - R/c$）会得到违反因果的解，物理上必须选推迟的。② 偶极近似 $p_0 = qd$ 的适用条件是「源尺寸远小于波长」（$d \ll \lambda$）；源尺寸与波长同量级时必须用更精细的电流分布模型。

## 7 小结

- **推迟势**：$t_r = t - R/c$，场的传播需要时间，是辐射的根源。
- 振荡偶极子的远场是**球面波**：$\mathbf{E}, \mathbf{B} \propto \sin\theta/r$，横波，$1/r$ 衰减。
- **辐射功率** $\langle P \rangle = \dfrac{\mu_0 p_0^2\omega^4}{12\pi c}$，即**拉莫尔公式** $P = \dfrac{q^2a^2}{6\pi\varepsilon_0 c^3}$——正比加速度平方。
- 辐射角分布 $\propto \sin^2\theta$，偶极方向无辐射。
- 近场（$1/r^2, 1/r^3$ 静态场）与远场（$1/r$ 辐射场）以波长尺度分界。
