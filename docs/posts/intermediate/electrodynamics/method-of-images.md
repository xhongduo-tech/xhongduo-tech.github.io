# 镜像法

<div class="epigraph">

## 为什么镜像法看起来像「作弊」

边值问题的标准解法是分离变量法——但也存在一类问题，它的解可以靠**猜**猜出来：在导体边界之外放一个（或几个）**假想的镜像电荷**，用「真实电荷 + 镜像电荷」的库仑叠加去满足边界条件，唯一性定理保证猜到的解就是真解。这就是**镜像法（method of images）**。它把「导体表面感应电荷的复杂分布」这一未知量，全部打包进几个虚拟点电荷——计算量从解级数降为解代数。<span class="marginnote">镜像法的合法性完全来自唯一性定理：只要叠加出的势满足「区域内泊松方程 + 边界条件」，无论过程多么取巧，结果都对。这就像猜谜——唯一性保证「猜到的就是答案」，前提是你验证了方程与边界。</span>

## 1 接地导体平面的镜像

**问题**：接地无限大导体平面（$z = 0$），上方 $z = a$ 处放点电荷 $q$，求 $z > 0$ 空间的电场与导体表面感应电荷。

**思路**：导体平面的作用等价于在平面另一侧对称位置放一个假想电荷 $-q$——即**镜像电荷（image charge）**。在 $z>0$ 空间，问题变成「两个异号电荷 $q$ 与 $-q$ 在真空中的叠加」，而导体平面所在的 $z=0$ 面上，两点电荷到场点的距离相等，电势恰好处处为零：

$$\varphi(x,y,z) = \frac{1}{4\pi\varepsilon_0}\left(\frac{q}{r_+} - \frac{q}{r_-}\right), \qquad r_\pm = \sqrt{x^2 + y^2 + (z \mp a)^2}$$

**验证**：$z=0$ 时 $r_+ = r_-$，$\varphi = 0$，满足接地边界条件；$z>0$ 区域泊松方程只含真实电荷 $q$。由唯一性定理，这就是原问题的解。<span class="marginnote">镜像电荷在 $z>0$ 区域没有任何物理意义——它只是求解工具。真正存在于导体表面的，是感应电荷，其面密度 $\sigma(x,y) = -\dfrac{qa}{2\pi(x^2+y^2+a^2)^{3/2}}$，总量恰好为 $-q$，且从 $\sigma$ 对平面积分可检验。把镜像电荷误当成「真实存在」，是镜像法最常见的误解。</span>

**受力计算**：真实电荷 $q$ 受到导体感应电荷的吸引力。用镜像法，这个力等于「$q$ 与 $-q$ 的库仑力」——$F = \dfrac{q^2}{4\pi\varepsilon_0 (2a)^2}$，方向指向平面。**这是用镜像法计算力的核心技巧：力由镜像电荷之间的相互作用给出。**

## 2 接地导体球与球形镜像

**问题**：接地导体球（半径 $R$），球外 $b$ 处放点电荷 $q$，求球外电势。

球对称问题的镜像电荷不再是对称点上的等量异号电荷，而是**球内一个位置经过专门调整的电荷**。设镜像电荷 $q'$ 位于球心与 $q$ 连线上、距球心 $a' = R^2/b$ 处，取

$$q' = -\frac{R}{b}\,q$$

则球面上任意一点到 $q$ 与到 $q'$ 的距离之比恒为 $b/R$，于是 $\dfrac{q'}{r'} + \dfrac{q}{r}$ 在球面上恰好为零（验证：$r/r' = b/R$ 时 $q'/r' + q/r = -(Rq/b)/(r\cdot R/b) + q/r = 0$）。<span class="marginnote">$a' = R^2/b$ 称为<strong>反转半径</strong>，是球面镜像的关键几何量。它来自球面反演（inversion）变换——把球面反演映射 $r \to R^2/r$ 应用到点电荷上。数学里的「反演圆」与电动力学中的「镜像球」，用的是同一个几何。</span>

**物理后果**：球外电势 = 点电荷 $q$ + 镜像电荷 $q'$ 的叠加。感应电荷总量恰好等于 $q' = -Rq/b$（比平面情形 $q' = -q$ 小，因为球面不是无限大）。导体球对电荷的吸引力 $F = \dfrac{1}{4\pi\varepsilon_0}\dfrac{qq'}{(b-a')^2}$，代入整理得 $F = -\dfrac{q^2 R b}{4\pi\varepsilon_0(b^2-R^2)^2}$——在 $b \gg R$ 极限下退化为点电荷对感应偶极的引力。

## 3 公式解析：为什么镜像电荷要放在 $a' = R^2/b$ 处

这是镜像法中最容易卡壳的一步：为什么镜像电荷不在对称点？

- **第一步，写出球面上势为零的条件**：球面 $r = R$ 上，$q$ 与 $q'$ 的势之和为零：$\dfrac{q}{4\pi\varepsilon_0 r} + \dfrac{q'}{4\pi\varepsilon_0 r'} = 0$，即 $\dfrac{q'}{q} = -\dfrac{r'}{r}$。要让此式在球面任意点成立，右侧必须是与角度无关的常数。
- **第二步，几何关系**：场点与球心距离 $b$（$q$ 的位置）、镜像距离 $a'$（$q'$ 的位置）。由余弦定理，$r^2 = b^2 + R^2 - 2bR\cos\theta$，$r'^2 = a'^2 + R^2 - 2a'R\cos\theta$。若 $\dfrac{a'}{b} = \dfrac{R^2}{b^2}$，即 $a' = R^2/b$，则 $r'/r = a'/b = R/b$ 为常数——这正是「$r/r'$ 恒定」的几何来源。
- **第三步，定电荷**：把 $r'/r = R/b$ 代入 $\dfrac{q'}{q} = -\dfrac{r'}{r}$，得 $q' = -\dfrac{R}{b}q$。两步合一：**先选位置使距离比恒定，再选电荷量使势为零**。<span class="marginnote">这套「距离比恒定」的思路还能推广到两个相交导体球面（用两组镜像电荷）、以及导体圆柱（镜像为一条均匀线电荷）。每种几何对应一组特定的镜像配置——记忆的关键不是背公式，而是理解「距离比恒定」这个几何条件。</span>

## 4 多种镜像配置

镜像法的配置库不止平面与球：

| 边界几何 | 镜像配置 | 说明 |
| --- | --- | --- |
| 无限大接地平面 | 对称点放 $-q$ | 最基础，验证边界为零 |
| 接地导体球 | 球内 $a' = R^2/b$ 处放 $q' = -Rq/b$ | 反转半径 |
| 绝缘导体球（总电荷 $Q$） | 球内再加 $Q - q'$ 于球心 | 球心电荷保证总电荷 |
| 两相交接地平面（夹角 $\pi/n$） | $2n-1$ 个镜像电荷 | $n$ 为整数时镜像可闭合 |
| 导体圆柱 | 镜像为圆柱内一条均匀线电荷 | 二维情形的类比 |

**辨析｜易错点：** 两相交平面夹角的镜像法有一个致命陷阱：只有夹角为 $\pi$ 的整数分之几（即 $\pi/n$，$n$ 整数）时，镜像电荷才能在有限个内闭合。夹角如 $60° = \pi/3$ 需要 5 个镜像；但夹角 $72° = 2\pi/5$（不能写成 $\pi/n$）则镜像永不闭合，镜像法失效。<span class="marginnote">判断标准：把每个镜像当作「镜子中的镜子」，绕公共棱转一圈，转回原位时若镜像已闭合且电荷分布周期化，则镜像法可行。这个「旋转对称下镜像闭合」的条件，本质上是群的有限性条件——又是数学结构决定物理方法可用性的例子。</span>

## 5 镜像法的边界：何时能用、何时失效

- **能用**：边界是平面、球面、柱面等「单点可反演」的几何；导体接地或带已知总电荷。
- **失效**：边界形状任意；介质界面（介电常数不同的两个半空间问题可解，但镜像电荷是「混合类型」，不如导体边界干净）；需要场在导体内部的值时（镜像法只保证边界与外部空间正确）。

镜像法的哲学：**唯一性定理让我们可以「猜」，而几何直觉负责「猜得好」**。它和分离变量法互为补充：分离变量法系统但繁重，镜像法优雅但只适用于特殊几何。实际求解时常先看能否用镜像法，不行再分离变量，再不行就数值计算。

## 6 镜像法的完整应用流程

镜像法的难点不在公式而在「如何找到镜像」。把流程拆成四步，配一个非平面例子的完整计算。

**步骤一：确认能用。** 边界必须是平面、球面、柱面等可反演几何；导体接地或带已知总电荷。**先判「能不能用镜像」，再动手。**

**步骤二：放置镜像电荷。** 目标是「让真实电荷 + 镜像电荷的叠加在边界上满足边界条件」。平面镜像放对称点、等量异号；球面镜像放在反转半径处、电量按比例缩。**放置的判据是「边界上的势（或法向导数）被凑成已知值」。**

**步骤三：在感兴趣的区域写解。** 用「真实电荷 + 镜像电荷」的库仑叠加直接写出区域内的电势，再取梯度得场。**镜像电荷只在「被镜像的区域」之外存在——它在求解区域内没有任何物理意义。**

**步骤四：用唯一性定理收尾。** 验证解满足方程与边界条件，由唯一性定理保证它就是真解。**「验证 + 唯一性」是镜像法合法的全部理由。**

**一个完整例子：点电荷与绝缘带电球。** 半径为 $R$ 的**绝缘**导体球带总电荷 $Q$，球心距点电荷 $q$ 为 $b$（$b > R$）。解由三部分组成：

1. 镜像电荷 $q' = -\dfrac{R}{b}q$ 放在反转半径 $a' = R^2/b$ 处，负责让球面（接地部分）势为零；
2. 球心放电荷 $Q - q'$，负责把总电荷补成 $Q$（球心电荷不影响球面等势性，只抬升整体电势）；
3. 总电势 $= \dfrac{1}{4\pi\varepsilon_0}\left[\dfrac{q}{|\mathbf{r}-\mathbf{b}|} + \dfrac{q'}{|\mathbf{r}-\mathbf{a}'|} + \dfrac{Q - q'}{r}\right]$。

**这个例子的意义**：接地球（$Q=0$）与绝缘球（给定 $Q$）的差别，只在球心多一个「补电荷」项。**镜像法的核心不是背三个特例，而是学会「用镜像凑边界 + 用额外项凑守恒量」的思维方式。**

**辨析｜易错点：** 镜像电荷的位置与电量是**一起**决定的，不能只定一个。平面情形两者恰好都是「对称 + 等量」，容易造成「镜像就是对称镜像」的错觉；球面情形位置与电量都要按反演关系算。**先算位置（反转半径），再算电量（比例 $R/b$），顺序不能反。**

**镜像法在「导体 + 介质」问题中的推广**：镜像法不只处理单个导体，也能处理「导体球 + 介质界面」的复合几何。例如「接地导体球半埋在介电常数为 $\varepsilon$ 的介质中」这类问题，需要在介质-真空界面两侧分别设置不同的镜像配置。**它的通用思想不变——把边界效应翻译成「等效源」，再用唯一性定理担保正确**，只是等效源的数目与类型变多。

**镜像法的历史与别称**：镜像法源于开尔文勋爵 1848 年前后的工作，英文叫 method of images 或 method of image charges。它也是「格林函数法」在特殊几何下的自然产物（见下一节）——镜像电荷本身就是「满足边界条件的格林函数」的一种构造。**「镜像」与「格林函数」是同一枚硬币的两面**：镜像法给直觉，格林函数给系统，二者互补。

**辨析｜易错点：** ① 镜像法解出的区域内的场，是「真实电荷 + 镜像电荷」叠加的结果，但**导体内部的场不可用镜像法计算**——镜像法只保证边界与外部区域正确。② 若导体不是接地而是带已知电势 $V_0$，在镜像电荷之外还要在球心（或合适位置）放一个「抬升电势」的电荷/项，把边界电势从 0 抬到 $V_0$。③ 判断镜像问题能否成立，始终回到「边界条件能否被有限个虚拟电荷凑出来」这一条。

**镜像法与唯一性定理的严格论证**：镜像法的每一步都要回到唯一性定理才能「免责」。对接地平面 + 点电荷，验证如下：

$$
\nabla^2\varphi = -\frac{q}{\varepsilon_0}\delta(\mathbf{r}-\mathbf{a}) \quad (z>0), \qquad \varphi|_{z=0} = 0
$$

镜像解 $\varphi = \dfrac{q}{4\pi\varepsilon_0}\left(\dfrac{1}{r_+} - \dfrac{1}{r_-}\right)$ 满足：① $z>0$ 区域内只有真实电荷 $q$，泊松方程正确；② $z=0$ 面上 $r_+ = r_-$，$\varphi = 0$ 满足边界。**由唯一性定理，这个解就是唯一正确的解**——这就是「镜像法合法」的完整论证。

**感应电荷分布的计算**：接地平面上感应电荷面密度为

$$
\sigma(x,y) = -\varepsilon_0\left.\frac{\partial\varphi}{\partial z}\right|_{z=0} = -\frac{qa}{2\pi(x^2+y^2+a^2)^{3/2}}
$$

对全平面积分 $\int\sigma\,\mathrm{d}S = -q$——**感应电荷总量恰好等于镜像电荷**。这个「总量守恒」是镜像法配置正确的重要自检：平面情形总量 $-q$，球面情形总量 $-Rq/b$，都对上了才算解对。

**辨析｜易错点：** ① 由 $\sigma = -\varepsilon_0\partial\varphi/\partial z$ 算感应电荷时，法向导数必须在**界面内侧**取极限，方向约定错了会差符号。② 「感应电荷总量 = 镜像电荷」只在「接地或孤立导体」情形成立；若导体与电源相连、电势固定，感应电荷总量由电容决定，不再是简单镜像量。

## 7 小结

- **镜像法**：用假想电荷替代导体边界，由唯一性定理保证解正确。
- 接地平面镜像：对称位置 $-q$；感应电荷总量 $-q$。
- 接地球镜像：$a' = R^2/b$（反转半径），$q' = -Rq/b$。
- **力的计算**：真实电荷受力 = 与镜像电荷的库仑力。
- 限制条件：镜像有限闭合需边界夹角为 $\pi/n$；任意几何不能靠镜像。

在下一节，我们把「点电荷的势」推广为「任意电荷分布的势」：借助一个被称为格林函数的影响函数，一次解决一族边值问题——**格林函数法**。
