# 分离变量法

## 为什么分离变量法是静电学的第一武器

上一节我们把静电问题归结为解拉普拉斯方程 + 边界条件。但「二阶偏微分方程」怎么解？分离变量法给出了一条系统路线：**假设 $\varphi$ 是若干单变量函数的乘积**，把偏微分方程拆成几个常微分方程，逐个求解后再叠加去凑边界条件。它在球、柱、直角三类坐标下有各自的完备函数系——勒让德多项式、贝塞尔函数、三角函数——构成一套「按对称性选坐标系、按坐标系选函数系」的完整方法论。<span class="marginnote">分离变量法不仅是静电学的工具，更是整个数学物理方程的核心方法：波动方程、热传导方程、薛定谔方程的定解问题全都靠它。你在这里学的「本征值问题」套路，在量子力学的谐振子、氢原子问题里会原封不动地重现。</span>

## 1 方法的基本思想

以二维拉普拉斯方程为例。设 $\varphi(x, y)$ 满足

$$\frac{\partial^2\varphi}{\partial x^2} + \frac{\partial^2\varphi}{\partial y^2} = 0$$

**第一步，分离**：假设解可写成乘积 $\varphi(x,y) = X(x)Y(y)$。代入方程并除以 $XY$：

$$\frac{X''}{X} + \frac{Y''}{Y} = 0$$

左边第一项只依赖 $x$，第二项只依赖 $y$。要让它们的和恒为零，两项必须各自等于常数：$X''/X = -\alpha^2$，$Y''/Y = \alpha^2$。这里「一项只依赖一个变量」是关键——正因为 $x$ 与 $y$ 可以独立变化，两个「只依赖各自变量」的函数之和恒为零，只能是常数。于是偏微分方程退化为两个**常微分方程**。

**第二步，解本征问题**：$X'' + \alpha^2 X = 0$ 的解是 $\sin(\alpha x), \cos(\alpha x)$；$Y'' - \alpha^2 Y = 0$ 的解是 $\sinh(\alpha y), \cosh(\alpha y)$（或指数）。$\alpha$ 并非任意——边界条件会把它离散化成本征值。<span class="marginnote">「边界条件决定本征值」是分离变量法的灵魂：在有限区间 $0 \le x \le a$ 上要求 $X(0) = X(a) = 0$，会强制 $\alpha = n\pi/a$，$n$ 为整数。这个离散化在量子力学里就是「束缚态能级量子化」的数学来源。</span>

**第三步，叠加**：线性方程的解是各个分离解之和，$\varphi = \sum_n (A_n\sin\alpha_n x + B_n\cos\alpha_n x)(C_n\sinh\alpha_n y + D_n\cosh\alpha_n y)$，系数由边界条件用傅里叶级数确定。

**辨析｜易错点：** 分离变量法的假设「$\varphi = XY$」并不是普遍成立的——它只对「线性齐次方程 + 坐标对齐的边界」有效。若边界是倾斜的或方程含非齐次项，先要处理成可分离的形式（如把点电荷奇异项提出、把泊松方程的特解提出）。把分离变量法当成万能钥匙，会碰壁。

## 2 直角坐标与柱坐标

### 直角坐标

直角坐标的核心是三角/双曲函数对。典型的应用场景是「矩形区域内电势为 0，某一边界电势给定」的盒子问题。给定边界条件后，解为二重或三重傅里叶级数。这一类问题直接、机械，但缺乏几何美感。

### 柱坐标

柱坐标 $(r, \theta, z)$ 中，拉普拉斯方程为

$$\frac{1}{r}\frac{\partial}{\partial r}\left(r\frac{\partial\varphi}{\partial r}\right) + \frac{1}{r^2}\frac{\partial^2\varphi}{\partial\theta^2} + \frac{\partial^2\varphi}{\partial z^2} = 0$$

设 $\varphi = R(r)\Theta(\theta)Z(z)$。$\Theta$ 满足 $\Theta'' + m^2\Theta = 0$（$m$ 整数，因角度周期性），$Z$ 满足 $Z'' - k^2 Z = 0$，而 $R$ 满足**贝塞尔方程**：

$$r^2 R'' + r R' + (k^2 r^2 - m^2)R = 0$$

其解为**贝塞尔函数** $J_m(kr)$ 与 $N_m(kr)$。<span class="marginnote">贝塞尔函数在柱对称问题中的地位，如同勒让德多项式在球对称问题中。它们都是特殊函数——无穷级数定义、有正交性、有递推关系。学电动力学时会「被迫」学会这些函数，而它们在波导、谐振腔、以及信号处理（贝塞尔滤波器）中都是常客。</span>

## 3 球坐标与勒让德多项式

球坐标是静电学最重要的坐标系。设 $\varphi = R(r)\Theta(\theta)\Phi(\phi)$。轴对称情形（$\partial/\partial\phi = 0$）下，拉普拉斯方程分离后，角度部分满足**勒让德方程**：

$$\frac{1}{\sin\theta}\frac{\mathrm{d}}{\mathrm{d}\theta}\left(\sin\theta\frac{\mathrm{d}\Theta}{\mathrm{d}\theta}\right) + l(l+1)\Theta = 0$$

要求 $\Theta$ 在 $\theta \in [0,\pi]$ 上有限，$l$ 被迫为整数，解是**勒让德多项式** $P_l(\cos\theta)$：

$$P_0(x) = 1, \quad P_1(x) = x, \quad P_2(x) = \frac{3x^2 - 1}{2}, \quad P_3(x) = \frac{5x^3 - 3x}{2}$$

径向部分满足 $r^2 R'' + 2rR' - l(l+1)R = 0$，解为 $R = Ar^l + Br^{-(l+1)}$。于是一般解写为

$$\varphi(r,\theta) = \sum_{l=0}^{\infty}\left(A_l r^l + B_l r^{-(l+1)}\right)P_l(\cos\theta)$$

**「$l$ 的取值由奇性/无穷远条件决定，$A_l, B_l$ 由边界条件决定」**。$r=0$ 处有限的解必须 $B_l = 0$；无穷远处为零的解必须 $A_l = 0$。<span class="marginnote">勒让德多项式是角度函数的「完备正交基」：任意轴对称的角分布都能展开成 $\sum c_l P_l(\cos\theta)$，系数 $c_l = \frac{2l+1}{2}\int_{-1}^{1} f(x)P_l(x)\,\mathrm{d}x$。这种「把函数按正交基展开」的思想，与傅里叶级数完全同源——只是换了基底函数。</span>

## 4 公式解析：均匀外场中的介质球

这是分离变量法的经典例题，完整走一遍流程。

**问题**：半径 $R$、介电常数 $\varepsilon_2$ 的介质球，置于均匀外场 $\mathbf{E}_0$（沿 $z$ 轴）中。求球内外的电势。

- **第一步，写出一般解**：取外场方向为极轴，问题轴对称。无穷远处 $\varphi \to -E_0 r\cos\theta + \text{const}$，这是外场的势（取常数项为零）。球外（$r > R$）解取 $\varphi_1 = -E_0 r\cos\theta + \sum_l B_l r^{-(l+1)}P_l(\cos\theta)$；球内（$r < R$）解取 $\varphi_2 = \sum_l C_l r^l P_l(\cos\theta)$（$r=0$ 处有限，舍 $r^{-(l+1)}$ 项）。
- **第二步，用界面条件定系数**：在 $r = R$ 处，电势连续 $\varphi_1 = \varphi_2$，且法向电位移连续 $\varepsilon_1\partial\varphi_1/\partial r = \varepsilon_2\partial\varphi_2/\partial r$。比对每一项 $P_l$ 的系数，发现除 $l=1$ 外所有系数为零——边界条件是 $\cos\theta = P_1$，只有 $l=1$ 项能被激发。
- **第三步，读出物理**：解得 $B_1 = \dfrac{\varepsilon_2 - \varepsilon_1}{\varepsilon_2 + 2\varepsilon_1}R^3 E_0$，$C_1 = -\dfrac{3\varepsilon_1}{\varepsilon_2 + 2\varepsilon_1}E_0$。球内是**均匀场** $\mathbf{E}_2 = \dfrac{3\varepsilon_1}{\varepsilon_2+2\varepsilon_1}\mathbf{E}_0$；球外场 = 外场 + 一个**电偶极子**场，偶极矩 $p = 4\pi\varepsilon_1\dfrac{\varepsilon_2-\varepsilon_1}{\varepsilon_2+2\varepsilon_1}R^3\mathbf{E}_0$。导体极限 $\varepsilon_2 \to \infty$ 时，球内场为零、球外退化为导体球的偶极场——一切自洽。<span class="marginnote">这个例题的价值在于展示了「边界条件如何筛选分离解」：只有与边界形状匹配的谐波（这里是 $l=1$）才存活。更深刻的是，介质球的响应被压缩成一个标量——极化率——这为《电介质中的静电场》里「微观分子如何响应宏观外场」的讨论做了铺垫。</span>

## 5 分离变量法的适用范围与局限

- **适用**：边界与某一坐标系的坐标面重合（球面、柱面、平面）；线性齐次方程。
- **局限**：边界形状任意（如椭球、带棱角的导体）时，分离变量法失效，需要数值方法或格林函数法。
- **补充手段**：非齐次方程（含自由电荷）先把特解提出，再对剩余齐次方程分离变量；多介质的层状结构在每层分别展开，用界面条件连接系数。

## 6 分离变量法的完整操作清单

分离变量法看似步骤繁多，其实是一张固定的流程表。把它整理成可照做的清单，做任何一道题都不慌。

**步骤一：选坐标系。** 看边界的形状——球面用球坐标、圆柱面用柱坐标、平面用直角坐标。**坐标系与边界对齐**是分离变量法的前提，选错坐标系一切白搭。

**步骤二：写出一般解。** 球坐标轴对称问题直接写出 $\varphi = \sum_l (A_l r^l + B_l r^{-(l+1)})P_l(\cos\theta)$。由「$r=0$ 处有限」舍掉 $r^{-(l+1)}$ 项，由「$r \to \infty$ 电势为零」舍掉 $r^l$ 项。**先按奇性/无穷远条件砍掉一半系数，再按边界条件定剩下的。**

**步骤三：匹配边界条件。** 把边界上的已知函数展开成对应函数系（勒让德级数或傅里叶级数），逐项比对系数。这里用到的正交性：$\int_{-1}^1 P_l(x)P_{l'}(x)\,\mathrm{d}x = \dfrac{2}{2l+1}\delta_{ll'}$——**正交性把「无穷多个系数」解耦成「一个个独立方程」。**

**步骤四：检验。** 把解代回边界条件验证；检查极限行为（$r\to\infty$ 是否趋于已知外场、$r\to 0$ 是否有限）。**唯一性定理保证：只要验证通过，这个解就是唯一正确的解。**

**一个常见的简化技巧：** 若边界条件是 $\cos\theta$（即 $P_1$），则解里只会出现 $l = 1$ 项——因为不同阶的 $P_l$ 在角度上正交，$\cos\theta$ 不能激发 $l \neq 1$ 的项。**「边界条件只激发匹配阶数的谐波」这条规律，能让很多题一眼看出答案。**

**辨析｜易错点：** ① 轴对称假设（$\partial/\partial\phi = 0$）只在边界绕极轴旋转对称时成立；否则角度部分还要加 $\Phi(\phi)$ 与连带勒让德函数。② 一般解中的 $A_l$、$B_l$ 符号约定随教材不同，混用会导致场的方向错。③ 若区域内有自由电荷，泊松方程的特解要先提出，分离变量法只解齐次部分。

**勒让德多项式的正交性与完备性**：分离变量法能「逐项比对系数」，靠的是正交性 $\int_{-1}^1 P_l(x)P_{l'}(x)\,\mathrm{d}x = \dfrac{2}{2l+1}\delta_{ll'}$。任意「合理的」轴对称角分布 $f(\theta)$ 都能展开为 $\sum_l c_l P_l(\cos\theta)$，系数 $c_l = \dfrac{2l+1}{2}\int_0^\pi f(\theta)P_l(\cos\theta)\sin\theta\,\mathrm{d}\theta$。**完备性保证「展开不漏项」，正交性保证「系数互不干扰」**——这两个性质是所有谱方法（傅里叶级数、勒让德级数、贝塞尔级数）的共同支柱，也是数值计算里「谱方法」高效的根源。

**分离变量法与其他解法互通**：介质球例题的偶极解 $\varphi \propto \cos\theta/r^2$ 其实就是一个电偶极子的势——**分离变量法解出的「均匀外场中的球」问题，正是「球被极化出一个等效偶极子」的图像**。这提示我们：三种经典解法不是孤立的，镜像法、分离变量法、格林函数法在「对称几何 + 线性方程」的框架下会给出同一答案的不同表述。**学完三种方法后，用同一道题分别用三种方法各解一遍，是最有效的整合练习。**

**球谐函数与更一般的球问题**：若问题不具轴对称性（边界绕极轴不旋转对称），角度部分需要完整的**球谐函数** $Y_{lm}(\theta,\phi) = P_l^m(\cos\theta)e^{im\phi}$，一般解为 $\varphi = \sum_{lm}(A_{lm}r^l + B_{lm}r^{-(l+1)})Y_{lm}$。**轴对称只是 $m=0$ 的特例**——大多数教材先从轴对称入手，是因为 $m \neq 0$ 的数学复杂度掩盖了物理。多极展开、辐射多极、量子力学氢原子都用球谐函数，它是球对称世界的通用语言。

**辨析｜易错点：** ① 分离变量法的解是无穷级数，实际计算要截断到有限项——截断误差取决于边界条件的「光滑程度」，边界越光滑收敛越快。② 「$r=0$ 处有限」与「$r\to\infty$ 处为零」是两个极限条件，分别删掉 $r^{-(l+1)}$ 与 $r^l$ 项；若问题区域不包含 $r=0$（如球壳），两类项都要保留。③ 勒让德多项式正交区间是 $[-1,1]$（对应 $\cos\theta$），积分时 $\mathrm{d}x = -\sin\theta\,\mathrm{d}\theta$ 的符号要小心。

## 7 小结

- 分离变量法 = 假设 $\varphi$ 为**单变量乘积** → 偏微分方程拆成**常微分方程** → 本征值由边界条件离散化 → 叠加凑边界。
- 三类坐标三套函数系：**直角**（三角/双曲函数）、**柱坐标**（贝塞尔函数）、**球坐标**（勒让德多项式）。
- 球坐标轴对称一般解：$\varphi = \sum_l (A_l r^l + B_l r^{-(l+1)})P_l(\cos\theta)$。
- 均匀外场中的介质球：球内均匀场、球外偶极子场——边界条件筛选出 $l=1$ 项。

在下一节，我们将使用唯一性定理的「偷懒」玩法：不硬解方程，而是**猜**一个满足边界的解——**镜像法**。
