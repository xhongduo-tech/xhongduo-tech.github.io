## 为什么静电问题的本质是「边值问题」

第一章建立了完整的方程：静电场的电势满足泊松方程 $\nabla^2\varphi = -\rho/\varepsilon_0$。但方程本身不够——它有无穷多解。物理上真正要解决的是：给定了电荷分布与边界上的条件，唯一地确定空间的电场。这类问题称为**静电场的边值问题（boundary value problem）**。它与「积分直接求场」是两种互补的路线：能直接积分时（已知全部电荷分布）用库仑叠加；不能直接积分时（电荷分布部分未知，例如导体表面的感应电荷）就必须解边值问题。<span class="marginnote">导体边值问题的典型场景：把一个点电荷放到接地的导体球附近。导体表面的感应电荷分布事先不知道，但它必须满足「导体表面电势为零」这个边界条件。先有边界条件、后有电荷分布——这正是边值问题比积分法更强大的地方。</span>

## 1 从泊松方程到边值问题

静电场的势函数 $\varphi$ 满足泊松方程，在无源区域满足拉普拉斯方程：

$$\nabla^2\varphi = -\frac{\rho}{\varepsilon_0} \qquad \text{（有源区）}$$

$$\nabla^2\varphi = 0 \qquad \text{（无源区）}$$

要唯一确定解，必须在边界 $\Sigma$ 上补充条件。经典边值问题有三类：

- **第一类边值问题（狄利克雷）**：给定边界上 $\varphi$ 的值 $\varphi|_{\Sigma} = f(\mathbf{r})$。导体表面电势已知时用这类。<span class="marginnote">狄利克雷条件对应「固定势」：例如导体球保持电势 $V_0$，无穷远处电势为零。物理上，第一类条件由「导体与电源相连」实现。</span>
- **第二类边值问题（诺伊曼）**：给定边界上电势的法向导数 $\left.\dfrac{\partial\varphi}{\partial n}\right|_{\Sigma} = g(\mathbf{r})$。由于 $E_n = -\partial\varphi/\partial n$，这等价于给定边界上的法向场强——即给定面电荷密度（导体表面 $\sigma = \varepsilon_0 E_n$）。<span class="marginnote">第二类条件对应「固定电荷」：导体带已知总电荷时，法向场强（也就是面电荷密度）被锁定。诺伊曼条件的解差一个常数——电势的绝对零点不可由第二类条件确定，还需另加约定。</span>
- **第三类边值问题（混合/罗宾）**：边界上同时给出 $\varphi$ 与 $\partial\varphi/\partial n$ 的线性组合。

**解的唯一性**：给定合适的边界条件，静电边值问题的解唯一（对第一类问题由能量泛函极值或格林公式证明；第二类问题解差常数）。**唯一性定理（uniqueness theorem）**是整个静电学最有力的工具：它保证「只要找到一个满足方程与边界条件的解，它就是要找的那个」，从而让镜像法、试探解等方法成为合法——你不需要从零推导，只要猜中一个解就赢。

**辨析｜易错点：** 边界条件必须在**整个**边界上给出，而不是只在部分边界。缺了某段边界条件，解不唯一；给多了（第一类与第二类条件同时硬给）则可能无解。物理问题中「导体的电势与总电荷不能同时自由指定」——指定电势就决定了电荷，反之亦然。

## 2 静电问题的两大数学工具

### 叠加原理

泊松方程与拉普拉斯方程都是**线性**方程。若 $\varphi_1$ 满足 $\nabla^2\varphi_1 = -\rho_1/\varepsilon_0$、$\varphi_2$ 满足 $\nabla^2\varphi_2 = -\rho_2/\varepsilon_0$，则 $\varphi_1 + \varphi_2$ 满足 $\nabla^2(\varphi_1+\varphi_2) = -(\rho_1+\rho_2)/\varepsilon_0$。这使复杂电荷分布可拆成若干简单分布分别求解再叠加。<span class="marginnote">叠加原理是「线性」这门数学的全部红利。它也是分离变量法、格林函数法、以及傅里叶级数解边值问题的理论基础——所有经典解法都是在反复使用「把复杂解拆成简单解的叠加」这一招。</span>

### 广义解与唯一性

在有导体与点电荷的问题中，电势在电荷位置有奇性（$\varphi \sim q/4\pi\varepsilon_0 r$），在导体表面有边界跃变。处理办法是把点电荷的贡献当作**已知奇异项**显式提出，把其余部分（光滑的感应场）作为待求的齐次解。例如「点电荷 + 接地导体球」的问题中，令 $\varphi = \varphi_{\text{点电荷}} + \varphi_{\text{感应}}$，其中 $\varphi_{\text{感应}}$ 满足拉普拉斯方程，且边界条件为 $\varphi_{\text{感应}}|_{\Sigma} = -\varphi_{\text{点电荷}}|_{\Sigma}$。

## 3 边界上的连接条件

静电问题还经常遇到**两种介质**或**介质-导体**交界面，场量在交界面两侧要满足**边值关系（boundary conditions）**。由麦克斯韦方程组的积分形式在薄层极限下得到：

- **法向分量**：$D_{2n} - D_{1n} = \sigma_f$，即电位移矢量的法向分量跨过自由面电荷时发生跃变，跃变值等于面自由电荷密度。
- **切向分量**：$E_{2t} - E_{1t} = 0$，即电场切向分量连续（静电场无旋的直接推论）。<span class="marginnote">用势函数表达更常用：$\varphi_1 = \varphi_2$（势连续）且 $\varepsilon_1\dfrac{\partial\varphi_1}{\partial n} - \varepsilon_2\dfrac{\partial\varphi_2}{\partial n} = \sigma_f$（法向电位移的跃变）。若界面上无自由电荷，则 $\varepsilon_1\partial\varphi_1/\partial n = \varepsilon_2\partial\varphi_2/\partial n$。这一对条件是后面《电介质中的静电场》反复使用的连接条件。</span>

**辨析｜易错点：** 电场强度 $\mathbf{E}$ 的**法向**分量在无自由电荷的界面上**不**连续（它由 $\varepsilon$ 的比值决定），而电位移 $\mathbf{D}$ 的法向分量连续；磁场/电场切向分量的连续性则相反地依赖于电流面密度。把「$\mathbf{E}$ 连续」误当成「$\mathbf{E}$ 处处连续」是常见的错误——只有切向分量连续，法向分量要看界面两侧的介电常数。

## 4 公式解析：唯一性定理为什么成立

唯一性定理是边值问题的方法论基石。以第一类问题为例，证明的骨架：

- **第一步，作差**：假设存在两个解 $\varphi_1$、$\varphi_2$ 都满足泊松方程与相同边界条件。令 $u = \varphi_1 - \varphi_2$，则 $u$ 满足拉普拉斯方程 $\nabla^2 u = 0$，且边界上 $u|_{\Sigma} = 0$。
- **第二步，能量积分**：利用恒等式 $\nabla\cdot(u\nabla u) = u\nabla^2 u + |\nabla u|^2 = |\nabla u|^2$（因为 $\nabla^2 u = 0$），对区域积分并用散度定理：$\int_V |\nabla u|^2\,\mathrm{d}V = \oint_{\Sigma} u\nabla u\cdot\mathrm{d}\mathbf{S} = 0$（边界上 $u = 0$）。
- **第三步，结论**：非负函数 $|\nabla u|^2$ 在区域内的积分为零，故 $|\nabla u|^2 \equiv 0$，即 $\nabla u = 0$，$u$ 为常数；再由边界 $u = 0$ 知 $u \equiv 0$。于是 $\varphi_1 = \varphi_2$，解唯一。<span class="marginnote">这个证明只用了一个恒等式和散度定理，却点破了「能量积分」的核心地位：静电场的能量 $\frac{\varepsilon_0}{2}\int|\nabla\varphi|^2\,\mathrm{d}V$ 对给定边界条件取极小值，正是最小能量原理——力学中的「势能极小」在静电场中的翻版。这个思想在后面《静电场的能量与作用力》一节会深化。</span>

## 5 三类经典解法预告

边值问题确立了目标，接下来的三节就是三件武器：

- **分离变量法**：在对称边界（球、柱、平面）上把 $\varphi$ 写成「径向 × 角度」的乘积级数，逐项满足方程与边界。
- **镜像法**：用假想电荷（镜像电荷）替换导体边界，把边值问题化为「两个真实点电荷的叠加」，凭唯一性定理保证正确。
- **格林函数法**：把边界效应打包进一个「影响函数」$G$，任意电荷分布的势场由 $G$ 对源积分得到。

## 6 边值问题的完整解法演示

把本章的「方程 + 边界条件 + 唯一性」思想用一道完整的题走一遍，看它们如何咬合成一套方法。

**问题**：两块相距 $d$ 的接地平行大平板，$x = 0$ 与 $x = d$ 处电势为零，两板之间 $x = a$ 处有一条均匀带电的薄层，面电荷密度 $\sigma$。求板间电势分布。

**第一步，分区分段。** 薄层把空间分成两段：$0 < x < a$ 与 $a < x < d$，两段内部无源，电势都满足拉普拉斯方程 $\nabla^2\varphi = 0$。一维问题的解是直线 $\varphi = A x + B$，但两段的斜率不同，需分别设常数：

$$\varphi_1(x) = A_1 x, \qquad \varphi_2(x) = A_2(x - d)$$

（已分别用 $\varphi(0) = 0$ 与 $\varphi(d) = 0$ 消去一个常数。）

**第二步，用界面条件接起来。** 在 $x = a$ 处：电势连续 $\varphi_1(a) = \varphi_2(a)$；法向电位移跃变 $\varepsilon_0(E_1 - E_2) = \sigma$，即 $\varepsilon_0(-A_1 + A_2) = \sigma$。解二元一次方程组得

$$A_1 = \frac{\sigma(d-a)}{\varepsilon_0 d}, \qquad A_2 = -\frac{\sigma a}{\varepsilon_0 d}$$

**第三步，读出物理。** 板间场强 $E_1 = -A_1 = \dfrac{\sigma(d-a)}{\varepsilon_0 d}$、$E_2 = -A_2 = \dfrac{\sigma a}{\varepsilon_0 d}$——**薄层两侧场强不等，差恰好是 $\sigma/\varepsilon_0$**。这个例子的完整结构（分段设解 → 界面条件定系数 → 场强跃变）就是后面分离变量法、镜像法处理的一切边值问题的骨架。

**辨析｜易错点：** 「界面法向电位移跃变 $\sigma$」的方向约定：$\sigma$ 指界面上的自由面电荷密度，法向方向由介质 1 指向介质 2。本例中薄层两侧都是真空，只是把「面电荷两侧的场强差」写成了跃变条件。**把「面电荷处场强跃变 $\sigma/\varepsilon_0$」当作死记结论，不如记住它来自「薄层两侧各做一次高斯定理」的推导。**

**诺伊曼问题的唯一性**：第二类边值问题（给 $\partial\varphi/\partial n$）的解**差一个常数**——因为拉普拉斯方程与边界条件只约束导数，不约束整体电势零点。物理上这对应于「零势点可以任选」。但若补充一个整体条件（如给定导体的总电荷，或指定某点电势），解就完全唯一。**「诺伊曼问题解不唯一」不是病，而是「电势零点自由」的数学表达。**

**导体边值问题的两个自然边界条件**：导体表面有两种等价的描述方式——「给定电势 $V$」（导体接电源）或「给定总电荷 $Q$」（导体孤立）。两者通过「导体的电容矩阵」关联：$Q_i = \sum_j C_{ij}V_j$。**边值问题选哪类边界条件，取决于实验上「锁定」的是什么量**：接电池锁电压，孤立锁电荷。

**边值问题与数值方法**：解析方法（分离变量、镜像、格林函数）只覆盖可分离几何；任意形状的导体（如芯片引脚、人体）只能用数值方法——有限差分、有限元把拉普拉斯方程离散成线性方程组，用「边界条件决定解」这个同样的逻辑求解。**理解「边值问题」的概念，是理解一切电磁数值模拟的前提。**

**边值问题的能量泛函视角**：唯一性定理的证明依赖于能量泛函 $\int_V |\nabla\varphi|^2\,\mathrm{d}V$ 的极小性。事实上，静电边值问题等价于「在满足边界条件的函数里，找使泛函 $F[\varphi] = \int_V\left(\frac{1}{2}\varepsilon|\nabla\varphi|^2 - \rho\varphi\right)\mathrm{d}V$ 取极小的函数」。**这个「变分表述」是有限元方法的理论基础**——有限元不直接解微分方程，而是离散化能量泛函并求极小，在任意形状边界上逼近真解。

**导体系统的电容矩阵**：对 $n$ 个导体，$Q_i = \sum_j C_{ij}V_j$。电容矩阵 $C_{ij}$ 有明确的物理解释：$C_{ii}$ 是自电容、$C_{ij}$（$i\neq j$）是互感系数。**电容矩阵是对称的（$C_{ij} = C_{ji}$），且 $C_{ii} > 0$**——这两个性质来自能量正定与互易定理。多导体系统的静电能量 $W = \frac{1}{2}\mathbf{V}^T C \mathbf{V}$，把「电容」从单导体概念推广为整个系统的矩阵描述。

**辨析｜易错点：** 电容矩阵中的 $C_{ij}$ 是「几何 + 介质」的属性，与电荷/电压的大小无关（线性介质中）。但电容与「导体是否接地」有关——接地导体的电势被固定为 0，自由度减少，电容矩阵也随之改变。**「电容是常数」只在线性介质与固定几何下成立。**

**平均值的两个性质**：静电学里有两条简洁的「平均定理」值得记住——① 无源区域内，$\varphi$ 在任意点的值等于以该点为球心的球面上的平均值；② 无源区域内 $\varphi$ 不可能有极值（极大或极小）。**「调和函数无极值」直接推论：电势的极大/极小只可能出现在边界或电荷处**——导体空腔内的电势被边界值唯一确定，不可能在腔体内出现「意外」的峰。这两条平均定理是理解边值问题解的结构、以及数值求解收敛性的有力工具。

**辨析｜易错点：** 平均定理的成立前提是「无源区域」（$\nabla^2\varphi = 0$）。含电荷的区域里 $\varphi$ 可以在电荷处取极值（如点电荷的势在 $r\to 0$ 处发散）。另外，「无极值」指的是「无内部极值」，边界上的极值不受此限——区分「区域内」与「边界上」，是这两条定理最容易出错的地方。

**狄利克雷与诺伊曼条件的物理解读**：两类边界条件对应实验上「锁定」的不同物理量。狄利克雷（给定 $\varphi$）= 导体接电压源，锁定电势；诺伊曼（给定 $\partial\varphi/\partial n$）= 导体孤立，锁定面电荷密度（因 $\sigma = \varepsilon_0 E_n = -\varepsilon_0\partial\varphi/\partial n$）。**「给定什么量」不是数学偏好，而是实验事实**——你实验室里是「把导体接到电源」（定势）还是「给导体充电」（定荷），决定了用哪类边值问题。

**「从方程到解」的分层**：静电边值问题的解法可以按「信息量」分层——先确定方程（泊松/拉普拉斯）→ 再补边界条件 → 然后选方法（分离变量/镜像/格林函数/数值）→ 最后用唯一性定理兜底。**每一层都是上一层的「输入」**：缺了边界条件，方法无从谈起；缺了唯一性，解的正确性无法担保。把这条链记在脑子里，任何一道静电题都能快速定位卡在哪一层。

## 7 小结

- 静电场边值问题 = 泊松/拉普拉斯方程 + 边界条件；三类条件：**狄利克雷**（给定 $\varphi$）、**诺伊曼**（给定 $\partial\varphi/\partial n$）、**混合型**。
- **唯一性定理**保证解唯一，从而「猜一个解」成为合法策略。
- 界面连接条件：$\varphi$ 连续；法向 $\varepsilon_1\partial\varphi_1/\partial n - \varepsilon_2\partial\varphi_2/\partial n = \sigma_f$；切向场强连续。
- 求解路线三条：叠加原理、边界条件 + 分离变量/镜像/格林函数。
