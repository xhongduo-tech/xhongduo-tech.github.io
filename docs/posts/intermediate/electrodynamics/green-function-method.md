## 为什么需要格林函数

镜像法优雅但只适用于特殊几何，分离变量法系统但每解一个新问题都要重来一遍。能不能构造一种「一劳永逸」的方法：先求出**单位点电荷**在给定边界条件下产生的场，然后任意电荷分布的场就只是它的积分？这就是**格林函数法（Green's function method）**。格林函数是「点源的影响函数」——它是泊松方程在 $\delta$-函数源下的解，扮演着线性代数中逆矩阵的角色。<span class="marginnote">格林函数的思想贯穿整个现代物理：量子力学里的传播子（propagator）就是薛定谔方程的格林函数；路径积分把所有传播子「相乘求和」；信号处理里的脉冲响应也是同一概念的翻版。学通格林函数，等于拿到了「线性系统对任意输入响应」的通用语言。</span>

## 1 格林函数的定义

**格林函数 $G(\mathbf{r}, \mathbf{r}')$**：满足如下方程的势函数

$$\nabla^2 G(\mathbf{r}, \mathbf{r}') = -\frac{1}{\varepsilon_0}\delta(\mathbf{r} - \mathbf{r}')$$

它描述「位于 $\mathbf{r}'$ 的单位点电荷在 $\mathbf{r}$ 处产生的电势」。其中 $\delta(\mathbf{r} - \mathbf{r}')$ 是三维狄拉克 $\delta$-函数——在 $\mathbf{r} = \mathbf{r}'$ 处无穷大、其余处处为零、体积分为 1 的广义函数。<span class="marginnote">三维 $\delta$-函数 $\delta(\mathbf{r}-\mathbf{r}') = \delta(x-x')\delta(y-y')\delta(z-z')$ 是「集中到一点的源」的数学语言。它的关键性质是筛选性：$\int f(\mathbf{r}')\delta(\mathbf{r}-\mathbf{r}')\,\mathrm{d}V' = f(\mathbf{r})$——这正是格林函数法「一次积分出任意源响应」的数学基础。</span>

**无界空间的格林函数**：由点电荷电势公式直接读出：

$$G_0(\mathbf{r}, \mathbf{r}') = \frac{1}{4\pi\varepsilon_0}\frac{1}{|\mathbf{r} - \mathbf{r}'|}$$

它满足 $\nabla^2(1/|\mathbf{r}-\mathbf{r}'|) = -4\pi\delta(\mathbf{r}-\mathbf{r}')$——这是 $\delta$-函数在球坐标下的著名结论（可用 $\nabla^2(1/r) = -4\pi\delta(\mathbf{r})$ 验证）。

## 2 用格林函数解泊松方程

**核心公式**：若已知区域 $V$ 内满足给定边界条件的格林函数 $G$，则泊松方程 $\nabla^2\varphi = -\rho/\varepsilon_0$ 的解为

$$\varphi(\mathbf{r}) = \int_V G(\mathbf{r},\mathbf{r}')\rho(\mathbf{r}')\,\mathrm{d}V' + \oint_{\Sigma}\left[\varphi(\mathbf{r}')\frac{\partial G}{\partial n'} - G\frac{\partial\varphi}{\partial n'}\right]\mathrm{d}S'$$

第一项是**体积分**——源电荷的贡献，由格林函数作为权重叠加；第二项是**面积分**——边界条件的贡献，把边界上的 $\varphi$ 与 $\partial\varphi/\partial n$ 也当成「源」叠加进来。

**公式的含义**：格林函数 $G(\mathbf{r}, \mathbf{r}')$ 描述「$\mathbf{r}'$ 处一个点源对 $\mathbf{r}$ 处观测的影响」，而任意源分布 $\rho$ 就是「无穷多个点源的叠加」，所以响应是 $G$ 与 $\rho$ 的叠加（积分）。这正是线性系统叠加原理的极致形式。<span class="marginnote">第二类格林函数（诺伊曼型）通常要求 $\partial G/\partial n'$ 在边界为常数（常用 $1/A$，$A$ 为边界面积），以匹配电荷守恒的自洽性。这处细节是教科书推导中最容易略过、考试最常考的点。</span>

**对称性**：格林函数具有对称性 $G(\mathbf{r}, \mathbf{r}') = G(\mathbf{r}', \mathbf{r})$——「$\mathbf{r}'$ 处点源在 $\mathbf{r}$ 处的影响」等于「$\mathbf{r}$ 处点源在 $\mathbf{r}'$ 处的影响」（互易定理）。它是泊松方程自伴性的直接推论。

## 3 公式解析：格林函数的「三重身份」

格林函数很难学，是因为它同时是三种东西，初学者常常只盯住其中一个：

**身份一：点源响应**。$G$ 满足带 $\delta$-源的方程，是「单位点电荷的电势」。无界空间即库仑势 $1/4\pi\varepsilon_0 r$。这是物理直觉的来源。
**身份二：影响函数**。$G(\mathbf{r},\mathbf{r}')$ 是「源到观测的传递系数」。任意源分布的结果是 $\int G\rho\,\mathrm{d}V$——每个源都「乘以」它到观测点的影响再叠加。这是线性代数中「矩阵乘向量」的连续版本：格林函数就是连续系统的**逆矩阵元素**。<span class="marginnote">把离散问题写清楚：若把空间离散成 $N$ 个格点，泊松方程 $\nabla^2\varphi = -\rho/\varepsilon_0$ 变成线性方程组 $A\varphi = b$，格林函数就是 $A^{-1}$ 的连续极限。这个类比能帮你理解格林函数的全部性质：对称性（$A$ 对称）、叠加性（线性）、边界依赖（$A$ 的边界条件）。</span>
**身份三：边值问题的积分核**。$G$ 一旦求出，同一区域**所有**边值问题的解都只需要做积分——换一个电荷分布、换一组边界值，$G$ 不用重算。这是格林函数法「一次求解、多次使用」的巨大价值。

**求解格林函数的三条途径**：

1. **镜像法**：把边界当作镜子，找镜像电荷使 $G$ 满足边界条件。例如接地导体球外的格林函数 = 无界格林函数 + 镜像项。
2. **本征函数展开**：在可分离坐标下把 $\delta$-函数展开成本征函数的完备集，得到 $G = \sum_n \dfrac{\psi_n(\mathbf{r})\psi_n(\mathbf{r}')}{\lambda_n}$。
3. **直接积分**：无界或简单边界时，直接解出 $\delta$-源的方程。

**典型格林函数**：

| 几何 | 格林函数 $G$（无界/已知） |
| --- | --- |
| 三维无界 | $\dfrac{1}{4\pi\varepsilon_0|\mathbf{r}-\mathbf{r}'|}$ |
| 二维无界（线源） | $-\dfrac{1}{2\pi\varepsilon_0}\ln|\mathbf{r}-\mathbf{r}'|$ |
| 上半空间（接地平面 $z=0$） | $G_0 - G_{\text{镜像}}$（平面镜像法） |
| 球外（接地球） | $G_0 + $ 反转半径处的镜像项 |

**辨析｜易错点：** 格林函数依赖边界条件，所以「同一个区域的格林函数只有一个」的说法不精确——狄利克雷格林函数与诺伊曼格林函数是不同的。而且格林函数必须取**正确的边界类型**：你解狄利克雷问题却用了诺伊曼格林函数，面积分项会给出错误结果。做积分前，先确认 $G$ 的边界类型与问题一致。

## 4 从格林函数到一般解：三步推导

格林函数的妙处也体现在它是「源头公式」——几乎一切静电场问题都可以从它推导。以「接地导体球外的点电荷」为例，格林函数法把镜像法的结果直接嵌入一个框架：

**第一步，识别源**：电荷密度 $\rho(\mathbf{r}') = q\delta(\mathbf{r}' - \mathbf{b})$（点电荷在 $\mathbf{b}$ 处）。
**第二步，写格林函数**：接地球的格林函数 = 无界项 $G_0 +$ 镜像项，镜像电荷 $q' = -Rq/b$ 位于 $a' = R^2/b$ 处。
**第三步，做卷积**：$\varphi(\mathbf{r}) = \int G(\mathbf{r},\mathbf{r}')q\delta(\mathbf{r}'-\mathbf{b})\,\mathrm{d}V' = qG(\mathbf{r}, \mathbf{b})$——直接用 $\delta$ 函数的筛选性质，把积分「剥掉」。这就是镜像法解为何能一步写出的原因。<span class="marginnote">看，镜像法与格林函数法在这里完美统一：镜像法求出的「$q$ 在接地球外的势」，正是「接地球的格林函数乘以 $q$」。镜像法解决的是「如何构造满足边界的 $G$」，格林函数法解决的是「有了 $G$ 之后一切问题怎么算」。</span>

**格林函数的实际价值**：在电磁场数值方法（矩量法、边界元法）中，格林函数是基本工具；在量子场论中，传播子计算全部用格林函数语言。它是把「解析方法」与「数值方法」串起来的桥梁。

## 5 格林函数法的完整演示：上半空间问题

把格林函数法从「定义」到「应用」完整走一遍。**问题**：无限大接地导体平面（$z = 0$），上方任意电荷分布 $\rho(\mathbf{r}')$，求 $z > 0$ 空间电势。

**第一步，构造上半空间的狄利克雷格林函数。** 用平面镜像法：$z=0$ 面上势为零，等价于在镜像位置放 $-1$ 的镜像电荷。于是

$$G_D(\mathbf{r},\mathbf{r}') = \frac{1}{4\pi\varepsilon_0}\left[\frac{1}{|\mathbf{r}-\mathbf{r}'|} - \frac{1}{|\mathbf{r}-\mathbf{r}''|}\right]$$

其中 $\mathbf{r}'' = (x', y', -z')$ 是源关于平面的镜像。**验证**：$z = 0$ 时两项距离相等，$G_D = 0$，满足接地边界条件。

**第二步，写出通解公式。** 狄利克雷问题的解为体积分 + 面积分：

$$\varphi(\mathbf{r}) = \int_V G_D(\mathbf{r},\mathbf{r}')\rho(\mathbf{r}')\,\mathrm{d}V' - \varepsilon_0\oint_{\Sigma}\varphi(\mathbf{r}')\frac{\partial G_D}{\partial n'}\,\mathrm{d}S'$$

其中面积分项包含边界上的电势值——对接地平面 $\varphi|_{\Sigma} = 0$，面积分消失，只剩体积分。

**第三步，代入具体源。** 若源是位于 $\mathbf{r}_0 = (0,0,a)$ 的点电荷 $q$，$\rho = q\delta(\mathbf{r}'-\mathbf{r}_0)$，利用 $\delta$ 函数筛选性：

$$\varphi(\mathbf{r}) = qG_D(\mathbf{r}, \mathbf{r}_0) = \frac{q}{4\pi\varepsilon_0}\left[\frac{1}{|\mathbf{r}-\mathbf{r}_0|} - \frac{1}{|\mathbf{r}-\mathbf{r}_0''|}\right]$$

这正是上一节镜像法的结果——**镜像法所求的「点电荷 + 导体」解，就是格林函数法的「格林函数 × 源」**。两法在这里完全统一。

**格林函数法的战略性优势**：$G_D$ 只依赖几何与边界，不依赖源。同一平面问题，换任何电荷分布都只需重做一次积分，而 $G_D$ 永远不用重算。**这就是「一次求解、多次使用」的含义。**

**辨析｜易错点：** 面积分项的符号与因子（$\varepsilon_0$）容易记错。对狄利克雷问题，面积分项写作 $-\varepsilon_0\oint\varphi\,\partial G_D/\partial n'\,\mathrm{d}S'$；对诺伊曼问题则需换用诺伊曼格林函数。**先确认边界类型，再写通解公式**，是格林函数法不出错的唯一保证。

**$\delta$-函数的本征函数展开**：在分离变量法适用的几何里，格林函数常写成本征函数展开：$G(\mathbf{r},\mathbf{r}') = \sum_n \dfrac{\psi_n(\mathbf{r})\psi_n^*(\mathbf{r}')}{\lambda_n}$，其中 $\psi_n$ 是拉普拉斯算子的本征函数、$\lambda_n$ 是本征值。**这就是「$\delta$-函数被展开成本征函数完备集」**——$\delta(\mathbf{r}-\mathbf{r}')$ 在分离坐标里是「所有本征函数模平方求和」的收敛级数。这条路径把格林函数法与分离变量法无缝连接：**在可分离几何里，格林函数不是「猜出来的镜像」，而是「展开出来的级数」**。

**格林函数法在数值方法中的角色**：边界元法（BEM）直接以格林函数为基本解，只在边界上离散未知量——比需要全空间离散的有限元（FEM）少一个维度。**「格林函数知道得越多，数值离散就越省」**：能用解析格林函数的区域，边界元法效率极高；解析解不存在的几何，才退回全空间离散。**格林函数法不是课本里的古董，它是现代计算电磁学（矩量法、边界元）的数学内核。**

## 6 小结

- **格林函数** $G(\mathbf{r},\mathbf{r}')$：单位点源在边界约束下的响应，满足 $\nabla^2 G = -\delta/\varepsilon_0$。
- 无界空间 $G_0 = 1/(4\pi\varepsilon_0|\mathbf{r}-\mathbf{r}'|)$。
- 泊松方程的一般解 = **体积分（源贡献）+ 面积分（边界贡献）**，$G$ 是积分核。
- 求解途径：**镜像法、本征函数展开、直接积分**。
- 格林函数法「一次求解、多次使用」，是数值电磁学的基石。
