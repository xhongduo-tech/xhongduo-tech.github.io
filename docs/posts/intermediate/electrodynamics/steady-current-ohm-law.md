# 稳恒电流与欧姆定律

<div class="epigraph">
<p>电流的驱动力不是电场本身，而是电场对电荷做功的能力——电动势。</p>

## 为什么静磁场篇要先讲电流

磁场由电流产生，而电流不是凭空存在的——它需要电源、需要导体、需要符合一定规律的电场分布。这一节先把「电流如何维持、电场在导体内部长什么样」讲清楚，静磁场才能建立在坚实的基座上。**稳恒电流（steady current）**是特殊的电流：电荷分布与电场分布都不随时间变化，但电荷在持续流动——这在逻辑上看似矛盾（流走电荷为何不减少？），答案藏在连续性方程里：稳恒电流要求 $\nabla\cdot\mathbf{J} = 0$，即流入多少流出多少，电荷分布恒定。<span class="marginnote">「电荷不随时间变化却持续流动」的解决办法是闭合回路：电流绕一圈回来，电荷总数不变。任何稳恒电流必然构成闭合环路，这是稳恒电流与静电学的根本区别——静电场可以「有头有尾」，稳恒电流的场必须「首尾相接」。</span>

## 1 电流密度与稳恒条件

**电流密度（current density）$\mathbf{J}$**：单位时间垂直穿过单位面积的电荷量，$\mathbf{J} = nq\mathbf{v}_d$，其中 $n$ 是载流子数密度，$\mathbf{v}_d$ 是漂移速度，单位 $\mathrm{A/m^2}$。穿过任意曲面 $S$ 的电流为

$$I = \int_S \mathbf{J}\cdot\mathrm{d}\mathbf{S}$$

**稳恒条件**：电荷分布不随时间变化要求 $\partial\rho/\partial t = 0$，由连续性方程得

$$\nabla\cdot\mathbf{J} = 0$$

即电流密度无散——**稳恒电流场是无散场**，电流线闭合。<span class="marginnote">漂移速度远比直觉慢：铜导线中电流 $1\ \mathrm{A}$、截面积 $1\ \mathrm{mm^2}$ 时，$v_d \approx 0.07\ \mathrm{mm/s}$——比蜗牛还慢。但电场的建立速度接近光速（约 $10^8\ \mathrm{m/s}$），所以合上开关，灯几乎瞬间亮起：是电场在推整个导体的自由电子，不是电子本身跑得快。</span>

**辨析｜易错点：** 稳恒 ≠ 静止。稳恒电流的电荷一直在流动，只是「流动的分布」不随时间变化。这与静电平衡（$\mathbf{J} = 0$，导体内部 $\mathbf{E} = 0$）完全不同。稳恒电流的导体内部电场**不为零**——正是这个电场驱动电流，且电场方向沿电流方向。

## 2 欧姆定律的微分形式

导体的宏观欧姆定律 $V = IR$ 对整体成立，但电动力学需要**局域**描述。实验表明，各向同性导体中电流密度与电场成正比：

$$\mathbf{J} = \sigma\mathbf{E}$$

其中 $\sigma$ 是**电导率（conductivity）**，单位 $\mathrm{S/m}$。电阻率 $\rho = 1/\sigma$。<span class="marginnote">微观点：自由电子在电场中加速，随即与晶格碰撞失去定向速度，平均效果是恒定漂移速度 $v_d = eE\tau/m$（$\tau$ 为平均碰撞时间）。由此可推 $\sigma = ne^2\tau/m$——电导率由载流子密度、碰撞时间、有效质量三者决定。这个简单的「德鲁德模型」能解释金属导电的大部分宏观规律。</span>

**从微分形式到积分形式**：设均匀导体棒长 $l$、截面积 $S$，两端电压 $V$，场强 $E = V/l$ 均匀，电流 $I = JS = \sigma E S = \sigma V S/l$，故 $R = V/I = l/(\sigma S)$——电阻与长度成正比、与截面积成反比，正是欧姆定律的几何版。

**焦耳定律的微分形式**：电场对电荷做的功率密度为

$$p = \mathbf{J}\cdot\mathbf{E} = \sigma E^2$$

这正是坡印亭定理右端的 $- \mathbf{J}\cdot\mathbf{E}$（电源侧）的能量耗散项。积分得焦耳热 $P = I^2R$。<span class="marginnote">「电阻发热」的微观本质：电子把从电场获得的动能通过碰撞交给晶格，转化为热能。焦耳热与机械摩擦热在微观上都是「动能耗散」，宏观表现同为熵增。</span>

## 3 稳恒电流的场方程与边界条件

稳恒电流导体内部，场满足的方程来自欧姆定律 + 稳恒条件：

$$\nabla\cdot(\sigma\mathbf{E}) = 0, \qquad \nabla\times\mathbf{E} = 0$$

第一个方程说「无源」：稳恒电流的电场无散（无电荷积累）；第二个方程说「无旋」：仍是保守场，可定义电势 $\varphi$，且 $\mathbf{E} = -\nabla\varphi$。代入得

$$\nabla^2\varphi = 0$$

**稳恒电流导体内部的电势满足拉普拉斯方程**——与无源静电场形式相同，但边界条件不同。

**电流的边界条件**：在两种导电介质界面，电流密度的法向分量连续（电荷不积累）：

$$J_{1n} = J_{2n}, \qquad \frac{\sigma_1\partial\varphi_1}{\partial n} = \frac{\sigma_2\partial\varphi_2}{\partial n}$$

而电场的切向分量连续（$\varphi$ 连续）。由 $J_n = \sigma E_n$ 连续，可推界面两侧场强法向分量的比值 $\dfrac{E_{1n}}{E_{2n}} = \dfrac{\sigma_2}{\sigma_1}$——电导率小的介质中场强法向分量大，这正是「不良导体中电场集中」的原因。<span class="marginnote">接地系统的安全分析靠这个：潮湿地面（低 $\sigma$）中电场集中，接触跨步电压更危险；电缆绝缘层（低 $\sigma$）承受大部分电压降。电流场与静电场在数学上同构，但物理角色完全不同——一个算「电荷与力」，一个算「电流与热」。</span>

## 4 公式解析：欧姆定律为什么有微分形式

把 $V = IR$ 从「整根导线」推广到「每一点」，是本节的核心动作：

**第一步，从整体到局域**：导线整体关系 $V = IR$ 隐含假设「$V$ 均匀、$I$ 均匀」。但真实导体的截面积、材料可能处处不同，需要逐点的关系。设长度为 $\mathrm{d}l$ 的小段，两端电势差 $\mathrm{d}V = E\,\mathrm{d}l$，电阻 $\mathrm{d}R = \mathrm{d}l/(\sigma S)$，电流 $I$ 相同，则 $\mathrm{d}V = I\,\mathrm{d}R$ 逐点成立。
**第二步，换用密度量**：$I = J S$，$E = \mathrm{d}V/\mathrm{d}l$。代入 $\mathrm{d}V = I\,\mathrm{d}l/(\sigma S)$ 得 $E = J/\sigma$，即 $J = \sigma E$。这就是微分形式——**局域关系，不依赖导体的具体形状**。
**第三步，补上方向**：电流沿电场方向流，故 $\mathbf{J} = \sigma\mathbf{E}$。它比积分形式更基本：积分形式可由它推出来，反之不行（积分形式默认了「均匀」）。<span class="marginnote">微分形式的威力：它可以处理不均匀导体、渐变截面、多层介质——逐点成立的关系让「场」的语言接管「电路」的语言。这标志着我们从「电路」进入「电流场」的层次，是电动力学区别于电工学的关键一步。</span>

**辨析｜易错点：** 欧姆定律不是普适定律。半导体、电解液、等离子体中 $J$ 与 $E$ 的关系往往非线性；超导体中 $E = 0$ 时 $J \neq 0$（欧姆定律彻底失效）。「$\mathbf{J} = \sigma\mathbf{E}$ 恒成立」是线性、各向同性、稳恒、普通导体的近似，超出这个范围要回到更基本的输运理论。

## 5 电动势与非静电力

稳恒电流在闭合回路中循环，意味着电荷在回路中走一圈回到原处时电势能不变——但电阻又持续耗散能量。谁在提供能量？答案是**电源**。电源内部存在**非静电力**，它对电荷做功形成**电动势（electromotive force, emf）**：

$$\mathcal{E} = \oint \mathbf{E}'\,\mathrm{d}\mathbf{l}$$

其中 $\mathbf{E}'$ 是单位电荷所受非静电力的等效场强（化学的、热学的、光学的或机械的）。<span class="marginnote">电池的化学非静电力、太阳能电池的光生伏打效应、发电机旋转的洛伦兹力、温差电偶的赛贝克效应——都是不同形式的非静电力。电动势只描述电源「提升电荷」的本领，它不等于路端电压；电路分析里「$U = \mathcal{E} - Ir$」的 $Ir$ 就是内阻压降。</span>

**稳恒电流闭合回路的能量平衡**：电源提供的功率 = 回路电阻耗散的总功率。麦克斯韦方程组 + 坡印亭定理在这个问题上的结论尤为深刻：**能量不是沿导线「流」的，而是通过导线周围的电磁场（坡印亭矢量）从电源「流」到负载的**——导线只是引导场的边界条件。

## 6 稳恒电流的完整例题：半球接地体

把稳恒电流的场方程与边界条件用一道接地电阻的经典题走通。

**问题**：半径为 $a$ 的半球形金属电极埋入电导率为 $\sigma$ 的均匀土壤中，电极表面与地面齐平。求电极与无穷远处的「接地电阻」。

**第一步，定方程与对称性。** 土壤区域满足 $\nabla^2\varphi = 0$，电流从半球表面径向流出，球对称（半球 + 地面反射保证对称性）。解为 $\varphi(r) = \dfrac{C}{r} + D$，取无穷远处 $\varphi(\infty) = 0$，则 $D = 0$。

**第二步，用电极边界条件定系数。** 电极表面电流密度 $J_r = \sigma E_r = -\sigma\dfrac{\mathrm{d}\varphi}{\mathrm{d}r}$。电极表面（$r = a$）电流沿径向流出半球面：

$$I = \int_{\text{半球}} J_r\,\mathrm{d}S = \sigma C \cdot 2\pi a$$

（注意只有半球面流出，面积是 $2\pi a^2$，不是 $4\pi a^2$。）于是 $C = \dfrac{I}{2\pi\sigma a}$，电势 $\varphi(r) = \dfrac{I}{2\pi\sigma r}$。

**第三步，读接地电阻。** 电极相对无穷远的电势差 $\varphi(a) = \dfrac{I}{2\pi\sigma a}$，接地电阻

$$R = \frac{\varphi(a)}{I} = \frac{1}{2\pi\sigma a}$$

**这个结果的价值**：接地电阻与土壤电导率成反比、与电极半径成反比——**半径越大接地电阻越小**，这是变电站、避雷针接地网设计的直接依据。把半球看成「镜像」的球体（完整球的电流是 $4\pi$），接地电阻恰为完整球的一半——又一次「平面镜像」的应用。

**辨析｜易错点：** ① 电流只从半球面流出，用 $4\pi$ 球面积分会把电阻算小一半。② 接地体表面不是等势面之外的简单情形——它确实是等势体，但电势值未知，要用「总电流 = 面电流密度积分」来定，而不是直接给电势。③ 接地问题的物理图像是「电流从电极向无穷远扩散」，与静电场中「点电荷的场」同构，但边界条件是电流而非电荷。

**漂移速度 vs 电场速度**：自由电子的热运动速度约 $10^5\ \mathrm{m/s}$（无规），漂移速度仅约 $0.1\ \mathrm{mm/s}$（定向），而电场信号的传播速度接近光速（约 $10^8\ \mathrm{m/s}$）。**三层速度量级相差悬殊**，合上开关时「电子没有从开关飞到你面前」，是「电场沿导线以光速建立、推动整条导线内的电子几乎同时开始漂移」。理解这三层速度，就能破除「电流 = 电子以光速跑」的直觉误区。

## 7 小结

- **电流密度** $\mathbf{J} = nq\mathbf{v}_d$；稳恒条件 $\nabla\cdot\mathbf{J} = 0$，电流线闭合。
- **欧姆定律微分形式** $\mathbf{J} = \sigma\mathbf{E}$，由它可推积分形式 $V = IR$。
- 稳恒电流导体内部 $\nabla^2\varphi = 0$；界面条件 $J_n$ 连续、$\varphi$ 连续。
- **焦耳热** $p = \mathbf{J}\cdot\mathbf{E}$；能量通过坡印亭矢量在导线周围的场中传输。
- **电动势**由非静电力驱动，是回路中能量循环的源头。
