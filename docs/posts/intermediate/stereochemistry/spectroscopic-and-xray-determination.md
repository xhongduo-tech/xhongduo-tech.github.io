# 手性的光谱与 X 射线测定

## 为什么需要「定构型」的仲裁者

前一篇的 ORD/CD 可以「指认」构型，但它是经验规则——需要标准品或理论计算的对照。当争议发生时，谁说了算？答案是 **X 射线晶体学**：它直接「看到」原子在三维空间里的排列，是绝对构型的最终仲裁者。而日常高通量场景里，X 射线太重，光谱方法（核磁的 Mosher 法、手性位移试剂、CD/ORD、振动圆二色 VCD、旋光拉曼 ROA）更轻便。本篇把这些工具摆成一张图：各自能回答什么、相互如何交叉验证、什么情况下必须上 X 射线（对标 Eliel《Stereochemistry of Organic Compounds》Ch. 13）。

## 1 相对构型与绝对构型

先厘清两个层次：

- **相对构型（relative configuration）**：分子内多个立体中心**彼此之间的**空间关系——哪个中心是 $R$、哪个是 $S$，但不涉及「整个世界到底是左手还是右手」。
- **绝对构型（absolute configuration）**：整个分子在真实三维空间中的手性方向，即每个中心的 $R/S$ 真值。

光谱方法（核磁偶合、NOE、圆二色、Mosher 法）天然擅长定**相对**构型；要升格为**绝对**构型，要么与已知绝对构型的标准物比对，要么直接上 X 射线。

**辨析｜易错点：**「相对构型」不包含「绝对方向」的信息，因此**两个相对构型相同、绝对构型相反的分子，其光谱（旋光、CD、核磁偶合）在非手性环境下完全一致**——这是大量「合成做对了相对构型、却拿错了对映体」事故的根源。所以报告构型时必须写清是相对还是绝对，以及依据的方法；只给一张 ORTEP 图而没有 Flack 参数，不算绝对构型证据。

**为什么光谱「天然」只定相对构型**：核磁的偶合常数、NOE 距离、CD 的符号都是分子内部的几何量——它们只编码「原子之间如何相对排列」，不编码「整个世界是左手还是右手」。要把相对构型升级为绝对构型，必须引入一个「已经知道左右手的外部标准」：已知构型的标准品、手性试剂（Mosher 法）的符号约定，或 X 射线对原子坐标的直接测量。理解这一点，就知道「相对构型确定」与「绝对构型确定」是证据强度完全不同两件事。

## 2 X 射线：Bijvoet 异常散射

普通 X 射线衍射能定出**原子间距**，却对「左右手」无能为力——因为常规散射的衍射强度遵守弗里德尔定律 $I(hkl) = I(\bar h\bar k\bar l)$，镜像对不可区分。打破这个对称的关键是**异常散射（anomalous scattering）**：

当入射 X 射线的能量接近晶体中原子的吸收边时，原子对 X 射线的散射产生附加的相移（异常散射因子 $f''$），弗里德尔定律被破坏，$I(hkl) \neq I(\bar h\bar k\bar l)$。1951 年比沃特正是利用这一效应，首次确定了酒石酸盐的绝对构型，把立体化学从「约定」变成「可实证」。

**操作要点**：晶体中必须含有重原子（如溴、碘、硫、金属），或借助硒代蛋氨酸等重原子衍生物（结构生物学中的标准操作）；然后在多波长或单波长下收集衍射数据，比较弗里德尔对（Friedel pairs）的强度差。

**为什么普通衍射不行**：把晶体里的原子坐标解出来只需要「普通散射」，但普通散射遵守弗里德尔定律 $I(hkl) = I(\bar h\bar k\bar l)$——一对镜像坐标会给出完全相同的衍射强度，左右手不可分辨。只有异常散射引入的 $f''$ 相移打破这一对称，衍射强度才携带构型信息。理解这一点，就知道「解析出结构」与「定出构型」是两件事：前者靠普通衍射，后者必须靠异常散射。**绝对构型的可信度用 Flack 参数 $x$ 表示：$x \approx 0$ 表示构型指认正确，$x \approx 1$ 表示应取镜像**。<span class="marginnote">现代结构解析软件会自动报告 Flack 参数。当 Flack 值在 0–1 之间且误差大时，说明晶体对（或孪晶、无序）令构型指认不可靠——此时把分子倒转重算并比较 $R$ 因子，取更优者。</span>

**辨析｜易错点：** X 射线给出的是**固态**结构；如果分子在溶液或气相中发生快速构象/构型互变（如胺的锥形翻转），单晶结构可能不代表溶液主导物种。因此 X 射线定的是「晶体里那个构象/构型」，把它外推到溶液应用时要谨慎。

**数值判读**：解析软件报出 Flack 参数 $x = 0.03 \pm 0.06$——区间包含 0，构型指认可信；若报 $x = 0.92 \pm 0.05$，几乎可以断定当前模型取了镜像，需把坐标全部倒转重算，倒转后 $x$ 应回到 0 附近。**判读口诀：$x$ 离 0 越近越好，误差 $u(x)$ 越小越好；$x$ 在 0–1 之间且误差大，说明晶体质量不足以定构型**，这时宁可补收数据也不要硬报。

**为什么必须重原子**：轻原子（碳、氢、氮、氧）对 X 射线的散射弱，异常散射信号（$f''$）几乎可以忽略，弗里德尔对的强度差太小、测不出。引入硫（天然）、溴、碘（衍生）或硒代甲硫氨酸后，$f''$ 显著增大，构型信号才可测。这也是为什么结构生物学必须做硒代标记——让重原子「照亮」蛋白晶体的左右手。

## 3 核磁法：Mosher 法定绝对构型

没有单晶时，核磁是最实用的替代。**Mosher 法（Mosher's method）**利用手性衍生试剂 $\ce{(R)}$-MTPA（$\alpha$-甲氧基-$\alpha$-三氟甲基苯乙酸）与底物醇/胺成酯（或酰胺），把对映体底物变成**非对映体衍生物**，核磁即可分辨。

核心操作是「双酯对照」：分别用 $\ce{(R)}$-与 $\ce{(S)}$-MTPA 氯（或酸）把底物衍生，比较两个衍生物中同一质子的化学位移差 $\Delta\delta = \delta_R - \delta_S$。**$\Delta\delta$ 的符号（正/负）与底物手性中心的构型有固定对应关系**：通过查 Mosher 模型的符号约定，可指认绝对构型。

**要点与陷阱**：底物需有可与 MTPA 反应的基团；苯环屏蔽效应的方向性决定 $\Delta\delta$ 的符号解读；对多手性中心分子，需逐个分析局部环境。Mosher 法是「溶液态绝对构型」最经济的路线之一，广泛用于天然产物鉴定<span class="marginnote">其它核磁路线：手性位移试剂（见《手性识别与对映体过量测定》）、手性溶剂、以及二维 NOE（核欧氏效应）定相对构型——把 NOE 的距离信息与构象模型比对，可把相对构型钉在特定构象上。</span>。

**实验流程**：1）把醇底物分成两份，分别与 $\ce{(R)}$- 和 $\ce{(S)}$-MTPA 酰氯缩合，得到一对非对映酯；2）分别做 $^1$H 核磁，指认同一组质子（常是 $\ce{C1-H}$ 或邻位甲基）在两个谱中的化学位移；3）算 $\Delta\delta = \delta_{(R)} - \delta_{(S)}$，按 Mosher 模型的屏蔽-去屏蔽约定推出手性中心的构型。**要点**：指认要基于同一质子，且用二维实验（COSY/HSQC）辅助归属；把 $\Delta\delta$ 的正负号记反，构型就判反——这是 Mosher 法最高发的错误。

## 4 公式解析：Flack 参数与构型指认

把 X 射线的构型指认写成定量判断。含重原子时，晶体的结构因子（structure factor）平方强度为

$$
|F(hkl)|^2 = (1 - x)\,|F_{\text{正确}}|^2 + x\,|F_{\text{镜像}}|^2
$$

对 Flack 参数 $x$ 做三步拆解：

- **第一步，理解参数含义**：$x$ 是「样品中镜像成分的比例」，由最小二乘拟合衍射强度得出。理想晶体 $x = 0$；完全倒反（构型取反）时 $x = 1$；$x \approx 0.5$ 表示晶体由对映体或孪晶混合，构型不可定。
- **第二步，阈值判断**：经验规则——$x < 0.2$ 且标准不确定度较小（如 $x \pm u(x)$ 区间含 0）时，构型指认可靠；否则应尝试镜像模型重算，比较拟合优度。
- **第三步，与光谱方法互证**：X 射线定的绝对构型再反向校验 CD/ORD 的经验规则（如八区律、Mosher 模型），长期下来让经验规则越来越可靠——「仲裁者」反过来给「日常工具」打标签，这是立体化学方法论的自我进化。

**Flack 值的替代指标**：当重原子太弱、或晶体只有轻原子时，还可以用「Bijvoet 差（|Δ|/σ）」与多波长异常散射等统计量辅助判断；新方法如对手性敏感的结构因子拟合能给出更可靠的构型判定。但对一般用户，记住「Flack 参数 + 误差」两条就足够应付绝大多数审稿意见。

## 5 光谱法的分工表

| 方法 | 回答的问题 | 优点 | 局限 |
| --- | --- | --- | --- |
| X 射线衍射（异常散射） | 绝对构型 | 直接、权威、有 Flack 参数 | 需单晶、需重原子 |
| Mosher 法（核磁） | 绝对构型（溶液） | 无需结晶、样品少 | 需可衍生官能团、符号约定 |
| 手性位移试剂（核磁） | ee 测定 | 快、样品量小 | 依赖结合常数、强配位底物 |
| CD / ORD（八区律等） | 绝对/相对构型 | 灵敏度高、可测 ee | 需发色团、规则有适用范围 |
| VCD / ROA | 绝对构型（振动级） | 无需发色团、水溶液可用 | 仪器贵、计算对照繁 |

**选型原则**：有单晶、且手性中心邻近重原子 → X 射线；没有单晶但有醇/胺 → Mosher 法；有羰基/发色团 → CD 加八区律；纯烃类、水溶液、无发色团 → VCD/ROA。多数严谨论文用「核磁 + CD 交叉验证 +（可获时）X 射线」三层证据链。

**真实工作流示例**：天然产物新结构鉴定的标准动作是——先培养单晶；能出晶且含重原子，直接 X 射线定绝对构型；晶体不佳或样品量少，先跑 CD 加八区律给出初步构型，再跑 Mosher 法（若含醇/胺）交叉验证；最后在论文里同时报告三种方法的结论。近年**结晶海绵法（crystalline sponge）**把微量液体样品吸收进多孔 MOF 单晶再衍射，让 X 射线能处理液体样品，正在改变「有晶才能测」的局限。

**数据质量的三道门槛**：分辨率（约 1.5 Å 以上才能谈绝对构型的可靠指认）、$R_{\text{int}}$（同一晶体内多次测量的偏离度，越小越好）、以及 Flack 参数及其不确定度。期刊审稿对「声称绝对构型」的稿件通常要求 Flack 值明显趋零且误差小，否则会被要求补做 CD / Mosher 交叉验证——这正是本篇反复强调「三层证据链」的原因。

**费用与时间的现实权衡**：X 射线单晶衍射从培养晶体到解析通常要数周，且常有「长不出晶」的风险；Mosher 法当天可出结果；CD 只需几毫克样品、几小时。因此在药物研发的早期阶段，先用光谱快速指认构型、把 X 射线留给「关键决定点」（申报、发表、争议仲裁），是既稳妥又经济的做法。

**一个快速决策清单**：

- 有单晶且含重原子 → X 射线，一步定绝对构型。
- 无单晶、有醇/胺 → Mosher 法当天出结果。
- 有发色团 → CD 加八区律，兼顾构型与 ee。
- 纯烃、水溶液、无发色团 → VCD / ROA。
- 关键争议或申报节点 → 无论如何补上 X 射线收尾。

## 7 小结

- **相对构型**讲分子内部关系，**绝对构型**讲真实三维方向；光谱主攻相对，X 射线直接定绝对。
- **Bijvoet 异常散射**打破弗里德尔定律，1951 年首次实证绝对构型；**Flack 参数** $x \approx 0$ 即构型指认正确。
- **Mosher 法**：$(R)/(S)$-MTPA 双酯对照，由 $\Delta\delta$ 符号定绝对构型，是溶液态首选。
- 光谱方法依赖标准品或经验规则，X 射线是最终仲裁；二者互为校验。
- 选型：单晶优先 X 射线；无发色团选 VCD/ROA；醇胺选 Mosher。
- 严谨构型工作讲究「多方法交叉验证」的三层证据链。

在下一节，我们把视角从「测定已有的手性」转向「反应如何创造手性」：**立体选择性与立体专一性**将给出反应立体化学的定量语言，并预告不对称合成的两条主路。
