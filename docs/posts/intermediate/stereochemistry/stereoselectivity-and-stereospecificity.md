# 立体选择性与立体专一性

## 为什么反应也有「立体化学」

前几篇把分子的静态立体化学讲透了：怎么命名、怎么分离、怎么测构型。但化学的根本在于**反应**——而反应的产物立体化学，是「哪里下手、哪一面进攻」的结果。同一个底物，不同的机制会给出完全不同的产物构型；同一类反应，有的只认一种进攻面，有的两面通吃。**立体选择性与立体专一性**正是描述「反应与立体化学关系」的两种语言。搞清它们的区别，才能读懂不对称合成的设计逻辑，也才能解释为什么酶能做到「万无一失」（对标 Eliel《Stereochemistry of Organic Compounds》Ch. 12）。

## 1 两个定义：专一 vs 选择

两个词听起来像近义词，含义却截然不同：

**立体专一性（stereospecificity）**：**反应物若仅构型不同，则产物也以相应的构型区分**。即：某种反应物（如纯 $E$）只会给出某种特定立体化学的产物（如纯 $anti$ 产物），其镜像反应物给出对应镜像的产物。**它是对「机制」的描述**：反应沿着一条确定的空间路径进行，路径本身就是立体化学的。

**立体选择性（stereoselectivity）**：**一个反应优先生成某一种立体异构体**，但并非只生成它。**它是对「结果」的描述**：产物是对映体或非对映体的混合物，只是比例不均。

用一个表厘清：

| | 立体专一性 | 立体选择性 |
| --- | --- | --- |
| 描述对象 | 机制（反应路径） | 结果（产物比例） |
| 若某反应物只给一种产物 | 是立体专一 | 自然也是立体选择（100:0） |
| 是否「只出一种」 | 是（按构型对应） | 否（比例不同而已） |
| 典型例子 | E2 反式消除、S_N2 构型翻转 | 加氢、羰基加成的对映选择性 |

**辨析｜易错点：** 两者不互斥。一个反应可以既立体专一又立体选择（E2 对特定反应物）；也可以只有立体选择性而没有立体专一性（生成一对非对映体但比例不均）。「立体专一的一定立体选择，立体选择的不一定立体专一」——判断时先问「换镜像反应物，产物会不会跟着换」，是的就是专一。

**再细分两种立体选择性**：产物若是**一对对映体**的比例不均，叫**对映选择性（enantioselectivity）**，量度用 ee；产物若是**一对非对映体**的比例不均，叫**非对映选择性（diastereoselectivity）**，量度用 de（diastereomeric excess）。同一反应可以同时既对映选择又非对映选择（如手性辅基控制的不对称合成，先定 de 再定 ee）。**报数值时务必标注是 ee 还是 de**——混用两者是反应立体化学报告里最常见的错误之一。

**为什么两个词要分得这么清**：因为「立体专一」是机制的、离散的（换镜像反应物必换镜像产物），而「立体选择性」是统计的、连续的（只是比例不同）。把「99% ee」说成「立体专一」会误导读者以为该反应换了镜像底物也会给出镜像产物——而这未必成立。教材与论文里，措辞上的混用常被审稿人直接打回。

## 2 立体专一的经典：E2 与 S_N2

两个基础反应的立体专一性，值得用立体化学语言重新读一遍：

- **E2 反式消除（anti-periplanar elimination）**：离去基团与 β-氢必须处于反式共线（扭转角 180°）才能发生。因此**环己烷体系里 E2 只消除反式的 β-氢**，顺式二取代环己烷与反式二取代环己烷得到不同的烯烃产物——同一分子式、两种反应物构型，输出截然不同，这就是立体专一。
- **S_N2 构型翻转（Walden 翻转）**：亲核试剂从离去基团的背面进攻，**产物构型一定翻转**。$R$ 底物给出 $S$ 产物，反之亦然——一步反应，构型翻转率 100%，教科书级的立体专一。

这两例说明：**立体专一性来自过渡态的几何约束**——反应「只能」走一条空间路径，路径决定了构型。

**再补一个经常被问的例证：溴代环己烷的 E2 需要反式-共面的 β-氢**——椅式环己烷中只有相邻碳上的直立氢（axial H）与离去基团保持反式共线，所以 E2 消除在椅式构象里「只认直立氢」。这解释了为什么某些环己烷衍生物的消除产物比例直接跟随构象平衡：先查椅式翻转后的轴向氢比例，再预测顺式/反式产物的相对比例。

**为什么 S_N2 是「教科书级」立体专一**：因为它的过渡态里亲核试剂与离去基团必须共线（背面进攻），几何上只有一种可行路径；任何溶剂化、离子对、邻基参与都会削弱这种严格性，所以 S_N2 在少数底物上也会出现部分保留。换言之，**立体专一性是「理想机制」的刻画，实际选择性仍由 $\Delta\Delta G^\ddagger$ 决定**——两者并不矛盾，只是描述层次不同。

## 3 立体选择：从比例到能量

大多数反应不是「只有一条路」，而是「几条路能量不同」。**立体选择性 = 各竞争过渡态的自由能差 $\Delta\Delta G^\ddagger$ 的指数函数**：

$$
\frac{[R]}{[S]} = e^{-\Delta\Delta G^\ddagger / RT}
$$

其中 $\Delta\Delta G^\ddagger = \Delta G^\ddagger_R - \Delta G^\ddagger_S$ 是两个非对映过渡态的活化自由能差。对这条式子做四步拆解：

- **第一步，翻译比例**：对映体比（er）$[R]/[S]$ 不是任意的，它由「两条路的相对高度」决定。er = 99:1 对应 $\Delta\Delta G^\ddagger = RT\ln 99$。
- **第二步，代入数字**：室温（298 K）下 $RT \approx 2.48\ \mathrm{kJ/mol}$。er = 99:1 时 $\Delta\Delta G^\ddagger \approx 2.48 \times \ln 99 \approx 11.4\ \mathrm{kJ/mol}$——只有约 2.7 kcal/mol 的能差，就能实现 98% ee。
- **第三步，看动力学**：$\Delta\Delta G^\ddagger$ 是**活化能**之差，与产物稳定性无关——立体选择性由「哪条路更快」决定，是动力学量。
- **第四步，引向热力学**：若产物之间能互相转化（平衡），则产物比例由 $\Delta G$ 决定而非 $\Delta\Delta G^\ddagger$，这叫**热力学控制**；反之若产物不能互变，比例锁死在动力学值上，叫**动力学控制**。<span class="marginnote">动力学控制 vs 热力学控制的判别实验：改变反应温度与时间看产物比例是否漂移。1,3-二羰基化合物烯醇化的 E/Z 比例就是经典的热力学/动力学竞争案例（动力学烯醇优先 Z）。</span>。

把「能差 → 比例」的换算做成一张速查表（295 K 附近 $RT \approx 2.45\ \mathrm{kJ/mol}$）：

| $\Delta\Delta G^\ddagger$（kJ/mol） | er | ee |
| --- | --- | --- |
| 2.5 | 2.8:1 | 47% |
| 5.7 | 10:1 | 82% |
| 11.4 | 100:1 | 98% |
| 17.1 | 1000:1 | 99.9% |

**读表启示**：立体选择性对能差的响应是**指数级的**——从 47% 到 98% ee 只需能差从 2.5 涨到 11.4 kJ/mol。这就是为什么「把选择性从 90% 做到 98%」常比「从 50% 做到 90%」更难：越往后，每一点 ee 提升需要的能差增量越大。

**实操提示**：要实测 $\Delta\Delta G^\ddagger$，只需在低温下取反应初期的 er（避免产物热力学平衡污染），代入 $er = e^{\Delta\Delta G^\ddagger/RT}$ 反解；同时比较不同温度下的 er，若基本不变则确认为动力学控制。这类「用数据反推能差」的做法，让过渡态模型从定性走向定量。

## 4 羰基加成的立体选择性：Cram 与 Felkin–Anh

把「过渡态能量差」落到最重要的底物——手性醛/酮的羰基加成。这类反应决定新立体中心是 $R$ 还是 $S$，是天然产物合成的日常问题。

**Cram 规则（1952）**：把羰基看作平面，想象加入一个「假想的大基团」，亲核试剂从羰基平面的哪一侧进攻，取决于已有手性中心相邻基团的大小关系；大基团之间要尽量远。

**Felkin–Anh 模型（1968–1980）**：更定量地把过渡态结构画出来——亲核试剂从与「最大基团」成约 109° 的位置进攻，同时避免与相邻碳上取代基的扭张力；LUMO（$\ce{C=O}$ 的 $\pi^*$）与相邻 σ 键的立体电子效应也被纳入。<span class="marginnote">Felkin–Anh 模型的精妙处：它同时考虑空间（大基团反式）与电子（C–C σ 键与 π* 反式共线利于接受电子）两种效应，能解释为什么某些 Cram 规则预测失败——当配位效应（螯合）存在时还要改用螯合控制模型，见《不对称合成方法》。</span>。

**核心要义**：无论哪种模型，**立体选择性的来源都是「进攻面」的选择**——这正是《前手性》里 Re/Si 面概念的用武之地：面选对了，产物构型就定了。

**工作算例：** 用 Felkin–Anh 模型预测 2-甲基丙醛（$\ce{(CH3)2CHCHO}$）与 $\ce{CH3MgBr}$ 加成的产物构型。把羰基碳连的三个取代基按「大-中-小」排开：异丙基（最大）、甲基（中）、氢（小）；亲核试剂从与最大基团反式的方向进攻，得到的加成产物以某一构型为主。实际实验中该体系给出约 70:30 的立体选择比，Felkin–Anh 预测的方向与之相符——这正是「先画过渡态、再定构型」的标准流程，也是天然产物合成里每天都要做的工作。

**扩展到生物催化**：酶催化的立体选择性也是同一个 $\Delta\Delta G^\ddagger$ 语言——酶的活性口袋预先排布了进攻面，把「两种进攻」的能差拉得极大，因此 ee 常 >99%。与化学催化剂不同，酶的 $R/S$ 选择是「锁死」的：想得到另一种构型，往往需要定向进化改造口袋，而不是换个配体。这把《立体选择性与立体专一性》与《不对称合成方法》里的酶催化路线直接接上了。

**一句收束**：把立体专一性、立体选择性、对映/非对映选择性放进同一张图——**立体专一性是「路径唯一」，立体选择性是「路径竞争但有高下」，ee/de 是「竞争结果的度量」**。三者是不同层次的概念，却常常被混着说；理清它们，是读懂整本《Stereochemistry of Organic Compounds》反应章节的前提。

## 5 术语速查表

| 术语 | 一句话含义 |
| --- | --- |
| 立体专一性 | 镜像反应物给镜像产物，机制决定构型 |
| 立体选择性 | 多路径竞争，产物比例不均（结果描述） |
| 对映选择性 / 非对映选择性 | ee / de，产物分别为对映体 / 非对映体 |
| 动力学控制 / 热力学控制 | 比例由活化能差 / 产物能量差决定 |
| $\Delta\Delta G^\ddagger$ | 两个非对映过渡态活化自由能差 |
| Cram 规则 / Felkin–Anh 模型 | 手性醛酮加成的进攻面预测模型 |
| Re / Si 面 | 羰基平面两侧的立体面记号 |

## 6 小结

- **立体专一性**描述机制：镜像反应物给镜像产物，路径几何锁死构型（E2 反式消除、S_N2 翻转）。
- **立体选择性**描述结果：多路径竞争，$\frac{[R]}{[S]} = e^{-\Delta\Delta G^\ddagger/RT}$；98% ee 只需约 2.7 kcal/mol 过渡态能差。
- **动力学控制 vs 热力学控制**：产物互变则比例由 $\Delta G$ 决定，否则由 $\Delta\Delta G^\ddagger$ 决定。
- **Cram / Felkin–Anh 模型**：从过渡态的位阻与立体电子效应预测羰基加成的手性面选择。
- 立体专一必立体选择，立体选择未必立体专一；先问「换镜像反应物会不会换镜像产物」。
