## 为什么从随机微分方程开始

Itô 公式给了我们一台机器：给定过程 $X$，求 $f(X)$ 的微分。随机分析的下一个动作是反过来——**给定「微分的规则」，求过程本身**。这就是随机微分方程（SDE）：把确定性的微分方程 $dx = b(x)\,dt$ 升级为

$$dX_t = b(X_t)\,dt + \sigma(X_t)\,dB_t,$$

其中 $b$ 是**漂移**（drift），$\sigma$ 是**扩散系数**（diffusion coefficient）。漂移给趋势，扩散给噪声，两者共同决定一条随机的轨线。

为什么这重要？因为自然界与金融界的「被噪声推着走」的系统几乎全在此列：股票价格、粒子扩散、神经元膜电位、利率曲线——它们都各自满足一条 SDE。这一节的目标是回答：**SDE 的解存在吗？唯一吗？长什么样？** 这将是 Feynman-Kac、Black-Scholes 等一切应用的共同地基。<span class="marginnote">对标 Karatzas &amp; Shreve 第五章与 Øksendal 第五章。SDE 不是「ODE 加个噪声」这么简单——<strong>噪声项的积分是 Itô 积分，这让解的性质与 ODE 有本质差异</strong>。</span>

## 1 SDE 的正确定义：积分形式才是有意义的

SDE 的微分记号 $dX_t = b\,dt + \sigma\,dB_t$ 本身没有独立意义，它的意义由**积分形式**给出：

$$X_t = X_0 + \int_0^t b(X_s)\,ds + \int_0^t \sigma(X_s)\,dB_s.$$

**重点：第一项是普通黎曼积分（漂移是「平均推动」），第二项是 Itô 积分（扩散是「噪声推动」）。** 两者的数学性质完全不同——这也决定了 SDE 的解为何常常不是可微的：扩散项让 $X$ 继承了布朗运动的粗糙度。<span class="marginnote">积分形式的好处：把「微分」这个不能成立的动作，替换成「两个各自动得了的积分」。<strong>写 SDE 必须心里装着积分形式。</strong></span>

**辨析｜易错点：** $\sigma(X_t)\,dB_t$ 里 $dB_t$ 的「平方等于 $dt$」效应会透过 Itô 公式渗透进解——所以解 $X_t$ 的期望演化不仅由 $b$ 决定，还要吃扩散系数的二阶账。后面 Girsanov 与鞅论中这个细节会反复出现。

## 2 存在唯一性定理：Lipschitz 时代的通行证

**定理（强解存在唯一性）**：设系数 $b, \sigma$ 满足

- **Lipschitz 条件**：$|b(x) - b(y)| + |\sigma(x) - \sigma(y)| \le K|x - y|$；
- **线性增长条件**：$|b(x)| + |\sigma(x)| \le K(1 + |x|)$；

且 $X_0$ 与 $B$ 独立、$E[X_0^2] < \infty$，则 SDE 存在唯一**强解**（即解关于滤流 $\mathcal{F}_t^B$ 适应）。

证明的思路与常微分方程完全同构——**Picard 迭代**：

$$X_t^{(0)} = X_0, \qquad X_t^{(n+1)} = X_0 + \int_0^t b(X_s^{(n)})\,ds + \int_0^t \sigma(X_s^{(n)})\,dB_s,$$

再借助 Itô 等距与 Grönwall 引理证明 $X^{(n)}$ 在 $L^2$ 中收敛到唯一极限。<span class="marginnote">为什么需要线性增长？防止解在有限时间内「爆炸」到无穷——比如 $dX = X^2\,dt$ 的确定性版本就会爆。随机情形同样需要这类生长控制。</span>

**辨析｜易错点：** Lipschitz 是充分条件，不是必要条件。许多实用模型（如平方根过程 $dX = \theta(\mu - X)\,dt + \sigma\sqrt{X}\,dB$）系数不满足全局 Lipschitz，解仍存在唯一——需要更精细的局部化论证，这是进阶主题。

## 3 两个看家模型

### 几何布朗运动

$$dS_t = \mu S_t\,dt + \sigma S_t\,dB_t,$$

解（下一节公式解析将验证）

$$S_t = S_0 \exp\Big(\Big(\mu - \frac{\sigma^2}{2}\Big)t + \sigma B_t\Big).$$

**几何布朗运动的对数是带漂移的布朗运动，而且几乎必然为正**——这是 Black-Scholes 模型里股票价格的首选模型。

### Ornstein-Uhlenbeck 过程

$$dX_t = \theta(\mu - X_t)\,dt + \sigma\,dB_t,$$

解

$$X_t = \mu + (X_0 - \mu)e^{-\theta t} + \sigma\int_0^t e^{-\theta(t-s)}\,dB_s.$$

**OU 过程是「均值回归」的模范：漂移把 $X$ 拉回长期均值 $\mu$，强度为 $\theta$。** 它是利率模型（Vasicek）、分子运动速度（物理起源）的常客。当 $t \to \infty$，$X_t$ 趋于稳态分布 $\mathcal{N}\big(\mu, \sigma^2/(2\theta)\big)$。<span class="marginnote">OU 的稳态高斯分布是「漂移拉回」与「噪声扩散」的平衡：<strong>均值回归的强度决定稳态方差的尺度</strong>。这个稳态思想在统计学习、连续时间金融里都反复出现。</span>

## 4 强解与弱解的分别

**强解（strong solution）**：解是给定的布朗运动的确定性函数（路径意义下可测），即「给噪声，得轨道」。

**弱解（weak solution）**：解与布朗运动**一起**被构造，只要求存在某个（可能不同的）布朗运动与之匹配。

**重点：强解是「同一场噪声下的轨道」，弱解是「重新设计一场噪声来配合轨道」。** 区分它们的意义在于：弱解放宽了唯一性要求，却依然能推出分布层面的唯一性（唯一的转移概率），这对金融定价与遍历性分析已经足够。<span class="marginnote">直观类比：强解像「给定乐队的演奏，每个乐手必须跟上」；弱解像「只要求整支乐曲听起来像同一首」——<strong>分布对，路径可以不同</strong>。</span>

## 5 公式解析：几何布朗运动解里的 $\sigma^2/2$

$\mu$ 是股票的名义漂移率，解里却出现 $\mu - \sigma^2/2$——这个 $- \sigma^2/2$ 让无数初学金融的人困惑。用 Itô 公式一步推穿：

设 $X_t = \ln S_t$，由 Itô 公式对 $f(x) = \ln x$：

- **第一步，代入**：$d(\ln S_t) = \frac{1}{S_t} dS_t + \frac12 \cdot \frac{-1}{S_t^2} d\langle S\rangle_t$。
- **第二步，代入 SDE**：$d\langle S\rangle_t = \sigma^2 S_t^2\,dt$，于是 $d(\ln S_t) = \big(\mu - \frac{\sigma^2}{2}\big)dt + \sigma\,dB_t$。
- **第三步，积分**：$\ln S_t - \ln S_0 = \big(\mu - \frac{\sigma^2}{2}\big)t + \sigma B_t$，两边取指数即得解。

**$-\sigma^2/2$ 是「对数展开的凸性修正」**：$S$ 的期望增长是 $\mu$（因为 $E[S_t] = S_0 e^{\mu t}$，可自行验证），但对数增长必须扣除噪声的二阶贡献。**同一时刻，$S$ 的期望与 $S$ 的「典型值」是两码事——对数正态分布的均值严格大于中位数，差的就是 $\sigma^2/2$。**

## 6 线性 SDE 的通用解法：变易常数法

许多实用的 SDE 是线性的：$dX_t = (a(t)X_t + b(t))\,dt + (c(t)X_t + d(t))\,dB_t$。这类方程总有显式解，套路与常微分方程同构——「先解齐次，再变易常数」。

**第一步，解齐次随机指数**：$dX = aX\,dt + cX\,dB$ 的解是 $X_t = X_0 \mathcal{E}(c)_t e^{at}$，其中 $\mathcal{E}(c)_t = e^{cB_t - c^2t/2}$ 是随机指数——用 Itô 公式可验证 $d\mathcal{E}(c) = \mathcal{E}(c)\,c\,dB$，再配乘积公式即可。

**第二步，变易常数**：设 $X_t = F_t\,Y_t$，$F$ 是齐次解，$Y$ 待求。由半鞅乘积公式 $d(XY) = X\,dY + Y\,dX + d[X,Y]$，把含 $Y$ 的漂移清零，得到

$$Y_t = Y_0 + \int_0^t F_s^{-1}(b_s - c_s d_s)\,ds + \int_0^t F_s^{-1} d_s\,dB_s.$$

**几何布朗运动与 OU 过程都是这个框架的特例**：GBM 取 $b = c = 0$（解即随机指数乘 $e^{at}$）；OU 取 $c = 0$、$a = -\theta$、$b = \theta\mu$。掌握变易常数法，等于掌握了线性随机动力学的全部显式解——这是卡尔曼滤波、利率模型（Vasicek/Hull-White）的共同地基。<span class="marginnote">工程视角：<strong>线性 SDE 是随机动力学的「线性系统」，变易常数法就是它的「传递函数法」</strong>；深度学习里的随机微分方程近似（如扩散模型的 ODE/SDE 对偶）也大量借用这套显式结构。</span>

## 7 为什么 SDE 值得单立一篇

ODE 的解是「函数」，SDE 的解是「过程」——但更深的分野在于：**ODE 描述确定性的因果，SDE 描述随机的因果**，后者要求我们同时回答「趋势多少」与「噪声多大」。这正是 SDE 的三个看家问题：**解的存在与唯一**（Picard + Itô 等距）、**解的性质**（Itô 公式检验）、**解对应的测度**（Girsanov 换尺子）。三个问题，将在后续各篇一一兑现——本专题剩下的大部分内容，本质上都是「对一条 SDE 问这三个问题」。

## 8 小结

- SDE 的精确含义是**积分形式**：$X_t = X_0 + \int b\,ds + \int \sigma\,dB$，漂移走黎曼积分，扩散走 Itô 积分。
- **强解存在唯一**需要 Lipschitz + 线性增长，证明用 Picard 迭代 + 等距 + Grönwall。
- **几何布朗运动** $S_t = S_0 e^{(\mu - \sigma^2/2)t + \sigma B_t}$：对数正态、几乎必然为正，是资产价格的头号模型。
- **OU 过程**是均值回归典范，$t\to\infty$ 时趋于高斯稳态。
- **强解 / 弱解**之别：同一噪声下的轨道 vs 重新设计噪声的分布匹配。
- 解法工具箱：Itô 公式（取对数、取幂）、随机指数、变易常数法。

在下一节，我们将做一件更颠覆的事：**换一把概率尺子来量同一场布朗运动**——Girsanov 定理与测度变换，让漂移在换测度后悄悄消失。
