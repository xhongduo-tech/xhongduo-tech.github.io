## 为什么从局部鞅与半鞅开始

Itô 积分在最朴素的版本里要求被积函数平方可积，但现实中的被积函数（比如 $e^{B_t}$ 这种无界指数）往往不满足。更麻烦的是，随机指数 $\mathcal{E}(\theta)$ 在上节被我们「默认」成了鞅——但它其实只是个**局部鞅**，全局鞅性需要 Novikov 条件来担保。这些「只差一步到鞅」的过程随处可见，逼着我们把鞅的概念放宽。

这一节要做两件事：把鞅**局部化**成局部鞅，再把局部鞅与「有界变差」拼成**半鞅**——一个被证明是**唯一能让 Itô 积分有意义的过程类**。半鞅不是猎奇，它就是随机积分「真正的家」：所有我们见过的、将要见的过程——布朗运动、扩散解、风险资产价格——都是半鞅。<span class="marginnote">对标 Protter 第二、三章。<strong>Bichteler–Dellacherie 定理说：能使良好随机积分有意义的过程，恰恰就是半鞅——这不是巧合，是结构。</strong></span>

## 1 局部鞅：先截断，再谈鞅

**局部鞅（local martingale）**：过程 $M$ 若存在一列停时 $\tau_n \uparrow \infty$，使每个「截断后的过程」$M^{\tau_n}_t := M_{t \wedge \tau_n}$ 都是鞅，则称 $M$ 为局部鞅。

这几乎是第一章「截断 — 取极限」手法的正式化：**每个时刻我都只要求它「在某个大口袋内是鞅」，口袋随 $n$ 不断扩张，覆盖全部时间。**<span class="marginnote">停时序列 $\tau_n$ 叫<strong>局部化序列</strong>。对连续过程，常用 $\tau_n = \inf\{t : |M_t| \ge n\}$——把过程锁在 $[-n, n]$ 里。</span>

**重点：局部鞅不一定真是鞅。** 经典反例：$M_t = \exp(B_t - t/2)$（几何布朗运动的对数版）是连续局部鞅，却**不是**鞅——它的期望随时间严格下降。这解释了为什么 Girsanov 里 Novikov 条件必不可少：没有它，密度过程 $Z$ 就「只是」局部鞅，测度就换不成。<span class="marginnote">反直觉之处：<strong>局部鞅的期望可以在不违反任何「局部」规则的前提下悄然漂移</strong>。可积性（uniform integrability）是局部鞅升级为鞅的充要条件。</span>

## 2 半鞅：局部鞅 + 有界变差

**半鞅（semimartingale）**：过程 $X$ 若能分解为

$$X_t = X_0 + M_t + A_t,$$

其中 $M$ 是局部鞅，$A$ 是有界变差过程（$A_0 = 0$），则称 $X$ 为半鞅。

直觉：半鞅 = **「噪声部分」加「趋势部分」**。布朗运动取 $A \equiv 0$；漂移扩散 $dX = b\,dt + \sigma\,dB$ 取 $M = \int\sigma\,dB$（局部鞅）、$A = \int b\,dt$（有界变差）。<span class="marginnote">这种分解叫<strong>Doob–Meyer 分解</strong>。注意：当 $A$ 可积时是「鞅 + 可料有界变差」的典范形式——它是停时、可料性这些概念的最终结算中心。</span>

**辨析｜易错点：** 半鞅分解里的 $M$ 与 $A$ 是**唯一的**吗？只要 $M$ 是鞅而非仅仅局部鞅，分解就唯一；若 $M$ 仅是局部鞅，分解可以有一定自由度。初学者常把「半鞅的分解唯一」当成理所当然——实际上唯一性本身就是一个定理，需要额外条件。

## 3 二次变差与交叉变差：半鞅的「二阶几何」

对半鞅 $X$，二次变差

$$[X, X]_t := \lim_{|\Pi| \to 0} \sum_i (X_{t_{i+1}} - X_{t_i})^2$$

存在且与取点无关（依概率）。对两个半鞅 $X, Y$，交叉变差由极化恒等式定义：

$$[X, Y]_t := \frac12\big([X+Y, X+Y]_t - [X, X]_t - [Y, Y]_t\big).$$

**重点：连续半鞅的二次变差是「纯鞅量」——$[X,X]_t = [M,M]_t$，有界变差部分 $A$ 对二次变差毫无贡献。** 因为一阶变差有限的项，其平方和必趋于零；二次变差只「看见」粗糙的鞅部分。<span class="marginnote">这正是前述「一阶粗糙、二阶光滑」的谱系化：<strong>有界变差过程在二阶上「光滑」到消失，鞅部分在二阶上「粗糙」到留下 $[M,M]$</strong>。</span>

## 4 公式解析：分部积分 $d(XY) = X\,dY + Y\,dX + d[X,Y]$

半鞅世界里的分部积分公式是

$$X_t Y_t = X_0 Y_0 + \int_0^t X_s\,dY_s + \int_0^t Y_s\,dX_s + [X, Y]_t,$$

微分写法即 $d(XY) = X\,dY + Y\,dX + d[X,Y]$。

- **第一步，回忆普通情形**：$d(XY) = X\,dY + Y\,dX$。那是光滑路径下二阶量被忽略的结果。
- **第二步，随机情形二阶不消失**：$X, Y$ 各带粗糙的鞅部分，它们的乘积里会渗出交叉二阶量 $d[X,Y]$。
- **第三步，辨认交叉项**：当 $X = Y = B$ 时 $d[X,Y] = dt$，回到 $d(B^2) = 2B\,dB + dt$——**与 Itô 公式完全自洽**。$X = B, Y = t$ 时交叉项为零，得到 $d(tB) = B\,dt + t\,dB$。

**分部积分是 Itô 公式的半鞅推广，二者是同一个「二阶账」的两种记法。**

## 5 为什么 Itô 积分「恰好」住在半鞅上

把 Bichteler–Dellacherie 定理的大意讲清：如果要求随机积分对被积函数的逼近有良好性质（比如某种连续性与可加性），那么积分器只能是半鞅——**半鞅是随机积分能存在的最大过程类，也是最小的自然类**。

这不是「定义出来的方便」，而是「定理逼出来的必然」：给一条过程，凡是想让 $\int H\,dX$ 对一堆良好的 $H$ 有意义，$X$ 就必须能分解成「局部鞅 + 有界变差」。所以你看过的所有过程——布朗运动、SDE 解、风险资产——都是半鞅，不是巧合，是它们能被 Itô 积分的先决条件。<span class="marginnote">工程视角：半鞅 = 「有限方差趋势 + 有限二阶噪声」的精确数学表述。<strong>机器学习里「确定性梯度 + 噪声批次」的优化动力学，也是同一结构。</strong></span>

## 6 随机指数：局部鞅的经典舞台

对半鞅 $X$（$X_0 = 0$），**随机指数（stochastic exponential）** $\mathcal{E}(X)$ 是 Doléans–Dade 方程的解：

$$d\mathcal{E}(X)_t = \mathcal{E}(X)_t \, dX_t, \qquad \mathcal{E}(X)_0 = 1.$$

连续情形下解为 $\mathcal{E}(X)_t = \exp\big(X_t - \tfrac12 [X,X]_t\big)$。注意这与 Girsanov 里的随机指数同源：$\mathcal{E}(\int \theta\,dB) = \exp\big(\int\theta\,dB - \tfrac12\int\theta^2\,ds\big)$。

**只要 $X$ 是局部鞅，$\mathcal{E}(X)$ 就是局部鞅**——但正如下一节即将验证的，局部鞅不等于鞅。随机指数是「局部鞅之所以非鞅」的最重要产地：它把「指数级波动」与「二阶修正」打包在一起，常常在无穷远处泄漏期望质量。

## 7 例：$M_t = e^{B_t - t/2}$ 是局部鞅而非鞅的完整验证

直接算期望：$E[M_t] = E[e^{B_t}]e^{-t/2} = e^{t/2}e^{-t/2} = 1$——每个 $t$ 时刻的期望都是 1，那它怎么不是鞅？猫腻在**均匀可积性**：$M$ 的尾部质量收敛得太慢，导致

$$E[M_\infty] = 0 \ne \lim_{t\to\infty} E[M_t] = 1.$$

因为 $B_t/t \to 0$ a.s. 而 $-t/2 \to -\infty$，所以 $M_t \to 0$ a.s.，期望「在无穷远处蒸发」了。**期望与极限不交换，就是局部鞅非鞅的诊断书。** 对条件期望同样成立：$E[M_T \mid \mathcal{F}_t]$ 一般严格小于 $M_t$——过程在下意识的「暗流」中悄悄衰减。

**辨析｜易错点：** 它是对照组：$e^{B_t}$ 连局部鞅都不是（因为 $e^{B_t}$ 的漂移项不为零），$e^{B_t - t/2}$ 是局部鞅但不均匀可积，$e^{B_t}$ 再配一个「可积边界」才是鞅。三个对象，三个层级，初学者常把「指数型过程」一律当成鞅。

**一个记忆锚点**：半鞅 = 局部鞅 + 有界变差，这几乎是「随机 + 确定性」的最小分解。凡是你能写出的扩散过程都自动是半鞅；反过来，凡是半鞅都允许 Itô 积分——于是「随机分析能用」的门槛，恰好就是「过程是半鞅」这道门槛。

## 8 半鞅里的金融：为什么定价要先「验鞅」

风险中性定价的每一步，都建立在本节的分类学上：

- **标的** $S$：通常是半鞅（局部鞅 + 有界变差趋势）；
- **折现过程** $e^{-rt}S_t$：在风险中性测度下是鞅（不只是局部鞅）；
- **随机指数** $Z = dQ/dP$：需要 Novikov 条件保证它是**真鞅**，否则「换测度」会把概率质量换丢在无穷远。

**重点：为什么「真鞅」这么较真？因为定价的全部结论——$E_Q[g(S_T)]$ 取期望——都依赖「取期望 = 加权平均」这一动作在 $Q$ 下成立。** 若 $Z$ 只是局部鞅，$Q$ 根本不是概率测度，期权价格就成了「没有测度的期望」，毫无意义。这就是为什么 Novikov 条件在金融文献里几乎从不缺席。

更一般的半鞅（带跳过程，如跳扩散模型）需要更精细的随机指数与爆炸条件——这已超出本篇，但骨架相同：**先把对象放进正确的类，再谈积分与期望。**<span class="marginnote">机器学习里的类比：<strong>「先验正确，再谈采样」——先确认度量结构，再谈优化</strong>；半鞅理论就是随机动力学的「度量结构」。</span>

（尾声：半鞅理论给了随机分析一个「家的地址」——凡是半鞅，Itô 积分就有意义；凡是更粗糙的过程，请先局部化或换一个框架。这个「先定类，再积分」的顺序，请务必刻在脑海里。下一站，我们将看见这座理论大厦如何照进偏微分方程与定价实务。）

（再补一句：局部鞅升级为鞅的三个常用判据——均匀可积、可积上界、Novikov 型条件。记住「局部鞅未必鞅」的警告，比记住任何公式都重要。）

## 9 小结

- **局部鞅** = 通过停时序列 $\tau_n \uparrow\infty$ 截断后逐段为鞅；局部鞅未必是鞅（随机指数、$e^{B_t - t/2}$ 即反例）。
- **半鞅** $X = X_0 + M + A$：局部鞅 + 有界变差，是随机积分能存在的唯一自然过程类（Bichteler–Dellacherie）。
- **二次变差**是纯鞅量：$[X,X] = [M,M]$，有界变差部分零贡献；交叉变差 $[X,Y]$ 由极化恒等式定义。
- **分部积分** $d(XY) = X\,dY + Y\,dX + d[X,Y]$：Itô 公式的半鞅推广。
- **Novikov 条件**把随机指数从局部鞅「升级」为鞅——Girsanov 由此保住了测度归一。

在下一节，我们将见证随机分析与偏微分方程的历史性握手——**Feynman-Kac 公式**，把 SDE 的解与热方程联结在一起。
