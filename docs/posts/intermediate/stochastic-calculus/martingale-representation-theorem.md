## 为什么从鞅表示定理开始

Black-Scholes 定价的关键一步，是声称「期权收益可以被自融资组合复制」。凭什么一定复刻得出来？凭什么只要把 Delta 调成 $f_x$ 就万事大吉？答案藏在鞅表示定理里——它是整个复制思想的数学担保。

鞅表示定理说的是一个惊人的事实：**在布朗运动生成的滤流下，每一个（平方可积的）鞅都能写成唯一的一个随机积分**：

$$M_t = M_0 + \int_0^t \phi_s\,dB_s.$$

换句话说，**布朗运动的「信息世界」里，任何不造势的随机过程（鞅）都只是一条 Itô 积分曲线**。这解释了为什么在 Black-Scholes 世界里「任何衍生品都可复制」——因为可复制的对象（鞅）与可积分的对象（Itô 积分）是同一个集合。它也揭示了市场为什么叫**完备（complete）**：噪声只有一种来源，于是风险只有一个维度可对冲。<span class="marginnote">对标 Karatzas &amp; Shreve 第三章。表示定理的深刻源头是 Itô 的 <strong>Wiener 混沌展开</strong>：布朗函数空间的每个 $L^2$ 元素都能写成一系列多重 Wiener 积分的正交和。</span>

## 1 定理陈述：噪声的「基」

**鞅表示定理（martingale representation theorem）**：设滤流 $\{\mathcal{F}_t\}$ 由布朗运动生成（$\mathcal{F}_t = \sigma\{B_s : 0\le s\le t\}$），$M$ 是关于它的鞅且 $E[\sup_t M_t^2] < \infty$，则存在唯一（在 $L^2(ds\times dP)$ 意义下）的适应过程 $\phi$，使

$$M_t = M_0 + \int_0^t \phi_s\,dB_s, \qquad \text{a.s. 对一切 } t \ge 0.$$

**重点：$M$ 的「全部随机性」都来自布朗运动，系数 $\phi$ 决定「每个时刻对噪声的暴露强度」**。这个定理把「鞅」这个巨大的对象家族，压缩成了「被积函数」这个便于操作的维度。<span class="marginnote">类比线性代数：布朗运动是函数空间的「基底」，鞅是「向量」，$\phi$ 是「坐标」。<strong>表示定理 = 鞅空间被布朗噪声张成的完备性定理</strong>。</span>

## 2 公式解析：$M_t = M_0 + \int_0^t \phi_s\,dB_s$ 的逐项含义

- **第一步，$M_0$ 是常数项**：鞅的「初始身价」。由于鞅性要求 $E[M_t] = M_0$，随机积分部分必须对每个 $t$ 期望为零——Itô 积分天然满足。
- **第二步，$\int_0^t \phi_s\,dB_s$ 是全部波动**：$M_t$ 与 $M_0$ 的差，逐时刻由「当前的噪声暴露 $\phi_s$」乘以「当前的噪声冲击 $dB_s$」累积而成。
- **第三步，唯一性**：若 $M = M_0 + \int\phi\,dB = M_0 + \int\psi\,dB$，则 $\int(\phi-\psi)\,dB = 0$，由 Itô 等距 $E\int(\phi-\psi)^2\,ds = 0$，故 $\phi = \psi$ a.e.——**表示是唯一的**。

**直观：给定一条鞅轨道，唯一地能反推出「它每个时刻该用多少布朗噪声来合成」。** 这就像一个解码器：波形已知，解出调制信号。

## 3 为什么它让市场完备：复制的数学担保

在 Black-Scholes 模型里，任何衍生品收益 $g(S_T)$ 的折现过程 $e^{-rT}g(S_T)$ 是一个 $Q$-鞅。由表示定理，存在 $\phi$ 使

$$e^{-rt} V_t = E_Q[e^{-rT}g(S_T) \mid \mathcal{F}_t] = V_0 + \int_0^t \phi_s\,d\big(e^{-rs}S_s\big),$$

而右边恰好是一个**自融资对冲组合**的价值。于是：

**重点：表示定理 ⇔ 市场完备。** 一个衍生品只要「折现收益是鞅」（Feynman-Kac 保证），就一定能写成随机积分（表示定理保证），而随机积分恰恰对应自融资组合（对冲论证保证）——三段一链，Black-Scholes 的复制故事严丝合缝。<span class="marginnote">反方向也成立：如果市场里多了一个独立噪声源（随机波动率），可表示的范围扩大，但「任意收益都可复制」反而失效——<strong>信息越多，完备性越难保</strong>。</span>

## 4 从表示定理看「马尔可夫」与「鞅」的分工

一个常被忽略的视角：表示定理要求**滤流由布朗运动生成**。这意味着过程必须能「只用布朗噪声」刻画——这正是马尔可夫性（只依赖现在）与鞅表示（只用当前噪声暴露）在结构上的亲缘关系。

**辨析｜易错点：** 表示定理要求的是**滤流**由布朗运动生成，不是过程本身是布朗运动。一个过程即使完全不是高斯的（比如随机波动率下的积分），只要它关于 $\mathcal{F}^B$ 可测、是鞅，就照样有表示——表示定理统治的是**信息的来源**，不是**分布的形态**。<span class="marginnote">在机器学习语境里：<strong>表示定理相当于说「在一个充分统计量的世界里，一切无偏估计都是它的函数」</strong>——信息源的完备性，决定了表示空间的大小。</span>

**三者的分工对照：**

| 概念 | 管什么 | 一句话 |
| --- | --- | --- |
| 马尔可夫性 | 依赖结构 | 给定现在，过去与未来独立 |
| 鞅性 | 条件期望 | 给定全部历史，未来均值是现在 |
| 鞅表示 | 表示基底 | 鞅是布朗噪声的唯一积分 |

**重点：马尔可夫性与鞅性讲的是「过程的内在纪律」，鞅表示讲的是「整个纪律空间恰好被布朗噪声张成」**。三者尺度不同，却层层咬合：马尔可夫性让你能从当前状态出发，鞅性让你能写条件期望方程，表示定理让你能把任何这样的对象显式展开成积分。

## 5 例：从表示定理「读」出系数

看一个具体表示。$M_t = B_t^2 - t$ 是鞅（前文已验证），由 Itô 公式 $d(B^2 - t) = 2B_t\,dB_t$，表示定理给出的系数是 $\phi_t = 2B_t$：

$$B_t^2 - t = \int_0^t 2B_s\,dB_s.$$

这条表示反过来验证了等距：$E[(B_t^2 - t)^2] = E\int_0^t 4B_s^2\,ds = 4\int_0^t s\,ds = 2t^2$，可与直接计算 $E[(B_t^2-t)^2] = 2t^2$ 对照——两条路，同一个数。<span class="marginnote">这个例子也是「反解码」的训练场：<strong>看到一条鞅轨道，你能立刻说出它每个时刻对噪声的暴露强度 $\phi_s$</strong>——在 Black-Scholes 里，这个 $\phi_s$ 就是 Delta 对冲的股票份额。</span>

**读法**：若 $M$ 是「资产折现价值的鞅」，表示定理说它的全部随机性可以唯一地分解成「每个时刻对布朗噪声的暴露强度 $\phi_s$」。表示定理不只是「存在性定理」，它顺手给出了**对冲的精确公式**。

## 6 更广阔的图景：Itô–Wiener 混沌展开

表示定理只是更一般定理的「一阶版本」。Itô 在 1950 年代证明：$L^2(\Omega, \mathcal{F}_T^B, P)$ 里的任何平方可积随机变量 $F$ 都能写成多重 Wiener 积分的正交和：

$$F = \sum_{n=0}^\infty I_n(f_n), \qquad I_n(f_n) = \int_{0 < t_1 < \cdots < t_n < T} f_n(t_1, \dots, t_n)\,dB_{t_1}\cdots dB_{t_n},$$

其中 $I_n$ 是 $n$ 重 Itô 积分，$f_n$ 是确定性对称函数，且**各阶混沌（$n$ 不同的 $I_n$）两两正交**。这个分解叫 **Wiener 混沌展开**。

- $n = 0$：常数部分 $E[F]$；
- $n = 1$：一重积分——「高斯噪声的线性滤波」，表示定理的积分形式正落在这里；
- $n \ge 2$：非线性混沌——高阶相互作用项。

**重点：布朗世界里的每个平方可积量，都由「各阶多项式噪声」张成。** 这解释了为什么表示定理对「一阶鞅」成立：鞅没有高阶混沌（$M_t - M_0$ 的展开只含 $n = 1$ 项）。量子场论里的 Wick 积、机器学习里的核特征空间、多项式混沌展开（PCE），都与这套分解同构。<span class="marginnote">机器学习视角：<strong>Wiener 混沌就是随机函数空间的「泰勒级数」——一阶项是线性模型，高阶项是相互作用特征</strong>。谱方法与深度核方法都在这张表上。</span>

**一个历史注脚**：表示定理的思想源自 Itô 1950 年代对 Wiener 混沌的研究，后经 Kunita–Watanabe 与 Clark 等人系统化，成为随机分析与泛函分析交汇的著名成果。它对概率论的意义，正如「每个 $L^2$ 函数都能用正交基展开」对傅里叶分析的意义——**一个「基底完备性」的定理**。

## 7 表示定理的「可料性」与多维版本

表示定理里的 $\phi$ 不只是适应，它还是**可料（predictable）**的：$\phi_t$ 在 $t$ 时刻之前就已知。这与「鞅的增量不可预测」形成绝妙对偶——**过程的不可预测性，被表示为可预测的系数对不可预测噪声的暴露**。金融里：$\phi_t$ 是 Delta，$t$ 时刻已知；$dB_t$ 是冲击，不可预知。整个对冲的哲学就藏在这个对偶里。

多维情形同样成立：设 $B = (B^1, \dots, B^d)$ 是 $d$ 维独立布朗运动，则 $\mathcal{F}^B$-鞅 $M$ 有

$$M_t = M_0 + \sum_{i=1}^d \int_0^t \phi^i_s\,dB^i_s,$$

其中 $\phi^i$ 唯一且可料。**$d$ 个噪声源，$d$ 个暴露系数——市场里有几个独立噪声源，就需要几个对冲工具**，这是「完备市场的维数 = 噪声维数」的精确陈述。

**辨析｜易错点：** 表示定理要求滤流**恰由** $B$ 生成。若过程里掺入额外随机性（随机波动率、跳），表示定理失效，市场不完备，Delta 对冲只能「近似」而非「精确」——无数定价悖论由此而来。

**为什么这对机器学习学习者重要？** 扩散模型的前向过程是「把数据加噪成纯布朗运动」，反向过程则用神经网络逼近「条件期望下的噪声估计」——而表示定理保证：只要知道噪声源的暴露系数 $\phi$，你就能在时间轴上重构一切。**表示的唯一性，是「从噪声中反演数据」可行的根基。** 而可料性的要求，则保证反演过程在每一步都是因果的、可实时计算的——这正是在线算法与实时对冲的共同底线。

（再补一句：表示定理的可料性来自 Itô 积分的构造，唯一性来自 Itô 等距；两者合起来意味着「表示」既是存在的、也是可计算的——这正是从理论到算法的最后一步。而它最迷人的后果，是把「市场完备」这个经济学命题，翻译成了「噪声基底完备」这个数学命题。）

## 8 小结

## 8 小结

- **鞅表示定理**：$\mathcal{F}^B$-鞅 $M$ 有唯一表示 $M_t = M_0 + \int_0^t \phi_s\,dB_s$。
- **唯一性**由 Itô 等距保证：$\int(\phi-\psi)\,dB = 0 \Rightarrow \phi = \psi$ a.e.。
- **市场完备 ⇔ 鞅表示**：折现收益是鞅 + 表示成随机积分 + 随机积分即自融资组合。
- 前提是**滤流由布朗运动生成**——信息源的完备性决定表示空间，分布形态无关。
- 理论基础是 Itô–Wiener 混沌展开；反例见随机波动率模型的「不完备」。
