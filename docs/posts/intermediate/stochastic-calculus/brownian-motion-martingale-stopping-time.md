## 为什么从三大基石开始

随机分析这门学科，浓缩成一个问题就是：**如何对一条处处不可导的随机轨道做微积分？** 普通的微积分要求被积对象够「光滑」，可布朗运动的轨道连导数都不存在，黎曼–斯蒂尔切斯积分在这里寸步难行。出路不是把轨道变光滑，而是换一套「积分规则」——Itô 积分。而在那套规则建立之前，必须先立起三块地基：

**布朗运动**提供轨道，**鞅**提供概率意义上的守恒律（「过去不能预告未来均值」），**停时**提供「何时入场、何时退场」的时钟。三者齐备，后续的一切——Itô 积分、Itô 公式、随机微分方程、Girsanov 测度变换——才有安放之处。

你已经在第二级《随机过程》里见过离散时间鞅与布朗运动的定义，也在第一级《概率》里学会了条件期望。这一篇的任务，是把它们在连续时间下焊接成一个整体。<span class="marginnote">本专题对标 Karatzas &amp; Shreve《Brownian Motion and Stochastic Calculus》前两章与 Protter 第一章。连续时间随机分析的全部「语法」——适应、可测、停时、局部化——几乎都在这两章里一次出现。<strong>第一次读不必求全懂，先建立「轨道 + 滤流 + 停时」的直觉骨架。</strong></span>

本节目标：把三大概念的定义立稳，证明布朗运动的鞅性，掌握可选停时定理，并为「为什么 $dB$ 的平方等于 $dt$」埋下伏笔。

## 1 布朗运动：连续时间微积分的「测试轨道」

**标准布朗运动（standard Brownian motion）**：随机过程 $\{B(t) : t \ge 0\}$ 若满足 $B(0) = 0$、增量独立平稳、$B(t) - B(s) \sim \mathcal{N}(0, t-s)$、轨道几乎必然连续，就称为标准布朗运动。

它在随机分析中有一个决定一切的性格：**二次变差等于时间本身**。设 $\Pi = \{0 = t_0 < t_1 < \cdots < t_n = t\}$ 是 $[0,t]$ 的划分，$|\Pi| = \max(t_{i+1} - t_i) \to 0$，则

$$\langle B, B\rangle_t := \lim_{|\Pi| \to 0} \sum_{i} \big(B(t_{i+1}) - B(t_i)\big)^2 = t \quad (\text{依概率}).$$

**重点：布朗运动在微尺度上「把时间几乎全部花在了二阶涨落上」**。增量标准差是 $\sqrt{\Delta t}$ 的量级，平方之后恰好是 $\Delta t$，一加总就成了时间本身。这个性质与「处处不可导」互为因果——轨道如此之粗糙，以至于二阶量不趋于零而趋于 $dt$。<span class="marginnote">对比普通光滑函数：$f$ 可导时 $\sum (\Delta f)^2 \approx \sum f'(t_i)^2 \Delta t_i^2 \to 0$，二阶量「消失」。布朗运动做不到这一点。<strong>正是这份「二阶不消失」，让 Itô 公式多出一个修正项。</strong></span>

**辨析｜易错点：** 二次变差 $= t$ 是依概率收敛到确定常数，不是「随机变量收敛到随机变量」。同一条轨道上的二阶和，几乎必然（可以取子列后）都奔着同一个数去——这是布朗运动「二阶光滑」的精确含义。

## 2 连续时间鞅：公平游戏的精确翻译

**鞅（martingale）**：设 $\{\mathcal{F}_t\}$ 是一个滤流（信息随时间的累积）。过程 $X$ 关于 $\mathcal{F}_t$ 适应、可积，且对一切 $0 \le s \le t$ 满足

$$E\big[X_t \mid \mathcal{F}_s\big] = X_s \quad \text{a.s.}$$

把 $X_t$ 读作「到 $t$ 时刻为止赌徒手中的资本」，鞅性说：**基于 $s$ 时刻之前的全部历史，$t$ 时刻资本的期望正是 $s$ 时刻的资本**。公平游戏不是「每把不输不赢」，而是「没有任何策略能靠过去的信息预测未来收益的方向」——这是无套利思想的数学雏形。<span class="marginnote">「鞅」一词源自法语 martingale——一种输钱后加倍下注的赌法。Doob 在 1940 年代把它精确化为「条件期望不变」的过程。<strong>赌徒试图用加倍策略战胜公平游戏，而鞅论告诉我们：这不可能。</strong></span>

布朗运动是鞅吗？是。因为对 $s < t$，增量 $B(t) - B(s)$ 独立于 $\mathcal{F}_s$ 且均值为零，于是

$$E\big[B(t) \mid \mathcal{F}_s\big] = E\big[B(s) \mid \mathcal{F}_s\big] + E\big[B(t) - B(s) \mid \mathcal{F}_s\big] = B(s) + 0 = B(s).$$

更进一步，$B(t)^2 - t$ 也是鞅（试试用 $E[\Delta B^2] = \Delta t$ 验证）。这个「平方鞅」是 Itô 公式修正项的另一种显现，后面会反复遇见。

**辨析｜易错点：** 鞅与马尔可夫是两回事。**马尔可夫性**管「依赖结构」：给定现在，过去与未来条件独立；**鞅性**管「条件期望」：给定全部历史，未来均值等于现在。布朗运动两者兼具，但一般过程可以只占其一。判断一个过程是否鞅，唯一的标准是条件期望等式，不是「看起来随机」。

## 3 停时：可依赖路径的随机时钟

**停时（stopping time）**：取值于 $[0, \infty]$ 的随机变量 $T$，若对每个 $t \ge 0$，事件 $\{T \le t\} \in \mathcal{F}_t$。

这个定义翻译成直觉就是：**判断「$T$ 是否已经发生」这件事，只能使用 $t$ 时刻之前的信息**。于是：

- 固定时刻 $t_0$ 是停时；
- 首次击中时刻 $\tau_a = \inf\{t : B(t) = a\}$ 是停时——到 $t$ 时刻能否判断「已经首次到 $a$」只取决于 $[0,t]$ 上的轨道；
- **最后一次**离开某区域的时间不是停时——它需要「未来不再回来」这种预知未来的保证。<span class="marginnote">金融里的「止损」「限价单」都是停时：触发条件只看已实现的价格。而「等我涨到最高点再卖」不是停时——<strong>判断「已经最高」必须偷看未来</strong>。</span>

**辨析｜易错点：** 停时不是「任意与轨道有关的随机时刻」。它要求决策规则是**因果的**：每一步只许看已经发生的事。可料停时（predictable stopping time）进一步要求「提前一步能预知」——那个概念我们到半鞅理论再展开。

## 4 Doob 可选停时定理

鞅最漂亮的性质是：任何有界的停时策略都改变不了期望。这就是**可选停时（optional stopping）**：

若 $T$ 是有界停时（存在 $C < \infty$ 使 $T \le C$ a.s.），$X$ 是鞅，则

$$E\big[X_T\big] = E\big[X_0\big].$$

**重点：只要停时有界，公平游戏的任何「入场退场策略」都不占便宜。** 直觉：策略信息全部来自过去，而鞅性保证过去预告不了未来的条件期望，于是「等到有利时刻再走」并不能提高平均收益。<span class="marginnote">注意区分：有界停时是「在已知的 C 之前必然结束」；像「首次出界」这类无界停时不能直接套用——需要把 $T$ 截断成 $T \wedge n$ 再取极限，或者验证可积条件。<strong>这一截断技巧就是随机分析里的「局部化」。</strong></span>

**一个立刻能用上它的例子——赌徒破产：** 设赌徒每局净赚 +1 或 -1 各半（公平游戏），$X_n$ 是 $n$ 局后的总收益，则 $X_n$ 是鞅。若他定下止损线 $-a$、止盈线 $+b$，首次触及二者之一的时刻 $\tau$ 是停时，由可选停时 $E[X_\tau] = 0$ 立得破产概率 $b/(a+b)$：止盈离得越远，破产风险越大。「赌徒必输」不是运气问题，是鞅论的必然。

## 5 公式解析：为什么 $E[B(\tau \wedge n)] = 0$ 恒成立

**「先截断、后取极限」——这是随机分析中反复使用的基本手法。** 考虑首次击穿区间的时刻 $\tau = \inf\{t : B(t) = a \text{ 或 } -a\}$，它无界，不能直接套用可选停时。但我们有

$$E\big[B(\tau \wedge n)\big] = E\big[B(0)\big] = 0, \qquad \text{对一切 } n \ge 1.$$

拆成三步：

- **第一步，认出可截断性**：$\tau \wedge n$ 是取值不超过 $n$ 的有界停时，可选停时定理直接适用，故 $E[B(\tau \wedge n)] = E[B(0)] = 0$。
- **第二步，令 $n \to \infty$**：$B(\tau \wedge n) \to B(\tau)$ 几乎必然；又在击穿发生前轨道被界在 $[-a, a]$ 内，由控制收敛得到 $E[B(\tau)] = 0$。
- **第三步，读出结论**：$B(\tau)$ 只能取 $\pm a$，而期望为零，于是 $P(B(\tau) = a) = P(B(\tau) = -a) = 1/2$——**一个没动用任何方程就得到的对称性结论**：布朗运动向 $a$ 与 $-a$ 哪个方向先跑的概率各半。

这个「截断 — 取极限」的骨架，正是下一节 Itô 积分构造的主线：先对简单被积函数积分，再通过 $L^2$ 逼近扩展到一般过程。

## 6 历史旁白：三个概念如何走到一起

布朗运动的数学故事始于 1900 年 Bachelier 的博士论文——他最早写下「$E[X_{t+s}\mid\mathcal{F}_t] = X_t$」这一条件期望形态；1905 年爱因斯坦从分子运动推出扩散方程；1918 年 Wiener 给出布朗运动的严格构造。鞅则由 Lévy 在 1930 年代的直觉与 Doob 在 1940–1950 年的系统奠基而成：Doob 把「公平游戏」写成条件期望等式，并证明了停时、可测性、可选停时等一整套核心结果。

真正把三者焊成「随机分析」的，是伊藤清 1942 年在东京帝国大学完成的工作：他以布朗运动的轨道为积分器，把鞅与停时的局部化手法直接织进了积分构造。此后一路生长：Doob 在 1950 年代用鞅论重写势论，Meyer 完成 Doob–Meyer 分解，Black–Scholes–Merton 在 1970 年代用它为期权定价——再到今日扩散模型（DDPM）的每一步「去噪」，都仍是这三兄弟的组合拳。

**重点：这不是「先有积分、后有鞅」，而是倒过来——停时与鞅先为积分准备好语法，局部化先为无界对象准备好安全网。** 学完本专题再回头看，你会发现每一件「新工具」都只是三兄弟的某种组合。

**先别急着往前冲**：这一节的三个概念会在后面以不同面貌反复出现——停时会变成「首次出界」「首次击穿」，鞅会变成「局部鞅」「Snell 包络」，布朗运动会变成「各种扩散的解」。把定义与直觉钉牢，后面的每一篇都是熟面孔。

## 7 为什么这套定义是「最小足够」的

布朗运动的五条公理并非相互独立。事实上可以压缩：**独立平稳增量 + 连续轨道 + $B(0)=0$ 基本定死了 $B(t)-B(s)\sim\mathcal{N}(0,\sigma^2(t-s))$**——高斯性不是外加的假设，而是从「平稳 + 有限二阶矩 + 连续」里挤出来的（中心极限定理式的论证）。反过来，高斯性加零均值独立增量也能推出 Markov 性与鞅性。

换句话说：**随机分析真正需要的是「连续 + 独立平稳增量 + 有限方差」——其余性质都是它们的影子。** 这也是为什么 Lévy 特征定理（「连续局部鞅 + 二次变差 $= t$」）能成为更干净的身份证：它把「分布的尾巴」压缩成了「二阶量的守恒」，下一篇我们会看到它如何大放异彩。

顺带一提，这一节的所有内容几乎不需要高维技巧，但它的每一行都将在全专题被反复调用——SDE 的强解、Girsanov 的密度、鞅表示的唯一性，最终都退回到这三兄弟的某一帧。把这一节的直觉养扎实，后面的路会顺很多。

（尾声：三大基石立好后，下一站是 Itô 积分——请带着「$(dB)^2 = dt$」与「停时 = 因果时钟」这两条直觉出发。）

## 8 小结

- **布朗运动**的轨道连续但处处不可导，二次变差 $\langle B, B\rangle_t = t$——它是连续时间随机分析的测试轨道。
- **鞅**是「条件期望不变」的过程：$E[X_t \mid \mathcal{F}_s] = X_s$；布朗运动与平方鞅 $B(t)^2 - t$ 都是鞅。
- **停时**是只依赖历史信息的随机时刻：$\{T \le t\} \in \mathcal{F}_t$；「最后一次」类时刻不是停时。
- **可选停时定理**：有界停时下 $E[X_T] = E[X_0]$，公平游戏无利可图；无界停时用 $T \wedge n$ 局部化。
- **局部化**手法将贯穿全专题：Itô 积分、局部鞅、鞅表示定理都在用同一个「先截断再取极限」的动作。

在下一节，我们将回答那个真正困难的问题：$f$ 是一个适应过程时，$\int_0^t f(s)\,dB(s)$ 到底是什么意思？这就是 **Itô 随机积分**。
