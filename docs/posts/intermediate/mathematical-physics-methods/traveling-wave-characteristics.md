## 为什么从行波法与特征线法开始

达朗贝尔公式已经透露：波动方程的解沿 $x \pm at = \text{const}$ 的直线携带信息。这条「信息高速公路」就是**特征线（characteristic curve）**。把「沿特征线方向找解」提升为一般方法，就是**特征线法（method of characteristics）**：它不展开级数、不做变换，而是**顺着信息传播的方向追踪解的变化**。对一阶方程它近乎万能，对非线性方程它能揭示「激波」的形成——这是最直观、也最接近物理的方法。<span class="marginnote">特征线法的雏形是黎曼研究气体动力学时建立的，它的最大战果是理解「激波」：当非线性使特征线互相追赶甚至交叉，解会在一瞬间失去光滑性，形成间断。声屏障、超音速机翼、交通流堵塞，全是同一套数学。</span>

## 1 一阶线性方程：解沿特征线为常数

最简单的传输方程 $u_t + au_x = 0$：物理上表示「波形以速度 $a$ 平移」。设特征线满足 $\frac{dx}{dt} = a$，则沿特征线 $x = x_0 + at$ 有

$$\frac{d}{dt}u(x(t), t) = u_t + u_x\frac{dx}{dt} = u_t + a u_x = 0$$

**沿特征线，$u$ 恒等于初始值**：$u(x,t) = u(x_0, 0) = \varphi(x_0) = \varphi(x - at)$。

**特征线法三步：① 解 $\frac{dx}{dt} = a$ 求特征线；② 沿特征线把 PDE 化成 ODE（$\frac{du}{dt} = 0$）；③ 用初始条件给每个特征线「标值」。**<span class="marginnote">这就是「行波法」的精确化：$F(x-at)$ 的每个点都坐在一条特征线 $x-at = \text{const}$ 上，波形的整体移动 = 每条特征线各自搬运自己的初值。达朗贝尔解的两个行波，就是两族特征线（$x-at$ 与 $x+at$）上的信息传递。</span>

**辨析｜易错点：** 传输方程里「$u$ 沿特征线为常数」依赖方程是**齐次**的。若方程带源项 $u_t + au_x = f$，则沿特征线 $u$ 会按 $\frac{du}{dt} = f$ 增长——特征线法依然有效，只是 ODE 变成非齐次的。**先看右端是否为 0，再决定「常数」还是「积分」。**

## 2 一般一阶拟线性方程

更一般的一阶方程 $a(x,t,u)u_x + b(x,t,u)u_t = c(x,t,u)$ 的特征线是常微分方程组：

$$\frac{dx}{ds} = a, \qquad \frac{dt}{ds} = b, \qquad \frac{du}{ds} = c$$

沿特征线（参数化为 $s$），PDE 变成三个 ODE 联立。<span class="marginnote">特征线法本质是「把偏导数沿某个方向变成全导数」：方向 $(a,b)$ 上，$\frac{du}{ds} = u_x\frac{dx}{ds} + u_t\frac{dt}{ds} = au_x + bu_t = c$。选择方向让 PDE 左边恰好等于全导数，方程就「降维」成 ODE——这是特征线法能用于非线性方程的原因。</span>

若系数 $a, b$ 只依赖 $x, t$ 不依赖 $u$（半线性），特征线预先可画，$u$ 沿每条线按 $\frac{du}{ds} = c$ 积分。若 $a, b$ 依赖 $u$（真正拟线性），特征线本身依赖 $u$——**问题变成「自洽」的：特征线告诉 $u$ 怎么走，$u$ 反过来决定特征线怎么弯。**

## 3 特征线交叉：激波的形成

**重点：特征线一旦交叉，单值解就不存在，解必须允许间断——这就是激波。** 交通流方程 $u_t + (1-2u)u_x = 0$（$u$ 是车辆密度）中，波速 $1-2u$ 随密度变化：密集区域的波跑得慢，后方车辆追上前方，特征线在有限时间交叉。

特征线交叉的时间叫**激波形成时间** $t_b$：设初值 $u_0(x)$，则

$$t_b = \frac{1}{\max\left[-\left(1-2u_0\right)'\right]}$$

在 $t_b$ 之后，特征线法给出的多值解必须用**激波条件**修补——在激波位置 $s(t)$ 处，跨过激波的 $u$ 值按**兰金-雨贡纽条件（Rankine–Hugoniot condition）** 连接：

$$s'(t) = \frac{[f(u)]}{[u]} = \frac{f(u_R) - f(u_L)}{u_R - u_L}$$

其中 $f$ 是通量函数，$[u] = u_R - u_L$ 是跨激波的跳变。<span class="marginnote">雨贡纽条件说的是「激波速度 = 通量跳变除以密度跳变」——它来自守恒律（质量/车辆数守恒），不是人为规定。这也解释了为什么激波是「守恒系统的必然」，交通流、浅水波、超音速气流里，激波无处不在。</span>

**辨析｜易错点：** 特征线交叉后，若只取多值解的一个分支，会违背物理守恒。必须先判定激波形成时间，再用雨贡纽条件求激波轨迹 $s(t)$——**「何时交叉、何处间断」两个问题，是拟线性方程与线性方程的分水岭**。线性方程特征线永不交叉，永远光滑。

## 4 公式解析：传输方程的特征线法全流程

把最基础的一阶问题完整走一遍，建立肌肉记忆：

$$
u_t + a u_x = 0, \qquad u(x,0) = \varphi(x)
$$

- **第一步，求特征线**：$\frac{dx}{dt} = a$ 得 $x = x_0 + at$，即特征线族 $x - at = x_0$——一族平行的直线，斜率 $\frac{dt}{dx} = \frac1a$。
- **第二步，沿特征线降维**：$\frac{du}{dt} = u_t + u_x\frac{dx}{dt} = 0$，所以 $u$ 在每条特征线上为常数 $u = \varphi(x_0)$。
- **第三步，代回坐标**：$x_0 = x - at$，故 $u(x,t) = \varphi(x-at)$——**解就是初值的平移**。

**三步里唯一需要「想」的是第一步：选方向 $(1, a)$，让 $u_t + au_x$ 恰好等于 $\frac{du}{dt}$。** 方向选对了，其余是纯机械操作。这个模式在二维、非线性、带源的情形下原样保留，只是特征线从直线变成曲线。

## 5 特征线法与其它方法的联系

特征线法不是孤立技巧，它和前面所有方法暗通款曲：

- **达朗贝尔公式** = 两族特征线（$x-at$ 与 $x+at$）上的信息传递。
- **格林函数法** = 特征线上源项的积分（§1 的带源版本）。
- **傅里叶变换法** = 在频域里，每条特征线变成一根独立的 ODE 模态。
- **分离变量法** = 有界区域里特征线被边界「弹回」，反射形成驻波。<span class="marginnote">四者的统一视角：<strong>都是把 PDE 沿「某个方向」解耦</strong>——特征线法沿实空间曲线、变换法沿频域基、分离变量沿本征函数、格林函数沿点源。方法虽多，「解耦」是它们共通的灵魂。</span>

## 7 延伸：交通流与浅水波——特征线的现实舞台

特征线法最直观的物理舞台之一就是**交通流（Lighthill–Whitham–Richards 模型）**。设车辆密度 $\rho(x,t)$、流量 $q = \rho v(\rho)$，守恒律为

$$\rho_t + q(\rho)_x = 0$$

当 $v = v_{\max}(1 - \rho/\rho_{\max})$（线性减速假设）时，$q = v_{\max}\rho(1-\rho/\rho_{\max})$，特征速度为 $q'(\rho) = v_{\max}(1 - 2\rho/\rho_{\max})$——**车越密，波传得越慢**。前方拥堵（高密度）时后方车辆追上来，特征线交叉，就形成**交通激波**：排队尾端突然出现、以某个速度向上游后退。

**雨贡纽条件在交通流里的含义：** 激波速度 $s' = \frac{q(\rho_R) - q(\rho_L)}{\rho_R - \rho_L}$ 正是「排队尾端后退的速度」。堵车从哪开始、以多快扩展，这个公式都能回答——这是城市交通模拟的数学内核。<span class="marginnote">同样的方程还描述浅水波（圣维南方程的一维简化）、粉尘沉降、公路上的「幽灵堵车」。一套特征线理论，从河床的洪水波到高速路的车流，用的是同一支笔。这就是数学物理方法「一套方法管一片物理」的写照。</span>

**重点：守恒律是特征线法背后的大宪章。** 任何「某种量不凭空产生」的物理过程，写成 $\rho_t + q(\rho)_x = 0$ 的形式，都自然长出特征线与激波——质量守恒给冲击波、电荷守恒给电磁激波、车数守恒给交通拥堵。**先写守恒律，再画特征线，最后补激波。**

**辨析｜易错点：** 交通流模型的激波速度不依赖「密度差的方向」——$\rho_L$ 与 $\rho_R$ 谁在左谁在右都要对应雨贡纽公式的约定，符号错误会算出「激波反向跑」。**激波速度是跳变比的斜率，不是平均速度。**

## 9 延伸练习与自查

**练习一（传输方程）：** $u_t + 3u_x = 0$，$u(x,0) = \sin x$。特征线 $x - 3t = x_0$，解 $u = \sin(x - 3t)$——波形以速度 $3$ 右移。

**练习二（带源项）：** $u_t + au_x = u$，初值 $\varphi(x)$。沿特征线 $\frac{du}{dt} = u$，解得 $u = \varphi(x-at)e^t$——**右端非零时，$u$ 沿特征线按指数增长**。

**练习三（特征线交叉）：** 交通流 $u_t + (1-2u)u_x = 0$，初值 $u_0(x) = x$。特征速度为 $1-2x$，前方慢后方快，特征线在有限时间交叉——激波形成。

| 方程 | 特征线 | 沿特征线行为 |
| --- | --- | --- |
| $u_t + au_x = 0$ | $x-at = c$ | $u$ 常数 |
| $u_t + au_x = bu$ | 同上 | $u$ 指数变化 |
| $u_t + (1-2u)u_x = 0$ | 依赖 $u$ | 可交叉成激波 |

<span class="marginnote">三行对照道破特征线法的分层：齐次→常数、半线性→指数、拟线性→交叉。做题先问「系数是否依赖 $u$」，再决定要不要考虑激波。</span>

## 10 小结

- **特征线** $dx/dt = a$ 是信息传播的路径；齐次传输方程沿特征线 $u$ 为常数，解 $= \varphi(x-at)$。
- 一般一阶方程：特征线 ODE 组 $\frac{dx}{ds}=a$、$\frac{dt}{ds}=b$、$\frac{du}{ds}=c$。
- **特征线交叉 ⇒ 多值 ⇒ 激波**：$t_b$ 之后需用**兰金-雨贡纽条件** $s' = [f(u)]/[u]$ 修补间断。
- 线性方程特征线永不交叉、解恒光滑；拟线性方程才有激波。
- 特征线法 = 达朗贝尔公式、格林函数、变换法、分离变量的共同底层视角：**解耦**。

在下一节，我们走向第三篇的收官方法——**变分法与瑞利-里兹法**：不直接解方程，而是把方程改写成「求某个量的极小值」。
