## 为什么从卷积与 Parseval 定理开始

变换的威力不只在于「把函数变个样」，更在于它重新组织了运算：**微分变成乘法、卷积变成乘法**。上一节我们反复预告「卷积变乘法」，这一节兑现。卷积是线性系统理论的灵魂——任何线性时不变系统的输出都是输入与冲激响应的卷积，从弹簧阻尼器到神经网络里的卷积层，全是这一个运算。而 Parseval 定理则是「时域能量 = 频域能量」的精确陈述，它在滤波器设计、谱估计里无处不在。<span class="marginnote">卷积在数学里是对 $f(t-\tau)g(\tau)$ 的「滑动加权求和」：把 $g$ 反转、平移，再与 $f$ 逐点相乘累加。工程里它描述「系统对过去输入的累积记忆」——越早的输入，权重越小（如果 $g$ 衰减）。</span>

## 1 卷积的定义

**卷积（convolution）：** 两个函数 $f, g$ 的卷积定义为

$$(f * g)(t) = \int_{-\infty}^{\infty} f(\tau)g(t-\tau)\,d\tau$$

对单边信号（$t\ge0$）常写成 $\int_0^t f(\tau)g(t-\tau)d\tau$。卷积满足三条代数律：交换律 $f*g = g*f$、结合律 $(f*g)*h = f*(g*h)$、分配律 $f*(g+h) = f*g + f*h$——它是一个真正的「乘法」，与普通乘法平行。

**物理意义：冲激响应与线性时不变系统。** 若系统对冲激 $\delta(t)$ 的响应为 $h(t)$（称为**冲激响应（impulse response）**），则对任意输入 $x(t)$，输出为

$$y(t) = (x * h)(t)$$

输入 $x$ 被拆成无穷多个冲激的叠加，每个冲激产生响应 $h(t-\tau)$，系统把这些响应**线性叠加**——这就是卷积。<span class="marginnote">「线性 + 时不变」（LTI）是卷积成立的充分条件：线性保证叠加、时不变保证冲激响应不随时间漂移。一旦系统有非线性或时变，卷积公式当场失效——这是卷积理论适用边界的分界线。</span>

## 2 卷积定理：变换把卷积变成乘法

**卷积定理（convolution theorem）** 是变换理论最值钱的一条：

$$\mathcal{F}[f * g] = \mathcal{F}[f] \cdot \mathcal{F}[g], \qquad \mathcal{L}[f * g] = \mathcal{F}(s)\cdot G(s)$$

傅里叶与拉普拉斯都成立：**时域卷积 $\Leftrightarrow$ 频域乘法**。反方向同样成立：

$$\mathcal{F}[f \cdot g] = \frac{1}{2\pi}\mathcal{F}[f] * \mathcal{F}[g]$$

**重点：时域卷积 = 频域乘法。** 这条双向通道让两类问题互相转化——滤波（频域乘一个窗）等价于时域卷积（与窗的逆变换卷积）；卷积积分方程则变为代数方程直接解。<span class="marginnote">证明只需交换积分次序：$\int\left(\int f(\tau)g(t-\tau)d\tau\right)e^{-i\omega t}dt = \int f(\tau)e^{-i\omega\tau}\left(\int g(u)e^{-i\omega u}du\right)d\tau$，内层就是 $G(\omega)$，外层就是 $F(\omega)$。变换把「滑动求和」分解成「逐频相乘」。</span>

## 3 卷积如何解积分方程

形如 $y(t) = f(t) + \int_0^t k(t-\tau)y(\tau)d\tau$ 的**沃尔泰拉积分方程（Volterra equation）**，右端积分正是卷积 $k * y$。两边取拉普拉斯变换：

$$Y(s) = F(s) + K(s)Y(s) \;\Rightarrow\; Y(s) = \frac{F(s)}{1 - K(s)}$$

解出 $Y(s)$ 后逆变换即得 $y(t)$。**卷积方程在频域里是一行代数式**——这正是「卷积变乘法」的实战威力。

**辨析｜易错点：** 变换解卷积方程时，注意卷积下界。若方程积分从 $0$ 到 $t$（因果情形），单边拉普拉斯变换的卷积公式直接适用；若积分区间是 $(-\infty, t)$，需要先截断或改用傅里叶型工具。**先看积分区间，再选变换。**

## 4 公式解析：$e^{-at}$ 与 $t$ 的卷积

手算一个具体卷积，把「反转、平移、分段、积分」四个动作走一遍：

$$
(e^{-at} * t)(t) = \int_0^t e^{-a\tau}(t-\tau)\,d\tau = \frac{t}{a} - \frac{1 - e^{-at}}{a^2}, \qquad t \ge 0
$$

三步拆解：

- **第一步，写积分并拆项**：$\int_0^t e^{-a\tau}(t-\tau)d\tau = t\int_0^t e^{-a\tau}d\tau - \int_0^t \tau e^{-a\tau}d\tau$。
- **第二步，算两个基本积分**：$\int_0^t e^{-a\tau}d\tau = \frac{1-e^{-at}}{a}$；$\int_0^t \tau e^{-a\tau}d\tau = \left[-\frac{\tau}{a}e^{-a\tau}\right]_0^t + \frac{1}{a}\int_0^t e^{-a\tau}d\tau = -\frac{t}{a}e^{-at} + \frac{1-e^{-at}}{a^2}$。
- **第三步，合并**：$t\cdot\frac{1-e^{-at}}{a} - \left(-\frac{t}{a}e^{-at} + \frac{1-e^{-at}}{a^2}\right) = \frac{t}{a} - \frac{1-e^{-at}}{a^2}$，$\frac{t}{a}e^{-at}$ 两项正好相消。

**验证用卷积定理**：$\mathcal{L}[e^{-at}] = \frac{1}{s+a}$，$\mathcal{L}[t] = \frac{1}{s^2}$，乘积 $\frac{1}{s^2(s+a)}$ 的部分分式 $\frac{1}{a^2}\left(\frac{1}{s^2} - \frac{1/a}{s} + \frac{1/a}{s+a}\right)$……逆变换给出同一个结果。**两条路（直接积分 / 变换）互验，是防算错的最佳保险。**

## 5 Parseval 定理：能量的守恒

**Parseval 定理（Parseval's theorem）** 是卷积定理的推论，也是最常用的能量关系：

$$\int_{-\infty}^{\infty} |f(t)|^2\,dt = \frac{1}{2\pi}\int_{-\infty}^{\infty}|\hat f(\omega)|^2\,d\omega$$

拉普拉斯版本（对单边信号）形如 $\int_0^\infty |f(t)|^2dt = \frac{1}{2\pi i}\int_{\sigma_0-i\infty}^{\sigma_0+i\infty}F(s)\overline{F(2\sigma_0 - \bar s)}\,ds$——不常用，实际更多用傅里叶版。<span class="marginnote">物理解读：$|f(t)|^2$ 是瞬时功率，$|\hat f(\omega)|^2$ 是功率谱密度（单位频率的功率）。Parseval 定理说「总功率 = 各频率功率之和」，这是频谱仪、声呐、雷达测距全部依赖的原理——测总能量不如测频谱直观，但频谱能告诉我们能量藏在哪些频率。</span>

**应用：计算难题**。用 Parseval 定理可以免积分地算出很多定积分。例如求 $\int_{-\infty}^\infty \operatorname{sinc}^2(ax)dx$：矩形脉冲的变换是 $2a\,\operatorname{sinc}(a\omega)$，反过来 $\operatorname{sinc}$ 的变换是矩形，能量守恒立刻给出结果——**把积分域从时域换到频域，难题变易题**。

## 7 延伸：卷积的数值实现与线性卷积的边界

卷积在离散世界里的实现，是把「反转、平移、求和」变成两个序列的内积滑窗：

$$(f * g)[n] = \sum_{k} f[k]\,g[n-k]$$

这个求和就是神经网络卷积层、FIR 滤波器、图像模糊的全部基础。而「卷积定理」在数值上有极高效的引擎——**FFT（快速傅里叶变换）**：时域卷积 $\approx$ FFT → 逐点相乘 → IFFT，复杂度从 $O(N^2)$ 降到 $O(N\log N)$。<span class="marginnote">「时域卷积 = 频域乘法」不只是数学恒等式，它是 FFT 卷积加速的依据：一段 10 万点的信号，直接卷积要 $10^{10}$ 次运算，FFT 路线只要约百万次。工程里凡是「大核卷积」，几乎都走 FFT。</span>

**辨析｜易错点：** FFT 卷积有个隐蔽陷阱——**循环卷积（circular convolution）**。FFT 隐含周期性，直接把两个序列的 FFT 相乘再逆变换，得到的是「首尾相接」的循环卷积，不是线性卷积。**解决办法是把序列补零到长度 $\ge N_1 + N_2 - 1$**，再做 FFT——补零是线性卷积的「隔离带」，防止头尾污染。初学 FFT 卷积时不补零，结果总差一块，就是这个原因。

**重点：线性卷积 vs 循环卷积的区分，是数字信号处理的第一个深坑。** 补零的「长度法则」$L \ge N_1 + N_2 - 1$ 必须记牢；它来自「线性卷积的长度 = 两个序列长度之和减一」这一基本事实。

**延伸：卷积还是「系统响应的叠加」**——两个系统的串联，总冲激响应是各自冲激响应的卷积：$h_{total} = h_1 * h_2$。这解释了为什么「级联滤波器等价于一个复合滤波器」：频域里就是频谱相乘，逐级压制。

## 9 延伸练习与自查

**练习一（卷积计算）：** $f = t$、$g = e^{-t}$（$t\ge0$），$f*g = \int_0^t \tau e^{-(t-\tau)}d\tau = t - 1 + e^{-t}$。

**练习二（卷积定理验证）：** $\mathcal{L}[t * e^{-t}] = \mathcal{L}[t]\cdot\mathcal{L}[e^{-t}] = \frac1{s^2}\cdot\frac1{s+1}$，部分分式逆变换应得 $t - 1 + e^{-t}$——与练习一对齐，两条路互验。

**练习三（系统响应）：** LTI 系统的冲激响应 $h(t) = e^{-2t}u(t)$，输入 $x(t) = u(t)$（阶跃），输出 $y = x*h = \int_0^t e^{-2\tau}d\tau = \frac12(1 - e^{-2t})$——阶跃响应是「一阶系统渐近逼近稳态」。

| 概念 | 公式 | 用途 |
| --- | --- | --- |
| 卷积 | $f*g = \int f(\tau)g(t-\tau)d\tau$ | LTI 输出 |
| 卷积定理 | $\mathcal{F}[f*g] = \hat f\hat g$ | 频域相乘 |
| 帕塞瓦尔 | $\int|f|^2 = \frac1{2\pi}\int|\hat f|^2$ | 能量守恒 |

<span class="marginnote">练习三的「阶跃响应 $=\frac12(1-e^{-2t})$」是控制里的标准结果：一阶系统的响应总是指数逼近稳态，时间常数 $1/2$。记住这个形状，理解任何一阶滤波器的行为。</span>

## 10 小结

- **卷积** $(f*g)(t) = \int f(\tau)g(t-\tau)d\tau$ 满足交换、结合、分配律；LTI 系统的输出是输入与冲激响应的卷积。
- **卷积定理**：时域卷积 = 频域乘法（傅里叶与拉普拉斯均成立），反方向是频域卷积 = 时域乘法的 $1/2\pi$ 倍。
- 卷积积分方程 $y = f + k*y$ 经变换化为 $Y = \frac{F}{1-K}$，一行代数式解出。
- 手算卷积三步走：反转、平移、分段积分；用变换互验防错。
- **Parseval 定理**：时域能量 = 频域能量，$|\hat f|^2$ 是功率谱密度，可把积分难题换成频域计算。

在下一节，我们把积分变换兵团集结起来，进攻第三篇的城池：**用傅里叶/拉普拉斯变换求解偏微分方程**，正式把三种典型方程收入囊中。
