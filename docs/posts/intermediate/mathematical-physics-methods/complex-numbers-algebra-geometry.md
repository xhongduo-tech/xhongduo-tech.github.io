## 为什么从复数的代数与几何表示开始

物理里到处是需要两个实数才能描述的量：波的相位与振幅、量子态的实部与虚部、交流电路里的电压与电流。把它们打包成一个对象，就是**复数（complex number）**。莱布尼茨曾说 $\sqrt{-1}$ 是「存在与不存在之间的两栖物」，但一旦我们承认 $i^2 = -1$ 是一句合法的宣言，整个数学就多出了一个优雅的维度——我们之后要学的柯西积分定理、留数定理、傅里叶变换，全部站在这个地基上。<span class="marginnote">复数是第二级《复变函数与积分变换》与《数学物理方法》共同的第一课。高中《复数》一节只讲了它的代数外壳，这里我们把代数形式与几何图像合并成一套工具。</span>

## 1 代数形式：把 $i$ 请进来

**虚数单位（imaginary unit）$i$**：满足 $i^2 = -1$ 的符号，我们把它当作一个数来运算。<span class="marginnote">$i^2=-1$ 不是一个可以「算出」的结果，而是一条新规则。引入它之后，负数开平方就总能进行了——这是「数不够用就造新数」叙事的又一次上演，上一轮是分数、负数、无理数。</span>

**复数（complex number）**：形如 $z = a + bi$ 的数，其中 $a, b$ 为实数，$a$ 称为**实部（real part）**，$b$ 称为**虚部（imaginary part）**，分别记作 $\operatorname{Re} z = a$、$\operatorname{Im} z = b$。全体复数记作 $\mathbb{C}$。

两个复数相等的条件是实部与虚部分别相等：

$$z_1 = z_2 \iff \operatorname{Re} z_1 = \operatorname{Re} z_2 \quad \text{且} \quad \operatorname{Im} z_1 = \operatorname{Im} z_2$$

四则运算照搬多项式的规则，只多用一条 $i^2 = -1$：

$$(a+bi) \pm (c+di) = (a\pm c) + (b\pm d)i$$

$$(a+bi)(c+di) = (ac - bd) + (ad + bc)i$$

**共轭复数（conjugate）**：$\bar{z} = a - bi$。它有两个立刻能用的性质：

$$z\bar{z} = a^2 + b^2 \in \mathbb{R}, \qquad \frac{1}{z} = \frac{\bar{z}}{z\bar{z}} = \frac{a - bi}{a^2 + b^2}$$

后一式给出了复数的除法法则：分子分母同乘分母的共轭，把虚数从分母里「请出去」。<span class="marginnote">这一步对应实数除法里「有理化分母」的复数版本，工程里叫「实数化」。记忆点：$z$ 与 $\bar{z}$ 的乘积永远是<strong>非负实数</strong> $a^2+b^2$，这是全部除法操作的心脏。</span>

## 2 几何表示：复平面

高斯把复数 $z = a+bi$ 画成平面上坐标为 $(a, b)$ 的点，这个平面称为**复平面（complex plane）**，横轴为实轴、纵轴为虚轴。于是复数与平面点一一对应，加法对应向量平移，乘法则要到三角形式才看得清。

**辨析｜易错点：** 把复数当成「一个数」还是「一个点」，取决于上下文。**加法、减法是坐标运算，乘法、除法是旋转与缩放**——这两套几何直觉不能混淆。初学最大的错误，是用坐标去理解乘法。

由点 $(a,b)$ 到原点的距离，定义**模（modulus）**：

$$|z| = r = \sqrt{a^2 + b^2} = \sqrt{z\bar{z}}$$

实轴正方向到向量 $\overrightarrow{Oz}$ 的有向夹角（取主值 $-\pi < \theta \le \pi$）称为**辐角（argument）**，记作 $\theta = \arg z$。于是复数有了第三种写法：

$$z = a + bi = r(\cos\theta + i\sin\theta)$$

这就是**三角形式**。$r$ 与 $\theta$ 称为复数的一对**极坐标（polar coordinates）**，它们与代数形式 $a, b$ 的换算公式要像九九乘法表一样熟：

$$a = r\cos\theta, \qquad b = r\sin\theta, \qquad \tan\theta = \frac{b}{a}$$

## 3 欧拉公式与指数形式

欧拉公式把三角形式浓缩成一个指数：

$$e^{i\theta} = \cos\theta + i\sin\theta$$

由此复数可写成**指数形式** $z = re^{i\theta}$。<span class="marginnote">这个公式被称作「数学里最优美的公式」，$\theta = \pi$ 时得到 $e^{i\pi} + 1 = 0$——把 $e, i, \pi, 1, 0$ 五个常数装进一行。严格证明见梁昆淼第 1 章与第二级《复变函数与积分变换》。</span>

指数形式让乘法、除法、幂立刻变得透明：

$$(r_1 e^{i\theta_1})(r_2 e^{i\theta_2}) = r_1 r_2 e^{i(\theta_1 + \theta_2)}$$

**复数相乘：模相乘、辐角相加；复数相除：模相除、辐角相减。** 这正是「乘法是旋转」的严格表述——乘 $i$（即 $e^{i\pi/2}$）就是把向量逆时针旋转 $90^\circ$。

反复应用乘法，得到**棣莫弗公式（de Moivre's formula）**：

$$(r e^{i\theta})^n = r^n e^{in\theta}$$

开方则推出 $n$ 次方根的公式——**一个非零复数恰有 $n$ 个 $n$ 次方根**，它们均匀分布在以原点为圆心、$\sqrt[n]{r}$ 为半径的圆上：

$$z_k = \sqrt[n]{r}\, e^{i(\theta + 2k\pi)/n}, \qquad k = 0, 1, \dots, n-1$$

## 4 公式解析：$n$ 次单位根为何均匀分布

单位根是 $z^n = 1$ 的全部根。把方程两边同取模，得 $|z|^n = 1$，故 $|z| = 1$；再由辐角方程 $n\theta = 2k\pi$（$k$ 为整数），得：

$$
z_k = e^{2\pi i k/n}, \qquad k = 0, 1, \dots, n-1
$$

三步拆解这条公式：

- **第一步，取模定半径**：$|z|^n = |1| = 1$ 推出 $|z| = 1$，所以所有根都落在单位圆上，半径没有自由度。
- **第二步，辐角加法定相位**：$z^n$ 的辐角是 $n\theta$，要等于 $0$（模 $2\pi$），故 $\theta = 2k\pi/n$，相位是等间距的。
- **第三步，$k$ 只取 $n$ 个值**：$k$ 从 $0$ 到 $n-1$ 得到 $n$ 个不同根；$k$ 再往大走就重复了，因为 $e^{2\pi i} = 1$。

于是单位根构成圆内接正 $n$ 边形的顶点——**一个纯代数方程的解，在复平面上竟是正多边形**。$n=2$ 时是 $1$ 与 $-1$，$n=3$ 时是等边三角形的三个顶点。这种「代数对象长出几何结构」的图景，正是复分析后续所有美妙结果的预演。

## 5 复变函数的预告

把复数提升为自变量，就得到**复变函数（complex function）**$w = f(z)$，其中 $z, w \in \mathbb{C}$。一个复变函数相当于两个二元实函数打包：

$$f(z) = u(x,y) + i\, v(x,y)$$

所以复变函数的图像画在四维空间里，无法直接可视——这迫使数学家发明了「映射」的眼光：把 $z$ 平面上的图形，看它在 $w$ 平面上变成什么样子。<span class="marginnote">这种「从一个平面映射到另一个平面」的视角，是理解解析函数、保角映射、以及后面留数理论的关键。工程上，处理平面场的流动问题正是靠这种映射来简化几何。</span>

## 7 延伸：复数的极坐标与电学、量子物理

复数的极坐标表示在物理里有两处经典应用，恰好对应「模辐角」的两层含义：

**交流电路：** 正弦电压 $V\cos(\omega t + \phi)$ 写成复相量 $V e^{i\phi}$，电路的阻抗、电抗运算全部变成复数的乘除——电阻 $R$ 是实数、电感阻抗 $i\omega L$、电容阻抗 $\frac{1}{i\omega C}$ 都带 $i$。**复阻抗的模是「幅值比」，辐角是「相位差」**——$|Z|$ 与 $\arg Z$ 各管一件事，这正是「模乘辐角加」的用武之地。<span class="marginnote">相量法让电路分析从「解微分方程」降为「复数代数」：RLC 串联阻抗 $Z = R + i(\omega L - 1/\omega C)$ 的辐角告诉你电流滞后还是超前电压。工程上「欧姆定律的复数版」$V = IZ$ 是交流分析的日常工具。</span>

**量子力学：** 波函数 $\psi(x,t) = Ae^{i(kx - \omega t)}$ 是复数——$|\psi|^2 = |A|^2$ 是概率密度，而相位 $kx - \omega t$ 承载干涉与衍射的全部信息。**概率只关心模，干涉只关心相位**——复数的双层结构在这里天然地各司其职。

**重点：复数 = 两个自由度的打包。** 无论是电路的幅值/相位，还是量子的概率/相位，还是波的振幅/相位，都是「两个实数装进一个复数」的实例。**学会用「一个复数装两件事」的眼光看世界，是复分析的第一课。**

**辨析｜易错点：** 复数的辐角主值区间取 $(-\pi, \pi]$ 时，乘除运算的辐角要先算再归位——$(-\pi/2)\times(-\pi/2)$ 类型的辐角加出来可能「越界」，要模 $2\pi$ 归一。**做完辐角加减，记得归到主值区间。**

## 8 小结

- **复数** $z = a+bi$ 有三个等价的表示：代数形式、三角形式 $z = r(\cos\theta+i\sin\theta)$、指数形式 $z = re^{i\theta}$。
- 加减小心实部虚部，**乘除在指数形式下是模相乘除、辐角相加减**。
- 共轭 $\bar{z}$ 的作用是让 $z\bar{z}$ 变实数，除法靠它把分母实数化。
- **欧拉公式** $e^{i\theta} = \cos\theta + i\sin\theta$ 是连接三角与指数的桥梁，也是全部积分变换的支点。
- $n$ 次方根均匀分布在圆周上——**代数方程的解具有几何对称性**。

在下一节，我们问：什么样的复变函数才配叫「解析函数」？答案是柯西-黎曼方程，它将把「可导」从实数世界升格到复数世界。
