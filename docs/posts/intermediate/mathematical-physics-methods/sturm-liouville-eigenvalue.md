## 为什么从本征值问题（斯特姆-刘维尔）开始

分离变量法反复撞见同一类问题：某个常微分方程配齐次边界条件，只有离散的 $\lambda_n$ 有非零解，本征函数还互相「正交」。这节课把这类问题单独提出来，做成一门统一理论——**斯特姆-刘维尔理论（Sturm–Liouville theory）**。它的意义在于：三角函数、勒让德多项式、贝塞尔函数，看起来是三个不同的函数族，其实全是同一个斯特姆-刘维尔问题的不同特例。抓住统一理论，就抓住了一整片特殊函数的森林。<span class="marginnote">斯特姆与刘维尔在 1830 年代研究热传导问题时建立了这套理论。今天它被认为是「线性微分算子谱理论」的古典源头，也是量子力学「本征函数展开」的数学骨架。</span>

## 1 斯特姆-刘维尔问题的一般形式

**斯特姆-刘维尔方程（Sturm–Liouville equation）：**

$$\frac{d}{dx}\left[p(x)y'\right] - q(x)y + \lambda\,\rho(x)\,y = 0, \qquad a < x < b$$

其中 $p, q, \rho$ 是给定的实函数，$\rho(x) > 0$ 称为**权函数（weight function）**，$\lambda$ 是待定参数（本征值）。配以适当的边界条件（如 $y(a)=y(b)=0$，或周期边界），就构成**斯特姆-刘维尔问题**。<span class="marginnote">「$\frac{d}{dx}[p y']$」这个自伴形式（self-adjoint form）是整套理论的心脏。自伴性保证了下面所有好性质；而勒让德方程、贝塞尔方程都能改写成这种形式——改写的过程叫「积分因子法」，把二阶线性 ODE 乘一个因子凑成 $[py']'$ 的样子。</span>

**三大经典方程都是它的特例：**

- 弦振动：$y'' + \lambda y = 0$，即 $p=1, q=0, \rho=1$ → 三角函数。
- 勒让德：$(1-x^2)y'' - 2xy' + n(n+1)y = 0$ → 改写为 $\left[(1-x^2)y'\right]' + \lambda y = 0$ → 勒让德多项式。
- 贝塞尔：$x^2y'' + xy' + (x^2 - \nu^2)y = 0$ → 改写后权函数为 $x$ → 贝塞尔函数。

**「所有特殊函数都是同一个统一理论的实例」——这是斯特姆-刘维尔理论的第一个大礼物。**<span class="marginnote">贝塞尔方程的改写：除以 $x$ 得 $xy'' + y' + (x-\nu^2/x)y = 0$，即 $[x y']' - \frac{\nu^2}{x}y + x\cdot y = 0$——权函数 $\rho = x$、$q = \nu^2/x$。三种方程的结构完全对齐，只差 $p, q, \rho$ 的具体形式。</span>

## 2 三大性质：实本征值、正交、完备

在适当的边界条件（正则型）下，斯特姆-刘维尔问题有三个统一性质：

**性质一：本征值为实数。** 且对应同一本征值只有一个线性无关的本征函数（对正则问题）。<span class="marginnote">「本征值必为实数」来自自伴性：若 $y$ 是本征函数，$\lambda = \frac{\int(p y'^2 + qy^2)dx}{\int\rho y^2dx}$ 是实数的商。量子力学里「可观测量的本征值必须是实数」正是这条性质的化身——海森堡矩阵力学的数学基础。</span>

**性质二：正交性（带权）。** 不同本征值 $\lambda_m \ne \lambda_n$ 对应的本征函数 $y_m, y_n$ 在区间 $[a,b]$ 上以 $\rho$ 为权正交：

$$\int_a^b y_m(x)\,y_n(x)\,\rho(x)\,dx = 0, \qquad m \ne n$$

**性质三：完备性。** 任何「足够好」的函数 $f$ 都可以按本征函数族展开（广义傅里叶级数）：

$$f(x) = \sum_{n=1}^{\infty} c_n y_n(x), \qquad c_n = \frac{\int_a^b f(x)y_n(x)\rho(x)dx}{\int_a^b y_n^2(x)\rho(x)dx}$$

**系数公式的分母就是「范数平方」**——当 $y_n$ 被归一化时分母为 $1$。这套「正交 + 完备 + 系数公式」的结构，正是我们在傅里叶级数里用过的套路，现在被提升为一般原理。

## 3 公式解析：正交性的证明骨架

正交性是整个展开理论的支柱，它的证明依赖**格林公式（Green's identity）**。对两个本征函数 $y_m, y_n$：

$$
\int_a^b y_m L[y_n] - y_n L[y_m]\,dx = \left[p(y_m y_n' - y_n y_m')\right]_a^b
$$

- **第一步，写差**：$L[y_n] = \lambda_n\rho y_n$、$L[y_m] = \lambda_m\rho y_m$（这里 $L[y] = [p y']' - qy$），于是 $y_m L[y_n] - y_n L[y_m] = (\lambda_n - \lambda_m)\rho\, y_m y_n$。
- **第二步，分部积分**：$y_m[p y_n']' - y_n[p y_m']' = [p(y_m y_n' - y_n y_m')]'$，两边积分得到右端的边界项。
- **第三步，边界项为零**：在正则边界条件（$y(a)=y(b)=0$ 等）下，$p(y_m y_n' - y_n y_m')|_a^b = 0$，于是 $(\lambda_n-\lambda_m)\int\rho y_my_ndx = 0$，因 $\lambda_m\ne\lambda_n$，正交性成立。

**整个证明只有三步，却需要两个前提：自伴形式（让分部积分正好消成边界项）与合适的边界条件（让边界项为零）。** 缺一个，正交性就塌方——这解释了为什么斯特姆-刘维尔理论总把「自伴形式」和「正则边界」绑在一起讲。

## 4 正则边界条件：哪些算「好」边界

斯特姆-刘维尔理论要求边界条件「正则」，常见的正则边界包括：

- **第一类** $y(a) = y(b) = 0$（两端固定）；
- **第二类** $y'(a) = y'(b) = 0$（两端自由）；
- **周期边界** $y(a) = y(b)$、$y'(a) = y'(b)$；
- **第三类** $\alpha_1 y(a) + \alpha_2 y'(a) = 0$。

**辨析｜易错点：** 边界条件不同，本征函数族就不同——同一方程配不同边界，会给出「正弦族」「余弦族」等不同的正交族。分离变量法里「选哪种展开」由物理边界决定，不是随意的。**边界条件一变，正交基就换人。**<span class="marginnote">傅里叶级数有正弦、余弦、全傅里叶三种形式，正是同一斯特姆-刘维尔问题在三种正则边界下的产物。量子力学里「无限深方阱」与「周期边界」给出不同波函数族，也是同一结构的重演。</span>

周期边界还有一个特殊之处：本征值 $\lambda$ 可能有**二重退化**（对应 $\cos$ 与 $\sin$ 两个本征函数），但正交性依然成立——退化情形下需要先把同本征值的函数做正交化。

## 5 从理论到展开：广义傅里叶级数

拿到三大性质，就能做「任何函数展开成本征函数族」这件事。以斯特姆-刘维尔问题 $\{[py']' - qy + \lambda\rho y = 0,\ \text{正则边界}\}$ 的本征函数 $\{y_n\}$ 为基：

$$f(x) = \sum_n c_n y_n(x), \qquad c_n = \frac{\langle f, y_n\rangle_\rho}{\langle y_n, y_n\rangle_\rho}, \quad \langle f,g\rangle_\rho = \int_a^b fg\,\rho\,dx$$

**展开的收敛性与傅里叶级数同款**：逐段光滑函数在连续点收敛到 $f$、间断点收敛到均值。这是「用特殊函数解 PDE」的通行证——分离变量法解完空间方程后，剩下来的初值匹配问题，就是做这样的广义傅里叶展开。<span class="marginnote">勒让德展开的系数分母有现成公式 $\int_{-1}^1 P_n^2 dx = \frac{2}{2n+1}$，贝塞尔展开则涉及「贝塞尔级数」的正交性与零点分布——这些具体化工作正是接下来两节的内容。理论给了统一框架，具体计算落在每个特殊函数身上。</span>

## 7 延伸：本征值的物理意义与最小原理

斯特姆-刘维尔问题的本征值不只是一个抽象参数，它常常对应物理的「量级门槛」：弦的 $\lambda_n = (n\pi/l)^2$ 决定音高，量子阱的 $\lambda_n$ 决定能级。更妙的是，本征值还有一个**变分特征（最小原理）**：

第一个本征值（最小本征值）可以由「瑞利商」的极小给出：

$$\lambda_1 = \min_{y} \frac{\int_a^b (p y'^2 + q y^2)dx}{\int_a^b \rho y^2 dx}, \qquad y \text{ 满足边界条件且非零}$$

**物理含义：基态本征值是「能量泛函与范数之比」的最小值。** 这直接通向瑞利-里兹法（第 30 节）：用试探函数逼近这个商的最小值，就得到基态本征值的上界估计。<span class="marginnote">「基态能量最小」是一切量子体系的变分原理：氢原子基态、原子核基态都能用「最小化能量泛函」的变分法求近似。这也是「变分法」在量子力学里成为首要近似工具的原因——本征值问题天然与极值问题相连。</span>

**重点：本征值单调性（比较定理）**——若权函数 $\rho$ 增大或势 $q$ 增大，本征值整体上升。直观：弦更重（$\rho$ 大）则频率更低，势阱更深（$q$ 大）则能级更高。**「参数变化 → 本征值整体移动」的单调性，是工程调参的理论依据。**

**辨析｜易错点：** 最小原理只对**最小本征值**给出极值刻画；高阶本征值要在「与已得本征函数正交」的约束下求极小。若把高阶本征值也当自由极值求，会退回最低的那个。**先正交化约束，再谈高阶本征值。**

## 9 延伸练习与自查

**练习一（化为 S-L 形式）：** 把 $y'' + 2y' + \lambda y = 0$ 化为斯特姆-刘维尔形式。积分因子 $e^{2x}$，乘后得 $\left[e^{2x}y'\right]' + \lambda e^{2x}y = 0$——$p = e^{2x}$、$\rho = e^{2x}$。

**练习二（权函数识别）：** 贝塞尔方程 $[x y']' - \frac{\nu^2}{x}y + xy = 0$ 的权函数 $\rho = x$、$q = \nu^2/x$——正交性积分 $\int_0^a rJ_nJ_ndr$ 里的那个 $r$ 就是从 $\rho$ 来的。

**练习三（本征函数展开）：** 在 $[0,\pi]$ 上把 $f(x) = x$ 按 $\sin nx$ 展开，系数 $b_n = \frac{2}{\pi}\int_0^\pi x\sin nx\,dx = \frac{2(-1)^{n+1}}{n}$——**同一「广义傅里叶」流程，基从 S-L 问题来**。

| 对象 | 权函数 | 正交性 |
| --- | --- | --- |
| $\sin nx$ | $1$ | $\int_0^\pi \sin m\sin n = 0$ |
| $P_n(x)$ | $1$ | $\int_{-1}^1 P_mP_n = 0$ |
| $J_n(kr)$ | $r$ | $\int_0^a rJ_nJ_n = 0$ |

<span class="marginnote">三张「正交表」是斯特姆-刘维尔理论的具体面容：同一个理论、三族基、三个权函数。做题时先认出「这是哪个 S-L 问题」，再套对应的正交性与系数公式。</span>

## 10 小结

- **斯特姆-刘维尔方程** $[py']' - qy + \lambda\rho y = 0$：自伴形式是理论地基；弦、勒让德、贝塞尔全是特例。
- **三大性质**：本征值实数、本征函数（带权 $\rho$）正交、函数族完备。
- **正交性证明**：格林公式三步走，依赖自伴形式 + 正则边界。
- **广义傅里叶级数**：$c_n = \frac{\langle f,y_n\rangle_\rho}{\langle y_n,y_n\rangle_\rho}$，收敛性与傅里叶级数相同。
- 边界条件决定正交族：同方程不同边界 → 不同本征函数家族。
