## 为什么从傅里叶级数法解方程开始

分离变量法给出「解是无穷级数」的形式，但初值匹配、非齐次项、非齐次边界这些实战问题，还需要一整套用**傅里叶级数直接怼上去**的操作。这一节把「傅里叶级数法」单独拎出来：把未知解直接写成三角级数、代入方程、比较系数，把 PDE 变成 ODE 的级数方程。它是分离变量法在「非齐次」战场上的主力补刀手——尤其当方程带强迫项、或边界条件非齐次时，傅里叶级数法是标准答案。<span class="marginnote">傅里叶级数法的灵魂是「比较系数」：把 $u$ 展开成 $\sum T_n(t)\sin\frac{n\pi x}{l}$，代入 PDE 后左右都是同一个三角级数，系数必须逐项相等——于是一个 PDE 变成无穷多个常微分方程，各个击破。</span>

## 1 初值匹配：用傅里叶级数定系数

分离变量法解完空间与时间，剩下「用初值定 $A_n, B_n$」。这一节把这个环节做成标准操作。以两端固定弦为例，解是

$$u(x,t) = \sum_{n=1}^{\infty}\left(A_n\cos\omega_n t + B_n\sin\omega_n t\right)\sin\frac{n\pi x}{l}, \qquad \omega_n = \frac{n\pi a}{l}$$

代入初值 $u(x,0)=\varphi(x)$、$u_t(x,0)=\psi(x)$：

$$\varphi(x) = \sum_{n=1}^{\infty} A_n\sin\frac{n\pi x}{l}, \qquad \psi(x) = \sum_{n=1}^{\infty} B_n\omega_n\sin\frac{n\pi x}{l}$$

**两边都是正弦级数，系数由正交性直接读出**——这就是傅里叶级数法在初值匹配里的作用。<span class="marginnote">这两行「系数 = 积分」的公式，我们早在分离变量法一节推导过：$A_n = \frac{2}{l}\int_0^l\varphi\sin\frac{n\pi x}{l}dx$。关键观察：<strong>方程本身已经把 $\varphi, \psi$ 的展开「预装」在解的结构里了</strong>，傅里叶级数法只是把最后的系数取出来。</span>

## 2 非齐次方程：强迫振动

有外力作用的弦满足非齐次方程：

$$u_{tt} = a^2u_{xx} + f(x,t), \qquad u(0,t)=u(l,t)=0$$

把 $f$ 也按正弦级数展开：$f(x,t) = \sum_{n=1}^{\infty} f_n(t)\sin\frac{n\pi x}{l}$，其中 $f_n(t) = \frac{2}{l}\int_0^l f(x,t)\sin\frac{n\pi x}{l}dx$。设解同样展开 $u = \sum T_n(t)\sin\frac{n\pi x}{l}$，代入方程得每个 $n$ 的常微分方程：

$$T_n'' + \omega_n^2 T_n = f_n(t), \qquad \omega_n = \frac{n\pi a}{l}$$

**每个模态 $n$ 都是一根「受迫谐振子」**——外力按傅里叶级数分配到各阶模态，各模态独立响应，再叠加。这个方程可以用常数变易法或拉普拉斯变换求解。<span class="marginnote">这就是模态分析（modal analysis）的雏形：结构力学的「振型分解法」、桥梁风振分析，都是「把激励按模态展开、逐模态响应、再叠加」这一流程。傅里叶级数法是它的数学底座。</span>

**共振的数学信号：** 当外力的某个频率 $\Omega$ 恰好等于本征频率 $\omega_n$，该模态的响应幅度随时间线性增长（解里出现 $t\cos\omega_n t$ 项）——这就是共振。**共振在方程里表现为「特解与齐次解线性相关」的退化情形。**

## 3 非齐次边界条件：齐次化的两板斧

边界条件非齐次（如端点温度 $u(0,t) = T_1$）时，分离变量法的齐次边界前提被破坏。两条路：

**路一：边界条件齐次化。** 找一个满足非齐次边界的简单特解 $v(x,t)$（常取线性或稳态解），令 $u = v + w$，$w$ 满足齐次边界，用分离变量法解 $w$。<span class="marginnote">典型例子：杆端恒温 $u(0,t)=T_1, u(l,t)=T_2$，取稳态特解 $v = T_1 + \frac{T_2-T_1}{l}x$（直线温度分布），$w$ 满足两端零温的齐次问题——物理上「先取出稳态背景，再求偏离」。</span>

**路二：直接傅里叶级数法。** 若边界随时间是周期函数，可直接把边界条件展开成傅里叶级数，设解为对应级数形式，逐项匹配。两条路最终都落到「级数展开 + 比较系数」。

**辨析｜易错点：** 齐次化选特解 $v$ 时，$v$ 不必满足方程——只需满足边界条件。很多初学者强行让 $v$ 同时解方程，反而把问题搞复杂。**$v$ 的任务是「占住边界」，方程的剩余部分交给 $w$。**

## 4 公式解析：非齐次热方程的模态解

把流程浓缩成一个可操作的三步模板，以非齐次热方程为例：

$$
u_t = a^2 u_{xx} + f(x,t), \qquad u(0,t)=u(l,t)=0, \qquad u(x,0)=\varphi(x)
$$

- **第一步，展开所有量**：$u = \sum T_n(t)\sin\frac{n\pi x}{l}$、$f = \sum f_n(t)\sin\frac{n\pi x}{l}$、$\varphi = \sum \varphi_n\sin\frac{n\pi x}{l}$。三组系数分别用正交性公式计算。
- **第二步，代入方程比较系数**：逐项得到一阶 ODE $T_n' + a^2\left(\frac{n\pi}{l}\right)^2 T_n = f_n(t)$。这是标准一阶线性 ODE，积分因子 $e^{a^2(n\pi/l)^2 t}$ 一套即可。
- **第三步，初值定解**：$T_n(0) = \varphi_n$，代入通解得 $T_n(t) = e^{-\lambda_n a^2 t}\varphi_n + \int_0^t e^{-\lambda_n a^2(t-s)}f_n(s)ds$，其中 $\lambda_n = (n\pi/l)^2$。

**注意解的物理结构：** 第一项是「初值衰减」（热扩散把初始温度抹平），第二项是「外力积累」（每个时刻的外力按指数衰减记忆叠加）。**傅里叶级数法把热方程的「扩散 + 源」拆成每个模态的「衰减 + 累积」，物理一目了然。**

## 5 方法总览：什么时候用傅里叶级数法

| 情形 | 用分离变量法 | 用傅里叶级数法 |
| --- | --- | --- |
| 齐次方程 + 齐次边界 | ✓ 首选 | 可，但绕远 |
| 非齐次方程（有源项） | 需先处理源项 | ✓ 直接展开源项 |
| 非齐次边界条件 | 先齐次化 | 可直接级数匹配 |
| 初值匹配 | ✓ 天然 | ✓ 天然 |

**重点：两者本质是同一种数学**——分离变量法是傅里叶级数法的「先分离、后展开」版本，傅里叶级数法是「先展开、后比较」版本。练熟任意一个，另一个就是它的换装。实际工程里，**有源项和周期边界的问题优先考虑傅里叶级数法**。<span class="marginnote">当系数不是常数（变系数方程）时，三角级数法失效，必须改用斯特姆-刘维尔本征函数族（勒让德、贝塞尔）。「用哪一族基展开」永远由方程系数与区域几何共同决定——这是特殊函数家族存在的根本理由。</span>

## 7 延伸：共振的实际形态与阻尼的救场

共振在数学里表现为「特解与齐次解线性相关」，但现实中系统总有阻尼，共振响应不会无限增长。带阻尼的受迫振动方程

$$T_n'' + 2\gamma T_n' + \omega_n^2 T_n = F\cos\Omega t$$

的稳态解幅度为

$$|T_n| = \frac{F}{\sqrt{(\omega_n^2 - \Omega^2)^2 + 4\gamma^2\Omega^2}}$$

当驱动力频率 $\Omega$ 接近本征频率 $\omega_n$ 时，幅度达到峰值；**峰值高度由阻尼 $\gamma$ 决定**——阻尼越小，峰越尖越高。这个「频率响应曲线」的形状，就是共振峰（resonance peak）。<span class="marginnote">工程里用「品质因数」$Q = \frac{\omega_n}{2\gamma}$ 描述峰的尖锐程度：$Q$ 越大峰越尖。桥梁、楼宇、耳机振膜的设计，核心就是在「避开共振频率」与「利用共振放大」之间权衡。傅里叶级数法把「结构有哪些共振峰」翻译成「各阶模态 $n$ 的 $\omega_n$ 与 $Q$」。</span>

**重点：模态分解让「共振位置」一目了然。** 每一阶模态 $n$ 有自己的本征频率 $\omega_n$；外力频谱里与哪个 $\omega_n$ 重合，哪一阶模态就被「点燃」。这就是模态分析「按阶数分工」的机制——一阶模态主导、高阶模态贡献修正。

**辨析｜易错点：** 无阻尼共振的 $t\cos\omega t$ 项（线性增长）只出现在**齐次解与特解频率精确相等**时。实际驱动频率稍偏一点，幅度就是大而有限、而非无限增长。**「共振」与「接近共振」是两回事**——前者解发散、后者解大而有界。

## 9 延伸练习与自查

**练习一（初值定系数）：** 两端固定弦，$l=\pi$，$a=1$，初值 $\varphi = \sin 2x$、$\psi = 0$。$A_2 = 1$，其余 $A_n = 0$，$B_n = 0$，故 $u = \sin 2x\cos 2t$——单模态纯驻波。

**练习二（非齐次方程）：** $u_{tt} = u_{xx} + \sin x$，两端零边界。把 $\sin x$ 展开：$f_n(t)$ 只有 $n=1$ 项 $f_1 = 1$，模态 $1$ 方程 $T_1'' + T_1 = 1$，特解 $T_1 = 1$，故稳态部分 $u = \sin x$——**常力源把弦「拱」成正弦形状**。

**练习三（共振）：** 外力频率 $\Omega = \omega_1$ 时，第一模态出现 $t\cos\omega_1t$ 项——幅度随时间线性增长，无阻尼共振的数学信号。

| 战场 | 做法 | 结果形态 |
| --- | --- | --- |
| 齐次初值 | 正弦级数定系数 | 驻波叠加 |
| 非齐次方程 | 源项展开逐模态解 | 稳态 + 瞬态 |
| 非齐次边界 | 齐次化特解 | 背景场 + 偏离 |
| 共振 | 频率匹配检测 | 线性增长 |

<span class="marginnote">练习二显示「源项展开」的妙处：$f=\sin x$ 恰好只激发第一模态，方程退化成一阶模态的简单 ODE。实际问题里源项往往激发多阶，但「逐模态处理」的骨架不变。</span>

## 10 小结

- **初值匹配**：$A_n, B_n$ 由 $\varphi, \psi$ 的正弦级数系数直接给出，正交性一手包办。
- **非齐次方程**：把源项 $f$ 展开，逐模态解受迫谐振子 $T_n'' + \omega_n^2T_n = f_n$；频率匹配时出现**共振**。
- **非齐次边界**：先选特解 $v$ 齐次化，或直接级数匹配；$v$ 只需占住边界。
- **三量展开模板**：$u, f, \varphi$ 同步展开、代入比较系数、初值定解，一个模板解遍非齐次问题。
- 分离变量法与傅里叶级数法本质同一；变系数方程换用斯特姆-刘维尔本征函数。
