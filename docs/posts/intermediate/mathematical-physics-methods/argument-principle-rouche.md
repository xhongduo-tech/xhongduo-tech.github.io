## 为什么从辐角原理与儒歇定理开始

留数定理让我们算积分，而辐角原理让我们**数零点**——不把零点找出来，先数清楚在某个区域里到底有几个。这听起来像绕远路，却是复分析最实用的招式之一：控制论里判断系统是否稳定、多项式根的重数分析、甚至「闭路内方程有几解」，全靠这一族工具。儒歇定理则是它的强力推论：**只要函数在边界上「大得压过」另一项，两者在圈内的零点个数就一样**。这一节是复变函数第一篇的收官战。<span class="marginnote">辐角原理的物理解释：把 $f(z)$ 想成平面场，沿闭路走一圈，场方向旋转的总圈数就是 $N-P$（零点减极点数）。这是「缠绕数」（winding number）概念的雏形，也是代数拓扑里「映射度」的复分析版本。</span>

## 1 对数留数与零点计数

设 $f$ 在闭曲线 $C$ 内部除有限个极点外解析，$C$ 上无零点无极点。定义**对数留数（logarithmic residue）**为沿 $C$ 对 $\frac{f'(z)}{f(z)}$ 的积分：

$$\frac{1}{2\pi i}\oint_C \frac{f'(z)}{f(z)}\,dz = N - P$$

其中 $N$ 是 $C$ 内部**零点总数**（按重数计），$P$ 是**极点总数**（按阶数计）。<span class="marginnote">「按重数计」意味着二阶零点算两个。这在求导公式里自然出现：若 $f = (z-a)^m g(z)$，则 $\frac{f'}{f} = \frac{m}{z-a} + \frac{g'}{g}$，积分一圈正好提取 $m$——每个零点的重数等于它贡献的对数留数。</span>

**为什么叫「对数」**：$\frac{f'(z)}{f(z)} = \frac{d}{dz}\ln f(z)$，所以积分等于 $\ln f$ 沿闭路的增量——即辐角变化除以 $2\pi$。这给出辐角原理的几何表述：**$f$ 的像曲线绕原点的圈数 $= N - P$**。

## 2 辐角原理

**辐角原理（argument principle）：** 在上述假设下，

$$\Delta_C \arg f(z) = 2\pi(N - P)$$

即 $f(z)$ 沿闭路 $C$ 走一圈，其辐角的总变化是 $2\pi$ 的 $N-P$ 倍。<span class="marginnote">这个「辐角变化」不用算出精确路径——只需知道 $f$ 沿 $C$ 的像是否绕原点、绕了几圈。它把「零点个数」这个代数问题，转化为「绕圈数」这个拓扑问题，用起来出奇地快。</span>

证明从对数留数出发：$\oint_C \frac{f'}{f}dz = \Delta_C \ln f = \Delta_C \ln|f| + i\Delta_C\arg f$，其中 $\Delta_C\ln|f| = 0$（沿闭路回到同一模长），剩下 $i\Delta_C\arg f = 2\pi i(N-P)$。

## 3 儒歇定理

**儒歇定理（Rouché's theorem）：** 设 $f, g$ 在闭曲线 $C$ 内部及边界上解析，且边界上严格成立 $|g(z)| < |f(z)|$，则 $f$ 与 $f+g$ 在 $C$ 内部有**相同个数**的零点（都按重数计）。

**直觉：** 边界上 $f$ 是「主项」，$g$ 只是「小扰动」，小扰动改变不了零点的数目。<span class="marginnote">儒歇定理是「连续变形保个数」思想的一个实例：把 $f$ 连续变形到 $f+g$，只要边界上从不穿过零，零点的个数就不会跳变。它和辐角原理、以及代数基本定理的拓扑证明是同一条血脉。</span>

证明的枢纽是辐角原理：在边界上 $\left|\frac{g}{f}\right| < 1$，所以 $\frac{f+g}{f} = 1 + \frac{g}{f}$ 始终落在以 $1$ 为中心、半径 $<1$ 的圆内——不绕原点。故 $\Delta\arg(f+g) = \Delta\arg f$，由辐角原理 $N_{f+g} = N_f$。

**标准应用：证明代数基本定理的复分析版。** 取 $f(z) = z^n$，$g(z) = a_{n-1}z^{n-1} + \cdots + a_0$，在大圆 $|z|=R$ 上，$|g| < R^n = |f|$（只要 $R$ 足够大）。由儒歇定理，$z^n + g$（即任意 $n$ 次多项式）在圆内与 $z^n$ 有同样多的零点——$z^n$ 在圆内恰有 $n$ 个零点（$0$ 是 $n$ 重），故原多项式也有 $n$ 个零点（按重数计）。<span class="marginnote">同一个代数基本定理，上一节用刘维尔定理证过一遍，这里用儒歇定理再证一遍——两条路一个从「有界」出发，一个从「零点计数」出发，殊途同归。复分析对代数命题的两次降维打击，都写进了教材。</span>

## 4 公式解析：$\oint_{|z|=2}\frac{dz}{z^2+3z+2}$ 的对数留数

用对数留数验证零点计数。取 $f(z) = z^2 + 3z + 2 = (z+1)(z+2)$，考虑：

$$
\frac{1}{2\pi i}\oint_{|z|=2} \frac{2z+3}{z^2+3z+2}\,dz = 2
$$

三步拆解：

- **第一步，分解零点**：$f = (z+1)(z+2)$，零点在 $z=-1$ 与 $z=-2$，都在 $|z|=2$ 内部，各是单零点，故 $N = 2$。
- **第二步，看极点**：$f$ 是多项式、全平面解析，$P = 0$。
- **第三步，部分分式套积分**：$\frac{f'}{f} = \frac{2z+3}{z^2+3z+2} = \frac{1}{z+1} + \frac{1}{z+2}$，于是积分 $\frac{1}{2\pi i}\oint\left(\frac{1}{z+1}+\frac{1}{z+2}\right)dz = \frac{1}{2\pi i}(2\pi i + 2\pi i) = 2$，恰等于 $N - P = 2 - 0$。

**辨析｜易错点：零点计数严重依赖闭路选在哪。** 把圆换成 $|z|=1$，$z=-2$ 就掉到圆外，$N=1$、对数留数变 $1$。同一函数、不同圆、不同答案——**先画圈，再数点，最后套公式**，顺序不能乱。本题取 $|z|=2$ 圈住两个零点，故对数留数 $=2$。

## 5 应用：方程根的分布

辐角原理与儒歇定理的实际用途，往往不是「算出数」，而是**判断存在性与个数**。例如问方程 $z^4 + z^3 + 1 = 0$ 在单位圆内有几个根：取 $f(z) = z^4$、$g(z) = z^3 + 1$，在 $|z|=1$ 上 $|g| \le |z|^3 + 1 = 2$，而 $|f| = 1$——**放缩给不出 $|g| < |f|$**，这题不能硬套。需要更精细的分组，或改用辐角原理直接数。<span class="marginnote">这个反例提醒：儒歇定理的边界不等式 $|g| < |f|$ 必须严格成立，而选哪个当 $f$、哪个当 $g$ 需要尝试。方法本身是「挑选 + 放缩 + 验证」三步，验证不过就换分组。</span>

**重点：儒歇定理给的是「计数保证」，不是「根的精确位置」。** 它回答「有几个」，至于「在哪」，仍需其他工具。工程里判断多项式是否稳定（所有根是否都在左半平面）时，常配合劳斯判据交叉使用。

## 7 延伸：奈奎斯特判据与稳定性

辐角原理在工程里最著名的化身是**奈奎斯特判据（Nyquist stability criterion）**。设开环传递函数为 $G(s)H(s)$，闭环系统是否稳定，取决于 $1 + G(s)H(s)$ 的零点是否都在左半平面。

把辐角原理套在右半平面的边界（虚轴 + 右侧大圆弧）上：**沿这条围道走一圈，$1+GH$ 的辐角变化等于其右半平面零点数减极点数**。而 $1+GH$ 的极点就是开环极点，零点就是闭环极点。于是工程师只需画出 $G(s)H(s)$ 在复平面上的**奈奎斯特图**，数它绕 $(-1, 0)$ 点的圈数，就能判定闭环稳定性——**连极点都不用求，画图就够**。<span class="marginnote">奈奎斯特 1932 年提出这个判据，是为了解决反馈放大器的稳定性问题。它的核心洞察正是辐角原理：绕 $-1$ 点的圈数 = 特征方程在右半平面的零点数。这是复变函数论第一次大规模「进入」控制系统设计。</span>

**辨析｜易错点：** 应用奈奎斯特判据时，围道必须绕开虚轴上的奇点（用小半圆凸进右半平面或左半平面），否则辐角变化会在奇点处跳跃。**奇点在围道上 = 辐角原理不适用**，必须先做小半圆处理——这和我们之前「实轴奇点用主值」的处理是同一套逻辑。

再补充一个儒歇定理的实用例：方程 $z^7 - 5z + 1 = 0$ 在单位圆内有几个根？取 $f = -5z$、$g = z^7 + 1$，在 $|z|=1$ 上 $|g| \le 2 < 5 = |f|$，儒歇定理给出 $f+g$ 与 $f$ 有同样多的零点——$f = -5z$ 在单位圆内恰有一个零点，故原方程在单位圆内**恰有一个根**。这就是「选主项」的经典示范。

## 9 延伸练习与自查

**练习一（对数留数）：** 求 $\oint_{|z|=2}\frac{z^2+1}{z^3-z}dz$ 的对数留数。先分解 $z^3 - z = z(z-1)(z+1)$，三个单零点都在圆内，$N=3$，故对数留数 $=3$。

**练习二（辐角原理）：** 设 $f(z) = z^3 - 2z + 1$，验证单位圆内零点个数。取 $f$ 本身在单位圆上，计算 $N - P$：无极点，沿 $|z|=1$ 走一圈数 $f$ 绕原点的圈数——用儒歇定理更省：$f = -2z + (z^3+1)$，$|z^3+1| \le 2$，在 $|z|=1$ 上不严格小于 $|-2z| = 2$（等号可能取到），需换分组 $f = z^3 + (1-2z)$。

**练习三（零点计数）：** 方程 $z^4 + 3z + 1 = 0$ 在 $|z|=2$ 内有几个根？取 $f = z^4$、$g = 3z+1$，$|g| \le 7 < 16 = |f|$，故与 $z^4$ 一样有 4 个根（按重数计）。

**练习四（概念辨析）：** 「儒歇定理只要求 $|g| < |f|$ 在边界上成立即可」——对，但要**逐点**严格；「边界上某点取等号也没关系」——错，取等号处论证失效。

| 方法 | 回答的问题 | 输入 | 输出 |
| --- | --- | --- | --- |
| 对数留数 | 零点减极点个数 | $\frac{f'}{f}$ 的闭路积分 | $N-P$ |
| 辐角原理 | 绕原点圈数 | $f$ 沿闭路辐角变化 | $2\pi(N-P)$ |
| 儒歇定理 | 扰动不改零点数 | 边界上 $|g|<|f|$ | $N_{f+g} = N_f$ |

<span class="marginnote">三件套的选用口诀：已知 $f$ 的形状用辐角原理，想比较两个函数用儒歇，直接数数用对数留数。做题先问「给的是什么、要的是什么」。</span>

> **课后思考**
>
> - 对数留数 $\oint\frac{f'}{f}dz$ 里，若 $f$ 在圈内既有零点又有极点，积分给出什么？符号分别怎么算？
> - 辐角原理的「绕圈数」如何用图像判断？画出 $f$ 沿 $|z|=R$ 的像曲线，怎么数它绕原点几圈？
> - 儒歇定理的边界条件 $|g| < |f|$ 若改成 $|g| \le |f|$，结论还成立吗？找反例。
> - 为什么儒歇定理要求 $f$ 与 $f+g$ 都在边界上**无零点**？若边界上有零点会发生什么？
> - 用儒歇定理估计 $z^5 + 2z^3 + 1 = 0$ 在 $|z|=1$ 与 $|z|=2$ 内的根数，分别选哪对 $f, g$？
> - 奈奎斯特判据里绕 $(-1,0)$ 点的圈数，和辐角原理的 $N-P$ 怎么对应？负圈数代表什么？

> - 对数留数能否直接用于「求根」而非「数根」？它只能计数，原因是什么？
> - 若 $f$ 在圈上有零点，辐角原理还适用吗？围道应如何修正？

## 12 小结

- **对数留数** $\frac{1}{2\pi i}\oint\frac{f'}{f}dz = N - P$：零点减极点，按重数计。
- **辐角原理** $\Delta_C\arg f = 2\pi(N-P)$：辐角变化圈数等于零点减极点数。
- **儒歇定理**：边界上 $|g| < |f|$ 时 $f$ 与 $f+g$ 零点个数相同——连续变形保个数。
- 应用：代数基本定理、方程根的存在性与个数判断；**边界不等式必须严格**，分组可以试。

至此，复变函数第一篇收官。在下一节，我们翻开第二篇：从周期函数的展开开始，进入**傅里叶级数**——把振动分解成谐波的叠加，这是整个积分变换理论的序曲。
