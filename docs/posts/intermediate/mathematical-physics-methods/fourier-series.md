## 为什么从傅里叶级数开始

复变函数第一篇收官后，我们翻到第二篇「积分变换」。第一篇的利器是「绕奇点积分」，第二篇的利器是「把函数拆成谐波」——**任何周期现象，无论是琴弦的振动、潮汐的涨落、还是电网里的谐波污染，都能写成一系列 $\cos n\omega t$ 与 $\sin n\omega t$ 的叠加**。傅里叶级数是这条线的起点：先回答「离散频率的叠加」，再在下一节把周期趋于无穷，级数就变成傅里叶积分。它是信号处理、偏微分方程分离变量法（第三篇）共同的语言。<span class="marginnote">傅里叶的《热的解析理论》（1822 年）声称任何函数都能这样展开，当时震动整个分析学界——因为「任何函数」在当时还是含糊的。今天的严格版本是狄利克雷与黎曼的工作，条件比傅里叶当初设想的温和得多。</span>

## 1 三角级数与欧拉-傅里叶公式

设 $f$ 是周期为 $2\pi$ 的函数，**三角级数（trigonometric series）** 为：

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty}\left(a_n\cos nx + b_n\sin nx\right)$$

系数由**欧拉-傅里叶公式（Euler–Fourier formulas）** 给出：

$$a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos nx\,dx, \qquad b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin nx\,dx$$

这些系数之所以这样定义，靠的是三角函数系的**正交性**：在 $[-\pi, \pi]$ 上，$\{\cos nx, \sin nx\}$ 中任意两个不同函数的内积为零，且 $\int_{-\pi}^{\pi}\cos^2 nx\,dx = \pi$。<span class="marginnote">正交性就是把「叠加」翻译成「投影」的机制：$a_n$ 等于 $f$ 向 $\cos nx$ 方向的投影，恰如向量的坐标是它向基向量的投影。这个思想在第三篇分离变量法和量子力学的本征函数展开里反复出现。</span>

**重点：系数公式是「投影」，不是「拟合」。** 求 $a_n$ 就是在积分意义下把 $f$ 投影到 $\cos nx$ 上——因为 $\int f\cos nx\,dx = \sum_m a_m\int\cos mx\cos nx\,dx$，正交性把求和里除 $m=n$ 以外的一切项都清零，只留 $a_n\pi$。

## 2 收敛性：狄利克雷条件与吉布斯现象

傅里叶级数何时收敛、收敛到哪，由**狄利克雷条件（Dirichlet conditions）** 回答：若 $f$ 在一个周期内逐段光滑（有有限个间断点与极值点），则傅里叶级数处处收敛，且

在连续点 $x$，收敛到 $f(x)$；
在间断点 $x_0$，收敛到 $\frac{f(x_0^-) + f(x_0^+)}{2}$，即**左右极限的平均**。

**辨析｜易错点：** 级数在间断点收敛到平均值，而不是函数值本身。这是傅里叶级数「跳变处取中值」的招牌特征——画图时，间断点上方会看到一个悬空的「中点」，这不算错误。<span class="marginnote">用「平均值」而非「端点值」的理由在傅里叶点态收敛理论里可以严格证明。工程上做波形重建时，跃变处看到的就是这个中点，属于正常现象。</span>

另一个视觉特征是**吉布斯现象（Gibbs phenomenon）**：在间断点附近，部分和会「超调」约 $9\%$，出现固定高度的过冲尖刺。这个超调不随项数增加而消失，只是越来越贴近间断点——**用傅里叶级数逼近有跳跃的函数，跳跃处总有那么一根刺**。<span class="marginnote">吉布斯现象不是误差的 bug，而是级数逼近的本质：当 $n\to\infty$ 时尖刺的高度收敛到约 $0.0895 \times$ 跳跃幅度。图像压缩、滤波器设计里处理边缘时，都要和这根刺共存。</span>

## 3 奇偶性与半幅展开

利用对称性可以把系数简化一半：

$f$ 为**偶函数**（$f(-x)=f(x)$）时，所有 $b_n = 0$，只剩余弦项——**余弦级数（cosine series）**。
$f$ 为**奇函数**（$f(-x)=-f(x)$）时，所有 $a_n = 0$，只剩正弦项——**正弦级数（sine series）**。

更有用的是**半幅展开（half-range expansion）**：如果函数只定义在 $[0, \pi]$ 上，可以人为把它延拓成偶函数或奇函数，从而得到余弦级数或正弦级数。**同一定义在 $[0,\pi]$ 上的函数，可以有两个不同的展开**——用哪个，取决于问题的边界条件。<span class="marginnote">这一点在第三篇分离变量法里是灵魂：两端固定弦用正弦级数（两端为零），绝热棒用余弦级数（两端导数为零）。「按边界条件挑展开类型」正是半幅展开存在的理由。</span>

## 4 复数形式的傅里叶级数

用欧拉公式把 $\cos nx = \frac{e^{inx}+e^{-inx}}{2}$ 代进去，三角级数收紧成指数形式：

$$f(x) = \sum_{n=-\infty}^{\infty} c_n e^{inx}, \qquad c_n = \frac{1}{2\pi}\int_{-\pi}^{\pi} f(x)e^{-inx}\,dx$$

系数 $c_n$ 与 $a_n, b_n$ 的关系：$c_0 = \frac{a_0}{2}$，$c_n = \frac{a_n - ib_n}{2}$（$n>0$），$c_{-n} = \frac{a_n + ib_n}{2}$。<span class="marginnote">复数形式的好处是「一个系数 $c_n$ 打包了 $\cos$ 与 $\sin$ 两个分量」，负频率 $n<0$ 不是物理上的负频率，而是欧拉公式带来的数学对称项。信号处理里常说「频谱关于零频共轭对称」，就是 $c_{-n} = \overline{c_n}$ 的体现。</span>

## 5 公式解析：方波的傅里叶系数

把方波 $f(x) = 1$（$0 < x < \pi$）、$f(x) = -1$（$-\pi < x < 0$）、周期 $2\pi$ 展开：

$$
f(x) = \frac{4}{\pi}\sum_{n=1}^{\infty}\frac{\sin(2n-1)x}{2n-1}
$$

三步拆解：

- **第一步，判奇偶**：$f(-x) = -f(x)$，是奇函数，故 $a_n = 0$ 全为零，只剩 $b_n$。
- **第二步，算 $b_n$**：$b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin nx\,dx = \frac{2}{\pi}\int_0^\pi \sin nx\,dx = \frac{2}{\pi}\cdot\frac{1-\cos n\pi}{n}$。当 $n$ 为偶数时 $\cos n\pi = 1$，$b_n = 0$；$n$ 为奇数时 $b_n = \frac{4}{n\pi}$。
- **第三步，留奇数项**：$n = 2k-1$，$b_{2k-1} = \frac{4}{(2k-1)\pi}$，代入得 $\frac{4}{\pi}\sum_{k=1}^\infty \frac{\sin(2k-1)x}{2k-1}$。

方波展开只含**奇次谐波**——这是奇函数 + 方波对称性的双重结果。第一项 $\frac{4}{\pi}\sin x$ 就占了方波能量的绝大部分，这就是「方波 ≈ 正弦波 + 三倍频小修正」的由来。**一个理想的方波，在频域里是一串间隔为 $2$、幅度按 $1/n$ 衰减的离散谱线。**

## 7 延伸：傅里叶级数的能量恒等式

把帕塞瓦尔定理用到周期函数的傅里叶级数上，得到一条极其实用的**能量恒等式**：

$$\frac{1}{\pi}\int_{-\pi}^{\pi} f^2(x)\,dx = \frac{a_0^2}{2} + \sum_{n=1}^{\infty}\left(a_n^2 + b_n^2\right)$$

左边的积分是 $f$ 在一个周期内的平均功率，右边是各谐波功率之和——**总功率 = 各谐波功率的叠加**。它有两个立刻的用途：

- **数值校验**：手算或数值求出的傅里叶系数，代入恒等式看左右是否相等，快速发现算错。
- **功率占比**：方波的 $\sum b_n^2 = \frac{8}{\pi^2}$ 中，基波 $\left(\frac{4}{\pi}\right)^2 = \frac{16}{\pi^2}$ 占约 $81\%$——「基波携带主要能量」从此有了定量依据。<span class="marginnote">「$n$ 项截断保留了总能量的多少」是信号压缩的核心问题。JPEG、MP3 的思想就是：只保留能量大的谐波，丢弃小的，再按能量占比评估失真。傅里叶级数 + 帕塞瓦尔，正是这一切的数学起点。</span>

**辨析｜易错点：** 帕塞瓦尔恒等式要求 $f$ 平方可积（能量有限），且级数按「范数收敛」理解。方波满足；但若 $f$ 平方不可积（如周期脉冲串），恒等式失去意义——**先确认 $f^2$ 可积，再套恒等式**。

**延伸计算：** 对锯齿波 $f(x) = x$（$-\pi < x \le \pi$），系数 $b_n = \frac{2(-1)^{n+1}}{n}$，由恒等式得 $\frac{1}{\pi}\int_{-\pi}^\pi x^2 dx = \sum_{n=1}^\infty \frac{4}{n^2}$，即 $\sum\frac1{n^2} = \frac{\pi^2}{6}$——**欧拉 1735 年用级数求出的著名结果，这里从傅里叶级数几行推出**。这是一条「分析 → 数论」的美丽小道。

## 9 延伸练习与自查

**练习一（系数计算）：** 周期 $2\pi$ 的偶函数 $f(x) = x^2$（$|x| \le \pi$）展开。偶函数只有余弦项，$a_n = \frac{4(-1)^n}{n^2}$，$a_0 = \frac{2\pi^2}{3}$，于是 $x^2 = \frac{\pi^2}{3} + 4\sum_{n=1}^\infty\frac{(-1)^n}{n^2}\cos nx$。

**练习二（间断点收敛值）：** 方波在跳跃点 $x=0$ 处级数收敛到 $\frac{1+(-1)}{2} = 0$（左右极限平均），而函数值定义可任取——**收敛值由平均决定，不由函数值决定**。

**练习三（半幅展开）：** 在 $[0,\pi]$ 上 $f(x)=1$，做余弦半幅展开：$a_0 = 2$，$a_n = \frac{2}{\pi}\int_0^\pi\cos nx\,dx = 0$（$n\ge1$），故 $f = 1$——常数函数展开成「只有 $a_0$」是平凡但容易漏的特例。

| 任务 | 公式 | 易错点 |
| --- | --- | --- |
| 求 $a_n$ | $\frac1\pi\int f\cos nx$ | 忘 $\frac1\pi$ |
| 求 $b_n$ | $\frac1\pi\int f\sin nx$ | 奇偶性误判 |
| 间断点值 | 左右极限平均 | 取成函数值 |
| 半幅展开 | 先延拓再展开 | 忘选偶/奇延拓 |

<span class="marginnote">四个练习覆盖「系数、收敛值、半幅、常数」四种考点。半幅展开的「同一个函数两个展开」最易混淆——先想清楚边界条件要什么，再选延拓方向。</span>

## 11 小结

- **傅里叶级数** $f \sim \frac{a_0}{2} + \sum(a_n\cos nx + b_n\sin nx)$，系数是向三角函数系的**正交投影**。
- **狄利克雷条件**保证逐点收敛：连续点收敛到 $f$，间断点收敛到左右极限平均；跳跃处有**吉布斯现象**超调 $9\%$。
- 偶函数→余弦级数，奇函数→正弦级数；**半幅展开**让 $[0,\pi]$ 上的函数有两种展开，按边界条件挑选。
- **复数形式** $f = \sum c_n e^{inx}$ 打包 $\cos$ 与 $\sin$，频谱共轭对称。
- 方波例：只含奇次谐波，幅度按 $1/n$ 衰减——理想方波的离散频谱。

在下一节，我们让周期 $T \to \infty$：频率从离散谱线铺成连续谱，傅里叶级数升级为**傅里叶变换**。
