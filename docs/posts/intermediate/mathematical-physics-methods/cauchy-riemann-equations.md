# 柯西-黎曼方程

<div class="epigraph">

## 为什么从柯西-黎曼方程开始

上一节我们留下一个悬念：「路径无关」这个苛刻条件，究竟把函数逼成了什么样子？柯西与黎曼的答案漂亮得出人意料：**只要 $f = u + iv$ 的实部与虚部可微，那么「复可导」就等价于两个实数偏微分方程**——它们合称柯西-黎曼方程（C-R 方程）。这一节我们从差商出发把它推出来，并立刻收获两个副产品：调和函数与「已知实部求虚部」的构造技巧。C-R 方程是整个复变函数论的守门人，也是之后泰勒展开、留数理论一切推导的起点。<span class="marginnote">这两条方程第一次出现在达朗贝尔关于流体力学的工作中，柯西与黎曼分别把它与复可导性联系起来。物理直觉始终领先——水流动的平面无旋场早就满足 C-R 方程，复数只是给了它一个漂亮的形式。</span>

## 1 从差商推出 C-R 方程

设 $f(z) = u(x,y) + iv(x,y)$ 在 $z_0$ 可导，记 $\Delta z = \Delta x + i\Delta y$，差商为：

$$\frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z}$$

**重点：让 $\Delta z$ 沿两个特殊方向趋零。** 由于导数存在，极限应与路径无关，于是挑两条最容易算的路径：

- **沿实轴**，即 $\Delta y = 0$，$\Delta z = \Delta x$：

$$\lim_{\Delta x \to 0} \frac{u(x_0 + \Delta x, y_0) - u(x_0,y_0)}{\Delta x} + i\, \frac{v(x_0 + \Delta x, y_0) - v(x_0,y_0)}{\Delta x} = u_x + i v_x$$

- **沿虚轴**，即 $\Delta x = 0$，$\Delta z = i\Delta y$：

$$\lim_{\Delta y \to 0} \frac{u(x_0, y_0 + \Delta y) - u(x_0,y_0)}{i\Delta y} + i\, \frac{v(x_0, y_0 + \Delta y) - v(x_0,y_0)}{i\Delta y} = -i\, u_y + v_y$$

两条路径必须给出同一个导数，实部虚部分别相等，就得到**柯西-黎曼方程（Cauchy-Riemann equations）**：

$$\boxed{\; u_x = v_y, \qquad u_y = -v_x \;}$$

且此时导数可写成任一形式：

$$f'(z) = u_x + iv_x = v_y - iu_y$$<span class="marginnote">两个式子怎么记？口诀：「实部对 $x$ = 虚部对 $y$」，「实部对 $y$ = 负的虚部对 $x$」。或者用转盘记忆：求导时「顺时针转一下」——$u_x$ 接 $v_y$，$u_y$ 接 $-v_x$。</span>

## 2 充分条件：C-R 加可微性

上面的推导只证明了**必要性**：复可导 ⇒ C-R 方程成立。反过来需要补一个条件——$u, v$ 的四个一阶偏导数连续（等价地 $u, v$ 可微）。此时：

**柯西-黎曼判别法：** 若 $u, v$ 在 $z_0$ 邻域内连续可微，且满足 C-R 方程，则 $f$ 在 $z_0$ 解析。<span class="marginnote">「$u, v$ 可微」这个前提常被初学者漏掉。一个反例：$u = \dfrac{xy^2}{x^2+y^2}$（原点处补 0），$v = 0$ 在原点满足 C-R 但函数不解析，因为偏导不连续。考试里这个反例几乎每年出现一次。</span>

**辨析｜易错点：** C-R 方程成立是「点」的局部条件，而解析要求它在**一个开邻域**上处处成立。所以验证解析性要三件事：① $u, v$ 偏导连续；② 在区域上逐点验证 $u_x = v_y$、$u_y = -v_x$；③ 得出结论。缺一不可。

## 3 公式解析：极坐标下的 C-R 方程

许多问题在极坐标下更自然，例如讨论 $z^n$ 或对数。把 $z = re^{i\theta}$，令 $f = u(r,\theta) + iv(r,\theta)$，链式法则把直角坐标 C-R 方程换成：

$$
u_r = \frac{1}{r}v_\theta, \qquad v_r = -\frac{1}{r}u_\theta
$$

三步拆解：

- **第一步，写链式法则**：$u_x = u_r r_x + u_\theta \theta_x$，其中 $r_x = \cos\theta$，$\theta_x = -\frac{\sin\theta}{r}$，代入原方程。
- **第二步，合并同类项**：把 $u_x = v_y$ 写成对 $r$ 与 $\theta$ 的混合偏导，经整理消去 $\cos\theta, \sin\theta$ 的组合。
- **第三步，读出两条干净方程**：剩下的两组方程正是 $u_r = \frac{1}{r} v_\theta$ 与 $v_r = -\frac{1}{r}u_\theta$。

用极坐标 C-R 方程立刻验证 $f(z) = z^n = r^n e^{in\theta}$：$u = r^n\cos n\theta$，$v = r^n\sin n\theta$，直接算出 $u_r = nr^{n-1}\cos n\theta = \frac{1}{r}v_\theta$，成立。**整幂函数在复平面上处处解析**，这为下一节初等解析函数的全面展开铺平了路。

## 4 调和函数与共轭调和函数

对 C-R 方程再求导：对 $u_x = v_y$ 关于 $y$ 求导、对 $u_y = -v_x$ 关于 $x$ 求导，利用二阶偏导可交换，消去 $v$ 得：

$$\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0$$

即 $u$ 满足**拉普拉斯方程（Laplace's equation）** $\nabla^2 u = 0$，这样的函数称为**调和函数（harmonic function）**。同理 $v$ 也调和。

**解析函数的实部与虚部都是调和函数**，且二者满足 C-R 方程，称 $v$ 是 $u$ 的**共轭调和函数（conjugate harmonic function）**。<span class="marginnote">反过来说：任意一个调和函数 $u$，只要区域单连通，就能找到唯一的（差常数）共轭调和 $v$，拼出一个解析函数。物理意义：$u$ 可以是静电势，$v$ 就是流线函数，或等量地 $v$ 是磁矢势——平面静电场与流场同享同一个解析函数的实虚部。</span>

已知 $u$ 求 $v$ 的套路叫**曲线积分法**：先由 $v_x = -u_y$、$v_y = u_x$ 得到 $dv = v_x dx + v_y dy = -u_y dx + u_x dy$，沿任意路径从定点 $(x_0,y_0)$ 积分到 $(x,y)$：

$$v(x,y) = \int_{(x_0,y_0)}^{(x,y)} -u_y\, dx + u_x\, dy + C$$

单连通区域上积分路径无关，结果唯一。**这给出了一个可操作配方：拿到一个调和函数，就能用曲线积分找回它的解析兄弟。**

## 6 延伸：C-R 方程的几何——等势线与流线

C-R 方程不只是代数条件，它还有深刻的几何图像。设 $f = u + iv$ 解析，则曲线 $u = \text{const}$（等势线）与 $v = \text{const}$（流线）处处**正交**。

验证：$u = \text{const}$ 的梯度 $\nabla u = (u_x, u_y)$ 垂直于等势线；由 C-R 方程，$\nabla u = (v_y, -v_x)$ 恰好是 $\nabla v = (v_x, v_y)$ 旋转 $90^\circ$——所以 $\nabla u \perp \nabla v$，两族曲线正交。<span class="marginnote">平面静电场里，$u$ 是电位、$v$ 是电力线（或流线）函数；C-R 方程保证了「等位面与电力线处处垂直」这一物理常识在数学上的必然性。用共轭调和函数画电场图，就是描两族正交曲线。</span>

**重点：解析函数的实虚部构成一个「正交曲线坐标系」。** 这解释了为什么解析函数能当「坐标变换」用——保角映射（第 5 节预告）把 $z$ 平面的曲线映到 $w$ 平面时保持夹角，正是因为这个正交结构。

**应用：** 已知电位 $u(x,y) = x^2 - y^2$，先验证调和（$\nabla^2 u = 4-4 = 0$），再求 $v$：$v_x = -u_y = 2y$、$v_y = u_x = 2x$，积分得 $v = 2xy + C$，于是 $f = (x^2 - y^2) + i(2xy) = z^2$——一个漂亮的解析函数。**「先验调和、再求共轭、拼成解析」** 是物理解场的标准三步。

**辨析｜易错点：** 两条曲线族正交不代表「两者夹角处处保持」——后者需要保角性（$f'\ne0$）。在 $f'(z_0)=0$ 处，映射出现临界点，正交性可能退化成其它夹角。**先查 $f'$ 是否为零，再谈保角。**

## 8 延伸练习与自查

**练习一（C-R 验证）：** 判断 $f(z) = z^2$ 是否解析。$u = x^2 - y^2$、$v = 2xy$，$u_x = 2x = v_y$、$u_y = -2y = -v_x$——**处处解析**，$f' = 2z$。

**练习二（构造共轭调和）：** 已知 $u = e^x\cos y$，求 $v$。$v_x = -u_y = e^x\sin y$，$v_y = u_x = e^x\cos y$，积分得 $v = e^x\sin y + C$，故 $f = e^z + iC$。

**练习三（极坐标 C-R）：** $f(z) = \ln r + i\theta$（主值分支）验证极坐标 C-R：$u_r = \frac1r$、$v_\theta = 1$，$u_r = \frac1r v_\theta$ 成立；$v_r = 0$、$u_\theta = 0$，第二式成立——**主值对数在割开平面上解析**。

| 练习 | 验证内容 | 结论 |
| --- | --- | --- |
| $z^2$ | 直角坐标 C-R | 解析 |
| $e^x\cos y$ 求 $v$ | 曲线积分法 | $f = e^z$ |
| $\ln r + i\theta$ | 极坐标 C-R | 割平面解析 |

<span class="marginnote">练习三是「多值函数在选定分支上解析」的示范——主值分支把 $\ln z$ 变成单值解析函数，这是复分析处理多值性的标准手法。</span>

## 9 小结

- **柯西-黎曼方程** $u_x = v_y$、$u_y = -v_x$ 是复可导的必要条件；加上 $u, v$ 可微（偏导连续）就构成充分条件。
- 极坐标形式：$u_r = \frac{1}{r}v_\theta$、$v_r = -\frac{1}{r}u_\theta$，适合 $z^n$、对数等径向问题。
- **解析函数的实部与虚部都是调和函数**，满足拉普拉斯方程 $\nabla^2 u = 0$。
- 已知调和 $u$，用曲线积分 $dv = -u_y dx + u_x dy$ 可找回共轭调和 $v$。

在下一节，我们把验证过的解析函数家族——多项式、指数、三角函数、对数——正式请上台，看看它们在复平面上长什么样子、有哪些实数世界里没有的新性质。
