## 为什么从达朗贝尔公式开始

有界区域的振动我们用分离变量法得到了级数解。可无穷长弦、整根无限长的线上的一击、或一个脉冲在媒质里传播——**级数方法要求边界，而达朗贝尔公式根本不问边界**。它的思想是：波动方程的解不是「站的」而是「跑的」——任意解都是「向右跑的波」与「向左跑的波」之和。这个「行波分解」的观点，为后面行波法与特征线法埋下伏笔，也直接回答了物理里最朴素的问题：**敲一下弦，扰动以多快的速度传多远。**<span class="marginnote">达朗贝尔 1747 年给出这个公式，比傅里叶的热方程早半个世纪。它不仅是波动方程的首次显式解，更是「特征线」思想的发源地——解被特征线分割成一个个相互独立的信息域。</span>

## 1 行波分解：$u = F(x-at) + G(x+at)$

对一维波动方程 $u_{tt} = a^2u_{xx}$，作变量代换 $\xi = x - at$、$\eta = x + at$，方程化为

$$\frac{\partial^2 u}{\partial\xi\partial\eta} = 0$$

这个方程一眼可解：先对 $\xi$ 积分得 $\frac{\partial u}{\partial\eta}$ 与 $\xi$ 无关，再对 $\eta$ 积分得

$$u(x,t) = F(\xi) + G(\eta) = F(x-at) + G(x+at)$$

**重点：波动方程的任何解都是两个行波之和。** $F(x-at)$ 以速度 $a$ 向右传播（波形保持），$G(x+at)$ 以速度 $a$ 向左传播。这就是**行波分解（traveling wave decomposition）**。<span class="marginnote">验证 $F(x-at)$ 是解：令 $u = F(\xi)$，$\xi = x-at$，则 $u_t = -aF'$、$u_{tt} = a^2F''$，$u_x = F'$、$u_{xx} = F''$，代入方程两边相等。波形不因传播而变形——一维波动方程没有色散，这是「无畸变传播」的数学陈述。</span>

**辨析｜易错点：** 行波分解只在**一维无界**波动方程上如此简单。二维、三维波动方程的行波会「留下尾巴」（惠更斯原理只在三维干净成立），有界区域则要叠加反射。**「两个行波」的简洁，是无穷长弦才有的特权。**

## 2 达朗贝尔公式

用初始条件 $u(x,0) = \varphi(x)$、$u_t(x,0) = \psi(x)$ 定出 $F, G$，得到**达朗贝尔公式（d'Alembert's formula）**：

$$u(x,t) = \frac{1}{2}\left[\varphi(x-at) + \varphi(x+at)\right] + \frac{1}{2a}\int_{x-at}^{x+at} \psi(s)\,ds$$

推导：$u(x,0) = F(x)+G(x) = \varphi(x)$，$u_t(x,0) = -aF'(x) + aG'(x) = \psi(x)$，解得 $F(x) = \frac{\varphi(x)}{2} - \frac{1}{2a}\int_0^x\psi(s)ds$，$G(x) = \frac{\varphi(x)}{2} + \frac{1}{2a}\int_0^x\psi(s)ds$，代入 $u = F(x-at)+G(x+at)$ 即得。<span class="marginnote">初速度 $\psi$ 的贡献是「速度除以 $2a$ 后对区间积分」——每一个初始速度微元都向两侧辐射一对等幅反向的波。初位移 $\varphi$ 的贡献则是对半分裂、双向传播。整个公式无需级数、无需特殊函数，一步到位。</span>

**公式的直接推论：初值只影响特征锥内的区域。** 若初始扰动只在 $x_0$ 附近，那么经过时间 $t$ 后，扰动恰好传播到 $x_0 \pm at$——**波前以速度 $a$ 推进，波后拖着振幅的余波**。

## 3 依赖区间、决定区域、影响区域

达朗贝尔公式里藏着波动方程的「因果结构」，三个概念必须分清：

**依赖区间（domain of dependence）**：$(x,t)$ 处解的值，只依赖初始数据在区间 $[x-at, x+at]$ 上的值——**过去的信息以速度 $a$ 的上界向当前点汇聚**。
**决定区域（domain of determinacy）**：初始区间 $[x_0, x_1]$ 上的数据能决定的解，局限在特征三角形 $\{(x,t): x_0+at < x < x_1-at\}$ 内——**初值「管辖」范围有限**。
**影响区域（domain of influence）**：$[x_0,x_1]$ 上的初值能影响的点，落在特征三角形 $x_0 - at \le x \le x_1 + at$ 内——**信息传播有速度上限**。<span class="marginnote">这三个概念是「信号速度有限」的数学化：任何扰动传播速度不超过 $a$，所以点 $(x,t)$ 只「知道」它过去光锥内的初值。相对论里「光锥决定因果」，波动方程里「特征锥决定因果」——同一个结构。</span>

**重点：有限传播速度是波动方程与热方程的最大差别。** 热方程的解即使初值只在一点，任意小的 $t>0$ 后整条线上都「瞬间」非零（速度无穷大）；波动方程的解严格限制在特征锥内。**一个记「热是慢炖、波是快传」，一个记「热方程扩散无穷速、波动方程传播有速限」。**

## 4 公式解析：初速度脉冲的响应

看初位移为零、初速度为一个方脉冲 $\psi(x) = v_0$（$|x|<b$）、其余为零的弦。达朗贝尔公式只剩积分项：

$$
u(x,t) = \frac{1}{2a}\int_{x-at}^{x+at} \psi(s)\,ds
$$

- **第一步，读公式**：积分区间 $[x-at, x+at]$ 与脉冲支集 $[-b, b]$ 的重叠长度决定 $u$ 的值。
- **第二步，分区域**：当 $t$ 较小时，区间与脉冲的重叠有两种情况——完全覆盖（$u = \frac{v_0}{2a}\cdot 2b = \frac{v_0 b}{a}$，弦上平直段）或部分覆盖（解是斜坡过渡）。
- **第三步，看演化**：随 $t$ 增大，两个「波前」$x = \pm b \pm at$ 向两侧外扩，脉冲变成两列振幅为 $\frac{v_0b}{2a}$ 的行波一左一右离去。**初速度脉冲不产生「静止图案」，直接分裂成两个传播的波。**

这验证了行波分解的直觉：**速度型的初始扰动 $\psi$ 化身为两个行波**，每个行波携带一半能量、沿相反方向传播。

## 5 半无界问题与反射

半无界弦 $x \ge 0$ 且端点固定 $u(0,t) = 0$：达朗贝尔公式在 $x \ge at$（尚未碰到边界）时直接适用；在 $x < at$ 时，需要把初始条件作**奇延拓**到 $x<0$（$\tilde\varphi(x) = -\varphi(-x)$，$\tilde\psi$ 同理），再套达朗贝尔公式。<span class="marginnote">奇延拓的妙处：$x=0$ 处延拓后的函数自然为零（奇函数），自动满足固定端条件。物理上等价于「一个向右的波撞上固定端，反射成一个反相向左的波」——鼓棒敲下去，敲击波碰到边缘弹回来是反的。</span>

若端点自由 $u_x(0,t) = 0$，则改用**偶延拓**——反射波同相，像「波穿过端点继续跑」的镜像。**固定端反相反射、自由端同相反射，是弦乐器与打击乐器的端点条件差异的根源。**

## 7 延伸：非齐次波动方程与杜哈梅尔原理

若波动方程带外力 $u_{tt} = a^2u_{xx} + f(x,t)$，初值为零，达朗贝尔公式要如何推广？答案是**杜哈梅尔原理（Duhamel's principle）**：把外力在每一时刻 $s$ 看成一次「初速度冲量」，再把这些冲量的响应叠加起来：

$$u(x,t) = \frac{1}{2a}\int_0^t \left[\int_{x-a(t-s)}^{x+a(t-s)} f(\xi, s)\,d\xi\right] ds$$

内层积分恰好是「在 $s$ 时刻给速度 $f(x,s)$」的达朗贝尔响应（初位移为零），外层积分把 $0$ 到 $t$ 所有时刻的冲量叠加。<span class="marginnote">杜哈梅尔原理是「线性 + 因果」的产物：每个时刻的外力独立产生一波响应，叠加时只累计过去。它与拉普拉斯变换解受迫振动殊途同归——事实上杜哈梅尔积分可以看作「对时间的卷积」的显式形式，与上一节卷积定理同一血脉。</span>

**重点：杜哈梅尔原理把「源」转译成「初速度」。** 这是一种通用的解题策略——任何线性演化方程，非齐次项都能通过「在每个时刻注入初始条件」来处理。热方程也有杜哈梅尔版本：$f(x,t)$ 看成每个时刻的「初始温度」，叠加热核响应。

**辨析｜易错点：** 杜哈梅尔积分里，内层积分区间以 $t-s$ 为半径——**「过去越久，影响半径越大」**，这正是有限传播速度的体现。若把区间误写成 $x\pm at$（不含 $s$），就失去了延迟结构，结果违背因果。先画时空图、再写积分区间，是防错的第一步。

## 9 延伸练习与自查

**练习一（达朗贝尔公式）：** 初值 $\varphi(x) = e^{-x^2}$、$\psi(x) = 0$、$a=1$，求 $u(x,t)$。公式第一项 $\frac12\left[e^{-(x-t)^2} + e^{-(x+t)^2}\right]$，两个高斯行波左右分离。

**练习二（速度初值）：** 初位移 $\varphi = 0$、初速度 $\psi = v_0$（常数）。$u = \frac{1}{2a}\int_{x-at}^{x+at}v_0 ds = v_0 t$——整个弦匀速上移，行波分量恰好拼成整体平移。

**练习三（依赖区间）：** 在 $(x,t)$ 处 $u$ 只依赖 $[x-at, x+at]$ 上的初值。若初值在 $[-1,1]$ 外为零，求 $t=2$、$a=1$ 时 $u$ 非零的 $x$ 范围。区间 $[x-2, x+2]$ 与 $[-1,1]$ 相交才非零，故 $x \in (-3, 3)$。

| 概念 | 定义 | 依赖什么 |
| --- | --- | --- |
| 依赖区间 | $[x-at, x+at]$ | 当前点 $(x,t)$ |
| 决定区域 | 特征三角形 | 初始区间 |
| 影响区域 | $x_0-at \le x \le x_1+at$ | 初始区间两端 |

<span class="marginnote">练习三是「因果结构」的直测：初值只在 $[-1,1]$ 有支撑，$t=2$ 时波前刚好扩到 $\pm3$。画一张 $x$-$t$ 图，三个概念一目了然。</span>

> **课后思考**
>
> - 达朗贝尔公式里初速度 $\psi$ 的贡献为什么带 $\frac{1}{2a}$ 因子？它的物理单位是什么？
> - 若初位移是「三角形脉冲」，画出 $t=0, t_1, t_2$ 三个时刻的解形状，验证「波形不变」。
> - 二维波动方程还有「行波分解成两个波」的简洁吗？为什么二维有尾巴而三维没有？
> - 半无界弦的奇延拓为什么能自动满足固定端条件？偶延拓对应哪种边界？
> - 杜哈梅尔原理里「每个时刻的源当初始速度」，若源是常数力，解里会出现什么项？
> - 热方程有没有「影响区域有界」的性质？为什么它与波动方程如此不同？

## 11 小结

- 波动方程任意解 = **两个行波** $F(x-at) + G(x+at)$，分别以速度 $a$ 左右传播、波形不变。
- **达朗贝尔公式** $\frac12[\varphi(x-at)+\varphi(x+at)] + \frac{1}{2a}\int_{x-at}^{x+at}\psi(s)ds$：初值直读解。
- 三个区域概念：依赖区间、决定区域、影响区域——**有限传播速度**是波动方程的因果根基。
- 热方程传播无穷速、波动方程传播有速限，二者行为截然不同。
- 半无界问题：固定端奇延拓（反相反射）、自由端偶延拓（同相反射）。

在下一节，我们把「行波与特征线」的武器库再扩充——**行波法与特征线法**将不只用于波动方程，而是推广到一般一阶拟线性方程。
