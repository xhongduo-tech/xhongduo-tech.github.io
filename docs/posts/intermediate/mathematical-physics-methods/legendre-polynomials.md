## 为什么从勒让德多项式开始

上一节的理论说：每个特殊函数都是一个斯特姆-刘维尔问题的孩子。勒让德多项式是第一个被接生出来的：当我们在**球坐标**里解拉普拉斯方程（静电势、引力势、稳态温度），角度部分 $\theta$ 的方程恰好就是勒让德方程，它的多项式解就叫**勒让德多项式**。它们是球面问题的天然正交基——从地球重力场建模、天线方向图到原子轨道的角分布，处处有它们的影子。<span class="marginnote">勒让德 1784 年在研究行星引力时引入这些多项式（当时为了展开 $\frac{1}{|\vec r - \vec r'|}$，即两点距离的倒数）。两百年后，同一个展开是电动力学里多极展开的起点，也是原子物理里角动量的数学语言。</span>

## 1 从球坐标拉普拉斯方程到勒让德方程

三维拉普拉斯方程在球坐标 $(r, \theta, \phi)$ 中分离变量 $u = R(r)\Theta(\theta)\Phi(\phi)$，角度部分在轴对称情形（与 $\phi$ 无关）满足：

$$\frac{1}{\sin\theta}\frac{d}{d\theta}\left(\sin\theta\frac{d\Theta}{d\theta}\right) + l(l+1)\Theta = 0$$

令 $x = \cos\theta$，方程变为**勒让德方程（Legendre's equation）**：

$$(1-x^2)\frac{d^2 y}{dx^2} - 2x\frac{dy}{dx} + l(l+1)y = 0$$

在 $x = \pm1$（即 $\theta = 0, \pi$）要解有限，只有 $l$ 为非负整数时存在多项式解——正是这个「有界性」筛选出本征值 $l(l+1)$ 与本征函数 $P_l(x)$。<span class="marginnote">换元 $x = \cos\theta$ 让区间变成 $[-1,1]$、端点恰好落在奇异点上。勒让德方程在 $x=\pm1$ 有奇异点，解要处处有限的要求就自动给出 $l$ 为整数——这是「边界筛选本征值」在特殊函数域的又一次上演。</span>

## 2 罗德里格公式与前几项

**勒让德多项式（Legendre polynomials）** 是勒让德方程 $l$ 取非负整数时的多项式解，由**罗德里格公式（Rodrigues' formula）** 统一给出：

$$P_l(x) = \frac{1}{2^l\,l!}\frac{d^l}{dx^l}\left[(x^2-1)^l\right], \qquad l = 0, 1, 2, \dots$$

前几项：

$$P_0 = 1, \quad P_1 = x, \quad P_2 = \frac{3x^2-1}{2}, \quad P_3 = \frac{5x^3-3x}{2}, \quad P_4 = \frac{35x^4-30x^2+3}{8}$$

**性质一览：** $P_l$ 是 $l$ 次多项式，$P_l(1) = 1$、$P_l(-1) = (-1)^l$，奇偶性与 $l$ 一致（$l$ 偶为偶函数、$l$ 奇为奇函数）。<span class="marginnote">罗德里格公式的直觉：$(x^2-1)^l$ 在 $x=\pm1$ 有 $l$ 重零点，求 $l$ 阶导后零点消失、留下一个 $l$ 次多项式；系数 $\frac{1}{2^l l!}$ 只是归一化，保证 $P_l(1)=1$。这是「从退化零点制造正交多项式」的通用模板。</span>

## 3 生成函数与递推关系

勒让德多项式藏在一条生成函数里：

$$\frac{1}{\sqrt{1 - 2xt + t^2}} = \sum_{l=0}^{\infty} P_l(x)\,t^l$$

这个式子物理意义直接：左端正是「单位电荷到场点距离的倒数」的展开——**静电学的多极展开就是勒让德级数**。由生成函数可推出最常用的三条**递推关系（recurrence relations）**：

$$(2l+1)xP_l = (l+1)P_{l+1} + lP_{l-1}$$

$$P'_{l+1} - P'_{l-1} = (2l+1)P_l$$

$$\frac{dP_{l+1}}{dx} = x\frac{dP_l}{dx} + (l+1)P_l$$

**重点：递推关系是「不查表生成高阶多项式」的引擎**——给定 $P_0, P_1$，反复用第一式就能算出任意阶。数值计算里常用它，避免存整张多项式表。<span class="marginnote">生成函数 $G(x,t) = \frac{1}{\sqrt{1-2xt+t^2}}$ 的名字「生成」名副其实：把 $G$ 对 $t$ 展开，系数就是全部 $P_l$。物理上它又是「点电荷势」的展开，这解释了勒让德多项式为何总在静电学里出现——它不是被发明，而是被「发现」在物理问题里。</span>

## 4 正交性：球面的天然正交基

**勒让德多项式的正交性**（在斯特姆-刘维尔理论里权函数 $\rho = 1$）：

$$\int_{-1}^{1} P_m(x)P_n(x)\,dx = \frac{2}{2n+1}\,\delta_{mn}$$

$n$ 次归一化范数平方 $\|P_n\|^2 = \frac{2}{2n+1}$。因此任意「足够好」的 $f(x)$ 在 $[-1,1]$ 上可按勒让德多项式展开：

$$f(x) = \sum_{n=0}^{\infty} c_n P_n(x), \qquad c_n = \frac{2n+1}{2}\int_{-1}^{1} f(x)P_n(x)\,dx$$

**这正是广义傅里叶级数在勒让德基下的具体形态。** 它与傅里叶级数的差别：基函数从三角函数换成多项式，区间从 $[-\pi,\pi]$ 换成 $[-1,1]$，系数公式多了因子 $\frac{2n+1}{2}$。<span class="marginnote">展开里的「截断到 $n$ 阶」就是工程里的「$n$ 阶近似」——比如重力场建模取到 $n=20$ 阶勒让德展开就够精细，谐波分析、球谐函数逼近都走这条路。</span>

**辨析｜易错点：** 勒让德展开的收敛判定与傅里叶级数相同（逐段光滑即逐点收敛），但**在端点 $x=\pm1$ 处**，勒让德级数的收敛行为没有傅里叶那么温和——端点处若有间断，收敛速度会变慢。判断收敛性先画区间、再看光滑性。

## 5 公式解析：罗德里格公式验证 $P_2$

用罗德里格公式实际算一遍 $l=2$，看清「求导制造多项式」的机制：

$$
P_2(x) = \frac{1}{2^2\cdot 2!}\frac{d^2}{dx^2}\left[(x^2-1)^2\right] = \frac{3x^2-1}{2}
$$

- **第一步，展开被导函数**：$(x^2-1)^2 = x^4 - 2x^2 + 1$。
- **第二步，求二阶导**：$P_2 = \frac{1}{8}\frac{d^2}{dx^2}(x^4 - 2x^2 + 1) = \frac{1}{8}(12x^2 - 4)$。
- **第三步，归一化**：$\frac{1}{8}(12x^2-4) = \frac{3}{2}x^2 - \frac12 = \frac{3x^2-1}{2}$。

验证 $P_2(1) = \frac{3-1}{2} = 1$、$P_2(-1) = 1$（偶函数），与「$P_l(1)=1$、奇偶性随 $l$」的规律吻合。**罗德里格公式 + 前几项死记 + 递推补全**，就是使用勒让德函数的全部弹药。

## 7 延伸：连带勒让德函数与球谐函数

实际球面问题很少是轴对称的——温度场、电磁场通常同时依赖 $\theta$ 与 $\phi$。完整分离变量后，角度部分方程变为**连带勒让德方程（associated Legendre equation）**：

$$(1-x^2)y'' - 2xy' + \left[l(l+1) - \frac{m^2}{1-x^2}\right]y = 0$$

解是**连带勒让德函数** $P_l^m(x) = (1-x^2)^{m/2}\frac{d^m}{dx^m}P_l(x)$（$|m| \le l$）。它与角度部分结合，构成**球谐函数（spherical harmonics）**：

$$Y_l^m(\theta,\phi) = \sqrt{\frac{2l+1}{4\pi}\frac{(l-m)!}{(l+m)!}}\,P_l^m(\cos\theta)\,e^{im\phi}$$

球谐函数是球面上的「傅里叶基」：$l$ 控制总阶数（角动量大小），$m$ 控制方位角的振荡次数（角动量投影）。<span class="marginnote">球谐函数在物理里无处不在：氢原子波函数的角度部分、地球重力场的球谐展开、麦克风阵列的波束成形。$Y_l^m$ 的正交归一性让「球面上的函数」也能像平面函数一样展开成级数——傅里叶分析从直线、圆周，一路推广到球面。</span>

**重点：$P_l^m$ 与 $P_l$ 是同一族的分支。** $m=0$ 时 $P_l^0 = P_l$ 回到勒让德多项式；$|m|>l$ 时 $P_l^m = 0$（无解）。**「方位角振荡次数不超过极角阶数」这一约束，来自球面几何的相容性。**

**辨析｜易错点：** 连带勒让德函数带因子 $(1-x^2)^{m/2}$，在 $x=\pm1$（两极）附近行为特殊，数值计算时 $m$ 大、$l$ 小时容易溢出。**球谐展开前先归一化、再检查 $m$ 的范围。**

## 9 延伸练习与自查

**练习一（罗德里格）：** 用罗德里格公式求 $P_3$：$\frac{1}{48}\frac{d^3}{dx^3}(x^2-1)^3 = \frac{5x^3-3x}{2}$，验证 $P_3(1)=1$、$P_3(-1)=-1$。

**练习二（递推）：** 用 $(2n+1)xP_n = (n+1)P_{n+1} + nP_{n-1}$ 从 $P_0=1$、$P_1=x$ 求 $P_2$：$3x\cdot x = 2P_2 + 1$，$P_2 = \frac{3x^2-1}{2}$。

**练习三（展开系数）：** 把 $f(x) = x^2$ 按勒让德多项式展开。$c_0 = \frac12\int_{-1}^1 x^2 dx = \frac13$，$c_2 = \frac52\int_{-1}^1 x^2\cdot\frac{3x^2-1}{2}dx = \frac23$，故 $x^2 = \frac13 P_0 + \frac23 P_2$——**展开在有限项处截断，因为 $x^2$ 本身是多项式**。

| 量 | 公式 | 例值 |
| --- | --- | --- |
| $P_n(1)$ | $1$ | $P_4(1)=1$ |
| 范数 | $\frac{2}{2n+1}$ | $\|P_2\|^2 = \frac25$ |
| 生成函数 | $\sum P_n t^n$ | $\frac1{\sqrt{1-2xt+t^2}}$ |

<span class="marginnote">练习三揭示了勒让德展开的一个便利：<strong>多项式函数按勒让德展开是「有限截断」的</strong>——$n$ 次多项式只需前 $n+1$ 个 $P_k$。这与傅里叶展开的「无穷级数」形成对照，也让勒让德基在多项式逼近里格外好用。</span>

## 10 小结

- 球坐标拉普拉斯方程的角度部分 → **勒让德方程**，有界性筛选出 $l$ 为非负整数。
- **勒让德多项式** $P_l$ 由罗德里格公式给出，$P_l(1)=1$，奇偶性随 $l$。
- **生成函数** $\frac{1}{\sqrt{1-2xt+t^2}} = \sum P_l t^l$ 是静电多极展开的源头。
- **正交性** $\int_{-1}^1 P_mP_ndx = \frac{2}{2n+1}\delta_{mn}$，展开系数 $c_n = \frac{2n+1}{2}\int fP_ndx$。
- 递推关系 $(2l+1)xP_l = (l+1)P_{l+1} + lP_{l-1}$ 是快速生成高阶多项式的引擎。
