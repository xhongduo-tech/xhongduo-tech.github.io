## 为什么从拉普拉斯逆变换开始

上一节我们学会了把 $f(t)$ 变成 $F(s)$，还看到「微分变乘法」能把 ODE 变成代数方程。但解方程的目的是回到时间域——**逆变换（inverse Laplace transform）才是把频域答案翻译成人话的那一步**。它有三级台阶：查表是电梯，部分分式是楼梯，留数积分是登山。实际题目九成靠前两级，但理解第三级才能真正明白「收敛域为什么重要」以及「$F(s)$ 的极点为什么决定了 $f(t)$ 的形状」。<span class="marginnote">拉普拉斯逆变换的严格定义是一条复平面上的积分（布罗姆维奇积分）：$f(t) = \frac{1}{2\pi i}\int_{\sigma_0 - i\infty}^{\sigma_0 + i\infty}F(s)e^{st}ds$。积分路径是一条竖直线，取在收敛域内——留数定理在这里是算积分的主力。</span>

## 1 查表法：直接对号入座

若 $F(s)$ 恰好是标准表里的形态，直接读出 $f(t)$。例如 $F(s) = \frac{5}{s^2+9}$ 对应 $5 \cdot \frac{1}{s^2+3^2}$ 型，查表得 $f(t) = \frac{5}{3}\sin 3t$。查表的核心是把 $F(s)$ 变形到标准形——配方、拆常数、凑系数。

**重点：查表先「凑形」再「查形」。** 看到 $s^2+2s+5$ 先配成 $(s+1)^2+2^2$，再用频移公式 $\mathcal{L}[e^{-t}\sin 2t] = \frac{2}{(s+1)^2+4}$，然后对号入座。**分母是二次式且判别式为负时，配方 + 频移是万能起手式。**<span class="marginnote">查表的「凑」不是瞎试：任何有理函数 $F(s)$ 都可以先化成真分式（分子次数低于分母），再部分分式分解成「标准件」的线性组合——这就是下一级台阶的核心。</span>

## 2 部分分式法：把 $F(s)$ 拆成标准件

设 $F(s) = \frac{P(s)}{Q(s)}$ 是真分式，把 $Q(s)$ 因式分解，$F$ 就拆成简单分式之和。关键情形：

**单根（heaviside 展开）：** 若 $Q(s)$ 有互不相同的根 $a_1, \dots, a_n$，

$$F(s) = \sum_{k=1}^{n}\frac{A_k}{s - a_k}, \qquad A_k = \left.(s-a_k)F(s)\right|_{s=a_k} = \frac{P(a_k)}{Q'(a_k)}$$

每个 $\frac{A_k}{s-a_k}$ 对应 $A_k e^{a_k t}$，逆变换是逐项读出再求和：

$$f(t) = \sum_{k=1}^{n} A_k e^{a_k t}$$

**重根处理：** 若 $a$ 是 $m$ 重根，对应部分分式 $\frac{A_1}{s-a} + \frac{A_2}{(s-a)^2} + \cdots + \frac{A_m}{(s-a)^m}$，逆变换用 $\mathcal{L}^{-1}\left[\frac{1}{(s-a)^k}\right] = \frac{t^{k-1}e^{at}}{(k-1)!}$。<span class="marginnote">重根时 $A_k$ 不再能单独用「乘 $(s-a)$ 代值」得到，因为代入后其它重根项仍发散。标准做法是逐次求导：$A_m = \frac{1}{(m-1)!}\left.\frac{d^{m-1}}{ds^{m-1}}\left[(s-a)^m F(s)\right]\right|_{s=a}$，正是极点的留数公式——两条线在这里重合。</span>

## 3 公式解析：$\mathcal{L}^{-1}\left[\frac{s+3}{s^2+4s+5}\right]$

一道综合配方 + 频移 + 查表的招牌题，分三步：

$$
\mathcal{L}^{-1}\left[\frac{s+3}{s^2+4s+5}\right] = e^{-2t}(\cos t + \sin t)
$$

- **第一步，配方**：$s^2+4s+5 = (s+2)^2 + 1$，分母是关于 $s+2$ 的 $\square^2 + 1^2$ 形。
- **第二步，拆分子对齐**：$\frac{s+3}{(s+2)^2+1} = \frac{(s+2) + 1}{(s+2)^2+1} = \frac{s+2}{(s+2)^2+1} + \frac{1}{(s+2)^2+1}$。
- **第三步，频移 + 查表**：第一项对应 $e^{-2t}\cos t$，第二项对应 $e^{-2t}\sin t$（因为 $\mathcal{L}[e^{at}\sin bt] = \frac{b}{(s-a)^2+b^2}$），相加得 $e^{-2t}(\cos t + \sin t)$。

**核心套路：把分子凑成「$(s+2)$ 的倍数加常数」，与配好的分母一一对齐**——这是「频移 + 查表」的精髓，也是二次真分式逆变换的通用流程。

## 4 布罗姆维奇积分与留数法

当 $F(s)$ 不是有理函数（比如含 $e^{-as}$ 的延迟项，或含 $\sqrt{s}$ 的多值项），查表和部分分式都失效，必须回到逆变换的定义：

$$f(t) = \frac{1}{2\pi i}\int_{\sigma_0 - i\infty}^{\sigma_0 + i\infty} F(s)e^{st}\,ds$$

**留数法（residue method）：** 把竖直线闭合成向左的围道（加上左侧大半圆），当 $t>0$ 时大半圆积分趋于零（由 $e^{st}$ 的衰减保证），于是

$$f(t) = \sum \operatorname{Res}\left(F(s)e^{st}, \text{ 所有 } s \text{ 平面奇点}\right)$$

**$F(s)$ 的极点决定了 $f(t)$ 的时间行为**：极点在 $a$，对应 $f$ 里一项 $e^{at}$；极点实部为正 → $f$ 指数发散（不稳定），实部为负 → 指数衰减（稳定），虚轴上 → 振荡。<span class="marginnote">这正是控制论「极点判稳」的数学本质：系统是否稳定，只看传递函数 $F(s)$ 的极点是否全部落在左半平面。逆变换的留数求和，把极点的位置直接翻译成响应曲线的形状——一次对应，一劳永逸。</span>

**辨析｜易错点：** 布罗姆维奇积分路径必须在收敛域内（竖线取 $\sigma_0$ 大于所有极点的实部）。若路径取错（比如落在收敛域左侧），闭合围道圈住的奇点会变化，留数求和的结果就错了。**先定收敛域，再定积分路径，最后才数奇点。**

## 5 三个方法怎么选

| 情形 | 推荐方法 | 理由 |
| --- | --- | --- |
| 标准表内 | 查表 | 最快，直接读 |
| 有理真分式 | 部分分式（Heaviside 展开） | 拆成标准件，逐项读出 |
| 单重根 | 代入公式 $A_k = P(a_k)/Q'(a_k)$ | 一步到位 |
| 重根 | 部分分式 + 求导公式 | 处理幂次 |
| 含 $e^{-as}$、$\sqrt{s}$ 等 | 留数法 / 布罗姆维奇积分 | 超越函数只能积分或特殊展开 |

实际工程里，**部分分式法的使用频率远超其它两者**——因为 ODE 解出来的 $F(s)$ 几乎都是有理函数。<span class="marginnote">延迟项 $e^{-as}F(s)$ 的处理其实还有捷径：用时移性质 $\mathcal{L}^{-1}[e^{-as}F(s)] = f(t-a)u(t-a)$，把「延迟」推迟到时间域再叠加——这是控制理论里处理时滞系统的标准手法，比硬算布罗姆维奇积分快得多。</span>

## 7 延伸：亥维赛展开公式与复数极点

实际系统的传递函数极点常常是**共轭复数对** $s = -\alpha \pm i\beta$（对应欠阻尼振荡）。此时 Heaviside 展开公式依然工作，但要会「合并共轭对」：

若 $F(s)$ 含极点 $s = -\alpha \pm i\beta$，对应时间项是 $e^{-\alpha t}(A\cos\beta t + B\sin\beta t)$——**复数极点给出衰减振荡，实部决定衰减速率、虚部决定振荡频率**。

**重点：留数法把「极点 → 时间行为」翻译表补全：**
实极点 $s = -a$ → $e^{-at}$（指数衰减，一阶系统）；
实极点 $s = a>0$ → $e^{at}$（发散，不稳定）；
共轭复极点 $s = -\alpha \pm i\beta$ → $e^{-\alpha t}(\cos\beta t \text{ 组合})$（衰减振荡）；
虚轴极点 $s = \pm i\beta$ → $\cos\beta t$（无阻尼振荡，临界稳定）。<span class="marginnote">这张翻译表是控制理论「极点配置」的直觉来源：想让学生系统的响应「快而不振」，就把极点设计成负实轴上相隔合理的实数极点；想让它振荡，就保留一对共轭复极点。设计极点 = 设计响应形状。</span>

**辨析｜易错点：** 共轭复极点成对出现时，若只算其中一个极点的留数再取实部，容易漏掉 $e^{-\alpha t}$ 前的系数因子。稳妥做法是把两个极点的留数都算出来相加，或直接套「二阶欠阻尼响应」标准形。**先识别极点类型，再选求响应的方式。**

## 9 延伸练习与自查

**练习一（部分分式）：** 求 $\mathcal{L}^{-1}\left[\frac{2s+1}{s(s+1)}\right]$。部分分式 $\frac{1}{s} + \frac{1}{s+1}$，逆变换 $1 + e^{-t}$。

**练习二（重根）：** $\mathcal{L}^{-1}\left[\frac{1}{(s+2)^3}\right] = \frac{t^2 e^{-2t}}{2}$——重根公式 $t^{k-1}e^{at}/(k-1)!$，$k=3$。

**练习三（配方）：** $\mathcal{L}^{-1}\left[\frac{1}{s^2+2s+5}\right]$。配方 $(s+1)^2+4$，对应 $e^{-t}\frac{\sin 2t}{2}$。

| 情形 | 手段 | 例子 |
| --- | --- | --- |
| 真分式单根 | Heaviside 代入 | $\frac{A}{s-a}$ |
| 重根 | 求导公式 | $\frac{t^{k-1}e^{at}}{(k-1)!}$ |
| 二次式 | 配方 + 频移 | $e^{-at}\sin bt$ |
| 延迟项 | 时移性质 | $f(t-a)u(t-a)$ |

<span class="marginnote">三个练习覆盖「单根、重根、配方」三大常规。做题先判断真分式与否——分子次数高于分母要先长除，这是最常被忽略的第一步。</span>

## 10 小结

- **逆变换三级台阶**：查表 → 部分分式 → 留数法；有理函数优先部分分式。
- **Heaviside 展开**：单根 $A_k = \left.(s-a_k)F(s)\right|_{s=a_k} = \frac{P(a_k)}{Q'(a_k)}$；重根用求导公式。
- **配方 + 频移 + 查表** 是二次真分式的通用流程，先凑形再查形。
- **留数法**：$f(t) = \sum\operatorname{Res}(Fe^{st})$，极点的位置直接决定 $f$ 的稳定性与振荡形态。
- 收敛域决定积分路径，先定域、再定路、最后数奇点。
