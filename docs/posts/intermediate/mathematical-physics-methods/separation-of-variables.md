## 为什么从分离变量法开始

三类方程认识完毕、定解条件学会提了，现在该动手求解。分离变量法是第三篇的主发动机：**假设解能写成「只含空间」与「只含时间」两部分的乘积，把偏微分方程拆成两个常微分方程**。这个假设听起来武断，却被证明有效得惊人——因为线性方程的叠加原理保证：把特殊解加起来，能配出任意初值。本征值问题、傅里叶级数、勒让德多项式、贝塞尔函数，全部在这个方法的流水线上依次登场。<span class="marginnote">分离变量法的雏形是傅里叶 1807 年解热传导方程时的「变量分离」；但当时他为了凑边界条件，硬把解写成无穷级数并争论收敛性，为此还被科学院评审驳回。百年后，这套方法才在黎曼等人的严格化下站稳脚跟。</span>

## 1 核心假设：解 = 空间 × 时间

以两端固定的弦振动为例：

$$u_{tt} = a^2 u_{xx}, \qquad u(0,t) = u(l,t) = 0$$

**假设 $u(x,t) = X(x)T(t)$**，代入方程得 $X T'' = a^2 X'' T$。把只含 $x$ 的项与只含 $t$ 的项分开：

$$\frac{X''}{X} = \frac{T''}{a^2 T} = -\lambda$$

左边只依赖 $x$、右边只依赖 $t$，而两者恒等——它们必然都等于同一个常数 $-\lambda$，这个常数叫**分离常数（separation constant）**。<span class="marginnote">「只依赖 $x$ 的量 = 只依赖 $t$ 的量」时，两者都必须是常数——这是分离变量法的逻辑支点。$-\lambda$ 前的负号是约定，让本征值 $\lambda > 0$ 时空间部分出现三角函数而非指数，正好匹配有界区域的振荡解。</span>

于是 PDE 拆成两个 ODE：

$$X'' + \lambda X = 0, \qquad T'' + a^2\lambda T = 0$$

## 2 本征值问题与边界条件筛选

边界条件 $u(0,t) = X(0)T(t) = 0$ 对所有 $t$ 成立，若 $T \not\equiv 0$ 则 $X(0) = 0$；同理 $X(l) = 0$。于是空间方程变成一个**本征值问题（eigenvalue problem）**：

$$X'' + \lambda X = 0, \qquad X(0) = X(l) = 0$$

**重点：不是所有 $\lambda$ 都有非零解。** 逐一排查：

- $\lambda < 0$：$X = C_1 e^{\sqrt{-\lambda}x} + C_2 e^{-\sqrt{-\lambda}x}$，边界条件迫使 $C_1 = C_2 = 0$，只有零解。
- $\lambda = 0$：$X = C_1 + C_2x$，边界条件同样只给零解。
- $\lambda > 0$：$X = A\cos\sqrt\lambda x + B\sin\sqrt\lambda x$，$X(0)=0$ 得 $A = 0$；$X(l) = B\sin\sqrt\lambda l = 0$ 要求 $\sqrt\lambda\,l = n\pi$。

于是本征值与本征函数被筛选出来：

$$\lambda_n = \left(\frac{n\pi}{l}\right)^2, \qquad X_n(x) = \sin\frac{n\pi x}{l}, \qquad n = 1, 2, \dots$$

**「边界条件 + 非零解」的双重要求，把连续的 $\lambda$ 筛选成分立的本征值**——这就是为什么有界区域里频率是分立的（谐波 $n=1,2,3,\dots$），与无穷域的连续频谱形成对照。<span class="marginnote">这也是量子力学里「束缚态能量量子化」的数学模板：$\lambda_n$ 就是能级，$X_n$ 就是定态波函数。分离变量法不只是数学技巧，它揭示了「有界 ⇒ 离散」这一普遍结构。</span>

## 3 时间部分与叠加

对每个 $n$，时间方程 $T'' + a^2\lambda_n T = 0$ 的解是

$$T_n(t) = A_n\cos\frac{n\pi a t}{l} + B_n\sin\frac{n\pi a t}{l}$$

于是每个 $u_n = X_n T_n$ 是方程的一个特殊解（本征振动，频率 $\omega_n = \frac{n\pi a}{l}$）。**由线性叠加原理**，一般解是它们的级数和：

$$u(x,t) = \sum_{n=1}^{\infty}\left(A_n\cos\frac{n\pi a t}{l} + B_n\sin\frac{n\pi a t}{l}\right)\sin\frac{n\pi x}{l}$$

**A 和 B 由初始条件定**：代入 $u(x,0) = \varphi(x)$ 与 $u_t(x,0) = \psi(x)$，分别得到 $\varphi$ 与 $\psi$ 的傅里叶正弦级数展开，系数为

$$A_n = \frac{2}{l}\int_0^l \varphi(x)\sin\frac{n\pi x}{l}dx, \qquad B_n = \frac{2}{n\pi a}\int_0^l \psi(x)\sin\frac{n\pi x}{l}dx$$

**流程闭环：分离 → 本征值 → 叠加 → 傅里叶系数。** 这就是分离变量法的完整流水线，几乎每个有界域问题都走这条线。<span class="marginnote">注意叠加原理在此的用法：我们只证明了每个 $u_n$ 满足方程和边界条件，而「任意线性组合仍满足」正由方程的<strong>齐次线性</strong>保证。初值条件是我们唯一「用力」的地方——把 $\varphi, \psi$ 展开成傅里叶级数，就是强迫解去匹配初始状态。</span>

## 4 公式解析：为什么 $\lambda>0$ 才「活」下来

本征值筛选是分离变量法最容易卡壳的地方，把 $\lambda > 0$ 的情形单独拆开看：

$$
X'' + \lambda X = 0, \quad X(0) = X(l) = 0 \;\Rightarrow\; \lambda_n = \frac{n^2\pi^2}{l^2}, \; X_n = \sin\frac{n\pi x}{l}
$$

三步拆解：

- **第一步，写通解**：$\lambda > 0$ 时 $X = A\cos(\sqrt\lambda\,x) + B\sin(\sqrt\lambda\,x)$——三角函数的振荡解。
- **第二步，套 $X(0)=0$**：$A\cos 0 + B\sin 0 = A = 0$，只剩正弦项 $B\sin(\sqrt\lambda x)$。
- **第三步，套 $X(l)=0$**：$B\sin(\sqrt\lambda l) = 0$。若 $B=0$ 则零解，排除；故 $\sin\sqrt\lambda l = 0$，即 $\sqrt\lambda l = n\pi$，$\lambda = (n\pi/l)^2$。

**边界条件的两次打击**——先杀掉余弦项（左端），再量化 $\lambda$（右端）——把一个「连续参数」变成「可数集」。**分离变量法的本质，就是连续问题在边界约束下产生分立本征值的过程**，这一套逻辑在勒让德、贝塞尔函数里会原样重演。

## 5 分离变量法的适用条件

分离变量法不是万能的，它有清楚的适用边界：

| 条件 | 说明 |
| --- | --- |
| 方程齐次、线性 | 非齐次需先化为齐次或另做处理 |
| 区域形状简单 | 矩形、圆、球等「可分离」坐标 |
| 边界条件齐次 | 非齐次边界需先平移变换 |

**重点：非齐次边界条件的处理——先「凑」一个满足边界条件的特解 $v$，令 $u = v + w$，$w$ 满足齐次边界，再用分离变量法解 $w$。** 这一招叫**边界条件的齐次化**，是考试高频操作。<span class="marginnote">几何上，分离变量法依赖坐标系的「可分离性」：矩形用直角坐标、圆盘用极坐标、球用球坐标。每种坐标系对应一族特殊函数（矩形→三角函数、圆盘→贝塞尔、球→勒让德），这就是后面三节的主题。</span>

**辨析｜易错点：** 分离变量法假设「$u = X(x)T(t)$」是构造性的，不等于「所有解都是这种形式」。真正合法的是：每个 $u_n$ 是乘积形式，而一般解是它们的叠加。**若初学者把「解是乘积」当唯一形式，就会漏掉初值匹配这一步**——分离变量法的完整解永远是「乘积 × 叠加 × 系数」。

## 7 延伸：分离变量法的物理直觉——驻波

分离变量法为什么「刚好能用」？背后的物理图像是**驻波（standing wave）**。两端固定的弦上，能稳定存在的振动形态是驻波：$u_n = \sin\frac{n\pi x}{l}\cos\omega_n t$——空间形状固定（$\sin\frac{n\pi x}{l}$），整体按 $\cos\omega_n t$ 起伏。每个驻波都是「时间 × 空间」的乘积，这正是分离变量假设 $u = X(x)T(t)$ 的物理来源。<span class="marginnote">「为什么解能写成乘积」的直觉：驻波是两端固定边界下唯一的「形状不变、整体振荡」的模态。任何复杂振动都是这些驻波的线性叠加——就像任何声音都是泛音的叠加。分离变量法本质上是在「找系统有哪些驻波模态」。</span>

**重点：本征频率谱 = 驻波模态表。** $\omega_n = \frac{n\pi a}{l}$ 给出的频率 $1,2,3,\dots$ 倍关系，正是弦乐器的泛音列——「基频 + 谐波」的结构不是近似，而是两端固定边界下的**精确**结果。吉他与钢琴的音色差异，本质是各阶驻波能量的配比不同。

**延伸：分离变量法 = 频谱分解。** 从信号处理的角度，分离变量法把 PDE 的解分解成本征模态（频谱），每个模态独立演化再叠加——这与傅里叶分析把信号拆成频率分量是同一个思想。**「本征函数展开」与「傅里叶展开」在更一般的斯特姆-刘维尔框架下合流。**

**辨析｜易错点：** 分离变量法得到的「驻波」只在**有界**区域成立；无界区域的解是行波（达朗贝尔公式）。**有界 → 驻波（级数），无界 → 行波（积分）**——这条分界线从分离变量法的适用条件里自然长出。

## 9 延伸练习与自查

**练习一（本征值）：** 两端固定弦 $l=\pi$、$a=1$，本征值 $\lambda_n = n^2$、频率 $\omega_n = n$——泛音频率是基频的整数倍。

**练习二（时间解）：** 对 $n$ 模态，$T_n = A_n\cos nt + B_n\sin nt$，若初速为零则 $B_n = 0$，驻波 $u = \sum A_n\sin nx\cos nt$。

**练习三（傅里叶系数）：** 初位移 $\varphi = \sin x + \frac13\sin 3x$，则 $A_1 = 1$、$A_3 = \frac13$、其余为零——**初值只激发与之重合的模态**。

| 步骤 | 操作 | 产物 |
| --- | --- | --- |
| 1 | 假设 $u = XT$ | 分离常数 $-\lambda$ |
| 2 | 边界筛选 | 本征值 $\lambda_n$ |
| 3 | 叠加 | 级数解 |
| 4 | 初值定系数 | $A_n, B_n$ |

<span class="marginnote">练习三显示分离变量法的「筛选」本性：初值形状决定了激活哪些模态。$\sin x + \frac13\sin3x$ 只命中两个模态，解的级数就两行写完——初值越「简单」、解越短。</span>

## 10 小结

- **分离变量** $u = X(x)T(t)$ 把 PDE 拆成两个 ODE，分离常数 $-\lambda$ 是枢纽。
- 空间方程 + 齐次边界 → **本征值问题**：$\lambda_n = (n\pi/l)^2$，$X_n = \sin\frac{n\pi x}{l}$。
- 时间方程给出 $\cos/\sin$ 振荡，**叠加原理**拼出一般解。
- **初始条件定系数**：$A_n, B_n$ 由 $\varphi, \psi$ 的傅里叶展开给出。
- 适用条件：齐次线性方程、简单区域、齐次边界；非齐次边界先做**齐次化**。

在下一节，我们把「本征值问题」单独拎出来放大镜观察——斯特姆-刘维尔理论将告诉我们，这类问题的解为什么总是那么好。
