## 为什么从拉普拉斯变换开始

傅里叶变换有个尴尬：信号只要长得不够快（比如 $e^{at}$，$a>0$），$\int |f|dx$ 就发散，变换不存在。而物理世界充满这样的量——放大电路的自激振荡、失控的温度场、放射性链式反应。拉普拉斯变换的补救优雅：**乘一个因子 $e^{-\sigma t}$ 强行压制增长，把不收敛的信号按回地下**。更妙的是，它把微分方程的初始条件直接织进代数方程——这就是自动控制里传递函数的根基，也是第三篇解热传导、波动方程的利器。<span class="marginnote">拉普拉斯变换在工程里几乎总指「单边拉普拉斯变换」$\mathcal{L}[f] = \int_0^\infty f(t)e^{-st}dt$，因为物理过程从 $t=0$ 开始。单边性是它「初始条件自动进场」的根源。</span>

## 1 定义与收敛域

**拉普拉斯变换（Laplace transform）：** 对定义在 $t\ge 0$ 上的函数 $f(t)$，

$$F(s) = \mathcal{L}[f](s) = \int_0^{\infty} f(t)e^{-st}\,dt, \qquad s = \sigma + i\omega$$

$s$ 是复变量。<span class="marginnote">把 $s$ 看作复频率：实部 $\sigma$ 控制衰减、虚部 $\omega$ 是振荡频率。拉普拉斯变换 = 傅里叶变换（在 $s = i\omega$ 轴上）加上实部平移的推广。</span>

**收敛域（region of convergence, ROC）：** 使积分收敛的 $\sigma$ 范围。若 $|f(t)| \le Me^{ct}$ 对某个实数 $c$ 成立，则积分在 $\sigma > c$ 时绝对收敛，$c$ 称为**收敛横坐标（abscissa of convergence）**。**收敛域决定变换是否合法，也决定逆变换时积分路径怎么画**——这是初学者最容易忽略、却在理论里绕不开的一环。

**辨析｜易错点：** 不是所有函数都有拉普拉斯变换。增长快于任何指数（如 $e^{t^2}$）的函数，收敛横坐标不存在，变换无定义。反过来，只要 $f$ 指数阶，变换就存在——条件比傅里叶宽松得多。

## 2 常用变换对

工程上拉普拉斯变换的查表是日常操作，几对最基础的必须刻进肌肉记忆：

| $f(t)$ | $F(s)$ | 收敛域 |
| --- | --- | --- |
| $1$ | $\frac{1}{s}$ | $\operatorname{Re} s > 0$ |
| $t^n$（$n$ 非负整数） | $\frac{n!}{s^{n+1}}$ | $\operatorname{Re} s > 0$ |
| $e^{at}$ | $\frac{1}{s-a}$ | $\operatorname{Re} s > \operatorname{Re} a$ |
| $\sin at$ | $\frac{a}{s^2 + a^2}$ | $\operatorname{Re} s > 0$ |
| $\cos at$ | $\frac{s}{s^2 + a^2}$ | $\operatorname{Re} s > 0$ |
| $\delta(t)$ | $1$ | 全平面 |

**重点：$e^{at}$ 的变换 $\frac{1}{s-a}$ 是所有其它对的模板**——$\sin at$、$\cos at$ 正是用欧拉公式写成 $e^{\pm iat}$ 的组合再线性叠加出来的。把 $e^{at}$ 记住，一族的变换都到手了。<span class="marginnote">注意 $t^n$ 的变换 $\frac{n!}{s^{n+1}}$：分母指数比次数高一次，配合积分性质 $\mathcal{L}[\int_0^t f] = F(s)/s$（除 $s$）可以递归验证。查表时若遇到 $\frac{1}{(s+a)^n}$，逆向就是 $t^{n-1}e^{-at}/(n-1)!$。</span>

## 3 基本性质：微分变乘法是主角

拉普拉斯变换的性质与傅里叶几乎平行，但**微分性质**含金量完全不同：

$$\mathcal{L}[f'(t)] = sF(s) - f(0^+)$$

$$\mathcal{L}[f''(t)] = s^2 F(s) - s f(0^+) - f'(0^+)$$

**初始条件 $f(0^+)$、$f'(0^+)$ 出现在公式里，这正是「拉普拉斯变换自动携带初值」的机制。** 高阶情形可归纳为：

$$\mathcal{L}[f^{(n)}(t)] = s^n F(s) - s^{n-1}f(0^+) - \cdots - f^{(n-1)}(0^+)$$

其余常用性质：时移 $\mathcal{L}[f(t-a)u(t-a)] = e^{-as}F(s)$（$u$ 是单位阶跃）、频移 $\mathcal{L}[e^{at}f(t)] = F(s-a)$、尺度 $\mathcal{L}[f(at)] = \frac{1}{a}F(s/a)$、卷积 $\mathcal{L}[f*g] = F(s)G(s)$。<span class="marginnote">时移性质依赖 $u(t-a)$ 的「滞后」信号，是因为单边变换只从 $0$ 积分。阶跃函数 $u(t-a)$ 正是「把信号从 $t=a$ 才打开」的开关，这是自动控制里「延迟环节」的数学化身。</span>

**重点：有了「微分变乘法」+「卷积变乘法」，常微分方程变成代数方程，积分方程变成代数方程。** 求导的代价是引入初始条件，这正是「解初值问题」所需要的全部信息。

## 4 初值定理与终值定理

两个「读状态」的定理，在不做逆变换的前提下直接从 $F(s)$ 读出时间函数的极限：

**初值定理（initial value theorem）：**

$$f(0^+) = \lim_{s\to\infty} sF(s)$$

**终值定理（final value theorem）：**

$$\lim_{t\to\infty} f(t) = \lim_{s\to 0} sF(s)$$

**辨析｜易错点：** 终值定理有前提——$sF(s)$ 的所有奇点必须位于左半平面（除原点处允许一个单极点）。若 $F$ 有虚轴上的极点（如 $\frac{1}{s^2+1}$），终值定理给不出正确结果，因为 $f$ 在 $\infty$ 处振荡、极限不存在。**先检查极点位置，再用终值定理。**<span class="marginnote">自动控制里，终值定理用来算稳态误差：输入阶跃后系统最终稳定在多少。若极点在右半平面，系统本就不稳定，「终值」没有意义——所以控制论先用极点判稳定，再谈终值。</span>

## 5 公式解析：$\mathcal{L}[t^n] = \frac{n!}{s^{n+1}}$

这条变换对是整个表格的「递归引擎」，用分部积分证明：

$$
\mathcal{L}[t^n] = \int_0^\infty t^n e^{-st}dt = \frac{n!}{s^{n+1}}
$$

三步拆解：

- **第一步，分部积分一次**：$\int_0^\infty t^n e^{-st}dt = \left[-\frac{t^n}{s}e^{-st}\right]_0^\infty + \frac{n}{s}\int_0^\infty t^{n-1}e^{-st}dt$。代入上下限时，只要 $\sigma>0$，$t^n e^{-st} \to 0$（指数压制多项式），首项为零。
- **第二步，提炼递推**：得到 $\mathcal{L}[t^n] = \frac{n}{s}\mathcal{L}[t^{n-1}]$——次数每降一次，分母多乘一个 $s$。
- **第三步，递推到 $n=0$**：$\mathcal{L}[t^0] = \int_0^\infty e^{-st}dt = \frac{1}{s}$，连续递推 $n$ 次得 $\frac{n!}{s^{n+1}}$。

这个递推展示了拉普拉斯变换「以初值为锚、逐级归纳」的风格——**递推关系配合一个基础情形，就能生成整张表**。它与第三篇里贝塞尔函数的递推公式是同一类数学结构。

## 7 延伸：拉普拉斯变换与传递函数

拉普拉斯变换在工程里最大的意义，是锻造了**传递函数（transfer function）**这把钥匙。对 LTI 系统的常微分方程 $\sum a_n y^{(n)} = \sum b_m f^{(m)}$，在零初始条件下取拉普拉斯变换：

$$H(s) = \frac{Y(s)}{F(s)} = \frac{b_M s^M + \cdots + b_0}{a_N s^N + \cdots + a_0}$$

输出 = 输入 × 传递函数：$Y(s) = H(s)F(s)$。**系统的一切「个性」都封存在 $H(s)$ 里**——极点是系统固有动态，零点是输入-输出耦合的静音点。<span class="marginnote">传递函数让「系统设计」变成「多项式设计」：想让系统稳定，极点都在左半平面；想要某种滤波特性，就配零极点的位置。伯德图、根轨迹、奈奎斯特图——控制理论的地图全画在 $H(s)$ 这张帆布上。</span>

**重点：$H(s)$ 的物理测量极其简单。** 给系统输入一个冲激 $\delta(t)$，输出的拉普拉斯变换恰好就是 $H(s)$；给输入阶跃，输出变换是 $H(s)/s$。**「测冲激响应 = 测传递函数」**——这是系统辨识（system identification）的基本原理。

**辨析｜易错点：** 传递函数要求**零初始条件**。若系统初始状态非零，$Y(s) = H(s)F(s) + (\text{初值项})$——忽略初值项会把「系统响应」算成纯「输入响应」，漏掉自由响应部分。**先归零初值，再写传递函数。**

**延伸对照：** 传递函数与格林函数是「同一思想的两个版本」——一个在频域（拉普拉斯）、一个在时域（冲激响应），二者互为拉普拉斯变换对。频率域的 $H(s)$ 与时域的 $h(t)$ 之间，就是逆变换那座桥。

## 9 延伸练习与自查

**练习一（收敛域）：** $f(t) = e^{5t}$ 的收敛横坐标是 $5$——$\mathcal{L}$ 只在 $\operatorname{Re}s > 5$ 收敛，对应 $F(s) = \frac1{s-5}$ 的极点位置。

**练习二（微分性质）：** 求 $\mathcal{L}[\sin at]$ 用微分性质：$\sin'' = -a^2\sin$，两边变换 $s^2F - s\sin 0 - a\cos 0 = -a^2F$，得 $F = \frac{a}{s^2+a^2}$——**不查表也能推**。

**练习三（终值定理）：** 用终值定理求 $F(s) = \frac{1}{s(s+2)}$ 对应 $f$ 的极限：$\lim_{t\to\infty}f = \lim_{s\to0}sF = \lim_{s\to0}\frac1{s+2} = \frac12$——一阶系统阶跃响应的稳态值。

| 定理 | 公式 | 前提 |
| --- | --- | --- |
| 微分 | $\mathcal{L}[f'] = sF - f(0)$ | 指数阶 |
| 初值 | $\lim_{s\to\infty}sF = f(0^+)$ | 极限存在 |
| 终值 | $\lim_{s\to0}sF = f(\infty)$ | 极点全在左半平面 |

<span class="marginnote">练习二的「微分性质反推变换对」是最省记忆的技巧：知道 $\sin$ 的微分方程，就推出它的拉普拉斯变换——不必背整张表，背几条性质就够。</span>

## 10 小结

- **拉普拉斯变换** $F(s) = \int_0^\infty f(t)e^{-st}dt$，$s = \sigma+i\omega$；单边性让初始条件自动进场。
- **收敛域**由收敛横坐标刻画：$f$ 指数阶即变换存在，比傅里叶宽得多。
- **常用变换对**：$1 \leftrightarrow \frac1s$、$t^n \leftrightarrow \frac{n!}{s^{n+1}}$、$e^{at}\leftrightarrow\frac{1}{s-a}$、$\sin/\cos$ 由欧拉公式合成。
- **微分变乘法** $\mathcal{L}[f'] = sF - f(0^+)$ 是解 ODE 的引擎，**卷积变乘法**把积分方程代数化。
- 初值/终值定理直接从 $F(s)$ 读极限，终值定理先检查极点位置。
