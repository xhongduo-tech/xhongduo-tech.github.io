## 为什么从初等解析函数开始

有了 C-R 方程这把尺子，我们要把所有熟知的初等函数搬到复平面上，逐一丈量它们的解析性。这份「搬家」收获惊人：**指数函数变成周期函数，三角函数不再有界，对数不再是单值函数**。这些新习性不是病态，而正是复分析丰富性的源头——傅里叶变换的收敛条件、积分变换的收敛域、多值函数的支点与割线，全都扎根于此。<span class="marginnote">梁昆淼的教材把「初等解析函数」放在复变函数前三章的核心位置，正是因为之后的一切——幂级数、留数、特殊函数——都要以这里定义的函数为原料。</span>

## 1 复指数函数：用级数定义

**复指数函数（complex exponential）** 由幂级数直接定义：

$$e^z = \sum_{n=0}^{\infty} \frac{z^n}{n!} = 1 + z + \frac{z^2}{2!} + \cdots$$

当 $z = i\theta$ 时，把实部虚部分开，恰好回收欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$。由此得指数函数的直角坐标展开：

$$e^{x + iy} = e^x (\cos y + i\sin y)$$

**复指数函数的核心新性质是周期性：** 因为 $\cos y$ 与 $\sin y$ 的周期是 $2\pi$，

$$e^{z + 2\pi i} = e^z$$

**复指数以 $2\pi i$ 为基本周期。** 实数里指数函数单调递增、绝无周期，复数里它变成周期函数——这是「复数世界刷新实数常识」的第一个实例。<span class="marginnote">这个周期性意义深远：$e^z$ 把 $z$ 平面上的一条水平带「卷」成 $w$ 平面上去掉原点的整个平面。把复平面映射到复平面（排除原点）是满射，但每个像对应无穷多个原像，差 $2\pi i k$。</span>

由指数函数可验证 C-R 方程：$u = e^x\cos y$，$v = e^x\sin y$，直接算 $u_x = v_y$、$u_y = -v_x$ 恒成立，故 $e^z$ **在全平面解析**，且 $f'(z) = e^z$。

## 2 复三角函数：有界性破产

用欧拉公式反解，定义**复正弦与复余弦**：

$$\sin z = \frac{e^{iz} - e^{-iz}}{2i}, \qquad \cos z = \frac{e^{iz} + e^{-iz}}{2}$$

当 $z = x$ 为实数时回到熟知的三角函数。复正弦的实虚部分解为：

$$\sin(x + iy) = \sin x \cosh y + i\cos x \sinh y$$

**重点：复三角函数在复平面上不再有界。** 实数里 $|\sin x| \le 1$ 的铁律，在复数里失效——因为 $\cosh y$ 与 $\sinh y$ 随 $y$ 指数增长。例如 $\sin(i) = i\sinh 1 \approx 1.175i$，模超过 1。

**辨析｜易错点：** 很多初学者把实三角恒等式想当然搬到复数。事实上加法定理、倍角公式在复平面依然成立（因为它们是多项式恒等式的推广），但**有界性、单调性这些与分析相关的性质全体失效**。判断标准：凡由解析恒等式导出的结论仍真，凡涉及不等式（$\le$）的结论一律可疑。此外 $\sin z$ 的零点仍是 $k\pi$，这来自 $\sin z = 0 \iff e^{iz} = e^{-iz} \iff e^{2iz} = 1 \iff z = k\pi$。

## 3 双曲函数与反三角

**双曲函数（hyperbolic functions）** 用指数对称组合定义：

$$\cosh z = \frac{e^z + e^{-z}}{2}, \qquad \sinh z = \frac{e^z - e^{-z}}{2}$$

它们与三角函数的联系一目了然：

$$\sin iz = i\sinh z, \qquad \cos iz = \cosh z, \qquad \cosh^2 z - \sinh^2 z = 1`$$<span class="marginnote">这一族关系在物理学里反复出现：阻尼振动、狭义相对论的洛伦兹变换、双曲型偏微分方程（波动方程）的名字都来自 $\cosh, \sinh$。波动方程之所以叫「双曲型」，正是因为其特征形式对应双曲方程。</span>

**反三角函数**由对数定义，例如：

$$\arcsin z = -i\ln\left(iz + \sqrt{1 - z^2}\right)$$

因为右端含有对数与根号，反三角函数在复数世界里天然是多值函数——这把我们引向下一节的重头戏：多值性。

## 4 复对数：多值性的登场

**复对数（complex logarithm）** 定义为指数函数的反函数：若 $e^w = z$，则 $w = \operatorname{Ln} z$。设 $z = re^{i\theta}$，$w = u + iv$，则 $e^u = r$、$v = \theta + 2k\pi$，于是：

$$\operatorname{Ln} z = \ln r + i(\theta + 2k\pi), \qquad k \in \mathbb{Z}$$

**复对数是无穷多值函数。** 其中 $k = 0$ 对应的值称为**主值（principal value）**，记作：

$$\ln z = \ln|z| + i\arg z, \qquad -\pi < \arg z \le \pi$$

**辨析｜易错点：** 实数里 $\ln(ab) = \ln a + \ln b$ 无条件成立；复数里它只在相差 $2\pi i$ 的整数倍意义下成立，即 $\operatorname{Ln}(z_1 z_2) = \operatorname{Ln} z_1 + \operatorname{Ln} z_2 + 2k\pi i$。**多值性让「等号」变得模糊**——这是复对数让初学者最头疼、也最需要习惯的一点。<span class="marginnote">「主值」的选择不是唯一的，有的书用 $0 \le \arg z < 2\pi$。关键是选定后要一致。辐角的主值区间 $(-\pi, \pi]$ 对应在负实轴上割开复平面——这条缝叫<strong>支割线（branch cut）</strong>，而原点称为<strong>支点（branch point）</strong>。绕着原点走一圈，对数变一次 $2\pi i$，回不到原值。</span>

## 5 公式解析：复幂函数 $z^\alpha$

一般幂函数定义为 $z^\alpha = e^{\alpha \operatorname{Ln} z}$，其多值性完全继承自对数：

$$
z^\alpha = e^{\alpha(\ln r + i\theta + 2k\pi i)} = r^\alpha e^{i\alpha\theta} \cdot e^{2k\pi i\alpha}, \qquad k \in \mathbb{Z}
$$

三步拆解：

- **第一步，翻译定义**：$z^\alpha = e^{\alpha\operatorname{Ln} z}$，把对数换成主值加 $2k\pi i$。
- **第二步，拆出主值项**：$e^{\alpha\ln r + i\alpha\theta}$ 是主值分支，等于 $r^\alpha e^{i\alpha\theta}$，这是一个确定的复数。
- **第三步，看多值因子**：剩下 $e^{2k\pi i\alpha}$。若 $\alpha$ 为整数，该因子恒为 $1$，$z^\alpha$ 单值（如 $z^n$）；若 $\alpha = \frac{p}{q}$ 为有理数，得 $q$ 个不同值（$n$ 次方根）；若 $\alpha$ 为无理数或虚数，则得到**无穷多值**。

这解释了上一节的单位根公式为什么有 $n$ 个值：$\alpha = 1/n$ 时 $e^{2k\pi i/n}$ 恰好跑遍 $n$ 个单位根。**多值性的根数由 $\alpha$ 的「类型」决定：整数→单值，有理数→有限多值，无理/虚数→无限多值。**

## 7 延伸：$\zeta$ 函数与黎曼面

多值函数（复对数、复幂函数）带来的「多值性」，催生了复分析里最美的几何对象——**黎曼面（Riemann surface）**。以 $\ln z$ 为例：辐角每绕原点一周增加 $2\pi i$，$\operatorname{Ln} z$ 就「换一层」——把无穷多层复平面按螺旋方式粘起来，得到一张「无限多层」的曲面，$\ln z$ 在这张曲面上变成**单值**的。<span class="marginnote">黎曼 1851 年提出黎曼面：与其让函数多值，不如让「定义域」多一层。这把多值函数的「病态」转译成曲面的「几何」。今天的黎曼面理论是代数几何与弦理论的核心语言，而它的起点就是中学就能问出的问题：$\sqrt{z}$ 为什么有两个值？</span>

**黎曼 $\zeta$ 函数**是这条线上的明星：$\zeta(s) = \sum_{n=1}^\infty \frac{1}{n^s}$（$\operatorname{Re}s > 1$ 收敛），通过解析延拓（第一篇第 7 节的概念）延拓到整个复平面。它在 $s=1$ 有简单极点，在负偶数 $s=-2,-4,\dots$ 有平凡零点，其余零点都落在临界带 $0<\operatorname{Re}s<1$ 内——**黎曼猜想（Riemann hypothesis）**断言它们全在 $\operatorname{Re}s = \frac12$ 这条线上，是当今数学最大的未解问题之一。<span class="marginnote">$\zeta$ 函数是解析延拓、多值性、零点分布三大主题的汇合点：定义域从半平面延拓到全平面，需要处理分支与极点；零点的分布与素数定理（$\pi(x) \sim x/\ln x$）直接挂钩。一个「数论函数」的复分析研究，牵引着整个分析数论的走向。</span>

**重点：多值性不是缺陷，是「更大定义域」的入口。** 每次遇到多值函数，想想「它住在哪张黎曼面上」——这张曲面上的单值函数，才是它的本来面目。这是复分析「从函数看几何、从几何看函数」的双向训练。

**辨析｜易错点：** $\zeta$ 的级数定义只在 $\operatorname{Re}s>1$ 有效，讨论 $s=0$ 或 $s=\frac12$ 时必须用解析延拓后的定义。**「级数收敛范围」与「函数定义范围」在解析延拓后不再重合**——这是初学最常踩的坑。

## 9 延伸练习与自查

**练习一（周期验证）：** $e^{z + 2\pi i} = e^z$，验证 $e^z$ 的基本周期是 $2\pi i$：设 $e^{z+T} = e^z$ 对一切 $z$ 成立，则 $e^T = 1$，$T = 2\pi ik$——最小正周期 $2\pi i$。

**练习二（多值性）：** 求 $\operatorname{Ln}(-1)$ 的全部值。$-1 = e^{i\pi}$，$\operatorname{Ln}(-1) = i\pi + 2k\pi i$——主值 $\pi i$，全体 $i(2k+1)\pi$。

**练习三（幂函数）：** $i^i$ 的值。$i^i = e^{i\operatorname{Ln} i} = e^{i(i\pi/2 + 2k\pi i)} = e^{-\pi/2 - 2k\pi}$——**无穷多个实数**，主值为 $e^{-\pi/2} \approx 0.208$，这是「$i^i$ 是实数」这个著名悖论的精确答案。

| 函数 | 单值/多值 | 周期/分支 |
| --- | --- | --- |
| $e^z$ | 单值 | 周期 $2\pi i$ |
| $\ln z$ | 无穷多值 | 支点 $0$ |
| $z^\alpha$（无理数） | 无穷多值 | 依赖 $\alpha$ |

<span class="marginnote">练习三是最著名的复数恒等式之一：「$i^i$ 等于一个实数」——因为它等于 $e^{-\pi/2}$（主值）。「$i$ 的 $i$ 次方」听起来病态，用指数-对数定义一算，竟落在实轴上。多值性的意义由此一目了然。</span>

## 10 小结

- **指数函数** $e^z$ 全平面解析，以 $2\pi i$ 为周期；**复三角函数不再有界**，但有界性之外的分析恒等式仍成立。
- 双曲函数与三角函数通过 $\sin iz = i\sinh z$ 等公式互换，洛伦兹变换、波动方程都与它们同源。
- **复对数无穷多值**，主值 $\ln z = \ln|z| + i\arg z$；多值性来自辐角绕支点一周的变化 $2\pi i$。
- **复幂函数** $z^\alpha$ 的多值根数由 $\alpha$ 决定：整数单值、有理数有限多值、无理/虚数无限多值。
