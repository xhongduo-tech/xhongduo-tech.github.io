## 为什么从「数值模拟」开始

前几篇的解析解（泰斯、Theis、ADE 解析解）都要求含水层「均质、规则、简单边界」。但真实的含水层是**非均质**的：有透镜体、有断层、有变化的厚度，边界弯弯曲曲，还要同时承受抽水井、河流、补给、蒸散的共同作用。<span class="marginnote">解析解能处理的是「圆形的井在无限均质介质里」，而工程问题往往是「弯弯曲曲的河岸、一层夹一层的砂黏互层、几十口井同时抽水」。解析解在这里无能为力，只能求助于数值方法。</span>

**数值模拟**把连续的地下世界切成小块，在每个小块上把微分方程近似成代数方程，再交给计算机联立求解。自 1980 年代 USGS 发布 **MODFLOW** 以来，它已成为全世界地下水模拟的事实标准。这一篇讲透 MODFLOW 背后的思想：离散化、有限差分、模块化、校准与不确定性。

## 1 为什么解析解不够用

解析解是「精确但受限于假设」的闭式公式；数值解是「近似但普适」的离散化计算。两条路的分水岭在于：

**非均质性**：$K$ 在空间上变化，解析解只能取一个等效常数；数值模型可以为每个网格单元赋不同的 $K$。
**不规则边界**：河流、断层、含水层尖灭构成的复杂边界，解析解难以表述，数值模型用网格直接贴合。
**联合应力**：多个抽水井、补给、河流渗漏同时作用，解析解靠叠加原理勉强处理，数值模型天然支持。

**辨析｜易错点：**数值模型「近似但不粗糙」——它的误差来自离散化（网格太粗）与参数不确定性，而非方法本身的局限。一个网格足够细、参数足够准的数值模型，可以非常接近真实含水层；反之，参数拍脑袋的模型再精细也是「精确的错误」。<span class="marginnote">数值模拟界有句老话：Garbage In, Garbage Out（进垃圾、出垃圾）。模型质量的上限由水文地质概念模型与数据质量决定，而不是由求解器精度决定。</span>

一个经典反例：把一口抽水井放进化简的解析模型，模型算出的降深与实测差几倍——不是公式错，而是含水层里有低渗透透镜体，等效 $K$ 根本不存在。数值模型能把透镜体「画」出来，这是它不可替代的原因。

## 2 离散化：把连续世界切块

数值模拟的第一步是把含水层切成网格：

**水平网格**：把研究区分成行、列矩形单元。源汇（井、河流、补给）落在具体单元上；水头在每个单元的中心（或角点）处求解。
**垂向分层**：把含水层沿深度分为若干层，每层可代表不同岩性。MODFLOW 用**块中心有限差分**，水头定义在单元中心。<span class="marginnote">网格就像照片的像素：网格越细，「照片」越清晰，但单元数成平方增长、计算量暴涨。工程上在井附近、边界附近加密，远处放宽——「局部加密」是平衡精度与成本的标准手法。</span>

网格设计的工程准则：单元长宽比尽量接近 1（过长条单元会引入各向异性误差）；行列方向尽量与主流向一致；井、河、断层等关键对象沿网格线或网格中心对齐；跨层单元厚度变化要平缓，突变处加密。MODFLOW 的网格编号有严格约定——行沿 y、列沿 x、层自上而下，应力期与时间步逐级递进，这些约定让不同建模者能交换输入文件而不产生歧义。

建模需要的数据清单：含水层分层与厚度（钻孔与地球物理解释）、$K$ 与 $S_s$（抽水试验反演，见第六篇）、补给量（水均衡与氯离子平衡，见第十二篇）、水位观测序列（校准用）。数据越扎实，模型越可信——建模 80% 的时间花在数据整理上并不夸张。

时间也要离散化：把模拟期切成**应力期（stress period）**（每期内应力不变，如枯水期、丰水期），每个应力期内再切**时间步**（可自动加密）。瞬态模拟逐时间步推进，稳态模拟只求最终平衡态。

## 3 有限差分：用代数代替微积分

有限差分的核心思想：**用差商近似微商**。对一维二阶导：

$$\frac{\partial^2 h}{\partial x^2} \approx \frac{h_{i+1} - 2h_i + h_{i-1}}{\Delta x^2}$$

把二阶导的近似代入稳态流方程，二维情形得到「五点格式」：

$$h_{i+1,j} + h_{i-1,j} + h_{i,j+1} + h_{i,j-1} - 4h_{i,j} = 0$$

每个网格单元写出一条这样的方程，未知数是各单元的水头 $h_{i,j}$，联立起来就是一个大型线性方程组 $[A]\{h\} = \{b\}$。<span class="marginnote">矩阵 $[A]$ 是稀疏的——每个方程只涉及本单元与四个邻居，非零元集中在主对角线附近。稀疏矩阵用迭代法（如共轭梯度、强隐式 SIP）求解，收敛快、省内存，这正是现代求解器的核心优化点。</span>

**辨析｜易错点：**差分格式的误差随网格尺寸平方下降（二阶精度），但网格太粗会把「井」这样的点源「抹平」——井附近的降深会被系统性低估。细网格 + 井的解析解内嵌（MODFLOW 的井包）是标准补救。

瞬态离散还有**稳定性**问题：显式格式对时间步有上限（如 $D\Delta t/\Delta x^2 \lt  0.5$），超限就发散；MODFLOW 采用无条件稳定的隐式格式，时间步可以放宽，但每个时间步都要解一次线性方程组。精度与稳定性的权衡，是数值方法课程的核心议题——这一篇只是「借用」其结论。

求解器本身也在进化：从早期的 SIP、PCG，到现代的 GMG（几何多重网格）、LGM（层间聚合）与 Krylov 族，MODFLOW 6 的求解器会针对不同问题自动选择。求解器收敛标准（如水头变化小于 $10^{-4}$ m）要设置合理——太松精度不足，太紧浪费时间。

## 4 MODFLOW 的模块化结构

MODFLOW 的伟大之处在于**模块化**：把物理过程拆成独立「包（package）」，用户按需组合：

**含水层包**：描述水流主体（LAY、BCF 或 LPF/HUF 包），设定每层每单元的 $K$、$S_s$、厚度。
**应力包**：描述边界与水收支——**井包（WEL）**、**补给包（RCH）**、**蒸散发包（EVT）**、**河流包（RIV）**、**排水包（DRN）**、**一般水头边界包（GHB）**。<span class="marginnote">把「井、雨、蒸发、河、排水沟」各自装进独立模块，新增一种过程只需加一个新包，不必重写求解器——这套插件式架构让 MODFLOW 活了几十年，衍生出 MT3DMS（溶质）、SEAWAT（咸淡水）、MODPATH（粒子追踪）等整个家族。</span>

MODFLOW 的流动解还是**溶质运移**的基础：把每时间步算出的流速场喂给 MT3DMS，就能模拟污染物浓度演化；把流速场喂给 MODPATH，就能追踪粒子的运移路径——「流动解 → 运移解」的耦合，让一个模型同时回答「水往哪流」与「污染去哪」。

**时间控制**：应力期—时间步的两级结构，配合自动时间步长控制，保证瞬态计算的稳定性与精度。

## 5 边界条件与初始条件：模型的「锚」

数值模型必须给定两类约束才能求解：

**初始条件**：模拟开始时每个单元的水头分布（瞬态模拟必需；稳态模拟不需要）。
**边界条件**：与外部环境的交互——定水头边界（大湖、大江，水头恒定）、定通量边界（补给率给定）、隔水边界（零通量）。<span class="marginnote">边界条件的选择是建模中最容易被「刻舟求剑」的地方：模型边界应取在含水层的自然边界（分水岭、基岩露头、河流）上，而不是「地图画到哪算哪」。边界取得太近，模拟结果会被边界假象污染。</span>

**辨析｜易错点：**把「含水层延伸很远」直接用定水头边界截断，会在边界附近制造虚假的补给或排泄。工程上常把边界外移数公里，或用通量边界代替水头边界，减小人为影响。

初始条件的常用做法：先跑一个长时段的稳态模拟（无应力），得到稳定水位场作为瞬态模拟的初值——这叫「冷启动预热」。若初始场与真实水位差太多，瞬态早期结果会剧烈震荡，需要丢弃前几个应力期作为「预热期」。

## 6 模型校准与不确定性：让模型对齐现实

模型建好只是开始，**校准**才是灵魂。流程是：

**试错校准**：手工调整 $K$、$S_s$ 等参数，反复运行模型，使模拟水头/流量尽量贴合观测值——观察模拟降深 vs 实测降深的散点图，目标是对角线附近的聚集。
**自动校准**：用优化算法（如 PEST）自动调整参数，最小化模拟与实测的残差，一次可调几十上百个参数。<span class="marginnote">自动校准不是「按个按钮就万事大吉」：参数越多、观测越少，反演越病态，会出现「多组参数同样拟合得好」。给模型做灵敏度分析与参数不确定性量化（UCODE、PEST 的 SVD 分析），是现代校准的标配。</span>

**验证与预报**：用独立时间段的数据检验模型（验证），再用于预报未来。预报必须带不确定性区间——「模型说水位会下降 3 米」应读作「有 90% 置信度下降 2.5–3.5 米」。

建模的起点永远是**水文地质概念模型**：含水层怎么分层、补给从哪来、边界在哪、水流总体方向如何。概念模型错了，再精密的数值模型也是错上加错——行业里称之为「概念模型陷阱」。一份规范的建模报告按「概念模型 → 数值实现 → 校准 → 验证 → 预报 → 不确定性」的结构组织，每一步都有可追溯的证据。

模型的可信度最终要靠**拟合统计量**说话：均方根误差（RMSE）、归一化均方根误差（NRMSE）、水头残差分布，业内对不同类型模型有经验阈值——校准报告里没有统计量，就像体检报告没有化验单。

## 7 公式解析：二维稳态流的五点格式

$$\frac{h_{i+1,j} - 2h_{i,j} + h_{i-1,j}}{\Delta x^2} + \frac{h_{i,j+1} - 2h_{i,j} + h_{i,j-1}}{\Delta y^2} = 0$$

- **第一步，横轴二阶导**：$(h_{i+1,j} - 2h_{i,j} + h_{i-1,j})/\Delta x^2$ 是 $\partial^2h/\partial x^2$ 的中心差分，用左右邻居与本点线性组合。
- **第二步，纵轴二阶导**：同理解 $\partial^2h/\partial y^2$，两项相加即二维拉普拉斯算子 $\nabla^2 h$。
- **第三步，五点加权平均**：合并后 $h_{i,j} = (h_{i+1,j} + h_{i-1,j} + h_{i,j+1} + h_{i,j-1})/4$——**每个单元的水头恰是其四个邻居的平均**，这正是「稳态无源流场处处满足调和平均」的离散版本。
