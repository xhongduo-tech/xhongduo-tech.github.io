## 为什么从「非饱和带与入渗」开始

前几篇我们都假定含水层是「满的」——孔隙被水完全填满，这是**饱和带（saturated zone）**。但地下水循环的起点在地表：**雨水先穿过土壤与岩石的干燥层，才能抵达潜水面**。这层位于地表与潜水面之间、孔隙中水气共存的过渡带，叫**非饱和带**或**包气带（unsaturated zone / vadose zone）**。<span class="marginnote">包气带既不是「空的」，也不是「饱和的」：孔隙中同时有水和空气。正是这层「半干半湿」的介质，决定了降雨有多少变成地下水、多少变成径流。</span>

**入渗（infiltration）**是水进入土壤表面的过程，**补给（recharge）**则是水穿过包气带最终到达潜水面的部分。两者之差被蒸散发、土壤储水与侧向径流吃掉。理解这条「过安检」的通道，是评估地下水可再生性的第一关。在「从极限到大模型」的知识地图上，这一篇把气象水文（降水）与地下水系统正式接通。

## 1 包气带：从地表到潜水面

自上而下，包气带常分为三层：

**土壤带（soil zone）**：最上层，富含有机质与根系，孔隙最活跃，蒸发与植物蒸腾都发生在这里。
**中间带（intermediate zone）**：连接土壤带与毛细带的过渡层，厚度可从小到几厘米、大到上百米（干旱区）。
**毛细带（capillary fringe）**：紧贴潜水面之上，毛管力把水从饱和带「吸」上来，使孔隙部分饱和。<span class="marginnote">毛细带中的水处于负压（张力）状态，却能垂直向上输运——这是表面张力对抗重力的胜利。细粒土毛细上升高度可达数米，粗砂只有几十厘米。</span>

刻画包气带水分状态的第一个量是**含水率（moisture content）$\theta$**：单位体积介质中水的体积占比。$\theta$ 可从近 0（极干）变化到孔隙度 $n$（完全饱和），因此它总是小于或等于 $n$。

含水率的测定方法从简到繁：**烘干法**称重-烘干-再称重，最可靠但具破坏性；**时域反射仪（TDR）**利用水的介电常数远高于空气与矿物，通过测量电磁波反射时间反演含水率，可连续监测而不扰动土体。TDR 让「含水率随深度、随时间变化的剖面」成为可实时观测的量，是农业水文学与山洪预警的利器。

包气带的厚度从潮湿区不足 1 m 到干旱区数百米不等——在沙漠绿洲，包气带本身就是一座「水的中转仓库」，其储水变化直接关系绿洲的命运。

## 2 非饱和带的水分状态：基质势与持水曲线

饱和带中水的能量用水头 $h = z + p/\rho g$ 描述，非饱和带却多出一个主角：**基质势（matric potential）$\psi$**。孔隙水与固体颗粒之间的表面张力、吸附力把水「拉住」，使水的压力低于大气压，表现为**负压水头（吸力）**。此时的总水头为：

$$H = z + \psi$$

其中 $\psi \lt  0$，量纲仍是长度（m）。含水率越低，孔隙水膜越薄、张力越大，$\psi$ 越负。<span class="marginnote">测基质势的仪器叫张力计（tensiometer）：陶瓷头插入土中，真空表读出的负压即 $\psi$。$\psi$ 值域从饱和时的 0 一直到干燥土的 -100 m 以下。</span>

**土水特征曲线（soil water characteristic curve）**是 $\theta$ 与 $\psi$ 的关系曲线，是理解非饱和带的核心图表。曲线上有两个农业与水文常用分界点：

**田间持水量（field capacity）**：重力水排干后土壤仍能保持的水量对应的含水率。**萎蔫点（wilting point）**：植物无法再吸水时的含水率，常粗略对应 $\psi = -15$ bar（约 $-150$ m）处。两者之差叫**有效水**。<span class="marginnote">田间持水量常被粗略对应为 $\psi = -0.1$ 至 $-0.33$ bar 时的含水率，是灌溉设计的核心参数；它不是一个严格的物理常数，而是「排水速率可忽略」的工程约定。</span>

**辨析｜易错点：**田间持水量并不是「土壤吸饱了水」的饱和含水率。饱和后重力水很快排走，剩在孔隙里、被毛管力与吸附力保住的水才叫持水量——把两者混为一谈，灌溉和污染物评估都会出错。

## 3 入渗过程与入渗能力

降雨落到地面，一部分被土壤吸收（入渗），一部分积洼、形成地表径流。**入渗能力（infiltration capacity）$f_c$**：地表允许水进入的最大速率。实际入渗速率 $f$ 取降雨强度与 $f_c$ 的较小值。<span class="marginnote">入渗能力随时间衰减：初始干燥土壤吸力大、入渗快；随含水率上升、表面结壳，$f_c$ 逐渐降到稳定值（接近饱和水力传导系数）。超渗产流正是「降雨强度超过 $f_c$」时的地表径流。</span>

按产流机制，地表径流分两种：**超渗产流（Hortonian runoff）**——降雨强度超过入渗能力，常见于植被稀少、土质致密的地区；**饱和地表径流（saturation overland flow）**——包气带已饱和、无处再渗，常见于湿润山区的坡脚。两种产流方式决定了不同流域洪水响应的快慢。

描述入渗的经典模型有两类：

**经验模型（Horton，1933）**：$f = f_\infty + (f_0 - f_\infty)\,e^{-kt}$，入渗率随时间指数衰减，参数 $f_0,f_\infty,k$ 由试验拟合。
**物理模型（Green–Ampt，1911）**：把入渗视为湿润锋的推进，锋前饱和、锋后干燥，基于达西定律推导：

$$f = K_s\left(1 + \frac{\psi_f\,\Delta\theta}{F}\right)$$

其中 $F$ 是累计入渗深度，$\Delta\theta$ 是湿润锋前后的含水率差，$\psi_f$ 是锋面吸力。Green–Ampt 参数物理意义明确，是中小流域水文模型的常见选择。

Green–Ampt 的物理图像极简：把复杂的含水率剖面简化为一个陡峭湿润锋，锋面两侧一边饱和、一边干燥；正是这个「一刀切」近似，让它在小流域水文模型中至今长盛不衰。

## 4 非饱和流：理查兹方程

饱和带中 $K$ 是常数；非饱和带中水力传导系数随含水率剧烈变化，记为 $K(\theta)$——含水率越低、导水能力越差，因为空气占据的孔隙不导水。把达西定律推广到非饱和流（**达西–白金汉定律**）：

$$q = -K(\theta)\,\nabla H = -K(\theta)\,\nabla(\psi + z)$$

结合质量守恒，得到**理查兹方程（Richards equation）**的一维竖直形式：

$$\frac{\partial \theta}{\partial t} = \frac{\partial}{\partial z}\left[K(\theta)\left(\frac{\partial \psi}{\partial z} + 1\right)\right]$$

实际求解理查兹方程，还需描述 $\theta(\psi)$ 与 $K(\theta)$ 的解析关系。最常用的是 **van Genuchten 模型**：以两个形状参数刻画持水曲线与导水曲线，配合 RETC 等工具由实测数据拟合参数，让非饱和带模拟成为工程常规手段。

## 5 公式解析：理查兹方程 $\dfrac{\partial \theta}{\partial t} = \dfrac{\partial}{\partial z}\left[K(\theta)\left(\dfrac{\partial \psi}{\partial z} + 1\right)\right]$

理查兹方程是「非饱和带里的地下水流方程」，分四步理解：

- **第一步，左端是储水变化**：$\partial\theta/\partial t$ 是含水率随时间的变化率——非饱和带以「改变含水率」来储存水，而非像承压含水层那样靠弹性释放。
- **第二步，通量项**：$q = -K(\theta)(\partial\psi/\partial z + 1)$ 是达西–白金汉定律：$\partial\psi/\partial z$ 是基质势梯度（吸力驱动），$+1$ 是重力项，两个驱动力叠加。
- **第三步，非线性是核心困难**：$K(\theta)$ 与 $\psi(\theta)$ 都是 $\theta$ 的强非线性函数，使理查兹方程远比饱和流方程难解——这正是它需要数值方法的根本原因。
- **第四步，滞后与空气**：吸水与排水过程中 $\theta$–$\psi$ 关系不重合（滞后现象），空气被困在孔隙中进一步改变流态，让模型与实测总是「差一点」。

**辨析｜易错点：**非饱和带中水可以**向上**流动（蒸发、毛管上升），这在饱和带的承压流中几乎不会出现；理查兹方程统一描述向上与向下，靠的是 $+1$ 重力项与 $\partial\psi/\partial z$ 吸力项的此消彼长。

## 6 从入渗到补给：一场雨的去向

一场降雨落到地面，去向大致是：地表径流 → 蒸发 → 植物蒸腾 → 深层渗漏。只有**深层渗漏（deep percolation）**穿过包气带底部、抵达潜水面，才算真正补给。影响补给比例的因素：土壤质地、降雨强度与历时、地形坡度、植被与前期含水率。<span class="marginnote">粗砂土上，一次透雨可能把 30%–50% 的雨量补给到潜水；致密黏土或强烈蒸发的旱区，补给比例常不足 5%。「降雨多 ≠ 补给多」是水文地质里反直觉的第一课。</span>

估算补给量的常用手段有：水均衡法、氯离子质量平衡、环境同位素（氚、氘、氧同位素）示踪与基流分割——第十二篇《地下水补给、资源评价与管理》会系统展开。

把饱和带与非饱和带并排比较，差异一目了然：

| 特征 | 饱和带 | 非饱和带（包气带） |
| --- | --- | --- |
| 孔隙含水 | 完全充满 | 水气共存 |
| 主要驱动力 | 压力 + 重力 | 吸力（基质势）+ 重力 |
| 压力水头 | $\ge 0$ | 通常 $\lt  0$ |
| 水力传导系数 | 常数 $K_s$ | 随 $\theta$ 变化 $K(\theta)$ |
| 水可向上流动 | 基本否 | 可以（蒸发/毛管） |

这张对比表是理解「为何非饱和带难测、饱和带好测」的钥匙：负压、低导水、强非线性，让非饱和带的现场参数测定远比饱和带昂贵与困难，也解释了为何大多数地下水模型仍以饱和带为主体。

## 7 小结

- **包气带**分土壤带、中间带、毛细带，含水率 $\theta$ 从近 0 变到 $n$，水头公式为 $H = z + \psi$。
- **基质势 $\psi$** 是负压吸力，含水率越低越负；**土水特征曲线**刻画 $\theta$–$\psi$ 关系，田间持水量与萎蔫点是两个实用分界点。
- **入渗能力 $f_c$** 随时间衰减：初始吸力大、入渗快，随含水率上升与表面结壳降到稳定值；Horton 与 Green–Ampt 是两大经典入渗模型。
- **理查兹方程**是「非饱和带里的地下水流方程」，$K(\theta)$ 与 $\psi(\theta)$ 的强非线性让它必须数值求解；van Genuchten 模型提供解析关系。
- 非饱和带中水可以向上流动（蒸发、毛管上升），理查兹方程的 $+1$ 重力项与 $\partial\psi/\partial z$ 吸力项此消彼长，统一描述向上与向下。
- 只有深层渗漏穿过包气带底部抵达潜水面才算补给：粗砂透雨可补 30%–50%，致密黏土或强烈蒸发的旱区常不足 5%。
- 含水率测定从烘干法到 TDR：时域反射仪利用水的介电常数远高于空气与矿物，可连续、无扰动地监测含水率剖面。
- 产流分超渗产流与饱和地表径流：植被稀少、土质致密区多为前者，湿润山区的坡脚常见后者。
- 基质势用张力计测量，值域从饱和时的 0 到干燥土的 -100 m 以下；土水特征曲线的田间持水量与萎蔫点之差是「有效水」。
