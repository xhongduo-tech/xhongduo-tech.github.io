## 为什么从「地下水化学」开始

前几篇回答了「水有多少、流多快」，这一篇转向**「水里有什么」**。天然地下水从不是纯净的 H₂O：它溶解了沿途接触过的矿物、有机质与气体，是一瓶「流动的地质档案」。<span class="marginnote">地下水在含水层中的平均滞留时间，从数年（浅层潜水）到数万年（深层承压水）不等。滞留越久，水与岩石反应越充分，化学成分越「成熟」——水化学记录着地下水的年龄与来路。</span>

理解地下水化学，有四层实用价值：**判断水源与补给区**（不同来源的水味道不同）、**评估水质是否适合饮用灌溉**、**识别污染信号**（自然化学基线是污染诊断的对照物），以及**反推水流路径**（化学成分随流动路径演化）。这一篇是下一篇「溶质运移」与第九篇「污染物修复」的共同地基。

## 1 天然地下水的主要成分

地下水中的溶质以离子为主。最常见的是六大离子：

**阳离子**：$\ce{Ca^{2+}}$、$\ce{Mg^{2+}}$、$\ce{Na+}$、$\ce{K+}$。
**阴离子**：$\ce{HCO3-}$、$\ce{SO4^{2-}}$、$\ce{Cl-}$。

它们合起来通常占水中溶解固体的 90% 以上。三个常用总量指标：

**总溶解固体（TDS）**：单位体积水中溶解物质的总质量，mg/L。**硬度**：主要是 $\ce{Ca^{2+}}$ 与 $\ce{Mg^{2+}}$ 的浓度折算，用 mg/L CaCO₃ 当量表示。**碱度（alkalinity）**：水中和酸的能力，主要由 $\ce{HCO3-}$、$\ce{CO3^{2-}}$ 提供。<span class="marginnote">「硬水」烧水起垢、「软水」易起泡，本质就是硬度离子浓度的差异。总硬度 > 300 mg/L 已属硬水，> 600 mg/L 则不宜直接作工业用水。</span>

典型地下水的 TDS 从几十 mg/L（补给区、降水稀释）到数万 mg/L（深层卤水）跨越三个数量级；海水约 35000 mg/L，是个天然的参照标尺。**pH** 多在 6–8.5 之间，受碳酸平衡主导。

六大离子的典型浓度范围（mg/L，淡水→咸水）：

| 离子 | 补给区淡水 | 深层/咸水 |
| --- | --- | --- |
| $\ce{Ca^{2+}}$ | 10–100 | 100–1000+ |
| $\ce{Mg^{2+}}$ | 1–50 | 50–2000 |
| $\ce{Na+}$ | 1–50 | 100–10000+ |
| $\ce{HCO3-}$ | 50–400 | 100–500 |
| $\ce{SO4^{2-}}$ | 1–100 | 10–3000 |
| $\ce{Cl-}$ | 1–30 | 50–20000 |

这张表藏着规律：咸水端 $\ce{Na+}$ 与 $\ce{Cl-}$ 增长最猛，$\ce{HCO3-}$ 增长有限——因为碳酸盐受溶解度封顶，而氯化物几乎不受限制。

水质分析的第一步是**采样**：专用采样器、避气避光、低温保存、限期送检。测定项目分两类：现场项（水温、pH、电导、溶解氧）当场测才有意义；实验室项（六大离子、微量金属、有机污染物）送回实验室。地下水采样是「化学实验室向野外延伸」的典型场景，样品失真（氧化、挥发、温度变化）是最大的误差来源。

## 2 水文地球化学作用：谁在改写水的成分

地下水化学成分的演化，由以下过程共同驱动：

**溶滤（dissolution）**：水溶解矿物，把离子带进溶液。方解石遇含 CO₂ 的水溶解，是碳酸盐区最常见反应：

$$\ce{CaCO3 + H2O + CO2(aq) \lt => Ca^{2+} + 2HCO3-}$$

**沉淀（precipitation）**：溶液过饱和时，矿物重新析出，把离子移出溶液。

**阳离子交换（cation exchange）**：黏土矿物表面的吸附离子（如 $\ce{Na+}$）与水中离子（如 $\ce{Ca^{2+}}$）发生交换，改写水的相对比例——海水入侵区常见「$\ce{Ca^{2+}}$ 入水、$\ce{Na+}$ 吸附」的钠质水特征。<span class="marginnote">离子交换让水的「阴阳离子比例」失衡，也是含水层作为天然净化器的机制之一：重金属离子常被黏土、有机质吸附而固定在原地。</span>

**氧化还原反应（redox）**：沿水流路径，溶解氧被耗尽的顺序构成著名的「氧化还原阶梯」：O₂ → NO₃⁻（反硝化）→ Mn⁴⁺ → Fe³⁺ → SO₄²⁻（硫酸盐还原）→ CO₂（产甲烷）。越往下游、滞留越久，氧化态越低。<span class="marginnote">红棕色的铁锈水、臭鸡蛋味的硫化物水，往往是地下水处于还原环境的标志。氧化还原状态决定了 Fe、Mn、As 等微量元素的溶解行为——As 在还原条件更易释放，这是南亚砷污染的地球化学根源。</span>

溶解有机碳（DOC）与气体也是重要成分：土壤带渗入的 CO₂ 驱动碳酸盐溶解；深层缺氧环境产生的 CH₄、H₂S 使水带特殊气味。有机质参与氧化还原，往往是污染场地生物修复的「燃料」——降解污染物的微生物靠消耗 DOC 与电子受体维持代谢。

**蒸发浓缩与混合**：干旱区强烈蒸发使浅层水浓缩、TDS 升高；不同来源的水在排泄区混合，成分趋向折中。

## 3 水化学类型与 Piper 图

把主要离子的相对比例画出来，就得到**水化学类型（hydrochemical facies）**。最常用的可视化工具是 **Piper 三线图**：左三角形画阳离子（$\ce{Ca^{2+}}$、$\ce{Mg^{2+}}$、$\ce{Na+ + K+}$），右三角形画阴离子（$\ce{HCO3- + CO3^{2-}}$、$\ce{SO4^{2-}}$、$\ce{Cl-}$），两条射线把各占比例投影到中央菱形上，每一样品在菱形中得一点。<span class="marginnote">菱形中点的位置一眼定类型：左下角是「$\ce{Ca-HCO3}$ 型」年轻淡水，右下角是「$\ce{Na-Cl}$ 型」老卤水或海水入侵水。一群样品连成轨迹，能读出「补给区 → 排泄区」的水化学演化路径。</span>

**补给区**的水通常为低 TDS 的 **$\ce{Ca-HCO3}$ 型**——降水溶解少量碳酸盐矿物即成。**排泄区**或深层水逐渐向 **$\ce{Na-HCO3}$**（离子交换）或 **$\ce{Na-Cl}$**（蒸发浓缩/残留海水）演化。**辨析｜易错点：**「$\ce{Na-Cl}$ 型」不等于「海水入侵」——它也可能来自蒸发岩溶解、深层残留卤水或离子交换；判断海水入侵要靠氯离子浓度梯度与离子比例（如 Br/Cl）的协同证据。

读 Piper 图的实战技巧：把同一含水层的多年样品画成一组点，看它们沿菱形移动的方向——朝 $\ce{Na+}$ 角移动说明离子交换或老化，朝 $\ce{Cl-}$ 角移动说明蒸发浓缩或咸水入侵，垂直上移说明硫酸盐增多（可能来自硫化矿氧化或工业污染）。一群点的「轨迹方向」比单个点更能说明问题。

## 4 饱和指数与矿物平衡

水与矿物是「溶还是沉」，由**饱和指数（saturation index）**定量判定：

$$\mathrm{SI} = \log_{10}\frac{\mathrm{IAP}}{K_{sp}}$$

其中 **IAP**（ion activity product）是溶液中离子活度按化学计量系数的乘积，$K_{sp}$ 是该矿物的溶度积常数。SI 的含义一目了然：SI = 0 恰好平衡，SI > 0 过饱和（倾向于沉淀），SI < 0 不饱和（倾向于溶解）。<span class="marginnote">方解石的 $K_{sp}$ 约 $10^{-8.4}$（25°C），而天然水的 IAP 常在 $10^{-9}$ 到 $10^{-7}$ 之间摆动，SI 从 -1 到 +1 都是常见值。SI 精确到 ±0.1 需要高质量的水质分析，工程上用它判断含水层是否结垢、地层是否被溶蚀。</span>

**辨析｜易错点：**SI 用的是**离子活度**而非浓度。高离子强度（高 TDS）溶液中活度系数明显小于 1，直接拿浓度算 IAP 会高估过饱和程度——处理咸水时必须用 Debye–Hückel 等活度模型校正。

在工程上，SI 用来预判**结垢**：热水井与地热系统中碳酸钙过饱和会在管壁结垢，需要酸洗或投加阻垢剂；地下水回灌也要求注入水与原水化学兼容，否则会引起地层堵塞。

## 5 从化学看水龄与来路：环境示踪剂

地下水化学成分还能充当「时钟」与「地图」。

**稳定同位素**：$\delta^{18}\mathrm{O}$ 与 $\delta\mathrm{D}$ 记录降水来源与蒸发历史——高海拔、内陆降水偏负，蒸发使它们偏正。测一个水样的同位素，能判断它来自海洋气团还是大陆气团、经历了多少蒸发。<span class="marginnote">雨水从补给区到排泄区，同位素指纹基本不变，是理想的「水源标签」；氢氧同位素还随海拔、纬度呈规律变化，可用来识别河流与地下水的交换。</span>

**放射性同位素测年**：氚（$^{3}\mathrm{H}$，半衰期 12.3 年）标记近 50 年内的补给水；碳-14（$^{14}\mathrm{C}$，半衰期 5730 年）测数千年尺度的深层水年龄；氯-36、氦-4 则覆盖更老的尺度。<span class="marginnote">水龄不是「这滴水存在了多久」，而是「这滴水进入含水层以来过了多久」。知道水龄，就能估算含水层的更新速率与可持续开采能力——这是第十二篇资源管理的化学依据。</span>

**辨析｜易错点：**示踪剂测的是「混合年龄」——含水层里新老水混合，测出的年龄是加权平均。深层承压水的「古老年龄」恰恰警告我们：它一旦被抽干，靠自然补给恢复要花数千年。

## 6 公式解析：方解石溶解反应的平衡常数

以方解石溶解为例，把「平衡常数」拆开看：

$$\ce{CaCO3(s) \lt => Ca^{2+} + CO3^{2-}}, \qquad K_{sp} = \frac{a_{\ce{Ca^{2+}}} \cdot a_{\ce{CO3^{2-}}}}{a_{\ce{CaCO3(s)}}}$$

- **第一步，固体的活度取 1**：纯固体与纯液体的活度约定为 1，所以 $K_{sp} = a_{\ce{Ca^{2+}}} \cdot a_{\ce{CO3^{2-}}}$——溶度积只是两种离子活度的乘积。
- **第二步，CO₂ 的参与**：天然水中 $\ce{CO3^{2-}}$ 很少，大量碳以 $\ce{HCO3-}$ 存在；把碳酸平衡写全，方解石溶解实质是 $\ce{CaCO3 + H2O + CO2 \lt => Ca^{2+} + 2HCO3-}$，有效平衡常数并入 CO₂ 分压项。
- **第三步，SI 的直觉**：溶液里 $\ce{Ca^{2+}}$ 与碳酸根越多，IAP 越大，SI 越高；温度升高使 CO₂ 溶解度下降、方解石溶解度降低，所以温泉口常见方解石沉淀（钙华）。
- **第四步，开放 vs 封闭系统**：开放系统（CO₂ 可从大气/土壤持续补充）中方解石持续溶解；封闭系统（CO₂ 被耗尽）则很快饱和停止。这也是为什么深井水钙镁含量通常高于浅井水。

## 7 小结

- 地下水主要含 **$\ce{Ca^{2+}}$、$\ce{Mg^{2+}}$、$\ce{Na+}$、$\ce{K+}$** 与 **$\ce{HCO3-}$、$\ce{SO4^{2-}}$、$\ce{Cl-}$** 六种离子；TDS、硬度、碱度是三个总量指标。
- 成分由**溶滤、沉淀、离子交换、氧化还原、蒸发浓缩与混合**共同塑造；氧化还原阶梯决定 Fe、Mn、As 的溶解行为。
- **Piper 三线图**把样品画进菱形图，水化学类型从补给区 $\ce{Ca-HCO3}$ 型向排泄区 $\ce{Na-Cl}$ 型演化。
- **饱和指数** SI = log(IAP/$K_{sp}$
