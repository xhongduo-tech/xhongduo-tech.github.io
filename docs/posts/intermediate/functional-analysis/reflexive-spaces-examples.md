# 自反空间及其例子

## 为什么自反性值得一章

上一节我们定义了自反空间（$X = X^{**}$）。它不只是个好奇的代数性质，而是「空间好不好的试金石」：自反空间拥有有限维空间的大部分福利——**单位球弱紧、有界序列有弱收敛子列、闭凸集有最佳逼近元**。反过来说，非自反空间（$c_0$、$l^1$、$L^1$）会遭遇各种「有限维失效」的悲剧。理解自反性，就是理解「哪些无穷维空间能保留有限维的几何直觉」。<span class="marginnote">James 定理（1964）给出了一个令人惊讶的刻画：<strong>赋范空间自反 ⟺ 每个连续线性泛函都达到它的范数</strong>。这说明自反性与「范数可达性」深度绑定——自反空间里，$\sup$ 总能变成 $\max$，而这正是极小/极大值存在问题的本质。</span>

## 1 自反空间的判别：两条实用路径

**判别法一（用已知对偶）**：若已知 $X^*$ 的具体形态，自反性可直接检查——$X = X^{**}$ 当且仅当「二次对偶回到自身」。

**判别法二（James 定理）**：$X$ 自反 ⟺ $X$ 中每个非零 $f \in X^*$ 都在闭单位球上达到范数（$\exists \|x\|=1$ 使 $f(x) = \|f\|$）。

**核心要点：自反性 = 泛函总能达到范数**。直觉：非自反空间里存在「永远够不到的 sup」，自反空间里 sup 都是 max。这直接决定了变分问题的解是否存在。<span class="marginnote">James 定理的证明方向：非自反 ⟹ 存在达不到范数的泛函（用 $X^{\ast\ast}$ 中的「多余点」构造）。它把「自反性」这个代数概念翻译成「泛函范数可达」这个更分析的条件——是理解自反性最好的窗口。</span>

## 2 例子：自反的

**例一（$l^p$、$L^p$，$1 < p < \infty$）**：由 $(l^p)^* = l^q$、$(l^q)^* = l^p$（$1/p + 1/q = 1$），且这些同构是典范畴的，故 $l^p$、$L^p$ 自反。<span class="marginnote">$p = 2$ 的 $l^2$、$L^2$（Hilbert 空间）自反是最干净的情形：$H^* = H$（Riesz），$H^{\ast\ast} = H$。量子力学、信号处理几乎都在自反的 $L^2$ 里工作，这正是「福利」的来源。</span>

**例二（有限维空间）**：一切有限维赋范空间自反（$X^{**} = X$ 且典范）。

**例三（自反空间的闭子空间与商）**：自反空间的闭子空间自反；自反空间对闭子空间的商自反（这是「自反性封闭于基本构造」的体现）。

## 3 例子：不自反的

**例一（$l^1$）**：$(l^1)^* = l^\infty$，$(l^\infty)^* \supsetneq l^1$——二次对偶严格大于 $l^1$，不自反。

**例二（$l^\infty$）**：它的对偶比 $l^1$ 更大（包含有限加测度等），二次对偶更大，不自反。

**例三（$c_0$）**：$(c_0)^* = l^1$，$(l^1)^* = l^\infty \supsetneq c_0$，不自反。

**例四（$C[a,b]$）**：它的对偶是测度空间，二次对偶远大于 $C$，不自反。<span class="marginnote">不自反空间的共同特征：<strong>对偶「膨胀」了</strong>——$X^*$ 比 $X$ 的「自然对偶」大。直觉：$X$ 太「瘦」或太「松」，装不下自己的二次对偶。$l^1$ 的对偶 $l^\infty$ 里塞满了「不是 $l^1$ 元素的泛函」。</span>

## 4 自反空间的福利：弱列紧性

**定理（Eberlein-Šmulian，自反版本）**：设 $X$ 是自反 Banach 空间。则 $X$ 的闭单位球是**弱列紧的**：每个有界序列都有弱收敛子列。

**弱收敛**（下节定义）是「被所有泛函观察时收敛」：$x_n \rightharpoonup x$ 当且仅当对一切 $f \in X^*$，$f(x_n) \to f(x)$。弱列紧定理说：自反空间里「有界序列必有一弱收敛子列」——这是 Bolzano-Weierstrass 在无穷维的替身。<span class="marginnote">对比：在无穷维非自反空间里，有界序列甚至可能没有弱收敛子列（如 $l^1$ 的标准基 $e_n$）。所以「有界 ⟹ 有（弱）收敛子列」是自反空间独有的福利，也是变分法里「极小化序列取极限」的保证——第十章变分原理的数学心脏。</span>

**推论（变分法的解存在性）**：自反空间中，适当下半连续的凸泛函在闭凸集上有极小值。证明：取极小化序列（有界），Eberlein-Šmulian 给弱收敛子列，下半连续性把极限的泛函值压到最小。

## 5 公式解析：James 定理的直觉

理解「自反 ⟺ 范数可达」的关键例子。在 $c_0$（不自反）里找一个达不到范数的泛函：

$$
f(x) = \sum_{n=1}^\infty \frac{x_n}{2^n}
$$

- **第一步，算范数**：$f \in (c_0)^* = l^1$，$\|f\| = \sum 1/2^n = 1$。要「达到」范数，需 $\|x\|_\infty = 1$ 且 $f(x) = 1$。
- **第二步，发现不可能**：$f(x) = \sum x_n/2^n$。若 $x \in c_0$，$x_n \to 0$，则 $|f(x)| \le \sum |x_n|/2^n$。要使和为 1 需 $|x_n| = 1$ 对一切 $n$（等比收紧），但 $x_n \to 0$ 时 $\sum |x_n|/2^n < 1$ 严格——**sup 永远够不到**。
- **第三步，结论**：$c_0$ 中范数不可达，$c_0$ 不自反。在 $l^p$（自反）中，类似泛函总能在某 $x$ 上达到 sup。

**关键**：非自反空间里「sup 不是 max」是常态——**极值永远差一点点够到**。自反性就是「把所有差一点点的 sup 都变成 max」的保证。<span class="marginnote">这个例子也说明了为什么变分法偏爱自反空间：<strong>在 $c_0$ 里极小化「$\sum x_n/2^n$」永远没有极小点，在 $l^p$ 里则总存在</strong>。「有没有极小点」就是「自不自反」的直接表现。</span>

## 6 对比表：自反 vs 非自反

| 空间 | 自反？ | 二次对偶 | 有界序列弱收敛子列？ |
| --- | --- | --- | --- |
| $l^p$、$L^p$（$1<p<\infty$） | ✅ | $= X$ | ✅ |
| $l^2$、$L^2$（Hilbert） | ✅ | $= X$ | ✅ |
| 有限维空间 | ✅ | $= X$ | ✅ |
| $c_0$ | ❌ | $\supsetneq X$ | ❌ |
| $l^1$、$L^1$ | ❌ | $\supsetneq X$ | ❌ |
| $C[a,b]$ | ❌ | $\supsetneq X$ | ❌ |

**记忆锚点：$1 < p < \infty$ 是「黄金区间」**——自反性、弱列紧、范数可达全部在线。<span class="marginnote">这也是「为什么分析都爱用 $L^2$ 而非 $L^1$ 或 $L^\infty$」的一个深层理由：$L^2$ 自反（且 Hilbert），而 $L^1$、$L^\infty$ 不自反——许多存在性定理在 $L^2$ 里免费成立，在 $L^1$ 里却需要额外的技巧。</span>

## 7 自反性与弱紧性：James 定理的进一步方向

James 定理（自反 ⟺ 泛函都能达到范数）把「自反」与「极值存在」绑在一起。这一节看它如何衔接紧性。

**方向一（范数可达 ⟹ 弱紧）**：若每个 $f \in X^*$ 都在闭单位球上达到范数，则 $X$ 自反，进而单位球弱紧。直觉：$\|f\| = \sup_{B}|f|$ 能取到，说明「sup 都是 max」，这正是不自反空间（$c_0$ 的例子）里缺失的性质。

**方向二（非自反 ⟹ 存在不可达范数）**：在 $c_0$ 里，$f(x) = \sum x_n/2^n$ 的范数是 1 却永远达不到（需要 $|x_n| = 1$ 对一切 $n$，违反 $x_n \to 0$）。这类「差一点」的 sup 就是非自反性的指纹。

**与弱列紧的连接**：自反 ⟹ 单位球弱紧（Alaoglu + 二次对偶）⟹ 有界序列有弱收敛子列（Eberlein-Šmulian）。于是变分法的「取极小化序列 → 抽弱收敛子列 → 下半连续取极限」三步走，在自反空间里畅通无阻。

**例（$L^2$ 上的凸变分问题）**：求 $J(u) = \int |\nabla u|^2 + V(x)u^2$ 在 $H^1$ 中的极小。$H^1$ 是自反的，极小化序列有界，Eberlein-Šmulian 给弱收敛子列，弱下半连续性给极小元——**每一步都不需要构造**，紧性自动到位。这就是「自反 = 有限维福利保留」的活例。

**辨析｜易错点：** 自反空间的弱紧是「弱」紧，不是「强」紧。单位球在范数意义下仍不紧（Riesz 引理），只有换到弱拓扑才紧。区分「弱紧」与「强紧」是自反空间理论的常识。

## 8 例题精讲：自反性的判别练习

**练习一：$l^p$（$1<p<\infty$）自反**。

- $(l^p)^* = l^q$（$1/p + 1/q = 1$），$(l^q)^* = l^p$，同构是典范的。
- 典范嵌入 $\kappa: l^p \to (l^q)^* = l^p$ 是恒等（坐标对应），满射。
- 故 $l^p$ 自反。

**练习二：$l^1$ 不自反**。

- $(l^1)^* = l^\infty$，$(l^\infty)^* \supsetneq l^1$（含有限加测度等）。
- $\kappa(l^1) \subsetneq (l^\infty)^*$，典范嵌入不是满射。
- 故 $l^1$ 不自反。

**练习三：James 定理的直观检验**。

- $l^1$ 中 $f(x) = \sum x_n/2^n$，$\|f\|_{(l^1)^*} = \|(2^{-n})\|_\infty = 1$。
- 但 $f$ 在 $l^1$ 单位球上达不到范数（需要 $|x_n| = 1$ 对某个 $n$，而 $2^{-n} < 1$）。
- 与 James 定理一致：$l^1$ 不自反，存在不可达范数的泛函。

**核心要点**：自反性判别 = 「二次对偶是否典范回自身」；不自反的指纹 = 「存在不可达范数的泛函」。

**辨析｜易错点：** 判断自反时，同构必须是**典范**的。存在非典范同构 $X \cong X^{**}$ 的不自反空间——「有同构」≠「自反」。


## 9 小结

- **自反空间**：$\kappa: X \to X^{**}$ 满射（等距同构 $X = X^{**}$）。
- **判别**：James 定理——自反 ⟺ 泛函都能达到范数。
- **自反的例子**：$l^p$、$L^p$（$1<p<\infty$）、有限维、自反空间的闭子空间/商。
- **非自反的例子**：$c_0$、$l^1$、$L^1$、$L^\infty$、$C[a,b]$——对偶「膨胀」。
- **福利**：Eberlein-Šmulian——有界序列有弱收敛子列；变分问题解存在。
- **本质**：自反 = 「sup 全是 max」，极值问题永远有解。

在下一节，我们正式定义**弱收敛与弱\* 收敛**——在泛函「观测」意义下的收敛，这是自反性与紧性理论的运作语言。
