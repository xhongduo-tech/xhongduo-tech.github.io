# 有界线性算子的代数性质：乘法、逆算子

<div class="epigraph">

## 为什么算子能「相乘」

矩阵可以相乘，算子当然也应该可以相乘——把「复合」当作「乘法」：先作用 $T$ 再作用 $S$，记作 $ST$。这个简单的操作把 $\mathcal{B}(X)$ 变成一个既有加法又有乘法的对象，即**算子代数（operator algebra）**。乘法带来两个全新的课题：**逆算子**（解方程 $Tx = y$ 需要它）与**谱理论**（特征值的推广，第九章的主角）。本节先把代数的骨架立起来。<span class="marginnote">矩阵乘法是算子乘法的有限维特例，但有一个重要差别：<strong>算子乘法一般不交换</strong>。$ST$ 与 $TS$ 不同——先微分再积分与先积分再微分是两回事。非交换性是算子理论比「数」更丰富的根源。</span>

## 1 算子的复合与乘积

**定义**：设 $T, S \in \mathcal{B}(X)$，定义**复合算子（乘积）**

$$
(ST)(x) = S(T x)
$$

容易验证 $ST$ 线性且有界，且关键不等式

$$
\|S T\| \le \|S\| \, \|T\|
$$

成立（对单位向量 $x$：$\|STx\| \le \|S\|\|Tx\| \le \|S\|\|T\|\|x\|$）。<span class="marginnote">这个不等式说「乘法与范数相容」，正是<strong>赋范代数</strong>（normed algebra）的定义：范数把乘法限制住了。在有限维，$ST$ 对应矩阵乘积，$\|ST\| \le \|S\|\|T\|$ 就是「谱范数对矩阵乘法次可乘」——你在线性代数里可能见过它。</span>

**辨析｜易错点：** 复合的顺序！$ST$ 先作用 $T$ 再作用 $S$。这个「从右到左」的规则与函数复合一致，但初学容易与「先 $S$ 后 $T$」搞混。写 $(ST)(x) = S(Tx)$ 永远是对的检查方式。

## 2 算子的幂与算子多项式

有了乘法，就有幂：$T^2 = TT$，$T^n = \underbrace{T \cdots T}_{n}$，$T^0 = I$（恒等算子）。于是可定义**算子多项式**：

$$
p(T) = a_n T^n + a_{n-1} T^{n-1} + \cdots + a_1 T + a_0 I
$$

它是把「数多项式」$p$ 代入「算子 $T$」的结果。<span class="marginnote">算子多项式的用处：一是用多项式逼近算子（Weierstrass 逼近定理的算子版），二是谱理论里「$p(\sigma(T)) = \sigma(p(T))$」之类的谱映射定理。代数的力量在这里初现。</span>

**幂次估计**：由次可乘性，$\|T^n\| \le \|T\|^n$——这将在谱半径公式（第九章）中扮演核心角色。注意反向一般不成立：$\|T^n\|$ 常常比 $\|T\|^n$ 小得多。

## 3 逆算子

**定义（可逆）**：设 $T \in \mathcal{B}(X)$。若存在 $S \in \mathcal{B}(X)$ 使

$$
ST = I, \qquad TS = I
$$

则称 $T$ **可逆（invertible）**，$S$ 称为 $T$ 的**逆算子（inverse）**，记作 $S = T^{-1}$。

**重要事实**：若 $T$ 是双射（单射且满射），且 $T$ 有界线性，则 $T^{-1}$ 自动有界线性——这是**逆算子定理**（第五章）的内容。本节只用到「存在有界逆」的定义。<span class="marginnote">对连续线性算子，代数可逆（存在线性逆）与「作为映射双射」相差一个<strong>开映射定理</strong>（第五章）：连续线性满射若单射，逆自动连续。这个微妙差别是初学者容易忽略的。</span>

**逆的唯一性**：若 $T$ 可逆，逆唯一（若 $S_1 T = T S_1 = I$ 且 $S_2 T = T S_2 = I$，则 $S_1 = S_1 I = S_1(T S_2) = (S_1 T)S_2 = S_2$）。

## 4 诺伊曼级数：逆算子存在的充分条件

上一节末的诺伊曼级数，本节把它正式化为「求逆」的工具：

**定理：设 $T \in \mathcal{B}(X)$，$\|T\| < 1$，则 $I - T$ 可逆，且**

$$
(I - T)^{-1} = \sum_{n=0}^\infty T^n
$$

证明要点：$\sum\|T^n\| \le \sum\|T\|^n < \infty$ 绝对收敛；再验证 $(I - T)\sum_{n=0}^N T^n = I - T^{N+1} \to I$。<span class="marginnote">把 $T$ 换成 $\lambda T$（$\lambda$ 是数），条件变成 $|\lambda|\|T\| < 1$——这为「谱」的定义埋下伏笔：$(\lambda I - T)^{-1}$ 何时存在？$\lambda$ 避开谱时，预解式就是诺伊曼级数。第九章将沿着这条线展开。</span>

**推论（逆算子对接近可逆算子的稳定性）**：若 $T$ 可逆且 $\|S\| < \|T^{-1}\|^{-1}$，则 $T + S$ 可逆——因为

$$
T + S = T(I + T^{-1}S)
$$

而 $\|T^{-1}S\| \le \|T^{-1}\|\|S\| < 1$，由诺伊曼级数 $I + T^{-1}S$ 可逆。**可逆算子的集合是开集**（附近的一切算子仍可逆），这是「逆算子连续依赖于算子」的量化版本。

## 5 公式解析：诺伊曼级数验证

把「$I - T$ 乘以级数等于 $I$」拆开：

$$
(I - T)\Big(\sum_{n=0}^\infty T^n\Big) = \lim_{N\to\infty} (I - T)(I + T + \cdots + T^N)
$$

- **第一步，有限部分和相乘**：$(I - T)(I + T + \cdots + T^N) = I + T + \cdots + T^N - T - T^2 - \cdots - T^{N+1}$，中间项两两相消，只剩 $I - T^{N+1}$。这仿照了「$(1-x)(1+x+\cdots+x^N) = 1 - x^{N+1}$」，是**裂项相消**。
- **第二步，余项趋于零**：$\|T^{N+1}\| \le \|T\|^{N+1} \to 0$（因为 $\|T\| < 1$）。故 $I - T^{N+1} \to I$。
- **第三步，极限穿入**：由于部分和的极限是级数本身，$(I - T)\sum T^n = I$。另一侧 $( \sum T^n)(I - T) = I$ 同理。故 $\sum T^n$ 确实是 $I - T$ 的逆。

**关键**：唯一的假设 $\|T\| < 1$ 用来保证「幂的范数以几何速率收缩」。**几何级数收敛 ⟹ 算子几何级数收敛**，这是「把数论搬到算子论」最直接的一例。

## 6 例题精讲：算子代数的三个计算

**例题一：复合算子的范数**。

- $\|ST\| \le \|S\|\|T\|$，但可能严格小于。
- 例：$S$ 投影到第一坐标，$T$ 投影到第二坐标，$ST = 0$ 而 $\|S\| = \|T\| = 1$。
- 次可乘性是「估计」不是「等式」。

**例题二：$(I - T)^{-1}$ 的诺伊曼级数**。

- $\|T\| = 0.5$，$\sum T^n$ 收敛，$(I-T)^{-1} = \sum T^n$。
- $\|(I-T)^{-1}\| \le \sum 0.5^n = 2$。
- 几何级数收敛半径在算子世界的对应。

**例题三：可逆算子是开集**。

- $T$ 可逆，$\|S\| < \|T^{-1}\|^{-1}$，则 $T + S$ 可逆。
- 证明：$T+S = T(I + T^{-1}S)$，$\|T^{-1}S\| \le \|T^{-1}\|\|S\| < 1$。
- 可逆算子集合是开的——「小扰动不破坏可逆性」。

**核心要点**：算子代数的三个操作——复合、求逆、扰动——都由范数不等式控制。

**辨析｜易错点：** 复合顺序 $ST$ 先 $T$ 后 $S$；$ST$ 与 $TS$ 一般不等。非交换性是算子代数的灵魂。


## 7 小结

- **算子乘法（复合）**：$(ST)x = S(Tx)$，次可乘 $\|ST\| \le \|S\|\|T\|$；乘法一般不交换。
- **算子多项式** $p(T)$：把数多项式代入算子，是逼近与谱映射的载体。
- **逆算子**：$ST = TS = I$ 才叫可逆；逆唯一；双射的连续线性算子自动有连续逆（第五章）。
- **诺伊曼级数**：$\|T\| < 1 \Rightarrow (I-T)^{-1} = \sum T^n$，是「几何级数的算子版」。
- **可逆算子是开集**：$T$ 可逆时 $T + S$（$\|S\|$ 小）仍可逆，逆算子对算子连续依赖。

在下一节，我们进入第三章后半——**连续线性泛函与共轭空间**：把「算子」的特例「数值算子」单独拿出来研究，它就是全部连续线性泛函的集合，即对偶空间。
