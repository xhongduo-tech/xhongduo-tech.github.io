## 为什么泛函可以「凭空」存在

共轭空间 $X^*$ 是有界线性泛函的家。但这里有个隐忧：**这个家里到底住着多少住户？** 也许只有零泛函？Hahn-Banach 定理回答：**住户足够多，多到能把任意两个不同的点分开。** 这是泛函分析的「充足性定理」——它不像三大定理那样给出算子的性质，而是**制造**泛函本身。<span class="marginnote">Hahn-Banach 定理由汉斯 · 哈恩（Hans Hahn，1927）与斯特凡 · 巴拿赫（Stefan Banach，1929）独立证明。它是少数几个<strong>不需要完备性</strong>的大定理——只靠 Zorn 引理（选择公理）即可推进，因而在一般赋范空间、甚至线性空间上都成立。</span>

Hahn-Banach 有两副面孔：**代数形式**（在线性空间上延拓线性泛函）与**几何形式**（用超平面分离凸集）。两副面孔是同一条定理的翻译。

## 1 代数形式：保范延拓

**定理（Hahn-Banach 延拓定理，实情形）**：设 $X$ 是实线性空间，$p: X \to \mathbb{R}$ 是**次线性泛函**（$p(x+y) \le p(x) + p(y)$，$p(\alpha x) = \alpha p(x)$，$\alpha \ge 0$）。若 $f$ 是子空间 $M \subset X$ 上的线性泛函，且

$$
f(x) \le p(x) \quad (\forall x \in M)
$$

则存在 $X$ 上的线性泛函 $F$ 使 $F|_M = f$ 且 $F(x) \le p(x)$ 对所有 $x \in X$ 成立。

**赋范空间保范版**：$X$ 赋范、$f \in M^*$ 时，取 $p(x) = \|f\|\|x\|$，得到 $F \in X^*$ 满足 $F|_M = f$、$\|F\| = \|f\|$——**延拓不增大范数**。

**直觉**：$M$ 上的泛函像一个「地基」，定理保证能盖出整座楼的泛函，且「高度」不超标。<span class="marginnote"><strong>证明的灵魂是「每次只延拓一维」</strong>：对 $x_0 \notin M$，把 $f$ 延到 $M + \mathbb{R}x_0$ 只需选好 $F(x_0)$ 的值 $c$，使 $c$ 落在区间 $\sup_{m \in M}[f(m) - p(m - x_0), \ \inf_{m\in M}[p(m + x_0) - f(m)]]$——非空性由次线性 + $f \le p$ 保证。然后一路延到不能延为止，用 Zorn 引理收尾。</span>

## 2 公式解析：保范延拓的一维步骤

**公式解析：$F(x_0) = c$ 的取值范围。** 设 $x_0 \notin M$，要对一切 $m \in M$、$\alpha$ 满足 $F(m + \alpha x_0) \le p(m + \alpha x_0)$：

$$
f(m) + \alpha c \le p(m + \alpha x_0)
$$

- **第一步，$\alpha > 0$**：不等式变成 $c \le \frac{p(m + \alpha x_0) - f(m)}{\alpha}$。令 $m' = m/\alpha$，$c \le p(m' + x_0) - f(m')$，对一切 $m' \in M$。
- **第二步，$\alpha < 0$**：设 $\alpha = -\beta$，$c \ge \frac{f(m) - p(m - \beta x_0)}{\beta} = f(m'') - p(m'' - x_0)$，对一切 $m'' \in M$。
- **第三步，非空性**：对任意 $m', m'' \in M$，$f(m') - p(m' - x_0) \le p(m'' + x_0) - f(m'')$（展开后由次线性 $p$ 与 $f \le p$ 化简）——上界恒不小于下界，$c$ 存在。
- **第四步，反复延拓**：延到「最大」时用 Zorn 引理，取极大延拓即得全空间上的 $F$。

**核心直觉：$c$ 是被两个「夹逼」常数夹出来的**——数学里无数次出现的「有下界必可延拓」。

**数值算例（在 $C[-1,1]$ 上把泛函延拓）**：设 $M = \{0\}$（零子空间），$f(0) = 0$，$p(x) = \|x\|_\infty$。取 $x_0 = 1$（常值函数 $x_0(t) = 1$）。延拓到 $\operatorname{span}\{x_0\}$：$F(\alpha x_0) = \alpha c$。夹逼区间为 $-\|1 - \alpha\|_\infty/\alpha \le c \le \|1 + \alpha\|_\infty/\alpha$，即 $c \in [-1, 1]$。取 $c = 1$，得 $F(x) = x(1)$——**这正是「在 1 处取值」的泛函 $\delta_1$ 的延拓**，范数恰为 $1$（保范）。若取 $c = 0$，得到「零平均」类泛函，范数也 ≤ 1。**同一情形存在多种保范延拓——Hahn-Banach 是存在定理，不是唯一性定理。**

## 3 推论：泛函能分开点

**推论一（点的分离）**：设 $X$ 赋范，$x_0 \ne 0$，则存在 $f \in X^*$ 使 $f(x_0) = \|x_0\|$ 且 $\|f\| = 1$。取 $M = \mathbb{R}x_0$，$f(\alpha x_0) = \alpha\|x_0\|$，保范延拓即可。

**推论二（分离两个不同点）**：$x_1 \ne x_2$ 时存在 $f$ 使 $f(x_1) \ne f(x_2)$。**共轭空间能把点分开——$X^*$ 是「满的探针库」。**

**推论三（二次对偶嵌入）**：典范映射 $\kappa: X \to X^{**}$，$\kappa(x)(f) = f(x)$ 是**保范线性嵌入**——$X$ 同构于 $X^{**}$ 的闭子空间。每个 $x$ 自己变成一个「作用在泛函上的泛函」。<span class="marginnote"><strong>这些推论的工程意义</strong>：想证明「$x = y$」，只需证明「一切有界线性泛函在 $x, y$ 处相等」。<strong>「泛函分开点」把向量之间的等号翻译成可验证的数字等式</strong>——这是对偶理论的第一个甜头，也是第四篇（对偶空间与弱拓扑）的伏笔。</span>

**推论四（弱收敛的唯一性）**：若 $x_n \rightharpoonup x$ 且 $x_n \rightharpoonup x'$，则 $x = x'$——由推论二，存在 $f$ 使 $f(x) \ne f(x')$ 若 $x \ne x'$，矛盾。**弱收敛极限唯一，虽弱却有身份。**

**推论五（对偶范数的原理解释）**：$\|x\| = \max_{\|f\|\le1}|f(x)|$——范数不仅能「量」，还能被泛函「精确探出」。这使「弱拓扑下范数的下界」变得可操作：想证明 $\|x\|$ 不小，只需找一个范数 ≤ 1 的泛函让它的值不小。**「下界证明」从此多了一条泛函通道。**

## 4 几何形式：凸集分离定理

**定理（凸集分离）**：设 $X$ 是赋范空间，$A$ 是**非空开凸集**，$B$ 是**非空凸集**，$A \cap B = \emptyset$。则存在非零 $f \in X^*$ 与实数 $\gamma$，使

$$
f(a) < \gamma \le f(b) \quad (\forall a \in A, \ b \in B)
$$

几何地说：**存在一个「超平面」$\{x : f(x) = \gamma\}$ 把 $A$ 与 $B$ 严格分开**。若 $B = \{x_0\}$ 是单点、$A$ 是开凸集不包含 $x_0$，则超平面把点与凸集分开。

**例子（$\mathbb{R}^2$ 中的直观）**：取 $A$ = 以原点为心、半径为 $1$ 的开圆盘，$B$ = 点 $(2, 0)$。$A \cap B = \emptyset$，取 $f(x,y) = x$、$\gamma = 1$：对 $(x,y) \in A$ 有 $x < 1$，而 $f(2,0) = 2 \ge 1$——**竖直线 $x = 1$ 严格分开圆盘与点**。若 $B$ 是更大的点集（如闭方块 $[1.5, 2] \times [-1,1]$），同样可找到严格分离超平面。**在 $\mathbb{R}^2$ 里这不过是「有一条直线隔着」的常识，分离定理把它推广到无穷维。**

**严格分离 vs 弱分离**：$A$ 开时得到「严格」分离 $f(a) < \gamma \le f(b)$；若 $A$ 只是闭凸集、$B$ 单点且在 $A$ 外，一般只能保证 $f(a) \le \gamma \le f(b)$（弱分离）。**「开性」换来「严格」——这是凸集分离理论里最常被忘记的前提。**

**为什么重要**：它把「集合不交」这个几何事实，翻译成「存在一个线性不等式把两者隔开」——**凸分析的基石**。优化理论（第八级《凸分析》、第九级《最优化》）里的强对偶、鞍点理论，全都从这里出发。

**公式解析：怎么从代数形式得到几何形式。** 核心是用一个特殊的次线性泛函 $p$ 吸收 $A, B$ 的信息：

$$
p(x) = \inf\{\alpha > 0 : x \in \alpha (A - b_0)\}, \qquad b_0 \in B \text{ 固定}
$$

- **第一步**：$A$ 凸开 ⟹ $A - b_0$ 是含 0 的开凸集，$p$ 是良定义的次线性泛函（闵可夫斯基泛函），且 $p \le 1$ 恰在 $A - b_0$ 的闭包内。
- **第二步**：在 $M = \mathbb{R}b_0$（或更精细的子空间）上定义线性泛函并控制于 $p$，由代数 Hahn-Banach 延拓到全空间。
- **第三步**：由 $B \cap A = \emptyset$，可在 $B$ 上选一点使 $p$ 值严格大于 $1$，翻译回来即得 $f(a) < \gamma \le f(b)$。**几何形式是代数形式穿上「闵可夫斯基泛函」这件衣服。**

**闵可夫斯基泛函的直觉**：$p(x)$ 回答「把 $x$ 缩到 $A$ 里需要多大比例」——它像「以 $A$ 为单位画尺子」。凸集的几何信息被编码成一个次线性泛函，代数 Hahn-Banach 再把它翻译回分离超平面。**「几何问题 → 次线性泛函 → 线性延拓」是分离定理的标准三段论，在优化理论里反复出现。**

## 5 应用速览：Hahn-Banach 的三次出场

**出场一：可解性判据。** 方程 $Tx = b$（值域闭）可解 ⟺ $b$ 与一切零化 $\ker T^*$ 的泛函正交——把解方程变成正交检验（与第八篇紧算子、Fredholm 二择一衔接）。

**出场二：对偶范数公式。** $\|x\| = \sup_{\|f\|\le1}|f(x)|$——**范数本身由泛函来「测量」**，这是弱拓扑与自反性（第五篇）的出发站。

**出场三：凸分析强对偶。** 分离定理直接给出线性规划、拉格朗日对偶的几何解释（第九级《优化》、第八级《凸分析》的桥）。

**辨析｜易错点：** Hahn-Banach 延拓是「存在性的」而不是「构造性的」——它不告诉你 $F$ 长什么样（Zorn 引理是选择公理家族的成员）。在具体计算中，我们通常只使用它的推论（分开点、保范嵌入），而不试图写出显式延拓。

**Hahn-Banach 与选择公理**：定理在「可分」情形下可以用纯构造（逐点延拓 + 归纳）证明，不需要 Zorn 引理；在一般情形（不可分、依赖 Hamel 基）则必须调用选择公理。**因此「$X^*$ 能分开点」「$\kappa$ 保范」这些命题在通常的 ZFC 数学里成立，但在某些「弱选择公理」的宇宙里可能失效**——这提醒我们：泛函分析的一些「常识」其实背着选择公理这件行李。

**出场四（$l^p$ 对偶的构造性味道）**：$1 < p < \infty$ 时 $(l^p)^* = l^q$ 的每个有界泛函都能**显式**写出（$f(x) = \sum f_n x_n$，$f \in l^q$）——此时 Hahn-Banach 不必出场。它真正不可或缺的是 $l^\infty$、$C[a,b]$ 这类「没有显式对偶」的空间：<strong>当探针无法显式构造时，Hahn-Banach 保证它们存在</strong>。**「显式能算」与「存在但说不出」之间的界限，正是 Hahn-Banach 划出的。**

## 6 小结

- **代数形式**：子空间上的线性泛函可延拓到全空间，且不超「次线性控制」。
- **保范版**：$f \in M^*$ 可延成 $F \in X^*$ 且 $\|F\| = \|f\|$——范数不增。
- **一维步骤**：选 $F(x_0) = c$ 落在夹逼区间内，Zorn 引理收尾。
- **分开点**：任意两不同点可由某个 $f \in X^*$ 分开——探针库是满的。
- **几何形式**：开凸集与凸集可被超平面分离——凸分析与对偶的基石。
- **存在非构造**：Zorn 引理保证存在，显式形式未必可得；可分情形才可构造。
- **选择公理依赖**：一般情形的 Hahn-Banach 背着选择公理；这是纯构造观点的边界。
- **弱收敛极限唯一**：$x_n \rightharpoonup x$ 与 $x_n \rightharpoonup x'$ 蕴含 $x = x'$——弱极限虽有弱，却有身份。
- **定位**：本篇制造的泛函，正是第五篇（对偶空间与弱拓扑）的全部原料。
