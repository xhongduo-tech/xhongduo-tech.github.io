# 开映射定理

<div class="epigraph">
<p>连续线性满射的威力，在于它把空间的结构完整地「平铺」到像空间上——开集还保持开。</p>

## 为什么满射值得一个定理

普通连续函数可以很「塌缩」：$f(x) = x^2$ 把开区间 $(-1,1)$ 映成 $[0,1)$——开集映成了不开的集。所以「连续映射把开集映到开集」一般不成立，这样的映射叫**开映射**，是特殊待遇。**开映射定理（open mapping theorem）** 却说：**Banach 空间之间的连续线性满射自动是开映射。** 一个「满射」加上「连续线性」和「完备」，就自动把开集映到开集——这是完备性换取拓扑威力的又一次展示。<span class="marginnote">定理也常写成「若 $T: X \to Y$ 是 Banach 空间之间的连续线性满射，则存在 $r > 0$ 使 $B_Y(0, r) \subset T(B_X(0,1))$」——即「像含有一个以 0 为中心的开球」。这个「含开球」版本是证明的关键，也是应用时最常引用的形态。</span>

## 1 定理陈述与直觉

**定理（开映射定理）**：设 $X, Y$ 是 Banach 空间，$T \in \mathcal{B}(X, Y)$ 是满射（$TX = Y$）。则 $T$ 是**开映射**：$X$ 中每个开集 $U$ 的像 $T(U)$ 是 $Y$ 中的开集。

**直觉**：满射保证「每个 $y$ 都能被 $T$ 打中」，而连续线性 + 完备性保证「打中」的方式是「健康的」——$T$ 不会把某个开球压扁成「薄片」。线性性让「某处开球」可以平移到「处处开球」，完备性（Baire）保证「某处开球」确实存在。<span class="marginnote">对照有限维：满秩矩阵（满射）的行列式非零，确实把开集映到开集（线性同胚）。开映射定理把「满秩 ⟹ 可逆」推广为「Banach 空间满射 ⟹ 开映射」，但<strong>并不保证单射</strong>——$T$ 可以有很大核，只是「开」的性质不受影响。</span>

## 2 证明：Baire 定理 + 缩放

证明的骨架与一致有界原理同源（都用 Baire），但方向不同：

- **第一步，用 Baire 得「某球在像的闭包内」**：$Y = TX = \bigcup_{n=1}^\infty n\,T(B_X(0,1))$（每个 $y \in Y$ 可写成 $Tx$，而 $x \in nB_X(0,1)$ 对某个 $n$）。$Y$ 是 Banach 空间，第二纲，故某个 $nT(B_X(0,1))$ 不是无处稠密的——它的闭包含有一个开球 $\overline{B}(y_0, r)$。
- **第二步，对称性与线性**：由 $T(B_X(0,1))$ 对称（$x \mapsto -x$），闭包也对称；由「闭包含 $B(y_0, r)$」且对称，推出 $\overline{T(B_X(0,1))}$ 含 $B(0, r)$——把球心搬到原点。
- **第三步，从闭包到像本身（关键）**：已知 $B(0, r) \subset \overline{T(B_X(0,1))}$，要证明 $B(0, r/2) \subset T(B_X(0,1))$ 或类似。取 $y \in B(0, r/2)$，递归构造：存在 $x_1$ 使 $\|y - Tx_1\| < r/4$ 且 $\|x_1\| < 1/2$；再对 $y - Tx_1$（范数 $< r/4$）取 $x_2$ 使 $\|y - Tx_1 - Tx_2\| < r/8$ 且 $\|x_2\| < 1/4$……级数 $\sum x_k$ 收敛（$\sum\|x_k\| < 1$，$X$ 完备），且 $T(\sum x_k) = y$（$T$ 连续）。于是 $y \in T(B_X(0,1))$，因为 $\|\sum x_k\| \le \sum\|x_k\| < 1$。<span class="marginnote">第三步的递归是证明的心脏：<strong>利用「像的闭包含球」，用「几何级数式的步长」逐次逼近，靠完备性把逼近点列收敛成精确解</strong>。这个「从闭包到像」的递归论证，本质上就是「把近似解升级成精确解」——它在数值分析与算子方程理论中反复出现。</span>

## 3 公式解析：递归逼近的收敛

把递归论证的关键不等式组写出来：

$$
\|y - T(x_1 + \cdots + x_N)\| < \frac{r}{2^{N+1}}, \qquad \|x_N\| < \frac{1}{2^N}
$$

- **第一步，归纳起点**：$y \in B(0, r/2)$，而 $B(0, r) \subset \overline{T(B_X(0,1))}$，故存在 $x_1$，$\|x_1\| < 1/2$，使 $\|y - Tx_1\| < r/4$（闭包中的点可以任意逼近）。
- **第二步，归纳步骤**：残差 $y - Tx_1$ 范数 $< r/4$，它属于 $B(0, r/2)$，同理存在 $x_2$，$\|x_2\| < 1/4$，使 $\|y - Tx_1 - Tx_2\| < r/8$。继续。
- **第三步，收敛**：$\sum \|x_k\| < \sum 2^{-k} = 1 < \infty$，故 $\sum x_k$ 在 $X$（完备）中收敛到 $x$，$\|x\| \le \sum\|x_k\| < 1$。由 $T$ 连续，$Tx = \lim T(x_1+\cdots+x_N) = y$。

**关键**：步长按 $\frac12, \frac14, \ldots$ 收缩，残差按 $\frac14, \frac18, \ldots$ 收缩——**几何级数保证「残差清零」与「级数收敛」同时发生**。完备性在这里把「几乎解」升级成「精确解」。

## 4 推论：满射等价于「被界控制」

开映射定理的一个等价表述极其实用：

**推论（有界逆推断）**：若 $T \in \mathcal{B}(X, Y)$ 满射，则存在常数 $c > 0$，使对每个 $y \in Y$ 存在 $x$ 满足 $Tx = y$ 且

$$
\|x\| \le c \|y\|
$$

即「每个像都有『不太大』的原像」。这是开映射定理的量化形式：$B(0,r) \subset T(B(0,1))$ 给出 $c = 2/r$ 之类的常数。<span class="marginnote">这个推论的用途：<strong>「满射」不只保证解存在，还保证解「以可控的方式存在」</strong>。在算子方程 $Tx = y$ 中，它说「解对右端连续依赖（但可能有多个解）」。它也是逆算子定理（下节）的跳板：再要求单射，$c$ 界就给出逆算子的连续性。</span>

## 5 应用：为什么「同构」在 Banach 空间如此普遍

开映射定理最著名的应用是 **Banach 同构定理**：若 $T : X \to Y$ 是 Banach 空间之间的连续线性**双射**，则 $T^{-1}$ 自动连续（从而 $T$ 是拓扑同构）。证明：$T$ 是满射 ⟹ 开映射 ⟹ 对开集 $U$，$T(U)$ 开 ⟹ $(T^{-1})^{-1}(U) = T(U)$ 开 ⟹ $T^{-1}$ 连续。

**核心要点：Banach 空间里「代数双射 + 连续」自动蕴含「拓扑同胚」。** 你不需要额外证明逆映射连续——完备性替你做了。这正是泛函分析里「两个空间同构」经常意味着「拓扑同构」的原因。<span class="marginnote">这个定理的实用版本：「如果一个 Banach 空间套着另一个 Banach 空间的范数，且范数更强的那个是完备的，那么两范数等价。」反过来说，两个可比范数若都完备，必等价——这是「范数等价性」的又一判据，与第二章的有限维结论遥相呼应。</span>

## 6 开映射定理的等价形态与反例

开映射定理可以从几个角度重新表述，每一个都在不同场合更顺手。

**等价形态一（有界原像）**：$T$ 满射当且仅当存在 $c > 0$，使每个 $y \in Y$ 都有解 $Tx = y$ 满足 $\|x\| \le c\|y\|$。它把「满射」量化成「每个像都有不太大的原像」，在估计解的大小时非常有用。

**等价形态二（开球版本）**：$T$ 满射当且仅当存在 $r > 0$ 使 $B_Y(0, r) \subset T(B_X(0,1))$。这个版本在证明与估计中最常用——它是「像含开球」的直接翻译。

**辨析｜易错点：** 开映射定理**不保证** $T$ 单射。满射的开映射可以有很大的核。例如投影 $T: \mathbb{R}^2 \to \mathbb{R}$，$T(x_1, x_2) = x_1$：$T$ 满射、开映射（开集投影仍是开集），但 $\ker T$ 是一维的。

**与商空间的联系**：$T$ 穿过商空间 $X/\ker T$ 后变成双射 $\tilde T$，开映射定理保证 $\tilde T^{-1}$ 连续（逆算子定理）。于是

$$
X / \ker T \;\cong\; \operatorname{ran} T \quad \text{（拓扑同构，若 } \operatorname{ran} T \text{ 闭）}
$$

「值域闭」这个条件值得注意：$T$ 满射时值域当然闭；一般情形值域不闭，商同构只在闭情形成立——这正是 Fredholm 理论（第八章）处理「值域何时闭」的动机。

**例（数值稳定性）**：设 $T = I - K$，$\|K\| \le 0.9$。诺伊曼级数给出 $T^{-1} = \sum K^n$，$\|T^{-1}\| \le 10$。于是方程 $(I-K)x = y$ 的解 $x = \sum K^n y$ 满足 $\|x\| \le 10\|y\|$——解对右端稳定依赖，这正是开映射定理「有界原像」形态在数值分析中的化身。


## 7 常见误区与反例汇总

**误区一：把「满射」误当「可逆」**。开映射定理只要求满射，不要求单射。$T(x_1,x_2) = x_1$ 满射但核一维，$T$ 是开映射却不可逆。可逆需要满射 + 单射。

**误区二：忘记值域闭**。$T$ 单射且值域闭时，$T$ 才把 $X$ 同构于 $\operatorname{ran}T$。值域不闭时，$T^{-1}$ 无界。反例：$T(x_n) = (x_n/n)$ 于 $l^2$。

**误区三：把开映射误当「同胚」**。开映射只保证「开集映到开集」，不保证单射、不保证逆连续。同胚 = 连续双射 + 开映射（逆连续），是更强的概念。

**一个有用的反例**：连续双射但逆不连续，在非完备空间可以发生。设 $X = c_{00}$（有限支撑序列，配 $\ell_1$ 范数），$T = $ 恒等但换个范数……这个例子的要点：**不完备时开映射定理失效**。

**对比：完备性在这里做了什么**。Baire 纲定理保证「某球在像的闭包内」，从而「像含开球」。没有完备性，满射的像可能「薄如纸」，开集映射成非开集。

**核心要点：开映射定理 = 完备性 + 满射 ⟹ 开**。三条腿缺一不可。

## 8 例题精讲：开映射的定量使用

**例题一：$\|T\|$ 与「有界原像」常数**。

- $T$ 满射，$B_Y(0,r) \subset T(B_X(0,1))$。
- 则每个 $y$ 有解 $x$ 满足 $\|x\| \le \frac{2}{r}\|y\|$。
- 「满射常数」$c = 2/r$ 量化了「解对右端的依赖」。

**例题二：商映射的同构**。

- $T: X \to Y$ 满射，$\ker T = M$。
- $X/M \cong Y$（拓扑同构），$T$ 分解为投影 + 同构。
- 「商掉核」让满射变双射——商空间理论的应用。

**例题三：逆算子定理的定量版本**。

- $T$ 双射，$\|T^{-1}\| = 1/c$（$c$ 是下界常数）。
- $c\|x\| \le \|Tx\| \le \|T\|\|x\|$：双界不等式。
- 数值上「条件数 $\|T\|\|T^{-1}\|$」度量良态性。

**核心要点**：开映射定理的定量形态 = 有界原像 + 双界不等式；它把「满射」翻译成「稳定可解」。

**辨析｜易错点：** 「有界原像」不唯一（$\ker T \neq 0$ 时解不唯一），它只说「存在一个不大的解」——是存在性不是唯一性。


## 9 小结

- **开映射定理**：Banach 空间间连续线性满射把开集映到开集。
- **等价形态**：满射 ⟹ 像含开球 $B(0,r) \subset T(B(0,1))$。
- **证明**：Baire 定理得「某球在像闭包内」→ 对称搬球心 → 递归逼近（几何级数步长）+ 完备性。
- **推论**：满射 ⟹ 每个像有界原像（$\|x\| \le c\|y\|$）；双射 ⟹ 逆自动连续（Banach 同构定理）。
- **意义**：完备性把「满射」升级为「开映射」，把「代数同构」升级为「拓扑同构」。
