## 为什么研究「数值算子」

有界线性算子的最简单情形，是目标空间 $Y = \mathbb{F}$（$\mathbb{R}$ 或 $\mathbb{C}$）——这时算子把一个向量（或函数）变成一个数。这样的映射叫**连续线性泛函（continuous linear functional）**。它们看起来不起眼，却是泛函分析最重要的研究对象：**内积、积分、求值、均值，全是泛函**。把全体连续线性泛函收集起来，就得到**共轭空间（conjugate space）**或**对偶空间（dual space）**$X^*$。对偶空间像一面镜子：通过「$X$ 上的所有泛函」来观察 $X$，往往能看出现有结构背后隐藏的信息——第七章的弱收敛、第六章的 Hahn-Banach 定理都建立在对偶空间上。<span class="marginnote">「泛函（functional）」一词的字面义就是「与函数相关的作用量」：给定一个函数，输出一个数。积分 $\int_a^b f$ 是泛函，求值 $\delta_t(f) = f(t)$ 是泛函，内积 $\langle x, y\rangle$（固定 $y$）也是泛函。一个空间上「有多少泛函、泛函长什么样」，决定了对偶空间的形状。</span>

## 1 连续线性泛函的定义

**定义**：设 $X$ 是赋范线性空间（$\mathbb{F} = \mathbb{R}$ 或 $\mathbb{C}$）。映射 $f : X \to \mathbb{F}$ 若线性且有界（连续），则称 $f$ 为 $X$ 上的**连续线性泛函（continuous linear functional）**。

由上一节的有界性等价定理，泛函的连续性等价于有界性：存在 $C$ 使

$$
|f(x)| \le C \|x\|, \qquad \forall x \in X
$$

**泛函范数**：

$$
\|f\| = \sup_{\|x\| \le 1} |f(x)|
$$

是「这个泛函最多能把单位向量放大到多大」的读数。<span class="marginnote">泛函的值域是 $\mathbb{F}$（一维），所以它的放大率是一个普通的数 $\|f\|$。全书记号约定：<strong>空间用 $X, Y$，算子用 $T, S$，泛函用小写 $f, g$</strong>——见到小写字母的映射，默认是「到数域」的。</span>

**例一（求值泛函）**：在 $C[0,1]$ 上，对固定 $t_0 \in [0,1]$，定义 $\delta_{t_0}(f) = f(t_0)$。它线性，且

$$
|\delta_{t_0}(f)| = |f(t_0)| \le \|f\|_\infty
$$

故 $\|\delta_{t_0}\| \le 1$；取 $f \equiv 1$ 得等号，$\|\delta_{t_0}\| = 1$。求值泛函是「在一点处观察函数」，它将在分布理论（广义函数）里以「狄拉克 $\delta$ 函数」的面目重生。

**例二（积分泛函）**：$f \mapsto \int_0^1 f(t)\, dt$ 线性，且 $|\int f| \le \int |f| \le \|f\|_\infty$，范数 $= 1$。

## 2 共轭空间 X*：双射的镜像

**定义**：设 $X$ 是赋范线性空间，全体连续线性泛函组成

$$
X^* = \mathcal{B}(X, \mathbb{F})
$$

配泛函范数，称为 $X$ 的**共轭空间 / 对偶空间（dual space）**。

**定理**：由于 $\mathbb{F}$ 是 Banach 空间（完备），由上一节的算子空间完备性定理，**$X^*$ 永远是 Banach 空间**——即使 $X$ 本身不完备。<span class="marginnote">这是个漂亮的补偿：<strong>$X$ 可以不完备，但它的对偶 $X^*$ 必然完备。</strong>于是「$X$ 太破，就研究 $X^*$」成了一种策略——很多问题在对偶空间里变得整齐。这也是共轭空间理论受欢迎的原因之一。</span>

**例：$(c_0)^* = l^1$、$(l^1)^* = l^\infty$**——具体空间的对偶是下一节的主题，这里先立住「对偶空间仍是 Banach 空间」这条主线。

## 3 泛函的几何形象：水平集与半空间

线性泛函 $f : X \to \mathbb{F}$（实情形）有清晰的几何解释。对常数 $\alpha \in \mathbb{R}$，称

$$
\{ x \in X \mid f(x) = \alpha \}
$$

为 $f$ 的**水平集（level set）**，它是一个「超平面」；称

$$
\{ x \in X \mid f(x) \le \alpha \}, \qquad \{ x \in X \mid f(x) \ge \alpha \}
$$

为**半空间（half-space）**。<span class="marginnote">在 $\mathbb{R}^2$ 上，$f(x) = \langle a, x\rangle$ 的水平集就是垂直于向量 $a$ 的直线，半空间就是直线一侧的半个平面。泛函的范数 $\|f\|$ 恰好是「相邻水平集之间的法向距离的倒数」——几何味道十足。</span>

**核心要点：线性泛函 = 一维投影。** $f(x)$ 就是把 $x$「投影到 $f$ 的方向」再报出读数。对偶空间 $X^*$ 就是「一切可能的投影方向」。理解这一点，第六章 Hahn-Banach 定理（「任何点都可以被某个泛函分开」）就有了几何直觉。

## 4 公式解析：泛函范数为什么是「最大放大率」

以积分泛函为例拆解 $\|f\|$ 的定义：

$$
\|f\| = \sup_{\|x\| \le 1} |f(x)|
$$

- **第一步，先看懂 sup 的集合**：$\{x : \|x\| \le 1\}$ 是单位闭球。$|f(x)|$ 在单位球上的上确界，就是「单位向量被 $f$ 放大后的最大绝对值」。
- **第二步，联系有界性定义**：$|f(x)| \le \|f\|\|x\|$ 对一切 $x$ 成立。取 $x$ 为单位向量即得 $|f(x)| \le \|f\|$；反过来 sup 给出的是「最小可行常数」——**泛函范数是满足 $|f(x)| \le C\|x\|$ 的最小 $C$**。
- **第三步，计算实例**：对积分泛函，$\|f\| = \sup_{\|g\|_\infty \le 1}|\int_0^1 g| \le \sup_{\|g\|_\infty\le 1}\int_0^1|g| \le 1$；取 $g \equiv 1$（范数 1）得 $|\int g| = 1$，故 $\|f\| = 1$。

**关键**：范数的计算分「上界」与「极值」两步——先放缩到某个常数，再找「取等号」的单位向量。上下夹击才得到精确范数。

## 5 双对偶的预告：X 与 X^** 

把「取对偶」再做一次：$X^*$ 的全体连续线性泛函组成 $X^{**} = (X^*)^*$，称为**二次共轭空间（second dual）**。存在自然嵌入

$$
\kappa : X \to X^{**}, \qquad (\kappa x)(f) = f(x)
$$

（把 $x$ 当作「作用在泛函 $f$ 上的泛函」：输入一个 $f$，输出 $f(x)$）。$X$ 通过 $\kappa$ 嵌入 $X^{**}$；若 $\kappa$ 是满射（即 $X^{**} = \kappa(X)$），则 $X$ 称为**自反空间（reflexive space）**。<span class="marginnote">这个「再看一眼」的构造在第七章展开。自反空间（如 $l^p$，$1<p<\infty$）具有「对偶的对偶回到自身」的好性质，而非自反空间（如 $c_0$、$l^1$）则暴露出「镜子多了会失真」的现象。今天先记住 $\kappa$ 的名字与含义。</span>

## 6 例题精讲：泛函的三个计算

**例题一：求值泛函的范数**。

- $\delta_{t_0}(f) = f(t_0)$ 于 $C[0,1]$。
- $|\delta_{t_0}(f)| = |f(t_0)| \le \|f\|_\infty$，$\|\delta_{t_0}\| \le 1$。
- 取 $f \equiv 1$ 得等号：$\|\delta_{t_0}\| = 1$。

**例题二：积分泛函的范数**。

- $f \mapsto \int_0^1 f$ 于 $C[0,1]$。
- $|\int f| \le \int|f| \le \|f\|_\infty$，$\|f\| \le 1$。
- 取 $f \equiv 1$ 得 $\int f = 1$：范数 = 1。

**例题三：$X^*$ 永远是 Banach 空间**。

- $\mathbb{F}$ 完备，$\mathcal{B}(X,\mathbb{F})$ 完备（算子空间定理）。
- 即使 $X$ 不完备，$X^*$ 也完备。
- 「对偶总完备」是 $X^*$ 受欢迎的原因。

**核心要点**：泛函范数 = 最大放大率；$X^*$ 自动完备；泛函是「一维投影」。

**辨析｜易错点：** 求值泛函 $\delta_{t_0}$ 在 $L^2$ 上没有意义（$L^2$ 函数在单点可取任意值）；它只对 $C$（连续函数）合法。


## 7 小结

- **连续线性泛函**：$f : X \to \mathbb{F}$ 线性且有界；范数 $\|f\| = \sup_{\|x\|\le 1}|f(x)|$。
- **共轭空间** $X^* = \mathcal{B}(X, \mathbb{F})$：永远是 Banach 空间，即使 $X$ 不完备。
- **几何形象**：泛函是「一维投影」，水平集是超平面，半空间是泛函的「正负半侧」。
- **经典例子**：求值泛函、积分泛函、内积（固定一变量）都是连续线性泛函。
- **二次共轭**：$X^{**}$ 通过 $\kappa$ 嵌入，满射时 $X$ 自反——这是第七章的伏笔。

在下一节，我们回答「具体空间上的泛函长什么样」——**具体空间上连续线性泛函的表示**：$C[0,1]$、$l^p$、$L^p$ 的对偶空间，将各自以漂亮的「表示定理」揭示出来。
