## 为什么从赋范空间开始

度量空间给我们一把「尺子」——距离 $d(x,y)$——却不知道「加法」与「数乘」是什么意思。而线性代数给我们一张「网」——向量空间——却没有「远近」。**赋范线性空间把两者焊接起来**：在一个线性空间上装上范数 $\|\cdot\|$，线性结构与拓扑结构同时到场。<span class="marginnote">这是泛函分析的第一块地基，也是整条主线的枢纽：往上看，<strong>Banach 空间的三大基本定理、Hahn-Banach、对偶理论全都建筑在它上面</strong>；往下看，第三级《线性代数》给了你有限维的直觉，而这里要把「有限」换成「无穷」。</span>

这一篇是泛函分析的**总览式开篇**：不纠缠每一条定理的细枝末节（那些在第二章至第十章各有专篇），而是把「赋范空间 + 完备性 + 有限维」这条主线一次看清——它们是整个学科大厦的承重墙。

## 1 线性空间：把加法和数乘抽象出来

**线性空间（vector space）**：非空集合 $X$ 上定义加法 $x+y$ 与数乘 $\alpha x$（$\alpha \in \mathbb{R}$ 或 $\mathbb{C}$），满足结合律、交换律、分配律、零元与负元存在、$1 \cdot x = x$ 等八条公理。<span class="marginnote">八条公理你早已在第三级《线性代数》逐条见过——那里的直觉（坐标、基、维数）在这里继续有效，只是「维数」可能要变成无穷。</span>

经典例子立即铺开：

- $\mathbb{R}^n$、$\mathbb{C}^n$：有限维，坐标直觉的故乡。
- 数列空间 $l^p$（$1 \le p < \infty$）：满足 $\sum |x_n|^p < \infty$ 的数列，按坐标相加。
- $l^\infty$：有界数列。
- $C[a,b]$：$[a,b]$ 上的连续函数，逐点相加、逐点数乘。
- $L^p(a,b)$：Lebesgue 意义下 $p$ 次幂可积的（等价类）函数。

这些例子共享同一座骨架：**元素不同，线性运算的规则却一模一样**。这正是「抽象」的收益——一条定理同时管住函数、数列与向量。

## 2 范数：长度如何公理化

**核心概念（范数）**：线性空间 $X$ 上的函数 $\|\cdot\|: X \to \mathbb{R}$ 称为**范数（norm）**，若满足

1. **正定性**：$\|x\| \ge 0$，且 $\|x\| = 0 \iff x = 0$；
2. **齐次性**：$\|\alpha x\| = |\alpha| \cdot \|x\|$；
3. **三角不等式**：$\|x + y\| \le \|x\| + \|y\|$。

有了范数，距离由 $d(x,y) = \|x - y\|$ 诱导，于是度量空间的一切结论（极限、完备、紧致）自动到场。**范数是一座桥：把「代数长度」翻译成「拓扑距离」。**<span class="marginnote">范数三条公理正是平面几何里「长度」的三条本质性质；它们足够少，少到能同时容纳 $\mathbb{R}^n$ 的欧氏长度、$C[a,b]$ 的上确界长度、$l^p$ 的 $p$ 次和长度——「长度」的多样性与统一性在此第一次相遇。</span>

几个同一条空间上可以放不同范数的例子：

- $\mathbb{R}^n$ 上的 $\|x\|_2 = \sqrt{\sum x_i^2}$（欧氏）、$\|x\|_1 = \sum |x_i|$、$\|x\|_\infty = \max |x_i|$。
- $C[a,b]$ 上的 $\|f\|_\infty = \max_{a \le x \le b}|f(x)|$（一致范数，几何意义最强）与 $\|f\|_1 = \int_a^b |f(x)|\,dx$。

**这些范数在有限维里「等价」（见 §4），在无穷维里却可能给出完全不同的收敛**——这是无穷维与有限维的第一道分水岭。

## 3 完备性与 Banach 空间

**核心概念（Banach 空间）**：按范数诱导的距离**完备**的赋范线性空间称为**Banach 空间**：每个 Cauchy 列都收敛。完备性回答的问题是：**「极限不存在」这种事，在这个空间里还会不会发生？**<span class="marginnote">类比中学数学：有理数 $\mathbb{Q}$ 里 $\sqrt{2}$ 的十进制逼近是 Cauchy 列却不收敛——因为极限「掉出」了 $\mathbb{Q}$。实数 $\mathbb{R}$ 补上了这个洞，这就是完备化。Banach 空间就是「把洞补上」的无穷维版本。</span>

**例题：$C[a,b]$ 完备吗？** 完备。若 $\{f_n\}$ 一致 Cauchy（即 $\|f_n - f_m\|_\infty \to 0$），则逐点极限 $f(x) = \lim f_n(x)$ 存在；由一致收敛的连续性定理（第一级《数学分析》），$f$ 连续——极限没掉出空间。**完备性的本质：连续函数的极限仍是连续函数。**

对照：$C[a,b]$ 配上积分范数 $\|f\|_1$ 就**不完备**——逐段函数的 Cauchy 序列可以收敛到一个不连续函数。**同一个空间，范数一换，完备性就丢。**

**例题：$l^p$（$1 \le p < \infty$）是 Banach 空间。** 设 $\{x^{(n)}\}$ 是 $l^p$ 中的 Cauchy 列。对每个坐标 $k$，$|x_k^{(n)} - x_k^{(m)}| \le \|x^{(n)} - x^{(m)}\|_p \to 0$，故每个坐标收敛到 $x_k$；再证明「坐标极限"聚拢"成一个 $l^p$ 元素」：由 Cauchy 性取 $N$ 使 $m, n \ge N$ 时 $\|x^{(n)} - x^{(m)}\|_p \le 1$，对有限和取极限得 $\sum_{k=1}^K |x_k^{(n)} - x_k|^p \le 1$，令 $K \to \infty$ 得 $x^{(n)} - x \in l^p$ 且 $x \in l^p$，最后 $\|x^{(n)} - x\|_p \to 0$。**逐坐标收敛 + 范数一致有界，是判定「$l^p$ 完备」的标准两步。**

**辨析｜易错点：** 完备性依赖范数，而范数依赖空间。同一元素集上，换一个范数可能从不完备变完备、或从完备变不完备；「完备」不是集合的固有属性，而是「集合 + 范数」这个整体的属性。另一个常见混淆：**「闭」与「完备」**——完备是「所有 Cauchy 列都收敛」（内在性质），闭是「极限点都在内」（相对环境性质）；完备度量空间中的闭子空间才完备。

**核心对比表：常见空间与其完备性。**

| 空间 | 范数 | Banach？ | 备注 |
| --- | --- | --- | --- |
| $\mathbb{R}^n$ / $\mathbb{C}^n$ | 任意等价范数 | 是 | 有限维全完备 |
| $l^p$（$1 \le p < \infty$） | $\|x\|_p = (\sum\|x_n\|^p)^{1/p}$ | 是 | 逐坐标收敛 + 一致有界 |
| $l^\infty$ | $\sup_n\|x_n\|$ | 是 | 有界数列 |
| $c_0$（收敛到 0 的数列） | $\|\cdot\|_\infty$ | 是 | $l^\infty$ 的闭子空间 |
| $C[a,b]$ | $\|\cdot\|_\infty$ | 是 | 一致收敛极限连续 |
| $C[a,b]$ | $\|f\|_1 = \int_a^b\|f\|$ | **否** | 逐段函数破坏完备性 |
| $\mathbb{Q}$ | $|\cdot|$ | 否 | $\sqrt 2$ 的逼近列不掉内 |

这张表值得背下来：**前几行全是 Banach，倒数两行不是——「完备性」是空间的原配，不是标配。**

## 4 公式解析：等价范数与 Riesz 引理

**公式解析：Riesz 引理——有限维的分水岭。** 设 $X$ 是赋范线性空间，$M \subsetneq X$ 是闭真子空间，则对每个 $\theta \in (0,1)$ 存在 $x_\theta$ 使

$$
\|x_\theta\| = 1, \qquad \operatorname{dist}(x_\theta, M) = \inf_{m \in M}\|x_\theta - m\| \ge \theta
$$

- **第一步，直觉**：单位球面上存在一点，它离子空间 $M$ 至少 $\theta$ 那么远。$\theta$ 可以任意接近 1——几乎「垂直」地伸出 $M$。
- **第二步，证明骨架**：取 $x_1 \notin M$，令 $d = \operatorname{dist}(x_1, M) > 0$（$M$ 闭），取 $m_0 \in M$ 使 $\|x_1 - m_0\| \le d/\theta$，再令 $x_\theta = (x_1 - m_0)/\|x_1 - m_0\|$，验证即可。
- **第三步，为什么是分水岭**：**有限维里，闭真子空间仍「布满」单位球——找不到这种点；无穷维里，闭真子空间可以被「绕开」。** 用 Riesz 引理可构造「几乎正交」的无穷单位向量列 $\{x_n\}$（$\|x_n\| = 1$，$\|x_n - x_m\| \ge \theta$，$n \ne m$），从而单位球不列紧——**有限维 ≠ 无穷维的第一严格证据**。

由此得到一组并列的等价刻画（有限维特征）：

- $X$ 有限维 ⟺ $X$ 的单位闭球紧 ⟺ $X$ 的每个闭有界集紧（Heine-Borel 在无穷维失效）。

## 5 范数的等价性

**核心概念（等价范数）**：$X$ 上两个范数 $\|\cdot\|_1, \|\cdot\|_2$ 称为**等价**，若存在常数 $a, b > 0$ 使

$$
a\|x\|_1 \le \|x\|_2 \le b\|x\|_1 \quad (\forall x \in X)
$$

**定理（有限维范数等价）**：$\mathbb{R}^n$ 上的一切范数彼此等价。

**证明要点**：把 $\|x\|$ 看作连续函数，限制在（欧氏范数下）紧的单位球面 $S = \{x : \|x\|_2 = 1\}$ 上，取到最小值 $m > 0$ 与最大值 $M$，于是 $m\|x\|_2 \le \|x\| \le M\|x\|_2$。**证明只用了两件事：球面紧 + 范数连续——而这两件事在有限维成立、在无穷维不成立。**<span class="marginnote"><strong>在无穷维，范数可以「不等价」到改变收敛与完备性</strong>：$l^1$ 与 $l^\infty$ 上的标准范数给出不同收敛；$C[a,b]$ 上的一致范数与 $L^1$ 范数甚至导出不同的完备化空间（连续函数 vs 可积函数）。<strong>「等价范数」是有限维独有的奢侈品。</strong></span>

**辨析｜易错点：** 不要把「范数等价」与「空间同构」混为一谈。等价范数不改变拓扑与收敛，而同构是代数结构之间的可逆线性映射（且保持有界）。等价的范数给出同一个 Banach 空间（换个尺子而已）；不同构的空间连元素都对应不上。

**数值算例：$\mathbb{R}^2$ 上三种范数之比。** 设 $x = (1, 2)$：$\|x\|_1 = 3$、$\|x\|_2 = \sqrt{5} \approx 2.236$、$\|x\|_\infty = 2$。一般地 $c_1\|x\|_2 \le \|x\|_1 \le c_2\|x\|_2$，其中最佳常数 $c_1 = 1$、$c_2 = \sqrt 2$（由 Cauchy-Schwarz，$\sum|x_i| \le \sqrt n \|x\|_2$）——**最佳等价常数由 $n$ 决定，这就是为什么「有限维」字样必不可少：$n$ 固定时常数有限，而把 $n \to \infty$ 推向 $l^p$ 时「等价」崩坏。**

**有限维闭子空间必完备**：设 $M \subset X$ 有限维，任取 $M$ 中 Cauchy 列，在 $M$ 的一组基下坐标是 $\mathbb{R}^n$ 中的 Cauchy 列（由范数等价，坐标范数等价于 $M$ 上的任一范数），收敛且极限仍在 $M$ 内。**这条事实在后面的正交分解、商空间、Riesz 引理证明里反复用到。**

## 6 小结

- **赋范线性空间 = 线性空间 + 范数**：范数的三角不等式把代数长度变成拓扑距离。
- **Banach 空间 = 完备的赋范空间**：Cauchy 列必收敛，极限不「掉出」空间。
- **Riesz 引理**：闭真子空间可被单位向量「绕开」——无穷维的签名。
- **有限维特征**：单位球紧、范数全等价、闭有界集紧——三者是有限维的专利。
- **对照**：$C[a,b]$ 配 $\|\cdot\|_\infty$ 完备，配 $\|\cdot\|_1$ 不完备——范数决定完备性。
- **定位**：Banach 空间是一切「有界线性算子」「基本定理」「对偶理论」的共同舞台。
