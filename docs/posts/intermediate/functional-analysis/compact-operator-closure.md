# 紧算子的极限与紧算子空间的闭性

<div class="epigraph">
<p>紧算子被一致收敛的大门守护着：一列紧算子的极限，也必须是紧算子。</p>

## 为什么「闭性」如此重要

我们在第三章证明过 $\mathcal{B}(X,Y)$ 是 Banach 空间——有界算子的极限仍是有界算子。现在问：**紧算子的极限还是紧算子吗？** 答案的肯定性，就是**紧算子空间的闭性**。它带来两个直接后果：一是「有限秩算子的一致极限是紧算子」（这是构造紧算子的万能方法）；二是 $\mathcal{K}(X,Y)$ 自身是 Banach 空间（可谈算子级数、可做逼近）。闭性是「紧算子 = 有限秩的完成」这一整套理论的钥匙。<span class="marginnote">为什么闭性不平凡？有界算子的极限当然有界（完备性），但「有界序列有收敛像子列」这个性质在取极限时可能丢失——需要证明它「极限封闭」。这正是本节的核心：<strong>用 $\varepsilon/3$ 三段估计把紧性传递过极限</strong>。</span>

## 1 定理陈述

**定理（紧算子空间的闭性）**：设 $X$ 是赋范线性空间，$Y$ 是 Banach 空间，$T_n \in \mathcal{K}(X,Y)$ 且 $T_n \to T$（一致收敛，即 $\|T_n - T\| \to 0$）。则 $T$ 是紧算子。

**推论**：$\mathcal{K}(X,Y)$ 是 $\mathcal{B}(X,Y)$ 的**闭**子空间，从而是 Banach 空间。特别地，**有限秩算子的一致极限是紧算子**。

**证明（$\varepsilon/3$ 三段论证）**：

- **第一步，逼近**：对 $\varepsilon > 0$，取 $n$ 使 $\|T - T_n\| < \varepsilon/3$。取有界列 $\{x_k\}$，$\|x_k\| \le 1$。
- **第二步，$T_n$ 的紧性**：$\{T_n x_k\}$ 有收敛子列（$T_n$ 紧），不妨设为柯西列：$\|T_n x_{k_i} - T_n x_{k_j}\| < \varepsilon/3$（$i, j$ 大）。
- **第三步，三段估计**：

$$
\|T x_{k_i} - T x_{k_j}\| \le \|Tx_{k_i} - T_n x_{k_i}\| + \|T_n x_{k_i} - T_n x_{k_j}\| + \|T_n x_{k_j} - T x_{k_j}\| < \varepsilon
$$

- **第四步，完备性**：$\{T x_{k_i}\}$ 是 $Y$ 中的柯西列，$Y$ 完备故收敛——$T$ 紧。<span class="marginnote">「$\varepsilon/3$ 三段估计」是分析学最经典的手法：<strong>把「$T$ 的作用」拆成「$T$ 到 $T_n$ 的误差」（两段，各 $\\varepsilon/3$）与「$T_n$ 的作用」（一段，$\\varepsilon/3$）</strong>。$T_n$ 紧（中间那段可控），误差可控（$T_n \\to T$），合起来 $T$ 紧。这个模板在泛函分析里反复出现。</span>

**核心要点：紧算子在一致收敛下封闭**——$\mathcal{K}(X,Y)$ 是 Banach 空间，且「有限秩的一致极限」自动是紧算子。

## 2 逆命题：紧算子都能被有限秩逼近吗

上一节我们有了「有限秩 ⟹ 紧」，本节有了「紧算子的一致极限仍紧」。**反过来：每个紧算子都是有限秩算子的一致极限吗？** 答案：**在 Banach 空间里，是！**

**定理（紧算子的有限秩逼近）**：设 $X$ 是 Banach 空间，$T \in \mathcal{K}(X,Y)$，则存在有限秩算子 $T_n$ 使 $\|T_n - T\| \to 0$。

**证明思路（用 $T(B_X)$ 的紧性）**：

- $T(B_X)$ 相对紧，对 $\varepsilon$ 取有限 $\varepsilon$-网 $\{y_1,\ldots,y_N\}$（全有界性）。
- 用 $\{y_i\}$ 构造有限秩算子 $T_\varepsilon$（如把 $y_i$ 上的「局部投影」拼起来），使 $\|T - T_\varepsilon\| < \varepsilon$。
- 取 $\varepsilon = 1/n$ 得 $T_n$。<span class="marginnote">这个定理说明：<strong>紧算子 = 有限秩算子的一致极限</strong>（若值域空间的范数结构允许，通常需要 $Y$ 的逼近性质）。它是「有限秩是紧算子的阶梯」这一直觉的精确化——紧算子正是「有限维片段的极限」。</span>

**辨析｜易错点：** 上述「有限秩逼近」定理需要 $Y$ 满足**逼近性质（approximation property）**——这在一般 Banach 空间未必成立（Enflo 1973 给出反例）。Hilbert 空间、$L^p$、$C(K)$ 都满足逼近性质，所以绝大多数应用场景下「紧 = 有限秩的极限」成立。

## 3 公式解析：ε/3 三段估计

把三段估计的每一步标清：

$$
\|T x_{k_i} - T x_{k_j}\| \le \underbrace{\|T x_{k_i} - T_n x_{k_i}\|}_{(A)} + \underbrace{\|T_n x_{k_i} - T_n x_{k_j}\|}_{(B)} + \underbrace{\|T_n x_{k_j} - T x_{k_j}\|}_{(C)}
$$

- **第一步（$A$、$C$：误差项）**：$\|T - T_n\| < \varepsilon/3$，且 $\|x_{k_i}\| \le 1$，故 $(A) \le \|T - T_n\|\|x_{k_i}\| < \varepsilon/3$，$(C)$ 同理。
- **第二步（$B$：$T_n$ 的紧性项）**：$T_n$ 紧，$\{T_n x_k\}$ 有柯西子列，取大 $i,j$ 使 $(B) < \varepsilon/3$。
- **第三步（相加）**：三段各 $< \varepsilon/3$，总和 $< \varepsilon$——$\{Tx_{k_i}\}$ 柯西。
- **第四步（完备性）**：$Y$ 完备，柯西列收敛——$T$ 紧。

**关键**：$\varepsilon/3$ 的「3」不是魔法，而是「误差两段 + 紧性一段」的三分。**把不可控项（$T$ 本身）替换成可控项（$T_n$）**，是分析学处理极限的通用策略。

## 4 例题精讲：闭性的三个应用

**例题一：积分算子的有限秩逼近**。

- $T_K$ 紧（连续核）。$K$ 可用退化核 $K_N(s,t) = \sum_{i=1}^N \alpha_i(s)\beta_i(t)$ 一致逼近（Weierstrass）。
- $T_{K_N}$ 有限秩（值域 $\subset \operatorname{span}\{\alpha_i\}$），$T_{K_N} \to T_K$。
- 紧算子 = 有限秩极限的活例。

**例题二：$\mathcal{K}(X)$ 是 Banach 空间**。

- $\mathcal{K}(X,Y)$ 是 $\mathcal{B}(X,Y)$ 的闭子空间，$\mathcal{B}$ 完备 ⟹ $\mathcal{K}$ 完备。
- 于是可谈「紧算子级数」：$\sum T_n$ 绝对收敛（$T_n$ 紧）则收敛（紧）。
- 数值方法里「用有限秩逼近紧算子」的收敛性由此保证。

**例题三：恒等算子不是有限秩极限**。

- 无穷维 $X$ 上，$\|I - T_n\| \ge 1$ 对任何有限秩 $T_n$（有限秩的值域不覆盖 $X$ 的有界集）。
- 故 $I$ 不能被有限秩一致逼近，$I$ 不是紧算子。
- 「恒等不可紧逼近」与「紧 = 有限秩极限」互相印证。

**核心要点**：闭性、有限秩逼近、$I$ 不可逼近——三个例题共同刻画「紧算子 = 有限秩的一致闭包」这一完整图景。

**辨析｜易错点：** 有限秩逼近定理的方向是「紧 ⟹ 有限秩极限」；反方向「有限秩极限 ⟹ 紧」正是本节定理。两个方向合起来：**紧算子 = 有限秩算子的一致极限**（在满足逼近性质的空间）。

## 5 例题精讲：闭性的练习

**练习一：有限秩算子的极限是紧的**。

- 有限秩 $T_n$，$T_n \to T$ 一致收敛。
- $\varepsilon/3$ 三段估计：$T$ 紧。
- 「有限秩的一致极限 = 紧」是构造紧算子的万能法。

**练习二：积分算子作为有限秩极限**。

- 连续核 $K$ 用退化核 $K_N$ 一致逼近。
- $T_{K_N}$ 有限秩，$T_{K_N} \to T_K$。
- 积分算子 = 有限秩极限的活例。

**练习三：恒等算子不能由有限秩逼近**。

- 无穷维时 $\|I - T_n\| \ge 1$ 对任何有限秩 $T_n$。
- $I$ 不是紧算子。
- 「恒等不可逼近」与「紧 = 有限秩极限」互补。

**核心要点**：闭性三练习——有限秩极限、退化核、恒等——都围绕「紧 = 有限秩的一致闭包」。

**辨析｜易错点：** 有限秩逼近需要值域空间满足逼近性质；$Y = C(K)$、$L^p$ 满足，但一般空间不一定。


## 6 小结

- **闭性定理**：紧算子的一致极限是紧算子；$\mathcal{K}(X,Y)$ 是 Banach 空间。
- **证明**：$\varepsilon/3$ 三段估计——误差两段 + 紧性一段。
- **有限秩逼近**：紧算子 = 有限秩的一致极限（需逼近性质）。
- **$I$ 不紧**：无穷维恒等算子不可被有限秩一致逼近。
- **地位**：闭性让紧算子理论成为「有限秩的完成」，Fredholm 理论建立在它之上。
