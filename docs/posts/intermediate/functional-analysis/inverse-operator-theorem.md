# 逆算子定理

## 为什么「逆自动连续」令人惊讶

微积分里，连续双射 $f$ 的逆 $f^{-1}$ 可以不连续：$f(x) = x$ 在 $[0,1)$ 与 $\{1\}$ 之间的双射（把 $[0,1)$ 映到 $[0,1]\setminus\{1\}$ 再调整）的逆就不连续。可对**线性**映射，事情完全不同：**Banach 空间之间的连续线性双射，其逆自动连续。** 这就是**逆算子定理（inverse operator theorem）**。它的惊人之处在于：只要 $T$ 是双射（代数性质）且连续（拓扑性质），逆的连续性（拓扑性质）就免费获得——中间全靠完备性与开映射定理。<span class="marginnote">在有限维，这个定理是显然的：满秩矩阵可逆且逆矩阵连续。但证明无法直接推广（无穷维没有行列式）。逆算子定理的威力是：<strong>验证「逆存在」只需验证「双射」，验证「逆连续」完全免费</strong>——这让「解方程算子可逆」的证明变得可行。</span>

## 1 定理陈述

**定理（逆算子定理）**：设 $X, Y$ 是 Banach 空间，$T \in \mathcal{B}(X, Y)$ 是双射（单射且满射）。则 $T^{-1} \in \mathcal{B}(Y, X)$，即 $T^{-1}$ 有界线性。

**证明**：$T$ 是满射 ⟹（开映射定理）$T$ 是开映射。设 $U \subset X$ 开，则 $T(U)$ 开，即 $(T^{-1})^{-1}(U)$ 开——这正是 $T^{-1}$ 连续的拓扑定义（开集的原像开）。线性性显然。证毕。<span class="marginnote">三行证明！这就是「站在开映射定理肩膀上」的全部。开映射定理负责「满射把开集映到开集」，逆算子的连续性就是开映射定义的直接重述。整个第五章三大定理的价值，在这一刻集中兑现。</span>

**核心要点：Banach 空间间「连续线性双射 = 拓扑同构」。** 代数双射 + 连续，自动给出拓扑同胚——这是完备性的最优厚赠之一。

## 2 逆算子的连续性 vs 有界性

逆算子定理说的是：$T^{-1}$ 作为线性算子有界（连续）。它的有界性可以量化：

**等价形态**：$T$ 是 Banach 空间间的连续线性双射 ⟺ 存在 $c > 0$ 使

$$
c\|x\| \le \|Tx\| \le C\|x\|, \qquad \forall x \in X
$$

（下界来自 $T^{-1}$ 有界：$\|x\| = \|T^{-1}(Tx)\| \le \|T^{-1}\|\|Tx\|$；上界来自 $T$ 有界。）这个「双界」形态在应用中极其常用：**要证明两个空间「本质上相同」，只需找双射且验证双界不等式**。<span class="marginnote">「双界」也解释了「范数等价」的算子视角：$X$ 上两个范数 $\|\cdot\|_a, \|\cdot\|_b$ 等价，当且仅当恒等映射 $I: (X,\|\cdot\|_a) \to (X,\|\cdot\|_b)$ 是连续双射且逆连续——即「双界」。第二章的有限维范数等价定理可以由此统一理解。</span>

## 3 例子：傅里叶变换的逆

$L^2(\mathbb{R})$ 上的傅里叶变换 $\mathcal{F}$ 是双射（Plancherel + 反演定理），由逆算子定理，$\mathcal{F}^{-1}$ 自动连续——事实上它是酉算子，$\mathcal{F}^{-1} = \mathcal{F}^*$。<span class="marginnote">这个例子展示定理的「免验证」威力：傅里叶变换的逆的存在性由「$\mathcal{F}$ 是双射」保证，连续性自动——不必手工估计逆的范数。反过来，若 $T$ 是双射但 $X, Y$ 不完备，逆可能无界——完备性是逆连续的前提。</span>

**例二（积分算子可逆性）**：设 $T = I - K$ 其中 $\|K\| < 1$，由诺伊曼级数 $T$ 可逆（第三章）。逆算子定理保证 $T^{-1}$ 有界，且 $\|T^{-1}\| \le \frac{1}{1 - \|K\|}$（由 $\|T^{-1}\| = \|\sum K^n\| \le \sum\|K\|^n$）。

## 4 公式解析：双界不等式

把「逆有界 ⟺ 双界」的推导写清楚：

$$
\|T x\| \le \|T\| \|x\|, \qquad \|x\| \le \|T^{-1}\| \|T x\|
$$

- **第一步（上界）**：$T$ 有界 ⟹ $\|Tx\| \le \|T\|\|x\|$——输出被输入控制。
- **第二步（下界）**：$T^{-1}$ 有界 ⟹ 对 $y = Tx$，$\|x\| = \|T^{-1}y\| \le \|T^{-1}\|\|y\| = \|T^{-1}\|\|Tx\|$——输入被输出控制。
- **第三步（合成）**：两个方向合起来：$\frac{1}{\|T^{-1}\|}\|x\| \le \|Tx\| \le \|T\|\|x\|$。这就是「双界」：$T$ 既不能压缩太多（下界），也不能放大太多（上界）。

**关键**：「逆有界」=「$T$ 有非零的下界」=「$T$ 不会把不同点压得太近」。**这个「下界」条件在求解算子方程 $Tx = y$ 时，就是「解对右端稳定依赖」（良定性）的保证。**

## 5 逆算子定理的应用：扰动与稳定性

**应用一（可逆算子对扰动的稳定性）**：若 $T$ 可逆且 $\|S\| < \|T^{-1}\|^{-1}$，则 $T + S$ 可逆，且

$$
\|(T + S)^{-1}\| \le \frac{\|T^{-1}\|}{1 - \|T^{-1}\|\|S\|}
$$

证明：$T + S = T(I + T^{-1}S)$，$\|T^{-1}S\| < 1$，用诺伊曼级数。（第三章已见，这里用逆算子定理把「可逆」提升为「逆连续」。）

**应用二（Banach 空间的同构分类）**：逆算子定理说明「Banach 空间之间的拓扑同构」与「连续线性双射」是同一件事。分类两个 Banach 空间是否「一样」，只需找连续线性双射。<span class="marginnote">在应用上，这个定理是「稳定性分析」的基石：数值方法里，若离散化算子 $T_h \to T$ 且 $T$ 可逆，则对足够小的 $h$，$T_h$ 可逆且逆一致有界——这就是「离散方案的收敛性/稳定性」的数学保障。</span>

## 6 逆算子定理的两个直接推论

逆算子定理最常被引用的两个推论，值得单独强调。

**推论一（范数等价）**：$X$ 上的两个范数 $\|\cdot\|_a, \|\cdot\|_b$ 都使 $X$ 成为 Banach 空间，且 $\|x\|_a \le C\|x\|_b$（一个范数被另一个控制），则两范数**等价**（存在 $c$ 使 $c\|x\|_b \le \|x\|_a$）。

证明：恒等映射 $I: (X, \|\cdot\|_b) \to (X, \|\cdot\|_a)$ 连续（由控制条件），且是双射；两个空间都是 Banach，逆算子定理给出 $I^{-1}$ 连续，即反向控制。**这是「完备空间上可比范数必等价」的精确版本**——比第二章的有限维结果更普遍，代价是需要完备性。

**推论二（闭值域的判别）**：设 $T \in \mathcal{B}(X, Y)$，$\operatorname{ran} T$ 闭。则 $T$ 是「几乎满射到值域」的——$T: X/\ker T \to \operatorname{ran} T$ 是拓扑同构，且存在 $c > 0$ 使 $d(x, \ker T) \le c\|Tx\|$。这条「闭值域 ⟹ 商映射同构」在 Fredholm 理论里反复出现。

**例（$\operatorname{ran}T$ 不闭的情形）**：$T: l^2 \to l^2$，$T(x_1, x_2, \ldots) = (x_1/1, x_2/2, x_3/3, \ldots)$。$T$ 是单射、值域稠密但不闭（$e_n$ 的像是 $e_n/n$，收敛到 0 不在值域）。此时 $T^{-1}$（在值域上）无界——「值域不闭」与「逆无界」相伴。这个例子说明为什么「闭值域」是逆算子定理适用的关键条件。

**辨析｜易错点：** 逆算子定理的「双射」是作为**集合映射**的双射，不是「拓扑同构」的先验假设。定理的全部意义在于：集合双射 + 连续 + 完备 ⟹ 拓扑同构。初学者容易忘记「$T$ 连续」的前提——不连续的代数同构当然逆不连续。

## 7 例题精讲：逆算子定理的使用

**例题一：证明 $l^2$ 上两个范数等价**。

- **第一步**：设 $\|x\|_a \le C\|x\|_b$ 对一切 $x$，且两范数都使 $l^2$ 完备。
- **第二步**：恒等 $I: (l^2, \|\cdot\|_b) \to (l^2, \|\cdot\|_a)$ 连续（由控制条件）、双射。
- **第三步**：逆算子定理，$I^{-1}$ 连续，即 $\|x\|_b \le c\|x\|_a$。两范数等价。

**例题二：积分算子 $I - K$ 的可逆性**。

- **第一步**：设 $K: C[0,1] \to C[0,1]$，$(Kf)(t) = \int_0^t k(t,s)f(s)\,ds$，$\|K\| < 1$。
- **第二步**：诺伊曼级数 $(I-K)^{-1} = \sum K^n$，且 $\|(I-K)^{-1}\| \le \frac{1}{1-\|K\|}$。
- **第三步**：逆算子定理保证 $I - K$ 是拓扑同构——「$I - K$ 满射」与「逆连续」同时成立。**Volterra 积分方程的解存在唯一且稳定**。

**例题三：值域不闭时的失败**。

- **第一步**：$T(x_n) = (x_n/n)$ 于 $l^2$。$T$ 单射、值域稠密不闭。
- **第二步**：$T$ 不是满射（$T l^2 \neq l^2$），逆算子定理不适用。
- **第三步**：$T^{-1}$ 在 $\operatorname{ran}T$ 上无界（$\|T^{-1} e_n\| = n$）。**「值域不闭」直接导致逆无界**——这正是逆算子定理对满射的依赖。

**核心要点**：逆算子定理的三种使用模式——「证范数等价」、「证算子可逆」、「诊断值域问题」。**它把「双射」升级为「同构」，把「可逆」升级为「稳定可逆」**。

**辨析｜易错点：** 例题三说明「$T^{-1}$ 无界」与「$\operatorname{ran}T$ 不闭」是一体两面。初学者用逆算子定理时，最常忘记验证「$T$ 是满射」——只验证单射是不够的。

## 8 例题精讲：可逆性的最后检查

**检查一：$T$ 双射 ⟺ 有连续逆**。

- $T$ 双射 + 连续 + 完备 ⟹ $T^{-1}$ 连续（逆算子定理）。
- 代数双射自动升级为拓扑同构。
- 「$X$ 完备」是升级的前提。

**检查二：双界不等式**。

- $c\|x\| \le \|Tx\| \le C\|x\|$：$T$ 连续双射的量化。
- $c = 1/\|T^{-1}\|$、$C = \|T\|$。
- 条件数 $\kappa = C/c$ 度量良态性。

**检查三：值域闭 ⟺ 逆有界**。

- $\operatorname{ran}T$ 闭 + 单射 ⟹ $T^{-1}$（在值域上）有界。
- $\operatorname{ran}T$ 不闭 ⟹ $T^{-1}$ 无界。
- 「值域闭」是 Fredholm 理论的关键条件。

**核心要点**：可逆性检查 = 双射 + 完备 + 值域闭；逆算子定理把「可逆」升级为「稳定可逆」。

**辨析｜易错点：** 单射不够（还要满射）；值域不闭时逆无界。两个条件缺一不可。


## 9 小结

- **逆算子定理**：Banach 空间间连续线性双射的逆自动有界连续。
- **证明**：开映射定理的直接推论——满射开映射 ⟹ 逆连续（三行）。
- **双界形态**：$c\|x\| \le \|Tx\| \le C\|x\|$ ⟺ $T$ 连续双射；这是范数等价的算子视角。
- **应用**：可逆算子附近仍可逆（$\|S\|$ 小）；Banach 空间同构分类；数值稳定性分析。
- **前提**：$X, Y$ 完备——不完备时双射的逆可以无界。
