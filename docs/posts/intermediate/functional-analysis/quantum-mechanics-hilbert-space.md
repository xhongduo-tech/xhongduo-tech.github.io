# 量子力学的数学框架：Hilbert 空间与态

## 为什么量子力学是泛函分析的化身

量子力学的基本对象——**态、观测、概率**——全部可以用本专题的语言精确表述：态是 $L^2$ 空间的单位向量，可观测物理量是自伴算子，测量概率是内积的模平方。这一整套框架由冯 · 诺伊曼在 1932 年的《量子力学的数学基础》中建立，它把量子力学的哲学争论（波粒二象性、测量问题）变成**数学定理**：Hilbert 空间给出态空间，Riesz 表示定理给出观测的对偶，谱分解给出测量的概率。泛函分析至此不再是「纯数学」，而是物理学的骨骼。<span class="marginnote">量子力学的四条公理与泛函分析一一对应：<strong>（1）态 = Hilbert 空间的单位向量；（2）可观测量 = 自伴算子；（3）测量 = 谱投影（Born 规则）；（4）演化 = 酉算子 $e^{-iHt}$</strong>。本节聚焦（1）——态空间的结构。</span>

## 1 态是 Hilbert 空间的单位向量

**公理（态）**：量子系统的态由可分 Hilbert 空间 $H$ 中的**单位向量** $\psi$ 描述（相差一个相位 $e^{i\theta}$ 的向量代表同一物理态）。

**例（单粒子）**：$H = L^2(\mathbb{R}^3)$，态 $\psi(x)$ 是波函数，归一化条件

$$
\int_{\mathbb{R}^3} |\psi(x)|^2\\, dx = 1
$$

$|\psi(x)|^2$ 是「粒子在 $x$ 处的概率密度」——Born 规则。<span class="marginnote">为什么是 $L^2$ 而不是别的空间？因为「平方可积」保证归一化可行（总概率为 1），且 $L^2$ 是 Hilbert 空间（完备 + 内积），支持叠加原理与概率解释。$L^1$（绝对可积）虽可归一化但没有内积——「态叠加」需要内积。</span>

**叠加原理**：$\psi_1, \psi_2$ 是态，则 $\alpha\psi_1 + \beta\psi_2$（归一化后）也是态——态空间是线性空间。这是量子力学区别于经典力学的核心：**态可以叠加**。

**例（自旋）**：自旋 $\frac12$ 系统的态空间是 $H = \mathbb{C}^2$，态 $|\psi\rangle = \alpha|{\uparrow}\rangle + \beta|{\downarrow}\rangle$（$|\alpha|^2 + |\beta|^2 = 1$）。二能级系统的所有态是 Bloch 球上的点。

## 2 可观测量是自伴算子

**公理（可观测量）**：每个可观测物理量 $A$ 对应 $H$ 上的**自伴算子** $\hat A$。

- 位置：$\hat x = M_x$（乘 $x$），自伴。
- 动量：$\hat p = -i\hbar\frac{\partial}{\partial x}$，在合适定义域上自伴。
- 能量（Hamiltonian）：$\hat H = -\frac{\hbar^2}{2m}\Delta + V(x)$，自伴（物理上要求）。

**为什么自伴（而非对称）**：自伴算子保证谱是实的（能量可测）、谱分解存在（测量概率可定义）。对称但不自伴的算子没有物理意义——这是 §5.7「自伴 vs 对称」的物理归宿。<span class="marginnote">「可观测量是自伴算子」是泛函分析给量子力学的最大礼物：<strong>谱分解定理（§9.7）保证每个自伴算子都有「测量值 + 投影」的完整结构</strong>。没有谱分解，量子测量理论无从谈起。冯 · 诺伊曼正是靠自伴算子理论把量子力学数学化的。</span>

**例**：位置算子 $\hat x$ 的自伴性：$\langle x\psi, \varphi\rangle = \int x\psi\bar\varphi = \langle \psi, x\varphi\rangle$——乘实函数自伴。谱 = $\mathbb{R}$（连续谱），对应「位置可以取任何实数」。

## 3 概率解释：Born 规则

**公理（Born 规则）**：对态 $\psi$（$\|\psi\| = 1$）测量可观测量 $A$：

- 结果的期望值是 $\langle \psi, \hat A\psi\rangle$；
- 结果落在集合 $B$ 的概率是 $\langle \psi, E_B\psi\rangle$，其中 $E_B$ 是谱投影。

**例**：若 $\hat A$ 有离散谱 $\{\lambda_n\}$（特征值），特征向量 $\{\psi_n\}$ 张成空间，则

$$
P(\text{测得 } \lambda_n) = |\langle \psi, \psi_n\rangle|^2
$$

**这就是「概率 = 内积平方」的 Born 规则**——把态 $\psi$ 在特征向量 $\psi_n$ 上的投影平方当作概率。<span class="marginnote">Born 规则的几何：<strong>$\\psi$ 在 $\\psi_n$ 上的投影 $\\langle\\psi,\\psi_n\\rangle$ 是「振幅」，概率是振幅的平方</strong>。这与 Fourier 系数、正交展开（第四章）完全一致——「测量」就是「投影」，谱分解就是「把态按测量基展开」。量子概率是内积几何的直接后果。</span>

## 4 公式解析：态叠加与归一化

把「态叠加」的数学细节写清：

$$
\psi = \alpha\psi_1 + \beta\psi_2, \qquad \|\psi\|^2 = |\alpha|^2 + |\beta|^2 + 2\operatorname{Re}(\bar\alpha\beta\langle\psi_1,\psi_2\rangle)
$$

- **第一步（叠加）**：$\psi_1, \psi_2$ 是单位向量（态），$\alpha, \beta$ 是复数振幅。
- **第二步（范数）**：$\|\psi\|^2 = |\alpha|^2\|\psi_1\|^2 + |\beta|^2\|\psi_2\|^2 + 2\operatorname{Re}(\bar\alpha\beta\langle\psi_1,\psi_2\rangle)$。
- **第三步（交叉项 = 干涉）**：$\langle\psi_1,\psi_2\rangle \neq 0$ 时出现**干涉项** $2\operatorname{Re}(\cdots)$——这是量子叠加的签名（双缝干涉正是它）。
- **第四步（归一化）**：物理态要求 $\|\psi\| = 1$，故 $\alpha, \beta$ 需调节使范数归一。

**关键**：叠加的范数不是「振幅平方和」，而是含交叉项（干涉）——**「量子叠加」与「经典混合」的本质区别就在干涉项**。正交态（$\langle\psi_1,\psi_2\rangle = 0$）无干涉，是「干净的」叠加。

## 5 例题精讲：态空间的练习

**例题一：位置态与动量态**。

- 位置态：$L^2(\mathbb{R})$ 中「局域在 $x_0$」的态（高斯波包 $\psi(x) = (2\pi\sigma^2)^{-1/4}e^{-(x-x_0)^2/4\sigma^2}$）。
- 动量态：$\hat p$ 的特征函数 $e^{ipx/\hbar}$（广义，不在 $L^2$，需用谱分解）。
- 位置与动量的变换：Fourier 变换（酉算子）。

**例题二：二能级系统的叠加**。

- $\psi = \alpha|{\uparrow}\rangle + \beta|{\downarrow}\rangle$，$\langle{\uparrow}|{\downarrow}\rangle = 0$。
- $\|\psi\|^2 = |\alpha|^2 + |\beta|^2 = 1$（正交态无干涉）。
- 测量自旋：$P({\uparrow}) = |\alpha|^2$。

**例题三：无限深势阱的能级**。

- $H = L^2(0,L)$，势阱边界 $u(0)=u(L)=0$。
- 能量本征函数 $\psi_n = \sqrt{2/L}\sin(n\pi x/L)$，能级 $E_n = \frac{n^2\pi^2\hbar^2}{2mL^2}$。
- $\{\psi_n\}$ 是正交基（完备），任何态按 $\{\psi_n\}$ 展开——谱分解的应用。

**核心要点**：态空间的三个练习——波包、叠加、能级——都验证「态 = 单位向量、观测 = 自伴算子、概率 = 内积平方」三条公理。

**辨析｜易错点：** 态向量相差全局相位 $e^{i\theta}$ 代表同一物理态（只影响整体相位，不影响概率），但**相对相位**（不同分量的相位差）是物理的——它决定干涉。叠加时相位不能随便丢弃。

## 6 常见误区与辨析

**误区一：以为波函数本身是概率**。

- $\psi$ 是振幅，$|\psi|^2$ 才是概率密度。
- 概率 = 内积平方（Born 规则）。

**误区二：把「叠加态」当「混合态」**。

- 叠加态含干涉项（交叉项），混合态（密度矩阵）不含。
- 这是量子与经典的本质区别。

**误区三：忘记归一化**。

- 物理态是单位向量，$\|\psi\| = 1$。
- 叠加后必须重新归一化。

**核心要点：态 = 单位向量、概率 = 内积平方**——量子力学公理与内积几何严格对应。


## 7 小结

- **态**：Hilbert 空间的单位向量（相差相位视为同一态）；$L^2$ 波函数是典型。
- **叠加原理**：态空间线性；干涉项来自内积交叉项。
- **可观测量**：自伴算子；谱实、谱分解存在。
- **Born 规则**：概率 = $|\langle\psi,\psi_n\rangle|^2$；测量 = 投影。
- **例子**：位置/动量/自旋/势阱能级。
- **定位**：量子力学把泛函分析的核心定理（自伴算子、谱分解、Riesz）全部用上。
