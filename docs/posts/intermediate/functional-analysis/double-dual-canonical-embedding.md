# 二次共轭空间与典范嵌入

<div class="epigraph">
<p>对偶可以再做一次：$X$ 反射进 $X^{**}$，就像空间在镜子里再映一次。</p>

</div>

## 为什么对偶还要再取一次

我们有了 $X^*$（连续线性泛函的全体）。自然的追问是：$X^*$ 也是赋范空间，它的对偶 $X^{**} = (X^*)^*$ 长什么样？答案出人意料地深刻：**$X$ 可以「嵌入」$X^{**}$——每个 $x$ 都对应一个作用在泛函上的泛函 $\kappa x$，且嵌入保持范数（等距）。** 于是每个 $X$ 都是某个「更大的空间」$X^{**}$ 的子空间。这一视角有两个后果：一是研究 $X$ 时可以「从对偶的对偶看回来」，二是**自反空间**（$X = X^{**}$，下节）成为一类特殊而重要的空间。<span class="marginnote">直觉：$f \in X^*$ 是「$X$ 上的观测者」。$X^{\ast\ast}$ 的元素是「观测者的观测者」——给定一个 $f$，返回一个数。$x$ 天然就是这样一位「观测者的观测者」：它把 $f$ 映到 $f(x)$。这就是典范嵌入（canonical embedding）。</span>

## 1 二次共轭空间

**定义**：$X^{**} = (X^*)^*$ 称为 $X$ 的**二次共轭空间（second dual / bidual）**。它是 Banach 空间（对偶永远完备，第三章已证）。配范数

$$
\|F\|_{X^{**}} = \sup_{\|f\|_{X^*} \le 1} |F(f)|
$$

**典范嵌入（canonical embedding）**：定义映射

$$
\kappa : X \to X^{**}, \qquad (\kappa x)(f) = f(x), \quad f \in X^*
$$

即「把 $x$ 当作一个『对 $f$ 求值』的泛函」：$\kappa x$ 输入泛函 $f$，输出 $f(x)$。<span class="marginnote">符号：$\kappa x$ 是一个作用在泛函上的泛函，所以 $(\kappa x)(f)$ 才合法。注意「求值」这个动作在两边都是线性的：$f \mapsto f(x)$ 是 $X^*$ 上的连续线性泛函——$\kappa x$ 的存在由「逐点求值是线性泛函」保证。</span>

**核心要点：$\kappa$ 把 $X$ 嵌入 $X^{**}$**——每个向量都被安放进「更高一层」的空间，作为「泛函的求值器」。

## 2 典范嵌入是等距的

**定理：$\kappa$ 是等距嵌入**：对每个 $x \in X$，

$$
\|\kappa x\|_{X^{**}} = \|x\|_X
$$

**证明（用 Hahn-Banach）**：

- **上界**：$\|\kappa x\| = \sup_{\|f\|\le 1}|f(x)| \le \sup_{\|f\|\le 1}\|f\|\|x\| \le \|x\|$。
- **下界**：由第六章推论一（保范泛函存在），存在 $\|f_0\| = 1$ 使 $f_0(x) = \|x\|$。故 $\|\kappa x\| \ge |f_0(x)| = \|x\|$。

两方向相等。<span class="marginnote">下界方向是 Hahn-Banach 的又一次登场：<strong>「单位泛函精确测出 $x$ 的范数」让嵌入不损失范数</strong>。没有 Hahn-Banach，$X$ 只是 $X^{\ast\ast}$ 的（不一定等距的）子空间；有了它，$X$ 是 $X^{\ast\ast}$ 的「等距副本」。</span>

**推论**：若 $\kappa x = \kappa y$，则 $f(x) = f(y)$ 对一切 $f$，由点分离 $x = y$——$\kappa$ 单射。于是 **$X$ 与 $\kappa(X)$ 等距同构**，我们可把 $X$ 视为 $X^{**}$ 的子空间。

## 3 什么时候 $\kappa$ 是满射：自反性

$\kappa(X)$ 是 $X^{**}$ 的闭子空间（等距嵌入的像是闭的，因为 $X$ 完备且 $\kappa$ 等距）。问题：$\kappa(X) = X^{**}$ 吗？

**定义**：若典范嵌入 $\kappa : X \to X^{**}$ 是**满射**（从而等距同构），则称 $X$ 为**自反空间（reflexive space）**，记作 $X = X^{**}$。<span class="marginnote">自反空间 = 二次对偶回到自身。注意「自反」不是「$X$ 与 $X^{\ast\ast}$ 同构」——那太弱（可能存在非典范畴同构）。自反性严格要求<strong>由 $\kappa$ 实现的同构</strong>——这是几何意义最丰富的那一个。</span>

**例子**：

- 有限维空间自反（$X^{**} = X$）。
- $l^p$、$L^p$（$1 < p < \infty$）自反（由 $(l^p)^* = l^q$ 与 $(l^q)^* = l^p$，$1/p + 1/q = 1$）。
- $c_0$、$l^1$、$L^1$、$L^\infty$ **不自反**。<span class="marginnote">记忆法：<strong>$1 < p < \infty$ 的空间自反，端点 $p = 1, \infty$ 不自反</strong>。自反性的「黄金区间」正是 Hilbert 空间（$p = 2$）所在的位置。为什么端点失败？因为 $l^1$ 的对偶是 $l^\infty$，而 $l^\infty$ 的对偶比 $l^1$ 大得多——对偶「膨胀」了。</span>

## 4 公式解析：$\kappa x$ 的范数

把「$\|\kappa x\| = \|x\|$」的完整计算写一遍：

$$
\|\kappa x\|_{X^{**}} = \sup_{\|f\|_{X^*} \le 1} \big| (\kappa x)(f) \big| = \sup_{\|f\| \le 1} |f(x)|
$$

- **第一步，展开定义**：$\|\kappa x\| = \sup_{\|f\|_{X^*}\le 1}|(\kappa x)(f)|$。这是 $X^{**}$ 的范数定义，$F = \kappa x$ 是作用在 $f$ 上的泛函。
- **第二步，代入 $\kappa x$ 的定义**：$(\kappa x)(f) = f(x)$。于是 $\|\kappa x\| = \sup_{\|f\|\le 1}|f(x)|$。
- **第三步，Hahn-Banach**：上界 $\le \|x\|$；下界用「存在 $\|f_0\|=1$，$f_0(x)=\|x\|$」得 $\ge \|x\|$。相等。

**关键**：$X^{**}$ 范数与 $X$ 范数的联系完全由 Hahn-Banach 提供——**没有保范泛函存在定理，$\|\kappa x\|$ 可能严格小于 $\|x\|$，嵌入就不是等距**。

## 5 自反空间为什么重要（预告）

自反空间有两条著名性质（下节展开）：

1. **有界序列有弱收敛子列**（Eberlein-Šmulian）：自反空间中闭单位球是弱列紧的——这是「无穷维的 Bolzano-Weierstrass」，变分法里「极小化序列有极限」的保证。
2. **$\|X\|$ 的几何**：自反空间的单位球是弱紧的，这让变分问题、对偶问题的解存在。

这两条让自反空间成为「最接近有限维行为的无穷维空间」——有限维空间的紧性、极小值存在性等福利，在自反空间里大部分保留。<span class="marginnote">在变分法（第十章）里：要找「泛函 $J$ 的极小值」，先取极小化序列，需要「有界 ⟹ 有收敛子列」——自反空间提供弱收敛子列，配合下半连续性得到极小元。$L^2$ 型空间（自反）因此成为变分法的理想舞台。</span>

## 6 常见误区与反例汇总

**误区一：误以为「$X$ 与 $X^{**}$ 同构」就是自反**。自反要求由**典范嵌入** $\kappa$ 实现的同构。存在 $X \cong X^{**}$（非典范同构）但不自反的空间——「存在某种同构」比「典范满射」弱得多。

**误区二：把「$X^*$ 与 $X$ 同构」当自反**。Hilbert 空间 $H^* \cong H$（Riesz），但这是「$H$ 与 $H^*$ 同构」，不是自反性。自反是 $X = X^{**}$。两者的区别：$X^*$ 与 $X^{**}$ 不是一回事。

**误区三：忘记 $\kappa$ 等距性的前提**。$\|\kappa x\| = \|x\|$ 依赖 Hahn-Banach（保范泛函存在）。若 $X^*$ 不够丰富（非赋范情形），嵌入可能不是等距。

**一个关键例子**：$c_0$ 的 $\kappa$ 是等距嵌入 $c_0 \hookrightarrow (l^1)^* = l^\infty$，但 $\kappa(c_0) \subsetneq l^\infty$——$c_0$ 不自反。

**例（自反的证明模板）**：证 $l^p$（$1<p<\infty$）自反：$(l^p)^* = l^q$、$(l^q)^* = l^p$，且这些同构**是典范的**（坐标对应），故 $\kappa$ 满射。

**核心要点：自反性 = 典范二次对偶满射**。判断自反，只需验证「$(X^*)^*$ 的典范嵌入是否满」，并确认同构是典范的而非任意的。

## 7 例题精讲：二次对偶的练习

**练习一：$\kappa$ 是等距嵌入**。

- $(\kappa x)(f) = f(x)$，$\|\kappa x\| = \sup_{\|f\|\le1}|f(x)| = \|x\|$。
- 上界：$|f(x)| \le \|x\|$；下界：支撑泛函 $f_0$。
- 等距 ⟹ $X$ 是 $X^{**}$ 的闭子空间。

**练习二：$l^p$（$1<p<\infty$）自反**。

- $(l^p)^* = l^q$、$(l^q)^* = l^p$，同构是典范的。
- $\kappa$ 满射，$l^p$ 自反。
- 二次对偶回到自身。

**练习三：$c_0$ 不自反**。

- $(c_0)^* = l^1$、$(l^1)^* = l^\infty$。
- $\kappa(c_0) \subsetneq l^\infty$（$c_0$ 是 $l^\infty$ 的真闭子空间）。
- 二次对偶「膨胀」了。

**核心要点**：二次对偶 = 「观测者的观测者」；自反 ⟺ 典范嵌入满射。

**辨析｜易错点：** 「$X$ 与 $X^{**}$ 同构」≠「自反」——自反要求典范嵌入满射，不是存在某个同构。


## 8 小结

- **二次共轭**：$X^{**} = (X^*)^*$，恒为 Banach 空间。
- **典范嵌入** $\kappa$：$(\kappa x)(f) = f(x)$，把 $x$ 变成「泛函的求值器」。
- **等距性**：$\|\kappa x\|_{X^{**}} = \|x\|_X$，靠 Hahn-Banach 的保范泛函存在定理。
- **自反性**：$\kappa$ 满射 ⟺ $X = X^{**}$；$l^p$、$L^p$（$1<p<\infty$）自反，端点不自反。
- **重要性**：自反空间有弱列紧性（Eberlein-Šmulian），变分问题的解存在性由此保证。
