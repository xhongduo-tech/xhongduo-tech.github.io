## 为什么从线性空间开始

第一章里，我们认识了度量空间：那里有「距离」、有「极限」、有「完备性」，却还没有「加法」与「数乘」。但泛函分析的主角不是随便什么点，而是**可以相加、可以伸缩的点**——函数、数列、多项式，它们天然可以逐点相加、逐项数乘。把这些点装进一个集合，配上加法与数乘两种运算，就得到**线性空间（linear space）**；再在它上面放一把「尺子」（范数）度量长短，就得到**赋范线性空间（normed linear space）**。<span class="marginnote">一句话记住本章的位置：<strong>线性结构</strong>（向量空间）保证「可以叠加」，<strong>度量结构</strong>（范数）保证「可以谈极限」——两个结构叠加，就是泛函分析的舞台。第二级《线性代数》研究的是有限维向量空间，本章把它推广到无穷维，并加上分析学的「极限」能力。</span>

本章的目标之一，是把你在《线性代数》里熟悉的「基」「坐标」「线性变换」「特征值」全部搬到无穷维空间——你会发现有些概念原样保留，有些则必须被彻底改造。而一切从今天这个最朴素的定义开始。

## 1 线性空间的定义

设 $X$ 是非空集合，$\mathbb{F}$ 是数域（本专题取 $\mathbb{F} = \mathbb{R}$ 或 $\mathbb{C}$）。在 $X$ 上定义两种运算：

- **加法** $+$：$X \times X \to X$，$(x, y) \mapsto x + y$；
- **数乘** $\cdot$：$\mathbb{F} \times X \to X$，$(\alpha, x) \mapsto \alpha x$。

若它们满足下列**八条运算律**，则称 $X$ 为**线性空间（linear space）**或**向量空间（vector space）**，其中的元素叫**向量（vector）**：

| 编号 | 加法运算律 | 编号 | 数乘运算律 |
| --- | --- | --- | --- |
| (1) | 交换律 $x + y = y + x$ | (5) | $(\alpha\beta)x = \alpha(\beta x)$ |
| (2) | 结合律 $(x+y)+z = x+(y+z)$ | (6) | $1 \cdot x = x$ |
| (3) | 存在零元 $0$，$x + 0 = x$ | (7) | $\alpha(x+y) = \alpha x + \alpha y$ |
| (4) | 存在负元 $-x$，$x + (-x) = 0$ | (8) | $(\alpha + \beta)x = \alpha x + \beta x$ |

这八条就是「线性结构」的全部：前四条说 $X$ 在加法下构成**交换群**，后四条把数乘与加法、数域自身的运算协调起来。<span class="marginnote">零元 $0$ 与负元 $-x$ 的唯一性由运算律自动推出，不必另作假设。第二级《抽象代数》中「群」理论会告诉你：凡是满足交换群公理的对象，加法结构完全相同——线性空间只是「多了数乘」的交换群。</span>

**辨析｜易错点：** 零元 $0$ 是一个**向量**，它不同于数 $0$，也不同于数乘的结果 $\alpha \cdot 0$——虽然三者常常共用符号 $0$。在函数空间里，零元就是「恒取零值的函数」$f \equiv 0$；在数列空间里，零元就是零序列。识别每个具体空间里「谁是 $0$」，是理解线性空间的第一步。

## 2 例子：从 $\mathbb{R}^n$ 到函数空间

**例一：$\mathbb{R}^n$ 与 $\mathbb{C}^n$。** 分量逐点相加、逐分量数乘，这是最经典的有限维线性空间，也是第二级《线性代数》的全部对象。

**例二：多项式空间。** $P$ 表示全体实系数多项式组成的集合，按通常的加法与数乘构成线性空间。它比 $\mathbb{R}^n$ 新在哪里？——它是**无穷维**的：基底 $\{1, t, t^2, \ldots\}$ 有无穷多个。有限维与无穷维的分水岭，第一次出现。

**例三：连续函数空间 $C[0,1]$。** 定义加法与数乘为逐点运算：

$$
(f + g)(t) = f(t) + g(t), \qquad (\alpha f)(t) = \alpha f(t)
$$

逐点运算把「函数的加法」化归为「数轴上的加法」，八条运算律自动成立。<span class="marginnote">注意 $C[0,1]$ 的零元是零函数 $f \equiv 0$，「$f + g$」是在<strong>每个点</strong>上把函数值相加——这就是「逐点」二字的含义。整个函数空间理论都建立在「逐点运算」这个朴素起点上。</span>

**例四：数列空间 $s$。** 全体实数列 $(x_1, x_2, \ldots)$ 按逐项加法与数乘构成线性空间。它提醒我们：线性空间不要求元素是「函数」，数列、矩阵、多项式都是合法的向量。

## 3 范数的定义

有了线性结构，再往上面放「长度」。设 $X$ 是数域 $\mathbb{F}$ 上的线性空间，若映射 $\|\cdot\| : X \to \mathbb{R}$ 满足**范数三公理**：

1. **非负性**：$\|x\| \ge 0$，且 $\|x\| = 0 \iff x = 0$；
2. **齐次性**：$\|\alpha x\| = |\alpha| \, \|x\|$，对一切 $\alpha \in \mathbb{F}$；
3. **三角不等式**：$\|x + y\| \le \|x\| + \|y\|$；

则称 $\|\cdot\|$ 为 $X$ 上的一个**范数（norm）**，$(X, \|\cdot\|)$ 称为**赋范线性空间（normed linear space）**。

把范数与第一章的度量对看：**三条公理恰好保证 $d(x, y) = \|x - y\|$ 是一个度量**——非负性与同一性对应度量公理 (1)，齐次性保证 $\|x - y\| = \|y - x\|$（取 $\alpha = -1$）对应对称性，三角不等式则直接对应度量三角不等式。<span class="marginnote">因此每个赋范线性空间都是度量空间，只是度量必须由范数「平移不变」地产生：$d(x+z, y+z) = d(x,y)$。反过来，度量空间不一定是线性的——它可能连加法都没有。</span>

**关键结论**：范数把线性结构与度量结构缝在了一起。度量可以定义「距离」，范数不仅定义「长度」$\|x\| = d(x, 0)$，还兼容线性运算。这正是 Banach 空间理论要建立的平台。

## 4 反三角不等式：范数是连续函数

范数三公理中，三角不等式有一个威力巨大的推论——**反三角不等式（reverse triangle inequality）**：

$$
\big| \|x\| - \|y\| \big| \le \|x - y\|
$$

证明只需两步：$\|x\| \le \|x-y\| + \|y\|$ 给出 $\|x\| - \|y\| \le \|x-y\|$；交换 $x, y$ 再合并即得带绝对值的版本。<span class="marginnote">这个不等式在第一章的度量版本里已经见过（$\big| d(x,z) - d(y,z) \big| \le d(x,y)$），现在它换上了范数形态。它说明范数是「利普希茨连续」的：自变量的变化 $\|x-y\|$ 直接控制范数读数的变化。</span>

它的实际用途遍布全书：估计「两个解的范数相差多少」、证明「范数作为映射 $X \to \mathbb{R}$ 连续」、以及未来一切「先估计范数再取极限」的操作。

## 5 公式解析：逐点范数怎么验证三角不等式

对初学者，范数三公理最容易卡在三角不等式的验证上。以 $C[0,1]$ 的 sup 范数为例拆解：

$$
\|f\|_\infty = \max_{t \in [0,1]} |f(t)|
$$

目标：证明 $\|f + g\|_\infty \le \|f\|_\infty + \|g\|_\infty$。

- **第一步，逐点估计**：对任意固定 $t \in [0,1]$，实数轴上的三角不等式给出

$$
|f(t) + g(t)| \le |f(t)| + |g(t)| \le \|f\|_\infty + \|g\|_\infty
$$

- **第二步，解释第二处 $\le$**：因为 $|f(t)|$ 对一切 $t$ 不超过 $\max_s |f(s)| = \|f\|_\infty$，$|g(t)|$ 同理。
- **第三步，取上界**：左边 $|f(t)+g(t)|$ 对 $t$ 的最大值正是 $\|f+g\|_\infty$，于是

$$
\|f+g\|_\infty \le \|f\|_\infty + \|g\|_\infty
$$

**关键**：验证范数三角不等式的通用套路是「**先逐点估计，再取上界**」——先用实数的三角不等式处理每个「点」，再把这些逐点估计统一放大到公共上界。这与第一章验证 sup 度量三角不等式的方法如出一辙，因为 $L^p$ 范数（$p>1$）的三角不等式验证要困难得多，需要闵可夫斯基不等式——那是后续章节的内容。

再看一个重要的区别。设 $X = \mathbb{R}^2$，在 $x = (x_1, x_2)$ 上定义三种范数：

$$
\|x\|_1 = |x_1| + |x_2|, \quad \|x\|_2 = \sqrt{x_1^2 + x_2^2}, \quad \|x\|_\infty = \max\{|x_1|, |x_2|\}
$$

**同一个线性空间上可以放不同的范数**。三种范数都满足三条公理，但数值不同、几何形状不同（单位球分别是菱形、圆、正方形）。在 $\mathbb{R}^2$ 上它们是「等价」的（第二章将证明有限维空间一切范数等价），但这已经预告：**范数的选择不是唯一的，选择不同，几何就不同**。

## 6 小结

- **线性空间**：非空集合配上加法与数乘，满足八条运算律；有限维的典型是 $\mathbb{R}^n$，无穷维的典型是 $C[0,1]$、多项式空间、数列空间。
- **范数**：非负（$\|x\|=0 \iff x=0$）、齐次、三角不等式三条公理；**$d(x,y) = \|x-y\|$ 自动是度量**，故赋范线性空间是度量空间。
- **反三角不等式** $\big|\|x\|-\|y\|\big| \le \|x-y\|$ 说明范数是连续函数，是全书最常用的估计工具。
- **范数不唯一**：同一线性空间可有多种范数（$\ell_1, \ell_2, \ell_\infty$ 等），单位球形状不同。
- **逐点运算**：函数空间的加法数乘是逐点的，零元是零函数——「谁是 $0$」要在具体空间里辨认。

在下一节，我们将认识三个最重要的无穷维赋范空间——**$C[a,b]$、$l^p$ 与 $L^p$**，看范数如何把它们各自装备成完整的研究对象。
