## 为什么线性算子是主角

泛函分析的研究对象是无穷维空间，而「研究」的方式是看空间之间的映射。线性代数告诉我们：有限维空间之间的线性映射就是**矩阵**，矩阵把向量空间的结构搬运到另一个空间。泛函分析的宏大目标之一，就是把「矩阵」从有限维推广到无穷维——推广后的对象就是**线性算子（linear operator）**。微分算子、积分算子、傅里叶变换、乘法算子……数学物理里几乎所有重要的变换都是线性算子。<span class="marginnote">「算子（operator）」一词偏向「作用在函数上」的映射，而「变换（transformation）」常指作用在向量上；本专题按中文习惯混用，都指线性映射。把矩阵理解为「有限维线性算子」，你就拥有了理解无穷维算子理论的起点。</span>

## 1 线性算子的定义

设 $X, Y$ 是同一数域 $\mathbb{F}$ 上的线性空间。映射 $T : X \to Y$ 若满足

1. **可加性**：$T(x_1 + x_2) = T x_1 + T x_2$，对一切 $x_1, x_2 \in X$；
2. **齐次性**：$T(\alpha x) = \alpha T x$，对一切 $\alpha \in \mathbb{F}$、$x \in X$；

则称 $T$ 为**线性算子（linear operator）**。两个条件常合并写成**线性组合保持**：

$$
T(\alpha x + \beta y) = \alpha T x + \beta T y
$$

**三个基本伴随对象**：

- **核（kernel）**：$\ker T = \{ x \in X \mid T x = 0 \}$，是 $X$ 的子空间；
- **值域（range）**：$\operatorname{ran} T = \{ T x \mid x \in X \}$，是 $Y$ 的子空间；
- 当 $X = Y$ 时，$T$ 称为 $X$ 上的**算子**（而非「到别的空间」）。

**辨析｜易错点：** 「线性」是关于**自变量**的线性，不是关于「像」的线性。$T(x_1 + x_2) = T x_1 + T x_2$ 说的是「和的像 = 像的和」。另外，核与值域的维数之间没有一般关系（有限维时 $\dim \ker T + \dim \operatorname{ran} T = \dim X$，无穷维失效）——这是第二章已预告的有限维/无穷维分界。

## 2 例一：微分算子与积分算子

**微分算子**：在多项式空间或 $C^1[0,1]$ 上定义

$$
(Df)(t) = f'(t)
$$

它显然是线性的：$(f+g)' = f' + g'$，$(\alpha f)' = \alpha f'$。注意它的核 $\ker D$ = 全体常函数（一维），值域是 $C[0,1]$——微分是「丢了常数项」的操作。<span class="marginnote">微分算子的核「非零」这件事意义重大：$Df = Dg$ 只说明 $f - g$ 是常数。后文处理微分方程 $Df = h$ 时，「通解 = 特解 + 核」就是这个道理。</span>

**积分算子**：设 $K(s, t)$ 是 $[a,b]^2$ 上的连续函数（称为**核**），定义

$$
(T_K f)(s) = \int_a^b K(s, t) f(t) \, dt
$$

由积分的线性性，$T_K$ 是线性算子。它是「把连续函数 $f$ 变成另一个连续函数 $g$」的变换，称为**积分算子（integral operator）**。<span class="marginnote">积分算子贯穿全书：Fredholm 积分方程、紧算子理论、谱分解的经典例子几乎都是积分算子。$K$ 光滑时 $T_K$ 还是<strong>紧算子</strong>（第八章），这是它与「无限大的矩阵」的联系。</span>

## 3 例二：移位算子与乘法算子

**移位算子（shift operator）**：在数列空间 $l^2$ 上定义

$$
S(x_1, x_2, x_3, \ldots) = (0, x_1, x_2, \ldots)
$$

即「把序列整体右移一格，前面补 0」。它是线性算子，$\ker S = \{0\}$（单射），但**不是满射**——像 $(1,0,0,\ldots)$ 就不在值域里（值域里的序列首项必为 0）。<span class="marginnote">单射而不满射，在有限维不可能发生（单射 ⟺ 满射），在无穷维却稀松平常。移位算子是「无穷维与有限维本质不同」的活标本，也是谱理论（第九章）里的经典反例制造机。</span>

**乘法算子（multiplication operator）**：在 $C[0,1]$ 上取固定函数 $\varphi$，定义

$$
(M_\varphi f)(t) = \varphi(t) f(t)
$$

即「逐点乘上 $\varphi$」。它线性；$\ker M_\varphi = \{ f \mid \varphi(t)f(t) = 0, \forall t \}$。若 $\varphi$ 只在孤立点为零，核就是「那些在零点处取零值的连续函数」。乘法算子将在谱理论中扮演「对角矩阵的无穷维版」——它的谱直接就是 $\varphi$ 的值域。

## 4 线性算子与矩阵的联系

在有限维，选定基后线性算子就是矩阵。设 $\dim X = n$，基为 $e_1, \ldots, e_n$，则

$$
T x = T\Big(\sum_i x_i e_i\Big) = \sum_i x_i T e_i
$$

每个 $T e_i$ 又可按基展开 $T e_i = \sum_j a_{ji} e_j$，系数 $a_{ji}$ 构成矩阵 $A$，于是 $T x$ 的坐标就是 $A$ 乘以 $x$ 的坐标向量。<span class="marginnote">这个「坐标化」观点在无穷维会遭遇困难：无穷维空间没有「有限基」，需要 Schauder 基（级数基）。第三章末有专门一节讨论「矩阵表示与无穷维算子的坐标化」，届时你会看到有限维的干净结论如何被无穷维「无限矩阵」取代。</span>

**核心要点：有限维线性算子 = 矩阵，核 = 零空间，值域 = 列空间，秩 = 值域维数。** 这是你已有的线性代数知识向无穷维移植的坐标轴。

## 5 公式解析：算子方程与核的关系

算子理论的一个核心操作是解**算子方程** $T x = y$：

- **存在性**：$y \in \operatorname{ran} T$ 时方程有解——解的存在性就是「$y$ 落在值域里」。
- **唯一性**：$\ker T = \{0\}$ 时解唯一（因为 $T x_1 = T x_2 \Rightarrow x_1 - x_2 \in \ker T$）。
- **通解结构**：若 $x_0$ 是一个特解，则全部解为

$$
\{ x_0 + z \mid z \in \ker T \}
$$

把 $T x = y$ 的两个解相减：

$$
T x_1 = y,\; T x_2 = y \;\Longrightarrow\; T(x_1 - x_2) = 0 \;\Longrightarrow\; x_1 - x_2 \in \ker T
$$

于是 $x_1 = x_2 + (\text{核元})$。**这是线性代数「齐次解 + 特解」公式的算子版**，也是微分方程「通解 = 特解 + 齐次解」的抽象依据。<span class="marginnote">把 $T$ 换成微分算子、$x$ 换成函数 $f$、$y$ 换成非齐次项 $h$，这句话就退化成你熟悉的常微分方程理论——线性算子的框架把「解方程」这门手艺统一成了一个定理。</span>

## 6 例题精讲：线性算子的练习

**练习一：$\ker T$ 与 $\operatorname{ran}T$ 是子空间**。

- $T(\alpha x + \beta y) = \alpha Tx + \beta Ty = 0$（若 $x,y \in \ker T$）。
- 核对线性组合封闭，是子空间。值域同理。
- 线性算子保持子空间结构。

**练习二：微分算子的核是常函数**。

- $Df = f' = 0$ ⟺ $f$ 常数。
- $\ker D$ = 一维常函数空间。
- 微分方程「通解 = 特解 + 核」。

**练习三：移位算子单射不满**。

- $S(x_1,x_2,\ldots) = (0,x_1,x_2,\ldots)$。
- $\ker S = \{0\}$（单射），但 $e_1$ 不在值域（值域首项为 0）。
- 无穷维中单射 ≠ 满射。

**核心要点**：核与值域是算子的「骨架」；无穷维里单射与满射分道扬镳。

**辨析｜易错点：** 有限维时 $\dim\ker T + \dim\operatorname{ran}T = \dim X$；无穷维无此公式——核与值域可以都很「大」。


## 7 小结

- **线性算子**：保持线性组合的映射 $T(\alpha x + \beta y) = \alpha Tx + \beta Ty$；核、值域是最重要的两个伴随子空间。
- **经典例子**：微分算子 $Df = f'$、积分算子 $T_K f = \int K f$、移位算子、乘法算子 $M_\varphi f = \varphi f$。
- **有限维联系**：线性算子 = 矩阵，核 = 零空间，值域 = 列空间；「通解 = 特解 + 核」是线性代数公式的算子版。
- **无穷维新现象**：单射不必满射（移位算子）、值域可以真包含于 $Y$、有限维的秩-零化度公式失效。
- **解方程语言**：$Tx = y$ 有解 ⟺ $y \in \operatorname{ran} T$；解唯一 ⟺ $\ker T = \{0\}$。

至此，第二章「赋范线性空间与 Banach 空间」全部完成。在下一章，我们将给线性算子装上「大小」——**有界线性算子的算子范数**，并揭示连续性与有界性的等价关系。
