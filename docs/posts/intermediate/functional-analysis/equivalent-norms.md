## 为什么讨论范数的等价性

上一节我们确认了 $C[a,b]$、$l^p$、$L^p$ 都是 Banach 空间——但注意，**「是 Banach 空间」依赖于范数的选择**。同一个线性空间上可以放很多范数：$C[0,1]$ 配 sup 范数是完备的，配 $L^1$ 范数就不完备。那问题来了：如果两个范数在「判断收敛」这件事上完全一致，是不是就可以不区分它们？这就引出**范数的等价性（equivalence of norms）**。它回答的问题是：**换一把尺子，会不会改变拓扑、改变收敛、改变连续性？** 如果不会，那么具体用哪把尺子就只是方便问题；如果会，我们就必须明确说清自己用的是哪把。<span class="marginnote">在 $\mathbb{R}^n$ 上我们早就用过这个事实：$\|x\|_1$、$\|x\|_2$、$\|x\|_\infty$ 在判收敛时毫无差别，「$x_n \to x$ 依 $\ell_1$ 范数」与「依 $\ell_2$ 范数」完全等价。本节把这件事严格化，并揭示它在无穷维的崩塌。</span>

## 1 等价范数的定义

设 $\|\cdot\|_a$ 与 $\|\cdot\|_b$ 是线性空间 $X$ 上的两个范数。若存在常数 $c, C > 0$，使对一切 $x \in X$ 有

$$
c \, \|x\|_a \le \|x\|_b \le C \, \|x\|_a
$$

则称 $\|\cdot\|_a$ 与 $\|\cdot\|_b$ **等价（equivalent）**。<span class="marginnote">更准确地说，上面的条件是「双 Lipschitz 等价」或「强等价」，它比「诱导相同拓扑」更强。但本专题（以及程其襄教材）约定俗成地称它为等价，因为：两个范数等价当且仅当它们诱导的<strong>拓扑相同</strong>——这一点对初学者最容易理解。</span>

**为什么这个不等式「很强烈」**：它说两把尺子的读数处处「互相有界地控制」。于是：

- $\|x_n - x\|_a \to 0$ 当且仅当 $\|x_n - x\|_b \to 0$——**收敛列完全相同**；
- $f$ 关于 $\|\cdot\|_a$ 连续当且仅当关于 $\|\cdot\|_b$ 连续；
- $\{x_n\}$ 是 $\|\cdot\|_a$-柯西列当且仅当是 $\|\cdot\|_b$-柯西列——**完备性也被保留**。

**核心要点：等价范数给出完全相同的研究对象**——同样的收敛、同样的连续、同样的完备性。差别只在数值大小，不在结构。

## 2 有限维空间的伟大事实：一切范数等价

**定理（有限维范数等价定理）：设 $X$ 是有限维线性空间，$\dim X = n < \infty$，则 $X$ 上任意两个范数都等价。**

这个定理的证明思路值得走一遍，它用到了「紧性」这个分析利器：

- **第一步，化归到 $\mathbb{R}^n$**：取 $X$ 的基 $\{e_1, \ldots, e_n\}$，把 $x = \sum x_i e_i$ 与坐标向量 $(x_1, \ldots, x_n)$ 认同。只需证明「任意范数 $\|\cdot\|$ 与标准范数 $\|x\|_\star = \max |x_i|$ 等价」。
- **第二步，上界**：用三角不等式，$\|x\| \le \sum |x_i| \|e_i\| \le (\sum \|e_i\|) \|x\|_\star$，得 $\|x\| \le C\|x\|_\star$。
- **第三步，下界**：关键一步。设单位球面 $S = \{ \|x\|_\star = 1 \}$ 是紧集。映射 $x \mapsto \|x\|$ 在 $S$ 上连续（上一步已证），故在 $S$ 上取到最小值 $c = \min_{x \in S} \|x\|$，且 $c > 0$（否则某个单位向量范数为 0，违反范数公理）。于是对 $x \neq 0$，$x/\|x\|_\star \in S$，得

$$
\frac{\|x\|}{\|x\|_\star} = \Big\| \frac{x}{\|x\|_\star} \Big\| \ge c
$$

即 $c\|x\|_\star \le \|x\|$。

**核心要点：证明的杠杆是「单位球面的紧性」**。有限维单位球面紧，所以连续函数取到最小值；最小值不为零，下界就成立。<span class="marginnote">紧性是本节真正的隐形主角。把「最大值」换成「下确界」的论证、把「逐点估计」换成「紧集上的一致估计」——这些操作的合法性全来自紧性。有限维空间「范数等价」的深层原因，就是它的单位球面是紧的。</span>

**推论**：有限维赋范线性空间都是 Banach 空间——因为范数等价意味着「柯西列」的概念与范数选择无关，而 $\mathbb{R}^n$ 完备。

## 3 无穷维的崩塌：范数不再等价

到了无穷维，上述定理的证明哪里断了？——**单位球面不再紧**。在 $C[0,1]$ 上，sup 范数与 $L^1$ 范数：

$$
\|f\|_\infty = \max|f(t)|, \qquad \|f\|_1 = \int_0^1 |f(t)| \, dt
$$

就不等价。找一个「在 sup 范数下很大、在 $L^1$ 范数下很小」的函数即可：比如高度为 1、宽度只有 $\frac{1}{n}$ 的窄三角形 $\varphi_n$，则 $\|\varphi_n\|_\infty = 1$ 而 $\|\varphi_n\|_1 = \frac{1}{2n} \to 0$。<span class="marginnote">这族函数还同时是「$\|\cdot\|_1 \to 0$ 但 $\|\cdot\|_\infty \not\to 0$」的例子：$L^1$ 收敛（平均收敛）完全不蕴含一致收敛。窄高柱函数是这类反例的万能素材。</span>

于是：

在 $\|\cdot\|_1$ 下 $\varphi_n \to 0$，在 $\|\cdot\|_\infty$ 下不收敛到 0——**两个范数给出的收敛列不同**。
$C[0,1]$ 配 $\|\cdot\|_\infty$ 完备、配 $\|\cdot\|_1$ 不完备——**完备性也不同**。

**辨析｜易错点：** 初学者容易把「有限维范数等价」误当成「所有范数都等价」。正确的边界是：**有限维 ⟹ 全部等价；无穷维 ⟹ 一般不等价**。正是这后一句话，让无穷维空间必须「选好范数」再谈一切——这也是为什么 $C[a,b]$ 与 $L^p$ 必须各自指定范数。

## 4 对照表：有限维 vs 无穷维的范数景观

| 性质 | 有限维赋范空间 | 无穷维赋范空间 |
| --- | --- | --- |
| 范数等价性 | 任意两个范数等价 | 一般不等价（$\|\cdot\|_\infty$ vs $\|\cdot\|_1$） |
| 单位球面 | 紧 | 一般不紧 |
| 完备性 | 自动完备（Banach） | 需逐一验证，随范数而变 |
| 收敛列 | 与范数选择无关 | 随范数选择而变（$L^1$ 收敛 ≠ 一致收敛） |
| 基的存在 | 有限基，坐标表示直接 | 需要 Hamel 基（依赖选择公理）或 Schauder 基（更强条件） |

这张表最重要的信息在第二行：**无穷维空间失去的正是「单位球面紧」这个看似不起眼的事实**，而它恰恰是一切「范数等价」「自动完备」的根基。<span class="marginnote">注意表末的「基」：有限维有坐标表示，无穷维没有现成的坐标——这是第二章后半部分（有限秩算子、矩阵表示）反复触碰的痛点。真正好用的基是 Schauder 基（每个向量可写成无穷级数），后面讨论紧算子时会用到。</span>

## 5 公式解析：等价性不等式两端的角色

把定义再盯一遍：

$$
c \, \|x\|_a \le \|x\|_b \le C \, \|x\|_a
$$

- **左侧 $c\|x\|_a \le \|x\|_b$** 说 $\|\cdot\|_b$ 是 $\|\cdot\|_a$ 的「下界控制」：$x$ 在 $b$-尺子下不会太短。它保证「$b$-收敛 ⟹ $a$-收敛」——因为 $\|x_n - x\|_a \le \frac{1}{c}\|x_n - x\|_b$。
- **右侧 $\|x\|_b \le C\|x\|_a$** 说 $b$-尺子不会太长，保证「$a$-收敛 ⟹ $b$-收敛」。
- **两个方向合起来**才是等价；缺一个方向就只是「一个收敛蕴含另一个」的单向关系。

用一个具体例子看两个方向各自的作用。在 $\mathbb{R}^n$ 上：

$$
\|x\|_\infty \le \|x\|_1 \le n \|x\|_\infty
$$

左侧：最大分量不超过各分量绝对值之和；右侧：各分量之和至多是「最大分量」的 $n$ 倍。于是 $\ell_\infty$ 收敛 ⟺ $\ell_1$ 收敛，虽然中间夹的常数 $n$ 随维度膨胀。

**关键**：等价性是两个不等式，不是两个定义；它比「诱导相同拓扑」更强也更好算——只要找到上下界常数，一切结构等价性就自动成立。

## 6 例题精讲：范数等价的三组练习

**练习一：$\mathbb{R}^n$ 上 $\ell_1$ 与 $\ell_\infty$ 等价**。

- $\|x\|_\infty \le \|x\|_1 \le n\|x\|_\infty$：两方向控制。
- 常数 $n$ 依赖维度——维度升高时控制变松。
- 有限维范数全等价（第二章定理）。

**练习二：$C[0,1]$ 上 sup 与 $L^1$ 不等价**。

- 窄高三角形 $\varphi_n$：$\|\varphi_n\|_\infty = 1$、$\|\varphi_n\|_1 = 1/(2n)$。
- 不存在常数 $c$ 使 $c\|\cdot\|_\infty \le \|\cdot\|_1$。
- 无穷维范数不等价。

**练习三：等价 ⟺ 拓扑相同**。

- $c\|x\|_a \le \|x\|_b \le C\|x\|_a$ ⟺ 两范数诱导相同开集。
- 收敛列、柯西列、完备性全部一致。
- 等价范数给出「相同的研究对象」。

**核心要点**：范数等价 = 双向控制；有限维全等价，无穷维一般不等价。

**辨析｜易错点：** 「有界但范数不等价」的反例（窄高函数）是理解无穷维的关键——一个范数收敛不蕴含另一个。


## 7 小结

- **等价范数**：存在 $c, C > 0$ 使 $c\|x\|_a \le \|x\|_b \le C\|x\|_a$；等价的范数给出相同的收敛、连续与完备性。
- **有限维定理**：有限维赋范空间的一切范数等价，证明靠「单位球面紧 + 连续函数取最小值」；推论是有限维空间自动完备。
- **无穷维崩塌**：$C[0,1]$ 的 sup 范数与 $L^1$ 范数不等价，$L^1$ 收敛不蕴含一致收敛，完备性也随之改变。
- **边界在哪**：紧性是分水岭——有限维单位球面紧，无穷维一般非紧。
- **实用价值**：讨论无穷维问题时必须明确范数；一旦选定范数，整个空间的结构就被锁定。

在下一节，我们面对有限维与无穷维的另一个分界——**Riesz 引理与有限维赋范空间的刻画**：它把「有限维」这个看似几何的条件翻译成单位球的性质，并由此证明有限维是「好空间」的精确边界。
