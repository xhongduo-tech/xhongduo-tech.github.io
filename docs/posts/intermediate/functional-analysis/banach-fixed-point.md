## 为什么从压缩映像开始

前面五节我们铺好了一张完整的桌子：度量空间、极限、连续、完备化。但光有「桌子」还不能做数学——你需要第一道真正能「做出来」的菜。**压缩映像原理（Banach 不动点定理）就是泛函分析的第一次实战**：它用一个极简单的几何条件（映射把距离按固定比例缩短），换来三个极强的结论——不动点的**存在**、**唯一**，以及一个从任意初值出发都能收敛的**迭代算法**。

这三个结论正是近代数学反复使用的那套三件套：**存在性 + 唯一性 + 可构造**。微分方程的解、积分方程的解、甚至机器学习里梯度下降的收敛点，本质都在等这一句「映射有唯一不动点」。这一节我们把定理本身证透；下一节再看它如何在方程里大显身手。

## 1 从「迭代求根」到不动点

先复习一个你早就见过的例子。解方程 $x = \cos x$ 可以怎么做？取初值 $x_0 = 1$，反复代入：

$$
x_1 = \cos x_0, \quad x_2 = \cos x_1, \quad \dots \quad x_{n+1} = \cos x_n
$$

算几项就会发现数列 $\{x_n\}$ 稳定在 $0.739085\dots$ 附近——它收敛到一个数 $x^*$，满足 $x^* = \cos x^*$。这个点就叫**不动点（fixed point）**：映射 $T$ 的不动点是满足

$$
T x^* = x^*
$$

的点，即被映射「钉住不动」的点。

**核心概念**：给定集合 $X$ 与自映射 $T: X \to X$，若 $x^* \in X$ 满足 $T x^* = x^*$，则称 $x^*$ 是 $T$ 的**不动点**。<span class="marginnote">「把解方程变成找不动点」是一次思想解放：方程 $f(x) = 0$ 可以改写成 $x = x + f(x)$ 之类的不动点形式，于是「解方程」统一成「找某个映射的钉子」。这个视角贯穿数值分析里几乎全部迭代法——牛顿法、不动点迭代、EM 算法都是不动点迭代的不同变体。</span>

问题来了：$\cos$ 这个映射凭什么让迭代收敛？因为它「收缩」——两点越靠越近。这就是压缩映像的全部直觉。

## 2 压缩映射：把距离按比例缩短

**定义（压缩映射）**：设 $(X, d)$ 是度量空间，$T: X \to X$ 是自映射。若存在常数 $q$，$0 \le q < 1$，使得对一切 $x, y \in X$ 有

$$
d(Tx, Ty) \le q\, d(x, y)
$$

则称 $T$ 是 $X$ 上的**压缩映射（contraction mapping）**，$q$ 称为**压缩因子**。

一句话：**压缩映射把任意两点的距离至少缩成原来的 $q$ 倍（$q < 1$）。** 两个关键点需要立刻钉住：

- $q$ 必须是一个**固定**的、小于 1 的常数，与 $x, y$ 无关。这比「$d(Tx, Ty) < d(x,y)$ 逐点成立」强得多，后者并不足以保证不动点存在——第 5 节会有反例。
- $q \ge 0$，所以距离的非负性保留；$q = 0$ 是「一切点都映到同一点」的极端情况，平凡成立。

**辨析｜易错点：** 压缩映射一定是（一致）连续的——取 $\delta = \varepsilon$（其实可放宽为 $\delta = \varepsilon / q$）由 $d(Tx, Ty) \le q\, d(x, y)$ 立即得到。**所以在第 3 节证明里「先取极限再作用 $T$」是被允许的，这是整个证明链的合法关节。**<span class="marginnote">连续性的来源：压缩不等式比连续性要求强得多，你可以把「压缩 ⟹ 连续」记成「几乎免费得到的连续」。顺带记住 q 越接近 1 收敛越慢：粗略估算，要迭代到误差 $\varepsilon$，约需 $n \approx \ln(\varepsilon / d_0) / \ln q$ 步，q 是收敛速度的主控旋钮。</span>

## 3 Banach 不动点定理：完备空间里的唯一钉子

**定理（Banach 不动点定理，1922）**：设 $(X, d)$ 是**完备**度量空间，$T: X \to X$ 是压缩映射，压缩因子为 $q$。则：

1. $T$ 在 $X$ 中有**唯一**不动点 $x^*$；
2. 对任意初值 $x_0 \in X$，迭代点列 $x_n = T^n x_0$（即 $x_{n+1} = T x_n$）都收敛到 $x^*$；
3. 有误差估计

$$
d(x_n, x^*) \le \frac{q^n}{1 - q}\, d(x_0, x_1)
$$

证明分五步，每一步都值得单独咀嚼：

- **第一步，构造迭代列**：任取 $x_0 \in X$，定义 $x_{n+1} = T x_n$。目标是证明它是柯西列。
- **第二步，逐次控制相邻距离**：反复用压缩不等式，

$$
d(x_{n+1}, x_n) = d(T x_n, T x_{n-1}) \le q\, d(x_n, x_{n-1}) \le q^2\, d(x_{n-1}, x_{n-2}) \le \cdots \le q^n\, d(x_1, x_0)
$$

相邻距离按等比数列衰减。
- **第三步，用几何级数证明柯西性**：对 $m > n$，用三角不等式把 $d(x_n, x_m)$ 拆成一串相邻距离：

$$
d(x_n, x_m) \le d(x_n, x_{n+1}) + \cdots + d(x_{m-1}, x_m) \le (q^n + \cdots + q^{m-1})\, d(x_0, x_1) \le \frac{q^n}{1 - q}\, d(x_0, x_1)
$$

最后一步是等比数列求和放缩（公比 $q < 1$）。于是对任意 $\varepsilon > 0$，取 $n$ 充分大使 $\frac{q^n}{1-q}\, d(x_0, x_1) < \varepsilon$，即 $\{x_n\}$ 是柯西列。
- **第四步，完备性给出极限**：$\{x_n\}$ 收敛，设 $x^* = \lim x_n$。对 $x_{n+1} = T x_n$ 两边取极限：左边趋于 $x^*$；右边由 $T$ 连续趋于 $T x^*$。故 $x^* = T x^*$——**不动点存在**。
- **第五步，唯一性**：若另有 $y^* = T y^*$，则

$$
d(x^*, y^*) = d(T x^*, T y^*) \le q\, d(x^*, y^*)
$$

移项得 $(1 - q)\, d(x^*, y^*) \le 0$。因 $1 - q > 0$，故 $d(x^*, y^*) = 0$，即 $x^* = y^*$。<span class="marginnote">唯一性的证明只有一行，却是「压缩」最锋利的刀刃：不动点若有两个，它们的距离被压缩后居然不小于自身，只有距离为 0 才能自洽。<strong>压缩因子 q 连同完备性，是整条证明链仅有的两件装备</strong>——其余全靠三角不等式与几何级数，普适性正源于此。</span>

**这五步合起来是本章最重要的证明样板**：迭代构造、相邻控制、几何级数、完备取限、唯一收口。请在下节的应用里反复对照这五步。

## 4 公式解析：误差估计的几何级数链

误差估计式是压缩映像原理最「值钱」的输出——它告诉你**迭代多少步能保证精度**。整条式子值得拆成三步：

$$
d(x_n, x^*) \le \frac{q^n}{1 - q}\, d(x_0, x_1)
$$

- **第一步，先估「未来步到当前步」**：由第三步的推导，$d(x_n, x_m) \le \frac{q^n}{1-q}\, d(x_0, x_1)$ 对一切 $m > n$ 成立。这是「从一点出发还能跑多远」的先验上界，它**不依赖** $m$ 具体取多大。
- **第二步，把 $m$ 推向无穷**：因为 $\{x_m\}$ 收敛到 $x^*$，在不等式 $d(x_n, x_m) \le \frac{q^n}{1-q}\, d(x_0, x_1)$ 中令 $m \to \infty$。距离函数是连续的，故 $d(x_n, x_m) \to d(x_n, x^*)$，右侧与 $m$ 无关保持不动。
- **第三步，读出直觉**：右侧 $= \underbrace{q^n}_{\text{几何衰减}} \cdot \underbrace{\frac{d(x_0, x_1)}{1-q}}_{\text{与初值相关的常数}}$。$q^n$ 随 $n$ 指数衰减，这是「收敛速度」；$\frac{d(x_0, x_1)}{1-q}$ 是「初值离答案多远」——其中 $d(x_0, x_1)$ 是迭代一次就走出的距离，$1 - q$ 是分母。**q 越接近 1，分母越小，常数越爆炸，收敛越慢。** 这条式子在数值分析里就是迭代法停机准则与收敛阶的理论依据。

**辨析｜易错点：** 公式里是 $d(x_0, x_1)$，**不是** $d(x_0, x^*)$——后者通常未知（你要解的正是它）。能用的量只有 $d(x_0, Tx_0)$ 这类「迭代一次就测得出」的数。这正是误差估计的实用价值：**只需初值与一次迭代，就能事前承诺精度。**

## 5 三个反例：条件缺一不可

Banach 不动点定理的三个条件——完备、$q < 1$、自映射——每个都不能少。三个反例把边界画出来：

- **缺完备性**：$(0, 1]$ 上取 $T x = x / 2$。它是压缩映射（$q = 1/2$），但唯一的不动点 $x = 0$ 不在空间里——迭代 $x_n = x_0 / 2^n \to 0$ 的极限「逃出」了空间。<span class="marginnote">这解释了我们为什么先花一整节做完备化：不完备的空间里有「悬空的极限」，不动点可能恰好悬空在外。<strong>完备化把悬空的极限补进来，压缩映像原理才敢打包票</strong>——你正在亲历 §1.5 与 §1.6 的第一次配合。</span>
**$q = 1$ 不够**：$\mathbb{R}$ 上取平移 $T x = x + 1$。它满足 $d(Tx, Ty) = d(x, y)$（$q = 1$），但没有不动点（$x + 1 = x$ 无解）。更狠的是 $T x = x + e^{-x}$（在 $[1, \infty)$ 上）：对一切 $x \neq y$ 都有 $d(Tx, Ty) < d(x, y)$ 严格成立，却仍无不动点——因为没有**统一的** $q < 1$。**「逐点缩短」与「一致缩短」是两回事**，这正是定义里「存在固定常数 q」的意义。
**缺自映射**：若 $T$ 只是 $X \to Y$ 而 $X \neq Y$，不动点无从谈起。实际应用中「$T$ 是否把空间映回自身」是第一道要验的关口。

## 6 为什么它是泛函分析的第一次胜利

把这一节放回课程地图：我们从一个高度抽象的对象（完备度量空间）出发，用一次几乎是「免费」的几何假设（压缩），得到了一个可以在任何完备空间里放心使用的存在性引擎。**这就是泛函分析的典型气质——用几何与拓扑的语言，把不同数学分支里「长得一模一样」的论证提炼成一条定理。**<span class="marginnote">对比拓扑的 Brouwer 不动点定理：它在有限维里断言连续自映射必有不动点，但<strong>不给出位置、不给出算法</strong>。Banach 定理则要求更强的「压缩」，却换来构造性——分析学更偏爱这种「会自己迭代出答案」的不动点。</span>

它在整个课程体系里的位置：下一节它在常微分方程与积分方程里开疆拓土；在数值分析里它是所有迭代法收敛性的共同祖先；在机器学习里，梯度下降、EM 算法、强化学习的价值迭代都可以写成「找某个映射的不动点」——只是那里压缩条件通常换成更宽松的论证。**先把这个定理刻进肌肉记忆，后面所有「迭代收敛」的话题都能往回看它一眼。**

## 7 小结

- **压缩映射**：存在固定 $0 \le q < 1$，使 $d(Tx, Ty) \le q\, d(x,y)$ 对一切 $x,y$ 成立。
- **Banach 不动点定理**（完备 + 压缩）：存在唯一不动点 $x^*$；任意初值迭代 $x_{n+1} = Tx_n$ 收敛到 $x^*$。
- **证明五步**：迭代构造 → 相邻距离等比衰减 → 几何级数证柯西 → 完备取极限 → 压缩证唯一。
- **误差估计**：$d(x_n, x^*) \le \frac{q^n}{1-q}\, d(x_0, x_1)$，只依赖初值与一次迭代。
- **三个反例**：缺完备性（$Tx = x/2$ 于 $(0,1]$）、$q = 1$（平移）、逐点缩短但无一致 $q$（$x + e^{-x}$）。

在下一节，我们带着这台「存在性引擎」走进微分方程与积分方程：把求导问题改写成积分方程，构造一个自然出现的压缩映射，然后让 Banach 定理一次性交付解的存在、唯一与构造——这就是经典的 Picard 逐次逼近法与 Fredholm 理论的开端。
