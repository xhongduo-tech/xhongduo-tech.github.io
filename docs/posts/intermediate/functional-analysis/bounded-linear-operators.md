## 为什么从「算子」讲起

上一篇我们造好了房间——Banach 空间。但数学关心的从来不只是房间，而是**房间之间的映射**。在有限维里，「线性映射」就是矩阵，一切都可显式计算；一旦进入无穷维，映射变成了**算子（operator）**：把函数变成函数、把数列变成数列。**有界线性算子是无穷维世界的「矩阵」**，而「算子范数」是给这个矩阵量的「模」。<span class="marginnote">本篇是理解全书的枢纽：<strong>泛函 = 值在数域上的算子</strong>，共轭空间、对偶理论、谱理论全部从「算子的有界性」长出来。往前接第三级《线性代数》的矩阵，往后送第四级《微分方程》、第五级《量子力学》里的具体算子。</span>

## 1 线性算子：线性映射的无穷维版

**核心概念（线性算子）**：设 $X, Y$ 是赋范线性空间（数域相同），映射 $T: X \to Y$ 称为**线性算子**，若

$$
T(\alpha x + \beta y) = \alpha Tx + \beta Ty \quad (\forall x, y \in X, \ \alpha, \beta \in \mathbb{K})
$$

线性算子把空间的线性结构完整搬走——「$X$ 的结构长什么样，$T(X)$ 就长什么样」。

经典例子俯拾即是：

- **积分算子**：$(Tf)(s) = \int_a^b K(s,t) f(t)\,dt$，把连续函数变成连续函数。
- **微分算子**：$Tf = f'$，把可微函数变成函数。
- **移位算子**：$S(x_1, x_2, \dots) = (0, x_1, x_2, \dots)$，把数列往后推一位。
- **乘算子**：$(Mf)(x) = \phi(x)f(x)$，把函数乘以固定函数 $\phi$。
- **取值泛函**：$\delta_t(f) = f(t)$，把函数送到它的「点值」——这是泛函（值在 $\mathbb{R}$ 或 $\mathbb{C}$）的典型。

**当 $Y = \mathbb{K}$（数域）时，$T$ 称为线性泛函（linear functional）**。泛函是「把函数数出来」的工具——积分 $\int$、求值 $\delta_t$、取均值，都是泛函。

## 2 有界性：算子连续的第一课

**核心概念（有界算子）**：线性算子 $T: X \to Y$ 称为**有界（bounded）**，若存在常数 $M \ge 0$ 使

$$
\|Tx\|_Y \le M\|x\|_X \quad (\forall x \in X)
$$

**重点：有界 = 连续。** 对线性算子，这两个概念完全等价（这是有限维「线性映射必连续」的无穷维替身，但不再自动成立——见 §4 的反例）。证明方向：「有界 ⟹ 连续」用 $\|Tx_n - Tx\| = \|T(x_n - x)\| \le M\|x_n - x\| \to 0$；「连续 ⟹ 有界」用反证法，找 $x_n$ 使 $\|Tx_n\| > n\|x_n\|$，归一化后矛盾。<span class="marginnote">「连续但无界」在无穷维是可能的——微分算子在 $C^1[a,b] \subset C[a,b]$ 上连续，却在 $C[a,b]$ 上（对一致范数）处处不连续。这就是为什么无穷维里「有界」是比「连续」更锋利、更常被直接要求的条件。</span>

**核心概念（算子范数）**：有界算子 $T$ 的**范数**定义为

$$
\|T\| = \sup_{x \ne 0} \frac{\|Tx\|}{\|x\|} = \sup_{\|x\| \le 1}\|Tx\| = \sup_{\|x\| = 1}\|Tx\|
$$

$\|T\|$ 是使 $\|Tx\| \le M\|x\|$ 成立的**最小**常数——它是「$T$ 最多把单位向量拉多长」。

## 3 公式解析：算子范数怎么算

**公式解析：$\|T\| = \sup_{\|x\| \le 1} \|Tx\|$。** 这是整章最重要的量，三步拆解：

- **第一步，为什么定义成 sup 而不是 max**：有限维里单位球紧，sup 总能取到（成 max）；无穷维里单位球不紧，sup 可能只是「上确界」而取不到。算子范数因此常以「对任意 $\|x\|=1$ 的估计」形式出现。
- **第二步，三条等式为何成立**：$\frac{\|Tx\|}{\|x\|} = \|T\frac{x}{\|x\|}\|$（齐次性），所以「在所有非零向量上取 sup」=「在单位球面上取 sup」；再因为 $\|x\| \le 1 \Rightarrow \|x\|/\|x\|$ 归一化后范数不减，三条形式等价。
- **第三步，算一个具体例子**：积分算子 $T: C[0,1] \to C[0,1]$，$Tf(s) = \int_0^1 K(s,t) f(t)\,dt$，$K \equiv 1$。则 $\|Tf\|_\infty = \max_s|\int_0^1 f| \le \int_0^1 |f| \le \|f\|_\infty$，所以 $\|T\| \le 1$；取 $f \equiv 1$ 得 $\|Tf\|_\infty = 1$，故 $\|T\| = 1$。**先上界、再构造取等，是算子范数的标准算程。**

**再算一个：移位算子 $S: l^1 \to l^1$，$S(x_1,x_2,\dots) = (0,x_1,x_2,\dots)$。** $\|Sx\|_1 = \sum_{n\ge2}|x_{n-1}| = \|x\|_1$——后移一位不改变 $l^1$ 范数，故 $\|S\| = 1$（对任意 $x$ 都取等）。而**前移算子** $L(x_1,x_2,\dots) = (x_2,x_3,\dots)$ 满足 $\|Lx\|_1 \le \|x\|_1$，取 $x = e_1$ 得 $\|L\| = 1$，但 $L$ **不是单射**（$\ker L = \operatorname{span}\{e_1\}$）——**范数相等，代数性质却天差地别，这就是算子的世界。**

**算子的「空间」也是空间**：一切有界算子 $T: X \to Y$ 组成 $\mathcal{B}(X, Y)$，配上算子范数构成赋范空间；$Y$ 完备时 $\mathcal{B}(X,Y)$ 是 **Banach 空间**（算子列的 Cauchy 收敛 ⟹ 逐点收敛 ⟹ 一致极限有界）。**「算子组成的空间本身完备」保证了后面逐项求和、几何级数 $\sum T^n$ 等操作安全。**

## 4 有界线性泛函与第一个「差距」

**核心概念（有界线性泛函）**：$Y = \mathbb{K}$ 时的有界线性算子。有界线性泛函组成的空间记作 $X^*$，叫**共轭空间（dual space）**：

$$
X^* = \{f : X \to \mathbb{K} \mid f \text{ 线性且有界}\}, \qquad \|f\| = \sup_{\|x\| \le 1}|f(x)|
$$

$X^*$ 本身是 Banach 空间（若 $X$ 是赋范空间）——**泛函组成的空间再次成为 Banach 空间**，这把「研究空间」升级成「研究空间的空间」。

**经典泛函的范数**：

- $C[a,b]$ 上的取值泛函 $\delta_t(f) = f(t)$：$\|\delta_t\| = 1$（取 $f \equiv 1$ 取等）。
- $L^1[a,b]$ 上的积分泛函 $I(f) = \int_a^b f$：$\|I\| = 1$（$f \equiv 1$ 取等）。
- $l^1$ 上求和泛函 $\sum x_n$：范数 1。
- $L^2[0,1]$ 上的内积泛函 $f \mapsto \langle f, g\rangle = \int f\overline g$：$\|g\|_2$（Riesz 表示定理预告，见希尔伯特空间一篇）。

**共轭空间的「经典搭档」**：$(l^p)^* = l^q$（$\frac1p + \frac1q = 1$，$1 < p < \infty$），$(L^p)^* = L^q$——**对偶空间「自带」一个标准的同构描述**。这些等式是本章到第七章之间最重要的桥梁：判断泛函有界，往往变成判断某个数列/函数落在哪个 $l^q / L^q$。

**辨析｜易错点：** 无限维里「无界线性泛函」真实存在（借助 Hamel 基构造），但它们「处处不连续」，毫无用处。**我们只对有界泛函感兴趣——它们才是共轭空间的成员。**<span class="marginnote"><strong>有界线性泛函是「把无穷维对象变成数字」的探针</strong>：积分、求值、取均值，全是这样的探针。Hahn-Banach 定理（第六章）将告诉你：这样的探针足够多，多到能「分开」任意两个不同的点。</span>

## 5 反例：无穷维里的「不自动」

有界性在无穷维里**不再自动成立**，三个经典反例值得记住：

**反例一（微分算子无界）**：$T: C^1[0,1] \to C[0,1]$，$Tf = f'$。取 $f_n(x) = \sin(nx)$，$\|f_n\|_\infty = 1$，但 $\|Tf_n\|_\infty = n \to \infty$——无界。

**反例二（发散级数泛函无界）**：$f(x) = \sum_{n\ge 1} x_n$ 定义在「有限支撑」序列子空间上，对坐标范数无界。

**反例三（有限维的「保护」）**：$X$ 有限维时一切线性算子都自动有界——这正是第三级《线性代数》从不讨论「算子有界性」的原因；**到了无穷维，有界性成为需要专门验证的稀缺品。**

**再想一层**：无界算子并非「病态到没用」——它们在量子力学（动量 $-i\hbar\frac{d}{dx}$）、PDE（Laplace 算子）里无处不在。只是它们只定义在稠密子空间、且需要专门理论（第九篇《无界算子初步》）。**「有界」与「无界」不是好与坏，而是两类不同的研究对象。**

**一句话总结**：有界线性算子是「无穷维世界的矩阵」，算子范数是最小拉伸倍数；线性泛函是「把无穷维压成数字」的探针；两者合起来，构成了共轭空间与对偶理论的全部原料。

**辨析｜易错点：** 有界算子的「有界」与函数的「有界」不是一回事。函数有界指「取值被某常数压住」；算子有界指「**单位球在映射下被拉伸有限倍**」——它其实更像「Lipschitz 连续」。另一个易错点：**$\sup_{\|x\|\le1}\|Tx\|$ 未必取得到**（无穷维里单位球不紧），所以算子范数总写成 sup 而非 max，计算时「先证 ≤ 再构造逼近」是常态。

**数值例子**：矩阵 $A = \begin{pmatrix}1&2\\0&3\end{pmatrix}: \mathbb{R}^2 \to \mathbb{R}^2$（欧氏范数）。$\|A\| = \sigma_{\max}(A) = \sqrt{\lambda_{\max}(A^T A)}$，$A^T A = \begin{pmatrix}1&2\\2&13\end{pmatrix}$，$\lambda_{\max} = 7 + \sqrt{40} \approx 13.32$，故 $\|A\| \approx 3.65$——**算子范数正是「最大奇异值」，矩阵谱范数在数值线性代数（第六级）里天天见。**

## 6 小结

- **有界线性算子 = 连续线性映射**：对线性算子，「有界」与「连续」完全等价。
- **算子范数**：$\|T\| = \sup_{\|x\|\le1}\|Tx\|$，是最小的 Lipschitz 常数，也是「拉长系数」。
- **线性泛函**：值在数域上的算子；共轭空间 $X^*$ 本身是 Banach 空间。
- **有界性不自动**：微分算子、发散级数泛函都是无界反例；有限维里才自动有界。
- **计算套路**：先证上界，再构造取等的 $x$，锁定算子范数。
- **矩阵观**：有限维里算子范数 = 最大奇异值 $\sigma_{\max}(A)$；数值线性代数里每天在用。
- **对偶搭档**：$(l^p)^* = l^q$、$(L^p)^* = L^q$——判断泛函有界变成判断数列落在哪个 $l^q$。
- **定位**：这是谱理论（第九章）与 Fredholm 理论（第八章）的起点——算子先有界，才能谈「逆」「谱」「分解」。

在下一节，我们把视线从单个算子抬到「定理层面」——**三大基本定理（一致有界原理、开映射与闭图像定理）**，看 Banach 空间如何反过来约束算子。
