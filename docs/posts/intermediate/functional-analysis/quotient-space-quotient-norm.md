## 为什么需要商空间

研究一个线性算子 $T$ 时，我们最关心的两个子空间是它的**核（kernel）**$\ker T$ 与**值域（range）**$\operatorname{ran} T$。可核内的一切信息在 $T$ 看来都是「零」——$x$ 与 $x + y$（$y \in \ker T$）被 $T$ 映到同一个点。于是自然的问题：**把核里「看不见的差异」全部揉成一个点，剩下的结构是什么？** 这就是**商空间（quotient space）**：它把「模掉一个子空间」严格化，让 $T$ 变成一个「单射 + 满射」的干净对象。<span class="marginnote">商空间在代数学中早已存在（群论里的商群、环论里的商环），泛函分析的贡献是给它配上<strong>范数</strong>，使商空间成为赋范线性空间甚至 Banach 空间。这一步是后文处理「值域分解」「对偶空间」「闭图像定理」的关键基础设施。</span>

## 1 商空间的定义：把子空间揉成零

设 $X$ 是线性空间，$M$ 是 $X$ 的线性子空间。在 $X$ 上定义等价关系：

$$
x \sim y \iff x - y \in M
$$

用 $M$ 模掉差异后，$x$ 所在的等价类记作

$$
[x] = x + M = \{ x + m \mid m \in M \}
$$

称 $[x]$ 为 $x$ 关于 $M$ 的**陪集（coset）**。全体陪集组成的集合

$$
X / M = \{ [x] \mid x \in X \}
$$

配上运算

$$
[x] + [y] = [x + y], \qquad \alpha[x] = [\alpha x]
$$

构成线性空间，称为 $X$ 关于 $M$ 的**商空间（quotient space）**。<span class="marginnote">必须验证运算「良定义」（well-defined）：如果 $[x] = [x']$ 且 $[y] = [y']$，那么 $[x+y] = [x'+y']$ 吗？因为 $x - x' \in M$、$y - y' \in M$，故 $(x+y) - (x'+y') \in M$，成立。把「良定义」三个字拆开，是抽象代数的基础功。</span>

**核心直觉**：商空间 $X/M$ 就是「忽略 $M$ 内的差异后的世界」。$X$ 里相差一个 $M$ 元素的点，在商空间里是同一个点。$X/M$ 中的零元是 $[0] = M$ 本身。

## 2 商范数的定义

现在假设 $X$ 是**赋范线性空间**，$M$ 是 $X$ 的**闭**线性子空间。定义 $X/M$ 上的**商范数（quotient norm）**：

$$
\|[x]\|_{X/M} = d(x, M) = \inf_{m \in M} \|x + m\|
$$

它测量的是「陪集 $[x]$ 到零陪集 $M$ 的距离」。三公理逐条验证：

- **非负性**：$\|[x]\| \ge 0$ 显然；$\|[x]\| = 0 \iff \inf_m \|x + m\| = 0 \iff x$ 可以被 $M$ 中元素任意逼近 $\iff x \in \overline{M} = M$（用 $M$ 闭）$\iff [x] = [0]$。
- **齐次性**：$\|\alpha[x]\| = \inf_m \|\alpha x + m\| = \inf_m \|\alpha(x + \frac{m}{\alpha})\| = |\alpha| \inf_m \|x + m\|$。
- **三角不等式**：$\|[x] + [y]\| = \inf_{m,n} \|x + y + m + n\| \le \inf_{m,n} \|x + m\| + \|y + n\|$，右边两项下确界可分别取，得到 $\le \|[x]\| + \|[y]\|$。<span class="marginnote">三角不等式这一步需要一点小心：<strong>和的 inf 未必等于 inf 之和，但一定 ≤ inf 之和</strong>——这正是我们要的方向。若把「≤」改成「=」，命题就不对了，这个细节是初学者常踩的坑。</span>

**辨析｜易错点：** 商范数中「$\inf$」而不是「$\min$」——下确界未必取到。这与 Riesz 引理中的情况一致：垂直投影未必存在。**而 $M$ 的闭性在这里不可省**：若 $M$ 不闭，$\|[x]\| = 0$ 的陪集可能不止 $[0]$，非负性公理就会崩塌。

## 3 自然映射与算子的标准分解

定义**自然映射（canonical projection）**

$$
\pi : X \to X/M, \qquad \pi(x) = [x]
$$

它是线性满射，且 $\|\pi\| \le 1$（因为 $\|[x]\| = d(x,M) \le \|x\|$，取 $m = 0$）。<span class="marginnote">自然映射的「把每点揉进陪集」这个动作，就是线性代数里「投影到商空间」的严格版。商空间理论的价值之一，是让「满射」变得平凡——因为 π 天然满。</span>

**商空间最漂亮的应用是算子分解定理**：设 $T : X \to Y$ 是线性映射，$M = \ker T$。定义

$$
\tilde{T} : X/\ker T \to \operatorname{ran} T, \qquad \tilde{T}([x]) = T x
$$

则：

- $\tilde{T}$ **良定义**：若 $[x] = [x']$，则 $x - x' \in \ker T$，故 $T x = T x'$。
- $\tilde{T}$ 是**单射**：$\tilde{T}([x]) = 0 \Rightarrow T x = 0 \Rightarrow x \in \ker T \Rightarrow [x] = [0]$。
- $\tilde{T}$ 是**满射**（映到值域）。

于是任何线性映射都分解为「商掉核的投影 + 单射满射」：

$$
T : X \xrightarrow{\;\pi\;} X/\ker T \xrightarrow{\;\tilde{T}\;\,} \operatorname{ran} T \hookrightarrow Y
$$

**核心要点：核与值域之间的那座桥，就是商空间。** 商掉核，$T$ 立刻变成「一对一」，一切多对一的麻烦都留在核里。

## 4 商空间何时完备：闭子空间的商

**定理：设 $X$ 是 Banach 空间，$M$ 是 $X$ 的闭线性子空间，则商空间 $X/M$ 配商范数是 Banach 空间。**

证明思路（用级数判别准则）：

- **第一步**：设 $\sum \|[x_n]\| < \infty$。由商范数定义，对每个 $n$ 可取 $m_n \in M$ 使 $\|x_n + m_n\| \le \|[x_n]\| + 2^{-n}$。于是 $\sum \|x_n + m_n\| \le \sum \|[x_n]\| + \sum 2^{-n} < \infty$。
- **第二步**：$X$ 完备，故 $\sum (x_n + m_n)$ 收敛到某 $z \in X$。
- **第三步**：自然映射 $\pi$ 连续线性，故 $\sum [x_n] = \pi\big(\sum(x_n + m_n)\big) = [z]$ 收敛。由绝对收敛判别法，$X/M$ 完备。

**核心要点：证明把「商空间的收敛」化归为「原空间某个代表的收敛」**——在每一块陪集里挑一个「好代表」（接近范数下确界的代表），剩下的交给 $X$ 的完备性。<span class="marginnote">「每陪集挑好代表」这个技巧在泛函分析里反复出现：从商空间理论到 Hahn-Banach 定理，再到对偶空间的构造。记住它：<strong>商空间的问题，常常翻译成「挑代表」的问题。</strong></span>

## 5 公式解析：商范数的三角不等式

把最容易出错的一步单独拆开：

$$
\|[x] + [y]\| \le \|[x]\| + \|[y]\|
$$

- **第一步，展开定义**：

$$
\|[x] + [y]\| = \inf_{m, n \in M} \|x + y + m + n\| = \inf_{m, n \in M} \|(x + m) + (y + n)\|
$$

- **第二步，三角不等式逐对控制**：

$$
\|(x+m) + (y+n)\| \le \|x + m\| + \|y + n\|
$$

- **第三步，取下确界**：对右边先固定 $n$ 取 $m$ 的下确界得 $\le \|[x]\| + \|y + n\|$，再取 $n$ 的下确界得 $\le \|[x]\| + \|[y]\|$。注意每一步取 inf 都不破坏「≤」。

**关键**：这里用到的性质是「$A \le B$ 对一切可行指标成立则 $A \le \inf B$」——下确界是最大下界，凡是「不小于」的都保住了。这是所有「inf 论证」的公理基础。

## 6 小结

- **商空间 $X/M$**：把 $M$ 揉成零元，陪集 $[x] = x + M$ 为点，是线性空间。
- **商范数** $\|[x]\| = \inf_{m \in M}\|x+m\|$，测量陪集到零的距离；**$M$ 必须闭**，非负性公理才成立。
- **算子分解**：$T = $ 自然映射 + 单射满射 $\tilde{T}$，$T$ 的一切多对一信息集中在核里，商掉核后 $T$ 变单射。
- **完备性**：Banach 空间的闭子空间的商仍完备；证明用「每陪集挑好代表 + 绝对收敛判别」。
- **核心技巧**：商空间问题翻译成「挑代表」问题，下确界论证保「≤」不保「=」。

在下一节，泛函分析的主角终于登场——**线性算子**：从线性空间到线性空间的保持线性结构的映射，它是「矩阵」在无穷维的化身，也是本书余下全部章节的研究对象。
