## 为什么从生灭过程开始

上一节我们把「到达」建模成 Poisson 流。现在给它配上服务：每个到达的顾客需要一个随机长度的服务时间。如果把服务时间也假设成指数分布，那么「系统里有多少顾客」这个量就变成了一条随机游走——只能在相邻整数之间跳动，向上跳是**生**（来了一个顾客），向下跳是**灭**（走了一个顾客）。这类过程叫**生灭过程（birth–death process）**，而「指数到达 + 指数服务 + 单服务台」的组合，就是排队论里最著名的 M/M/1 队列。

M/M/1 是整个学科的**重力中心**：它简单到可以手算，又完整到容纳了排队论最核心的四个思想——状态图、稳态方程、Little 定律、流量强度。后面 M/M/c、M/G/1、排队网络全都是它的推广。先把这张图刻进脑子里：

## 1 排队记号：A/B/c 从哪儿来

Kendall 记号（David G. Kendall，1953）用一条简短的字符串描述一个队列：

$$A / B / c / K / N / D$$

依次是：到达间隔分布 / 服务时间分布 / 服务台数 / 系统容量 / 顾客源规模 / 服务规则。<span class="marginnote">A 与 B 的字母约定：M 表示指数分布（Markov，无记忆），D 表示确定分布（deterministic），G 表示一般分布（general），G`<sup>`I 表示独立同分布间隔。</span>默认省略 $K=\infty, N=\infty, D=FCFS$（先到先服务）。

所以 M/M/1 读作：**指数到达、指数服务、单个服务台**。M/M/c 是 $c$ 个并行的服务台；M/G/1 是到达指数、服务任意分布；G/G/1 是两者都一般化。记号本身就在预告课程的路线图：本专题正是沿着 A、B 逐一解放「指数」这个紧身衣的过程。

## 2 生灭过程与平衡方程

**生灭过程（birth–death process）**：一种状态空间为 $\{0,1,2,\ldots\}$ 的连续时间马尔可夫链，其中状态 $n$ 只能跳向 $n+1$（生，速率 $\lambda_n$）或 $n-1$（灭，速率 $\mu_n$）。<span class="marginnote">「生灭」是人口学语言：出生一个（+1）、死亡一个（-1）。排队论直接借用——来一个顾客是出生，服务完走一个是死亡，状态就是「当前人口 = 排队人数」。</span>

关键问题是：长时间运行后，系统处在状态 $n$ 的概率 $\pi_n$ 是多少？答案不靠硬解微分方程，而靠一张**状态转移图 + 平衡方程**。

写平衡方程的黄金法则：**在稳态下，从状态 $n$ 流入的概率流等于流出的概率流**。逐条看下图，状态 $n$ 只可能从 $n-1$ 生过来、从 $n+1$ 灭过来，也只可能生到 $n+1$、灭到 $n-1$。于是：

$$\pi_{n-1}\lambda_{n-1} + \pi_{n+1}\mu_{n+1} = \pi_n(\lambda_n + \mu_n), \qquad n\ge 1$$

更漂亮的写法是**流量守恒（flow balance）**：跨过「$n$ 与 $n+1$ 之间的割线」的概率流必须相等——向上流 $\pi_n\lambda_n$，向下流 $\pi_{n+1}\mu_{n+1}$，稳态时二者相等：

$$\pi_{n+1} = \frac{\lambda_n}{\mu_{n+1}}\,\pi_n, \qquad n\ge 0$$

这一递推可以直接积出来：$\pi_n = \pi_0 \prod_{i=0}^{n-1}\frac{\lambda_i}{\mu_{i+1}}$，再让所有概率之和为 1 定出 $\pi_0$。

**辨析｜易错点：** 平衡方程是稳态方程，不是瞬时方程。它回答的是「长期运行后状态占比」，前提是稳态**存在**——而稳态存在性取决于后面的稳定性条件。先把「写平衡方程」和「求稳态分布」这两个动作分开：前者是结构，后者是积分。

## 3 M/M/1 的稳态分布

M/M/1 是生灭过程的特例：**$\lambda_n=\lambda$（到达速率与系统状态无关）、$\mu_n=\mu$（服务速率恒定）**。定义**流量强度 / 业务强度（traffic intensity）**：

$$\rho = \frac{\lambda}{\mu}$$

代入流量守恒递推：$\pi_n = \rho^n \pi_0$，用归一化条件 $\sum_{n\ge0}\pi_n=1$ 解出 $\pi_0$，得到**M/M/1 稳态分布**：

$$\pi_n = (1-\rho)\,\rho^n, \qquad n\ge 0$$

这是一个**几何分布**。它在排队论里的地位，相当于正态分布之于统计：一切从它出发。

**稳定性条件（stationarity）**：$\rho = \lambda/\mu < 1$，即**到达速率必须严格小于服务速率**。这是排队论最重要的一条不等式。直观解释：平均每单位时间来 $\lambda$ 个、能服务 $\mu$ 个；若 $\lambda \ge \mu$，系统净人口不降，队列无界增长，稳态不存在。<span class="marginnote">$\rho<1$ 还有一个工程读法：$\rho$ 是服务台处于忙期的长期占比，也叫「服务台利用率」。利用率超过 1 的服务台是「入不敷出」，迟早崩盘；紧贴 1 的利用率意味着排队时间飞速上涨——这是第 5 节公式解析会定量揭示的「利用率陷阱」。</span>

## 4 Little 定律：排队论的第一定律

排队论所有结果之上，悬着一条与具体分布无关的定律——**Little 定律（Little's law）**：

$$\boxed{L = \lambda_{\text{eff}}\, W}$$

长期平均系统内顾客数 $L$，等于有效到达率 $\lambda_{\text{eff}}$ 乘以平均逗留时间 $W$。它对几乎任何稳定系统成立：单服务台、多服务台、网络、优先权……只要系统有稳态、到达率有定义。<span class="marginnote">John D. C. Little 在 1961 年严格证明。它的日常翻译是一句反直觉的话：「要让队变短，要么少来点人，要么让每个人快点走。」证明思路极其朴素：把到达与离开画成两条阶梯线，两者之间夹着的「水平距离」就是逗留时间，竖直差就是队长，两边积分一比即得。</span>

Little 定律给工程师一个免费工具：任意能测的两个量，第三个立刻得到。测出队列平均长度和平均到达率，无需任何分布假设，平均等待时间就是商。

## 5 公式解析：M/M/1 的性能公式

从 $\pi_n=(1-\rho)\rho^n$ 出发，排队论教科书上的四件套一次推完。

**平均队长：**

$$L = \sum_{n=0}^{\infty} n\,\pi_n = (1-\rho)\sum_{n=0}^{\infty} n\rho^n = (1-\rho)\frac{\rho}{(1-\rho)^2} = \frac{\rho}{1-\rho}$$

- **第一步，写定义**：平均队长是 $n$ 按稳态概率的期望；
- **第二步，求和**：几何级数的均值公式 $\sum n\rho^n = \rho/(1-\rho)^2$（对 $\sum\rho^n=1/(1-\rho)$ 求导即得）；
- **第三步，约分**：$(1-\rho)$ 消去一个因子。

**平均逗留时间（Little 定律）：** $W = L/\lambda = \frac{1}{\mu-\lambda}$——注意分母是 $\mu-\lambda$，**平均逗留时间随利用率非线性爆炸**。

**平均等待时间：** $W_q = W - \frac{1}{\mu} = \frac{\rho}{\mu-\lambda}$，其中 $1/\mu$ 是平均服务时间。

**平均等待队长：** $L_q = \lambda W_q = \frac{\rho^2}{1-\rho}$。

把 $L$ 对 $\rho$ 画出来，你看到的不只是一条曲线，而是排队论的**第一教训**：$\rho$ 从 0.5 涨到 0.9，队长从 1 涨到 9；$\rho$ 从 0.9 涨到 0.99，队长从 9 涨到 99。**利用率每向 1 逼近一位小数，等待时间约放大十倍。** 这就是为什么生产系统从不把 CPU 利用率推到 99%——那不是高效，是排队灾难的伏笔。

**辨析｜易错点：** $L = \rho/(1-\rho)$ 只对单服务台成立。到 M/M/c 那里公式完全不同（见下一节），但 $L=\lambda W$ 仍然成立。**Little 定律是通用的，几何分布不是。** 别把 M/M/1 的闭式公式当普适真理。

## 6 实战：一条客服热线的容量核算

把公式用到一条具体的客服热线上。设来电 Poisson，速率 $\lambda=1.5/\text{min}$；客服平均处理一通电话 $0.5$ 分钟，即服务速率 $\mu=2/\text{min}$。

**第一步，判稳定**：$\rho=\lambda/\mu=1.5/2=0.75<1$，稳态存在，客服利用率 75%。

**第二步，套四件套公式**：$L=\rho/(1-\rho)=0.75/0.25=3$ 通电话在系统里；$W=1/(\mu-\lambda)=1/0.5=2$ 分钟平均逗留；$W_q=\rho/(\mu-\lambda)=0.75/0.5=1.5$ 分钟平均等待；$L_q=\rho^2/(1-\rho)=0.5625/0.25=2.25$ 通在排队。

**第三步，算几个有工程含义的概率**：$P(\text{客服空闲})=\pi_0=1-\rho=0.25$——四分之一时间闲着；$P(\text{系统里至少有 5 通})=\sum_{n\ge5}\pi_n=\rho^5\approx0.237$——近四分之一的时刻队深超过 4。

把结果整理成一张表，运营上的含义一目了然：

| 量 | 数值 | 工程读法 |
| --- | --- | --- |
| $\rho$ | 0.75 | 客服 75% 忙，还有余量 |
| $L$ | 3 通 | 平均 3 通在系统里 |
| $W_q$ | 1.5 分钟 | 平均等 1 分半 |
| $P(\text{空闲})$ | 0.25 | 有四分之一时间没活干 |
| $P(\text{队长}\ge5)$ | 0.237 | 深队并不罕见 |

**辨析｜易错点：** 若把 $\lambda$ 提到 $1.9$（$\rho=0.95$），$W_q$ 从 1.5 分钟暴涨到 $0.95/0.1=9.5$ 分钟——**到达只增了 27%，平均等待却翻了 6 倍多**。这就是第 5 节「利用率陷阱」的数值版：扩容决策要在 $\rho$ 接近 1 之前做出，而不是之后。

## 7 小结

- **Kendall 记号** A/B/c/K/N/D 一行描述队列；M/M/1 = 指数到达 + 指数服务 + 单台。
- **生灭过程**：状态只跳相邻整数；稳态由流量守恒方程 $\pi_{n+1}\mu_{n+1}=\pi_n\lambda_n$ 决定。
- **M/M/1 稳态分布** $\pi_n=(1-\rho)\rho^n$，几何分布，前提是稳定性条件 $\rho<1$。
- **Little 定律** $L=\lambda W$：与分布无关的第一定律，从任意两个可测量推第三个。
- **四件套公式**：$L=\rho/(1-\rho)$，$W=1/(\mu-\lambda)$，$W_q=\rho/(\mu-\lambda)$，$L_q=\rho^2/(1-\rho)$；利用率越近 1，等待近似十倍放大。

在下一节，我们把单服务台扩成 $c$ 个服务台，并把多个服务台串联成**排队网络**——那里会第一次遇到「乘积形式解」这个漂亮结构。
