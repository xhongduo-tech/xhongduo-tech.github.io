# 有约束情况下的信源信道分离

<div class="epigraph">
<p>无损分离的门槛是 $H < C$；允许失真后，门槛放宽成 $R(D) < C$——多出的余地，正是失真买的。</p>
<footer>—— 克劳德 · 香农（Claude E. Shannon）</footer>
</div>

<div class="article-byline">
<p>第二级 · 信息论 ｜ Cover &amp; Thomas《Elements of Information Theory》 §10.6 ｜ 2026-08-07</p>
</div>

## 为什么从「放宽门槛」开始

第 36 篇的信源信道分离定理说的是：**无损**传输需要 $H < C$，且分离设计即可达到最优。

但现实里更常见的是**有损**传输：语音、图像、视频的码率远低于信源熵，靠的就是「允许失真」。那么分离定理在有损情形下怎么推广？

答案干净利落：把「$H$」换成「率失真函数 $R(D)$」——

$$
R(D) < C \ \Longleftrightarrow\ \text{失真 $\le D$ 的可靠传输可能}
$$

- **正向**：只要 $R(D) < C$，就可以「先有损压缩到 $R(D)$、再纠错到容量 $C$」，分离设计达到失真 $\le D$。
- **逆向**：若 $R(D) > C$，任何（联合或分离）方案都无法做到失真 $\le D$。

这一篇证明这个推广、解释「$R(D)$ 取代 $H$」的含义，并把它与无损版本对照。<span class="marginnote">有损分离定理在 Cover &amp; Thomas §10.6。它是「第三定理」与「分离定理」的汇合：率失真给「信息率」下定义（$R(D)$），分离定理给「率与容量比较」下结论（$R(D) < C$）。至此，信息论三大支柱收拢成一个判据。</span>

## 1 定理的陈述

**有损信源信道分离定理**：设信源熵率 $H$、失真度量 $d$、率失真函数 $R(D)$，信道容量 $C$。

- **正向**：若 $R(D) < C$，则存在分离系统（先率失真编码、再信道编码），使接收端失真 $\le D$、错误概率任意小。
- **逆向**：若 $R(D) > C$，则任何系统都无法做到失真 $\le D$。

**与无损版本的关系**：无损情形 $D = 0$，$R(0) = H$，退化为 $H < C$——**无损分离定理是有损定理的特例**。<span class="marginnote">「$R(0) = H$」把两个分离定理无缝衔接：有损版本把无损版本「包含」进去，而不是「取代」。这在数学里是最舒服的结构——一个更一般的定理，自动涵盖旧结论。</span>

## 2 正向证明：分离依然够用

**正向（$R(D) < C$ 可达）**：

1. **率失真编码**：由率失真定理，存在码率 $R_1$（$R(D) < R_1 < C$）的有损编码，使失真 $\le D$、压缩到 $2^{nR_1}$ 个消息。
2. **信道编码**：把 $2^{nR_1}$ 个消息当作信道输入消息，码率 $R_1 < C$，由信道编码定理，存在码本使错误概率任意小。
3. **串联**：压缩失真 $\le D$、信道误码任意小，总失真 $\le D + \epsilon$。

**关键**：两段各自用各自的定理，中间只依赖「$R(D) < R_1 < C$」这个数。**压缩与纠错分开设计，依然达到最优。**<span class="marginnote">正向证明的唯一新意是「挑一个中间码率 $R_1$」：它必须同时大于 $R(D)$（压缩可行）且小于 $C$（信道可行）。因为 $R(D) < C$，这样的 $R_1$ 一定存在——「两个区间非空相交」是全部条件。</span>

## 3 逆向证明：为什么 $R(D) > C$ 不行

**逆向（$R(D) > C$ 不可能）**：设系统做到失真 $\le D$。

- 系统整体定义了 $X^n \to \hat X^n$（编码 + 信道 + 解码的复合）。
- 失真 $\le D$ ⇒ 由率失真定理的逆向，$I(X^n; \hat X^n) \ge nR(D)$（达到失真 $D$ 至少要 $R(D)$ 信息）。
- 但 $X^n \to Y^n \to \hat X^n$ 是马尔可夫链，DPI 给出 $I(X^n; \hat X^n) \le I(X^n; Y^n) \le nC$。
- 于是 $nR(D) \le nC$，即 $R(D) \le C$，与 $R(D) > C$ 矛盾。✔<span class="marginnote">逆向证明把三大定理串成一条线：率失真定理给出「失真 $D$ 需要 $nR(D)$ 信息」的下界，DPI 给出「信道只能传 $nC$」的上界——两个极限量在「$R(D)$ vs $C$」处撞车。一条不等式，把信源、信道、失真三件事焊在一起。</span>

## 4 公式解析：$R(D) < C$ 的直觉

把判据拆开：

$$
R(D) < C \quad\Longleftrightarrow\quad \text{失真 $\le D$ 的通信可能}
$$

- **$R(D)$**：信源「压缩到失真 $D$」所需的最小码率——有损传输的「信息需求」。
- **$C$**：信道的「信息供给」。
- **$R(D) < C$**：需求小于供给。失真预算 $D$ 把信源的「需求」从 $H$ 降到 $R(D)$，让本来传不过去的信源（$H > C$）变得传得过去。

**意义**：**失真不是「缺陷」，是「把信息需求压到容量以下的工具」。**

- 若 $H > C$：无损传输不可能，但允许失真 $D$（使 $R(D) < C$）就可行。
- 若 $R(D) = C$：临界，理论上可行但不现实（需无限复杂度）。
- 失真的「购买力」：$H - R(D)$ 是「用失真买来的码率余量」。

**一个具体例子**：语音信源熵率 $H \approx 64$ kbps（PCM），电话信道容量 $C \approx 30$ kbps——无损传不过。但允许语音失真（MOS 评分的感知质量），$R(D)$ 可降到 8 kbps（G.729 标准），$R(D) \ll C$，传输轻松可行。**失真预算把不可能变成可能。**<span class="marginnote">「$H - R(D)$ 是失真买来的余量」是通信系统的经济学：语音编码用「感知失真」换来 8:1 的压缩，把 64 kbps 的需求砍到 8 kbps。这个「用失真换可行」的思维，从电话到 4G/5G 视频通话，贯穿整个通信史。</span>

**辨析｜易错点：** 三个容易错的地方：

- **$R(D)$ 依赖失真度量**：判据里的 $R(D)$ 是针对**具体失真度量**算的。换了失真（均方误差 vs 感知模型），$R(D)$ 变，判据也可能翻转。「感知失真」的好处正在于此：感知上允许的失真大，$R(D)$ 小。
- **分离最优仍然成立**：有损情形下，联合设计（端到端信源信道编码）在**渐近 + 点对点**下不优于分离——与无损版本同一条定理。
- **「$R(D) < C$」不是「$H < C$」的简单改名**：$R(D)$ 是函数、依赖失真预算 $D$，它的计算（二元、高斯、逆注水）正是前几篇的全部内容。<span class="marginnote">「联合设计不优于分离」在深度学习的「语义通信」里被反复讨论：有限块长、非平稳信源、多用户场景下，联合确实可能更好；但点对点无记忆 + 渐近 + 固定失真度量下，分离定理仍然成立。端到端学习的收益来自「边界条件」，不是「推翻定理」。</span>

**与全课程体系的连接：** 有损分离定理是信息论三大定理 + 分离定理的「最终汇合」：信源编码（$H$）、信道编码（$C$）、率失真（$R(D)$）在一个判据里相遇。在《信息与通信工程》里，它是「语音/视频编码 + 信道编码」分层设计的理论执照——与第 36 篇的无损版本并列，构成通信系统设计的总纲。

## 5 有损分离定理的工程意义

「$R(D) < C$」这个判据在通信工程里有非常直接的落地。

**语音编码的实例**：PCM 语音 64 kbps（$H \approx 64$），电话信道 $C \approx 30$ kbps——无损传不过。

- 用感知失真允许 $D$，$R(D)$ 降到 8-16 kbps（G.729 等）。
- $R(D) \ll C$，传输轻松可行。
- **失真预算把「不可能」变成「可能」**。

**视频编码的实例**：原始视频码率极高（$H$ 巨大），全靠「感知失真」压缩到 $R(D) < C$ 才能传。

**「分离设计」的工程红利**：

- 压缩器（语音/视频编码器）独立演进，不断降低 $R(D)$。
- 信道编码（Turbo/LDPC）独立演进，不断提高逼近 $C$ 的能力。
- 两端各自优化，组合仍然最优——**分离定理给了「分工」理论执照**。

**「有损分离」与「无损分离」的关系**：$D = 0$ 时退化为 $H < C$——同一套框架，两种极端。

**一句话**：有损分离定理是「压缩 + 纠错分层」的理论依据——失真预算让「信息需求」降到容量之下，分离设计让两端可以独立优化。
## 6 小结

- **有损分离定理**：$R(D) < C$ 是「失真 $\le D$ 可靠传输」的充要条件。
- 正向：率失真编码（$R_1 > R(D)$）+ 信道编码（$R_1 < C$），选 $R_1$ 衔接。
- 逆向：率失真下界 $nR(D) \le I(X^n;\hat X^n)$ + DPI 上界 $nC$，矛盾。
- **无损是特例**：$R(0) = H$，退化为 $H < C$。
- **直觉**：失真预算把「信息需求」从 $H$ 压到 $R(D)$，让本来传不过去的信源变得可行。
- 分离最优在点对点 + 渐近下仍成立；端到端联合的收益来自边界被破坏。
