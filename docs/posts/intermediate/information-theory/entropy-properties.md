# 熵的性质：非负性、对称性与可加性

<div class="epigraph">
<p>你应当把它叫作熵。理由有二：其一，你的不确定性函数在统计力学里早已以此命名；其二，也是更重要的——没有人真正知道熵是什么，所以在辩论中你永远占上风。</p>

## 为什么从熵的性质开始

上一节我们定义了熵：$H(X) = -\sum_x p(x)\log_2 p(x)$，把它理解为随机变量 $X$ 的「不确定性」。可是一个量若能真正成为理论的基石，光有定义还不够——我们必须知道它**在什么运算下保持稳定、在什么边界上达到极端**。这就是性质的意义：性质是定义与后续定理之间的脚手架。

在「从极限到大模型」的主线上，这一步尤其关键。大语言模型的损失函数是交叉熵，而交叉熵的一切行为——为什么损失非负、为什么把词表里所有 token 概率一视同仁地对待、为什么自回归分解下总损失能拆成每一项之和——全部由熵的性质决定。今天先立住三条最基本的性质，之后无论是条件熵、链式法则还是 KL 散度，都会反复回来调用它们。<span class="marginnote">本专题后续会反复用到这三条性质：条件熵的定义依赖「把联合熵按条件拆开」（链式法则），相对熵的非负性依赖「熵不超过均匀分布的熵」，而后者又依赖 Jensen 不等式。性质是地基，地基打得牢，后面才盖得高。</span>

## 1 非负性：确定性是熵的底线

**熵（离散）是非负的**：对任意离散随机变量 $X$，

$$H(X) \ge 0$$

取等号当且仅当 $X$ 以概率 $1$ 取某一个值——也就是 $X$ 根本没有不确定性。

证明只有一行：对每个 $x$，$0 < p(x) \le 1$，故 $\log_2 p(x) \le 0$，于是 $-p(x)\log_2 p(x) \ge 0$；按约定 $0\log 0 = 0$，非负项求和仍非负。<span class="marginnote"><strong>辨析｜注意范围：</strong>非负性只对<strong>离散</strong>熵成立。连续随机变量的「微分熵」可以是负的，这是第七篇《微分熵》的著名陷阱——那里底数与单位的选择会直接改变熵的值，与这里的非负性形成鲜明对照。</span>

这条性质的直觉是：**信息只可能消除不确定性，不可能制造不确定性**。你观察一个随机变量，最坏也就是毫无收获（熵为 0，结果早已确定），不可能越观察越糊涂。

## 2 对称性：熵只看概率的多重集

**熵关于它的参数是对称的**：把概率分布的各分量任意调换顺序，熵不变。设 $X$ 取值于 $\{x_1, \dots, x_n\}$，则

$$H(p_1, p_2, \dots, p_n) = H(p_{\pi(1)}, p_{\pi(2)}, \dots, p_{\pi(n)})$$

其中 $\pi$ 是任意一个排列（permutation）。

理由同样直接：求和 $\sum_i p_i \log p_i$ 只依赖「每个概率值出现几次」，不依赖它们贴在哪个符号上。于是

$$H(0.5,\, 0.25,\, 0.25) = H(0.25,\, 0.5,\, 0.25) = 1.5 \text{ bits}$$

三个符号只是换了名字，不确定性的总量纹丝不动。<span class="marginnote"><strong>直觉：</strong>熵度量的是「结果有多难猜」，而不是「结果本身有多重要」。一枚硬币即使把「正面」改叫「天」、把「反面」改叫「地」，掷出的不确定性还是 1 比特——含义变了，熵不变。这正说明熵是<strong>结构量</strong>而非<strong>语义量</strong>。</span>

对称性引出一个关键推论：**熵只由概率分布的多重集决定，与取值符号无关**。这意味着当我们只关心「不确定性」时，标签叫什么无关紧要——这为后面把熵写成 $H(p)$（以分布为自变量）提供了合法性，也让「$H(X) = H(\text{Bernoulli}(p))$」这类写法成为可能。

## 3 可加性：独立变量让熵「相加」

**如果 $X$ 与 $Y$ 相互独立，则联合熵等于各自熵之和**：

$$H(X, Y) = H(X) + H(Y) \qquad (X \perp Y)$$

这里 $H(X,Y)$ 是**联合熵（joint entropy）**，即把 $(X,Y)$ 当作一个整体随机变量时的熵——它是下一节的主角，这里先借用它的定义：

$$H(X,Y) = -\sum_{x}\sum_{y} p(x,y)\log_2 p(x,y)$$

可加性的直观含义是：**独立的两件事，不确定性正好叠加**。掷一枚硬币再掷一枚硬币，两枚硬币各自都是 1 比特不确定性，合起来恰好 2 比特——不多不少。因为两件事互不牵扯，观察其中任何一件，都不会减少另一件的不确定性。

一个立即出现的反例提醒我们「独立」二字不可省：若 $Y = X$（完全依赖），则联合熵 $H(X,Y) = H(X)$，远小于 $2H(X)$。**依赖越强，联合不确定性越被「压缩」**——这正是下一节条件熵与互信息要精确刻画的现象。

把两条路各自算一遍，差异立刻显形。设 $X$、$Y$ 独立且都等概率取值于 $\{0,1\}$，则联合分布恒为 $p(x,y) = \tfrac14$，于是

$$H(X,Y) = -4 \cdot \tfrac14 \log_2 \tfrac14 = 2 \text{ bits} = H(X) + H(Y)$$

可加性成立。再令 $Y = X$，则 $(X,Y)$ 只可能取 $(0,0)$ 或 $(1,1)$、各占 $\tfrac12$，联合熵

$$H(X,Y) = -\left(\tfrac12 \log_2 \tfrac12 + \tfrac12 \log_2 \tfrac12\right) = 1 \text{ bit}$$

同一个 $X$、$Y$，仅仅从「独立」换成「完全依赖」，联合熵就从 $2$ 掉到 $1$。**消失的这 1 bit，正是两个变量共享的那份信息**——它不会凭空蒸发，而是被互信息接管了。这个「守恒」视角，是理解互信息的钥匙。

## 4 公式解析：为什么可加性只在独立时成立

把「独立 ⇒ 可加」证一遍，等于把整个信息论最关键的一步「概率相乘 ⇄ 熵相加」走通。过程四步。

- **第一步，写出独立的概率条件**：$X$、$Y$ 独立当且仅当对一切 $x, y$ 有

$$p(x, y) = p(x)\, p(y)$$

- **第二步，代入联合熵，对数把乘积拆成和**：

$$H(X,Y) = -\sum_{x}\sum_{y} p(x)p(y) \log_2\big(p(x)p(y)\big) = -\sum_{x}\sum_{y} p(x)p(y)\Big(\log_2 p(x) + \log_2 p(y)\Big)$$

- **第三步，把双重和拆开**：第一项先对 $y$ 求和、$\sum_y p(y) = 1$，剩 $\sum_x p(x)\log_2 p(x)$；第二项同理。于是

$$H(X,Y) = -\sum_x p(x)\log_2 p(x) \;-\; \sum_y p(y)\log_2 p(y) = H(X) + H(Y)$$

- **第四步，读出「为什么」**：等号成立的根源是 $p(x,y)$ 能因式分解。一旦 $X$、$Y$ 有依赖，$\log_2 p(x,y)$ 就拆不成两项之和，可加性随之失效。

对照来看，不独立时只会得到一个**不等式**（次可加性）：

$$H(X,Y) \le H(X) + H(Y)$$

「联合的不确定性不超过各自不确定性之和」——直觉上，共同信息被两份不确定性重复计数了。这条不等式与它的等式条件（独立）构成了信息论的第一个「差距」：差的这部分恰好是后面要定义的**互信息**。<span class="marginnote">把 $H(X)+H(Y)-H(X,Y)$ 记为 $I(X;Y)$，它度量「知道 $Y$ 能减少多少对 $X$ 的不确定性」。本专题《互信息的定义与多种等价表达》会系统展开，这里先记住这个「差距」的存在。</span>

## 5 辨析：可加性 ≠ 链式法则

初学最容易把两条式子弄混：

$$H(X,Y) = H(X) + H(Y) \quad \text{（可加性，仅 $X \perp Y$）}$$

$$H(X,Y) = H(X) + H(Y \mid X) \quad \text{（链式法则，恒成立）}$$

**辨析｜易错点：** 可加性要求独立，是一个**条件性结论**；而链式法则对任意 $X$、$Y$ 都成立，它是从条件概率 $p(y \mid x)$ 直接推出来的，不需要任何独立性假设。把两者混用，是后续所有「信息量算错」的常见源头。链式法则我们会在下一节之后专门用一篇来讲；今天只需记住：**独立时两者重合，不独立时以链式法则为准**。

顺带一提，这两个公式在机器学习里的地位截然不同：可加性告诉你「独立特征可以分别建模、损失相加」；链式法则告诉你「任何联合分布都能被分解成一组条件分布逐项相乘」——后者正是自回归语言模型逐个 token 预测的数学根据，也是交叉熵损失能被写成「每个位置单独算损失再求和」的原因。<span class="marginnote">一个实用的自查习惯：遇到「联合分布能否拆成和」的问题，先问一句「独立吗」。词表里相邻 token 显然不独立，所以大模型的损失必须按<strong>条件</strong>（给定前文）逐项求和，而不是把每个 token 的边缘熵相加——前者是链式法则，后者是错误使用可加性。</span>

## 6 小结

- **非负性**：离散熵 $H(X) \ge 0$，取等当且仅当 $X$ 几乎必然取某值；信息只能消除不确定性，不能制造不确定性。
- **对称性**：$H(p_1,\dots,p_n)$ 对参数的任意排列不变，熵只依赖概率的多重集，与符号标签无关。
- **可加性**：$X \perp Y$ 时 $H(X,Y) = H(X) + H(Y)$；证明的关键是 $p(x,y) = p(x)p(y)$ 使对数能把乘积拆成和。
- **次可加性**：一般情形 $H(X,Y) \le H(X) + H(Y)$，等号在独立时成立；两者的差距正是互信息。
- **与链式法则的区别**：可加性要求独立，链式法则恒成立——不要混用。
- **一句话记忆**：熵度量「一个分布的不确定」，非负是底线、对称是本性、可加是独立红利。

在下一节，我们将正式引入联合熵与条件熵，把「已知 $Y$ 之后 $X$ 还剩多少不确定性」用公式钉死——这是通往互信息与信道容量的必经之路。
