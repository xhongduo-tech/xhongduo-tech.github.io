# 信道编码定理：可达性的证明

<div class="epigraph">
<p>凡低于容量者，皆可抵达——这是香农对「可靠通信」最慷慨也最精确的允诺。</p>
<footer>—— 克劳德 · 香农（Claude E. Shannon）</footer>
</div>

<div class="article-byline">
<p>第二级 · 信息论 ｜ Cover &amp; Thomas《Elements of Information Theory》 §7.7 ｜ 2026-08-07</p>

## 为什么从「把承诺兑现」开始

随机编码 + 联合典型译码已经给出了「对固定输入分布 $p(x)$，$R < I(X;Y)$ 可达」。要得到完整的**信道编码定理**，还差最后一步：**对最优输入分布取最大化**，把「$R < I(X;Y)$」升级成「$R < C = \max_p I(X;Y)$」。

这一篇我们做三件事：

1. 完整陈述信道编码定理（正向 + 逆向）；
2. 完成正向（可达性）的证明——选 $p^*$、随机编码、联合典型译码、平均论证；
3. 提炼证明的结构，让它成为「一切正向编码证明」的模板。

**信道编码定理（Shannon 第二定理）**：对离散无记忆信道，容量 $C = \max_{p(x)} I(X;Y)$。对任意 $R < C$，存在码率为 $R$ 的 $(n, M)$ 码，使解码错误概率 $P_e \to 0$（$n \to \infty$）；反之，任何 $R > C$ 的码，$P_e$ 不可能趋向于 0。<span class="marginnote">「可达性」与「不可能性」合起来，容量 $C$ 成为「可靠通信速率」的精确分界。值得强调：定理对<strong>任意 DMC</strong> 成立，不依赖信道的具体结构——这正是「容量」这个概念的力量。</span>

## 1 正向证明：完整的一步到位

**定理（正向）**：对任意 $R < C$，存在 $(n, M)$ 码（$M = 2^{nR}$），使 $P_e \le 2\epsilon$。

**证明框架**（五步）：

1. **选最优输入分布**：取 $p^*(x)$ 使 $I_{p^*}(X;Y) = C$。这是存在的（$I$ 关于 $p$ 连续、$p$ 空间紧）。
2. **随机生成码本**：独立生成 $M$ 个码字，每个码字的符号独立采样自 $p^*$。
3. **联合典型译码**：收到 $y^n$，找唯一联合典型的码字。
4. **框错误**（对 $W = 1$）：
   $$
   \bar P_e \le \epsilon + (M - 1) 2^{-n(C - 3\epsilon)}
   $$
5. **取 $n$ 大**：$R < C$ 时选 $\epsilon$ 使 $3\epsilon < C - R$，则 $(M-1)2^{-n(C-3\epsilon)} = 2^{n(R - C + 3\epsilon)} \to 0$。于是 $\bar P_e \le 2\epsilon$。

**收尾**：存在码本 $P_e \le \bar P_e \le 2\epsilon$。✔<span class="marginnote">第 4 步里把 $I$ 换成 $C$ 是「最大化」的唯一作用：$I_{p^*}(X;Y) = C$，所以随机码本按 $p^*$ 生成时，错误界里的指数直接用 $C$。这正是「容量 = 可达上限」的机制——$p^*$ 让码字「恰好按最能传的方式生成」。</span>

## 2 公式解析：$R < C$ 为什么足够

把关键不等式拆开看：

$$
(M - 1) \cdot 2^{-n(C - 3\epsilon)} = 2^{nR} \cdot 2^{-n(C - 3\epsilon)} = 2^{-n(C - R - 3\epsilon)}
$$

- **$M = 2^{nR}$**：码本大小按码率 $R$ 指数增长——消息越多，码字越多。
- **$2^{-nC}$**：每个码字「偶然与 $y^n$ 联合典型」的概率按容量指数衰减——码字越多，错误越多；但每错一个码字的概率按 $C$ 指数减小。
- **净指数 $C - R$**：$C > R$ 时，衰减压倒增长，总错误指数级消失。
- **$3\epsilon$ 的松弛**：$C - R > 3\epsilon$ 即可，$C$ 与 $R$ 的「间隙」给典型性容差留出空间。

**一句话**：**码率的增长用 $2^{nR}$，错误码字每错一个用 $2^{-nC}$——只要 $R < C$，乘法上「错的增长速度」追不上「单个错的衰减速度」。**<span class="marginnote">「$C - R$ 是净指数」这个观察，是错误指数理论的开端：$P_e \approx 2^{-n E(R)}$，而 $E(R) > 0$ 当且仅当 $R < C$。随机编码给出的具体指数 $E_r(R)$ 就是 Gallager 界——它定量回答「错误到底降多快」。</span>

## 3 证明的结构：一切正向定理的模板

正向证明的五步，几乎原样复用于所有「可达性」定理：

| 步骤 | 信源编码（压缩） | 信道编码（通信） |
| --- | --- | --- |
| 1. 分布 | 真实信源 $p(x)$ | 最优输入 $p^*(x)$ |
| 2. 构造 | 典型集编号 | 随机生成码本 |
| 3. 规则 | 典型序列编短码 | 联合典型译码 |
| 4. 错误框 | 非典型概率 $\le \epsilon$ | 两类错误上界 |
| 5. 收尾 | $R > H$ 即可 | $R < C$ 即可 |

两个定理共享同一骨架：**典型性定义「多数好对象」→ 只处理好的 → 误差 $\le \epsilon$ → 取 $n$ 大收敛**。理解了这个模板，信息论的三大定理（信源、信道、率失真）就都「长得一样」了。<span class="marginnote">把信源与信道定理并排看，会发现它们互为镜像：压缩是「$R > H$ 时错误任意小」，通信是「$R < C$ 时错误任意小」——一边是「信息多于熵」，一边是「信息少于容量」。这两个不等号方向的对称，正是「信源信道分离定理」能成立的深层原因。</span>

**辨析｜易错点：** 正向证明里三个容易滑过的地方：

**$P_e \le 2\epsilon$ 里的 $\epsilon$ 是三重角色**：典型集容差、AEP 概率余量、以及「$C - R > 3\epsilon$」的间隙。三者合一，选参要统筹。
**「存在」不是「随机选一个就成」**：平均论证保证存在，但随机生成的特定码本可能碰巧很差。工程上靠显式构造或「多试几个」，理论只承诺存在。
**$n$ 要「足够大」**：所有量都是渐进的；$R$ 越接近 $C$，需要的 $n$ 越大。定理不承诺「小 $n$ 也能接近容量」。<span class="marginnote">「$R$ 越接近 $C$，$n$ 要求越大」是正向定理的软肋——它只保证「极限可达」。有限块长理论（色散）给出了更精细的量化：$n$ 有限时，可达速率是 $C - \sqrt{\frac{V}{n}}\Phi^{-1}(\epsilon) + O(\frac{\log n}{n})$，其中 $V$ 是信道色散。这是现代短码设计的理论依据。</span>

## 4 从正向到完整定理

正向证明的是「$R < C$ 可达」。完整的信道编码定理还要补上「$R > C$ 不可达」——那是下一篇的主角（用 Fano 不等式）。

两个方向合起来：

$R < C$：$P_e$ 可以任意小（正向，本篇）。
$R > C$：$P_e$ 有正下界，不可能任意小（逆向，下一篇）。
$R = C$：临界情形，理论上无限复杂度可达，实际不可行。

**容量 $C$ 因此是「精确的门槛」**，不是「大致的好目标」。这一精确性，正是信息论区别于工程经验的地方。<span class="marginnote">工程上常说「逼近香农极限」——Turbo 码离容量 0.004dB、LDPC 到 0.04dB、极化码可证明达到容量但有限长表现受色散限制。这些「逼近」都以 $C$ 为坐标原点，可见 $C$ 作为「门槛」的工程分量。</span>

**与全课程体系的连接：** 信道编码定理在《信息与通信工程》里是纠错码设计的宪法；在第三级《计算机网络》里对应「可靠传输」的理论极限。它和信源编码定理、率失真定理构成三大定理，是信息论「正名」的基石。

## 5 从定理到实践：Turbo、LDPC 与极化码

信道编码定理说「好码存在」，但没说「好码长什么样」。半个世纪的编码实践，就是「找好码」的过程。

**Turbo 码（1993）**：两个卷积码交织并联，迭代译码——首次逼近容量（离 $C$ 约 0.5 dB）。

**LDPC 码（1962 发明、1990s 复兴）**：稀疏校验矩阵 + 置信传播译码——离 $C$ 约 0.04 dB，进入 5G 标准。

**极化码（2008）**：信道极化的显式构造——**理论上可证明达到容量**，但有限长下仍需级联。

**三条路线的共同点**：

- 都逼近「随机编码界」——随机编码给出的错误指数是它们的性能基准。
- 都用「迭代/置信传播」译码——工程实现「找般配」的高效近似。
- 都依赖「码率低于容量」的余量换取可靠性。

**为什么随机编码理论如此重要**：它提供了「极限」——任何显式码的性能都以它为参照。LDPC「离香农极限 0.04 dB」这句话，坐标原点就是随机编码界。

**工程现实**：达到容量需要无限长码，实际码长有限，所以永远「接近」而非「达到」。码长与性能的权衡，是编码工程的核心张力。

**一句话**：信道编码定理是「宪法」，Turbo/LDPC/极化码是「执行」——执行永远在接近宪法，但不超越它。
## 6 小结

- **信道编码定理**：$R < C$ 可靠可达（正向），$R > C$ 错误必现（逆向）。
- 正向五步：选 $p^*$ → 随机编码 → 联合典型译码 → 框错误 → 平均论证。
- 核心不等式：$P_e \le \epsilon + 2^{-n(C - R - 3\epsilon)}$，净指数 $C - R$ 决定成败。
- 证明模板：典型性定义「好对象」→ 只处理好的 → 误差 $\le \epsilon$ → 大 $n$ 收敛。
- **辨析**：$\epsilon$ 一量三角色；「存在」≠「随机即得」；渐进性靠大 $n$ 兑现。
- 与信源编码定理互为镜像：$R > H$ 与 $R < C$ 的两个方向，是分离定理的伏笔。
