## 为什么从条件互信息开始

上一节我们把互信息定义为「$Y$ 替 $X$ 消掉的不确定性」。但现实中几乎没有「无背景」的提问：医生说「这个指标告诉我病情」时，前提往往是「在年龄、病史都已知的情况下」。**给定一个背景变量 $Z$，$Y$ 还能告诉 $X$ 多少？** 这就是**条件互信息（conditional mutual information）**要回答的问题。

更深刻的是：互信息在「条件化」面前并不忠厚——**它可以因条件化而变大，也可以因条件化而变小**。这与条件熵截然不同（条件熵永远只减不增）。蒙提霍尔问题、辛普森悖论、贝叶斯网络的「explaining away」，全是这一现象的化身。而把条件互信息沿变量逐个累加，就得到**互信息的链式法则**——它与熵的链式法则同构，是自回归模型与贪心特征选择的数学依据。<span class="marginnote">条件互信息在信息论里的地位常被低估：信道容量的多符号版本、马尔可夫链的互信息单调性（第二篇）、以及「充分统计量」的定义，全都要靠它。它在贝叶斯网络里还有一个日常名字：<strong>给定父节点后，节点与祖先的依赖被切断</strong>——这正是不变式，也是后文「explaining away」的来源。</span>

## 1 定义：给定 Z 之后，Y 还告诉 X 多少

**条件互信息（conditional mutual information）**：设 $X,Y,Z$ 是三个随机变量，定义

$$I(X;Y \mid Z) = H(X\mid Z) - H(X\mid Y,Z)$$

逐项解读：$H(X\mid Z)$ 是「已经知道 $Z$、还不知道 $Y$」时猜 $X$ 的比特数；$H(X\mid Y,Z)$ 是「$Z$ 和 $Y$ 都知道」后剩下的比特数。两者之差正是**在 $Z$ 已知的前提下，$Y$ 额外替 $X$ 消掉的不确定性**。

它与互信息的定义完全同构，只是每一项都「条件在 $Z$ 上」。和互信息一样，它也有多种等价表达：

$$I(X;Y\mid Z) = H(Y\mid Z) - H(Y\mid X,Z)$$
$$I(X;Y\mid Z) = H(X,Z) + H(Y,Z) - H(Z) - H(X,Y,Z)$$
$$I(X;Y\mid Z) = \sum_z p(z)\, D\big(p(x,y\mid z) \;\big\|\; p(x\mid z)p(y\mid z)\big)$$

最后一种尤其值得留意：**条件互信息 = 对每个 $z$ 计算「给定 $z$ 时联合分布离独立分布的距离」，再按 $p(z)$ 加权平均**。它把「整体离独立多远」换成了「逐层离独立多远再平均」——这是理解「条件化为何能改变互信息」的钥匙。

记号上要把三个东西分清：$I(X;Y\mid Z)$ 是条件互信息（给定 $Z$ 后 $X,Y$ 的共享信息），$I(X;Y)$ 是无条件互信息，而 $I(X;Y;Z)$ 是三元互信息（三者共享的交互项，可正可负，见《Venn 图关系》）。**分号与竖线的差别，是读信息论文献的第一道门槛。**

## 2 互信息的链式法则

把互信息推广到「多个变量合起来」的情形。**互信息的链式法则（chain rule for mutual information）**：

$$I(X_1, X_2, \dots, X_n; Y) = \sum_{i=1}^{n} I(X_i; Y \mid X_1, \dots, X_{i-1})$$

读法：**「$X_1,\dots,X_n$ 全体与 $Y$ 的互信息」=「$X_1$ 单独对 $Y$ 的信息」+「在 $X_1$ 已知后 $X_2$ 新增的对 $Y$ 的信息」+「在 $X_1,X_2$ 已知后 $X_3$ 新增的信息」……一直加到最后一项。**

两变量的特例最常见，值得单独写出：

$$I(X_1, X_2; Y) = I(X_1; Y) + I(X_2; Y \mid X_1)$$

它回答了「两个特征合起来告诉我多少关于标签 $Y$ 的事」：先问第一个特征单独知道多少，再问第二个特征在第一个已知之后**额外**知道多少。贪心特征选择正是沿这条链逐个贪下去——每次选「在当前已选特征条件下，信息增益最大的下一个特征」<span class="marginnote">这解释了机器学习里一个反直觉现象：<strong>两个各自无用的特征，合起来可能极有用</strong>（例如异或型标签：$Y=X_1\oplus X_2$ 时每个特征单独与 $Y$ 独立，但合起来完全决定 $Y$）。链式法则告诉我们，第二个特征的贡献要在第一个已知之后重新评估——「单独无用」与「合起来有用」并不矛盾。</span>。

举个具体数字把「合起来有用」钉死：设标签 $Y=X_1\oplus X_2$，$X_1,X_2$ 独立均匀于 $\{0,1\}$。单个看，$I(X_1;Y)=0$、$I(X_2;Y)=0$——每个特征与标签独立；但 $I(X_1,X_2;Y)=H(Y)=1$ bit。链式法则把它拆开：$I(X_1,X_2;Y)=I(X_1;Y)+I(X_2;Y\mid X_1)=0+1=1$——第二个特征在 $X_1$ 已知后贡献了整整 1 bit。**这就是为什么异或型任务需要「组合特征」：单个特征无从谈起，配对之后才信息满载。**

## 3 条件化既能增信息也能减信息

这是本节最反直觉、也最重要的观察：**$I(X;Y\mid Z)$ 与 $I(X;Y)$ 之间没有确定的大小关系**。

**方向一：条件化增加互信息。** 最经典的例子是蒙提霍尔问题（Monty Hall）。设 $X$ 是汽车所在的门，$Y$ 是主持人打开的门，$Z$ 是你最初选的门。不给定 $Z$ 时，$Y$ 与 $X$ 几乎没有共享信息（主持人开哪扇门还取决于你选哪扇，边缘化掉 $Z$ 后两者近乎独立）；但**给定 $Z$ 之后**，主持人开出的门 $Y$ 几乎完全确定了汽车在哪扇门——于是 $I(X;Y\mid Z)$ 显著大于 $I(X;Y)$。条件化把「隐藏在背景里的结构」点亮了。

更干净的数字例子是异或：设 $X,Y$ 独立同分布 $\text{Bernoulli}(1/2)$，$Z = X \oplus Y$。则 $I(X;Y)=0$（本来就独立），而给定 $Z$ 后 $X$ 与 $Y$ 互相锁定（知道 $X$ 与 $Z$ 就完全知道 $Y$），故 $I(X;Y\mid Z)=1$ bit。**$0 \to 1$，条件化让共享信息从无到有。**

**方向二：条件化减少互信息。** 设 $Z$ 是一个「共同原因」，$X$、$Y$ 都是它的独立噪声版本，例如 $Z\sim\text{Bernoulli}(1/2)$，$X=Z\oplus N_1$、$Y=Z\oplus N_2$（$N_1,N_2$ 独立小噪声）。边缘上看，$X$、$Y$ 因共同的 $Z$ 而相关，$I(X;Y)>0$；但**给定 $Z$ 之后**，$X$、$Y$ 只剩各自独立的噪声，互信息归零：$I(X;Y\mid Z)=0$。条件化把「虚假的关联」拆穿了。

一句话总结：**条件化不是滤镜——它可能揭示关系，也可能消除关系，方向由「$Z$ 在因果结构里扮演什么角色」决定。** 这是信息论与因果推断（第二级《概率论与数理统计》的延伸）交汇最深的地方。

## 4 一个数值例子：异或与共同原因

把「条件化可增可减」落到具体数字上，用两个小世界各算一遍。

**例一（条件化增加）**：$X,Y$ 独立均匀于 $\{0,1\}$，$Z=X\oplus Y$。此时 $H(X)=H(Y)=1$，$H(X,Y)=2$；联合分布 $p(x,y)=\frac14$ 与独立分布 $p(x)p(y)=\frac14$ 逐点相等，故 $I(X;Y)=0$。再看条件版本：给定 $Z=0$，则 $X=Y$，于是 $H(X\mid Y,Z=0)=0$；$Z=1$ 时同理，故 $H(X\mid Y,Z)=0$。而 $H(X\mid Z)=1$（给定 $Z$ 后 $X$ 仍是均匀的）。于是

$$I(X;Y\mid Z) = H(X\mid Z) - H(X\mid Y,Z) = 1 - 0 = 1 \text{ bit}$$

**$I(X;Y\mid Z)=1 > I(X;Y)=0$**：条件化把两个独立的变量「锁」在了一起。

**例二（条件化减少）**：$Z$ 均匀于 $\{0,1\}$，$X=Z\oplus N_1$、$Y=Z\oplus N_2$，其中 $N_1,N_2$ 独立、各自以概率 $0.9$ 取 $0$。边缘地看，$X,Y$ 因共享 $Z$ 而正相关，$I(X;Y)>0$（直觉：$Z$ 相同时 $X,Y$ 倾向于相等）；但给定 $Z$ 之后，$X$ 与 $Y$ 只剩各自独立的噪声，故 $H(X\mid Y,Z)=H(X\mid Z)$，于是

$$I(X;Y\mid Z) = H(X\mid Z) - H(X\mid Y,Z) = 0 < I(X;Y)$$

**$0 = I(X;Y\mid Z) < I(X;Y)$**：条件化拆穿了「虚假的关联」。<span class="marginnote"><strong>两条例子的因果结构：</strong>例一是 $Z$ 在「下游」（$Z$ 是 $X,Y$ 的共同结果），条件化<strong>增加</strong>互信息；例二是 $Z$ 在「上游」（$Z$ 是共同原因），条件化<strong>减少</strong>互信息。先分清因果方向，再判断条件化的效果——这个习惯在信息论与因果推断里通用。</span>

## 5 公式解析：链式法则的证明

互信息的链式法则看似新东西，其实只是**熵的链式法则换了件外套**。四步走完。

- **第一步，把互信息写成熵的差**：对全体变量，$I(X_1,\dots,X_n;Y) = H(X_1,\dots,X_n) - H(X_1,\dots,X_n\mid Y)$。这一式就是把「减熵形式」推广到 $n$ 个变量。

- **第二步，两边各用熵的链式法则展开**：联合熵拆成 $\sum_i H(X_i \mid X_{<i})$，条件联合熵拆成 $\sum_i H(X_i \mid X_{<i}, Y)$。于是

$$I(X_1,\dots,X_n;Y) = \sum_{i=1}^{n} H(X_i \mid X_{<i}) - \sum_{i=1}^{n} H(X_i \mid X_{<i}, Y)$$

- **第三步，把两项配成对**：每个 $i$ 都贡献 $H(X_i\mid X_{<i}) - H(X_i\mid X_{<i},Y)$，而这正是 $I(X_i; Y \mid X_{<i})$ 的定义（把「条件互信息定义」里的 $Z$ 换成 $X_{<i}$）：

$$= \sum_{i=1}^{n} \Big[H(X_i \mid X_{<i}) - H(X_i \mid X_{<i},Y)\Big] = \sum_{i=1}^{n} I(X_i; Y \mid X_{<i})$$

- **第四步，读出本质**：整条证明只复用了熵的链式法则与互信息的定义，**没有引入任何新的假设**。这就是「链式法则同构」的含义：熵拆得了，互信息就拆得了。

顺带收获一个常用的三变量恒等式 $I(X;Y;Z) := I(X;Y) - I(X;Y\mid Z)$——它定义了三元互信息（可正可负），下一篇《Venn 图关系》将专门处理它。

这也顺便说明：链式法则不仅告诉我们「怎么拆」，还告诉我们「拆完每项长什么样」——每一项都是一个条件互信息，而条件互信息自身又可以用 $H$ 差或相对熵形式再展开。**链式法则是一套可递归的工具，不是一条孤立的等式。**

## 6 辨析：条件互信息的三个易错点

**辨析｜易错点一：$I(X;Y\mid Z)$ 与 $I(X;Y)$ 谁大谁小？** 没有定论——这正是第 3 节的核心。**判别记忆法：** 条件熵有「$H(X\mid Z)\le H(X)$」的硬定理（条件作用使熵减小），但互信息没有对应的「条件作用使互信息减小」——条件化改变的是「共享」而非「剩余」，方向取决于因果结构。

**辨析｜易错点二：链式法则的求和顺序能任意换吗？** 不能。$I(X_i;Y\mid X_{<i})$ 里的 $X_{<i}$ 是**已经排序**的前缀。换一个变量顺序，每一项的「背景」就不同，和也不同。这与熵的链式法则一致：**顺序是链式法则的一部分**。

**辨析｜易错点三：$I(X;Y\mid Z)=0$ 的含义。** 它说的是「给定 $Z$ 后 $X$ 与 $Y$ 条件独立」，即 $p(x,y\mid z)=p(x\mid z)p(y\mid z)$。**它不意味着 $X$、$Y$ 本身独立，也不意味着 $Z$ 无用**——在贝叶斯网络里，这恰恰是「$Z$ 把 $X$、$Y$ 之间的通道切断」的精确表述。<span class="marginnote">条件独立是统计学里最容易被误读的概念之一：$I(X;Y\mid Z)=0$ 与 $I(X;Y)=0$ 是<strong>完全不同的两回事</strong>。前者描述「给定 $Z$ 后的关系」，后者描述「不考虑 $Z$ 时的关系」——辛普森悖论的全部张力就藏在这两个等号之间。</span>

## 7 小结

- **定义**：$I(X;Y\mid Z)=H(X\mid Z)-H(X\mid Y,Z)$，度量「在 $Z$ 已知的前提下 $Y$ 替 $X$ 消掉的信息」。
- **等价表达**：条件互信息 = $\sum_z p(z)\,D(p(x,y\mid z)\|p(x\mid z)p(y\mid z))$，逐层比较分布再加权平均。
- **链式法则**：$I(X_1,\dots,X_n;Y)=\sum_i I(X_i;Y\mid X_{<i})$，与熵的链式法则同构，证明只复用后者与定义。
- **条件化可增可减**：蒙提霍尔与异或说明可增，共同原因说明可减；方向由因果结构决定。
- **条件独立**：$I(X;Y\mid Z)=0$ ⇔ 给定 $Z$ 后 $X,Y$ 条件独立，与无条件独立完全是两回事。
