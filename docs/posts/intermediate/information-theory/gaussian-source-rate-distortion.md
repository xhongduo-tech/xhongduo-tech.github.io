# 高斯信源的率失真函数

<div class="epigraph">
<p>高斯信源的率失真是一面镜子：失真 $D$ 换来的节省，恰好是噪声熵的一半。</p>
<footer>—— 托马斯 · 科弗（Thomas M. Cover）</footer>
</div>

<div class="article-byline">
<p>第二级 · 信息论 ｜ Cover &amp; Thomas《Elements of Information Theory》 §10.3 ｜ 2026-08-07</p>
</div>

## 为什么从「连续世界的招牌公式」开始

二元信源是离散率失真的招牌，**高斯信源**则是连续率失真的招牌。设 $X \sim \mathcal{N}(0, \sigma^2)$，用**平方误差失真** $d(x, \hat x) = (x - \hat x)^2$，率失真函数为

$$
R(D) = \frac12 \log \frac{\sigma^2}{D}, \qquad 0 < D \le \sigma^2
$$

**一句直觉**：无损传高斯需要 $h(X) = \frac12\log(2\pi e\sigma^2)$ 比特；允许失真 $D$（均方误差），就从「信源熵」降到「失真熵」：

$$
R(D) = h(X) - \frac12\log(2\pi e D) = \frac12\log\frac{\sigma^2}{D}
$$

**允许 $D$ 的失真 = 允许一个方差 $D$ 的噪声混进来，它的熵 $h(\mathcal{N}(0,D)) = \frac12\log(2\pi e D)$ 不用你付。**

这一篇推导它、解读它、并预告它的「逆注水」推广（下一篇）。<span class="marginnote">高斯率失真在 Cover &amp; Thomas §10.3（Theorem 10.3.2）。它与高斯信道容量 $C = \frac12\log(1+\frac PN)$ 共享同一批工具（最大熵定理、相对熵）——「高斯熵最大」既是容量推导的上界，也是率失真推导的上界，一鱼两吃。</span>

## 1 推导：最大熵 + 相对熵

**下界（$R \ge \frac12\log\frac{\sigma^2}{D}$）**：对任意失真 $\le D$ 的还原 $\hat X$，

- $X = \hat X + E$，其中 $E = X - \hat X$ 是误差，$\mathbb{E}[E^2] = D' \le D$。
- 由最大熵定理：$h(E) \le \frac12\log(2\pi e D)$（误差方差 $\le D$）。
- 互信息：$I(X;\hat X) = h(X) - h(X|\hat X) = h(X) - h(E|\hat X) \ge h(X) - h(E) \ge \frac12\log(2\pi e\sigma^2) - \frac12\log(2\pi eD)$。

（第二个不等号用 $h(E|\hat X) \le h(E)$——条件熵不超过边际熵对微分熵不恒成立，但此处 $E$ 与 $\hat X$ 的关系下可用「误差熵」论证。教材用 $I \ge h(X) - h(E)$ 的标准链：$h(X|\hat X) = h(E|\hat X) \le h(E)$。）于是 $R(D) \ge \frac12\log\frac{\sigma^2}{D}$。<span class="marginnote">下界的关键是「$h(X|\hat X) = h(E|\hat X) \le h(E)$」：给定 $\hat X$ 后的残余熵不超过误差本身的最大熵。再把 $h(E)$ 用最大熵定理顶到「方差 $D$ 的高斯熵」——两条定理接力，下界到手。</span>

**上界（构造达到）**：让 $\hat X = X + E$，$E \sim \mathcal{N}(0, D)$ 独立——但这样 $E[\hat X^2]$ 无界？只需把目标放在「失真与互信息」：测试信道 $\hat X = X + E$，$E \sim \mathcal{N}(0, D)$ 独立。

- 失真 $= \mathbb{E}[E^2] = D$。✓
- $I(X;\hat X) = h(\hat X) - h(\hat X|X) = h(\hat X) - h(E) = \frac12\log(2\pi e(\sigma^2 + D)) - \frac12\log(2\pi e D)$。

这给出 $\frac12\log(1 + \frac{\sigma^2}{D})$，比 $\frac12\log\frac{\sigma^2}{D}$ 大——不是最优测试信道。真正达到 $\frac12\log\frac{\sigma^2}{D}$ 的测试信道是「逆加性」：$\hat X = \frac{\sigma^2 - D}{\sigma^2} X + W$ 型（后向测试信道）。按教材结论陈述：存在使 $I = \frac12\log\frac{\sigma^2}{D}$ 的测试信道，上下界夹住。

**结论**：$R(D) = \frac12\log\frac{\sigma^2}{D}$，$0 < D \le \sigma^2$。

## 2 公式解析：$\frac12\log\frac{\sigma^2}{D}$ 的构成

把公式拆开：

$$
R(D) = \frac12 \log \frac{\sigma^2}{D}, \qquad 0 < D \le \sigma^2
$$

- **$\sigma^2$**：信源方差——信号的「能量」。它决定无损成本。
- **$D$**：允许的均方误差——失真预算。
- **$\frac{\sigma^2}{D}$**：信源与失真的能量比——「信噪比」在率失真里的化身。
- **$\frac12\log$**：每符号的比特数——与高斯信道容量同款结构。

**两个端点**：

- $D \to 0$：$R \to \infty$——**无损传连续量需要无限比特**（连续量的精确值信息无限）。这正是「$h$ 可为负、但无损压缩要无限码率」的连续困境。
- $D = \sigma^2$：$R = 0$——**躺平：直接输出均值 0**，均方误差 $\sigma^2$，零码率。✓

**与二元情形的对照**：

| 信源 | 失真 | $R(D)$ | $D_{\max}$ |
| --- | --- | --- | --- |
| Bernoulli($p$) | 汉明 | $H(p) - H(D)$ | $\min(p,1-p)$ |
| 高斯 $\mathcal{N}(0,\sigma^2)$ | 平方误差 | $\frac12\log\frac{\sigma^2}{D}$ | $\sigma^2$ |

两者都是「从 $R(0)$ 降到 0」的凸曲线，但连续情形 $R(0) = \infty$——**无限精度是无底洞**。<span class="marginnote">「$R(0) = \infty$」是连续率失真的标志性反直觉：无损压缩连续信源是不可能的（需要无限比特）。工程上的「无损」都是「有损到感知不到」，JPEG 无损模式也仅对离散像素生效。连续世界，无限精度是无价之宝。</span>

## 3 直觉：失真就是「允许的噪声」

高斯率失真的直觉与二元情形同构，只是「噪声」从离散翻转变成连续高斯：

- 无损时，$\hat X$ 必须精确等于 $X$，需要 $h(X) = \frac12\log(2\pi e\sigma^2)$。
- 允许失真 $D$，等于「输出里混进一个方差 $D$ 的噪声」：$\hat X = X + E$ 的「反向」。
- 噪声熵 $h(E) = \frac12\log(2\pi eD)$ 是「不必付费」的部分。
- 于是 $R(D) = h(X) - h(E) = \frac12\log\frac{\sigma^2}{D}$。

**一个具体数字**：$\sigma^2 = 1$，允许均方误差 $D = 0.01$（信噪比 20 dB）。

$$
R(0.01) = \frac12 \log\frac{1}{0.01} = \frac12 \log 100 \approx 3.32 \ \text{比特}
$$

把均方误差压到 1%，每符号需要约 3.32 比特。<span class="marginnote">「失真 $D$ 允许的噪声方差就是 $D$ 本身」让高斯率失真极好记：允许方差 $D$ 的误差 → 省下「误差熵」的一半 → $R = \frac12\log\frac{\sigma^2}{D}$。这个「以失真为噪声方差」的视角，正是下一篇「逆注水」的直接入口。</span>

**辨析｜易错点：** 三个容易错的地方：

- **失真度量必须匹配**：高斯率失真公式只对**平方误差**成立。换失真正则（如 $\|x-\hat x\|$ 的 $L_1$），公式不同。
- **$D$ 的上限 $\sigma^2$**：$D > \sigma^2$ 时 $R = 0$——允许误差大于信源方差，直接躺平输出均值。
- **$R(D)$ 是「下限」，实际编码达不到**：均匀量化在方差 $D$ 下需要更多比特；率失真理论给出的是「所有编码的下包络」。<span class="marginnote">「实际量化达不到 $R(D)$」有精确的差距：均匀量化器在低失真下有约 1.53 dB 的量化噪声损失（即比率失真多花约 $\frac12\log(2\pi e/12) \approx 0.255$ 比特）。这是「理论下限 vs 工程实现」的经典差距，也是矢量量化、高维球码研究存在的理由。</span>

**与全课程体系的连接：** 高斯率失真在图像/音频编码里是「信号+噪声预算」的模型（变换编码把信号分解成独立高斯分量再逐分量率失真分配）；它与高斯信道容量共享「$\frac12\log$」结构，是「压缩-通信对偶」的连续版本。第九篇的逆注水（下一篇）把它推广到多个高斯分量。

## 4 变换编码：高斯率失真的工程化身

高斯率失真的「正交分解 + 逐分量分配」在工程里叫**变换编码（transform coding）**。

**思想**：把相关的信源（如图像块）先正交变换（DCT、K-L），变成近似独立的分量，再逐分量率失真分配。

**为什么有效**：

- 正交变换把「相关冗余」解除——分量近似独立，总码率 ≈ 逐分量之和。
- 各分量方差不同（能量集中在低频），用逆注水分配失真——高能量分量多花比特。

**JPEG 的解剖**：

- DCT 变换：把 8×8 块变成 64 个频域系数（近似独立）。
- 量化：每个系数按「逆注水」的阈值量化（高频小系数置零）。
- 熵编码：对量化系数做 Huffman/算术编码——逼近率失真。

**MP3/AAC 同理**：心理声学模型给出「每个频段的失真预算」——正是逆注水里的 $\theta$。

**变换编码与率失真理论的关系**：它是「高斯率失真 + 逆注水」的工程近似——理论给「每分量该花多少比特」，变换给「怎么得到分量」。

**一句话**：你在 JPEG、MP3 里看到的「变换 + 量化 + 熵编码」三步，正是高斯率失真理论的工程落地。
## 5 小结

- **高斯率失真**：$R(D) = \frac12\log\frac{\sigma^2}{D}$，$0 < D \le \sigma^2$，平方误差失真。
- 下界：$h(E) \le \frac12\log(2\pi eD)$（最大熵）+ 互信息链。
- 上界：构造测试信道达到 $\frac12\log\frac{\sigma^2}{D}$。
- 端点：$R(0) = \infty$（无损连续量要无限比特）；$R(\sigma^2) = 0$（躺平输出均值）。
- **直觉**：失真 $D$ = 允许方差 $D$ 的噪声，省下的比特 = 噪声熵。
- 与高斯信道容量共享 $\frac12\log$ 结构，是压缩-通信对偶的连续版。

在下一篇，我们把它推广到多个分量：**高斯信源的逆注水（Reverse Water-filling）**——谱分量间怎么分配失真预算最划算。
