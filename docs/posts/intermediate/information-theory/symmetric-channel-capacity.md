# 对称信道及其容量的简化计算

<div class="epigraph">
<p>对称是把复杂变简单的旧魔法：当每个输入都一视同仁，最优的用法就是公平地对待它们。</p>
<footer>—— 克劳德 · 香农（Claude E. Shannon）</footer>
</div>

<div class="article-byline">

## 为什么从「一视同仁的噪声」开始

BSC 与 BEC 的容量都算得很轻松，靠的是它们的**对称性**：每个输入面对的是同一种噪声。如果把这个性质抽象出来，就能得到一整类「好算容量」的信道。

**对称信道（symmetric channel）**：信道矩阵的**每一行**都是同一组概率的排列，**每一列**也是同一组概率的排列。

BSC、无噪信道都是对称信道的特例。对这类信道（以及更宽的「弱对称」类），容量有一个通用公式：

$$
C = \log|\mathcal{Y}| - H(\text{任意一行})
$$

最优输入就是**均匀分布**。这一篇我们定义对称信道、推导这个公式、并划清它与 BEC 的边界——BEC 恰好**不**属于这一类，这正是它值得单独推导的原因。<span class="marginnote">Cover &amp; Thomas §7.2 把「对称」形式化，并给出定理 7.2.1：弱对称信道的容量 $= \log|\mathcal{Y}| - H(\text{行})$，均匀输入最优。BSC 是它的明星例子，而 BEC 因为列结构不整齐，游离在这条定理之外。</span>

## 1 定义：行对称与列对称

**对称信道**：设转移矩阵 $p(y|x)$（行 = 输入 $x$，列 = 输出 $y$）。若满足：

1. **行对称**：每一行都是同一组概率 $\{p_1, \dots, p_{|\mathcal{Y}|}\}$ 的排列；
2. **列对称**：每一列也都是同一组概率的排列。

则称该信道为对称信道。

**弱对称信道（weakly symmetric channel）**：放宽列条件——只要求每一行是同一组概率的排列，且**每一列之和相等**（不要求各列是同一组概率的排列）。

两个定义都保证两件关键的事：

**行性质 ⇒ 噪声熵恒定**：$H(Y \mid X = x)$ 对每个 $x$ 都等于同一行的熵 $H(\mathbf{p})$，所以 $H(Y|X) = H(\mathbf{p})$ 与输入分布无关。
**列性质 ⇒ 均匀输出可达**：输入均匀时，$p(y) = \frac{1}{|\mathcal{X}|} \times (\text{第 } y \text{ 列之和})$。弱对称要求列和相等，于是输出 $Y$ 均匀。<span class="marginnote">行性质与列性质分工明确：前者让「最大化 $I$」只剩 $H(Y)$ 一个变量，后者保证「均匀输入就能顶满 $H(Y)$」。两个性质凑齐，容量就从「凸优化」塌缩成「一次减法」。</span>

## 2 公式解析：$C = \log|\mathcal{Y}| - H(\mathbf{p})$

**定理（弱对称信道的容量）**：

$$
C = \log|\mathcal{Y}| - H(\mathbf{p}), \qquad \text{最优输入为均匀分布}
$$

推导四步：

- **第一步**：$I(X;Y) = H(Y) - H(Y|X) = H(Y) - H(\mathbf{p})$。行对称让 $H(Y|X)$ 与输入无关，从最大化里提出去。
- **第二步**：$H(Y) \le \log|\mathcal{Y}|$，等号当且仅当输出均匀（输出熵上界）。
- **第三步**：弱对称的列性质保证均匀输入 ⇒ 输出均匀，于是取均匀输入即可达到 $H(Y) = \log|\mathcal{Y}|$。
- **第四步**：代入得 $C = \log|\mathcal{Y}| - H(\mathbf{p})$。

**验算 BSC**：$|\mathcal{Y}| = 2$，行熵 $H(1-p, p) = H(p)$，$C = 1 - H(p)$。✓

**验算无噪信道**：行是单位向量，$H(\mathbf{p}) = 0$，$C = \log|\mathcal{Y}|$。✓<span class="marginnote">公式的直觉：容量 = 「输出最多能装多少熵」减去「噪声每行固有的熵」。噪声熵 $H(\mathbf{p})$ 是每用信道的「固定税」，与你怎么用无关；输出熵能顶到 $\log|\mathcal{Y}|$；差额就是净容量。</span>

## 3 边界：BEC 不在其中

**关键判别**：BEC 的转移矩阵是

$$
\begin{pmatrix} 1-\alpha & 0 & \alpha \\ 0 & 1-\alpha & \alpha \end{pmatrix}
$$

- **行对称** ✓：每行都是 $\{1-\alpha, 0, \alpha\}$ 的排列。
- **列之和**：第 0 列 $= 1-\alpha$，第 1 列 $= 1-\alpha$，第 $e$ 列 $= 2\alpha$——**不相等**。
- 因此 BEC **既不列对称，也不弱对称**，**不能**套用 $C = \log 3 - H(\alpha)$。

BEC 的容量 $1 - \alpha$ 要用「$p(e) = \alpha$ 恒定」这个特殊结构单独推导（上一篇已完成）。它恰好也以均匀输入最优，但理由不同：不是「列和相等」，而是「删除概率被信道锁死，未删除部分可调成均匀」。<span class="marginnote">「$e$ 列之和是 $2\alpha$」这个细节是 BEC 与对称信道家族的真正分界线。$e$ 列是「两个输入都会掉进去」的坑，它的列和翻倍——这让均匀输入下的输出虽仍均匀（$0,1$ 各 $\frac{1-\alpha}{2}$，$e$ 为 $\alpha$），但 $H(Y) < \log 3$。</span>

**辨析｜易错点：** 三个陷阱要避开：

**陷阱一**：把 BEC 当对称信道，套 $C = \log 3 - H(\alpha)$。错——BEC 不弱对称，容量是 $1 - \alpha$。
**陷阱二**：以为「行对称就够用公式」。不够，列条件（列和为常）是「输出可达均匀」的必要保证。
**陷阱三**：以为均匀输入总是最优。一般信道（如 Z 信道）的最优输入并不均匀——「均匀最优」是行/列对称的**结论**，不是普遍事实。<span class="marginnote">Z 信道 $\begin{pmatrix} 1 & 0 \\ p & 1-p \end{pmatrix}$ 是「非对称噪声」的最小例子：行不对称，$H(Y|X)$ 随输入变，容量问题需要 KKT 条件或数值方法。它提醒我们，对称是「可免费计算」的充分条件，不是必要条件。</span>

## 4 对称信道的实践意义

「对称 → 容量好算」这个事实，在实践里有两层价值：

**设计的起点**：许多真实信道被刻意设计成「近似对称」——均衡、交织、星座图设计都在往对称上靠。对称化之后，容量立刻有了闭式答案。
**理论探针**：容量公式给「码率能否可行」一个即时判据，让编码设计（如 LDPC 的密度演进）可以逐信道验证。BSC 与 BEC 之所以成为编码理论的基准，正因为它们落在「好算容量」这一侧。<span class="marginnote">对称性的另一面是「对称信道的最优输入是均匀的」——这在系统层面意味着「等概率符号 + 对称噪声」是最标准的配置。现代通信里的比特交织、加扰（scrambling）本质上都在把信道「对称化」，好让容量公式与最优编码成立。</span>

**与全课程体系的连接：** 对称信道在《信息与通信工程》里对应「均衡信道」的理想化；在第三级《计算机网络》里对应「对称链路」假设。它也是理解「为什么 BSC/BEC 是教科书首选」的钥匙——**好算的模型，才适合做理论的温床**。

## 5 对称信道的更多例子

除了 BSC，对称信道的例子还有一批，能加深对「对称」的理解。

**例 1：四元对称信道**。$\mathcal{X} = \mathcal{Y} = \{0,1,2,3\}$，每个符号以概率 $1-p$ 保持、$p/3$ 翻到其他三个。

- 每行是同一组概率的排列（对称）。
- 每列同理（对称）。
- 容量 $= \log 4 - H(1-p, p/3, p/3, p/3)$。

**例 2：无噪信道**。每行是「单位向量」的排列——$H(\text{行}) = 0$，容量 $= \log|\mathcal{Y}|$。

**例 3：均匀出错信道**。输出在「错误集合」里均匀分布——列和相等，弱对称。

**「强对称 vs 弱对称」的判别**：

- 强对称：行、列都是同一排列。
- 弱对称：行同排列 + 列和相等。
- 判别技巧：看转移矩阵——行对称一眼看出；列对称要算列和。

**对称性的工程来源**：星座图设计（QAM）、交织、加扰都在「把信道对称化」——对称信道好算容量、好设计编码。

**一句话**：对称信道是一个「家族」——BSC、无噪、四元对称都是成员；「行同排列 + 列和相等」是家族的两把钥匙。
## 6 小结

- **对称信道**：行对称（每行同排列）+ 列对称（每列同排列）；**弱对称**放宽为「列和相等」。
- **容量公式**：$C = \log|\mathcal{Y}| - H(\mathbf{p})$，均匀输入最优（定理 7.2.1）。
- 推导：行对称 ⇒ 噪声熵恒定；列性质 ⇒ 均匀输出可达；$H(Y) \le \log|\mathcal{Y}|$。
- **BEC 的边界**：行对称但列和不齐，不弱对称，容量 $1-\alpha$ 需单独推导。
- **辨析**：BEC 不能套公式；行对称不够；均匀最优是结论不是前提。
- 对称性让容量好算，是编码理论以 BSC/BEC 为基准的深层原因。
