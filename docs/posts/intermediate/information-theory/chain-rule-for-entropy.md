## 为什么从链式法则开始

前两节我们分别认识了熵、联合熵与条件熵。现在把三块拼图合在一起：它们之间有一条恒等式，把「联合熵」拆成「一串条件熵」，这就是**熵的链式法则（chain rule for entropy）**。

它看上去只是把条件概率的定义代进去，但分量极重。**任何联合分布都能按链式法则分解成一组条件分布**，而自回归语言模型正是这样做的：它不直接估计「整句话的概率」，而是逐个 token 估计「给定前文的条件下这个 token 的概率」，再把它们相乘。换句话说，链式法则就是大模型得以工作的概率论依据——也是交叉熵损失能被拆成「每个位置单独算再求和」的原因。<span class="marginnote">链式法则在第三级《深度学习》里对应「teacher forcing」与自回归解码的数学基础；在本专题里，它更是推导<strong>互信息的链式法则</strong>与<strong>相对熵的链式法则</strong>的模板。先把它吃透，后面所有「链式」都举重若轻。</span>

## 1 两个变量的链式法则

**熵的链式法则（两变量）**：对任意两个随机变量 $X$、$Y$，

$$H(X, Y) = H(X) + H(Y \mid X)$$

读作：**$X$、$Y$ 联合的不确定性 = $X$ 自身的不确定性 + 已知 $X$ 之后 $Y$ 剩余的确定性**。这个等式对任意联合分布恒成立——不要求独立，上一节例子里的 $H(X,Y)=1.5 = H(X)+H(Y\mid X)$ 已经验证过一次。

把 $X$、$Y$ 对调，得到同样合法但一般不同的分解：

$$H(X, Y) = H(Y) + H(X \mid Y)$$

两条路都是对的，通向同一个 $H(X,Y)$；只是中间项不同——这正是条件熵不对称（$H(Y\mid X) \ne H(X\mid Y)$）的另一种表现。

## 2 多个变量的链式法则

两变量的规则可以直接推广到 $n$ 个变量。对任意 $X_1, \dots, X_n$：

$$H(X_1, X_2, \dots, X_n) = H(X_1) + H(X_2 \mid X_1) + H(X_3 \mid X_1, X_2) + \cdots + H(X_n \mid X_1, \dots, X_{n-1})$$

简记为

$$H(X_1, \dots, X_n) = \sum_{i=1}^{n} H(X_i \mid X_1, \dots, X_{i-1})$$

**逐步看：先单独承担 $X_1$ 的不确定性；已知 $X_1$ 后看 $X_2$ 还剩多少；已知前两个再看 $X_3$ 剩多少……一直到最后一项。** 把每一步的「剩余不确定性」加起来，恰好是整体熵。可以类比付账：每个变量只负责「前人没解释掉的那部分」。

一个重要推论是**单调性**：因为每个条件熵都非负，所以

$$H(X_1, \dots, X_n) \ge H(X_1, \dots, X_{n-1})$$

**知道的变量越多，联合熵只增不减**——新引入一个随机变量，只会给系统增加或保留不确定性，绝不会减少。<span class="marginnote">这与条件熵 H(X_n \mid X_1..X_{n-1}) \le H(X_n) 并不矛盾：单个变量的剩余不确定性在给定条件下<strong>变小</strong>，但系统里<strong>多了一个变量</strong>，整体不确定性仍会上升。一个看「新增的余量」，一个看「总量」，别弄混。</span>

## 3 条件链式法则

链式法则还能在「已经知道某个 $Z$」的前提下进行。**条件链式法则**：

$$H(X, Y \mid Z) = H(X \mid Z) + H(Y \mid X, Z)$$

一般形式：

$$H(X_1, \dots, X_n \mid Z) = \sum_{i=1}^{n} H(X_i \mid X_1, \dots, X_{i-1}, Z)$$

直觉：把普通链式法则的每一项都「条件在 $Z$ 上」。$Z$ 相当于一个对所有变量都已知的背景——它的信息量被预先扣除，剩下的仍然可以逐项分解。这在处理「以某个公共条件为背景」的问题（如给定信道输入看输出、给定上下文看 token）时是标准工具。

## 4 公式解析：链式法则为什么恒成立

链式法则的证明几乎是「一步到位」，但把它拆细能看清每一步消掉什么。以两变量为例，四步。

- **第一步，从定义出发**：

$$H(X,Y) = -\sum_{x}\sum_{y} p(x,y)\log_2 p(x,y)$$

- **第二步，用条件概率的乘积公式替换联合概率**：$p(x,y) = p(x)\,p(y\mid x)$，对数把乘积拆成和：

$$H(X,Y) = -\sum_{x}\sum_{y} p(x,y)\Big(\log_2 p(x) + \log_2 p(y \mid x)\Big)$$

- **第三步，分别对两项求和**：第一项先对 $y$ 求和，$\sum_y p(x,y) = p(x)$，得 $-\sum_x p(x)\log_2 p(x) = H(X)$；第二项不动，恰是条件熵的另一种写法 $-\sum_x\sum_y p(x,y)\log_2 p(y\mid x) = H(Y\mid X)$。于是

$$H(X,Y) = H(X) + H(Y \mid X)$$

- **第四步，读出本质**：整个证明只用了 $p(x,y) = p(x)p(y\mid x)$——**没有用任何独立性假设**。这就是「恒成立」的根源：条件概率的乘积公式对任意联合分布都对，链式法则自然也就对任意分布都对。

$n$ 个变量的情形完全同构：把 $p(x_1,\dots,x_n) = \prod_i p(x_i \mid x_1,\dots,x_{i-1})$ 代入定义，对数把连乘拆成连加，逐项对照即得。<span class="marginnote">这个「乘积 ⇄ 求和」的对应是信息论的主旋律：概率论里相乘的东西，在熵的世界里相加。可加性（上一节）是它在独立时的特例，链式法则是它的完整形态。</span>

## 5 链式法则与大模型：自回归分解

把链式法则的威力放到最大，是把它用于**序列数据**。设 $X_1, \dots, X_n$ 是一句话的 $n$ 个 token，则

$$H(X_1, \dots, X_n) = \sum_{i=1}^{n} H(X_i \mid X_1, \dots, X_{i-1})$$

右边每一项 $H(X_i \mid X_1, \dots, X_{i-1})$ 正是「给定前文，下一个 token 平均还剩多少比特」——也就是语言模型在每个位置上的理想交叉熵损失。于是三个深层结论浮出水面：

- **联合分布的概率可以「逐位置」估计**：$p(x_1,\dots,x_n) = \prod_i p(x_i \mid x_{\\lt i})$。大模型不预测整句，只预测下一个 token，靠这个恒等式拼出整句的概率。
- **总熵等于各位置条件熵之和**：训练时把每个位置单独算交叉熵再求和，正是对 $H(X_1,\dots,X_n)$ 的估计——链式法则保证了「局部之和 = 全局」。
- **每个 token 的不确定性是「剩余的」**：$H(X_i \mid X_{\\lt i})$ 一般随 $i$ 增大而减小——前文越多，预测越容易，这与长上下文的低困惑度观察一致。

这条视角也解释了为什么困惑度（perplexity）是 $2^{\text{平均条件熵}}$：它在问「平均而言，模型要在多少个 token 里猜下一个」。链式法则把这个「平均」定义得明明白白。<span class="marginnote">语言模型领域的「上下文越长、困惑度越低」并非模型魔法，而是<strong>条件作用使熵减小</strong>的宏观表现——给定更多前文，剩余不确定性整体下降。这条性质我们将在《条件作用使熵减小》中严格证明。</span>

## 6 辨析：链式法则、可加性与互信息

三个相关恒等式，是初学者最常搅在一起的：

$$H(X,Y) = H(X) + H(Y) \quad \text{（仅 $X \perp Y$）}$$
$$H(X,Y) = H(X) + H(Y\mid X) \quad \text{（恒成立）}$$
$$H(X,Y) = H(X) + H(Y) - I(X;Y) \quad \text{（互信息修正）}$$

**辨析｜易错点：** 可加性要求独立，链式法则恒成立，互信息版本则是把「重复计算的那部分」显式扣掉。三者放在一起看，就得到互信息的另一个定义 $I(X;Y) = H(X) + H(Y) - H(X,Y)$——它是「两个熵之和减去联合熵」，即上节说的那个「差距」。三条式子其实说的是同一件事的三个侧面。

还有一个常见误解值得单独点出：**链式法则不等于「$H(Y\mid X) = H(Y) - H(X)$」**。条件熵是「减法」，但只能在互信息的语境里做：$H(Y\mid X) = H(Y) - I(X;Y)$，因为 $I \ge 0$ 才保证 $H(Y\mid X) \le H(Y)$。直接从链式法则里想当然地「移项相减」，会得到没有意义的等式。

## 7 小结

- **链式法则（两变量）**：$H(X,Y) = H(X) + H(Y\mid X)$，对任意联合分布恒成立。
- **链式法则（$n$ 变量）**：$H(X_1,\dots,X_n) = \sum_{i=1}^n H(X_i \mid X_1,\dots,X_{i-1})$；每个变量只承担「前人未解释的剩余」。
- **条件链式法则**：$H(X_1,\dots,X_n\mid Z) = \sum_i H(X_i \mid X_{\\lt i}, Z)$，即每一项都条件在背景 $Z$ 上。
- **证明核心**：只用了 $p(x,y)=p(x)p(y\mid x)$，没有独立性假设，故恒成立。
- **与大模型**：自回归分解 $p(x_1,\dots,x_n)=\prod_i p(x_i\mid x_{\\lt i})$ 与逐位置交叉熵之和，都是链式法则的直接应用。
- **与可加性、互信息**：可加性是独立特例；互信息版本显式扣除重复计数。

在下一节，我们将进入信息论最核心的度量之一：**相对熵（KL 散度）**——它度量两个分布之间的「距离」，是交叉熵损失的真正本质。
