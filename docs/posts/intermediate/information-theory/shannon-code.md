# 香农码（Shannon Code）及其构造

## 为什么从「第一个能用的码」开始

上一节的结论很漂亮：最优码长 ≈ $\log\frac{1}{p}$，整数化后平均码长在 $[H, H+1)$ 之间。

但「存在一个前缀码达到这个长度」还没有真正动手构造——这一篇补上这个构造，它就是**香农码（Shannon code）**。

香农码的价值不在「最优」——它通常不是最优的（Huffman 才是）——而在**它是第一个明确写出的、可证明平均码长 $< H + 1$ 的构造**。它把「理论上存在」变成「手上真有」，并为算术编码铺好了路：给概率排序、按累积分布切区间、取区间的前缀比特。

这一篇我们走完构造三步、证明前缀性、算平均码长，并厘清它与 Shannon-Fano、Huffman 的血缘关系。<span class="marginnote">香农码的构造第一次把「编码」从「猜」变成「算」：你不需要设计树，只需要按概率排序、算累积和、取二进制小数前几位。这个「区间切分」的视角，正是算术编码（把整个序列编成一个区间）的雏形。</span>

## 1 构造算法：三步走

**输入**：信源符号 $x_1, \dots, x_M$，概率 $p_1, \dots, p_M$。

**第一步，按概率排序**：设 $p_1 \ge p_2 \ge \cdots \ge p_M$（从大概率到小概率排列）。

**第二步，算码长与累积分布**：对每个 $i$，

$$
l_i = \left\lceil \log \frac{1}{p_i} \right\rceil, \qquad F_i = \sum_{j=1}^{i-1} p_j
$$

$F_i$ 是 $x_i$ 之前的累积概率（$F_1 = 0$）。

**第三步，取二进制前缀**：把 $F_i$ 写成二进制小数，取其**前 $l_i$ 位**作为 $x_i$ 的码字。<span class="marginnote">第三步的几何意义：把 $[0,1)$ 区间按概率切成 $M$ 段，第 $i$ 段是 $[F_i, F_i + p_i)$；每段的长度 $p_i \ge 2^{-l_i}$，所以段内必有一个「前 $l_i$ 位二进制」的锚点可取。码字就是「段内最靠左的那个 $l_i$ 位小数」。</span>

## 2 示例：一个小信源

设信源有 4 个符号，概率 $p = (\tfrac12, \tfrac14, \tfrac18, \tfrac18)$。

| 符号 | $p_i$ | $l_i = \lceil\log\frac{1}{p_i}\rceil$ | $F_i$ | 二进制小数 | 码字 |
| --- | --- | --- | --- | --- | --- |
| $x_1$ | 1/2 | 1 | 0 | 0.0 | `0` |
| $x_2$ | 1/4 | 2 | 0.5 | 0.10 | `10` |
| $x_3$ | 1/8 | 3 | 0.75 | 0.110 | `110` |
| $x_4$ | 1/8 | 3 | 0.875 | 0.111 | `111` |

得到码字 `0, 10, 110, 111`——恰好是上节的完备码示例，平均长度 $\bar L = 1\cdot\frac12 + 2\cdot\frac14 + 3\cdot\frac18 + 3\cdot\frac18 = 1.75 = H$。这个信源概率都是 2 的负幂，香农码无损失地达到了熵。

再看一个非对齐的例子：$p = (0.4, 0.3, 0.2, 0.1)$。

- $l = (2, 2, 3, 4)$，$F = (0, 0.4, 0.7, 0.9)$。
- 码字：0.4 的二进制 `0.0110…` 取前 2 位 → `01`；0.7 → `10`；0.9 → `111`；1.0 → `1111`。
- 平均长度 $= 0.4\cdot2 + 0.3\cdot2 + 0.2\cdot3 + 0.1\cdot4 = 2.4$，而 $H \approx 1.846$，$H + 1 = 2.846$——确实落在 $[H, H+1)$ 内。<span class="marginnote">注意这个例子里的累积概率用的是「排序后」的顺序，而非符号本来的顺序——排序保证了区间切分单调，也保证了前缀性证明的简洁。Huffman 编码同样要求先排序，两者的输入预处理是一致的。</span>

## 3 公式解析：前缀性从哪来

香农码为什么是前缀码？关键在区间「段长 ≥ 码长所能覆盖的范围」。

**核心事实**：若 $i < j$，则码字 $i$ 不是码字 $j$ 的前缀。

- 第 $i$ 段区间 $[F_i, F_i + p_i)$，$F_j \ge F_i + p_i$（排序保证 $j$ 在 $i$ 后面）。
- 第 $i$ 个码字是「$F_i$ 的前 $l_i$ 位」，它对应的二进制小区间是 $[F_i^{(l_i)}, F_i^{(l_i)} + 2^{-l_i})$，其中 $F_i^{(l_i)}$ 是截断后的值。
- 因为 $2^{-l_i} \le p_i$（由 $l_i = \lceil\log\frac{1}{p_i}\rceil$），有 $F_i^{(l_i)} + 2^{-l_i} \le F_i + p_i \le F_j \le F_j^{(l_j)}$。
- 所以第 $i$ 个码字的小区间整体落在第 $j$ 段**之前**——$j$ 的码字不可能以 $i$ 的码字开头。<span class="marginnote">把证明翻译成人话：<strong>前面的码字只占据自己那段小区间，后面符号的累积起点都在更右边，因此永远踩不到前面的前缀</strong>。区间的「左小右大」顺序，就是前缀性的几何保证。</span>

**平均码长**：由构造 $l_i \le \log\frac{1}{p_i} + 1$，期望得

$$
H(X) \le \bar L < H(X) + 1
$$

香农码**保证**落在熵与熵加 1 之间。

## 4 辨析：香农码、Shannon-Fano 与 Huffman

**辨析｜易错点：** 三个名字容易混，它们的差别要分清：

- **香农码（Shannon code）**：按累积分布切区间、取前缀比特。**保证 $\bar L < H + 1$**，但通常不是最优整数码。
- **Shannon-Fano 码**：把符号按概率对半切，左右分叉编码。直观但**不保证最优**，平均长度可能超过 $H+1$。
- **Huffman 码**：自底向上的贪心合并。**保证整数码中的最优**（平均长度最小），且 $\bar L < H + 1$。

一句话记忆：**Shannon 是「区间取位」、Shannon-Fano 是「对半切」、Huffman 是「贪心合」**；只有 Huffman 保证最优。香农码的意义在于「证明存在 + 构造简单 + 逼近熵」，而不是与 Huffman 竞争最优。<span class="marginnote">历史上 Shannon-Fano 编码（1948）比 Huffman（1952）早，且两人曾在 MIT 同事。Huffman 在研究生课程作业里发现「对半切不一定最优」，于是发明了贪心合并，一锤定音。这个故事是「理论够用 ≠ 构造最优」的经典注脚。</span>

**与全课程体系的连接：** 香农码的「区间切分」思想在算术编码里被推演到极致：不再给符号编独立码字，而是把**整条序列**编成 $[0,1)$ 里的一个区间。从这个意义上说，香农码是「符号级」的算术编码；第四级《数据结构》里的区间查找、以及 RANS（非对称数系）编码，都是同一棵树的旁枝。

## 5 香农码的局限与改进

香农码是「第一个能用的构造」，但它的局限催生了后续的改进。

**局限一：不最优**。$\lceil \log\frac1p \rceil$ 的取整损失可能累积，平均码长不是整数码中的最小值。

**局限二：单符号视角**。它对每个符号独立取整，没有「成块摊薄」——概率极端时浪费明显。

**改进路线一：Huffman**。贪心合并给出整数码的最优——比香农码更省。

**改进路线二：算术编码**。把整条序列编成一个区间——取整损失从「每符号 +1」降到「每条 +1」。

**改进路线三：分块香农**。把 $n$ 个符号捆成块再编——$1/n$ 的摊薄代价。

**香农码的历史地位**：

- 它是「区间切分」思想的首次系统化——算术编码的祖父。
- 它证明了「熵可达」的构造性——虽不最优，但「够用」。

**「够用 vs 最优」的辩证**：香农码证明「存在且可达」；Huffman 证明「可达且最优」；算术编码证明「可任意逼近」——三级台阶，一个极限。

**一句话**：香农码是「区间取位」的第一次亮相——不最优但开创了「编码 = 切区间」的范式，为 Huffman 与算术编码铺了路。
## 6 小结

- **香农码三步**：按概率排序 → 算码长 $l_i = \lceil\log\frac{1}{p_i}\rceil$ 与累积分布 $F_i$ → 取 $F_i$ 的前 $l_i$ 位为码字。
- **前缀性**：由「段长 $\ge 2^{-l_i}$」与区间的左小右大顺序保证。
- **平均长度**：$H \le \bar L < H + 1$，概率为 $2^{-k}$ 时恰好等于 $H$。
- 它是「第一个可证明逼近熵的显式构造」，也是算术编码的雏形。
- **辨析**：香农码 vs Shannon-Fano（对半切）vs Huffman（贪心合并）；只有 Huffman 保证整数码最优。
