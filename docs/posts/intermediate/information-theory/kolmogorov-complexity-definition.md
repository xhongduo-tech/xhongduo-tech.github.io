# 科尔莫戈罗夫复杂度（Kolmogorov Complexity）的定义

<div class="epigraph">
<p>一条字符串的复杂度，是写出它所需的最短程序——这个「最短」是它的固有属性，与谁在描述无关。</p>
<footer>—— 安德烈 · 科尔莫戈罗夫（Andrey N. Kolmogorov）</footer>
</div>

<div class="article-byline">
<p>第二级 · 信息论 ｜ Cover &amp; Thomas《Elements of Information Theory》 §14.2 ｜ 2026-08-07</p>
</div>

## 为什么从「单条字符串的信息量」开始

Shannon 熵回答「一个分布平均产生多少信息」，但它回答不了「这条具体的字符串有多少信息」——因为单条数据没有分布。

**科尔莫戈罗夫复杂度（Kolmogorov complexity）**补上这个缺口：一条二进制字符串 $x$ 的复杂度 $K(x)$，是**能生成 $x$ 的最短程序的长度**。

$$
K(x) = \min_{p: U(p) = x} |p|
$$

它把「信息」从「期望」变成「具体」，从「概率」变成「程序」。这一篇我们形式化这个定义、证明它最重要的**不变性定理**、并列出它的基本界。<span class="marginnote">科尔莫戈罗夫复杂度由 Kolmogorov（1965）、Solomonoff（1964）、Chaitin（1966）几乎同时提出。它之所以革命性，在于它给了「单条字符串的随机性」一个精确度量——在此之前，「随机」只能由分布定义。</span>

## 1 形式定义与不变性

**定义**：固定一台通用图灵机 $U$，$x$ 的**科尔莫戈罗夫复杂度**为

$$
K_U(x) = \min_{p: U(p) = x} |p|
$$

其中 $p$ 是二进制程序，$U(p)$ 是 $U$ 运行 $p$ 后输出的字符串。

**不变性定理（invariance theorem）**：对任意两台通用图灵机 $U_1, U_2$，存在常数 $c_{U_1,U_2}$ 使

$$
|K_{U_1}(x) - K_{U_2}(x)| \le c_{U_1, U_2}
$$

对所有 $x$ 成立。

**证明**：写一个「解释器」$E$：$U_1$ 上跑 $p$ 等价于 $U_2$ 上跑「$E$ + $p$」。于是 $K_{U_2}(x) \le |E| + K_{U_1}(x)$，反过来同理。常数 $c = |E_{12}| + |E_{21}|$。

**含义**：$K(x)$ 的精确值依赖机器，但**量级不依赖**——「$K(x)$ 与 $n$ 同阶」「$K(x) \approx K(y)$」这类渐近结论是机器无关的。<span class="marginnote">不变性定理是科尔莫戈罗夫复杂度的「营业执照」：它保证「最短描述」这个概念有意义到「差常数」的程度。代价是——我们只能谈「$K$ 的渐近」，不能谈「$K$ 的精确值」。这个「常数模糊」贯穿整个算法信息论。</span>

## 2 基本界：$K(x)$ 不会太大

**界一（平凡上界）**：任何 $x$ 都可以被「原样列出」的程序描述：

$$
K(x) \le |x| + c
$$

程序「输出接下来的 $|x|$ 个比特」的长度 ≈ $|x|$ + 常数。**没有字符串比它自身更复杂（差常数）。**

**界二（整数的复杂度）**：对整数 $n$（编码成长度 $|n|$ 的串），

$$
K(n) \le \log^* n + c
$$

其中 $\log^* n$ 是「递归对数」。更常用的是宽松版本 $K(n) \le \log_2 n + 2\log_2\log_2 n + c$——「先写长度、再写值」的描述。

**界三（不可压缩串存在）**：长度 $n$ 的串有 $2^n$ 个，而长度 $< n - k$ 的程序只有 $2^{n-k} - 1$ 个。所以**至少 $2^n - 2^{n-k} + 1$ 个串满足 $K(x) > n - k$**——绝大多数字符串几乎不可压缩（$K(x) \ge n - O(1)$）。<span class="marginnote">「绝大多数串不可压缩」是个深刻的结论：随机串不是「罕见」，而是「主流」——几乎所有的长字符串都压不动。结构化（可压缩）的字符串反而是极少数。这翻转了「世界充满规律」的直觉：在字符串空间里，规律是例外。</span>

## 3 公式解析：$K(x)$ 的三个构成部分

把定义拆开：

$$
K(x) = \min_{p: U(p) = x} |p|
$$

- **$p$（程序）**：任何能生成 $x$ 的二进制串——可以是「数据 + 算法」、「规则 + 参数」、「直接列出」。
- **$U(p) = x$**：程序在通用机上运行并输出 $x$。「生成」比「压缩」更宽：不需要「先压缩后解压」，只要程序算出 $x$ 就行。
- **$\min$**：取所有方式中的最短——$K(x)$ 是 $x$ 的「固有长度」，与你想到哪种描述无关。

**直觉**：$K(x)$ 度量「$x$ 里的信息有多少」。用三个极端感受：

- 全零串 `000...0`：$K \approx \log n$——「输出 $n$ 个 0」，短。
- 前 $n$ 个素数：$K \approx \log n$——「输出前 $n$ 个素数」，短。
- 抛硬币结果：$K \approx n$——没有程序比「列出」更短。

**程序与数据的分离**：最短描述往往 = 「小算法 + 参数」。$K(x)$ 小意味着「存在一个短算法解释 $x$」——这正是「可压缩 = 有规律」的严格形式。<span class="marginnote">「小算法 + 参数」视角是 MDL（最小描述长度）的基石：一条数据的最短描述 = 「解释它的模型 + 模型参数」。学习 = 找「模型 + 参数」使总描述最短。这个视角把「学习」与「压缩」统一起来——第 63 篇会展开。</span>

**辨析｜易错点：** 三个容易误解的地方：

- **$K(x)$ 不是「压缩率」**：它是「最短绝对长度」，不是「相对原来的比例」。长串可能 $K$ 很大但压缩率很好（比如一串随机的长文本）。
- **「不可计算」不是「不存在」**：$K(x)$ 是良定义的数（最小程序长度必然存在），只是无法用算法求出（下一篇）。
- **$K$ 依赖机器但只差常数**：别试图给出 $K(x)$ 的精确数值；只用「量级」与「比较」。<span class="marginnote">「$K(x)$ 良定义但不可计算」是算法信息论最微妙的地方：最短程序<strong>存在</strong>（因为自然数集合有最小值），但无法找到（停机问题）。所以 $K$ 是「概念上完美、算法上不可及」的量——它的价值在理论，不在数值。</span>

## 4 从定义到理论的三根支柱

有了 $K(x)$ 定义，算法信息论的三个核心概念依次展开：

- **条件复杂度** $K(x \mid y)$：给定 $y$ 时生成 $x$ 的最短程序——「$y$ 提供多少关于 $x$ 的信息」。$K(x|y)$ 远小于 $K(x)$ 说明 $y$ 能解释 $x$。
- **互信息（算法版）**：$I(x;y) = K(x) + K(y) - K(x,y)$——两条字符串共享多少结构。
- **通用概率** $m(x)$（第 62 篇）：与 $K(x)$ 对偶——「$x$ 由随机程序生成的概率」满足 $-\log m(x) \approx K(x)$。

这三根支柱构成算法信息论的主体，也是 MDL、Solomonoff 归纳、以及「智能 = 压缩」这一学说的数学根基。<span class="marginnote">「$I(x;y) = K(x) + K(y) - K(x,y)$」是 Shannon 互信息的算法对应：$K(x) + K(y)$ 是「分别描述」，$K(x,y)$ 是「一起描述」，差 = 「共享的信息」。它不需要分布——这是算法信息论相对 Shannon 信息论的独特贡献。</span>

**与全课程体系的连接：** 科尔莫戈罗夫复杂度在《计算理论》里与停机问题、不可判定性直接相关（下一篇）；在《数据压缩》里是「通用压缩极限」的理论答案；在《机器学习》里是「奥卡姆剃刀」的数学化——「优先选择更短描述」在 MDL 里有了精确的量化。

## 5 复杂度的量化直觉

把「$K(x)$ 小意味着什么」量化为几个判断，能更快建立直觉。

**$K(x) \approx \log n$**：$x$ 有「短生成规则」——大概率是「简单结构 + 小参数」。

**$K(x) \approx n$**：$x$ 没有「短生成规则」——大概率是「随机数据」。

**$K(x)$ 在两者之间**：$x$ 有「部分结构」——可以压缩一些，但不完全。

**「$K$ 小」与「概率高」的联系**：如果 $x$ 来自某个可计算分布 $p$，$K(x) \le -\log p(x) + c$——「高概率的串，复杂度不会太大」。

**这个联系是 Solomonoff 先验的预演**：简单（$K$ 小）的串在「随机程序」下概率高——复杂度与概率在此交汇。

**实践的陷阱**：「$K(x)$ 小」的判断依赖「你想到的生成规则」——你没想到的规则可能更短。所以「$K$ 的上界好找，下界难证」。

**一句话**：$K(x)$ 的量级告诉你「$x$ 有多可压缩」——$\log n$ 是「有规则」，$n$ 是「无规则」，中间是「部分规则」。
## 6 小结

- **科尔莫戈罗夫复杂度**：$K(x) = \min_{p: U(p) = x}|p|$——生成 $x$ 的最短程序长度。
- **不变性定理**：$|K_{U_1}(x) - K_{U_2}(x)| \le c$——量级机器无关，精确值机器依赖。
- 基本界：$K(x) \le |x| + c$；$K(n) \le \log n + c$；绝大多数串不可压缩（$K \ge n - O(1)$）。
- **直觉**：$K$ 小 = 有规律（小算法 + 参数）；$K$ 大 = 随机（只能列出）。
- **辨析**：$K$ 不是压缩率；良定义但不可计算；只谈量级与比较。
- 三根支柱：条件复杂度、算法互信息、通用概率——算法信息论的主体。
