# 无噪二元信道与有噪信道的例子

<div class="epigraph">
<p>噪声不是通信的失败，而是通信的成本——关键在于认清它每比特值多少。</p>
<footer>—— 克劳德 · 香农（Claude E. Shannon）</footer>
</div>

<div class="article-byline">
<p>第二级 · 信息论 ｜ Cover &amp; Thomas《Elements of Information Theory》 §7.1 ｜ 2026-08-07</p>
</div>

## 为什么从「理想与现实的对照」开始

容量 $C = \max_p I(X;Y)$ 的定义是抽象的，但它落到具体信道上，给出的数字非常有画面感：

- **无噪信道**：$C = 1$ 比特/使用——每用一次，干净地传一个比特。
- **有噪信道**：$C < 1$——噪声「吃掉」一部分比特，即使你把输入分布优化到极致也补不回来。
- **更糟的信道**：$C = 0$——噪声大到输入输出独立，无论怎么用，一个比特也传不过去。

这三个数字，把「噪声对通信能力的影响」压缩成一条曲线。这一篇我们逐个算清这些例子：无噪二元信道、带删除的无噪信道、BSC、BEC、Z 信道，并提炼出「容量如何随噪声变化」的直觉。

下一篇与再下一篇会专门深挖 BSC 与 BEC 的推导；这里先把「全景图」挂起来。<span class="marginnote">Cover &amp; Thomas §7.1 用一串例子串起容量的概念：无噪信道、无噪复制信道、无噪删除信道、BSC、BEC。每个例子的容量都能闭式算出，共同构成「容量是什么」的第一批直觉样本。</span>

## 1 无噪信道：容量的上限基准

**无噪二元信道**：$\mathcal{X} = \{0, 1\}$，$p(y|x) = 1$ 当且仅当 $y = x$。

- 输出完全由输入决定，$H(Y \mid X) = 0$。
- $I(X;Y) = H(Y) - 0 = H(Y) \le 1$（二元输出的熵最大 1）。
- 取 $p(0) = p(1) = \frac12$，$H(Y) = 1$，达到最大值。

$$
C_{\text{无噪}} = \max_p H(Y) = 1 \ \text{比特/使用}
$$

**推广**：字母表大小 $M$ 的无噪信道，$C = \log M$。**无噪信道的容量 = 每个符号能承载的最大熵**——这是所有信道容量的上限基准：噪声只会让它下降，永远不会上升。<span class="marginnote">「无噪信道容量 $= \log|\mathcal{Y}|$」是一条普适上界：任何信道（无论多好）的容量都不超过 $\log|\mathcal{Y}|$，因为 $I(X;Y) \le H(Y) \le \log|\mathcal{Y}|$。这个「输出熵上界」在求容量时是常用的第一道闸门。</span>

**一个有趣的变体——无噪复制信道**：输出是一个二元组 $(Y_1, Y_2)$，两路都等于 $X$（$|\mathcal{Y}| = 4$）。

- $H(Y) \le \log 4 = 2$，但 $I(X;Y) = H(X) \le 1$（输入只有 2 个值）。
- 所以 $C = 1$，**不是 2**——复制不增加信息，只增加冗余。

这个例子再次击中「输出熵 ≠ 信息」：$|\mathcal{Y}|$ 大，但输入限制让容量仍只有 1。

## 2 有噪信道：噪声如何「吃掉」比特

**无噪删除信道（BEC 的特例 $\alpha$ 控制）**：$\mathcal{X} = \{0,1\}$，$\mathcal{Y} = \{0, 1, e\}$，输入以概率 $\alpha$ 被删除（输出 $e$）、以 $1-\alpha$ 正确传输。

- 输入均匀时：输出 $y \in \{0, 1, e\}$ 的概率分别是 $\frac{1-\alpha}{2}, \frac{1-\alpha}{2}, \alpha$。
- $H(Y) = -(1-\alpha)\log\frac{1-\alpha}{2} - \alpha \log\alpha$，而 $H(Y|X) = \alpha \log\frac{1}{\alpha} \cdot ?$ 需要细算（下一篇正式推导）。
- 直觉先行：删除概率 $\alpha$ 越大，容量越小；$\alpha \to 0$ 时回到无噪信道 $C \to 1$，$\alpha \to 1$ 时 $C \to 0$。<span class="marginnote">删除信道的好处是它的容量有<strong>闭式解</strong> $C = 1 - \alpha$（下一篇推导）。这个简洁的线性公式在信道编码里极有用——它让「容量 vs 编码冗余」的分析可以精确到比特。</span>

**二进制对称信道（BSC）**：每个比特以概率 $p$ 翻转。

- $p = 0$：无噪，$C = 1$。
- $p = \frac12$：输出与输入独立（完全随机），$I = 0$，$C = 0$。
- 中间：$C = 1 - H(p)$（下一篇推导）——$p = 0.1$ 时 $C \approx 0.531$，噪声吃掉了近一半的比特。

**Z 信道**：只有「1 → 0」出错，概率 $p$。它的容量没有简单闭式，但可以用 KKT 条件算出（最优输入不是均匀的）——提醒我们，**噪声不对称时，「均匀输入」往往不是最优**。

## 3 公式解析：噪声熵如何压容量

用一个统一的分解看清所有例子的共性：

$$
C = \max_p \big[ H(Y) - H(Y \mid X) \big] \le \log|\mathcal{Y}| - H(Y \mid X)
$$

- **第一项 $H(Y) \le \log|\mathcal{Y}|$**：输出熵的上界由输出字母表大小决定，这是「天花板」。
- **第二项 $H(Y \mid X)$（噪声熵）**：给定输入后输出的残余随机性。**每一项噪声，都在从容量里扣掉一块。**
- **无噪信道**：$H(Y|X) = 0$，容量顶到 $\log|\mathcal{Y}|$。
- **有噪信道**：$H(Y|X) > 0$，容量被拉下来。噪声越大，扣得越多。
- **极端情形**：$H(Y|X) = H(Y)$（输入输出独立），$I = 0$，容量为 0。

**一句话**：**容量的损失，正好等于「给定输入后仍剩的随机性」——噪声是「每比特的随机税」。**<span class="marginnote">把这条直觉与「条件作用使熵减小」连起来：$H(Y|X) \le H(Y)$ 保证 $I \ge 0$；而 $H(Y|X)$ 的具体大小，完全由信道矩阵决定。求容量的本质，就是找一个输入分布，让「$H(Y)$ 的增益」与「$H(Y|X)$ 的代价」之差最大。</span>

## 4 辨析：有噪不代表「没用」

**辨析｜易错点：** 容量小 ≠ 信道没用。三个层次要分清：

- **$C > 0$**：总能以小于 $C$ 的速率可靠通信——只是速率被压低了。BSC($p=0.1$) 容量 0.531 比特，意味着「每用一次最多可靠传半比特多」，可以通过编码（如把 2 个输入比特编成 3 个信道符号之类）实现。
- **$C = 0$**：输入输出独立，信息真的过不去——这是唯一「没用」的情形。
- **$0 < C < \log|\mathcal{Y}|$**：是常态。几乎所有真实信道都落在这里，而编码理论的任务就是「逼近 $C$ 但不越过 $C$」。
- 另一个误区：**认为「加噪后可以靠放大信号补回来」**。功率约束（第八篇高斯信道）确实能提升容量，但那是因为信噪比变好，不是「绕过」噪声——噪声的随机税照扣不误。<span class="marginnote">「信号功率提升容量」的严格表述是第八篇的香农公式：$C = W\log(1 + \frac{P}{N_0W})$。功率 $P$ 提升，信噪比 $\frac{P}{N}$ 上升，容量对数增长——但噪声 $N_0$ 永远在分母里。噪声可以被压制，不能被消灭。</span>

**与全课程体系的连接：** 无噪/有噪的对照在第三级《计算机网络》里对应「理想链路 vs 含误码链路」；在《通信原理》里对应「编码增益」的概念。信息论给出的精确数字（$1 - H(p)$、$1 - \alpha$）是所有这些工程概念的理论坐标。

## 5 容量曲线与信噪比的直觉

把「无噪 vs 有噪」的容量画成一条随噪声变化的曲线，能建立最直接的直觉。

**BSC 容量曲线**：$C = 1 - H(p)$，$p \in [0, 1]$。

- $p = 0$：$C = 1$（无噪，满格）。
- $p$ 增大：$C$ 单调下降。
- $p = 0.5$：$C = 0$（完全随机）。
- $p > 0.5$：$C$ 回升（因为「取反」等价于 $1-p$）。

**曲线的三个特征**：

- 在 $p = 0$ 附近「最陡」——轻噪声就吃掉不少容量。
- 在 $p = 0.5$ 附近「最平」——接近完全随机时，容量趋零但「很难降到负」。
- 对称：$C(p) = C(1-p)$——翻转概率与补概率等价。

**「容量曲线」的工程用途**：

- 知道噪声水平，直接查容量——「这条链路最多能传多快」。
- 噪声升高，容量下降——「该考虑加编码余量或降速率了」。

**「无噪是上限，噪声是税」**：$C = \log|\mathcal{Y}| - H(\text{噪声})$——噪声的熵就是容量的税。

**一句话**：容量随噪声单调下降的曲线，是「链路预算」的直观化身——无噪是满格，噪声是每比特的随机税。
## 6 小结

- **无噪信道**：$C = \log|\mathcal{Y}|$，是容量的普适上界；复制信道不增加容量。
- **有噪信道**：容量 = 输出熵上界 − 噪声熵，噪声是「每比特的随机税」。
- BSC($p$)：$C = 1 - H(p)$（下一篇推导）；$p = \frac12$ 时 $C = 0$。
- BEC($\alpha$)：$C = 1 - \alpha$（闭式线性）；无噪删除是它的特例。
- **辨析**：$C > 0$ 就能可靠通信（只是慢）；$C = 0$ 才真正没用；功率能提升容量但消除不了噪声的税。
- 噪声对称性决定最优输入：对称信道均匀输入最优，Z 信道则不然。
