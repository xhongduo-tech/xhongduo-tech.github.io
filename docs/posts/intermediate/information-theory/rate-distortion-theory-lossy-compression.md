# 率失真理论（有损压缩的理论极限）

<div class="epigraph">
<p>当信息可以携带一点失真时，压缩的极限就不再是熵，而是一个关于失真的函数。</p>
<footer>—— 香农（Claude Shannon）《通信的数学理论》对率失真的预见（1948）</footer>
</div>

## 为什么从率失真开始

前几篇的压缩都是**无损**的：平均码长贴着熵走，输出必须能逐比特还原。但真实世界的压缩几乎全是有损的——JPEG 的图片、MP3 的音乐、H.264 的视频、语音通话的编码，都以「牺牲一点保真度」换取「大幅节省比特」。问题随之而来：**允许失真 $D$ 时，信息最少能压到多少比特？**

答案是**率失真函数 $R(D)$**——有损压缩的理论极限。它回答的不再是「一个数（熵）」，而是一整条**「比特 vs 失真」的权衡曲线**：纵轴是码率，横轴是失真，曲线之下的区域可行，之上的区域不可行。<span class="marginnote">率失真理论是香农 1948 年论文与 1959 年专著《Coding Theorems for a Discrete Source With a Fidelity Criterion》的核心成果。无损压缩是它的退化情形：失真 $D=0$ 时 $R(0)=H(X)$，曲线在这里接回熵。</span>

这一篇把「第1篇」的信源编码叙事推到底：熵管无损下限，$R(D)$ 管有损下限。在课程体系里，它是图像/音视频编码（第三级《数字信号处理》、第四级《大模型》的量化压缩）的理论根基，也是「感知编码」「生成模型的比特级分析」的出发点。

## 1 有损压缩：先定义「失真」

有损压缩的第一步是定义「差多少」。设信源符号 $x$、重构符号 $\hat x$，一个**失真度量（distortion measure）** $d(x,\hat x)$ 衡量用 $\hat x$ 代表 $x$ 的代价。常用的几种：

- **汉明失真（Hamming）**：$d(x,\hat x)=0$ 若 $x=\hat x$，否则 $1$——用于离散信源，单位是「错几个符号」。
- **平方误差（squared error）**：$d(x,\hat x)=(x-\hat x)^2$——用于连续信源，单位是「方差」。
- **绝对误差**：$d(x,\hat x)=|x-\hat x|$——鲁棒性更好，但分析较难。<span class="marginnote">「失真度量」的选取是有损压缩的第一设计决策：JPEG 用均方误差近似、H.264 用「感知加权」的失真、音频用心理声学模型——<strong>度量选对了，比特才花在刀刃上</strong>。本书《失真度量与量化问题》一篇给出系统分类。</span>

**平均失真**：$D=\mathbb{E}[d(X,\hat X)]=\sum p(x,\hat x)\,d(x,\hat x)$。率失真理论里，「允许失真 $D$」指平均失真不超过 $D$。

## 2 率失真函数：定义与含义

**率失真函数（rate-distortion function）**：对失真不超过 $D$ 的约束，最小可能的码率是

$$R(D) = \min_{p(\hat x\mid x):\; \mathbb{E}[d(X,\hat X)]\le D} I(X; \hat X)$$

- **最小化对象是条件分布 $p(\hat x\mid x)$**：它描述「如何把 $X$ 映射成有损的重构 $\hat X$」。
- **约束是平均失真** $\le D$：允许越大的失真，可行集越大，互信息可以越小。
- **$R(D)$ 是「权衡曲线」**：$D$ 增大时 $R(D)$ 单调下降；$D=0$ 时 $R(0)=H(X)$。<span class="marginnote"><strong>与容量定义的对称：</strong>容量是 $C=\max_{p(x)}I(X;Y)$（最大化互信息），率失真是 $R(D)=\min_{p(\hat x\mid x)}I(X;\hat X)$（最小化互信息）——一个「最多能传多少」，一个「最少需要多少」，一脉相承的双胞胎。这也解释了为什么 Cover & Thomas 把这两章放在镜像位置。</span>

## 3 公式解析：二元信源的 R(D)

对二元信源 $X\sim\text{Bernoulli}(p)$（$p\le\tfrac12$）、汉明失真，率失真函数有闭式：

$$R(D) = H_2(p) - H_2(D), \qquad 0\le D\le p$$

- **$D=0$**：$R=H_2(p)$——回到无损压缩的熵，符合直觉。
- **$D=p$**：$R=H_2(p)-H_2(p)=0$——允许一半失真时，一个比特都不需要传（收端直接猜「0」即可，反正允许 $p$ 的误差）。
- **$0<D<p$**：曲线在两者之间线性地下降：$R=H_2(p)-H_2(D)$。<span class="marginnote">推导的思路：取「测试信道」$p(\hat x\mid x)$ 使 $\hat X$ 以概率 $1-D$ 等于 $X$、以概率 $D$ 翻转，则平均失真恰为 $D$，而 $I(X;\hat X)=H_2(p)-H_2(D)$；再用数据处理性质证明任何失真 $\le D$ 的映射互信息都 $\ge$ 这个值——上下夹逼即得。</span>

**数字**：$p=0.1$（很偏斜的源），$H_2(0.1)\approx 0.469$。允许 $5\%$ 失真：$R\approx 0.469-H_2(0.05)\approx 0.469-0.286=0.183$ bit/符号——**比无损的 0.469 省了一半多**。这就是「容忍一点错，节省一大截」的量化答案。

把这条曲线展开成表，失真的「性价比」一目了然（$p=0.1$）：

| 允许失真 $D$ | $R(D)=H_2(0.1)-H_2(D)$ | 相比无损省多少 |
| --- | --- | --- |
| $0$ | $0.469$ bit | 无损基线 |
| $0.01$ | $0.469-0.081=0.388$ bit | 省 17% |
| $0.05$ | $0.469-0.286=0.183$ bit | 省 61% |
| $0.08$ | $0.469-0.402=0.067$ bit | 省 86% |
| $0.10$ | $0.469-0.469=0$ bit | 完全不用传 |

观察：失真从 0 放宽到 1%，省 17%；再放宽到 5%，累计省 61%——**前半段的失真「最值钱」，越往后收益越少**。这是 $R(D)$ 凹性的体现，也是所有有损编码器「先花小失真换大节省」策略的理论根据。<span class="marginnote">这条「前段陡、后段平」的曲线在图像编码里直接可见：JPEG 质量参数从 95 调到 85，肉眼几乎无差别，文件却小一半；从 85 再往下，省得越来越少，画质却开始崩。$R(D)$ 正是这张「画质-体积」权衡图的精确理论版。</span>

## 4 高斯信源的 R(D) 与逆注水

对高斯信源 $X\sim\mathcal{N}(0,\sigma^2)$、平方误差失真，率失真函数为：

$$R(D) = \frac12 \log_2 \frac{\sigma^2}{D}, \qquad 0 \le D \le \sigma^2$$

- **$D=\sigma^2$**：$R=0$，完全不传也能把「重构」做到失真 $\sigma^2$（收端直接猜均值 0）。
- **$D\to 0$**：$R\to\infty$——**高斯信源要无损表示，需要无限多的比特**（连续值的信息量无穷大），这正呼应微分熵的性质。
- **半失真规则**：$D=\sigma^2/4$ 时 $R=1$ bit/符号——把高斯信源「量化」到均方误差为方差的四分之一，只需 1 bit/符号。

**逆注水（reverse water-filling）**：多个并联高斯信源（如频域里的各分量）的率失真问题，最优解是把**失真预算倒过来分配**：给方差大的分量多分失真预算（它们「粗糙一点无所谓」），给方差小的分量少分甚至零失真（它们「必须精雕」）。规则写成：若 $D_i$ 表示第 $i$ 个分量的失真，则 $D_i=\min(\lambda,\sigma_i^2)$，其中 $\lambda$ 由总失真预算决定。<span class="marginnote">逆注水与高斯信道里的注水法方向正好相反：信道注水是「把功率往噪声小的地方灌」，率失真逆注水是「把失真往方差大的地方推」——同一个「水面齐平」思想，应用场合不同，记号却惊人的一致。本书《高斯信源的逆注水》一篇专门对照。</span>

## 5 率失真定理：可达与必要

**率失真定理**：对离散无记忆信源、失真度量 $d(\cdot,\cdot)$，码率为 $R$ 的编码能在平均失真 $\le D$ 下表示信源，当且仅当 $R\ge R(D)$。

- **可达性（$R>R(D)$）**：把信源序列 $X^n$ 分块，随机地选「重构序列」$\hat X^n$（按测试信道分布），只有约 $2^{nR(D)}$ 个重构块是「可行的」——给它们编号即可。与信道编码的随机编码论证如出一辙。<span class="marginnote">率失真定理的证明结构与信道编码定理完全平行：<strong>随机编码 + 典型集</strong>。区别只是「典型」的对象：信道编码联合典型的是（码字，接收），率失真联合典型的是（信源块，重构块）。这再次印证「第1篇」想传达的主线——信息论几大定理是同一套思想的不同投影。</span>
- **逆定理（$R<R(D)$）**：由 Fano 类不等式推出，码率低于 $R(D)$ 时平均失真必超 $D$。<span class="marginnote">一句话记忆率失真定理：<strong>压缩到 $R(D)$ 以下必然超失真，压到 $R(D)$ 以上可以达标</strong>。它与信道编码定理、信源编码定理一起，构成香农三大极限定理。</span>

## 6 从理论到工程：量化与感知编码

率失真理论给的是「极限」，工程要造的是「逼近它的编码器」。三大工程手法与理论的对应：

- **标量量化**：把连续值 $x$ 映射到最近的码字 $q(x)$。均匀量化器的均方误差随步长 $\Delta$ 为 $\Delta^2/12$——量化误差与码率的权衡，正是 $R(D)$ 曲线的工程投影。<span class="marginnote">「$\Delta^2/12$」是均匀量化器的经典结果：把区间 $[-\Delta/2,\Delta/2]$ 里的均匀噪声的方差算出来。量化的比特数每加 1，$\Delta$ 减半，失真降为四分之一——每比特换来约 6 dB 的 SNR 提升，这是 ADC 里「6 dB/bit」的口诀来源。</span>
- **变换编码**：JPEG 先做 DCT、JPEG 2000 做小波变换，把能量集中到少数系数上——这就是「逆注水」的工程实现：把失真预算推给能量小（方差小）的高频系数，甚至直接置零。
- **感知建模**：人眼对亮度比色彩敏感、人耳对低频比高频敏感——用「感知失真」替换均方误差，让 $R(D)$ 的「有效失真」更贴近主观质量。<span class="marginnote"><strong>与无损压缩的分工：</strong>无损压缩（Huffman、算术编码）在现代编码器里往往只是<strong>最后一道熵编码</strong>：JPEG 先量化（有损）再用 Huffman 收尾，H.264 先变换量化再用 CAVLC/CABAC（算术编码）。有损把码率压下来，无损把残余码率压到熵——两套理论在一台编码器里协作。</span>

**大模型的衔接**：嵌入向量的乘积量化（PQ）压缩、量化感知训练（QAT）、「让模型更省比特」的种种努力，本质上都在做同一件事——**在「模型质量（失真）」与「模型体积（码率）」之间找最优的 $R(D)$ 点**。率失真语言是理解它们的统一框架。

## 7 核心对比表：无损 vs 有损压缩

| | 无损压缩 | 有损压缩（率失真） |
| --- | --- | --- |
| 重构 | 逐比特还原 | 允许失真 $D$ |
| 极限 | 熵 $H(X)$ | 率失真函数 $R(D)$ |
| 工具 | 典型集、Huffman、算术编码 | 测试信道、随机重构 |
| 连续信源 | 熵发散（无法无损） | $R(D)=\tfrac12\log(\sigma^2/D)$ 有限 |
| 应用 | gzip、文本 | JPEG、MP3、H.264、语音编码 |

最有启发性的一行是「连续信源」：**对连续数据谈「无损」无意义（熵无穷），谈「有损」才有意义**——这正是为什么图像、音频、视频从第一天起就是有损编码。<span class="marginnote">「从极限到大模型」的另一处衔接：大模型做<strong>向量量化（VQ）</strong>、<strong>乘积量化（PQ）</strong>压缩嵌入时，用的正是率失真思想——给定重建误差预算，选最小的码率。第三级《机器学习》、第四级《大模型》都会遇到这张「比特 vs 失真」曲线。</span>

## 8 小结

- **有损压缩**先定义失真度量 $d(x,\hat x)$；率失真理论问「允许失真 $D$ 时最少要多少比特」。
- **率失真函数** $R(D)=\min_{p(\hat x\mid x)} I(X;\hat X)$，是容量定义 $C=\max I$ 的镜像。
- **二元信源**：$R(D)=H_2(p)-H_2(D)$，允许失真省比特立竿见影。
- **高斯信源**：$R(D)=\tfrac12\log(\sigma^2/D)$；连续信源无损不可能，有损才有意义。
- **逆注水**：失真预算往方差大的分量推，与信道注水方向相反。
- **率失真定理**：$R\ge R(D)$ 是「能在失真 $\le D$ 下压缩」的充要条件。
- **工程对应**：标量量化、变换编码（DCT/小波）、感知建模都是逼近 $R(D)$ 的具体手艺。
