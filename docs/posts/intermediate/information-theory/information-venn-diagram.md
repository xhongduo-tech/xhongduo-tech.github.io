## 为什么从 Venn 图开始

把熵、联合熵、条件熵、互信息四个量摆在一起，初学者最容易的感觉是「关系太多、记不住」。它们的恒等式确实不少：

$$H(X,Y) = H(X) + H(Y) - I(X;Y)$$
$$I(X;Y) = H(X) - H(X\mid Y) = H(Y) - H(Y\mid X)$$

但这一切可以压缩成**一张图**。第一级《集合的概念》里我们学过用韦恩图（Venn diagram）表示集合的并、交、差——把「信息」当成「面积」，熵、条件熵、互信息就分别对应圆的整体、新月形与交叠部分。**一张图，所有恒等式自动浮现。**<span class="marginnote">把熵画成集合的想法，让信息量第一次有了「看得见的大小」。但它有一个重要的限度：<strong>对两个变量，这张图是精确的；对三个及以上变量，图上会出现「负面积」，图就降级为助记工具</strong>。理解「精确到哪一步、从哪一步开始失效」，正是本节要练的判断力。</span>

## 1 把信息画成面积：两个圆的图

用两个互相交叠的圆代表两个随机变量 $X$、$Y$。约定：**每个「区域」的面积代表对应的信息量**。

![熵、条件熵与互信息的韦恩图：左圆 H(X)、右圆 H(Y)，重叠区域是 I(X;Y)，左右新月形分别是 H(X|Y) 与 H(Y|X)，虚线框整体是 H(X,Y)](/images/information-theory/information-venn-diagram-1.svg)

图上的每一块都对应一个我们认识过的量：

**左圆整体** = $H(X)$：$X$ 自身的不确定性。
**右圆整体** = $H(Y)$：$Y$ 自身的不确定性。
**两圆重叠部分** = $I(X;Y)$：两个变量共享的信息。
**左圆独有（新月形）** = $H(X\mid Y)$：知道 $Y$ 后 $X$ 还剩的不确定性——即「$Y$ 分不走的那部分 $X$」。
**右圆独有（新月形）** = $H(Y\mid X)$：知道 $X$ 后 $Y$ 还剩的不确定性。
**虚线框整体（并集）** = $H(X,Y)$：两个变量合起来的总不确定性。

把「区域 → 量 → 含义」整理成一张表，随时可查：

| 图上的区域 | 对应量 | 含义 |
| --- | --- | --- |
| 左圆整体 | $H(X)$ | $X$ 自身的不确定性 |
| 右圆整体 | $H(Y)$ | $Y$ 自身的不确定性 |
| 两圆交叠 | $I(X;Y)$ | 两变量共享的信息 |
| 左新月 | $H(X\mid Y)$ | 知道 $Y$ 后 $X$ 的剩余 |
| 右新月 | $H(Y\mid X)$ | 知道 $X$ 后 $Y$ 的剩余 |
| 虚线并集 | $H(X,Y)$ | 总不确定性 |

**「知道 $Y$ 后 $X$ 的剩余」= 左圆挖掉重叠区**，这正是 $H(X\mid Y)=H(X)-I(X;Y)$ 的图形读法。上一节我们在《互信息》里用贝叶斯公式代数地证明了这个式子，现在它变成了「看一眼图就明白」的几何直觉。

## 2 从图上读出所有恒等式

有了这张图，前面三节的恒等式全部可以「读」出来。

**$I(X;Y) = H(X) - H(X\mid Y)$**：重叠区 = 左圆 − 左新月。<span class="marginnote">这是互信息的「减法定义」在图上最直观的一例：<strong>共享 = 自有 − 剩余</strong>。每一个方向都有对应的图。</span>
- **$I(X;Y) = H(Y) - H(Y\mid X)$**：重叠区 = 右圆 − 右新月。两张面孔在图上指着同一个区域——对称性一目了然。
- **$H(X,Y) = H(X) + H(Y) - I(X;Y)$**：并集面积 = 两圆面积之和 − 重叠区（否则重叠被数了两遍）。这正是集合论里的容斥原理（inclusion-exclusion）在信息论里的翻版。
- **$H(X,Y) = H(X) + H(Y\mid X) = H(Y) + H(X\mid Y)$**：并集也可以拆成「一个圆 + 另一个的新月」，两条路径殊途同归——这是熵的链式法则的图形形态。

值得强调：重叠区的大小就是 $I(X;Y)$。当 $X,Y$ 独立时 $I=0$，两个圆退化为互不相交；当 $Y$ 完全决定 $X$ 时 $H(X\mid Y)=0$，左圆被右圆整个盖住。**Venn 图把「独立」画成「不相交」，把「函数关系」画成「包含」**——第一级《集合的概念》里建立的那套集合直觉，在这里被完整地借用了过来。

**辨析｜易错点：** 图上的「面积」是**信息量**，不是概率质量。圆的大小取决于分布的熵，与取值的个数、概率的具体数值都有关；一个圆可以比另一个大得多，不代表「$X$ 比 $Y$ 更重要」，只代表「$X$ 携带的不确定更多」。别把「信息面积」和「事件概率」混为一谈。

## 3 三变量的图：哪里会出问题

两个圆这么完美，自然想画三个圆。三个变量的 8 个区域也可以写出对应的量：$H(X\mid Y,Z)$、$I(X;Y\mid Z)$……最中央的**三元交叠**对应的是**三元互信息（interaction information）**：

$$I(X;Y;Z) = I(X;Y) - I(X;Y\mid Z)$$

问题恰恰出在这一块：**$I(X;Y;Z)$ 可以为负。** 看我们熟悉的异或例子：$X,Y$ 独立同分布 $\text{Bernoulli}(1/2)$，$Z = X\oplus Y$。上一节算过 $I(X;Y)=0$、$I(X;Y\mid Z)=1$，于是

$$I(X;Y;Z) = 0 - 1 = -1$$

一个面积不可能是 $-1$。**所以三个变量的「韦恩图」不再是真实的面积图，而是信息论里的助记图（information diagram）**——公式可以照写，但「面积」的说法必须退休。<span class="marginnote">三元互信息为负，在机器学习里对应一种著名的现象叫<strong>冗余（redundancy）</strong>：两个特征各自携带的信息在第三个已知后「互相抵消」；反之 $I(X;Y;Z)>0$ 对应<strong>协同（synergy）</strong>——合起来才有、拆开都没有的信息。负面积不是错误，而是信息论在告诉你：三个变量之间的信息，比两个变量「多出了一个维度」。</span>

三变量的容斥式也值得写出来，它把「负区域」放进一个仍然成立的恒等式里：

$$H(X,Y,Z) = H(X) + H(Y) + H(Z) - I(X;Y) - I(X;Z) - I(Y;Z) + I(X;Y;Z)$$

与两变量的容斥式相比，多出了最后一项「加回三元交叠」。回到异或例子验证：$H(X)=H(Y)=H(Z)=1$，$H(X,Y,Z)=2$，三对互信息都是 $0$，而 $I(X;Y;Z)=-1$，代入得 $1+1+1-0-0-0-1=2$——恰好等于 $H(X,Y,Z)$。**容斥式继续成立，只是中间的「面积」出现了负数。**

**边界总结**：两个变量时，信息恒等式恰似集合运算，Venn 图精确成立；三个及以上变量时，只有「链式法则」「容斥式」这类**代数恒等式**依然成立，几何图像只能当作辅助记忆。这提醒我们：**图是理解的脚手架，公式才是信息论的承重墙。**

## 4 公式解析：H(X,Y) = H(X) + H(Y) − I(X;Y)

这是全专题最常被引用的恒等式之一，值得一步步走通。它本质上是「容斥原理」在信息论中的样子。

- **第一步，从互信息的定义出发**：$I(X;Y) = H(X) - H(X\mid Y)$。把 $H(X\mid Y)$ 移到等号另一边：

$$H(X\mid Y) = H(X) - I(X;Y)$$

- **第二步，用熵的链式法则换掉 $H(X\mid Y)$**：$H(X,Y) = H(Y) + H(X\mid Y)$（先承担 $Y$、再看 $X$ 的剩余）。代入上一步：

$$H(X,Y) = H(Y) + H(X) - I(X;Y)$$

- **第三步，读出容斥的几何含义**：并集（联合熵）等于两个集合的面积之和，减去重叠区域（互信息），因为重叠在相加时被数了两次。**这就是「两圆之和 − 交叠 = 并集」的代数版。**

- **第四步，反向读出互信息**：把恒等式改写成 $I(X;Y)=H(X)+H(Y)-H(X,Y)$——互信息是「两圆面积之和比并集多出的那部分」，也就是重叠区。与第 1 节图上指认的完全一致。

全程只用了互信息定义与链式法则，没有新假设。**记住这张图，等于记住了这张恒等式表。**

## 5 辨析：信息图的三条边界

**辨析｜易错点一：「面积」是比喻，不是字面意义。** 信息量不是几何面积，Venn 图只是把「非负、可加、满足容斥」这三条性质翻译成了图像。对两个变量，这个翻译是**保真的**——每个区域都是非负信息量，加减关系精确对应。

**辨析｜易错点二：三个变量出现「负面积」。** 三元互信息 $I(X;Y;Z)=I(X;Y)-I(X;Y\mid Z)$ 可正可负，异或例子给出 $-1$。因此**三变量及以上的信息图只是助记工具**，不能把每个区域当真面积。<span class="marginnote"><strong>记忆锚点：</strong>「两变量精确、三变量助记」这条分界线，正好对应信息论的「加法」结构只到二阶为止——更高阶的交互信息不再是「量的大小」，而是「关系的符号」。</span>

**辨析｜易错点三：信息图没有「全集」。** 集合的 Venn 图通常画在一个有限的「全集」里，并集之外还有空间；但信息没有总预算——$H(X,Y)$ 之上没有「宇宙」来兜底。这也是为什么「补集」$H(X\mid Y)$ 之后没有「补集的补集」：信息总是关于「已知多少」的相对概念，而非绝对存量。

## 6 小结

- **两变量 Venn 图精确成立**：左圆 $H(X)$、右圆 $H(Y)$、交叠 $I(X;Y)$、新月 $H(X\mid Y)$、$H(Y\mid X)$、并集 $H(X,Y)$。
- **一张图读出全部恒等式**：$I=H(X)-H(X\mid Y)=H(Y)-H(Y\mid X)$；$H(X,Y)=H(X)+H(Y)-I(X;Y)$。
- **本质是容斥原理**：联合熵 = 两圆面积之和 − 重叠区；互信息 = 重叠区。
- **三变量降级为助记图**：三元互信息可为负（异或例 $I(X;Y;Z)=-1$），图像失效、代数恒等式仍成立。
- **图是脚手架，公式是承重墙**：理解「精确到两变量」的分界线，比背下图像更重要。

在下一节，我们将回到相对熵，证明它最重要的一条性质——**非负性（吉布斯不等式）**，并看到它如何一锤定音地推出「交叉熵 ≥ 熵」「互信息 ≥ 0」与「条件作用使熵减小」。
