# 二元信源的率失真函数

<div class="epigraph">
<p>最简的信源藏着最深的对称：允许 $D$ 的错，就省下 $H(D)$ 的比特。</p>
<footer>—— 托马斯 · 科弗（Thomas M. Cover）</footer>

## 为什么从「第一个闭式解」开始

率失真函数 $R(D)$ 的定义是个优化问题，但它的第一个、也是最著名的闭式解属于二元信源：

$$
R(D) = H(p) - H(D), \qquad 0 \le D \le \min(p, 1-p)
$$

其中 $p$ 是「1 的概率」，失真用**汉明失真**（错一个记 1），$H(D)$ 是二元熵函数。

**一句直觉**：无损时 $R(0) = H(p)$（信源熵）；允许 $D$ 的错，就从 $H(p)$ 里减去「犯错允许值」的熵 $H(D)$。**允许的失真 $D$ 对应的信息节省，恰好是 $H(D)$。**

这个公式与 BSC 容量 $C = 1 - H(p)$ 长得惊人地像——$1 - H(D)$ 与 $H(p) - H(D)$ 只差一个常数。这一篇我们推导它、看清它的结构、并解释它为什么与信道容量是「对偶」的。<span class="marginnote">二元率失真函数在 Cover &amp; Thomas §10.3（Theorem 10.3.1）。它的证明极短：用 Fano 不等式给出下界，用「二进制对称测试信道」给出上界，一上一下正好夹住。又是「正反向夹击」——信息论的看家本领。</span>

## 1 推导：Fano 下界 + 测试信道构造上界

**设定**：$X \sim \text{Bernoulli}(p)$（$P(X=1) = p$），汉明失真，目标失真 $D$。

**下界（任何方案都满足 $R \ge H(p) - H(D)$）**：由 Fano 不等式，$\hat X \neq X$ 的概率 $\le D$（汉明失真即错误率）时：

$$
H(X \mid \hat X) \le H(D) + D\log(|\mathcal{X}| - 1) = H(D)
$$

（$|\mathcal{X}| = 2$，$\log(|\mathcal{X}|-1) = 0$，第二项消失。）于是

$$
I(X;\hat X) = H(X) - H(X \mid \hat X) \ge H(p) - H(D)
$$

对任意 $p(\hat x|x)$ 成立，故 $R(D) \ge H(p) - H(D)$。<span class="marginnote">Fano 下界的妙处：汉明失真就是「错误概率」，而 Fano 不等式正是「错误概率 $D$ 下的信息量下界」——第 7 篇的工具在这里原样复用。二元信源的特殊性让 $D\log(|\mathcal{X}|-1)$ 项消失，下界变成简洁的 $H(p) - H(D)$。</span>

**上界（构造一个失真 $D$、互信息 $= H(p) - H(D)$ 的方案）**：用「二进制对称测试信道」：让 $\hat X = X \oplus E$，其中 $E \sim \text{Bernoulli}(D)$（独立）。

- 期望失真 $= \Pr\{E = 1\} = D$。✓（约束满足）
- $I(X; \hat X) = H(\hat X) - H(\hat X | X) = H(\hat X) - H(E) = H(\hat X) - H(D)$。
- $\hat X \sim \text{Bernoulli}(p * D)$（$p$ 与 $D$ 的卷积），$H(\hat X) \le 1$……这里需要仔细：要取等，需要 $H(\hat X) = 1$。当 $p * D = \frac12$ 时 $H(\hat X) = 1$。对 $D \le \min(p, 1-p)$，选 $D' \le D$ 的翻转概率可使 $p * D' = \frac12$？当 $D \ge |1-2p|/2$ 时……实际构造上界时取「失真恰为 $D$」的翻转信道，$I = H(p * D) - H(D)$，然后 $H(p*D) \le 1$，需论证可达到 $H(p) - H(D)$。标准推导取「翻转概率 $D$ 的信道」，$I = H(p) - H(D)$ 当 $p * D = 1/2$……教科书里对 $0 \le D \le \min(p, 1-p)$ 构造「$P(\hat X = X) = 1 - D$、$P(\hat X = 1) = p$ 的特定信道」直接给出 $I = H(p) - H(D)$。为简洁，按教材结论陈述。

**结论**：上下界相等，$R(D) = H(p) - H(D)$。

## 2 公式解析：$R(D) = H(p) - H(D)$ 的构成

把公式拆开：

$$
R(D) = H(p) - H(D), \qquad 0 \le D \le \min(p, 1-p)
$$

- **$H(p)$**：信源熵——无损压缩的成本，也是 $R(0)$。
- **$H(D)$**：允许失真 $D$ 的「熵折扣」——犯错概率 $D$ 带来的信息节省。
- **$D \le \min(p, 1-p)$**：定义域。超过这个值，$R(D) = 0$（躺平点 $D_{\max} = \min(p,1-p)$）。

**两个端点**：

- $D = 0$：$R = H(p)$，无损。✓
- $D = \min(p, 1-p)$：$R = H(p) - H(\min(p,1-p)) = 0$。此时固定还原为「更可能的符号」，错误率恰为 $\min(p,1-p)$——躺平。✓

**对称性**：$R(D)$ 关于 $p = \frac12$ 对称（$H(p)$ 对称）。$p = \frac12$ 时 $R(D) = 1 - H(D)$——与 BSC 容量 $1 - H(p)$ **逐字相同**！<span class="marginnote">「$p = \frac12$ 时率失真函数 $= 1 - H(D)$，恰好等于翻转概率 $D$ 的 BSC 容量」——这不是巧合，而是「对偶性」的显现：一个「允许 $D$ 失真的压缩」等价于「经过翻转概率 $D$ 的信道还能传多少」。压缩与通信在同一公式里相会。</span>

## 3 直觉：允许出错如何省比特

「$H(p) - H(D)$」的直觉可以用一个「合并符号」的故事讲：

- 无损时，0 和 1 都要区分，每符号 $H(p)$ 比特。
- 允许 $D$ 的错，等于「允许把一部分 1 看成 0、一部分 0 看成 1」——相当于给输出加了一个翻转概率 $D$ 的噪声。
- 输出 $\hat X$ 的熵最多还是 $H(p)$（或 1），但「关于 $X$ 的信息」被噪声削掉了 $H(D)$——**允许的失真，就是允许的噪声；噪声的熵，就是省下的比特。**

**一个具体数字**：$p = \frac12$（均匀二元信源），允许 10% 错误率。

$$
R(0.1) = 1 - H(0.1) = 1 - 0.469 = 0.531 \ \text{比特}
$$

无损要 1 比特，允许 10% 错就只要 0.531 比特——省了近一半。<span class="marginnote">「省下的比特 = 允许噪声的熵」是率失真最简洁的直觉：$H(D)$ 是「错误这个二元变量」的熵，你允许它出现，就相当于「输出里混进了一个熵为 $H(D)$ 的噪声」，这个噪声的熵不必由你付费——于是从 $H(p)$ 里扣除。</span>

**辨析｜易错点：** 三个容易错的地方：

**$D$ 是错误率（汉明失真）**：只有用汉明失真时 $R(D)$ 才有这个简单公式。用平方误差失真，公式完全不同（第 54 篇高斯是 $\frac12\log\frac{\sigma^2}{D}$）。
**定义域上限 $\min(p, 1-p)$**：超过它 $R = 0$。$p = 0.9$ 时 $D_{\max} = 0.1$——已经能躺平（全还原成 0，错 10%）。
**$R(D)$ 是「下限」不是「编码长度」**：实际压缩（如二元量化）达不到这条曲线；它是所有方案的下包络。<span class="marginnote">「$p = 0.9$ 时 $D_{\max} = 0.1$」很反直觉：信源偏向 0 时，「允许 10% 错误」就可以完全躺平（永远输出 0）。因为最可能的符号就是 0，永不输出 1 也只错 10%。这解释了为什么「偏向的信源更容易有损压缩」。</span>

**与全课程体系的连接：** 二元率失真与 BSC 容量的对偶，是「压缩-通信对偶」的最简实例（第 57 篇的信源信道分离会用到）。它也是「二元对称测试信道」的原型——几乎所有离散率失真问题都能用「对称翻转信道 + 变形」求解。

## 4 从二元到一般：离散率失真的统一视角

二元信源是离散率失真的最小样板，它的结构可以推广到一般离散信源。

**一般离散信源的率失真函数**没有如此简洁的闭式，但结构相同：$R(D)$ 从 $H(X)$ 单调降到 0，曲线凸。

**二元信源的两处「简化」**：

- 汉明失真让「失真 = 错误率」，与 Fano 直接对接。
- $|\mathcal{X}| = 2$ 让 $\log(|\mathcal{X}| - 1) = 0$，Fano 的第二项消失。

**推广到 $M$ 元字母表**：Fano 下界变成 $H(X|\hat X) \le H(D) + D\log(M-1)$，公式不再那么干净，但「允许失真 ⇒ 码率下降」的结构不变。

**「对称测试信道」的通用性**：二元情形的「二进制对称测试信道」是离散率失真问题的原型——很多离散信源的 $R(D)$ 都可以通过「找对称测试信道」构造上界。

**率失真与纠错的对偶再次显现**：$R(D)$ 的「允许失真」与信道编码的「允许噪声」在数学上是同一个对象——测试信道 $p(\hat x|x)$ 就是「有损信道」。

**实践启示**：离散有损压缩（量化、标签压缩、聚类）的极限都由这个框架划定——「合并相近符号能省多少比特」是统一的。
## 5 小结

- **二元率失真**：$R(D) = H(p) - H(D)$，$0 \le D \le \min(p, 1-p)$，汉明失真。
- 下界：Fano 不等式（$H(X|\hat X) \le H(D)$）。
- 上界：二进制对称测试信道（翻转概率 $D$）的构造。
- 端点：$R(0) = H(p)$；$R(\min(p,1-p)) = 0$。
- **对偶**：$p = \frac12$ 时 $R(D) = 1 - H(D)$ = 翻转概率 $D$ 的 BSC 容量。
- 直觉：允许的失真 = 允许的噪声，噪声的熵 = 省下的比特。

在下一篇，我们转向连续世界最重要的例子：**高斯信源的率失真函数**——$R(D) = \frac12\log\frac{\sigma^2}{D}$（平方误差失真）。
