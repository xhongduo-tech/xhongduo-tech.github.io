## 为什么需要系统化处理「不定式」

第三章里我们用手工招数对付过两类极限：$\frac00$ 型靠约公因式，$\frac{\infty}{\infty}$ 型靠除以最高次。但这些招数只对多项式管用——$\lim_{x\to0}\frac{e^x-1-x}{x^2}$ 约不了公因式，$\lim_{x\to\infty}\frac{e^x}{x^2}$ 除以最高次也没用。面对「$\frac00$」「$\frac{\infty}{\infty}$」这类**不定式**，需要统一的理论武器。

**洛必达法则**正是这把武器：**把「函数之比」的极限，转化为「导数之比」的极限**。它把复杂的代数结构交给导数——而导数往往是更简单的对象。这一节我们系统展开洛必达法则，并盘点 $\frac00,\frac\infty\infty,0\cdot\infty,\infty-\infty,1^\infty,\infty^0,0^0$ 七种不定式的归化路线。<span class="marginnote">洛必达法则以侯爵洛必达命名，但公认由约翰·伯努利（Johann Bernoulli）发现，两人之间有私人协议。数学史上这样的「以买主命名」并不罕见——但法则本身属于伯努利。今天叫它洛必达，是一种历史惯性，也提醒我们：数学发现常与命名权分道扬镳。</span>

## 1 洛必达法则：0/0 型

**定理（洛必达法则 I，$\frac00$ 型）：设**
1. $f,g$ 在 $x_0$ 的去心邻域内可导，且 $g'(x)\ne0$；
2. $\displaystyle\lim_{x\to x_0}f(x)=\lim_{x\to x_0}g(x)=0$；
3. $\displaystyle\lim_{x\to x_0}\frac{f'(x)}{g'(x)}=A$（$A$ 可为有限或 $\pm\infty$）。

**则 $\displaystyle\lim_{x\to x_0}\frac{f(x)}{g(x)}=A$。**

**证明思路（用柯西中值定理）**：补定义 $f(x_0)=g(x_0)=0$（连续化，不影响极限）。由柯西中值定理（§6.2），对 $x\ne x_0$，存在 $\xi$ 介于 $x_0$ 与 $x$ 之间，使

$$\frac{f(x)}{g(x)}=\frac{f(x)-f(x_0)}{g(x)-g(x_0)}=\frac{f'(\xi)}{g'(\xi)}.$$

当 $x\to x_0$ 时 $\xi\to x_0$（被夹在中间），于是 $\frac{f(x)}{g(x)}=\frac{f'(\xi)}{g'(\xi)}\to A$。∎

> **辨析｜易错点：洛必达法则的三个前提缺一不可。** 第一，必须是 $\frac00$ 型（或 $\frac\infty\infty$ 型）——$\lim\frac{x}{1+x}$ 在 $x\to\infty$ 不是不定式，直接得 1，不必（也不该）用洛必达。第二，**求导后极限必须存在**——$\lim_{x\to0}\frac{x^2\sin\frac1x}{\sin x}$ 是 $\frac00$ 型，但求导后 $\frac{2x\sin\frac1x-\cos\frac1x}{\cos x}$ 的极限不存在（振荡），而原极限却存在（为 0，可用夹逼）；**洛必达失效时，极限未必不存在——换方法！** 第三，$g'(x)\ne0$ 是柯西中值的条件，别忽略。

## 2 洛必达法则：∞/∞ 型与单侧、无穷远端

**定理（洛必达法则 II，$\frac{\infty}{\infty}$ 型）：把条件 2 换成 $\displaystyle\lim_{x\to x_0}|g(x)|=\infty$，结论同样成立。**

证明比 $\frac00$ 型繁琐（需要精细的估计），但直觉一致：分子分母都冲向无穷时，它们的「增长竞赛」由导数主导。洛必达法则还有两个常用变体：

- **单侧版**：$x\to x_0^+$ 或 $x\to x_0^-$ 时同样成立；
- **无穷远版**：$x\to+\infty$ 或 $x\to-\infty$ 时，令 $t=\frac1x$ 化归到 $t\to0$，或直接用「无穷远柯西中值」证明。

**应用示范**：$\displaystyle\lim_{x\to+\infty}\frac{x^2}{e^x}$。这是 $\frac\infty\infty$ 型，反复用洛必达：

$$\lim_{x\to\infty}\frac{x^2}{e^x}=\lim_{x\to\infty}\frac{2x}{e^x}=\lim_{x\to\infty}\frac{2}{e^x}=0.$$

每次求导都让分子降幂、分母不动，三次即得 0。**这个极限说明 $e^x$ 最终压过任何多项式**——「指数征服幂」，是无穷大阶谱（§3.5）的又一次证明。<span class="marginnote">洛必达法则用起来可以「连坐」：只要仍是 $\frac00$ 或 $\frac\infty\infty$ 型，就可以继续求导。但要注意<strong>每次使用前都要验证类型</strong>——$\lim_{x\to\infty}\frac{2x}{e^x}$ 还是 $\frac\infty\infty$，可以再来一次；若中途变成非不定式（如 $\frac{2}{e^x}$ 直接算），就停下直接用极限。机械连用而不验型，是常见错误。</span>

## 3 公式解析：七种不定式的归化

除 $\frac00$ 与 $\frac\infty\infty$ 外，其余五种不定式都要**先变形**再套洛必达：

| 类型 | 变形手法 | 例子 |
| --- | --- | --- |
| $\frac00,\frac\infty\infty$ | 直接用洛必达 | $\lim_{x\to0}\frac{1-\cos x}{x^2}=\frac12$ |
| $0\cdot\infty$ | 化倒数变 $\frac00$ | $\lim_{x\to0^+}x\ln x=\lim\frac{\ln x}{1/x}=0$ |
| $\infty-\infty$ | 通分/有理化 | $\lim_{x\to\infty}(\sqrt{x^2+x}-x)=\frac12$ |
| $1^\infty$ | 取对数变 $0\cdot\infty$ | $\lim_{x\to\infty}(1+\frac1x)^x=e$ |
| $\infty^0$ | 取对数 | $\lim_{x\to\infty}x^{1/x}=1$ |
| $0^0$ | 取对数 | $\lim_{x\to0^+}x^x=1$ |

**核心示范：$0\cdot\infty$ 型**。$\lim_{x\to0^+}x\ln x$——$x\to0$、$\ln x\to-\infty$，乘积是不定式。把 $x$ 挪到分母：

$$\lim_{x\to0^+}x\ln x=\lim_{x\to0^+}\frac{\ln x}{1/x}\quad(\text{现在是 }\frac\infty\infty\text{ 型}).$$

用洛必达：分子 $\frac1x$，分母 $-\frac1{x^2}$，比值 $=-x\to0$。故 $\lim_{x\to0^+}x\ln x=0$。

**三步拆解**：
- **第一步，识别类型**：$x\ln x$ 是 $0\times\infty$；
- **第二步，选变形**：把「趋于 0 的」搬到分母，制造 $\frac\infty\infty$ 型（或把「趋于 $\infty$ 的」搬到分母制造 $\frac00$ 型）——**选择哪一项搬家，取决于求导后哪边更简单**；
- **第三步，洛必达**：分子分母求导，$\frac{\frac1x}{-1/x^2}=-x\to0$。

**幂指型示范：$1^\infty$**。$\lim_{x\to\infty}(1+\frac1x)^x$ 是 $1^\infty$ 型。取对数：

$$\ln L=\lim_{x\to\infty}x\ln\left(1+\frac1x\right)=\lim_{x\to\infty}\frac{\ln(1+\frac1x)}{1/x}\quad(\frac00\text{ 型}).$$

洛必达：分子 $\frac{-\frac1{x^2}}{1+\frac1x}$，分母 $-\frac1{x^2}$，比值 $=\frac1{1+\frac1x}\to1$。故 $\ln L=1$，$L=e$。**第二重要极限被洛必达「重算」了一遍**——两种方法殊途同归，但洛必达提供了机械化路径。

> **辨析｜易错点：**取对数变形的关键点是**底数必须为正**（对数只在正数上有定义）。$0^0$ 型的 $x^x$ 在 $x>0$ 时有意义，取对数没问题；但若底数可取负（如 $(-x)^x$），对数法失效。另外，**洛必达不是万能的**：$\lim_{x\to\infty}\frac{x+\sin x}{x}$ 是 $\frac\infty\infty$，洛必达求导后 $\frac{1+\cos x}{1}$ 极限不存在，但原极限 $=1$（直接约分）。**洛必达失败 ≠ 极限不存在**，务必记住这条。

## 4 洛必达与之前方法的对比

把求极限的工具箱排开：

| 方法 | 适用 | 局限 |
| --- | --- | --- |
| 四则法则 + 代入 | 非不定式 | 不定式直接失效 |
| 约公因式 / 除以最高次 | 多项式型 $\frac00,\frac\infty\infty$ | 非多项式结构无效 |
| 夹逼 | 有界因子 | 需两边夹住 |
| 等价无穷小替换 | 乘除结构 | 加减禁用（§3.5） |
| 洛必达法则 | $\frac00,\frac\infty\infty$ 及归化型 | 导数比极限须存在 |

洛必达的最大优势是**机械化**：识别类型 → 变形 → 求导，三步循环。但它无法替代「判断极限是否真的存在」——求导后极限不存在时，答案悬而未决，需要回到其他方法。<span class="marginnote">在机器学习里，softmax 与 log-sum-exp 的数值稳定性计算（第四级《大模型部署》）也用到了「变形避免不定式」的思想：直接算 $\frac{e^{z_i}}{\sum e^{z_j}}$ 会溢出，减去最大值就变成 $\frac{e^{z_i-m}}{\sum e^{z_j-m}}$——这与洛必达「变形后再算」是同一类工程智慧。</span>

## 5 洛必达法则的边界

洛必达法则不是「极限的终点」，而是一把需要分寸的利器：

- **可逆性**：洛必达给出的是「若导数比极限存在，则原极限 = 它」。反方向不自动成立——原极限存在，导数比极限未必存在（振荡反例）。所以**使用前必须确认「导数比的极限」存在或趋于 $\pm\infty$**；
- **循环风险**：$\lim_{x\to\infty}\frac{e^x}{e^x+x}$ 若盲目洛必达会陷入循环（求导回到原样），需先约分 $\frac{e^x}{e^x+x}=\frac1{1+x/e^x}\to1$；
- **泰勒替代**：很多洛必达题目用泰勒展开（§6.4）更直观——当分子分母都能展开时，**主部一对比就出答案**，还避免了「洛必达失败」的尴尬。两条路互为备份。

## 6 小结

- **洛必达法则**：$\frac00$ 与 $\frac\infty\infty$ 型下，$\lim\frac fg=\lim\frac{f'}{g'}$（前提：导数比极限存在）；证明靠柯西中值定理。
- **三个前提**：确为不定式、$g'\ne0$、导数比极限存在——缺一不可。
- **七种归化**：$0\cdot\infty$ 搬家、$\infty-\infty$ 通分、幂指型取对数；各配一条示范。
- **失效不等于不存在**：洛必达失败时换夹逼或泰勒，勿断言发散。
- **工具箱对比**：洛必达是机械化主刀，但代入、夹逼、等价替换、泰勒各有用武之地。

在下一节，我们把「求导」推向极限：**泰勒公式**。洛必达只回答极限「等于多少」，泰勒公式则回答函数「能被多项式逼近得多好」——它把 $f$ 展开成 $\sum\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k$，是分析学最强、最通用的近似工具。
