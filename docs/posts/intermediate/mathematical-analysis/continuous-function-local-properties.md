# 连续函数的局部性质与四则运算、复合运算

## 为什么关心「连续函数的保值性」

上一节定义了「点连续」。但「定义」只是门票，真正的财富是**「连续函数的代数与复合运算仍连续」**这条保值链。有了它，我们不需要逐个验证每个函数——只要确认少数「种子函数」连续，就能用加减乘除、复合构造出铺天盖地的连续函数（多项式、有理函数、三角函数组合、$\sqrt{}$、$\ln$ 的复合……），它们自动继承连续性。

这是分析学里反复出现的方法论：**建立少数「种子」+ 一套「保值运算」，即可生成整个函数族。** 后面初等函数的连续性（§4.5）、幂级数、乃至深度学习的激活函数族，都遵循同一套路。<span class="marginnote">种子 + 运算生成全族——这个思想远不止于分析。线性代数里「基 + 线性组合」生成整个空间，深度学习里「基本激活 + 网络结构」生成函数逼近族，语法里「词素 + 生成规则」生成语言。连续性定理是你在数学里第一次系统见到这个「生成式」方法论。</span>

## 1 连续函数的局部性质

上一章「极限的局部性质」直接升级为连续版本：

**定理（局部性质）：设 $f$ 在 $x_0$ 连续。**
**局部有界性**：存在 $\delta>0,M>0$，使 $|x-x_0|<\delta$ 时 $|f(x)|\le M$；
**局部保号性**：若 $f(x_0)>0$，存在 $\delta>0$ 使 $|x-x_0|<\delta$ 时 $f(x)>0$（$f(x_0)<0$ 同理）；
**极限可置换**：若 $\lim_{x\to x_0}\varphi(x)=x_0'$ 且 $f$ 在 $x_0'$ 连续，则 $\displaystyle\lim_{x\to x_0}f(\varphi(x))=f(x_0')=f(\lim\varphi(x))$。

第三条是「**极限与连续函数可交换次序**」：连续函数可以「穿进」极限记号。这条性质在计算复合函数极限时几乎每天都要用——$\lim\sin(\varphi(x))=\sin(\lim\varphi(x))$，前提是外层函数在 $\lim\varphi(x)$ 处连续。<span class="marginnote">「极限可穿进连续函数」是分析里被使用频率最高的运算法则之一。它保证了：先取极限再套函数 = 先套函数再取极限。注意前提是外层<strong>连续</strong>——如果外层在关键点有跳跃，交换次序就失效，这正是第六章「函数与极限交换次序」类问题的敏感点。</span>

**示范（极限可穿进）**：$\lim_{x\to0}\sqrt{1+x}=\sqrt{\lim_{x\to0}(1+x)}=\sqrt1=1$。外层 $\sqrt{\cdot}$ 在 $1$ 处连续，所以根号可以穿进极限记号——若没有连续，这一步就非法。**「先取极限再开方」与「先开方再取极限」得到同一个数**，正是「极限与连续函数可交换」的日常体现。<span class="marginnote">「极限可置换」的证明其实很简单：$\varphi(x)\to x_0'$ 用 ε-δ 翻译成「$\varphi(x)$ 靠近 $x_0'$」，$f$ 在 $x_0'$ 连续翻译成「$f$ 在 $x_0'$ 附近受控」，两级一接就是「$f(\varphi(x))\to f(x_0')$」。它与复合连续的证明同构——本质上是同一件事的两种说法。</span>

**定理（四则运算保持连续）：若 $f,g$ 在 $x_0$ 连续，则 $f\pm g$、$fg$、$\frac fg$（$g(x_0)\ne0$ 时）都在 $x_0$ 连续。**

证明是「极限的四则法则 + 连续 = 极限等于值」一句带过：

$$\lim(f+g)(x)=\lim f(x)+\lim g(x)=f(x_0)+g(x_0)=(f+g)(x_0).$$

推论：**多项式处处连续**（有限个 $x^n$ 的线性组合），**有理函数 $\frac{P}{Q}$ 在其分母非零处连续**。这两个推论是「种子 + 运算」的第一次大丰收——整个初等函数连续性的版图从此展开。

> **辨析｜易错点：**局部保号性说的是「$f(x_0)>0$ ⇒ 附近 $f>0$」，反过来「$f(x_0)\ge0$」推不出「附近 $f>0$」——$f(x)=x^2$ 在 0 处 $f(0)=0$，但附近恒非负而不恒正。**「大于零」与「大于等于零」在保号性上待遇完全不同**：前者给「带余量的严格正」，后者只给「非负」。这个细微差别在证明极限四则运算（分母不为零）时很关键。

## 2 复合运算保持连续

**定理（复合保持连续）：若 $\varphi$ 在 $x_0$ 连续，$\varphi(x_0)=u_0$，$f$ 在 $u_0$ 连续，则复合函数 $f\circ\varphi$ 在 $x_0$ 连续。**

证明用 ε-δ 接力：由 $f$ 在 $u_0$ 连续，对任意 $\varepsilon>0$ 存在 $\eta>0$ 使 $|u-u_0|<\eta\Rightarrow|f(u)-f(u_0)|<\varepsilon$；又 $\varphi$ 在 $x_0$ 连续，对这个 $\eta$ 存在 $\delta>0$ 使 $|x-x_0|<\delta\Rightarrow|\varphi(x)-u_0|<\eta$。两级接力，得 $|x-x_0|<\delta\Rightarrow|f(\varphi(x))-f(\varphi(x_0))|<\varepsilon$。∎

> **辨析｜易错点：**复合连续的证明里，**外层给出 $\varepsilon\to\eta$，内层负责 $\eta\to\delta$**——内层连续性的「$\varepsilon$」恰是外层连续性的「$\delta$」。这个「参数接力」结构经常被初学搞反（拿外层当内层的输入）。记住口诀：**外层定精度，内层找范围。** 这条链在后面的「一致连续性」（§4.4）、隐函数定理（§18.1）中还会以更复杂的形式出现。

**应用示范**：$h(x)=e^{\sin x^2}$ 处处连续。种子函数 $x\mapsto x^2$、$u\mapsto\sin u$、$v\mapsto e^v$ 都在各自定义域连续，复合三次即得 $h$ 连续。**从三个种子出发，一句「复合保持连续」就完成了证明，无需任何 ε-δ。**

**再示范（复合可去）**：$k(x)=\sqrt{\frac{1-\cos x}{x^2}}$ 在 $x=0$ 附近。先看内层 $\frac{1-\cos x}{x^2}\to\frac12$（§3.4），外层 $\sqrt{\cdot}$ 在 $\frac12>0$ 处连续，故 $k(x)\to\sqrt{\frac12}$。**复合连续保证「外层接受内层的极限值」**——即使内层表达式在 0 处无定义，只要极限存在且落在外层定义域内，复合极限照样可算。

> **辨析｜易错点：**复合保持连续的反方向**不成立**：$f\circ g$ 在 $x_0$ 连续不能推出 $f$ 在 $u_0$ 连续或 $g$ 在 $x_0$ 连续。例：$g(x)=0$ 常值，$f(u)=\begin{cases}1,&u\ne0\\0,&u=0\end{cases}$——$f\circ g$ 恒为 0 处处连续，但 $f$ 在 0 处不连续。**连续性不会从复合的「结果」倒推回「因子」**，这是判别题常挖的坑。

**复合连续的深层含义**：它把「连续函数族」闭合成一个「可运算的类」——分析学里这种「对某种运算封闭」的类非常珍贵。到 §4.4 的一致连续，这个封闭性会打折扣；到第十二章的函数项级数，逐项取极限的封闭性甚至失效。**「保值链在哪一环断裂」往往标志着理论的边界**。

## 3 公式解析：复合函数极限的计算

复合保持连续性直接给出了求复合极限的「换元法」。看经典例：

$$\lim_{x\to0}\frac{\ln(1+x)}{x}.$$

直接套公式看不出门道，但令 $t=\ln(1+x)$，则 $x=e^t-1$，且 $x\to0$ 时 $t\to0$（因为 $\ln(1+x)$ 在 0 处连续）。于是

$$\lim_{x\to0}\frac{\ln(1+x)}{x}=\lim_{t\to0}\frac{t}{e^t-1}=\frac{1}{\lim_{t\to0}\frac{e^t-1}{t}}=\frac{1}{\ln e}=1.$$

**三步拆解**：

- **第一步，定换元**：$t=\ln(1+x)$，反解 $x=e^t-1$。选择换元的标准是让「难看的因子」变成「已知极限的形式」——这里把 $\ln(1+x)/x$ 换成 $(e^t-1)/t$ 的倒数。
- **第二步，验连续性**：$x\to0$ 时 $t\to0$，用的是 $\ln$ 在 $1$ 处连续（这是换元合法的前提，不能跳过）。
- **第三步，套已知极限**：$\lim_{t\to0}\frac{e^t-1}{t}=1$ 来自第二重要极限（§3.4），取倒数得答案 $1$。

**换元法** 与「复合保持连续」是同一个硬币的两面：换元即复合的逆运算。当直接计算困难时，找一个连续且「好反解」的中间变量，把极限翻译成已知形式——这个技巧在下一章的导数定义、以及定积分的换元法（§9.6）里会升级为正式的积分工具。<span class="marginnote">换元法的本质是「视角切换」：同样一个极限过程，换个自变量来度量，难看的结构可能变得人畜无害。这在概率论里叫「变量变换」（随机变量的函数），在数值分析里叫「变量代换」（改善积分精度）——同一个思想，换了无数件外衣。</span>

**示范二（换元解另一经典）**：$\lim_{x\to0}\frac{1-\cos x}{x^2}$。用半角公式 $1-\cos x=2\sin^2\frac x2$，原式 $=\lim_{x\to0}2\cdot\frac{\sin^2(x/2)}{(x/2)^2}\cdot\frac14=\frac12$。也可以令 $t=\frac x2$ 换元，$x\to0$ 时 $t\to0$，$\frac{\sin t}{t}\to1$——**两种写法（半角 + 换元）其实是同一次极限的两种视角**，都依赖「$t\to0$ 时 $\frac{\sin t}{t}\to1$」这个已知极限。

> **辨析｜易错点：**换元求极限的合法性 = 「$x\to x_0$ 时 $t\to t_0$」+「外层在 $t_0$ 连续（或极限存在）」。若 $t$ 在过程中取不到 $t_0$ 附近的值（如换元后 $t$ 恒为常数），换元可能失效。**先验证明「$t$ 随 $x$ 趋向 $t_0$」，再谈套用已知极限**——顺序不能省。

## 4 连续函数族的扩张图

把「种子 + 保值运算」的版图画出来：

| 运算 | 种子 | 生成的函数族 |
| --- | --- | --- |
| 加、减、乘 | 常值、$x$ | 多项式 |
| 商 | 多项式 | 有理函数（去零点） |
| 根式 | $x\mapsto\sqrt[n]x$ | 代数函数 |
| 复合 | 以上 + 三角、指数、对数 | 初等函数的全部 |

每一个箭头都来自本节的一条保值定理。到 §4.5，我们将走完最后一步：确认三角、指数、对数这些「种子」自身连续，然后「初等函数在其定义域内连续」这个总定理就水到渠成。

**连续性的保值链总览**：

| 运算 | 保值定理 | 生成的函数 |
| --- | --- | --- |
| 加减 | 四则（$f\pm g$） | 多项式 |
| 乘除 | 四则（$fg,\ f/g$） | 有理函数 |
| 复合 | 复合保持连续 | 复合函数 |
| 穿极限 | 极限可置换 | 复合极限的计算 |

**四条定理是本节的全部家当**：加法、乘法、商、复合、穿极限——连续函数的「运算免疫力」由它们构成。记住这张表，§4.5 的总定理就只剩「确认种子」这一步。

**为什么要「先确认种子连续」**：保值运算只负责「从连续到连续」，不负责「从无到有」。若种子函数自身不连续（如 $\operatorname{sgn}$），乘除复合也救不回。§4.5 将逐一确认三角、指数、对数等种子的连续性——**种子连续是保值链条的起点，缺了它，整座函数族大厦无地基**。

## 5 小结

- **局部性质**：局部有界性、局部保号性、极限可穿进连续函数（$\lim f(\varphi)=f(\lim\varphi)$）。
- **四则保值**：连续函数加减乘除仍连续（商需分母非零）⇒ 多项式处处连续、有理函数去零点连续。
- **复合保值**：外层定精度、内层找范围；参数接力 ε-δ 证明。
- **换元法**：求复合极限用「连续换元」，$x\to0$ 时 $\ln(1+x)\sim x$ 由此得证。
- **方法论**：种子 + 保值运算 = 生成整个连续函数族。
- **示范**：$\sqrt{1+x}$、$\sqrt{(1-\cos x)/x^2}$ 的极限——「连续函数穿进极限」的实操。
- **反方向陷阱**：$f\circ g$ 连续推不出 $f$ 或 $g$ 连续——连续性不「倒流」。
- **种子先行**：保值运算只保「连续到连续」，种子自身连续靠 §4.5 逐一定案。
- **保值链总览**：加、乘、除、复合、穿极限——五条定理构成连续函数的全部「运算免疫力」。
- **方法论收获**：种子 + 保值 = 函数族；同一套路在幂级数、深度学习激活函数族里反复出现。

在下一节，我们离开「一点连续」，来到「区间上的整体性质」：**闭区间上的连续函数必有界、必有最大值最小值、必穿过一切中间值**。这三条性质是连续函数最深刻的整体结论，也是第四章后半段的绝对主角。
