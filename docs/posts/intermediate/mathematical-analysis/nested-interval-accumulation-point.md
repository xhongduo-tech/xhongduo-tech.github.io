## 为什么研究「嵌套区间」与「凝聚点」

完备性链的第二环，是区间套定理与聚点定理。它们各自回答一个问题：

- **区间套**：一列闭区间 $[a_n,b_n]$ 依次嵌套（$[a_{n+1},b_{n+1}]\subset[a_n,b_n]$）且长度趋于 0，是否必有一个点属于所有区间？——**是**，且唯一。
- **聚点**：一个无穷点集，即使没有收敛数列（如全体有理数），是否必有「凝聚中心」？——**是**，聚点总是存在的。

前四章的证明里它们已经多次客串：介值定理用区间套找零点，最值定理用致密性挖子列。这一节把它们的完整形态摆上台面，并纳入完备性等价链。<span class="marginnote">区间套定理的直觉是「俄罗斯套娃」：套娃一层套一层，且每层都缩小到任意小——那么所有套娃共享一个「最小核心」。闭区间条件至关重要：若是开区间 $(0,\frac1n)$，它们的公共交集是空集（0 不在任何开区间里），定理失效。<strong>「闭」保证公共点被含住，「长度→0」保证唯一。</strong></span>

## 1 区间套定理

**区间套（nested intervals）**：一列闭区间 $[a_n,b_n]$ 满足 $[a_{n+1},b_{n+1}]\subset[a_n,b_n]$（$n=1,2,\dots$），即 $a_n\le a_{n+1}\le b_{n+1}\le b_n$。

**定理（区间套定理 / Nested Interval Theorem）：若 $\{[a_n,b_n]\}$ 是区间套，则存在一点 $\xi$ 属于所有区间；若再设长度 $b_n-a_n\to0$，则这样的 $\xi$ 唯一，且 $a_n\to\xi$、$b_n\to\xi$。**

**证明**：左端点列 $\{a_n\}$ 单调递增（$a_{n+1}\ge a_n$）且有上界（被 $b_1$ 上界住），由单调有界定理收敛于 $\xi_1$；右端点列 $\{b_n\}$ 单调递减且有下界（被 $a_1$ 下界住），收敛于 $\xi_2$。又对一切 $n$，$a_n\le b_n$，取极限得 $\xi_1\le\xi_2$。故 $\xi_1,\xi_2$ 之间的任何点都属于所有区间（因为 $a_n\le\xi_1\le\xi_2\le b_n$）。若 $b_n-a_n\to0$，则 $\xi_1=\xi_2=\xi$ 唯一，且 $a_n\to\xi,\ b_n\to\xi$。∎

> **辨析｜易错点：**「闭区间」与「长度趋于 0」是两个独立的条件，各有作用。**闭区间保证公共点存在**（开区间 $(0,\frac1n)$ 没有公共点）；**长度趋于 0 保证公共点唯一**（若长度不趋于 0，如 $[0,1+\frac1n]$，公共点有无穷多个）。定理最常用的形态是两个条件都满足：**唯一的公共点 = 两端点列的公共极限**。这正是二分法（§4.3、§6.7）每次求根时在悄悄使用的结论。

**区间套定理是「找存在点」的瑞士军刀**：要证「存在 $\xi$ 满足某性质」，就构造一族「越来越精确」的闭区间，让 $\xi$ 被套在公共交集里。介值定理的零点、不动点定理的固定点、后续一致连续与积分理论，都依赖它。

## 2 聚点与聚点定理

**聚点（accumulation point）**：设 $S$ 是数集，$x_0$ 是实数。若 $x_0$ 的**任意去心邻域**都含有 $S$ 中的点，则称 $x_0$ 是 $S$ 的**聚点**。

> **辨析｜易错点：聚点 vs 极限点 vs 孤立点。** 聚点**不要求属于 $S$**：$x_0=1$ 是开区间 $(0,1)$ 的聚点，但 $1\notin(0,1)$。**聚点也不要求 $S$ 中有点等于它**：集合 $\{1,2,\dots\}$ 的聚点可以是 $\infty$（无聚点）。与「极限」的区别：数列极限要求「$x_0$ 附近的所有点都在 $S$ 中（从某处起）」，聚点只要求「任意近处都**能碰见** $S$ 的点」——更弱。孤立点是「有邻域不含其他点」的点，不是聚点；有限集没有聚点。

**聚点的等价刻画**：$x_0$ 是 $S$ 的聚点 ⇔ 存在 $S$ 中两两不同的点列 $x_n\to x_0$。这个刻画把「聚点」翻译成「收敛点列的存在」，是证明与应用的桥梁。

**聚点定理（Bolzano-Weierstrass 的第一形态）：有界无穷点集必有聚点。**

**证明**：设 $S$ 有界，包含于 $[a,b]$。二分区间：若 $[a,\frac{a+b}{2}]$ 含有 $S$ 的无穷多点，取该半区间；否则另一半含无穷多点（因为整个 $S$ 无穷）。得到区间套 $[a_n,b_n]$，每段含 $S$ 无穷多点。由区间套定理，公共点 $\xi$ 存在。对任意去心邻域 $(\xi-\varepsilon,\xi+\varepsilon)$，取 $n$ 使区间长度 $<\varepsilon$，则该区间含 $S$ 无穷多点且整个落在邻域内——$\xi$ 是聚点。∎

**这是致密性定理（§7.3）的「集合版」**：致密性说「有界数列有收敛子列」，聚点定理说「有界无穷集有聚点」——两个表述通过「聚点 ⟺ 收敛点列」互相翻译。<span class="marginnote">聚点定理的证明再次是「二分构造 + 区间套」：把「无穷多点」这个信息逐层传递到半区间，最后把无穷多点压缩到一个点上。这套「无穷信息压缩」的手法，在实变函数论（第二级《实变函数与测度论》）里会被推向极致——测度、稠密性、康托尔集都在用「压缩无穷」的思维。</span>

## 3 公式解析：区间套定理的证明链

以「用区间套证聚点定理」为完整示范，拆成四步：

**第一步，造区间套。** $S\subset[a_1,b_1]$，二分取「含 $S$ 无穷多点」的半区间 $[a_2,b_2]$，归纳得 $[a_n,b_n]$，每段含 $S$ 无穷多点且长度 $\frac{b_1-a_1}{2^{n-1}}\to0$。

**第二步，取公共点。** 由区间套定理，$a_n,b_n\to\xi$，$\xi$ 属于所有区间。

**第三步，验证聚点身份。** 任取 $\varepsilon>0$，选 $n$ 使 $b_n-a_n<\varepsilon$，则 $[a_n,b_n]\subset(\xi-\varepsilon,\xi+\varepsilon)$。该区间含 $S$ 无穷多点，故 $S$ 在 $\xi$ 的任意去心邻域内有值。

**第四步，收口。** 由聚点定义，$\xi$ 是 $S$ 的聚点。∎

**要点**：每一步都在「把无穷信息向更小范围传递」——区间套负责收缩，无穷多点负责保证「每层都有料」，聚点定义负责收口。**四步链是完备性证明的标准节奏：构造 → 取极限 → 验身份 → 收口。**

## 4 区间套与聚点在分析学中的角色

两条定理的用途清单：

| 定理 | 找什么 | 典型使用场景 |
| --- | --- | --- |
| 区间套 | 唯一公共点 | 介值定理零点、二分法、中值定理证明 |
| 聚点定理 | 无穷点集的凝聚点 | 有界无穷集必有「极限点」、致密性证明 |

**介值定理**（§4.3）：二分保号区间 → 区间套 → 零点；
**最值定理**（§4.3）：上确界序列 → 子列收敛 → 最值点；
**一致连续性**（§4.4）：反证 → 子列收敛 → 矛盾；
**§7.3 致密性**：有界数列必有收敛子列——聚点定理的数列版本。

几乎每一处「存在 $x$」的证明，都能在「区间套」或「聚点/子列」中找到工具。它们与确界原理、有限覆盖一起，构成分析学的「存在性四件套」。<span class="marginnote">「存在性四件套」——确界、区间套、聚点/子列、有限覆盖——在拓扑学里各有抽象版本：完备性、紧性、列紧性、覆盖紧性。第二级《拓扑学》会告诉你：在一般的度量空间里这四者未必等价（要加条件），而「它们何时等价」恰是紧性理论的中心问题。今天在实数里看到的美妙等价，是那个一般理论的第一个样板。</span>

## 5 小结

- **区间套定理**：嵌套闭区间列必有公共点；长度趋于 0 时唯一，且为端点列公共极限。
- **「闭」保存在、「趋于 0」保唯一**——两个条件独立分工，缺一不可。
- **聚点**：任意去心邻域都含集合点的数；不必属于集合；⟺ 存在收敛点列。
- **聚点定理**：有界无穷点集必有聚点；证明用「二分构造 + 区间套」压缩无穷信息。
- **应用谱系**：介值、最值、一致连续、致密性——存在性证明的四件套之二。

在下一节，完备性链进入第三环：**致密性定理（波尔查诺—魏尔斯特拉斯）与有限覆盖定理（海涅—博雷尔）**。一个说「有界数列必挖得出收敛子列」，一个说「闭区间的开覆盖必有有限子覆盖」——两条看似无关的定理，将在等价链中正面相遇。
