# 无穷小量与无穷大量：阶的比较与等价无穷小替换

<div class="epigraph">

## 为什么需要「阶」

上一节我们见到 $\sin x\sim x$（$x\to0$）——两个无穷小量「差不多一样快」地趋向零。但更多时候，无穷小量**快慢不同**：$x^2$ 比 $x$ 更快地奔向 0，$x^3$ 更快，$e^{-1/x^2}$ 快到「远超任何幂」。要精确描述这些速度差异，就需要「**阶**」的概念。

「阶」的价值在于**化简**：极限计算中，把一个复杂的无穷小量换成与它「同阶」或「等价」的简单无穷小，往往一步到位。同时，「阶」也是泰勒展开（§6.4）的直觉入口——展开式的每一项，就是不同阶的无穷小的叠加。<span class="marginnote">把无穷小比作「奔向 0 的赛跑」，阶就是它们的速度等级：$x^2$ 是 $x$ 的「2 倍速」，$\sin x$ 与 $x$ 是「同速」。当多个无穷小同场竞技（如 $\lim\frac{\sin x}{x^2}$），只有「最快的主导项」决定结果——这正是等价替换背后的物理直觉。</span>

## 1 无穷小量与无穷大量

**无穷小量**：若 $\displaystyle\lim_{x\to x_0}f(x)=0$，称 $f$ 为 $x\to x_0$ 时的**无穷小量**。

> **辨析｜易错点：**无穷小量**不是「很小的数」**，而是「在过程中趋于 0 的变量」。$10^{-100}$ 是个常数，不是无穷小；只有 $f(x)\to0$ 这种「动态趋向零」才是。另外，**0 也是无穷小量**（常值 0 处处趋于 0），它是唯一的常值无穷小。

**无穷大量**：若对任意 $M>0$，存在 $\delta>0$ 使 $0<|x-x_0|<\delta$ 时 $|f(x)|>M$，称 $f$ 为 $x\to x_0$ 时的**无穷大量**，记作 $\lim f=\infty$。类似定义 $+\infty,-\infty$ 的情形。

无穷小与无穷大有对偶关系：**若 $f$ 是无穷小（且局部 $f\ne0$），则 $\frac1f$ 是无穷大；反之亦然。** 这条对偶让两类问题可以互相转化。

**无穷小的运算性质**：

有限个无穷小之和仍是无穷小；
无穷小与有界函数之积仍是无穷小（**「有界 × 无穷小 = 无穷小」**，§3.2 的预告在此兑现）；
无穷小与常数之积仍是无穷小。

这三条是极限计算的「隐形基础设施」。特别是第二条，它让 $\lim_{x\to0}x\sin\frac1x=0$ 这种「震荡 × 趋于零」的极限无需夹逼就能秒解。

## 2 无穷小的阶

设 $f,g$ 都是 $x\to x_0$ 时的无穷小，且 $g$ 在去心邻域内非零。比较 $\frac{f}{g}$ 的极限行为：

若 $\displaystyle\lim\frac{f}{g}=0$，称 $f$ 是比 $g$ **高阶的无穷小**，记作 $f=o(g)$（$f$ 比 $g$ 更快趋于 0）；
若 $\displaystyle\lim\frac{f}{g}=c\ne0$，称 $f$ 与 $g$ **同阶**，记作 $f=O(g)$（双向）；
若 $\displaystyle\lim\frac{f}{g}=1$，称 $f$ 与 $g$ **等价**，记作 $f\sim g$；
特别地，若 $f$ 与 $(x-x_0)^k$ 同阶（$k>0$），称 $f$ 为 **$k$ 阶无穷小**。

记号 $o(g)$ 读作「$g$ 的小欧」，$O(g)$ 读作「$g$ 的大欧」——这两个记号在数值分析、算法复杂度里是常客，数学家借用了同一套「阶」的语言。<span class="marginnote">$o$ 与 $O$ 记号出自兰道（Landau），后来被算法分析借用：第四级《算法设计与分析》里的 $O(n\log n)$、$o(n^2)$ 正是同一套语言。无穷小的阶与算法复杂度的阶，共享「谁更快趋向极限（0 或 $\infty$）」的比较逻辑——学一个，两个都通。</span>

**等价无穷小的常用库**（$x\to0$ 时）：

$$\sin x\sim x,\quad \tan x\sim x,\quad 1-\cos x\sim\frac{x^2}{2},\quad \ln(1+x)\sim x,\quad e^x-1\sim x,\quad \arctan x\sim x,\quad (1+x)^\alpha-1\sim\alpha x.$$

其中 $\ln(1+x)\sim x$ 与 $e^x-1\sim x$ 来自两个重要极限的变形，$1-\cos x\sim\frac{x^2}{2}$ 则预告了泰勒展开的二次项。这张表是整个「极限化简」的弹药库。

## 3 公式解析：等价无穷小替换定理

**定理（等价替换）：若 $x\to x_0$ 时 $\alpha\sim\alpha'$ 且 $\beta\sim\beta'$，则**

$$\lim\frac{\alpha}{\beta}=\lim\frac{\alpha'}{\beta'},\qquad\lim\alpha\gamma=\lim\alpha'\gamma\ (\text{当 } \gamma \text{ 存在时}).$$

证明只需一句话：因为 $\alpha=\alpha'\cdot\frac{\alpha}{\alpha'}$ 且 $\frac{\alpha}{\alpha'}\to1$，所以

$$\lim\frac{\alpha}{\beta}=\lim\frac{\alpha'}{\beta'}\cdot\frac{\alpha/\alpha'}{\beta/\beta'}=\lim\frac{\alpha'}{\beta'}.$$

等价替换的本质是：**在乘积与商的极限里，因子可以换成与之等价的无穷小而不改变结果。** 因为「等价」保证了两者只差一个趋于 1 的因子，而乘积里趋于 1 的因子可以忽略。

> **辨析｜易错点（最重要的一条）：**等价替换**只适用于「因子」（乘除结构），绝不适用于「项」（加减结构）**。看反例：
>
> `$$`\lim_{x\to0}\frac{\tan x-\sin x}{x^3}.$$
>
> 若对分子里的 $\tan x$ 与 $\sin x$ 分别替换成 $x$ 与 $x$，得 $\frac{x-x}{x^3}=0$——**这是错的**！正确答案须用泰勒展开：$\tan x-\sin x=x+\frac{x^3}{3}-\bigl(x-\frac{x^3}{6}\bigr)+o(x^3)=\frac{x^3}{2}+o(x^3)$，故极限 $=\frac12$。**加减里的替换抹掉了被抵消的高阶项，直接把答案偷走了。** 口诀：**「乘除大胆换，加减要谨慎——除非能整体化成一个因子。」**

## 4 无穷大的阶与主部思想

无穷大的比较与无穷小完全平行：设 $\lim f=\lim g=\infty$，若 $\lim\frac fg=0$，称 $f$ 是比 $g$ **低阶**的无穷大；若 $\lim\frac fg=\infty$，称 $f$ 是**高阶**；若 $\lim\frac fg=c\ne0$，同阶；$c=1$ 等价。

无穷大的标准谱系（$x\to+\infty$）：

$$\ln x\ \ll\ x^\alpha\ \ll\ a^x\ \ll\ x!\ \ll\ x^x\qquad(\alpha>0,\ a>1).$$

「$\ll$」表示「远慢于」：$\ln x$ 增长最慢，幂次居中，指数爆炸，阶乘与 $x^x$ 是终极怪物。这条链是「**增长层级**」的精华，在算法复杂度、概率论的尾部估计里无处不在。

**主部思想**：求 $\lim_{x\to+\infty}\frac{x^3+2x^2+1}{x^3-5x}$ 这类无穷大比无穷大，只需比较**最高次主部**：

$$\lim\frac{x^3+2x^2+1}{x^3-5x}=\lim\frac{1+2/x+1/x^3}{1-5/x^2}=1.$$

**低阶项在极限中被主部吞没**——这是「除以最高次」技巧的理论依据，也与等价替换是同一哲学的两面：加减被主部主导，乘积可换等价。

## 5 把「阶」穿成一条线

「阶」的概念贯穿分析学全程：

- **§3.5 这里**：无穷小的阶、等价替换——极限计算的化简语言；
- **§6.4 泰勒公式**：$f(x)=a_0+a_1x+\cdots+a_nx^n+o(x^n)$ 的余项记号 $o(x^n)$，就是高阶无穷小的标准记法——泰勒展开本质是「把函数按无穷小的阶逐级分解」；
- **数值分析**：截断误差的阶（$O(h^2)$ 格式比 $O(h)$ 格式更精确）直接决定算法收敛速度；
- **随机过程/概率**：$P(X>t)\sim t^{-\alpha}$ 的尾部等价式决定厚尾分布。

每一个地方，「阶」都在回答同一个问题：**当某量趋于极限时，各项谁主谁次、快多少倍。** 掌握了今天这张图，后面所有 $o$ 记号都不会再陌生。

## 6 小结

- **无穷小/无穷大**：动态趋向 0 / $\infty$ 的变量，不是「很小的数」；两者互为倒数对偶。
- **阶的定义**：高阶 $o$、同阶 $O$、等价 $\sim$、$k$ 阶无穷小；核心比较是 $\lim\frac fg$ 的取值。
- **等价替换**：乘除里大胆换因子，结果不变；**加减里禁止替换**（$\frac{\tan x-\sin x}{x^3}$ 是经典陷阱）。
- **常用等价表**：$\sin x\sim x$、$1-\cos x\sim\frac{x^2}2$、$\ln(1+x)\sim x$、$e^x-1\sim x$ 等。
- **主部思想**：极限被主部主导，低阶项被吞没；这是「除以最高次」与泰勒展开的共同哲学。
