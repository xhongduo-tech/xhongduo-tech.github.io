# 数学分析

数学分析是严格化的微积分，以 ε-δ 语言和实数完备性为基石，重建极限、连续、微分、积分与级数的整个证明体系。本分类对标华东师范大学《数学分析》章节体系，与面向工程应用的《高等数学》（同济）形成互补：那里重计算，这里重证明。
