# 二元函数的泰勒公式与中值定理

<div class="epigraph">
<p>多元泰勒展开把函数在一点附近写成「常数 + 线性项 + 二次项 + …」——其中的二次项由黑塞矩阵编码，它决定了函数的局部形状。</p>

## 为什么多元需要「泰勒公式」

一元泰勒公式（§6.4）是「用多项式逼近函数」的引擎。多元同样需要：判断极值（§17.5）要看二阶项，误差分析要看余项，优化算法的收敛性分析要看展开。**多元泰勒公式的结构与一元完全平行，只是「导数」变成「偏导数矩阵」，「$(x-x_0)^k$」变成「方向向量的幂」**。

最关键的新对象是**黑塞矩阵**——它编码了「二阶偏导数的全部信息」，是多元函数的「二阶导数」。黑塞矩阵不仅出现在泰勒展开里，更是多元极值判别（§17.5）、牛顿法（第二级《最优化理论》）的核心。<span class="marginnote">「方向导数的泰勒展开」给出最优雅的表述：设 $\vec h=(h_1,h_2)$ 是增量方向，则 $f(P_0+\vec h)$ 沿方向 $\vec h$ 的展开为 $f(P_0)+(\nabla f\cdot\vec h)+\frac12(\vec h^T H\vec h)+o(|\vec h|^2)$。<strong>一阶项是「梯度 × 方向」，二阶项是「方向的二次型（黑塞）」</strong>——这解释了为什么牛顿法用「黑塞矩阵修正梯度方向」：它同时利用了函数的一阶与二阶形状。你在第二级《最优化理论》里学牛顿法时，会发现它就是「多元泰勒到二阶 + 求驻点」。</span>

## 1 高阶偏导数与黑塞矩阵

**二阶偏导数**：$f_{xx}=\frac{\partial^2 f}{\partial x^2}$、$f_{yy}$、以及**混合偏导数** $f_{xy}=\frac{\partial}{\partial y}\left(\frac{\partial f}{\partial x}\right)$、$f_{yx}$。

**定理（混合偏导数的可交换性 / Clairaut's Theorem）：若 $f_{xy},f_{yx}$ 在 $P_0$ 连续，则 $f_{xy}(P_0)=f_{yx}(P_0)$。**

**混合偏导可交换**——在「二阶偏导连续」的温和条件下，求导顺序无关。这是对称性的来源。

**黑塞矩阵（Hessian matrix）**：

$$H=\begin{pmatrix}f_{xx}&f_{xy}\\f_{yx}&f_{yy}\end{pmatrix}.$$

由可交换性，$f_{xy}=f_{yx}$，**黑塞矩阵是对称矩阵**——这是它能够「对角化」、判断正定性（§17.5）的前提。

> **辨析｜易错点：**混合偏导可交换**不是自动成立**的——需要「$f_{xy}$ 连续」的额外条件。反例：$f(x,y)=\frac{x^2-y^2}{x^2+y^2}\cdot xy$（补 $f(0,0)=0$），在原点 $f_{xy}(0,0)=-1$ 但 $f_{yx}(0,0)=1$——**不连续时混合偏导可以不同**。「$f_{xy}=f_{yx}$」的默认假设在病态函数上失效，好在实际问题几乎总满足连续条件。

## 2 多元泰勒公式

**定理（二元函数的泰勒公式）：设 $f$ 在含 $P_0$ 的邻域内有直到 $n+1$ 阶连续偏导数，则对 $P=P_0+\vec h$：**

$$f(P)=f(P_0)+\left(f_x\Delta x+f_y\Delta y\right)+\frac{1}{2!}\left(f_{xx}\Delta x^2+2f_{xy}\Delta x\Delta y+f_{yy}\Delta y^2\right)+\cdots+R_n,$$

**二阶情形显式写出**：

$$f(x_0+\Delta x,y_0+\Delta y)=f(x_0,y_0)+f_x\Delta x+f_y\Delta y+\frac12\left(f_{xx}\Delta x^2+2f_{xy}\Delta x\Delta y+f_{yy}\Delta y^2\right)+o(\rho^2).$$

**公式解析：三步拆解**

**第一步，方向化**。令 $\vec h=(\Delta x,\Delta y)$，则一阶项 $f_x\Delta x+f_y\Delta y=\nabla f\cdot\vec h$——**梯度 × 方向**；

**第二步，二阶项是二次型**。$\frac12(f_{xx}\Delta x^2+2f_{xy}\Delta x\Delta y+f_{yy}\Delta y^2)=\frac12\vec h^T H\vec h$——**黑塞矩阵夹在方向向量之间**（$\vec h^T H\vec h$ 是二次型）；

**第三步，余项**。$o(\rho^2)$（佩亚诺型）或含 $n+1$ 阶偏导的拉格朗日型——与一元平行。

**要点**：**多元泰勒 = 一元泰勒的「方向向量 + 矩阵」版本**：常数项（函数值）、线性项（梯度）、二次项（黑塞二次型）、高阶项。**黑塞矩阵编码了函数的「弯曲」**——正如梯度编码了「倾斜」。

**示范**：$f(x,y)=x^2y$ 在 $(1,1)$ 展开到二阶。$f(1,1)=1$，$\nabla f=(2xy,x^2)=(2,1)$，$H=\begin{pmatrix}2y&2x\\2x&0\end{pmatrix}=\begin{pmatrix}2&2\\2&0\end{pmatrix}$。

$$f(1+\Delta x,1+\Delta y)\approx1+2\Delta x+\Delta y+\frac12(2\Delta x^2+4\Delta x\Delta y)=\ 1+2\Delta x+\Delta y+\Delta x^2+2\Delta x\Delta y.$$

## 3 多元中值定理

**定理（多元中值定理）：设 $f$ 在有界开区域 $D$ 内连续可微（偏导数连续），$P,Q\in D$ 且线段 $PQ\subset D$，则存在 $\xi$ 在线段 $PQ$ 上，使**

$$f(Q)-f(P)=\nabla f(\xi)\cdot(Q-P).$$

**证明（化归一元）**：把 $P,Q$ 连成参数线段 $\varphi(t)=P+t(Q-P)$（$0\le t\le1$），则 $g(t)=f(\varphi(t))$ 是一元函数。由一元中值定理（§6.1），存在 $\tau\in(0,1)$ 使

$$g(1)-g(0)=g'(\tau).$$

由链式法则 $g'(t)=\nabla f(\varphi(t))\cdot(Q-P)$，代入即得。∎

**公式解析：三步拆解**

- **第一步，参数化线段**：$\varphi(t)=P+t(Q-P)$——把「$P$ 到 $Q$」变成「$t$ 从 0 到 1」；
- **第二步，化一元**：$g(t)=f(\varphi(t))$ 是一元函数，套一元中值定理；
- **第三步，链式还原**：$g'(\tau)=\nabla f(\xi)\cdot(Q-P)$——**中值公式 = 梯度在某点的投影 × 位移**。

**要点**：**多元中值定理 = 一元中值定理 + 参数化 + 链式法则**——「沿线段取一元切片」是多元问题化一元的万能手法。注意：**$\xi$ 在某条线段上（不是任意点），且公式是「梯度内积位移」而非「单个导数乘位移」**。

## 4 泰勒公式的应用

**应用一：二次近似的局部形状**。$f$ 在驻点（$\nabla f=0$）附近，$f\approx f_0+\frac12\vec h^T H\vec h$——**局部形状完全由黑塞二次型决定**：$H$ 正定（谷形）、负定（峰形）、不定（鞍形）。这正是 §17.5 极值判别的数学内核。

**应用二：误差分析**。一元里 $|\Delta f|\approx|f'||\Delta x|$；多元里

$$|\Delta f|\le|\nabla f||\vec h|+\frac12|H|_{\text{范数}}|\vec h|^2+\cdots$$

——**误差被梯度和黑塞的范数控制**。这用于数值方法的误差界（第二级《数值分析》）与优化算法的收敛分析。

**应用三：牛顿法的二阶修正**。最小化 $f$：用二阶泰勒近似 $f(P+\vec h)\approx f(P)+\nabla f\cdot\vec h+\frac12\vec h^T H\vec h$，对 $\vec h$ 求驻点（对 $\vec h$ 求导令为零）：

$$\vec h=-H^{-1}\nabla f,$$

**牛顿步**。它比梯度下降多用了黑塞矩阵，收敛更快（二阶），但每次要算 $H^{-1}$（代价高）。<span class="marginnote">「牛顿步 $\vec h=-H^{-1}\nabla f$」是优化理论的巅峰之一：一阶方法（梯度下降）每次走「最陡下降」，二阶方法（牛顿法）走「二次近似的驻点」——在凸二次函数上一步到位。但 $H$ 是 $n\times n$ 矩阵，$n=10^6$ 时求逆不可行，于是有了拟牛顿法（BFGS、L-BFGS，用低秩更新近似 $H^{-1}$）。第四级《机器学习》里的优化器、第二级《最优化理论》的牛顿系列，都是今天这条公式的后裔。</span>

## 5 泰勒公式的谱系

| | 一元 | 多元 |
| --- | --- | --- |
| 一阶项 | $f'(x_0)\Delta x$ | $\nabla f\cdot\vec h$ |
| 二阶项 | $\frac12f''\Delta x^2$ | $\frac12\vec h^T H\vec h$ |
| 余项 | $\frac{f^{(n+1)}(\xi)}{(n+1)!}\Delta x^{n+1}$ | 高阶梯度的张量 |
| 中值定理 | $f(b)-f(a)=f'(\xi)(b-a)$ | $f(Q)-f(P)=\nabla f(\xi)\cdot(Q-P)$ |

**「导数→梯度、二阶导→黑塞、乘积→内积/二次型」**——这是从一元到多元的完整翻译表。

## 6 小结

- **黑塞矩阵**：$H=\begin{pmatrix}f_{xx}&f_{xy}\\f_{yx}&f_{yy}\end{pmatrix}$，对称（混合偏导可交换，需连续）。
- **多元泰勒**：$f=f_0+\nabla f\cdot\vec h+\frac12\vec h^T H\vec h+o(\rho^2)$——梯度 + 黑塞二次型。
- **混合偏导可交换**：$f_{xy}=f_{yx}$（连续时）；病态反例 $f_{xy}\ne f_{yx}$。
- **多元中值定理**：$f(Q)-f(P)=\nabla f(\xi)\cdot(Q-P)$——参数化 + 一元中值 + 链式。
- **应用**：极值判别（黑塞定号）、误差分析、牛顿法 $h=-H^{-1}\nabla f$。

在下一节，我们进入本章收官：**多元函数的极值——必要条件与黑塞矩阵判别法**。梯度为零（驻点）是必要条件，黑塞矩阵的正负定性决定极大、极小还是鞍点。
