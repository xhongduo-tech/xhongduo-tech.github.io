## 为什么它是「基本定理」

定积分定义给出了「面积」的严格意义，但真按定义计算，每道题都要做「分割—求和—取极限」，累死人。而求原函数（不定积分）恰好是**已解决**的问题——第八章攒了一整套积分表与技法。

**牛顿—莱布尼茨公式**（微积分基本定理的核心）把这些串起来：

$$\int_a^b f(x)\,dx=F(b)-F(a),\qquad F'=f.$$

**面积 = 原函数在端点的差。** 这句话看似平凡，却是整个微积分的枢纽：它把「几何」（面积）与「代数」（反导数）焊在一起。没有它，定积分只是概念玩具；有了它，定积分才成为可计算的引擎。<span class="marginnote">为什么「基本」？因为它把微积分的两半——微分与积分——确认为<strong>互逆运算</strong>。牛顿与莱布尼茨在 17 世纪 70 年代各自独立发现了它（牛顿用流数、莱布尼茨用微分），引爆了微积分发明的优先权之争。但对数学而言，真正的胜利是：从此「求面积」这个古老难题，被化约成「查积分表」这件例行公事。</span>

## 1 微积分基本定理（第二部分）

**定理（牛顿—莱布尼茨公式 / Fundamental Theorem of Calculus, Part 2）：设 $f$ 在 $[a,b]$ 上可积，$F$ 是 $f$ 在 $[a,b]$ 上的一个原函数（$F'=f$），则**

$$\int_a^b f(x)\,dx=F(b)-F(a).$$

记法：$F(b)-F(a)$ 常写作 $\bigl[F(x)\bigr]_a^b$ 或 $F(x)\Big|_a^b$。

**证明（用定积分定义）**：对 $[a,b]$ 任取分割 $a=x_0<\cdots<x_n=b$，由中值定理（§6.1），在每个子区间 $[x_{i-1},x_i]$ 上存在 $\xi_i$ 使

$$F(x_i)-F(x_{i-1})=F'(\xi_i)(x_i-x_{i-1})=f(\xi_i)\Delta x_i.$$

把这些等式从 $i=1$ 加到 $n$（望远镜相消！）：

$$F(b)-F(a)=\sum_{i=1}^{n}\bigl[F(x_i)-F(x_{i-1})\bigr]=\sum_{i=1}^{n}f(\xi_i)\Delta x_i.$$

**左边与分割无关**，右边是黎曼和。令 $\|\Delta\|\to0$，右边趋于 $\int_a^bf$，左边不动，故 $\int_a^bf=F(b)-F(a)$。∎

**公式解析：证明的三步拆解**

- **第一步，中值定理搭桥**：$F(x_i)-F(x_{i-1})=f(\xi_i)\Delta x_i$——**每个子区间的增量 = 导数值 × 长度**，把「原函数的差」翻译成「被积函数的矩形」；
- **第二步，望远镜求和**：$F(x_1)-F(x_0)+F(x_2)-F(x_1)+\cdots$ 中间项全部相消，只剩 $F(b)-F(a)$——**这一手是证明的杠杆**，它把「区间上所有小段」压成一个「端点的差」；
- **第三步，黎曼和收口**：右端恰好是黎曼和，取极限即得定积分。

**证明的要害**：中值定理把「$F$ 在小区间的增量」与「$f$ 在该区间的某点值」配对，让黎曼和**恰好等于** $F(b)-F(a)$——所以两边取极限，等式保持不变。**「望远镜相消」是这份证明的灵魂**，它展示了为什么端点值如此重要。

## 2 用牛顿—莱布尼茨公式计算

公式让定积分计算变成「两步走」：**求原函数 → 代上下限**。

**示范一**：$\displaystyle\int_0^1x^2\,dx=\left[\frac{x^3}{3}\right]_0^1=\frac13$——与 §9.1 用定义算的结果一致，但快了一个数量级。

**示范二**：$\displaystyle\int_0^\pi\sin x\,dx=\left[-\cos x\right]_0^\pi=-(-1)-(-1)=2$。几何意义：半个正弦拱的面积。

**示范三**：$\displaystyle\int_1^2\frac{dx}{x}=\left[\ln|x|\right]_1^2=\ln2-\ln1=\ln2$。

**示范四（带绝对值的积分）**：$\displaystyle\int_0^2|x-1|\,dx$。**被积函数含绝对值，必须先分区间去掉绝对值**：

$$\int_0^2|x-1|dx=\int_0^1(1-x)dx+\int_1^2(x-1)dx=\left[x-\frac{x^2}{2}\right]_0^1+\left[\frac{x^2}{2}-x\right]_1^2=\frac12+\frac12=1.$$

**区间可加性 + 分段去绝对值**，是含绝对值积分的标准处理。

> **辨析｜易错点：牛顿—莱布尼茨公式的前提是「$f$ 可积且 $F$ 是 $f$ 的原函数」。** 若 $f$ 有间断点，公式仍可能成立（如分段连续函数的原函数分段可写），但**必须小心断点处**：$f(x)=\operatorname{sgn}x$ 在 $[-1,1]$ 可积，其原函数不是单一的 $|x|$ 那么简单——$|x|$ 在 0 处不可导，不是处处导数等于 $\operatorname{sgn}$。**「找原函数」时若函数有间断，要逐段找并保证拼接连续**。另一陷阱：**代入上下限时要把原函数完整写好再代**，忘写负号、代错端点是最常见的低级错误。

## 3 牛顿—莱布尼茨公式的应用

**应用一：求「累积量」**。速度 $v(t)$ 从 $t_1$ 到 $t_2$ 的位移：$s(t_2)-s(t_1)=\int_{t_1}^{t_2}v(t)dt$——位置是速度的原函数。**物理里的「求总变化量」都是这条公式**。

**应用二：计算面积与体积**。曲线 $y=f(x)\ge0$ 与 $x=a,x=b$ 及 $x$ 轴围成的面积：$S=\int_a^bf(x)dx$。旋转体体积等（第十章）也全靠它。

**应用三：定积分的数值思想**。公式需要原函数——但 $e^{-x^2}$ 没有初等原函数，怎么办？回到定义，用数值积分（矩形、梯形、辛普森）逼近。**「有原函数用公式，没原函数用数值」**——这是工程计算的第一分流规则。<span class="marginnote">正态分布的概率 $P(a\le X\le b)=\frac1{\sqrt{2\pi}}\int_a^b e^{-x^2/2}dx$ 没有初等原函数，因此<strong>所有统计学教材都必须依赖数值积分表或误差函数 erf</strong>。第二级《概率论与数理统计》里查正态分布表，本质就是「用数值积分算了 $e^{-x^2}$ 的定积分」。牛顿—莱布尼茨公式在此「罢工」，却正是数值方法登场的舞台。</span>

## 4 微积分基本定理的两个部分

标准的微积分基本定理（FTC）分两部分，本节与 §9.5 各占其一：

| | 第一部分（§9.5） | 第二部分（本节） |
| --- | --- | --- |
| 内容 | 变上限积分 $F(x)=\int_a^x f$ 是 $f$ 的原函数 | $\int_a^b f=F(b)-F(a)$ |
| 方向 | 「积分求导回函数」 | 「函数积分靠原函数」 |
| 意义 | 连续 ⇒ 有原函数（存在性） | 定积分可计算（算法性） |

**两部分互为因果**：第一部分保证「连续函数的原函数存在」（所以「找原函数」有指望），第二部分把「原函数」用于「算定积分」。两半合璧，微积分的「微分—积分」互逆关系才完整成立。

## 5 计算示范：定积分的综合技巧

**示范五（分部积分型）**：$\displaystyle\int_0^1 xe^x\,dx=\bigl[xe^x\bigr]_0^1-\int_0^1 e^x\,dx=e-(e-1)=1$——**先用分部积分（§8.3）把 $xe^x$ 变成可积的 $e^x$，再套牛顿—莱布尼茨**。技巧与公式的分工：积分法负责「找原函数」，本公式负责「代端点」。

**示范六（恒等变形 + 对称性）**：$\displaystyle\int_0^{\frac\pi2}\sin^2x\,dx$。用 $\sin^2x=\frac{1-\cos2x}{2}$：

$$\int_0^{\frac\pi2}\sin^2x\,dx=\left[\frac{x}{2}-\frac{\sin2x}{4}\right]_0^{\frac\pi2}=\frac\pi4.$$

**示范七（分段线性）**：$\displaystyle\int_{-1}^1|x|\,dx=\int_{-1}^0(-x)\,dx+\int_0^1x\,dx=\frac12+\frac12=1$——**含 $|x|$ 的分段函数，以「折点」为界拆区间**，与示范四同法。

**示范八（几何即答案）**：$\displaystyle\int_0^1\sqrt{1-x^2}\,dx=\frac\pi4$——这是「四分之一单位圆」的面积，**几何意义直接给出答案，甚至不用找原函数**。同理 $\int_0^1\frac{dx}{1+x^2}=\arctan1-\arctan0=\frac\pi4$。<span class="marginnote">示范八提醒：牛顿—莱布尼茨是「代数捷径」，但不是唯一捷径。四分之一圆、半圆这类标准图形面积，用几何一眼看出；含绝对值的用对称性；含三角平方的用倍角公式降幂。<strong>「先想几何/对称/变形，再决定是否硬算原函数」</strong>——这既是考试技巧，也是数值计算里「先化简再求值」的工程习惯。</span>

**示范九（分段连续函数的端点陷阱）**：$\displaystyle\int_0^2\max(x,1)\,dx$。$\max(x,1)=\begin{cases}1,&0\le x\le1\\x,&1<x\le2\end{cases}$，故积分 $=\int_0^1 1\,dx+\int_1^2x\,dx=1+\frac32=\frac52$。**「最大值/最小值」函数天然是分段的**，先画出图像再拆区间，是这类题的不二法门。

> **辨析｜易错点：**用牛顿—莱布尼茨时，**先确认 $F$ 在 $[a,b]$ 上处处有 $F'=f$**（分段连续函数要逐段找原函数并保证拼接连续），再确认上下限代入无误。示范四到示范九展示了「拆区间、做变形、想几何」三类预处理——**公式只负责最后一步「代端点」，前面的化简全靠技巧**。

## 6 小结

- **牛顿—莱布尼茨公式**：$\int_a^bf(x)dx=F(b)-F(a)$（$F'=f$）——面积 = 原函数端点差。
- **证明三连**：中值定理搭桥 → 望远镜相消 → 黎曼和取极限。
- **两步计算**：求原函数 → 代入上下限；含绝对值先分区间。
- **前提注意**：$f$ 可积且 $F$ 是原函数；有间断点时分段处理。
- **应用**：位移、面积、体积等一切累积量；没有初等原函数时转数值方法。
- **计算预处理三件套**：拆区间（含 $|x|$、$\max$）、做变形（倍角降幂）、想几何（圆、对称）——公式只负责「代端点」。
- **分部分工**：积分法（§8）负责「找原函数」，牛顿—莱布尼茨负责「算定积分」——两章技法在此合流。
- **两种记号**：$F(b)-F(a)$ 可写 $\bigl[F(x)\bigr]_a^b$ 或 $F(x)\big|_a^b$——代入时先代上端减下端。
- **与 §9.1 对照**：公式给出的结果必须与「分割—求和—取极限」的定义一致，示范一即用 $x^2$ 验证过。
- **数值兜底**：$e^{-x^2}$ 等无初等原函数时，退回到数值积分（矩形/梯形/辛普森）——公式与数值两条腿走路。
