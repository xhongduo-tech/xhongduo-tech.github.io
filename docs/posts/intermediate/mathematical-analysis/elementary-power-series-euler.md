## 为什么幂级数理论「毕业」于欧拉公式

前三节把幂级数的收敛域、性质、展开条件研究透彻。现在把这些成果倾泻到一个惊人的等式上：**欧拉公式**。它把指数函数、三角函数、复数三种看似无关的对象焊在一起，是幂级数理论最辉煌的产物——也是「函数可以展开成幂级数」这一事实的终极回报。

这个公式不仅美丽，而且实用：**一切三角函数运算可以化归为指数运算**——信号处理、微分方程、量子力学、傅里叶分析全仰仗这条捷径。从「从极限到大模型」的视角看，注意力机制里的复数域运算、Transformer 里的位置编码（正弦/余弦波）都直接建在欧拉公式之上。<span class="marginnote">欧拉公式的证明只需三步：把 $e^x,\cos x,\sin x$ 都展开成幂级数（§14.3 已证），代入 $ix$，发现实部虚部分别是 $\cos,\sin$。<strong>它「免费」地给出了三角函数的加法定理</strong>：$e^{i(a+b)}=e^{ia}e^{ib}$ 两边展开，实虚部分别得到 $\cos$ 与 $\sin$ 的加法公式——一个从指数运算「长出来」的三角恒等式。用幂级数重新发明三角学，这是幂级数理论最优雅的自我证明。</span>

## 1 欧拉公式

**定理（欧拉公式 / Euler's Formula）**：

$$e^{ix}=\cos x+i\sin x\qquad(x\in\mathbb R).$$

**推论（欧拉恒等式）**：取 $x=\pi$，$e^{i\pi}+1=0$。

**公式解析：三步拆解**

**第一步，展开指数**。$e^{ix}=\sum_{n=0}^\infty\frac{(ix)^n}{n!}$（对一切 $x$ 收敛，§14.3）。逐项算 $(ix)^n$：$i^0=1,\ i^1=i,\ i^2=-1,\ i^3=-i,\ i^4=1,\dots$——**虚数单位 $i$ 的幂以 4 为周期**；

**第二步，按实虚部分组**。实部来自 $n$ 偶的项：$\sum\frac{(ix)^{2k}}{(2k)!}=\sum\frac{(-1)^kx^{2k}}{(2k)!}=\cos x$；虚部来自 $n$ 奇的项：$\sum\frac{(ix)^{2k+1}}{(2k+1)!}=i\sum\frac{(-1)^kx^{2k+1}}{(2k+1)!}=i\sin x$；

**第三步，合并**。$e^{ix}=\cos x+i\sin x$。∎

**要点**：**欧拉公式的三个输入（$e^x$ 的展开、$\cos,\sin$ 的展开、$i$ 的周期性）都是已经证明的事实**——公式本身是「展开 + 分组」的免费产物。它把「指数」从实轴扩展到了复平面。

## 2 欧拉公式的应用

**应用一：三角函数的复指数表示**。

$$\cos x=\frac{e^{ix}+e^{-ix}}{2},\qquad \sin x=\frac{e^{ix}-e^{-ix}}{2i}.$$

**这两条把三角运算变成指数运算**：$\cos^2x+\sin^2x=1$ 变成「指数代数」，加法公式变成「指数相乘」。信号处理里的「相量法」、量子力学里的「平面波 $e^{ikx}$」全用这套语言。<span class="marginnote">「用复指数代替三角函数」是工程数学的第一快捷键：电路分析里的相量（phasor）、通信里的调制解调、量子力学的波函数，都把 $\cos,\sin$ 换成 $e^{i\omega t}$——因为「相乘」「求导」在指数域里退化成「加法」「乘法」。《信号与系统》（第六级《信息与通信工程》）里，傅里叶变换 $F(\omega)=\int f(t)e^{-i\omega t}dt$ 的核就是欧拉公式——三角函数的正交性、频谱分析，全靠这个代换。</span>

**应用二：三角函数的加法定理**。$e^{i(a+b)}=e^{ia}e^{ib}$ 展开：

$$(\cos a+i\sin a)(\cos b+i\sin b)=(\cos a\cos b-\sin a\sin b)+i(\cos a\sin b+\sin a\cos b),$$

实虚部分别得 $\cos(a+b)$ 与 $\sin(a+b)$ 的公式。**「乘法 → 加法」让三角恒等式变成例行代数**。

**应用三：复数的极坐标形式**。任何复数 $z=a+ib$ 可写为 $z=re^{i\theta}$（$r=|z|$、$\theta=\arg z$）。**复数的乘法变成「模相乘、辐角相加」**：

$$(r_1e^{i\theta_1})(r_2e^{i\theta_2})=r_1r_2e^{i(\theta_1+\theta_2)}.$$

**棣莫弗定理** $(e^{i\theta})^n=e^{in\theta}$ 即「$n$ 倍角公式」：$\cos n\theta+i\sin n\theta=(\cos\theta+i\sin\theta)^n$。

## 3 初等函数的幂级数展开总表

把「乘法口诀表」补齐，供逐项运算使用：

| 函数 | 展开 | 收敛域 |
| --- | --- | --- |
| $e^x$ | $\sum\frac{x^n}{n!}$ | $\mathbb R$ |
| $\sin x$ | $\sum\frac{(-1)^nx^{2n+1}}{(2n+1)!}$ | $\mathbb R$ |
| $\cos x$ | $\sum\frac{(-1)^nx^{2n}}{(2n)!}$ | $\mathbb R$ |
| $\ln(1+x)$ | $\sum\frac{(-1)^{n+1}x^n}{n}$ | $(-1,1]$ |
| $\arctan x$ | $\sum\frac{(-1)^nx^{2n+1}}{2n+1}$ | $[-1,1]$ |
| $\arcsin x$ | $\sum\frac{(2n)!x^{2n+1}}{4^n(n!)^2(2n+1)}$ | $[-1,1]$ |
| $(1+x)^\alpha$ | $\sum\binom\alpha n x^n$ | $(-1,1)$（$\alpha$ 非整数） |
| $\frac1{1+x^2}$ | $\sum(-1)^nx^{2n}$ | $(-1,1)$ |

**每一行都能通过「几何级数 + 逐项求导/积分/复合」或直接泰勒展开得到**。这些展开是数值计算（多项式逼近）、概率论（特征函数）、物理（势函数展开）的公共弹药库。<span class="marginnote">$\arctan x$ 的展开在 $x=1$ 收敛：$\frac\pi4=\arctan1=\sum\frac{(-1)^n}{2n+1}=1-\frac13+\frac15-\cdots$——<strong>莱布尼茨级数给出了 $\pi$ 的第一个无穷级数表示</strong>。虽然它收敛很慢（要几千项才精确到小数后几位），但它证明了「$\pi$ 可以用有理数的交错和逼近」，开启了「用级数算 $\pi$」的时代。后来的马青公式、现代高速算法（收敛极快的级数）都是它的后裔。</span>

## 4 用幂级数展开求值

**示范**：用展开求 $e$ 的近似值。$e=\sum_{n=0}^\infty\frac1{n!}$。取前 $n+1$ 项，余项 $\le\frac{e}{(n+1)!}$（§6.4）。取 $n=10$，$e\approx2.7182818$，误差 $<10^{-7}$——**收敛极快**（阶乘分母）。

**示范二**：用展开求 $\sin0.1$。$\sin x=x-\frac{x^3}{3!}+\cdots$，代入 $x=0.1$：$\sin0.1\approx0.1-\frac{0.001}{6}\approx0.099833$——**用三次项就够，误差 $O(x^5)\approx10^{-7}$**。

**要点**：幂级数展开是**「手算函数值」的终极武器**——不需要任何初等公式，只要加加减减。这也是计算机算 $\sin,\exp,\log$ 的原理。<span class="marginnote">计算机里 $\sin,\exp$ 的「标准库」实现，就是「展开到固定阶数 + 余项界保证精度」：先把自变量缩小到收敛极快的范围（如 $[-\pi/4,\pi/4]$ 或 $[0,\ln2]$），再取泰勒级数前几项。第四级《高性能计算》与《大模型部署》里的「近似计算」章节，会把「查表 + 多项式修正」的技术细节展开——但核心思想你今天已经掌握：<strong>幂级数截断 + 余项控制</strong>。</span>

## 5 幂级数理论的收官地位

第十四章把「用多项式逼近函数」推到了极致：

$$\text{§6.4 泰勒公式（有限逼近）}\xrightarrow{n\to\infty}\text{§14.3 泰勒级数（精确表示）}\xrightarrow{\text{运算}}\text{§14.4 展开与应用}$$

**展开是「函数 = 无穷多项式」**，而「无穷多项式」可以放心地加减乘除、求导积分——整个函数论在幂级数里获得了「多项式式」的可操作性。这为后续铺路：

- **傅里叶级数**（第十五章）：用三角多项式（不是幂多项式）逼近周期函数；
- **复变函数**（第二级）：解析函数 = 局部幂级数可展开，欧拉公式是复分析的入门券；
- **微分方程**：幂级数解法（第二级《常微分方程》）直接用 $y=\sum a_nx^n$ 代入方程。

**幂级数是「局部信息编码」的极致**：一个点处的全部导数，编码了整个函数（在收敛域内）。这个「局部决定整体」的奇迹，是分析学最深刻的主题之一。<span class="marginnote">「解析函数：局部决定整体」是复分析的第一原理：只要在一点附近等于幂级数，整个连通区域上的值都被确定（解析延拓）。这与实数上的 $C^\infty$ 完全不同（$e^{-1/x^2}$ 是反例）。幂级数在实轴与复平面的不同命运，是第二级《复变函数与积分变换》的开门主题——而欧拉公式，就是打开那扇门的钥匙。</span>

## 6 小结

- **欧拉公式**：$e^{ix}=\cos x+i\sin x$；证明 = 展开 + 按实虚部按 $i$ 的周期分组。
- **欧拉恒等式**：$e^{i\pi}+1=0$——五个常数一个等式。
- **应用**：$\cos,\sin$ 的复指数表示、加法定理的代数化、复数极坐标 $z=re^{i\theta}$、棣莫弗定理。
- **展开总表**：几何、指数、三角、对数、反正切、反正弦、广义二项式——共同弹药库。
- **求值**：截断幂级数 + 余项界——计算机算函数的标准原理。

在下一节，我们进入第十五章：**傅里叶级数**。幂级数用「单项式」$x^n$ 逼近函数，傅里叶级数改用「三角函数」$\sin nx,\cos nx$——周期函数的世界里，三角基是最自然的语言。
