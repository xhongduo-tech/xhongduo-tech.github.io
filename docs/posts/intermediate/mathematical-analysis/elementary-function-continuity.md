# 初等函数的连续性

<div class="epigraph">
<p>初等函数在其定义域内处处连续——这不是一条被证明的定理，而是整个函数论大厦的基座：它保证我们熟悉的每一张函数图像都是一笔画成的。</p>

## 为什么「初等函数连续」是总收官

第四章花了四节建立连续性的局部与整体理论。现在到了收网的时刻：**证明每一个初等函数在定义域内连续。** 这不仅是一份「成绩单」，更是把前四章所有工具——极限、四则法则、复合、反函数、闭区间性质——串成一条生产线的总装配。

「初等函数」不是随手起的名：它们由**常数、幂函数、指数函数、对数函数、三角函数、反三角函数**这六类基本初等函数，经过有限次四则运算与有限次复合得到。所以「初等函数连续」只需两步：①六类种子各自连续；②四则与复合保持连续（§4.2 已证）。<span class="marginnote">布尔巴基学派把「初等函数连续」当作不言自明的基础，但数学分析的任务恰恰是把「不言自明」逐条兑现成证明。这个「种子 + 生成规则」的框架与编程语言高度同构：字面量（常数）+ 原生操作（六类函数）+ 组合子（四则、复合），构成了整个可计算函数族的「语法」。</span>

## 1 六类种子函数的连续性

**（一）常数函数与幂函数。** $f(x)=c$ 处处连续（$\Delta y=0$）；$f(x)=x$ 处处连续（$\Delta y=\Delta x\to0$）。由四则法则，多项式 $P(x)=\sum a_kx^k$ 处处连续，有理函数 $\frac{P}{Q}$ 在 $Q\ne0$ 处连续——这是 §4.2 的现成推论，种子已备好。

**（二）三角函数。** 先证 $\sin x$ 处处连续。用差化积：

$$|\sin(x+h)-\sin x|=\left|2\cos\left(x+\frac h2\right)\sin\frac h2\right|\le2\left|\sin\frac h2\right|\le|h|,$$

最后一步用了 $|\sin t|\le|t|$（第一重要极限的推论）。于是 $h\to0$ 时 $|\Delta y|\le|h|\to0$，$\sin x$ 处处连续。$\cos x$ 同理（或由 $\cos x=\sin(x+\frac\pi2)$ 与复合保持）。其余四个三角函数由 $\tan x=\frac{\sin x}{\cos x}$ 等商式在分母非零处连续。<span class="marginnote">证明 $\sin$ 连续只用了两条事实：和差化积公式与 $|\sin t|\le|t|$。而 $|\sin t|\le|t|$ 正是第一重要极限（§3.4）的产物——「重要极限」的名字不是白叫的，它们在此刻兑现为连续性。</span>

**（三）指数函数。** 需要严谨地定义 $a^x$（$a>0$）并证连续。标准路径：先对有理数定义 $a^q=\sqrt[n]{a^m}$，证有理点连续；再由「有理数在实数中稠密 + 一致连续性（§4.4）」延拓到全体实数，得到 $a^x$。这个延拓正是 §4.4 预告的「一致连续支持完备化」的实际应用——**$a^x$ 的连续性建立在 $a^q$ 的有理连续性 + 一致延拓之上**。

**（四）对数函数。** $y=\log_a x$ 是 $x=a^y$ 的反函数。$a^y$ 在 $\mathbb{R}$ 上严格递增连续，值域 $(0,\infty)$，由反函数连续性定理（§4.4），$\log_a x$ 在 $(0,\infty)$ 上连续。

**（五）反三角函数。** $y=\arcsin x$ 是 $\sin y$ 在 $[-\frac\pi2,\frac\pi2]$ 上的反函数，由反函数定理在 $[-1,1]$ 上连续；$\arctan x$ 同理在 $\mathbb{R}$ 上连续。**反函数连续性定理在这一步第三次建功**（前两次是根式与对数）。

## 2 幂函数 x^α 的连续性

幂函数 $x^\alpha$（$\alpha$ 为任意实数）可以化归为指数与对数的复合：

$$x^\alpha=e^{\alpha\ln x}\qquad(x>0).$$

这是「**指数—对数互逆**」的威力：任意实指数的幂函数，被写成「外指数、内对数」的复合。由于 $e^u$ 连续、$\alpha\ln x$ 连续（$\ln$ 连续且乘以常数保持连续），复合保持连续，故 $x^\alpha$ 在 $(0,\infty)$ 上连续。<span class="marginnote">$x^\alpha=e^{\alpha\ln x}$ 这条恒等式把「任意实指数」的幂函数整个收编进指数函数——它也是后面 §6.4 求 $x^\alpha$ 导数、以及泰勒展开里 $(1+x)^\alpha$ 的理论起点。学到这里，第一级《基础数学》里「幂的运算法则」才算有了完整的高阶解释。</span>

对于 $\alpha$ 为整数或有理数的特殊情形，连续性也可以直接从定义得到（$x^n$ 是多项式，$x^{1/n}=\sqrt[n]x$ 由反函数定理），但**统一公式 $e^{\alpha\ln x}$ 对一切实 $\alpha$ 一次搞定**，是最高效的路线。

## 3 公式解析：初等函数连续性的证明策略

把整章证明的组织方式画成一张「生产流程图」：

$$\text{种子：}\ \underbrace{c,\ x}_{\text{直接}},\quad \underbrace{\sin,\cos,\tan}_{\text{和差化积}+\lvert\sin t\rvert\le\lvert t\rvert},\quad \underbrace{a^x}_{\text{有理延拓+一致连续}},\quad \underbrace{\log_a,\arcsin,\arctan}_{\text{反函数定理}}$$

$$\Downarrow\quad\text{生成规则（§4.2 保持连续）}$$

$$\text{初等函数}：\ \text{四则运算 }\&\ \text{有限次复合}\quad\Longrightarrow\quad\text{在定义域内处处连续}$$

**三步拆解**：

**第一步，点亮种子。** 六类基本初等函数各自连续：直接验证（常数、$x$）、差化积（三角）、有理延拓（指数）、反函数定理（对数、反三角）。每类用的工具都不同，但都已在前面备好。

**第二步，动用生成规则。** §4.2 的「四则保持连续」与「复合保持连续」是流水线：只要输入连续，输出就连续。因此任何由种子经有限步生成的对象自动连续。

**第三步，宣告总定理。** 由定义，一切初等函数都可表为「六类种子 + 有限次四则/复合」，故**一切初等函数在其定义域内连续**。∎

> **辨析｜易错点：**「在其定义域内连续」——注意是**定义域内**。$\tan x$ 在 $x=\frac\pi2$ 处没有定义，谈不上连续；$\sqrt{x}$ 只在 $[0,\infty)$ 有定义。**初等函数的间断点只可能出现在「函数无定义的点」**（如 $\tan$ 的极点、$1/x$ 的零点处），而在定义域内部绝不间断。这是「初等函数连续」总定理的最直接应用：**判断一个复杂函数是否连续，先找定义域，再查间断点只能在定义域边界。** 这个「找定义域」的习惯，是所有极限与连续计算的第一个动作。

## 4 总定理的应用

**应用一：极限的代入法。** 若 $f$ 是初等函数且 $x_0$ 在定义域内，则

$$\lim_{x\to x_0}f(x)=f(x_0).$$

这是初等函数连续性最朴素的兑现：**求初等函数极限，直接代入。** $\lim_{x\to1}\frac{\ln(1+\sqrt x)}{\sin x}=\frac{\ln 2}{\sin 1}$，一个动作完成，因为所有参与的函数在 $x=1$ 都连续。<span class="marginnote">「直接代入」是初等函数求极限的第一口诀。但它的前提——$x_0$ 在定义域内、且不是 $\frac00$ 型不定式——必须时刻记住：$x\to1$ 时 $\frac{x^2-1}{x-1}$ 不能代入（分母为零），要先化简（§3.2 的例一）。代入法是「连续」送的礼，别忘了它的适用范围。</span>

**应用二：建立「处处连续」的直觉。** 指数衰减 $e^{-x}$、逻辑斯蒂 $\sigma(x)=\frac1{1+e^{-x}}$、$\tanh x$——这些在机器学习里天天见的光滑函数，全是由种子经四则与复合得到的初等函数，因此处处连续。深度学习理论里「神经网络的输出对输入连续」的合法性，正是这条总定理在 $n$ 元情形的延伸（第十六章）。

**应用三：为反函数、隐函数铺路。** $e^x$ 连续是定义 $\ln$ 的前提，$\ln$ 连续又是 $x^\alpha$ 连续的前提——这条「种子链」一路延伸，到第十八章隐函数定理时，你会看到同样的「连续 + 严格单调 ⇒ 局部可逆」思想在多元世界重演。

## 5 小结

- **六类种子连续**：常数、幂直接；三角用差化积 + $|\sin t|\le|t|$；指数用有理延拓 + 一致连续；对数、反三角用反函数定理。
- **幂函数统一化**：$x^\alpha=e^{\alpha\ln x}$，任意实指数一次搞定。
- **总定理**：初等函数（种子 + 有限次四则/复合）在其定义域内处处连续。
- **代入法**：定义域内初等函数极限 = 直接代值；间断点只可能在定义域边界。
- **生产流程图**：种子 → 生成规则 → 全族连续，与编程的「字面量 + 操作 + 组合子」同构。

在下一节，我们进入第五章：**导数与微分**。连续性回答「函数是否平滑」，导数回答「平滑得多快」。瞬时速度、切线斜率、变化率——这些直觉将在 ε-δ 语言下获得第一个严格形态，而连续性是导数的必要前提：可导必连续，连续却未必可导。
