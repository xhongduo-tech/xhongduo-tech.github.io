# 连续性概念：点连续、单侧连续与间断点的分类

<div class="epigraph">
<p>连续性用一句话说：自变量的小变化，只会引起函数值的小变化。而把它写成 ε-δ，就是「小到什么程度」的精确度量。</p>
<footer>—— 伯纳德·波尔查诺（Bernard Bolzano），《无穷的悖论》（Paradoxien des Unendlichen）</footer>
</div>

## 为什么「连续」需要重新定义

直觉上，连续就是「曲线不断」。但「不断」太模糊——$x^2\sin\frac1x$ 在 0 处剧烈震荡却依然连续，符号函数在 0 处跳一下就不连续。要精确刻画「断」与「不断」，必须回到极限语言。

**连续性与极限的关系只有一句话：连续 = 极限值等于函数值。** 这个等式看似平淡，却是整个第四章的总纲。它把「函数值存在」「极限存在」「两者相等」三件事捆在一起，任何一个环节出问题，连续性就崩溃。<span class="marginnote">波尔查诺在 1817 年第一次给出连续性的精确表述，比柯西早四年。有趣的是，他的动机是证明「介值定理」——连续性理论从一开始就不是为概念本身而建，而是为了给「穿过零点的曲线必经过零点」这种几何直觉一个可证明的形态。今天的介值定理（§4.3）正是这条思想线的终点。</span>

## 1 函数在一点连续

**函数在点 $x_0$ 连续**：设 $f$ 在 $x_0$ 的某邻域内有定义。若

$$\lim_{x\to x_0}f(x)=f(x_0),$$

则称 $f$ 在 $x_0$ 处**连续**。

用 ε-δ 语言展开：对任意 $\varepsilon>0$，存在 $\delta>0$，使得当 $|x-x_0|<\delta$ 时 $|f(x)-f(x_0)|<\varepsilon$。

> **辨析｜易错点：连续与极限的三处不同。** 第一，连续的邻域是**实心**的（$|x-x_0|<\delta$，含 $x_0$），极限是**去心**的——因为连续要求函数在 $x_0$ 处有定义，且极限恰等于它。第二，连续的三要素缺一不可：$f(x_0)$ 存在、$\lim f(x)$ 存在、两者相等。第三，用 ε-δ 验证连续时，可以直接比较 $f(x)$ 与 $f(x_0)$，无需像极限那样绕开 $x_0$——这反而让连续性的直接证明常比极限更省事。

**函数在区间上连续**：若 $f$ 在开区间 $(a,b)$ 内**每一点**都连续，称 $f$ 在 $(a,b)$ 上连续；若在闭区间 $[a,b]$ 上连续，还需在端点单侧连续（见下）。

**用「改变量」改写**：令 $\Delta x=x-x_0$，$\Delta y=f(x_0+\Delta x)-f(x_0)$，则连续等价于

$$\lim_{\Delta x\to0}\Delta y=0.$$

**自变量趋于零的改变量，必引起函数改变量也趋于零**——这是「小变化只引起小变化」最直接的翻译，也是微分学（第五章）把 $\Delta y$ 拆成线性主部加高阶项的出发点。

## 2 单侧连续与间断点的分类

**左连续**：$\displaystyle\lim_{x\to x_0^-}f(x)=f(x_0)$；**右连续**：$\displaystyle\lim_{x\to x_0^+}f(x)=f(x_0)$。

**定理：$f$ 在 $x_0$ 连续 ⇔ $f$ 在 $x_0$ 既左连续又右连续。** 这是「左右极限相等」定理（§3.1）的直接推论。闭区间连续要求在左端点右连续、右端点左连续。

**间断点**：若 $f$ 在 $x_0$ 不连续，称 $x_0$ 为 $f$ 的**间断点**。按「坏」的程度分类：

**第一类间断点**（左右极限都存在）：
- **可去间断点**：$\lim_{x\to x_0}f(x)$ 存在但不等于 $f(x_0)$（或 $f(x_0)$ 无定义）。「可去」的含义是：重新定义 $f(x_0)=\lim f(x)$ 即可补上缺口。
- **跳跃间断点**：左右极限都存在但**不相等**。跳变的大小是 $|\lim f(x_0^+)-\lim f(x_0^-)|$。

**第二类间断点**（左右极限至少一个不存在）：
- **无穷间断点**：至少一侧趋向 $\pm\infty$，如 $f(x)=\frac1x$ 在 0 处；
- **振荡间断点**：左右极限都不存在且不趋向无穷，如 $f(x)=\sin\frac1x$ 在 0 处。

分类表一目了然：

| 类型 | 条件 | 例子 | 可否修复 |
| --- | --- | --- | --- |
| 可去 | $\lim f$ 存在，$\ne f(x_0)$ | $\frac{\sin x}{x}$ 在 0 处 | 可补定义修复 |
| 跳跃 | $\lim^-f\ne\lim^+f$ | $\operatorname{sgn}x$ 在 0 处 | 不可修复 |
| 无穷 | 一侧 $\to\pm\infty$ | $\frac1x$ 在 0 处 | 不可修复 |
| 振荡 | 两侧极限都不存在 | $\sin\frac1x$ 在 0 处 | 不可修复 |

## 3 公式解析：判别一点处连续性

完整流程用 $f(x)=\begin{cases}x\sin\frac1x,&x\ne0\\0,&x=0\end{cases}$ 示范，判断它在 0 处是否连续。

**第一步，看函数值是否存在。** $f(0)=0$，有定义。✓

**第二步，看极限是否存在。** 对 $x\ne0$，$|x\sin\frac1x|\le|x|$，由夹逼（或「有界 × 无穷小」），$\lim_{x\to0}x\sin\frac1x=0$。✓

**第三步，比较两者。** $\lim f(x)=0=f(0)$，相等。故 $f$ 在 0 处连续。∎

> **辨析｜易错点：**这个函数在 0 附近**剧烈震荡**（$\sin\frac1x$ 的振荡被 $x$ 压扁成振幅趋于 0 的「阻尼振荡」），却**依然连续**。它教育我们：**连续 ≠ 图像好画**。凡是用「画得出来」判断连续，都会被这种函数难倒。判别连续只看三件事：定义、极限、相等——震荡只要被「压到 0」，照样连续。这是分析学反直觉的第一课。

对比：$g(x)=\begin{cases}\sin\frac1x,&x\ne0\\0,&x=0\end{cases}$ 在 0 处，极限 $\lim_{x\to0}\sin\frac1x$ 不存在（海涅定理，§3.3 已证），故为**振荡型第二类间断点**。**同一副骨架，乘不乘「衰减因子 $x$」，决定了从连续到间断的分野**——这个「衰减因子压震荡」的技巧，在信号处理、随机过程里是控制不规则性的常规手段。

## 4 连续性的否定表述

证明「不连续」，常用三种武器：

- **找极限不存在**：用海涅定理找两条数列给出不同极限（$\sin\frac1x$）；
- **找左右极限不等**：分段函数在拼接点常如此（$\operatorname{sgn}x$）；
- **找极限不等于函数值**：可去间断点的典型判据。

写否定形式：$f$ 在 $x_0$ 不连续 ⇔ 存在 $\varepsilon_0>0$，使得对任意 $\delta>0$，都能找到 $|x-x_0|<\delta$ 且 $|f(x)-f(x_0)|\ge\varepsilon_0$ 的 $x$。

这个否定式与「存在性」的否定式（§3.3）同构，都是「对任意 δ 都能挑出坏点」的套路。掌握它，就掌握了分析中所有「不存在性」论证的共同语法。<span class="marginnote">「否定式三件套」——极限不存在、左右不等、极限≠值——会在后面反复出场：可导性的失败（第五章）、一致连续性的失败（§4.4）、级数收敛的失败（第十二章）各有自己的否定判据，但都共享「找反例点」的思路。</span>

## 5 小结

- **连续定义**：$\lim_{x\to x_0}f(x)=f(x_0)$；ε-δ 版用实心邻域，与极限的去心邻域相区别。
- **改变量表述**：$\Delta x\to0\Rightarrow\Delta y\to0$——「小变只引起小变」的精确形态。
- **单侧连续**：连续 ⇔ 左连续且右连续；闭区间端点按单侧理解。
- **间断点分类**：第一类（可去、跳跃）与第二类（无穷、振荡）；可去间断点可补定义修复。
- **判别流程**：看定义 → 看极限 → 比相等；「震荡 × 衰减」照样连续，连续与「好画」无关。

在下一节，我们研究连续函数的**运算闭环**：连续函数做四则运算、复合运算后是否仍连续？答案几乎全是肯定的——这个「连续函数的保值性」将让我们从少数已知连续的函数出发，构造出海量的连续函数。
