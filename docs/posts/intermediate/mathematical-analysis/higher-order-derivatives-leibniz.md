# 高阶导数与莱布尼茨公式

<div class="epigraph">
<p>函数的二阶导数刻画加速度，三阶导数刻画加速度的变化率；而 n 阶导数，则是函数在一点附近全部「曲率信息」的目录。</p>

## 为什么需要高阶导数

一阶导数 $f'$ 是变化率，它本身仍是 $x$ 的函数——若再可导，就有二阶导数 $f''$，表示「变化率的变化率」；如此迭代，得到 $n$ 阶导数 $f^{(n)}$。

物理直觉很直接：位置 $s(t)$ 的一阶导是速度，二阶导是加速度，三阶导是「急动度」（jerk）——火箭设计、电梯舒适度都关心它。数学上，高阶导数藏着函数更深层的信息：**$f'(x_0)$ 决定切线的倾角，$f''(x_0)$ 决定弯曲的方向与程度（凸凹），$f^{(n)}(x_0)$ 决定函数与 $n$ 次多项式在 $x_0$ 附近「贴得多紧」**——这正是泰勒公式（§6.4）的伏笔。<span class="marginnote">「高阶导数是光滑性的精细度标尺」：$C^n$ 表示 $n$ 阶导函数连续，$C^\infty$ 表示任意阶可导（如 $e^x,\sin x$），而处处 $C^\infty$ 却非解析的函数（如 $e^{-1/x^2}$）把「光滑」与「可展开」区分开来——这个区分在第十四章幂级数理论里会变得尖锐。</span>

## 1 高阶导数的定义与记号

**高阶导数**：若 $f'$ 在 $x_0$ 处可导，其导数记为 $f''(x_0)$，称为 $f$ 在 $x_0$ 处的**二阶导数**。归纳地，$f^{(n)}$ 定义为 $f^{(n-1)}$ 的导数（若存在），称为 $n$ 阶导数。约定 $f^{(0)}=f$。

记号汇总：

$$y',\ f'(x),\ \frac{dy}{dx};\qquad y'',\ f''(x),\ \frac{d^2y}{dx^2};\qquad y^{(n)},\ f^{(n)}(x),\ \frac{d^ny}{dx^n}.$$

**注意**：$\frac{d^ny}{dx^n}$ 的写法是**约定**，不是「$d$ 的 $n$ 次方除以 $dx$ 的 $n$ 次方」——$\frac{d^2y}{dx^2}$ 表示「对 $y$ 关于 $x$ 求两次导」，它不等于 $\left(\frac{dy}{dx}\right)^2$，也不等于 $\frac{d^2y}{(dx)^2}$ 的字面运算。这记号是莱布尼茨留下的，强大但也误导人。

**常见高阶导数表**：

$$(e^x)^{(n)}=e^x,\qquad (\sin x)^{(n)}=\sin\left(x+\frac{n\pi}{2}\right),\qquad (\ln x)^{(n)}=\frac{(-1)^{n-1}(n-1)!}{x^n},$$

$$(x^\alpha)^{(n)}=\alpha(\alpha-1)\cdots(\alpha-n+1)\,x^{\alpha-n},\qquad \left(\frac1{1+x}\right)^{(n)}=\frac{(-1)^n n!}{(1+x)^{n+1}}.$$

这些公式的规律性极强（$\sin$ 每求导四次循环），是「求 $n$ 阶导」的种子库。<span class="marginnote">「求 $n$ 阶导」的题型核心是<strong>找模式</strong>：$\sin,\cos$ 每 4 阶循环；$x^k$ 求 $n$ 阶导后若 $n>k$ 则归零；$\frac1{ax+b}$ 是符号交替的阶乘结构。遇到「求某函数的 $n$ 阶导」，先猜模式再归纳证明——这是数学归纳法在求导里的经典表演。</span>

## 2 莱布尼茨公式

**定理（莱布尼茨公式 / Leibniz Formula）：设 $u,v$ 都有 $n$ 阶导数，则**

$$(uv)^{(n)}=\sum_{k=0}^{n}\binom{n}{k}\,u^{(k)}v^{(n-k)}.$$

**公式解析：为什么像二项式定理**

把 $(uv)'=u'v+uv'$、$(uv)''=u''v+2u'v'+uv''$ 写出来，已经能看出规律——**系数就是二项式系数**：

$$(uv)^{(n)}=\binom n0 u^{(0)}v^{(n)}+\binom n1 u'v^{(n-1)}+\cdots+\binom nn u^{(n)}v^{(0)}.$$

**三步拆解**：

- **第一步，类比**：展开 $(uv)^{(n)}$ 如同展开 $(a+b)^n$——「$u$ 求 $k$ 阶导、$v$ 求 $n-k$ 阶导」的所有分配方式，对应 $a^kb^{n-k}$ 的所有项；
- **第二步，定系数**：每一项出现的次数恰是「从 $n$ 次求导中选 $k$ 次给 $u$」的组合数 $\binom nk$；
- **第三步，归并**：把 $u^{(k)}v^{(n-k)}$ 按 $k=0,\dots,n$ 求和。

为什么系数是组合数？因为每次求导都「或作用于 $u$ 或作用于 $v$」，$n$ 次作用中「$k$ 次落在 $u$ 上」的选择方式是 $\binom nk$ 种，每一种贡献相同的项。**「导数的分配」与「括号的展开」是同构的**——这就是莱布尼茨公式最深的结构。

**证明用数学归纳法**：假设公式对 $n$ 成立，对 $n+1$ 求导，用 $u^{(k+1)}v^{(n-k)}+u^{(k)}v^{(n+1-k)}$ 合并同类项，系数由杨辉恒等式 $\binom n{k-1}+\binom nk=\binom{n+1}k$ 接力。∎

> **辨析｜易错点：**莱布尼茨公式**只对乘积**有效，对复合函数、商**不适用**。$(f\circ g)^{(n)}$ 没有简单的二项式型公式（那是「法诺塔·费阿·迪·布鲁诺公式」，复杂得多），商的高阶导更无通式。**看到 $uv$ 用莱布尼茨，看到 $\frac uv$ 或 $f(g(x))$ 就另想办法**（通分、换元、化成低阶递推）。

## 3 莱布尼茨公式的应用

**应用一：乘积高阶导。** 求 $y=x^2e^x$ 的 $n$ 阶导数。令 $u=e^x$（各阶导数都是 $e^x$）、$v=x^2$（三阶起为 0），由莱布尼茨公式

$$y^{(n)}=\sum_{k=0}^{2}\binom nk (e^x)^{(k)}(x^2)^{(n-k)}=e^x\left(x^2+2nx+n(n-1)\right).$$

求和只需 $k=0,1,2$ 三项（$x^2$ 的高阶导为 0），干净利落。**「一端是 $e^x$（各阶不变）、一端是多项式（有限阶非零）」的组合，是莱布尼茨公式最常用的情形**——求和自动截断。

**应用二：多项式在一点的 n 阶导。** 对 $n$ 次多项式 $P(x)=\sum a_kx^k$，有重要关系式

$$a_k=\frac{P^{(k)}(0)}{k!}.$$

这揭示了「**系数 = 高阶导数值 ÷ 阶乘**」——它正是泰勒公式的雏形：$n$ 次多项式完全由它在 0 处的前 $n$ 阶导数决定。高阶导数在这里第一次展现出「编码函数信息」的能力，§6.4 将把它放大到一般函数。

**应用三：物理中的急动度。** $s'''(t)$ 是急动度（jerk）。列车启停曲线设计、工业机械臂轨迹规划都要限制急动度以保证平稳——**三阶导数不是数学奢侈品，是工程设计的硬指标**。<span class="marginnote">自动驾驶的轨迹规划（第六级）里，路径 $s(t)$ 的高阶导数——速度 $s'$、加速度 $s''$、急动度 $s'''$——被分别约束上下限，构成「加加速度有界」的舒适性约束。你在本节学的三阶导数记号，正是那些约束的数学表述。</span>

## 4 高阶导数的整体视角

高阶导数不只是「求很多次导」，它打开三个方向：

- **光滑性层级**：$C^n$（$n$ 阶连续可导）、$C^\infty$（光滑）、解析——这是函数「质量」的标尺，也是函数逼近论（§6.4 泰勒、第十四章幂级数）讨论的前提；
- **局部信息编码**：$f^{(k)}(x_0)\ (k=0,1,\dots,n)$ 决定「函数在 $x_0$ 附近最接近它的 $n$ 次多项式」——高阶导数是「局部信息」的目录；
- **递推与生成函数**：常微分方程里「设 $y=e^{rx}$ 代入」得到特征方程，本质是「求导把 $e^{rx}$ 变成 $r^k e^{rx}$」——高阶导数把微分方程翻译成代数方程。

这三个方向分别通向泰勒公式、幂级数与微分方程——都是后面章节的绝对主线。<span class="marginnote">常微分方程（第二级《常微分方程》）的解法几乎全建立在「求导是线性算子」这一事实上：$y''+py'+qy=0$ 的特征方程 $r^2+pr+q=0$，就是把「求 $n$ 阶导」对应成「乘以 $r^n$」。高阶导数在这时成为「把分析问题代数化」的翻译官。</span>

## 5 小结

- **高阶导数**：$f^{(n)}$ 是 $f^{(n-1)}$ 的导数；记号 $\frac{d^ny}{dx^n}$ 是约定，非字面运算。
- **常见公式**：$e^x$ 不变，$\sin$ 每 4 阶循环，$\ln$ 是交替阶乘，$(1+x)^{-1}$ 是 $(-1)^nn!$——「找模式 + 归纳」是通法。
- **莱布尼茨公式**：$(uv)^{(n)}=\sum\binom nk u^{(k)}v^{(n-k)}$，像二项式定理；只适用于乘积。
- **截断求和**：一端 $e^x$、一端多项式的组合自动截断为有限项。
- **编码能力**：$P^{(k)}(0)/k!$ 是多项式的系数——高阶导数是函数局部信息的目录，泰勒公式的伏笔。

在下一节，我们进入**微分**：$dy=f'(x)dx$。如果说导数回答「变化率是多少」，微分则回答「函数在该点附近能被直线逼近得多好」——它给出了「线性化」的严格表述，也是近似计算的第一个工具。
