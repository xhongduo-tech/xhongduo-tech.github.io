# 三角级数与正交函数系：傅里叶系数的引出

<div class="epigraph">
<p>一个周期函数能否被分解成不同频率的弦波的叠加？傅里叶的回答是：能——只要你愿意把无穷多个正弦与余弦加在一起。</p>

## 为什么「三角基」如此自然

幂级数用 $1,x,x^2,\dots$ 逼近函数——对**周期函数**这不是好语言（单项式不周期）。周期函数 $f(x+T)=f(x)$ 的自然语言是**三角函数**：$\sin nx$、$\cos nx$ 都是周期 $2\pi$ 的。于是问题变成：**任何周期函数能否写成不同频率的正弦/余弦之和？**

这就是**傅里叶级数**。它的思想：把周期函数「分解成谐波」——就像把白光分解成彩虹。这一节建立第一个支柱：**正交函数系**。$\{\sin nx,\cos nx\}$ 在 $[-\pi,\pi]$ 上两两正交（积分内积为零），这个正交性让「求展开系数」变成「投影」——与分析几何里「向坐标轴投影」完全同构。<span class="marginnote">「正交」是几何概念在函数空间的推广：两个向量正交 = 内积为零，两个函数正交 = 积分 $\int fg=0$。函数看成「无穷维向量」，积分是内积，傅里叶级数就是「向正交基投影」。这套「函数 = 向量、积分 = 内积」的语言在第二级《泛函分析》里成为希尔伯特空间理论——傅里叶级数正是「无穷维空间的坐标展开」的原型。</span>

## 1 三角级数与三角多项式

**三角级数（trigonometric series）**：

$$\frac{a_0}{2}+\sum_{n=1}^{\infty}(a_n\cos nx+b_n\sin nx),$$

其中 $a_n,b_n$ 为常数。**$a_0/2$ 的写法**是惯例——为了让 $a_0$ 的公式与其他 $a_n$ 统一（见下）。

**三角多项式**：截断到有限项 $S_n(x)=\frac{a_0}{2}+\sum_{k=1}^n(a_k\cos kx+b_k\sin kx)$——部分和就是三角多项式。

**三角级数的性质**：每一项都是周期 $2\pi$ 的函数，且**部分和连续**；若级数一致收敛，和函数也连续且周期 $2\pi$。**「展开目标」是周期函数，展开的「构件」是三角函数。**

## 2 正交函数系

**定义（正交）**：函数 $f,g$ 在 $[a,b]$ 上正交，若 $\int_a^bf(x)g(x)dx=0$。函数族 $\{\varphi_n\}$ 是正交系，若两两正交。

**定理（三角函数的正交性）：在 $[-\pi,\pi]$ 上，以下积分成立（$m,n\ge1$，$m\ne n$ 时）：**

$$\int_{-\pi}^{\pi}\sin mx\sin nx\,dx=0,\qquad\int_{-\pi}^{\pi}\cos mx\cos nx\,dx=0,\qquad\int_{-\pi}^{\pi}\sin mx\cos nx\,dx=0,$$

$$\int_{-\pi}^{\pi}\sin^2nx\,dx=\pi,\qquad\int_{-\pi}^{\pi}\cos^2nx\,dx=\pi,\qquad\int_{-\pi}^{\pi}1\cdot1\,dx=2\pi.$$

**公式解析：正交性从哪来**

**第一步，积化和差**。$\sin mx\sin nx=\frac12[\cos(m-n)x-\cos(m+n)x]$（§6.3 的和差化积/积化和差公式）。$m\ne n$ 时两项都是「整数倍角的余弦」；

**第二步，整周期积分**。$\int_{-\pi}^{\pi}\cos kx\,dx=0$（$k\ne0$ 整数）——余弦在整周期上净积分为零（正负半拱抵消）。代入得 $\int\sin mx\sin nx=0$；

**第三步，平方项**。$m=n$ 时 $\sin^2nx=\frac{1-\cos2nx}{2}$，$\int_{-\pi}^\pi\sin^2nx=\pi$（$\cos2nx$ 整周期积分为零）。

**要点**：**正交性的根源是「整数倍角的余弦/正弦在整周期上积分为零」**——不同频率的谐波「互不干扰」，它们构成函数空间的「正交坐标轴」。

> **辨析｜易错点：**积分区间是 $[-\pi,\pi]$（长 $2\pi$），**不是** $[0,\pi]$。正交性对「周期 $2\pi$」的完备周期成立；若换区间 $[0,2\pi]$ 也成立（平移不变性）。另外，**常数函数 1 与 $\cos nx,\sin nx$ 也正交**（$\int\cos nx=0$），但 $\int1\cdot1=2\pi$ 而非 $\pi$——**这就是 $a_0/2$ 写法的原因**：为了让 $a_0$ 的公式 $a_0=\frac1\pi\int f$ 与其他 $a_n$ 统一，常数项取「半系数」。

## 3 傅里叶系数：向正交基投影

设周期 $2\pi$ 的函数 $f$ 能展开成三角级数（且可逐项积分）：

$$f(x)=\frac{a_0}{2}+\sum_{n=1}^\infty(a_n\cos nx+b_n\sin nx).$$

**傅里叶系数（Fourier coefficients）**：两边同乘 $\cos mx$ 并在 $[-\pi,\pi]$ 积分，由正交性，除 $n=m$ 的项外全为零：

$$\int_{-\pi}^{\pi}f(x)\cos mx\,dx=a_m\int_{-\pi}^{\pi}\cos^2mx\,dx=a_m\pi,$$

$$a_m=\frac1\pi\int_{-\pi}^{\pi}f(x)\cos mx\,dx\qquad(m=0,1,2,\dots),$$

$$b_m=\frac1\pi\int_{-\pi}^{\pi}f(x)\sin mx\,dx\qquad(m=1,2,\dots).$$

**公式解析：三步拆解**

**第一步，两边同乘 $\cos mx$**。目标：把「想要的那个系数」从求和里「挑」出来；

**第二步，积分 + 正交性**。$\int f\cos mx=\sum a_n\int\cos nx\cos mx+\sum b_n\int\sin nx\cos mx$——**除 $n=m$ 的 $a_m\pi$ 外全为零**（正交性），一堆无穷求和坍缩成一个数；

**第三步，解出 $a_m$**。除以 $\pi$，得 $a_m=\frac1\pi\int f\cos mx$。$b_m$ 同理（同乘 $\sin mx$）。

**要点**：**傅里叶系数 = 函数向各谐波的「投影分量」**——与「向量在坐标轴上的投影 = 内积」完全同构。正交性把「解无穷多个系数」变成「逐个投影」，这就是傅里叶级数理论的第一块基石。

**示范**：$f(x)=x$（$-\pi\le x<\pi$）。$a_n=\frac1\pi\int_{-\pi}^\pi x\cos nx\,dx=0$（奇函数 × 偶函数在对称区间积分）；$b_n=\frac1\pi\int_{-\pi}^\pi x\sin nx\,dx=\frac1\pi\left[-\frac{x\cos nx}{n}+\frac{\sin nx}{n^2}\right]_{-\pi}^\pi=\frac{2(-1)^{n+1}}{n}$。展开 $x=2\sum\frac{(-1)^{n+1}\sin nx}{n}$。<span class="marginnote">$f(x)=x$ 在 $[-\pi,\pi)$ 上是「锯齿波」——它在 $x=\pm\pi$ 处跳变（周期延拓后在 $\pi$ 处从 $\pi$ 跳到 $-\pi$）。它的傅里叶级数 $2\sum\frac{(-1)^{n+1}\sin nx}{n}$ 是「锯齿波」的谐波分解：$n=1$ 主导、高频项逐级衰减。这个展开在 $x=\pi$ 处「收敛到 $\pi$ 与 $-\pi$ 的平均 0」——预告了第十五章末尾的收敛定理（间断点处收敛到平均值）。</span>

## 4 正交系在函数空间的意义

把「函数展开」翻译成「向量展开」，一切豁然开朗：

| 几何 | 函数空间 |
| --- | --- |
| 向量 $\vec v$ | 函数 $f(x)$ |
| 内积 $\vec u\cdot\vec v$ | 积分 $\int fg$ |
| 标准正交基 $\{\vec e_n\}$ | 正交函数系 $\{\frac1{\sqrt\pi}\cos nx,\frac1{\sqrt\pi}\sin nx,\frac1{\sqrt{2\pi}}\}$ |
| 投影系数 $\vec v\cdot\vec e_n$ | 傅里叶系数 $\frac1\pi\int f\cos nx$ |
| 展开 $\vec v=\sum(\vec v\cdot\vec e_n)\vec e_n$ | 傅里叶级数 $f=\frac{a_0}2+\sum(a_n\cos nx+b_n\sin nx)$ |

**傅里叶级数就是「函数空间的坐标展开」**——这个类比是第二级《泛函分析》希尔伯特空间理论的雏形，也是「函数逼近」「信号分解」的数学母题。

## 5 计算示范：傅里叶系数的实操

**示范一（$f(x)=|x|$，偶函数只用余弦）**：$|x|$ 在 $[-\pi,\pi]$ 上是偶函数，故 $b_n=0$（奇函数乘 $\sin nx$ 在对称区间积分为零）。求 $a_n$：

$$a_n=\frac1\pi\int_{-\pi}^{\pi}|x|\cos nx\,dx=\frac{2}{\pi}\int_0^\pi x\cos nx\,dx=\frac{2}{\pi}\left[\frac{x\sin nx}{n}+\frac{\cos nx}{n^2}\right]_0^\pi=\frac{2}{\pi}\cdot\frac{\cos n\pi-1}{n^2}.$$

$\cos n\pi=(-1)^n$，故 $a_n=0$（$n$ 偶）、$a_n=-\frac{4}{\pi n^2}$（$n$ 奇）。$a_0=\frac1\pi\int_{-\pi}^{\pi}|x|dx=\frac{2}{\pi}\cdot\frac{\pi^2}{2}=\pi$。于是

$$|x|=\frac\pi2-\frac4\pi\sum_{k=0}^{\infty}\frac{\cos(2k+1)x}{(2k+1)^2}.$$

**偶函数 → 只用 $\cos$（余弦级数）；展开系数全是「偶次项消失」**。<span class="marginnote">这个展开在 $x=0$ 处给出著名的 $\frac{\pi^2}{8}$：$0=\frac\pi2-\frac4\pi\sum\frac1{(2k+1)^2}$，故 $\sum_{k=0}^\infty\frac1{(2k+1)^2}=\frac{\pi^2}{8}$。<strong>傅里叶级数不仅分解函数，还「免费」给出若干数论常数</strong>——$\zeta(2)=\frac{\pi^2}{6}$ 可由 $\frac{\pi^2}{8}$ 推出（$\frac1{1^2}+\frac1{3^2}+\frac1{5^2}+\cdots$ 与偶数项之和的关系）。这个「用分析求数论常数」的技巧，是解析数论（第二级《数论》）的常用戏法。</span>

**示范二（奇函数只用正弦）**：$f(x)=x$ 在 $[-\pi,\pi)$ 上是奇函数，$a_n=0$，$b_n=\frac{2(-1)^{n+1}}{n}$（见第 3 节）。展开 $x=2\sum_{n=1}^\infty\frac{(-1)^{n+1}\sin nx}{n}$——**锯齿波的谐波分解**。

**示范三（系数的数值核对）**：对示范一，取 $x=0$ 代入验证：$|0|=0=\frac\pi2-\frac4\pi\sum\frac1{(2k+1)^2}$——给出 $\sum\frac1{(2k+1)^2}=\frac{\pi^2}{8}$。取 $x=\pi$：$|\pi|=\pi=\frac\pi2-\frac4\pi\sum\frac{\cos(2k+1)\pi}{(2k+1)^2}=\frac\pi2+\frac4\pi\sum\frac1{(2k+1)^2}$，代入 $\frac{\pi^2}{8}$ 得 $\pi=\frac\pi2+\frac{\pi}{2}=\pi$——**自洽**。

> **辨析｜易错点：**计算傅里叶系数时，先**判奇偶**再动手：偶函数 $b_n=0$、奇函数 $a_n=0$（含 $a_0$），能省一半积分。另一个坑：**$a_0$ 的公式是 $a_0=\frac1\pi\int f$ 而非 $\frac2\pi\int f$**——因为常数项与自身的积分为 $2\pi$，除以 $\pi$ 得 $2a_0/2$ 对应「$\frac{a_0}{2}$」的系数。还有：**逐项积分需要级数可积**（一致收敛或至少逐点收敛），严谨推导在 §15.4 收敛定理处补上——本节先用「形式展开」建立系数公式，收敛性后再严格化。

**示范一至三的方法论**：写三角级数 → 判奇偶定系数的类别 → 用正交性投影逐个求 $a_n,b_n$ → 用特殊点验证（自洽性检查）。

## 6 小结

- **三角级数**：$\frac{a_0}{2}+\sum(a_n\cos nx+b_n\sin nx)$；三角多项式是有限截断。
- **正交性**：$\sin,\cos$ 不同频率在 $[-\pi,\pi]$ 上积分互为零；根源是「整周期余弦积分为零」。
- **傅里叶系数**：$a_n=\frac1\pi\int_{-\pi}^\pi f\cos nx$、$b_n=\frac1\pi\int f\sin nx$——向正交基投影。
- **$a_0/2$ 的惯例**：让 $a_0$ 公式与其他 $a_n$ 统一（常数项与自身的积分为 $2\pi$）。
- **类比**：函数 = 向量、积分 = 内积、正交基 = 谐波、系数 = 投影。
