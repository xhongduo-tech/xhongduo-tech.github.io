# 曲线积分与路径无关的条件

<div class="epigraph">
<p>做功与路径无关——这是保守力场的定义，而它的数学判据是「旋度为零」。格林公式把「路径无关」变成「旋度恒零」的可检验条件。</p>

## 为什么「路径无关」如此重要

重力做功与路径无关（只取决于高度差），摩擦力做功依赖路径——**「路径无关」把向量场分成两等公民**：保守场（路径无关，存在势函数）与非保守场（路径相关）。物理里「保守力」的定义，数学里「梯度场」的刻画，全靠「路径无关」。

这一节用格林公式给出完整判据：**路径无关 ⇔ 任何闭曲线积分 = 0 ⇔ 旋度为零 ⇔ 存在势函数 $u$ 使 $\vec F=\nabla u$**。四个条件互相等价，构成「保守场」的完整画像。<span class="marginnote">「做功与路径无关 ⇔ 存在势能函数」是力学的核心思想：重力场 $\vec F=(0,-mg)$ 有势能 $u=-mgy$（$\vec F=\nabla u$），弹力场 $\vec F=-kx$ 有势能 $u=-\frac12kx^2$。第二级《理论力学》里「保守力 = 梯度场」「机械能守恒 = 路径无关」——这些概念的数学根基就是本节。而「旋度为零」的判据，让「是否保守」从「验证所有路径」变成「算一个偏导差」。</span>

## 1 路径无关的定义与基本判据

**路径无关**：设 $\vec F=(P,Q)$ 在区域 $D$ 上连续。若积分 $\int_C P\,dx+Q\,dy$ 只依赖起点与终点、不依赖路径 $C$（$C\subset D$），则称积分在 $D$ 上**与路径无关**。

**定理（基本判据）：在 $D$ 上，积分与路径无关 ⇔ 沿 $D$ 内任何闭曲线 $\oint P\,dx+Q\,dy=0$。**

**证明**：若路径无关，闭曲线 $C$ 的起点 = 终点，积分 = 沿「同点路径」的积分 = 0；反之，若一切闭曲线积分为 0，两条路径 $C_1,C_2$ 首尾相接成闭曲线，$\int_{C_1}-\int_{C_2}=0$，故 $\int_{C_1}=\int_{C_2}$（路径无关）。∎

> **辨析｜易错点：**「路径无关」与「闭曲线积分为零」是**同一件事的两面**——前者说「只依赖端点」，后者说「绕一圈无净变化」。验证路径无关**不必检查所有路径**：只需「任意闭曲线积分为 0」。而判断「任意闭曲线积分为 0」用格林公式化归为「旋度为零」——**一条代数条件替换无穷多条路径检验**。

## 2 原函数（势函数）

**定理（原函数的存在性）：设 $D$ 单连通（无洞），$P,Q$ 在 $D$ 上有连续偏导数。则以下四者等价：**
1. 积分 $\int P\,dx+Q\,dy$ 在 $D$ 上**与路径无关**；
2. 沿 $D$ 内**任何闭曲线** $\oint P\,dx+Q\,dy=0$；
3. **旋度为零**：$\dfrac{\partial Q}{\partial x}-\dfrac{\partial P}{\partial y}=0$ 在 $D$ 内恒成立；
4. 存在**势函数** $u$，使 $du=P\,dx+Q\,dy$（即 $u_x=P,\ u_y=Q$）。

**此时 $\int_C P\,dx+Q\,dy=u(\text{终点})-u(\text{起点})$**——积分 = 势函数在端点的差。

**公式解析：为什么「单连通」是前提**

**第一步，格林公式连接 2 与 3**。由格林公式，$\oint_{\partial\Omega}Pdx+Qdy=\iint_\Omega(Q_x-P_y)$。若旋度恒零，任何闭曲线（围成区域 $\Omega$）积分 $=0$；反之若一切闭曲线积分为 0，由反证（若某点 $Q_x-P_y>0$，取小区域使积分 $>0$）得旋度恒零——**2 ⇔ 3 在单连通下成立**；

**第二步，「单连通」的含义**。单连通 = 无洞——**任何闭曲线都能收缩成一点**，闭曲线围成的区域整体在 $D$ 内（格林公式的 $\Omega$ 不跑出 $D$）。有洞时（如圆环 $1<x^2+y^2<4$），绕洞的闭曲线不能收缩，格林公式的 $\Omega$ 含洞内的「非 $D$ 点」，旋度恒零推不出闭曲线积分为 0；

**第三步，构造势函数**。条件 1 成立时，$u(x,y)=\int_{(x_0,y_0)}^{(x,y)}Pdx+Qdy$（沿任意路径）定义势函数，且 $u_x=P,\ u_y=Q$——**积分路径无关保证了 $u$ 的单值性**。∎

**要点**：**「单连通」是旋度判据的安全边界**——有洞时旋度为零仍可能路径相关（绕洞一圈积分非零）。$\frac{-y}{x^2+y^2}dx+\frac{x}{x^2+y^2}dy$ 在圆环上旋度为零，但绕洞积分 $=2\pi\ne0$——**「有洞」让旋度判据失效**。

## 3 求势函数

**示范**：$\vec F=(2xy+y^2,\ x^2+2xy)$。验证旋度：$Q_x-P_y=(2x+2y)-(2x+2y)=0$——路径无关，存在势函数。

**方法一：积分求 $u$**。由 $u_x=2xy+y^2$ 对 $x$ 积分：$u=x^2y+xy^2+\varphi(y)$（$y$ 的「积分常数」）。由 $u_y=x^2+2xy$ 得 $x^2+2xy+\varphi'(y)=x^2+2xy$，故 $\varphi'(y)=0$、$\varphi$ 常数。$u=x^2y+xy^2+C$。

**公式解析：三步拆解**

**第一步，对一个变量积分**。$u_x=P$ ⇒ $u=\int P\,dx+\varphi(y)$——**对 $x$ 积分时，$y$ 是常数，$\varphi(y)$ 是「积分常数」**（一元积分的 $C$ 变成 $y$ 的函数）；

**第二步，对另一变量求导核对**。$u_y=Q$：$\frac{\partial}{\partial y}\left[\int P\,dx+\varphi(y)\right]=Q$——解出 $\varphi'(y)$；

**第三步，积分 $\varphi$**。$\varphi'(y)=$ 与 $y$ 有关的项，积分得 $\varphi(y)$，势函数 $u$ 完成。

**方法二：路径积分**。沿「先水平再竖直」的折线：$u(x,y)=\int_0^xP(t,0)dt+\int_0^yQ(x,t)dt$——**任意固定起点、沿简单路径积分**。结果一致。

**示范**：$\int_C(2xy+y^2)dx+(x^2+2xy)dy$ 从 $(0,0)$ 到 $(1,2)$——路径无关，直接用势函数：

$$=\bigl[x^2y+xy^2\bigr]_{(0,0)}^{(1,2)}=2+4=6.$$

**「路径无关」让线积分变成「代端点值」**——与牛顿—莱布尼茨公式同构（$\int_a^bF'=F(b)-F(a)$）。

## 4 奇点的处理

若 $D$ 内有奇点（$P,Q$ 无定义处），路径无关可能被破坏。**挖洞法**：绕奇点挖小圆，格林公式在「外边界逆时针 + 内边界顺时针」的复合边界上成立，从而**绕奇点一圈的积分 = 常数**（不依赖小圆半径）。

**示范**：$\vec F=\frac{-y}{x^2+y^2}dx+\frac{x}{x^2+y^2}dy$ 在 $\mathbb R^2\setminus\{0\}$ 上旋度为零，但绕原点一周积分 $=2\pi\ne0$——**路径无关失效**（奇点破坏单连通）。「绕奇点的环量 $2\pi$」在复分析里是「留数」的雏形（第二级《复变函数》）。<span class="marginnote">「绕奇点一圈的积分是常数」是复分析「留数定理」的种子：$\oint\frac{dz}{z}=2\pi i$ 与这里的 $\oint\frac{-y\,dx+x\,dy}{x^2+y^2}=2\pi$ 是同一件事（把 $z=x+iy$ 代入）。第二级《复变函数与积分变换》里，留数定理用「绕奇点的积分」计算各种定积分——今天的「挖洞法 + 环量常数」，是那条深刻理论的二维前奏。</span>

## 5 路径无关的判据总览

| 条件 | 判定 | 用法 |
| --- | --- | --- |
| 旋度为零 | $Q_x-P_y=0$（单连通） | 验证路径无关 |
| 闭曲线积分 = 0 | $\oint=0$（一切闭曲线） | 路径无关的等价说法 |
| 势函数存在 | $du=Pdx+Qdy$ | 积分 = 端点势差 |
| 挖洞处理 | 奇点环量 = 常数 | 带奇点的区域 |

**「单连通 + 旋度为零 ⇒ 路径无关」**是标准判据；「势函数」是路径无关的「积分果实」。

## 6 计算示范：路径无关的实战

**示范一（判路径无关 + 求势函数 + 代端点）**：$\vec F=(y^2,\ 2xy)$。

- **判旋度**：$Q_x-P_y=(2y)-(2y)=0$，且定义域 $\mathbb R^2$ 单连通——**路径无关**，存在势函数。
- **求势函数**：由 $u_x=y^2$ 对 $x$ 积分：$u=xy^2+\varphi(y)$；$u_y=2xy+\varphi'(y)=2xy\Rightarrow\varphi'(y)=0$，故 $u=xy^2+C$。
- **代端点**：$\int_{(1,0)}^{(0,2)}(y^2\,dx+2xy\,dy)=\bigl[xy^2\bigr]_{(1,0)}^{(0,2)}=0-0=0$。

**三步一气呵成**——验证旋度、积分求 $u$、代端点，正是「路径无关题」的标准流水线。

**示范二（含奇点：绕洞一圈 ≠ 0）**：$\vec F=\frac{-y}{x^2+y^2}dx+\frac{x}{x^2+y^2}dy$ 在 $\mathbb R^2\setminus\{0\}$ 上旋度为零，但绕单位圆逆时针一圈（$x=\cos t,\ y=\sin t$）：

$$\oint\frac{-y\,dx+x\,dy}{x^2+y^2}=\int_0^{2\pi}\frac{\sin^2t+\cos^2t}{1}dt=2\pi\ne0.$$

**旋度恒零却环量非零**——因为原点这个「洞」破坏了单连通性。**「单连通 + 旋度零」缺一不可**，这是路径无关判据最容易踩的坑。<span class="marginnote">注意示范二中「路径无关」到底失败在哪：绕原点的闭曲线积分为 $2\pi$，从 $(1,0)$ 走上半圆到 $(-1,0)$ 与走下半圆到 $(-1,0)$，两条路径积分分别为 $\pi$ 与 $-\pi$——<strong>不同路径不同值，路径无关彻底失效</strong>。但「挖掉原点取单连通区域」后，在剩余区域内路径无关恢复成立。这个「挖洞救场」的手法，正是复变函数里「把多连通区域切开成单连通」的先声。</span>

**示范三（用线积分验证做功）**：在保守场 $u(x,y)=x^2y$（即 $\vec F=(2xy,\ x^2)$）中，沿任意路径从 $P(1,1)$ 到 $Q(2,3)$ 做功：

$$W=u(Q)-u(P)=2^2\cdot3-1^2\cdot1=12-1=11.$$

**不管路径怎么绕，做功恒为 11**——这正是「保守力做功与路径无关」的数值体现，也是物理里「势能差决定做功」的出处。

**示范四（判别「是否保守」的数值套路）**：$Q_x-P_y$ 的计算要逐项小心。$\vec F=(e^x\sin y,\ e^x\cos y)$：$Q_x=e^x\cos y$，$P_y=e^x\cos y$——相等，保守。势函数 $u=e^x\sin y$（直接看出：$u_x=e^x\sin y=P$，$u_y=e^x\cos y=Q$）。**「一眼看出势函数」往往比积分更快**，前提是对常见函数族的偏导够熟。

## 7 小结

- **路径无关**：$\int_C$ 只依赖端点；⇔ 一切闭曲线积分为 0。
- **四条件等价**（单连通）：路径无关 ⇔ 闭曲线积分 0 ⇔ 旋度为零 ⇔ 存在势函数。
- **势函数**：$u_x=P,\ u_y=Q$；积分 $=\ u(\text{终点})-u(\text{起点})$。
- **单连通前提**：有洞时旋度为零仍可能路径相关；$\frac{-y}{x^2+y^2}$ 绕洞环量 $2\pi$。
- **奇点处理**：挖洞法，绕奇点环量 = 常数——留数定理的雏形。
