## 为什么把两个话题放在一起

本节讲的两件事，一件是「用两个夹住一个」，一件是「以 0 为极限的特殊数列」。它们表面不同，内里却是同一个动作的两面：**判断一个数列是否趋近某个数，常常不需要直接计算它，而是把它「卡」在两个已知的数列之间。** 迫敛性（夹逼定理）给出「被夹住就必然跟着跑」的保证；无穷小数列则是「比 0 还难捉摸的东西」——它不是一个很小的数，而是一个以 0 为极限的过程，是一切「误差」「余项」「主部拆解」的主角。

上一节我们有了四则运算：已知 $a_n,b_n$ 收敛，就能算出组合后的极限。可现实里很多数列**算不出精确值**——比如 $\dfrac{\sin n}{n}$ 的极限是多少？直接套四则运算不行，因为 $\sin n$ 没有极限。这时候夹逼定理登场：虽然不知道它「精确在哪」，但知道它「跑不出哪两条道」，而这两条道的极限又相同，就足以断定它的极限。<span class="marginnote">「不知道精确位置，却知道它被夹在两条收敛到同一点的轨道之间」——这种思维方式会一直沿用到定积分、级数与勒贝格积分：很多存在性结论靠的不是算，而是「夹」。</span>

## 1 迫敛性：夹逼定理

**定理（迫敛性 / 夹逼定理 / Squeeze Theorem）**：设数列 $\{a_n\},\{b_n\},\{c_n\}$ 满足

- 从某一项起 $a_n\le b_n\le c_n$；
- $\displaystyle\lim_{n\to\infty}a_n=\lim_{n\to\infty}c_n=a$，

则 $\{b_n\}$ 收敛，且 $\displaystyle\lim_{n\to\infty}b_n=a$。

证明只有三行，但每行都是上两节语法的直接复用：

- 任给 $\varepsilon>0$，由 $a_n\to a$，存在 $N_1$，当 $n>N_1$ 时 $a-\varepsilon<a_n$；
- 由 $c_n\to a$，存在 $N_2$，当 $n>N_2$ 时 $c_n<a+\varepsilon$；
- 取 $N\ge\max\{N_1,N_2\}$ 且从该起 $a_n\le b_n\le c_n$，则当 $n>N$ 时
$$a-\varepsilon<a_n\le b_n\le c_n<a+\varepsilon,$$
即 $|b_n-a|<\varepsilon$。∎

> **辨析｜易错点：**夹逼有三个前提，缺一不可。第一，**两侧必须收敛到同一个极限**——两侧极限不同或有一侧发散，无法下结论；第二，不等式 $a_n\le b_n\le c_n$ **不必从第一项成立**，从某一项起即可；第三，也是新手最容易栽的——**夹逼只能证收敛，不能证发散**。想证 $b_n$ 发散，靠的是别的工具（比如无界、或周期性摆动）。

直觉上，夹逼定理说的是：**上界和下界都在向 $a$ 收缩，被夹在中间的 $b_n$ 想逃也逃不出去**。就像两条逐渐合拢的轨道，中间的小球只能沿着轨道最终抵达汇合点。

## 2 无穷小数列：以 0 为极限的过程

**无穷小数列（infinitesimal sequence）**：以 $0$ 为极限的数列，即 $\lim a_n=0$ 的数列，称为**无穷小数列**（或无穷小量）。

这个概念简单，却容易被名字误导。<span class="marginnote">「无穷小」不是「很小的数」，而是一个「趋近于 0 的变量」：$10^{-100}$ 是数但不是无穷小，$\dfrac{1}{n}$ 才是无穷小。这个区别是微积分历史上「无穷小论战」的核心，也是后来极限理论之所以要把「无穷小」严格定义为「以 0 为极限的数列」的原因。</span>

无穷小数列是极限分析的「零件」：既然 $a_n\to a$ 等价于误差 $a_n-a\to 0$，那么**研究收敛，本质上就是研究「误差」这个无穷小**。由此得到最重要的关系式：

$$a_n\to a \quad\Longleftrightarrow\quad a_n-a \text{ 是无穷小数列}.$$

这给了极限一种「主部 + 余部」的视角：$a_n=a+\alpha_n$，其中 $a$ 是主部（极限），$\alpha_n$ 是无穷小余部。后面研究函数极限、泰勒公式时，这个拆解会是贯穿始终的脚手架。

无穷小数列有两条漂亮的运算性质（证明都只是一两步放缩）：

- **有限个无穷小之和仍为无穷小。** 若 $\alpha_n,\beta_n\to 0$，则 $\alpha_n+\beta_n\to 0$：任给 $\varepsilon>0$，各自压到 $\varepsilon/2$ 再相加。
- **无穷小与有界数列之积仍为无穷小。** 若 $\alpha_n\to 0$ 且 $|b_n|\le M$，则 $\alpha_n b_n\to 0$：因为 $|\alpha_n b_n|\le M|\alpha_n|$，压 $|\alpha_n|<\varepsilon/M$ 即可。

第二条尤其常用：它说明「一个很小的量乘以一个有界的东西，仍然很小」——比如 $\dfrac{\sin n}{n}$ 中，$\dfrac{1}{n}$ 是无穷小，$\sin n$ 有界，乘积就是无穷小，所以 $\dfrac{\sin n}{n}\to 0$。

还有一个平凡却常被忽略的事实：**常数数列若为无穷小，只能是全零数列**。因为若 $a_n\equiv c$ 且 $a_n\to 0$，则 $|c|=|a_n-0|<\varepsilon$ 对一切 $n$ 与一切 $\varepsilon$ 成立，只能 $c=0$。它提醒我们：无穷小是「动态趋零」的变量，而不是静止的数值。<span class="marginnote">这个例子已经提前碰见了后面「两个重要极限」之一的近亲：$\dfrac{\sin x}{x}$ 在 $x\to 0$ 时极限是 1（那要等第三章），而 $\dfrac{\sin n}{n}$（$n\to\infty$）的极限是 0——方向不同，结论天差地别。</span>

## 3 公式解析：证明 $\lim_{n\to\infty}\sqrt[n]{n}=1$

这是夹逼定理最经典的应用之一。结论反直觉：$n$ 次根号把 $n$「拉回」到 $1$——$n$ 增长得再猛，被 $1/n$ 次方一压，还是被压回 $1$。我们用「引入正量 + 二项式展开 + 夹逼」三步拿下。

**第一步，设根号稍大于 1。** 因为 $\sqrt[n]{n}\ge 1$，令
$$x_n=\sqrt[n]{n}-1\ge 0,$$
目标是证明 $x_n\to 0$。

**第二步，用二项式展开放缩出 $x_n$ 的上界。** 由 $n=(1+x_n)^n$，把 $(1+x_n)^n$ 的二项式展开只保留前两项：
$$n=(1+x_n)^n=1+n x_n+\binom{n}{2}x_n^2+\cdots\ge \binom{n}{2}x_n^2=\frac{n(n-1)}{2}x_n^2.$$
于是
$$x_n^2\le\frac{n}{n(n-1)/2}=\frac{2}{n-1},\qquad\text{即}\qquad 0\le x_n\le\sqrt{\frac{2}{n-1}}.$$

**第三步，夹逼收口。** 注意到 $\sqrt{\dfrac{2}{n-1}}\to 0$（$n\to\infty$），左右两端分别是 $0$ 与 $\sqrt{\dfrac{2}{n-1}}$，都趋于 $0$。由夹逼定理，
$$x_n\to 0,\qquad\text{即}\qquad \sqrt[n]{n}=1+x_n\to 1.$$
∎

这条证明链的精髓在第二步：**把「根号式」翻译成「二项式」**，展开后挑出关键的一项做下界，就得到了 $x_n$ 可以被 $n$ 显式控制的上界。同样的手法可以证明 $\lim\sqrt[n]{a}=1$（$a>0$）：设 $x_n=\sqrt[n]{a}-1\ge 0$，由 $a=(1+x_n)^n\ge 1+n x_n$ 得 $0\le x_n\le\dfrac{a-1}{n}\to 0$。<span class="marginnote">注意两处放缩的差别：$\sqrt[n]{n}$ 要保留二次项 $\binom{n}{2}x_n^2$ 才能压住 $n$（因为一次项 $nx_n$ 只能给出 $x_n\le \frac{n-1}{n}\not\to 0$，不够用），而 $\sqrt[n]{a}$ 是常数底、一次项就够。挑哪一项，取决于对手是「变底」还是「常底」。</span>

## 4 应用：用夹逼处理「算不出」的极限

夹逼定理最常见的战场，是那些**本身无法用四则运算直接求**的极限。三个典型：

**例 1（有界因子 × 无穷小）：** 上面已见，$\dfrac{\sin n}{n}\to 0$（夹在 $-\dfrac1n$ 与 $\dfrac1n$ 之间）。

**例 2（凑主项）：**
$$\lim_{n\to\infty}\left(\sqrt{n^2+n}-n\right).$$
直接算会撞上「$\infty-\infty$」。有理化：
$$\sqrt{n^2+n}-n=\frac{(\sqrt{n^2+n}-n)(\sqrt{n^2+n}+n)}{\sqrt{n^2+n}+n}=\frac{n}{\sqrt{n^2+n}+n},$$
再同除以 $n$：
$$=\frac{1}{\sqrt{1+\frac1n}+1}\longrightarrow\frac{1}{1+1}=\frac12.$$
有理化把「差」变成「商」，分母极限 $2\ne 0$，就可以放心取极限了。

**例 3（用夹逼证主项为 0）：** $\displaystyle\lim_{n\to\infty}\frac{n}{2^n}=0$。用伯努利不等式 $2^n=(1+1)^n\ge 1+n+\dfrac{n(n-1)}{2}>\dfrac{n(n-1)}2$，得
$$0<\frac{n}{2^n}<\frac{n}{n(n-1)/2}=\frac{2}{n-1}\to 0.$$
夹逼给出 $\dfrac{n}{2^n}\to 0$——指数增长打败多项式增长。<span class="marginnote">「指数打败多项式」是分析里最重要的增长排序之一：$2^n\gg n^k$（任意固定 $k$）。到第四级《算法》你会看到它决定了为什么指数级复杂度不可救药、多项式级勉强可用。数学分析的这一小节，正是那一判断的严格来源。</span>

> **辨析｜易错点：**例 2 的有理化，容易错在把 $\sqrt{n^2+n}$ 当 $n$ 直接代入——$\sqrt{n^2+n}=n\sqrt{1+1/n}\approx n+\frac12$，差的那 $\frac12$ 恰好就是答案。**求差型极限，千万不要把主项以外的部分随手丢弃**；先有理化，或先展开到足够阶，再取极限。

## 5 无穷小与迫敛的关系

把本节两件事放在一起看：夹逼定理本质上是「**用两个已知的无穷小控制一个新无穷小**」——当 $a_n\to a$ 且 $c_n\to a$ 时，$a_n-a$ 与 $c_n-a$ 都是无穷小，且 $a_n-a\le b_n-a\le c_n-a$，被上下两个无穷小夹住的 $b_n-a$ 也是无穷小，于是 $b_n\to a$。

所以夹逼定理的「主部 + 余部」画面是：**误差被夹在两条都会收敛到 0 的轨道之间**。这解释了为什么夹逼常常与无穷小配合使用：先构造上、下界，让它们的误差成为能被 $n$ 显式控制的无穷小，再借夹逼把中间数列的误差也压成无穷小。

顺带说一句「有限」与「无限」的边界：有限个无穷小之和仍是无穷小，但**无限个无穷小之和可能不是无穷小**——例如 $n$ 个 $\dfrac1n$ 相加等于 $1$。这个「有限成立、无限失效」的警报，是后面级数理论的核心张力，也是实变函数「可数可加性」要处理的问题。<span class="marginnote">第三级《实变函数》中，勒贝格积分相对黎曼积分的一大优势，正是把「有限可加」升级成「可数可加」。这里的「无限个无穷小之和」警报，是那条路的起点。</span>

## 6 小结

- **迫敛性（夹逼）**：$a_n\le b_n\le c_n$（从某端起）且两侧极限同为 $a$，则 $b_n\to a$。前提缺一不可。
- **无穷小数列**：以 $0$ 为极限的数列；$a_n\to a\iff a_n-a$ 是无穷小（主部 + 余部视角）。
- **无穷小运算**：有限个之和仍为无穷小；无穷小乘有界数列仍为无穷小（例：$\dfrac{\sin n}{n}\to 0$）。
- **样板证明**：$\sqrt[n]{n}\to 1$（设根号减 1、二项式展开、夹逼）；$\dfrac{n}{2^n}\to 0$（伯努利不等式 + 夹逼）。
- 方法论：算不出精确值的极限，用「夹」；求差型极限先有理化；注意有限与无限在「和」上的本质差别。

在下一节，我们把视野从「给定数列求极限」转向「给定条件判断极限是否存在」：不把数列具体写出来，只凭「单调 + 有界」两个条件，就断言它必然收敛——这就是**单调有界定理**。
