## 为什么从酶催化动力学开始

酶是自然界最精妙的催化剂：效率高到每秒转化百万个底物分子，专一性精确到只认一种底物。理解酶，就是理解生命体内所有的生化反应如何被精确调控。<span class="marginnote">酶催化动力学把上一节《催化原理》的通用框架应用到生物大分子：酶的活性位点像一个「分子车间」，底物结合后发生催化、产物释放、酶复原。米氏方程（Michaelis–Menten）是酶动力学最核心的方程——它用两个参数（$K_m$、$V_\text{max}$）就能描述酶的催化行为，是药理学、代谢学、生物化学的共同语言。</span>

在课程轴上，酶动力学是物理化学与生命科学的接口：米氏方程的推导用的是《链反应》一节的稳态近似，酶的催化原理是《催化原理》的均相催化特例，而酶的调控（别构、反馈抑制）又是热力学与动力学在活细胞中的协同。

## 1 酶的特征与米氏机理

**酶（enzyme）** 是蛋白质（少数是 RNA），其**活性位点（active site）** 是底物结合与催化的部位。酶的标志性特征：

- **高效**：速率提升 $10^6\text{–}10^{14}$ 倍（对比非催化）。
- **专一**：只催化特定底物（锁钥或诱导契合模型）。
- **可调控**：底物浓度、产物、别构调节物、抑制剂都能调其活性。

酶催化的标准机理（米氏机理）：

$$\ce{E + S <=>[$k_1$][$k_{-1}$] ES ->[$k_2$] E + P}$$

酶 E 与底物 S 可逆结合成复合物 ES，ES 再分解为产物 P 并释放酶。**这是「反应物结合 → 催化 → 释放」的最小催化循环。**<span class="marginnote">米氏机理与《催化原理》的催化循环完全同构：E 是催化剂、ES 是活性中间体、E 净不消耗。差别在于酶循环的每一步都有精确的速率常数 $k_1$、$k_{-1}$、$k_2$，可被实验逐一测定——酶是「机理最透明」的催化剂。</span>

## 2 米氏方程：由稳态近似推导

对 ES 用稳态近似（$\mathrm{d}[\ce{ES}]/\mathrm{d}t = 0$），设总酶浓度 $[\ce{E}]_0 = [\ce{E}] + [\ce{ES}]$ 恒定，解出 $[\ce{ES}]$ 后代入产物生成速率 $v = k_2[\ce{ES}]$，得**米氏方程（Michaelis–Menten equation）**：

$$v = \frac{V_\text{max}[\ce{S}]}{K_m + [\ce{S}]}, \qquad V_\text{max} = k_2[\ce{E}]_0, \qquad K_m = \frac{k_{-1} + k_2}{k_1}$$

其中 $V_\text{max}$ 是最大速率（酶全被底物饱和），$K_m$ 是**米氏常数**。<span class="marginnote">$K_m$ 的量纲是浓度，数值上等于 $v = V_\text{max}/2$ 时的底物浓度。它衡量「底物与酶的结合强度」：$K_m$ 小 → 低底物浓度就能达到半速 → 酶对底物亲和力高。但严格说 $K_m$ 是 $k_{-1}+k_2$ 与 $k_1$ 之比，只有在 $k_{-1} \gg k_2$（ES 分解慢、达准平衡）时才近似等于解离常数 $K_d = k_{-1}/k_1$。</span>

**重点：米氏方程的两段极限。** $[\ce{S}] \ll K_m$ 时 $v \approx \dfrac{V_\text{max}}{K_m}[\ce{S}]$——准一级，速率正比底物；$[\ce{S}] \gg K_m$ 时 $v \to V_\text{max}$——零级，酶饱和。这条「先线性、后饱和」的曲线就是《一级/二级反应动力学》里零级到一级的连续过渡。

## 3 米氏参数与催化常数

- **$K_m$（米氏常数）**：特征浓度，底物亲和力的量度。生理上 $\ce{K_m}$ 接近细胞内底物浓度，使酶对底物变化最灵敏。
- **$V_\text{max}$**：最大速率，正比酶总量 $[\ce{E}]_0$。测 $V_\text{max}$ 可定量酶的活性单位。
- **$k_\text{cat} = V_\text{max}/[\ce{E}]_0$**：**转换数（turnover number）**——单个酶分子每秒转化的底物分子数，是酶催化效率的直接指标。碳酸酐酶 $k_\text{cat} \approx 10^6\ \text{s}^{-1}$，是已知最快的酶之一。
- **$k_\text{cat}/K_m$**：**催化效率（specificity constant）**，同时衡量结合与催化，是酶优劣的总评分。<span class="marginnote">$k_\text{cat}/K_m$ 的极限：当它接近扩散控制极限（约 $10^8\text{–}10^9\ \text{L·mol}^{-1}\text{s}^{-1}$），酶已达到「每遇一次底物就催化一次」的完美程度——催化效率理论上的天花板。多种底物竞争时，$k_\text{cat}/K_m$ 最高的底物占优，这就是酶专一性的定量来源。</span>

## 4 公式解析：米氏方程 $v = \frac{V_\text{max}[\ce{S}]}{K_m + [\ce{S}]}$

**米氏方程是「饱和动力学」的原型，也是稳态近似的经典成果。** 四步拆解：

- **第一步，写 ES 的稳态方程**：$\dfrac{\mathrm{d}[\ce{ES}]}{\mathrm{d}t} = k_1[\ce{E}][\ce{S}] - (k_{-1} + k_2)[\ce{ES}] = 0$。**生成速率 $k_1[\ce{E}][\ce{S}]$ 与消耗速率 $(k_{-1}+k_2)[\ce{ES}]$ 平衡**——消耗包括解离回去（$k_{-1}$）与变成产物（$k_2$）。
- **第二步，代入酶守恒**：$[\ce{E}] = [\ce{E}]_0 - [\ce{ES}]$，解出 $[\ce{ES}] = \dfrac{k_1[\ce{E}]_0[\ce{S}]}{k_{-1}+k_2 + k_1[\ce{S}]}$。这是稳态下 ES 的浓度。
- **第三步，写成米氏形式**：$v = k_2[\ce{ES}]$，分子分母同除 $k_1$，得 $v = \dfrac{k_2[\ce{E}]_0[\ce{S}]}{(k_{-1}+k_2)/k_1 + [\ce{S}]} = \dfrac{V_\text{max}[\ce{S}]}{K_m + [\ce{S}]}$。
- **第四步，看参数测定**：**双倒数作图（Lineweaver–Burk）**：$\dfrac{1}{v} = \dfrac{K_m}{V_\text{max}}\cdot\dfrac{1}{[\ce{S}]} + \dfrac{1}{V_\text{max}}$，以 $1/v$ 对 $1/[\ce{S}]$ 作图得直线——斜率 $K_m/V_\text{max}$、截距 $1/V_\text{max}$，两个参数一次读出。

## 5 酶抑制

**酶抑制剂（inhibitor）** 降低酶活性，按作用方式分：

- **竞争性抑制（competitive）**：抑制剂与底物争抢活性位点。$K_m$ 增大（表观）、$V_\text{max}$ 不变——增大 $[\ce{S}]$ 可克服。双倒数图上不同抑制剂浓度直线交于 $1/V_\text{max}$ 轴。
- **非竞争性抑制（non-competitive）**：抑制剂结合在非活性位点，$V_\text{max}$ 减小、$K_m$ 不变。增大底物无法克服——双倒数图直线交于横轴。
- **不可逆抑制**：抑制剂与酶共价结合，酶永久失活（如有机磷毒剂抑制乙酰胆碱酯酶）。<span class="marginnote">竞争性抑制是药学设计的核心：很多药物是「酶的竞争性抑制剂」，如他汀抑制 HMG-CoA 还原酶、甲氨蝶呤抑制二氢叶酸还原酶。区分抑制类型靠双倒数图的直线交点位置——竞争交纵轴、非竞争交横轴。药理学里「$K_i$」（抑制常数）的测定就用这套酶动力学。</span>

**辨析｜易错点：** 「竞争性」指**结合位点**竞争，不是「浓度大小」竞争。竞争性抑制剂不改变 $V_\text{max}$，只升高表观 $K_m$；非竞争性反之。判断类型看双倒数图交点，不看直觉。

## 6 酶的调控与米氏动力学的边界

真实酶常受更复杂的调控：

- **别构调节（allosteric regulation）**：效应物结合在非活性位点，改变酶构象、进而改变活性——S 形（sigmoidal）速率曲线而非米氏双曲线。
- **反馈抑制（feedback inhibition）**：代谢产物抑制途径上游的酶，实现通路自我调节。
- **产物抑制、pH 与温度依赖**：酶活性-温度有最适温度，过高变性失活。<span class="marginnote">米氏方程是「单底物、无调控」的简单模型。别构酶（如血红蛋白、磷酸果糖激酶）用希尔方程描述：$v = \dfrac{V_\text{max}[\ce{S}]^n}{K + [\ce{S}]^n}$，$n$（希尔系数）> 1 表示协同。从米氏到希尔，是从「简单酶」走向「调控酶」的阶梯，也是理解代谢调控的第一步。</span>

## 7 酶动力学在现代生物医学中的应用

米氏方程是现代药物设计与临床诊断的定量工具。

**药物设计的 $K_i$ 测定**：酶抑制剂候选物的活性用抑制常数 $K_i$ 定量。竞争性抑制的双倒数图在不同抑制剂浓度下交于 $1/V_\text{max}$ 轴，由斜率变化求 $K_i$——**$K_i$ 是药物与靶酶结合强度的直接度量**，新药筛选的核心指标之一。

**药代动力学的一级近似**：药物在体内的消除常按一级动力学近似，清除率与半衰期 $t_{1/2} = \ln2/k$ 决定给药间隔。多剂量给药达到稳态浓度的计算、治疗窗（有效浓度与毒性浓度之间）的把握，都建立在酶动力学（代谢酶）与一级消除模型之上。

**代谢酶与药物相互作用**：细胞色素 P450 酶家族代谢大多数药物。一个药物抑制或诱导某个 P450 酶，会改变其他药物的代谢速率——**基于米氏动力学的「药物-药物相互作用」评估是药理学常规**。抑制使 $V_\text{max}$ 下降（非竞争）或 $K_m$ 上升（竞争），后果是合用药物浓度升/降。

**酶活性诊断**：临床上测血清酶活性（如转氨酶、乳酸脱氢酶）诊断组织损伤。酶活性测定用的就是米氏动力学原理：在底物饱和区（$v \to V_\text{max}$）测反应初速率，速率正比酶量——**一次比色动力学测定，读出酶浓度**。

**辨析｜易错点：** 体外测定的 $K_m$、$V_\text{max}$ 与体内行为有差距：体内有蛋白结合、组织分布、代谢旁路，且底物浓度常低于 $K_m$（一级区）。把体外表征直接外推到体内剂量设计，须结合药代模型，不可机械套用米氏参数。

一个用双倒数作图提取米氏参数的完整算例。某酶催化反应在几个底物浓度下的初速率：

| $[\ce{S}]$ / mmol·L⁻¹ | $v$ / µmol·L⁻¹·s⁻¹ | $1/[\ce{S}]$ / L·mmol⁻¹ | $1/v$ / L·s·µmol⁻¹ |
| --- | --- | --- | --- |
| 0.5 | 1.25 | 2.0 | 0.80 |
| 1.0 | 2.00 | 1.0 | 0.50 |
| 2.0 | 3.33 | 0.5 | 0.30 |
| 5.0 | 5.00 | 0.2 | 0.20 |

**双倒数方程** $\dfrac{1}{v} = \dfrac{K_m}{V_\text{max}}\cdot\dfrac{1}{[\ce{S}]} + \dfrac{1}{V_\text{max}}$。由表，$1/v$ 对 $1/[\ce{S}]$ 为直线，截距 $1/V_\text{max} = 0.10$，故 $V_\text{max} = 10\ \mu\text{mol·L}^{-1}\text{s}^{-1}$；斜率 $K_m/V_\text{max} = (0.80-0.20)/(2.0-0.2) = 0.60/1.8 \approx 0.333$，故 $K_m = 0.333\times10 = 3.3\ \text{mmol·L}^{-1}$。

**解读**：$K_m = 3.3\ \text{mmol/L}$ 表示底物浓度达到 3.3 mmol/L 时速率到一半——**$K_m$ 越小，酶对底物越「敏锐」**。若已知酶浓度 $[\ce{E}]_0 = 1\ \mu\text{mol·L}^{-1}$，转换数 $k_\text{cat} = V_\text{max}/[\ce{E}]_0 = 10\ \text{s}^{-1}$，催化效率 $k_\text{cat}/K_m = 10/(3.3\times10^{-3}) \approx 3000\ \text{L·mol}^{-1}\text{s}^{-1}$——三个参数一次拟合全部提取，是酶动力学分析的标准操作。

把酶动力学放回《催化原理》的自然延伸。**酶是催化原理的「生物版」**——催化循环、活性位、专一性在酶这里达到极致：$k_\text{cat}$ 可达每秒百万次、$k_\text{cat}/K_m$ 可逼近扩散极限。米氏方程的推导用的是《链反应》的稳态近似，参数提取用的是双倒数作图，抑制剂分析又是催化活性调控的精确工具。

**重点：酶动力学是「生命体的调控语言」**。代谢通路的酶活性由底物浓度（米氏动力学）、产物抑制、别构调节共同控制，药物的疗效与毒性由靶酶的 $K_i$ 决定——**米氏参数不是书上的符号，而是药代与代谢的实操标尺**。理解「$K_m$ 是半速浓度、$V_\text{max}$ 是饱和速率、$k_\text{cat}/K_m$ 是催化效率」三件套，就掌握了从酶学测定到药物设计的基本工具。

## 8 小结

- **酶**是高效、专一、可调控的催化剂；米氏机理 $\ce{E + S <=> ES -> E + P}$ 是催化循环最小模型。
- **米氏方程** $v = \dfrac{V_\text{max}[\ce{S}]}{K_m + [\ce{S}]}$：低底物准一级、高底物零级饱和，由稳态近似导出。
- $K_m$（亲和力）、$V_\text{max}$（酶量）、$k_\text{cat}$（转换数）、$k_\text{cat}/K_m$（催化效率）四个参数完备刻画酶。
- **双倒数作图**由直线求 $K_m$、$V_\text{max}$；竞争/非竞争抑制在图上各具特征。
- 别构酶用希尔方程（S 形曲线），反馈抑制实现代谢通路调控。

在下一节，我们把动力学的「光源」打开——**光化学动力学**：光子作为反应物，激发态化学与量子产率。
