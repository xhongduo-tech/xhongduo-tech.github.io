# 相平衡与相图

<div class="epigraph">
<p>多相系统的平衡条件，是每一个组分在所有相中的化学势相等。</p>

## 为什么从相平衡与相图开始

冰、水、水蒸气共存于一个杯子，为什么偏偏是在 $0.01\,^\circ\text{C}$ 与 $611\ \text{Pa}$？水为什么有反常的相图、冰能浮在水上？合金、石油分馏、半导体结晶的工艺参数又从哪里来？这些问题的统一答案藏在**相平衡**里。上一节确立的「各相化学势相等」在此落地为一张可以亲手画、随手查的**相图（phase diagram）**——物质的存在形态随温度、压力、组成变化的全局地图。<span class="marginnote">相图是物理化学最「可视化」的分支，也是连接实验室与工业的桥梁：钢铁热处理看铁碳相图，药物结晶筛选看溶剂-溶质相图，色谱分离的依据也是液-液相平衡。学会读相图，等于学会用一张图回答「什么条件下什么形态稳定」。</span>

## 1 相、组分与自由度数

三个基本概念先行：

- **相（phase）**：系统内物理性质与化学性质完全均匀的部分。冰水混合是两相（固、液），乙醇水溶液是一相（分子级均匀）。
- **独立组分数 $K$**：构成系统各相所需的最少独立物质种数。若各物质间无化学反应，$K$ 等于物种数；有反应则减去独立平衡关系数。
- **自由度数 $f$**：在保持相数不变的条件下，可以独立改变的强度变量（温度、压力、浓度）的数目。

**相律（phase rule）** 把它们统一起来：

$$f = K - \Phi + 2$$

其中 $\Phi$ 是相数，2 来自温度和压力两个可调强度变量。<span class="marginnote">相律的威力在于不涉及具体物质就能给出普适约束：纯水 $K=1$，单相时 $f=2$（温度压力都独立可调）；两相共存时 $f=1$（给定温度压力即定）；三相共存时 $f=0$——三相点没有自由度，温度压力都被锁定。这就是为什么冰-水-汽只能在一个点同时存在。</span>

**重点：自由度数的物理意义是「在不破坏相平衡的前提下还能自由变几个变量」。** 相律是系统可能形态的会计学，它告诉我们什么不能发生——例如纯物质不可能有四个相共存，因为那会给出 $f = 1 - 4 + 2 = -1 < 0$。

## 2 单组分系统：水的相图

对单组分系统，相图是 $p$-$T$ 平面上的图。水的相图（示意图见图 1）由三条平衡线分割出固、液、气三个单相区，两个特殊点（三相点、临界点）构成全图骨架。

![水的相图示意：三条平衡线交汇于三相点](/images/physical-chemistry/phase-equilibrium-and-phase-diagrams-1.svg)

- **汽化线**（液⇌气）：水蒸气压随温度升高，止于**临界点**（$374.2\,^\circ\text{C}$、$22.06\ \text{MPa}$）。超过临界点后液气不可区分，只有超临界流体。
- **熔化线**（固⇌液）：斜率陡峭。绝大多数物质熔化线向右倾（压力越大越难熔化，如二氧化碳），**水例外——向左倾**：压力增大反而降低冰点。这是水能浮冰、湖底不冻的根源。
- **升华线**（固⇌气）：固态直接升华为气。
- **三相点**：$0.01\,^\circ\text{C}$、$611\ \text{Pa}$，三条线唯一交点，$f = 0$。

**辨析｜易错点：** 三相点（$0.01\,^\circ\text{C}$）与常说的冰点（$0\,^\circ\text{C}$）不同。常压冰点是「被空气溶解与压力影响过的」三相共存温度，比三相点低 $0.01\ \text{K}$。热力学温标以水的三相点为固定点（$273.16\ \text{K}$），因为它是可复现的天然基准。

## 3 克拉佩龙与克劳修斯-克拉佩龙方程

两相平衡线上的任意一点，两相化学势相等：$\mu^\alpha = \mu^\beta$。沿线移动时保持相等，即 $\mathrm{d}\mu^\alpha = \mathrm{d}\mu^\beta$。代入 $\mathrm{d}\mu = -S\,\mathrm{d}T + V\,\mathrm{d}p$（对 1 mol 纯物质），得到**克拉佩龙方程（Clapeyron equation）**：

$$\frac{\mathrm{d}p}{\mathrm{d}T} = \frac{\Delta H_\text{m}}{T\,\Delta V_\text{m}}$$

其中 $\Delta H_\text{m}$ 是摩尔相变焓（熔化、汽化或升华），$\Delta V_\text{m}$ 是摩尔体积变化。**熔化线的负斜率正是由 $\Delta V_\text{m} < 0$（水结冰体积增大）造成的**——公式的符号直接解释了水的反常。

对气-液、气-固平衡，气相摩尔体积远大于凝聚相，把气相近似为理想气体 $V_\text{g} = RT/p$，代入得**克劳修斯-克拉佩龙方程（Clausius–Clapeyron equation）**：

$$\frac{\mathrm{d}\ln p}{\mathrm{d}T} = \frac{\Delta_\text{vap}H_\text{m}}{RT^2}$$

## 4 公式解析：克劳修斯-克拉佩龙方程的积分形式

**这是工程上计算蒸气压随温度变化的实用工具。** 设汽化焓与温度无关，积分上式：

$$\ln\frac{p_2}{p_1} = -\frac{\Delta_\text{vap}H_\text{m}}{R}\left(\frac{1}{T_2} - \frac{1}{T_1}\right)$$

- **第一步，看变量的配对**：$(p_1, T_1)$ 与 $(p_2, T_2)$ 是相平衡线上两点。已知一个基准点（如常压沸点 $p_1 = 101.325\ \text{kPa}$、$T_1 = 373\ \text{K}$）与汽化焓，即可求任意温度下的蒸气压。
- **第二步，看斜率的意义**：$\ln p$ 对 $1/T$ 作图是一条直线，斜率为 $-\Delta_\text{vap}H_\text{m}/R$。实验上测一系列温度下的蒸气压，用这条直线就能反推汽化焓——这是测定汽化焓的标准方法。
- **第三步，看适用范围**：它假设气体理想、汽化焓不随温度变，故只在远离临界点、温度区间不宽时准确。汽化焓本身随温度升高而减小，到临界点降为零。
- **第四步，回到相图**：方程还预言「沸点随外压升高而升高」。高原上气压低，水在 $80\,^\circ\text{C}$ 左右就沸腾——高压锅反之，把沸点推到 $120\,^\circ\text{C}$ 以上，正是这个方程在厨房里的应用。

## 5 二组分系统：从相律到精馏原理

二组分系统 $K = 2$，相律 $f = 2 - \Phi + 2 = 4 - \Phi$。单相区 $f = 3$（$T$、$p$、组成），常固定 $p$ 使相图退化为 $T$-$x$ 图。理想溶液（两组分都服从拉乌尔定律）的 $T$-$x$ 图由泡点线与露点线构成：

- 液相线上方是气、下方是液；两线之间的梭形区是**两相共存区**。
- 气相的易挥发组分摩尔分数大于液相——这就是**精馏（fractional distillation）**的分离原理：反复蒸发冷凝，把易挥发组分富集到气相。
- 非理想溶液可能出现**恒沸物（azeotrope）**：$T$-$x$ 图上出现极值点，此时气相组成等于液相组成，精馏无法跨越，乙醇-水约在 $95.6\%$ 处形成恒沸物。<span class="marginnote">恒沸物不是化合物，只是特定温度组成下两相组成恰好相等。打破恒沸要靠共沸精馏（加第三组分如苯）或分子筛吸附脱水——工业无水乙醇正是这样生产的。</span>

**杠杆规则（lever rule）** 定量给出两相区各相的量：两相区中某总组成点，两相的量之比等于线段长度反比，就像杠杆平衡。设总组成为 $z$，液相组成 $x_l$、气相组成 $x_g$，则液相量 $n_l$ 与气相量 $n_g$ 满足：

$$\frac{n_l}{n_g} = \frac{x_g - z}{z - x_l}$$

**重点：相图是「地图」，杠杆规则是「天平」。** 前者告诉你各温度组成下有哪些相，后者告诉你在两相区各相各有多少。两者结合，就能完整回答任意降温结晶或蒸馏过程每一步的相变行为。

## 6 二组分相图的实战阅读

以「精馏分离乙醇-水」为例，把 $T$-$x$ 图用到实战。

**第一步，认图**。乙醇-水在常压下不是理想溶液，$T$-$x$ 图出现**最低恒沸点**（约 $78.2\,^\circ\text{C}$、乙醇 $95.6\%$）。恒沸点处气相组成等于液相组成，杠杆规则的分离「在此失效」——精馏无法跨越恒沸组成。

**第二步，定操作**。对低于恒沸组成的乙醇水溶液（如 $30\%$），升温进入两相区，气相富含乙醇（易挥发组分富集），冷凝后组成提高；反复精馏可把乙醇含量推到恒沸组成——但**再往上推不动**，这就是工业上「无水乙醇不能靠普通精馏直接制得」的原因。

**第三步，打破恒沸**。加第三组分（苯、环己烷）形成新的恒沸体系（三元恒沸精馏），或改用分子筛吸附脱水、渗透汽化膜分离——**绕开恒沸点才能得到纯乙醇**。

**杠杆规则定量**：对 $50\%$ 总组成的乙醇-水在 $T = 80\,^\circ\text{C}$ 处处于两相区，若液相组成 $x_l = 40\%$、气相组成 $x_g = 75\%$，则气相量 : 液相量 $= (50-40) : (75-50) = 1:2.5$。**知道两相组成与总组成，就能算出各相的量**——这是蒸馏、结晶、萃取分离所有物料衡算的基础。

**辨析｜易错点：** 恒沸点处「气相组成 = 液相组成」不是说「没有相变」，而是说**相变不改变组成**——连续汽化只改变总量不改变组成。恒沸物不是化合物（比例随压力变），改变压力可移动甚至消除恒沸点——**变压精馏（PSA 式的变压力分离）利用的正是这一点**。

一个用克劳修斯-克拉佩龙方程做工程估算的算例。水在 $100\,^\circ\text{C}$ 的汽化焓 $40.7\ \text{kJ·mol}^{-1}$，求海拔 3000 m 处（大气压约 $70\ \text{kPa}$）水的沸点。由积分式：

$$\ln\frac{p_2}{p_1} = -\frac{\Delta_\text{vap}H}{R}\left(\frac{1}{T_2} - \frac{1}{T_1}\right) \quad\Longrightarrow\quad \ln\frac{70}{101.3} = -\frac{40700}{8.314}\left(\frac{1}{T_2} - \frac{1}{373.15}\right)$$

$$\frac{1}{T_2} = \frac{1}{373.15} + \frac{8.314\times\ln(101.3/70)}{40700} = 0.002680 + 7.27\times10^{-5} = 0.002753$$

$$T_2 = 363.3\ \text{K} \approx 90\,^\circ\text{C}$$

**3000 m 高原上水约 90 °C 就沸腾**——与高原煮饭「夹生」的经验完全一致。反向应用：高压锅把压力升到 $2\ \text{atm}$，沸点推高到约 $120\,^\circ\text{C}$，蒸煮时间大幅缩短。**一条克劳修斯-克拉佩龙方程，同时解释了高原烹饪与高压锅**，这就是相平衡方程「从实验室到厨房」的日常威力。

把相平衡放回《化学势》的延伸。**相平衡是「化学势相等」在相变上的具体化**——克拉佩龙方程给出相图曲线的斜率，克劳修斯-克拉佩龙方程给出蒸气压的温度依赖，相律给出系统的自由度约束。单组分相图的三相点、临界点与二组分相图的精馏原理，构成了「读图」与「用图」的完整体系。

**重点：相图是「物质存在形态的地图」**。从水的反常熔化线到乙醇-水恒沸物，从金属热处理到药物结晶筛选，相图把「什么条件下什么相稳定」压缩成一张可读的图。理解「化学势相等是平衡、克拉佩龙给斜率、相律给自由度」这三条主线，就掌握了从冰水共存到工业精馏的统一框架。

## 7 小结

- **相律** $f = K - \Phi + 2$：不破坏相平衡的可独立变量数；纯物质三相点 $f = 0$。
- **克拉佩龙方程** $\mathrm{d}p/\mathrm{d}T = \Delta H_\text{m}/(T\Delta V_\text{m})$，水熔化线负斜率源于 $\Delta V_\text{m} < 0$。
- **克劳修斯-克拉佩龙方程** $\ln(p_2/p_1) = -\Delta_\text{vap}H_\text{m}/R \cdot (1/T_2 - 1/T_1)$，可求任意温度蒸气压与汽化焓。
- 单组分相图由三条平衡线、三相点、临界点构成；二组分 $T$-$x$ 图用**杠杆规则**算两相量。
- 恒沸物阻挡精馏分离；相律决定「几个相、几个自由度」的全局框架。

在下一节，我们把平衡思想从「两相之间的物质转移」推进到「化学反应」——反应何时达到平衡、平衡常数从何而来，这是**化学平衡**。
