## 为什么从链反应开始

氢气与氯气在光照下爆炸式化合，甲烷热裂解成碳与氢，高分子聚合、石油裂化、烃类氧化、大气光化学——这些反应有一个共同机制：**链反应（chain reaction）**。它们靠极活泼的**自由基（free radical）**（带未成对电子的原子或基团）一环接一环地传递，一个自由基能引发成千上万次转化。<span class="marginnote">链反应的发现史：博登斯坦（Bodenstein）研究 $\ce{H2 + Cl2}$ 时发现「一个光子可以引发 $10^5$ 个分子反应」，哈贝尔、能斯特先后提出链机理，谢苗诺夫与欣谢尔伍德因链反应与支链爆炸理论获 1956 年诺贝尔化学奖。链反应理论是「自由基化学」的奠基，也是燃烧、聚合、大气的机理基石。</span>

本节把《一级/二级反应动力学》与《碰撞/过渡态理论》的方法用于复合反应：用**稳态近似**把复杂的多步机理压缩成可用速率方程，并解释为何某些反应会**爆炸**。

## 1 链反应的三个基本步骤

一切链反应都由三类步骤构成：

**链引发（initiation）**：产生自由基。需打破化学键，能量大——光照（光解）、高温、引发剂。$\ce{Cl2 + h\nu -> 2Cl\cdot}$。
**链传递（propagation）**：自由基与稳定分子反应，生成产物并再生自由基（或转移自由基）。$\ce{Cl\cdot + H2 -> HCl + H\cdot}$、$\ce{H\cdot + Cl2 -> HCl + Cl\cdot}$。自由基数目不变，链持续。
**链终止（termination）**：自由基互相结合或与器壁碰撞而消亡。$\ce{2Cl\cdot + M -> Cl2 + M}$。

**重点：链反应的核心是「自由基数目守恒的传递循环」。** 引发产生自由基，传递不断再生，终止消耗——只要传递速率远大于终止，一个自由基就能转化大量产物。<span class="marginnote">链长（chain length）是每个引发自由基平均引发的转化数，可高达 $10^5\text{–}10^6$。量子效率（每吸收一个光子转化的分子数）正是链长的体现。对 $\ce{H2 + Cl2}$，一个光子引发约 $10^5$ 个 $\ce{HCl}$ 生成——这就是光化学量子效率大于 1 的机理。</span>

## 2 直链反应实例：$\ce{H2 + Cl2}$

$\ce{H2 + Cl2 -> 2HCl}$ 的链机理：

- 引发：$\ce{Cl2 -> 2Cl\cdot}$（光解或热解）
- 传递：$\ce{Cl\cdot + H2 -> HCl + H\cdot}$（慢）与 $\ce{H\cdot + Cl2 -> HCl + Cl\cdot}$（快）
- 终止：$\ce{2Cl\cdot + M -> Cl2 + M}$

用稳态近似（自由基浓度不变）推导速率方程：

$$\frac{\mathrm{d}[\ce{HCl}]}{\mathrm{d}t} = 2k_2[\ce{Cl\cdot}][\ce{H2}] = 2k_2\left(\frac{k_1}{k_4}\right)^{1/2}[\ce{H2}][\ce{Cl2}]^{1/2}$$

**重点：链反应速率方程的特征是「$\ce{Cl2}$ 的 1/2 次方」——来自引发（一次方）与终止（二次方）的组合。** 这种分数级数（$v \propto [\ce{H2}][\ce{Cl2}]^{1/2}$）正是链机理的指纹，与《反应速率》一节的分数级数预言相印证。<span class="marginnote">对比 $\ce{H2 + Br2}$：溴的链机理含 $\ce{Br\cdot + H2 <=> HBr + H\cdot}$ 的逆反应，速率方程出现分母 $1 + k'[\ce{HBr}]/[\ce{Br2}]$——产物 $\ce{HBr}$ 抑制自身生成（负催化）。这正是《反应速率与速率方程》预告过的那个复杂速率方程，也是链反应机理分析的名场面。</span>

## 3 稳态近似：把机理变成方程

**稳态近似（steady-state approximation）**：反应中间体（自由基）浓度低、寿命短，其生成与消耗几乎平衡，浓度随时间近似不变：

$$\frac{\mathrm{d}[\ce{R\cdot}]}{\mathrm{d}t} \approx 0$$

对每个自由基都写稳态方程，联立解出自由基浓度，代入产物生成速率即得总速率方程。<span class="marginnote">稳态近似成立的物理前提：中间体消耗比积累快得多，经过很短的「诱导期」后浓度即达准定常。它与《一级/二级反应动力学》中的连串反应中间体峰值一脉相承——$k_2 \gg k_1$ 时中间体浓度趋平台。近平衡时用<strong>平衡近似</strong>（决速步前的步骤视作平衡）则是另一条路，两种近似要按机理选用。</span>

**辨析｜易错点：** 稳态近似不是「令生成速率等于零」，而是「净积累速率为零」。自由基的生成项与消耗项都要写全。且稳态近似只在诱导期之后成立——反应初期自由基浓度快速爬升的阶段不能用它。

## 4 公式解析：稳态近似推导

以简化的链机理 $\ce{A2 ->[\text{引发}] 2R\cdot}$、$\ce{R\cdot + B ->[\text{传递}] P + R\cdot}$（自由基再生）、$\ce{2R\cdot ->[\text{终止}] S}$ 为例：

**第一步，对自由基写稳态方程**：$\dfrac{\mathrm{d}[\ce{R\cdot}]}{\mathrm{d}t} = 2k_\text{init}[\ce{A2}] - 2k_\text{term}[\ce{R\cdot}]^2 = 0$。引发产生 2 个自由基、终止消耗 2 个，系数 2 是关键。
**第二步，解出自由基浓度**：$[\ce{R\cdot}] = \left(\dfrac{k_\text{init}[\ce{A2}]}{k_\text{term}}\right)^{1/2}$。**引发速率与终止速率之比的开方——这就是分数级数 1/2 的根源。**
**第三步，代入产物生成速率**：$v_P = k_\text{prop}[\ce{R\cdot}][\ce{B}] = k_\text{prop}\left(\dfrac{k_\text{init}}{k_\text{term}}\right)^{1/2}[\ce{B}][\ce{A2}]^{1/2}$。总级数 1.5，对引发物 1/2 次。
**第四步，看温度依赖**：$k_\text{有效} = k_\text{prop}(k_\text{init}/k_\text{term})^{1/2}$。三个基元常数组合成表观速率常数——**实验测出的「活化能」是各基元活化能的组合**（$E_a = E_\text{prop} + \frac{1}{2}(E_\text{init} - E_\text{term})$），这正是链反应表观动力学与基元动力学的关系。

## 5 支链反应与爆炸界限

**支链反应（branching chain reaction）**：链传递中一个自由基变成**两个**自由基，链呈指数式增殖——自由基越积越多，反应失控，发生**爆炸**。经典例子是氢氧混合气：

直链：$\ce{H\cdot + O2 -> OH\cdot + O\cdot}$（一个变两个，**支化**）；$\ce{O\cdot + H2 -> OH\cdot + H\cdot}$；$\ce{OH\cdot + H2 -> H2O + H\cdot}$。

氢气与氧气并非在任何条件下都爆炸：压力-温度图上有**爆炸界限（explosion limits）**——低压下自由基易扩散到器壁终止、不爆；高压下自由基浓度高、复合终止快、也不爆；中间压力区间直链竞争不过支化，爆炸。<span class="marginnote">爆炸界限是支链反应理论最漂亮的预言：三条界限（低限、二限、三限）把 $p$-$T$ 图分成爆炸区与非爆炸区。低限由「器壁终止 vs 支化」竞争决定，二限由「气相三体终止 vs 支化」竞争决定。理解了爆炸界限，才能安全设计氢能利用、燃烧器与化工装置——这是「动力学安全」的核心内容。</span>

**辨析｜易错点：** 链爆炸（支链）与热爆炸是两种机制：支链爆炸是自由基指数增殖，热爆炸是放热使温度指数升高、反过来加速反应。实际爆炸常是两者耦合——燃烧学里区分「链式爆炸界限」与「热自燃界限」是基础功。

## 6 链反应的工程舞台

**聚合**：自由基聚合是链反应——引发剂产生自由基、链增长（单体加成）、链终止。分子量与聚合度由引发/增长/终止速率比决定，聚合物工业的分子设计就在这套动力学上。
**石油裂化**：烷烃热裂解经自由基链机理，高温下碳碳键均裂、自由基传递分解——轻质烯烃与汽油组分由此而来。
**燃烧**：烃类氧化是高度支链化的自由基链反应，火焰传播本质是自由基链的扩散与增殖。
**大气化学**：臭氧的生成与破坏、光化学烟雾都是自由基链反应（$\ce{OH\cdot}$ 循环）。<span class="marginnote">自由基链反应还是「抗氧化剂」发挥作用的对象：抗氧化剂（维生素 E、BHT）捕捉自由基、终止链传递，从而保护油脂、细胞膜不被氧化变质。抑制自由基的「反链反应」研究，与利用链反应的工业催化同等重要。</span>

## 7 链反应动力学的定量分析

链反应的研究不只是定性框架，还有一整套定量工具。

**自由基浓度的稳态解**：对给定机理写出每个自由基的稳态方程，得到自由基浓度与速率常数的代数关系。以 $\ce{H2 + Cl2}$ 为例，$[\ce{Cl\cdot}] = (k_1[\ce{Cl2}]/k_4)^{1/2}$、$[\ce{H\cdot}] = k_2[\ce{Cl\cdot}][\ce{H2}]/k_3[\ce{Cl2}]$——**每个自由基的稳态浓度都由生成与消耗的平衡决定**，代回产物速率即得总速率方程。

**链长的定量表达**：链长 $\nu = \dfrac{\text{传递速率}}{\text{引发速率}}$（或终止速率）。对 $\ce{H2 + Cl2}$，链长正比于 $[\ce{H2}]/([\ce{Cl2}]^{1/2}\cdot \text{终止强度})^{1/2}$——**光强越强（引发越快）、链越短，量子效率越低**。这与实验「强光下量子效率下降」一致：强光产生太多自由基、互相终止。

**爆炸界限的定量理论**：支链反应 $\ce{H2 + O2}$ 的爆炸条件写成「支化速率 vs 终止速率」的不等式。设支化速率常数 $k_b$、终止 $k_t$，单位体积单位时间的支化净速率 $f = k_b[\ce{R}] - k_t[\ce{R}]^2$——$f > 0$ 则自由基增殖、爆炸；$f < 0$ 则稳定。**爆炸界限就是 $f$ 的符号翻转线**，器壁尺寸、总压、壁面性质都进入 $k_t$，解释了「小容器不易爆炸」等实验事实。

**辨析｜易错点：** 稳态近似要求自由基「生成 ≈ 消耗」的平衡在观测时间内成立。链反应的**诱导期**（自由基累积阶段）内稳态近似不适用——诱导期的动力学须积分求解。且支链反应中自由基指数增长、稳态近似在爆炸前失效，用稳态近似描述支链爆炸是原理性错误。

一个用稳态近似推导链反应速率方程的完整算例。乙醛热分解 $\ce{CH3CHO -> CH4 + CO}$ 的链机理为：引发 $\ce{CH3CHO -> CH3\cdot + CHO\cdot}$（$k_1$）；传递 $\ce{CH3\cdot + CH3CHO -> CH4 + CH3CO\cdot}$（$k_2$）、$\ce{CH3CO\cdot -> CH3\cdot + CO}$（$k_3$）；终止 $\ce{2CH3\cdot -> C2H6}$（$k_4$）。

对 $\ce{CH3\cdot}$ 与 $\ce{CH3CO\cdot}$ 写稳态方程（$\mathrm{d}[\ce{R}]/\mathrm{d}t = 0$），联立解出：

$$[\ce{CH3\cdot}] = \left(\frac{k_1[\ce{CH3CHO}]}{k_4}\right)^{1/2}$$

代回产物 $\ce{CH4}$ 生成速率：$v = k_2[\ce{CH3\cdot}][\ce{CH3CHO}] = k_2\left(\frac{k_1}{k_4}\right)^{1/2}[\ce{CH3CHO}]^{3/2}$。

**预言：乙醛热分解应是 3/2 级反应**——实验测得分级数 1.5，与机理推导完全吻合。这就是「由机理推速率方程、再与实验对照验证机理」的标准循环：**稳态近似 + 每个自由基的生成/消耗平衡，把复杂链机理压缩成可检验的速率方程**。

**辨析｜易错点：** 稳态方程里引发项系数要看「生成几个自由基」：引发一步生成 1 个 $\ce{CH3\cdot}$（另一个是 $\ce{CHO\cdot}$），终止一步消耗 2 个 $\ce{CH3\cdot}$，故终止项系数为 2——系数写错会直接导致级数算错。

把链反应放回化学动力学的核心。**它是「复合反应机理」的教科书案例**——引发、传递、终止三步结构 + 稳态近似 + 分数级数，构成了从机理推导速率方程的标准范式。自由基的概念从这里进入化学，链长与量子效率解释了「一个光子引发十万分子」的宏观放大。

**重点：链反应是燃烧、聚合、大气化学的共同机理**。支链反应给出爆炸界限（安全设计的依据），直链反应给出聚合与裂化的动力学（高分子与炼油工业的基础），$\ce{OH\cdot}$ 循环主导大气氧化（空气质量与气候）。理解「自由基如何产生、如何传递、如何终止」这三位一体，就掌握了从火焰到塑料、从大气到体内的自由基化学主线，这也是《催化原理》与《光化学动力学》的前置基础。

一个补充的辨析：链反应的表观速率常数是各基元速率常数的组合，因此表观活化能也是组合值——实验测出的「活化能」不能直接归于某一步。判断机理时必须结合基元步的独立信息（光谱、同位素效应），不能只凭表观活化能下结论。

## 8 小结

- **链反应三步**：引发（产生自由基）、传递（自由基循环再生）、终止（自由基消亡）。
- **稳态近似** $\mathrm{d}[\ce{R\cdot}]/\mathrm{d}t \approx 0$ 把机理化为速率方程；链反应的分数级数（如 $\ce{[Cl2]^{1/2}}$）是链机理指纹。
- 表观活化能是各基元活化能的组合；一个光子引发 $10^5$ 分子——量子效率即链长。
- **支链反应**自由基指数增殖，产生**爆炸界限**（低限/二限/三限），燃烧与安全设计的基础。
- 聚合、裂化、燃烧、大气化学、抗氧化剂抑制，全是链反应的正反应用。
