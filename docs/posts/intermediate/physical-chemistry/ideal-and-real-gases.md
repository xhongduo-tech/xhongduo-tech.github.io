# 理想与真实气体

<div class="epigraph">

## 为什么从理想与真实气体开始

化学热力学所有公式都在引用 $pV = nRT$，但现实中没有真正的理想气体——高压储氢、超临界萃取、天然气开采，处处都要面对真实气体的偏差。<span class="marginnote">理想气体模型的价值不在于「真实」，而在于「简单且可解析」：它为热力学提供了一个完全可算的基准系统。统计热力学里配分函数、麦克斯韦分布都从理想气体出发；真实气体则是理想气体加修正项。先立基准，再谈偏差，是物理化学的一贯策略。</span>

本节把第一定律中反复使用的理想气体做一次彻底体检：它从哪儿来、凭什么成立、什么时候失效、失效后怎么办。这为后面《统计热力学》的微观图像与《热力学量的统计解释》埋下伏笔。

## 1 理想气体状态方程：经验与微观的统一

**理想气体状态方程** $pV = nRT$ 合并了三个经验定律：玻意耳定律（$T$ 恒定时 $pV = \text{const}$）、查理定律（$V$ 恒定时 $p/T = \text{const}$）、阿伏伽德罗定律（同温同压下同体积含等分子数）。<span class="marginnote">玻意耳 1662 年的实验、查理 1787 年的发现、阿伏伽德罗 1811 年的假说，经过一个多世纪才合并为一条状态方程。它描述的是低压高温下一切气体的共同极限行为——温度越高、压力越低，任何气体越接近这条方程。</span>

微观图像给出更深刻的解释。把气体分子看成**无体积、无相互作用**的质点，它们做无规则热运动、与器壁碰撞产生压力。由动量传递可得：

$$pV = \frac{1}{3}Nm\overline{v^2}$$

其中 $N$ 是分子数、$m$ 是分子质量、$\overline{v^2}$ 是速率平方的平均。定义分子的平均平动动能 $\bar\varepsilon_k = \frac{1}{2}m\overline{v^2}$，得 $pV = \frac{2}{3}N\bar\varepsilon_k$。与 $pV = nRT$ 对比，得到**温度的本质**：

$$\bar\varepsilon_k = \frac{3}{2}kT$$

**重点：温度是分子平均平动动能的量度。** 这是从宏观热力学进入微观统计的第一座桥——温度不再是「冷热的读数」，而是分子无规则运动剧烈程度的统计表现。<span class="marginnote">$k = R/N_A = 1.381 \times 10^{-23}\ \text{J·K}^{-1}$ 是玻尔兹曼常数，$R$ 是它的宏观放大版。这里的 $kT$ 是统计力学里反复出现的能量单位：后面玻尔兹曼分布中 $e^{-E/kT}$ 的尺度就是它。</span>

## 2 分子速率分布：麦克斯韦-玻尔兹曼分布

分子速率并不相同，而是服从**麦克斯韦-玻尔兹曼速率分布（Maxwell–Boltzmann speed distribution）**。速率处于 $v$ 到 $v+\mathrm{d}v$ 的分子占比为：

$$f(v)\,\mathrm{d}v = 4\pi\left(\frac{m}{2\pi kT}\right)^{3/2} v^2 e^{-mv^2/2kT}\,\mathrm{d}v$$

分布有三个特征速率：最概然速率 $v_p = \sqrt{2kT/m}$、平均速率 $\bar v = \sqrt{8kT/\pi m}$、方均根速率 $v_\text{rms} = \sqrt{3kT/m}$，恒有 $v_p < \bar v < v_\text{rms}$。<span class="marginnote">速率分布的温度效应：升温使曲线变宽、峰值右移，「高能尾部」的分子比例急剧增大。化学反应的速率由尾部高能分子决定，这正是《阿伦尼乌斯方程》中活化能的微观基础——反应速率随温度指数上升，因为超过活化能阈值的高能分子比例按玻尔兹曼因子增长。</span>

**辨析｜易错点：** $f(v)$ 的单位是 $\text{s·m}^{-1}$ 而不是「概率」。它是概率密度，要乘以速率区间 $\mathrm{d}v$ 才得到概率；$f(v)$ 本身可以大于 1。另外最概然速率是「单分子最可能的速率」，不是「平均速率」，三者不可混用。

## 3 真实气体与理想气体的偏差

真实气体偏离 $pV = nRT$ 的程度用**压缩因子（compressibility factor）** 衡量：

$$Z = \frac{pV}{nRT} = \frac{pV_\text{m}}{RT}$$

理想气体 $Z = 1$。真实气体 $Z$ 随压力与温度变化：<span class="marginnote">$Z$-$p$ 图上有著名的玻意耳温度：在某个特定温度 $T_B$，$Z$ 在低压区几乎保持 1，气体最「像」理想气体；高于 $T_B$ 则 $Z$ 随压力单调上升，低于 $T_B$ 则先降后升。玻意耳温度约等于分子间相互作用最温和的温度。</span>

- $Z < 1$：分子间引力占主导，分子「拉拢」在一起，实际体积小于理想值——如低温低压段的真实气体。
- $Z > 1$：分子体积效应占主导，气体「占地方」，实际体积大于理想值——如高压气体。

两种偏差分别对应理想假设的两个失效点：**分子有体积**与**分子间有作用力**。范德华方程正是把这两个修正同时做进去。

## 4 公式解析：范德华方程

**范德华方程（van der Waals equation）是真实气体最著名的半经验状态方程。** 对 1 mol 气体：

$$\left(p + \frac{a}{V_\text{m}^2}\right)(V_\text{m} - b) = RT$$

四步拆解：

- **第一步，看体积修正 $b$**：分子有体积，分子「可自由移动的空间」比容器体积小。$b$ 约为分子体积的 4 倍，称为**排除体积（excluded volume）**。修正后可用空间为 $V_\text{m} - b$。
- **第二步，看压力修正 $a/V_\text{m}^2$**：分子间引力使表面分子受内拉、碰撞器壁的动量减小，实测压力偏低。修正项 $a/V_\text{m}^2$ 与分子数密度平方成正比——引力正比于「两两相遇」的分子对，数密度越大修正越大。
- **第三步，看常数 $a$、$b$ 的物性来源**：$a$ 衡量分子间引力强度（分子越易极化、越大，$a$ 越大），$b$ 衡量分子自身大小。查表可得，不同气体的 $a$、$b$ 相差很大，对应各自偏离理想的程度。
- **第四步，看极限行为**：$V_\text{m} \to \infty$ 时 $a/V_\text{m}^2 \to 0$、$b$ 可忽略，方程退化为 $pV_\text{m} = RT$——低压高温下真实气体回归理想，一致性得到保证。

## 5 临界现象与对应态原理

范德华方程在 $p$-$V$ 图上能给出等温线的拐点，对应真实的**临界点（critical point）**——液气两相界限消失的极限状态。对范德华气体，临界参数为：

$$p_c = \frac{a}{27b^2}, \qquad V_c = 3b, \qquad T_c = \frac{8a}{27Rb}$$

把实际变量对临界参数归一化：$p_r = p/p_c$、$T_r = T/T_c$、$V_r = V/V_c$，得到**对应态原理（principle of corresponding states）**：不同气体在相同的对比压力与对比温度下，具有相同的对比体积。也就是说，**一切真实气体在临界点看来都「长得一样」**。<span class="marginnote">对应态原理让气体性质的估算超越「逐个查表」：只需知道某气体的 $p_c$、$T_c$，就能把它的性质换算成标准气体的性质。工程上普遍用对比态查压缩因子图（$Z$-$p_r$-$T_r$ 图），误差常在百分之几以内。</span>

**辨析｜易错点：** 临界温度不是「可以液化」的温度上限以上的无关量，而是**液化的最高温度**——高于 $T_c$ 无论加多大压力都不能液化，只能得到超临界流体。二氧化碳 $T_c = 31\,^\circ\text{C}$，常温下加压即可液化，是超临界萃取的常用工质；氮气 $T_c = -147\,^\circ\text{C}$，常温高压也压不成液体，只能用钢瓶储气。

## 6 真实气体方程的现代应用

范德华方程与对应态原理不只是教材习题，它们活跃在真实工程与科研中。

**压缩因子图查表**：工程上最实用的做法是**通用压缩因子图（$Z$-$p_r$-$T_r$ 图）**。对任意气体，由查表的 $p_c$、$T_c$ 算对比参数 $p_r = p/p_c$、$T_r = T/T_c$，在通用图上读出 $Z$，代入 $pV = ZnRT$ 计算实际体积。天然气管道输送、储气罐容量设计、超临界流体的密度计算都靠它，误差常在百分之几以内。

**超临界流体技术**：二氧化碳（$T_c = 31\,^\circ\text{C}$、$p_c = 7.4\ \text{MPa}$）在超临界态兼具「气体渗透 + 液体溶解」特性——超临界萃取（咖啡因脱除、天然产物提取）是真实气体对应态性质的典型应用。临界区气体密度随压力剧变（$Z$ 变化剧烈），必须用真实气体方程描述。

**维里方程与高级状态方程**：更高精度用**维里方程（virial equation）** $Z = 1 + B(T)/V_m + C(T)/V_m^2 + \cdots$（第二维里系数 $B$ 含分子对相互作用），以及工业标准——**SRK、PR（Peng–Robinson）立方方程**。它们把范德华的思想推广：用两个以上参数拟合蒸气压与液相密度，是石油化工相平衡计算的标准工具。

**辨析｜易错点：** 对应态原理基于「两参数对应态」——假定一切气体在对比态下行为相同。真实气体有第三参数（偏心因子 $\omega$）修正，不带 $\omega$ 的两参数图对强极性、强缔合气体（水、氨、醇）误差增大。**把对应态原理用于极性气体须加修正**，这是工程中最常踩的坑。

一个用压缩因子修正理想气体计算的算例。$50\ ^\circ\text{C}$、$10\ \text{MPa}$ 下，$1\ \text{mol}$ 二氧化碳占据多大体积？

**理想气体**：$V = nRT/p = 8.314\times323.15/(10\times10^6) = 2.69\times10^{-4}\ \text{m}^3 = 0.269\ \text{L}$。

**真实气体**：查 $\ce{CO2}$ 的 $p_c = 7.38\ \text{MPa}$、$T_c = 304.1\ \text{K}$，得 $p_r = 10/7.38 = 1.36$、$T_r = 323.15/304.1 = 1.06$。通用压缩因子图查得 $Z \approx 0.55$：

$$V = \frac{ZnRT}{p} = 0.55\times0.269 \approx 0.148\ \text{L}$$

**理想气体高估了体积近一倍**——在超临界附近（$T_r$、$p_r$ 都接近 1），$\ce{CO2}$ 的分子间作用与体积效应显著，$Z = 0.55$ 远小于 1。这正是超临界 $\ce{CO2}$ 萃取必须用真实气体方程的原因：密度是理想气体的近两倍，溶解能力因此剧增。

**工程启示**：储气罐设计、超临界流体设备容量计算，若直接用理想气体方程会带来近 50% 的偏差——**「先判断工况是否远离临界区，再决定用理想还是真实气体方程」是化工计算的必要检查**。

把气体放回热力学的出发点。**理想气体是一切热力学计算的「第一基准」**——焓、熵、自由能、化学势的公式都以它为起点，真实气体则是它的修正。而气体行为本身又是统计热力学最好的演示场：压力来自分子碰撞、温度是平均平动动能、速率分布是玻尔兹曼分布的直接表现。

**重点：理想气体模型的价值在于「干净且可解」**。它给了化学热力学一个完全解析的参照系，让「先立基准、再谈偏差」成为物理化学的标准策略。从 $pV = nRT$ 出发，加分子体积与引力得范德华方程，加量子效应得费米-玻色统计，加相互作用得维里展开——**气体这一章为整个物理化学提供了「如何从理想走向真实」的方法论模板**，这正是《理想与真实气体》在课程中的独特位置。

一个补充的辨析：范德华方程的 $a$、$b$ 是「拟合参数」不是「分子固有常数」——不同物性数据（临界参数、pVT 数据）拟合出的 $a$、$b$ 略有差异。工程上直接用临界参数反推 $a = 27R^2T_c^2/(64p_c)$、$b = RT_c/(8p_c)$，比拟合 pVT 数据更稳定，这是范德华方程「参数-临界量」换算的标准做法。

## 7 小结

- **理想气体方程** $pV = nRT$ 是低压高温的极限规律；微观上温度 $\bar\varepsilon_k = \frac{3}{2}kT$ 是分子平均平动动能。
- **麦克斯韦速率分布**给出速率统计，最概然、平均、方均根三种速率满足 $v_p < \bar v < v_\text{rms}$。
- **压缩因子** $Z$ 衡量真实气体偏差：$Z<1$ 引力主导，$Z>1$ 体积主导。
- **范德华方程** $(p + a/V_\text{m}^2)(V_\text{m} - b) = RT$ 同时修正分子体积 $b$ 与分子间引力 $a$。
- **对应态原理**：以 $p_c$、$T_c$ 归一化后，一切真实气体行为相似；临界温度是液化上限。

在下一节，我们把热力学与统计的眼光收拢到「绝对零度附近的世界」——为什么熵的零点存在，标准熵如何测定，这是**热力学第三定律**。
