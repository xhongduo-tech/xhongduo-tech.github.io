# 一级 / 二级反应动力学

<div class="epigraph">
<p>微分速率方程告诉我们在某一瞬间反应有多快；积分速率方程告诉我们浓度如何随时间演化。</p>

## 为什么从一级/二级反应动力学开始

速率方程是微分方程：$v = k[\ce{A}]$ 说的是「此刻的速率」。要回答「10 分钟后还剩多少」「药物半衰期多长」「反应什么时候基本完成」，必须**积分**速率方程，得到浓度随时间的显式函数。<span class="marginnote">一级与二级反应是最常见、也最能解析积分的两类：放射性衰变、药物代谢、异构化、许多热分解是一级；双分子缔合、多数气相双分子反应、溶液中 $\ce{NO + O3}$ 类是二级。掌握了这两类积分式与半衰期，就掌握了动力学「由数据到预测」的核心手艺。</span>

本节从微分式积分出 $c(t)$，引出半衰期，并给出判断级数的标准操作。它是《反应速率与速率方程》的深化，也是后续《阿伦尼乌斯方程》（温度依赖）与复合反应（对行/平行/连串）的基础。

## 1 一级反应：指数衰减

**一级反应** $\ce{A -> P}$，速率方程 $v = -\dfrac{\mathrm{d}[\ce{A}]}{\mathrm{d}t} = k[\ce{A}]$。分离变量积分：

$$[\ce{A}] = [\ce{A}]_0 e^{-kt} \qquad\Longleftrightarrow\qquad \ln[\ce{A}] = \ln[\ce{A}]_0 - kt$$

**重点：一级反应的浓度按指数衰减，$\ln[\ce{A}]$ 对 $t$ 是直线，斜率 $-k$。** 特征性质：

- 半衰期 $t_{1/2} = \dfrac{\ln 2}{k}$——**与初始浓度无关**，这是判断一级反应最便捷的标志。
- 浓度降到任一分数所需时间恒定：降到 1/2 用时 $t_{1/2}$，降到 1/4 再一个 $t_{1/2}$。
- $k$ 单位 $\text{s}^{-1}$。<span class="marginnote">放射性衰变是天然的一级反应：碳-14 衰变 $k = 1.21\times10^{-4}\ \text{a}^{-1}$，半衰期 5730 年——考古测年的原理。药物代谢、体内化学物质消除通常按一级近似，医生说的「半衰期」就是 $t_{1/2} = \ln2/k$，一个恒定的时间。</span>

## 2 二级反应：倒数线性

**二级反应**有两种情形：一种反应物 $\ce{2A -> P}$（或 $\ce{A -> P}$ 但 $v = k[\ce{A}]^2$），与两种反应物 $\ce{A + B -> P}$ 且 $[\ce{A}] = [\ce{B}]$。积分：

$$\frac{1}{[\ce{A}]} = \frac{1}{[\ce{A}]_0} + kt$$

**重点：$1/[\ce{A}]$ 对 $t$ 是直线，斜率 $k$；半衰期 $t_{1/2} = \dfrac{1}{k[\ce{A}]_0}$——与初始浓度成反比。** 二级反应无「恒定半衰期」，浓度越低衰减越慢。<span class="marginnote">二级反应的本质是碰撞：两分子必须相遇才能反应，速率 ∝ 两浓度之积。半衰期反比于初始浓度正是因为「人多碰撞多、消耗快」。$[\ce{A}]_0$ 减半则 $t_{1/2}$ 翻倍——与一级的「半衰期恒定」形成鲜明对照，是判断级数的黄金判据。</span>

对 $\ce{A + B -> P}$ 且 $[\ce{A}]_0 \neq [\ce{B}]_0$，积分式为 $\dfrac{1}{[\ce{B}]_0 - [\ce{A}]_0}\ln\dfrac{[\ce{B}]_0[\ce{A}]}{[\ce{A}]_0[\ce{B}]} = kt$，形式复杂但原理相同。

## 3 零级反应与准一级处理

**零级反应** $v = k$，积分 $[\ce{A}] = [\ce{A}]_0 - kt$，半衰期 $t_{1/2} = \dfrac{[\ce{A}]_0}{2k}$——**速率恒定、与浓度无关**。常见于表面催化反应（表面活性中心被饱和，浓度再高也没用）与酶饱和区（米氏动力学极限）。<span class="marginnote">准一级反应（pseudo-first-order）是实验技巧：让 $\ce{B}$ 大量过量（$[\ce{B}]_0 \gg [\ce{A}]_0$），$[\ce{B}]$ 几乎不变，二级反应 $\ce{A + B -> P}$ 退化为 $v = k'[\ce{A}]$，$k' = k[\ce{B}]_0$。水解反应（水大量过量）都按准一级处理——一个技巧，把复杂二级变简单一级。</span>

**辨析｜易错点：** 同一反应在不同条件下「级数」可以不同——不是因为机理变，而是近似变了。强酸性溶液中酯水解是准一级（$\ce{H+}$ 是催化剂、浓度恒定），换成酸性可变时动力学更复杂。报告级数时必须注明条件。

## 4 公式解析：半衰期 $t_{1/2}$

**半衰期是「级数的指纹」，也是工程估算的最爱。** 三种常见级数的统一形式：

$$t_{1/2} \propto \frac{1}{[\ce{A}]_0^{n-1}}$$

- **第一步，看 $n=1$（一级）**：$t_{1/2} = \ln2/k$，与浓度无关。**恒定半衰期是标志。** 放射性物质的「半衰期」标签就是这个。
- **第二步，看 $n=2$（二级）**：$t_{1/2} = 1/(k[\ce{A}]_0)$，反比于初始浓度。浓度越大消耗越快。
- **第三步，看 $n=0$（零级）**：$t_{1/2} = [\ce{A}]_0/(2k)$，正比于初始浓度。表面饱和反应吃得「匀速」。
- **第四步，看如何测级数**：实验上测不同 $[\ce{A}]_0$ 下的 $t_{1/2}$：$t_{1/2}$ 不变 → 一级；$t_{1/2}$ 与 $[\ce{A}]_0$ 成反比 → 二级；成正比 → 零级。**由 $\log t_{1/2}$ 对 $\log[\ce{A}]_0$ 作图，斜率 $= 1 - n$，一次实验定级数。**

## 5 级数的实验判断汇总

| 级数 | 线性关系 | $t_{1/2}$ | $k$ 单位 |
| --- | --- | --- | --- |
| 0 | $[\ce{A}]$ ~ $t$ | $[\ce{A}]_0/(2k)$ | $\text{mol·L}^{-1}\text{s}^{-1}$ |
| 1 | $\ln[\ce{A}]$ ~ $t$ | $\ln2/k$ | $\text{s}^{-1}$ |
| 2 | $1/[\ce{A}]$ ~ $t$ | $1/(k[\ce{A}]_0)$ | $\text{L·mol}^{-1}\text{s}^{-1}$ |

**重点：三种图「哪个直就是哪个级数」——$[\ce{A}]$ 直为零级、$\ln[\ce{A}]$ 直为一级、$1/[\ce{A}]$ 直为二级。** 数据好时一目了然；数据噪声大时用半衰期法或初始速率法交叉验证。<span class="marginnote">一个实用的实验设计：同时画三种图看线性度，再算各法的 $k$ 看是否一致。现代数据用非线性拟合直接解微分方程更精确，但「看图定级数」的直觉仍是第一判断——它教你认识数据长什么样。</span>

## 6 复合反应概览

真实反应常由多个基元步骤组合：

**对行反应（可逆反应）** $\ce{A <=> B}$：正逆都有速率，净速率 = 差。长时间后趋平衡，$K = k_1/k_{-1}$——**平衡常数是正逆速率常数之比**，动力学与热力学在此汇合。
**平行反应（竞争反应）** $\ce{A -> B}$ 与 $\ce{A -> C}$：产物比由两速率常数之比决定，可调控选择性。
**连串反应（连续反应）** $\ce{A -> B -> C}$：中间体 B 出现「浓度峰值」，其位置与高度由 $k_1/k_2$ 决定——放射衰变链、逐级水解的标准模型。<span class="marginnote">连串反应的「中间体峰值」是理解代谢、催化循环、核衰变链的核心：药物先形成活性代谢物再降解，活性代谢物浓度有个峰值；放射性衰变链中母体、子体、孙体各有丰度曲线。若中间体极不稳定（$k_2 \gg k_1$），用<strong>稳态近似</strong>假设其浓度近似不变——这个近似是催化与链反应分析（《链反应》一节）的基本工具。</span>

## 7 复杂动力学的数值方法与真实体系

当反应不再是单一步骤，解析解失效，数值方法登场。

**从解析到数值**：对复杂机理（链反应、连串反应、平行反应组合），微分方程组无解析解，用数值积分（Runge-Kutta、刚性求解器）直接解出浓度-时间曲线。**现代动力学模拟的标准流程**：写出各物种的速率方程 → 数值积分 → 与实验数据拟合参数 → 验证机理。化学动力学仿真软件（Kintecus、COPASI）就是这样工作的。

**稳态近似的现代验证**：解析的稳态近似是否可靠，可以用数值解对比验证——当中间体寿命远短于观测时间、且无诱导期累积时，稳态近似与数值解几乎重合。**数值解是「精确裁判」，稳态近似是「快速估算」**——理解两者关系才能放心用近似。

**实验动力学拟合的陷阱**：用非线性最小二乘拟合速率常数时，参数相关性与初值敏感性常导致多解。判断标准：不同初值收敛到同一参数、残差随机分布、预测与独立实验吻合。**「拟合得好」不等于「机理正确」**——多个机理可能拟合同一组数据，需用独立实验（同位素标记、中间体检测）甄别。

**真实体系案例：酯水解** $\ce{RCOOR' + H2O -> RCOOH + R'OH}$。酸催化下对酯准一级、对 $\ce{H+}$ 一级，总二级；碱催化同理。工业与药代中这类「表观级数随条件变」的体系，必须回到「机理 → 稳态/平衡近似 → 表观速率方程」的完整链条，而不是机械套用级数表。

**辨析｜易错点：** 数值拟合得到的参数置信区间依赖实验误差的准确估计。把噪声数据「硬拟合」会得到假精确的参数。且拟合只能确认「机理与数据不矛盾」，不能证明机理唯一——**动力学机理研究是「排除法」而非「证明法」**。

一个用积分法判断级数并求 $k$ 的完整算例。某分解反应在 $25\,^\circ\text{C}$ 测得浓度-时间数据：

| $t$ / min | $[\ce{A}]$ / mol·L⁻¹ | $\ln[\ce{A}]$ | $1/[\ce{A}]$ |
| --- | --- | --- | --- |
| 0 | 0.100 | −2.303 | 10.0 |
| 10 | 0.067 | −2.703 | 14.9 |
| 20 | 0.050 | −2.996 | 20.0 |
| 30 | 0.040 | −3.219 | 25.0 |
| 40 | 0.033 | −3.411 | 30.3 |

**看哪个图是直线**：$[\ce{A}]$ 每 10 min 约从 0.100 → 0.067 → 0.050 → 0.040（比值 $\approx 0.67$、0.75、0.80，非恒定）；$\ln[\ce{A}]$ 每 10 min 间隔均匀（−2.303 → −2.703 → −2.996 → −3.219，差约 0.3）；$1/[\ce{A}]$ 每 10 min 增量均匀（+4.9 → +5.1 → +5.0 → +5.3）。

**判断**：$\ln[\ce{A}]$ 与 $1/[\ce{A}]$ 都近似直线——需用半衰期区分。一级半衰期应恒定：由 $t_{1/2}$ 估算，浓度 0.100 → 0.050 用时约 20 min（$t_{1/2} \approx 20$ min），0.050 → 0.025 理论再 20 min；数据支持一级（$t_{1/2}$ 恒定是强判据）。求速率常数：$k = \ln2/t_{1/2} = 0.693/20 \approx 0.035\ \text{min}^{-1}$。

**重点：级数判断要用「线性 + 半衰期」交叉验证**——两条线都直时用半衰期定论，避免误判。这正是「看图定级数」的操作要点。

把积分动力学放回《反应速率与速率方程》的延续。**它是「由微分到演化」的一步**——积分速率方程给出浓度随时间的显式函数，半衰期给出「多快完成」的工程指标，线性作图给出级数判定的实验方法。一级的恒定半衰期、二级的反比半衰期、零级的匀速消耗，是动力学数据的三种「指纹」。

**重点：积分动力学是「预测工具」**。从药物半衰期到反应器转化率，从放射性衰变到产品保质期，积分式让「10 分钟后还剩多少」成为可计算的答案。掌握「先判级数（线性/半衰期）→ 求速率常数 → 预测任意时刻浓度」这套流程，就掌握了动力学从数据到预测的完整手艺，也为《阿伦尼乌斯方程》的温度外推与复合反应分析铺路。

## 8 小结

- **一级**：$[\ce{A}] = [\ce{A}]_0 e^{-kt}$，$t_{1/2} = \ln2/k$ 恒定，$\ln[\ce{A}]$~$t$ 直线。
- **二级**：$1/[\ce{A}] = 1/[\ce{A}]_0 + kt$，$t_{1/2} = 1/(k[\ce{A}]_0)$ 反比于初始浓度。
- **零级**：$[\ce{A}] = [\ce{A}]_0 - kt$，速率恒定（表面饱和、酶饱和）。
- **半衰期指纹** $t_{1/2} \propto [\ce{A}]_0^{1-n}$；线性图「哪个直就是哪个级数」。
- 对行、平行、连串反应组合出复杂动力学；稳态近似是分析中间体的利器。
