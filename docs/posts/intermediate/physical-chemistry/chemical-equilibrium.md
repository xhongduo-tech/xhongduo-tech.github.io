# 化学平衡

<div class="epigraph">
<p>任何化学反应都向平衡移动，平衡位置由吉布斯自由能决定；改变条件，平衡便向抵抗这种改变的方向移动。</p>

## 为什么从化学平衡开始

「反应能否发生」在《熵与自由能》里有了 $\Delta G$ 判据，但那只回答「能」，不回答「到哪儿停」。合成氨在室温下 $\Delta G < 0$，可实际只转化百分之几就「卡住」了——平衡限制了产率。**化学平衡**研究反应的**限度**：反应进行到何种程度停止，平衡常数怎么算，温度压力如何把平衡推来推去。<span class="marginnote">平衡不是反应停止，而是正逆速率相等、宏观上组成不再变化的动态稳态。放射性同位素示踪证明平衡态下正逆反应仍在进行。化学平衡的本质是「正反应自由能降低的驱动力」与「逆反应恢复驱动力」恰好抵消。</span>

化学平衡是工业化学的计算基础：合成氨的平衡产率决定反应器压力与温度的选择，碳捕捉的平衡常数决定吸收剂的效率。它在课程轴上衔接《化学势》（平衡条件 $\sum\nu_i\mu_i = 0$）与《相平衡》（平衡思想在相图中的应用），并为《电化学》中电极反应的平衡提供模板。

## 1 反应进度与平衡条件

对一般反应 $a\text{A} + b\text{B} \rightleftharpoons l\text{L} + m\text{M}$，记化学计量数 $\nu_i$（产物为正、反应物为负），平衡时各组分的化学势满足：

$$\sum_i \nu_i \mu_i = 0$$

这就是化学平衡的热力学条件，是「总自由能最小」对组成变量的体现。<span class="marginnote">反应进度（extent of reaction）$\xi$ 定义为 $\mathrm{d}n_i = \nu_i\,\mathrm{d}\xi$，使所有组分共享同一个「反应进行程度」坐标。反应摩尔吉布斯自由能变化为 $\Delta_r G_m = (\partial G/\partial \xi)_{T,p} = \sum_i \nu_i \mu_i$，平衡时 $\Delta_r G_m = 0$——「自由能对反应进度取极小」就是这个条件。</span>

**重点：平衡条件 $\sum \nu_i \mu_i = 0$ 与「反应物浓度、产物浓度满足某个比值」是同一件事的两种说法。** 把各组分的 $\mu_i = \mu_i^\ominus + RT\ln a_i$ 代入，对数项合并，就得到平衡常数。

## 2 反应等温式与平衡常数

把化学势表达式代入 $\Delta_r G_m = \sum \nu_i \mu_i$：

$$\Delta_r G_m = \Delta_r G_m^\ominus + RT\ln Q$$

其中 **$Q$ 是反应商（reaction quotient）**：$Q = \prod a_i^{\nu_i} = \dfrac{a_L^l a_M^m}{a_A^a a_B^b}$，$\Delta_r G_m^\ominus = \sum \nu_i \mu_i^\ominus$ 是标准摩尔反应自由能变。平衡时 $\Delta_r G_m = 0$，反应商取平衡值即**标准平衡常数** $K^\ominus$：

$$0 = \Delta_r G_m^\ominus + RT\ln K^\ominus \qquad\Longrightarrow\qquad \Delta_r G_m^\ominus = -RT\ln K^\ominus$$

**重点：$K^\ominus$ 是无量纲的，且由 $\Delta_r G_m^\ominus$ 唯一决定。** $\Delta_r G_m^\ominus$ 只与温度有关（标准态固定），故 $K^\ominus$ 只与温度有关，与浓度、压力无关。<span class="marginnote">高中化学里的平衡常数 $K_c$（用浓度）、$K_p$（用分压）与这里的 $K^\ominus$ 的区别在于：标准平衡常数要求以活度/标准态分压代入，从而无量纲、可互相衔接。对理想气体稀溶液，$K^\ominus$ 与 $K_p$、$K_c$ 只差标准态的换算因子。</span>

反应等温式 $\Delta_r G_m = RT\ln(Q/K^\ominus)$ 给出统一的判据：

- $Q < K^\ominus$：$\Delta_r G_m < 0$，正向自发，反应右移。
- $Q > K^\ominus$：$\Delta_r G_m > 0$，逆向自发，反应左移。
- $Q = K^\ominus$：平衡。

## 3 公式解析：$\Delta_r G_m^\ominus = -RT\ln K^\ominus$

**这是把自由能（热力学量）换算成平衡常数（组成量）的黄金公式，物理化学最常用的换算器之一。** 四步拆解：

- **第一步，认清 $\Delta_r G_m^\ominus$**：标准摩尔反应自由能变，等于「所有反应物和产物都处于标准态时的 $\Delta G$」。它是一个**换算基准**，数值可查（标准生成自由能表），量纲是能量/摩尔。
- **第二步，看 $R$ 与 $T$**：$R = 8.314\ \text{J·mol}^{-1}\text{·K}^{-1}$，$T$ 是开尔文温度。$RT$ 是「每摩尔的热能标尺」——$\Delta_r G_m^\ominus$ 相对这个标尺的大小决定了 $K^\ominus$ 偏离 1 的程度。
- **第三步，读指数关系**：$K^\ominus = e^{-\Delta_r G_m^\ominus / RT}$。$\Delta_r G_m^\ominus$ 越负，$K^\ominus$ 越大，平衡越靠产物。$\Delta_r G_m^\ominus$ 每差 $2.3RT$（$25\,^\circ\text{C}$ 约 $5.7\ \text{kJ·mol}^{-1}$），$K^\ominus$ 变 10 倍——这个「每 $5.7\ \text{kJ}$ 差十倍」的经验换算极为实用。
- **第四步，注意判别陷阱**：$\Delta_r G_m^\ominus < 0$ 只说明 $K^\ominus > 1$、平衡偏向产物，**不代表**在该条件下反应必然大量进行——还要看实际 $Q$。反之，$\Delta_r G_m > 0$ 时反应仍可进行（只要 $Q < K^\ominus$）。**「标准」与「实际」自由能变是两个量，初学最易混淆。**

## 4 温度对平衡的影响：范特霍夫方程

$K^\ominus$ 只随温度变。由吉布斯-亥姆霍兹关系，$\ln K^\ominus$ 对 $T$ 的依赖为**范特霍夫方程（van't Hoff equation）**：

$$\frac{\mathrm{d}\ln K^\ominus}{\mathrm{d}T} = \frac{\Delta_r H_m^\ominus}{RT^2}$$

积分形式（设焓变不随温度变）：

$$\ln\frac{K_2^\ominus}{K_1^\ominus} = -\frac{\Delta_r H_m^\ominus}{R}\left(\frac{1}{T_2} - \frac{1}{T_1}\right)$$

**重点：放热反应（$\Delta_r H_m^\ominus < 0$）升温使 $K^\ominus$ 减小，吸热反应升温使 $K^\ominus$ 增大。** 这与勒夏特列原理一致：升温有利于吸热方向。<span class="marginnote">范特霍夫方程与克劳修斯-克拉佩龙方程形神皆似——都把「平衡常数/蒸气压随温度的对数变化」归因于「焓变除以 $RT^2$」。二者同源：相平衡是特殊反应（组分在两相间转移），化学平衡是同一思想的一般化。</span>

**辨析｜易错点：** 升温改变的是 $K^\ominus$（平衡位置），而催化剂改变的是到达平衡的速率、不改变 $K^\ominus$。合成氨工艺选高压低温（利于平衡）加铁催化剂（加速），就是「热力学选方向、动力学选速度」的经典分工。

## 5 压力、惰性气体与勒夏特列原理

对气体反应，压力通过改变分压影响平衡：

**增大总压**：平衡向气体分子数减少的方向移动。对 $\ce{N2 + 3H2 <=> 2NH3}$，增大压力使平衡右移、产率升高。
**加入惰性气体**：恒温恒容下加入惰性气体，分压不变、$Q$ 不变，平衡不移动；恒温恒压下加入惰性气体，需扩大体积、各反应组分分压下降，平衡向分子数多的一方移动。
**勒夏特列原理（Le Chatelier's principle）**：改变平衡系统的某个条件，平衡向削弱这种改变的方向移动。它是化学势判据的直观版，但注意它只是**定性**规则，定量移动多少要靠平衡常数计算。<span class="marginnote">勒夏特列原理不是独立定律，而是平衡条件 $\sum\nu_i\mu_i=0$ 的推论。它的价值在于快速直觉：勒夏特列本人用它指导合成氨工艺设计——高温高压的选型正是这一原理的工程胜利。</span>

## 6 平衡计算的完整案例：合成氨

把本章公式串成一个工业案例。合成氨 $\ce{N2 + 3H2 <=> 2NH3}$ 的平衡转化率如何计算与优化？

**第一步，查热力学数据**。$25\,^\circ\text{C}$ 时 $\Delta_f G_m^\ominus(\ce{NH3}) = -16.5\ \text{kJ·mol}^{-1}$，故 $\Delta_r G_m^\ominus = 2\times(-16.5) = -33.0\ \text{kJ·mol}^{-1}$。代入黄金公式：

$$K^\ominus = e^{33000/(8.314\times298.15)} \approx 6.1\times10^5$$

**第二步，看平衡常数随温度的下降**。合成氨放热（$\Delta_r H_m^\ominus = -92.2\ \text{kJ·mol}^{-1}$），由范特霍夫方程，升温 $K^\ominus$ 剧降——$500\ \text{K}$ 时 $K^\ominus \approx 0.13$。**热力学说低温好，动力学说低温慢**，工业折中取 400–500 °C 并用催化剂。

**第三步，算压力效应**。对气体反应 $K_p = \dfrac{p_{\ce{NH3}}^2}{p_{\ce{N2}}p_{\ce{H2}}^3}$。设总压 $p$、平衡转化率 $x$，由分压与摩尔分数关系代入 $K_p$，可解出 $x(p)$：总压从 10 MPa 提到 30 MPa，平衡转化率显著上升——因为反应分子数减少（4 → 2），增压利于产物，与勒夏特列原理一致。

**第四步，看工程权衡**。高压有利平衡但设备与能耗代价大；工业上 150–300 atm、450 °C 附近运行，实际转化率 15%–25%，未反应气体循环套用。**平衡计算给出了理论天花板，工程选择是在天花板下做经济优化**——这正是物理化学进入化工的典型路径。

**辨析｜易错点：** 用 $\Delta_f G_m^\ominus$ 算 $K^\ominus$ 时，温度必须与数据表的温度一致。用 25 °C 的数据算 450 °C 的平衡常数必须先用范特霍夫方程做温度修正，不可直接代用。

一个用反应商判断方向的算例。反应 $\ce{N2 + 3H2 <=> 2NH3}$ 在某温度 $K^\ominus = 4.0$，此刻各气体分压（MPa）：$p_{\ce{N2}} = 3.0$、$p_{\ce{H2}} = 1.0$、$p_{\ce{NH3}} = 2.0$。

**算反应商**（以 $p^\ominus = 0.1\ \text{MPa}$ 归一）：

$$Q = \frac{(p_{\ce{NH3}}/p^\ominus)^2}{(p_{\ce{N2}}/p^\ominus)(p_{\ce{H2}}/p^\ominus)^3} = \frac{20^2}{30\times10^3} = \frac{400}{30000} \approx 0.0133$$

**比较**：$Q = 0.0133 < K^\ominus = 4.0$，由 $\Delta_r G_m = RT\ln(Q/K^\ominus) < 0$，**反应正向自发，平衡右移（生成更多氨）**。由反应等温式还可量化：$\Delta_r G_m = RT\ln(0.0133/4.0) = 8.314T\times\ln(3.3\times10^{-3})$，若 $T = 500\ \text{K}$ 则 $\Delta_r G_m \approx 8.314\times500\times(-5.7) \approx -23.7\ \text{kJ·mol}^{-1}$——驱动力明确。

**要点**：**$Q$ 与 $K^\ominus$ 的比较是「当前状态」与「平衡状态」的距离标尺**。$Q < K$ 右移、$Q > K$ 左移、$Q = K$ 平衡——这条「距离判据」与 $\Delta_r G_m$ 的符号完全等价，是《化学平衡》最实用的判断工具，也是工业上「现在该往哪个方向走」的实时指南。

把化学平衡放回第一篇的收官。**它是「反应限度」的定量理论**——平衡常数由 $\Delta_r G_m^\ominus$ 唯一决定、只随温度变化，反应商与平衡常数的比较给出方向，范特霍夫方程给出温度依赖，压力与惰性气体给出勒夏特列原理的定量表达。化学平衡把《化学势》的 $\sum\nu_i\mu_i = 0$ 兑现为可查表、可计算、可优化的工程工具。

**重点：化学平衡是「化学工业的计算中枢」**。合成氨、碳捕捉、反应器设计的平衡转化率，全由本章公式计算；「催化剂不改变平衡」这条铁律又把热力学与动力学的关系钉死。**理解平衡常数与自由能的连接（$\Delta G^\ominus = -RT\ln K$），就掌握了从热力学数据到工业生产极限的完整换算链**，这也是第一篇化学热力学通向后续电化学（能斯特方程）与相平衡的共同逻辑。

## 7 小结

- **化学平衡条件**：$\sum_i \nu_i \mu_i = 0$，即 $\Delta_r G_m = 0$，是自由能对反应进度取极小。
- **反应等温式**：$\Delta_r G_m = \Delta_r G_m^\ominus + RT\ln Q$；$Q$ 与 $K^\ominus$ 比较决定方向。
- **黄金公式**：$\Delta_r G_m^\ominus = -RT\ln K^\ominus$；$K^\ominus$ 只与温度有关。
- **范特霍夫方程**：$\ln K^\ominus$ 对 $1/T$ 作图为直线，斜率给出 $\Delta_r H_m^\ominus$；放热反应升温使平衡左移。
- **压力与惰性气体**：改变总压移动平衡，勒夏特列原理给出定性方向；催化剂不移动平衡。
