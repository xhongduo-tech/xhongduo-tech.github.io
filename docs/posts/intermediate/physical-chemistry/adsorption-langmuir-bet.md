## 为什么从吸附开始

催化剂工作的第一步是反应物**吸附**在表面；净水器除重金属靠吸附；储氢材料、气体分离、传感器，都建立在这条「物质在界面富集」的现象上。**吸附（adsorption）** 是表面自由能最小化的直接表现：表面分子受力不对称，吸附外来分子能降低表面能，于是表面「抓住」气体或溶质。<span class="marginnote">吸附是表面科学通向应用的枢纽：它既是催化（第五篇《催化原理》）的前置，也是多相反应、气体净化、纳米材料表征（比表面测定）的共同基础。吸附等温线——吸附量与压力的关系曲线——是描述这一现象的标准语言，而朗缪尔与 BET 是两条最经典、应用最广的等温线。</span>

本节把表面自由能（上节）与化学平衡（第一篇）结合：吸附本质是「表面位」与「气相/溶液中分子」的平衡，等温式就是这种平衡的浓度依赖关系。

## 1 物理吸附与化学吸附

按吸附力本质，吸附分两类：

| 特征 | 物理吸附 | 化学吸附 |
| --- | --- | --- |
| 作用力 | 范德华力 | 化学键 |
| 吸附热 | 8–30 kJ/mol | 40–400 kJ/mol |
| 选择性 | 无，普遍吸附 | 有，与表面化学活性匹配 |
| 层数 | 可多层 | 单层 |
| 可逆性 | 易脱附、可逆 | 常不可逆 |
| 活化能 | 无（瞬时） | 可能有（慢） |

**重点：物理吸附像「躺」在表面，化学吸附像「焊」在表面。** 物理吸附是低温下多层、可逆、无选择性的；化学吸附是单层、常需活化、有选择性的。催化中反应物必须先化学吸附才能活化，而比表面测定利用的是低温物理吸附。<span class="marginnote">两类吸附的区分并非总是分明：许多系统介于两者之间。但热力学判据清晰——吸附热大于 40 kJ/mol 基本是化学吸附；分子轨道计算能给出吸附键的本质。活性炭吸附气体多为物理吸附（分子完好），而 $\ce{H2}$ 在铂表面的解离吸附（$\ce{H2 -> 2H(ads)}$）是典型化学吸附，是加氢催化的第一步。</span>

## 2 朗缪尔等温式

**朗缪尔等温式（Langmuir isotherm）** 基于四个假设：表面均匀、单层吸附、吸附位独立、吸附与脱附达到动态平衡。设表面覆盖率为 $\theta$，气体压力 $p$：

$$\theta = \frac{bp}{1 + bp}, \qquad b = \frac{k_a}{k_d}$$

其中 $b$ 是吸附平衡常数，衡量吸附强度（吸附热大则 $b$ 大）。极限行为：$p$ 很小时 $\theta \approx bp$（线性，亨利区）；$p$ 很大时 $\theta \to 1$（饱和单层）。<span class="marginnote">朗缪尔推导的本质是「空位计数」：吸附速率 ∝ 空位分数 $(1-\theta) \times$ 压力，脱附速率 ∝ 覆盖分数 $\theta$，平衡时两者相等。这个动力学平衡的框架与《化学动力学》的基元反应完全同构，也解释了为何 $b = k_a/k_d$ 是平衡常数——吸附就是一个「表面化学反应」。</span>

线性化形式方便作图：$\dfrac{p}{V} = \dfrac{1}{bV_m} + \dfrac{p}{V_m}$，以 $p/V$ 对 $p$ 作图，斜率的倒数给出单层饱和吸附量 $V_m$。

## 3 吉布斯吸附等温式

对溶液表面的吸附，用**吉布斯吸附等温式（Gibbs adsorption isotherm）** 描述溶质在表面的富集与表面张力的关系：

$$\Gamma = -\frac{1}{RT}\left(\frac{\partial\gamma}{\partial\ln c}\right)_T$$

$\Gamma$ 是表面过剩（表面单位面积上溶质的超额量）。**重点：$(\partial\gamma/\partial\ln c) < 0$ 时 $\Gamma > 0$——溶质降低表面张力、在表面富集，这就是表面活性剂；反之溶质升高表面张力（如无机盐），则在表面贫化。** 一条方程直接解释了「什么物质是表面活性剂」。<span class="marginnote">由吉布斯方程可求吸附量 $\Gamma$：测表面张力随浓度的变化曲线，斜率代入即得。对离子型表面活性剂，公式分子里要乘 2（正负离子共同富集），这是实际应用中常做的修正。吉布斯方程还把「表面张力-浓度」的宏观测量与「表面富集」的微观图像连在一起。</span>

## 4 公式解析：朗缪尔等温式 $\theta = \frac{bp}{1 + bp}$

**这条等温线是表面化学最常用的「工作曲线」。** 四步拆解：

- **第一步，看平衡框架**：吸附-脱附平衡 $\text{气相} + \text{空位} \underset{k_d}{\overset{k_a}{\rightleftharpoons}} \text{吸附态}$。吸附速率 $v_a = k_a p(1-\theta)$（压力×空位分数），脱附速率 $v_d = k_d\theta$。
- **第二步，令 $v_a = v_d$**：$k_a p(1-\theta) = k_d\theta$，解得 $\theta = \frac{k_a p}{k_d + k_a p} = \frac{bp}{1+bp}$，其中 $b = k_a/k_d$。**等温式是「吸附速率 = 脱附速率」的直接产物。**
- **第三步，看 $b$ 的温度依赖**：$b$ 是吸附平衡常数，遵循范特霍夫型温度依赖——吸附热越大、温度越低，$b$ 越大、吸附越强。这就是「低温利于吸附、升温脱附」的定量依据（变压/变温吸附分离正是靠它工作）。
- **第四步，看如何测 $V_m$ 与比表面**：把覆盖度换成吸附量 $V = V_m\theta$，线性化 $p/V = 1/(bV_m) + p/V_m$，作图求 $V_m$。若已知每个吸附分子占的面积 $\sigma$（氮气取 $0.162\ \text{nm}^2$），比表面 $S = V_m N_A\sigma/V_0$——**一克催化剂有几平方米表面，就靠这条方程**。

## 5 BET 多分子层吸附

物理吸附可形成多层，朗缪尔只适用于单层。**BET 等温式（Brunauer–Emmett–Teller）** 推广到多层，在 $0.05 < p/p_0 < 0.35$ 区间给出：

$$\frac{p}{V(p_0 - p)} = \frac{1}{V_m c} + \frac{c-1}{V_m c}\cdot\frac{p}{p_0}$$

其中 $p_0$ 是饱和蒸气压，$c$ 是反映第一层吸附热与液化热之差的常数。**BET 在朗缪尔基础上加了一条假设：第一层之后各层吸附热等于液化热。** 由此它同时适用于多层物理吸附。<span class="marginnote">BET 方程的历史地位：它让「比表面」成为可测的常规参数。测氮气在低温下的吸附等温线，按 BET 线性式作图，$V_m$ 得单层容量，乘分子截面积即比表面。催化剂、吸附剂、建筑材料、药品粉体的「比表面」标定几乎都用 BET——这是表面科学最普及的定量工具。</span>

**辨析｜易错点：** BET 线性式只在相对压力 $0.05\text{–}0.35$ 内适用：太高则多层厚度发散、孔中毛细凝聚干扰，太低则第一层未铺满、均匀性假设失效。**朗缪尔 $p/V$ 图与 BET $p/[V(p_0-p)]$ 图的适用对象不同**——前者单层化学吸附，后者多层物理吸附，混用会得到无意义的 $V_m$。

## 6 吸附的应用

- **催化**：反应物化学吸附、活化、反应、产物脱附——催化循环的每一步都发生在表面，吸附等温式给出表面覆盖，决定反应速率与级数（详见《催化原理》）。
- **吸附分离**：活性炭/分子筛吸附有机污染物；变压吸附（PSA）分离氧气/氮气利用吸附量随压力与温度的变化。
- **储氢**：高比表面材料（MOF、活性炭）在低温高压下物理吸附储氢，吸附量与比表面、孔径直接挂钩。
- **气相色谱**：固定相对组分的吸附/分配差异是分离的基础——吸附等温线即色谱保留行为的物化基础。<span class="marginnote">吸附在环保和新能源里的角色越来越大：CO₂ 捕获用胺改性吸附剂、水净化用多孔碳、储氢用 MOF——吸附剂的性能指标（比表面、孔容、选择性）全部由吸附等温线表征，而朗缪尔/BET 是解读这些等温线的两把钥匙。</span>

## 7 吸附的现代应用与表征

吸附理论在现代科技中扮演着「表征工具」与「功能材料」的双重角色。

**比表面与孔径表征**：BET 法是催化剂、吸附剂、电池材料表征的第一道工序。测氮气吸附-脱附等温线，BET 段求比表面，吸附等温线的滞后环（毛细凝聚）配合 BJH、DFT 方法给出孔径分布——**一克电极材料的「微孔 vs 介孔」结构，直接决定储能性能**。材料科学论文里的「BET 比表面」就是这么来的。

**吸附分离工程**：变压吸附（PSA）与变温吸附（TSA）利用「吸附量随压力/温度变化」实现气体分离——制氧（沸石分子筛优先吸附氮）、制氢（脱除 $\ce{CO2}$、$\ce{CO}$）、天然气脱硫。**吸附剂的选择性与容量决定分离成本**，朗缪尔等温式是设计吸附床的入门模型。

**储氢与碳捕捉**：金属有机框架（MOF）、共价有机框架（COF）以超高比表面物理吸附储氢、捕碳；胺改性吸附剂化学吸附 $\ce{CO2}$。吸附热力学（等温线 + 等量吸附热）与吸附动力学（扩散进入孔道）共同决定材料的性能上限。

**辨析｜易错点：** BET 比表面是「氮气分子数 × 单分子截面积」的换算结果，隐含「吸附为六方密堆」的假设。微孔材料（孔径 < 2 nm）的孔填充并非单层铺满，BET 结果会偏大，须用 DFT/微孔分析方法交叉验证——**比表面数字要注明方法才有意义**。

一个用朗缪尔线性化作图求 $V_m$ 的完整算例。某催化剂上测 $\ce{N2}$ 在 $77\ \text{K}$ 的吸附数据（低压段，单层为主）：

| $p$ / kPa | $V$ / cm³·g⁻¹ | $p/V$ / (kPa·cm⁻³·g) |
| --- | --- | --- |
| 2.0 | 8.0 | 0.25 |
| 4.0 | 13.3 | 0.30 |
| 6.0 | 17.1 | 0.35 |
| 8.0 | 20.0 | 0.40 |

**由朗缪尔线性式 $p/V = 1/(bV_m) + p/V_m$**，以 $p/V$ 对 $p$ 作图，斜率 $= 1/V_m$。由表：$p/V$ 从 0.25 到 0.40 对应 $p$ 从 2 到 8，斜率 $= (0.40-0.25)/(8-2) = 0.025\ \text{g·cm}^{-3}$，故 $V_m = 40\ \text{cm}^3\text{·g}^{-1}$。

**换算比表面**：$V_m = 40\ \text{cm}^3\text{·g}^{-1}$（标准态）对应单层分子数 $N = V_m/V_0\times N_A = 40/22400\times6.02\times10^{23} = 1.07\times10^{21}\ \text{g}^{-1}$。乘 $\ce{N2}$ 分子截面积 $0.162\ \text{nm}^2$：

$$S = 1.07\times10^{21}\times0.162\times10^{-18}\ \text{m}^2 = 174\ \text{m}^2\text{·g}^{-1}$$

**比表面 174 m²/g**——这是催化剂的「活性面积」标尺，也是「一克催化剂有几平方米表面」这句话的定量答案。

把吸附放回表面科学的枢纽。**它是「界面富集」的定量理论**——朗缪尔等温式描述单层均匀吸附，BET 推广到多层物理吸附并成为比表面测定的标准，吉布斯吸附等温式把溶液表面的富集与表面张力连接。物理吸附与化学吸附的区分（作用力、吸附热、层数）则决定了应用的方向。

**重点：吸附是「催化、分离、表征」的共同基础**。反应物先吸附才被催化活化（《催化原理》），吸附剂靠选择性吸附分离气体与污染物，比表面与孔径表征（BET）是材料研发的第一道工序。理解「吸附等温线的形状对应吸附模型」这条线索，就掌握了从催化剂评价到储氢材料设计的标准工具，也完成了第四篇表面科学向实际应用的延伸。

## 8 小结

- **物理吸附**（范德华力、多层、可逆）vs **化学吸附**（化学键、单层、常不可逆），吸附热区分二者。
- **朗缪尔等温式** $\theta = bp/(1+bp)$：单层均匀表面；线性化作图求单层容量 $V_m$ 与比表面。
- **吉布斯吸附等温式** $\Gamma = -(\partial\gamma/\partial\ln c)/RT$：溶质降表面张力则表面富集，即表面活性剂判据。
- **BET 等温式**描述多层物理吸附，$0.05\text{–}0.35$ 相对压力内适用，是比表面测定的标准方法。
- 吸附是催化、分离、储氢、净化的共同基础。
