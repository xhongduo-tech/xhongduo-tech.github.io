# 电极电势

<div class="epigraph">

## 为什么从电极电势开始

电池电动势是整体量，化学家却想把它拆成**每个电极的贡献**——毕竟反应发生在电极上，「锌电极的倾向」与「铜电极的倾向」各自可谈。**电极电势（electrode potential）** 把电动势分解为两个半电池的贡献，并建立一张**标准电极电势表**——化学上最常用的数据表之一。<span class="marginnote">单电极电势的绝对值无法测量（任何测量都需要第二个电极做回路），但<strong>差值</strong>可以。因此约定一个基准——标准氢电极，规定其电势为零，所有电极电势都是相对它测出的差值。这就像海平面定海拔：绝对值是约定，差值才可测可用。</span>

有了标准电极电势表，判断氧化还原方向、计算电池电动势、设计电池，都变成查表与加减法。本节之后《能斯特方程》将给电极电势加上浓度依赖，使表能在任意浓度下使用。

## 1 标准氢电极与电极电势定义

**标准氢电极（standard hydrogen electrode, SHE）**：$\ce{Pt | H2(p^\ominus) | H+(a=1)}$。氢气在铂黑表面被吸附并建立 $\ce{2H+ + 2e- <=> H2}$ 平衡，规定其电极电势**恒为零**：$\varphi^\ominus(\ce{H+/H2}) = 0$。

任意电极的**电极电势**定义为：该电极与标准氢电极组成的电池的电动势，且规定电极反应写成还原方向。按 IUPAC 约定，标准电极电势表给出的是**标准还原电势（standard reduction potential）** $\varphi^\ominus$——电极反应写成「氧化型 + ze⁻ → 还原型」，其还原倾向越大，$\varphi^\ominus$ 越正。<span class="marginnote">铂黑电极的意义：铂本身不参与反应，只提供电子传导表面，让 $\ce{H2}$ 与 $\ce{H+}$ 建立快速平衡。凡是气体电极（氢、氧、氯电极）都用惰性铂做导体。SHE 是「原电池电势」与「氧化还原方向」的全球基准，一切电化学标准都以它为原点。</span>

**重点：电极电势数值越正，该电极的氧化型越容易得电子（还原倾向强）；越负，还原型越容易失电子（氧化倾向强）。** 正负号是「与 SHE 相比的还原倾向」，不是「正负电荷」。

## 2 标准电极电势表

把各电极与 SHE 组成电池、测出电动势，得到标准还原电势表。几个经典值（$25\,^\circ\text{C}$）：

| 电极反应 | $\varphi^\ominus$ / V |
| --- | --- |
| $\ce{F2 + 2e- -> 2F-}$ | +2.87 |
| $\ce{Cl2 + 2e- -> 2Cl-}$ | +1.36 |
| $\ce{O2 + 4H+ + 4e- -> 2H2O}$ | +1.23 |
| $\ce{Cu^{2+} + 2e- -> Cu}$ | +0.34 |
| $\ce{2H+ + 2e- -> H2}$ | 0.00 |
| $\ce{Zn^{2+} + 2e- -> Zn}$ | −0.76 |
| $\ce{Na+ + e- -> Na}$ | −2.71 |

<span class="marginnote">表上氟最正（最强氧化剂）、锂/钠最负（最强还原剂）。这张表的用途远超电池：预测氧化还原反应方向（$\varphi^\ominus$ 大的氧化型氧化 $\varphi^\ominus$ 小的还原型）、判断金属活泼性、选氧化剂还原剂、解释元素化学（为什么 $\ce{F2}$ 极活泼、为什么钠能还原钛）。无机化学的「氧化还原规律」几乎都能从表上读出来。</span>

**辨析｜易错点：** 标准还原电势**不随计量系数变化**——$\varphi^\ominus$ 是强度量。把 $\ce{2Cu^{2+} + 4e- -> 2Cu}$ 写成两倍，$\varphi^\ominus$ 仍是 +0.34 V，但 $\Delta G = -zFE$ 中的 $z$ 变为 4、$\Delta G$ 翻倍。合并半反应算电动势时，千万不能把电势按系数加权平均。

## 3 电池电动势 = 正极 − 负极

**重点：电池电动势等于正极（右）电极电势减负极（左）电极电势。**

$$E = \varphi_\text{右} - \varphi_\text{左}$$

对丹尼尔电池 $\ce{Zn | Zn^{2+} || Cu^{2+} | Cu}$：$E^\ominus = \varphi^\ominus(\ce{Cu^{2+}/Cu}) - \varphi^\ominus(\ce{Zn^{2+}/Zn}) = 0.34 - (-0.76) = 1.10\ \text{V}$。<span class="marginnote">这个「右减左」是 IUPAC 的图示约定：电池写法右边是正极（还原），左边是负极（氧化）。所以 $E$ 的计算恒为「还原端电势 − 氧化端电势」。若图示写反，计算得负号——说明实际自发方向与图示相反。</span>

判断自发方向的直接规则：**电极反应中，$\varphi$ 较高的半反应做还原（正极），$\varphi$ 较低的做氧化（负极）**。锌与铜相遇，$\varphi(\ce{Cu^{2+}/Cu}) = +0.34 > \varphi(\ce{Zn^{2+}/Zn}) = -0.76$，所以 $\ce{Cu^{2+}}$ 被还原、$\ce{Zn}$ 被氧化，方向确定。

## 4 公式解析：$\Delta_r G_m = -zF(\varphi_\text{右} - \varphi_\text{左})$

**把电池电动势的拆分与自由能连接起来，是理解「电动势从哪来」的关键。** 四步拆解：

**第一步，看自由能的拆分**：$\Delta_r G_m = -zFE$ 且 $E = \varphi_\text{右} - \varphi_\text{左}$，故 $\Delta_r G_m = -zF\varphi_\text{右} + zF\varphi_\text{左}$。总反应自由能 = 还原半反应（右）自由能 − 氧化半反应（左）自由能。
**第二步，看每个电极的半反应自由能**：把还原半反应看成独立「虚拟电池」$\Delta G_i = -zF\varphi_i$。$\varphi_i$ 越正，该还原半反应的 $\Delta G$ 越负，还原倾向越强。
**第三步，看自发方向的判据**：$E > 0 \Leftrightarrow \varphi_\text{右} > \varphi_\text{左} \Leftrightarrow \Delta G < 0$——电池自发。三个判据是同一条热力学规律的三种语言。
**第四步，看组合技巧**：任意两个电极可组合成电池，电动势 = 两者电势差。因此**不需要为每个反应单独设计电池**——查表组合即可。这正是电极电势表的核心价值：可组合、可移植。

## 5 常见电极类型

**金属-金属离子电极**：$\ce{Zn | Zn^{2+}}$、$\ce{Cu | Cu^{2+}}$。金属浸在含其离子的溶液中，电极电势取决于离子活度。
**气体电极**：$\ce{Pt | H2 | H+}$、$\ce{Pt | Cl2 | Cl-}$。气体吸附在惰性铂上建立平衡，用于氢、氧、氯。
**氧化还原电极**：$\ce{Pt | Fe^{3+}, Fe^{2+}}$。铂惰性，电势由溶液中氧化型/还原型活度比决定——不涉及金属溶解。
**甘汞电极**：$\ce{Hg | Hg2Cl2(s) | KCl}$。电势稳定、制作方便，实验室常用的**参比电极**（取代 SHE，因 SHE 的氢气操作不便）。<span class="marginnote">参比电极是测量的"常数项"：它给出稳定电势作为基准，被测电极与之组成电池，测出电动势再减去参比电势即得被测电极电势。银/氯化银电极（$\ce{Ag/AgCl}$）是生物电化学的标准参比，甘汞电极则是传统分析化学的主力。</span>

## 6 电极电势表的应用：拉蒂默图与弗罗斯特图

标准电极电势表不仅是「查电压」的字典，还提供了看氧化还原化学的全局视图。

**拉蒂默图（Latimer diagram）**：把同一元素各氧化态按从高到低排列，相邻氧化态之间标出标准还原电势。以氯为例（酸性介质）：

$$\ce{ClO4- \xrightarrow{1.20} ClO3- \xrightarrow{1.18} HClO2 \xrightarrow{1.65} HClO \xrightarrow{1.63} Cl2 \xrightarrow{1.36} Cl-}$$

- 相邻两态间的 $\varphi^\ominus$ 直接给出该半反应的还原倾向。
- **歧化（disproportionation）判断**：若右侧电势（高氧化态→中间态）大于左侧电势（中间态→低氧化态），中间态会歧化。例如 $\ce{HClO2}$ 两侧电势 1.65 与 1.63——$\ce{HClO2}$ 可歧化为 $\ce{HClO}$ 与 $\ce{Cl2}$（$E = 1.65 - 1.63 > 0$）。**歧化方向判断是拉蒂默图最常用的功能**。

**弗罗斯特图（Frost diagram）**：以氧化态为横轴、$N\varphi$（$N$ 是氧化态对应的电子数）为纵轴作图。图中斜率越小（越平缓）的氧化态越稳定；曲线上的「凸点」是易歧化的物种、「凹点」是稳定的物种。元素化学里「为什么 $\ce{Cl2}$ 在碱性中歧化而 $\ce{Cl-}$ 稳定」这类问题，弗罗斯特图一目了然。

**应用示例——预测反应方向**：问 $\ce{Cl2 + 2I- -> 2Cl- + I2}$ 能否自发？查表 $\varphi^\ominus(\ce{Cl2/Cl-}) = 1.36 > \varphi^\ominus(\ce{I2/I-}) = 0.54$，故 $\ce{Cl2}$ 氧化 $\ce{I-}$、反应自发——**卤素单质的氧化性强弱顺序（$\ce{F2 > Cl2 > Br2 > I2}$）直接从电势表读出**，是无机化学「卤素递变规律」的定量根源。

**辨析｜易错点：** 拉蒂默图上的电势都是**标准还原电势**，方向统一为「左边氧化态 + 电子 → 右边还原态」。用图判断歧化时，要把两段电势写成同方向比较（$E_\text{右段} - E_\text{左段}$），且注意介质的酸碱性（酸性图与碱性图数值不同），不可混用。

一个用标准电极电势判断反应方向的完整算例。判断 $\ce{Fe + Cu^{2+} -> Fe^{2+} + Cu}$ 能否自发进行。查表：

$$\varphi^\ominus(\ce{Cu^{2+}/Cu}) = +0.34\ \text{V}, \qquad \varphi^\ominus(\ce{Fe^{2+}/Fe}) = -0.44\ \text{V}$$

**方法一（电池拆分）**：铁为负极（氧化）、铜为正极（还原），$E^\ominus = \varphi_\text{右} - \varphi_\text{左} = 0.34 - (-0.44) = 0.78\ \text{V} > 0$——反应自发，且可设计成铁-铜电池（伏打电池原型）。

**方法二（直接比较）**：$\varphi^\ominus(\ce{Cu^{2+}/Cu}) > \varphi^\ominus(\ce{Fe^{2+}/Fe})$，故 $\ce{Cu^{2+}}$ 得电子能力更强、被还原；$\ce{Fe}$ 失电子、被氧化。**电势高的氧化型氧化电势低的还原型**——这个「对角线规则」是判断一切氧化还原方向的口诀。

**方法三（自由能）**：$\Delta_r G^\ominus = -zFE^\ominus = -2\times96485\times0.78 \approx -150\ \text{kJ·mol}^{-1} < 0$——与方向判断一致。

三个方法从不同角度给出同一结论，互相印证。**标准电势表 + 「大者氧化小者还原」规则，是氧化还原化学最通用的判据**。

**辨析｜易错点：** 以上用标准电势（活度均为 1）。实际浓度下方向可能翻转（能斯特方程修正）——标准电势只判标准态方向，非标准态必须用能斯特方程，把标准电势当普遍判据是常见误区。

把电极电势放回电化学的地基。**它是「电动势可分解」的关键一步**——电池总电压拆成两半，各自对应一个电极对电子的亲和力，于是「查表组合」取代「逐个实验」成为可能。标准氢电极作为零点，让所有电极有了可比的海拔；标准还原电势表则是这张「电势地图」的等高线。

**重点：电极电势表是整个电化学与无机化学的「公共字典」**。它同时服务于氧化还原方向判断（对角线规则）、电池设计（$E = \varphi_\text{右} - \varphi_\text{左}$）、元素化学（卤素活性、金属活泼性）与生物化学（氧化还原电位）。理解「电势越正越易得电子」这条主线，再配合能斯特方程的浓度修正，就掌握了从标准态到任意条件的完整电极电势应用——这是《电极电势》到《能斯特方程》的自然递进。

一个补充的辨析：标准氢电极的「标准态」指 $a_{\ce{H+}} = 1$ 的假想溶液与 $1\ \text{atm}$ 氢气——不是任意 pH 的溶液。实际测量中 SHE 用高氯酸等强酸配成活度为 1 的溶液；日常实验室更常用甘汞或银/氯化银参比电极，测得电动势后加上参比电势换算回 SHE 标尺。**报电极电势必须注明参比电极**，否则数值无意义。

## 7 小结

- **标准氢电极（SHE）** 电势定义为零，是所有电极电势的基准。
- **标准电极电势**按还原方向约定，$\varphi^\ominus$ 越正还原倾向越强；是强度量、不随系数变。
- **电池电动势** $E = \varphi_\text{右} - \varphi_\text{左}$，正负号由图示约定决定。
- $\Delta_r G_m = -zF(\varphi_\text{右} - \varphi_\text{左})$：电动势拆分的自由能实质；查表即可组合任意电池。
- 金属电极、气体电极、氧化还原电极、甘汞参比电极各司其职。

在下一节，我们给电极电势加上浓度依赖——**能斯特方程**：浓度、温度如何改变电极电势与电池电动势，这正是「电极电势表扩展到任意条件」的定量工具。
