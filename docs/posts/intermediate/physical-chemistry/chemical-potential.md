## 为什么从化学势开始

前几节讨论的净是**纯物质**系统：一杯水、一摩尔理想气体。可化学研究的对象几乎都是**多组分系统**——溶液、混合物、两相共存的体系。问题是：系统总吉布斯自由能 $G$ 是整体量，当我们加入一滴水、移走一摩尔溶质时，总自由能怎么变？哪一部分「推动力」真正驱动物质从一相跑向另一相、从高浓度跑向低浓度？<span class="marginnote">答案藏在吉布斯 1875 年引入的概念里：<strong>化学势（chemical potential）</strong>。它回答「系统的吉布斯自由能对第 $i$ 组分物质的量的偏导数是多少」，是温度、压力之外决定物质转移方向的第三类「势」。正如温度差驱动热流、压力差驱动流动，化学势差驱动物质流动。</span>

化学势是整个物理化学的枢纽：相平衡说「各相化学势相等」，化学平衡说「反应前后化学势之和守恒」，电化学里带电粒子的化学势与电势合并为电化学势，渗透压、分配定律也都由化学势导出。理解化学势，等于拿到理解全部「平衡」问题的统一钥匙。

## 1 偏摩尔量

先看一个更一般的概念。系统的吉布斯自由能是温度、压力、各组分物质的量的函数：$G = G(T, p, n_1, n_2, \dots, n_k)$。全微分：

$$\mathrm{d}G = \left(\frac{\partial G}{\partial T}\right)_{p,n} \mathrm{d}T + \left(\frac{\partial G}{\partial p}\right)_{T,n} \mathrm{d}p + \sum_i \left(\frac{\partial G}{\partial n_i}\right)_{T,p,n_{j\neq i}} \mathrm{d}n_i$$

前两项我们已经认识：$(\partial G/\partial T)_p = -S$、$(\partial G/\partial p)_T = V$。最后一项是「组分 $i$ 的物质的量变化引起的自由能变化」，定义为第 $i$ 组分的**偏摩尔吉布斯自由能**，也就是**化学势**：

$$\mu_i = \left(\frac{\partial G}{\partial n_i}\right)_{T,p,n_{j\neq i}}$$

**重点：化学势是「在恒温恒压、其他组分不变时，加入 1 mol 组分 $i$ 引起的系统自由能增加」。** 它衡量第 $i$ 个组分在这个混合环境中「身价」的高低——浓度稀的组分、结合紧密的组分，化学势各不相同。<span class="marginnote">偏摩尔量的思想不止用于自由能：偏摩尔体积 $\bar V_i$、偏摩尔焓 $\bar H_i$ 都是同一套框架。例如 $50\ \text{mL}$ 乙醇加 $50\ \text{mL}$ 水体积不足 $100\ \text{mL}$，就是因为各组分的偏摩尔体积不等于纯态摩尔体积——混合改变了微观堆叠方式。</span>

## 2 化学势判据：物质转移的方向标

把化学势代入自由能判据，就得到多组分系统的方向判据。恒温恒压下，若系统内部发生物质转移（物质从一相 $\alpha$ 转移到另一相 $\beta$）：

$$\Delta G = \mu^\alpha \Delta n^\alpha + \mu^\beta \Delta n^\beta = (\mu^\alpha - \mu^\beta)\,\Delta n^\alpha \leq 0$$

**重点：物质自发地从化学势高的一相流向化学势低的一相，直到两相化学势相等。** 这正是「水往低处流」的化学版——只是这里的「低处」不是高度，而是化学势。<span class="marginnote">把这个道理用到生活：浓糖水中的糖会向清水扩散，是因为糖在水中的化学势随浓度升高而升高；扩散的终点是两侧浓度相等、化学势相等。<strong>浓度差只是表象，化学势差才是本质</strong>——这也是渗透压、分配平衡的出发点。</span>

**辨析｜易错点：** 化学势判据的条件是恒温恒压。但「化学势相等是相平衡条件」本身不要求恒压过程——平衡态成立的条件是在平衡态下检验，只要系统已达平衡，各相化学势必相等。初学者常把「判断方向需恒温恒压」与「平衡时化学势相等」混为一谈，二者不是一回事。

## 3 纯组分理想气体的化学势

先算最简单的系统：纯理想气体。恒温下 $\mathrm{d}G = V\,\mathrm{d}p$，对 $1\ \text{mol}$ 气体，从标准态压力 $p^\ominus$ 变到 $p$：

$$\mu = \mu^\ominus(T) + RT\ln\frac{p}{p^\ominus}$$

这里 $\mu^\ominus(T)$ 是标准态（$p^\ominus = 100\ \text{kPa}$，指定温度）下气体的化学势，只与温度有关。<span class="marginnote">对数项 $RT\ln(p/p^\ominus)$ 是「压缩带来的化学势提升」。压力越大、浓度越高，化学势越高，物质越「想」跑向低压低浓区域。这一对数关系是整个化学势体系的种子——混合物、溶液、平衡常数里的对数结构全都从这里长出来。</span>

对理想气体混合物，第 $i$ 组分的化学势同样成立：

$$\mu_i = \mu_i^\ominus(T) + RT\ln\frac{p_i}{p^\ominus}$$

其中 $p_i = y_i p$ 是分压。混合物中各组分的化学势只与**自身分压**有关，与其他组分无关——理想气体分子之间无相互作用，这是「理想」二字的全部含义。

## 4 公式解析：溶液中组分的化学势

**溶液与理想气体唯一的差别，是把「分压」换成「浓度」或「活度」。** 以理想稀溶液为例，溶剂 A 服从拉乌尔定律、溶质 B 服从亨利定律，它们的化学势分别为：

$$\mu_A = \mu_A^\ast(T,p) + RT\ln x_A, \qquad \mu_B = \mu_B^\ominus(T,p) + RT\ln x_B$$

- **第一步，认识 $x_A$、$x_B$**：摩尔分数。$x_A$ 接近 1（稀溶液），$x_B$ 很小。化学势随浓度对数上升：浓度越大，化学势越高。
- **第二步，理解两个基准 $\mu_A^\ast$ 与 $\mu_B^\ominus$**：溶剂的标准态是纯溶剂（$x_A = 1$）；溶质的标准态是 $x_B = 1$ 的假想纯态，因为真实溶液在 $x_B \to 1$ 时早就不服从亨利定律了。**溶质标准态是外推出来的参考点**，这是溶液热力学最易困惑处。
- **第三步，看非理想修正**：真实溶液中组分间有相互作用，用**活度（activity）$a$** 取代浓度：$a = \gamma x$，其中 $\gamma$ 为**活度系数（activity coefficient）**。于是普遍形式是：
$$\mu_i = \mu_i^\ominus + RT\ln a_i$$
- **第四步，读出判据意义**：活度越高，化学势越高。把 $a = \gamma x$ 代入平衡条件 $\sum \nu_i \mu_i = 0$，就能推出真实化学平衡的平衡常数 $K^\ominus = \prod a_i^{\nu_i}$——下一节《化学平衡》的核心公式。

**重点：活度是「有效浓度」。** 它把一切非理想性（离子缔合、分子间作用、静电屏蔽）收进一个修正因子 $\gamma$，使化学势的漂亮形式 $\mu = \mu^\ominus + RT\ln a$ 在任意系统中继续成立。活度系数的计算（德拜-休克尔理论）是电解质溶液理论的核心，见第三篇《电解质溶液》。<span class="marginnote">亨利定律与拉乌尔定律的分工值得记牢：<strong>拉乌尔定律</strong>描述溶剂（高浓度端）：$p_A = p_A^\ast x_A$；<strong>亨利定律</strong>描述溶质（稀浓度端）：$p_B = k_x x_B$，比例系数 $k_x$ 是与溶剂有关的经验常数。同一组分在不同区域适用的定律不同，这正是溶质标准态要外推的原因。</span>

## 5 化学势的实际用法：三个标志性应用

化学势的威力在于一以贯之。三个最典型的应用：

- **渗透压**：半透膜两侧溶剂化学势相等可推出范特霍夫渗透压定律 $\Pi = cRT$。溶质降低溶剂化学势，为恢复平衡，纯溶剂侧必须加压力升高化学势，这个压力差就是渗透压。
- **相平衡条件**：两相平衡时 $\mu^\alpha = \mu^\beta$，结合纯物质化学势的温度压力关系，得到克拉佩龙方程——它是相图全部曲线的来源。
- **化学平衡条件**：反应 $\sum \nu_i B_i = 0$ 达平衡时 $\sum \nu_i \mu_i = 0$，由此推出反应等温式与平衡常数。化学势是化学平衡的微观基础。

**辨析｜易错点：** 化学势的数值依赖标准态的选择——同一系统在不同标准态下 $\mu_i^\ominus$ 不同。但**平衡条件**、**化学势之差**与标准态无关，因为标准态项在相减时抵消。所以查表时要先看清标准态约定（纯物质？假想 1 mol·L⁻¹？1 mol·kg⁻¹ 质量摩尔浓度？），而判据本身不受影响。

## 6 化学势在分离与生物过程中的应用

化学势的「物质从高化学势流向低化学势」判据，是大量实际过程的统一解释。

**萃取分离**：溶质在两种不互溶溶剂间分配，平衡条件是两相化学势相等。由 $\mu = \mu^\ominus + RT\ln a$，得**分配定律** $c^\alpha/c^\beta = K_D$（分配系数）——萃取分离的理论基础。工业萃取、药物在油水两相的分布、色谱分离的保留行为，全是同一原理。

**渗透与膜分离**：半透膜两侧溶剂化学势相等给出渗透压 $\Pi = cRT$（范特霍夫渗透压定律）。海水淡化（反渗透）正是对高渗侧加压、迫使水反渗透——外加压力就是「抬高化学势」的工具。血液透析、植物吸水、细胞体积调节都是渗透压的生理表现。

**生物膜电位**：细胞膜内外 $\ce{K+}$、$\ce{Na+}$、$\ce{Cl-}$ 浓度不同，带电粒子的化学势与静电势合并为**电化学势** $\tilde\mu = \mu + zF\phi$。平衡时膜两侧电化学势相等，给出**能斯特电位** $E = \dfrac{RT}{zF}\ln\dfrac{c_\text{外}}{c_\text{内}}$——神经细胞静息电位的来源。电化学势是《电化学》与生物物理的接口。

**辨析｜易错点：** 化学势相等是平衡条件，但**渗透压、分配、膜电位这些公式都只在理想稀溶液成立**。真实体系须用活度修正（$\mu = \mu^\ominus + RT\ln a$），且带电体系必须用化学势 + 电势合并的电化学势，只取其中一项会得到错误结论——这也是《电解质溶液》中活度系数理论的用武之地。

一个用化学势理解分配平衡的算例。碘 $\ce{I2}$ 在四氯化碳与水之间分配，$25\,^\circ\text{C}$ 分配系数 $K_D = c_{\ce{CCl4}}/c_{\ce{H2O}} = 85$。平衡时碘在两相的化学势相等：$\mu_{\ce{CCl4}}^\ominus + RT\ln c_{\ce{CCl4}} = \mu_{\ce{H2O}}^\ominus + RT\ln c_{\ce{H2O}}$，故：

$$\ln K_D = \frac{\mu_{\ce{H2O}}^\ominus - \mu_{\ce{CCl4}}^\ominus}{RT}$$

**化学势之差决定分配倾向**：碘在 $\ce{CCl4}$ 中标准化学势低（更「舒服」），平衡时它富集在 $\ce{CCl4}$ 相。**分配系数不是「浓度喜好」而是「化学势差」的指数表现**——同一个碘分子在两种溶剂里的化学势差 11 kJ/mol 就对应 $K_D = 85$。

**萃取设计**：若用 $\ce{CCl4}$ 萃取 100 mL 水中的碘，每次用 50 mL $\ce{CCl4}$，一次萃取后水中残留比例 $= \dfrac{V_\text{水}}{V_\text{水} + K_D V_\text{有机}} = \dfrac{100}{100 + 85\times50} = \dfrac{100}{4350} \approx 2.3\%$；分两次各 25 mL，残留 $\left(\dfrac{100}{100+85\times25}\right)^2 \approx (4.5\%)^2 = 0.2\%$——**少量多次萃取效率远高于一次大量萃取**，这是化学势分配定律在萃取工程中的经典结论。

**辨析｜易错点：** 分配定律要求溶质在两相中以**同一种分子形态**存在。若溶质在水中电离或缔合（如 $\ce{HA <=> H+ + A-}$），有效分配系数随 pH 变化，须用「表观分配系数」——把解离平衡一并计入，这是药物在油水两相分配的常见复杂情形。

把化学势放回第一篇的收官位置。它是「自由能的最小单元」——**温度、压力之外，化学势是驱动物质转移的第三种「势」**，正如温度差驱动热流、压力差驱动流动、化学势差驱动物质流。相平衡说「化学势相等」，化学平衡说「反应各方化学势加权和为零」，溶液理论、渗透压、电化学势全部从这里长出。

**重点：化学势让「多组分热力学」有了统一的起点**。从纯物质的 $G$ 到混合体系的 $\mu_i$，是把热力学从「一个系统」推广到「一群组分」的关键一步；配分函数的统计版本 $\mu = -kT\ln(q/N)$ 又为它提供了微观解释。**掌握化学势，等于拿到了从《熵与自由能》通向《相平衡》《化学平衡》《电化学》的枢纽**——它是整个物理化学中复用率最高的概念之一，也是理解「为什么物质会移动、会反应、会平衡」的总钥匙。

一个补充的辨析：化学势是**偏摩尔量**——它的定义是「恒温恒压下加入 1 mol 组分 $i$ 引起的系统自由能变化」，因此它描述的是「这个组分在混合体系中的边际贡献」，而不是纯态的性质。温度、压力、其他组分浓度都会改变 $\mu_i$。这也解释了为何「化学势相等」是普适平衡条件：任何相内组分转移，总是以「降低高化学势方、升高低化学势方」为方向，直到处处相等。

一条记忆锚点：**温度差驱动热、压力差驱动流动、化学势差驱动物质**——化学势是「物质移动的势」，相平衡与化学平衡都是它的平衡条件。

## 7 小结

- **偏摩尔量**：系统某性质对各组分物质的量的偏导；**化学势** $\mu_i = (\partial G/\partial n_i)_{T,p}$ 是偏摩尔吉布斯自由能。
- **化学势判据**：物质自发从化学势高处流向低处，平衡时各相（各反应方）化学势相等。
- 纯组分理想气体：$\mu = \mu^\ominus + RT\ln(p/p^\ominus)$；溶液中推广为 $\mu_i = \mu_i^\ominus + RT\ln a_i$。
- **活度** $a = \gamma x$ 是有效浓度，把非理想性收进活度系数 $\gamma$。
- 渗透压、相平衡、化学平衡三大平衡都统一于「化学势相等」这一条原理。

在下一节，我们把「各相化学势相等」具体化到两相系统——温度、压力对相平衡如何影响，相图上的曲线从何而来，这正是**相平衡与相图**的内容。
