# 加速失效时间模型

## 为什么从 AFT 模型开始

Cox 比例风险模型统治了临床生存分析半个世纪，但它有一个不可回避的前提：**任何两个体的危险比不随时间改变**。当这个假设被违例——比如治疗只在早期有效、或风险曲线交叉——Cox 的估计就会扭曲。这时需要另一副眼镜来看数据：**加速失效时间（accelerated failure time, AFT）模型**。<span class="marginnote">AFT 的历史比 Cox 更早：它源自工程可靠性领域「时间被加速/减速」的直觉——更高的应力让元件更快失效，等效于「把时钟拨快」。把这个直觉写进回归，就是 AFT 模型。</span>

AFT 的核心假设是：**协变量的作用不是「倍增风险」，而是「伸缩时间」**。治疗不是把危险乘以某个倍数，而是把整条生命时间轴拉长或压缩。对很多应用（尤其是疾病进展缓慢、或危险曲线形态复杂）来说，「时间伸缩」比「风险成比例」更贴合机制。

## 1 模型的回归形式：对对数生存时间做线性回归

AFT 模型把生存时间的对数写成线性回归形式：

$$\ln T_i = \mu + \boldsymbol{\beta}'\mathbf{X}_i + \sigma \varepsilon_i$$

其中 $\mu$ 是截距，$\boldsymbol{\beta}$ 是协变量系数，$\sigma > 0$ 是尺度参数，$\varepsilon_i$ 是误差项，服从某个指定的分布（标准极值分布 → Weibull；标准正态 → 对数正态；logistic → 对数 logistic）。<span class="marginnote">这个形式与普通线性回归惊人地相似——唯一不同的是响应是「对数生存时间」，且它天然带删失。把第 2 课的删失似然配方套进来：事件个体贡献 $f(t)$，删失个体贡献 $S(t)$，MLE 照常工作。</span>

**重点：AFT 直接对时间建模，系数 $\boldsymbol{\beta}$ 的意义是「把对数生存时间移动多少」**，而不是「把风险乘多少」。这看似只是表述差异，实则是对数据机制的不同承诺。

**关于删失的说明**：AFT 的对数线性形式让删失处理依旧优雅——事件个体贡献密度 $f(t) = f_\varepsilon\!\big((\ln t - \mu - \boldsymbol{\beta}'\mathbf{X})/\sigma\big)/(\sigma t)$，删失个体贡献生存函数 $S(t) = S_\varepsilon\!\big((\ln t - \mu - \boldsymbol{\beta}'\mathbf{X})/\sigma\big)$，代入第 2 课的通用似然配方即可。删失者继续只出现在「未事件」分支，机制与参数模型完全一致。

## 2 生存函数视角：整条时间轴被伸缩

对 $\ln T$ 的模型取指数，得到生存函数的「伸缩」形式。设 $S_0$ 是 $\varepsilon$ 的基线生存函数（$\mathbf{X} = \mathbf{0}$），则

$$S(t \mid \mathbf{X}) = S_0\!\left( \frac{t}{e^{\boldsymbol{\beta}'\mathbf{X}}} \right)$$

**解读**：协变量把时间坐标 $t$ 除以一个常数 $e^{\boldsymbol{\beta}'\mathbf{X}}$ 再代入基线生存函数。若 $e^{\boldsymbol{\beta}'\mathbf{X}} = 2$，意味着「这个人的时间轴被放大了 2 倍」——他比基线人群多活一倍的时间，无论看哪个时刻。**整条生存曲线沿着时间轴被均匀地拉伸或压缩**，而不是像 PH 那样沿概率轴等比移动。

**分位数视角**：对任意分位数 $q$，设基线人群的 $q$ 分位生存时间为 $\tau_q$，则协变量 $\mathbf{X}$ 下的人群 $q$ 分位生存时间为 $e^{\boldsymbol{\beta}'\mathbf{X}} \tau_q$。也就是说，**所有分位数都被同一个因子伸缩**——中位数、25 分位、90 分位，全部乘以同一个 $e^{\boldsymbol{\beta}'\mathbf{X}}$。这正是 AFT 被称为「时间伸缩」的原因，也直接催生了**分位数回归**在生存分析中的版本：把「时间比」解读为「分位生存时间的伸缩比」。<span class="marginnote">这正是「加速」二字的来源：把时间乘上 $e^{-\boldsymbol{\beta}'\mathbf{X}}$ 相当于快进/慢放。可靠性的经典例子：温度每升高 10°C，元件寿命减半，就对应一个 $e^{\beta} = 0.5$ 的伸缩因子。</span>

## 3 系数解读：时间比与加速因子

单个系数 $\beta_k$ 的解读是 AFT 与 Cox 最大的不同。对协变量 $X_k$ 增加 1 个单位，生存时间的中位数（或任意分位数）的比值为：

$$\text{时间比（time ratio）} = e^{\beta_k}$$

- $e^{\beta_k} > 1$：$X_k$ 越大，生存时间越长（如保护因素），风险越低；
- $e^{\beta_k} \lt  1$：$X_k$ 越大，生存时间越短（如不利因素）；
- 通常报「生存时间增加 $e^{\beta_k} - 1$ 倍」或「缩短 $1 - e^{\beta_k}$」。<span class="marginnote">注意与 Cox 的对比：Cox 的 $e^{\beta}$ 是风险比（hazard ratio），越大越危险；AFT 的 $e^{\beta}$ 是时间比（time ratio），越大越长寿。<strong>同一个符号 $e^{\beta}$，两种模型里方向相反</strong>——读文献前先确认模型类型，是最容易踩的坑。</span>

**直觉对照**：若化疗组的 AFT 时间比 = 1.5，意思是「化疗组的中位生存时间是对照组的中位数乘以 1.5」——不是「风险降低 33%」，而是「时间轴放长 50%」。两个说法数值相近但机制不同，对患者沟通时后者更直白。

**对连续协变量的读法**：年龄系数若为 $e^{\beta} = 0.96$，则「每增一岁，生存时间中位数乘以 0.96」，即每增一岁大约缩短 4%。把连续变量标准化后再进模型，系数解读会变为「每增一个标准差」——这改变了 $e^{\beta}$ 的数值但不改变模型的拟合，只是让解读更易沟通。**易错点｜辨析**：AFT 的 $e^{\beta} \lt  1$ 表示「更快失效」，与 Cox 的 $e^{\beta} > 1$ 表示「更高风险」指向同一现象——但符号方向相反，跨模型比较时务必先确认模型类型，切勿只凭「小于 1 就是好」的直觉。

## 4 公式解析：AFT 与 PH 的异同

把 AFT 的危险函数写出来，与 Cox 并排看，两者的差别立刻显现。

对 $\ln T = \mu + \boldsymbol{\beta}'\mathbf{X} + \sigma\varepsilon$，其危险函数为：

$$h(t \mid \mathbf{X}) = \frac{1}{e^{\boldsymbol{\beta}'\mathbf{X}}} \, h_0\!\left( \frac{t}{e^{\boldsymbol{\beta}'\mathbf{X}}} \right)$$

**第一步，看时间参数被伸缩**：$h_0$ 的自变量是 $t/e^{\boldsymbol{\beta}'\mathbf{X}}$，即「被压缩过的时间」——这是 AFT 的本质：**基线危险函数本身随时间轴伸缩**。

**第二步，看整体多了一个因子 $1/e^{\boldsymbol{\beta}'\mathbf{X}}$**：危险函数还被整体缩放。两个作用叠加，结果是：**任意两个体的危险比不再恒定，而是随时间变化**（除非 $h_0$ 是幂函数，见下）。

**第三步，对比 Cox**：Cox 的危险 $h(t) = h_0(t) e^{\boldsymbol{\beta}'\mathbf{X}}$ 是「同一时刻、危险等比」；AFT 的危险是「同一时刻、时间坐标已移位、危险按移位后的值再缩放」。**PH 假设危险比恒定；AFT 假设的是时间被伸缩**。

**第四步，Weibull 的特殊地位**：当 $\varepsilon$ 服从标准极值分布（Weibull 误差）时，$h_0(t) = \lambda\gamma t^{\gamma-1}$ 是幂函数，伸缩 $t \mapsto t/e^{\beta}$ 恰好等价于危险乘一个常数——**Weibull 是唯一同时满足 PH 与 AFT 的分布族**。<span class="marginnote">这是 AFT 与 PH 的「握手点」：对 Weibull 数据，用 Cox 与用 AFT 估计同一参数得到的是同一个模型的两种表述，系数互为倍数关系 $\beta_{\text{AFT}} = -\beta_{\text{PH}} \cdot \sigma$（注意符号）。实务中用 Weibull 拟合后，可同时报告风险比与时间比。</span>

**延伸**：对数正态与对数 logistic 的危险函数先升后降（倒浴盆），它们的 AFT 形式在 Cox 框架下没有对应的 PH 表述——这正是 AFT 覆盖 Cox 之外的「领地」。若数据呈现出「早期风险上升、后期风险下降」（如手术后感染、新药急性毒性），这些分布在 AFT 里能自然刻画，而 Cox 只能靠复杂的时变系数或分层勉强逼近。

## 5 何时选 AFT：PH 违例时的自然选择

选 AFT 而非 Cox，通常出于三类理由：

**PH 违例**：Schoenfeld 残差提示风险比随时间漂移，或生存曲线明显交叉时，AFT 的「时间伸缩」机制往往更贴切；
**可解释性**：想直接回答「治疗让生存时间延长百分之多少」，AFT 的时间比是最自然的语言；
**分布结构**：对数 logistic、对数正态等分布的危险先升后降（倒浴盆），其 AFT 形式有闭合的生存函数，便于计算分位数与预测。<span class="marginnote">对数 logistic 分布还有一个吸引人的性质：它允许危险函数非单调，却仍能写出闭式的生存函数 $S(t) = 1/(1 + (\lambda t)^{1/\sigma})$——这让它在「潜伏期」类数据（HIV 感染到发病、设备维修后复发的间隔）中很受欢迎。</span>

**代价**：AFT 的参数估计对误差分布假设更敏感——如果 $\varepsilon$ 的真实分布与指定分布差得远，系数估计会失真；而 Cox 对 $h_0$ 的形状免疫。所以实践中常用信息准则（AIC）比较不同分布的 AFT 拟合，并与 Cox 的结果交叉验证。

**一个补充视角**：AFT 的「时间伸缩」与物理加速试验天然契合，也因此它比 Cox 更早出现在工程领域。统计上两者的关系可以概括为——**PH 是「危险的乘法」，AFT 是「时间的乘法」**。当研究者关心的机制是「处理改变了疾病进展的速度」时，AFT 是对机制更忠实的表述；而当关心的是「处理改变了某时刻的风险」时，Cox 更直接。选择不应只看数据拟合，还要看**研究问题本身承诺哪种机制**。

## 6 一个数值例子：时间比落到具体数字

用一组简化数据体会 AFT 的「时间伸缩」。设某种治疗方案对复发时间建模（Weibull 误差），拟合得到 $\hat{\mu} = 4.6$、$\hat{\sigma} = 0.8$、治疗系数 $\hat{\beta} = -0.69$（治疗组 $X = 1$，对照组 $X = 0$）。

**时间比**：$e^{-0.69} = 0.50$。解读为：**治疗组的中位复发时间是对照组的一半**——治疗反而加速复发？还是说治疗组是保护因素？（本例演示：若 $\beta$ 为负，时间比小于 1，说明 $X$ 增大生存时间缩短。数值正负要与研究情境对应，切勿机械套用。）

**中位生存时间**：Weibull 的基线中位数满足 $S_0(m) = 0.5$。对照组中位复发时间约 $e^{\hat{\mu}} = e^{4.6} \approx 99$（天）；治疗组约 $99 \times 0.50 \approx 50$ 天。**注意：AFT 的乘法结构让「中位数之比 = 时间比」处处成立**——不管分布偏斜与否，因为伸缩是对分位数整体施加的。<span class="marginnote">这一点与 Cox 形成鲜明对照：Cox 只给出风险比，要换算成「中位数差多少」需要另配基线生存估计；AFT 直接把分位数比例写在系数里。</span>

**与 Cox 的换算**：同一批 Weibull 数据若用 Cox 拟合，风险比系数 $\hat{\beta}_{\text{PH}}$ 与 AFT 系数满足 $\hat{\beta}_{\text{AFT}} = -\hat{\sigma}\,\hat{\beta}_{\text{PH}}$。代入数字：$\hat{\beta}_{\text{PH}} = -(-0.69)/0.8 = 0.86$，即风险比 $e^{0.86} \approx 2.4$——治疗组风险约是对照组 2.4 倍，与「中位时间减半」在机制上完全一致（同一批数据、同一个模型，只是两种参数化）。这个等式是核对软件输出正确性的极好工具：**Cox 的风险比与 Weibull AFT 的时间比可以通过 $\sigma$ 互相转换**。

## 7 估计与模型比较

AFT 的估计完全走参数模型的通用配方：写删失似然，代入所选误差分布的密度与生存函数，数值最大化。<span class="marginnote">R 的 `survreg`、`flexsurv` 与 Python 的 `lifelines` 都内置 AFT：`survreg` 的默认输出直接给出 $\mu, \boldsymbol{\beta}, \sigma$（$\sigma$ 叫 `Scale`），`lifelines` 的 `AFT` 类支持指数、Weibull、对数正态、对数 logistic 四种误差。注意各软件对参数化的约定（如 $\lambda$ 与 $\sigma$ 的关系）略有差异，读输出时先核对定义。</span>

模型比较分两层：**同一分布族内**，用似然比检验比较嵌套协变量集；**不同分布之间**，用 AIC 比较（参数个数不同时不能用似然比）。若 AFT 的 AIC 明显低于 Cox 的 AIC，说明「时间伸缩」假设比「风险成比例」更贴合这批数据——但 AIC 比较的前提是两者的似然定义可比（都包含基线部分的处理，实务中通常近似可比）。<span class="marginnote">一个务实建议：不要执着于「哪个模型绝对正确」。两模型都拟合、都报告——若结论在两种机制下一致，结果是稳健的；若矛盾，说明数据对模型假设敏感，应在论文中如实展示。</span>

**关于尺度参数 $\sigma$**：$\sigma$ 本身也有解读——它控制误差的分散程度，$\sigma$ 越大，生存时间的变异越大（在对数尺度）。在 Weibull 下 $\sigma = 1/\gamma$，所以 $\sigma \lt  1$ 对应危险递增（$\gamma > 1$），$\sigma > 1$ 对应危险递减。报告 AFT 结果时，$\sigma$ 与系数同样值得汇报，它承载了「时间伸缩的随机性有多大」的信息。

**稳健性**：若担心误差分布假设过强，可改用**半参数 AFT**（对 $\varepsilon$ 的分布不做假设，用秩方法估计），或用删失数据的秩回归。这类方法在小样本下不如全参数 AFT 有效，但放宽了分布假设，是介于 Cox 与全参数 AFT 之间的中间路线。

## 8 小结

- **AFT 模型**：$\ln T = \mu + \boldsymbol{\beta}'\mathbf{X} + \sigma\varepsilon$，把协变量效应建模为「对数生存时间的移动」。
- **生存函数** $S(t \mid \mathbf{X}) = S_0(t/e^{\boldsymbol{\beta}'\mathbf{X}})$：整条时间轴被均匀伸缩。
- **时间比** $e^{\beta_k}$：$X_k$ 每增一单位，生存时间（中位数）乘以 $e^{\beta_k}$；与 Cox 的风险比方向相反。
- **Weibull 是唯一同时满足 PH 与 AFT 的分布**，也是两种模型的握手点。
- **选型**：PH 违例、要时间解读、或想用倒浴盆危险时选 AFT；误差分布假设越强，越要用 AIC 与 Cox 交叉验证。
- 所有分位数被同一个因子伸缩；中位数之比 = 时间比，与分布形状无关。
- 与 Cox 并用时注意符号方向相反（AFT 时间比 $< 1$ 对应 PH 风险比 $> 1$）；Weibull 下可经 $\sigma$ 与 $\hat{\beta}_{\text{PH}}$ 互相换算，这是核对软件输出的廉价工具。
- **估计与实现**：走删失似然的通用配方；R 的 `survreg`、`flexsurv` 与 Python `lifelines` 的 `AFT` 类都内置指数、Weibull、对数正态、对数 logistic 四种误差，`survreg` 的 `Scale` 即 $\sigma$。
- **半参数路线**：若担心误差分布假设过强，可用秩方法拟合半参数 AFT——它介于 Cox 与全参数 AFT 之间，小样本效率略低但分布假设更弱。

在下一节，我们将进入第 2 篇，处理一个更贴近临床现实的问题：协变量会随时间变化——**时依协变量**。AFT 的「时间伸缩」与 Cox 的「风险成比例」，都将被放到动态协变量的新情境下重新检验。
