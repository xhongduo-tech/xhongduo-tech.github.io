# 外测度：定义（开覆盖下确界）与基本性质

## 为什么从外测度开始

前三篇的工具终于要兑现成实变函数论的核心货币——**测度**。黎曼积分的问题在于「细分割」依赖区间端点的连续性；Lebesgue 的破解之道是换一把尺子：**不问集合内部怎么切，而问用多少「开区间」从外面把它罩住。** 罩住的总长度取下确界，就是外测度。

外测度有三个特点决定了整章走向：它**处处有定义**（任何集合都有外测度，可能是 $+\infty$）、它**是次可加的**（可数个集合之和 ≥ 并之外测度）、但它**不一定是可加的**（两两不相交的并之外测度未必等于之和）。第三点是关键缺陷——外测度太平凡了，需要从中**筛选**出「好集合」（可测集），才能让可加性恢复。<span class="marginnote">「从平凡的外测度中挑出好集合」是 Carathéodory 的伟大洞见。他的筛选条件是「对任意试探集 $T$，$m^*(T)=m^*(T\cap E)+m^*(T\setminus E)$」——用「$E$ 能否把任何集合都干净地切开」来判定 $E$ 可测。这个条件初看抽象，却恰好保证可加性。</span>

## 1 外测度的定义

**定义（Lebesgue 外测度）**：设 $E\subset\mathbb{R}^n$。用开区间族覆盖 $E$，记

$$m^*(E)=\inf\left\{\sum_{k=1}^{\infty}|I_k|:\ E\subset\bigcup_{k=1}^{\infty}I_k,\ I_k\ \text{为开区间}\right\}$$

其中 $|I_k|$ 是 $I_k$ 的体积（一维长度、二维面积、$n$ 维体积）；覆盖允许至多可数多个开区间，也允许 $I_k$ 的并超出 $E$。$m^*(E)$ 称为 $E$ 的 **Lebesgue 外测度（outer measure）**。

**核心直觉：「外测度 = 罩住 $E$ 的最便宜的开区间账本」。** 允许罩得略大（开区间必须开，$E$ 的边界点难精确贴合），所以叫「外」——从外面量，宁多勿少。取**可数**覆盖而非有限覆盖，是因为像 $\mathbb{Q}$ 这样的集合只有用可数堆点才能精确贴合。<span class="marginnote">为什么开区间而非闭区间？因为开区间的构造定理（第二篇）保证任何开集都是可数个互不相交开区间的并，外测度因此与「开集之体积」无缝衔接。闭区间覆盖会把单点集量成 $0$ 很麻烦（端点重叠导致计数问题），开区间最省事。</span>

**例**：$m^*(\{x\})=0$（用 $I_k=(x-\tfrac1{k},x+\tfrac1{k})$ 覆盖，总长 $2\sum\tfrac1k\to\infty$？不——只需**一个**区间 $(x-\varepsilon,x+\varepsilon)$，下确界为 $0$）。$m^*(\mathbb{Q})=0$（$\mathbb{Q}$ 可数，用第 $k$ 个长 $\tfrac{\varepsilon}{2^k}$ 的区间罩第 $k$ 个有理点，总长 $\varepsilon$，下确界 $0$）。

## 2 外测度的基本性质

**性质一（单调性）**：$E\subset F\Rightarrow m^*(E)\le m^*(F)$。覆盖 $F$ 的开区间族也覆盖 $E$，下确界只可能更小。

**性质二（次可加性）**：对任意至多可数族 $\{E_k\}$，

$$m^*\left(\bigcup_{k=1}^{\infty}E_k\right)\le\sum_{k=1}^{\infty}m^*(E_k)$$

证明要点：对每个 $E_k$，取覆盖 $\{I_{k,j}\}_j$ 使 $\sum_j|I_{k,j}|\le m^*(E_k)+\tfrac{\varepsilon}{2^k}$；全体 $\{I_{k,j}\}$ 覆盖并集，故 $m^*(\bigcup E_k)\le\sum_{k,j}|I_{k,j}|\le\sum_k m^*(E_k)+\varepsilon$，令 $\varepsilon\to0$。**「$\varepsilon/2^k$」的分配技巧**（每个集合分到的误差随 $k$ 指数衰减）是测度论的第一招，往后处处可见。

**性质三（正则性）**：$m^*(E)=\inf\{m^*(G):G\supset E,\ G\ \text{开}\}$。外测度等于「从外面用开集逼近」的下确界——事实上定义里用开区间，而开区间族的并是开集，两条路殊途同归。这条性质让「用开集外逼近」成为可能，是下一节等价刻画的主角。

**性质四（平移不变性）**：$m^*(E+a)=m^*(E)$。把开区间族整体平移，总长不变——测度不随坐标系移动而改变。

**性质五（区间自身）**：$m^*([a,b])=m^*((a,b))=b-a$。开区间被自身覆盖，故 $m^*((a,b))\le b-a$；而任何覆盖的开区间总长至少 $b-a$（连通性论证），故相等。**外测度与「长度」在区间上完全吻合——这就是它配得上「测度」之名的底气。**

## 3 外测度的「缺陷」：次可加 ≠ 可加

次可加性给的是「≤」。若集合两两不相交，我们希望是「=」——**可数可加性**。外测度能否做到？

**定理（区间外测度可加）**：若 $\{I_k\}$ 是两两不相交的区间（开、闭、半开均可），则

$$m^*\left(\bigcup_{k=1}^{\infty}I_k\right)=\sum_{k=1}^{\infty}|I_k|$$

证明较繁，本质靠区间的体积可数可加（用有限可加性 + 单调收敛夹逼）。但对一般集合，外测度的可加性**并不自动成立**——问题出在「从外面罩」会同时罩住间隙。

**重点：外测度对一般集合未必可加，这是整个测度论要解决的根本矛盾。** 若 $E,F$ 不相交，$m^*(E\cup F)\le m^*(E)+m^*(F)$ 恒成立；反向不等式需要「$E\cup F$ 的覆盖能拆成对 $E,F$ 分别有效的覆盖」，这要求 $E,F$ 被罩住时不会互相「蹭到」对方的结构。什么样的集合保证这点？下一节的可测性条件正是为此而生。<span class="marginnote">外测度不满足可数可加的具体反例依赖<strong>选择公理</strong>（Vitali 集，本主题第八节）。在没有不可测集公理系统里，外测度恰好是可加的——所以「外测度可加」其实与「不存在不可测集」等价，这解释了为什么我们必须认真对待不可测集。</span>

## 4 公式解析：次可加性证明里的 $\varepsilon/2^k$ 分配

次可加性是外测度最常用的不等式，它的证明结构值得逐行拆解：

$$m^*\left(\bigcup_k E_k\right)\le\sum_{k,j}|I_{k,j}|\le\sum_k m^*(E_k)+\varepsilon$$

- **第一步，读「对每个 $E_k$ 挑覆盖」**：由外测度的定义，对任意 $\delta_k>0$，存在覆盖 $\{I_{k,j}\}_j$ 使 $\sum_j|I_{k,j}|<m^*(E_k)+\delta_k$。**「下确界」意味着总能逼近到任意误差**——这是定义被写成 $\inf$ 的全部用意。
- **第二步，读「误差分配 $\delta_k=\varepsilon/2^k$」**：取 $\delta_k=\tfrac{\varepsilon}{2^k}$。所有误差之和 $\sum_k\tfrac{\varepsilon}{2^k}=\varepsilon$ 可控。**每步分一点点，无限步加起来仍然有限**——等比级数让无穷次「几乎覆盖」的总误差不爆炸。
- **第三步，读「整体覆盖」**：$\{I_{k,j}\}$ 作为全体覆盖了 $\bigcup_k E_k$，所以 $m^*(\bigcup_k E_k)$ 小于等于它的总长（定义中的下确界 ≤ 任一具体覆盖的代价）。这给出第一条不等号；第二条由第一步的逐项控制。令 $\varepsilon\to0$ 得结论。

**这条「$\varepsilon/2^k$」的证明模式**，在可数可加性、Egorov 定理、控制收敛定理中会反复出现——先逐项逼近到误差 $\varepsilon/2^k$，再让总误差归零。它是「可数步骤」能保住不等式的秘密。

## 5 数值演练与术语速查

**算例一（可数集外测度为零）**：$\mathbb{Q}=\{q_1,q_2,\dots\}$。用 $I_k=(q_k-\tfrac{\varepsilon}{2^{k+1}},q_k+\tfrac{\varepsilon}{2^{k+1}})$ 罩第 $k$ 个有理点，总长 $\sum_k\tfrac{\varepsilon}{2^k}=\varepsilon$——$m^*(\mathbb{Q})=0$。**可数集零测：用「$\varepsilon/2^k$ 分配」把总罩价压到任意小。**

**算例二（Cantor 集的构造性估计）**：第三篇的 Cantor 集 $C$ 由每次去掉中段三分之一的步骤构造，第 $n$ 步留下 $2^n$ 段、每段长 $3^{-n}$，总长 $(\tfrac23)^n\to0$——$m^*(C)\le\inf_n(\tfrac23)^n=0$。**「自相似分形」被开区间罩到零测。**

**对照表：外测度的性质清单**

| 性质 | 陈述 | 证明核心 |
| --- | --- | --- |
| 单调性 | $E\subset F\Rightarrow m^*(E)\le m^*(F)$ | 覆盖传递 |
| 次可加性 | $m^*(\bigcup E_k)\le\sum m^*(E_k)$ | $\varepsilon/2^k$ 分配 |
| 正则性 | $m^*=\inf\{m^*(G):G\ \text{开}\supset E\}$ | 开区间并是开集 |
| 平移不变 | $m^*(E+a)=m^*(E)$ | 覆盖平移 |
| 区间吻合 | $m^*([a,b])=b-a$ | 连通性论证 |

**术语速查**

| 记号 | 含义 |
| --- | --- |
| $m^*(E)$ | 外测度 |
| 覆盖 | 开区间族罩住 $E$ |
| 下确界 | 最便宜的罩价 |
| Carathéodory 条件 | 可测性判据（下节） |

**辨析｜易错点：外测度「处处有定义」但「不保证有限」；$m^*(E)=+\infty$ 是合法值。** $\mathbb{R}$ 本身的外测度为 $+\infty$（任何覆盖总长发散）。许多论证（如次可加性）默认「各 $m^*(E_k)$ 有限」，无穷情形需用截断或直接接受等式两边同无穷。

### 三步看懂「$\varepsilon/2^k$ 分配」

- **逐项逼近**：对每个 $E_k$ 找覆盖使 $\sum|I_{k,j}|<m^*(E_k)+\varepsilon/2^k$。
- **求和**：$\sum_k(m^*(E_k)+\varepsilon/2^k)=\sum_km^*(E_k)+\varepsilon$。
- **归零**：令 $\varepsilon\to0$，得 $m^*(\bigcup E_k)\le\sum_km^*(E_k)$。

**延伸（与不可测集的连接）**：外测度「次可加但不可加」的根本矛盾，在第八节 Vitali 集处爆发——用选择公理构造两个不相交集合 $V$、$V+q$ 使外测度不可加。**「挑出可测集」是化解这一矛盾的唯一出路**，下节 Carathéodory 条件正是那把筛子。

**一道收束练习**：证明 $m^*$ 对「有限并」也满足次可加且可加性对「相距正距离」的紧集成立——这预告了「可测集逼近」论证的基础。

## 6 小结

- **外测度**：$m^*(E)=\inf\{\sum|I_k|:E\subset\bigcup I_k,\ I_k\ \text{开区间}\}$，对任何集合有定义。
- **基本性质**：单调、次可加（$\varepsilon/2^k$ 技巧）、正则（开集外逼近）、平移不变、区间长度吻合。
- **根本缺陷**：次可加性只是「≤」，对一般集合不一定可加——需要筛选「好集合」。
- **思想转向**：从「量集合」转为「挑集合」——可测集的 Carathéodory 条件将修复可加性。
- **数值**：$\mathbb{Q}$ 与 Cantor 集外测度皆 $0$——可数/分形结构被罩到零测。
- **警报**：$m^*(E)=+\infty$ 合法；不可加性在 Vitali 集处爆发。

在下一节，我们专门研究**有界集外测度的等价刻画**：外测度与「开集外逼近、闭集内逼近」如何互相转化，为可测集的逼近定理铺平道路。
