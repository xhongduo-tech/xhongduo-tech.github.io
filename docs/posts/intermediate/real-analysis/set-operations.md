## 为什么从集合运算开始

第一级《集合的概念》里，我们把「解不等式 $x^2>1$」写成了解集 $(-\infty,-1)\cup(1,+\infty)$——一个「>」把实数轴剪成两段，再用并号 $\cup$ 拼回一个集合。当时我们说，**「把解集拆成互不相交的块的并集」这个操作将贯穿数学**。现在到了实变函数与测度论，这门课要研究的对象是「什么样的集合可以被度量、可以被积分」，集合运算就不再是直觉上的拼拼剪剪，而是需要被当作一套**精确的代数语言**来使用。

本节要做的三件事：把并、交、差、补、对称差五种运算**用集合定义严格化**；证明贯穿全课的**德摩根（De Morgan）对偶律**——它让「整体取补」能落到「每个局部取补」，是后面处理可测集补集、开集与闭集对偶的关键杠杆；并引入**集合列的上下极限**，体会「有限个集合的运算」如何升级为「无穷多个集合的极限」——这一步是从「中学集合」走向「分析学」的真正门槛。

## 1 集合的运算：并、交、差、补与对称差

约定：下面所有集合都视为某个**全集（universal set）** $X$ 的子集。全集视上下文而定——研究实数时取 $X=\mathbb{R}$，研究平面点集时取 $X=\mathbb{R}^2$。

**并集（union）**：由至少属于 $A$、$B$ 之一的元素组成的集合，记作 $A\cup B$：

$$A\cup B = \{x \in X \mid x\in A \ \text{或}\ \ x\in B\}$$

**交集（intersection）**：由同时属于 $A$、$B$ 的元素组成的集合，记作 $A\cap B$：

$$A\cap B = \{x \in X \mid x\in A \ \text{且}\ \ x\in B\}$$

**差集（difference）**：属于 $A$ 但不属于 $B$ 的元素组成的集合，记作 $A\setminus B$：

$$A\setminus B = \{x \in X \mid x\in A \ \text{且}\ \ x\notin B\}$$

**补集（complement）**：全集 $X$ 中不属于 $A$ 的元素组成的集合，记作 $A^c$（周民强书中亦记作 $C_XA$ 或 $CA$）：

$$A^c = X\setminus A = \{x\in X \mid x\notin A\}$$

注意，**补集永远相对于某个全集而言**，离开全集谈补集没有意义；而差集 $A\setminus B$ 不需要全集就能定义。<span class="marginnote">差集也叫「相对补集」：$A\setminus B$ 是 $B$ 相对于 $A$ 的补，$A^c$ 是 $A$ 相对于全集的补。实变函数里符号 $A^c$ 几乎总是指「对当下讨论的全集取补」，读者须时刻记住全集是谁。</span>

**对称差（symmetric difference）**：恰好属于 $A$、$B$ 之一（属于但不共同属于）的元素，记作 $A\,\triangle\,B$：

$$A\triangle B = (A\setminus B)\cup(B\setminus A) = (A\cup B)\setminus(A\cap B)$$

四个概念一图看懂（文氏图）：

![文氏图：并、交、差、补四种基本运算](/images/real-analysis/set-operations-1.svg)

这里有两个立即要用的**基本换算**，实变函数中反复出现：

$$A\setminus B = A\cap B^c, \qquad (A\cup B)^c = A^c\cap B^c$$

第二式正是德摩根律（第 3 节详述）。第一式把「差」翻译成「交与补」——**只要有了补与交，差就不是新概念**。对称差的两个公式同理：它既可以用「两个差再并」，也可以用「并减去交」。

**重点：** 集合运算的真正用途是把「日常语言的判断」翻译成「集合的符号」。一个元素 $x$ 属于 $A\cup B$，就是「$x$ 满足条件 $A$ 或条件 $B$」；属于 $A^c$，就是「$x$ 不满足条件 $A$」。「或、且、非」这三个逻辑连词，与「并、交、补」这三个集合运算一一对应——这是第 3 节德摩根律能被「逐点证明」的根本原因。

## 2 运算律：交换、结合与分配

像数系有运算律一样，集合运算也有一套代数律。以下 $A,B,C$ 均为 $X$ 的子集。

**交换律**：$A\cup B = B\cup A$，$A\cap B = B\cap A$。

**结合律**：$(A\cup B)\cup C = A\cup(B\cup C)$，$(A\cap B)\cap C = A\cap(B\cap C)$。结合律保证我们可以无歧义地写 $A\cup B\cup C$。

**分配律**：并、交互相分配：

$$A\cap(B\cup C) = (A\cap B)\cup(A\cap C)$$

$$A\cup(B\cap C) = (A\cup B)\cap(A\cup C)$$

**辨析｜易错点：** 第一条像「乘法对加法分配」，直觉上容易接受；第二条「并对交分配」初看很不自然，但它与数系里「$a+bc$ 拆不成 $(a+b)(a+c)$」并不矛盾——因为集合的并、交是**同一套符号体系里的两种运算**，它们互为镜像（见第 3 节对偶原理）。证明可逐点验证：$x$ 属于左端当且仅当「$x\in A$ 或 $x$ 同时属于 $B,C$」，恰等于右端。

还有一组常被用到的「空集与全集」律：

$$A\cup\emptyset = A, \quad A\cap\emptyset = \emptyset, \quad A\cup X = X, \quad A\cap X = A$$

以及**幂等律** $A\cup A = A$、$A\cap A = A$——注意集合没有「$2A$」这种倍乘，重复取并、交不会产生新元素。<span class="marginnote">幂等律让集合代数区别于通常的数代数：$a+a=2a$，而 $A\cup A=A$。这套「幂等」结构在抽象代数里叫「布尔代数」（boolean algebra），命题逻辑、电路开关、搜索标签系统都是它的实例。</span>

## 3 对偶律：德摩根律

**德摩根律（De Morgan's laws）**，又称**对偶律**，给出「取补」与「取并、取交」之间的互换：

$$(A\cup B)^c = A^c\cap B^c, \qquad (A\cap B)^c = A^c\cup B^c$$

对任意多个集合——甚至任意指标集 $\Lambda$ 的一族集合 $\{A_\lambda\}_{\lambda\in\Lambda}$——同样成立：

$$\left(\bigcup_{\lambda\in\Lambda} A_\lambda\right)^{c} = \bigcap_{\lambda\in\Lambda} A_\lambda^{c}, \qquad
\left(\bigcap_{\lambda\in\Lambda} A_\lambda\right)^{c} = \bigcup_{\lambda\in\Lambda} A_\lambda^{c}$$

**对偶原理（duality principle）**：在任何一个只涉及并、交、补的恒等式中，把 $\cup$ 与 $\cap$ 互换、$\emptyset$ 与 $X$ 互换、$A$ 与 $A^c$ 互换，得到的仍是恒等式。德摩根律正是「补」与「并、交」互换的基本规则，是整套对偶变换的引擎。<span class="marginnote">对偶原理在实变函数中最典型的应用是「开集与闭集的对偶」：开集取补是闭集，闭集取补是开集；Borel 集类（$\sigma$-代数）对补运算封闭，靠的也是这一条。</span>

直觉：**「整体取补」等于「把每个局部取补，再把并变成交（或交变成并）」**——一个元素不在「并集」里，意味着它不属于任何一个成员，也就是它属于每一个成员的补集。

## 4 公式解析：德摩根律的逐点推理链

现在把第一条德摩根律 $(A\cup B)^c = A^c\cap B^c$ 拆成一串「逐点推理」。这是分析学证明的模板——**证明两个集合相等，最常用的方法是逐点验证互为子集**；而对「元素属于集合」的判断，最终都落到逻辑词「或 / 且 / 非」上。

**第一步：把左端翻译成元素判断。** 对任意 $x\in X$：

$$x\in(A\cup B)^c \iff x\notin A\cup B$$

**第二步：对「或」取否定。** 「$x$ 不属于 $A\cup B$」的意思是「$x$ 不属于 $A$ 且 $x$ 不属于 $B$」——**对「或」取否定，要变成「且」**：

$$x\notin A\cup B \iff (x\notin A) \wedge (x\notin B)$$

**第三步：翻译回集合语言。** 「$x\notin A$」即 $x\in A^c$，「$x\notin B$」即 $x\in B^c$，两者同时成立即 $x\in A^c\cap B^c$：

$$(x\notin A)\wedge(x\notin B) \iff x\in A^c\cap B^c$$

**第四步：串成等价链，得到结论。** 把三环相连：

$$x\in(A\cup B)^c \iff x\notin A\cup B \iff (x\notin A)\wedge(x\notin B) \iff x\in A^c\cap B^c$$

每一步都是 $\iff$，说明两集合的元素完全重合，故 $(A\cup B)^c = A^c\cap B^c$。第二条 $(A\cap B)^c = A^c\cup B^c$ 同理，唯一改动是把第二步换成「对『且』取否定，要变成『或』」——这正对应逻辑学中的德摩根律「$\neg(P\vee Q)\iff\neg P\wedge\neg Q$」与「$\neg(P\wedge Q)\iff\neg P\vee\neg Q$」。<span class="marginnote">逻辑学中的德摩根律与集合的德摩根律是同一件事：布尔代数 $\{0,1\}$ 里的「与/或/非」，正是集合「交/并/补」的二元素特例。康托尔的集合论让逻辑推理有了图形化的对象，希尔伯特所说的「乐园」正在于此。</span>

## 5 集合列的上下极限：lim sup 与 lim inf 引子

单论有限个集合，并、交、补已够用。但实变函数要处理的是**无穷多个集合**。设 $A_1, A_2, \dots$ 是一列集合（简称**集合列**），我们常关心两类问题：

- **「哪些元素出现在无穷多个 $A_n$ 里？」**——比如「$x_n$ 有无穷多项落在集合 $A_n$ 里」；
- **「哪些元素除有限个 $A_n$ 外全都出现？」**——比如「从某项起 $x_n$ 永远落在 $A_n$ 里」。

这两个集合分别叫集合列的**上极限**与**下极限**，记作：

$$\varlimsup_{n\to\infty} A_n = \bigcap_{n=1}^{\infty}\bigcup_{k=n}^{\infty} A_k, \qquad
\varliminf_{n\to\infty} A_n = \bigcup_{n=1}^{\infty}\bigcap_{k=n}^{\infty} A_k$$

直观上：**上极限** $=\bigcap_n$「从第 $n$ 项起的并」，即「无论从哪一项往后看，元素都还会出现」——恰是「出现无穷多次」；**下极限** $=\bigcup_n$「从第 $n$ 项起的交」，即「从某一项开始以后每个集合都有它」——恰是「最终一直在」。显然 $\varliminf A_n \subseteq \varlimsup A_n$；二者相等时，称该公共集合为集合列的**极限**。<span class="marginnote">上、下极限集的出现，标志着「集合论」升级为「分析学」：有限个集合的运算只能回答「是否」，而上下极限引入了「无穷 + 极限」的问答方式，与数列的上、下极限在精神上一脉相承，下一节我们专门展开。</span>

举一个直观的例子：设 $A_n=[0,\,1+(-1)^{n+1}]$，即 $A_1=[0,2], A_2=[0,0], A_3=[0,2], \dots$。那么「属于无穷多个 $A_n$」的集合是什么？「最终一直在」的集合又是什么？两个答案并不同——这正是下一节要精确求解的问题。这里只需记住：**一旦涉及无穷多个集合，单靠有限运算不再够，必须引入极限。**

## 6 为什么实变函数需要更精细的集合语言

「从极限到大模型」这条主线里，本专题的位置是把「极限」从数列推广到函数、再推广到「集合」。为什么中学数学的集合语言不够用？三个理由。

**第一，黎曼积分有一个「看不见」的障碍。** 黎曼积分的定义依赖「分割区间、取黎曼和」，它对函数的连续性要求太高：即使函数只在很少的点上出问题，黎曼积分也可能失效。要刻画「很少的点」，就得先回答「一个集合『多小』才算小」——这正是测度论的问题，而测度论的第一步就是把「长度、面积」这些直觉概念翻译成集合语言。

**第二，几乎处处（almost everywhere）本质上是一个集合论概念。** 实变函数里「函数 $f$ 与 $g$ 几乎处处相等」的意思是「使 $f(x)\neq g(x)$ 的 $x$ 构成的集合是零测集」。要表达「除了一个很小的集合以外」，就必须能精确地构造、比较、运算这些「例外集」——德摩根律在这里负责把「例外集的补」与「补集的例外」来回翻译。

**第三，可测结构是一族集合。** 现代概率论与统计学习——大模型训练里的一切「期望」「损失函数」都建立在概率空间之上，而概率空间就是一个「带测度的集合」。刻画「哪些集合可以赋予概率」需要 $\sigma$-代数：一族对可数并、可数交、取补都封闭的集合。**可数并、可数交**（而非有限并、有限交）之所以必须，正是第 5 节上下极限与后面测度可数可加性的需要。

一句话：**实变函数把「集合」从静态的分类工具，改造成动态的、可以取极限、可以测量大小的分析对象。** 本节学的五种运算与德摩根律，是这套语言的语法基础。

## 7 小结

- **五种基本运算**：并 $A\cup B$、交 $A\cap B$、差 $A\setminus B$、补 $A^c$（相对全集 $X$）、对称差 $A\triangle B$；差与对称差都能用「交、补」表示。
- **运算律**：交换律、结合律、分配律、幂等律；并、交互相分配，构成**布尔代数**。
- **德摩根律**：$(A\cup B)^c=A^c\cap B^c$、$(A\cap B)^c=A^c\cup B^c$，可推广到任意指标集；逐点推理链是「两集合相等」的标准证法。
- **对偶原理**：把 $\cup$ 与 $\cap$、$\emptyset$ 与 $X$ 互换，恒等式仍成立——这是开集闭集对偶与 $\sigma$-代数取补封闭的伏笔。
- **集合列上下极限**：上极限「出现无穷多次」、下极限「最终一直在」；涉及无穷个集合时必须引入极限语言。

在下一节，我们将正式研究**集合列的极限**：上限集与下限集的定义、性质，以及它们如何为测度论中的可数可加性铺路。本节只是一个引子——真正的分析学大门，从那里打开。
