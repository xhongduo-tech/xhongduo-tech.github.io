# 实变函数与测度论

实变函数论是数学分析的深化：以集合论与测度论为工具，重建积分理论（Lebesgue 积分），并研究函数的可测性、可积性与微分结构。本篇对标周民强《实变函数论》与那汤松《实变函数论》的章节体系，从集合与基数讲起，经测度、可测函数、Lebesgue 积分，直至微分与不定积分、L^p 空间。
