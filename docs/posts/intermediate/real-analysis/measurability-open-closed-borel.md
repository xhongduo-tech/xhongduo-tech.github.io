# 开集、闭集与 Borel 集的可测性

## 为什么从开集、闭集与 Borel 集的可测性开始

上一节建立了 $\sigma$-代数 $\mathcal{M}$，但它还是抽象的：里面到底有哪些集合？本节回答这个名单问题：**开集可测、闭集可测、从而一切 Borel 集可测**。这等于宣告：你在分析中遇到的所有「正常」集合——区间、开集、闭集、$F_\sigma$、$G_\delta$——全都是可测的。

这个结论的意义是双重的。**理论上**，它把测度论与拓扑学的鸿沟填平：Borel 集类 $\mathcal{B}\subset\mathcal{M}$，且 $\mathcal{M}$ 是包含 $\mathcal{B}$ 的最小 σ-代数吗？不——$\mathcal{M}$ 比 $\mathcal{B}$ 大（多了零测集的余集，Vitali 集除外）。**实践上**，它保证「测度」与「长度」在常见集合上完全一致，让我们可以放心地把 $m((a,b))=b-a$ 推广到任意可测集。<span class="marginnote">$\mathcal{B}\subsetneq\mathcal{M}$ 的严格不等是关键：$\mathcal{M}$ 是 $\mathcal{B}$ 的<strong>完备化</strong>——把每个 Borel 集的零测子集也收进来。事实上 $\mathcal{M}$ 恰由「Borel 集 $\cup$ 零测集的子集」组成（$\mathcal{M}=\{B\cup N:B\in\mathcal{B},\ m^*(N)=0\}$），这是 Lebesgue 测度完备性的完全刻画。</span>

## 1 开集可测

**定理（开集可测）**：$\mathbb{R}^n$ 中的每个开集 $G$ 都是 Lebesgue 可测集。

证明（利用直线开集构造定理与可数可加性）：先处理 $n=1$ 的情形。由构造定理，$G=\bigcup_{k}(a_k,b_k)$ 是至多可数个互不相交开区间的并。每个开区间 $(a_k,b_k)$ 都可测（验证：$(a_k,b_k)$ 与任何 $T$ 切割无损耗，或用「开区间是 $G_\delta$ 与闭区间的差」的初等证法）。再由 σ-代数可数并封闭，$G$ 可测。

对于 $n>1$：$\mathbb{R}^n$ 的开集 $G$ 可以写成可数个开长方体的并（以有理点为顶点的可数族），而开长方体是开区间的笛卡尔积，每个可测，可数并仍可测。<span class="marginnote">「开长方体 = 一维开区间的乘积」与「可数并」两步，把 $n$ 维问题归约到一维。这里已预告了<strong>乘积测度</strong>：$n$ 维 Lebesgue 测度是一维测度的乘积，后面《乘积空间的测度》一节会严格化。</span>

**重点：开集可测的实质是「开区间可测 + σ-代数封闭」。** 开区间是最简单的可测元，构造定理保证开集是它们的可数并，可数并封闭性完成其余。**一旦开集可测，闭集（补集）、$F_\sigma$（可数并）、$G_\delta$（可数交）全部自动可测**——σ-代数的封闭性把「种子」长成「森林」。

## 2 Borel 集可测

**定理（Borel 集可测）**：$\mathcal{B}\subset\mathcal{M}$——每个 Borel 集都是 Lebesgue 可测集。

证明（最小性论证）：$\mathcal{B}$ 是「包含开集的最小 σ-代数」。而 $\mathcal{M}$ 本身是一个包含开集的 σ-代数（开集可测 + σ-代数封闭）。由 $\mathcal{B}$ 的最小性，$\mathcal{B}\subset\mathcal{M}$。

**辨析｜易错点：$\mathcal{M}$ 与 $\mathcal{B}$ 不相等。** $\mathcal{M}$ 比 $\mathcal{B}$ 大。原因：$\mathcal{M}$ 是「完备的」（零测集的子集也可测，见上节判据二），而 $\mathcal{B}$ 不完备——Borel 集的零测子集未必是 Borel 集（例如康托尔集的某个子集）。**直观上：$\mathcal{M}=\mathcal{B}\oplus$（零测集的子集）。** 在概率论里，这个差距被称为「完备化」，而 $\sigma(\mathcal{B})=\mathcal{M}$ 在「相差零测集」的意义下成立。<span class="marginnote">「Borel 集可测」正是概率论里「随机变量可测性」的基石：随机变量 $X:\Omega\to\mathbb{R}$ 要求 $\{X\le t\}$ 是 Borel 可测的。<strong>可测性 = 能回答「$X$ 落在某区间里吗」的一切问题</strong>，这就是现代概率论放弃「可测性定义在具体空间」、改用「Borel σ-代数」的原因。</span>

## 3 测度与长度的衔接：常见集合的测度

现在可以结算前面积累的「账单」：

**定理（常见集合的测度）**：

- 区间：$m([a,b])=m((a,b))=m([a,b))=b-a$；
- 单点：$m(\{x\})=0$；可数集：$m(\mathbb{Q})=0$；
- 康托尔集：$m(C)=0$（前节已算）；
- 闭区间套、开区间并：由可数可加性拼接。

**「测度 = 长度的推广」至此完成：** 在一切 Borel 集上，Lebesgue 测度与「长度/面积/体积」的朴素概念一致；它的额外能力在于可以度量康托尔集、可测函数的下方图形这类「黎曼长度」束手无策的对象。

**重点：Lebesgue 测度是「长度的可数可加扩张」**——从区间出发，用 σ-代数封闭性扩展到 Borel 集，再完备化到可测集。这条扩张路径是测度论的标准蓝本（Carathéodory 扩张定理），也是抽象测度论的基本定理。

## 4 公式解析：开集可测的归约链

把「开集可测」的证明浓缩成一条归约链：

$$G\ \text{开}\ \xrightarrow{①}\ G=\bigcup_k(a_k,b_k)\ \xrightarrow{②}\ (a_k,b_k)\ \text{可测}\ \xrightarrow{③}\ G\in\mathcal{M}$$

- **第一步，读归约 ①**：用直线上开集的构造定理，把开集 $G$ 写成可数个互不相交开区间的并。**这一步把「任意开集」降维成「开区间」**——拓扑结构消解为区间。
- **第二步，读归约 ②**：单个开区间 $(a,b)$ 可测。验证只需一句：对任意 $T$，$m^*(T\cap(a,b))+m^*(T\setminus(a,b))=m^*(T)$ 对区间显然成立（切割无模糊边界），或写 $(a,b)=\bigcap_k[a+\tfrac1k,b-\tfrac1k]\cup$（端点处理），用闭集可测证。**「区间」是测度的原子**，它可测是全部论证的地基。
- **第三步，读归约 ③**：σ-代数的可数并封闭性。**「种子可测 + 代数封闭 = 森林可测」**——这是最小性的力量：不必逐集验证，只需验证生成元。

**这条归约链的价值在于可复用**：任何「由开集生成」的结构（Borel 集、可测函数、Luzin 逼近）都自动继承开集的可测性，只要对应的运算在 σ-代数内封闭。

## 5 小结

- **开集可测**：开区间可测 + 构造定理 + 可数并封闭。
- **闭集、$F_\sigma$、$G_\delta$ 可测**：σ-代数的补集、可数并、可数交封闭自动给出。
- **Borel 集可测**：$\mathcal{B}$ 是含开集的最小 σ-代数，故 $\mathcal{B}\subset\mathcal{M}$。
- **$\mathcal{M}$ 是 $\mathcal{B}$ 的完备化**：$\mathcal{M}=\{B\cup N:B\in\mathcal{B},m^*(N)=0\}$，$\mathcal{B}\subsetneq\mathcal{M}$。
- **测度 = 长度的可数可加扩张**：在一切 Borel 集上与「长度」一致，且能度量更奇特的集合。

在下一节，我们研究测度自身的分析性质——**可数可加性与连续性**：测度关于集合列极限（递增并、递减交）如何表现，这是所有极限定理的测度论引擎。
