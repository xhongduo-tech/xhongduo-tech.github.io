## 为什么从 Lᵖ 中的稠密性开始

$L^p$ 空间里都是「野」函数（可测但可能处处不连续）。但**稠密性定理**说：那些「好」函数——简单函数、阶梯函数、连续函数、$C^\infty$ 函数——在 $L^p$ 中稠密。即：任意 $f\in L^p$ 都能被简单函数/连续函数在 $L^p$ 范数下任意逼近。这等于宣告：**「好的近似」无处不在，研究 $L^p$ 只需先研究好函数再取极限。**

稠密性是逼近论与数值分析的合法性来源：Fourier 级数、多项式逼近、有限元方法都靠「好函数稠密」来保证「逼近能任意精确」。它也把 Luzin/Egorov 的「测度逼近」升级为「范数逼近」——这是从「点集论」到「函数空间论」的彻底转换。<span class="marginnote">稠密性的核心推论是「<strong>先证性质对好函数成立，再由稠密 + 连续性延拓到全体 $L^p$</strong>」——这是泛函分析的「稠密性延拓」原则。Fourier 变换、卷积算子、线性泛函的构造都靠这条原则：在简单函数上定义，证明连续（有界），再由稠密唯一延拓。</span>

## 1 简单函数稠密

**定理（简单函数稠密）**：设 $1\le p<\infty$，$f\in L^p$。则对任意 $\varepsilon>0$，存在简单函数 $\varphi$，使

$$\|f-\varphi\|_p<\varepsilon$$

**证明**：对 $f$ 的正部 $f^+$ 与负部 $f^-$ 分别处理（线性）。$f^+\ge0$，由逼近定理存在简单函数列 $\varphi_k\uparrow f^+$（逐点）。由控制收敛（$|f^+-\varphi_k|^p\le(f^+)^p\in L^1$）：

$$\|f^+-\varphi_k\|_p^p=\int|f^+-\varphi_k|^p\to0$$

对 $f^-$ 同理，合并得 $\varphi$。**「逐点逼近 + 控制收敛」把点态逼近升级为范数逼近**。<span class="marginnote">证明的关键是「控制收敛替换 Lebesgue 定理」：<strong>逐点收敛只给「点态接近」，$L^p$ 范数需要「积分接近」——两者由 DCT 缝合</strong>。这里控制函数 $(f^+)^p\in L^1$ 恰好存在，因为 $f\in L^p$。</span>

**重点：简单函数稠密是「先立地基」**——它把 $L^p$ 的研究归约为「简单函数 + 极限」。简单函数的范数 $\|\varphi\|_p=(\sum a_i^p m(E_i))^{1/p}$ 可显式计算，一切都能落地。

## 2 连续函数稠密

**定理（连续函数稠密）**：设 $1\le p<\infty$，$E\subset\mathbb{R}^n$ 可测，$m(E)<\infty$。则对任意 $f\in L^p(E)$ 与 $\varepsilon>0$，存在连续函数 $g$（可在 $\mathbb{R}^n$ 上有紧支集），使

$$\|f-g\|_{L^p(E)}<\varepsilon$$

**证明**（三层逼近）：

- **第一步，简单函数逼近**：由简单函数稠密，$f\approx\varphi=\sum_ia_i\chi_{E_i}$（$L^p$ 误差 $\varepsilon/3$）。
- **第二步，指示函数用连续逼近**：对每个 $E_i$，由 Luzin 定理（或外正则性），存在连续 $g_i$ 使 $m(\{x\in E_i:\chi_{E_i}\neq g_i(x)\})<\delta$（误差小），且 $0\le g_i\le1$。于是 $\|\chi_{E_i}-g_i\|_p\le(\text{差集测度})^{1/p}$ 小。
- **第三步，线性组合**：$g=\sum_ia_ig_i$ 连续，$\|\varphi-g\|_p\le\sum|a_i|\|\chi_{E_i}-g_i\|_p$（Minkowski），误差 $\varepsilon/3$。三合一：$\|f-g\|_p<\varepsilon$。<span class="marginnote">「简单 → 指示 → 连续」三层逼近是标准链条：<strong>简单函数差在「台阶系数」，指示函数差在「台阶底是否被连续函数贴合」</strong>。Luzin 定理负责「指示函数 ≈ 连续函数（测度误差）」，再借 $L^p$ 范数的「测度控制」升级为范数逼近。</span>

**推论（$C_c$ 稠密）**：紧支连续函数 $C_c(\mathbb{R}^n)$ 在 $L^p(\mathbb{R}^n)$ 中稠密（用截断 + 本定理）。

## 3 稠密性的推论

**推论一（$C^\infty$ 稠密）**：$C_c^\infty$（光滑紧支函数）在 $L^p$ 中稠密（连续函数用磨光近似）。**「任意 $L^p$ 函数可由光滑函数逼近」**——数值分析、PDE 弱解理论的基石。

**推论二（逼近延拓原则）**：若线性算子 $T$ 在简单函数（或连续函数）上有界（$\|T\varphi\|_p\le C\|\varphi\|_p$），则由稠密性可唯一延拓到 $L^p$。**「在稠密子集上定义 + 连续 ⇒ 全局定义」**——Fourier 变换、卷积、积分算子的标准构造法。

**推论三（$L^p$ 的可分性雏形）**：$L^p(\mathbb{R}^n)$（$p<\infty$）是可分空间（存在可数稠密子集）——由「简单函数（系数有理数 + 底集为有理区间）可数」+ 稠密性推出。可分性是泛函分析的常用性质。

**辨析｜易错点：稠密性的证明中「逐点逼近」必须升级为「范数逼近」，不能想当然。** 简单函数 $\varphi_k\uparrow f$ 逐点，但 $\|f-\varphi_k\|_p\to0$ 需要 DCT（控制函数 $(f)^p$）。**「逐点稠密」与「范数稠密」是两回事**——稠密性定理的内容是后者，证明必须用控制收敛。

## 4 公式解析：三层逼近的误差预算

连续函数稠密证明的误差分配是标准「$\varepsilon/3$」技巧：

$$\|f-g\|_p\le\|f-\varphi\|_p+\|\varphi-g\|_p\le\frac{\varepsilon}{3}+\sum_i|a_i|\|\chi_{E_i}-g_i\|_p<\varepsilon$$

- **第一步，读「$f\approx\varphi$」**：简单函数稠密给出第一层误差 $\varepsilon/3$（先花掉一部分预算）。
- **第二步，读「$\chi_{E_i}\approx g_i$」**：Luzin 给出 $m(\{\chi_{E_i}\neq g_i\})<\delta_i$，$\|\chi_{E_i}-g_i\|_p\le\delta_i^{1/p}$。**「测度误差」通过「$L^p$ 范数 ≤ 差集测度^{1/p}」转成范数误差**——这里 $0\le\chi,g_i\le1$ 保证「差 ≤ 1」。
- **第三步，读「误差汇总」**：$\sum_i|a_i|\delta_i^{1/p}$ 取 $\delta_i$ 小，$<\varepsilon/3$。**总误差 $<\varepsilon/3+\varepsilon/3+\varepsilon/3$**——三份预算各司其职。

**「$\varepsilon/3$ 分账 + 测度转范数」**，是三层逼近的标准预算表——它把「近似链条」变成「误差控制」。

## 6 数值演练与稠密性速查

**算例一（$L^1$ 中的连续逼近数值）**：$f=\chi_{[0,\tfrac12]}$ 于 $[0,1]$。用斜坡函数 $g_\delta$：$[0,\tfrac12-\delta]$ 取 1、$[\tfrac12+\delta,1]$ 取 0、中间线性过渡。$\|f-g_\delta\|_1=\int_{1/2-\delta}^{1/2+\delta}|f-g_\delta|\le2\delta$，取 $\delta<\varepsilon/2$ 即得范数逼近。**「台阶」被斜坡任意 $L^1$ 贴合——Luzin 定理在此的具体化。**

**算例二（$L^2$ 中的多项式逼近预览）**：$f=x^2$ 于 $[0,1]$ 本身是多项式；$f=|x-\tfrac12|$ 用 Bernstein 多项式 $B_n$ 一致逼近（Weierstrass），从而 $L^2$ 逼近——连续函数稠密再叠多项式稠密，$L^p$ 中处处有「代数好函数」。

**对照表：$L^p$ 中的稠密子集族**

| 稠密子集 | 条件 | 证明工具 |
| --- | --- | --- |
| 简单函数 | $p<\infty$ | 逼近定理 + DCT |
| 连续函数 | $p<\infty$，$m(E)<\infty$ | 简单 → 指示 → 连续 |
| $C_c$（紧支连续） | $p<\infty$，$E=\mathbb{R}^n$ | 截断 + 本定理 |
| $C_c^\infty$（光滑） | $p<\infty$ | 磨光 |
| 阶梯函数 | $p<\infty$ | 特例 |

**术语速查**

| 记号 | 含义 |
| --- | --- |
| $\|f-\varphi\|_p$ | $L^p$ 范数误差 |
| DCT | 控制收敛定理 |
| 磨光 | 卷积光滑化 |
| $\varepsilon/3$ 分账 | 三层误差预算 |

**辨析｜易错点：稠密性需要 $p<\infty$。** $L^\infty$ 中连续函数不一定稠密——本质上不可测的「本性有界函数」无法被连续函数一致逼近（如 $\chi_{\text{不可测集}}$ 在 $L^\infty$ 范数下与任何连续函数相差至少 1）。**「稠密」的适用范围是「可积」（$p<\infty$），$L^\infty$ 要另说。**

### 三步记住「简单 → 连续」的链条

- **简单函数**：先立地基（逐点逼近 + DCT 升级为范数）。
- **指示函数**：Luzin 把 $\chi_{E_i}$ 贴合到连续 $g_i$（测度误差小）。
- **线性组合**：$g=\sum a_ig_i$ 连续，Minkowski 汇总误差。

**延伸（与调和分析连接）**：$C_c^\infty$ 稠密是「分布论」的基础——测试函数空间 $C_c^\infty$ 在适当拓扑下稠密，广义函数正是其连续线性泛函。Fourier 变换在 $C_c^\infty$ 上定义后按稠密延拓到 $L^p$（Plancherel 定理），整座调和分析大厦都站在稠密性上。

**一道收束练习**：证明 $L^2$ 中多项式稠密（先连续函数稠密，再用 Weierstrass 定理对连续函数一致逼近、从而 $L^2$ 逼近）——它为下一节 $L^2$ 的正交展开（Fourier 级数）提供「基稠密」的保证。

## 7 小结

- **简单函数稠密**：$\|f-\varphi\|_p<\varepsilon$（逐点逼近 + DCT 升级）。
- **连续函数稠密**：$\|f-g\|_p<\varepsilon$（简单 → 指示 → 连续三层，Luzin 桥）。
- **$C^\infty$ 稠密**：磨光 + 连续稠密。
- **逼近延拓原则**：稠密子集上有界 ⇒ 全局唯一延拓——泛函分析构造法。
- **可分性**：$L^p$（$p<\infty$）可分，可数稠密子集存在。
- **边界**：$L^\infty$ 中连续函数不稠密——稠密性只对「可积」（$p<\infty$）成立。

**再读一遍「好函数稠密」的分量**：$L^p$ 里的「野」函数之所以可操作，正因为「规则」函数在它里面稠密——逼近论、数值法、Fourier 级数都由此获得合法性。稠密性是把「可测性」翻译成「可计算性」的桥梁。
