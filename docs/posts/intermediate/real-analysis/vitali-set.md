# 不可测集：Vitali 集的构造

## 为什么从不可测集开始

前七节证明了许多集合可测——开集、闭集、Borel 集、可测集的可数并与交。读者可能会问：**会不会所有集合都可测？** 如果那样，Carathéodory 条件岂不是多余的摆设？Vitali 在 1905 年回答：不是。他构造了一个**不可测集**，证明「可测性」是有实质内容的筛选，同时揭示出 Lebesgue 测度的边界。

Vitali 集的构造极其精妙又极其简单：把 $[0,1]$ 按有理数平移划分成等价类，用选择公理在每个等价类里挑一个代表。构造的唯一「奢侈品」是**选择公理**——这是数学中争论不休的公理。了解 Vitali 集，就是理解「测度论与集合论公理的关系」：**测度论的结论严重依赖于你接受多少选择公理**。<span class="marginnote">Vitali 集的不可测性证明是「<strong>矛盾三连</strong>」：假设 $V$ 可测 → 由平移不变性，所有平移 $V+r$ 测度相同 → 把 $[0,1]$ 拆成可数无穷个这种平移 → 由可数可加性推出测度既 ≤1 又 ≥1，且每个平移测度相同——于是 $m(V)$ 同时要满足「$+\infty$ 乘以 $0$ 等于 $1$」的不可能方程。矛盾。</span>

## 1 构造：等价类与选择公理

**构造（Vitali 集）**：在 $[0,1]$ 上定义等价关系：$x\sim y\iff x-y\in\mathbb{Q}$。这是一个等价关系（有理数对加、减封闭）。记等价类为 $[x]=\{x+r:r\in\mathbb{Q}\}\cap[0,1]$。

- **等价类的性质**：每个等价类是 $[0,1]$ 中「彼此差有理数」的点的集合；不同等价类不相交；等价类全体覆盖 $[0,1]$；每个等价类**至多可数**（因为与 $\mathbb{Q}$ 等势），而等价类的个数是**不可数**的（否则 $[0,1]$ 作为可数多个可数集的并就可数了，矛盾）。
- **选择公理**：设 $\Lambda$ 是所有等价类组成的集合。用选择公理，存在一个集合 $V$，恰好从每个等价类中取**一个**代表元素。$V$ 即 **Vitali 集**。

**重点：$V$ 的存在依赖选择公理。** 等价类不可数，无法显式列出代表；必须有公理保证「可以从每个袋子里挑一个苹果」。**这是 Lebesgue 测度论与公理集合论的第一次正面相遇**——不可测集的存在性，等价于某种选择公理。

## 2 不可测性的证明

**定理（Vitali）**：$V$ 不是 Lebesgue 可测集。

证明（反证，三幕）：

**第一幕，建立平移覆盖**：设 $\{r_k\}_{k=1}^{\infty}$ 是 $[-1,1]\cap\mathbb{Q}$ 的一个排列。考察平移族 $V_k=V+r_k=\{x+r_k:x\in V\}$。这些 $V_k$ 两两不相交：若 $x\in V_i\cap V_j$，则 $x=v_i+r_i=v_j+r_j$，$v_i-v_j=r_j-r_i\in\mathbb{Q}$，故 $v_i\sim v_j$；但 $V$ 每等价类只取一个代表，$v_i=v_j$，于是 $r_i=r_j$，矛盾。又它们都含于 $[-1,2]$（$V\subset[0,1]$，$r_k\in[-1,1]$）。

**第二幕，覆盖 $[0,1]$**：对任意 $x\in[0,1]$，$x$ 属于某个等价类，其代表 $v\in V$，且 $x-v\in\mathbb{Q}\cap[-1,1]$，故 $x=v+r_k$ 对某 $k$，即 $x\in V_k$。于是

$$[0,1]\subset\bigcup_{k=1}^{\infty}V_k\subset[-1,2]$$

**第三幕，测量矛盾**：假设 $V$ 可测，则由平移不变性 $m(V_k)=m(V)$ 对所有 $k$ 成立。对上面双重包含取测度（注意 $V_k$ 两两不相交）：

$$1=m([0,1])\le m\left(\bigcup_kV_k\right)=\sum_{k=1}^{\infty}m(V)\le m([-1,2])=3$$

中间的等式要求可数可加性——**这正是 Carathéodory 条件承诺给可测集的权利**。现在看 $m(V)$ 的值：若 $m(V)=0$，则 $\sum_k m(V)=0$，与左边 $1\le0$ 矛盾；若 $m(V)>0$，则 $\sum_km(V)=+\infty$，与右边 $\le3$ 矛盾。<span class="marginnote">第三幕的悖论本质：<strong>一个不可数族的「每块同大」且「每块非零」，其总和同时被要求等于 $1$（下界）与小于 $3$（上界）</strong>——唯有「可数无穷个非零数之和 $=+\infty$」与「可数无穷个零之和 $=0$」这两个极端，都不符合夹逼。这就是矛盾的全部。</span>

## 3 选择公理与不可测集：一座冰山

Vitali 的结论立刻引出更深的问题：**不可测集到底有多大？Lebesgue 测度能扩展到哪里？**

- **Solovay 定理（1970）**：如果放弃选择公理（只接受「可数依赖选择」），则存在一个 ZF 的模型，其中**实数的一切子集都可测**。Vitali 的不可测性证明在那里失效——因为构造 $V$ 需要选择公理。
- **对策（对偶命题）**：在 ZFC 中，不可测集不可避免。而且「存在不可测集」与「存在 Hamel 基」「存在非主超滤子」等命题**彼此等价**（在 ZF 中），它们是同一个「选择公理烙印」的不同面孔。
- **Lebesgue 测度的立场**：接受选择公理，接受不可测集存在，然后在可测集上建立全部理论。**可测性不是数学对象的内在属性，而是我们选择「可以测量哪些集合」的界线。**

**重点：不可测集不是「病态」，而是「测度论的边界标记」。** 它告诉我们：Lebesgue 测度不是全能的，它精确地作用于 σ-代数 $\mathcal{M}$；而 $\mathcal{M}$ 之外的世界，由选择公理填充。**知道边界在哪里，比假装没有边界更重要**——这正是 Vitali 集对这门学科的最大贡献。

## 4 公式解析：矛盾三幕的量化链

把 Vitali 证明浓缩成一条量化链，拆开每步：

$$[0,1]\ \subset\ \bigcup_{k=1}^{\infty}V_k\ \subset\ [-1,2],\qquad V_i\cap V_j=\varnothing\ (i\neq j)$$

$$\Longrightarrow\quad 1\le\sum_{k=1}^{\infty}m(V_k)\le3,\qquad m(V_k)=m(V)$$

- **第一步，读「双包含」的来源**：左包含「每点都在某个平移里」（等价类分解），右包含「$V\subset[0,1]$ 且 $r_k\in[-1,1]$」（平移不跑出 $[-1,2]$）。**集合论的构造决定了测度论的边界**——包含链给出测度夹逼。
- **第二步，读「$V_k$ 两两不相交」**：若平移重合则代表相同（等价类唯一性）。**「不相交」是把可数可加性从「≤」升级为「=」的钥匙**——若相交，只能得不等式，矛盾就不锋利了。
- **第三步，读「$m(V)$ 的二分」**：$m(V)=0$ 与 $m(V)>0$ 是仅有的两种可能，而两者都违反夹逼 $1\le\cdot\le3$。**「穷尽两种可能」是反证法的完全形态**——没有第三种可能留给 $m(V)$。

**这条链的教训**：可数可加性、平移不变性、等价类分解、选择公理，四者缺一不可。任何一个环节松动，矛盾就消失——这解释了为何「可测性」如此精确地依赖公理环境。

## 6 数值演练与公理速查

**算例一（等价类结构的数值感受）**：$[0,1]$ 按「$x-y\in\mathbb{Q}$」分等价类。$x=\tfrac12$ 与 $x=\tfrac13$ 同类（差 $\tfrac16\in\mathbb{Q}$）；$x=\tfrac12$ 与 $x=\tfrac{\sqrt2}{2}$ 不同类（差无理数）。每类至多可数（$[x]=x+\mathbb{Q}$），类的个数不可数（否则 $[0,1]$ 可数）。**「不可数多个可数袋」的分解，就是 Vitali 构造的原料。**

**算例二（为什么平移不能跑出 $[-1,2]$）**：$V\subset[0,1]$，$r_k\in\mathbb{Q}\cap[-1,1]$。$V+r_k\subset[0,1]+[-1,1]=[-1,2]$——右包含的测度上界是 $3$。若用 $r_k\in[-\tfrac12,\tfrac12]$ 则 $V_k\subset[-\tfrac12,\tfrac32]$，上界 $\tfrac32$——夹逼更紧，但矛盾的本质不变（$m(V)$ 仍必须同时满足「零与非零」两个不可能）。

**对照表：可测 / 不可测 / 零测**

| 集合 | 外测度 | 可测? | 说明 |
| --- | --- | --- | --- |
| $\mathbb{Q}$ | 0 | 是 | 可数零测 |
| Cantor 集 | 0 | 是 | 不可数零测 |
| Vitali 集 $V$ | ? | 否 | 外测度存在但不可测 |
| $[0,1]$ | 1 | 是 | 基本区间 |

**术语速查**

| 记号 | 含义 |
| --- | --- |
| 等价类 | $[x]=x+\mathbb{Q}$ |
| 选择公理 | 每袋取一代表的存在公理 |
| Solovay 模型 | 无不可测集的 ZF 模型 |
| Hamel 基 | 实数作为 $\mathbb{Q}$ 向量空间的基 |

**辨析｜易错点：不可测集的外测度可能「恰好存在」但「不是测度」。** $m^*(V)$ 是良定义的（外测度处处有定义），但它落在 $(0,3]$ 的某个值——只是 $V$ 不满足 Carathéodory 条件，无法进入可数可加的测度世界。**「外测度存在」≠「集合可测」。**

### 三步看懂「矛盾三幕」

- **平移不相交**：每等价类只取一个代表 → $V+r_i$ 两两无交。
- **双包含**：$[0,1]\subset\bigcup V_k\subset[-1,2]$ → 测度夹逼 $1\le\sum m(V_k)\le3$。
- **二分击穿**：$m(V)=0$ 或 $>0$ 都违反夹逼 → 矛盾。

**延伸（与泛函分析连接）**：Hamel 基的存在与不可测集同源于选择公理——任何 $\mathbb{R}$ 作为 $\mathbb{Q}$ 向量空间的基给出「加法同态不连续」的例子，进而在泛函分析中产生「无界线性泛函」。**选择公理的烙印遍布分析与代数。**

**一道收束练习**：证明「存在不可测集」蕴含「存在非主超滤子」（在 ZF 中两者等价）——把 Vitali 的几何构造翻译成组合语言，理解「不可测」的集合论本质。

## 7 小结

- **Vitali 集构造**：在 $[0,1]$ 上按「差为有理数」分等价类，选择公理每类取一代表。
- **不可测性证明**：矛盾三幕——平移不相交、覆盖 $[0,1]$ 含于 $[-1,2]$、测度夹逼被 $m(V)$ 的二分击穿。
- **公理地位**：不可测集存在 ⇔ 某种选择公理；Solovay 模型里一切集合可测。
- **测度论的边界**：可测性是「选择可以测量的集合」的界线，不是对象的固有属性。
- **对后续的影响**：不可测集提醒我们「几乎处处」「可测函数」的表述必须精确——第五篇可测函数理论正是这条界线的正式版图。
- **外测度 ≠ 可测**：$m^*(V)$ 存在但 $V$ 不可测——两者是不同概念。

**再读一遍「边界」的哲学**：不可测集的存在不是理论的失败，而是「测量」这一概念的精确边界——它告诉我们可测 σ-代数之外还有世界，而 Carathéodory 条件正是通往那个可测量世界的唯一桥梁。
