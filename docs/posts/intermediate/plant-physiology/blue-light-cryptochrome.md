## 为什么植物还要蓝光受体

上一节的光敏色素只对红/远红光敏感，那植物的向光性、气孔开启、昼夜节律是怎么感知方向的？
答案在**蓝光受体**——一整个家族，
其中最有名的是**隐花色素（cryptochrome）**与**向光素（phototropin）**。<span class="marginnote">蓝光受体管「这里和现在」：方向（向光性）、当下的光照质量（避荫、气孔）、与生物钟对表。
红光受体管「季节和昼夜长度」，
蓝光受体管「方向与即时状态」——分工明确。</span>这一节把蓝光感应的机制、成员与生物学后果讲清楚。

一个直觉问题：为什么植物要单设蓝光受体，而不是只靠光敏色素？因为光敏色素只测「红/远红光比例」，对光照方向、瞬间光照强度不敏感；而向光性需要「哪边亮」的空间信息，气孔需要「现在多亮」的即时信息——这些都要波长更短、响应更快的蓝光通道来完成。

## 1 蓝光受体家族：各有分工

蓝光应答由至少三大家族承担，它们共享一个发色团（chromophore），
但用途迥异：

**隐花色素（cryptochrome, CRY）**：负责**抑制下胚轴伸长**、促进开花、调控昼夜节律。
  它的蛋白结构与光裂合酶（photolyase）同源，
  但失去了 DNA 修复功能——「窃取」了光敏结构却改行了信号员。  <span class="marginnote">隐花色素（cryptochrome）的名字意为「隐秘的色素」——因为研究者先观察到生理效应、很久之后才找到这个受体。
  它是「先有表型、后有分子」的经典逆向研究案例。</span>
**向光素（phototropin, phot）**：负责**向光性弯曲、气孔开启、叶绿体运动**。
  它自身就是激酶，蓝光直接激活它（自磷酸化）——「受体-效应器一体」的极简设计。
- **ZTL（zeitlupe，德语「时间透镜」）**：调控生物钟周期。

**蓝光受体家族对照：**

| 受体 | 发色团/结构域 | 主要生理功能 |
| --- | --- | --- |
| 隐花色素（CRY） | FAD | 伸长抑制、开花、节律 |
| 向光素（phot） | LOV 结构域 | 向光性、气孔、叶绿体运动 |
| ZTL | LOV/F-box | 生物钟周期调控 |

**核心概念：蓝光受体 = 光敏蛋白 × 功能模块的「乐高」组合。** 隐花色素把光感结构（FAD 辅基）接到信号模块上，
向光素把光感结构（LOV 结构域）接到激酶模块上——同一类发色团，配不同的下游，
就是不同的生理功能。这是「一个传感元件，
多种执行器」的通用设计。<span class="marginnote">蓝光受体的「共享传感、分叉执行」，
与芯片里「一个 ADC，多个外设」同构。
生物学和工程都偏爱「通用传感器 + 专用执行器」的架构——因为它让演化/研发的成本分摊到最小。</span>

**记一个「分工口诀」**：红光管「季节」（长夜/日照），蓝光管「方位与即时」（方向、开关）；光敏色素算「累计账」（Pfr/Pr 比例），蓝光受体读「瞬时表」（此刻的强度与方向）。两个家族合起来，植物才既知道「什么时候」，也知道「在哪、多亮」。

## 2 隐花色素：从光化学到信号

隐花色素含黄素辅基 **FAD**。
机制概览：

1. **蓝光激发**：CRY 结合 FAD，蓝光被吸收，FAD 被还原（形成半醌/还原态），
   蛋白构象变化。
2. **信号释放**：CRY 与 **COP1/SPA** 复合体互作——COP1 本是 E3 泛素连接酶，
   会降解促进光形态建成的转录因子 HY5；蓝光激活 CRY 后**抑制 COP1**，
   HY5 得以积累，
   启动光形态建成基因。   <span class="marginnote">这里又是「解除抑制」语法：COP1 是「黑暗守门人」，
   CRY 把守门人撤走。
   与激素章节的 TIR1、DELLA、PP2C 全部同构——植物信号语法的最高频动词是「撤掉刹车」。</span>
3. **转录变化**：HY5 调控数百个基因，抑制下胚轴伸长、促进子叶展开。

**CRY 的双重身份**：它在拟南芥中既抑制下胚轴伸长，又参与生物钟的校时——同一个分子承担「形态」与「计时」两类任务，靠的是与不同蛋白伙伴（COP1、ZTL 等）的多元互作。一个受体、多路输出，是蓝光受体「乐高架构」的又一体现。

**辨析｜易错点：「蓝光受体管向光性」** 需要修正：向光性主要由**向光素（phot）**负责，
而非隐花色素；隐花色素主要负责**伸长抑制、开花、节律**。两者都是蓝光受体，
但岗位不同——把「蓝光受体」当单一实体，就会张冠李戴。真正记住的映射是：**向光性→phot，
避荫/开花/节律→CRY。**

**CRY 在动物界同样存在**：果蝇、哺乳动物的生物钟里也有隐花色素，充当光/磁信号的中转——蓝光受体不是植物的专利，而是整个生命界「感知与计时」的共享分子。这个跨界的共享，本身就是演化的一份广告。

## 3 向光素与向光性机制

向光素（phot1/phot2）是自身激酶：蓝光激活后自磷酸化，
磷酸化 AUX/IAA 相关蛋白与质膜 H⁺-ATPase，
最终**导致生长素向背光侧再分布**——单侧光下背光侧生长素浓度更高、伸长更快，
茎弯向光源。<span class="marginnote">向光性把「光的方向」转译成「生长素浓度差」，
再用生长素的「酸生长」机制弯曲——信息→化学梯度→力学弯曲，三层转译一气呵成。
这是把两个章节（信号 + 生长素 + 细胞壁酸生长）接成一条流水线的最佳演示。</span>

**气孔开启**是向光素的另一个岗位：蓝光激活向光素 → 激活质膜 H⁺-ATPase → 保卫细胞酸化、$\ce{K+}$ 涌入 → 水进 → 气孔张开。
这就是为什么清晨气孔「看到蓝光就开」。

**气孔开启的「红蓝双控」**：红光通过光合提高保卫细胞蔗糖与 $\ce{K+}$ 浓度，蓝光则直接激活 H⁺-ATPase——「红光管底色、蓝光管开关」，两者叠加决定气孔张开度。这也是为什么阴天（蓝光弱）气孔开得小、晴天开得大的原因之一。

## 4 公式解析：避荫反应的「红蓝比例」

植物在遮荫下会伸高、提前开花——**避荫反应（shade avoidance）**。
它靠「比较红/远红光比例（R:FR）」实现：浓密冠层下的透射光远红光占比高（红光被叶子吸走），
R:FR 降低。
植物的感应方程可用光敏色素稳态近似：

$$
\frac{[\mathrm{Pfr}]}{[\mathrm{Pfr}] + [\mathrm{Pr}]} = \frac{\sigma_R}{\sigma_R + \sigma_{FR}}
$$

- **$[\mathrm{Pfr}]/([\mathrm{Pfr}]+[\mathrm{Pr}])$：光敏色素的光稳态比例**——即「活性态占比」。
- **$\sigma_R$：Pr 吸收红光的有效速率**——红光越强、占比越高，Pfr 越多。
- **$\sigma_{FR}$：Pfr 吸收远红光后变回 Pr 的有效速率**——远红光越多，
  这个分母越大，  Pfr 比例越低。
- **结论**：树荫下 R:FR 低 → $\sigma_{FR}$ 相对大 → Pfr 比例低 → 植物判定「被遮荫」→ 伸长、提早开花。

拆解直觉：**植物不是测量绝对光量，而是测量「颜色比」。** 用比例而非强度做决策，
让植物在晴天、阴天、清晨都能用同一套标准——这是「归一化」的智慧，
与相机白平衡用「颜色比」而非「绝对亮度」是一个道理。<span class="marginnote">比例信号 vs. 绝对信号，
在生物里到处都是：感光用颜色比、激素用「浓度比梯度」、免疫用「抗原密度」。绝对量随环境漂移，
比值则稳定——工程里的「差分信号」是同一设计原则。</span>

带入数字感受 R:FR 的量级：晴天日光 R:FR 约 1.1–1.2，树荫下可低到 0.3–0.5。以 $\sigma_R/\sigma_{FR}$ 的比值粗略代入，Pfr 稳态比例会从日光的约 60% 掉到荫下的约 20%——颜色比翻几倍，植物就能明确判定「被遮荫」并启动避荫伸长。

## 5 小结

- 蓝光受体三大族：**CRY（伸长抑制、开花、节律）、phot（向光性、气孔、叶绿体运动）、ZTL（生物钟）**。
- 隐花色素含 FAD，
  蓝光激发后**抑制 COP1**→释放 HY5→启动光形态建成——又是「解除抑制」语法。
- **向光性归 phot 不归 CRY**：phot 自磷酸化→生长素再分布→背光侧伸长→弯曲。
- 向光素激活质膜 H⁺-ATPase→气孔开启；蓝光是气孔的「开门信号」。
- 避荫反应靠**测量 R:FR 颜色比**而非光强：$[\mathrm{Pfr}]$ 稳态比例 = $\frac{\sigma_R}{\sigma_R+\sigma_{FR}}$，
  低 R:FR→伸长逃避遮荫。
