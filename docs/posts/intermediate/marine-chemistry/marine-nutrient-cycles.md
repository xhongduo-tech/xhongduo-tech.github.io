## 为什么从营养盐开始

浮游植物是海洋食物网的第一环，它需要的不是「食物」而是溶解在海水里的**营养盐**：氮、磷、硅。这些元素在海洋中的浓度低得可怜（磷只有纳摩尔到微摩尔级），却像服务器上的 GPU 配额一样，决定了海洋光合作用的上限。这一篇要讲清楚：**营养盐为什么表层枯竭、深层富集；氮、磷、硅各自的循环有何不同；以及一条贯穿一切的比例定律——雷德菲尔德比值**。它与你之前读过的生物泵、之后要读的氧化还原分带，构成理解海洋生命动力学的完整闭环。<span class="marginnote">把营养盐想象成大模型的训练数据：表层是「耗尽区」（数据被消费殆尽），深层是「存储区」（再矿化不断补充）。海洋的垂直梯度，就是这套「数据生命周期」的物理实现。</span>

## 1 雷德菲尔德比值：生命的化学计量

1930 年代，阿尔弗雷德 · 雷德菲尔德（Alfred Redfield）发现海洋浮游生物的组成、海水中溶解营养盐的分布，遵循几乎固定的化学计量比：

$$\mathrm{C : N : P} = 106 : 16 : 1$$

**雷德菲尔德比值**意味着：浮游生物每吸收 1 mol 磷，就平均带走 16 mol 氮、106 mol 碳。它在海洋化学里扮演「天平」的角色——因为吸收与再矿化都按这个比例进行，所以硝酸盐与磷酸盐的深度剖面形状几乎完全重合。<span class="marginnote">雷德菲尔德比值为何恒定，至今没有唯一的解释——可能由生物化学的需求决定，也可能由海洋循环的反馈塑形。它是海洋学里少数「好用却未完全证伪根基」的经验定律，与新世界数据科学的「尺度律」有相似的处境：被反复检验、仍不断校准。</span>由此写出海洋光合作用的化学计量方程（以硝酸盐为氮源）：

$$\ce{106CO2 + 16NO3^- + HPO4^{2-} + 122H2O + 18H+ -> C106H263O110N16P + 138O2}$$

这是营养盐循环的总纲：**营养盐被光合作用消耗、又随有机质再矿化释放，构成封闭循环；而这条循环正是生物泵的物质基础**。

## 2 氮循环：海洋里最复杂的氧化还原环

**氮**在海洋中形态最多、氧化还原状态最丰富，因而循环最复杂：

- **固氮（N2 fixation）**：固氮蓝藻把大气 $\ce{N2}$ 还原为氨，是海洋新氮的重要来源——但受铁与磷限制。
- **同化吸收**：浮游植物吸收 $\ce{NH4+}$ 或 $\ce{NO3^-}$ 合成有机氮。
- **硝化（nitrification）**：氨被氧化为 $\ce{NO2^-}$ 再氧化为 $\ce{NO3^-}$（亚硝化 + 硝化细菌）。
- **反硝化（denitrification）**：缺氧条件下 $\ce{NO3^-}$ 被还原为 $\ce{N2}$ 逸出海洋——海洋的「失氮」通道。
- **厌氧氨氧化（anammox）**：$\ce{NH4+}$ 与 $\ce{NO2^-}$ 直接合成 $\ce{N2}$，是缺氧带失氮的另一主力。

氮循环的形态图景是：表层被同化耗尽，深层靠再矿化富集；而**缺氧海区（oxygen minimum zone）的反硝化与 anammox 把氮「泄漏」回大气**，使海洋氮库处于动态平衡。<span class="marginnote">反硝化与 anammox 只在溶解氧极低处进行，因此海洋的氮平衡与溶解氧分布紧密耦合——这为《海洋氧化还原过程》埋下伏笔：氧化还原状态决定物质归途，氮是第一个范例。</span>

## 3 磷与硅：两条「另类」的循环

**磷**没有气态形态，地球上没有一个「大气磷库」。它的循环是纯「沉积型」的：陆地风化 → 河流入海 → 生物吸收 → 颗粒沉降 → 沉积物 → 地质抬升再风化。这意味着**磷是海洋生产力的终极限制元素**——氮可以靠固氮从大气补充，磷却没有捷径。<span class="marginnote">「氮可补、磷不可补」是海洋生态化学的一条铁律：这也解释了为什么工业氮肥可以大规模提高产量，而磷的短缺才是长期瓶颈——类似算力可租、数据不可再生的资源结构。</span>

**硅**的循环与硅藻、放射虫等硅质生物绑定：硅藻摄取溶解硅（$\ce{H2SiO4}$）构筑硅质壳体，沉降后在深层溶解。硅的再矿化发生在更浅深度，且不受有机质分解完全控制，所以硅酸盐剖面通常比硝酸盐在更浅处就开始上升。

## 4 新生产力与再生生产力

把循环拆成「新料」与「回料」两本账，是营养盐动态的核心视角：

**再生生产力（regenerated production）**：浮游植物利用水体中被快速再矿化的 $\ce{NH4+}$、磷酸盐——这是海洋生产力的大头（约 80%）。
- **新生产力（new production）**：利用从外部补给的**新氮**（固氮新输入的 $\ce{NO3^-}$ 或大气沉降），与碳输出绑定。
- **f 比值**：$\mathrm{f} = \text{新生产力} / \text{总生产力}$。

**新生产力才是真正从表层「净移走」碳的部分**——因为它对应于生物泵的净输运。全球 f 比值约 0.1–0.2，意味着只有约 10–20% 的生产力参与了向深海的净碳输出。<span class="marginnote">新生产力 ≈ 净固碳出口，这个「净」字暗含了再矿化平衡：表层生产的有机碳大部分在浅层就被吃掉了。f 比值因此是气候尺度上碳汇强弱的直接度量——调节 f，就等于调节海洋的「碳出口带宽」。</span>

## 5 公式解析：雷德菲尔德方程的一步一世界

$$\ce{106CO2 + 16NO3^- + HPO4^{2-} + 122H2O + 18H+ -> C106H263O110N16P + 138O2}$$

- **第一步，系数从哪来**：分子式 $\ce{C106H263O110N16P}$ 是浮游植物有机质（活质）的平均元素组成，由红海菲尔德的 106:16:1 扩展而来。每固定 106 mol 碳、16 mol 氮、1 mol 磷，同时消耗 18 mol 质子（因为 $\ce{NO3^-}$ 吸收放出 $\ce{OH-}$）。
- **第二步，氧平衡**：产物 138 mol $\ce{O2}$ 来自碳、氢、氧的化学计量配平——光合作用「产氧」的本质就是这 138。把方程倒过来读，就是**再矿化**：有机质 + 138 $\ce{O2}$ → 二氧化碳 + 营养盐 + 水，这正是生物泵深层的呼吸引擎。
- **第三步，它的用途与边界**：用这个方程可以从氧耗估算碳通量（如用溶解氧亏损反推新生产力），也可以从营养盐剖面预测碳的垂直分布。**辨析｜易错点：** 雷德菲尔德比值是统计平均，实际随物种、光照、养分状态波动（浮游植物的 C:N 可偏离到 8–15 甚至更高）；当营养盐失衡时（如氮限制海域），直接套用 106:16:1 会系统性高估或低估通量。

## 6 全球视野：铁、氮与营养盐地图

把营养盐画上全球地图，能立刻看出海洋的「贫富不均」：副热带环流是巨大的营养盐荒漠（表层硝酸盐近零），而高纬与上升流区（东边界流、赤道涌升带）则是「绿洲」。解释这张地图的钥匙，不只是营养盐本身，还有我们在《微量元素》里认识的**铁**：

- **高营养、低叶绿素（HNLC）海域**：南大洋、赤道东太平洋、亚北极太平洋——表层硝酸盐、磷酸盐充足，但浮游植物长不起来。瓶颈正是缺铁。
- **铁的来源**：风尘输入（撒哈拉尘暴喂饱了热带大西洋）、大陆架与火山、以及深层水再循环。
- **铁的停留时间极短**（在表层仅数天到数月），所以它的分布高度局地化——营养盐循环因此是「氮磷为纲、铁为总开关」的复合系统。<span class="marginnote">铁作为「总开关」的隐喻很精确：营养盐是大数据量的主体（像参数），铁是稀缺的调控信号（像调度器）。调节一个铁原子的供应，可以改写整片海域的生产力——这是化学调控生态的极致案例。</span>

由此，营养盐循环的全球图景可以浓缩为一句话：**生物泵在哪里强，取决于氮磷的供给；而氮磷供给的有效性，往往被铁的开关拧紧**。全球观测计划（如 GLODAP）正是带着这张地图去校准模型——把海洋化学从「点测量」推进到「场重建」。

## 7 小结

- **雷德菲尔德比值 C:N:P = 106:16:1** 是吸收与再矿化的通用天平，支撑着生物泵的净输运。
- 营养盐剖面形态：表层枯竭、深层富集；硝酸盐与磷酸盐剖面几乎重合。
- 氮循环最复杂：**固氮—同化—硝化—反硝化—anammox** 构成闭环，缺氧海区是失氮窗口。
- 磷无气态、纯沉积循环，是终极限制元素；硅循环受硅质生物与溶解控制。
- **新生产力 / f 比值**才是与碳净出口挂钩的变量，全球 f 约 0.1–0.2。
