## 为什么从氧化还原开始

上一节我们在海水里看到，再矿化靠溶解氧进行。但海洋中只有约 0.1% 的有机碳最终埋藏成岩，而绝大多数沉降有机质在沉积物中被微生物分解——问题是：**当氧气耗尽，分解还要不要继续？** 答案是必须继续，而微生物找到了另一套氧化剂。海洋沉积物于是被组织成一条「电子受体接力赛」：有氧呼吸 → 反硝化 → 锰还原 → 铁还原 → 硫酸盐还原 → 产甲烷。这条序列不仅决定了碳的命运，还控制着黄铁矿的形成、海水的碱度与硫循环、以及黑色页岩的分布。这一篇先建立「能量排序」的热力学直觉，再走进孔隙水的剖面去读这条接力的实况。<span class="marginnote">把氧化还原分带想成一组「梯度下降」的调度器：微生物永远选择能释放最多能量的反应，能量耗尽才切换下一级。自由能递减，决定了电子受体按固定顺序登场——这是海洋化学里最优雅、也最好用的规律之一。</span>

## 1 氧化还原分带：自由能的阶梯

有机质（用 $\ce{CH2O}$ 近似）的氧化是沉积物的「总需求」，而可供选择的氧化剂（电子受体）各有各的能量收益。以每摩尔有机碳计，标准自由能变化约为：

| 反应（电子受体） | 产物 | $\Delta G^\circ$（kJ/mol 有机碳） |
| --- | --- | --- |
| $\ce{O2}$ | $\ce{H2O}$ | −479 |
| $\ce{NO3^-}$ | $\ce{N2}$ | −453 |
| $\ce{Mn(IV)}$ | $\ce{Mn^{2+}}$ | −349 |
| $\ce{Fe(III)}$ | $\ce{Fe^{2+}}$ | −114 |
| $\ce{SO4^{2-}}$ | $\ce{HS^-}$ | −77 |
| $\ce{CO2}$ | $\ce{CH4}$ | −59 |

**微生物优先使用自由能释放最多的受体**，于是随着有机碳向下输送、上层受体逐渐耗尽，反应依次向深处推进，形成垂直分带。分带在「深度」上展开的原因，是沉积物不断把新有机质埋下去，而扩散只允许氧气、硝酸盐等缓慢渗入——这是一个「供应 < 需求」的动力学平衡。<span class="marginnote">氧气与硝酸盐扩散进沉积物的通量有限，而有机质沉降源源不断，于是浅层就把高能受体消耗殆尽。分带是通量竞争的结果，不是预先设计好的分层——这跟 CPU 缓存的替换策略同构：容量有限，只能按优先级让热数据驻留。</span>

![海相沉积物的氧化还原分带与孔隙水剖面](/images/marine-chemistry/redox-zonation-1.svg)

**在开放大洋沉积物里，几乎总能看到完整的分带序列**；而在有机质通量极高的富营养海盆（如缺氧盆地），带与带会急剧压缩甚至缺失中间环节。

## 2 硫酸盐还原：海洋版「巨量电池」

海水中 $\ce{SO4^{2-}}$ 浓度高达约 28 mmol/kg——它的总氧化容量远超溶解氧，是海洋中最大的电子受体储库。硫酸盐还原虽然后序出场、单位能量低，但凭借储量优势，成为埋藏有机碳分解的主力，尤其主导了半深海与富有机质沉积物：

$$\ce{2CH2O + SO4^{2-} -> 2HCO3^- + H2S}$$

- 产物 $\ce{H2S}$（硫化物）是极强的还原剂与毒物，驱动着整个**铁—硫耦合**：$\ce{Fe^{2+} + HS^- -> FeS -> FeS2}$（黄铁矿）。<span class="marginnote">黄铁矿（FeS₂）的沉淀把硫酸盐还原固定的硫「锁」进沉积物，是硫循环的出口；而黄铁矿丰度本身就是古海洋缺氧事件（OAE）与黑页岩的矿物学签名。</span>
- 碱度升高：硫酸盐还原每氧化 1 mol 有机碳释放约 2 mol 碱度，显著改变孔隙水化学——这是后文古海洋示踪里「碱度异常」的信号源。

## 3 铁锰氧化物与「氧化还原因子」的迁移

在铁还原带与锰还原带，高价态固体氧化物溶解为低价态离子：

$$\ce{MnO2 + 2e^- + 4H+ -> Mn^{2+} + 2H2O},\qquad \ce{FeOOH + e^- + 3H+ -> Fe^{2+} + 2H2O}$$

生成的 $\ce{Fe^{2+}}$、$\ce{Mn^{2+}}$ 会向上扩散到有氧带重新氧化沉淀——形成经典的**「氧化还原因子（redox cline）循环」**：铁锰在界面上反复溶解—沉淀，使沉积物中形成富集层。这个循环是控制痕量金属（如铜、镍、镉、钴）去向的枢纽：许多痕量金属被铁锰氧化物吸附共沉淀，又在还原带释放——这正是《微量元素与痕量金属》清除机制的沉积端。<span class="marginnote">铁锰氧化物的「溶解—再沉淀」像一个循环泵，不断把氧化性颗粒抛向表层、把还原性溶质送向深部。任何研究痕量金属沉积记录的人，都必须先校准这台泵——它也是古海洋代用指标里最著名的「干扰项」。</span>

## 4 公式解析：氧化还原自由能的排序逻辑

以硝酸盐还原（反硝化）为例，把反应拆开看能量从哪来：

$$\ce{5CH2O + 4NO3^- + 4H+ -> 5CO2 + 2N2 + 7H2O}$$

- **第一步，谁是氧化剂**：$\ce{NO3^-}$ 中氮为 +5 价，被还原为 $\ce{N2}$（0 价）——每个 $\ce{NO3^-}$ 接受 5 个电子，4 个硝酸根共接受 20 个电子，恰好氧化 5 个 $\ce{CH2O}$（每个失 4 电子）。
- **第二步，能量差从哪来**：电子从有机质的碳氢键（高位）跌落到氮原子（低位），落差越大放能越多。$\ce{O2}$ 的电子亲和力最大（O 电负性最强），故自由能最负；越靠序列下端，受体持电子能力越弱，收益越小。
- **第三步，分带的判据**：比较不同反应的 $\Delta G^\circ$ 只是热力学判据；实际分带还要看各受体的**供给速率**。**辨析｜易错点：** $\ce{SO4^{2-}}$ 的 $\Delta G^\circ$ 比 $\ce{Fe(III)}$ 更正，但硫酸盐还原通常出现在铁还原之下——因为在许多环境里硫酸盐的扩散供给远比可还原铁充足，动力学盖过热力学排序的直觉。分带永远是「能量 × 供给」的联合结果。

## 5 从孔隙水到全球：缺氧事件与黑色页岩

分带不只是「沉积物内部的事」——它在大时间尺度上改写了全球地球化学。当大洋局部出现**大规模缺氧**（如大洋缺氧事件，OAE），海底进入以硫酸盐还原与产甲烷为主的极端分带状态：

- **黑色页岩（black shale）**：缺氧条件下有机质埋藏率飙升，与黄铁矿一起沉积，形成富含有机碳的黑色页岩——今天全球相当一部分石油与天然气都产自这类古缺氧沉积。
- **海洋碱度与硫平衡**：硫酸盐还原释放碱度、黄铁矿固定硫，改变海水的化学组成；硫酸盐浓度本身也随地质历史涨落（元古宙曾低至现在的几分之一）。
- **反馈到大气**：缺氧洋盆扩大意味着更多硫化物氧化释放 $\ce{SO2}$、更多有机碳埋藏意味着净固碳——氧化还原分带因此是地球气候系统的「地下发动机」之一。<span class="marginnote">把「沉积物—孔隙水」的微观剖面放大十万年，就是「大洋—大气」的宏观循环：局部成岩的每一步，都在为全球演化记账。理解尺度跳跃，是地球化学区别于实验室化学的精髓。</span>

**辨析｜易错点：** 不要以为「缺氧事件 = 一次灾难性的物质瞬变」。氧化还原状态的变化往往缓如流水——分带在垂直方向上的迁移、深度的呼吸式伸缩，才是常态。读剖面时要同时考虑**定态分带**与**瞬态迁移**两种解释，否则会把一次环流调整误读成地质突变。

## 6 小结

- 沉积物再矿化遵循**氧化还原分带**：O₂ → NO₃⁻ → Mn(IV) → Fe(III) → SO₄²⁻ → CH₄，自由能逐级递减。
- 分带是**通量竞争**的结果：有机质供给 > 电子受体扩散，故受体沿深度依次耗尽。
- **硫酸盐还原**以约 28 mmol/kg 的储量成为深海沉积物再矿化主力，并驱动黄铁矿沉淀与碱度升高。
- 铁锰氧化物在氧化/还原带之间**循环溶解—再沉淀**，是痕量金属与古海洋记录的关键调制器。
