## 为什么从有机地球化学开始

前几篇的碳、营养盐、氧化还原，主角都是「无机化学」。但海洋碳库里有约 700 Pg 的**溶解有机碳（DOC）**——规模与大气碳库相当，却几乎全部是分子级别的「化学汤」，形态从糖到木质素到古老惰性分子应有尽有。这一篇要回答：海洋有机质的来源是什么、为什么大部分有机质在到达深海之前就被吃掉、又有哪些「顽固分子」能活过千年的降解。<span class="marginnote">有机地球化学是「分子层面的侦探工作」：用特定生物标记物（如木质素之于陆源、烯酮之于球石藻）辨认有机质的身世，再用碳同位素与年代学确定它的年龄——每一类分子都是海洋碳循环里的一枚指纹。</span>它对大模型主题同样意味深长：海洋有机碳的「存活与降解」问题，与语料库中信息的「保存与遗忘」共享同一套取舍逻辑。

## 1 有机碳库的形态与分布

海洋有机碳以两种形态存在：

**溶解有机碳（DOC）**：全球约 662 Pg C，其中大部分是**惰性（recalcitrant）**分子。表层 DOC 约 50–80 μmol/kg，深层约 35–45 μmol/kg——深层虽低，却因水体庞大而占了绝大部分库存。
- **颗粒有机碳（POC）**：全球仅约 5–10 Pg C，是「运输中的碳」——浮游植物的残骸、粪便颗粒与海洋雪，负责把碳从表层送往深海。<span class="marginnote">DOC 是「库存」，POC 是「流量」：库存巨大而流动缓慢，流量虽小却是生物泵的实际载体。这个「存量 vs 通量」的区分是海洋碳循环一切定量讨论的起点，也让人想起训练数据里「参数量 vs token 吞吐」的辨析。</span>

有机质的来源可分成两大门类：**海洋原位**（浮游植物及其降解产物，δ¹³C 约 −20‰）与**陆源**（河流输入与陆源碎屑，δ¹³C 约 −27‰）。二者用碳同位素一眼就能分开——碳同位素在此扮演了「来源指纹」的角色，呼应上一节的同位素化学。

## 2 再矿化与 Martin 曲线：碳的垂向衰减

沉降颗粒在深海中不断被微生物分解。实测发现，有机碳通量随深度呈幂律衰减——**Martin 曲线**：

$$F(z) = F(z_0)\left(\frac{z}{z_0}\right)^{-b},\qquad b \approx 0.86$$

- $z_0$：参考深度（通常取 100 m）；
- $F(z_0)$：该深度的沉降通量；
- $b$：**衰减指数**，控制通量随深度减弱的快慢。

这条曲线的含义深刻：**到达海底的有机碳只占表层的百分之几**。例如 $z_0 = 100\,\mathrm{m}$ 处的通量为 100，到 1000 m 衰减为 $100 \times 10^{-0.86} \approx 14$，到 4000 m 只剩约 4。<span class="marginnote">b ≈ 0.86 的「通用性」至今令人着迷：不同海区、不同季节拟合出的 b 出奇地稳定。它像一个宏观上的「平均降解律」，把数千种微生物、数百种分子的降解行为浓缩成一个指数——这是经验定律的又一枚标本。</span>再矿化的副产品正是我们在《营养盐循环》与《氧化还原》中反复看到的氮、磷释放与氧消耗。

## 3 微生物碳泵：惰性碳库的缔造者

为什么深层 DOC 能在海水中滞留数千年？答案不是「微生物无能为力」，而是**微生物碳泵（microbial carbon pump）**：微生物在降解有机质的同时，把不稳定的生物分子改造成越来越难分解的**惰性溶解有机碳（RDOC）**——每一次「消化」都留下更顽固的残骸，分子越改越不亲微生物。<span class="marginnote">RDOC 的形成是「以难降解换取长存留」的化学进化：深海 DOC 的 ¹⁴C 表观年龄高达 4000–6000 年，说明它是数千年尺度上缓慢累积的「老碳」。这条「活碳 → 老碳」的转化链，是海洋封存碳的核心机制之一。</span>此外，透明外聚合物颗粒（TEP）与凝胶态物质是 POC 向 DOC 转化的中间站——颗粒在沉降途中「溶解」，把有机质重新撒回水体，构成 DOC 与 POC 之间的动态循环。

## 4 生物标记物：分子级的来源档案

除碳同位素外，海洋有机地球化学的看家本领是**生物标记物（biomarkers）**——只由特定生物合成的分子：

| 生物标记物 | 来源 | 用途 |
| --- | --- | --- |
| 木质素酚类 | 陆生维管植物 | 陆源有机质示踪 |
| 烯酮（alkenones） | 颗石藻 | 表层海水温度计（$U^K_{37}$） |
| 正构烷烃、脂肪酸 | 浮游植物/细菌 | 来源与降解状态判别 |
| 甾醇（sterols） | 浮游动物、藻类 | 食物网结构的分子档案 |
| GDGTs | 古菌 | 古温度与古 pH 指标 |

**辨析｜易错点：** 生物标记物并非「坚不可摧」——不同分子降解速率不同，叫做**选择性降解**。如果忽略降解差异，就会高估耐降解分子的来源贡献；所有通量重建都必须同时校正「来源」与「降解」，这是有机示踪最容易被忽略的坑。<span class="marginnote">选择性降解带来的偏差，类似推荐系统里「存活者偏差」：能留下来的分子才被观测到，而真正决定原始输入的是那些已消失的分子。校正模型必须显式建模降解损失，才能反推原初通量。</span>

## 5 公式解析：Martin 曲线的斜率决定封存效率

$$F(z) = F(z_0)\left(\frac{z}{z_0}\right)^{-b},\qquad b \approx 0.86$$

- **第一步，取对数看线性**：$\ln F = \ln F(z_0) - b \ln(z/z_0)$。在双对数坐标里，Martin 曲线是一条直线，斜率 $-b$。
- **第二步，b 的物理含义**：$b$ 越大，通量衰减越快、碳越早被消耗在浅层；$b$ 越小，碳越能深入深海。因此 $b$ 直接控制「封存效率」——到达海底的碳比例 $\propto (z/z_0)^{-b}$。
- **第三步，外推与风险**：实测数据通常只覆盖表层几百米，深层通量靠这条曲线外推。**辨析｜易错点：** 幂律在浅层可能高估、深层可能低估（实测深层通量常高于 Martin 外推），且底部边界层、侧向输运会附加干扰——把 b 当成普适常数用于单个站位时，务必保留误差带。

## 6 化学考古：如何「看见」看不见的汤

惰性 DOC 的分子小、浓度低、彼此相似，传统分离手段几乎失效——海洋有机化学因此催生了「分子考古」的层层武器：

- **固态 ¹³C NMR**：直接识别有机物里的官能团骨架（烷基、羧基、芳香碳的比例），不依赖分离。
- **超高分辩质谱（FT-ICR-MS）**：把海水中的分子按精确质量「数出来」，一次可解析上万种分子式——海洋 DOC 因此被称为「化学宇宙」（chemodiversity），其分子种类之多的确堪比宇宙中的恒星数。<span class="marginnote">把 DOC 当「化学宇宙」不是比喻而是操作定义：每条质谱峰是一个分子式，上万条峰就是上万种分子。分析这种高维数据要用上聚类、主成分这类工具——海洋有机化学早已是数据科学的前沿。</span>
- **光学指纹（CDOM 荧光）**：陆源与海源有机质的荧光特征不同，卫星可以从太空「看」表层溶解有机物的来源——遥感与分子分析第一次在同一条碳流上汇合。

**辨析｜易错点：** 「测出上万种分子」不等于「懂这个体系」——FT-ICR-MS 给出的是分子式，不是结构，更不是活性。**分子存在 ≠ 分子重要**：惰性库的绝大多数分子可能只是「存在」而代谢活性极低。现代研究正在从「数分子」转向「跟踪活性」（用同位素标记追踪哪些分子真的在被改造），这一转向深刻改变了整个领域的问题意识。

## 7 小结

- 海洋有机碳以 **DOC（约 662 Pg C）为库存、POC（约 5–10 Pg C）为流量**；来源分海洋原位与陆源，碳同位素一辨即分。
- **Martin 曲线** $F(z) = F(z_0)(z/z_0)^{-b}$（$b \approx 0.86$）描述有机碳通量随深度的幂律衰减，决定深海封存效率。
- **微生物碳泵**把活性有机质改造成惰性 RDOC，造就了表观年龄 4000–6000 年的「老碳」库。
- 生物标记物（木质素、烯酮、GDGTs）提供分子级来源档案，但必须校正**选择性降解**偏差。

在下一节，我们将把前面积累的全部化学探针——同位素、示踪剂、生物标记物——组合成一套「反演仪器」，用沉积记录重建千万年前的海洋状态，这就是**化学示踪与古海洋学**。
