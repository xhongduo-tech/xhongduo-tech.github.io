## 为什么先造「道路类」再谈乘法

基本群的元素将是「回路（起点终点重合的道路）」的同伦类——即**道路类**。在定义群运算前，必须先回答两个问题：其一，两条道路什么时候「算一样」？答案是**道路同伦**（保端点同伦）；其二，两个道路类怎么「相乘」？答案是**先乘道路、再取类**。本课把这两个问题做扎实：道路同伦的定义与性质、道路乘法的定义与「良定义」验证。这些看似「定义」的工作，是整个基本群理论的合法性根基——一旦「道路类乘法」不是良定义的，基本群就不存在。<span class="marginnote">「良定义」是代数构造的命门：若 $[\sigma] = [\sigma']$、$[\tau] = [\tau']$ 但 $[\sigma * \tau] \neq [\sigma' * \tau']$，乘法就没法在「类」的层面谈论。基本群的所有性质，都建立在「乘法良定义」这一地基上。</span>

## 1 道路同伦：保端点

**道路同伦（path homotopy）**：设 $\sigma, \tau : [0,1] \to X$ 是两条道路，$\sigma(0) = \tau(0) = x_0$、$\sigma(1) = \tau(1) = x_1$（同起点同终点）。若存在连续映射 $F : [0,1] \times [0,1] \to X$ 使得

$$F(s, 0) = \sigma(s), \qquad F(s, 1) = \tau(s) \quad (0 \le s \le 1)$$

$$F(0, t) = x_0, \qquad F(1, t) = x_1 \quad (0 \le t \le 1)$$

则称 $\sigma$ 与 $\tau$ **道路同伦**，记作 $\sigma \simeq_p \tau$。

两组条件各司其职：

- 第一组：$F(s, 0) = \sigma$、$F(s, 1) = \tau$——「从 $\sigma$ 变形到 $\tau$」。
- 第二组：$F(0,t) = x_0$、$F(1,t) = x_1$——「端点全程钉住」，变形过程中起点终点不动。

**辨析｜易错点：** 道路同伦比「自由同伦」强——自由同伦允许端点动，道路同伦要求端点钉住。基本群用的是**道路同伦**（保端点）。「保端点」这条条件让道路类在乘法下有「好的代数结构」。<span class="marginnote">「端点钉住」是道路同伦与普通同伦的关键差别：$F(0,t) = x_0$、$F(1,t) = x_1$ 保证变形不「挪窝」。若允许端点动，任何同起点终点的道路都可能「自由同伦」但「道路同伦」不成立——两个概念别混。</span>

**道路类（path class）**：道路同伦是等价关系（静止、倒带、拼接，与普通同伦的三条操作一致），其等价类 $[\sigma]$ 称为**道路类**。

## 2 道路乘法：先接后类

**道路的乘法（product of paths）**：设 $\sigma$ 以 $x_1$ 为终点、$\tau$ 以 $x_1$ 为起点（$\sigma(1) = \tau(0) = x_1$），定义

$$(\sigma * \tau)(s) = \begin{cases} \sigma(2s), & 0 \le s \le 1/2 \\ \tau(2s - 1), & 1/2 \le s \le 1 \end{cases}$$

前半段以两倍速跑 $\sigma$，后半段以两倍速跑 $\tau$，在 $s = 1/2$ 处（都等于 $x_1$）平滑衔接。$\sigma * \tau$ 是连续道路（拼接点值相等）。

**道路类的乘法**：定义

$$[\sigma] * [\tau] = [\sigma * \tau]$$

**关键：这是良定义的。** 即若 $[\sigma] = [\sigma']$、$[\tau] = [\tau']$，则 $[\sigma * \tau] = [\sigma' * \tau']$。

**良定义的证明**：设 $F$ 是 $\sigma$ 到 $\sigma'$ 的道路同伦、$G$ 是 $\tau$ 到 $\tau'$ 的道路同伦。定义

$$H(s, t) = \begin{cases} F(2s, t), & 0 \le s \le 1/2 \\ G(2s - 1, t), & 1/2 \le s \le 1 \end{cases}$$

在 $s = 1/2$ 处 $F(1, t) = x_1 = G(0, t)$（端点钉住），故 $H$ 连续。$H(s, 0) = \sigma * \tau$、$H(s, 1) = \sigma' * \tau'$，且端点钉住——$H$ 是 $\sigma * \tau$ 到 $\sigma' * \tau'$ 的道路同伦。∎<span class="marginnote">证明的技巧：把两条同伦「拼」成一条——上半段跑 $F$、下半段跑 $G$，接缝处因「端点钉住」而连续。这个「拼接同伦」与「拼接道路」是同构论证，都靠「衔接点值相等」。</span>

于是「先乘道路、再取类」与「先取类、再乘」一致——道路类乘法良定义。

## 3 道路类乘法的性质

道路类乘法有三个性质，为基本群的群结构做准备：

**结合律（同伦意义下）**：$([\sigma] * [\tau]) * [\upsilon] = [\sigma] * ([\tau] * [\upsilon])$。注意道路的「精确结合」不成立（$(\sigma * \tau) * \upsilon$ 与 $\sigma * (\tau * \upsilon)$ 的「切换时刻」不同，$s = 1/2$ vs $s = 1/4$），但它们是**道路同伦**的（重新参数化）。于是类的层面结合律成立。<span class="marginnote">「道路乘法不精确结合、但同伦意义下结合」是基本群理论的第一处「同伦宽容」：精确等式被换成同伦等式，类层面就干净了。这是「类」这一抽象带来的自由。</span>
- **单位元**：常值道路 $e_{x_0}$（$e_{x_0}(s) \equiv x_0$）是「在 $x_0$ 处」的单位元：$[e_{x_0}] * [\sigma] = [\sigma]$、$[\sigma] * [e_{x_1}] = [\sigma]$（同伦意义下，$e * \sigma$ 与 $\sigma$ 只差参数化）。
- **逆元**：逆道路 $\bar{\sigma}(s) = \sigma(1-s)$ 满足 $[\sigma] * [\bar{\sigma}] = [e_{x_0}]$、$[\bar{\sigma}] * [\sigma] = [e_{x_1}]$（同伦意义下，「走 $\sigma$ 再原路返回」可缩成常值）。

这三个性质恰好对应群的三条公理——下一课把「以 $x_0$ 为基点的回路类」收集成群，就得到**基本群**。

## 4 公式解析：道路乘法的参数化

$$(\sigma * \tau)(s) = \begin{cases} \sigma(2s), & 0 \le s \le 1/2 \\ \tau(2s - 1), & 1/2 \le s \le 1 \end{cases}$$

- **第一步，前半段**：$s \in [0, 1/2]$ 时，$2s \in [0,1]$，$\sigma(2s)$ 以两倍速跑完 $\sigma$。
- **第二步，后半段**：$s \in [1/2, 1]$ 时，$2s - 1 \in [0,1]$，$\tau(2s-1)$ 以两倍速跑完 $\tau$。
- **第三步，衔接**：$s = 1/2$ 处，$\sigma(1) = x_1 = \tau(0)$，两段值相等，拼接连续。

参数化的本质：把「$\sigma$ 全段 + $\tau$ 全段」压缩进单位区间，各占一半时间。这个「各半」是约定的——换成其他参数化只改变同伦类，不改变道路类。

## 5 辨析｜易错点（续）

**辨析｜易错点：** 道路类乘法有四个高频误区：

- **道路乘法要求「首尾相接」**：$\sigma(1) = \tau(0)$ 是前提。不满足则 $\sigma * \tau$ 无定义。基本群里都是回路，自动满足（同基点）。
- **精确结合律不成立**：$(\sigma * \tau) * \upsilon \neq \sigma * (\tau * \upsilon)$（切换时刻不同），只有同伦意义下相等。别写精确等式。
- **乘法良定义要证**：$[\sigma]=[\sigma']$、$[\tau]=[\tau']$ 时 $[\sigma * \tau] = [\sigma' * \tau']$——拼接同伦证明。漏掉这步，「类乘法」就是空中楼阁。
- **逆道路的方向**：$\bar{\sigma}(s) = \sigma(1-s)$ 是「倒带」；$[\sigma] * [\bar{\sigma}] = [e]$ 靠「走一个来回可缩」的同伦，不是精确相等。

## 6 小结

- **道路同伦**：保端点同伦（$F(0,t)$、$F(1,t)$ 钉住）。
- **道路类**：$[\sigma]$——道路同伦的等价类。
- **乘法**：$[\sigma] * [\tau] = [\sigma * \tau]$，拼接道路取类。
- **良定义**：拼接同伦证明——类乘法与代表元选择无关。
- **三性质**：结合律（同伦）、单位元（常值）、逆元（倒带）——群结构的三个胚芽。
- **意义**：基本群的全部合法性建立在「道路类乘法良定义」之上。

在下一节，我们将收拢这三性质：**基本群的定义**——以点为基点的回路类成群。

### 道路类的「集合」与「群胚」视角

道路类不仅能相乘，还构成一个更一般的代数对象——**群胚（groupoid）**：

- **群胚**：一个集合，元素是道路类，乘法定义在「首尾相接」的元素对上（不是全定义的二元运算），有单位元（常值类）、逆元（倒带类），结合律（同伦意义下）。
- **与群的差别**：群胚的乘法「部分定义」（只有首尾相接才能乘），单位元不止一个（每点一个常值类）。
- **基本群是群胚的「一点截取」**：固定基点 $x_0$，只看「起点终点都是 $x_0$」的回路类——此时乘法全定义、单位元唯一，群胚退化为群。

这个「群胚 → 基本群」的视角，让「为什么基本群依赖基点」变得清晰：群胚是全局对象，基本群是局部（某点处）的切片。第七篇覆盖空间理论会用群胚语言统一处理不同基点。

### 道路类乘法的「几何」直觉

道路类乘法的几何意义值得再咀嚼：

- **乘法 = 首尾相接**：$[\sigma] * [\tau]$ 就是「先走 $\sigma$，再走 $\tau$」——把两条路「接」成一条。
- **类 = 忽略参数化**：$[\sigma] = [\sigma']$ 意味着「参数化不同、轨迹形状同伦等价」——类的乘法与参数化无关。
- **逆 = 原路返回**：$[\bar{\sigma}]$ 把 $\sigma$ 倒着走——「去了再回来」可缩成常值。
- **群 = 回路的「代数化」**：把「怎么绕」编码成代数运算——这就是基本群「用代数谈拓扑」的起点。

几何直觉与代数定义的对接，是学习基本群的关键——每一步代数定义（类、乘法、结合律）都对应一个几何动作（同伦、接路、重参数化）。
