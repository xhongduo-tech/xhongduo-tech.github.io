# 拓扑学

拓扑学研究空间在连续变形下保持不变的性质，是分析、几何与代数的共同语言。本分类对标尤承业《基础拓扑学讲义》与 Munkres《Topology》入门部分的章节体系，覆盖点集拓扑与代数拓扑初步的全部核心内容。
