## 为什么从曲面开始

学完覆盖空间，我们已经把「空间的连续形变」这一思想用到了极致。现在换一个视角：不是研究空间的映射，而是研究**空间本身长什么样**。一个自然的起点是二维的曲面——它够简单，能画出来；又够复杂，蕴含深刻的分类结果。**曲面（surface）**，或者更正式地说**二维拓扑流形（2-dimensional topological manifold）**，是第八篇「曲面分类初步」的地基。<span class="marginnote">「流形」一词源于「多重流形」（manifold，德文 Mannigfaltigkeit），意为「局部像欧氏空间的拓扑空间」。爱因斯坦的广义相对论把时空当成四维流形，正是这个概念的鼎盛应用。</span>

为什么值得学曲面？因为曲面的分类定理给出一个惊艳的结论：**紧连通曲面总共只有可数无穷多种，全部列得出来**。在拓扑学这个「万物皆可变」的世界里，这几乎是不可思议的秩序。

## 1 拓扑流形的定义

<strong>定义（n 维拓扑流形）：拓扑空间 $M$ 称为 n 维（拓扑）流形，如果它是 Hausdorff 空间、有可数基（第二可数），并且每个点都有一个与 $\mathbb{R}^n$ 的某个开子集同胚的开邻域。</strong>

最后一条叫**局部欧氏**：任取 $x \in M$，存在开邻域 $U$ 与开子集 $V \subseteq \mathbb{R}^n$，以及同胚 $\varphi: U \to V$。同胚对 $(\varphi, U)$ 称为**坐标卡（chart）**，$U$ 上的点有了「坐标」$\varphi(x) \in \mathbb{R}^n$。

三条公理各司其职：

**局部欧氏**：保证 $M$ 在每个点附近「长得像」$\mathbb{R}^n$，这是流形定义的灵魂。
**Hausdorff（T2）**：保证极限唯一、两点可分离。没有它，流形可能「缠绕」出病态。
**第二可数**：保证流形可以「数得过来」地覆盖，是许多构造（如单位分解、度量化）的技术前提。

**辨析｜易错点：** 「局部欧氏」是**逐点**性质，它**不**保证整体是欧氏空间——圆周处处像直线，但整体是闭的环；球面处处像平面，但整体没有平面那样的「无限延伸」。局部像与整体是两回事，这正是拓扑学最需要警惕的地方。

## 2 曲面与带边曲面

当 $n = 2$ 时，流形就叫**曲面**。它的每个点都有一个邻域同胚于 $\mathbb{R}^2$ 的开子集。

许多常见的「曲面」其实带边界，比如圆盘 $D^2$、圆柱的侧面、Möbius 带。为此引入**带边流形**：把「半空间」加进来。

<strong>定义（带边流形）：设 $\mathbb{H}^2 = \{(x, y) \in \mathbb{R}^2 \mid y \ge 0\}$。曲面 $M$ 称为带边曲面，如果每个点都有邻域同胚于 $\mathbb{R}^2$ 的开子集或 $\mathbb{H}^2$ 的开子集。$M$ 中邻域同胚于 $\mathbb{H}^2$（且 $y = 0$ 的点）的那些点构成边界 $\partial M$；其余点构成内部 $\operatorname{int} M$。</strong>

**辨析｜易错点：** $\partial M$ 是**拓扑意义**的边界，与「集合的边界」不是一回事——圆盘 $D^2$ 作为 $\mathbb{R}^2$ 的子集，其边界是 $S^1$；但一个抽象曲面的边界是**它自己的内部结构**，与它是否嵌在某处无关。球面 $S^2$ 没有边界，即 $\partial S^2 = \emptyset$。

## 3 常见曲面举例

| 曲面 | 构造 | 紧？ | 带边？ | 可定向？ |
| --- | --- | --- | --- | --- |
| 球面 $S^2$ | $\mathbb{R}^3$ 中的单位球面 | 是 | 否 | 是 |
| 环面 $T^2$ | $S^1 \times S^1$ | 是 | 否 | 是 |
| 射影平面 $\mathbb{RP}^2$ | $S^2$ 对径点粘合 | 是 | 否 | 否 |
| Klein 瓶 $K$ | 方块按反向边字粘合 | 是 | 否 | 否 |
| Möbius 带 | 长方形两端扭转粘合 | 否 | 是 | 否 |
| 圆盘 $D^2$ | $\{x^2 + y^2 \le 1\}$ | 是 | 是 | 是 |

其中「可定向性」将在「可定向性与 Euler 示性数」一课系统展开；这里只需先有直觉：能否在曲面上**一致地**定义「上下面」或「左右手」。Möbius 带走一圈会翻面，所以不可定向；球面、环面则不会。<span class="marginnote">可定向性在物理上对应「手性」：无法在 Möbius 带上定义一个连续的、不翻转的法向量场。这也是第九篇毛球定理讨论「向量场」的预演。</span>

## 4 非例：为什么这些「不是曲面」

看反例能帮我们把定义钉死。

- **锥面（单圆锥）**：顶点处的任何邻域都不同胚于 $\mathbb{R}^2$ 的开子集——顶点「尖」得无法拉平。所以单圆锥不是曲面。
- **两个平面粘于一点**：粘点处没有欧氏邻域（去掉粘点，邻域会裂成两个分支，而 $\mathbb{R}^2$ 去掉一点仍连通）。它不是流形。
- **带「交叉帽」的奇异面**：任何在一点处自交、且交点无法拉开的空间，都会破坏局部欧氏性质。

**辨析｜易错点：** 反例的关键都在「一点处的局部结构」。判别某空间是否为曲面，只需逐点检查局部欧氏性、Hausdorff 性与第二可数性——这是本章所有证明的起点。

## 5 公式解析：坐标卡的局部模型

把「局部欧氏」压缩成一条公式，它是流形论的通用语言：

$$
\forall\, x \in M,\quad \exists\, U \ni x \text{ 开},\ \exists\, V \subseteq \mathbb{R}^2 \text{ 开},\ \exists\, \varphi: U \xrightarrow{\cong} V
$$

逐项拆解：

- **$\forall x \in M$**：条件要对**每个点**成立，一点都不能漏——这正是「局部」二字的精确含义。
- **$U \ni x$ 开**：邻域 $U$ 是 $M$ 的开集，保证同胚 $\varphi$ 能定义在 $x$ 附近。
- **$V \subseteq \mathbb{R}^2$ 开**：像集在欧氏平面里是开集。对带边曲面，允许 $V$ 取自 $\mathbb{H}^2$。
- **$\varphi$ 同胚**：$\varphi$ 连同逆映射都连续，所以 $U$ 与 $V$ 在拓扑上不可区分——「长得像」在这里就是「拓扑同胚」。
- **一句话直觉**：流形 = 每一点都有「欧氏身份证」$\varphi$，把本地风景翻译成平面坐标。

## 6 曲面的局部与整体：一张对照表

流形论的入门者最常卡住的地方，就是「局部欧氏」与「整体结构」的关系。把各曲面放在一起对比：

| 曲面 | 局部模型 | 紧致性 | 边界 | 可定向 |
| --- | --- | --- | --- | --- |
| 平面 $\mathbb{R}^2$ | $\mathbb{R}^2$ | 否 | 无 | 是 |
| 球面 $S^2$ | $\mathbb{R}^2$ | 是 | 无 | 是 |
| 圆盘 $D^2$ | $\mathbb{R}^2$ 或 $\mathbb{H}^2$ | 是 | 有（$S^1$） | 是 |
| 环面 $T^2$ | $\mathbb{R}^2$ | 是 | 无 | 是 |
| 射影平面 $\mathbb{RP}^2$ | $\mathbb{R}^2$ | 是 | 无 | 否 |
| Klein 瓶 $K$ | $\mathbb{R}^2$ | 是 | 无 | 否 |
| Möbius 带 | $\mathbb{R}^2$ 或 $\mathbb{H}^2$ | 否 | 有（$S^1$） | 否 |

注意第一列：**所有曲面在每一点附近的局部模型都一样（都是 $\mathbb{R}^2$ 或 $\mathbb{H}^2$）**，差别完全来自「整体怎么拼」。球面与平面局部不可区分，整体却一个闭一个开；Möbius 带与圆柱面局部相同，整体却一个扭转一个不扭转。

**辨析｜易错点：** 判断一个空间是不是曲面，一定要**逐点**检查。常见的错误是「看整体像」：只要整体像球面或像平面就以为它是曲面。反例：把两个球面沿一点粘起来的「哑铃形」，粘点处局部不是 $\mathbb{R}^2$——它整体像两个球，但那个粘点破坏了流形性质。<span class="marginnote">「整体像」不可靠，「逐点检查」才可靠——这几乎是拓扑学最重要的方法论。它和第七篇提升定理要「局部道路连通」是一回事：局部性质决定整体论证能否进行。</span>

**带边曲面的一个重要性质：** 带边曲面的边界 $\partial M$ 是**曲面上的 $1$ 维流形**——它总是一些互不相交的圆周的并。例如 Möbius 带的边界是一个圆周，带三个洞的曲面边界是三个圆周。这个性质保证「把边界圆粘上圆盘」的操作总是可行的，是下一课连通和与第八篇分类定理的前提。

最后把「流形」与「带边流形」连成一句话：带边曲面可以看作「若干闭曲面各挖一个圆盘再拼接」的产物，而边界圆正是挖出来的口。这个视角让「边界」从一个抽象名词变成可操作的对象，也为第八篇「多边形粘合」提供了直观基础。

**维数为什么从 2 开始重要：** 一维流形只有两种连通情形（直线与圆周），几乎无分类可言；二维给出第一道「分类难题」；三维至今未解。曲面是「分类恰好能完成」的最低维——这使它的理论既完整又深刻，也是「为什么先学二维」的根本答案。

**一个「局部欧氏」的深度例子——锥面为何不行：** 单圆锥（一个顶点连一圈底边）在顶点处，去掉顶点后邻域分裂成上下两片；而 $\mathbb{R}^2$ 去掉一点仍然连通。局部欧氏要求「去掉一个点后仍连通」这类性质处处成立，顶点破坏了它。这个例子也说明：局部欧氏不是「每点附近看起来像」这么简单，它隐含局部性质的种种传递性。

**带边曲面的边界性质再补一句：** $\partial M$ 的每个连通分支都是圆周 $S^1$。这来自「边界点邻域同胚于 $\mathbb{H}^2$ 的 $y = 0$ 部分」：边界是 1 维流形，而紧致无界的 1 维流形必为圆周。

## 7 小结

- **n 维拓扑流形** = Hausdorff + 第二可数 + 局部欧氏；**曲面**即 $n = 2$ 的情形。
- **带边曲面**允许点的邻域同胚于半平面 $\mathbb{H}^2$；边界是曲面的内在结构，非嵌入意义下的边界。
- 球面、环面、射影平面、Klein 瓶、Möbius 带、圆盘构成基本曲面的「动物园」。
- 反例（锥面、双平面粘点）告诉我们局部欧氏性有多苛刻。
- 判别曲面只需逐点检查三条公理。

在下一课，我们将学习曲面的**组合表示**：把曲面剪开、摊平成一个多边形，用「边字」记录粘合方式——这是分类定理的核心语言。
