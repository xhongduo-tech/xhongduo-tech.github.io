## 为什么「扩张」是重要的问题

给定闭集 $A$ 上的连续函数 $f : A \to \mathbb{R}$，能否把它「无痛」地扩张成全空间 $X$ 上的连续函数 $F$，使得 $F|_A = f$？这不是 trivial 的：$f$ 只在 $A$ 上有定义，要扩展到 $A$ 外而不破坏连续性，需要空间的「配合」。**Tietze 扩张定理**给出完美的回答：**在正规空间里，闭子集上的任何连续函数都能扩张到全空间**。这条定理把「闭集」的重要性凸显出来——闭集上的函数「说了算」，其余部分总能补上。它在泛函分析里对应 Hahn–Banach 定理（连续线性泛函的扩张），是「局部信息能否确定整体」问题的拓扑版本。<span class="marginnote">Tietze 定理是 Urysohn 引理的「函数版」：Urysohn 扩张「常数函数」（$A$ 上 $0$、$B$ 上 $1$），Tietze 扩张「任意连续函数」。两者共享「逐层收紧 + 收敛求和」的证明骨架。</span>

## 1 定理陈述

**Tietze 扩张定理**：设 $X$ 是正规空间，$A \subset X$ 是闭子集。若 $f : A \to [0,1]$（或 $f : A \to \mathbb{R}$）连续，则存在连续函数 $F : X \to [0,1]$（或 $F : X \to \mathbb{R}$）使得

$$F|_A = f$$

即 $F$ 是 $f$ 的全空间连续扩张。

三个要点：

- **$A$ 必须闭**：这是定理的前提。若 $A$ 不开也不闭，扩张可能不存在。
- **陪域 $[0,1]$ 或 $\mathbb{R}$**：都成立。$[0,1]$ 版本是基本形，$\mathbb{R}$ 版本由它伸缩得到（或用逐层扩张到 $\mathbb{R}$）。
- **正规性是充分条件**：正规空间保证「闭集上的函数可扩张」。

**辨析｜易错点：** 扩张的唯一性不保证——一般有无穷多个扩张。$F$ 在 $A$ 外可以「变形」，只要整体连续。唯一的例外是在「稠密子集」上扩张是唯一的（Hausdorff），但那是「稠密」的情形，与「闭」的情形不同。<span class="marginnote">「闭集上扩张」与「稠密集上扩张」是两个互补的命题：闭集保证存在性（Tietze），稠密集保证唯一性（连续函数在稠密子集上相等则整体相等）。一个管「能扩张」，一个管「扩张唯一」。</span>

## 2 证明思路：逐层逼近

Tietze 定理的证明（Munkres §35）是 Urysohn 引理的迭代应用，核心思想是「**逐层修正**」：

**第一步，把 $f$ 逼近到更小的值域**。设 $f : A \to [-1, 1]$（先证陪域 $[-1,1]$）。定义

$$A_0 = f^{-1}\left(\left[-1, -\frac{1}{3}\right]\right), \qquad B_0 = f^{-1}\left(\left[\frac{1}{3}, 1\right]\right)$$

$A_0, B_0$ 是 $A$ 中的不交闭集（$f$ 连续，原像闭）。由于 $A$ 闭，$A_0, B_0$ 在 $X$ 中也闭。由 Urysohn 引理，存在 $g_0 : X \to [-1/3, 1/3]$ 连续，使 $g_0 \equiv -1/3$ 在 $A_0$ 上、$g_0 \equiv 1/3$ 在 $B_0$ 上。于是「$f - g_0$」在 $A$ 上的值域缩进 $[-2/3, 2/3]$——第一层修正完成。<span class="marginnote">第一层的关键是把值域「压」小：$g_0$ 在「负区」与「正区」各取 $\mp 1/3$，使得 $f - g_0$ 在 $A$ 上的振幅从 $2$ 缩到 $4/3$。每层的压缩比是 $2/3$。</span>

**第二步，迭代压缩**。对 $f - g_0$ 重复同样操作，得 $g_1$（值域 $[-2/9, 2/9]$），使 $f - g_0 - g_1$ 在 $A$ 上的值域缩进 $[-4/9, 4/9]$。逐层下去，得函数列 $g_0, g_1, g_2, \ldots$，第 $n$ 个的值域 $[-(2/3)^n/3, (2/3)^n/3]$，且

$$\left| f(x) - \sum_{i=0}^{n} g_i(x) \right| \le \left(\frac{2}{3}\right)^{n+1} \quad \text{对 } x \in A$$

**第三步，求和取极限**。定义 $F = \sum_{i=0}^{\infty} g_i$。由压缩比 $2/3 < 1$，级数**一致收敛**（Weierstrass M-检验），故 $F$ 连续（一致收敛的连续函数列之极限连续）。在 $A$ 上，$F(x) = \lim \sum g_i(x) = f(x)$（误差趋于 0）。∎

这个「逐层修正 + 几何级数收敛」的证明，是分析「逼近论」的经典模板。

## 3 直接推论

Tietze 定理有一串漂亮推论：

- **陪域 $\mathbb{R}$ 版本**：$f : A \to \mathbb{R}$ 连续 ⟹ 扩张到 $F : X \to \mathbb{R}$。从 $[0,1]$ 版本用同胚 $\mathbb{R} \cong (0,1)$ 伸缩并处理边界。
- **「正规空间有足够多连续函数」的加强**：不仅 Urysohn 函数（常值二分），任何闭集上的连续函数都能整体化。
- **度量化定理的桥梁**：Tietze 与 Urysohn 一起，为「第二可数正则 ⟹ 可度量化」提供「构造足够多函数」的手段。
- **泛函分析的类比**：Hahn–Banach 定理（连续线性泛函的保范扩张）是 Tietze 在「向量空间 + 连续线性映射」语境下的远亲——两者都是「局部可扩张 ⟹ 整体可扩张」的存在性定理。<span class="marginnote">Tietze 与 Hahn–Banach 的类比是拓扑与分析的一次对望：闭集（拓扑）对应闭子空间（泛函），连续函数对应连续线性泛函，扩张定理对应扩张定理。这种「结构保扩张」的思想贯穿数学。</span>

## 4 公式解析：逐层逼近的压缩比

核心的迭代不等式

$$\left| f(x) - \sum_{i=0}^{n} g_i(x) \right| \le \left(\frac{2}{3}\right)^{n+1} \quad (x \in A)$$

- **第一步，读误差**：第 $n$ 层修正后，$A$ 上的误差 $\le (2/3)^{n+1}$——随 $n$ 指数衰减到 $0$。
- **第二步，读压缩机制**：每层 Urysohn 函数把值域压到前层的 $2/3$。压缩比 $2/3 < 1$ 保证几何级数收敛。
- **第三步，一致收敛**：$\sum \|g_i\|_\infty \le \sum (2/3)^i / 3 < \infty$，由 M-检验级数一致收敛，极限连续。

## 5 辨析｜易错点（续）

**辨析｜易错点：** Tietze 定理有四个高频误区：

- **$A$ 必须闭**：$A = (0,1) \subset \mathbb{R}$ 上 $f(x) = 1/x$ 无法扩张到 $[0,1]$——非闭子集上连续函数可能「爆炸」。Tietze 的前提是闭。
- **正规性是充分非必要**：存在非正规空间里某些闭子集的函数也能扩张；但「一切闭子集的连续函数都可扩张 ⟹ 正规」（Munkres §35 习题），所以正规几乎也是必要的。
- **扩张不唯一**：$A$ 外的值可以自由调整。别以为扩张是「唯一最佳」的。
- **陪域 $[0,1]$ 与 $\mathbb{R}$ 的证明有差别**：$[0,1]$ 是紧区间、$[-1,1]$ 压缩到 $[-1/3,1/3]$ 时边界无碍；$\mathbb{R}$ 版本要处理「值域无界」的收敛问题，证明更精细。

## 6 小结

- **Tietze 扩张定理**：正规空间闭子集上的连续函数可扩张到全空间（陪域 $[0,1]$ 或 $\mathbb{R}$）。
- **证明骨架**：Urysohn 逐层修正 + 压缩比 $2/3$ + 一致收敛。
- **意义**：闭集是连续函数的「决定性」部分；正规空间「函数足够多」的加强版。
- **推论**：$f: A \to \mathbb{R}$ 版本、与 Hahn–Banach 的类比。
- **易错**：$A$ 必须闭；扩张不唯一；正规性是前提。
- **记忆锚点**：闭集管「存在性」（Tietze）、稠密集管「唯一性」——两个互补的扩张定理。
- **逼近论内核**：逐层修正 + 几何级数收敛（压缩比 $2/3$）——「误差指数衰减」的方法论示范。
- **跨课连接**：与 Hahn–Banach 定理（连续线性泛函扩张）的类比。
- **判定练习**：$A = \{0\}$ 是 $\mathbb{R}$ 的闭子集，$f(0) = 5$ 连续；Tietze 给 $F: \mathbb{R}\to\mathbb{R}$ 连续且 $F(0)=5$——平凡但验证了定理（$F \equiv 5$ 即可）。
- **本课一句话**：闭子集上的连续函数说了算，其余部分总能无痛补上——正规性的「函数红利」。
- **自测**：$A = \mathbb{Q} \cap [0,1]$ 是 $[0,1]$ 的闭子集吗？否——Tietze 定理不适用（$A$ 非闭），这正好说明「闭」是前提。
- **证明一句话**：Urysohn 逐层修正 + 压缩比 $2/3$ + 一致收敛——「误差指数衰减」的逼近模板。
- **Tietze 与 Urysohn 的关系**：Tietze 是 Urysohn 引理的「任意函数版」——Urysohn 造「常值二分」函数，Tietze 造「任意连续」函数。
- **扩展方向**：陪域 $\mathbb{R}^n$、赋范空间的 Tietze 定理也成立（逐坐标扩张）——「向量值扩张」是它的直接推广。

在下一节，我们将用 Urysohn 引理与 Tietze 定理，攀登度量化理论的高峰：**Urysohn 度量化定理**。

### Tietze 定理的「逼近论」解读

Tietze 证明的「逐层修正 + 一致收敛」是逼近论的标准模板，值得提炼成通用方法：

- **分解成「可修正」的块**：把 $f$ 拆成「需要修正的部分」与「修正函数」$g_i$，每块都把误差压缩到前层的 $2/3$。
- **几何级数收敛**：$\sum (2/3)^i$ 收敛 ⟹ 修正函数列一致收敛 ⟹ 极限连续。
- **应用**：这个「逐层逼近」方法在数值分析（迭代法）、调和分析（Fourier 级数收敛）、泛函分析（投影定理）里反复出现——「误差指数衰减」是一切逼近方法的内核。

Tietze 定理因此不只是拓扑定理，更是「把局部函数逼近到整体」的方法论示范。

### 「闭子集」为何关键：反例

为什么 Tietze 要求 $A$ 闭？看反例：

- $A = (0,1) \subset \mathbb{R}$（不开不闭），$f(x) = \sin(1/x)$。$f$ 在 $A$ 上连续，但 $x \to 0^+$ 时剧烈震荡，**无法**扩张到含 $0$ 的全空间（任何扩张在 $0$ 处都不连续）。
- $A = \mathbb{Q} \subset \mathbb{R}$，$f(q)$ 是「$q$ 的二进制展开」——定义在稠密但非闭的 $\mathbb{Q}$ 上，无法连续扩张。
- 反例说明：「闭」不是装饰——它保证「$A$ 的极限点都在 $A$ 内」，$f$ 在 $A$ 边界处的行为已被约束，可被平滑接续。

「闭 ⟹ 可扩张、稠密 ⟹ 扩张唯一」——Tietze 与「稠密唯一性」定理正好互补，覆盖了「子集上函数扩张」的两个侧面。
