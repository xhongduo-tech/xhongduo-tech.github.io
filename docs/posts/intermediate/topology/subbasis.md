## 为什么基还不够「小」

上一节我们把基搬上生产线，拼出了欧氏拓扑与序拓扑。基已经比开集族小得多——可拓扑学家是贪心的：基是一堆「砖块」，砖块本身还得一个个开列出来。能不能用**更少的原料**，甚至只指定一小撮集合，就让整个拓扑自己长出来？答案藏在「支点」的比喻里：阿基米德说给我一个支点能撬起地球；**子基（subbasis）** 就是拓扑世界里的那个支点——只需极少数集合，就能撬起整座开集大厦。

为什么要这么省？因为有些拓扑**天然就适合用少量集合来指定**。比如积拓扑：定义积空间最省事的办法，是指定「每个坐标方向的投影开集」作为生成器，而不必列出所有开矩形。子基正是为这种「以少驭多」的场景量身定做的。它的口号可以概括成一句话：**给出最少的种子，让拓扑自己长齐。**

## 1 子基的定义：先有限交、再任意并

**子基（subbasis）**：设 $\mathcal{S}$ 是 $X$ 的一族子集（对它的成员，我们暂不要求「开」）。令
$$\mathcal{B} = \{ S_1 \cap S_2 \cap \cdots \cap S_n \mid n \ge 1, \ S_i \in \mathcal{S} \} \cup \{ X \}$$
即 $\mathcal{S}$ 中**全体有限交**的集合，外加一个 $X$（称为「空交」的约定）。若 $\mathcal{B}$ 是 $X$ 上某个拓扑的基，则这个拓扑称为**由 $\mathcal{S}$ 生成的拓扑**，记作 $\mathcal{T}_{\mathcal{S}}$，而 $\mathcal{S}$ 被称为该拓扑的一个**子基**。

由上一节的生成规则，$\mathcal{T}_{\mathcal{S}}$ 中的开集就是「有限交的任意并」：
$$U \in \mathcal{T}_{\mathcal{S}} \iff U = \bigcup_{\alpha} \big( S_{\alpha,1} \cap \cdots \cap S_{\alpha, n_\alpha} \big), \qquad S_{\alpha, k} \in \mathcal{S}$$

这里有三个容易绊脚的点，逐个说清：

- **空交约定**：所谓「零个集合的交」按约定等于 $X$。这是给覆盖条件兜底——没有它，$\mathcal{B}$ 里可能没有任何集合含某个点，基就缺了「盖满」的能力。<span class="marginnote">「空交 = $X$」看起来像一条人为规定，其实是与「空并 = $\emptyset$」对偶的自然约定：并的交集操作都有一个「中性元」，空并对空集、空交对全集。约定它，比处处特殊处理端点干净得多。</span>
- **有限交，不是无限交**：$\mathcal{B}$ 只收**有限**多个 $\mathcal{S}$ 成员的交。因为开集公理只保证有限交开，无限交开不出来——这与我们在余有限拓扑里看到的「有限与无限的分水岭」是同一道坎。
- **子基成员未必事先开**：$\mathcal{S}$ 里的集合在被生成之前，并不要求属于任何拓扑；生成之后，每个 $S \in \mathcal{S}$ 都是 $\mathcal{T}_{\mathcal{S}}$ 的开集（见第 4 节）。

## 2 为什么不能直接「任意并」

一个自然的念头是：既然基直接取「任意并」就得到拓扑，那子基也直接取「任意并」不就行了？**不行。** 直接取并，得到的族可能连「有限交」都守不住。

**辨析｜易错点：**看一个最小反例。$X = \{ a, b, c \}$，取 $\mathcal{S} = \{ \{a,b\}, \{b,c\} \}$。若直接取 $\mathcal{S}$ 的任意并，得到族
$$\{ \emptyset,\ \{a,b\},\ \{b,c\},\ \{a,b,c\} \}$$
它含 $\emptyset$ 与 $X$，对并封闭，但 $\{a,b\} \cap \{b,c\} = \{b\} \notin$ 该族——**有限交不封闭，不是拓扑**。$b$ 这个点被两块砖交叠处「漏」了出去。而走「先有限交」的流程：$\mathcal{B}$ 里就有 $\{a,b\} \cap \{b,c\} = \{b\}$，于是 $\{b\}$ 也成了开集，问题瞬间解决。<span class="marginnote">这个反例值得记一辈子：它说明「任意并」这一操作对拓扑公理并不「安全」，必须先在砖块层面把「交」这个洞补上。子基的两步流程——有限交、再任意并——正是在回答「如何安全地以小搏大」。</span>

所以子基的生成必须分两步：**第一步，有限交，把砖块之间的缝补严；第二步，任意并，把所有补严的砖块拼成开集。** 基只走了第二步，因为它的砖块天生补严了（相交条件）；子基的砖块不管三七二十一，得靠第一步先补严。

## 3 有限交族恰好是基

把第一步说成定理，就是子基理论的心脏：

**定理**：设 $\mathcal{S}$ 是 $X$ 的任意一族子集，令 $\mathcal{B}$ 为 $\mathcal{S}$ 的全体有限交（含空交 $X$），则 $\mathcal{B}$ 是 $X$ 上某个拓扑的基。

验证上一节的两条判定条件：

- **覆盖条件**：$X$ 本身属于 $\mathcal{B}$（空交约定），而 $X$ 当然含每个点，覆盖条件不攻自破。
- **相交条件**：设 $x \in B_1 \cap B_2$，其中
$$B_1 = S_1 \cap \cdots \cap S_n, \qquad B_2 = T_1 \cap \cdots \cap T_m$$
都是有限交。那么
$$B_1 \cap B_2 = S_1 \cap \cdots \cap S_n \cap T_1 \cap \cdots \cap T_m$$
仍是 $\mathcal{S}$ 的**有限交**，故它属于 $\mathcal{B}$；又 $x$ 在 $B_1 \cap B_2$ 里，取 $B_3 = B_1 \cap B_2$ 即可。相交条件以最省事的方式通过——**因为 $\mathcal{B}$ 按定义对有限交封闭，两块砖的交叠区本身就是一块砖。**

**辨析｜易错点：**注意这里的论证不需要 $\mathcal{S}$ 满足任何前置条件——它甚至可以是空集。$\mathcal{S} = \emptyset$ 时，全体有限交只有一个「空交」$X$，于是 $\mathcal{B} = \{ X \}$，生成的拓扑是平凡拓扑 $\{ \emptyset, X \}$。这说明子基的定义「宽」到什么程度：随便抓一族子集，都能成为某个拓扑的子基。<span class="marginnote">这与基的判定条件形成鲜明对照：基要先验地满足覆盖与相交，子基则「零门槛」入场。代价是生成流程多一步——子基是「先交后并」两拍子，基是「直接就并」一拍子。</span>

## 4 公式解析：子基生成的是「包含 $\mathcal{S}$ 的最粗拓扑」

子基生成的拓扑有一个漂亮的刻画，它把「生成」这个词的数学含义彻底说透：

> **定理**：$\mathcal{T}_{\mathcal{S}}$ 是 $X$ 上**包含 $\mathcal{S}$ 的一切拓扑中，最粗的那一个**（即包含于任何其他包含 $\mathcal{S}$ 的拓扑）。

拆成三步证明。

- **第一步，$\mathcal{T}_{\mathcal{S}}$ 确实包含 $\mathcal{S}$**：任取 $S \in \mathcal{S}$，它是一段「单项有限交」（$n = 1$），所以 $S \in \mathcal{B}$；而 $\mathcal{B}$ 的成员当然都是 $\mathcal{T}_{\mathcal{S}}$ 的开集。故 $\mathcal{S} \subseteq \mathcal{T}_{\mathcal{S}}$。
- **第二步，任何包含 $\mathcal{S}$ 的拓扑都得吞下所有有限交**：设 $\mathcal{T}'$ 是任意一个包含 $\mathcal{S}$ 的拓扑。拓扑对**有限交**封闭，所以每个有限交 $S_1 \cap \cdots \cap S_n$（$S_i \in \mathcal{S}$）都在 $\mathcal{T}'$ 里；拓扑又对**任意并**封闭，所以这些有限交的任意并也在 $\mathcal{T}'$ 里。于是
$$\mathcal{T}_{\mathcal{S}} = \{ \text{有限交的任意并} \} \subseteq \mathcal{T}'$$
- **第三步，读结论**：$\mathcal{T}_{\mathcal{S}}$ 包含于**每一个**包含 $\mathcal{S}$ 的拓扑，即它是最粗（开集最少）的那个。证毕。

这三步的节奏是：**先承认自己含 $\mathcal{S}$，再看别人必须吞多少，最后发现别人吞的比我还多。** 「最粗」的直觉：子基生成拓扑时，只做不得不做的两件事（有限交、任意并），绝不额外多造一个开集。它把「指定少数集合」与「最小开销地扩张成拓扑」这两件事缝成了一个定理。

这个刻画还有一个等价的表述：$\mathcal{T}_{\mathcal{S}}$ 等于**所有包含 $\mathcal{S}$ 的拓扑之交集**。因为「所有包含 $\mathcal{S}$ 的拓扑之交」既包含 $\mathcal{S}$、又最粗，由唯一性必与 $\mathcal{T}_{\mathcal{S}}$ 重合。两种说法，同一件事。

## 5 例子：少数集合撬起整个拓扑

**例一：实数轴的两种射线。** 设 $X = \mathbb{R}$，取
$$\mathcal{S} = \{ (-\infty, a) \mid a \in \mathbb{R} \} \cup \{ (b, +\infty) \mid b \in \mathbb{R} \}$$
即全体「左射线」与「右射线」。它们的有限交正是开区间：$(-\infty, a) \cap (b, +\infty) = (b, a)$（当 $b < a$），而射线本身也在。于是 $\mathcal{T}_{\mathcal{S}}$ 就是通常拓扑。**整个实数轴的拓扑，竟能被两类射线完全生成**——这是子基最震撼的例子：不需要区间，只要「小于某数」与「大于某数」两种集合。

**例二：积拓扑的预告。** 设 $X = X_1 \times X_2$，$Y_i$ 是 $X_i$ 的开集，取
$$\mathcal{S} = \{ \pi_1^{-1}(U_1) \mid U_1 \subseteq X_1 \text{ 开} \} \cup \{ \pi_2^{-1}(U_2) \mid U_2 \subseteq X_2 \text{ 开} \}$$
其中 $\pi_i$ 是向第 $i$ 个坐标的投影。有限交 $\pi_1^{-1}(U_1) \cap \pi_2^{-1}(U_2) = U_1 \times U_2$ 恰好是开矩形，于是生成积拓扑。**积拓扑的「矩形基」，在子基语言里就是两条投影的并**——第二篇《积拓扑》将以此为起点，一路推广到无限多个因子。<span class="marginnote">投影原像 $\pi_i^{-1}(U_i)$ 是「只看第 $i$ 个坐标落在 $U_i$」的圆柱体集合。用它当子基，等于声明：积空间的拓扑由「每个坐标方向各自说了算」的集合生成。这是理解无限积空间的关键开关。</span>「用投影原像当生成器」这套语言，在第二级《概率论与数理统计》里同样眼熟：随机变量的「事件域」正是由「只约束单个坐标」的原像集合生成的——子基给积空间配的语法，概率论早就在用。

**例三：单点集生成离散拓扑。** $\mathcal{S} = \{ \{x\} \mid x \in X \}$。两个不同单点的交为空，空交得 $X$，于是 $\mathcal{B}$ 含所有单点与 $X$；任意并给出所有子集，即离散拓扑。

**例四：余有限拓扑的再发现。** $\mathcal{S} = \{ X \setminus \{x\} \mid x \in X \}$。有限交 $ (X \setminus \{x_1\}) \cap \cdots \cap (X \setminus \{x_n\}) = X \setminus \{x_1, \dots, x_n\}$ 是「挖掉有限个点」的集合——这正是余有限拓扑的基。我们绕了一大圈，用子基又把它造了出来，可见同一拓扑可以有许多不同的「出身」。

这四个例子里，例一与例二尤其值得品味：它们都是**用一个很自然的子基，把一种「本就存在」的拓扑干净地再生**出来。子基不只是造新拓扑的机器，也是理解老拓扑的新眼镜——换个生成器，往往能把某个拓扑的「本性」照得更亮。

## 6 基与子基：对照表

把两种生成器摆在一起，各自的性格一目了然：

| 项目 | 基（Basis） | 子基（Subbasis） |
| --- | --- | --- |
| 生成流程 | 任意并 | 有限交 → 任意并 |
| 前置条件 | 覆盖 + 相交 | 无（任意一族子集） |
| 成员何时开 | 直接是开集 | 生成之后才开 |
| 需要的原料 | 较多（砖块级） | 极少（支点级） |
| 典型用途 | 描述已有拓扑 | 指定新拓扑（积拓扑、初始拓扑） |

这张表回答了「为什么有了基还要子基」：**基是给已经存在的拓扑找一套方便的砖；子基是给还不存在的拓扑提供一个最省原料的说明书。** 两者接力，正好构成「子基 → 基 → 拓扑」的完整生成链。

## 7 小结

- **子基**：$X$ 的任意一族子集，其全体有限交（含空交 $X$）构成基，生成拓扑 $\mathcal{T}_{\mathcal{S}}$。
- **两步流程**：先有限交把「缝」补严，再任意并拼成开集；直接任意并会漏掉交（$X=\{a,b,c\}$ 反例）。
- **核心定理**：有限交族天然是基——覆盖条件靠空交 $X$，相交条件靠「有限交的交仍是有限交」。
- **最粗刻画**：$\mathcal{T}_{\mathcal{S}}$ 是包含 $\mathcal{S}$ 的最粗拓扑 = 一切包含 $\mathcal{S}$ 的拓扑之交。
- **典型例子**：两种射线生成实数轴通常拓扑；投影原像生成积拓扑（预告）。
- **对照**：基直接「任意并」、子基「先交后并」；基查前置条件，子基零门槛。

在下一节，我们把注意力从「如何生成开集」转向「如何度量一个集合」：**闭包（closure）** 回答「一个集合贴着多少空间」——它是包含该集合的最小闭集，也将是连续映射、稠密性、分离公理等一大串概念的起点。
