## 为什么引入「道路」

连通性说「空间连成一片」，但没有说「怎么连」——两点之间有没有一条**可见的路**？「道路连通」给出了肯定的版本：**任何两点之间都有一条连续道路**（单位区间到空间的连续像）。这个「强连通性」在几何与代数拓扑里无处不在：同伦、基本群（第六篇）全部建立在道路之上；证明一个空间「好」，第一反应就是验证它道路连通。而且道路连通**蕴含连通**，于是它成了判断连通性的常用「入场券」——验证道路连通往往比直接验证连通简单得多。<span class="marginnote">道路是代数拓扑的原子：基本群里的「回路」就是两端重合的道路。理解道路，就是为第六篇的 $\pi_1$ 打地基。Munkres 在 §24 引入道路，紧接着就用它证明 $\mathbb{R}^n$、$S^n$ 等大空间的道路连通性。</span>

## 1 道路的定义

**道路（path）**：设 $X$ 是拓扑空间。**道路**是从单位区间到 $X$ 的连续映射

$$\sigma : [0, 1] \to X$$

$\sigma(0)$ 称为道路的**起点**，$\sigma(1)$ 称为**终点**。道路是**映射**，不是「轨迹」——同一条轨迹可以有不同的参数化，参数化不同的道路视为不同道路。

**道路连通空间（path-connected space）**：若对任意 $x_0, x_1 \in X$，都存在道路 $\sigma$ 使 $\sigma(0) = x_0$、$\sigma(1) = x_1$，则称 $X$ **道路连通**。

看例子：

- **$\mathbb{R}^n$ 道路连通**：任两点 $x_0, x_1$，直线段 $\sigma(t) = (1-t)x_0 + t x_1$ 是连续道路（凸组合），且 $\sigma(0) = x_0$、$\sigma(1) = x_1$。
- **任何凸集道路连通**：凸性保证直线段留在集内。
- **星形域道路连通**：存在一点能看到全体（线段全在集内），星形域比凸弱一点，但道路连通照成立。
- **$S^n$（$n \ge 1$）道路连通**：$S^1$ 可参数化走圆弧，$S^2$ 可走大圆弧。
- **$\mathbb{Q}$ 不道路连通**：任意两个有理数之间没有「全在 $\mathbb{Q}$ 内的道路」。

**辨析｜易错点：** 道路是映射，图像（轨迹）只是道路的一个副产品。第六篇基本群中「道路的乘法」「逆道路」都是对**映射**操作（参数重排），不是对几何轨迹操作。现在就把「道路 = 映射」这个习惯建立起来。

## 2 道路连通蕴含连通

**定理**：道路连通空间是连通的。

证明：设 $X$ 道路连通。取定 $x_0 \in X$。对每个 $x \in X$，存在道路 $\sigma_x : [0,1] \to X$ 使 $\sigma_x(0) = x_0$、$\sigma_x(1) = x$。$[0,1]$ 连通，$\sigma_x$ 连续，故像 $\sigma_x([0,1])$ 连通（连续像保连通），且含 $x_0$ 与 $x$。于是

$$X = \bigcup_{x \in X} \sigma_x([0,1])$$

每个连通集 $\sigma_x([0,1])$ 都含 $x_0$，两两相交，并保持连通，故 $X$ 连通。<span class="marginnote">证明的图形直觉：从 $x_0$ 出发，向每个点伸出一条道路，所有「道路的像」在起点 $x_0$ 处汇合，互相搭桥连成一片。起点 $x_0$ 是整片网络的枢纽。</span>

推论：**道路连通性是拓扑性质**（同胚保持），且可用于判别不同胚。

## 3 连续映射保持道路连通

**定理（保持）**：$f : X \to Y$ 连续，$X$ 道路连通 ⟹ $f(X)$ 道路连通。

证明：任取 $f(x_0), f(x_1) \in f(X)$，$X$ 道路连通给道路 $\sigma : [0,1] \to X$ 连 $x_0$ 到 $x_1$，则 $f \circ \sigma : [0,1] \to f(X)$ 连续（复合保持连续），连 $f(x_0)$ 到 $f(x_1)$。<span class="marginnote">「道路被连续映射送到道路」——$f\circ\sigma$ 的复合论证只有一行，却让道路连通性像连通性一样成为「沿连续映射传递」的性质。这个传递性是第六篇函子性的先声。</span>

### 道路的代数：逆道路与复合

道路不仅是「连通工具」，还是第六篇基本群的**原子**，因此现在就把道路的代数运算定义清楚：

- **逆道路（reverse path）**：设 $\sigma : [0,1] \to X$ 是道路，定义 $\bar{\sigma}(t) = \sigma(1 - t)$——把参数倒着跑一遍，从终点走回起点。注意 $\bar{\sigma}$ 的轨迹与 $\sigma$ 相同，只是方向相反；在基本群里 $\bar{\sigma}$ 是 $\sigma$ 的逆元候选。
- **复合道路（path concatenation）**：设 $\sigma$ 以 $x_1$ 为终点、$\tau$ 以 $x_1$ 为起点（首尾相接），定义

$$\sigma * \tau (t) = \begin{cases} \sigma(2t), & 0 \le t \le 1/2 \\ \tau(2t - 1), & 1/2 \le t \le 1 \end{cases}$$

前半段以两倍速跑 $\sigma$，后半段以两倍速跑 $\tau$，在 $x_1$ 处平滑衔接。复合道路也是连续道路（拼接点处两段都收敛到 $x_1$）。这两个运算在第六篇定义基本群时直接复用——现在先建立起「道路可加可逆」的代数直觉。

### 道路连通性与同伦的桥梁

道路不仅是「连通工具」，更是第六篇**同伦**的语言基础。这里先立三个桥梁概念：

- **道路 = 同伦的参数**：$f \simeq g$（同伦）是「$f$ 连续变形到 $g$」，其严格定义是一条「路径」$H : X \times [0,1] \to Y$——在**映射空间**里走一条道路。所以「道路」的概念是「映射之间也能走道路」的出发点。
- **回路（loop）**：起点终点重合的道路，即 $\sigma(0) = \sigma(1)$。回路的全体是第六篇基本群的元素候选。
- **道路的同伦类**：以「保端点同伦」为等价关系，把道路分类。基本群就是在「回路类」上定义群结构。

「从极限到大模型」主线里的「同伦」直觉——「拓扑性质在连续变形下不变」——正是从「道路」这个最小连续变形单元一步步搭建的。现在把「道路可逆、可复合」练熟，第六篇就能直接进入群结构验证。

### 道路连通与弧连通的界线

「道路连通」要求两点间有连续道路，但不要求道路「不重复」。更强的版本是**弧连通（arc-connected）**：要求存在**单射**的连续道路（即轨迹是「干净的一段」）连接两点。

- **弧连通 ⟹ 道路连通**：显然，单射道路也是道路。
- **道路连通 ⟹ 弧连通（在好空间里）**：若 $X$ 是 Hausdorff 空间且道路连通，则 $X$ 弧连通（可以把自交的道路「修剪」成单射道路）。Munkres 定理 24.1 证明了这个结论。
- **一般空间的反例**：非 Hausdorff 空间里存在道路连通但非弧连通的空间（如「双点化」的某空间）。

这条界线告诉我们：在分析、几何、代数拓扑的「常见空间」（Hausdorff）里，道路连通与弧连通通常不区分；但「修剪道路」这一论证不是免费的，它依赖 Hausdorff 性。

### 道路连通的「商空间」陷阱

商空间的道路连通性有一个经典陷阱：**$X$ 道路连通 ⟹ $X/\sim$ 道路连通**（商映射是连续满射，连续像保道路连通），但**反过来不成立**——即使 $X/\sim$ 道路连通，$X$ 也可能不道路连通。

- 例：$X$ 是两根互不相交的线段，把每根线段的左端点粘到一点。商空间「V 形」道路连通，但 $X$ 是两根分离线段，不道路连通。
- 教训：**商映射「焊合」道路，不能逆推原空间的道路连通性**。与连通性的情形一致——商映射只向一个方向传递。

遇到「$X/\sim$ 道路连通 ⟹ $X$ 道路连通」的推理，务必停下检查方向。这是商空间理论里最常见的误用之一。

同样的「乘积保持」也成立：$X, Y$ 道路连通 ⟹ $X \times Y$ 道路连通（把两坐标道路并成 $\sigma(t) = (\sigma_1(t), \sigma_2(t))$）。

## 4 公式解析：直线段道路

凸集里最标准的道路是直线段：

$$\sigma(t) = (1 - t)\,x_0 + t\,x_1, \qquad 0 \le t \le 1$$

- **第一步，读系数**：$t$ 从 $0$ 到 $1$ 变化，$x_0$ 的权重 $(1-t)$ 从 $1$ 降到 $0$，$x_1$ 的权重 $t$ 从 $0$ 升到 $1$。$\sigma$ 从 $x_0$ 匀速滑向 $x_1$。
- **第二步，连续性**：$\sigma$ 是坐标的线性组合，坐标连续、组合连续，故 $\sigma$ 连续（多元函数连续性）。
- **第三步，凸性保证**：若 $X$ 凸，则对一切 $t$ 有 $\sigma(t) \in X$，直线段全程留在 $X$ 内——这就是「凸集道路连通」的完整证明。

## 5 辨析｜易错点（续）

**辨析｜易错点：** 道路连通有四个高频误区：

- **道路连通 ⟹ 连通，反之不真**：反例是拓扑学家的正弦曲线（下一课）。「连通但不道路连通」是存在的，别把两者划等号。
- **道路是映射不是轨迹**：同一个圆环可以有无穷多道路（不同速度、不同起跑点）。判断「存在道路」时，只要存在一个连续映射即可，轨迹不必「干净」（可以自交、可以重复）。
- **道路连通 ≠ 弧连通**：要求道路**单射**（弧）是更强的「弧连通」，两者在好空间（Hausdorff）里常等价，但一般空间有差别。
- **道路连通的像、积都保**：连续像保道路连通、积保道路连通，但**商空间的道路连通**需要额外论证——商映射是连续满射，$p(X)$ 道路连通，但商空间本身的道路连通要逐例验证。

## 6 小结

- **道路**：连续映射 $\sigma : [0,1] \to X$；道路是映射，轨迹只是副产品。
- **道路连通**：任意两点由道路相连；$\mathbb{R}^n$、凸集、星形域、$S^n$（$n\ge1$）道路连通。
- **蕴含关系**：道路连通 ⟹ 连通；反之不真。
- **保持性**：连续像、乘积都保持道路连通。
- 道路是第六篇同伦与基本群的原子结构。

在下一节，我们将面对那个著名的「反之不然」：**拓扑学家的正弦曲线**——连通却完全没有道路连通性的怪兽。
