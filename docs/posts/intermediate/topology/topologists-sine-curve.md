## 为什么需要这个「怪兽」

第三篇里我们证明了**道路连通 ⟹ 连通**，但反过来是否成立？直觉上「连成一片的空间，两点之间总该有条路」——可惜直觉在这里失效。**拓扑学家的正弦曲线**是「连通但不道路连通」的最著名反例，它把「连通」与「道路连通」之间的鸿沟精确地展示出来：这个空间看起来像一条不断振荡、贴着 $y$ 轴来回摆动的曲线，它整体连通（因为振荡部分与竖直段通过「闭包」粘连），却没有任何一条道路能连起振荡部分与竖直段。这个反例是点集拓扑的「成人礼」——它迫使你放弃「连通 ≈ 可到达」的幼稚直觉。<span class="marginnote">「拓扑学家的正弦曲线」是 20 世纪拓扑学最著名的病态空间之一。它的存在告诉我们：连通性是「开集层面的粘」，道路连通性是「映射层面的通」——两者是不同深度的事。</span>

## 1 正弦曲线的定义

**拓扑学家的正弦曲线（topologist's sine curve）**：设

$$S = \operatorname{cl}\bigl(\{(x, \sin(1/x)) \mid 0 < x \le 1\}\bigr) \subset \mathbb{R}^2$$

即「振荡曲线」$\{(x, \sin(1/x)) \mid 0 < x \le 1\}$ 的**闭包**。

这条曲线由两部分组成：

- **振荡部分** $G = \{(x, \sin(1/x)) \mid 0 < x \le 1\}$：$x \to 0^+$ 时，$\sin(1/x)$ 在 $[-1,1]$ 之间无穷次振荡，频率趋于无穷。
- **竖直段** $L = \{0\} \times [-1, 1]$：振荡的「极限」——当 $x \to 0$，曲线在 $y$ 轴附近来回扫过整段 $[-1,1]$，闭包把这段「竖直墙」补上。

$S = G \cup L$。$G$ 是 $S$ 的稠密开子集（去掉 $L$），$L$ 是「极限」的承载者。<span class="marginnote">直观图像：从 $(1, \sin 1)$ 出发，曲线向左振荡越来越快，像一条无限折叠的毛巾，最终「贴」在 $y$ 轴上的整段 $[-1,1]$。竖直段 $L$ 是振荡的「极限墙」。</span>

## 2 S 是连通的

**命题**：拓扑学家的正弦曲线 $S$ 是连通的。

证明：

- **$G$ 连通**：$G$ 是 $(0,1]$ 在连续映射 $x \mapsto (x, \sin(1/x))$ 下的像，$(0,1]$ 连通、连续像保连通 ⟹ $G$ 连通。
- **$S = \operatorname{cl} G$**：由定义，$S$ 正是 $G$ 的闭包。
- **闭包保连通**：$G$ 连通 ⟹ $\operatorname{cl} G$ 连通（第三篇「闭包保持连通」工具）。

三步拼起来：$S$ 连通。∎

注意这个证明的关键是「闭包保连通」——$S$ 的连通性来自 $G$ 与其闭包的「粘合」。$G$ 与 $L$ 本身「互不相连」（没有公共点），但 $L \subset \operatorname{cl} G$，闭包操作把两者「焊」成一个连通整体。<span class="marginnote">「$G$ 连通、$L \subset \operatorname{cl}G$，故 $G \cup L$ 连通」——这是「闭包保连通」的标准应用。竖直段 $L$ 虽然不是 $G$ 的一部分，却是 $G$ 的「极限」，闭包把它并入整体。</span>

## 3 S 不是道路连通的

**命题**：拓扑学家的正弦曲线 $S$ **不**道路连通——不存在连续道路从 $L$ 走到 $G$。

证明思路（反证）：设 $\sigma : [0,1] \to S$ 是一条道路，起点 $\sigma(0) \in L$、终点 $\sigma(1) \in G$。设 $t_0$ 是「第一次离开 $L$」的时刻：

- 记 $t_0 = \inf\{t \mid \sigma(t) \notin L\}$，则 $\sigma(t_0) \in L$（$L$ 闭），且对任意 $t > t_0$，$\sigma(t) \notin L$ 或可取得足够接近 $G$。
- 道路的连续性要求 $\sigma$ 在 $t_0$ 附近「平滑过渡」，但 $\sin(1/x)$ 在 $x \to 0^+$ 的振荡使曲线无法「贴」到整段 $L$ 上——任何进入 $G$ 的连续路径必须在某点「瞬移」到无穷振荡的一侧，破坏连续性。

严格证明（Munkres §24）：把 $L$ 上的点「压」到第一坐标投影，利用「$\sigma$ 连续 ⟹ $\pi_1 \circ \sigma$ 连续」与「$\sin(1/x)$ 无极限」的矛盾。核心事实是：**$S$ 中没有任何道路的像同时含 $L$ 的点与 $G$ 的点**。∎<span class="marginnote">证明的直觉：要进入 $G$ 就必须「跨」过无穷次振荡，而「跨」的动作在 $x = 0$ 处需要连续地同时到达整段 $[-1,1]$——一条一维道路做不到「同时覆盖无穷多个振荡峰值」。振荡频率无穷，道路只能「卡」在 $L$ 或「跳」进 $G$，无法平滑过渡。</span>

**结论**：$S$ 连通但不道路连通——「道路连通 ⟹ 连通」的逆命题不成立。

## 4 公式解析：闭包把 G 与 L 焊起来

$$S = \operatorname{cl}(G), \qquad G = \{(x, \sin(1/x)) \mid 0 < x \le 1\}, \qquad L = \{0\} \times [-1,1]$$

- **第一步，读 $G$**：振荡曲线的点集，$x > 0$，取值 $\sin(1/x) \in [-1,1]$。
- **第二步，读 $\operatorname{cl}$**：闭包加入所有极限点——$x \to 0$ 时曲线扫过 $[-1,1]$ 的每个值，故整段 $L$ 都是 $G$ 的极限点。
- **第三步，读粘合**：$S = G \cup L$，$L$ 虽与 $G$ 不相交，却是 $G$ 的极限——闭包操作完成「焊接」。
- **为什么道路断**：$G$ 与 $L$ 的「焊接」只在极限层面，不在一维道路可达层面——「开集粘」与「道路通」是两种深度的连接。

## 5 辨析｜易错点（续）

**辨析｜易错点：** 正弦曲线有四个高频误区：

- **「$S$ 连通 ⟹ 任意两点可连」是错的**：$S$ 连通但 $L$ 的点到不了 $G$ 的点。连通 ≠ 道路连通。
- **「闭包保连通」在这里是「保」不是「造路」**：闭包把 $L$ 并入连通整体，但不保证「有道路」。
- **去掉 $L$ 后 $G$ 是连通的但「敞开」**：$G$ 连通，$S = \operatorname{cl}G$ 连通，但 $G$ 与 $L$ 之间「无路」。
- **正弦曲线不局部连通**：$L$ 上的点的邻域都不连通——这是「连通但处处不局部连通」的例子，也是「局部连通」概念的动机之一。

## 6 小结

- **定义**：$S = \operatorname{cl}\{(x, \sin(1/x)) \mid 0 < x \le 1\}$，含振荡部分 $G$ 与竖直段 $L$。
- **连通**：$G$ 连通 + 闭包保连通 ⟹ $S$ 连通。
- **不道路连通**：$L$ 与 $G$ 之间无道路——振荡频率无穷阻止一维道路跨越。
- **教训**：连通 ≠ 道路连通；「开集粘」与「道路通」是不同深度。
- **意义**：点集拓扑最著名的反例之一，也是「局部连通」的动机。
- **记忆锚点**：连通靠闭包、道路断在振荡。
- **自测**：$S$ 去掉竖直段 $L$ 后还连通吗？是（$G$ 本身连通）；还道路连通吗？是（$G$ 同胚于 $(0,1]$）。
- **自测**：$S$ 的分支数？一个连通分支、两个道路分支。
- **本课一句话**：正弦曲线是「连通不道路连通」的活证据——闭包粘住、道路断掉。
- **跨课连接**：这个反例在第六篇基本群（道路分支）、第八篇曲面理论（局部连通）里反复被引用。
- **证明要义**：连通靠「$G$ 连通 + 闭包保连通」；不道路连通靠「振荡频率无穷阻断一维道路」。
- **图像记忆**：无限折叠的毛巾贴上竖直墙——整体是布的，却走不到墙。
- **易错警示**：别把「$G$ 稠密于 $S$」误当「$G$ 道路连通 $S$」——稠密是开集层面，道路是映射层面。
- **本节定位**：连通性的收尾——「连通 ⟹ 道路连通」被证伪，两个概念正式分家。
- 第三篇至此完结：连通、分支、道路分支、正弦曲线——「整体性」的完整图谱。

在下一节，我们将正式进入基本群的构造：**道路类与道路类的乘法**。

### 正弦曲线的变体与「病态」家族

拓扑学家的正弦曲线不是孤例，它属于一整个「病态连通」家族，对照着看更能把握边界：

- **带振荡的直线（extended sine curve）**：把振荡部分延伸到整个 $x > 0$，闭包加整段 $y$ 轴。同样连通不道路连通。
- **两个正弦曲线的「对接」**：左右各一条振荡曲线共享 $y$ 轴，连通且道路连通（可沿 $y$ 轴走）——同一构造，不同结论。
- **Cantor 集上的病态**：Cantor 集「尘」空间全不连通，与正弦曲线的「连通不道路连通」互补——「病态」可以朝两个方向走。
- **局部连通的缺失**：正弦曲线的 $L$ 上每点没有连通邻域——「处处不局部连通」。这是「局部连通」概念（第三篇末预告）的第一反例。

这张「病态家族」表说明：拓扑学的「反例」不是孤立的怪胎，而是相互映照的坐标系——正是它们逼出了「局部连通」「道路连通」「可缩」等更精细的概念。

### 从反例到「概念进化」的方法论

正弦曲线的历史价值，在于它驱动了拓扑学的概念进化：

- **它逼出「道路连通」**：没有这个反例，「连通」可能一直与「可到达」混为一谈。有了它，两个概念被严格分开。
- **它逼出「局部连通」**：正弦曲线处处不局部连通，让人意识到「局部」性质的独立价值。
- **它预告「基本群」**：基本群研究「回路」——而回路生活在一个道路分支里。正弦曲线有两个道路分支，基本群因此「看不见」跨分支的结构。

「一个反例逼出一个新概念」，是数学发展的典型模式。记住正弦曲线，等于记住「连通 ≠ 可到达」这条拓扑学的第一戒律。
