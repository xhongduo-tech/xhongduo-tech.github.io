## 为什么同伦是代数拓扑的起点

前五篇是「点集拓扑」——研究开集、连续、紧致。从本篇开始进入**代数拓扑**：把拓扑问题翻译成代数问题（群、同态），再用代数计算回答拓扑问题。同伦是这场翻译的第一个工具：**两个映射能否被「连续变形」彼此转化**。如果 $f$ 能连续变形到 $g$，就说它们**同伦**（$f \simeq g$）。这个看似简单的概念引出整个「同伦理论」：同伦等价、可缩空间、基本群……最终回答「空间有没有洞」「洞怎么缠」的问题。<span class="marginnote">同伦是「同胚」的松弛版：同胚要求「双向连续的双射」，同伦只要求「能连续变形」。同一个空间可以有无数同伦类——而同伦类正是代数拓扑的「原子」。</span>

## 1 同伦的定义

**同伦（homotopy）**：设 $f, g : X \to Y$ 是连续映射。若存在连续映射

$$F : X \times [0,1] \to Y$$

使得对每个 $x \in X$，

$$F(x, 0) = f(x), \qquad F(x, 1) = g(x)$$

则称 $F$ 是 $f$ 到 $g$ 的**同伦**，记作 $f \simeq g$。

三点直觉：

- **参数 $t$ 是「时间」**：$F(x, t)$ 在 $t = 0$ 时是 $f(x)$，在 $t = 1$ 时是 $g(x)$，中间 $0 < t < 1$ 是「变形过程」。
- **每个时刻 $F(\cdot, t)$ 都是连续映射**：$F$ 的整体连续性保证「变形过程不撕裂」。
- **同伦是「连续路径」**：在映射空间 $\mathcal{C}(X, Y)$ 里，$f \simeq g$ 意味着「$f$ 与 $g$ 之间有连续道路相连」——$t \mapsto F(\cdot, t)$ 就是那条道路。<span class="marginnote">「$f \simeq g$ ⟺ $f, g$ 在函数空间 $\mathcal{C}(X,Y)$ 的同一道路分支里」——把同伦翻译成函数空间的连通性。这个视角在本篇后面会反复用到：同伦类 = 函数空间的连通分支。</span>

## 2 同伦的等价关系

**命题**：同伦 $\simeq$ 是连续映射族 $\mathcal{C}(X, Y)$ 上的**等价关系**：

- **自反性**：$f \simeq f$——用「静止同伦」$F(x, t) = f(x)$（每个时刻都是 $f$）。
- **对称性**：$f \simeq g$（同伦 $F$）⟹ $g \simeq f$——用「倒带同伦」$F'(x, t) = F(x, 1-t)$。
- **传递性**：$f \simeq g$（同伦 $F$）、$g \simeq h$（同伦 $G$）⟹ $f \simeq h$——用「拼接同伦」：

$$H(x, t) = \begin{cases} F(x, 2t), & 0 \le t \le 1/2 \\ G(x, 2t - 1), & 1/2 \le t \le 1 \end{cases}$$

前半段以两倍速跑 $F$，后半段以两倍速跑 $G$，在 $t = 1/2$ 处衔接（都等于 $g(x)$）。∎

三条性质的证明分别对应「静止、倒带、拼接」三个操作——与道路的「常值、逆、复合」如出一辙。同伦类（equivalence class）由此定义：$[f] = \{g \mid g \simeq f\}$。

**辨析｜易错点：** 同伦的拼接与道路拼接是同构的论证：$t = 1/2$ 处需要「值相等」来保证连续。若 $F(x,1) \neq G(x,0)$，拼接不连续——所以拼接同伦要求「$f \simeq g$ 且 $g \simeq h$」的中间映射 $g$ 一致。

## 3 同伦的例子与意义

- **任何映射同伦于常值映射（在凸集内）**：$f : X \to \mathbb{R}^n$，$Y$ 凸，$f \simeq c_{y_0}$（常值 $y_0$）——直线同伦 $F(x,t) = (1-t)f(x) + t y_0$ 全程留在凸集内。
- **$\mathbb{R}^n$ 里的映射互相同伦**：$f, g : X \to \mathbb{R}^n$ 都同伦于常值，故 $f \simeq g$（传递性）。
- **圆周 $S^1$ 上的「绕圈」**：$f(\theta) = e^{i\theta}$ 与常值映射 $c_1$ **不**同伦——$S^1$ 不是凸集，直线同伦会「穿过原点」逃出 $S^1$。「绕一圈」不能被「拉缩」成「点」，这是 $S^1$ 有洞的第一次显现。
- **道路的同伦**：两条道路 $\sigma, \tau : [0,1] \to X$（起点终点相同）同伦，指「保端点」的同伦 $F$（$F(0,t)$、$F(1,t)$ 固定）。这是基本群的前奏。<span class="marginnote">「$S^1$ 的绕圈映射不可缩」是代数拓扑的第一课：它精确地捕捉了「$S^1$ 有一个洞」的直觉。第六篇的 $\pi_1(S^1) \cong \mathbb{Z}$ 将把这个直觉形式化——绕几圈对应整数几。</span>

## 4 公式解析：直线同伦

凸集里最标准的同伦是直线同伦：

$$F(x, t) = (1 - t)\, f(x) + t\, g(x)$$

- **第一步，读时间参数**：$t = 0$ 时 $F = f$，$t = 1$ 时 $F = g$，中间 $t$ 从 $f(x)$ 线性滑向 $g(x)$。
- **第二步，连续性**：$F$ 是坐标的线性组合，$f, g$ 连续 ⟹ $F$ 连续（积空间的连续映射之线性组合）。
- **第三步，凸性保证**：$Y$ 凸 ⟹ 线段 $(1-t)f(x) + tg(x)$ 全程在 $Y$ 内——直线同伦合法。$S^1$ 不凸，直线同伦「穿出」$S^1$，所以 $S^1$ 的绕圈不能这样缩。

## 5 辨析｜易错点（续）

**辨析｜易错点：** 同伦概念有四个高频误区：

- **同伦 ≠ 同胚**：同伦是「映射之间」的关系，同胚是「空间之间」的关系。$f \simeq g$ 与「$X \cong Y$」是两码事。
- **同伦不保「单射/满射」**：$f$ 单射、$f \simeq g$，$g$ 不必单射。同伦是「软」变形，可以压扁。
- **同伦的「时间」$t$ 必须连续地走**：$F$ 是连续映射，不能「瞬移」。$t$ 轴不可数，变形过程是连续的轨迹。
- **「$f \simeq g$」与「$f = g$」**：相等是特例（静止同伦），同伦是松弛版。代数拓扑研究「同伦类」，不是「函数本身」。

## 6 小结

- **同伦**：$F : X \times [0,1] \to Y$，$F(\cdot, 0) = f$、$F(\cdot, 1) = g$——「连续变形」。
- **等价关系**：静止、倒带、拼接三条操作分别证自反、对称、传递。
- **例子**：凸集内一切映射同伦于常值；$S^1$ 的绕圈映射不可缩（有洞）。
- **直觉**：同伦 = 函数空间中的连续道路；同伦类 = 连通分支。
- **与同胚的区别**：同伦管「映射的变形」，同胚管「空间的等同」。
- **自测**：$f, g : X \to \mathbb{R}^n$ 为何必同伦？——$\mathbb{R}^n$ 凸，直线同伦全程在 $\mathbb{R}^n$ 内。
- **自测**：$S^1$ 的恒等映射 $\mathrm{id}_{S^1}$ 与常值映射是否同伦？——否，直线同伦会穿出 $S^1$；这正是「$S^1$ 有洞」的体现。
- **跨课连接**：第三篇「道路连通 = 函数空间连通」的直觉，在这里升级为「同伦 = 函数空间中的道路」。
- **本课一句话**：同伦是「连续变形」的严格化——$F(x,t)$ 一张时间轴上的连续快照，$f \simeq g$ 意味着「$f$ 能滑到 $g$」。

### 同伦与「刚体变形」的对照

物理里的「刚体变形」与拓扑的「同伦」是两种极端，对照能凸显同伦的「软」：

| | 刚体变形 | 同伦变形 |
| --- | --- | --- |
| 保长度 | 是 | 否 |
| 保单射 | 是 | 否 |
| 保角度 | 是 | 否 |
| 允许「压扁」 | 否 | 是 |
| 研究对象 | 度量/几何 | 拓扑 |

同伦不关心长度、角度、单射性——只关心「不断裂地滑过去」。这就是为什么它能识别「洞」而几何变形识别不了：「压扁」会改变几何但保留拓扑，「洞」却在压扁中幸存。代数拓扑的全部力量，来自「只问洞、不问形状」的这种「软」视角。

在下一节，我们将用同伦定义空间的「等价」：**同伦等价与空间的伦型**。

### 同伦与「形变」的直观模型

同伦的几何直觉可以用三个「变形」阶段来建立：

- **拉伸与压缩**：同伦允许把映射的像「拉伸」「压缩」，只要连续——不要求保长、保角、保单射。
- **不撕裂、不粘合的限制**：$F$ 连续禁止「撕裂」（像不能断开），但不禁止「粘合」（两个点可以并成一个点）。这就是为什么 $S^1$ 的绕圈不能缩成点：缩的过程必须「保持 $S^1$ 是闭圈」，而一旦「粘合」就会断裂。
- **时间的维度**：$X \times [0,1]$ 给「变形」加了一维时间轴。每个时刻 $t$ 是一张「快照」$F(\cdot, t)$，快照之间连续过渡。

这三个阶段的图像，是理解一切同伦论证（可缩、基本群、Van Kampen）的基础直觉。

### 同伦类的「集合」视角

同伦类是等价类，它们构成一个集合，这个集合本身是拓扑研究对象：

- **同伦类集合**：$\pi(X,Y) = \mathcal{C}(X,Y)/\simeq$——连续映射按同伦分类。
- **当 $X = S^n$ 时**：$\pi_n(Y)$ 是第 $n$ 个同伦群（$n \ge 1$ 时成群），是代数拓扑最深的工具之一——本专题只走到 $\pi_1$（基本群）。
- **当 $X$ 是单点时**：$\mathcal{C}(\{*\}, Y) \cong Y$，同伦类 = 道路连通分支——与第三篇的道路分支直接接通。

「把映射按同伦分类」这一视角，是「拓扑问题 → 代数对象」翻译的第一步。同伦类的结构（群、集合）携带空间的拓扑信息。
