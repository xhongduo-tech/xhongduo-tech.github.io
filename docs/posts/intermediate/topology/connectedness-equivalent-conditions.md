## 为什么需要等价条件与例子库

上一课给出连通的分离定义，但定义本身还不能构成「工具箱」——证明一个空间连通，需要趁手的判据；判断一个空间不连通，需要反例库。本节把连通的**等价条件**整理成一套，并建立常见连通空间的**例子库**。这些是后续一切连通性论证（连续像、乘积、分支、道路连通）的弹药：有了「$\mathbb{R}$ 连通」「圆周连通」「连续映射保连通」这几件熟知的武器，复杂的连通性证明就能拆成简单部件的组合。<span class="marginnote">数学的「例子库」是隐形的第一生产力：判断「连通与否」靠的是拿新空间与已知例子比对，等价条件负责把比对结果翻译成证明。Munkres 在 §23 前后就建立这样一套「标准空间」清单。</span>

## 1 三条等价刻画

设 $X$ 是拓扑空间，以下三条命题**等价**：

1. **分离版本**：$X$ 不能写成两个互不相交非空开集之并。
2. **既开又闭版本**：$X$ 中既开又闭的子集只有 $\emptyset$ 与 $X$。
3. **连续常值版本**：从 $X$ 到二点离散空间 $\{0,1\}$ 的任何连续映射都是**常值**的。

第 3 条最深刻，值得拆开看：若 $f : X \to \{0,1\}$ 连续且不常值，则 $f^{-1}(0)$ 与 $f^{-1}(1)$ 是互不相交的非空开集，铺满 $X$，构成分离；反过来，若 $X$ 有分离 $U \cup V$，定义 $f(x) = 0$（$x \in U$）、$1$（$x \in V$），则 $f$ 连续但不常值。所以「连续性只能取常值」与「无分离」是同一件事的两张脸。<span class="marginnote">「连续映射到 $\{0,1\}$ 必常值」是连通性最顺手的判据：在证明「$X$ 连通 ⟹ 某性质」时，常构造这样一个 $f$ 并让它取两个值，导出矛盾。这招在数学分析里早已出现：连续函数 $f: \mathbb{R} \to \mathbb{R}$ 若只取值 $0,1$，必常值——那正是「$\mathbb{R}$ 连通」的初等版本。</span>

## 2 常见例子库

**定理（实轴连通）**：$\mathbb{R}$ 与一切区间（开、闭、半开、无界）都是连通的。

证明用「既开又闭」判据：设 $C \subset \mathbb{R}$ 既开又闭且非空，取 $x_0 \in C$。若 $C \neq \mathbb{R}$，存在 $x_1 \notin C$，无妨 $x_1 > x_0$。考虑集合 $S = \{t \in C \mid t < x_1\}$ 在 $[x_0, x_1]$ 内，取上确界 $b$。由 $C$ 闭知 $b \in C$；由 $C$ 开知 $b$ 有一小邻域含于 $C$，于是存在 $b' > b$、$b' < x_1$ 且 $b' \in C$，矛盾于 $b$ 是上确界。故 $C = \mathbb{R}$。<span class="marginnote">这段证明的钥匙是实数的<strong>上确界性质</strong>（完备性）：$S$ 的上确界 $b$ 若在 $C$ 外则违反 $C$ 开、若在 $C$ 内又被 $C$ 开「推」出矛盾。连通性在 $\mathbb{R}$ 上的成立，本质上归功于实数轴没有「缝」。</span>

由此建立的例子库：

- **$\mathbb{R}^n$ 连通**：$\mathbb{R}^n = \mathbb{R} \times \cdots \times \mathbb{R}$，连通空间之积仍连通（下一节定理），逐个乘上去即得。
- **球面 $S^n$ 连通**：$S^n$ 是 $\mathbb{R}^{n+1}$ 的连续像或同胚像，连续映射保连通（下一课）。
- **圆盘、实心立方体连通**：都是凸集，凸集必然连通（两点间线段在集内，用道路连通或直接论证）。
- **$S^1$ 连通**：$S^1$ 是 $[0,1]$ 的连续像（$t \mapsto e^{2\pi i t}$），连续像保连通。
- **多项式函数图、曲线的图**：一般连通。

### 常见例子的连通性速查表

把「空间 → 连通性」整理成表，做题时对照着查：

| 空间 | 连通？ | 道路连通？ | 理由 |
| --- | --- | --- | --- |
| $\mathbb{R}$、区间 | 是 | 是 | 上确界论证 / 直线段 |
| $\mathbb{R}^n$ | 是 | 是 | 积保持连通 / 直线段 |
| $S^n$（$n\ge1$） | 是 | 是 | $[0,1]$ 的连续像（或大圆弧） |
| $[0,1]\cup[2,3]$ | 否 | 否 | 两个分支 |
| $\mathbb{Q}$ | 否 | 否 | 到处有缝 |
| $\{a,b\}$ 离散 | 否 | 否 | 单点分离 |
| 拓扑学家正弦曲线 | 是 | 否 | 闭包保连通 / 无道路 |
| $\mathbb{R}\setminus\{0\}$ | 否 | 否 | 两个分支 |

表格中最后两行特别值得留意：拓扑学家的正弦曲线（连通不道路连通）与 $\mathbb{R}\setminus\{0\}$（既不连通也不道路连通）提醒我们，「连通」与「道路连通」是两个不同的强度，别混为一谈。这张表在后续所有章节都会被反复引用。

### 用等价条件证连通的示范

把「连续常值判据」用在一条经典证明上：**$\mathbb{R}^2 \setminus \{0\}$ 连通**。

方法一（用「连续常值」）：设 $f : \mathbb{R}^2\setminus\{0\} \to \{0,1\}$ 连续。限制到第一象限的射线 $\{(t,0) \mid t>0\}$ 上，$f$ 仍连续且恒等于某值；沿这条射线转个圈（用极坐标 $\theta$ 连续旋转），在每个角度的射线 $(\cos\theta,\sin\theta)\cdot t$ 上 $f$ 都取同一个值——因为相邻角度的射线在无穷远「几乎重合」但需严谨。更简单的做法是分两步：$\mathbb{R}^2\setminus\{0\}$ 可以写成两片连通集的并：$U = \{(x,y)\mid x>0\}$（连通，同胚于 $\mathbb{R}^2$）与 $V = \{(x,y)\mid x<0\}$（连通），再加上与 $y$ 轴的交叠区；这三者两两相交，并连通。

方法二（更省事）：先证 $\mathbb{R}^2\setminus\{0\}$ 道路连通——任意两点可用「折线或圆弧」相连，再调用「道路连通 ⟹ 连通」。这正是等价条件（以及道路判据）的意义：**多一条判据，就多一条捷径**。

### 连通性的「不可分」直觉再校准

「连通」的直觉是「不可分」，但「不可分」有三个易混层次，务必分清：

- **不可劈成两块开集**（连通）——最弱，本节的分离定义。
- **不可劈成两块闭集**——与开集版本等价（$U$ 开 ⟺ $X\setminus U$ 闭），不是新概念。
- **不可被连续函数分成两个值**——「连续常值判据」版本，是连通的最实用形态。

还有一个更高阶的「不可分」——**不可分空间（inseparable）**，那是指「没有可数稠密子集」（第一篇可分性的反面），与连通性无关。同一个中文词「可分」在「可分空间」与「可分离」语境里意思完全不同，跨章节阅读时要注意上下文。

### 连通性的反例库扩充

除了 $\mathbb{Q}$、离散空间，连通性的反例库还有几件「藏货」，做题时能救命：

- **$\mathbb{R} \setminus \{0\}$**：不连通（$(-\infty,0)$ 与 $(0,\infty)$ 分离），但它的闭包 $\mathbb{R}$ 连通。
- **$\mathbb{R}^2$ 去掉一条直线**：不连通（直线两侧分离）；去掉**一个点**则连通——「删一点」与「删一维」的差别。
- **Cantor 集**：全不连通（每个点自成分支），却是紧、完备、不可数——「不连通」与「丰富」可以共存。
- **Sorgenfrey 直线**（$\mathbb{R}$ 取下极限拓扑）：完全不连通（每个有理点与无理点可分离），却比 $\mathbb{R}$ 更「细」——连通性对拓扑粗细极敏感。

每个反例都提醒：**别用「看起来连不连」替代谢严格判据**。

## 3 连通性的「保持」工具箱

连通性有四个常规「保持」工具，证明几乎都用既开又闭判据：

**命题 A（连续像保持连通）**：$f : X \to Y$ 连续，$X$ 连通 ⟹ $f(X)$ 连通。证明：设 $C \subset f(X)$ 在 $f(X)$ 中既开又闭，则 $f^{-1}(C)$ 在 $X$ 中既开又闭，由 $X$ 连通知 $f^{-1}(C) = \emptyset$ 或 $X$，故 $C = \emptyset$ 或 $f(X)$。

**命题 B（同胚保持连通）**：连通性是拓扑性质——同胚的空间连通性一致。这是 A 的直接推论。

**命题 C（并保持连通，若两两相交）**：若 $\{A_i\}$ 一族连通子集且 $\bigcap A_i \neq \emptyset$，则 $\bigcup A_i$ 连通。特别地，两个连通集若有公共点，其并连通。

**命题 D（闭包保持连通）**：$A$ 连通 ⟹ $\operatorname{cl} A$ 连通。这是「拓扑学家的正弦曲线」能连通的关键——它由「振荡图形」（连通）与其闭包（补上竖直线段）构成。

**辨析｜易错点：** 注意「并」的**充分条件不可削弱**：$[0,1] \cup [2,3]$ 不相交，不连通；$([0,1]\cap\{0\})\cup([0,1]\cap\{1\})$ 虽各连通但不交也不连通。「交集非空」或更一般的「传递相连」是必要的。

## 4 公式解析：连续常值判据

$$X \text{ 连通} \iff \text{每个连续映射 } f : X \to \{0,1\} \text{ 都是常值映射}$$

- **第一步，认识陪域**：$\{0,1\}$ 取离散拓扑，它的每个子集都开。于是「$f$ 连续」的条件非常弱——只要 $f^{-1}(0)$、$f^{-1}(1)$ 都是 $X$ 的开集。
- **第二步，非平凡解 ⟺ 分离**：若 $f$ 不常值，则 $f^{-1}(0)$ 与 $f^{-1}(1)$ 都是非空开集、互不相交、并成 $X$——正是分离。
- **第三步，合流**：所以「存在不常值的连续 $f$」⟺「$X$ 有分离」⟺「$X$ 不连通」。取逆否命题即得公式。

## 5 辨析｜易错点（续）

**辨析｜易错点：** 等价条件应用时注意：

- **「连续映射到离散空间」中的离散不能丢**：若 $\{0,1\}$ 取平凡拓扑，任何映射都连续，判据失效。判据依赖二点离散空间。
- **并的保持需要「公共点」**：两两相交或更一般「连锁相交」才保连通。只凭「各自连通」并在一起，可能不连通。
- **闭包保持连通，但「补」不保**：$A$ 连通，$\operatorname{cl} A$ 连通，但 $X \setminus A$ 完全可以不连通（$\mathbb{R}$ 去掉一个点裂成两支）。
- **例子库的适用范围**：$\mathbb{R}^n$、$S^n$、凸集连通，但不可把「凸」误当「连通」的替代——连通远比凸普遍。

## 6 小结

- **三条等价刻画**：无分离、无平凡既开又闭子集、连续映射到 $\{0,1\}$ 必常值。
- **实轴连通**：由上确界性质证明；区间、$\mathbb{R}^n$、$S^n$、凸集皆连通。
- **保持工具**：连续像、同胚、两两相交之并、闭包——四者都保持连通。
- **常用反例**：$\mathbb{Q}$、两个点的离散空间、$[0,1]\cup[2,3]$ 不连通。
- 连通性是拓扑性质，可用来证明空间不同胚。

在下一节，我们将把「$\mathbb{R}$ 连通」打磨成一套完整的理论：**实数轴与区间的连通性**——它是中间值定理、不动点定理与一切「连续变化」论证的根基。
