## 为什么用「粘合」制造曲面

上一课的商拓扑给出了一套严密的语法：定义等价关系，取商空间，开集用原像判定。现在到了展示语法能力的时候——**用一张正方形的对边粘合，制造出拓扑学里最著名的四件展品**：圆柱、Möbius 带、环面、射影平面。这四件展品表面上看只是「几何玩具」，实际上它们预告了本专题的两条主线：其一，**商构造是同胚意义下「新形状」的制造机**；其二，**同一张正方形、同一种粘合语法，只因「同向还是反向」的细微差别，就产出拓扑上根本不同的曲面**——这个差别将引导我们走向可定向性、Euler 示性数与曲面的完整分类（第八篇）。<span class="marginnote">四件展品各有名片：圆柱有两条边界、Möbius 带只有一条边界且不可定向、环面无边界且可定向、射影平面无边界却不可定向。这四个属性矩阵是第八篇曲面分类的预告表。</span>

## 1 正方形作为「画布」

一切从单位正方形 $I \times I$（$I = [0,1]$）出发。我们想在上面定义等价关系，把**对边**的点粘在一起。规范地说，正方形上的点 $(s, t)$ 属于开内部；而边界上的点要被配对。

先看最简单的两种：

**圆柱**：定义等价关系 $(0, t) \sim (1, t)$（对每个 $t$），即把**左边与右边**按同一高度粘合。商空间 $I \times I / \sim$ 同胚于圆柱面 $S^1 \times I$。上下两条边 $(s,0)$、$(s,1)$ 保持原样，成为圆柱的两条边界。
**环面（torus）**：在圆柱的基础上**再**把上边与下边粘合：$(s,0) \sim (s,1)$，连同 $(0,t) \sim (1,t)$。商空间同胚于环面 $T^2 = S^1 \times S^1$——没有边界，首尾相接成甜甜圈。<span class="marginnote">「先粘左右成圆柱，再粘上下成环面」是理解环面的两步走。它同时给出 $T^2 \cong S^1 \times S^1$ 的同胚：正方形网格的粘合对应两个圆周的乘积。</span>

## 2 扭转一下：Möbius 带

**Möbius 带**来自一次「反向」粘合：$(0, t) \sim (1, 1 - t)$。把右边**翻转 180°**再与左边粘合——纸上操作就是：取一张纸条，扭转半圈，再把两端接起来。

关键对比：圆柱与 Möbius 带都只粘了一对边，都由「正方形」这个画布造出，但结果**不同胚**。最直观的证明是看边界：圆柱有两条边界（上下边），Möbius 带只有一条边界（上下边其实在粘合处连成了一条）。边界条数是拓扑性质吗？需要小心：边界条数是「流形边界」概念下的不变量，第八篇会严格化。此处先凭直观建立感受：**Möbius 带的边界是一条闭合曲线，走一圈要穿过「扭转」处**。<span class="marginnote">在 Möbius 带中间沿中线画一条线，走回原点时它落在纸的背面——「不可定向」的第一个征兆。这个「走一圈翻个面」的现象，是射影平面与 Klein 瓶的远房亲戚。</span>

## 3 更极端的反向：射影平面

**射影平面** $\mathbb{RP}^2$ 的定义相对抽象：它是 $\mathbb{R}^3 \setminus \{0\}$ 中所有「过原点的直线」构成的集合，也可视为球面 $S^2$ 上**对径点等同**：$\mathbb{RP}^2 = S^2/\{x \sim -x\}$。

但用正方形表示更直观：取正方形，把两对对边**都反向**粘合——左边与右边反向粘、上边与下边反向粘。这个「全面反向」的粘合造出的就是射影平面。直观上它像 Möbius 带的平方：无处不扭转，且没有边界。<span class="marginnote">射影平面无法嵌入 $\mathbb{R}^3$ 而不自交——它只能在 $\mathbb{R}^4$ 里被「放平」。这解释了为何它远不如圆柱、环面常见：我们对三维空间太习惯了。</span>

值得注意：射影平面有一个非常规的表现——它也可以看成**一个圆盘 $D^2$ 的边界点按对径等同**得到。这给出 $D^2/\{x\sim -x, x \in \partial D^2\} \cong \mathbb{RP}^2$。圆盘表示是后续计算基本群与示性数的便捷入口。

### Klein 瓶：第四种反向粘合

在介绍完四种标准曲面后，补一个重要的「表亲」——**Klein 瓶**：正方形的一对对边反向粘、另一对对边同向粘：

$$(0, t) \sim (1, 1-t) \quad \text{且} \quad (s, 0) \sim (s, 1)$$

它「一半像 Möbius、一半像环面」：沿一条方向走会翻面（不可定向），沿另一条方向走却闭合如环。Klein 瓶无边界、不可定向，**无法嵌入 $\mathbb{R}^3$ 而不自交**——它需要把「瓶颈」穿进「瓶身」的第四维才能装下。

| 曲面 | 粘合 | 边界 | 可定向 | 能否嵌入 $\mathbb{R}^3$ |
| --- | --- | --- | --- | --- |
| 圆柱 | 一对同向 | 两条 | 是 | 能 |
| Möbius 带 | 一对反向 | 一条 | 否 | 能 |
| 环面 | 两对同向 | 无 | 是 | 能 |
| Klein 瓶 | 一反向一同向 | 无 | 否 | 不能（不自交） |
| 射影平面 | 两对反向 | 无 | 否 | 不能（不自交） |

Klein 瓶与射影平面共享「不可定向无边界」的身份，它的引入让第八篇曲面分类的「不可定向族」更加完整。

### 为什么「角点识别」这么重要

商构造最容易忽略的环节是**顶点的粘合**。以射影平面的正方形表示为例：四个角 $(0,0), (1,0), (1,1), (0,1)$ 在粘合规则下会怎样？

- 角 $(0,0)$ 与角 $(1,1)$：左边 $0$ 与右边 $1$ 在 $t=0$ 处粘合（$(0,0)\sim(1,0)$），又上边与下边在 $s=1$ 处粘合，辗转下来四个角**全部等同**——射影平面的正方形表示中，四个角粘成了**一个点**。
- 对环面：$(0,0)\sim(1,0)\sim(0,1)\sim(1,1)$，四个角也粘成一个点。
- 对圆柱：只有左右边相粘，$(0,0)\sim(1,0)$、$(0,1)\sim(1,1)$ 分别成对，角点合成两个点。

「角点识别」直接影响顶点数 $V$ 的计数，而 $V$ 又进 Euler 示性数公式。若漏掉角点识别，算出的 $\chi$ 就错。这就是第八篇「多边形表示」计算中反复强调的第一纪律：**先数顶点等价类，再谈 $V$。**

### 四种曲面的一笔画验证

判断四种曲面「能否一笔画完回到原点而不翻面」，是体验「可定向性」的直观入口：

- **圆柱/环面**：沿表面走一圈，回到原点时「仍然站在纸的同一面」——可定向。
- **Möbius 带**：沿中线走一圈，回到原点时站在「反面」——不可定向。这就是「不可定向」的操作定义：**存在一条闭合路径，沿它走一圈局部朝向翻转**。
- **射影平面 / Klein 瓶**：同样存在「翻转朝向」的闭合路径——不可定向。

「可定向性」的严格定义（第八篇）用「是否有连续的曲面法向场」表述，但直觉内核就是这一笔画实验。现在先建立「走一圈翻不翻面」的操作感，第八篇再把它形式化为「定向覆盖」与 Euler 示性数的符号。

## 4 公式解析：粘合数据就是等价关系

所有粘合规则都可以写成一个统一的等价关系。对正方形 $I^2$ 上的点，用「边字（edge word）」记录每条边的配对方式。例如环面的边字是 $aba^{-1}b^{-1}$，读作：四边按顺序为 $a, b, a^{-1}, b^{-1}$，同字母的边相粘，有负号表示反向。

$$\text{圆柱：}\ ab\,a^{-1}b \quad \longleftrightarrow \quad (0,t)\sim(1,t)$$

$$\text{环面：}\ aba^{-1}b^{-1} \quad \longleftrightarrow \quad \text{两对对边同向粘合}$$

- **第一步，解码边字**：按顺时针给正方形四边命名。字母 $a$ 出现两次，表示这两条边粘合；$a^{-1}$ 出现表示反向粘合。
- **第二步，解码方向**：同向粘合（$a$ 与 $a$）不扭转；反向粘合（$a$ 与 $a^{-1}$）扭转。圆柱的两个 $a$ 同向，Möbius 带是 $ab\,a^{-1}b$ 中夹着反向——这解释了「圆柱有两条边、Möbius 一条边」。
- **第三步，总结**：边字不仅是「配方」，还是计算 Euler 示性数与基本群的钥匙——第八篇将系统使用它。

## 5 辨析｜易错点

**辨析｜易错点：** 商构造四件展品时有四个高频误区：

- **把 Möbius 带当「环面的一半」**：不是。Möbius 带不可定向、有边界；环面可定向、无边界。它们的边界条数与可定向性都不同。
- **混淆「无边界」与「不可定向」**：环面无边界且可定向；射影平面无边界但不可定向。两者是两个独立属性，可以任意组合。
- **以为「反向粘合」会产生「洞」**：不产生。环面有一个「洞」（亏格 1），而射影平面没有洞却有扭转。洞与扭转是两个不同概念。
- **忽略等价关系的传递性**：对边粘合会把**四个角**也粘在一起。例如射影平面的四个角实际上粘成了**一个点**。画商空间时漏掉角点的识别，会得到错误拓扑。

## 6 小结

| 曲面 | 粘合方式 | 边界 | 可定向 |
| --- | --- | --- | --- |
| 圆柱 | 一对对边同向 | 两条 | 是 |
| Möbius 带 | 一对对边反向 | 一条 | 否 |
| 环面 $T^2$ | 两对对边同向 | 无 | 是 |
| 射影平面 $\mathbb{RP}^2$ | 两对对边反向 | 无 | 否 |

- 商构造用等价关系把正方形对边粘合，制造出圆柱、Möbius 带、环面、射影平面。
- 同向粘合不扭转、反向粘合扭转；Möbius 带与射影平面是「反向」的产物。
- 环面 $T^2 \cong S^1 \times S^1$；射影平面 $\cong D^2/\text{对径等同}$。
- 边界条数、可定向性、洞（亏格）是三个独立属性，组合出不同曲面。
- 粘合时角点也会被识别，商空间的结构比「纸面直观」更微妙。
