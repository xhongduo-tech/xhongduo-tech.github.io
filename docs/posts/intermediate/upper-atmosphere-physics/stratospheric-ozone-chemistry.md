## 为什么从臭氧讲起

上一篇把大气切成五层，其中平流层之所以温度随高度上升，全靠**臭氧**吸收太阳紫外辐射加热。臭氧（ozone，化学式 $\ce{O3}$）在整个大气中的体积占比不到百万分之一，却一手决定了平流层的温度结构、拦截了对生物致命的紫外线，并在 1985 年后成为人类第一次「用化学家的大脑预测、再拿全球政策应对」的教科书案例。<span class="marginnote">臭氧的故事是中层大气化学的完美入门：它既有纯粹的光化学方程（Chapman 循环），又有大气动力学（极涡隔离）、非均相化学（云表面反应）、政策科学（蒙特利尔议定书）的多层嵌套。理解了臭氧，就理解了中层大气化学的整套「语法」。</span>

这一节我们回答三个问题：臭氧**从哪来**、**为什么观测到的比理论预测的少**、以及**南极上空为什么会出现臭氧洞**。

答案的链条是层层递进的：先有纯净大气的 Chapman 理论，再被观测「打脸」而补上催化循环，最后被南极冬季的特殊动力条件放大成臭氧洞——**每补上一块拼图，都要同时动用方程、观测与大气环流**。

## 1 臭氧层在哪里，有多厚

臭氧不是均匀分布在平流层的，而是集中在约 15–35 km 的**臭氧层（ozone layer）**，峰值混合比出现在 20–25 km 附近（约 10 ppmv）。衡量臭氧总量不用浓度，而用**柱总量（column abundance）**：把整根垂直气柱里的臭氧压缩到海平面标准大气压，折成厚度，单位是**多布森（Dobson unit，DU）**，1 DU = $10^{-5}$ m 即 0.01 mm 的纯臭氧层。全球平均约 300 DU，相当于一枚一元硬币厚度再除以几百——**保护整颗行星的臭氧层，只有这么薄**。

臭氧的「本职工作」是吸收太阳 UV-B（280–315 nm）与部分 UV-C：吸收发生在光解臭氧本身的过程里，紫外能量因此不会到达地面。<span class="marginnote">UV-B 是造成皮肤癌、白内障与作物损伤的主要波段；臭氧层把它挡掉约 99%。「薄薄一层却挡住 99% 有害紫外」——这是大气化学最直观的一次「以小搏大」。</span>正因如此，**臭氧层的厚度变化直接关乎地面上每个人的健康**，这正是臭氧洞引起全球恐慌的原因。

**为什么臭氧峰值不在臭氧「生产最旺」的地方？** 电离紫外线最强的区域是热带高空，那里的光解速率最大；但臭氧的**化学寿命在低纬短、高纬长**，加上 Brewer–Dobson 环流（本篇与第 12 篇都会展开）把臭氧从热带向两极输送，观测到的臭氧总量反而是**高纬偏多、低纬偏少**。「哪里产的多」与「哪里积的多」是两回事——这条「生产—输运—损耗」的三角关系，是理解臭氧分布的一把钥匙。

## 2 Chapman 循环：纯净大气中的臭氧收支

1930 年，英国地球物理学家查普曼（Sydney Chapman）提出纯氧大气的臭氧光化学四步反应，至今仍是理解臭氧的骨架：

$$\ce{O2 + h\nu ->[\lambda\lt 242\,\mathrm{nm}] O + O}\qquad (J_2)$$

$$\ce{O + O2 + M -> O3 + M}\qquad (k_3)$$

$$\ce{O3 + h\nu ->[\lambda\lt 320\,\mathrm{nm}] O2 + O}\qquad (J_3)$$

$$\ce{O + O3 -> 2 O2}\qquad (k_4)$$

其中 $\ce{M}$ 是任何碰撞的第三体分子（主要是 $\ce{N2}$、$\ce{O2}$），负责带走结合释放的动能。前两步是臭氧的**生产**：氧气被短波紫外线打碎成两个氧原子，氧原子再与氧气结合成臭氧；后两步是臭氧的**损耗**：臭氧光解又变回氧气加氧原子，氧原子还能直接与臭氧反应销毁两个臭氧。<span class="marginnote">把 $\ce{O}$ 与 $\ce{O3}$ 合称<strong>奇氧（odd oxygen）</strong> $\ce{O_x = O + O3}$：这三步中前两步只是把奇氧在 $\ce{O}$ 与 $\ce{O3}$ 两种形态之间切换，只有 $J_2$（生产）与 $k_4$（销毁）真正改变奇氧总量。这个「快循环切换形态、慢过程决定总量」的分离，是全部光化学分析的第一技巧。</span>

两条紫外线窗口的分工值得记住：**λ < 242 nm** 的光才有力把 $\ce{O2}$ 直接打碎（$J_2$），而 **λ < 320 nm** 的光就能把 $\ce{O3}$ 光解（$J_3$）。由于平流层上方的 $\ce{O2}$ 已把大部分 λ < 242 nm 的辐射吸收殆尽，真正能抵达 20–30 km 的「拆氧气」光子很少——**臭氧层恰恰是太阳把自己的短波「用光」之后才得以生存的**，这解释了为什么臭氧峰值出现在 20–25 km 而不是更高的地方。

## 3 公式解析：Chapman 稳态能给出多少臭氧

**把 Chapman 循环写成代数，看看「纯净大气」理论预言多少臭氧，再与观测对比，就暴露了理论的缺口。** 奇氧总量 $O_x = [\ce{O}] + [\ce{O3}]$ 由生产项 $2J_2[\ce{O2}]$ 与损耗项 $2k_4[\ce{O}][\ce{O3}]$ 竞争。氧原子形态切换极快，近似平衡：

- **第一步，假设 $\ce{O}$ 与 $\ce{O3}$ 快速互转**：光解 $J_3$ 与结合 $k_3[\ce{M}]$ 平衡，得 $[\ce{O}]/[\ce{O3}] = J_3/(k_3[\ce{M}])$，比值通常 $10^{-4}$ 量级——大部分奇氧以 $\ce{O3}$ 形式存在。
- **第二步，奇氧总量守恒**：稳态下生产等于损耗，$2J_2[\ce{O2}] = 2k_4[\ce{O}][\ce{O3}]$。
- **第三步，代入比值消去 $[\ce{O}]$**，解出臭氧浓度：

$$[\ce{O3}]_{\mathrm{Chapman}} = \sqrt{\frac{J_2\,k_3\,[\ce{M}]\,[\ce{O2}]}{J_3\,k_4}}$$

<span class="marginnote">这个平方根公式是「理论臭氧」的标尺。它在 20 km 以上大致合理，但在 30 km 以下<strong>系统性高估</strong>观测值约 50–100%。差额指向一件事：Chapman 循环漏掉了损耗通道——这就是下一节的催化循环。</span>**理论多于观测，说明有「看不见的杀手」在额外销毁臭氧**。查普曼模型因此被戏称为「含氧大气应有的臭氧」，而真实大气是加了其他成分的大气。

四大催化家族对号入座：

| 家族 | 关键自由基 | 主要来源 | 活性窗口 |
| --- | --- | --- | --- |
| $\ce{HO_x}$ | $\ce{OH}$、$\ce{HO2}$ | 水汽、甲烷氧化 | 中层与高层平流层 |
| $\ce{NO_x}$ | $\ce{NO}$、$\ce{NO2}$ | $\ce{N2O}$ 光解 | 中高层平流层 |
| $\ce{ClO_x}$ | $\ce{Cl}$、$\ce{ClO}$ | CFC 光解（人为） | 中低层平流层 |
| $\ce{BrO_x}$ | $\ce{Br}$、$\ce{BrO}$ | 哈龙、甲基溴 | 各层，效率最高 |

其中 $\ce{NO_x}$ 与 $\ce{ClO_x}$ 还有一条著名的**交叉循环** $\ce{ClO + NO2 + M -> ClONO2 + M}$，把活性氯重新装回储库——所以硫酸盐气溶胶与 PSC 上的反应改变氮分配时，会连带放大氯的破坏力，这正是「化学偶联」的经典例子。

**各自由基的「杀伤力」差别巨大**：同是催化循环，$\ce{Cl}$ 与 $\ce{Br}$ 因活性高、寿命长而尤其危险——**每个溴原子对臭氧的破坏大约是氯原子的 40–60 倍**（因为溴循环中的 $\ce{BrO + ClO}$ 交叉循环效率更高）。这也是为什么尽管大气溴丰度远低于氯，溴仍被单列监管；而天然来源的 $\ce{HO_x}$、$\ce{NO_x}$ 循环则在背景臭氧平衡中长期存在。

催化循环还有一条**自我限制的物理边界**：它需要原子氧 $\ce{O}$ 参与，而 $\ce{O}$ 主要存在于**高层平流层**。因此在 25 km 以下，$\ce{O}$ 稀少，氯催化循环的速率反而下降——这也是为什么臭氧洞最深的损耗发生在 12–20 km，而不是臭氧浓度最高的 25 km 处：**损耗的深度取决于「氯有没有被激活」，而不只是「臭氧有多少」**。

## 4 催化损耗循环：一个自由基毁掉成千上万个臭氧

弥补缺口的主角是**催化循环（catalytic cycle）**。自由基 $\ce{X}$（可以是 $\ce{OH}$、$\ce{NO}$、$\ce{Cl}$、$\ce{Br}$）参与的通用两步循环：

$$\ce{X + O3 -> XO + O2}$$

$$\ce{XO + O -> X + O2}$$

净效果是 $\ce{O + O3 -> 2O2}$，而 $\ce{X}$ **在循环中被再生**，可以反复摧毁臭氧。催化循环之所以可怕，在于一个自由基分子能在寿命期内消灭成百上千个臭氧分子——**催化剂不消耗自己，只放大破坏**。<span class="marginnote">天然来源的自由基：$\ce{HO_x}$ 来自水汽与甲烷（平流层内由 $\ce{O(^1D) + H2O}$ 产生），$\ce{NO_x}$ 来自氧化亚氮 $\ce{N2O}$ 的光解。人类排放则给大气注入了新的氯与溴源：平流层本身没有 $\ce{Cl}$，氯几乎全部来自地面释放的 CFC 在高层光解后沉降。</span>尤其要强调：**平流层氯几乎全部来自人类活动**（CFC 等含氯氟烃），这是臭氧层问题的要害——天然大气的氯含量本可以维持臭氧平衡，人类把大量氯「空运」到了平流层。

## 5 南极臭氧洞：非均相化学与极涡

1985 年，英国南极考察队发现南半球春季南极上空臭氧柱总量骤降至正常值的约一半——**臭氧洞（ozone hole）**。它并不真的是「洞」，而是柱总量低于 220 DU 的大片区域。问题来了：催化循环需要原子氧 $\ce{O}$，而南极春季 12–20 km 处太阳辐射还不足以产生足够 $\ce{O}$，上述气相循环太慢——臭氧洞需要另一条通道。

为什么是南极而不是北极？因为**南极冬季的极涡更强、更冷、更稳定**（被南大洋环绕、地形强迫弱），温度能降到 PSC 形成的阈值以下；而北极极涡较易被行星波扰动（第 3 篇）、温度偏高，PSC 少、氯活化弱，所以北极只在个别极冷冬季出现明显但较轻的臭氧损耗。**「够冷」与「够隔绝」是臭氧洞的两块跳板**。

答案在**极地平流层云（polar stratospheric cloud，PSC）**。南极冬季，极涡把极区空气与中纬度隔离开来，温度骤降至 −78 ℃ 以下，水汽与硝酸凝结成冰晶云。氯原本以「储库形式」$\ce{ClONO2}$、$\ce{HCl}$ 呆在气柜里，但云冰晶表面发生的**非均相反应（heterogeneous reaction）**把它们转化成可光解的活性氯 $\ce{Cl2}$：

$$\ce{ClONO2 + HCl ->[PSC] Cl2 + HNO3}$$

$$ \ce{ClONO2 + H2O ->[PSC] HOCl + HNO3}$$

<span class="marginnote">非均相反应把氯从「惰性储库」解放成「活性形式」$\ce{Cl2}$、$\ce{HOCl}$；等到南半球春天太阳一升起，这些分子迅速光解，释放海量 $\ce{Cl}$ 自由基，由催化循环在几周内清空低层平流层的臭氧。这解释了臭氧洞为什么总在<strong>春季</strong>出现——冬季储氯，春季放氯。</span>**辨析｜易错点：** 臭氧洞不是「臭氧层破了一个物理的洞」，也不是 CFC 分子本身「戳出」了洞——它是**催化循环在特定季节、特定区域的高效消耗**。同时，硝酸在 PSC 表面被转化为 $\ce{HNO3}$ 并沉降，造成氮的去极化（denitrification），进一步抑制 $\ce{Cl}$ 重新回到惰性储库，让破坏得以持续。

## 6 保护臭氧层：蒙特利尔议定书

1974 年，罗兰与莫利纳（Mario Molina）发表论文警告 CFC 会破坏臭氧；1985 年臭氧洞被发现；1987 年《蒙特利尔议定书》签订，对 CFC 的生产与消费实行全球逐步淘汰。这是**人类历史上最成功的全球环境条约**：到 2020 年代，大气中的氯当量已从峰值回落，臭氧层进入「恢复期」，预计本世纪中叶前后回到 1980 年前水平。

「恢复」为何如此之慢？因为衡量指标不是 CFC 排放量，而是**有效等效平流层氯（EESC）**——它在排放停止后仍要等 CFC 分子被 UV 光解、释放出氯并完成损耗，整个过程滞后数十年。**上一代人排放的氯，这一代人才看到它的影响**——这句话既是臭氧恢复缓慢的原因，也是环境条约必须「未雨绸缪」的教训。

观测臭氧总量自 1980 年代起主要靠卫星：**TOMS**（1978 起）与 **OMI**（2004 起）逐日给出全球臭氧地图，南极春季的「洞」因此无处遁形；地基的多布森分光计网络（约百余站）则提供近 70 年的连续记录。**「地面长记录 + 卫星全球覆盖」的双轨观测**，是这场环境治理得以「看着疗效停药」的数据底座。<span class="marginnote">每条化学结论背后都是观测与建模的反复对账：从地基多布森分光计、卫星（TOMS、OMI）到大气化学传输模式。臭氧恢复缓慢，是因为 CFC 在大气中的寿命长达数十年——上一代人排放的氯，这一代人才看到它的影响。</span>臭氧层故事给本专题最重要的方法论启示：**中层大气无法靠实验「烧杯」验证，化学家依靠的是「方程 + 观测 + 全球协作」这三脚凳**——这条方法论将延续到气辉、电离层化学。

## 7 小结

- 臭氧集中于 15–35 km 的**臭氧层**，柱总量用**多布森（DU）**计量，全球平均约 300 DU。
- **Chapman 循环**用四步反应描述纯氧大气的臭氧收支，稳态给出 $[\ce{O3}] = \sqrt{J_2 k_3 [\ce{M}] [\ce{O2}] / (J_3 k_4)}$。
- 观测臭氧低于 Chapman 预测，缺口由**催化循环**补足：$\ce{X}$ 自由基再生式地销毁臭氧，一个自由基可毁掉成千上万个 $\ce{O3}$。
- **南极臭氧洞**源于 PSC 表面的**非均相反应**把惰性氯活化成 $\ce{Cl2}$、$\ce{HOCl}$，春季太阳一升起即光解释放 $\ce{Cl}$ 自由基，由催化循环在几周内清空低层臭氧。
- 臭氧洞为什么在南极：南极极涡更强、更冷、更稳定，温度能降到 PSC 形成阈值以下；北极极涡易被行星波扰动，只在个别极冷冬季出现较轻损耗。
- 四大催化家族各自主导不同高度：$\ce{HO_x}$（中层）、$\ce{NO_x}$（中高层）、$\ce{ClO_x}$（中低层，人为来源）、$\ce{BrO_x}$（效率最高，每溴原子约为氯的 40–60 倍）。
- 平流层氯几乎全部来自人类活动（CFC 光解后沉降）——天然大气本无氯，人类把大量氯「空运」到了平流层，这是臭氧问题的要害。
- **蒙特利尔议定书**是最成功的全球环境条约：氯当量已从峰值回落，臭氧层进入恢复期；衡量指标是 EESC，滞后数十年——上一代人排放的氯，这一代人才看到影响。
- 观测靠「地面长记录 + 卫星全球覆盖」双轨：TOMS/OMI 逐日全球臭氧图，地基多布森分光计网络提供近 70 年连续记录。
- 催化循环是自我限制的：它需要原子氧参与，而 $\ce{O}$ 主要在高层平流层，故损耗最深在 12–20 km 而非臭氧峰值高度——损耗深度取决于「氯有没有被激活」。
- 中层大气化学的方法论：方程 + 观测 + 全球协作三脚凳——同一套方法延续到气辉与电离层化学。

在下一节，我们将从臭氧的化学世界转向动力世界：看行星波如何从对流层敲响平流层的大门，把极涡撕碎、让极地温度在几天内飙升——**行星波与平流层爆发性增温**。
