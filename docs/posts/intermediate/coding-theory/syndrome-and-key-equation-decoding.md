## 为什么从关键方程开始

前两节我们解决了 RS/BCH 码的编码：码字是「根串约束下的多项式倍式」或「低次多项式在采样点上的取值」。但接收端的问题更硬：收到被污染的码字，怎么**高效地恢复原始消息**？通用线性码的伴随式译码要查 $q^{n-k}$ 大小的表——对 $[255, 239]$ 的 RS 码，那是 $2^{128}$ 张表，想都别想。

RS/BCH 码的代数结构提供了另一条路：**把错误问题压缩成一个方程**。这个方程——**关键方程（key equation）**——把「找错误位置」与「求错误值」拆成两步，而每一步都有 $O(n^2)$ 以内的快速算法。这一节建立关键方程本身，下一节再讲怎么解它（Berlekamp-Massey 与欧几里得算法）。<span class="marginnote">信息论视角：$n-k$ 个校验符号能提供 $n-k$ 个「约束」，即 $2t$ 个伴随式。关键方程的全部巧妙在于：把这 $2t$ 个数组织成一个多项式方程，使「$t$ 个位置 + $t$ 个值」共 $2t$ 个未知数恰好可解——约束数与未知数严格对齐。</span>

## 1 从接收向量到伴随式

设发送码字 $c(x)$，错误多项式 $e(x) = \sum e_{i_l} x^{i_l}$（非零位置 $i_1 \lt  \cdots \lt  i_w$，值 $e_{i_l} \neq 0$），接收 $r(x) = c(x) + e(x)$。

回忆 BCH 码的根约束：$g$ 的根串 $\alpha^b, \dots, \alpha^{b+\delta-2}$ 全是 $c(x)$ 的根。定义**伴随式**

$$S_j = r(\alpha^j) = c(\alpha^j) + e(\alpha^j) = e(\alpha^j), \qquad j = b, b+1, \dots, b + \delta - 2$$

**重点：伴随式只含错误信息，不含码字。** 这正是第 4 篇「伴随式 = 错误的指纹」在 RS/BCH 语境下的具体形态——只不过这里的「指纹」是错误多项式在根串上的取值。<span class="marginnote">若全部 $S_j = 0$，则 $r$ 是码字，宣告无错（或不可检错误）；否则 $S_j$ 携带了「错误长什么样」的全部可观测信息。注意「$S_j$」与第 4 篇的向量伴随式 $\boldsymbol{s}$ 名字相同、精神一致：都是「校验结果」，只是一个是标量序列、一个是向量。</span>

设错误个数 $w \le t$（$t = \lfloor(\delta-1)/2\rfloor$），记 $X_l = \alpha^{i_l}$（**错误位置数**）与 $Y_l = e_{i_l}$（**错误值**）。则

$$S_j = \sum_{l=1}^{w} Y_l X_l^j, \qquad j = b, \dots, b + \delta - 2$$

这是 $w$ 个位置、$w$ 个值共 $2w \le 2t$ 个未知数的 $2t$ 个方程——**欠定当 $w \lt  t$，但代数的巧劲让解依然唯一**。

## 2 错误位置多项式

直接解上面的非线性方程组（$Y_l X_l^j$ 里有乘积）是死路。经典手法是把问题**线性化**。

**错误位置多项式（error locator polynomial）：**

$$\sigma(x) = \prod_{l=1}^{w} (1 - X_l x) = 1 + \sigma_1 x + \sigma_2 x^2 + \cdots + \sigma_w x^w$$

它的根是 $X_l^{-1}$（错误位置数的逆）。**知道 $\sigma$ 就知道所有错误位置**——因为 $X_l^{-1}$ 的倒数就是位置数 $X_l$。<span class="marginnote">为什么用 $1 - X_l x$ 而不是 $(x - X_l)$？这是「按根的倒数」写的：$x = X_l^{-1}$ 时 $1 - X_l x = 0$。系数 $\sigma_m$ 是 $X_l$ 的 $m$ 次初等对称多项式（带符号），它们与伴随式之间由 Newton 恒等式连接——下一节的 BM 算法正是从伴随式解出这些 $\sigma_m$。</span>

**Newton 恒等式**（以 $b=1$ 狭义情形为例，$S_j = \sum_l Y_l X_l^j$，$j \ge 1$）：

$$S_{j+w} + \sigma_1 S_{j+w-1} + \cdots + \sigma_w S_j = 0, \qquad j \ge 1$$

这组线性递推关系正是「$\sigma$ 满足的递推」与「$S$ 满足的递推」的一致性——它是关键方程的种子。

## 3 关键方程的推导

把伴随式组织成**伴随式多项式**

$$S(x) = \sum_{j=b}^{b+2t-1} S_j x^j \quad (\text{或按 } b \text{ 平移后的规范形式})$$

**关键方程（key equation）：**

$$\sigma(x) S(x) \equiv \omega(x) \pmod{x^{2t}}$$

其中 $\omega(x)$ 是**错误值多项式（error evaluator polynomial）**，次数 $\lt  w$。

推导分三步：

- **第一步，把 $S$ 写成「错误值之和」**：$S(x) = \sum_{l=1}^{w} Y_l X_l^b \sum_{j=0}^{2t-1} (X_l x)^j = \sum_l Y_l X_l^b \cdot \frac{1 - (X_l x)^{2t}}{1 - X_l x}$。
- **第二步，乘上 $\sigma$**：$\sigma(x) = \prod(1 - X_l x)$ 恰好消掉每个分母 $1 - X_l x$，得 $\sigma(x) S(x) = \sum_l Y_l X_l^b \frac{\sigma(x)}{1 - X_l x} - (\text{含 } x^{2t} \text{ 的高阶项})$。
- **第三步，模掉高阶项**：把含 $x^{2t}$ 及以上的部分舍去，左边模 $x^{2t}$ 后等于 $\omega(x) = \sum_l Y_l X_l^b \prod_{m \ne l}(1 - X_m x)$，次数 $\lt  w$。

**直觉：** $\sigma$ 是「消分母的武器」——一乘上去，错误位置 $X_l$ 就从分母里解放出来，整个方程变成一个多项式同余。<span class="marginnote">关键方程把「找错误」拆成两半：$\sigma$ 的根 → 位置；$\omega$ 与 $\sigma$ 的比值 → 值（Forney 公式）。解关键方程的任务（求满足同余的低次 $\sigma$）正是下一节 BM 算法与欧几里得算法的工作——本节到此为止，方程已经建好。</span>

## 4 公式解析：从伴随式到位置再到值

完整译码分三步，每一步都是「解方程或找根」的确定性算法。

**第一步，解关键方程求 $\sigma$。** 给定伴随式 $S_1, \dots, S_{2t}$（取 $b=1$），求次数最小的 $\sigma(x)$（首一或 $\sigma(0)=1$）使 $\sigma(x) S(x) \equiv \omega(x) \pmod{x^{2t}}$。这一步由 Berlekamp-Massey 算法或欧几里得算法完成（下一节）。

**第二步，找错误位置。** 求 $\sigma(x)$ 的根：对每个 $i = 0, \dots, n-1$，检查 $\sigma(\alpha^{-i}) = 0$。若是，则 $\alpha^{-i} = X_l^{-1}$，错误位置 $i_l = i$，且 $X_l = \alpha^i$。这一步叫 **Chien 搜索**，是 $O(nw)$ 次域运算，硬件上一个时钟周期扫一个位置。

**第三步，求错误值（Forney 公式）。** 对每个错误位置 $l$：

$$Y_l = -\frac{X_l^{1-b} \omega(X_l^{-1})}{\sigma'(X_l^{-1})}$$

其中 $\sigma'(x)$ 是形式导数。推导：对 $\sigma(x) S(x) \equiv \omega(x)$ 两边在 $X_l^{-1}$ 处取「留数」——$\omega(X_l^{-1}) = Y_l X_l^b \prod_{m \ne l}(1 - X_m X_l^{-1})$，而 $\sigma'(X_l^{-1}) = -X_l \prod_{m \ne l}(1 - X_m X_l^{-1})$，两式相除即得 $Y_l$。<span class="marginnote">Forney 公式是「复变函数留数定理在有限域上的翻版」：$\sigma'$ 是「根处的一阶导数」，$Y_l$ 是「在这个极点处的留数」。域论与复分析在此共用同一个「极点展开」的内核——这个联系在代数几何码（第 18 篇）里会以更深刻的 Riemann-Roch 形式重现。</span>

**单错误实例（$w=1$）：** 设仅第 $i$ 位出错，$X = \alpha^i$，值 $Y$。伴随式 $S_j = Y X^j$。位置多项式 $\sigma(x) = 1 - X x$，一次求出：$X = S_{j+1}/S_j$（任取两相邻伴随式相除），位置 $i = \log_\alpha X$。值多项式 $\omega(x) = Y X^b$ 是常数。Forney 公式核验：$\sigma'(x) = -X$，$Y = -X^{1-b} \cdot (Y X^b)/(-X) = Y$，正确复现。这个平凡情形演示了全部三件套的机械运作——多错误只是把「单根」换成「多项式的根」，算法骨架不变。

**辨析｜易错点：** 三个多项式别搞混——$\sigma$（位置）、$\omega$（值）、$S$（输入）。$\sigma$ 的次数 $= w$（错误个数，未知）；$\omega$ 的次数 $\lt  w$；$S$ 的长度 $= 2t$（已知）。若 BM 算法解出的 $\sigma$ 次数大于 $t$ 或 Chien 搜索找不到 $w$ 个不同根，说明实际错误数超过设计能力——此时只能宣告「不可纠」，这正是工程里「译码失败」的代数判据。

## 5 关键方程解码的复杂度全景

把整条译码流水线的成本摊开：

| 步骤 | 算法 | 复杂度 |
| --- | --- | --- |
| 伴随式计算 | 在根串上求值 | $O(nt)$ |
| 解关键方程 | Berlekamp-Massey / 欧几里得 | $O(t^2)$ |
| 找错误位置 | Chien 搜索 | $O(nw)$ |
| 求错误值 | Forney 公式 | $O(t)$ |

总复杂度 $O(n \cdot t)$，对码长 $n$ 是多项式时间——**从「查指数大小的表」到「多项式时间的流水线」，全部功劳归于代数结构**。一个 $[255, 239]$ 的 RS 码（$t = 8$）在硬件上做完全程不到一微秒，这正是 CD 播放器、固态硬盘控制器里每秒纠错百万次的秘密。<span class="marginnote">对比第 4 篇的通用伴随式查表法：$q^{n-k} = 256^{16}$ 张表 vs 一次 $O(n t)$ 的代数流水线——差距是「写不完」与「几纳秒」。RS 码从实验室走进消费电子的关键，不是构造（构造早有了），而是这套解码算法。</span>

这四条流水线还有一层深意：**每条都只依赖有限域的「局部」运算**（求值、找根、除法），没有「全局」的枚举或排序。代数编码理论的整个设计哲学——让「纠错」成为「解方程」——在这张表里得到了最完整的兑现。

## 6 小结

- **伴随式** $S_j = r(\alpha^j) = e(\alpha^j)$：只含错误信息；$2t$ 个伴随式编码「错误的全部可观测面」。
- **错误位置多项式** $\sigma(x) = \prod(1 - X_l x)$：根是位置数的逆，Newton 恒等式连接 $\sigma$ 与 $S$。
- **关键方程** $\sigma(x) S(x) \equiv \omega(x) \pmod{x^{2t}}$：把「找错误」拆成位置 + 值两半。
- 译码三连：BM/欧几里得解 $\sigma$ → Chien 搜索找位置 → Forney 公式求值。
- 复杂度 $O(nt)$：从指数查表到多项式流水线，代数结构是唯一功臣。
- $\sigma$ 次数超限或 Chien 搜索根不足 → 实际错误超设计，判「不可纠」。
- 单错误时 $\sigma(x) = 1 - Xx$ 一次可得（$X = S_{j+1}/S_j$），Forney 自动复现值 $Y$。
- 全程无全局枚举：求值、找根、除法都是有限域局部运算——「纠错即解方程」的哲学落地。
- 关键方程把「$2t$ 个约束 ↔ $2w$ 个未知」（$w$ 个位置 + $w$ 个值）的对应写得明明白白——这正是它能被 BM 用 $O(t^2)$ 解出的代数原因。
- **框架与实现的分离**：本节是通用框架，BM 给出多项式解法、欧几里得给出替代路线；下一步把它们落到可跑的算法。

在下一节，我们把关键方程真正「解出来」——Berlekamp-Massey 算法与欧几里得解码：两条路线殊途同归，都让 $O(nt)$ 译码成为现实。
