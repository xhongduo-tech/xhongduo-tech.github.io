## 为什么从代数几何码开始

第 6 篇我们说过：Gilbert-Varshamov 界是「保证存在好码」的下界，但几十年来没人能系统性地超过它。直到 1981 年，**V. D. Goppa** 用代数几何（尤其是 Riemann-Roch 定理）构造了一族码——**代数几何码（AG 码）**——首次在一段参数区间上**超过**了 GV 界。1982 年 Tsfasman、Vlăduț 与 Zink 更近一步：在某些条件下 AG 码的渐近性能严格优于 GV 界。这是编码理论史上少有的「纯数学直接改写工程蓝图」的时刻。<span class="marginnote">Goppa 早在 1970 年代就提出过「Goppa 码」（用有理函数构造），代数几何码是它的几何化。你可能在密码学里见过 McEliece 公钥方案用的「Goppa 码」——那是经典 Goppa 码，而 AG 码是更广的框架。AG 码在 1990 年代还被用于构造量子码与局部可修复码，至今是「代数曲线 ↔ 编码」这条线的顶梁柱。</span>

AG 码的美在于：**RS 码只是它的特例**（射影直线 $\mathbb{P}^1$，亏格 0）。把「直线」换成「高亏格曲线」，就获得了更多的有理点、更长的码、更好的距离——几何的自由度直接兑换成编码的性能。

## 1 从 RS 码到曲线上的求值码

RS 码的构造是「在 $\mathbb{P}^1$ 上求值」：消息 = 次数 $\lt  k$ 的多项式，在 $n$ 个点上取值。用代数几何的语言重述：

- **曲线**：射影直线 $\mathbb{P}^1$；
- **求值点**：$\mathbb{P}^1$ 上的 $n$ 个 $\mathbb{F}_q$-有理点；
- **消息空间**：$L(G)$，其中 $G$ 是「次数 $k-1$ 的除子」，$L(G)$ = 分母由 $G$ 控制的有理函数空间（次数 $\lt  k$ 的多项式）。

**AG 码的定义**：设 $X$ 是 $\mathbb{F}_q$ 上的光滑射影代数曲线，亏格 $g$。取 $n$ 个互异的 $\mathbb{F}_q$-有理点 $P_1, \dots, P_n$，与一个与它们不相交的**除子** $G$。定义 Riemann-Roch 空间

$$L(G) = \{f \in \mathbb{F}_q(X) : (f) \ge -G\} \cup \{0\}$$

（$f$ 的有理函数零点/极点由 $G$ 约束）。**Goppa 码 / AG 码**：

$$\mathcal{C}(X, D, G) = \{(f(P_1), \dots, f(P_n)) : f \in L(G)\}, \qquad D = P_1 + \cdots + P_n$$

即「对 $L(G)$ 里所有函数在全部有理点求值」的码。<span class="marginnote">这套定义对初学者最大的门槛是「除子 $G$」——它本质上是「在哪些点允许几阶极点」的账单。$L(G)$ 就是「极点不超过账单、且零点自动受补偿」的函数空间。Riemann-Roch 定理则回答：这张账单能撑起多大的函数空间——一个「极点预算 ↔ 函数维度」的换算公式。</span>

## 2 公式解析：Riemann-Roch 定理与 Goppa 界

AG 码的性能完全由一条定理控制。

**Riemann-Roch 定理**：对亏格 $g$ 的光滑曲线 $X$ 与除子 $G$，

$$\ell(G) = \deg G + 1 - g + \ell(K - G)$$

其中 $\ell(G) = \dim L(G)$，$K$ 是典范除子（次数 $2g-2$）。当 $\deg G > 2g - 2$ 时，$\ell(K - G) = 0$，于是

$$\dim L(G) = \deg G + 1 - g$$

逐项拆解：

- **第一步，$\deg G$ 是「极点预算」**：允许的极点越多，函数空间越大。预算每加 1，维度加 1——这是「极点」的自由度。
- **第二步，$1 - g$ 是「曲线弯曲度」的罚金**：亏格 $g$ 越高，曲线越「扭曲」，处处正则函数越少（$g=0$ 时只有常数；$g=1$ 时…）。直线上 $g=0$，罚金为 1，对应「$k-1$ 次多项式空间维数 = 次数 + 1」。
- **第三步，$\ell(K-G)$ 是「预算耗尽」的修正**：预算足够大（$\deg G > 2g-2$）时这一项消失，公式变干净。

**Goppa 界（距离下界）**：AG 码 $\mathcal{C}(X, D, G)$ 的参数满足

$$n = \#\{\text{有理点}\} = \deg D, \qquad k \ge \deg G + 1 - g, \qquad d \ge n - \deg G$$

距离界来自「$L(G)$ 里非零函数的零点个数 $\le \deg G$」（一个函数在除子 $G$ 控制的极点限制下，零点数不可能超过极点预算）——这与 RS 码「$k-1$ 次多项式至多 $k-1$ 个根」完全同构，只是根数上界从「次数」换成了「除子度数」。<span class="marginnote">对比 RS：$g=0$ 时 $k = \deg G + 1$、$d \ge n - \deg G = n - k + 1$——正好回到 Singleton 界等号。<strong>RS 码 = 亏格 0 的 AG 码</strong>。高亏格时 $k$ 被罚掉 $g$、$d$ 保持 $n - \deg G$，净效果是「同样的码长与距离，信息量少了 $g$」——但曲线提供了更多有理点（更长 $n$），这笔交易在足够大的 $q$ 下是赚的。</span>

## 3 为什么要曲线：有理点的数目

AG 码「值不值」取决于一条数论事实：**$\mathbb{F}_q$ 上亏格 $g$ 的曲线能有多少有理点？**

**Hasse-Weil 界**：$N \le q + 1 + 2g\sqrt{q}$。

对直线（$g=0$）：$N \le q+1$，这正是 RS 码长度上界。亏格越高，有理点上限越高——**曲线提供了「更多求值点」，也就是更长的码**。<span class="marginnote">这个数论界是「有理点数量」的地板，编码理论要看的是天花板：曲线族的有理点数随亏格增长的速率 $A(q) = \limsup N_g / g$ 直接决定 AG 码的渐近性能。Tsfasman–Vlăduț–Zink 的核心就是找到「有理点增长最快的曲线族」。</span>

**模曲线（modular curves）** 是有理点增长率最优的曲线族之一：对 $q \ge 49$ 的平方数，存在曲线族使 $A(q) = \sqrt{q} - 1$（达到 Drinfeld–Vlăduț 上界）。用它构造 AG 码，就得到突破 GV 界的渐近性能。

## 4 Tsfasman-Vlăduț-Zink：超越 GV 界

把 Riemann-Roch 与模曲线的有理点合起来，就得到 TVZ 定理。

**TVZ 定理（渐近版）**：若 $q$ 是平方数且 $q \ge 49$，则存在 $q$ 元码序列满足

$$R \ge 1 - \frac{1}{\sqrt{q} - 1} - \delta$$

在 $(R, \delta)$ 平面上，这条曲线在 $\delta \in (\delta_1, \delta_2)$ 的区间内**严格高于 GV 界曲线** $R = 1 - H_q(\delta)$。<span class="marginnote">这里的「高于」是实打实的：TVZ 证明存在码，在同样相对距离 $\delta$ 下码率 $R$ 更大——即「纠同样比例的错，用更少的冗余」。GV 界只是「存在性下界」，TVZ 给出了「超越它的构造」。这是编码理论第一次证明「GV 不是终点」。</span>

**为什么模曲线能赢？** 直觉：GV 界的随机码「平均」性能如此；AG 码把「随机性」替换成「曲线的几何结构」——结构化的曲线在有理点密度上比随机码「挤」出更多。$q \ge 49$ 的条件来自「$A(q) = \sqrt{q}-1$ 要足够大，弥补 $1 - g/n$ 的亏空」——$q$ 太小，几何的收益盖不过罚金。

## 5 AG 码的例子：Hermitian 码与椭圆码

**Hermitian 码**：$\mathbb{F}_{q^2}$ 上的 Hermitian 曲线 $y^q + y = x^{q+1}$，亏格 $g = q(q-1)/2$，有理点 $q^3 + 1$ 个——达到 Hasse-Weil 界。用它构造的 Hermitian AG 码参数好、且存在多项式时间译码算法（利用曲线上的求值结构），是 AG 码在工程上最接近实用的代表。<span class="marginnote">Hermitian 曲线是「极大曲线」——有理点数达到 Hasse-Weil 上界的曲线。它的名字来自 Hermitian 形式（$y^q + y$ 是迹函数），与第二级《抽象代数》里有限域的自同构、迹范数理论直接相连。</span>

**椭圆码**：亏格 1 的曲线（椭圆曲线）。$g=1$ 时罚金最小（$1-g=0$），有理点数 $N \le q + 1 + 2\sqrt{q}$。椭圆码在密码学里格外重要——椭圆曲线上的函数空间编码，与椭圆曲线密码（ECC）共享同一条曲线，但用途截然不同。<span class="marginnote">一个有趣的桥梁：椭圆曲线的点群结构（第二级《椭圆曲线与模形式》的重点）给椭圆码提供了「自动生成求值点」的机制——点的加法给出无限多个有理点，码长可以灵活伸缩。AG 码与椭圆曲线密码是「同一条曲线的两个产业」。</span>

**例（最简单的 AG 码）**：$X = \mathbb{P}^1$（$g=0$），$G = (k-1)P_\infty$（在无穷远点有 $k-1$ 阶极点），$L(G)$ = 次数 $\le k-1$ 的多项式。取 $n \le q+1$ 个有限点求值——这就是 RS 码。**整个 AG 码理论从 RS 码出发，绕着曲线转了一大圈，又回到 RS 码**：直线是最简单的曲线，RS 是最简单的 AG 码。

## 6 AG 码的译码与工程现状

AG 码不只有漂亮的参数，还配有可计算的结构。

**多项式时间译码**：1990 年代，Shen、Porter、Justesen 等人基于「曲线上的求值」给出 AG 码的多项式时间译码；列表解码时代（下一节），Guruswami-Sudan 算法也被推广到 AG 码，能超越唯一译码半径。这些算法把「Riemann-Roch 空间的代数」落实成「可算的线性代数 + 多项式运算」——AG 码不是纸上谈兵。<span class="marginnote">译码的关键工具是<strong>曲线上的对偶理论</strong>：AG 码的对偶仍是 AG 码（由余除子 $K + D - G$ 给出），伴随式、关键方程、Berlekamp-Massey 在曲线上都有对应物。整个第 11–12 篇的译码流水线，在 AG 码身上「重演」了一遍，只是把「多项式环」换成了「曲线函数域」。</span>

**工程冷热不均**：尽管理论上优于 GV 界，AG 码在商业系统里仍少见——原因有二：一是「超越 GV」只发生在渐近意义（码长很长、$q$ 够大），实际码长下 RS 码的简单与成熟难以撼动；二是 AG 码的实现复杂度（曲线模型、除子计算、有理点搜索）远高于 RS 码。**AG 码的价值更多在理论深度**：它是「构造接近信道容量的码」的钥匙之一，也是量子 LDPC 码、局部可修复码的重要源头。

**对照小结**：

| 维度 | RS 码 | Hermitian AG 码 |
| --- | --- | --- |
| 曲线 | $\mathbb{P}^1$（$g=0$） | Hermitian 曲线（$g = q(q-1)/2$） |
| 码长 | $\le q+1$ | $\le q^3 + 1$ |
| 距离界 | Singleton 等号 | Goppa 界（可超 GV） |
| 工程现状 | 无处不在 | 理论前沿 + 特定场景 |

## 7 小结

- **AG 码** = 曲线上 Riemann-Roch 空间的求值码：$\mathcal{C}(X, D, G) = \{(f(P_i)) : f \in L(G)\}$。
- **Riemann-Roch**：$\ell(G) = \deg G + 1 - g + \ell(K-G)$；预算充足时 $\dim = \deg G + 1 - g$。
- **Goppa 界**：$k \ge \deg G + 1 - g$，$d \ge n - \deg G$；$g=0$ 时退化回 Singleton 界——**RS 码是亏格 0 的 AG 码**。
- 曲线提供更多有理点（Hasse-Weil 界 $N \le q+1+2g\sqrt{q}$），即更长的码。
- **TVZ 定理**：$q \ge 49$ 平方数时模曲线 AG 码渐近**超越 GV 界**——编码理论的里程碑。
- Hermitian 码（极大曲线）、椭圆码（$g=1$）是 AG 码在工程与密码学里的代表。
- AG 码有多项式时间译码（对偶理论重演 RS 流水线），但工程上仍被 RS 码主导；其价值在理论深度与量子/局部可修复码源头。
