## 为什么从有限域开始

上一节我们建立了通信模型，知道了纠错要靠「拉开码字距离」。但要在高维空间里系统地构造、分析码，光靠 0/1 的枚举远远不够——我们需要**能自由做四则运算的数系**。整数的算术不够用：没有除法，无法解方程；实数的算术又太多：每个数要无穷多位才能表示。

有限域（finite field）正好卡在中间：**它只有有限多个元素，却具备完备的加、减、乘、除**。这个名字也叫**伽罗瓦域（Galois field）**，记作 $\mathrm{GF}(q)$ 或 $\mathbb{F}_q$。<span class="marginnote">伽罗瓦（Évariste Galois）在 19 世纪研究多项式方程可解性时建立了域论；他 20 岁因决斗去世，却在遗作中留下了「有限域在素数幂阶时存在且唯一」的完整理论。编码理论是这门「为纯数学而生的理论」最成功的工程应用。</span>几乎所有著名码——BCH、Reed-Solomon、代数几何码——都定义在有限域上。学不懂有限域，就看不懂后面所有编码构造。

## 1 什么是有限域

**域（field）**：一个集合 $F$，配有两个运算「加法」与「乘法」，满足三条基本要求：

1. **加法与乘法都构成交换群**（有零元 $0$、单位元 $1$，每元有加法逆元，非零元有乘法逆元）；
2. **乘法对加法分配**：$a(b+c) = ab + ac$；
3. $0 \neq 1$，且 $0$ 没有乘法逆元。

**有限域（finite field）**：元素个数有限的域。元素的个数叫**阶（order）**。

你早已熟悉的数系里，$\mathbb{Q}$、$\mathbb{R}$、$\mathbb{C}$ 都是无限域。有限域的最小例子是 **$\mathbb{F}_2$**：只有 $\{0, 1\}$ 两个元素，加法是异或（$1+1=0$），乘法是逻辑与。<span class="marginnote">$\mathbb{F}_2$ 正是计算机里二进制的代数化身：$1+1=0$ 对应进位被丢弃的异或。后面所有二元线性码都建立在 $\mathbb{F}_2$ 上。</span>

**重点：有限域的阶必是某个素数的幂。** 若有限域有 $q$ 个元素，则 $q = p^m$，其中 $p$ 是素数（称为**特征 characteristic**），$m$ 是正整数；反之，对每个素数幂 $p^m$，存在且仅存在一个同构意义下的 $p^m$ 元域，记作 $\mathbb{F}_{p^m}$。<span class="marginnote">「唯一性」是编码理论的幸事：无论你用什么多项式去构造 $\mathbb{F}_{16}$，得到的代数结构都一样（同构），只是「写法」不同。这让我们可以放心地在码理论里说「$\mathbb{F}_{16}$ 上的码」而无需指定构造方式。</span>

## 2 素域 $\mathbb{F}_p$：模 $p$ 算术

阶为素数 $p$ 的有限域是最简单的：它就是**整数模 $p$ 的剩余类**，记为 $\mathbb{F}_p = \mathbb{Z}/p\mathbb{Z}$。

取 $p = 5$。元素是 $\{0, 1, 2, 3, 4\}$。加法和乘法都「做完后取模 5」：

$$3 + 4 = 7 \equiv 2 \pmod 5, \qquad 2 \times 3 = 6 \equiv 1 \pmod 5$$

关键是**除法可行**：$2$ 的乘法逆元是 $3$，因为 $2 \times 3 \equiv 1 \pmod 5$；$4$ 的逆元是 $4$，因为 $4 \times 4 \equiv 1$。每个非零元都有逆元这件事，恰好要求 $p$ 是素数——若模数 $6$，则 $2$ 没有逆元（$2$ 与 $6$ 不互素），$Z/6Z$ 就不是域。**这正是「素数」在有限域理论里的核心地位：模素数才谈得上除法。**

## 3 扩域 $\mathbb{F}_{p^m}$：不可约多项式与商环

$\mathbb{F}_2$ 太小，很多编码构造（如 Reed-Solomon 码）需要更大的符号集。怎么得到 $\mathbb{F}_{2^m}$？**重点：$\mathbb{F}_{p^m}$ 可以看成「模一个 $m$ 次不可约多项式的多项式环」。**

做法分三步：

1. 取一个系数在 $\mathbb{F}_p$ 里的 $m$ 次**不可约多项式** $f(x)$（不能分解成两个次数更低的因式）；
2. 考虑全体「次数 $\lt  m$ 的多项式」；
3. 定义加法为普通多项式加法，乘法为「相乘后除以 $f(x)$ 取余」。

写成标准记号就是 $\mathbb{F}_p[x] / (f(x))$。这与构造 $\mathbb{F}_5 = \mathbb{Z}/(5)$ 完全同构：整数模一个「素」的对象，多项式模一个「不可约」的对象。

用 $\mathbb{F}_2$ 上的 $x^3 + x + 1$ 构造 $\mathbb{F}_8$，元素是 $\{0, 1, x, x+1, x^2, x^2+1, x^2+x, x^2+x+1\}$，共 $2^3 = 8$ 个。乘法示例：

$$x \cdot (x^2 + x + 1) = x^3 + x^2 + x \equiv (x+1) + x^2 + x = x^2 + 1 \pmod{x^3+x+1}$$

因为 $x^3 \equiv x + 1$（由 $x^3 + x + 1 = 0$ 移项得到）。<span class="marginnote">「取余」这步用到了 $x^3 = x + 1$ 这个关系，它来自不可约方程 $x^3 + x + 1 = 0$。凡出现 $x^3$ 就用 $x+1$ 替换，直到次数降到 2 以下——这正是把「无穷多个多项式」压缩成「有限 8 个」的机制。</span>

## 4 公式解析：乘法群是循环群

有限域最重要的结构定理，直接决定编码的构造方式。

**定理（乘法群的循环性）：** $\mathbb{F}_q$ 的非零元集合 $\mathbb{F}_q^*$ 在乘法下构成一个 $q-1$ 阶的**循环群**。即存在某个元素 $\alpha$，使得

$$\mathbb{F}_q^* = \{\alpha^0, \alpha^1, \alpha^2, \dots, \alpha^{q-2}\} \cup \{\alpha^{q-1} = 1\}$$

这样的 $\alpha$ 称为**本原元（primitive element）**。

逐步拆解这条定理为什么成立：

- **第一步，群的阶**：非零元有 $q-1$ 个，乘法封闭、有逆，所以 $\mathbb{F}_q^*$ 是 $q-1$ 阶群。
- **第二步，有限交换群的元素阶整除群阶**（拉格朗日定理的有限群版本）：对每个非零元 $\beta$，有 $\beta^{q-1} = 1$，即每个非零元都是多项式 $x^{q-1} - 1$ 的根。
- **第三步，本原元存在**：多项式 $x^{q-1}-1$ 在域里至多有 $q-1$ 个根，而它恰有 $q-1$ 个根（全部非零元），说明根集就是全体非零元；利用有限域的交换群结构可证其中存在一个阶恰为 $q-1$ 的元素——它就是本原元。

在 $\mathbb{F}_8$（模 $x^3+x+1$）里，$\alpha = x$ 就是本原元：$\alpha^3 = \alpha + 1$，$\alpha^7 = 1$，且 $1, \alpha, \alpha^2, \dots, \alpha^6$ 恰好遍历全部 7 个非零元。<span class="marginnote">本原元把非零元的乘法「重命名」成指数的加法：$\alpha^i \cdot \alpha^j = \alpha^{i+j}$。于是查表即可做乘法——这正是下一节计算技术的根基，也是 Reed-Solomon 码「用符号位置做多项式求值」的代数依据。</span>

**辨析｜本原元 vs 生成元：** 群论里任意循环群的生成元都叫生成元；有限域里特指「阶恰为 $q-1$」的生成元为本原元。一个元素是生成元当且仅当它与 $q-1$ 互素的那些幂也够大——判断本原性靠的是阶，而非元素本身的大小。

## 5 有限域的计算：本原元与对数表

工程上，$\mathbb{F}_{2^m}$ 的运算靠**两张表**落地：本原元的幂表 $\alpha^i$ 的多项式表示，与它的逆——**对数表**（每个非零元对应的指数）。

**计算套路：**

| 运算 | 做法 |
| --- | --- |
| 加法 | 多项式系数逐位异或 |
| 乘法 | 指数相加后模 $q-1$ |
| 除法 | 指数相减后模 $q-1$ |
| 求逆 | 指数取负后模 $q-1$ |

例如在 $\mathbb{F}_8$ 中算 $\frac{x^2+1}{x+1}$：若 $x^2+1 = \alpha^6$、$x+1 = \alpha^3$，则商 $= \alpha^{6-3} = \alpha^3 = x+1$。整张表一次算好、反复使用，是硬件里 RS 码编码器/译码器的标准实现。<span class="marginnote">这就是「本原多项式」的价值：选 $f(x)$ 为本原多项式（其根是本原元），能让 $\alpha$ 的幂遍历所有非零元，对数表才完整。不是每个不可约多项式都是本原多项式，构造时要专门挑选。</span>

**辨析｜易错点：** 有限域的加法和「整数加法」不同——$\mathbb{F}_2$ 里 $1+1=0$，没有进位。做 $\mathbb{F}_{2^m}$ 运算时，系数加法是异或，绝不能按整数进位。反过来，$\mathbb{F}_p$（$p$ 为奇素数）的加法又确实是「取模后的整数加法」。**两个情形别混用**：$\mathbb{F}_{2^m}$ 是特征 2 的域，处处都要按异或处理。

## 6 有限域与信息论、抽象代数的接口

有限域不是孤立的概念，它把多个学科串在一起：

在第二级《抽象代数》里，有限域是「环 → 整环 → 域」这条代数链的终点例证，$\mathbb{F}_p[x]/(f)$ 与整数商环 $\mathbb{Z}/(p)$ 共享「主理想整环商掉极大理想」的统一构造。
在第一级《信息论》里，符号集的大小 $q = 2^m$ 决定每个符号携带 $m$ 比特：$q$ 元码的每个符号是 $m$ 个二进制位的打包。
- 在第六级《通信原理》里，有限域运算对应着实际电路中的线性反馈移位寄存器（LFSR），BCH 与 RS 码的编码器就是一排寄存器加异或门。<span class="marginnote">LFSR 由本原多项式决定反馈抽头，产生的序列就是本原元的幂——编码理论、序列设计与数字电路的接口，全在有限域这一个概念上。</span>

## 7 小结

- **有限域**：元素有限但四则运算完备的数系；阶必为素数幂 $p^m$，记为 $\mathbb{F}_{p^m}$。
- **素域** $\mathbb{F}_p$：整数模素数 $p$；「模素数才谈得上除法」是素数的核心作用。
- **扩域** $\mathbb{F}_{p^m}$：模 $m$ 次不可约多项式的多项式商环 $\mathbb{F}_p[x]/(f(x))$，共 $p^m$ 个元素。
- **乘法群循环性**：非零元构成 $q-1$ 阶循环群，本原元 $\alpha$ 的幂遍历全部非零元。
- 工程计算靠本原元幂表 + 对数表：乘法变指数加法、除法变指数减法；$\mathbb{F}_{2^m}$ 加法是异或，勿按整数进位。
- 有限域串起抽象代数、信息论与数字电路，是全部纠错码构造的公共地基。
- 记牢两个对照：$\mathbb{F}_p$ 加法是取模整数的进位算术、$\mathbb{F}_{2^m}$ 加法是逐位异或——后者没有「进位」动作，硬件因此就是一堆异或门。
- **素域与二元扩域的取舍**：$\mathbb{F}_{2^8}$ 让「一个字节 = 一个符号」，RS 码因此天然按字节纠错（CD/QR 的物理基础）；$\mathbb{F}_p$ 适合整数意义的结构（格、密码）。
- **共轭类与最小多项式**：$\alpha$ 的最小多项式把 $\mathbb{F}_{2^m}$ 的 $m$ 个共轭元捆成一个不可约因子——BCH 码的生成多项式正是按共轭类取 lcm 拼出来的。
