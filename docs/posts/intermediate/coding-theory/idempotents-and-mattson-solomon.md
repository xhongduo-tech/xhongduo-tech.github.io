## 为什么从幂等元开始

上一节我们建立了循环码的基本定理：每个循环码由一个生成多项式 $g(x)$ 生成，$g \mid (x^n-1)$。但 $g(x)$ 不是唯一的描述方式——同一个理想有无数个生成元（$g$ 的任意多项式倍式都能生成它）。这带来一个尴尬：**「理想由 $g$ 生成」并不挑出唯一的 $g$**。

幂等元（idempotent）解决这个问题：每个循环码都有一个**唯一**的「自身平方等于自身」的生成元，它像一把钥匙，把码的代数结构完全锁进一个多项式里。Mattson-Solomon 多项式则是这把钥匙的另一面：它把码字看成「在一组根上取值」，用有限域版本的傅里叶变换把码的结构翻译成频谱。<span class="marginnote">这两个概念都默认一个前提：$\gcd(n, q) = 1$，即 $x^n - 1$ 无重根。若 $n$ 被域的特征整除（如二元码的 $n$ 为偶数），$x^n-1$ 有重根，幂等元理论要打折扣——工程上常用「把 $n$ 取成与 $q$ 互素」来绕开。</span>这一节偏理论，但它给出的「码 ↔ 频谱」视角，是分析 BCH 码重量分布与设计最优码的暗器。

## 1 幂等元的定义与唯一性

**幂等元（idempotent）**：$R_n$ 中满足 $e(x)^2 = e(x)$ 的元素。名字来自拉丁文「idem + potens」——「同一个幂」，即平方不变。

平凡幂等元有两个：$0$（$0^2 = 0$）和 $1$（$1^2 = 1$）。非平凡的如 $x^7-1$ 的因式分解结构会给出更多。<span class="marginnote">在整数模 $n$ 里，幂等元也常见：$\mathbb{Z}/6\mathbb{Z}$ 里 $3^2 \equiv 3$、$4^2 \equiv 4$。幂等元是「把环切成直和块的投影算子」——$e$ 与 $1-e$ 把环劈成两个互补的部分。</span>

**定理（唯一幂等生成元）：** 若 $\gcd(n, q) = 1$，则每个循环码 $\mathcal{C}$ 有**唯一**的幂等元 $e(x)$ 满足 $\mathcal{C} = \langle e(x) \rangle$。

证明思路分两步：

1. **存在**：取 $\mathcal{C}$ 的生成多项式 $g(x)$。因为 $\gcd(n,q)=1$，$x^n-1$ 无重根，存在多项式 $a(x)$ 使 $a(x)g(x) \equiv 1 \pmod{h(x)}$（$g$ 与 $h$ 互素）。可构造 $e(x) = a(x)g(x)$ 的某种组合使其幂等；
2. **唯一**：若 $e_1, e_2$ 都幂等且生成同一理想，则 $e_1 = e_1 \cdot 1 \equiv e_1 \cdot (\text{由 } e_2 \text{ 生成})$，两方向一夹逼出 $e_1 = e_2$。

**重点：幂等元 $e(x)$ 是「这个码的身份证」。** 生成多项式 $g(x)$ 可以乘上别的因式变成别的生成元，但幂等元只有那一个。<span class="marginnote">直觉：$g$ 是「基」，$e$ 是「在这个基上的恒等投影」。任何生成元 $f$ 都能写成 $f = e \cdot \text{某元}$，但只有 $e$ 本身满足「平方不动」——它站在所有生成元的中心。</span>

## 2 幂等元的取值：在根上打 1 或 0

幂等元最漂亮的刻画在「根」的视角下展开。设 $\alpha$ 是 $\mathbb{F}_q$ 扩域里的一个 $n$ 次本原单位根（$\alpha^n = 1$ 且 $\alpha^i \neq 1$ for $0 \lt  i \lt  n$）。

**定理：** 设 $\mathcal{C} = \langle g(x) \rangle$，$h(x) = (x^n-1)/g(x)$，则 $\mathcal{C}$ 的幂等元 $e(x)$ 在 $n$ 次单位根上取值是「0/1 指示函数」：

$$e(\beta) = 0 \;(\beta \text{ 是 } g \text{ 的根}), \qquad e(\gamma) = 1 \;(\gamma \text{ 是 } h \text{ 的根})$$

验证很直接：$e(x) \in \mathcal{C}$ 意味着 $e(x)$ 是 $g$ 的倍式，所以在 $g$ 的根 $\beta$ 处 $e(\beta) = 0$；又 $e(x) \equiv 1 \pmod{h}$（由 CRT 分解 $R_n \cong \mathbb{F}_q[x]/(g) \times \mathbb{F}_q[x]/(h)$，幂等元在自身理想上恒等），故在 $h$ 的根 $\gamma$ 处 $e(\gamma) = 1$。<span class="marginnote">这等于说：<strong>幂等元就是「码的根集」的反向特征函数——在生成多项式的根处清零、在其余单位根处取 1</strong>。它把「码的根集」从抽象的代数概念，变成了一个可具体写出的多项式。BCH 码正是「先定根集、再找幂等元/生成多项式」的设计范式。</span>

**辨析｜易错点：** 别把幂等元的取值方向记反。码字是 $g$ 的倍式，在 $g$ 的根处**必然为 0**；「取 1」发生在 $h$ 的根（非 $g$ 的根）上。这对应频域的「掩膜」：谱在 $g$ 的根处被置零（信息被滤掉），在 $h$ 的根处保持原样。

**例（$[7,4]$ Hamming 码）**：取 $g(x) = x^3 + x + 1$，其根是 $\alpha, \alpha^2, \alpha^4$（$\alpha$ 为 $\mathbb{F}_8$ 的本原元）；$h(x) = x^4 + x^2 + x + 1$ 的根是 $1, \alpha^3, \alpha^5, \alpha^6$。幂等元 $e(x) = x^4 + x^2 + x$：它在 $g$ 的根处取 0、在 $h$ 的根处取 1（如 $e(1) = 1$），且 $e^2 = e$、生成同一个 $[7,4]$ 码——下一节会完整推导它。

## 3 Mattson-Solomon 多项式：有限域上的傅里叶变换

**Mattson-Solomon（MS）多项式** 把「码字 → 频谱」这件事严格化。对码字 $a(x) = \sum_{i=0}^{n-1} a_i x^i$，定义

$$A(z) = \sum_{j=0}^{n-1} a(\alpha^j) z^{n-1-j}$$

其中 $\alpha$ 是 $n$ 次本原单位根。<span class="marginnote">对比第三级《数字信号处理》里的 DFT：$X_k = \sum_{i} x_i \omega^{ik}$。「在 $\alpha^j$ 处求值」$a(\alpha^j) = \sum_i a_i \alpha^{ij}$ 与 DFT 的求和完全同构——MS 变换就是 DFT 的有限域版，只是求和上标换成了乘法群 $\{1, \alpha, \dots, \alpha^{n-1}\}$。</span>

**逆变换**（对应 IDFT）：

$$a(x) = \frac{1}{n} \sum_{j=0}^{n-1} A(\alpha^j) x^j$$

所以 MS 变换是可逆的线性映射：码字 $\leftrightarrow$ 频谱一一对应，且「谱的零结构」编码着码的关键信息。

**核心结论：码字 $a(x)$ 的重量等于「谱里非零点的个数」的补。** 更精确地说，

$$\mathrm{wt}(a) = n - \#\{j \mid a(\alpha^j) = 0\}$$

因为 $a(\alpha^j)$ 是「$a$ 在第 $j$ 个根处的值」，而 $a$ 若在某个根处取 0，说明 $g$ 的根集「吃掉」了 $a$ 的一个自由度。<span class="marginnote">这把重量分布问题翻译成了「谱的支撑大小」问题——而谱的结构由根集决定，根集由 $g$ 决定。于是「算重量分布」变成「数频谱非零点的个数」，MS 多项式是这条翻译链的中间桥梁。</span>

## 4 公式解析：MS 变换为什么是「逐位独立」的

把 MS 变换的公式拆开，理解它为何能成为傅里叶变换。

- **第一步，把求值展开**：$a(\alpha^j) = \sum_{i=0}^{n-1} a_i \alpha^{ij}$。这里 $\alpha^{ij}$ 扮演了 DFT 的旋转因子 $\omega^{ij}$——它是「第 $i$ 位输入对第 $j$ 个频率的贡献」。
- **第二步，矩阵视角**：MS 变换是矩阵 $F = (\alpha^{ij})_{i,j}$ 作用在系数向量上，$F$ 是有限域上的 **Vandermonde 矩阵**（由 $\alpha^j$ 的幂构成）。因为 $\alpha$ 是本原 $n$ 次单位根，$F$ 可逆——这正是「无重根」条件 $\gcd(n,q)=1$ 的用处：保证 $F$ 非退化。
- **第三步，卷积定理的类比**：循环码里「乘 $x$」是移位，移位在频域就是逐点乘 $\alpha^j$；「乘 $g(x)$」在频域是逐点乘 $g(\alpha^j)$。「码 = $g$ 的倍式」在频域翻译成「谱在 $g$ 的根处必须为 0」——这正是上节「根定义码」的频谱版本。

**直觉：** 幂等元在频域是「0/1 掩膜」（在根处为 1、否则为 0），生成多项式在频域是「掩膜乘以 $g(\alpha^j)$」。二者一个「滤波」、一个「成形」，都在频谱上操作——码理论里的构造，常常就是设计一个频谱掩膜。

## 5 幂等元与 MS 多项式的联姻

把两个概念拼起来，会得到一个工程上极其有用的对偶描述。

**定理：幂等元 $e(x)$ 的 MS 多项式 $\bar{E}(z)$ 与「根的指示函数」互为傅里叶对。** 具体地，设 $\mathcal{C}$ 的幂等元为 $e(x)$，则它的 MS 多项式在单位根上的取值是

$$E(\alpha^j) = \begin{cases} 1, & j \equiv 0 \pmod{\text{该循环}}\cdots \end{cases}$$

——更实用的事实是：**码的重量枚举器可以由幂等元的 MS 谱直接读出**。对二元循环码，$\mathcal{C}$ 的重量分布等于

$$A_i = \#\{c \in \mathcal{C} \mid \mathrm{wt}(c) = i\}$$

而每个码字的重量由「谱非零点的个数」给出。当码字数 $2^k$ 仍很大时，MS 视角不直接省枚举，但配合 MacWilliams 恒等式与「谱稀疏」结构，能推导出重量分布的闭合公式。<span class="marginnote">经典例子：$[7,4]$ Hamming 码的 MS 分析能干净地导出重量分布 $(1,0,0,7,7,0,0,1)$，无需逐字枚举；对更长的 BCH 码，MS 工具是分析「重量分布长什么样」的主要理论手段。</span>

**辨析｜易错点：** MS 变换里的「求值」必须在包含 $\alpha$ 的扩域里做，结果一般落在扩域而非 $\mathbb{F}_q$ 里；逆变换要除以 $n$，而 $n$ 在特征 $p$ 下当且仅当 $p \nmid n$ 才可逆。**先确认 $\gcd(n,q)=1$，再做 MS 变换**——这是本节的隐含前提，忘了它一切公式都会在除法上崩掉。

## 6 实例：完整推导 $[7,4]$ Hamming 码的幂等元

把上节的结果亲手推一遍。$g(x) = x^3 + x + 1$，$x^7 - 1 = (x+1)(x^3+x+1)(x^3+x^2+1)$，所以

$$h(x) = \frac{x^7-1}{g(x)} = x^4 + x^2 + x + 1$$

**目标**：找一个次数 $\lt  7$ 的多项式 $e(x)$，满足 $e \equiv 0 \pmod{g}$ 且 $e \equiv 1 \pmod{h}$，且 $e^2 = e$。

第一步，$e \equiv 0 \pmod g$ 要求 $e(x) = g(x) \cdot q(x)$，先试 $q(x) = x$，得 $e_0(x) = x^4 + x^2 + x$。

第二步，检查 $e_0 \bmod h$：$e_0 - h = (x^4+x^2+x) - (x^4+x^2+x+1) = 1$，所以 $e_0 \equiv 1 \pmod h$——条件全部满足。

第三步，验证幂等：$e_0^2 = (x^4+x^2+x)^2 = x^8 + x^4 + x^2 = x + x^4 + x^2 = e_0$（叉乘项在特征 2 下成对消失，$x^8 = x$）。所以 $e(x) = x^4 + x^2 + x$ 就是我们要的幂等元。

第四步，核对取值表：

| 单位根 | 1 | $\alpha$ | $\alpha^2$ | $\alpha^3$ | $\alpha^4$ | $\alpha^5$ | $\alpha^6$ |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 是否为 $g$ 的根 | 否 | 是 | 是 | 否 | 是 | 否 | 否 |
| $e$ 的取值 | 1 | 0 | 0 | 1 | 0 | 1 | 1 |

与定理完全吻合。<span class="marginnote">这套「先定根集 → CRT 解同余 → 验证幂等」的流程，是把任意循环码「翻译成幂等元」的标准操作。手工算 $[7,4]$ 还可行，码长上百时就得靠多项式算法与计算机——但原理不变。</span>有了 $e(x)$，编码可以改用「消息与 $e(x)$ 的某种组合」，重量分布的谱分析也有了具体的出发点。

## 7 小结

- **幂等元** $e(x)^2 = e(x)$：$\gcd(n,q)=1$ 时每个循环码有**唯一**幂等生成元，是码的「身份证」。
- 幂等元的取值是指示函数：在 $g(x)$ 的根处为 0、在 $h(x)$ 的根处为 1——「根集的掩膜」，别记反方向。
- **MS 多项式** $A(z) = \sum_j a(\alpha^j) z^{n-1-j}$：有限域上的 DFT，码字 ↔ 频谱一一对应。
- 重量 = $n$ − 谱零点个数：重量分布问题翻译成「数频谱非零点」问题。
- 幂等元与 MS 变换联手：码的谱结构由根集决定，重量分布可被系统推导。
- 全程前提 $\gcd(n,q)=1$（$x^n-1$ 无重根），做 MS 变换前务必确认。
