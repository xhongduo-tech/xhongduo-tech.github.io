## 为什么从循环码开始

前面五节建立起一个完整的线性码理论，但缺一样东西：**构造**。随机挑一个 $[n,k,d]$ 线性码，距离可能不错，可它的生成矩阵是一张「长得像噪声」的表，编码、译码都要处理任意矩阵，既慢又难分析。工程需要「有结构、可快速运算、距离可证明」的码。

循环码（cyclic code）用一条额外约束换取全部结构：**码字循环移位后仍是码字**。这条看似温柔的约束，把码从「向量空间」提升为「多项式环里的理想」，让有限域 + 多项式的全部代数火力都倾泻进来。<span class="marginnote">在第六级《数字信号处理》里你见过「圆周卷积」——DFT 的移位不变性。循环码的「乘 $x$ 模 $x^n-1$」正是同一件事的代数版本：循环移位 = 乘以一个固定的轮转算子。两者共享同一个「循环结构 = 可对角化」的数学内核。</span>BCH 码、Reed-Solomon 码、代数几何码全部是循环码或循环码的近亲。这一节是整部编码理论的承重墙。

## 1 循环码的定义

**循环码（cyclic code）**：一个 $[n, k]$ 线性码 $\mathcal{C}$，若满足「$\boldsymbol{c} = (c_0, c_1, \dots, c_{n-1}) \in \mathcal{C} \implies (c_{n-1}, c_0, c_1, \dots, c_{n-2}) \in \mathcal{C}$」，即任意码字右移一位仍在码中，则称为循环码。<span class="marginnote">注意定义要求<strong>任意</strong>移位都保持——右移一次成立，右移 $n$ 次回到自己，所以等价于「循环移位」（shift register 的闭环）。这不是「恰好有一条对称」，而是「整个码对轮转运算封闭」。</span>

先看两个例子。**全零码、全空间 $\mathbb{F}_q^n$、重复码**都是循环码（平凡例子）。**单校验位码** $[n, n-1, 2]$：码字满足 $\sum c_i = 0$，循环移位不改变求和，仍是码字——是循环码。**$[7,4]$ Hamming 码**（按合适顺序排校验矩阵列）也是循环码——事实上它对应下面要讲的一个特定的生成多项式。

## 2 多项式表示：把码字写成多项式

把向量与多项式一一对应：$\boldsymbol{c} = (c_0, \dots, c_{n-1})$ 对应 $c(x) = c_0 + c_1 x + \cdots + c_{n-1} x^{n-1}$。

**重点：循环移位在多项式语言里就是「乘以 $x$ 再模 $x^n - 1$」。** 因为

$$x \cdot c(x) = c_0 x + c_1 x^2 + \cdots + c_{n-1} x^n$$

而 $x^n \equiv 1 \pmod{x^n - 1}$，所以 $x \cdot c(x) \bmod (x^n-1) = c_{n-1} + c_0 x + \cdots + c_{n-2} x^{n-1}$——正是右移一位的结果。<span class="marginnote">这解释了为什么「模 $x^n-1$」而非别的多项式：$x^n \equiv 1$ 恰好让最高位回到最低位，形成环。$(x^n-1)$ 这个多项式是整个循环码理论的「环模」，后面的一切都发生在这个商环里。</span>

于是所有运算都搬进了**多项式商环**

$$R_n = \mathbb{F}_q[x] / (x^n - 1)$$

码字是 $R_n$ 里的元素，循环移位是「乘以 $x$」这个环作用。**循环码 = $R_n$ 中对「乘 $x$」封闭的线性子空间**。而「对乘 $x$ 封闭的线性子空间」在环论里有个现成的名字——**理想（ideal）**。

## 3 循环码就是环里的理想

**定理：$\mathbb{F}_q^n$ 的循环码与 $R_n$ 的理想一一对应。** 证明只要三步：

1. 循环码对「乘 $x$」封闭（定义）；
2. 对任意多项式 $a(x)$，「乘 $a(x)$」是「乘若干次 $x$」的线性组合，所以循环码对任意「乘 $a(x)$」封闭；
3. 对「乘以任意元」封闭的加法子群 = 理想。

而 $R_n = \mathbb{F}_q[x]/(x^n-1)$ 是**主理想环**——这个性质在第二级《抽象代数》里学过：多项式环商掉首一多项式后，每个理想都由一个多项式生成。<span class="marginnote">主理想环是循环码全部好处的根源：理想由一个生成元撑起，意味着整个码可由<strong>一个多项式</strong>描述，而不是一整张生成矩阵。编码理论的「压缩」在此达到极致：$[n,k]$ 码的 $k \times n$ 矩阵退化成 1 个多项式。</span>

**推论：每个循环码 $\mathcal{C}$ 都存在唯一一个首一多项式 $g(x)$，使得 $\mathcal{C} = (g(x)) = \{a(x) g(x) \bmod (x^n-1)\}$，且 $g(x)$ 整除 $x^n - 1$。**

## 4 公式解析：生成多项式 $g(x)$ 与维数

**生成多项式（generator polynomial）** $g(x)$ 是循环码里「次数最低、首一」的非零多项式。它完全决定码。

- **第一步，$g(x)$ 整除 $x^n - 1$**：因为 $g(x)$ 是最低次非零元，而「用 $g$ 去模 $x^n-1$ 的余数」仍是码元（理想性质），若余数非零则次数更低，矛盾；故余数为零，即 $g \mid x^n-1$。
- **第二步，$\deg g = n - k$**：码 $\mathcal{C} = \{a(x) g(x)\}$，作为 $\mathbb{F}_q$ 向量空间，一组基是 $g, xg, x^2 g, \dots, x^{k-1} g$，共 $k$ 个（因为 $\deg g = n-k$，乘以 $x^{k-1}$ 后次数仍 $\lt  n$）。故 $\dim \mathcal{C} = k = n - \deg g$。
- **第三步，编码**：消息多项式 $u(x)$（次数 $\lt  k$）编码为 $c(x) = u(x) g(x)$；系统形式则先让 $u(x)$ 占前 $k$ 位，用多项式除法算校验位。

$$[n, k] \text{ 循环码 } \mathcal{C} = \langle g(x) \rangle, \qquad \deg g(x) = n - k, \qquad g(x) \mid (x^n - 1)$$

**直觉：** 选 $g(x)$ 就是在选码——它把「$x^n-1$ 的因式」当建材，每次挑几个因式相乘，就造出一个循环码。这让我们可以**按需要的距离去挑因式**（下一节 BCH 码正是这样干的）。<span class="marginnote">例如二元 $[7,4]$ Hamming 码取 $g(x) = x^3 + x + 1$，它整除 $x^7 - 1 = (x+1)(x^3+x+1)(x^3+x^2+1)$。二元域上 $x^3+x+1$ 的根是本原元，这预示着它与「根集」理论的联系——BCH 码将以「根」为设计语言。</span>

## 5 校验多项式 $h(x)$：对偶码也在环里

**校验多项式（parity-check polynomial）**：定义

$$h(x) = \frac{x^n - 1}{g(x)}, \qquad \deg h = k$$

**重点：$\mathcal{C}$ 的对偶码 $\mathcal{C}^\perp$ 的生成多项式是 $\tilde{h}(x) = x^k h(x^{-1})$**（把 $h$ 的系数倒过来），所以 $[n, n-k]$ 循环码的对偶仍是循环码。直观验证：$c(x) \in \mathcal{C}$ 与 $a(x) \in \mathcal{C}^\perp$ 正交当且仅当 $c(x) a(x) \equiv 0 \pmod{x^n - 1}$ 的某个系数条件成立，而 $g$ 与 $h$ 相乘为 $x^n-1$ 保证了这个正交性。<span class="marginnote">这与第5篇「校验矩阵 = 对偶码生成矩阵」完全呼应——循环码的对偶还是循环码，由「补因式」$h(x)$ 生成。一对互补的因式，描述一对互补的码。</span>

编码也可以用 $h$：系统循环码里，$c(x) = x^{n-k} u(x) - r(x)$，其中 $r(x)$ 是 $x^{n-k}u(x)$ 除以 $g(x)$ 的余数，满足「$c(x)$ 是 $g(x)$ 的倍式」这个循环码的等价刻画——校验在译码端就是「检查能否被 $g$ 整除」。

## 6 一个具体的系统编码

**系统编码**要求前 $k$ 位就是消息。做法：消息 $u(x)$ 先左移 $n-k$ 位（乘 $x^{n-k}$），再减去「除以 $g(x)$ 的余数」$r(x)$，得到

$$c(x) = x^{n-k} u(x) - r(x), \qquad r(x) \equiv x^{n-k} u(x) \pmod{g(x)}$$

这样 $c(x)$ 是 $g(x)$ 的倍式（循环码成员），且低 $n-k$ 位恰是校验位。

**实例：$[7,4]$ 循环码，$g(x) = x^3 + x + 1$，编码消息 $u = 1101$（$u(x) = x^3 + x^2 + 1$）。**

第一步，左移三位：$x^3 u(x) = x^6 + x^5 + x^3$。

第二步，多项式长除求余：

- $x^6$ 除以 $x^3$ 得 $x^3$，减去 $x^3 g(x) = x^6 + x^4 + x^3$，余 $x^5 + x^4$；
- $x^5$ 除以 $x^3$ 得 $x^2$，减去 $x^2 g(x) = x^5 + x^3 + x^2$，余 $x^4 + x^3 + x^2$；
- $x^4$ 除以 $x^3$ 得 $x$，减去 $x g(x) = x^4 + x^2 + x$，余 $x^3 + x$；
- $x^3$ 除以 $x^3$ 得 $1$，减去 $g(x) = x^3 + x + 1$，余 $x^2 + x + 1$。

第三步，拼码字：$c(x) = x^3 u(x) + r(x) = x^6 + x^5 + x^3 + x^2 + x + 1$，即 $\boldsymbol{c} = 1101111$。前四位 $1101$ 就是消息，后三位 $111$ 是校验位。<span class="marginnote">整个编码就是一次多项式除法——硬件用带反馈的移位寄存器（LFSR）实现：一个 $n-k$ 级的寄存器，反馈抽头由 $g(x)$ 系数决定，$n$ 个时钟周期内完成一次编码。这也是「循环码 = 工程可实现」的实锤。</span>

**检查**：$c(x)$ 能否被 $g(x)$ 整除？直接验证 $x^6+x^5+x^3+x^2+x+1$ 除以 $x^3+x+1$ 余 0（长除留给读者），或等价地验证 $c$ 落在由 $g$ 生成的码里。这个「能否被 $g$ 整除」的测试，就是下一节伴随式译码的原型——`$r(x) \bmod g(x)$` 非零即出错。

## 7 循环码为什么好：从矩阵到多项式

把线性码那一节的三个工具换到多项式语言：

| 线性码 | 循环码 |
| --- | --- |
| 生成矩阵 $G$（$k \times n$） | 生成多项式 $g(x)$（1 个） |
| 校验矩阵 $H$（$(n-k)\times n$） | 校验多项式 $h(x)$（1 个） |
| 编码 $\boldsymbol{c} = \boldsymbol{u}G$ | $c(x) = u(x) g(x)$ |
| 伴随式 $H\boldsymbol{r}^T$ | $r(x) \bmod g(x)$ |

**编码 = 乘法**（$O(n^2)$ 次域运算，硬件上是移位寄存器），**伴随式 = 取余**（一次多项式除法），**存储 = 两个多项式**。<span class="marginnote">工程意义是革命性的：一个 $[255, 239]$ 的 Reed-Solomon 码，生成矩阵是 $239 \times 255$ 的大表，而循环表示只要 17 个校验多项式系数——体积缩小上千倍，速度提升几个数量级。这也是为什么 CD、DVD、磁盘、深空链路里跑的几乎全是循环码族。</span>下一次要学的 BCH 码，正是「在循环码框架里按根的需求挑 $g(x)$」的直接产物。

## 8 小结

- **循环码** = 移位封闭的线性码；移位 = 多项式「乘 $x$ 模 $x^n-1$」。
- 码字 ↔ 多项式、移位 ↔ 乘 $x$，全部运算落在商环 $R_n = \mathbb{F}_q[x]/(x^n-1)$ 里。
- **循环码 = $R_n$ 的理想**；主理想环保证每个码由一个首一多项式生成。
- **生成多项式 $g(x)$**：次数最低的首一项，$\deg g = n-k$，且 $g \mid (x^n-1)$；编码 $c(x) = u(x)g(x)$。
- **校验多项式 $h(x) = (x^n-1)/g(x)$**；对偶码仍为循环码，由反向 $h$ 生成。
- 循环性把「矩阵 → 多项式」：编码变乘法、伴随式变取余、存储缩至两个多项式，是工程可行性的关键一跃。
