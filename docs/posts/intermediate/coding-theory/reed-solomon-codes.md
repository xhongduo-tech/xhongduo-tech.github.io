## 为什么从 Reed-Solomon 码开始

上一节我们见识了 BCH 码「用根设计距离」的威力，但它有个工程上的「浪费」：根在 $\mathbb{F}_{q^m}$ 里、符号在 $\mathbb{F}_q$ 里，共轭外溢让生成多项式的次数虚高，信息维数 $k$ 被白白吃掉。能不能把符号域直接提到根所在的域，让每个根都「物尽其用」？

Reed-Solomon 码（RS 码）正是这样做的：**符号域 = 根域 = $\mathbb{F}_q$**，于是每个根的最小多项式都是一次的，共轭外溢消失，$k$ 达到最大可能——**Singleton 界的等号**。RS 码因此是编码理论里最优雅的存在：参数 $[n, k, n-k+1]$ 无可挑剔，且处处达到理论极限。<span class="marginnote">RS 码是 Irving Reed 与 Gustave Solomon 在 1960 年提出的，比 BCH 码早、且更简单：它不绕道「循环码 + 根」，而是直接「把消息当多项式，在若干点上求值」。工程上 CD/DVD、二维码、太空链路、Wi-Fi 里大量使用 RS 码或其级联——它是符号纠错的事实标准。</span>

## 1 从求值到码字：RS 码的定义

**RS 码的构造：** 固定符号域 $\mathbb{F}_q$，取 $n$ 个互不相同的求值点 $\alpha_1, \dots, \alpha_n \in \mathbb{F}_q$（通常 $n \le q$；取遍全部非零元时 $n = q-1$，码是循环的）。设消息是次数 $\lt  k$ 的多项式 $f(x)$，把 $f$ 的 $k$ 个系数当作消息符号。编码：

$$\boldsymbol{c} = (f(\alpha_1), f(\alpha_2), \dots, f(\alpha_n)) \in \mathbb{F}_q^n$$

即**码字 = 消息多项式在所有求值点上的取值**。这样的码叫 **RS 码**，记作 $\mathrm{RS}_q(n, k)$。<span class="marginnote">这是「求值码（evaluation code）」的鼻祖：把抽象的多项式「物化」成一组离散采样。接收端拿到 $n$ 个采样值，若其中 $\le t$ 个被噪声污染，仍能通过「找次数 $\lt  k$ 且与多数采样吻合的多项式」恢复 $f$——采样越多、冗余越大，抗污染能力越强。</span>

**为什么消息是「多项式」而非「向量」？** 因为多项式有强大的代数性质：次数 $\lt  k$ 的非零多项式至多有 $k-1$ 个根。这个看似简单的性质（代数学基本定理的有限域版本），就是 RS 码全部纠错能力的来源。

## 2 参数与 MDS 性质

**RS 码的参数：** $\mathrm{RS}_q(n, k)$ 是 $[n, k, n-k+1]$ 线性码。

**码长** $n$：等于求值点个数（$n \le q$）；
**维数** $k$：消息多项式次数 $\lt  k$，系数空间是 $k$ 维；
- **最小距离** $d = n - k + 1$。

**重点：RS 码达到 Singleton 界（$d = n-k+1$），是 MDS 码。**

为什么距离这么大？看下一节的公式解析——一句话版本是：**两个不同的次数 $\lt  k$ 多项式之差仍是次数 $\lt  k$ 的非零多项式，至多有 $k-1$ 个根，所以两个码字在至少 $n - (k-1)$ 个求值点上不同**。用 $n-k$ 个校验符号，换来了恰好 $n-k+1$ 的距离——一分冗余、一分距离，一点不浪费。<span class="marginnote">$d = n-k+1$ 是最优的：任何 $[n,k]$ 码的 $d \le n-k+1$（Singleton 界），RS 码全部取等，故称 MDS（maximum distance separable）。MDS 码的几何语言是「$k$ 维子空间与任意 $n-k$ 个坐标超平面都横截相交」——见第 13 篇《MDS 码》详谈。</span>

## 3 公式解析：为什么 $d = n-k+1$

证明「任意两个码字至少距离 $n-k+1$」，等价于证明「任意非零码字重量至少 $n-k+1$」。

**第一步，非零码字 ↔ 非零多项式**：$f(x) \neq 0$（否则码字为零）。设 $f$ 是次数 $\lt  k$ 的非零多项式。
**第二步，根数上界**：$\mathbb{F}_q$ 上的非零 $k-1$ 次多项式至多有 $k-1$ 个根（有限域的代数基本定理：$n$ 次多项式至多 $n$ 个根，这里次数 $\le k-1$）。
- **第三步，计数**：码字 $(f(\alpha_1), \dots, f(\alpha_n))$ 的零分量恰是 $f$ 的根落在求值点集合里的那些位置，最多 $k-1$ 个；非零分量至少 $n - (k-1) = n-k+1$ 个。故 $\mathrm{wt}(\boldsymbol{c}) \ge n-k+1$。

**直觉：** 多项式「太光滑」，低次多项式不能到处穿越零点。次数限制 $k-1$ 直接上界住了「码字里的零」，也就下界住了「非零位置数」。反过来看，$k$ 越大（多项式越能弯曲），根越多、码字越容易碰零、距离越小——**$k$ 与 $d$ 的此消彼长，在 RS 码里是代数基本定理的直接推论**。

## 4 编码的两种实现

### 非系统编码：直接求值

消息 $(m_0, \dots, m_{k-1})$ → 多项式 $f(x) = \sum m_i x^i$ → 码字 $c_j = f(\alpha_j)$。复杂度 $O(kn)$，简单直接，但码字里不直接含消息——译码要先恢复多项式才能读出消息。<span class="marginnote">求值编码在硬件里是一排并行的多项式求值器，每个求值点一个。对 $n = q-1$ 的循环 RS 码，可用多项式乘法 $c(x) = u(x) g(x)$ 实现，其中 $g(x) = \prod_{i=1}^{n-k}(x - \alpha^i)$——这是 BCH 框架下 RS 码的循环形式。</span>

### 系统编码：消息在前

系统形式要求前 $k$ 个符号就是消息。做法：把求值点排序后，取前 $k$ 个点做「多项式插值」——直接令 $f(\alpha_j) = m_j$（$j = 1, \dots, k$）确定唯一次数 $\lt  k$ 的 $f$（Lagrange 插值），再在剩余 $n-k$ 个点上求值当校验符号。<span class="marginnote">Lagrange 插值：$f(x) = \sum_{j=1}^k m_j \prod_{l \ne j} \frac{x - \alpha_l}{\alpha_j - \alpha_l}$。它保证「前 $k$ 个采样 = 消息」的同时，把多项式唯一确定下来。系统编码天然适合「带外校验」的存储协议：数据区原样存放，校验区附加。</span>

## 5 实例：$[7,3,5]$ RS 码的求值编码

在 $\mathbb{F}_8$ 上走一遍完整编码。取 $\mathbb{F}_8$ 的本原元 $\alpha$（$\alpha^3 = \alpha + 1$），求值点取全部非零元 $\alpha^0, \alpha^1, \dots, \alpha^6$，$n = 7$。取 $k = 3$，则 $d = 7 - 3 + 1 = 5$，$t = 2$——纠 2 个错误符号。

设消息为 $(m_0, m_1, m_2) = (1, \alpha, \alpha^2)$，对应的消息多项式

$$f(x) = 1 + \alpha x + \alpha^2 x^2$$

逐点求值（用到 $\alpha^3 = \alpha+1$、$\alpha^7 = 1$）：

| 求值点 | $f(\alpha^j)$ | 二元表示 |
| --- | --- | --- |
| $\alpha^0 = 1$ | $1 + \alpha + \alpha^2$ | `111` |
| $\alpha$ | $1 + \alpha$ | `011` |
| $\alpha^2$ | $1 + \alpha + \alpha^2$ | `111` |
| $\alpha^3$ | $1 + \alpha^2$ | `101` |
| $\alpha^4$ | $1 + \alpha^2$ | `101` |
| $\alpha^5$ | $1 + \alpha$ | `011` |
| $\alpha^6$ | $1$ | `001` |

码字是这 7 个符号的串。**观察三点**：第一，同一个消息多项式在相邻求值点上会「重复」取值（如 $f(1) = f(\alpha^2)$）——这是多项式光滑性的体现，恰好是「任何两次求值不可能太接近」的来源；第二，码字里出现了两次 $1+\alpha+\alpha^2$、两次 $1+\alpha^2$——重量分布并非均匀，但**最轻的非零码字也有重量 5**（由 $d=5$ 保证）；第三，任意删掉 $d-1 = 4$ 个符号，剩下 3 个采样仍足以唯一恢复 $f$（次数 $\lt  3$ 的多项式被 3 个点唯一确定）——这就是 MDS「最大距离可分」的操作性含义。<span class="marginnote">「3 个点定一个二次多项式」是 Lagrange 插值的标准事实：$k$ 个点定 $k-1$ 次多项式。RS 码把这条中学代数事实放大成纠错机制：只要 $n-k = 4$ 个校验符号里最多 $t=2$ 个被污染，剩下的采样仍能锁定 $f$。</span>

**验证距离**：若另一消息 $\hat{f}$ 与 $f$ 不同，$f - \hat{f}$ 是次数 $\le 2$ 的非零多项式，至多 2 个根，所以在至少 $7-2 = 5$ 个求值点上两个码字不同——$d \ge 5$，且恰好等于 5。

## 6 广义 RS 码：给求值点加权

**广义 RS 码（GRS 码）** 在 RS 码上加了「列乘子」：固定非零向量 $\boldsymbol{v} = (v_1, \dots, v_n)$，定义

$$\boldsymbol{c} = (v_1 f(\alpha_1), v_2 f(\alpha_2), \dots, v_n f(\alpha_n))$$

即每个求值点上的值再乘一个权重 $v_i \neq 0$。<span class="marginnote">乘子 $v_i$ 相当于「给采样点装不同的灵敏度」。$v_i = 1$ 时退回普通 RS。GRS 的用处：<strong>RS 码的缩短与扩展、对偶码、以及后面代数几何码的局部化构造，都自然落在 GRS 框架里</strong>。GRS 仍是最小距离 $n-k+1$ 的 MDS 码（乘非零权重不改变零的位置）。</span>

**关键事实：GRS 码的对偶仍是 GRS 码。** 具体地，$\mathrm{GRS}_k(\boldsymbol{\alpha}, \boldsymbol{v})^\perp = \mathrm{GRS}_{n-k}(\boldsymbol{\alpha}, \boldsymbol{v}')$，其中 $v_i'$ 由 $v_i$ 与「各点差分积」决定。这是第 5 篇对偶码理论在 RS 家族里的具体形态——两个 GRS 码互为对偶，参数完美互补。<span class="marginnote">一个漂亮推论：RS 码的校验矩阵可以从「求值 + 加权」直接写出来——校验矩阵的列就是「对偶 GRS 码的生成矩阵的列」。这让 RS 码的译码（下篇）可以用伴随式 + 关键方程系统展开。</span>

## 7 RS 码为什么无处不在

RS 码的成功是「理论最优 + 工程友好」的双重胜利：

**最优性**：$d = n-k+1$ 达到 Singleton 界，没有别的 $[n,k]$ 码能做得更好；
**符号级纠错**：纠正 $t$ 个错误符号，等价于纠正任何「跨 $t$ 个符号的突发错误」——一个符号错 1 位和错 8 位（一个字节）代价相同，这让 RS 码天然擅长对抗 CD 划痕、磁盘坏块这类「成串出错」；
- **快速译码**：Berlekamp-Massey 或欧几里得算法（第 12 篇）在 $O(n^2)$ 内完成译码。<span class="marginnote">CD 的 CIRC 用两级 RS 码交叉交织，能纠正长达 4000 位的突发错误；二维码的版本 40-L 用 RS 码在 3706 个码字里纠正 150 个符号错误；深空链路（Voyager、旅行者）与 DVB 广播也都用 RS 码或其级联。RS 码是「一个符号一个符号地守护数据」的通用语言。</span>

## 8 小结

- **RS 码** = 求值码：消息是次数 $\lt  k$ 的多项式，码字是它在 $n$ 个不同点上的取值。
- **参数** $[n, k, n-k+1]$，达到 **Singleton 界**，是 **MDS 码**——一分冗余换一分距离。
- 距离证明靠代数基本定理：非零 $k-1$ 次多项式至多 $k-1$ 个根。
- 编码两种：直接求值（$O(kn)$，非系统）；Lagrange 插值 + 补校验（系统，消息在前）。
- **GRS 码**加列乘子 $v_i$，仍 MDS；对偶仍是 GRS，是 RS 族最自然的包装。
- 符号级纠错 + 抗突发 + 快速译码，让 RS 码统治光盘、二维码、深空与无线链路。
- 实例：$\mathbb{F}_8$ 上 $[7,3,5]$ 码，消息 $(1,\alpha,\alpha^2)$ 编码为 7 个求值符号，$d=5$ 由「非零多项式至多 2 个根」保证。
- 编码一条龙：非系统直接求值；系统用 Lagrange 插值保证「前 $k$ 个采样 = 消息」。
- GRS 码的列乘子不改距离，只改「对偶形状」；RS 族对偶仍是 GRS，为译码提供校验矩阵。
- RS 码选参一条：$n \le q$、$k$
