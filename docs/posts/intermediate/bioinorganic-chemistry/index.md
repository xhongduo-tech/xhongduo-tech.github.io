# 生物无机化学

生物无机化学研究金属离子与金属配合物在生物体系中的结构、功能、调控与转化，是连接无机化学与生命科学的交叉分支。从血红素载氧到金属酶催化再到金属药物的设计，它揭示了生命运转中的金属化学逻辑，是理解金属酶、金属蛋白与铁卟啉体系的关键学科。

## 对标教材

- Stephen J. Lippard, Jeremy M. Berg, "Principles of Bioinorganic Chemistry" (University Science Books)
- Ivano Bertini, Harry B. Gray, Stephen J. Lippard, Joan Selverstone Valentine, "Bioinorganic Chemistry" (University Science Books)
