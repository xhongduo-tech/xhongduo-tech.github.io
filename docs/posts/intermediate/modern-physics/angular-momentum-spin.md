# 角动量与自旋

## 为什么从角动量与自旋开始

前面几篇里的「能级」只用了主量子数 $n$。但原子光谱的**精细结构**、磁场中的**塞曼分裂**、元素周期表的全部结构，都指向同一个事实：电子还有更多隐藏的自由度。玻尔模型之所以算不出这些，是因为它遗漏了**角动量**与**自旋**这两个量子数维度。<span class="marginnote">角动量量子化是量子力学里「测量只能得到若干离散值」的最纯粹体现：轨道角动量的取值由量子数 $l$ 和 $m_l$ 控制，自旋则只有两个可能的方向。理解它，就理解了「量子数的世界」——一切都从连续变成离散。</span>

而自旋 $s = 1/2$ 是标准模型的真正主角：夸克、电子、中微子全是自旋 1/2 的费米子。从它开始的「泡利不相容」直接决定了元素周期表——第 8 篇的内容，也决定了化学的整座大厦。

## 1 轨道角动量与量子数

对氢原子求解定态薛定谔方程，会自然出现三个量子数：

**主量子数 $n$**（$n = 1, 2, \dots$）：决定能级 $E_n$。
- **角量子数 $l$**（$l = 0, 1, \dots, n-1$）：决定角动量大小，$|\vec{L}| = \sqrt{l(l+1)}\,\hbar$。习惯用光谱学记号 $s, p, d, f$ 表示 $l = 0, 1, 2, 3$。
- **磁量子数 $m_l$**（$m_l = -l, -l+1, \dots, l$）：决定角动量沿外场方向的分量，$L_z = m_l \hbar$，共 $2l+1$ 个取值。

**角动量的方向也是量子化的**——$L_z$ 只能取 $2l+1$ 个离散值，角动量矢量像倾斜一定角度的陀螺绕 $z$ 轴进动，这个现象叫**空间量子化（space quantization）**。<span class="marginnote">空间量子化听起来极端：角动量与 $z$ 轴的夹角只能是若干特定值。1922 年施特恩—格拉赫实验（银原子束通过非均匀磁场）观察到束流分裂成两束，直接证实了这一点——而且银原子只有两条线，说明它由纯自旋贡献，$l=0$ 时角动量仍有非零来源。</span>

## 2 自旋的提出

1925 年，乌伦贝克（Uhlenbeck）与古兹密特（Goudsmit）为解释反常塞曼效应，提出电子具有**自旋角动量（spin）**。电子是自旋量子数 $s = 1/2$ 的粒子，它的自旋大小固定为

$$S = \sqrt{s(s+1)}\,\hbar = \frac{\sqrt{3}}{2}\hbar$$

沿任意测量方向的分量只有两个可能值

$$S_z = \pm \frac{1}{2}\hbar$$

对应两个自旋态，习惯记作**自旋向上** $\left| \uparrow \right\rangle$（$m_s = +\frac{1}{2}$）与**自旋向下** $\left| \downarrow \right\rangle$（$m_s = -\frac{1}{2}$）。<span class="marginnote">「自旋」这个名字源于类比自转的陀螺，但电子是点粒子，没有「表面」可供自转。自旋是粒子固有的、内禀的角动量——就像电荷是粒子的固有属性一样，你不能再问「为什么是 1/2」。它由相对论性量子力学（狄拉克方程）自然导出。</span>

**辨析｜易错点：** 不要用经典自转模型计算电子的「自转速度」——那会得出表面速度远超光速的荒谬结论。自旋是**内禀自由度**，与几何旋转无关；它只在角动量相加、磁矩耦合时才显形。

## 3 公式解析：自旋磁矩与 g 因子

电子带电荷，自旋带来磁矩，两者成正比：

$$\vec{\mu}_s = -g_s \frac{e}{2m_e}\vec{S}, \qquad g_s \approx 2$$

- **$\frac{e}{2m_e}$ 是旋磁比的轨道值**：由经典轨道运动推得，$\mu_L = -\frac{e}{2m_e}L$。
- **$g_s \approx 2$ 是电子的 g 因子**：自旋磁矩是轨道磁矩的约两倍，这个「2」是狄拉克方程的预言。
- **负号**：电子带负电，磁矩方向与自旋方向相反。

精确测量发现 $g_s = 2.00231930436$，比 2 多出的 $0.0023\ldots$ 来自量子电动力学（QED）的辐射修正——它是人类目前验证过的最精确的理论预言之一（精度达到 $10^{-12}$ 量级）。<span class="marginnote">电子反常磁矩与 QED 的吻合是「量子场论对得上实验」的黄金标准。这个「2 之外的小尾巴」的每一步高阶修正都对应一张费曼图，是可计算性与可测性结合的最深成就——第 12 篇我们会再见费曼图。</span>

## 4 自旋—轨道耦合与精细结构

自旋不是孤立存在：电子绕核运动，在电子的参考系里，原子核绕电子旋转产生一个磁场，这个磁场与电子自旋磁矩相互作用，能量修正

$$\Delta E_{so} \propto \frac{1}{r^3} \vec{L} \cdot \vec{S}$$

把 $\vec{L}\cdot\vec{S}$ 对角化需要把轨道角动量与自旋耦合成**总角动量** $\vec{J} = \vec{L} + \vec{S}$。结果：同一 $l$ 的能级劈裂成 $j = l \pm 1/2$ 的两条——这就是氢光谱的**精细结构**（如钠的 D1/D2 双线）。<span class="marginnote">精细结构劈裂的典型大小是主能级间隔的 $\sim 10^{-4}$ 倍，需要高分辨光谱才能看见。玻尔模型完全没有这层结构；只有把相对论修正与自旋—轨道耦合一起纳入，才能解释它。</span>

## 5 泡利不相容原理

1925 年泡利提出：**没有两个电子可以处于完全相同的量子态**。对原子来说，这意味着电子不能有相同的四元组 $(n, l, m_l, m_s)$——每个轨道态 $(\psi_{nlm_l})$ 最多容纳两个电子（自旋一上一下）。

**这一条原理决定了元素周期表的全部结构**：$n=1$ 壳层最多 2 个电子，$n=2$ 壳层最多 8 个，第 $n$ 壳层最多 $2n^2$ 个。<span class="marginnote">泡利原理是自旋统计的必然：自旋 $1/2$ 的粒子是费米子，多体波函数交换反对称，于是「同态排斥」。凡是由电子、质子、中子、夸克构成的物质，都受它管辖；它解释了为什么原子不坍缩、为什么有化学、为什么白矮星有质量上限（钱德拉塞卡极限）。</span>

**易错点：** 泡利原理禁止的是「完全相同的一组量子数」，不是「同一能级」。$n=2$ 壳层可以放 8 个电子，因为它们 $(l, m_l, m_s)$ 各不相同。不要把它理解成「一个能级只能坐两个电子」。

## 6 小结

- 角动量由 $(l, m_l)$ 描述，**空间量子化**使 $L_z$ 只能取离散值；$s, p, d, f$ 分别对应 $l = 0, 1, 2, 3$。
- **自旋**是电子内禀角动量，$s = 1/2$，$S_z = \pm \hbar/2$，与几何旋转无关。
- 自旋磁矩的 g 因子约等于 2，其反常部分是 QED 的精确预言。
- **自旋—轨道耦合**把能级劈裂成 $j = l \pm 1/2$，产生光谱精细结构。
- **泡利不相容原理**禁止全同量子态，直接决定周期表结构。

在下一节，我们将用这四个量子数和泡利原理「重建」元素周期表：为什么氖稳定、为什么碱金属活泼、为什么镧系元素性质相似——多电子原子的一切都将从电子排布开始。
