## 为什么从薛定谔方程开始

德布罗意告诉我们「物质是波」，但没有说波如何演化。1926 年薛定谔给出了答案：一个二阶偏微分方程，像牛顿第二定律之于质点一样，规定了量子系统的波函数如何随时间演化。这一节我们从一个几乎最简单的系统——**一维无限深势阱**——出发，因为它是量子力学里唯一能「手算到底」又保留全部量子特色的例子：**能量分立、零点能存在、波函数有节点**。<span class="marginnote">无限深势阱的地位相当于经典力学里的简谐振子：简单到可以完全解析，又丰富到能演示量子力学的所有关键概念。后面几乎所有多体、固体、原子物理都可以看成是它的各种推广。</span>

而在大模型一侧，「位置编码 + 离散 token 空间」与「势阱中波函数的离散能级」在数学结构上惊人地相似——**约束导致离散**，这是两个领域共享的思想。

## 1 薛定谔方程的由来

对一个能量守恒系统，**定态薛定谔方程**（一维）为

$$-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} + V(x)\psi = E\psi$$

- 第一项 $-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2}$ 是动能算符作用在 $\psi$ 上；
- $V(x)$ 是势能函数；
- $\psi(x)$ 是**波函数（wave function）**，本身不是物理量，但 $|\psi(x)|^2$ 是粒子在 $x$ 处出现的**概率密度**。

它的直觉来源：把德布罗意关系 $p = h/\lambda$ 与自由粒子平面波 $\psi = Ae^{i(kx - \omega t)}$ 代入经典能量关系 $E = \frac{p^2}{2m} + V$，就会得到上式。<span class="marginnote">可以理解为「把经典能量关系里的动量换成算符 $-i\hbar\frac{d}{dx}$」——这是量子化的操作规则。但薛定谔方程的地位是公理级的：它不能被从更基本的原理「推出」，只能被合理地假设，然后用实验检验。</span>

**波函数的意义**：$\psi$ 本身可以是复数，概率密度 $|\psi|^2 = \psi^*\psi$ 是实的。归一化条件 $\int_{-\infty}^{\infty} |\psi|^2 dx = 1$ 意味着「粒子必定出现在空间某处」——这在离散能级问题里会自然逼出量子化。

与定态方程对应的是**含时间的薛定谔方程** $i\hbar\frac{\partial\psi}{\partial t} = \hat{H}\psi$。若哈密顿量不含时，试探解 $\psi(x,t) = \psi_n(x)\,e^{-iE_n t/\hbar}$ 就能把含时方程约化成定态方程——这正是「定态」名字的由来：能量确定的状态，其概率密度 $|\psi|^2$ 不随时间改变。<span class="marginnote">「定态不是静态」是一个常见误解：波函数本身一直在以频率 $E_n/\hbar$ 振荡，只是概率密度不随时间变。真正随时间变化的物理来自不同定态的叠加——这是第 4 节叠加态与量子跃迁的伏笔。</span>

## 2 一维无限深势阱

设粒子被关在宽度为 $L$ 的盒子里，势能为

$$V(x) = \begin{cases} 0, & 0 < x < L \\ +\infty, & x \leq 0 \text{ 或 } x \geq L \end{cases}$$

势阱壁无穷高意味着波函数在壁处必须为零（$\psi(0) = \psi(L) = 0$，否则概率密度不连续、动能发散）。在阱内 $V = 0$，方程化为 $\psi'' = -\frac{2mE}{\hbar^2}\psi$，即简谐振荡方程，通解为

$$\psi(x) = A\sin(kx) + B\cos(kx), \qquad k = \frac{\sqrt{2mE}}{\hbar}$$

边界条件 $\psi(0) = 0$ 逼迫 $B = 0$；$\psi(L) = 0$ 逼迫 $kL = n\pi$，即**波数量子化** $k_n = n\pi/L$。<span class="marginnote">这个推导和「两端固定的弦的驻波」在数学上完全一样：边界条件把连续的自由波筛选成一串离散的驻波模式。量子力学在这里第一次用「边界 + 波动」把能量离散化了，没有任何人为的「量子化假设」。</span>

**数值算例：电子在盒子里的零点能有多大？** 取电子（$m_e \approx 9.11\times10^{-31}\ \mathrm{kg}$）关在宽度 $L = 1\ \mathrm{nm}$ 的盒中，由 $E_1 = h^2/(8m_eL^2)$ 得 $E_1 \approx 0.38\ \mathrm{eV}$——与室温热能 $kT \approx 0.026\ \mathrm{eV}$ 同量级，量子效应已经显著。若把盒子压到原子尺度 $L = 0.1\ \mathrm{nm}$，$E_1$ 涨到约 $38\ \mathrm{eV}$——**零点能随 $1/L^2$ 暴涨**，这是「约束越强、能量越高」的定量写照，也解释了被关进小盒子的电子为何会「急着逃跑」。<span class="marginnote">对比：质子质量约为电子的 1836 倍，同样盒子里质子的零点能只有电子的约 $1/1836$——「质量越重、量子效应越弱」在盒子里同样成立。这就是宏观物体完全感觉不到零点能的原因。</span>

这个「量子点（quantum dot）」模型离真实器件并不远：半导体纳米晶把电子关在约 10 nm 的三维势阱里，量子化能级直接决定它吸收/发射光子的颜色——把盒子做得越小，能隙越大，发光的颜色越偏蓝。量子点显示、生物荧光标记，正是「把一维势阱推广到三维并缩小 $L$」的工程实现。<span class="marginnote">量子点的能级间隔随尺寸连续可调（约 1–3 eV），这在块体材料里不可能——它是「约束导致离散」最直观的纳米级产品。第 10 篇《固体物理初步》会讲量子阱与超晶格的半导体版本。</span>

## 3 公式解析：能级与本征函数

由 $k_n = n\pi/L$ 和 $E = \hbar^2 k^2/(2m)$ 立刻得到

$$E_n = \frac{n^2\pi^2\hbar^2}{2mL^2} = \frac{n^2 h^2}{8mL^2}, \qquad n = 1, 2, 3, \dots$$

$$\psi_n(x) = \sqrt{\frac{2}{L}}\sin\left(\frac{n\pi x}{L}\right), \qquad |\psi_n|^2 = \frac{2}{L}\sin^2\left(\frac{n\pi x}{L}\right)$$

拆开看：

- **$n^2$ 使能级间隔越来越大**：$E_n \propto n^2$，这是势阱与玻尔氢原子（$E_n \propto -1/n^2$）最大的不同——氢原子能级往上收敛，势阱能级往上发散。
- **$n$ 从 1 开始**，最小的能量 $E_1 = \frac{h^2}{8mL^2}$ 叫**零点能（zero-point energy）**，不为零！粒子被关得越紧（$L$ 越小），零点能越高。
- **归一化系数 $\sqrt{2/L}$**：来自 $\int_0^L |\psi_n|^2 dx = 1$，保证「粒子必在阱内」。
- **波函数有 $n-1$ 个节点**：$n=1$ 无节点、$n=2$ 有一个零点……节点数越多能量越高，这是「波长越短、能量越高」在盒子里的严格表述。

**辨析｜易错点：** $n=0$ 不存在（会导致 $\psi \equiv 0$，归一化失败），所以**粒子不可能静止在阱底**。零点能的本质是不确定关系 $\Delta x \Delta p \geq \hbar/2$：位置被锁在 $L$ 范围内，动量必然有展宽，能量不可能为零。这是经典与量子最直观的对照。

**对应原理的兑现**：当量子数 $n$ 很大时，相邻能级的相对间隔 $(E_{n+1}-E_n)/E_n = 2/n \to 0$，能级趋近连续；同时概率密度 $|\psi_n|^2$ 的振荡越来越快，在高速振荡下平均后趋近经典的均匀分布——「大量子数极限回到经典」，这正是玻尔的**对应原理（correspondence principle）**。一个宏观摆的振动能级对应的 $n$ 高达约 $10^{34}$，分立性完全隐没在测量精度之下。<span class="marginnote">对应原理是量子力学的自检准则：任何新理论都必须在大量子数或 $\hbar \to 0$ 的极限下退回旧理论。第 1 篇洛伦兹变换退回伽利略变换、第 3 篇普朗克公式退回瑞利—金斯公式，都是同一思想的体现。</span>

## 4 正交归一与叠加态

这些本征函数之间满足**正交归一性**

$$\int_0^L \psi_m^* \psi_n \, dx = \delta_{mn} = \begin{cases} 1, & m = n \\ 0, & m \neq n \end{cases}$$

而且它们构成完备集：阱内任何波函数都可以展开为 $\psi_n$ 的线性组合 $\psi = \sum_n c_n \psi_n$。这正是傅里叶级数在量子力学里的化身——把函数分解到正弦基上。<span class="marginnote">这套「希尔伯特空间 + 正交完备基 + 展开系数」的语言，与线性代数里「正交单位向量张成空间」完全同构。大模型的注意力机制里把 query 投影到 key 空间、线性变换保持范数，也是同一套语言。第二级《线性代数》与《数学分析》是它的语法书。</span>

当粒子处于叠加态 $\psi = c_1\psi_1 + c_2\psi_2$ 时，测量能量会以概率 $|c_1|^2$ 得到 $E_1$、以 $|c_2|^2$ 得到 $E_2$——**测量把叠加态「坍缩」到某个本征态**，这是量子力学最反直觉、也最核心的诠释问题。

叠加态也不只是数学游戏，它直接对应真实实验：**波包**就是连续频率的平面波叠加，用来描述局域化的自由粒子；**干涉**是各成分相干叠加的宏观后果。电子双缝实验里屏幕上的条纹，正是 $\psi = \psi_1 + \psi_2$ 中交叉项 $2\,\mathrm{Re}(\psi_1^*\psi_2)$ 的贡献——若没有相干叠加、只剩 $|\psi_1|^2 + |\psi_2|^2$，条纹会彻底消失。<span class="marginnote">「概率相加」与「振幅相加」是量子与经典的分水岭：经典粒子过双缝是概率相加（无条纹），量子粒子是振幅相加（有条纹）。只要记住「先加振幅、再取模平方」，多数干涉悖论都能解开。</span>

## 5 有限深势阱与阱外穿透

若把阱壁改成有限高度 $V_0$，事情立刻不同：波函数**不**在壁处消失，而是以指数衰减的形式**渗入**阱外的经典禁戒区

$$\psi(x) \propto e^{-\kappa x}, \qquad \kappa = \frac{\sqrt{2m(V_0 - E)}}{\hbar}$$

这意味着粒子有一定概率出现在「经典上不可能」的地方——动能 $E - V_0 < 0$ 的区域。渗入深度 $\delta \approx 1/\kappa$ 随 $V_0 - E$ 增大而减小。<span class="marginnote">有限深阱里波函数的「尾巴」是量子隧穿的前奏：如果阱壁再变成有限的势垒，粒子就能穿过去。这正是第 6 篇《量子隧穿》的主题，也是扫描隧道显微镜、核聚变、α 衰变的共同物理基础。</span>

**易错点：** 阱外虽然 $|\psi|^2 \neq 0$，但粒子「穿过势垒」需要势垒有限厚；对无限高或无限厚的墙，概率仍趋于零。波函数衰减是指数级而非突变，这是理解隧穿的必经之路。

束缚态的数量也由阱深决定：有限深势阱对给定的 $V_0$ 只有**有限个**束缚态（数量级约为 $L\sqrt{2mV_0}/\hbar$），而无限深势阱有无穷多个。阱越深，束缚态越多；能级越过 $V_0$ 之后，谱就变成连续的了。<span class="marginnote">「束缚态离散、散射态连续」是量子力学的普遍法则：把粒子锁住的势给出离散能级，允许粒子逃走的势给出连续谱。这条法则在固体能带、原子谱线、核物理里反复出现——第 10 篇《固体物理初步》的能带结构就由此而来。</span>

## 7 小结

- **定态薛定谔方程**是量子系统的运动方程，$|\psi|^2$ 是概率密度。
- 一维无限深势阱的边界条件使波矢 $k_n = n\pi/L$ 与能级 $E_n = n^2 h^2/(8mL^2)$ **离散化**。
- 存在**零点能** $E_1 \neq 0$，源于不确定性原理，是经典所无的效应。
- 本征函数正交归一且完备，叠加态的测量导致**坍缩**。
- 有限深势阱的波函数**渗入经典禁戒区**，为量子隧穿铺路。

在下一节，我们将让波函数真正「穿过」一道势垒：量子隧穿——粒子翻不过去却过得去的墙，以及它在现代技术里的惊人应用。
