## 为什么从性别开始

摩尔根 1910 年发现白眼果蝇几乎全是雄性的那一刻，遗传学第一次碰到「基因与性别纠缠」的问题：为什么有些性状的遗传总是和性别绑定？答案藏在性染色体里——XX 与 XY 那对特殊的同源染色体。

**伴性遗传（sex-linked inheritance）**是遗传模式里最「反直觉」的一类：同一对等位基因，在儿子和女儿身上的表现完全不同。读懂它，是系谱分析的第一课，也是理解后文《人类遗传病》中性染色体异常的基础。

伴性遗传在遗传学史上的分量，在于它是「基因在染色体上」的第一个决定性证据：一个基因若随性别分离，它必然住在一张「分性别的染色体」上。摩尔根的白眼果蝇实验之后，遗传学才真正进入染色体时代。<span class="marginnote">伴性遗传的教学价值在于：它是「基因在染色体上」最直接、最干净的证明。一个基因若随 X 染色体遗传，它的传递路径就必然与性别绑定——这是摩尔根用来证明染色体学说的王牌证据。</span>

## 1 性决定系统

不同生物的性别决定机制差异很大，四种常见系统：

| 系统 | 雌性 | 雄性 | 举例 |
| --- | --- | --- | --- |
| XY 型 | XX | XY | 人类、果蝇、哺乳动物 |
| XO 型 | XX | X（无 Y） | 蝗虫、蟋蟀 |
| ZW 型 | ZW | ZZ | 鸟类、鳞翅目昆虫 |
| 单倍二倍型 | 二倍体 | 单倍体 | 蜜蜂、蚂蚁 |

**核心概念**：在 XY 型中，雌性（XX）产生**同型配子**（全部含 X），雄性（XY）产生**异型配子**（一半 X、一半 Y）——所以后代的性别由**父亲的精子**决定。<span class="marginnote">在鸟类（ZW 型）里这个角色反转：雌鸟（ZW）产异型配子，后代的性别由<strong>雌性</strong>决定。性决定机制本身就是「生物多样性」的一个剖面，值得与第一级《生物》中生殖细胞的内容对照着读。</span>

## 2 伴性遗传的系谱规律

人类性染色体上 1550 多个基因，绝大多数位于 X 染色体。X 连锁基因的遗传有三个结构性前提：

- 男性只有**一条** X 染色体，称为**半合子（hemizygous）**——没有第二条 X 来提供显性掩盖。
- 所以 X 连锁隐性基因在男性身上**只要出现就表达**，男性患病率远高于女性。
- 男性的 X 染色体**只能传给他的女儿**，不能传给儿子。

**重点：交叉遗传（criss-cross inheritance）**。X 染色体在代际间呈「之」字形传递：父亲 → 女儿 → 外孙。一个 X 连锁隐性等位基因，常在男性后代中「隔代」暴露。

## 3 X 连锁隐性遗传：红绿色盲与血友病

红绿色盲是最经典的 X 连锁隐性性状。致病基因 $X^b$，正常等位基因 $X^B$。设女性携带者（$X^BX^b$）与正常男性（$X^BY$）婚配：

$$
\begin{aligned}
\text{儿子} &: X^BY : X^bY = 1 : 1 \quad \Rightarrow \text{儿子 1/2 患病}\\
\text{女儿} &: X^BX^B : X^BX^b = 1 : 1 \quad \Rightarrow \text{女儿全正常，其中 1/2 为携带者}
\end{aligned}
$$

**公式解析：**

- **第一步，列出亲本配子**：母亲产生 $X^B$、$X^b$ 各半；父亲只产生 $X^B$ 与 $Y$ 两种精子，各半。
- **第二步，按性别合并**：儿子的 Y 来自父亲，所以儿子的基因型只由母亲的 X 决定——患病概率 = 母亲把 $X^b$ 传下来的概率 = **1/2**。
- **第三步，注意女儿的对称性**：女儿的 X 一来自父一来自母，父方 $X^B$ 保证女儿不患病，但可能成为携带者。<span class="marginnote">这就是 X 连锁隐性遗传最出名的「不对称」：同一个患病等位基因，在儿子身上发病，在女儿身上「安全通过」。系谱里因此呈现「男多女少、隔代出现、母系传递」三大特征。</span>

> **辨析｜易错点：** 血友病、红绿色盲、杜氏肌营养不良都是 X 连锁隐性，但它们之间**不同基因、不同染色体位置**，不能混为一谈。另一个高频错误：把「父亲患病 → 女儿患病」当成普遍规律。父亲只会把 $X^b$ 传给女儿，但女儿的另一条 X 若来自正常母亲（$X^B$），就只是携带者——**只有 X 连锁显性才会出现父亲患病、女儿必然患病**。

### 系谱判型的一个完整例子

给一张系谱：患者全部是男性，分布在母系一侧，隔代出现；患病男性的母亲正常，但她的兄弟可能患病；患病男性的女儿全部正常但可能携带，儿子一定正常（因为 Y 来自父亲）。

**判别步骤**：

1. 男性患者多 → 怀疑 X 连锁隐性（或 Y 连锁，先排除后者）。
2. 没有「父传子」的连续男性链 → 排除 Y 连锁。
3. 患者父亲正常、母亲正常但外祖父母可能患病 → 母系携带传递，符合 X 连锁隐性。
4. 若出现女性患者，需检查其父亲是否患病——X 连锁隐性女性患者必须父患（或父患 + 母携带）。

这套判型流程把《人类遗传病》的系谱分析提前演练了一遍，也是遗传咨询里「先判模式、再算风险」的标准动作。

## 4 X 连锁显性与 Y 连锁

**X 连锁显性（X-linked dominant）**遗传要罕见得多，因为女性杂合即患病。典型例是 X 染色体上的抗维生素 D 佝偻病。

| 特征 | X 连锁隐性 | X 连锁显性 | 常染色体显性 |
| --- | --- | --- | --- |
| 男女患病比例 | 男 ≫ 女 | 女 ≥ 男 | 男女均等 |
| 患病父亲的后代 | 女儿全为携带者 | **女儿全患病** | 子女各 1/2 患病 |
| 患者母亲的后代 | 儿子 1/2 患病 | 子女各 1/2 患病 | 子女各 1/2 患病 |
| 传递 | 不传男传女 | 不传男传女 | 直传 |
| 世代特点 | 隔代、男性为主 | 每代连续出现 | 每代连续出现 |

**Y 连锁（Y-linked）**基因更简单：只传男不传女，如人类外耳道多毛症。它没有杂合子概念，系谱呈「全男性链状传递」。

**核心对比表**（本条为纯概念主题，以对比表代替公式解析）：区分四种模式只需三个问题——**患者是否男女均等？患病父亲是否把病传给所有女儿？是否隔代？** 三个问题的答案组合唯一确定遗传模式。<span class="marginnote">把这张表当成「决策树」而非「背表」：系谱分析时先数男女比例，再盯住「患病父亲 × 正常母亲」的家庭——它同时检验 X 连锁显性（女儿必病）与常染色体显性（子女各半）的区分，是判型的关键卡口。</span>

### 伴性遗传的「为什么」速查

| 现象 | 原因 |
| --- | --- |
| 男性 X 连锁隐性病多于女性 | 男性半合子，一个拷贝即发病 |
| 交叉遗传 | X 从父亲传给女儿、经女儿传给外孙 |
| 患病父亲女儿全患病（XD） | 父亲只传 X 给女儿，显性则必发病 |
| 患病父亲儿子不患病（XR） | 父亲不传 X 给儿子 |
| 女性携带者表现不一 | X 失活随机，见《表观遗传学》 |

**一个易被忽略的细节**：X 连锁与「完全显性/隐性」是正交的两个维度。X 连锁基因同样有显隐之分——红绿色盲是 X 连锁隐性，抗维生素 D 佝偻病是 X 连锁显性。判型时必须同时回答「在哪条染色体」与「显性还是隐性」两个问题。

**一句话记住本节**：伴性遗传的钥匙是「半合子」——男性只有一条 X，隐性基因无处可藏，于是男女的患病概率、传递路径彻底分叉。

**与《人类遗传病》的衔接**：本节的四类判型表就是《人类遗传病》系谱分析的完整工具箱——血友病、红绿色盲的系谱练习，就是本节规则的直接应用。

## 5 小结

- **性决定**：XY、XO、ZW、单倍二倍型四种系统；XY 型性别由父方精子决定。
- **半合子**：男性 X 连锁基因无显性掩盖，隐性即表达——这是伴性遗传不对称的根源。
- **交叉遗传**：X 染色体父亲 → 女儿 → 外孙，「之」字形隔代传递。
- **判型三问**：男女是否均等、患病父亲女儿是否必病、是否隔代——组合决定四种遗传模式。
- X 连锁隐性「男多女少、隔代、母系传递」；X 连锁显性「每代连续、父亲患则女儿全患」。

在下一节，我们把目光从单条染色体内部的基因，移到**整组染色体**的数目变化——多一条或少一条染色体，会产生怎样的后果？这就是**染色体数目变异**。
