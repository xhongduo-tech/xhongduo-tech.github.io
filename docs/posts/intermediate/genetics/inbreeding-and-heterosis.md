# 近交与杂种优势

## 为什么从「近亲交配」开始

Hardy-Weinberg 平衡假设**随机交配**——每个个体与群体中任何异性配对的概率相同。但自然界大量存在非随机交配：植物自花授粉、动物近亲繁殖、人类堂表亲婚配。**近交（inbreeding）**是最重要的非随机交配形式，它不改变等位基因频率，却**系统性地减少杂合子、增加纯合子**。

近交的后果是双重的：个体层面它让隐性有害基因「现形」（近交衰退），群体层面它又为**杂种优势（heterosis）**提供了镜像背景。理解近交系数，是理解动物育种、遗传咨询里「近亲婚配风险」、以及「为什么杂交玉米更高产」的共同语言。

近交的问题为什么值得单独一节？因为它在三个层面同时重要：个体层面决定近亲婚配后代的健康风险，群体层面决定野生小种群的遗传负荷，育种层面决定自交系与杂交种的搭配策略。一条公式（F 如何改变基因型频率）贯穿三个层面。<span class="marginnote">达尔文 1876 年就记载了近交衰退（他本人还做了大量植物异花/自花授粉实验），却无法解释机制。今天我们知道机制：近交提高纯合度，让隐性有害等位基因从杂合「隐身」状态暴露——这是孟德尔-摩尔根-群体遗传学三代累积的答案。</span>

## 1 近交系数与基因型频率的偏移

**核心概念**：**近交系数（inbreeding coefficient）** $F$ 度量一个个体某基因座上两个等位基因**来自同一祖先拷贝**（同源，identical by descent, IBD）的概率。$F$ 从 0（随机交配）到 1（完全纯合）。

近交改变基因型频率但不改变等位基因频率。设等位基因频率 $p$、$q$，则：

| 基因型 | 随机交配 | 近交系数 $F$ |
| --- | --- | --- |
| $AA$ | $p^2$ | $p^2 + Fpq$ |
| $Aa$ | $2pq$ | $2pq\,(1-F)$ |
| $aa$ | $q^2$ | $q^2 + Fpq$ |

**重点：近交只「挪动」频率，不增减等位基因**。把纯合子的比例从 $p^2$、$q^2$ 各抬高 $Fpq$，同时从杂合子里扣除 $2Fpq$——总数守恒，杂合度下降为原来的 $(1-F)$ 倍。这一条是理解近交一切后果的枢纽：**近交 = 纯合化机器**。

近交系数的另一个视角是「纯合子超出随机预期的比例」。随机交配下纯合度是 $p^2 + q^2$，近交下纯合度被抬高到 $p^2 + q^2 + 2Fpq$——多出来的 $2Fpq$ 恰好是从杂合子「挪」过去的。因此 $F$ 也可以写成 $F = 1 - H/(2pq)$（$H$ 为观测杂合度），用分子标记估计群体近交程度时正是用这个式子。

## 2 公式解析：杂合度随自交的衰减

最极端的近交是**自交（selfing）**。自交一代，杂合子 $Aa$ 的后代里有 1/2 仍是 $Aa$、1/4 变成 $AA$、1/4 变成 $aa$。于是每自交一代，群体的杂合度**减半**：

$$
H_n = H_0 \left(\frac{1}{2}\right)^{n}
$$

**第一步，验证一代自交**：$Aa$ 自交，子代 $AA : Aa : aa = 1 : 2 : 1$——杂合子比例 1/2，正好是亲代（全杂合）的一半。

**第二步，迭代 n 代**：每代都减半，$n$ 代后 $H_n = H_0 \cdot (1/2)^n$。

**第三步，看极限**：$n \to \infty$ 时 $H_n \to 0$——长期自交的品系**完全纯合**。这正是植物育种里「自交到纯系」的理论依据：玉米自交 n 代后得到遗传上同质的自交系。

**近交系数与杂合度的关系**：任意近交下 $H = 2pq(1-F)$，即 $F = 1 - H/(2pq)$。**从观测杂合度反推 $F$**，是育种和群体遗传学里估计近交强度的标准手法。<span class="marginnote">堂表亲（first cousin）婚配的后代近交系数 $F = 1/16$（0.0625）；叔侄 $F = 1/8$；自交 $F = 1/2$。遗传咨询里「近亲婚配子女的出生缺陷风险加倍」的估算，正是把这些 $F$ 值代入「隐性病暴露概率」的计算——详见《遗传咨询》一节。</span>

## 3 近交衰退：隐性有害暴露

**核心概念**：**近交衰退（inbreeding depression）**：近交后代的适应度（存活率、生育力、产量）下降。机制几乎唯一指向**隐性有害等位基因的纯合化**。

一个有害隐性等位基因 $d$（频率 $q$，纯合适应度 $1-s$）在近交下暴露的概率：

$$
P(dd) = q^2 + Fpq
$$

**第一步，拆解**：$q^2$ 是随机交配下就有的部分，$Fpq$ 是**近交额外抬高的部分**——$F$ 越大、稀有隐性有害等位基因越多，暴露越严重。

**第二步，看为什么小 $q$ 也危险**：稀有有害隐性（$q \ll 1$）在随机交配下几乎不出现（$q^2$ 极小），但近交把暴露概率从 $q^2$ 抬到 $q^2 + Fq(1-q) \approx Fq$——**从 $q^2$ 到 $q$ 的差别是数量级级的**。这就是近亲婚配「罕见病爆发」的数学解释。<span class="marginnote">野生种群因近交衰退而脆弱（如佛罗里达美洲狮因奠基者效应 + 近交出现尾曲、生育力下降）；而「遗传负荷」越高的群体，近交衰退越明显。近交衰退的存在反过来证明：隐性有害等位基因在群体里远比想象普遍——它们藏在杂合子里「记账」，近交时才「兑现」。</span>

**重点：近交衰退是显性假说的最强证据**——有害等位基因主要是隐性的，因此纯合化才导致伤害。若有害等位基因是显性的，选择早就把它们清掉了，近交不会额外伤害。

## 4 杂种优势：两大学说

**核心概念**：**杂种优势（heterosis / hybrid vigor）**：杂交后代表现出超过双亲均值的生活力与产量。它是近交衰退的**镜像**——近交纯合化有害，杂交杂合化受益。

| 学说 | 主张 | 数学直觉 |
| --- | --- | --- |
| **显性假说** | 杂种中双亲的有害隐性等位基因被对方显性等位基因「掩盖互补」 | 互补消除了 $q^2$ 与 $Fq$ 的暴露 |
| **超显性假说** | 杂合子本身优于任一纯合子（$w_{Aa} > w_{AA}, w_{aa}$） | 杂合状态有内在优势 |

**重点：显性假说是主流解释**——杂种优势主要来自**显性互补**：两个自交系各携带不同的隐性缺陷，杂交后 F₁ 每个基因座都至少有一个显性等位基因「兜底」，隐性缺陷全部被掩盖。<span class="marginnote">玉米杂交育种是这场科学史的主角：自交系产量低（近交衰退），但两个自交系的杂交 F₁ 产量剧增（杂种优势）——20 世纪 30 年代「杂交玉米」让美国玉米单产翻倍。今天的水稻、蔬菜、家禽都靠同一条「纯系 × 纯系 → 杂交种」的流水线。杂种优势把遗传学从实验室送进了粮仓。</span>

**F₁ 优势为何不能固定？** 因为 F₁ 是杂合的，自交后代会分离、重组，优势被「稀释」。所以商业育种每年重新杂交，无法「保存」F₁ 基因型——除非无性繁殖（如马铃薯）或多倍体（见《染色体数目变异》）。这个「优势不可遗传」的特点，是显性假说的又一印证。

### 近交系数的谱系计算入门

近交系数 $F$ 可以从系谱直接算出来。核心思想：找一个共同祖先，看父方与母方各从它遗传同一拷贝的概率。

1. **找共同祖先**：A 是父方 B 与母方 C 的共同祖先。
2. **数路径步数**：B → A → C 共 2 步。
3. **套公式**：单条路径贡献 $(1/2)^{n+1}$，$n$ 是路径上的个体数（不含父母双方），再按共同祖先数求和。

对堂表亲婚配（共同祖先是祖父母，路径 4 步），$F = 2 \times (1/2)^5 = 1/16$。

| 婚配关系 | 近交系数 F |
| --- | --- |
| 表兄妹（first cousins） | 1/16 |
| 叔侄/姨甥 | 1/8 |
| 半同胞 | 1/8 |
| 全同胞 | 1/4 |
| 自交 | 1/2 |

**为什么遗传咨询要算 F？** 因为 F 直接进入子代隐性病风险公式 $q^2 + Fq(1-q)$（见《遗传咨询》）——F 越大，罕见隐性病暴露的风险越高。近交系数不止是「伦理警示」，它是可计算的遗传学参数。

### 近交与杂种优势的应用链

1. **自交系培育**：连续自交获得纯合自交系（如玉米自交系）。
2. **杂交制种**：两个自交系杂交得 F₁，F₁ 杂合度最高、表现杂种优势。
3. **每年重制**：F₁ 的优势不可自交固定，所以商业种子每年重新杂交。

**这条链在动物育种里的变体**：动物不能自交，用「品系内近交 + 品系间杂交」达到类似效果——近交纯化、杂交显优势。理解这条「纯化-杂交」的循环，等于理解了现代作物与畜禽育种的共同底层逻辑。

## 5 小结

- **近交系数 $F$**：两个等位基因同源（IBD）的概率；近交不改变等位基因频率，只抬高纯合、压低杂合。
- **自交衰减**：$H_n = H_0 (1/2)^n$，长期自交完全纯合。
- **近交衰退**源于隐性有害等位基因纯合暴露：$P(dd) = q^2 + Fpq$，稀有隐性从 $q^2$ 抬到 $Fq$。
- **杂种优势**主流解释为**显性互补**：杂交掩盖双亲的隐性缺陷；优势不可固定，需每年制种。
