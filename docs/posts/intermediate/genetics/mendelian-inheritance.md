# 孟德尔遗传定律

## 为什么从孟德尔开始

遗传学（genetics）问的是一个问题：**亲代怎么把性状传给子代？** 在孟德尔之前，流行的是「混合遗传」——就像两种颜料混在一起，后代是父母性状的混合。如果是这样，差异会被一代代「稀释」掉，可现实中豌豆的高矮、花的颜色却会隔代再现。孟德尔用 22 年豌豆杂交实验，把「遗传」从模糊的直觉变成可检验的数学规律。<span class="marginnote">孟德尔的《植物杂交实验》1866 年发表，却直到 1900 年被德弗里斯、科伦斯、切尔马克三人「重新发现」才进入主流。他比生物学同行超前了三十四年，因为他是把数学引入遗传的第一人。</span>

这一节是整个遗传学的第一块基石：**分离定律**与**自由组合定律**。后面所有内容——连锁、重组、基因突变、群体遗传——都在这两条定律的框架上修正与扩展。

## 1 豌豆：孟德尔选对了材料

孟德尔实验成功的第一个秘密是**选材**。豌豆（*Pisum sativum\*）有七个难以忽略的优点：

**性状鲜明且稳定**：株高、种子圆皱、花色紫白等性状界限分明，不模糊。
**严格自花传粉**：豌豆天然自交，后代遗传背景纯，孟德尔可以人工控制杂交。
**繁殖快、后代多**：一株可以产生大量种子，统计上有意义。
**性状成对出现**：每个观察的性状都有两个清楚的相对形态。

他把每一株亲本先连续自交，确认是**纯种（true-breeding）**后才开始实验。这个「先纯化材料、再统计后代」的纪律，是之后一切遗传分析的样板。

### 实验设计：三代的完整流程

孟德尔的实验不是「做一次杂交看结果」，而是设计了严格的**三代流程**：先让亲本连续自交获得纯种，再做杂交得到 F₁，再让 F₁ 自交得到 F₂，必要时用 F₂ 继续自交到 F₃ 验证遗传的稳定性。这个「先纯、再杂、后验」的结构，保证了他看到的现象是「可重复的规律」而非「偶然的个案」。

更关键的是他的**统计规模**：单看一株豌豆的种子数，3 : 1 可以被抽样噪声淹没；孟德尔种植数千株、统计数万粒种子，才让比例稳定浮现。今天我们知道，这就是《概率论与数理统计》里「样本量决定统计功效」的道理——孟德尔在概率论成熟之前，凭直觉用了正确的统计实践。<span class="marginnote">今天我们把孟德尔的「性状」叫作「表型（phenotype）」，把控制它的遗传因子叫作「基因（gene）」、等位形式叫「等位基因（allele）」——这些术语由约翰逊（Wilhelm Johannsen）1909 年命名，孟德尔本人只叫它「因子（Faktor）」。</span>

## 2 分离定律：一对性状的 3 : 1

**核心概念**：孟德尔先只看**一对相对性状**的杂交（单因子杂交，monohybrid cross）。

以纯种紫花 × 纯种白花为例：

**P 代（亲代）**：紫花 × 白花。
**F₁（子一代）**：全部紫花。白花「消失」了。
**F₂（子二代）**：让 F₁ 自交，紫花 : 白花 ≈ **3 : 1**。

从这个结果孟德尔提出**分离定律（law of segregation）**：每个个体携带**一对**决定性状的遗传因子，形成配子时这对因子**彼此分离**，各进入一个配子，因此每个配子只携带其中一个因子。<span class="marginnote">「消失」的白花没有丢失，只是被<strong>显性（dominant）</strong>因子掩盖；它会在 F₂ 重新出现，说明决定白花的<strong>隐性（recessive）</strong>因子一直在 F₁ 里潜伏。因子的颗粒性——不混合、可分离——是孟德尔对「混合遗传」的决定性反驳。</span>

用字母记法表示（紫 = 显性等位基因 $A$，白 = 隐性等位基因 $a$）：

- P：$AA \times aa$
- F₁：全部 $Aa$（表现紫花）
- F₂：$AA : Aa : aa = 1 : 2 : 1$，其中基因型 $AA$ 与 $Aa$ 都开紫花，所以**表型**紫 : 白 = 3 : 1

**重点：基因型（genotype）与表型（phenotype）不是一回事**。F₂ 中「紫花」这一个表型对应了 $AA$ 与 $Aa$ 两种基因型；只有白花唯一对应 $aa$。这是初学者最容易踩的第一个坑。

### Punnett 方格：把分离定律画成棋盘

分离定律的配子比例，可以用 **Punnett 方格（Punnett square）** 直观呈现：把父母双方的配子分别写在方格的行与列，交叉格就是可能的合子基因型。以 F₁（$Aa$）自交为例：

| 配子 | A（1/2） | a（1/2） |
| --- | --- | --- |
| A（1/2） | $AA$（1/4） | $Aa$（1/4） |
| a（1/2） | $Aa$（1/4） | $aa$（1/4） |

**第一步，确定配子**：F₁ 的基因型是 $Aa$，产生 A 与 a 两种配子、各占 1/2——这正是分离定律在「配子层」的含义：一对因子在形成配子时彼此分离。
**第二步，交叉相乘**：每个格子 = 两个配子概率之积，四个格子各 1/4，总和为 1。
**第三步，合并表型**：含 A 的格子（$AA$ 与 $Aa$）都是显性表型，共 3/4；$aa$ 是隐性表型，1/4。于是 3 : 1 本质上是「3 个格子 : 1 个格子」。

Punnett 方格的力量在可视化：它把「配子比例 → 合子比例」的二项式展开，变成一眼能看尽的棋盘。双因子杂交（$RrYy \times RrYy$）的方格是 4 × 4 = 16 格，对应 16 个等概率的配子组合——这正是下一节 9 : 3 : 3 : 1 的分子来源。需要注意的是：Punnett 方格假设**配子等概率且随机结合**，这个假设在后文《Hardy-Weinberg平衡》里会被明确为一个理想条件。

孟德尔选定的七对性状——株高（高/矮）、种子形状（圆/皱）、种子颜色（黄/绿）、花位（腋生/顶生）、花色（紫/白）、豆荚形状（饱满/缢缩）、豆荚颜色（绿/黄）——每一对都按同样的流程做：纯种 × 纯种 → F₁ → F₂，逐代逐株统计。七对性状的 F₂ 全部呈现 3 : 1（总计约两万株的数据与 3 : 1 高度吻合）。这一致性不是巧合：它说明「一对因子、一对性状」的分离规律是普适的，而不是某个特定性状的特例。

## 3 公式解析：从 3 : 1 到 9 : 3 : 3 : 1

孟德尔接着问：如果同时看**两对**性状呢？比如种子形状（圆 R / 皱 r）与种子颜色（黄 Y / 绿 y）。P 代为纯种圆黄（RRYY）× 皱绿（rryy），F₁ 全部圆黄（RrYy），F₂ 出现四种表型：

$$
\text{圆黄}:\text{圆绿}:\text{皱黄}:\text{皱绿} = 9 : 3 : 3 : 1
$$

把这条式子拆开看：

- **第一步，把两对性状拆成两个独立事件**：每对性状都独立地服从 3 : 1。种子形状圆 : 皱 = 3 : 1，颜色黄 : 绿 = 3 : 1。
- **第二步，两事件的概率相乘**：若两对因子独立分配，四种组合的概率就是各自概率之积——$\frac{3}{4} \times \frac{3}{4} = \frac{9}{16}$（圆黄），$\frac{3}{4} \times \frac{1}{4} = \frac{3}{16}$（圆绿），$\frac{1}{4} \times \frac{3}{4} = \frac{3}{16}$（皱黄），$\frac{1}{4} \times \frac{1}{4} = \frac{1}{16}$（皱绿）。
- **第三步，归一化成整数比**：通分后即 $9 : 3 : 3 : 1$。

**自由组合定律（law of independent assortment）**由此提出：**不同对的遗传因子在形成配子时彼此独立、随机组合**。F₁（RrYy）会等概率产生 $RY、Ry、rY、ry$ 四种配子，各占 $\frac{1}{4}$。

> **辨析｜易错点：** 9 : 3 : 3 : 1 的「9」不是 9 个基因型，而是**表型数**。F₂ 的基因型是 $RRYY、RrYy、RRyy\cdots$ 共 9 种（3² 种基因型），表型 4 种（2² 种）。「表型数 = 2ⁿ、基因型数 = 3ⁿ」（n 为独立基因对数）这个规律只在完全显性、基因自由组合时成立。

## 4 自由组合定律的检验：测交

孟德尔如何证明 F₁ 确实产生了四种等比例配子？方法是**测交（test cross）**：让 F₁ 与隐性纯合体杂交。

**核心概念**：隐性纯合体（rryy）只能产生 $ry$ 一种配子，不贡献任何显性掩盖。因此**后代的表型比例直接反映 F₁ 配子的比例**。

- 若 F₁ 产生 $RY : Ry : rY : ry = 1 : 1 : 1 : 1$，测交后代就是圆黄 : 圆绿 : 皱黄 : 皱绿 = 1 : 1 : 1 : 1。
- 实测与预测完全吻合，自由组合定律得到直接验证。<span class="marginnote">测交是遗传学的「探针」：用一个配子组成已知的个体，去「读出」另一个体的配子。这个思想今天仍在使用——回交（backcross）与分子标记定位都建立在同一逻辑上。</span>

测交为什么必须用**隐性纯合**？因为任何显性基因的存在都会掩盖配子的真实构成。让 F₁ 直接自交，只能看到 9 : 3 : 3 : 1 的表型比例；而测交把「看不见的配子比例」直接暴露成「看得见的后代比例」——这是分离与自由组合定律能被定量检验的关键一步。

测交还有一个孟德尔未必预料到、但今天极常用的推广：**回交（backcross）**。把 F₁ 与任一亲本杂交都叫回交，但只有「与隐性亲本回交」才能无歧义地读出配子比例——「与显性亲本回交」会被显性掩盖，读不出信息。现代育种中，回交被用来把目标基因「转移」到特定遗传背景（如高产但不抗病的品种）里，每一次回交的分子依据，正是测交所揭示的那条配子比例链。

**一句话记住本节**：孟德尔把遗传从「描述」变成了「可检验的比例」——分离定律与自由组合定律不是「豌豆的规律」，而是「颗粒遗传」的普遍数学。

**判型起点**：见到任何遗传数据，先问两个问题——每对性状是不是 3 : 1？两对性状是不是 9 : 3 : 3 : 1？回答「是」，就从孟德尔出发；回答「否」，就到了下一节的「例外」领域。

## 5 小结

- 孟德尔的两条定律：**分离定律**（一对因子形成配子时分离）与**自由组合定律**（不同对因子独立分配）。
- 单因子杂交给出**3 : 1**表型比，双因子杂交给出**9 : 3 : 3 : 1**；测交把配子比例直接暴露为后代比例。
- **基因型 ≠ 表型**：显性掩盖使多个基因型共享一个表型。
- 因子的**颗粒性**是全部推论的根基——它不混合、可分离、可再组合。
- 孟德尔的统计规模：数千株、数万粒种子让 3 : 1 稳定浮现——样本量是比例判断的前提。

在下一节，我们将看到孟德尔定律的三个「例外」：不完全显性、共显性与复等位基因——它们不是反例，而是把「一个基因控制一个性状」这个隐含假设放宽之后自然涌现的规律。
