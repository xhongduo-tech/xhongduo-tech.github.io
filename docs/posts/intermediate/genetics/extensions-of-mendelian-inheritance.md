## 为什么从「例外」开始

孟德尔定律建立在几个隐含假设上：等位基因之间**完全显性**、一个基因只影响**一个性状**、每个性状**只由一对基因**控制。自然界很少这么听话。红花与白花杂交可能得到粉花，同一基因可能影响三个性状，狗的毛色可能被四个基因联手决定。<span class="marginnote">这些「例外」没有推翻孟德尔，反而把孟德尔的框架从「一对基因一对性状」推广成「基因与性状之间的真实网络关系」。学遗传学，先学会在 3 : 1 与 9 : 3 : 3 : 1 的标准之外识别各种修正比例，是判断「读懂没有」的第一道关卡。</span>

这一节我们逐一放宽那三条假设，看看表型比如何被改写。

## 1 不完全显性与共显性

**不完全显性（incomplete dominance）**：杂合子的表型介于两个纯合子**之间**，是两者的「中间型」。金鱼草花色就是经典例：红花（$RR$）× 白花（$rr$）→ F₁ 全粉花（$Rr$）→ F₂ 红 : 粉 : 白 = **1 : 2 : 1**。

这里表型比等于基因型比，因为每个基因型都有了可区分的表型——显性因子不再「掩盖」隐性因子，只是部分表达。

**共显性（codominance）**：杂合子的表型**同时**表现出两个亲本的性状，而不是中间型。人类 MN 血型系统是标准例：$L^M L^N$ 个体同时具有 M 抗原与 N 抗原。<span class="marginnote">不完全显性是「混合成第三态」（粉），共显性是「两者并列同时表达」（M 与 N 都有）。区别在杂合子的表型是新的中间物，还是两个亲本特征的叠加——这是考试里区分两者的关键判据。</span>

> **辨析｜易错点：** 不完全显性与共显性在「1 : 2 : 1」的基因型比上相同，区别只在杂合子表型的**性质**。F₂ 表型比 1 : 2 : 1 时，应回头问一句：杂合子的表型是中间型（不完全显性）还是双亲叠加（共显性）？

不完全显性与共显性的区别还有一个容易踩的坑：**它们不是显性的强弱等级**。不完全显性是「1 份显性剂量不够表达满」（粉 = 半个剂量），共显性是「两个等位基因各自完整表达」（M 与 N 抗原并存）——后者不是「显性更强」，而是「两种显性同时成立」。检查杂合子表型时，如果见到「新的中间形态」，判不完全显性；如果见到「两个亲本特征同时出现」，判共显性。

## 2 复等位基因：ABO 血型

**核心概念**：一个基因座（locus）在群体中可以有**两个以上**的等位基因，这组等位基因叫**复等位基因（multiple alleles）**。每个二倍体个体仍然只携带其中**两个**。

人类的 ABO 血型由 $I$ 基因座决定，有三个等位基因：$I^A$、$I^B$ 与 $i$。其中 $I^A$ 与 $I^B$ 之间共显，二者对 $i$ 完全显性：

| 基因型 | 血型表型 | 抗原 |
| --- | --- | --- |
| $I^AI^A$ 或 $I^Ai$ | A 型 | A 抗原 |
| $I^BI^B$ 或 $I^Bi$ | B 型 | B 抗原 |
| $I^AI^B$ | AB 型 | A 与 B 抗原 |
| $ii$ | O 型 | 无 |

等位基因的数目 $m$ 决定了可能的**基因型总数** = $\dfrac{m(m+1)}{2}$（$m$ 个同型组合 + $\binom{m}{2}$ 个杂合组合）。ABO 三个等位基因对应 $3 \times 4/2 = 6$ 种基因型。<span class="marginnote">ABO 血型的遗传学价值不止于输血安全：它是亲子鉴定的第一代工具。孩子是 O 型（$ii$）而父母都是 AB 型（$I^AI^B$）——这不可能，因为 AB 型不可能生出 $ii$ 的后代。这类「排除」逻辑是后文《人类遗传病》中系谱分析的雏形。</span>

## 3 致死等位基因与表型比的扭曲

有些等位基因在纯合时会**致死**，导致 F₂ 的 3 : 1 被改写成 **2 : 1**。经典例是小鼠的黄色皮毛基因 $A^y$：

$A^yA^y$（纯合黄）：胚胎期死亡
$A^y a$（杂合黄）：存活，黄毛
$aa$（纯合非黄）：存活，黑毛

所以黄色 × 黄色的杂交，F₂ 中黄 : 黑 = 2 : 1，而预期的 3 : 1 因为「少了一类后代」而变形。

**核心概念**：致死可以发生在**合子前**（配子致死，改变配子比例）或**合子后**（胚胎/幼体死亡，改变后代比例）。只要某类基因型不出现，标准孟德尔比就会被系统性地截掉一项。

> **辨析｜易错点：** 看到 2 : 1 的比例，第一时间该怀疑「纯合致死」。反过来，**当样本量小时不要急于判断比例**——3 : 1 在 n = 20 的样本里也可能随机波动成 2.5 : 1。比例判断需要足够的后代数，这正是一篇中的《基因突变与突变率》讲统计检验的伏笔。

### 复等位基因的实例：ABO 的亲子排除

复等位基因不只是「多于两个等位基因」的抽象概念，它立刻有实际应用：**亲子排除**。设母亲是 A 型（$I^AI^A$ 或 $I^Ai$），孩子是 O 型（$ii$），那么孩子必须从父母各得一个 $i$。母亲若是 $I^Ai$ 可以给出 $i$，父亲必须也能给出 $i$——所以父亲不可能是 AB 型（$I^AI^B$），因为 AB 型不携带 $i$。

**重点：ABO 血型能「排除」父亲，但不能「确认」父亲**。它能证明「此人不是生父」，却无法证明「此人就是生父」——因为 A 型与 B 型都有两种可能基因型。「只能排除、不能确认」的不对称，是遗传标记应用里反复出现的原则：排除是决定性的，认亲是概率性的。

| 父母血型 | 孩子可能的血型 | 孩子不可能的血型 |
| --- | --- | --- |
| A × A | A、O | B、AB |
| A × B | A、B、AB、O | — |
| AB × O | A、B | AB、O |
| AB × AB | A、B、AB | O |

### 致死等位基因的实例：黄鼠的 2 : 1

小鼠黄色皮毛的 $A^y$ 等位基因是纯合致死的经典例。$A^yA^y$ 在胚胎期死亡，所以黄色 × 黄色的杂交实际能观察到的后代只有两类：$A^ya$（黄）与 $aa$（黑）。按分离定律，原本的基因型比 $A^yA^y : A^ya : aa = 1 : 2 : 1$，去掉死掉的 $A^yA^y$ 后，存活的表型比黄 : 黑 = 2 : 1。

这个例子教给我们两点：其一，**孟德尔比例是在「所有合子都存活」的前提下写出的**，任何一类合子不出现，比例就会被系统性改写；其二，**致死与否是基因多效性（pleiotropy）的表现**——同一个基因既影响毛色，又影响胚胎存活。一个基因影响多个性状，正是本节主题「基因与性状的非一一对应」的又一次出现。

## 4 基因互作：上位效应

**核心概念**：**上位效应（epistasis）**指一个基因座的基因型**掩盖或修饰**另一个基因座表型表达的相互作用。注意它与显性的区别：显性是**同一基因座**内的掩盖，上位是**不同基因座**之间的掩盖。

典型例子是小鼠毛色：$C$ 基因座决定色素是否产生（$C$ 产生，$cc$ 不产生），$A$ 基因座决定色素的分布（$A$ 为野灰色，$a$ 为黑色）。当 $cc$ 时小鼠是白色（白化），无论 $A$ 座如何——$C$ 座在上位。

双因子杂交的 9 : 3 : 3 : 1 因此被改写成各种修正比：

| 相互作用类型 | F₂ 表型比 | 直观含义 |
| --- | --- | --- |
| 无互作（独立） | 9 : 3 : 3 : 1 | 两对基因各管一性状 |
| 互补作用 | 9 : 7 | 两个显性都需在场才出新性状 |
| 隐性上位 | 9 : 3 : 4 | 隐性纯合掩盖另一座 |
| 显性上位 | 12 : 3 : 1 | 一个显性掩盖另一座 |
| 重叠作用 | 15 : 1 | 两个基因功能冗余 |
| 抑制作用 | 13 : 3 | 一个显性抑制另一座 |

**重点：9 : 3 : 3 : 1 的每一项都可以被「合并」**。上位并没有增加新规律，只是把自由组合定律的结果按生物学机制重新分桶——数字仍然来自那 16 个等可能的配子组合，但表型的分组方式变了。这一认识让「记各种比例」变成「画一个 4 × 4 的配子棋盘，再按机制合并格子」的机械劳动。

### 用棋盘推修正比例的一个练习

以**互补作用（9 : 7）**为例，亲手推一遍。设开紫花的香豌豆需要两个显性基因 C 与 P 同时存在（各自催化合成通路上的一步，缺一步就无色）。双杂合 $CcPp$ 自交的 16 格棋盘里，只有同时含 C 与 P 的 9 格开紫花，其余 7 格（$C\_pp$、$ccP\_$、$ccpp$）都是白花——于是得到 9 : 7。

**核心动作只有一步：把「表型定义」套到标准棋盘上。** 9 : 7、12 : 3 : 1、15 : 1 都不是新机制，而是「什么组合算一个表型」的定义不同。做题时先画 4 × 4 棋盘，再按题目给的互作规则给 16 格分组，比例自然出现——比背诵每个比例可靠得多。<span class="marginnote">把 9 : 3 : 3 : 1 看成 16 个等概率事件的直方图，一切修正比例都是直方图「分箱（binning）」方式不同——这个视角在第三级《概率论与数理统计》里会得到完整的数学表述。</span>

**一句话记住本节**：孟德尔的 3 : 1 是「标准形态」，本节的所有比例都是「放宽假设后的变形」——放宽显性、放宽等位基因数、放宽存活、放宽基因独立性，每一种放宽都对应一组新的表型比。

**判型口诀**：杂合子长什么样？（不完全显性/共显性）几个等位基因？（复等位基因）有没有合子死亡？（致死）几个基因参与？（上位）——四个问题问完，比例自然浮现。

## 5 小结

- 放宽「完全显性」假设：**不完全显性**（杂合为中间型，F₂ = 1 : 2 : 1）与**共显性**（杂合双亲性状并显）。
- 放宽「只有两个等位基因」假设：**复等位基因**，如 ABO 血型，基因型总数 $= m(m+1)/2$。
- 致死等位基因把 3 : 1 改成 **2 : 1**。
- 放宽「一个基因只管一个性状」：**上位效应**在不同基因座间起作用，把 9 : 3 : 3 : 1 改写成 9 : 7、12 : 3 : 1 等修正比。
- 四个判型问题：杂合子表型？等位基因数？合子是否致死？几个基因参与？——问完比例自然浮现。

在下一节，我们将进入孟德尔定律真正的修正：当两对基因位于**同一条染色体**上时，它们不再自由组合，而是**连锁**并发生重组——那是遗传学从「花园里的豆子」走向「染色体上的图」的关键一步。
