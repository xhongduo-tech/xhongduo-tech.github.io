## 为什么从「不改变序列的遗传」开始

《发育遗传学基础》留下一个悖论：肝细胞与神经细胞 DNA 相同，命运却不同。细胞是怎么「记住」自己该当肝细胞还是神经细胞、并把这份记忆**传给子代细胞**的？答案就是**表观遗传（epigenetics）**：不改变 DNA 序列，却改变基因表达，且这种改变可以遗传。

表观遗传把这个系列里很多「线头」收拢了：X 染色体剂量补偿（《染色体数目变异》）、细胞分化的记忆（《发育遗传学基础》）、环境对基因表达的影响（《遗传力估计》）。它是「基因型之外」的第二层遗传信息——也是理解癌症、衰老与「基因不改变却生病」的钥匙。

读这一节的关键在于把「遗传」两个字拆开理解：表观标记确实能传——**传的是「表达状态」，不是「碱基序列」**。细胞分裂时，DNA 序列被精确复制；表观标记则在复制后「补抄」到新链上。这套「复制序列之外还复制状态」的双轨机制，让一个基因一旦被沉默，就能在细胞谱系中保持沉默——这就是分化状态能稳定存在的基础。<span class="marginnote">「epigenetics」一词由沃丁顿（Waddington）1942 年造出，本指「发育过程中基因型如何产生表型」。今天的含义收窄到「可遗传的基因表达改变，不涉及 DNA 序列变化」。沃丁顿的「表观遗传景观」（细胞命运像滚球滚过沟壑地形）仍是理解细胞分化的经典隐喻。</span>

## 1 表观遗传的三个机制

**核心概念**：表观遗传信息写在三层「标记」里：

| 机制 | 分子形式 | 作用 | 可逆性 |
| --- | --- | --- | --- |
| **DNA 甲基化** | 胞嘧啶 5′ 位加甲基（5mC） | 通常抑制基因表达 | 可逆（去甲基化酶） |
| **组蛋白修饰** | 组蛋白尾部的乙酰化/甲基化/磷酸化 | 改变染色质松紧 | 可逆（写入/擦除酶） |
| **非编码 RNA** | miRNA、lncRNA、siRNA | 转录后调控、异染色质形成 | 可逆 |

**重点：DNA 甲基化是最「教科书」的表观标记**。甲基化常发生在 CpG 二核苷酸的胞嘧啶上；基因启动子区的 CpG 岛被甲基化时，转录机器被挡住，基因沉默。关键在于：**甲基化是可维持的**——DNA 复制时，半甲基化的模板会引导新链对应位点甲基化（维持性甲基化酶 DNMT1），于是「沉默状态」随细胞分裂一代代传下去。这就是分化状态的「分子记忆」。

**组蛋白修饰是第二套主要标记**，比甲基化更「细粒度」。核心组蛋白（H3、H4 等）的尾巴伸出核小体，可以被乙酰化、甲基化、磷酸化等多种修饰；不同修饰的组合被称为「组蛋白密码」（histone code）。粗略地说：**乙酰化通常打开染色质**（中和正电荷、放松核小体），**甲基化则依位点而不同**（H3K4me3 激活、H3K27me3 沉默）。「打开」与「关闭」的染色质状态由此被写入组蛋白，并靠复制时分配到子链的组蛋白传递下去——这是比 DNA 甲基化更动态、更精细的调控层。<span class="marginnote">维持性甲基化的巧妙之处：复制后新链是未甲基化的，但识别「半甲基化位点」的酶会把它补全——表观标记因此能「抄」到下一代 DNA 上。这个「复制不复制序列、只复制标记」的机制，是表观遗传能成为「遗传」的关键。</span>

## 2 DNA 甲基化与基因组印记

**核心概念**：**基因组印记（genomic imprinting）**：某些基因的表达**取决于它来自父亲还是母亲**——来自一方的拷贝被沉默，另一方的拷贝表达。沉默靠的正是**印记控制区的甲基化**。

典型例子：

- **Prader-Willi 综合征**：15q11-q13 区域的父源拷贝缺失/失活（母源拷贝被印记沉默）——表现为肥胖、智力障碍。
- **Angelman 综合征**：同一区域的**母源**拷贝缺失/失活（父源拷贝被印记沉默）——表现为小头、癫痫、快乐面容。

**重点：印记是「剂量不对称」**——一个基因只有父源或母源一个等位基因在工作，另一份被甲基化「贴了封条」。这带来独特的遗传模式：**同一个基因的突变，传给后代是否致病，取决于来自父方还是母方**。<span class="marginnote">Prader-Willi 与 Angelman 是「同一区段、两个病」的经典：区别只在「哪个亲本的拷贝坏了」。这个「亲本来源决定表型」的反直觉事实，是表观遗传最震撼的教学案例——它让「基因型相同、表型不同」第一次有了确定性的分子机制。</span>

**印记在发育中如何被擦除与重写**：配子形成时会**擦除**亲代的印记，再按**性别特异**的方式重写（父亲的精子印上一套、母亲的卵子印上另一套）——所以印记能代代重现，又随性别切换。这个「擦除-重写」周期是印记基因表达程序稳定的基础。

印记的临床后果常常「出人意料」：一个父母都正常的家庭，孩子却患 Prader-Willi 综合征——因为孩子从父亲继承的 15q11-q13 区段发生了微小缺失，而母源拷贝本就因印记而沉默，于是「两个拷贝都不工作」。这类病例说明：**印记把「单拷贝缺失」放大成「功能完全缺失」**。临床上如果发现某个基因病的遗传模式「不符合孟德尔」（同样的缺失，有的孩子病、有的不病），要立刻怀疑印记在起作用。

## 3 X 失活：剂量补偿

《染色体数目变异》提到 X 染色体有剂量补偿，这里展开机制。

**核心概念**：哺乳动物雌性（XX）有两条 X，雄性（XY）只有一条。为避免 X 连锁基因「双倍剂量」，雌性胚胎会在早期发育中**随机失活**其中一条 X——失活的 X 高度浓缩成**巴氏小体（Barr body）**。这一过程由 **Xist** 非编码 RNA 主导：Xist 从失活的那条 X 转录，沿整条染色体「铺开」，招募抑制性修饰，把整条 X 沉默。

**关键事实**：

- **失活是随机的**：每个细胞的父源或母源 X 失活是随机的。
- **失活是稳定的**：一旦决定，该细胞系的所有后代保持同一条 X 失活。
- **结果：雌性是「嵌合体」**——不同细胞群分别表达父源或母源 X 的基因。

**Xist 的工作机制值得展开**：在早期胚胎的每个细胞里，两条 X 上都开始有 Xist 表达，但随后「竞争」出胜负——最终只有一条 X 的 Xist 持续高表达，沿整条染色体「铺开」招募 Polycomb 复合体等抑制因子，把这条 X 卷成沉默的异染色质（巴氏小体）；另一条 X 的 Xist 被关闭，保持活跃。这个「随机竞争，赢者沉默」的机制，保证了每个细胞恰好保留一条活性 X。

**重点：X 失活让 X 连锁基因在男女之间「剂量均衡」，但也带来表型后果**——携带 X 连锁隐性突变的女性杂合子，由于失活随机，可能出现「部分表现」（如某些血友病携带者有轻度出血倾向）。X 失活是《染色体数目变异》里「47,XXX 相对温和」的分子答案：多余的 X 被失活「关掉」了。<span class="marginnote">三色猫（玳瑁猫）几乎全是雌性，就是 X 失活的「活招牌」：橘色与黑色毛色基因位于 X 染色体，雌性随机失活使不同斑块的毛色由不同 X 决定——雄猫只有一条 X，永远不能同时有橘黑两色（除非 XXY，罕见例外）。</span>

## 4 表观遗传的遗传与环境

**表观遗传能「跨代遗传」吗？** 这是当前最活跃也最有争议的方向：

- **体细胞内的表观遗传**（细胞代际）：确定无疑——分化状态的记忆就是证据。
- **生殖系跨代遗传**（个体代际）：哺乳动物有部分证据（如营养环境改变后代代谢表型），但机制与稳健性仍在激烈争论——因为配子会经历「印记擦除-重写」，大部分表观标记在传代时被清除。

**表观遗传与环境的相互作用**：营养、毒素、压力可以改变表观标记，且**某些改变确实可逆**——这为「生活方式干预疾病风险」提供了分子入口：

- **荷兰饥饿冬天（Dutch Hunger Winter）**：1944–45 年纳粹封锁期间，孕期经历饥荒的孩子，几十年后某些基因的甲基化仍与正常对照不同——一次环境事件在表观基因组上留下了**可测量的长期痕迹**。
- **衰老**：全基因组甲基化随年龄呈现系统性变化（有的位点甲基化增加、有的丢失），甚至能作为「表观遗传时钟」预测生理年龄。
- **吸烟**：吸烟者的特异位点甲基化改变，戒烟后可部分恢复——表观标记「可逆」的最好例证。

- 癌症表观遗传：肿瘤抑制基因的**启动子甲基化沉默**是癌变的重要事件，且甲基化抑制剂已成为抗癌药。
- 药物可逆性：表观标记的「可逆性」使表观药物（去甲基化药、组蛋白去乙酰化酶抑制剂）成为表观遗传学走向临床的直接成果。<span class="marginnote">表观遗传在肿瘤学里的地位早已确立：CpG 岛甲基化是「检测癌变的分子标志」，全基因组甲基化谱（甲基化组）已成为癌症分型的新维度。比起「基因突变」，表观异常更像「基因表达的开关被卡住」——而开关是可以重新拨动的，这正是表观治疗的希望所在。</span>

> **辨析｜易错点：** ① 把「表观遗传」等同于「获得性遗传」——大多数表观标记在配子形成时被擦除，跨代遗传远没有媒体渲染的普遍；② 混淆「DNA 甲基化」与「组蛋白甲基化」——前者直接修饰胞嘧啶、后者修饰组蛋白尾巴，作用机制不同；③ 以为表观标记「只影响一个细胞」——恰恰相反，维持性甲基化让它在细胞系里稳定传代；④ 把 X 失活当成「所有雌性细胞失活同一条 X」——失活是随机的，雌性是嵌合体。

### 表观标记的「读-写-擦」机器

表观遗传不是「标记放着不动」，而是一套持续的动态循环：**写入酶（writer）**加上标记，**读取蛋白（reader）**识别标记并执行功能，**擦除酶（eraser）**移除标记。三者缺一不可：

- DNA 甲基化：DNMT（写）、MBD 蛋白（读）、TET（擦）。
- 组蛋白乙酰化：HAT（写）、溴结构域蛋白（读）、HDAC（擦）。
- 组蛋白甲基化：HMT（写）、染色质结构域蛋白（读）、HDM（擦）。

**这个「写-读-擦」框架的价值在于解释「可逆性」**：只要擦除酶还在，表观标记就本质上是可逆的——这也是表观药物（去甲基化药、HDAC 抑制剂）能起效的分子前提。对比之下，DNA 序列突变大多不可逆，表观异常却「有救」，这给了癌症治疗一个独特窗口。

**区分三组容易混淆的概念**：

1. **DNA 甲基化 vs 组蛋白甲基化**：前者修饰胞嘧啶碱基本身，后者修饰组蛋白尾巴上的赖氨酸/精氨酸。
2. **印记 vs X 失活**：印记是「按亲本来源」沉默单基因，X 失活是「随机选择」沉默整条 X。
3. **表观遗传 vs 基因突变**：前者改变表达不改变序列，后者改变序列；前者可逆、后者大多不可逆。

**X 失活研究的三个关键证据**：

1. 巴氏小体计数：雌性细胞核里出现一个浓缩的 X 染色质块，雄性没有——失活的细胞学证据。
2. 三色猫：橘黑斑块对应不同 X 失活克隆——失活随机且嵌合的直观证据。
3. X 染色体易位个体：失活常偏向完整 X，畸形 X 被优先沉默——选择压力会影响失活倾向。

**一句话记住本节**：表观遗传是「读同一本书的不同读法」——书页（DNA 序列）没变，但哪些段落被翻开、哪些被合上（表达状态），由甲基化与组蛋白修饰标注，并能随细胞分裂传下去。

## 5 小结

- **表观遗传**：不改变序列的可遗传表达改变；三大机制——DNA 甲基化、组蛋白修饰、非编码 RNA。
- 维持性甲基化让沉默状态随分裂**传代**；基因组印记靠亲本特异的甲基化，造成「亲本来源决定表型」。
- **X 失活**：Xist RNA 随机沉默一条 X，雌性为嵌合体，巴氏小体是它的细胞学标志。
- 表观标记**可逆**：表观药物、营养干预可改变它们；跨代遗传的证据在哺乳动物中仍有限。
- 癌症表观遗传：启动子甲基化沉默抑癌基因，甲基化谱成为癌症分型工具。
