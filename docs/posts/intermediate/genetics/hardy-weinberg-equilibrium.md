# Hardy-Weinberg平衡

<div class="epigraph">
<p>在没有外力扰动的理想群体里，基因频率代代不变——变异本身不会自动消失。</p>

## 为什么从「不变」开始

上一节我们学会了计算等位基因频率。现在问一个更根本的问题：**如果什么都不做，频率会怎么变？** 达尔文主义与孟德尔遗传在 20 世纪初有个著名误解——有人以为显性等位基因会一代代「扩散」，最终把隐性等位基因消灭。1908 年哈代（数学家的回答）与温伯格（医生的独立推导）证明：**错。只要条件理想，等位基因频率一代代保持不变。**

这个「不变」的结论看似平淡，却是整个群体遗传学的坐标系：**有了零模型，才能谈偏离**。就像物理学先假设无摩擦，遗传学先假设无扰动——所有选择、漂变、突变、迁移的研究，都是对 HWE 这个「静止参考系」的偏离分析。<span class="marginnote">哈代是被朋友问起「显性是否会消灭隐性」这个疑问而提笔的，他把回答写在 1908 年的《Science》上，一段话就给出了平衡法则。温伯格同年独立在德国期刊发表——「科学发现常常几乎同时出现」在遗传学里又一次上演（孟德尔的重新发现也是三人同年）。</span>

## 1 HWE 的五个条件与两条结论

**核心概念**：**Hardy-Weinberg 平衡**描述一个**理想群体**：当且仅当五个条件成立时，等位基因频率与基因型频率代代保持恒定，且基因型频率由等位基因频率唯一确定。

五个理想条件：

1. **群体无限大**（没有遗传漂变）。
2. **随机交配**（无选型交配）。
3. **无突变**（突变不发生或不改变频率）。
4. **无选择**（各基因型生存与繁殖力相同）。
5. **无迁移**（没有个体进出）。

两条结论：

- **等位基因频率恒定**：$p$、$q$ 一代传一代不变。
- **基因型频率由二项式确定**：$P_{AA} = p^2$，$P_{Aa} = 2pq$，$P_{aa} = q^2$。

**重点：HWE 不是「没有进化」，而是「进化的零假设」**。真实群体几乎总偏离 HWE——偏离的方向与程度，正是选择、漂变等力量存在的证据。HWE 的价值不在「符合」，而在「可检验地不符合」。

换句话说，HWE 是群体遗传学的「静止坐标系」：先把「如果什么都没发生」的频率预言出来，再用实际数据对照——任何偏离都是一个待解释的信号。这个「先设零模型、再找偏离」的思路，是整个定量生物学的通用方法。

## 2 公式解析：平衡的推导与检验

**平衡的推导**：设亲代配子中 $A$ 频率 $p$、$a$ 频率 $q$，随机交配等价于配子随机两两结合：

| 精子 \ 卵子 | A（p） | a（q） |
| --- | --- | --- |
| A（p） | $AA = p^2$ | $Aa = pq$ |
| a（q） | $Aa = pq$ | $aa = q^2$ |

**第一步，合并棋盘**：$AA = p^2$，$Aa = pq + pq = 2pq$，$aa = q^2$。且
$$
p^2 + 2pq + q^2 = (p+q)^2 = 1
$$

**第二步，验证等位基因频率不变**：子代中 $A$ 的频率 $= p^2 + \frac{1}{2}(2pq) = p^2 + pq = p(p+q) = p$——**恰好等于亲代的 $p$**。于是下一代又是同样的 $p^2, 2pq, q^2$，平衡自持。

**第三步，检验是否达到平衡**：用实际观测的基因型数与期望数做 $\chi^2$ 检验。期望数：$AA$ 期望 $= p^2 \times N$，$Aa$ 期望 $= 2pq \times N$，$aa$ 期望 $= q^2 \times N$。
$$
\chi^2 = \sum \frac{(\text{观测数} - \text{期望数})^2}{\text{期望数}}
$$
自由度 = 基因型类别数 − 等位基因数 = 3 − 2 = 1。<span class="marginnote">检验 HWE 时自由度为什么是 1 而非 2？因为基因型数受 $p$ 一个参数约束（$q = 1-p$），期望值是由数据估计的参数算出来的。这个「估计一个参数扣一个自由度」的思想，是《遗传力估计》与统计学衔接的起点。</span>

> **辨析｜易错点：** ① 期望基因型数必须用**个体数**（$p^2 N$）而不是百分比；② $\chi^2$ 检验的**期望数 ≥ 5** 的要求在稀有等位基因时常常不满足——当 $q$ 很小（如罕见病 $q^2 \approx 10^{-4}$），$aa$ 期望数远小于 5，此时 $\chi^2$ 不可靠，要用精确检验；③ 检验「偏离 HWE」不等于「检验有没有进化」——样本量太小或太大都会误导结论，偏离可能只是抽样噪声。

## 3 应用：从发病率推算携带者频率

HWE 最重要的实用价值：**从隐性疾病的发病率反推携带者频率**。

设某常染色体隐性遗传病的发病率为 $f$（即 $q^2$），则：

- 致病等位基因频率 $q = \sqrt{f}$。
- 正常等位基因频率 $p = 1 - q$。
- **携带者频率 $= 2pq$**（杂合子，不发病但携带着一个致病等位基因）。

**算一个具体例子**：囊性纤维化在白人中的发病率约 1/2500，即 $q^2 = 0.0004$。则
$$
q = \sqrt{0.0004} = 0.02, \qquad p = 0.98, \qquad \text{携带者频率 } = 2 \times 0.98 \times 0.02 \approx 0.039
$$

**重点：发病率 1/2500，携带者频率却是 1/25 左右**——携带者是患者的 50 倍。这个「冰山效应」是遗传咨询的核心：大多数致病基因藏在看似健康的杂合子携带者身上。<span class="marginnote">携带者频率 ≈ $2\sqrt{f}$（当 $p \approx 1$），所以「发病率开方再乘 2」就是携带者比例。从 1/2500 到 1/25，只差一个开方——这个放大正是隐性病「表面罕见、背后普遍」的数学本质。</span>

## 4 HWE 的偏离诊断

当观测基因型频率偏离期望时，问三个问题找原因：

| 观测特征 | 提示的原因 | 后续检查 |
| --- | --- | --- |
| $H_o < H_e$（杂合子偏少） | 近交、亚群分化（Wahlund 效应） | 算近交系数 $F$、检查亚群 |
| $H_o > H_e$（杂合子偏多） | 选型异交、杂合优势 | 检查选择系数 |
| 频率在世代间变化 | 选择、漂变、迁移、突变 | 世代追踪 |

**核心概念**：**Wahlund 效应**：即使每个亚群内部都符合 HWE，把亚群合并成大群体后，会因等位基因频率不同而出现杂合子**缺失**——合并本身制造「表面近交」。这是群体分层（如不同族群混合样本）造成假象的经典来源，也是全基因组关联研究（GWAS）必须校正群体分层的原因。<span class="marginnote">Wahlund 效应是「分层数据」的统计学警钟：把两个频率不同的亚群数据一锅炖，会造出根本不存在的杂合子缺失。今天的 GWAS 用主成分分析校正人群结构，正是对同一个问题的现代处理——这条线索延续到《基因组学与遗传学前沿》。</span>

### HWE 的「成对」概念清单

| 概念对 | 关系 |
| --- | --- |
| 基因型频率 vs 等位基因频率 | 前者个体比例、后者配子比例 |
| 期望杂合度 $2pq$ vs 观测杂合度 $H_o$ | 偏离 = 近交/分化的证据 |
| 平衡 vs 不平衡 | 平衡是零假设，不平衡是信号 |
| 群体频率 vs 个体风险 | 频率是群体属性，风险是个人概率 |

**HWE 检验的实用要点**：

1. 期望数必须用「个体数 × 概率」，不是百分比。
2. 稀有等位基因时期望数 < 5，$\chi^2$ 不适用，改用精确检验。
3. 检出「显著偏离」先别急着说「有进化」——先排除抽样误差与群体分层（Wahlund 效应）。

**从平衡到不平衡的意义**：偏离 HWE 的杂合子缺失，可能是近交（增加纯合）、Wahlund 效应（亚群分层）、或选型婚配。杂合子过量则可能提示杂合优势（如镰状细胞贫血携带者对疟疾的抗性）——这正是《突变、选择与迁移》里平衡选择的故事。

## 5 小结

- **HWE 五条件**：无限大、随机交配、无突变、无选择、无迁移；两条结论：频率恒定 + 基因型 $p^2, 2pq, q^2$。
- 平衡的证明靠**配子随机结合 + 频率循环自持**；偏离用 $\chi^2$ 检验（自由度 = 1）。
- 应用：**隐性病发病率开方 → 等位基因频率 → 携带者频率 $2pq$**；携带者远多于患者。
- $H_o$ 与 $H_e$ 之差诊断近交（$H_o < H_e$）或远交（$H_o > H_e$）；Wahlund 效应提醒「合并≠平衡」。

在下一节，我们开始逐项打破五个条件：先看**突变、选择与迁移**如何系统地改变等位基因频率——进化的三大驱动力。
