## 为什么是 SU(2) 与 SU(3)

前面的篇章建立了抽象的表示论，而物理中绝大多数对称性是**紧李群**：$SU(2)$（自旋、同位旋）、$SU(3)$（色荷、八重法）、$SO(3)$（空间旋转）。好消息是：紧李群的表示论与它们的复化李代数的表示论**一一对应**，Weyl 定理、最高权分类全部适用。于是第 6、11、12 篇的抽象结果在 $SU(2)$ 与 $SU(3)$ 上落地成量子数与粒子多重态。<span class="marginnote">「紧群表示 = 复李代数表示」的精确机制由 Weyl 的「酉技巧」给出：紧群上可做平均积分，把任意表示度量化为酉表示；而酉群与复化代数的表示一一对应。第 14 篇《指数映射》将给出李群→李代数方向的桥梁。</span>

为什么偏偏是这两个群？因为它们是**维数最低、物理最丰富**的紧单李群：$SU(2) \cong \operatorname{Spin}(3)$ 掌管三维空间的旋转与自旋，$SU(3)$ 掌管色荷与味对称。更实际的原因是它们都「足够小到能画出来」——$SU(2)$ 的权重图是线段，$SU(3)$ 的权重图是平面三角形/六边形，都能在一张图上完整画出所有不可约表示。把这两个案例吃透，$SU(N)$ 的高维推广就只是把平面图换成高维图。

还值得一提的是「表示 = 量子数」的对应在这两个群上尤其完整：$SU(2)$ 的一个表示由单个量子数 $j$ 确定，$SU(3)$ 的一个表示由一对 $(p,q)$ 确定——表示的维数公式、张量积规则、Clebsch–Gordan 系数全都能写成这两个数的函数。这套「少参数刻画全结构」的简洁性，正是表示论在物理中长盛不衰的原因。

## 1 SU(2)：自旋的表示

$SU(2)$ 是行列式为 1 的 $2\times2$ 酉矩阵群，其李代数 $\mathfrak{su}(2)$ 的复化正是 $\mathfrak{sl}(2,\mathbb{C})$：

$$\mathfrak{su}(2) \otimes \mathbb{C} \cong \mathfrak{sl}(2, \mathbb{C})$$

因此 $SU(2)$ 的不可约表示就是第 6 篇的 $V_n$（维数 $n+1$），用物理语言标记为**自旋 $j$**（$j = n/2$）。<span class="marginnote">自旋 $j = 0, \tfrac12, 1, \tfrac32, \dots$ 对应 $n = 0,1,2,3$。半整数自旋来自 $SU(2)$ 是 $SO(3)$ 的二重覆盖：$SU(2) \to SO(3)$ 是 2 对 1，$SO(3)$ 只看见整数自旋，$SU(2)$ 还给出半整数自旋——这是量子力学中「自旋 1/2 存在」的群论根源。</span>

**核心事实（$SU(2)$ 表示清单）**：对每个 $j \in \{0, \tfrac12, 1, \dots\}$，恰有一个 $2j+1$ 维不可约表示，记作 $V_j$。$j=0$ 平凡，$j=\tfrac12$ 是定义表示，$j=1$ 是伴随表示（三维）。

**Clebsch–Gordan 分解**是张量积的规则：

$$V_j \otimes V_{j'} = \bigoplus_{J = |j - j'|}^{j + j'} V_J$$

例如 $V_{1/2} \otimes V_{1/2} = V_1 \oplus V_0$（自旋 1/2 与自旋 1/2 耦合出自旋 1 和 0）。<span class="marginnote">这是量子力学角动量耦合的代数表述；谱分解 $V_{1/2}\otimes V_{1/2} = V_1 \oplus V_0$ 对应「三重态 + 单态」——自旋三重态 $|1,m\rangle$ 与自旋单态 $|0,0\rangle$ 的著名分裂。</span>

**矩阵实现**：$V_j$ 的基可以取为齐次多项式的空间——$V_j$ 作用在由两个复变量 $z_1, z_2$ 组成的 $2j$ 次齐次多项式上，$SU(2)$ 通过线性变换 $(z_1, z_2) \mapsto (az_1 + bz_2, -\bar b z_1 + \bar a z_2)$ 作用。于是 $V_{1/2}$ 是二元一次多项式（二维），$V_1$ 是二元二次多项式 $\{z_1^2, z_1z_2, z_2^2\}$（三维）。这套「多项式实现」让每个表示的态都有了显式函数形状，是量子力学里球谐函数作为角动量本征态的代数根源。

## 2 SU(3)：八重法与夸克模型

$SU(3)$ 的不可约表示由两个非负整数 $(p, q)$ 标记（对应最高权 $p\omega_1 + q\omega_2$），维数为

$$\dim V_{(p,q)} = \frac{(p+1)(q+1)(p+q+2)}{2}$$

**核心事实（$SU(3)$ 小表示）**：

| $(p,q)$ | 维数 | 物理角色 |
| --- | --- | --- |
| $(1,0)$ | $3$ | 夸克三重态（$u, d, s$） |
| $(0,1)$ | $\bar 3$ | 反夸克 |
| $(1,1)$ | $8$ | 介子八重态 / 胶子（伴随） |
| $(3,0)$ | $10$ | 重子十重态（含 $\Omega^-$） |

这些维数与粒子物理中 Gell-Mann 的**八重法（Eightfold Way）**精确吻合：强子的多重态正是 $SU(3)$ 的不可约表示。<span class="marginnote">Gell-Mann 1961 年提出八重法时，$\Omega^-$ 尚未发现，但 $SU(3)$ 十重态预言了它的存在、质量与衰变——1964 年被实验证实。这是表示论预言物理的教科书级事件。</span>

**维数公式的快速验证**：代入 $(p,q)$ 逐个核对——$(0,0)$：$1$；$(1,0)$：$\tfrac{2\cdot1\cdot3}{2}=3$；$(0,1)$：$3$；$(1,1)$：$\tfrac{2\cdot2\cdot4}{2}=8$；$(2,0)$：$\tfrac{3\cdot1\cdot4}{2}=6$；$(3,0)$：$\tfrac{4\cdot1\cdot5}{2}=10$；$(2,1)$：$\tfrac{3\cdot2\cdot5}{2}=15$。维数从小到大正是 $1, 3, \bar 3, 6, 8, 10, 15, \dots$——所有已知强子多重态的大小全在这串数里，没有例外。这个「只靠两个整数 $(p,q)$ 就生成全部维数」的现象，正是最高权理论（第 11 篇）在物理里最直观的落地。

**张量积规则**（$SU(3)$）用 Young 图或直接分解：

$$3 \otimes \bar 3 = 8 \oplus 1, \qquad 3 \otimes 3 = 6 \oplus \bar 3, \qquad 3 \otimes 3 \otimes 3 = 10 \oplus 8 \oplus 8 \oplus 1$$

例如 $3 \otimes \bar 3$：介子由夸克与反夸克组成，分解出八重态 $8$ 与单态 $1$。<span class="marginnote">「$8 \oplus 1$」对应八个介子加一个 $\eta'$ 单态；$3\otimes3\otimes3 = 10 \oplus 8 \oplus 8 \oplus 1$ 对应重子的十重态与两个八重态——八重法的完整谱全被这些式子盖住。</span>

## 3 Young 图：张量积分解的字典

$SU(N)$ 的张量积分解有一套统一的图解法——**Young 图（Young diagram）**。每个不可约表示对应一个「左对齐的行方块排列」，例如 $SU(3)$ 的 $3$ 对应 $\Box$，$\bar 3$ 对应竖排两格 $\begin{smallmatrix}\Box\\\Box\end{smallmatrix}$，$6$ 对应横排两格 $\Box\Box$。

**分解规则（要点）**：把两个 Young 图做张量积，相当于把一个图的所有方块用「标记后的对称化」塞进另一个图，再按「每列无重复数字、行递增、列严格递增」的 Littlewood–Richardson 规则读出结果。对 $3 \otimes 3$：

- $\Box \otimes \Box = \Box\Box \oplus \begin{smallmatrix}\Box\\\Box\end{smallmatrix}$——对称部分 $6$ 加反对称部分 $\bar 3$，即 $3 \otimes 3 = 6 \oplus \bar 3$。

- 对 $3 \otimes \bar 3$：$\Box \otimes \begin{smallmatrix}\Box\\\Box\end{smallmatrix} = \Box\Box \oplus \Box$ 带两个「直积行」的修正——最终 $8 \oplus 1$，其中 $8$ 对应「三列各两格的阶梯」，$1$ 对应全反对称（单态）。

**数值对照**：维数公式 $(p+1)(q+1)(p+q+2)/2$ 对 $(1,1)$ 给出 $\tfrac{2\cdot 2\cdot 4}{2} = 8$，对 $(0,0)$ 给出 $1$——图、公式、物理三重印证。Young 图的价值在于：它把「查 Clebsch–Gordan 表」变成「摆积木」，$SU(2)$、$SU(3)$、$SU(N)$ 全部通用。

## 4 公式解析：$3 \otimes \bar 3 = 8 \oplus 1$

用特征标（第 12 篇）或权重图验证 $SU(3)$ 最常用的分解。$3$ 的权谱是三个权 $\{\omega_1, \omega_2 - \omega_1, -\omega_2\}$（三角形顶点），$\bar 3$ 是它的对偶（反向三角形）。

**第一步，张量积的权谱**：$\operatorname{ch}(3 \otimes \bar 3) = \operatorname{ch}3 \cdot \operatorname{ch}\bar 3$——九个权对（$3\times3 = 9$ 项）相加。
- **第二步，识别不变子空间**：九维中有一维由「迹」张量张成（$\sum_i e_i \otimes e^i$ 是 $SU(3)$ 不变，构成单态 $1$）；其余八维是「无迹部分」（$3 \times 3$ 无迹矩阵构成伴随表示 $8$）。

这第二步其实是「矩阵就是张量积」的视角：$3 \otimes \bar 3$ 自然同构于 $3\times3$ 矩阵空间（行指标来自 $3$，列指标来自 $\bar 3$），$SU(3)$ 作用为 $M \mapsto U M U^{-1}$。在这个实现下，「迹」是唯一不变量，「无迹条件 $\operatorname{tr}M = 0$」恰好切出八维的伴随表示——抽象的张量积分解变成了「把矩阵空间按迹拆开」这么一句直白的话。
- **第三步，读出分解**：$9 = 8 + 1$，正是 $8 \oplus 1$。<span class="marginnote">无迹条件 $\operatorname{tr} M = 0$ 把九维劈成八维 + 一维，这正是 Killing 型正交补思想的体现——$8$ 是伴随表示，$1$ 是平凡表示。</span>

**核心要点**：$SU(3)$ 的张量积分解（Young 表法）是「如何组合夸克得到强子」的完整字典；维数公式 $(p+1)(q+1)(p+q+2)/2$ 与 Clebsch–Gordan 规则构成物理表示论的运算系统。

**从一个分解读出的物理故事**：$3 \otimes 3 \otimes 3 = 10 \oplus 8 \oplus 8 \oplus 1$ 对应「三个夸克组成重子」。其中 $10$ 是十重态（含 $\Omega^-$），两个 $8$ 是八重态（核子、$\Xi$ 等），$1$ 是单态。若只数维数：$27 = 10 + 8 + 8 + 1$——分解守恒维数，不增不减。这套「维数守恒」是检查任何张量积分解是否算对的第一道保险：**先加维数，再信分解**。

**权重图与量子数**：每个不可约表示都能画成「权重图」——权在平面上排成的格子。$3$ 的权重图是三角形顶点 $\{\omega_1, \omega_2-\omega_1, -\omega_2\}$，$8$ 的权重图是正六边形（中心是零权，多重度 2）。物理上每个权对应一组量子数（超荷 $Y$ 与同位旋第三分量 $I_3$），权重图因此直接就是「粒子量子数谱」：Gell-Mann 把强子按权重图分类，就得到了那张著名的八重法谱图。

## 5 与深度学习等变的联系

表示论并非只属于粒子物理。**等变神经网络（equivariant neural networks）**在设计网络时要求权重更新与对称群作用可交换——$SO(3)$/$SU(2)$ 的不可约表示（球谐函数）正是消息传递的基函数。<span class="marginnote">例如点云模型利用 $SO(3)$ 不可约表示作为滤波器组；这些「旋转等变」网络能泛化到未见过的旋转，是表示论在机器学习中的直接落地。第 13 篇与第三级《深度学习》《计算机视觉》的连接正在此处。</span>

**辨析｜易错点：** $SU(2)$ 与 $SO(3)$ 的表示**不是一回事**：$SO(3)$ 只有整数自旋（$j \in \mathbb{Z}$），$SU(2)$ 还多出半整数自旋。凡涉及「2 对 1 覆盖」的场合（自旋、费米子），必须用 $SU(2)$ 而非 $SO(3)$。这是量子力学与表示论衔接处最经典也最易错的一个坑。

**一个具体场景**：点云分类网络里，若要求对三维旋转不变，输入特征必须按 $SO(3)$ 的不可约表示分解——每个特征通道对应一个 $j$，通道间的耦合由 Clebsch–Gordan 系数给出（第 13 篇）。旋转「改变特征值但不改变通道内结构」，正是「等变」的含义。这套思路从粒子物理搬到机器学习只换了标签，数学一字未动——这就是表示论作为「通用对称语言」的力量。

## 6 小结

- $SU(2)$ 表示 = $\mathfrak{sl}(2,\mathbb{C})$ 表示：$2j+1$ 维，$j$ 取半整数；$SO(3)$ 只见整数 $j$。
- **Clebsch–Gordan 分解** $V_j \otimes V_{j'} = \bigoplus_{|j-j'|}^{j+j'} V_J$ 是角动量耦合的代数规则。
- $SU(3)$ 表示由 $(p,q)$ 标记，维数公式 $\dim V_{(p,q)} = (p+1)(q+1)(p+q+2)/2$。
- **八重法**：$3 \otimes \bar 3 = 8 \oplus 1$，$3\otimes3\otimes3 = 10\oplus 8\oplus 8\oplus 1$——强子谱的代数来源。
- 表示论同时是**等变深度学习**的基础；$SU(2)$ vs $SO(3)$ 的覆盖差别是最易错点。
- **Young 图**把张量积分解变成「摆积木」，$3\otimes 3 = 6 \oplus \bar 3$、$3\otimes\bar 3 = 8 \oplus 1$ 全由此读出。
- 权重图 = 量子数谱：$3$ 是三角形，$8$ 是六边形（中心权多重度 2），Gell-Mann 八重法谱图由此而来。
- 物理 ↔ 等变深度学习的映射：Clebsch–Gordan 系数既耦合角动量，也耦合旋转不变特征通道。
- $V_j$ 的「多项式实现」把表示态写成显式函数，是球谐函数作为角动量本征态的代数根源。
- 维数公式生成 $1, 3, 6, 8, 10, 15, \dots$——全部强子多重态大小都在其中，无一例外。
- 「先加维数，再信分解」是检验张量积分解是否算对的第一道保险。
- 酉技巧保证紧群表示 = 复李代数表示，物理中全部对称群分析可放心在代数层面进行。
- 少参数刻画全结构：$SU(2)$ 一个 $j$、$SU(3)$ 一对 $(p,q)$ 决定整个表示论。
