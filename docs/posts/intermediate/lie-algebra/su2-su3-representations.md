## 为什么是 SU(2) 与 SU(3)

前面的篇章建立了抽象的表示论，而物理中绝大多数对称性是**紧李群**：$SU(2)$（自旋、同位旋）、$SU(3)$（色荷、八重法）、$SO(3)$（空间旋转）。好消息是：紧李群的表示论与它们的复化李代数的表示论**一一对应**，Weyl 定理、最高权分类全部适用。于是第 6、11、12 篇的抽象结果在 $SU(2)$ 与 $SU(3)$ 上落地成量子数与粒子多重态。<span class="marginnote">「紧群表示 = 复李代数表示」的精确机制由 Weyl 的「酉技巧」给出：紧群上可做平均积分，把任意表示度量化为酉表示；而酉群与复化代数的表示一一对应。第 14 篇《指数映射》将给出李群→李代数方向的桥梁。</span>

## 1 SU(2)：自旋的表示

$SU(2)$ 是行列式为 1 的 $2\times2$ 酉矩阵群，其李代数 $\mathfrak{su}(2)$ 的复化正是 $\mathfrak{sl}(2,\mathbb{C})$：

$$\mathfrak{su}(2) \otimes \mathbb{C} \cong \mathfrak{sl}(2, \mathbb{C})$$

因此 $SU(2)$ 的不可约表示就是第 6 篇的 $V_n$（维数 $n+1$），用物理语言标记为**自旋 $j$**（$j = n/2$）。<span class="marginnote">自旋 $j = 0, \tfrac12, 1, \tfrac32, \dots$ 对应 $n = 0,1,2,3$。半整数自旋来自 $SU(2)$ 是 $SO(3)$ 的二重覆盖：$SU(2) \to SO(3)$ 是 2 对 1，$SO(3)$ 只看见整数自旋，$SU(2)$ 还给出半整数自旋——这是量子力学中「自旋 1/2 存在」的群论根源。</span>

**核心事实（$SU(2)$ 表示清单）**：对每个 $j \in \{0, \tfrac12, 1, \dots\}$，恰有一个 $2j+1$ 维不可约表示，记作 $V_j$。$j=0$ 平凡，$j=\tfrac12$ 是定义表示，$j=1$ 是伴随表示（三维）。

**Clebsch–Gordan 分解**是张量积的规则：

$$V_j \otimes V_{j'} = \bigoplus_{J = |j - j'|}^{j + j'} V_J$$

例如 $V_{1/2} \otimes V_{1/2} = V_1 \oplus V_0$（自旋 1/2 与自旋 1/2 耦合出自旋 1 和 0）。<span class="marginnote">这是量子力学角动量耦合的代数表述；谱分解 $V_{1/2}\otimes V_{1/2} = V_1 \oplus V_0$ 对应「三重态 + 单态」——自旋三重态 $|1,m\rangle$ 与自旋单态 $|0,0\rangle$ 的著名分裂。</span>

## 2 SU(3)：八重法与夸克模型

$SU(3)$ 的不可约表示由两个非负整数 $(p, q)$ 标记（对应最高权 $p\omega_1 + q\omega_2$），维数为

$$\dim V_{(p,q)} = \frac{(p+1)(q+1)(p+q+2)}{2}$$

**核心事实（$SU(3)$ 小表示）**：

| $(p,q)$ | 维数 | 物理角色 |
| --- | --- | --- |
| $(1,0)$ | $3$ | 夸克三重态（$u, d, s$） |
| $(0,1)$ | $\bar 3$ | 反夸克 |
| $(1,1)$ | $8$ | 介子八重态 / 胶子（伴随） |
| $(3,0)$ | $10$ | 重子十重态（含 $\Omega^-$） |

这些维数与粒子物理中 Gell-Mann 的**八重法（Eightfold Way）**精确吻合：强子的多重态正是 $SU(3)$ 的不可约表示。<span class="marginnote">Gell-Mann 1961 年提出八重法时，$\Omega^-$ 尚未发现，但 $SU(3)$ 十重态预言了它的存在、质量与衰变——1964 年被实验证实。这是表示论预言物理的教科书级事件。</span>

**张量积规则**（$SU(3)$）用 Young 图或直接分解：

$$3 \otimes \bar 3 = 8 \oplus 1, \qquad 3 \otimes 3 = 6 \oplus \bar 3, \qquad 3 \otimes 3 \otimes 3 = 10 \oplus 8 \oplus 8 \oplus 1$$

例如 $3 \otimes \bar 3$：介子由夸克与反夸克组成，分解出八重态 $8$ 与单态 $1$。<span class="marginnote">「$8 \oplus 1$」对应八个介子加一个 $\eta'$ 单态；$3\otimes3\otimes3 = 10 \oplus 8 \oplus 8 \oplus 1$ 对应重子的十重态与两个八重态——八重法的完整谱全被这些式子盖住。</span>

## 3 公式解析：$3 \otimes \bar 3 = 8 \oplus 1$

用特征标（第 12 篇）或权重图验证 $SU(3)$ 最常用的分解。$3$ 的权谱是三个权 $\{\omega_1, \omega_2 - \omega_1, -\omega_2\}$（三角形顶点），$\bar 3$ 是它的对偶（反向三角形）。

**第一步，张量积的权谱**：$\operatorname{ch}(3 \otimes \bar 3) = \operatorname{ch}3 \cdot \operatorname{ch}\bar 3$——九个权对（$3\times3 = 9$ 项）相加。
- **第二步，识别不变子空间**：九维中有一维由「迹」张量张成（$\sum_i e_i \otimes e^i$ 是 $SU(3)$ 不变，构成单态 $1$）；其余八维是「无迹部分」（$3 \times 3$ 无迹矩阵构成伴随表示 $8$）。
- **第三步，读出分解**：$9 = 8 + 1$，正是 $8 \oplus 1$。<span class="marginnote">无迹条件 $\operatorname{tr} M = 0$ 把九维劈成八维 + 一维，这正是 Killing 型正交补思想的体现——$8$ 是伴随表示，$1$ 是平凡表示。</span>

**核心要点**：$SU(3)$ 的张量积分解（Young 表法）是「如何组合夸克得到强子」的完整字典；维数公式 $(p+1)(q+1)(p+q+2)/2$ 与 Clebsch–Gordan 规则构成物理表示论的运算系统。

## 4 与深度学习等变的联系

表示论并非只属于粒子物理。**等变神经网络（equivariant neural networks）**在设计网络时要求权重更新与对称群作用可交换——$SO(3)$/$SU(2)$ 的不可约表示（球谐函数）正是消息传递的基函数。<span class="marginnote">例如点云模型利用 $SO(3)$ 不可约表示作为滤波器组；这些「旋转等变」网络能泛化到未见过的旋转，是表示论在机器学习中的直接落地。第 13 篇与第三级《深度学习》《计算机视觉》的连接正在此处。</span>

**辨析｜易错点：** $SU(2)$ 与 $SO(3)$ 的表示**不是一回事**：$SO(3)$ 只有整数自旋（$j \in \mathbb{Z}$），$SU(2)$ 还多出半整数自旋。凡涉及「2 对 1 覆盖」的场合（自旋、费米子），必须用 $SU(2)$ 而非 $SO(3)$。这是量子力学与表示论衔接处最经典也最易错的一个坑。

## 5 小结

- $SU(2)$ 表示 = $\mathfrak{sl}(2,\mathbb{C})$ 表示：$2j+1$ 维，$j$ 取半整数；$SO(3)$ 只见整数 $j$。
- **Clebsch–Gordan 分解** $V_j \otimes V_{j'} = \bigoplus_{|j-j'|}^{j+j'} V_J$ 是角动量耦合的代数规则。
- $SU(3)$ 表示由 $(p,q)$ 标记，维数公式 $\dim V_{(p,q)} = (p+1)(q+1)(p+q+2)/2$。
- **八重法**：$3 \otimes \bar 3 = 8 \oplus 1$，$3\otimes3\otimes3 = 10\oplus 8\oplus 8\oplus 1$——强子谱的代数来源。
- 表示论同时是**等变深度学习**的基础；$SU(2)$ vs $SO(3)$ 的覆盖差别是最易错点。
