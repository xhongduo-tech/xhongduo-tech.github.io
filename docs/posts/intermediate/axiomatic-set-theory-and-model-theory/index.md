# 公理集合论与模型论

公理集合论与模型论是数理逻辑的两大核心分支：前者以 ZFC 公理系统重建数学基础，从序数与基数一路走向可构造宇宙与力迫法，最终证明连续统假设等经典问题的独立性；后者研究一阶逻辑中结构与理论的整体性质，以紧致性定理、Löwenheim-Skolem 定理为出发点，通向量词消去、饱和模型与 Morley 范畴性定理。学完本专题，即掌握现代数学基础中最深刻的独立性证明与模型论的核心工具箱。

## 对标教材

- Thomas Jech, "Set Theory" (Springer, 3rd Millennium Edition)
- Kenneth Kunen, "Set Theory" (College Publications, 2011)
- David Marker, "Model Theory: An Introduction" (Springer GTM 217, 2002)
