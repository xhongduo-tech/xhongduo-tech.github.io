## 为什么从「一致的证据集」开始

上一篇定义了结构与满足。现在问：**给出一组句子，它什么时候有模型？** 紧致性定理（compactness theorem）给出最漂亮也最反直觉的答案：

$$\text{理论 } T \text{ 有模型} \Longleftrightarrow T \text{ 的每个有限子集有模型}$$

「有限地一致」居然蕴含「整体一致」——把无限多证据压缩成有限检验，这正是「紧致」二字的来历（与拓扑里紧空间的有限子覆盖一脉相承）。<span class="marginnote">紧致性定理由哥德尔 1930 年（作为完全性定理的推论）得到，马利采夫（Malcev）1941 年独立证明并首次作为「模型存在性」工具使用，亨金（Henkin）1949 年给出构造性证明。它现在是模型论的「第一定理」——几乎所有后续结果都从它出发。</span>

这一篇讲它的三个经典应用：**非标准模型**（自然数的「无穷大」）、**非标准分析**（鲁宾逊 1966 年让无穷小复活）、以及**超积构造**（用超滤把一族结构粘成一个）。它们合起来证明一件事：**紧致性定理不是抽象存在性，而是能造出「不存在的对象」的机器**。

## 1 非标准自然数：在 ω 之外还有数

在自然数理论 $T$ 里加一个新常量 $c$，加一整套句子 $\{n < c : n \in \mathbb{N}\}$。每个有限子集只含有限多个 $n < c$，取足够大的普通自然数当 $c$ 的解释即可——有限子集总有模型。于是由紧致性：

$$T \cup \{n < c : n \in \mathbb{N}\} \text{ 有模型 } \mathbb{N}^*$$

**$\mathbb{N}^*$ 就是非标准自然数模型**：它满足与 $\mathbb{N}$ 完全相同的一阶算术句子，却含有一个「大于每个标准自然数」的元素 $c$。<span class="marginnote">这是「初等等价 ≠ 同构」的第一次实质收获（上一篇的预告兑现）：$\mathbb{N}^* \equiv \mathbb{N}$，但论域里藏着 $\mathbb{N}$ 没有的元素。超滤在这里还没登场，紧致性就够了。</span>

**公式解析：为什么有限子集总有模型。** 关键在「有限」二字：

- 给定 $T' = \{n < c : n \in \mathbb{N}\}$ 的一个有限子集，它只涉及 $n < c$ 的**有限个**（比如 $n = 5, 17, 999$）。取 $c = 1000$ 就全满足。
- 每个有限子集都这样「各自取个够大的 $c$」——但**没有一个** $c$ 能同时满足所有 $n < c$（那要 $c$ 大于一切自然数）。紧致性定理恰恰断言：有限检验通过 ⟹ 有一个**完整**模型。矛盾吗？不——新模型的论域里有「新的」自然数（非标准元），它们不属于 $\mathbb{N}$。**我们用一个「更大的数」回答了「有没有比一切自然数都大的数」**，代价是模型不再同构于 $\mathbb{N}$。

这个构造立即连锁爆炸：存在满足 PA 的模型，其论域是任何给定大小的基数（由 Löwenheim-Skolem 与紧致性配合）；算术真理性也无法在「标准模型 $\mathbb{N}$」里一阶地封死——这正是哥德尔第一不完全性定理的模型论侧影。

## 2 非标准分析：无穷小的合法化

同一个套路搬到实分析。在实闭域理论 $\mathrm{RCF}$ 里加常量 $c$ 与句子 $\{r < c : r \in \mathbb{R}\}$，紧致性给出**非标准实数模型** $\mathbb{R}^*$：$\mathbb{R}^* \equiv \mathbb{R}$，但含无限大元素 $c$。取倒数 $1/c$ 就是**无穷小**。<span class="marginnote">莱布尼茨用无穷小推了二百年的微积分，被柯西与魏尔斯特拉斯的 $\varepsilon\text{-}\delta$ 语言驱逐；1966 年鲁宾逊用模型论把它们请了回来——无穷小在 $\mathbb{R}^*$ 里不是「不存在」而是「非标准」。这条历史线在《从极限到大模型》的「极限」一章正好衔接。</span>

**为什么非标准分析安全**：$\mathbb{R}^* \equiv \mathbb{R}$ 保证「$\mathbb{R}$ 里可证明的，$\mathbb{R}^*$ 里也真」——所有一阶定理自动移植。但注意陷阱：**勒贝格测度、完备性（二阶性质）在非标准扩张里会走样**，所以非标准分析严格说处理的是「可转移的一阶命题」。鲁宾逊的方法把分析学里「取极限」的步骤替换成「取标准部分 $\mathrm{st}$」，本质上是用模型论把 $\varepsilon\text{-}\delta$ 换成了「结构内部的无穷小」。

**公式解析：无穷小如何定义。** 设 $\mathbb{R}^*$ 由超滤 $U$ 造出（下一节）。元素 $x \in \mathbb{R}^*$ 分三类：

- **标准**：$x = r$（$r \in \mathbb{R}$ 的常值像）；
- **无穷小**：$|x| < \varepsilon$ 对所有正标准 $\varepsilon$，即 $x \approx 0$；
- **无限大**：$|x| > n$ 对所有标准自然数 $n$。

对每个有限元素 $x$，存在唯一标准实数 $\mathrm{st}(x)$ 使 $x \approx \mathrm{st}(x)$。于是导数 $f'(a)$ 可以写成

$$f'(a) = \mathrm{st}\left( \frac{f(a+\eta) - f(a)}{\eta} \right), \qquad \eta \text{ 无穷小，}\eta \ne 0$$

——这正是莱布尼茨「$\frac{dy}{dx}$」的严格版：先取真分式，再取标准部分。极限被翻译成「相邻无穷小的比值」，而 $\mathrm{st}$ 把「取极限」变成一个结构内运算。<span class="marginnote">对照：在标准分析里，$f'(a)$ 的定义是一个 $\forall \varepsilon \exists \delta$ 的限定式（含二阶量词），而 $\mathrm{st}(\cdots)$ 只在一阶框架里消化了它。非标准分析的价值是「把无限过程压成结构内的一步」，代价是要先买下超积与超滤这笔基础投资。</span>

## 3 超积：用超滤把一族结构粘成一个

**超积（ultraproduct）** $\prod_{i \in I} M_i / U$：给定指标集 $I$、一族结构 $M_i$、$I$ 上的超滤 $U$。论域是「一致类」$[f]$（$f,g$ 相同当且仅当 $\{i : f(i) = g(i)\} \in U$），解释逐坐标定义后取一致类。

**Łoś 定理**：对每个公式 $\varphi$，
$$\prod_{i \in I} M_i / U \models \varphi \Longleftrightarrow \{ i \in I : M_i \models \varphi \} \in U$$
「超积里真的，恰好在 $U$-多数坐标上真」——这是把「点态成立」与「超滤判定」合二为一的粘合剂。<span class="marginnote">直觉：$U$ 是一把「哪一半坐标才算数」的尺子，Łoś 定理说这把尺子完全决定超积里的真假。取所有 $M_i = M$（同构副本）的超积叫<strong>超幂（ultrapower）</strong> $M^I / U$，$M$ 以常值函数嵌入 $M^I/U$，且当 $U$ 是 $\aleph_0$-完全时这是<strong>初等嵌入</strong>——大基数篇里 $V^\kappa/U$ 的引擎，正是这一节的特例。</span>

**紧致性的超积证明（一步到位）**：给理论 $T$，取指标集 $I$ = 所有有限子集 $s \subseteq T$；每个 $M_s \models s$（由有限可满足性）。在 $I$ 上取「细超滤」$U$（对每个句子 $\sigma \in T$，集合 $\{s : \sigma \in s\}$ 属于 $U$），则超积 $\prod M_s / U$ 是 $T$ 的模型——因为每个 $\sigma$ 在 $U$-多数坐标上真，Łoś 定理给出 $\prod M_s/U \models \sigma$。**紧致性定理于是变成超滤 + Łoś 定理的直接推论。**

**辨析｜易错点：** 超滤的存在依赖选择公理；「细超滤」的构造是「非主超滤存在」的体现。所以超积证明紧致性 = 用 AC 造一个「哪儿都去的尺子」，再让 Łoś 定理说话——这正好把本专题第2篇「AC 等价于各种存在性」的伏笔收了尾。

## 4 核心对比表：三种构造一台戏

| 构造 | 输入 | 输出 | 核心定理 |
| --- | --- | --- | --- |
| 紧致性（Henkin） | 有限可满足的理论 $T$ | $T$ 的模型 | Henkin 完全性构造 |
| 紧致性（超积） | 有限可满足的 $T$ + 细超滤 | $T$ 的模型 | Łoś 定理 |
| 非标准扩张 | $\mathbb{R}$ + 无穷常量 | $\mathbb{R}^* \equiv \mathbb{R}$ | 紧致性 + 标准部分 |
| 超积/超幂 | 结构族 + 超滤 $U$ | 一个结构 | Łoś 定理 |

**辨析｜易错点：** 「非标准自然数」不是「$\mathbb{N}$ 的一个更大的子集」，而是**初等等价但不同构**的新模型。它的论域里既有标准元（常值像）又有非标准元；一阶句子看不出差别，但集合论层面（二阶）判若云泥——这正是模型论「初等等价 ≠ 同构」的核心教训。

**推广**：非标准方法不止用于分析与算术——它同样适用于数论（非标准有限域）、代数（非标准扩张）与概率（非标准测度空间）。只要理论完备且可数，紧致性就自动给出「标准世界的忠实副本 + 新元素」的整个仓库——这是模型论方法「一法通、法法通」的缩影。

## 5 动手推导：紧致性的超积证明（完整走一遍）

把第3节的一句话展开成四步，看「有限 ⟹ 整体」如何被超滤兑现。

- **第一步，选指标集**：$I = \{ s \subseteq T : s \text{ 有限} \}$，每个 $s$ 是 $T$ 的有限子集。由有限可满足性，对每个 $s$ 选一个模型 $M_s \models s$（这一步用一次选择公理——对每个有限子集挑一个模型）。
- **第二步，造细超滤**：对每个句子 $\sigma \in T$，定义 $D_\sigma = \{ s \in I : \sigma \in s \}$。这些 $D_\sigma$ 有**有限交性质**：$D_{\sigma_1} \cap \cdots \cap D_{\sigma_k} \supseteq \{ \{\sigma_1,\dots,\sigma_k\} \} \ne \emptyset$。由超滤存在定理（第2篇选择公理专文），存在超滤 $U$ 同时包含所有 $D_\sigma$。
- **第三步，取超积**：$\mathcal{M} = \prod_{s \in I} M_s / U$。
- **第四步，Łoś 定理收官**：对任意 $\sigma \in T$，集合 $\{ s : M_s \models \sigma \} \supseteq D_\sigma \in U$，故「$M_s \models \sigma$」在 $U$-多数坐标上成立；Łoś 定理给出 $\mathcal{M} \models \sigma$。因 $\sigma$ 任意，$\mathcal{M}$ 是 $T$ 的模型。

**为什么比 Henkin 证明更短**：Henkin 需要扩充语言 + 逐条构造，超积证明把「一致性」还原成「有限交性质 + 超滤存在」，后者是 AC 的经典等价命题。<span class="marginnote">这里 AC 换了三副面孔出场：选模型（一次）、造超滤（非主超滤存在 = AC）、Łoś 定理的证明。可以说紧致性定理是「AC 在模型论里的最大功臣」——没有 AC 就没有超滤，也就没有这个一步到位的证明。</span>

## 7 小结

- **紧致性定理**：有限可满足 ⟹ 可满足；是哥德尔完全性定理的推论，也是模型论的第一定理。
- **非标准模型**：$\mathbb{N}^* \equiv \mathbb{N}$ 但含大于一切标准自然数的元素。
- **非标准分析**（鲁宾逊 1966）：$\mathbb{R}^*$ 让无穷小合法复活，$f'(a) = \mathrm{st}\bigl(\frac{f(a+\eta)-f(a)}{\eta}\bigr)$。
- **超积/超幂 + Łoš 定理**：点态成立由超滤判定，紧致性由此一步证得。
- 大基数篇的 $V^\kappa/U$ 与这里共享同一台引擎。

在下一节，我们把模型论从「全体模型」聚焦到「个别元素」：**型与稳定性理论初步**——类型如何刻画元素的「一阶个性」，饱和模型、原子模型与量词消去如何把理论分类。
