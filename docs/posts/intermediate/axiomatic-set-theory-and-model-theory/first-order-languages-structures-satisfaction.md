## 为什么从一阶语言开始

集合论篇以「ZFC 是一组公理」结束，但「公理」本身还是一团未经审视的符号。模型论给集合论提供了一面镜子：把数学理论**形式化**成一阶语言里的句子集合，把数学结构**语义化**成解释这些句子的模型。于是「ZFC 一致吗」「CH 独立吗」这类问题变成「是否存在模型」「两个模型是否初等等价」——这正是前面所有独立性证明的元数学框架。<span class="marginnote">一阶逻辑是「量词只作用于个体（元素）、不作用于谓词或函数」的逻辑。它比二阶逻辑弱（后者可量化函数与谓词），但换来的是紧致性、完全性这些好性质——它们让模型论成为一门可以「算」的理论。</span>

今天立起模型论的第一组概念：**一阶语言**（语法）、**结构**（语义）、**满足关系 $\vDash$**（语法与语义的对接）。这是 Marker 第1章的核心，也是后续紧致性、Löwenheim-Skolem、超积等一切内容的语法地基。

## 1 一阶语言：语法组件

**一阶语言（first-order language）** $\mathcal{L}$ 由三部分组成：

**逻辑符号**（固定不变）：变元 $x_0, x_1, \dots$、联结词 $\lnot, \wedge, \vee, \rightarrow$、量词 $\forall, \exists$、等号 $=$、括号。
**非逻辑符号**（随语言而定）：**常数符号** $c$、**函数符号** $f$（带元数 arity）、**关系符号** $R$（带元数）。非逻辑符号的集合叫 **语言签名（signature）**。

例如：

- **环的语言** $\mathcal{L}_{ring} = \{+, \cdot, -, 0, 1\}$（两个二元函数、一个一元函数、两个常数）。
- **序的语言** $\mathcal{L}_{ord} = \{\lt \}$（一个二元关系）。
- **集合论的语言** $\mathcal{L}_\in = \{\in\}$——整个 ZFC 都写在 $\mathcal{L}_\in$ 里。<span class="marginnote">$\mathcal{L}_\in$ 只有一个二元关系符号，却承载了全部集合论——这体现了一阶语言的「节俭」：表达力不靠符号多，靠组合规则深。ZFC 的每个公理都是 $\mathcal{L}_\in$ 里的一个（或一模式）句子。</span>

**项（term）**：由变元、常数与函数符号递归构成（$x + y \cdot 0$）。**原子公式**：$t_1 = t_2$ 或 $R(t_1,\dots,t_n)$。**公式（formula）**：由原子公式经 $\lnot, \wedge, \vee, \rightarrow, \forall x, \exists x$ 递归生成。**句子（sentence）**：没有自由变元的公式。

## 2 结构：语义组件

**$\mathcal{L}$-结构（structure）** $\mathcal{M} = (M, \ldots)$：一个非空集 $M$（论域），加上对每个常数 $c$ 的解释 $c^{\mathcal{M}} \in M$、每个函数符号 $f$ 的解释 $f^{\mathcal{M}}: M^n \to M$、每个关系符号 $R$ 的解释 $R^{\mathcal{M}} \subseteq M^n$。

例：$(\mathbb{R}, +, \cdot, -, 0, 1)$ 是环的语言 $\mathcal{L}_{ring}$ 的结构；$(\mathbb{Q}, \lt )$ 是序语言的结构；$(V, \in)$ 与 $(L, \in)$ 都是 $\mathcal{L}_\in$ 的结构。<span class="marginnote">同一个语言有成千上万个结构——这正是模型论的基本姿态：不预先钦定「标准模型」，把一切结构都视为平等候选。集合论里我们关心 $(V, \in)$ 与 $(L, \in)$ 这类特殊结构，模型论则把它们放进「全体结构」的星空里比较。</span>

**要点**：结构是「给符号分配含义」的舞台。语言是「空模板」，结构是「填好的实例」。同一个句子在不同的结构里可以有不同的真值——这正是「解释」的意义。

## 3 满足关系：语法与语义的对接

**满足关系（satisfaction）** $\mathcal{M} \vDash \varphi$：结构 $\mathcal{M}$ 满足句子 $\varphi$，递归定义（Tarski 真值定义）：

$\mathcal{M} \vDash t_1 = t_2$ 当且仅当 $t_1^{\mathcal{M}} = t_2^{\mathcal{M}}$；
$\mathcal{M} \vDash R(t_1,\dots,t_n)$ 当且仅当 $(t_1^{\mathcal{M}},\dots,t_n^{\mathcal{M}}) \in R^{\mathcal{M}}$；
- $\mathcal{M} \vDash \lnot \varphi$ 当且仅当不满足 $\varphi$；
- $\mathcal{M} \vDash \varphi \wedge \psi$ 当且仅当两者都满足；
- $\mathcal{M} \vDash \forall x\, \varphi(x)$ 当且仅当对每个 $a \in M$，$\mathcal{M} \vDash \varphi(a)$；
- $\exists$ 同理（存在一个 $a \in M$）。

带自由变元的公式需要**赋值（assignment）** $s: \text{Var} \to M$ 来补全变元；句子无自由变元，无需赋值。<span class="marginnote">Tarski 的这一定义 1933 年提出，是「形式语义学」的奠基：它把「命题为真」从哲学概念变成「关于结构的一次计算」。模型论的一切——初等类、初等等价、完全性——都建立在这条递归定义上。</span>

**辨析｜易错点：** 满足关系是**元语言**（我们谈论模型的语言）里的递归定义，不是对象语言里的公式。$\vDash$ 与 $\rightarrow$（对象语言里的蕴含）不同：前者是「结构满足句子」的元断言，后者是句子内部的一个符号。初学者常把两者混写。

## 4 公式解析：$\vDash$ 的一条完整计算

用一个具体的句子走一遍满足关系的递归。取 $\mathcal{L}_{ord} = \{\lt \}$ 的语言，看结构 $(\mathbb{Q}, \lt )$ 与句子

$$
\varphi \equiv \forall x\, \exists y\, (x \lt  y)
$$

- **最内层 $x \lt  y$**：对赋值 $s$（$s(x)=a, s(y)=b$），$(\mathbb{Q},\lt ) \vDash x<y[s]$ 当且仅当 $a \lt  b$（有理数的通常序）。
- **$\exists y\,(x<y)$**：$(\mathbb{Q},\lt ) \vDash \exists y\,(x<y)[s]$ 当且仅当存在 $b \in \mathbb{Q}$ 使 $a \lt  b$——对任意有理数 $a$ 都成立（比如 $b = a+1$）。
- **$\forall x\, \exists y\,(x<y)$**：对所有 $a \in \mathbb{Q}$ 上述都成立，故 $(\mathbb{Q},\lt ) \vDash \varphi$。

**要点**：满足关系的递归结构把「句子真」化归为「最底层的原子事实真」。用同样的三步，$(\mathbb{N},\lt )$ 也满足 $\varphi$（对每个自然数都有更大的自然数）；而 $(\{0,1\}, \lt )$ 不满足——取 $x = 1$ 时没有更大的元素。**同一个句子，不同结构，不同真值**——这就是「模型」一词的语义张力。

**辨析｜易错点：** $\forall$ 的量域是**该结构的论域**，不是「全体集合」或「全体实数」。$(\mathbb{Q},\lt ) \vDash \forall x\cdots$ 检查的是每个**有理数** $x$；若换成 $(\mathbb{N},\lt )$，检查的是每个自然数。量词的「范围」由结构决定——这是初学者最容易混淆的一点（常常不自觉地把 $\forall x$ 读成「对一切实数」）。

## 6 动手推导：把「$2 + 2 = 4$」写成一阶句子

用环的语言 $\mathcal{L}_{ring}$，把一个算术事实翻译成严格的一阶句子，感受「形式化」的强度。

- **第一步，选定语言与结构**：语言 $\mathcal{L}_{ring} = \{+, \cdot, -, 0, 1\}$，结构取自然数环 $(\mathbb{N}, +, \cdot, -, 0, 1)$（视 $-$ 为一元函数，$\cdot$ 为乘法）。
- **第二步，写项**：数字「$2$」不是常数——我们只有 $0,1$ 与运算。$2$ 的项是 $1+1$（或 $\underline 2 = 1+1$ 的缩写）。同理 $4$ 的项是 $((1+1)+(1+1))$。
- **第三步，写句子**：要表达的命题是「$(1+1)+(1+1) = ((1+1)+(1+1))$」——这是原子公式 $t_1 = t_2$，其中 $t_1 = (1+1)+(1+1)$，$t_2 = (1+1)+(1+1)$。它甚至没有量词——纯项等式。
- **第四步，验证满足**：$(\mathbb{N},+,\cdot,-,0,1) \vDash (1+1)+(1+1) = (1+1)+(1+1)$ 当且仅当「两项在结构里算出同一元素」——左边 $2+2$，右边 $4$，相等。故句子真。
- **第五步，要点**：形式化把「$2+2=4$」变成「项等式在结构里求值相等」。$2$ 与 $4$ 不是基本符号而是**缩写项**——这提醒我们「数」在形式语言里是被定义出来的对象，不是天生的记号。

**辨析｜易错点：** 「$2$」在 $\mathcal{L}_{ring}$ 里不是常数符号——它只是 $1+1$ 的缩写。初学者常把「数字」当成语言里的常数；实际上语言只有 $0,1$，其他自然数全是项。这正说明「表达式」与「对象」的区分：$1+1$ 是表达式，它在结构里的值才是对象。

### 更进一步：一阶与二阶的鸿沟

为什么模型论偏爱一阶逻辑？因为一阶逻辑有三个「好性质」：**完全性**（每个一致理论有模型）、**紧致性**（每个有限一致的整体一致）、**Löwenheim-Skolem**（模型可大可小）。这三个性质在二阶逻辑里全部失效：

- **二阶逻辑**允许量化「函数与谓词」，于是能表达「$\mathbb{N}$ 是最小归纳集」——但代价是：二阶算术的完全性不再成立，甚至「二阶逻辑的语义」本身需要集合论来定义。
- **二阶不可公理化**：自然数的二阶理论 $\mathrm{PA}_2$ 有唯一模型（标准模型），但「唯一性」的证明要用到集合论——二阶逻辑把「理论能定义什么」变成了「集合论能定义什么」。
- **一阶的代价**：一阶逻辑表达不了「有限」「可数」这类基数性质——Skolem 悖论正源于此。二阶能表达，但代价是失去紧致性。

**要点**：一阶逻辑是「可算的逻辑」——它的推理完全、模型丰富、定理可机械化检查。二阶逻辑表达力强，但「语义」跳到集合论层面，失去了「逻辑内部的自洽」。模型论选择一阶，是为了「能用模型计算真理」；而「哪些真理一阶够不到」——正是集合论（如 CH）里独立性问题的最深刻来源。

### 补充：可定义性——模型论与集合论共享的词汇

「可定义（definable）」是本篇最被低估的概念：$X \subseteq M^n$ 是 $\mathcal{M}$ 中**可定义**的，若存在公式 $\varphi(\bar x, \bar a)$（参数 $\bar a \in M$）使 $X = \{\bar b : \mathcal{M} \vDash \varphi(\bar b, \bar a)\}$。

- **在模型论里**：可定义集是「用语言能指认的子集」，它们是量词消去、型空间、几何稳定性的基本单元。
- **在集合论里**：可构造宇宙 $L$ 的每一层 $L_{\alpha+1} = \mathrm{Def}(L_\alpha)$ 正是「$L_\alpha$ 里可定义子集的全体」——$L$ 就是「反复取可定义闭包」的产物。模型论与集合论在此共用同一个「可定义」概念。
- **在代数里**：代数闭域里「代数集」= 多项式零点集 = 可定义集（由方程定义）——模型论的「可定义」与代数几何的「代数集」重合，这是模型论用于代数几何的接口。

**要点**：「可定义」是「语言能描述」的精确形式化。它是模型论（结构里能指认什么）、集合论（$L$ 里能造出什么）、代数（方程能定义什么）三者的共同底层概念——本专题两条主线在此交汇。

### 补充：语法与语义的二分——为何重要

「语言（语法）」与「结构（语义）」的二分是模型论的基本姿态，它的价值值得再强调：

- **语法是有限的**：公式是有限字符串，可机械化生成、检查——这是「可计算性」进入逻辑的入口。
- **语义是集合论的**：结构、满足关系都定义在集合论宇宙里——这使「模型论本身」成为集合论的应用。
- **完全性定理把它们缝起来**：$T \vdash \varphi$（语法可证）⟺ $T \vDash \varphi$（语义恒真）——Gödel 1929 年的定理保证「两套语言描述同一回事」。

**要点**：语法-语义二分 + 完全性，让逻辑成为「有限符号的推理」与「集合论的结构」之间的精确翻译机。这个二分会贯穿第4篇的每一个定理——紧致性、Löwenheim-Skolem、超积，都是「语法-语义互动」的具体形态。

## 10 小结

- **一阶语言**：逻辑符号（固定）+ 非逻辑符号（签名：常数/函数/关系）；ZFC 写在 $\mathcal{L}_\in$ 里。
- **结构**：论域 + 符号解释；$(V,\in)$、$(\mathbb{R},+,\cdot,-,0,1)$ 都是例子。
- **满足关系 $\vDash$**：Tarski 递归定义；句子真 = 结构里可计算；量词量域 = 结构论域。
- **句子的真值随结构而变**；$\vDash$ 是元语言断言，$\rightarrow$
