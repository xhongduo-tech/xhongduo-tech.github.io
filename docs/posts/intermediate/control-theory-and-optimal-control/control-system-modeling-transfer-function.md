## 为什么从「建模」开始

第 1 篇到第 4 篇已经沿着状态空间的线索把「系统如何被数学描述」走了一遍：微分方程、传递函数、状态方程、实现理论。<span class="marginnote">这条路线是<strong>从传递函数到状态空间</strong>，属于「分析」；而第 5 篇要做的事是反过来的<strong>「建模」</strong>：从具体的物理对象出发，把一台电机、一套热工装置、一条液压回路翻译成数学方程。分析的前提是已有方程，建模则是方程的源头。</span>

这里有个容易被忽略的事实：控制理论里的一切「判据」——能控性矩阵的秩、极点的位置、Nyquist 曲线——都建立在「模型是可信的」这个前提上。**模型不准，判据再漂亮也白搭。** 博克斯那句「所有模型都是错的」是对建模者最好的提醒：我们追求的不是「完美再现」，而是在给定精度要求下**足够有用**。本章的目标，就是学会从物理机理出发，把真实对象写成「既有用、又不失真」的数学表达。

## 1 建模的一般流程：从物理到方程

任何系统的数学模型都是「用物理定律翻译对象」的结果。通用流程分四步：

1. **确定变量**：明确输入变量 $u$（外部施加的作用）与输出变量 $y$（我们关心的被观测量）。有时还要引入中间物理量。
2. **选用定律**：机械系统用牛顿第二定律，电系统用基尔霍夫定律，流体与热系统用守恒律（质量、能量、动量守恒）。<span class="marginnote">选定律的直觉：<strong>把系统拆成可分离的「元件」</strong>，每个元件贡献一项方程（弹簧贡献 $ky$、电容贡献 $C\dot{u}$……），再把元件按拓扑连接关系组合。这种「元件 + 连接」的拆解思路，与电路里阻抗法、力学里自由体图是同一件事。</span>
3. **消去中间变量**：把步骤 2 得到的多个方程联立，消去中间量，整理成关于 $u$、$y$ 的单个（或单个方程组）微分方程。
4. **规范化**：把方程整理成首一形式，并显式写出输入项，得到标准形 $y^{(n)} + a_{n-1}y^{(n-1)} + \cdots + a_0 y = b_m u^{(m)} + \cdots + b_0 u$。

**例（RLC 电路）**。输入为电压 $u$，输出为电容电压 $y$。由基尔霍夫定律与元件方程

$$
L\,\frac{\mathrm{d}^2 y}{\mathrm{d}t^2} + R\,\frac{\mathrm{d}y}{\mathrm{d}t} + \frac{1}{C}\,y = \frac{1}{C}\,u.
$$

把 $R=2,\;L=1,\;C=\tfrac14$ 代入，得 $\ddot{y} + 2\dot{y} + 4y = 4u$。这个二阶常系数方程就完整刻画了「在电压 $u$ 作用下电容电压如何变化」。<span class="marginnote">注意这里三个元件各贡献一项：<strong>电感贡献 $L\ddot{y}$、电阻贡献 $R\dot{y}$、电容贡献 $y/C$</strong>。元件的「行为」与「连接拓扑」分离，正是建模能系统化的原因。</span>

## 2 四大物理域的建模

控制工程的对象横跨多个物理域，但数学模型结构高度统一。Ogata 第 3、4 章系统梳理了这些域，我们各举一例。

**机械平移系统**：弹簧-质量-阻尼，$m\ddot{y} + b\dot{y} + ky = u$，前面已经见过。转动系统则把 $m,b,k$ 换成转动惯量 $J$、粘性摩擦系数 $B$ 与扭转刚度 $K$：$J\ddot{\theta} + B\dot{\theta} + K\theta = T$。

**机械旋转 → 电气类比**：质量 $m$ ↔ 电感 $L$，阻尼 $b$ ↔ 电阻 $R$，弹簧 $1/k$ ↔ 电容 $C$。**力-电压类比**（或阻抗类比）让工程师能用电路仿真器去模拟机械系统——这是「不同物理背景、相同数学结构」最直接的红利。

**机电系统（直流电机）**：电枢电压 $e_a$ 为输入，转角 $\theta$ 为输出。电路方程与力学方程耦合：

$$
L_a\frac{\mathrm{d}i_a}{\mathrm{d}t} + R_a i_a + K_b\dot{\theta} = e_a, \qquad
J\ddot{\theta} + B\dot{\theta} = K_t i_a.
$$

其中 $K_t$ 是转矩常数，$K_b$ 是反电动势常数。消去 $i_a$ 可得关于 $\theta$ 的方程；在电枢电感很小时常简化为 $\frac{\ddot\theta}{\dots}$ 的一阶形式——**机电系统是「跨域耦合」建模的典型**，也是伺服电机控制的物理基础。

**液压系统**：考虑液体通过阻力 R 流入容器，输入流量 $q_i$，输出液位 $h$。由质量守恒 $A\dot{h} = q_i - q_o$ 与孔口线性化 $q_o = h/R$，得 $AR\,\dot{h} + h = R\,q_i$——又是一阶惯性环节。<span class="marginnote">液位系统与 RC 电路、热容系统的方程形式完全同构：<strong>都是 $T\dot{x} + x = K u$ 的一阶惯性环节</strong>，时间常数 $T$、增益 $K$ 各有物理来源。掌握一个域的方程，就掌握了四个域的骨架。</span>

**热系统**：加热器输入热量 $q$，房间温度 $T$ 相对环境温度 $\theta$。热容 $C$ 蓄能、热阻 $R$ 传热，得 $C\dot{T} = q - (T - \theta)/R$。同样的数学，不同的物理。

把五个域的「元件—方程」对应关系排成一张表，你会看到它们的骨架惊人地一致：

| 物理域 | 输入变量 | 输出变量 | 储能元件 | 耗能元件 | 基本方程 |
| --- | --- | --- | --- | --- | --- |
| 机械平移 | 力 $u$ | 位移 $y$ | 质量 $m$、弹簧 $k$ | 阻尼 $b$ | $m\ddot{y} + b\dot{y} + ky = u$ |
| 机械转动 | 转矩 $T$ | 转角 $\theta$ | 惯量 $J$、扭簧 $K$ | 摩擦 $B$ | $J\ddot{\theta} + B\dot{\theta} + K\theta = T$ |
| 电气（RLC） | 电压 $u$ | 电容电压 $y$ | 电感 $L$、电容 $C$ | 电阻 $R$ | $LC\ddot{y} + RC\dot{y} + y = u$ |
| 流体（液位） | 输入流量 $q_i$ | 液位 $h$ | 容器面积 $A$ | 液阻 $R$ | $AR\dot{h} + h = Rq_i$ |
| 热力 | 热流 $q$ | 温度 $T$ | 热容 $C$ | 热阻 $R$ | $C\dot{T} + T/R = q$ |

表里每一行的结构都是「二阶（或一阶）线性方程」。**这意味着：你只要会分析其中一个域，其他域的结论全部免费移植。** 这也是为什么控制理论能成为独立学科——它研究的是「一类方程」，而不是「一类机器」。<span class="marginnote">这张表也是<strong>机电一体化的翻译词典</strong>：汽车悬挂工程师与电路工程师讨论同一套理论时，各自的「质量」与「电感」可以互换角色。到了本专题后面的状态空间章节，这种统一性会被推向极致——一切线性系统都是 $\dot{x} = Ax + Bu$。</span>

## 3 从微分方程到传递函数，再看非线性系统

对线性时不变系统，取零初始条件的拉普拉斯变换，就得到传递函数 $G(s) = Y(s)/U(s)$。以 RLC 电路为例：

$$
G(s) = \frac{1/L}{s^2 + (R/L)s + 1/(LC)} = \frac{1}{s^2 + 2s + 4}.
$$

**辨析｜易错点：** 建模时最容易犯的两类错误。第一，**忽略了「小信号」前提**：很多「线性模型」其实是对非线性系统在平衡点附近的近似，变量必须理解为相对工作点的**增量**，而非绝对值。第二，**张冠李戴了输入与输出**：把扰动当输入、把设定值当输入，会得到错误的传递函数——传递函数的「分母」属于系统，「分子」属于输入通道，两者不能互换。真实世界几乎都是非线性的，线性化必须在平衡点（工作点）处做：设 $x = x_e + \delta x$，对 $f$ 做一阶泰勒展开，得到增量方程 $\delta\dot{x} = A\,\delta x + B\,\delta u$，其中 $A = \partial f/\partial x$ 是雅可比矩阵。<span class="marginnote">线性化只在<strong>平衡点附近</strong>可信：飞行器姿态控制（小角度）、电机调速（工作点附近）都满足；但大角度机动、饱和、死区则必须保留非线性。第 1 篇的《非线性系统与平衡点的线性化》专门讲过细节，这里重申它也是建模的一环。</span>

### 模型从哪来：机理建模与数据建模

方程未必总写得出。当物理机理太复杂（化学反应炉、生物系统、气候装置）时，工程师改用**系统辨识（system identification）**：给对象施加精心设计的输入信号，记录输出，再反推出与数据最吻合的模型。

- **机理建模（white-box）**：靠物理定律直接写方程，参数有物理意义，但需要深刻理解对象。
- **黑箱建模（black-box）**：只依赖输入输出数据，典型形式是传递函数拟合、状态空间辨识（如子空间法）、神经网络。参数无物理含义，但拟合能力强。
- **灰箱建模（grey-box）**：机理给出结构（几阶、哪些变量耦合），数据估出其中的系数——既保留物理骨架，又用数据修正细节。<span class="marginnote">工程实践里<strong>灰箱最多</strong>：结构来自物理直觉，系数靠实验标定。电机里测 $R_a$、$J$ 常数，飞机里做风洞实验标定气动导数，都是灰箱思路。</span>

「先机理后辨识」与「直接数据驱动」之争，是控制理论一条贯穿几十年的主线。第 12 篇我们谈现代控制前沿时，模型预测控制里的「模型」正处在这场争论的中心。

## 4 公式解析：直流电机的传递函数 $G(s) = \frac{\Theta(s)}{E_a(s)}$

以直流电机为例子，把「建模 → 传递函数」的完整链条走一遍，你会看清每个符号的来历：

$$
G(s) = \frac{\Theta(s)}{E_a(s)} = \frac{K_t}{s\big[(L_a s + R_a)(Js + B) + K_b K_t\big]}.
$$

- **第一步，两个域各自的方程**：电路方程 $L_a\frac{\mathrm{d}i_a}{\mathrm{d}t} + R_a i_a + K_b\dot{\theta} = e_a$（电气域），力学方程 $J\ddot{\theta} + B\dot{\theta} = K_t i_a$（机械域）。$K_b\dot\theta$ 项说明「转动的电机会产生反电动势」，$K_t i_a$ 说明「电流会产生转矩」——两个域由此耦合。
- **第二步，零初始条件下取拉普拉斯变换**：电路方程变为 $(L_a s + R_a)I_a(s) + K_b s\Theta(s) = E_a(s)$，力学方程变为 $(Js^2 + Bs)\Theta(s) = K_t I_a(s)$。微分变成了 $s$ 域乘法。
- **第三步，消去 $I_a(s)$**：从力学方程得 $I_a = \frac{Js^2+Bs}{K_t}\Theta$，代入电路方程，整理出 $\Theta(s)$ 与 $E_a(s)$ 的比，即上式。
- **第四步，读结构**：分母中因子 $s$ 意味着系统含一个积分环节（对电压输入，转角是「速度的积分」），$L_a s + R_a$ 与 $Js + B$ 分别来自电气与机械惯性。**每个因子的物理来源都清清楚楚**——这正是「传递函数可读」的含义。

实际中电枢电感很小，常令 $L_a \approx 0$，则 $G(s)$ 简化为一阶形式 $\frac{K}{s(Ts+1)}$，其中 $K = K_t/(R_a B + K_b K_t)$、$T = R_a J/(R_a B + K_b K_t)$——电机调速的经典一阶模型由此而来。<span class="marginnote">这个简化说明建模的<strong>「精度-复杂度」权衡</strong>：要不要保留 $L_a$，取决于时间尺度。在毫秒级电流环里 $L_a$ 不可省，在秒级位置环里可以省。工程建模永远是「为问题服务的近似」。</span>

## 5 建模质量的三个检验

方程写完了，怎么知道它「够不够用」？三个经验法则：

1. **量纲检验**：方程每一项量纲必须一致。若某两项量纲对不上，建模必有错。
2. **阶数与自由度核对**：二阶系统对应两个独立储能元件；一个 $n$ 阶微分方程对应 $n$ 个状态。状态数对不上，说明漏了或多了自由度。
3. **极端情形代入**：令某参数趋于 0 或无穷，看模型退化为是否合理。例如 $b \to 0$ 时弹簧-质量系统应退化为无阻尼振荡——若不振荡，模型有误。<span class="marginnote">极端检验非常廉价却极有效：它把「方程」与「物理直觉」焊在一起。控制理论史上不少「怪结论」，追根溯源都是建模阶段引入的误差被极端情形放大了。</span>

## 6 小结

- 建模四步：**定变量 → 选定律 → 消中间变量 → 规范化**；核心思想是「元件行为 + 连接拓扑」分离。
- 四大物理域（机械、电气、流体、热）**共享同一套数学骨架**，力-电压类比把机械系统映射到电路。
- 直流电机是**跨域耦合**的典型：电气方程与力学方程经 $K_b$、$K_t$ 耦合，消元后得传递函数。
- 传递函数 $G(s) = Y(s)/U(s)$ 在**零初始条件**下由微分方程唯一确定，分母属于系统、分子属于输入通道。
- 真实系统多为非线性，线性化在平衡点附近做一阶泰勒展开，得到雅可比矩阵 $A$；增量变量必须是相对工作点的偏差。
- 建模质量用**量纲、阶数、极端情形**三把尺子检验；「所有模型都是错的」但建模者的责任是让模型「足够有用」。

在下一节，我们把视线从「怎么写模型」转向「模型给出什么信息」：给系统一个阶跃输入，看它的响应曲线能告诉我们什么——**时域分析（阶跃响应、性能指标）**。
