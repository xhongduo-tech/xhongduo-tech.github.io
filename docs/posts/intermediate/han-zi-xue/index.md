# 汉字学（文字学：六书、汉字构形与演变、简化字与规范汉字）

汉字学（文字学）研究汉字这一自足的文字系统——其构形规律（六书与三书）、形体演变（甲骨、金文、篆、隶、楷）与规范化整理（简化字与《通用规范汉字表》），是从根本上理解汉字形、音、义关系及现行规范汉字的学科根基，也是中文、历史、书法等一切汉字应用研究的入门基石。

## 对标教材

- 裘锡圭《文字学概要》（修订本，商务印书馆）
- 唐兰《中国文字学》（上海古籍出版社）
- 国务院《通用规范汉字表》（2013 年发布）
