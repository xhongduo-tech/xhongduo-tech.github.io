## 为什么「接受更差解」反而能找到最好

局部搜索的致命弱点是**困在局部极小**：它只接受「改进」，遇到山脊就停下。**模拟退火（Simulated Annealing, SA）**借冶金学的「退火」思想：**以一定概率接受更差的解**——概率随「温度」降低而减小。高温时大胆乱跳（逃离局部极小），低温时收敛（精细搜索）。<span class="marginnote">SA 的数学骨架是统计物理：Metropolis 算法（1953）模拟粒子系统在给定温度下的平衡分布——玻尔兹曼分布 $\propto e^{-E/kT}$。Kirkpatrick 等人在 1983 年把它搬到组合优化，开创了「模拟物理过程求解优化」的元启发式时代。SA 的魅力在于它<strong>既有漂亮的统计力学理论、又极其通用</strong>——目标几乎可以是任何东西。</span>

## 1 算法：Metropolis 准则

SA 的每次迭代做一次「随机扰动 + 概率接受」：

```
给定初始解 x, 初始温度 T0, 退火计划
while 未满足终止条件:
    扰动: 从 x 的邻域随机选 y
    ΔE = f(y) − f(x)
    if ΔE ≤ 0: x = y                      # 改进必接受
    else: with prob exp(−ΔE/T): x = y     # 更差按概率接受
    降温: T ← 降温(T)
```

**Metropolis 准则**（接受概率）是核心：

$$
P(\text{接受更差解}) = e^{-\Delta E / T}
$$

- $\Delta E$ 越小（差得不多）、$T$ 越大（温度高）→ 接受概率越大。
- 温度高时几乎「随机行走」；温度趋零时退化为「只接受改进」（贪心）。<span class="marginnote">Metropolis 准则对应统计物理的玻尔兹曼因子：系统在温度 $T$ 下处于能量差 $\Delta E$ 状态的概率比是 $e^{-\Delta E/T}$。优化中把「能量」换成「目标函数值」，把「温度」当控制参数——SA 就是在模拟「逐渐冷却的系统」走向「能量最低态」。</span>

## 2 退火计划（cooling schedule）

**退火计划**决定温度如何下降，是 SA 唯一关键的「旋钮」：

- **几何降温**：$T_{k+1} = \alpha T_k$（$\alpha \in [0.8, 0.99]$）——最常见、简单有效。
- **线性降温**：$T_k = T_0 - \beta k$——简单但需要设置终点。
- **对数降温**：$T_k = T_0/\log(k+1)$——理论上保证收敛，但慢得无法实用。
- **自适应降温**：根据接受率调节（接受率低则降温慢）。<span class="marginnote">退火计划的哲学：<strong>前期要「热」得够久，让系统充分探索；后期要「冷」得够慢，让系统精细收敛</strong>。降温太快会「淬火」——卡在坏的局部极小；降温太慢浪费计算。理论最优的对数降温太慢，工程上几何降温 $\alpha \approx 0.9$ + 每温度若干次迭代是「够用就好」的主流。<strong>初始温度 $T_0$ 要设到「接受率约 0.8」</strong>——太高纯随机、太低提前贪心。</span>

## 3 收敛性：理论完美，实践打折

SA 有「理论上几乎必然收敛到全局最优」的结论：

**定理（Hajek 1988）**：在可逆 Markov 链、连通邻域、以及退火计划满足「降温慢于某临界速率」的条件下，SA 几乎必然收敛到全局最优。临界速率与「局部极小的深度」有关——**要保证收敛，退火必须慢到「能爬出任何局部极小」的程度**。<span class="marginnote">这个收敛定理既是 SA 的荣耀也是它的「空头支票」：它要求对数级慢降温（$T \sim 1/\log k$），意味着「需要无限长时间」。实践中没人这么跑——几何降温在有限预算内「尽力而为」。<strong>SA 的收敛性结论的价值不在实用，而在「给出了逃离局部极小的原理」</strong>——接受更差解的概率结构是经过统计力学论证的。</span>实用结论：**SA 不保证最优，但在「目标黑盒、无梯度、离散大邻域」的场景里是最稳健的通用选择之一。**

## 4 公式解析：Metropolis 接受概率的推导

把 $e^{-\Delta E/T}$ 的来历看清楚——它来自玻尔兹曼分布的比：

- **第一步，平衡分布**：统计物理中，系统在能量 $E$ 的平衡概率 $\propto e^{-E/(kT)}$（玻尔兹曼分布，$k$ 玻尔兹曼常数，$T$ 温度）。
- **第二步，转移的细致平衡**：希望 Markov 链收敛到玻尔兹曼分布，需满足**细致平衡（detailed balance）**：$P(x)P(x\to y) = P(y)P(y\to x)$。
- **第三步，解出接受概率**：设「提议」对称（$q(x\to y) = q(y\to x)$），接受概率 $A(x\to y)$ 需满足 $e^{-E_x/T}A(x\to y) = e^{-E_y/T}A(y\to x)$。取 $A(x\to y) = \min\{1, e^{-(E_y - E_x)/T}\}$——**恰是 Metropolis 准则**。
- **第四步，优化翻译**：把 $E$ 换成目标 $f$，$T$ 当控制参数，得到 SA 的接受规则。

**要点：Metropolis 准则不是拍脑袋，而是「让采样过程遵循玻尔兹曼分布」的必然选择**——它保证了在固定温度下，SA 的长期行为是「在可行解空间按 $e^{-f/T}$ 采样」，温度降低时质量高的解被采样得更密。

## 5 SA 速查与应用

| 维度 | 内容 |
| --- | --- |
| 接受准则 | $e^{-\Delta E/T}$（Metropolis） |
| 降温 | 几何 $\alpha T$ 最常用 |
| 邻域 | 问题相关的扰动算子 |
| 收敛 | 理论上几乎必然（对数降温）；实践尽力而为 |
| 适用 | 黑盒目标、无梯度、离散/连续均可 |

**辨析｜易错点：**其一，**降温太快 = 淬火**——卡在局部极小，白跑；其二，初始温度与「每温度迭代次数」要配对——太热浪费时间、太冷没用；其三，邻域算子的设计比退火计划更重要——扰动「太大会退化成随机搜索」「太小爬不出局部极小」；其四，终止条件别只看温度——加「连续 N 次无改进即停」防浪费。<span class="marginnote">在「从极限到大模型」里，SA 常作为<strong>超参数调优的简单基线</strong>（对黑盒目标函数）、神经网络结构搜索的早期方法、以及「精确算法给不出解」时的最后手段。它的思想——「用温度控制的随机性逃离局部极小」——也被用在很多更现代的方法里（如学习率退火、模拟退火式贝叶斯优化）。</span>

## 6 小结

- **SA**：随机扰动 + Metropolis 接受 + 降温——以退为进逃局部极小。
- **Metropolis 准则**：$e^{-\Delta E/T}$，来自玻尔兹曼分布与细致平衡。
- **退火计划**：几何降温最常用；初始温度与降温速率决定成败。
- **收敛**：理论上对数降温可保证全局；实践中有限预算尽力而为。
- **定位**：黑盒、无梯度、通用性最强的元启发式之一。
