## 为什么加权和是「第一直觉」

多目标问题最朴素的处理：**给每个目标一个权重 $w_i$，最小化加权和 $\sum w_i f_i(x)$**。它把多目标变成一个普通单目标——之前学的一切算法立即可用。对凸问题，这套方法甚至「完备」：**每一个 Pareto 最优解都可以用某个权重组合扫出来**。<span class="marginnote">加权和法的历史可追溯到 Zadeh（1963）与 Geoffrion，它是「标量化（scalarization）」最简单的一族。它的优点（简单、凸时完备）与局限（非凸时漏解、权重难解释）同样鲜明——理解这两面，是掌握多目标优化的分水岭。本节先讲「何时完美」，再讲「何时翻车」。</span>

本节标题里的「及其局限」不是附带的补充，而是全文的题眼：**一个「简单好用」的工具，其局限往往就在它「简单」的来源里**——加权和用「线性组合」聚合目标，线性只对凸结构完备，这是它无法逃避的天花板。所以本节的阅读方式是：先把「凸时为什么完备」的几何想透，再记住「非凸时凹部漏解」的反例，最后把「何时该用、何时该换」的判断标准刻进习惯里。

在「从极限到大模型」的知识地图里，本节接续上一节的 Pareto 概念，是**第九篇多目标优化**的第一个「实战工具」：上一节告诉你「权衡曲线长什么样」，本节告诉你「最简单的扫描工具怎么用、什么时候失灵」。读懂本节的「凸时完备、非凸翻车」，你就能理解为什么后文还要发明 ε-约束法、目标规划、以及进化多目标算法——每一个都是来补加权和的洞的。

**先记住一个「一句话画像」**：加权和法就是「在目标空间里，用一族方向固定的平行线去触碰前沿」。方向由权重 $w$ 决定，触碰点就是优化解。这个几何画面几乎解释了本节的所有结论——凸前沿处处能被平行线支撑（完备），凹前沿的凹陷处是「躲」在两条支撑线之间的（漏解），权重变化时触碰点沿前沿滑动（扫描）。带着这个画面读下文，每个定理都变得可以「看见」。

## 1 加权和法的形式

对多目标 $\min (f_1(x), \ldots, f_k(x))$，取权重 $w \ge 0$（$w \ne 0$），解

$$
\min_x\ \sum_{i=1}^{k} w_i f_i(x) \quad \mathrm{s.t.}\quad x \in \mathcal{F}
$$

权重向量 $w$ 是**决策者的偏好**：$w_i$ 越大，越在意目标 $i$。**扫描 $w$ 就得到一列 Pareto 最优解**——它们勾画有效前沿。<span class="marginnote">权重归一化（$\sum w_i = 1$）是常见约定，因为乘常数不改变最优解。但<strong>权重 ≠ 目标的重要性</strong>：目标量纲不同（元 vs 秒 vs 百分比），同样的 $w_i$ 效果天差地别。工程上要先对目标<strong>归一化</strong>（如除以各自的范围），否则权重会被量纲「绑架」。</span>

## 2 凸情形：完备性定理

**标量化定理（scalarization theorem）**：设原问题是凸的（目标凸、可行域凸）。则

$$
x^* \text{ 是 Pareto 最优} \iff \exists\ w > 0 \ \text{使 } x^* \in \arg\min \sum w_i f_i
$$

- **充分性（加权和 ⇒ Pareto）**：若 $x^*$ 最小化 $\sum w_if_i$ 且 $w > 0$，则任何支配 $x^*$ 的解都会使加权和更小——矛盾。所以加权和的最优解必 Pareto 最优。
- **必要性（Pareto ⇒ 存在权重）**：凸性保证目标空间的「帕累托集」是凸的；对 Pareto 点用**分离超平面定理**（第一篇）找一个支撑超平面，其法向量就是权重 $w$。<span class="marginnote">必要性的证明正是分离定理的又一应用：Pareto 点与「更优区域」被一个支撑超平面分开，超平面法向量给出一组权重。这就是为什么凸性是「完备性」的关键——分离定理在凸集上成立。<strong>凸 ⇒ 每个 Pareto 点都能被某组权重「命中」</strong>，扫描权重即可覆盖整个前沿。</span>

**实践含义**：凸多目标问题，用「权重扫描」（从 $w=(1,0)$ 到 $w=(0,1)$ 均匀取点）就能得到有效前沿的完整采样。

**一个二维数值算例**。两目标都最小化，可行域给出一段凸的 Pareto 前沿，形如 $f_2 = -f_1 + 10$（$f_1 \in [0,5]$ 的一段）。扫描权重 $w = (\lambda, 1-\lambda)$，$\lambda$ 从 0 到 1：

- $\lambda = 0$：$\min f_2$，得 $f = (5, 5)$（前沿一端）。
- $\lambda = 0.5$：$\min 0.5f_1 + 0.5f_2$，得 $f = (2.5, 7.5)$（中点）。
- $\lambda = 1$：$\min f_1$，得 $f = (0, 10)$（另一端）。

可见权重从 0 到 1 均匀扫过时，解在目标空间沿着那条凸直线从左端滑到右端——**前沿被完整采样**。这个「$\lambda$ 从 0 扫到 1，解沿前沿滑动」的画面，就是加权和法在凸情形下的全部魅力：一个标量参数，控制一条完整的权衡曲线。

## 3 非凸情形：凹陷漏解

凸性是加权和完备性的**必要条件**——非凸问题时，定理失效。关键现象：**前沿的「凹部」（非支撑解）无法被任何权重组合找到**。<span class="marginnote">几何解释：加权和等价于「找目标空间里、方向为 $w$ 的最低等高线支撑」——它只能「摸到」目标集凸包边界上的点。前沿若在目标空间「凹」进去，那些凹点不在凸包边界上，任何 $w$ 都切不到它。<strong>加权和能扫出的是有效前沿的「凸包边界」子集</strong>。</span>**例子**：两个目标的可行域非凸，Pareto 前沿是「凹曲线」——权重扫描只会覆盖曲线的两端，中间的凹陷点全部漏掉，且**不同权重可能给出同一个端点解**（权重区间「扎堆」）。<span class="marginnote">非凸时还有一个更糟的副作用：权重稍微变化，解可能在「两个极端」间跳变——前沿不是被「均匀扫描」，而是被「点射」。这让「用权重当偏好旋钮」变得不可靠。ε-约束法（下一节）正是为补这个洞而设计的。</span>

**把「漏掉凹部」落到具体的数**。设 Pareto 前沿是一段「凹」折线：端点 $A=(0,10)$、中间凹点 $B=(4,4)$、端点 $C=(10,0)$。加权和要「摸到」$B$，需要方向 $w$ 使 $B$ 是 $\min w_1f_1+w_2f_2$ 的最优——即 $B$ 在某族等高线 $w_1f_1+w_2f_2 = c$ 上支撑目标集。但凹点 $B$ 落在 $A$、$C$ 连线的**凸包内部**（凹进去了），任何线性等高线都会先碰到 $A$ 或 $C$——$B$ 永远被跳过。于是权重从 0 扫到 1，解只在 $A$ 与 $C$ 之间跳，$B$ 这个「其实很均衡的好解」彻底丢失。<span class="marginnote">这个反例的教训是结构性的：<strong>加权和「看不见凹进去的好解」</strong>——而现实里很多「均衡方案」恰恰位于凹部（牺牲一点这个、换回很多那个的「划算区」）。要抓住这些解，必须换一种「直接约束某个目标」的扫描方式，这正是 ε-约束法的思路。</span>

## 4 公式解析：分离定理如何给出权重

把「Pareto ⇒ 存在权重」的证明核心拆开。设 $x^*$ 是 Pareto 最优，$F^* = f(x^*)$ 是它的目标向量，定义「更优锥」

$$
\mathcal{W} = F^* - \mathbb{R}^k_{++} = \{ y : y_i < F^*_i,\ \forall i \}
$$

- **第一步，更优锥与目标集分离**：若 $x^*$ 是 Pareto 最优，则目标集 $f(\mathcal{F})$ 与更优锥 $\mathcal{W}$ 不相交（否则存在严格更好的点，支配 $x^*$）。
- **第二步，凸性 + 分离**：$f(\mathcal{F})$ 凸（原问题凸 ⇒ 目标像凸）、$\mathcal{W}$ 是开凸锥；两者不相交 ⇒ 存在超平面分离：有 $w \ne 0$ 使 $w^Ty \ge w^TF^*$ 对所有 $y \in f(\mathcal{F})$，且 $w \ge 0$（法向指向更优锥内侧）。
- **第三步，转成最优性**：$w^Tf(x) \ge w^Tf(x^*)$ 对所有可行 $x$ ⇒ $x^*$ 最小化 $w^Tf$——**权重 $w$ 就是分离超平面的法向量**。
- **第四步，非凸为何失败**：$f(\mathcal{F})$ 不凸时，分离定理不适用——Pareto 点可能在凸包内部，没有支撑超平面。

**要点：加权和的完备性 = 分离定理的完备性**——凸集处处有支撑面，非凸集的凹陷处没有。

## 5 加权和法的工程守则

| 场景 | 做法 |
| --- | --- |
| 凸问题 | 权重均匀扫描可得完整前沿 |
| 非凸问题 | 加权和会漏凹部——用 ε-约束法或 NSGA-II 等启发式 |
| 量纲差异 | 先归一化目标（除以范围）再加权 |
| 权重含义 | 别把权重当「重要性」，它只决定「扫描方向」 |
| 少量解 | 只需几个代表解时，加权和够用 |

**术语速查：**

| 术语 | 含义 | 一句话记忆 |
| --- | --- | --- |
| 标量化 scalarization | 把多目标转成单目标 | 压成一个数 |
| 加权和 | $\min \sum w_i f_i$ | 权重加权 |
| 权重向量 $w$ | 决定前沿扫描方向 | 偏好旋钮 |
| 完备性 | 凸时每个 Pareto 点都能被命中 | 全覆盖 |
| 支撑解 | 加权和扫得到的点 | 凸包边界 |
| 非支撑解 | 加权和扫不到的凹点 | 凹坑里的宝藏 |
| 量纲绑架 | 大数量纲目标主导优化 | 归一化 |
| 归一化 | 目标除以各自范围 | 公平秤 |

**辨析｜易错点：**其一，**归一化不是可选项**——量纲不同的目标直接加权，权重会被大数量纲的目标绑架；其二，「权重 = 重要性」是常见误解——$w$ 决定前沿扫描方向，不是「这个目标重要几倍」；其三，非凸时「权重连续扫描」可能**重复命中同一解**且漏掉凹部——看到「解不随权重变化」要警觉；其四，目标数量多时权重空间维数高，「均匀扫描」成本爆炸；其五，**别在「权重小变化、解大跳变」时硬调权重**——那往往意味着问题非凸、加权和的结构性局限，该换方法而不是换权重。<span class="marginnote">在「从极限到大模型」里，加权和是<strong>多任务学习（MTL）</strong>的默认做法（损失加权求和），也因此继承它的全部局限：任务损失量纲差异需归一化、非凸时难均衡、权重对性能敏感。理解加权和的几何，就理解了为什么 MTL 需要「梯度平衡」「不确定度加权」等更精细的调度——它们都在补加权和的洞。</span>

**在多任务学习（MTL）里的具体表现**。假设同时训练「翻译 + 摘要」两个任务，总损失 $L = w_1 L_{trans} + w_2 L_{sum}$。若翻译损失的量级是摘要的 100 倍，即便 $w_2$ 很大，优化也被翻译主导——这是「量纲绑架」的真实版。更麻烦的是：两个任务的梯度可能**方向相反**（优化一个会伤害另一个），此时「$w$ 平权求和」在梯度空间里等价于「往一个尴尬的折中方向走」——这就是为什么业界出现 GradNorm（按梯度范数自动调权）、不确定度加权（按同方差性调权）等方案。**它们的共同目标都是「让每个任务在加权和里获得公平的话语权」**——本质仍是「补加权和量纲与方向上的洞」。

## 6 小结

- **加权和法**：$\min \sum w_if_i$，权重扫描勾画前沿。
- **凸完备性**：凸问题下每个 Pareto 点都对应某权重——分离定理保证。
- **非凸失效**：前沿凹部（非支撑解）任何权重都扫不到；权重可能「扎堆」。
- **归一化**：先按量纲归一，否则权重被绑架。
- **定位**：简单、凸时强大；非凸时需 ε-约束或进化算法补位。
- **数值直觉**：$\lambda$ 从 0 扫到 1，解沿凸前沿平滑滑动；非凸时则可能在端点间跳变、漏掉凹部。
- **MTL 警示**：多任务学习继承加权和的全部局限——量纲差异、梯度方向冲突、权重敏感；GradNorm/不确定度加权都在补这些洞。
- **与主线相连**：加权和 = 多目标里「最简单、最常用、也最先失效」的工具——理解它的几何（支撑超平面法向量），就理解了为什么凸性是完备性的关键。
- **一句话复盘**：加权和用「线性等高线」去摸前沿——凸前沿处处有支撑线所以全覆盖，凹前沿的凹陷处没有支撑线所以漏解；这正是「凸性决定完备性」的直观画面。
- **动手建议**：拿一对冲突目标（如「时间 vs 成本」）手画一个凹前沿，标出三个点 A/B/C，验证「B 在凸包内、任何权重都扫不到它」。
- **适用判断**：先问「我的问题凸吗、需要完整前沿吗、权重好解释吗」——三个都答「是」再用加权和；否则早做打算换 ε-约束或进化算法。
