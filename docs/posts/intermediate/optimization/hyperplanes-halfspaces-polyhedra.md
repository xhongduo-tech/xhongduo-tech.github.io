## 为什么从「平直」开始

上一篇的最后一幕留下了一个悬念：凸包给集合一副「由顶点生成」的面孔，而优化里最常见的集合其实长着另一副面孔——「由不等式定义」。线性规划的全部约束都是「一条线性不等式」，而**每一条线性不等式切出来的，正是半空间；若干条切在一起的交集，正是多面体**。可以说，多面体是优化里最常出现的凸集，没有之一。

本节把超平面、半空间与多面体这三块「平直砖」逐一打磨：超平面是「一条等式切出的最平集合」，半空间是「一条不等式切出的一侧」，多面体是「有限个半空间（与超平面）的交集」。我们还要回答上一篇留下的问题：单纯形为什么既能由顶点凸包生成，又能由不等式交集定义？答案是——**同一个多面体有两副面孔（H 表示与 V 表示）**，而线性规划的全部几何直观都建筑在这两副面孔之上。

## 1 超平面：一条等式，一整片「平直」

**超平面（hyperplane）**：取 $a \in \mathbb{R}^n$，$a \neq 0$，$b \in \mathbb{R}$，集合

$$
\{x \mid a^T x = b\}
$$

称为一个超平面。<span class="marginnote">$a$ 是法向量，$b$ 决定超平面离原点的远近。$\mathbb{R}^2$ 里超平面就是直线，$\mathbb{R}^3$ 里是平面，$\mathbb{R}^n$ 里是 $n-1$ 维的「平直切片」——「超」字正是指它比整个空间低一维。</span>

超平面有一个重要的度量解释：对任意 $x$，**有符号距离** $(a^T x - b)/\|a\|_2$ 衡量「$x$ 到超平面带符号的垂直距离」——在法向量指向的一侧为正，另一侧为负，恰好在超平面上为 0。所以 $a^T x = b$ 这句话在几何上的意思是：**$x$ 在法向量 $a$ 方向上的投影，恰好是 $b/\|a\|_2$**。这个「有符号距离」的视角，是下一节分离超平面定理的核心语言。

超平面也可以是「仿射参数化」的：任取其上一点 $x_0$，超平面等于 $x_0$ 加上法向量的正交补

$$
\{x \mid a^T x = b\} = \{x_0 + v \mid a^T v = 0\} = x_0 + a^\perp
$$

其中 $a^\perp$ 是 $a$ 的正交补空间。这与上一篇「仿射集 = 线性子空间 + 平移」完全一致：超平面是 $n-1$ 维的仿射集，其平移方向的自由度正是 $a^\perp$——这是第二级《线性代数》里「齐次方程的解空间 + 特解」的几何翻版。

## 2 半空间：不等式切出「一侧」

**半空间（halfspace）**：集合

$$
\{x \mid a^T x \le b\}
$$

称为（闭）半空间。它的边界恰好是超平面 $\{x \mid a^T x = b\}$；在几何上，半空间就是「法向量 $a$ 指向的那一侧」全部点。用有符号距离的语言：半空间要求 $x$ 到超平面的有符号距离不超过 $b/\|a\|_2$。

把不等号换成严格不等号，$\{x \mid a^T x < b\}$ 仍是凸集，但它既不闭也不开<span class="marginnote">它不开：边界点 $a^T x = b$ 不在集合里，但任意邻域都被集合内的点穿透；它不闭：集合内的点列可以收敛到边界上的点。严格半空间在优化里要单独小心，因为「最小值点」可能恰好站在边界上。</span>。一个半空间被它的边界超平面「一分为二」：边界一侧是 $a^T x \le b$，另一侧是 $a^T x \ge b$。把两个互补半空间交起来，恰好还原出边界超平面：

$$
\{x \mid a^T x \le b\} \cap \{x \mid a^T x \ge b\} = \{x \mid a^T x = b\}
$$

这句话在后面的对偶理论里会反复出现：**一个超平面，可以看成两个半空间「夹」出来的**；反之，任何「≤」约束与「≥」约束同时存在，就等价于一条「=」约束。

**辨析｜易错点：半空间不是仿射集。** 半空间只含超平面的一侧，不含整条直线——任取两侧各一点，连线段的中段会穿过边界留在集合内，但把线段「反向延长」就立刻穿出集合。仿射集要求整条直线留在集合内，半空间做不到。所以半空间是凸集、非仿射集，它与超平面在「凸 vs 仿射」的谱系上分属两端。

## 3 多面体：有限个半空间（与超平面）的交集

**多面体（polyhedron）**：有限个半空间与超平面的交集：

$$
\mathcal{P} = \{x \mid a_i^T x \le b_i,\ i = 1, \ldots, m;\ \ c_j^T x = d_j,\ j = 1, \ldots, p\}
$$

写成矩阵形式就是

$$
\mathcal{P} = \{x \mid Ax \preceq b,\ Cx = d\}
$$

因为半空间与超平面都是凸集，而凸集的交集保持凸（上一篇第 6 节），**多面体一定是凸集**。多面体是线性规划（LP）的可行域，是第四篇《线性规划》的全部主角。

几个立刻能认出的多面体例子：

- **盒子（box）**：$\{x \mid l \preceq x \preceq u\}$，即各坐标被夹在上下界之间。
- **标准单纯形**：$\Delta = \{x \succeq 0,\ \mathbf{1}^T x = 1\}$——它是第 4 节公式解析的主角。
- **$\ell_1$ 球**：$\{x \mid \|x\|_1 \le 1\}$ 在二维是菱形、在三维是八面体，都是多面体（$\ell_p$ 球中只有 $p=1$ 与 $p=\infty$ 是多面体，其余是光滑凸集）。
- **单位立方体**：$[0,1]^n$，由 $2n$ 个半空间切出。

**有界的多面体称为多胞形（polytope）**。多胞形是「多面体 + 有限」的交集：它不会沿任何方向无限延伸。线性规划的可行域若是多胞形，则最优解必然「有界可得」——这是第四篇会反复用到的假设。

**辨析｜易错点：多面体的边界不是超平面，而是「片」。** 多面体的边界由若干「面（facet）」拼成，每一片是某个半空间的边界超平面的一个子集。二维多面体是多边形，边是线段；三维多面体是立体，面是平面多边形。「多面」这个词本身就说清楚了：它是很多个平面拼出来的。

## 4 公式解析：标准单纯形——同一集合的两副面孔

上一节说「多面体 = 有限个半空间的交集」，上一上一节说「凸包 = 由顶点生成」。同一个集合，能否同时拥有这两副面孔？答案是最漂亮的例子：标准单纯形。

**标准单纯形**：$n+1$ 维空间里的集合

$$
\Delta = \{x \in \mathbb{R}^{n+1} \mid x \succeq 0,\ \mathbf{1}^T x = 1\}
$$

其中 $\mathbf{1}$ 是全 1 向量。我们来证明它同时等于 $n+1$ 个标准基向量的凸包：

$$
\Delta = \operatorname{conv}\{e_1, \ldots, e_{n+1}\}
$$

拆成三步：

- **第一步，H 面孔：$\Delta$ 是多面体**。条件 $x \succeq 0$ 是 $n+1$ 条半空间（$x_i \ge 0$，即 $-e_i^T x \le 0$），条件 $\mathbf{1}^T x = 1$ 是一条超平面。有限个半空间与一条超平面的交集，按定义是多面体。
- **第二步，包含方向一（$\supseteq$）**：每个基向量 $e_i$ 显然满足 $e_i \succeq 0$ 且 $\mathbf{1}^T e_i = 1$，所以 $e_i \in \Delta$；而 $\Delta$ 是凸集，故 $\operatorname{conv}\{e_i\} \subseteq \Delta$。
- **第三步，包含方向二（$\subseteq$）**：任取 $x \in \Delta$，把 $x$ 按坐标展开 $x = \sum_{i=1}^{n+1} x_i e_i$。因为 $x_i \ge 0$ 且 $\sum_i x_i = 1$，这**本身就是** $\{e_i\}$ 的一个凸组合！所以 $x \in \operatorname{conv}\{e_i\}$，故 $\Delta \subseteq \operatorname{conv}\{e_i\}$。

两边一夹，$\Delta = \operatorname{conv}\{e_1, \ldots, e_{n+1}\}$。$\blacksquare$

**第三步是整个证明的华彩**：它不是「费力构造」一个凸组合，而是**发现 $x$ 的坐标分解本来就是凸组合**——因为 $\Delta$ 的定义恰好把坐标约束成「非负且和为一」。H 面孔给集合「用不等式切」，V 面孔给集合「用顶点撑」，二者在标准单纯形上严丝合缝地重合。这个「坐标分解 = 凸组合」的观察，是理解接下来极点与基本可行解的关键。

## 5 顶点、极点与多面体的 V 表示

凸包给多面体一副面孔后，我们自然要问：多面体的顶点长什么样？先给一个概念。

**极点（extreme point）**：$x \in \mathcal{P}$ 称为 $\mathcal{P}$ 的极点，若它不能写成 $\mathcal{P}$ 中两个不同点的凸组合，即

$$
x = \theta y + (1-\theta) z,\quad y,z \in \mathcal{P},\ y \neq z,\ \theta \in (0,1)
$$

不可能成立。直观上，极点是「凹不下去的角落」：它不位于任何连接 $\mathcal{P}$ 中两点的线段内部。多面体的极点就是通常说的**顶点**。

多面体的两副面孔在此合体为一条深刻的定理。

**Minkowski–Weyl 定理**：一个有界多面体（多胞形）恰好等于它的顶点的凸包：

$$
\mathcal{P} = \operatorname{conv}\{\text{$\mathcal{P}$ 的全部顶点}\}
$$

（无界多面体还要加上「极方向（extreme ray）」的锥组合，形式是「多胞形 + 凸锥」的 Minkowski 和。）这条定理把两个方向都讲透了：由有限个不等式切出的多面体，也可以由有限个顶点撑出；反过来，任何有限点集的凸包都是有界多面体。<span class="marginnote">对标准单纯形 $\Delta$，它的顶点恰是 $\{e_1, \ldots, e_{n+1}\}$——验证：$\Delta$ 中任意点 $x$ 都写成 $x = \sum x_i e_i$，若 $x$ 有两个坐标非零，它就在「连接两个边界点」的线段内部，故不是极点；只有坐标形如 $e_i$ 时才是极点。</span>

**辨析｜易错点：极点 ≠ 边界点。** 边界上除顶点外的点（比如正方形的边中点）也是边界点，但它不是极点——它落在连接两个顶点的线段内部。极点比边界点更「尖」：**极点是「唯一的极小元素」，边界点是「任何边缘」**。这个区别在第四篇《线性规划》里会转化为「基本可行解」与「边界可行解」的区别：单纯形法的每一步，都从顶点跳到顶点，从不光顾普通的边界点。

## 6 小结

- **超平面**：$\{x \mid a^T x = b\}$，法向量 $a$，有符号距离 $(a^T x - b)/\|a\|_2$；$n-1$ 维仿射集。
- **半空间**：$\{x \mid a^T x \le b\}$，边界是超平面；凸但非仿射；严格半空间既不闭也不开。
- **多面体**：有限个半空间与超平面的交集，$\{x \mid Ax \preceq b,\ Cx = d\}$；有界多面体称为多胞形。
- **标准单纯形**：$\Delta = \{x \succeq 0,\ \mathbf{1}^T x = 1\} = \operatorname{conv}\{e_1, \ldots, e_{n+1}\}$——坐标分解天然就是凸组合。
- **极点 / 顶点**：不能写成两点凸组合的点；Minkowski–Weyl 定理说多胞形 = 顶点的凸包。

在下一节，我们要回答一个更「工程化」的问题：手里有一堆已经认识是凸的集合，怎么放心地「拼」出新的凸集？——这就是**保凸运算**：交集、仿射变换、透视函数与线性分式函数。多面体之所以是凸的，靠的是交集保凸；而下一节我们会看到，仿射变换还能把球变成椭球、把平面切成超平面——「砖拼砂浆」，才能盖出整个可行域。
