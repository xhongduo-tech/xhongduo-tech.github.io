## 为什么 CG 需要「非线性版」

线性共轭梯度依赖两个前提：目标必须是二次函数、步长必须精确线搜索。真实问题（神经网络、物理反演）目标一般非二次，步长也不能精确求——于是**非线性共轭梯度（nonlinear CG）**登场：把 CG 的「方向组合」公式保留，步长改用 Wolfe 线搜索，目标换成任意可微函数。它只需要一阶信息 + $O(n)$ 内存，却在很多问题上逼近牛顿类方法的收敛速度——是「便宜而强大」的典型。<span class="marginnote">关键区别在 $\beta$ 的选择：线性 CG 的 $\beta_k$ 由「精确 A-正交」唯一确定；非线性下没有固定的 $A$，$\beta_k$ 有多种配方，FR 与 PRP 是两大流派。它们各有各的收敛性定理与「脾气」，本节把两种配方掰开揉碎。</span>

## 1 非线性共轭梯度的骨架

非线性 CG 的迭代结构与梯度下降几乎一样，只是方向不再单纯是负梯度：

```
给定 x0，方向 d0 = -∇f(x0)
k = 0
while 未收敛:
    步长: t_k 由 Wolfe 线搜索确定（沿 d_k）
    更新: x_{k+1} = x_k + t_k d_k
    梯度: g_{k+1} = ∇f(x_{k+1})
    系数: β_k 由公式确定（FR 或 PRP 等）
    方向: d_{k+1} = -g_{k+1} + β_k d_k
```

方向由「新梯度」与「旧方向」线性组合——$\beta_k$ 控制「保留多少旧方向的记忆」。<span class="marginnote">$d_{k+1} = -g_{k+1} + \beta_k d_k$ 的直觉：先朝新梯度的反方向（新鲜的下山信息），再借一点旧方向（保持前进步伐的惯性）。$\beta_k = 0$ 时退化为梯度下降；$\beta_k$ 大时方向更「惯性」。</span>**步长必须满足 Wolfe 条件**——这不仅保证下降，还给收敛性证明提供 `Zoutendijk` 级基础。

## 2 FR 公式：简单而严格

**Fletcher–Reeves（FR）公式**直接照搬线性 CG 的 $\beta$：

$$
\beta_k^{FR} = \frac{\|g_{k+1}\|_2^2}{\|g_k\|_2^2}
$$

性质：

- 对二次函数 + 精确线搜索，FR 恰好还原线性 CG（$\beta^{FR} = r_{k+1}^Tr_{k+1}/(r_k^Tr_k)$）。
- **收敛性定理（FR）**：在标准假设下（$f$ 下有界、梯度 Lipschitz、强 Wolfe 线搜索），FR **全局收敛**——只要步长满足强 Wolfe 且 $\beta^{FR}$ 用「$\max\{\beta, 0\}$」截断。<span class="marginnote">FR 的收敛性证明很经典：它保证 $\sum \cos^2\theta_k$ 发散（方向不过分偏离负梯度），配 Zoutendijk 定理即得收敛。但 FR 有个「坏脾气」：如果某步没走好、梯度几乎没变，$\beta^{FR} \approx 1$，方向会「卡」在旧方向里——实践上可能慢。</span>
- **弱点**：对非二次目标，FR 可能产生「jamming」——方向退化，连续几步方向几乎相同，收敛变慢。

## 3 PRP 公式：更聪明也更好用

**Polak–Ribière–Polyak（PRP）公式**用梯度的**变化量**代替范数比：

$$
\beta_k^{PRP} = \frac{g_{k+1}^T (g_{k+1} - g_k)}{\|g_k\|_2^2}
$$

**直觉**：分子是「新梯度沿自身方向的投影差」，衡量「这一步梯度变了多少」。若梯度没怎么变（$g_{k+1} \approx g_k$），$\beta^{PRP} \approx 0$——**自动重启为梯度下降**；这正是修复 FR「jamming」的关键。<span class="marginnote">PRP 的「自适应重启」是它的杀手锏：当方向不奏效时，分子 $g_{k+1}^T(g_{k+1}-g_k)$ 变小，$\beta$ 变小，方向退回负梯度——等于自动「忘了旧记忆」。数值实验普遍显示 PRP 比 FR 稳且快，是非线性 CG 的默认选择。</span>

但 PRP 的**收敛性**比 FR 微妙：原始 PRP 在强 Wolfe 下可能不全局收敛，需配合截断：

$$
\beta_k = \max\{\beta_k^{PRP},\ 0\}
$$

截断后（**PRP+**），可以证明全局收敛——兼得 PRP 的实践优势与 FR 的收敛保证。

## 4 公式解析：FR 与 PRP 的差别在哪

把两个公式并排看，找出「差的那一项」。对二次函数 + 精确线搜索，$g_{k+1}$ 与 $g_k$ 正交，于是

$$
\beta^{PRP} = \frac{g_{k+1}^Tg_{k+1} - g_{k+1}^Tg_k}{\|g_k\|^2} = \frac{\|g_{k+1}\|^2}{\|g_k\|^2} = \beta^{FR}
$$

- **第一步，在精确情形下两者相等**：对二次 + 精确线搜索，$g_{k+1}^Tg_k = 0$（残差正交性），PRP 恰好退化为 FR——**这不是巧合**，说明 PRP 是 FR 的「推广」。
- **第二步，非精确情形分裂**：若线搜索不精确或函数非二次，$g_{k+1}^Tg_k \ne 0$，两个公式分道扬镳。FR 只看范数比（忽略方向信息），PRP 用「梯度变化」感知局部景观。
- **第三步，PRP 的自适应语义**：$g_{k+1}^T(g_{k+1} - g_k)$ 大 = 这一步梯度方向剧变 = 旧方向还有价值（保留）；小 = 梯度平稳 = 旧方向该被遗忘（重启）。**PRP 把「记忆该保留多久」交给数据本身**。
- **第四步，重启策略**：工程上还会**周期性重启**（每 $n$ 步强制 $\beta = 0$）——清除累积的「记忆污染」，让非线性 CG 重获「干净梯度」的保证。

**一句话：PRP 是 FR 的非精确推广，多出来的项 $g_{k+1}^Tg_k$ 提供了「何时该忘」的开关。**

## 5 FR vs PRP 速查

| 维度 | FR | PRP |
| --- | --- | --- |
| 公式 | $\|g_{k+1}\|^2/\|g_k\|^2$ | $g_{k+1}^T(g_{k+1}-g_k)/\|g_k\|^2$ |
| 二次+精确线搜索 | 线性 CG | 退化为 FR |
| 实践表现 | 可能 jamming、偏慢 | 自适应重启、通常更快 |
| 全局收敛 | 强 Wolfe 下成立 | 需截断（PRP+）后成立 |
| 工程默认 | 较少 | 更常用 |

**辨析｜易错点：**其一，非线性 CG 的步长**必须**用 Wolfe 线搜索，用 Armijo（只防大）可能导致 $s_k^Ty_k \le 0$、$\beta$ 变负、方向失去下降性——因此还要加 $\beta \leftarrow \max\{\beta, 0\}$ 的「防负」截断；其二，`jamming` 是 FR 的典型失败模式，遇到「看似不收敛」先查方向是否退化；其三，非线性 CG 对**非凸问题**只能保证收敛到驻点（可能鞍点），与拟牛顿同样受非凸本质限制。<span class="marginnote">在深度学习语境里，非线性 CG 的「$\beta$ 选择」对应的是「动量系数」的调度——Momentum SGD 的 $\gamma$ 是常数版 FR（$\beta$ 恒为 $\gamma$），而 PRP 的「自适应 $\beta$」则对应各类自适应动量。经典与深度学习的步长策略在这里又一次汇合。</span>

## 6 小结

- **非线性 CG**：$d_{k+1} = -g_{k+1} + \beta_k d_k$ + Wolfe 线搜索，只需一阶信息与 $O(n)$ 内存。
- **FR**：$\beta = \|g_{k+1}\|^2/\|g_k\|^2$，收敛性最干净，但易 jamming。
- **PRP**：$\beta = g_{k+1}^T(g_{k+1}-g_k)/\|g_k\|^2$，自适应重启、实践更佳；PRP+ 截断保收敛。
- **区别本质**：PRP 是 FR 的非精确推广，$g_{k+1}^Tg_k$ 项提供「何时忘」开关。
- **工程注意**：Wolfe 步长 + $\beta \ge 0$ 截断 + 周期性重启是标准三件套。
