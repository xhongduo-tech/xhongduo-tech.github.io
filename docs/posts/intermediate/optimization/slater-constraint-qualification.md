## 为什么「约束长什么样」要单独立一章

前面几节反复出现「Slater 条件成立则强对偶成立」。但 Slater 只是众多**约束品性（constraint qualification, CQ）**中的一种。约束品性是优化理论里一个经常被忽略、却决定成败的环节：它是「保证对偶间隙为零」「保证 KKT 条件是必要条件」的门槛。<span class="marginnote">通俗地说：约束品性回答「可行域的边界是否被约束‘规范地’描述」。边界若是「皱巴巴」的——约束之间线性相关、可行域是条瘦脊——那么最优解处的几何信息（梯度关系）就不一定可靠，KKT 与强对偶都会失效。品性条件就是给「规范」下的精确定义。</span>

## 1 什么是约束品性：为什么需要它

最优化里要反复用到这样的推理：

> 若 $x^*$ 是最优解，则在 $x^*$ 处，目标梯度 $\nabla f_0(x^*)$ 必须能由**激活约束的梯度**线性组合出来。

这个推理（KKT 必要性的核心）依赖一个隐藏假设：**激活约束在 $x^*$ 附近「互相独立且足够肥」**。如果激活约束在 $x^*$ 处病态——比如两条约束梯度几乎平行，或可行域在那个点缩成一条线——上述线性组合可能根本不存在，KKT 条件就不成立了。<span class="marginnote">直观例子：$\min\ x$ 约束 $x^2 \le 0$。可行集是单点 $\{0\}$，目标在 $x=0$ 处最优，但该点处约束梯度 $2x = 0$，无法张成任何方向——KKT 的「乘子存在性」在这里需要仔细处理。约束品性就是来管这种边缘情形的。</span>

**约束品性（constraint qualification）**是一组保证「最优解处约束集合具有良好的正则性」的条件。它们的作用有两处：

- **保证强对偶**（对凸问题）：Slater 条件正是为此。
- **保证 KKT 必要性**（KKT 条件成立为「最优」的必要条件）：这里需要的是另一种品性，如 **LICQ**。

## 2 Slater 条件：凸优化里的「肥可行域」

我们已经见过 Slater 条件，本节给出严格陈述与变体。

**Slater 条件**：对凸优化问题，若存在 $\tilde x$ 满足

$$
f_i(\tilde x) < 0 \ (i=1,\ldots,m), \qquad h_j(\tilde x) = 0 \ (j=1,\ldots,p)
$$

则称 Slater 条件成立。它保证：**强对偶成立（$d^* = p^*$），且若 $d^*$ 有限则对偶最优解 $(\lambda^*, \nu^*)$ 存在。**

三个重要变体：

- **弱 Slater**：只对**非仿射**不等式约束要求严格成立；仿射不等式约束（如 $Ax \le b$）允许取等。这让 LP（全仿射）无条件满足，纯等式约束问题（$m=0$）也自动满足。
- **可行性 vs 严格可行性**：可行集非空只保证「有可行点」；Slater 要求「有严格可行点」——可行域内部非空。
- **相对内部**：更精细的版本允许 $\tilde x$ 落在可行集的**相对内部**（相对于仿射包），放宽了对等式约束的处理。<span class="marginnote">工程上记住宽版本即可：<strong>只要可行域「不是一片零体积的薄壳」，Slater 基本就成立</strong>。遇到问题先检查「能不能找到一个点让所有不等式严格松」，能，强对偶就白送。</span>

## 3 LICQ 与其他品性：非线性规划的世界

走出凸优化，KKT 必要性的标准品性是 **LICQ（线性独立约束品性，Linear Independence CQ）**：

**LICQ**：设 $x^*$ 可行，$\mathcal{A}(x^*) = \{ i \mid f_i(x^*) = 0 \}$ 是激活不等式约束的指标集。若梯度集合

$$
\{ \nabla f_i(x^*) : i \in \mathcal{A}(x^*) \} \cup \{ \nabla h_j(x^*) : j = 1,\ldots,p \}
$$

**线性无关**，则称 LICQ 在 $x^*$ 处成立。它保证 $x^*$ 是最优解时，KKT 乘子存在且唯一。<span class="marginnote">LICQ 的名字直白：「线性独立」。激活约束的梯度要互相独立——不独立（如两条约束在切平面上重合），乘子就有自由度，KKT 的判定力变弱。工程里 LICQ 是最常用的非线性 KKT 品性，绝大多数光滑约束优化都满足它。</span>

其他值得知道的品性：

- **MFCQ（Mangasarian–Fromovitz CQ）**：比 LICQ 弱（允许梯度线性相关），仍保证 KKT 乘子存在（但不一定唯一）。是 LICQ 的稳健替代。
- **Slater（凸）**：保证强对偶与 KKT 充分性，但不保证乘子唯一。
- **无约束/纯等式**：若没有不等式约束且等式梯度线性无关，KKT 简化为经典拉格朗日乘子理论（第六篇）。

## 4 公式解析：Slater 如何救活强对偶

把 Slater 放进强对偶证明的「关键一步」，看它到底堵住了哪个漏洞。回顾上一节的镜像集

$$
\mathcal{G} = \{(p,u,v) \mid \exists x,\ f_0(x)\le p,\ f_i(x)\le u_i,\ h_j(x)=v_j\}
$$

- **第一步，分离目标**：想证明 $d^* = p^*$，等价于证明点 $(p^*, 0, 0)$ 不能与 $\mathcal{G}$ 被严格分离——若有分离超平面 $(1,\lambda,\nu)$ 使 $(p^*,0,0)$ 与 $\mathcal{G}$ 分开，则 $p^* + \sum \lambda_i u_i + \sum \nu_j v_j \ge \text{某常数}$ 且 $\lambda \ge 0$，直接推出 $g(\lambda,\nu) \ge p^*$，与弱对偶矛盾。
- **第二步，凸性保证能分或不能分**：$\mathcal{G}$ 凸时，$(p^*,0,0) \notin \mathrm{cl}\,\mathcal{G}$ 才会导致分离；若 $(p^*,0,0) \in \mathrm{cl}\,\mathcal{G}$，则强对偶成立。
- **第三步，Slater 堵漏洞**：Slater 保证**可行域内部非空**，从而 $\mathcal{G}$ 在「$u$ 方向」有厚度，$(p^*,0,0)$ 不可能落在 $\mathrm{cl}\,\mathcal{G}$ 之外——分离超平面不存在，强对偶成立。

**Slater 的角色精确到此为止：它只负责「$\mathcal{G}$ 在关键点处足够厚」**。不厚（可行域是薄壳）时，点就可能飘在外面被分离，强对偶崩掉。这就是为什么「严格可行」是 Slater 的精髓。

## 5 约束品性速查表

| 品性 | 适用场景 | 保证什么 | 条件强度 |
| --- | --- | --- | --- |
| Slater | 凸优化 | 强对偶、KKT 充分性 | 弱（容易满足） |
| 弱 Slater | 凸优化 | 同上 | 最弱 |
| LICQ | 一般光滑非线性 | KKT 必要性、乘子唯一 | 较强 |
| MFCQ | 一般光滑非线性 | KKT 必要性（乘子存在） | 中等 |
| 无约束 / 纯等式（满秩） | 任意光滑 | 拉格朗日乘子理论 | 看等式秩 |

**辨析｜易错点：**把 Slater 与 LICQ 混用是常见错误：Slater 用于**凸问题证强对偶**，LICQ 用于**一般问题证 KKT 必要**。凸问题里 KKT 的充分性不需要品性，但「$x^*$ 最优 ⇒ KKT 成立」这条路（必要性）有时仍需要某种品性（凸问题的必要性常靠 Slater + 次梯度论证）。另一误区：认为「可行集内部非空」自动成立——当约束把可行域压成低维流形时（如 $x^2+y^2=1$ 是圆周，内部为空），任何 Slater 型条件都失败。

## 6 例题：检查 Slater 是否成立

判断问题是否满足 Slater 条件：

$$
\min\ x_1^2 + x_2^2 \quad \mathrm{s.t.}\quad x_1 + x_2 \le 1,\ \ -x_1 + 2x_2 \le 1
$$

- **第一步，找严格可行点**：两条不等式约束都要**严格**小于 0。取 $\tilde x = (0, 0)$：$x_1+x_2 = 0 < 1$、$-x_1 + 2x_2 = 0 < 1$——都严格松。
- **第二步，确认凸性**：目标凸二次、约束仿射，问题凸。
- **第三步，下结论**：Slater 成立 ⇒ 强对偶成立，$d^* = p^*$。求解（$x^* = (0.2, 0.4)$ 附近）可用对偶算法或直接 KKT。

若把约束改成 $x_1 + x_2 \le 1$ 与 $x_1 + x_2 \ge 1$ 同时要求，可行集是直线 $x_1 + x_2 = 1$——内部为空，Slater 失败。但约束全仿射，**弱 Slater 变体仍成立**，强对偶依旧无恙。这提醒我们：**仿射约束即便绷紧也不怕，Slater 只对非仿射约束较真。**

## 7 小结

- **约束品性**：保证「最优解处约束集合正则」的条件，服务于强对偶（Slater）与 KKT 必要性（LICQ 等）。
- **Slater**：存在严格可行点，非仿射不等式约束全部严格松；凸 + Slater ⇒ 强对偶。
- **弱 Slater**：仿射约束允许取等，LP 与纯等式问题自动满足。
- **LICQ / MFCQ**：激活约束梯度线性无关（或更弱），用于一般非线性规划的 KKT 必要性。
- **几何角色**：Slater 保证镜像集 $\mathcal{G}$ 在关键点「足够厚」，堵住分离超平面。
- **易错点**：可行 ≠ 严格可行；凸问题 KKT 充分性免品性，必要性仍可能需要。
- **一句话记忆**：Slater 管「凸 + 强对偶」、LICQ 管「一般 + KKT 必要」——分工别混。
- **几何本质**：Slater 让镜像集 $\mathcal{G}$ 在关键点「足够厚」，堵住分离超平面——薄壳就崩。
