## 为什么「切一刀」能收紧下界

线性松弛的可行域比整数点的凸包大——那部分「多余」的多面体正是 gap 的来源。**割平面法（cutting plane method）**的思路：**如果松弛最优解不是整数，就找一条「有效不等式」把它切掉，同时不切掉任何整数可行解**。反复切，松弛的多面体被「雕刻」得越来越接近凸包，下界越来越紧。<span class="marginnote">「有效不等式（valid inequality）」是割平面法的核心概念：它对<strong>所有整数可行解</strong>都成立，但<strong>当前的松弛最优解</strong>（非整数）不满足它。切掉这个解的同时绝不误伤真解。Gomory（1958）证明了一个惊人的事实：<strong>从 LP 单纯形表出发，总能机械地造出这样的割</strong>——这使割平面法第一次成为完备的整数规划算法。</span>

## 1 割平面法的主循环

割平面法的框架：

```text
重复：
  1. 解 LP 松弛，得最优解 x* 与最优单纯形表；
  2. 若 x* 的整数变量全部取整数值，停止——x* 即整数最优；
  3. 否则，从某一行（基变量为整数、右端非整）生成一条 Gomory 割；
  4. 把割作为新约束加入松弛，多面体收紧，回到步骤 1。
```

**收敛**：若每轮都能找到「切掉当前解」的割，且割的数量有限，则算法终止于整数最优解。<span class="marginnote">Gomory 割平面法在理论上有限步收敛（Gomory 1958），但实践中<strong>收敛极慢</strong>——割平面法的「纯」版本不适合直接商用。它的价值有两层：一是理论完备性的证明，二是与分支定界结合成 <strong>branch-and-cut</strong>（先切几刀再分支）——后者是现代求解器的标配。理解割平面，就理解了求解器「为什么松弛那么紧」。</span>

## 2 Gomory 割：从单纯形表机械生成

Gomory 割的构造只需要 LP 松弛的**最优单纯形表**。设当前最优表中某行（对应基变量 $x_B$）为

$$
x_B + \sum_{j \in \mathcal{N}} \bar a_j x_j = \bar b
$$

其中 $x_B$ 是整数变量，$\bar b$ 非整数。<span class="marginnote">分离整数与非整数部分：把 $\bar a_j$ 拆成整数部分 $\lfloor\bar a_j\rfloor$ 与小数部分 $f_j = \bar a_j - \lfloor\bar a_j\rfloor$，$\bar b$ 拆成 $\lfloor\bar b\rfloor$ 与 $f_0 = \bar b - \lfloor\bar b\rfloor$。关键观察：若所有变量都是整数，则 $x_B + \sum\lfloor\bar a_j\rfloor x_j$ 是整数，从而 $\sum f_j x_j \equiv f_0 \pmod{1}$——而 $f_j \ge 0$、$f_0 > 0$。</span>

**Gomory 割**（由该行构造）：

$$
\sum_{j \in \mathcal{N}} f_j\, x_j \ge f_0
$$

- **整数性论证**：整数解下，左边 $\sum f_jx_j$ 与 $f_0$ 同余（模 1），而 $f_0 > 0$、$\sum f_jx_j \ge 0$——故左边 $\ge f_0$ 必然成立？需要更细致：左边是「非负小数之和」，同余 $f_0$，若它 $\ne f_0$ 则至少 $f_0 + $ 某个正数，总之 $\ge f_0$。<span class="marginnote">严格论证：$x_B + \sum\lfloor\bar a_j\rfloor x_j = \bar b - \sum f_j x_j = \lfloor\bar b\rfloor + (f_0 - \sum f_jx_j)$。左边是整数 ⇒ $f_0 - \sum f_jx_j$ 是整数。但 $\sum f_jx_j \ge 0$ 且 $0 < f_0 < 1$，若 $\sum f_jx_j < f_0$ 则 $f_0 - \sum f_jx_j \in (0,1)$ 非整数——矛盾。故 $\sum f_jx_j \ge f_0$。</span>
**切割性**：当前松弛解中，非基变量 $x_j = 0$，故左边 $= 0 < f_0$——**松弛最优解被切掉**。

## 3 公式解析：一个 Gomory 割的数值例子

解一个具体例子生成 Gomory 割。考虑 $0-1$ 背包：$\max 45x_1 + 48x_2$ s.t. $16x_1 + 20x_2 \le 40$、$x \in \{0,1\}$。

**第一步，解 LP 松弛**（$0\le x_i\le 1$）：最优 $x_1 = 1$、$x_2 = 0.75$，$z = 81$。松弛变量 $s = 40 - 16 - 15 = 9 \ge 0$，非基。
**第二步，写最优表的关键行**：约束 $16x_1 + 20x_2 + s = 40$。以 $x_1, x_2$ 为基重排……直接对「$x_2$ 是基变量且值 0.75 非整数」这一行操作。简化：考虑 $x_2$ 对应的行（$x_2 = 0.75 - 0.8s + \cdots$）——取约简行 $x_2 + \frac{4}{5}s = \frac{3}{4}$（$\bar b = 3/4$、$\bar a_s = 4/5$）。
**第三步，分离**：$f_0 = 3/4$，$f_s = 4/5$（$x_1$ 的系数若为整数则 $f = 0$，忽略）。
**第四步，写 Gomory 割**：$\frac{4}{5}s \ge \frac{3}{4}$，即 $s \ge \frac{15}{16}$。代回 $s = 40 - 16x_1 - 20x_2$：$40 - 16x_1 - 20x_2 \ge \frac{15}{16}$，整理得 $16x_1 + 20x_2 \le 39.0625$。取整强化为 $16x_1 + 20x_2 \le 39$（右端向下取整仍有效）。
**第五步，重新求解**：新约束下最优 $x = (1, 1)$，$z = 93$——**整数最优**。

**要点：Gomory 割把「从最优表读出一行 → 分离小数 → 写不等式」变成纯机械流程**，且每轮都能收紧下界。

## 4 有效不等式家族

Gomory 割只是有效不等式的一种。现代求解器使用多种更强的割：

| 割类型 | 来源 | 强度 |
| --- | --- | --- |
| Gomory 割 | 单纯形表 | 一般 |
| 混合整数舍入割（MIR） | 单条约束的整数舍入 | 常用、强 |
| 覆盖不等式（cover） | 背包结构的子集 | 很强（0-1 背包） |
| 流覆盖 / 提升不等式 | 网络流结构 | 强 |
| 奇集不等式 | 匹配/划分结构 | 很强 |

**辨析｜易错点：**其一，割必须**有效**（不切整数解）——无效的「割」会毁掉正确性；其二，割太弱（切不下非整数解）则浪费计算；其三，割平面法的**收敛在理论上有限但在实践中极慢**——纯割平面法很少直接用，必须配分支定界；其四，分离问题（找割）本身可能很难——但对 Gomory 割是平凡的（从表读）。<span class="marginnote">现代 branch-and-cut 求解器的工作流：解松弛 → 用分离算法找一组割（Gomory、MIR、覆盖……）→ 加入并重新求解 → 割不动了再分支。割让每个节点的下界大幅收紧，分支树大幅变瘦——这是「间隙」从理论概念变成求解器速度的桥梁。</span>

## 5 分离问题：找割的成本

割平面法每轮都要回答一个问题：**给定一个点 $x^*$，是否存在一条有效不等式把它与整数凸包分开？** 这叫**分离问题（separation problem）**。

- **分离问题的正式表述**：给定凸集 $C$ 与点 $x^*$，求一条超平面把 $x^*$ 与 $C$ 分开，或断言不存在。
- **对 Gomory 割是平凡的**：直接从单纯形表读一行，机械生成——分离成本 $O(1)$。
- **对覆盖不等式不平凡**：给定背包约束 $\sum a_jx_j \le b$ 与当前解，找最小权覆盖子集本身是难的子问题——但 0-1 背包结构让启发式分离极快。
- **分离与优化的对偶（Grötschel–Lovász–Schrijver）**：对一族多面体，多项式时间分离 ⟺ 多项式时间优化——这条深刻定理说明「会分离就会优化」。<span class="marginnote">分离问题的视角把割平面法上升为一般框架：<strong>任何一种「能高效分离的约束族」都能被割平面法利用</strong>。这就是为什么求解器内置几十种割族——每个族对应一个可分离的结构。理解分离，就理解了 branch-and-cut 的引擎室。</span>

## 6 分支定界 vs 割平面：两种收紧下界的方式

| 维度 | 分支定界 | 割平面法 |
| --- | --- | --- |
| 怎么收紧 | 拆成子问题，分别求解 | 加约束，收紧单一体 |
| 对下界的影响 | 每支各自算 | 全局下界提升 |
| 几何动作 | 用超平面把可行域切开 | 用超平面把非整数点切掉 |
| 理论收敛 | 有限（分支有限） | 有限（Gomory，理论上） |
| 实践表现 | 快（配合好的分支规则） | 纯割慢，配合分支更强 |
| 现代形态 | branch-and-cut（先切后支） | branch-and-cut（切完再支） |

**辨析｜易错点：**其一，「割」和「分支」是互补的：分支把空间切成两块，割把空间雕小——现代求解器先割后支，两者叠加大幅压缩搜索树；其二，割平面法要保证「每次割都有效」，加入无效割会污染多面体、拖慢求解；其三，Gomory 割在数值上可能很密、很小，工程上要舍入与净化处理。<span class="marginnote">把这一篇与整数规划的整条线索连起来：<strong>线性松弛给出下界 → 间隙量化松紧 → 割平面把下界抬升 → 分支定界用下界剪枝</strong>。四条武器环环相扣，共同构成现代混合整数规划求解器的骨架。</span>

## 7 把「割」和「支」拼在一起：branch-and-cut

纯割平面法理论完备、实践慢，纯分支定界靠割平面提供的紧下界才能剪枝。**branch-and-cut** 把它们拼成一条流水线。

**每一轮**：解当前节点的 LP 松弛 → 用分离器找一组割（Gomory、MIR、覆盖）→ 加入割并重新求解 → 割得差不多了（分离器报告「找不到更强割」）→ 再分支。

**为什么先割后支**：割把每个节点的下界抬高，分支时「剪掉一个节点」的判断就更容易成立。一条经验法则：**节点处下界越紧，搜索树越瘦**。对 0-1 背包这类「割很强」的问题，几刀下去树就能小一个量级。

| 工作流阶段 | 动作 | 目的 |
| --- | --- | --- |
| 解松弛 | 单纯形/内点求 LP 最优 | 得到当前节点下界 |
| 分离 | 生成 Gomory/MIR/覆盖割 | 抬高下界 |
| 重新求解 | 加割后重解 | 检验割是否生效 |
| 分支 | 拆成两个子节点 | 无强割时缩小空间 |

**辨析｜易错点：**branch-and-cut 的「cut」层与「branch」层共享同一个下界信息——如果分离器一直加不出有效割，就退化成纯分支定界（仍正确、只是慢）；反之若割太强而有效，树可能小到直接在根节点就出整数解——这两种极端都说明「割的质量是求解器性能的杠杆」。

## 8 小结

- **割平面法**：反复找「有效但切掉当前松弛解」的不等式，收紧下界逼近整数凸包。
- **有效不等式**：对所有整数解成立、但被当前松弛解违反。
- **Gomory 割**：从最优单纯形表机械生成；$\sum f_jx_j \ge f_0$，有限步收敛（理论上）。
- **分离与强度**：Gomory/MIR/覆盖/奇集不等式各有来源与强度。
- **实践**：纯割平面慢，branch-and-cut（切 + 分支）是现代求解器标配。
