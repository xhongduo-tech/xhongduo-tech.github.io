## 为什么 LP 对偶是「最干净」的对偶

第三篇的对偶理论在 LP 上达到最纯粹的形态：**强对偶无条件成立**、对偶问题仍是 LP、互补松弛给出显式桥接。更重要的是，LP 对偶直接催生了一个新算法——**对偶单纯形法**：在原问题「初始不可行」时，它改在**对偶空间**里行走，从一个「对偶可行」的起点出发，逐步恢复原始可行性。<span class="marginnote">对偶单纯形法常被初学者当成「单纯的对称游戏」，其实它有硬核的工程价值：<strong>warm start</strong>——当约束右端项 $b$ 变化、而旧解「几乎还可用」时，对偶单纯形法能以极少迭代重新收敛，这正是分支定界（第八篇）每个节点都复用它解的底气。</span>

## 1 LP 对偶的标准表格

LP 的对偶可以写成整齐的「转置」规则。**对称形式**：

$$
\text{原问题}\ \min\ c^Tx,\ Ax \ge b,\ x\ge0
\qquad\Longleftrightarrow\qquad
\text{对偶}\ \max\ b^Ty,\ A^Ty \le c,\ y \ge 0
$$

**等式标准形式**（我们前面用的）：原问题 $\min c^Tx$ s.t. $Ax = b,\ x\ge0$，对偶为 $\max b^Ty$ s.t. $A^Ty \le c$（$y$ 无符号约束）。

**转置规则速记**：原问题与对偶问题的**变量与约束互换**，目标系数 $c$ 与右端 $b$ 互换，矩阵转置，$\le$ 与 $\ge$、$\min$ 与 $\max$ 对调。<span class="marginnote">对称形式里 $x\ge0$ 对应 $A^Ty\le c$，$Ax\ge b$ 对应 $y\ge0$——「原问题的约束符号决定对偶变量的符号」，这是写对偶时最容易记错、也最需要查表的一步。多练几次「给约束贴符号」就熟了。</span>LP 对偶是**自对偶**的：对偶的对偶回到原问题。

## 2 LP 的互补松弛

LP 上的互补松弛有最干净的形式。设 $x^*$、$y^*$ 分别是原问题与对偶问题的最优解，则

$$
(Ax^* - b)_i \cdot y_i^* = 0, \qquad (c - A^Ty^*)_j \cdot x_j^* = 0
$$

**第 $i$ 条约束若松弛（$Ax^* > b$），其对偶变量必为 0；第 $j$ 个原始变量若为正，对应对偶约束必绷紧（$A^Ty^* = c$）**。<span class="marginnote">这组条件让「验证 LP 最优」变成一次 $O(n+m)$ 的检查：给定一对可行解，只要互补松弛成立，强对偶就自动给出 $c^Tx^* = b^Ty^*$——两者都是最优。求解器输出的「原始解 + 对偶解」对，就是用来跑这条验证的。</span>

## 3 对偶单纯形法的思想

**对偶单纯形法（dual simplex method）**的思想是：维持**对偶可行性**（检验数非负，即 $A^Ty \le c$ 对当前对偶基成立），逐步消除**原始不可行**（右端列出现负分量）。

普通单纯形法 = 从原始可行出发，向对偶可行走（换基让检验数变非负）；对偶单纯形法 = 从对偶可行出发，向原始可行走（换基让右端变非负）。**两者在同一个多面体上行走，只是「可行」的定义互换。**<span class="marginnote">几何上，对偶单纯形法从一个「对偶意义下可行、原始意义下不可行」的顶点出发，沿棱移动到原始可行的顶点。它的每次迭代在表格上仍是 pivot，只是进基/出基的角色对调：先选「负右端」行，再选「合适的负检验数」列。</span>迭代规则（表格版）：

1. **选出基**：右端列最负的那一行（原始最不可行）。
2. **选进基**：在该行中选「检验数/该行系数」比值最合适的列（保证换基后仍对偶可行）。
3. **转轴**：标准 pivot。
4. **终止**：右端列全部非负——原始可行，又保持对偶可行，最优。

## 4 公式解析：为什么右端负 = 原始不可行

把「对偶单纯形法在干什么」用 KKT 语言读透。考虑 LP 标准形与它的 KKT 条件：

$$
Ax = b,\ x \ge 0, \qquad A^Ty \le c, \qquad (c - A^Ty)_j x_j = 0
$$

- **第一步，拆成两组可行性**：原始可行性 = $Ax = b,\ x \ge 0$；对偶可行性 = $A^Ty \le c$。
- **第二步，观察单纯形表**：检验数非负 ⟺ $A^Ty \le c$（对偶可行）；右端列非负 ⟺ $x_B \ge 0$（原始可行）。
- **第三步，最优 = 双可行 + 互补松弛**：KKT 说「最优」等价于「原始可行 + 对偶可行 + 互补松弛」。普通单纯形法始终保持「原始可行 + 互补松弛」、追求「对偶可行」；对偶单纯形法始终保持「对偶可行 + 互补松弛」、追求「原始可行」。
- **第四步，殊途同归**：两条路都收敛到「双可行」= KKT 点 = 最优解。**对偶单纯形法的每一步，都是在一个已经满足 KKT 的后两式的点之间行走。**

**这条解析的价值：KKT 把两个「看起来不同的算法」统一成同一目标的不同逼近路线**——这也是本书反复出现的主题：算法千万条，KKT 一条心。

## 5 对偶单纯形法的应用

对偶单纯形法在工程里不是理论摆设，而是性能引擎：

- **分支定界的热启动**：整数规划的分支定界（第八篇）在每个节点对 LP 松弛求解；子节点约束只多一条，父节点的解「几乎可行」，用对偶单纯形法从父解出发只需几次迭代。<span class="marginnote">这是对偶单纯形法最「赚钱」的应用：分支定界的性能瓶颈在数以万计的 LP 求解，热启动让每个 LP 从「接近解」开始，迭代数从数百降到个位数。</span>
- **灵敏度分析**：$b$ 或 $c$ 微小变化后，旧解可能失去可行性，对偶单纯形法快速修复。
- **与单纯形法互补**：原始单纯形适合「从可行到最优」，对偶单纯形适合「从几乎最优到可行」——现代求解器按场景自动选用。

## 6 小结

- **LP 对偶**：变量约束互换、$c$ 与 $b$ 互换、矩阵转置；对称/等式两种形式。
- **互补松弛**：$(Ax^* - b)_i y_i^* = 0$、$(c - A^Ty^*)_j x_j^* = 0$——松弛约束的乘子必为 0。
- **对偶单纯形法**：保持对偶可行，消除原始不可行；与普通单纯形法在同一多面体上「反向行走」。
- **KKT 统一**：两法都是「逼近双可行 + 互补松弛」的路线，目标一致。
- **工程价值**：分支定界热启动、灵敏度修复——从「几乎可用」到「重新最优」的利器。
