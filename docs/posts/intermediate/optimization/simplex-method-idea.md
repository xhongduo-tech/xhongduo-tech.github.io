## 为什么叫「单纯形」法

上一节我们有了「顶点 = 基本可行解」这张地图。但地图上顶点可能数以亿计，直接枚举不现实。**单纯形法（simplex method）**给出聪明的寻路策略：从一个顶点出发，**沿着「目标会改善」的棱**，每次走到相邻的更好顶点，直到无法再改善。<span class="marginnote">「单纯形」一词来自 Dantzig 早期的几何构想——他一度想在单纯形（广义四面体）上做系统地枚举，后来发现沿棱寻路更高效，但名字保留了下来。它本质是「多面体顶点图上的贪心下降」，配上严格的最优性判据，就成了完备算法。</span>

## 1 从当前顶点出发：检验数

设当前 BFS 的基为 $B$，基本变量 $x_B = B^{-1}b$，目标值 $z = c_B^T x_B$。如何判断「是否还能改进」？对每个非基本变量 $x_j$，定义**检验数（reduced cost）**

$$
\bar c_j = c_j - c_B^T B^{-1} A_j
$$

其中 $A_j$ 是 $A$ 的第 $j$ 列。<span class="marginnote">检验数的含义：把 $x_j$ 从 0 增加到 1（保持其他非基本变量为 0），目标值的<strong>净变化率</strong>。$c_j$ 是直接成本，$c_B^T B^{-1} A_j$ 是「为了腾出空间而调整基本变量带来的间接成本」。检验数为负 = 增加 $x_j$ 会让目标下降 = 值得进基。</span>

**最优性判定**：若对所有非基本变量都有 $\bar c_j \ge 0$，则当前 BFS 已是最优——任何进基尝试都不会改善目标，且这是充分条件（配合凸性）。这一条就是单纯形法的「停车标志」。

## 2 一次换基：进基与出基

若存在 $\bar c_j < 0$，选一个**进基变量（entering variable）** $x_j$（通常取检验数最负的），把 $x_j$ 从 0 增大，同时调整基本变量维持 $Ax = b$。设 $d = B^{-1}A_j$，则 $x_B$ 沿方向 $-d$ 移动：$x_B(\theta) = B^{-1}b - \theta d$，$x_j = \theta$。

**出基规则（最小比值检验）**：$x_B$ 必须保持非负，所以 $\theta$ 的最大值是

$$
\theta^* = \min\left\{ \frac{(B^{-1}b)_i}{d_i} : d_i > 0 \right\}
$$

取到最小比值的那个基本变量 $x_r$ 降到 0——它就是**出基变量（leaving variable）**。把 $A_j$ 换进基、$A_r$ 换出基，得到新基，目标值下降 $\bar c_j \theta^* \le 0$。<span class="marginnote">最小比值检验保证「换基后仍在可行域内」——这是单纯形法最关键的防护：任何一步都不能把某个基本变量推出非负区域。$d_i \le 0$ 的分量对应「$x_j$ 增大时 $x_i$ 不减」，不会碰到边界，不参与最小比值。</span>

**几何对应**：进基 $x_j$ 从 0 增大 = 从当前顶点沿一条棱出发；出基 $x_r$ 降到 0 = 走到棱的另一端（新顶点）。一次换基 = 沿一条更优的棱走一步。

## 3 为什么能终止：有限性与目标单调

单纯形法的终止性依赖两件事：

1. **目标值单调不增**：每一步 $\Delta z = \bar c_j \theta^* \le 0$，且非退化时 $\theta^* > 0$、$\Delta z < 0$ 严格下降。
2. **非退化下不重访**：严格下降保证不会回到之前访问过的 BFS；BFS 有限（至多 $\binom{n}{m}$ 个），故必终止于某个「所有检验数非负」的 BFS——最优解。

**辨析｜易错点：**退化的坑就在这里。若当前 BFS 退化（某个基本变量为 0），最小比值可能取 $\theta^* = 0$，换基不移动位置、目标不下降——算法可能进入**循环（cycling）**，永不终止。这是理论上的最大威胁（实践中极罕见），需要 Bland 规则等防循环策略（下下节专门讲）。<span class="marginnote">一句话记牢：<strong>非退化时单纯形法必然终止且不重访；退化时可能原地打转。</strong> 工程代码里的「扰动法」「Bland 规则」都是给这条理论漏洞打的补丁。</span>

## 4 公式解析：完整的一次迭代

把一次换基的数值过程走完整。设 LP 已化为标准形

$$
A = \begin{bmatrix} 1 & 1 & 1 & 0 \\ 2 & 1 & 0 & 1 \end{bmatrix},\ b = \begin{pmatrix}4\\6\end{pmatrix},\ c = (-2, -1, 0, 0)^T
$$

当前基 $B = (A_1, A_2)$，$x_B = (2,2)$，$c_B = (-2,-1)$，$z = -6$。

- **第一步，算检验数**：$B^{-1} = \begin{bmatrix}-1&1\\2&-1\end{bmatrix}$。对非基本变量 $x_3$（$A_3 = (1,0)^T$）：$\bar c_3 = 0 - c_B^TB^{-1}A_3$。先算 $c_B^TB^{-1} = (-2,-1)\begin{bmatrix}-1&1\\2&-1\end{bmatrix} = (0,-1)$，则 $\bar c_3 = 0 - (0,-1)(1,0)^T = 0$；对 $x_4$（$A_4=(0,1)^T$）：$\bar c_4 = 0 - (0,-1)(0,1)^T = 1 \ge 0$。检验数全部 $\ge 0$——**当前 BFS 已最优**。
- **第二步，确认最优**：$x^* = (2,2,0,0)$，$p^* = -6$。回代约束验证 $x_1+x_2=4$、$2x_1+x_2=6$ 成立，且 $x \ge 0$。
- **第三步，换一个起点试试**：若从基 $B=(A_1,A_3)$ 出发（$x_2$ 进基），检验数会给出 $\bar c_2 < 0$，触发换基迭代——这才需要走完整的进基/出基流程。

**要点：检验数全非负 = 停车；有负检验数 = 继续换基。** 上面的例子恰好一步到最优，避免了繁琐的迭代，正好展示「停车标志」怎么用。

## 5 单纯形法在现代求解器中的地位

半个世纪过去，单纯形法仍是工业界的主力之一，而且历久弥新：

- **实践表现**：虽然最坏情形是指数的（Klee–Minty 反例），但真实 LP 上几乎总是线性级迭代，快得惊人。
- **互补地位**：单纯形法给出顶点解（天然稀疏、适合做整数规划分支定界的起点）；内点法给出内部解（适合大规模）。现代求解器两者都用，按问题结构切换。<span class="marginnote">工程细节：单纯形法的每次迭代只改基的一列，用稀疏 LU 更新维持 $B^{-1}$，加上预求解、伸缩、反基，今天的单纯形实现能稳定求解千万变量的问题。算法背后的数学还是 Dantzig 1947 年的那一套。</span>
- **对偶单纯形法**：在「对偶多面体」上行走，特别适合「从一个几乎可行的解开始、逐步修到可行」的场景（分支定界里每个节点都要复用父节点解）。

## 6 小结

- **单纯形法 = 顶点图上的贪心下降**：沿更优的棱走到相邻顶点，检验数非负即停。
- **检验数** $\bar c_j = c_j - c_B^TB^{-1}A_j$：进基变量的目标净变化率。
- **进基/出基**：选负检验数进基，最小比值检验定出基，保证可行。
- **终止性**：非退化下目标严格下降、BFS 有限，必达最优；退化可能循环。
- **工程地位**：实践高效（最坏指数但几乎不遇），与内点法互补，是分支定界的顶配起点。
