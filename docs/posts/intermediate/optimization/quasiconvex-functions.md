## 为什么要把凸性「放宽」

前几节我们反复强调凸性的价值：局部最优即全局最优、算法有收敛保证。但现实中并非每个问题都那么听话——目标函数常常不是凸函数，却比「任意非凸」要温和得多。**拟凸函数（quasiconvex function）**正是这条中间地带里的主力：它保留了凸性最核心的「服务条款」——子水平集都是凸的——却大幅放开了函数本身的形状约束。<span class="marginnote">把话说白：凸性要求「整个函数是个碗」，拟凸性只要求「每个水位的截面都是凸的」。后者比前者宽松得多，却已经足够让我们用二分法这一类稳健算法去求解。</span>在「从极限到大模型」的主线里，拟凸函数藏在许多角落：到达率的比值优化、定位问题、甚至部分强化学习的目标，都能用拟凸语言建模。

## 1 拟凸的定义：子水平集凸

**拟凸函数（quasiconvex function）**：$f: \mathbb{R}^n \to \mathbb{R}$ 满足：对所有 $\alpha \in \mathbb{R}$，子水平集

$$
S_\alpha = \{ x \in \mathrm{dom}\,f \mid f(x) \le \alpha \}
$$

都是凸集，则称 $f$ 是拟凸函数。<span class="marginnote">回忆《上镜图与下水平集》：凸函数的子水平集一定凸，但那是凸性的「副产品」；拟凸把这一条直接<strong>升级为定义</strong>——我们不要求上镜图凸，只要求每个水位的截面凸。</span>同理，**拟凹函数（quasiconcave）**要求所有 $\alpha$ 的超水平集 $\{x \mid f(x) \ge \alpha\}$ 都是凸集；既是拟凸又是拟凹的函数称为**拟线性（quasilinear）**。

这个定义与凸函数定义的关键差别在于：**凸性约束的是「函数值」之间的凸组合关系，拟凸性约束的是「集合」的几何形状**。所以拟凸函数允许函数图像上有波谷、波峰、平台，只要任何一条水平线切出来的截面仍是凸集即可。

## 2 拟凸 vs 凸：放宽了什么，留下了什么

把三层概念放在一起对比：

| 函数类 | 定义要点 | 局部最优 = 全局最优？ | 典型例子 |
| --- | --- | --- | --- |
| 凸函数 | 弦在曲线上方 | 是 | $x^2$、$e^x$、$\|x\|$ |
| 拟凸函数 | 子水平集凸 | 是（对最小值而言） | $\lceil x \rceil$、$x^3$、$\log x$ |
| 一般非凸 | 无结构 | 通常不 | $\sin x$、$x^4 - x^2$ |

三行表格揭示了本质：**「局部最优即全局最优」这一结论，其实不依赖完整凸性，只需要子水平集凸就够**。证明很直接：若 $x^*$ 是拟凸 $f$ 的局部极小点，取 $\alpha = f(x^*)$，则 $S_\alpha$ 是凸集且含 $x^*$；若存在 $y$ 使 $f(y) < f(x^*)$，则 $x^*$ 落在 $S_\alpha$ 的内部，而 $y$ 在 $S_\alpha$ 之外，由凸性连线必穿出 $S_\alpha$，与「$x^*$ 是局部极小」矛盾。<span class="marginnote">这段论证是「放宽定义仍保住最优性」的标准样板：凸集不允许「内部点比外部点更高」的几何配置，这一条足够证明全局最优。</span>

**辨析｜易错点：**拟凸函数**可以不是凸函数**。$\lceil x \rceil$（向上取整）在整数点跳跃，图像上一级一级的台阶，但它每个子水平集都是形如 $(-\infty, k]$ 的区间，显然是凸集。反过来，$x^2$ 凸也拟凸——**凸蕴含拟凸**，方向只有一个。

## 3 可微拟凸函数的一阶刻画

当 $f$ 可微时，拟凸性有简洁的一阶刻画，与凸函数的一阶条件形似而神异：

$$
f \text{ 拟凸} \iff \Big( f(y) \le f(x) \ \Rightarrow \ \nabla f(x)^T (y - x) \le 0 \Big)
$$

读法：**若从 $x$ 走到 $y$ 不会让函数值上升，那么初始方向 $\nabla f(x)^T(y-x)$ 必须「不指向上升侧」**——即不能朝上坡走。这与凸函数一阶条件 $f(y) \ge f(x) + \nabla f(x)^T(y-x)$ 的区别在于：凸性要求的是「切平面在全空间支撑」，拟凸性只要求在「不上升的方向上」不上升。<span class="marginnote">一个方向感记忆：凸的一阶条件约束「所有」$y$，拟凸的一阶条件只约束「$f(y)\le f(x)$ 的那些」$y$。约束越少，允许的函数形状就越多。</span>

最常用的拟凸函数族是**线性分式函数**（比值）：$f(x) = \frac{a^T x + b}{c^T x + d}$，在定义域 $c^T x + d > 0$ 上，它既是拟凸又是拟凹（拟线性）。它的子水平集

$$
\frac{a^T x + b}{c^T x + d} \le \alpha \iff (a - \alpha c)^T x + (b - \alpha d) \le 0
$$

是半空间——凸集。**一个比值问题就这样被化成了线性不等式**，这就是拟凸性在建模里的典型威力。

## 4 公式解析：拟凸的 Jensen 型刻画

拟凸性除了集合定义，还有一条等价的不等式刻画，对应着凸性里的 Jensen 不等式：

$$
f\big(\theta x + (1-\theta)y\big) \le \max\{f(x), f(y)\}, \qquad \forall \theta \in [0,1]
$$

拆三步理解它为何等价于「子水平集凸」：

- **第一步，必要性**：若子水平集都凸，取 $\alpha = \max\{f(x), f(y)\}$，则 $x, y \in S_\alpha$；$S_\alpha$ 凸保证 $\theta x + (1-\theta)y \in S_\alpha$，即 $f(\theta x + (1-\theta)y) \le \alpha$。
- **第二步，充分性**：反推也成立——若不等式对任意 $x, y$ 成立，任取 $\alpha$ 与 $x, y \in S_\alpha$，不等式给出 $\theta x + (1-\theta)y \in S_\alpha$，子水平集凸。
- **第三步，对比凸 Jensen**：凸性要求 $f(\theta x + (1-\theta)y) \le \theta f(x) + (1-\theta)f(y)$——弦的平均值；拟凸只要求不超过两个端点值的**较大者**——取 max。**max 比加权平均宽松得多**，这正解释了为什么拟凸函数能容纳台阶、波峰等「非碗形」形状。

## 5 拟凸优化的二分法

拟凸函数最大的工程红利，是它的最小化可以用**二分法**稳健求解。拟凸优化问题 $\min f(x)$ 等价于求「最小的可行水位」：

**对任意水位 $\alpha$，检验「$S_\alpha$ 是否非空」是一个可行性问题。** 由于 $S_\alpha$ 是凸集，可行性检验通常是一次凸优化或一次线性/半定可解性判断；随着 $\alpha$ 增大，$S_\alpha$ 单调扩大，「可行/不可行」关于 $\alpha$ 是单调的——于是可以二分。<span class="marginnote">二分法的前提是单调：$\alpha$ 越大，子水平集越大，越可能可行。这个单调性正是「子水平集凸」给拟凸优化带来的免费结构。</span>

算法的骨架是：取上下界 $\alpha_l < \alpha_u$，反复取中点 $\alpha$，检验 $S_\alpha$ 可行性，可行则收紧上界、不可行则抬高下界，直到区间足够窄。每一步只需要一次可行性求解，迭代约 $\log_2((\alpha_u - \alpha_l)/\epsilon)$ 次。**拟凸性把一个非凸外形的最小化问题，转换成了几十次「看起来更简单」的可行性问题**——这是「放宽」换来「可解」的经典交易。

## 6 常见拟凸 / 拟凹函数速查表

与凸函数字母表并列，再记一张拟凸/拟凹表：

| 函数 | 类型 | 说明 |
| --- | --- | --- |
| $\lceil x \rceil$、$\lfloor x \rfloor$ | 拟凸 / 拟凹 | 台阶函数，子水平集是区间 |
| 单调函数（$\mathbb{R}$ 上） | 既拟凸又拟凹 | 任一水平集是区间 |
| $x^3$ | 既拟凸又拟凹 | 严格单调，拟线性 |
| $\log x$ | 拟线性（$x>0$） | 既拟凸又拟凹 |
| $\dfrac{a^Tx+b}{c^Tx+d}$ | 拟线性 | 线性分式，子水平集为半空间 |
| $\lambda_{\max}(X)$ | 拟凸（$X \in \mathbb{S}^n$） | 最大特征值，子水平集为凸锥不等式 |
| 凸函数 | 拟凸 | 凸蕴含拟凸（单向） |

**辨析｜易错点：**拟凸**不保证**「拟凸 + 拟凹」的凸性，也不保证唯一全局极小——$f(x) = \lceil x \rceil$ 在整条数轴上处处是全局极小点。另外，两个拟凸函数之和**不必拟凸**（$\lceil x \rceil + \lceil -x \rceil$ 处处取 $0$ 或 $1$，虽本身拟线性，但更复杂的组合可破坏结构），所以拟凸没有「非负加权和」那条保凸运算——这是拟凸函数最不方便的地方。

## 7 例题：二分法求解一个比值优化

把二分法流程完整走一遍。设我们要最小化拟凸函数 $f(x) = \dfrac{x_1 + x_2 + 2}{x_1 - x_2 + 3}$，定义域 $x_1 - x_2 + 3 > 0$，并设约束 $0 \le x_i \le 1$。

- **第一步，写子水平集**：$f(x) \le \alpha$ 等价于 $(1-\alpha)x_1 + (1+\alpha)x_2 + (2 - 3\alpha) \le 0$——一条线性不等式，加上盒子约束后仍是凸集。
- **第二步，检验可行性**：对固定的 $\alpha$，可行性问题「是否存在 $x$ 满足线性不等式 + 盒子约束」是一个线性规划（LP），可以精确求解。
- **第三步，估出二分区间**：$\alpha=0$ 时要求 $x_1+x_2+2 \le 0$，与 $x_i\ge0$ 矛盾，不可行；$\alpha=2$ 时要求 $-x_1+3x_2-4\le0$，取 $x=(1,1)$ 代入得 $-1+3-4=-2\le0$，可行。于是区间取 $[0,2]$。
- **第四步，迭代**：$\alpha=1$ 时 $2x_2-1\le0$，取 $x=(1,0)$ 可行，下界抬到 $1$；$\alpha=1.5$ 时 $-0.5x_1+2.5x_2-2.5\le0$，取 $x=(1,1)$ 得 $-0.5+2.5-2.5=-0.5\le0$，可行……每次二分都把最优值夹在更窄区间里。

这个小例子展示拟凸优化的完整节拍：**一次二分 = 一次线性可行性检验**，全程不碰梯度与线搜索。工程上，这就是「稳健、简单、可证收敛」的全部含义。

## 8 小结

- **拟凸定义**：所有子水平集 $\{x \mid f(x) \le \alpha\}$ 都是凸集；拟凹与拟线性同理。
- **凸蕴含拟凸，反之不成立**：$\lceil x \rceil$、$x^3$ 拟凸但不凸。
- **等价刻画**：$f(\theta x + (1-\theta)y) \le \max\{f(x), f(y)\}$，与凸 Jensen 只差「max 替代加权平均」。
- **一阶刻画**：$f(y) \le f(x) \Rightarrow \nabla f(x)^T (y-x) \le 0$。
- **算法红利**：拟凸最小化可由二分法 + 可行性检验求解，稳健且无需梯度下降的精细调参。
- **代价**：拟凸没有保凸运算（非负和、复合都会破坏拟凸性），建模自由度受限。

在下一节，我们将进入本专题的核心战场——**优化问题的标准形式**：如何把「目标、约束、最优值」这三大要素写成一套严格的语言，并据此定义什么是凸优化问题。
