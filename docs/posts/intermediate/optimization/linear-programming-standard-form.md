## 为什么线性规划如此重要

在所有优化问题里，**线性规划（Linear Programming, LP）**最古老也最成熟：目标函数与全部约束都是线性的。它诞生于二战时期的军事后勤，如今是交通运输、生产计划、金融配置、供应链的日常工作语言，也是凸优化家族里**算法最完备、求解规模最大**的一员——现代求解器（如 Gurobi、CPLEX）能稳定求解千万级变量的 LP。<span class="marginnote">线性规划为何能「又好又快」？几何上，线性目标在凸多面体上的最小值必在多面体的顶点取得；算法上，单纯形法沿顶点行走，内点法沿中心路径逼近——两条路都被吃透了近八十年。本专题第四篇会专门拆解这两条路。</span>

## 1 LP 的标准形式

LP 的标准形式是：目标线性、不等式约束线性、等式约束线性，全部归一为

$$
\begin{aligned}
\min_x \quad & c^T x \\
\mathrm{s.t.} \quad & a_i^T x \le b_i, \quad i = 1, \ldots, m \\
& a_j^T x = b_j, \quad j = 1, \ldots, p
\end{aligned}
$$

其中 $c$ 是**成本向量（cost vector）**，$a_i$ 是约束法向量，$b_i$ 是右端项。由于 $f_0 = c^Tx$ 与所有约束都是仿射（凸），LP 是凸优化的特例，直接继承「局部最优即全局最优」的保证。<span class="marginnote">LP 的另一种更「操作化」的写法是「不等式 + 非负变量」：$Ax = b,\ x \ge 0$，称为等式标准形。它是单纯形法、对偶理论的母体，第四篇会以它为骨架展开。</span>

**为什么 LP 的可行域是凸多面体？** 每条不等式 $a_i^Tx \le b_i$ 定义半空间，等式定义超平面；可行域是有限个半空间与超平面的交——正是第一篇《超平面、半空间与多面体》里的多面体（polyhedron）。一个有界多面体叫**多胞形（polytope）**。线性函数在凸多面体上的最小值必在顶点达到，这一几何事实是理解 LP 全部算法的钥匙。

## 2 如何把「不像 LP」的问题改写成 LP

LP 建模的第一课是识别哪些「非线性表达」其实可以被线性化。三个常用技巧：

- **绝对值**：$\lvert x_i \rvert$ 出现在目标或约束中，引入 $t$ 使 $-t \le x_i \le t$，最小化 $t$。<span class="marginnote">$|x| = \min\{t : -t \le x \le t\}$——绝对值这个「非线性函数」被两个线性约束夹住。这种「用线性约束夹非线性」的手法，是 LP 建模的精髓。</span>
- **分段线性凸函数**：$\max\{a_1^Tx + b_1, \ldots, a_k^Tx + b_k\}$ 可用上镜图技巧改写为线性目标 $t$ + $k$ 条线性约束。
- **极小化凸分段线性函数**：目标里同时出现 $x^+ = \max\{x,0\}$ 与 $x^- = \max\{-x,0\}$ 时，分别用 $x^+ - x^- = x$、$x^+, x^- \ge 0$ 替换。

**辨析｜易错点：**线性化只对「凸的」非线性有效。$\min \lvert x \rvert$ 可以改写，但 $\max \lvert x \rvert$ 不行——最大化凸函数会把问题变成非凸。线性化前先判断「这条非线性是凸的还是凹的」，是 LP 建模的体检项。

## 3 三类经典的 LP 建模

LP 的建模套路在工程里已经模板化，这里给出三个最常复用的原型。

**饮食问题（diet problem）**：要在满足营养需求的前提下最小化食物总成本。设 $x_j$ 为第 $j$ 种食物的购买量，$c_j$ 为单位成本，$a_{ij}$ 为第 $j$ 种食物每单位含第 $i$ 种营养的量，$b_i$ 为营养 $i$ 的需求下限：

$$
\min_x\ c^T x \quad \mathrm{s.t.}\quad Ax \ge b,\ x \ge 0
$$

**生产计划（production planning）**：设 $m$ 种产品、$n$ 种资源，$x_j$ 为产品 $j$ 的产量，$A$ 为资源消耗矩阵，$b$ 为资源库存，$p$ 为单位利润。最大化利润：

$$
\max_x\ p^T x \quad \mathrm{s.t.}\quad Ax \le b,\ x \ge 0
$$

与饮食问题只差一个方向——**一个求最小成本，一个求最大利润，数学结构完全相同**。

**运输问题（transportation）**：把 $m$ 个产地运往 $n$ 个销地，$x_{ij}$ 为运量，$c_{ij}$ 为单位运费，$s_i$ 与 $d_j$ 为供应与需求：$\min \sum_{ij} c_{ij}x_{ij}$，约束 $\sum_j x_{ij} = s_i$、$\sum_i x_{ij} = d_j$、$x_{ij}\ge0$。<span class="marginnote">运输问题是「LP 有网络结构」的代表：约束矩阵是区间矩阵（完全幺模），因此存在整数最优解——这为第八篇的整数规划埋下伏笔：某些整数问题可以「免费」当 LP 解。</span>

## 4 公式解析：从几何到代数——LP 最优解在顶点

LP 的「顶点取到最优」是理解一切的基石，把它从几何翻译成代数：

$$
p^* = \min\{ c^T x \mid Ax \le b \} \quad\Rightarrow\quad \exists\ \text{顶点 } v \text{ 使 } c^T v = p^*
$$

- **第一步，可行域是有界多胞形**（先假定有界）：多胞形 $\mathcal{P} = \{x \mid Ax\le b\}$ 是有限个顶点的凸包（第一篇的表示定理）。
- **第二步，凸包表示**：任意可行点 $x = \sum_k \lambda_k v_k$（$\lambda_k \ge 0, \sum_k \lambda_k = 1$）。
- **第三步，线性目标取极值在顶点**：$c^T x = \sum_k \lambda_k (c^T v_k) \ge \min_k c^T v_k$——加权平均不小于最小的那个顶点值。因此 $p^* \ge \min_k c^T v_k$，而每个顶点本身可行，反向不等式成立，等号取到。

**几何直觉：线性函数没有「内部弯折」，它的等高面是平行平面族。** 在凸多胞形里找最低等高面，一定会先碰到顶点。这正是「从几何到代数」：$Ax \le b$ 描述形状，$c^Tx$ 定义方向，顶点是形状与方向相遇的地方。

## 5 LP 的对偶与求解概览

LP 不仅建模简单，理论上也最完整。三条主线贯穿本专题后续章节：

- **对偶**：LP 的对偶问题仍是 LP，且**强对偶无条件成立**（LP 是强对偶成立的典型代表，无需 Slater 条件）。对偶变量就是约束的**影子价格**——第 $i$ 条约束松一格，最优值改善多少。
- **单纯形法**：沿多面体的边从一个顶点走到更优的顶点，实践中极其高效，但最坏情形是指数的。
- **内点法**：沿可行域内部中心路径逼近最优顶点，多项式时间，是「大规模 LP」的现实选择。<span class="marginnote">单纯形法快而不保证多项式时间，内点法保证多项式时间；两者互补，现代求解器内部按问题规模自动切换。这个「实践 vs 理论」的张力，在第四篇《椭球法与线性规划的多项式可解性》会有完整交代。</span>

今天 LP 的疆域远不止教材上的经典问题：推荐系统的在线分配、广告位的实时出价、云计算的资源调度、交通信号灯配时，都被建模成大规模 LP 或它的在线变体。理解 LP 的标准形式与几何直觉，等于掌握了这批工业级优化器背后共同的语言——无论是 Gurobi、CPLEX 还是开源求解器，它们接受的输入都是本节这套「$\min c^Tx$、$Ax$ 与 $b$ 的关系」的骨架，只是规模大了几个量级而已。

## 6 LP 建模实战对照表

把「自然语言 → LP」的常见翻译收成一张速查表，建模时直接对号入座：

| 自然语言表述 | LP 写法 | 说明 |
| --- | --- | --- |
| 不超过 $b$ | $a^Tx \le b$ | 上限约束 |
| 不少于 $b$ | $a^Tx \ge b$ | 下限约束 |
| 恰好等于 $b$ | $a^Tx = b$ | 等式约束 |
| 变量的绝对值不超过 $t$ | $-t \le x_i \le t$ | 两个线性约束夹住 |
| 成本不超过预算、收益最大化 | $\max p^Tx,\ c^Tx \le B$ | 双目标取其一 |
| 第 $i$ 种资源不超量使用 | $(A^Tx)_i \le b_i$ | 行式约束 |
| 产量 / 运量 / 采购量非负 | $x \ge 0$ | 非负约束 |

**辨析｜易错点：**三个高频错误值得单独点名：其一，「不超过」被误写成等式 $=$；其二，$\ge$ 约束忘了归一化（标准形式统一用 $\le$ 与 $=$）；其三，把「非负」约束漏掉——很多真实问题（产量、运量、采购量）都隐含 $x \ge 0$，漏掉它可行域会无界，求解器给出错误结论。**LP 建模的一条金律：把约束逐条与自然语言核对，缺一条比多一条更危险。**

这张表还能反向用：看到 LP 的某个约束，立刻知道它在自然语言里意味着什么——建模与「读模」（读懂别人的模型）是同一枚硬币的两面。工程实践中，维护一张逐条核对的「约束清单」，比堆叠公式更能避免灾难性错误。

## 7 小结

- **LP 定义**：目标与约束全部线性，是凸优化特例，可行域是凸多面体。
- **顶点定理**：线性目标在凸多胞形上的最小值在顶点取得——几何与代数在此合一。
- **线性化技巧**：绝对值、分段线性凸函数、上镜图都能「夹」成线性约束。
- **三大模板**：饮食（$Ax\ge b$）、生产（$Ax\le b$）、运输（等式 + 非负）。
- **求解双轨**：单纯形法（实践高效）与内点法（多项式时间），强对偶无条件成立。
