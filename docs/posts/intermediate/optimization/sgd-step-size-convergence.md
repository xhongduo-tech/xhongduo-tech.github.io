## 为什么「学习率」是深度学习最常调的参数

SGD 的全部收敛性都押在**步长（学习率）序列**上：步长太大发散、太小停滞、衰减太快走不到、衰减太慢噪声不减。步长规则直接决定「快不快、稳不稳、准不准」——它就是随机优化的方向盘。<span class="marginnote">上一节的 RM 条件给出「$\sum a_n = \infty$ 且 $\sum a_n^2 < \infty$」的理论框架，但工程上的步长远比理论丰富：固定步长、分段衰减、余弦退火、自适应（Adam）。本节先把理论收敛率算清楚，再看工程规则如何在实际与理论之间取舍。</span>

在「从极限到大模型」的知识地图里，本节是**第十篇 随机优化**承上启下的一环：上一节 Robbins–Monro 给出「步长要满足 RM 条件」，本节把「步长具体怎么选、收敛率是多少」量化；下一节的小批量、动量、方差缩减则回答「如何在 SGD 的便宜与 GD 的精确之间折中」。理解步长，是理解深度学习中「训练为什么会失败、怎么调」的钥匙——**大部分训练事故（发散、震荡、停滞）都追根到学习率**。

一个贯穿全文的心法先立住：**学习率不是一个「参数」，而是一条「曲线」**。初值决定「多快起步」，衰减形状决定「末期多准」，warmup 决定「起步稳不稳」——三者合起来才是完整的学习率设计。理论给出的是这条曲线的「形状定律」（$1/k$），工程给出的是「可实现的近似」（warmup + cosine）。把「形状」与「实现」分开记，你就不会被具体配方淹没。

## 1 步长的理论选择

对强凸光滑目标，SGD 的收敛分析给出三档步长：

**固定步长 $a$**：收敛到最优解的**邻域**（不精确收敛），误差界 $\propto a$——**步长越小越准但越慢**。适合「噪声有界、精度有限」的工程。
**衰减步长 $a_k = c/k$**：**精确收敛**，强凸下误差 $O(1/k)$。这是「最优衰减」——$1/k$ 满足 RM 条件（$\sum 1/k = \infty$、$\sum 1/k^2 < \infty$）。
**$a_k = c/\sqrt{k}$**：$\sum a_k^2 = c^2\sum 1/k$ 发散——**不满足 RM 条件**，但弱假设下仍可「期望收敛」，且对「非强凸」常更稳。<span class="marginnote">为什么理论钟爱 $1/k$？对强凸目标，最优收敛率（考虑噪声）是 $O(1/k)$，$a_k = c/k$ 正好达到。$1/\sqrt{k}$ 步长在「只有光滑、无强凸」时给出 $O(1/\sqrt{k})$ 的目标误差。<strong>步长衰减越快，收敛越准但越慢——$1/k$ 是「噪声-速度」平衡点。</strong></span>常数 $c$ 由光滑常数与噪声方差决定，理论最优 $c = 1/\mu$（$\mu$ 强凸常数），实践中靠调。

**常数 $c$ 怎么调（实践直觉）**：$c$ 本质是「步长的初值」——它把 $1/k$ 曲线整体抬高或压低。理论告诉你「曲线形状用 $1/k$」，但「抬多高」要看问题尺度：$c$ 太小，前几百步几乎不动（曲线太矮）；$c$ 太大，前几步就跳过头（曲线太高）。工程上的经验是「从一个偏大的 $c$ 开始，看到 loss 震荡就减半」——**先让曲线尽可能地高，再用震荡信号把 $c$ 压下来**，这与固定学习率的调法如出一辙。

## 2 收敛率的分层结论

把 SGD 在不同条件下的收敛率汇总（目标误差 $E[f(\bar x_k)] - f^*$，$\bar x_k$ 是「迭代平均」）：

| 目标类型 | 最优步长 | 收敛率 |
| --- | --- | --- |
| 强凸 + 光滑 | $a_k = 1/(\mu k)$ | $O(1/k)$ |
| 凸 + 光滑 | $a_k = 1/\sqrt{k}$（或 1/√μk） | $O(1/\sqrt{k})$ |
| 非凸（光滑） | 衰减 | 收敛到驻点（梯度范数 $O(1/\sqrt{k})$） |

**关键对比**：全批量 GD 强凸下是线性收敛（误差指数衰减），SGD 只有 $O(1/k)$——**噪声把「指数」打成「代数」**。<span class="marginnote">这个「线性 → $1/k$」的降档是随机优化的核心代价：每步便宜 $n$ 倍，换来收敛慢一个等级。小批量在两者之间：批量越大、噪声越小，收敛越接近 GD——但每步越贵。「批量-步长-收敛率」三角是随机优化工程平衡的中心。</span>此外，**迭代平均（Polyak–Ruppert averaging）**是个免费加速技巧：直接用 $\bar x_k = \frac1k\sum_{i\le k}x_i$ 代替 $x_k$ 输出——对 $a_k = c/\sqrt{k}$ 的步长，平均后达到 $O(1/k)$（比原始 $O(1/\sqrt k)$ 高一档）。

**「算得快」与「算得准」为什么不可兼得**：GD 每步要用全部 $n$ 个样本（贵但准），SGD 每步用一个样本（便宜但噪声大），小批量介于两者。用「计算量」而非「迭代数」衡量，结论更微妙：在总预算固定的前提下，**小批量通常比全批量更早达到给定精度**（每步成本低、步数多），而「最优批量」取决于「噪声对步长的限制」与「每步成本」的权衡——这就是机器学习里「大 batch 未必更好」的理论根源，也是下一节方差缩减（SVRG）要解决的问题。

## 3 工程步长规则

理论的 $1/k$ 在深度学习里很少直接用，工程上有更成熟的规则：

**分段衰减（step decay）**：训练到某个 epoch 数，学习率乘一个因子（如 $\times 0.1$）。简单、可预测，实践中很常用。
**余弦退火（cosine annealing）**：学习率按余弦曲线从大平滑衰减到 0——无参数、效果好，配合 warm restart 是 SOTA 常客。
**Warmup**：开头几百步学习率从 0 线性涨到目标值——**防止初始大步长把参数炸飞**（尤其大 batch 与 Transformers）。
**自适应（Adam/AdaGrad）**：每参数独立步长，自动缩放——用「梯度二阶矩」估计噪声方差。<span class="marginnote">为什么理论 $1/k$ 工程不用？深度学习目标非凸、噪声非平稳、训练预算固定——「精确收敛到最优」不是目标，「在有限 epoch 内达到好泛化」才是。分段/余弦退火本质是「模拟 $1/k$ 的衰减、但更平滑更可控」。<strong>理论的 $1/k$ 是北极星，工程规则是航线。</strong></span>

**一条实用配方（现代 Transformer 训练的标准做法）**：

- **Warmup**：前 $T_w$ 步（如总步数的 1%）学习率从 0 线性涨到峰值 $\eta_{\max}$——避免初始参数远离最优时大步长震荡。
- **余弦衰减**：峰值后按 $\eta_k = \eta_{\min} + \tfrac12(\eta_{\max}-\eta_{\min})(1+\cos(\pi k/K))$ 平滑降到 $\eta_{\min}$——比分段衰减更平滑、通常泛化更好。
- **峰值学习率与 batch 的缩放律**：batch 翻倍，峰值学习率大致翻倍（线性缩放律）——这解释了「大 batch 要大学习率」。

这套配方没有魔法，它的每一步都在补「朴素 SGD 的洞」：warmup 补「初始爆炸」，余弦补「末期噪声」，缩放律补「批量变化」。<span class="marginnote">对「从极限到大模型」的读者，这套配方就是你读大模型训练论文（LLaMA、GPT）时反复见到的「warmup + cosine」——<strong>把它读成「$1/k$ 平衡思想的工程化」，你就不会被超参数表吓到</strong>。</span>

## 4 公式解析：为什么 $1/k$ 是「最优」步长

用强凸二次模型把「$a_k = 1/(\mu k)$ 达到 $O(1/k)$」的机制算清楚。设 $f(x) = \frac\mu2\|x - x^*\|^2$（最简强凸），噪声梯度 $\nabla f + \xi$：

**第一步，递推方差**：$x_{k+1} = x_k - a_k\mu(x_k - x^*) - a_k\xi_k$，令 $e_k = x_k - x^*$，得 $e_{k+1} = (1 - a_k\mu)e_k - a_k\xi_k$。
**第二步，平方期望**：$E\|e_{k+1}\|^2 = (1-a_k\mu)^2 E\|e_k\|^2 + a_k^2 E\|\xi_k\|^2$（噪声独立交叉项为零）。
**第三步，选 $a_k$ 平衡两项**：第一项 $\approx (1 - 2a_k\mu)E\|e_k\|^2$（衰减），第二项 $a_k^2\sigma^2$（噪声注入）。最优 $a_k$ 让「衰减率 × 当前误差 ≈ 噪声注入」——解得 $a_k = 1/(\mu k)$，此时误差 $E\|e_k\|^2 = O(1/k)$。
**第四步，直觉**：**$1/k$ 恰好让「每步衰减的量」与「噪声注入的量」同阶**——比它大噪声主导（误差停在邻域），比它小衰减主导（太慢）。

**要点：$1/k$ 不是魔法，而是「衰减 vs 噪声」两种力量平衡的必然结果。** 这也是为什么它反复出现在所有随机优化的最优步长里。若噪声方差 $\sigma^2$ 与光滑常数 $L$ 都已知，最优常数其实是 $c = 1/\mu$；当 $\mu$ 未知时，用一个「与 $k$ 无关但随问题尺度定」的 $c$ 同样能收敛，只是常数项不是最优。

这个二阶递推的推导还顺便给出了一个观测：**误差的「收敛速率」由衰减项主导，而「最终精度」由噪声项主导**。所以当你看到 SGD 训练「前期下降快、后期震荡平」时，完全符合理论——前期衰减项占优、后期噪声项占优。若想让后期更准，正确动作不是「加大学习率」（会放大噪声），而是「让学习率继续衰减」或「增大批量」。

**用一个数字感受「平衡」**。设 $\mu = 1$、噪声方差 $\sigma^2 = 4$、初始误差 $E\|e_0\|^2 = 100$。若取固定步长 $a = 0.1$：每步衰减因子 $(1-a\mu)^2 = 0.81$，噪声注入 $a^2\sigma^2 = 0.04$。误差收敛到固定点 $0.04/(1-0.81) \approx 0.21$——**停在邻域**，不会更准。若取 $a_k = 1/k$：第 $k$ 步噪声注入 $1/k^2 \cdot 4$，累计到第 1000 步约 $\sum 4/k^2 \approx 4 \times 1.64 \approx 6.6$，而衰减项把初始误差指数压到近 0——总误差 $O(1/k)$，能无限制地趋近最优。**固定步长给你一个「精度天花板」，衰减步长把天花板掀掉**——这就是工程上「先固定、后衰减」的数学原因。<span class="marginnote">实践中常见做法：先用固定或常数学习率跑到接近最优的邻域，再切换到衰减步长继续逼近——两者结合 = 「先用大学习率快速逼近，再用小学习率精确落地」，这正是 warmup + cosine 的雏形。</span>

## 5 步长规则速查

| 规则 | 公式 | 性质 |
| --- | --- | --- |
| 固定 | $a_k = a$ | 邻域收敛，误差 ~ $a$ |
| 衰减 | $a_k = c/k$ | 精确收敛，强凸 $O(1/k)$ |
| 慢衰减 | $a_k = c/\sqrt{k}$ | 非强凸稳，配合平均 |
| 分段衰减 | 每 epoch 乘 $\gamma$ | 工程常用，简单 |
| 余弦退火 | $\cos$ 曲线 | 平滑、SOTA |
| 自适应（Adam） | 每参数量纲化 | 免调、快但泛化有争议 |

**术语速查：**

| 术语 | 含义 | 一句话记忆 |
| --- | --- | --- |
| 学习率/步长 | 每步沿梯度走的距离 | 方向盘 |
| RM 条件 | $\sum a_k=\infty$、$\sum a_k^2<\infty$ | 走得远且不飘 |
| 邻域收敛 | 固定步长停在最优附近 | 精度天花板 |
| 精确收敛 | 衰减步长误差 $\to 0$ | 无限逼近 |
| 迭代平均 | Polyak–Ruppert 平均输出 | 免费加速 |
| 分段衰减 | 每 epoch 乘 $\gamma$ | 阶梯下降 |
| 余弦退火 | $\cos$ 平滑衰减 | 平滑落地 |
| Warmup | 开头从 0 涨到峰值 | 防爆炸 |
| 线性缩放律 | batch 翻倍学习率翻倍 | 大 batch 大学习率 |

**辨析｜易错点：**其一，**固定学习率不精确收敛**——看到训练后期 loss 震荡，是噪声在平衡点抖动，不是 bug；其二，**学习率太大崩、太小慢**——「损失曲线变平 + 梯度爆炸」先查学习率；其三，衰减配合 warmup 才稳（尤其大模型），别从大学习率直接跳；其四，Adam 的自适应步长「免调」不等于「最优」——它的泛化常逊于调好的 SGD，需按任务权衡；其五，**步长序列比步长初值更重要**——同样的峰值学习率，不同的衰减计划（cos vs 分段 vs 不衰减）收敛结果差异显著，调参先选计划再调峰值；其六，**看 loss 曲线的形状而不是只看数值**——「平坦期突然又降」往往是步长从大区间进入新区间的正常现象，别误判为过拟合。<span class="marginnote">在「从极限到大模型」里，学习率调度是训练大模型的关键手艺：GPT/BERT 系的经典配方「warmup + cosine」、以及「batch size 与学习率的线性缩放律」都是本节理论的工程化。<strong>理解「$1/k$ 的平衡」，就理解了一切学习率调度的底层逻辑。</strong></span>

## 6 小结

- **步长三档**：固定（邻域收敛）、$1/k$（精确、$O(1/k)$）、$1/\sqrt k$（非强凸稳）。
- **噪声代价**：SGD 把强凸的线性收敛降为 $O(1/k)$——批量越大越接近 GD。
- **迭代平均**：Polyak–Ruppert 免费把 $1/\sqrt k$ 提到 $1/k$。
- **工程规则**：分段衰减、余弦退火、warmup——平滑可控的 $1/k$ 模拟。
- **本质**：$1/k$ 是「衰减 vs 噪声」平衡的必然结果。
- **配方**：warmup + cosine + 线性缩放律 = 现代 Transformer 训练的标准学习率配置。
- **数值直觉**：固定步长给你「精度天花板」（误差 ~ $a$），衰减步长把天花板掀掉——先固定逼近、再衰减落地。
- **与主线相连**：理解「$1/k$ 平衡」就理解了一切学习率调度——这是从 Robbins–Monro 到大模型训练配方之间那条贯穿全书的线。
- **一句话复盘**：步长不是「越大越好」也不是「越小越好」，而是「让衰减与噪声在每一步同阶」——$1/k$ 就是这个平衡的解析解，一切工程调度都在逼近它。
