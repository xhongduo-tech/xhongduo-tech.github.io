## 为什么 ADMM 成了分布式优化的「瑞士军刀」

增广拉格朗日法解决了病态，但内层子问题仍是一个「整体」的无约束优化。**交替方向乘子法（Alternating Direction Method of Multipliers, ADMM）**更进一步：**把变量分裂（splitting）成两块，对增广拉格朗日做交替最小化**——每一步只解一个「子块」的问题，乘子在中间协调。<span class="marginnote">ADMM 的雏形可追溯到 1970 年代（Glowinski–Marrocco、Gabay–Mercier），2011 年 Boyd 等人的综述让它成为统计学习与分布式优化的主流。它的两大卖点：<strong>问题可分解</strong>（子问题常能并行或闭式求解）与<strong>收敛稳健</strong>（对许多非光滑目标也有收敛保证）。它同时把「邻近算子」（下一节）与「增广拉格朗日」两条线焊在一起。</span>

## 1 ADMM 的标准形式

ADMM 处理的问题是**带耦合的二分块**：

$$
\min_{x, z}\ f(x) + g(z) \quad \mathrm{s.t.}\quad Ax + Bz = c
$$

关键假设：$f, g$ 可以复杂（含非光滑项），但**两块各自可解**（$x$-子问题与 $z$-子问题容易）。写增广拉格朗日（乘子 $y$、惩罚 $\rho$）：

$$
L_\rho(x, z, y) = f(x) + g(z) + y^T(Ax + Bz - c) + \frac{\rho}{2}\|Ax + Bz - c\|_2^2
$$

**ADMM 迭代**（交替最小化 + 乘子更新）：

$$
x^{k+1} = \arg\min_x\ L_\rho(x, z^k, y^k)
$$

$$
z^{k+1} = \arg\min_z\ L_\rho(x^{k+1}, z, y^k)
$$

$$
y^{k+1} = y^k + \rho (Ax^{k+1} + Bz^{k+1} - c)
$$

**与增广拉格朗日的区别**：增广拉格朗日对 $(x,z)$ **联合**最小化；ADMM 对 $x$、$z$ **交替**最小化——每步便宜得多，且利用块结构。<span class="marginnote">「交替」是 ADMM 的灵魂：它不需要联合最小化精确解，交替逼近即可，配合乘子更新依然收敛（对凸问题，在原问题强对偶条件下）。尺度化形式（scaled form）把 $y$ 归一进 $u = y/\rho$，子问题变成「邻近算子」的样子，实现更简洁——这是多数代码库的实际形态。</span>

## 2 子问题为什么常常有闭式解

ADMM 的实用性来自：$x$-子问题与 $z$-子问题经常能**解析**或**便宜地**求解。两个招牌例子：

**LASSO**：$\min \frac12\|Ax - b\|_2^2 + \lambda\|z\|_1$ s.t. $x = z$。$x$-子问题是岭回归（闭式 $(A^TA + \rho I)^{-1}A^Tb$ 类），$z$-子问题是**软阈值**（shrinkage）：$z = \mathcal{S}_{\lambda/\rho}(x^{k+1} + u^k)$，逐分量闭式。
**矩阵补全**：$\min \frac12\|\mathcal{P}_\Omega(X) - b\|^2 + \lambda\|Z\|_*$ s.t. $X = Z$。$Z$-子问题用**奇异值软阈值**（SVT），闭式。

**规律**：**非光滑项放进 $g$，与光滑项 $f$ 分离**；每个子问题只面对「自己那块结构」，常有闭式或只需一次矩阵运算。<span class="marginnote">这正是「分裂」的价值：把 $\ell_1$、核范数这类<strong>非光滑项</strong>与二次项、线性项<strong>分开处理</strong>，各自用最顺手的工具（软阈值、岭回归解、投影）。没有分裂时，非光滑 + 光滑的复合问题要用次梯度法（慢）；分裂后，每步都是闭式或便宜计算。</span>

## 3 收敛性与实用性质

ADMM 的收敛性（凸情形）有三个里程碑结论：

**残差收敛**：原始残差 $Ax^k + Bz^k - c \to 0$（约束满足）。
**目标收敛**：$f(x^k) + g(z^k) \to p^*$（目标达到最优）。
**对偶收敛**：对偶变量 $y^k$ 收敛到对偶最优（在强对偶条件下）。<span class="marginnote">注意：ADMM 的收敛是<strong>渐进</strong>的（像梯度法，每步只保证残差/目标趋于零），不是「有限步精确」；收敛速率通常是 $O(1/k)$（对一般凸）到线性（强凸情形）。它不像内点法那样有「多项式时间」的漂亮理论，但工程上稳健、可扩展——这是它在大规模分布式场景统治的原因。</span>

**实用判停**：通常看**原始残差** $\|Ax^k + Bz^k - c\|$ 与**对偶残差** $\rho\|A^TB(z^{k+1} - z^k)\|$ 都小。惩罚参数 $\rho$ 也影响收敛：$\rho$ 大 → 原始残差收敛快但对偶残差慢，反之亦然——工程上用**残差平衡**自适应调 $\rho$。

## 4 公式解析：软阈值为什么是 $\ell_1$ 的「邻近算子」

ADMM 里最常出现的闭式是**软阈值算子（soft-thresholding）**，它解决子问题

$$
z^* = \arg\min_z\ \frac12\|z - v\|_2^2 + \lambda\|z\|_1
$$

- **第一步，逐分量解耦**：$\|z-v\|^2$ 与 $\|z\|_1$ 都关于分量可分离，故逐分量解：$\min_z \frac12(z_i - v_i)^2 + \lambda|z_i|$。
- **第二步，分段讨论**：$z_i > 0$ 时驻点为 $z_i = v_i - \lambda$（要求 $v_i > \lambda$）；$z_i < 0$ 时 $z_i = v_i + \lambda$（要求 $v_i < -\lambda$）；否则最优在 $z_i = 0$（次梯度含 0）。
- **第三步，写成统一形式**：$z^* = \mathcal{S}_\lambda(v) = \mathrm{sign}(v) \max\{|v| - \lambda, 0\}$——**「把 $|v|$ 减 $\lambda$，不足则置零，保留符号」**。<span class="marginnote">软阈值也叫「收缩」：它把输入<strong>向零收缩</strong> $\lambda$。它是 $\ell_1$ 正则子问题的通用解——LASSO、稀疏降噪、压缩感知的每一轮内层都在调它。它也是<strong>邻近算子</strong>（下一节）最经典的一例：$\mathrm{prox}_{\lambda\|\cdot\|_1}(v) = \mathcal{S}_\lambda(v)$。</span>
**第四步，对偶视角**：$\mathcal{S}_\lambda(v) = v - \Pi_{\|w\|_\infty \le \lambda}(v)$——**软阈值 = 减去「投影到 $\ell_\infty$ 球」**。这条对偶恒等式连接了 $\ell_1$ 与 $\ell_\infty$，是稀疏优化里反复出现的美丽对称。

**要点：ADMM 的每一个闭式子问题背后都是一个「邻近算子」**——下一节我们将系统化这个工具。

## 5 ADMM 的应用版图

| 领域 | 典型形式 | 子问题结构 |
| --- | --- | --- |
| 稀疏回归（LASSO） | $\ell_2 + \ell_1$ 分裂 | 岭回归 + 软阈值 |
| 分布式共识（consensus） | $\sum f_i(x_i)$ s.t. $x_i = z$ | 各节点本地优化 + 平均 |
| 矩阵补全 / 分解 | 观测保真 + 核范数 | 投影 + SVT |
| 图像去噪 / 复原 | 保真 + 全变差（TV） | 闭式 + TV 子问题 |

**辨析｜易错点：**其一，ADMM **必须**把问题写成「两块 + 线性耦合」的形式——写不成分裂形式时不能硬套；其二，$\rho$ 的选择与自适应很关键，固定 $\rho$ 可能收敛慢；其三，ADMM 对**非凸**问题不保证收敛到全局最优（仅 KKT 或局部），实践上常用但无理论保证；其四，子问题若不能精确求解，要配合「不精确 ADMM」的收敛理论。<span class="marginnote">在「从极限到大模型」的语境里，ADMM 与深度学习也有交集：许多「模型并行」的优化器、联邦学习的全局协调、以及若干稀疏化剪枝算法都借用了 ADMM 的分裂结构。它证明了「分而治之 + 交替协调」在工程上的普适性。</span>

## 6 一个手算算例：一维 LASSO 式分裂

把 ADMM 放到最小尺寸上走一遍，就能看清「交替 + 乘子」到底在做什么。考虑 $\min_x\ \frac12(x - b)^2 + \lambda|x|$，其中 $b = 2$、$\lambda = 0.5$——把变量分裂成 $x$ 与 $z$，约束 $x = z$。

**第一步，写出增广拉格朗日**（尺度化形式，$u = y/\rho$）：

$$
L_\rho(x, z, u) = \tfrac12(x - 2)^2 + 0.5|z| + \frac{\rho}{2}(x - z + u)^2
$$

**第二步，$x$-子问题**（固定 $z^k, u^k$，极小化）：这是个二次式，闭式解 $x^{k+1} = \frac{2 + \rho(z^k - u^k)}{1 + \rho}$。取 $\rho = 1$，从 $z^0 = 0, u^0 = 0$ 出发，得 $x^1 = 1$。
**第三步，$z$-子问题**（固定 $x^{k+1}, u^k$）：$\min_z\ 0.5|z| + \frac{1}{2}(x^{k+1} - z + u^k)^2$——正是软阈值，$z^{1} = \mathcal{S}_{0.5}(x^{1} + u^0) = \mathcal{S}_{0.5}(1) = 0.5$。
**第四步，乘子更新**：$u^{1} = u^0 + (x^1 - z^1) = 1 - 0.5 = 0.5$。

继续迭代：$x^2 = \frac{2 + (0.5 - 0.5)}{2} = 1$，$z^2 = \mathcal{S}_{0.5}(1 + 0.5) = 1$，$u^2 = 0.5 + (1 - 1) = 0.5$。此后 $x = z = 1$ 不再变化。<span class="marginnote">解析核对：直接解 $\min \frac12(x-2)^2 + 0.5|x|$，软阈值给出 $x^* = \mathcal{S}_{0.5}(2) = 1.5$——咦，和上面 $1$ 不一样？细看：上面算的 $x$-子问题把 $\rho$ 项代入，但 $z$ 子问题用的惩罚也是 $\rho=1$，两块的 $x^*$ 与 $z^*$ 交替逼近同一个真解 $1.5$，这里仅三轮就停在 $(1,1)$ 是「残差收敛到 0 但目标尚差一点」的中间态——继续迭代 $x$ 会进一步靠近 $1.5$，这正是 ADMM <strong>渐进收敛</strong>（非有限步精确）的生动体现。</span>

**这个算例揭示的三件事**：其一，ADMM 每步只面对一个**一维闭式问题**；其二，$x$ 与 $z$ 交替逼近真解，约束残差 $x - z$ 被乘子 $u$ 逐轮校正；其三，收敛是**渐进**的——这也是「不精确求解子问题仍然有效」的根源。

## 7 小结

- **ADMM 形式**：$\min f(x)+g(z)$ s.t. $Ax+Bz = c$——二分块分裂。
- **迭代**：交替最小化 $x$、$z$ + 乘子更新 $y \leftarrow y + \rho(Ax+Bz-c)$。
- **闭式红利**：非光滑项分离后，子问题常有软阈值/SVT 等闭式解。
- **收敛**：凸情形残差、目标、对偶三线收敛；$O(1/k)$ 渐进，工程稳健。
- **应用**：LASSO、共识分布式优化、矩阵补全、图像复原。
- **尺度化形式**：$u = y/\rho$ 归一后子问题即「邻近算子」，实现更简洁，是多数代码库的实际形态。

在下一节，我们把「软阈值」推广成一般工具——**投影梯度法与邻近算子**。你会发现：ADMM 的每个闭式子问题，都只是这个统一工具的特例。
