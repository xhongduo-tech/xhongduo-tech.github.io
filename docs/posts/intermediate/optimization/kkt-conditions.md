## 为什么 KKT 是「一站到底」的最优性判据

到此为止，我们已经拥有了最优性的全部零件：一阶条件（梯度为零）、可行性、$\lambda \ge 0$、互补松弛。把它们拼成一张完整的清单，就是**KKT 条件**——以 Karush、Kuhn、Tucker 三人命名的、带约束优化最核心的定理。<span class="marginnote">KKT 条件的地位怎么强调都不过分：对凸问题，它是「最优解」的<strong>充要</strong>判据；对非凸问题，它是必要条件。几乎所有约束优化算法（SQP、内点法、积极集法）都在「逼近 KKT」的意义上工作——求解器返回「满足 KKT 到容差」的点，就相当于交出了最优性证书。</span>本节把 KKT 完整陈述，并严格区分必要性与充分性两条路。

## 1 KKT 条件的完整陈述

考虑光滑优化问题

$$
\min_x\ f_0(x) \quad \mathrm{s.t.}\quad f_i(x) \le 0,\ h_j(x) = 0
$$

**KKT 条件**指下列四组关系同时成立：

1. **驻点性（stationarity）**：

$$
\nabla f_0(x) + \sum_{i=1}^{m} \lambda_i \nabla f_i(x) + \sum_{j=1}^{p} \nu_j \nabla h_j(x) = 0
$$

2. **原始可行性（primal feasibility）**：$f_i(x) \le 0$、$h_j(x) = 0$。
3. **对偶可行性（dual feasibility）**：$\lambda_i \ge 0$。
4. **互补松弛（complementary slackness）**：$\lambda_i f_i(x) = 0$。

满足四组的 $(x^*, \lambda^*, \nu^*)$ 称为**KKT 点**。<span class="marginnote">驻点性是把「无约束时梯度为零」推广到带约束：目标梯度与激活约束梯度必须「平衡」——这正是拉格朗日函数 $L$ 关于 $x$ 的梯度为零：$\nabla_x L = 0$。回忆无约束 QP 的 $Px^* + q = 0$，那就是 KKT 驻点性在无约束下的特例。</span>KKT 点把「最优解」这个几何概念，翻译成一组**代数方程 + 不等式**，而后者是算法可以直接操作的。

## 2 必要性：最优解 ⇒ KKT

**必要性定理（KKT necessary conditions）**：若 $x^*$ 是**局部最优解**，且在 $x^*$ 处**某种约束品性（CQ）成立**（如 LICQ、MFCQ；凸问题常用 Slater），则存在乘子 $(\lambda^*, \nu^*)$ 使 $(x^*, \lambda^*, \nu^*)$ 满足 KKT 条件。

为什么需要 CQ？回顾上一节的推理：最优解处，目标梯度必须落在激活约束梯度的锥组合里（Farkas 引理的形式）。若激活约束梯度线性相关（CQ 失败），这个「落在锥里」的结论可能不成立，驻点性随之失效。<span class="marginnote">必要性的直觉：在最优解处，没有任何可行的「下降方向」存在。把「无可行下降方向」用 Farkas 引理翻译成「$-\nabla f_0$ 属于激活约束梯度的锥」，就得到驻点性与互补松弛。CQ 是这条翻译的「技术许可」。</span>

**辨析｜易错点：**必要性**不是充要**。非凸问题里，KKT 点可能是鞍点或局部极大——满足 KKT 不等于最优。反例：$\min x^3$ s.t. $x \ge -1$，$x=0$ 处 KKT 满足（$\lambda=0$、$3x^2=0$），但 $x=0$ 既不是极小也不是极大——它是驻点，KKT 照常成立。

## 3 充分性：凸问题里 KKT ⇒ 最优

对**凸优化问题**，方向反转：

**充分性定理（KKT sufficient conditions）**：若 $f_0, f_i$ 可微且凸、$h_j$ 仿射，且 $(x^*, \lambda^*, \nu^*)$ 满足 KKT 条件，则 $x^*$ 是**全局最优解**。

证明只需三行：

- **第一步，从驻点性出发**：$0 = \nabla_x L(x^*, \lambda^*, \nu^*) = \nabla f_0(x^*) + \sum_i \lambda_i^* \nabla f_i(x^*) + \sum_j \nu_j^* \nabla h_j(x^*)$。
- **第二步，用凸一阶条件**：凸函数 $f_0$ 满足 $f_0(x) \ge f_0(x^*) + \nabla f_0(x^*)^T(x - x^*)$，对 $f_i$ 同理。
- **第三步，代入整理**：对所有可行 $x$，把三个凸不等式组合起来，利用 $f_i(x) \le 0$、$\lambda_i^* \ge 0$、$h_j(x)=0$ 与互补松弛，得到 $f_0(x) \ge f_0(x^*)$——**任意可行点不优于 $x^*$，$x^*$ 全局最优**。

**合起来**：对凸问题，在 Slater/LICQ 下，KKT 条件与「$x^*$ 是全局最优」**完全等价**。这就是为什么凸优化的求解 = 求 KKT 点：**找到一个满足这四组条件的点，就拿到了全局最优的完整证书。**

## 4 公式解析：用 KKT 解一个完整例子

把 KKT 用于实际求解。解

$$
\min_{x_1, x_2}\ (x_1 - 2)^2 + (x_2 - 1)^2 \quad \mathrm{s.t.}\quad x_1^2 + x_2^2 \le 1
$$

- **第一步，写拉格朗日与驻点性**：$L = (x_1-2)^2 + (x_2-1)^2 + \lambda(x_1^2 + x_2^2 - 1)$。驻点性：

$$
\begin{cases}
2(x_1 - 2) + 2\lambda x_1 = 0 \\
2(x_2 - 1) + 2\lambda x_2 = 0
\end{cases}
\quad\Rightarrow\quad
x_1 = \frac{2}{1+\lambda},\quad x_2 = \frac{1}{1+\lambda}
$$

- **第二步，互补松弛两种分支**：若 $\lambda = 0$，$x=(2,1)$，但 $\|x\|_2^2 = 5 > 1$ 违反可行性——弃。故 $\lambda > 0$，互补松弛要求 $x_1^2 + x_2^2 = 1$。
- **第三步，代入求 $\lambda$**：$\left(\frac{2}{1+\lambda}\right)^2 + \left(\frac{1}{1+\lambda}\right)^2 = 1 \Rightarrow \frac{5}{(1+\lambda)^2} = 1 \Rightarrow \lambda = \sqrt{5} - 1 > 0$。
- **第四步，还原最优解**：$x_1^* = \frac{2}{\sqrt5}$、$x_2^* = \frac{1}{\sqrt5}$，$\lambda^* = \sqrt5 - 1$。验证可行性 $\|x^*\|^2 = 1$ 与互补松弛——全部满足。

**这个例子的方法论：KKT 求解 = 猜互补松弛的分支（激活/不激活）→ 解代数系统 → 验证所有不等式。** 分支判断是唯一「智能」环节，其余全是机械计算。若约束不激活（$\lambda=0$）也能出解，就要检查它是否真的可行——本例正是靠这一步否掉了 $\lambda=0$ 分支。

## 5 KKT 与算法的关系

KKT 条件不是终点，而是所有约束优化算法的**目标函数**：

- **内点法**：构造一族 KKT 系统的「中心路径」，随障碍参数趋于零逼近 KKT 点。
- **SQP（序列二次规划）**：每轮解一个 QP，其 KKT 系统是原 KKT 系统的牛顿线性化。
- **积极集法**：猜激活集，把互补松弛替换成等式，解线性 KKT 系统。
- **增广拉格朗日 / ADMM**：交替更新原始/对偶变量，最终收敛到 KKT 点。<span class="marginnote">第四篇内点法、第五篇无约束、第六篇约束优化、第七篇 QP——全书的算法章节都可以看作「不同路径走向同一个 KKT 点」。理解 KKT，等于理解了全书算法的心脏。这也是为什么本节值得反复读。</span>

## 6 速查与辨析

| 情形 | 最优 ⇒ KKT？ | KKT ⇒ 最优？ |
| --- | --- | --- |
| 一般光滑 + CQ | 是（局部最优） | 否（可能鞍点） |
| 凸 + 可微 | 是（Slater 等） | 是（全局最优） |
| LP（全仿射） | 是 | 是 |

**辨析｜易错点：**四个高频错误：其一，忘了 $\lambda \ge 0$（对偶可行性）——缺它，驻点性可能选到「不合法」的乘子；其二，互补松弛只对不等式约束，等式约束没有 $\nu_j h_j = 0$ 这项；其三，把 KKT 当充要用于非凸问题——只有凸问题才双向；其四，可微性是前提——$|x|$ 这类不可微点要用次梯度 KKT，这里不适用。

## 7 小结

- **KKT 四件套**：驻点性、原始可行性、对偶可行性（$\lambda \ge 0$）、互补松弛。
- **必要性**：局部最优 + CQ（LICQ/Slater）⇒ KKT；非凸下 KKT 点可能是鞍点。
- **充分性**：凸 + 可微下 KKT ⇒ 全局最优；凸问题中「最优」与「KKT 点」等价。
- **KKT 求解法**：猜互补松弛分支 → 解代数系统 → 验证可行性。
- **算法视角**：内点法、SQP、积极集法都是「逼近 KKT」的路径。
- **易错点**：$\lambda \ge 0$ 不能丢；互补松弛只属不等式；可微性前提要满足。
