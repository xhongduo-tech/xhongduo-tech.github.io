## 为什么幂函数值得一个专属章节

工程里大量「设计尺寸」的问题——电路里的晶体管宽度、结构里的梁截面、网络里的带宽分配——目标与约束都写成**幂函数的乘积与和**：面积 = 长 × 宽，功耗 = 电压² × 电阻倒数，时间 = 距离 × 速度⁻¹。这些函数不是线性的，也不是二次的，但它们有一个共同点：**取对数之后会变「乖」**。**几何规划（Geometric Programming, GP）**正是抓住这个共性的一族问题：它在原始变量下非凸，但通过换元 $x_i = e^{y_i}$ 变成凸优化。<span class="marginnote">「几何」这个名字来自早期发展：问题里每一项都是幂积（monomial），研究它的文献最早关注几何平均值。今天 GP 的用武之地在芯片设计（模拟电路自动尺寸优化）、航空（机翼几何）、结构工程（桁架优化），是现代工程设计自动化的核心建模语言之一。</span>

## 1 单项式与正项式

GP 的积木是两类函数。

**单项式（monomial）**：$f(x) = c x_1^{a_1} x_2^{a_2} \cdots x_n^{a_n}$，其中 $c > 0$、指数 $a_i$ 是任意实数（可负、可非整数），定义域 $x > 0$。<span class="marginnote">单项式的名称与多项式的「单项式」同源，但指数不必是非负整数——这里 $x_1^{-2}x_2^{0.5}$ 也是合法的单项式。$c>0$ 与 $x>0$ 的正性要求，是 GP 能在对数域变凸的前提。</span>

**正项式（posynomial）**：若干单项式的**非负和**：$f(x) = \sum_k c_k x_1^{a_{1k}} \cdots x_n^{a_{nk}}$，$c_k > 0$。它是「系数为正的若干幂积之和」——面积、功耗、延迟这类「正量加总」的函数都是正项式。

**辨析｜易错点：**正项式的**减法**不属于正项式。$x_1^2 - x_1 x_2$ 含有负系数项，是「符号多项式（signomial）」——符号多项式的优化通常是 NP-hard 的。GP 的一切理论都建立在「只有加法、系数全正」上。

## 2 GP 的标准形式与对数换元

GP 的标准形式是

$$
\begin{aligned}
\min_x \quad & f_0(x) \\
\mathrm{s.t.} \quad & f_i(x) \le 1, \quad i = 1, \ldots, m \quad (f_i \text{ 正项式}) \\
& g_j(x) = 1, \quad j = 1, \ldots, p \quad (g_j \text{ 单项式})
\end{aligned}
$$

**为什么能化成凸问题？** 关键换元 $x_i = e^{y_i}$：

- 单项式取对数：$\log(c x_1^{a_1}\cdots x_n^{a_n}) = a^T y + \log c$——变成 **$y$ 的仿射函数**。
- 正项式取对数：$\log\left(\sum_k e^{a_k^T y + b_k}\right)$——这正是**log-sum-exp 函数**，第一篇证明过它凸！<span class="marginnote">全篇的伏笔在此收网：《常见凸函数》里的 log-sum-exp 当初看似抽象，如今正是 GP 换元后目标的标准形状。前文的字母表在这里变成 GP 的骨架。</span>

于是换元后的 GP 是：**线性目标（若 $f_0$ 是单项式）+ log-sum-exp 不等式 + 仿射等式**——一个凸优化问题。GP 就这样「免费」拿到了凸性的全部保证。

## 3 公式解析：把正项式约束变凸

把最关键的改写拆成三步。原约束 $f(x) = \sum_k c_k x_1^{a_{1k}}\cdots x_n^{a_{nk}} \le 1$：

**第一步，取对数**：$\log\left(\sum_k c_k e^{a_{1k}y_1 + \cdots + a_{nk}y_n}\right) \le 0$。定义 $A_{ki} = a_{ik}$、$b_k = \log c_k$，改写为 $\log\left(\sum_k e^{A_{k\cdot}y + b_k}\right) \le 0$。
**第二步，识别凸性**：左边是 log-sum-exp 在仿射变换下的复合——第一篇与《保凸运算》证明过它凸，因此这是一条**凸不等式**约束。
**第三步，可微形式**：log-sum-exp 光滑可微，梯度与 Hessian 都有闭式（Softmax 结构），内点法可以精确处理它。

**直觉总结：换元把「幂指数乘法」变成「内积」，把「加法」变成「log-sum-exp」，GP 的整个复杂性被对数吸收。** 原本在 $x>0$ 域上非凸的问题，在 $y$ 域上变成一碗标准的凸汤。

## 4 GP 的典型建模

GP 建模有一套约定俗成的配方，三类最常见：

**尺寸 / 缩放问题**：约束「功耗 ≤ 预算」「时延 ≤ 指标」写成正项式不等式；目标「最小化总面积」是单项式。芯片的晶体管尺寸自动设计几乎都是 GP。
**结构优化**：桁架的每根杆件承重、应力、变形都是单项式/正项式，GP 给出全局最优的截面尺寸。
**不等式系统与可行性**：很多「物理可实现性」检验本身是正项式不等式组，直接落进 GP 求解。<span class="marginnote">一个细节：等式约束必须是<strong>单项式</strong> $=1$ 而非正项式——正项式等式 $\sum_k c_k x^{a_k} = 1$ 取对数后变成 log-sum-exp = 0，是非凸的。建模时把正项式等式拆成两条不等式时也要小心。</span>

**广义 GP（generalized GP）**允许正项式等式，但通过引入新变量与不等式处理；也允许「正项式之间取 max」等扩展。这些扩展多数仍能换元回凸或拟凸框架。

## 5 GP 速查与辨析

| 术语 | 定义 | 取对数后 |
| --- | --- | --- |
| 单项式 | $c x^a$，$c>0$ | 仿射 |
| 正项式 | $\sum_k c_k x^{a_k}$，$c_k>0$ | log-sum-exp（凸） |
| 符号多项式 | 允许负系数 | 非凸 |
| GP 目标 | 正项式最小化 | 凸 |

**辨析｜易错点：**三个高频坑：其一，**负系数**项（符号多项式）混入会立刻毁掉凸性；其二，**等式约束**必须是单项式，写成正项式等式会非凸；其三，**变量必须为正**——GP 建模前先确保所有设计变量落在 $x>0$ 域，出现「可正可负」的量时先用平移或拆分处理。GP 的优雅建立在正性 + 加法的双重前提上，越界一步就失效。

## 6 数值算例：一个简单的尺寸设计问题

用最小尺寸的 GP 把换元走一遍。设计一个长方形容器，要求体积至少 1、表面积尽量小。设三边 $x_1, x_2, x_3 > 0$，目标表面积 $2(x_1x_2 + x_1x_3 + x_2x_3)$，约束体积 $x_1x_2x_3 \ge 1$。

**第一步，写正项式形式**：目标 $f_0 = 2x_1x_2 + 2x_1x_3 + 2x_2x_3$（正项式）；约束改写为 $x_1^{-1}x_2^{-1}x_3^{-1} \le 1$（单项式 $\le 1$）。
**第二步，换元** $x_i = e^{y_i}$：目标变 $2e^{y_1+y_2} + 2e^{y_1+y_3} + 2e^{y_2+y_3}$（log-sum-exp 的和仍是凸）；约束变 $e^{-y_1-y_2-y_3} \le 1$，即仿射不等式 $y_1 + y_2 + y_3 \ge 0$。
**第三步，对称性分析**：目标与约束关于三变量对称，最优在三边相等：$x_1 = x_2 = x_3 = t$。
**第四步，降为一维**：体积 $t^3 = 1$ 且最小化 $6t^2$ ⇒ $t = 1$，表面积 $= 6$。**这正是「立方体表面积最小」的经典结论，$x^* = (1,1,1)$、$p^* = 6$。**

**这个例子的两个要点**：其一，GP 换元后的凸性保证「对称 ⇒ 最优对称」这条推理是合法的；其二，真实 GP 问题没有这样的对称性，就靠内点法在 $y$ 域上数值求解——**换元 + 凸性保证了无论规模多大、初始点多差，求解器都能收敛到全局最优**。

**常见正项式配方**（建模时照着套）：

| 物理量 | 表达式 | 类型 |
| --- | --- | --- |
| 面积 | $w \times h$ | 单项式 |
| 功耗 | $C V^2 f$ | 单项式 |
| RC 延迟 | $R \cdot C$ | 单项式 |
| 总面积（多模块） | $\sum w_i h_i$ | 正项式 |
| 信噪比约束 | 信号 / 噪声 $\ge$ 阈值 | 改写为单项式不等式 |

| 环节 | 原始 $x$ 域 | 换元 $y$ 域 |
| --- | --- | --- |
| 单项式 | $c x^a$ | 仿射 $a^Ty + \log c$ |
| 正项式 | $\sum c_k x^{a_k}$ | log-sum-exp（凸） |
| 约束 | 正项式 $\le 1$ | 凸不等式 |
| 求解 | 直接上非凸（危险） | 内点法（全局收敛） |

## 7 小结

- **单项式 / 正项式**：$c x^a$ 与「正系数幂积之和」，GP 只允许它们。
- **核心换元**：$x_i = e^{y_i}$ 让单项式变仿射、正项式变 log-sum-exp（凸），GP 因此是「披着非凸外衣的凸问题」。
- **标准形式**：正项式 $\le 1$ + 单项式 $= 1$；等式约束必须是单项式。
- **工程应用**：芯片尺寸、结构桁架、带宽分配——正量加总类问题的建模母语。
- **易错点**：负系数（符号多项式）与正项式等式都会破坏凸性；变量须为正。
- **换元要点**：$x_i = e^{y_i}$ 把「幂积」变内积、把「正项式和」变 log-sum-exp——GP 的复杂性被对数吸收。
- **算例结论**：对称问题的最优必对称（立方体），这是凸性对「对称 ⇒ 最优对称」推理的背书。
- **工程母语**：尺寸/功耗/延迟/面积类「正量加总」问题，第一反应就该是「能不能写成 GP」。
