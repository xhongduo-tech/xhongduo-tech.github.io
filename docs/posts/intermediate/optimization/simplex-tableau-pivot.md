## 为什么需要一张「表」

上一节的换基迭代概念清晰，但每次都要重新算 $B^{-1}$，笨重。**单纯形表（simplex tableau）**把整个迭代包装成一张会自我更新的表格：每一行是一次行变换，每一次换基就是一次**转轴（pivot）**操作——本质是**高斯-若尔当消元**，用 $O(mn)$ 的机械运算取代重算逆矩阵。<span class="marginnote">单纯形表的价值不在理论，而在工程：它让每一次换基变成「选主元 → 行变换 → 读新解」的流水线，既快又不易错。理解表格的结构，等于掌握了单纯形法在纸笔时代能推广到工业规模的原因。</span>

## 1 单纯形表的结构

对标准形式 $\min c^Tx$ s.t. $Ax = b$、$x \ge 0$，从初始基 $B$ 出发，单纯形表长这样：

| 基变量 | $x_1$ | $x_2$ | $\cdots$ | $x_n$ | 右端 $b$ |
| --- | --- | --- | --- | --- | --- |
| $x_{B(1)}$ | | | | | $B^{-1}b$ 的第 1 行 |
| $\vdots$ | $B^{-1}A$ 的系数 | | | | $\vdots$ |
| $x_{B(m)}$ | | | | | $B^{-1}b$ 的第 m 行 |
| **检验行** | $\bar c_1$ | $\bar c_2$ | $\cdots$ | $\bar c_n$ | $-z$ |

表的左列列出当前基本变量，主体是 $B^{-1}A$（把基矩阵消成单位阵后的系数），右端是 $B^{-1}b$，最后一行是检验数 $\bar c$ 与当前目标值的相反数 $-z$。<span class="marginnote">检验行放在最后一行，是「目标方程的系数」：$z - c_B^TB^{-1}b = \sum \bar c_j x_j$。表格的每个元素都可以直接读出：基本变量列是单位向量，右端列是基本变量取值，检验行负值表示可改进。</span>**表格的构造本质：对增广矩阵 $[A \mid b]$ 做行变换，把基矩阵消成单位阵，同时把目标行消成检验数。**

## 2 转轴（pivot）运算

一次换基在表格上对应一次**转轴**：选定进基变量所在列与出基变量所在行交叉处的元素为**主元（pivot element）**，做高斯-若尔当消元把它变成 1、该列其他元素变成 0。

标准流程四步：

1. **选主元**：进基列中，用最小比值检验 $\min\{(B^{-1}b)_i / d_i : d_i > 0\}$ 选出基行，交叉处即主元 $d_r > 0$。
2. **主元归一**：把主元行整行除以 $d_r$，使主元变为 1。
3. **消元**：用主元行的倍数去加/减其他所有行（含检验行），使主元列的其他元素（含检验数）全部变 0。
4. **换基标注**：左列把 $x_r$ 换成 $x_j$，读新解（右端列）、新目标（检验行右端取反）。<span class="marginnote">注意检验行也要参与消元——检验数在换基后必须重新正确，否则下一步的最优性判定失效。这也是单纯形表区别于普通线性方程组消元的关键：<strong>每一行（含目标行）都被主元列洗一遍</strong>。</span>

**转轴的正确性**：整个操作是「对增广矩阵做初等行变换」，不改变方程组解集，只是把「当前基」从 $B$ 换成新基——几何上正是沿棱走到相邻顶点。

## 3 从表上读一切

会读表，就会用单纯形法。读法规则：

**基本解**：右端列对应基本变量取值；非基本变量为 0。
**目标值**：检验行最右格取反（$-z$ 的位置存的是 $-z$，所以 $z = -(\text{该值})$）。
**最优性**：检验行除右端格外全部 $\ge 0$，则当前解最优。
**无界性**：存在负检验数 $\bar c_j < 0$，但进基列 $d$ 所有分量 $\le 0$——最小比值不存在，目标可沿此方向无限下降，LP 无界。<span class="marginnote">「进基列全非正」= 沿该方向可行域无边界、目标持续下降 = 无界。这张表同时兼任「最优判定」与「无界探测」两个角色，是它工程实用的另一个原因。</span>

**辨析｜易错点：**初学最常犯的错：忘记把检验行右端取反；或者把「检验数非负」与「目标值最小」混淆——检验数是针对**非基本变量**的，基本变量对应的检验数恒为 0（因为基列是单位向量，消元后检验数必为 0），只看非基本变量的检验数即可。

## 4 公式解析：一次完整的转轴演算

用一个 2×4 例子把转轴全过程走一遍。问题

$$
\min\ -2x_1 - x_2 \quad \mathrm{s.t.}\quad x_1 + x_2 + x_3 = 4,\ \ 2x_1 + x_2 + x_4 = 6,\ \ x \ge 0
$$

初始基 $B = (A_3, A_4) = I$，初始表（已消元）：

| 基 | $x_1$ | $x_2$ | $x_3$ | $x_4$ | 右端 |
| --- | --- | --- | --- | --- | --- |
| $x_3$ | 1 | 1 | 1 | 0 | 4 |
| $x_4$ | 2 | 1 | 0 | 1 | 6 |
| 检验 | -2 | -1 | 0 | 0 | 0 |

- **第一步，选进基**：检验数最负是 $\bar c_1 = -2$，$x_1$ 进基，进基列 $d = (1, 2)^T$。
- **第二步，最小比值**：$\min\{4/1,\ 6/2\} = 3$，对应 $x_4$ 行——$x_4$ 出基，主元为 2。
- **第三步，转轴**：主元行除以 2 得 $(1, \frac12, 0, \frac12 \mid 3)$；用它消去 $x_1$ 列其他元素：$x_3$ 行减主元行，检验行加 $2\times$主元行。新表：

| 基 | $x_1$ | $x_2$ | $x_3$ | $x_4$ | 右端 |
| --- | --- | --- | --- | --- | --- |
| $x_3$ | 0 | $\frac12$ | 1 | $-\frac12$ | 1 |
| $x_1$ | 1 | $\frac12$ | 0 | $\frac12$ | 3 |
| 检验 | 0 | 0 | 0 | 1 | 6 |

- **第四步，读解**：$x_1 = 3$、$x_3 = 1$、$x_2 = x_4 = 0$，$z = -6$。检验行非基本变量 $\bar c_2 = 0$、$\bar c_4 = 1$ 全部 $\ge 0$——**最优**。

**一次转轴 = 选主元 + 高斯-若尔当 + 读表**。整个过程没有算一次矩阵逆，全是行操作——这就是单纯形表把理论变成流水线的秘诀。

## 5 单纯形表与大规模计算

纸笔时代，单纯形表让 LP 可以手工求解几十变量的题目；计算机时代，同样的逻辑被重写成**修订单纯形法（revised simplex）**：不维护整张表，只维护 $B^{-1}$（或它的 LU 分解）与检验数，一次迭代只更新一个方向向量——内存从 $O(mn)$ 降到 $O(m^2 + n)$，稀疏结构也得以保留。<span class="marginnote">现代求解器的单纯形实现几乎都是「修订版」：表是理解工具，修订是效率工具。理解表格的 pivot 逻辑，是读懂修订单纯形法一切细节的钥匙——两者在做同一件事，只是存储与更新的策略不同。</span>此外，退化处理（Bland、扰动）、反基（防止数值误差）都是围绕 pivot 展开的工程加固。

## 6 小结

- **单纯形表** = 消元后的增广矩阵 + 检验行，左列标注基变量。
- **读表**：右端列是基本解，检验行右端取反是目标值，检验数全非负即最优。
- **转轴四步**：选主元（最小比值）→ 主元归一 → 消元（含检验行）→ 换标注。
- **无界探测**：负检验数但进基列全非正 ⇒ LP 无界。
- **修订单纯形法**：只维护 $B^{-1}$，内存更省、稀疏更好，是工业实现。
