## 为什么从「把两点平均推广开」开始

回顾凸函数的定义，它说的其实只是一件事：**两个点的加权平均，函数值不超过函数值的加权平均**。两个点——这听起来平淡无奇。但把「两个点」换成「$n$ 个点」、换成「无穷多个点」、再换成「随机变量的期望」，这句话会摇身一变，成为整个数学里最强有力的不等式之一——**Jensen 不等式**。

琴生不等式的力量在于它是「永动机式的定理」：随便找一个凸函数，往里灌一个期望，就能产出一条漂亮的不等式。算术-几何平均不等式、柯西–施瓦茨不等式、信息论里 KL 散度非负、机器学习里 EM 算法与变分推断的下界，全都是它不同品种的化身。<span class="marginnote">为什么它如此「多产」？因为「凸函数」与「期望」都是线性（保加权平均）结构，而 Jensen 不等式恰好把这两个线性结构之间的次序钉死：<strong>期望可以穿过函数，但代价是方向必须顺着凸性</strong>。</span>这一课，我们先把琴生不等式本身吃透，再用它连推三个重量级结论，最后回到本博客主线——大模型训练里无处不在的 ELBO 下界。

## 1 有限形式的 Jensen 不等式

**Jensen 不等式（有限形式）**：设 $f$ 是凸函数，$x_1, \ldots, x_n \in \operatorname{dom} f$，权重 $\theta_1, \ldots, \theta_n \ge 0$ 且 $\sum_i \theta_i = 1$，则

$$
f\Big(\sum_{i=1}^{n} \theta_i x_i\Big) \;\le\; \sum_{i=1}^{n} \theta_i f(x_i)
$$

它就是把定义式从「两个点」推广到「$n$ 个点」。证明用归纳法，两句话：$n=2$ 时就是定义本身；$n > 2$ 时，把前 $n-1$ 项缩成一个点 $z = \frac{\sum_{i<n} \theta_i x_i}{1 - \theta_n}$（注意 $1 - \theta_n = \sum_{i<n} \theta_i$ 仍是非负权重和），对 $\{z, x_n\}$ 用两点定义，再对 $z$ 用 $n-1$ 情形的归纳假设即可。**归纳的每一步都在调用「平均点的函数值 ≤ 函数值的平均」，凸性就是最小公理。**<span class="marginnote">名字由来：Johan Jensen（约翰 · 琴生，1859—1925），丹麦数学家。他 1906 年发表的这篇文章把这个不等式正式确立，但不等式的雏形其实可以追溯到更早的 Hölder 等人。中文译名「琴生不等式」即来自 Jensen 的音译。</span>

**辨析｜易错点：权重必须是「凸组合」，即非负且和为 1。** 如果只要求 $\sum \theta_i = 1$ 但允许负权重（那是仿射组合），不等式立刻崩掉。反例：$f(x) = x^2$，取 $x_1 = 0$、$x_2 = 2$，权重 $\theta_1 = -1$、$\theta_2 = 2$（和为 1 但一负一正），左边 $f(-1 \cdot 0 + 2 \cdot 2) = f(4) = 16$，右边 $-1 \cdot 0 + 2 \cdot 4 = 8$，$16 \le 8$ 荒谬。**琴生只对「平均」负责，不负责「外推」——这再次呼应第一课「凸集允许平均、仿射集才允许外推」。**

## 2 期望形式与积分形式

把有限和推广到「按概率加权」，就得到概率论里的形式。设 $X$ 是取值在 $\operatorname{dom} f$ 内的随机变量，$f$ 凸，则

$$
f\big(\mathbb{E}[X]\big) \;\le\; \mathbb{E}\big[f(X)\big]
$$

**平均点的函数值，不超过函数值的平均——把「平均」换成「期望」，句子原封不动。** 这是第二级《概率论与数理统计》里期望的基本性质之一，也是统计学习里几乎一切「下界论证」的起点。更一般的积分形式对任意概率测度 $\mu$ 成立：

$$
f\Big(\int x \, d\mu\Big) \;\le\; \int f(x) \, d\mu
$$

为什么期望形式在统计里如此常用？因为它把「随机性」与「凸性」两个概念缝在一起：**取期望这个线性算子，无法压过凸函数的非线性——除非顺着凸的方向。** 凹函数则反向：若 $f$ 凹，则 $f(\mathbb{E}[X]) \ge \mathbb{E}[f(X)]$，例如 $\log$ 凹，所以 $\log \mathbb{E}[X] \ge \mathbb{E}[\log X]$——这个反向版本正是信息论里一切熵与互信息不等式的心脏。

## 3 公式解析：用 Jensen 推导 AM-GM 不等式

最经典的练兵场，是用琴生不等式推出初等不等式中的明珠——**算术-几何平均不等式（AM-GM）**：对正数 $x_1, \ldots, x_n$，

$$
\frac{x_1 + x_2 + \cdots + x_n}{n} \;\ge\; \big(x_1 x_2 \cdots x_n\big)^{1/n}
$$

算术平均不小于几何平均。初等证明要动点脑筋，而琴生版本几乎是「即插即用」。逐行拆解：

- **第一步，选凸函数**：取 $f(x) = -\log x$，定义域 $x > 0$。它的二阶导数 $f''(x) = \tfrac{1}{x^2} > 0$，由二阶条件 $f$ 是**严格凸函数**（见《凸函数的一阶条件与二阶条件》）。
- **第二步，灌琴生**：对 $x_1, \ldots, x_n$ 取等权重 $\theta_i = \tfrac1n$，代入有限形式：

$$
-\log\Big(\frac{x_1 + \cdots + x_n}{n}\Big) \;\le\; -\frac{1}{n}\big(\log x_1 + \cdots + \log x_n\big)
$$

- **第三步，翻符号**：两边同乘 $-1$，不等号反向：

$$
\log\Big(\frac{x_1 + \cdots + x_n}{n}\Big) \;\ge\; \frac{\log x_1 + \cdots + \log x_n}{n} = \log\big(x_1 \cdots x_n\big)^{1/n}
$$

- **第四步，指数化**：$\exp$ 单调递增，两边取指数：

$$
\frac{x_1 + \cdots + x_n}{n} \;\ge\; (x_1 \cdots x_n)^{1/n}
$$

  这正是 AM-GM。$\blacksquare$

**等号条件也免费奉送**：因为 $-\log$ 严格凸，琴生取等的充要条件是 $x_1 = x_2 = \cdots = x_n$——AM = GM 当且仅当所有数相等。**严格凸性把等号条件从「没有直线段贴在图像上」翻译成了「取等的权重分布必须集中在单点」**，这条对应关系在信息论里同样重要。

## 4 三个重量级应用

### KL 散度非负

信息论与机器学习里最常用的量是 **KL 散度** $D_{KL}(q \| p) = \mathbb{E}_{q}\big[\log \frac{q(X)}{p(X)}\big]$，它度量分布 $q$ 偏离 $p$ 的程度。证它非负只需一步琴生：

$$
-D_{KL}(q \| p) = \mathbb{E}_q\Big[\log \frac{p(X)}{q(X)}\Big] \;\le\; \log \mathbb{E}_q\Big[\frac{p(X)}{q(X)}\Big] = \log \int q(x) \frac{p(x)}{q(x)} dx = \log 1 = 0
$$

第一个 $\le$ 用的是**凹函数 $\log$ 的琴生反向版本**。于是 $D_{KL}(q\|p) \ge 0$，等号当且仅当 $q = p$ 几乎处处。这个「散度非负」是最大熵原理、变分推断、以及深度学习里一切用 KL 当正则项的设计的合法性来源。<span class="marginnote">小实验：取两个离散分布 $q = (0.6, 0.4)$、$p = (0.5, 0.5)$，$D_{KL} = 0.6\log(0.6/0.5) + 0.4\log(0.4/0.5) \approx 0.0201 \ge 0$；把 $q$ 换成 $p$ 本身则等于 0。琴生不是告诉你「它大于零」，而是告诉你「为什么它不可能小于零」。</span>

### EM 算法与变分推断的 ELBO

大模型与概率图模型里，对数边际似然 $\log p(x)$ 往往不可直接计算，因为要对隐变量积分。变分推断的核心技巧就是用琴生造一个可优化的**下界**：

$$
\log p(x) = \log \int p(x, z)\, dz = \log \mathbb{E}_{q(z)}\Big[\frac{p(x, Z)}{q(Z)}\Big] \;\ge\; \mathbb{E}_{q(z)}\big[\log p(x, Z) - \log q(Z)\big] =: \mathcal{L}(q)
$$

这个 $\mathcal{L}(q)$ 就是 **ELBO（证据下界，evidence lower bound）**。琴生保证了 $\log p(x) \ge \mathcal{L}(q)$，于是「最大化对数似然」被替换成「最大化 ELBO」——而 ELBO 的梯度可以用 Monte Carlo 估计，这正是 VAE 的训练方式，也是 EM 算法 E 步的实质。**没有琴生，就没有变分推断，也就没有一大半生成式大模型的基础**：VAE、扩散模型的变分目标，骨架都是这条不等式。<span class="marginnote">注意这里的 $q(z)$ 是任意的变分分布，琴生要求它非负且和为 1（归一化的概率分布）——所以 ELBO 里的 $q$ 必须是合法分布。把 ELBO 变形：$\log p(x) = \mathcal{L}(q) + D_{KL}(q\|p(\cdot|x))$，正好暴露了「琴生下界 + KL 非负」的孪生结构。</span>

### 方差不等式

最简单的应用之一：$f(x) = x^2$ 凸，所以 $\mathbb{E}[X^2] \ge (\mathbb{E}[X])^2$，即**方差非负** $\mathrm{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2 \ge 0$。以及 Jensen 在统计估计里的经典用法：如果 $\hat\theta$ 是 $\theta$ 的无偏估计，凸函数 $g$ 下 $g(\hat\theta)$ 一般**不是** $g(\theta)$ 的无偏估计——因为 $g$ 穿过期望会「压」出下界。这把「凸性」与「无偏性」的矛盾摆上了台面，是统计决策理论的常见起点。

## 5 辨析｜易错点

**辨析｜易错点一：凹函数必须反向。** $f$ 凹时是 $f(\mathbb{E}[X]) \ge \mathbb{E}[f(X)]$。做题时先判凹凸再选方向，这是琴生题里最大的失分点。$\log$、$\sqrt{\cdot}$、熵都是凹函数，方向天然相反。

**辨析｜易错点二：权重和为 1 但可负时琴生失效。** 见第 1 节的 $x^2$ 反例。琴生的舞台是凸组合；换成仿射组合（允许负权）不等式不再成立，这是它与「线性」的本质区别。

**辨析｜易错点三：取等条件由严格凸性决定。** 对非严格凸函数（如仿射函数），琴生可能处处取等；对严格凸函数，等号只在「所有 $x_i$ 相等」或「权重集中在单点」时发生。用琴生证明「$\ge$」时，如果想顺带证「$=$ 的充要条件」，必须依赖严格凸性——这正是 AM-GM 取等论证的关键。

**辨析｜易错点四：琴生给出的是「下界」，不是「等式」。** $\log p(x) = \mathcal{L}(q) + D_{KL}$ 才是等式；ELBO 只是下界。把 ELBO 当成了 $\log p(x)$ 本身、忘掉 KL 残差，是变分推断初学者最常犯的概念错误——「下界」与「目标」之间的缝隙，恰恰是拟合能力的来源。

```python
import numpy as np

def kl(q, p):
    q, p = np.asarray(q), np.asarray(p)
    return float(np.sum(q * np.log(q / p)))

q = np.array([0.6, 0.4]); p = np.array([0.5, 0.5])
print(kl(q, p))            # ≈ 0.0201 ≥ 0
print(kl(p, p))            # 0.0
# 随机生成 10000 组离散分布，KL 恒非负（数值噪声量级 < 1e-12）
rng = np.random.default_rng(0)
worst = min(
    kl(rng.dirichlet(np.ones(5)), rng.dirichlet(np.ones(5))) for _ in range(10000)
)
print(worst)               # 始终 ≥ -1e-12
```

## 6 小结

- **有限形式**：$f\big(\sum \theta_i x_i\big) \le \sum \theta_i f(x_i)$，权重非负且和为 1；归纳法从两点定义一步到位。
- **期望形式**：$f(\mathbb{E}[X]) \le \mathbb{E}[f(X)]$；凹函数反向——这是统计与信息论里一切下界/上界论证的枢纽。
- **AM-GM**：选严格凸的 $-\log$，灌等权琴生，翻号、指数化，算术平均 ≥ 几何平均，等号当且仅当全相等。
- **三大应用**：KL 散度非负；ELBO 下界撑起 VAE 与 EM；方差不等式 $\mathbb{E}[X^2] \ge (\mathbb{E}[X])^2$。
- **四道易错**：凹函数反向；权重必须是凸组合；取等靠严格凸性；琴生只是下界不是等式。

在下一节，我们暂时放下不等式，回到构造的舞台：盘点那些「一看就是凸」的常用函数，并学习怎么用**非负加权和、逐点取最大、复合规则**把已知凸函数拼成新的凸函数——那是建模时判断「我的目标函数凸不凸」最实用的一课。
