## 为什么「全批量梯度」在大数据时代不可行

梯度下降要求每步算全数据上的梯度 $\nabla f(x) = \frac1n\sum_i\nabla f_i(x)$——$n$ 是样本数。当 $n$ 以百万计、$f_i$ 是深网络时，一次全梯度计算就是一次全数据集扫描，每步代价 $O(n)$。**随机梯度下降（Stochastic Gradient Descent, SGD）**的赌注：**只用一个（或一小批）样本的梯度 $\nabla f_i(x)$ 就更新**，每步代价 $O(1)$，但梯度带噪声——上一节 RM 理论告诉我们：噪声可控时照样收敛。<span class="marginnote">SGD 的来历可追溯到 Robbins–Monro（1951）与 Widrow–Hoff 的 LMS 算法，而让它成为深度学习主流的是「每次迭代只用一个样本/小批」的工程事实。它有三重红利：<strong>计算便宜</strong>（$O(1)$/步）、<strong>天然逃离鞍点</strong>（噪声扰动）、<strong>隐式正则</strong>（有助于泛化）。这些让 SGD 成为「从极限到大模型」里训练一切模型的默认引擎。</span>

## 1 三种梯度

按「每次用多少数据」把梯度方法分档：

| 方法 | 每步梯度 | 每步代价 | 噪声 | 收敛性 |
| --- | --- | --- | --- | --- |
| 全批量 GD | $\nabla f$ | $O(n)$ | 无 | 确定性收敛 |
| 小批量 SGD | $\frac1{|B|}\sum_{i\in B}\nabla f_i$ | $O(\lvert B\rvert)$ | 小 | 收敛（RM 条件） |
| 单样本 SGD | $\nabla f_i$ | $O(1)$ | 大 | 收敛（RM 条件） |

**小批量（minibatch）**是工程主流：$|B|$ 常取 32–512，兼顾「梯度方向够准」与「每步够便宜」。单样本 SGD（在线学习）是极端情形——每步只用一条数据。<span class="marginnote">小批量带来的梯度是无偏的：$E_{i\sim U}\big[\nabla f_i(x)\big] = \nabla f(x)$——随机梯度的期望等于真梯度。这是 SGD 收敛的基石：噪声零均值（上一节 RM 的条件）。批量越大，梯度方差越小、方向越准，但每步越贵——批量大小是「噪声-成本」的旋钮。</span>

## 2 SGD 更新与它的「不精确」

SGD 的迭代是

$$
x_{k+1} = x_k - a_k\, \nabla f_{i_k}(x_k)
$$

其中 $i_k$ 是第 $k$ 步随机采样的样本，$a_k$ 是步长（学习率）。与梯度下降的唯一差别：**用 $\nabla f_{i_k}$ 代替 $\nabla f$**——其余一切照旧。这个「不精确」反而带来好处：

- **计算省**：每步 $O(1)$，适合流式/在线数据。
- **噪声即扰动**：随机梯度天然在解附近「抖动」，有逃离浅谷与鞍点的能力——这是它能在非凸深度网络上工作的原因之一。
- **泛化红利**：经验证据显示 SGD 找到的解泛化更好（可能与噪声导致的平坦极小有关）。<span class="marginnote">「噪声是朋友还是敌人」取决于阶段：<strong>早期噪声大 = 大步探索</strong>（逃离坏区域），<strong>后期噪声该小</strong>（精细收敛）。这启发了「退火学习率」——步长从大衰减到小，噪声自动从强到弱。Adam 等自适应方法也是在调节「有效噪声」。</span>

## 3 公式解析：无偏性与方差

把「随机梯度 = 真梯度 + 零均值噪声」写清楚，这是 SGD 一切理论的支点：

$$
\nabla f_{i}(x) = \nabla f(x) + \xi, \qquad E[\xi] = 0
$$

- **第一步，无偏性**：$E_{i\sim U}\big[\nabla f_i(x)\big] = \frac1n\sum_i\nabla f_i(x) = \nabla f(x)$——随机梯度的期望精确等于全梯度。
- **第二步，噪声方差**：$\mathrm{Var}(\nabla f_i) = \frac1n\sum_i\|\nabla f_i - \nabla f\|^2$——衡量「样本梯度之间差多远」。小批量 $B$ 的梯度方差 = $\mathrm{Var}(\nabla f_i)/|B|$——**批量越大方差越小**（独立样本平均）。
- **第三步，代入 RM 框架**：SGD 迭代 $x_{k+1} = x_k - a_k(\nabla f(x_k) + \xi_k)$ 正是 RM 迭代——$g = \nabla f$、噪声 $\xi_k$ 零均值、方差有界（假设梯度有界）。
- **第四步，收敛结论**：在光滑凸/强凸条件下，配合 RM 步长条件，SGD **几乎必然收敛到最优**；强凸下误差以 $O(1/k)$ 衰减（比全批量的线性慢——**噪声的代价**）。<span class="marginnote">「噪声的代价」很具体：全批量 GD 在强凸下线性收敛（误差指数衰减），SGD 因为噪声只能 $O(1/k)$（代数衰减）。想要「又快又省」？方差缩减（SVRG，后一节）在两者之间搭桥——用「周期性的全梯度」压低噪声。</span>

## 4 例子：线性回归的 SGD

用最小二乘演示 SGD 的机械流程。数据 $(x_i, y_i)$，损失 $f_i(w) = \frac12(w^Tx_i - y_i)^2$，目标 $\min \frac1n\sum f_i(w)$。

- **第一步，单样本梯度**：$\nabla f_i(w) = (w^Tx_i - y_i)x_i$——一次内积 + 标量乘，$O(d)$ 计算。
- **第二步，SGD 更新**：$w_{k+1} = w_k - a_k (w_k^Tx_{i_k} - y_{i_k})x_{i_k}$。
- **第三步，与全批量的对比**：全批量需要 $\sum_i$（$O(nd)$），SGD 只要 $O(d)$——**$n$ 倍差距**。
- **第四步，数据遍历**：一次「过完所有样本」叫一个 **epoch**。SGD 常用「每 epoch 打乱数据、逐样本更新」；小批量则「每 epoch 迭代 $n/|B|$ 次」。<span class="marginnote">实践细节：SGD 的「收敛」看的是 epoch 数而非迭代数——一 epoch 用 $O(n)$ 代价，与全批量 GD 的一次迭代同价。公平比较下，SGD 在凸问题上通常比 GD 更早「达标」（因为前几 epoch 的快速进步），这是它工程取胜的重要原因。</span>

## 5 SGD 速查与辨析

| 维度 | 内容 |
| --- | --- |
| 更新 | $x \leftarrow x - a\nabla f_i(x)$（或小批量平均） |
| 每步代价 | $O(|B|)$ |
| 梯度性质 | 无偏、带噪 |
| 收敛 | RM 步长下几乎必然；强凸 $O(1/k)$ |
| 工程优势 | 便宜、逃鞍点、泛化好 |
| 需要小心 | 学习率调度、批量大小、数据打乱 |

**辨析｜易错点：**其一，固定学习率 + SGD **不严格收敛**（噪声不减）——需要衰减或自适应；其二，数据**必须打乱（shuffle）**再采样——不打乱会导致梯度有偏、收敛变慢；其三，批量太小噪声大、太大每步贵——32/64/128 是常见默认，需调；其四，SGD 的收敛性分析多针对**凸**目标，深度学习非凸下的表现靠经验——「实践先行、理论滞后」是这里的常态。<span class="marginnote">在「从极限到大模型」主线里，SGD 是整个训练流程的心脏：学习率调度（step/cosine/warmup）、动量、Adam 都是在 SGD 骨架上加「步长与噪声」的工程优化。理解 SGD 的「无偏梯度 + 噪声 + RM 步长」三角，就是理解深度学习优化器的第一性框架。</span>

## 6 小结

- **SGD**：$x \leftarrow x - a_k\nabla f_{i_k}(x)$，用单样本/小批量梯度代替全梯度。
- **三重红利**：$O(1)$ 每步、天然逃鞍点、隐式正则。
- **无偏性**：$E[\nabla f_i] = \nabla f$——随机梯度是零均值噪声包裹的真梯度。
- **收敛代价**：噪声使强凸收敛降为 $O(1/k)$；RM 步长条件不可缺。
- **工程要点**：数据打乱、学习率调度、批量大小——三旋钮决定成败。
