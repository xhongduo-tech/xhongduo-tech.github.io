## 为什么「墙」要建在可行域内部

外罚法在可行域外罚，解从外部逼近——数值病态是硬伤。**内点障碍法（barrier method）**反其道而行：在可行域**内部**筑一堵「对数墙」，解从内部逼近边界上的最优解。<span class="marginnote">「障碍（barrier）」函数的特性：在可行域内部有限、越靠近边界趋向 $+\infty$——把约束「挡」在墙内。对数障碍 $-\log(-f_i(x))$ 是最标准的选择。这套方法在 1960 年代由 Fiacco 与 McCormick 提出，沉寂多年，1984 年后因内点法的多项式分析（Nesterov–Nemirovskii 的自和谐理论）重获新生，成为现代凸优化求解器（SDPT3、MOSEK、CVX）的内核。</span>

## 1 对数障碍与障碍问题

对不等式约束 $f_i(x) \le 0$（$i=1,\ldots,m$），定义**对数障碍函数**

$$
\phi(x) = -\sum_{i=1}^{m} \log(-f_i(x)), \qquad \mathrm{dom}\, \phi = \{x : f_i(x) < 0\}
$$

**性质**：$x$ 越靠边界（$f_i(x) \to 0^-$），$-\log(-f_i) \to +\infty$——墙在边界竖起；内部则平滑有限。<span class="marginnote">定义域严格取「内部」（所有 $f_i < 0$）——这正对应「内点」的含义：迭代全程保持在可行域内部，从不越界。注意 $\phi$ 是凸函数（$-\log$ 复合凹函数的保凸规则），且光滑可微。</span>

**障碍问题（barrier problem）**：对参数 $t > 0$，

$$
\min_x\ t\, f_0(x) + \phi(x) \quad \mathrm{s.t.}\quad h_j(x) = 0
$$

$t$ 是「目标权重」：$t$ 小 → 障碍主导 → 解在「中心」（远离边界）；$t$ 大 → 目标主导 → 解逼近边界上的真最优。**障碍法的工作方式：逐步增大 $t$，对每个 $t$ 解一次障碍问题，让解沿中心路径滑向最优**（上一节《内点法概述》已见过中心路径，这里给出实现细节）。

## 2 障碍法算法

**障碍法的标准流程**（对每个 $t$ 用牛顿法解障碍问题）：

```
给定严格可行起点 x（f_i(x) < 0），t = t0 > 0，μ > 1，容差 ε
while m/t > ε:                          # 对偶间隙控制
    牛顿法解障碍问题: x = argmin t f0(x) + φ(x)  (从 x 起步)
    t = μ t                             # 增大目标权重
    检查: m/t ≤ ε 则停止
```

**为什么以 $m/t$ 作间隙？** 对障碍问题的 KKT，可证对偶间隙满足

$$
f_0(x) - p^* \le \frac{m}{t}
$$

其中 $m$ 是不等式约束个数。<span class="marginnote">$m/t$ 是障碍法的「免费间隙证书」：障碍问题的解 $x(t)$ 与真最优的差距不超过 $m/t$。每轮把 $t$ 乘 $\mu$，间隙除以 $\mu$——只需 $\log(m/\epsilon)/\log\mu$ 轮就能把间隙压到 $\epsilon$。而每轮牛顿迭代约几十次（自和谐函数下为常数），总代价是温和的。</span>**收敛分析**：牛顿法在障碍问题上的迭代次数与 $t$ 无关（自和谐保证），所以总迭代 ≈ 轮数 × 每轮常数——这是「多项式时间」的落地形态。

## 3 公式解析：障碍问题的 KKT 与中心路径

把障碍问题的 KKT 写出来，看它与原问题 KKT 的差别：

- **第一步，障碍问题的一阶条件**（设 $h_j$ 仿射，乘子 $\nu$）：$t\nabla f_0(x) + \sum_i \frac{-1}{-f_i(x)}\nabla f_i(x) + \sum_j \nu_j\nabla h_j(x) = 0$，即

$$
t\nabla f_0(x) + \sum_i \frac{\nabla f_i(x)}{-f_i(x)} + A^T\nu = 0
$$

- **第二步，定义「隐式乘子」**：令 $\lambda_i = \frac{1}{-t\,f_i(x)}$（或等价 $\lambda_i = \frac{1/t}{-f_i(x)}$），代入得

$$
\nabla f_0(x) + \sum_i \lambda_i \nabla f_i(x) + \sum_j (\nu_j/t)\nabla h_j(x) = 0
$$

**与 KKT 驻点性同形**，且 $\lambda_i \ge 0$、互补松弛的「软化版」$\lambda_i f_i(x) = -1/t$。<span class="marginnote">注意互补松弛是 $-\lambda_i f_i(x) = 1/t$ 而非 0——<strong>障碍法用「乘积等于一个小常数」软化了互补松弛</strong>。$t \to \infty$ 时 $1/t \to 0$，软化消失，隐式乘子收敛到真实乘子 $\lambda^*$。这就是「障碍法 = 软化的 KKT」的精确含义。</span>
- **第三步，中心路径**：$x^*(t)$ 满足上述系统——它是「目标与障碍折中」的轨迹，$t \to \infty$ 收敛到原问题最优解。

**一句话：障碍问题是最优性条件的「软化版」，$t$ 控制软化程度，$m/t$ 控制间隙。** 内点法的全部多项式性质都从这条「软化 + 收紧」机制来。

## 4 与外罚法的对比

| 维度 | 外罚法 | 内点障碍法 |
| --- | --- | --- |
| 逼近方向 | 从外部 | 从内部 |
| 惩罚项 | 违反量的平方/绝对值 | $-\log(-f_i)$ 障碍 |
| 可行性 | 中间解不可行 | 全程严格可行 |
| 病态 | 严重（$\kappa \sim \mu$） | 相对温和（自和谐控制） |
| 多项式性 | 无干净理论 | 有（Nesterov–Nemirovskii） |
| 间隙 | 无免费证书 | $m/t$ 显式证书 |

**辨析｜易错点：**其一，障碍法**需要严格可行起点**（所有 $f_i < 0$）——如何找这个起点是阶段一问题（用相位一或最小化障碍自身）；其二，等式约束若**非线性**，障碍问题仍需处理（用增广拉格朗日或线性化）；其三，$t$ 的增长因子 $\mu$ 不能太大（否则每轮牛顿迭代增多）、也不能太小（轮数多），经验值 $\mu \in [10, 50]$。<span class="marginnote">现代实现多采用<strong>原始-对偶内点法</strong>（同时更新 $x$ 与 $\lambda$，见第四篇概述）而非「纯障碍法」，但障碍法的「软化 KKT + 免费间隙」直觉是理解一切内点法的钥匙。</span>

## 5 小结

- **对数障碍**：$\phi = -\sum\log(-f_i)$，内部有限、边界 $+\infty$，凸且光滑。
- **障碍问题**：$\min t f_0 + \phi$，$t$ 控制「目标 vs 障碍」权重。
- **障碍法流程**：逐步增大 $t$，牛顿法解每个障碍问题；间隙 $m/t$ 显式可控。
- **软化 KKT**：互补松弛变成 $-\lambda_i f_i = 1/t$，$t\to\infty$ 时收敛到真实乘子。
- **与外罚互补**：从内逼近、全程可行、病态温和、有多项式理论。
