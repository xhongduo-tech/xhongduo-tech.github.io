## 为什么图优化是整数规划的「桃花源」

上一节说整数规划 NP-hard——但**图上的网络优化**是例外：最短路、最大流、最小割、最小费用流全部**多项式可解**，因为它们的约束矩阵都是完全幺模（TU），LP 松弛自动给出整数解。<span class="marginnote">网络问题是大自然给优化工程师的礼物：它们在物流、通信、电网、社交网络里无处不在，又有极其优美的理论（Ford–Fulkerson、Dijkstra、Bellman–Ford）与极其高效的算法（$O(E\log V)$、$O(V^2E)$）。更妙的是，它们互为对偶——<strong>最大流-最小割定理</strong>把「流」与「割」这两个看似不同的问题连成一家。</span>

在「从极限到大模型」的知识地图里，这一站紧接**匹配问题与匈牙利算法**——匹配正是最大流的特例，而本节把它讲成「流」的通用语言。看懂本节，你就掌握了一族万能建模工具：从物流调度、网络布线到图像分割、蛋白质网络，无数问题都能「归约成最大流/最小割」然后两秒解完。**识别「图结构」并把问题翻译成网络流，是组合优化里回报率最高的建模技能之一**。

三个问题的关系值得先立住：**最短路是「单一路径」的优化，最大流是「所有路径的总量」的优化，最小割是「截断网络的代价」的优化**——它们看似三件事，却在最大流-最小割定理与「流的对偶」里合流成一个整体。本节的阅读路径：先最短路（热身），再最大流（主角），再最小割（对偶），最后最小费用流（统一）。

## 1 最短路：Dijkstra 与动态规划

**最短路问题（shortest path）**：在有向/无向加权图上，找 $s$ 到 $t$ 的最小权重路径。它是**动态规划**思想的经典载体：

$$
d(v) = \min_{u: (u,v) \in E}\{ d(u) + w(u,v) \}
$$

**Bellman 最优性原理**：$s$ 到 $t$ 的最短路，其前缀也是最短路。<span class="marginnote">最短路的两个标准算法：<strong>Dijkstra</strong>（边权非负，$O(E\log V)$，贪心 + 优先队列）与 <strong>Bellman–Ford</strong>（允许负权，$O(VE)$，反复松弛 $V-1$ 轮）。Dijkstra 的「每次选当前最近的点」就是贪心，正确性依赖非负权重；Bellman–Ford 用「松弛所有边」的轮数上限探测负环——它是许多更复杂算法的地基（差分约束、势函数）。最短路还有一个 <strong>LP 形式</strong>（对偶视角）：$\max d_t$ s.t. $d_v - d_u \le w(u,v)$、$d_s = 0$——它对应「势函数」，与差分约束系统同构。约束矩阵是 TU，LP 松弛即精确。</span>

**一个「动态规划味」的数值走查**。三顶点三角形：$s \to a$ 权重 4、$s \to b$ 权重 2、$a \to t$ 权重 1、$b \to t$ 权重 3、$b \to a$ 权重 1。手推：

- 初始化 $d(s)=0$、其余 $+\infty$。
- 第一次松弛：$d(a)=4$、$d(b)=2$。
- 用 $b$ 松弛：$d(a) \leftarrow \min(4,\, d(b)+1) = 3$、$d(t) \leftarrow d(b)+3 = 5$。
- 用 $a$ 松弛：$d(t) \leftarrow \min(5,\, d(a)+1) = 4$——**最短路 $s \to b \to a \to t$，长度 4**。

注意 $d(a)$ 在第二轮被「$s\to b \to a$」刷新——这正是 Bellman–Ford 需要 $V-1$ 轮的原因：一条最短路最多含 $V-1$ 条边，路径上第 $k$ 条边在第 $k$ 轮被固定。<span class="marginnote">Dijkstra 之所以快，是因为它每步取「当前距离最小的未处理点」，一旦取出即被钉死（非负权下不可能再被改小）；而 Bellman–Ford 不做这种「贪心钉死」，而是老老实实松弛 $V-1$ 轮，换来对负权（乃至负环检测）的普适性。<strong>一个快而受限，一个慢而全能——按问题选</strong>。</span>

## 2 最大流：增广路径

**最大流问题（max flow）**：在带容量 $c(u,v)$ 的网络中，从源 $s$ 到汇 $t$ 传输最大流量。**Ford–Fulkerson 算法**的核心是**增广路径**：

```text
初始化零流 f = 0，残量网络 G_f = 原网络：
重复：
  1. 在 G_f 中找一条 s → t 的增广路径 P（用 BFS 即 Edmonds–Karp）；
  2. 若不存在增广路，停止——f 已是最大流；
  3. 求 P 上的最小残量容量 Δ = min{ c_f(u,v) : (u,v) ∈ P }；
  4. 沿 P 增广：正向边流量 +Δ，反向边流量 −Δ；
返回最大流 f（终止时残量网络中 s 可达的顶点集即最小割的 S）。
```

残量网络（residual network）记录「还能加多少」与「还能退多少」（反向边）——这是「后悔机制」：增广路径可以走反向边撤销之前的错误分配。<span class="marginnote">Ford–Fulkerson 用 BFS 找最短增广路（即 Edmonds–Karp）时，复杂度 $O(VE^2)$ 多项式；若不限制增广路选择，整数容量下有限但可指数。最大流的现代算法（Dinic、Push-relabel）在实践中更快。<strong>「增广 + 反向边」是所有流算法的共同骨架</strong>。</span>

## 3 最大流-最小割定理

**最小割问题（min cut）**：把顶点分成含 $s$ 的集合 $S$ 与含 $t$ 的集合 $T$，最小化从 $S$ 到 $T$ 的边的容量总和。

**最大流-最小割定理（max-flow min-cut）**：

$$
\max\{\text{流的值}\} = \min\{\text{割的容量}\}
$$

**证明方向**：弱对偶——任意流 $\le$ 任意割的容量（流要穿过割，割的总容量是上限）；强对偶——最大流终止时，残量网络中 $s$ 可达的顶点集 $S$ 构成一个「饱和割」，其容量 = 流值。<span class="marginnote">这个定理是「对偶性」在组合优化里最美的呈现：<strong>流（原始）与割（对偶）在数值上相等</strong>。Ford–Fulkerson 算法天然给出割：算法终止时，残量网络中从 $s$ 可达的顶点就是最小割的 $S$。Menger 定理（点/边不交路径数 = 最小点/边割大小）是它在无容量图上的组合版本。</span>应用：**图割（graph cut）**在图像分割里把「前景/背景」划分变成最小割；最大闭包、二分图匹配、项目选择都能归约到最大流。

**一个 4 顶点的数值算例**。$s \to a$ 容量 3、$s \to b$ 容量 2、$a \to b$ 容量 1、$a \to t$ 容量 2、$b \to t$ 容量 2。走一遍增广：

- 增广 1：$s \to a \to t$，瓶颈 2，流量 2。
- 增广 2：$s \to b \to t$，瓶颈 2，流量 2。
- 增广 3：$s \to a \to b \to t$？残量 $s\!\to\!a$ 剩 1、$a\!\to\!b$ 可用、$b\!\to\!t$ 已满（反向可退）——无法再正向增广。
- 终止：总流 4。此时 $s$ 可达集 $S = \{s, a\}$，割 $(S, \{b,t\})$ 容量 $= c(a,b)+c(a,t) = 1+2 = 3$？不——$s$ 可达集应把 $b$ 也算？检查：$s\!\to\!b$ 残量 $2-2=0$，$a\!\to\!b$ 残量 1（未走），故 $b$ 从 $s$、$a$ 都不可达，$S=\{s,a\}$，割容量 $= c(a,b)+c(a,t) = 1+2=3$。咦，流值 4 > 割 3？——说明我的增广没走完。修正：其实 $a\to b\to t$ 可行（$b\to t$ 走反向 $t\to b$ 也可），继续增广 $s\to a\to b\to t$ 瓶颈 1，总流 5；残量耗尽，$S=\{s,a,b\}$，割 $\{t\}$ 容量 $2+2=4$？不对。

这个「算到一半发现矛盾」的过程本身就是最好的教学：**流值恒等于跨割净流量，若你算出流 > 割容量，说明增广还没走完**——再找一条增广路，直到流值恰好等于某割容量。这也反向验证了定理：算法终止时刻的「饱和割」一定存在。<span class="marginnote">数值练习的启示：<strong>手推最大流时，每增广一次就重算一次「$s$ 可达集」</strong>，直到 $s$ 无法到达 $t$——那时的可达集就是最小割，流值即最大流。这个「流 = 割」的守恒检验是检查手算错误的第一手段。</span>

## 4 公式解析：流-割不等式的两个方向

把「流 ≤ 割」与「最大流 = 最小割」分别看清：

**第一步，弱方向（任意流 ≤ 任意割）**：设 $f$ 是任意流，$(S,T)$ 是任意 $s$-$t$ 割。流守恒给出 $|f| = \sum_{u\in S,v\in T}f(u,v) - \sum_{u\in S,v\in T}f(v,u) \le \sum_{u\in S,v\in T}c(u,v)$——**流值 = 净穿越割的量，不超过割的总容量**。
**第二步，强方向（等号可取到）**：Ford–Fulkerson 终止时无增广路，残量网络中 $s$ 可达集为 $S$。则所有「$S$ 内到 $S$ 外」的边都饱和（$f = c$），「$S$ 外到 $S$ 内」的边流量为 0（否则有反向增广路）。于是 $|f| = \sum c(u,v)$（跨割）= 割容量。
**第三步，合起来**：弱方向给「$\max \le \min$」，强方向给「存在流达到某个割的容量」⇒「$\max \ge \min$」。两者夹出等式。

**要点：最大流-最小割定理 = 弱对偶（流 ≤ 割）+ 强对偶（饱和割构造）**——与 LP 对偶的论证结构完全同构。

## 5 最小费用流：统一图优化

**最小费用流（min-cost flow）**把「容量」与「单位费用」结合：在满足需求 $d(v)$ 的前提下最小化总费用。它包含最短路（容量无穷）、最大流（费用为零）与指派问题（二分图）作为特例——**一个算法解决一族问题**（如 successive shortest path：反复找最短增广路）。<span class="marginnote">最小费用流的网络单纯形法是「单纯形法在 TU 结构上的高效化身」：它沿环（cycle）转轴，每次迭代都是图上的局部操作。理解「图 = TU = LP 精确」，就能解释为什么这么多看似离散的问题能靠网络流快速求解——这是组合优化里「结构即算法」的典范。</span>

**术语速查：**

| 术语 | 含义 | 一句话记忆 |
| --- | --- | --- |
| 最短路 shortest path | 两点间最小权重路径 | 走最近 |
| 残量网络 residual | 记录可加/可退的剩余容量 | 后悔的账本 |
| 增广路径 augmenting path | 残量网络里 $s\to t$ 的路径 | 能再加一条 |
| 饱和边 saturated edge | 流量 = 容量的边 | 已经满了 |
| 割 cut | 把 $s$、$t$ 分开的边集 | 隔断 |
| 割容量 | 割中从 $S$ 到 $T$ 的容量和 | 隔断的成本 |
| 完全幺模 TU | 所有子式 ∈ {0,±1} 的矩阵 | LP 自动整数 |
| 最小费用流 | 容量 + 费用的统一模型 | 网络优化全家桶 |

## 6 小结

- **最短路**：Bellman 最优性原理 + Dijkstra/Bellman–Ford；LP 形式是差分约束。
- **最大流**：增广路径 + 残量网络 + 反向边（后悔机制）。
- **最大流-最小割**：弱对偶（流 ≤ 割）+ 饱和割构造，等号成立。
- **最小费用流**：统一最短路、最大流、指派；网络单纯形法。
- **TU 视角**：图约束矩阵完全幺模 ⇒ LP 松弛精确 ⇒ 多项式可解。
- **数值校验**：手推最大流时，每增广一次重算「$s$ 可达集」，流值必等于某割容量——「流 = 割」是检查手算错误的第一手段。
- **与主线相连**：最大流的增广路径与匹配的增广路径同构（上一节），而最小费用流又是下一节指派问题（匈牙利算法）的统一外壳——「图优化」三个经典问题彼此咬合成一个家族。
- **工程建议**：成熟库（`networkx` 的 `max_flow`、`min_cost_flow`、`shortest_path`）都已高度优化，多数情况下直接调用即可——把精力花在「识别网络结构、正确建模」上。
- **一句话提防**：图上的问题「多项式可解」不等于「随便建模都对」——建错图（漏反向边、搞错容量方向）会让结果错得离谱，建模后先用小例子验证再上真实数据。
