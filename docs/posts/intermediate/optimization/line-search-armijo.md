## 为什么「步长」值得专门一章

方向决定后，剩下「走多远」。这一步看似平凡，却是算法成败的关键：步长太小，收敛慢如蜗牛；步长太大，直接跨过谷底、可能震荡甚至发散。**线搜索（line search）**就是系统解决「走多远」的学问：在给定方向 $\Delta x$ 上，把步长 $t$ 当变量，最小化一维函数 $\phi(t) = f(x + t\Delta x)$。<span class="marginnote">历史上，线搜索曾是每个算法步的标配，直到自适应步长（如 Adam 的自适应学习率）在深度学习里大行其道——但两者思想同源：<strong>都是「根据局部信息决定移动幅度」</strong>。理解经典线搜索，等于理解了深度学习步长策略的祖先。</span>

## 1 精确线搜索

**精确线搜索（exact line search）**：求解一维问题

$$
t_k = \arg\min_{t > 0}\ \phi(t) = f(x_k + t \Delta x_k)
$$

几何上，就是沿射线 $x_k + t\Delta x_k$ 走到函数值最低处再转弯。<span class="marginnote">对二次函数 $\phi(t) = \frac12 a t^2 + bt + c$，精确解是 $t^* = -b/a$，一步到位；对一般函数，需要用一维极小化（黄金分割、三次插值）迭代求 $\phi$ 的极小，每次求值都是一次 $f$ 的计算，代价不菲。</span>精确线搜索的理论地位很高（许多收敛性证明用它作理想步长），但工程上常被嫌贵：

- **优点**：方向最优地利用，每次迭代走到底。
- **缺点**：一维极小化本身要多次函数求值；对复杂 $f$ 可能很贵。
- **更深的缺点**：过度精确往往没必要——`optimize t exactly` 花掉的成本，换来的收益边际递减。**这就是「非精确线搜索」兴起的动机。**

## 2 Armijo 回溯：够用就好

**Armijo 回溯线搜索（backtracking line search）**的理念是「先试大步，不行就退」：

```
给定 α ∈ (0,1)（如 0.5），β ∈ (0,1)（如 0.1），t = 1
while f(x + tΔx) > f(x) + β t ∇f(x)^TΔx:
    t = α t
return t
```

判据 $f(x + t\Delta x) \le f(x) + \beta t\nabla f^T\Delta x$ 称为**充分下降条件（sufficient decrease）**。<span class="marginnote">右侧 $f(x) + \beta t \nabla f^T\Delta x$ 是「从 $f(x)$ 沿斜率 $\nabla f^T\Delta x$ 画的一条直线」，斜率乘以 $\beta < 1$ 打折扣——要求函数值「至少按这条更缓的直线下降」。$\beta$ 越小要求越松，$t$ 越容易通过；$\alpha$ 控制回溯速度（0.5 表示每退一步减半）。</span>为什么一定要回溯？因为**大步长的函数值可能不降**（翻过山丘到了对面斜坡）——回溯从 1 开始试，不行就缩，保证最终接受的步长「确实带来下降」。

**正确性**：只要 $\Delta x$ 是下降方向（$\nabla f^T\Delta x < 0$），对充分小的 $t$，$f(x + t\Delta x) \approx f(x) + t\nabla f^T\Delta x < f(x) + \beta t\nabla f^T\Delta x$（因 $\beta < 1$）——**回溯必在有限步内停止**，且接受的 $t$ 满足充分下降。这保证了算法「不会空转」。

## 3 为什么只要求「充分下降」就够了

Armijo 条件的妙处在于它**只要求线性下降**，而非精确极值：

$$
f(x_{k+1}) \le f(x_k) + \beta t_k \nabla f(x_k)^T \Delta x_k
$$

- **充分性**：配合 $\nabla f^T\Delta x < 0$，保证每次迭代函数值严格下降，且下降量与步长、梯度成比例——这是几乎所有收敛性证明的起点。
- **非精确性**：它不要求找到一维极小，只要求「别走太远」——省掉大量函数求值。
- **与方向的配合**：方向越差（夹角越接近 90°），充分下降条件要求步长越小；若方向是负梯度，$t=1$ 的通过概率高。<span class="marginnote">一个精细点：Armijo 只防「步长太大」，不防「步长太小」——若 $t$ 退得极小而仍不满足，虽然理论上不会（有限步必停），但数值上可能接受一个近乎零的步长，导致收敛缓慢。因此工程上会设「步长下限」，或配合 Wolfe 条件（下一节）同时约束「别太小」。</span>

## 4 公式解析：为什么回溯必停

把「回溯必在有限步内停」证明一遍，它是整个线搜索理论的地基。设 $\Delta x$ 为下降方向，令 $\phi(t) = f(x + t\Delta x)$，则

$$
\phi'(0) = \nabla f(x)^T \Delta x < 0
$$

- **第一步，看 $t \to 0^+$ 的泰勒**：$\phi(t) = \phi(0) + t\phi'(0) + o(t)$。因为 $\phi'(0) < 0$ 且 $\beta < 1$，有 $\phi'(0) < \beta\phi'(0)$（负值乘 $\beta<1$ 变得「更负」方向，实际 $\beta\phi'(0) > \phi'(0)$，即更缓）。于是对足够小的 $t$：$\phi(t) \approx \phi(0) + t\phi'(0) < \phi(0) + \beta t \phi'(0)$。
- **第二步，推出存在可行小步长**：存在 $\bar t > 0$ 使所有 $t \le \bar t$ 都满足充分下降条件。
- **第三步，回溯必达**：回溯从 $t=1$ 开始按 $\alpha$ 等比缩小，序列 $\alpha^k$ 终将 $\le \bar t$——**在有限步内必找到满足条件的 $t$**。

**要点：充分下降条件 + 下降方向 = 回溯必然终止且接受「不空转」的步长。** 这也是它被所有主流实现采用的原因：理论上无懈可击，实现上只要几行代码。

## 5 线搜索家族速查

| 方法 | 判据 | 成本 | 场景 |
| --- | --- | --- | --- |
| 精确线搜索 | 一维极小化 | 高 | 理论、二次函数 |
| Armijo 回溯 | 充分下降 | 低 | 通用默认 |
| Goldstein 条件 | 充分下降 + 下界 | 中 | 需双侧约束 |
| Wolfe 条件 | 充分下降 + 曲率 | 中 | 拟牛顿法 |
| 黄金分割 | 精确一维搜索 | 中 | 无需导数 |

**辨析｜易错点：**其一，Armijo 的 $\beta$ 取太小（如 0.001）会让条件形同虚设，可能接受过大的步长；$\beta$ 取太大（如 0.9）要求过严，步长会偏保守。经验值 $\beta \in [10^{-4}, 10^{-1}]$。其二，**回溯必须配合「步长上限」**，否则在某些病态函数上可能一直退到机器精度。其三，`f(x) < f(x_k)` 的朴素判据（$\beta=0$）不够——它可能接受一个几乎没下降的步长，因此要有正 $\beta$ 的「裕度」。

## 6 小结

- **线搜索任务**：沿方向 $\Delta x$ 定步长 $t$，最小化一维函数 $\phi(t)$。
- **精确线搜索**：一维极小化，理论最优但工程偏贵。
- **Armijo 回溯**：充分下降条件 $f \le f + \beta t\nabla f^T\Delta x$ + 等比缩小；够用就好。
- **终止保证**：下降方向 + 充分下降 ⇒ 回溯有限步必停。
- **参数**：$\alpha$（缩步率）、$\beta$（下降裕度）；与 Wolfe（下一节）互补约束双侧。
