## 为什么局部搜索需要「记忆」

局部搜索（local search）沿邻域不断改进，但它有两个病：**困在局部极小**（没有改进移动就停）与**循环**（在两个解之间来回跳）。**禁忌搜索（Tabu Search, TS）**用一张「禁忌表（tabu list）」记住最近访问过的解或最近做过的移动，**禁止短期内重复**——既防止循环，又强迫探索新区域。<span class="marginnote">禁忌搜索由 Fred Glover 在 1986 年提出，是「智能局部搜索」的代表：它把「爬山」升级为「带记忆的山爬」——遇到局部极小时不停止，而是「被迫」走一个不那么好的移动，绕过障碍。它的核心发明是<strong>禁忌表 + 渴望准则</strong>这对组合，让「记忆」既有纪律又有弹性。</span>

## 1 局部搜索的基础框架

**局部搜索（local search）**的通用框架：

```
给定初始解 x
repeat:
    1. 生成 x 的邻域 N(x)
    2. 在 N(x) 中找一个改进移动 x′，使 f(x′) < f(x)
    3. 若不存在改进移动：返回 x（局部最优）
    4. x ← x′
```

**邻域（neighborhood）**是局部搜索的灵魂：一次「小扰动」能到达的解的集合。不同问题的邻域设计：

TSP：交换两条边的 2-opt。
调度：交换两个任务的顺序。
连续优化：在球内扰动。

**多起点局部搜索（multistart）**是最简单也最常被低估的策略：随机初始化跑多次局部搜索，取最好。<span class="marginnote">局部搜索的「改进只接受」保证它终止于局部最优——但它可能是个坏局部最优。改进方向有两条：<strong>随机化</strong>（多起点、模拟退火的概率接受）与<strong>记忆化</strong>（禁忌搜索的禁止回头）。TS 走第二条路：它不靠随机，靠「记住不要重复」，是更确定性的智能搜索。</span>

## 2 禁忌表与渴望准则

**禁忌表（tabu list）**：记录最近 $L$ 次做过的「移动」（move）或访问过的解属性，$L$ 是禁忌长度（tabu tenure）。当前移动若在表中，则**被禁止**（除非渴望准则放行）。

**禁忌移动**：最近做过的移动短期内不重做——防止「刚换了边又换回来」的循环。
**禁忌解**：最近访问的解不再访问——防止绕圈。

**渴望准则（aspiration criterion）**：即使移动被禁忌，**若它能产生比当前最好解更好的解，则放行**——「禁忌是为了更好，若这个移动能突破纪录，值得破例」。<span class="marginnote">禁忌与渴望是 TS 的一对矛盾统一：禁忌表负责「别回头」，渴望准则负责「别傻等」——当被禁忌的移动能创造新纪录时，规则让位给全局目标。工程上常见禁忌：记「移动」（最近交换的边对）比记「整个解」省内存；禁忌长度 $L$ 是主要旋钮，太长探索过度、太短防不了循环。</span>

## 3 长期记忆：强化与多样化

TS 的另一层智能是**长期记忆**（long-term memory），它超出「短期禁忌表」：

**强化（intensification）**：把搜索引回「有希望的区域」——记忆里最成功的解附近精细搜索。
**多样化（diversification）**：把搜索推向「未探索的区域」——记忆里没去过的解附近重新搜索。

实现手段：频率记忆（记录每个移动被用了多少次，少用的优先）、精英解存档（好的解附近重启）。<span class="marginnote">强化与多样化是元启发式的两大战略方向：<strong>强化 = 利用</strong>（深耕好区域），<strong>多样化 = 探索</strong>（开拓新区域）。TS 用记忆让两者交替：短期禁忌防循环（微观），长期频率与精英存档引方向（宏观）。这套「记忆驱动的搜索」让它比纯随机方法更「聪明」——这也是它被归为「智能优化」的原因。</span>

## 4 公式解析：TS 的一步迭代

把 TS 的「禁忌 + 渴望」写成一可执行流程：

```
给定初始解 x，禁忌表 T ← ∅
repeat:
    1. 生成邻域 N(x)
    2. 过滤：先用禁忌表 T 禁掉重复的移动；再用渴望准则放行能破纪录的被禁移动
    3. 从候选集中选最好的移动 x′（允许 f(x′) ≥ f(x)）
    4. 更新 x ← x′，把该移动加入 T（长度 L，先进先出）
    5. 更新全局最好解与长期记忆（频率 / 精英解存档）
until 迭代上限 或 连续无改进
```

**第一步，候选过滤**：先用禁忌表过滤邻居（禁掉重复），再用渴望准则放行「破纪录」的被禁邻居。
**第二步，允许变差**：TS **不要求改进**——候选集中最好的（即使比当前差）也会被接受——这是它「绕过局部极小」的关键：宁可暂时上坡，也要走出盆地。
**第三步，记忆更新**：禁忌表滚动窗口（先进先出）。
**第四步，终止**：迭代上限或连续无改进。

**要点：TS = 局部搜索 + 禁忌表（防循环）+ 允许变差（逃局部极小）+ 渴望准则（破例破纪录）**。

## 5 TS 速查与应用

| 组件 | 作用 |
| --- | --- |
| 邻域算子 | 一次扰动（2-opt、交换、插入） |
| 禁忌表 | 防循环（记移动或解属性） |
| 渴望准则 | 破例（能破纪录就放行） |
| 长期记忆 | 强化 / 多样化 |
| 终止 | 迭代上限 / 无改进 |

**辨析｜易错点：**其一，禁忌**长度 $L$ 是关键超参**——太短防不了循环、太长抑制搜索；其二，禁忌「移动」还是「解」取舍——记移动省内存但可能漏掉「换种路径回到同一解」，记解更安全但贵；其三，TS 没有「保证找到全局最优」——它仍是启发式，靠的是「记忆 + 变差」的工程智慧；其四，**邻域算子的质量 > 禁忌表**——邻域太弱（只能小步）TS 也走不远。<span class="marginnote">在「从极限到大模型」里，TS 常用于<strong>调度与路由</strong>（车辆路径、作业车间调度）、以及<strong>特征选择</strong>等组合问题——它擅长「邻域清晰、改进快」的离散问题。它和模拟退火、遗传算法一起构成元启发式三巨头：SA 靠概率、GA 靠种群、TS 靠记忆——<strong>三种「逃出局部极小」的哲学</strong>。</span>

## 6 数值算例：禁忌表如何阻止循环

用一个小 TSP 演示禁忌表的「防循环」机制。4 个城市，解是一个排列（如 $[1,2,3,4]$），邻域用「交换相邻两城」的 2-opt。当前解 $[1,2,3,4]$，目标（总距离）$f = 10$。

**第一步，候选邻域**：交换相邻对得 3 个邻居：$[2,1,3,4]$（$f=9$）、$[1,3,2,4]$（$f=11$）、$[1,2,4,3]$（$f=12$）。
**第二步，选择**：选最好的 $[2,1,3,4]$（$f=9$），把「交换位置 1-2」记入禁忌表。
**第三步，下一轮**：从 $[2,1,3,4]$ 出发，邻域含 $[1,2,3,4]$（交换 1-2 回去，$f=10$）——**但在禁忌表中，被禁止**。于是只能选次好的邻居，**被迫离开局部最优点继续探索**；纯局部搜索则会在这里来回跳、永不进步。
**第四步，渴望准则**：若「回到 $[1,2,3,4]$」竟能给出比历史最好（9）更小的 $f$，则放行——但本例不会，于是禁忌表有效防住「来回跳」。

| 轮 | 解 | 禁忌表 | 动作 |
| --- | --- | --- | --- |
| 1 | $[1,2,3,4]$，$f=10$ | 空 | 交换 1-2 → $[2,1,3,4]$ |
| 2 | $[2,1,3,4]$，$f=9$ | {1-2} | 交换 1-2 被禁 → 选次好邻居 |
| 3 | 新解 | {1-2, 新移动} | 继续，禁忌表滚动更新 |

**这个例子的要点**：禁忌表把「刚走过的回头路」短期锁死，强迫搜索向新区域推进——没有它，局部搜索会在两个相邻最优之间无限循环；有了它，即使暂时变差，也能走出盆地找到更优。

## 7 小结

- **局部搜索**：邻域 + 改进移动，终止于局部最优；多起点是最朴素升级。
- **禁忌表**：记住最近移动/解，禁止重复——防循环。
- **渴望准则**：能破纪录就放行——让禁忌有弹性。
- **允许变差**：TS 接受「候选集中最好（可更差）」——逃局部极小。
- **长期记忆**：强化（深耕）与多样化（拓荒）交替。
- **定位**：记忆驱动的智能局部搜索，擅长离散组合问题。
- **算例要点**：禁忌表锁死「刚走的回头路」，纯局部搜索会 $[1,2,3,4]\leftrightarrow[2,1,3,4]$ 无限循环、TS 被迫探索。
- **矛盾统一**：禁忌表「别回头」+ 渴望准则「能破纪录就破例」——纪律与弹性并存。
- **三巨头哲学**：SA 靠概率、GA 靠种群、TS 靠记忆——三种逃出局部极小的思路。
