## 为什么 QP 值得一整篇

二次规划是「LP 与一般凸优化之间最甜蜜的一点」：表达力覆盖最小二乘、SVM、投资组合，又有几乎完美的算法理论（积极集法、内点法、以及第七篇将展开的种种技巧）。本节先把 QP 的**标准形式**立起来，再回答那个决定命运的问题——**它到底凸不凸？**<span class="marginnote">凸性判别是 QP 建模的第一道分诊：凸 QP 有全套理论（全局最优、多项式可解）；非凸 QP 的全局最优一般是 NP-hard 的。判别标准只有一条——<strong>Hessian 矩阵 $P$ 是否半正定</strong>。但实践中「$P$ 是否半正定」常藏在问题结构里，本节教你把隐藏的 $P$ 挖出来。</span>

在「从极限到大模型」的知识地图里，本节开启**第七篇 二次规划**：它夹在「线性规划（第四篇）」与「一般凸优化」之间，是最「甜」的中间地带——约束是线性的（多面体），目标只比线性多一个二次项。读懂本节的「标准形式 + 凸性判别」，你就能判断一个现实问题（SVM、组合优化、控制）是不是 QP、是不是凸 QP，从而决定能不能用第七篇后面那些「又好又快」的算法。

## 1 QP 的标准形式

**二次规划（Quadratic Programming）**：目标为二次、约束为仿射：

$$
\begin{aligned}
\min_x \quad & \frac12 x^T P x + q^T x + r \\
\mathrm{s.t.} \quad & Gx \preceq h \\
& Ax = b
\end{aligned}
$$

- $P \in \mathbb{S}^n$ 对称，$q \in \mathbb{R}^n$，$r$ 常数（不影响最优解，常省略）。
- $Gx \preceq h$：分量式线性不等式；$Ax = b$：等式约束。<span class="marginnote">注意「$\frac12$」的约定：很多文献写成 $\frac12x^TPx + q^Tx$，让梯度恰好是 $Px + q$、Hessian 恰为 $P$——省去系数混乱。与 Boyd 的 $f_0(x) = x^TPx + q^Tx + r$（无 1/2）相比，只差一个常数缩放，阅读文献时先确认约定。</span>QP 覆盖 LP（$P=0$ 即退化）。

**变量空间**：$x \in \mathbb{R}^n$，可行域 $\{x : Gx \le h,\ Ax = b\}$ 是多面体。**QP = 在多面体上最小化二次函数**。

**一个「最小二乘是 QP」的具体展开**：$\min \|Ax - b\|_2^2$ 写成 $\min (Ax-b)^T(Ax-b) = x^T A^TA x - 2b^TAx + b^Tb$，与标准形式对照：$P = 2A^TA$、$q = -2A^Tb$、$r = b^Tb$。这条「把目标展开成二次+线性+常数」的操作，是「挖出隐藏的 $P$」的第一步——**任何目标里出现 $\|·\|^2$、$x^TPx$、协方差项，都先展开，看二次项系数矩阵长什么样**。<span class="marginnote">这也是「从极限到大模型」里反复出现的手艺：正则化项 $\lambda\|x\|^2$ 展开成 $\lambda x^TIx$，$P$ 是 $\lambda I$；SVM 的对偶目标 $x^TQx$ 里 $Q$ 由核矩阵构成——<strong>认出二次项 = 认出问题类型</strong>。</span>

## 2 凸性判别：$P \succeq 0$ 是唯一标准

**定理**：QP 是凸优化问题，当且仅当 $P \succeq 0$（半正定）。

目标 $\frac12x^TPx + q^Tx + r$ 的 Hessian 就是 $P$；凸 ⇔ Hessian 半正定（第一篇二阶条件）。
$P \succ 0$（正定）：目标严格凸，最优解唯一（若有界可行集）。
$P \succeq 0$ 但奇异：目标凸但非严格，最优解集是凸的（可能是一条线段或面）。
$P$ 有负特征值（不定）：目标非凸——**全局最优可能 NP-hard**。<span class="marginnote">判别手段：特征值分解（$O(n^3)$）、Cholesky（尝试分解 $P = LL^T$，失败即非半正定）、或主元检查。工程上对大规模 $P$ 常用「$P + \lambda I$ 可分解」作为「接近半正定」的近似。<strong>发现 $P$ 不定时，先别急着解——回到建模层，看能否重写成凸形式</strong>（见第五节）。</span>

**为什么「半正定」如此生死攸关？** 因为凸性给 QP 带来：全局最优的免费证书、多项式时间的算法、以及稳定的数值行为。非凸 QP 连「找到全局最优」都不可判定地难。

**一个「不定 $P$ 之害」的直觉**：考虑一维 $f(x) = -x^2$（$P = -2 < 0$，不定）。在无约束区间上它无下界，目标 $\to -\infty$；加上边界约束 $[-1, 1]$ 后，两个端点 $x=\pm1$ 都是局部极小、目标值相同——但它「有没有其他更好的解」取决于整个约束多面体，这正是一般非凸 QP 的困难本质：**局部最优可以很多，彼此之间隔着「山脊」，没有任何局部条件能告诉你「已到全局」**。凸 QP 恰恰相反：$P \succeq 0$ 保证任何局部极小都是全局极小，一次求解即得证书。<span class="marginnote">给「从极限到大模型」读者的一句话：<strong>遇到非凸 QP 先别硬解——问「能不能改写成凸代理问题」</strong>，这正是 SVM 里「把非凸的 0/1 损失换成凸的 hinge」、以及「松弛」思想反复上演的地方。</span>

## 3 隐藏的 $P$：从问题结构识别凸性

很多问题不直接写成 $\frac12x^TPx$，但 $P$ 藏在结构里：

**最小二乘** $\min\|Ax - b\|_2^2$：展开得 $x^T(A^TA)x - 2b^TAx + b^Tb$，$P = 2A^TA \succeq 0$——**永远凸**（任何 $A$ 都有 $A^TA$ 半正定）。
**岭回归** $\min\|Ax-b\|^2 + \lambda\|x\|^2$：$P = 2(A^TA + \lambda I) \succ 0$——严格凸，解唯一。
**投资组合** $\min \frac12 x^T\Sigma x - \mu^T x$：协方差矩阵 $\Sigma \succeq 0$——凸；$\Sigma$ 奇异（资产线性相关）时半正定非正定。<span class="marginnote">识别技巧：把目标展开成「二次 + 线性 + 常数」，二次项系数矩阵就是 $P$。若二次项来自「平方范数」「协方差」「能量」，几乎必然半正定——<strong>结构性凸</strong>是最可靠的凸性来源。</span>
**Lasso** $\min\frac12\|Ax-b\|^2 + \lambda\|x\|_1$：二次部分凸 + $\ell_1$ 凸 → 凸（非光滑，用邻近梯度而非 QP 算法）。

**「判别清单」把上面的例子收成一条可执行流程**：

1. 把目标展开成「二次 + 线性 + 常数」，读出 $P$（二次项系数矩阵）。
2. 快速检查 $P$：尝试 Cholesky 分解（$P = LL^T$ 成功即半正定）；或看 $P$ 是否「结构上凸」（平方范数/协方差/能量 → 自动半正定）。
3. 若 $P$ 半正定：恭喜，是凸 QP，用第七篇的积极集/内点法。
4. 若 $P$ 不定：先想「能否重新建模成凸」，再想 SDP 松弛、分支定界。

这四步把「凸性判别」从定理变成了日常工作流。<span class="marginnote">工程上还有一个务实信号：直接拿现成求解器（如 OSQP、Gurobi）去解，若报「非凸」或收敛异常，多半就是 $P$ 不定——<strong>求解器是最快的凸性探测器</strong>。</span>

## 4 公式解析：最小二乘的 $P$ 恒半正定

把「$A^TA$ 为什么恒半正定」证明到透明，它是「结构凸」的样板：

**第一步，任意 $v$**：$v^T(A^TA)v = (Av)^T(Av) = \|Av\|_2^2 \ge 0$——**任何向量的平方范数非负**。
**第二步，结论**：$A^TA$ 对任意 $A$（不必满秩）都半正定；$A$ 列满秩时正定。
**第三步，推论**：凡目标含「$\|Ax-b\|^2$」项的模型，其二次部分自动凸——**不需要任何额外检查**。
**第四步，为什么重要**：机器学习里海量模型（线性回归、岭、Lasso、SVM 的对偶）都建立在这条「白送凸性」上——这是凸优化能成为机器学习地基的物理原因。

**要点：识别「平方范数结构」= 免费获得凸性**。建模时优先把目标写成「范数平方 + 光滑项」的形式，凸性往往随之而来。

**这个结论的直接推论**：任何「最小二乘类」问题（回归、插值、滤波、反问题）都是凸 QP，不管数据矩阵有多「病态」——$A^TA$ 恒半正定是绝对的。反问题的正则化版本更是如此：最小二乘 + 正则项（岭）仍是凸 QP，且由于 $P$ 正定，解唯一、数值稳定。这就是为什么「反问题 = 凸 QP」能成为「从极限到大模型」里一条几乎免费的理论保证。<span class="marginnote">注意一个边界情况：$A$ 列不满秩时 $P = A^TA$ 半正定但奇异，目标有无穷多个最优（一条水平线/面），但仍「凸」——<strong>凸 ≠ 唯一解，凸只保证「解集是凸集」且「局部即全局」</strong>。</span>

## 5 非凸 QP 怎么办

若 $P$ 确实不定，选项有三：

**SDP 松弛**：把非凸二次问题松弛为半定规划（第二篇 SDP 章），得到多项式时间的**下界**——不保证原问题最优，但给出可用的界。
**分解/分支定界**：对非凸 QP 用分支定界（第八篇）在有限精度内逼近全局最优。
**重新建模**：检查约束能否「吸收」非凸项——如把 $x^TPx$ 改写成「引入辅助变量」的凸形式。<span class="marginnote">工程铁律：<strong>遇到不定 $P$，先想能不能绕开</strong>。绕不开才动用 NP-hard 算法（分支定界等）。很多「非凸 QP」其实是建模不当——比如让变量进二次项前没做适当的替换。在「从极限到大模型」里，这对应「把非凸损失改写成凸代理损失」的常见实践。</span>

**术语速查：**

| 术语 | 含义 | 一句话记忆 |
| --- | --- | --- |
| QP | 二次目标 + 线性约束 | 二次版 LP |
| $P \succeq 0$ | 半正定 | 凸的钥匙 |
| $P \succ 0$ | 正定 | 严格凸、解唯一 |
| 不定矩阵 | 有负特征值 | 非凸、NP-hard |
| 结构凸 | 平方范数/协方差/能量 | 白送凸性 |
| Cholesky | $P = LL^T$ 分解 | 半正定的探针 |
| 松弛 | 放宽非凸项成凸 | 绕开 NP-hard |
| 凸代理 | 用凸函数近似非凸损失 | 建模铁律 |

## 6 小结

- **QP 标准形式**：$\min \frac12x^TPx + q^Tx$ s.t. $Gx\le h,\ Ax=b$；LP 是 $P=0$ 特例。
- **凸性判别**：$P \succeq 0$ 即凸；$P\succ0$ 严格凸、解唯一；$P$ 不定则 NP-hard。
- **结构凸**：平方范数结构（$A^TA$）、协方差、能量——天然半正定。
- **判别手段**：特征值 / Cholesky / 主元 / 直接丢求解器。
- **非凸出路**：SDP 松弛、分支定界、重新建模。
- **工作流**：展开读出 $P$ → Cholesky 或结构检查 → 凸则用积极集/内点、非凸则先想凸化再想硬解。
- **数值直觉**：一维 $f=-x^2$ 的端点皆局部极小却无「全局证书」——凸性的本质是「局部即全局」。
- **与主线相连**：最小二乘、岭、SVM、组合优化全都落在 QP 里——认出二次项 = 认出问题类型。
- **一句话复盘**：QP 的「甜」来自「约束线性 + 目标二次」；凸性的生死线是「$P$ 半正定」——它决定你是用多项式算法还是掉进 NP-hard。
- **动手建议**：用 `numpy` 展开一个随机最小二乘的 $P = 2A^TA$ 并做 Cholesky，直观确认「任何 $A$ 都半正定」；再构造一个 $P$ 有负特征值的例子，看求解器如何报非凸。
