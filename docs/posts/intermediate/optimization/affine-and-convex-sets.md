## 为什么从「集合的形状」开始

这个网站叫「从极限到大模型」。走到今天，我们手上已经有两件工具：第一级《基础数学》教会我们用集合与不等式说话<span class="marginnote">「把对象写进花括号」是集合的功劳：本专题里几乎每一个集合都写作 $\{x \mid \cdots\}$ 的描述法，这是第一级《集合的概念》埋下的伏笔。</span>，第二级《线性代数》给了我们向量、范数与线性方程组的语言。而**最优化理论**要回答的问题只有一句话：**在允许的范围里，把目标函数做到最好**。「允许的范围」在数学里就是一个集合——可行域。可行域的形状，决定了这个优化问题好不好解。

于是本节研究凸分析的第一课：**集合的形状**。两个最基础的问题：什么样的集合「平坦得可以平移」？什么样的集合「凹陷的、带缝的都不行，只有鼓鼓的才是好公民」？前者引出**仿射集**，后者引出**凸集**与**凸锥**。它们是最优化的地基：凸优化问题之所以好解，几乎全部源于可行域是凸的——我们会在第二篇证明「局部最优即全局最优」，在第三篇用「分离超平面」把最优性与几何挂钩，而这些都建立在今天的概念上。

## 1 仿射集：过两点的直线仍留在集合内

先从最熟悉的几何对象出发。直线、平面、三维空间里的超平面，它们有一个共同特征：**过集合内任意两点的整条直线，都仍在这个集合里**。把这个特征写严格，就是仿射集的定义。

**仿射集（affine set）**：集合 $C \subseteq \mathbb{R}^n$ 称为仿射集，若对任意 $x_1, x_2 \in C$ 与任意实数 $\theta \in \mathbb{R}$，都有

$$
\theta x_1 + (1 - \theta) x_2 \in C
$$

注意 $\theta$ 取遍**全体实数**，不是只取 0 到 1。当 $\theta$ 从 $-\infty$ 滑到 $+\infty$，$\theta x_1 + (1-\theta)x_2$ 描出的正是过 $x_1$、$x_2$ 两点的**整条直线**（$\theta = 1$ 时落在 $x_1$，$\theta = 0$ 时落在 $x_2$，$\theta = \frac12$ 时是中点）。「仿射」要求的是整条直线都留在集合内，而不是两点之间那一小段。

把定义从「两个点」推广到「有限个点」，就得到仿射组合：

**仿射组合（affine combination）**：$\theta_1 x_1 + \cdots + \theta_k x_k$，其中 $\theta_1 + \cdots + \theta_k = 1$。**一个集合是仿射集，当且仅当它包含其中任意有限个点的一切仿射组合。**

仿射集最深刻的结构藏在它与线性子空间的关系里。

**仿射集 = 线性子空间 + 平移**：若 $C$ 是仿射集且 $x_0 \in C$，则 $V = C - x_0 = \{x - x_0 \mid x \in C\}$ 是一个线性子空间；反过来，$C = x_0 + V$。<span class="marginnote">这解释了「仿射」（affine）一词的来历：它比「线性」多了一个平移。线性子空间必须过原点，仿射集则可以「偏离原点」——这正是线性代数里「线性方程组的解集 = 特解 + 齐次解空间」的几何形态。</span>

**例子（线性方程组的解集）**：设 $A \in \mathbb{R}^{m \times n}$，$b \in \mathbb{R}^m$，集合

$$
\{x \in \mathbb{R}^n \mid Ax = b\}
$$

若非空，就是仿射集：任取 $x_1, x_2$ 满足 $Ax_1 = Ax_2 = b$，则对任意 $\theta$，

$$
A\big(\theta x_1 + (1-\theta)x_2\big) = \theta Ax_1 + (1-\theta)Ax_2 = \theta b + (1-\theta)b = b
$$

解集是仿射集。它与线性代数里「非齐次方程组的解 = 一个特解加上齐次解空间」完全一致：$x_0$ 是特解，$V$ 是 $Ax=0$ 的解空间（零空间）。<span class="marginnote">这里有一个常见约定：<strong>空集也算仿射集</strong>（Boyd 中注明 by convention）。不然「$Ax=b$ 无解时解集是不是仿射集」就成了一桩悬案。约定空集为仿射集，让许多命题不用再单独讨论无解情形。</span>

**辨析｜易错点：仿射集不一定包含原点。** 直线、平面一般不过原点；只有「过原点的仿射集」才是线性子空间。判断一个集合是否仿射，唯一的标准是「过任意两点的直线是否留在集合内」，与原点无关。

## 2 凸集：线段仍在集合内

把上一条定义里 $\theta$ 的范围从「全体实数」收窄到「0 和 1 之间」，就得到凸集——这也是本专题最重要的一个概念。

**凸集（convex set）**：集合 $C \subseteq \mathbb{R}^n$ 称为凸集，若对任意 $x_1, x_2 \in C$ 与任意 $\theta \in [0, 1]$，都有

$$
\theta x_1 + (1-\theta)x_2 \in C
$$

现在 $\theta$ 只取 $[0,1]$，$\theta x_1 + (1-\theta)x_2$ 描出的不再是整条直线，而是两点之间那条**线段**。「凸」就是「集合没有凹坑、没有裂缝」：任意两点的连线段都老老实实躺在集合内。<span class="marginnote">几何直觉：站在集合内部任意一点，往任意方向看去，视线都能看到边界而不被自己挡住——集合处处「鼓起」。这个直觉在第五篇《分离超平面定理》会变成严格陈述。</span>

**凸组合（convex combination）**：$\theta_1 x_1 + \cdots + \theta_k x_k$，其中 $\theta_i \ge 0$ 且 $\theta_1 + \cdots + \theta_k = 1$。仿射组合只要求系数和为 1，凸组合额外要求系数**非负**——于是凸组合是「带权平均」，每一项的权重都非负且加起来是 1。**集合 $C$ 是凸集，当且仅当它包含其中任意有限个点的一切凸组合。**

仿射与凸的差别，全在那个系数上：

| 性质 | 系数条件 | 几何对象 | 例子 |
| --- | --- | --- | --- |
| 仿射组合 | $\sum \theta_i = 1$ | 整条直线 | 过 $x_1,x_2$ 的直线 |
| 凸组合 | $\sum \theta_i = 1,\ \theta_i \ge 0$ | 两点间线段 | 线段 $[x_1, x_2]$ |

因为线段是直线的一部分，**仿射集一定是凸集**（$\theta \in [0,1]$ 是 $\theta \in \mathbb{R}$ 的特例）；反过来凸集不一定是仿射集，半空间就是典型例子。一条有用的直觉：**凸集 = 允许「平均」；仿射集 = 允许「整个线性插值」**。

**辨析｜易错点：「中点凸」不顶用。** 有些定义只要求中点在集合内（$\theta = \frac12$ 的情形）。对闭集来说，反复取中点可以逼近整条线段，于是「中点凸 + 闭」确实能推出凸；但对一般的集合，只保证中点会让「星形却漏掉中间大片」的怪集合蒙混过关。本书定义直接要求整个线段，稳妥、无歧义。

## 3 凸锥：射线都在集合内

第三种形状是「从原点出发的射线」。**锥（cone）**：集合 $C$ 称为锥，若对任意 $x \in C$ 与任意 $\theta \ge 0$，都有 $\theta x \in C$——把集合里任意一点沿原点方向拉长任意非负倍数，仍在集合内。锥不一定凸：例如两条不共线的射线并在一起（一个「V」字）是锥但不是凸集。

把「锥」与「凸」叠在一起，就得到最有用的对象。

**凸锥（convex cone）**：$C$ 称为凸锥，若它既是锥又是凸集。等价地，对任意 $x_1, x_2 \in C$ 与任意 $\theta_1, \theta_2 \ge 0$，都有

$$
\theta_1 x_1 + \theta_2 x_2 \in C
$$

凸锥 = 对**非负线性组合**封闭。平面直角坐标系的第一象限 $\{(x_1, x_2) \mid x_1 \ge 0, x_2 \ge 0\}$ 是凸锥；$\mathbb{R}^n$ 里最重要的凸锥有：

- **范数锥（norm cone）**：$C = \{(x, t) \in \mathbb{R}^{n+1} \mid \|x\|_2 \le t\}$，像一只倒扣的「冰淇淋蛋筒」。它是二阶锥规划（SOCP）的核心对象，我们会在第二篇见到。
- **半正定锥（PSD cone）**：$S^n$ 中所有半正定矩阵构成的集合，记作 $S_+^n$。它是半定规划（SDP）的舞台，也是「$X \succeq 0$」这类记号背后那个集合。

凸锥是「带方向的加法」：两个可行方向一加权就能继续用。机器学习里的对偶锥、多目标里的支配锥，都是它的化身。<span class="marginnote">一个容易混的层级关系：子空间 $\subseteq$ 仿射集 $\subseteq$ 凸集；而子空间同时也是凸锥。仿射集不必过原点，凸锥却必须过原点——「锥」字本身就把顶点钉在了原点。</span>

## 4 基本例子：从超平面到多面体

有了三种定义，下面用 Boyd 的经典例子把它们一一落成具体的集合。以下全部在 $\mathbb{R}^n$ 中，$a \neq 0$。

**超平面（hyperplane）**：$\{x \mid a^T x = b\}$。它是仿射集（从而也是凸集）。验证很简单：若 $a^T x_1 = a^T x_2 = b$，则对任意 $\theta$，$a^T(\theta x_1 + (1-\theta)x_2) = \theta b + (1-\theta)b = b$，整条直线都在上面。$a$ 是超平面的法向量，$b$ 决定它离原点的距离。在 $\mathbb{R}^2$ 里超平面就是直线，在 $\mathbb{R}^3$ 里是平面。

**半空间（halfspace）**：$\{x \mid a^T x \le b\}$。它是凸集但**不是**仿射集——它只含直线的一侧，不含整条直线。它的边界恰好是超平面 $\{x \mid a^T x = b\}$。把不等号换严格，$\{x \mid a^T x < b\}$ 仍是凸集，但既不开（open）也不闭（closed），在后面的优化理论里要单独小心对待。

**球（Euclidean ball）**：以 $x_c$ 为球心、半径 $r > 0$：

$$
B(x_c, r) = \{x \mid \|x - x_c\|_2 \le r\}
$$

它是凸集——这正是下一节「公式解析」要亲手验证的结论。把范数换成其他 $p$ 范数 $\|x\|_p$（$p \ge 1$），得到的 $p$ 范数球也都是凸集；机器学习里常见的 $\ell_1$ 球（菱形）、$\ell_\infty$ 球（方块）都在其列，正则化与稀疏性全靠它们刻画。

**椭球（ellipsoid）**：取 $P$ 为对称正定矩阵（$P \in S_{++}^n$），

$$
\mathcal{E} = \{x \mid (x - x_c)^T P^{-1} (x - x_c) \le 1\}
$$

它也可以写成 $\mathcal{E} = \{x_c + Au \mid \|u\|_2 \le 1\}$，其中 $A = P^{1/2}$。正定矩阵 $P$ 在这里扮演「方向加权」的角色：$P$ 的特征向量给出椭球各主轴的方向，特征值给出各轴长度——这正是线性代数里「二次型与正定矩阵」在我们面前的第一次实战应用。椭球是内点法、椭球法与信赖域的常客。

**多面体（polyhedron）**：有限个半空间与超平面的交集：

$$
\mathcal{P} = \{x \mid a_i^T x \le b_i,\ i = 1,\ldots,m;\ \ c_j^T x = d_j,\ j = 1,\ldots,p\}
$$

写成矩阵形式就是 $\mathcal{P} = \{x \mid Ax \preceq b, Cx = d\}$。多面体一定是凸集——因为半空间与超平面都是凸集，而有限个凸集的交集保持凸（见第 6 节）。单位立方体、单纯形（$\{x \succeq 0, \mathbf{1}^T x = 1\}$）都是多面体。线性规划（LP）的可行域就是多面体，这是第四篇的全部主角。

把这五个例子并排看，形状的谱系一目了然：超平面（最「平」）→ 半空间 → 球 → 椭球 → 多面体（由平片拼出，可有尖角）。

上图把「凸 / 非凸」的差别画成一幅图：左图是凸集，$x$ 与 $y$ 之间那整条线段都躺在集合内；右图是非凸集，$x$、$y$ 都在集合内，可它们之间的线段却有一段穿出集合之外——非凸性，本质就是「两点在集内、中间那段却溜到了集外」。

## 5 公式解析：证明球是凸集

上面说「球是凸集」，不能只靠眼睛看，得用手证。这一节的公式解析就完成一次完整推理链。

**命题**：设 $x_c \in \mathbb{R}^n$，$r > 0$，则球 $B = \{x \mid \|x - x_c\|_2 \le r\}$ 是凸集。

**要证**：任取 $x, y \in B$ 与 $\theta \in [0, 1]$，都有

$$
\theta x + (1-\theta) y \in B
$$

即验证 $\|\theta x + (1-\theta)y - x_c\|_2 \le r$。完整推理链拆成三步：

- **第一步，写出凸组合**：这是套定义，没有任何技巧，但必须写清楚——「$z = \theta x + (1-\theta)y$，目标是 $\|z - x_c\| \le r$」。
- **第二步，把球心「塞进组合里」**：这一步是整个证明的眼睛。注意到 $\theta x_c + (1-\theta)x_c = x_c$，于是

$$
z - x_c = \theta x + (1-\theta)y - x_c = \theta (x - x_c) + (1-\theta)(y - x_c)
$$

  因为 $x_c$ 拆成了它自己的凸组合，$z - x_c$ 就被改写成两个「点到球心的差向量」的同一组合。**凸性的核心技巧常常就是把某个不动点拆成加权和，好让它参与后续的放缩。**
- **第三步，三角不等式收尾**：由三角不等式与系数非负，

$$
\|z - x_c\|
= \|\theta (x - x_c) + (1-\theta)(y - x_c)\|
\le \theta \|x - x_c\| + (1-\theta) \|y - x_c\|
\le \theta r + (1-\theta) r
= r
$$

  $\theta, 1-\theta \ge 0$ 保证「提出系数时不改变不等号」——这是第一级《基础数学》里「可乘性分正负」的翻版；而三角不等式 $\|u + v\| \le \|u\| + \|v\|$，是向量范数三公理之一，由第二级《线性代数》的内积与柯西–施瓦茨不等式推出。

- **第四步，画上句号**：对任意 $x, y \in B$ 与 $\theta \in [0,1]$，都有 $\theta x + (1-\theta)y \in B$，按定义 $B$ 是凸集。$\blacksquare$

注意第三步里两处放缩各司其职：第一个 $\le$ 是三角不等式（对任意向量都真），第二个 $\le$ 用 $x, y \in B$（即 $\|x-x_c\|, \|y-x_c\| \le r$）。而 $\theta \in [0,1]$ 保证了 $\theta r + (1-\theta)r$ 正好是 $r$——如果 $\theta$ 能取到区间外，两个系数一正一负，第二个放缩就会失去依据。**这个推理链长得近乎机械，正是凸性定义的直接兑现；后面我们会用同一套「三步走」证明许多集合的凸性。**

## 6 凸集运算的保持性质

光会认还不算数，得会「造」。本节的保持性质告诉我们：从已知凸集出发，用哪些运算拼出来的新集合仍是凸集。这里先讲两条最基础的，透视与线性分式函数留到下一篇《保凸运算》。

**交集保持凸性**：若 $C_1, C_2$ 是凸集，则 $C_1 \cap C_2$ 是凸集。证明几乎是免费的：任取 $x, y \in C_1 \cap C_2$，则 $x, y$ 同属 $C_1$，线段 $[x,y] \subseteq C_1$；同理 $[x,y] \subseteq C_2$，故 $[x,y] \subseteq C_1 \cap C_2$。任意多个凸集（哪怕无限个）的交集都保持凸——多面体是有限个半空间/超平面的交集，所以多面体凸，正是这条性质的直接推论。

**辨析｜易错点：并集不保持凸性。** 上图的非凸集就可以看成两个「鼓包」的并集——两个凸集一并为凹腰，凸性立刻丢掉。做优化时「可行域 = 几个约束的交」让人放心，因为交是安全的；而「可行域 = 几个情形的并」则是典型的不凸来源，整数规划里处处是这种坑。

**仿射函数的像与原像保持凸性**：设 $f(x) = Ax + b$ 是仿射映射，则

- 若 $C$ 是凸集，则 $f(C) = \{Ax + b \mid x \in C\}$ 是凸集；
- 若 $D$ 是凸集，则 $f^{-1}(D) = \{x \mid Ax + b \in D\}$ 是凸集。

平移、缩放、旋转、投影都属于仿射映射，所以凸集被「平移缩放」还是凸的。这条性质还带来一个重要推论：**线性矩阵不等式（LMI）的解集是凸的**——$\{x \mid A_0 + x_1 A_1 + \cdots + x_n A_n \preceq 0\}$ 是半正定锥在半仿射映射下的原像，所以凸。这为第二篇的半定规划铺好了地基。<span class="marginnote">「保持性质」是凸分析里的惯用武器：与其一个个检查新集合，不如把它写成「已知凸集的某种运算」。这也是为什么我们在第 4 节先认超平面、半空间、球、椭球、多面体这些「砖」，第 6 节再学「砂浆」——砖拼砂浆，才能盖出大片可行域。</span>

## 7 小结

- **仿射集**：过任意两点的整条直线都留在集合内；仿射组合系数和为 1；仿射集 = 线性子空间 + 平移。例：$\{x \mid Ax = b\}$ 的解集。
- **凸集**：过任意两点的线段都留在集合内；凸组合系数非负且和为 1；仿射集 ⊂ 凸集。
- **凸锥**：对非负倍数与非负线性组合封闭；范数锥、半正定锥是两颗明星。
- **基本例子**：超平面（仿射）、半空间（凸非仿射）、球、椭球、多面体（半空间与超平面之交）。
- **保持性质**：交集、仿射像与原像都保持凸性；并集不保持。
- **证明套路**：证凸性 = 写凸组合 → 把不动点拆成加权和 → 三角不等式放缩。

在下一节，我们先把凸组合升级成「凸包」，用少数几个点生成大片的凸区域；然后，把「线段落在集合内」这把尺子架到函数上——若对任意 $x, y$ 与 $\theta \in [0,1]$ 恒有

$$
f\big(\theta x + (1-\theta) y\big) \le \theta f(x) + (1-\theta) f(y)
$$

函数就是**凸函数**。这就是下一节《凸函数》的入口：集合的凸性管「可行域」，函数的凸性管「目标」，两者合璧，才拼出完整的凸优化世界。
