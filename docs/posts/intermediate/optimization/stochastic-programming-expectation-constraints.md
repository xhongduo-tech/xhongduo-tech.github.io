## 为什么确定性模型不够

前九篇的模型假设参数确定——但现实参数（需求、收益率、故障率）是随机的。把随机参数直接塞进确定性模型，解可能「在期望意义上灾难」。**随机规划（stochastic programming）**系统处理「参数带随机性」的优化：目标取期望、约束取期望或概率形式，并给出可计算的求解方法。<span class="marginnote">随机规划是运筹学的核心分支（Dantzig 1955 奠基），在能源、金融、物流、供应链里无处不在。它的核心挑战是「期望」：目标 $E_\xi[f(x,\xi)]$ 的期望一般没有闭式，要靠采样逼近。本节聚焦两条主线：<strong>期望约束</strong>（约束在平均意义下满足）与<strong>两阶段规划</strong>（先决定、后补救）。</span>

## 1 随机参数下的三种问题形式

设随机向量 $\xi$ 服从分布 $P$，问题含随机参数。三种标准建模：

**期望目标**：$\min_x\ E_\xi[f(x,\xi)]$——「平均意义上最优」。
**期望约束**：$E_\xi[g(x,\xi)] \le 0$——「平均意义上满足约束」（本节重点）。
**概率约束（chance constraint）**：$P_\xi(g(x,\xi) \le 0) \ge 1-\alpha$——「以高概率满足」（下节延伸）。<span class="marginnote">三种形式表达不同的风险态度：期望目标 = 中性（平均最优）；期望约束 = 平均可行；概率约束 = 保守（高概率可行）。它们可互相转化——把概率约束用指示函数写进目标就得到「CVaR」等风险度量，把期望约束的乘子展开就得到拉格朗日型方法。随机规划的建模艺术在于「选对风险语言」。</span>

## 2 期望约束问题与 SAA

**期望约束随机规划**的标准形式：

$$
\min_x\ E_\xi[f(x,\xi)] \quad \mathrm{s.t.}\quad E_\xi[g_i(x,\xi)] \le 0,\ x \in \mathcal{X}
$$

**难点**：期望 $E_\xi[\cdot]$ 通常无闭式（$f, g$ 非线性、$\xi$ 连续分布）。**样本平均逼近（Sample Average Approximation, SAA）**用独立样本 $\xi^1, \ldots, \xi^N$ 近似：

$$
\min_x\ \frac1N\sum_{j=1}^{N} f(x, \xi^j) \quad \mathrm{s.t.}\quad \frac1N\sum_{j=1}^{N} g_i(x, \xi^j) \le 0
$$

**SAA 的性质**：把随机问题变成确定性问题（只是样本多、规模大）；$N \to \infty$ 时 SAA 解收敛到原问题解（大数定律 + 一致性定理）。<span class="marginnote">SAA 是随机规划的「工作马」：它把期望换成样本平均，剩下的交给确定性优化器。收敛理论保证：$N$ 足够大时，SAA 最优值与真最优值之差以 $O(1/\sqrt N)$ 衰减（样本复杂度）。工程上 $N$ 常取「样本量 = 数据量」，配「样本外验证」估计解的质量。<strong>SAA 是「随机问题 → 确定性问题的万能翻译器」。</strong></span>

## 3 两阶段随机规划

**两阶段随机规划（two-stage stochastic programming）**处理「先决策、后补救」：

$$
\min_x\ c^Tx + E_\xi\big[Q(x, \xi)\big] \quad \mathrm{s.t.}\quad Ax = b,\ x \ge 0
$$

其中 $Q(x,\xi) = \min_y\{ q(\xi)^Ty : T(\xi)x + Wy = h(\xi),\ y \ge 0\}$ 是**第二阶段（补救）问题**——第一阶段的 $x$ 决定后，随机实现 $\xi$ 揭晓，再以最小代价 $Q$ 补救。<span class="marginnote">直觉：第一阶段「现在决定」（如建多少电厂），第二阶段「未来补救」（需求随机，事后买多少电）。$W$ 是<strong>补偿矩阵</strong>，$Q$ 度量「事后调整的成本」。两阶段规划把「不确定性」变成「后悔的期望」——决策在「现在就定」与「未来可改」之间权衡。它是能源、物流、金融里最标准的随机规划模型。</span>用 SAA 离散化 $\xi$ 后，两阶段问题变成一个大 LP（场景数 × 各阶段变量）。

## 4 公式解析：期望约束的拉格朗日对偶

期望约束问题也有干净的对偶理论。考虑

$$
\min_x\ E[f(x,\xi)] \quad \mathrm{s.t.}\quad E[g(x,\xi)] \le 0
$$

- **第一步，写拉格朗日**：$L(x, \lambda) = E[f(x,\xi)] + \lambda E[g(x,\xi)] = E\big[f(x,\xi) + \lambda g(x,\xi)\big]$——**期望与拉格朗日可交换**（线性算子的交换）。
- **第二步，对偶函数**：$d(\lambda) = \inf_x E[f + \lambda g] = E[\inf_x(f + \lambda g)]$？——不总是相等（下确界与期望交换需条件），但弱对偶 $d(\lambda) \le p^*$ 恒成立。
- **第三步，SAA 下的强对偶**：用 SAA 离散化后是普通凸问题，Slater 下强对偶成立——对偶变量 $\lambda^*$ 是**期望约束的影子价格**（「平均约束每放松一格，最优期望成本降多少」）。
- **第四步，乘法器方法**：期望约束也可用增广拉格朗日迭代（第六篇）——每步对随机目标做 SAA，乘子更新处理期望约束。<span class="marginnote">这条「期望与拉格朗日交换」的代数，是随机优化与对偶理论衔接的枢纽：它让「约束在期望意义下」也能用乘子定价。工程上这支撑了「随机对偶分解」类算法——把大随机问题拆成场景子问题，用乘子协调。</span>

## 5 随机规划速查与辨析

| 建模 | 形式 | 风险态度 | 求解 |
| --- | --- | --- | --- |
| 期望目标 | $\min E[f]$ | 中性 | SAA + 确定性优化 |
| 期望约束 | $E[g] \le 0$ | 平均可行 | SAA / 对偶 |
| 概率约束 | $P(g \le 0) \ge 1-\alpha$ | 保守 | 需转化（SAA 或凸近似） |
| 两阶段 | $c^Tx + E[Q(x,\xi)]$ | 后悔最小 | 场景分解 + Benders |

**辨析｜易错点：**其一，SAA 的样本量 $N$ 不是越大越好无脑——大 $N$ 成本高，且「样本内最优」可能「样本外差」，要配验证；其二，期望约束与概率约束**不是一回事**——$E[g]\le0$ 允许「一半场景严重违反、一半场景大幅满足」的抵消，风险中性者可以接受，保守者不能；其三，两阶段问题的**补偿矩阵 $W$ 要恰当**——不可行补偿（某些场景无法补救）会让问题无界或不可行，需预检验；其四，随机参数的**分布选择**决定一切——分布错了，SAA 再精确也白搭。<span class="marginnote">在「从极限到大模型」里，随机规划的思想渗透在：鲁棒机器学习（数据分布偏移）、随机优化的约束处理、以及「分布鲁棒优化」（DRO）——后者把「期望」换成「最坏分布的期望」，是期望约束的「稳健升级」。理解期望约束，就是理解「在不确定下的优化」这一大类的数学语法。</span>

## 6 数值算例：SAA 的一次手工展开

用一个极小的两阶段问题演示「期望 → 样本平均」的展开。设第一阶段只决定 $x$，第二阶段需求 $\xi$ 服从两点分布：$\xi = 5$（概率 $0.5$）或 $\xi = 8$（概率 $0.5$）。补偿问题为

$$
Q(x,\xi) = \min_y \{ 3y :\ y \ge \xi - x,\ y \ge 0 \}
$$

（需求超出 $x$ 的部分按单位成本 3 补救）。第一阶段目标 $\min_x\ 2x + E[Q(x,\xi)]$，$x \ge 0$。

- **闭式期望**：$E[Q(x,\xi)] = 0.5\cdot3\max(5-x,0) + 0.5\cdot3\max(8-x,0)$。分段讨论：$x \le 5$ 时等于 $0.5\cdot3(5-x) + 0.5\cdot3(8-x) = 19.5 - 3x$；$5 < x \le 8$ 时等于 $0.5\cdot0 + 1.5(8-x) = 12 - 1.5x$；$x > 8$ 时为 0。
- **整体目标**：$x \le 5$ 时 $2x + 19.5 - 3x = 19.5 - x$，随 $x$ 递减，取 $x=5$ 得 $14.5$；$5 < x \le 8$ 时 $2x + 12 - 1.5x = 12 + 0.5x$，随 $x$ 递增，取 $x=5$ 得 $14.5$；$x > 8$ 时 $2x$ 递增。故最优 $x^* = 5$，期望成本 $14.5$。

**SAA 视角**：用 $N=2$ 个样本 $\xi^1 = 5,\ \xi^2 = 8$ 逼近，得确定性问题 $\min_x\ 2x + \tfrac12[3\max(5-x,0) + 3\max(8-x,0)]$，与上面的期望表达式**逐项相同**——两点分布下 $N=2$ 恰好「精确」。真实世界分布连续，SAA 的样本只是近似，这就引出「样本外验证」的必要性。<span class="marginnote">这个算例最值得记的一点：<strong>两阶段问题的目标不是单点，而是「决策 + 期望后悔」的折中</strong>。$x$ 太小补救贵，$x$ 太大预置浪费；最优 $x^*=5$ 恰好让「预置成本」与「期望补救」的边际相等——这正是随机规划里「供需平衡」的数学形状。</span>

把这次手工展开上升为方法，SAA 有两条纪律：其一，**样本必须独立同分布**——样本间相关会让「平均」系统性偏离真实期望，尤其时间序列数据要警惕；其二，**对比方案时用公共随机数（common random numbers）**——让两个候选解吃同一批样本，随机波动在差里抵消，方案高下看得更清。这两条是随机实验设计的通用原则，放到仿真、强化学习评估里同样成立。

这个例子还演示了「决策规则」的雏形：$x$ 的最优值不依赖 $\xi$ 的实现（第一阶段先定），而补救量 $y$ 却随 $\xi$ 变化——**第一阶段的决策要「稳健」，第二阶段的决策才「随机」**。把这条分层直觉记住，读任何两阶段模型的文献都不会迷路。

## 7 随机规划工具箱

| 工具 | 解决什么 | 一句话 |
| --- | --- | --- |
| SAA | 期望不可算 | 期望换样本平均 |
| 场景树 | 期望可离散化 | 把分布变成有限分支 |
| L 形方法 / Benders | 两阶段大规模 | 场景分解 + 割平面协调 |
| 增广拉格朗日 | 期望约束 | 乘子迭代处理平均约束 |
| 分布鲁棒（DRO） | 分布不确定 | 最坏分布的期望 |

**辨析｜易错点：**其一，别把「SAA 的最优值」当「真最优值」——最小化问题里样本内最优偏乐观，样本越大越准；其二，期望约束与「软约束」不同——软约束可违反、付代价，期望约束必须平均成立；其三，场景数量与求解规模指数相关，两阶段问题的场景爆炸要配分解算法，别无脑把场景全塞进一个 LP。<span class="marginnote">在机器学习语境里，随机规划的味道随处可见：<strong>经验风险最小化本身就是「SAA 化」的期望目标</strong>，Dropout 可看作「随机化补偿」，域随机化是「对参数分布做场景平均」——理解了 SAA，你就理解了训练损失函数的数学出身。</span>

## 8 小结

- **随机规划**：参数带随机性；期望目标 / 期望约束 / 概率约束三种风险语言。
- **期望约束**：$E[g(x,\xi)] \le 0$——平均意义下满足。
- **SAA**：期望换样本平均，随机问题变确定性；$N \to \infty$ 收敛。
- **两阶段规划**：先决策 + 后补救的期望；场景分解可解。
- **两阶段直觉**：第一层决策稳健，第二层决策随机——分层记住不迷路。
- **对偶**：期望与拉格朗日交换，期望约束有影子价格。
- **SAA 纪律**：样本独立同分布、对比用公共随机数——期望近似才可靠。
