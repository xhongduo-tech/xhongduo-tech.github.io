## 为什么顶点要用「基」来算

上一节的顶点是几何概念：$n$ 条独立约束取等的点。但计算机不画图，它需要**代数操作**。把顶点翻译成代数，主角就是**基（basis）**：从等式约束 $Ax = b$ 里挑出一组线性独立的列，把对应变量设为「基本变量」，其余设为零——一个顶点就出来了。<span class="marginnote">这套翻译是单纯形法一切表格操作的地基：算法不是在「多面体上爬」，而是在「基之间切换」。搞懂了「顶点 = 基可行解」的对应，单纯形法的换基迭代就只是「从一个基滑到相邻基」的代数实现。</span>

## 1 标准形式与基的选取

LP 的**等式标准形式**是

$$
\min_x\ c^Tx \quad \mathrm{s.t.}\quad Ax = b,\ x \ge 0
$$

设 $A \in \mathbb{R}^{m\times n}$，$m \le n$ 且 $A$ 行满秩。从中挑出 $m$ 列构成**基矩阵** $B$（要求 $B$ 可逆），其余 $n-m$ 列记 $N$。相应地，变量分为

- **基本变量（basic variables）** $x_B$：对应基矩阵的列。
- **非基本变量（nonbasic variables）** $x_N$：其余变量。

**基本解（basic solution）**：令 $x_N = 0$，解 $B x_B = b$ 得 $x_B = B^{-1}b$。于是

$$
x = \begin{pmatrix} x_B \\ x_N \end{pmatrix} = \begin{pmatrix} B^{-1}b \\ 0 \end{pmatrix}
$$

是一个「顶点候选」。若 $B^{-1}b \ge 0$（基本变量非负），它就是**基本可行解（basic feasible solution, BFS）**。<span class="marginnote">「基」的选择有 $\binom{n}{m}$ 种，每个可逆的 $B$ 对应一个基本解，但不一定可行（可能 $x_B$ 有负分量）。可行才配叫「顶点」。标准形里「$x \ge 0$」这一条，正是区分「基本解」与「基本可行解」的分界线。</span>

## 2 对应定理：BFS = 顶点

**核心定理（BFS 与顶点一一对应）**：设 LP 为标准形式且 $A$ 行满秩。则 $x$ 是可行域的**顶点**，当且仅当 $x$ 是一个**基本可行解**。

证明的骨架分两半：

**BFS ⇒ 顶点**：设 $x$ 是 BFS，基本变量对应可逆 $B$。若 $x = \theta y + (1-\theta)z$ 是两个可行点的组合，则 $y,z$ 的非基本分量也必为 0（因 $x_N = 0$ 且 $y,z \ge 0$）；于是 $By_B = b$、$Bz_B = b$，由 $B$ 可逆得 $y_B = z_B$——$y = z = x$，$x$ 是顶点。<span class="marginnote">这半的直觉：基矩阵可逆，把非基本变量钉死在 0 上，剩下的方程有唯一解——所以 $x$ 不能是任何两点的真凸组合，只能是「角」。</span>
**顶点 ⇒ BFS**：设 $x$ 是顶点。把所有正分量对应的列收集起来，它们线性无关（否则 $x$ 可写成两个可行点的组合，矛盾）；补齐到 $m$ 列构成可逆基 $B$，于是 $x$ 是对应 BFS。

**这条定理是 LP 几何与代数之间的「同一律」**：多面体的角 = 基可行解 = 代数上「挑一组合适列、其余置零」。此后「在顶点间移动」与「在基之间切换」是同一件事的两种说法。

## 3 非退化与退化

若 BFS 的所有基本变量都**严格为正**（$x_B > 0$，零分量个数恰为 $n-m$），称该 BFS **非退化（nondegenerate）**；若某些基本变量为零，称**退化（degenerate）**。

退化的几何含义：**一个顶点被多于 $n$ 条约束同时「压住」**——在 $\mathbb{R}^2$ 里就是一个顶点处三条线共点。退化给单纯形法带来麻烦：换基可能不移动位置（基本变量从 0 换成 0），算法可能原地打转——这正是下一节「循环（cycling）」现象的温床。<span class="marginnote">退化在现实中极其常见：冗余约束、数据线性相关都会造成顶点「重叠」。处理退化的标准武器是 Bland 规则（下一节）与扰动法。记住：<strong>退化不是病，但会传染</strong>——它让几何上「一步一个顶点」的单纯形法可能「一步原地踏步」。</span>

## 4 公式解析：一个 BFS 的手工构造

用具体矩阵演示「选基 → 解方程 → 得 BFS」的完整流程。设

$$
A = \begin{bmatrix} 1 & 1 & 1 & 0 \\ 2 & 1 & 0 & 1 \end{bmatrix}, \quad b = \begin{pmatrix} 4 \\ 6 \end{pmatrix}, \quad n=4,\ m=2
$$

- **第一步，选基**：取 $B = (A_1, A_2) = \begin{bmatrix}1&1\\2&1\end{bmatrix}$，$\det B = -1 \ne 0$，可逆。$x_B = (x_1, x_2)$，$x_N = (x_3, x_4)$。
- **第二步，解方程**：$x_N = 0$，$B x_B = b$ 即 $\begin{cases} x_1 + x_2 = 4 \\ 2x_1 + x_2 = 6 \end{cases}$，解得 $x_1 = 2$、$x_2 = 2$。
- **第三步，判定 BFS**：$x_B = (2,2) \ge 0$——可行！于是 $x = (2,2,0,0)$ 是 BFS（顶点）。
- **第四步，再试一基**：取 $B = (A_2, A_3) = \begin{bmatrix}1&1\\1&0\end{bmatrix}$，$\det = -1$。$x_2, x_3$ 为基本变量，$x_1 = x_4 = 0$，解 $\begin{cases} x_2 + x_3 = 4 \\ x_2 = 6 \end{cases}$ 得 $x_2 = 6$、$x_3 = -2 < 0$——**基本解但不可行**，不是顶点。

**要点：选基的次序改变，解跟着变；只有非负解才是顶点。** 手工验证 $\binom{4}{2} = 6$ 个基，可得本问题顶点分布——这就是「顶点 = 基可行解」的直接演练。

## 5 BFS 的数量与最优性

基本可行解的数量有限：至多 $\binom{n}{m}$ 个，其中可行的那部分对应顶点。这带来一个重要的**搜索原则**：

**若 LP 有最优解，则存在一个基本可行解是最优的。** 证明思路：最优顶点存在（有界情形），而顶点 = BFS。<span class="marginnote">这条原则把「连续优化问题」变成「有限候选问题」：最优解藏在至多 $\binom{n}{m}$ 个 BFS 里。虽然这个数可以巨大（$n=50, m=25$ 时约 $10^{14}$ 量级），但它把「找最优」从无限搜索变成「遍历有限候选」——单纯形法做的正是「聪明地遍历，不全枚举」。</span>工程上由此有了**最优性判定**：若一个 BFS 满足「所有非基本变量的检验数（reduced cost）非负」，它已是最优——这是单纯形法终止的依据。

## 6 公式解析：检验数（reduced cost）为什么能判最优

给定一个 BFS，怎么知道「该不该离开」？答案是**检验数**。设当前基 $B$，把目标写成基本变量与非基本变量的分块：

$$
c^Tx = c_B^T x_B + c_N^T x_N = c_B^T B^{-1}b + \big(c_N^T - c_B^T B^{-1}N\big)x_N
$$

- **第一步，消去基本变量**：由 $x_B = B^{-1}(b - Nx_N)$，把目标里的 $x_B$ 全部换掉，剩下只含 $x_N$ 与常数项。
- **第二步，读出检验数**：$x_N$ 的系数向量 $c_N^T - c_B^T B^{-1}N$ 就是检验数（reduced cost）行。
- **第三步，解读**：把某个非基本变量 $x_j$ 从 0 增加到 1（保持其它非基本变量为 0），目标值变化 $\bar c_j = c_j - c_B^T B^{-1}A_j$。最小化问题中 $\bar c_j < 0$ 说明「增加 $x_j$ 能降目标」——该变量值得进基。
- **第四步，终止判据**：所有 $\bar c_j \ge 0$ 时，任何可行方向都不能再降目标——当前 BFS 最优。<span class="marginnote">检验数的几何含义：<strong>它是目标函数沿「指向相邻顶点的那条棱」的斜率</strong>。斜率向下就走（进基），全是向上或水平的棱就停在顶点——单纯形法的每一步都是「沿某条棱走到下一角」，与梯度下降在连续世界里做的事情如出一辙。</span>

**手工验证**：接着第 4 节的例子，基 $B = (A_1,A_2)$ 对应 BFS $x = (2,2,0,0)$。设目标 $c = (1,2,3,4)$，则 $c_B = (1,2)$，$B^{-1} = \begin{bmatrix}-1&1\\2&-1\end{bmatrix}$（$\det B = -1$）。对非基本变量 $x_3$：$\bar c_3 = 3 - c_B^T B^{-1}A_3 = 3 - (1,2)\binom{-1}{2} = 3 - 3 = 0$；对 $x_4$：$\bar c_4 = 4 - (1,2)\binom{1}{-1} = 4 + 1 = 5 \ge 0$。两个检验数非负，$x = (2,2,0,0)$ 是该目标下的最优顶点——一次「底行检查」判出最优。

这个例子里 $\binom{4}{2} = 6$ 个候选基，只有一部分可行——把可行基对应的 BFS 全列出来，就是 LP 的「顶点清单」。若把目标函数 $c$ 改一改，最优顶点可能切换，但「最优在顶点上」这条事实不变——这就是下一节单纯形法敢在顶点间「跳」的根本保证。

## 7 相邻基与单纯形路径速查

| 概念 | 定义 | 在表上的体现 |
| --- | --- | --- |
| 相邻顶点 | 只差一个变量的两个 BFS | 换一列 |
| 基 | $m$ 个独立列 | 表格左侧列 |
| BFS | 非负的基本解 | 右端列非负 |
| 退化 | 某个基本变量为 0 | 换基后位置不动 |
| 检验数 | $c_N^T - c_B^T B^{-1}N$ | 表格底行 |
| 最优判据 | 全部检验数非负 | 底行无负数 |

**辨析｜易错点：**其一，一个 BFS 可能对应多个基（退化时），所以「BFS 与基」不是一一对应，而是「顶点 ↔ BFS 一一对应、BFS 可配多个基」；其二，检验数非负只判「该 BFS 最优」，不保证唯一——检验数出现 0 说明存在其它同值最优顶点；其三，别把「基本解」与「可行解」混为一谈——基本解可能不可行，可行解也可能不是基本解，只有两者交叉才是顶点。<span class="marginnote">把本节与前几节的链条串起来：<strong>多面体有顶点 ⟺ 顶点是 BFS ⟺ 单纯形法在相邻 BFS 间爬</strong>。这就是为什么「基」「顶点」「BFS」三个词可以互换使用——它们是同一枚硬币的三面，理解了这一点，LP 的全部几何与代数就通了。</span>

## 8 小结

- **标准形式**：$\min c^Tx$ s.t. $Ax = b,\ x \ge 0$；基 = $m$ 个独立列。
- **基本解**：$x_N = 0$、$x_B = B^{-1}b$；**基本可行解**要求 $x_B \ge 0$。
- **对应定理**：顶点 ⟺ 基本可行解——几何的角就是代数的基。
- **非退化 / 退化**：$x_B > 0$ / 某个 $x_B = 0$；退化是顶点「重叠」，孕育循环。
- **最优性**：若 LP 有最优解，则某 BFS 达到它；检验数非负判最优。
- **检验数**：$\bar c_j = c_j - c_B^T B^{-1}A_j$——沿棱的目标斜率，非负即最优。
- **顶点清单**：$\binom{n}{m}$ 个基里只有一部分可行——最优藏在其中。
