## 为什么整数规划的「引擎」是分支定界

线性松弛给了下界，但下界不等于解。**分支定界法（branch and bound, B&B）**把「松弛 + 下界」变成一套完备的搜索算法：**把整数变量的小数点「分叉」成两种选择（分支），用松弛下界判断哪些分支不可能含最优（剪枝）**。<span class="marginnote">B&B 是现代整数规划求解器（Gurobi、CPLEX、SCIP）的绝对核心，配以割平面（branch-and-cut）与启发式。它的思想极其朴素——「切小块、淘汰不可能」——却能在实践中处理上亿变量的整数问题。理解 B&B 的「界」，就理解了它为什么聪明。</span>

在「从极限到大模型」的知识地图里，这一站紧接**线性松弛与整数间隙**：上一节告诉你「松弛解差多远」，本节告诉你「如何利用松弛把差距磨掉」。B&B 是整数规划的灵魂算法，而它只有三个零件——分支、定界、剪枝——缺一个都不成立。把这三个零件想透，你就拥有了「为什么商业求解器能解上亿变量」的完整心智模型。

值得先建立的一个直觉：**B&B 不是「暴力枚举的加速版」，而是「用信息淘汰不可能」**。枚举要检查每个解；B&B 用「下界」把一大片解一次性判死刑。一个高效的 B&B 往往只探索几万个节点，却能证明含 $10^{30}$ 个候选解的问题的最优性——靠的正是「用一个不等式剪掉一棵子树」的力量。理解这一点，你就抓住了现代整数规划的全部奥妙。

## 1 分支：把小数解「逼」成整数

假设松弛 LP 给出最优解 $\tilde x$，但某个变量 $\tilde x_j = 2.4$（非整数）。**分支（branching）**把问题分成两个子问题：

$$
x_j \le 2 \quad \text{与} \quad x_j \ge 3
$$

这是**互斥且完备**的划分：整数可行解要么满足 $x_j \le 2$、要么满足 $x_j \ge 3$，无第三种可能。<span class="marginnote">分支的几何：在连续松弛的最优解处「切一刀」，把可行域分成两半——原来那个「最优点」（$x_j = 2.4$）被排除，两个子问题各自重新优化。分支变量选「最偏离整数的」通常最有效，也可用「伪成本」「强分支」等启发式选变量。</span>每个子问题又是一个新的「小整数规划」，继续分支——形成**分支树**：根是原始松弛，叶是「已定界」的节点。

## 2 定界：用松弛给子问题上保险

对每个子问题，解它的 **LP 松弛**得到**局部下界** $\underline{z}$。全局下界是所有未处理节点下界的最小值。同时维护**全局上界 $\bar z$**（当前找到的最好整数可行解的目标值）。

**剪枝（pruning）规则**——当一个节点被判「死刑」，就不再深入：

**不可行剪枝**：子问题的松弛 LP 无可行解 ⇒ 整数解也不存在 ⇒ 剪。
**界限剪枝**：子问题的松弛下界 $\underline{z} \ge \bar z$（最小化情形）⇒ 该子问题不可能比当前最好解更优 ⇒ 剪。
**整数解剪枝**：松弛最优解恰为整数 ⇒ 它就是一个可行解，更新上界 $\bar z$，节点本身被「解决」。<span class="marginnote">剪枝是 B&B 高效的全部秘密：<strong>每个被剪的节点都是一整棵子树的省略</strong>。界限剪枝尤其关键——松弛下界越紧（gap 越小），越多分支被提前剪掉。这就是为什么上一节的「收紧松弛」直接影响 B&B 速度：下界紧一寸，搜索省一片。</span>

**终止**：上界 = 下界（或 gap 小于容差）时，最优解已找到。

**为什么 B&B 一定终止（有限性）**：每次分支都会给整数变量「钉死」一个界（$x_j \le 2$ 或 $x_j \ge 3$）。对有限整数域（如 0-1 或 $0\le x \le U$ 的整数），分支深度有限——最深的叶子是「每个整数变量都被钉到具体整数」，此时要么是整数可行解（更新上界并解决），要么不可行（剪枝）。因此分支树有限、每片叶子都被判定，**B&B 在有限步内必然终止**，且不会漏掉最优（完整性）。<span class="marginnote">一个易混淆点：B&B 的「有限终止」不保证「多项式时间」——最坏情形仍是枚举全部叶子（指数）。但它给了你一个确定性的保证：<strong>只要肯等，一定等到最优解</strong>。相比启发式的「可能找不到」，这是质的不同。</span>

## 3 公式解析：为什么界限剪枝「安全」

把「$\underline{z} \ge \bar z$ ⇒ 剪」证明为「不会漏掉最优」：

**第一步，节点含义**：一个子问题对应「原问题 + 一些额外的整数约束」（分支产生的 $x_j \le 2$ 等）。
**第二步，下界与最优值的关系**：该子问题的整数最优值 $z_{sub}^*$ 满足 $z_{sub}^* \ge \underline{z}$（松弛是下界）。
**第三步，与全局上界比较**：若 $\underline{z} \ge \bar z$，则 $z_{sub}^* \ge \bar z$——子问题里**任何**整数解的目标值都不优于已经找到的 $\bar z$。
**第四步，结论**：探索该子问题不可能改进当前最好解，剪掉它不损失最优性。<span class="marginnote">这套论证的可靠性来自两个「不变量」：<strong>上界 $\bar z$ 永远是某个真实可行解的目标值</strong>（合法性），<strong>下界 $\underline z$ 永远是子问题最优值的下界</strong>（有效性）。两条不变量保证剪枝「只剪不可能更优的」，从而 B&B 完整（不漏解）且完备（有限步终止）。</span>

**一个对称的观察**：若目标是最小化，则「下界 $\underline z$ 越紧，剪得越多」；若最大化，则把「下界/上界」对调后完全同理。B&B 的界可以来自任何「子问题最优值的可靠估计」——LP 松弛是最常用的一种，但也常叠加拉格朗日松弛、半定松弛（本专题第三篇）给出更紧的界。**换一种松弛 = 换一套更锋利的剪枝刀**，这正是 branch-and-bound 家族如此丰富的根源。

## 4 一个完整的小例子

用「$0-1$ 背包」演示 B&B。$\max 45x_1 + 48x_2 + 30x_3$ s.t. $16x_1 + 20x_2 + 14x_3 \le 40$、$x \in \{0,1\}^3$。

**根节点，松弛**：把 $x_i \in \{0,1\}$ 换成 $0\le x_i\le1$，解 LP 得 $x = (1, 0.75, 1)$，$z = 111$。上界 $\bar z = -\infty$（尚无整数解），下界 $\underline z = 111$。
**分支 1（$x_2 \le 0$）**：松弛解 $x = (1, 0, 1)$，$z = 75$——**整数解！** 更新上界 $\bar z = 75$。
**分支 2（$x_2 \ge 1$）**：约束变 $16x_1 + 20 + 14x_3 \le 40$。松弛解 $x = (1, 1, 0.286)$，$z = 93 + 8.57 = 101.6$。非整数，继续分支 $x_3 \le 0$：解 $(1,1,0)$，$z = 93$，整数，但 $93 < \bar z = 75$？不——$93 > 75$，**更新上界 $\bar z = 93$**。
**剪枝**：分支 2 的另一支 $x_3 \ge 1$：$16x_1 + 20 + 14 \le 40$ ⇒ $x_1 \le 0.375$。松弛 $x = (0.375, 1, 1)$，$z = 16.9 + 48 + 30 = 94.9$。它 $\ge \bar z = 93$？是（94.9 > 93），**界限剪枝**——但等等，需要 $x_1$ 分支。继续：$x_1 \le 0$ 时 $z = 78 < 93$，剪；$x_1 \ge 1$ 不可行（容量超），剪。
**结论**：最优 $x^* = (1,1,0)$，$z^* = 93$。

**要点：B&B 用一个「下界 111 → 找到 75 → 找到 93 → 剪掉 94.9 以下的全部」的流程，只探索了 5 个节点。** 没有剪枝就要枚举 $2^3 = 8$ 个；规模大时，剪枝的效率差距是指数级的。

**从 0-1 到一般整数与混合整数**。上面的例子是 0-1 背包；对一般整数变量，分支点取 $\tilde x_j = 2.4$ 时切 $x_j \le 2$ / $x_j \ge 3$ 同样成立；对混合整数规划（部分变量连续、部分整数），只对整数变量分支，连续变量留在松弛里即可。**唯一的差别是分支变量集合**——其余骨架完全一致，这就是 B&B 能统治整个整数规划家族的原因：它只依赖「整数变量存在」，不关心它们长什么样。<span class="marginnote">实践中 90% 的整数模型是 0-1 混合整数规划（MILP）——设施选址、排班、网络设计都是。求解器内部对 0-1 变量有专门的强分支策略，但对用户完全透明。<strong>学会建模成 0-1 MILP，等于把问题送进最成熟的求解生态</strong>。</span>

**分支变量为什么不能随便挑**。若选一个「偏离整数极小的」变量（如 $\tilde x_j = 2.01$）分支，两个子问题几乎和原问题一样，下界几乎不收紧、剪枝几乎不发生；而选「偏离最大」的变量（$\tilde x_j = 2.5$）分支，两半各去掉一半「灰色地带」，下界紧得多。**强分支（strong branching）**先对几个候选变量各做一次「试分支」，看谁带来的下界提升最大，再选它——每步多花一点计算，换来整棵树更小。这是「花小钱省大钱」的典型。

**再补一个「为什么分支要对整数」的直觉**。分支在 $\tilde x_j = 2.4$ 处把可行域劈成 $x_j \le 2$ 与 $x_j \ge 3$ 两半，中间空出一条缝（$2 < x_j < 3$）——这条缝里没有整数点，删掉它对整数最优毫无损失。每次分支都「抠掉一块不含整数点的空间」，随着分支树加深，剩下的可行域越来越「贴」在整数格点上，最终被穷尽。<span class="marginnote">对照二分搜索：二分在连续空间里把区间一分为二，B&B 的「分支」则在整数格点之间切缝——<strong>本质都是「每次排除一半不可能区域」，区别只在排除的是连续区间还是整数间的缝隙</strong>。</span>

## 5 工程实践：节点选择与热启动

B&B 的工程细节决定成败：

**节点选择**：深度优先（内存省）vs 最佳优先（下界最小的节点，上界更快收紧）vs 混合。
**变量选择**：最偏离整数的变量、伪成本、强分支（先试几个候选再选）。
**热启动**：父节点的松弛解是子节点的极好起点——**对偶单纯形法（第四篇）在这里大显身手**，几轮迭代就解出新节点。
**割平面增强**：每个节点先加割平面再分支（branch-and-cut）——收紧下界、减少分支。<span class="marginnote">商业求解器在这三层做了大量启发式与预求解：初始启发式（找好上界）、冲突分析、对称性破缺……但核心永远是 B&B 的「分支 + 定界 + 剪枝」三件套。理解这个骨架，再复杂的求解器行为都能看懂。</span>

**术语速查：**

| 术语 | 含义 | 一句话记忆 |
| --- | --- | --- |
| 分支 branching | 按非整数变量切出两个子问题 | 切缝 |
| 定界 bounding | 用 LP 松弛求子问题下界 | 上保险 |
| 剪枝 pruning | 下界 ≥ 上界就放弃该分支 | 判死刑 |
| 上界 $\bar z$ | 当前最好整数解的目标值 | 天花板 |
| 下界 $\underline z$ | 未处理节点松弛界的最小值 | 地板 |
| 分支树 | 递归切分形成的搜索树 | 分治骨架 |
| gap | $\bar z - \underline z$ 的差距 | 还有多远 |
| branch-and-cut | 先加割平面再分支 | 收紧再切 |

**B&B 的复杂度画像**：最坏情形是枚举全部叶节点（指数），但实际性能几乎完全由「剪枝的早与晚」决定——越早剪，树越小。度量指标是**探索节点数**：一个好实现把「分支树规模」压到最优解规模的线性甚至常数倍。这也是为什么「初始上界质量」极其重要：**先用贪心/启发式找到一个不错的 $\bar z$，剪枝立竿见影**——很多求解器花 1% 的时间在初始启发式上，换取 10 倍的节点缩减。

**在求解器里实际怎么用**：以 SCIP 或 Gurobi 为例，你只需要把模型写成 LP 文件或 Python API，求解器自动跑 B&B（以及隐藏的割平面、启发式、预求解）。要读懂求解器日志，只需盯住两列——**Best Incumbent（当前上界）与 Best Bound（当前下界）**：两者差距（gap）随时间收敛到 0 就是「快解完了」。如果 gap 卡在某个正值不动，通常是下界紧度不够（需要更好的割）或上界太差（需要更好的初始解）——这正回到本节强调的两个发力点。<span class="marginnote">写给「从极限到大模型」读者的一句话：<strong>商业求解器把 B&B 的每个工程细节都做成了自动档，你的工作不是重新发明 B&B，而是把问题建模成「好松弛 + 好初始解」的形态</strong>——这才是模型开发者真正的用武之地。</span>

## 6 小结

- **分支**：在非整数变量处切分 $x_j \le \lfloor\tilde x_j\rfloor$ / $x_j \ge \lceil\tilde x_j\rceil$，互斥且完备。
- **定界**：每个节点的 LP 松弛给出下界；全局维护上界（最好整数解）。
- **剪枝**：不可行、界限（$\underline z \ge \bar z$）、整数解三种——不损失最优性。
- **不变量**：上界合法（真实解）+ 下界有效（松弛界）⇒ 剪枝安全。
- **工程**：对偶单纯形热启动、branch-and-cut、节点/变量选择启发式。
- **完整与有限**：B&B 不漏解（完整性）且有限步终止（有限性）——代价是可能指数时间。
- **性能钥匙**：初始上界质量 + 下界紧度共同决定剪枝效率——先用启发式找好 $\bar z$，再靠紧松弛压低 $\underline z$。
- **与主线相连**：下一节的 Gomory 割正是「压低 $\underline z$」的利器——割平面 + B&B 合并成 branch-and-cut，统治了现代求解器。
- **求解器读法**：盯 Best Incumbent 与 Best Bound 两列，gap 收敛即收工——卡住就检查上界/下界的发力点。
- **动手建议**：用 SCIP/Gurobi 解一个 $n=30$ 的随机 0-1 背包，对比「默认配置」与「关了启发式」的节点数与耗时，直观感受初始上界的力量。
- **一句话心法**：B&B = 分支（切缝）+ 定界（LP 松弛）+ 剪枝（下界 ≥ 上界就放弃）——三个零件构成完备搜索的引擎。
- **自测题**：若根节点松弛给出下界 111、当前最好整数解为 93，某子问题松弛给出下界 100——该子问题该剪吗？答案：该剪（$100 \ge 93$），因为它不可能比 93 更优。
- **一句话提防**：B&B 最优但可能指数时间——碰上「gap 卡住不动」的实例，工程上常设时间上限，接受「差一个容差的次优」。
