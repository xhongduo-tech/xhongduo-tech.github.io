## 为什么「罚 + 乘子」能治外罚法的病

外罚法的病在 $\mu \to \infty$ 引起病态。**增广拉格朗日方法（augmented Lagrangian method）**，又称**乘子法（method of multipliers）**，在外罚的惩罚项之外再加**拉格朗日乘子项**——于是**有限的 $\mu$ 就足够精确**，不再需要 $\mu \to \infty$，病态大幅缓解。<span class="marginnote">思想的源头可追溯到 Hestenes（1969）与 Powell（1969）：罚函数解的「偏移」恰好可以由乘子修正。加一个乘子项，等价于「告诉惩罚项还差多少」——罚函数不再孤军奋战，而是与乘子「分工」。增广拉格朗日也是 ADMM（下一节）的直接前身，理解它是理解 ADMM 的必经之路。</span>

在「从极限到大模型」的知识地图里，这一站是**第六篇 约束优化**的转折点：前两节的外罚法与内点障碍法各有病根（外罚病态、内点要处理不等式），本节给出的增广拉格朗日是「既简单又稳」的主流选择——它只比外罚多了一个乘子项，就换来了「有限 $\mu$ 高精度」。下一节的 ADMM 正是它向「可分结构」的推广，而它对「并行、分布式、以及大模型时代的分解式训练」都有深远影响。

## 1 增广拉格朗日函数

对等式约束问题 $\min f_0(x)$ s.t. $h(x) = 0$，定义**增广拉格朗日函数**

$$
L_\mu(x, \nu) = f_0(x) + \nu^T h(x) + \frac{\mu}{2}\|h(x)\|_2^2
$$

它 = 拉格朗日 + 二次惩罚。**为什么加二次项？** 它让 $L_\mu$ 关于 $x$ 严格凸（至少在 $f_0$ 凸时局部），且为「乘子更新」提供载体。<span class="marginnote">对比外罚函数 $f_0 + \frac\mu2\|h\|^2$：增广拉格朗日多了一项 $\nu^Th$。正是这一项让解「不再依赖 $\mu\to\infty$」——乘子 $\nu$ 承担了「纠偏」的角色，$\mu$ 只需固定在一个适度大的值。</span>对不等式约束，用类似技巧（记 $z = \max\{0, g(x) + \nu/\mu\}$ 的 Moreau 分解）或引入松弛变量转换。

## 2 乘子迭代法

**乘子法（method of multipliers）**的流程是「内层解增广拉格朗日，外层更新乘子」：

```text
初始化乘子 ν₀ = 0、惩罚参数 μ（适中值）：
重复：
  1. 以 x_{k−1} 为起点，解无约束问题 min_x L_μ(x, ν_k)；
  2. 得 x_k；
  3. 若 ‖h(x_k)‖ 足够小，停止；
  4. 更新乘子 ν_{k+1} = ν_k + μ h(x_k)；
  5. 若约束违反量不再下降，μ ← 10μ（偶尔增大）。
```

**乘子更新 $\nu_{k+1} = \nu_k + \mu h(x_k)$ 的直觉**：若 $h(x_k) > 0$（约束被「欠约束」），下轮的 $\nu$ 变大，惩罚项的「参考水平」抬升，解被进一步压向约束——**乘子在累积「还差多少」的信息**。<span class="marginnote">为什么这个更新有效？可证（对二次情形）$x_k$ 与真实最优的偏离与 $(\nu_k - \nu^*)/\mu$ 同阶——<strong>乘子越接近 $\nu^*$，解越接近 $x^*$</strong>，而更新恰好让 $\nu_k \to \nu^*$。于是固定的 $\mu$（不必很大）就能达到高精度，因为「精度」由乘子而不是 $\mu$ 提供。</span>收敛性：对凸问题，乘子序列 $\nu_k$ 收敛到 $\nu^*$，$x_k$ 收敛到 $x^*$，且通常超线性（在无约束内层精确求解时）。

**一个数值走查**。设等式约束 $h(x) = x - 1 = 0$，目标 $f_0(x) = \tfrac12 x^2$，最优显然是 $x^*=1$、$\nu^* = -1$（由 $\nabla f_0 + \nu\nabla h = x + \nu = 0$ 得 $\nu^* = -x^* = -1$）。取 $\mu = 1$、$\nu_0 = 0$：

- **内层**：$\min_x \tfrac12 x^2 + \nu_0(x-1) + \tfrac12 (x-1)^2$，解 $\nabla = x + \nu_0 + (x-1) = 2x - 1 = 0 \Rightarrow x_1 = 0.5$。
- **更新**：$\nu_1 = \nu_0 + \mu h(x_1) = 0 + (0.5 - 1) = -0.5$。
- **再内层**：$\nabla = x + \nu_1 + (x-1) = 2x - 1.5 = 0 \Rightarrow x_2 = 0.75$；更新 $\nu_2 = -0.5 + (0.75-1) = -0.75$。
- **继续**：$x_3 = 0.875$、$\nu_3 = -0.875$……$x_k \to 1$、$\nu_k \to -1$，几何收敛。

注意 $x_k$ 每轮**都偏离** $x^*=1$（欠收敛到约束内侧），但乘子一步步「把惩罚参考线抬高」，把 $x_k$ 推向 $1$。**正是这个「乘子纠偏」让 $\mu$ 不用增大**——对比外罚法需要 $\mu\to\infty$ 才能把 $x$ 压到 1，这里 $\mu=1$ 恒定就足够了。<span class="marginnote">这个算例的收敛速度是线性的（比例 $\approx 1/2$），因为 $\mu=1$ 恰等于二阶项系数；增大 $\mu$ 会让 $x_k$ 更快逼近 $1$，但 $\mu$ 太大又回到病态——<strong>乘子法把「精度」从 $\mu$ 移交给了 $\nu$，让 $\mu$ 只需在「速度」上起作用</strong>。</span>

## 3 为什么能治「病态」

外罚法需要 $\mu \to \infty$ 是因为「惩罚项独自扛精度」。增广拉格朗日让乘子分担：

外罚：$x^*(\mu)$ 与约束边界的距离 $\sim 1/\mu$——要精确必须 $\mu$ 大。
增广拉格朗日：$x_k$ 的约束违反量 $\sim \|\nu_k - \nu^*\|/\mu$——**乘子收敛到 $\nu^*$ 后，即使 $\mu$ 固定，违反量也趋向 0**。

**数值后果**：增广拉格朗日的 Hessian 含 $\mu$ 项但 $\mu$ 不必发散，条件数受控；乘子迭代提供了「外循环」的收敛，不需要 $\mu \to \infty$。<span class="marginnote">实践上的经典做法：$\mu$ 从适中值开始，仅在乘子迭代「卡住」时才偶尔增大（如违反量不再下降时 $\mu \leftarrow 10\mu$）——大多数迭代用固定 $\mu$，病态只偶尔出现。</span>这是它相对外罚法的决定性优势。

**它在哪类问题上特别有用**（工程视角）：

- **大规模约束优化**：内层子问题是无约束的，可用 L-BFGS 等「只要梯度」的求解器，对变量上百万的问题友好——经典实现 LANCELOT 就是为此设计的。
- **结构约束**：当约束是「简单闭式」（如 $x = \text{某投影}$）时，内层求解可以算得飞快，增广拉格朗日配合这类「闭式内层」是主流。
- **分解与并行**：若目标可分（$f = \sum_i f_i(x_i)$），增广拉格朗日的「变量块」可并行更新——这正是 ADMM 能上分布式系统的直接原因。

这三类场景共同刻画了增广拉格朗日的定位：**它是「外罚的稳健性」与「对偶的精准性」之间的桥梁**，也是「把大问题拆成小问题」这一思想的工程载体。<span class="marginnote">给「从极限到大模型」读者的提醒：增广拉格朗日的「拆解 + 乘子纠偏」模式，在分布式训练、联邦学习、以及「多智能体协调」里反复以 ADMM 或原对偶算法的面目出现——<strong>把本节「乘子纠偏」的心智模型装进脑子里，之后读任何分裂算法都不陌生</strong>。</span>

## 4 公式解析：乘子更新从哪来

把「$\nu \leftarrow \nu + \mu h(x)$」推导出来，看它为什么是「对的」。设 $x$ 是当前内层最优，满足 $\nabla_x L_\mu = 0$：

- **第一步，展开梯度**：$\nabla_x L_\mu(x,\nu) = \nabla f_0(x) + \nabla h(x)^T(\nu + \mu h(x)) = 0$。
- **第二步，认出「乘子候选」**：括号里 $\nu + \mu h(x)$ 是「当前乘子 + 惩罚修正」——记 $\hat\nu = \nu + \mu h(x)$，方程变成 $\nabla f_0(x) + \nabla h(x)^T \hat\nu = 0$——**与 KKT 驻点性同形**！
- **第三步，更新的由来**：$\hat\nu$ 是「更好的乘子估计」。把它设为下一轮 $\nu_{k+1}$：$\nu_{k+1} = \nu_k + \mu h(x_k)$。随着迭代，$\hat\nu \to \nu^*$，$x$ 自动逼近 $x^*$。
- **第四步，为什么有限 $\mu$ 够**：因为「纠偏」由 $\nu$ 负责——$h(x)$ 不必小到 $O(1/\mu)$，只要 $\nu$ 接近 $\nu^*$，驻点方程就在正确位置成立。

**要点：乘子更新是「从增广拉格朗日的驻点方程里，把乘子显式剥出来」的必然结果。** 它让每次迭代都在「接近正确的乘子」下解一个局部问题，因而精度不依赖 $\mu$ 发散。

## 5 增广拉格朗日 vs 外罚 vs 拉格朗日

| 方法 | 子问题 | 精度来源 | 病态 |
| --- | --- | --- | --- |
| 纯拉格朗日（对偶） | 解对偶 | 强对偶 | 不适用一般非凸 |
| 外罚 | $f + \frac\mu2\|h\|^2$ | $\mu \to \infty$ | 严重 |
| 增广拉格朗日 | $f + \nu^Th + \frac\mu2\|h\|^2$ | 乘子收敛 | 温和 |

**辨析｜易错点：**其一，增广拉格朗日的内层子问题仍要用**无约束求解器**（牛顿/拟牛顿/L-BFGS），内层精度不够会拖累乘子更新——工程上常用「内层粗解即可」的**不精确版本**（配合外循环收敛性定理）；其二，$\mu$ 的选择是门手艺：太大病态、太小乘子收敛慢，很多实现用启发式自适应；其三，对**非凸问题**，增广拉格朗日仍只能保证收敛到 KKT 点（可能鞍点），没有全局保证；其四，**别把乘子法与「纯对偶法」混淆**——纯拉格朗日对偶解的是 $\max_\nu g(\nu)$，乘子法解的是「带惩罚的原始问题 + 乘子更新」，两者算法结构完全不同；其五，**停止准则要盯约束违反量 $\|h(x_k)\|$**——它由乘子收敛驱动，别只看目标值。

**术语速查：**

| 术语 | 含义 | 一句话记忆 |
| --- | --- | --- |
| 增广拉格朗日 | $f + \nu^Th + \frac\mu2\|h\|^2$ | 拉格朗日 + 惩罚 |
| 乘子法 method of multipliers | 内层解增广、外层更新 $\nu$ | 罚 + 纠偏 |
| 乘子更新 | $\nu \leftarrow \nu + \mu h(x)$ | 累积欠约束量 |
| 病态 ill-conditioning | Hessian 条件数随 $\mu$ 恶化 | 惩罚太狠 |
| 不精确版本 | 内层只粗解 | 省计算、有定理兜底 |
| Moreau 分解 | 处理不等式约束的投影技巧 | 咬合松弛变量 |

## 6 小结

- **增广拉格朗日**：$L_\mu = f_0 + \nu^Th + \frac\mu2\|h\|^2$——拉格朗日 + 惩罚的合体。
- **乘子法**：内层解 $L_\mu$，外层 $\nu \leftarrow \nu + \mu h(x)$。
- **治病的原理**：精度由乘子承担，$\mu$ 不必发散，条件数受控。
- **更新来源**：从增广拉格朗日驻点方程剥出「乘子候选」$\hat\nu$。
- **应用**：约束优化主力方法之一，也是 ADMM 的直接前身。
- **数值直觉**：乘子把「精度」从 $\mu$ 移交给 $\nu$——$\mu$ 只需负责「速度」，固定 $\mu$ 即可高精度（一维算例 $x_k \to 1$、$\nu_k \to -1$ 线性收敛）。
- **工程选择**：内层不精确解 + 约束违反量 $\|h\|$ 作停止准则 + $\mu$ 自适应增大——是现代实现的三大默认。
- **与主线相连**：增广拉格朗日是最优化里「拆出乘子、外循环纠偏」范式的原型，ADMM、以及大模型时代的分裂式/分布式优化都从这里起步。
- **一句话复盘**：外罚靠「罚得越来越狠」逼近约束，乘子法靠「乘子越来越准」逼近约束——后者用对偶信息换来了有限 $\mu$ 的稳定性。
- **自测**：对 $f_0 = \tfrac12 x^2$、$h(x) = x-1$、$\mu=1$、$\nu_0=0$，手推两轮，验证 $x: 0.5 \to 0.75$、$\nu: 0 \to -0.5 \to -0.75$——乘子在一步步「纠偏」。
