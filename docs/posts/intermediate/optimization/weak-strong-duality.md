## 为什么「间隙」是全部问题的浓缩

对偶问题的意义在于它给 $p^*$ 一个下界 $d^*$。但下界到底**多紧**，决定了对偶理论是「优雅的装饰」还是「可用的引擎」。弱对偶说 $d^* \le p^*$ 永远成立——这是安全网；强对偶说 $d^* = p^*$——这是理想状态，让对偶问题与原问题完全等价。<span class="marginnote">可以把对偶间隙 $p^* - d^*$ 想成「用对偶撬动原问题」时剩下的那段撬不动的距离。本节回答：什么时候这段距离是零？答案由两部分组成——<strong>原问题必须凸</strong>，且<strong>可行域内部足够「肥」</strong>（Slater 条件）。</span>

## 1 弱对偶：无条件的安全网

**弱对偶定理：对任意优化问题，$d^* \le p^*$。** 没有凸性假设，没有光滑性假设，没有约束品性假设——唯一要求是对偶问题定义良好（$g$ 不是恒为 $-\infty$）。

证明在上一节已经完整给出，这里只提炼直觉：**对偶问题的每个可行点 $(\lambda,\nu)$ 都给出一个下界 $g(\lambda,\nu) \le p^*$，取上确界当然不超过 $p^*$。** 弱对偶的用处有三：

**诊断**：任何对偶可行点都提供 $p^*$ 的即时下界——求解器用它做实时间隙诊断。
**最优性证书**：若找到一个可行 $x$ 使 $f_0(x) = g(\lambda,\nu)$，则这个 $x$ 已是最优（不可能有更好的可行点了）——**原始-对偶联合最优性的判定**。
**非凸问题的最后防线**：对 NP-hard 问题，$d^*$ 往往是能计算的最好下界，用于分支定界的剪枝。<span class="marginnote">分支定界（第八篇）能跑得快，一半功劳来自对偶下界：下界紧，就能更早砍掉不可能更优的分支。弱对偶在最坏情形下的价值，恰好在最好的算法里体现。</span>

## 2 强对偶：间隙为零的理想状态

**强对偶：$d^* = p^*$，对偶间隙为零。** 此时解对偶问题等于解原问题。

强对偶**不自动成立**。反例很容易构造：非凸原问题一般有严格正间隙。例如 $\min\{ x^2 \mid x^2 = 1\}$ 的某种变形……实际上最标准的反例来自非凸问题。更微妙的是：**凸问题也不一定强对偶**——约束品性（constraint qualification）不足时，凸问题也会有正间隙。

因此研究者的任务从「证明强对偶」变为「找出保证强对偶的充分条件」。结果出奇地简洁：**对凸问题，一个非常温和的条件——Slater 条件——就够了。** 而实际工程问题几乎都满足它，所以强对偶在凸优化的应用里几乎是「免费」的。

## 3 Slater 条件

**Slater 条件（Slater's condition）**：存在一个**严格可行点** $\tilde x$，满足

$$
f_i(\tilde x) < 0, \quad i = 1, \ldots, m \qquad \text{（所有不等式约束严格松）}
$$

即存在一点落在可行域**内部**——每条不等式约束都留有余量，不被任何约束「绷紧」在边界上。<span class="marginnote">「严格可行」意味着可行集有非空内部。如果只有等式约束（$m=0$），Slater 条件自动满足——所以纯等式约束的凸问题总是强对偶的。直觉：可行域要有「肉」，不能是贴着边界的薄壳。</span>

**定理（Slater 强对偶）**：若原问题是凸优化且 Slater 条件成立，则强对偶成立，即 $d^* = p^*$。<span class="marginnote">更精细的版本：只需对「非仿射」的不等式约束要求严格可行——仿射不等式（如 $Ax \le b$）即使绷紧也不破坏强对偶。这解释了为什么 LP（约束全仿射）无条件强对偶，无需任何约束品性。</span>

Slater 条件的工程意义：**建模时只要可行域有「内部」，强对偶就白送。** 几乎所有的真实凸问题——只要不是把约束恰巧压在一个零体积的集合上——都满足它。

## 4 公式解析：强对偶的几何证明（支撑超平面）

为什么「凸 + Slater」能推出强对偶？用几何看穿它。定义集合

$$
\mathcal{G} = \big\{ (p, u, v) \in \mathbb{R}^{m+p+1} \mid \exists x,\ f_0(x) \le p,\ f_i(x) \le u_i,\ h_j(x) = v_j \big\}
$$

- **第一步，把问题塞进集合**：$p^*$ 是「在 $u=0,v=0$ 处 $p$ 的最小值」。$\mathcal{G}$ 是原问题可行（目标、约束）点的全体「镜像」。
- **第二步，凸性搬家**：原问题凸 $\Rightarrow$ $\mathcal{G}$ 是凸集。<span class="marginnote">这是凸性的「集合化」：函数凸性保证 $\mathcal{G}$ 这个高维集合也是凸的。对偶函数的凹性与 $g$ 的下界性质，都从 $\mathcal{G}$ 的凸性里长出来。</span>
**第三步，分离定理登场**：若强对偶不成立（$d^* < p^*$），则点 $(p^*, 0, 0)$ 在 $\mathcal{G}$ 的闭包之外，可用分离超平面把它与 $\mathcal{G}$ 分开。这个超平面给出一组 $(\lambda,\nu)$，对应一个对偶可行点，其 $g$ 值恰为分离「高度」——从而 $d^* \ge p^*$，矛盾。
**第四步，Slater 的作用**：分离论证需要「$d^* < p^*$ 时 $(p^*,0,0) \notin \mathrm{cl}\,\mathcal{G}$」。若可行域内部为空（Slater 失败），$\mathcal{G}$ 可能是「薄片」，分离论证失效——这正是需要 Slater 条件的地方。

**一句话总结：强对偶 = 分离定理在「凸集 $\mathcal{G}$ 与它外面的点」之间的应用**。凸性保证能分，Slater 保证那个点确实在外面。

## 5 强对偶失效的两个典型情形

强对偶并非总是成立，看两个教科书反例：

**非凸原问题**：$\min\{ -x^2 \mid x \le 1 \}$？此类非凸问题间隙恒正。非凸时，$\mathcal{G}$ 不是凸集，分离定理无从谈起。
**凸但 Slater 失败**：$\min_x\ x \ \mathrm{s.t.}\ x^2 \le 0$。约束等价于 $x = 0$，可行集是单点 $\{0\}$，内部为空。计算对偶：$L = x + \lambda x^2$，$g(\lambda) = \inf_x (x + \lambda x^2) = -\frac{1}{4\lambda}$（$\lambda>0$），$d^* = \sup_{\lambda>0} (-\frac{1}{4\lambda}) = 0$。而 $p^* = 0$——**这里强对偶其实成立了**，但需要一个更微妙的论证。<span class="marginnote">严格说这个例子强对偶仍成立；要造出强对偶失败需要更病态的约束（如 $\mathrm{dom}$ 本身无内部）。更常见的失败案例出现在非凸问题与半无限约束里。初学者记住结论即可：<strong>凸 + Slater ⇒ 强对偶</strong>，这是工程上够用的充分条件。</span>

## 6 速查与辨析

| 情形 | 弱对偶 | 强对偶 |
| --- | --- | --- |
| 任意问题 | 恒成立 | 未必 |
| 凸问题 + Slater | 成立 | 成立 |
| LP（约束仿射） | 成立 | 无条件成立 |
| 非凸问题 | 成立 | 通常不成立 |

**辨析｜易错点：**其一，强对偶是**充分条件**的产物——凸 + Slater 是「保证」强对偶，但并非「必要」，有些凸问题在 Slater 失败时仍强对偶。其二，不要把 Slater 条件与「可行集非空」混为一谈：非空只保证有可行点，Slater 要求有**严格**可行点（内部非空）。其三，LP 的特例地位要牢记：约束全仿射，强对偶无需 Slater。

## 7 小结

- **弱对偶**：$d^* \le p^*$ 无条件成立；提供即时下界、最优性证书与分支定界的剪枝工具。
- **强对偶**：$d^* = p^*$；对偶问题与原问题等价，解对偶即解原问题。
- **Slater 条件**：存在严格可行点使所有非仿射不等式约束严格松；凸 + Slater ⇒ 强对偶。
- **几何本质**：强对偶 = 分离超平面定理作用于「凸镜像集 $\mathcal{G}$」。
- **LP 特例**：约束仿射，强对偶无条件成立。
- **易错点**：Slater 是充分非必要；「可行」≠「严格可行」。

在下一节，我们深入强对偶成立的构造性一面——**互补松弛条件**：最优解处，对偶变量与原约束如何「成双成对」地激活。
