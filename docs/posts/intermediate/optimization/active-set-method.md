## 为什么不等式 QP 的关键是「猜激活集」

不等式约束的困难在于：**不知道哪些约束在最优处绷紧**。若已知激活集 $\mathcal{A}$，问题就退化为上一节的等式约束 QP（把激活约束当等式）——有解析解。**积极集法（active-set method）**把这个「不知道」变成「先猜、再验、错了改」的迭代：维护一个**工作集（working set）**，每轮解对应的等式约束 QP，用互补松弛与乘子符号校验工作集猜得对不对。<span class="marginnote">它像「单纯形法在 QP 里的表亲」：同样沿约束边界走、同样在「顶点」间切换、同样有退化与防循环的需求。对凸 QP 它有限步收敛；对中小规模问题（尤其带热启动）它常是最快的方法。SQP 的内层也常由它来解。</span>

## 1 算法骨架

考虑凸 QP：$\min \frac12x^TQx + q^Tx$ s.t. $Gx \le h$（忽略等式约束的推广）。积极集法从可行点 $x_0$ 出发，维护工作集 $\mathcal{W}$：

```text
从可行点 x₀、工作集 W₀ 出发：
重复：
  1. 解工作集等式 QP：min ½dᵀQd + (Qx_k + q)ᵀd  s.t.  G_W d = 0，得 d_k 与乘子 ν；
  2. 若 d_k ≠ 0：
      沿 d_k 走最大步 α ≤ 1（中途撞到新约束边界则停，把该约束加入 W）；
      x_{k+1} = x_k + α d_k；
  3. 若 d_k = 0：
      检查乘子：若全部 ν_i ≥ 0，停止（x_k 最优）；
      否则删去最负乘子对应的约束，更新 W。
```

**两个关键动作**：**沿 $d_k$ 走**（最多走满 $d_k$，但若中途撞上新的约束边界，只能停在那并把它加入工作集）；**在 $d_k = 0$ 时检查乘子**（乘子有负说明该约束「拉错了方向」，应从工作集移除）。<span class="marginnote">这两个动作的直觉：工作集是「当前认为绷紧的约束」。走步阶段验证「猜的激活集是否还可行」——撞到新约束就补；站住阶段验证「乘子是否非负」——乘子为负说明该约束在「顶着不让走、但方向不对」，应该删掉。一加一删，工作集向真实激活集收敛。</span>

## 2 为什么乘子符号决定「删」

当 $d_k = 0$，当前点 $x_k$ 是「工作集等式 QP」的最优解。该子问题的 KKT 给出

$$
Qx_k + q + \sum_{i \in \mathcal{W}} \nu_i \nabla g_i = 0
$$

- 若所有 $\nu_i \ge 0$：这就是**原问题 KKT**（$\nu$ 非负 + 互补松弛 + 可行性）——$x_k$ 是原问题最优，停止。
- 若某 $\nu_i < 0$：把该约束从工作集移除。<span class="marginnote">为什么「$\nu_i < 0$ ⇒ 删除」？$\nu_i$ 是「该约束把最优值撑住的力」的强度与方向。$\nu_i < 0$ 表示这条约束在等式解里「反向用力」——它其实不该绷紧（真实最优处它在内部）。删掉它，子问题允许沿「越过它」的方向下降，目标还能改善。</span>选最负的乘子删，是最陡的「释放」。

**几何**：$d_k = 0$ 时 $x_k$ 被工作集「钉住」；删掉一条约束 = 松开一个自由度，$d_k$ 变非零，沿新释放方向走。**工作集法本质上在「约束边界骨架」上做换基**——与单纯形法的「基」概念一一对应。

## 3 公式解析：走步阶段的最小比值

走步阶段的「可行步长上界」用最小比值计算，与单纯形法异曲同工。对 $i \notin \mathcal{W}$ 的约束 $g_i(x) = a_i^Tx - b_i \le 0$：

$$
\alpha_{\max} = \min\left\{ \frac{b_i - a_i^Tx_k}{a_i^T d_k} : a_i^T d_k > 0 \right\}
$$

- **第一步，条件**：$g_i(x_k + \alpha d_k) \le 0$ 即 $g_i(x_k) + \alpha a_i^Td_k \le 0$。若 $a_i^Td_k > 0$（沿 $d_k$ 该约束在「收紧」），则 $\alpha \le (b_i - a_i^Tx_k)/(a_i^Td_k)$。
- **第二步，取最小**：所有「收紧中」的约束给出各自的上界，取最小的 $\alpha_{\max}$ 就是「第一个撞上的约束」。
- **第三步，走**：$\alpha = \min\{1, \alpha_{\max}\}$。$\alpha < 1$ 时撞上新约束 → 加入工作集；$\alpha = 1$ 时走满牛顿步 → 工作集不变，进入「乘子检查」。
- **第四步，退化处理**：若 $x_k$ 处已有某条未在工作集的约束取等（退化），$\alpha_{\max} = 0$，工作集加入它但步长为零——需要防循环（类似 Bland 规则）。<span class="marginnote">这条「最小比值」与单纯形法的最小比值检验是同一个数学：在不等式约束下沿方向走到第一个边界。理解它，等于同时理解了单纯形法与积极集法共同的「边界行走」机制。</span>

## 4 一个完整例子

用二维 QP 走一遍。$\min \frac12(x_1^2 + x_2^2)$ s.t. $x_1 + x_2 \ge 1,\ x_1 \ge 0,\ x_2 \ge 0$（改写为标准 $Gx \le h$）。

**第一步，从 $x_0 = (1, 0)$ 出发**，工作集 $\mathcal{W} = \{x_2 = 0\}$（该点取等的约束；$x_1 + x_2 \ge 1$ 也取等，任选其一加入，另一条暂记）。
**第二步，解等式子问题**（工作集：$x_2 = 0$，即 $d_2 = 0$）：$\min \frac12(d_1^2 + d_2^2) + (1,0)^Td$ s.t. $d_2 = 0$。解：$d_1 = -1$、$d_2 = 0$，方向 $d = (-1, 0)$。
**第三步，走步**：沿 $d = (-1,0)$，检查 $x_1 + x_2 \ge 1$：$x_1$ 降到 0 时 $x_1 + x_2 = 0 < 1$ 违反，故 $\alpha_{\max} = 1$ 处 $x_1 + x_2 = 1$ 撞上。$\alpha = 1$，$x_1 = 0$、$x_2 = 0$，工作集加 $x_1 + x_2 = 1$。
**第四步，乘子检查**：$d = 0$？新子问题（工作集 $x_2 = 0$、$x_1 + x_2 = 1$）解为 $x = (1/2, 1/2)$，不是当前点，方向非零，继续走。
**第五步，收敛**：最终走到 $(1/2, 1/2)$，工作集 $\{x_1 + x_2 = 1\}$，乘子 $\nu = -1$（对约束 $-x_1-x_2+1 \le 0$，$\lambda = 1 \ge 0$），停止。$x^* = (1/2, 1/2)$、$p^* = 1/2$。

**要点：积极集法每一步都在「走边界」与「换工作集」之间交替，最终锁定真正的激活集。**

## 5 积极集法速查

| 维度 | 内容 |
| --- | --- |
| 子问题 | 等式约束 QP（工作集当等式），用上一节解析解 |
| 步长 | 最小比值定上界，撞约束即加入工作集 |
| 终止 | $d = 0$ 且乘子全非负 = KKT 满足 |
| 收敛 | 凸 QP 有限步（激活集只增删有限次）；退化解需防循环 |
| 热启动 | 极佳——从近似解出发只加几步，SQP 分支定界常用 |

**辨析｜易错点：**其一，工作集可能包含**多余的约束**（线性相关），子问题会奇异——需先删除冗余；其二，退化时可能「加了删、删了加」空转——用防循环规则；其三，$Q$ 半正定时可能无界，需先判断有界性；其四，积极集法适合**中小规模**，大规模 QP 用内点法更合适。<span class="marginnote">积极集法与内点法的分工：积极集法「边界行走」，热启动好、稀疏解好，适合分支定界与 SQP 内层；内点法「内部逼近」，迭代次数与规模无关，适合大规模。现代求解器（如 quadprog、OSQP 的积极集模式）按规模自动选择。</span>

## 6 小结

- **积极集思想**：猜激活集 → 解等式 QP → 走步/删约束 → 收敛到真激活集。
- **走步**：最小比值定上界，撞约束加入工作集。
- **删约束**：乘子为负 = 约束「反向用力」，应释放。
- **终止**：$d = 0$ + 乘子非负 = KKT 满足。
- **定位**：凸 QP 有限步收敛，热启动佳，SQP 与分支定界的内层常客。
