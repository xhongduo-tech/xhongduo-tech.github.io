# 光合作用与呼吸作用

<div class="epigraph">
<p>光合作用把太阳的能量写进糖的化学键里，呼吸作用再把这笔能量取出来——植物的生命就是在这张存单的存取之间流转。</p>

## 为什么从光合与呼吸开始

植物一生最核心的两套代谢，就是**光合作用**与**呼吸作用**——前者是「存钱」（把光能固定成化学能），后者是「取钱」（把化学能转成 ATP 供生命活动使用）。<span class="marginnote">地球上几乎全部生命的能量都来自太阳，而唯一能把光能变成有机物化学能的规模性通路，就是光合作用。全球每年光合作用固定的太阳能约相当于人类年消耗能量的数十倍——但植物自己就消耗掉了其中一大半用于呼吸。</span>对「从极限到大模型」这条主线来说，光合作用尤其值得驻足：它是一台**把持续能量流（光子）转化为离散化学键（糖）的「能量编码器」**，而呼吸作用则是它的**解码器**。植物通过这两套过程，实现了「能量守恒 + 物质循环」的自洽系统——这正是所有自组织系统的底层逻辑。

## 1 光合作用总览：光能 → 化学能

光合作用的总体方程式：

$$\ce{6CO2 + 6H2O ->[光能] C6H12O6 + 6O2}$$

分两个阶段进行：

- **光反应（光依赖反应）**：在类囊体膜上进行。叶绿素吸收光能，将水光解为 $H^+$、电子与 $O_2$；光能推动电子传递链，同时合成 **ATP（光合磷酸化）**与 **NADPH**。产物：$O_2$（释放）、ATP、NADPH。
- **暗反应（卡尔文循环，光不依赖但需光反应产物）**：在叶绿体基质中进行。利用 ATP 与 NADPH，把 $CO_2$ 固定并还原为三碳糖（G3P），再合成葡萄糖等有机物。<span class="marginnote">「暗反应」的名字有误导性：它本身不需要光，但<strong>依赖光反应的产物 ATP 与 NADPH</strong>，所以光一停，暗反应很快也会停下来。准确说它叫「碳反应」或「卡尔文循环」更合适。</span>

**公式解析：光反应的能量账本**

光反应的能量转化可用一个「量子效率」来审视。设每还原 1 分子 $CO_2$ 需要 $n$ 个光量子，则光合作用的量子需要量可写为：

$$E_{\text{total}} = n \cdot h\nu = 8 \cdot h\nu$$

- **$h\nu$**：单个光子的能量，$h$ 为普朗克常数、$\nu$ 为光的频率。
- **$n$**：每固定一分子 $CO_2$ 消耗的光量子数。理论上需 8 个光子（每个光合电子传递链需要 2 个电子、每 2 个电子需要 4 个光子，一条线性电子流共 8 光子）。
- **$E_{\text{total}}$**：固定 1 分子 $CO_2$ 需输入的光能总量。

固定 1 分子 $CO_2$ 释放的化学能约为 477 kJ，而 8 个红光光子（波长约 680 nm）的能量约为 8 × 175 kJ = 1400 kJ，于是**理论能量转化效率约 477/1400 ≈ 34%**——实际田间效率远低于此（约 1–3%），因为光饱和、呼吸消耗、吸收损失等。<span class="marginnote">量子需要量 $n=8$ 是理解光合「理论天花板」的钥匙：把 34% 的理论效率与太阳能电池板（约 20%）对比，植物的「光伏系统」其实并不低效——只是它还要维持自身运转（呼吸消耗）。</span>

## 2 呼吸作用：把「存款」取出来

**呼吸作用（respiration）**是把有机物（主要是葡萄糖）氧化分解、释放能量的过程，总方程：

$$\ce{C6H12O6 + 6O2 -> 6CO2 + 6H2O + 能量(ATP)}$$

有氧呼吸分三阶段：**糖酵解**（细胞质基质，葡萄糖 → 丙酮酸，少量 ATP）、**三羧酸循环（柠檬酸循环）**（线粒体基质，丙酮酸彻底氧化）、**氧化磷酸化/电子传递链**（线粒体内膜，生成大量 ATP）。<span class="marginnote">一分子葡萄糖完全氧化约净得 30–32 分子 ATP。其中绝大部分在电子传递链的氧化磷酸化中产生——这解释了为什么氧气一旦缺乏，呼吸立刻跌入无氧模式（酒精发酵），产能骤降到每分子葡萄糖仅 2 ATP。</span>

**呼吸作用与光合作用的关系**：二者互为逆过程、共享中间代谢物：

| 对比项 | 光合作用 | 呼吸作用 |
| --- | --- | --- |
| 场所 | 叶绿体 | 细胞质 + 线粒体 |
| 原料 | $CO_2$ + $H_2O$ | 有机物 + $O_2$ |
| 产物 | 有机物 + $O_2$ | $CO_2$ + $H_2O$ |
| 能量方向 | 光能 → 化学能（储能） | 化学能 → ATP（放能） |
| 时间 | 有光时 | 白天黑夜都进行 |
| 意义 | 制造有机物 | 提供能量与中间产物 |

**辨析｜易错点：** 「植物白天进行光合作用，晚上进行呼吸作用」是错的——**呼吸作用日夜不停**，植物白天同时进行光合与呼吸；白天表现出的净放氧/净增重，是「光合减去呼吸」的差值。另一个易错点：**光合作用只有绿色部位（含叶绿体的细胞）能进行，而呼吸作用所有活细胞都在进行**。<span class="marginnote">用「收支」想清楚：光合是「毛收入」，呼吸是「日常开销」，植物「净积累 = 光合 − 呼吸」。白天收入大于支出（净积累），夜间只有支出（净消耗）。这就是为什么晴天光强时植物长得快。</span>

## 3 影响光合作用的因素

光合速率受内外因素制约，农业上常据此调控：

- **光照强度**：光弱时光合随光强线性上升，达到**光饱和点**后不再增加；光强低于**光补偿点**时，光合产物被呼吸全部消耗，净积累为负。
- **$CO_2$ 浓度**：提高 $CO_2$ 浓度可提升光合速率（温室施气肥的原理），但同样存在饱和。
- **温度**：光反应与暗反应都受酶催化，有最适温度；过高使酶失活、呼吸加剧，净光合下降。
- **水分与矿质**：缺水导致气孔关闭、$CO_2$ 进入受阻；缺镁使叶绿素合成受阻（叶脉间失绿）。

**公式解析：光补偿点与净光合**

植物的净光合速率 $P_n$ 是总光合 $P_g$ 与呼吸 $R_d$ 之差：

$$P_n = P_g - R_d$$

- **$P_g$**：总光合速率，随光强 $I$ 近似按饱和曲线上升：$P_g = \frac{P_{\max} I}{K + I}$。
- **$R_d$**：呼吸速率（暗呼吸），近似恒定。
- **$P_n$**：净光合速率。当 $P_g = R_d$，即 $P_n=0$ 时的光强称为**光补偿点**——低于它，植物「入不敷出」。

同一植物在弱光下长期生活的**阴生植物**，光补偿点与光饱和点都低；**阳生植物**则相反。把阳生植物移到阴处，光合不足、净积累变负，就会逐渐衰亡——「喜光植物不能栽在背阴处」的生理根据就在这条式子里。<span class="marginnote">光补偿点的思维与「盈亏平衡点」完全同构：收入（光合）= 成本（呼吸）时，利润为零。农业大棚补光、判断室内植物该放哪，都是在调整「收入曲线」让它在目标光强下为正。</span>

**辨析｜易错点：** 呼吸作用的「底物」不只是葡萄糖——脂肪与蛋白质也可作为呼吸底物。油料种子萌发时以脂肪为主要底物，此时呼吸商（$CO_2$ 释放量 / $O_2$ 消耗量）小于 1；以碳水化合物为底物时呼吸商约为 1。测定呼吸商可以帮助判断植物正在「烧」哪种养料。

## 4 C3、C4 与 CAM：三条固碳路线

植物固定 $CO_2$ 有三大策略，是植物对炎热干旱环境的适应分化：

**C3 植物**：直接由 Rubisco 把 $CO_2$ 固定成三碳化合物（3-PGA）。水稻、小麦、大豆等。光呼吸较强，高温下效率降低。
**C4 植物**：先用 PEP 羧化酶在叶肉细胞固定 $CO_2$ 成四碳化合物（草酰乙酸等），再运到维管束鞘细胞释放 $CO_2$ 供卡尔文循环。玉米、甘蔗、高粱。**光呼吸几乎被消除，高温高光下效率远高于 C3**。
**CAM 植物**：夜间气孔开放吸收 $CO_2$、固定成苹果酸储于液泡，白天关闭气孔、分解苹果酸释放 $CO_2$ 供光合。仙人掌、景天、凤梨。**适应极度干旱**。

**核心对比表：C3 / C4 / CAM**

| 对比项 | C3 | C4 | CAM |
| --- | --- | --- | --- |
| 首固定产物 | 三碳（3-PGA） | 四碳（草酰乙酸/苹果酸） | 四碳（夜间苹果酸） |
| 空间分隔 | 无 | 叶肉/维管束鞘分隔 | 无（时间分隔） |
| 时间分隔 | 无 | 无 | 有（夜吸昼放） |
| 气孔开闭 | 白天开 | 白天开 | 夜间开 |
| 光呼吸 | 明显 | 几乎无 | 少 |
| 代表植物 | 稻、麦、大豆 | 玉米、甘蔗、高粱 | 仙人掌、景天 |

**辨析｜易错点：** C4 与 CAM 都先用四碳化合物「暂存」$CO_2$，区别在于**分隔方式**：C4 用空间（两种细胞分工），CAM 用时间（昼夜分工）。C4 是「白天把 $CO_2$ 塞进四碳小车运到内部」，CAM 是「夜里把 $CO_2$ 装进苹果酸仓库、白天再取出来」。<span class="marginnote">C4 的「双重羧化」类似缓存系统：PEP 羧化酶在门口快速捕获 $CO_2$，Rubisco 在内部拿到高浓度 $CO_2$ 稳定工作——就像 CPU 的 L1 缓存，用一层「快而糙」的介质挡住慢而精的介质。CAM 则是「把高峰期的负载挪到低谷期处理」的削峰填谷策略。</span>

**易错再提醒**：植物白天同时进行光合与呼吸，晚上只呼吸；净积累 = 光合 − 呼吸。判断「净放氧还是净吸氧」，先看光补偿点以下还是以上。

**一个数字**：全球光合作用每年固定的碳约为千亿吨量级，而化石燃料燃烧每年排放约百亿吨——植物是地球碳循环里最大的「固定碳引擎」，也是碳汇的物理基础。

## 5 小结

- 光合作用分**光反应**（类囊体，产 $O_2$/ATP/NADPH）与**碳反应**（基质，固定 $CO_2$ 合成糖）；总反应 $\ce{6CO2 + 6H2O ->[光] C6H12O6 + 6O2}$。
- 每固定 1 分子 $CO_2$ 约需 **8 个光量子**，理论能量效率约 34%，田间实际仅 1–3%。
- 呼吸作用日夜进行，分**糖酵解、三羧酸循环、氧化磷酸化**三阶段；净积累 = 光合 − 呼吸。
- 光合受**光照、$CO_2$、温度、水分矿质**影响；**光补偿点**是净积累由负转正的阈值。
- **C3/C4/CAM** 是三条固碳路线：C3 简单常见，C4 用空间分隔消除光呼吸，CAM 用时间分隔适应干旱。
