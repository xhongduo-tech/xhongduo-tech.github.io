## 为什么从系统学开始

前几篇我们按「从低等到高等」的顺序认识了藻类、苔藓、蕨类、裸子与被子植物——这本身就是一种**系统学**叙事。但「低等到高等」只是简化版本：真实演化不是一条直线，而是一棵分叉的树。<span class="marginnote">「系统学（systematics）」研究生物的多样性及其演化关系，其核心产品是<strong>系统发育树（phylogenetic tree）</strong>——一棵用分叉结构表示亲缘关系的「家族树」。而「分类学（taxonomy）」则是给生物命名、归类的工作。</span>植物系统学的意义不止于「排座次」：只有知道谁和谁亲缘近，才能理解性状是怎么演化的、亲缘近的物种可以互相嫁接、药用植物的有效成分在哪一族里最丰富。这一节，我们把植物界所有类群装进一棵演化树，再看植物学家如何用形态、化石与分子三类证据重建它。

## 1 系统学的基本概念：从分类到系统发育

植物系统学建立在几个核心概念上：

**分类单元（taxon）**：任何一个具体的分类群，如「松属」「被子植物门」。
**等级（rank）**：界、门、纲、目、科、属、种等层级。种（species）是最基本的分类单元。
**单系群（monophyletic group）**：包含一个共同祖先及其全部后代的类群，是系统学追求的目标。
**姐妹群（sister group）**：系统树上亲缘关系最近的两个分支。

**核心概念**：**系统发育树（phylogenetic tree）**是一棵有根的分叉树——**根**代表所有分类单元的共同祖先，**节点**代表共同祖先事件，**分支（枝）**代表演化谱系，**末端（叶）**代表现存或化石的分类单元。树的拓扑结构（谁跟谁分叉）编码了全部亲缘信息。<span class="marginnote">系统树与「从极限到大模型」主线里的概念树同构：根是公理/起点，分支是分化出的子概念，叶是具体结论。读系统树要会看「最近共同祖先」——两个物种的亲疏，取决于它们的最近共同祖先位于多深的节点。</span>

## 2 植物界演化树：一张全景图

把全篇学过的类群装进一棵树，植物的演化主线是这样的：

```
蓝藻（最早的光合放氧生物）
 └─ 绿色植物（绿藻 + 有胚植物）
     ├─ 苔藓植物（苔纲 / 藓纲 / 角苔纲）
     └─ 维管植物
         ├─ 蕨类植物（石松类 / 真蕨类）
         └─ 种子植物
             ├─ 裸子植物（苏铁 / 银杏 / 松柏 / 买麻藤）
             └─ 被子植物（木兰类 → 单子叶 / 真双子叶）
```

**关键信息**：现代系统学把植物界重新组织为——**绿色植物**（绿藻+有胚植物）是一个单系群，其中**有胚植物**（陆地植物）又分苔藓与维管植物两支。过去按「低等→高等」的线性排列，如今被一棵分叉树取代。<span class="marginnote">注意红藻、褐藻的位置：它们虽然传统上叫「藻类」，但与绿藻的色素组成不同，亲缘上独立。这说明「藻类」不是一个单系群，而是「会光合、无胚、无根茎叶」的并系拼盘——系统学正在不断修正传统教科书的分组。</span>

## 3 重建系统树的三类证据

植物学家如何知道谁和谁亲缘近？用三类可以互相校验的证据：

**形态证据**：花部结构（基数、子房位置）、叶脉类型、维管组织、胚胎特征。形态性状最直观，但容易趋同演化（如仙人掌的刺与山楂的刺来源不同）。<span class="marginnote">趋同演化是形态分类的陷阱：多肉植物（仙人掌科的柱状茎、大戟科的柱状茎）在干旱环境下各自演化出相似形态，形态相似却亲缘很远。形态学家靠「同源 vs 同功」的甄别来绕过这个坑。</span>
**化石证据**：化石记录了已灭绝的中间环节（如**前裸子植物**、**种子蕨**），把形态的演化时间线钉进地质年代，是形态证据的「时间轴」。
**分子证据**：比较 DNA 序列（如叶绿体基因 *rbcL\*、核基因 18S rDNA），用序列差异估计亲缘距离。分子数据量大、客观、可量化，是现代系统学的利器。<span class="marginnote">分子钟（molecular clock）：以序列突变速率恒定为前提，用序列差异反推分化时间。它把「谁和谁亲」升级为「什么时候分的家」——比如被子植物与裸子植物的分化被估算在约 3 亿年前。</span>

**公式解析：序列差异与亲缘距离**

分子系统学把两条同源序列的差异度转化为亲缘距离。设两条序列长度为 $L$，其中差异位点数为 $k$，则 p-距离为：

$$d = \frac{k}{L}$$

- **$k$**：两条序列中碱基或氨基酸不同的位点数。
- **$L$**：比对后序列的总长度。
- **$d$**：p-距离（observed divergence），范围 0–1。

对远缘物种，p-距离会**低估真实距离**（因为多位点突变、回复突变会掩盖差异），需用模型校正（如 Jukes-Cantor 校正：$d_{JC} = -\frac{3}{4}\ln\left(1-\frac{4}{3}p\right)$）。**差异越大、校正越多，亲缘越远**——把「差异度」翻译成「亲缘距离」，再用距离聚类（NJ 法）或性状矩阵（最大简约、最大似然、贝叶斯）构建系统树。<span class="marginnote">p-距离、JC 校正、聚类建树——这套「度量差异→估计距离→层级聚类」的流程，与信息检索里的「编辑距离→相似度→近邻聚类」、以及大模型嵌入空间里的「向量距离→相似度→聚类」几乎一一对应。分类与聚类，本质是同一件事的生物学版本。</span>

### 3.1 数值算例：一段 *rbcL* 序列的 p-距离与 JC 校正

把公式落到数字上。设两条叶绿体 *rbcL* 片段比对后长度 $L = 500$，其中差异位点 $k = 90$，则 p-距离为：

$$d = \frac{90}{500} = 0.18$$

若物种亲缘较远，直接把 $0.18$ 当作亲缘距离会偏低——多位点突变与回复突变会掩盖一部分真实差异。改用 Jukes-Cantor 校正：

$$d_{JC} = -\frac{3}{4}\ln\left(1-\frac{4}{3}\times 0.18\right) \approx -\frac{3}{4}\ln(0.76) \approx 0.205$$

校正后距离 0.205 大于原始 0.18，差异被「放大」了。再对比两组数据：同属两个近缘种（$d = 0.02$）与分属不同科的两个类群（$d = 0.35$），前者校正后仅约 0.0203，几乎不变；后者校正后约 0.47，显著增大。**结论：差异越小，校正越轻微；差异越大，必须校正才不致低估亲缘距离。**<span class="marginnote">JC 校正的前提是四类碱基频率相等、任意替换等概率。更真实的模型（K80、GTR 等）逐步放宽这些假设——模型越复杂、参数越多，所需序列越长，这就是分子系统学里「模型选择」的日常取舍。</span>

## 4 现代分类系统：从恩格勒到 APG

分类系统本身也在演化。历史上影响最大的两个系统：

**恩格勒系统（Engler system）**：以「假花说」为基础，认为无被花（如杨、柳）最原始，把双子叶植物放在前面。长期用于中国植物志的排序，影响深远。
**哈钦松系统（Hutchinson system）**：以「真花说」为基础，认为木兰类（木本、花被发达）最原始，强调木本与草本的分野。

现代主流是**APG 系统（Angiosperm Phylogeny Group）**：基于大规模分子系统发育分析，把被子植物重新划分为**基部被子植物**（睡莲、木兰类等）、**单子叶植物**与**真双子叶植物**（菊类、蔷薇类等）几大支。<span class="marginnote">APG 是「用数据改教科书」的当代案例：200 多位植物学家协作、基于多基因序列，每几年更新一版（APG I–IV），把几百年的形态分类结果用分子证据系统性重排。今天的植物园、在线植物志都在向 APG 靠拢。</span>

### 4.1 从形态到分子的证据整合

三类证据各有长短，植物学家的做法是**互相校验**：形态提供可观察的性状框架，化石提供时间坐标，分子提供可量化的亲缘距离。一个经典案例是**被子植物的起源**：化石证据把最早的被子植物推回白垩纪早期，形态分析长期争议「木兰类还是无被花类最原始」，而分子系统学（APG）给出了出人意料的答案——现存基部被子植物是**无油樟**（Amborella）与睡莲类，它们既不是典型木兰类、也不是典型无被花类。三类证据叠加，才画出了今天这棵树。

**辨析｜易错点：** 「分子系统学完全取代形态分类」是误解。分子数据擅长回答「谁和谁亲」，但**命名、鉴定、野外工作仍依赖形态**；而且分子树也受取样偏差、基因选择、长枝吸引等误差影响。当代植物学是「形态 + 分子 + 化石」三角互证——单一证据都可能是片面的。还要区分一组易混概念：**系统发育树**是亲缘关系图；**分支图**只表示分支关系、不含演化时间；**分子钟定年树**把时间标在枝上——读文献时先分清「这张树图画的是什么信息」，再解读结论。

### 5.1 植物系统学考点清单

- 系统学 vs 分类学：系统学重建演化关系，分类学负责命名归类。
- 系统发育树要素：根（共同祖先）、节点（分化事件）、分支、末端（分类单元）。
- 单系群：共同祖先 + 全部后代，是系统学追求的目标。
- 演化主线：蓝藻 → 绿色植物（绿藻+有胚植物）→ 苔藓 / 维管植物（蕨类 / 种子植物）。
- 三类证据：形态（直观易趋同）、化石（时间轴）、分子（可量化）。
- 趋同演化陷阱：仙人掌柱状茎 vs 大戟柱状茎，形似非同源。
- p-距离：$d = k/L$，把序列差异转成亲缘距离。
- 分子钟：以突变速率恒定为前提，反推分化时间。
- 恩格勒系统：假花说，无被花原始；哈钦松系统：真花说，木兰类原始。
- APG 系统：分子系统发育，基部被子植物 + 单子叶 + 真双子叶。
- 无油樟与睡莲是现存基部被子植物——分子学说的著名结论。
- 分子树也有误差：取样偏差、长枝吸引。

## 6 小结

- 系统学研究**生物多样性与演化关系**，核心产品是**系统发育树**；分类学负责命名与归类。
- 植物界演化主线：**蓝藻 → 绿色植物（绿藻+有胚植物）→ 苔藓 / 维管植物（蕨类 / 种子植物）**。
- 重建系统树用三类证据：**形态、化石、分子**；趋同演化是形态证据的主要陷阱。
- p-距离 $d=k/L$ 把序列差异翻译成亲缘距离，再经模型校正、聚类构树。
- 分类系统从**恩格勒、哈钦松**演进到**APG 分子系统**，当代主流以单系群划分被子植物。
