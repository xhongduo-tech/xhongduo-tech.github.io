# 裸子植物

<div class="epigraph">

## 为什么从裸子植物开始

蕨类靠孢子繁殖、受精依赖水，这让它们在陆地上的扩张始终带着「半水栖」的枷锁。植物界真正的「第二次解放」，来自**种子**的发明——而率先装备种子的，就是**裸子植物**。<span class="marginnote">「裸子」的字面意思就是「种子裸露」：它们的种子没有果皮包裹，直接裸露在球果的鳞片（种鳞）上，与被子植物「种子包在果实里」形成鲜明对比。松塔里那片片「鳞片」之间的空隙处，就是种子着生的位置。</span>裸子植物首次用**花粉管**把精子直接送到胚珠，**受精不再依赖水**；又用**种子**把胚、胚乳与种皮打包成耐旱耐候的「旅行箱」。它们是中生代的霸主——恐龙脚下的参天松柏、苏铁与银杏，都是裸子植物。理解裸子植物，就抓住了「种子植物 = 摆脱水 + 打包后代」这条演化主线，也为下一节被子植物的双受精与果实创新提供了参照系。

## 1 裸子植物的形态结构：木本、针叶、单轴

裸子植物绝大多数是**常绿木本植物**，形态上高度适应干旱与寒冷：

**茎**：普遍有发达的**次生生长**，木质部主要由**管胞**构成（少数有导管，如麻黄、买麻藤），韧皮部为筛胞。木材致密、富含树脂。
**叶**：多为**针形、条形或鳞形**（松、柏、杉），叶表面积小、角质层厚、气孔内陷，高度抗旱。少数为扇形叶（银杏）、羽状叶（苏铁）。
**根**：发达的主根与侧根，常与真菌形成**菌根**，帮助吸收水分与矿质。

裸子植物的输导与光合系统都偏「节约」：管胞效率低于导管，针叶面积远小于阔叶。这些「保守」的设计换来的是**极端环境下的生存力**——从寒带针叶林到高山、干旱地区，裸子植物都是优势植被。<span class="marginnote">针叶的抗旱策略是「节流」：气孔深陷在表皮内（气孔下陷），角质层厚，冬天还能通过降低代谢「熬冬」。对比被子植物的阔叶「开源」路线（大叶面、高效率导管），裸子植物选择了「少消耗、抗逆境」的另一条路——这正是一个「trade-off」的经典案例。</span>

## 2 生殖结构：球果与小孢子叶球

裸子植物的生殖器官是**球花（孢子叶球）**，通常雌雄同株或异株，分小孢子叶球（雄球花）与大孢子叶球（雌球花）。

**雄球花**：由许多**小孢子叶（雄蕊）**螺旋排列而成，每个小孢子叶腹面生有**花粉囊（小孢子囊）**，内含花粉粒。松树的花粉粒两侧有**气囊**，能随风飘得很远。
**雌球花**：由**大孢子叶（珠鳞）**与**苞鳞**组成，珠鳞基部生有裸露的**胚珠**。胚珠由珠被与珠心组成，珠心内形成大孢子母细胞，经减数分裂产生大孢子，进而发育出**雌配子体**。

**传粉到受精的过程**：花粉落在胚珠的**珠孔**附近，萌发出**花粉管**，花粉管穿过珠心把精子送到颈卵器附近——受精发生在**珠心内**。松属从传粉到受精完成，常常要经历**一年以上**的时间（传粉当年，受精翌年），这是裸子植物生殖的著名特征。<span class="marginnote">松树从传粉到种子成熟全程约两年：第一年春天传粉、花粉管缓慢生长并休眠过冬，第二年春天才完成受精，秋天种子成熟。所以松塔从幼嫩绿色到成熟褐色，要跨两个生长季——这是「慢工出细活」的生殖节奏。</span>

### 2.1 松属生活史主线

1. 成熟孢子体（2n）——松树本身。
2. 雄球花产生花粉粒（雄配子体，n）；雌球花胚珠内产生雌配子体（n）。
3. 花粉借风传到珠孔 → 萌发花粉管 → 精子（n）+ 卵（n）受精 → 合子（2n）。
4. 合子发育成**胚**，胚珠发育成**种子**（n 的雌配子体存留为胚乳）。
5. 种子落在适宜处萌发成新孢子体（2n）。

**关键**：裸子植物也有配子体世代，但**配子体极度退化**——雄配子体只是花粉粒里的几个细胞，雌配子体是胚珠内的胚乳组织（n，未受精就存在），二者都寄居在孢子体上。孢子体世代占据绝对优势。

## 3 种子：第一代「旅行箱」

**种子（seed）**是裸子植物与被子植物共有的最高级繁殖器官，由**种皮、胚、胚乳**三部分组成：

- **种皮**：由珠被发育而来，坚硬保护。
- **胚**：由合子发育而来，包含胚芽、胚轴、胚根与子叶（裸子植物子叶常多枚，如松 5–18 枚）。
- **胚乳**：裸子植物的胚乳是**雌配子体**（单倍体 n），在受精前就已形成；这与被子植物受精后才形成的**三倍体胚乳（3n）**根本不同——**这是裸子植物与被子植物最重要的生殖差异之一**。

**公式解析：种子的传播方程**

种子要扩大领地，必须「散布得远」。设种子被传播到距离母株 $d$ 之外的概率为 $P(d)$，种子在途中的存活概率为 $p_{\text{surv}}(d)$（随距离增加先升后降：太近竞争激烈，太远环境陌生），则成功建立新个体的期望为：

$$F(d) = P(d) \cdot p_{\text{surv}}(d)$$

- **$P(d)$**：传播距离分布函数，风媒种子常近似指数分布，动物传播则呈重尾分布（能一次搬到很远）。
- **$p_{\text{surv}}(d)$**：到达处定殖成功概率。距离近时受母株竞争与同种密度制约，$p_{\text{surv}}$ 低；距离过远则可能进入不适生境，$p_{\text{surv}}$ 又下降。
- **$F(d)$**：定殖成功率的距离分布，存在一个最优距离 $d^*$ 使 $F$ 最大——这就是「**母树效应/距离制约**」模型的雏形。<span class="marginnote">松树的风媒种子气囊让 $P(d)$ 的尾巴更肥（重尾），能飘得更远；而橡子靠松鼠搬运则形成「散点式」重尾分布。数学上，这个「存在最优传播距离」的思想与信息论里的「最优码长」、机器学习里的「探索-利用权衡」共享同一个结构：太少走不远，太多走不活。</span>

### 3.1 种子为何是演化的「革命」

把种子的优势与孢子对比，就明白它为何重要：

| 对比项 | 孢子 | 种子 |
| --- | --- | --- |
| 营养储备 | 无，靠环境 | 有胚乳/子叶，自带「干粮」 |
| 抗逆能力 | 娇弱、需水 | 种皮保护，耐旱耐寒耐候 |
| 休眠能力 | 弱 | 强，可长期休眠等待时机 |
| 传播装置 | 无 | 有翅、刺、肉质种皮等 |
| 遗传来源 | 有性（孢子由减数分裂来） | 有性（受精发育而来） |

**核心结论**：种子的出现让植物可以「把大量营养预存在后代里」，使后代在萌发初期不再完全依赖当时的环境——这是植物从「广种薄收」走向「少种优育」的分水岭。种子植物的繁殖成功率远高于孢子植物，因此可以用较少的后代数量维持种群，把更多资源投入个体竞争。

**辨析｜易错点：** 裸子植物与被子植物都有种子，区别在**胚珠与种子是否被包裹**：裸子植物的胚珠裸露在珠鳞上、种子裸露；被子植物的胚珠包在子房内、种子包在果实里。「有没有种子」不是裸子与被子之分，「种子是否被果实包裹」才是。

## 4 裸子植物的主要类群

现代裸子植物分四大纲：

**苏铁纲**：茎粗壮不分枝，叶为大型羽状复叶，雌雄异株，如苏铁（铁树）。<span class="marginnote">苏铁「千年铁树开花」其实是误解：铁树在热带亚热带每年或数年开花，只是北方盆栽因低温不开花。它的「花」其实是雌雄异株的球花，形态像巨型的球果。</span>
**银杏纲**：仅存银杏一种（单科单属单种，「活化石」），叶扇形、二叉脉，雌雄异株，种子橙黄色具肉质外种皮（成熟后散发臭味）。
**松柏纲**：现代裸子植物的大多数，叶针形/鳞形/条形，球果显著，如松、柏、杉。北方针叶林的主要建群种。
**盖子植物纲（买麻藤纲）**：形态最特化的一群，茎有导管、生殖结构复杂，如麻黄（含麻黄碱，药用）、买麻藤、百岁兰（纳米布沙漠的「两片叶活千年」的奇植物）。

**辨析｜易错点：** 银杏的「白果」是种子还是果实？**是种子**——它的橙黄色「肉质」是**外种皮**（珠被外层肉质化），不是果皮。裸子植物没有果实，所以银杏、松子、红豆杉的「红豆」都是**裸子植物的种子**，只是外种皮常肉质化，形态上很像「果」，但结构上不属于果实。判别金标准：**果实必须来自子房，裸子植物没有子房，因此裸子植物的一切「果」都是种子**。<span class="marginnote">同样地，松子不是果实是种子，红豆杉「红豆」不是果实是肉质假种皮包着的种子。凡是裸子植物，见「果」字都要打问号——这是识别题的高频陷阱。</span>

## 5 核心对比表：裸子植物 vs 被子植物

| 对比项 | 裸子植物 | 被子植物 |
| --- | --- | --- |
| 胚珠/种子 | 裸露在珠鳞上 | 包在子房（果实）内 |
| 花 | 球花（无花被） | 真正的花（花被+雄雌蕊） |
| 胚乳 | 雌配子体（n），受精前形成 | 三倍体（3n），受精后形成（双受精） |
| 木质部 | 以管胞为主 | 导管为主 |
| 传粉 | 几乎全为风媒 | 风媒、虫媒、鸟媒等多渠道 |
| 受精 | 不依赖水（花粉管） | 不依赖水（花粉管） |
| 代表 | 松、柏、杉、银杏、苏铁 | 桃、稻、玫瑰、橡树 |

### 4.1 裸子植物考点清单

- 裸子植物：最早种子植物，花粉管受精摆脱水，种子繁殖打包后代。
- 种子裸露：胚珠在珠鳞上、无果皮包裹，所以「裸」。
- 形态抗旱：针叶/鳞叶、角质层厚、气孔下陷、管胞输导。
- 木质部以管胞为主（少数有导管，如麻黄）。
- 生殖结构：雄球花（小孢子叶球）、雌球花（大孢子叶球）。
- 胚乳是未受精的雌配子体（n）——与被子植物三倍体胚乳根本不同。
- 松属生活史：传粉到种子成熟约需两年（隔年受精）。
- 花粉粒有气囊：风媒传粉飘得更远。
- 四大纲：苏铁纲、银杏纲、松柏纲、盖子植物纲（买麻藤纲）。
- 银杏「白果」是种子不是果实；松子、红豆杉「红豆」也是种子。
- 判据铁律：果实必须来自子房，裸子植物无子房，故无果实。
- 演化意义：种子自带营养与保护，繁殖成功率远超孢子。

## 6 小结

- 裸子植物是**最早的种子植物**：用**花粉管**受精（摆脱水）、用**种子**繁殖（打包后代）。
- 形态高度抗旱：针叶、角质层厚、气孔下陷、管胞输导；多为常绿木本。
- 生殖结构为**球花**；胚珠裸露在珠鳞上；松属从传粉到种子成熟约需两年。
- 胚乳是**未受精的雌配子体（n）**，区别于被子植物的三倍体胚乳。
- 现代裸子植物分**苏铁纲、银杏纲、松柏纲、盖子植物纲**；银杏的「白果」、松子都是种子而非果实。

在下一节，我们将迎来植物界最庞大、最成功的家族——**被子植物**。双受精、果实与高效的输导系统，让它们统治了今天的陆地。让我们看双子叶与单子叶如何分家。
