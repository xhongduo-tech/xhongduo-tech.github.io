## 为什么从苔藓开始

上一节我们说藻类在水中完成了光合革命，那么从水到陆的「第一步」是谁迈出的？答案是**苔藓植物**。它们是**高等植物（有胚植物）中最原始的一群**，出现了**胚**这一新结构，也出现了**茎叶分化**，但还没有真正的根、没有维管组织的完善运输系统，因此只能紧贴潮湿地面生长。<span class="marginnote">苔藓对「登陆」的意义可以用一句演化概括：它们是第一代从水生过渡到陆生的有胚植物，把「水陆两栖」的状态固定成了自己的生存方式——永远离不开水，却又已经站在了陆地上。</span>理解苔藓，就是理解植物登陆后面对的第一组难题：**如何保水、如何输导、如何完成有性生殖而不依赖水**。苔藓解决得「半吊子」，但正是这半吊子的方案，为后来蕨类与种子植物的彻底登陆铺了路。

## 1 苔藓的形态结构：有茎叶、无真根

苔藓植物的营养体（配子体）有三种基本形态：

**苔类**：叶状体或带分化的「茎叶体」，无中肋（叶脉），如地钱（叶状体苔类）、耳叶苔。
**藓类**：有明显的「茎」「叶」分化，叶常具中肋，如葫芦藓、泥炭藓。<span class="marginnote">注意引号：苔藓的「茎」「叶」不是真正的茎叶——它们没有维管组织、没有真正的根。学名里叫「拟茎叶体」，以示与蕨类和种子植物的根茎叶相区别。</span>
**角苔类**：配子体是薄叶状体，孢子体细长如角，如角苔。

苔藓的「根」实际上是**假根（rhizoid）**，由单细胞（苔类）或多细胞（藓类）的丝状结构组成，主要起**固定作用**，吸收能力弱。由于没有真正的输导组织，苔藓植物体内的水分运输靠**渗透与表面张力**，因此它们不能长高，只能贴地成片生长，且必须生活在阴湿环境中。

**辨析｜易错点：** 「苔藓有茎叶但没有根」与「苔藓没有真正的茎叶根」是两句话。准确表述是：苔藓有**茎叶分化但无维管组织、无真正的根**（只有假根）。「有茎叶」指形态分化，「无真根」指结构与功能都不完整。考试时把「苔藓有真正的根」判为错，把「苔藓无根茎叶分化」也判为错——两句话都错在极端。

## 2 生活史：配子体占优的「单倍体时代」

苔藓植物最独特的特征是**生活史中配子体（单倍体 n）占优势，孢子体（二倍体 2n）寄生在配子体上**。

生活史主链如下：<span class="marginnote">先记住两个术语：<strong>配子体</strong>是产生配子（精卵）的植株，体细胞为单倍体 n；<strong>孢子体</strong>是产生孢子的植株，由受精卵发育而来，体细胞为二倍体 2n。</span>

1. 成熟的**配子体**（n）产生精器（产精子）与颈卵器（产卵细胞）。
2. 精子借水游动，游入颈卵器与卵结合，形成**合子（2n）**。
3. 合子在颈卵器内发育成**胚**，胚进一步长成**孢子体（2n）**。
4. 孢子体顶端产生**孢子囊**，经减数分裂产生**孢子（n）**。
5. 孢子散落萌发，先长成**原丝体**，再分化出新配子体（n）。

关键点有二：**一是精子必须借水游动**，所以苔藓的有性生殖离不开水；**二是孢子体不能独立生活**，它终生寄生在配子体上，靠配子体供养。

**公式解析：世代交替的倍性账本**

任何高等植物都经历**世代交替**：二倍体孢子体世代与单倍体配子体世代交替出现。一次完整循环中，染色体数目的变化是：

$$2n \;\xrightarrow{\text{减数分裂}}\; n \;\xrightarrow{\text{受精}}\; 2n \;\xrightarrow{\text{孢子体发育}}\; 2n$$

- **$2n$（孢子体）**：由合子发育而来，进行**减数分裂**产生 n 的孢子，这是倍性从高到低的转折点。
- **$n$（配子体）**：由孢子发育而来，进行**有丝分裂**产生精卵，这是倍性从低保持到低的阶段。
- **$2n$（合子）**：精卵受精，倍性从 n 回到 2n，这是倍性从低到高的转折点。

**减数分裂是「降倍」的唯一出口，受精是「升倍」的唯一入口**——两者把整条生活史锁死成闭环。<span class="marginnote">这个「两个开关」的视角可以推广到整个植物界：苔藓是配子体占优（n 世代长、独立），蕨类两个世代都独立但配子体小，种子植物则孢子体占绝对优势、配子体退化到藏在孢子里。倍性图谱一变，整个类群的生态策略就跟着变。</span>

## 3 苔藓的生态意义：水陆之间的「绿毯」

苔藓虽小，生态作用却不可小觑：

**先锋植物**：能在岩石、沙地、火烧迹地等恶劣环境率先着生，分泌有机酸风化岩石，为后来植物创造土壤条件——它们是生态演替的「开路工」。
**保水与水土保持**：苔藓层吸水能力极强（泥炭藓可吸自重十余倍的水），像海绵一样涵养水源、减缓地表径流。<span class="marginnote">泥炭藓（Sphagnum）是「吸水冠军」，它的细胞有大型储水细胞，吸水能力远超棉花。二战时泥炭藓还被用作绷带敷料，因为它吸液快、还有抑菌性。</span>
- **成炭**：泥炭藓堆积的泥炭是重要的燃料与园艺基质，也是「泥炭地」生态系统的核心。
- **环境指示**：许多苔藓对大气污染敏感，是环境监测的指示植物。

### 3.1 苔藓的主要类群与生境

按形态与生殖特征，苔藓植物分三大类群：

- **苔纲（肝叶类）**：配子体多为叶状体，背腹扁平，贴地生长，如地钱。叶状体有简单的「拟根」与气室。
- **藓纲（真藓类）**：配子体有茎叶分化、具中肋，是苔藓中种类最多、分布最广的一群，如葫芦藓、泥炭藓、金发藓。孢子体有蒴柄与孢蒴，成熟后弹散孢子。
- **角苔纲**：配子体叶状、孢子体细长如角、可长期生长，如角苔。

**辨析｜易错点：** 苔与藓不是一回事。「苔」多指叶状体、贴地成片（如地钱、青苔）；「藓」多有茎叶分化、相对直立（如葫芦藓、墙藓）。日常口语「苔藓」混称，但分类上苔纲与藓纲形态差异明显：**苔无中肋、藓多有中肋**，是快速区分的特征。

苔藓分布极广：从热带雨林树干到两极冻原、从高山岩面到沙漠边缘都能找到它们。泥炭藓在寒冷潮湿地区形成大面积泥炭藓沼泽，是重要的碳汇——全球泥炭地储存的碳约占土壤碳库的三分之一，比森林碳库更大。假根虽然吸收能力弱，但「贴地」策略让苔藓能在极端贫瘠的基质上生存：岩石、沙地、屋顶瓦片，只要表面能留住一层水膜，苔藓就能着生。这种「不求深、只求湿」的生存方式，让苔藓成为城市与荒野之间最常见的绿色底色。

## 4 核心对比表：苔藓 vs 藻类 vs 蕨类

把三类低等—中等植物放在一起对比，演化的脉络就清楚了：

| 对比项 | 藻类 | 苔藓 | 蕨类 |
| --- | --- | --- | --- |
| 根茎叶分化 | 无 | 有茎叶（拟）、无真根 | 有根茎叶与维管组织 |
| 维管组织 | 无 | 无（有输导能力的类群也弱） | 有（真正的维管束） |
| 胚 | 无 | 有 | 有 |
| 生活史优势世代 | 配子体为主 | **配子体占优** | **孢子体占优** |
| 有性生殖对水的依赖 | 完全依赖 | 依赖（精子游泳） | 依赖（精子游泳） |
| 体型 | 单细胞~数十米 | 矮小（几毫米~几十厘米） | 几厘米~数米 |
| 代表 | 水绵、海带 | 葫芦藓、地钱 | 肾蕨、铁线蕨 |

**辨析｜易错点：** 蕨类虽然有了真正的根茎叶与维管组织，但**它的精子仍然靠水游动**，所以蕨类生殖仍离不开水——这就是为什么蕨类多生于阴湿处。从苔藓到蕨类，「结构」升级了（有维管、能长高），但「生殖」还没有完全摆脱水的束缚；直到种子植物出现，用**花粉管+种子**把受精过程彻底从水中解放出来，植物才真正完成了「陆生独立」。

### 3.2 苔藓考点清单

- 苔藓是有胚植物中最原始类群：有胚、无维管、无真根。
- 配子体占优：绿色植物体是配子体（n），孢子体寄生其上。
- 精子借水游动：有性生殖离不开水。
- 假根：单细胞（苔）或多细胞（藓），主要起固定作用。
- 三大类群：苔纲（叶状体）、藓纲（茎叶分化、有中肋）、角苔纲。
- 世代交替的倍性闭环：减数分裂降倍、受精升倍。
- 生态角色：先锋植物、保水涵养、泥炭成炭。
- 泥炭藓：吸水极强，可做园艺基质与燃料。
- 环境指示：对大气污染敏感，可作指示植物。
- 易错辨析：「苔藓有真正的根」是错的，「苔藓无根茎叶分化」也是错的。
- 易错辨析：苔（无中肋）与藓（多有中肋）不是一回事。
- 与蕨类对比：苔藓无维管、配子体占优；蕨类有维管、孢子体占优。
- 原丝体：孢子萌发先长出的丝状体，再分化出新配子体，是苔藓独有的发育环节。

## 5 小结

- 苔藓是**有胚植物中最原始**的类群，有**茎叶分化、无真根、无完善维管组织**，配子体占优。
- 生殖**依赖水**：精子借水游动与卵结合；孢子体寄生在配子体上。
- 世代交替的倍性闭环：**减数分裂降倍、受精升倍**，这是所有高等植物生活史的总开关。
- 苔藓是**先锋植物**、保水涵养的关键，泥炭藓可成炭。
- 与藻类、蕨类对比：苔藓是「有胚、无维管、配子体占优」的中间环节。

在下一节，植物界迎来了第一次「长高」：真正有维管组织的**蕨类植物**登上舞台，在石炭纪长成遮天蔽日的森林——而它们留下的巨量遗体，变成了我们今天燃烧的煤。
