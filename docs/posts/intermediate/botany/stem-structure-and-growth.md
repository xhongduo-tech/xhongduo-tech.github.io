# 茎的结构与生长

## 为什么从茎开始

如果把植物体比作一座城市，根是地下的自来水厂，叶是地面上的太阳能发电厂，那么**茎**就是连接两者的城市骨架与交通网：它支撑着数以万计的叶片抢占阳光，又把根吸收的水分和叶制造的有机物在数米到上百米的高度差上双向运输。<span class="marginnote">世界最高的树——北美红杉——高逾 110 米，水能从根尖到树冠顶部完成「逆重力」输送，靠的不是泵，而是蒸腾拉力与水柱的内聚力。这个「连续水柱」假说我们在第五篇详细拆解。</span>茎还有储存养分、繁殖（扦插、压条都靠茎）的功能，而它「一生能不断长高、还能在木本植物中一年年加粗」的本领，正是植物与动物最本质的差别之一。弄懂茎的结构，就弄懂了「一株植物如何站到几十年后的大树」。

## 1 茎的基本形态：节、节间与芽

茎的形态特征可以用三个词概括：**节（node）**、**节间（internode）**与**芽（bud）**。

**节**：着生叶与芽的部位，是茎上相对膨大的区域。
**节间**：相邻两节之间的茎段。节间的长短变化极大——果树枝条上密集的节间与竹子飞速伸长的节间形成了鲜明对比。
**芽**：未发育的枝、花或花序的雏体。按发育结果分**叶芽**（长成枝条）、**花芽**（长成花或花序）与**混合芽**（先长枝叶后开花）。按着生位置分**顶芽**与**腋芽**（侧芽）。

**辨析｜易错点：** 「节」是叶着生的位置，判断茎上某处是不是节，要看有没有叶痕、芽或枝条——这是识别茎与根的关键：**茎有节和节间，根没有**。茎上能长芽和叶，根上不能（不定芽除外）。<span class="marginnote">「顶端优势」：顶芽抑制腋芽萌发的现象。摘除顶芽后侧芽解放、株形变得饱满，园艺上叫「打顶」——本质是顶芽产生的生长素（IAA）向下运输、抑制侧芽。</span>

## 2 茎的初生结构：维管束怎么排

把幼嫩茎横切，从外到内是**表皮、皮层、维管柱**三层，但茎的维管柱与根有一个关键区别：茎的**木质部与韧皮部相对排列**，维管束在横切面上排成一圈或散生，而不是像根那样木质部与韧皮部相间成星芒状。

按维管束的排列方式，茎分为两大类型：

**双子叶植物茎**：维管束在皮层以内排成**一轮（环状排列）**，维管束之间有髓射线相连。木质部在束的内侧，韧皮部在束的外侧，两者之间还夹着一层**束中形成层**——这让双子叶植物茎具有次生加粗的能力。<span class="marginnote">「茎木质部在内、韧皮部在外」与「根木质部辐射、韧皮部相间」是初生结构的两大坐标；记不住时想一句：茎像电缆（里铜外皮），根像车轮辐条（木条与皮条相间）。</span>
**单子叶植物茎**：维管束**散生于基本组织中**（玉米茎）或排成两轮（小麦茎），维管束内没有束中形成层，所以单子叶植物茎一般不能无限加粗——玉米秆长到一定粗细就定型了。<span class="marginnote">竹子是单子叶植物中「长不粗」的典型：竹笋破土时粗细即最终粗细，之后只长高不长粗，全靠在最初就定型的维管束密集排布获得强度。</span>

### 2.1 双子叶植物茎的三维结构

从外到内依次是：

1. **表皮**：一层细胞，外壁有角质层，气孔与皮孔分布其上，起保护与气体交换作用。
2. **皮层**：多层薄壁细胞，含叶绿体的皮层细胞使幼茎呈绿色，可进行光合作用。
3. **维管柱**：由维管束、髓与髓射线组成。**髓**位于茎中央，多为薄壁细胞；**髓射线**连接皮层与髓，兼有储藏与横向运输功能。

## 3 茎的次生生长：年轮从哪来

木本双子叶植物与裸子植物的茎，在初生生长完成后启动**次生生长**，这是茎变粗的根本机制。主角是两种侧生分生组织：

**维管形成层（vascular cambium）**：位于木质部与韧皮部之间（束中形成层 + 束间形成层连成一圈）。它向内分裂产生**次生木质部**（形成年轮的木部分），向外分裂产生**次生韧皮部**（树皮的内侧部分）。由于向内分裂产生的细胞远多于向外，年轮的主体几乎全是次生木质部。
**木栓形成层（cork cambium）**：在皮层中产生**周皮**（木栓层 + 木栓形成层 + 栓内层），木栓层细胞壁栓质化、不透水气，是树皮的主要来源。

**为什么会有年轮？** 温带地区维管形成层的活动随季节波动：春季水足，细胞大而壁薄，木材质地疏松，形成**早材（春材）**；夏秋水分渐少，细胞小而壁厚，形成**晚材（夏材）**。早材与晚材交替出现，就构成了一圈年轮。<span class="marginnote">年轮不只是「计龄器」：早材与晚材的宽窄比、细胞大小，记录了当年的水热条件——这就是「树木年轮气候学」（dendroclimatology）的根据，用它可重建数百上千年的气候变化。</span>

**公式解析：年轮年代学的计数**

$$N = \sum_{i=1}^{m} 1 + n_0$$

- **$N$**：树木的估计年龄（年）。
- **$m$**：在茎的横切面上数出的完整年轮数。一轮 = 一个早材带 + 紧邻的一个晚材带，代表一年的生长。
- **$n_0$**：误差修正项。因为树心处的髓与早期形成的木质部（尤其幼苗期）可能不含清晰年轮，以及人为取样高度等原因，需加 0–5 年修正。

对古树而言，还要结合**放射性碳定年**互相印证，因为髓心腐烂常让年轮数偏少。这个「数层数」的思想，与地质学里数地层、考古学里数陶片层是同一个操作——**把时间写进结构里**。<span class="marginnote">在「从极限到大模型」的主线里，这也是「用数据反推过程」的又一例：给定静态的横截面，重建动态的历史轨迹——和从一棵决策树反推训练过程是同一类思维。</span>

### 3.2 木材的结构：三个切面

从一段树干上切出三个互相垂直的切面，可以看到木材的立体结构：

**横切面**：垂直于树干纵轴的切面。年轮呈同心环状，木射线呈放射状细线，是数年轮、鉴别早晚材的最佳切面。
**径切面**：沿半径方向并通过髓心的纵切面。年轮呈平行纵带，射线呈横带状，纹理通直，是优质板材的来源。
**弦切面**：不通过髓心的纵切面。年轮呈「V」形或抛物线状花纹，射线细胞呈纺锤形，家具面板的美丽花纹多来自弦切面。

**辨析｜易错点：** 横切面上从髓心向外呈放射状的细线，是**木射线**——负责水与养分的径向运输与储藏，不是裂纹。初学者常把射线误认为裂缝，其实射线是正常的次生结构，贯穿木质部与韧皮部（维管射线）。同一株树，三个切面呈现的纹理完全不同；节疤、树瘤等缺陷在不同切面上形态各异。识别木材、下料与木工制作，都依赖对三个切面的空间想象力——这也是把「二维切片」还原成「三维结构」的经典训练，和医学影像、工程制图是同一类空间思维。

此外，「树皮」是一个笼统的称呼：木本茎的树皮通常指维管形成层以外的全部组织，包括次生韧皮部、皮层、周皮与表皮。每次形成层活动向外产生的次生韧皮部，在内部新韧皮部生成后逐渐被挤向外部、失去功能，成为「死韧皮部」；周皮则层层更替，老周皮连同其内的死组织一起剥落。所以树皮是「活韧皮部 + 死韧皮部 + 周皮」的复合体——树皮上粗糙的裂纹，正是周皮逐年更新留下的「历史的皮肤」。

## 4 茎的变态与功能总结

茎同样有丰富的**变态**类型，与根的变态遥相呼应：

| 变态类型 | 实例 | 功能 |
| --- | --- | --- |
| 块茎 | 马铃薯 | 储藏淀粉与不定芽 |
| 鳞茎 | 洋葱、大蒜 | 储藏 + 越冬 |
| 球茎 | 荸荠、慈姑 | 储藏 |
| 根状茎 | 姜、竹鞭 | 储藏 + 蔓延繁殖 |
| 茎卷须 | 葡萄 | 攀援 |
| 茎刺 | 山楂、皂荚 | 防御 |
| 匍匐茎 | 草莓 | 营养繁殖 |

**辨析｜易错点：** 马铃薯的「土豆」是**块茎**，红薯的「地瓜」是**块根**——前者是茎（有节、有芽眼，芽眼就是节上的芽），后者是根（无节无芽）。「马铃薯上的芽眼能发芽、红薯不能从身上直接长出芽」是区分二者的生活常识判据。<span class="marginnote">「茎上长芽、根上长根毛」：识别变态器官先问「它有没有节和芽」。有节有芽的是茎的变态，无节无芽、能长侧根的是根的变态。</span>

**辨析｜易错点：** 草莓的「匍匐茎」与葡萄的「茎卷须」同为茎变态，但匍匐茎执行营养繁殖、沿地蔓延并在节上生根；茎卷须执行攀援、缠绕他物。判断茎变态的通用口令仍然是「看节与芽」：匍匐茎每节都有叶与芽，卷须特化后节与芽不明显。把「有无节与芽」用熟，地上地下、储藏攀援的各种茎变态都能一眼分辨。

### 3.3 茎的结构考点清单

- 茎的三大形态特征：节、节间、芽。
- 茎 vs 根第一判据：茎有节与芽，根没有。
- 双子叶茎维管束环状排列、有束中形成层，能次生加粗。
- 单子叶茎维管束散生、无形成层，不能无限加粗。
- 双子叶茎三层：表皮、皮层、维管柱（维管束 + 髓 + 髓射线）。
- 维管形成层：向内产次生木质部、向外产次生韧皮部。
- 木栓形成层：产生周皮（树皮来源）。
- 年轮：早材（春材）大而壁薄 + 晚材（夏材）小而壁厚交替。
- 木材三切面：横切面看年轮同心环、径切面看平行纵带、弦切面看 V 形花纹。
- 茎变态：块茎（有芽眼）、鳞茎（鳞茎盘）、球茎、根状茎、茎卷须、茎刺、匍匐茎。
- 易错辨析：马铃薯是块茎（有芽眼），甘薯是块根（无节无芽）。
- 易错辨析：木射线是正常次生结构，不是裂缝。

## 5 小结

- 茎的基本形态是**节、节间、芽**；**茎有节与芽，根没有**，这是判别二者的第一判据。
- 双子叶植物茎维管束**环状排列**、含束中形成层，能次生加粗；单子叶植物茎维管束**散生**、无形成层，不能无限加粗。
- 双子叶植物茎从外到内为**表皮、皮层、维管柱**（维管束 + 髓 + 髓射线）。
- **维管形成层**向内产生次生木质部、向外产生次生韧皮部；**木栓形成层**产生周皮。早材与晚材交替形成**年轮**。
- 茎的变态（块茎、鳞茎、根状茎、茎卷须、茎刺、匍匐茎等）以「有无节与芽」与根变态区分。
