# 世界地理（区域地理：各洲与主要区域/国家地理）

世界区域地理以全球海陆格局为起点，从各大洲自然地理切入，系统梳理各区域与主要国家的自然与人文地理特征，是地理科学专业的核心必修课。以刘德生《世界自然地理》与杜德斌《世界地理》为纲，学完这些章节，就写完了世界地理的完整框架。

## 对标教材

- 刘德生《世界自然地理》（高等教育出版社）
- 杜德斌《世界地理》（高等教育出版社）
