# 植物病理学

植物病理学是植物保护学科（0904）的主干二级学科，系统研究植物病害的成因（真菌、细菌、病毒、线虫等病原物及非侵染性因素）、发生发展规律与防治原理，是连接微生物学、植物学与农业生产实践的桥梁学科。对标权威教材体系，按章节逐节写成博文，学完一个学科 = 写完该学科权威教材对应的全部博文。

## 对标教材

- George N. Agrios, *Plant Pathology* (5th ed., Academic Press)
- 谢联辉等《普通植物病理学》中国农业出版社
- 康振生等《植物病理学原理》中国农业出版社
