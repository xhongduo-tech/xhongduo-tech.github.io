## 植物也会「打了疫苗记住敌人」吗

上一课的基因对基因假说回答「为什么抗」，这一课要问一个更反直觉的问题：**植物被病原感染过一次之后，会不会「免疫」？**

哺乳动物有免疫记忆——打过疫苗就不会再得天花。植物没有抗体、没有淋巴细胞，但在 20 世纪中叶，人们发现：**被某些病原（或诱导物）轻度刺激过的植物，全株会对后续侵染产生广谱而持久的抗性**。

这种「被刺激后全株变强」的现象，就是**系统获得抗性（SAR）**。它听起来像疫苗，机制上又别具一格。

## 1 系统获得抗性（SAR）：一场「全株军训」

**系统获得抗性（systemic acquired resistance, SAR）**：植物受到局部侵染或诱导物处理后，在未受侵染的部位也产生广谱、持久的抗病性。

SAR 的关键特征：

**系统性**：抗性扩展到全株，不只局限在刺激部位——「一处发炎，全身警戒」。

**广谱性**：对多种病原（真菌、细菌、病毒）普遍有效，不针对单一病原。

**持久性**：诱导后可维持数周至数月，覆盖整个生长季。

**依赖水杨酸（SA）**：SAR 的信号传导以**水杨酸**为核心介导分子——这是它与另一类「诱导抗性」的分水岭。

<span class="marginnote">SAR 最像「打疫苗」的地方：先用弱毒株或非致病诱导物「练练兵」，让植物建立警戒，再面对真正的强毒病原时就从容应对。但注意 SAR 不是「识别特定病原的记忆」，而是「广谱的警戒状态提升」——更像「提高整体免疫力」而非「接种特异性疫苗」。</span>

## 2 SAR 的分子机器：从伤疤到全身

SAR 是怎么从「局部伤口」传到「全身警戒」的？经典的分子链条是：

**第一步，局部坏死信号**：局部被病原侵染并触发 HR（超敏反应）后，坏死区释放信号分子。

**第二步，系统信号传递**：水杨酸（SA）在局部合成，并经韧皮部运往全株；同时 **NPR1** 蛋白作为核心「开关」接受 SA 信号。

**第三步，广谱防御基因上调**：NPR1 进入细胞核，激活大量**PR 蛋白（病程相关蛋白）**基因的表达——几丁质酶、β-1,3-葡聚糖酶等抗菌蛋白在全株累积。

**第四步，警戒状态维持**：PR 蛋白与防御代谢物的持续积累，使全株处于「常备警戒」状态，持续数周至数月。

<span class="marginnote">把 SAR 链条与《先天免疫》对照：SAR 是 ETI 的「余波」——ETI 在局部引爆超敏反应，SAR 把这个「警报」传遍全株并转换为持续性的防御准备。可以说，SAR 是先天免疫的「记忆化」延伸。</span>

**辨析｜易错点：** 水杨酸（SA）与茉莉酸（JA）两条信号通路常相互拮抗。SA 主导的 SAR 对活体营养型病原有效，而 JA/ET 通路主导的诱导抗性（ISR）则对死体营养型与昆虫更有效——所以「一种诱导物打天下」并不现实，选诱导物要看目标病害类型。

## 3 诱导抗性（ISR）：另一条「训练」通路

除了 SAR，植物还发展出**诱导系统抗性（induced systemic resistance, ISR）**——由**根际有益微生物**（如某些芽孢杆菌、假单胞菌、菌根真菌）定殖根部后诱导产生。

ISR 与 SAR 的关键区别：

**信号不同**：ISR 依赖**茉莉酸（JA）/乙烯（ET）**通路，而非水杨酸。

**诱导源不同**：ISR 由根际益生菌「打卡」诱导，不需要病原侵染或坏死。

**结果类似**：两者都使全株对后续侵染广谱抗病。

<span class="marginnote">ISR 是「生物防治」与「诱导抗性」的交汇点：施用芽孢杆菌类生防菌剂，既能直接拮抗病原，又能通过 ISR 让植物「变强」。这给《生物防治》一课埋下一个伏笔——好的生防菌往往「一菌多效」。</span>

## 4 诱导抗性的农业应用

把 SAR/ISR 从实验室搬到田间，就成了一类绿色防控手段——**植物免疫诱导剂**：

**商品化诱导剂**：水杨酸类衍生物（如 BTH/苯并噻二唑）、茉莉酸甲酯、壳聚糖、β-氨基丁酸（BABA）等，可在生产上喷施诱导植物抗病。

**生防菌剂诱导 ISR**：芽孢杆菌、木霉等制剂在根部定殖，既拮抗病原又诱导 ISR。

**栽培诱导**：适度锻炼（如控水）、合理营养（硅、钾）可提升基础抗病性，虽不属严格 SAR，但同属「让植物更强」的思路。

<span class="marginnote">诱导抗性的农业价值在于「预防性、广谱、低残留」：它不能救急（发病后再诱导来不及），适合作为<strong>预防性策略</strong>与化学防治轮换、搭配，减少农药用量。这与第5篇《综合防治》的「绿色防控」理念直接衔接。</span>

## 5 核心对比表：SAR 与 ISR

（纯概念主题，用核心对比表替代公式解析）

| 比较项 | 系统获得抗性（SAR） | 诱导系统抗性（ISR） |
| --- | --- | --- |
| 诱导源 | 局部病原侵染/坏死 | 根际有益微生物定殖 |
| 核心信号 | 水杨酸（SA） | 茉莉酸（JA）/乙烯（ET） |
| 关键调控 | NPR1 | 常不依赖 NPR1 |
| 作用对象 | 活体营养型病原较有效 | 死体营养型与昆虫较有效 |
| 典型表现 | PR 蛋白全株累积 | 基础防御状态提升 |
| 农业载体 | 免疫诱导剂（BTH 等） | 生防菌剂（芽孢杆菌等） |

## 6 术语速查表

| 术语 | 含义 | 关键点 |
| --- | --- | --- |
| 系统获得抗性 | 局部刺激后全株广谱抗病 | 依赖水杨酸 |
| NPR1 | SAR 信号的核心开关 | SA 下游 |
| PR 蛋白 | 病程相关蛋白 | 几丁质酶、葡聚糖酶 |
| 诱导系统抗性 | 根际益生菌诱导的广谱抗病 | 依赖 JA/ET |
| 免疫诱导剂 | 喷施诱导植物抗病的物质 | BTH、BABA、壳聚糖 |
| 拮抗作用 | SA 与 JA/ET 通路相互抑制 | 选诱导物看病害 |
| 系统信号 | 局部刺激传遍全株的信号 | 韧皮部转运 |
| 诱导抗性 | 广义：被刺激后变强 | 含 SAR 与 ISR |
| 信号传导 | 局部到全株的警报传递 | NPR1、SA |

**补充｜延伸：** SAR/ISR 是「免疫接种式」防治的理论基石，但要注意诱导抗性不改变寄主的基因型——它只是「状态」上的提升。若病原发生新的毒性变异，诱导抗性同样可能失效，因此它需与抗病品种、药剂配合使用。

## 7 小结

- **系统获得抗性（SAR）**：局部侵染刺激后，全株产生广谱、持久的抗病性，核心信号是**水杨酸（SA）**。
- SAR 的分子链条：局部 HR → SA 合成转运 → NPR1 开关 → PR 蛋白全株累积。
- **诱导系统抗性（ISR）**：由根际益生菌诱导，依赖**茉莉酸/乙烯**通路，是另一条「训练」路径。
- SA 与 JA/ET 通路常**相互拮抗**，选诱导物须看目标病害类型。
- 农业应用为**植物免疫诱导剂**（BTH、BABA、壳聚糖等）与生防菌剂，是预防性的绿色防控手段。

在下一节，我们将把这些抗病机制「变现」为育种的行动——如何把抗病基因选出来、聚起来、导入优良品种，这就是**抗病育种与分子育种**。
