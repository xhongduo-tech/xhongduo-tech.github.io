## 为什么从病毒开始

前四节的生命都有完整的细胞结构，无论原核还是真核。病毒把这条底线掀翻：
**它没有细胞，没有核糖体，没有能量代谢，只有一个核酸核心加一层蛋白质壳**——却能在宿主细
胞内精准地劫持分子机器，大量复制自己。
病毒是「生命边界」的试金石，也是理解分子生物学（复制、转录、翻译如何被操纵）最锋利的手术刀。
<span class="marginnote">「病毒是不是生物」在教科书上长期悬置：
它不满足细胞生命的所有代谢标准，又确实携带遗传信息、能演化。答案取决于你怎么定义「生命」——
这正是《生物学哲学》或科学哲学乐于追问的问题。</span>

## 1 病毒是什么

**病毒（virus）**：一类形体微小（
$20\text{–}300\ \text{nm}$，多数需电子显微镜观察）、结构简单、
只含一种核酸（DNA 或 RNA）、不能独立进行代谢、
必须专性寄生于活细胞内增殖的非细胞生物。

把这段定义拆成四个要件，就是病毒的「简历」：

**非细胞**：没有细胞膜包裹的独立代谢区室（虽有部分病毒有包膜，那只是宿主膜脂的偷借）。
**一种核酸**：任何病毒只含 DNA 或只含 RNA，不像细胞那样两者兼具。
  <span class="marginnote">这条「一种核酸」原则是巴尔的摩分类法（Ba
  ltimore classification，按核酸类型与复制方式分七类）的基石——HIV
  是 RNA 病毒（巴尔的摩 VI 类），乙肝病毒是 DNA 病毒却经 RNA 中间体复制。
  </span>
**无核糖体、无产能酶系**：病毒完全依赖宿主细胞的核糖体合成蛋白、依赖宿主 ATP 供能
  ——这决定了它**不能用培养基培养**，只能用活细胞（细胞培养、鸡胚、实验动物）。
**专性胞内寄生**：在细胞外，病毒只是无生命的核酸-蛋白质复合体，
  可以结晶存放（烟草花叶病毒是最早被结晶的病毒）。

## 2 病毒的结构与形态

一个病毒粒子的标准构造由两部分组成：

**核心**：一条或几条核酸分子（DNA 或 RNA，单链或双链）。
**衣壳（capsid）**：由许多**衣壳粒（capsomere）**规则排列成的蛋白质壳
  ，保护核酸并介导与宿主受体的识别。

核酸 + 衣壳合称**核衣壳（nucleocapsid）**。有些病毒在核衣壳外再裹一层
**包膜（envelope）**——这是从宿主细胞膜上「偷」来的脂双层，上面插着病毒编码的
**刺突糖蛋白**（如流感病毒的血凝素 HA、神经氨酸酶 NA），用于识别与进入宿主细胞。
<span class="marginnote">包膜病毒（流感、HIV、
新冠病毒）的包膜本质是宿主脂膜，因此<strong>对脂溶剂和干燥极敏感</strong>——肥皂洗手、
酒精消毒之所以能高效灭活它们，原理就在此。</span>

衣壳的对称方式决定病毒的整体形态：

**二十面体对称**：衣壳粒排列成二十面体，像一颗足球，如腺病毒、脊髓灰质炎病毒。
**螺旋对称**：衣壳粒沿核酸螺旋盘绕成杆状，如烟草花叶病毒。
**复合对称**：头部二十面体 + 尾部螺旋，是噬菌体（细菌病毒）的招牌造型。

## 3 病毒的增殖：一次典型的裂解循环

以 T4 噬菌体感染大肠杆菌为例，病毒的增殖分六步，通称
**裂解循环（lytic cycle）**：

1. **吸附（adsorption）**：尾丝与宿主细胞壁/受体特异性结合——**特异性**决定
   宿主范围，这是病毒「认门」的关键。
2. **侵入（penetration）**：尾鞘收缩，把头部 DNA 注入细菌胞内，
   衣壳留在外面。
3. **脱壳与复制（replication）**：病毒核酸借宿主 RNA 聚合酶、核糖体，
   先合成早期蛋白（破坏宿主 DNA、接管转录机器），再复制自身核酸、合成晚期结构蛋白。
4. **装配（assembly）**：核酸与衣壳蛋白组装成完整子代病毒。
5. **释放（release）**：裂解酶溶破宿主细胞，子代噬菌体释放（对包膜病毒则是出芽，
   不一定杀死细胞）。

从吸附到释放，一个裂解循环在合适条件下约 30–40 分钟，
一个被感染的细菌可释放数百个子代噬菌体。**一个细菌被劫持成病毒工厂，数量呈指数爆炸**——
这正是病毒「不代谢却极快扩散」的真相。

## 4 温和噬菌体：裂解之外的第三条路

并非所有噬菌体都走裂解路线。**温和噬菌体（temperate phage）**感染宿主后可
以不走裂解循环，而是把自身核酸整合进宿主染色体，随宿主一起复制传代——这种状态叫
**溶原（lysogeny）**，整合进去的病毒核酸叫**前噬菌体（prophage）**。
<span class="marginnote">溶原状态可以长期稳定：宿主照常生长，
前噬菌体随染色体传给子代。当紫外线、辐射等条件诱发时，前噬菌体被切除、转入裂解循环——这是「
休眠病毒」在分子层面的机制。</span>

**辨析｜易错点：** 溶原 ≠ 病毒不增殖。
溶原只是把「增殖」延后并改为随宿主染色体同步复制，诱发条件一到照样裂解。
同时注意：有些前噬菌体还携带毒素基因（白喉杆菌的毒素、霍乱弧菌的霍乱毒素都由前噬菌体编码）
——**细菌的致病力有时是病毒「赐予」的**。

## 5 核心辨析：病毒与细菌

| 特征 | 细菌 | 病毒 |
| --- | --- | --- |
| 细胞结构 | 有（原核细胞） | 无 |
| 核酸 | DNA + RNA | 仅一种核酸 |
| 核糖体 | 有（70S） | 无 |
| 能量代谢 | 有（呼吸/发酵） | 无，靠宿主 |
| 培养 | 普通培养基可培养 | 必须活细胞/鸡胚/动物 |
| 抗生素作用 | 有效 | 无效（需抗病毒药） |
| 大小 | $0.5\text{–}5\ \mu m$ | $20\text{–}300\ \text{nm}$ |

**辨析｜易错点：** 「抗生素杀病毒」是流传极广的误解。
抗生素攻击细菌的细胞壁合成、70S 核糖体等靶点，病毒没有这些结构，自然无从下手；
普通感冒用抗生素无效，正是这个道理。<span class="marginnote">此外，
病毒之下还有更简的<strong>亚病毒因子</strong>：类病毒（viroid）是裸露的环状 RNA 分子，
能感染植物；朊病毒（prion）干脆是<strong>一个蛋白质</strong>，
能诱导正常蛋白变构而致病（疯牛病）。朊病毒把「生物」的定义推向极致。</span>

## 6 小结

- 病毒是**非细胞、只含一种核酸、无核糖体、专性胞内寄生**的增殖实体。
- 结构 = 核酸核心 + 衣壳（± 包膜）；形态分**二十面体、螺旋、复合**对称。
- 增殖六步：**吸附→侵入→复制→装配→释放**；温和噬菌体另可走**溶原**路线。
- 溶原态下病毒基因随宿主传代，还常携带毒素基因。
- **抗生素对病毒无效**；亚病毒因子（类病毒、朊病毒）比病毒更简单。
