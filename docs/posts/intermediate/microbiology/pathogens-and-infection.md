## 为什么从病原开始

上一节我们站在宿主这边看防御，这一节站到病原那边看进攻。
感染不是「细菌来了就生病」的简单事件，而是一场
**取决于病原体毒力、宿主免疫力与环境条件的三方博弈**——同一株大肠杆菌，
在健康成年人肠道里相安无事，进了腹腔或尿道就引发重症。
理解致病机制，才能理解诊断、治疗与预防的每一个环节。
<span class="marginnote">「病原微生物（pathogen）」与「致病
性（pathogenicity）」要分清：致病性是一个物种「能不能致病」的定性属性，
毒力（virulence）是「致多重的病」的定量程度，常用半数致死量 LD50 衡量。
</span>

## 1 感染：入侵、定殖与发病

**感染（infection）**：病原微生物侵入宿主、在体内繁殖并引起机体病理变化的过程。
它通常要闯过四关：

1. **黏附与定殖**：先用菌毛、黏附素「锚定」在宿主黏膜或组织表面——粘不住就进不去。
2. **侵入**：借助损伤部位、受体介导内吞或酶解组织屏障，进入组织或细胞内部。
3. **繁殖与扩散**：在局部繁殖，再沿血液、淋巴或神经扩散。
4. **损伤与发病**：通过毒素、酶或免疫病理反应损伤组织，表现出症状。

**感染三要素**是**病原体、宿主、环境**：三个变量互相制约。宿主免疫力强时，入侵可能以
**隐性感染**告终（无临床症状），病原却借此传播——这正是「看不见的传染源」让流行病学棘手
的根源。<span class="marginnote">无症状携带者是传染病防控的关键盲区
。结核、乙肝、新冠都存在大量隐性或亚临床感染者，他们不发病，却可能持续排菌。</span>

## 2 致病机制：侵袭力与毒素

病原菌致病的本领可归为两大类：**侵袭力**与**毒素**。

**侵袭力（invasiveness）**：病原菌突破宿主防御、在体内定殖扩散的能力，
靠的是结构与酶：

**荚膜与微荚膜**：抵抗吞噬细胞的吞噬，如肺炎链球菌的荚膜。
**黏附因子**：菌毛、表面蛋白，帮助定殖。
**侵袭性酶**：透明质酸酶溶解结缔组织、使感染扩散；
  凝固酶使纤维蛋白沉积、把细菌包进「堡垒」逃避吞噬。
  <span class="marginnote">金黄色葡萄球菌既产凝固酶又产多种毒素，
  所以化脓、毒血症样样在行——它是「侵袭力 + 毒素」双修的代表。</span>

**毒素（toxin）**：细菌分泌或释放的毒性物质，分**外毒素**与**内毒素**两大系
统。

## 3 核心辨析：外毒素与内毒素

| 特征 | 外毒素（exotoxin） | 内毒素（endotoxin） |
| --- | --- | --- |
| 来源 | 革兰氏阳性菌为主（也有的 G⁻） | 革兰氏阴性菌外膜的脂多糖（LPS） |
| 化学本质 | 蛋白质 | 脂多糖 |
| 释放方式 | 分泌到菌体外 | 菌体裂解或死亡时释放 |
| 毒性 | 极强（微克级致死） | 较弱（休克、发热） |
| 稳定性 | 不耐热（60–80°C 失活） | 耐热（121°C 不失活） |
| 免疫学 | 可制成**类毒素**（甲醛脱毒） | 不能制成类毒素 |
| 代表 | 白喉毒素、破伤风毒素、霍乱毒素 | 肠道革兰氏阴性菌感染时的发热与内毒素休克 |

**辨析｜易错点：** 「革兰氏阴性菌 = 内毒素、阳性菌 = 外毒素」不成立——某些革兰氏
阴性菌（霍乱弧菌）也分泌强效外毒素。区分的根本是**化学本质与释放方式**：蛋白质、
主动分泌的是外毒素；LPS、裂解释放的是内毒素。另外**内毒素耐热**，
消毒不彻底照样残留致热活性——这是无菌制剂生产必须做内毒素检测的原因。
<span class="marginnote">破伤风类毒素、
白喉类毒素就是「缴了械的外毒素」：保留抗原性、去掉毒性，注射后让免疫系统预习而不受伤——疫苗
学的经典操作。</span>

## 4 传播途径与感染类型

**传播途径**决定防控重点，记住五条主路：

**呼吸道**：飞沫、气溶胶——流感、结核、新冠，戴口罩与通风是防线。
**消化道**：粪-口途径——霍乱、痢疾、伤寒，食品安全与手卫生是防线。
**接触传播**：直接或间接接触——皮肤伤口感染、性传播疾病。
**血液/体液**：输血、共用针具、母婴垂直传播——乙肝、HIV、梅毒。
**虫媒**：蚊、蜱等节肢动物叮咬——疟原虫、登革病毒。

**感染类型**按表现分：**显性感染**（有明显症状）与**隐性感染**（无症状）；
按病程分**急性**与**慢性**；特殊情形还有**潜伏感染**（病原长期潜伏、
条件合适再激活，如结核、水痘-带状疱疹病毒）与**机会性感染**（只在免疫力低下时发作，
如肺孢子菌肺炎、巨细胞病毒）。<span class="marginnote">机会性感染是
艾滋病患者死亡的主要原因：HIV 摧毁 CD4⁺ T 细胞后，平时无害的微生物纷纷「反水」
——这解释了为什么免疫缺陷者的感染谱与正常人截然不同。</span>

## 5 典型病原微生物速览

**金黄色葡萄球菌**：G⁺ 球菌，化脓性感染之王；产肠毒素致食物中毒、产毒性休克毒素。
  耐药株 MRSA 是医院感染的头号难题。
**大肠杆菌**：G⁻ 杆菌，肠道正常菌群，但进入泌尿道、腹腔即致病；
  肠出血株（O157:H7）产志贺样毒素。
**结核分枝杆菌**：G⁺（抗酸染色阳性）胞内菌，慢性呼吸道感染，靠荚膜样蜡质抵抗吞噬，
  需长程联合用药。
**霍乱弧菌**：G⁻ 弧菌，产霍乱毒素使肠细胞大量排水，腹泻脱水可在数小时内致命。
**HIV**：RNA 病毒，感染 CD4⁺ T 细胞，破坏细胞免疫，导致 AIDS。
  <span class="marginnote">HIV 是「破坏免疫系统本身」的病毒，
  所以它攻击的是上一节《免疫》的主角——CD4⁺ T 细胞。免疫学与病原学在这里精确对接。
  </span>
- **流感病毒**：包膜 RNA 病毒，表面 HA/NA 抗原漂移与转变，年年引发季节性流行。

## 6 小结

- **感染三要素**：病原体、宿主、环境；胜负取决于毒力、免疫力与暴露方式。
- 致病机制两大支柱：**侵袭力**（黏附、荚膜、酶）与**毒素**。
- 外毒素（蛋白、可成类毒素）vs 内毒素（LPS、耐热）——区分看本质与释放方式。
- 传播途径五条：**呼吸道、消化道、接触、血液体液、虫媒**。
- 感染类型含**显性/隐性、急性/慢性、潜伏、机会性**；机会性感染是免疫缺陷的哨兵。
