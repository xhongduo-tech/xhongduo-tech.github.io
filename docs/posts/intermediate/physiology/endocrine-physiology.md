## 为什么从内分泌开始

神经系统靠神经纤维「点对点」传递信号，快而精准；但有些调节需要**持久、弥散、波及全身**——比如生长发育、新陈代谢、生殖、水盐平衡。这套靠**激素（hormone）**经血液运输实现的调节系统，就是**内分泌系统**。<span class="marginnote">内分泌与神经的比较：神经是「电报」（毫秒级、直达），内分泌是「广播」（分钟到小时级、覆盖全身）。但二者高度耦合——下丘脑就是神经与内分泌的「转换站」，神经信号在此变成激素释放。这正是《稳态与生理调节》里「神经-体液调节」的一体两面。</span>前面各章多次提到的激素（EPO、ADH、醛固酮、甲状腺激素、胰岛素）在这一章汇成一个体系：**它们由谁分泌、怎么起作用、怎么被调控**。

## 1 激素的一般特性与作用机制

**激素（hormone）**是内分泌腺或内分泌细胞分泌的高效能生物活性物质，经血液运输到靶细胞起作用。按化学结构分两大类，作用机制也据此分成两条路：

**含氮激素**（肽/蛋白类：胰岛素、生长激素、促激素；胺类：肾上腺素、甲状腺激素）：多数与靶细胞**膜受体**结合，经**第二信使**（cAMP、IP3/DAG、$\ce{Ca^2+}$ 等）把信号放大并传导，作用快；
**类固醇激素**（糖皮质激素、盐皮质激素、性激素）与**甲状腺激素**：分子小且脂溶性高，可进入细胞与**胞内受体 / 核受体**结合，直接**调节基因转录**，作用慢而持久。<span class="marginnote">易错点要在这里立住：<strong>甲状腺激素虽然分子上是胺类（酪氨酸衍生），却像类固醇激素一样作用于核受体、调节基因转录</strong>——所以它起效慢、持续时间长（半衰期以天计）。判断一种激素「走膜受体还是核受体」，看的是它的作用方式，不是它属于哪一类化学。</span>

激素作用有四个特征：**信使作用**（只传递信息、不直接参与反应）、**微量高效**（血中浓度极低即可起作用）、**信息传递**（同一种激素在不同细胞可引发不同反应，取决于靶细胞的受体）、**相互作用**（协同作用如胰高血糖素与肾上腺素都升血糖；拮抗作用如胰岛素与胰高血糖素；**允许作用**——一种激素为另一种激素发挥作用提供条件，如**糖皮质激素允许儿茶酚胺**的缩血管效应）。<span class="marginnote">「允许作用」是内分泌里最绕也最重要的概念：糖皮质激素本身收缩血管作用弱，但没有它，去甲肾上腺素几乎无法收缩血管——糖皮质激素是给儿茶酚胺「开绿灯」。临床上长期用糖皮质激素的病人骤停激素，可能因「绿灯熄灭」而发生低血压。</span>

## 2 下丘脑-垂体系统：内分泌的总指挥部

**下丘脑**是神经与内分泌的枢纽，它通过两套通路指挥垂体：

**下丘脑-腺垂体轴**：下丘脑的神经内分泌细胞分泌**下丘脑调节肽**（释放激素与释放抑制激素），经垂体门脉系统到达**腺垂体**，调节腺垂体分泌。腺垂体分泌六种激素：**生长激素（GH）**（促生长、促蛋白质合成）、**催乳素（PRL）**、**促甲状腺激素（TSH）**、**促肾上腺皮质激素（ACTH）**、**促性腺激素（FSH、LH）**。<span class="marginnote">生长激素的「过量」与「不足」留下经典的疾病谱：幼年分泌不足 → 侏儒症（身材矮但比例匀称），幼年分泌过多 → 巨人症，成年后分泌过多 → 肢端肥大症（骨不再长，软组织与颅面增生）。GH 还能促进脂肪分解、抗胰岛素，长期过多会继发糖尿病。</span>

**下丘脑-神经垂体轴**：神经垂体不合成激素，它只**储存并释放**下丘脑视上核、室旁核合成的两种激素：**抗利尿激素（ADH）**（保水，见《尿的生成与排出》）与**缩宫素（OT）**（促进子宫收缩、射乳反射）。

**下丘脑-垂体-靶腺轴**：TSH→甲状腺、ACTH→肾上腺皮质、FSH/LH→性腺，三条「轴」都遵循同一套控制逻辑：**下丘脑释放激素 → 垂体促激素 → 靶腺激素，靶腺激素反过来负反馈抑制下丘脑与垂体**。这就像三层恒温器：越往下游越「具体」，越上游越「总控」。<span class="marginnote">「轴」的临床意义在测定与诊断：血中 TSH 高而 T3/T4 低 → 问题在甲状腺本身（原发性甲减）；TSH 低而 T3/T4 低 → 问题在垂体或下丘脑（中枢性）。「激素水平 + 上游激素水平」联合判读，是内分泌诊断的标准思维。</span>

## 3 甲状腺：代谢的油门

甲状腺分泌**甲状腺激素**，主要有 **T4（四碘甲腺原氨酸）**与**T3（三碘甲腺原氨酸）**——T4 分泌量大但活性低，T3 分泌量小却活性强（约为 T4 的 5 倍），且 T4 可在靶组织脱碘变为 T3。甲状腺有强大的**聚碘能力**（碘泵，$\ce{Na^+-I^-}$ 共转运，腺内碘浓度可比血浆高约 30 倍），这是它能高效合成激素的基础，也是放射性碘（碘-131）用于诊断与治疗甲亢的原理——甲状腺把碘「抢」进去，治疗就跟着碘进去。

**甲状腺激素的生理作用**有三方面：**促进能量代谢**（提高基础代谢率，是《能量代谢与体温》里 BMR 的主要决定因素）、**促进生长发育**（尤其脑与骨骼，婴儿期缺乏 → **呆小症**：智力低下 + 身材矮小）、**提高神经系统兴奋性**（过多则易激动、手抖、失眠）。由此推出两幅相反的临床图景：

- **甲亢**（T3/T4 过多）：怕热多汗、体重下降、心悸、手抖、突眼，基础代谢率升高 30%–80%；
- **甲减**（T3/T4 不足）：怕冷、乏力、反应迟钝、黏液性水肿、记忆力减退，基础代谢率降低 30%–50%。<span class="marginnote">碘的双刃剑：缺碘 → 甲状腺激素合成不足 → TSH 代偿性升高 → 甲状腺代偿性增生肥大，即<strong>地方性甲状腺肿（大脖子病）</strong>；补碘过量同样可诱发甲亢（碘甲亢）。「碘盐、海带、甲状腺肿大」这条线索，把营养、内分泌与公共卫生串在同一条生理逻辑上。</span>

**甲亢与甲减对照速览**：

| 维度 | 甲亢 | 甲减 |
| --- | --- | --- |
| 激素水平 | T3/T4 升高、TSH 降低 | T3/T4 降低、TSH 升高（原发性） |
| 基础代谢率 | 升高 30%–80% | 降低 30%–50% |
| 体温与体重 | 怕热多汗、体重下降 | 怕冷、体重增加 |
| 心脏 | 心悸、心率快、房颤 | 心率慢 |
| 神经系统 | 兴奋、手抖、失眠 | 反应迟钝、嗜睡 |
| 眼 | 突眼 | 黏液性水肿 |

**辨析｜易错点：** 看「TSH 与 T3/T4 谁先低」能定位病变层级——T3/T4 低 + TSH 高 = 问题在甲状腺本身（原发性）；T3/T4 低 + TSH 也低 = 问题在垂体或下丘脑（继发性）。「下游不足 + 上游代偿升高」这套逻辑，对肾上腺、性腺轴同样适用。

甲状腺受 **TSH 调控**，TSH 又受下丘脑 **TRH** 调控，T3/T4 反过来负反馈抑制 TRH 与 TSH——这是「下丘脑-垂体-靶腺轴」的第一条完整样板，也是第 2 节「激素 + 上游激素」联合判读的实战对象。

## 4 肾上腺：应急与保命的双管

**肾上腺**分**皮质**与**髓质**，二者胚胎来源不同、功能迥异。髓质由神经嵴细胞分化而来，本质是**交感神经的「节后神经元」**；皮质是真正的内分泌腺体，分三层各分泌一类激素。

**髓质**分泌**肾上腺素**与**去甲肾上腺素**（儿茶酚胺），作用与交感神经兴奋一致：心跳加快、血压升高、支气管舒张、血糖升高——「应激（fight or flight）」的激素版，短时爆发、迅速见效。<span class="marginnote">肾上腺素与去甲肾上腺素的分工：<strong>肾上腺素主打心脏与代谢</strong>（加快心率、升高血糖），<strong>去甲肾上腺素主打血管收缩</strong>（升压）。临床上抢救过敏性休克首选肾上腺素（强心 + 收缩血管 + 舒张支气管三管齐下），升压则常用去甲肾上腺素——「一个救心、一个保压」。</span>

**皮质**三层各管一摊：**球状带**分泌**盐皮质激素**（醛固酮，保钠排钾、保水，是《尿的生成与排出》与《血液循环生理》里 RAAS 的末端执行者）；**束状带**分泌**糖皮质激素**（皮质醇，调节糖、脂、蛋白质代谢，抗炎、抗过敏、抗休克，并具有允许作用）；**网状带**分泌少量**性激素**（以雄激素为主）。

**糖皮质激素**是临床上用得最多的激素之一：它升高血糖（糖异生）、动员脂肪、促进蛋白分解；长期大量使用可致向心性肥胖、骨质疏松、免疫抑制与血糖升高——「激素的副作用」说的主要就是糖皮质激素。它受 **HPA 轴**（下丘脑 CRH → 垂体 ACTH → 皮质醇）调控，皮质醇负反馈抑制 CRH 与 ACTH，与甲状腺轴完全同构。<span class="marginnote"><strong>地塞米松抑制试验</strong>是内分泌诊断的经典工具：正常情况下外源性地塞米松会抑制 ACTH 与皮质醇，若皮质醇仍居高不下，提示分泌已不受负反馈约束（库欣综合征的病因定位）。用「激素能不能压下激素」来诊断，靠的正是 HPA 轴的负反馈。</span>

## 5 胰岛：血糖的精细天平

**胰岛**是胰腺内散在的内分泌细胞团，分泌**胰岛素**（B 细胞）与**胰高血糖素**（A 细胞），是血糖调节的两只主力手。

**胰岛素**是体内**唯一降低血糖的激素**：促进葡萄糖进入细胞氧化利用、促进糖原合成、抑制糖异生，同时促进蛋白质与脂肪合成——一言以蔽之，**储能的激素**。血糖升高直接刺激胰岛素分泌，胰岛素又把血糖压回正常——血糖与胰岛素构成一个负反馈环。<span class="marginnote">胰岛素分泌不只看血糖：<strong>氨基酸、胃肠激素（GIP 等）、迷走神经都能促进胰岛素分泌</strong>——「看到或闻到食物胰岛素就开始分泌」，正是《稳态与生理调节》里前馈调节的实例。前馈抢跑 + 负反馈纠偏，两种控制在这里合流。</span>

**胰高血糖素**与胰岛素作用相反：升高血糖（促糖原分解、糖异生）、促进脂肪分解。两激素在肝的「对决」决定血糖水平：**餐后胰岛素占优，饥饿时胰高血糖素占优**。糖尿病的基本病理就是胰岛素相对或绝对不足——1 型（自身免疫破坏 B 细胞，依赖胰岛素治疗）与 2 型（以胰岛素抵抗为主）。血糖调节的细节与糖尿病机制，将在《生物化学》与《病理生理学》中展开。

## 6 公式解析：内分泌的「联合判读」模型

内分泌主题没有典型的分式计算，这里用一条**判读模型**代替公式——**激素水平 + 上游激素水平**联合定位病变层级：

$$
\text{病变层级} = f(\text{激素水平},\ \text{上游激素水平})
$$

对这条式子做三步拆解：

- **第一步，先测激素本身**：如甲减时 T3/T4 低、甲亢时 T3/T4 高——激素水平只能告诉你「下游够不够」，分不清问题出在哪一层。
- **第二步，再看上游激素**：TSH 高而 T3/T4 低 → 垂体在「拼命催」而甲状腺不干活，问题在甲状腺（原发性甲减）；TSH 低而 T3/T4 低 → 甲状腺想干活却没人催，问题在垂体或下丘脑（继发性甲减）。
- **第三步，读直觉**：内分泌诊断像查「谁没干活」——下游缺货先看上游有没有催单。这套「激素 + 上游激素」的联合判读，对甲状腺、肾上腺、性腺三条轴通用，是内分泌诊断的标准思维框架。

## 8 小结

- 激素分**含氮激素**（膜受体、第二信使，快）与**类固醇激素**（核受体、调节转录，慢而持久）；甲状腺激素虽为胺类却走核受体。
- 激素作用四特征：信使作用、微量高效、信息传递（取决于靶细胞受体）、相互作用（协同/拮抗/**允许作用**）。
- 下丘脑-垂体系统是内分泌总指挥部：调节肽经垂体门脉管腺垂体，神经垂体只储存释放 ADH 与缩宫素。
- 三条「下丘脑-垂体-靶腺轴」（TSH/ACTH/FSH-LH）遵循同一负反馈逻辑：靶腺激素抑制上游，把激素水平稳定在窄区间。
- 甲状腺是代谢油门（碘泵聚碘、T3 活性强），甲亢/甲减对应代谢亢进/低下；肾上腺皮质管糖盐、髓质管应急；胰岛管血糖。
- 内分泌诊断用「激素 + 上游激素」联合判读定位病变层级，是甲状腺、肾上腺、性腺诊断通用的思维。
