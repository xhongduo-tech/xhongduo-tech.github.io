## 为什么从细胞开始

**生理学（physiology）**研究的是正常生命活动的规律，而一切生命活动的舞台都在**细胞**。心脏在跳、肺在呼吸、肾在滤过，说到底都是数万亿个细胞各自完成「物质转运、兴奋传导、信号传递」这三件事，再由器官把它们协调起来。<span class="marginnote">生理学与基础课的关系：解剖学问「长什么样」，生理学问「干什么、怎么干」；生物化学给出分子机制，生理学把它们组装成功能。到第五级《基础医学》里，你还会看到这些功能在病理状态下如何「出错」。</span>先学透细胞这一章，等于拿到了理解后面循环、呼吸、神经、内分泌全部章节的钥匙——**每一条全身性规律，都能回溯到某一种细胞膜的离子移动或某一种受体的激活**。

## 1 细胞膜的物质转运

细胞膜是磷脂双分子层夹着蛋白质的「流动镶嵌」结构。它既要拦住细胞内的成分不流失，又要允许营养物质与代谢废物进出，于是进化出四类转运方式。

**单纯扩散**：脂溶性小分子（$\ce{O2}$、$\ce{CO2}$、乙醇）顺浓度差直接穿过脂双层，不消耗能量、不需载体。<span class="marginnote">气体交换为什么在肺里能瞬间完成？因为 $\ce{O2}$、$\ce{CO2}$ 都是脂溶性分子，走的是最省事的单纯扩散。这条直觉后面学《呼吸生理》时会反复用到。</span>

**易化扩散**：水溶性物质靠膜蛋白帮助顺浓度梯度转运，也属被动转运。它分两种——经**通道**的（$\ce{Na+}$、$\ce{K+}$、$\ce{Ca^2+}$ 经离子通道）与经**载体**的（葡萄糖、氨基酸经葡萄糖转运体 GLUT）。<span class="marginnote">载体转运有三大特点：结构特异性（只能运特定物质）、饱和现象（载体数目有限）、竞争性抑制（结构相似的物质争抢同一载体）。这正是《生物化学》里酶动力学那套规律在膜转运上的翻版。</span>

**主动转运**：逆浓度梯度或电位梯度转运，必须耗能。**原发性主动转运**直接分解 ATP，最典型的是钠泵（$\ce{Na^+-K^+-ATPase}$），每分解一分子 ATP 泵出 3 个 $\ce{Na+}$、泵入 2 个 $\ce{K+}$，同时产生电学效应——这是后面静息电位最重要的能量来源。**继发性主动转运**不直接耗 ATP，而是利用钠泵建立的 $\ce{Na+}$ 浓度梯度作「蓄水池」，让 $\ce{Na+}$ 顺梯度回流时捎带转运其他物质，如肠上皮对葡萄糖的吸收、肾小管对葡萄糖的重吸收。<span class="marginnote">继发性主动转运是「借力」的典型：钠泵先把势能存进 $\ce{Na+}$ 浓度差里，其他转运体再花掉这笔势能。小肠与肾小管里的葡萄糖就是这样被「拉」进细胞的——详见《消化与吸收》《尿的生成与排出》。</span>

**膜泡转运**：大分子或颗粒物质靠膜泡整体吞入或吐出。**入胞**（胞吞）与**出胞**（胞吐），前者如吞噬细胞吞细菌，后者如神经末梢释放递质——乙酰胆碱就是被出胞吐出去的。

## 2 静息电位与它的来源

细胞安静时，膜内电位比膜外低，这个电位差叫**静息电位（resting potential）**。以神经细胞为例，静息电位约 $-70\ \mathrm{mV}$。

静息电位由三个因素共同决定：膜两侧**离子浓度差**、膜对离子的**通透性**、以及离子的**电荷**。安静时膜主要对 $\ce{K+}$ 通透（钾漏通道一直开着），于是：

细胞内 $\ce{K+}$ 浓度远高于细胞外，$\ce{K+}$ 顺着浓度差外流；
$\ce{K+}$ 带正电，外流使膜内变负、膜外变正，形成一个「内负外正」的电势差；
这个电场反过来阻止 $\ce{K+}$ 继续外流，当**浓度差驱动的外流动力**与**电场阻止的阻力**恰好抵消时，达到平衡。

**静息电位 ≈ $\ce{K+}$ 的平衡电位**，这就是它的本质。<span class="marginnote">为什么是「≈」不是「=」？因为安静时膜并非只对 $\ce{K+}$ 通透，还有少量 $\ce{Na+}$ 漏入，拉低了电位。用 Goldman 方程（见第 4 节公式解析）能精确算出这个修正量。改变膜外 $\ce{K+}$ 浓度，静息电位随之改变——这是临床上高钾血症影响心脏电活动的基础。</span>

## 3 动作电位：一次「全或无」的放电

给神经纤维一个足够强的刺激，膜电位会从 $-70\ \mathrm{mV}$ 迅速上升到 $+30\ \mathrm{mV}$ 再回落，这一整套「去极化—复极化」的电位波动叫**动作电位（action potential）**。它是细胞兴奋的可靠标志，也是神经传导信息的基本编码方式。

**去极化阶段（上升支）**：刺激使膜局部去极化到**阈电位**（约 $-55\ \mathrm{mV}$），膜上的**电压门控 $\ce{Na+}$ 通道**大量开放，$\ce{Na+}$ 顺浓度差与电位差双重驱动猛烈内流，膜内电位迅速变为正。这是「正反馈」过程——去极化越强，通道开得越多，内流越多，去极化更快。

**复极化阶段（下降支）**：$\ce{Na+}$ 通道失活关闭，**电压门控 $\ce{K+}$ 通道**开放，$\ce{K+}$ 外流把膜电位拉回静息水平。

**后电位**：膜电位还会在静息值附近有一个小幅波动（负后电位、正后电位），由 $\ce{Na+}$ 通道的残余与钠泵活动引起。

动作电位有三个重要特征：**全或无**（刺激达到阈强度就产生幅度固定的动作电位，达不到就完全不产生）、**不衰减传导**（传导中幅度不减，如同沿导火索的火线）、**不应期**（绝对不应期里任何刺激都无效，决定了放电频率的上限）。

**局部电位与动作电位的差别**是高频考点：局部电位幅度随刺激强度变化（等级性）、可总和、有衰减、以电紧张形式扩布；动作电位则全或无、不衰减、以局部电流方式跳跃传导。<span class="marginnote">有髓神经纤维的髓鞘是天然的「绝缘体」，动作电位只能在郎飞结之间「跳跃」传导，速度远快于无髓纤维。中枢里感觉与运动信号都要靠速度，髓鞘损伤（如多发性硬化）会让传导变慢甚至中断。</span>

## 4 公式解析：Nernst 方程

**某种离子在膜两侧的电化学平衡电位，用 Nernst 方程计算**——它是理解一切膜电位（静息、动作、突触后电位）的数学起点。

$$
E_X = \frac{RT}{zF} \ln \frac{[X]_o}{[X]_i}
$$

换成常用对数并在 $37^\circ\mathrm{C}$ 代入常数后：

$$
E_X \approx \frac{61}{z} \lg \frac{[X]_o}{[X]_i} \ \mathrm{(mV)}
$$

对这条式子做三步拆解：

- **第一步，认识每个符号**：$E_X$ 是离子 $X$ 的平衡电位；$z$ 是离子价数（$\ce{K+}$、$\ce{Na+}$ 为 $+1$）；$[X]_o$ 与 $[X]_i$ 分别是膜外、膜内的离子浓度；$61\ \mathrm{mV}$ 是把 $R$（气体常数）、$T$（开尔文温度）、$F$（法拉第常数）合并后的结果。
- **第二步，看分子分母怎么摆**：$[X]_o / [X]_i$ 是「外浓 ÷ 内浓」。对 $\ce{K+}$ 来说，膜内浓、膜外稀，比值小于 1，取对数得负数——所以 $\ce{K+}$ 平衡电位是负值（约 $-90\ \mathrm{mV}$）；对 $\ce{Na+}$ 正好相反，平衡电位是正值（约 $+60\ \mathrm{mV}$）。
- **第三步，读直觉**：平衡电位就是「浓度差想推动离子流动、电场想把它拉回去，两者打平」时的电位。电位越接近某离子的平衡电位，说明膜对该离子的通透性越高——静息时接近 $\ce{K+}$ 平衡电位，上升支峰值接近 $\ce{Na+}$ 平衡电位，这正是「静息靠钾、兴奋靠钠」的数学表达。

## 5 细胞的信号转导

细胞不仅要维持自身稳态，还要接收外界信号并作出反应。能跨膜传递信号的分子叫**信号分子**（配体），细胞接受信号的装置是**受体**。受体分四类：

- **离子通道型受体**：配体结合后通道直接开放，离子立即涌入，产生快速电信号——神经-肌肉接头处的 $\ce{N_2}$ 型乙酰胆碱受体即属此类，作用以毫秒计。
- **G 蛋白耦联受体**：配体激活受体 → 激活 G 蛋白 → 激活效应器酶（如腺苷酸环化酶）→ 产生第二信使（cAMP）→ 激活蛋白激酶 A → 磷酸化靶蛋白。作用时间以秒计，是数量最大的一类受体，肾上腺素、组胺、大多数激素都走这条路。
- **酶联型受体**：受体本身就带激酶活性，配体结合后受体二聚化并自身磷酸化，再激活下游信号级联。生长因子、胰岛素走这条路，与细胞增殖、分化密切相关。
- **核受体**：配体是脂溶性的（如类固醇激素），可直接穿过细胞膜进入胞内，与核内受体结合后调节**基因转录**。作用最慢，以分钟到小时计，但效应持久——这正是性激素「影响深远」的分子基础。

## 6 辨析｜易错点：被动转运 vs 主动转运

| 维度 | 被动转运（单纯扩散 + 易化扩散） | 主动转运（原发 + 继发） |
| --- | --- | --- |
| 方向 | 顺浓度梯度 / 电位梯度 | 逆浓度梯度 / 电位梯度 |
| 耗能 | 不耗能 | 耗能（直接 ATP 或借钠泵势能） |
| 载体/通道 | 需要载体或通道（单纯扩散两者皆无） | 需要载体蛋白 |
| 代表 | $\ce{O2}$ 扩散、葡萄糖经 GLUT 入胞 | 钠泵、肠上皮葡萄糖-钠同向转运 |
| 饱和性 | 通道无、载体有 | 有 |

**辨析｜易错点：** 判断一种转运是主动还是被动，唯一可靠的标准是**看它是否逆浓度/电位梯度**，而不是看它是否用了蛋白。葡萄糖经 GLUT 入胞是顺梯度，仍是被动转运；葡萄糖在肠上皮「从低浓度到高浓度」被吸收，才需要继发性主动转运。同理，「载体」不等于「主动」——易化扩散也靠载体。

## 7 术语速查表

| 术语 | 含义 |
| --- | --- |
| 单纯扩散 | 脂溶性小分子顺浓度差直接穿过脂双层，不需载体、不耗能 |
| 易化扩散 | 水溶性物质经通道或载体顺梯度转运，仍属被动转运 |
| 原发性主动转运 | 直接分解 ATP 逆梯度转运，典型是钠泵 |
| 继发性主动转运 | 不直接耗 ATP，借钠泵建立的钠梯度转运其他物质 |
| 静息电位 | 细胞安静时膜内负外正的电位差，约等于钾平衡电位 |
| 阈电位 | 触发动作电位的临界膜电位（约 $-55\ \mathrm{mV}$） |
| 动作电位 | 去极化-复极化的「全或无」电位波动，可远距离不衰减传导 |
| 绝对不应期 | 钠通道失活期，任何强度刺激都不能再引起兴奋 |
| 局部电位 | 等级性、可总和、衰减性扩布的电位，未达到阈值前不能传导 |
| 第二信使 | 胞内传递膜受体信号的分子（cAMP、IP3、DAG、$\ce{Ca^2+}$） |
| 受体 | 细胞上接受配体信号并启动效应的分子装置 |
| 兴奋性 | 细胞对刺激作出反应（产生动作电位）的能力 |

## 8 小结

- 细胞膜转运分**被动（单纯扩散、易化扩散）**与**主动（原发、继发）**两大类，另有膜泡转运处理大分子。
- **静息电位 ≈ $\ce{K+}$ 平衡电位**，由浓度差、通透性、电荷共同决定，用 Nernst 方程定量。
