## 为什么从几何表示开始

上一节我们学会了复数的四则运算：$z=a+bi$ 像多项式一样相加减、相乘除，一切有条有理。但代数运算再严密，也掩盖不了一个尴尬——**复数长得不像「数」，倒像「指令」**：$i^2=-1$ 到底在干什么？为什么两个复数相乘会冒出减号？这些问题在纯代数里只能「记住规则」，很难「看见原因」。

答案藏在高斯（Gauss）1799 年的一个念头里：**把复数画到平面上**。从此复数的每一个代数运算都有了几何画面——加是平移，乘是旋转，共轭是镜像。这个视角不是装饰：第七章的傅里叶变换把信号画成圆周上的旋转，大模型里的旋转式位置编码（RoPE）把 token 的相对位置画成旋转角度，底层全是「复数的几何」。所以这一节，我们给复数「安一个家」：**复平面、模与辐角**。

## 1 复平面：给复数安一个家

**核心概念：复平面（complex plane）**：取两条互相垂直的数轴——水平的**实轴（real axis）**与竖直的**虚轴（imaginary axis）**，交点称为**原点** $O$。复数 $z=a+bi$ 与平面上的点 $(a,b)$ 一一对应，也与「从原点指向该点」的向量一一对应。

$$z = a + bi \;\longleftrightarrow\; (a, b) \;\longleftrightarrow\; \overrightarrow{Oz}$$

**重点：复数、点、向量三者是同一个东西的三种写法。** 于是复数加法自然就是向量加法（平行四边形法则），这在上一节已经见过；但复数还比向量多出一样东西——**乘法**。向量之间通常没有乘法，复数却有一套「旋转 + 缩放」的乘法，这正是复数比二维向量更强大的原因。<span class="marginnote">阿尔冈（Jean-Robert Argand）在 1806 年独立发表了这幅图，因此复平面也叫<strong>阿尔冈图（Argand diagram）</strong>；高斯 1799 年在博士论文中已使用而未详述。1831 年高斯系统阐述后，「把复数画在平面上」才成为共识。</span>

## 2 模：复数的「长度」

**核心概念：模（modulus）**：复数 $z=a+bi$ 的模是向量 $\overrightarrow{Oz}$ 的长度，记作 $|z|$：

$$|z| = r = \sqrt{a^2 + b^2}$$

模是非负实数，满足 $|z| = 0 \iff z = 0$（只有零向量长度为零）。它最常用的三条性质：

- $|z| = |\bar{z}|$：共轭不改变长度；
- $|z_1 z_2| = |z_1|\,|z_2|$：乘积的模等于模的乘积（§1.3 用指数表示三行证完）；
- $|z_1 + z_2| \le |z_1| + |z_2|$：**三角不等式**，第 4 节专门解析。

**重点：$|z_1 - z_2|$ 就是复平面上两点之间的距离。** 因为

$$|z_1 - z_2| = \sqrt{(a_1 - a_2)^2 + (b_1 - b_2)^2}$$

![复平面上两点 z1 与 z2 的距离 |z1−z2|：实部差与虚部差构成直角三角形，距离即斜边](/images/complex-analysis/complex-plane-modulus-argument-1.svg)

这正是第一级《微积分》里两点间距离公式的复数写法。<span class="marginnote">把「差的模」读作「距离」，是复数几何里最划算的一次翻译：不等式、圆、中点、三角形……平面几何的一切语言都能用 <code>|z - w|</code> 重新书写。之后第三、四章判断级数与积分是否收敛时，$|z|$ 就是「到原点的距离」。</span>

## 3 辐角：复数的「方向」

向量 $\overrightarrow{Oz}$ 不仅有长度，还有方向。

**核心概念：辐角（argument）**：向量 $\overrightarrow{Oz}$ 与实轴正方向的夹角称为复数 $z$ 的辐角，记作 $\mathrm{Arg}\,z$。因为转一整圈方向不变，辐角是**多值**的：

$$\mathrm{Arg}\,z = \arg z + 2k\pi \qquad (k \in \mathbb{Z})$$

其中 $\arg z$ 称为**主辐角（principal argument）**，本专题约定取在 $(-\pi, \pi]$ 内。

**重点：辐角的多值性，是复数与实数最大的气质差异。** 实数的「方向」只有两个（正、负），复数的方向却有无穷多个相差 $2\pi$ 的取值。这个「缠了一圈又一圈」的结构，正是第二章对数函数与根式函数成为多值函数的根源。

由这幅图还能立刻读出共轭的几何意义：

**重点：共轭就是关于实轴的镜像。** 点 $z=a+bi$ 与 $\bar{z}=a-bi$ 关于实轴上下对称，于是 $|\bar{z}| = |z|$，$\arg\bar{z} = -\arg z$。

**辨析｜易错点：$z = 0$ 没有辐角。** 零向量的方向没有定义，所以「$0$ 的辐角」这个说法不成立。很多同学想当然给 $0$ 赋一个辐角，这在后面讨论多值函数时会引出假根。写「辐角为 $\theta$」时，若未加说明，默认是某一支（通常是主辐角），全体辐角必须补上 $2k\pi$。

**例题：从代数式读出模与辐角。** 取三个复数，练习「长度与方向」的拆解：

- $z_1 = 1 + i$：$r = \sqrt{2}$，点在第一象限，$\arg z_1 = \frac{\pi}{4}$；
- $z_2 = -1 + i$：$r = \sqrt{2}$，点在第二象限，$\arg z_2 = \frac{3\pi}{4}$（不是 $-\frac{\pi}{4}$）；
- $z_3 = -2$：$r = 2$，点在负实轴上，主辐角取 $\arg z_3 = \pi$（符合 $(-\pi, \pi]$ 约定）。

同一个 $r = \sqrt{2}$，$z_1$ 与 $z_2$ 的辐角却一正一负、相差 $\frac{\pi}{2}$。长度与方向是两个相互独立的数据——这正是下一节「用长度 + 角度写复数」的出发点。

## 4 公式解析：三角不等式与两点距离

模的性质里最有用的，是**三角不等式**。它说：三角形两边之和大于第三边，在复数里的写法是

$$|z_1 + z_2| \le |z_1| + |z_2|$$

我们分四步证明它，顺便复习共轭的运算。

- **第一步，把模的平方展开。** 由 $|w|^2 = w\bar{w}$，有

$$|z_1 + z_2|^2 = (z_1 + z_2)(\bar{z}_1 + \bar{z}_2)$$

- **第二步，展开并用共轭的穿透性。** $\overline{z_1 + z_2} = \bar{z}_1 + \bar{z}_2$，展开得

$$|z_1 + z_2|^2 = |z_1|^2 + |z_2|^2 + z_1\bar{z}_2 + \bar{z}_1 z_2$$

- **第三步，认出实部。** 中间两项互为共轭，加起来是实部：$z_1\bar{z}_2 + \bar{z}_1 z_2 = 2\,\mathrm{Re}(z_1 \bar{z}_2)$。而任何复数的实部不超过它的模：$\mathrm{Re}(w) \le |w|$，所以

$$|z_1 + z_2|^2 \le |z_1|^2 + |z_2|^2 + 2|z_1 \bar{z}_2| = |z_1|^2 + |z_2|^2 + 2|z_1|\,|z_2| = (|z_1| + |z_2|)^2$$

- **第四步，开方。** 两边都是非负数，开方即得 $|z_1 + z_2| \le |z_1| + |z_2|$。

**几何直觉：** 把 $z_1$、$z_2$ 看成两条向量，$z_1 + z_2$ 是它们的合向量。沿「先 $z_1$ 再 $z_2$」的折线走到终点，路程是 $|z_1|+|z_2|$；从起点直接画直线过去，路程是 $|z_1+z_2|$。**折线不会比直线短**——这就是名字「三角不等式」的来源。把 $z_2$ 换成 $-z_2$，还得到它的孪生兄弟 $|z_1 - z_2| \ge \bigl||z_1| - |z_2|\bigr|$。

距离公式 $|z_1 - z_2| = \sqrt{(a_1-a_2)^2 + (b_1-b_2)^2}$ 同样可以拆成三步看：先分别读出两点的实部虚部，再取差值平方相加，最后开方。它把「两点的远近」压缩成一个非负实数，是后面「点列收敛」「曲线长度」一切度量工作的起点。

## 5 复平面上的曲线：用模与辐角写方程

把「差的模是距离」用起来，就能用复数语言描写平面上的几何对象。设 $z_0$、$z_1$、$z_2$ 是给定复数，$r>0$ 是常数：

- **圆**：$|z - z_0| = r$ 表示到 $z_0$ 距离为 $r$ 的点的集合——以 $z_0$ 为圆心、$r$ 为半径的圆。
- **中垂线**：$|z - z_1| = |z - z_2|$ 表示到 $z_1$ 与 $z_2$ 距离相等的点——线段 $z_1 z_2$ 的**垂直平分线**。
- **直线**：$\mathrm{Re}(z) = c$ 是竖直线 $x = c$，$\mathrm{Im}(z) = c$ 是水平线 $y = c$；更一般地 $\arg z = \alpha$ 表示从原点出发、倾角为 $\alpha$ 的**射线**。

**辨析｜易错点：$\arg z = \alpha$ 是射线，不是整条直线。** 直线有两个方向，射线只有一个。$\arg z$ 固定意味着「方向固定」，但 $|z|$ 可以在 $(0, +\infty)$ 内任意取，所以集合是「从原点出发的一条半线」——原点本身因为辐角无定义而被排除在外。

更一般地，两点到某点的距离关系还能勾出二次曲线。例如

$$|z - z_1| + |z - z_2| = 2a \qquad \left(a > \frac{|z_1 - z_2|}{2}\right)$$

表示到两定点 $z_1, z_2$ 的距离之和为常数的点的集合——正是以 $z_1, z_2$ 为焦点的**椭圆**。到两点距离之差为常数，则对应**双曲线**。<span class="marginnote">「到两定点距离之和为常数」的几何定义在第一级《解析几何》里是用 $\sqrt{(x-x_1)^2+y^2} + \cdots$ 写的，换成复数 $|z-z_1|+|z-z_2|$ 后，整个定义被压缩成一个式子——这是复数「差的模即距离」这个翻译的又一次胜利。</span>

这三种方程的威力在于：它们把「几何图形」翻译成了「复数方程」，为第六章《共形映射》铺好了语言——那里我们将研究什么样的复数映射把圆变成圆、把直线变成圆。

## 6 小结

- **复平面**：$z = a+bi \leftrightarrow$ 点 $(a,b) \leftrightarrow$ 向量 $\overrightarrow{Oz}$，三者一一对应。
- **模**：$|z| = \sqrt{a^2+b^2}$ 是向量长度；$|z_1 - z_2|$ 是两点距离；$|z_1 z_2| = |z_1|\,|z_2|$。
- **辐角**：$\mathrm{Arg}\,z = \arg z + 2k\pi$，**多值**；主辐角 $\arg z \in (-\pi, \pi]$；$z = 0$ 没有辐角。
- **三角不等式**：$|z_1 + z_2| \le |z_1| + |z_2|$，由共轭展开 + 实部放缩四步证得。
- **共轭是镜像**：$z$ 与 $\bar z$ 关于实轴对称，$|\bar z| = |z|$，$\arg\bar z = -\arg z$。
- **曲线语言**：$|z - z_0| = r$ 是圆，$|z - z_1| = |z - z_2|$ 是中垂线，$\arg z = \alpha$ 是射线。

在下一节，我们不再用 $a+bi$ 而改用「长度 + 角度」来写复数，得到**三角表示与指数表示**——欧拉公式会把 $e^{i\theta}$ 与 $\cos\theta$、$\sin\theta$ 连在一起，让「乘法就是旋转」从一句口号变成三行公式。
