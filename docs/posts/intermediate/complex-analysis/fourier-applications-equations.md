## 为什么「取变换」能解方程

前面积累了三大工具：微分性质（$f'\leftrightarrow i\omega F$）、卷积定理（$f*g\leftrightarrow FG$）、帕塞瓦尔（能量守恒）。现在把它们组合成**变换求解法**：对含微积分运算的方程两边取傅里叶变换，**微分变乘法、积分变除法、卷积变乘积**——方程从「微积分方程」降维成「代数方程」，解出频域解 $U(\omega)$，再逆变换回时域。这一节用三道典型题目演示完整流程。<span class="marginnote">变换求解法的适用边界：被积函数须绝对可积（或有广义变换）、解须在 $t\to\pm\infty$ 时衰减（否则逆变换不收敛）。傅里叶变换适合「全实轴上的稳态/无界问题」；带初始条件的因果问题更适合第八章拉普拉斯变换——那是「初值问题的默认工具」。</span>

## 1 方法总览：变换求解四步

**变换求解法（frequency-domain method）的标准流程：**

1. **取变换**：对方程两边取傅里叶变换，把微分 $d^n/dt^n$ 换成 $(i\omega)^n$，卷积换成乘积。
2. **解代数方程**：在频域解出 $U(\omega)$（通常含参数 $\omega$）。
3. **逆变换**：对 $U(\omega)$ 取傅里叶逆变换，得 $u(t)$。
4. **核对**：验证初始条件/边界条件（若需要）。

**重点：微分性质的威力。** $u''(t)\leftrightarrow(i\omega)^2U(\omega)=-\omega^2U(\omega)$——**二阶导数变成 $-\omega^2$ 乘频谱**，常系数线性微分方程变成多项式方程。这就是「微分方程化代数方程」的精确含义。<span class="marginnote">「求导 = 乘 $i\omega$」把「解微分方程」变成「解多项式方程」——这是傅里叶变换最伟大的工程应用。电路瞬态分析、机械振动、信号去噪，全都是「变换 → 代数 → 逆变换」的模板。</span>

## 2 例一：热传导方程（无界杆）

**例：** 求解 $u_t = a^2 u_{xx}$（$-\infty<x<\infty$，$t>0$），初值 $u(x,0)=f(x)$。

**第一步，对 $x$ 取傅里叶变换。** 设 $U(\omega,t)=\mathcal{F}_x[u(x,t)]$，则 $u_{xx}\leftrightarrow(i\omega)^2U=-\omega^2U$，$u_t$ 只对 $t$ 求导，变换后仍是 $\partial_t U$：

$$\frac{\partial U}{\partial t} = -a^2\omega^2 U$$

**第二步，这是关于 $t$ 的常微分方程**（$\omega$ 是参数）。解之：

$$U(\omega,t) = F(\omega)\,e^{-a^2\omega^2 t}$$

其中 $F(\omega)=\mathcal{F}[f]$，由初值 $U(\omega,0)=F(\omega)$ 定常数。

**第三步，逆变换。** 关键：$e^{-a^2\omega^2 t}$ 是高斯型，其逆变换是高斯核 $\frac{1}{2a\sqrt{\pi t}}e^{-x^2/(4a^2t)}$。由卷积定理：

$$u(x,t) = f * \left(\frac{1}{2a\sqrt{\pi t}}e^{-x^2/(4a^2t)}\right) = \frac{1}{2a\sqrt{\pi t}}\int_{-\infty}^{\infty}f(\xi)e^{-\frac{(x-\xi)^2}{4a^2t}}d\xi$$

**这就是热传导方程的泊松公式（高斯核卷积初值）。** 一个「变换 → 代数 → 高斯逆变换 → 卷积定理」的完整示范。<span class="marginnote">高斯核 $G_t(x)=\frac{1}{2a\sqrt{\pi t}}e^{-x^2/(4a^2t)}$ 是热传导方程的基本解：初值越尖锐（越像 $\delta$），解的扩散越接近高斯。$t\to0^+$ 时 $G_t\to\delta$——「$\delta$ 是热传导的初值极限」在分布意义下成立，与第五章/第七章的 $\delta$ 观呼应。</span>

## 3 例二：含卷积的积分方程

**例：** 求解 $\int_{-\infty}^{\infty}f(\tau)h(t-\tau)d\tau = g(t)$，其中 $h$ 已知，求 $f$。

**这是卷积方程 $f*h=g$**。取傅里叶变换，卷积定理给出：

$$F(\omega)H(\omega) = G(\omega) \quad\Longrightarrow\quad F(\omega)=\frac{G(\omega)}{H(\omega)}$$

逆变换：$f(t)=\mathcal{F}^{-1}\left[\frac{G(\omega)}{H(\omega)}\right]$。

**重点：卷积方程在频域变成「除法」。** 未知函数 $f$ 从「卷积积分里」被解出来，只需频谱相除再逆变换。**这是「解卷积」（deconvolution）的基本原理**——图像去模糊、信号反卷积都是这个框架。<span class="marginnote">「解卷积」在工程里是双刃剑：频域相除 $\frac{G}{H}$ 在 $H(\omega)$ 接近零处会放大噪声（小除数放大误差）。所以实际的反卷积要正则化（如维纳滤波）——噪声放大是频域除法固有的病态。这解释了为什么「反卷积」需要专门算法。</span>

## 4 例三：RLC 电路的频域分析

**例：** 一个 RLC 串联电路，输入电压 $v_i(t)$，求电流 $i(t)$。电路方程：

$$L\frac{di}{dt} + Ri + \frac{1}{C}\int_{-\infty}^{t}i(\tau)d\tau = v_i(t)$$

**第一步，取傅里叶变换。** 用微分性质与积分性质（$\int_{-\infty}^t i\longleftrightarrow\frac{I(\omega)}{i\omega}$，忽略直流项）：

$$\left(i\omega L + R + \frac{1}{i\omega C}\right)I(\omega) = V_i(\omega)$$

**第二步，解出电流频谱。** $I(\omega)=\frac{V_i(\omega)}{Z(\omega)}$，其中

$$Z(\omega) = R + i\omega L + \frac{1}{i\omega C} = R + i\left(\omega L - \frac{1}{\omega C}\right)$$

**$Z(\omega)$ 是电路的复阻抗**——电阻 $R$、感抗 $\omega L$、容抗 $\frac1{\omega C}$ 在频域里自然合体。

**第三步，逆变换。** $i(t)=\mathcal{F}^{-1}[V_i/Z]$。**整个电路分析变成「频谱相除」**：给定输入频谱，除以阻抗得电流频谱。<span class="marginnote">电路分析是傅里叶变换最经典的工程落地：时域微分方程（难）→ 频域代数方程（易）→ 阻抗法。每个元件在频域都是一次「乘法因子」：电阻 $R$、电感 $i\omega L$、电容 $\frac1{i\omega C}$。这比逐个解微分方程不知道快多少倍。</span>

## 5 公式解析：RLC 方程的频域化

把 RLC 方程的变换过程拆成三步，展示「微积分运算 → 代数因子」的映射：

$$L\frac{di}{dt} + Ri + \frac{1}{C}\int_{-\infty}^t i\,d\tau = v_i(t)$$

$$\Big\downarrow\ \mathcal{F}$$

$$\underbrace{(i\omega L)}_{\text{电感}}I + \underbrace{R}_{\text{电阻}}I + \underbrace{\frac{1}{i\omega C}}_{\text{电容}}I = V_i$$

- **第一步，逐项变换。** 每一项都用对应的性质：$L i'\leftrightarrow L(i\omega)I$（微分），$Ri\leftrightarrow RI$（线性），$\frac1C\int i\leftrightarrow\frac1C\frac{I}{i\omega}$（积分）。
- **第二步，提公因子。** 三项都有 $I(\omega)$，提出得 $(i\omega L+R+\frac1{i\omega C})I=V_i$——**三元件「串联」在频域就是三项相加**，这正是电路串并联的频域语言。
- **第三步，读出阻抗。** $Z=i\omega L+R+\frac1{i\omega C}$，$I=V/Z$。**解方程变除法。**

**直觉：** 傅里叶变换把「电路的时间演化」换成「频率响应」。**每个元件在频域都是一张「频率-阻抗」标签**，串联相加、并联取倒数——电路设计的全部规则在频域里重新长出来。

## 6 补充：变换求解法的适用边界与反例

「取变换就能解」不是万能的——搞清楚边界，才能选对工具。

**适用边界：**
1. **线性常系数方程**：微分性质把导数变成 $s$（或 $i\omega$）的幂，才成代数方程。**变系数方程（系数含 $t$）没有这么漂亮的性质。**
2. **零初值或全实轴问题**（傅里叶）；**因果初值问题**（拉普拉斯）。
3. **逆变换可求**：$U(\omega)$ 或 $U(s)$ 须能逆变换（有理函数最好）。

**反例一（变系数）：** 方程 $ty''+y'=0$。取傅里叶变换，$t$ 与 $y''$ 的乘积变成「频域导数」（$tf(t)\leftrightarrow iF'(\omega)$）——**方程变成含 $Y'$ 的方程，仍是「方程」，只是换了变量。** 变换法对变系数不「降维」。

**反例二（非线性）：** $y''+\sin y=0$。$\sin y$ 没有简单的变换表达，变换法失效。**非线性问题基本排除变换法。**

**反例三（傅里叶的绝对可积限制）：** $y'+y=1$（常数输入）。$1$ 不绝对可积，傅里叶变换需广义形式；用拉普拉斯则 $1\leftrightarrow\frac1s$ 干净利落。**「常数/阶跃输入」用拉普拉斯比傅里叶顺手。**

**重点：工具选择的决策——「稳态 + 频谱」用傅里叶，「初值 + 瞬态」用拉普拉斯，「变系数/非线性」绕开变换法。** 第八章的拉普拉斯在初值问题上全面接棒。

**例（为何拉普拉斯更配初值）：** $y'+y=0$，$y(0)=2$。傅里叶变换默认零初值（或不含初值项），需手工处理；拉普拉斯 $sY-2+Y=0\Rightarrow Y=\frac2{s+1}\Rightarrow y=2e^{-t}$——**初值直接进公式。** 这就是「瞬态用拉普拉斯」的原因。

**辨析｜易错点：变换法给的解要验证。** 逆变换结果代入原方程与初值核对——**尤其在「可积性存疑」时，验证是必须的收尾。**

## 7 小结

- **变换求解四步**：取变换 → 解代数方程 → 逆变换 → 核对。
- **热传导方程**：$u_t=a^2u_{xx}$ 的解是「高斯核卷积初值」（泊松公式）。
- **卷积方程**：$f*h=g\Rightarrow F=G/H$，反卷积在频域是除法（噪声放大需正则化）。
- **RLC 电路**：时域微分方程变频域代数方程 $I=V/Z$，阻抗法诞生。
- **适用边界**：全实轴问题用傅里叶；带初值的因果问题留给第八章拉普拉斯。
