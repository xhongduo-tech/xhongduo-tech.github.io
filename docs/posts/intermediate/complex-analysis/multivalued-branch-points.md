## 为什么「多值」值得单独讲一节

上一节我们见过 $z^{1/2}$ 有两个值、$\mathrm{Ln}\,z$ 有无穷多个值。有人会想：多值不过是「多几条分支」，挑一条不就完了？但事情没这么简单——**多值函数绕某个点走一圈，函数值会从一个分支溜到另一个分支**。这个「绕一圈就变卦」的点，就是**支点（branch point）**。支点不是普通的奇点，它是多值性的几何源头。理解支点，等于拿到了黎曼曲面、解析延拓乃至现代复分析大门的钥匙。<span class="marginnote">「支点」的英文 branch point 直译就是「分支点」：它是各分支相互纠缠、无法干净分离的地方。$\mathrm{Ln}\,z$ 与 $\sqrt{z}$ 的支点是 $z=0$ 与 $z=\infty$，两者都是。</span>

## 1 从实验观察：绕原点一圈会发生什么

先做一个思想实验。取 $f(z)=\sqrt{z}$，从 $z=1$ 出发（此时 $\sqrt{1}=1$），沿以原点为圆心的单位圆周走一圈：

走到 $z = e^{i\pi/2}=i$ 时，$f(z) = e^{i\pi/4}$，是主分支的值。
走到 $z = e^{i\pi}=-1$ 时，$f(z)=e^{i\pi/2}=i$。
走到 $z = e^{i3\pi/2}=-i$ 时，$f(z)=e^{i3\pi/4}$。
走回 $z=1$ 时，辐角累计增加了 $2\pi$，而 $f(z) = e^{i(0+2\pi)/2} = e^{i\pi} = -1$。

**你回到了出发点，但 $\sqrt{z}$ 的值从 $1$ 变成了 $-1$！**<span class="marginnote">这个实验是复分析最著名的「脑筋急转弯」：沿闭环走一圈，单值函数的直觉彻底失效。$\sqrt{z}$ 的值翻了一倍符号，$\mathrm{Ln}\,z$ 的值增加了 $2\pi i$——多值函数正是这样「绕圈换层」的。</span>

绕第二圈，$\sqrt{z}$ 从 $-1$ 变回 $1$——所以绕两圈回到原分支。更一般地：**绕支点 $n$ 圈，$z^{1/n}$ 的值以 $n$ 为周期循环；绕任意圈，$\mathrm{Ln}\,z$ 的值永不相同。**

## 2 支点与支割线：把多值函数「剪开」

**核心概念：支点（branch point）**：若点 $z_0$ 的一个**任意小邻域**内，沿一条绕 $z_0$ 一周的闭合曲线走一圈，多值函数的某个分支变成另一个分支，则称 $z_0$ 为**支点**。

支点必须是「绕任意小圈都会变分支」的点——这是它与普通奇点的根本区别。$f(z)=\frac{1}{z}$ 在 $z=0$ 是极点，但绕 $z=0$ 一圈 $\frac{1}{z}$ 的值完全不变，所以 $z=0$ 不是支点。$z^{1/2}$ 与 $\mathrm{Ln}\,z$ 的支点是 **$z=0$ 与 $z=\infty$**。

**核心概念：支割线（branch cut）**：从支点出发，画一条把平面「剪开」的线（通常取负实轴或正实轴），规定**不允许跨越它**。剪开之后，辐角被限制在一个长度为 $2\pi$ 的区间内，多值函数在每个「剪开的平面」上变成单值解析函数，这个单值函数称为**一个分支（branch）**。

**重点：支割线不是天然的，而是人为选择的。** 你选主辐角 $(-\pi,\pi]$，割线就沿负实轴；选 $[0,2\pi)$，割线就沿正实轴。割线位置变了，分支定义也随之改变——但「剪开后单值化」的机制完全相同。<span class="marginnote">把「剪开的平面」沿割线粘合，会得到一个双层的曲面（对 $\sqrt{z}$）或无穷层的螺旋曲面（对 $\mathrm{Ln}\,z$）——这就是<strong>黎曼曲面（Riemann surface）</strong>。在黎曼曲面上，多值函数变成单值函数，所有分支按「绕支点换层」的规则连成一片。</span>

## 3 公式解析：$\mathrm{Ln}\,z$ 的支点为什么是 0 与 ∞

设 $w = \mathrm{Ln}\,z$，沿圆 $z = re^{i\theta}$（$r$ 固定，$\theta$ 从 0 到 $2\pi$）走一圈，$w$ 的变化是

$$\Delta w = \mathrm{Ln}(re^{i(\theta+2\pi)}) - \mathrm{Ln}(re^{i\theta}) = i\cdot 2\pi$$

分三步读这个式子：

- **第一步，拆开实部虚部。** $\mathrm{Ln}\,z = \ln r + i\theta$，实部 $\ln r$ 只依赖 $r$，绕圈不变；虚部 $\theta$ 随辐角增加 $2\pi$ 而增加 $2\pi$。

- **第二步，识别变化量。** 绕一圈虚部净增 $2\pi$，即 $w \to w + 2\pi i$——**换到了相邻的分支**。半径 $r$ 不管取多小，只要圆周绕原点一圈，这个换层必定发生。所以 $z=0$ 是支点。

- **第三步，为什么 $z=\infty$ 也是支点。** 在扩大的复平面（复球面）上，「绕 $z=\infty$ 一圈」就是取一条足够大的圆周绕一圈。同样地，虚部净增 $2\pi$，换层照旧。因此 $\mathrm{Ln}\,z$ 在复球面上有两个支点：$0$ 与 $\infty$。一条支割线（比如负实轴）正好把这两个支点**连通**起来，剪开后多值函数单值化。

**类比直觉：** 支点就像螺旋楼梯的轴心——绕轴走一圈，你上了一层楼；割线就是那扇「禁止跨越」的门，不让你在楼梯上抄近道换层。

## 4 单值分支的解析性：在割开的平面上验明

选主辐角 $\arg z\in(-\pi,\pi)$，在**割掉负实轴的平面** $D$ 上定义 $\mathrm{Log}\,z$。它在这个区域内单值、连续，且由上一节极坐标 C-R 方程的验证，$\mathrm{Log}\,z$ 在 $D$ 内解析，$(\mathrm{Log}\,z)'=\frac{1}{z}$。

同理，对 $\sqrt{z}=e^{\frac{1}{2}\mathrm{Log}\,z}$，它在同一割开平面上解析，且

$$(\sqrt{z})' = e^{\frac{1}{2}\mathrm{Log}\,z}\cdot\frac{1}{2z} = \frac{1}{2\sqrt{z}}$$

与实函数的 $\left(\sqrt{x}\right)'=\frac{1}{2\sqrt{x}}$ 形式一致。<span class="marginnote">注意导数公式里的 $\sqrt{z}$ 应取与函数相同的分支——多值函数求导后仍然是同一条分支上的多值函数，分支选择要全程一致，否则差一个符号。</span>

**辨析｜易错点：支点与极点、本性奇点完全不同。** 极点（如 $\frac{1}{z}$ 的 $z=0$）处 $f\to\infty$；本性奇点（如 $e^{1/z}$ 的 $z=0$）处极限不存在。而支点处**函数本身有定义（单分支意义下）但不绕圈则无法单值化**。三者的判别方式也各异：绕支点一圈函数换分支，绕极点一圈函数回到自身但趋近无穷，绕本性奇点一圈函数值游荡于整个平面。第五章我们将系统给奇点分类，支点自成一类。

## 5 补充：根式函数与对数函数的支点对比

多值函数的支点结构，可以从「绕圈换层」的周期数来理解。把 $\sqrt{z}$ 与 $\mathrm{Ln}\,z$ 并排对比：

| 函数 | 支点 | 绕一圈的分支变化 | 绕 $n$ 圈 | 分支数 |
| --- | --- | --- | --- | --- |
| $z^{1/2}$ | $0,\infty$ | $\sqrt{z}\to-\sqrt{z}$ | 交替（2 为周期） | 2 |
| $z^{1/n}$ | $0,\infty$ | $\sqrt[n]{z}\to e^{2\pi i/n}\sqrt[n]{z}$ | 以 $n$ 为周期 | $n$ |
| $\mathrm{Ln}\,z$ | $0,\infty$ | $\mathrm{Ln}\,z\to\mathrm{Ln}\,z+2\pi i$ | 永不重复 | $\infty$ |

这张表揭示一条规律：**有限值函数（$z^{1/n}$）的分支数有限，多值性「温和」；对数函数分支无穷，多值性「剧烈」。** 根式绕 $n$ 圈回到原分支（像绕着楼梯转了 $n$ 层回到出发点），对数每圈都上一层新楼（永不回到原层）。

**实践中的判别技巧：** 给定一个函数，如何快速找出支点？

- **第一步，找「多值因子」。** 只关心含 $z^{1/n}$、$\mathrm{Ln}$、$\mathrm{Arg}$ 等结构的因子——它们携带多值性。整函数与单值有理函数（如 $e^z$、$z^2$）不产生支点。
- **第二步，找这些因子的「孤立点」。** $z^{1/n}$ 的支点是 $z=0$ 与 $z=\infty$；$\mathrm{Ln}\,z$ 同理。复合函数 $f(g(z))$ 的支点还包括使 $g(z)$ 取 0 或 $\infty$ 的点。
- **第三步，验证。** 画一条绕候选点的小圈，看函数值是否换分支——换则支点成立。

**例：** $f(z)=\sqrt{z-1}$。它等于 $z-1$ 的 $1/2$ 次幂，支点出现在 $z-1=0$（即 $z=1$）与 $z=\infty$。所以 $z=1$ 是支点——绕 $z=1$ 一圈，$\sqrt{z-1}$ 改变符号。**支点可以不在原点，位置由「内部为零的点」决定。**

**辨析｜易错点：$\mathrm{Ln}(z^2)$ 与 $2\mathrm{Ln}\,z$ 的支点不同。** $\mathrm{Ln}(z^2)$ 的支点在 $z=0$（$z^2=0$）——但绕 $z=0$ 一圈，$\mathrm{Ln}(z^2)$ 增加 $4\pi i$（$z^2$ 绕两圈），每半圈就换一次分支，实际上 $z=0$ 仍是唯一支点。而 $2\mathrm{Ln}\,z$ 绕一圈增加 $2\pi i$。**复合会改变「绕一圈的分支步长」但不改变支点位置**——这是多值函数复合时最需要小心的代数陷阱。

## 6 补充：多值函数与单值化的完整流程

把「处理多值函数」的工程化流程总结成四步，配上典型例子。

**处理多值函数的四步：**
1. **找出支点**：多值因子的孤立零点/无穷远点。
2. **选择割线**：连接支点的「禁止跨越线」（通常沿负实轴或正实轴）。
3. **固定分支**：在割开的平面上选主值（如 $\arg z\in(-\pi,\pi]$）。
4. **单值化**：在多值函数名前冠以「主值」记号（如 $\mathrm{Log}$、$\sqrt{}$），在割开的平面内它单值解析。

**例（完整走一遍）：** 处理 $f(z)=\mathrm{Log}(z^2-1)$。

- **支点：** $z^2-1=0$ 即 $z=\pm1$（以及 $\infty$）。绕 $z=1$ 一圈，$z^2-1$ 的辐角变化 $2\pi$（$z-1$ 贡献一圈，$z+1$ 在 $1$ 附近变化小），$\mathrm{Log}$ 虚部增加 $2\pi i$——$z=1$ 是支点，同理 $z=-1$。
- **割线：** 取连接 $z=-1$ 到 $z=1$ 的线段（实轴上 $[-1,1]$）为割线。
- **分支：** 在割掉 $[-1,1]$ 的平面上取主值分支，$f$ 单值解析。
- **验证：** 割线把平面剪开，绕任一「洞」（$\pm1$ 附近）不再能转整圈，多值性被隔离。

**重点：割线必须「连通所有支点」。** 割掉 $[-1,1]$ 连接了两个支点，绕单个支点的闭路无法在割开平面上闭合——多值性被割线「锁死」。**割线的选择不唯一（也可向无穷延伸），但必须让支点无法被「干净地绕过」。**

**例（数值体验多值）：** $\sqrt{4}$ 主值 $=2$，另一分支 $=-2$；$\mathrm{Log}(-1)=i\pi$（主值），多值形式 $\mathrm{Ln}(-1)=i\pi+2k\pi i=(2k+1)\pi i$。**「一个数多个值」在取定分支后收敛为「一个数一个值」。**

**辨析｜易错点：割线不是「函数无定义」的线。** 割线上函数仍有定义（取该侧极限），只是「跨越」会让分支改变。**割线是「禁止跨越」而非「禁地」——理解这个区别，才能正确沿割线积分。**

## 7 小结

- **绕圈实验**：绕原点一圈，$\sqrt{z}$ 从 $1$ 变 $-1$、$\mathrm{Ln}\,z$ 增加 $2\pi i$——多值函数的「换层」由此可见。
- **支点**：绕任意小圈都会使函数换分支的点。$\sqrt{z}$、$\mathrm{Ln}\,z$ 的支点是 $0$ 与 $\infty$。
- **支割线**：人为选择的「禁止跨越」线，剪开后多值函数在每个分支上单值解析；割线位置随辐角选择而变。
- **黎曼曲面**：把分支按绕圈换层的规则粘起来，多值函数在曲面上成为单值函数。
- 单值分支求导照常：$(\sqrt{z})'=\frac{1}{2\sqrt{z}}$，$(\mathrm{Log}\,z)'=\frac{1}{z}$，但分支选择必须全程一致。

在下一节，我们将进入解析函数与物理的隐秘通道：**调和函数**。C-R 方程迫使解析函数的实部虚部都满足拉普拉斯方程 $\Delta u=0$——这个方程描述稳态的温度场、引力位势与静电场。解析函数于是成了调和函数的「镜像车间」。
