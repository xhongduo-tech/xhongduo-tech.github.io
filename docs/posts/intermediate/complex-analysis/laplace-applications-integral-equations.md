## 为什么积分方程也能「取变换就解」

微分方程取变换变代数方程，积分方程同样——只要积分是卷积型 $\int_0^t f(\tau)g(t-\tau)d\tau$，卷积定理就把它变成 $s$ 域乘积，未知函数从「积分号里」被解出来。而**线性系统分析**则把「传递函数 $H(s)$」用到底：系统的稳定性、冲激响应、阶跃响应、频率响应，全部由 $H(s)$ 的极零点读出。本节是第八章收官，也是整个专题的收官——复变函数论与积分变换在这里合流成完整的工程数学语言。<span class="marginnote">「卷积型积分方程」和「LTI 系统」是同一个数学对象的两张脸：方程 $y=f*h$ 里的 $h$ 就是系统的冲激响应。解积分方程 = 反卷积 = 系统反演——$s$ 域里它们统统是一次除法 $Y/F$ 或 $Y/H$。</span>

## 1 卷积型积分方程

**核心概念：Volterra 积分方程**：未知函数 $y(t)$ 出现在卷积积分里的方程：

$$y(t) = f(t) + \lambda\int_0^{t}y(\tau)g(t-\tau)\,d\tau$$

**这是第二类 Volterra 方程**——$y$ 在等式两边都出现。取拉普拉斯变换，卷积定理 $\int_0^t y*g\leftrightarrow Y(s)G(s)$：

$$Y(s) = F(s) + \lambda Y(s)G(s)$$

**解出：** $Y(s)\left[1-\lambda G(s)\right]=F(s)$，故

$$Y(s) = \frac{F(s)}{1-\lambda G(s)}$$

**逆变换即得 $y(t)$。** 积分方程取变换后变成「一次除法」——未知函数从积分号里干净地解出。<span class="marginnote">第二类 Volterra 方程是工程里最常见的积分方程（反馈系统、粘弹性、种群模型）。它的解「$Y=F/(1-\lambda G)$」里分母的 $1-\lambda G(s)$ 正是反馈系统的特征——「$1+$ 回路增益」的分母结构在控制理论里无处不在。</span>

**例：** 求解 $y(t)=e^{-t}+\int_0^{t}y(\tau)\sin(t-\tau)d\tau$。

- 取变换：$Y(s)=\frac1{s+1}+Y(s)\cdot\frac1{s^2+1}$（$\sin t\leftrightarrow\frac1{s^2+1}$）。
- 解：$Y(s)\left(1-\frac1{s^2+1}\right)=\frac1{s+1}$，$Y(s)=\frac{s^2+1}{(s+1)s^2}$。
- 部分分式：$\frac{s^2+1}{(s+1)s^2}=\frac{A}{s+1}+\frac{B}{s}+\frac{C}{s^2}$，解出 $A,B,C$。
- 逆变换：$y(t)=Ae^{-t}+B+Ct$（每项查表）。

**重点：卷积积分取变换 → 乘积 → 除法 → 逆变换，一步不落。** 与微分方程的唯一区别是「积分运算换成卷积」，处理方式同构。

## 2 线性系统的传递函数分析

**核心概念：传递函数（transfer function）** 设 LTI 系统由常系数线性微分方程描述，零初值下

$$H(s) = \frac{Y(s)}{X(s)} = \frac{b_ms^m+\cdots+b_0}{a_ns^n+\cdots+a_0}$$

**系统的全部行为由 $H(s)$ 的极零点决定：**

1. **稳定性**：系统稳定 ⟺ $H(s)$ 的**全部极点位于左半平面**（$\mathrm{Re}s_k<0$）。极点在虚轴上 ⟹ 临界稳定（等幅振荡）；在右半平面 ⟹ 不稳定（发散）。
2. **冲激响应**：$h(t)=\mathcal{L}^{-1}[H(s)]$——由极点决定模式。
3. **阶跃响应**：$y_{\text{step}}(t)=\mathcal{L}^{-1}[\frac{H(s)}s]$——除以 $s$ 再逆变换。
4. **频率响应**：$H(i\omega)=H(s)|_{s=i\omega}$——把 $s$ 放在虚轴上，得频响（与第七章傅里叶对接）。

**重点：极点决定「响应的形状」，零点决定「响应的幅度分布」。** 一对共轭复极点 $s=-\sigma\pm i\omega_d$ 产生「衰减振荡」$e^{-\sigma t}(A\cos\omega_d t+B\sin\omega_d t)$；实极点产生指数衰减 $e^{-pt}$。<span class="marginnote">「极点图 → 系统行为」是控制理论的读图基本功：极点越靠左，衰减越快；共轭极点对越靠近虚轴，振荡越持久。到《自动控制原理》你会用根轨迹、奈奎斯特图、伯德图把这些读图技巧系统化——$H(s)$ 是这一切的中心。</span>

## 3 例：二阶系统的完整分析

**例：** 系统 $y''+2y'+5y=5x(t)$，零初值，求传递函数、冲激响应、阶跃响应。

- **传递函数：** 取变换 $s^2Y+2sY+5Y=5X$，
$$H(s)=\frac{5}{s^2+2s+5}=\frac{5}{(s+1)^2+4}$$
极点 $s=-1\pm2i$（共轭复，左半平面）⟹ **系统稳定**、欠阻尼振荡模式。
- **冲激响应：** $h(t)=\mathcal{L}^{-1}[H]=\frac52e^{-t}\sin2t$（对照 $\frac{\omega}{(s-a)^2+\omega^2}$，$\omega=2,a=-1$）。
- **阶跃响应：** $Y=\frac{H(s)}s=\frac5{s(s^2+2s+5)}$，部分分式 + 逆变换得 $y(t)=1-e^{-t}(\cos2t+\frac12\sin2t)$。

**解读：** 阶跃响应从 0 上升到 1（稳态），中间有衰减振荡（欠阻尼）。**极点 $-1\pm2i$ 的实部 $-1$ 决定衰减速率，虚部 $\pm2$ 决定振荡频率。** 这就是「从 $H(s)$ 读系统行为」的完整示范。<span class="marginnote">二阶系统的阻尼比 $\zeta$、自然频率 $\omega_n$ 都能从极点直接读出：$s=-\zeta\omega_n\pm i\omega_n\sqrt{1-\zeta^2}$。这里 $\omega_n=\sqrt5$，$\zeta=\frac1{\sqrt5}$（欠阻尼）。「极点 ↔ 阻尼/频率」的对应是二阶系统分析的日常用语。</span>

## 4 公式解析：稳定性判据——极点必须都在左半平面

把「稳定 ⟺ 左半平面极点」这条判据拆开：

$$H(s)=\frac{\prod(s-z_k)}{\prod(s-p_k)}, \qquad h(t)=\sum_k \mathrm{Res}\left[H(s)e^{st},p_k\right]$$

- **第一步，看冲激响应的模式。** 由留数法逆变换，每个极点 $p_k$ 贡献一项 $A_ke^{p_kt}$（重极点则 $t^m e^{p_kt}$）。**$h(t)$ 是各极点模式的叠加。**
- **第二步，看指数 $e^{p_kt}$ 的性态。** $p_k=\sigma_k+i\omega_k$：$e^{p_kt}=e^{\sigma_kt}e^{i\omega_kt}$——$\sigma_k<0$ 时指数衰减（稳定），$\sigma_k=0$ 时等幅（临界），$\sigma_k>0$ 时指数增长（发散）。
- **第三步，判据成立。** 系统稳定要求 $t\to\infty$ 时 $h(t)\to0$，即每个模式的 $\sigma_k<0$——**全部极点实部为负（左半平面）**。只要有一个极点落在右半平面，响应就发散。

**直觉：** 极点就是系统的「自然频率」——系统被扰动后按这些频率自由振荡。**左半平面 = 衰减（稳定），右半平面 = 增长（不稳定）**，虚轴是「分界线」。这比解特征方程直观得多，也是控制工程师「看极点图判稳定」的原因。

## 6 补充：积分方程与系统分析的收官练习

用两道综合题把「积分方程」与「系统分析」串成收官演练。

**例 1（积分方程）：** 求解 $y(t)=\sin t+2\int_0^t y(\tau)\cos(t-\tau)d\tau$。

- 取变换：$Y(s)=\frac1{s^2+1}+2Y(s)\cdot\frac{s}{s^2+1}$（$\cos t\leftrightarrow\frac{s}{s^2+1}$）。
- 整理：$Y(s)\left(1-\frac{2s}{s^2+1}\right)=\frac1{s^2+1}$，$Y(s)=\frac{1}{s^2+1-2s}=\frac1{(s-1)^2}$。
- 逆变换：$y(t)=te^{t}$。

**验证：** 直接代入原方程数值可核。**卷积积分方程 → $s$ 域除法 → 逆变换，三步解出。**

**例 2（线性系统闭环分析）：** 单位反馈系统，前向 $G(s)=\frac5{s(s+2)}$，闭环传递函数 $\Phi(s)=\frac{G}{1+G}$：

$$\Phi(s)=\frac{\frac5{s(s+2)}}{1+\frac5{s(s+2)}}=\frac5{s^2+2s+5}$$

极点 $s=-1\pm2i$（左半平面）⟹ 闭环稳定。阶跃响应 $Y=\frac{\Phi(s)}s=\frac5{s(s^2+2s+5)}$，逆变换得 $y(t)=1-e^{-t}(\cos2t+\frac12\sin2t)$——**欠阻尼振荡逼近稳态 $1$。**

**重点：闭环稳定性看「$1+G$ 的零点」（闭环极点）——这正是辐角原理/奈奎斯特判据的用武之地（第五章）。** 「前向 $G$、反馈 $1$、闭环 $\frac G{1+G}$」的框架，把积分变换与复变留数连成一气。

**本专题收官感言：** 从复数的 $i^2=-1$ 出发，经过解析函数、柯西积分、留数、共形映射，再到傅里叶与拉普拉斯——**你掌握的已经是一门完整的「复变函数与积分变换」课**。这套语言在信号处理、控制理论、电磁场、量子力学里将持续发光，也是「从极限到大模型」主线上连接分析数学与工程数学的枢纽。

## 7 小结

- **Volterra 积分方程**：$y=f+\lambda y*g\Rightarrow Y(s)=\frac{F(s)}{1-\lambda G(s)}$——卷积变乘积、除法、逆变换。
- **传递函数** $H(s)$：LTI 系统在 $s$ 域的身份证，极零点决定一切行为。
- **稳定性**：全部极点实部为负 ⟺ 系统稳定；虚轴是分界线。
- **响应三件套**：冲激响应 $h$、阶跃响应 $\frac{H}s$、频率响应 $H(i\omega)$。
- **专题总图**：复分析（留数、映射）给工具，积分变换（傅里叶、拉普拉斯）给应用，工程给动力——网已织成。
