## 为什么带域问题需要「卷」与「摊」

上一节幂函数处理角域；本节处理另一类高频区域——**带域**（两条平行线之间的区域，如 $0<y<\pi$）。分式线性映射和幂函数都对带域无能为力（带域边界是平行直线，不是圆也不是射线），但指数函数天生适合：**$w=e^z$ 把水平带映成角域**，把「直线」卷成「射线」。反过来，对数函数把角域映成带域。带域是工程里的高频区域（平板、带状导体、沟槽），这两把工具不可或缺。<span class="marginnote">$w=e^z=e^{x+iy}$：实部 $x$ 控制模、虚部 $y$ 控制辐角。于是「$y$ 走水平带」对应「$\arg w$ 走角域」——<strong>虚轴的平移变成了辐角的旋转</strong>。这就是「卷」的几何本质。</span>

## 1 $w=e^z$ 的映射行为

**核心概念：指数映射（exponential mapping）**：$w=e^z$。设 $z=x+iy$：

$$w = e^x e^{iy} = e^x(\cos y + i\sin y)$$

**几何效果：**
- **水平带 → 角域**：水平带 $0<\mathrm{Im}\,z<\alpha$ 映成角域 $0<\arg w<\alpha$。
- **竖直线 → 圆**：直线 $x=c$ 映成圆周 $|w|=e^c$。
- **水平线 → 射线**：直线 $y=c$ 映成射线 $\arg w=c$。
- **临界点**：$w'=e^z\ne0$ 处处成立，**无临界点**，全平面共形（局部）。

**重点：$w=e^z$ 在宽度 $\le 2\pi$ 的水平带内是单叶的。** $e^z$ 以 $2\pi i$ 为周期，宽度超过 $2\pi$ 的带会重叠。**最常用的情形：带 $0<\mathrm{Im}\,z<\pi$ 映成上半平面**（因为 $0<\arg w<\pi$）。

**例：** $w=e^z$ 把带 $0<y<\pi$ 映成上半平面。边界 $y=0$ 映到正实轴，$y=\pi$ 映到负实轴，带内映到上半平面。**这是「带 → 半平面」的标准映射。**<span class="marginnote">「带 → 半平面」的用途：静电学里两块平行板（带域）的场，映成半平面后可用上半平面的泊松核直接写出解。工程里「平行板电容器」「带状传输线」的场论问题都是这条映射的直接受益者。</span>

## 2 $w=\mathrm{Log}\,z$：对数映射

**核心概念：对数映射（logarithmic mapping）**：$w=\mathrm{Log}\,z$（主值），设 $z=re^{i\theta}$：

$$w = \ln r + i\theta, \qquad 0<\theta<2\pi\ \text{（主分支）}$$

**几何效果（与指数互逆）：**
- **角域 → 水平带**：角域 $0<\arg z<\alpha$ 映成水平带 $0<\mathrm{Im}\,w<\alpha$。
- **圆 → 竖直线**：圆周 $|z|=r$ 映成竖直线 $\mathrm{Re}\,w=\ln r$。
- **射线 → 水平线**：射线 $\arg z=\theta$ 映成水平线 $\mathrm{Im}\,w=\theta$。
- **支点**：$z=0$ 是支点，映射在「割掉正实轴的平面」上单值解析。

**例：** $w=\mathrm{Log}\,z$ 把右半平面 $-\frac\pi2<\arg z<\frac\pi2$ 映成水平带 $-\frac\pi2<\mathrm{Im}\,w<\frac\pi2$。**半平面 → 带，对数一步到位。**<span class="marginnote">对数映射的多值性意味着「像的带高」取决于分支：主分支取 $\theta\in(0,2\pi)$ 时像带是 $0<\mathrm{Im}w<2\pi$。选择分支 = 选择「辐角从哪里开始数」，工程上按物理边界摆放割线，分支随之而定。</span>

## 3 综合例：水平带 → 单位圆

**例：** 求把带 $D=\{z: 0<\mathrm{Im}\,z<\pi\}$ 映成单位圆 $|w|<1$ 的映射。

**两步复合：**

**第一步，指数映射把带卷成半平面。** $w_1=e^z$ 把带 $0<y<\pi$ 映成上半平面 $\mathrm{Im}\,w_1>0$（上节结论）。
**第二步，分式线性把半平面映成单位圆。** $w_2=e^{i\theta}\frac{w_1-a}{w_1-\bar a}$（$a$ 在上半平面，如 $a=i$）。

**复合：** $w=e^{i\theta}\frac{e^z-i}{e^z+i}$ 把水平带映成单位圆。**「带 → 指数 → 半平面 → 分式线性 → 圆」——两条工具链串联。**

**重点：这类「多步复合」是共形映射工程的标准动作。** 每步用一个初等映射把区域变成「更标准」的形状，直到落到已知的标准区域。**背熟每类映射的「管辖区域」，再学会串联，共形映射题就只剩选工具的顺序。**<span class="marginnote">复合映射的「逆」也要会：把单位圆映回带，反向串联逆映射即可（先 $\frac{w-i}{w+i}$ 类把圆映成半平面，再 $\mathrm{Log}$ 把半平面映成带）。工程里「正反都要会」，因为物理问题常在两个区域间双向转换。</span>

## 4 公式解析：为什么指数映射把「带」卷成「角」

拆开 $w=e^z$ 的「卷」的动作：

$$w = e^z = e^{x+iy} = e^x e^{iy}, \qquad \arg w = y$$

- **第一步，分离实虚。** $e^x$ 决定模 $|w|=e^x$，$e^{iy}$ 决定辐角 $\arg w=y$。**辐角直接等于 $z$ 的虚部 $y$。**
- **第二步，读几何。** 让 $y$ 在 $(0,\alpha)$ 内变化，则 $\arg w$ 在 $(0,\alpha)$ 内变化——水平带 $(0<y<\alpha)$ 被「映射」成角域 $(0<\arg w<\alpha)$。**「虚轴的区间」变成「辐角的区间」。**
- **第三步，看边界。** 下边界 $y=0$ 映到 $\arg w=0$（正实轴），上边界 $y=\alpha$ 映到 $\arg w=\alpha$（角域另一边）。**带的两条平行边被「卷」成角域的两条射线——这就是「卷」的精确含义。**

**直觉：** 指数函数的周期性（$2\pi i$）让「竖直平移」变成「绕原点旋转」。**把带想象成一条纸带，$e^z$ 把它绕成一个角域（扇形面）**——宽度 $2\pi$ 的带正好卷一整圈成全平面。

## 5 指数/对数映射的应用场景

| 问题 | 映射 | 效果 |
| --- | --- | --- |
| 水平带 → 半平面 | $w=e^z$ | 卷带成角 |
| 半平面 → 水平带 | $w=\mathrm{Log}z$ | 摊角成带 |
| 水平带 → 单位圆 | $w=e^{i\theta}\frac{e^z-a}{e^z-\bar a}$ | 指数 + 分式线性 |
| 角域 → 水平带 | $w=\mathrm{Log}z$ | 摊角成带 |
| 圆环 → 带 | $w=\mathrm{Log}z$ 变形 | 半径变横坐标 |

**辨析｜易错点：指数映射的「带高」与周期性。** $e^z$ 以 $2\pi i$ 为周期，所以带的宽度不得超过 $2\pi$，否则重叠、不单叶。**宽度为 $\alpha$ 的带映成张角 $\alpha$ 的角域，$\alpha$ 可以大于 $\pi$（映成超过半平面的角域），但不能超过 $2\pi$。** 反过来，对数映射的「带高」等于所选分支的辐角范围。<span class="marginnote">「带宽 vs 张角」的守恒：带宽 $\alpha$ ⟺ 张角 $\alpha$。设计映射时先定目标张角，再选带高，两者必须一致。若带的宽度与目标张角不匹配（比如带高 $\pi$ 要映张角 $\frac\pi2$ 的角域），需先用相似变换（乘常数）把带压窄，再指数映射。</span>

## 6 补充：指数对数映射的典型例题

带域是工程高频区域，用三道典型题把「指数/对数映射」练到熟练。

**例 1（带 → 半平面）：** 求把带 $D=\{z:\ 0<\mathrm{Im}z<\frac\pi2\}$ 映成上半平面的映射。带宽 $\frac\pi2$，$w=e^z$ 把 $y\in(0,\frac\pi2)$ 映成 $\arg w\in(0,\frac\pi2)$——是**第一象限**，不是上半平面。要映成上半平面需张角 $\pi$：$w=(e^z)^2=e^{2z}$。验证：$y\in(0,\frac\pi2)\Rightarrow\arg(e^{2z})=2y\in(0,\pi)$ ✓。**「带宽 × 幂次 = 目标张角」——先算需要的总张角，再决定是否叠加幂函数。**

**例 2（半平面 → 带）：** 求把上半平面映成带 $0<\mathrm{Im}w<1$ 的映射。$\mathrm{Log}z$ 把上半平面（$\arg z\in(0,\pi)$）映成带 $0<\mathrm{Im}w<\pi$。要压到 $0<\mathrm{Im}w<1$：$w=\frac1\pi\mathrm{Log}z$。**「对数摊角 + 缩放调带宽」。**

**例 3（带 → 单位圆）：** 求把带 $0<y<\pi$ 映成单位圆的映射。

- 第一步：$w_1=e^z$ 把带映成上半平面。
- 第二步：$w_2=\frac{w_1-a}{w_1-\bar a}$（$a$ 取 $i$）把上半平面映成单位圆。
- 复合：$w=\frac{e^z-i}{e^z+i}$。

**边界追踪验证：** $z$ 在下边界 $y=0$ 时 $w_1=x>0$（正实轴），$w_2=\frac{x-i}{x+i}$ 模 $=1$——单位圆边界 ✓；$z$ 在上边界 $y=\pi$ 时 $w_1=e^{x+i\pi}=-e^x<0$（负实轴），同样映到单位圆。**内部点 $z=i$ 映 $w_2=\frac{e^i-i}{e^i+i}$，模 <1？** 数值可验。**三步：指数卷带 → 分式线性收圆 → 边界追踪验证。**

**重点：带域问题几乎总是「指数/对数 + 分式线性」的复合。** 指数管「卷」，分式线性管「收圆」，对数管「摊平」——**组合拳覆盖所有带域映射。**

**辨析｜易错点：带宽超过 $2\pi$ 的带不单叶。** $e^z$ 周期 $2\pi i$，带宽 $>2\pi$ 时像重叠。**先用相似变换（乘常数）把带压到 $\le2\pi$ 宽，再指数映射。**

## 7 补充：指数对数映射的易错清单

指数/对数映射的题目高频出错点集中在「带宽」「分支」「方向」三处，集中排查。

**易错一：带宽超过 $2\pi$ 不单叶。** $e^z$ 周期 $2\pi i$，带宽 $>2\pi$ 时像重叠。**先压带宽再指数映射。**

**易错二：$\mathrm{Log}$ 的分支与割线。** $\mathrm{Log}z$ 主值在割掉负实轴的平面上单值。**带角域用 $\mathrm{Log}$ 时，割线要选在角域之外。**

**易错三：复合的顺序。** 「带 → 圆」是先 $e^z$ 后分式线性；「圆 → 带」先分式线性后 $\mathrm{Log}$。**顺序反了，区域对不上。**

**例（综合）：** 求把带 $0<\mathrm{Im}z<2\pi$ 映成单位圆的映射。带宽 $2\pi$ 等于周期——**先压带**：$w_1=\frac{z}{2}$ 把带压到 $0<\mathrm{Im}w_1<\pi$，再 $w_2=e^{w_1}$ 映成上半平面，最后分式线性收圆。**「压带宽」是第一动作。**

**例（对数方向）：** $\mathrm{Log}z$ 把右半平面（$\arg z\in(-\frac\pi2,\frac\pi2)$）映成带 $-\frac\pi2<\mathrm{Im}w<\frac\pi2$。**主值分支的辐角区间决定带的位置。**

**重点：指数/对数映射的三道关——带宽（$\le2\pi$）、分支（$\mathrm{Log}$ 的主值）、顺序（卷/摊与收圆的先后）。** 每道题过三关。

**辨析｜易错点：$\mathrm{Log}z$ 的带高 = 所选分支的辐角范围。** 主值分支（$-\pi<\arg z\le\pi$）把全平面（去掉负实轴）映成带 $-\pi<\mathrm{Im}w\le\pi$，高 $2\pi$。**改选分支（如 $(0,2\pi)$）则带高不变但位置移动。**

## 8 小结

- **指数映射** $w=e^z$：水平带 $0<y<\alpha$ → 角域 $0<\arg w<\alpha$；无临界点；带宽 $\le2\pi$ 单叶。
- **对数映射** $w=\mathrm{Log}z$：角域 → 水平带，是指数的逆；$z=0$ 是支点。
- **复合链路**：带 → 指数 → 半平面 → 分式线性 → 圆；反向亦然。
- **带宽守恒**：带宽 = 张角；带宽超过 $2\pi$ 会重叠。
- **工具分工**：指数/对数管带，幂/根式管角，分式线性管圆与半平面。
