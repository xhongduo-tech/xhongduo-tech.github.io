## 为什么一个「简单分式」能长成机翼

前面几节的映射都在「标准区域」之间打转。本节的主角——**茹科夫斯基映射** $w=\frac12(z+\frac1z)$——能把**圆**映成**机翼截面**形状的区域，这在空气动力学里开创了一个时代：绕圆柱的流动（有显式解）经此映射变成绕机翼的流动（真实关心的对象）。一个二次分式，既是共形映射理论的收官展示，也是复分析工程价值的最佳名片。<span class="marginnote">茹科夫斯基（1847—1921）是「俄国航空之父」。他发现 $w=z+\frac1z$ 型的映射把圆映成翼型后，绕圆柱的有环量流动被精确映射为绕翼型的升力流动——库塔-茹科夫斯基升力定理由此而来。这是复变函数论进入工程殿堂的标志性时刻。</span>

## 1 茹科夫斯基映射的定义与行为

**核心概念：茹科夫斯基映射（Joukowski map）**：

$$w = \frac12\left(z+\frac1z\right)$$

**关键性质：**
- **临界点**：$w'=\frac12(1-\frac1{z^2})$，$w'=0$ 在 $z=\pm1$。故 $z=\pm1$ 是临界点，映射在 $\pm1$ 处不共形。
- **对称性**：$w(z)=w(\frac1z)$——$z$ 与 $\frac1z$ 映到同一点（反射对称）。
- **保圆**：不是分式线性映射，但把经过 $\pm1$ 的圆/直线映成特殊曲线（下节）。

**几何效果（极坐标形式）：** 设 $z=re^{i\theta}$，则

$$w = \frac12\left(re^{i\theta}+\frac1r e^{-i\theta}\right) = \frac12\left(r+\frac1r\right)\cos\theta + i\frac12\left(r-\frac1r\right)\sin\theta$$

**单位圆 $r=1$ 的像：** $u=\cos\theta$，$v=0$——**单位圆被映成实轴上线段 $[-1,1]$**（两遍覆盖）。**这是理解茹科夫斯基映射的起点：单位圆坍缩成线段。**<span class="marginnote">单位圆映成线段 $[-1,1]$ 是茹科夫斯基映射最反直觉的地方：一个二维图形（圆）被「拍扁」成一维线段。关键在于 $w(\frac1z)=w(z)$——单位圆上的点与「反演点」重合，像只有实部。这个「折叠」是后续翼型生成的根源。</span>

## 2 圆 → 椭圆、翼型

**若 $z$ 在圆 $|z|=R>1$ 上：** 记 $a=\frac12(R+\frac1R)$，$b=\frac12(R-\frac1R)$，则

$$u = a\cos\theta, \qquad v = b\sin\theta$$

**这正是椭圆的参数方程** $\frac{u^2}{a^2}+\frac{v^2}{b^2}=1$——**半径 $R>1$ 的圆被映成椭圆**（长半轴 $a$，短半轴 $b$）。$R\to1$ 时椭圆退化成长度为 $2$ 的线段。

**圆 → 翼型的机制：** 若圆**不**以原点为圆心（圆心在 $z=c$，$c$ 很小），且**经过 $z=1$ 点**（或接近 $z=1$），则茹科夫斯基映射把它映成一个**翼型**——前缘圆钝、后缘尖削的形状。**「偏离圆心的圆 + 经过临界点」= 翼型。**<span class="marginnote">翼型参数化的具体做法：取圆 $|z-c|=R$，其中 $c$ 小且满足 $R=|1-c|$（保证圆过 $z=1$），则映射的像是一条闭合翼型曲线，后缘尖点落在 $w=1$ 处（$z=1$ 是临界点，映射把圆「折」出尖角）。调整 $c$ 的实部虚部可控制翼型的弯度与厚度。</span>

## 3 茹科夫斯基映射与空气动力学的连接

**核心思想（库塔-茹科夫斯基方法）：**

1. **圆上有显式解**：不可压缩无黏流体绕圆柱的流动，其复势是显式的：$F(z)=U(z+\frac{a^2}{z})+\frac{\Gamma}{2\pi i}\ln z$（均匀流 + 偶极子 + 点涡）。
2. **映射到翼型**：茹科夫斯基映射把圆映成翼型截面。
3. **复势回映**：$F\circ w^{-1}$ 给出绕翼型的复势——翼型上的流动完全确定，升力由库塔-茹科夫斯基定理给出。

**重点：共形映射「传送」的是复势（解析函数）。** 因为共形映射保持调和方程与边界对应，圆域上的复势经映射后自动满足翼型边界条件。**这就是「保角变换法」在空气动力学里的全部剧本。**<span class="marginnote">「升力 = $\rho U\Gamma$」（库塔-茹科夫斯基定理）里，$\Gamma$ 是绕翼型的环量，由「后缘光滑条件」确定（库塔条件）。整个现代机翼理论建立在「圆 → 翼型」这一映射之上——你正在学的映射是航空史的数学支点。</span>

**注意适用范围：** 茹科夫斯基映射产生的是理想流体的二维势流解，不含黏性与涡流分离。真实机翼的空气动力学远比这复杂（边界层、湍流），但茹科夫斯基映射仍是理解「升力从哪来」的第一原理模型。

## 4 公式解析：$z+\frac1z$ 如何把圆「挤」成翼型

拆开茹科夫斯基映射的作用机制：

$$w = \frac12\left(z+\frac1z\right)$$

- **第一步，$z$ 与 $1/z$ 的叠加。** $w$ 是「$z$」与「它的反演」的平均。反演 $1/z$ 把圆外映到圆内，两者叠加，圆周上的点「对折」到同一像——单位圆因此坍缩成线段。
- **第二步，偏心的圆「不对称折叠」。** 若圆的圆心不在原点，$z$ 与 $1/z$ 的「对折」不再对称，像曲线两侧的曲率不同——一侧鼓起（前缘）、一侧变尖（后缘），翼型诞生。**临界点 $z=1$ 处映射的折叠产生后缘尖角。**
- **第三步，参数控制形状。** 圆的半径 $R$ 与圆心偏移 $c$ 共同决定翼型的厚度与弯度。**调整 $R,c$，翼型从对称椭圆连续变形到带弯度的翼型**——茹科夫斯基映射是一个「翼型生成器」。

**直觉：** 茹科夫斯基映射像一台「挤圆机」——把圆放在某个位置，机器一压（$z+\frac1z$ 的折叠），圆就被挤成特定的流线型。**圆心的位置决定「怎么挤」，圆周经过临界点与否决定「有没有尖角」。**

## 5 其他初等函数映射一览

| 映射 | 作用 | 典型区域 |
| --- | --- | --- |
| $w=z^2$ | 张角加倍 | 象限 → 半平面 |
| $w=\sqrt z$ | 角域收缩、割缝拉直 | 挖缝平面 → 半平面 |
| $w=e^z$ | 带 → 角域 | 水平带 → 半平面 |
| $w=\mathrm{Log}z$ | 角域 → 带 | 角域 → 水平带 |
| $w=\frac12(z+\frac1z)$ | 圆 → 椭圆/翼型 | 圆 → 机翼截面 |
| $w=\frac{z-a}{1-\bar az}$ | 圆 → 圆 | 圆盘自同构 |

**重点：这些映射配合分式线性映射，几乎能处理所有「直线/圆/射线/弧」围成的区域。** 判断该用哪个：看边界形状——**圆与直线用分式线性，角与缝用幂/根式，带用指数/对数，翼型用茹科夫斯基。**<span class="marginnote">「边界形状 → 工具」的映射表是共形映射的最终版决策树。学完本节，你手里的工具已覆盖复变函数论「初等映射」的全部经典家族——剩下的就是组合与练习。</span>

## 6 补充：茹科夫斯基映射的定量示例

用具体数值看清「圆 → 椭圆/翼型」的机制，比抽象描述更直观。

**例 1（圆 → 椭圆）：** $w=\frac12(z+\frac1z)$ 把 $|z|=2$ 映成什么？$R=2$，$a=\frac12(2+\frac12)=\frac54$，$b=\frac12(2-\frac12)=\frac34$，故

$$\frac{u^2}{(5/4)^2}+\frac{v^2}{(3/4)^2}=1$$

**长半轴 $\frac54$、短半轴 $\frac34$ 的椭圆。** $R\to1$ 时 $b\to0$，椭圆退化成长度为 $2$ 的线段——单位圆坍缩成 $[-1,1]$。

**例 2（偏心的圆 → 翼型）：** 取圆心 $z=0.2$、半径 $R=0.9$ 的圆（不过 $z=1$），$w=\frac12(z+\frac1z)$ 的像是一条闭合曲线——**对称翼型**（弯度为零）。若圆心带虚部（如 $z=0.2+0.1i$），像曲线前后缘不再对称——**带弯度的翼型**。**圆心实部控制厚度、虚部控制弯度。**

**例 3（验证单位圆坍缩）：** 对 $|z|=1$ 上一点 $z=e^{i\theta}$：

$$w=\frac12(e^{i\theta}+e^{-i\theta})=\cos\theta$$

**像恰是实轴上的 $\cos\theta$，随 $\theta\in[0,2\pi]$ 在 $[-1,1]$ 上来回扫两遍**——单位圆被「对折」成线段。这验证了「$w(z)=w(1/z)$」的对称性：$e^{i\theta}$ 与 $e^{-i\theta}$ 映到同一点。

**为什么机翼要用「过 $z=1$ 的圆」：** $z=1$ 是临界点（$w'=0$），映射在临界点把曲线「折」出尖角——**后缘的尖点恰来自临界点的折叠**。若圆不过 $z=1$，像曲线是光滑的椭圆/卵形（无尖点），不是机翼。

**辨析｜易错点：茹科夫斯基映射在临界点不共形。** $z=\pm1$ 处 $w'=0$，夹角不再保持——机翼后缘的尖角正是「不共形」的产物。**它说明：共形映射理论允许「边缘的临界退化」，工程应用恰恰利用这种退化制造尖角。**

## 7 补充：茹科夫斯基映射的工程意义再体会

茹科夫斯基映射不只是「数学技巧」，它是复变函数论进入工程殿堂的里程碑——理解它的工程地位，比多算几道题更重要。

**升力理论的完整链条：**

1. 绕圆柱的均匀流 + 偶极子 + 点涡，复势 $F(z)=U(z+\frac{a^2}{z})+\frac{\Gamma}{2\pi i}\ln z$ 是显式解（圆域上的解析函数）。
2. 茹科夫斯基映射 $w=\frac12(z+\frac1z)$ 把圆映成翼型。
3. 复势经映射回传，得到绕翼型的流动；库塔条件（后缘光滑）确定环量 $\Gamma$。
4. **库塔-茹科夫斯基定理：升力 $L=\rho U\Gamma$**——升力与环量成正比。

**为什么映射「传送」复势：** 共形映射保持调和方程与边界对应。圆域上满足边界条件的复势，映射后自动满足翼型边界条件——**「在简单区域解、映射回复杂区域」是保角变换法的全部哲学**。

**更广的工程背景：** 同样的思路用于——静电场（共形映射解复杂电极）、热传导（映射解异形截面）、地下水渗流（映射解井群）——**凡「拉普拉斯方程 + 复杂边界」，保角变换法都有一席之地。**

**现代视角的补充：** 茹科夫斯基映射是理想势流模型，真实机翼还有边界层、湍流、黏性——**但它作为「升力从哪来」的第一性原理解释，至今无法替代。** 学空气动力学的人，几乎都会在入门时遇到它。

**例（映射的几何验证）：** 圆 $|z|=R>1$ 映成椭圆 $\frac{u^2}{a^2}+\frac{v^2}{b^2}=1$（$a=\frac12(R+\frac1R)$，$b=\frac12(R-\frac1R)$）。$R=3$：$a=\frac53$，$b=\frac43$——**长短轴之比 $\frac{a}{b}=\frac{5}{4}$**，椭圆「压扁」程度由 $R$ 控制。$R\to\infty$ 时 $a,b\to\infty$、比趋近 $1$（趋近圆）——**圆越远离原点，像越接近圆**。

**辨析｜易错点：茹科夫斯基映射不是处处单叶。** $w(z)=w(1/z)$ 说明 $z$ 与 $1/z$ 映到同一点——**全平面不单叶**。只在「圆外区域」（$|z|>1$）单叶。**用映射前先限定区域（$|z|>1$ 或单位圆内），别在全平面谈论单叶性。**

## 8 小结

- **茹科夫斯基映射** $w=\frac12(z+\frac1z)$：临界点 $z=\pm1$，对称性 $w(z)=w(1/z)$。
- **单位圆 → 线段** $[-1,1]$；$|z|=R>1$ 的圆 → 椭圆；偏心过临界点的圆 → 翼型。
- **空气动力学**：绕圆流动经映射成为绕翼型流动，升力由库塔-茹科夫斯基定理给出。
- **公式机制**：$z$ 与 $1/z$ 的「对折」+ 偏心 + 临界点 = 翼型生成。
- **工具表**：分式线性管圆、幂根式管角、指对数管带、茹科夫斯基管翼型。

在下一节，我们做共形映射的总复习：**共形映射综合问题与边界对应原理**。边界对应是「找映射」的终极判据——只要边界对应正确且方向一致，映射就必然把内部映到正确的一侧。
