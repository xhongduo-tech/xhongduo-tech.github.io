## 为什么「标准区域」够用

共形映射工程的关键思想：**任何区域都能用初等映射（分式线性、幂、指数等）映到「标准区域」——上半平面、单位圆、右半平面、带域**。于是问题「区域 $D$ 上的物理场」化归为「标准区域上的物理场」。本节把标准区域之间**用分式线性映射**能完成的所有转换整理成表，并给出推导与典型应用。上一节的三点定映射 + 对称点法在这里集中亮相。<span class="marginnote">「标准区域」的集合是刻意的：圆、半平面、带域这些区域的边界是圆或直线（分式线性映射的「主场」），且它们之上有显式的格林函数、泊松核。共形映射把一切区域都「标准化」，是工程数学的一贯策略。</span>

## 1 上半平面 ↔ 单位圆

**核心公式：把上半平面 $\mathrm{Im}\,z>0$ 映到单位圆 $|w|<1$、且 $z=a$（$\mathrm{Im}\,a>0$）映到 $w=0$ 的映射：**

$$w = e^{i\theta}\frac{z-a}{z-\bar a}$$

**推导要点：** 由对称性，$a$ 的对称点 $\bar a$（关于实轴）必须映到 $0$ 的对称点 $\infty$。分母取 $z-\bar a$ 让 $\bar a$ 映到 $\infty$，分子取 $z-a$ 让 $a$ 映到 $0$。实轴 $z=x$ 映到 $|w|=\left|\frac{x-a}{x-\bar a}\right|=1$（分子分母共轭），故实轴映到单位圆。上半平面内部点（如 $z=i$，当 $a=i$ 时）映到 $0$，在圆内——方向确定。

**例：** $w=\frac{z-i}{z+i}$ 把上半平面映到单位圆，$z=i$ 映到 $0$，$z=0$ 映到 $-1$，$z=\infty$ 映到 $1$。<span class="marginnote">这个映射的逆：$z=i\frac{1+w}{1-w}$，把单位圆映回上半平面。工程里「从圆盘到半平面」常直接用逆公式。$a$ 的选择控制「哪个点变圆心」，等价于「选哪个点送到新区域的内部中心」。</span>

## 2 右半平面 ↔ 单位圆

**核心公式：右半平面 $\mathrm{Re}\,z>0$ 映到单位圆 $|w|<1$、$z=a$（$\mathrm{Re}\,a>0$）映到 $w=0$：**

$$w = e^{i\theta}\frac{z-a}{z+\bar a}$$

**推导：** 与上半平面情形完全平行——右半平面的边界是虚轴，$a$ 关于虚轴的对称点是 $-\bar a$。分母 $z+\bar a$ 让对称点映到 $\infty$，分子 $z-a$ 让 $a$ 映到 $0$。虚轴 $z=iy$ 映到 $|w|=\left|\frac{iy-a}{iy+\bar a}\right|=1$（分子分母共轭）。

**例：** $w=\frac{z-1}{z+1}$ 把右半平面 $\mathrm{Re}\,z>0$ 映到单位圆（$z=1$ 映到 $0$，$z=0$ 映到 $-1$，$z=\infty$ 映到 $1$）。**这个例子就是上一节「$w=\frac{z-1}{z+1}$ 映实轴到实轴」的姊妹——现在它映虚轴到单位圆。**<span class="marginnote">右半平面 ↔ 单位圆在控制理论里特别重要：模拟滤波器设计里用双线性变换 $s\leftrightarrow z$ 把 $s$ 平面（稳定性区域是左半平面）映到 $z$ 平面（稳定性区域是单位圆内）。$w=\frac{z-1}{z+1}$ 型的双线性变换是 DSP 教材的常客。</span>

## 3 上半平面 ↔ 带域与角域

**核心公式（指数把带域映成角域/半平面）：** $w=e^z$ 把水平带 $0<\mathrm{Im}\,z<\pi$ 映到上半平面 $\mathrm{Im}\,w>0$。

**推导：** $e^z=e^{x+iy}$，$y\in(0,\pi)$ 时 $\arg w=y\in(0,\pi)$，故 $w$ 落在上半平面。**带的边界 $y=0$、$y=\pi$ 分别映到正实轴与负实轴。**（这是下一节指数映射的预告，但「带域 ↔ 半平面」经常与分式线性映射联合使用。）

**联合用法：** 求「上半带 $0<y<\pi$」到单位圆的映射：先 $w_1=e^z$ 映到上半平面，再 $w_2=\frac{w_1-a}{w_1-\bar a}$ 映到单位圆。**分式线性映射负责「圆 ↔ 半平面」，指数负责「带 ↔ 半平面」——两者复合，覆盖带域问题。**<span class="marginnote">「分式线性管圆和半平面、指数管带、幂函数管角」是共形映射的分工图。本节先立起「标准区域转换表」，下两节把指数与幂函数的「管辖区」补全。复合映射 = 按分工串联标准步骤。</span>

## 4 公式解析：为什么「对称点法」能确定整个映射

用「上半平面 → 单位圆」的标准形式，拆开对称点法的推理链：

$$w = e^{i\theta}\frac{z-a}{z-\bar a}$$

- **第一步，零极点定位。** 要求 $z=a$ 映到 $w=0$（内部点 → 圆心），故分子为 $z-a$。由保对称性，$a$ 的实轴对称点 $\bar a$ 映到 $0$ 的对称点 $\infty$，故分母为 $z-\bar a$。**一对对称点（$a,\bar a$）锁定了分子分母。**
- **第二步，边界约束定模长。** 实轴（$z=x$）映到单位圆边界：$|w|=|e^{i\theta}|\left|\frac{x-a}{x-\bar a}\right|=1\cdot1=1$（因为 $x-a$ 与 $x-\bar a$ 互为共轭，模相等）。**$|e^{i\theta}|=1$ 由「边界映边界」自动要求。**
- **第三步，$e^{i\theta}$ 是残余自由度。** 一旦「$a$ 映到 $0$」给定，映射还剩一个旋转自由度 $e^{i\theta}$——它不影响「哪个点映圆心」，只旋转整个圆盘。**若题目还指定边界上某点的像，就由 $e^{i\theta}$ 来确定。**

**直觉：** 对称点法用「一个内部点 + 它的对称点」锁定分式线性映射的分子分母，用「边界映边界」锁定模长，最后用旋转因子满足附加条件。**几何约束一步步收紧，直到映射唯一。**

## 5 标准区域转换表

| 从 → 到 | 映射 | 关键对应 |
| --- | --- | --- |
| 上半平面 → 单位圆 | $w=e^{i\theta}\frac{z-a}{z-\bar a}$ | $a\mapsto0$ |
| 单位圆 → 上半平面 | $w=e^{i\theta}\frac{z-a}{1-\bar a z}$（$|a|<1$） | $a\mapsto0$ 或逆变换 |
| 右半平面 → 单位圆 | $w=e^{i\theta}\frac{z-a}{z+\bar a}$ | $a\mapsto0$ |
| 单位圆 → 右半平面 | $w=e^{i\theta}\frac{z-a}{1-\bar a z}$ 复合 | 逆变换 |
| 带域 → 上半平面 | $w=e^z$ | $y\in(0,\pi)$ |
| 上半平面 → 带域 | $w=\mathrm{Log}z$ | $\arg z\in(0,\pi)$ |

**重点：查表 + 复合。** 任何一个「典型区域 → 另一个典型区域」的映射都能查表得到；非典型区域先映到典型区域，再查表串联。**共形映射的工程学 = 标准区域表 + 复合规则。**<span class="marginnote">这三张「往返」公式（半平面↔圆、右半↔圆、带↔半平面）是考试与工程的双重高频点。背它们时连「哪个点映到 0」一起记——$a$ 的取值是唯一需要定制的参数，其余结构固定。</span>

## 6 补充：从「上半平面→单位圆」推导「单位圆→单位圆」

两套标准公式其实出自同一个推理模板。把「单位圆 → 单位圆」的推导完整走一遍，展示对称点法的一致性：

**问题：** 求把 $|z|<1$ 映到 $|w|<1$、且 $z=a$（$|a|<1$）映到 $w=0$ 的映射。

- **第一步，零极点定位。** 分子取 $z-a$ 让 $a$ 映到 $0$。$a$ 关于单位圆的对称点是 $\frac1{\bar a}$，由保对称性它映到 $0$ 的对称点 $\infty$，故分母取 $1-\bar a z$（在 $z=\frac1{\bar a}$ 处为零）。
- **第二步，边界约束。** $|z|=1$ 时 $|z-a|=|1-\bar a z|$（因为 $z\bar z=1$ 时 $z-a=z(1-\bar a z)$，模相等），故 $\left|\frac{z-a}{1-\bar a z}\right|=1$——单位圆映到单位圆。乘 $|k|=1$ 不破坏这一点。
- **第三步，写出通式。** $w=e^{i\theta}\frac{z-a}{1-\bar a z}$（$|a|<1$，$\theta\in\mathbb{R}$）。**与「上半平面→单位圆」的公式 $e^{i\theta}\frac{z-a}{z-\bar a}$ 结构同源**：都是「内部点 $a$ 映圆心、对称点映 $\infty$、边界映边界」。

**对比记忆：**

| 映射 | 分母的「对称点」位置 | 关键区别 |
| --- | --- | --- |
| 上半平面 → 单位圆 | $z=\bar a$（实轴对称） | 分母 $z-\bar a$ |
| 单位圆 → 单位圆 | $z=\frac1{\bar a}$（圆内反演） | 分母 $1-\bar a z$ |

**重点：两套公式只需记「内部点 $a$、对称点 $a^*$」的配对规则**——$a$ 映到 $0$，$a^*$ 映到 $\infty$，边界自动映边界。**分母写「$z-a^*$」的形式随对称点而定。**

**综合例：** 求把「右半单位圆 $\{|z|<1,\ \mathrm{Re}z>0\}$」映到单位圆的映射。它是「半圆 + 分式线性」的复合：先用 $w_1=\frac{z+1}{z-1}$ 把右半单位圆映成右半平面（或查表），再用 $w_2=e^{i\theta}\frac{w_1-a}{w_1+\bar a}$ 映到单位圆。**「半圆 → 半平面 → 圆」的链路里，本节两套公式各用一次。**

## 7 补充：标准映射的「验证法」与易错提醒

「映射对不对」的验证有一套固定动作，配上一组易错提醒，是本章的收官检查。

**验证三步：**
1. **边界三点核对**：取源区域边界三点，看像是否落在目标边界。
2. **内部点定方向**：取源区域一个测试点，看像在目标区域内部还是外部。
3. **$ad-bc$ 检查**：分式线性映射非退化。

**例（验证上半平面 → 单位圆）：** $w=\frac{z-i}{z+i}$。边界实轴 $z=x$：$|w|=\left|\frac{x-i}{x+i}\right|=1$ ✓（三点 $0,\infty,\pm1$ 都在单位圆上）。内部点 $z=i$：$w=0$，在圆内 ✓。$ad-bc=1\cdot i-(-i)\cdot1=2i\ne0$ ✓。**三步全过，映射正确。**

**易错提醒一：$\bar a$ 与 $a$ 的摆放。** 上半平面 → 单位圆用 $\frac{z-a}{z-\bar a}$；单位圆 → 单位圆用 $\frac{z-a}{1-\bar a z}$。**分母对应「对称点」：实轴对称是 $\bar a$，圆内反演是 $\frac1{\bar a}$。**

**易错提醒二：$e^{i\theta}$ 是旋转自由度，不影响「哪个点映圆心」。** 题目若指定「$z_0$ 映到 $0$」，由 $a$ 决定；指定「某边界点映到某位置」，由 $e^{i\theta}$ 决定。**两个自由度各管一件事。**

**易错提醒三：目标区域的方向。** 同样的边界对应，可以映到「内部」或「外部」——取决于映射的方向。**测试点定方向是必须的，别只核对边界。**

**重点：标准映射表 + 验证三步，是「查表映射题」的完整武器。** 背表解决「用什么」，验证解决「对不对」。

**综合例：** 求把右半平面映到单位圆、$z=1$ 映到 $0$ 的映射，并验证。$w=\frac{z-1}{z+1}$：$z=1\mapsto0$ ✓；虚轴 $z=iy$：$\left|\frac{iy-1}{iy+1}\right|=1$ ✓；内部点 $z=2$：$w=\frac13$，模 $<1$ 在圆内 ✓。**验证全过，答案正确。**

## 8 小结

- **上半平面 → 单位圆**：$w=e^{i\theta}\frac{z-a}{z-\bar a}$（$a$ 在上半平面）。
- **右半平面 → 单位圆**：$w=e^{i\theta}\frac{z-a}{z+\bar a}$（$a$ 在右半平面）。
- **带域 → 半平面**：$w=e^z$；逆用 $\mathrm{Log}$。
- **推导引擎**：对称点法（内部点 + 对称点锁定分子分母）+ 边界约束 + 旋转因子。
- **工作流**：查标准区域表，复合串联，映射非典型区域。

在下一节，我们把目光从分式线性映射移向初等解析映射的另一族：**幂函数与根式函数所构成的映射**。$w=z^n$ 把角域张角、把 $1/n$ 圆弧映成半圆——处理角域问题的利器。
