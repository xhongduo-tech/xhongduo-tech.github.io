# 洛朗级数（Laurent 级数）

<div class="epigraph">
<p>泰勒级数只能描述「干净」的函数；洛朗级数把奇点的秘密也写进了幂级数的语言。</p>

## 为什么泰勒级数不够用

泰勒级数要求函数在展开点解析——但解析函数偏偏常被奇点「包围」。$f(z)=\frac{1}{z}$ 在 $z=0$ 附近没有任何泰勒展开（$z=0$ 是奇点），而它在 $\frac{1}{z}$ 这种「负幂」却大有文章可做。洛朗的洞察是：**不要执着于非负幂——把级数放宽到「负幂 + 非负幂」的双向形式，函数在圆环域内（含奇点周围）也能展开。** 这一放宽让级数语言能描述奇点本身，而负幂项中 $\frac{1}{z-z_0}$ 的系数——正是第五章「留数」的定义。洛朗级数是连接级数与积分两大理论的桥。<span class="marginnote">洛朗级数在 1843 年由洛朗提出，但魏尔斯特拉斯此前已私下使用类似思想。它本质上「泰勒级数 + 奇点的负幂指纹」，是研究奇点、计算留数、求围道积分的万能语言。</span>

## 1 洛朗级数：双向幂级数

**核心概念：洛朗级数（Laurent series）**：形如

$$\sum_{n=-\infty}^{\infty} c_n (z-z_0)^n = \sum_{n=-\infty}^{-1} c_n(z-z_0)^n + \sum_{n=0}^{\infty}c_n(z-z_0)^n$$

的级数称为以 $z_0$ 为中心的**洛朗级数**。它由两部分组成：

- **正幂部分** $\sum_{n=0}^{\infty}c_n(z-z_0)^n$：在 $|z-z_0|<R_2$ 内收敛；
- **负幂部分** $\sum_{n=-\infty}^{-1}c_n(z-z_0)^n$：令 $w=\frac{1}{z-z_0}$，它是 $w$ 的幂级数，在 $|w|<1/R_1$ 收敛，即 $|z-z_0|>R_1$。

两部分同时收敛的区域是**圆环域**：

$$R_1 < |z-z_0| < R_2$$

**核心概念：圆环域（annulus）**：两条同心圆之间的环形区域。$R_1$ 可为零（内圆收缩为点），$R_2$ 可为 $\infty$（外圆消失）。在圆环域内，洛朗级数绝对且一致收敛。

**重点：洛朗级数的唯一性。** 在同一个圆环域内，表示同一个函数的洛朗级数**唯一**。若在**不同**圆环域内展开（比如 $0<|z|<1$ 与 $|z|>1$），系数不同——因为奇点分布不同。<span class="marginnote">唯一性在「固定圆环域」内成立，这是最重要的限定。同一个函数可以有不同的洛朗展开，但每个展开对应一个具体的圆环域。求展开前先画奇点、定圆环域，这是洛朗展开的第一动作。</span>

## 2 洛朗定理

**核心概念：洛朗定理（Laurent's theorem）**：设 $f$ 在圆环域 $R_1<|z-z_0|<R_2$ 内解析，则 $f$ 在该圆环域内可展成洛朗级数

$$f(z) = \sum_{n=-\infty}^{\infty}c_n(z-z_0)^n$$

其中系数由积分给出：

$$c_n = \frac{1}{2\pi i}\oint_C\frac{f(\zeta)}{(\zeta-z_0)^{n+1}}\,d\zeta, \qquad n=0,\pm1,\pm2,\dots$$

$C$ 是圆环域内任意一条围绕 $z_0$ 的正向闭曲线。**系数公式在形式上与泰勒系数一样，但 $n$ 取全体整数。**

**注意：当 $n<0$ 时，$c_n$ 不能再用 $f^{(n)}(z_0)$ 解释**——$f$ 在 $z_0$ 未必有定义或未必解析。$c_{-1}$ 尤其重要，它没有「导数」对应，却正是第五章的**留数**：

$$c_{-1} = \frac{1}{2\pi i}\oint_C f(\zeta)\,d\zeta$$

**这是整个复变函数论最著名的系数。**<span class="marginnote">$c_{-1}$ 叫留数，记作 $\mathrm{Res}(f,z_0)$。它度量「$f$ 在 $z_0$ 的奇点强度」：绕 $z_0$ 一圈的积分等于 $2\pi i\cdot c_{-1}$。第五章留数定理的一切，都建立在这个系数上。</span>

## 3 公式解析：$\frac{1}{1-z}$ 的两种展开——同一函数两个圆环域

洛朗级数与泰勒级数的根本差异，用一个例子一次看清。$f(z)=\frac{1}{1-z}$ 只有一个奇点 $z=1$。

**展开一（在 $|z|<1$ 内）：** 这是泰勒展开

$$\frac{1}{1-z} = \sum_{n=0}^{\infty}z^n, \qquad |z|<1$$

**展开二（在 $|z|>1$ 内）：** 圆环域是外环，内圆半径为 $1$、外圆为 $\infty$。此时把 $\frac{1}{1-z}$ 改写成

$$\frac{1}{1-z} = -\frac{1}{z}\cdot\frac{1}{1-\frac1z} = -\frac{1}{z}\sum_{n=0}^{\infty}\frac{1}{z^n} = -\sum_{n=0}^{\infty}\frac{1}{z^{n+1}} = -\sum_{m=1}^{\infty}\frac{1}{z^m}$$

这是**纯负幂**的洛朗级数，在 $|z|>1$ 内收敛。拆三步：

- **第一步，把「大分母」变成「$\frac1z$ 的小量」。** 在 $|z|>1$ 时 $\left|\frac1z\right|<1$，于是 $\frac{1}{1-\frac1z}=\sum\left(\frac1z\right)^n$ 合法。
- **第二步，提取 $\frac1z$ 因子。** $\frac{1}{1-z}=\frac{1}{z(\frac1z-1)}$ 的改写方式不止一种，关键是凑出「$\frac1z$ 的幂级数」。
- **第三步，重命名指标。** $\sum\frac1{z^{n+1}}$ 换 $m=n+1$ 得 $\sum_{m=1}^\infty\frac1{z^m}$，系数全是 $-1$。

**重点：同一个函数在 $|z|<1$ 与 $|z|>1$ 有完全不同的展开**——前者是非负幂，后者全是负幂。**圆环域不同，展开不同，但每个展开都在自己的圆环域内正确。** 这是洛朗级数与泰勒级数最大的认知跳跃：**展开式依附于圆环域，而不只是依附于函数。**<span class="marginnote">「展开式依附于圆环域」是初学者最难转过弯的地方。好消息是泰勒展开只是洛朗展开的特例——在 $z_0$ 的邻域（不含奇点）内，洛朗级数自动退化为泰勒级数（负幂全为零）。从这个角度，洛朗级数是更一般的语言，泰勒是它的子集。</span>

## 4 洛朗级数怎么求：实操策略

求洛朗展开几乎从不硬套系数积分，而是用代数方法「凑」：

1. **画奇点，定圆环域。** 标出 $f$ 的所有奇点，确定展开区域 $R_1<|z-z_0|<R_2$。
2. **分拆函数。** 把 $f$ 拆成「在 $z_0$ 解析的部分」与「含 $(z-z_0)$ 负幂的部分」。
3. **对每部分分别展开。** 解析部分用泰勒（或已知级数），负幂部分用「把 $\frac{1}{z-z_0}$ 当小量」的几何级数。
4. **按圆环域决定形式。** $|z-z_0|$ 较大时把 $\frac{z_0}{z}$ 当小量；较小时把 $\frac{z}{z_0}$ 当小量。

**例：** 求 $f(z)=\frac{1}{(z-1)(z-2)}$ 在 $0<|z-1|<1$ 内的洛朗展开。奇点 $z=1,2$；圆环域是绕 $z=1$、半径 $(0,1)$ 的小环（不含 $z=2$）。拆：

$$\frac{1}{(z-1)(z-2)} = \frac{1}{z-2}\cdot\frac{1}{z-1} = -\frac{1}{1-(z-1)}\cdot\frac{1}{z-1}$$

其中 $\frac{1}{z-2}=\frac{1}{(z-1)-1}=-\frac{1}{1-(z-1)}$。在 $|z-1|<1$ 内 $\frac{1}{1-(z-1)}=\sum(z-1)^n$，故

$$\frac{1}{(z-1)(z-2)} = -\frac{1}{z-1}\sum_{n=0}^{\infty}(z-1)^n = -\sum_{n=0}^{\infty}(z-1)^{n-1} = -\sum_{m=-1}^{\infty}(z-1)^m$$

**主负幂项只有 $\frac{-1}{z-1}$，其余全是非负幂。** 这也是「$z=1$ 是一阶极点」的级数特征——洛朗展开里负幂项终止于 $-\frac{1}{z-1}$ 这一项，没有更高负幂。**负幂项的最高阶数，就是奇点的阶数。**<span class="marginnote">这句观察是第五章孤立奇点分类的核心：洛朗展开中负幂项到 $-(z-z_0)^{-1}$ 为止 ⟹ 一阶极点（可去奇点则无负幂，本性奇点则负幂无穷多）。奇点类型 = 洛朗展开的负幂结构。</span>

## 5 补充：洛朗级数 vs 泰勒级数的对照

洛朗级数常被误当成「泰勒的复杂版」，其实两者是「对象不同」的两个工具。对照表如下：

| 方面 | 泰勒级数 | 洛朗级数 |
| --- | --- | --- |
| 成立区域 | 圆盘 $|z-z_0|<R$ | 圆环域 $R_1<|z-z_0|<R_2$ |
| 幂次范围 | 非负幂 $n\ge0$ | 全部整数 $n\in\mathbb{Z}$ |
| 负幂项 | 无 | 可能有（奇点指纹） |
| 中心要求 | $z_0$ 处解析 | $z_0$ 处可任意（可去心） |
| 唯一性 | 区域内唯一 | 同一环域内唯一 |

**核心差别：洛朗允许「去心」与「负幂」。** 泰勒在 $z_0$ 处解析的圆盘内展开；洛朗在「可能含奇点」的圆环域内展开——负幂项正是奇点「漏」出来的部分。

**例（同一函数两种展开）：** $\frac1{1-z}$ 在 $|z|<1$ 内是泰勒 $\sum z^n$；在 $|z|>1$ 内是洛朗 $-\sum\frac1{z^n}$。**「环域决定形式」：$|z|<1$ 无奇点（泰勒），$|z|>1$ 含 $z=1$ 的奇点信息（负幂洛朗）。**

**重点：泰勒是洛朗的特例。** 若 $z_0$ 是解析点（环域内缩为圆盘），洛朗展开的负幂项自动为零，退化为泰勒。**「洛朗更一般」意味着「能用泰勒的题洛朗也能做，反之不然」。**

**例（用洛朗思想看可去奇点）：** $\frac{\sin z}{z}$ 在 $0<|z|<\infty$ 的洛朗展开 $1-\frac{z^2}{6}+\cdots$ 无负幂——虽是洛朗展开（去心），但无负幂，说明 $z=0$ 是可去奇点。**洛朗展开同时给出「展开」与「奇点类型」。**

**辨析｜易错点：洛朗展开的「唯一性」有区域限定。** 同一函数在不同环域的洛朗展开不同——**「唯一」指同一环域内，不是全局唯一。** 别把「多个展开」误解为「不唯一」。

## 6 小结

- **洛朗级数**：$\sum_{n=-\infty}^{\infty}c_n(z-z_0)^n$，在圆环域 $R_1<|z-z_0|<R_2$ 内绝对一致收敛。
- **洛朗定理**：圆环域内解析 ⟹ 可展成洛朗级数，系数 $c_n=\frac{1}{2\pi i}\oint_C\frac{f(\zeta)}{(\zeta-z_0)^{n+1}}d\zeta$。
- **$c_{-1}$ 是留数**：$\mathrm{Res}(f,z_0)=c_{-1}=\frac{1}{2\pi i}\oint_C f\,dz$，整个第五章的中心。
- **展开依附于圆环域**：同一函数在不同圆环域有不同展开（$\frac1{1-z}$ 在 $|z|<1$ 与 $|z|>1$）。
- **实操策略**：画奇点定圆环域 → 分拆 → 每部分凑级数；泰勒是洛朗的特例。
