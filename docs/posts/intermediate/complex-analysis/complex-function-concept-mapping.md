## 为什么从复变函数开始

上一节，我们把复平面上的「形状」命名为区域。现在要给这些形状里注入「运动」——也就是函数。**函数**是整个复变函数论的主角：我们要研究的就是「什么样的函数，复平面上的哪些行为」，以及为什么这样的函数会拥有实函数望尘莫及的漂亮性质。

但一上来就会遇到一个认知上的坎：**复变函数没法像实函数那样画出「图像」。** 实函数 $y = f(x)$ 的图像是一条曲线，因为输入是一维、输出是一维，正好凑成二维平面。复变函数 $w = f(z)$ 的输入是平面上的点，输出也是平面上的点，加起来是四维——画不出来。所以我们换一种看法：**把函数看作一个「变换」，把一张平面映射成另一张平面。** 学会用「映射」的眼光看函数，是这门课最重要的心智升级。<span class="marginnote">四维确实没法直接画，但可以取巧：把 $z$ 平面上的网格、圆、射线分别送给 $f$，看它们在 $w$ 平面上变成什么形状。这种「画网格」的手法贯穿全书，也是第六章<strong>共形映射</strong>的思想雏形。</span>

## 1 复变函数的定义

**核心概念：复变函数（complex function）**：设 $G$ 是一个复数集，若有一个确定的法则 $f$，使 $G$ 内每一个复数 $z$，都有唯一确定的复数 $w$ 与之对应，则称 $w$ 是 $z$ 的**复变函数**，记作

$$w = f(z), \qquad z \in G$$

其中 $G$ 称为**定义域**，所有 $w$ 构成的集合称为**值域**。若每个 $z$ 对应唯一的 $w$，称 $f$ 为**单值函数**；若一个 $z$ 对应多个 $w$，称 $f$ 为**多值函数**。<span class="marginnote">多值函数是复分析特有的麻烦。$w = \sqrt{z}$ 在非零复数处一般有两个值，$w = \operatorname{Ln} z$ 甚至有无穷多个值。初学常在这里摔跟头——<strong>「函数」这个词在复分析里默认指单值函数</strong>，多值函数要专门处理（第二章对数、幂函数一节详谈）。</span>

由于 $z = x + iy$、$w = u + iv$，一个复变函数本质上是**两个二元实函数**的捆绑：

$$w = f(z) = u(x, y) + i\,v(x, y)$$

其中 $u = \mathrm{Re}\,f$ 称为**实部**，$v = \mathrm{Im}\,f$ 称为**虚部**。这一步「拆实部虚部」极其重要——很多复变函数的性质，最终都要翻译成关于 $u$、$v$ 的实分析命题（下一章的柯西-黎曼方程就是这样得到的）。

**例：$w = z^2$ 的实部与虚部。** 设 $z = x + iy$，则

$$z^2 = (x + iy)^2 = x^2 - y^2 + 2xy\,i$$

所以 $u(x,y) = x^2 - y^2$，$v(x,y) = 2xy$。这两个二元函数都是多项式，光滑得很——「多项式复函数 = 两个多项式实函数」。

## 2 映射：平面到平面的变换

**核心概念：映射（mapping）**：把复变函数 $w = f(z)$ 看成复平面上的点 $z$ 到复平面上的点 $w$ 的一种对应，称为**映射**。通常称 $z$ 平面上的图形被 $f$ 「映射」到 $w$ 平面上相应的图形。

实函数把区间送到区间，压缩或拉伸数轴；复变函数把**平面上的点**送到**平面上的点**，把整块区域变形成另一块区域。三种最基本的「变形」值得建立直觉：

- **平移** $w = z + c$：把整个平面平移向量 $c$，形状完全不变。
- **旋转与伸缩** $w = a z$（$a$ 为复常数）：把平面旋转 $\arg a$、并按 $|a|$ 伸缩。<span class="marginnote">复数的乘法「旋转加伸缩」在《复数的三角表示与指数表示》一节已经学过。此刻它升级为映射语言：$w = a z$ 是平面的<strong>旋转伸缩变换</strong>，是复分析里最温和的映射，也是第六章分式线性映射的基本砖块。</span>
- **反演** $w = \frac{1}{z}$：把单位圆内部的点变到外部，外部的点变到内部——圆与直线在这里开始「角色互换」，为第六章的保圆性埋伏笔。

**重点：复变函数把区域映成区域、把边界映到边界。** 当一个复变函数在某个区域上「行为良好」（单叶且解析，那是后话），它会把这块区域内部映射成另一块区域的内部，把边界曲线映射成边界曲线。这给了我们一个很强的工具：**不必逐点计算函数值，只需要跟踪边界曲线变成了什么，就知道区域变成了什么。** 第六章的共形映射全是这个思路。

## 3 公式解析：$w = z^2$ 到底做了什么

$w = z^2$ 是最简单也最富内涵的复变函数。用三角形式最容易看清它的几何作用。设

$$z = r(\cos\theta + i\sin\theta), \qquad w = \rho(\cos\varphi + i\sin\varphi)$$

则 $w = z^2$ 给出：

$$\rho = r^2, \qquad \varphi = 2\theta$$

分三步理解：

- **第一步，模平方，辐角加倍。** 这是复数的乘幂法则（德摩弗定理）在 $n=2$ 时的特例：$z^2$ 把模变成平方，把辐角变成两倍。映射 $w = z^2$ 因此是一个「**把角度摊开**」的变换。
- **第二步，看坐标分解。** 回到直角坐标：$u = x^2 - y^2$，$v = 2xy$。若把 $z$ 平面上的直线 $x = c$ 送进映射，会得到 $w$ 平面上的抛物线族；射线 $\arg z = \theta_0$ 则会映成射线 $\arg w = 2\theta_0$。角度被拉伸了一倍。
- **第三步，找「折叠」现象。** 因为 $(-z)^2 = z^2$，上半平面与下半平面被映到**同一张** $w$ 平面。也就是说 $w = z^2$ 在 $z$ 平面上是「二对一」的：$z$ 与 $-z$ 难分彼此。这也是为什么 $w = \sqrt{z}$ 作为反函数是多值的——正因为它必须同时回答「谁平方得了你」。

**辨析｜易错点：$w = z^2$ 处处可导，却不是一个「一对一」的映射。** 单值性（一个 $z$ 一个 $w$）与单叶性（一个 $w$ 一个 $z$）是两个不同的性质，初学者极易混淆。$w = z^2$ 单值但非单叶；真正单叶的区域要限制在辐角跨度不超过 $\pi$ 的角形域内（例如上半平面），此时 $w = z^2$ 才把该区域一对一地映成整个 $w$ 平面。

## 4 反函数与复合函数

与实函数一样，复变函数也可以复合与求反。

**复合**：设 $w = f(z)$ 的定义域含 $f$ 的值域，$g$ 以 $f$ 的值域为定义域，则复合函数

$$w = g(f(z))$$

把 $z$ 先经过 $f$ 再经过 $g$。复合映射在几何上就是「先变形一次，再变形一次」。

**反函数**：若 $w = f(z)$ 把 $G$ 单叶地映射为 $G^*$，则 $G^*$ 上存在**反函数** $z = f^{-1}(w)$，满足 $f^{-1}(f(z)) = z$。反函数存在的前提正是单叶性——所以 $w = z^2$ 在全平面上没有反函数，但限制到上半平面就有反函数 $w = \sqrt{z}$（取主值）。<span class="marginnote">反函数与多值性是同一枚硬币的两面：<strong>不单叶 ⇒ 反函数多值</strong>。第二章处理对数 $w = \operatorname{Ln} z$ 时，会看到它是 $w = e^z$ 的反函数，而 $e^z$ 以 $2\pi i$ 为周期、严重不单叶，所以 $\operatorname{Ln}$ 天然多值——这就是「支点」概念诞生的地方。</span>

**例：映射的复合。** 求 $w = \frac{1}{z^2}$ 在 $z = 1 + i$ 处的值。先算 $z^2 = (1+i)^2 = 2i$，再取倒数：

$$w = \frac{1}{2i} = -\frac{i}{2}$$

复合映射 $z \mapsto z^2 \mapsto 1/z^2$ 先「倍角平方」再「反演」，两步变换叠加成一次整体变形。

## 5 函数的像集与区域对应

给定定义域 $G$，全体函数值的集合 $f(G) = \{f(z) : z \in G\}$ 称为 $G$ 的**像集**。研究「某区域被某个函数映到哪里」，是复分析里反复出现的问题——它既是共形映射的预备，也是第四章幂级数收敛圆的直观来源。

**例：$w = z^2$ 把单位圆盘映到什么？** 设 $z = re^{i\theta}$，$0 \le r < 1$，$0 \le \theta < 2\pi$。则 $w = r^2 e^{2i\theta}$。当 $r$ 扫过 $[0,1)$ 而 $\theta$ 扫过 $[0, 2\pi)$ 时，$\rho = r^2$ 扫过 $[0, 1)$，$\varphi = 2\theta$ 扫过 $[0, 2\pi)$——**整个 $w$ 平面上的单位圆盘，仍然映成单位圆盘本身**。也就是说 $|z| < 1$ 在 $w = z^2$ 下不变。辐角翻倍没有造成「出圈」，因为 $\theta$ 的完整一圈让 $\varphi$ 也走完完整两圈。

**例：$w = z^2$ 把角形域 $\{z : 0 < \arg z < \frac{\pi}{2}\}$ 映成什么？** 第一象限内 $\theta \in (0, \pi/2)$，则 $\varphi = 2\theta \in (0, \pi)$——第一象限被映成**上半平面**。这是「倍角」最直接的兑现：角度范围被拉伸了一倍，象限变成半平面。<span class="marginnote">这个例子的模式——<strong>角形域经 $w = z^\alpha$ 映成更宽的角形域</strong>——是第六章共形映射计算的标准套路。现在看到的是 $\alpha = 2$ 的特例，到第六章你会见到一般的「把角度乘以 $\alpha$」把扇形映成半平面、把半平面映成全平面。</span>

**重点：写复变函数时，永远问一句「它把什么映到了什么」。** 实函数关心的是「函数值多大」，复变函数关心的是「区域变成什么形状」——后者在共形映射与积分的变形里是真正的生产力。

## 6 例题：三种基本变换的像

把三种最基础的映射各算一个像，让「区域到区域」的映射直觉落地。

**例：平移 $w = z + c$ 保持形状。** 若 $D$ 是圆盘 $|z| < 1$，则 $w = z + c$ 的像集是

$$|w - c| < 1$$

仍是圆盘，只是圆心从 $0$ 移到了 $c$。平移是「刚性运动」：区域、边界、夹角一律不变，像与原像全等。

**例：旋转伸缩 $w = az$ 的像。** 设 $a = |a| e^{i\alpha}$。$z$ 平面上的圆盘 $|z| < R$ 被映成

$$|w| < |a|\, R$$

半径乘以 $|a|$；射线 $\arg z = \theta_0$ 被映成射线 $\arg w = \theta_0 + \alpha$。于是 $w = az$ 先把平面旋转 $\alpha$、再按 $|a|$ 放大或缩小，区域变成「同心相似」的新区域。

**例：反演 $w = \frac{1}{z}$ 的像。** 设 $z = re^{i\theta}$，则

$$w = \frac{1}{r}\,e^{-i\theta}$$

圆 $|z| = r$ 被映成圆 $|w| = \frac1r$；射线 $\arg z = \theta$ 被映成射线 $\arg w = -\theta$（关于实轴对称）。**反演把单位圆的内部与外部互换**：$|z| < 1$ 映成 $|w| > 1$。<span class="marginnote">反演与「共轭倒置」会在第六章合流：<strong>莫比乌斯变换</strong> $w = \frac{az + b}{cz + d}$ 就是平移、旋转伸缩、反演三类基本映射的复合。到那时「保圆性」会作为它们的共同遗产正式登场。</span>

这三个例子是后续所有映射计算的积木：**任何复杂的映射，都是先分解成这三种基本变形，再逐块求像。** 第六章的分式线性映射之所以只需要研究「圆与直线映到圆与直线」，正是因为这三块积木各自都保圆。

## 7 小结

- **复变函数** $w = f(z)$ 是复数集到复数集的对应；拆开实部虚部得 $w = u(x,y) + i v(x,y)$，本质是两个二元实函数。
- **单值函数**默认；多值函数（如 $\sqrt{z}$）是复分析特有的研究对象，留待第二章。
- 复变函数是**平面到平面的映射**，基本变形有平移 $z + c$、旋转伸缩 $az$、反演 $1/z$。
- **$w = z^2$ 的几何**：模平方、辐角加倍（$\rho = r^2$，$\varphi = 2\theta$）；第一象限映成上半平面；$z$ 与 $-z$ 二对一，故非单叶。
- **反函数存在的条件是单叶性**；不单叶导致反函数多值。
- 研究区域映射的快捷法：**跟踪边界**——边界曲线变成什么，区域就变成什么。

在下一节，我们开始逼近真正的核心问题：复变函数在 $z$ 趋近某一点时，函数值会怎样？这就是**复变函数的极限与连续性**——你会发现，极限在复平面上比在实轴上严格得多，因为趋近的「路径」突然变得无穷多了。
