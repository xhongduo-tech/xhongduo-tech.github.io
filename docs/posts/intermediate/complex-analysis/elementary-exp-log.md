## 为什么初等函数要「重新定义」

实函数里 $e^x$、$\ln x$、$\sin x$ 你已经用得很熟。但把它们搬进复平面，不能简单地把 $x$ 换成 $z$——因为「$e^z$ 到底等于什么」并没有先天答案。数学的通行做法是：**保留实函数最核心的性质，用它来定义复版本，再验证其他性质是否依然成立**。本节先处理两个最重要的成员：指数函数与对数函数。对数函数尤其关键——它将第一次让你见识**多值函数**的威力与麻烦，这正是复分析区别于实分析的又一个标志性事件。<span class="marginnote">回想第二章的 C-R 判据：一个函数要解析，实部虚部必须满足 C-R 方程。定义初等函数时要刻意选实部虚部，使得 C-R 方程成立——这就是「按性质定义」落地的具体方式。</span>

## 1 复指数函数

**核心概念：指数函数（exponential function）**：对 $z = x+iy$，定义

$$e^z = e^{x+iy} = e^x(\cos y + i\sin y)$$

这个定义不是凭空而来：当 $y=0$ 时它退化为实指数 $e^x$；当 $x=0$ 时它是欧拉公式 $e^{iy}=\cos y + i\sin y$。上一节已验明它处处满足 C-R 方程，故 $e^z$ 是**整函数**，且 $(e^z)' = e^z$。

复指数最重要的三个性质，前两个与实指数一致，第三个是全新的：

1. **加法定理**：$e^{z_1+z_2} = e^{z_1}e^{z_2}$。
2. **恒不为零**：$|e^z| = e^x > 0$，所以 $e^z \ne 0$ 对所有 $z$ 成立。
3. **周期性**：$e^{z+2\pi i} = e^z$，周期为 $2\pi i$。<span class="marginnote"><strong>$2\pi i$ 是纯虚周期</strong>——复指数沿虚轴方向每移动 $2\pi$ 就回到自身。由此 $e^z$ 在每一条水平带上都是「周期重复」的。这解释了为什么 $\log z$ 必是多值的：指数有周期，对数自然收到无穷多个候选。</span>

**辨析｜易错点：$e^z$ 没有「实指数那种极限」。** 实函数 $\lim_{x\to-\infty}e^x = 0$、$\lim_{x\to+\infty}e^x=\infty$ 都是沿实轴说的。但在复平面里，若让 $z$ 沿虚轴趋于 $\infty$，$e^z$ 只是转圈，不趋近任何极限；若沿斜线，则可能震荡发散。因此 **$\lim_{z\to\infty}e^z$ 不存在**。写作「$e^\infty$」毫无意义。

## 2 复对数函数：多值性的第一次亮相

既然 $e^z$ 恒不为零，自然会问：**方程 $e^w = z$ 的解 $w$ 是什么？** 记 $z = re^{i\theta}$，$w = u+iv$，则

$$e^w = e^u e^{iv} = re^{i\theta} \iff e^u = r,\quad v = \theta + 2k\pi \ (k\in\mathbb{Z})$$

于是

**核心概念：对数函数（logarithm）**：

$$\mathrm{Ln}\, z = \ln|z| + i\,\mathrm{Arg}\, z = \ln r + i(\theta + 2k\pi), \qquad k \in \mathbb{Z}$$

由于辐角多值，**对数函数也是多值函数**：每一个 $z\ne 0$ 对应无穷多个对数，彼此相差 $2\pi i$ 的整数倍。这与你熟悉的实对数「一个数一个对数」完全不同。

为了得到单值函数，必须**选一个辐角分支**。通常约定取主辐角 $\arg z \in (-\pi, \pi]$，得到

**核心概念：对数主值（principal value）**：

$$\mathrm{Log}\, z = \ln|z| + i\arg z$$

其中 $\mathrm{Log}$（大写 L）表示主值。于是「$\ln$ 的真数不能为负」这条实规则被推翻：$\mathrm{Log}(-1) = \ln 1 + i\pi = i\pi$——负数的对数不再是禁区。<span class="marginnote">实分析里 $\ln x$ 的定义域是 $(0,\infty)$，复分析把定义域扩展到整个去心平面 $\mathbb{C}\setminus\{0\}$，代价是函数变多值。主值 $\mathrm{Log}$ 把幅角裁剪到 $(-\pi,\pi]$，从而在「割掉负实轴的平面」上变成单值解析函数——负实轴就是那条著名的<strong>支割线</strong>。</span>

**重点：$\mathrm{Ln}$ 与 $\mathrm{Log}$ 的关系。** 多值对数是主值加上所有整数倍的 $2\pi i$：

$$\mathrm{Ln}\, z = \mathrm{Log}\, z + 2k\pi i$$

$e^{\mathrm{Ln}\,z} = z$ 对所有 $z\ne 0$ 恒成立；但 $\mathrm{Ln}(e^z) = z$ **只在 $-\pi < \mathrm{Im}\,z \le \pi$ 时成立**——因为取主值会把虚部拉回主辐角区间。这是多值函数最容易踩的坑。

## 3 对数函数的求导与解析性

**重点：$\mathrm{Log}\, z$ 在割掉负实轴的平面内解析，且**

$$\frac{d}{dz}\mathrm{Log}\, z = \frac{1}{z}$$

验证用极坐标 C-R 方程：$u = \ln r$，$v = \theta$（主辐角），则 $u_r = \frac{1}{r}$，$v_\theta = 1$，满足 $u_r = \frac{1}{r}v_\theta$；又 $v_r = 0$，$u_\theta = 0$，满足 $v_r = -\frac{1}{r}u_\theta$。故在 $r>0$、$\theta\in(-\pi,\pi)$ 的开区域内解析，导数由公式 $f'(z)=e^{-i\theta}(u_r+iv_r)$ 给出：

$$(\mathrm{Log}\,z)' = e^{-i\theta}\left(\frac{1}{r}+i\cdot 0\right) = \frac{1}{re^{i\theta}} = \frac{1}{z}$$

**辨析｜易错点：为什么要在负实轴上「割一刀」。** 主辐角在负实轴两侧发生跳跃：$\theta$ 从 $+\pi$ 跳到 $-\pi$。跨越负实轴时 $\arg z$ 不连续，$\mathrm{Log}\,z$ 也不连续，自然不可导。所以「支割线」不是任意画的，它恰好画在主辐角的间断处。选不同的主值区间（如 $(0,2\pi]$），割线就沿正实轴——**支割线的位置取决于你对辐角的选择**。

## 4 公式解析：$e^z$ 的加法公式为什么成立

复指数的加法定理 $e^{z_1+z_2}=e^{z_1}e^{z_2}$ 是它一切运算的地基。证明只需三步：

- **第一步，两边写成定义。** 设 $z_1=x_1+iy_1$，$z_2=x_2+iy_2$。左边 $e^{z_1+z_2} = e^{(x_1+x_2)+i(y_1+y_2)} = e^{x_1+x_2}\left[\cos(y_1+y_2)+i\sin(y_1+y_2)\right]$。

- **第二步，展开右边。** 右边 $= e^{x_1}e^{x_2}(\cos y_1+i\sin y_1)(\cos y_2+i\sin y_2)$。把实数部分 $e^{x_1}e^{x_2}$ 提出，括号内按第一章学过的复数乘法公式展开：
$$(\cos y_1+i\sin y_1)(\cos y_2+i\sin y_2) = \cos(y_1+y_2) + i\sin(y_1+y_2)$$
（这正是「模相乘、辐角相加」在单位圆上的特例。）

- **第三步，拼合。** 右边 $= e^{x_1+x_2}[\cos(y_1+y_2)+i\sin(y_1+y_2)]$，与左边完全一致。证毕。

这个证明的关键是复数的乘法公式与三角和角公式的配合——**复数乘法把「角度相加」内置在代数运算里了**。加法定理还顺带推出著名的 **棣莫弗公式**：$(\cos\theta+i\sin\theta)^n = \cos n\theta + i\sin n\theta$，以及 $e^z$ 的任意次「乘幂」规则。

## 5 补充：指数对数的实战计算

把「$e^z$ 与 $\mathrm{Log}z$ 的计算」做成一组高频小练习，建立手感。

**例 1（计算 $e^z$ 的实部虚部）：** 求 $e^{2+3i}$。$e^{2+3i}=e^2(\cos3+i\sin3)$。数值：$e^2\approx7.39$，$\cos3\approx-0.99$，$\sin3\approx0.14$，故 $e^{2+3i}\approx-7.32+1.04i$。**复指数 = 实数部分（$e^x$）乘旋转（$e^{iy}$）。**

**例 2（计算 $\mathrm{Log}$）：** 求 $\mathrm{Log}(1+i)$。$|1+i|=\sqrt2$，$\arg(1+i)=\frac\pi4$，故

$$\mathrm{Log}(1+i)=\ln\sqrt2+i\frac\pi4=\frac12\ln2+i\frac\pi4$$

**多值形式：** $\mathrm{Ln}(1+i)=\frac12\ln2+i(\frac\pi4+2k\pi)$。

**例 3（方程求解）：** 解 $e^z=1+i$。$e^z=e^x e^{iy}=1+i$，故 $e^x=\sqrt2\Rightarrow x=\frac12\ln2$，$y=\frac\pi4+2k\pi$。**解是 $z=\frac12\ln2+i(\frac\pi4+2k\pi)$——无穷多个解**（周期 $2\pi i$）。这就是「指数方程无穷解」的复分析版。

**例 4（验证恒等式）：** $e^{z_1}e^{z_2}=e^{z_1+z_2}$ 用定义验证：

$$e^{z_1}e^{z_2}=e^{x_1}(\cos y_1+i\sin y_1)e^{x_2}(\cos y_2+i\sin y_2)=e^{x_1+x_2}[\cos(y_1+y_2)+i\sin(y_1+y_2)]=e^{z_1+z_2}$$

**加法公式成立（用三角和角公式）。**

**重点：$e^z$ 与 $\mathrm{Log}$ 的互逆关系是「多值→单值」的规范操作。** 给定 $z$ 求 $\mathrm{Log}$ 用主值；解方程 $e^z=w$ 用多值 $\mathrm{Ln}$。**「求值」用主值，「解方程」用多值——两套动作区分清楚。**

**辨析｜易错点：$\mathrm{Log}(z_1z_2)\ne\mathrm{Log}z_1+\mathrm{Log}z_2$（主值意义下）。** 例：$z_1=z_2=e^{i3\pi/4}$，$\mathrm{Log}(z_1z_2)$ 与 $2\mathrm{Log}z_1$ 可能差 $2\pi i$。**多值函数的「加法公式」只在分支选择相容时成立——用主值要小心边界。**

## 6 小结

- **复指数** $e^z=e^x(\cos y+i\sin y)$：整函数、$(e^z)'=e^z$、恒不为零、**以 $2\pi i$ 为周期**；$\lim_{z\to\infty}e^z$ 不存在。
- **复对数** $\mathrm{Ln}\,z = \ln|z|+i\,\mathrm{Arg}\,z$ 是**多值函数**，各分支相差 $2\pi i$。
- **主值** $\mathrm{Log}\,z=\ln|z|+i\arg z$ 在割掉负实轴的平面内解析，$(\mathrm{Log}\,z)'=\frac{1}{z}$。
- **关系** $e^{\mathrm{Ln}z}=z$ 恒成立，$\mathrm{Ln}(e^z)=z$ 仅在主值区间内成立。
- 负实轴是主值分支的**支割线**；选不同的辐角区间，割线位置随之改变。

在下一节，我们将用指数与对数当积木，搭出剩下的初等函数：**幂函数 $z^\alpha$、三角函数 $\sin z$、$\cos z$ 与双曲函数**，看看「多值性」如何传染给 $z^\alpha$，而三角函数的周期性又如何与指数纠缠在一起。
