## 为什么从点集开始

前面的几节，我们把复数安放在了复平面上，给它配好了模、辐角、指数表示，甚至把平面卷成了球面。但到目前为止，我们谈的还只是「单个复数」。复变函数要讨论的是**一类**复数的集体行为——函数在什么地方有定义、在什么范围内能积分、在什么曲线上做围道积分——而这些都要求我们先把「复平面上的一块形状」严格定义出来。

这一节要回答一个看似朴素的问题：**什么样的点集才算「一块像样的领地」？** 答案里藏着三个词：**开集、连通、区域**。而区域又分**单连通**与**多连通**，这个分别将在第三章成为柯西积分定理能否直接使用的分水岭。<span class="marginnote">「单连通」与「多连通」是第三章<strong>柯西积分定理</strong>的关键前提：定理要求区域单连通。很多初学者在第三章才发现「区域里有个洞就出问题」，根源就在这一节没把连通的分别立住。</span>

## 1 距离与邻域：点集的基本度量

复平面上两个点 $z_1 = x_1 + i y_1$ 与 $z_2 = x_2 + i y_2$ 之间，天然有一套距离——就是复数差的模：

$$d(z_1, z_2) = |z_1 - z_2| = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$

这套距离把复平面变成了一个「度量空间」：它满足距离应有的全部直觉（非负、对称、三角不等式），而我们上一节学过的三角不等式 $|z_1 + z_2| \le |z_1| + |z_2|$ 正是「两边之和大于第三边」的复平面版本。<span class="marginnote">把距离抽象出来，就是<strong>度量空间（metric space）</strong>的概念，这是第二级《拓扑学》与《泛函分析》的入口。复平面只是无数度量空间中的一个样本——学会在复数上做分析，等于提前预习了度量空间的一切论证。</span>

**核心概念：邻域（neighborhood）**。以 $z_0$ 为圆心、$\delta > 0$ 为半径的开圆盘

$$N(z_0, \delta) = \{ z : |z - z_0| < \delta \}$$

称为 $z_0$ 的 **$\delta$-邻域**。把它挖掉圆心，得到

$$N'(z_0, \delta) = \{ z : 0 < |z - z_0| < \delta \}$$

称为**去心邻域**。邻域是复分析里最基础的工具：所有「局部」的概念——内点、边界点、极限、导数——都要借它来表达。比如上一节说的无穷远点邻域 $\{z : |z| > R\} \cup \{\infty\}$，就是把「圆外部」当作无穷远点的 $\delta$-邻域。

## 2 点集的分类：内点、边界点、外点与聚点

给定一个点集 $G$，复平面上任意一点都可以按与 $G$ 的「亲疏」分类。

- **内点（interior point）**：存在 $\delta > 0$，使 $N(z_0, \delta) \subset G$。通俗地说，$z_0$ 周围有一整圈都属于 $G$。
- **外点（exterior point）**：存在 $\delta > 0$，使 $N(z_0, \delta)$ 与 $G$ 不相交。
- **边界点（boundary point）**：$z_0$ 的**任意** $\delta$-邻域里，既有点属于 $G$，又有点不属于 $G$。<span class="marginnote">边界点的定义不要求 $z_0$ 自己在 $G$ 里。比如开圆盘 $|z|&lt;1$ 的边界点 $z=1$ 并不属于圆盘，但它的任何邻域都同时含圆盘内外的点。所有边界点组成<strong>边界（boundary）</strong>。</span>

这三类把整个平面划成了互不相交的三块：$G$ 的内部、外部、边界。**边界点是三类中最「黏糊」的**——它既不属于内部也不属于外部，是 $G$ 与补集之间的「膜」。

再引入两个更精细的概念。若 $z_0$ 的任意去心邻域都含有 $G$ 的点，称 $z_0$ 为 $G$ 的**聚点（accumulation point）**；聚点可以属于 $G$，也可以不属于。若 $z_0 \in G$，且存在 $\delta > 0$ 使去心邻域内没有 $G$ 的其他点，称 $z_0$ 为**孤立点（isolated point）**。

**辨析｜易错点：内点一定是聚点，但聚点不一定是内点。** 例如 $G = \{z : |z| \le 1\}$（闭圆盘），边界上的点 $z = 1$ 是聚点但不是内点；$z = 0$ 既是内点也是聚点。而孤立点是聚点的反面：点集 $\{1\}$ 中，$z = 1$ 是孤立点，却不是聚点（去心邻域里没有 $G$ 的点了）。

## 3 开集、闭集、有界集与区域

**核心概念：开集（open set）**：点集 $G$ 中每一点都是 $G$ 的内点，则称 $G$ 为开集。**闭集（closed set）**：若 $G$ 的补集是开集，或等价地 $G$ 包含自己的全部聚点，则称 $G$ 为闭集。

**辨析｜易错点：「开」和「闭」不是反义词，存在既不闭也不开的集合。** 半开半闭的条带 $\{z : 0 \le \mathrm{Re}\,z < 1\}$，边界上的直线 $\mathrm{Re}\,z = 0$ 上的点不是内点（所以不是开集），而聚点 $\mathrm{Re}\,z = 1$ 不在集合里（所以也不是闭集）。「开」与「闭」的对称性只在**全平面与空集**处同时成立——它们既开又闭。

**有界集（bounded set）**：存在正数 $M$，使 $G$ 内一切点满足 $|z| \le M$。既**有界又闭**的集合称为**紧集（compact set）**。<span class="marginnote">紧集在复分析里的作用是「取极限不出圈」：紧集里任意点列都有收敛到自身某个点的子列（Bolzano-Weierstrass 性质）。第四章证明幂级数在收敛圆内一致收敛时，就要反复把问题限制到紧集上做。</span>

现在可以给出本节最重要的定义：

**核心概念：区域（domain）**：满足以下两条的平面点集 $D$ 称为区域：

1. $D$ 是**开集**；
2. $D$ 是**连通的**——即 $D$ 内任意两点，都能用**完全含于 $D$ 的折线**连接起来。<span class="marginnote">这里的连通是「弧连通」，比拓扑里的「连通」更强但更直观。为什么要求折线而不是任意曲线？因为折线便于计算与判断，也是第三章构造积分路径时实际使用的对象。</span>

区域与它的边界合在一起，记作 $\overline{D} = D \cup \partial D$，称为**闭区域**。

## 4 公式解析：用 ε-邻域判定内点与边界点

点集理论的全部论证，最终都要回到**用邻域做逐点检验**。把「内点」「边界点」的判定翻译成可操作的公式，是本节的核心技能。

**内点的判定**：$z_0$ 是 $G$ 的内点，当且仅当

$$\exists\,\delta > 0 \quad \text{使得} \quad N(z_0, \delta) \subset G$$

**边界点的判定**：$z_0$ 是 $G$ 的边界点，当且仅当对**一切** $\delta > 0$ 同时有

$$N(z_0, \delta) \cap G \neq \varnothing \quad \text{且} \quad N(z_0, \delta) \cap (\mathbb{C} \setminus G) \neq \varnothing$$

分三步理解这两组式子：

- **第一步，看量词顺序。** 内点要求「**存在**某个 $\delta$」（有一个足够小的圈能装进 $G$）；边界点要求「**任意** $\delta$」（不管圈多小，都同时踩到 $G$ 内外的点）。量词从「存在」换成「任意」，性质就整个翻转——这正是分析学里「局部」语言的精髓。
- **第二步，看方向。** 内点判定是「向外缩」：$N(z_0,\delta)$ 要整个落进 $G$，所以 $G$ 必须在 $z_0$ 附近「足够胖」。边界点判定是「向外探」：任何邻域都要同时碰到 $G$ 与 $\mathbb{C}\setminus G$，说明 $z_0$ 附近 $G$ 与补集「犬牙交错」，$z_0$ 恰好卡在分界线上。
- **第三步，动手验证一个例子。** 设 $G = \{z : |z| < 1\}$，取 $z_0 = 0$。对 $\delta = \frac{1}{2}$，有 $N(0, \frac12) = \{|z| < \frac12\} \subset G$，故 $0$ 是内点。取 $z_0 = 1$（在边界上）。对任意 $\delta > 0$，圆盘 $N(1, \delta)$ 里既有模小于 $1$ 的点（如 $1 - \frac{\delta}{2}$），又有模大于 $1$ 的点（如 $1 + \frac{\delta}{2}$），所以 $1$ 是边界点。

**重点：一个集合是开集，当且仅当它不含有自己的任何边界点。** 这条等价陈述把「开」从「每点是内点」改写成了「边界在外面」，是判断一个集合是否开集的快捷方式。

## 5 曲线：积分要走的路径

复变函数的积分（第三章）是**沿曲线的积分**，所以必须先把「曲线」精确化。

**核心概念：连续曲线（continuous curve）**：设 $z(t) = x(t) + i y(t)$ 在闭区间 $[a, b]$ 上连续，则 $\Gamma = \{z(t) : a \le t \le b\}$ 称为复平面上的一条**连续曲线**，$z(a)$ 与 $z(b)$ 分别称为起点与终点。若 $z(t_1) \neq z(t_2)$（$t_1 \neq t_2$，端点除外），称曲线为**简单曲线（simple curve）**，即不自相交。若 $z(a) = z(b)$，则称**闭曲线（closed curve）**；既简单又闭的曲线称为**简单闭曲线（simple closed curve）**，也叫**若尔当曲线（Jordan curve）**。<span class="marginnote"><strong>若尔当曲线定理</strong>（Jordan curve theorem）：任何一条简单闭曲线都把平面分成内部与外部两个区域。这定理「显然」得让人觉得不值得证明，但严格的证明却需要相当精细的拓扑功夫——它是直观与严格之间的一道著名鸿沟。</span>

若 $x'(t)$ 与 $y'(t)$ 连续且不同时为零，称曲线为**光滑曲线（smooth curve）**；由有限条光滑曲线首尾相接而成的曲线叫**按段光滑曲线（piecewise smooth curve）**。复分析里讨论的积分路径通常都是按段光滑的——它保证积分有意义，又足够一般。

## 6 单连通与多连通：区域里有没有洞

现在回到区域。区域可以按「有没有洞」分成两类，这个分别比看起来重要得多：

**核心概念：单连通区域（simply connected domain）**：若区域 $D$ 内任意一条简单闭曲线，都可在 $D$ 内连续收缩成一点，则称 $D$ 为单连通区域。等价地说，$D$ 内任何一条简单闭曲线所围成的区域，全部含于 $D$ 内。

**多连通区域**：非单连通的区域称为多连通区域——直观地说，就是区域里「有洞」。

![区域与连通性：左边开圆盘是单连通区域，右边圆环是多连通区域，绕洞的闭曲线不能缩成一点](/images/complex-analysis/point-sets-regions-connectedness-1.svg)

看几个典型例子：

- **开圆盘 $|z| < 1$**：单连通。它没有洞，任何闭曲线都可以缩成一个点。
- **全平面 $\mathbb{C}$**：单连通。
- **圆环 $1 < |z| < 2$**：多连通。绕中间洞一圈的闭曲线 $|z| = \frac32$ 无法在圆环内缩成一点——要缩就得穿过内边界 $\Gamma_2$。
- **去心圆盘 $0 < |z| < 1$**：多连通。**挖掉一个点就制造了一个洞**，圆心这个「点洞」足以让区域变成多连通。这是最容易漏掉的反例。

**辨析｜易错点：挖掉一个点，区域就从单连通变成多连通。** 初学者常以为「洞必须足够大才算洞」，其实不然：去心圆盘 $0 < |z| < 1$ 里，绕原点转一圈的闭曲线无法缩成一点，因为缩到圆心时必须经过不属于区域的点 $z = 0$。一个点就能制造障碍——这正是后面研究 $f(z) = \frac{1}{z}$、$\log z$ 时反复撞上的那个「点」。

单连通与多连通的分别，将在第三章以定理的形式兑现：**柯西积分定理**要求区域单连通，而**复合闭路定理**专门处理多连通区域——把绕洞的积分拆成沿每个洞边界的积分之和。换句话说，这一节「数洞」，第三章「绕洞积分」，第五章「在洞（孤立奇点）上取留数」，是同一件事的三个阶段。<span class="marginnote">多连通区域里的积分可以「变形」到洞的边界上。第五章的<strong>留数定理</strong>正是把这条思路推向极致：闭曲线包围的每个孤立奇点贡献一个留数，积分就等于 $\sum$ 留数。洞的个数，就是留数的个数。</span>

## 7 小结

- **邻域** $N(z_0, \delta) = \{z : |z - z_0| < \delta\}$ 与**去心邻域**是全部局部概念的工具；无穷远点的邻域是圆外部。
- 点按与点集 $G$ 的关系分为**内点、外点、边界点**；另有**聚点**与**孤立点**。内点必是聚点，聚点不一定是内点。
- **开集** = 每点都是内点 = 不含边界点；**闭集** = 含全部聚点 = 补集为开集。开与闭不互斥。
- **有界集**：$|z| \le M$；有界且闭称为**紧集**。
- **区域** = **开集** + **连通**（任意两点可用 $D$ 内折线连接）；区域加边界为**闭区域**。
- **单连通区域**：任意简单闭曲线可缩成一点；有洞的区域是**多连通**。**挖掉一个点就能制造洞**。
- **曲线**：连续曲线、简单曲线、闭曲线、若尔当曲线、光滑曲线——第三章积分的路径就是按段光滑曲线。

在下一节，我们终于要把函数装进这些区域里：定义**复变函数**，并第一次体会它与实函数的最大不同——它不再是「数轴到数轴」的对应，而是**平面到平面的映射**。
