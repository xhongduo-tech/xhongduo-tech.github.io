## 为什么「圆环域」决定一切

上一节指出洛朗展开依附于圆环域。这一节把这句话变成肌肉记忆：**拿到函数，先画奇点图，把所有可能的圆环域找出来，再在每个圆环域里分别展开。** 同一个 $f$ 在不同圆环域的展开是不同「乐曲」，但每个都在自己的区域里正确收敛。这套「画奇点 → 定环域 → 逐环展开」的流程，是洛朗展开的标准动作，也是第五章奇点分类与留数计算的直接前戏。<span class="marginnote">洛朗展开的工程观：函数是「奇点 + 解析骨架」的组合。每个奇点都向四周「辐射」自己的负幂指纹，而圆环域就是「你在哪条缝里看这个函数」的视角。视角不同，看到的展开自然不同。</span>

## 1 如何确定所有圆环域

设 $f$ 的全部奇点为 $a_1, a_2, \dots, a_m$，要围绕中心 $z_0$ 展开。**圆环域的个数 = 以 $z_0$ 为圆心、以各奇点距离为半径画同心圆，相邻半径之间的环带各是一个圆环域。** 具体步骤：

**第一步，列出奇点到 $z_0$ 的距离**，从小到大排序：$d_1<d_2<\cdots<d_m$。
**第二步，写出所有圆环域**：$0<|z-z_0|<d_1$、$d_1<|z-z_0|<d_2$、……、$d_m<|z-z_0|<\infty$。
**第三步，逐环展开**：每个环域对应一个展开，环内不含奇点、边界含奇点。

**例：** $f(z)=\frac{1}{(z-1)(z-2)}$，以 $z_0=0$ 为中心。奇点 $1,2$，距离 $1,2$。圆环域有三个：$|z|<1$、$1<|z|<2$、$|z|>2$。每个环域一个展开。

**重点：环域 $0<|z-z_0|<d_1$ 是最常见的**——它围绕一个孤立奇点，排除中心本身。$d_1\to 0$ 时退化为「去心邻域」，正是研究单个奇点行为的舞台。<span class="marginnote">「去心邻域 $0<|z-z_0|<\rho$」是复分析最常出没的舞台：它允许 $z$ 任意接近 $z_0$ 但永远不踩到 $z_0$ 本身。孤立奇点的定义、洛朗展开、留数计算全部发生在这个去心邻域里。</span>

## 2 三个圆环域的完整展开：一个贯穿例题

**例：** 求 $f(z)=\frac{1}{(z-1)(z-2)}$ 在三个圆环域（以 $0$ 为中心）内的洛朗展开。

先做铺垫——部分分式：

$$f(z) = \frac{1}{z-2} - \frac{1}{z-1}$$

**展开一（$|z|<1$）：** 两项都是「小 $z$」视角。$\frac{1}{z-2}=-\frac12\cdot\frac{1}{1-z/2}=-\frac12\sum\frac{z^n}{2^n}$，$\frac{1}{z-1}=-\frac{1}{1-z}=-\sum z^n$。故

$$f(z) = -\frac12\sum_{n=0}^{\infty}\frac{z^n}{2^n} + \sum_{n=0}^{\infty}z^n = \sum_{n=0}^{\infty}\left(1-\frac{1}{2^{n+1}}\right)z^n, \qquad |z|<1$$

这其实是**泰勒展开**（无负幂，因为圆环域不含奇点）。

**展开二（$1<|z|<2$）：** 关键区别：对 $\frac{1}{z-1}$，$z$ 比 $1$ 大，要按「大 $z$」展开；对 $\frac{1}{z-2}$，$z$ 比 $2$ 小，按「小 $z$」展开。

- $\frac{1}{z-1}=\frac1z\cdot\frac{1}{1-1/z}=\frac1z\sum_{n=0}^{\infty}\frac1{z^n}=\sum_{n=1}^{\infty}\frac1{z^n}$（纯负幂）；
- $\frac{1}{z-2}=-\frac12\sum_{n=0}^{\infty}\frac{z^n}{2^n}$（非负幂）。

$$f(z) = \sum_{n=1}^{\infty}\frac{1}{z^n} - \frac12\sum_{n=0}^{\infty}\frac{z^n}{2^n}, \qquad 1<|z|<2$$

**展开三（$|z|>2$）：** 两项都按「大 $z$」。$\frac{1}{z-1}=\sum_{n=1}^{\infty}\frac1{z^n}$，$\frac{1}{z-2}=\frac1z\cdot\frac{1}{1-2/z}=\frac1z\sum_{n=0}^{\infty}\left(\frac2z\right)^n=\sum_{n=0}^{\infty}\frac{2^n}{z^{n+1}}=\sum_{m=1}^{\infty}\frac{2^{m-1}}{z^m}$。故

$$f(z) = \sum_{n=1}^{\infty}\frac{1-2^{n-1}}{z^n}, \qquad |z|>2$$

**纯负幂级数。**<span class="marginnote">三个展开放在一起看：$|z|<1$ 是全非负幂（泰勒），$1<|z|<2$ 是「负幂 + 非负幂」混合，$|z|>2$ 是全负幂。越往外，奇点的「负幂指纹」越占主导——函数在大圆外的行为完全由奇点结构支配。</span>

**辨析｜易错点：「大 $z$ 展开」与「小 $z$ 展开」的选择。** 判断标准只有一条：$\left|\frac{a}{z}\right|<1$ 还是 $\left|\frac{z}{a}\right|<1$。当 $|z|>|a|$ 时用 $\frac{1}{z-a}=\frac1z\frac{1}{1-a/z}$（大 $z$ 视角）；当 $|z|<|a|$ 时用 $\frac{1}{z-a}=-\frac1a\frac{1}{1-z/a}$（小 $z$ 视角）。**别凭感觉，画个同心圆图确认 $z$ 在哪个区间。**

## 3 含「中心奇点」的展开：$0<|z|<R$

当中心 $z_0$ 本身是奇点时，圆环域是去心邻域 $0<|z-z_0|<R$，展开必然含负幂项。

**例：** 求 $f(z)=\frac{\sin z}{z^3}$ 在 $0<|z|<\infty$ 内的洛朗展开。$z=0$ 是奇点。利用 $\sin z=\sum_{n=0}^{\infty}\frac{(-1)^n z^{2n+1}}{(2n+1)!}$：

$$\frac{\sin z}{z^3} = \sum_{n=0}^{\infty}\frac{(-1)^n z^{2n+1}}{(2n+1)!\,z^3} = \sum_{n=0}^{\infty}\frac{(-1)^n z^{2n-2}}{(2n+1)!} = \frac{1}{z^2} - \frac{1}{3!} + \frac{z^2}{5!} - \cdots$$

**洛朗展开的负幂项最高到 $z^{-2}$**（来自 $\sin z$ 的首项 $z$ 除以 $z^3$），这意味着 $z=0$ 是**二阶极点**（见第五章）。**只含偶次幂是 $\sin z/z^3$ 的对称性所致**——$\frac{\sin z}{z^3}$ 是偶函数，展开自然只含偶次项。<span class="marginnote">展开的对称性检查是很好的验算手段：偶函数的洛朗展开只含偶次幂，奇函数只含奇次幂。$\frac{\sin z}{z^3}$ 为偶函数，展开里 $z$ 的指数全是偶数（$z^{-2}, z^0, z^2, \dots$），恰好吻合。</span>

**例：** 求 $f(z)=e^{1/z}$ 在 $0<|z|<\infty$ 内的展开。$e^u=\sum\frac{u^n}{n!}$，令 $u=1/z$：

$$e^{1/z} = \sum_{n=0}^{\infty}\frac{1}{n!\,z^n} = 1 + \frac{1}{z} + \frac{1}{2!z^2} + \frac{1}{3!z^3} + \cdots$$

**负幂项无穷多**——这是本性奇点的级数特征（第五章）。$e^{1/z}$ 在 $z=0$ 的展开不像前例那样「负幂到某阶为止」，而是无限延伸。

## 4 公式解析：为什么「负幂项到 $-k$ 为止」对应「$k$ 阶极点」

这是洛朗展开与奇点分类的接口，拆开它：

$$\text{洛朗展开的负幂最高阶} = \text{奇点的阶}$$

- **第一步，观察结构。** $\frac{\sin z}{z^3}$ 的展开 $\frac{1}{z^2}-\frac{1}{3!}+\cdots$ 负幂到 $z^{-2}$ 为止。而 $\sin z$ 的泰勒首项是 $z$（一次幂），除以 $z^3$ 得 $z^{-2}$。**「分子泰勒的最低阶」减去「分母的幂」决定负幂的最高阶。**

- **第二步，推广到一般有理函数。** 若 $f(z)=\frac{g(z)}{(z-z_0)^k}$ 且 $g(z_0)\ne0$、$g$ 在 $z_0$ 解析，则 $z_0$ 是 $k$ 阶极点，洛朗展开负幂到 $(z-z_0)^{-k}$ 为止：
$$f(z) = \frac{g(z_0)}{(z-z_0)^k} + \frac{g'(z_0)}{(z-z_0)^{k-1}} + \cdots + \text{非负幂}$$
- **第三步，三种奇点的级数判据。**
  - **可去奇点**：洛朗展开无负幂（泰勒）。
  - **$k$ 阶极点**：负幂项到 $(z-z_0)^{-k}$ 为止，$k$ 有限。
  - **本性奇点**：负幂项无穷多。

**直觉：** 洛朗展开的负幂项像奇点的「能量谱」——能量有限则极点，能量无限则本性奇点。第五章的孤立奇点分类，几乎就是把这条「谱系判据」展开成系统理论。

## 5 补充：圆环域展开的系统练习

把「定环域 → 逐环展开」的流程用两道题完整走通，特别是「多环域」的情形。

**例 1（三环域展开）：** 求 $f(z)=\frac1{(z-1)(z-2)}$ 在 $|z|<1$、$1<|z|<2$、$|z|>2$ 三个环域的展开。

- **$|z|<1$（泰勒）**：两个奇点都在外。$\frac1{z-2}=-\frac12\sum\frac{z^n}{2^n}$，$\frac1{z-1}=-\sum z^n$。合并 $f=\sum\left(1-\frac1{2^{n+1}}\right)z^n$。
- **$1<|z|<2$**：$z-1$ 按大 $z$（$\frac1z\sum\frac1{z^n}$），$z-2$ 按小 $z$。$f=\sum_{n=1}^{\infty}\frac1{z^n}-\frac12\sum\frac{z^n}{2^n}$。
- **$|z|>2$**：都按大 $z$。$f=\sum_{n=1}^{\infty}\frac{1-2^{n-1}}{z^n}$。

**关键动作：每个环域重新判断「哪些奇点在环内、哪些在环外」，分别选「大 $z$/小 $z$」展开。** 三个展开对应三个视角，彼此不同但各自正确。

**例 2（围绕奇点展开）：** 求 $f(z)=\frac1{(z-1)(z-2)}$ 在 $0<|z-1|<1$ 内的展开。中心移到 $z=1$：$\frac1{z-2}=\frac1{(z-1)-1}=-\frac1{1-(z-1)}$。故

$$f(z)=\frac1{z-1}\cdot\frac{-1}{1-(z-1)}=-\sum_{n=0}^{\infty}(z-1)^{n-1}=-\frac1{z-1}-1-(z-1)-\cdots$$

**主负幂只有 $\frac{-1}{z-1}$——$z=1$ 是一阶极点**（负幂到 $-1$ 为止）。**展开自动暴露奇点阶数。**

**重点：展开的形式由「环域 + 中心」双重决定。** 同样的 $f$，围绕 $0$ 与围绕 $1$ 展开完全不同；同样的中心，不同半径环域也不同。**做题先写「中心 $z_0$ + 环域」，再动手展开。**

**辨析｜易错点：$|z-z_0|<R$ 的「内环」也可能是 $0<|z-z_0|<R$（去心）。** 中心本身是奇点时用去心邻域，展开必含负幂。**先看中心是否奇点，决定要不要去心。**

## 6 小结

- **圆环域的确定**：以 $z_0$ 为圆心、奇点距离为半径画同心圆，相邻半径之间各是一个圆环域。
- **逐环展开**：每个环域一个展开；$|z|<d_1$ 时泰勒，外层逐步引入负幂。
- **大 $z$/小 $z$ 视角**：$|z|>|a|$ 用 $\frac1z\cdot\frac{1}{1-a/z}$，$|z|<|a|$ 用 $-\frac1a\cdot\frac{1}{1-z/a}$。
- **去心邻域 $0<|z-z_0|<R$**：研究孤立奇点的标准舞台，展开含负幂。
- **级数判据**：负幂到 $-k$ 为止 ⟹ $k$ 阶极点；无负幂 ⟹ 可去奇点；负幂无穷多 ⟹ 本性奇点。

在下一节，我们将看到洛朗级数最实用的收益：**利用洛朗级数计算积分**。$\oint_C f\,dz$ 恰好等于 $2\pi i$ 乘以展开式中 $\frac{1}{z-z_0}$ 的系数——于是围道积分被降维成「读系数」。这是第五章留数理论的前奏。
