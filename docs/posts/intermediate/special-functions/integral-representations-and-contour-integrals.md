## 为什么从积分表示开始

前面各章里，我们见到同一个特殊函数被反复「换装」：Gamma 有欧拉积分与 Weierstrass 乘积两种长相，$2F_1$ 有级数、微分方程与欧拉积分三种身份，Bessel 有级数、生成函数与泊松积分。**为什么同一个函数需要这么多表示？** 答案在应用：级数适合小自变量、乘积适合看零点与极点、积分表示适合推导恒等式与渐近行为、围道积分则能同时给出解析延拓与第二类解。<span class="marginnote">这一章是「方法论」章节：前面每一章都在具体函数里用到积分表示，这里把它们提炼成一般武器。理解「表示的等价性」是阅读任何特殊函数文献的钥匙——论文里随手写的 $J_\nu(z) = \frac{1}{2\pi i}\oint e^{\frac{z}{2}(t - 1/t)}t^{-\nu-1}dt$，本质就是「Bessel 的围道积分版本」。</span>围道积分还把特殊函数与复变函数论最漂亮的工具（留数定理、解析延拓、鞍点法）焊接在一起——下一章《渐近展开与最速下降法》将在此直接起飞。

## 1 为什么要研究「表示」：三张面孔的互补

同一个特殊函数，站在三个视角看，能看见三样不同的东西：

**级数表示**（幂级数）：定义直接、系数透明，适合 $|z|$ 小时的数值与恒等式验证；但对大自变量收敛慢，且常只给出解析分支的一部分。
**积分表示**：把函数写成沿路径的积分，权重自带物理意义（Beta 核、指数核），是推导变换公式与渐近展开的发动机；积分路径可变形，从而进入复平面。
**围道积分表示**：积分路径是复平面上的闭合（或无穷）围道，可以绕开奇点、通过留数定理求值，并**自动给出解析延拓**——用级数定义不了的区域，围道积分照样定义。<span class="marginnote">「解析延拓的唯一性」是这一切的合法依据：复变函数论保证，只要两个表示在某个非空开集上一致，它们就是同一个函数。因此级数在 $|z|\lt 1$ 收敛、围道在 $|z|>1$ 收敛，两者并不矛盾——它们只是同一个解析函数在不同区域的分支表现。</span>

三类表示互相转化的经典范例是 Gamma 函数：欧拉积分 $\Gamma(z) = \int_0^\infty t^{z-1}e^{-t}dt$ 只在 $\operatorname{Re}z>0$ 收敛，而 **Hankel 围道积分**把积分路径改成绕负实轴的围道，使定义在全复平面成立（除极点外），并且直接看出 $1/\Gamma$ 是整函数。

## 2 一般理论：从微分方程出发的围道解

为什么「方程的解」可以写成「积分」？有一套通用机制。设我们有二阶线性方程

$$
y'' + P(z)\,y' + Q(z)\,y = 0
$$

**办法一：Laplace 变换型表示**。猜测 $y = \int_C e^{zt}w(t)\,dt$，代入方程后通过分部积分，把关于 $z$ 的微分方程转化为关于 $t$ 的**代数或一阶方程**——这被称为「把方程变成 $t$ 侧的传输问题」。路径 $C$ 的选择要保证分部积分的边界项消失，这通常要求 $C$ 是复平面上「两端伸向使 $e^{zt}w(t)\to0$ 的方向」的路径。<span class="marginnote">这个套路在《复变函数与积分变换》里的 Laplace 变换一节有严格形式：对常系数方程，$w(t)$ 满足的是「代数」方程；对变系数方程（Bessel、Legendre），$w(t)$ 满足一阶或更简单的方程。Bessel 函数 $J_\nu(z) = \frac{1}{2\pi i}\oint_C e^{\frac{z}{2}(t-1/t)}t^{-\nu-1}dt$ 就是这样得到的：$e^{zt}$ 换成 $e^{\frac{z}{2}(t-1/t)}$ 正是生成函数的围道版本。</span>

**办法二：Riemann 表示**。对只在有限个正则奇点有奇性的方程，解可以写成「沿连接奇点的围道」的积分，被积函数来自奇点的局部分支结构。超几何方程的解就有这样的 Riemann–Papperitz 表示。

**办法三：用留数定理求和级数**。围道积分还能把「无穷级数」变成「围道积分」。Euler 与后来的研究者的著名技巧是

$$
\sum_{n=-\infty}^{\infty} f(n) = \frac{1}{2\pi i}\oint_C \pi\cot\pi z\, f(z)\, dz
$$

右端围道的留数恰在整数点给出 $f(n)$——这把「求和」变成「围道积分」，是解析数论与特殊函数求和里反复出现的王牌。<span class="marginnote">这条公式的价值在于：围道可以被变形，变形后新积分往往更易处理。像 $\sum_n \frac{1}{(n+a)^2} = \pi^2/\sin^2\pi a$ 一类经典和，都能用这条谱系秒证。它在《解析数论》与《复变函数与积分变换》中有完整展开。</span>

**一个完整范例：Gamma 的 Hankel 表示。** 把上面三招合起来用一次。考虑围道 $C$：从 $+\infty$ 沿实轴上方到 0，绕原点正向一圈，再沿实轴下方回到 $+\infty$（这是一个「钥匙孔」围道，把正实轴的上岸与下岸分开）。考察积分

$$
\frac{1}{2\pi i}\int_C (-t)^{-z}e^{-t}\,dt
$$

其中 $(-t)^{-z}$ 按 $e^{-z\ln(-t)}$ 取分支。被积函数除 $t=0$ 处的本性奇点外全平面解析，把围道压拢到正实轴两侧，上岸与下岸的差正好是 $(e^{-i\pi z} - e^{i\pi z})(-1)^z$ 类的因子，配上 $t^{z-1}e^{-t}$ 的欧拉积分，最终得到

$$
\frac{1}{\Gamma(z)} = \frac{1}{2\pi i}\int_C (-t)^{-z}e^{-t}\,dt
$$

**这条 Hankel 表示的价值在于：右边的围道对一切复数 $z$ 收敛**，于是它直接给出了 $1/\Gamma$ 的全平面定义——没有右半平面的限制，且一眼看出 $1/\Gamma$ 是整函数。<span class="marginnote">「把实轴积分改写成钥匙孔围道」的收益是双重的：一方面扫清了收敛半平面，另一方面把函数方程的证明变成了「平移围道」的几何操作。这套手法在 Gamma、Bessel、超几何三条线上反复使用，是围道积分最典型的教学范例。</span>

## 3 公式解析：Bessel 的围道积分表示

以第一类 Bessel 函数为标本，看一条围道积分表示如何诞生。

**目标**：证明 $J_\nu(z) = \frac{1}{2\pi i}\oint_C e^{\frac{z}{2}(t - 1/t)}\,t^{-\nu-1}\,dt$，其中 $C$ 是绕 $t=0$ 的闭围道（正向）。

**第一步，写被积函数的级数**：$e^{\frac{z}{2}(t - 1/t)} = \sum_{n=-\infty}^{\infty}J_n(z)\,t^n$（这是雅可比生成函数，见《Bessel 函数》一章）。于是被积函数为 $\sum_n J_n(z)\,t^{n-\nu-1}$。
**第二步，用留数定理**：$\oint_C t^{m}\,dt = 0$（$m\ne-1$）而 $\oint_C t^{-1}dt = 2\pi i$。因此围道积分「筛选」出 $n - \nu - 1 = -1$ 即 $n=\nu$ 的那一项。
**第三步，读出结论**：$\frac{1}{2\pi i}\oint_C \sum_n J_n(z)t^{n-\nu-1}dt = \frac{1}{2\pi i}\cdot 2\pi i\cdot J_\nu(z) = J_\nu(z)$。
- **第四步，推广到非整数阶**：当 $\nu$ 非整数，$t^{-\nu-1}$ 是 $t=0$ 的多值函数，围道应取**割线围道**（Hankel 型：从 $-\infty$ 沿负实轴到 0，绕 $t=0$ 一圈，再沿负实轴返回）。此时同样的推导给出**对任意复阶都成立**的围道表示——这正是围道积分优于实积分表示的地方：**不受收敛半平面限制，直接给出解析延拓**。<span class="marginnote">Hankel 型围道（在割线平面上绕奇点一圈）是处理多值被积函数的标准手段：它把「分支跳跃」吸收进围道几何。Gamma 的 Hankel 表示、Bessel 的 Hankel 型围道、以及下一章鞍点法的围道变形，用的是同一种「在割线平面上思考」的思维。</span>

## 4 围道积分带来的三大红利

**红利一：解析延拓。** 级数表示局限于收敛圆内，围道表示可以在全平面（除奇点外）定义函数。Gamma、$2F_1$、Bessel 的围道表示都提供了级数到不了区域的「合法身份证」。

**红利二：第二类解。** 很多二阶方程（Bessel、Legendre）的第二个独立解，天然来自「绕着多值奇点走一圈」的积分：走一圈带回一个相位因子，两个相位因子不同的组合就是线性独立的两个解。**这个「绕圈产生新解」的机制，解释了为什么 $Y_\nu$、$Q_n$（第二类 Legendre 函数）总是和对数项绑在一起。**<span class="marginnote">例如第二类 Legendre 函数 $Q_n(z) = \frac12\int_{-1}^1\frac{P_n(t)}{z-t}dt$（$z\notin[-1,1]$）——它把 $P_n$ 当作核、在割线上取积分，得到的正是 Legendre 方程与 $P_n$ 线性无关的第二个解。这类「沿割线的积分」在数学物理方法里俯拾即是。</span>

**红利三：渐近展开的原料。** 围道积分把函数写成「沿鞍点路径」的积分，用最速下降法即可提取大自变量下的首项——这是下一章的全部内容，围道表示在此成为渐近分析的前置条件。

## 5 若干标准积分表示的清单

把最有用的积分表示集中成一张「工具卡」，便于查阅：

| 函数 | 积分表示 | 适用条件 |
| --- | --- | --- |
| $\Gamma(z)$ | $\int_0^\infty t^{z-1}e^{-t}dt$ | $\operatorname{Re}z>0$ |
| $B(p,q)$ | $\int_0^1 t^{p-1}(1-t)^{q-1}dt$ | $\operatorname{Re}p,\operatorname{Re}q>0$ |
| ${}_2F_1(a,b;c;z)$ | $\frac{\Gamma(c)}{\Gamma(b)\Gamma(c-b)}\int_0^1 t^{b-1}(1-t)^{c-b-1}(1-zt)^{-a}dt$ | $\operatorname{Re}c>\operatorname{Re}b>0$ |
| $J_\nu(z)$ | $\frac{1}{2\pi i}\oint_C e^{\frac{z}{2}(t-1/t)}t^{-\nu-1}dt$ | 任意复 $\nu$，围道绕 $0$ |
| $Y_\nu(z)$ | $\frac{J_\nu\cos\nu\pi - J_{-\nu}}{\sin\nu\pi}$（或割线积分） | 第二类解 |
| $Q_n(z)$ | $\frac12\int_{-1}^1\frac{P_n(t)}{z-t}dt$ | $z\notin[-1,1]$ |
| $I_\nu(z)$ | $\frac{1}{2\pi i}\oint_C e^{\frac{z}{2}(t + 1/t)}t^{-\nu-1}dt$ | 修正 Bessel，围道绕 $0$ |
| $K_\nu(z)$ | $\frac{\pi}{2}\frac{I_{-\nu}(z) - I_\nu(z)}{\sin\nu\pi}$ | 第二类修正 Bessel，衰减解 |

**修正 Bessel 函数** $I_\nu$ 与 $K_\nu$ 值得单独提一句：它们是 Bessel 方程中 $x^2$ 前符号取正（即 $x^2y'' + xy' - (x^2+\nu^2)y=0$）时的解，对应「指数型增长/衰减」而非振荡。$K_\nu$ 在 $x\to+\infty$ 时指数衰减，是物理上「圆柱外场的有限解」——静电场里圆柱导体外部的势、热传导里的温度分布，最终都落到 $K_0$ 或 $K_1$ 这类函数上。

这些表示有一条共同的结构：**被积函数都是一族「已知函数」的乘积，积分路径承担解析延拓与分支选择**。<span class="marginnote">读表时注意每条的「适用条件」栏——积分表示多数带收敛条件（参数范围或路径方向），无条件套用会得到错误结果。例如欧拉积分表示 $2F_1$ 要求 $\operatorname{Re}c>\operatorname{Re}b>0$，越界时需用解析延拓后的围道版本。</span>

## 6 应用与易错点

**恒等式证明**：变换公式（欧拉变换、高斯变换）几乎都是「对积分表示做变量代换」的产物。
**解析延拓与函数方程**：反射公式、加倍公式都能从围道/积分表示推出。
**数值计算**：许多特殊函数在参数困难区（大阶、大参数）用围道积分 + 数值积分最稳。
- **量子场论与统计物理**：Mellin–Barnes 积分（用 Gamma 的围道表示把积分化成 Gamma 比值的围道积分）是计算 Feynman 图与配分函数的常用工具。<span class="marginnote">Mellin–Barnes 表示把形如 $\int_0^\infty x^{s-1}f(x)dx$ 的 Mellin 变换反演写成 $\frac{1}{2\pi i}\int_{c-i\infty}^{c+i\infty}x^{-s}\mathcal{M}f(s)ds$ 的围道积分——这种「把积分换到 Gamma 平面上」的技巧，是现代解析计算（超几何函数的 MB 表示）的标准开场。</span>

**一个完整算例：用积分表示导出 $\Gamma(1/2) = \sqrt{\pi}$。** 这是「表示的等价性」最便宜的一次兑现。欧拉积分取 $z = 1/2$，得 $\Gamma(1/2) = \int_0^\infty t^{-1/2}e^{-t}dt$。作代换 $t = u^2$（$dt = 2u\,du$），$t^{-1/2}dt = 2du$，积分化为 $\Gamma(1/2) = 2\int_0^\infty e^{-u^2}du$。右端的被积函数没有初等原函数，但可以用极坐标法整体求出：记 $I = \int_0^\infty e^{-u^2}du$，则 $I^2 = \int_0^{\pi/2}\int_0^\infty e^{-r^2}r\,dr\,d\theta = \frac{\pi}{2}\cdot\frac12 = \frac{\pi}{4}$，故 $I = \sqrt{\pi}/2$，代回即得 $\Gamma(1/2) = \sqrt{\pi}$。<span class="marginnote">这个 $\sqrt{\pi}$ 同时解释了《概率论与数理统计》里正态分布归一化常数 $1/\sqrt{2\pi}$ 的来路：高斯积分与 Gamma 积分在 $\Gamma(1/2)=\sqrt{\pi}$ 处相遇。$t=u^2$ 这类代换正是下一章推导渐近展开时反复出现的动作。</span>

**第二个算例：Beta 积分的同一招。** 把 $t = \sin^2\theta$ 代入 $B(1/2,1/2) = \int_0^1 t^{-1/2}(1-t)^{-1/2}dt$，得 $dt = 2\sin\theta\cos\theta\,d\theta$，于是 $t^{-1/2}(1-t)^{-1/2}dt = 2d\theta$，积分化为 $\int_0^{\pi/2}2\,d\theta = \pi$。这与公式 $B(p,q) = \Gamma(p)\Gamma(q)/\Gamma(p+q)$ 取 $p=q=1/2$ 给出的 $\Gamma(1/2)^2/\Gamma(1) = \pi$ 完全一致——两个算例从两条路走到同一个数，再一次印证「同一函数的多重表示彼此等价」。

**一个求和→围道的小练习。** 第 2 节的公式 $\sum_{n=-\infty}^{\infty}f(n) = \frac{1}{2\pi i}\oint_C \pi\cot\pi z\,f(z)dz$ 不是摆设。取 $f(z) = 1/(z+a)^2$，被积函数 $\pi\cot\pi z/(z+a)^2$ 在 $z=-a$ 处有二阶极点，留数计算给出 $\sum_{n=-\infty}^{\infty}\frac{1}{(n+a)^2} = \frac{\pi^2}{\sin^2\pi a}$——这正是第 2 节边注预告的经典结果，也是「把级数搬上围道、再让留数替我们求和」最直观的示范。

**辨析｜易错点：** 第一，围道的**方向**决定符号——Bessel 的围道表示里 $C$ 正向绕 $0$ 得 $J_\nu$，反向会得到 $-J_\nu$。第二，多值函数的**分支切割**必须先定（通常沿负实轴），否则被积函数在同一围道上取值不一致。第三，「积分表示对哪些参数范围成立」不能省——欧拉积分表示 $2F_1$ 的收敛条件一旦突破，就需要换围道版本。

## 7 小结

- **三种表示互补**：级数定义直白、积分推导恒等式、围道提供解析延拓与第二类解；解析延拓唯一性保证三者是同一函数。
- **围道解的一般机制**：Laplace 型表示把二阶方程化为 $t$ 侧传输问题；留数定理把级数求和化为围道积分。
- **Bessel 围道表示** $J_\nu(z)=\frac1{2\pi i}\oint_C e^{\frac{z}{2}(t-1/t)}t^{-\nu-1}dt$ 用留数定理从生成函数一行导出，割线围道给出任意复阶。
- **三大红利**：解析延拓、第二类解（$Y_\nu,Q_n$）、渐近展开原料。
- **标准清单**：Gamma/Beta/$2F_1$/$J_\nu$/$Q_n$

在下一节，我们将进入《渐近展开与最速下降法》：把这一章的围道表示沿鞍点路径变形，用最速下降法提取大自变量下的渐近首项——届时你会看到，积分表示不只是恒等式的来源，更是计算的发动机。
