## 为什么从生成函数方法开始

回顾前几章，一条线索若隐若现：Legendre 多项式的生成函数 $1/\sqrt{1-2xt+t^2}$、Bessel 函数的生成函数 $e^{\frac{x}{2}(t-1/t)}$、Hermite 的 $e^{2xt-t^2}$——**几乎每一族特殊函数都自带一把「母函数」**。生成函数方法（generating function method）把这些散例提升为一种系统方法论：**用一个函数把一族特殊函数全部打包，通过函数的幂级数展开、代数运算与微分方程，一次获得整族的恒等式、递推关系与积分性质**。<span class="marginnote">生成函数的思想远不止于特殊函数：组合数学里 Catalan 数的 $C(t) = (1-\sqrt{1-4t})/(2t)$、概率论里矩母函数 $M(t) = \mathbb{E}e^{tX}$、信号处理里 Z 变换，都是同一架「把离散序列打包成解析函数」的机器。这一章的方法是横向贯穿整个数理工具的。</span>学它，等于学会从「一个个函数」的视角跃迁到「一族函数」的视角。

## 1 生成函数的三种类型

按打包方式，生成函数主要分三类，适用场景不同：

**普通生成函数（ordinary generating function, OGF）**：

$$
G(t) = \sum_{n=0}^{\infty} a_n\, t^n
$$

把数列 $(a_n)$ 装进幂级数。Legendre 的 $1/\sqrt{1-2xt+t^2} = \sum_n P_n(x)t^n$ 就是 OGF。<span class="marginnote">OGF 最适合「组合计数」：两个 OGF 相乘 $(a_n)*(b_n)$ 得到的系数正是卷积 $\sum_k a_k b_{n-k}$——「选 $k$ 个 A 再选 $n-k$ 个 B」的组合计数自动浮现。这就是「生成函数把组合推理变成代数运算」的准确含义。</span>

**指数生成函数（exponential generating function, EGF）**：

$$
E(t) = \sum_{n=0}^{\infty} a_n\, \frac{t^n}{n!}
$$

Hermite 的 $e^{2xt - t^2} = \sum_n H_n(x)\frac{t^n}{n!}$ 用的是 EGF。EGF 适合「带排列数」的计数（如排组合、标号结构），因为 $n!$ 吸收掉了排列重数。

**狄利克雷级数（Dirichlet 生成函数）**：

$$
D(s) = \sum_{n=1}^{\infty} \frac{a_n}{n^s}
$$

适合数论性的数列（如黎曼 Zeta 函数的 Euler 乘积）。三类选择的标准是**看数列的运算在哪种包装下变成最自然的代数运算**——卷积 → OGF，排列 → EGF，乘性 → Dirichlet。

## 2 从生成函数能读出什么

**（一）读出整族。** 生成函数的 Taylor 系数就是整族特殊函数。给一个函数，展开，取系数——一次获得全部成员，无需逐项定义。

**（二）读出递推关系。** 对生成函数求导或代入微分方程，比较 $t^n$ 的系数，就得到整族的递推。以 Legendre 为例：对 $G(x,t) = (1-2xt+t^2)^{-1/2}$ 求 $\partial/\partial t$，可得

$$
(n+1)P_{n+1}(x) - (2n+1)xP_n(x) + nP_{n-1}(x) = 0
$$

这正是三项递推——**从生成函数「不费力气」地推出正交多项式的三项递推，是这一章最漂亮的示范**。<span class="marginnote">为什么能「不费力气」？因为生成函数满足一个一阶偏微分方程（如 $(1-2xt+t^2)\partial_t G = (x-t)G$），把方程按 $t^n$ 展开、比较系数，递推关系就一行行地冒出来。这与「从微分方程推递推」殊途同归，但路径更短。</span>

**（三）读出恒等式。** 两个不同的代数表达式若给出同一个函数，它们的系数必然逐项相等——这是「生成函数证明恒等式」的万能钥匙。例如 $(1-2xt+t^2)^{-1/2}$ 关于 $x\to -x$ 的对称性直接给出 $P_n(-x) = (-1)^n P_n(x)$。

**一个完整的微型实例：用生成函数解递推。** 设数列 $a_n$ 满足 $a_{n+1} = 2a_n + 1$，$a_0 = 0$。三步走：

**第一步，构造 OGF**：令 $G(t) = \sum_{n\ge0}a_n t^n$，把递推两边同乘 $t^{n+1}$ 并对 $n\ge0$ 求和，得到 $G(t) - a_0 = 2tG(t) + \frac{t}{1-t}$。
**第二步，解出函数**：代入 $a_0=0$，$G(t) = \frac{t}{(1-t)(1-2t)} = \frac{1}{1-2t} - \frac{1}{1-t}$。
**第三步，再展开**：$G(t) = \sum(2^n - 1)t^n$，故 $a_n = 2^n - 1$。

这三步是「求解递推」的通用模板：**递推 → 生成函数方程 → 闭式函数 → 展开得通项**。把它与特殊函数联系起来的正是同一条流水线：Legendre 的递推给 $G=(1-2xt+t^2)^{-1/2}$，反过来从 $G$ 的展开又得到 $P_n$ 的闭式。<span class="marginnote">组合数学里几乎所有线性常系数递推（Fibonacci、Lucas、错排）都能用这个模板机械化求解；而特殊函数的三项递推（比 Fibonacci 多一项、系数含 $x$）则是它的「变系数」版本——后者正是本章第 3 节要处理的场景。</span>

## 3 公式解析：从生成函数到正交性与积分

生成函数不只是「产出系数」，它还能**证明整族的整体性质**，最典型的是正交性与范数。

**目标**：用生成函数证明 Legendre 多项式在 $[-1,1]$ 上正交。

- **第一步，写下两个生成函数的乘积对 $x$ 的积分**：

$$
\int_{-1}^{1}\frac{1}{\sqrt{1-2xt+t^2}}\frac{1}{\sqrt{1-2xs+s^2}}\,dx = \sum_{m,n} t^m s^n \int_{-1}^1 P_m(x)P_n(x)\,dx
$$

- **第二步，直接算这个积分**：做变量代换，利用 $\int_{-1}^1(1-2xu+u^2)^{-1/2}dx$ 的显式可积性，得到只含 $ts$ 的组合 $\frac{1}{ts}\ln\frac{1+\sqrt{ts}}{1-\sqrt{ts}}$。
- **第三步，比较系数**：右边展开成 $\sum_k (\text{常数}) (ts)^k$——**只含 $(ts)^k$ 的项**，意味着所有 $m\neq n$ 的交叉项系数为零，即 $\int P_mP_n = 0$（$m\neq n$）。而 $(ts)^k$ 的系数给出范数 $\int P_k^2 = 2/(2k+1)$。<span class="marginnote">这个证明的美妙在于「整体化」：不逐个验证正交性，而是用一个积分 + 系数比较同时处理全部 $m,n$。它展示了生成函数作为「整族证明工具」的威力——这种「打包处理」的思想在现代解析组合里被发扬光大（D-finite 函数、符号化方法）。</span>
**第四步，推广**：同样的套路对 Bessel（用加法公式）、Hermite（用高斯积分）都能重演——**生成函数 → 乘积积分 → 系数比较**，是证明一族正交性质的统一剧本。

## 4 生成函数与微分方程：D-finite 函数

生成函数与特殊函数的关系是双向的：

**方向一**：一族特殊函数满足二阶常微分方程（如 Legendre 方程），那么它的 OGF $G(x,t)$ 满足一个**偏微分方程**——前文已见。
**方向二（更深刻）**：如果某数列的生成函数是**D-finite（满足一个线性常微分方程）** 的函数，那么该数列满足**线性递推**——这一对应由「函数满足 ODE ⇄ 系数满足递推」给出。

具体地，设 $F(t) = \sum a_n t^n$ 满足 $p_0(t)F' + p_1(t)F + p_2(t) = 0$（多项式系数），代入并比较系数，就得到 $a_n$ 的线性递推。**这条「函数 → 递推」的机器是符号计算（如 Mathematica、SymPy 的 `ore_algebra`）的理论基础**——判定一个函数是否 D-finite、并自动导出其递推，是计算代数里的标准算法。<span class="marginnote">D-finite 类对代数运算封闭（和、积、组合、反演……），因此是「可计算特殊函数」的天然疆界。数值上，知道线性递推就能用 ODE 的初值方法快速算整列；`scipy` 与 `mpmath` 里许多特殊函数正是靠「递推 + 局部展开」实现的。</span>

## 5 生成函数在组合、概率与物理中的应用

**组合数学**：Catalan 数、Bell 数、分拆数 $p(n)$ 的 OGF $\prod_{k\ge1}(1-x^k)^{-1}$、Stirling 数的 OGF/EGF——生成函数是组合计数的第一语言。<span class="marginnote">分拆数的生成函数 $\sum p(n)x^n = \prod_{k=1}^\infty(1-x^k)^{-1}$ 是数论与组合的经典桥：Euler 五角数定理、Hardy–Ramanujan 渐近公式都从它出发。Ramanujan 的分拆同余 $p(5n+4)\equiv 0 \pmod 5$ 也是这个 OGF 的模性质。</span>
**概率论**：矩母函数 $M_X(t) = \mathbb{E}e^{tX} = \sum \mathbb{E}X^n t^n/n!$ 就是 $(\mathbb{E}X^n)$ 的 EGF；特征函数是它的虚参数版本。概率分布的卷积对应矩母函数相乘——与 OGF 卷积同一原理。<span class="marginnote">矩母函数与特殊函数交织最深：Gamma 分布的矩母函数 $(1-t)^{-\alpha}$ 的二项展开系数正是 $(\alpha)_n/n!$——超几何级数的系数又出现了。概率与特殊函数的这个「偶遇」在数理统计教材里几乎每一章都能遇到。</span>
- **量子力学与统计物理**：配分函数、相干态的生成、二次型高斯积分的 Wick 定理，都能用生成函数统一表述。
- **图论与算法**：树、括号匹配、随机图的结构计数全部用 OGF/EGF；「符号化方法」把「组合类」自动翻译成生成函数方程。

## 6 应用与易错点

- **求解递推**：给定递推，构造生成函数 → 解出函数 → 再展开，三步解决组合数列闭式。
- **证明恒等式**：两个表达式是同一函数 → 系数相等。
- **推导整族性质**：三项递推、正交性、范数、加法定理，都能从生成函数批量导出。
- **数值与符号**：D-finite 判定与自动递推导出是计算机代数的基础设施。

**辨析｜易错点：** 第一，**OGF 与 EGF 不可混用**——$e^{2xt-t^2}$ 是 Hermite 的 EGF，若误当 OGF 展开会得到完全不同的「函数」（符号也不对）。第二，**收敛域不是重点**：生成函数常常在形式幂级数（formal power series）的意义下使用，不关心收敛半径，只关心系数代数——严格讲时要用「形式幂级数」语言，这与「解析函数」语言是不同的框架。第三，比较系数时要小心起点：从 $n=0$ 还是 $n=1$ 起算，决定常数项是否参与。

## 7 小结

- **三类生成函数**：OGF $\sum a_n t^n$（卷积）、EGF $\sum a_n t^n/n!$（排列）、Dirichlet（乘性），按数列运算选包装。
- **三样产出**：读出整族（Taylor 系数）、读出三项递推（对生成函数求导比较系数）、读出恒等式（同一函数的两种表达式）。
- **整体证明**：生成函数乘积积分 + 系数比较，一次证明整族正交性与范数。
- **D-finite ↔ 线性递推**：函数满足多项式系数 ODE ⇄ 系数满足线性递推，是符号计算的理论基础。
- 生成函数贯通组合计数、概率矩、量子配分与图论结构。
