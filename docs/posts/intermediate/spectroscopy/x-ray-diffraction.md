## 为什么从 X 射线衍射开始

前面十篇的所有光谱，测的都是「分子本身」：键、官能团、骨架、构象。
但有一个终极问题它们回答不了——**分子里的每个原子到底坐落在三维空间的哪个精确位置？
** 光谱给的是平均值、间接量，而 X 射线衍射（X-ray diffraction）直接给出**电子密度的三维地图**：小分子全结构、蛋白质折叠、晶体的堆积方式，精度高达千分之一埃。
它是结构生物学与晶体化学的「黄金标准」，也是本专题从「光谱」走向「衍射」的分水岭。
<span class="marginnote">本专题对标教材为 Atkins《Physical Chemistry》第 11 版 Focus 16；布拉格父子因晶体衍射共获 1915 年诺贝尔物理学奖，其中老布拉格主张粒子说、小布拉格用波动说正确解释了衍射——科学进步常发生在两代人的争论里。
</span>

## 1 为什么必须用 X 射线

要「看清」原子，光的波长必须与原子间距（约 1–3 Å）同数量级。
可见光波长 4000–7000 Å，远不够用；而**X 射线的波长（约 0.5–2.5 Å）恰好与晶格间距匹配**——这是 X 射线衍射能成立的第一个前提。
<span class="marginnote">经典光学里「分辨极限 ≈ 波长」的直觉在这里成立：波长匹配，晶体才可能「看」到原子间距。
用电子衍射、中子衍射也是同理——只是各自「看」的物理量不同（电子看电荷，中子看原子核与磁矩）。
</span>

但单独一束 X 射线照单分子，散射太弱。
于是第二个前提登场：**晶体是天然放大器**——周期性排列的亿万个重复单元（unit cell）把同一散射信号叠加起来，形成可测的衍射斑点。
**X 射线衍射的物理是「周期结构的傅里叶变换」**：晶体是实空间里的周期函数，衍射花样就是它在倒易空间（reciprocal space）里的频谱。
<span class="marginnote">这里与 NMR 的 FID→FT 是同一个思想：NMR 从时域信号做傅里叶变换得到频率谱，X 射线从晶体的实空间周期结构做傅里叶变换得到衍射花样。
傅里叶变换是贯穿本博客多条主线的共同数学。
</span>

## 2 布拉格定律：把衍射当反射

1912 年劳厄发现 X 射线通过晶体产生衍射点；1913 年布拉格父子给出最简洁的解释：**把晶体的平行原子面当成一面面「镜子」**，X 射线在相邻晶面间的反射会产生光程差。

![布拉格衍射：nλ = 2d sinθ](/images/spectroscopy/x-ray-diffraction-1.svg)

**布拉格定律（Bragg's law）**：

$$n\lambda = 2d\sin\theta$$

其中 $d$ 是晶面间距，$\theta$ 是**掠射角**（入射方向与晶面的夹角，注意不是与法线的夹角），$n$ 是衍射级数（整数）。
只有当 $2d\sin\theta$ 恰好等于波长的整数倍时，各晶面的反射才**同相叠加**（相长干涉），形成衍射峰。
<span class="marginnote">θ 是「掠射角」是布拉格定律最大的坑：中学光学里入射角对着法线，布拉格定律的 θ 对着晶面。
图上阴影区的标注一旦画错，nλ = 2d sinθ 就推不出来了。
</span>

**重点：衍射出现的条件是「路径差恰好是波长整数倍」**——这是整个衍射理论的出发点，它把「晶面间距 d」与「可测角度 θ」直接挂钩：测出 θ，就得到 d；测出一族 θ，就得到整组晶面间距——晶胞的尺寸由此确定。

## 3 公式解析：布拉格定律 nλ = 2d sinθ

**把相邻两条晶面反射的光程差拆开看，这个公式几乎是自己推出来的：**

**第一步，画几何**：射线 1 在表面晶面 A 点反射，射线 2 穿透到下一层晶面（垂直间距 d）在 B 点反射。两条反射线最后平行射出。
- **第二步，算光程差**：射线 2 多走的距离 = AB 段的下行加回程的「多出部分」。以晶面法线为参照，每条路径的水平分量抵消，净多出的路程是 $2d\sin\theta$——d 是面间距，θ 是掠射角。<span class="marginnote">把 d 沿射线方向投影：每条射线在垂直方向穿过的厚度是 d，投影到射线方向得到 d sinθ，来回两程共 2d sinθ。三角函数的投影运算在这里是纯几何，不必背。</span>
- **第三步，干涉判据**：光程差为 $n\lambda$（n 为整数）时同相增强，得 $n\lambda = 2d\sin\theta$。n=1 为主峰，n=2、3 为高阶级数（强度递减）。

**易错点：** θ 的取值有上限（sinθ ≤ 1），所以 $d \ge \lambda/2$ 才可能衍射——晶面间距太小时即使掠射角最大也凑不出相长条件。
这就是为什么不同波长适合探测不同尺度的结构：X 射线对原子间距，中子对磁结构。

## 4 结构因子与相问题：强度的数学

布拉格定律告诉你衍射「出现在哪个角度」，却没说「有多强」。
衍射强度由**结构因子（structure factor）**决定——它把晶胞里每个原子的贡献按相位相加：

$$F(hkl) = \sum_{j} f_j\, e^{2\pi i\,(h x_j + k y_j + l z_j)}$$

其中 $(h,k,l)$ 是**米勒指数（Miller indices）**（衍射点的三维坐标），$(x_j,y_j,z_j)$ 是第 j 个原子在晶胞里的分数坐标，$f_j$ 是它的散射因子（原子散射本领）。
**实测强度 $I(hkl) \propto |F(hkl)|^2$**——强度只给振幅、丢了相位。

**核心概念：相问题（phase problem）**：电子密度 $\rho(\mathbf{r})$ 是 $F(hkl)$ 的傅里叶逆变换，要重建电子密度必须同时知道每个 $F(hkl)$ 的**振幅和相位**；但探测器只记录振幅。
如何找回丢失的相位，是晶体学百年来的核心难题。
<span class="marginnote">相位信息的丢失是因为「平方损失」：I ∝ |F|² 把复数 F 的虚部信息抹掉了。
解决思路各有妙招：重原子法（用重原子的强散射逼近相位）、帕特森法（用 |F|² 的傅里叶直接出原子间距离）、直接法（用数学关系从振幅反推相位）、以及生物领域的神器——同晶置换与分子置换。
2012 年的冷冻电镜革命则绕开了晶体学，直接把相位留在衍射图里。
</span>

**重点：晶体学是「测振幅、猜相位、傅里叶重建」的三步曲**——测衍射图很容易，难在把相位「猜」准，然后用一次傅里叶逆变换把电子密度画出来。

## 5 从电子密度到原子结构

一旦拿到足够多衍射点的振幅（通常几千到几十万条），并按某种方法确定相位，就能计算电子密度图：

$$\rho(\mathbf{r}) = \frac{1}{V}\sum_{hkl} F(hkl)\, e^{-2\pi i\,(hx + ky + lz)}$$

在电子密度图上，原子呈现为密度峰——**峰的位置就是原子坐标，峰的形状反映原子种类**（重元素峰高、轻元素峰矮）。
从电子密度图出发，晶体学家能：<span class="marginnote">现代小分子晶体学已经「流水线化」：自动寻峰、自动精修、自动验证（R 因子、残差密度），一台桌面 X 光衍射仪几小时就能出一个小分子结构。
而蛋白质晶体学仍是「一场战役」——长晶体难、衍射弱、相问题难解，一个结构打磨数年并不罕见。
</span>

1. **定坐标**：峰中心即原子坐标，给出键长、键角、二面角——化学结构的最直接证据；
2. **看对称**：空间群、晶系、不对称单元数决定分子如何堆积；
3. **建模与精修**：把候选结构放进密度图，用最小二乘法调整参数，让计算强度逼近实测强度（以 R 因子衡量吻合度）。

**易错点：** 晶体结构是「晶胞里的平均结构」——如果分子在晶胞里无序或热运动强烈，电子密度会糊成一片，键长测出来偏短。
报告的键长通常比真实值短约 0.01 Å（振动收缩效应），精确键长要考虑温度校正。

## 6 衍射在化学与生命科学里的坐标

X 射线衍射早已是常规化学利器，但它的野心不止于此：

**小分子结构**：配合物、药物的绝对构型（配合反常散射测绝对构型）、反应中间体晶体学；
- **粉末衍射（XRD）**：多晶样品不用单晶，出「指纹图谱」用于物相鉴定——材料学、矿物学、药品晶型控制全靠它；
- **蛋白质晶体学**：血红蛋白、溶菌酶到核糖体，数以万计的生物大分子结构定义了现代结构生物学；
- **材料科学**：应力、织构、薄膜厚度、原位相变——衍射是材料「看内部」的眼睛。<span class="marginnote">与前面的光谱对照：光谱给「分子内」的信息（键、官能团），衍射给「原子坐标」与「晶格几何」。对小分子，二者互为补充——先光谱定骨架，再衍射定精确定位与立体化学。对蛋白质，衍射几乎是结构信息的唯一来源（冷冻电镜在 2017 年后才成为主角）。</span>

## 7 小结

- **为什么用 X 射线**：波长（0.5–2.5 Å）与原子间距匹配；晶体把弱散射周期性叠加成可测衍射。
- **布拉格定律**：$n\lambda = 2d\sin\theta$，θ 是掠射角；光程差 $2d\sin\theta$ 为波长整数倍时相长干涉。
- **结构因子**：$F(hkl) = \sum_j f_j e^{2\pi i(hx_j+ky_j+lz_j)}$，强度只给振幅，相位丢失。
- **相问题**：探测器只有 $|F|^2$，重建电子密度必须「测振幅、猜相位、傅里叶逆变换」。
- **电子密度图**：峰位即原子坐标，键长键角直接读出；晶体学是三步曲：衍射-相位-重建。

在下一节，我们从「衍射的 X 光」转向「散射的可见光」：**拉曼光谱与 SERS**——一束激光打进分子，绝大部分光直穿而过，但极少数光被「偷走」或「借来」能量，泄露分子的振动秘密。
