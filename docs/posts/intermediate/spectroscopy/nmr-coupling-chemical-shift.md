## 为什么从耦合与化学位移开始

上一篇我们知道了每个氢有属于自己的化学位移 δ，还有积分给出氢数——但拿到一张真实 1H 谱，你会发现大多数峰不是单根棒，而是**被劈裂成一簇**：三重峰、四重峰、复杂多重峰。
这些劈裂不是仪器噪声，而是**自旋-自旋耦合（spin-spin coupling）**——相邻氢的核自旋通过成键电子「隔空传话」，把一个峰拆成几何图案。
读懂图案，你就能读出谁和谁是邻居、甚至判断立体化学。
可以说，1H 谱 90% 的信息量都在这劈裂里。
<span class="marginnote">本专题对标教材为 Williams & Fleming《Spectroscopic Methods in Organic Chemistry》第 3 章；本篇的「等性」判定与 Karplus 方程是后续二维 NMR 与结构鉴定综合应用的基础工具。
</span>

## 1 化学位移的规律：电负性是总指挥

先把上一篇的位移规律做成可预测的**加法模型**。
质子 δ 由周围的**去屏蔽效应**决定，三大来源：

1. **诱导效应（电负性）**：相邻原子越电负性，拉走电子密度越多，δ 越大。
$\ce{-CH3}$（0.9）< $\ce{-CH2Br}$（3.4）< $\ce{-CH2Cl}$（3.5）< $\ce{-CH2F}$（4.3），每多一个卤素、每近一个碳，δ 递增约 0.2–0.5 ppm。<span class="marginnote">Shooley 曾给出预测化学位移的经验公式：δ = 0.23 + Σ(各取代基的增量)。
这类「基值 + 增量」公式与 Woodward–Fieser 规则同构——经验化学的通用算法。
</span>
2. **各向异性效应（磁各向异性）**：芳环的环电流、双键、三键的 π 电子在磁场中产生局部反磁场，使某些区域去屏蔽、某些区域屏蔽。
芳环氢落在去屏蔽区（6.5–8.5），而恰在芳环平面上下方的质子被屏蔽（如某些环内氢可到 0 以下）。
**π 体系的磁各向异性让「δ 高低」不再是简单的电负性排序**。
3. **氢键**：氢键削弱屏蔽，使活泼氢（OH、NH）δ 增大且随浓度、温度漂移——这也是活泼氢常无固定 δ 的原因。
<span class="marginnote">「氢键使 δ 移动」是判断活泼氢的利器：往样品里滴一滴 D2O，活泼氢峰消失（被氘代），残留的峰就是你该好好解读的碳骨架信号。
D2O 交换实验是 NMR 实验的第一课。
</span>

**易错点：** 别拿「电负性」去解释芳香氢的高 δ——那是各向异性效应，与诱导效应是两套机制。
同样的提醒适用于烯氢（4.5–6.5，受双键各向异性影响）。

## 2 自旋-自旋耦合与 n+1 规则

氢核的磁矩有两种取向（α、β，即「向上」与「向下」），各自产生微小局部磁场。
相邻氢的取向会轻微改变你观察氢感受到的总磁场，于是共振频率裂成 2 个、3 个…… 这被称为**自旋-自旋耦合（spin-spin coupling）**，其大小用**耦合常数（coupling constant）J** 衡量，单位 Hz。

对一组**等价氢**而言，相邻 $n$ 个等价氢会把峰劈成 $n+1$ 条，峰强度比符合**帕斯卡三角形（Pascal's triangle）**——这就是著名的 **n+1 规则**：<span class="marginnote">为什么是帕斯卡三角形？
因为每个相邻氢的 α/β 取向各占一半，n 个氢的取向组合服从二项分布——1:2:1、1:3:3:1、1:4:6:4:1…… 这就是把「组合数学」写进了谱图。
概率论里的二项分布在这里直接长成峰形。
</span>

1 个相邻氢 → 二重峰（1:1）；
- 2 个相邻氢 → 三重峰（1:2:1）；
- 3 个相邻氢 → 四重峰（1:3:3:1）；
- 邻苯二甲酸乙酯式的链越长，图案越复杂，峰向「多重峰」过渡。

**重点：n+1 规则说的是「相邻等价氢的个数」，不是「相邻氢的个数」**——如果相邻的 3 个氢彼此不等价，劈裂会逐级进行，峰数远多于 4，图案也失去简单的整数比。
是否「等价」成为读谱的第一个关键判断，见下节。

## 3 耦合常数 J：谱图里的标尺

J 是**通过成键传递**的磁相互作用强度，有三个重要性质：

1. **与磁场无关**：J 的单位是 Hz，不管 400 MHz 还是 900 MHz 仪器，同一对氢的 J 不变——这是它和化学位移（ppm）最根本的区别；
2. **与键数相关**：同碳上的两个氢（2J，同碳耦合）约 10–15 Hz；相邻碳上的氢（3J，邻位耦合）约 6–8 Hz；更远的 4J、5J 通常小到看不见（除非跨 π 体系）；
3. **J 相等 ⇔ 彼此耦合**：如果两组峰的劈裂距离完全相同（J 相等），它们一定互相耦合、互为邻居。
这是读谱时「找邻居」的核心判据——**两个多重峰共享同一 J，就是同一条键的两端**。
<span class="marginnote">把这个思想推广：二维 COSY 谱（第 7 篇）做的正是「把共享 J 的峰自动连线」的工作。
理解了 J，二维谱就只是它的自动化版本。
</span>

**易错点：** 耦合常数 J 并不随原子间距单调递减到零——烯烃的反式 3J（12–18 Hz）大于顺式（6–12 Hz），因为它们共享 π 键，电子的传递更高效。
立体化学对 J 的依赖正是下一节 Karplus 方程的主题。

## 4 等性：读谱的第一步判断

「等价」有两种，差一个词但后果天差地别：

**化学等价（chemically equivalent）**：两个氢化学环境相同、δ 相同。例如乙烷的 6 个氢全部等价，只出一根峰。
- **磁等价（magnetically equivalent）**：化学等价，且对每一个外部氢的耦合常数都相同。磁等价的氢才服从 n+1 规则；化学等价但磁不等价的氢（如 $\ce{CH2=CH2}$ 中顺式/反式的两对氢）会形成更复杂的二级谱图。

**对映等价与非对映等价（enantiotopic / diastereotopic）**是最容易踩的坑：<span class="marginnote">判据口诀：把分子中的一个氢替换成氘（或 Cl），若手性中心翻转后仍是同一化合物 → 对映等价（同 δ，不劈裂）；若得到的是非对映异构体 → 非对映等价（不同 δ，可能互相耦合）。
苄基类化合物 $\ce{PhCH2X}$ 的 CH2 质子正是非对映等价——它们的 1H 谱常出现 AB 型四重峰。
</span>

- 前手性中心上的两个氢（如苄基 CH2 的 H_a、H_b）：若中心不是手性中心，二者对映等价、化学环境相同；
- 若旁边有手性中心（或换成氘后产生手性），则非对映等价、δ 不同，会出现 ABX 甚至更复杂的图案。

**等价性判错，n+1 规则就全线崩盘**——这是 1H 谱读谱错误的第一大来源。

## 5 Karplus 方程：J 与二面角的三角函数

邻位耦合常数 3J 与 C–C 键的二面角 φ 有定量关系，这就是 **Karplus 方程（Karplus equation）**：

$$\,^3J(\phi) = 7 - \cos\phi + 5\cos 2\phi \quad \text{(Hz)}$$

拆成三步理解：

- **第一步，看懂自变量 φ**：φ 是 H–C–C–H 四个原子绕中间 C–C 键的二面角。在 Newman 投影里，全重叠（eclipsed）时 φ=0°，反式（anti）时 φ=180°。
- **第二步，代数值**：φ=0°（顺式全重叠）时 $J = 7 - 1 + 5 = 11$ Hz；φ=180°（反式）时 $J = 7 + 1 + 5 = 13$ Hz；φ=90°（垂直）时 $J = 7 - 0 - 5 = 2$ Hz——**J 在二面角 90° 附近取极小值，在 0°/180° 附近取极大值**。<span class="marginnote">为什么是 cos 的组合？因为耦合传递依赖两对 C–H 键轨道与 C–C 键轨道之间的重叠，重叠角度的投影关系正是 cos 级数。三角函数从纯几何直接进入谱学，是「数形结合」在 NMR 里的最好例证。</span>
- **第三步，读出立体化学**：环己烷上相邻两个氢，轴向-轴向（anti，φ≈180°）3J 约 8–13 Hz，轴向-赤道（gauche，φ≈60°）约 2–5 Hz。**测 J 就能判定构象**——Karplus 方程让 NMR 成为立体化学的显微镜。

**易错点：** 实际 3J 还受电负性取代基、键长、环张力影响，Karplus 方程给的是趋势而非精确值——用在构象分析上要「相对比较」而不是「绝对读数」。

## 6 公式解析：n+1 与帕斯卡三角形

**n+1 规则的完整表述值得写成一张小表，它同时囊括「峰的个数」和「强度的二项式系数」：**

$$\text{峰的个数} = n + 1, \qquad \text{相对强度} = \binom{n}{k} = \frac{n!}{k!(n-k)!}$$

拆成两步理解：

- **第一步，为什么是 n+1**：相邻 $n$ 个等价氢的每个氢提供 α/β 两种取向，总取向组合数为 $2^n$ 种，但它们按「α 的个数」归类（0 到 n 共 n+1 类），每一类对应一条峰线。
- **第二步，强度为什么是二项式系数**：每类组合的个数 = 从 n 个氢里取 k 个 α 的组合数 $\binom{n}{k}$。n=3 时得到 1:3:3:1——这正是帕斯卡三角形第四行，也是掷 3 枚硬币时「正面朝上 0,1,2,3 次」的概率比。

**重点：n+1 规则是「概率分布长成谱线」**。
读谱时先数劈裂数定 n，再核对强度比是否为整数比；一旦强度比偏离帕斯卡三角形，说明你数错了等价氢、或谱图进入了二级谱范畴（δ 差与 J 同数量级时，峰形扭曲，规则失效）。

## 7 小结

- **位移三来源**：诱导效应（电负性）、各向异性效应（π 体系）、氢键（活泼氢漂移）。
- **n+1 规则**：相邻 n 个等价氢劈成 n+1 峰，强度比帕斯卡三角形；磁等价才适用。
- **J 的性质**：与磁场无关、随键数减小、共享 J 的两组峰必互为邻居。
- **等价性**：化学等价 ≠ 磁等价；对映等价不劈裂，非对映等价会劈裂——判错则满盘皆输。
- **Karplus 方程**：3J 与二面角 φ 满足 $J = 7 - \cos\phi + 5\cos2\phi$，90° 极小、0°/180° 极大，可判构象。

在下一节，我们把这些一维工具推向二维：**COSY、HSQC、NOESY**——把「谁和谁耦合」「谁和谁相连」「谁和谁空间靠近」一次性画成一张相关谱。
