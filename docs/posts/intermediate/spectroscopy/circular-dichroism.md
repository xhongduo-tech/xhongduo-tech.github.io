## 为什么从圆二色光谱开始

1848 年，巴斯德在显微镜下徒手分离酒石酸盐的两种晶体，发现它们使偏振光旋转的方向相反——**手性**由此进入化学。
一百多年后，手性分子如何快速测定？
答案是**圆二色光谱（circular dichroism，CD）**：让左旋与右旋圆偏振光分别穿过样品，手性分子对二者的吸收不同，这一丁点差异被仪器放大成特征曲线。
CD 是测定**绝对构型**与**生物大分子二级结构**的主力工具，也是本专题「光与分子」序列的最后一站。
<span class="marginnote">本专题对标教材为 Atkins《Physical Chemistry》第 11 版 Focus 11；CD 的姊妹技术是旋光（optical rotation，只测折射率差），而 CD 测的是吸收差——CD 的信息量远大于旋光，因为它同时携带波长分辨。
</span>

## 1 手性分子与圆偏振光

先补一堂光学课。
一束**线偏振光**可以分解为两束等振幅、旋转方向相反的**圆偏振光**：左旋（L）与右旋（R）。
当这两束光通过各向同性介质时，若介质**非手性**，L 与 R 被同等对待，出来还是线偏振；若介质**手性**（如含手性中心的分子），L 与 R 的吸收和折射都不同：<span class="marginnote">手性为什么能区分 L 与 R？
因为手性分子与其镜像不能重叠——L 与 R 圆偏振光互为镜像，手性分子对它们的作用天然不同。
这就像左手套认识左手、不认识右手：手性就是「光的左右手识别器」。
</span>

- **吸收不同** → 圆二色（CD）：L 与 R 出射振幅不等；
- **折射率不同** → 旋光（optical rotation）：L 与 R 出射相位不同，合偏振面旋转。

两者同源于「手性介质的 L/R 不对称」，只是观测量不同。
CD 谱把这种不对称按波长画出来，得到一张**带符号的谱图**。

## 2 CD 信号：Δε 与摩尔椭圆率

**核心概念：圆二色（CD）**定义为手性分子对左旋与右旋圆偏振光摩尔吸光系数之差：

$$\Delta\varepsilon = \varepsilon_L - \varepsilon_R$$

Δε 可正可负——分子在某波长对左旋光吸收更强（Δε > 0）或更弱（Δε < 0）。仪器实际给出的量通常是**摩尔椭圆率（molar ellipticity）** $[\theta]$，单位 $\mathrm{deg\,cm^2\,dmol^{-1}}$，它与 Δε 的关系是（见第 5 节）：$[\theta] = 3298\,\Delta\varepsilon$。<span class="marginnote">为什么 CD 常报告 $[\theta]$ 而不是 Δε？
纯历史原因——早期仪器测的是出射椭圆的椭圆角 θ。
现代仪器大多直接给 Δε 或 $[\theta]$，换算只需乘 3298。
这个数别记反了：Δε 是无量纲吸光系数差，$[\theta]$ 才有椭圆率的单位。
</span>

**重点：CD 是「有符号的吸收谱」**——吸收谱告诉你「在 λmax 吸多少光」，CD 告诉你「左旋和右旋光吸收差多少、谁多谁少」。
非手性分子 Δε ≡ 0、CD 谱为平线；任何 CD 信号都标志着手性环境。

## 3 Cotton 效应：CD 谱的「S 形签名」

当手性发色团吸收光时，CD 谱在吸收带附近呈现特有的**S 形曲线**，叫 **Cotton 效应（Cotton effect）**：

**正 Cotton 效应**：短波侧 Δε 为正（峰），跨过 λmax 后变为负（谷），谱线「先正后负」；
- **负 Cotton 效应**：短波侧为负，跨过 λmax 后为正，谱线「先负后正」。

无论正负，CD 曲线都在吸收峰 λmax 处**过零**——因为 λmax 处左旋右旋吸收同时达到极值，吸收差方向发生翻转。
<span class="marginnote">Cotton 效应把「手性」与「电子跃迁」绑在一起：CD 谱的符号由手性发色团的绝对构型决定。
1920 年代 Cotton 本人最早观察到旋光随波长变化，后人把他的名字给了这条 S 形曲线——一条曲线的正负，就是分子构型的签名。
</span>

![Cotton 效应：正与负的圆二色谱曲线](/images/spectroscopy/circular-dichroism-1.svg)

**易错点：** 正 Cotton 效应的「正峰」在**短波侧**。
很多初学者记反——判断正负的唯一可靠办法是看「跨过 λmax 的方向」：短波侧为正是正 Cotton，短波侧为负是负 Cotton。

## 4 应用：蛋白质二级结构与绝对构型

CD 的两大主战场：

**（1）生物大分子的二级结构。
** 蛋白质主链的肽键发色团（~190–240 nm）在手性折叠里给出特征 CD 谱形：<span class="marginnote">这一段的三个「形状口令」务必记牢：α-螺旋在 208 与 222 nm 两个负峰、190 nm 一个正峰；β-折叠约 218 nm 一个负峰；无规卷曲约 200 nm 一个负峰。
把实测谱与标准谱形拟合，就能估算 α/β/无规的相对含量——CD 是蛋白质折叠表征的最快捷手段。
</span>

**α-螺旋**：208 nm 与 222 nm 两处负峰、~190 nm 正峰；
- **β-折叠**：~218 nm 单负峰；
- **无规卷曲**：~200 nm 单负峰。

**（2）手性分子的绝对构型。
** 对含手性发色团的小分子（如羰基化合物、芳族衍生物），CD 谱的 Cotton 效应符号直接与**绝对构型**关联：同一系列衍生物中，构型相同则 Cotton 符号一致；再配合经验规则（如羰基的八区律、芳香发色团的方位规则）或量子化学计算，可确立未知物的 R/S 构型。
<span class="marginnote">「八区律（octant rule）」是经典经验规则：把羰基周围的取代基按空间分区，各区对 n→π* Cotton 效应的贡献正负不同——查各区的符号表即可判断哪个方向是正 Cotton。
现代的用法是先用 TD-DFT 算 CD 谱、再与实测比对，经验规则退居校验角色。
</span>

**易错点：** CD 只对手性发色团敏感——**分子有手性中心但不含发色团（如纯烷烃）时，CD 谱接近平线**。
判断构型前先确认样品在吸收区有没有可测的 Cotton 效应，别把「无信号」误读成「无手性」。

## 5 公式解析：摩尔椭圆率与 Δε 的换算

**CD 谱横轴是波长、纵轴可以是 Δε 也可以是 [θ]，两者差一个普适常数 3298：**

$$[\theta] = 3298\,\Delta\varepsilon$$

拆成三步理解：

- **第一步，明确 Δε 的定义**：$\Delta\varepsilon = \varepsilon_L - \varepsilon_R$，量纲与普通摩尔吸光系数相同（$\mathrm{L\,mol^{-1}\,cm^{-1}}$），但带符号。它的绝对值反映手性发色团对 L/R 光吸收的不对称强度。
- **第二步，看懂 3298 的来历**：椭圆率 θ 与吸收差的关系是 θ = 3300 × Δε × c × l（弧度与对数的换算），再把浓度光程并入摩尔量、把弧度换算成度，常数折合成 3298。**它是「对数吸光系数差」与「椭圆角度」之间的单位桥梁**，不是物理定律而是单位制换算。<span class="marginnote">换个视角：3298 = (180/π) × (100/ln10) 的合成——(180/π) 把弧度换度，(100/ln10) 把摩尔吸光系数与椭圆角的对数关系归一化。两个「纯数字」单位因子叠乘，恰得 3298。</span>
- **第三步，读谱换算**：仪器给 [θ] 就除 3298 得 Δε；文献里两者混用，比较前先统一单位。对蛋白质常用「平均残基椭圆率」$[\theta]_{MRW}$（按每个氨基酸残基计算），数值比 [θ] 小约一个数量级，别把两者混在一起比。

**易错点：** Δε 有正负，3298 只是正的换算常数——正负号原样保留。
换算错符号（或漏符号）是 CD 数据比较最常见的失误。

## 6 小结

- **物理根源**：手性分子对左旋/右旋圆偏振光吸收不同，Δε = εL − εR 可正可负。
- **Cotton 效应**：CD 谱在 λmax 附近呈 S 形；短波侧为正即正 Cotton，短波侧为负即负 Cotton，λmax 处必过零。
- **换算关系**：$[\theta] = 3298\,\Delta\varepsilon$，符号随 Δε，蛋白质常用平均残基椭圆率。
- **二级结构指纹**：α-螺旋（208/222 nm 双负峰）、β-折叠（218 nm 单负峰）、无规卷曲（200 nm 单负峰）。
- **绝对构型**：Cotton 符号 + 经验规则（八区律）或 TD-DFT 计算，可定 R/S；无发色团则 CD 平线。
- **测量注意**：CD 须在吸收的朗伯-比尔线性区测量，常与 UV 吸收谱同机记录；浓度过高会让谱形与 Δε 失真，读数前先校验吸收值落在合理区间。

到此，本专题的十四篇全部落幕：从 UV 的共轭体系、IR 的官能团、MS 的分子式与碎片、NMR 的骨架与立体、EPR 的自由基、X 射线衍射的原子坐标，到拉曼、荧光与圆二色——**波谱学用一束束不同波长的光，把分子从「看不见的假设」变成「看得见的真相」**。
下一段旅程，我们可以带着这套「结构鉴定方法论」走进更高层的物理化学与结构生物学，去读那些用光谱书写的生命与材料的故事。
