## 为什么从紫外-可见光谱开始

结构鉴定有四张王牌：紫外-可见光谱（UV-Vis）、红外光谱（IR）、质谱（MS）与核磁共振（NMR）。
从 UV-Vis 起手，是因为它是**电子结构的探测器**——别的光谱回答「分子里有什么」，UV 首先回答「分子的骨架有多大的共轭体系」。
它原理最浅（只需要一束光和朗伯-比尔定律），却为后面所有光谱铺平了「光与物质作用」的思想基础：一束电磁波打向分子，分子吸收能量、发生量子化的跃迁，我们在另一端记录下「缺了多少光」。
这个「缺了多少光」的读数，就是整门波谱学的方法论起点。
<span class="marginnote">本专题对标教材为 Silverstein 等《Spectrometric Identification of Organic Compounds》第 7 章；本章内容是全专题第一篇，后续 IR、MS、NMR 各篇会反复调用「吸收-跃迁-记录」这套框架。
</span>

## 1 光是一把尺子：电子跃迁

分子的能量不是连续的，而是**量子化的**。
当一束能量恰好等于某两个能级之差的光照射分子时，分子就会吸收它，完成一次**电子跃迁（electronic transition）**——把电子从占据轨道送到空轨道。
波长越短、能量越高，能"撬动"的跃迁就越大。

有机分子的常见跃迁按所需能量从高到低排序：<span class="marginnote">记住这条顺序就能推出：哪个官能团出现在哪个波长区间。
σ→σ* 所需能量最大，只有真空紫外（<200 nm）才能测到，这也是普通仪器看不见它的原因。</span>

$$\sigma \to \sigma^{*} > n \to \sigma^{*} > \pi \to \pi^{*} > n \to \pi^{*}$$

- **σ→σ\***：饱和 C–C、C–H 键，能量极高，远在普通仪器范围（约 120–150 nm）之外。
- **n→σ\***：含杂原子的 σ 键，如 $\ce{C-O}$、$\ce{C-Cl}$、$\ce{C-S}$，约 180–260 nm。
- **π→π\***：双键、芳环、共轭体系的跃迁，约 170–300 nm，随共轭增长而红移。
- **n→π\***：羰基、硝基等含孤对电子与 π 体系的基团，约 270–350 nm，强度弱。

**核心概念：发色团（chromophore）**：能够吸收紫外-可见光而产生特征的 π→π\* 或 n→π\* 跃迁的不饱和基团，例如 $\ce{C=C}$、$\ce{C=O}$、$\ce{C=N}$、$\ce{N=N}$、$\ce{NO2}$。
**助色团（auxochrome）**：本身吸光很弱、但连到发色团上会改变吸收的杂原子基团，如 $\ce{-OH}$、$\ce{-NH2}$、$\ce{-OR}$、卤素——它们带着孤对电子参与共轭，把吸收推向长波。
<span class="marginnote">「发色团决定有没有吸收，助色团决定吸收在哪、多强」——这句话是本章所有经验规则的出发点。
</span>

## 2 Beer–Lambert 定律

测量吸收的核心定律是 **Beer–Lambert 定律**：一束单色光穿过浓度为 $c$、光程为 $l$ 的溶液，其吸光度与浓度、光程成正比：

$$A = \varepsilon c l$$

其中 $A$ 是**吸光度（absorbance）**，$\varepsilon$ 是**摩尔吸光系数（molar absorptivity）**，$c$ 是浓度（mol/L），$l$ 是光程（cm）。
吸光度由透光率 $T = I/I_0$ 定义：$A = -\log_{10} T$。
<span class="marginnote">注意 $A$ 用的是以 10 为底的常用对数，而 NMR、IR 里不少信号强度用 $T$（透过率）画图——IR 图谱的纵轴常常是 $T\%$，坐标是倒过来的，读谱时要先看纵轴。
</span>

**Beer–Lambert 定律把「吸收」翻译成了可测的数**，这是定量分析的基石：测出 $A$、知道 $\varepsilon$ 与 $l$，就能算出浓度；反过来，配制已知浓度的溶液，就能测出 $\varepsilon$——而 $\varepsilon$ 的大小反映的是跃迁的「强度」（是否对称允许、是否与激发的电子耦合），是结构信息。

## 3 共轭：红移的发动机

单独一个 $\ce{C=C}$，π→π\* 吸收约在 175 nm；可一旦双键与双键、双键与孤对电子相互**共轭**，成键 π 与反键 π\* 之间的能隙被压缩，吸收便向长波方向移动（红移），强度也大幅增强。
<span class="marginnote">直觉上可以这样想：共轭把 π 电子「摊开」到一个更大的轨道范围，电子越自由，能级越靠近，需要的光能量就越低。
这个直觉同样解释了后面 13C NMR 里共轭体系化学位移的特例。
</span>

丁二烯（共轭双烯）约 217 nm；
- 苯 254 nm（苯环的 π→π\*，弱而特征）；
- 共轭链越长，吸收波长越长、颜色越深——**胡萝卜素的橙红色正来源于它长串的共轭双键**。

**共轭体系越大，λmax 越往长波走**——这句话几乎可以当作本章的唯一主定理。
它连接着日常经验：多数「无色」的有机物共轭很小，而天然色素、染料往往有一条长得吓人的共轭链。
颜色，就是共轭体系写给你的情书。

## 4 溶剂与谱带位移

换溶剂也会移动吸收峰，称为**溶剂效应（solvent effect）**。
总体规则是：

- π→π\* 跃迁：极性溶剂使吸收**红移**（极性溶剂稳定了更极性的激发态）；
- n→π\* 跃迁：极性溶剂使吸收**蓝移**（极性溶剂通过与孤对电子的氢键，把基态降得更多）。

于是同一分子在不同溶剂里，λmax 可能相差几十纳米——报告 UV 数据时必须注明溶剂。

描述谱带移动与强弱的术语是结构鉴定里的黑话，务必记牢：<span class="marginnote">这四个词在有机化学文献里高频出现，也常考：「红移」与「蓝移」说的是位置，「增色」与「减色」说的是强度。
</span>

| 术语 | 含义 |
| --- | --- |
| 红移（bathochromic shift） | 吸收向长波移动 |
| 蓝移（hypsochromic shift） | 吸收向短波移动 |
| 增色效应（hyperchromic effect） | 吸收强度增大 |
| 减色效应（hypochromic effect） | 吸收强度减小 |

## 5 公式解析：Beer–Lambert 定律

**核心公式是 $A = \varepsilon c l$，它把「看不见的电子跃迁」换算成「仪器读到的数」。
** 拆成三步理解：

**第一步，读等式左边 $A$**：吸光度 $A = -\log_{10}(I/I_0)$。若光全部透过，$I = I_0$，$A = 0$；若光被吸收掉 90%，$I/I_0 = 0.1$，$A = 1$。所以 $A$ 是「光被扣掉了多少个数量级」，而不是「扣掉了百分之几」——$A=1$ 意味着扣掉 90%，$A=2$ 意味着扣掉 99%。<span class="marginnote">为什么用对数？因为每个分子层独立地按比例吸光，光强度按指数衰减，取对数后「每层贡献相同」才变成线性关系——这正是积分的直觉，和辐射穿过大气、射线穿过屏蔽的衰减同一数学形式。</span>
**第二步，读比例常数 $\varepsilon$**：摩尔吸光系数是「每一个摩尔每厘米路程贡献的吸光本领」，单位 $\mathrm{L\,mol^{-1}\,cm^{-1}}$。π→π\* 跃迁的 $\varepsilon$ 可达 $10^{4}$–$10^{5}$，n→π\* 只有 $10^{1}$–$10^{2}$——强度差几个数量级，直接判读跃迁类型。
- **第三步，读 $c$ 与 $l$**：浓度与光程是「试验设计变量」。标准比色皿光程 $l=1$ cm，测的是 $A$ 随浓度的线性关系；偏离线性（高浓度、散射、荧光污染）时定律失效，这是定量实验最常见的坑。

**易错点：** Beer–Lambert 定律只在低浓度、单色光、无散射无荧光的理想条件下成立。
浓度过高时分子间相互作用、电荷转移都会让 $A$ 对 $c$ 的线性关系弯曲——「定律」有适用范围，如同理想气体方程。

## 6 Woodward–Fieser 规则：从结构预测 λmax

既然共轭决定 λmax，那能否从结构**定量预测** λmax？
能。
有机化学家 William R. Woodward 与 Louis F. Fieser 总结出一套经验规则：给定一个共轭二烯或 α,β-不饱和酮的骨架，从基值出发，每个取代基、每个延伸共轭、每个环外双键都贡献一个增量，加起来就是预测的 λmax（乙醇中）。
<span class="marginnote">Woodward–Fieser 规则是「经验 + 增量」范式的典范——它不是从量子力学推出来的，而是从几百个实测谱归纳出来的加法表。
这个「从数据学规律」的姿势，与今天机器学习预测光谱是同构的。
</span>

共轭双烯：无环双烯基值 **214 nm**；同环（homoannular）二烯基值 **253 nm**；
- 每个烷基取代 +5，每个环外双键 +5，每个延伸共轭的双键 +30，助色团 $\ce{-OR}$ +6，$\ce{-OAc}$ 0；
- α,β-不饱和酮：基值 **215 nm**；α 位取代 +10，β 位 +12，γ、δ 位各 +18。

这类规则的意义在于：**算出的 λmax 与实测相差超过 ±5 nm 时，提示你假定的结构可能是错的**。
它把 UV 从「定性看看有没有共轭」提升为「定量检验某个候选结构」的工具——这是整个结构鉴定逻辑的第一次演练。

## 7 从 UV 走向全谱

UV-Vis 能回答的问题很集中：有没有共轭、共轭多大、是哪种跃迁、大概的结构骨架。
它几乎不回答官能团的种类（$\ce{C=O}$ 与 $\ce{C=C}$ 的 π→π\* 都可能在 200 nm 附近），也几乎不谈分子的整体骨架——这两件事分别交给红外（化学键的种类）与核磁（原子的连接方式）去办。
<span class="marginnote">因此 UV 在结构鉴定里通常是「辅助判据」：先由 MS 定分子式、IR 定官能团、NMR 定骨架，最后用 UV 校验共轭假设。
单独一张 UV 谱几乎定不了结构——这正是它与后面三张谱的互补关系。
</span>

## 8 小结

- **吸收的本质**：分子吸收能量恰好匹配的量子化光子，完成电子跃迁；跃迁能量排序为 σ→σ\* > n→σ\* > π→π\* > n→π\*。
- **核心定律**：Beer–Lambert 定律 $A = \varepsilon c l$，$A$ 是光强被扣掉的数量级（对数），$\varepsilon$ 反映跃迁强度。
- **发色团与助色团**：不饱和基团决定「有没有吸收」，杂原子助色团决定「吸收移到哪、多强」。
- **共轭是主旋律**：共轭体系越大，λmax 越红移、$\varepsilon$ 越大；颜色即共轭。
- **经验规则**：Woodward–Fieser 增量法可从结构定量预测 λmax，实测与预测的偏差用于校验结构假设。

在下一节，我们转向第二种光与分子的作用：**红外光谱**。
UV 看的是电子跃迁（波长短、能量高），红外看的却是分子中化学键的振动——那是官能团的指纹，也是结构鉴定的第二张王牌。
