## 为什么从卤代烃开始

烷烃、烯烃、炔烃、芳香烃——烃类家族我们已经走完。现在进入含官能团的世界，第一站是**卤代烃（alkyl halide）**：$\ce{R-X}$（X = F、Cl、Br、I）。它本身并非天然产物，却是有机合成中**最重要的一类中间体**——因为碳卤键既能被亲核试剂取代（变成醇、醚、胺、腈……），又能发生消除（生成烯烃），几乎是「一扇通往所有官能团的大门」。<span class="marginnote">卤代烃的重要性在于它的「可塑性」：C–X 键的极性使碳带 δ+，亲核试剂可进攻取代；同时 β-氢又可被碱夺走消除。一个基团，两种反应，全部由条件掌控。</span>

理解卤代烃的亲核取代，是理解整个极性反应体系的第一步。它的两大机理——SN1 与 SN2——是《亲核取代机理 SN1/SN2》一节的正式内容，本节先建立完整的反应图像。

## 1 卤代烃的结构与反应性根源

**卤代烃（alkyl halide）**：烷基中的一个或多个氢被卤素原子取代的化合物，通式 $\ce{R-X}$。

碳–卤键是**极性共价键**：卤素电负性大于碳（F 4.0、Cl 3.0、Br 2.8、I 2.5 vs C 2.5），C–X 键的电子偏向卤素，碳端带部分正电荷 δ+。<span class="marginnote">碳端 δ+ 是亲核取代的「开关」：亲核试剂（富电子物种）被吸引来进攻这个带正电的碳。碳越 δ+、空间位阻越小，取代越容易发生。</span>

不同卤素对反应性的影响由键能与离去能力共同决定：

| C–X 键 | 键能 (kJ/mol) | 卤素离去能力 |
| --- | --- | --- |
| C–F | 485 | 很差 |
| C–Cl | 339 | 中等 |
| C–Br | 285 | 好 |
| C–I | 240 | 最好 |

**核心概念：离去基团（leaving group）**：被亲核试剂替换、带着电子对离去的基团。离去能力越强（越能稳定带走负电荷），取代反应越快。碘负离子大而极化率高、稳定分散负电荷，因此碘代烃最活泼。

## 2 亲核取代反应：把卤素换成别的

**亲核取代（nucleophilic substitution）**：亲核试剂（Nu⁻）进攻带 δ+ 的碳，把离去基团（X⁻）替换下来：

$$\ce{R-X + Nu^- -> R-Nu + X^-}$$

这一反应可以把卤代烃转化为几乎任何含官能团的化合物：

| 亲核试剂 | 产物 | 产物类型 |
| --- | --- | --- |
| $\ce{OH-}$ | $\ce{R-OH}$ | 醇 |
| $\ce{RO-}$ | $\ce{R-OR'}$ | 醚 |
| $\ce{NH3}$ | $\ce{R-NH2}$ | 胺 |
| $\ce{CN-}$ | $\ce{R-CN}$ | 腈 |
| $\ce{SH-}$ | $\ce{R-SH}$ | 硫醇 |
| $\ce{I-}$ | $\ce{R-I}$ | 碘代烃（卤素交换） |

**核心规律**：亲核取代的本质是「用亲核试剂换掉离去基团」，碳骨架不变、卤素被替换。这是有机合成中碳链「挂官能团」的基础操作。<span class="marginnote">这张表也揭示了卤代烃的合成地位：它是「官能团转换的中转站」。醇 → 卤代烃 → 胺/腈/醚……合成设计时，常常先把目标官能团「变成卤代烃」再转化为下一个官能团。</span>

**亲核试剂 vs 碱**：同一个物种可以身兼两职。$\ce{OH-}$ 既是亲核试剂（进攻碳）又是碱（夺 β-氢）。反应走取代还是消除，取决于底物结构与条件——这正是下一节《消除反应与竞争》的主题。

## 3 取代与底物结构：一、二、三级卤代烃

卤代烃按卤素所连碳的取代程度分为**一级（伯，primary）、二级（仲，secondary）、三级（叔，tertiary）**卤代烃。这一分类对反应性有决定性影响：

**一级（1°）**：卤素连伯碳，如 $\ce{CH3CH2Br}$。
**二级（2°）**：卤素连仲碳，如 $\ce{CH3CHBrCH3}$。
**三级（3°）**：卤素连叔碳，如 $\ce{(CH3)3CBr}$。<span class="marginnote">取代程度的判断：看卤素所连碳上还有几个碳直接相连。1 个 → 伯，2 个 → 仲，3 个 → 叔。这是预测 SN1/SN2、E1/E2 反应路径的第一把尺子。</span>

取代程度同时影响两条性质：**空间位阻**（阻碍亲核试剂从背后进攻）与**中间体稳定性**（碳正离子/碳自由基的稳定）。一级卤代烃位阻小但中间体不稳定，三级卤代烃中间体稳定但位阻大——这一矛盾正是 SN1/SN2 分流的根源。

## 4 公式解析：亲核取代的速率方程

亲核取代的速率方程直接反映其机理，这是本节最精炼的「公式」：

**SN2 反应速率**：
$$\text{rate} = k\,[\ce{R-X}][\ce{Nu-}]$$

**SN1 反应速率**：
$$\text{rate} = k\,[\ce{R-X}]$$

- $k$：速率常数；
- 速率方程由**决速步**决定：SN2 一步协同、两分子都参与，故速率依赖两者浓度；SN1 分两步、第一步（解离）决定速率，故只依赖卤代烃浓度。<span class="marginnote">「速率方程揭示机理」是化学动力学的黄金法则：谁进入决速步，谁的浓度就出现在速率方程里。SN2 中 Nu 参与决速步，SN1 中 Nu 在决速步之后才登场，两者的速率方程天差地别。</span>

**说明**：SN2 的「2」指**双分子（bimolecular）**，决速步有两个分子参与；SN1 的「1」指**单分子（unimolecular）**，决速步只有卤代烃一个分子解离。名字里的数字不是反应步骤数，而是**决速步的分子数**——这个细节初学者极易混淆。

## 5 从卤代烃到官能团化学

卤代烃的亲核取代是「官能团转换」的枢纽，它把所有主要官能团连接成一个网络：

$$\text{卤代烃} \xrightarrow{\ce{OH^-}} \text{醇} \xrightarrow{\text{氧化}} \text{醛/酮} \xrightarrow{\ce{RMgX}} \text{醇}$$

这样的「官能团转化网络」是有机合成的底层地图。而卤代烃自身可以通过**醇与氢卤酸反应**制备：

$$\ce{R-OH + HX -> R-X + H2O}$$

或通过**烯烃与 HX 加成**（马氏规则）制备。掌握「制备」与「转化」两条路径，就掌握了卤代烃在合成中的位置。<span class="marginnote">在「从极限到大模型」的知识树中，卤代烃的亲核取代是《有机化学》的核心枢纽之一，它向前承接烃类，向后开启醇、醚、胺、腈、羧酸等全部含官能团化学；也是《化学合成》与《药物化学》中 C–C、C–N、C–O 成键的常规手段。</span>

下一节我们将正式进入 SN1/SN2 两种机理的深入对比，本节先记住它们的「名字含义」与「速率方程差异」这两个关键抓手。

## 6 卤代烃的物理性质与光谱

卤代烃的物理性质与光谱特征是识别与应用它们的基础。

**物理性质规律**：

| 卤代烃 | 相对密度 | 沸点趋势 |
| --- | --- | --- |
| 氟代烃 | 轻于水 | 接近烷烃 |
| 氯代烃 | 重于水（多数） | 高于烷烃 |
| 溴代烃 | 明显重于水 | 更高 |
| 碘代烃 | 很重 | 最高 |

**核心规律：卤素引入显著改变物理性质。** 引入卤素（尤其 Br、I）使分子质量大增、色散力增强，沸点明显高于相应烷烃；多数氯、溴代烃密度大于水，且因极性键可微溶于水、易溶于有机溶剂。<span class="marginnote">「密度大于水」是卤代烃的实用特征：实验中它们常作为有机相沉在水下，萃取分层时一眼可辨。氟代烃特殊——氟原子小、电负性大，C–F 键极性虽强但分子间作用力有限，含氟化合物常密度较低。</span>

**光谱特征**：
- **红外光谱**：C–X 伸缩振动（750–500 cm⁻¹，C–Cl；~560 cm⁻¹ C–Br）在指纹区；
- **质谱**：含 Cl、Br 的分子有特征的「同位素峰」——Cl 有 $^{35}$Cl/$^{37}$Cl（约 3:1），Br 有 $^{79}$Br/$^{81}$Br（约 1:1），分子离子峰呈现「双峰」形态；
- **¹H NMR**：卤素吸电子使相邻质子的化学位移增大（去屏蔽）。

**公式解析：C–X 键能与反应性的关系**

卤代烃的反应活性与 C–X 键能直接相关：

$$\ce{C-X\ 键能}:\ \ce{C-F\ (485) > C-Cl\ (339) > C-Br\ (285) > C-I\ (240)}\ \text{kJ/mol}$$

- 键能越低，键越容易断裂，离去基团越容易离开；
- 因此碘代烃在取代/消除中活性最高，氟代烃最惰性；
- 「键能低 → 反应活性高」这条线把卤代烃的整个反应性图谱串了起来——也解释了为什么 C–F 键在药物设计中如此流行（极稳定、不易代谢）。<span class="marginnote">C–F 键的稳定性成就了现代药物化学：氟原子小、吸电子、形成牢固的 C–F 键，能阻断代谢位点、改善药效（如氟西汀、氟康唑）。「最惰性的卤素」在药物设计里反而是「最有用的修饰」——这提醒我们，反应性不是唯一的价值标准。</span>

**应用**：卤代烃是合成中间体（我们已经熟悉）、制冷剂（CFC 曾用、因臭氧破坏被淘汰）、以及含氟药物的关键结构单元。其物理与光谱性质是《分析化学》与《药物化学》识别卤代化合物的基础。

## 7 小结

- **卤代烃** $\ce{R-X}$ 含极性 C–X 键，碳端 δ+，是亲核取代的反应中心。
- 离去能力：**I⁻ > Br⁻ > Cl⁻ > F⁻**，键能越低越易离去。
- 亲核取代通式：$\ce{R-X + Nu^- -> R-Nu + X^-}$，可转化为醇、醚、胺、腈等。
- 卤代烃分**一、二、三级**，取代程度决定位阻与中间体稳定性。
- 速率方程：SN2 双分子（含 [Nu⁻]），SN1 单分子（只含 [RX]）。
- 卤代烃是官能团转换网络的枢纽：由醇/烯烃制备，又转化为各种官能团。

在下一节，我们将直面亲核取代的「双胞胎兄弟」——消除反应，以及它与取代反应的激烈竞争：**消除反应与竞争**。
