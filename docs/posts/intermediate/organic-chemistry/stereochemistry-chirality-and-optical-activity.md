## 为什么从手性开始

上一节我们区分了构象与构型，其中构型异构的一支——**对映异构**——是最奇特也最重要的一类：两个分子组成完全相同、连接方式完全相同，唯一的差别是互为镜像。可它们竟然可以有不同的化学行为，甚至在生物体内一种有药效、另一种有毒。这就是**手性（chirality）**。<span class="marginnote">「手性」一词源于希腊语 cheir，意为「手」。1858 年，开尔文勋爵（Lord Kelvin）首次用「chirality」定义「一个物体与其镜像不能重合」的性质。</span>

2006 年，「反应停（沙利度胺）」丑闻让世界记住了手性的残酷：R 型缓解孕吐，S 型却导致胎儿畸形。手性不是抽象几何游戏，而是生命化学的核心密码——因为生物体内的受体、酶大多是手性的，它们只认「对」的手。

## 1 手性：什么是「不能重合」

**手性（chirality）**：一个物体若与其镜像不能通过旋转、平移等操作重合，则称这个物体是手性的。

判断一个物体是否手性，最直观的方法：**让物体与它的镜像比一比，看能否完全叠合**。你的左右手叠合不了——手是手性的；一个完美的球、一把平底锅，能和镜像完全重合——是非手性的。<span class="marginnote">数学上，手性意味着分子没有某些对称元素：没有对称面、对称中心，也没有反轴。其中「没有对称面」是最常见也最容易检验的条件——只要分子有一个镜面，它就必然非手性。</span>

在有机化学里，手性最常见的来源是**手性碳原子（chiral carbon / stereocenter）**：一个连有四个互不相同的原子或基团的碳。

$$\ce{C*H(Cl)(Br)(F)(H)} \quad \text{四氯甲烷? 不，是连有四个不同基团的碳}$$

**核心判定**：一个碳原子若连有四个**互不相同**的基团，它就是一个手性中心，含该碳的分子通常是手性的。<span class="marginnote">注意「通常」二字：分子整体手性还要看全局对称性。有的分子含两个手性碳，但整体对称（内消旋化合物），反而非手性。我们将在《构型与构象分析》中讨论。</span>

## 2 对映体与非对映体

手性分子有一对特殊的立体异构关系：

**对映体（enantiomers）**：互为镜像、不能重合的一对手性分子。

**非对映体（diastereomers）**：立体异构体中，除了对映体之外的构型异构体（如顺反异构，以及含多个手性碳时仅部分手性中心相反的异构体）。

| 比较项 | 对映体 | 非对映体 |
| --- | --- | --- |
| 互为镜像？ | 是 | 否 |
| 旋光能力 | 相反（一左一右） | 各不相同 |
| 一般物理性质（沸点、溶解度） | 相同（在手性环境外） | 不同 |
| 分离难度 | 极难 | 较易 |

两个含一个手性碳的分子，若构型相反则互为对映体；若分子有两个手性中心，则最多可有 $2^2 = 4$ 种立体异构体，它们之间的亲缘关系就要逐一判断：所有手性中心都相反者为对映体，仅部分相反者为非对映体。<span class="marginnote">这个 $2^n$ 规则很强大：n 个手性中心最多产生 $2^n$ 种立体异构体。但若分子有内消旋结构，数目会少于 $2^n$——这是下一节的伏笔。</span>

**辨析｜易错点：** 对映体的物理性质「相同」有前提——在**非手性环境**中相同。一旦遇到偏振光、手性试剂或手性酶，对映体立刻表现出差异。这正是对映体难以用蒸馏、结晶等常规手段分离的原因：它们与普通环境完全等价。

## 3 旋光：用手去「看见」手性

手性分子最重要的物理表现是**旋光性（optical activity）**：能使平面偏振光的振动平面发生旋转。

自然光是各个方向振动的电磁波的混合，通过偏振片后只剩下单一振动方向的**平面偏振光**。当一束平面偏振光通过手性化合物的溶液时，振动平面会被旋转一个角度 $\alpha$：使振动面顺时针旋转的称**右旋（+）**，逆时针旋转的称**左旋（−）**。<span class="marginnote">对映体对偏振光的旋转方向相反、大小相等：若 R 型使光右旋 +13.5°，则 S 型使光左旋 −13.5°。这个「对称的响应」是识别对映体的第一线索。</span>

**比旋光度（specific rotation）** $[\alpha]$ 是校正了浓度、光程、温度与波长后的标准化旋光值：

$$[\alpha]_\lambda^T = \frac{\alpha}{l \cdot c}$$

- $\alpha$：实测旋光角（度）；
- $l$：样品管光程（dm，即 0.1 m）；
- $c$：溶液浓度（g/mL）或纯液体密度（g/mL）；
- $T$：测定温度，$\lambda$：光源波长（通常用钠 D 线，589 nm）。

比旋光度是物质的特征常数，如同熔点、沸点，可用来鉴定物质、判断纯度。例如乳酸的比旋光度 $[\alpha]_D^{20}$ 在适当条件下约 +2.6°，而它的对映体为 −2.6°。<span class="marginnote">注意：比旋光度的大小随溶剂、温度变化，因此报告时必须注明条件，如「$[\alpha]_D^{20} = +2.6° (c=1, H2O)」——浓度 c 与溶剂缺一不可，否则数值不可比。</span>

## 4 公式解析：从对映体过量到光学纯度

旋光度的另一个强大用途是**测定手性纯度**。实际合成得到的手性产物往往不是纯的单一对映体，而是两种对映体的混合物。定义：

**对映体过量（enantiomeric excess, ee）**：

$$ee = \frac{|R - S|}{R + S} \times 100\%$$

- $R, S$：两种对映体的摩尔分数或物质的量。
- ee 为 100% 表示纯单一对映体；ee 为 0 表示外消旋体（1:1 混合物）。

**光学纯度（optical purity）**：实测比旋光度与纯对映体比旋光度之比：

$$\text{光学纯度} = \frac{[\alpha]_\text{实测}}{[\alpha]_\text{纯}} \times 100\%$$

对一对对映体，**ee 数值上等于光学纯度**。例如合成产物实测 $[\alpha] = +1.3°$，而纯 R 型为 $+2.6°$，则光学纯度 $= 50\%$，即 ee = 50%，混合物中 R:S = 75:25。<span class="marginnote">为什么 ee 等于光学纯度？因为 S 型恰好抵消等量 R 型的旋光，净旋光正比于「多余的」R 型比例。这个「大数减小数」的思路，在《分析化学》的偏振测量中还会以更精密的形式出现。</span>

推导：设混合物中 R 占分数 $r$、S 占 $s$，$r+s=1$。净旋光为 $r[\alpha]_R + s[\alpha]_S = r[\alpha] - s[\alpha] = (r-s)[\alpha]$，除以 $[\alpha]$ 即得 $r-s = ee$。**旋光测量因此成了监测不对称合成的日常工具**——这是《不对称合成》一节的重要前提。

## 5 手性在生命与药物中的意义

手性不是实验室里的抽象概念，它渗透进生命的每一个层面。

生物大分子——氨基酸、糖、核酸——几乎都是手性的，且自然界只选用一种对映体：天然氨基酸几乎全是 L 型，天然糖几乎全是 D 型。<span class="marginnote">生命为何偏爱单一对映体，是科学尚未完全解开的谜。一种假说是原始生命起源于手性选择事件；另一些研究关注圆偏振光或矿物的手性催化。这个话题连接着《进化论》与《宇宙学》中的对称性破缺。</span>酶是手性的催化机器，其活性口袋只对特定构型的底物「敞开」。

这对药物化学有直接后果：**手性药物的两个对映体往往活性不同甚至相反**。经典的例子除了沙利度胺，还有 ibuprofen（布洛芬）——只有 S 型有止痛活性，市售药却是外消旋体（S 型起效，R 型在体内可缓慢转化为 S 型）。因此现代药物研发中，对手性药物的每一个对映体都要单独研究毒理与药效，这正是《精准医学》与《药物化学》关注的核心问题之一。

## 6 手性纯化：从外消旋体到单一对映体

当合成得到外消旋体（1:1 混合物）时，如何获得单一对映体？这是制药工业的日常难题，有几种经典手段。

**方法一：手性拆分（resolution）**

利用对映体与手性试剂反应后变成「非对映体」这一性质来分离。原理：非对映体的物理性质不同（熔点、溶解度、色谱保留时间），可以分离；分离后再把手性试剂解下，得到纯对映体。

$$\text{外消旋酸} + \text{手性碱} \to \text{非对映体盐}\ \xrightarrow{\text{分级结晶}} \ \text{分离} \xrightarrow{\text{解离}} \text{纯对映体}$$

- 经典案例：用天然手性碱（如辛可宁、马钱子碱）拆分外消旋酸；
- 优点：不需要手性催化剂，简单可靠；缺点：最多只能得到 50% 产率（另一半是不要的对映体，需「外消旋化循环」回收）。<span class="marginnote">拆分法被戏称为「一半产物是废物，除非让废物再循环」。但通过「不需要的对映体 → 外消旋化 → 再次拆分」的循环，理论上可以把另一半也转化为目标对映体——这就是「动力学拆分 + 差向异构化」的工业策略。</span>

**方法二：动力学拆分（kinetic resolution）**

利用「两种对映体与手性试剂反应速率不同」来分离：快反应的对映体先被消耗，慢反应的留下。理想情况下，50% 的混合物中，一种对映体完全反应、另一种原封不动。

$$\ce{R-对映体 + 手性酶 ->[快] 产物} \qquad \ce{S-对映体 + 手性酶 ->[慢] 剩余底物}$$

- 脂肪酶催化酯水解是动力学拆分的常用工具；
- 酶的高度手性选择性让动力学拆分「天然高效」。

**方法三：手性色谱（chiral chromatography）**

手性固定相（如环糊精、纤维素衍生物）能区分对映体，使它们在色谱柱上保留时间不同而分离。这是现代分析最常用的手性纯度检测与半制备手段。<span class="marginnote">手性 HPLC 是现代药物分析的标准配置：既能测定 ee 值，也能制备少量纯对映体。它与《分析化学》中的色谱技术、与《不对称合成》的 ee 测量直接衔接——「看得见手性」才能「控制手性」。</span>

**公式解析：拆分效率与产率**

动力学拆分中，分离效果由选择因子 $s$ 决定：

$$s = \frac{k_R}{k_S} = \frac{\text{快对映体的反应速率}}{\text{慢对映体的反应速率}}$$

- $s$ 越大，拆分越彻底（一个反应完、另一个几乎不动）；
- 酶催化的 $s$ 常高达 100–1000，拆分效果极佳；
- 当 $s$ 不够大时，需要「迭代拆分」或改用不对称合成直接控制手性。<span class="marginnote">选择因子 $s$ 与《不对称合成》中的 ee 公式同源：它们都源于「两个对映体经过手性环境的速率/能量差」。$s = 100$ 意味着快对映体的消耗速率是慢的 100 倍——酶这种「天然手性机器」正是靠极高的 $s$ 实现了几乎完美的手性筛选。</span>

**现代趋势**：直接不对称合成（催化控制手性）正逐渐替代「先合成外消旋体再拆分」的路线，因为后者最高 50% 的理论产率是硬伤。但拆分法因其简单可靠，在实验室与工业中仍占一席之地。

## 7 小结

- **手性**是物体与其镜像不能重合的性质；手性碳 = 连有四个不同基团的碳。
- 立体异构分为**对映体**（镜像不重合）与**非对映体**（其余构型异构）。
- 对映体在非手性环境中物理性质相同，在**手性环境**中表现截然不同。
- 手性分子使偏振光旋转，**比旋光度** $[\alpha] = \alpha/(l\cdot c)$ 是其特征常数。
- **ee 值**与**光学纯度**描述对映体混合物的组成，是监测不对称合成的工具。
- 生命偏爱单一对映体，手性药物的两个对映体活性可能完全不同。

在下一节，我们将回答：怎么给手性分子「定名」？R/S 构型如何判断，构象又如何影响分子的能量与反应？这就是**构型与构象分析**。
