## 为什么从酰胺开始

胺是「自由的碱」，但一旦氮连上羰基，就变成了**酰胺（amide）**——化学性格彻底改变。酰胺键是蛋白质的骨架、尼龙的分子砖、许多药物的活性中心。它的稳定性、平面性、弱碱性，全部来自氮孤对电子与羰基的共振。含氮化合物的世界，也远不止胺与酰胺：还有硝基化合物、亚胺、腈、重氮盐、杂环……<span class="marginnote">本节以酰胺为中心，兼览含氮化合物的图谱。理解酰胺，就是理解蛋白质结构与功能化学的钥匙；而硝基、亚胺、重氮盐则是合成化学中的重要中间体。</span>

上一节我们认识了胺，本节看它的「羰基化」与「家族扩展」。两条线索：酰胺的独特结构与反应，以及含氮化合物在合成中的多样角色。

## 1 酰胺：被羰基驯服的氮

**酰胺（amide）**：羧酸衍生物之一，氮直接连在羰基碳上，通式 $\ce{R-CO-NR'2}$。

酰胺的结构独特：
氮的孤对电子与羰基 π 体系**强共轭**，C–N 键有约 40% 双键性质；
因此酰胺是**平面结构**（羰基碳、氮、两个取代基共面）；
氮的碱性大减（pKa 共轭酸约 -0.5），几乎不显碱性；<span class="marginnote">对比胺：胺氮 pKa 共轭酸约 10，酰胺氮约 -0.5——相差 10 个数量级。这就是「孤对被羰基吸收」的代价：酰胺氮的孤对电子参与了共振，不再能自由接受质子。</span>
- 酰胺是所有羧酸衍生物中**最稳定**的，亲电性最弱。

**核心概念：酰胺键（peptide bond）**。氨基酸之间通过酰胺键（肽键）相连，是所有蛋白质的骨架。理解酰胺的平面性与刚性，就理解了蛋白质二级结构的基础。

## 2 酰胺的制备与水解

**制备**：酰胺由羧酸衍生物与胺反应制得（活性下坡路）：

$$\ce{RCOCl + R'NH2 -> RCONHR' + HCl}$$
$$\ce{RCOOR' + R''NH2 -> RCONHR'' + R'OH}$$

**水解**：酰胺是衍生物中最难水解的，需强酸或强碱催化：
$$\ce{RCONH2 + H2O ->[H+ 或 OH-] RCOOH + NH3}$$

**酰胺的还原**：强还原剂 $\ce{LiAlH4}$ 把酰胺还原为胺（C=O 变 $\ce{CH2}$）：
$$\ce{RCONH2 + 4[H] -> RCH2NH2 + H2O}`$$<span class="marginnote">酰胺还原是「从羧酸级官能团制胺」的经典路线，比卤代烃氨解更可控。这个「酰胺 → 胺」的还原在生物碱与药物合成中常用。</span>

**霍夫曼降解（Hofmann rearrangement）**：一级酰胺与次卤酸盐（$\ce{Br2/NaOH}$）反应，脱去羰基碳，生成少一个碳的一级胺：
$$\ce{RCONH2 + Br2 + 4NaOH -> RNH2 + 2NaBr + Na2CO3 + 2H2O}$$

这条反应链「缩短碳链并生成胺」，是合成设计中有趣的碳链操作。

## 3 含氮化合物的家族图谱

含氮化合物远不止胺与酰胺，它们的核心成员各司其职：

| 化合物 | 结构 | 特点 |
| --- | --- | --- |
| 硝基化合物 | $\ce{R-NO2}$ | 强吸电子，芳香硝基易还原 |
| 亚胺 | $\ce{R2C=NR'}$ | 醛酮与胺的缩合产物 |
| 腈 | $\ce{R-CN}$ | 直线形，三键，可还原/水解 |
| 重氮盐 | $\ce{Ar-N2+X-}$ | 芳香重氮盐极活泼 |
| 叠氮 | $\ce{R-N3}$ | 点击化学原料 |
| 含氮杂环 | 吡啶、吡咯、嘌呤 | 生物碱与核酸骨架 |

**亚胺（imine）**：醛酮与伯胺缩合、脱水生成的 C=N 化合物，是生物转氨反应的核心中间体：
$$\ce{R2C=O + R'NH2 -> R2C=NR' + H2O}$$

**硝基化合物**：硝基是极强的吸电子基，芳香硝基可被还原为氨基（制苯胺的工业路线）；硝基也赋予化合物爆炸性（TNT、硝化甘油）。

**重氮盐**：芳香重氮盐（$\ce{ArN2+X-}$）极其活泼，能发生 Sandmeyer 反应（把 $\ce{NH2}$ 换成 Cl、Br、CN 等）与偶联反应（生成偶氮染料）。<span class="marginnote">重氮盐是芳香合成的「万金油」：它把氨基换成卤素、氰基、羟基、氢等几乎任何基团，还能与酚/胺偶联成有色的偶氮化合物——偶氮染料是最重要的合成染料类别。</span>

## 4 公式解析：酰胺的共振与平面性

酰胺的平面性是它最重要的结构特征，其根源是共振稳定化：

$$\ce{R-C(=O)-NR'2 \longleftrightarrow R-C(O^-)=NR'2+}$$

- 共振式使 C–N 键部分双键化（键长 133 pm），键旋转受阻；
- 酰胺的旋转能垒约 60–90 kJ/mol——低于常温可被快速翻转（约 20 kJ/mol 即可）的 C–N 单键，但高于普通单键的旋转自由度；
- 因此酰胺采取**平面（或近平面）构象**，这在蛋白质中形成刚性的肽键平面。<span class="marginnote">肽键平面的生物意义：α-螺旋与 β-折叠正是由这些刚性平面以特定二面角连接而成。相邻两个肽键平面之间可绕 Cα–N 与 Cα–C 键旋转，二面角 φ、ψ 决定了蛋白质的局部构象——这是《生物化学》蛋白质结构学的核心几何。</span>

**酰胺的惰性再利用**：正因为酰胺稳定，蛋白质在生物体内由酶温和水解、在实验室需强酸强碱长时间处理。这种「稳定 → 需要特定条件才反应」的特性，使酰胺成为优秀的**保护基**与**药物骨架**。

## 5 含氮化合物：从染料到药物

**偶氮染料**：重氮盐与芳胺/酚偶联生成偶氮化合物，颜色鲜艳，是最大类合成染料。<span class="marginnote">偶氮染料的颜色来自长共轭体系（N=N 连接两个芳环）。苏丹红、甲基橙都是偶氮化合物。甲基橙还是酸碱指示剂，在《分析化学》中用于滴定终点判断。</span>
**多肽与蛋白质**：酰胺键连接氨基酸，是生命化学的核心骨架。
**尼龙与凯夫拉**：聚酰胺纤维，尼龙-66 与凯夫拉都是酰胺类高分子。
**药物**：对乙酰氨基酚（扑热息痛）、青霉素类、苯二氮䓬类镇静剂都含酰胺或含氮环。<span class="marginnote">从「从极限到大模型」的知识树看，酰胺与含氮化合物是《有机化学》通向《生物化学》（蛋白质、核酸碱基）、《药物化学》（酰胺类药）与《材料科学》（尼龙）的三岔路口。含氮杂环（嘌呤、嘧啶、吡啶）更是核酸与无数生物碱的骨架。</span>
- **炸药与推进剂**：硝基化合物（TNT、RDX、硝化甘油）的能量来自硝基分解。

## 6 含氮杂环：从吡啶到嘌呤

含氮化合物中最丰富的一支是**含氮杂环**。它们既是生物碱与核酸的骨架，也是现代药物与材料的核心结构。

**六元含氮杂环：吡啶与嘧啶**

- **吡啶**：苯环的一个 CH 被氮替换，保留 6 π 电子、芳香稳定，氮上孤对电子指向环外（碱性位点）；
- **嘧啶**：六元环含两个氮（1,3-位），是 DNA 中胞嘧啶、胸腺嘧啶、尿嘧啶的母核。

$$\ce{吡啶（C5H5N）: \text{一个氮、芳香、弱碱}} \qquad \ce{嘧啶（C4H4N2）: \text{两个氮、更缺电子}}$$

**五元含氮杂环：吡咯与咪唑**

- **吡咯**：五元环含一个氮，氮的孤对电子全部参与 π 体系（6 π 电子、芳香），因此吡咯几乎不显碱性；
- **咪唑**：五元环含两个氮，一个氮供 π 电子、另一个氮留孤对（碱性位点），是组氨酸侧链与许多酶活性中心的催化基团。<span class="marginnote">含氮杂环的「电子分工」最精妙之处：同样是氮原子，参与芳香性的氮（提供 π 电子）不显碱性，留在环外的孤对才显碱性。吡啶、咪唑能作碱与配体，吡咯不能——关键就看氮的孤对电子是否被「征用」进 π 体系。</span>

**核心概念：含氮杂环与生物信息载体**

核酸的碱基——嘌呤（腺嘌呤、鸟嘌呤）与嘧啶（胞嘧啶、胸腺嘧啶、尿嘧啶）——都是含氮杂环。DNA 的碱基配对（A-T、G-C）正是杂环之间氢键的精确排布。<span class="marginnote">嘌呤是咪唑与嘧啶稠合的双环，嘧啶是六元二氮杂环。碱基互补配对靠的是杂环上的氢键给体（N-H）与受体（N、O）的精确匹配。含氮杂环化学，因此直接通向《分子生物学》与《遗传学》的核心。</span>

**公式解析：杂环的碱性由孤对电子的「去向」决定**

判断一个含氮杂环的碱性，先问：氮的孤对电子参与芳香性了吗？

| 杂环 | 孤对去向 | 碱性 | pKa(共轭酸) |
| --- | --- | --- | --- |
| 吡啶 | 环外（保留） | 碱 | 5.2 |
| 咪唑 | 一个在环外 | 碱 | 7.0 |
| 吡咯 | 全部进 π 体系 | 近中性 | ≈ 0 |

孤对留在环外 → 能接受质子、显碱性；
孤对参与 π 体系 → 无法接受质子、碱性消失；
咪唑因「一氮供 π、一氮留孤对」而碱性适中，且同时具备酸（N–H）与碱（另一 N），是生物体内的「双功能催化剂」。<span class="marginnote">咪唑的双功能催化是酶学的基础：组氨酸的咪唑侧链既能夺取质子又能提供质子，在丝氨酸蛋白酶等酶的催化循环中扮演「质子穿梭」的角色。理解杂环碱性，就理解了许多酶「怎么干活」。</span>

**应用**：含氮杂环是药物设计的「香饽饽」——抗疟药氯喹（喹啉）、降压药（含吡啶）、抗病毒药（嘧啶类似物）、抗癌药（嘌呤类似物）都以杂环为骨架。理解杂环，是打开《药物化学》大门的钥匙。

## 7 小结

- **酰胺** $\ce{R-CO-NR'2}$：氮连羰基，C–N 键部分双键、平面、弱碱性、最稳定的羧酸衍生物。
- 酰胺由酰氯/酸酐/酯与胺反应制备；水解需强酸/碱。
- 酰胺还原成胺、霍夫曼降解少一个碳——合成中的碳链操作。
- 含氮家族：硝基、亚胺、腈、重氮盐、叠氮、含氮杂环各有专长。
- 重氮盐能转化出多种芳基化合物与偶氮染料。
- 酰胺键是蛋白质骨架，酰胺是尼龙与众多药物的分子砖。
