## 为什么从逆合成分析开始

上一节我们讲了「从原料到产物」的正向合成设计。但化学家真正思考合成时，用的是**逆向**方法：从目标分子出发，一步步「断开」它，回溯到简单可得的原料。这套方法由科里（E. J. Corey）在 1960–70 年代系统化，他因此获 1990 年诺贝尔化学奖。<span class="marginnote">科里把合成设计变成了一门「逻辑学科」：目标分子 → 逆合成分析 → 合成树 → 最短路线的选择。他甚至尝试用计算机辅助（LHASA 系统）——这是计算化学与 AI 辅助合成的先声。</span>

逆合成分析之所以强大，是因为它把「未知的合成问题」转化成「已知的反应知识」：每断开一个键，就对应一个可逆的反应；断到简单原料为止，反向就是完整合成路线。

## 1 逆合成分析的基本语言

**逆合成分析（retrosynthetic analysis）**：从目标分子出发，通过逻辑断开（disconnection）倒推至简单起始原料的过程。

**关键术语**：
**目标分子（target molecule, TM）**：要合成的化合物。
**断开（disconnection）**：在想象中打断一个键，得到两个片段（合成时用特定反应把片段连回）。
**合成子（synthon）**：断开后得到的理想化片段（正离子/负离子/自由基），对应某个实际试剂。
**合成等效试剂（synthetic equivalent）**：实际使用的、能扮演合成子的试剂。<span class="marginnote">例：目标分子含 $\ce{C-OH}$ 键，断开得「羰基合成子（$\ce{C=O}$）」与「烷基负离子合成子（$\ce{R-}$）」，实际用格氏试剂 $\ce{RMgX}$ 进攻羰基——格氏试剂就是烷基负离子的合成等效试剂。</span>
- **逆合成箭头**：用「$\Longrightarrow$」（反推箭头）表示「可由…得到」，区别于正向反应的箭头。

$$\text{目标分子} \xLongrightarrow{\text{断开}} \text{片段 1} + \text{片段 2} \xLongrightarrow{} \text{原料}$$

## 2 逆合成的核心策略

逆合成分析有若干条「战略原则」，帮助你决定从哪个键下手：

**① 优先断开能对应经典反应的键**。如果某个键恰好是格氏反应、D–A 反应、羟醛缩合等「可靠 C–C 成键」能生成的键，优先从它断开。

**② 优先断开「连接处」而非「骨架内部」**。找分子中「最弱」或「最明显」的键——如官能团旁的键、两个大片段之间的键。

**③ 简化原则**：选择使片段尽可能简单、对称、易得的断开方式。<span class="marginnote">目标分子常可以多种方式断开。好的逆合成分析会「试错」：画出几种断开方案，比较哪种导向的片段更简单、原料更便宜、步骤更少——这就像下棋时计算多条变化线。</span>

**④ 官能团转化（FGI）作为辅助**：当目标分子无合适断点，先逆推官能团转化（把目标官能团换成更易断开的基团），再断开。

**⑤ 识别「策略性键」**：寻找分子中能导向已知原料的「天然分界」——如天然产物的生物合成前体、对称结构的中轴线。

## 3 常用断开：C–C 键的经典逆向

C–C 成键反应的逆向断开是最常用的：

| 正向反应 | 逆向断开 | 目标键 |
| --- | --- | --- |
| 格氏加成 | 醇 → 羰基 + 格氏试剂 | $\ce{C-OH}$ 旁的 C–C |
| D–A 反应 | 环己烯 → 二烯 + 亲双烯体 | 环上两个 C–C |
| 羟醛缩合 | β-羟基醛 → 两个醛/酮 | 形成 β-C 的 C–C |
| 烷基化 | 取代产物 → 烯醇负离子 + 卤代烃 | α 位的 C–C |
| Wittig | 烯烃 → 羰基 + 叶立德 | C=C 的一个 C–C |

**示例**：目标分子为 2-甲基-2-丁醇（三级醇），从「羟基碳旁」断开，逆向为：

$$\text{目标}\ \ce{(CH3)2C(OH)CH2CH3} \xLongrightarrow{\text{断开 C-C}} \ce{(CH3)2C=O} + \ce{CH3CH2MgX}$$

正向合成：乙基格氏试剂进攻丙酮，水解得 2-甲基-2-丁醇——一条路线瞬间设计完成。<span class="marginnote">这个例子的精髓：三级醇的「叔碳」暗示它由「酮 + 格氏试剂」而来（格氏加成到酮生成三级醇）。看到分子的官能团与骨架，脑中自动弹出「这可能是哪类反应生成的」——这是逆合成分析的核心能力。</span>

## 4 公式解析：合成树的评估

逆合成分析会生成一棵**合成树**：目标分子在树根，每层断开分出不同分支，树叶是可能的原料。评估哪条分支最优，需综合多个指标：

$$\text{路线评分} = w_1 f(\text{步骤数}) + w_2 f(\text{总收率}) + w_3 f(\text{原料成本}) + w_4 f(\text{风险/安全})$$

- 步骤数：越少越好（总收率指数衰减，见《合成路线设计》）。
- 总收率：各步收率之积。
- 原料成本：起始原料是否廉价易得。
- 风险：中间体是否稳定、反应是否安全、是否需苛刻条件。<span class="marginnote">现代计算机辅助合成（如 ICSynth、Retrosynthesis 的 AI 工具）正是把「合成树 + 评分函数」算法化：用反应数据库与 AI 模型搜索可能的断开路径，按评分排序推荐。这是《计算化学》与《AI for Science》的活跃前沿。</span>

**实用判断**：两条候选路线，一条 4 步每步 80%（总收率 41%）、一条 6 步每步 85%（总收率 38%）——虽然步骤多但收率接近，此时还要比原料成本与安全性，综合取舍。

## 5 逆合成分析在真实合成中

逆合成分析不是纸上谈兵，它是现代全合成的「标准操作」：

**维生素 B₁₂ 的全合成**：伍德沃德与埃申莫瑟的团队用逆合成分析把庞大的 B₁₂ 分子拆解成可操作的片段，分头合成再组装——这是逆合成思想的史诗级应用。
**青蒿素的合成**：从青蒿素（抗疟药）逆推，找到「过氧桥 + 多环」的断开方案，化学合成与生物合成（青蒿素前体经工程酵母发酵）结合，解决了药物供应问题。<span class="marginnote">青蒿素的全合成与半合成是逆合成分析的现代典范：屠呦呦团队发现青蒿素，而合成化学家用逆推思想从双氢青蒿酸出发完成半合成。2015 年诺贝尔生理学或医学奖颁给青蒿素研究。</span>
**计算机辅助合成**：今日的逆合成工具用机器学习从数百万反应中学习，能自动推荐合成路线——化学家与 AI 合作设计合成，是《AI for Science》的活跃方向。<span class="marginnote">从「从极限到大模型」的知识树看，逆合成分析是《有机化学》与《计算化学》《AI for Science》的接口：把「分子的逻辑」变成「可搜索的算法」，正是本博客主线的有趣交汇。</span>

## 6 逆合成分析实例：从目标分子到原料

纸上得来终觉浅，我们用一个完整的例子走一遍逆合成分析全流程。

**目标分子：2-甲基-3-戊醇**

$$\ce{CH3CH2-CH(OH)-CH(CH3)-CH3}$$

**第一步，识别官能团**：分子含二级醇（$\ce{-CH(OH)-}$）。醇可以由羰基还原或格氏加成得到。

**第二步，断开候选方案**：

- **方案 A（格氏加成）**：把 $\ce{C-OH}$ 旁的一根 C–C 键断开，逆向为「醛 + 格氏试剂」：

$$\text{2-甲基-3-戊醇} \xLongrightarrow{\text{断开}} \ce{CH3CH2CHO} + \ce{(CH3)2CHMgX}$$

正推：异丙基格氏试剂进攻丙醛，水解得 2-甲基-3-戊醇。<span class="marginnote">格氏加成的逆推口诀：「醇的羟基碳上还连两个烃基，就断成醛（连一个）+ 格氏（另一个）」；若连三个烃基，则断成酮 + 格氏；若连一个烃基（即甲醇型），断成甲醛 + 格氏。数一数羟基碳上连的基团，答案就出来了。</span>

- **方案 B（还原）**：逆向为「甲基异丙基酮还原」：$\ce{CH3-CO-CH(CH3)2 ->[还原]}$ 目标醇。

**第三步，评估方案**：方案 A 需要异丙基卤与丙醛；方案 B 需要相应的酮。若这些原料都易得，则选步骤更少、更可靠者。格氏试剂与羰基的兼容性、还原试剂的选择（NaBH₄ vs LiAlH₄）都要纳入考虑。

**公式解析：从合成子到合成等效试剂**

逆合成分析把「理想片段」（合成子）翻译成「真实试剂」（合成等效试剂）：

$$\text{烷基负离子合成子 } \ce{R^-} \xrightleftharpoons[\text{实际试剂}]{} \ce{RMgX}\ (\text{格氏试剂})\ \text{或}\ \ce{RLi}\ (\text{有机锂})$$

$$\text{羰基合成子 } \ce{C=O} \xrightleftharpoons[\text{实际试剂}]{} \ce{RCHO}\ \text{或}\ \ce{R2C=O}\ (\text{醛/酮})$$

- 合成子是「逻辑上的离子」，不一定是真实存在的物种；
- 合成等效试剂是「化学上可操作的原料」——格氏试剂扮演碳负离子，醛酮扮演羰基；
- 逆合成分析的精髓：找到「能用现有试剂实现的断开」。<span class="marginnote">这个「逻辑片段 → 实际试剂」的翻译，是逆合成分析区别于「凭空猜想」的关键：每个断开都必须对应一个已知的可靠反应。反过来说，你掌握的反应越多，「可断开的键」就越多——这就是为什么反应知识是合成的弹药库。</span>

**进阶练习**：试试断开环己烯 → 丁二烯 + 乙烯（D–A 逆向）；β-羟基醛 → 两个醛（羟醛缩合逆向）。这些「断键 = 反应逆向」的模式，正是逆合成分析的核心工具箱。

## 7 小结

- **逆合成分析**：从目标分子倒推到简单原料，核心是「断开」与「合成子」。
- 术语：目标分子、断开、合成子、合成等效试剂、逆合成箭头。
- 策略：优先断开对应经典反应的键、简化原则、必要时先做 FGI。
- 常用断开：格氏加成、D–A、羟醛缩合、烷基化、Wittig。
- 合成树 + 评分函数（步骤数、收率、成本、风险）决定路线取舍。
- 逆合成是全合成的标准方法，也与计算机辅助合成/AI 合成直接相连。
