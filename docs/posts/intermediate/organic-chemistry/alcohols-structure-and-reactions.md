## 为什么从醇开始

烃类之后，我们正式进入含氧官能团。第一站是**醇（alcohol）**——分子中含羟基（$\ce{-OH}$）的化合物。醇无处不在：乙醇是酒与燃料，甲醇是化工原料，甘油（丙三醇）是护肤品成分，胆固醇的骨架里也有羟基。<span class="marginnote">羟基是水分子「劈」掉一个氢后的残基（$\ce{-OH}$），因此醇与水有天然的亲和性。但醇的性质由「羟基 + 烷基」共同决定：羟基亲水、烷基疏水，两者博弈出醇的整体行为。</span>

醇是含氧化学的基石：它能被氧化成醛/酮/羧酸，能脱水成烯烃，能与酸成酯，是连接烃类与羰基化学的桥梁。理解醇，等于理解了「羟基的两种身份」——作为酸（失去 H）与作为碱（接受 H）。

## 1 醇的结构：羟基的电子面貌

**醇（alcohol）**：烃分子中的氢被羟基（$\ce{-OH}$）取代而成的化合物，通式 $\ce{R-OH}$。

羟基的电子结构决定了醇的全部化学：

- **氧是 sp³ 杂化**，两个孤对电子占据两个杂化轨道，O–H 键与 C–O 键呈弯曲几何。
- **O 电负性大（3.5）**，C–O 与 O–H 键都强烈极化：氧带 δ−，碳与氢都带 δ+。
- **醇可形成分子间氢键**：$\ce{O-H\cdots O}$，这是醇沸点远高于相应烷烃的根本原因。<span class="marginnote">乙醇沸点 78 °C，乙烷仅 -89 °C——相差 167 °C，全部来自氢键。醇能与水以氢键互溶，但随烷基增长疏水性增强，丁醇以上在水中的溶解度骤降。这是「羟基亲水、烷基疏水」博弈的直观体现。</span>

**醇的酸性**：O–H 键可以解离出质子，pKa 约 16–18，比水（pKa ≈ 15.7）略弱。醇与活泼金属（Na、K）反应放出氢气：

$$\ce{2CH3CH2OH + 2Na -> 2CH3CH2ONa + H2}$$

**醇的碱性**：氧上的孤对电子可以接受质子，使醇显弱碱性——这是醇与酸成酯、以及与卤化氢反应的起点。

## 2 醇的分类与命名

醇按羟基所连碳的取代程度分类：

| 类型 | 结构 | 例子 |
| --- | --- | --- |
| 一级醇（1°） | $\ce{RCH2OH}$ | 乙醇、正丁醇 |
| 二级醇（2°） | $\ce{R2CHOH}$ | 异丙醇 |
| 三级醇（3°） | $\ce{R3COH}$ | 叔丁醇 |

**命名**：以含羟基的最长链为主链，编号使羟基位次最小，后缀 -ol。如 $\ce{CH3CH(OH)CH3}$ 为 2-丙醇；$\ce{HOCH2CH2OH}$ 为 1,2-乙二醇。<span class="marginnote">含多个羟基时用二、三…表示个数（-diol, -triol）。甘油（丙三醇）就是 1,2,3-丙三醇。多羟基化合物的命名在糖类化学中格外重要——葡萄糖、果糖都有多个羟基。</span>

**醇的「两重性」**：羟基既能以质子形式离去（酸性、酯化），又能以氧的形式连接（取代、成醚）。这种「一根键、两种断法」是理解醇反应多样性的钥匙。

## 3 醇的主要反应

醇的反应可分为三大类，分别围绕羟基的三种「出路」：

**① 取代（羟基被卤素替换）**：醇与氢卤酸反应生成卤代烃：
$$\ce{R-OH + HX -> R-X + H2O}$$
反应活性：三级醇 > 二级醇 > 一级醇（三级醇经稳定的叔碳正离子，反应最快）。<span class="marginnote">醇与 HX 的反应实质是「羟基变卤素」。卢卡斯试剂（浓盐酸 + 氯化锌）常用来区分一/二/三级醇：三级醇立即浑浊，二级醇几分钟浑浊，一级醇室温不反应——一个经典的定性鉴别实验。</span>

**② 脱水（消除生成烯烃）**：醇在酸催化下加热脱水：
$$\ce{CH3CH2OH ->[H2SO4, 170°C] CH2=CH2 + H2O}$$
按扎伊采夫规则，主产物是取代较多的烯烃。这是实验室与工业制烯烃的重要方法。

**③ 氧化（生成醛/酮/羧酸）**：羟基碳可被氧化，一级醇 → 醛 → 羧酸，二级醇 → 酮，三级醇不氧化：
$$\ce{CH3CH2OH ->[KMnO4] CH3CHO -> CH3COOH}$$
$$\ce{CH3CH(OH)CH3 ->[K2Cr2O7] CH3COCH3}$$

**辨析｜易错点：** 三级醇因羟基碳上没有氢，无法被氧化成醛酮（需先脱水）。「羟基碳上有几个氢」决定了氧化产物：2 个 → 醛/酸，1 个 → 酮，0 个 → 不氧化。判断氧化产物先数羟基碳上的氢。

## 4 公式解析：醇的酸性与诱导效应

醇的酸性（pKa）随结构变化，核心是**电子效应**。氧上的负电荷越被分散，醇越易失去质子（酸性越强）。

$$\ce{R-OH <=> R-O^- + H+}, \qquad K_a = \frac{[\ce{R-O^-}][\ce{H+}]}{[\ce{R-OH}]}$$

对醇，pKa ≈ 16–18。甲基使醇酸性减弱（甲基给电子，负电荷集中）；而氟代乙醇因 F 的强吸电子诱导效应使酸性增强：

| 醇 | pKa |
| --- | --- |
| 乙醇 $\ce{CH3CH2OH}$ | 16.0 |
| 2-氯乙醇 | 14.3 |
| 三氟乙醇 $\ce{CF3CH2OH}$ | 12.4 |

**诱导效应（inductive effect）**：取代基通过 σ 键的电子拉/推作用。吸电子基（F、Cl、$\ce{NO2}$）把电子拉离氧负离子，分散负电荷，稳定醇负离子，酸性增强；给电子基（烷基）则相反。<span class="marginnote">诱导效应与共轭效应并称有机化学的两大电子效应。诱导效应沿 σ 键传递、随距离衰减，作用相对弱；共轭效应通过 π 体系传递、作用强但需要共轭骨架。后者的精彩案例在《酚》一节（酚的酸性）中会充分展现。</span>

**核心规律**：负电荷越分散，物种越稳定。这个「电荷分散即稳定」的原则，贯穿酸的强度、中间体的稳定性、离去能力等一切判断。

## 5 醇的工业与生物角色

醇是化工与生命体系中的常客：

- **乙醇**：酒类成分、消毒剂、生物燃料（与汽油混合成 E10、E85）、化工原料。<span class="marginnote">燃料乙醇是新能源的重要一环：玉米、甘蔗发酵制乙醇，作为可再生能源替代部分化石燃料。这个「生物质 → 乙醇 → 燃料」的转化是《生物技术与生物工程》与能源交叉的热点。</span>
- **甲醇**：化工基础原料，可制甲醛、乙酸、甲基叔丁基醚等；也是燃料电池的燃料。
- **甘油（丙三醇）**：化妆品保湿剂、药物辅料、硝化甘油炸药的原料。
- **生物分子**：糖类（多羟基醛/酮）、胆固醇、维生素 A 等都含羟基。<span class="marginnote">从「从极限到大模型」的知识树看，醇是《有机化学》通向《生物化学》的枢纽：糖类、脂类、甾体的官能团化学都离不开羟基；《药物化学》中的许多药效团也以羟基为活性中心。</span>

## 6 醇的鉴别：卢卡斯试剂与氧化法

实验室里区分醇的种类、甚至区分醇与酚，有非常实用的化学方法——它们都基于我们已经学过的反应。

**卢卡斯试剂（Lucas reagent）**：浓盐酸 + 无水氯化锌。用于区分一、二、三级醇：

$$\ce{R-OH + HCl ->[ZnCl2] R-Cl + H2O}$$

| 醇的类型 | 反应速度 | 现象 |
| --- | --- | --- |
| 三级醇 | 立即 | 立刻浑浊（生成不溶于水的氯化物） |
| 二级醇 | 数分钟 | 几分钟后浑浊 |
| 一级醇 | 室温不反应 | 保持澄清 |

**原理**：三级醇经稳定的叔碳正离子，SN1 反应极快；一级醇则需强条件。浑浊来自生成的卤代烃不溶于水——用「眼睛」判断反应是否发生，这是经典的定性鉴别实验。<span class="marginnote">卢卡斯试剂的局限：只适用于含 6 个碳以下的醇（小醇溶于水、产物不溶才看得出浑浊）。它把「碳正离子稳定性」这个理论概念直接变成实验台上的「浊度秒表」——理论指导实验的绝佳例子。</span>

**氧化法鉴别**：利用氧化产物的不同来判断醇的种类：
- 一级醇 → 醛 → 羧酸（能被弱氧化剂氧化，托伦试剂银镜、斐林试剂砖红色沉淀）；
- 二级醇 → 酮（不被弱氧化剂氧化）；
- 三级醇 → 不反应。

**公式解析：从键能理解醇的氧化**

醇的氧化本质是「羟基碳上失去氢」。一级醇氧化为醛时，羟基碳上的两个 C–H 键转化为 C=O 双键：

$$\ce{RCH2OH ->[O] RCHO ->[O] RCOOH}$$

- 一级醇羟基碳连 2 个 H → 先氧化为醛（剩 1 个 H）、再氧化为羧酸（0 个 H）；
- 二级醇羟基碳连 1 个 H → 氧化为酮（0 个 H），不再继续；
- 三级醇羟基碳连 0 个 H → 无 H 可失，不氧化。<span class="marginnote">判断醇氧化产物的万能口诀：「数羟基碳上的氢」。2 个氢 → 醛/酸，1 个氢 → 酮，0 个氢 → 不氧化。这个「数氢」的方法不只适用于醇，也适用于判断醛酮的氧化行为——一个简单的计数，概括了一大类反应。</span>

**应用场景**：这些鉴别方法在《分析化学》的定性分析中仍在使用；在现代工业中，乙醇氧化制乙醛（再氧化为乙酸）是重要的化工路线。醇的氧化化学把「理论鉴别」与「工业合成」统一在同一套反应逻辑之下。

## 7 小结

- **醇** $\ce{R-OH}$ 含羟基，氧 sp³、带孤对电子，C–O 与 O–H 键强极化。
- 醇能形成分子间氢键，沸点远高于烷烃；短链醇与水互溶。
- 醇酸性（pKa≈16–18）、碱性（接受质子）兼备，与 Na 反应放出 $\ce{H2}$。
- 醇按羟基碳取代程度分一/二/三级，命名后缀 -ol。
- 主要反应：**取代**（成卤代烃）、**脱水**（成烯烃）、**氧化**（成醛/酮/酸）。
- 酸性受诱导效应调控：吸电子基增强酸性。

在下一节，我们将看到羟基的「加强版」——羟基连在苯环上。苯环的共振效应让酚的酸性突飞猛进，这就是**酚**。
