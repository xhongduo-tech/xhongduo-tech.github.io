## 为什么从马氏规则开始

上一节我们看到 HBr 对乙烯的加成是简单的——两端对称，产物唯一。但现实中的烯烃大多**不对称**，比如 2-丁烯加成 HBr，氢和溴各加到哪一端？马尔科夫尼科夫在 1870 年通过大量实验总结出一条经验规律，至今仍是每一位有机化学学生的第一课。<span class="marginnote">马氏规则是「实验归纳 → 机理解释」的绝佳范例：它先由经验得出，后来才被碳正离子理论从机理上解释。理解它，等于同时理解了一条规则和它背后的电子逻辑。</span>

更重要的是，本节的「反马氏加成」展示了一个深刻道理：**同一试剂，改变反应机理，产物走向就完全反过来**。这让化学家拥有了一把「调控产物结构」的精密旋钮。

## 1 马氏规则：经验表述

以 $\ce{CH3CH=CH2}$（丙烯）与 HBr 的加成为例，理论上 H 可以加到两端，得到两种产物：

$$\ce{CH3-CH=CH2 + HBr -> CH3-CHBr-CH3}\ (\text{主要})$$

$$\ce{CH3-CH=CH2 + HBr -> CH3-CH2-CH2Br}\ (\text{次要})$$

实验表明，主要产物是**2-溴丙烷**——溴加到了取代基较多的碳上。马尔科夫尼科夫总结规律：

**马氏规则（Markovnikov's rule）**：亲电加成中，氢加到含氢较多的碳上（即取代较少的碳上），卤素或负电性部分加到含氢较少的碳上（即取代较多的碳上）。<span class="marginnote">口诀常写作「氢上加氢，卤上加卤」或「富氢的碳得氢」。更本质的记忆方式：产物中，稳定碳正离子中间体那一端（取代多的碳）接的是亲核部分。</span>

这条规则适用于 HX、$\ce{H2O}$（酸催化）、$\ce{H2SO4}$ 等「H–Nu」型试剂的加成。它用一句话统一了大量实验事实，是经验规则最成功的样子。

## 2 马氏规则的机理解释

马氏规则并非铁律，而是**碳正离子稳定性**的自然推论。回到机理：加成第一步生成碳正离子，这一步决定速率与产物走向。

丙烯 + H⁺ 时，H 加到哪一端，正电荷就出现在另一端。比较两种碳正离子：

$$\ce{CH3-CH+-CH3}\ (\text{仲，较稳定}) \qquad \ce{CH3-CH2-CH2+}\ (\text{伯，不稳定})$$

- H 加到 C1（末端），正电荷出现在 C2——形成**仲碳正离子**；
- H 加到 C2，正电荷出现在 C1——形成**伯碳正离子**。

由于仲碳正离子更稳定，反应沿第一条路径进行，产物为 2-溴丙烷。<span class="marginnote">为什么仲碳正离子稳定？相邻的甲基可以通过超共轭与诱导效应把电子「输送」到带正电的碳上，分散正电荷。取代基越多，这种稳定化越强，于是叔 > 仲 > 伯。</span>

**核心结论**：马氏规则的本质是「**让反应经过最稳定的碳正离子中间体**」。只要判断哪个碳正离子更稳定，就能预测加成方向。这一思路——「先想中间体，再定产物」——是学习全部有机反应机理的通用心法。

## 3 反马氏加成：机理切换

到了 1933 年，化学家发现一个「违例」：当 HBr 在**过氧化物**存在下加到丙烯时，产物竟反过来变成 1-溴丙烷（反马氏产物）。<span class="marginnote">这一反常现象被称为「过氧化物效应」（peroxide effect），由卡拉施（Kharasch）与梅奥（Mayo）系统研究。他们发现，过氧化物产生的自由基把反应机理从离子机理切换成了自由基机理。</span>

**反马氏加成的自由基机理**：

1. **引发**：过氧化物 $\ce{RO-OR}$ 均裂生成烷氧自由基 $\ce{RO.}$。
2. **夺氢**：$\ce{RO. + HBr -> ROH + Br.}$ 溴自由基生成。
3. **自由基加成**：溴自由基进攻烯烃双键（富电子处），生成更稳定的碳自由基：
$$\ce{Br. + CH3CH=CH2 -> CH3CH-CH2Br}$$

溴自由基加到 C1 末端，产生的自由基在 C2（仲自由基，较稳定）；若加到 C2，则产生伯自由基（C1），不稳定。因此加成方向被**自由基稳定性**（仲 > 伯）决定。
4. **夺氢再生**：$\ce{CH3CH-CH2Br + HBr -> CH3CH2CH2Br + Br.}$，溴自由基再生，链式循环。<span class="marginnote">关键点：自由基机理中，是「溴原子（自由基）」而不是「氢」先进攻双键。溴加到的位置取决于哪个碳自由基更稳定，结果恰好与离子机理相反——Br 去了取代较少的碳，H 去了取代较多的碳。</span>

产物 1-溴丙烷称为**反马氏产物**（anti-Markovnikov product）。

## 4 公式解析：两种机理的对比矩阵

马氏与反马氏加成的差异，可浓缩成一张对比表——这是本节的「公式解析」：

| 对比项 | 马氏加成 | 反马氏加成 |
| --- | --- | --- |
| 适用试剂 | $\ce{HX}$、$\ce{H2O}$、$\ce{H2SO4}$ | 仅 $\ce{HBr}$ + 过氧化物 |
| 中间体 | 碳正离子 | 碳自由基 |
| 进攻物种 | $\ce{H+}$（亲电） | $\ce{Br.}$（自由基） |
| 稳定性判据 | 碳正离子：叔>仲>伯 | 碳自由基：叔>仲>伯 |
| 溴加到 | 取代多的碳 | 取代少的碳 |
| 产物 | 马氏产物 | 反马氏产物 |

判断一个加成到底走哪条路，用一张流程图：

1. 试剂是 $\ce{HBr}$ 吗？不是 → 必然马氏。
2. 是 $\ce{HBr}$，有$\ce{ROOR}$（过氧化物）吗？有 → 反马氏（自由基机理）。
3. 是 $\ce{HBr}$，无过氧化物 → 马氏（离子机理）。<span class="marginnote">这里要特别强调「仅 HBr」：$\ce{HCl}$、$\ce{HI}$ 即使在过氧化物存在下也不发生反马氏加成。原因是 Cl–H 键较强、Cl 自由基夺取氢的步骤吸热；而 I–H 键虽弱，但碘自由基加成到双键是可逆的，方向不专一。只有 Br 恰到好处。</span>

**辨析｜易错点：** 反马氏不是「规则失效」，而是「机理切换」。马氏规则从未被推翻，只是它描述的离子机理在自由基条件下被另一条通道替代。考试中常见的错误是把「反马氏」当作「例外」死记，而没有理解它背后的自由基逻辑。

## 5 从规则到预测：马氏规则的应用

掌握马氏规则后，面对任何 H–Nu 对烯烃的加成，都能快速预测：

- **$\ce{CH3CH=CH2 + HCl}$** → 2-氯丙烷（马氏）。
- **$\ce{(CH3)2C=CH2 + H2O/H+}$** → 2-甲基-2-丙醇（马氏，经叔碳正离子）。
- **$\ce{CH3CH=CH2 + HBr/ROOR}$** → 1-溴丙烷（反马氏）。<span class="marginnote">水合反应（H₂O + H⁺）在工业上用于从丙烯制异丙醇（2-丙醇），是重要的化工工艺；其马氏方向经仲碳正离子，产物为 2-丙醇而非 1-丙醇。</span>

马氏规则的应用远不止烯烃：它与《碳正离子与重排》一节直接衔接——当形成的碳正离子不稳定时，它还可能发生重排（氢迁移、烷基迁移），生成更稳定的碳正离子，进而改变最终产物。理解了「碳正离子稳定性主导产物」，你就掌握了亲电加成乃至一大类反应的选择性逻辑。

## 6 水合与羟汞化：马氏加成的实验室工具

马氏规则不仅适用于 HX 加成，也适用于**烯烃的水合**（加水）。实验室里实现「马氏水合」与「反马氏水合」各有标准方法。

**马氏水合：酸催化直接水合**

$$\ce{R-CH=CH2 + H2O ->[H2SO4,\ \Delta] R-CH(OH)-CH3}$$

- 氢加到取代少的碳，羟基加到取代多的碳（马氏方向）；
- 产物是二级醇（或三级醇）；
- 机理经碳正离子，可能伴随重排。

**反马氏水合：羟汞化-脱汞（oxymercuration）**

$$\ce{R-CH=CH2 ->[1)\ Hg(OAc)2/H2O\ \ 2)\ NaBH4] R-CH2-CH2OH}$$

- 汞离子先与双键形成环状汞鎓离子，水从背面进攻取代多的碳；
- 随后 $\ce{NaBH4}$ 把汞换成氢，得到**反马氏醇**（羟基加在取代少的碳）；
- 关键优点：**无碳正离子中间体、无重排**——这是羟汞化相对酸催化水合的巨大优势。<span class="marginnote">羟汞化-脱汞是「想反马氏又怕重排」时的首选：汞鎓离子机理不经碳正离子，所以不会发生 1,2-迁移。酸催化水合若经不稳定碳正离子会重排，羟汞化则「绕道」避免了这个问题——一个机理选择解决一个合成难题。</span>

**公式解析：三种加水的对比**

| 方法 | 区域选择性 | 重排 | 关键机理 |
| --- | --- | --- | --- |
| 酸催化水合 | 马氏 | 可能 | 碳正离子 |
| 羟汞化-脱汞 | 反马氏 | 无 | 汞鎓离子 |
| 硼氢化-氧化 | 反马氏 | 无 | 四中心过渡态 |

- 酸催化水合：马氏 + 可能重排；
- 羟汞化：反马氏 + 无重排；
- 硼氢化-氧化：反马氏 + 无重排（且羟基加到末端碳，产物为一级醇）。

**核心结论**：想「马氏醇」用酸催化水合；想「反马氏醇」且怕重排，用羟汞化或硼氢化。方法的选择本质是「机理的选择」——每条路线用不同的中间体绕开或利用马氏规则。<span class="marginnote">硼氢化-氧化是制备反马氏一级醇的经典：$\ce{BH3}$ 对双键的四中心加成把硼加到取代少的碳，氧化后得到末端醇。它与羟汞化一样「无重排」，且给出不同结构的醇——两条路线互补，几乎覆盖了所有水合需求。</span>

**应用**：这些水合方法是合成醇的标准工具箱。从烯烃出发制备特定结构的醇（一级/二级/三级、马氏/反马氏），是药物与天然产物合成的常见起点。把「机理决定区域选择性」这条主线吃透，水合、卤代、加氢的产物就都能预测。

## 7 小结

- **马氏规则**：H 加到富氢的碳，负性部分加到贫氢的碳；适用于 HX、水合等离子机理加成。
- 规则本质是**碳正离子稳定性**：反应经过最稳定的碳正离子中间体。
- **反马氏**：$\ce{HBr}$ + 过氧化物时走**自由基机理**，Br 加到取代少的碳，产物方向反转。
- 反马氏仅限 $\ce{HBr}$；$\ce{HCl}$、$\ce{HI}$ 无此效应。
- 判断流程：是否 HBr → 是否有过氧化物 → 确定机理与产物。
- 「先想中间体、再定产物」是预测有机反应的通用心法。
