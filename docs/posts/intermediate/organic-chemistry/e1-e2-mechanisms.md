## 为什么从 E1/E2 开始

在《消除反应与竞争》一节，我们了解了 β-消除的整体图像与扎伊采夫规则。现在把消除反应的两种机理——**E1 与 E2**——讲透。与 SN1/SN2 平行，E1 是分步（先解离成碳正离子）、E2 是协同（碱夺氢与卤素离去同步）。四者（SN1、SN2、E1、E2）共同构成卤代烃反应的完整机理地图。<span class="marginnote">E1 与 E2 的命名延续「单分子/双分子」逻辑：E1 决速步只涉及底物解离，E2 决速步同时涉及碱与底物。理解 E1/E2 与 SN1/SN2 的亲缘关系，是把机理化学学活的窍门。</span>

本节的目标：把 E1 与 E2 的机理、立体化学、与取代反应的竞争讲清楚，让你能预测「一个卤代烃在特定条件下到底给什么」。

## 1 E2：一步协同的消除

**E2（双分子消除）**：碱夺 β-氢与离去基团离去**同步**进行的单步消除。

$$\ce{B^- + R-CH2-CH2-X ->[\text{过渡态}] R-CH=CH2 + BH + X^-}$$

**关键特征**：
- **一步协同**，无中间体，过渡态中 C–H 断裂、C=C 形成、C–X 断裂同时发生；
- **速率依赖两者**：$\text{rate} = k[\ce{RX}][\ce{B-}]$；
- **反式共平面（anti-periplanar）**：β-氢与离去基团必须处于反式共平面，轨道才能最大化重叠；
- **偏好二级、三级底物**（有 β-氢且位阻利于碱接近）。<span class="marginnote">「反式共平面」是 E2 的立体化学铁律：β-氢与 X 必须处于相反一侧的同一平面。这导致 E2 对产物烯烃的构型有选择性——环状底物中，a（直立）与 e（平伏）键的取向直接决定能生成顺式还是反式烯烃。</span>

**立体化学**：E2 倾向生成**反式（E）烯烃**，因为反式构型允许 β-H 与 X 反式共平面。环己烷衍生物的 E2 常生成反式双取代烯烃。

## 2 E1：分步消除，碳正离子当家

**E1（单分子消除）**：分步消除，第一步底物解离生成碳正离子（决速步），第二步碱夺 β-氢、生成烯烃。

$$\ce{R-X ->[\text{慢}] R+ + X- ->[B^- \ \text{快}] \text{烯烃} + BH}$$

**关键特征**：
- **碳正离子中间体**（与 SN1 共享第一步）；
- **速率只依赖底物**：$\text{rate} = k[\ce{RX}]$；
- **需要三级底物**（碳正离子稳定）；
- **可能重排**（碳正离子重排后再消除）；
- **弱碱有利**（强碱会走 E2）。

**E1 与 SN1 的纠缠**：E1 与 SN1 的第一步完全相同（都是碳正离子），只是第二步不同——亲核试剂结合（SN1）还是碱夺氢（E1）。因此 E1 几乎总与 SN1 竞争，三级卤代烃在无强碱时通常同时给出取代与消除产物。<span class="marginnote">E1 与 SN1 是「同源兄弟」：共享碳正离子中间体，产物一个是取代、一个是消除。这也解释了为什么三级卤代烃的水解常伴随烯烃副产物——这是 E1 与 SN1 竞争的直接体现。</span>

## 3 E1 与 E2 的对比

把两种消除机理与两种取代机理放在一起，形成「机理四联体」：

| 对比项 | SN1 | SN2 | E1 | E2 |
| --- | --- | --- | --- | --- |
| 步骤 | 分步 | 一步 | 分步 | 一步 |
| 决速步 | 解离 | 进攻 | 解离 | 协同 |
| 中间体 | 碳正离子 | 无 | 碳正离子 | 无 |
| 速率方程 | $k[\ce{RX}]$ | $k[\ce{RX}][\ce{Nu}]$ | $k[\ce{RX}]$ | $k[\ce{RX}][\ce{B-}]$ |
| 底物偏好 | 3° | 1° | 3° | 2°、3° |
| 碱强度 | 弱 | 强亲核 | 弱 | 强碱 |
| 温度 | 低 | 低 | 高 | 高 |

**核心规律**：
**SN2 与 E2 竞争**（都是一步、都依赖第二物种）：强亲核弱碱 → 取代，强碱大位阻 → 消除。
**SN1 与 E1 竞争**（都经碳正离子）：产物是取代与消除的混合物，弱碱、极性质子溶剂有利。
升温、大体积强碱 → 消除；低温、强亲核 → 取代。<span class="marginnote">判断机理四联体的实用口诀：先看底物（3° 走碳正离子路线 SN1/E1，1° 走 SN2，2° 看试剂），再看试剂（强碱大位阻 → E2，强亲核 → SN2，弱亲核 → SN1/E1），最后看温度（高温 → 消除）。</span>

## 4 公式解析：E2 的速率与反式共平面

E2 的速率方程与立体化学要求都可以定量理解：

$$\text{rate}_{E2} = k[\ce{RX}][\ce{B-}]$$

- 浓度乘积反映了决速步中碱与底物同时参与；
- $k$ 对温度、碱强度、底物结构敏感。

**为什么要求反式共平面？** 用轨道图像理解：β-H 的 σ 键（C–H）与离去基团的 σ*（C–X 反键轨道）需要最大重叠，才能让电子从 C–H 键「流入」C–X 反键、促成断裂。只有当 β-H 与 X 处于反式共平面时，这两个轨道才能平行重叠：

$$\text{最大重叠} \iff \text{H-C-C-X 二面角} = 180^\circ`$$<span class="marginnote">这个轨道图景把 E2 的立体化学要求讲透了：电子需要「反键轨道接力」才能流动。反式共平面让 C–H 成键轨道与 C–X 反键轨道对齐，电子高效地从 C–H 转移到 C–X 反键，促成双键形成与卤素离去。这也是《协同反应与轨道对称》的前奏。</span>

**实际应用**：在环己烷衍生物中，只有 a（直立）取向的 β-H 与离去基团能保持反式共平面，因此 E2 消除常发生在直立键上的 β-氢，产物的立体化学可以预测。

## 5 机理选择与合成策略

面对「一个卤代烃 + 一种试剂」，如何预测主产物？用决策树：

1. **底物是一级** → 主要走 SN2（取代），除非用大体积强碱（如叔丁醇钾）则走 E2。
2. **底物是三级** → 走碳正离子路线（SN1/E1）；用强碱则走 E2 消除。
3. **底物是二级** → 最纠结：强亲核弱碱 → SN2；强碱大位阻 → E2；弱亲核质子溶剂 → SN1/E1 混合物。
4. **温度**：高温把平衡与速率都推向消除（E1/E2 活化能更高）。<span class="marginnote">二级底物的判断最常考也最容易错。关键抓手是「试剂的体积与强度」：叔丁醇钾几乎总是给 E2，碘化钠（丙酮中）几乎总是给 SN2。记住几个「标志性试剂」，判断就快多了。</span>

**合成启示**：想合成烯烃 → 三级底物 + 强碱 + 高温（E2）；想保留取代产物 → 一级底物 + 强亲核 + 低温（SN2）。机理知识直接转化为合成条件的选择。

## 6 E2 的立体化学：反式消除的应用

E2 的「反式共平面」要求不仅是一个理论细节，它直接决定了反应产物与立体化学，也是合成中控制产物构型的工具。

**环己烷衍生物的 E2 消除**

在环己烷衍生物中，β-氢必须与离去基团处于反式共平面。由于环己烷椅式中 a（直立）键与 e（平伏）键的取向固定，只有**处于反式双直立（antiperiplanar a/a）**的 β-氢与离去基团才能高效消除。<span class="marginnote">想象环己烷衍生物：离去基团占 a 键时，只有对面的 a 键 β-氢能与之反式共平面。所以 E2 消除「挑」特定的 β-氢，产物的双键位置与顺反构型都因此被锁定——这是「几何约束决定立体化学」的典范。</span>

**核心概念：E2 是立体专一的。** 因为反式共平面是硬性要求，E2 消除时 β-氢与离去基团的相对取向「写死」了产物的构型。例如，从特定的反式-2-溴环己烷衍生物消除，只会得到特定构型的环己烯。

**公式解析：Zaitsev vs Hofmann 产物的竞争**

消除反应可能生成两种烯烃：取代多的（Zaitsev，通常主产物）与取代少的（Hofmann，大体积碱时的产物）：

$$\ce{R-CH2-CH(Br)-CH3 ->[碱] R-CH=CH-CH3\ (Zaitsev) + R-CH2-CH=CH2\ (Hofmann)}$$

- **小体积强碱**（如 $\ce{OH-}$、$\ce{CH3O-}$）：能接近取代多的 β-氢，生成 Zaitsev 产物（更稳定）；
- **大体积强碱**（如叔丁醇钾 $\ce{(CH3)3COK}$）：位阻大，难以接近取代多的 β-氢，转而夺取空间上更易接近的 β-氢，生成 Hofmann 产物（取代少的烯烃）。<span class="marginnote">「Hofmann 产物」是对大体积碱反应产物的称呼：叔丁醇钾体积庞大，被取代多的 β-氢旁边的烷基「挡住」，只好去夺位阻小的末端 β-氢，得到末端烯烃。这条「碱的体积 → 产物选择性」的规律，是消除反应中最精彩的调控旋钮之一。</span>

**合成应用**：想要 Zaitsev 烯烃用 $\ce{OH-}$/$\ce{CH3O-}$，想要 Hofmann 烯烃（末端烯烃）用叔丁醇钾。通过「换碱」就能切换产物结构——机理知识直接变成合成工具。此外，E2 的立体专一性被用于构建特定构型的烯烃，是天然产物合成中「安装双键」的可靠手段。

## 7 小结

- **E2**：一步协同、碱夺 β-H 与离去同步、$k[\ce{RX}][\ce{B-}]$、反式共平面、偏好 2°/3°。
- **E1**：分步解离、碳正离子中间体、$k[\ce{RX}]$、偏好 3°、弱碱。
- 机理四联体：SN2/E2（一步，竞争），SN1/E1（碳正离子，竞争）。
- 判断抓手：底物取代程度 + 试剂体积/强度 + 温度。
- E2 的反式共平面可用轨道重叠理解，是轨道对称守恒的前奏。
- 合成策略：消除要高温强碱、取代要低温强亲核。
