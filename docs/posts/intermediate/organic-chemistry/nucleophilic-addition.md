## 为什么从亲核加成开始

上一节我们认识了羰基：碳带 δ+，是亲核进攻的靶心。现在我们把镜头拉近，看看**亲核加成（nucleophilic addition）**到底如何发生——亲核试剂怎样加到羰基碳上、氧又怎样变成羟基、各种亲核试剂如何衍生出醛酮的丰富产物化学。<span class="marginnote">亲核加成是醛酮区别于烯烃的关键反应类型：烯烃做亲电加成（π 电子富集），醛酮做亲核加成（碳 δ+）。两种「加成」方向正好相反，这是有机化学中一对极佳的对比教材。</span>

亲核加成的产物覆盖广谱：加氢生成醇、加水生成水合物、加醇生成缩醛、加 HCN 生成氰醇、加胺生成亚胺、加格氏试剂生成新醇……理解统一的机理，就能一通百通地掌握整族反应。

## 1 亲核加成的通用机理

醛酮的亲核加成分两步：

**第一步（亲核进攻）**：亲核试剂 $Nu^-$ 进攻羰基碳的 δ+，π 电子被推向氧，生成**四面体中间体（tetrahedral intermediate）**，碳由 $sp^2$ 变成 $sp^3$：

$$\ce{R2C=O + Nu^- ->[\text{快}] R2C(O^-)(Nu)}$$

**第二步（质子化）**：氧负离子（带 δ− 或负电荷）从溶剂或酸中获得质子，生成羟基：

$$\ce{R2C(O^-)(Nu) + H+ -> R2C(OH)(Nu)}$$

**核心特征**：
- 决速步通常是第一步亲核进攻（对强亲核试剂）或质子化（对弱亲核试剂）。
- 反应可逆：加成的逆过程（脱水消除）在特定条件下发生。
- 产物是**四面体碳**（原 $sp^2$ → $sp^3$），羰基消失，生成新的 C–Nu 键与羟基。<span class="marginnote">把羰基想象成「平面三角形」，亲核加成后变成「四面体」——几何上从 120° 键角变 109.5°。这个「平面 → 四面体」的转变是识别加成是否发生的几何判据，也与《立体化学》中的面进攻（顺式/反式）直接相关。</span>

## 2 各族亲核试剂与产物

亲核试剂千变万化，但机理骨架一致。常见亲核试剂及其产物：

| 亲核试剂 | 产物 | 反应类型 |
| --- | --- | --- |
| $\ce{H2O}$ | 偕二醇（水合物） | 水合 |
| $\ce{ROH}$ | 半缩醛/缩醛 | 醇加成 |
| $\ce{HCN}$ | 氰醇（α-羟基腈） | 氰化 |
| $\ce{RNH2}$ | 亚胺（Schiff 碱） | 胺缩合 |
| $\ce{RMgX}$ | 醇（格氏加成） | C–C 成键 |
| $\ce{NaBH4/H-}$ | 醇 | 还原 |
| $\ce{Ph3P=CHR}$ | 烯烃 | Wittig 反应 |

**① 加 HCN 成氰醇**：HCN 的亲核碳进攻羰基，生成 α-羟基腈（氰醇），是增长碳链的重要反应：

$$\ce{CH3COCH3 + HCN ->[碱] (CH3)2C(OH)CN}$$

**② 加胺成亚胺**：伯胺的氮进攻羰基，脱水后生成亚胺（C=N）：

$$\ce{R2C=O + R'NH2 -> R2C=NR' + H2O}$$

亚胺是生物体内许多转氨反应的关键中间体。<span class="marginnote">亚胺（Schiff 碱）是维生素 B6 参与的转氨反应、以及多种酶催化过程的中间体。从醛酮到亚胺的转化是《生物化学》氨基酸代谢的核心步骤之一。</span>

**③ 格氏加成**：格氏试剂 $\ce{RMgX}$ 的碳负离子进攻羰基，生成醇，是构建 C–C 键的重要方法：

$$\ce{R2C=O + R'MgX ->[①加成 ②水解] R2C(OH)R'}$$

## 3 缩醛与半缩醛：醛酮的「保护」

醛酮与醇的加成产物具有重要的合成意义。

**半缩醛（hemiacetal）**：一分子醇加到羰基上，生成半缩醛（碳连 OH 与 OR）：

$$\ce{R-CHO + R'OH ->[H+] R-CH(OH)(OR')}$$

**缩醛（acetal）**：半缩醛再与一分子醇反应（脱水），生成缩醛（碳连两个 OR）：

$$\ce{R-CH(OH)(OR') + R'OH ->[H+] R-CH(OR')2 + H2O}`$$<span class="marginnote">注意半缩醛仍含羟基、可逆地回到醛；缩醛没有羟基、对碱稳定，只在酸下水解回醛。这个「保护基」逻辑是合成设计的常用技巧：先把醛保护成缩醛，让其他反应安全进行，最后酸解恢复醛。</span>

**核心概念：缩醛作为醛的保护基**。醛基活泼，在合成中常干扰其他反应（如被还原、被格氏试剂进攻）。把醛转成缩醛后，醛基被「隐藏」，其他反应可以放心进行；最后用稀酸水解，醛基「复活」。

$$\text{醛} \xrightarrow{\ce{ROH/H+}} \text{缩醛（保护）} \xrightarrow{\text{其他反应}} \text{缩醛} \xrightarrow{\ce{H3O+}} \text{醛（恢复）}`$$<span class="marginnote">缩醛保护是合成中「先保护、后反应、再脱保护」策略的经典例子。糖化学里，葡萄糖在溶液中以环状半缩醛形式存在，正是这个反应的生物版——糖的环状结构与缩醛化学一脉相承。</span>

## 4 公式解析：加成的平衡与热力学

亲核加成往往是**可逆平衡**反应，其平衡位置取决于亲核试剂与底物。对水合反应：

$$\ce{R2C=O + H2O <=> R2C(OH)2}$$

平衡常数 $K_{hyd}$ 反映水合程度。甲醛的水合常数 $K_{hyd} \approx 2000$（几乎完全水合），丙酮仅约 $2\times10^{-3}$：

$$K_{hyd} = \frac{[\text{水合物}]}{[\text{羰基}][\ce{H2O}]}$$

**为什么差异巨大？** 水合生成偕二醇，涉及碳从 $sp^2$ 到 $sp^3$ 的变化。醛的羰基碳更缺电子（δ+ 更强）、更易被水进攻，且水合后释放的空间张力小；酮的两个烷基提供位阻、又降低 δ+，水合困难。<span class="marginnote">这个平衡常数的巨大差异（$10^6$ 倍）再次印证「醛比酮活泼」：甲醛几乎全部水合，丙酮几乎不水合。热力学数据把活性差异从定性变成了定量。</span>

**一般规律**：羰基碳越缺电子、位阻越小，亲核加成越容易；亲核试剂越强（碳负离子 > 氮 > 氧），加成越彻底。强亲核试剂（如格氏试剂、氢化物）的加成不可逆，弱亲核试剂（水、醇）的加成可逆。

## 5 亲核加成在合成中的应用

亲核加成是碳碳成键的核心手段，也是天然产物合成的常规武器：

**增长碳链**：加 HCN 成氰醇（多一个碳），格氏加成（多一个烷基）。
**合成醇**：还原（NaBH₄、LiAlH₄）或格氏加成，分别得一级/二级/三级醇。
**构建烯烃**：Wittig 反应用磷叶立德把羰基转成烯烃（碳碳双键），是有机合成的「换键神器」。
**生物合成**：醛缩酶催化羟醛缩合，是糖代谢中碳碳成键的生化版。<span class="marginnote">亲核加成是《有机合成路线设计》与《逆合成分析》的基本操作：想在某个位置装羟基、胺基、烷基或双键，往往就是规划一次亲核加成。它也是《化学生物学》中生物正交反应、代谢标记的化学基础。</span>

## 6 亲核加成的立体化学与生物版

亲核加成不仅决定「加了什么」，还常决定「从哪个面加」——立体化学在羰基加成中格外重要。

**羰基的面选择性**

羰基是平面三角形，亲核试剂可以从两个面（re 面与 si 面）进攻。当羰基两侧取代基不同时，两个面不等价，反应会偏向从位阻小的一面进攻：

位阻大的取代基「挡住」一侧，亲核试剂优先从另一侧进攻；
若底物本身含手性中心，亲核加成可以实现**非对映选择**——这是《不对称合成》中「内源手性诱导」的基础。<span class="marginnote">想象酮的羰基平面：一侧被大基团「占着」，亲核试剂只能从空旷的一侧进攻，产物以某一立体异构体为主。这种「从哪面进攻」的偏好，是羰基化学通往立体化学的关键桥梁，也是合成含手性醇的核心考量。</span>

**生物版亲核加成：醛缩酶与转氨酶**

亲核加成在生物体内由酶催化，效率与选择性远超实验室：

- **醛缩酶**催化羟醛缩合（碳负离子对羰基的加成），是糖代谢（糖酵解/糖异生）中 C–C 成键的核心；
- **转氨酶**催化羰基与氨基的加成-消除（生成亚胺中间体），是氨基酸代谢的枢纽；
- 酶的活性口袋用「手性环境」控制面选择性，只生成一种立体异构体。

**公式解析：加成反应的立体化学追踪**

追踪亲核加成中羰基碳的构型变化：

$$\ce{R2C=O\ (sp^2,\ 平面) ->[Nu^-] R2C(O^-)(Nu)\ (sp^3,\ 四面体)}$$

- 加成前羰基碳是平面（$sp^2$）；
- 加成后变成四面体（$sp^3$）——若四个基团互不相同，则产生新的手性中心；
- 「平面 → 四面体」的转变意味着：**亲核加成是新立体中心生成的时刻**。<span class="marginnote">这是《立体化学：手性与旋光》一节的直接延伸：许多手性分子的手性中心，正是由一次亲核加成「创造」出来的。控制这次加成的面选择性（从 re 还是 si 面进攻），就控制了产物的绝对构型——这正是不对称合成的核心。</span>

**应用**：从羰基化合物的亲核加成制备手性醇、手性胺，是现代药物合成的常规操作。理解「加成造手性、面选择定构型」，就把亲核加成从「官能团转化」提升到了「立体化学控制」的层次——这是通往《不对称合成》的必经之路。

## 7 小结

- 亲核加成机理：**亲核进攻成四面体中间体 → 质子化**，羰基碳由 $sp^2$ 变 $sp^3$。
- 常见亲核试剂：水、醇、HCN、胺、格氏试剂、氢化物，产物各异。
- 半缩醛/缩醛化学：醛可被保护为缩醛，酸解恢复，是合成中的保护基策略。
- 加成常为可逆平衡，$K_{hyd}$ 由羰基缺电子程度与位阻决定（醛≫酮）。
- 强亲核试剂加成不可逆，弱亲核试剂可逆。
- 亲核加成是增长碳链、合成醇/烯烃、构建 C–C 键的核心手段。
