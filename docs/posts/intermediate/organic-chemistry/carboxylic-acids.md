# 羧酸

## 为什么从羧酸开始

醛、酮之后，我们来到含氧官能团的「终点站」之一——**羧酸（carboxylic acid）**。它含**羧基（carboxyl, $\ce{-COOH}$）**，是羟基与羰基的「合体」。乙酸是醋的酸味来源，柠檬酸是水果的酸味来源，脂肪酸构成油脂，氨基酸与蛋白质的骨架里也都有羧基。<span class="marginnote">羧酸是有机化学里最重要的酸性官能团，pKa 约 4–5，远强于酚（10）与醇（16）。这个「强酸」的身份使它成为中和反应、酯化反应、以及无数生物过程的枢纽。</span>

理解羧酸，是理解后续所有羰基衍生物（酯、酰胺、酰氯、酸酐）的起点——因为它们都是羧酸的「变形」。掌握羧基的电子结构，就能推知整族羧酸衍生物的反应逻辑。

## 1 羧基的结构：共振稳定的秘密

**羧酸（carboxylic acid）**：含羧基（$\ce{-COOH}$）的化合物，通式 $\ce{R-COOH}$。

羧基的结构极其精巧：羰基碳与羟基氧相邻，羟基氧的孤对电子能与羰基 π 体系共轭，形成**共振稳定**：

$$\ce{R-C(=O)-OH \quad\longleftrightarrow\quad R-C(O^-)=OH+}$$

两个共振式使羧酸的 C–O 键、C=O 键都呈「平均化」：实测甲酸的 C=O 键长 123 pm、C–O 键长 136 pm，都不完全是纯双键或纯单键。<span class="marginnote">羧基的共振是理解它一切性质的钥匙：为什么羧酸比醇酸性强？为什么羧酸的羰基不如酮的羰基活泼？答案都在这两个共振式里。羧基是「羰基 + 羟基 + 共振」的完美组合。</span>

**核心概念：羧基的共振稳定化**。羟基氧的孤对电子「借」给羰基，使整个羧基成为一个平面、共轭、低能的体系。这一稳定化既是酸性的来源，也是羧基惰性（相对酮）的根源。

## 2 羧酸的酸性：为什么它这么强

羧酸 pKa ≈ 4–5，比醇（16）强 $10^{11}$ 倍，比酚（10）强约 $10^5$ 倍。原因：**羧酸根负离子的共振稳定**。

失去质子后生成羧酸根（carboxylate）：

$$\ce{R-COOH <=> R-COO^- + H+}$$

羧酸根负离子的负电荷被两个氧原子**等分**，通过共振离域：

$$\ce{R-C(=O)O^- \longleftrightarrow R-C(O^-)=O}$$

- 两个 C–O 键完全等价（实测键长相等，均为约 126 pm）；
- 负电荷分散在两个氧上，负离子特别稳定；
- 因此平衡强烈偏右，酸性强。<span class="marginnote">对比醇：醇负离子 $\ce{RO^-}$ 的负电荷困在单个氧上，无共振离域，稳定性差，故酸性弱。酚负离子有苯环共振（负电荷可到环碳），比醇强但仍不如羧酸根——因为羧酸根的负电荷分散在两个电负性氧上，效率最高。</span>

**取代基对酸性的影响**：吸电子基增强酸性，给电子基减弱酸性。

| 羧酸 | pKa |
| --- | --- |
| 乙酸 $\ce{CH3COOH}$ | 4.76 |
| 氯乙酸 $\ce{ClCH2COOH}$ | 2.87 |
| 二氯乙酸 | 1.29 |
| 三氯乙酸 | 0.65 |
| 甲酸 $\ce{HCOOH}$ | 3.77 |

氯代个数越多、酸性越强——吸电子诱导效应稳定羧酸根负离子。这一趋势与《酚》一节的哈米特方程思想完全一致：负电荷越分散，酸越强。

## 3 羧酸的常见反应

羧酸的反应都围绕两个活性点：**O–H 键（酸性）**与**羰基碳（亲电）**。

**① 成盐**：与碱中和：
$$\ce{CH3COOH + NaOH -> CH3COONa + H2O}$$

**② 酯化**：与醇在酸催化下生成酯（详见《酯化与水解》一节）：
$$\ce{R-COOH + R'OH <=>[H+] R-COOR' + H2O}$$

**③ 成酰氯**：与亚硫酰氯反应生成酰氯（更强的亲电试剂）：
$$\ce{R-COOH + SOCl2 -> R-COCl + SO2 + HCl}$$

**④ 还原**：强还原剂（$\ce{LiAlH4}$）把羧基还原为一级醇：
$$\ce{R-COOH ->[LiAlH4] R-CH2OH}$$

**⑤ 脱羧**：某些条件下失去 $\ce{CO2}$，碳链减少一个碳。<span class="marginnote">脱羧反应在生物体内意义重大：丙酮酸脱羧、柠檬酸循环中的脱羧步骤，都是碳链缩短的关键环节。β-酮酸尤其容易脱羧，这是《生物化学》中糖代谢的核心步骤。</span>

## 4 公式解析：酸强度的定量——pKa 与结构

羧酸的酸性可以用 pKa 精确量化，而 pKa 与结构的关系可从热力学循环理解。对电离平衡：

$$\ce{R-COOH <=> R-COO^- + H+}, \qquad pK_a = -\log K_a$$

**与取代基的定量关系（哈米特方程应用于羧酸）**：对取代苯甲酸：

$$\log\frac{K_a}{K_a^0} = \sigma\rho, \qquad \rho \approx 1.0\ (\text{苯甲酸电离})$$

- $\sigma$：取代基常数（吸电子正、给电子负）；
- $\rho$：反应常数（苯甲酸酸性对取代基的敏感度约 1.0）。

取对硝基苯甲酸：$\sigma(\ce{NO2}) \approx +0.78$，则 $\log(K_a/K_a^0) \approx 0.78$，$K_a \approx 6 K_a^0$，pKa 比苯甲酸（4.20）低约 0.78，约 3.42。预测与实测（3.44）吻合。<span class="marginnote">哈米特方程的价值在于「可移植」：同一个 σ 值可用于不同反应，只需换 ρ。它把「吸电子/给电子」的定性语汇翻译成了可计算的数量，是现代定量构效关系（QSAR）与机器学习构效模型的先驱。</span>

**核心逻辑**：酸强度 ∝ 羧酸根负离子的稳定性。任何能稳定负电荷的因素（共振、诱导吸电子、离域）都增强酸性；任何集中负电荷的因素都减弱酸性。

## 5 羧酸：从调味品到生物分子

**乙酸（醋酸）**：食醋主要成分，工业上用甲醇羰基化生产，是制乙酸乙烯酯（PVAc、PVA 原料）、醋酐的原料。<span class="marginnote">乙酸是全球产量最大的有机酸之一，年产量数百万吨。从发酵酿醋到石油化工的甲醇羰基化，乙酸的制造史本身就是一部化学工业简史。</span>
**脂肪酸**：长链羧酸是油脂（甘油三酯）的组分，是能量储存与细胞膜（磷脂）的基础。
**氨基酸**：蛋白质单体含有羧基与氨基，羧基参与肽键形成。<span class="marginnote">氨基酸的羧基与氨基缩合成肽键（酰胺键），是蛋白质一级结构的化学本质。这一连接让《有机化学》的羧酸化学直接通向《生物化学》与《分子生物学》。</span>
**药物与材料**：阿司匹林（乙酰水杨酸）含羧基；对苯二甲酸是 PET 塑料单体；许多非甾体抗炎药（布洛芬、萘普生）都是羧酸类。
**天然产物**：柠檬酸（柑橘）、酒石酸（葡萄）、草酸（菠菜）等。

## 6 二元羧酸与羟基酸

羧酸家族不止单羧酸，还有二元酸、羟基酸等成员，它们有独特的性质与应用。

**二元羧酸（dicarboxylic acid）**：含两个羧基的酸。草酸、丙二酸、丁二酸、己二酸（尼龙单体）都是重要成员。两个羧基互相影响：第一个解离后，第二个羧基因邻近负电荷而更难解离（pKa₂ > pKa₁）。<span class="marginnote">草酸（乙二酸）是果蔬（菠菜、甜菜）中的天然成分，能与钙结合成草酸钙（结石成分）；己二酸是尼龙-66 的单体，工业上大量生产。二元酸的 pKa 递变是「电荷效应影响酸性」的经典例子。</span>

**羟基酸（hydroxy acid）**：同时含羟基与羧基的酸，如乳酸（酸奶）、柠檬酸（柑橘）、苹果酸、酒石酸（葡萄）。羟基酸的羟基能参与分子内氢键与螯合，影响溶解度与酸性。

**核心概念：羧酸的多种存在形态。** 羧酸既可以是单酸、二元酸、羟基酸，也可以是不饱和酸（含双键）、芳香酸（连苯环）。识别「羧酸骨架上还连了什么」，是判断它性质的第一步。

**公式解析：二元酸的逐步解离**

以草酸为例：

$$\ce{HOOC-COOH <=>[K_{a1}] HOOC-COO- + H+ <=>[K_{a2}] ^-OOC-COO- + 2H+}$$

- $K_{a1}$（第一个羧基解离）相对较大（草酸 pKa₁ ≈ 1.25）；
- $K_{a2}$（第二个羧基解离）明显更小（pKa₂ ≈ 4.27），因为负电荷在阴离子上积累、解离更难；
- 两个 pKa 相差约 3 个单位，说明「电荷效应」在二元酸中显著。<span class="marginnote">二元酸的 pKa₁ 通常比一元酸低（另一个羧基吸电子），pKa₂ 又比 pKa₁ 高（负电荷排斥）。这个「先易后难」的两步解离，是《分析化学》中「多元酸分步滴定」的理论基础——每个解离台阶对应一个滴定突跃。</span>

**应用**：柠檬酸是食品酸味剂与金属螯合剂；酒石酸用于拆分外消旋体与软饮料；己二酸/对苯二甲酸是聚酯、尼龙的原料。二元酸与羟基酸的螯合能力使它们在配位化学与生物化学（柠檬酸循环）中扮演重要角色。

## 7 小结

- **羧酸** $\ce{R-COOH}$ 含羧基，是羰基与羟基的「合体」，pKa ≈ 4–5。
- 羧酸强酸性源于**羧酸根负离子的共振稳定**（负电荷分散到两个氧）。
- 吸电子取代基增强酸性（氯代乙酸 pKa 低至 0.65），哈米特方程定量描述。
- 主要反应：**成盐、酯化、成酰氯、还原、脱羧**。
- 羧酸是脂肪、氨基酸、药物、塑料单体的基础官能团。
- 酸性 ∝ 羧酸根负离子稳定性，是判断一切酸强度的核心逻辑。

在下一节，我们将看看羧基的「变身」产物——酯、酰胺、酰氯、酸酐这些羧酸衍生物，它们共享羰基却各有性格：**羧酸衍生物**。
