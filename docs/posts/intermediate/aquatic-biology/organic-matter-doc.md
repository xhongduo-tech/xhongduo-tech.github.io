## 为什么有机质是生态系统的「货币」

生态系统的能量流本质上是有机碳的流动：光合作用把无机碳变成有机碳，异养生物把有机碳消耗、转化、矿化。**有机质（organic matter）就是生态系统的「货币」**——它的总量、形态与去向，决定了湖泊是「净生产者」还是「净消费者」、是碳汇还是碳源。本节把有机质分成颗粒态与溶解态两大库，重点讲透易被忽视却占绝大多数的**溶解性有机物（DOC）**——它是微生物环的燃料，也是水色的来源。<span class="marginnote">湖泊中的有机碳绝大多数以溶解态存在：DOC 常占总有机碳的 80–95%，颗粒有机碳（POC）只占少数。研究有机质，重点是研究溶解态。</span>

## 1 有机质的来源：内源与外源

湖泊有机质有两个来源：

**内源有机质（autochthonous）**：湖内光合作用产生——浮游植物、底栖藻、水生植物的分泌物、死亡细胞与残体。内源有机质新鲜、易分解、营养丰富。

**外源有机质（allochthonous）**：流域输入——土壤淋溶的腐殖质、落叶、污水有机质、大气沉降。外源有机质多为难降解的腐殖质，营养相对贫乏但数量常很大。<span class="marginnote">贫营养湖与森林湖泊中外源有机质常占主导：湖水呈茶褐色就是外源腐殖质（DOC）的杰作。外源输入把流域的碳「搬」进湖里，使湖的碳收支与流域紧密耦合。</span>

内外源的「质」与「量」常成反比，
这是理解有机质的一把钥匙：**外源有机质数量大但难分解（腐殖质为主），内源有机质数量小但易分解（藻类分泌物、死亡细胞为主）**。
因此一个湖的有机质「总量」高，
未必代表「可利用能量」高——富营养湖的内源比例高，
能量可利用率高；
森林小湖的外源比例高，
大部分碳是「死碳」。
判断一个湖泊的能量供给状况，
不能只看有机质总量，
更要看**内外源比例**——这正是研究有机质「质量（quality）」的意义。

**辨析｜易错点：** 「湖内长出来的」不等于「湖内消耗的」。很多湖泊的有机质输入以外源为主，而大部分被呼吸消耗的却可能是内源（新鲜易分解）。**判断湖泊是碳源还是碳汇，必须分别算清内外源输入与输出，不能凭颜色或直觉。**

## 2 颗粒有机质与碎屑链

**颗粒有机质（POC）**：粒径大于约 0.45 µm 的有机颗粒，包括活的浮游生物、死亡细胞、粪便颗粒、植物残体与吸附于矿物的有机质。

颗粒有机质的重要性质是**沉降**：颗粒越大、越致密，沉降越快。浮游植物的死亡细胞与浮游动物的粪便颗粒（粪球）以每天数米到数十米的速度沉降，把表层固定碳输向深层与沉积物——这就是**生物泵（biological pump）**的颗粒相。<span class="marginnote">沉降的颗粒有机质是深水层与底栖生态系统的能量来源：深水层的异养细菌、深水底栖动物都靠「从天而降」的颗粒为生。颗粒沉降速度越快，在途中被分解得越少，到达湖底的碳越多——这也是第21条能量流动里「碳输运效率」的决定因素。</span>

沉降途中还有一场「分解竞赛」：颗粒每下沉一米，
沿途的异养细菌与浮游动物都在分解它。
**沉降速度 vs 分解速度的赛跑，决定了有多少碳能到达湖底**。
大而致密的粪球沉降快，
可能在几小时内就到达浅湖湖底；
细小颗粒沉降慢，
可能在水柱中悬浮数周、被分解掉大半。
这个「谁快谁赢」的赛跑，
直接决定湖泊的碳去向——是大部分被矿化回大气（浅湖、小颗粒），
还是大部分被埋藏（深湖、大颗粒）。
理解这场赛跑，
是理解湖泊碳汇强弱的核心。

碎屑（detritus）是颗粒有机质的主体，
碎屑链（第7条）正是围绕它展开：碎屑 → 细菌 → 小型动物 → 鱼类。

## 3 溶解性有机物：最大的有机碳库

**溶解性有机物（DOC）**：粒径小于约 0.45 µm 的有机分子，是湖泊最大的有机碳库。DOC 的成分复杂，主要包括：

**腐殖质（humic substances）**：外源为主的难降解高分子聚合物（黄腐酸、腐殖酸、胡敏素），赋予水体茶色，是 DOC 的「顽固」部分。<span class="marginnote">腐殖质是植物残体在土壤中分解不完全的产物，结构含大量苯环与羧基。它们化学稳定、难被微生物快速分解，能存活数十年——这是「惰性碳」（recalcitrant carbon）的代表。腐殖质还螯合金属、吸附有机污染物，影响它们的迁移与毒性。</span>

**易分解 DOC（labile DOC）**：藻类与植物分泌的单糖、氨基酸、有机酸等，是微生物环的直接燃料。藻类光合过程中释放的胞外产物（extracellular products）是湖泊内源 DOC 的重要来源。

DOC 的生态角色多重：**微生物环的底物**（第16条）、**水色的决定者**、**紫外线的遮蔽剂**（保护水生生物免受 UV 伤害）、**污染物的载体**（与疏水污染物结合增加其迁移）。

「紫外线遮蔽」这个角色近年备受关注：大气臭氧层变薄使到达地面的 UV-B 增强，
而 DOC 是水中最强的 UV 吸收者之一——**DOC 高的茶色湖泊，UV 穿透浅，水生生物被保护；DOC 低的清澈高山湖，UV 直达深水，敏感生物面临辐射压力**。
这也解释了为什么高山清澈湖的浮游动物演化出更强的 UV 修复能力。
DOC 因此是一把双刃剑：它让水变茶色（难看）、消耗氧（化学耗氧），
却也保护生物、螯合金属、调节光环境——评价 DOC 时要权衡其多重角色。

## 4 有机质的分解：从大到小、从颗粒到溶解

有机质分解是一个「由大到小」的级联：

大颗粒残体 →（撕食者破碎）→ 细颗粒 →（细菌外酶水解）→ 溶解态 →（细菌吸收矿化）→ CO₂ + 营养盐

每一步都缩短有机质的「寿命」。分解速率取决于三件事：**有机质性质**（易分解 vs 顽固）、**环境条件**（温度、氧气、营养盐）、**分解者活性**。<span class="marginnote">温度每升高 10 °C，分解速率约翻倍（Q₁₀ 效应）。这使热带湖的有机质周转远快于寒带湖，也意味着气候变暖会加速湖泊有机碳的矿化——湖泊从碳汇转向碳源的风险随之上升。</span>在厌氧的沉积物深层，分解不完全，有机质以半分解态积累埋藏——这是湖泊碳埋藏（碳汇）的途径。

用「一口锅里炖烂食材」来理解分解速率的差异：易分解 DOC 像嫩豆腐，
几分钟就被细菌分解；
藻类死亡细胞像肉片，
几天被分解；
植物枯落物像牛筋，
要几周到几个月；
腐殖质像骨头，
几年到几十年也未必炖烂。
**有机质的「可分解性光谱」从分钟跨度到十年**，这决定了它在湖泊中的「寿命」与去向——易分解的快速进入食物网与呼吸，顽固的慢慢沉入沉积物成为碳汇。
光谱的两端，
一头连着当下生产力，
一头连着长期碳埋藏。

## 5 公式解析：碳收支的箱式模型

湖泊碳收支可写成箱式模型：

$$
\frac{dC}{dt} = I_{外源} + NPP - R_{异养} - F_{出流} - F_{埋藏}
$$

- **第一步，看输入项**：$I_{外源}$（流域与大气输入）与 $NPP$（湖内净初级生产）是碳的两个来源。
- **第二步，看输出项**：$R_{异养}$（异养呼吸，矿化为 CO₂）是最大的支出；$F_{出流}$（随水流出）与 $F_{埋藏}$（沉降埋藏进沉积物）是其余两个去向。
- **第三步，读稳态与判断**：若 $dC/dt > 0$，碳在湖内积累（湖泊为净碳汇）；若 $dC/dt < 0$，碳净流失（湖泊为净碳源）。稳态时 $dC/dt = 0$，输入项之和等于输出项之和——此时 $I_{外源} + NPP = R_{异养} + F_{出流} + F_{埋藏}$。
- **第四步，看决定因子**：湖泊是汇是源，取决于**异养呼吸 $R_{异养}$ 与净初级生产 NPP 的对比**——光合固定得多、分解得少，湖就是汇；反之则是源。气候变暖加速分解（Q₁₀ 效应），正在把许多湖泊从汇推向源，这是湖沼学与气候变化研究交汇的焦点。

用一个「银行流水」的比喻收束：外源与 NPP 是「收入」，异养呼吸是「最大的日常开销」，埋藏是「强制储蓄」（碳进入沉积物），出流是「少量提现」。**判断湖泊是「攒钱」（碳汇）还是「透支」（碳源），就看收入能否覆盖开销**。而 DOC 这个最大的碳库，正是这场收支里最活跃的「活期存款」——它既被细菌快速周转（微生物环），也有一部分转入「定期」（腐殖质埋藏）。

## 6 小结

- 湖泊有机质分**内源（湖内光合产物）与外源（流域输入）**，两者「质与量」常成反比——判断能量供给要看内外源比例，不能只看总量。
- 颗粒有机质经**生物泵**沉降，沉降速度与分解速度的「赛跑」决定有多少碳能到达湖底与埋藏。
- **DOC 是湖泊最大的有机碳库**（占总有机碳 80–95%），既是微生物环的燃料，也是水色、UV 遮蔽与污染物载体的决定者。
- 有机质分解是「由大到小」的级联，**可分解性光谱从分钟跨度到十年**——易分解的进食物网，顽固的成碳汇。
- 碳收支箱式模型 $\frac{dC}{dt} = I_{外源} + NPP - R_{异养} - F_{出流} - F_{埋藏}$ 给出判断湖泊是碳汇还是碳源的定量框架。
