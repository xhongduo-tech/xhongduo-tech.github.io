# 水生生物学

以湖泊与河流等内陆水域生态系统为核心对象，系统讲授水体的理化环境、水化学过程、主要水生生物类群及其生态学机制，并延伸至水污染治理、渔业增殖与生态修复等应用方向。
学完这些章节，就搭建起从湖泊学基础到应用水生生物学的完整知识框架。

## 对标教材

- 刘建康主编《高级水生生物学》（科学出版社）
- Robert Wetzel《Limnology: Lake and River Ecosystems》（3rd ed., Academic Press）
