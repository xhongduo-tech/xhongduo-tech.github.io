## 为什么从光谱项开始

前两篇的晶体场图像把 d 电子当成「一个个填进能级」的粒子，这对基态足够。但 d-d 光谱里，电子从低能级激发到高能级时，不同电子排布会组合出**不同的总角动量态**——要预言光谱有几个吸收峰，就得先给自由离子（没有配体时）的电子态「编号」，再把它们在配位场中分裂。这套编号就是**光谱项（term symbol）**。<span class="marginnote">光谱项是原子光谱学的语言：$\ce{Fe^{2+}}$（d⁶）的自由离子基态光谱项是 $^5D$，它在八面体场中分裂成 $^5T_{2g}$ 与 $^5E_g$ 两个能级——d-d 光谱里那个 10000 cm⁻¹ 的吸收峰，正是这两个能级之间的跃迁。没有光谱项，Orgel 图与 Tanabe–Sugano 图（第 15、16 篇）就无从谈起。</span>本篇打通「原子光谱项 → 配位场分裂」这关键一环。

## 1 光谱项的构成

**光谱项（term symbol）**用四个符号描述一个电子组态的总角动量态：

$$
{}^{2S+1}L_J
$$

- **$S$**：总自旋量子数。$2S+1$ 叫**多重度（multiplicity）**，等于「未成对电子数 + 1」。
- **$L$**：总轨道角动量量子数，用字母表示：$L=0,1,2,3,4,5,\dots$ 对应 $S, P, D, F, G, H,\dots$。
- **$J$**：总角动量量子数（$L$ 与 $S$ 的耦合），对轻过渡金属（LS 耦合）是 $|L-S|$ 到 $L+S$。

**未成对电子数的意义**：多重度越大，未成对电子越多，能量越低（洪特第一规则）。d⁶ 高自旋（4 个未成对）的多重度是 $2S+1 = 5$，写作 $^5D$。

## 2 公式解析：dⁿ 基态光谱项的推法

对 d 电子组态，基态光谱项按**洪特规则**三步确定。以 d²（如 $\ce{V^{3+}}$）为例：

- **第一步，最大化 $S$**：2 个电子各占一个 d 轨道、自旋平行 → $S = \frac{1}{2} + \frac{1}{2} = 1$，多重度 $2S+1 = 3$（三重态）。
- **第二步，最大化 $L$**：两个电子尽量让 $m_l$ 大且分开——$m_l = +2$ 与 $+1$ 各一 → $L = 2+1 = 3$ → 字母 $F$。
- **第三步，定 $J$**：d 壳层不足半满，$J = |L - S| = 3 - 1 = 2$。

故 d² 基态光谱项为 $^3F_2$。<span class="marginnote">同理可推：d¹ 与 d⁹ 是 $^2D$，d³ 与 d⁷ 是 $^4F$，d⁴ 与 d⁶ 是 $^5D$，d⁵ 是 $^6S$（L=0）。<strong>dⁿ 与 d¹⁰⁻ⁿ 的 L、S 相同</strong>——正电子空穴对称，这个对称性让 Orgel 图的左右两半互为镜像。</span>

**关于 J 的说明**：第一过渡系金属在配合物中轨道角动量常被猝灭，光谱项常省略 J（写作 $^5D$）；但自由离子的能级精细结构由 J 决定。J 的取值规则：**壳层半满前 $J=|L-S|$，半满后 $J=L+S$**（洪特第三规则）。

## 3 配位场中的分裂：群论记号

自由离子的 $L$ 态在配位场的低对称环境下，按轨道对称性分裂。八面体场（$O_h$）中，不同 $L$ 的分裂规则：

| 自由离子态 | 八面体场分裂 | 说明 |
| --- | --- | --- |
| $S$（$L=0$） | $A_{1g}$ | 不分裂 |
| $P$（$L=1$） | $T_{1g}$ | 不分裂（p 轨道等价） |
| $D$（$L=2$） | $E_g + T_{2g}$ | 分裂为两组 |
| $F$（$L=3$） | $A_{2g} + T_{1g} + T_{2g}$ | 分裂为三组 |
| $G$（$L=4$） | $A_{1g}+E_g+T_{1g}+T_{2g}$ | 分裂为四组 |

记号规则：**$A$（一维，全对称）、$E$（二维）、$T$（三维）**；下标 1、2 区分对称性质；$g$ 表示对中心对称（偶）——d 轨道都是 $g$。<span class="marginnote">晶体场理论里的 $e_g$ 与 $t_{2g}$ 记号，正是 $D$ 态分裂后得到的 $E_g$ 与 $T_{2g}$ 两组——「d 轨道分裂成 $t_{2g}$ 和 $e_g$」这句话的严格说法是「d 电子的 $^2D$ 态在 $O_h$ 场中分裂为 $^2T_{2g}$ 与 $^2E_g$」。记号的谱系从此打通。</span>

## 4 关联表：晶体场图像与光谱项图像

两种语言讲同一件事，对比表锁死对应关系：

| 视角 | 基态描述 | 激发态 | 适用场景 |
| --- | --- | --- | --- |
| 晶体场（单电子） | $t_{2g}^n e_g^m$ 排布 | 单电子 $t_{2g}\to e_g$ | 基态磁性、CFSE |
| 光谱项（多电子） | $^{2S+1}L$ 态 | 谱项间跃迁 | d-d 光谱、能级图 |

**联系**：晶体场的「$t_{2g}$/$e_g$」是轨道能级，光谱项的「$^5T_{2g}$、$^5E_g$」是**多电子态能级**。d⁶ 高自旋基态在光谱项语言里是 $^5T_{2g}$，与 $^5E_g$ 的间距恰好就是单电子图像里的 $\Delta_o$——两种语言在基态时吻合，但在激发态上光谱项语言更完整（因为还要考虑电子间的交换作用）。

## 5 为什么要学这套语言

光谱项与配位场分裂是理解过渡金属光谱的必经之路：

**Orgel 图**（第 15 篇）：画出各 dⁿ 的谱项能级随配体场强的变化，预测吸收峰数目。
**Tanabe–Sugano 图**（第 16 篇）：处理高低自旋转变与更强的相互作用。
- **电荷转移光谱**（第 17 篇）：区分配体到金属、金属到配体的电荷转移带。
- 从「有几个吸收峰」反推配位环境与自旋态——光谱学是配位化学家的眼睛。

### 5.1 常见 dⁿ 基态光谱项速查表

把 d¹–d⁹ 的基态光谱项列成速查表，是读 Orgel/Tanabe–Sugano 图的必备弹药：

| dⁿ | 基态光谱项 | 多重度（未成对+1） | 例子 |
| --- | --- | --- | --- |
| d¹ | $^2D$ | 2（1 未成对） | $\ce{Ti^{3+}}$ |
| d² | $^3F$ | 3（2） | $\ce{V^{3+}}$ |
| d³ | $^4F$ | 4（3） | $\ce{Cr^{3+}}$、$\ce{V^{2+}}$ |
| d⁴ | $^5D$ | 5（4） | $\ce{Cr^{2+}}$、$\ce{Mn^{3+}}$ |
| d⁵ | $^6S$ | 6（5） | $\ce{Mn^{2+}}$、$\ce{Fe^{3+}}$ |
| d⁶ | $^5D$ | 5（4） | $\ce{Fe^{2+}}$、$\ce{Co^{3+}}$ |
| d⁷ | $^4F$ | 4（3） | $\ce{Co^{2+}}$ |
| d⁸ | $^3F$ | 3（2） | $\ce{Ni^{2+}}$ |
| d⁹ | $^2D$ | 2（1） | $\ce{Cu^{2+}}$ |

**观察规律**：

- **dⁿ 与 d¹⁰⁻ⁿ 的基态光谱项完全相同**（$L$、$S$ 相同）：d¹ 与 d⁹ 都是 $^2D$，d³ 与 d⁷ 都是 $^4F$——电子与空穴的对称性（第 15 篇 Orgel 图左右镜像的根源）。
- **多重度即未成对电子数 + 1**：高自旋 d⁵ 多重度 6（$^6S$），是所有过渡金属里最高的——这就是 Mn²⁺ 极稳定（半满壳）的光谱项表达。
- **d⁵ 是 $^6S$（L=0）**：半满壳层总轨道角动量为零，配位场里不分裂（$^6A_{1g}$）——第 15 篇「d⁵ 自旋禁阻、几乎无色」的根源之一。<span class="marginnote">$^6S$ 的 L=0 意味着轨道角动量彻底猝灭，磁矩完全来自自旋（第 18 篇自旋唯公式对 Mn²⁺ 最准）。「半满壳 L=0」还让 d⁵ 的 CFSE 为 0（第 10 篇）——光谱项、磁学、热力学在这里指向同一个事实：d⁵ 半满壳是天然的特殊点。</span>

**查表用法**：拿到一个 dⁿ 离子，先查基态光谱项，再看它在配位场里分裂成几个支态（$D\to E+T$、$F\to A+T+T$、$S\to A$），就能预言吸收峰的上限数目——这是第 15 篇 Orgel 图读图的「前置知识」。

**一句话收束**：光谱项是「电子如何协同地拥有角动量」的档案——读得懂 $^5D$、$^4F$、$^6S$，就掌握了从原子光谱到配位场分裂的整套语法。

**与第 18 篇的衔接**：光谱项里的 $L$、$S$ 直接决定磁性——$S$ 给自旋磁矩，$L$ 给轨道磁矩；$L=0$（d⁵ 的 $^6S$）时轨道贡献猝灭、自旋唯公式最准。光谱项、磁学、晶体场三套语言在 d 电子构型这里汇合，互为印证。

最后一句：光谱项是「多电子角动量组合」的归档系统——它让 d⁴ 与 d⁶ 共享 $^5D$、让半满壳 d⁵ 独得 $^6S$ 这些「长相」，背后是电子与空穴的对称、洪特规则的次序。读懂这份档案，第 15、16 篇的能级图就不再是黑箱。

（补充：写光谱项时先写多重度再写轨道字母再写下标 J——$^{2S+1}L_J$ 的顺序是约定，别写反。）

## 6 小结

- 光谱项 ${}^{2S+1}L_J$：**多重度 $2S+1$**（未成对电子数+1）、**轨道字母 $S/P/D/F/G$**、**总角动量 $J$**。
- 洪特规则三步定基态谱项：**最大 $S$ → 最大 $L$ → 定 $J$**；dⁿ 与 d¹⁰⁻ⁿ 的 $L$、$S$ 对称。
- 自由离子态在 $O_h$ 场中分裂：$S\to A_{1g}$、$P\to T_{1g}$、$D\to E_g+T_{2g}$、$F\to A_{2g}+T_{1g}+T_{2g}$。
- **$A$ 一维、$E$ 二维、$T$ 三维**，d 轨道带 $g$（中心对称），d-d 跃迁受 Laporte 禁阻。
- 意义：谱项是 Orgel/Tanabe–Sugano 图的「原料」，没有谱项就没有光谱学——它是 d 电子从原子走向配位场的桥梁。
