## 为什么从组成开始

配位化学研究的是**配合物（coordination compound）**：由中心原子（通常是过渡金属离子）与一定数目的配体通过配位键结合而成的物种。它是过渡金属化学的骨架——金属酶、均相催化剂、发光材料、MRI 造影剂，几乎每一项都建立在一个配合物的化学式之上。<span class="marginnote">为什么先讲组成？因为配合物化学式里藏着全部信息的「压缩编码」：中心是谁、配体是哪些、配位数多少、电荷几何分布——读懂了组成，后面所有成键理论、光谱、稳定性分析才有抓手。</span>这一篇把「怎么把一个配合物说清楚」讲透，也顺势复习《无机化学》中价键与离子键的基础。

## 1 什么算配合物

**配合物（coordination compound）**：由一个中心原子或离子（**中心离子/中心原子**）与若干配体（ligand）以配位键结合形成的电中性或带电荷的物种。

判断「是不是配合物」有三个要件：

**中心体**：必须有可接受孤对电子的空轨道，通常是过渡金属离子（如 $\ce{Fe^3+}$、$\ce{Cu^2+}$），也可以是主族离子（如 $\ce{Al^3+}$）或中性原子（如 $\ce{Fe}$、$\ce{Ni}$ 羰基中的金属）。
**配体**：必须有孤对电子或 π 电子可供出，如 $\ce{H2O}$、$\ce{NH3}$、$\ce{Cl^-}$、$\ce{CN^-}$。
**配位键**：配体把孤对电子「让渡」到中心体空轨道上形成的共价键。<span class="marginnote">配位键（dative bond）的本质仍是共价键，只是两个成键电子来源不同——都来自配体。写成 $\ce{NH3 -> Ag+}$ 中的箭头就表示这种「单方供电子」的关系。</span>

例如硫酸铜溶于水得到深蓝色的铜氨溶液：

$$\ce{[Cu(H2O)4]^2+ + 4NH3 -> [Cu(NH3)4]^2+ + 4H2O}$$

这里的 $\ce{[Cu(NH3)4]^2+}$ 就是一个配离子，整体是配合物的一部分。

## 2 解剖一个配合物：内界与外界

**配合物的组成分为内界（配离子）与外界。** 方括号括起来的整体叫**内界（coordination sphere）**，它由中心离子与配体组成，写化学式时紧挨中心；方括号外面的离子叫**外界（outer sphere）**，只是靠离子键维系、不直接配位的对离子。

以氯铂酸钾 $K_2[PtCl_6]$ 为例：

| 部分 | 组成 | 说明 |
| --- | --- | --- |
| 外界 | $2\ce{K+}$ | 与内界以离子键结合，不进入配位圈 |
| 内界 | $[\ce{PtCl6}]^{2-}$ | 中心 $\ce{Pt^{4+}}$ + 6 个 $\ce{Cl^-}$ 配体 |
| 电荷守恒 | $2 \times (+1) + (-2) = 0$ | 内界与外界电荷之和必为零 |

**内界电荷**由中心离子电荷与配体电荷代数和决定：$Q_{\text{内界}} = Q_{\text{中心}} + \sum Q_{\text{配体}}$。<span class="marginnote">判断配合物是阳离子型、阴离子型还是中性分子，就看内界净电荷：$\ce{[Co(NH3)6]Cl3}$ 是阳离子型，$\ce{K4[Fe(CN)6]}$ 是阴离子型，$\ce{[Ni(CO)4]}$ 是中性分子型。</span>这一「内外有别」正是维尔纳确立的经典框架——它也解释了为什么化学式写 $K_2[PtCl_6]$ 而非 $K_2PtCl_6$：方括号框出的正是配位作用直接覆盖的范围。

## 3 配位数与中心离子

**配位数（coordination number, CN）**：内界中直接与中心离子成键的配位原子数目。它是描述配合物「拥挤程度」的第一个数字，直接决定几何构型（下一节《配位数与配位多面体》展开）。

常见配位数与对应构型：

| 配位数 | 典型构型 | 实例 |
| --- | --- | --- |
| 2 | 直线形 | $\ce{[Ag(NH3)2]+}$ |
| 4 | 四面体 / 平面正方形 | $\ce{[Zn(NH3)4]^2+}$ / $\ce{[PtCl4]^{2-}}$ |
| 6 | 八面体 | $\ce{[Co(NH3)6]^3+}$ |
| 8 | 十二面体等 | $\ce{[Mo(CN)8]^{4-}}$ |

配位数受三重因素制约：**中心离子的大小与电荷**（大而高电荷的中心倾向高配位）、**配体的体积**（大配体因位阻压低配位数）、**电子结构**（18 电子规则见第 6 篇）。<span class="marginnote">同一种金属的配位数不是固定的：$\ce{Fe^3+}$ 与 $\ce{F^-}$ 得 $\ce{[FeF6]^{3-}}$，与体积更大的 $\ce{Cl^-}$ 则可得 $\ce{[FeCl4]^-}$——「空间不够就少配几个」是配位数最直观的调节机制。</span>因此配位数必须由实验与成键理论共同确认，不能仅凭化学式猜。

## 4 中文命名规则

命名是化学式到语言的翻译，规则的核心是**「某酸某」与「某化某」之分、内外界顺序、配体次序**。

**配离子命名的通用次序**：配体数（用一、二、三……）+ 配体名（多个配体按先阴离子后中性分子、先简单后复杂的次序）+ 「合」+ 中心离子名 + 氧化数（罗马数字，括号）。阴离子配体名把「-化」改「-合」（如氯化 → 氯合），中性配体一般保留原名（如水、氨、羰基）。

命名口诀对照表：

| 类别 | 结构式 | 中文名 |
| --- | --- | --- |
| 阳离子型 | $\ce{[Co(NH3)6]Cl3}$ | 三氯化六氨合钴(Ⅲ) |
| 阴离子型 | $\ce{K4[Fe(CN)6]}$ | 六氰合铁(Ⅱ)酸钾 |
| 中性型 | $\ce{[Ni(CO)4]}$ | 四羰基合镍 |
| 配体含酸根 | $\ce{[Cu(NH3)4]SO4}$ | 硫酸四氨合铜(Ⅱ) |

<span class="marginnote">阴离子型配离子命名时中心元素要用含氧酸根的旧名后缀：「亚铁酸」「铁酸」「钴酸」——$\ce{K4[Fe(CN)6]}$ 若中心是铁(Ⅲ)就写成「铁(Ⅲ)酸」。</span>命名容易出错的两处：一是**配体次序**要先阴离子后中性分子（$\ce{[CoCl(NH3)5]^2+}$ 命名里氯合在氨之前）；二是**氧化数必须写**，因为它决定电荷平衡。

**常用配体缩写速查**（写化学式时几乎天天用）：

| 缩写 | 全称 | 供电子 |
| --- | --- | --- |
| en | 乙二胺 $\ce{NH2CH2CH2NH2}$ | 双齿、2 |
| bipy / bpy | 联吡啶 | 双齿、2 |
| edta⁴⁻ | 乙二胺四乙酸根 | 六齿、6 |
| acac⁻ | 乙酰丙酮根 | 双齿、2 |
| Cp⁻ | 环戊二烯基 | 五齿、6 |
| PPh₃ | 三苯基膦 | 单齿、2 |

记住这些缩写，化学式可读性立刻提升一个台阶——它们也是后续各篇（螯合效应、配体场、催化）反复登场的主角。

## 5 核心对比表：配合物的分类

配合物分类角度多，用一张对比表收束：

| 分类依据 | 类别 | 例子 | 要点 |
| --- | --- | --- | --- |
| 配体齿数 | 单齿 / 多齿 / 螯合 | $\ce{NH3}$ / $\ce{en}$ / $\ce{edta^{4-}}$ | 多齿配体形成螯环，稳定性大增（见第 20 篇） |
| 内界电荷 | 阳离子 / 阴离子 / 中性 | $[\ce{Cu(NH3)4}]^{2+}$ / $[\ce{Fe(CN)6}]^{4-}$ / $[\ce{PtCl2(NH3)2}]$ | 决定溶解性、迁移方向 |
| 配体种类 | 水合 / 氨合 / 氰合 / 羰基 | $[\ce{Al(H2O)6}]^{3+}$ / $[\ce{Fe(CO)5}]$ | 配体场强弱直接关联（光谱化学序列） |
| 结构类型 | 单核 / 多核 / 簇合物 | $[\ce{Fe2(CO)9}]$ | 多核涉及桥连配体与金属—金属键 |
| 配位数 | 2~12 不等 | 见上表 | 与几何构型一一对应 |

**辨析｜易错点：**「配合物」不等于「配离子」——中性分子 $\ce{[Ni(CO)4]}$ 是配合物但不是离子；「含结晶水的水合物」如 $\ce{CuSO4 \cdot 5H2O}$ 的结晶水不进入内界，与配位水（如 $[\ce{Cu(H2O)4}]^{2+}$ 中的水）有本质区别。<span class="marginnote">区分配位水与结晶水的实验办法是热重或电导：配位水进入内界，对摩尔电导的贡献随配位数不同而改变，这在后续溶液配位平衡一章还会用到。</span>

### 5.1 从组成看性质：内界电荷的连锁效应

配合物的物理性质几乎全由「内界电荷 + 外界离子」这个组成特征决定，值得展开几条：

**溶解性**：内界电荷高、外界离子小的配合物往往水溶性好；电荷中和、外界离子大（如 $\ce{Ph4As+}$、$\ce{BPh4^-}$）则倾向低极性溶剂。设计「把配合物从水相萃到有机相」时，正是靠调节外界离子控制溶解性——液液萃取分离金属的原理。

**导电性**：摩尔电导率（$\Lambda_M$）与「每式单位电离出的离子数」直接相关。$\ce{[Co(NH3)6]Cl3}$ 电离出 4 个离子（1 配离子 + 3 Cl⁻），摩尔电导落在「3:1 电解质」区间；$\ce{[CoCl(NH3)5]Cl2}$ 是 3 个离子、$\ce{[CoCl2(NH3)4]Cl}$ 是 2 个离子——电导呈 4:3:2 的「阶梯」。<span class="marginnote">这条阶梯是配位化学史上真实用过的实验武器：维尔纳在 X 射线衍射诞生之前，正是靠摩尔电导、电泳与同分异构体计数来验证「内界—外界」的划分。今天解结构有衍射与光谱，但「用电导数离子」的思路仍是水溶液配合物研究的基础工具。</span>

**异构体计数**：组成相同、结构不同的配合物数目往往能「反推」配位数与几何。维尔纳用 Co(III) 配合物（氯代氨配合物只有固定几种）证明了八面体六配位——这是「组成 → 性质 → 结构」三角推断法的经典示范，第 4 篇《配合物的异构现象》会专门展开。

## 6 小结

- 配合物三要件：**中心体**（有空轨道）、**配体**（有孤对电子）、**配位键**（单方供电子）。
- 组成分**内界**（方括号内：中心 + 配体）与**外界**（对离子），内外界电荷代数和必为零。
- 配位数由**中心大小与电荷、配体体积、电子结构**三重因素决定，直接对应几何构型。
- 中文命名次序：配体数 + 配体名（先阴离子后中性分子）+「合」+ 中心元素 + 氧化数（罗马数字）。
- 分类视角：配体齿数、内界电荷、配体种类、结构类型、配位数——不同视角服务不同分析目的。
- 内界电荷连锁决定溶解性、导电性与迁移方向；**摩尔电导阶梯**是实验测定配离子电荷的经典工具。
