## 为什么从 SIR 模型讲起

从这一节起，生物数学直接面对人类最紧迫的问题：**传染病如何在人群里扩散、达到峰值、最终退潮？** 1927 年，Kermack 与 McKendrick 写下 SIR 方程，开创了数学流行病学。此后整整一个世纪的传染病防控——疫苗接种、口罩政策、封控时机的选择——都建立在这套方程的分析之上。SIR 模型把人群分成三个仓室（Susceptible 易感、Infectious 感染、Removed 移除），用守恒律写出三条常微分方程。它是第 3 篇的奠基，也是理解「为什么一个参数 $R_0$ 能决定疫情生死」的必经之路。

## 1 三个仓室与三条方程

人群按疾病状态分成三个**仓室（compartment）**：

- **$S$（Susceptible，易感）**：尚未感染、可能被传染的人。
- **$I$（Infectious，感染）**：正在传染他人的人。
- **$R$（Removed，移除）**：已康复且有免疫力（或死亡）的人，不再参与传播。

设总人口 $N = S + I + R$ 恒定（假定疾病期间出生与自然死亡忽略不计）。**SIR 模型**：

$$\frac{dS}{dt} = -\beta S I, \qquad \frac{dI}{dt} = \beta S I - \gamma I, \qquad \frac{dR}{dt} = \gamma I$$

各参数的含义：

- $\beta$：**有效接触率**——单位时间内一个感染者能「成功传染」的易感人数与易感者密度的乘积系数，量纲为 $1/(\text{人数}\cdot\text{时间})$。
- $\gamma$：**移除率**——感染者康复（或隔离、死亡）的速率，量纲 $1/\text{时间}$。平均感染期为 $1/\gamma$。<span class="marginnote">注意 $S + I + R = N$ 时，三条方程相加得 $dN/dt = 0$，总人口守恒——这是对模型一致性的第一个检查。任何仓室模型写完后都要验一遍「总量是否守恒」，这是建模的基本卫生习惯。</span>

传播项 $- \beta S I$ 的直觉：传播需要「一个感染者」与「一个易感者」相遇，相遇次数正比于乘积 $SI$（与捕食模型里 $NP$ 项同理）；$\beta$ 是「相遇转化为感染」的效率。

## 2 为什么方程长这样：质量作用律

**质量作用定律（law of mass action）**：反应（相遇）速率正比于各反应物浓度的乘积。传染病传播的「反应」是

$$S + I \xrightarrow{\beta} I + I$$

一个易感者 + 一个感染者 → 两个感染者。<span class="marginnote">这套类比来自化学动力学——Kermack 和 McKendrick 正是借用化学反应的数学工具来写流行病。不同点在于：化学反应里的分子均匀混合，而人接触是网络化的；但作为第一近似，「均匀混合 + 质量作用」给出了惊人的解释力。现实中异质性（超级传播者、社交网络）的影响在第 17 篇异质种群模型里再展开。</span>

**辨析｜易错点：** $\beta SI$ 的 $S$ 与 $I$ 用的是**绝对人数**，不是比例。若用比例 $s = S/N$、$i = I/N$，方程变成 $ds/dt = -\beta N s i$ 等。用人数还是比例取决于建模约定，但**参数随之变化**——用比例时接触率会吸收 $N$。混用两种写法是初学者最常见的翻车点，务必在一开始就统一。

## 3 疫情的过程与典型曲线

给定初始条件 $S(0) \approx N$、$I(0)$ 很小、$R(0) = 0$，SIR 方程的解展示一条典型的疫情曲线：

- **爆发初期**：$I$ 快速增长，$S$ 缓慢下降。
- **峰值**：当 $S$ 降到阈值 $S = \gamma/\beta$ 时，$dI/dt = \beta SI - \gamma I = \gamma I(S/(\gamma/\beta) - 1) = 0$，$I$ 达到**峰值 $I_{\max}$**。
- **退潮期**：$S$ 继续下降使 $dI/dt \lt  0$，$I$ 衰减，最终 $I \to 0$，$S$ 停在某个剩余值 $S_\infty > 0$。

三个关键量：

- **峰值规模 $I_{\max}$**：医疗卫生系统压力的直接指标。
- **最终易感者 $S_\infty$**：疫情结束后仍未被感染的人数（「未感染比例」）。
- **累计感染数** $N - S_\infty$：疫情总负担。

**SIR 模型的一个惊人结论：疫情会自动结束，不是因为易感者被清空，而是因为 $S$ 降到阈值之下，传播效率不足以维持流行。** 即使有大量易感者幸存（$S_\infty$ 可能远大于 0），疫情也因「有效传播率 < 移除率」而自然衰减——这被称为**群体免疫的数学本质**（见第 16 篇）。

## 4 公式解析：SIR 系统消去时间后的相平面

SIR 的三条方程无法解析求解，但可以消去时间 $t$，在 $SI$ 平面分析轨道的几何。

$$
\frac{dI}{dS} = \frac{\beta S I - \gamma I}{-\beta S I} = -1 + \frac{\gamma}{\beta S}
$$

- **第一步，消去 $dt$**：$\frac{dI}{dS} = \frac{dI/dt}{dS/dt}$，代入方程得 $\frac{dI}{dS} = -1 + \frac{\gamma}{\beta S}$。
- **第二步，分离变量**：这是关于 $S$ 的常微分方程，分离变量得

$$
dI = \left(-1 + \frac{\gamma}{\beta S}\right) dS
$$

- **第三步，积分**：

$$
I = -S + \frac{\gamma}{\beta}\ln S + C
$$

其中 $C = I_0 + S_0 - \frac{\gamma}{\beta}\ln S_0$ 由初值定出。

- **第四步，解读轨道**：轨道在 $(S, I)$ 平面是曲线 $I = -S + \frac{\gamma}{\beta}\ln S + C$。从 $S = N$ 附近出发，$I$ 先升（$S$ 大时 $dI/dS \lt  0$，$I$ 随 $S$ 减小而增大），到 $S = \gamma/\beta$ 处 $dI/dS = 0$，$I$ 达峰，之后 $I$ 随 $S$ 继续减小而回落——**这条曲线的形状就完整描出了疫情进程**。<span class="marginnote">阈值 $S^* = \gamma/\beta$ 是整条曲线的「山脊」：所有轨道都在 $S = \gamma/\beta$ 处取 $I$ 最大值。$1/\gamma$ 是平均感染期，$\beta$ 是接触效率，所以 $S^* = \gamma/\beta$ 的生态含义是「易感者多到足以支撑每一个感染者持续传播」的临界线。轨道一旦越过这条线，疫情就进入退潮。</span>

**这就是 SIR 的全部几何**：一条把「易感者消耗」与「感染者数量」联系起来的轨道曲线，阈值 $\gamma/\beta$ 决定疫情的分水岭。下一节我们会看到，这个阈值翻过来写就是鼎鼎大名的基本再生数 $R_0 = \beta N/\gamma$。

## 5 数值模拟：SIR 的四个阶段与防控窗口

SIR 方程虽然不能解析求解，但数值模拟极其简单——用欧拉法或四阶 Runge-Kutta 就能在几分钟内跑出整条疫情曲线。设 $N = 10^6$、$R_0 = 2.5$、$\gamma = 1/7$（感染期 7 天），则 $\beta = R_0\gamma/N$。模拟显示疫情可分四个阶段：

**潜伏爬升期**：$I$ 从几个指数增长，$S$ 几乎不动——此时肉眼看不见危机，但传播已在加速。
**指数爆发期**：$I$ 快速增长，医疗系统开始承压，$S$ 明显下滑。
- **峰值平台期**：$I$ 达到峰值 $I_{\max}$，约在 $S = \gamma/\beta$ 附近；此后 $I$ 开始回落。
- **长尾消退期**：$I$ 缓慢衰减，$S$ 停在剩余值 $S_\infty$，疫情「自然熄火」。

**防控窗口的数学含义**：在指数爆发期，每过 $\ln 2 / \gamma(R_0 - 1) \approx 0.7/(2.5-1) \times 7 \approx 3.3$ 天，$I$ 就翻一倍。<span class="marginnote">翻倍时间是理解「为什么不能等」的钥匙：$R_0 = 2.5$ 时每 3–4 天翻倍，晚一周干预，峰值就高一个数量级。SIR 模型给防控的启示是——<strong>干预越早，峰值越低、总感染越少</strong>；一旦错过指数期，同样的干预力度只能「削峰」而无法「压量」。数学把「早发现早隔离」从口号变成了可计算的时间窗。</span>

**干预如何进入模型**：把 $\beta$ 写成「接触率 × 传染概率」：$\beta = c \times p$。口罩、保持距离降低 $c$（减少接触）；卫生习惯降低 $p$（降低单次传染概率）。封控就是同时压 $c$ 与 $p$，从而压低 $R_0$、推迟并削平峰值——SIR 模型因此成为一切非药物干预（NPI）评估的基线框架。

**辨析｜易错点：** SIR 假设「移除后永久免疫」且「人群均匀混合」。对真实疾病，若免疫衰减（再感染）或人群高度异质（超级传播者），SIR 的峰值与 $S_\infty$ 会系统性偏差——这些修正正是第 15–17 篇的内容。**把 SIR 的数值预测当精确预报是误用**；把它当「机制基线 + 相对比较工具」才是正解。

## 6 仓室模型的三条构建原则

SIR 是仓室模型的范式，把它背后的构建原则提炼出来，后续所有模型（SEIR、SIS、媒介、年龄结构）都是这三条原则的组合。

**原则一：仓室完备且互斥。** 每个个体在任何时刻恰好属于一个仓室，仓室并集覆盖全体。SIR 里「一人一个状态」，$S + I + R = N$ 恒成立——这是总人口守恒的保证。

**原则二：每条转移都是「流出速率 × 源仓室规模」。** 转移 $I \to R$ 的速率是 $\gamma \times I$；$S \to I$ 的速率是 $\beta \times S \times I$（质量作用）。**「线性转移（$\propto$ 源规模）」与「双线性传播（$\propto$ 乘积）」是仓室模型仅有的两种转移形态**——识别一个仓室模型，只需认准这两种项。

**原则三：参数有明确的生物含义与量纲。** $\gamma$ 的倒数 $1/\gamma$ 是平均停留时间（感染期），$\beta$ 是「接触 × 概率」的乘积。<span class="marginnote">三条原则合起来给了仓室模型一个「可审计」的结构：<strong>每个仓室的方程 = 流入 − 流出，流入流出每一项都能讲出生物故事，参数量纲都能自检</strong>。这也是为什么仓室模型是数学生物学最可靠的入门工具——它的错误极易被「守恒检查 + 量纲检查」抓住。后续每接触一个新仓室模型，都先用这三条原则「验尸」，能省下大量排查时间。</span>

**一个自检练习**：把 SEIR 的四条方程（第 15 篇）逐项对照三原则——$E \to I$ 转移是 $\sigma E$（线性），$S \to E$ 传播是 $\beta SI$（双线性），四仓室之和守恒（原则一）。**能独立完成这个练习，你就真正「会」仓室模型了。**

**辨析｜易错点：** 仓室模型是「均质混合」假设的产物——它把人群抽象成「充分搅拌的罐子」。真实人群有空间、网络与行为结构，仓室模型是它们的零阶近似。**理解模型的假设边界，比记住公式更重要**——这正是从「会用模型」到「会选模型」的分水岭。

## 7 小结

- **SIR 仓室模型**：$S, I, R$ 三仓室，方程 $dS/dt=-\beta SI$、$dI/dt=\beta SI-\gamma I$、$dR/dt=\gamma I$，总人口守恒。
- 传播项源自**质量作用律** $S + I \to I + I$；参数 $\beta$ 是有效接触率，$1/\gamma$ 是平均感染期。
- 疫情自动结束的关键：$S$ 降到阈值 $S^* = \gamma/\beta$ 之下，有效传播不足以维持流行——**不是易感者被清空**。
- 消去时间得轨道 $I = -S + (\gamma/\beta)\ln S + C$，在 $S = \gamma/\beta$ 处 $I$ 取峰值。
- 相平面轨道 + 阈值 $S^*$ 完整刻画疫情进程，是后续所有流行病分析的起点。
