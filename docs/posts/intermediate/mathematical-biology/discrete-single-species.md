## 为什么从离散时间模型开始

很多生命系统的更新是**逐代、逐季、逐龄级**地进行的：一年生的昆虫一年只繁殖一次，候鸟按年迁徙，鱼类的渔获量按年统计。在这样的系统里，「时间」天然是离散的——第 $n$ 代、第 $n$ 年、第 $n$ 周。用**差分方程（difference equation）**描述这类系统，比用微分方程更贴切，也往往更简单。更重要的是，离散模型会暴露一个连续世界完全没有的现象——**混沌**。上一节我们建立了建模的翻译框架，这一节开始第一次真正的实战：用最简的差分方程追踪一个物种逐代的数量，并学会找它的**平衡点**。

## 1 从繁殖节律到差分方程

**差分方程（difference equation）**：用上一时刻的变量值通过一个递推规则得到下一时刻的值，形如 $N_{n+1} = f(N_n)$，其中 $n$ 是离散的时间步。<span class="marginnote">这里的时间下标 $n$ 读作「第 $n$ 代」或「第 $n$ 个繁殖季」。连续模型里的 $dN/dt$ 在这里换成差分 $\Delta N = N_{n+1} - N_n$，积分换成求和。差分方程在数学上属于迭代映射，其动力学与连续方程有本质差异。</span>

最自然的出发点是**线性（指数）离散模型**：

$$N_{n+1} = \lambda N_n$$

其中 $\lambda$ 是**每代净增长率**（即每个个体平均产生多少个能存活到下一代的子代）。<span class="marginnote">若 $\lambda > 1$，每代都在扩大；若 $\lambda \lt  1$，每代都在缩小；若 $\lambda = 1$，种群恰好维持不变。$\lambda$ 与连续模型的内禀增长率 $r$ 的关系是 $\lambda = e^{r}$——二者描述同一个过程的两种计时方式。</span>迭代求解很容易：

$$N_n = \lambda^n N_0$$

这是教科书上最简单的生物模型：不重叠世代、无资源限制、每个个体同等繁殖。它的预言是单调的——要么爆炸，要么灭绝。

## 2 平衡点：什么才算「稳定」

**平衡点（equilibrium / steady state）**：满足 $N_{n+1} = N_n$ 的种群数量，记作 $N^*$。在平衡点上，种群逐代不变。

求平衡点只需解方程 $N^* = f(N^*)$。对线性模型 $N_{n+1} = \lambda N_n$，$N^* = \lambda N^*$，即 $N^*(\lambda - 1) = 0$，故只有一个平衡点 $N^* = 0$。

但「存在平衡点」不等于「回到平衡点」。**平衡点分为稳定与不稳定两类**：

- **局部稳定（locally stable）**：从平衡点附近出发的轨道会被吸引回平衡点。
- **局部不稳定（locally unstable）**：哪怕只偏离一点点，轨道也会越走越远。

判断准则很直观：**看 $|f'(N^*)|$**。若 $|f'(N^*)| \lt  1$，扰动被压缩，平衡点稳定；若 $|f'(N^*)| > 1$，扰动被放大，平衡点不稳定。<span class="marginnote">这个判据来自一阶泰勒近似：在 $N^*$ 附近 $N_{n+1} - N^* \approx f'(N^*)(N_n - N^*)$。每迭代一步，偏差都乘以因子 $f'(N^*)$；因子的绝对值小于 1，偏差就逐代衰减。这就是「线性化 + 稳定性」思想的第一次登场，第 6 篇会把它推广到方程组。</span>边界情形 $|f'(N^*)| = 1$ 需要更高阶的分析，我们留给第 3 篇的分岔讨论。

## 3 离散 Logistic 模型：密度制约的登场

线性模型太天真——现实里资源有限，种群越大、每只个体能分到的资源越少。把密度制约放进离散框架，最著名的就是**离散 Logistic 模型**：

$$N_{n+1} = N_n + rN_n\left(1 - \frac{N_n}{K}\right)$$

或者写成更简洁的参数化形式，令 $x_n = rN_n/(K(1+r))$，化成**二次迭代映射**

$$x_{n+1} = a x_n (1 - x_n)$$

这就是鼎鼎大名的 **Logistic 映射**，参数 $a = 1 + r$。<span class="marginnote">这个二次映射表面上平凡，却是混沌理论最著名的实验室。把参数 $a$ 从 1 逐渐增大到 4，系统会经历：稳定点 → 周期 2 → 周期 4 → … → 混沌。它的几何意义是：$x_{n+1}$ 作为 $x_n$ 的函数是一条开口向下的抛物线，抛物线「越陡」（$a$ 越大），迭代越容易失控。</span>

**辨析｜易错点：** 连续 Logistic 方程 $dN/dt = rN(1-N/K)$ 与离散 Logistic 映射 $N_{n+1} = N_n + rN_n(1-N_n/K)$ 长得几乎一样，但动力学完全不同——连续版永远不会混沌，离散版却能。差别根源在于离散递推里**一步可以跨出很大范围**：当 $N_n$ 接近 $K$ 时，若 $r$ 很大，$N_{n+1}$ 可能被「抛」到 $K$ 的另一边甚至更远，产生过冲与振荡，而连续版本的种群只能「滑」向平衡点。**同名的方程，离散与连续的命运截然不同。**

## 4 公式解析：离散 Logistic 的平衡点与稳定条件

对离散 Logistic 模型 $N_{n+1} = N_n + rN_n(1 - N_n/K)$ 做完整的平衡点分析：

$$
N^* = N^* + rN^*\left(1 - \frac{N^*}{K}\right)
$$

逐项拆解：

- **第一步，求平衡点**：两边消去 $N^*$，得 $rN^*\left(1 - \frac{N^*}{K}\right) = 0$。于是 $N^* = 0$ 或 $N^* = K$。$N^*=0$ 是灭绝平衡点，$N^*=K$ 是承载量平衡点。
- **第二步，计算导数**：令 $f(N) = N + rN(1 - N/K)$，求导得 $f'(N) = 1 + r - \frac{2rN}{K}$。
- **第三步，代入判据**：在 $N^* = K$ 处，$f'(K) = 1 + r - 2r = 1 - r$。稳定条件 $|f'(K)| \lt  1$ 即 $|1 - r| \lt  1$，解得 $0 \lt  r \lt  2$。
- **第四步，解读**：当 $r \lt  2$ 时，$N = K$ 是稳定平衡点，种群收敛到承载量；当 $r > 2$ 时，平衡点失稳，种群开始振荡；当 $r$ 继续增大到约 2.57 之后，振荡发展为混沌。<span class="marginnote">注意一个惊人的事实：$r$ 只代表每代的净增长潜力，它超过 2 并不罕见——很多昆虫每代能翻好几倍。这意味着「种群稳定在承载量」并不是默认结局，振荡与混沌才是高繁殖率物种的常态。现实中的昆虫种群暴发与崩溃，正是这套数学的直接体现。</span>

这条结论还有一层更深的生态学含义：**稳定性不是物种的固有属性，而是增长率与环境承载量共同作用的结果**。同一个物种，在资源丰富时（$r$ 相对大）可能振荡，在资源紧张时反而稳定。

## 5 数值图示与蛛网图：把递推画出来

差分方程除了代数分析，还有一套非常直观的几何工具，能「看着图」理解迭代。

**蛛网图（cobweb diagram）**：在 $(N_n, N_{n+1})$ 平面上画 $y = f(N)$ 曲线与对角线 $y = N$。从 $(N_0, 0)$ 出发，竖直向上到曲线得 $(N_0, N_1)$，水平移到对角线得 $(N_1, N_1)$，再竖直向上到曲线……反复迭代，蛛网图就画出了整条轨道。

平衡点 $N^*$ 是对角线与曲线的交点——蛛网收敛到交点的方向直接可见。
$N^*$ 附近曲线斜率绝对值 $\lt  1$ 时，蛛网螺旋向内（稳定）；$> 1$ 时螺旋向外（不稳定）。
- 过冲（overshoot）现象一目了然：$N_{n+1}$ 越过 $K$ 再折返，正是 $r > 2$ 时振荡的几何起源。

**数值时间序列**：画出 $N_n$ 对 $n$ 的折线图，观察从初值出发如何趋近平衡点或进入周期。实践上，从不同初值跑多次迭代、舍弃前几百步暂态，再看长期行为，是判别「收敛 / 周期 / 混沌」的标准数值流程。<span class="marginnote">蛛网图的价值在于它把「平衡点稳定 ⟺ $|f'(N^*)|\lt 1$」这条抽象判据变成了可见的几何事实：曲线在对角线附近的陡峭程度直接决定蛛网的去留。学习差分方程的推荐路径是「代数求平衡点 → 几何画蛛网 → 数值跑时间序列」三件套并用，三者互相印证，很少出错。</span>

**辨析｜易错点：** 蛛网图的横纵坐标轴都是种群数量（$N_n$ 与 $N_{n+1}$），不是「时间」轴；时间沿蛛网的边前进，而不是沿坐标轴。初学常把蛛网图误读成时间序列，把「蛛网的转折点」当成「种群的历史峰值」——两者完全不同，蛛网的每一折都对应一次完整迭代。

## 6 离散收获模型：把捕捞写进差分方程

把上一节的收获思想放进离散框架，会看到一个与连续版本不同的新现象。设每年捕捞固定比例 $h$，离散 Logistic 变为

$$N_{n+1} = (1 - h)\left[N_n + rN_n\left(1 - \frac{N_n}{K}\right)\right]$$

**辨析｜易错点：** 收获发生在「生长之后」还是「生长之前」会导致不同方程——这里假设先繁殖后捕捞（收获括号内已生长的种群）。顺序不同，平衡点不同，稳定条件也不同。**建模时务必写明事件顺序**，这是离散模型特有的「时序敏感性」。

对这条方程的平衡点分析：设 $g(N) = (1-h)[N + rN(1 - N/K)]$。平衡点 $N^*$ 满足 $N^* = g(N^*)$，即

$$N^* = (1-h)N^* + (1-h)rN^*(1 - N^*/K)$$

整理得 $N^*\left[h - (1-h)r(1 - N^*/K)\right] = 0$，非零平衡点

$$N^* = K\left(1 - \frac{h}{(1-h)r}\right)$$

- **当 $h \lt  \frac{r}{1+r}$ 时**：$N^* > 0$，平衡点存在。
- **当 $h > \frac{r}{1+r}$ 时**：$N^* \lt  0$ 无物理意义，**种群必然灭绝**——捕捞强度超过临界 $h_c = r/(1+r)$ 就「一网打尽」。

稳定条件用 $g'(N^*)$ 判断。$g'(N) = (1-h)[1 + r - 2rN/K]$，在 $N^*$ 处代入化简得 $g'(N^*) = (1-h)(1 + r) - 2h\cdot$… 整理为 $g'(N^*) = (1-h)(1+r) - 2(1-h)r(1 - h/((1-h)r))$。<span class="marginnote">离散收获模型的临界捕捞率 $h_c = r/(1+r)$ 与连续模型的 $E_c = r$ 不同——离散的临界值总小于 1（$r$ 再大 $r/(1+r)$ 也 <1），因为离散模型里一次捕捞就能把种群「拉」到下一代，而连续模型是渐进过程。<strong>离散模型对过度捕捞更敏感</strong>：同样的参数，离散框架下更早崩溃。这类「离散 vs 连续」的差异反复提醒我们：模型选择本身会改变结论，选型要和生物时间节律匹配。</span>

**数值算例**：$r = 2$、$K = 100$、$h = 0.4$。临界捕捞率 $h_c = 2/3 \approx 0.67$，$h = 0.4 \lt  h_c$，平衡点存在且 $N^* = 100(1 - 0.4/(0.6\times2)) = 100(1 - 1/3) \approx 66.7$——可持续。若把 $h$ 提到 0.7 > $h_c$，种群必然灭绝。**离散收获模型给出的红线 $h_c = r/(1+r)$，是渔业配额管理可以直接使用的数学阈值**。

## 7 小结

- **差分方程** $N_{n+1} = f(N_n)$ 描述逐代/逐季更新的系统；线性模型 $N_{n+1} = \lambda N_n$ 的解是 $N_n = \lambda^n N_0$。
- **平衡点**满足 $N^* = f(N^*)$；**稳定性判据**是 $|f'(N^*)| \lt  1$ 稳定、$> 1$ 不稳定。
- 离散 Logistic 模型有 $N^*=0$ 与 $N^*=K$ 两个平衡点；$K$ 在 $0<r\lt 2$ 时稳定，$r>2$ 时失稳。
- **离散与连续同名方程动力学截然不同**：连续 Logistic 永无混沌，离散 Logistic 在高增长率下振荡直至混沌。
- 稳定性取决于增长率与环境，而非物种「天生」稳定。
