## 为什么从派生法讲起

上一节我们认识了词根、词干、词缀三个构件，现在进入第3章——**构词法**，即「词是如何被造出来的」。构词法有四大家族：**派生（derivation）**、**复合（compounding）**、**转类（conversion）**、**缩略类（shortening，含截短、缩略、混成）**。其中派生法是产词能力最强、也最系统的一支。<span class="marginnote">据语言学统计，英语新词中有相当大比例经由派生产生——每记住一组前缀/后缀，相当于解锁一群新词。</span>

这一节的另一层意义：**派生是「组合性（compositionality）」的极致体现**。一个词的意义可以拆解成「词根义 + 词缀义」的加合——这正是大模型时代 tokenizer 处理未见词的策略的雏形。

## 1 派生法及其基本类型

**派生法（derivation / affixation）**：通过给词根（或词干）添加派生词缀来构成新词的方法。

派生法按词缀位置分三类：

**前缀法（prefixation）**：在词首加前缀。`un- + kind → unkind`。
**后缀法（suffixation）**：在词尾加后缀。`kind + -ness → kindness`。
**中缀法（infixation）**：英语几乎不用，略。

**重点：** 前缀与后缀在英语中功能分工明确——**前缀主要改变意义，后缀主要改变词性**。这条规律是本章的纲。

## 2 前缀的语义功能

英语前缀虽多，但可按语义功能归纳为几大类：

**否定前缀**：`un-`（unhappy 不高兴的）、`in-/im-/il-/ir-`（incomplete 不完整的、impossible 不可能的、illegal 非法的、irregular 不规则的）、`dis-`（disagree 不同意）、`non-`（nonstop 不停的）、`a-`（amoral 与道德无关的）。<span class="marginnote">注意 `in-` 的四条变体依发音同化：`in-` 后遇 `p/b/m` 变 `im-`，遇 `l` 变 `il-`，遇 `r` 变 `ir-`。这是语音规则在词法中的投影。</span>
**反向/剥夺前缀**：`de-`（deforest 砍伐森林）、`un-`（unlock 解锁）、`dis-`（disarm 解除武装）。这类前缀表示「做反动作」。
**方位前缀**：`in-/im-`（inside 向内）、`out-`（outdoor 户外）、`over-`（overhead 头顶上）、`under-`（underground 地下）、`inter-`（international 国际的）、`trans-`（transatlantic 横跨大西洋的）。
**时间/次序前缀**：`pre-`（prewar 战前的）、`post-`（postwar 战后的）、`re-`（rewrite 重写）、`ex-`（ex-president 前总统）。
**数量前缀**：`mono-`（monologue 独白）、`bi-`（bicycle 自行车）、`tri-`（triangle 三角形）、`multi-`（multimedia 多媒体）、`semi-`（semifinal 半决赛）。
**加强/贬抑前缀**：`super-`（supermarket 超级市场）、`sub-`（submarine 潜艇）、`mal-`（malnutrition 营养不良）、`pseudo-`（pseudo-science 伪科学）。<span class="marginnote">许多前缀同义却源自不同语言：`un-`（日耳曼）、`in-`（拉丁）、`a-`（希腊）都表否定。词源上的「三套前缀」对应第9章的词汇历史层次。</span>

**辨析｜易错点：** 否定前缀不能随意互换。`un-` 多与日耳曼词根搭配（untrue, unfair），`in-` 多与拉丁词根搭配（incorrect, inactive）；`unhappy` 常见，而 `*inhappy` 不存在。**选哪个前缀，部分由词根来源决定**——这是英语词汇「拼装规则」的一个隐藏约束。

## 3 后缀的语义功能

后缀的核心作用是**决定词性**，但也在词性之内贡献语义层次：

**名词后缀**：`-ness`（表状态：happiness）、`-tion/-sion`（表行为/结果：education, decision）、`-ment`（表行为/产物：development）、`-ity`（表性质：activity）、`-er/-or`（表人/物：teacher, actor）、`-ee`（表受动者：employee）、`-ist`（表职业/主义信奉者：artist）、`-ism`（表主义：socialism）、`-ship`（表关系/身份：friendship）、`-hood`（表时期/身份：childhood）。<span class="marginnote">`-er/-ee` 是一对：`employer`（雇用者）与 `employee`（被雇用者）、`interviewer`（面试官）与 `interviewee`（被面试者）。把这对后缀放进「施动/受动」框架里记，一次记俩。</span>
**形容词后缀**：`-ful`（充满……的：hopeful）、`-less`（无……的：hopeless）、`-ous`（多……的：dangerous）、`-able/-ible`（可……的：readable, visible）、`-al`（……的：national）、`-ive`（有……倾向的：active）、`-y`（……状的：rainy）。
**动词后缀**：`-ize`（使……化：modernize 现代化）、`-ify`（使……化：beautify 美化）、`-en`（使……：strengthen 加强）、`-ate`（使……：activate 激活）。
**副词后缀**：`-ly`（……地：quickly）、`-ward(s)`（朝……方向：northward(s) 向北）。

**重点：** 后缀常引发**拼写变化**——`happy + -ness` 去 y 变 i 得 `happiness`；`write + -tion` 变 `writing` 的 `-ing` 除外。拼写规则（去 e、变 y 为 i、双写辅音）是派生法最实用的「隐藏章节」。

## 4 公式解析：词义 = 词根义 + 词缀义

派生法的核心是**意义的可计算组合**，可写成公式：

$$ \text{新词义} = \text{词根义} \times \text{词缀义}_1 \times \text{词缀义}_2 \cdots $$

以 `hopelessness` 为例逐步拆解：

- **第一步，词根**：`hope`（希望）。
- **第二步，加后缀 `-less`**：`hopeless` = hope + -less，义为「无望的、绝望的」（形容词）。
- **第三步，再加后缀 `-ness`**：`hopelessness` = hopeless + -ness，义为「无望的状态」——名词。
- **结果**：词根义「希望」被 `-less` 取反为「无望」，再被 `-ness` 名物化为「无望这种性质」。

**直觉**：每个后缀像一次「函数调用」——输入一个词，输出一个词性/词义变换后的新词。`-less` 是「not X」函数，`-ness` 是「the state of X」函数，层层套用即得长词。<span class="marginnote">这种「层层套函数」的图像与编程中的高阶函数同构：`stateOf(not(hope)) = hopelessness`。NLP 中词形还原（lemmatization）所做的正是把这一层层的词缀「剥回去」。</span>

## 5 派生法与全课程体系

派生法直接支撑三个后续章节：第3章后续的复合、转类、缩略是对「构词法全图」的补全；第12章词汇量扩展把「认识词根词缀」当作爆词量的主策略；而在跨学科层面，**派生词缀的「组合性」为词嵌入（word embedding）提供了直觉**——Word2Vec 里 `unfair` 的向量往往与 `fair` 的向量之差近似等于某种「否定方向」，这正是「词根义 + 词缀义」在向量空间的体现。<span class="marginnote">这不是巧合：语言的系统性会在任何忠实于语料的统计模型里自我显现。</span>

| 术语 | 英文 | 要点 |

| 派生法 | derivation / affixation | 加派生词缀造新词 |
| 前缀法 | prefixation | 词首加缀，多管语义 |
| 后缀法 | suffixation | 词尾加缀，多管词性 |
| 否定前缀 | negative prefixes | un-, in-, dis-, non-, a- |
| 反向前缀 | reversative prefixes | de-, un-, dis-（做反动作） |
| 名词后缀 | noun suffixes | -ness, -tion, -ment, -ity |
| 形容词后缀 | adjective suffixes | -ful, -less, -ous, -able |
| 动词后缀 | verb suffixes | -ize, -ify, -en, -ate |
| 词性变化 | part-of-speech change | 后缀决定词类 |
| 拼写规则 | spelling rules | 去 e、y 变 i、双写辅音 |

## 7 常见误区与易错点

**误区一：以为前缀也能改词性。** 前缀主要管语义，几乎不改词性——`unhappy` 仍是形容词、`rewrite` 仍是动词。把词性变掉的是后缀。

**误区二：否定前缀随便换。** `un-` 多配日耳曼词根（untrue）、`in-` 多配拉丁词根（incorrect）——`inhappy` 不存在。选前缀受词根来源制约，不是逻辑等价替换。

**误区三：忽略派生引发的拼写变化。** `happy + -ness` 要 y 变 i 成 `happiness`；`hope + -less` 要去 e 成 `hopeless`。拼写规则是派生法最实用的隐藏考点。

**辨析｜易错点：** `-less` 与 `-ful` 是一对「反义后缀」：`hopeful`（满怀希望）vs `hopeless`（毫无希望）。但并非所有 -less 都有 -ful 反义词（`childless` 无对应 childful），记住「配对存在但不对等」。

## 8 动手练一练

- 用否定前缀改写：`agree, possible, legal, regular, polite`，写出各自的否定形式并注意变体。
- 给 `nation` 依次加 `-al`、`-ize`、`-ation`，写出每个步骤的词性与意义。
- 用 `hopelessness` 练习「拼写规则」：说出 `hope` 加 `-less`、再加 `-ness` 时发生的拼写变化。
- 判断 `unlock`、`incomplete`、`rewrite`、`dismount` 各属于前缀的哪类语义功能。
- 找三个「-er/-or」表施动者、三个「-ee」表受动者的词，体会这对后缀的方向性。

## 9 小结

- **派生法**：加派生词缀造新词，是产词能力最强的构词方式。
- **前缀管语义**：否定、反向、方位、时间、数量等类；选前缀受词根来源（日耳曼/拉丁/希腊）制约。
- **后缀管词性**：名/形/动/副四大后缀族；同时贡献状态、施动、性质等语义。
- **公式**：新词义 ≈ 词根义 × 词缀义；`hopelessness = stateOf(not(hope))`。
- **拼写规则**：去 e、y 变 i、双写辅音，是派生法最容易扣分的实践环节。
- **NLP 连接**：组合性思想映射到词形还原与词嵌入的「否定方向」。
