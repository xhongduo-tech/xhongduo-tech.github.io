# 英语词汇学（构词法、词义关系、语块与词汇学习体系）

英语词汇学是高校英语专业的必修基础课程，以语素与构词法、词义与语义关系、语块与习语为核心，系统揭示英语词汇的内部结构与使用规律。以汪榕培《英语词汇学》和陆国强《现代英语词汇学》为纲，按章节逐节写成博文，学完一个学科 = 写完该学科权威教材对应的全部博文。

## 对标教材

- 汪榕培《英语词汇学》
- 陆国强《现代英语词汇学》
- 张维友《英语词汇学》
