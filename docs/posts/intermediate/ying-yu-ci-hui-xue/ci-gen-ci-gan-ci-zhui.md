## 为什么从「词的三构件」入手

上一节我们完成了第一次切分：把词切成语素。这一节要换个角度，从**拼装**而非**拆解**看词汇：一个词由三类构件——**词根、词干、词缀**——搭起来。掌握这三个构件及其系统，你就拥有了「看词即拆词」的能力：见到 `antidisestablishmentarianism`（33 个字母）不再慌张，而能一眼指出它是 `anti- + dis- + establish + -ment + -arian + -ism` 的套娃。<span class="marginnote">这个著名的长词是政治史术语，本意「反对政教分离的主张」，1860 年代英国政坛的产物。语言学家爱拿它做「词缀套娃」的展示品。</span>

这一章是第3章构词法的「零件库」：构件认全了，才能讨论造词工艺。

## 1 词根：词汇的核心

**词根（root）**：一个词去掉全部词缀后剩下的、携带核心词汇意义的不可再分部分。

词根分两类：

**自由词根（free root）**：可独立成词的词根。`friend`、`nation`、`love`、`write` 都是自由词根，本身就是一个词。<span class="marginnote">英语大部分本土词根是自由的——这是英语「日耳曼底层」的特征。</span>
**粘着词根（bound root）**：不能独立成词、必须加词缀才能进入词汇的词根。大多来自拉丁语与希腊语：`dict`（说）、`spect`（看）、`cred`（信）、`mort`（死）、`ped`（脚）、`aqua`（水）。如 `predict` = `pre-` + `dict`，`inspect` = `in-` + `spect`。<span class="marginnote">记住粘着词根是记学术词的捷径：`spect` 一族有 `inspect/spectator/spectacle/respect/expect`，认识词根后整族词汇半通。这正是第12章词汇量扩展法的原理。</span>

**重点：** 词根决定词的核心意义，词缀只起修饰与定位作用。`unbelievable` 的核心是 `believe`，`un-` 与 `-able` 只是给「相信」加上「不可」「可……」的色彩。

## 2 词干：加词尾之前的形态

**词干（stem）**：一个词去掉屈折词尾（`-s, -es, -ed, -ing, -er, -est`）后剩下的部分。词干是「加屈折词尾的底子」，它是词根或「词根+派生词缀」。

| 词 | 词干 | 词根 | 说明 |
| --- | --- | --- | --- |
| `books` | `book` | `book` | 词干=词根 |
| `unfriendliness` | `unfriendli-` | `friend` | 词干含派生词缀 |
| `nationalization` | `nationalize` | `nation` | 词干=nation+al+iz(e) |
| `boys` | `boy` | `boy` | 词干=词根 |

**辨析｜易错点：** 词干与词根经常被混用，关键差异是**层次**：词干是「等在那等着加屈折词尾」的形态单位，词根是「剥光所有词缀」的语义单位。`nationalization` 的词干是 `nationalize`（去掉 `-ation`），词根是 `nation`（剥光一切）。<span class="marginnote">在形态学里还有「词基（base）」这一术语，指任何可加词缀的形态——词根、词干都是词基的具体形态。本专题按汪著只强调 root / stem 两层的划分。</span>

## 3 词缀：英语的加工车间

**词缀（affix）**：附着在词根/词干上、起构词或构形作用的粘着语素。

词缀是一个完备的系统，按**位置**可分为：

**前缀（prefix）**：加在词首。英语前缀主要起**语义修饰**作用：`un-`（不）、`re-`（再）、`pre-`（前）、`anti-`（反）、`inter-`（之间）、`mis-`（错）。`rewrite` = re- + write。<span class="marginnote">英语前缀几乎不改变词性——`unhappy` 仍是形容词，`rewrite` 仍是动词。这条规律在第3章派生法中会再次强调。</span>
**后缀（suffix）**：加在词尾。英语后缀**主要决定词性**：`-ness`（名）、`-ful`（形）、`-ize`（动）、`-ly`（副）。`happiness` = happy + -ness，`beautify` = beauty + -fy。
**中缀（infix）**：插入词中。英语几乎没有真正的中缀（`abso-bloody-lutely` 这类「插入粗话」是例外），阿拉伯语、他加禄语则大量使用。

按**功能**可分为：

**派生词缀（derivational affix）**：创造新词。`-er`（动作发出者）使 `teach` → `teacher`，词位变了。
**屈折词缀（inflectional affix）**：不造新词，只表语法关系。英语的屈折词缀仅 8 个：复数 `-s/-es`、名词属格 `-'s`、第三人称单数 `-s`、过去式 `-ed`、过去分词 `-en/-ed`、进行体 `-ing`、比较级 `-er`、最高级 `-est`。<span class="marginnote">注意屈折词缀数量极少且封闭——英语是「分析型」语言，语法关系主要靠语序与功能词（of, to, have）表达，而非词尾变化；对比俄语、拉丁语丰富的屈折系统就明白英语为何「词形简单」。</span>

## 4 公式解析：三构件的组合逻辑

**「词根+派生词缀」在先，「屈折词尾」殿后**，这是英语构形的核心公式：

$$ \text{词} = [\text{词根（root）} \pm \text{派生词缀}...] + \text{屈折词尾} $$

逐步拆解 `nationalization`：

- **第一步，定核心**：词根 `nation`（民族/国家），携带核心意义。
- **第二步，加派生词缀**：`nation + -al` → `national`（形容词，国家的）；`national + -ize` → `nationalize`（动词，使国有化）；`nationalize + -ation` → `nationalization`（名词，国有化）。
- **第三步，加屈折词尾**：若要复数，写 `nationalizations`，屈折 `-s` 永远加在最外层。

**直觉**：词根是地基，派生词缀一层层「盖楼」改变词性与意义，屈折词尾是最后粉刷的墙面。这就是为什么英语派生词可无限长，而屈折永远只有薄薄一层。<span class="marginnote">验证：`denationalization` = de- + nationaliz(e) + -ation，`de-` 是「去/反向」前缀，加在 `nationalize` 前得到「去国有化」。屈折 `-s` 若要出现，一定在 `-ation` 之后，绝无例外。</span>

## 5 术语速查表：本章核心概念

本章的三个构件是全书最常用的「零件库」，用速查表锁定：

| 术语 | 英文 | 要点 |
| --- | --- | --- |
| 词根 | root | 去掉全部词缀后的核心义载体 |
| 自由词根 | free root | 可独立成词的词根（friend） |
| 粘着词根 | bound root | 须加词缀才能成词的词根（spect） |
| 词干 | stem | 去屈折词尾后的形态 |
| 词缀 | affix | 附着于词根/词干的粘着语素 |
| 前缀 | prefix | 加在词首，多管语义 |
| 后缀 | suffix | 加在词尾，多管词性 |
| 中缀 | infix | 插入词中，英语几乎没有 |
| 派生词缀 | derivational affix | 造新词（-ness, -er） |
| 屈折词缀 | inflectional affix | 表语法（-s, -ed） |
| 词基 | base | 可加词缀的形态，词根/词干皆属 |

## 6 常见误区与易错点

**误区一：把「词干」当「词根」。** `nationalization` 的词干是 `nationalize`（去掉 -ation），词根是 `nation`（剥光一切）。词干是「等待加屈折词尾」的形态，词根是「剥光词缀」的语义核——层次不同。

**误区二：以为「前缀也改词性」。** 英语前缀几乎不改变词性——`unhappy` 仍是形容词、`rewrite` 仍是动词。改词性主要靠后缀，这条分工规律是第3章派生法的基础。

**误区三：把英语当「中缀丰富的语言」。** 英语没有真正的中缀，`abso-bloody-lutely` 只是插入粗话的调侃。对比阿拉伯语、他加禄语才谈得上中缀系统。

**辨析｜易错点：** 屈折词缀「封闭」意味着什么？英语的屈折词缀仅 8 个，且绝不再增加——新词永远不需要新的复数、时态词尾。这是英语作为分析型语言的形态学标志。

## 7 动手练一练

- 拆解 `unfriendliness`，标出词根、词干，指出词根是自由还是粘着。
- 从 `denationalization` 中分别找出它的词干与词根，并说明两者的差别。
- 各举三个「后缀决定词性」的例子（形容词+ness→名词、动词+tion→名词、名词+ful→形容词）。
- 用一句话向朋友解释：「为什么 `nationalizations` 的 `-s` 一定在最外层？」
- 查词典，找到 `spect` 作为粘着词根构成的三个词，验证「认识词根解锁词族」。

## 8 小结

- **词根**：核心意义承载体，分自由词根与粘着词根；粘着词根多来自拉丁、希腊语。
- **词干**：去屈折词尾后的形态，是「等着加词尾」的底子；词干≠词根，层次不同。
- **词缀**：按位置分前缀/后缀/中缀；英语前缀管语义、后缀管词性、中缀几乎不存在。
- **派生 vs 屈折**：派生造新词、可无限扩展；屈折只表语法、英语仅 8 个且封闭。
- **组合公式**：词根 ± 派生词缀 + 屈折词尾，屈折永远殿后。

在下一节，我们将对词缀做更细的解剖，从「词根/词干/词缀」进入语素的自由与粘着二分，以及派生层次的叠加规则——**自由语素、粘着语素与派生层次**。
