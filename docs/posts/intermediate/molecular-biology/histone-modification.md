## 为什么从组蛋白修饰开始

《DNA甲基化》的结尾说「甲基化扣扳机，组蛋白修饰完成射击」——现在来看组蛋白修饰本身。核小体的组蛋白**从核小体表面伸出柔性的 N 端尾巴**，上面有几十个可被化学修饰的氨基酸残基。<span class="marginnote">这些修饰包括<strong>乙酰化（acetylation）、甲基化（methylation）、磷酸化（phosphorylation）、泛素化（ubiquitination）</strong> 等十余种，在几十个特定位点上组合，构成一组精细的「分子标注」。<strong>DNA 甲基化只有 5mC 一种，而组蛋白修饰是一整个字母表。</strong></span>这一课讲三类核心修饰的写入-读取-擦除，以及「组蛋白密码」的概念与限度。

先建立一个「分子标注」的观念：如果把基因组比作一本巨型手册，DNA 序列是「正文」，那么组蛋白修饰就是写在意料之外的**页边标注**——用化学基团标记哪些章节「正在使用」（活性）、哪些「归档冻结」（沉默）。组蛋白从核小体伸出的 N 端尾巴上有几十个可修饰位点，乙酰化、甲基化、磷酸化、泛素化等修饰组合起来，构成一套精细的「分子标注系统」。

这套系统与 DNA 甲基化（上一课）互补又联动：DNA 甲基化提供「长期存档」，组蛋白修饰提供「快速标注」。而它的核心逻辑是**「写-读-擦」三方的循环**——写入器（HAT/HMT）、读码器（溴结构域/染色质域）、擦除器（HDAC/去甲基化酶）共同决定「标注的状态」。这一课讲三种核心修饰（乙酰化、甲基化为主）的化学与功能，深入「组蛋白密码假说」及其限度，并落到与癌症的联系。

## 1 修饰的化学：乙酰化与甲基化为主角

**赖氨酸乙酰化（Kac）** 是最「直白」的修饰：

**写入**：组蛋白乙酰转移酶（**HAT**，如 p300/CBP）把乙酰基加到赖氨酸的 ε-氨基上。
**效果**：乙酰基**中和了赖氨酸的正电荷**，削弱组蛋白与 DNA 磷酸骨架（负电）的静电吸引 → 核小体间的相互作用变弱、染色质松弛 → **「开门」**。
**擦除**：组蛋白去乙酰化酶（**HDAC**）移除乙酰基 → 恢复正电 → 染色质收紧 → **「关门」**。<span class="marginnote">乙酰化-去乙酰化的「开关」是<strong>可逆且快速</strong>的，是细胞响应信号最灵活的表观开关之一。HDAC 抑制剂（如伏立诺他）是已上市的抗癌药——通过放开乙酰化、激活沉默基因来抑制肿瘤。</span>

**赖氨酸甲基化（Kme）** 更微妙——它**不改变电荷**，主要作为**识别信号**：

甲基化有**单（me1）、双（me2）、三（me3）** 三种程度；
不同位点、不同程度的甲基化含义截然不同：
**H3K4me3** → 活跃启动子的标志；
**H3K36me3** → 转录延伸中的基因体标志；
**H3K9me3** → 组成型异染色质、沉默；
**H3K27me3** → 多梳（Polycomb）介导的发育沉默。<span class="marginnote"><strong>甲基化不改变电荷，却携带最多的「语义」</strong>——因为不同的甲基化状态被不同的「读码器」识别。<strong>同一种化学修饰（甲基），靠「位置 + 程度」编码截然不同的含义</strong>——这是理解表观调控必须建立的坐标系。</span>

## 2 写入器、擦除器与读码器

组蛋白修饰系统由三类蛋白组成，构成「写-读-擦」的完整循环：

| 角色 | 代表 | 识别/催化 |
| --- | --- | --- |
| 写入器（writer） | HAT、HMT（如 EZH2）、激酶 | 催化添加修饰 |
| 擦除器（eraser） | HDAC、去甲基化酶（LSD1、JmjC） | 移除修饰 |
| 读码器（reader） | 溴结构域（bromodomain）、染色质域（chromodomain）、PHD 指 | 结合特定修饰 |

**读码器是「组蛋白密码」的翻译官**：**溴结构域**读乙酰化，**染色质域**读甲基化（如 HP1 的 chromodomain 读 H3K9me3）。读码器结合修饰后，招募下游机器（重塑复合物、转录机器），把「标注」变成「行动」。<span class="marginnote"><strong>HP1 的故事</strong>：H3K9me3 → HP1 通过 chromodomain 结合 → HP1 寡聚并招募 HMT（SUV39）继续在相邻核小体上写 H3K9me3 → <strong>修饰自蔓延</strong>，形成大片异染色质。这是「正反馈造就沉默域」的教科书机制，也是《染色质重塑与表观遗传》里「自维持记忆」的分子实现。</span>

## 3 组蛋白密码假说与它的限度

2000 年，Strahl 与 Allis 提出**组蛋白密码假说（histone code hypothesis）**：组蛋白上的多种修饰组合起来，像密码一样编码调控信息，被下游效应器（读码器）解码。<span class="marginnote">这个假说的动人之处在于它把「组合」提升为「编码」——单个修饰的含义依赖上下文，多个修饰的组合携带更多信息。<strong>它与《信息论》的亲和性极强：组合状态数 = 信息容量。</strong></span>

**公式解析：组蛋白修饰的「信息容量」**

设一个组蛋白尾上有 $m$ 个可修饰位点，每个位点有 $s$ 种可能状态（无修饰 + 各修饰），则理论上的组合状态数为：

$$
N_{\text{状态}} = s^{m}
$$

- **第一步，代入粗略数字**：若 $m = 20$、$s = 4$，则 $N = 4^{20} \approx 1.1 \times 10^{12}$——**超过万亿种组合状态**。
- **第二步，理性降温**：这个数字是**理论上限**。真实细胞中：(1) 位点间并不独立，某些修饰互相依赖（**串话，cross-talk**）；(2) 读码器只有有限几十种，无法区分万亿种状态；(3) 大量组合可能毫无生物学效应。<span class="marginnote"><strong>「组蛋白密码」更像「组蛋白标点」而非「密码本」</strong>：修饰确实携带信息、确实被读取，但信息的「分辨率」远低于 10¹² 种状态。<strong>警惕把组合计数误当作「实际编码容量」</strong>——这是分子生物学里信息论类比最容易被滥用的地方。</span>
**第三步，看实证方法**：要确定某修饰的「语义」，靠**染色质免疫沉淀测序（ChIP-seq）**：用特异性抗体富集带某修饰的 DNA 片段，再测序定位——**把「某处有某修饰」变成全基因组地图**。<span class="marginnote">ChIP-seq 是表观基因组学的核心技术：它把「化学修饰的空间分布」翻译成「测序读段密度」，与《分子生物学技术》的测序篇直接相连。一张 H3K4me3 的 ChIP-seq 图谱，就是一份「全基因组启动子活跃度地图」。</span>

## 4 修饰与转录的联动：两条「沉默通路」

组蛋白修饰经常与转录调控机器联动，最著名的两条沉默通路：

**H3K9me3 通路**：SUV39 写 H3K9me3 → HP1 读 → 异染色质建立，沉默重复序列与转座子（防止转座子爆发）。
**H3K27me3 通路（多梳）**：**PRC2**（含催化亚基 EZH2）写 H3K27me3 → PRC1 读并泛素化 H2A → 发育基因被**可逆地、组织特异性地**沉默。<span class="marginnote"><strong>多梳（Polycomb）</strong> 是果蝇里发现的发育调控因子——它沉默的是<strong>本该沉默、但未来可能再开的基因</strong>（如 Hox 基因）。与组成型异染色质不同，多梳沉默<strong>保留可重激活的潜力</strong>，是「可逆开关」的典型。</span>

**正反两面**：H3K4me3（激活）与 H3K27me3（沉默）可以**同时出现在同一个启动子**上，形成**二价结构域（bivalent domain）**——尤其在胚胎干细胞中，使发育基因「引而待发」：分化方向确定后，二价解体，一边胜出。<span class="marginnote">二价域是「基因调控中的薛定谔盒子」：<strong>同一个启动子同时挂着「开」与「关」两种标记，静待分化的判决</strong>。这是表观调控「多状态、可切换」本质的极致体现。</span>

## 5 修饰串话与表观-遗传的接口

组蛋白修饰不是孤立的：修饰之间、以及修饰与 DNA 甲基化之间，存在大量**串话（cross-talk）**。例如 H3K9me3 招募的蛋白可以招募 DNMT，把组蛋白沉默「固化」为 DNA 甲基化——**组蛋白修饰提供「快照」，DNA 甲基化提供「长期存档」**。<span class="marginnote">由此看表观调控的层级：<strong>磷酸化（秒级）→ 组蛋白乙酰化（分钟级）→ 组蛋白甲基化（小时级）→ DNA 甲基化（跨代级）</strong>——时间尺度越长的机制越稳定、也越难逆转。表观调控的「时间轴」本身就是一个完整的故事。</span>

## 6 组蛋白修饰与癌症：表观致癌的「开关误置」

组蛋白修饰系统的失调是癌症的常见「元凶」——**表观遗传的「开关」被拨错，效果等同于致癌突变**：

**EZH2（PRC2 催化亚基）过度活跃**：在多种淋巴瘤与实体瘤中高表达或突变，使 H3K27me3 过度沉积、抑癌基因被过度沉默——**EZH2 抑制剂（如 tazemetostat）已获批治疗上皮样肉瘤**。<span class="marginnote"><strong>EZH2 的故事说明「表观酶」可以像「激酶」一样被成药</strong>：它把「H3K27me3 太多 → 抑癌基因沉默 → 肿瘤」这条链清晰地串起来，药物则通过「降低甲基化、重新打开基因」来逆转。<strong>组蛋白修饰酶，已经成为继激酶之后的第二大类表观药物靶点。</strong></span>
**组蛋白突变（oncohistone）**：某些儿童胶质瘤携带 **H3K27M 突变**——H3 第 27 位赖氨酸被换成甲硫氨酸，**抑制 PRC2 活性、全局降低 H3K27me3**，导致基因表达失衡。**组蛋白本身突变致癌**——「表观遗传硬件」直接参与癌变，是近年最引人注目的发现之一。<span class="marginnote"><strong>oncohistone 提醒我们</strong>：表观遗传与遗传的界限并不绝对——组蛋白的「修饰位点」被突变破坏，效果是「全局表观失调」。<strong>「读-写-擦」系统的任何一个环节（序列、酶、修饰状态）出问题，都可能致癌。</strong></span>
**去乙酰化酶抑制**：HDAC 抑制剂（伏立诺他）已用于皮肤 T 细胞淋巴瘤，通过「放开乙酰化」重新激活部分基因。

## 7 组蛋白修饰的「解读」：从 ChIP-seq 到表观注释

组蛋白修饰研究离不开「如何解读大规模修饰数据」的方法论——这本身就是一门学问：

**ChIP-seq 的「峰」**：用抗体富集带某修饰的 DNA，测序后在全基因组上形成**峰值（peak）**——峰值位置即该修饰的分布。**H3K4me3 峰对应启动子、H3K27ac 峰对应活性增强子与启动子、H3K36me3 峰对应基因体**——「修饰类型 → 基因组元件的注释」是表观基因组学的核心操作。<span class="marginnote"><strong>「组蛋白修饰是基因组的『彩色注释』」</strong>：不同修饰像不同颜色的荧光笔，标出启动子、增强子、基因体、异染色质——<strong>一张 ChIP-seq 图谱就是一份「基因组功能地图」</strong>。RNA-seq 告诉「表达量」，ChIP-seq 告诉「调控状态」，两者叠加才能理解「为什么表达」。</span>
**「三联峰」的陷阱**：抗体质量差、ChIP 效率低或背景高，都会产生**伪峰（artifact）**——**「看到峰 ≠ 真的有修饰」**。因此需要用对照（Input/IgG）与统计显著（如 MACS 的峰调用）来过滤。<span class="marginnote"><strong>「峰调用的统计」是生信基本功</strong>：比较 ChIP 与 Input 的富集倍数、计算 p 值、控制 FDR——<strong>「一个峰的置信度」是可以量化的</strong>。这提醒我们：<strong>分子生物学的「定性结论」背后，站着一整套统计推断。</strong></span>
**从「单修饰」到「修饰组合」**：真正决定状态的常是**多个修饰的组合**（如活性启动子 = H3K4me3 + H3K27ac，抑制 = H3K27me3）——**「单看一个修饰会误判，看组合才准确」**（呼应第 3 节的「组蛋白密码」讨论）。

**方法论的意义**：组蛋白修饰研究教会我们——**「数据 → 注释 → 机制」的每一步都需要明确的判据与统计**，而这正是「组学时代」分子生物学的通用范式。

## 8 组蛋白修饰与「表观状态图」：把修饰读成细胞的「操作系统」

组蛋白修饰最终要回答的问题是：**「细胞的表观状态是怎样的？」**——这需要一个整合的「状态图」：

**染色质状态（chromatin state）**：用多组 ChIP-seq（多种修饰 + 开放性 + 结合因子）通过聚类，可以把基因组注释成有限的几种「状态」——活性启动子、增强子、基因体、异染色质、沉默区等（ChromHMM 等工具）——**「把亿万修饰信号压缩成一张『基因组状态图』」**。<span class="marginnote"><strong>「染色质状态 = 基因组的『标注层』」</strong>：就像地图上用不同颜色标出城市、农田、森林，染色质状态把基因组标成「活跃」「沉默」「待定」等区域。<strong>「读这张状态图，就能预测基因表达」</strong>——这是表观基因组学的核心产品。</span>
**状态图的应用**：预测增强子（H3K27ac + 开放）、注释细胞类型特异的调控区、解释疾病风险变异（风险 SNP 落在哪个状态区）——**「状态图是理解『调控在何处发生』的地图」**。<span class="marginnote"><strong>「疾病变异的功能注释依赖状态图」</strong>：一个风险 SNP 若落在「活性增强子」状态区，比落在「异染色质」更可能与调控有关——<strong>「状态图把 GWAS 的『百万位点』过滤成『候选调控位点』」</strong>。</span>
- **动态性**：状态图不是静态的——同一细胞在不同条件下状态会切换（增强子开/关、沉默/激活）——**「表观状态是动态平衡，不是一成不变的标签」**。

**「从修饰到状态，从状态到功能」**：组蛋白修饰研究的终点，是构建一张可预测、可解释、可操作的「基因组表观状态图」——**它让「表观遗传」从概念变成可计算的图景**。

## 9 小结

- **组蛋白尾巴**上发生乙酰化、甲基化、磷酸化、泛素化等修饰；**乙酰化**中和电荷、开门，**甲基化**不改变电荷、靠读码器传语义。
- **写-读-擦**：HAT/HMT 写入、HDAC/去甲基化酶擦除、溴结构域/染色质域读取；HP1 使 H3K9me3 自蔓延。
- **关键标记**：H3K4me3（启动子激活）、H3K36me3（基因体）、H3K9me3（异染色质）、H3K27me3（多梳沉默）。
- **组蛋白密码假说**：组合状态 $s^m$ 可达万亿级，但实际编码远低于上限——「密码」更像「标点」。
- **ChIP-seq** 把修饰定位到全基因组；二价域（H3K4me3+H3K27me3）让发育基因「引而待发」。
- **染色质状态注释**：把多种修饰聚类成「活性启动子/增强子/异染色质」等状态图——「修饰 → 功能地图」。

在下一节，我们从「化学修饰」转向「RNA 层面的调控」：**非编码 RNA 家族中的明星——miRNA，如何像剪刀一样精确剪断基因表达。**
