# 布朗运动的马尔可夫性与鞅性

<div class="epigraph">
<p>布朗运动既记不住过去（马尔可夫），又不偏向未来（鞅）——它是随机过程里最「无私」的两个性质的化身。</p>

## 两个「主义」的汇合

布朗运动同时拥有随机过程的两大「主义」：**马尔可夫性**（给定现在，未来独立于过去）与**鞅性**（条件期望等于现在）。它不是巧合——**独立增量同时孕育了两者**：独立增量让「未来增量」与「过去」脱钩（马尔可夫），也让「未来增量的期望」为零（鞅）。

这一节的收获是三个「布朗鞅」——它们是布朗运动最锋利的工具：
$$
B(t), \qquad B(t)^2 - t, \qquad e^{\theta B(t) - \theta^2 t/2}.
$$
**第一个说「位置公平」，第二个说「平方扣除时间后公平」，第三个说「指数折现后公平」**。这三件法宝将在第八篇的 Itô 公式、第十篇的期权定价里反复出场。<span class="marginnote">三件法宝的分工：<strong>$B(t)$ 管「一阶矩」，$B(t)^2 - t$ 管「二阶矩与方差」，指数鞅管「大偏差与测度变换」</strong>。它们分别对应「线性鞅 / 二次鞅 / 指数鞅」——与赌徒破产里那套「三件法宝」完全同构，只是从离散换成了连续。</span>

本节目标：证明马尔可夫性与鞅性、验证三个布朗鞅、并理解「强马尔可夫性」带来的延伸。

## 1 马尔可夫性

**布朗运动的马尔可夫性**：对 $t \ge 0$ 与 $s \ge 0$，给定 $B(t)$，$B(t+s)$ 的条件分布只依赖 $B(t)$，与 $B(u)$（$u < t$）无关。

**为什么成立**：写出 $B(t+s) = B(t) + \big(B(t+s) - B(t)\big)$。增量 $B(t+s) - B(t)$ 与 $B(t)$ 之前的一切**独立**（独立增量），于是给定 $B(t)$ 后，$B(t+s)$ 的分布完全由 $B(t)$ 与「独立的正态增量」决定——**过去不再参与**。

**更强的形式——强马尔可夫性（strong Markov property）**：把「固定时刻 $t$」换成「停时 $\tau$」：
$$
B(\tau + s) - B(\tau) \;\text{ 与 } \tau \text{ 之前的历史独立，且 } \sim N(0, s),
$$
条件是 $\tau$ 是停时且 $P(\tau < \infty) = 1$。<span class="marginnote">强马尔可夫性把「重新开始」从固定时刻推广到随机时刻：<strong>在停时 $\tau$ 之后，布朗运动「重新出生」，从 $B(\tau)$ 出发，与过去完全独立</strong>。这几乎是下一节「反射原理」的全部依据——反射原理就是「在首中时刻停住、再翻转」。</span>

## 2 鞅性

**定理**：以下三个过程都是（关于 $\{B(s) : s \le t\}$ 的）鞅：

1. **位置鞅**：$B(t)$——由 $E[B(t+s) - B(t) \mid \text{过去}] = E[\text{增量}] = 0$；
2. **二次鞅**：$B(t)^2 - t$——$E[B(t+s)^2 \mid \cdots] = B(t)^2 + s$（增量独立），故 $E[B(t+s)^2 - (t+s) \mid \cdots] = B(t)^2 - t$；
3. **指数鞅**：$\mathcal{E}_\theta(t) = e^{\theta B(t) - \theta^2 t/2}$——$E[e^{\theta \text{增量}}] = e^{\theta^2 s/2}$（正态矩母），正好抵消 $-s\theta^2/2$ 的扣除。

**指数鞅的推导**：增量 $B(t+s)-B(t) \sim N(0, s)$，矩母 $E[e^{\theta\Delta B}] = e^{\theta^2 s/2}$。于是
$$
E\big[ \mathcal{E}_\theta(t+s) \mid \mathcal{F}_t \big] = \mathcal{E}_\theta(t) \cdot e^{-\theta^2 s/2} \cdot E[e^{\theta \Delta B}] = \mathcal{E}_\theta(t).
$$
**「扣除 $e^{-\theta^2 t/2}$」恰好抵消正态矩母的 $e^{\theta^2 t/2}$——指数鞅是「把正态增长折现成公平」的产物。**<span class="marginnote">指数鞅 $\mathcal{E}_\theta(t)$ 是金融里「风险中性测度」和「鞅表示」的主角（第十篇）。它也叫「随机指数」——Itô 积分的指数版本。记它的结构：<strong>$e^{\text{布朗部分}}$ × $e^{-\frac12\text{时间部分}}$</strong>，两项互相抵消。</span>

## 3 公式解析：验证 B(t)² - t 是鞅

**目标：把 $E[B(t+s)^2 - (t+s) \mid \mathcal{F}_t] = B(t)^2 - t$ 的每一步写清。**

第一步，展开条件平方。把 $B(t+s)$ 拆成 $B(t) + \Delta$（$\Delta \sim N(0,s)$ 且与 $\mathcal{F}_t$ 独立）：
$$
E\big[ B(t+s)^2 \mid \mathcal{F}_t \big] = E\big[ (B(t) + \Delta)^2 \mid \mathcal{F}_t \big] = B(t)^2 + 2B(t)E[\Delta] + E[\Delta^2].
$$
第二步，用增量的矩。$E[\Delta \mid \mathcal{F}_t] = 0$，$E[\Delta^2 \mid \mathcal{F}_t] = s$（条件于过去，$\Delta$ 仍是 $N(0,s)$）：
$$
E[B(t+s)^2 \mid \mathcal{F}_t] = B(t)^2 + s.
$$
第三步，减去时间。两边减 $(t+s)$：
$$
E\big[ B(t+s)^2 - (t+s) \mid \mathcal{F}_t \big] = B(t)^2 + s - t - s = B(t)^2 - t.
$$
第四步，结论。$B(t)^2 - t$ 满足鞅条件。**「平方的期望增长恰好等于时间」——$B(t)^2$ 的「漂移」是 $t$，扣掉它，剩下的公平。**

**这个推导为什么重要**：它示范了「验证连续鞅」的标准动作——**条件于过去、利用增量独立性、展开再抵消**。二次鞅 $B(t)^2 - t$ 是第八篇 Itô 公式在 $f(x) = x^2$ 时的特例：Itô 公式说 $dB^2 = 2B dB + dt$，其中 $dt$ 就是这里扣掉的「漂移」。

## 4 强马尔可夫性与反射原理

强马尔可夫性最漂亮的应用是**反射原理（reflection principle）**（下一节详述）：设 $T_a = \min\{t : B(t) = a\}$（$a > 0$，首中时刻）。由强马尔可夫性，$T_a$ 之后的过程从 $a$ 重新开始，与之前独立。于是「首中后再超过 $2a$」与「直接超过 $2a$」有对称关系——这直接给出首中时分布。

**马尔可夫 + 鞅 + 强马尔可夫，三者合一**：布朗运动同时是**马尔可夫过程、鞅、强马尔可夫过程**——这三个身份在连续时间里同时成立，是布朗运动独特地位的源泉。<span class="marginnote">对照第四篇：<strong>离散马尔可夫链同时具有「强马尔可夫性」（在停时后重新开始）与「鞅的构造」（如 $S_n^2 - n$）</strong>。布朗运动把这两条从离散继承到连续，且因为连续时间的平滑性，两条性质都「更干净」——下一节的反射原理正是离散对称随机游走的「反射」技巧的连续版。</span>

## 5 应用一瞥

- **反射原理**：首中时、最大值分布、反正弦律（下两节）——全靠强马尔可夫性。
- **期权定价**：指数鞅给出风险中性测度；$B(t)$ 的鞅性保证「无套利」。
- **随机积分**：$B(t)^2 - t$ 的鞅性是 Itô 等距的种子；指数鞅是 Itô 公式的指数版本。
- **统计检验**：布朗运动的鞅性让「是否有漂移」的检验有精确零分布。

## 6 小结

- **马尔可夫性**：独立增量 ⟹ 给定现在、未来独立于过去；**强马尔可夫性**：停时后同样重新开始。
- **三大布朗鞅**：$B(t)$、$B(t)^2 - t$、$e^{\theta B(t) - \theta^2 t/2}$——分别管一阶、二阶、指数矩。
- **验证套路**：条件于过去 + 利用增量独立性 + 展开抵消。
- **强马尔可夫 + 反射原理**：首中时、最值分布的地基。
- 应用：定价、随机积分、检验、测度变换。

在下一节，我们用强马尔可夫性解决布朗运动的第一个经典问题：**首中时的分布与反射原理**——第一次到达某个水平的时刻。
