## 一座「两端归零」的桥

布朗运动从 0 出发，终点 $B(1)$ 是随机的。如果**强迫终点也归零**——考虑 $B(1) = 0$ 条件下的布朗运动——会得到一座漂亮的「桥」：起点与终点都在 0，中间随机摆动。这就是**布朗桥（Brownian bridge）**。

布朗桥不只是理论玩具：**Kolmogorov-Smirnov 检验**（拟合优度检验的基石）的统计量分布，正是布朗桥上确界的分布；统计中的「经验过程」在极限下也收敛到布朗桥。理解布朗桥，等于打通了「随机过程 → 统计检验」的任督二脉。<span class="marginnote">布朗桥的统计意义：<strong>经验分布函数与真实分布函数之差（乘 $\sqrt n$）在 $n \to \infty$ 时收敛到一个布朗桥</strong>（Donsker 定理）。于是「数据是否符合某分布」的检验，被翻译成「布朗桥是否触碰某条边界」——K-S 检验的全部理论都在这里。</span>

本节目标：定义布朗桥、给出它的协方差与高斯结构、并理解「条件布朗运动」视角。

## 1 定义与构造

**布朗桥（Brownian bridge）**：设 $B(t)$ 是标准布朗运动，定义
$$
B^0(t) = B(t) - t\, B(1), \qquad 0 \le t \le 1.
$$
**性质**：$B^0(0) = B(0) - 0 = 0$，$B^0(1) = B(1) - B(1) = 0$——**两端都归零**。中间的 $tB(1)$ 项是一条「从 0 到 $B(1)$ 的直线」，把它从布朗运动里扣掉，正好把终点拉回 0。

**均值与协方差**：
$$
E[B^0(t)] = 0, \qquad \mathrm{Cov}\big( B^0(s), B^0(t) \big) = \min(s,t) - st.
$$
**协方差从 $\min(s,t)$ 变成 $\min(s,t) - st$**——扣掉线性趋势后，相关性减弱了「$st$」那么多。在两端（$s$ 或 $t$ 为 0 或 1）协方差为 0——桥的两端被钉死，没有波动。<span class="marginnote">协方差 $\min(s,t) - st$ 的几何：<strong>布朗桥的方差 $\mathrm{Var}(B^0(t)) = t(1-t)$——中间最大（$t=1/2$ 时 $1/4$），两端为 0</strong>。桥在中间晃得最厉害，两端被钉死。这是一个「两端约束、中间自由」的抛物线方差形状。</span>

## 2 条件布朗运动视角

布朗桥还有一个更深刻的身份：**它是「给定 $B(1) = 0$」的条件布朗运动**：
$$
B^0(t) \;\overset{d}{=}\; \big( B(t) \mid B(1) = 0 \big).
$$

**为什么成立**：$(B(t), B(1))$ 是二维正态，条件于 $B(1) = 0$ 的正态条件期望为
$$
E\big[ B(t) \mid B(1) = 0 \big] = 0 + \frac{\mathrm{Cov}(B(t), B(1))}{\mathrm{Var}(B(1))}\big(0 - 0\big) = 0,
$$
而条件方差与协方差恰好给出 $\min(s,t) - st$。**条件正态 ⟹ 条件过程仍是高斯过程，均值为 0、协方差 $\min(s,t) - st$——与构造式完全一致。**<span class="marginnote">「条件布朗运动 = 布朗桥」是一个更一般的模式的例子：<strong>高斯过程在固定某些点的条件，仍是高斯过程，且协方差被「钉点」修正</strong>。这正是贝叶斯非参数 / 高斯过程回归（Gaussian process regression）的核心机制——先验高斯过程，条件于观测点，后验仍是高斯过程。本站「从极限到大模型」的贝叶斯优化一章会再次遇见它。</span>

## 3 高斯过程视角

布朗桥是**高斯过程（Gaussian process）**家族的一员：它的任意有限维分布都是多元正态。高斯过程的完整描述只需要两个函数——**均值函数 $m(t)$ 与协方差函数 $k(s,t)$**：
$$
B^0: \qquad m(t) = 0, \qquad k(s,t) = \min(s,t) - st.
$$
**「高斯过程」=「任意有限维分布高斯的随机过程」**。布朗运动（$k = \min$）、布朗桥（$k = \min - st$）、后面第九篇的平稳过程，都是高斯过程的特例。<span class="marginnote">高斯过程的普适框架：<strong>选一个协方差函数，就定义了一个高斯过程</strong>。$\min(s,t)$ 给布朗运动，$\min - st$ 给布朗桥，$e^{-|s-t|}$ 给 OU 过程（第八篇），$e^{-\|s-t\|^2/2}$ 给 RBF 核（机器学习）——<strong>同一个「均值 + 协方差」语言，贯穿随机过程与机器学习</strong>。</span>

## 4 公式解析：从条件公式推布朗桥协方差

**目标：用「条件正态」公式推出 $\mathrm{Cov}(B^0(s), B^0(t)) = \min(s,t) - st$。**

第一步，写条件协方差公式。对联合高斯 $(X, Y)$，条件于 $Y = y$ 的协方差
$$
\mathrm{Cov}(X_1, X_2 \mid Y) = \mathrm{Cov}(X_1, X_2) - \frac{\mathrm{Cov}(X_1, Y)\mathrm{Cov}(X_2, Y)}{\mathrm{Var}(Y)}.
$$
第二步，代入。$X_1 = B(s)$，$X_2 = B(t)$，$Y = B(1)$：
$$
\mathrm{Cov}(B(s), B(t) \mid B(1)) = \min(s,t) - \frac{s \cdot t}{1} = \min(s,t) - st.
$$
第三步，注意 $\mathrm{Cov}(B(u), B(1)) = \min(u, 1) = u$（$u \le 1$）。代入即得。

第四步，对照构造式。$B^0 = B - tB(1)$ 的直接展开：
$$
\mathrm{Cov}(B^0(s), B^0(t)) = \mathrm{Cov}(B(s) - sB(1), B(t) - tB(1)) = \min(s,t) - st - ts + st = \min(s,t) - st.
$$
两条路殊途同归——**条件视角与构造视角给出同一个协方差**。

**这个推导为什么重要**：它演示了「条件高斯」的两条等价路线——**要么条件正态公式，要么直接构造式展开**。高斯过程的「条件保持高斯」性质，是统计学习里高斯过程回归的全部根基。

## 5 应用：Kolmogorov-Smirnov 检验

**K-S 检验**：检验样本是否来自某分布 $F_0$。经验分布函数 $F_n(x)$ 与 $F_0(x)$ 的最大偏差
$$
D_n = \sup_x \big| F_n(x) - F_0(x) \big|
$$
是检验统计量。**Donsker 定理**：$\sqrt{n} (F_n - F_0)$ 在 $n \to \infty$ 时（时间重标定后）收敛到**布朗桥**。

于是检验的临界值来自
$$
P\big( \sup_{0\le t\le 1} |B^0(t)| \le c \big),
$$
即「布朗桥的确界分布」。K-S 检验表里的每个数字，都是布朗桥的这个分布算出来的。<span class="marginnote">「K-S 检验 = 布朗桥的确界」是随机过程与统计的著名握手：<strong>一个看似纯统计的检验，其临界值的来源是布朗桥</strong>。这解释了为什么「经验过程」（empirical process）与随机过程理论密不可分——样本的累积分布是「数据版的随机过程」。</span>

## 6 小结

- **布朗桥** $B^0(t) = B(t) - tB(1)$：两端归零，均值 0，协方差 $\min(s,t) - st$。
- **条件视角**：$B^0 \overset{d}{=} (B(t) \mid B(1) = 0)$——条件高斯仍是高斯。
- **高斯过程**：均值 + 协方差函数完全决定分布；布朗运动/桥/OU 都是特例。
- **方差形状** $\mathrm{Var}(B^0(t)) = t(1-t)$：中间最大、两端钉死。
- **应用**：K-S 检验 = 布朗桥确界分布；Donsker 定理连接经验过程。
