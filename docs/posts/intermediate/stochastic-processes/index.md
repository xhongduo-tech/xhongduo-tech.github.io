# 随机过程

随机过程研究随时间演化的随机现象，是概率论向动态系统的延伸。本分类对标张波《应用随机过程》与 Ross《Stochastic Processes》的章节体系，从泊松过程、马尔可夫链一路写到鞅、布朗运动与随机积分。
