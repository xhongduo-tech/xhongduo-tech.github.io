# 强化学习的随机过程视角：贝尔曼方程与马尔可夫性

## 当 MDP 的「模型」未知

上一节的 MDP 假设我们知道转移概率 $P$ 与回报 $r$。但现实里几乎从不知道——机器人不知道物理的精确转移律，棋手不知道对手的策略，大模型调优不知道「奖励函数」的精确形式。**强化学习（Reinforcement Learning, RL）**解决的就是「$P$、$r$ 未知时的最优决策」——它通过与环境的交互（试错）学习最优策略。

从随机过程的视角看，RL 的一切都建立在两条腿上：**马尔可夫性**（状态是充分的统计量）与**贝尔曼方程**（价值可递归）。**蒙特卡洛、时序差分、Q-learning——所有 RL 算法都是「在未知环境下逼近贝尔曼方程的解」**。<span class="marginnote">RL 与随机过程的分工：<strong>随机过程给了 RL 全部「静态」工具——马尔可夫性（状态概括）、贝尔曼方程（递归）、鞅与收敛（算法分析的数学）</strong>；RL 加了「动态」——如何在没有模型时估计这些量。</span>

本节目标：建立 RL 的随机过程框架、梳理三大算法家族的数学身份、并理解「探索-利用」的权衡。

## 1 RL = MDP + 未知模型

**RL 问题**：与 MDP 相同的四元组，但 $P$、$r$ **未知**，只能通过与环境交互观测 $(S_t, A_t, R_t, S_{t+1})$。目标是学一个策略 $\pi$ 最大化折现回报。

**模型类**：

- **有模型 RL**：先学 $P$、$r$ 的估计，再解 MDP（规划）；
- **无模型 RL**：跳过模型，直接学值函数或策略。

**随机过程视角**：即使 $P$ 未知，**每个固定策略下的状态序列仍是马尔可夫链**（马尔可夫性由环境保证）——所以马尔可夫链的收敛、平稳、遍历理论仍然是「策略评估」的数学基础。

**辨析｜易错点：** 「每个固定策略下状态序列是马尔可夫链」不等于「环境是马尔可夫的」。若环境状态本身非马尔可夫（如部分可观测的 POMDP），基于当前状态的 $V(S_t)$ 会系统性偏差——**马尔可夫性是 RL 的第一假设，破坏了它，值函数的收敛性就站不住**。这也是「记忆增强」（把历史塞进状态）存在的理由。

## 2 三大算法家族的随机过程身份

**蒙特卡洛（MC）**：跑完整条轨道，用经验回报平均估计 $V^\pi(s)$。**它利用「遍历性」——时间平均近似集合平均**（第九篇）。无偏但高方差（需完整回合）。

**时序差分（TD）**：用「当前回报 + 下一步估计」更新：
$$
V(S_t) \leftarrow V(S_t) + \alpha\big[ R_t + \gamma V(S_{t+1}) - V(S_t) \big].
$$
**TD 是「在线的贝尔曼方程」——它每一步都往贝尔曼不动点走一步**。偏差低（不需完整回合）、方差高。**TD 的收敛性用随机逼近（鞅）理论证明**（第六篇的鞅派上用场）。

**Q-learning**：学习动作值函数 $Q(s, a)$：
$$
Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha\big[ R_t + \gamma \max_{a'} Q(S_{t+1}, a') - Q(S_t, A_t) \big].
$$
**Q-learning 是不依赖策略的（off-policy）——它直接逼近最优贝尔曼方程 $Q^*$**。这是 RL 最经典的算法，也是 DQN（深度 Q 网络）的骨架。

**数值体验：TD 的一步更新。** 设 $\gamma = 0.9$、$\alpha = 0.1$，当前估计 $V(S_t) = 10$，观测到回报 $R_t = 2$、下一步估计 $V(S_{t+1}) = 12$。TD 目标是
$$
R_t + \gamma V(S_{t+1}) = 2 + 0.9 \times 12 = 12.8,
$$
TD 误差 $\delta = 12.8 - 10 = 2.8$，于是
$$
V(S_t) \leftarrow 10 + 0.1 \times 2.8 = 10.28.
$$
**把三个算法放进同一个数字里对比**：蒙特卡洛必须等整条轨道跑完、用经验回报 $G_t$ 更新（本例尚未知）；TD 用「一步观测 + 已有估计」当场更新，偏差低、无需完整回合；Q-learning 把式中的 $V(S_{t+1})$ 换成 $\max_{a'} Q(S_{t+1}, a')$，就从依赖策略变成最优逼近。**同一个三步骨架，只换一步，就是一个新算法——这就是 RL 算法家族能被「不动点语言」一句话串起来的原因。**<span class="marginnote">三大算法的谱系：<strong>MC = 全轨道平均（高方差低偏差），TD = 单步逼近（低方差高偏差），Q-learning = 无模型逼近最优贝尔曼方程</strong>。它们共享同一个目标——$V^\pi$ 或 $V^*$ 这个「不动点」——只是逼近的路径不同。随机过程的「不动点」语言，一句话说清整个 RL 算法家族。</span>

## 3 公式解析：Q-learning 为什么收敛

**目标：理解 Q-learning 更新式如何「逼近最优贝尔曼方程」，以及随机逼近（鞅）如何保证收敛。**

第一步，写最优贝尔曼方程（Q 形式）。$Q^*(s,a) = r(s,a) + \gamma \sum_{s'} P(s'|s,a) \max_{a'} Q^*(s',a')$。

第二步，把更新式看成「朝不动点走一步」。记 $\delta_t = R_t + \gamma\max_{a'} Q(S_{t+1}, a') - Q(S_t, A_t)$ 为 **TD 误差**，更新为 $Q \leftarrow Q + \alpha \delta$。$E[\delta_t \mid \text{历史}]$ 正是「贝尔曼方程的两边之差」——**$\delta$ 的期望为零时，$Q$ 就是 $Q^*$**。

第三步，用随机逼近收敛。$\sum \alpha = \infty$、$\sum \alpha^2 < \infty$（Robbins-Monro 条件）时，$Q$ 几乎必然收敛到 $Q^*$——**证明的数学工具是鞅收敛定理**（第六篇）：TD 误差构成鞅差序列，其累积被控制。

第四步，直觉。**Q-learning 每一步都在「让 $Q$ 更符合贝尔曼方程」**——像解方程 $Q = TQ$（$T$ 是贝尔曼算子）的迭代，只不过用样本近似期望。

**这个推导为什么重要**：它把 RL 算法的收敛性绑在鞅理论上——**TD 误差是鞅差，随机逼近用鞅收敛定理收尾**。这是第六篇《鞅》在机器学习里最直接的兑现。

**TD 与 MC 的方差-偏差光谱**：MC 用整条轨道的经验回报（高方差、无偏），TD 用单步自助（低方差、有偏——偏差来自当前估计不精确）；Q-learning 是 TD 家族的无模型一员。**「更长的回溯 = 更低偏差、更高方差」这条光谱是理解所有 RL 值估计算法的主线**——从 TD(0) 到 TD(λ) 到蒙特卡洛，参数 $\lambda$ 控制的正是「回溯多长」。

## 4 探索-利用权衡

RL 的独特困境：**要用已知的好策略（利用），又要有新信息（探索）**。策略：
**$\epsilon$-贪心**：以概率 $\epsilon$ 随机动作（探索）、否则贪心（利用）；
**UCB（上限置信界）**：选「估计值 + 不确定度」最大的动作——「乐观面对未知」；
**软最大化（softmax）**：按「$e^{Q/\tau}$」加权选动作，温度 $\tau$ 控制探索强度。

**数学本质**：探索-利用是「信息获取」与「回报兑现」的平衡——**最优策略在「遗憾最小化」意义下要主动探索**。这个权衡是多臂老虎机（MAB）的核心，也是 RL 与「后悔理论」的连接点。

**辨析｜易错点：** 初学者常误以为「$\epsilon$-贪心」与「UCB」水火不容。实际上 $\epsilon$-贪心是**固定随机度**的探索（参数少、是行业基准线），UCB 是**随不确定度衰减**的探索（更高效，但要估计方差）；还有「熵正则」一类方法把策略的熵直接写进目标函数（Soft Actor-Critic 家族）。**没有免费午餐：探索越聪明，方差越大，调参越难。** 另一个常见误区是把 $\epsilon$ 当成可学参数——它应当随训练逐步退火（anneal）到接近 0，而不是一上来就固定。

**一个可检验的直觉**：在确定性环境里 $\epsilon$-贪心的最优 $\epsilon$ 趋于 0（探索纯属浪费）；在随机回报的环境里它必须保持一个正值——**最优探索量由环境的噪声水平决定**。

**数值例：$\epsilon$ 退火。** 设 $\epsilon_0 = 1$、每步 $\epsilon \leftarrow 0.999\, \epsilon$：前 100 步几乎全探索（$\epsilon$ 从 1 降到约 0.90），第 1000 步约 0.37，第 10000 步约 0.00005——**前期广泛探索、后期专注利用**。对比固定 $\epsilon = 0.1$：始终有 10% 随机动作，样本效率低但鲁棒。**退火是「想清楚了再收敛」，固定是「永远保持好奇」**——两者没有绝对优劣，取决于环境是否稳定。<span class="marginnote">多臂老虎机与本专题：<strong>MAB 是「只有一个状态的 MDP」——每个动作的回报独立随机，目标是最小化遗憾</strong>。它的解（UCB、Thompson 采样）用 Azuma/集中不等式分析（第六篇）——探索-利用的量化是「随机过程集中不等式」的又一次亮相。</span>

## 5 RL 与随机过程的对照表

| 随机过程概念 | RL 中的角色 |
| --- | --- |
| 马尔可夫性 | 状态是充分统计量 |
| 转移矩阵 $P$ | 未知，需学习/估计 |
| 值函数 $V^\pi$ | 策略评估目标 |
| 贝尔曼方程 | TD / Q-learning 的更新目标 |
| 鞅 / 随机逼近 | 收敛性证明 |
| 遍历性 | 蒙特卡洛平均的合法性 |

**一句话**：**RL = 在未知 $P$、$r$ 下，用随机过程工具（马尔可夫、鞅、不动点）逼近贝尔曼方程的解。**「不动点」这一视角尤其值得记住：**MC、TD、Q-learning 的差别只在逼近路径，靶子都是同一个 $V^\pi$ 或 $V^*$**——这正是随机过程「不动点语言」对 RL 的统摄。<span class="marginnote">RL 与本站主线：<strong>现代大模型的对齐（RLHF）本质是 RL——用策略梯度/PPO 优化奖励模型</strong>。随机过程给 RL 提供数学骨架，RL 给大模型提供对齐引擎——「从极限到大模型」的链条在这里合拢。</span>

**辨析｜易错点：** 蒙特卡洛用「经验回报 $G_t$」要求能跑完整回合；TD 用「一步自助」不要求回合结束，但有偏差。**没有免费的精确：样本越「前瞻」（MC），方差越大；越「即时」（TD(0)），偏差越大**——TD(λ) 用参数 $\lambda$ 在两者之间滑动，正是这条光谱的工程化。

## 6 小结

- **RL = 未知模型的 MDP**：$P$、$r$ 未知，靠交互学习最优策略。
- **三大算法**：MC（全轨道平均）、TD（单步逼近）、Q-learning（无模型逼近 $Q^*$）——共享「贝尔曼不动点」目标。
- **收敛性**：TD 误差是鞅差，随机逼近 + 鞅收敛定理收尾。
- **探索-利用**：$\epsilon$-贪心、UCB、softmax——信息 vs 回报的平衡。
- 与随机过程关系：马尔可夫性、鞅、遍历、不动点——RL 的数学骨架。

**一处延伸**：RL 与随机过程的关系是双向的——**随机过程给 RL 数学骨架，RL 反过来让马尔可夫链、鞅、遍历性这些「静态」概念有了「学会最优」的动态出口**。理解了贝尔曼不动点，再看大模型对齐（RLHF 用 PPO 逼近策略不动点），就不再是新事物。
