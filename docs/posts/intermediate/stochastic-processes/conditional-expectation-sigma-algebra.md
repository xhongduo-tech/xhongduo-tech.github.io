## 为什么需要更严格的条件期望

上一节我们把条件期望定义为 $\mathbb{E}[X \mid Y = y]$，靠的是 $P(Y = y) > 0$ 时除一个正数。
可一旦 $Y$
是连续型随机变量，$P(Y = y) = 0$，公式直接失灵——「除以零」没有意义。<span class="marginnote">这是概率论里经典的「零概率事件上的条件」难题：
严格地说，连续场合下 $\{Y = y\}$ 是零概率事件，$P(X \le x \mid Y = y)$ 无法用除法定义。
柯尔莫哥洛夫（A. N. Kolmogorov）在 1933 年用测度论给出绕开它的定义，就是本节要讲的版本。</span>

不绕开的后果很严重：随机过程中到处是连续型随机变量——泊松过程的到达时刻、布朗运动的位置。条件期望要是只对离散场合成立，这门课就废了大半。
所以必须把「条件期望」从一条公式，升级成**一个由两条性质刻画的随机变量**。

## 1 σ-代数：什么是「已知的信息」

「给定 $Y = y$」之所以难办，是因为我们把条件化绑死在「某个具体取值」上。换个角度：
条件化不是针对「一个点」，而是针对「一份信息」——而信息在测度论里用 **σ-代数（σ-algebra）** 表示。

一个 σ-代数 $\mathcal{G}$ 是 $\Omega$ 的一些子集组成的族，满足三条：
对补集封闭、对可列并封闭（从而对可列交封闭）、包含全集 $\Omega$。<span class="marginnote">最小平凡的
σ-代数是 $\{\emptyset, \Omega\}$——它不含任何信息，只知道「结果总是 $\Omega$ 里的某一点」；最大的
σ-代数是整个 $\mathcal{F}$——知道一切。中间每一层 $\mathcal{G}$ 都是一份「可分辨能力」的等级。第一次接触
σ-代数是在第一级《概率》与第二级《离散数学》的集合运算里，这里是它的正式登场。</span>

为什么 σ-代数代表信息？因为**「在 $\mathcal{G}$ 下可知」的意思是：对每个
$A \in \mathcal{G}$，观察者能判断「$A$ 发生了没有」**。若 $Y$ 是随机变量，记 $\sigma(Y)$ 为「由
$Y$ 生成」的 σ-代数，即所有形如 $\{Y \in B\}$ 的事件（$B$ 为 Borel 集）生成的 σ-代数——这就是「观察
$Y$ 所能得到的全部信息」。给定 $Y$，等价于给定 $\sigma(Y)$。

## 2 严格定义：两条性质刻画一个随机变量

**定义（关于 σ-代数的条件期望）：** 设 $X$ 是可积随机变量，$\mathcal{G} \subset \mathcal{F}$
是一个 σ-代数。若随机变量 $Z$ 满足：

1. **$Z$ 是 $\mathcal{G}$-可测的**（即 $Z$ 的值完全由 $\mathcal{G}$ 决定，等价于
$\sigma(Z) \subset \mathcal{G}$）；
2. 对一切 $A \in \mathcal{G}$，有 $\int_A Z \, dP = \int_A X \, dP$；

则称 $Z$ 为 $X$ 关于 $\mathcal{G}$ 的**条件期望（conditional expectation）**，记作
$Z = \mathbb{E}[X \mid \mathcal{G}]$。

这个定义完全绕开了「除以零」——它没有除法，只有积分等式。第二条性质说的是：**只要问的是「$\mathcal{G}$ 能分辨的事件
$A$」上的平均值，$Z$ 和 $X$ 必须给出相同的结果。** $Z$ 就是把 $X$「降噪」到 $\mathcal{G}$
层面、但不改变 $\mathcal{G}$ 内任何可测集合上平均值的那个版本。

**存在性与唯一性**由 Radon–Nikodym 定理保证：这样的 $Z$
存在，且在「几乎处处相等」的意义下唯一（即两个候选者只在一个零概率集上不同）。<span class="marginnote">「几乎处处唯一」是测度论世界的常态：
我们只在乎概率为 1 的集合上发生什么，单个点上的取值无关紧要。 这条备注在后面鞅的收敛定理里会成为关键的宽容度来源。</span>

## 3 几何直觉：向「可测世界」的正交投影

为什么条件期望长这样？把它放进函数空间看。设 $L^2$ 是所有二阶矩有限的随机变量的空间，其上定义内积
$\langle U, V \rangle = \mathbb{E}[UV]$。$\mathcal{G}$-可测的随机变量构成一个子空间；
而 $\mathbb{E}[X \mid \mathcal{G}]$ 正是 $X$ 在该子空间上的**正交投影**。

正交投影的刻画是「残差垂直于子空间」：对每个 $\mathcal{G}$-可测的 $Y$ 有
$\mathbb{E}[(X - \mathbb{E}[X \mid \mathcal{G}]) Y] = 0$。取
$Y = \mathbf{1}_A$（$A \in \mathcal{G}$），就还原成定义里的积分等式。<span class="marginnote">投影视角解释了一切：
为什么条件期望是最优猜测？因为投影就是「在信息 $\mathcal{G}$ 的限制下离 $X$ 最近的
$\mathcal{G}$-可测函数」——这与统计里「条件期望 = 最小均方误差预测」完全一致，也顺带预告了第六篇鞅的几何画像：
鞅是「在越来越大的信息里保持投影稳定」的对象。</span>

## 4 公式解析：定义式 $\int_A \mathbb{E}[X \mid \mathcal{G}] \, dP = \int_A X \, dP$

把这条核心等式拆开看：

- **第一步，看对象**：左边被积函数 $Z = \mathbb{E}[X \mid \mathcal{G}]$ 是我们要找的「降噪版
$X$」，右边的 $X$ 是原始、可能携带大量信息的 $X$。$A$ 是 $\mathcal{G}$ 里任意一个事件。
- **第二步，看等式含义**：$\int_A Z \, dP$ 是「$Z$ 在 $A$ 上的概率加权和」，即 $A$ 上的平均值乘以 $P(A)$。
等式要求它与 $X$ 在 $A$ 上的概率加权和相等。换句话说：**在 $\mathcal{G}$ 能分辨的每一个块 $A$ 上，$Z$
与 $X$ 的总量持平。**
- **第三步，看为什么是「所有 $A \in \mathcal{G}$」**：正是这些等式，逼着 $Z$ 在每一个
$\mathcal{G}$-可分辨的粒度上复刻 $X$ 的平均行为。块分得越细（$\mathcal{G}$ 越大），$Z$ 就越接近
$X$； $\mathcal{G} = \mathcal{F}$ 时
$Z = X$，$\mathcal{G} = \{\emptyset, \Omega\}$ 时
$Z = \mathbb{E}[X]$（一个常数）。 这两端验证了定义的自洽性。

## 5 三块试金石

- **$\mathcal{G} = \{\emptyset, \Omega\}$（不知道任何信息）**：
$\mathbb{E}[X \mid \mathcal{G}] = \mathbb{E}[X]$，退化为普通期望。
- **$\mathcal{G} = \sigma(Y)$（只观察 $Y$）**：$\mathbb{E}[X \mid \sigma(Y)]$
习惯记为 $\mathbb{E}[X \mid Y]$，它是一个 $Y$ 的函数——上一节那个「随机变量」的严格版本；
离散场合下它与逐点定义完全一致。
- **$\mathcal{G} = \mathcal{F}$（知道一切）**：
$\mathbb{E}[X \mid \mathcal{F}] = X$，因为 $X$ 本身已经 $\mathcal{F}$-可测。

三块试金石说明：
**条件期望不是一条固定公式，而是一台「按信息粒度降噪」的机器**——信息越细，输出越接近原变量。<span class="marginnote">这条「信息越细越接近原变量」的单调性，正是下一节塔性质（$H \subset G \Rightarrow \mathbb{E}[\mathbb{E}[X \mid G] \mid H] = \mathbb{E}[X \mid H]$）的直觉底座，也是后续理解鞅的「信息流」的关键。</span>

### 一个把定义落到算术上的例子

一个有限例子能让抽象定义落地。设 $\Omega = \{1, 2, 3, 4, 5, 6\}$，$P$
为均匀分布，$X(\omega) = \omega$。取 $\mathcal{G}$ 为划分
$\{\{1,2\}, \{3,4,5\}, \{6\}\}$ 生成的 σ-代数——它只告诉你 $\omega$ 落在哪个块里。则
$\mathbb{E}[X \mid \mathcal{G}]$ 在每个块上取块内平均值：在 $\{1,2\}$ 上为 $1.5$，在
$\{3,4,5\}$ 上为 $4$，在 $\{6\}$ 上为 $6$。用定义第二条验证：取 $A = \{1,2\}$，左边
$\int_A \mathbb{E}[X \mid \mathcal{G}] \, dP = 1.5 \times \frac{2}{6} = 0.5$，右边
$\int_A X \, dP = \frac{1 + 2}{6} = 0.5$，两边相等；其余块同理。
这个例子把「按信息粒度取平均」从测度论定义还原成了人人能算的算术——条件期望就是把 $X$ 在每个「可分辨的块」上磨平成块的均值。

## 6 辨析：严格定义带来的三个易错点

**辨析｜易错点：** 第一，「条件期望」必须指明**关于哪个 σ-代数**，否则无意义——$\mathbb{E}[X \mid Y]$
是 $\sigma(Y)$ 的缩写，不能把它当成「对 $Y$ 求期望」；
第二，定义只保证**几乎处处**唯一，两个只在一个零概率集上不同的版本都合法，别为某个点上的取值较劲；第三，$Z$ 的
$\mathcal{G}$-可测性（第一条）是硬条件——只看积分等式而不检查可测性，会得到一堆「假条件期望」。<span class="marginnote">「可测性」为什么重要：
它保证 $Z$ 本身只携带 $\mathcal{G}$ 内的信息，不偷看 $\mathcal{G}$ 之外的事。
这条在随机过程里对应「不偷看未来」——鞅的可选停时定理就靠它把关。</span>

## 7 小结

- 连续场合下 $P(Y = y) = 0$，逐点条件期望定义失效，必须用测度论重写。
- σ-代数 $\mathcal{G}$ 编码「已知信息」；$\sigma(Y)$ 是观察 $Y$ 得到的全部信息。
- **定义**：$\mathbb{E}[X \mid \mathcal{G}]$ 是满足「$\mathcal{G}$-可测 + 对所有
$A \in \mathcal{G}$ 积分等式」的随机变量；存在性由 Radon–Nikodym 定理保证，唯一性是「几乎处处」意义下的。
- **几何直觉**：它是 $X$ 在 $\mathcal{G}$-可测函数子空间上的正交投影，即给定信息下的最小二乘最优预测。
- 三个端点：
$\mathbb{E}[X \mid \{\emptyset,\Omega\}] = \mathbb{E}[X]$，$\mathbb{E}[X \mid \sigma(Y)] = \mathbb{E}[X \mid Y]$，$\mathbb{E}[X \mid \mathcal{F}] = X$。

在下一节，我们拿这套严格定义推导它最重要的运算性质——**塔性质、取己知量、独立性**。
这三条性质组装起来，就是鞅的定义，也是随机过程理论的发动机。
