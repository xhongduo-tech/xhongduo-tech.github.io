## 生与灭的拉锯

纯生过程只有增加，但真实系统几乎都是「有进有出」：队列里顾客来了又走、种群里有出生也有死亡、库存有补货也有消耗。**生灭过程（birth-death process）**把「生」与「灭」都装进来，是 CTMC 里最常用的一类——它只允许状态相邻移动（$i \to i+1$ 或 $i \to i-1$），速率分别记为 $\lambda_i$（出生）与 $\mu_i$（死亡）。

生灭过程的地位怎么强调都不过分：**M/M/1 排队模型（下一节）就是生灭过程的直接应用**，而它的平稳分布可以用一条极简的递推——细致平衡——一路算到底。<span class="marginnote">为什么「只允许相邻移动」还如此强大？因为大量系统天然如此：<strong>队列长度、机器台数、种群规模，一次变化通常只改变 1</strong>。而「单步可逆」的结构让平稳分布的计算从「解 $|S|$ 元方程组」降为「逐边递推」。</span>

本节目标：定义生灭过程、用细致平衡递推平稳分布、给出存在性判据。

## 1 定义

**生灭过程（birth-death process）**：状态 $\{0, 1, 2, \dots\}$ 上的 CTMC，转移速率
$$
q_{i, i+1} = \lambda_i \quad (i \ge 0), \qquad q_{i, i-1} = \mu_i \quad (i \ge 1),
$$
其余非对角为 0。$\lambda_i$ 是**出生速率**，$\mu_i$ 是**死亡速率**；$\mu_0 = 0$（状态 0 无法死亡）。离开速率 $q_i = \lambda_i + \mu_i$。

**例（M/M/1 队列）**：顾客按 $\lambda$ 到达、服务速率 $\mu$：$\lambda_i \equiv \lambda$，$\mu_i \equiv \mu$——出生/死亡速率都与人数无关。

**例（线性生灭）**：$\lambda_i = i\lambda$，$\mu_i = i\mu$（每人独立生/死）——连续时间的**出生-死亡分支过程**（Yule 过程加上死亡）。

**嵌入链**：从状态 $i$，跳 $i+1$ 的概率 $\lambda_i/(\lambda_i + \mu_i)$，跳 $i-1$ 的概率 $\mu_i/(\lambda_i+\mu_i)$——一维加权随机游走。

## 2 平稳分布：细致平衡递推

生灭链的转移图是**一条线**：$0 \leftrightarrow 1 \leftrightarrow 2 \leftrightarrow \cdots$。一维单步结构保证链**可逆**——它的平稳分布满足**细致平衡**（《可逆链》一节）：
$$
\pi_i\, \lambda_i = \pi_{i+1}\, \mu_{i+1}, \qquad i = 0, 1, 2, \dots
$$
**从 $i$ 流向 $i+1$ 的速率 = 从 $i+1$ 流向 $i$ 的速率。** 由此得到**逐边递推**：
$$
\pi_{i+1} = \pi_i\, \frac{\lambda_i}{\mu_{i+1}} \;\Longrightarrow\; \pi_i = \pi_0 \prod_{j=0}^{i-1} \frac{\lambda_j}{\mu_{j+1}}.
$$
归一化 $\sum_i \pi_i = 1$ 定出 $\pi_0$。**求平稳分布 = 连乘速率比 + 归一化**——这就是生灭过程的名场面。<span class="marginnote">「一维单步 ⟹ 可逆」是全场最省心的速断：<strong>只要转移只在相邻状态间发生，平稳分布就满足细致平衡，可以逐边推出</strong>。这在排队论里被用到飞起——每个 $M/M/s$ 队列的平稳分布都是这样一条连乘。</span>

## 3 存在性判据

$\pi_0$ 由归一化决定，而 $\sum_i \pi_i = 1$ 有解当且仅当「连乘和」收敛：
$$
\sum_{i=0}^\infty \prod_{j=0}^{i-1} \frac{\lambda_j}{\mu_{j+1}} < \infty.
$$
**收敛 ⟺ 平稳分布存在 ⟺ 链正常返。** 若不收敛，链是暂留或零常返，没有（可归一化的）平稳分布。<span class="marginnote">直觉判据：<strong>出生长期压过死亡（$\lambda_i$ 相对太大）就「爆」</strong>。最典型的例子是 $M/M/1$：$\lambda < \mu$ 时有平稳分布，$\lambda \ge \mu$ 时没有（队列无限膨胀）。「服务能力必须大于到达率」这句运维常识，正是这条级数收敛条件的化身。</span>

**例（$M/M/1$）**：$\lambda_i = \lambda$，$\mu_i = \mu$。连乘 $\prod_{j=0}^{i-1} \frac{\lambda}{\mu} = (\lambda/\mu)^i$。记 $\rho = \lambda/\mu$（**流量强度**），平稳分布
$$
\pi_i = (1 - \rho)\, \rho^i, \qquad \rho < 1.
$$
这是**几何分布**。平均队长 $L = \sum i\pi_i = \frac{\rho}{1-\rho}$。

## 4 公式解析：从细致平衡递推 M/M/1 平稳分布

**目标：把「$\pi_i \lambda_i = \pi_{i+1}\mu_{i+1}$」递推到 $M/M/1$ 的几何分布 $\pi_i = (1-\rho)\rho^i$。**

第一步，写细致平衡。$M/M/1$ 中 $\lambda_i = \lambda$，$\mu_{i+1} = \mu$：
$$
\pi_i\, \lambda = \pi_{i+1}\, \mu \;\Longrightarrow\; \pi_{i+1} = \pi_i\, \frac{\lambda}{\mu} = \pi_i\, \rho.
$$
第二步，逐层推出。$\pi_1 = \pi_0 \rho$，$\pi_2 = \pi_1 \rho = \pi_0 \rho^2$，归纳得 $\pi_i = \pi_0 \rho^i$。

第三步，归一化。$\sum_{i\ge0} \pi_i = \pi_0 \sum_{i\ge0} \rho^i = \pi_0 \frac{1}{1-\rho} = 1$（几何级数，需 $\rho < 1$）。于是 $\pi_0 = 1 - \rho$。

第四步，检查直觉。$\rho \to 0$（几乎没人来）时 $\pi_0 \to 1$（系统基本空闲）；$\rho \to 1$（满负荷）时 $\pi_0 \to 0$（系统几乎总有人）。**$\rho$ 既是负载参数，也是分布的形状参数。**

**这个推导为什么重要**：它演示了生灭链的完整套路——**细致平衡 + 几何级数 + 收敛条件**。这个套路将原封不动地用于下一节的 $M/M/s$、$M/M/\infty$，以及第十篇的排队网络。

## 5 一般生灭过程的应用

- **种群生态**：$\lambda_i = i\lambda$、$\mu_i = i\mu$ 的线性生灭，平稳分布是负二项——种群在出生死亡拉锯下的稳态规模。
- **机器维修**：$k$ 台机器、$r$ 个修理工的模型是有限生灭过程（$\lambda_i = (k-i)\lambda$，$\mu_i$ 由修理工数决定）。
- **化学反应**：单分子反应 $A \rightleftharpoons B$ 是两态生灭；生化网络的随机模拟（Gillespie）本质上就在跑生灭过程的推广。

**辨析｜易错点：** 生灭过程的平稳分布**唯一**且**可逆**，但要注意「正常返」与「$\sum \pi_i = 1$ 收敛」是同一件事。做题时先算连乘积，再看收敛——**别默认 $\pi_0$ 可以归一化**，$\rho \ge 1$ 时根本没有平稳分布。

## 6 小结

- **生灭过程**：相邻单步转移，速率 $\lambda_i$（出生）、$\mu_i$（死亡），$\mu_0 = 0$。
- **细致平衡** $\pi_i \lambda_i = \pi_{i+1} \mu_{i+1}$ ⟹ $\pi_i = \pi_0 \prod_{j<i} \lambda_j/\mu_{j+1}$。
- **存在性**：连乘和收敛 ⟺ 正常返 ⟺ 有平稳分布。
- $M/M/1$：$\pi_i = (1-\rho)\rho^i$（几何分布），需 $\rho = \lambda/\mu < 1$。
- 应用：排队、种群、机器维修、生化反应。

**辨析｜易错点：** 生灭链的 CTMC 平稳分布 $\pi$ 与嵌入链平稳分布 $\tilde\pi$ 不同：前者按「时间占比」加权（每个状态乘上平均停留 $1/(\lambda_i+\mu_i)$），后者只算「访问频率」。求 CTMC 稳态务必用细致平衡 $\pi_i\lambda_i = \pi_{i+1}\mu_{i+1}$，而不是把嵌入链的 $\tilde\pi$ 直接当 $\pi$。

在下一节，我们把生灭过程用于排队论的第一个战场：**排队论初步：M/M/1 排队模型**——从到达、服务到队长与等待时间的完整分析。
