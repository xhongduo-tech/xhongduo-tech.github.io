## 「何时停止都不亏」的数学化

鞅的期望守恒说 $E[X_n] = E[X_0]$——**固定时刻** $n$ 的期望不变。但赌徒关心的不是「第 100 局后的期望」，而是「**在我离场的那一刻**的期望」。如果停时允许「看到趋势再走」，岂不是能挑好时刻离场、稳赚不赔？

**可选停时定理（Optional Stopping Theorem, OST）**回答：**只要停时是「诚实的」（不偷看未来），且满足某些正则条件，则**
$$
E\big[ X_\tau \big] = E\big[ X_0 \big].
$$
**停在任何合法时刻，期望都不变——「何时停止」无法改变公平性。** 这是「没有必胜赌博策略」的严格证明，也是 Wald 等式、赌徒破产、金融定价的核心工具。<span class="marginnote">「可选」（optional）这个名字来自法语 *arrêt facultatif\*——指「可以选着停」。定理说的是：<strong>选择权（在公平游戏里）换不来任何期望优势</strong>。这是随机过程对「不可战胜」这一直觉最深刻的数学表述。</span>

本节目标：陈述 OST 的适用条件、给出条件为什么必要的反例、并看到它的第一个应用（Wald 等式）。

## 1 定理陈述

**可选停时定理**：设 $X_n$ 是鞅（或上鞅），$\tau$ 是停时。若以下**任一**条件成立，则 $E[X_\tau] = E[X_0]$（鞅）或 $E[X_\tau] \le E[X_0]$（上鞅）：

1. **$\tau$ 有界**：存在 $K$ 使 $\tau \le K$ 几乎必然；
2. **$X$ 有界增量 + $\tau$ 期望有限**：存在常数 $c$ 使 $|X_{n+1} - X_n| \le c$，且 $E[\tau] < \infty$；
3. **一致可积**：$\{X_{\min(\tau,n)}\}$ 一致可积（最常见于「$X_\tau$ 有界」的情形）。

**三个条件是「够用即可」的充分条件**——任取其一即可用 OST，不必同时满足。<span class="marginnote">记忆：<strong>「停时越早」或「过程越规整」或「终点越收敛」，OST 越稳</strong>。条件 1（有界停时）最常用也最好记；条件 2 处理「会一直走下去」的首达类停时；条件 3 是最一般的（用一致可积性控制尾部）。</span>

## 2 为什么必须有条件：反例

如果什么都不要求，OST **不成立**。经典反例：

**例（对称随机游走 + 首达）**：$S_n$ 对称随机游走（鞅），$\tau = \min\{n : S_n = 1\}$（第一次到 1 就走）。直觉上「赢 1 块就走」——可 $E[S_\tau] = 1$，而 $E[S_0] = 0$，**OST 失败**！

问题出在哪？$\tau$ **期望无穷**（对称随机游走首次到 1 的平均时间是无穷），不满足任何条件。**一个「合法但不守规矩」的停时，确实能赢**——因为你要等无穷久（平均），现实中「等无穷久」不可行。<span class="marginnote">这个反例非常深刻：<strong>数学上没有必胜策略，但如果你愿意等无穷久，公平游戏也能「看起来赢」</strong>——因为「无穷久」在现实中不是选项。条件 $E[\tau] < \infty$ 正是把「等无穷久」这个后门堵死。</span>

**另一个反例（有界增量但 $\tau$ 期望无穷）**：同样的 $\tau$，$E[\tau] = \infty$ 违反条件 2，OST 不可用。**条件 2 的「$E[\tau] < \infty$」是专门对付「首达类」停时的。**

## 3 公式解析：证明有界停时的 OST

**目标：证明条件 1（$\tau \le K$）下 $E[X_\tau] = E[X_0]$。**

第一步，把 $X_\tau$ 写成分段。$\tau \le K$，故 $X_\tau = \sum_{n=0}^K X_n\, \mathbb{1}[\tau = n]$（在 $\tau$ 发生的时刻取值）。取期望：
$$
E[X_\tau] = \sum_{n=0}^K E\big[ X_n\, \mathbb{1}[\tau = n] \big].
$$
第二步，把 $X_n$ 与「是否在 $n$ 停」解耦。$\{\tau = n\}$ 只依赖前 $n$ 步（停时性质），而 $E[X_{n+1} - X_n \mid \text{前 } n \text{ 步}] = 0$（鞅性）——**需要把 $X_n \mathbb{1}[\tau=n]$ 换成 $X_{n+1}\mathbb{1}[\tau=n]$ 不改变期望**。

更直接地，用**停止过程** $X^{\min(\tau, n)}$：它仍是鞅（截断停时保持鞅性），且 $X^{\min(\tau,K)} = X_\tau$（因为 $\tau \le K$）。于是
$$
E[X_\tau] = E\big[ X_{\min(\tau, K)} \big] = E\big[ X_{\min(\tau, 0)} \big] = E[X_0].
$$
第三步，中间那个等号来自「$X_{\min(\tau,n)}$ 是鞅」——每步期望守恒。**截断把随机停时变成确定时刻 $K$，确定时刻的期望守恒是已知的。**

**这个推导为什么重要**：它演示了 OST 的标准证明套路——**把随机停时截成有界停时，再用「停止过程是鞅」逐层传递期望守恒**。条件 2、3 的证明只是把「截断后取极限」这一步做得更精细。

## 4 推论：Wald 等式

**Wald 等式（从 OST 推出）**：设 $X_i$ 独立同分布，$E[X_1] = \mu$，$\tau$ 是停时，$E[\tau] < \infty$，则
$$
E\Big[ \sum_{i=1}^\tau X_i \Big] = \mu\, E[\tau].
$$

证明：令 $S_n = \sum_{i=1}^n (X_i - \mu)$，它是鞅（零均值步长和）。由 OST（条件 2）：
$$
E[S_\tau] = E[S_0] = 0 \;\Longrightarrow\; E\Big[\sum_{i=1}^\tau X_i - \mu\tau\Big] = 0,
$$
即 $E[\sum_{i=1}^\tau X_i] = \mu E[\tau]$。<span class="marginnote">我们在《初等更新定理》一节就用过 Wald 等式——现在它的出处清楚了：<strong>Wald 等式是 OST 对「零均值步长和」的直接应用</strong>。当时只敢「用」不敢「证」，现在补上了证明的最后一环。</span>

## 5 应用清单

**赌徒破产**（下一节）：从 $i$ 出发、$0$ 或 $N$ 吸收，用 OST 同时给出破产概率与期望持续时间。
**更新理论**：Wald 等式是初等更新定理证明的捷径（第三篇已用）。
**金融**：风险中性测度下资产折现价是鞅，OST 保证「套利不可能」——期权定价的核心（第十篇）。
**算法**：随机算法「何时停止」的期望复杂度分析，常用 OST 或 Wald 等式收口。<span class="marginnote">OST 的哲学地位：<strong>它是「信息优势无济于事」的数学证明</strong>——在公平环境里，无论你多聪明地选择停止时机（只要不偷看未来），期望收益都是零。这是「有效市场假说」和「不可能稳赢」的数学内核。</span>

## 6 小结

- **可选停时定理**：$E[X_\tau] = E[X_0]$（鞅）——合法停时不改变期望。
- **三个条件**：有界停时 / 有界增量 + 有限期望停时 / 一致可积——任一即可。
- **反例**：对称随机游走首次到 1（$\tau$ 期望无穷）破坏 OST——「等无穷久」是唯一后门。
- **证明套路**：截断停时 → 停止过程是鞅 → 期望逐层守恒。
- **推论**：Wald 等式 $E[\sum_{i=1}^\tau X_i] = \mu E[\tau]$——OST 的直接应用。

在下一节，我们把 OST 用到最经典的赌博场景：**停时定理的应用：赌徒破产问题**——一个从鞅视角几乎「白送」的答案。
