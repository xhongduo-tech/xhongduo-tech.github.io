## 当随机算法遇上鞅

随机算法（随机化快排、随机抽样、Las Vegas 算法）的「随机性」来自哪里？来自算法内部的一连串随机选择。而鞅理论恰好是分析「一串逐步揭露的信息」的工具——**把算法的随机性组织成一个鞅差序列，就可以用 Azuma / McDiarmid 给出高概率界**。

这一节把鞅方法用到算法分析：三件武器——**Doob 鞅**（从函数构造鞅）、**有界差不等式 / McDiarmid**（Azuma 的函数版）、**Wald 等式 / OST**（期望运行时间）。它们是「随机算法分析」这门手艺的三板斧。<span class="marginnote">为什么鞅适合算法分析：<strong>算法的输出是输入的复杂函数，而 Doob 鞅把「逐步揭露输入」变成一列条件期望，其增量恰是鞅差</strong>。于是「输出对输入的敏感性」翻译成「鞅差的有界性」，Azuma 自动给集中界——这是「有界差方法」的全部秘密。</span>

本节目标：掌握 Doob 鞅与 McDiarmid 不等式、并用它们分析随机化快排与抛球问题。

## 1 Doob 鞅：从任意函数造鞅

**Doob 鞅（Doob martingale）**：设 $X$ 是任意随机变量（如算法输出），$Y_1, \dots, Y_n$ 是逐步揭露的信息（如输入前 $i$ 项）。定义
$$
M_i = E\big[ X \mid Y_1, \dots, Y_i \big], \qquad M_0 = E[X].
$$
则由塔性质，$M_i$ 是鞅：$E[M_{i+1} \mid Y_1, \dots, Y_i] = E[E[X \mid Y_{1..i+1}] \mid Y_{1..i}] = E[X \mid Y_{1..i}] = M_i$。

**含义**：$M_i$ 是「基于前 $i$ 项信息对最终输出 $X$ 的最佳预测」。鞅差 $D_i = M_i - M_{i-1}$ 是「第 $i$ 项信息带来的预测改进」。**若每项信息对 $X$ 的影响有限（有界差），Azuma 就给出「$X$ 对 $E[X]$ 的高概率接近」。**<span class="marginnote">Doob 鞅的美：<strong>不需要知道 $X$ 的分布，只要信息逐步揭露且单步影响有界</strong>。它是「从函数造鞅」的通用工厂——随机算法、组合优化、统计估计的分析都从这一步开始。</span>

## 2 有界差不等式（McDiarmid）

**McDiarmid 不等式**：设 $X = f(Y_1, \dots, Y_n)$，且对任意 $i$ 与任意输入，改变 $Y_i$ 至多改变 $f$ 的值 $c_i$（「第 $i$ 个坐标对 $f$ 的敏感性 ≤ $c_i$」），$Y_i$ 相互独立。则
$$
P\big( |X - E[X]| \ge a \big) \le 2\exp\!\Big( -\frac{2a^2}{\sum_i c_i^2} \Big).
$$
**输出偏离期望的概率，由「各坐标敏感性平方和」控制。** 它是 Azuma 在「独立坐标 + 有界差」下的直接推论（用 Doob 鞅 + 条件期望剥皮）。

**应用流程**：① 找输出函数 $f$；② 估计每个坐标的敏感性 $c_i$；③ 套不等式得高概率界。<span class="marginnote">McDiarmid 是「有界差方法」的招牌：<strong>一个复杂算法的输出，只要「换一个随机选择影响不大」，输出就集中在期望附近</strong>。它把「证明集中」简化为「算敏感性」——后者通常是简单的上界估计。</span>

## 3 应用：随机化快排的比较次数

**随机化快排**：枢纽随机选取，$C_n$ = $n$ 个元素排序的比较次数。已知 $E[C_n] = 2n\ln n + O(n)$（第四篇分支过程的生成函数法可证）。现在用 McDiarmid 给出集中性。

**构造 Doob 鞅**：$Y_i$ = 第 $i$ 次随机枢纽的选择。$M_i = E[C_n \mid Y_1, \dots, Y_i]$。改变一个枢纽选择，至多影响它参与的比较（约 $n$ 次量级）——**敏感性 $c_i = O(n)$**。<span class="marginnote">更精细的分析用「每个元素对」而不是「每次枢纽」做坐标：元素对 $(a,b)$ 是否被比较只由「$a,b$ 中谁先被选为枢纽」决定，敏感性 $c_i = 1$（一个元素对只影响 1 次比较）。<strong>选对坐标，敏感性就能压到 $O(1)$</strong>——这是有界差方法的「建模艺术」。</span>

**结论**：用「元素对」坐标（$c_i = 1$，共 $\binom n2$ 个坐标），McDiarmid 给出
$$
P\big( |C_n - E[C_n]| \ge a \big) \le 2 \exp\!\Big( -\frac{2a^2}{\binom n2} \Big).
$$
取 $a = n^{3/2}\sqrt{\ln n}$ 量级，概率高概率成立——**比较次数以高概率为 $2n\ln n + O(n^{3/2}\sqrt{\ln n})$**。随机化快排不仅是「期望快」，而是「几乎总是快」。

## 4 公式解析：抛球问题的集中界

**问题**：把 $n$ 个球独立随机抛进 $n$ 个箱子，$X$ = 空箱数。求 $X$ 的高概率界。

第一步，算期望。每个箱子为空的概率 $(1-1/n)^n \approx e^{-1}$，故 $E[X] = n e^{-1} + O(1)$。

第二步，找敏感性。把 $X = f(Y_1, \dots, Y_n)$ 写成「每个球 $Y_i$ 抛到哪」的函数。改变一个球的位置：它可能离开或进入某个箱子，至多改变空箱数 2——**$c_i = 2$ 对所有 $i$**。

第三步，套 McDiarmid：
$$
P\big( |X - E[X]| \ge a \big) \le 2 \exp\!\Big( -\frac{2a^2}{\sum_{i=1}^n 4} \Big) = 2e^{-a^2/(2n)}.
$$
第四步，结论。取 $a = \sqrt{2n\ln n}$，得 $P(|X - E[X]| \ge a) \le 2/n$——**空箱数以高概率落在 $n/e \pm O(\sqrt{n\ln n})$ 内**。

**这个推导为什么重要**：它演示了 McDiarmid 的完整打法——**输出函数、敏感性上界、代入不等式**。抛球问题的敏感性只有「常数」，所以集中界几乎免费；这正是有界差方法在随机算法分析里如此受欢迎的原因。

## 5 期望运行时间：Wald / OST

随机算法的**期望运行时间**常用停时工具：

**Las Vegas 算法**：算法在随机尝试 $X_1, X_2, \dots$ 后成功（每次尝试成功概率 $p$）。运行时间 $T$ = 成功前的尝试次数，$E[T] = 1/p$。更一般地，若每次尝试成本 $c$，总成本 $= cT$，由 Wald 等式
$$
E[\text{总成本}] = c\, E[T] = \frac{c}{p}.
$$
**随机化的成本 = 单次成本 ÷ 成功概率。**<span class="marginnote">这个「$c/p$」公式统治着随机算法的期望复杂度：<strong>从随机化快速排序到随机 MCMC 收敛，期望运行时间几乎都是「单步成本 ÷ 成功概率」</strong>。Wald 等式把「随机次数」的期望变成「几何步数」的期望，一步到位。</span>

**例**：随机化找中位数（快选算法），每次随机枢纽「好枢纽」概率 $p \ge 1/2$（把问题缩小到常数比例），期望划分次数 $O(\log n)$，每次划分 $O(n)$，总期望 $O(n)$——比最坏 $O(n^2)$ 快得多，且几乎总是 $O(n)$（McDiarmid 再控波动）。

## 6 小结

- **Doob 鞅** $M_i = E[X \mid Y_1, \dots, Y_i]$：从任意函数逐步揭露信息造鞅。
- **McDiarmid 不等式**：$P(|f - E[f]| \ge a) \le 2e^{-2a^2/\sum c_i^2}$——敏感性决定集中度。
- **随机化快排**：元素对坐标 $c_i = 1$，比较次数以高概率 $= 2n\ln n + o(n\ln n)$。
- **抛球问题**：敏感性常数，空箱数以高概率集中 $n/e \pm O(\sqrt{n\ln n})$。
- **期望运行时间**：$E[\text{成本}] = c/p$（Wald / 几何）——随机化成本的通用公式。

到这里，第六篇《鞅》全部结束。从下一篇起，我们进入连续时间的「优雅殿堂」——**布朗运动**：从花粉的随机舞蹈到现代金融的数学根基。
