## 为什么分支过程是一族「自带爆点」的链

马尔可夫链的状态通常固定（天气、位置、队列人数）。但有一类现象状态空间本身在「膨胀」或「收缩」：一个细胞分裂成两个，两个成四个……；一个病毒传染几个人，这些人再传染……；一个姓氏一代代传下去，有的家族开枝散叶，有的断香火。**分支过程（branching process）**就是为「每个个体独立地产生随机数量的后代」设计的模型。

它的学名是**高尔顿-沃森过程（Galton-Watson process）**，诞生于 19 世纪对英国贵族姓氏灭绝的统计研究。它本质是一条马尔可夫链（$X_n$ = 第 $n$ 代个体数），但它的理论核心不是转移矩阵，而是**生成函数**。最深刻的问题是：**家族最终灭绝的概率是多少？** 答案是后代分布生成函数的最小不动点——一条漂亮得几乎像神谕的结论。<span class="marginnote">分支过程的独特地位：<strong>它把「生成函数」升格为第一公民</strong>——其他链靠矩阵，它靠生成函数的迭代与不动点。这个「函数迭代」视角还通向现代随机图、流行病学与粒子物理的级联模型。</span>

本节目标：定义分支过程、推导均值与方差的迭代公式、并彻底搞清「灭绝概率 = 生成函数最小不动点」。

## 1 定义

**分支过程（Galton-Watson process）**：设 $X_0 = 1$（初始一个个体）。每个个体独立地产生 $Z$ 个后代，其中 $Z$ 取非负整数值、分布为 $\{p_k\}_{k\ge0}$（**后代分布**）。第 $n$ 代个体数
$$
X_n = \sum_{i=1}^{X_{n-1}} Z_{n-1,i},
$$
其中 $Z_{n-1,i}$ 是第 $n-1$ 代第 $i$ 个个体的后代数，全部独立同分布 $Z$。$X_n = 0$ 时过程**灭绝**（$X_{n+1} = 0$ 恒成立）。<span class="marginnote">记号要点：<strong>$Z$（后代分布）与 $X_n$（第 $n$ 代总数）是两个不同的量</strong>。$Z$ 是「一个个体生几个」，$X_n$ 是「一代有多少人」。它们通过「随机和」连接：$X_n$ 是 $X_{n-1}$ 个独立 $Z$ 之和。</span>

**马尔可夫性**：$X_{n+1}$ 只依赖 $X_n$（第 $n$ 代的人数与后代分布），不依赖更早历史——是马尔可夫链。但状态空间无穷、转移概率有特殊结构（$\sum$ 个独立同分布之和）。

## 2 生成函数与矩

**后代分布的生成函数（probability generating function）**：
$$
\phi(s) = E\big[ s^{Z} \big] = \sum_{k=0}^\infty p_k s^k, \qquad 0 \le s \le 1.
$$
**第 $n$ 代总数 $X_n$ 的生成函数**满足迭代：
$$
\phi_n(s) = E[s^{X_n}] = \phi\big(\phi_{n-1}(s)\big) = \phi^{\circ n}(s),
$$
即 $\phi_n$ 是 $\phi$ 的 $n$ 次复合。**证明：$X_n$ 是 $X_{n-1}$ 个独立 $Z$ 之和，随机和的生成函数是 $\phi$ 的 $X_{n-1}$ 次幂，再对 $X_{n-1}$ 求期望得 $\phi_{n-1}(\phi(s))$。**

**均值**：对 $\phi_n = \phi^{\circ n}$ 在 $s=1$ 求导，链式法则给出
$$
E[X_n] = \mu^n, \qquad \mu = E[Z].
$$
**每代平均扩大 $\mu$ 倍：$\mu < 1$ 收缩，$\mu = 1$ 持平，$\mu > 1$ 膨胀。**<span class="marginnote">这个「乘法因子」直觉统治一切：<strong>$\mu$ 是分支过程的『人口倍增率』</strong>。但注意：均值膨胀 ≠ 不灭绝——$\mu > 1$ 时仍可能灭绝（下面就是）。「平均」和「概率」在这里分道扬镳，正是分支过程最反直觉的地方。</span>

**方差**（二阶矩，$Z$ 方差 $\sigma^2$）：
$$
\mathrm{Var}(X_n) = \begin{cases} \sigma^2 \mu^{n-1} \frac{\mu^n - 1}{\mu - 1}, & \mu \ne 1, \\ n \sigma^2, & \mu = 1. \end{cases}
$$

**数值体验（均值 vs 概率的分歧）。** 设 $P(Z=0) = 0.3$、$P(Z=1) = 0.4$、$P(Z=3) = 0.3$。则 $\mu = 1.3 > 1$，$E[X_n] = 1.3^n$ 每代膨胀 30%；但 $\phi(s) = 0.3 + 0.4s + 0.3s^3$，解 $\pi = \phi(\pi)$ 得 $\pi \approx 0.62$——**平均每人生 1.3 个后代，仍有约 62% 的家族最终灭绝**。均值膨胀只说明「幸存者」长得快，绝口不提「绝后」是否发生。这是分支过程给流行病学最硬的提醒：$R_0 > 1$ 时的爆发趋势与局部灭绝可以并存。

**辨析｜易错点：** 生成函数 $\phi(s)$ 的定义域是 $0 \le s \le 1$，迭代 $\phi^{\circ n}$ 必须在 $[0,1]$ 内进行——不能把 $s$ 取到 1 之外。**求导算矩在 $s = 1$ 处、求灭绝概率在 $s = \pi$ 处，两者是同一个函数的不同「读法」。**

## 3 灭绝概率：最小不动点

设 $\pi$ 为**灭绝概率**——从 $X_0 = 1$ 出发，过程最终灭绝的概率 $P(X_n = 0 \text{ 对某个 } n)$。

**关键定理**：$\pi$ 是方程
$$
\pi = \phi(\pi)
$$
的**最小非负解**，即 $\pi = \lim_{n\to\infty} \phi^{\circ n}(0)$。

**直觉（迭代观）**：$\phi^{\circ n}(0) = P(X_n = 0)$（第 $n$ 代灭绝的概率）。第 $n$ 代灭绝 ⇔ 前 $n$ 代灭绝，故 $P(X_n = 0)$ 单调递增收敛到「最终灭绝概率」$\pi$。而每一步复合都把当前概率映到下一个，极限满足 $\pi = \phi(\pi)$。

**分类定理**：
$$
\pi = 1 \iff \mu \le 1, \qquad \pi < 1 \iff \mu > 1.
$$
**平均后代 ≤ 1：几乎必然灭绝；平均后代 > 1：有正概率不灭绝**（但灭绝仍可能发生）。

**例（后代 0 或 2）**：$P(Z = 0) = 1-p$，$P(Z = 2) = p$。$\phi(s) = 1 - p + p s^2$。$\mu = 2p$。
- $p \le 1/2$：$\mu \le 1$，$\pi = 1$。
- $p > 1/2$：解 $\pi = 1 - p + p\pi^2$，即 $p\pi^2 - \pi + 1 - p = 0$，得 $\pi = \frac{1-p}{p}$（另一根 1 非最小解）。**$p = 2/3$ 时 $\pi = 1/2$——平均生 4/3 个后代的家族，仍有 1/2 概率绝后。**

## 4 公式解析：灭绝概率是最小不动点

**目标：证明 $\pi$ 是 $\phi(\pi) = \pi$ 的最小非负解，并解释「为什么取最小」。**

第一步，建立递推。设 $\pi_n = P(X_n = 0)$。第 $n$ 代灭绝当且仅当「第一个体没有后代（概率 $p_0$）」或「第一个体有 $k$ 个后代（概率 $p_k$）且这 $k$ 个后代的家族都在第 $n-1$ 代前灭绝（概率 $\pi_{n-1}^k$）」：
$$
\pi_n = \sum_{k\ge0} p_k\, \pi_{n-1}^{k} = \phi(\pi_{n-1}), \qquad \pi_0 = 0.
$$
第二步，取极限。$\pi_n$ 单调递增（第 $n$ 代灭绝蕴含第 $n+1$ 代灭绝），故 $\pi = \lim \pi_n$ 存在，且由 $\phi$ 连续：
$$
\pi = \lim \phi(\pi_{n-1}) = \phi(\pi).
$$
第三步，为什么是最小解。若 $\eta$ 是任何非负不动点（$\eta = \phi(\eta)$），由 $\pi_0 = 0 \le \eta$ 且 $\phi$ 单调递增，归纳得 $\pi_n \le \eta$，故 $\pi \le \eta$。**$\pi$ 不大于任何不动点——它是最小不动点。**

第四步，几何直觉。$0 \le \phi(s) \le 1$，$\phi(1) = 1$。$\pi$ 是「从 0 出发、沿 $\phi$ 迭代」的收敛点：$\phi$ 的图像从 $(0, p_0)$ 出发，若它在 $s=1$ 处斜率 $\le 1$（$\mu \le 1$）则只碰对角线于 1；若斜率 $> 1$（$\mu > 1$）则先在 1 之下穿过对角线，那个交点就是 $\pi$。

**这个推导为什么重要**：它示范了「不动点迭代」这一通用工具——**任何「每代独立复制」的递归结构，其极限都是生成函数的不动点**。从种群灭绝到传染病最终规模，这个框架到处可用。

## 5 分支过程的应用

- **流行病学**：一个感染者传染 $R_0$ 人（基本再生数）。$R_0 \le 1$：疫情必然自行消退；$R_0 > 1$：有正概率爆发。**灭绝概率分析是「群体免疫阈值」的随机版本。**
- **种群生物学**：判断物种在随机生育下是存续还是灭绝；临界值 $\mu = 1$ 是生态学里的「最小存活种群」思想的雏形。
- **算法分析**：随机递归结构（随机二叉搜索树、快速排序比较次数）的规模演化常用分支过程近似。<span class="marginnote">还有一个迷人的历史注脚：<strong>高尔顿-沃森过程最初就是为「英国贵族姓氏是否会消失」设计的</strong>——数据显示多数姓氏确实在代数迭代中消亡，这正是 $\mu$ 略小于或等于 1 的数学写照。「祖先人数众多却仍逃不过灭绝」是分支过程最早的公众时刻。</span>

**数值例：$R_0$ 与灭绝概率。** 设每个感染者传染人数 $Z$ 服从 $P(Z = 0) = 0.2$、$P(Z = 2) = 0.8$，则 $R_0 = 1.6 > 1$，但解 $\pi = 0.2 + 0.8\pi^2$ 得 $\pi = 0.25$——**基本再生数大于 1，仍有 25% 的疫情从单个病例起就自然消退**。这正是「群体免疫」必须远超 1 的原因：$R_0$ 略大于 1 时，随机波动就能掐灭许多局部爆发。

## 6 小结

- **分支过程** $X_n$：每个个体独立产生 $Z$ 个后代，$X_n$ 是 $X_{n-1}$ 个独立 $Z$ 之和。
- 生成函数复合：$\phi_n = \phi^{\circ n}$；均值 $E[X_n] = \mu^n$，方差有闭式。
- **灭绝概率** = $\phi(\pi) = \pi$ 的最小非负解；$\mu \le 1$ 必灭绝，$\mu > 1$ 有正生存概率。
- 迭代观：$\pi_n = \phi(\pi_{n-1})$，$\pi = \lim \phi^{\circ n}(0)$。
- 应用：流行病 $R_0$ 分析、种群存续、随机递归算法。

**连接与延伸**：分支过程在连续时间里的对应物是纯生过程（第五篇）——每个个体以速率 $\lambda$ 分裂，$\lambda_i = i\lambda$ 正是「每人独立繁殖」的连续版本；而 Yule 过程的转移概率是负二项，与离散分支过程的生成函数迭代同源。**离散与连续、代数与生成函数，分支过程是串联它们的一个枢纽。**
