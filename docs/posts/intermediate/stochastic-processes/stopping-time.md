## 一个「能选但不偷看」的时刻

鞅研究「公平赌博」，而赌博总要「离场」。什么时候离场？**停时（stopping time）**就是离场时刻的数学化：一个随机时刻 $\tau$，它可以是随机的（比如「第一次赢到 100 块就走」），但它有一个铁律——**决定「是否在 $n$ 时刻停止」时，只能用 $n$ 时刻之前（含 $n$）的信息，不能偷看未来。**

这个「不能偷看」的条件，是停时与「普通随机变量」的区别。它保证了在停止时刻，我们仍然处于「只知道过去」的境地——于是鞅的公平性、期望守恒在停止后依然成立。**停时是「何时停止」与「公平性」之间的桥梁。**<span class="marginnote">停时的词源与生活直觉一致：<strong>「看到结果再停」不算停时——那叫事后诸葛亮</strong>。比如「在我最后一次赢的时候离场」不是停时，因为你得先知道「以后还会不会赢」才能确定「最后一次」；而「在我第一次赢到 100 块时离场」是停时。</span>

本节目标：严格定义停时、识别典型例子与非例子、掌握停时的运算性质。

停时在整条学习主线上的位置也值得点明：它是「鞅」能被用于赌徒破产、算法随机化、序贯分析的关键齿轮——没有「不能偷看未来」的约束，一切停时定理都是空谈。先把停时的语感建立起来，下一节的可选停时定理才有落脚的支点。

## 1 定义

**停时（stopping time）**：随机变量 $\tau$（取值 $\{0, 1, 2, \dots\} \cup \{\infty\}$）称为关于 $\{X_n\}$ 的**停时**，若对任意 $n$，
$$
\{ \tau = n \} \in \sigma(X_0, X_1, \dots, X_n),
$$
即事件「$\tau = n$」只依赖 $X_0, \dots, X_n$，**不依赖未来**。等价地，$\{\tau \le n\}$ 只依赖 $X_0, \dots, X_n$。

**直观**：把信息流想成「逐步揭露的谜底」，$\tau$ 是「喊停的时刻」——喊停的瞬间，你手里只有已揭露的信息。<span class="marginnote">等价的 $\{\tau \le n\}$ 形式更常用：<strong>「在 $n$ 时刻之前已停」这个事件，只能用前 $n$ 步的信息判断</strong>。两种写法等价，做证明时哪个顺眼用哪个。</span>

为什么用「$\tau = n$」或「$\tau \le n$」都行？因为「在 $n$ 停」与「在 $n$ 之前已停」可以互相推出：知道前者能推出后者，反之亦然（对每个 $n$）。**选哪一版取决于手头的事件结构**——证明首达时用 $\{\tau \le n\}$ 更顺手，处理停时运算时用 $\{\tau = n\}$ 更直观。

## 2 典型例子与非例子

**是停时的例子**：

- **常数**：$\tau \equiv k$——固定时刻离场，当然合法。
- **首达时刻**：$\tau = \min\{n : X_n \ge a\}$——「第一次达到目标就走」。$\{\tau \le n\} = \{\text{前 } n \text{ 步内到过 } a\}$，只看过去。
- **首达与末达的组合**：$\min(\tau_1, \tau_2)$、$\max(\tau_1, \tau_2)$（两个停时的 min/max 仍是停时）。

例如「当股票首次涨破 100 或跌破 50 时清仓」——两个首达停时的 min，仍是停时；「等三只基金都首次盈利后卖出」——max 三个停时，仍是停时。**min/max 的封闭性让「复合策略」也能用停时语言描述**。

**不是停时的例子**：

- **末次离场**：$\tau = \max\{n : X_n \ge a\}$——「最后一次到目标」。要知道「最后一次」，必须看完全程（包括未来），**不是停时**。
- **首次打破记录之后的下一局**：依赖「破纪录」这个事件发生后的信息也合法，但「等到纪录不再被打破」不行。

**辨析｜易错点：** 「随机时刻」≠「停时」。停时的核心是**信息限制**——时刻可以随机，但「此刻是否停止」的判定只能基于过去。**检查方法：写 $\{\tau \le n\}$，看它的判定是否用到 $X_{n+1}, X_{n+2}, \dots$。**

**一个判别练习**：设 $\tau = \min\{n : X_n \ge 100\ \text{或}\ X_n \le -50\}$（首次达到任一阈值），这是停时——$\{\tau \le n\}$ = 「前 $n$ 步内到过 $\ge 100$ 或 $\le -50$」，只看过去。而「赢到 100 之后马上离场」看似只用了 $X_n$，若定义成「在 $X_n \ge 100$ 的时刻且要等下一局确认」就会出岔——**判定只用「已经发生」的，不用「即将发生」的，是停时的底线**。

## 3 停时运算与停时 σ-代数

**性质（停时的运算）**：

1. 常数、$\min(\tau_1,\tau_2)$、$\max(\tau_1,\tau_2)$、$\tau_1 + \tau_2$ 都是停时；
2. 若 $\tau$ 是停时，则**截断停时** $\min(\tau, n)$（到 $n$ 为止）也是停时——这在证明里常用来「把无穷停时截成有限」。

这些运算的直觉都很自然：两个合法离场规则里「取先到者」或「取后到者」都不偷看未来；「到 $n$ 为止」的截断更是把无穷停时变成有限——**证明里几乎总是先截断、后取极限**。$\tau_1 + \tau_2$ 合法则稍微绕一点：先走完 $\tau_1$ 的判定过程，再重新计数走 $\tau_2$，全程只用过去。

**停时 σ-代数（$\mathcal{F}_\tau$）**：停止时刻 $\tau$ 前可观测的全部信息
$$
\mathcal{F}_\tau = \{\, A : A \cap \{\tau \le n\} \in \mathcal{F}_n \;\forall n \,\}.
$$
**$X_\tau$（停止时刻的过程值）关于 $\mathcal{F}_\tau$ 可测**——停止时的值只用停止前信息确定。这个「停时信息」概念是下一节可选停时定理的语言。<span class="marginnote">$\mathcal{F}_\tau$ 的直观：<strong>「在 $\tau$ 时刻你知道的一切」</strong>。比如「第一次赢到 100 块时」，你不仅知道当前赌本，还知道「这是第一次赢到」——这些都在 $\mathcal{F}_\tau$ 里。</span>

一个容易混淆的点：$\mathcal{F}_\tau$ 不是「某个固定的 $\mathcal{F}_n$」，而是一个随 $\tau$ 变化的 σ-代数——不同路径在不同时刻停止，得到的「停止前信息」也不一样。**它把「路径相关的信息量」统一封装成一个对象**，这正是停时理论能处理「每局策略不同」的原因。

## 4 公式解析：为什么首达时刻是停时

**目标：验证「$\tau = \min\{n : X_n \ge a\}$」满足停时定义，并看清「首达」结构正是停时的模板。**

第一步，改写 $\{\tau \le n\}$。$\tau \le n$ 的意思是「在前 $n$ 步内已经到过目标 $a$」：
$$
\{\tau \le n\} = \bigcup_{k=0}^n \{X_k \ge a\}.
$$
第二步，检查可测性。每个 $\{X_k \ge a\}$ 只依赖 $X_k$（$\subseteq \sigma(X_0,\dots,X_n)$，因 $k \le n$），有限并仍在 $\sigma(X_0, \dots, X_n)$ 里。

第三步，结论。$\{\tau \le n\} \in \sigma(X_0, \dots, X_n)$——停时定义满足。

第四步，对照非停时。末次离场 $\sigma = \max\{n : X_n \ge a\}$ 的 $\{\sigma \le n\}$ 需要「$n$ 之后永不再到 $a$」——依赖 $X_{n+1}, X_{n+2}, \dots$，**不在** $\sigma(X_0,\dots,X_n)$ 里，不是停时。

**这个推导为什么重要**：它把「首达」与「末达」的差别精确到可测性层面——**「第一次」只需看过去（并集到 $n$），「最后一次」要看未来（补集到无穷）**。这条「首达是停时、末达不是」的对照，是做停时题目的万能试金石。

这里补一个细节：$\{\tau \le n\} = \bigcup_{k=0}^n\{X_k \ge a\}$ 之所以是有限并，是因为「前 $n$ 步内到过」是有限个事件的并——**有限并仍可测，可数并也可测，但「永不」这类补集到无穷的判定要用上未来**。可测性语言把「看过去 vs 看未来」翻译得干干净净。

## 5 停时在应用中的角色

- **赌徒策略**：一切「看当前赌本决定是否离场」的策略都是停时——这保证了「离场时刻的期望」仍可用鞅的公平性。
- **算法随机化**：「当误差小于 $\epsilon$ 时停止迭代」是停时——Azuma 不等式（第九节）对随机停止时刻的偏差估计依赖停时性质。
- **序贯分析**：序贯检验中「样本数达到临界值时停止」是停时——序贯概率比检验的数学基础。<span class="marginnote">停时概念是「自适应策略」的形式化：<strong>任何「边走边看、按当前信息做决定」的停止规则都是停时</strong>。这正是在线算法、强化学习里「策略」的数学结构——第十篇 MDP 的「策略」本质就是停时的推广。</span>

把「赌徒策略」落到具体数字：设赌本 $X_n$，策略「当 $X_n \le 0$ 或 $X_n \ge 100$ 时离场」，则 $\tau = \min\{n : X_n \le 0 \text{ 或 } X_n \ge 100\}$ 是停时（首次触及边界）。赌徒破产问题（下一篇）正是要算 $P(X_\tau = 100)$——**停时把「何时离场」这个策略问题，变成「在边界处的取值」这个可计算问题**。

## 6 停时术语速查

| 术语 | 记号 | 含义 | 判别要诀 |
| --- | --- | --- | --- |
| 停时 | $\tau$ | 随机时刻，不偷看未来 | $\{\tau\le n\}$ 只用前 $n$ 步 |
| 首达时刻 | $\min\{n: X_n \ge a\}$ | 第一次到目标 | 并集到 $n$，是停时 |
| 末次离场 | $\max\{n: X_n \ge a\}$ | 最后一次到目标 | 需看未来，不是停时 |
| 截断停时 | $\min(\tau, n)$ | 到 $n$ 为止 | 把无穷停时截成有限 |
| 停时 σ-代数 | $\mathcal{F}_\tau$ | 停止前全部信息 | $X_\tau$ 关于它可测 |
| 自适应策略 | 边走边看、按当前信息决定 | 停时的推广 | 在线算法、强化学习 |

## 7 小结

- **停时**：$\{\tau \le n\}$ 只依赖 $X_0, \dots, X_n$——能选但不偷看未来。
- **典型例子**：常数、首达时刻、停时的 min/max；**非例子**：末次离场。
- 运算性质：min/max/和/截断都保持停时性。
- **停时 σ-代数 $\mathcal{F}_\tau$**：停止前全部信息；$X_\tau$ 关于它可测。
- 判定口诀：写 $\{\tau \le n\}$，看是否用到未来——用到了就不是。
- **与后续的接口**：停时 σ-代数是可选停时定理的语言；「策略 = 停时」是算法与强化学习的数学结构。

在下一节，我们迎来鞅理论的心脏：**可选停时定理（Optional Stopping Theorem）**——什么时候「公平游戏在任何停时停止后仍公平」。
