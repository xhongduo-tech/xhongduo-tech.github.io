# 伊藤积分的性质：等距性与鞅性

<div class="epigraph">
<p>一个积分既是等距（范数不变）又是鞅（期望守恒）——它同时是度量与公平的化身。</p>
<footer>—— 伊藤清（Kiyosi Itô）</footer>
</div>

<div class="article-byline">

## 构造完之后的「工具箱」

上一节构造了 Itô 积分。这一节把它当成一件**工具**来打磨——整理它的核心性质，这些性质是后面 Itô 公式与随机微分方程（SDE）的一切计算基础。两个主角我们已经见过：**等距性**（范数）与**鞅性**（公平）。这里把它们系统化，并补充第三个关键性质——**二次变差**。

这三个性质形成一套「随机积分微积分」的原子操作：
$$
\int f\,dB \;\text{期望} = 0, \qquad \text{方差} = E[\int f^2 dt], \qquad \text{二次变差} = \int f^2 dt.
$$
**二阶矩、方差、二次变差三位一体——都指向同一个量 $\int f^2 dt$。**<span class="marginnote">三性质合一的画面：<strong>Itô 积分把「对时间的平方」当成它的「能量」</strong>——期望为 0（公平）、方差等于能量、二次变差也等于能量。这个「能量」概念在随机分析里反复出现，也是第八篇 SDE 求解的核心工具。</span>

本节目标：整理等距性、鞅性、二次变差三大性质，并给出计算示范。

## 1 期望与方差

**期望**：由鞅性（或直接由左端点定义），
$$
E\Big[ \int_0^t f\, dB \Big] = 0.
$$
**Itô 积分的期望恒为 0**——这是「公平游戏」的最强声明：无论被积函数多复杂，积分在期望上不偏不倚。

**方差**：由等距性，
$$
\mathrm{Var}\Big( \int_0^t f\, dB \Big) = E\Big[ \int_0^t f^2\, dt \Big].
$$
**方差 = 被积函数平方的期望积分**。若 $f$ 是确定性函数，方差 $= \int_0^t f(s)^2 ds$——这是最常用的一条：**确定性权重的 Itô 积分方差就是权重的 $L^2$ 平方**。<span class="marginnote">对比普通积分：$\int f \, dt$ 的方差是「$f$ 的波动方差」；而 $\int f\,dB$ 的方差是「$f^2$ 的积分」。<strong>随机积分自带「平方化」效应——它把权重平方后按时间累计</strong>，这来自 $(dB)^2 = dt$ 的本质。</span>

## 2 鞅性与条件期望

**鞅性**：$M(t) = \int_0^t f\, dB$ 关于 $\{\mathcal{F}_t\}$ 是鞅：
$$
E\big[ M(t+s) \mid \mathcal{F}_t \big] = M(t), \qquad s \ge 0.
$$
**推论（鞅的停止）**：对停时 $\tau$，$M(\min(\tau, t))$ 仍鞅，$E[M_\tau] = E[M_0] = 0$（合适条件下）——**可选停时定理对 Itô 积分适用**。

**条件方差（用于计算）**：
$$
E\Big[ \Big(\int_0^T f\,dB\Big)^2 \mid \mathcal{F}_t \Big] = E\Big[ \int_t^T f^2\, ds \mid \mathcal{F}_t \Big].
$$
**给定现在的信息，未来积分的条件方差 = 未来权重的条件平方积分**——这是「分段计算」的利器。

## 3 二次变差

Itô 积分的**二次变差**：
$$
\Big[ \int_0^\cdot f\,dB \Big]_t = \int_0^t f^2\, ds.
$$
**积分的二次变差 = 被积函数平方的积分**。这是 Itô 公式（下一节）的燃料：$dM^2$ 的「$dt$ 部分」由 $f^2$ 贡献。

**启发**：对简单过程，$M$ 的二次变差 $\sum (\Delta M_k)^2 = \sum f_k^2 (\Delta B_k)^2 \to \sum f_k^2 \Delta t_k = \int f^2 dt$——**$(dB)^2 = dt$ 原样搬进 $f^2$**。<span class="marginnote">「二次变差 $= \int f^2 dt$」统一了前面所有线索：<strong>布朗运动 $f = 1$ 时二次变差 $= t$；Itô 积分把权重 $f$ 平方后放大这个变差</strong>。这就是随机积分的「能量守恒」——波动能量精确等于权重平方的能量。</span>

## 4 公式解析：计算 ∫₀ᵗ B dB 的均值与方差

**目标：用三大性质计算 $X(t) = \int_0^t B\, dB$ 的期望与方差——不用碰路径，纯靠性质。**

第一步，期望。$X(t)$ 是 Itô 积分（$f = B$ 适应、可积），鞅性给 $E[X(t)] = 0$。

第二步，方差。等距性：
$$
\mathrm{Var}(X(t)) = E\Big[\int_0^t B(s)^2\, ds\Big] = \int_0^t E[B(s)^2]\, ds = \int_0^t s\, ds = \frac{t^2}{2}.
$$
（$E[B(s)^2] = s$，交换积分与期望由 Fubini 保证。）

第三步，对照。$\frac{t^2}{2}$ 也可以从 Itô 公式得到：$B(t)^2 = 2\int_0^t B\,dB + t$，故 $X(t) = \frac{B(t)^2 - t}{2}$，其方差
$$
\mathrm{Var}\Big(\frac{B(t)^2 - t}{2}\Big) = \frac14 \mathrm{Var}(B(t)^2) = \frac14 (2t^2) = \frac{t^2}{2}.
$$
两条路殊途同归。

第四步，**看公式的威力**：我们甚至没展开任何一条路径，只用了「期望 0 + 等距」就拿到了精确方差。**性质驱动的计算，是随机积分的标准打法。**

**这个推导为什么重要**：它示范了「用性质而非路径」的计算范式——**期望靠鞅性、方差靠等距、二次变差靠定义**。后面解 SDE（几何布朗运动、OU 过程）时，这套范式是唯一可行的工具，因为路径根本无法显式写出。

## 5 计算清单：Itô 积分速查

| 要算的量 | 工具 | 公式 |
| --- | --- | --- |
| $E[\int f\,dB]$ | 鞅性 | $0$ |
| $\mathrm{Var}(\int f\,dB)$ | 等距性 | $E[\int f^2 dt]$ |
| 条件方差 | 等距 + 条件 | $E[\int_t^T f^2 ds \mid \mathcal{F}_t]$ |
| 二次变差 | 定义 | $\int f^2 dt$ |
| 停时期望 | OST | $E[\int_0^\tau f\,dB] = 0$ |

**五个公式覆盖随机积分计算的 90% 场景。**<span class="marginnote">这五条对应着随机分析的所有「免费午餐」：<strong>期望归零、方差平方化、停时免费</strong>。做题时先问「我要算的是期望、方差还是二次变差」，再挑工具——比硬解路径快一个数量级。</span>

## 6 小结

- **期望** $E[\int f\,dB] = 0$——鞅性的直接后果，公平的最强声明。
- **方差** $\mathrm{Var} = E[\int f^2 dt]$——Itô 等距，权重平方按时间累计。
- **二次变差** $[\int f\,dB]_t = \int f^2 dt$——$(dB)^2 = dt$ 的权重版本。
- **鞅性 + 可选停时**：停时期望免费归零。
- 计算范式：**期望靠鞅、方差靠等距、变差靠定义**——性质驱动，不碰路径。

**例（确定性权重）**：$f(t) = t$，则 $\int_0^t s\,dB(s)$ 的方差 $= \int_0^t s^2 ds = t^3/3$——纯靠等距得到，无需任何路径展开。「确定性权重的 Itô 积分方差 = 权重平方的普通积分」是公式库里最常用的一条，在模拟与定价里天天见：它把随机积分的波动直接换算成确定性的时间积分。

在下一节，我们迎来随机微积分的核心定理：**伊藤公式（Itô's Lemma）：单变量形式**——带 $(dB)^2 = dt$ 的泰勒展开。
