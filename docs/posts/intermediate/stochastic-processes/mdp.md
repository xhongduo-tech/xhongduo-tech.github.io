## 当马尔可夫链学会「选择」

前面研究的马尔可夫链，状态转移由概率矩阵**被动**决定。但如果系统在每个状态都能**选择动作**，而转移概率与回报都依赖这个动作——这就是**马尔可夫决策过程（Markov Decision Process, MDP）**。它是强化学习的数学心脏，也是「随机过程 × 最优控制」的汇合。

MDP 给马尔可夫链加了三样东西：**动作集**（每个状态能选什么）、**转移依赖动作**（$P(s' \mid s, a)$）、**回报**（$r(s, a)$）。目标从「分析链」变成「设计策略」——**在每一步选动作，使长期总回报最大化**。求解的钥匙是**贝尔曼方程（Bellman equation）**——它就是「首步分解」在决策问题里的化身。<span class="marginnote">MDP 与马尔可夫链的血缘：<strong>固定一个策略 $\pi$ 后，MDP 退化成一条普通马尔可夫链</strong>——转移矩阵 $P^\pi(s'|s) = \sum_a \pi(a|s)P(s'|s,a)$。所以马尔可夫链的全部工具（平稳分布、常返、极限）在「策略已定」时照常可用。MDP 的新东西是「选策略」。</span>

本节目标：定义 MDP、写出贝尔曼方程、并掌握价值迭代与策略迭代两个求解算法。

## 1 MDP 的定义

**马尔可夫决策过程（MDP）**：四元组 $(S, A, P, r)$：

- **状态空间 $S$**：系统的所有可能状态；
- **动作空间 $A$**：每个状态可选的行动；
- **转移概率** $P(s' \mid s, a)$：在状态 $s$ 选动作 $a$ 后转移到 $s'$ 的概率；
- **回报函数** $r(s, a)$（或 $r(s, a, s')$）：在 $s$ 选 $a$ 后获得的即时回报。

**策略（policy）** $\pi(a \mid s)$：每个状态下选各动作的概率。**目标**：找最优策略 $\pi^*$ 使**折现总回报**最大化：
$$
E_\pi\Big[ \sum_{t=0}^\infty \gamma^t r(S_t, A_t) \Big],
$$
其中 $\gamma \in [0, 1)$ 是**折扣因子**（未来回报打折，保证无穷和收敛）。<span class="marginnote">折扣因子的角色：<strong>$\gamma$ 权衡「现在」与「未来」——$\gamma$ 接近 1 看重长期，接近 0 只关心眼前</strong>。它也让无穷和收敛（几何级数），数学上不可或缺。工程里 $\gamma = 0.9 \sim 0.99$ 常见。</span>

## 2 值函数与贝尔曼方程

**状态值函数（value function）**：
$$
V^\pi(s) = E_\pi\Big[ \sum_{t=0}^\infty \gamma^t r(S_t, A_t) \mid S_0 = s \Big],
$$
从状态 $s$ 出发、按策略 $\pi$ 行动的期望折现总回报。

**贝尔曼方程（Bellman equation）**：
$$
V^\pi(s) = \sum_a \pi(a \mid s) \Big[ r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^\pi(s') \Big].
$$
**读法**：从 $s$ 出发的长期价值 = 「现在回报 + 未来折现价值的期望」——正是首步分解的决策版。<span class="marginnote">贝尔曼方程与「首步分解」的关系：<strong>更新方程的 $m(t) = F(t) + \int m(t-x)dF(x)$、马尔可夫链的 $h_i = \sum p_{ik}h_k$、贝尔曼方程的 $V = r + \gamma P V$——三者是同一个「先走一步、再递归」思想的三个化身</strong>。学会一个，另两个白送。</span>

**最优值函数与最优贝尔曼方程**：
$$
V^*(s) = \max_a \Big[ r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^*(s') \Big].
$$
**最优策略：在每个状态选「使当前回报 + 未来最优值最大」的动作**——贪心于最优值函数。

## 3 公式解析：贝尔曼方程的推导

**目标：从定义推出贝尔曼方程，理解「$\gamma$ 从哪来、期望怎么拆」。**

第一步，展开定义。$V^\pi(s) = E_\pi\big[ r(S_0, A_0) + \gamma r(S_1, A_1) + \gamma^2 r(S_2, A_2) + \cdots \mid S_0 = s \big]$。

第二步，拆第一步。先选动作（按 $\pi$），得即时回报，然后进入 $S_1 = s'$：
$$
V^\pi(s) = \sum_a \pi(a|s) r(s,a) + \gamma \sum_a \pi(a|s) \sum_{s'} P(s'|s,a) E_\pi\big[ \sum_{t=0}^\infty \gamma^t r(S_{t+1}, A_{t+1}) \mid S_1 = s' \big].
$$
第三步，认出后项是 $V^\pi(s')$。马尔可夫性保证「从 $S_1 = s'$ 起的未来」只依赖 $s'$：
$$
V^\pi(s) = \sum_a \pi(a|s)\Big[ r(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s') \Big].
$$
第四步，最优版本取 $\max$。**$V^*$ 满足「现在动作取最优」的方程。**

**这个推导为什么重要**：它把「无穷期期望」化成了「一期递推」——**贝尔曼方程把动态规划变成解不动点方程**。这个「动态规划 → 不动点」的转化，是 MDP 理论一切算法的数学基础。

## 4 求解算法

**策略评估（policy evaluation）**：固定 $\pi$，迭代 $V_{k+1}(s) = \sum_a \pi(a|s)[r + \gamma\sum_{s'}P V_k(s')]$——**收敛到 $V^\pi$**（压缩映射，收敛率 $\gamma$）。

**价值迭代（value iteration）**：$V_{k+1}(s) = \max_a [r + \gamma\sum P V_k(s')]$——**迭代最优贝尔曼方程，收敛到 $V^*$**。

**策略迭代（policy iteration）**：① 评估当前策略；② 改进：$\pi'(s) = \arg\max_a [r + \gamma\sum P V^\pi(s')]$；③ 重复到策略稳定。**有限 MDP 的策略迭代在有限步内收敛**。<span class="marginnote">价值迭代 vs 策略迭代：<strong>价值迭代快但每步近似，策略迭代慢但精确收敛</strong>。工程折中：先价值迭代若干步、再策略改进。这两个算法是强化学习的「古典地基」——现代 DQN 只是用神经网络近似 $V^*$ 或 $Q^*$。</span>

## 5 例子：网格世界

**网格世界**：$S$ = 网格格点，$A$ = 上下左右，$P$ = 按意图移动（有噪声），$r$ = 到达目标 +1、掉坑 -1、其他 0。目标：找从任意格点到目标的最优路径。

用价值迭代：从 $V = 0$ 出发，反复应用最优贝尔曼方程，$V$ 逐轮「传播」——**价值像水波一样从目标向外扩散**，收敛后每个格点的 $V$ 指示「距离目标的折现价值」，贪心即可得最优策略。<span class="marginnote">网格世界是 MDP 的「hello world」：<strong>它演示了「价值传播」的全部直觉——最优值函数就是「从每个状态到目标的期望折现回报」，策略就是「朝值大的方向走」</strong>。学会它，强化学习的直觉就立住了。</span>

## 6 小结

- **MDP**：$(S, A, P, r)$ + 策略 $\pi$；目标 = 折现总回报最大化。
- **值函数** $V^\pi$：期望折现回报；**贝尔曼方程** $V^\pi = r + \gamma P V^\pi$——首步分解的决策版。
- **最优方程**：$V^* = \max_a[r + \gamma PV^*]$；最优策略 = 贪心于 $V^*$。
- **算法**：策略评估、价值迭代、策略迭代——都是「压缩映射不动点」。
- 与马尔可夫链关系：固定策略 ⟹ 普通链；MDP 的新东西是「选策略」。
