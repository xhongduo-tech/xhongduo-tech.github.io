## 为什么从制备与表征讲起

前几节我们知道了「活性位长什么样、怎么失活」，但还有一个更早的问题：**活性位是怎么造出来的？** 催化剂不是从货架上买来的通用品，而是按配方「炼制」的——制备方法决定了分散度、晶粒尺寸、孔结构与金属-载体相互作用，而这些又决定了前面讨论的一切性能。**表征（characterization）**则是制备的「验收质检」：不测比表面、不数晶粒、不探酸位，就无法知道制备是否成功。本节讲两种最主流的制备路线——**浸渍**与**沉淀/共沉淀**，再给出表征工具箱，最后用一个公式（Scherrer 方程）把「XRD 谱线宽」翻译成「晶粒尺寸」。<span class="marginnote">连接第17篇与第18篇：金属催化剂多用浸渍，氧化物/复合氧化物多用共沉淀，沸石用离子交换——「什么催化剂配什么制备法」是催化工业的经验地图。</span>

## 1 浸渍法：把金属「灌」进孔道

**浸渍（impregnation）**是最常用、最简单的负载方法，流程四步：

1. **配制浸渍液**：把金属前驱体盐（如 $\ce{H2PtCl6}$、$\ce{Ni(NO3)2}$）溶于水，浓度由目标负载量决定。
2. **浸渍**：把载体（$\ce{Al2O3}$、$\ce{SiO2}$、炭）浸泡在溶液中，让前驱体溶液「灌」进孔道。
**初湿浸渍（incipient wetness）**：溶液量恰好等于载体的孔体积，一滴不多、一滴不少——负载量最精确可控。
**过量浸渍**：溶液过量，靠吸附/干燥控制分布，配合竞争吸附剂可调「蛋壳」或「均匀」分布。
3. **干燥 + 焙烧（calcination）**：蒸发溶剂，前驱体分解为氧化物（如 $\ce{H2PtCl6 -> PtO_x}$），并固定在载体上。
4. **还原活化**：通 $\ce{H2}$ 把氧化物还原为金属纳米颗粒，活性位诞生。

**浸渍的核心优势**：负载量可精确设计、贵金属利用率高、可精确控制金属分布（均匀/蛋壳/蛋清）。**劣势**：颗粒尺寸受焙烧/还原条件控制，分散度易受金属-载体相互作用影响。<span class="marginnote">辨析｜易错点：焙烧不是「把水烤干」那么简单——它同时完成前驱体分解、脱除模板/杂质、建立金属-载体相互作用三件事。焙烧温度、气氛、升温速率都在「塑造」最终颗粒：温度过高颗粒长大（烧结），过低前驱体分解不完全。</span>

## 2 沉淀与共沉淀：从溶液里「长」出催化剂

**沉淀法（precipitation）**：把金属盐溶液与沉淀剂（碱、碳酸盐）混合，控制 pH、温度与陈化时间，使金属氢氧化物/碳酸盐**沉淀析出**，再洗涤、干燥、焙烧成氧化物。

**共沉淀（co-precipitation）**：把**两种以上**金属盐同时沉淀，得到组成均匀的混合氧化物——这是制备复合氧化物催化剂（如 $\ce{Cu/ZnO/Al2O3}$ 甲醇合成催化剂）的主力方法。

共沉淀的精髓在**均匀性**：两种金属离子必须在同一时刻、同一比例地进入沉淀，才能得到分子级混合的前驱体；若一种先沉淀完，产物就分相了。<span class="marginnote">控制均匀性的关键是<strong>过饱和度</strong>：让沉淀瞬间发生在整个溶液，而非局部——快速混合、强力搅拌、控制加碱速率都是为这一点服务。工业上连续沉淀反应器（CSTR）配合 pH 反馈，正是为了「均匀」二字。</span>

**沉淀法 vs 浸渍法**：沉淀法得到的是「催化剂本体」（不是负载在现成载体上），可做纯氧化物或混合氧化物，比表面与孔结构可通过 pH、老化调节；浸渍法做的是「载体上的金属」，贵金属更省。**低负载贵金属用浸渍，高负载复合氧化物用共沉淀**，是选型的拇指规则。

## 3 表征工具箱：给催化剂「体检」

制备之后必须验收，表征手段按「测什么」分类：

| 表征手段 | 测什么 | 回答的问题 |
| --- | --- | --- |
| $\ce{N2}$ 物理吸附（BET） | 比表面、孔容、孔径分布 | 表面积够不够大？孔道通不通？ |
| 化学吸附（$\ce{CO}$/$\ce{H2}$） | 金属分散度、活性位密度 | 贵金属有多少原子在表面？ |
| XRD | 物相、晶粒尺寸（Scherrer） | 是什么晶相？晶粒多大？ |
| TPR/TPO | 还原/氧化温度 | 金属氧化物好不好还原？ |
| NH₃-TPD / 吡啶 IR | 酸位密度与类型（B/L） | 酸性够不够、是质子酸还是 Lewis 酸？ |
| TEM/SEM + EDX | 颗粒形貌、尺寸、组成分布 | 纳米颗粒长什么样？元素分布均不均匀？ |
| XPS | 表面组成、元素价态 | 表面是什么价态？载体与金属怎么相互作用？ |

**一套完整的催化剂评价，是「活性测试 + 表征」的双轨**：活性测试回答「好不好用」，表征回答「为什么」。没有表征的活性数据是黑箱，没有活性测试的表征是陈列。<span class="marginnote">近年兴起<strong>操作态表征（operando）</strong>：在真实反应条件下同时测活性与光谱——把「催化剂在工作时的真实状态」抓拍下来，避免「休息时体检、工作时出问题」的错位。</span>

## 4 公式解析：Scherrer 方程

XRD 谱线的宽度与晶粒尺寸相关：晶粒越小，衍射峰越宽。**Scherrer 方程**把这种展宽翻译成晶粒尺寸：

$$
D_{hkl} = \frac{K\,\lambda}{\beta\,\cos\theta}
$$

- **第一步，认符号**：$D_{hkl}$ 是垂直于 $(hkl)$ 晶面的晶粒尺寸（nm）；$\lambda$ 是 X 射线波长（$\ce{Cu\ K\alpha}$ 约 0.154 nm）；$\theta$ 是衍射角；$\beta$ 是**峰的半高宽（FWHM，弧度）**扣除仪器展宽后的净展宽；$K$ 是形状因子（球形晶粒取约 0.9）。
- **第二步，看反比关系**：$D \propto 1/\beta$——**峰越宽，晶粒越小**。一个 20 nm 的铂晶粒给出尖锐的窄峰，一个 2 nm 的晶粒给出弥散的宽峰（甚至宽到近乎消失）。
- **第三步，识别适用范围**：Scherrer 只适用于晶粒 `<100 nm` 左右且无微观应变的粉末样品；晶粒太大时展宽小于仪器展宽，方程失效。
- **第四步，连到催化**：XRD 测出的 $D_{hkl}$ 与化学吸附测出的分散度互相印证（第17篇 $D\approx1.1/d$）——两个独立手段给出同一结论，表征才算闭环。

## 5 制备-表征-性能的闭环

把整节串成一个工程循环：

1. **配方与制备**：选载体、定负载量、选浸渍/共沉淀、定焙烧还原条件。
2. **表征验收**：BET 看表面、XRD 看晶粒、吸附看分散度、TPR 看还原性。
3. **活性测试**：固定床/间歇反应器测 X、S、TOF，与表征数据对照。
4. **迭代优化**：分散度不够→降焙烧温度；活性位被载体毒化→换载体；晶粒太大→调还原条件——**每一步表征数据都是下一步制备的输入**。

**这就是催化研究的「制备-表征-性能」铁三角**：没有哪个环节可以省略，三者循环迭代直到性能达标。<span class="marginnote">展望第4篇：氨合成铁催化剂的制备（熔融）、汽车尾气整体式催化剂的涂覆、加氢脱硫催化剂的浸渍——工业案例中你会反复见到这条闭环在发挥作用。</span>

## 6 延伸：一条制备-表征-性能的实例闭环

用 Cu/ZnO/$\ce{Al2O3}$（甲醇合成催化剂，共沉淀制得）走一遍闭环：

1. **制备**：$\ce{Cu(NO3)2}$、$\ce{Zn(NO3)2}$、$\ce{Al(NO3)3}$ 混合液与 $\ce{Na2CO3}$ 共沉淀，控制 pH ≈ 7、温度约 70 °C，得类孔雀石前驱体。
2. **表征**：BET 看比表面（常 60–120 m²/g）、XRD 看 CuO/ZnO 晶粒、TPR 看还原温度、TEM 看颗粒形貌。
3. **活性测试**：固定床中测 CO 加氢到甲醇的转化率与选择性。
4. **迭代**：比表面不够 → 调沉淀 pH 与老化时间；还原温度过高 → 调 $\ce{Al2O3}$ 比例（它抑制 Cu 烧结）；颗粒长大 → 控焙烧温度。

**这条闭环说明**：制备工艺的每个参数（pH、温度、老化、焙烧）都对应一个可表征的指标（比表面、晶粒、还原性、形貌），而指标又对应一个性能问题——「制备-表征-性能」是首尾相连的。

## 7 术语速查：制备与表征关键词

| 术语 | 一句话定义 | 记忆锚点 |
| --- | --- | --- |
| 浸渍 | 前驱体溶液灌进载体孔道 | 低负载贵金属 |
| 初湿浸渍 | 溶液量=孔体积 | 负载量最精确 |
| 共沉淀 | 多金属同时沉淀 | 分子级混合 |
| 过饱和度 | 沉淀瞬间遍及全溶液 | 均匀性关键 |
| 焙烧 | 前驱体分解 + 固定 + 建相互作用 | 温度管晶粒 |
| 还原活化 | $\ce{H2}$ 把氧化物还原成金属 | 活性位诞生 |
| Scherrer 方程 | $D = K\lambda/(\beta\cos\theta)$ | 峰宽 → 晶粒 |
| 操作态表征 | 反应条件下同步测活性与光谱 | 抓「工作中」状态 |
| BET | 液氮物理吸附测比表面 | 体检必查 |
| TPR/TPO | 测还原/氧化温度 | 好不好还原 |
| 老化/陈化 | 沉淀后静置熟化 | 调晶粒与孔结构 |

## 8 小结

- **浸渍法**：金属盐溶液灌进载体孔道，干燥→焙烧→还原，适合低负载贵金属，分布可精确设计。
- **沉淀/共沉淀法**：从溶液沉淀出（混合）氧化物，适合高负载复合氧化物，均匀性靠过饱和度控制。
- **表征工具箱**：BET、化学吸附、XRD、TPR/TPD、TEM、XPS 各司其职，活性测试与表征必须双轨并行。
- **Scherrer 方程** $D = K\lambda/(\beta\cos\theta)$：峰越宽晶粒越小；$D$ 与化学吸附分散度互相印证才闭环。
- **两条制备路线**：浸渍做「载体上的金属」（低负载、精确分布），共沉淀做「复合氧化物本体」（高负载、均匀）。
- **表征双轨**：活性测试回答「好不好用」，表征回答「为什么」；操作态表征抓「工作中的状态」。
- **铁三角闭环**：制备参数 → 表征指标 → 性能问题，首尾相连迭代优化。
