# 催化化学

催化化学研究催化剂如何提高反应速率并定向调控选择性，是衔接物理化学与化学工程的工业化学核心。均相、多相与生物催化三大体系是能源转化、石油化工、绿色合成与环境保护产业的基石，学完本专题即贯通从分子机理到工业流程的完整链条。

## 对标教材

- Gadi Rothenberg, "Catalysis: Concepts and Green Applications" (2nd ed., Wiley-VCH, 2017)
- B. C. Gates, "Catalytic Chemistry" (Wiley, 1992)
- 黄开辉、万惠霖, 《催化原理》（科学出版社）
