## 为什么从交叉偶联讲起

前面几个循环都在「改造小分子」，而现代有机合成的终极需求是**造大分子、造复杂分子**——尤其是芳环与芳环之间的 C—C 键。传统方法（Friedel-Crafts 等）条件苛刻、选择性差；1970 年代起，Heck、Negishi、Suzuki 等人发展出以**钯为催化剂**的交叉偶联反应，让「芳卤 + 金属试剂 → 联芳」变得温和、通用、可设计，2010 年共同荣获诺贝尔化学奖。交叉偶联的意义远超方法学：它把制药工业从「碰运气造分子」带进了「按图纸焊接分子」的时代——今天几乎每一个新药分子里都藏着至少一次钯催化偶联。本节解剖钯循环这个「通用焊接机」，并对比几种主要偶联类型的异同。<span class="marginnote">交叉偶联连接第4篇《绿色催化》：这类反应底物范围广、官能团耐受强、通常只需温和条件与化学计量碱——天然契合绿色合成「少废物、高原子经济」的目标。</span>

## 1 通用骨架：Pd(0)/Pd(II) 循环

所有钯催化的偶联共享同一个核心循环，区别只在第二步如何把「第二个偶联伙伴」送上来：

$$
\ce{R-X + R'-Y ->[\ce{Pd}] R-R' + XY}
$$

循环三步：

1. **氧化加成（OA）**：$\ce{R-X}$（芳卤、烯基卤）拆到 $\ce{Pd(0)}$ 上，生成 $\ce{Pd(II)(R)(X)}$。这是「上车」步，通常决定底物适用范围。
2. **转金属（transmetalation）或插入**：第二个伙伴 $\ce{R'-M}$（Suzuki 的硼酸、Negishi 的锌试剂、Stille 的锡试剂、Kumada 的格氏试剂）把 $\ce{R'}$ 转移到钯上，副产物 $\ce{MX}$ 离去；Heck 则不走转金属，而是烯烃配位 + 顺式插入。
3. **还原消除（RE）**：$\ce{R}$ 与 $\ce{R'}$ 偶联成 $\ce{R-R'}$ 脱去，钯回到 $\ce{Pd(0)}$，循环闭合。<span class="marginnote">循环的「心脏」是 Pd(0) 与 Pd(II) 之间 2 电子的振荡：$\ce{Pd(0)}$ 是 $d^{10}$、16e（配两个配体时 14e），氧化加成后变 $\ce{Pd(II)}$、$d^8$；还原消除再回到 $d^{10}$。低价、富电子的 Pd(0) 是 OA 的前提——这就是为什么配体必须维持 Pd 的富电子与配位不饱和。</span>

## 2 公式解析：氧化加成与钯的电子记账

氧化加成是偶联的起点，也是理解钯配体设计的关键。用电子记账看这一下：

$$
\ce{L_nPd(0) + Ar-X -> L_nPd(II)(Ar)(X)}
$$

- **第一步，数初始态**：$\ce{Pd(0)}$ 是 $d^{10}$，配两个单齿膦时价电子数 $= 10 + 2\times2 = 14$（或加一个配体为 16）——**配位不饱和**，等着拆键。
- **第二步，数 OA 后的态**：$\ce{Ar-X}$ 断裂，两个电子进金属，$\ce{Ar^-}$ 与 $\ce{X^-}$ 各捐一对孤对电子给金属，钯变成 $\ce{Pd(II)}$、$d^8$，配位数加 2、价电子数加 2（16e）。
- **第三步，读动力学含义**：OA 是富电子金属「掏电子拆键」的过程——配体越富电子（给电子越强）、钯配位数越低，OA 越快。这就解释了为什么大位阻富电子膦（如 $\ce{P(tBu)3}$、JohnPhos）能加速顽固芳卤（$\ce{Ar-Cl}$）的偶联：位阻压低配位数、富电子提高拆键能力。
- **第四步，对比难易**：$\ce{Ar-I}$ 比 $\ce{Ar-Br}$ 比 $\ce{Ar-Cl}$ 容易 OA（C—X 键能递减/键能实际为 I < Br < Cl，断裂所需能量递增），所以**氯代芳烃是「硬骨头」，要靠强配体才能啃动**——这是配体筛选（第9篇）在偶联里的直接应用。

## 3 Heck 反应：芳卤直接焊接烯烃

**Heck 反应**：$\ce{Ar-X + RCH=CH2 -> Ar-CH=CH-R&#125;$，芳基与烯烃偶联，不经过转金属。机理在通用骨架上换血：

1. $\ce&#123;Pd(0)&#125;$ 对 $\ce&#123;Ar-X&#125;$ 氧化加成得 $\ce&#123;Pd(II)(Ar)(X)&#125;$。
2. 烯烃配位、顺式插入 $\ce&#123;Ar-Pd&#125;$ 键（迁移插入）。
3. **β-氢消除**：$\ce&#123;Pd-H&#125;$ 从烷基上离去，释放偶联产物烯烃，钯成 $\ce&#123;Pd(II)-H&#125;$。
4. 碱抓走 $\ce&#123;HX&#125;$，再生 $\ce&#123;Pd(0)&#125;$。

**碱在这里不是陪衬，而是再生循环的必需**——没有碱，$\ce&#123;Pd(II)-H&#125;$ 无法脱去 $\ce&#123;HX&#125;$ 回到 $\ce&#123;Pd(0)&#125;$，循环就死了。<span class="marginnote">辨析｜易错点：Heck 的 β-氢消除方向决定了产物烯烃的双键位置；当底物烯烃两端不对称时，区域选择性由插入取向控制，不是简单的 Markovnikov。用位阻与电子效应调控这一步，是 Heck 合成精细烯烃的要点。</span>

## 4 Suzuki 反应：硼酸牵手芳环

**Suzuki 偶联**：$\ce&#123;Ar-X + Ar'-B(OH)2 -> Ar-Ar'&#125;$，芳基硼酸与芳卤偶联成联芳，是制药与材料化学中使用最广的偶联。它的关键差异在**转金属**：

硼酸的 $\ce&#123;C-B&#125;$ 键较惰性，须先被**碱活化**：碱（如 $\ce&#123;K2CO3&#125;$、$\ce&#123;NaOH&#125;$、$\ce&#123;CsF&#125;$）与硼酸生成四配位硼酸盐 $\ce&#123;Ar'-B(OH)3^-&#125;$，负电性增强、使 $\ce&#123;Ar'&#125;$ 更易转移到钯上。
转金属生成 $\ce&#123;Pd(II)(Ar)(Ar')&#125;$，随后还原消除给出联芳与 $\ce&#123;Pd(0)&#125;$。

**Suzuki 的优势**：硼酸稳定、无毒、官能团耐受极强、可在含水体系进行，副产物硼酸易除——是「绿色友好」的偶联。<span class="marginnote">对照记忆五种偶联的第二伙伴：Suzuki 用硼酸（需碱活化）、Negishi 用锌试剂、Stille 用锡试剂（有毒但活性高）、Kumada 用格氏试剂（活性高但官能团耐受差）、Sonogashira 用末端炔（还需铜共催化）。第二伙伴的选择 = 活性与官能团耐受的权衡。</span>

## 5 钯偶联的工业与合成地位

交叉偶联从实验室走向万吨级与制药工厂，靠的是三件事：

**配体设计解锁惰性底物**：大位阻、富电子的膦与 NHC 配体让 $\ce&#123;Ar-Cl&#125;$、$\ce&#123;Ar-OTs&#125;$ 这类廉价底物也能高效偶联，大幅降低成本。
**低催化剂负载**：现代偶联的 Pd 负载可低至 ppm–千分比级，配合高 TON，贵金属成本大幅摊薄。
- **多组分与串联**：一锅法多步偶联、C—H 活化的出现，让「先焊接再修饰」的合成策略成为可能。

典型工业案例包括：除草剂、液晶材料、药物中间体（如抗肿瘤药、抗炎药的联芳骨架）的大规模偶联。<span class="marginnote">连接第2篇《不对称催化》与第4篇《绿色催化》：不对称偶联（手性配体控制烯丙基取代）与偶联废液中的钯回收，都是这个领域正在深化的方向。</span>

## 6 延伸：五种偶联的家族谱

交叉偶联是一个家族，区别只在「第二个偶联伙伴怎么送上来」。一张表看清全貌：

| 偶联类型 | 第二伙伴 | 需碱活化 | 官能团耐受 | 相对活性 |
| --- | --- | --- | --- | --- |
| Suzuki | 硼酸 $\ce{RB(OH)2}$ | 是 | 极强 | 中 |
| Heck | 烯烃（不转金属） | 是 | 强 | 中 |
| Negishi | 锌试剂 $\ce{RZnX}$ | 否 | 中 | 高 |
| Stille | 锡试剂 $\ce{RSnR3'}$ | 否 | 中 | 高（有毒） |
| Kumada | 格氏试剂 $\ce{RMgX}$ | 否 | 低 | 很高 |
| Sonogashira | 末端炔（+Cu 共催化） | 是 | 强 | 中 |

**选型口诀**：制药多选 Suzuki（温和、无毒、耐受强）；要活性且底物简单选 Kumada/Negishi；Heck 免转金属、专接烯烃。第二伙伴的选择 = 活性与官能团耐受的权衡。

## 7 术语速查：交叉偶联关键词

| 术语 | 一句话定义 | 记忆锚点 |
| --- | --- | --- |
| 氧化加成 | 芳卤拆到 Pd(0)，Pd 变 Pd(II) | 上车步 |
| 转金属 | 第二伙伴把 R' 转移到钯上 | Suzuki 需碱活化 |
| 还原消除 | R 与 R' 偶联成键脱去 | 卸货步 |
| 碱活化硼酸 | 碱生成四配位硼酸盐 | 让 Ar' 更易转移 |
| 大位阻富电子膦 | 压低配位数 + 加速 OA | 啃动 Ar-Cl |
| β-氢消除 | Pd-H 从烷基离去 | Heck 的卸货方式 |
| 幽灵催化 | 微量 Pd 杂质冒充催化剂 | 对照实验必做 |
| 一锅多步偶联 | 串联偶联构建复杂分子 | 现代合成策略 |
| 芳卤活性序 | $\ce&#123;Ar-I > Ar-Br > Ar-Cl&#125;$ | 氯是硬骨头 |
| 钯负载量 | ppm–千分比级 | 贵金属摊薄 |

**读表要点**：六种偶联的差异只在「第二伙伴怎么送」——选型 = 活性与官能团耐受的权衡。

## 8 小结

- **通用钯循环**：氧化加成（拆 $\ce&#123;R-X&#125;$）→ 转金属/插入（送 $\ce&#123;R'&#125;$）→ 还原消除（成键卸货），Pd 在 0/+2 间振荡。
- **Heck 反应**：芳卤 + 烯烃，迁移插入 + β-氢消除 + 碱再生；不经转金属。
- **Suzuki 反应**：芳卤 + 硼酸，碱活化硼酸促转金属；温和、无毒、官能团耐受强。
- **配体是钥匙**：大位阻富电子膦/NHC 啃动惰性 $\ce&#123;Ar-Cl&#125;$——位阻压低配位数、富电子加速 OA。
- **家族谱**：Suzuki/Heck/Negishi/Stille/Kumada/Sonogashira 六种偶联，第二伙伴的选择是活性与耐受的权衡。
- **工业地位**：制药与材料化学中联芳骨架的主要来源；Pd 负载可低至 ppm 级。
- **诺贝尔奖**：Heck、Negishi、Suzuki 2010 年共享化学奖，表彰把「焊接分子」带进工业。
- **活性序**：$\ce&#123;Ar-I > Ar-Br > Ar-Cl&#125;$——氯代芳烃靠大位阻富电子配体啃动。
- **绿色友好**：Suzuki 的硼酸稳定、副产物易除，在制药中应用最广。
