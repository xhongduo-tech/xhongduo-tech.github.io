## 为什么从重量分析讲起

滴定分析通过「消耗体积」推算含量，**重量分析（gravimetric analysis）**则直接通过「称量质量」得出结果。它不依赖标准溶液、不依赖体积测量，只需一台准确的天平——这使它成为分析化学里**准确度最高、最不依赖标定的方法**，常被用作仲裁分析和基准方法。虽然操作冗长（沉淀、过滤、洗涤、灼烧、恒重），但它把一个简单道理贯彻到底：**用天平测量，比什么都可靠**。

## 1 重量分析的基本过程

重量分析的操作流程是一套「沉淀 → 净化 → 称重」的完整工艺：

1. **溶解试样**：把试样溶解成溶液。
2. **沉淀**：加入沉淀剂，使待测组分生成难溶化合物（沉淀形式）。
3. **陈化、过滤、洗涤**：让沉淀长大、洗净可溶性杂质。
4. **灼烧（或烘干）**：把沉淀转化为组成确定的**称量形式**。
5. **称至恒重**：两次称量之差 ≤ 0.2 mg 即为恒重，记录质量。

**沉淀形式（precipitated form）** 是沉淀析出时的化学形态；**称量形式（weighing form）** 是灼烧后用于称量的化学形态。<span class="marginnote">二者可以相同也可以不同：测 $\ce{SO4^{2-}}$ 时沉淀形式与称量形式都是 $\ce{BaSO4}$（恒重，无水）——沉淀后直接在 800°C 灼烧成 $\ce{BaSO4}$ 称量。测铁时沉淀形式是 $\ce{Fe(OH)3.xH2O}$，灼烧后称量形式是 $\ce{Fe2O3}$。</span>

## 2 沉淀形式与称量形式的要求

**对沉淀形式的要求**：①溶解度小（沉淀完全）；②纯度高（不易共沉淀杂质）；③便于过滤洗涤（晶形沉淀优于无定形沉淀）；④易转化为称量形式。

**对称量形式的要求**：①组成确定、与化学式完全一致；②性质稳定（不吸湿、不吸收 $\ce{CO2}$、不易氧化）；③摩尔质量大——称量误差对结果的影响小。<span class="marginnote">「摩尔质量大」与基准物质的要求同理：称量形式摩尔质量越大，同样的含量对应越大的称量质量，天平的绝对误差造成的相对误差越小。测 $\ce{Al^{3+}}$ 用 $\ce{Al2O3}$（$M=102$）不如转化为 $\ce{Al(C9H6NO)3}$ 8-羟基喹啉铝（$M=459$）称量更有利。</span>

## 3 沉淀的形成与纯度控制

沉淀能否做好，取决于**沉淀过程的条件**。沉淀按形态分两类：

- **晶形沉淀**（如 $\ce{BaSO4}$、$\ce{MgNH4PO4}$）：颗粒大、易过滤、表面吸附杂质少。
- **无定形沉淀**（如 $\ce{Fe(OH)3}$、$\ce{Al(OH)3}$）：颗粒小、比表面大、易吸附杂质、难过滤。

**沉淀条件（晶形沉淀）**：在**稀溶液**、**热溶液**中，**缓慢加入沉淀剂并搅拌**，然后**陈化**。这保证生成较少的晶核、让晶体长大。<span class="marginnote">这些条件背后的物理化学逻辑：稀溶液降低过饱和度、减少晶核数；加热增大溶解度、减小过饱和度并加速晶体生长；陈化（放置）让细小晶体溶解、大晶体长大，同时释放吸附的杂质（Ostwald 熟化）。</span>

**共沉淀（coprecipitation）**：沉淀过程中杂质被一起带下来的现象。它是沉淀纯度下降的主要来源，机制包括表面吸附、吸留（包夹）、混晶与后沉淀。减小共沉淀的手段：洗涤、再沉淀、陈化、控制沉淀条件。

**辨析｜易错点：**「无定形沉淀反而要在浓热溶液中快速沉淀」是看似矛盾实则正确的规则。晶形沉淀要慢（控过饱和度长大晶体），无定形沉淀则要快——在浓热溶液中快速沉淀使胶体粒子尽快聚沉成较大的聚集体，减少分散的表面积与吸附，再趁热过滤、用热电解质溶液洗涤防止胶溶。

## 4 公式解析：换算因数

重量分析计算的核心是**换算因数（gravimetric factor）** $F$：由称量形式质量换算待测组分质量的比例系数。

$$F = \frac{a \times M_{\text{待测物}}}{b \times M_{\text{称量形式}}}$$

其中 $a$、$b$ 是使分子分母所含待测元素的**原子数相等**的系数。以测定镁（沉淀为 $\ce{MgNH4PO4}$，灼烧成 $\ce{Mg2P2O7}$ 称量）为例：

$$F = \frac{2 M_{\ce{Mg}}}{M_{\ce{Mg2P2O7}}} = \frac{2 \times 24.31}{222.55} = 0.2185$$

- **第一步，确定称量形式与待测物**：称量的是 $\ce{Mg2P2O7}$，待测的是 $\ce{Mg}$。
- **第二步，配平元素守恒**：1 mol $\ce{Mg2P2O7}$ 含 2 mol $\ce{Mg}$，故分子用 $2 M_{\ce{Mg}}$，分母用 $M_{\ce{Mg2P2O7}}$——系数 $a = 2$、$b = 1$。
- **第三步，算含量**：$\omega_{\ce{Mg}} = \dfrac{m_{\ce{Mg2P2O7}} \times F}{m_{\text{试样}}}$。

换算因数的意义：把「称量形式的摩尔质量」与「待测物的摩尔质量」的比例固化为一个常数，使每次计算只需一步乘法。<span class="marginnote">常见换算因数：$\ce{BaSO4}$ 换算 $\ce{S}$：$F = \dfrac{M_{\ce{S}}}{M_{\ce{BaSO4}}} = 0.1374$；$\ce{Fe2O3}$ 换算 $\ce{Fe}$：$F = \dfrac{2M_{\ce{Fe}}}{M_{\ce{Fe2O3}}} = 0.6994$。写因数前先写元素守恒式，是防止系数错配的可靠习惯。</span>

**辨析｜易错点：**系数 $a$、$b$ 不是随意配的，必须保证分子分母**含待测元素的原子数相等**。测铁用 $\ce{Fe2O3}$ 称量时，分子必须是 $2M_{\ce{Fe}}$（不是 $M_{\ce{Fe}}$），因为 $\ce{Fe2O3}$ 里有 2 个铁原子。漏系数是重量分析计算的第一高频错误。

## 5 重量分析的结果计算

完整的结果计算链条：

$$m_{\ce{Mg}} = m_{\ce{Mg2P2O7}} \times F,\qquad \omega_{\ce{Mg}} = \frac{m_{\ce{Mg}}}{m_{\text{试样}}}$$

所有称量都用分析天平（$\pm 0.1\ \pu{mg}$），恒重差 ≤ 0.2 mg。由于不涉及体积与标准溶液，重量分析的误差来源集中在**称量误差**与**沉淀不完全/共沉淀**——所以沉淀化学（上一篇）是它的前提，称量恒重是它的纪律。

**辨析｜易错点：**恒重的判定。恒重不是「称一次」，而是「灼烧—冷却—称量—再灼烧—再称量」循环，直至**连续两次称量之差不超过 0.2 mg**。有人只称一次就报数，无法排除沉淀未完全转化为称量形式或仍含吸附水的可能。

## 6 硫酸钡重量法测硫的完整算例

重量分析的经典范例是 $\ce{BaSO4}$ 法测硫。称取煤样 $0.8000\ \pu{g}$，用氧化熔融法把硫转化为 $\ce{SO4^{2-}}$，稀盐酸酸化后加热近沸，缓慢滴加热的 $\ce{BaCl2}$ 溶液沉淀，陈化、过滤、洗涤，灼烧至恒重得 $\ce{BaSO4}$ $0.05832\ \pu{g}$。

- **第一步，写元素守恒**：$\ce{BaSO4}$ 中 1 mol 含 1 mol 硫，换算因数 $F = \dfrac{M_{\ce{S}}}{M_{\ce{BaSO4}}} = \dfrac{32.07}{233.39} = 0.1374$。
- **第二步，算硫的质量**：$m_{\ce{S}} = m_{\ce{BaSO4}}\times F = 0.05832\times0.1374 = 0.008013\ \pu{g}$。
- **第三步，算质量分数**：$\omega_{\ce{S}} = \dfrac{0.008013}{0.8000} = 1.002\%$。<span class="marginnote">这个算例的关键在于「恒重」二字：沉淀在 $800°C$ 灼烧后 $\ce{BaSO4}$ 组成确定（无结晶水、不吸湿），连续两次称量差 ≤ 0.2 mg 才可用。若灼烧温度过高（> $900°C$），$\ce{BaSO4}$ 开始分解成 $\ce{BaO + SO3}$，称量形式不再是纯 $\ce{BaSO4}$，结果失真。</span>

**沉淀操作要点回顾**：稀（$c_{\ce{BaCl2}}$ 约 0.1 mol/L 缓慢滴加）、热（近沸）、搅拌、陈化 12 小时——这些条件都是为了获得粗大、纯净、易过滤的晶形沉淀，减少共沉淀与吸附。沉淀完成后检验是否沉淀完全（上层清液加一滴沉淀剂不再浑浊）。

**辨析｜易错点：**$\ce{BaSO4}$ 沉淀在酸性溶液中进行，为什么不用中性？因为 $\ce{BaCO3}$、$\ce{Ba3(PO4)2}$ 等也难溶——酸化可防止这些干扰沉淀生成。但酸度太高会增大 $\ce{BaSO4}$ 溶解度（酸效应），一般控制在 pH 1–2。酸碱度又是「防干扰」与「防溶解」的权衡。

## 7 重量分析的误差来源与精度控制

重量分析的精度高，但误差来源同样要逐项排查：

| 误差来源 | 性质 | 控制手段 |
| --- | --- | --- |
| 沉淀不完全（溶解度损失） | 系统误差 | 沉淀剂过量、同离子效应 |
| 共沉淀/后沉淀（杂质带入） | 系统误差 | 稀热慢搅、陈化、洗涤、再沉淀 |
| 洗涤不净（杂质残留） | 系统误差 | 规范洗涤（少量多次、检验洗涤液） |
| 灼烧温度不当（分解/吸湿） | 系统误差 | 按方法控制灼烧温度与恒重判定 |
| 称量误差 | 随机误差 | 分析天平校准、恒温防潮 |
| 换算因数错误 | 系统误差 | 元素守恒复核 |

**为什么重量分析准确度高**：它不依赖标准溶液与体积测量，最敏感的「量」是天平称量——分析天平相对误差可达 $10^{-4}$ 量级。误差主要来自沉淀化学（完全度、纯度），而这些是**方法设计**可以控制的。<span class="marginnote">重量分析常被用作<strong>仲裁方法</strong>：当滴定与仪器方法结果分歧时，用重量分析定夺。这正是因为它不依赖标定链——只要天平准、沉淀净，结果就可靠。它的代价是慢（陈化、灼烧、恒重动辄数小时），所以日常批量分析用滴定/仪器，仲裁复核用重量法。</span>

**辨析｜易错点：**恒重不等于「重量不再变」。恒重判定是「连续两次灼烧后称量差 ≤ 0.2 mg」，说明已无显著的质量变化来源（吸附水、分解产物）。若只灼烧一次就称量，无法证明达到稳定态——恒重是一个「过程合格」的判据，不是一次称量的结果。

## 8 重量分析与滴定分析的适用边界

同为经典化学分析，重量法与滴定法各有主场，选哪个看任务：

| 维度 | 重量分析 | 滴定分析 |
| --- | --- | --- |
| 准确度 | 最高（仲裁级） | 高（0.1%–0.3%） |
| 速度 | 慢（沉淀、灼烧、恒重） | 快（数分钟到数十分钟） |
| 对标准溶液的依赖 | 无 | 依赖 |
| 操作复杂度 | 高（多步骤、易出错） | 中 |
| 适用范围 | 可沉淀/灼烧成确定称量形式者 | 有定量反应与终点指示者 |

**选择逻辑**：需要最高准确度的仲裁测定 → 重量法；常规批量、追求速度 → 滴定法。两者测的对象高度重叠（很多离子既可用沉淀法也可用配位/沉淀滴定），差异主要在「要有多准」与「能等多久」之间权衡。<span class="marginnote">工业分析的实际分工：日常生产控制用滴定/仪器（快），出厂仲裁与争议复核用重量法（准）。重量分析在现代的价值定位不是「日常主力」，而是「计量基准」——它的地位来自「不依赖标定链」的独立性，恰如天平在计量学里的基础地位。</span>

**辨析｜易错点：**「重量法一定比滴定准」有条件。重量法的准确度建立在「沉淀纯净 + 称量形式确定」上——若共沉淀严重或灼烧形式不纯，误差可能反而大于滴定。准确度是「做得好」的结果，不是「方法名」的保证。

## 9 小结

- 重量分析以**天平直接称量**为核心，准确度高、不依赖标准溶液，是仲裁方法。
- 流程：溶解 → 沉淀 → 陈化过滤洗涤 → 灼烧 → 称至恒重；涉及**沉淀形式**与**称量形式**两个概念。
- 沉淀形式要求溶解小、纯度高、易过滤；称量形式要求组成确定、稳定、摩尔质量大。
- 晶形沉淀「稀热慢搅陈化」，无定形沉淀「浓热快速聚沉」；**共沉淀**是纯度的大敌。
- **换算因数** $F = \dfrac{a M_{\text{待测}}}{b M_{\text{称量形式}}}$，系数须满足元素守恒；恒重差 ≤ 0.2 mg。
