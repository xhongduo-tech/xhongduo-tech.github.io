## 为什么从核磁共振讲起

红外、质谱能告诉你「有什么基团、分子多重」，但**核磁共振（nuclear magnetic resonance, NMR）**能告诉你「这些原子在分子里怎么连接」——它是结构测定里信息量最大、最接近「看」到分子骨架的技术。有机化学、药物化学、代谢组学离开 NMR 几乎寸步难行。这一篇以 $^1\ce{H}$ NMR 为主线，讲清化学位移、积分、裂分三大信息块，并延伸到 $^{13}\ce{C}$ NMR。

## 1 核自旋与共振条件

某些原子核（$^1\ce{H}$、$^{13}\ce{C}$、$^{19}\ce{F}$、$^{31}\ce{P}$）具有**自旋角动量**，像小磁针一样具有**磁矩**。把它们放进外磁场 $B_0$ 中，磁矩只能取量子化的取向——对 $I = 1/2$ 的核（如 $^1\ce{H}$），有两个能级：平行（低能）与反平行（高能）。

**共振条件**：当射频（RF）波的频率满足

$$\nu = \frac{\gamma B_0}{2\pi}$$

时，低能级核吸收能量跃迁到高能级——这就是核磁共振。<span class="marginnote">$\gamma$ 是<strong>旋磁比</strong>（核的特征常数，$\ce{H}$ 约 $42.6\ \pu{MHz T-1}$）。在 $B_0 = 14.1\ \pu{T}$ 的现代高场仪器中，$^1\ce{H}$ 的共振频率约 600 MHz。核磁共振为什么「弱」？因为两个能级的能量差极小，热平衡时两能级布居差只有约百万分之几——信号天然微弱，这也是 NMR 灵敏度低（相比质谱）的物理根源。</span>

## 2 化学位移：电子云的局部磁场

如果所有 $^1\ce{H}$ 都在同一频率共振，NMR 就毫无用处。幸运的是，**核外电子**在外磁场中产生**屏蔽（shielding）**，使核实际感受到的磁场小于 $B_0$：

$$B_{\text{实际}} = B_0(1 - \sigma)$$

$\sigma$ 是屏蔽常数，取决于核周围的电子环境。<span class="marginnote">电子密度大的氢（如连在氧旁的 $\ce{-OH}$ 附近、或受供电子基影响的 H）屏蔽强，共振频率略低，化学位移值偏小；电子被吸走的氢（连在羰基、芳环、卤素旁）去屏蔽，化学位移偏大。这就是「化学位移反映化学环境」的机制。</span>

**化学位移（chemical shift）$\delta$**：把共振频率相对内标（TMS，四甲基硅烷）的偏移，换算成无量纲的 ppm 数：

$$\delta\ (\pu{ppm}) = \frac{\nu_{\text{样品}} - \nu_{\ce{TMS}}}{\nu_0} \times 10^6$$

$\delta$ 与磁场强度无关，因此不同仪器测得的 $\delta$ 可直接比较。<span class="marginnote">TMS（$\ce{Si(CH3)4}$）选作内标是因为：12 个氢全等价、强屏蔽、单峰，化学位移定为 0，且化学惰性不干扰样品。</span>

**常见 $^1\ce{H}$ 化学位移范围**：烷基氢 $\delta$ 0.9–1.8；烯丙基/苄基 1.8–2.6；醛氢 9–10；羧酸氢 10–12；苯环氢 6.5–8.5；醇/胺氢 1–5（宽峰、可变）。

## 3 积分与裂分：数氢与看邻居

$^1\ce{H}$ NMR 谱给三类信息：

**（1）化学位移**——氢处于什么化学环境（读 $\delta$）。

**（2）积分（integration）**——峰面积正比于等价氢的数目。积分线的高度比给出各组氢的相对个数。例如乙醇 $\ce{CH3CH2OH}$ 三组峰的积分比约为 3:2:1。

**（3）裂分（splitting）**——相邻碳上的氢（$n$ 个等价氢）通过**自旋-自旋耦合**把峰裂分为 $n+1$ 重峰（**n+1 规则**）。<span class="marginnote">例：乙醇的 $\ce{-CH3}$ 邻接 $\ce{-CH2-}$（2 个等价氢），甲基峰裂分为 3 重峰（triplet）；$\ce{-CH2-}$ 邻接甲基（3 个氢），亚甲基峰裂分为 4 重峰（quartet）。「邻位氢数 + 1」即峰形，让 NMR 能读出氢的「邻居关系」——这是确定分子连接方式的钥匙。</span>

**耦合常数的规律**：裂分峰的间隔叫**耦合常数 $J$**（单位 Hz），反映耦合强度。$J$ 只取决于化学键连接，不随磁场强度变化——这是与化学位移（随场强变化）的本质区别。

## 4 公式解析：耦合裂分的峰形与强度

以甲基裂分为三重峰为例，理解峰形来源与强度比例：

$$\text{三重峰：} 1 : 2 : 1,\qquad \text{四重峰：} 1 : 3 : 3 : 1$$

- **第一步，自旋组合**：两个等价邻位氢的核自旋取向有四种组合：$\uparrow\uparrow$、$\uparrow\downarrow$、$\downarrow\uparrow$、$\downarrow\downarrow$。
- **第二步，等价归并**：$\uparrow\downarrow$ 与 $\downarrow\uparrow$ 对甲基核产生的局部磁场相同，合并为一种，于是三种局部磁场对应三个峰，强度比 $1:2:1$。
- **第三步，推广**：$n$ 个等价邻位氢产生 $n+1$ 个峰，强度按**二项式系数**（杨辉三角）分布：1:3:3:1（四重峰）、1:4:6:4:1（五重峰）。

这就是 n+1 规则的完整数学。**「几重峰」直接告诉你邻位有几个氢**——谱图解析里最常用的一条线。

**辨析｜易错点：**n+1 规则只适用于「邻位氢等价且与观测氢非等价」的简单情形。等价氢之间不裂分（它们共振频率相同，不产生可观测的耦合分裂）；手性中心附近或化学位移接近的氢可能呈现复杂多重峰。把 n+1 规则硬套到复杂体系，会得到错误的峰形预期。

## 5 $^{13}\ce{C}$ NMR 与二维谱

$^{13}\ce{C}$ 核也有自旋（$I = 1/2$），但其天然丰度仅 1.1%、旋磁比约为氢的 1/4，灵敏度远低于 $^1\ce{H}$。现代仪器常用**去耦（decoupling）**技术：照射时消除 $^{13}\ce{C}$–$^1\ce{H}$ 耦合，每个不等价碳给一个**单峰**，直接读出碳骨架。<span class="marginnote">$^{13}\ce{C}$ 化学位移范围约 0–220 ppm（远宽于氢的 0–12 ppm），区分度高：羰基碳约 170–210、芳环碳 110–160、烯碳 100–150、饱和碳 10–60。配合 DEPT 等编辑实验可分辨 $\ce{CH3}$、$\ce{CH2}$、$\ce{CH}$、季碳。</span>

**二维 NMR（2D NMR）**：把两种核关系展开成二维图，如 COSY（氢-氢相关）、HSQC/HMBC（碳-氢相关）。二维谱是复杂分子（天然产物、蛋白质）结构测定的标准工具。<span class="marginnote">COSY 图的对角线是普通一维谱，交叉峰显示两个氢相隔 2–3 个键的耦合关系；HMBC 能「看」到 2–3 键以外的远程相关，像搭积木一样把片段拼成完整分子。有机化学家说「COSY 找邻居、HMBC 找远亲」，正是结构解析的两步走。</span>

## 6 乙醇 NMR 谱的完整解析算例

把化学位移、积分、裂分三信息合一，解析乙醇 $\ce{CH3CH2OH}$ 的 $^1\ce{H}$ NMR。

**谱图信息**：三组峰。①$\delta\ 1.2$，三重峰（triplet）；②$\delta\ 3.7$，四重峰（quartet）；③$\delta\ 2.5$ 附近，宽峰（可变位置）。积分比 3 : 2 : 1。

- **第一步，化学位移定位**：$\delta\ 1.2$ 是烷基氢（$\ce{-CH3}$），$\delta\ 3.7$ 是连氧碳上的氢（$\ce{-CH2-OH}$，O 吸电子去屏蔽），$\delta\ 2.5$ 宽峰是 $\ce{-OH}$（活泼氢，位置随浓度温度漂移）。
- **第二步，积分定数目**：3 : 2 : 1 → 甲基 3 个氢、亚甲基 2 个氢、羟基 1 个氢。
- **第三步，裂分定邻居**：甲基（3 重峰）→ 邻位 2 个等价氢（来自 $\ce{-CH2-}$）；亚甲基（4 重峰）→ 邻位 3 个等价氢（来自 $\ce{-CH3}$）。峰形与积分互相印证，结构 $\ce{CH3-CH2-OH}$ 唯一确定。<span class="marginnote">$\ce{-OH}$ 的氢通常不与邻位碳上的氢耦合，呈现单峰或宽峰（因为质子交换速度快，耦合被平均掉）。所以羟基不参与 n+1 裂分——这正是乙醇谱只有两组裂分峰的原因。若样品极干燥，羟基也可能显示耦合，这是活泼氢的常见现象。</span>

**三信息协同的价值**：化学位移告诉「哪类氢」，积分告诉「几个」，裂分告诉「邻位几个」。三者像拼图一样互相约束，往往几组峰就能确定一个小分子的完整骨架。配合 $^{13}\ce{C}$ NMR 与二维谱，大分子也能逐步拼出。

**辨析｜易错点：**活泼氢（$\ce{-OH}$、$\ce{-NH}$）的位置**不可靠**。它们受浓度、温度、溶剂、含水量影响可在很宽范围漂移（$\delta$ 1–5），且常呈宽峰。解析时先找「可预期的稳定峰」（甲基、芳环、醛），活泼氢最后再认——把活泼氢当成固定 $\delta$ 使用，会推错结构。

## 7 常见基团 $^1\ce{H}$ 化学位移速查表

把解析最常用的 $^1\ce{H}$ 化学位移范围收成一张表：

| 氢的类型 | 化学位移 δ（ppm） | 备注 |
| --- | --- | --- |
| $\ce{R-CH3}$（烷基甲基） | 0.9–1.0 | 三重峰常见 |
| $\ce{R-CH2-R}$ | 1.2–1.6 | |
| $\ce{R2CH}$ | 1.5–2.0 | |
| $\ce{R-CH2-C=O}$ / 苄基 | 2.0–2.6 | 羰基/芳环旁 |
| $\ce{-OCH3}$ / $\ce{-NCH3}$ | 3.3–3.8 | 杂原子旁 |
| $\ce{-CH2-O}$ / $\ce{-CH2-N}$ | 3.4–4.2 | |
| $\ce{=CH}$（烯氢） | 4.6–6.0 | |
| 芳环氢（Ar-H） | 6.5–8.5 | |
| $\ce{-CHO}$（醛氢） | 9–10 | 特征明显 |
| $\ce{-COOH}$ | 10–12 | 宽峰 |
| $\ce{-OH}$ / $\ce{-NH}$ | 1–5（可变） | 浓度温度漂移 |

**记忆锚点**：从低到高的顺序——烷基（1）→ 杂原子旁（3–4）→ 烯（5–6）→ 芳环（7–8）→ 醛（9–10）→ 羧酸（10–12）。**看到 δ 9–10 的单峰，第一个想到醛氢**，这是解析里最有用的经验判断之一。<span class="marginnote">δ 的范围会随溶剂、浓度微调，但「顺序」几乎不变。解析新手常犯的错是背几个「标准值」却不管峰的裂分与积分——正确姿势是四维综合：位移（位置）、积分（数量）、裂分（邻居）、耦合常数（键连）。只看 δ 一个维度，会把异构体认错。</span>

**辨析｜易错点：**$\ce{-CHCl3}$（氯仿残峰 δ 7.26）常被误认成芳环氢。氘代氯仿是 NMR 最常用溶剂，其残留 $\ce{CHCl3}$ 单峰恰落在芳环区。解析时先认出溶剂峰（报告里会标注「$\ce{CDCl3}$ 残留 δ 7.26」），再谈样品峰——把溶剂峰当样品峰，是每个 NMR 新手的必经之坑。

## 8 小结

- NMR 基于核自旋在磁场中的能级分裂与射频共振：$\nu = \dfrac{\gamma B_0}{2\pi}$；灵敏度低源于能级布居差微小。
- **化学位移 $\delta$**（ppm）由电子屏蔽决定，反映化学环境；用 TMS 作内标、与场强无关。
- $^1\ce{H}$ NMR 三信息：**化学位移**（什么环境）、**积分**（几个氢）、**裂分 n+1**（邻位几个氢）。
- 裂分峰强度按**二项式系数**分布；$J$ 耦合常数不随场强变，与 $\delta$ 区别明显。
- $^{13}\ce{C}$ NMR 去耦后一碳一峰，范围 0–220 ppm；**二维谱（COSY、HSQC、HMBC）**把连接关系展开成平面，是复杂分子结构测定的标准武器。
