## 为什么从色谱分离基础讲起

萃取只能「两相分离」，**色谱（chromatography）**则能把几十上百个组分逐一分开并依次检出——它是现代分析化学最重要的分离技术，也是后续色谱-质谱联用、生命科学分析的技术底座。从最初的「色层」（叶绿素分层）到今天的 HPLC、GC，色谱的核心思想始终如一：**让混合物在流动相驱动下，因各组分在固定相上保留能力不同而分道扬镳**。这一篇建立色谱的基础语言：保留值、分离度、塔板理论与速率理论。

## 1 色谱分离的基本原理

**色谱分离**：利用各组分在**固定相**与**流动相**两相间分配（或吸附、离子交换等）能力的不同，使混合物随流动相移动时**以不同速度迁移**，从而彼此分离。

常见色谱按固定相/流动相分类：

| 类型 | 流动相 | 固定相 | 分离依据 |
| --- | --- | --- | --- |
| 气相色谱（GC） | 气体（$\ce{N2}$、$\ce{He}$） | 液体涂渍或固体吸附剂 | 沸点/极性/吸附性 |
| 液相色谱（LC/HPLC） | 液体 | 键合相颗粒 | 极性/疏水性 |
| 薄层色谱（TLC） | 液体 | 板上涂层 | 分配/吸附 |
| 离子交换色谱 | 液体 | 离子交换树脂 | 离子交换能力 |

各组分在两相间反复分配：亲固定相的组分走得慢（保留强），亲流动相的走得快（保留弱），柱尾流出的时间序列就是**色谱图（chromatogram）**。<span class="marginnote">「色谱」之名来自 1903 年茨维特（Tswett）的经典实验：把植物色素提取液通过碳酸钙填充柱，色素分离成不同颜色的谱带——chromatography 字面即「书写颜色」。现代色谱早已不限于有色物质，但名字保留了下来。</span>

## 2 色谱的基本参数

色谱图上的三个基本量：

**保留时间（retention time）$t_R$**：组分从进样到浓度最大（峰顶）的时间。**死时间（dead time）$t_0$**：不被固定相保留的物质（如空气）通过色谱柱的时间。**调整保留时间（adjusted retention time）**：$t_R' = t_R - t_0$，真正反映组分被固定相保留的程度。

**容量因子（retention factor）$k$**：组分在固定相与流动相中分配量之比：

$$k = \frac{t_R - t_0}{t_0} = \frac{t_R'}{t_0}$$

$k$ 是无量纲参数，不随柱长与流速变化，是保留行为的「身份证」。<span class="marginnote">$k$ 与分配系数 $K$ 的关系：$k = K \cdot \dfrac{V_S}{V_M}$（$V_S$、$V_M$ 为固定相与流动相体积）。$k$ 太小时组分与流动相几乎一起流出（分离差），太大时出峰太慢。一般理想区间为 $1 \le k \le 10$。</span>

**分离度（resolution）$R_s$**：衡量相邻两峰分离程度：

$$R_s = \frac{2(t_{R,2} - t_{R,1})}{W_1 + W_2}$$

其中 $W_1$、$W_2$ 为两峰底宽。$R_s = 1$ 时两峰基本分开（重叠约 2%），$R_s = 1.5$ 时完全分离（基线分离）。**$R_s \ge 1.5$ 是色谱分离的质量标准**。

## 3 塔板理论：分离度与柱效

**塔板理论**把色谱柱类比为蒸馏塔：设想柱子由许多「理论塔板」串联，组分在每个塔板内达成一次分配平衡。<span class="marginnote">理论塔板数（plate number）$N$ 反映柱效：$N = \left(\dfrac{t_R}{\sigma}\right)^2 = 16\left(\dfrac{t_R}{W}\right)^2$（$W$ 为峰底宽）。$N$ 越大，峰越窄、柱效越高。塔板理论虽是简化模型（假设瞬间平衡），但它给出了 $N$ 与峰宽、分离度之间的定量关系。</span>

分离度与柱效、选择性、容量因子的关系（**分离度方程**）：

$$R_s = \frac{\sqrt{N}}{4}\cdot\frac{k_2}{1+k_2}\cdot\frac{\alpha - 1}{\alpha}$$

其中 $\alpha = k_2/k_1$ 为**分离因子（selectivity factor）**。这个方程拆出提高分离度的三条路：

1. **增大 $N$**（加长柱子、减小填料粒径）：$R_s \propto \sqrt{N}$，柱长加倍，$R_s$ 只增 $\sqrt{2}$ 倍。
2. **增大 $\alpha$**（改变固定相/流动相/温度）：最有效，但取决于化学选择性。
3. **优化 $k_2$**（调流动相强度）：$k_2/(1+k_2)$ 随 $k$ 增大趋近 1，$k$ 太小时损失分离度。

## 4 速率理论：峰为什么会展宽

塔板理论回答「能分多开」，**速率理论（Van Deemter 方程）**回答「峰为什么宽」——峰宽由三个动力学因素决定：

$$H = A + \frac{B}{u} + C u$$

其中 $H$ 为**塔板高度**（$H = L/N$，$L$ 柱长），$u$ 为流动相线速度：

- **$A$ 项（涡流扩散）**：流动相在填料颗粒间不同路径流动，路径长短不一导致展宽。减小填料粒径、装填均匀可减小 $A$。<span class="marginnote">$A$ 项与流速无关，只取决于填料几何。这正是为什么现代 HPLC 用 3–5 μm 的细颗粒填料——$A$ 项大幅减小，柱效提升一个数量级。</span>
- **$B/u$ 项（纵向扩散）**：分子沿柱方向的扩散展宽。流速越大，$B/u$ 越小；$B$ 与流动相中扩散系数成正比，气体中扩散快，所以 GC 的 $B$ 项显著。
- **$Cu$ 项（传质阻力）**：组分在流动相与固定相之间转移需要时间，流速越快，未达平衡的展宽越大。

Van Deemter 曲线呈「U 形」，存在最佳流速 $u_{\text{opt}}$（$H$ 最小处）。操作时选最佳流速附近的流速，可获最高柱效。

## 5 公式解析：用分离度方程设计分离

设两组分 $k_1 = 4.0$、$k_2 = 4.8$（$\alpha = 1.20$），现有色谱柱 $N = 2500$，判断能否基线分离：

$$R_s = \frac{\sqrt{2500}}{4}\cdot\frac{4.8}{1+4.8}\cdot\frac{1.20-1}{1.20} = \frac{50}{4}\times0.828\times0.167 = 1.73$$

- **第一步，算 $\sqrt{N}/4$**：$\sqrt{2500} = 50$，除以 4 得 12.5——柱效项的贡献。
- **第二步，算 $k$ 项**：$\dfrac{k_2}{1+k_2} = \dfrac{4.8}{5.8} = 0.828$——容量因子在合理区间，此项接近 1 不拖后腿。
- **第三步，算选择性项**：$\dfrac{\alpha-1}{\alpha} = \dfrac{0.20}{1.20} = 0.167$——选择性的贡献最小，是限制因素。
- **结论**：$R_s = 1.73 \ge 1.5$，可基线分离。若 $R_s$ 不足，最经济的改进是**提高 $\alpha$**（换流动相/固定相），其次才是加长柱子（$N$ 只按平方根起作用）。

**辨析｜易错点：**$R_s$、$\alpha$、$k$ 三个参数别混。$k$（容量因子）描述「一个组分保留多强」，$\alpha$（分离因子）描述「两个组分保留差异多大」（$\alpha = k_2/k_1 \ge 1$），$R_s$（分离度）描述「两个峰实际分开多少」。提高分离度的杠杆按性价比排序：$\alpha$ > $k$ > $N$。

## 6 从色谱图读出参数的实例

把色谱参数的计算落到一张具体谱图上。某组分在 GC 上的数据：空气峰（死时间）$t_0 = 0.50\ \pu{min}$，组分保留时间 $t_R = 4.50\ \pu{min}$，峰底宽 $W = 0.40\ \pu{min}$。

- **第一步，算调整保留时间**：$t_R' = t_R - t_0 = 4.50 - 0.50 = 4.00\ \pu{min}$——这才是该组分被固定相「真正留住」的时间。
- **第二步，算容量因子**：$k = \dfrac{t_R'}{t_0} = \dfrac{4.00}{0.50} = 8.0$——落在 $1\le k\le10$ 的理想区间，保留适中。
- **第三步，算理论塔板数**：$N = 16\left(\dfrac{t_R}{W}\right)^2 = 16\left(\dfrac{4.50}{0.40}\right)^2 = 2025$。<span class="marginnote">若相邻另一组分 $t_{R,2} = 5.00\ \pu{min}$、$W_2 = 0.43\ \pu{min}$，则分离度 $R_s = \dfrac{2(5.00-4.50)}{0.40+0.43} = 1.20$——略低于基线分离标准 1.5，两峰部分重叠。要提高分离度，先考虑提高 $\alpha$（换固定相/流动相），而不是盲目加长柱子。</span>

**这三个参数的工程含义**：$k$ 告诉你「要不要调流动相强度」（$k$ 太大则洗脱太慢）；$N$ 告诉你「柱子好不好」（$N$ 越大峰越窄）；$R_s$ 告诉你「分离够不够」（$R_s\ge1.5$ 才可定量）。色谱方法开发就是不断测这三个数、调一个变量、再测——循环直至 $R_s\ge1.5$ 且分析时间可接受。

**辨析｜易错点：**计算 $N$ 用的是 $t_R$（含死时间）还是 $t_R'$？教材惯例用 $t_R$ 与峰底宽 $W$（$N = 16(t_R/W)^2$）；但严格讨论柱效时应扣除死时间用调整保留时间。不同文献口径不同，比较 $N$ 时先确认用的是哪个——否则数值不可比。

## 7 常见色谱类型的选型速查

面对一个分离任务，先选色谱类型。四类主力各有所长：

| 色谱类型 | 固定相/流动相 | 适用样品 | 分离依据 |
| --- | --- | --- | --- |
| 气相色谱（GC） | 液体涂渍/气体 | 挥发性、热稳定有机物 | 沸点/极性 |
| 高效液相（HPLC） | 键合相/液体 | 极性、热不稳定、大分子 | 疏水性/极性 |
| 薄层色谱（TLC） | 板上涂层/液体 | 快速筛选、小样 | 分配/吸附 |
| 离子色谱（IC） | 离子交换树脂/电解质 | 阴阳离子 | 离子交换 |

**选型判断链**：先问「样品能气化吗」——能且热稳定走 GC；不能（极性、热不稳定、大分子）走 LC；要快速粗筛走 TLC；测无机离子走 IC。<span class="marginnote">HPLC 是当代色谱的主力：它不受挥发性限制，配合反相 C18 柱可覆盖绝大多数有机物。GC 的优势是分离效率高、与质谱联用成熟（GC-MS 谱库检索）；HPLC 的优势是样品面广、与 ESI 质谱联用覆盖生物大分子——两者互补而非取代。</span>

**辨析｜易错点：**「GC 比 HPLC 分离效率高」的适用范围。GC 的塔板数通常高于 HPLC（每米塔板数高一个量级），但只对「能气化」的样品成立。把某个挥发性差的极性化合物硬塞进 GC，结果不是不出峰就是分解——**选型先看样品属性，再看柱效高低**。

## 8 小结

- 色谱利用各组分在**固定相/流动相间分配差异**实现分离；分类有 GC、HPLC、TLC、离子交换色谱等。
- 基本参数：保留时间 $t_R$、死时间 $t_0$、调整保留时间 $t_R'$、**容量因子 $k = t_R'/t_0$**。
- **分离度 $R_s = \dfrac{2\Delta t_R}{W_1+W_2}$**，$R_s \ge 1.5$ 为基线分离标准。
- **分离度方程** $R_s = \dfrac{\sqrt{N}}{4}\cdot\dfrac{k}{1+k}\cdot\dfrac{\alpha-1}{\alpha}$ 给出三条提高分离度的路。
- **Van Deemter 方程** $H = A + B/u + Cu$ 解释峰展宽：涡流、纵向扩散、传质阻力；存在最佳流速。
