# 非确定性有限状态自动机与 Kleene 定理

## 为什么允许"不确定性"

确定性自动机（DFA）每个状态 + 输入只有唯一去处。但很多语言用"确定"来构造很绕，用"猜测"来构造很自然。**非确定性有限状态自动机（NFA）**允许一个状态 + 一个输入**有多个去处**，甚至允许**不读输入就转移**（$\lambda$ 转移）。NFA"同时尝试所有可能性"，只要**有一条路径**走到接受态就接受。奇妙的是：**NFA 并不比 DFA 强**——它们识别完全相同的语言（正则语言）。这是 Kleene 定理家族的一部分，也是"非确定性不增加计算能力（对有限状态）"的第一课。<span class="marginnote">NFA 是正则引擎的内部表示：Thompson 构造（上节）产生 NFA，子集构造（本节）转成 DFA 再执行——现代正则引擎大多走"正则→NFA→模拟"的路线。而"非确定性不增强能力"在有限状态成立、在更强调算模型（图灵机）也成立，是计算理论的一条主线。</span>

## 1 NFA 与 DFA 的差别

**NFA** $M = (S, I, f, s_0, F)$，其中转移函数允许：

1. **多值**：$f(s, x)$ 是状态的一个集合（可空、可多元素）。
2. **$\lambda$ 转移**：不读输入也能转移。

**DFA 是 NFA 的特例**：$f(s,x)$ 总是单元素集合（且无 $\lambda$ 转移）。

**接受条件**：读完整串后，**存在一条路径**停在接受态即接受——"存在"是 NFA 的关键词。

**例（NFA 的好处）**：识别"含子串 01 的 0/1 串"——NFA 用一个"猜测转移"（看到 0 就猜开始匹配 01），构造极简；DFA 要追踪"是否看到过 01"，状态多但也可做。

## 2 公式解析：NFA 的语言与 $\lambda$ 闭包

**$\lambda$ 闭包（$\lambda$-closure）**：状态 $s$ 的 $\lambda$-closure $\text{CL}(s)$ = 从 $s$ 只沿 $\lambda$ 边可达的状态集合。

**NFA 接受的定义**：串 $x = x_1 x_2 \dots x_k$ 被接受，若存在状态序列 $s_0 \to s_1 \to \dots \to s_k$，使 $s_{i} \in \text{CL}(f(s_{i-1}, x_i))$ 且 $s_k \in F$（$\lambda$ 转移随时可用）。

- **第一步，读 $\lambda$ 闭包**：读一个符号前，先免费走到所有 $\lambda$ 可达状态——"闭包"吸收所有无消耗转移。
- **第二步，读多路径**：$f(s_{i-1}, x_i)$ 给出多个候选，$s_i$ 从中任选（存在路径即可）。
- **第三步，读接受**：只要一个路径能到接受态。∎

**例**：NFA 状态 $s_0 \xrightarrow{0} s_1$、$s_1 \xrightarrow{\lambda} s_2$（$s_2$ 接受）。串 `0`：$s_0$ 读 0 到 $s_1$，$\text{CL}(s_1)$ 含 $s_2$，接受 ✓。

## 3 Kleene 定理

**定理（Kleene 定理）**：语言 $L$ 是正则的（能用正则表达式描述）⟺ $L$ 能被某个 FSA（DFA 或 NFA）识别。

**证明的两个方向**：

- **（⟸）自动机 → 正则表达式**：把自动机转成广义自动机，逐步删状态，每删一个状态把经过它的路径"合成"一个正则表达式，最后得到整机语言的正则表达式。过程繁琐但机械。
- **（⟹）正则表达式 → 自动机**：上节的 Thompson 构造给出 NFA。

**推论**：DFA、NFA、正则表达式、正则文法——**四者识别同一族语言**。

## 4 子集构造：NFA 到 DFA

**定理**：每个 NFA 都有等价的 DFA。

**子集构造法（subset construction）**：DFA 的每个状态 = NFA 的**状态集合**（含 $\lambda$ 闭包）：

- DFA 初态 = $\text{CL}(s_0)$。
- DFA 转移：状态 $T$（状态集）读 $x$ 到 $\text{CL}(\bigcup_{s\in T} f(s, x))$。
- DFA 接受态：含 NFA 接受态的状态集。

**例（转换）**：NFA 有状态 $\{a,b\}$、$a \xrightarrow{0} b$。DFA 状态 $\{a\}$ 读 0 → $\{b\}$。NFA 的"多路径"被 DFA 的"状态=集合"一次性吸收。

- **第一步，初态闭包**：DFA 从 NFA 的初态 $\lambda$ 闭包开始。
- **第二步，集合转移**：读符号后取所有可达状态（含 $\lambda$ 闭包）作为一个 DFA 状态。
- **第三步，接受判定**：集合里含接受态则 DFA 状态是接受态。∎

**为什么可行**：NFA 的状态数有限（$n$），其幂集的子集数 $2^n$ 有限——DFA 状态数最多 $2^n$（可能指数爆炸，但可构造）。**NFA 的"同时存在"被 DFA 的"集合状态"模拟**。

**辨析｜易错点：** 子集构造后 DFA 状态数**可能指数级**（$2^n$）——NFA 与 DFA 等价但"规模"可能差指数倍。题目常考"这个 NFA 转成 DFA 有几个状态"，要数清可达子集，别漏。

<span class="marginnote">"非确定性不增强能力"在有限自动机成立（子集构造），在更强调算模型同样成立（图灵机里的非确定版本 = 确定版本的等价类，NP 是另一个故事）。<strong>Kleene 定理 + 子集构造 = 正则语言完全理论</strong>：DFA/NFA/正则表达式三视图自由切换。第三级《计算理论》会把这套从"正则"一路推到"图灵机"。</span>

## 5 一个 NFA 设计实例与子集构造对照

用"NFA 简洁 vs DFA 繁琐"的对比，感受非确定性的威力与子集构造的必要。

**例**：识别"倒数第 3 个字符是 1"的 0/1 串语言。直觉上：需要"记住最近 3 位"。

**NFA 设计（很简洁）**：3 个状态 $s_0, s_1, s_2$ + 接受态 $s_3$：

- $s_0 \xrightarrow{1} s_1$（猜测"这里开始倒数第 3"）。
- $s_1 \xrightarrow{0,1} s_2$、$s_2 \xrightarrow{0,1} s_3$（接受）。
- 同时 $s_0 \xrightarrow{0,1} s_0$（继续扫描，随时重新猜测）。

**关键**：$s_0$ 读 1 时**同时**留在 $s_0$（继续猜）并进 $s_1$（开始数 3 位）——非确定性让"猜测 + 验证"并行。

**子集构造（转 DFA）**：DFA 状态是 NFA 状态子集。$s_0$ 读 1 → $\{s_0, s_1\}$；$\{s_0,s_1\}$ 读 0 → $\{s_0, s_2\}$、读 1 → $\{s_0,s_1,s_2\}$…… DFA 状态数可到 $2^3 = 8$（实际可达的更少）。

**公式解析：NFA 的"猜测"被 DFA 的"集合"吸收**

$$
\delta_{\text{DFA}}(\{q_1,\dots,q_k\}, x) = \bigcup_{i} \delta_{\text{NFA}}(q_i, x)
$$

- **第一步，读 NFA 一步**：$\delta_{\text{NFA}}(q, x)$ 返回状态**集合**（可能多个分支）。
- **第二步，读 DFA 一步**：DFA 把"NFA 可能所在的所有状态"打包成一个状态，读 $x$ 后取并集。
- **第三步，读等价**：DFA 的"集合状态"恰好追踪 NFA 的所有并行路径——**接受条件相同**（含接受态）。∎

**为什么"倒数第 3 个字符"要 8 状态**：需记住最近 3 位是 0/1——$2^3 = 8$ 种历史。NFA 用"猜起点"绕过记忆，DFA 老老实实记住。**NFA 把"记忆"换成"猜测"，代价是运行时并行追踪**。

**辨析｜易错点：** 子集构造里**空集状态**也要处理：NFA 状态集读某输入可能到 $\emptyset$——$\emptyset$ 是 DFA 的"死状态"（非接受、转移自环）。**别漏掉死状态**，否则 DFA 转移函数不完全。

**这个例子的要点**：NFA 的"多分支"让设计直觉化（猜 + 验证），子集构造把它确定化。**"非确定性 = 并行猜测"** 是理解 NFA 的一把钥匙，而"集合状态"把它落成可执行的 DFA。

## 6 小结

- **NFA**：转移可多值、可有 $\lambda$ 转移；存在路径到接受态即接受。
- **$\lambda$ 闭包**：沿 $\lambda$ 边可达的状态集，读符号前先吸收。
- **Kleene 定理**：正则语言 ⟺ FSA 识别——正则表达式 ⟷ 自动机双方向。
- **子集构造**：NFA → DFA（状态=集合），DFA 状态数 ≤ $2^n$。
- 非确定性对有限状态不增能力；正则引擎 = 正则→NFA→模拟。

**小结补记**：NFA 的"非确定性"看似强大，子集构造却证明它只是"确定性的并行模拟"——**表达力不变，只是状态数可能膨胀**。这个"非确定不增能力"的结论，是理解"为什么 NP 不等于 NTM 自动赢"的第一课。
