# 程序正确性：前置断言、后置断言与循环不变量

<div class="epigraph">
<p>程序不只要运行，更要能证明自己为什么是对的——把直觉变成不变量，把不变量变成结论。</p>

## 为什么程序需要"证明"

上一节我们用结构归纳证明了递归算法正确，但那只覆盖递归结构。一个任意的程序——一堆赋值、条件、循环——它的正确性怎么严格保证？直觉上"跑几个测试没问题"远远不够，因为测试只覆盖有限输入。**程序正确性（program correctness）** 理论给出的是：用**逻辑断言**描述程序"应当满足的性质"，再用规则证明程序**必然**满足。这一套由霍尔（C.A.R. Hoare）在 1969 年奠基，是软件工程里正式方法、以及编译器优化（验证不改变程序语义）的数学根。<span class="marginnote">这套理论在现代的化身是<strong>形式验证</strong>：航空航天、汽车、芯片的认证代码要用工具（如 Coq、Isabelle）机械地证明正确性。第三级《软件工程》里"测试不是正确性的保证"这句老话，正来自这里——测试证伪、证明才证真。</span>

## 1 断言与霍尔特三元组

**断言（assertion）**：一段关于程序变量状态的命题，写在程序某个位置的注释里。两种关键断言：

- **前置条件（precondition）**：程序/函数**执行前**必须为真的命题 $P$。
- **后置条件（postcondition）**：程序/函数**执行后**应当为真的命题 $Q$。

把两者与程序 $S$ 合起来，写成**霍尔特三元组（Hoare triple）**：

$$P\ \{S\}\ Q$$

读作："若执行前 $P$ 为真，则执行 $S$ 后 $Q$ 为真。" 它断言 $S$ 是**部分正确（partially correct）**的——在满足前置条件的前提下，运行结束后的状态满足后置条件。

**完全正确性** = 部分正确 + **终止性**（$S$ 对满足 $P$ 的输入必然终止）。两部分都要证：部分正确靠断言推理，终止性靠良基论证（变量严格下降）。

## 2 赋值与条件语句的规则

**赋值语句**的证明规则最微妙：要从后置条件**倒推**前置条件。对语句 `x := e`，若想证明执行后 $Q(x)$ 为真，则执行前必须 $Q(e)$ 为真（把 $Q$ 里所有 $x$ 换成表达式 $e$）。记作

$$\text{若 } Q(x) \text{ 真，则 } Q(e)\ \{x := e\}\ Q(x)$$

**实例**：证明 `y := 2` 使 $y$ 为偶数。后置条件是"$y$ 是偶数"，把 $y$ 换成 $2$ 得前置条件"$2$ 是偶数"——显然为真，于是语句正确。

**条件语句** `if c then S1 else S2` 的规则：前置条件 $P$ 且条件 $c$ 为真时，$S1$ 要达到后置 $Q$；$P$ 且 $c$ 为假时，$S2$ 要达到 $Q$。两条分支都要验证。

## 3 公式解析：循环不变量——循环的"归纳假设"

**循环不变量（loop invariant）**：一个在**循环每次迭代开始前**都为真的命题。它之于循环，正如归纳假设之于归纳法——循环的证明就是"归纳 + 终止"：

1. **初始化（initialization）**：进入循环前，不变量为真。
2. **保持（maintenance）**：若一次迭代开始前不变量为真，则迭代结束后它仍为真。
3. **终止（termination）**：循环终止后，不变量 + 循环结束条件 ⟹ 后置条件。

这三条正是归纳法的基础步、归纳步、结论——**循环不变量证明就是把归纳法套在循环上**。

**实例**：证明下面求和的程序把 `sum` 置为 $1+2+\dots+n$：

```
sum := 0
i := 1
while i <= n:
    sum := sum + i
    i := i + 1
```

取**循环不变量**：$P$："进入迭代时，$sum = 1+2+\dots+(i-1)$ 且 $1 \le i \le n+1$"。

- **初始化**：循环前 $i=1$、$sum=0$。$sum = 1+\dots+0$（空和）为 0，$1 \le i \le n+1$ 成立，$P$ 真。
- **保持**：设迭代前 $sum = 1+\dots+(i-1)$。执行 `sum := sum + i` 后 $sum = 1+\dots+i$；`i := i+1` 后新 $i' = i+1$，于是新 $sum = 1+\dots+(i'-1)$，$P$ 对新状态仍真。
- **终止**：循环在 $i > n$ 时退出，此时 $i = n+1$，而 $P$ 说 $sum = 1+\dots+(i-1) = 1+\dots+n$。后置条件达成。∎

**拆解**：这个不变量为什么这么选？因为它"既快照了已完成的工作（$sum$ 累加到 $i-1$），又标记了进度（$i$ 到了哪）"——一个不变量要能同时支撑保持性与终止后的结论。

**辨析｜易错点：** 不变量必须**每次迭代开始前都成立**，包括最后一次迭代开始前。很多人把不变量写成"循环结束后成立"的命题——那是后置条件不是不变量。另外，**不变量本身是归纳假设，证明保持时必须对一般性的迭代论证**，不能拿具体数字凑。

## 4 不变量是"找到的"而非"猜出的"

不变量往往不唯一，而且找它是工程直觉。常见来源：

- **进度变量**：`i` 的取值区间（如 $1 \le i \le n+1$）。
- **累加/累积变量**：`sum`、`product` 已经算出的部分和。
- **数据约束**：数组已排序、指针不越界、集合无重复。

**例**：二分搜索的循环不变量是"目标若存在，必在区间 `[low, high]` 内"。初始化时是全集；每次迭代收缩区间但不破坏"目标仍在其中"；终止时区间坍缩到一点，检查即得答案。**不变量就是"算法为什么没把答案弄丢"的书面证据**。<span class="marginnote">二分搜索的不变量在第三级《算法设计与分析》里是经典讲解对象；而"区间收缩不丢失候选"的思路，在第四级《大模型部署》的 beam search、top-p 采样里其实也是同一件事：<strong>候选集被约束却不被错误裁剪</strong>。</span>

## 5 一个含循环不变量的完整证明：幂运算

把"循环不变量三步"完整走在一个真实算法上——快速幂（也叫二分幂）。

**算法**：计算 $b^n$（$n$ 为正整数）：

```
result := 1
power := b
k := n
while k > 0:
    if k 是奇数:
        result := result * power
    power := power * power
    k := k // 2
```

**不变量**：$P$："$b^n = \text{result} \times \text{power}^k$"。

- **初始化**：循环前 result=1、power=b、k=n，$1 \times b^n = b^n$ ✓。
- **保持**：设迭代前 $b^n = r \times p^k$。若 $k$ 偶，$k' = k/2$、$p' = p^2$：$r \times (p^2)^{k/2} = r\times p^k$ ✓。若 $k$ 奇，$r' = rp$、$k' = (k-1)/2$、$p' = p^2$：$rp \times p^{k-1} = r p^k$ ✓。不变量保持。
- **终止**：$k = 0$ 时 $b^n = \text{result} \times \text{power}^0 = \text{result}$——返回 result 即 $b^n$。∎

**公式解析：为什么不变量如此设计**

$$
\underbrace{b^n}_{\text{待算}} = \underbrace{\text{result}}_{\text{已算出的部分}} \times \underbrace{\text{power}^k}_{\text{剩余部分}}
$$

- **第一步，读快照**：不变量把"已完成的（result）"与"未完成的（power^k）"分装，乘积守恒。
- **第二步，读转移**：$k$ 减半 ⟹ power 平方，乘积不变——**每步都维持"总量守恒"**。
- **第三步，读终止**：$k$ 归零时"剩余"消失，result 就是答案。∎

**这个不变量是"快速幂"正确性的完整证据**——比"跑几个例子"可靠得多。它也是"指数二进制展开"（前面模运算一节）的证明版。

**这个例子的要点**：循环不变量 = "总量守恒的快照"。**设计不变量：把答案拆成"已完成 × 剩余"两部分，使每步保持乘积不变**——这是累加/累积型算法的通用不变量模板。

**辨析｜易错点：** 不变量必须在**每次迭代开始前**成立，包括最后一次。证明"保持"时用的是"迭代前的 $k$、power"，别把"迭代后的值"提前代入。**先写迭代前状态，再算迭代后，验证等式不变**。

## 6 小结

- **程序正确性** = 部分正确（断言推理）+ 终止性（良基论证）。
- **霍尔特三元组** $P\ \{S\}\ Q$：前置条件满足则执行后满足后置条件。
- 赋值规则**从后置倒推前置**；条件语句分两分支验证。
- **循环不变量**三步：初始化、保持、终止⟹后置条件——循环版归纳法。
- 不变量要兼顾"已完成工作的快照"与"进度标记"。
