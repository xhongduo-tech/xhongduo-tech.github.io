## 为什么朴素的传递闭包太慢

上一节算传递闭包 $R^* = R \cup R^2 \cup \dots \cup R^n$ 要 $O(n^4)$ 次布尔运算。但 $n=1000$ 个顶点时，$10^{12}$ 次运算已经不可接受。**沃舍尔算法（Warshall's algorithm）** 用动态规划把复杂度降到 $O(n^3)$，思路极妙：不是"算路径长度"，而是"**逐步放开允许经过的中间顶点**"。它是动态规划思想的教科书级演示——也是弗洛伊德最短路算法（Floyd-Warshall）的直接前身。<span class="marginnote">沃舍尔算法与弗洛伊德最短路算法只差一行：把"布尔 OR"换成"取最小权值"。本节的中间顶点技巧，到第十一篇《最短通路》时会以 Floyd 算法再相见。而"逐步放开中转站"的思想，也是第四级《图神经网络》里多层消息传递的离散原型。</span>

## 1 核心思想：中间顶点逐步放开

设顶点集 $V = \{v_1, v_2, \dots, v_n\}$。定义 $W_k$：矩阵 $W_k$ 的 $(i,j)$ 位为 1，当且仅当存在一条从 $v_i$ 到 $v_j$ 的路径，**且路径的中间顶点只取自 $\{v_1, \dots, v_k\}$**（端点 $v_i, v_j$ 不算中间顶点，任意）。

- $W_0 = M_R$：中间顶点集为空，只能直接走一条边。
- $W_n = M_{R^*}$：中间顶点可取自全部顶点，任意路径都允许——正是传递闭包。

**递推关系**（动态规划的灵魂）：

$$W_{k}(i,j) = W_{k-1}(i,j) \ \lor\ (W_{k-1}(i,k) \land W_{k-1}(k,j))$$

**读法**：允许中间顶点到 $v_k$ 时，$i$ 到 $j$ 可达，要么**不经过 $v_k$**（保持 $W_{k-1}(i,j)$），要么**经过 $v_k$**（$i$ 到 $v_k$ 且 $v_k$ 到 $j$，且这两段的中间顶点都不超过 $v_{k-1}$）。

## 2 公式解析：递推式为什么正确

$$
W_k(i,j) = W_{k-1}(i,j) \lor \left( W_{k-1}(i,k) \land W_{k-1}(k,j) \right)
$$

- **第一步，分两类路径**：从 $v_i$ 到 $v_j$、中间顶点 ≤ $v_k$ 的路径，要么不经过 $v_k$，要么经过 $v_k$。
- **第二步，处理"不经过 $v_k$"**：这类路径的中间顶点其实 ≤ $v_{k-1}$，正是 $W_{k-1}(i,j)$。
- **第三步，处理"经过 $v_k$"**：路径被 $v_k$ 切成两段——$v_i$ 到 $v_k$、$v_k$ 到 $v_j$，两段的中间顶点都 ≤ $v_{k-1}$（$v_k$ 是端点不是中间点），分别对应 $W_{k-1}(i,k)$ 与 $W_{k-1}(k,j)$。
- **第四步，合并**：两情形之一成立即可达，用 $\lor$ 合并。∎

**为什么$W_{k-1}(i,k)$ 和 $W_{k-1}(k,j)$ 的中间顶点 ≤ $v_{k-1}$**：因为 $v_k$ 是这两段的端点，不算中间顶点；其余中间顶点按定义不超过 $v_{k-1}$。这正是递推式的"无后效性"保证。

## 3 算法的执行过程

**沃舍尔算法**（设 $W^{(0)} = M_R$，$W^{(k)}$ 表示第 $k$ 轮）：

```
procedure Warshall(M_R, n)
    W := M_R
    for k := 1 to n:            # 放开中间顶点 v_k
        for i := 1 to n:
            for j := 1 to n:
                W[i][j] := W[i][j] or (W[i][k] and W[k][j])
    return W                    # 即 M_{R*}
```

**实例**：$V = \{1,2,3\}$，$R = \{(1,2),(2,3),(3,1)\}$（一个 3-圈）。$W_0$ 对应边 $(1,2),(2,3),(3,1)$。

- **k=1**：放开顶点 1。检查 $(i,1)$ 与 $(1,j)$ 都 1 的配对。$(3,1)$ 且 $(1,2)$ ⟹ 新增 $(3,2)$。$W_1$ 加 $(3,2)$。
- **k=2**：放开顶点 2。$(1,2)$ 且 $(2,3)$ ⟹ $(1,3)$；$(3,2)$ 且 $(2,3)$ ⟹ $(3,3)$（新增自环）。$W_2$ 加 $(1,3)$、$(3,3)$。
- **k=3**：放开顶点 3。$(2,3)$ 且 $(3,1)$ ⟹ $(2,1)$；$(1,3)$ 且 $(3,1)$ ⟹ $(1,1)$；$(3,3)$ 且 $(3,1)$ ⟹ $(3,1)$（已有）。$W_3$ 加 $(2,1)$、$(1,1)$。

最终 $W_3$ 全 1——在 3-圈上任意两点互相可达，正确。

**复杂度**：三重循环，$O(n^3)$ 次布尔运算；空间 $O(n^2)$（原地更新矩阵）。

## 4 正确性证明：不变式

**循环不变量**：第 $k$ 轮结束时，$W[i][j] = 1$ 当且仅当 $v_i$ 到 $v_j$ 存在中间顶点只取自 $\{v_1,\dots,v_k\}$ 的路径。

- **初始化**：$W^{(0)} = M_R$，中间顶点集为空——边即路径，成立。
- **保持**：假设 $W^{(k-1)}$ 满足不变量。第 $k$ 轮更新 $W[i][j] \gets W[i][j] \lor (W[i][k] \land W[k][j])$。由递推式，更新后 $W^{(k)}(i,j)$ 恰为"中间顶点 ≤ $v_k$ 的可达性"——不变量保持。
- **终止**：$k = n$ 时，中间顶点可取任意顶点，$W^{(n)} = M_{R^*}$。∎

这正是一节循环不变量证明（第七篇）的标准应用——**不变量 + 递推式 = 算法正确性的完整证据**。

**辨析｜易错点：** 三层循环的**顺序不能乱**——$k$ 必须是外层。若把 $k$ 放内层，$W[i][k]$ 会在本轮中被更新，破坏递推式"只依赖上一轮 $W^{(k-1)}$"的前提。沃舍尔算法的正确性**依赖 $k$ 外层**，这是实现时最隐蔽的坑。

<span class="marginnote">沃舍尔算法是"<strong>最短路动态规划</strong>"的入门台阶：把布尔矩阵换成权值矩阵、$\land$ 换成加法、$\lor$ 换成取最小，就得到 Floyd 算法（$O(n^3)$ 求全源最短路）。第十一篇《最短通路》会再见面。它也是理解"DP 状态设计 = 逐步放开限制"的最佳范本。</span>

## 5 沃舍尔算法与弗洛伊德最短路：一字之差

沃舍尔算法最精彩的延伸是——**把布尔矩阵换成权值矩阵，就得到弗洛伊德最短路算法**。两者共享同一个动态规划骨架。

**弗洛伊德算法（Floyd）**：$D_k(i,j)$ = 从 $i$ 到 $j$ 的、中间顶点 ≤ $v_k$ 的**最短**路径长度。

$$
D_k(i,j) = \min\big(D_{k-1}(i,j), \ D_{k-1}(i,k) + D_{k-1}(k,j)\big)
$$

**对比沃舍尔**：

| | 沃舍尔（可达性） | 弗洛伊德（最短路） |
| --- | --- | --- |
| 值 | 0/1（是否可达） | 距离（最短长度） |
| 运算 | $\lor$（或） | $\min$（取最小） |
| 合并 | $\land$（且） | $+$（相加） |
| 初值 | $M_R$ | 权值矩阵 |

**公式解析：为什么"换运算"就换算法**

动态规划的骨架完全一样——"经过 $v_k$ 是否更好"：

$$
W_k = W_{k-1} \lor (W_{k-1}^{(i,k)} \land W_{k-1}^{(k,j)}), \qquad D_k = \min(D_{k-1}, D_{k-1}^{(i,k)} + D_{k-1}^{(k,j)})
$$

- **第一步，读共同骨架**：两者都在问"允许经过 $v_k$ 后，$i$ 到 $j$ 是否改善"。
- **第二步，读沃舍尔的布尔语义**：$i$ 到 $k$ 可达**且** $k$ 到 $j$ 可达 ⟹ $i$ 到 $j$ 可达。
- **第三步，读弗洛伊德的加权语义**：$i$ 到 $k$ 最短路 + $k$ 到 $j$ 最短路，取 $\min$。∎

**这个对比的价值**：**理解"算法家族"比记忆单个算法更有效**——同一动态规划思想，布尔版管可达、加权版管最短路。第十一篇《最短通路》里弗洛伊德会正式登场。

**辨析｜易错点：** 弗洛伊德要求**无负环**（负权边可，负权回路不可——否则最短路无穷小）。沃舍尔无此问题（布尔）。**用弗洛伊德前先确认无负环**，否则 $\min$ 可能无限收缩。

**这个例子的要点**：沃舍尔与弗洛伊德是"一个 DP 骨架的两种填料"。**"可达（布尔）"与"最短（加权）"的类比**，是理解图算法家族的统一视角——从传递闭包到最短路，只有一步之遥。

## 6 小结

- **核心思想**：逐步放开"允许经过的中间顶点"，$W_0 \to W_1 \to \dots \to W_n = M_{R^*}$。
- **递推式** $W_k(i,j) = W_{k-1}(i,j) \lor (W_{k-1}(i,k) \land W_{k-1}(k,j))$。
- 三重循环 $O(n^3)$、空间 $O(n^2)$，原地更新。
- **正确性**靠循环不变量：第 $k$ 轮后记录"中间顶点 ≤ $v_k$"的可达性。
- $k$ 必须在最外层；弗洛伊德最短路是它的加权版本。
