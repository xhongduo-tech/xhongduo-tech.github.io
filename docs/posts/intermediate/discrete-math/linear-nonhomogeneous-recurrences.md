## 为什么"非齐次"更接近现实

前两节的齐次递推右边是 0（即 $a_n - c_1 a_{n-1} - \dots = 0$）。但真实模型常常带"外力"：汉诺塔 $H_n = 2H_{n-1} + 1$ 右边的 $+1$ 是"每次都要多动一次大圆盘"；存款模型 $P_n = 1.05P_{n-1} + 100$ 的 $+100$ 是每月追加的存款。这类递推叫**线性非齐次（linear nonhomogeneous）**。解法仍是标准两段式：**齐次通解 + 一个特解**——这与微分方程里"通解 = 齐次解 + 特解"完全同构。<span class="marginnote">非齐次递推在工程里到处是：房贷每月固定还款、算法分析里分治递推的 $+cn$ 项、信号处理里差分方程的输入信号。它的"通解 + 特解"结构与微分方程相通的这一事实，值得反复强调——离散与连续共享同一套线性理论。</span>

## 1 非齐次递推的定义与结构

**线性非齐次递推**：$a_n = c_1 a_{n-1} + \dots + c_k a_{n-k} + F(n)$，其中 $F(n)$ 是**已知的**关于 $n$ 的函数（称为"驱动项"）。$F(n) \equiv 0$ 时退化回齐次。

**结构定理（叠加原理）**：若 $a_n^{(p)}$ 是非齐次递推的**一个特解**，且 $a_n^{(h)}$ 是对应齐次递推（去掉 $F(n)$）的**通解**，则非齐次递推的通解是

$$a_n = a_n^{(h)} + a_n^{(p)}$$

**为什么**：把 $a_n^{(h)} + a_n^{(p)}$ 代入非齐次递推，齐次部分贡献 0、特解贡献 $F(n)$，两边相等。两个自由参数来自齐次通解，由初始条件确定。

## 2 特解的选取：猜测表

特解的选取靠"跟着驱动项的形式猜"，有标准对照表：

| 驱动项 $F(n)$ | 特解形式 |
| --- | --- |
| 常数 $c$ | $A$（常数） |
| $n$ 的 $d$ 次多项式 | $n$ 的 $d$ 次多项式（全部系数待定） |
| $s^n$（$s$ 不是特征根） | $A s^n$ |
| $s^n$（$s$ 是特征根，重数 $m$） | $A n^m s^n$ |

**例（汉诺塔）** $H_n = 2H_{n-1} + 1$：

- **齐次通解**：$H_n^{(h)} = \alpha \cdot 2^n$（特征根 2）。
- **特解**：$F(n) = 1$ 是常数，猜 $H_n^{(p)} = A$。代入：$A = 2A + 1$，解得 $A = -1$。
- **通解**：$H_n = \alpha \cdot 2^n - 1$。
- **初始条件** $H_1 = 1$：`$2`\alpha - 1 = 1$，$\alpha = 1$。得 $H_n = 2^n - 1$。

与上一节"展开找规律"的结果完全一致——现在它是机械推导出来的，不需要灵感。

## 3 公式解析：多项式驱动项的特解

**例**：解 $a_n = a_{n-1} + n$，$a_0 = 0$。

- **第一步，齐次通解**：特征方程 $r - 1 = 0$，根 1，$a_n^{(h)} = \alpha \cdot 1^n = \alpha$（常数）。
- **第二步，猜特解**：$F(n) = n$ 是一次多项式，猜 $a_n^{(p)} = An + B$（一次多项式，含全部系数）。
- **第三步，代入定系数**：

$$
An + B = A(n-1) + B + n = An - A + B + n = (A+1)n + (B - A)
$$

比较系数：$A = A+1$？——不，右边 $n$ 的系数是 $A+1$，左边是 $A$，矛盾。**说明猜错了，需要升级猜测**。

- **第四步，升级**：猜 $a_n^{(p)} = An^2 + Bn$（二次）。代入：

$$
An^2 + Bn = A(n-1)^2 + B(n-1) + n = An^2 - 2An + A + Bn - B + n
$$

比较系数：$n^2$ 项 $A = A$ ✓；$n$ 项 $B = -2A + B + 1$ ⟹ $A = 1/2$；常数项 `$0` = A - B$ ⟹ $B = 1/2$。特解 $a_n^{(p)} = \frac12 n^2 + \frac12 n$。

- **第五步，通解**：$a_n = \alpha + \frac12(n^2 + n)$。初始条件 $a_0 = 0$：$\alpha = 0$。得

$$
a_n = \frac{n(n+1)}{2}
$$

这正是前 $n$ 个自然数之和——验算 $a_3 = 6$，`$1`+2+3 = 6$。∎

**辨析｜易错点：** 特解猜测**可能不够**（如上例 $An+B$ 失败）。原因：$F(n) = n$ 与齐次解 $\alpha$ 的"常数项"结构冲突。规则：**若驱动项与齐次通解的某个解"共振"（形式相同），特解要乘以 $n$ 的幂升级**。遇到矛盾就升级猜测，这是标准流程。

## 4 共振情形：驱动项撞上特征根

**例**：$a_n = 2a_{n-1} + 2^n$，$a_0 = 1$。特征根是 2，驱动项 `$2`^n$ 正好是特征根对应的指数。

- **猜特解失败**：$A \cdot 2^n$ 代入：$A2^n = 2A2^{n-1} + 2^n = A2^n + 2^n$ ⟹ `$0` = 2^n$，矛盾。
- **升级猜测**：$A n \cdot 2^n$（乘 $n$）。代入：$A n 2^n = 2A(n-1)2^{n-1} + 2^n = A(n-1)2^n + 2^n$ ⟹ $An = A(n-1) + 1$ ⟹ $A = 1$。
- **特解** $a_n^{(p)} = n 2^n$；齐次通解 $\alpha 2^n$；通解 $a_n = \alpha 2^n + n 2^n$。$a_0 = 1$ 得 $\alpha = 1$。

$$
a_n = 2^n + n 2^n = (n+1)2^n
$$

**共振规则**：驱动项 $s^n$ 且 $s$ 是特征根（重数 $m$），特解取 $A n^m s^n$。这与重根情形"$n^j r_0^n$"的补全逻辑一脉相承。

<span class="marginnote">"共振"在物理里是同一件事：系统固有频率与驱动力频率相同，振幅随 $n$ 线性放大。差分方程的共振解 $n s^n$，对应微分方程里强迫振动频率等于固有频率时的<span><strong>$t e^{rt}$ 发散解</strong>。离散数学又一次与物理同构。</span></span>

## 5 多项式驱动项的特解：一个"多次尝试"的完整例子

特解猜测"猜错再升级"是正常流程，用一个二阶例子展示完整路径。

**例**：解 $a_n = 2a_{n-1} + n$，$a_0 = 1$。

- **齐次通解**：特征根 2，$a_n^{(h)} = \alpha 2^n$。
- **猜特解**：$F(n) = n$ 一次多项式，猜 $a_n^{(p)} = An + B$。代入：

$$
An + B = 2(A(n-1) + B) + n = 2An - 2A + 2B + n
$$

比较系数：$n$ 项 $A = 2A + 1 \implies A = -1$；常数项 $B = -2A + 2B \implies B = 2A = -2$。特解 $a_n^{(p)} = -n - 2$。这次**没失败**（因为齐次根 2 不是 $n$ 多项式驱动的"共振源"——驱动是多项式，齐次解是指数，不冲突）。

- **通解**：$a_n = \alpha 2^n - n - 2$。初始条件 $a_0 = 1$：$\alpha - 2 = 1 \implies \alpha = 3$。
- **解**：$a_n = 3\cdot 2^n - n - 2$。

**验算**：$a_1 = 6 - 3 = 3$；递推 `$2`\cdot1 + 1 = 3$ ✓。$a_2 = 12 - 4 = 8$；递推 `$2`\cdot3 + 2 = 8$ ✓。

**公式解析：为什么"猜同次多项式"通常够用**

驱动 $F(n)$ 是 $d$ 次多项式，特解也猜 $d$ 次多项式 $An+B$（一次猜一次）——代入后比较系数，$d+1$ 个方程解 $d+1$ 个未知数。

- **第一步，猜形**：$d$ 次驱动 ⟹ 猜 $d$ 次多项式（全部系数待定）。
- **第二步，代入**：展开右边，比较 $n$ 的各次幂系数。
- **第三步，解系数**：得 $d+1$ 元一次方程组。∎

**什么时候要升级**：驱动多项式与齐次解"结构冲突"（如 $F(n)$ 是常数、齐次根是 1——常数函数与 $\alpha\cdot1^n$ 共振），此时特解要乘 $n$。**升级的判据是"驱动形式与齐次解的某成员相同"**。

**辨析｜易错点：** 比较系数时**逐项对齐**——$n$ 的每个幂次都单独列方程，别把常数项与 $n$ 项混在一处。**"同次幂系数相等"是唯一正确的方法**。

**这个例子的要点**：非齐次求解 = "齐次通解 + 猜特解 + 定系数"三件套。**多项式驱动猜同次多项式，代入比较系数**——机械、可验、不易错，是标准流程。

## 6 小结

- **非齐次递推** = 齐次递推 + 驱动项 $F(n)$；通解 = 齐次通解 + 特解。
- 特解按驱动项形式**猜**：常数→常数、多项式→同次多项式、$s^n$→$As^n$。
- 猜测矛盾时**升级**：驱动项与齐次解共振则乘 $n$（重数 $m$ 乘 $n^m$）。
- 汉诺塔、自然数求和都是非齐次递推的标准解。
- 与微分方程共享"齐次解 + 特解"的线性理论。
