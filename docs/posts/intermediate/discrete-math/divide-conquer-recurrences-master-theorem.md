## 为什么分治递推需要"主定理"

第七篇的递归算法（二分搜索、归并排序、找最大值）复杂度都长成同一个形状：

$$f(n) = a f(n/b) + g(n)$$

把规模 $n$ 的问题分成 $a$ 个规模 $n/b$ 的子问题，再把子结果合并，合并代价 $g(n)$。这类**分治递推关系（divide-and-conquer recurrence）**出现频率极高，一个个展开太慢。**主定理（master theorem）** 给出一张"查表"：看一眼 $a$、$b$、$g(n)$，直接读出 $f(n) = \Theta(\dots)$。它把"解递推"变成"套公式"，是算法分析效率手册里最实用的一页。<span class="marginnote">主定理在第三级《算法设计与分析》和《数据结构》里是复杂度分析的标准工具：归并排序 $\Theta(n\log n)$、二分搜索 $\Theta(\log n)$、斯特拉森矩阵乘法 $\Theta(n^{2.807})$ 全是它的案例。掌握它，等于掌握一批经典算法的复杂度"批量生产"能力。</span>

## 1 分治递推的标准形式

**分治递推**：$f(n) = a f(n/b) + g(n)$，其中 $a \ge 1$、$b > 1$ 是常数，$g(n)$ 是合并代价，$f(1) = c$ 是基础情形。

**例**：

- 二分搜索：$f(n) = f(n/2) + 1$（$a=1, b=2, g=1$）。
- 找最大值：$f(n) = 2f(n/2) + 1$（$a=2, b=2, g=1$）。
- 归并排序：$f(n) = 2f(n/2) + n$（$a=2, b=2, g=n$）。
- 朴素矩阵乘法（分块）：$f(n) = 8f(n/2) + n^2$（$a=8, b=2, g=n^2$）。

**直觉**：$a$ 是"分几路"，$b$ 是"每路缩小几倍"，$g(n)$ 是"合并与切分的成本"。三者的相对大小决定总复杂度。

## 2 公式解析：主定理

**主定理**：设 $f(n) = a f(n/b) + g(n)$（$a \ge 1$、$b > 1$），且 $g(n)$ 是"好的"函数。记 $n^{\log_b a}$ 为关键比较量，则：

1. 若 $g(n) = O(n^{\log_b a - \epsilon})$（$\epsilon > 0$），则 $f(n) = \Theta(n^{\log_b a})$——**叶层主导**；
2. 若 $g(n) = \Theta(n^{\log_b a})$，则 $f(n) = \Theta(n^{\log_b a} \log n)$——**均衡**；
3. 若 $g(n) = \Omega(n^{\log_b a + \epsilon})$ 且满足正则条件，则 $f(n) = \Theta(g(n))$——**根层主导**。

拆解这三条：

- **第一步，算关键指数** $\log_b a$：它衡量"递归树有多少片叶子"。$a$ 个子问题、每层规模除以 $b$，树高 $\log_b n$，叶子数 $a^{\log_b n} = n^{\log_b a}$。
- **第二步，比较合并代价与叶子量**：若合并代价 $g(n)$ **小于**叶子量（情形 1），总代价由叶子主导；若**等于**（情形 2），每层代价相同，层数 $\log n$ 倍增；若**大于**（情形 3），根层（第一次合并）主导。
- **第三步，代入查表**：把 $a, b, g$ 代进三种情形之一，直接读 $\Theta$。

## 3 主定理的三个实例

**例 1（归并排序）**：$f(n) = 2f(n/2) + n$。$n^{\log_2 2} = n$，$g(n) = n$ 与它同阶 ⟹ 情形 2：$f(n) = \Theta(n \log n)$。

**例 2（二分搜索）**：$f(n) = f(n/2) + 1$。$n^{\log_2 1} = n^0 = 1$，$g(n) = 1$ 同阶 ⟹ 情形 2：$f(n) = \Theta(1 \cdot \log n) = \Theta(\log n)$。

**例 3（朴素分块矩阵乘法）**：$f(n) = 8f(n/2) + n^2$。$n^{\log_2 8} = n^3$，$g(n) = n^2 = O(n^{3-\epsilon})$ ⟹ 情形 1：$f(n) = \Theta(n^3)$。

这三个结果与直觉完全吻合：归并排序要 $\log n$ 层、每层合并 $O(n)$；二分搜索每层只做常数工作但只有 $\log n$ 层；矩阵乘法分 8 路导致立方。

<span class="marginnote">主定理揭示的核心思想：<strong>分治复杂度的三种形态由"叶子数 $n^{\log_b a}$"与"单层合并代价 $g(n)$"的赛跑决定</strong>。谁赢谁主导。这个"赛跑"直觉比背三条情形更重要——遇到主定理覆盖不到的形式，也靠它判断方向。</span>

## 4 主定理之外的展开法

当 $g(n)$ 不满足主定理条件（如 $g(n) = n/\log n$、$g(n)$ 带对数平方），退回**递归树/展开法**。

**例**：$f(n) = 2f(n/2) + n \log n$。主定理情形 2 的条件要求 $g(n) = \Theta(n)$，这里多了 $\log n$，属于"情形 2 与 3 之间"。展开递归树：

$$
f(n) = n\log n + 2 \cdot \frac{n}{2}\log\frac{n}{2} + 4 \cdot \frac{n}{4}\log\frac{n}{4} + \cdots
$$

第 $j$ 层总代价 $= n(\log n - j)$。求和 $j = 0$ 到 $\log n$：

$$
f(n) = n\sum_{j=0}^{\log n}(\log n - j) = n \cdot \frac{(\log n)(\log n + 1)}{2} = \Theta(n\log^2 n)
$$

**要点**：展开法分三步——画递归树、数每层总代价、求和。它是主定理的后备方案，也是理解主定理"为什么"的钥匙。

**辨析｜易错点：** 主定理情形 1 与 3 的 $\epsilon$ 不能是 0。若 $g(n) = n^{\log_b a}\log n$，它既不是 $O(n^{\log_b a - \epsilon})$ 也不是 $\Theta(n^{\log_b a})$——主定理不适用，要回到展开法。**"差一个对数因子"是主定理的典型盲区**。

## 5 主定理的"为什么"：递归树视角

三条情形不是黑箱——用**递归树**展开就能看出谁主导。设 $f(n) = a f(n/b) + g(n)$。

**递归树的结构**：根节点代价 $g(n)$，第一层 $a$ 个节点各 $g(n/b)$，第二层 $a^2$ 个各 $g(n/b^2)$…… 第 $k$ 层总代价 $= a^k g(n/b^k)$。树高 $\log_b n$，叶子层有 $a^{\log_b n} = n^{\log_b a}$ 个叶子。

**公式解析：三情形的总代价**

$$
f(n) = \sum_{k=0}^{\log_b n} a^k g(n/b^k)
$$

- **第一步，读等比结构**：每层代价是"节点数 $a^k$ × 单节点代价 $g(n/b^k)$"。
- **第二步，读几何级数**：
  - $g(n) = n^{\log_b a}$（均衡）：每层代价相同，共 $\log_b n$ 层 ⟹ $\Theta(n^{\log_b a}\log n)$。
  - $g(n)$ 更小（叶层主导）：几何级数以叶子项（$k = \log_b n$）为主 ⟹ $\Theta(n^{\log_b a})$。
  - $g(n)$ 更大（根层主导）：首项（$k=0$）为主 ⟹ $\Theta(g(n))$。
- **第三步，读赛跑**：$g(n)$ 与 $n^{\log_b a}$ 谁大，谁主导——**这是三条情形的统一直觉**。∎

**例（直观验证）**：归并排序 $f(n)=2f(n/2)+n$：每层节点数 $2^k$、单节点 $n/2^k$，每层总代价 $n$，共 $\log_2 n$ 层 ⟹ $n\log n$。与主定理情形 2 一致。

**这个例子的要点**：主定理不是咒语，而是"几何级数求和"的查表结果。**记住"叶子数 $n^{\log_b a}$ 与单层合并代价 $g(n)$ 的赛跑"**，遇到主定理边界情形（差对数因子）也能凭直觉判断方向。

## 6 小结

- **分治递推** $f(n) = a f(n/b) + g(n)$；$a$ 路分、$b$ 倍缩、$g$ 合并代价。
- **主定理**：以 $n^{\log_b a}$ 为界，比较 $g(n)$ 落在小于/等于/大于——对应叶层、均衡、根层主导。
- 实例：归并 $\Theta(n\log n)$、二分 $\Theta(\log n)$、朴素分块矩阵 $\Theta(n^3)$。
- 情形 1/3 需要"严格小于/大于"；差对数因子时主定理失效。
- 展开法（递归树）是通用后备，也是理解主定理的钥匙。

**再辨析｜易错点：** 主定理要求"$a$ 个子问题、每个规模 $n/b$"——**子问题规模必须相等（或近似相等）**。若子问题规模不等（如 $T(n) = T(n/3) + T(2n/3) + n$），主定理不直接适用，需回到递归树分析。**先核对"均分子问题"再套主定理**。

**小结补记**：分治递推 + 主定理 = 分治算法的"复杂度查表"。**"叶子数 $n^{\log_b a}$ 与合并代价 $g(n)$ 的赛跑"** 是贯穿三情形的主线——记住它，比背三条情形更可靠。下一节的生成函数是解递推的另一种通用武器，两者互补。

**快速自测**：$T(n) = 2T(n/2) + n$ 的复杂度？$n^{\log_2 2} = n$，$g(n) = n$ 同阶 ⟹ 情形 2：$\Theta(n\log n)$（归并排序）。**先算 $n^{\log_b a}$，再比 $g(n)$**——三步查表。
