## 为什么最短路是图的"第一算法"

图上最实用的问题：从 $a$ 到 $b$ 怎么走最近？**最短通路问题（shortest path problem）**是导航、路由、网络规划的核心。**迪克斯特拉算法（Dijkstra's algorithm）**在带非负权的图上求单源最短路径，是贪心算法的教科书范例——它每步"贪心地"确定一个最近顶点，并用**交换论证**证明贪心没错。学会它，等于同时学会了一个经典算法和一种证明套路。<span class="marginnote">迪克斯特拉算法是互联网路由（OSPF、链路状态协议）、地图导航、社交网络六度分隔的底层引擎。带负权边时它失效，要用贝尔曼-福特算法；多源全源最短路用弗洛伊德算法。这些在第三级《算法设计与分析》里都会系统展开。</span>

## 1 问题与算法

**问题**：带非负权无向/有向图，给定源点 $s$，求 $s$ 到每个顶点的最短距离。

**迪克斯特拉算法**：维护集合 $S$（已确定最短距离的顶点）与距离数组 $d$（当前最短估计）。

```
procedure Dijkstra(G, w, s)
    for each v: d[v] := ∞
    d[s] := 0; S := ∅
    while S 不含所有顶点:
        选 u ∉ S 使 d[u] 最小       # 贪心：最近未定顶点
        把 u 加入 S
        for each 边 (u, z):
            if d[u] + w(u,z) < d[z]:
                d[z] := d[u] + w(u,z)   # 松弛
```

**松弛（relaxation）**：用 $u$ 更新 $z$ 的距离——"经过 $u$ 可能更近"。

## 2 完整实例

**例**：顶点 $a,b,c,d$，边：$a\!-\!b$ 权 2、$a\!-\!c$ 权 5、$b\!-\!c$ 权 1、$b\!-\!d$ 权 6、$c\!-\!d$ 权 3。源点 $a$。

- 初始化：$d[a]=0$、其余 ∞。$S=\emptyset$。
- 选 $a$：$d[a]=0$ 最小，入 $S$。松弛：$d[b]=2$、$d[c]=5$。
- 选 $b$（$d=2$ 最小）：入 $S$。松弛：$d[c] = \min(5, 2+1)=3$、$d[d] = \min(∞, 2+6)=8$。
- 选 $c$（$d=3$）：入 $S$。松弛：$d[d] = \min(8, 3+3)=6$。
- 选 $d$（$d=6$）：入 $S$。完成。

结果：$a$ 到 $b,c,d$ 最短距离 2、3、6。注意 $b\!-\!c$ 权 1 使"经 $b$ 到 $c$"（2+1=3）优于"直接 $a\!-\!c$"（5）——**松弛捕捉了这条捷径**。

## 3 公式解析：正确性（交换论证）

**定理**：迪克斯特拉算法正确——每次把 $u$ 加入 $S$ 时，$d[u]$ 就是 $s$ 到 $u$ 的真实最短距离。

**证明（归纳于加入次序）**：

- **第一步，归纳基础**：$s$ 第一个被选，$d[s]=0$ 正确。
- **第二步，归纳假设**：$S$ 中所有顶点的 $d$ 值都是真实最短距离。
- **第三步，关键论断**：设 $u$ 是 $S$ 外 $d$ 值最小的顶点，要证 $d[u]$ 是真实最短。取任何一条 $s$ 到 $u$ 的真实最短路径 $P$，它第一次离开 $S$ 时经过某顶点 $y \notin S$（令 $x \in S$ 是 $P$ 上最后一个 $S$ 内顶点）。
- **第四步，比较**：$P$ 的长度 ≥ $d[x] + w(x,y) \ge d[y] \ge d[u]$（第一个 ≥ 因 $d[x]$ 是真实最短；第二个 ≥ 因松弛过；第三个 ≥ 因 $u$ 是 $S$ 外最小）。而 $d[u]$ 是某条 $s$ 到 $u$ 路径的长度，故它 ≥ 真实最短。合起来 $d[u]$ = 真实最短。∎

**这个证明是"交换论证"的变体**：任何潜在更短路径都必须"离开 $S$"经过某个未定顶点 $y$，而 $y$ 已被 $d[u]$ 压制——**贪心选择（最小 $d$）保证没有外部路径能偷袭**。这正是第五篇贪心正确性论证的标准形态。

**辨析｜易错点：** 迪克斯特拉**要求非负权**。负权边会破坏"$d[u]$ 最小即真实"的论断（可能先绕远路取负权再来便宜）。带负权要用贝尔曼-福特。**看到负权，换算法**。

## 4 复杂度与实现

**朴素实现**：每轮扫描全部未定顶点找最小（$O(n)$），共 $n$ 轮，总 $O(n^2)$。

**堆优化**：用最小堆维护"未定顶点的 $d$"，选最小 $O(\log n)$、松弛更新 $O(\log n)$，总 $O((n+m)\log n)$——稀疏图上远优于朴素。

| 实现 | 时间复杂度 |
| --- | --- |
| 朴素（数组扫描） | $O(n^2)$ |
| 二叉堆 | $O((n+m)\log n)$ |
| 斐波那契堆 | $O(n\log n + m)$ |

**为什么贪心在这里可行**：非负权保证"已定 $S$ 外的最近点"再也不可能被别的路径超过——这就是"贪心正确性"的关键条件。**结构让贪心不再是冒险，而是必然**。

<span class="marginnote">迪克斯特拉算法的思想延伸极广：<strong>A\* 搜索</strong>（用启发式引导优先队列）、<strong>迪克斯特拉堆优化</strong>（网络路由的标准实现）都是它的直接后代。第四级《大模型部署》里"路由、调度"的图模型、知识图谱的最短语义路径，也常用它的思想。</span>

## 5 迪克斯特拉 vs 其他最短路算法

最短路问题有多个算法，各自适用不同的图。把迪克斯特拉放进全景里定位：

| 算法 | 适用范围 | 复杂度 | 思路 |
| --- | --- | --- | --- |
| 迪克斯特拉 | 单源、非负权 | $O((n+m)\log n)$ | 贪心 + 优先队列 |
| 贝尔曼-福特 | 单源、可负权 | $O(nm)$ | 松弛 $n-1$ 轮 |
| 弗洛伊德 | 全源 | $O(n^3)$ | 动态规划（中间顶点） |
| BFS | 单源、无权 | $O(n+m)$ | 逐层扩展 |

**为什么迪克斯特拉不能处理负权**：负权边会破坏"$d[u]$ 最小即真实"的贪心论断——可能先绕远路吃到负权、再绕回来反而更短。贝尔曼-福特用"松弛 $n-1$ 轮"硬扛负权，代价是更慢。

**公式解析：一个负权反例**

图：$s \to a$ 权 2、$s \to b$ 权 5、$b \to a$ 权 $-3$。求 $s$ 到 $a$ 最短路。

- **迪克斯特拉**：$d[s]=0$，选 $s$ 松弛得 $d[a]=2$、$d[b]=5$；选 $a$（$d=2$ 最小）入 $S$，**锁死 $d[a]=2$**。
- **真实最短**：$s \to b \to a$ 权 $5 + (-3) = 2$？——$2 = 2$，碰巧相等。换一种：$s \to b$ 权 5、$b\to a$ 权 $-6$，则真实最短路 $5-6 = -1 < 2$，迪克斯特拉给出错误的 2。

**拆解**：

- **第一步，读贪心假设**：迪克斯特拉假设"非负权下，已定 $S$ 外的最小 $d$ 不会被再缩短"。
- **第二步，读负权破坏**：负权可以让"先到一个远处顶点、再退回来"更短——最小 $d$ 可能被后续负权超越。
- **第三步，读取舍**：非负权（地图、路由）用迪克斯特拉；有负权（某些经济/转化模型）用贝尔曼-福特。**看到负权，换算法**。∎

**这个例子的要点**：算法选择 = 问题条件 + 复杂度权衡。迪克斯特拉是"非负权单源"的最优默认；弗洛伊德则是"全源"场景的万能钥匙（沃舍尔算法的加权版）。第三级《算法设计与分析》会把这些全部展开。

## 6 小结

- **问题**：带非负权图单源最短路。
- **算法**：贪心选未定最近点 + 松弛更新。
- **正确性**：交换论证——$S$ 外最小 $d[u]$ 无法被任何路径超越。
- **要求非负权**：负权换贝尔曼-福特。
- **复杂度**：朴素 $O(n^2)$，堆优化 $O((n+m)\log n)$。
