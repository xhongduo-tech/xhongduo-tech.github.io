## 为什么从幂集与笛卡尔积开始

前两节我们学会了「在集合上做运算」，但集合本身仍然只能**装元素**。这一节介绍两种把集合「升维」的结构：**幂集（power set）** 把集合变成「由它所有子集组成的集合」，**笛卡尔积（Cartesian product）** 把集合变成「由它元素拼成的一切有序对组成的集合」。

这两件事是离散数学从「一维集合」走向「多维结构」的杠杆。幂集联系着计数：一个有 $n$ 个元素的集合有 `$2`^n$ 个子集，这个「每个元素选或不选」的直觉是第八篇《计数》与信息论里「比特」概念的源头。笛卡尔积更是一台「结构生成器」：函数是 $A$ 到 $B$ 的笛卡尔积里的特殊子集，关系是笛卡尔积的任意子集，平面坐标 $\mathbb{R}^2$ 是 $\mathbb{R} \times \mathbb{R}$，连大模型里的注意力矩阵都可以看成「位置对之间的权重」——而「位置对」正是笛卡尔积的元素。<span class="marginnote">笛卡尔积以笛卡尔命名，因为正是他把「用一对数表示平面上一个点」的想法系统化——$(x, y)$ 从此成为几何与分析的第一公民。今天我们依然在沿用这张「用一个有序对标记一个位置」的许可证。</span>

## 1 幂集：所有子集组成的集合

**幂集（power set）**：设 $A$ 是集合，$A$ 的所有子集组成的集合称为 $A$ 的幂集，记作 $\mathcal{P}(A)$：

$$\mathcal{P}(A) = \{X \mid X \subseteq A\}$$

注意这里的变化：**$A$ 的元素是对象，而 $\mathcal{P}(A)$ 的元素是 $A$ 的子集——即集合。** 幂集让「集合的集合」成为研究对象，这也是上一节《集合的基本概念》里「元素可以是集合」这句话真正派上用场的地方。

看几个小例子：

$$\mathcal{P}(\emptyset) = \{\emptyset\}, \qquad \mathcal{P}(\{1\}) = \{\emptyset, \{1\}\}$$

$$\mathcal{P}(\{1, 2\}) = \{\emptyset, \{1\}, \{2\}, \{1, 2\}\}$$

**重点：空集 $\emptyset$ 和 $A$ 自身，永远是 $\mathcal{P}(A)$ 的元素**——空集是任何集合的子集，任何集合是自身的子集。$\mathcal{P}(\emptyset)$ 不是空集，而是「含一个元素（即空集）的集合」，所以 $|\mathcal{P}(\emptyset)| = 1$。<span class="marginnote">这是一个反复出现的辨析题：$\emptyset$ 有 0 个元素，而 $\mathcal{P}(\emptyset) = \{\emptyset\}$ 有 1 个元素。幂集「升了一维」，元素个数也随之上了一个台阶。</span>

## 2 笛卡尔积：有序对的全体

**有序对（ordered pair）** $(a, b)$ 是「有先后次序」的两个对象，它满足：

$$(a, b) = (c, d) \iff a = c \text{ 且 } b = d$$

与集合不同，有序对**顺序敏感**：$(1, 2) \neq (2, 1)$。正是这一点，让有序对能表达「第一分量」「第二分量」这样的位置语义——坐标、向量、数据库记录都建立在这个微小的约定上。

**笛卡尔积（Cartesian product）**：集合 $A$ 与 $B$ 的笛卡尔积是「一切以 $A$ 中元素为第一分量、$B$ 中元素为第二分量的有序对」组成的集合，记作 $A \times B$：

$$A \times B = \{(a, b) \mid a \in A \land b \in B\}$$

举一个具体的例子。设 $A = \{1, 2\}$，$B = \{a, b, c\}$，则

$$A \times B = \{(1,a), (1,b), (1,c), (2,a), (2,b), (2,c)\}$$

共 `$2` \times 3 = 6$ 个元素。下图把 $A = \{1,2,3\}$ 与 $B = \{a,b\}$ 的笛卡尔积画成网格——**每个格子交点就是一个有序对**：

![笛卡尔积 A × B 的网格](/images/discrete-math/power-set-cartesian-product-1.svg)

**辨析｜易错点：$A \times B \neq B \times A$（一般情形）。** $A \times B$ 里的有序对第一分量来自 $A$，$B \times A$ 里的第一分量来自 $B$，两个集合的元素类型都不同，自然不相等。只有当 $A = B$（或 $A, B$ 均为空集）时才有 $A \times B = B \times A$。另外注意**空集的吞噬作用**：$A \times \emptyset = \emptyset$，因为没有 $b$ 可以拿来组成 $(a, b)$。

## 3 公式解析：为什么 $|\mathcal{P}(A)| = 2^{|A|}$

幂集最迷人的性质是它的**基数公式**：一个有 $n$ 个元素的集合，有 `$2`^n$ 个子集。设 $|A| = n$，则

$$
|\mathcal{P}(A)| = 2^n
$$

对这条式子做四步拆解：

- **第一步，把「子集」还原成「选择」**：给 $A$ 的每一个元素 $x$ 提问「$x$ 在这个子集里吗？」。构造一个子集，本质上就是逐一回答这个是非题。
- **第二步，每个元素两种选择**：对元素 $x$，它要么入选、要么落选，恰有 $2$ 种可能，且不同元素的抉择互不影响。
- **第三步，用乘法原理汇总**：$n$ 个元素各 $2$ 种选择，独立组合，子集总数是 `$2` \times 2 \times \cdots \times 2 = 2^n$。这是第八篇《计数》乘法原理的第一次正式亮相。
- **第四步，用二进制串重新理解**：每个子集可以写成一条长度为 $n$ 的 0/1 串——第 $i$ 位是 1 表示「第 $i$ 个元素入选」。于是 $A = \{1,2,3\}$ 的 8 个子集对应 `$000`, 001, \dots, 111$ 八条二进制串，而「$n$ 位二进制数共有 `$2`^n$ 个」正是我们在《数论与密码学》里会反复使用的常识。**子集 ⟺ 比特串**，这个对应是整个信息论的出发点。

这条公式把「组合结构」与「指数增长」绑在了一起：元素个数从 $n$ 到 `$2`^n$，规模瞬间爆炸。正因如此，第五篇《算法》里「枚举一个集合的全部子集」是不可承受的操作，而「`$2`^n$ 种可能」也成了复杂度分析里最常出现的警告信号。

## 4 笛卡尔积的推广与基数

笛卡尔积不限于两个集合。三个集合的笛卡尔积是**有序三元组**的全体：

$$A \times B \times C = \{(a, b, c) \mid a \in A \land b \in B \land c \in C\}$$

一般地，$n$ 个集合的笛卡尔积是**有序 $n$ 元组（ordered n-tuple）** 的全体。基数规律是自然的推广：

$$|A \times B| = |A| \cdot |B|, \qquad |A_1 \times A_2 \times \cdots \times A_n| = |A_1| \cdot |A_2| \cdots |A_n|$$

特别地，实数轴自身的乘积给出了高维空间：$\mathbb{R}^2 = \mathbb{R} \times \mathbb{R}$ 是平面，$\mathbb{R}^n$ 是 $n$ 维空间——线性代数里向量、矩阵的「形状」正是这种乘积结构的记法。<span class="marginnote">在编程语言里，有序 $n$ 元组几乎是原样存在的：Python 的 tuple、Rust 的 tuple、C++ 的 $\mathbb{R}^n$。而「$A \times B$ 是全体可能组合」这个直觉，直接对应关系型数据库里两张表做笛卡尔积（JOIN 不写条件时）的行为——当然工程师会尽量避免这种「爆炸」。</span>

### 例子：笛卡尔积与幂集在程序里长什么样

这两个概念不是数学的专利。Python 的 `itertools` 模块把它们原样实现了：

```python
from itertools import product, combinations

A = {1, 2, 3}
B = {'a', 'b'}

list(product(A, B))          # 笛卡尔积 A×B：3×2 个有序对，保留顺序、允许重复
list(combinations(A, 2))     # 组合：从 A 中取 2 个、不看顺序，共 C(3,2) = 3 个
```

注意这里的分工恰好对应数学上的区别：`product` 保留顺序、允许重复的组合，正是**笛卡尔积**；`combinations` 不看顺序、只挑子集，正是**幂集**的「按大小切片」版本。写代码时选错函数，就是数学里把「有序对」和「集合」混为一谈的错误在程序世界的投影。

## 5 通向关系：$R \subseteq A \times B$

笛卡尔积之所以在离散数学里如此重要，是因为它定义了**关系的栖身之所**：

**重点：从集合 $A$ 到集合 $B$ 的一个（二元）关系（relation），就是 $A \times B$ 的一个子集。** 即 $R \subseteq A \times B$。

例如在 $A = \{1, 2, 3\}$ 上定义「小于」关系：

$$< = \{(a, b) \in A \times A \mid a < b\} = \{(1,2), (1,3), (2,3)\}$$

这个 $<$ 就是 $A \times A$ 的一个子集。**关系把「两个对象之间的某种关联」翻译成了有序对的集合**，从此「$a$ 与 $b$ 有关系」与「$(a,b) \in R$」完全等价。第十篇《关系》的全部内容——自反、对称、传递、偏序、等价——都从「$R$ 是 $A \times B$ 的子集」这一定义出发。

更早的伏笔在第三篇《函数》：函数 $f: A \to B$ 可以视为 $A \times B$ 中满足「每个 $a \in A$ 恰好对应一个 $b$」这一约束的子集。**关系是函数的推广（去掉「恰好一个」的约束），函数是关系的一种特殊情形。** 把「关系 = 子集」「函数 = 特殊关系」这两个等价记牢，后面读《关系》《函数》《图》都会畅通许多。<span class="marginnote">大模型里最常见的「关系」是词对共现与注意力权重：模型预测「token $u$ 之后接 token $v$」的概率，本质就是在整个词表笛卡尔积 $V \times V$ 上定义了一个（概率）函数。你已经在用笛卡尔积思考，只是还没给它起这个名字。</span>

## 6 小结

- **幂集** $\mathcal{P}(A) = \{X \mid X \subseteq A\}$ 是 $A$ 的所有子集组成的集合；$\emptyset$ 与 $A$ 自身恒为 $\mathcal{P}(A)$ 的元素。
- **基数公式** $|\mathcal{P}(A)| = 2^{|A|}$：每个元素「选或不选」，$n$ 个元素对应 `$2`^n$ 个子集，也对应 $n$ 位二进制串。
- **有序对** $(a,b)$ 顺序敏感，$(a,b) = (c,d) \iff a=c \land b=d$；**笛卡尔积** $A \times B = \{(a,b) \mid a \in A \land b \in B\}$。
- $|A \times B| = |A||B|$，可推广到 $n$ 元组；$A \times \emptyset = \emptyset$；$A \times B \neq B \times A$（一般情形）。
- **关系是笛卡尔积的子集**（$R \subseteq A \times B$），函数是「每个 $a$ 恰好对应一个 $b$」的特殊关系——这是第十篇《关系》与第三篇《函数》的共同入口。
