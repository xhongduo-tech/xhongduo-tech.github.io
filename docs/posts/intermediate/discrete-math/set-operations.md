## 为什么从集合运算开始

上一节我们认识了集合的静态结构：元素、属于、子集、空集。但集合的价值在于**它可以参与计算**——就像数能做加减乘除，集合也有自己的「四则运算」：**并、交、补、差、对称差**。

这一节是离散数学第一次真正「动起来」的地方。并集与交集对应逻辑里的「或」与「且」，补集对应「非」，对称差对应「异或」——**集合运算就是逻辑联结词在集合世界的投影**。这一层对应关系会反复出现在后面的章节：布尔代数里与门/或门/非门的真值表、概率论里的 $P(A \cup B)$、数据库查询里的 $P(A \cup B)$ 与 UNION、信息论里集合的划分——全都从这五个基本运算出发。

## 1 并集与交集：两个最常用的运算

**并集（union）** 是「合在一起」的运算：$A$ 与 $B$ 的并集是那些属于 $A$ 或属于 $B$ 的元素构成的集合，记作 $A \cup B$。

$$A \cup B = \{x \mid x \in A \lor x \in B\}$$

**交集（intersection）** 是「取共同部分」的运算：$A$ 与 $B$ 的交集是那些同时属于 $A$ 和 $B$ 的元素构成的集合，记作 $A \cap B$。

$$A \cap B = \{x \mid x \in A \land x \in B\}$$

<span class="marginnote">注意逻辑联结词与集合运算的对应：$\cup$ 对应「或」$\lor$，$\cap$ 对应「且」$\land$，补集对应「非」$\neg$。这套对应不是巧合，而是由定义逐字翻译而来——下一节《集合恒等式》的许多证明，就是利用这条对应把集合运算翻译成语义逻辑直接算。</span>

若 $A \cap B = \emptyset$，则称 $A$ 与 $B$ **不相交（disjoint）**，意思是两个集合没有任何公共元素。若干个集合若两两不相交，则称它们**两两不相交（pairwise disjoint）**——这个「两两」限定词在第八篇《计数》里极其重要：只有互相不重叠的块，才能把各自的元素个数直接相加。

举一个具体的例子。设

$$A = \{1, 2, 3, 4, 5\}, \qquad B = \{4, 5, 6, 7\}$$

则 $A \cup B = \{1, 2, 3, 4, 5, 6, 7\}$（`$4`, 5$ 只写一次——集合无重复），$A \cap B = \{4, 5\}$，且 $A$ 与 $B$ **不**不相交。

## 2 差集与补集：两种「去掉」的运算

**差集（difference）** 也叫**相对补集**：$A$ 与 $B$ 的差集是那些属于 $A$ 但不属于 $B$ 的元素构成的集合，记作 $A - B$。

$$A - B = \{x \mid x \in A \land x \notin B\}$$

**补集（complement）** 则是相对某个**全集** $U$ 而言的：集合 $A$ 的补集是 $U$ 中所有不属于 $A$ 的元素构成的集合，记作 $\overline{A}$（罗森书中也写作 $A^c$）。

$$\overline{A} = \{x \in U \mid x \notin A\}$$

**辨析｜易错点：差集与补集的区别**在于是否需要全集。$A - B$ 只依赖 $A$ 与 $B$ 两个集合，不需要事先指定全集；而 $\overline{A}$ 是一个**相对**概念——「$A$ 之外」的边界由全集 $U$ 决定。同一时刻必须固定同一个全集，否则「补集」没有意义。把 $U$ 取为 $\mathbb{Z}$ 时，$A = \{x \mid x \ge 0\}$ 的补集是负整数集；把 $U$ 取为 $\mathbb{R}$ 时，同一 $A$ 的补集还包括「非整数的实数」。**同一个 $A$，不同的 $U$，补集不同。**

差集与补集之间有一个随时可用的等式：

$$A - B = A \cap \overline{B}$$

含义很直观：从 $A$ 里去掉「属于 $B$ 的部分」，等价于保留「在 $A$ 中且不在 $B$ 中」的部分。这个等式在下一节会被当作恒等式正式证明并反复调用。<span class="marginnote">差集、补集与交集的换算，很像减法对加法的换算：$A - B = A \cap \overline{B}$ 把「减法」变成了「加法 + 取反」。离散数学里到处是这种「把一种运算换成另一种更顺手的运算」的化简技巧。</span>

## 3 对称差：集合版的「异或」

**对称差（symmetric difference）** 是只保留「恰好属于其中之一」的元素的运算，记作 $A \oplus B$。

$$A \oplus B = (A - B) \cup (B - A) = \{x \mid (x \in A) \oplus (x \in B)\}$$

这里 $\oplus$ 在集合符号和逻辑符号两个层面同时出现：右边花括号里的 $\oplus$ 是逻辑联结词**异或（XOR）**，意思是「两个条件恰有一个成立」。因此对称差的直觉一句话：**$x \in A \oplus B$ 当且仅当 $x$ 恰好在 $A$ 和 $B$ 之一里面。**<span class="marginnote">对称差的词源：$A \oplus B$ 关于 $A$、$B$ 完全对称——它既不偏爱 $A$ 也不偏爱 $B$。相比之下 $A - B$ 就不对称：$A - B \neq B - A$（一般情形）。「对称」二字正是在提醒这个区别。</span>

对称差有一个重要的基数公式：

$$|A \oplus B| = |A| + |B| - 2|A \cap B|$$

意思是：先分别数出 $A$ 与 $B$ 的元素数，加起来；但共同部分被数了两次，所以要**减掉两倍**的交集元素数。这个「先相加、再扣掉重复」的套路，正是第八篇《容斥原理》的雏形。

## 4 文氏图：把运算画出来

五个运算的直观差异，用文氏图（Venn diagram）看一眼就懂：着色区域就是该运算的结果集合。

![五种集合运算的文氏图](/images/discrete-math/set-operations-1.svg)

文氏图不是「可爱的装饰」，而是一种**证明工具与验证工具**。一个集合恒等式画出来两幅图着色相同，就说明两侧相等；而更重要的用途是**发现反例**：想验证「$A \cup (B \cap C)$ 是否等于 $(A \cup B) \cap C$」这类命题，画图能最快地暴露差异区域在哪里。下一节我们证明恒等式时，会先用文氏图「验货」，再用元素法（element proof）给出严格证明。

## 5 推广：一族集合的并集与交集

并、交不止能对两个集合做，也能一口气对一**族**集合做。设 $A_1, A_2, \dots, A_n$ 是 $n$ 个集合，定义：

$$
\bigcup_{i=1}^{n} A_i = A_1 \cup A_2 \cup \cdots \cup A_n = \{x \mid \exists i\,(1 \le i \le n \land x \in A_i)\}
$$

$$
\bigcap_{i=1}^{n} A_i = A_1 \cap A_2 \cap \cdots \cap A_n = \{x \mid \forall i\,(1 \le i \le n \to x \in A_i)\}
$$

竖线后的量词结构，正是第一篇《嵌套量词》学过的「存在量词 + 范围」与「全称量词 + 范围」。**把并集读作「存在一个下标使得 $x$ 属于它」，把交集读作「每个下标都有 $x$ 属于它」**——量词的直觉直接翻译成了集合运算，两种语言在这里完全互通。

这个推广不是书斋里的摆设。计算机科学里「对一批集合求并 / 求交」是数据库查询、倒排索引合并、推荐系统打分的第一原语；概率论里「事件列 $\{E_i\}$ 的并」更是处处出现。更一般地，下标的范围可以不是有限的：

$$
\bigcup_{i=1}^{\infty} A_i, \qquad \bigcap_{i \in \mathbb{Z}} A_i
$$

对无穷族求并、求交，在第三级《实数分析》与《测度论》中会再次与我们相遇——那里它有一个正式的名字：**可数个集合的并**，并集与交集将被嫁接到「收敛」「测度」这些分析概念上。

## 6 公式解析：对称差的两副面孔

对称差之所以值得单独立一节，是因为它有**两种等价写法**，而两种写法各自通往不同的应用：

$$
A \oplus B = (A - B) \cup (B - A) = (A \cup B) - (A \cap B)
$$

对这条等式做三步拆解：

- **第一步，从「异或」直觉出发**：一个元素 $x$ 属于 $A \oplus B$，当且仅当 $x \in A$ 与 $x \in B$ **恰好成立一个**。这是对称差的定义，也是它叫「异或」的原因——与逻辑里「两个真值只有一个为真时结果为真」完全一致。
- **第二步，翻译成差集的并**：$(A - B) \cup (B - A)$。「$x$ 只在 $A$ 里」（$A - B$）加上「$x$ 只在 $B$ 里」（$B - A$），二者恰好覆盖「恰好成立一个」的所有情况，而且这两部分互不相交。
- **第三步，翻译成「并集减去交集」**：$(A \cup B) - (A \cap B)$。先在 $A \cup B$ 里把所有「至少属于一个」的元素都拿过来，再把「两个都占」的 $A \cap B$ 剔除，剩下的正是「恰好一个」。同一句话，两种组装顺序。
- **第四步，为什么两者相等**：本质是异或的真值表——$A \cup B$ 包含「仅 $A$、仅 $B$、两者」三类元素，减去 $A \cap B$ 后只剩前两类，与 $(A - B) \cup (B - A)$ 给出的集合完全一致。

由此我们看到一个通用手法：**同一个集合概念，常常有多种「组装」方式，选择哪种取决于手头的工具。** 处理元素时用第一种写法，处理基数或概率时用第二种写法往往更顺。

## 7 小结

- **并集** $A \cup B = \{x \mid x \in A \lor x \in B\}$，**交集** $A \cap B = \{x \mid x \in A \land x \in B\}$。
- $A \cap B = \emptyset$ 时称 $A$ 与 $B$ **不相交**；若干集合**两两不相交**才能直接相加元素个数。
- **差集** $A - B = \{x \mid x \in A \land x \notin B\}$ 不需要全集；**补集** $\overline{A}$ 依赖全集 $U$，且 $A - B = A \cap \overline{B}$。
- **对称差** $A \oplus B = (A - B) \cup (B - A) = (A \cup B) - (A \cap B)$，对应逻辑里的**异或**。
- 文氏图是验证与发现反例的直观工具，但严格证明要靠元素法。
- **一族集合的并** $\bigcup_{i=1}^{n} A_i$ 与**交** $\bigcap_{i=1}^{n} A_i$ 分别用存在量词与全称量词定义，可推广到无穷族。
- 基数公式 $|A \cup B| = |A| + |B| - |A \cap B|$ 是容斥原理的雏形，也是下一节要严格证明的恒等式之一。

在下一节，我们将把这一节的全部运算放进同一张「恒等式清单」——**集合恒等式与文氏图**，并学会用元素法系统证明它们，就像用代数恒等式化简算式一样化简集合表达式。
