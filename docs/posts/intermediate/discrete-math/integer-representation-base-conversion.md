## 为什么学进制表示

上一节的同余给了我们"模 $m$ 世界"的抽象视角，但计算机是个**具体的**世界：内存里的整数不是抽象的数，而是按位存放的 0 和 1。整数如何在机器里表示、如何从一种表示换成另一种，是数论与硬件之间的桥梁。<span class="marginnote">进制的"按位展开"思想比计算机古老得多——十进制是印度-阿拉伯数字系统的遗产，而二进制、十六进制不过是同一套位置记数法在不同基数下的实例。第三级《计算机组成原理》第一章就要讲机器数与数据表示，这里的展开式正是它的数学基础。</span>

**位置记数法（positional notation）**：一个 $b$ 进制的整数 $n$ 写成 $n = (a_{k-1} a_{k-2} \dots a_1 a_0)_b$，表示

$$n = a_{k-1} b^{k-1} + a_{k-2} b^{k-2} + \dots + a_1 b + a_0$$

其中每一位 $a_i$ 满足 `$0` \le a_i \le b-1$。$b$ 称为**基数（base）**。日常用十进制（$b=10$），计算机用二进制（$b=2$），而十六进制（$b=16$）是二进制的"压缩速记"。

## 1 为什么是 2、8、16

**二进制**之所以是机器的语言，因为物理器件天然只有两种稳定状态：开关的断开/闭合、磁畴的正/反向、电压的高/低。用两种状态表示 0/1，可靠性最高。

**十六进制**是二进制与人类的折中：`$16` = 2^4$，于是**每 4 位二进制恰好对应 1 位十六进制**。一个 32 位的数写成二进制要 32 个字符，写成十六进制只要 8 个——这就是为什么程序员用 `$16` = 2^4$ 而不是二进制看内存。

| 十六进制 | 二进制 | 十进制 |
| --- | --- | --- |
| 0 | 0000 | 0 |
| 7 | 0111 | 7 |
| A | 1010 | 10 |
| F | 1111 | 15 |

十六进制的十个数字不够用，借用了字母 A–F 表示 10–15。`0x` 前缀、`0b` 前缀分别是十六、二进制的常见标记。

## 2 公式解析：十进制转二进制（除基取余法）

要把十进制数 $n$ 转成 $b$ 进制，核心工具就是**带余除法**——每次除以 $b$，余数就是一位，从低位到高位依次取出。

$$
n = bq + r_0,\quad q = bq' + r_1,\quad \dots
$$

**实例**：`$11`_{10}$ 转二进制。

- **第一步，除 2 取余**：`$11` = 2 \times 5 + 1$，最低位 $r_0 = 1$。
- **第二步，继续除商**：`$5` = 2 \times 2 + 1$，$r_1 = 1$；`$2` = 2 \times 1 + 0$，$r_2 = 0$；`$1` = 2 \times 0 + 1$，$r_3 = 1$；商为 0，停止。
- **第三步，倒序排列**：余数从后往前读，$r_3 r_2 r_1 r_0 = 1011$，即 `$11`_{10} = (1011)_2$。

**为什么倒序**：因为第一次除得的余数是 $b^0$ 位（最低位），越往后除得的余数位权越高。余数的出场顺序是低位在前，写成数字时自然要倒过来。

**辨析｜易错点：** 反转顺序是最常见的失误。可以用验算自纠：$(1011)_2 = 8 + 0 + 2 + 1 = 11$，对得上就说明没转错。任何进制转换做完，都建议**按展开式验算一遍**。

## 3 二进制与十六进制的互转

因为 `$16` = 2^4$，二进制与十六进制之间可以直接**分组换算**，无需经过十进制：

- **二进制 → 十六进制**：从**右**往左每 4 位一组，不足 4 位在左侧补 0，每组换算成一位十六进制。
- **十六进制 → 二进制**：每一位十六进制展开成 4 位二进制，按顺序拼接。

**实例**：$(1011100)_2$ 转十六进制。从右往左分组：`101 | 1100`（左侧补 0 成 4 位），`0101` = 5，`1100` = C，所以 $(1011100)_2 = \text{0x5C}$。

**实例**：$\text{0x2F}$ 转二进制。`2` → `0010`，`F` → `1111`，拼接得 `00101111`，去掉前导 0 即 $(101111)_2$。

<span class="marginnote">分组方向必须从右往左，因为高位的 0 可以省略、低位的 0 不能丢。例如 $(10)_2 = \text{0x2}$ 而非 $\text{0x20}$——$\text{0x20}$ 是 32，比 2 大了 16 倍。方向搞反是工程里查一整天 bug 的常见来源。</span>

## 4 八进制、负数的表示与溢出

**八进制**（$b=8$）与二进制同理：`$8` = 2^3$，每 3 位一组。Unix 文件权限的 `755`、`644` 就是八进制表示。

**负数在机器里怎么表示**？教科书先给出抽象的约定：符号位 + 数值位，或补码。罗森在此只讲正整数表示，负数的补码表示留待第三级《计算机组成原理》详细展开，这里只需知道：**补码让加减法统一成模 `$2`^k$ 上的加法**——这恰好就是我们前两节学的模算术！$k$ 位二进制整数本质是模 `$2`^k$ 的整数，溢出就是余数环绕。

**溢出（overflow）**：当运算结果超出表示范围时，丢弃最高进位。例如 4 位无符号数里 `$15` + 1 = (1111)_2 + 1 = 10000_2$，只保留低 4 位得 0——这正等价于 `$15` + 1 \equiv 0 \pmod{16}$。<span class="marginnote">「溢出 = 模 `$2`^k$ 环绕」是连接数论与硬件的关键一句：理解了它，你就理解了为什么无符号加法天然是模运算。大模型训练里 fp16 的梯度上溢/下溢，本质也是有限表示范围的环绕——只不过浮点数的"模"换成了指数范围。</span>

## 5 进制转换的通用模板与一个"任意基数"的例子

除基取余法不限于 2/8/16——它适用**任意基数**。练一个"反向"例子：把二进制转十进制。

**例（任意基数转十进制）**：$(2AC)_{16}$ 转十进制。

$$
(2AC)_{16} = 2 \times 16^2 + 10 \times 16 + 12 = 512 + 160 + 12 = 684
$$

**例（十进制转任意基数）**：把 $684$ 转回十六进制——除 16 取余：`$684` = 42\times16 + 12$（C）、`$42` = 2\times16 + 10$（A）、`$2` = 0\times16 + 2$，倒序得 $(2AC)_{16}$。✓

**公式解析：位置记数法的统一形式**

$$
(b_k b_{k-1} \dots b_1 b_0)_b = \sum_{i=0}^{k} b_i b^i
$$

- **第一步，读正向（基数→十进制）**：按位展开求和——每一位乘上它的位权 $b^i$。
- **第二步，读逆向（十进制→基数）**：除 $b$ 取余，余数从低到高。
- **第三步，读"任意基数"**：$b$ 可以是 2、8、10、16，乃至任何整数——**同一套算法，换 $b$ 即可**。∎

**十六进制字母的陷阱**：$A=10$、$B=11$、…、$F=15$。转十进制时字母要换成数值；反向时数值 ≥10 要换回字母。**字母与数值的互换**是十六进制特有的易错点。

**辨析｜易错点：** 除基取余的"余数"必须落在 $[0, b-1]$。对负数的处理与十进制取模一致（余数非负）。另外**验证方向**：转完后用"按位展开"还原原数，是最可靠的自检——任何进制转换做完都该还回去验一遍。

**这个例子的要点**：进制转换是"位置记数法"的两个方向——**展开（b 进制→十进制）与取余（十进制→b 进制）互逆**。掌握统一公式，2/8/16 进制都是特例，计算机里的一切整数表示都在这里。

## 6 小结

- **位置记数法**：$n = \sum a_i b^i$，每位 `$0` \le a_i < b$。
- 计算机用二进制，十六进制是每 4 位一组的速记，八进制是每 3 位一组。
- **十进制 → $b$ 进制**：除基取余，余数倒序排列。
- **二进制 ↔ 十六进制**：从右往左每 4 位分组直接换。
- 溢出就是模 `$2`^k$ 环绕；补码让减法变成模算术里的加法。

**小结补记**：进制是"数字的表示"，而表示选择影响计算——**二进制让硬件便宜、十六进制让人可读、十进制是人脑默认**。位置记数法的"位权求和"是这一切的统一公式。

**快速自测**：`$13`_{10}$ 转二进制？除 2 取余：13=2×6+1、6=2×3+0、3=2×1+1、1=2×0+1，倒序得 $(1101)_2$。验算 `$8`+4+1=13$ ✓。**除基取余、余数倒序、展开验算**三步走。
