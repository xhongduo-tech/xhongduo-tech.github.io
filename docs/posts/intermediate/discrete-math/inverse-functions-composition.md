## 为什么从逆函数与函数复合开始

前两节定义了函数，并给函数分了类。这一节回答两个更「活」的问题：**函数能不能接起来用**（复合），**函数能不能撤销**（逆）。复合把两个函数串成一条流水线，逆函数把一次变换原路退回——它们是「组合」与「拆解」这对孪生动作的函数版。<span class="marginnote">霍布斯把推理比作计算，现代意义上「函数复合」正是计算最原始的模样：上一个函数的输出，喂给下一个函数当输入。你每一次在命令行写 `grep ... | sort | uniq`，都在做函数复合。</span>

这两个概念在工程里的出场频率高得惊人。数据管道是函数的复合：清洗 → 分词 → 过滤 → 统计；神经网络是成千上万个函数层的复合；编译器的每个阶段都是上一阶段的消费者。而「撤销」同样无处不在：压缩与解压、编码与解码、加密与解密——**RSA 的加密与解密本质上就是模指数函数与其逆函数**。这一节，我们把这套「组合 / 撤销」的语法彻底搞清楚。

## 1 函数复合：把两条流水线接起来

**复合（composition）**：设 $f: A \to B$，$g: B \to C$。$g$ 与 $f$ 的复合是函数 $g \circ f: A \to C$，定义为

$$(g \circ f)(a) = g(f(a))$$

读作「$g$ after $f$」或「$g$ 复合 $f$」。注意执行顺序：**先 $f$，后 $g$**——因为 $f$ 的输出要作为 $g$ 的输入。<span class="marginnote">记号里的陷阱：$g \circ f$ 从右往左读，先把 $a$ 交给最右边的 $f$，再把结果交给左边的 $g$。很多初学者第一眼以为「$\circ$ 左边先执行」，这是复合最常见的口误来源。记住：右侧先生效，就像函数调用 `g(f(a))` 先算内层。</span>

看一个具体例子。设 $A = \{1,2,3\}$，$B = \{a,b,c,d\}$，$C = \{x,y,z\}$：

$$f = \{(1,a), (2,b), (3,c)\}, \qquad g = \{(a,x), (b,y), (c,z), (d,z)\}$$

则 $g \circ f: A \to C$ 为 $\{(1,x), (2,y), (3,z)\}$——逐点先跑 $f$ 再跑 $g$。

**复合不满足交换律**：$g \circ f \neq f \circ g$（一般情形），即使两边都有定义。看公式例子，$f(x) = x + 1$、$g(x) = x^2$ 都取 $\mathbb{R} \to \mathbb{R}$：

$$(g \circ f)(x) = (x+1)^2, \qquad (f \circ g)(x) = x^2 + 1$$

两者不同（$x=2$ 时分别得 $9$ 与 $5$）。**先平方再加一，与先加一再平方，是两回事。**

但复合满足**结合律**：对 $f: A \to B$，$g: B \to C$，$h: C \to D$，

$$(h \circ g) \circ f = h \circ (g \circ f)$$

因为两边作用在 $a$ 上都得到 $h(g(f(a)))$。结合律的实用意义是：**复合多层函数时括号无关紧要**，可以放心地写作 $h \circ g \circ f$。这与矩阵乘法、关系复合的代数结构一脉相承。

## 2 逆函数：撤销一次变换

**逆函数（inverse function）**：设 $f: A \to B$ 是双射。$f$ 的逆函数 $f^{-1}: B \to A$ 定义为

$$f^{-1}(b) = a \iff f(a) = b$$

即把「$f$ 射出去的箭」原路射回来。<span class="marginnote">「逆」字在这里是字面义：$f^{-1}$ 把 $f$ 的结果还原成最初的输入。温度换算 $C = \frac{5}{9}(F-32)$ 是 $F = \frac{9}{5}C + 32$ 的逆函数；指数与对数互为逆函数——$a^b$ 与 $\log_a$ 互逆正是「取对数能解指数方程」的原因。</span>

**重点：只有双射才有（双向）逆函数。** 为什么？两个方向各有各的难处：

- 若 $f$ 非单射，比如 $f(a_1) = f(a_2) = b$，那么 $f^{-1}(b)$ 该回 $a_1$ 还是 $a_2$？——不唯一，无法定义。
- 若 $f$ 非满射，比如某个 $b$ 没有来源，那么 $f^{-1}(b)$ 无意义——不存在。
- 只有双射，「每个 $b$ 恰好有一个来源」，$f^{-1}$ 才是一个货真价实的函数。

单射与满射分别只够「半边」：单射给出定义在**值域**上的左逆 $g$（满足 $g \circ f = \mathrm{id}_A$），满射（配合选择公理）给出右逆 $h$（满足 $f \circ h = \mathrm{id}_B$）；要**两侧同时成立**，函数必须双射。此时

$$f^{-1} \circ f = \mathrm{id}_A, \qquad f \circ f^{-1} = \mathrm{id}_B$$

**辨析｜易错点：$f^{-1}$ 记号的两副面孔。** $f^{-1}$ 有两个截然不同的含义：一是逆函数 $f^{-1}: B \to A$（仅当 $f$ 双射时存在）；二是对 $B$ 的任意子集 $S$ 的**原像（preimage）**

$$f^{-1}(S) = \{a \in A \mid f(a) \in S\}$$

原像**不需要 $f$ 可逆**——任意函数都有原像，它只是「被 $f$ 射进 $S$ 的那些输入」组成的集合。把「$f^{-1}(4)$ 等于多少」与「$f^{-1}(\{4\})$ 等于哪个集合」混为一谈，是函数一章最经典的乌龙。

## 3 复合与逆的顺序：穿袜子、穿鞋子

复合与逆相遇时，出现一条乍看反直觉、细想极自然的规则：

**重点：$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$。** 复合的逆，等于各自逆函数的**反向**复合。

直觉是「穿袜子、穿鞋子」：先穿袜子再穿鞋，出门；回家要脱，**先脱鞋、再脱袜子**——与穿的顺序正好相反。函数也一样：$y = g(f(x))$ 是「先 $f$ 后 $g$」，要从 $y$ 还原 $x$，必须**先撤销 $g$、再撤销 $f$**。<span class="marginnote">工程版同理：发消息先压缩再加密，收消息就必须先解密再解压——顺序反过来。如果先解压再解密，得到的是密文流上的乱码。任何「编码/解码」工具链都遵守这条反转规则。</span>

验证一条具体式子。设 $f(x) = 2x$，$g(x) = x + 3$，则 $(g \circ f)(x) = 2x + 3$，它的逆是 $x \mapsto \frac{x-3}{2}$。而按公式：

$$(g \circ f)^{-1} = f^{-1} \circ g^{-1}, \qquad f^{-1}(x) = \frac{x}{2}, \quad g^{-1}(x) = x - 3$$

$$(f^{-1} \circ g^{-1})(x) = f^{-1}(x - 3) = \frac{x-3}{2}$$

对上了。若错写成 $g^{-1} \circ f^{-1}$，会得到 $\frac{x}{2} - 3 = \frac{x-6}{2}$，与 $\frac{x-3}{2}$ 不符——**顺序错了，撤销就失效**。

## 4 复合与逆在计算机科学中

把复合与逆翻译成程序，印象更深：

```python
def compose(f, g):
    """数学记法的复合：返回 g ∘ f，先应用 f，再应用 g。"""
    return lambda x: g(f(x))

add1   = lambda x: x + 1
double = lambda x: x * 2

h1 = compose(double, add1)     # add1 ∘ double：先 double 再 add1
h2 = compose(add1, double)     # double ∘ add1：先 add1 再 double
h1(3), h2(3)                   # (7, 8) —— 顺序不同，结果不同
```

这行 `h1(3), h2(3)  # (7, 8)` 把「复合不交换」落在可运行代码上。

再看三个真实场景：

- **数据管道**：`清洗 → 分词 → 过滤停用词 → 统计` 是四个函数的复合；每一步的输出类型必须与下一步的输入类型匹配，这正是函数复合对「接口一致」的要求。
- **神经网络**：一层网络是 $x \mapsto \sigma(Wx + b)$，整网是数十层的复合；反向传播之所以要「倒着算」，正是因为它沿着 $(g \circ f)$ 的逆顺序回推梯度——$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$ 的影子处处可见。<span class="marginnote">反向传播里「从输出层往输入层走」的方向，与「复合逆要反序」是同一直觉：先撤销最后一层，再逐步向前撤销。第三级《神经网络与深度学习》会把它严格展开。</span>
- **加密与解密**：公钥加密先经一个双射变换，私钥解密执行其逆；**RSA 的加密是 $m \mapsto m^e \bmod n$，解密是 $c \mapsto c^d \bmod n$，两把密钥互为逆（模意义下）**——这正是「只有双射才有逆函数」在密码学里的分量。

## 5 公式解析：为什么复合的逆要倒着来

把这条规则证明一遍，胜过背十遍。设 $f: A \to B$ 与 $g: B \to C$ 都是双射，要证

$$
(g \circ f)^{-1} = f^{-1} \circ g^{-1}
$$

分五步走：

- **第一步，明确目标**：$y = (g \circ f)(x) = g(f(x))$。所谓「求逆」，是给定 $y$，找出那个唯一的 $x$。
- **第二步，先撤销外层 $g$**：$y$ 在 $C$ 里，第一步必须把 $g$ 的影响去掉——对 $y$ 作用 $g^{-1}$，得到 $g^{-1}(y) = f(x)$。
- **第三步，再撤销内层 $f$**：此时手里是 $f(x)$，再作用 $f^{-1}$，得到 $f^{-1}(g^{-1}(y)) = x$。
- **第四步，读出复合**：$x = f^{-1}(g^{-1}(y)) = (f^{-1} \circ g^{-1})(y)$。既然 $(g \circ f)^{-1}(y) = x$ 而 $(f^{-1} \circ g^{-1})(y) = x$，两个函数对每个 $y$ 取值相同，故相等。
- **第五步，回到袜子鞋子**：为什么是反序？因为复合是「先 $f$ 后 $g$」，撤销必须「先删最近做的事」。$g$ 是最后执行的，所以最先被撤销；$f$ 最先执行，最后被撤销——顺序自然反转。

这条规则还说明一件事：**「求逆」与「复合」两个操作在函数组成的系统里彼此兼容，且逆的复合是反序的。** 这种「运算 + 逆运算」的结构（群、半群）是第三级《抽象代数》的主角；在这里先埋下直觉。

## 6 小结

- **复合** $(g \circ f)(a) = g(f(a))$：先 $f$ 后 $g$，从右往左读；**结合律**成立，**交换律**不成立。
- **逆函数** $f^{-1}(b) = a \iff f(a) = b$；**只有双射**才有双向逆，此时 $f^{-1} \circ f = \mathrm{id}_A$、$f \circ f^{-1} = \mathrm{id}_B$。
- **辨析**：$f^{-1}(S)$（原像，任意函数都有）与 $f^{-1}$（逆函数，仅双射有）是两回事。
- **反转规则**：$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$——「穿袜子、穿鞋子」的顺序直觉。
- 应用：数据管道、神经网络反向传播、加密解密的密钥配对，处处是复合与逆。
