## 为什么偏序还要继续加结构

偏序太宽松：有些子集没有上界。若**任意两个元素**都有最小上界与最大下界，偏序就升级为**格（lattice）**——这是一种"运算完备"的偏序，交与并处处可行。格在布尔代数（第十三篇）、逻辑电路、数据库的包含格里都是主角。而**拓扑排序（topological sorting）**则回答偏序的工程问题：给定一组带先后约束的任务，如何排出一个"满足所有约束的执行顺序"？<span class="marginnote">拓扑排序是现代软件工程的日常：包管理器解析依赖、构建系统决定编译顺序、任务调度器排流水线、数据库做外键约束检查——全是"把偏序展平成线性序列"。它也是第三级《算法设计与分析》里 DAG 拓扑排序的入门，届时会有 $O(V+E)$ 的卡恩算法与 DFS 实现。</span>

## 1 格的定义

**格（lattice）**：偏序集 $(L, \preceq)$ 若对任意 $a, b \in L$，$a, b$ 的**最小上界**（记 $a \lor b$，叫**并/join**）与**最大下界**（记 $a \land b$，叫**交/meet**）都存在，则 $L$ 是格。

**例 1（幂集格）**：$(\mathcal{P}(S), \subseteq)$ 是格——任意 $A, B$ 的最小上界是 $A \cup B$、最大下界是 $A \cap B$。这就是"并 = join、交 = meet"命名的来源。

**例 2（整数格）**：$(\mathbb{Z}, \le)$ 是格——$a \lor b = \max(a,b)$、$a \land b = \min(a,b)$。

**例 3（整除格）**：$(\mathbb{Z}^+, |)$ 是格——$a \lor b = \operatorname{lcm}(a,b)$、$a \land b = \gcd(a,b)$。

**非例**：偏序 $\{1,2,3,4,6,8,12\}$（整除）**不是**格：$6$ 与 $8$ 的上界只有 $24$（lcm=24）但 $24 \notin$ 集合，所以最小上界不存在。

**辨析｜易错点：** 格要求**任意两元素**都有 lub 与 glb，且 lub/glb 必须在集合**内**。仅"某些对有"不算格。验证一个偏序是不是格：任取两元素，看它们的 lub 与 glb 是否都存在且在集合中。

## 2 格的运算性质

格的并与交满足一组很像集合运算的法则：

- **交换律**：$a \lor b = b \lor a$、$a \land b = b \land a$。
- **结合律**：$(a \lor b) \lor c = a \lor (b \lor c)$。
- **吸收律**：$a \lor (a \land b) = a$、$a \land (a \lor b) = a$。
- **幂等律**：$a \lor a = a$、$a \land a = a$。

**直觉**：$\lor$ 像"取大/合并"、$\land$ 像"取小/求交"，直觉与集合/整除例子完全一致。

**分配格**：若 $a \lor (b \land c) = (a \lor b) \land (a \lor c)$ 对一切 $a,b,c$ 成立，则称分配格。幂集格是分配格，但并非所有格都分配——有些格（如钻石格 $M_3$）不满足分配律。**分配性是格到布尔代数的桥梁**，第十三篇会用到。

<span class="marginnote">格的代数结构在抽象代数里是"格论"——它有独立的运算系统（交并 + 吸收律）而不必依赖偏序。当格还满足互补律时，就成为布尔代数（第十三篇），那是逻辑电路和搜索算法的数学骨架。<strong>偏序 → 格 → 布尔代数</strong>是一条清晰的结构升级链。</span>

## 3 拓扑排序的定义

**拓扑排序（topological sorting）**：给定偏序集 $(S, \preceq)$，把 $S$ 的元素排成一个线性序列 $a_1, a_2, \dots, a_n$，使得**只要 $a_i \prec a_j$，就有 $i < j$**（偏序关系在序列中被保持，箭头都朝前）。

**例**：课程依赖——微积分先于线性代数，线性代数先于机器学习。拓扑排序给出一种可行的选课顺序：微积分 → 线性代数 → 机器学习。

**拓扑排序何时存在**：对**有穷偏序**，拓扑排序**一定存在**。原因是：有穷偏序必有极小元（上一节），把它放第一位，删掉它后剩下仍是有穷偏序，再取极小元……重复到空。这个构造本身就是算法：

```
procedure topological_sort(S, ≼)
    while S 非空:
        选一个极小元 a          # 没有元素排在 a 前面
        输出 a
        S := S \ {a}
```

**为什么每次都能选到极小元**：有穷非空偏序必有极小元（沿"更小"方向走，有穷必停）。所以算法不会卡住，一定给出完整排序。

## 4 公式解析：拓扑排序的正确性

**定理**：上述贪心式的拓扑排序算法对任何有穷偏序都输出合法拓扑排序。

**证明（归纳）**：

- **第一步，看第一步**：算法选的 $a$ 是 $S$ 的极小元——没有 $b$ 使 $b \prec a$。所以 $a$ 之前没有任何元素必须在它前面，放在首位不违反任何约束。
- **第二步，看归纳步**：假设算法已正确排好前 $k$ 个。从 $S$ 中删去这些后，剩下的偏序中，若 $b$ 是极小元，则剩余元素中没有必须在 $b$ 之前的（且已排出的都在 $b$ 前，因它们先被选）。把 $b$ 放第 $k+1$ 位，仍合法。
- **第三步，归纳收尾**：有穷性保证过程终止，每一步都合法，输出合法拓扑排序。∎

**这个证明的要点**：算法是"贪心"（每步选极小元），正确性靠"极小元放在前面永远安全"这一观察 + 归纳。与第五篇贪心正确性论证同构——**选择永远安全，剩余问题是同型子问题**。

**辨析｜易错点：** 拓扑排序**不唯一**——极小元可能有多个，选哪个都行。所以拓扑排序的结果不是唯一的序列，而是"一族合法序列"。别把"找到一种"当成"唯一的一种"。

<span class="marginnote">拓扑排序在 DAG 上的标准算法是卡恩算法（Kahn）与 DFS 后序逆序，复杂度 $O(V+E)$。构建系统（Make、Ninja）、包管理器（npm、pip）每次跑构建都在执行一次拓扑排序——<strong>依赖解析 = 偏序的线性化</strong>。第三级《算法设计与分析》会把它作为图算法经典题展开。</span>

## 5 拓扑排序的完整实例：课程依赖

把拓扑排序放到最直观的场景——选课依赖，走一遍完整流程。

**例**：课程依赖（箭头表示"先修"）：微积分 $\to$ 线性代数 $\to$ 机器学习，微积分 $\to$ 概率论 $\to$ 机器学习。课程集合 $\{$微积分，线性代数，概率论，机器学习$\}$，偏序：微积分 $<$ 线性代数 $<$ 机器学习、微积分 $<$ 概率论 $<$ 机器学习。

**拓扑排序（贪心取极小元）**：

- 极小元：微积分（没有先修课）→ 排第 1。
- 删微积分后，极小元：线性代数、概率论（都只依赖已删的微积分）→ 任选其一，如线性代数排第 2。
- 删线性代数后，极小元：概率论 → 排第 3。
- 最后机器学习 → 排第 4。

得到序列：微积分 → 线性代数 → 概率论 → 机器学习。

**公式解析：为什么"任选极小元"都合法**

极小元 $a$ 满足"没有 $b \prec a$"——即 $a$ 的所有先修都已被排在前面（若某先修没排，它排在 $a$ 前，$a$ 就不是极小元）。

- **第一步，读极小元**：$a$ 之前没有任何元素必须在它前面。
- **第二步，读归纳**：删掉已排序列后，剩余仍是偏序，新极小元的先修都在已排部分。
- **第三步，读合法**：每步都把"先修已齐"的课排出，序列满足所有依赖。∎

**另一个合法序列**：微积分 → 概率论 → 线性代数 → 机器学习——**拓扑排序不唯一**，本例有两解。都满足"先修在后修前"。

**辨析｜易错点：** 拓扑排序只要求"偏序关系保持"，不要求"全序"——**不可比的课程（线性代数、概率论）可以任意顺序**。若题目要求"字典序最小"，则极小元中选最小——那是附加约束，不是拓扑排序本身的保证。

**这个例子的要点**：拓扑排序 = "反复排先修已齐的课"。**构建系统、包管理器、任务调度就是这张依赖图上的拓扑排序**——每次 `npm install` 都在做这件事。

## 6 小结

- **格**：任意两元素都有 lub（$\lor$，并）与 glb（$\land$，交）的偏序；幂集格、整除格是标准例子。
- 格的交并满足交换、结合、吸收、幂等律；分配格再满足分配律。
- **拓扑排序**：把偏序展平成保持约束的线性序列；有穷偏序必存在。
- 贪心构造：反复取极小元放队首，正确性靠"极小元放前面永远安全" + 归纳。
- 拓扑排序不唯一；构建系统/包管理器的依赖解析就是它的工程形态。
