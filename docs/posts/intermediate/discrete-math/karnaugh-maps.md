# 卡诺图（Karnaugh map）化简

<div class="epigraph">

</div>

## 为什么需要"画图"化简

代数化简（用恒等式）依赖"看出"哪几步能合并，人脑易错且不系统。**卡诺图（Karnaugh map, K-map）**把真值表重新排版成**相邻格子只差一个变量**的网格，于是"相邻 1 的合并"在图上**可见**——圈住相邻的 1，就能读出化简后的乘积项。它是 4 变量以内布尔函数化简的"看图说话"工具，也是数字逻辑课程的必备技能。<span class="marginnote">卡诺图的本质是"几何化的吸收律"：相邻两格 $x\bar y$ 与 $xy$ 合并为 $x$（$x\bar y + xy = x$）。它是奎因-麦克拉斯基算法的"画图版"，变量多时（>5）图太挤，要退回算法——下一节就是算法的机械化。</span>

## 1 卡诺图的布局

**卡诺图**：把 $n$ 个变量分成两组，行与列按**格雷码**（每次只变一位）排列，构成 $2^n$ 个格子的网格。每个格子对应一个最小项，填该输入下的函数值（1/0，或无关项 X）。

**2 变量图**：

```
      y  y'
x   | 1 | 0 |
x'  | 0 | 1 |
```

**3 变量图**（$x$ 分上下两行，$yz$ 按格雷码 00,01,11,10 排四列）：

```
     yz=00  01  11  10
x=0  |    |   |   |   |
x=1  |    |   |   |   |
```

**为什么格雷码**：相邻格（含首尾环绕）恰好**只差一个变量**——这是合并的前提。$yz$ 的 11 与 10 相邻（末位从 1 变 0），与 01 也相邻（中间位从 1 变 0）——**环绕边也相邻**（左右、上下、以及"卷起来"的边界）。

## 2 公式解析：圈相邻 1 合并

**合并规则**：圈住**大小为 2 的幂**（1、2、4、8…）的、形状规整（矩形/方形）的相邻 1 块，每个圈对应一个乘积项——**圈内变化过的变量被消掉**。

**例（3 变量）**：$F(x,y,z) = \sum m(0,1,3,5)$（最小项 0,1,3,5 输出 1）。

- 填图后，1 在格 000、001、011、101。
- 圈 $m(0,1)$：$yz = 00,01$ 两格，$y$ 不变为 0、$z$ 变化（0↔1）——消 $z$，得 $\bar x \bar y$。
- 圈 $m(0,?)$ 注意 $m(0)$ 与 $m(1)$ 相邻、$m(1)$ 与 $m(3)$ 相邻、$m(3)$ 与 $m(5)$？不相邻（010 与 101 差两位）。重新圈：$m(0,1)$ → $\bar x \bar y$；$m(1,5)$（001 与 101 相邻，$x$ 变化）→ $\bar y z$；$m(3)$ 孤立？$m(3)=011$，与 $m(1)=001$ 相邻（$z$ 变）已圈、与 $m(5)$? 011 与 101 差两位。实际最优：$F = \bar x\bar y + \bar y z + \bar x z$？——手动验证繁，重点在方法。

**拆解合并为何消变量**：

$$
x \bar y \bar z + x \bar y z = x\bar y(\bar z + z) = x\bar y
$$

- **第一步，找相邻对**：两格只差一个变量（如 $\bar z$ 与 $z$）。
- **第二步，套互补消元**：$\bar z + z = 1$，该变量消失。
- **第三步，读乘积项**：剩下不变的变量相乘——圈越大消的变量越多，乘积项越简。

**为什么圈越大越好**：4 格圈消 2 个变量、8 格圈消 3 个——**圈越大，乘积项越短**。贪心：先用大圈覆盖尽可能多的 1，再补小圈，追求"圈最少 + 总项最简"。

## 3 卡诺图的规则与无关项

**完整流程**：

1. 按格雷码填表；
2. 圈 1：圈越大越好、圈要覆盖所有 1、允许"环绕"（首尾相邻）、允许重叠（同一格可属多个圈）；
3. 读乘积项：每个圈内不变的变量相乘；
4. OR 全部乘积项。

**无关项（don't care）**：某些输入组合不可能出现（或输出无关紧要），标 X。X 可当作 1 来圈（帮助合并）、也可留作 0——**善用 X 能显著化简**。

**例**：BCD 码中 1010–1111 不会出现，标 X；圈 1 时把 X 当 1 用，可能圈出更大块。

**辨析｜易错点：** 卡诺图合并的两个高频错误：一是**圈非矩形**（如对角两格不能圈，必须矩形/方形且边数 2 的幂）；二是**忘记环绕**（最左与最右列、最上与最下行相邻）。**格子的"邻接"是环绕的**——这是卡诺图布局最反直觉、也最容易丢分的地方。

## 4 为什么卡诺图能化简

**本质**：卡诺图把"找可合并的最小项"变成"找相邻的 1"。相邻 = 只差一个变量 = 可套吸收律合并。

**与代数的对应**：

- 相邻 2 格 → 消 1 个变量（吸收律一次）。
- 相邻 4 格 → 消 2 个变量（吸收律两次）。
- 相邻 $2^k$ 格 → 消 $k$ 个变量。

**局限**：变量 $\le 4$ 时图清晰好用；5 变量要两张图、6 变量四张——图变得笨重。此时转向**奎因-麦克拉斯基算法**（下一节），它是卡诺图思想的机械化和可编程化。

<span class="marginnote">卡诺图在 EDA 里被 QM 算法和启发式逻辑综合取代，但它的<strong>"相邻合并"直觉</strong>仍是理解两级逻辑最小化的钥匙。而"用几何邻接表达逻辑邻近"的想法，在第四级《大模型部署》的算子调优（数据布局、图优化）里也有回响——<strong>把逻辑结构画成空间结构，常常让难题变直观</strong>。</span>

## 5 一个含无关项的卡诺图完整例子

无关项（don't care）是卡诺图最有威力的地方——用好它，化简效果立竿见影。

**例**：$F(w,x,y,z) = \sum m(1,3,7,11,15) + d(0,2,5)$（$d$ 为无关项，4 变量）。

**不用无关项的圈法**：圈 1 需要 5 个圈，表达式较长。

**善用无关项的圈法**：把无关项当 1 来圈，能圈出更大的块。

- $m(1,3,5,7)$（含无关项 5）：$w$ 变、$x$ 变、$y$ 不变为 1、$z$ 变 → 乘积项 $y$。
- $m(3,7,11,15)$：$y$、$z$ 变，$w$、$x$ 不变为 1 → 乘积项 $wx$。
- $m(1,3,9?,...)$ 视布局而定……

标准结果：$F = y + wx$（用无关项把第一块圈成 4 格）。

**公式解析：为什么无关项能"白用"**

无关项 $X$ 在"输出 1"的行上既可填 1 也可填 0。把它当 1 圈进来，**只是扩大圈、消除更多变量**：

$$
xy + x\bar y = x(y + \bar y) = x \quad \text{（2 格消 1 变量）}
$$

$$
xy + x\bar y + \bar x y + \bar x \bar y = 1 \quad \text{（4 格消 2 变量）}
$$

- **第一步，读收益**：圈越大消的变量越多，乘积项越短。
- **第二步，读合法性**：无关项对应的输入实际不会出现，输出任意——当 1 当 0 都不影响真值表正确性。
- **第三步，读风险**：别把无关项圈成"必须"——它只是"可借用"，最终表达式对真实输入必须正确。∎

**辨析｜易错点：** 无关项**不是**一定当 1。若某个无关项在 $F=0$ 的圈里更有用（帮助消变量），也可以当 0。**"哪里有用放哪里"**——同一无关项可同时参与多个圈的"借力"，但最终要保证真实输入的正确性。

**这个例子的要点**：无关项把卡诺图化简从"圈 1"升级为"借 X 圈大块"。**工程里"不会出现的输入"很常见（如非法编码），正确标注无关项能省一半电路**——EDA 工具最爱的优化空间。

## 6 小结

- **卡诺图**：格雷码排布的 $2^n$ 格真值表，相邻格只差一个变量（含环绕）。
- **合并**：圈 $2^k$ 个相邻 1，消 $k$ 个变化变量，读乘积项。
- 圈越大越简；覆盖全部 1；允许重叠与环绕。
- **无关项 X**：可当 1 用，帮助合并。
- 变量 >4 时卡诺图拥挤，转奎因-麦克拉斯基算法。
