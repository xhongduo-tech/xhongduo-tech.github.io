# 整除性：整除、因子与带余除法

<div class="epigraph">
<p>数论的一个基本事实是：任何一个整数都可以被除以另一个整数，留下一个余数。这看似平凡，却是一切密码学的起点。</p>

## 为什么从整除开始

我们在算法篇学会了数复杂度、写伪代码、证明正确性，但那都是**通用的计算骨架**。从本篇起，我们进入数论——研究对象不是"任意输入"，而是**整数本身**。为什么离散数学要把整整一章献给整数？因为整数是计算机唯一能精确表示的对象，而**密码学、哈希、RSA、错误校验码全部建立在整数的整除结构之上**。<span class="marginnote">整除性在大模型世界里并不遥远：tokenizer 的 BPE 词表构建、attention 的 mask、分布式训练里 batch 的切分，处处是整数划分问题。而 RAG 检索用的向量量化，也依赖有限域上的算术。</span>

罗森把整除放在第 4 章第 1 节，是有意的：先立住"整除是什么、余数怎么定义"这两个地基，后面的同余、素数、最大公约数、RSA 才有处安放。

## 1 整除与因子

**整除（divisibility）**：若存在整数 $c$ 使得 $a = bc$，则称 $b$ **整除** $a$，记作 $b \mid a$，并称 $b$ 是 $a$ 的**因子（factor）**或**除数（divisor）**，$a$ 是 $b$ 的**倍数（multiple）**。若 $b$ 不整除 $a$，记作 $b \nmid a$。

几个立刻要养成的符号习惯：

- $b \mid a$ 是一个**命题**（对/错），不是运算结果。$3 \mid 12$ 为真，$4 \mid 7$ 为假。
- 整除定义里允许 $a$ 为负：$3 \mid -12$ 成立，因为 $-12 = 3 \times (-4)$。
- 若 $b \mid a$，则 $-b$ 也整除 $a$：因子总是成对出现 $\pm$。通常我们只讨论正因子。

**核心性质**（可直接从定义推出，构成整除的运算规则）：

1. 若 $a \mid b$ 且 $a \mid c$，则 $a \mid (b + c)$；
2. 若 $a \mid b$，则 $a \mid bc$ 对任意整数 $c$ 成立；
3. 若 $a \mid b$ 且 $b \mid c$，则 $a \mid c$（**传递性**）。

<span class="marginnote">这三条性质会反复用于证明：性质 1 说"整除保持加法"，性质 2 说"整除可被缩放"，性质 3 说"整除可传递"。第 3 级算法里判断"一个数能否被 3 整除"、密码学里推导模运算的恒等式，都是这些性质的直接应用。</span>

**辨析｜易错点：** 整除记号 $a \mid b$ 与除法 $a/b$ 方向相反，初学极易写反。$a \mid b$ 读作「$a$ 整除 $b$」，等价于 $b = a \cdot k$。检验：$2 \mid 6$ 为真，$6 \mid 2$ 为假。记法上，**竖线左侧是除数**。

## 2 带余除法：整除的推广

不是所有整数对都能整除。把「恰好除尽」放宽成「除到不能除为止」，就是**带余除法（division algorithm）**：

**定理（带余除法）**：设 $a$ 是整数，$d$ 是正整数，则存在**唯一**的整数 $q$ 与 $r$，使得

$$a = dq + r, \qquad 0 \le r < d$$

其中 $q$ 称为**商（quotient）**，$r$ 称为**余数（remainder）**。

这个定理有两个值得强调的点：

- **存在性**：总能把 $a$ 写成 $d$ 的倍数加一个"足够小"的余数。
- **唯一性**：$q$ 与 $r$ 只有一对——**这是余数能作为"身份标识"的前提**。正因为唯一，我们才能用余数给整数分类（下一节的同余）。

**例**：$a = 101$，$d = 11$。$101 = 9 \times 11 + 2$，所以 $q = 9$、$r = 2$。注意余数必须满足 $0 \le r < 11$，写 $101 = 10 \times 11 - 9$（$r = -9$）就不符合约定。

**辨析｜易错点：** 当 $a$ 为负数时，余数仍要取**非负**。例如 $a = -101$，$d = 11$：$-101 = (-10) \times 11 + 9$，$q = -10$、$r = 9$。这里商向下取整（$-101/11 \approx -9.18$，取 $-10$），余数才能落在 $[0, d)$。很多语言的 `%` 运算符对负数的行为与此不同，是工程里的经典坑。

## 3 公式解析：余数的计算公式

给定 $a$ 与 $d$，商和余数可以直接用取整函数算：

$$
q = \left\lfloor \frac{a}{d} \right\rfloor, \qquad r = a - d\left\lfloor \frac{a}{d} \right\rfloor
$$

以 $a = -101$、$d = 11$ 为例拆解：

- **第一步，算商**：$a/d = -101/11 = -9.181\dots$，下取整得 $q = \lfloor -9.18\dots \rfloor = -10$。注意对负数，下取整是**往更小的方向取**，所以是 $-10$ 而不是 $-9$。
- **第二步，算余数**：$r = a - dq = -101 - 11 \times (-10) = -101 + 110 = 9$。
- **第三步，验证范围**：$0 \le 9 < 11$ 成立，正是我们要的非负余数。

这里 `floor` 的语义至关重要：**余数非负，是因为商向下取整**。如果用截断除法（向零取整），$-101/11$ 会得到 $q = -9$、$r = -2$，余数为负——这就是编程语言 `%` 的经典分歧根源（Python 与 C 对负数取模结果不同）。

## 4 整除结构：模算术的前奏

带余除法把整数分成两类：**余数恰为 0** 的（即被整除），与**余数非零**的。整除就是"余数为 0"的特殊情形：

$$d \mid a \iff a \bmod d = 0$$

从此以后，`a mod d` 与「$d$ 除 $a$ 的余数」是同义语，这是整座数论大厦的通用记号。由余数的唯一性，立刻得到一个重要的**分类视角**：对固定模数 $d$，每个整数都落入 $d$ 个"余数桶"之一——余数为 0、1、2、……、$d-1$。**整个整数集被模 $d$ 划分成 $d$ 个等价类**，这正是下一节同余概念、以及后面密码学里"模 $n$ 运算"的入口。<span class="marginnote">「按余数把整数分桶」是离散数学里最深刻的视角之一：它把无穷的整数集折叠成有穷的 $d$ 个桶，运算在桶之间仍然闭合。到第三级《数据结构》，哈希表的取模寻址用的就是同一个折叠。</span>

## 5 整除性质的证明：一个完整例子

用整除的三条性质做一道完整的证明题，体会"性质驱动的论证"。

**命题**：若 $a \mid b$ 且 $a \mid c$，则 $a \mid (b + c)$ 且 $a \mid (b - c)$。

**证明**：由 $a \mid b$，存在整数 $m$ 使 $b = am$；由 $a \mid c$，存在整数 $n$ 使 $c = an$。于是

$$
b + c = am + an = a(m+n), \qquad b - c = am - an = a(m-n)
$$

$m+n$ 与 $m-n$ 都是整数，所以 $a$ 整除 $b+c$ 与 $b-c$。∎

**公式解析：线性组合的推广**

上面的论证立即推广为：**若 $a \mid b$ 且 $a \mid c$，则 $a$ 整除 $b$ 与 $c$ 的任何整数线性组合 $sb + tc$**。

$$
sb + tc = s(am) + t(an) = a(sm + tn)
$$

- **第一步，读代入**：把 $b = am$、$c = an$ 代入组合式。
- **第二步，读提公因子**：提取 $a$，剩下 $sm + tn$ 是整数。
- **第三步，读推论**：$a \mid (sb + tc)$ 对任意整数 $s, t$ 成立。∎

**这个推广的地位**：它是带余除法、扩展欧几里得算法里"贝祖系数组合"的雏形——$sa + tb = \gcd(a,b)$ 正是"整除可缩放可加"的组合版。**你在第五篇见过的贝祖等式，源头就是这条小小的性质**。

**辨析｜易错点：** 整除的性质说的是"若 $a\mid b$ 且 $a\mid c$，则 $a$ 整除**它们的组合**"，方向别反——"$a$ 整除组合"推不出"$a$ 整除每个分量"（如 $2 \mid (1+1)$ 但 $2 \nmid 1$）。**"和整除 ⟹ 分量整除"不成立**。

## 6 小结

- **整除** $b \mid a$：存在整数 $c$ 使 $a = bc$；竖线左侧是除数。
- 整除三性质：保持加法、可缩放、可传递。
- **带余除法**：$a = dq + r$，$0 \le r < d$，$q$、$r$ 唯一存在。
- 商**向下取整**、余数**非负**——负数除法最易出错。
- $d \mid a \iff a \bmod d = 0$；模 $d$ 把整数划分成 $d$ 个余数桶。

在下一节，余数将从一个"除法的副产品"升级为"整数的身份标签"——我们进入**模算术**，研究"两个数除以 $d$ 余数相同"这件事的运算性质。
