## 为什么"涂颜色"是个深刻问题

地图上的国家要染成不同颜色使相邻国不同色，问最少几种颜色。把它翻译成图：国家是顶点、相邻是边，问题变成**给图的顶点染色使相邻顶点异色**，最少颜色数叫**色数（chromatic number）**。四色定理——平面图最多需要 4 色——是图论最著名的定理，也是第一个依靠计算机证明的重大定理。而图着色远不止地图：考试排课、寄存器分配、无线频段分配全是着色问题。<span class="marginnote">图着色是组合优化的"着色工厂"：课程表（同一时间不能冲突的课染不同色）、编译器寄存器分配（同一寄存器不能给冲突变量）、频谱分配（相邻基站不同频）——全部建模成着色。判定"色数 ≤ k"是 NP 完全问题，但平面图四色定理给出特例的简单上界。</span>

## 1 着色与色数

**图着色（graph coloring）**：给 $G$ 的每个顶点赋一种颜色，使**相邻顶点颜色不同**。用 $k$ 种颜色的着色叫 **$k$-着色**。

**色数（chromatic number）$\chi(G)$**：$G$ 的 $k$-着色存在的最小 $k$。

**例**：

- $\chi(K_n) = n$：完全图任意两顶点相邻，必须全不同色。
- $\chi(C_n) = 2$（$n$ 偶）、$3$（$n$ 奇）：偶圈可以两色交替，奇圈不行（回到起点撞色）。
- $\chi(K_{m,n}) = 2$：二分图两拨各一色。
- **二分图 ⟺ $\chi \le 2$**：一个图能用 2 色着 ⟺ 它是二分图（无奇圈）——这与特殊图一节完全呼应。

**辨析｜易错点：** 色数是"最少需要几种颜色"，不是"我们用了几种"。$K_4$ 用 5 色染也行，但 $\chi(K_4) = 4$。**求色数 = 找最少方案**。

## 2 四色定理

**定理（四色定理）**：每个平面图都是 4-可着色的，即平面图 $G$ 满足 $\chi(G) \le 4$。

- **历史**：1852 年由地图着色问题提出（格思里）。百年悬而未决，无数错误证明（包括大数学家肯普的"证明"，后被发现漏洞）。
- **解决**：1976 年阿佩尔与哈肯用计算机检查约 2000 个"不可约构型"，首次计算机辅助证明，震惊数学界。
- **三色**：判定平面图是否 3-可着色是 NP 完全——所以四色是"刚好够用"的漂亮上界。

**为什么是"4"**：欧拉公式的推论给出平面图 $e \le 3v - 6$，从而**每个平面图必有度 ≤ 5 的顶点**（否则总度 > 6v > 2e 矛盾）。这个"存在低度顶点"的事实是五色、四色证明的支点。

## 3 公式解析：平面图六色/五色的简单证明

四色证明需要计算机；但**六色与五色**可以用归纳法手工证明。以**六色**为例：

**定理**：每个平面图 $\chi(G) \le 6$。

**证明（归纳于顶点数）**：

- **基础**：$v \le 6$ 时每个顶点一色，≤ 6 色。✓
- **归纳步**：由 $e \le 3v - 6$，存在度 ≤ 5 的顶点 $u$（若所有顶点度 ≥ 6，总度 ≥ 6v > 2(3v-6) 当 $v$ 大时矛盾）。删去 $u$，剩下 $G - u$ 是平面图，由归纳假设可 6-着色。$u$ 最多 5 个邻居，占至多 5 种颜色，还剩至少 1 种颜色给 $u$。用剩余颜色染 $u$，完成 6-着色。∎

- **第一步，找低度顶点**：平面性 ⟹ 总有度 ≤ 5 的顶点。
- **第二步，归纳删点**：删 $u$ 后小图可 6 着色。
- **第三步，回填**：$u$ 的邻居 ≤ 5 个，6 色里必有空余。∎

**五色的证明**略难（需处理"两邻居颜色相同怎么办"的 Kempe 链），但核心骨架与六色相同。**"平面性给出低度顶点，低度顶点让归纳可行"** 是这一系列证明的统一套路。

## 4 着色算法与贪心

**贪心着色**：按某个顶点顺序，逐个给顶点染"邻居没用过的最小颜色"。它最多用 $\Delta + 1$ 种颜色（$\Delta$ 是最大度），所以

$$\chi(G) \le \Delta(G) + 1$$

**例**：$K_n$：$\Delta = n-1$，贪心用 $n$ 色——恰好等于 $\chi$。星图 $K_{1,n}$：$\Delta = n$，但 $\chi = 2$——贪心上界很松。

**为什么贪心上界重要**：即使不知道 $\chi$，$\Delta + 1$ 给出**保证可用的颜色数**。着色问题的工程版（排课）常常只要"不太多"的颜色即可。

**辨析｜易错点：** 贪心着色结果**依赖顶点顺序**——不同顺序可能用不同颜色数。$\Delta + 1$ 是任何顺序都保证的上界，不是最优。**求 $\chi$ 需优化顺序或回溯**，贪心只是近似。

<span class="marginnote">着色与计算复杂性的关系：<strong>判断 $\chi(G) \le 3$ 是 NP 完全</strong>（3-着色），而 2-着色（二分性判定）是多项式。这条"2 易、3 难"的断层线，是复杂性理论最生动的教材。平面图 4-着色容易但 3-着色判定仍是 NP 完全——着色问题的难度结构层层嵌套。</span>

## 5 着色应用：排课问题与贪心着色

图着色最大的工程价值在**排课/调度**：把"不能同时发生的冲突"建模成边，颜色 = 时间段。

**例（排课）**：5 门课 A、B、C、D、E。冲突：A 与 B、A 与 C、B 与 D、C 与 D、D 与 E。把这些冲突画成图，求最少时间段（色数）。

**贪心着色**（按某顺序逐个染最小可用色）：

- 染 A 色 1；B 与 A 冲突 → 色 2；C 与 A 冲突 → 色 2（B、C 不冲突）；D 与 B、C 冲突 → 色 1（A 色）；E 与 D 冲突 → 色 2（B 色）。

结果用了 2 色：{A, D} 时间段 1、{B, C, E} 时间段 2。**2 个时间段即可完成全部排课**——若不用着色，暴力排课要试 $5!$ 种顺序。

**公式解析：贪心着色的上界证明**

设最大度 $\Delta$，贪心着色至多用 $\Delta + 1$ 色：

$$
\chi(G) \le \Delta(G) + 1
$$

- **第一步，读贪心**：给顶点 $v$ 染色时，$v$ 至多有 $\Delta$ 个已染邻居，占至多 $\Delta$ 种颜色。
- **第二步，读结论**：$\Delta + 1$ 种颜色里必有空余，$v$ 必可染。
- **第三步，读推广**：这个上界对**任何顺序**的贪心都成立——虽然可能远松于 $\chi$（如 $K_{1,n}$ 的 $\Delta=n$ 但 $\chi=2$）。∎

**辨析｜易错点：** 贪心着色结果**依赖顶点顺序**——不同顺序可能给出不同颜色数。$\Delta+1$ 是所有顺序都保证的"安全上界"，不是最优。**要真最优得回溯或求色数，贪心只是快近似**。

**这个例子的要点**：着色的工程形态 = "冲突图 + 时间段染色"。排课、寄存器分配、频谱分配全是这个模型。**贪心着色给"够用"的解，$\Delta+1$ 给"保证"的界**——工程里"够用"常比"最优"更有价值。

## 6 小结

- **$k$-着色**：相邻顶点异色的顶点染色；**色数 $\chi(G)$** = 最少颜色数。
- 二分图 ⟺ $\chi \le 2$；$\chi(K_n) = n$、$\chi(C_n) = 2$（偶）或 3（奇）。
- **四色定理**：平面图 $\chi \le 4$；1976 年首个重大计算机辅助证明。
- **六色/五色**可由"平面性 ⟹ 有度 ≤5 顶点" + 归纳证明。
- **贪心着色**：$\chi \le \Delta + 1$；$\chi \le 3$ 的判定是 NP 完全。

**再辨析｜易错点：** 色数 $\chi(G)$ 与"最大团大小 $\omega(G)$"不同——团是"两两相邻的顶点集"，色数是最少颜色数。$\chi \ge \omega$（团内必须异色），但**不相等**（某些图 $\chi > \omega$，如奇圈 $C_5$：$\omega=2$、$\chi=3$）。**别把"团"当"色数"**。

**小结补记**：着色把"冲突"变成"颜色分配"——**排课、寄存器、频谱全是同一模型**。四色定理给平面图一个漂亮的保证（≤4），而一般图的色数求值则掉进 NP 完全的深水区。**"平面图好办、一般图难办"** 是着色问题最鲜明的分界。

**快速自测**：$K_4$ 的色数是多少？4——任意两顶点相邻，必须全异色。$C_4$（方形）呢？2——偶圈可两色交替。**$\chi(K_n)=n$、$\chi(C_n)=2$（偶）/3（奇）、二分图 $\chi \le 2$**。

**本节一句话回顾**：图着色 = "冲突图 + 颜色分配"，色数是最少颜色数；**平面图四色定理给出保证，一般图求色数是 NP 完全**。
