## 为什么图里能"长树"

树是最小连通骨架，而任何连通图都"包含"一棵树——把多余的边删掉，剩下一个覆盖所有顶点的树。这棵树叫**生成树（spanning tree）**。如何高效地找生成树？**深度优先搜索（DFS）**与**广度优先搜索（BFS）**是两种最基本的图遍历，也是生成树的两大产地。它们不只是数据结构课的算法，更是理解图结构的"显微镜"。<span class="marginnote">DFS 与 BFS 是第三级《数据结构》与《算法设计与分析》的双主角：连通性判断、二分图判定、强连通分量、拓扑排序、最短路径（无权 BFS）全建立在它们之上。而"生成树 = 图的最小覆盖骨架"是下一节最小生成树的直系前身。</span>

## 1 生成树

**生成树（spanning tree）**：图 $G$ 的**生成子图**（顶点全保留），且是一棵树（连通无圈）。

**例**：$C_4$（方形）删去一条边得 $P_4$——$C_4$ 的一棵生成树。$C_4$ 共有 4 棵生成树（删任意一条边）。

**性质**：连通图的生成树有 $n$ 个顶点、$n-1$ 条边——由树的性质自动成立。

**定理**：$G$ 连通 ⟺ $G$ 有生成树。

**证明**：连通则反复删"圈上的边"（删掉不破坏连通），直到无圈——得到连通无圈生成子图 = 生成树。反过来，有生成树则 $G$ 含连通子图，$G$ 连通。∎

**这个"反复删圈边"的构造**是生成树存在性的核心论证，也是"冗余边可以被安全移除"的直觉来源——网络的备份链路可以删到只剩骨架。

## 2 深度优先搜索（DFS）

**DFS**：从起点出发，尽可能深入——走到不能走再回溯。

```
procedure DFS(G, v):
    mark v visited
    for each 邻接 u of v:
        if u 未访问:
            DFS(G, u)
```

**DFS 生成树**：记录 DFS 过程中"首次发现"的边（树边），形成一棵生成树。

**例**：从顶点 a 出发 DFS，若邻居顺序固定，得到一棵 DFS 生成树；树的边是"探索新顶点"的边，其余边是回边（指向祖先）。

**DFS 性质**：

- 空间 $O(h)$（递归栈，$h$ 为深度）；时间 $O(V+E)$。
- **判连通**：一次 DFS 访问到所有顶点 ⟺ 连通。
- 回边出现 ⟺ 图有圈。

## 3 广度优先搜索（BFS）

**BFS**：从起点出发，**一层层**向外推进——先访问所有距离 1 的，再距离 2 的……

```
procedure BFS(G, v):
    队列 Q; Q.push(v); mark v visited
    while Q 非空:
        u = Q.pop()
        for each 邻接 w of u:
            if w 未访问:
                mark w; Q.push(w)
```

**BFS 生成树**：记录"首次发现"的边，形成 BFS 生成树。**BFS 树从根到每个顶点的路径恰好是该顶点的最短路径（无权图）**——这是 BFS 最珍贵的性质。

**例**：无权图从 a 出发 BFS：a 的距离 0；其邻居距离 1；邻居的邻居距离 2……BFS 树按"层"组织，根到任何顶点的树路径就是最短路。

**DFS vs BFS**：

| 维度 | DFS | BFS |
| --- | --- | --- |
| 结构 | 递归/栈 | 队列 |
| 顺序 | 深（一条路走到底） | 宽（逐层扩展） |
| 空间 | $O(h)$（$h$ 深度） | $O(w)$（$w$ 宽度） |
| 最短路径 | 否 | **是（无权图）** |
| 圈检测 | 回边 | 跨层边 |

## 4 公式解析：为什么 BFS 树是最短路树

**定理**：无权图 $G$ 中，BFS 树从根 $s$ 到任意顶点 $v$ 的唯一路径是 $s$ 到 $v$ 的一条最短路径。

**证明（按距离归纳）**：设 $\text{dist}(v)$ = $s$ 到 $v$ 的真实最短路长，$d(v)$ = BFS 树中 $v$ 的深度。

- **第一步，$d(v) \ge \text{dist}(v)$**：树路径是一条具体路径，长度不小于最短路。
- **第二步，$d(v) \le \text{dist}(v)$（归纳）**：对 $\text{dist}(v) = k$ 归纳。取真实最短路径 $s \to \dots \to u \to v$，$\text{dist}(u) = k-1$。由归纳假设 $d(u) \le k-1$。BFS 中 $u$ 出队时，$v$ 尚未访问或已被访问：若未访问则 $v$ 在 $u$ 的下一层入队，$d(v) = d(u)+1 \le k$；若已访问则 $d(v) \le d(u)+1 \le k$。两种情形 $d(v) \le k = \text{dist}(v)$。
- **第三步，合并**：$d(v) = \text{dist}(v)$，树路径最短。∎

**为什么 BFS 而非 DFS**：BFS 按层推进，先访问近的——"层数 = 距离"；DFS 乱序深入，树深不代表距离。**BFS 队列的先进先出保证层序**。

**辨析｜易错点：** 这一定理只对**无权图**成立。带权图的最短路（迪克斯特拉）需要优先队列，BFS 不再适用——"层"与"距离"在带权时脱钩。

<span class="marginnote">DFS/BFS 的"树 + 剩余边"分解（树边/回边/跨边）是图算法分析的通用语言：无向图无向 DFS 的回边 ⟺ 有圈；有向图 DFS 的时间戳区分树边、前向边、回边、横叉边——这是 Tarjan 求强连通分量、拓扑排序（DFS 后序）的基础。第三级《算法》会把这些全部展开。</span>

## 5 DFS 与 BFS 的完整应用：判断连通性与找路径

把 DFS/BFS 落到两个最常见的判定任务上。

**任务 1：判连通**。从任意顶点做一次 DFS 或 BFS，若访问到全部 $n$ 个顶点则连通。

```
procedure isConnected(G):
    v := 任一顶点
    visited := DFS(G, v)      # 或 BFS
    return |visited| == |V|
```

**为什么对**：DFS/BFS 访问的正是"从 v 可达的全部顶点"（可达集）。图连通 ⟺ 任意顶点的可达集是全图。**一次遍历 $O(V+E)$ 解决连通性判定**。

**任务 2：找无权最短路径**。BFS 树中，根到任意顶点的路径即最短路——用 BFS 逐层扩展。

**公式解析：为什么 BFS 是"层层推进"**

BFS 用队列，先入先出：当前层全部出队后才轮到下一层。

$$
\text{队列}:\ \text{距离 } 0 \to \text{距离 } 1 \to \text{距离 } 2 \to \dots
$$

- **第一步，读层序**：队列保证"先进先出"，距离 $k$ 的顶点全部先于距离 $k+1$ 出队。
- **第二步，读距离**：顶点首次被访问时的"层号"就是它到根的距离（无权）。
- **第三步，读树路径**：BFS 树的边都是"从已访问到新访问"，树路径即最短路径。∎

**DFS vs BFS 的选择**：

| 场景 | 选谁 |
| --- | --- |
| 判连通 / 找圈 | 两者皆可，DFS 栈浅 |
| 无权最短路 | **BFS**（层序 = 距离） |
| 拓扑排序 | DFS 后序 |
| 深度受限搜索 | DFS |

**这个例子的要点**：DFS/BFS 是最通用的图遍历件——**连通性、可达集、无权最短路、圈检测全是一次遍历**。选型口诀：**要"最短"用 BFS，要"深入"用 DFS**。

**辨析｜易错点：** BFS 找最短路的路径是"树路径"，但**可能有多个同样短的路径**——BFS 只保证找到"一条"最短的。另外 BFS 需要标记已访问，否则队列无限增长（环导致重复入队）。**访问标记是 BFS 不出死循环的保障**。

## 6 小结

- **生成树**：连通图的顶点全保留的树子图；$n$ 顶点 $n-1$ 边；连通 ⟺ 有生成树。
- **DFS**：一条道走到底 + 回溯；递归/栈；判连通、找圈。
- **BFS**：逐层推进；队列；**无权最短路**。
- **BFS 树路径 = 最短路**：层数 = 距离，归纳证明。
- 两者都 $O(V+E)$，是图算法的基本遍历件。
