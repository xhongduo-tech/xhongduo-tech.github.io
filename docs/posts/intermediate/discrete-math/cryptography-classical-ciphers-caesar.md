## 为什么在数论里学密码学

前面几节的同余、模逆元、欧拉定理，抽象度一路走高。这一节它们终于有了"用处"——**密码学（cryptography）**。罗森把密码学放进数论章节是有深意的：古代密码是"换字母"的拼图游戏，现代密码则是模运算的数学工程。从凯撒密码到 RSA 的跳跃，正好展示离散数学如何从玩具级变成安全级。<span class="marginnote">这一节是整个《离散数学及其应用》里"从数学到应用"的缩影。密码学本身在第三级《密码学与信息安全》中是一门完整学科；这里先建立加密/解密/密钥的词汇表，为下一节 RSA 做铺垫。</span>

## 1 密码学的基本词汇

**密码学（cryptography）**研究如何把可读的**明文（plaintext）**通过**加密（encryption）**变成不可读的**密文（ciphertext）**，再通过**解密（decryption）**还原。加密与解密使用的关键信息叫**密钥（key）**。

几个必须分清的术语：

- **密码（cipher）**：加密/解密的具体算法，是"变换规则"。
- **密钥（key）**：控制算法具体怎么变的参数——同一个密码配不同密钥，加解密结果不同。
- **密码分析（cryptanalysis）**：在不掌握密钥的情况下破解密文的研究。

**凯撒密码（Caesar cipher）**：把每个字母在字母表上**后移 3 位**，尾部回绕。明文 `MEET` 加密为密文 `PHHW`。

**数学表述**：把字母映射为数字 `a=0, b=1, ..., z=25`，加密公式是

$$f(p) = (p + 3) \bmod 26$$

解密是 $f^{-1}(c) = (c - 3) \bmod 26$。这里"后移 3 位"就是密钥；模 26 的回绕正是我们学过的模运算——**凯撒密码就是一个模 26 的加法**。

## 2 公式解析：仿射密码——凯撒的推广

把"固定移 3 位"推广成"乘一个数再移一个数"，得到**仿射密码（affine cipher）**：

$$
f(p) = (ap + b) \bmod 26
$$

其中 $a$、$b$ 是密钥（整数），且要求 $\gcd(a, 26) = 1$。

- **第一步，加密**：明文数字 $p$，密文 $c \equiv ap + b \pmod{26}$。
- **第二步，解密要解方程**：$ap \equiv c - b \pmod{26}$。因为 $\gcd(a,26)=1$，$a$ 有模 26 逆元 $a^{-1}$，两边同乘：
- **第三步，得解密式**：$p \equiv a^{-1}(c - b) \pmod{26}$。

**实例**：$f(p) = (7p + 3) \bmod 26$。加密 `H`（=7）：$7 \times 7 + 3 = 52 \equiv 0$（`a`），密文为 `a`。解密时 $7$ 模 26 逆元为 $15$（$7 \times 15 = 105 \equiv 1$），对 `a`（=0）：$p = 15 \times (0 - 3) = -45 \equiv 7$（`h`），还原成功。

**辨析｜易错点：** 为什么要求 $\gcd(a, 26) = 1$？因为解密需要 $a$ 的模逆元；而逆元存在的充要条件正是互素。若 $a = 2$，则 $f(p) = 2p + b$ 把两个不同的明文字母映射到同一个密文（如 $p=0$ 与 $p=13$ 都得到 $b$），解密会得到两个可能明文——加密不可逆，密码就废了。**可逆性是密码的第一要求**。

## 3 破解古典密码：频率分析

凯撒密码只有 26 种密钥，暴力试 26 次就破。仿射密码的密钥 $(a,b)$ 组合数是 $\varphi(26) \times 26 = 12 \times 26 = 312$ 种，暴力也能破。但更有名的破解手段是**频率分析（frequency analysis）**：英语中 `e` 出现约 12.7%，`t` 约 9.1%，而 `z` 不到 0.1%。密文中出现最多的字母，大概率对应明文的 `e`。

<span class="marginnote">频率分析在 9 世纪由阿拉伯学者肯迪（Al-Kindi）系统化，是历史上最早的密码分析方法之一。它的原理是：单表替换密码（凯撒、仿射都属于它）把字母一一替换，但<strong>不改变频率分布</strong>——统计分布成了明文信息的泄漏通道。这个"替换不改变统计结构"的思想，在现代密码的"扩散与混淆"设计原则里依然回响。</span>

**对抗手段**：多表替换（如维吉尼亚密码）、换位密码等，都试图打破频率的一一对应。但它们依然属于**古典密码（classical ciphers）**——全部基于"替换/换位"的拼图式变换。

## 4 古典密码与公钥密码的鸿沟

古典密码有个共同特征：**加密密钥与解密密钥本质上是同一个秘密**（凯撒的"3"既是加密也是解密依据）。知道加密方式就能推出解密方式。这在密码学上叫**对称密码（symmetric cryptography）**，它带来一个现实难题：**双方怎么安全地共享密钥？**

这个难题正是公钥密码（下一节 RSA）要解决的：**加密密钥公开，解密密钥保密**。前者任何人都能用，后者只有接收方知道。从"共享秘密"到"公开加密、私密解密"，是密码学史上最大的范式转换。<span class="marginnote">对称密码的密钥分发难题直到 1976 年迪菲与赫尔曼发表《密码学的新方向》才得到根本解决——他们的密钥交换协议用了模幂运算，是下一节 RSA 的直接前奏。整个脉络是：<strong>数论（模运算）→ 密钥分发 → 公钥加密</strong>。</span>

## 5 破译凯撒密码：穷举与频率分析的对照

用一个具体例子把"数学表述"与"破译手段"串起来。

**例**：截获密文 `WKH TXLFN EURZQ IRA`（凯撒加密 3 位后的 `THE QUICK BROWN FOX`）。若知道密钥是 3，直接解密：每个字母回移 3 位得明文。若**不知道**密钥，怎么办？

**手段 1：穷举（brute force）**：凯撒只有 26 个密钥，逐个试：密文移 1、移 2、……、移 25。只有"移 3"得到有意义的英文，其余都是乱码。26 次尝试，人类几分钟、计算机忽略不计。

**手段 2：频率分析**：若密文很长，统计每个字母出现次数。英文 `e` 约占 12.7%，密文里出现最多的字母大概率对应明文 `e`——据此推断移位量。例如密文里 `X` 最多，则 $\text{移量} = \text{X} - \text{e} = 23 - 4 = 19$（模 26），试之即破。

**公式解析：破译的代数形式**

设明文字母 $p$、密文字母 $c$、密钥 $k$，加密 $c = (p + k) \bmod 26$。破译 = 求 $k$：

$$
k \equiv c - p \pmod{26}
$$

- **第一步，读未知数**：一个已知"明文-密文"字母对（如"最多字母对 e"）就给一个同余方程。
- **第二步，读单点破解**：一个字母对就能解出 $k$（模 26 唯一）——这就是为什么古典密码对已知明文攻击毫无抵抗力。
- **第三步，读推广**：仿射密码 $c = (ap+b) \bmod 26$ 需要**两个**字母对（解二元方程），比凯撒略强但仍秒破。∎

**辨析｜易错点：** 频率分析对**短密文**不可靠——样本太小，统计偏差大。凯撒密码的 26 个密钥穷举在短密文上更直接。**方法选择看长度：短用穷举，长用频率**。

**这个例子的要点**：古典密码的"数学表述"让破译成为"解同余方程"——数论与密码学的第一次实战。而"穷举可行"与"频率泄漏"共同说明：**古典密码的安全性是零**，它们的历史意义在于确立了"加密 = 数学变换"的范式。

## 6 小结

- **密码学术语**：明文、密文、加密、解密、密钥、密码分析。
- **凯撒密码** = 模 26 加法：$f(p) = (p+3) \bmod 26$，密钥是移位量。
- **仿射密码** $f(p) = (ap+b) \bmod 26$，可逆要求 $\gcd(a, 26)=1$（逆元存在）。
- **频率分析**破解单表替换：统计分布是明文信息的泄漏。
- 古典密码都是对称的，密钥分发难题引向公钥密码。

**再辨析｜易错点：** 凯撒密码的移位量 $k$ 与字母编号的约定要统一——若约定 `a=0`，加密是 $(p+k) \bmod 26$；若约定 `a=1`，公式要写成 $(p+k-1) \bmod 26 + 1$。**"从 0 开始还是从 1 开始"决定了公式形态**，做题先定坐标。

**小结补记**：古典密码的价值不在安全，而在确立了加密的"数学变换"范式——凯撒是模加、仿射是线性变换、频率分析是统计攻击。**"替换 + 换位 + 密钥"**三个词概括了整个古典密码时代；下一节 RSA 将用数论推翻"加密必须共享密钥"的假设。

**快速自测**：凯撒加密"后移 3 位"把 `HELLO` 变成什么？`KHOOR`（每个字母后移 3 位：H→K、E→H、L→O、L→O、O→R）。解密时每位回移 3 位即还原。**加密 $p+3 \bmod 26$、解密 $c-3 \bmod 26$，方向相反、模 26 回绕**。

**本节一句话回顾**：古典密码 = "替换 + 换位 + 密钥"的数学变换——凯撒是模加、仿射是线性变换，两者都被穷举与频率分析轻易击破；**对称密码的密钥分发难题，正是公钥密码的登场理由**。
**易混点再提醒**：仿射密码 $f(p) = (ap+b) \bmod 26$ 的 $a$ 必须与 26 互素（否则不可逆、无法解密）；凯撒是 $a=1$ 的特例。**"可逆"是密码的第一要求，$\gcd(a,26)=1$ 是仿射的可逆条件**。

**易错点再提醒**：频率分析对短密文不可靠（样本太小、统计偏差大），短密文用穷举更直接；仿射密码密钥空间 $12 \times 26 = 312$ 种，仍可穷举——**古典密码的安全性为零，它们的价值是确立"加密 = 数学变换"的范式**。
**易错点再提醒**：凯撒密码字母编号约定（`a=0` 或 `a=1`）决定公式形态——"从 0 开始"是 $(p+k) \bmod 26$，"从 1 开始"要移位调整，**做题先定坐标**。
**易错点再提醒**：多表替换（如维吉尼亚）打破单表频率的一一对应，但仍属古典密码——**"替换不改变统计结构"是现代密码"扩散与混淆"要解决的根源**。
**易错点再提醒**：古典密码的"加密密钥=解密密钥"是对称的；公钥密码把加密密钥公开、解密密钥保密——**密钥分发难题是两者分野的由来**。
**易错点再提醒**：破解仿射密码只需两个"明文-密文"字母对（解二元方程）——已知明文攻击对古典密码是致命的。
