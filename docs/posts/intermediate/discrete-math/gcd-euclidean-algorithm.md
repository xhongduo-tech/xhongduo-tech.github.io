## 为什么最大公约数如此关键

素数是整数的原子，但原子之间怎么"组合"？两个整数的公共结构就是它们的**最大公约数（greatest common divisor, gcd）**。它度量两个数"共享"多少素数因子，是整除理论里最重要的运算对象之一。<span class="marginnote">gcd 的应用无处不在：分数约分看分子分母的 gcd；RSA 生成密钥要验证两个数互素（gcd 为 1）；多项式的因式分解、错误校验码都建立在 gcd 之上。而计算 gcd 的欧几里得算法，是现存最古老的算法之一，却有着教科书级别的效率与优雅。</span>

## 1 最大公约数与互素

**最大公约数（gcd）**：设 $a$、$b$ 是不全为 0 的整数，$a$ 与 $b$ 的**最大公约数** $\gcd(a, b)$ 是能同时整除 $a$ 与 $b$ 的最大正整数。

**互素（relatively prime）**：若 $\gcd(a, b) = 1$，则称 $a$ 与 $b$ 互素——它们没有公共的素数因子。

- $\gcd(24, 36) = 12$，因为 $24 = 2^3 \cdot 3$、$36 = 2^2 \cdot 3^2$，公共部分 $2^2 \cdot 3 = 12$。
- $\gcd(17, 22) = 1$，17 与 22 互素。
- 约定 $\gcd(0, a) = |a|$、$\gcd(0, 0) = 0$，用数学约定填平边界。

**gcd 的"素数幂取小"公式**：若 $a = p_1^{e_1} \cdots p_k^{e_k}$、$b = p_1^{f_1} \cdots p_k^{f_k}$，则

$$\gcd(a, b) = p_1^{\min(e_1, f_1)} \cdots p_k^{\min(e_k, f_k)}$$

即每个素数因子**取指数较小的那个**。这个公式定义了 gcd，但前提是已经会分解质因数——而大数分解恰恰是困难的，所以实际计算 gcd 不能靠它。

## 2 欧几里得算法：辗转相除

**欧几里得算法（Euclidean algorithm）**建立在一条引理上：

**引理**：设 $a = bq + r$，其中 $a \ge b$、$0 \le r < b$，则

$$\gcd(a, b) = \gcd(b, r)$$

**证明**：任何同时整除 $a$ 与 $b$ 的数都整除 $r = a - bq$（整除保持加法缩放），故 $\gcd(a,b)$ 整除 $\gcd(b,r)$ 的候选；反过来任何整除 $b$ 与 $r$ 的数也整除 $a = bq + r$。两边互不遗漏，gcd 相等。

于是算法就是把"大问题 $\gcd(a,b)$"一步步降成"小问题 $\gcd(b, r)$"，余数严格减小，最终余数为 0 时停下：

```
procedure gcd(a, b)    # 假设 a >= b > 0
    while b != 0:
        r = a mod b
        a = b
        b = r
    return a
```

**实例**：$\gcd(252, 105)$。

| 步骤 | $a$ | $b$ | $r = a \bmod b$ |
| --- | --- | --- | --- |
| 1 | 252 | 105 | 42 |
| 2 | 105 | 42 | 21 |
| 3 | 42 | 21 | 0 |

余数首次为 0 时，返回此时的 $a = 21$，即 $\gcd(252, 105) = 21$。

<span class="marginnote">欧几里得算法为什么快？每次迭代余数至少减半：$r \le b/2$（因为若 $r > b/2$，则 $b \bmod r = b - r < b/2$）。所以迭代次数是 $O(\log b)$——对 512 位的数，只需约 512 次模运算，现代 CPU 一毫秒都不要。</span>

## 3 公式解析：为什么 gcd 收敛得这么快

证明欧几里得算法**终止且正确**，是理解它的一半。假设 $a > b > 0$，写出余数序列：

$$
\begin{aligned}
a &= bq_1 + r_1, \quad 0 \le r_1 < b \\
b &= r_1 q_2 + r_2, \quad 0 \le r_2 < r_1 \\
r_1 &= r_2 q_3 + r_3, \quad 0 \le r_3 < r_2 \\
&\vdots \\
r_{n-2} &= r_{n-1} q_n + r_n, \quad 0 \le r_n < r_{n-1} \\
r_{n-1} &= r_n q_{n+1} + 0
\end{aligned}
$$

- **第一步，看严格下降**：$b > r_1 > r_2 > \dots > r_n \ge 0$。余数序列是严格递减的非负整数列，最多 $b$ 步内必到 0——**终止性**有了。
- **第二步，回推相等**：$\gcd(a,b) = \gcd(b,r_1) = \gcd(r_1,r_2) = \dots = \gcd(r_{n-1}, r_n) = \gcd(r_n, 0) = r_n$——**正确性**有了。
- **第三步，看速度**：$r_{k+2} < r_k/2$，所以每两步至少减半，迭代数 $O(\log b)$。这比试除法快得多，正是"能处理 512 位大数"的原因。

**辨析｜易错点：** 递归版本写起来很漂亮，但**栈深**等于迭代次数。虽然 $O(\log b)$ 一般不深，但在极端情形（两个相邻斐波那契数）下迭代次数约 $\log_\varphi b \approx 1.44\log_2 b$——仍是对数级，安全。真正要警惕的是把终止条件写成 `while a != b`，当 $a$、$b$ 互素时会一路减到 1，退化成 $O(n)$。

## 4 斐波那契数与最坏情形

欧几里得算法的最坏情形发生在相邻斐波那契数上。斐波那契数列 $F_0=0, F_1=1, F_n = F_{n-1}+F_{n-2}$，相邻两项的 gcd 迭代恰好走满：

$$
\gcd(F_{n}, F_{n-1}) \to \gcd(F_{n-1}, F_{n-2}) \to \cdots \to \gcd(F_2, F_1) = \gcd(1,1) = 1
$$

因为 $F_n \bmod F_{n-1} = F_{n-2}$——每一步余数都是"上一上一个"斐波那契数，绝不减半，只按黄金比收缩。于是迭代次数约 $n \approx \log_\varphi b$，给出了欧几里得算法的最坏情形复杂度 $\Theta(\log b)$。<span class="marginnote">斐波那契数会在第七篇《归纳与递归》中正式登场：它的递推定义、封闭公式（比内公式）以及"相邻项互素"的性质，是离散数学里反复出现的明星序列。欧几里得算法的最坏分析是它最早的应用之一。</span>

## 5 gcd 与 lcm 的联系及一个完整计算例

gcd 与 lcm 之间有一条优雅的恒等式，是验算和速算的利器。

**定理**：对正整数 $a, b$：

$$\gcd(a,b) \cdot \operatorname{lcm}(a,b) = ab$$

**例**：$a = 12 = 2^2 \cdot 3$、$b = 18 = 2 \cdot 3^2$。$\gcd = 6$、$\operatorname{lcm} = 36$，$6 \times 36 = 216 = 12 \times 18$。✓

**公式解析：为什么恒等式成立**

从标准分解式看，设 $a = \prod p_i^{e_i}$、$b = \prod p_i^{f_i}$：

$$
\gcd(a,b) \cdot \operatorname{lcm}(a,b) = \prod p_i^{\min(e_i,f_i)} \cdot \prod p_i^{\max(e_i,f_i)} = \prod p_i^{\min(e_i,f_i) + \max(e_i,f_i)}
$$

- **第一步，读指数**：$\min + \max = e_i + f_i$ 恒成立（两者之和恒为两数之和）。
- **第二步，读乘积**：$\prod p_i^{e_i + f_i} = (\prod p_i^{e_i})(\prod p_i^{f_i}) = ab$。
- **第三步，读推论**：$\operatorname{lcm}(a,b) = ab / \gcd(a,b)$——**算 lcm 不必分解，先算 gcd 再除**。∎

**完整计算例**：求 $\operatorname{lcm}(252, 105)$。

- 用欧几里得：$\gcd(252,105) = 21$（前面算过）。
- $\operatorname{lcm} = 252 \times 105 / 21 = 26460 / 21 = 1260$。
- 验算（分解）：$252 = 2^2\cdot3^2\cdot7$、$105 = 3\cdot5\cdot7$，$\operatorname{lcm} = 2^2\cdot3^2\cdot5\cdot7 = 1260$。✓

**辨析｜易错点：** $\gcd \cdot \operatorname{lcm} = ab$ 要求 $a, b$ 是**正整数**；对 0 或负数不直接成立（约定 $\gcd(0,b) = |b|$ 时需另行处理）。另外这个恒等式**不推广到三个数**：$\gcd(a,b,c)\operatorname{lcm}(a,b,c) \ne abc$。**两数版本可放心用，三数版本别套**。

**这个例子的要点**：欧几里得算法算 gcd、恒等式算 lcm——**"先 gcd 后除"避免了分解大数**。这是工程里算 lcm 的标准捷径，也是"分解困难"时代数方法价值的体现。

## 6 小结

- **gcd**：同时整除两数的最大正整数；$\gcd(a,b)=1$ 称互素。
- gcd 公式：素数幂取小指数；但大数分解困难，不能靠它算。
- **欧几里得算法**：$\gcd(a,b)=\gcd(b, a \bmod b)$，余数序列严格下降直到 0。
- 复杂度 $O(\log b)$，最坏情形是相邻斐波那契数。
- 引理证明靠整除的加减性质：整除 $a,b$ ⇔ 整除 $b, r$。

在下一节，我们把 gcd 提升为整数的完整骨架——**算术基本定理与唯一分解**，证明"素数积木"的分解是唯一的。
