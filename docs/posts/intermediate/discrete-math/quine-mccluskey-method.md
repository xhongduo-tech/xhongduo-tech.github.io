# 奎因-麦克拉斯基方法（Quine–McCluskey method）

<div class="epigraph">
<p>把"找相邻的 1"翻译成"找差一位的二进制串"——卡诺图靠眼睛，QM 方法靠表格。</p>
<footer>—— 改编自 Willard V. Quine 与 Edward J. McCluskey（1956）</footer>
</div>

<div class="article-byline">

## 为什么要把化简"机械化"

卡诺图在变量 ≤4 时靠人眼圈 1，但变量一多（5、6、7 个）图就不可用，而且人眼圈图无法保证"最优"。**奎因-麦克拉斯基方法（Quine–McCluskey, QM）**是卡诺图合并的系统化、算法化版本：用表格找出所有"可合并项"（素蕴含项），再用**覆盖问题**选出一组最简覆盖。它是可编程的（EDA 工具的逻辑综合核心），也是"组合优化"在逻辑化简里的标准形态。<span class="marginnote">QM 方法的两阶段——<strong>生成素蕴含项 + 最小覆盖</strong>——是很多组合优化问题的通用框架。第三级《算法》的集合覆盖问题、以及第四级《最优化理论》的覆盖/打包模型都长这个形状。而 QM 的可编程性让它能处理几十个变量，远超卡诺图的人眼极限。</span>

## 1 素蕴含项

**蕴含项（implicant）**：乘积项若使函数为 1 的所有输入都覆盖到（该乘积项为 1 ⟹ 函数为 1），则是蕴含项。

**素蕴含项（prime implicant）**：不能再被"消变量合并"的蕴含项——它本身无法与另一个蕴含项合并成更大的蕴含项。

**例**：$F = \bar x \bar y + \bar x z + y z$ 中，各乘积项是蕴含项；若 $\bar x \bar y$ 能与 $\bar x z$ 合并（共享 $\bar x$，消 $y/z$）成 $\bar x$？——$\bar x \bar y + \bar x z$ 不直接等于 $\bar x$（缺 $\bar x y z$ 项），所以未必。**素蕴含项 = 合并后的"最大块"**。

**直觉**：素蕴含项对应卡诺图的"最大圈"——不能再扩大的圈。最简表达式 = 用最少的素蕴含项覆盖全部 1。

## 2 算法第一步：生成素蕴含项

**方法**：用二进制串表示最小项，逐对合并"只差一位"的项，用 `-` 标记被消去的位。

**例**：$F(x,y,z) = \sum m(1,2,3,5,7)$。

- 最小项二进制：$m(1)=001$、$m(2)=010$、$m(3)=011$、$m(5)=101$、$m(7)=111$。
- **第一轮合并**（差一位的两项）：
  - 001 与 011 → `0-1`；001 与 101 → `-01`；010 与 011 → `01-`；011 与 111 → `-11`；101 与 111 → `1-1`。
  - 被合并过的项标记"已用"。
- **第二轮合并**（`-` 位置相同的差一位项）：`-01` 与 `-11` → `--1`；`0-1` 与 `1-1` → `--1`。
- **素蕴含项**：未被合并的项 = 最终输出。这里是 `01-`（= $\bar x y$）与 `--1`（= $z$）。

- **第一步，按"1 的个数"分组**：只可能"1 的个数差 1"的项合并——分组加速。
- **第二步，逐对比较**：二进制串恰一位不同则合并，那位写 `-`。
- **第三步，反复直到不能合并**：没被合并的串就是素蕴含项。∎

## 3 算法第二步：最小覆盖

**覆盖问题**：给定素蕴含项与它们覆盖的最小项，选出**最少**的素蕴含项覆盖所有最小项（每个"1"至少要有一个选中素蕴含项覆盖）。

**用蕴含项表（prime implicant chart）**：行 = 素蕴含项、列 = 必需覆盖的最小项，交叉处打标记。

**必需素蕴含项（essential prime implicant）**：某列只有一个标记——那个素蕴含项必须选。

**选完必需项后**：剩余列用"尽量少的行"覆盖——这是**集合覆盖问题**（通常 NP 难，但小实例可直观解）。

**例（续）**：素蕴含项 `01-`（覆盖 010,011 = 2,3）与 `--1`（覆盖 1,3,5,7）。

- 蕴含项表：$m(1)$ 只被 `--1` 覆盖 → `--1` 必需；$m(2)$ 只被 `01-` 覆盖 → `01-` 必需。
- 两者都选，覆盖全部。最简：$F = \bar x y + z$。

**验证**：$F = \bar x y + z$：$z=1$ 时输出 1（覆盖 1,3,5,7）；$z=0$ 时需 $\bar x y$（覆盖 2）。总覆盖 = 全部 1 行。✓

**为什么"最少覆盖"**：每个素蕴含项对应电路里一个与门，门越少电路越省。**选最少素蕴含项 = 最小化电路规模**。

## 4 公式解析：QM vs 卡诺图

**本质同一**：

| 卡诺图 | QM 算法 |
| --- | --- |
| 人眼圈相邻 1 | 二进制串逐对合并 |
| "圈最大" | 合并到素蕴含项 |
| "选最少的圈" | 覆盖表选最少行 |
| ≤4 变量好用 | 任意变量、可编程 |

**为什么 QM 能替代卡诺图**：它把"相邻"翻译成"二进制串差一位"，把"圈"翻译成"合并"，把"选圈"翻译成"覆盖"——**每一步都是机器可执行的操作**。变量多时，人眼不可行，算法可行。

**复杂度**：素蕴含项可能指数多（最坏），QM 是"指数最坏但实用快速"的算法。真实 EDA 用启发式（ESPRESSO）处理大实例。

**辨析｜易错点：** 覆盖阶段最易漏"必需项优先"。先圈出**只被一个素蕴含项覆盖的最小项**，强制选那个素蕴含项，再处理剩余——跳过必需项会选多或选错。**"必需项 + 最少补充"是覆盖问题的解题顺序**。

<span class="marginnote">QM 方法的两阶段结构在第四级《最优化理论》里是"生成候选 + 子集选择"的典型模式：先枚举（素蕴含项），再组合优化（覆盖）。这也是许多"从候选集中选最优子集"问题的共同骨架——<strong>生成 + 选择，是组合算法的通用两拍</strong>。</span>

## 5 一个完整的 QM 流程：从最小项到最简式

把 QM 两阶段走在一个完整例子上，每一步都落实。

**例**：$F(w,x,y,z) = \sum m(0,1,2,5,6,7,8,9,10,14)$。

**第一阶段：生成素蕴含项**（按"1 的个数"分组合并）：

- 组 0（0 个 1）：0000。组 1（1 个 1）：0001、0010、1000。组 2：0101、0110、1001、1010。组 3：0111、1110。
- 合并（差一位）：0000–0001 → `000-`；0000–0010 → `00-0`；0000–1000 → `-000`；0001–0101 → `0-01`；0001–1001 → `-001`；0010–0110 → `0-10`；0010–1010 → `-010`；1000–1001 → `100-`；1000–1010 → `10-0`；0101–0111 → `01-1`；0110–0111 → `011-`；0110–1110 → `-110`；1001–?；1010–?；0111–?；1110–?（1010 与 1110 → `1-10`）。
- 第二轮合并（`-` 同位的）：`00-0` 与 `10-0` → `-0-0`；`0-01` 与 `0-11`?（无 0-11）；`0-10` 与 `1-10` → `--10`；`-000` 与 `-100`?（无）……
- 未被合并的项即素蕴含项。

**第二阶段：覆盖表**。列出素蕴含项与其覆盖的最小项，找出必需素蕴含项，再选最少补充覆盖。

**公式解析：为什么"按 1 的个数分组"加速合并**

两个二进制串能合并（差一位）当且仅当"1 的个数差 1"——因为只差一位意味着 1 的个数恰好差 1。

- **第一步，读分组**：把最小项按 $k$（1 的个数）分组。
- **第二步，读候选对**：只需比较相邻两组（$k$ 与 $k+1$），跳过不相邻组。
- **第三步，读加速**：避免全对全比较，减少无效合并。∎

**这个例子的要点**：QM 的机械化核心 = "分组 + 逐对差一位合并"。**"1 的个数"是天然的排序键**，它让合并只发生在相邻组——这是把"相邻"从几何（卡诺图）变成代数（分组）的关键。

**辨析｜易错点：** 第二轮合并**必须**保持 `-` 位置一致（只能合并 `-` 位置相同的项），且新消去的位也变成 `-`。**"合并两次消两位"需要两个 `-` 对齐**——这是新手最易漏的约束。

## 6 小结

- **素蕴含项**：不能再合并的蕴含项 = 卡诺图的"最大圈"。
- **第一阶段**：二进制串逐对合并（差一位），`-` 标记消去的变量，直到不能合并。
- **第二阶段**：蕴含项表选最少的素蕴含项覆盖全部最小项。
- **必需素蕴含项**：只被一个素蕴含项覆盖的最小项强制选择。
- QM 是卡诺图的机械化，可编程、变量不限，但覆盖阶段本质是集合覆盖。
