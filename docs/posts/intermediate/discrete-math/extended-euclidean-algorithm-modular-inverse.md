## 为什么需要"求逆"

我们在模算术里学会了加、减、乘，但还有一个运算没解决：**除法**。在实数里"除以 $a$"就是"乘以 $a$ 的倒数 `$1`/a$"。在模 $m$ 的世界里，倒数变成了**模逆元**——一个数 $x$，使得 $a x \equiv 1 \pmod m$。有了它，线性同余方程 $ax \equiv b \pmod m$ 就能像解普通方程一样两边"除以 $a$"。<span class="marginnote">模逆元是 RSA 解密的核心运算：加密是 $C \equiv M^e \pmod n$，解密是 $M \equiv C^d \pmod n$，其中 $d$ 正是 $e$ 的模逆元。没有快速求逆的算法，RSA 就无法运转。</span>

求模逆元的标准工具是**扩展欧几里得算法（extended Euclidean algorithm）**——它不止求出 $\gcd(a,b)$，还同时把 gcd 写成 $a$ 与 $b$ 的整数线性组合。

## 1 贝祖定理

**贝祖定理（Bézout's identity）**：设 $a$、$b$ 为整数，则存在整数 $s$、$t$ 使得

$$sa + tb = \gcd(a, b)$$

即最大公约数可以写成 $a$ 与 $b$ 的**整数线性组合**。这样的 $(s, t)$ 叫**贝祖系数**。当 $\gcd(a,b)=1$（互素）时，就有 $sa + tb = 1$。

**例**：$\gcd(252, 105) = 21$，而 `$252` \times 2 + 105 \times (-5) = 504 - 525 = -21$，取负号得 `$252` \times (-2) + 105 \times 5 = 21$，所以 $s = -2$、$t = 5$ 是贝祖系数。

贝祖定理只说系数**存在**，不告诉我们怎么找。扩展欧几里得算法就是在欧几里得算法的回退过程中把这些系数**显式地算出来**。

## 2 扩展欧几里得算法

普通欧几里得算法只追踪余数；扩展版多追踪每个余数"由最初的 $a$、$b$ 线性组合表示"的系数。核心思路：**边辗转相除，边回代**。

**实例**：求 $s, t$ 使 `$252`s + 105t = \gcd(252,105)$。

欧几里得算法的余数链：

$$
\begin{aligned}
252 &= 2 \times 105 + 42 \\
105 &= 2 \times 42 + 21 \\
42 &= 2 \times 21 + 0
\end{aligned}
$$

从倒数第二个式子**回代**，把每个余数换成上一层的组合：

- 由 `$105` = 2 \times 42 + 21$，得 `$21` = 105 - 2 \times 42$；
- 把 `$42` = 252 - 2 \times 105$ 代入：`$21` = 105 - 2(252 - 2 \times 105) = 5 \times 105 - 2 \times 252$。

于是 $\gcd = 21 = 252 \times (-2) + 105 \times 5$，贝祖系数 $s = -2$、$t = 5$，与上节验算一致。

**辨析｜易错点：** 回代时符号极容易错。稳妥的检查法：把求出的 $(s,t)$ 代回原式验算 $sa + tb$ 是否等于 gcd。每次算完都验算一遍，比背公式可靠得多。

## 3 公式解析：模逆元的存在性与求法

**模逆元（modular inverse）**：整数 $a$ 在模 $m$ 下的**逆元**是整数 $\bar{a}$，满足

$$a\, \bar{a} \equiv 1 \pmod m$$

**存在性定理**：$a$ 模 $m$ 的逆元存在当且仅当 $\gcd(a, m) = 1$。

**为什么**：逆元存在 ⟺ 存在 $x$ 使 $ax \equiv 1 \pmod m$ ⟺ 存在 $x, k$ 使 $ax - 1 = km$ ⟺ $ax - km = 1$。这是 $a$ 与 $m$ 的线性组合等于 1，由贝祖定理，当且仅当 $\gcd(a,m)=1$。

**求法三步**：

1. 用扩展欧几里得算法求 $s, t$ 使 $sa + tm = 1$。
2. 模 $m$ 下看：$sa \equiv 1 \pmod m$（$tm$ 项是 $m$ 的倍数，消掉）。
3. 于是 $s$ 就是 $a$ 的模逆元；若 $s$ 为负，加 $m$ 调回 $[0, m)$。

**实例**：求 7 模 11 的逆元。扩展欧几里得：`$11` = 1\times7+4$、`$7` = 1\times4+3$、`$4`=1\times3+1$，回代得 `$1` = 4 - 3 = 4 - (7-4) = 2\times4 - 7 = 2(11-7) - 7 = 2\times11 - 3\times7$。故 $s = -3$、$t = 2$，$7$ 的模 11 逆元为 $-3 \equiv 8 \pmod{11}$。验算：`$7` \times 8 = 56 \equiv 1 \pmod{11}$ 对。

## 4 为什么逆元存在性条件苛刻

$\gcd(a, m) = 1$ 这个条件值得细品。它意味着**只有与模数互素的数才有逆元**：

- 模 12 下，只有 1、5、7、11 有逆元（都与 12 互素）；2、3、4、6、8、9、10 都没有。
- 直觉：$a$ 与 $m$ 不互素时，$a$ 与 $m$ 有公共因子 $d>1$。若 $ax \equiv 1 \pmod m$，则 $m \mid (ax - 1)$，而 $d$ 整除 $m$ 也整除 $ax$，故 $d$ 整除 1——矛盾。

<span class="marginnote">当 $m$ 是素数 $p$ 时，`$1`, 2, \dots, p-1$ 全部与 $p$ 互素，于是<strong>每个非零元素都有逆元</strong>——这正是 $\mathbb{Z}_p$ 成为域的原因。域里能做除法，所以 $p$ 是素数的模世界"运算完备"；这直接通往下一节费马小定理，以及 RSA 的密钥构造。</span>

**工程含义**：RSA 选 $e$ 时要求 $\gcd(e, \varphi(n)) = 1$，正是为了保证 $e$ 的模逆元 $d$ 存在。若 $e$ 与 $\varphi(n)$ 不互素，密钥就构造不出来。

## 5 扩展欧几里得的工程实现与递归形式

扩展欧几里得算法除了"回代"的写法，还有优雅的**递归实现**，直接返回 $(d, s, t)$：

```
procedure extended_gcd(a, b)
    if b = 0 then return (a, 1, 0)
    (d, s_1, t_1) := extended_gcd(b, a mod b)
    return (d, t_1, s_1 − ⌊a/b⌋·t_1)
```

**例**：`extended_gcd(252, 105)`：

- `extended_gcd(252,105)` → `extended_gcd(105,42)` → `extended_gcd(42,21)` → `extended_gcd(21,0)` 返回 $(21, 1, 0)$。
- 回填：$d=21$，$s = t_1 = 0$，$t = s_1 - (42//21)\cdot t_1 = 1 - 2\cdot0 = 1$，即 `$21` = 0\cdot42 + 1\cdot21$。
- 再回填：$d=21$，$s = 1$，$t = 0 - (105//42)\cdot1 = -2$，即 `$21` = 1\cdot105 - 2\cdot42$。
- 最终：$d=21$，$s = -2$，$t = 1 - (252//105)\cdot(-2) = 1+4 = 5$，即 `$21` = -2\cdot252 + 5\cdot105$。

与手算回代结果完全一致。∎

**公式解析：递归步为什么成立**

设 $\gcd(a,b) = \gcd(b, r)$（$r = a \bmod b$），且 $s_1 b + t_1 r = d$。要凑 $sa + tb = d$：

$$
s_1 b + t_1(a - \lfloor a/b \rfloor b) = t_1 a + (s_1 - \lfloor a/b\rfloor t_1)b
$$

- **第一步，代入**：$r = a - \lfloor a/b\rfloor b$。
- **第二步，整理**：$a$ 的系数是 $t_1$，$b$ 的系数是 $s_1 - \lfloor a/b\rfloor t_1$——正是代码里的 `s_1 − ⌊a/b⌋·t_1`。
- **第三步，读终止**：$b=0$ 时 $\gcd(a,0)=a$，`$1`\cdot a + 0\cdot0 = a$，返回 $(a, 1, 0)$。∎

**辨析｜易错点：** 递归版里 $t_1$ 与 $s\cdot a + t\cdot b = d$ 的**交换**最容易写错。递归调用返回的 $(s_1, t_1)$ 是针对 $(b, r)$ 的，回填时新 $s$ 取旧 $t_1$、新 $t$ 取"旧 $s_1$ 减去商倍 $t_1$"。**每层都要验算 $s\cdot a + t\cdot b = d$**，这是最稳的自检。

**这个例子的要点**：递归实现把"回代"藏进调用栈，代码更短但更容易出错；迭代实现（表格回代）更直白。**无论哪种写法，"算完验算贝祖等式"是永不失误的保险**。

## 6 小结

- **贝祖定理**：$sa + tb = \gcd(a,b)$，gcd 可写成整数线性组合。
- **扩展欧几里得算法**：辗转相除 + 回代，显式求出贝祖系数。
- **模逆元**：$a\bar a \equiv 1 \pmod m$；存在当且仅当 $\gcd(a,m)=1$。
- 求逆三步：扩展欧几里得 → 模 $m$ 取余 → 调整到 $[0,m)$。
- 素数模下每个非零元都有逆元，$\mathbb{Z}_p$ 因此是域。
