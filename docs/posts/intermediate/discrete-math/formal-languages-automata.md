## 为什么从形式语言与自动机初步开始

离散数学的全书收官，指向一个终极问题：**什么是「能算」？** 编译器要读懂程序语言，正则表达式要匹配文本，DNA 序列要识别模式，大模型要生成下一个 token——它们共享同一套骨架：**形式语言**（如何生成一串合法字符串）与**自动机**（如何机械地识别一串字符串）。<span class="marginnote">这一讲是「从极限到大模型」主线上离散部分的收束：极限通向分析，而自动机与可计算性通向「计算的本质」——图灵机的停机问题划出了算法的边界，这正是大模型时代谈论「智能是否可计算」时的理论坐标。</span>

Rosen 把「建模计算」放在第 13 章作为全书终点，我们顺着他的安排，用「乔姆斯基谱系 → 有限状态机 → 正则语言 → 图灵机 → 停机问题」五步，把离散数学收进「计算」这个最宏大的句号。

## 1 语言与文法：字符串的生成规则

**字母表（alphabet）** 是符号的有限集，其上的字符串拼成**语言（language）**——语言的成员判断，等价于「这个句子是否合法」。**短语结构文法（phrase-structure grammar）** $G=(V,T,S,P)$ 给出生成规则：$V$ 变元集、$T$ 终结符集、$S$ 起始符、$P$ 产生式 $w_1\to w_2$。

从 $S$ 出发反复套产生式，得到一串推导，最终全为终结符的字符串就是文法生成的语言 $L(G)$。<span class="marginnote">「语言 = 从公理（$S$）出发、按规则（$P$）推导」——这个结构与《逻辑与证明》里的推理完全同构：文法之于语言，正如公理系统之于定理。自然语言处理里，生成语法、句法树都是这一框架的直系后代。</span>

**一个小文法**：$V=\{S,A\}$、$T=\{a,b\}$、$P=\{S\to ab,\ S\to aSb\}$。从 $S$ 出发套 $S\to aSb$ 得 $aaSbb$、再套 $S\to ab$ 得 $aabb$；反复可得 $\{a^nb^n\mid n\ge1\}$——「$a$ 的个数恒等于 $b$ 的个数」这种计数性质，正是由文法规则保证的。**巴科斯-诺尔范式（BNF）** 是描述产生式的实用记号（`<句子> ::= <主语> <谓语>`），今天的编程语言手册、语法分析器生成器（yacc/Bison）全用它。

**算例：把推导一步步走完。** 用上面的文法生成 $a^3b^3$ 的完整推导是：

$$
S \xrightarrow{S\to aSb} aSb \xrightarrow{S\to aSb} aaSbb \xrightarrow{S\to ab} aaabbb
$$

每一步只替换当前串里的一个变元 $S$；当串里不再有变元（全是终结符 $a,b$）时推导停止。先套三次 $aSb$、最后换 $ab$，正好得到 3 个 $a$ 后接 3 个 $b$。「个数相等」不是靠运气：每套一次 $aSb$ 就同时多放一个 $a$ 和一个 $b$，计数的义务被写进了规则本身。<span class="marginnote">这里藏着整讲的伏笔：$a^nb^n$ 需要「记住 n 是多少」——那是<strong>无限种</strong>可能的记忆，而有限状态机只有有限个状态，因此<strong>永远识别不了</strong>它。先记住这个结论，§3 的易错辨析会回来找它。</span>

再看**括号匹配**：$V=\{S\}$、$T=\{(,)\}$、$P=\{S\to (S),\ S\to SS,\ S\to \lambda\}$，其中 $\lambda$ 表示空串。它生成的是所有「括号配得对」的串，如 $(())$ 与 $()(())$；而 `(()` 配不对，不在语言里。为什么这个语言比「以 `ab` 结尾」难得多？因为匹配需要记住「已经用了多少个左括号没还」——又是无限计数，与 $a^nb^n$ 同款，有限状态机对它们一样无能为力。

## 2 有限状态机与语言识别

**有限状态机（finite-state machine）** 是「只有有限个记忆状态」的计算模型：给定当前状态与输入符号，跳到下一个状态并（可选用）输出一个符号。<span class="marginnote">有限状态机是人类最先想明白的「有限记忆」机器——电灯开关、自动售货机、电梯控制、正则匹配器都是它；它也是今天大模型「隐状态 + 逐 token 更新」的一个极简原型（尽管后者无限维）。</span>

按输出有无分两类：**带输出的有限状态机**又分**米利机（Mealy）**（输出依赖状态与输入）与**摩尔机（Moore）**（输出只依赖状态）；**不带输出的有限状态机**则只回答问题「这个字符串被接受吗」。

**算例：识别「以 `ab` 结尾」的字符串。** 用状态 $s_0$（还没见到 `a`）、$s_1$（刚见 `a`）、$s_2$（接受态）。输入 `a` 从 $s_0\to s_1$，再输入 `b` 从 $s_1\to s_2$；任何不符合的转移回退。三种状态，机器穷尽了「记忆」的全部可能。把转移整理成表，读起来更清楚：

| 当前状态 | 输入 `a` | 输入 `b` |
| --- | --- | --- |
| $s_0$ | $s_1$ | $s_0$ |
| $s_1$ | $s_1$ | $s_2$ |
| $s_2$ | $s_1$ | $s_0$ |

**辨析｜易错点：** 注意 $s_2$ 这一行——它**不是终点站**。$s_2$ 收到 `a` 要去 $s_1$（新的 `a` 可能是下一段 `ab` 的开头），收到 `b` 则回 $s_0$（`bb` 不以 `ab` 结尾，清零重来）。比如串 `abb`：$s_0\xrightarrow{a}s_1\xrightarrow{b}s_2\xrightarrow{b}s_0$，最终落在非接受态，正确拒绝。**「落在接受态」必须在字符串读完之后判定**，中途经过接受态不算数。

**米利与摩尔，怎么选？** 自动售货机是摩尔机的经典例子：找零金额只取决于「投了多少币」这个状态，与最后一个硬币无关；而信号序列检测器更自然的是米利机——报警信号在「刚读到非法序列」的那一跳当场给出。

| | 输出依赖 | 典型场景 | 状态数 |
| --- | --- | --- | --- |
| 米利机 | 状态 + 输入 | 序列检测、实时报警 | 往往更少 |
| 摩尔机 | 仅状态 | 售货机找零、时序电路 | 往往更多 |

## 3 正则语言与 Kleene 定理

**有限状态自动机（finite-state automaton）** 是不带输出的有限状态机，专司语言识别：它有起始状态与一组接受状态，从起始状态沿输入符号游走，**走完恰好落在接受状态**则字符串被接受。被某个有限自动机接受的语言叫**正则语言（regular language）**，可用**正则表达式**（如 `(a|b)*ab`）紧凑描述。<span class="marginnote">正则表达式是现代软件的通用语言：`grep`、文本编辑器的查找、词法分析器的 token 匹配、以及每个 Web 框架的 URL 路由，底层都是有限自动机或它的变体——写一个正则，等于画一台自动机。</span>

**算例：把正则翻译成自动机。** 语言「以 `01` 结尾的二进制串」写作 `(0|1)*01`。它对应三状态 DFA：$q_0$（等待）、$q_1$（刚读 `0`）、$q_2$（接受）。读到 `0` 进 $q_1$，读 `1` 从 $q_0\to q_1$ 则达 $q_2$；任何破坏模式的输入都按「只看最近两字符」回退。顺着这张表逐字符走一遍 `1001`，你会看到接受与拒绝的分界多么机械。

**非确定性有限状态自动机（NFA）** 允许一个输入符号跳到多个状态（甚至空跳），看似更自由。**Kleene 定理**一锤定音：**NFA 与 DFA 等价，二者都恰好刻画正则语言**——非确定性不增加语言识别能力，只是描述更短。

正则语言由三件套封闭：**并**（$L_1\cup L_2$）、**连接**（$L_1L_2$）、**Kleene 星**（$L^*$，零次或多次重复），与自动机构造一一对应。本专题《有限状态自动机》《非确定性有限状态自动机与 Kleene 定理》两篇有「自动机 ↔ 正则表达式」互转的完整构造。

**辨析｜易错点：** 正则语言**不能**表达「$a$ 与 $b$ 个数相等」（$a^nb^n$）、**不能**表达括号匹配。区分标准不是「看起来简单」，而是**是否需要无限记忆**：凡是语言里的成员判定需要记住「数目」「层次」这类无上界的量，它就不是正则的，得让位给下推自动机。初学常误以为「反正正则写不出来就用 DFA 硬凑状态」——状态不够数，永远凑不出无限记忆。

## 4 图灵机与可计算性

把「有限记忆」放宽成「无限纸带 + 读写头 + 状态转移」，就得到**图灵机（Turing machine, 1936）**——图灵为「什么是可计算」给出的精确模型。<span class="marginnote">图灵机的优雅在于极简：一条纸带、一个读写头、一张转移表。图灵证明了它等价于一切更花哨的模型（λ 演算、递归函数、寄存器机）——「图灵完备」从此成为「能算一切可算之事」的代名词；今天每个编程语言都自称图灵完备，正因此。</span>

图灵还造出**通用图灵机**：一台能模拟任何其他图灵机的机器——即「可编程计算机」的数学原型，也是现代计算机「存储程序」概念的出生证。<span class="marginnote">通用图灵机就是「软件」的发明：机器本身固定，把「程序」当作输入数据喂进去，机器便能算一切可算函数——冯 · 诺依曼架构、操作系统的「加载程序」概念，都是这台理想机器的工程化。</span>

然而「能算」的边界在同一个 1936 年轰然现形：**停机问题（halting problem）**——判断「给定程序与输入，程序是否会停机」没有算法能解。证明分三步走：

- **第一步，反设存在。** 假设有「停机判定器」$H(P,I)$：输入程序 $P$ 与数据 $I$，$H$ 输出「停机」或「不停机」。
- **第二步，造一台「叛逆机」。** 让机器 $P^*$ 调用 $H$ 问「$P$ 对自己（把 $P$ 当数据）是否停机」，若答「停机」，$P^*$ 就故意进入死循环。
- **第三步，自指引爆矛盾。** 让 $P^*$ 对自己提问：若 $H$ 判它停机，它偏不停机；若判它不停机，它偏停机。无论答案为何都矛盾，故 $H$ 不存在。<span class="marginnote">这把钥匙我们在《函数与基数》已经见过：康托尔用对角线证明「实数不可数」，图灵用它证明「停机不可判定」，哥德尔用它证明「算术不完备」——自指 + 对角线，三脉同源。</span>

停机问题不可判定，意味着「验证程序行为」这类任务存在本质的天花板——它是计算理论、程序验证、乃至 AI 对齐讨论绕不开的理论基石。可计算性谱系由此展开：递归集、递归可枚举集、以及「存在不可计算函数」的确凿事实。

## 5 核心对比表：乔姆斯基谱系

纯概念的一讲，用一张表把四类文法的「表达力阶梯」一次看清（替代公式解析）：

| 类型 | 文法约束 | 识别机器 | 典型语言 | 应用出口 |
| --- | --- | --- | --- | --- |
| 0 型 | 无约束短语结构 | 图灵机 | 递归可枚举语言 | 可计算性理论 |
| 1 型 | 上下文有关 $w_1\to w_2$ 且 $|w_1|\le|w_2|$ | 线性有界自动机 | 自然语言句法（部分） |
| 2 型 | 上下文无关 $A\to\alpha$（单变元左端） | 下推自动机 | 括号匹配、算术表达式 | 编译器语法（BNF） |
| 3 型 | 正则文法（右线性） | 有限自动机 | `(a\|b)*ab` 类 | 词法分析、文本搜索 |

**辨析｜易错点：** 谱系是**层层包含**而非并列——正则 ⊂ 上下文无关 ⊂ 上下文有关 ⊂ 无约束。判定「是几型」，先看产生式左端是单个变元（2 型起）还是更一般（1/0 型），再看右端是否线性（3 型）——语言越「弱」机器越简单，正则语言最好算但表达力也最窄。

## 6 术语速查：一张表收官

把本讲的九个关键词钉进一张表，日后翻回来一眼定位：

| 术语 | 一句话定义 | 易错提醒 |
| --- | --- | --- |
| 字母表 | 符号的有限集，如 $\{a,b\}$ | 字母表必有限 |
| 字符串 | 字母表上符号的有穷序列 | 空串 $\lambda$ 也要算 |
| 语言 | 字母表上字符串的集合 | 语言可无限，字符串必有限 |
| 文法 | $(V,T,S,P)$ 四元组 | 产生式方向 $w_1\to w_2$ 不可逆 |
| 推导 | 从 $S$ 到终结符串的替换序列 | 一步只换一个变元 |
| DFA / NFA | 有限状态的语言识别器 | NFA 不更强，只是更短 |
| 正则语言 | DFA 可接受的语言 | 不能计数、不能配括号 |
| 图灵机 | 「可计算」的精确模型 | 纸带无限，状态有限 |
| 停机问题 | 判定停机不可解 | 自指 + 对角线证明 |

## 7 小结

- **形式语言**由文法生成：字母表、终结符、变元、产生式；BNF 是实用描述记号。
- **有限状态机**只有有限记忆：米利/摩尔机带输出，有限自动机做语言识别。
- **正则语言** = 有限自动机 = 正则表达式；**Kleene 定理**：NFA 与 DFA 等价。
- **图灵机**是「可计算」的精确模型；通用图灵机 = 可编程计算机的原型。
- **停机问题**不可判定：自指 + 对角线的证明，与康托尔、哥德尔三脉同源。
- 乔姆斯基谱系 0→3 型层层包含：机器越弱、表达力越窄、计算越轻松。

到这里，本专题十讲收束：我们以**逻辑与证明**奠基，借**集合与关系**、**函数与基数**立骨，用**组合计数**、**递推与生成函数**数数，靠**数论与密码**、**图与树**建模，经**代数结构**抽象，最终抵达**形式语言与自动机**——它们合起来正是「离散世界的地图」与「计算的边界」。在下一阶段，你将带着这张地图走进算法的纵深（第三级《数据结构与算法》）、走进概率与统计（离散概率是它们的前哨），也带着「什么是可计算」的坐标，重新审视大模型时代的每一个智能命题。
