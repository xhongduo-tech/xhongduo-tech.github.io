# 用生成函数求解递推关系

<div class="epigraph">

## 为什么生成函数能"自动"解递推

特征方程法解线性递推很机械，但对更复杂的递推（非线性、变系数、带复杂驱动项）会失灵。**生成函数法**的思路完全不同：先把递推关系"整体平移"到生成函数上——把每一项的递推式代进 $G(x) = \sum a_n x^n$，整理成一个关于 $G(x)$ 的**代数方程**，解出 $G(x)$，再把 $G(x)$ 展开读系数。递推的"逐项纠缠"变成函数的"整体约分"，往往一步到位。<span class="marginnote">生成函数法的五步流程——写生成函数 → 代递推 → 平移下标 → 解方程 → 展开读系数——是"变换求解"范式的典型：先换到一个"好算"的表示，算完再换回来。这与傅里叶变换解微分方程、拉普拉斯变换解电路是同构的——第四级《信号与系统》会正式讲这套"变换域"思想。</span>

## 1 生成函数法的五步流程

**流程**（以斐波那契 $a_n = a_{n-1} + a_{n-2}$，$a_0 = 0$、$a_1 = 1$ 为例）：

1. **写生成函数**：$G(x) = \sum_{n\ge 0} a_n x^n$。
2. **两端乘 $x^n$ 并对 $n \ge 2$ 求和**：

$$
\sum_{n\ge 2} a_n x^n = \sum_{n\ge 2} a_{n-1} x^n + \sum_{n\ge 2} a_{n-2} x^n
$$

3. **用 $G(x)$ 表示每个和**（平移下标）：左边 $= G(x) - a_0 - a_1 x = G(x) - x$；第一项 $= x(G(x) - a_0) = xG(x)$；第二项 $= x^2 G(x)$。
4. **得到代数方程**：$G(x) - x = xG(x) + x^2 G(x)$。
5. **解出并展开**：$G(x) = \frac{x}{1 - x - x^2}$，再部分分式展开读出系数。

## 2 公式解析：解方程与部分分式

**第一步，解出** $G(x)$：

$$
G(x) = \frac{x}{1 - x - x^2}
$$

**第二步，分母因式分解**：$1 - x - x^2 = (1 - \varphi x)(1 - \psi x)$，其中 $\varphi = \frac{1+\sqrt5}{2}$、$\psi = \frac{1-\sqrt5}{2}$。

**第三步，部分分式**：

$$
\frac{x}{1-x-x^2} = \frac{A}{1-\varphi x} + \frac{B}{1-\psi x}
$$

通分比较系数，解得 $A = \frac{1}{\sqrt5}$、$B = -\frac{1}{\sqrt5}$。

**第四步，用几何级数展开**：

$$
G(x) = \frac{1}{\sqrt5}\sum_{n\ge0}(\varphi x)^n - \frac{1}{\sqrt5}\sum_{n\ge0}(\psi x)^n
$$

**第五步，读系数**：

$$
a_n = [x^n]G(x) = \frac{1}{\sqrt5}(\varphi^n - \psi^n)
$$

这正是比内公式——**与特征方程法得到同一个封闭公式**。两条路殊途同归，验证了两种方法的正确性。

## 3 完整实例：汉诺塔（非齐次）

用生成函数解 $H_n = 2H_{n-1} + 1$，$H_1 = 1$。

- **写** $G(x) = \sum_{n\ge1} H_n x^n$（从 $n=1$ 起）。
- **代递推**（$n \ge 2$）：$\sum_{n\ge2} H_n x^n = 2\sum_{n\ge2} H_{n-1}x^n + \sum_{n\ge2} x^n$。
- **平移**：左边 $= G(x) - H_1 x = G(x) - x$；$2$ 项 $= 2x G(x)$；常数项 $\sum_{n\ge2} x^n = \frac{x^2}{1-x}$。
- **方程**：$G(x) - x = 2xG(x) + \frac{x^2}{1-x}$。
- **解出**：$G(x) = \frac{x}{(1-x)(1-2x)}$。
- **部分分式**：$\frac{x}{(1-x)(1-2x)} = \frac{1}{1-2x} - \frac{1}{1-x}$。
- **展开读系数**：$H_n = 2^n - 1$。与之前的结果一致。∎

**要点**：非齐次项 $+1$ 变成几何级数 $\frac{x^2}{1-x}$——**驱动项进入方程，但不破坏解法的机械性**。

## 4 生成函数法 vs 特征方程法

两种方法各有千秋，选型看题型：

| 维度 | 特征方程法 | 生成函数法 |
| --- | --- | --- |
| 适用 | 线性常系数齐次/简单非齐次 | 更广（含变系数、复杂驱动） |
| 步骤 | 求根 → 通解 → 定系数 | 写式 → 平移 → 解方程 → 展开 |
| 核心操作 | 多项式求根 | 部分分式 + 几何级数 |
| 上手难度 | 低 | 中（需熟练部分分式） |
| 通用性 | 中 | 高（还能证恒等式、数组合） |

**经验法则**：线性常系数用特征方程（快）；遇到特征方程搞不定的、或者要"顺带证恒等式/数组合"，用生成函数。**两种方法会互相验证**——同一题两法都做，答案一致时信心加倍。

**辨析｜易错点：** 平移下标是最容易出错的一步。$G(x) = \sum_{n\ge0} a_n x^n$ 时，$\sum_{n\ge1} a_n x^n = G(x) - a_0$，$\sum_{n\ge2} a_n x^n = G(x) - a_0 - a_1x$。**每一项的"起始下标"决定要减掉几个前项，漏减/多减会让方程整个错掉**。写平移时把 $n=0,1$ 的项显式列出来最稳妥。

<span class="marginnote">生成函数解递推的底层原理是：<strong>递推关系 ⟺ 生成函数满足的有理函数方程</strong>。线性递推对应有理生成函数；部分分式把有理函数拆成几何级数之和，系数自然读出。这个"线性递推 ⟺ 有理母函数"的对应，是整节的精神内核。</span>

## 5 用生成函数解一个"变系数"递推

生成函数相对特征方程的最大优势：能处理**变系数**递推。看一个经典例子。

**例**：解 $a_n = \frac{1}{n+1} a_{n-1}$ 型？——不，换一个标准变系数例：数列 $a_0 = 1$、$a_n = 2 a_{n-1} + 3^n$（$n \ge 1$，驱动项指数）。

**用生成函数解**：设 $G(x) = \sum_{n\ge0} a_n x^n$。

$$
\sum_{n\ge1} a_n x^n = 2\sum_{n\ge1} a_{n-1}x^n + \sum_{n\ge1}3^n x^n
$$

- **左**：$G(x) - a_0 = G(x) - 1$。
- **第一项**：$2x G(x)$。
- **第二项**：$\sum_{n\ge1}(3x)^n = \frac{3x}{1-3x}$。

于是 $G(x) - 1 = 2xG(x) + \frac{3x}{1-3x}$，解得

$$
G(x) = \frac{1 - 3x + 3x}{(1-2x)(1-3x)} \cdot \frac{1}{1-3x}? \quad \text{不，直接算：}
$$

$$
G(x)(1-2x) = 1 + \frac{3x}{1-3x} \implies G(x) = \frac{1}{1-2x} + \frac{3x}{(1-2x)(1-3x)}
$$

部分分式：$\frac{3x}{(1-2x)(1-3x)} = \frac{-6}{1-2x} + \frac{9}{1-3x}$（通分验证）。所以

$$
G(x) = \frac{1 - 6}{1-2x} + \frac{9}{1-3x} = \frac{-5}{1-2x} + \frac{9}{1-3x}
$$

**读系数**：$a_n = -5 \cdot 2^n + 9 \cdot 3^n$。验算：$a_0 = -5 + 9 = 4$？——不对，$a_0$ 应为 1。**回查**：$G(0) = a_0$，而 $G(0) = -5 + 9 = 4 \ne 1$，说明部分分式系数算错了。重算 $\frac{3x}{(1-2x)(1-3x)}$：设 $\frac{A}{1-2x} + \frac{B}{1-3x}$，$A(1-3x) + B(1-2x) = 3x$，常数项 $A+B=0$、$x$ 项 $-3A-2B=3$ ⟹ $A = -3$、$B = 3$。于是 $G(x) = \frac{1}{1-2x} + \frac{-3}{1-2x} + \frac{3}{1-3x} = \frac{-2}{1-2x} + \frac{3}{1-3x}$。$G(0) = -2 + 3 = 1$ ✓。系数 $a_n = -2\cdot2^n + 3\cdot3^n$。验算 $a_1 = -4 + 9 = 5$，而递推 $a_1 = 2\cdot1 + 3 = 5$ ✓。

**公式解析：为什么中间容易错**

- **第一步，列方程**：平移下标 + 处理驱动项 $\sum 3^nx^n = \frac{3x}{1-3x}$。
- **第二步，解 $G$**：整理成有理函数。
- **第三步，部分分式**：设 $\frac{A}{1-2x} + \frac{B}{1-3x}$，联立解 $A, B$——**每步都可验算**。
- **第四步，验算 $G(0)$**：$G(0)$ 必须等于 $a_0$——**这是最便宜的自检**，能抓出绝大部分系数错误。∎

**辨析｜易错点：** 部分分式系数算错是最高频错误。**算完先看 $G(0) = a_0$**——不满足必错。这个"初始值自检"比硬背公式可靠得多。

**这个例子的要点**：生成函数法对"齐次 + 指数驱动项"的递推照常工作——驱动项只是变成一个几何级数进方程。**特征方程需要"猜特解"，生成函数只是"解方程"**——这是它更机械的原因。

## 6 小结

- **五步流程**：写 $G$ → 代递推 → 平移下标 → 解方程 → 部分分式展开读系数。
- 斐波那契：$G(x) = \frac{x}{1-x-x^2}$，展开得比内公式。
- 汉诺塔（非齐次）：驱动项 $+1$ 变成几何级数，$H_n = 2^n - 1$。
- 特征方程法与生成函数法互相验证，选型看题型。
- 平移下标时显式列出 $n=0,1$ 项，是防错关键。
