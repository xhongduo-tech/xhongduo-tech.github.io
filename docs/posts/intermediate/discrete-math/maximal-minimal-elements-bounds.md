# 极大元、极小元、上界与下界

## 为什么"最大"在偏序里要拆成两半

全序里"最大"只有一种含义：比所有元素都大。但偏序里有不可比元素，"比所有元素都大"（最大元）可能不存在——这时退而求其次的"**极大元**"（没人在它上面）仍然存在。同理有最小元与极小元。更进一步，对**子集**而言还有**上界/下界**、**最小上界/最大下界**。这组概念是理解格（下一节）、以及求偏序里"极端"的完整工具箱。<span class="marginnote">极大/极小与最大/最小的区分在数学里反复出现：偏序里"极大元"是"局部无人压过"，"最大元"是"全局压过一切"。集合论里佐恩引理谈的是极大元的存在性，博弈论里的"帕累托最优"本质上就是偏序里的极大元——<strong>不可比情形下"没有更好的"就是最优</strong>。</span>

## 1 极大元、极小元

设 $(S, \preceq)$ 是偏序集。

- **极大元（maximal element）**：$S$ 中不存在 $b$ 使 $a \prec b$（$a$ 不被任何元素严格压过）。
- **极小元（minimal element）**：$S$ 中不存在 $b$ 使 $b \prec a$。
- **最大元（greatest element）**：$S$ 中所有 $b$ 都满足 $b \preceq a$（$a$ 压过一切）。
- **最小元（least element）**：所有 $b$ 都满足 $a \preceq b$。

**关键区别**：极大元可能**不止一个**（不可比元素都可以是极大）；最大元**至多一个**（唯一）。全序里极大=最大，偏序里分家。

**例**：偏序 $(\{1,2,3,4,6,8,12\}, |)$。

- 极大元：8 和 12（没有更大的倍数在集合里）——两个极大元，无最大元。
- 极小元：1（唯一的）。
- 最小元：1；最大元：不存在。

**例（帕累托最优）**：两个维度都想要"越多越好"，方案 $(5,3)$ 与 $(4,4)$ 不可比，都是极大元（没有方案在**两个维度上都**超过它们）。这就是经济学里的帕累托前沿。

## 2 上界与下界

对**子集** $A \subseteq S$：

- **上界（upper bound）**：$u \in S$ 使所有 $a \in A$ 满足 $a \preceq u$。
- **下界（lower bound）**：$l \in S$ 使所有 $a \in A$ 满足 $l \preceq a$。
- **最小上界（least upper bound, lub / supremum）**：$A$ 的所有上界中的最小元。
- **最大下界（greatest lower bound, glb / infimum）**：$A$ 的所有下界中的最大元。

**例**：偏序 $(\mathcal{P}(\{1,2,3\}), \subseteq)$，取 $A = \{\{1\}, \{2\}\}$。

- 上界：$\{1,2\}$、$\{1,2,3\}$（都包含 $\{1\}$ 与 $\{2\}$）。最小上界 = $\{1,2\}$。
- 下界：$\emptyset$。最大下界 = $\emptyset$。

**直觉**：子集 $A$ 的最小上界就是"能盖住 $A$ 所有元素的最小的那一个"——在 $\subseteq$ 下就是并集 $\bigcup A$；最大下界是"被所有元素都盖住的最大的那一个"——就是交集 $\bigcap A$。

## 3 公式解析：极大/极大与最大/最小的关系

把四个概念的关系整理成一张逻辑表，是本节的核心：

| 概念 | 定义（局部） | 存在性 | 唯一性 |
| --- | --- | --- | --- |
| 极大元 | $\nexists b: a \prec b$ | 有穷偏序必有 | 可能多个 |
| 最大元 | $\forall b: b \preceq a$ | 不一定存在 | 至多一个 |
| 极小元 | $\nexists b: b \prec a$ | 有穷偏序必有 | 可能多个 |
| 最小元 | $\forall b: a \preceq b$ | 不一定存在 | 至多一个 |

- **第一步，读存在性**：**有穷**偏序必有极大元与极小元（沿"向上/向下"走，有穷必停）。最大元/最小元则不然——如前例整除偏序没有最大元。
- **第二步，读唯一性**：极大元可能多个（互相不可比），最大元唯一（可比全序性质）。
- **第三步，看关系**：最大元必是极大元（"压过一切"蕴含"无人压过"），反之不成立——**极大是最大的弱化版**。

**辨析｜易错点：** "极大元"与"最大元"是最易混淆的一对。记法锚：**极大 = maximal = 没有更大的（无人压过）；最大 = greatest = 比所有都大（压过一切）**。判断时问两个问题：有几个这样的元素？它们之间可比吗？多个不可比 → 只能叫极大。

## 4 求极大元的算法视角

在有穷偏序上找极大元，算法上就是"逐个排除被压过的"：

- 从任意元素出发，若存在严格比它大的，就换过去；
- 重复直到没有更大的——有穷保证终止，到达一个极大元。

**这个过程揭示一个重要事实**：极大元是"**局部最优**"——沿着"更大"的方向爬升到爬不动。这与第五篇贪心算法的"局部最优"是同一个词：贪心的每一步找局部最优，最后落点常是极大元而非最大元。**偏序的极大元理论，是贪心与局部搜索算法正确性分析的数学语言**。

<span class="marginnote">上界/下界的用途在数学分析里举足轻重：实数集的有界性、完备性公理"非空有上界子集必有最小上界"，正是构造实数、定义极限的根基。离散版的上界/下界是分析学的离散镜像——第二级《数学分析》里你会重逢 supremum 与 infimum，只是换成了 $\mathbb{R}$ 上连续的世界。</span>

## 5 上界下界的计算：一个完整例题

把"上界/下界/最小上界/最大下界"放在同一张图上算一遍，是理解这组概念的最佳方式。

**例**：偏序 $(\mathcal{P}(\{a,b,c\}), \subseteq)$，取子集 $A = \{\{a\}, \{b\}\}$。

- **上界**：包含 $\{a\}$ 且包含 $\{b\}$ 的集合：$\{a,b\}$、$\{a,b,c\}$。
- **最小上界（lub）**：上界中最小的：$\{a,b\} = \{a\} \cup \{b\}$。
- **下界**：被 $\{a\}$ 与被 $\{b\}$ 都包含的集合：$\emptyset$。
- **最大下界（glb）**：下界中最大的：$\emptyset = \{a\} \cap \{b\}$。

**公式解析：$\subseteq$ 偏序下 lub/glb = 并/交**

对 $\subseteq$ 偏序，任意子集族 $A$ 的 lub 与 glb 有通式：

$$
\operatorname{lub}(A) = \bigcup_{S \in A} S, \qquad \operatorname{glb}(A) = \bigcap_{S \in A} S
$$

- **第一步，读 lub**：能"盖住"所有 $A$ 中集合的最小集合 = 它们的并。
- **第二步，读 glb**：被所有 $A$ 中集合"盖住"的最大集合 = 它们的交。
- **第三步，读一般偏序**：整除偏序下 lub = lcm、glb = gcd；$\le$ 全序下 lub = max、glb = min。**每种偏序有自己的"并/交"**。∎

**例（整除偏序）**：$A = \{4, 6\}$（整除偏序）：lub = lcm(4,6) = 12；glb = gcd(4,6) = 2。

**辨析｜易错点：** lub/glb 必须**存在且在集合内**才能谈——若 lub 落在偏序集之外，则"不存在最小上界"。如整除偏序 $\{1,2,3,6,12\}$ 中 $A=\{2,3\}$ 的 lub = 6（在），但 $A=\{4,6\}$ 的 lub = 12（在）；若集合只有 $\{1,2,3,6\}$ 则 $A=\{2,3\}$ 的 lub = 6（在）但 $A=\{4,6\}$ 里 4 不在集合。**先确认元素在不在集合**。

**这个例子的要点**：lub/glb 是"上界里的最小、下界里的最大"——**$\subseteq$ 下就是并与交**。这组概念是下一节"格"的定义基础：格 = 任意两元素都有 lub 与 glb 的偏序。

## 6 小结

- **极大/极小元**：不被压过/不压过别人，有穷偏序必有、可多个；**最大/最小元**：压过/被一切压过，未必存在、至多一个。
- 最大元必是极大元，反之不一定。
- **上界/下界**对子集定义；**最小上界（supremum）/最大下界（infimum）**是上/下界里的极端。
- $\subseteq$ 下：最小上界 = 并、最大下界 = 交。
- 极大元 = 局部最优，是贪心/搜索算法的数学落点。
