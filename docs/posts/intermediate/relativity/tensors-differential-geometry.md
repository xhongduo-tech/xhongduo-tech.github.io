## 为什么物理定律必须"不认坐标"

广义相对论面对一个全新的难题：时空是弯曲的，没有全局的"平直坐标系"可以依赖。牛顿力学可以选定一个惯性系写 $\vec F = m\vec a$，但在弯曲时空里，**任何坐标系都只是局部的"贴纸"**——换个坐标，方程的写法可能完全不同，但物理必须不变。这就需要一套**坐标无关**的语言来描述定律：**张量（tensor）**。<span class="marginnote">这是爱因斯坦在 1912–1915 年间最大的难关：他想要一个"在任意坐标变换下形式不变"的引力方程，但当时数学家朋友格罗斯曼告诉他，工具已经存在——黎曼 1854 年、里奇与列维-齐维塔 1901 年发展出的<strong>张量分析</strong>。爱因斯坦曾感叹这套数学"如同天书"，但一旦掌握，它就成为广义相对论的母语。</span>

这一篇是广义相对论的"语法课"：理解张量是什么、协变导数怎么算、曲率从哪来。它不追求完整数学证明，而是建立一套能读懂后续所有方程的工作语言。

## 1 为什么需要坐标无关的语言

弯曲时空里没有全局惯性系。假设你想写"自由落体方程"，在某个局部坐标下它是 $d^2x^\mu/d\tau^2 = 0$，但换个弯曲坐标（比如极坐标、或绕转动的坐标），这个式子就不对了——因为坐标本身在"弯"。

**关键认识**：物理定律不应该关心"坐标怎么画"。正如一张球面的几何不依赖你用的地图投影，时空的物理也不依赖坐标系。这就要求定律写成**协变形式**：方程两边的量在坐标变换下按相同的规则变，从而"两边一起变"，方程的**形式**保持不变。

**张量**就是按这种"坐标变换规则"分类的对象。一个量是不是张量，取决于它在坐标变换 $x^\mu \to x^{\mu'}$ 下如何变：

**标量**：不变，$T' = T$。
**逆变矢量（contravariant）**：$A^{\mu'} = \frac{\partial x^{\mu'}}{\partial x^\nu} A^\nu$（用导数变换，指标在上）。
**协变矢量（covariant）**：$A_{\mu'} = \frac{\partial x^\nu}{\partial x^{\mu'}} A_\nu$（用逆变换，指标在下）。

"逆变/协变"的区别是**张量语言的第一课**：一个指标的"位置"（上下）决定它随坐标怎么变。<span class="marginnote">直觉记忆：<strong>逆变（上指标）像"分量"，坐标变它也"顺着变"</strong>（除以雅可比）；<strong>协变（下指标）像"余向量"，坐标变它"逆着变"</strong>。物理量如坐标差 $dx^\mu$ 是逆变，梯度 $\partial_\mu \phi$ 是协变。用上/下指标严格配对（爱因斯坦求和约定：上下成对指标自动求和），能防止一半的计算错误。</span>

## 2 度规张量：升降指标的"货币兑换"

**度规张量（metric tensor）** $g_{\mu\nu}$ 是协变二阶张量，它定义间隔：

$$ds^2 = g_{\mu\nu} dx^\mu dx^\nu$$

（重复指标 $\mu, \nu$ 自动求和——**爱因斯坦求和约定**）。$g_{\mu\nu}$ 同时承担三个职能：定义距离、升降指标、决定光锥结构。

**升降指标**是张量计算的"货币兑换"：

$$A^\mu = g^{\mu\nu} A_\nu, \qquad A_\mu = g_{\mu\nu} A^\nu$$

其中 $g^{\mu\nu}$ 是 $g_{\mu\nu}$ 的逆矩阵。在平直时空里，$g_{\mu\nu} = \eta_{\mu\nu} = \mathrm{diag}(-1,1,1,1)$，升降只是给时间分量换符号。<span class="marginnote">升降指标看起来是"记号的把戏"，实则有物理含义：同一个物理量有"协变版本"和"逆变版本"两种面孔。比如四维动量 $p^\mu$ 与它的"余向量版" $p_\mu$，升降之间就差一个度规——在弯曲时空里，度规逐点不同，升降也逐点不同，这正是"引力如何影响物理量"的数学入口。</span>

## 3 公式解析：协变导数——弯曲时空里怎么"求导"

平直时空里的普通偏导数 $\partial_\mu A^\nu$ 在弯曲坐标下**不是张量**——因为"坐标刻度"逐点变化，直接求导混入了坐标的"虚假变化"。修正的办法是引入**协变导数（covariant derivative）**：

$$\nabla_\mu A^\nu = \partial_\mu A^\nu + \Gamma^\nu_{\ \mu\lambda} A^\lambda$$

其中 $\Gamma^\nu_{\ \mu\lambda}$ 是克氏符号（由度规的一阶导数构成），它"抵消"坐标系弯曲带来的虚假变化。**协变导数是张量**：它在坐标变换下正确变换，是弯曲时空中唯一合法的"求导"。

**第一步，为什么需要修正项。** 在球面极坐标里，矢量"看起来"在转动坐标系中长度变化，但真实几何长度不变——普通导数无法区分"真变化"与"坐标变化"，克氏符号就是用来剥离"坐标变化"的。

**第二步，克氏符号从哪来。** 它完全由度规决定：

$$\Gamma^\lambda_{\ \mu\nu} = \frac{1}{2} g^{\lambda\sigma}\left(\partial_\mu g_{\nu\sigma} + \partial_\nu g_{\sigma\mu} - \partial_\sigma g_{\mu\nu}\right)$$

**度规给定时，克氏符号是确定的**——这就是"度规决定一切几何"的数学来源。

**第三步，平行移动与测地线。** 沿曲线"平行移动"一个矢量要求协变导数沿曲线为零：$U^\mu \nabla_\mu A^\nu = 0$。若移动的是自身切向量，就得测地线方程 $\frac{dU^\mu}{d\tau} + \Gamma^\mu_{\ \alpha\beta}U^\alpha U^\beta = 0$——上一节的方程在这里被"语法化"了。<span class="marginnote">这个框架揭示了一个重要的哲学点：<strong>广义相对论没有引入任何"引力力场"，只引入了"如何正确求导"的规则</strong>。引力的一切效应——自由落体、光线偏折、时间膨胀——都是"协变求导"在弯曲背景上的后果。引力是一种"几何的语法"，不是"额外的力"。</span>

## 4 曲率：弯曲的"硬证据"

有了协变导数，就能定义**曲率**。黎曼曲率张量度量"平行移动一圈后矢量的变化"：

$$R^\rho_{\ \sigma\mu\nu} = \partial_\mu \Gamma^\rho_{\ \sigma\nu} - \partial_\nu \Gamma^\rho_{\ \sigma\mu} + \Gamma^\rho_{\ \mu\lambda}\Gamma^\lambda_{\ \sigma\nu} - \Gamma^\rho_{\ \nu\lambda}\Gamma^\lambda_{\ \sigma\mu}$$

这是一个"不证自明"的判据：**$R^\rho_{\ \sigma\mu\nu} = 0$ 当且仅当时空平直**（可整体化为闵可夫斯基形式）。平直时空检验法就一条：黎曼张量为零。

曲率张量可以"收缩"（把上下指标配对求和）得到两个更常用的对象：

- **里奇张量（Ricci tensor）**：$R_{\mu\nu} = R^\lambda_{\ \mu\lambda\nu}$——描述"体积如何被弯曲改变"；
- **曲率标量（Ricci scalar）**：$R = g^{\mu\nu} R_{\mu\nu}$——单个数，总体弯曲程度。

这三个对象是广义相对论"引力探测器"的刻度盘：测地线偏离（潮汐力）用黎曼张量描述，场方程用里奇张量描述，球对称解用曲率标量辅助判断奇点。<span class="marginnote">里奇张量在引力里扮演"物质源"的对偶角色：爱因斯坦场方程左边（几何）就是里奇张量的组合，右边（物质）是能量-动量张量。<strong>"物质如何让时空弯曲"在数学上就是"里奇张量如何等于物质能量分布"</strong>——这是下一篇《爱因斯坦场方程》的接线图。</span>

## 5 张量语言的"验收标准"

为什么物理学愿意接受这套繁琐的语言？因为它带来三个硬收益：

**自动协变**：定律写成张量等式，任意坐标变换下形式不变——相对性原理"自动"满足。
**自动不变**：张量的"收缩"（上下指标配对求和）给出坐标无关的不变量——物理量（如间隔、曲率标量）天然绝对。
**统一描述**：能量-动量张量 $T^{\mu\nu}$、电磁场张量 $F^{\mu\nu}$、度规 $g_{\mu\nu}$——所有"场"都是同一家族的对象，可用同一套运算。

从第一级《线性代数》的向量空间，到《数学物理方法》的张量初识，再到这里的协变张量——**"按变换行为分类对象"这一思想一路升级**：普通矢量按旋转/平移变换，四维矢量按洛伦兹变换，张量按任意坐标变换。层级递进，语言也逐级成熟。<span class="marginnote">这套"变换分类学"的思想是理解整个现代物理的脊椎：量子力学里的算符按酉变换分类、粒子物理里的场按洛伦兹群表示分类、广义相对论里的张量按坐标变换分类。<strong>物理学家其实只做一件事：找那些"不随视角变化"的东西。</strong> 张量语言让这件事系统化。</span>

## 6 一例实战：用张量语言重写电磁学

张量语言不是抽象摆设——它能把一门完整的物理（电磁学）写成"几何上显然"的形式，这也是它真正的说服力所在。

**电磁场的四维张量**。定义**电磁场张量**（协变形式）：

$$F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu$$

其中 $A_\mu = (-\phi/c, \vec A)$ 是四维矢势。$F_{\mu\nu}$ 的分量包含了全部电磁场：$F_{0i} = E_i/c$、$F_{ij} = \epsilon_{ijk}B_k$——**电场与磁场不是两个独立的量，而是同一个二阶反对称张量的不同分量**。

**麦克斯韦方程的协变形式**。四条麦克斯韦方程（两个"散度"、两个"旋度"）压缩成两条张量方程：

$$\partial_\mu F^{\mu\nu} = \mu_0 J^\nu, \qquad \partial_{[\mu} F_{\nu\lambda]} = 0$$

第一条含电流源 $J^\nu$（有源），第二条是"无源/恒等式"（Bianchi 型）。**四条变两条，且自动满足相对性原理**——因为它们是张量等式，洛伦兹变换下形式不变。<span class="marginnote">这个改写是"张量语言 = 相对性原理的自动实现"的典范：经典电磁学里，电场和磁场在伽利略变换下"各管各的"，让人以为它们是独立实体；写成 $F_{\mu\nu}$ 后一目了然——<strong>电与磁只是同一个四维对象在不同参考系里的投影</strong>。运动电荷旁静止观察者看到纯电场，运动观察者看到电场+磁场，但 $F_{\mu\nu}$ 本身不变。这是"数值相对、结构绝对"在电磁学里的翻版。</span>

**对广义相对论的意义**：一旦学会这种"重写"，就会理解爱因斯坦为什么坚持引力方程必须是张量等式——他不是追求"数学美"，而是**只有张量等式才能保证物理定律在任意坐标系（包括加速系、引力场）中形式不变**。电磁学的例子证明这条路可行，引力不过是同一套方法应用于"时空几何"本身。

**补充一个实用技巧**：验证一个式子是不是张量，就检验它在坐标变换下是否"按规则变"；而构造不变量，就是把上下指标配对求和（收缩）。**指标"配对即求和、配对即不变"**——记住这一条，张量运算就成功了一半。

## 7 小结

- **张量**是按坐标变换规则分类的量：标量、逆变矢量、协变矢量、高阶张量；**张量等式自动协变**。
- **度规张量** $g_{\mu\nu}$：定义间隔、升降指标、决定光锥——是弯曲时空的第一对象。
- **协变导数** $\nabla_\mu A^\nu = \partial_\mu A^\nu + \Gamma^\nu_{\ \mu\lambda}A^\lambda$：弯曲时空的"合法求导"，克氏符号由度规决定。
- **测地线方程**是"平行移动切向量"的协变版本——上一节的运动方程在这里获得语法根据。
- **曲率**由黎曼张量 $R^\rho_{\ \sigma\mu\nu}$ 度量；$R = 0$ 判平直；收缩得里奇张量与曲率标量。
- 张量语言带来**自动协变、自动不变、统一描述**三大收益。
