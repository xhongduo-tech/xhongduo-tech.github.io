## 为什么速度加法会被"修正"

在牛顿力学里，速度叠加是幼儿园级别的常识：你以 30 km/h 骑车，迎面来的风以 30 km/h 吹，相对速度 60 km/h。但相对论一登场，这个"常识"就必须被改写成一条更复杂的公式——因为**经典加法会让光速不变公设破产**：如果一艘飞船以 $0.9c$ 前进，船上又发射一枚以 $0.9c$ 前进的导弹，经典相加得 $1.8c$，超过光速，而这在相对论里不可能。<span class="marginnote">这条"速度加法修正"和洛伦兹变换一样，不是人为规定，而是<strong>从光速不变公设硬推出来的</strong>。它保证了任何小于 $c$ 的速度加起来仍然小于 $c$——光速是速度空间的"天花板"。</span>

这一篇我们推导相对论速度叠加公式，看它如何自动"保护"光速上限，并处理一个常见误区：光速不变到底和速度叠加冲不冲突。

## 1 从洛伦兹变换微分出发

速度 = 位移对时间的导数。在 $S$ 系中，粒子速度 $u = dx/dt$；在 $S'$ 系中，$u' = dx'/dt'$。我们对洛伦兹变换两边微分：

$$dx' = \gamma(dx - v\,dt), \qquad dt' = \gamma\left(dt - \frac{v}{c^2}dx\right)$$

**记住 $y,z$ 方向不变**：$dy' = dy$、$dz' = dz$。

## 2 公式解析：一维速度叠加公式

先看最简单的情形——粒子沿 $x$ 方向运动。

**第一步，作除法。** $u' = \dfrac{dx'}{dt'} = \dfrac{\gamma(dx - v\,dt)}{\gamma\left(dt - \frac{v}{c^2}dx\right)} = \dfrac{dx/dt - v}{1 - \frac{v}{c^2}\frac{dx}{dt}}$

**第二步，代入 $u = dx/dt$：**

$$u' = \frac{u - v}{1 - \frac{uv}{c^2}}$$

这就是相对论速度叠加公式的一维形式。它把 $S$ 系中的速度 $u$ 和 $S'$ 系对 $S$ 的运动速度 $v$ 合成出 $S'$ 系中的 $u'$。<span class="marginnote"><strong>低俗极限检查</strong>：当 $u, v \ll c$ 时，分母 $1 - uv/c^2 \approx 1$，公式退化为 $u' = u - v$——经典伽利略速度叠加，无缝衔接。这是所有相对论公式的"体检项"：低俗必须回归牛顿，否则就是错的。</span>

**第三步，读出两个关键性质：**

- **对称性**：$u$ 与 $v$ 交换位置公式不变（只差负号约定），说明两速度地位对等。
- **光速保护**：若 $u = c$，则 $u' = \dfrac{c - v}{1 - v/c} = c$——光在任何系中都是 $c$，完美复现光速不变公设。

**辨析｜易错点：** 分子与分母的符号要同时处理。若求的是 $S'$ 中的速度 $u'$，分子是 $u - v$；若要反解回 $S$ 系，则 $u = \dfrac{u' + v}{1 + u'v/c^2}$（把 $v$ 换号）。**常见错误是只改分子不改分母**，或者把分母写成 $1 + uv/c^2$ 导致光速变成 $c$ 以外的东西。

## 3 三维推广与"光速不变"的自我一致

粒子不一定沿 $x$ 运动。把 $S'$ 沿 $x$ 方向相对 $S$ 运动，$y,z$ 分量如何变换？由 $dy' = dy$ 与 $dt' = \gamma(dt - v\,dx/c^2)$：

$$u'_y = \frac{dy'}{dt'} = \frac{u_y}{\gamma\left(1 - \frac{v u_x}{c^2}\right)}$$

注意 $u'_y$ 的变换里出现了 $\gamma$ 与 $u_x$——**横向速度也会被纵向运动"拖累"**，因为时间膨胀影响了一切时间间隔。<span class="marginnote">这个"横向分量带 $\gamma$"的细节在粒子物理里极其重要：一个横向动量很大的粒子在实验室系中寿命变长，其横向速度分量却受 $\gamma$ 压低。计算相对论粒子在磁场中的轨道时，必须用这套三维变换而不是牛顿的直角分解。</span>

**光速不变的自我检验**：若粒子速度 $|\vec{u}| = c$，即 $u_x^2 + u_y^2 + u_z^2 = c^2$，代入三维变换可验证 $|\vec{u}'| = c$ 依然成立——光速不变对任意方向的光都自动满足。这是公式内在一致性的绝佳演示：**相对论速度叠加不会"造出"或"消灭"光速，它只是把光速从一个系搬运到另一个系**。

## 4 超光速的幻影：相速度与"视超光速"

速度叠加公式保证物质与信息不能超光速，但有一类"速度"可以超过 $c$ 而不违反任何物理：**相速度**。波包 $e^{i(kx - \omega t)}$ 的相速度 $v_\phi = \omega/k$ 可以大于 $c$（例如波导、色散介质中的情况），但**信号速度**（信息传递速度）始终由群速度决定，且被 $c$ 封顶。<span class="marginnote">射电天文学里还有一个著名现象：活动星系核喷流看起来以 4–10 倍光速横向运动——这叫<strong>视超光速（superluminal motion）</strong>，其实是喷流以接近 $c$ 的倾角朝地球方向运动时，光速延迟造成的投影错觉。它不违反相对论，反而<strong>证明</strong>喷流速度确实接近 $c$。</span>

这些"幻影超光速"的共同点：**都不传递信息**。相对论禁止的是"信号超光速"，因为那会破坏因果律（总可以找到一个惯性系，让"因"发生在"果"之后）。相速度、视超光速都是可解释的几何或波的效应，信息速度依旧 ≤ $c$。

## 5 相对论速度叠加的工程现场

速度叠加公式不是纸面体操，它在真实工程里反复出现：

**粒子加速器**：两束粒子对撞时，实验室系里每束 $0.999c$，对撞相对速度并非 $1.998c$，而是 $u_{\mathrm{rel}} = \dfrac{0.999c + 0.999c}{1 + (0.999)^2} \approx 0.9999995c$——这直接决定了对撞的能量标度，是 LHC 设计的基础。
**宇宙线**：极高能宇宙线粒子相对地球的速度 $u$ 与地球相对银河系的速度 $v$ 合成时，必须用相对论公式，否则会算错到达时间与方向分布。
**GPS 与卫星编队**：星载钟的相对速度修正虽然用时间膨胀足够，但多普勒测速等环节依赖速度叠加的精确形式。

在所有这些地方，如果工程师偷懒用了经典加法，误差会随时间累积到不可接受——**相对论不是"当速度接近光速才需要"的例外，它是一条处处生效的精确法则，只是低俗时恰好约等于牛顿公式**。<span class="marginnote">这是全专题最值得记住的一句话：<strong>牛顿力学是相对论在 $v \ll c$ 时的极限</strong>。理解这个"极限关系"，比背诵任何公式都更能建立整门学科的坐标系——它解释了为什么两百年的经典物理"看起来"都对，却仍然只是特例。</span>

## 6 三组经典算例

把公式用三组具体数字"喂"一遍，速度叠加的"脾气"就全出来了。

**算例一：光的再合成。** 飞船以 $0.5c$ 前进，向前发射一束光。按经典加法，光相对地面该是 $1.5c$？不——代入 $u = c$、$v = 0.5c$：

$$u' = \frac{c - 0.5c}{1 - 0.5c^2/c^2} = \frac{0.5c}{1 - 0.5} = c$$

**光速不变自动复现**：无论飞船多快，光相对地面永远是 $c$。这是速度叠加公式最强的自检。

**算例二：两束光对撞。** 两束光相向而行，一束相对另一束的速度是多少？经典答案是 $2c$（相对论"禁止"），代入公式：$u = c$、$v = -c$（反向），

$$u' = \frac{c - (-c)}{1 - c(-c)/c^2} = \frac{2c}{2} = c$$

**相对速度也是 $c$，不是 $2c$**——这背后是"光速没有更大的参照"：光在任何参考系里都是 $c$，所以"一束光看另一束光"也必然是 $c$。<span class="marginnote">这个结果常让初学者震惊，但它完全自洽：如果把"相对速度"定义成"一束光的参考系里另一束光的运动速度"，而光的参考系里时间不流逝，这个"速度"本身就没有通常意义。物理上更常用的量是<strong>不变量</strong> $s$（两光子的质心能量），它才是守恒计算的主角。</span>

**算例三：相对论火箭的速度墙。** 火箭每次喷射都把速度提高 $0.5c$（相对自身）。经典：第一次 $0.5c$、第二次 $1.0c$、第三次 $1.5c$（超光速！）。相对论：用公式逐次合成，

$$v_1 = 0.5c,\quad v_2 = \frac{0.5c + 0.5c}{1 + 0.25} = 0.8c,\quad v_3 = \frac{0.8c + 0.5c}{1 + 0.4} \approx 0.929c,\quad \cdots$$

速度越来越接近 $c$，但**永远到不了**——每加一次，增量越来越小。<span class="marginnote">这个"永远到不了"的级数是相对论动力学"无穷能量墙"的速度学版本：推进剂能给你有限的速度增量，但增量在 $c$ 面前"越来越不值钱"。科幻里的星际航行若靠逐步加速，将永远被钉在光速之下——这就是为什么真实星际任务（如太阳帆、光帆）直接瞄准"接近光速的粒子束/光子推动"。</span>

这三组算例揭示了速度叠加公式的"三张面孔"：**光速不变的自检、相对速度的封顶、加速级数的收敛**。理解了它们，速度叠加公式就不再是一个孤立的公式，而是光速上限在一切速度问题中的投影。

**补充一个极易出错的细节：分母的单位。** $u' = \dfrac{u - v}{1 - uv/c^2}$ 的分母是无量纲的，但使用时必须保证 $u$、$v$ 用**相同单位**（都除以 $c$ 化成 $\beta$ 最稳）。很多计算错误不是公式错，而是"$u$ 用 m/s、$v$ 用 km/s"或"忘记把 km 换算成 m"——先统一单位再代入，是相对论计算的第一纪律。

**速度叠加与四维速度的呼应**：为什么相对论里"速度"这么别扭，而"快度"（rapidity）$\eta = \operatorname{artanh}(v/c)$ 却让叠加变成加法 $\eta_{\rm total} = \eta_1 + \eta_2$？因为快度是洛伦兹变换的"旋转角"——角度相加自然是加法。这个视角在粒子物理里很实用：粒子的快度是实验测量与理论计算的常用量（如 LHC 喷注的快度分布）。**"换一个坐标，加法就复活了"**——这是物理学家对付非线性公式的通用技巧：找到让问题"线性化"的量。

**速度叠加"一页速查"**：

**一维公式**：

$$u' = \frac{u - v}{1 - uv/c^2}$$

- 低速极限（$u, v \ll c$）：$u' \approx u - v$，退回伽利略叠加；
- 光速自检（$u = c$）：$u' = c$，任意 $v$ 都保光速不变；
- 对撞光（$u = c, v = -c$）：$u' = c$，不是 $2c$；
- 反解：$u = \dfrac{u' + v}{1 + u'v/c^2}$（把 $v$ 换号）。

**三维推广要点**：

- $x$ 方向合成同上一维公式；
- 横向分量 $u'_y = \dfrac{u_y}{\gamma(1 - v u_x/c^2)}$——**时间膨胀拖累横向速度**；
- $|\vec u| = c \Rightarrow |\vec u'| = c$：任意方向的光速都不变。

**三类"超光速幻影"**：

- **相速度** $v_\phi = \omega/k$：可超 $c$，但不传信号；
- **视超光速**：喷流投影错觉，不违反因果；
- 共同点：**都不传递信息**——相对论禁止的是信号超光速。

**快度的妙用**：$\eta = \operatorname{artanh}(v/c)$，叠加变加法 $\eta_{\rm total} = \eta_1 + \eta_2$——"换坐标，加法复活"，粒子物理常用。

## 7 小结

- **相对论速度叠加**（一维）：$u' = \dfrac{u - v}{1 - uv/c^2}$，低俗时退化为 $u' = u - v$。
- 三维情形下横向分量带 $\gamma$ 因子，因为时间膨胀影响所有时间间隔。
- **光速不变自我一致**：$u = c$ 时任意 $v$ 都给出 $u' = c$，光速是速度空间的绝对天花板。
- 相速度、视超光速**可以**超过 $c$，但它们不传递信息，不破坏因果律。
- 工程价值：加速器对撞能量、宇宙线到达、GPS 多普勒修正都依赖精确速度叠加。

在下一节，我们把速度问题暂时放下，转向相对论最著名的"招牌"——**质量与能量的等价 E=mc²**，看相对论如何把"惯性"这个概念也重新定义。
