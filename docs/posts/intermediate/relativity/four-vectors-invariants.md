## 为什么需要一套"四维语言"

我们已经有了洛伦兹变换和间隔，但物理世界还有很多量：速度、动量、能量、力、电磁场……它们怎么变换？如果每个都单独推导，那会是一团乱麻。**四维矢量（four-vector）** 提供了一把统一的钥匙：把物理量按"洛伦兹变换下的行为"分类，凡是在变换时像 $(ct, x, y, z)$ 一样"旋转"的量，它们的"模长"自动是不变量——守恒与不变都藏在同一个结构里。<span class="marginnote">这就像三维矢量：你不需要分别记"力怎么随旋转变""动量怎么随旋转变"——只要知道它们都是矢量，就自动知道它们在旋转下怎么变，且长度不变。四维矢量就是把这个套路搬到四维时空。</span>

这一篇我们定义四维矢量、学会算它的"模长"（不变量），并把位置、速度、动量、能量全部放进这个框架——重点是：**E=mc²、动量守恒、间隔不变，其实都是同一个四维矢量的同一个不变量。**

## 1 四维矢量的定义与模长

**四维矢量（four-vector）** 是一个有序四元组 $A^\mu = (A^0, A^1, A^2, A^3)$，在洛伦兹变换下按照与坐标 $(ct, x, y, z)$ 相同的规则变换。它的"模长平方"（也叫**洛伦兹不变量**）定义为：

$$|A|^2 = (A^0)^2 - (A^1)^2 - (A^2)^2 - (A^3)^2$$

注意那个关键的**负号**：时间分量取正、空间分量取负（或反过来，是约定问题）。正是这个负号让"模长"可以是正、零或负——对应类时、类光、类空，见上一篇。**负号的存在使四维矢量的"模长"在洛伦兹变换下不变，这是整个框架的核心定理**：因为洛伦兹变换是对 $ct$ 与 $x$ 的伪旋转，伪旋转保持 $A^2 - B^2$ 型组合不变。<span class="marginnote">读者可能注意到这和欧氏长度 $A_x^2 + A_y^2 + A_z^2$ 的差别——欧氏空间里全是加号，闵可夫斯基时空里时间项前是减号。这个"一正三负"的符号模式，正是把平直时空与欧氏空间区分开的数学签名，它决定了光锥、因果、以及后面所有引力几何。</span>

## 2 四维速度：本征时间的妙用

定义四维速度 $U^\mu$ 为位置对**本征时间**的导数：

$$U^\mu = \frac{d}{d\tau}(ct, x, y, z) = \left(\gamma c,\ \gamma v_x,\ \gamma v_y,\ \gamma v_z\right)$$

**为什么对本征时间求导？** 因为 $dt$ 随参考系变，而 $d\tau$ 是洛伦兹不变量（本征时间是世界线弧长）。用不变量做分母，得到的 $U^\mu$ 才能保证是一个真正的四维矢量。<span class="marginnote">这是选择"分母"的关键技巧：<strong>任何量对 $d\tau$ 求导，都自动继承四维矢量的变换性质</strong>。反之若对 $dt$ 求导，得到的就是普通三维速度 $v$，它不构成四维矢量——这是为什么经典速度变换那么麻烦，而四维速度一个公式走天下。</span>

四维速度的模长是常数：

$$|U|^2 = \gamma^2 c^2 - \gamma^2 v^2 = \gamma^2 c^2(1 - v^2/c^2) = c^2$$

**四维速度的模长恒等于 $c$**——无论粒子以多快运动，它的四维速度"长度"永远是光速。这是一个让人惊叹的不变量：粒子的"四维速率"不随时间、不随运动改变，恒为 $c$。只是低速时它的分量几乎全在时间方向（$\gamma c \approx c$，空间分量很小），高速时空间分量才显山露水。

## 3 公式解析：四维动量与质能关系

定义**四维动量**（能量-动量四矢）为静质量乘以四维速度：

$$p^\mu = m U^\mu = \left(\frac{E}{c},\ p_x,\ p_y,\ p_z\right)$$

其中 $E = \gamma mc^2$，$\vec p = \gamma m\vec v$——正是上一篇独立推导出的能量与动量！现在它们自动"配对"成一个四维矢量。

**第一步，算模长。** $|p|^2 = (E/c)^2 - (p_x^2 + p_y^2 + p_z^2) = \left(\frac{E}{c}\right)^2 - p^2$

**第二步，代入 $E = \gamma mc^2$、$p = \gamma mv$：**

$$\left(\frac{E}{c}\right)^2 - p^2 = \gamma^2 m^2 c^2 - \gamma^2 m^2 v^2 = \gamma^2 m^2(c^2 - v^2) = m^2 c^2$$

**第三步，两边乘 $c^2$ 还原成熟悉的质能关系：**

$$E^2 = (pc)^2 + (mc^2)^2$$

这条公式的**几何含义**：$mc$ 是四维动量的"模长"（不变量），$(E/c, \vec p)$ 是这个矢量的分量。不同参考系看到不同的 $E$ 和 $\vec p$，但它们的"组合模长" $mc$ 永远不变——**质量 $m$ 正是四维动量的洛伦兹不变量**。<span class="marginnote">这个视角统一了守恒律：<strong>四维动量守恒</strong>（四个分量都守恒）同时包含了能量守恒与动量守恒；而静质量守恒只是模长不变。在粒子物理里，计算对撞产物时用的是四维动量守恒——一个不变量，四行方程，一步到位。</span>

## 4 标量、矢量与张量的分层

四维语言还引入了更精细的分类，这是通向广义相对论的阶梯：

**四维标量（scalar）**：洛伦兹变换下完全不变的单个数。例如：静质量 $m$、间隔 $\Delta s^2$、本征时间 $\tau$。
**四维矢量（vector）**：按坐标方式变换的四个数。例如：位置、四维速度、四维动量。
**二阶张量（tensor）**：按"两个指标"方式变换的 $4 \times 4$ 数组，例如能量-动量张量 $T^{\mu\nu}$——它在《爱因斯坦场方程》里是引力的"源"。

分类的价值在于：**物理定律若写成"同类型量的等式"，就自动是洛伦兹不变式**。比如 $p^\mu = mU^\mu$，左边是矢量、右边标量乘矢量，两边同为矢量，等式在所有惯性系里形式相同——这就是相对性原理对"定律写法"的要求。<span class="marginnote">这个"按变换行为分类"的思想会被爱因斯坦在广义相对论里推向极致：<strong>定律必须写成协变形式，即左右两边的张量指标完全匹配</strong>。到《张量与微分几何入门》一篇，你会看到这套语言如何把整个物理定律"翻译"成"坐标无关"的几何陈述。</span>

**辨析｜易错点：** "洛伦兹不变量"不是说"数值不变"，而是"方程形式不变"或"组合模长不变"。例如 $E$ 本身随参考系变，但 $E^2 - (pc)^2$ 不变。另一个常见误区是把**能量** $E$ 当标量——它不是，能量是四维动量的**时间分量**，随参考系变；只有静能 $mc^2$ 是不变量。分不清"分量"与"模长"，是相对论里几乎所有数值困惑的根源。

## 5 守恒律的四维表述

牛顿力学里能量与动量分开守恒，相对论里它们是同一件事的四个分量。写四维动量守恒：

$$\sum_i p^\mu_{\text{(初)}} = \sum_j p^\mu_{\text{(末)}}$$

这一条方程包含四行：能量守恒一行，三维动量守恒三行。**碰撞、衰变、对撞，一切粒子过程的计算都从这里开始**。<span class="marginnote">一个漂亮的例子：静止的正负电子对湮灭产生两个光子。在质心系中两个光子的动量必须大小相等方向相反（三维动量守恒），总能量 $2m_ec^2$ 平均分给两个光子（能量守恒）。只要四维动量守恒写对，结果唯一——不需要任何额外假设。</span>

这种"一条四维守恒 = 四条守恒"的统一，正是相对论"让复杂变简单"的缩影：表面上多了公式，实际上把原本各自为政的守恒律收编进了同一几何结构，并为《相对论运动学与动力学》铺好了路。

## 6 实战：用不变量算"质心能量"

四维矢量的真正威力在于：**算不变量时，你可以挑最方便的参考系**。我们用它算粒子物理最常用的量——质心系总能量。

**题目**：两个同质量 $m$ 的粒子对撞，实验室系中一个静止、一个以速度 $v$ 运动。求质心系（两粒子总动量零的参考系）中的总能量 $E_{\rm cm}$。

**第一步，写实验室系的两条四维动量。** 静止粒子的四维动量 $p_1^\mu = (mc, \vec 0)$；运动粒子的 $p_2^\mu = (E/c, \vec p)$，其中 $E = \gamma mc^2$、$p = \gamma mv$。

**第二步，构造不变量 $s$。** 定义 Mandelstam 变量 $s = -(p_1 + p_2)^2$（模长平方取负号是粒子物理的约定），它等于质心系总能量的平方（除以 $c^2$）：$s = E_{\rm cm}^2/c^2$。

**第三步，在实验室系算这个不变量（挑方便的系）。**

$$s = -(p_1^\mu + p_2^\mu)^2 = -[mc^2 + E/c]^2/c^2 \cdots$$

更直接地：$s c^2 = (E + mc^2)^2 - (pc)^2$。展开并代入 $E^2 = (pc)^2 + (mc^2)^2$：

$$E_{\rm cm}^2 = (E + mc^2)^2 - (pc)^2 = E^2 + 2Emc^2 + m^2c^4 - (pc)^2 = 2mc^2E + 2m^2c^4 = 2mc^2(\gamma mc^2 + mc^2)$$

即 $E_{\rm cm} = \sqrt{2mc^2(\gamma + 1)mc^2} = mc^2\sqrt{2(\gamma+1)}$。<span class="marginnote">这个结果的意义：把能量 $E$ 灌进"固定靶"实验，质心能量只随 $\sqrt{\gamma}$ 增长（很慢）；而<strong>对撞机</strong>（两束粒子各带能量 $E$）的质心能量 $\propto \gamma$（线性增长）——所以 LHC 用对撞而非固定靶：同样的束流能量，对撞能获得多得多的"可用能量"来产生新粒子。</span>

**这一步"挑参考系计算"正是四维方法的精髓**：质心能量是标量（不变量），你在任何系算都一样；于是你选**计算最简单**的实验室系。这比"先在质心系求两粒子速度、再合成能量"的传统做法省一半功夫，也不容易错。

**这套方法的普适配方**：遇到任何粒子过程，先写四维动量、再构造不变量（$s$、$t$、$u$ 等 Mandelstam 变量）、在方便系里算、最后读出物理。粒子物理里几乎所有"能产生什么、需要多大能量"的问题都走这条路。**"找不变量 + 挑参考系"是相对论计算的万能钥匙**——它把"坐标系依赖"的麻烦全部消化在"不变量"里，这正是四维语言被发明出来的意义。

**四维语言"一页速查"**：

**四维矢量全家福**：

| 对象 | 分量 | 模长（不变量） |
| --- | --- | --- |
| 位置 $x^\mu$ | $(ct, \vec x)$ | $\Delta s^2$（间隔） |
| 四维速度 $U^\mu$ | $(\gamma c, \gamma\vec v)$ | $c^2$（恒为光速） |
| 四维动量 $p^\mu$ | $(E/c, \vec p)$ | $mc$（静质量） |
| 四维力 $F^\mu$ | $(\frac{1}{c}\frac{dE}{dt}, \gamma\vec F)$ | — |

**三大操作**：

- **升降指标**：$A^\mu = g^{\mu\nu}A_\nu$，$A_\mu = g_{\mu\nu}A^\nu$；
- **收缩（配对求和）**：上下指标成对即求和，结果是不变量；
- **协变等式**：两边同型张量相等 ⇒ 自动满足相对性原理。

**一个万能配方**：遇到粒子过程 → 写四维动量 → 构不变量（$s, t, u$）→ 挑方便参考系计算 → 读出物理。

**一个反直觉结论**：四维速度的模长恒为 $c$——无论粒子多慢或多快，它在时空里的"速率"都是光速，只是低速时几乎全"指向时间方向"。

**常用不变量口诀**：间隔、静质量、本征时间、光速 $c$——这四个是相对论里的"绝对"，其余都是相对。

## 7 小结

- **四维矢量**按坐标方式随洛伦兹变换，**模长** $(A^0)^2 - (A^1)^2 - \cdots$ 是不变量。
- **四维速度** $U^\mu = (\gamma c, \gamma\vec v)$：对本征时间求导保证矢量性，模长恒为 $c$。
- **四维动量** $p^\mu = (E/c, \vec p) = mU^\mu$：模长 $mc$ 即静质量，由此**自动**得到 $E^2 = (pc)^2 + (mc^2)^2$。
- 物理量分**标量 / 矢量 / 张量**；定律写成同类量等式即自动满足相对性原理。
- **能量与动量守恒合并为四维动量守恒**，是粒子物理一切计算的起点。
