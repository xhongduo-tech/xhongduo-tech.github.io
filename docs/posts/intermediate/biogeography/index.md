# 生物地理学

生物地理学是研究物种与群落在空间和时间上的分布格局及其形成机制的学科，是生态学与地理学的经典交叉分支。从扩散、物种形成到岛屿平衡理论与区系演化，理解生物多样性的地理规律既是认识地球生命史的关键，也是保护生物多样性的科学基础。

## 对标教材

- Mark Lomolino, Brett Riddle & Robert Whittaker, "Biogeography" (5th ed., Oxford University Press, 2020)
- 殷秀琴 等, 《生物地理学》（高等教育出版社）
