# 生物地理区系：世界动物区与植物区

## 为什么从区系讲起

前面我们看了物种、群系与多样性热点。现在把镜头推到最高空：
把地球陆地当成一张地图，问一句——**能不能像「国家」一样，把地表划分成若干「动物王国」与「植物王国」？**
<span class="marginnote">这就是<strong>生物地理区系（biogeographic realms）</strong>：依据区系组成的相似性，把全球划分成几个大区。
划分本身不是目的，目的是揭示「哪些地区共享演化历史、被什么屏障分开」——
区系的边界往往就是历史的伤疤（海峡、山脉、沙漠的长期隔离）。</span>
这一节以 Lomolino 第14章为纲：先讲动物地理区的经典划分，再讲植物区系王国，
最后用相似性系数把「区系亲疏」变成可计算的量。
它为你提供一套「全球视角的坐标系」，后面第18、19篇的区域历史与分布区类型都要挂在这张图上。

## 1 动物地理区的提出：斯克雷特与华莱士

把动物界划分为若干「区」的尝试，可追溯到 1858 年——达尔文与华莱士在伦敦发表自然选择论文的同一年，
鸟类学家**斯克雷特（Philip Sclater）**基于雀形目鸟类的分布，把全球划分为六大动物地理区。
这六区后来被华莱士在 1876 年巨著《动物的地理分布》（The Geographical Distribution of Animals）
中沿用与完善，成为今天仍在使用的基本框架。

<strong>华莱士的洞见：动物区系的分界与气候带并不重合，而与「古代地理屏障」重合——
因此区系地图是「历史的地图」，不是「气候的地图」。</strong>
<span class="marginnote">这与达尔文那句题记一脉相承：气候相似的大陆（如南美与非洲的赤道带）动物群截然不同，
说明决定区系的是隔离历史而非当代环境。动物地理区的提出，
是生物地理学「历史解释」战胜「气候决定论」的标志性时刻——正是第2篇思想史的延续。</span>
斯克雷特与华莱士的六区方案经受住了 150 年检验，至今仍是动物区系划分的默认框架。

## 2 六大动物地理区巡礼

华莱士的六大动物地理区（zoogeographic realms）大致是：

**古北区（Palearctic）**：欧亚大陆大部、北非。没有「标志性」的特有大型类群
（因为它在冰期与人类扩张中反复被冲刷），但拥有北极熊、驯鹿、骆驼等广布代表，
脊椎动物特有性低、多样性中等——「大而匀」。

**新北区（Nearctic）**：北美洲大部（含墨西哥北部）。与古北区共享许多类群
（北方林带让它们多次交流），但拥有叉角羚、北美豪猪等特有类群。

**东洋区（Oriental）**：南亚、东南亚、中国南部。大型兽类多样：虎、犀牛、大象、猩猩、长臂猿。
与古北区、以及南方的澳新区在马来群岛一线交锋——这里是区系交汇最剧烈的前线。

**埃塞俄比亚区（Afrotropical / Ethiopian）**：撒哈拉以南非洲。
哺乳动物多样性与特有性极高：斑马、长颈鹿、河马、大猩猩、以及多样的大型猫科——「最丰富的陆地动物区」。
<span class="marginnote">埃塞俄比亚区与东洋区共享大象、犀牛、猿猴等古老血统，
却又有大量独自演化的大型哺乳动物——说明它们曾有陆桥相连，又长期隔离。
非洲与亚洲的动物相似性，是「间断分布 + 陆桥」的经典注脚，
也解释了为何古生物学家反复在两地之间寻找迁徙通道。</span>

**澳新区（Australasian / Australian）**：澳大利亚、新几内亚及其附近岛屿。
以有袋类与单孔类（鸭嘴兽、针鼹）独占鳌头，特有性极高——「最独特的动物区」。
这里的哺乳动物几乎全为有袋类与单孔类，胎盘哺乳类（蝙蝠、啮齿类、人类引入者除外）长期缺席。

**新热带区（Neotropical）**：南美洲、中美洲、加勒比。
拥有全球最丰富的哺乳动物与鸟类（金刚鹦鹉、蜂鸟、树懒、美洲豹），特有科最多——「多样性的殿堂」。

## 3 植物区系王国：另一套地图

动物与植物共享历史，但分布细节不同——植物对气候更敏感、扩散手段不同，
所以植物区系有自己的一套划分。植物地理学通常划分**六大植物区系王国（floristic kingdoms）**
（古德 Good、塔赫塔詹 Takhtajan 系统）：

**泛北极（Holarctic）王国**：北半球温带至寒带，涵盖古北与新北。
以松柏类、杨柳科、菊科等温带类群为特征，特有科少、但属级特有多。

**古热带（Paleotropical）王国**：非洲、亚洲、大洋洲的热带。
以棕榈、芭蕉、樟科等热带类群为特征——「热带生物多样性的主干」。

**新热带（Neotropical）王国**：南美与中美热带。拥有仙人掌科、凤梨科等标志类群，植物多样性全球最高。

**南非（Cape）王国**：南非开普区，面积最小却拥有山龙眼科等极其特异的类群——「小而精」。

**澳大利亚（Australian）王国**：以桉树、金合欢、山龙眼科为代表，极强的旱生与特有性。

**南极（Antarctic）王国**：以南极洲与亚南极岛屿为主，植被贫乏但特有性极高。
<span class="marginnote">动物区与植物王国的边界并不完全重合——动物六区与植物六王国各自独立演化，
却惊人地彼此呼应（如新热带区≈新热带王国、澳新区≈澳大利亚王国）。
这种「双系统互相印证」本身就是强证据：它们反映的是同一个深层历史——大陆的分合。</span>

## 4 区系的相似性与过渡带

区系划分听起来是「画几条线」，但线画在哪里、怎么衡量亲疏，需要定量。两个核心问题：

**区系相似性**：两地区物种组成重叠多少？用相似性系数（下一节公式）量化——
相似性高说明交流多或历史近，相似性低说明长期隔离。

**过渡带（transition zones）**：区系之间并非一刀切，而是存在渐变与交错。
最著名的是**华莱士区（Wallacea）**——苏拉威西、摩鹿加、小巽他群岛之间的岛屿群，
动物群是亚洲与澳大利亚的混合：既有虎与犀牛（亚洲血统），又有有袋类与凤头鹦鹉（澳大利亚血统）。
<span class="marginnote">华莱士区是「区系交界」的活标本：它不在六区任何一区内，而是亚澳两大区系的碰撞带。
深水海峡（如深约 1200 米的望加锡海峡）比浅水陆棚更能区分区系——
因为末次冰期海平面下降时，浅陆棚连成陆地、深海峡仍是天堑。这解释了为什么华莱士线要沿深水走。</span>

**边界与障碍的尺度问题**：海洋、高山、沙漠是「硬障碍」，但区系边界常由「软障碍」——
如气候过渡、生态竞争——塑造。区分硬、软障碍，是读懂区系地图的关键。

## 5 公式解析：雅卡德相似性系数

把「区系亲疏」变成数字，最常用的工具是**雅卡德相似性系数（Jaccard similarity coefficient）**：

$$
J = \frac{a}{a + b + c}
$$

其中 $a$ 是两地共有的物种数，$b$ 与 $c$ 分别是仅见于 A 地与仅见于 B 地的物种数。拆开看：

- **$a$**：共有的「分母权重」——相似性的证据。
- **$b + c$**：各自的独有物种——差异的来源，放在分母里作为「惩罚」。
- **$J$ 取值范围 0–1**：两地物种完全相同则 $J = 1$，完全无交集则 $J = 0$。
  <span class="marginnote">雅卡德系数只关心「有没有」，不关心「有多少个体」，所以适合物种名录而非丰度数据。
  它的变体（如 Sorensen 系数 $2a/(2a+b+c)$）给共有种更高权重，常用于植被与样方分析——
  选择哪种系数取决于你想放大「共有」还是「特有」的信号。</span>

**区系相似性矩阵 → 区系聚类树**：对 N 个地区两两算 J 值，得到相似性矩阵，
再用聚类分析画成树状图——同一枝的地区共享历史，不同枝的之间隔着长期屏障。
这正是第19篇《分布区类型与区系分析》的直接前奏：区系划分不再是「拍脑袋划线」，
而是「数据聚出的树枝」。

## 6 小结

- **动物地理六区**（古北、新北、东洋、埃塞俄比亚、澳新、新热带）源于斯克雷特 1858、
  完善于华莱士 1876，反映的是隔离历史而非当代气候。
- **植物区系王国**（六大王国）是独立演化出的第二套地图，与动物区互相印证。
- **过渡带**（如华莱士区）是区系碰撞的前线，深水海峡比浅陆棚更能区分区系。
- **雅卡德相似性系数** $J = a/(a+b+c)$ 把区系亲疏量化，是区系聚类分析的基础。
- 区系地图是「历史的地图」：边界 = 长期隔离的伤疤。

在下一节，我们把「区系相似性」继续深化：一个地区的区系不是静止的清单，
而是由多次扩散、替代与灭绝事件拼成的历史拼图——如何重建一部区系史，这就是**重建生物区系历史**。
