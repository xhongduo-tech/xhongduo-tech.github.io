## 为什么从一阶线性开始

在《常微分方程》里，我们研究的是连续世界的演化律：温度随时间如何冷却，行星按什么轨道运动。但真实世界还有一个巨大的子集，演化发生在**离散的步子上**——银行账户按天计息、种群按世代繁殖、算法按迭代推进。描述「后一步由前一步决定」的数学工具，正是**差分方程（difference equation）**。<span class="marginnote">差分方程与微分方程是一对孪生兄弟：把微分方程里的 $y'(x)$ 换成 $\dfrac{y_{n+1}-y_n}{h}$，微分就变成了差分。学完本篇，你等于同时打开了离散动力学与《线性代数》里的递推结构两扇门。</span>

我们从**一阶线性差分方程**出发，因为它是最简单的、却几乎承载了差分方程全部核心概念的例子：通解、特解、平衡点、稳定性，都会在这台「显微镜」下第一次显形。

## 1 差分与差分方程的定义

**差分（difference）**：给一个数列 $\{x_n\}_{n=0}^{\infty}$，相邻两项之差 $\Delta x_n = x_{n+1} - x_n$ 称为数列在 $n$ 处的**一阶差分**。<span class="marginnote">差分是离散世界的「导数」：连续世界里 $\dfrac{dy}{dx}$ 衡量变化率，离散世界里 $x_{n+1} - x_n$ 衡量一步的变化量。把步长视为 1 个单位时间，差分与导数在直觉上完全平行。</span>

**一阶差分方程**：把一阶差分与自变量、未知函数本身联系起来的方程。例如：

$$\Delta x_n = f(n, x_n)$$

把 $\Delta x_n = x_{n+1} - x_n$ 代进去，可以改写成显式递推形式：

$$x_{n+1} = f(n, x_n)$$

若 $f$ 关于 $x_n$ 是**线性的**，即形如：

$$x_{n+1} = a_n x_n + b_n$$

就得到**一阶线性差分方程**；若系数 $a_n$、$b_n$ 都不随 $n$ 变化（是常数），则进一步称其为**常系数一阶线性差分方程**：

$$x_{n+1} = a x_n + b$$

给定初值 $x_0$，递推式就唯一决定整个数列——这与常微分方程的初值问题一一对应，称为**初值问题（initial value problem）**。

## 2 常系数情形：逐项迭代与封闭解

先看最特殊的一类：$b = 0$，即 $x_{n+1} = a x_n$。这正是等比数列：

$$x_1 = a x_0, \quad x_2 = a^2 x_0, \quad \ldots \quad x_n = a^n x_0$$

当 $b \neq 0$ 时，直接迭代也能看出规律：

$$x_1 = a x_0 + b, \quad x_2 = a^2 x_0 + ab + b, \quad x_3 = a^3 x_0 + a^2 b + ab + b$$

$b$ 项累加出一个等比级数。当 $a \neq 1$ 时用求和公式，得到**封闭解（closed-form solution）**：

$$x_n = a^n x_0 + b \cdot \frac{1 - a^n}{1 - a}$$

当 $a = 1$ 时方程退化为 $x_{n+1} = x_n + b$，解是等差数列 $x_n = x_0 + n b$。<span class="marginnote">$a=1$ 是临界情形：等比求和公式分母为 0，须单独处理。这种「公式在某参数处失效、须分情形讨论」的谨慎，在差分方程里会反复出现，比如后面高阶方程的特征根重根情形。</span>

### 数值示例：按月复利存款

设存款月利率 $r$，每月初追加存入 $m$ 元，则第 $n$ 月末余额 $x_n$ 满足 $x_{n+1} = (1+r)x_n + m$，其中 $a = 1 + r$、$b = m$。取 $r = 0.5\%$、$m = 1000$、$x_0 = 0$，代入封闭解：

$$
x_n = 1000 \cdot \frac{(1.005)^n - 1}{0.005}
$$

第 12 期余额 $x_{12} \approx 1000 \times \dfrac{1.06168 - 1}{0.005} \approx 12336$ 元；若不计利息（$r = 0$），12 期仅 $12000$ 元——差额 $336$ 元正是复利的累计收益。

再看平衡点 $x^* = \dfrac{b}{1-a} = \dfrac{m}{1-(1+r)} = -\dfrac{m}{r} \lt  0$：负数平衡点是纯数学痕迹，实际存款无意义——它只是说明系统单调增长、没有「停在某余额」的可能，与 $|a| = 1.005 > 1$（不稳定、发散）的判断一致。

**易错点｜辨析：** 初值下标从 $0$ 还是从 $1$ 开始，会改变封闭解的形式。若递推写作 $x_{n+1} = a x_n + b$ 且初值为 $x_0$，则指数是 $a^n$；若改用 $x_n = a x_{n-1} + b$、初值 $x_1$，则指数是 $a^{n-1}$。解题第一步永远是**统一记号**，再套公式。

## 3 平衡点与稳定性初探

**平衡点（equilibrium）**：满足 $x_{n+1} = x_n$ 的点，记作 $x^*$。它意味着「系统停在这一点后不再变化」。

对常系数方程，令 $x^* = a x^* + b$，解得唯一平衡点（当 $a \neq 1$）：

$$x^* = \frac{b}{1 - a}$$

**稳定性**关心的是：若初值偏离平衡点一点点，后续轨迹是回到平衡点，还是越走越远？把解写成相对偏差 $\varepsilon_n = x_n - x^*$，代入递推：

$$\varepsilon_{n+1} = a \varepsilon_n$$

于是 $\varepsilon_n = a^n \varepsilon_0$。结论一目了然：

- $|a| \lt  1$：偏差以 $|a|^n$ 衰减到 0，平衡点**渐近稳定**；
- $|a| > 1$：偏差按 $|a|^n$ 放大，平衡点**不稳定**；
- $|a| = 1$：偏差既不放大也不收敛，称为**临界情形**，稳定性取决于高阶项。

这一条「看系数绝对值」的判据，是整个差分方程稳定性理论的种子。后面在《平衡解与稳定性判据》篇，我们会看到它被推广到非线性系统。

## 4 公式解析：常系数一阶线性方程的封闭解

我们把最核心的公式拆开：

$$
x_n = a^n x_0 + b \cdot \frac{1 - a^n}{1 - a} \qquad (a \neq 1)
$$

- **第一步，看 $a^n x_0$ 这一项**：它来自齐次部分 $x_{n+1} = a x_n$。每一步把当前值乘 $a$，走 $n$ 步就是 $a^n$ 倍。这一项决定「记忆」——初值的影响力按几何级数放大或衰减。
- **第二步，看 $\dfrac{1 - a^n}{1 - a}$**：它是 $1 + a + a^2 + \cdots + a^{n-1}$ 的紧凑写法，记录了外源项 $b$ 在过去 $n$ 步里被逐次「贴现」后的累计贡献。$b$ 在第 $k$ 步注入，到第 $n$ 步时已被乘了 $a^{n-k}$ 次。
- **第三步，理解与平衡点的关系**：把 $x^* = \dfrac{b}{1-a}$ 代入，可将解改写成 $\varepsilon_n = a^n \varepsilon_0$，即相对偏差按纯几何规律演化。这一改写说明：**封闭解 = 平衡点 + 初值偏差的等比演化**。

**辨析｜易错点：** 公式中的指数是 $n$ 而非 $n+1$。逐项迭代时 $x_n$ 共经过 $n$ 次乘以 $a$，容易多写一次。用 $n=1$ 代入自检：$x_1 = a x_0 + b$，与递推式一致。

## 5 变系数方程：乘积与求和公式

若系数随步数变化，即 $x_{n+1} = a_n x_n + b_n$，封闭解由**乘积**与**求和**两件套给出：

$$
x_n = \left(\prod_{k=0}^{n-1} a_k\right) x_0 + \sum_{j=0}^{n-1} \left(\prod_{k=j+1}^{n-1} a_k\right) b_j
$$

直观理解：初值 $x_0$ 被后面每一步的系数一路相乘；第 $j$ 步注入的外源 $b_j$，从第 $j+1$ 步起参与乘积。**常系数是变系数的特例**——把 $a_k \equiv a$ 代入，乘积项变成 $a^n$，求和项还原为等比级数。<span class="marginnote">这个乘积-求和结构在离散线性系统里无处不在：马尔可夫链的状态转移、数字滤波器的响应、贷款月供的计算，本质都是「历史贡献被逐期折现」。它与连续情形的积分因子法（见《常微分方程》）是同一思想的离散版。</span>

## 6 小结

- **一阶线性差分方程** $x_{n+1} = a_n x_n + b_n$：线性 = 对 $x_n$ 是线性的；常系数是其特例。
- **常系数封闭解**：$x_n = a^n x_0 + b \cdot \dfrac{1-a^n}{1-a}$（$a \neq 1$）；$a = 1$ 时为等差数列。
- **平衡点** $x^* = \dfrac{b}{1-a}$；稳定性由 $|a|$ 决定：$\lt 1$ 渐近稳定、$>1$ 不稳定、$=1$ 临界。
- **封闭解可重写为**「平衡点 + 偏差等比演化」$\varepsilon_n = a^n \varepsilon_0$，这一视角贯穿全专题。
- **变系数解**由乘积（初值）与求和（外源）两部分构成，是常系数的推广。
