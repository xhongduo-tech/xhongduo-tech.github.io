## 为什么差分方程通向函数方程

差分方程 $x_{n+1} = a x_n + b$ 说的是「数列相邻两项的关系」。如果把它推到极限——自变量 $n$ 变成连续变量 $x$，未知量从数列变成**函数** $f$，约束从「递推」变成「对任意输入都成立的关系」——就得到**函数方程（functional equation）**。它看似与差分方程分道扬镳，实则同根：都研究「一个关系式决定一个未知量」的确定性问题。<span class="marginnote">函数方程是数学里「以小见大」的极致：一条简单等式（如 $f(x+y)=f(x)+f(y)$）竟然能唯一确定函数族 $f(x)=cx$。它是「加法分配律」「乘法分配律」等基本定律的抽象化，也是信息论、经济学公理化里「从公理推出公式」的引擎。</span>

## 1 函数方程的定义与例子

**函数方程**：含有未知函数 $f$、且要求对定义域中所有变量都成立的方程。与差分方程的关键差异：

- 差分方程约束**数列的相邻项**（离散下标）；函数方程约束**任意两个自变量**的函数值关系（连续自变量）；
- 差分方程的解是数列；函数方程的解是函数。

常见例子（后文会反复用到）：

| 函数方程 | 正则解 | 直觉 |
| --- | --- | --- |
| $f(x+y) = f(x) + f(y)$ | $f(x) = cx$ | **加法律**：和映射到和 |
| $f(x+y) = f(x) f(y)$ | $f(x) = a^x$ | 指数律：和映射到积 |
| $f(xy) = f(x) + f(y)$ | $f(x) = c\ln x$ | 积映射到和 |
| $f(xy) = f(x) f(y)$ | $f(x) = x^c$ | 幂律 |

**易错点｜辨析：** 函数方程的解必须说明「在什么正则条件下」。$f(x+y)=f(x)+f(y)$ 在「无任何连续性假设」时解比 $cx$ 多得多（见第 3 节），而加了连续性后解才唯一。**「解」的答案依赖假设集**，这是函数方程与差分方程最不同的地方。

## 2 Cauchy 方程：四个正则化条件

**Cauchy 方程**是函数方程的主角：

$$f(x+y) = f(x) + f(y), \qquad x, y \in \mathbb{R}$$

只靠这条方程，先在**有理数**上推出 $f(q) = c q$：对整数 $n$，$f(n) = n f(1)$；对分数，$f\left(\tfrac{m}{n}\right) = \tfrac{m}{n} f(1)$。有理数全被固定。剩下的是无理数——它们与有理数的联系由**连续性**等正则条件补上。经典结论：**在下列任一条件下，Cauchy 方程的解都是 $f(x) = cx$**：

- $f$ 在某一点**连续**；
- $f$ 在某个区间上**单调**；
- $f$ 在某个区间上**有界**；
- $f$ 在某个区间上**可测**（Lebesgue）。

**辨析｜易错点：** 四个条件**等价地**够用，但缺一不可替换。特别是「有界」只需在某一个（哪怕极窄的）区间上有界即可——条件之宽松与结论之强形成鲜明对比。<span class="marginnote">这四个条件的罗列是函数方程「正则化」的标准套路：方程本身先定结构，再借一点点「良好性」把它钉死在唯一解上。这种「代数 + 分析」的组合拳，是整门学科的方法论核心。</span>

## 3 无正则假设的病理解

如果完全不假设连续、单调、有界或可测，Cauchy 方程还有**无穷多个「病态」解**——它们处处不连续、在每个区间上无界。构造依赖于**Hamel 基**（选择公理）：把 $\mathbb{R}$ 看成有理数域 $\mathbb{Q}$ 上的向量空间，取一组 Hamel 基 $B$，对每个基向量 $b$ 任意指定值 $f(b) \in \mathbb{R}$，再线性地延拓到整个 $\mathbb{R}$。<span class="marginnote">Hamel 基的存在依赖选择公理（AC），所以这些病态解是「存在但不可显式构造」的。它们提醒我们：不加正则条件的函数方程是「伪问题」，数学实践里正则条件是定义的一部分。</span>

**易错点｜辨析：** 病态解不是「近似等于 $cx$」——它们是**截然不同**的函数，只是与 $cx$ 在稠密的子空间（如有理数）上重合。它们的存在说明：**方程确定「线性」只在线性空间的意义上，正则条件才把线性钉成「连续线性」**。

## 4 Jensen 方程与中点凸性

**Jensen 方程**（凸性公理）：

$$f\left(\frac{x+y}{2}\right) = \frac{f(x) + f(y)}{2}$$

它刻画「中点处的函数值等于两端均值」——这是凸函数的定义式（当改为 $\le$ 时是凸性）。在连续假设下，Jensen 方程的解是**仿射函数**：

$$f(x) = cx + d$$

**Jensen 与 Cauchy 的联系**：令 $g(x) = f(x) - f(0)$，则 $g$ 满足 Cauchy 方程——Jensen 方程「去常数项」就还原成 Cauchy 方程；反过来 Cauchy 解加常数就得 Jensen 解。<span class="marginnote">这条「平移消常数」的套路极具普适性：先猜特解（这里是常数 $d = f(0)$），再让未知函数减去特解归到更简单的方程。它与差分方程里「非齐次通解 = 齐次通解 + 特解」是同一思想。</span>

**辨析｜易错点：** Jensen 方程的解是**仿射**（含常数项）而非纯线性 $cx$。$f(x) = cx + d$ 满足中点条件但不满足 $f(x+y)=f(x)+f(y)$（除非 $d=0$）。两者的区别正是「加法保持」与「中点保持」的区别。

### d'Alembert 方程与余弦函数

另一个贯穿数学分析的经典是 **d'Alembert 方程**（余弦加法公式的函数方程版本）：

$$
f(x+y) + f(x-y) = 2 f(x) f(y)
$$

在 $f(0) = 1$ 且连续的正则条件下，解是 $f(x) = \cos(cx)$ 或 $f(x) = \cosh(cx)$——三角恒等式 $\cos(x \pm y) = \cos x \cos y \mp \sin x \sin y$ 正是这个方程的解。它说明：**一条「对任意 $x, y$ 都成立」的方程，足以把余弦函数从茫茫函数海中唯一挑出来**——函数方程因此是基本初等函数的「公理化定义」方式，也是《数学分析》中三角函数的严谨入门。

## 5 公式解析：从 Cauchy 方程推出 $f(x) = cx$

以「连续 Cauchy 方程」为例，把完整推理拆成三步：

- **第一步，整数**：令 $y = x$ 得 $f(2x) = 2f(x)$；归纳得 $f(n) = n f(1)$。记 $c = f(1)$。

$$
f(n) = n c, \qquad n \in \mathbb{Z}
$$

- **第二步，有理数**：由 $n \cdot \tfrac{m}{n} = m$ 得 $f\left(\tfrac{m}{n}\right) = \tfrac{1}{n} f(m) = \tfrac{m}{n} c$。对任意有理数 $q$，$f(q) = c q$。
- **第三步，无理数**：任取无理数 $x$，取有理数序列 $q_k \to x$。由连续性：

$$
f(x) = f\left(\lim_{k\to\infty} q_k\right) = \lim_{k\to\infty} f(q_k) = \lim_{k\to\infty} c q_k = c x
$$

**核心洞察**：有理数上「加法方程」用初等代数即可破解；无理数是靠**连续性极限**接管的。没有连续性，第三步就塌了——这正是病态解存在的缝隙所在。<span class="marginnote">这套「先有理数、再极限延拓」的证明，在数学分析里反复出现（稠密子集上的等式延拓到闭包）。它与《实变函数与测度论》里「几乎处处相等」的延拓思想一脉相承。</span>

## 6 应用：从公理到公式

函数方程的价值在公理化科学里集中爆发——**从几条公理推出具体公式**：

- **信息论**：Shannon 从「信息量可加」等四条公理出发，用函数方程推出信息量必为 $I(p) = -k \log p$——熵公式不是猜的，是**推出来的**；
- **经济学**：效用函数的加性可分解性、成比例性，都归结为特定函数方程，解出 $x^\alpha$、$\ln x$ 等具体形式；
- **几何**：勾股定理的函数方程刻画、几何量（面积、体积）的加性公理，同样以函数方程为准绳。

**易错点｜辨析：** 应用时「正则条件」不可省略。经济学里效用函数若不假设连续性，Cauchy 方程的病态解会让「效用可加」模型失去可操作性——所以公理化分析的第一步总是先声明正则性。

## 7 小结

- **函数方程**是约束函数关系的方程，解是函数；差分方程是它在离散下标上的表亲。
- **Cauchy 方程** $f(x+y)=f(x)+f(y)$ 在连续/单调/有界/可测任一条件下解为 $f(x)=cx$；无正则条件时存在病态解（Hamel 基）。
- **Jensen 方程** $f\left(\frac{x+y}{2}\right)=\frac{f(x)+f(y)}{2}$ 在连续条件下解为仿射函数 $f(x)=cx+d$
