# 平衡解与稳定性判据

<div class="epigraph">
<p>系统的命运，往往不取决于它精确的运动，而取决于它「不运动」的那几个点是否牢靠。</p>

## 为什么「不求解」也能知道命运

前几篇我们把差分方程解出来，看到通解与初值。但很多实际问题并不需要完整轨迹，只关心一个更粗的问题：**系统最终会停在哪儿、会不会被扰动弹飞？** 这就是平衡解与稳定性理论要回答的。它在生态学（种群会不会灭绝）、经济学（价格会不会回到均衡）、控制论（系统会不会发散）里，是比「精确解」更常用的决策依据。<span class="marginnote">「定性优先于定量」是庞加莱开启的现代动力系统视角：不必知道轨迹的每个点，只研究平衡点附近的行为。本篇先把一维判据讲透，二维的相图分析见后文《相图与周期解》。</span>

## 1 平衡点的定义

对一般一阶自治差分方程：

$$x_{n+1} = f(x_n)$$

若存在 $x^*$ 使 $f(x^*) = x^*$，则称 $x^*$ 为系统的**平衡点（equilibrium）**或**不动点（fixed point）**。它的含义是：一旦 $x_n$ 到达 $x^*$，后续一切状态都停在 $x^*$。

**辨析｜易错点：** 平衡点要求 $f(x^*) = x^*$，不是 $f(x^*) = 0$。后者是连续系统 $\dot x = f(x)$ 的平衡条件——离散与连续的一字之差，是最常见的混淆源。<span class="marginnote">翻译一下：连续系统「速度为零」即静止，所以平衡点是 $f=0$；离散系统「一步走完仍回到原处」才静止，所以平衡点是 $f(x)=x$。两者定义域不同，不能混用。</span>

例如线性方程 $x_{n+1} = a x_n + b$ 的平衡点 $x^* = \dfrac{b}{1-a}$（$a \neq 1$）；非线性方程 $x_{n+1} = x_n^2$ 的平衡点解 $x^* = (x^*)^2$，得 $x^* = 0$ 或 $x^* = 1$——一个方程可能有多个平衡点，各自的稳定性还可能不同。

**求平衡点的一般步骤**：解方程 $f(x) = x$，通常移项为 $f(x) - x = 0$ 再求根。对 $f(x) = x^2 + c$ 型，是解二次方程；对 $f(x) = x\, e^{r(1-x)}$（Ricker 模型）型，无初等解，需数值求根——**「求平衡点」本身就可能是个数值问题**，不能总指望手算。

## 2 线性化判据：看导数

非线性方程一般求不出通解，但稳定性可以在平衡点附近**线性化**。把 $x_n = x^* + \varepsilon_n$ 代入并做一阶 Taylor 展开：

$$x^* + \varepsilon_{n+1} = f(x^* + \varepsilon_n) \approx f(x^*) + f'(x^*) \varepsilon_n = x^* + f'(x^*) \varepsilon_n$$

于是偏差的线性近似方程为：

$$\varepsilon_{n+1} = f'(x^*) \varepsilon_n$$

这与第一篇的 $\varepsilon_{n+1} = a \varepsilon_n$ 形式完全相同，只是 $a$ 换成了 $f'(x^*)$。于是得到**线性化稳定性判据（linearization theorem）**：

- $|f'(x^*)| \lt  1$：平衡点**渐近稳定**（吸引子）；
- $|f'(x^*)| > 1$：平衡点**不稳定**（排斥子）；
- $|f'(x^*)| = 1$：**临界情形**，线性化失效，须看高阶项。

**易错点｜辨析：** $f'(x^*)$ 是在平衡点处取值，不是任意点。计算时必须先求出 $x^*$，再代入导数；顺序颠倒会得到完全错误的判据。另外，判据给出的是**局部**结论——只保证平衡点附近足够小的邻域内成立，大扰动仍可能翻越到别的吸引域。

**一个直觉**：$|f'(x^*)|$ 是「平衡点附近每步的伸缩率」。$\lt 1$ 表示每步压缩一点，反复压缩自然收敛；$>1$ 表示每步拉伸，必然发散。这与等比数列 $a^n$ 的收敛判据 $|a| \lt  1$ 完全同构——**非线性系统的局部稳定性，本质上就是「在平衡点处近似成等比演化」的稳定性**，第一篇的种子在这里长成了大树。

## 3 三类稳定性的严格定义

线性化判据回答「稳不稳」，但「稳」在数学上需要精确定义。设 $\|x_n - x^*\|$ 表示离平衡点的距离：

- **Lyapunov 稳定**：对任意足够小的初值偏差，整个轨迹都能被控制在一个任意小的邻域内——不要求收敛，只要求**不跑远**。
- **渐近稳定**：在 Lyapunov 稳定之上，还要求初值足够近时 $\|x_n - x^*\| \to 0$——**最终被吸引**。
- **不稳定**：存在任意靠近平衡点的初值，使轨迹最终远离。

**辨析｜易错点：** 渐近稳定比 Lyapunov 稳定强得多。临界情形 $|f'(x^*)| = 1$ 时，可能 Lyapunov 稳定却不渐近稳定（例如 $x_{n+1} = -x_n$ 在 0 处产生 2-周期振荡），也可能连稳定都谈不上——这正是判据在临界处失效的原因。

## 4 蛛网图：稳定性的几何直觉

一维迭代 $x_{n+1} = f(x_n)$ 有直观的画法，叫**蛛网图（cobweb plot）**：在 $xy$ 平面画 $y = f(x)$ 与直线 $y = x$，从 $(x_0, 0)$ 出发，垂直向上到曲线得 $(x_0, f(x_0))$，再水平向右到直线得 $(f(x_0), f(x_0))$，如此交替。曲线与直线 $y=x$ 的交点即平衡点。<span class="marginnote">蛛网图把抽象迭代变成可视化「爬楼梯」：若蛛网向交点聚拢，平衡点稳定；若越缠越大，则不稳定。它正是后文《相图与周期解》的离散版直觉来源。</span>

几何上可以直观读出：在平衡点附近，若 $|f'(x^*)| \lt  1$，曲线比直线「平缓」，蛛网被吸进去；若 $|f'(x^*)| > 1$，曲线更陡，蛛网被甩出来。这从图像上复现了线性化判据。

## 5 公式解析：Logistic 方程两个平衡点的命运

考察离散 Logistic 方程（无尺度化形式）$x_{n+1} = r x_n (1 - x_n)$，$r > 0$，$x_n \in [0,1]$。分步分析：

- **第一步，求平衡点**：解 $x^* = r x^*(1 - x^*)$，即 $x^*[r(1-x^*) - 1] = 0$，得

$$
x_1^* = 0, \qquad x_2^* = 1 - \frac{1}{r} \quad (r > 1)
$$

- **第二步，算导数**：$f'(x) = r - 2rx = r(1 - 2x)$，于是 $f'(0) = r$，$f'\left(1 - \tfrac{1}{r}\right) = 2 - r$。
- **第三步，套判据**：平衡点 $0$ 当 $|r| \lt  1$ 即 $0 \lt  r \lt  1$ 时渐近稳定（此时 $x_2^*$ 无意义）；平衡点 $x_2^*$ 在 $1 \lt  r \lt  3$ 时渐近稳定（因为 $|2 - r| \lt  1$）。当 $r = 3$ 时 $f'(x_2^*) = -1$，进入临界情形，稳定性由更高阶项决定——这将引出周期倍化，是《Logistic 方程与混沌》篇的核心。

这里我们看到**同一个非线性方程，两个平衡点命运相反**：$r \in (1, 3)$ 时 $0$ 不稳定而 $x_2^*$ 稳定，种群从「灭绝」转向「存活于正水平」。**线性化判据 $|f'(x^*)|$ 比一比，稳定性立判**，全程不需要求出通解。

**数值自检**：取 $r = 2.5$，则 $x_2^* = 1 - 1/2.5 = 0.6$，$f'(0.6) = 2 - 2.5 = -0.5$，$|f'| = 0.5 \lt  1$，判为稳定。从 $x_0 = 0.2$ 迭代验证：$x_1 = 2.5 \times 0.2 \times 0.8 = 0.4$，$x_2 = 2.5 \times 0.4 \times 0.6 = 0.6$，$x_3 = 2.5 \times 0.6 \times 0.4 = 0.6$——两步后稳定在 0.6，与判据完全一致。再用 $r = 3.2$（判为 $x_2^*$ 失稳、进入 2 周期）迭代，$x$ 会在两个值间交替——判据预测的「临界点」$r = 3$ 确实是行为突变处。<span class="marginnote">$r=3$ 处 $f'=-1$ 标志着稳定的临界点：参数再增大一点，稳定平衡点让位给周期振荡——这是通往混沌之路的第一站，后文《Logistic 方程与混沌》将沿 $r$ 轴一路走到 $r=4$ 的混沌区。</span>

## 6 全局稳定性与吸引域

局部判据只回答「平衡点附近稳不稳」，不回答「从哪儿出发能到它」。**吸引域（basin of attraction）**是初值的集合——凡落在此集合内的初值，轨道最终都收敛到该平衡点。

以一维系统 $x_{n+1} = f(x_n)$ 为例。取 $f(x) = x^2$：平衡点 0 与 1 的导数分别为 $f'(0) = 0$（稳定）、$f'(1) = 2$（不稳定）。从初值 $x_0 \in (-1, 1)$ 出发，$x_n = x_0^{2^n} \to 0$，故 0 的吸引域是开区间 $(-1, 1)$；从 $x_0 > 1$ 出发则 $x_n \to +\infty$，发散；$x_0 = 1$ 停在平衡点。一个稳定、一个不稳定，两个平衡点的命运截然不同，而**吸引域的边界恰是那个不稳定的平衡点**。

**易错点｜辨析：** 吸引域边界上的点往往「既不属于这个域也不属于那个域」，且边界通常由不稳定平衡点或周期点的稳定流形构成。在多维系统里吸引域边界可以是分形（见《非线性差分方程》篇的 Smale 马蹄），「从哪出发会到哪」这个问题，往往比「稳不稳定」难得多。

**Liapunov 函数法**：局部线性化失效（临界情形）或需要全局结论时，可构造**Liapunov 函数** $V(x)$（在平衡点处取最小），验证沿轨道单调不增 $V(f(x)) \le V(x)$：若如此，轨道被「困」在 $V$ 的水平集内；若沿轨道严格递减，则收敛到平衡点。离散系统里 $V$ 常取 $|x - x^*|^p$ 或二次型 $x^T P x$。它把「证明稳定性」变成「找一个合适的势函数」，是处理非双曲平衡点与高维系统的有力工具，也是通往《动力系统》与 Lyapunov 稳定性理论的桥梁。

Liapunov 函数的选择没有通用算法，常凭物理直觉（能量、距离、方差）构造——这一面是「艺术多于技术」，但用熟了，往往是解决临界情形的最短路径。

一维稳定性判据汇总如下：

| 条件 | 结论 | 适用范围 |
| --- | --- | --- |
| $|f'(x^*)| \lt  1$ | 渐近稳定（局部） | 双曲平衡点 |
| $|f'(x^*)| > 1$ | 不稳定（局部） | 双曲平衡点 |
| $|f'(x^*)| = 1$ | 临界，须高阶项 | 非双曲，线性化失效 |
| $f$ 单调递增且轨道有界 | 全局收敛到某平衡点 | 单调映射 |
| 存在严格递减的 Liapunov 函数 | 收敛到平衡点 | 全局/高维 |

**辨析｜易错点：** 局部判据与全局判据的适用范围务必分清。工程上常见的错误是「用局部判据断言全局收敛」——只算出 $|f'(x^*)| \lt  1$ 就宣称「系统一定稳定」。严谨的说法是「在 $x^*$ 附近**局部**渐近稳定」；若要全局结论，必须补证轨道有界、单调或存在全局 Liapunov 函数等额外条件。

## 7 小结

- **平衡点**：$f(x^*) = x^*$，是离散系统的「静止点」，可与连续系统的 $f=0$ 混淆而需辨析。
- **线性化判据**：$x_{n+1} = f(x_n)$ 在平衡点附近的偏差演化 $\varepsilon_{n+1} \approx f'(x^*) \varepsilon_n$，由 $|f'(x^*)|$ 判定稳定性。
- 稳定性三定义：**Lyapunov 稳定**（不跑远）、**渐近稳定**（被吸引）、**不稳定**（被排斥）。
- **蛛网图**给出稳定性的几何直觉：曲线比直线平缓则吸、陡则甩。
- 临界情形 $|f'(x^*)| = 1$ 线性化失效，需高阶项或全局分析。

在下一节，我们把一维方程推广到多维：$k$ 阶线性差分方程可以用状态向量改写成一阶**线性差分方程组**，而那里的稳定性判据从「看一个导数 $f'(x^*)$」升级为「看整个转移矩阵的特征值谱」——一维的 $|f'(x^*)|<1$ 会变成「所有特征值的模都小于 1」，同样的直觉，更丰富的内容。
