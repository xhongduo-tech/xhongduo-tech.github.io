## 为什么等价是件大事

我们花了一整章学积分方程的理论，但一个根本问题还没正面回答：**积分方程到底从哪来？** 答案就藏在标题里——它们几乎都是从**微分方程边值问题（BVP）**和初值问题（IVP）翻译过来的。反过来，一旦理解了这层等价，你就掌握了一招「化难为易」：把微分方程的求导运算，换成积分方程的求逆积分，把局部的边值条件，换成整体的积分约束。<span class="marginnote">这层等价也是历史上积分方程理论诞生的动机：Fredholm 1903 年正是为了严格证明 Dirichlet 问题的可解性，才建立了自己的理论——势论是他的试验场，积分方程是他的武器。</span>

翻译的枢纽是 **Green 函数**：一个「点源响应」函数。它在微分方程侧扮演「基本解」，在积分方程侧扮演「核」。**任何一个线性边值问题，都能用 Green 函数改写成等价积分方程；而任何第二类积分方程，在适当条件下也能还原成某个边值问题。** 这堂课就是把这个「硬币的两面」彻底翻给读者看。

## 1 一维情形：二阶 ODE 边值问题到 Fredholm 方程

考虑最简单的二阶线性边值问题

$$y'' + q(x)\, y = f(x), \qquad y(a) = y(b) = 0$$

构造 Green 函数 $G(x,t)$：固定 $t$，它作为 $x$ 的函数满足 $G'' = \delta(x-t)$（$\delta$ 为 Dirac 函数），且在两端 $G(a,t) = G(b,t) = 0$、在 $x=t$ 处连续、导数有跳变 $G'(t^+,t) - G'(t^-,t) = 1$。**Green 函数的物理含义：在 $t$ 处放一个点源，$x$ 处测得的响应。**<span class="marginnote">$G'' = \delta(x-t)$ 的正确理解：在 $t$ 处「注入一单位跳变」——这是《常微分方程》里「齐次解拼接」思想的紧凑写法。对自伴算子，Green 函数一定对称：$G(x,t) = G(t,x)$，对应物理上的互易性（reciprocity）。</span>

用分部积分（或直接验证）得到**等价积分方程**：

$$y(x) = \int_{a}^{b} G(x,t)\, f(t)\, dt - \int_{a}^{b} G(x,t)\, q(t)\, y(t)\, dt$$

右边第二项含未知的 $y$，于是这是一个 **Fredholm 第二类积分方程**，核是 $-G(x,t)q(t)$，自由项是 $\int G(x,t)f(t)dt$。**边值条件已被 Green 函数吸收**：无论 $y$ 怎么变，只要满足积分方程，就自动满足 $y(a)=y(b)=0$——这正是积分方程「化边界条件为积分约束」的威力。

Green 函数本身有一套系统构造法，不必每次从头猜。取齐次方程 $y'' = 0$ 的两个解 $u_1 = 1$、$u_2 = x$（满足左、右边界条件的解），Green 函数可写成

$$G(x,t) = \frac{u_1(x)\, u_2(t) - u_2(x)\, u_1(t)}{W(u_1,u_2)(t)}, \qquad x \le t \text{ 或 } x \ge t \text{ 分别取用}$$

其中 $W$ 是 Wronskian。**这套「两个解拼 Green 函数」的程序在《常微分方程》里叫常数变易法**，在积分方程语境下就是「点源响应的显式构造」——它是整个等价性的引擎。

**辨析｜易错点：** Green 函数的符号约定在文献里不统一：有的对 $y''$ 取 $+1$ 跳变、有的取 $-1$。跳变方向错了，积分方程的自由项就整体差个负号，解的表达式会整体变号。写公式前先盯一眼 $G'' = \delta$ 还是 $G'' = -\delta$。

## 2 公式解析：为什么这样翻译是合法的

把等价性链条拆成四步，看每个符号的职责：

$$
y'' + qy = f \;\xrightarrow{\;G''=\delta\;}\; y = \int_a^b G(x,t)\,f(t)\,dt - \int_a^b G(x,t)\,q(t)\,y(t)\,dt
$$

- **第一步，把方程左端当作用 $L = d^2/dx^2 + q$ 作用在 $y$ 上**：$Ly = f$。Green 函数是 $L$ 的「右逆」：$L_x G(x,t) = \delta(x-t)$，即「$G$ 把点源送回自身」。
- **第二步，两边乘 $G$ 并积分**：由 $\int_a^b G(x,t)\, Ly(t)\,dt$ 分部积分两次，边界项因 $G(a,t)=G(b,t)=0$ 消失，得到 $y(x) = \int_a^b G(x,t)f(t)dt$——这是对**齐次方程右端无 $q$ 的情形**（$q=0$）。
- **第三步，把 $qy$ 挪到右端当「源」**：$y'' = f - qy$，把 $-qy$ 和 $f$ 一并当源项，再次用 Green 函数积分，得 $y = \int G(f - qy)$——**未知量 $y$ 出现在积分号内，积分方程诞生**。
- **第四步，确认类型**：$y$ 在积分内以「$G(x,t)q(t)y(t)$」出现一次，积分号外没有单独的 $y$ 项（第一类？不——注意 $y(x)$ 在左边），实际上整理成 $y + \int G q\, y = \int G f$，是标准第二类 Fredholm 方程，$\lambda$ 已并入核。**「微分算子 + 边界条件」整体被替换成「Green 函数核」，正是这步操作。**

## 3 高维情形：Dirichlet 问题与层势

一维的图景在高维被放得更大。考虑调和函数 $u$ 在区域 $\Omega$ 内的 **Dirichlet 问题**：$\Delta u = 0$，$u|_{\partial\Omega} = g$。Green 表示公式给出

$$u(x) = \int_{\partial\Omega} \left[ G(x,y)\, \frac{\partial u}{\partial n}(y) - u(y)\, \frac{\partial G}{\partial n}(x,y) \right]\, dS_y$$

$x$ 在 $\Omega$ 内时 $u$ 由边界上的 $u$ 与法向导数共同决定。<span class="marginnote">把 $x$ 推向边界 $\partial\Omega$ 时，积分出现奇点——这正是上一课 Cauchy 主值登场的地方：边界积分方程天然是<strong>奇异积分方程</strong>，于是 §8 的整套工具（Plemelj 公式、指标）在这里找到用武之地。</span>

若用**单层势** $u(x) = \int_{\partial\Omega} \rho(y)\, |x-y|^{-1}\, dS_y$ 或**双层势** $u(x) = \int_{\partial\Omega} \rho(y)\, \partial_n |x-y|^{-1}\, dS_y$ 表示解，把 $x$ 推向边界，Dirichlet/Neumann 问题就化成边界上的积分方程——**区域降维成边界**，这是「边界元方法（BEM）」的全部数学根基。

写成算子的样子更清楚。设 $S$ 是单层势算子、$K$ 是双层势算子，Dirichlet 问题化为

$$\frac12\, \rho(x) + \int_{\partial\Omega} K(x,y)\, \rho(y)\, dS_y = g(x), \qquad x \in \partial\Omega$$

系数 $1/2$ 来自双层势跨过边界时「跳跃取半」——这正是上一课 Plemelj 公式 $\Phi^+ - \Phi^- = f$ 在几何边界上的化身。<span class="marginnote">$1/2$ 这一项让边界方程从「第一类」升格为「第二类」：它保证了算子 $I/2 + K$ 的良态性，也使数值离散后矩阵条件数温和。边界元法偏爱第二类边界方程，原因正在此。</span>

**辨析｜易错点：** 单层势跨过边界是**连续**的（法向导数有跳变），双层势跨过边界是**跳变**的（函数本身有跳变）。这两条互补的跳变关系（正是 Plemelj 公式的几何版）决定了该用哪种势去配 Dirichlet 还是 Neumann 条件。用错势、配错边值，是边界元建模最常见的错误。

## 4 为什么翻译值得：三个好处

把 BVP 换成积分方程，不是换汤不换药，而是有实打实的好处：

**好处一：降维。** 高维 PDE 变成低维边界积分方程，网格只需剖分边界而非整个区域——边界元方法因此成为大尺度工程问题（声学、电磁、弹性）的首选之一。

**好处二：良态。** 积分算子比微分算子「光滑」，是**紧算子**；紧算子加恒等算子的可逆性由 Fredholm 理论把握，数值上离散出来的矩阵也远比微分算子离散矩阵病态程度低。<span class="marginnote">微分算子高频放大（特征值 $\propto n^2$），积分算子高频压制（特征值 $\to 0$）。离散化后，前者产生条件数爆炸的稠密矩阵，后者产生条件数温和的矩阵——「积分方程比微分方程好算」这句工程谚语，根源在此。</span>

**好处三：边界条件自动满足。** Green 函数与层势的构造已经内置了边界条件，积分方程里没有「边界条件」这个额外行李——实现与理论都更干净。

**数值上的连锁反应**：因为积分方程「良态」，离散后的线性方程组往往规模小、迭代快；又因为边界元只剖边界，三维问题只需二维网格。这两条叠加，使「先化成积分方程、再数值求解」成为声学与电磁学大规模仿真的事实标准——下一节的 Nyström 法与配置法，正是这套流程的两种具体实施。

**反方向的等价也成立**：任何第二类 Volterra 方程（核足够光滑）都能求导还原成 IVP，任何 Fredholm 方程在核可微时也能还原成 ODE BVP。**「等价」是双向的**，这解释了为什么微分方程与积分方程的理论总在互相借力。

## 5 例：手算 Green 函数并写出等价方程

把整套翻译在 $[0,1]$ 上完整跑一遍。取方程 $y'' + q(x)y = f(x)$，$y(0) = y(1) = 0$。

**第一步，解出 Green 函数**。对 $L = d^2/dx^2$ 与零边界条件，Green 函数分两段：

$$G(x,t) = \begin{cases} x\,(t-1), & 0 \le x \le t \\ t\,(x-1), & t \le x \le 1 \end{cases}$$

验证三条规矩：$x=0$ 时 $G = 0\cdot(t-1) = 0$ ✓；$x=1$ 时 $G = t(1-1) = 0$ ✓；$x=t$ 处两段都给 $t(t-1)$，连续 ✓；导数跳变 $G_x(t^+) - G_x(t^-) = t - (t-1) = 1$ ✓。

**第二步，套等价公式**：

$$y(x) = \int_0^1 G(x,t)\, f(t)\, dt - \int_0^1 G(x,t)\, q(t)\, y(t)\, dt$$

**第三步，验证边界条件已内建**：取 $x=0$，两段积分里 $G(0,t) = 0\cdot(t-1) = 0$，故 $y(0) = 0$，无需另行强加；$x=1$ 同理。**边界条件被 Green 函数吞掉**，这正是「等价」最实用的一面。

**第四步，看核的对称性**：$G(x,t) = G(t,x)$（把两段的表达式对换即见），印证「自伴算子 Green 函数对称」的一般结论。若 $q$ 是常数，核 $-G(x,t)q$ 也是对称的，方程就落在上一课 Hilbert–Schmidt 理论的可展开范围内。

这个例子虽小，却示范了完整的等价流程：**BVP → 拼 Green 函数 → 写积分方程 → 检验对称性与边界条件内建**。把 $[0,1]$ 换成任意区间、$q$ 换成任意连续函数，程序一字不改；换成高维区域，程序的核心思路（Green 函数 / 层势 + 边界积分方程）也一字不改。

## 6 小结

- 线性边值问题可用 **Green 函数**改写成等价积分方程：$y = \int Gf - \int Gqy$，边界条件被积分自动吸收。
- Green 函数是「点源响应」，对自伴算子**对称**；导数跳变条件 $G'(t^+) - G'(t^-) = 1$ 编码了 Dirac 源。
- 高维 Dirichlet/Neumann 问题通过**单层/双层势**化为边界积分方程，天然是奇异积分方程。
- 翻译的三个好处：**降维**、**良态**（紧算子）、**边界条件内建**。
- 等价是双向的：第二类积分方程也可还原为边值/初值问题。
- Green 函数可由「两个齐次解 + Wronskian」系统构造，是等价性的引擎。
- 单层势跨界连续、双层势跨界跳变，$1/2$
