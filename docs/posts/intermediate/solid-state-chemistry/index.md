# 固体化学

固体化学研究无机固体的晶体结构、化学键与缺陷化学，以及这些微观因素如何决定材料在电、磁、光学上的宏观性质与功能，是连接化学与材料科学的基础分支。从钙钛矿、固体电解质到高温超导与功能陶瓷，它揭示了结构与性能之间的内在联系，是理解并设计新型功能材料的核心学科。

## 对标教材

- Anthony R. West, "Solid State Chemistry and Its Applications" (2nd ed., Wiley)
- Lesley E. Smart, Elaine A. Moore, "Solid State Chemistry: An Introduction" (4th ed., CRC Press)
