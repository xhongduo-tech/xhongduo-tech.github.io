## 为什么从固相相变开始

晶体的结构不是一成不变的。温度升高、压力增
大、电场施加，都可能触发晶体从一种结构变成
另一种结构——这就是**固相相变**。它既
是材料应用的开关（铁电、压电、形状记忆全靠
相变工作），也是相图在动态维度的延伸。相变
按「原子怎么动」分成两大类：**重构性**
相变要拆旧键、建新键，慢而猛烈；**位移性
**相变只让原子轻挪位置，快而可逆。这一节
把两类相变讲透，并以 BaTiO₃ 的铁电
相变与石英的多种相变为实例。

## 1 两类相变：拆了重砌，还是轻轻挪步

**重构性相变（reconstructiv
etransition）**：相变过程中大
量化学键被破坏、重新形成，原子从一种配位环
境整体搬到另一种。因为要打破强键，它通常**
活化能高、速度慢、滞后明显（热滞 hyst
eresis）**，而且往往**不可逆或极
难可逆**。

**位移性相变（displacive tr
ansition）**：原子只发生微小位移
（几分之一 Å），配位与键合方式基本不变，
只是对称性降低。它**活化能低、速度快、可
逆性好**，相变温度附近常伴随明显的物性突
变（如介电常数峰）。<span class="marginnote">
记忆锚点：<strong>重构性 = 拆房
子重盖（键断了，慢）；位移性 = 家具挪位
（键没断，快）。</strong>因此重构
性相变在冷却时会「回不去」或严重滞后，位移
性相变则几乎紧跟温度即时响应。</span>

| 对比项 | 重构性 | 位移性 |
| --- | --- | --- |
| 键的变化 | 断键重建 | 键基本保持 |
| 原子位移 | 大，重新配位 | 小，微调位置 |
| 活化能 / 速率 | 高 / 慢 | 低 / 快 |
| 滞后 | 明显热滞 | 几乎无滞后 |
| 可逆性 | 差 | 好 |
| 实例 | 石墨→金刚石、石英→方石英 | BaTiO₃ 立方→四方、SrTiO₃ 倾转 |

## 2 位移性相变：BaTiO₃ 的铁电相变

钙钛矿 BaTiO₃ 是位移性相变最经典的
舞台。它随温度经历多次相变，每次都是八面体
框架的「轻挪」：

- 高温立方相（$>120$ °C）：Ti⁴⁺ 位于 O₆ 八面体正中心，正负电荷中心重合，无净极化。
- 120 °C 以下：Ti⁴⁺ 沿 c 轴**偏移约 0.1 Å**，正负电荷中心错开，晶体出现自发极化——这就是**铁电相变**，对称性从立方降到四方。

**软模（soft mode）**是位移性
相变的微观图像：晶体里某些晶格振动模式（声
子）的恢复力随温度趋近相变点而**软化**
（频率趋近零）。当频率降到零，该振动模式的
位移「冻结」成静态结构畸变——原子被钉在新
位置上，相变完成。软模频率与温度的关系近似
为：

$$\omega^2 \propto (T - T_c)$$

- $T_c$：相变温度。当 $T\to T_c^+$，$\omega\to0$，振动模式「软掉」，位移性相变爆发。
- 物理图像：温度降低，原子间的有效恢复力减弱；到临界点恢复力归零，旧结构失去稳定性，原子顺势滑向新结构。<span class="marginnote">软模是「失稳驱动的相变」：不是新结构「拉」原子过去，而是旧结构的某个振动<strong>失去刚度</strong>，原子被放行。<strong>位移性相变的本质 = 结构失稳，而非能量竞争</strong>——这个视角对整个相变物理都极其深刻。</span>

**辨析｜易错点：** BaTiO₃ 在 
120 °C 的相变不是「原子重新配位」，
Ti只挪了 0.1 Å。但这么小的位移却带
来巨大的物理后果——自发极化、介电常数峰值
、铁电性。**位移性相变「位移小」不等于「
影响小」**：对称性一降，整个宏观性质谱系
都被改写。

## 3 重构性相变：石墨与石英的「涅槃」

**石墨 → 金刚石**是重构性相变的首席
案例：石墨层内是 $sp^2$、层间是范德
华力，金刚石是纯 $sp^3$ 三维网络。
从石墨变金刚石，每个碳都要从平面三角配位改
造成四面体配位，**所有层间弱键与大量面内
键被重建**——这就是为什么它在常压下几乎
不发生（金刚石是亚稳态），必须靠高温高压（
约 5 GPa、1500 °C）或催化剂才
能实现。<span class="marginnote">
顺带一个反直觉的事实：金刚石在热力学上比亚
稳态石墨「更不稳定」，室温常压下它其实该变
成石墨，只是重构能垒高到「永远过不去」。<strong>
你手上的钻石，是一块被动力学冻住的亚稳晶体
。</strong></span>

**石英（quartz）的多形转变**展示
了重构与位移的「混合剧目」：α-石英 ↔ 
β-石英 是位移性相变（SiO₄ 四面体倾
转，573 °C，快而可逆，无滞后）；而 
β-石英→ 鳞石英 → 方石英则是重构性相
变（Si–O 键要断开重组，缓慢、有滞后，
伴随明显的体积变化）。

重构性相变的体积突变让它成为工程难题：陶瓷
烧成后的冷却过程若经过重构性相变，体积骤变
会引发开裂——**配方的设计常常要绕着相变
温度走**。<span class="marginnote">
这一条直接连回工业：耐火砖的「抗热震性」差
，往往就是因为成分里某个物相在服役温度附近
发生重构性相变、体积剧变。相图与相变知识，
是陶瓷工程师的生存手册。</span>

## 4 相变与对称性：一个统一视角

两类相变可以用**对称性**的语言统一起来
：

**位移性相变**是**对称性降低**：高温相具有较高对称性（如立方），低温相是它的一个子群（如四方）。对称群之间存在包含关系，相变可以连续进行，遵循 Landau 理论的有序参量描述。
**重构性相变**的对称性关系更复杂：两相之间可能不存在简单的群包含关系，需要「越过山丘」——这也是它动力学缓慢、滞后严重的群论根源。<span class="marginnote">用群论的语言：位移性相变是「降群」$G\to H\subset G$，重构性相变则跳出了包含链。Landau 判据甚至能预测哪些位移性相变可以是一级、哪些是二级——对称性把「会不会相变」「怎么相变」都管了起来。</span>

**辨析｜易错点：** 相变的「可逆」与「
可连续」不是一回事。位移性相变通常连续可逆
，但**一级位移性相变（如 BaTiO₃ 
的某些转变）仍伴随潜热与两相共存**——「
位移性」描述原子运动方式，「一级/二级」描
述热力学行为，两者是正交的分类轴，不可混用
。

## 5 小结

- **重构性相变**：断键重建、慢、滞后大、可逆性差（石墨→金刚石、石英→方石英）。
- **位移性相变**：原子微移、快、可逆、几乎无滞后（BaTiO₃ 铁电相变、α↔β 石英）。
- **软模机制**：$\omega^2\propto(T-T_c)$
