## 为什么从非化学计量化合物开始

「定比定律」说化合物里元素以固定比例结合—
—可固体化学很快撞见反例：方铁矿写成 Fe
O，实际成分却是 Fe₀.₉₅O；二氧化钛
写成TiO₂，还原后变成 TiO₁.₉₅。
**非化学计量（nonstoichiome
try）**是过渡金属氧化物的常态，而不是
例外。它的本质是「缺陷浓度高到成分都变了」
，而这些「缺出来的比例」直接决定材料是 n
 型还是 p型半导体、是白是蓝是黑、能不能
当氧传感器。这一节以 Fe₁₋ₓO 与 T
iO₂₋ₓ 两个主角，看懂非化学计量如何用
缺陷化学的语言被精确刻画。

## 1 非化学计量：成分不再是「定比」

**非化学计量化合物（nonstoichi
ometric compound）**：实
际组成与理想化学式存在可测量偏差的化合物，
写成如Fe₁₋ₓO、TiO₂₋ₓ、UO₂₊
ₓ。它仍是单一物相（单相区），只是成分在相
图上有一定宽度。

偏差的方向有两种，分别对应两种缺陷类型：

- **金属不足 / 氧过量（cation-deficient）**：阳离子空位占主导，如 Fe₁₋ₓO（$V_{Fe}$）。缺金属意味着「少了带正电的离子」，为电荷平衡会伴生高价阳离子或空穴——典型 **p 型**半导体。
- **氧不足 / 金属过量（anion-deficient）**：阴离子空位占主导，如 TiO₂₋ₓ（$V_O$）。缺氧释放电子到晶格——典型 **n 型**半导体。<span class="marginnote">记忆锚点：<strong>缺金属 → p 型（空穴）；缺氧 → n 型（电子）。</strong>为什么？缺一个金属离子（如 Fe²⁺ 缺失），电荷不平衡就得让某个 Fe 升到 Fe³⁺——三价铁等价于「一个空穴」；缺一个 O²⁻ 则多出两个电子进导带。非化学计量的类型直接标定了半导体类型。</span>

**辨析｜易错点：** 非化学计量不是「杂
质的功劳」，也不是「配比不准的失误」。它是
**热力学平衡**的结果：成分可以在相图单
相区内连续变化（如 FeO 在约 900 
°C 以上的成分范围为 Fe₀.₉₅O 到
 Fe₀.₈₈O），偏差大小由温度与氧分压
控制。把 FeO 的 x 值调到不同数值，
材料性质就跟着变——这是「成分工程」的原始
形态。

## 2 Fe₁₋ₓO：铁空位当家

方铁矿（wüstite）Fe₁₋ₓO 是阳
离子不足的标本：在约 570 °C 以上才
稳定，且 x 可达 0.05–0.12——
每十个铁位就空一个以上，是缺陷浓度最高的典
型氧化物之一。用 Kröger–Vink 
语言，铁空位 $V_{Fe}''$（带 −
2 有效电荷）靠两个 Fe³⁺ 的 +1 
有效电荷补偿：

$$0 \rightleftharpoons V_{Fe}'' + 2Fe_{Fe}^{\bullet} + O_{O}^{\times}$$

**电荷守恒**：$V_{Fe}''$ 的
−2 由两个 $Fe_{Fe}^{\bullet}$
（Fe³⁺ 替换 Fe²⁺，各带 +1）平
衡。这条反应同时解释了三个事实：为什么 F
e₁₋ₓO 一定含 Fe³⁺、为什么它是 
p 型半导体（$Fe_{Fe}^{\bullet}$
可视为局域空穴）、为什么成分 x 越大电导
越偏空穴型。<span class="marginnote">
实际方铁矿的缺陷比这更热闹：高浓度铁空位会
「抱团」成缺陷簇，比如 4:1 簇（4 个
空位+ 1 个间隙 Fe³⁺）。<strong>
缺陷浓度高到一定程度，缺陷之间开始相互作用
、有序化——这正是后面《固相相变》里「缺陷
有序」的伏笔。</strong></span>

**Fe₁₋ₓO 的用途与困境**：它在铁
锈（腐蚀层）中扮演中间相，也是炼钢「脱氧」
的媒介。但正因为缺陷多，它极难做成纯化学计
量的FeO——把 x 压到零几乎不可能，这
是「非化学计量是热力学必然」的又一例证。

## 3 TiO₂₋ₓ：氧空位当家

二氧化钛是 n 型非化学计量的代表。纯化学
计量的 TiO₂ 是宽带隙（约 3.2 e
V）绝缘体、白色颜料（钛白粉）；一旦在还原
气氛（缺氧）下加热，氧原子离开晶格留下 $V_O^{\bullet\bullet}$
：

$$O_{O}^{\times} \rightleftharpoons V_{O}^{\bullet\bullet} + 2e' + \frac{1}{2}O_2$$

**氧空位释放的两个电子进导带**——这就
是TiO₂₋ₓ 成为 n 型半导体的机理。
化学计量的白色 TiO₂ 与还原后的灰色/
蓝色TiO₂₋ₓ，成分只差几个 ppm 的
氧，颜色与导电性却天差地别。<span class="marginnote">
TiO₂₋ₓ 的颜色变化是缺陷化学的「可视
化教材」：白色（化学计量）→ 灰色 → 蓝
色→ 黑色（深度还原）。每加深一档，就是氧
空位浓度抬高一个数量级。<strong>一
块氧化物的颜色，常常就是它的缺陷浓度计。</strong>
</span>

**Magnéli 相**是 TiO₂₋ₓ
家族的另一面：当氧空位浓度高到一定程度，空
位不再随机分布，而是沿一定晶面规则排列，形
成**剪切结构（crystallograp
hicshear plane）**，化学成
分呈TiO₂、Ti₄O₇、Ti₅O₉…… 
一系列离散的中间相。**缺陷从「点」发展为
「面」**，是氧空位「有序化」的极端形态—
—它告诉我们，非化学计量并非总能写成一个连
续可变的 x，有时会「量子化」成一组确定成
分的亚相。

## 4 核心对比：两种非化学计量

本主题以缺陷化学概念为主，核心对比表如下（
纯概念主题，以对比表替代公式解析）：

| 对比项 | Fe₁₋ₓO（阳离子不足） | TiO₂₋ₓ（阴离子不足） |
| --- | --- | --- |
| 主导缺陷 | $V_{Fe}''$（铁空位） | $V_{O}^{\bullet\bullet}$（氧空位） |
| 电荷补偿 | $2Fe_{Fe}^{\bullet}$（Fe³⁺） | $2e'$（导带电子） |
| 半导体类型 | p 型（空穴主导） | n 型（电子主导） |
| 成分偏差方向 | 金属减少（x>0） | 氧减少（x>0） |
| 极端形态 | 缺陷簇（4:1 簇） | Magnéli 剪切相 |
| 典型现象 | 铁锈层、炼钢 | 钛白粉变色、氧传感器 |

**辨析｜易错点：** 非化学计量化合物的
「偏差方向」决定「电学类型」，但方向不是由
元素种类决定，而是由**缺陷形成能**决定
——FeO 形成铁空位更便宜，TiO₂ 形
成氧空位更便宜。**不能凭「过渡金属氧化物
就怎么怎么样」一概而论**，每个体系要单独
查它的缺陷形成能排序。

## 5 小结

- **非化学计量**是成分在单相区内的连续偏差，热力学平衡所致，非配比失误。
