# 二元相图基础：共晶、包晶与固溶体

## 为什么从二元相图开始

前面十二节我们都在问「给定成分，原子怎么排
」。现在要问一个更实际的问题：**把 A 
和B 按不同比例混合、加热到不同温度，体系
会变成什么？**——是两种固体的混合物，还
是均匀的固溶体，还是液体？答案全部画在一张
**二元相图**上。相图是材料科学的「地图
」：烧结温度怎么选、陶瓷会不会偏析、金属的
显微组织长什么样，都能从相图上直接读出。这
一节我们掌握相图的三把钥匙——相律、杠杆规
则、以及共晶与包晶两大不变反应。

## 1 相图的基本语言：相、组分与自由度

**相（phase）**：体系中物理与化学
性质均匀的部分。水和冰是两相，不同晶型的两
种晶体也是两相。**相图（phase di
agram）**：以温度为纵轴、成分为横轴
，标出平衡状态下各成分在各温度出现哪些相的
图。

**吉布斯相律（Gibbs phase r
ule）**给出体系的自由度——可以独立改
变而不改变相数的变量个数：

$$F = C - P + 2$$

- $C$：组分数（二元体系为 2）。
- $P$：共存相数。
- $2$：温度和压力两个外界变量；对凝聚态体系常固定压力，退化为 $F = C - P + 1$。

**直觉**：相越多，自由度越少。二元体系
里，单相区 $F=2$（温度和成分都能变）
，两相区 $F=1$（温度定了，各相成分就
定了），三相共存时 $F=0$——**三相
只能在一个固定的温度、一个固定的成分点共存
**，这个点就是共晶点或包晶点。<span class="marginnote">
相律是相图的「语法检查器」：任何一张正确的
二元相图上，三相水平线两端的区域必然都是两
相区，绝不会出现「水平线连着单相区」的非法
结构——用相律可以快速检验一张相图画得对不
对。</span>

## 2 固溶体：你中有我的单相

**固溶体（solid solution）
**：一种组分（溶质）均匀溶解在另一种晶体
（溶剂）的晶格里，仍保持单一晶体结构的相。
按溶质占位方式分两类：

**置换固溶体（substitutional）**：溶质原子顶替溶剂原子坐进晶格位点，如 Cu–Ni（两者同为 fcc、半径相近，可无限互溶）。
**间隙固溶体（interstitial）**：溶质原子钻进晶格空隙，如碳溶入铁——碳原子小于铁原子，坐进八面体空隙，形成奥氏体/铁素体。

**Hume–Rothery 规则**概括
了能否形成连续固溶体的经验判据：**半径差
 < 15%、电负性相近、晶型相同、价态相近**，满足得越多，越容易无限互溶。半径差超 15% 时溶解度急剧下降。<span class="marginnote">
Hume–Rothery 规则是「化学直觉
」的结晶：<strong>原子想进别人的晶
格，必须先「长得像」被替换的原子。</strong>
这套规则在合金设计里用了一百年，至今仍是第
一道筛选。</span>

在二元相图上，固溶体表现为一个单相区。它的
边界线叫**液相线（liquidus）**
与**固相线（solidus）**：液相线
之上全熔，固相线之下全凝，两线之间是液固两
相共存区。

## 3 共晶反应：两相同时析出

**共晶（eutectic）**是二元体系
最重要的不变反应：液相冷却到共晶温度 $T_E$
时，**同时析出两种固相**：

$$\text{液体 } L_E \;\xrightarrow{\text{冷却}}\; \alpha + \beta$$

共晶点是三相（$L,\alpha,\beta$
）共存的零自由度点：温度和成分都被唯一固定
。共晶组分的显微组织极具辨识度——α 与 
β交替排列成层状（lamellar）或棒状
结构，因为两种固相必须从液体里「肩并肩」同
时长大、互相让位。<span class="marginnote">
为什么共晶成分好焊、好铸？因为共晶在<strong>
最低温度</strong>熔化——共晶点恰
好是液相线的最低点。焊锡（Pb–Sn 共晶
约183 °C）与灰铸铁都利用了这一特性：
低熔点 + 精细的共晶组织。</span>

**杠杆规则（lever rule）**用
来定量两相区中各相的相对量。设合金整体成分
为$X_0$，α 相成分为 $X_\alpha$
、β 相成分为 $X_\beta$，则：

$$\frac{w_\alpha}{w_\beta} = \frac{X_\beta - X_0}{X_0 - X_\alpha}$$

**直觉**：整体成分点像一个支点，它到两
相成分点的「距离」与两相的量成反比——离哪
一相的成分点近，那一相就多。这条规则在相图
上任何两相区都成立，是「从相图读含量」的标
准工具。<span class="marginnote">
杠杆规则的图像就是「力矩平衡」：把成分轴当
杠杆，整体成分 $X_0$ 是支点，两相成
分$X_\alpha,X_\beta$ 是
两端砝码。<strong>支点偏向哪端，哪
端量越少——与「距离反比」完全一致。</strong>
记住图，就记住了公式。</span>

## 4 包晶反应：旧相溶解，新相生成

**包晶（peritectic）**是另一
类不变反应：已析出的固相 α 与剩余液体反
应，生成新的固相 β：

$$\alpha + L \;\xrightarrow{\text{冷却}}\; \beta$$

包晶反应中，新相 β 在 α 颗粒表面「包
裹」生长，把 α 与液体隔开，反应要靠扩散
穿过β 壳才能继续——因此**包晶反应常常
进行不完全**，冷却稍快就会在产物里残留未
反应的α 核。包晶组织多为「核–壳」结构，
与共晶的层状结构截然不同。<span class="marginnote">
包晶体系的代表有 Fe–C（奥氏体包晶转变
）、Cu–Sn（青铜）与许多陶瓷体系。工业
上常刻意利用包晶反应不完全：把部分 α 保
留在核心，得到「芯+壳」复合颗粒，改善性能
。</span>

**辨析｜易错点：** 共晶与包晶「长得像
」，但方向相反：共晶是**液体分解为两个固
相**（$L\to\alpha+\beta$
），包晶是**固液反应生成一个新固相**（
$\alpha+L\to\beta$）。判
断一张相图的不变点是共晶还是包晶，就看水平
线下方——共晶的线下方连接两个固相区，包晶
的线下方连接一个固相区与一个液相区。

## 5 小结

- **相律** $F=C-P+2$ 约束相图结构：二元三相共存点必为固定温度与成分（共晶/包晶点）。
- **固溶体**分置换与间隙两类；Hume–Rothery 规则（半径差 <15% 等）判据可预测能否连续互溶。
- **共晶** $L\to\alpha+\beta$：液相在最低温度同时析出两相，组织为层状；**包晶** $\alpha+L\to\beta$：新相包裹旧相、常不完全。
- **杠杆规则** $\frac{w_\alpha}{w_\beta}=\frac{X_\beta-X_0}{X_0-X_\alpha}$
