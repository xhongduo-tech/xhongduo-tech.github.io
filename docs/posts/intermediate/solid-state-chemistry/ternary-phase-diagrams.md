## 为什么从三元相图开始

二元相图已经能描述「A–B 两组分」的全景，但真实陶瓷与合金几乎没有纯二元的：砖瓦是 CaO–Al₂O₃–SiO₂，耐火材料是 MgO–Al₂O₃–SiO₂，水泥是 CaO–Al₂O₃–Fe₂O₃–SiO₂。

要真正设计一种工业材料，必须会读**三元相图**。三元相图增加了一个组分，自由度随之增加，图像从「一条线」变成「一个三角形」。

这一节我们建立三元相图的读图语言：等边三角形成分坐标、等温截面、以及由结线三角形控制的相关系。它是上一节二元相图的自然延伸，也是后面「缺陷与非化学计量」讨论里「成分—相」思维的再深化。

从课程体系看，相图是「成分 → 相 → 性质」链条的第一环：它不关心原子怎么排列，只回答「什么成分在什么温度变成什么相」。**读懂相图，是把热力学落到陶瓷与合金配方的通用语言**——无论去耐火材料厂还是电池材料实验室，这张三角形都会反复出现。

## 1 等边三角形：三个组分怎么画进一个平面

**三元相图（ternary phase diagram）**用等边三角形的内部点表示三种组分 A、B、C 的成分。三角形的三个顶点分别代表 100% 的 A、B、C；三条边代表三个二元体系（A–B、B–C、C–A）；内部任意一点代表 A+B+C 的某种配比。

读成分用「平行线法」：过三角形内一点 $P$ 作三条分别平行于三条边的直线，三条直线在三条边上截出的三段长度（按比例换算）就是 A、B、C 的百分含量。三者的和恒为 100%，因此**任意点只有两个独立成分变量**——等边三角形用两个维度恰好装下了两个自由度。<span class="marginnote">为什么用等边三角形？因为等边三角形的「任意点到三边距离之和为常数」（重心性质）。<strong>把距离换成百分比，三个含量就自动满足「和 = 100%」</strong>——几何性质直接编码了质量守恒。</span>

**一个读数例子**：设点 $P$ 距 A 边 10 格、距 B 边 30 格、距 C 边 60 格，则 $P$ 的成分为 A = 10%、B = 30%、C = 60%。**离哪个顶点近，那个组分就多**——读三元成分，永远记住「距离反比于含量」这条铁律。

成分背后还压着一条**吉布斯相律**：$F = C - P + 2$。对三元系（$C=3$），两相共存时 $F = 3$，恒压等温下还剩 2 个自由度；三相共存 $F=2$，恒压等温下自由度归零——**这正是「三相区」在等温截面上必须是三角形的几何原因**：三个相共存时，成分被「钉」在三个固定点上。

**辨析｜易错点：** 三元相图里「纯组分」「二元边」「三元内部」是三套不同的语言。顶点是单相（$F=2$），边上是二元体系（按二元相图读），内部才是真正的三元问题。初学者最常犯的错，是把「三角形边上的点」当成「内部点」来读成分——边上任何点都至少缺一个组分。

**一组真实的成分点**帮你建立直觉：水泥 CaO–SiO₂–Al₂O₃ 生料大致落在 CaO 角附近；玻璃（钠钙硅）靠近 SiO₂ 角；镁铝尖晶石耐火材料靠近 MgO–Al₂O₃ 边。**每一个「角」和「边」都对应一类工业材料**——读三元相图，本质是给每一类材料在三角形里找到「坐标」。

## 2 等温截面：把温度「切片」来看

三元相图是三维的：温度是第三维（垂直于成分三角形的轴）。完整的三元相图是一个三维棱柱，直接读很吃力，因此实际分析常用**等温截面（isothermal section）**——固定某个温度，切出一个水平薄片，得到一张「该温度下的成分–相图」。

等温截面的另一个常见伴侣是**液相面（liquidus surface）**：把棱柱顶部「液相存在的最高温度」投影回三角形平面，画出等温线（类似地形图的等高线）。**液相面越高，材料越难熔化**——耐火材料选材，正是看成分点在液相面上的「海拔」。

- **单相区**：只有一种相稳定，面积最大。
- **两相区**：两个相共存。区内任一点，两相的成分由一条**结线（tie-line）**连接，结线的两个端点落在两侧单相区边界上——**用杠杆规则可以读出两相的相对量**（杠杆规则对三元结线完全成立）。<span class="marginnote">结线是三元素相分析的核心工具：它告诉你「这个成分点在这个温度下由哪两个相组成、各占多少」。<strong>等温截面上的结线方向随温度转动</strong>，因此不同温度的截面，结线的指向不同——比较几个温度的截面，就能追踪相的生成与消失。</span>
- **三相区**：三个相共存，是一个**结线三角形（compatibility triangle）**。区内任一点，三个顶点的相成分固定、相对量由重心规则确定：把该点看作三角形的重心，三个顶点「分得」的面积与对应相的量成正比。<span class="marginnote">重心规则是杠杆规则的三维推广：<strong>点在三角形里离哪个顶点越远，那个顶点相的量越少</strong>——与「杠杆的支点偏向决定分配」同出一源。三相共存时自由度只剩 0（等温截面内温度已固定），所以成分不能自由移动。</span>

**辨析｜易错点：** 等温截面是「切片」，不是「投影」。切片只反映**该温度下的平衡相**；降温后相组成会变，不能把不同温度的截面直接叠加读。**要追踪温度演变，必须读一系列截面或完整的立体图**，单张截面只是瞬间快照。

## 3 相关系：三角形告诉你「哪些相能共存」

**相关系（phase relations）**研究的是：哪些相在平衡时可以共存、哪些相注定不能同时出现。这个信息在等温截面上浓缩为结线三角形的划分方式：

- 截面上划出若干**结线三角形**，每个三角形的三个顶点是三个共存的相。
- 相邻三角形共享一条结线（两个相）；三个相如果能连成一个三角形，它们就「兼容」，否则不兼容。
- **不兼容的相组合**在平衡状态下不可能同时存在——当体系成分落在某个三角形内，实际存在的相就是该三角形的三个顶点相，其他「中间相」会被消耗掉。<span class="marginnote">这一条对陶瓷生产极其重要：烧结三组分体系时，<strong>产物到底是哪几个相，不看原料种类，只看原料成分落在哪个结线三角形里</strong>。成分一经确定，「该有的相」就被三角形的拓扑关系钉死了。</span>

**相容与不相容的例子**：在 CaO–Al₂O₃–SiO₂ 三元系中，CaO 与 SiO₂ 在高温会先反应生成 Ca₂SiO₄ 等中间相，而不是直接得到某种「自由硅」——成分落在不同子三角形，终产物组合就不同。水泥熟料中 Ca₃SiO₅（C₃S）的生成路径，本质上就是成分点在结线三角形间的移动史。

**杠杆规则在三角形里照样用**：两点成分给定后，混合物的成分点一定落在线段上，且**混合物点越靠近哪一相，那一相占的比例越大**——支点距离成反比。这条「线段定成分、距离定比例」的几何法则，是两相区与三相区读量的公共基础，贯穿相图的全部定量分析。

## 4 核心对比：二元与三元相图

本主题以读图方法为主，核心对比表如下（纯概念主题，以对比表替代公式解析）：

| 对比项 | 二元相图 | 三元相图 |
| --- | --- | --- |
| 成分坐标 | 一条线段（1 个变量） | 等边三角形（2 个变量） |
| 完整图像 | 平面（T–成分） | 三维棱柱（T–三角形） |
| 两相区工具 | 杠杆规则 | 结线 + 杠杆规则 |
| 三相共存 | 不变点（共晶/包晶） | 结线三角形（区域而非点） |
| 不变反应 | 三相点 | 四相点（如三元共晶） |
| 常用读法 | 整张图直接读 | 等温截面逐层切片 |

**直觉**：三元相图把二元里的「三相点」升级为「三相区」，把自由度再压一级——三元不变反应（如三元共晶 $L \to \alpha + \beta + \gamma$）是四个相在固定温度同时共存，自由度降至零，在图上表现为一个点。<span class="marginnote">三元体系的「四相不变点」比二元的「三相点」多出一大堆花样：<strong>三元共晶、三元包晶、共晶–包晶复合</strong>——每一类都有自己特有的「成分路径」。读图的核心不是背类型，而是会数自由度。</span>

还有一点要提前打预防针：真实相图常标注**固溶体范围**而不是「纯相点」——三组分常互相溶解，形成成分可变的固溶体（如镁铝尖晶石可偏离化学计量）。**「相」不是「纯物相」，「固溶区」才是常态**——这正是下一节「非化学计量化合物」的伏笔。

合金里的三元相图同样关键：不锈钢、高温合金、焊料的性能都由成分点在三元系里的位置与凝固路径决定——**读三元相图，是金属材料工程师与陶瓷工程师共享的第一门课**。

## 5 结晶路径：冷却时成分怎么移动

等温截面是「快照」，结晶路径则是「电影」。从液相冷却析晶时，液相成分在三角形里沿一条特定路径移动：

- **初晶相析出**：成分点位于某相的原生相区内，冷却后首先析出该相，液相成分**背离该相顶点**、沿直线向边界移动。
- **到达共晶线/包晶线**：液相成分到达边界后，第二相开始析出，液相沿边界移动，两相共同析出。
- **到达四相不变点**：液相最终到达三元不变点（如三元共晶），在固定温度下三相同时析出、液相耗尽——**温度不再下降，直到结晶完成**。

这套「成分路径」正是水泥、陶瓷烧成的理论脚本：**初晶相决定最先长出的矿物，路径终点决定最后的共晶组成**。<span class="marginnote">结晶路径是「成分守恒」的直观体现：<strong>析出的固相成分 + 剩余液相成分 = 原始成分</strong>。用杠杆规则逐段追踪，就能算出每一步「析出多少、剩下什么」——这是从相图走到工艺的桥梁。</span>

**辨析｜易错点：** 结晶路径依赖「平衡冷却」假设。实际生产常是**非平衡冷却**：冷却过快，初晶相来不及与液相完全反应，就留下**核晶、包晶残留与玻璃相**——产物偏离平衡相图，正是「相图是上限、工艺是实际」的又一例证。

## 6 实例：CaO–Al₂O₃–SiO₂ 与水泥熟料

把读图语言落到一个真实体系，**CaO–Al₂O₃–SiO₂（CAS）**是最经典的教材案例，也是水泥与耐火材料的地基。

- 水泥熟料的核心矿物——**C₃S（Ca₃SiO₅）、C₂S（Ca₂SiO₄）、C₃A（Ca₃Al₂O₆）、C₄AF**——在 CAS（加 Fe₂O₃ 扩展成四元）相图里有各自的原生相区（primary field）。
- 配料时把生料成分点「投」进相图：**落在哪个原生相区，冷却结晶就主要析出哪一相**——C₃S 的含量直接决定水泥强度，所以熟料配方本质是在 CAS 相图上「瞄」C₃S 的原生相区。
- 耐火材料则要看另一角：**高铝砖、镁砖**的服役上限由 CaO–Al₂O₃–SiO₂ 里的低共熔温度决定——液相出现越晚，耐火度越高。

**辨析｜易错点：** 相图给的是「平衡」信息，烧结给的是「实际」。**冷却太快、组分不均、动力学不足**，都可能让产物偏离相图预测——相图是「天花板」，实际工艺是「爬多高」。读到「成分点在某相区」只能说「最终应得这些相」，中间相、玻璃相都可能让实际产物更复杂。

**三元相图在科研与工业里的「形态」也值得一提**：成熟体系（如 CAS、MAS、MgO–Al₂O₃–SiO₂）有汇编成册的**相图手册与数据库**（如 ACerS/NIST 相图数据库），工程师直接查图；而新体系则要自己用**淬火 + XRD 定相**一步步测定——每画出一条相界线，都是一轮「平衡实验 + 物相鉴定」的往返。<span class="marginnote">相图是「实验烧出来的知识」：<strong>每一根结线、每一个不变点背后，都是几百个淬火样品与 XRD 花样</strong>。查图快、测图慢——所以读图能力是工程师的日常，测图能力是研究者的硬功夫。</span>

## 7 小结

- **三元相图**用等边三角形编码三组分成分，任意点只有两个独立变量；等温截面是「切片」读法。
- 两相区用**结线 + 杠杆规则**，三相区用**结线三角形 + 重心规则**——几何工具直接给出相的成分与相对量。
- **相关系**由结线三角形的划分决定：成分落在哪个三角形，终产物就是哪三个顶点相。
- 三元不变反应（如三元共晶）是四相共存的不变点，自由度归零。
- CAS 相图是水泥与耐火材料的「配料地图」：**C₃S 原生相区决定水泥强度，低共熔温度决定耐火度**。
- 结晶路径描述「冷却时液相成分怎么走」：初晶相 → 边界 → 不变点；非平衡冷却会留下核晶、玻璃相与包晶残留。
- 液相面是「熔化难易的海拔图」，相图数据库与淬火定相实验是测图的两种方式——**查图快、测图慢**。
- 吉布斯相律 $F = C - P + 2$ 是读图的总纲：**自由度归零处，就是不变点**。
