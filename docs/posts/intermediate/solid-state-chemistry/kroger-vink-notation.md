## 为什么从 Kröger–Vink 符号开始

上一节我们认识了空位、间隙、杂质，但还缺一
门「语言」：把缺陷写成化学方程式。Krög
er与 Vink 在 1956 年给出的记
号体系，至今是缺陷化学的通用语——它用三个
要素精确记录「什么缺陷、占哪个位、带多有效
电荷」，并让**质量守恒、位点守恒、电荷守
恒**三条规则像化学计量一样可检查。有了这
套语言，掺杂反应、缺陷平衡、非化学计量全都
能写成方程来推演——这是固体化学从「看图说
话」走向「定量分析」的关键一步。

## 1 记号语法：主体 · 位点 · 有效电荷

**Kröger–Vink 符号（Krög
er–Vink notation）**写成
 $X_S^c$，三个组成部分：

- **主体（X）**：缺陷是什么。空位用 `V`，间隙原子用下标 `i`，电子用 `e′`，空穴用 `h•`，正常原子用其元素符号。
- **位点（S）**：缺陷占据哪个亚晶格。`M` 表示金属位，`X` 表示阴离子位（注意：当 X 是卤素时，位点与元素符号可能相同，靠上下文区分）。
- **有效电荷（c）**：缺陷实际电荷减去原位点应有的电荷。用三个符号表示：**点 `•`** 表示 +1 有效正电荷，**撇 `′`** 表示 −1 有效负电荷，**叉 `×`** 表示电中性。

把符号读出来比背规则更快。几个最常用的：

| 符号 | 含义 | 有效电荷 |
| --- | --- | --- |
| $V_M'$ | 金属位空位 | −1（少了本该带正电的阳离子） |
| $V_X^{\bullet}$ | 阴离子位空位 | +1 |
| $V_O^{\bullet\bullet}$ | 氧空位（双负氧离子缺失） | +2 |
| $M_i^{\bullet\bullet}$ | 间隙阳离子 | +2 |
| $e'$ | 电子（导带） | −1 |
| $h^{\bullet}$ | 空穴（价带） | +1 |

**直觉**：有效电荷是「相对理想晶格的电
荷差」。想象把缺陷放回完美晶格，比该位本应
有的电荷多多少、少多少——多就是 `•`，
少就是`′`。<span class="marginnote">
读号诀窍：<strong>阳离子跑掉 → 
负电荷多余 → $V_M'$（撇）；阴离子
跑掉→ 正电荷多余 → $V_X^{\bullet}$
（点）。</strong>间隙阳离子 $M_i$
多带了正电荷，也是点。</span>

**辨析｜易错点：** 有效电荷 ≠ 真实
电荷。$V_O^{\bullet\bullet}$
是「氧空位带 +2 有效电荷」，但它本身只
是一个空位——这个「+2」是相对完整晶格缺
少了 O²⁻ 的静电记账，不是空位真的带正
电。**把所有缺陷的有效电荷加在一起，理想
晶格被零偏置，这就是电中性判据的由来。**

## 2 缺陷反应：把缺陷写成化学方程式

用 Kröger–Vink 符号可以写出**
缺陷反应（defect reaction）
**，比如掺杂——把外来氧化物溶进宿主晶体
。三个守恒律是书写的检查器：

- **质量守恒**：方程式两边的原子种类与数目必须相等（缺陷反应不改变化学组成）。
- **位点守恒**：反应前后，各类位点（金属位、阴离子位、间隙位）的总数必须相等。
- **电荷守恒**：反应前后总有效电荷必须为零——晶体的电中性必须被保持。

以 **CaCl₂ 掺入 NaCl** 为
例。Ca²⁺ 替换一个 Na⁺，带 +1 
有效电荷（$Ca_{Na}^{\bullet}$
）；为了电中性，必须同时产生一个 Na 空
位$V_{Na}'$：

$$CaCl_2 \;\longrightarrow\; Ca_{Na}^{\bullet} + V_{Na}' + 2Cl_{Cl}^{\times}$$

逐条检验：质量——左 1 Ca、2 Cl，
右1 Ca、2 Cl，✓；位点——1 个 
Na 位被 Ca 占 + 1 个 Na 空
位，Cl 位恰好接 2 个 Cl，✓；电荷
——$+1 + (-1) = 0$，✓。这
条反应说明：**每掺入一个 Ca²⁺，宿主
就「欠」一个 Na⁺，用空位来还**——空
位浓度被掺杂直接泵升，这正是离子导电的开关
。<span class="marginnote">
注意 $Cl_{Cl}^{\times}$
记作「正常」：掺进去的 Cl 安放到 Cl
位上，不改变有效电荷。<strong>掺杂
反应的价值在于，它把「杂质怎么进来」翻译成
「缺陷怎么产生」</strong>——空位
、间隙、电子、空穴的浓度都能被这类方程定量
控制。</span>

## 3 公式解析：掺杂如何泵升空位

把掺杂反应与质量作用定律结合，就能定量「每
加多少掺杂剂，产生多少缺陷」。以低价掺杂为
例，平衡常数

$$K = \frac{[Ca_{Na}^{\bullet}][V_{Na}']}{[CaCl_2]} = \exp\left(-\frac{\Delta G}{k_BT}\right)$$

- **第一步，写出浓度关系**：因为反应是 1:1 生成 $Ca_{Na}^{\bullet}$ 与 $V_{Na}'$，在电中性约束 $[Ca_{Na}^{\bullet}]=[V_{Na}']$ 下，空位浓度正比于掺杂浓度的平方根：$[V_{Na}']\propto\sqrt{[CaCl_2]}$。
- **第二步，看极限**：当掺杂浓度远大于本征缺陷浓度时，空位浓度几乎**线性**正比于掺杂量——掺杂成了空位的「提款机」。
- **第三步，读物理**：掺杂浓度每提高一个数量级，空位浓度大约提高一个数量级；而空位浓度直接决定离子导电率（电导正比于载流子数）。**「掺杂 → 空位 → 导电」这条链，是固体电解质与燃料电池陶瓷的全部秘密。**<span class="marginnote">把这条链记牢：$Ca^{2+}$ 替换 $Na^+$ → 有效电荷 $+1$ → 为电中性必须配一个 $V_{Na}'$。<strong>阳离子掺杂调阴离子空位，阴离子掺杂调阳离子空位</strong>——想给材料「开多少导电通道」，就选对应价态的掺杂剂。</span>

**辨析｜易错点：** 掺杂反应不是简单的
「替换」。Ca²⁺ 进了 Na⁺ 的位，但
 Na⁺ 并没有被「挤出去」——Na 位变
成空位，Na 原子去了别处（或被交换掉）。
**用元素守恒 + 位点守恒 + 电荷守恒
三重检查，任何缺陷反应都不会写错**；只凭
直觉写「CaCl₂ 替换 NaCl」是最容
易翻车的地方。

## 4 从单条反应到缺陷平衡

实际晶体里多个缺陷反应同时存在，它们通过**
缺陷平衡**互相制约：

**本征缺陷平衡**：Schottky 平衡 $0 \rightleftharpoons V_M' + V_X^{\bullet}$ 与 Frenkel 平衡 $M_M^{\times} \rightleftharpoons M_i^{\bullet\bullet} + V_M''$ 定义了本征缺陷浓度。
**电子–空穴平衡**：$0 \rightleftharpoons e' + h^{\bullet}$，即本征激发，其浓度乘积 $[e'][h^{\bullet}] = K_i$ 恒定。
- **电中性条件**：把所有带正有效电荷与负有效电荷的缺陷相加，令总和为零——这是解缺陷浓度方程组的封闭条件。<span class="marginnote">一个漂亮的推论：当掺杂把某类缺陷推到主导地位，<strong>电中性条件就被「钉」在那个主导缺陷上</strong>，其余缺陷浓度随之被压缩。缺陷化学的「主导缺陷近似」与统计物理里的「主项近似」同出一辙。</span>

把上面的平衡方程联立起来，就能算出任意掺杂
、温度、氧分压下的缺陷浓度图（**Brou
wer 图**）。Brouwer 图是缺陷
化学的「相图」——横轴是氧分压或掺杂浓度，
纵轴是各缺陷浓度，几条斜线交叉出不同的主导
区。它在固体氧化物燃料电池、传感器设计中是
标配工具。

## 5 小结

- **Kröger–Vink 符号** $X_S^c$：主体 · 位点 · 有效电荷；点 `•` = +1，撇 `′` = −1，叉 `×` = 中性。
- 有效电荷是相对理想晶格的电荷差，不是真实电荷；所有缺陷的有效电荷总和必须为零。
- **缺陷反应**受质量、位点、电荷三条守恒律约束：CaCl₂ 掺 NaCl 得 $Ca_{Na}^{\bullet}+V_{Na}'+2Cl_{Cl}^{\times}$
