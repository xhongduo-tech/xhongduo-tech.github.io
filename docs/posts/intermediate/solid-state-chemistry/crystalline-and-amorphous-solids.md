# 晶体与非晶态固体：长程序与短程序

## 为什么从「晶体与非晶」开始

「从极限到大模型」这条路走到这里，我们已经
在高等数学里建立起连续与极限的直觉，在物理
化学里理解过原子与分子如何靠化学键结合。可
是当几十亿个分子被压在一起，凝成一块我们能
摸到、敲响、摔不碎的材料时，一种全新的秩序
出现了——它既不属于单个分子，也无法从单根
化学键直接推出来。固体化学的全部问题，就是
从「固体里的原子到底怎么排」这个最朴素的问
题开始的。

而这个问题有一个再干脆不过的回答切分：**
要么原子在三维空间里周期性重复，要么它们只
在近旁几个原子范围内有序**。前者叫晶体，
后者叫非晶态。这个分野是后续所有章节的地基
——晶胞、布拉维点阵、缺陷、能带，全都建立
在这两种「序」之上。

## 1 晶体：长程序把微观排成宏观

**晶体（crystal）**：由原子、离
子或分子按**长程序（long-range
 order）**在三维空间作周期性重复排
列而构成的固体。长程序的意思是：从任意一个
原子出发，沿某个方向平移固定的距离，总能落
到另一个完全等价的原子位置上——这种平移不
变性，就是晶体最本质的几何特征。

晶体可以分解为两个构件：**晶格（latt
ice）**与**基元（motif / b
asis）**。晶格是几何点阵，它描述「重
复的节奏」；基元是每个格点上实际安放的内容
（一个分子、几个离子或一组原子）。**晶体
 = 晶格+ 基元**。<span class="marginnote">
晶体与晶格的差别常被混淆：晶格只是抽象的数
学点阵，本身没有「原子」；真正把原子放上去
、形成有化学意义的实体，才是晶体。这个区分
在下一节《晶格、晶胞与七大晶系》里会反复用
到。</span>

长程序最直观的证据来自对称性。一块天然石英
晶体长成六棱柱，雪花长成六角星，盐粒是规整
的立方块——这些宏观的几何外形不是巧合，而
是内部周期性排列在晶体生长时「顺着原子台阶
一级级堆砌」的外露。正因为内部有严格的平移
周期，晶面才会以固定的角度相交。

**固体化学最关心的不是「晶体有没有长程序
」这个事实，而是「长程序如何被打破、被掺杂
、被取代」**——这正是后面缺陷化学与非化
学计量的出发点。<span class="marginnote">
一块「完美晶体」在热力学上其实是不可能存在
的：温度大于绝对零度时，平衡态必然含有一定
浓度的空位等缺陷。长程序是理想模型，真实晶
体是「有缺陷的长程序」。</span>

## 2 非晶态：短程序与「冻结的液体」

**非晶态（amorphous）**：原子
只在几个原子间距的范围内保持有序排列、长距
离上完全无序的固体。它没有平移周期，因而不
存在晶格。非晶态的代表是玻璃，因此有时也直
接叫**玻璃态（glassy state）
**。

非晶态并非「乱成一团」。恰恰相反，它保留了
**短程序（short-range ord
er）**：一个硅原子周围仍然是四个氧原子
按四面体配位，Si–O 键长与键角与晶体中
的几乎一样。<span class="marginnote">
短程序来自化学键的局域定向性：键长键角几乎
固定，决定了最近邻的配位结构；但键与键之间
的「扭角」自由，导致原子没法把这种局部规则
延续到宏观。短程序守恒，长程序丢失——这是
非晶态与气体的「完全无序」的本质差别。</span>

非晶态与晶态的分野，在热力学上是这样发生的
：液体冷却时，如果原子来得及调整位置，会在
熔点$T_m$ 处结晶；如果降温太快、黏度
迅速增大，原子来不及重排，就被「冻」在液体
般的无序结构中，越过熔点继续降温，在**玻
璃化转变温度 $T_g$** 附近固化成玻
璃。所以玻璃常被称作「冻结的液体」——它保
留了液体的无序，却拥有了固体的硬度。

晶体有确定的熔点 $T_m$：熔化是热力学上的一级相变，需要吸收潜热。
非晶没有熔点，只有玻璃化转变：没有潜热，只有热容与膨胀系数的台阶式变化。<span class="marginnote">正因为没有潜热、没有固定熔点，玻璃的「熔化」更像一个连续软化的过程。这也是日常生活中「玻璃是液体还是固体」争论的根源——按热力学定义，玻璃是处于非平衡（介稳）态的固体。</span>

## 3 三条判别之尺：衍射、熔点与各向异性

怎么知道一块固体是晶体还是非晶？实验室里有
三条可靠的尺子，它们分别从结构、热学与物理
性质三个角度给出判断。

**X 射线衍射（XRD）**是最直接的结
构之尺。晶体的周期性排列像一台三维光栅，能
把X 射线相干散射成一组锐利的**Brag
g峰**（其条件是 $2d\sin\theta = n\lambda$
，下一节我们会专门拆解）；非晶态没有周期性
，相干散射只留下少数几个宽化的**弥散环（
diffuse halo）**。<span class="marginnote">
判读口诀：<strong>锐峰＝晶态，弥散
＝非晶。</strong>这也是 XRD 
粉末衍射图在论文里被当成「结晶性证据」的原
因——一张干净的衍射图意味着长程序存在。</span>

**热学行为**是第二把尺。晶体在固定温度
熔化，DSC 曲线上是一个尖锐的吸热峰；非
晶在$T_g$ 处只出现基线台阶。若把非晶
继续加热，它还可能先结晶（放热）、再熔化（
吸热）——这条「玻璃 → 晶体 → 液体」
的路线正是后面《热分析》一节要细看的。

**各向异性**是第三把尺。单晶的力学、光
学、电学性质随方向而变（比如云母沿层状方向
极易解理、石墨沿平面方向导电性远高于垂直方
向）；非晶是各向同性的，任何方向上的性质都
一样。<span class="marginnote">
多晶（polycrystal）是晶体的特殊
情况：由大量取向随机的微小晶粒构成，宏观上
因取向平均而呈现各向同性，但微观仍是晶体—
—所以「各向同性」并不等于「非晶」，判读时
要当心。</span>

## 4 核心要点对比：晶态与非晶态

本主题以概念辨析为主，核心对比表如下（纯概
念主题，以对比表替代公式解析）：

| 判别维度 | 晶体 | 非晶态 |
| --- | --- | --- |
| 原子排列 | 长程序：三维周期性平移 | 短程序：近旁有序，长程无序 |
| 是否存在晶格 | 是（晶体 = 晶格 + 基元） | 否 |
| X 射线衍射 | 锐利 Bragg 峰 | 弥散环（halo） |
| 热学行为 | 确定熔点 $T_m$，有熔化潜热 | 玻璃化转变 $T_g$，无潜热 |
| 宏观性质 | 单晶各向异性 | 各向同性 |
| 热力学状态 | 热力学平衡（理想晶体） | 介稳的非平衡态 |
| 对称性 | 有平移对称性 | 无平移对称性 |

这张表里有三个词最容易出错，逐一辨析：

**辨析｜易错点：**「各向同性」不等于「
非晶」。多晶金属由取向随机的小晶粒组成，宏
观各向同性，但每个晶粒内部都是晶体。**「
短程序」不等于「无序」**：非晶的短程序与
晶体几乎一致，差别只在长程序。**「玻璃态
」不等于「液体」**：玻璃是力学上的固体（
能承受剪切应力而不流动），只是结构上像液体
。

## 5 小结

- **晶体**以长程序为标志，可拆解为**晶格 + 基元**；平移周期性是它一切几何性质的根源。
- **非晶态**保留短程序、丢失长程序；玻璃是「冻结的液体」，在 $T_g$ 处连续软化而非在 $T_m$
