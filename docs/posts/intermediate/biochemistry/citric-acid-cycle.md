# 三羧酸循环

<div class="epigraph">
<p>三羧酸循环是代谢的中央旋钮：碳进去，烟酰胺和氢走掉，能量被记在每一笔账上。</p>

## 为什么从三羧酸循环开始

糖酵解只把葡萄糖「半烧」成丙酮酸，大部分能量还锁在碳骨架里。要榨干它，必须让**乙酰基进入一个循环**——**三羧酸循环（TCA cycle，也叫柠檬酸循环 / Krebs 循环）**。它是几乎所有燃料的共同终点站：糖、脂肪、氨基酸降解后都以**乙酰 CoA** 的形式汇入这个循环，被彻底氧化成 $\ce{CO2}$，同时把能量装进 NADH、FADH₂、GTP。克雷布斯在 1937 年把它拼出来时，用的是一张「燕子叼泥」式的实验推理——代谢途径不是靠猜，而是靠「喂同位素、看它从哪冒出来」实证的。**这一节是「代谢地图」的心脏：三羧酸循环既产能量（供呼吸链），又吐碳骨架（供生物合成）——看懂它，整张代谢地图就活了。**

## 1 入口：丙酮酸脱氢酶复合体

线粒体内，丙酮酸被**丙酮酸脱氢酶复合体（PDC）**氧化脱羧，生成乙酰 CoA：

$$
\ce{pyruvate + NAD+ + CoA-SH -> acetyl-CoA + CO2 + NADH + H+}
$$

这个复合体是代谢里最精密的「分子机器」之一：由三种酶、五个辅因子组装而成——**TPP、硫辛酸、FAD、NAD⁺、CoA**。注意，其中 TPP 和 CoA 正是维生素 B₁ 与 B₅ 的功能形态——上一节「辅酶是零件的仓库」在此兑现。脱羧（丢一个碳成 $\ce{CO2}$）发生在 TPP 上，硫辛酸把乙酰基「摆渡」到 CoA 上。<span class="marginnote">PDC 是砷中毒的经典靶点：砷化物专攻硫辛酸，让它失活，于是丙酮酸堆积、产能停摆——「慢性毒杀」在分子层面就是把一个辅因子焊死。维生素 B₁ 缺乏（脚气病）也有类似后果，因为 TPP 是它的一部分。</span>

<strong>辨析｜易错点：</strong> PDC 是「多酶复合体」——不是一种酶，而是 E1（脱羧）、E2（转乙酰基）、E3（再氧化）三种酶 + 五种辅因子拼成的「分子流水线」。硫辛酸作为「摆渡臂」在 E1 与 E2 之间来回运送乙酰基。这类「多酶复合体」在代谢里不少见（脂肪酸合酶、剪接体同理），它们把多步反应「关进一个车间」，靠<strong>底物通道效应</strong>避免中间物散失。

## 2 循环的八步：一次「绕圈」

循环从草酰乙酸（OAA，四碳）出发，与乙酰 CoA（两碳）缩合成**柠檬酸（六碳）**，然后经过两次氧化脱羧（丢两分子 $\ce{CO2}$、回到四碳），再经几步氧化把骨架转回 OAA——**一进一出，循环周转**。八个中间物按顺序：柠檬酸 → 异柠檬酸 → α-酮戊二酸 → 琥珀酰CoA → 琥珀酸 → 延胡索酸 → 苹果酸 → 草酰乙酸 → 回到柠檬酸。

配图把它画成一张「八边形转盘」：三个 NAD⁺ 被还原成 NADH（异柠檬酸、α-酮戊二酸、苹果酸三步）、一个 FAD 被还原成 FADH₂（琥珀酸→延胡索酸）、一次底物水平磷酸化产出 GTP（琥珀酰CoA→琥珀酸）。**注意 $\ce{CO2}$ 的两步脱羧恰好发生在「六碳区」，把六碳骨架削回四碳——碳的平衡（一乙酰基两碳进、两碳出）是循环能「转起来」的关键。**

![三羧酸循环](/images/biochemistry/citric-acid-cycle.svg)

**辨析｜易错点：** 循环的名字来自中间物柠檬酸（三羧酸），但**循环本身不消耗 OAA**——OAA 是催化剂式的「运输载体」，把乙酰基的碳送进 $\ce{CO2}$ 后自身复原。因此循环「产物」是 NADH/FADH₂/GTP，而不是 OAA 的增减；OAA 若被挪用去糖异生，循环就会「停转」，需要回补反应补货。

八个中间物按「碳数」看一次，就记住了循环的骨架：

| 中间物 | 碳数 | 这一步的「动作」 |
| --- | --- | --- |
| 柠檬酸 | 6 | 乙酰基进来 |
| 异柠檬酸 | 6 | 第一次氧化脱羧 |
| α-酮戊二酸 | 5 | 第二次氧化脱羧 |
| 琥珀酰 CoA | 4 | 底物水平磷酸化 |
| 琥珀酸 | 4 | 脱氢（FADH₂） |
| 延胡索酸 | 4 | 加水 |
| 苹果酸 | 4 | 脱氢（NADH） |
| 草酰乙酸 | 4 | 再接一分子乙酰 CoA |

**6 → 5 → 4**：两次脱羧把「六碳」削回「四碳」，之后四碳在 OAA 复原——整个循环就是「两碳进、两碳出、载体不耗」。

## 3 公式解析：一圈的完整账本

把八步的氧化还原与能量收成一条总反应：

$$
\ce{acetyl-CoA + 3 NAD+ + FAD + GDP + Pi + 2 H2O}
$$

$$
\ce{-> 2 CO2 + 3 NADH + 3 H+ + FADH2 + GTP + CoA-SH}
$$

- **第一步，数还原当量**：每圈产出 **3 NADH + 1 FADH₂ + 1 GTP**。这是循环给后续呼吸链的「存款」。
- **第二步，数碳**：2 个 $\ce{CO2}$ 恰好等于乙酰基带进来的两个碳，但这两个碳**不是**乙酰基的那两个碳（循环转第二圈才真正排走）——**$\ce{CO2}$ 来自「循环体内的碳」，这个细节常考易错**。
- **第三步，换算 ATP**：按现代化学渗透核算，NADH 约兑 2.5 ATP、FADH₂ 约 1.5 ATP、GTP 约 1 ATP，则每圈等效约 $3 \times 2.5 + 1.5 + 1 = 10$ ATP。加上前面糖酵解与 PDC 的贡献，一分子葡萄糖完全氧化共约 **30–32 ATP**——这个数字会在氧化磷酸化一节严谨推导。
- **第四步，读名字**：循环不是「产能的主角」，而是「把还原当量装进 NADH/FADH₂」——**真正的 ATP 工厂在下一节的呼吸链**。

## 4 循环的双重身份：产能与合成

TCA 循环**既产能又供合成**，叫**双用代谢（amphibolic）**——中间物可以被「抽调」去当合成原料：

- **α-酮戊二酸 → 谷氨酸 → 脯氨酸/谷氨酰胺**（氨基酸代谢）。
- **草酰乙酸 → 天冬氨酸 → 嘌呤/嘧啶合成**（核苷酸代谢）。
- **柠檬酸 → 胞质乙酰 CoA → 脂肪酸合成**（脂质代谢）。

中间物被抽调后，循环必须**回补（anaplerosis）**，否则「转盘」缺料。最重要的回补反应：**丙酮酸羧化酶**把丙酮酸变成草酰乙酸（这也是糖异生绕道的第一步）。<span class="marginnote">「中间物双向流动」让三羧酸循环成为代谢网络的「分诊台」：饥饿时草酰乙酸被糖异生抽走、循环让位于造糖；吃饱时中间物涌向合成。一个环同时服务产能与建材，是「模块复用」在代谢里的极致体现。</span>

循环「供货」给合成分支的具体清单：

| 抽走的中间物 | 合成方向 |
| --- | --- |
| 柠檬酸 → 胞质乙酰 CoA | 脂肪酸合成 |
| α-酮戊二酸 → 谷氨酸 → 脯氨酸 / 谷氨酰胺 | 氨基酸 |
| 草酰乙酸 → 天冬氨酸 → 嘌呤 / 嘧啶 | 核苷酸 |
| 琥珀酰 CoA | 血红素（卟啉环）合成 |

回补反应不只有丙酮酸羧化酶：<strong>谷氨酰胺 → α-酮戊二酸、天冬氨酸 → 草酰乙酸</strong>也能「补货」——细胞会挑代价最低的那条路把中间物池填满。

## 5 调控：三把钥匙

三羧酸循环的闸门在三个「不可逆步」：**柠檬酸合酶、异柠檬酸脱氢酶、α-酮戊二酸脱氢酶**。它们的开关规则高度一致：

**高能抑制**：ATP、NADH 抑制；ADP、NAD⁺ 激活——**能量足就减速，缺能量就加速**（呼应上一节的能荷逻辑）。
- **产物反馈**：柠檬酸（柠檬酸合酶的产物）抑制柠檬酸合酶；琥珀酰 CoA 抑制 α-酮戊二酸脱氢酶。
- **钙离子激活**：肌肉收缩时 $\ce{Ca^{2+}}$ 升高，同时激活异柠檬酸脱氢酶与 α-酮戊二酸脱氢酶——**运动指令直接打开产能开关**，让循环与需求联动。<span class="marginnote">把三把钥匙连起来看：NADH/ATP 高=「电池满，别充了」；ADP/NAD⁺/Ca²⁺ 高=「开工，放电」。三羧酸循环不是「永远满速转」，而是一台被需求驱动的发电机——这提醒我们，代谢速率由「消费方」决定，而非「供给方」一厢情愿。</span>

三个闸门的「高能抑制」其实是同一个能荷逻辑的具体化：NADH/ATP 高了说明「电池充满」，循环就该减速甚至把中间物让给合成；ADP/NAD⁺ 高了说明「正在放电」，循环就得加速补能。<strong>TCA 的速率几乎完全由「消费端需求」驱动，而不是由「供给端」一厢情愿</strong>——这是代谢调控最根本的一条。

## 6 术语速查

- **乙酰 CoA**：两碳载体（CoA + 乙酰基），是糖、脂、氨基酸代谢的共同汇合点。
- **回补（anaplerosis）**：被抽调的三羧酸中间物通过回补反应补足，如丙酮酸羧化酶。
- **双用代谢（amphibolic）**：一条途径既产能量又供合成原料。
- **底物水平磷酸化**：TCA 中琥珀酰 CoA → 琥珀酸直接产 GTP。
- **PDC（丙酮酸脱氢酶复合体）**：E1/E2/E3 多酶复合体，把丙酮酸接入循环。
- **GTP/ATP 等效**：琥珀酰 CoA 合成的 GTP 与 ATP 等价（经核苷二磷酸激酶互转）。

## 7 小结

- **丙酮酸脱氢酶复合体**把丙酮酸 → 乙酰 CoA + $\ce{CO2}$ + NADH，需 TPP、硫辛酸、FAD、NAD⁺、CoA 五辅因子。
- 循环八步、以 **OAA 为催化剂式载体**：柠檬酸 → … → 草酰乙酸，一乙酰基两碳进、两分子 $\ce{CO2}$ 出。
- 每圈净得 **3 NADH + 1 FADH₂ + 1 GTP**，约合 **10 ATP**；葡萄糖完全氧化总计约 30–32 ATP。
- 循环是**双用代谢**：中间物被抽调供合成，靠**回补反应**（丙酮酸羧化酶）补货。
- 调控三闸门：柠檬酸合酶、异柠檬酸脱氢酶、α-酮戊二酸脱氢酶；ATP/NADH 抑制、ADP/NAD⁺/$\ce{Ca^{2+}}$ 激活。

在下一节，NADH 与 FADH₂ 要兑现成 ATP 了——**氧化磷酸化**：电子传递链把还原当量沿着电压差送下坡，化学渗透把质子梯度变成旋转的 ATP 合酶。
