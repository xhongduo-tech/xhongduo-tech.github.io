## 为什么从氨基酸开始

上一节我们建立了生物化学的舞台（细胞）与台词（分子、能量）。现在开始逐个认识主角。**蛋白质（protein）**是功能最多样的大分子：催化（酶）、转运（血红蛋白）、结构（胶原）、运动（肌球蛋白）、防御（抗体）、调控（激素受体）。而一切蛋白质都是把 20 种**标准氨基酸（amino acid）**按不同顺序串成的链。记住一句话：**蛋白质的剧情是「序列决定一切」，而序列就是氨基酸的排列。** 学懂氨基酸的化学，等于拿到了解读整本蛋白质「天书」的字母表。

## 1 氨基酸的通用结构

每个标准氨基酸都长这样：一个**α-碳（alpha carbon）**连着一个氨基 $\ce{-NH2}$、一个羧基 $\ce{-COOH}$、一个氢，以及一个各不相同的侧链 **R 基团**：

$$
\ce{H2N-CH(R)-COOH}
$$

R 基团决定了每个氨基酸的性格。按 R 的极性，20 种标准氨基酸分四类：

| 类别 | 特点 | 代表 |
| --- | --- | --- |
| 非极性（疏水） | R 是碳氢链 / 环，躲水 | 甘氨酸、丙氨酸、缬氨酸、亮氨酸、异亮氨酸、甲硫氨酸、苯丙氨酸、色氨酸、脯氨酸 |
| 极性不带电 | R 含羟基 / 酰胺基，亲水 | 丝氨酸、苏氨酸、半胱氨酸、酪氨酸、天冬酰胺、谷氨酰胺 |
| 酸性 | R 含羧基，常带负电 | 天冬氨酸、谷氨酸 |
| 碱性 | R 含氨基 / 胍基，常带正电 | 赖氨酸、精氨酸、组氨酸 |

氨基酸的缩写是蛋白质化学的通用速记——每个氨基酸都有三字母码与单字母码，序列书写、蛋白质数据库（UniProt）、文献都用它们：

| 类别 | 氨基酸（三字母 / 单字母） |
| --- | --- |
| 非极性 | 甘氨酸 Gly/G、丙氨酸 Ala/A、缬氨酸 Val/V、亮氨酸 Leu/L、异亮氨酸 Ile/I、甲硫氨酸 Met/M、苯丙氨酸 Phe/F、色氨酸 Trp/W、脯氨酸 Pro/P |
| 极性不带电 | 丝氨酸 Ser/S、苏氨酸 Thr/T、半胱氨酸 Cys/C、酪氨酸 Tyr/Y、天冬酰胺 Asn/N、谷氨酰胺 Gln/Q |
| 酸性 | 天冬氨酸 Asp/D、谷氨酸 Glu/E |
| 碱性 | 赖氨酸 Lys/K、精氨酸 Arg/R、组氨酸 His/H |

记忆小技巧：单字母码大多取英文名首字母，但有几枚「例外」要特别记——**Lys 用 K、Arg 用 R、Asn 用 N、Gln 用 Q、Phe 用 F、Trp 用 W、Tyr 用 Y、Asp 用 D、Glu 用 E**。这套速记在蛋白质结构、酶动力学与测序章节里会反复出现，值得现在就背熟。

**辨析｜易错点：** 严格说「标准氨基酸」不止 20 种——**硒代半胱氨酸（Sec，U）**与吡咯赖氨酸（Pyl，O）能在特殊条件下被「共翻译」掺入蛋白质，被称作第 21、22 种氨基酸。入门先记牢 20 种；遇到 Sec 时知道它是「硒替硫」的例外即可，不必背诵全部细节。

蛋白质折叠成特定形状，靠的正是这些侧链之间的「恩怨」：疏水侧链挤进内部躲水，带电侧链在表面与溶剂互动，半胱氨酸的 $-SH$ 能形成**二硫键（disulfide bond）**把链条焊起来。<span class="marginnote">甘氨酸的 R 只是一个氢，太小太灵活，因此它总出现在蛋白质弯曲急转的位置；脯氨酸的侧链把自己连回主链氮上形成环，刚性极强，常「打断」螺旋——这两枚「特例」在预测蛋白质结构时极其重要。</span>

氨基酸还有手性：除甘氨酸外，α-碳都是手性中心，有两种互为镜像的构型 D 与 L。**生物蛋白质清一色使用 L-氨基酸**——这是生命的化学「手性指纹」，与上一节的沙利度胺教训同源。

## 2 氨基酸的酸碱化学：两性、pKa 与等电点

氨基酸同时有氨基和羧基，是**两性电解质（ampholyte）**。在生理 pH 下，羧基失去质子、氨基得到质子，氨基酸以**兼性离子（zwitterion）**形式存在：$\ce{+NH3-CH(R)-COO-}$。它既能结合酸又能结合碱，本身就是微型缓冲剂。

每个可电离基团有自己的 $pK_a$（沿用上节 Henderson–Hasselbalch 方程的框架）。关键结论是**等电点**：

**等电点（isoelectric point, pI）**：氨基酸净电荷为零时的 pH。对只有一个氨基和一个羧基的中性氨基酸：

$$
pI = \frac{pK_a(\ce{-COOH}) + pK_a(\ce{-NH3+})}{2}
$$

pH < pI 时分子带正电，pH > pI 时带负电——**在电场里，氨基酸就凭这个 pH 差被拖向不同电极**，这就是电泳分离的第一原理。<span class="marginnote">组氨酸的咪唑基 $pK_a \approx 6.0$ 恰好落在生理 pH 附近，让它能在血红蛋白里充当质子「中继站」——这正是 Bohr 效应（详见蛋白质功能一节）的化学根源。带侧链的氨基酸，pI 还要把侧链的 pKa 算进去。</span>

## 3 肽键与肽链

两个氨基酸脱水缩合，形成一个**肽键（peptide bond）**：

$$
\ce{H2N-CH(R1)-COOH + H2N-CH(R2)-COOH -> H2N-CH(R1)-CO-NH-CH(R2)-COOH + H2O}
$$

**肽键**：一个氨基酸的羧基与另一个的氨基脱去一分子水形成的酰胺键 $\ce{-CO-NH-}$。短链称**寡肽**，长链称**多肽**，具有生物功能的链状分子就是蛋白质。

肽键有三个关键性质，全来自它的共振结构：

- **平面性**：$\ce{C-N}$ 键有部分双键特征，不能自由旋转，六个原子共面（酰胺平面）。
- **顺反偏好**：几乎总是**反式**（相邻 α-碳在肽键两侧），因为反式位阻小。
- **主链自由度只集中在 φ、ψ 两个角**：整个蛋白质主链的「舞蹈」就靠它们摆姿势——下一节《蛋白质的三维结构》的拉氏图将专门讲这两个角。

一条多肽有**方向性**：一端是游离氨基，称 **N 端**；另一端是游离羧基，称 **C 端**。序列书写与合成方向永远是 N 端 → C 端。

## 4 公式解析：等电点实例

拿甘氨酸来算一遍。甘氨酸 $pK_a(\ce{-COOH}) = 2.34$，$pK_a(\ce{-NH3+}) = 9.60$：

$$
pI = \frac{2.34 + 9.60}{2} = 5.97
$$

三步拆解：

- **第一步，代入两个主链 pKa**：对中性氨基酸只需主链羧基与氨基两档。
- **第二步，算术平均**：净电荷为零的 pH 恰在两档 $pK_a$ 的中点——因为此时分子恰好在两种电离态之间「各占一半」。
- **第三步，读意义**：pH 5.97 时甘氨酸整体不带电，在等电点聚焦电泳中停在原地；把 pH 调到 7 附近，甘氨酸带负电，朝阳极跑。**pI 是把「氨基酸的电荷态」变成「可计算的数」的桥梁**，同理可推广到肽与蛋白质整体。

### 带侧链的氨基酸怎么算

天冬氨酸有三个可电离基团：α-羧基 $pK_a = 2.09$、侧链羧基 $pK_a = 3.86$、α-氨基 $pK_a = 9.82$。净电荷为零发生在两个羧基都已电离、氨基还带正电的时刻——**取两个羧基 pKa 的平均**：

$$
pI = \frac{2.09 + 3.86}{2} = 2.98
$$

同理，碱性氨基酸（如赖氨酸）取两个氨基 pKa 的平均。规则一句话：**酸性氨基酸用两个酸性 pKa 求均值，碱性氨基酸用两个碱性 pKa 求均值**——判断「等电点处哪两个基团被中和」，是这类题的唯一关键。

## 5 一级结构：序列如何被测定

蛋白质的氨基酸顺序叫**一级结构（primary structure）**。它的测定曾是化学史上最著名的攻坚之一：桑格在 1953 年花十年时间测定了胰岛素（51 个氨基酸）的完整序列——这是人类首次弄清一个蛋白质的氨基酸顺序，桑格因此获 1958 年诺贝尔化学奖。<span class="marginnote">桑格后来把同样的「测序」思路用到核酸上，发明了 DNA 双脱氧测序法（Sanger 测序，见《DNA 技术与基因工程方法》一节），成为史上唯一两次获得诺贝尔化学奖的人。测序的核心永远是同一句话：把长链切碎、逐个读出、再拼回原样。</span>

经典策略：先用专一切割试剂（如胰蛋白酶切在赖氨酸、精氨酸后）把长链切成可分辨的片段，分别测序，再用不同特异性的酶切出重叠片段，交叉比对拼出全长。今天的自动化序列分析早已跑在这套逻辑之上——**「分而治之 + 重叠拼图」是序列科学的祖传算法**，你在第三级《算法》里会再次遇见它。

## 6 小结

- 蛋白质由 20 种**标准氨基酸**经肽键连成；α-碳连氨基、羧基、H 与 R 基团，R 决定极性分类。
- 氨基酸是**两性电解质**，在中性 pH 下呈兼性离子；**等电点** $pI = \frac{pK_a(\ce{-COOH}) + pK_a(\ce{-NH3+})}{2}$（中性氨基酸），电泳据此分离。
- **肽键**是脱水缩合形成的酰胺键：平面、近全反式、只能靠 φ/ψ 两个角转动——这是三维结构的伏笔。
- 多肽有方向性：**N 端 → C 端**。
- **一级结构**即氨基酸序列，桑格测定胰岛素是里程碑；测序方法是「切碎—读出—重叠拼回」。
