# 氨基酸代谢与尿素循环

## 为什么从氨基酸代谢开始

糖与脂肪的代谢只涉及 C、H、O——烧完变成 $\ce{CO2}$ 与水，干净利落。**氨基酸的代谢多了一个大麻烦：氮（N）**。氨基 $\ce{-NH2}$ 是氨基酸的核心，但当氨基酸被用作燃料时，游离的氨（$\ce{NH3}$）是**剧毒**的（它会使大脑中毒——肝性脑病的根源）。于是生命进化出一整套「氮处理管线」：**转氨基**把氨基集中到谷氨酸上 → **氧化脱氨基**卸下氨 → **尿素循环**把两分子氨与一分子 $\ce{CO2}$ 打包成低毒、易溶的**尿素**排出。氨基酸的碳骨架则各有归宿：一部分进三羧酸循环产能，另一部分（生糖/生酮）参与代谢整合。**读懂氨基酸代谢，等于读懂了人体处理「氮垃圾」的整个闭环。**

## 1 转氨基：氨基的「搬运工」

氨基酸氧化第一步几乎都是**转氨基（transamination）**——把氨基转移给 α-酮戊二酸，自己变成 α-酮酸，α-酮戊二酸则变成谷氨酸：

$$
\ce{氨基酸 + \alpha-酮戊二酸 <=> \alpha-酮酸 + 谷氨酸}
$$

催化的是**转氨酶（氨基转移酶）**，辅酶是 **PLP（维生素 B₆ 的功能形态）**。PLP 以希夫碱中间体把氨基「接住」再「交出」，完成一次漂亮的分子摆渡。临床上最著名的两个转氨酶是 **ALT（丙氨酸转氨酶）**与 **AST（天冬氨酸转氨酶）**——肝细胞受损时它们漏进血液，所以体检里的「转氨酶升高」是肝损伤的信号。<span class="marginnote">转氨基把「许多氨基酸的氨基」汇聚到谷氨酸一处——谷氨酸成了氮的「集散中心」。这是「多对一」的信息汇聚，与代谢调节原理一节「用少数代谢物当全局信号」是同一个设计哲学：先把散乱的输入归一，再统一处理。</span>

## 2 氧化脱氨基：把氨真正卸下来

汇聚到谷氨酸后，**谷氨酸脱氢酶（GDH）**把氨基以氨的形式卸下：

$$
\ce{谷氨酸 + NAD+ + H2O <=> \alpha-酮戊二酸 + NH4+ + NADH + H+}
$$

这一步的产物就是游离的 $\ce{NH4+}$ 与 α-酮戊二酸（回到三羧酸循环）。GDH 受 GTP/ATP 抑制、ADP 激活——**氮代谢也服从能荷指挥**。氨的转运则依赖**谷氨酰胺合成酶**：谷氨酸 + $\ce{NH4+}$ + ATP → **谷氨酰胺**，这是把氨「解毒包装」送往肝/肾的运输形式；肌肉则用**丙氨酸**（经丙氨酸-葡萄糖循环）把氨送到肝。<span class="marginnote">「氨很毒，所以要打包运输」——谷氨酰胺和丙氨酸就是氨的「快递盒」。理解这一点，就理解了为什么临床上高血氨（肝衰竭）患者要用谷氨酰胺对抗、也是为什么膳食蛋白过量会增加肝与肾的解毒负担。</span>

## 3 公式解析：尿素循环的总账

肝细胞线粒体+胞质里运行的**尿素循环**（克雷布斯-亨塞莱特循环）把氨无害化。总反应：

$$
\ce{2 NH4+ + CO2 + 3 ATP + H2O -> 尿素 + 2 ADP + 2 Pi + AMP + PPi}
$$

- **第一步，数氮**：尿素含两个氮——一个来自氨，另一个来自天冬氨酸的氨基（天冬氨酸由草酰乙酸与谷氨酸转氨基而来）。**两个氮都要收走**。
- **第二步，数能量**：消耗 4 个高能磷酸键当量（2 个 ATP → 2 ADP 在氨甲酰磷酸合成酶；1 个 ATP → AMP + PPi 在精氨酸琥珀酸合成酶，其中 PPi 再水解给 1 个额外当量）。**合成一分子尿素很贵，但比让氨在体内积累便宜无数倍**。
- **第三步，看五步循环**：氨甲酰磷酸（线粒体）→ 瓜氨酸 → 精氨酸琥珀酸（胞质）→ 精氨酸 → 尿素 + 鸟氨酸（鸟氨酸是催化剂式的「载体」，循环转起来）。**每一轮循环净消耗 2 氨、回收鸟氨酸，尿素作为产物排出。**

**辨析｜易错点：** 尿素循环与三羧酸循环都在肝线粒体「接壤」——α-酮戊二酸/草酰乙酸被两个循环共享，饥饿时 OAA 优先糖异生、尿素循环就「转得慢」，这是为什么饥饿会伴随高血氨风险。

## 4 碳骨架的命运：生糖与生酮氨基酸

脱掉氨基后，氨基酸的**碳骨架**（α-酮酸）怎么处理？看它变成什么：

- **生糖氨基酸（glucogenic）**：碳骨架能转成丙酮酸或三羧酸循环中间物，进而糖异生（如丙氨酸、天冬氨酸、谷氨酸）。
- **生酮氨基酸（ketogenic）**：碳骨架变成乙酰 CoA 或乙酰乙酸（如亮氨酸、赖氨酸），只能氧化产能或成酮体。
- 多数氨基酸两兼（部分生糖部分生酮），亮氨酸与赖氨酸是纯生酮——**糖尿病/饥饿时的氨基酸代谢会同时喂饱糖异生与酮体两条线**。

生物化学里常背的口诀「**一个丙氨酸 = 丙酮酸，一个天冬氨酸 = 草酰乙酸，一个谷氨酸 = α-酮戊二酸**」就是这个「翻译表」的浓缩——**氨基酸的碳骨架通过这三个人口进入代谢地图，氨基酸代谢由此与糖、脂代谢完全打通**。<span class="marginnote">把氨基酸代谢想成「把砖拆了分类回收」：氨基是危废（走尿素循环），碳骨架是可回收建材（进三羧酸循环）。代谢整合一节会看到，正是这三个人口让「氨基酸 → 葡萄糖」在饥饿时成为可能。</span>

## 5 一碳单位与叶酸

氨基酸代谢还贡献了**一碳单位（one-carbon units）**的供给：丝氨酸、甘氨酸把「一碳」交给**四氢叶酸（THF，维生素 B₉ 的功能形态）**，THF 再把一碳单位交给嘌呤、胸腺嘧啶与甲硫氨酸的合成。**一碳单位代谢是「细胞分裂的原材料流水线」**——这也是为什么叶酸缺乏主要伤及分裂旺盛的造血与胚胎组织，孕期补叶酸成了铁律。甲氨蝶呤（化疗药）正是叶酸的类似物，通过抑制二氢叶酸还原酶来「饿死」快速分裂的癌细胞。<span class="marginnote">一碳单位这条线把「氨基酸代谢」与「核苷酸代谢」直接焊接：叶酸 → THF → 嘌呤/胸腺嘧啶合成。所以抗叶酸药物既是抗癌药、也是强效致畸物——<strong>干预一碳单位，就是干预细胞分裂本身</strong>。</span>

## 6 小结

- **转氨基**（PLP 辅酶）把氨基汇聚到谷氨酸；**氧化脱氨基**（谷氨酸脱氢酶）卸下 $\ce{NH4+}$，受能荷调控。
- 氨用**谷氨酰胺、丙氨酸**打包转运到肝。
- **尿素循环**（肝）把 2 $\ce{NH4+}$ + $\ce{CO2}$ 转成尿素，耗 4 个高能磷酸键当量；鸟氨酸是催化剂式载体。
- 碳骨架分**生糖**（进丙酮酸/三羧酸中间物）与**生酮**（进乙酰 CoA）两类，经三个入口接入代谢地图。
- **一碳单位**（THF 运输）连接氨基酸与核苷酸合成，是细胞分裂的原料线，也是叶酸缺乏与化疗药的作用点。
