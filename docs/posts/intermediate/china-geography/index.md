# 中国地理（区域综合：自然地理与人文地理的整合）

以中国疆域为研究对象、贯通自然与人文两大系统的区域综合学科，是地理科学专业的核心必修课。从地形、气候、水文到人口、产业、城市，系统认识中国地表格局与区域分异，是理解国情、服务国土空间规划与区域发展战略的基础。

## 对标教材

- 赵济、王静爱《中国地理》（高等教育出版社）
- 王静爱《中国地理教程》（北京师范大学出版社）
- 赵济《新编中国自然地理》（高等教育出版社）
