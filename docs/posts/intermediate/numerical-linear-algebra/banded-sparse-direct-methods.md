## 为什么零也是一种信息

德谟克利特说「除了原子与虚空，别无他物」——对矩阵而言，**绝大多数真实矩阵都接近「虚空」**：有限元的刚度矩阵、电路的节点导纳矩阵、网络的邻接矩阵、偏微分方程的离散矩阵，非零元往往只占万分之一甚至更低。朴素地当成稠密矩阵处理，存储就要 $n^2$，分解要 $n^3$，等于「把虚空也存下来、也算进去」。**数值线性代数对「零」的态度是：零是信息，是可以被省掉的计算。**

本节对标 Golub 与 Van Loan《Matrix Computations》第 11 章，讲稀疏直接法（sparse direct methods）的三板斧：**怎么存（稀疏存储）→ 怎么算（带宽内分解）→ 怎么避免算太多（重排抗填元）**。它是有限元、电路仿真、图分析背后的无声功臣——你调用的每个 `scipy.sparse.linalg.splu`、`Eigen::SparseLU` 都在执行这套逻辑。

## 1 稀疏与带状：把零管起来

**核心概念：稀疏矩阵（sparse matrix）** 指非零元个数 $\mathrm{nnz}$ 远小于 $n^2$ 的矩阵；**带状矩阵（banded matrix）** 指非零元只在主对角线附近一个窄带内：$a_{ij} \neq 0 \Rightarrow |i-j| \leq \beta$，其中 $\beta$ 叫**带宽（bandwidth）**。

存储的第一原则：**绝不用 $n \times n$ 的二维数组装稀疏矩阵。** 标准做法是压缩行存储（CSR，compressed sparse row）：用三个数组分别记「每行第一个非零的位置」「每列的列号」「每列的值」，总存储 $O(\mathrm{nnz} + n)$。<span class="marginnote">带状矩阵更奢侈：只需要存 $n \times (2\beta+1)$ 的「斜带」数组。三对角矩阵（$\beta=1$）是极限常见特例——只需三个长度 $n$ 的数组，矩阵的「密度」从 $n^2$ 压缩到 $3n$。</span>**衡量稀疏直接法优劣的第一个指标，就是「分解后 $L$、$U$ 里有多少非零元」**——因为那才是真实的计算量与存储量。

### 存储格式一览：CSR、CSC 与 COO

除 CSR 外，工程里还有两个常见格式：**CSC（压缩列存储）** 与 **COO（坐标格式）**。CSC 是 CSR 的转置镜像，利于按列访问（如列主元消元）；COO 则是最直观的「(行, 列, 值)」三元组列表，常见于从文件或网络读入稀疏矩阵的中间态。<span class="marginnote">成熟库（SciPy、SuiteSparse、Eigen）内部通常以 CSR/CSC 承载实际运算，COO 只作建图与格式转换的中转站。理解这三个格式的相互切换，是读懂一切稀疏库源码的第一把钥匙——也是「零是信息」这一信念在数据结构层面的落地。</span>对规模到百万级的矩阵，格式选错（例如该用 CSR 却用了稠密二维数组）会让「能算」瞬间退化成「不可能算」。

## 2 带状矩阵：带宽内的 LU 是免费的

对带状矩阵做 LU（不选主元或主元不逃出带宽），有非常干净的结论：

**核心结论（带状 LU）：若 $A$ 上/下带宽均为 $\beta$，则 $L$ 的下带宽 $\leq \beta$、$U$ 的上带宽 $\leq \beta$——分解只在带内进行，带外保持为零。**

于是代价与存储都由带宽而非维数决定：

**存储**：$O(n \beta)$（不是 $n^2$）；
- **分解**：约 $2 n \beta^2$ flops（$\beta=1$ 时是 $O(n)$——三对角系统线性时间可解）；
- **前代回代**：各 $O(n \beta)$。

**直觉**：消元第 $k$ 步只影响「第 $k$ 行以下、$k + \beta$ 列以内」的块；每行至多 $\beta$ 个乘子，每个乘子至多与 $\beta$ 个元素相互作用。**带状结构在 LU 下自动「闭关」**——只要分解一开始就不越界，之后永远不会越界。<span class="marginnote">这就是为什么有限差分离散偏微分方程偏爱「规则网格」：规则网格天然给出固定带宽矩阵，直接法几乎免费。而有限元的不规则网格会破坏带状结构，逼出下一节的重排技术。</span>

### 特例：三对角系统的 Thomas 算法

带宽 $\beta = 1$ 的带状 LU 有个专门的名字——**Thomas 算法**。它把三对角矩阵分解成两个双对角因子 $L, U$，全程只动三条对角数组，代价 $O(n)$、存储 $O(n)$，**线性时间解三对角系统**。它出现在哪里？偏微分方程一维离散（热传导、扩散方程的隐式时间步）、三次样条插值的系数矩阵、以及一切「相邻网格点才相互作用」的物理问题。<span class="marginnote">Thomas 算法是「带状免费」的最纯粹体现：三个数组进，两个数组出，一个循环跑完，没有任何二次成本。工程上它常被手写进循环里而非调用通用库——因为太便宜、太常见。</span>把它与稠密 LU 对比：$n=10^6$ 的三对角系统，Thomas 算法毫秒级跑完，稠密 LU 需要 $10^{18}$ 量级的运算——**「带状 = 免费」在极端规模下就是「能算」与「不能算」的分界线**。

### 判断矩阵该存稠密还是稀疏

一个实用的经验法则：当 $\mathrm{nnz}$ 超过 $\tfrac{1}{3}n^2$ 时，稀疏存储的索引开销会反超稠密存储，直接按稠密处理反而更快。**「稀疏」是相对的**——一个 $n=100$、$\mathrm{nnz}=2000$ 的矩阵用稀疏格式纯属自找麻烦。规则是：先数 $\mathrm{nnz}$，再决定数据结构；先估填元，再决定算法。

**辨析｜易错点：选主元会破坏带状。** 部分选主元交换两行后，非零元可能跑到带宽之外——带宽不保。工程折中：**只用「带内选主元」**（在带宽范围内挑最大），带宽保住了，稳定性略打折；或用 Givens 旋转做带内正交化（QR），稳定性与带状两全。

## 3 填元：稀疏 LU 的头号大敌

稀疏 LU 与带状 LU 有一个根本区别：**稀疏结构不会在 LU 下自动保持**。消元过程中，原来为零的位置会被填成非零——这个现象叫**填元（fill-in）**。

**核心概念：填元（fill-in）** 是稀疏分解中由消元产生的「新生非零元」。它决定稀疏直接法的成败：填元越多，$L+U$ 越接近稠密矩阵，存储与计算量指数回升。<span class="marginnote">经典反例：箭头矩阵（第一行/第一列全非零、其余为对角）稀疏度极好，可任意消除顺序都会把 $L$ 填满成稠密——因为第 1 步的消元就把后面所有行「互相之间」的零填掉了。<strong>稀疏 ≠ 可分解得稀疏</strong>，两者之间隔着一道叫「顺序」的鸿沟。</span>

填元从哪里来？看消元的代数机制：第 $k$ 步把「行 $i$、行 $j$ 都含非零的列 $k$」作为「媒介」，$u_{ij}$ 需要减去 $l_{ik} \cdot u_{kj}$ 的乘积——**只要第 $k$ 列同时在第 $i$、第 $j$ 行非零，$A$ 原来的零 $(i,j)$ 就可能被填上**。

## 4 重排：与填元博弈的三种策略

填元的多少完全取决于**消元顺序**——而顺序可以自己挑！这就是稀疏直接法的核心博弈：**找一个行/列重排（ordering），使分解的填元最少。** 三大策略：

**最小度（minimum degree）**：贪心——每一步选「当前非零元最少的行」当主元。局部最优、实现简单，是历史上最普及的启发式。
- **嵌套剖分（nested dissection）**：递归地把矩阵对应图切成两半，先消「隔板」再消两半——对偏微分方程离散系统近乎最优。**2 维规则网格：分解代价从 $O(n^{3/2})$ 降到 $O(n \log n)$ 量级，存储从 $O(n^2)$ 降到 $O(n \log n)$**；3 维问题收益更明显。
- **谱方法 / 图论专用排序**：如 AMD、METIS、Scotch 等工业排序库，把图划分、谱分解、KL 型启发式全部打包成「几毫秒给出好顺序」的黑盒。

**图形视角**：矩阵的非零结构就是一张无向图（$a_{ij} \neq 0 \Rightarrow$ 顶点 $i$、$j$ 连边）。消元顺序 = 顶点的删去顺序；填元 = 删顶点时把它的邻居们「连成团」的新边。<span class="marginnote">这张图还定义了<strong>消去树（elimination tree）</strong>：每个顶点指向它消元时依赖的「祖先」，树的深度决定分解可以并行到多细、也可用于规划内存重用。现代稀疏 Cholesky 的并行化几乎全靠消去树。</span>一句话：**稀疏直接法的一半工程是「先把图整漂亮，再分解」。**

**实践的排序库**：你几乎不需要自己实现这些启发式。AMD（近似最小度，`scipy` 默认之一）、METIS（图划分）、Scotch（超图划分）都是久经考验的工业排序库，接口一行调用。对对称正定矩阵，稀疏 Cholesky 的符号分解还可以**复用**——同一非零结构、多组数值，只需重排一次、符号分解一次，之后数值分解反复跑。**这正是「先整图、再分解」思想在软件层面的落地。**

## 5 稀疏直接法的三步曲与总账

工业稀疏直接法（$P A = L U$ 或稀疏 Cholesky）分四个阶段：

1. **排序（ordering）**：选重排使填元少（上述三种策略之一）；
2. **符号分解（symbolic factorization）**：只按非零结构预测 $L$、$U$ 的填元分布，分配存储——**不碰数值**；
3. **数值分解（numeric factorization）**：在预定结构里填入数值，复用符号分解的结果；
4. **求解**：前代 + 回代，可用消去树做并行。

**总账怎么算**：稠密 LU 是 $O(n^3)$；稀疏矩阵的代价由**填元的数量与分布**决定，范围从「近乎 $O(n)$」（三对角、带状、树形图）到「接近稠密 $O(n^3)$」（几乎稠密的图）。**判断一个稀疏直接法划不划算，第一步永远是估算 $L$、$U$ 的填元量。**<span class="marginnote">什么时候迭代法更优？当矩阵巨大、填元失控（如 3 维大规模问题）时，Krylov 方法（第 7–8 节）以「每次 matvec」的成本取而代之，配合预处理器（第 8 节）成为主流。<strong>工程决策口诀：小中矩阵、填元可控 → 直接法；超大矩阵、填元爆炸 → 迭代法。</strong></span>

### 直接法还是迭代法：一张决策表

| 情形 | 首选 | 理由 |
| --- | --- | --- |
| 三对角 / 固定带宽 | Thomas / 带状 LU | $O(n)$ 线性时间，最优 |
| 中规模、填元可控（$\mathrm{nnz}(L+U)$ 不过分） | 稀疏直接法（AMD/METIS 重排） | 稳健、可复用分解 |
| 对称正定稀疏 | 稀疏 Cholesky | 一半成本、无需选主元 |
| 超大、填元爆炸（3 维 PDE 等） | 预处理迭代法（CG/GMRES） | 填元是直接法死穴 |
| 需要多次解同一矩阵 | 直接法（分解复用） | 多组右端项白赚 |
| 精度要求苛刻、病态 | 直接法 + 迭代细化 | 迭代法难保证后端精度 |

**一句话**：直接法赢在「稳健 + 复用」，迭代法赢在「一次 matvec 的成本」。**先估填元，再选阵营**——这是稀疏计算的最高原则。

## 6 公式解析：带状 LU 的带宽传播

为什么带状 LU 只在带内忙活？以第 $k$ 步消元为例，用公式看清「为什么填不到带宽外」：

- **第一步，写第 $k$ 步的更新**：对 $i, j > k$，$u_{ij} \leftarrow u_{ij} - l_{ik} \cdot u_{kj}$。要产生「新非零」，需要 $l_{ik} \neq 0$ 且 $u_{kj} \neq 0$ 同时成立。
- **第二步，用带限约束**：$l_{ik} \neq 0 \Rightarrow i \leq k + \beta$；$u_{kj} \neq 0 \Rightarrow j \leq k + \beta$（带内非零只在 $k$ 的 $\beta$ 邻域内）。于是 $u_{ij}$ 的非零只可能出现在 $i, j \leq k + \beta$ 的方块里。
- **第三步，收紧**：这个方块对应的行 $i$、列 $j$ 都满足 $|i - k|, |j-k| \leq \beta$，即 $|i - j| \leq 2\beta$——**但更进一步，逐行往后推可得 $L$ 下带宽 $\leq \beta$、$U$ 上带宽 $\leq \beta$**（消到第 $k$ 步时，第 $k$ 列以下每行至多与带内元素互动）。
- **第四步，总账**：每步只更新 $O(\beta^2)$ 个元素、$n$ 步共 $O(n\beta^2)$——**分解成本由带宽决定，与 $n$ 近乎线性**。这就是「三对角 $O(n)$、带状 $O(n\beta^2)$」的公式来源。

**对比学习**：同样的「谁给谁当媒介」的乘积机制，在稀疏非带情形下就变成填元——差别全在「非零的结构受不受控」。

## 7 小结

- **稀疏是信息**：CSR 等压缩存储把空间从 $O(n^2)$ 压到 $O(\mathrm{nnz})$；带状矩阵只需斜带数组，三对角只占 $3n$。
- **带状 LU**：$L$、$U$ 带宽 $\leq \beta$，分解 $O(n\beta^2)$、存储 $O(n\beta)$，带内闭关、免费；选主元会破带，需折中。
- **填元是头号大敌**：稀疏 LU 不自动保持稀疏，「谁给谁当媒介」的乘积机制填出新非零；箭头矩阵反例说明稀疏 ≠ 可分解得稀疏。
- **重排是博弈**：最小度（贪心）、嵌套剖分（分治，2 维 $O(n^{3/2}) \to O(n\log n)$）、工业图排序（AMD/METIS）——先整图再分解。
- 直接法四阶段：**排序 → 符号分解 → 数值分解 → 求解**；填元量决定成败；超大稀疏问题把接力棒交给迭代法。
- 记住两个「免费时刻」：**三对角 $O(n)$、带状 $O(n\beta^2)$**——稀疏结构用对顺序，直接法也能逼近线性成本。

**一门学科的地图**：稠密直接法、稀疏直接法、迭代法，三支流派分别回答「多少未知数」「零怎么省」「算子怎么迭代」；它们的交接处，正是你手里的工程决策——先估填元，再选阵营，永远不要对「虚空」做不必要的计算。

至此，《数值线性代数》专题的十一讲全部收官：从矩阵-向量乘法与正交化出发，途经 QR、SVD、条件数与稳定性、特征值算法、Krylov 与 CG/GMRES，最后回到 LU、Cholesky 与稀疏直接法。每一讲都围绕同一句话展开——**用正交性保证稳定，用谱与条件数衡量难易，用结构与稀疏换取速度**。下一段旅程，你可以带着这把尺子去量「从极限到大模型」路上的一切矩阵：神经网络的 Hessian、Transformer 的注意力矩阵、以及优化与概率背后的线性代数心脏。
