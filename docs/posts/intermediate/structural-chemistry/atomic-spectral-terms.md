## 为什么从光谱项开始

上一节的电子组态告诉你「电子住在哪个轨道」，但**一个组态对应多个能级**。
碳的 $1s^22s^22p^2$，实验光谱显示它有三组能量不同的能级，基态能级之下还藏着多重分裂。
为什么同样的两个 $2p$ 电子会有不同的能量？
答案在于电子之间的**角动量耦合**：每个电子自带自旋与轨道角动量，多个角动量按量子规则加合，产生一组离散的总角动量态。
这个精细的能级结构，就是**光谱项（spectral term）**要描述的对象。
<span class="marginnote">光谱项是连接「波函数」与「光谱实验」的枢纽：原子光谱的每一组谱线系，都能用光谱项之间的跃迁精确编号。
光谱学家的语言，从这一节开始就是你的语言。
</span>

对化学家而言，光谱项最大的价值有两个：其一，它决定了原子光谱的精细结构（选择定则、塞曼分裂）；
其二，**基态光谱项预言了化学行为**——配位场理论、稀土离子的磁性、顺磁共振都从光谱项出发。
本节从矢量耦合讲起，直到能写出任意原子的基态光谱项。

## 1 罗素–桑德斯耦合

多电子原子的角动量耦合有两种极端方案。
对轻、中原子（$Z$ 不太大），采用**罗素–桑德斯耦合（LS 耦合）**：先分别把所有电子的轨道角动量加合为总轨道角动量 $L$，把所有自旋加合为总自旋 $S$，再把 $L$ 与 $S$ 耦合为总角动量 $J$。
<span class="marginnote">另一种方案是 $jj$ 耦合（先耦合每个电子的 $l_i$ 与 $s_i$ 成 $j_i$，再合成 $J$），适用于重原子。
本专题主要用 LS 耦合，它解释了轻元素的绝大多数化学。
</span>

角动量的加合不是经典算术，而是**矢量量子化**：两个角动量 $l_1, l_2$ 合成 $L$ 时，$L$ 取 $|l_1 - l_2|$ 到 $l_1 + l_2$ 的每一个整数值。
于是两个 $p$ 电子（各 $l=1$）的 $L$ 只能取 $0, 1, 2$——对应 $S, P, D$ 光谱项；
自旋各 $\frac12$，总自旋 $S = 0$ 或 $1$。
$L$ 与 $S$ 的不同组合给出能量不同的态，这就是组态内能级分裂的来源。

**辨析｜易错点：** $S$ 有两个身份——总自旋量子数（可取的数值，如 $0, 1, 2$）和轨道字母 $s$ 的谱号（$L=0$）。光谱项记号里上标用 $S$ 的数、字母用 $L$ 的谱号，两者千万别混。习惯上用大写 $L, S, J$ 表示总量子数，小写 $l, s, j$ 表示单电子量子数。

## 2 光谱项的记号

一个光谱项写成

$$^{2S+1}L_J$$

四个部件各司其职：

- **上标 $2S+1$**：自旋多重度，等于 $2S+1$。$S=0$ 时是 1（单重态），$S=1$ 时是 3（三重态），$S=\frac32$ 时是 4（四重态）……
- **字母 $L$**：总轨道角动量谱号，$L=0,1,2,3,4,5$ 对应 $S, P, D, F, G, H$（沿用光谱学的字母传统）。
- **下标 $J$**：总角动量量子数，取 $|L-S|$ 到 $L+S$ 的每个值（步长 1）。

以碳基态 $2p^2$ 为例：$L = 0,1,2$，$S = 0,1$，可组合出 $^1S, ^3P, ^1D$ 三个光谱项。再按 $J$ 细分：$^3P$ 因 $J = 0,1,2$ 又劈成三个能级 $^3P_0, {}^3P_1, {}^3P_2$。**一个组态 → 几个光谱项 → 若干精细能级**，这条分裂链条正是原子光谱「线系内再细分」的结构来源。<span class="marginnote">多重度为什么叫「多重」？因为它决定一条谱线能劈成几条：多重度为 3 的态在磁场中劈成 3 个分量，这是塞曼效应、也是电子顺磁共振的读解基础。</span>

## 3 洪特规则与基态光谱项

同一组态产生的多个光谱项，能量高低由**洪特规则**排序：

1. **多重度最大者能量最低**（$S$ 最大）——因为交换能最大。
2. **$S$ 相同者，$L$ 最大者能量最低**——因为大 $L$ 意味着电子尽量同向运动、平均距离更大。
3. **多重度相同的同一谱项**：亚壳层**未半满**时 $J$ 最小者能量最低，**超过半满**时 $J$ 最大者能量最低。

以碳为例：$2p^2$ 的多重度最大是 $S=1$，故 $^3P$ 最低；$^3P$ 中 $L=1$ 唯一；$p^2$ 未半满（$2p$ 容量 6，2 个电子），故 $J$ 最小者 $^3P_0$ 为基态。氧 $2p^4$ 与之对称：$^3P$ 中因超半满取 $J$ 最大，基态是 $^3P_2$。<span class="marginnote">第三规则是洪特规则里最反直觉的一条：未半满取 $J_{\min}$、超半满取 $J_{\max}$。它源于自旋–轨道耦合的符号翻转，电子少于半满时 $L$ 与 $S$ 反平行（$J = |L-S|$）更稳定。</span>

## 4 公式解析：$^{2S+1}L_J$ 怎么算

用氮原子（$1s^22s^22p^3$）走一遍完整推导，三条规则逐个落地：

- **第一步，求 $S$**：$2p$ 有 3 个电子，洪特规则要求它们分占三个 $p$ 轨道且自旋平行，故 $S = 3 \times \frac12 = \frac32$，多重度 $2S+1 = 4$。
- **第二步，求 $L$**：三个电子各占 $m = +1, 0, -1$ 轨道，$M_L = 1 + 0 + (-1) = 0$，故 $L = 0$，谱号为 $S$。于是光谱项是 $^4S$。
- **第三步，求 $J$**：$p^3$ 未半满（$2p^3$ 恰为半满，属「≤ 半满」，取 $J_{\min}$），$J = |L - S| = \frac32$。基态光谱项：

$${}^4S_{3/2}$$

把「碳、氮、氧、氟」四个轻元素的基态光谱项列成表，模式一目了然：

| 元素 | 组态 | 基态光谱项 |
| --- | --- | --- |
| C | $2p^2$ | $^3P_0$ |
| N | $2p^3$ | $^4S_{3/2}$ |
| O | $2p^4$ | $^3P_2$ |
| F | $2p^5$ | $^2P_{3/2}$ |

多重度 $2, 4, 3, 2$ 的起伏，正是洪特规则在 $p$ 壳层依次填充时的「心跳」——氧的顺磁性（两个未配对电子）也由此而来。

## 5 光谱项决定了光谱与磁性

光谱项不是抽象的标签，它直接控制可观测：

- **选择定则**：电偶极跃迁要求 $\Delta L = \pm 1$、$\Delta S = 0$、$\Delta J = 0, \pm 1$（但 $J=0 \to J=0$ 禁戒）。光谱项的量子数关系决定了哪些跃迁「允许」、哪些「禁戒」，也就决定了谱线系的结构。
- **磁性**：未成对电子数越多，磁矩越大。基态光谱项给出未成对电子数（由 $S$ 读出），直接预言原子的顺磁性与磁矩大小——这是《配位场理论》里磁矩公式 $\mu = \sqrt{n(n+2)}\ \mu_B$ 的原子级源头。<span class="marginnote">O$_2$ 的顺磁性、Fe$^{3+}$ 的高自旋态，宏观上都是「未成对电子数」的表现，而「未成对电子数」正是光谱项的 $S$ 决定的。</span>
**精细结构**：$J$ 的劈裂在无外场时已存在（自旋–轨道耦合），加磁场后每个 $J$ 再按 $M_J$ 劈裂——塞曼效应由此而来，也是原子钟、磁共振技术的物理基础。

**辨析｜易错点：** 光谱项的多重度 $2S+1$ 不等于未成对电子数本身。两个未成对电子自旋平行给出 $S=1$、多重度 3，但未成对电子数是 2。读未成对电子数要看 $S$ 的贡献，不是直接看多重度的数字。

## 5.5 碱金属的双线：光谱项在真实谱线上的签名

光谱项不只是理论标签，它在真实光谱里有直接可见的签名——**碱金属的双线结构**。钠的黄线（589.6 nm 与 589.0 nm，仅差 0.6 nm）是著名的双线，其来源正是光谱项的自旋–轨道劈裂。

钠的价电子组态是 $3s^1$，激发态 $3p^1$ 的光谱项为 $^2P$（$S=\tfrac12$，$L=1$）。按 $J$ 取 $|L-S|$ 到 $L+S$，$^2P$ 劈成 $^2P_{1/2}$ 与 $^2P_{3/2}$ 两个能级，能量差即自旋–轨道耦合能。电子从这两个精细能级跃迁回 $^2S_{1/2}$，就产生波长只差零点几纳米的两条线——**双线**。

用这个例子走一遍「组态 → 光谱项 → 精细能级 → 谱线」的完整链条：

**第一步，写组态**：$3p^1$，一个电子，$s=\tfrac12$, $l=1$。
**第二步，定光谱项**：$L=1$（$P$），$S=\tfrac12$，多重度 2 → $^2P$。
**第三步，劈 $J$**：$J = \tfrac12, \tfrac32$，得 $^2P_{1/2}$ 与 $^2P_{3/2}$。
**第四步，读跃迁**：双线正是这两个能级分别到 $^2S_{1/2}$ 的跃迁。

双线的间距随原子序数增大而增大（自旋–轨道耦合 $\propto Z^4$）——碱金属谱线从钠的细双线到铯的明显分裂，是原子「越重、耦合越强」的直观证据。<span class="marginnote"><strong>历史注脚</strong>：光谱学家正是靠双线的规律，比量子力学更早地「数」出了电子自旋的存在——乌伦贝克与古德斯米特提出自旋时，引用的实验证据就是碱金属双线的 2 倍间隔。</span>

## 6 小结

- 同一组态因角动量耦合分裂成多个**光谱项**，记号 $^{2S+1}L_J$。
- LS 耦合先合 $L$、$S$，再合 $J$；重原子转用 $jj$ 耦合。
- **洪特三规则**决定光谱项能量：$S$ 大优先、$L$ 大优先、$J$ 按半满取小/大。
- 基态光谱项可由「求 $S$ → 求 $L$ → 求 $J$」三步机械算出，如 N 为 $^4S_{3/2}$。
- 光谱项通过**选择定则**控制光谱线系，通过 $S$ 控制磁性——是原子性质与光谱实验之间的通用翻译器。
