## 为什么从配位场理论开始

周期表里最丰富多彩的化学属于过渡金属：蓝宝石的蓝色、血液中血红蛋白的红色、血红蛋白载氧/脱氧时颜色的翻转——这些都来自 $d$ 电子在配体电场中的能级分裂。
**晶体场理论（crystal field theory, CFT）**把问题极端简化：把配体当成点电荷或点偶极，只问它们产生的静电场如何劈裂中心金属的 $d$ 轨道。
<span class="marginnote">CFT 是个「故意天真」的模型——它甚至不讨论共价键，却在解释颜色、磁性、配位几何上极其成功。
它和价键、MO 一样，都是同一量子问题的不同近似方言。
</span>

本节从「$d$ 轨道为什么分裂」讲起，给出八面体场的定量分裂，然后用一把能量尺子（晶体场稳定化能）解释高低自旋与光谱化学序。
配位场理论（LFT）作为 CFT 的分子轨道化版本，在本节末补上它最重要的修修补补。

## 1 $d$ 轨道为什么分裂

自由过渡金属离子的五个 $d$ 轨道简并（能量相等）。
一旦把配体放在六个方向（$+x, -x, +y, -y, +z, -z$），对称性被打破：配体是负电荷（或负端），会**排斥**指向自己的 $d$ 轨道电子。

五个 $d$ 轨道因此分成两组：

- **$e_g$ 组**：$d_{z^2}$ 与 $d_{x^2-y^2}$，瓣沿坐标轴方向伸展，正对六个配体，受排斥强、能量升高。
- **$t_{2g}$ 组**：$d_{xy}, d_{xz}, d_{yz}$，瓣指向坐标轴的夹缝（45°方向），避开配体，受排斥弱、能量相对降低。

于是八面体场把简并的 $d$ 能级劈成两组，间隔记为**晶体场分裂能** $\Delta_o$（下标 $o$ 表示 octahedral）。
<span class="marginnote">符号 $t_{2g}, e_g$ 来自群论不可约表示：$t$ 表示三维简并、$e$ 表示二维简并，$g$ 表示中心对称。
到《对称操作与点群》一节，这套符号会成为严格的对称性语言。
</span>

## 2 八面体场的定量分裂

设分裂能 $\Delta_o = 10Dq$，且能级重心守恒（五个轨道平均能量不变），则

$$E(e_g) - E(t_{2g}) = \Delta_o = 10Dq, \qquad E(e_g) = +\frac{3}{5}\Delta_o, \qquad E(t_{2g}) = -\frac{2}{5}\Delta_o$$

**辨析｜易错点：** 重心守恒是量子力学「平均能量不变」的体现——劈裂只是重新分配，不创造也不消灭能量。初学者常误以为「$e_g$ 升高、$t_{2g}$ 不变」，正确的是**两组一升一降、总量为零**。这也是晶体场稳定化能计算里 $-\frac25$ 与 $+\frac35$ 两个系数的来源。

**晶体场稳定化能（CFSE）** 是电子占据分裂能级后相对「未分裂时球对称分布」的能量收益：

$$\text{CFSE} = \left(-0.4\,n_{t_{2g}} + 0.6\,n_{e_g}\right)\Delta_o$$

其中 $n_{t_{2g}}$ 与 $n_{e_g}$ 分别是两组轨道上的电子数。
CFSE 是负值（稳定化），它解释了配合物的很多怪癖：为什么 $d^3$（如 $\ce{[Cr(H2O)6]^{3+}}$）异常稳定、为什么晶格能、离子半径随 $d$ 电子数呈「双驼峰」变化——都是 CFSE 在作祟。
<span class="marginnote">CFSE 是「结构化学 → 无机化学」最锋利的一座桥：配位化合物的热力学稳定性、过渡金属的离子半径序列、乃至许多矿物晶体场的颜色，都可以用这一个数做第一近似。
</span>

## 3 高低自旋的判据：$\Delta$ 与成对能的拉锯

$d^4$–$d^7$ 离子面临一个抉择：电子是优先占据 $t_{2g}$ 配对（**低自旋**），还是按洪特规则往 $e_g$ 里塞自旋平行电子（**高自旋**）？
判据是分裂能 $\Delta$ 与**成对能 $P$**（让两个电子挤进同一轨道的能量代价）之比：

- $\Delta > P$：低自旋，电子先填满 $t_{2g}$。强场配体（$\ce{CN-}$）分裂能大，倾向低自旋。
- $\Delta < P$：高自旋，电子尽量分占、自旋平行。弱场配体（$\ce{F-}, \ce{H2O}$）分裂能小，倾向高自旋。

以 $\ce{[Fe(CN)6]^{4-}}$（$d^6$，低自旋）为例，全部六个电子填进 $t_{2g}$，**无未成对电子、反磁**；
而 $\ce{[Fe(H2O)6]^{2+}}$（$d^6$，高自旋）有四个未成对电子、**顺磁**——同一金属、不同配体，磁性截然相反。
<span class="marginnote">这是 CFT 最直观的胜利：不需要任何共价键语言，单凭「$\Delta$ 与 $P$ 谁大」就能预言一个配合物磁不磁。
实验上用磁天平一测便知。
</span>

配体按分裂能大小排成的序列叫**光谱化学序**（spectrochemical series）：

$$\ce{I- < Br- < Cl- < F- < OH- < H2O < NH3 < en < NO2- < CN- < CO}$$

序列两侧的规律明显：电负性大、难极化的配体（卤素）给弱场，π 受体配体（$\ce{CO}$、$\ce{CN-}$）给强场。后者能「接受」金属 $d$ 电子反键，形成 **π 反键（dπ–pπ 反馈）**，把 $\Delta$ 撑大——这正是晶体场理论需要升级为配位场理论的第一个理由。

## 4 公式解析：$d^4$ 离子的 CFSE 与自旋选择

用 $d^4$ 高自旋离子（如 $\ce{[Mn(H2O)6]^{2+}}$）完整算一遍：

- **第一步，定组态**：$d^4$ 高自旋，电子按洪特规则分占：$t_{2g}^3\, e_g^1$（三个 $t_{2g}$ 各一个电子、一个 $e_g$ 有一个电子，四个未成对）。CFSE：

$$\text{CFSE} = -0.4 \times 3 + 0.6 \times 1 = -0.6\Delta_o$$

- **第二步，换自旋**：若改低自旋，组态 $t_{2g}^4$（四个电子全在 $t_{2g}$，其中一对配对），CFSE $= -0.4 \times 4 = -1.6\Delta_o$——能量低得多，但多付一份成对能 $P$。
- **第三步，比大小**：低自旋胜出当且仅当 $1.6\Delta_o - 0.6\Delta_o > P$，即 $\Delta_o > P$。弱场 $\ce{H2O}$ 使 $\Delta_o$ 小，故 Mn(II) 高自旋（实验：Mn$^{2+}$ 有 5 个未成对电子，因 $d^5$ 高自旋恰为半满）。强场如 $\ce{[Fe(CN)6]^{3-}}$（$d^5$）则低自旋。

**辨析｜易错点：** CFSE 是相对「球对称场」的能量收益，不是配合物的总键能。两个 CFSE 不同的组态比稳定性时，还要把成对能 $P$ 一起算进去——只比 CFSE 会得出「永远低自旋稳定」的错误结论。

## 5 颜色、变形与配位场理论的升级

$d$–$d 跃迁是配合物颜色的来源：$\ce{[Ti(H2O)6]^{3+}}$ 的 $d^1$ 电子从 $t_{2g}$ 跳到 $e_g$，吸收绿光、呈紫色。能隙 $\Delta_o$ 对应可见光波段，所以**配合物颜色≈配体场强度的直观读数**。<span class="marginnote">这个关系还被做成了「颜色的顺序」经验律：同一金属配不同配体时，配体场越强，吸收波长越短（颜色越偏紫）。光谱化学序的「光谱」二字，正来自它最初是依吸收颜色排序的。</span>

但纯 CFT 有两个硬伤：其一，它把配体当点电荷，无法解释共价成分（顺磁的 $\ce{[CuCl4]^{2-}}$ 配体到金属的电荷转移）；
其二，它无法解释**姜–泰勒效应**——$d^9$ 离子（如 $\ce{Cu^{2+}}$）的配合物总被拉长成四方变形，因为 $\ce{Cu^{2+}}$ 的 $e_g$ 上只有一个电子，拉长 $z$ 轴方向的配体可以降低 $d_{z^2}$ 的能量、稳化体系。
<span class="marginnote">姜–泰勒定理：任何非线性分子若电子态简并，必发生形变以消除简并、降低能量。
铜氨配合物的深蓝、许多 Jahn–Teller 活性离子的八面体畸变，都是它的现场。
</span>

**配位场理论（ligand field theory, LFT）** 是 CFT 的分子轨道升级版：把配体的轨道与金属 $d$ 轨道做 LCAO，形成成键/反键分子轨道，$\Delta_o$ 于是被重新解释为「金属–配体成键与反键轨道之间的能隙」。它的语言更准确，但 CFT 的定性能级图（$t_{2g}$ 低、$e_g$ 高）在大多数场合足够好用，所以两套理论一直并存。

## 5.5 CFSE 的宏观签名：水合焓的双驼峰

CFSE 不是一个只在理论里存在的数，它直接印在实验数据上。第二过渡系二价离子的**水合焓**（$\ce{M^{2+} + aq -> [M(H2O)6]^{2+}}$ 的放热）随 $d$ 电子数变化，呈现出著名的**双驼峰**曲线：从 $\ce{Ca^{2+}}$（$d^0$）到 $\ce{Zn^{2+}}$（$d^{10}$），水合焓先升、后降、再升，形成两个峰。

三个要点把这条曲线与 CFSE 挂钩：

- **基线是有效核电荷**：随 $Z$ 增大、离子半径减小，水合焓整体应单调增大——这是「无 CFSE」时的预期。
- **双驼峰 = CFSE 的叠加**：$d^3$（$\ce{V^{2+}}$）与 $d^8$（$\ce{Ni^{2+}}$）处水合焓比基线**更低**（更稳定），恰好是 CFSE 最大的两个电子数（$t_{2g}^3$ 与 $t_{2g}^6e_g^2$）。$d^5$（$\ce{Mn^{2+}}$）处 CFSE 为零，水合焓跌回基线——曲线在此凹下去。
- **读出分裂能**：把双驼峰与基线之差除以电子数，可反过来估算 $\Delta_o$ 的量级——热化学数据成为晶体场分裂能的独立探针。<span class="marginnote"><strong>模式</strong>：理论预言「CFSE 在 $d^3, d^8$ 最大」，实验画出的水合焓恰好在那两个点最深——结构化学「理论—实验互证」的又一现场。</span>

**辨析｜易错点：** 双驼峰出现在「水合焓」这类同时含多种贡献的热力学量里，必须先把「离子半径随 $Z$ 收缩」这个基线趋势剥掉，剩下的起伏才是 CFSE。直接看原始曲线的形状而不扣除基线，会把「半径收缩」误读成「CFSE」。

## 6 小结

- 配体的静电场打破 $d$ 轨道简并：八面体场中五裂为二，$t_{2g}$（低）与 $e_g$（高），间隔 $\Delta_o = 10Dq$，重心守恒。
- **CFSE** $= (-0.4 n_{t_{2g}} + 0.6 n_{e_g})\Delta_o$，量化了分裂带来的稳定化收益。
- **高低自旋判据**：$\Delta$ 与成对能 $P$ 比大小；弱场高自旋、强场低自旋，磁性随之翻转。
- **光谱化学序**把配体按 $\Delta$ 大小排队，π 受体配体靠反馈键撑大分裂能。
- 配合物颜色来自 $d$–$d 跃迁；姜–泰勒效应与 LFT 是 CFT 的两项重要升级。

在下一节，我们走出共价键与配位键，进入化学世界里最柔软也最普适的一类相互作用：不形成化学键也能把分子拉在一起——这就是**弱相互作用：氢键与范德华**。
