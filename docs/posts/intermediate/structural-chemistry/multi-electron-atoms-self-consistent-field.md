## 为什么从多电子原子开始

氢原子只有核与一个电子，它的薛定谔方程可以严格求解——但化学世界里几乎没有第二个这样的原子。
氧、铁、铜，每一个都是「核 + 许多互相排斥的电子」。
一旦加上电子与电子之间的排斥项，方程立刻变得不可分离、没有解析解。
多电子原子是人类第一次被迫面对「**精确不可解，但近似可控**」的量子化学问题，而解决它的思路——**自洽场（self-consistent field, SCF）**——将在后面《分子轨道理论》《配位场理论》里一次次复活。
<span class="marginnote">这条方法论链贯穿全专题与《计算化学》：SCF 是哈特里–福克、密度泛函等一切现代量子化学计算的祖先。
</span>

本节要回答三个问题：多电子原子难在哪？
如何用「有效核电荷」近似它？
近似解怎么一层层迭代到自洽？
学完你会发现，「电子组态」「能级交错」「有效核电荷」这些无机化学里的经验规则，全部出自同一种近似逻辑。

## 1 多电子原子的方程：加一项就无解

对一个 $Z$ 核、$N$ 电子的原子，定态薛定谔方程（原子单位下）是

$$\left[-\frac{1}{2}\sum_{i=1}^{N}\nabla_i^2 - \sum_{i=1}^{N}\frac{Z}{r_i} + \sum_{i<j}\frac{1}{r_{ij}}\right]\Psi = E\Psi$$

方括号里前三项分别是电子动能、电子—核吸引、**电子—电子排斥**。正是最后一项 $\sum_{i<j}\frac{1}{r_{ij}}$ 让方程变得不可分离：它同时依赖两个电子的坐标 $r_i$ 与 $r_j$，波函数无法写成单电子波函数的简单乘积。<span class="marginnote">即使是一个「仅仅」拥有 10 个电子的氖，这个方程的未知函数也依赖 30 个坐标，远超任何解析手段。多体问题是量子力学的天堑，也是整个量子化学存在的理由。</span>

物理直觉给出了出路：既然每个电子都「感受到」其他电子的平均排斥，为什么不把这种排斥**平均成一个平滑的势场**，让每个电子在「核电荷 + 平均电子场」里独立运动？这样 $N$ 电子问题就退化为 $N$ 个单电子问题——这就是**中心力场近似**与自洽场方法的起点。

## 2 屏蔽效应与有效核电荷

在中心力场近似下，每个电子的势能写成

$$V_i(r_i) = -\frac{Z_{\text{eff}}(r_i)}{r_i}$$

其中 $Z_{\text{eff}} = Z - \sigma$ 称为**有效核电荷**，$\sigma$ 是**屏蔽常数**。
它把「其他电子对我的排斥」折算成「核电荷被抵消了一部分」——内层电子挡在核与外层电子之间，像一层「盾牌」削弱了核的吸引，这就是**屏蔽效应（shielding）**。

**辨析｜易错点：** 屏蔽效应与电子之间的**交换关联**不是一回事。屏蔽源于经典的库仑排斥，是平均场的产物；而交换效应源于「电子是全同费米子、波函数须反对称」这一纯量子要求——两个同自旋电子彼此「回避」是统计性的，无经典对应。两者在多电子原子中同时存在，常被混为一谈。

要快速估算屏蔽常数，斯莱特（Slater）给出了一套经验规则：把电子按 $(1s)(2s,2p)(3s,3p)(3d)(4s,4p)\cdots$ 分组，被屏蔽电子右侧的组贡献 0；
同组其他电子贡献 0.35（1s 组内为 0.30）；
$(n-1)$ 层电子贡献 0.85；
更内层贡献 1.00。
这些数字粗糙，但能定性解释大量周期律现象。
<span class="marginnote">Slater 规则是「经验的量子化学」典型样本：不追求精确，只求给出可手算的定性趋势。
精确的 $\sigma$ 要由自洽场解本身定义——见下一节。
</span>

## 3 自洽场方法：让势场自己说服自己

哈特里（1928）把「平均排斥」做成了可以迭代执行的算法：

- **第一步，猜**：给每个电子猜一个初始轨道 $\psi_i$（比如从类氢轨道开始）。
- **第二步，构造势场**：用当前轨道算出电子密度，求出每个电子感受到的「平均场」$\langle V_i \rangle$。
- **第三步，求解**：在平均场里解每个电子的单电子方程，得到新的轨道与能量。
- **第四步，自洽判定**：用新轨道重新构造势场，再求解……如此循环，直到前后两轮得到的轨道与能量差小到忽略不计——此时称**自洽**，解不再随迭代改变。

弗克（Fock）在哈特里基础上加入交换项，得到**哈特里–弗克方程**，单电子算符称为**福克算符** $\hat{F}$：

$$\hat{F}\,\psi_i = \varepsilon_i\,\psi_i$$

它的物理图景是：**每个电子都在所有电子的平均场里运动，而这个平均场又由所有电子的轨道共同构成**——场塑造电子，电子塑造场，最终两者互相咬合成一个不动点。<span class="marginnote">自洽场的思想远远超出化学：任何「环境决定个体、个体反塑环境」的系统——从凝聚态物理的能带论到人工智能里的自举训练——都是同一种不动点逻辑。</span>

## 4 公式解析：多电子原子的轨道能量

在自洽场框架下，第 $i$ 个电子的轨道能量近似为

$$\varepsilon_i \approx -\frac{1}{2}\frac{Z_{\text{eff},i}^2}{n_i^2}\ \text{(a.u.)}$$

拆解三步：

- **第一步，看形式**：它长得很像氢原子能级 $E_n = -Z^2/(2n^2)$，只是把 $Z$ 换成了 $Z_{\text{eff}}$。这正说明多电子原子是用「修改后的类氢模型」逼近的。
- **第二步，看 $Z_{\text{eff}}$ 的含义**：$Z_{\text{eff}}$ 不是常数，随 $r$ 变化——在核附近几乎没有屏蔽，$Z_{\text{eff}} \approx Z$；在远处被完全屏蔽，$Z_{\text{eff}}$ 趋向 $Z - (N-1)$。轨道能量的近似用某个代表性数值代表整条曲线。
- **第三步，看 $n$ 与 $l$ 的依赖**：对多电子原子，同一主量子数下 $s, p, d$ 的能量并不相等，因为穿透能力不同：$s$ 轨道在核附近有显著振幅（「穿透」进内层），受到的屏蔽少、能量更低，于是

$$E_{ns} < E_{np} < E_{nd} < E_{nf}$$

同一壳层的能级被 $l$ 劈开，这就是「能级交错」的微观根源。<span class="marginnote">穿透（penetration）与屏蔽（screening）是一枚硬币两面：能钻到核附近 = 穿透强 = 屏蔽弱 = 能量低。周期表中 $4s$ 先于 $3d$ 填充，正是因为 $4s$ 穿透更强，填进 $3d$ 前 $4s$ 更稳定。</span>

自洽场方程的解还有一个漂亮的副产品——**库普曼斯定理**：从一个原子的 HF 解里拿走一个电子（或加进一个），体系能量的变化近似等于被移走/加入电子的**轨道能量 $\varepsilon_i$ 的负值**。于是电离能 ≈ $-\varepsilon_i$，电子亲和能 ≈ $-\varepsilon_i$（对空轨道）——**HF 轨道能量可以直接预测电离能**，这是光电子能谱（测分子/原子电离能）与量子化学计算对账的理论桥梁。<span class="marginnote"><strong>注意</strong>：库普曼斯定理是近似——忽略电子弛豫与关联修正，实际电离能与之差几 eV 到零点几 eV。它的价值在于给「轨道能量」一个可观测的意义，而不是精确预测。</span>

这条定理还解释了 X 射线光电子谱（XPS）的直觉：XPS 每个元素的特征峰位置 ≈ 该原子某轨道能量的负值——**谱图上的每条峰，就是库普曼斯意义上的一条轨道能量**。它也让「轨道能量」这个计算量第一次有了「可测」的实证身份，成为连接量子化学计算与表面分析实验的纽带。

## 5 能级交错与原子实

有了轨道能量，电子组态的构造规则就齐了：**泡利不相容原理 + 能量最低原理 + 洪特规则**。多电子原子的填充顺序大致是

$$1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p < 7s$$

注意 $4s$ 排在 $3d$ 之前、$6s$ 排在 $4f$ 之前——这正是上面「$s$ 穿透强」的直接后果。
钾的电子组态是 $[\text{Ar}]4s^1$ 而非 $[\text{Ar}]3d^1$，实验测得如此，自洽场算出的轨道能量也如此。
<span class="marginnote">严格说，「$4s$ 能量低于 $3d$」是中性原子轨道能量的结论；
一旦电离，$3d$ 与 $4s$ 的相对能量可能反转（如过渡金属阳离子 $3d$ 更稳定）。
这也是《配位场理论》里过渡金属化学的伏笔。
</span>

**辨析｜易错点：** 「填充顺序」是构造的**顺序**，不是电离的**顺序**。铁的组态是 $[\text{Ar}]3d^64s^2$，但失去电子时先丢的是 $4s$ 电子——因为电离前后原子结构不同，不能拿中性原子的填充顺序套电离过程。

这条辨析在《配位场理论》里还有更深一层：当配体把 $3d$ 能级压低（强场），$3d$ 轨道甚至会比 $4s$ 更稳定，于是配合物中的「有效组态」可能与自由原子的填充顺序相反——判断配合物电子数时，要先看场的强弱。

## 6 小结

- 多电子原子因**电子—电子排斥项**不可严格求解，只能用平均场近似。
- **中心力场近似**把排斥折算为有效核电荷 $Z_{\text{eff}} = Z - \sigma$；屏蔽与穿透决定 $Z_{\text{eff}}$。
- **自洽场（SCF）** 以迭代方式让「场决定电子、电子决定场」收敛到不动点，即哈特里–弗克方程的解。
- 同一 $n$ 下轨道能量按 $s < p < d < f$ 排列，源于穿透能力的差异；这解释了周期表中的**能级交错**。
- 填充顺序由**泡利原理 + 能量最低 + 洪特规则**共同给出；填充顺序 ≠ 电离顺序。
