## 为什么从光与褪黑素开始

上一篇讲了主钟 SCN 如何接光、如何输出。可 SCN 本身藏在颅骨深处，光进不去；它又是靠什么把「现在是几点」变成全身都知道的信号的？答案是两种媒介：**光**从眼睛进来，**褪黑素（melatonin）**从松果体释放出去。两者一进一出，构成授时系统最核心的一对「输入—输出」<span class="marginnote">褪黑素常被误解为「安眠药」或「助眠激素」。它真正的功能不是让你睡着，而是向全身广播「现在是黑夜」——它是时间信号，不是催眠药。这个区分是理解全部时间药理学的前提。</span>

这条链路把前面几篇串成完整的一圈：**光 → ipRGC → SCN → 交感神经 → 松果体 → 褪黑素 → 血液与脑脊液 → 全身（包括 SCN 自己）**。理解光授时，就理解了时差、轮班、季节性情绪障碍的共同机制；理解褪黑素，就理解了市面上几乎所有「助眠补剂」到底在干什么、什么时候用才有效。

## 1 褪黑素：黑暗的化学信使

褪黑素的合成发生在**松果体（pineal gland）**——一个豌豆大小的内分泌腺，位于脑的几何中心附近。它的生物合成路径是色氨酸代谢的一条侧枝：

**色氨酸 → 5-羟色胺（血清素）→ N-乙酰血清素 → 褪黑素**。其中两步关键酶是 **AANAT**（芳基烷基胺 N-乙酰转移酶）与 **HIOMT/ASMT**（羟吲哚-O-甲基转移酶）。AANAT 是限速酶：它的活性在夜间暴涨约 **100 倍**，把整条流水线的产量从白天几乎为零推到夜间的峰值。<span class="marginnote">AANAT 的昼夜调控就是分子钟输出到内分泌的经典范例：SCN 通过交感神经在夜间给松果体释放去甲肾上腺素，经 β1-肾上腺素能受体 → cAMP → PKA 通路，快速磷酸化并稳定 AANAT 蛋白。光线一照，AANAT 失活，褪黑素合成数分钟内回落。</span>

褪黑素的昼夜曲线因此非常「干净」：**白天几乎测不到，入夜后上升，午夜前后达峰，清晨回落**。它在血浆中的半衰期只有约 30–50 分钟——涨得快、落得也快，正适合当一个高时间分辨率的「黑夜信号」。

## 2 光如何抑制褪黑素：一条三级神经链

褪黑素「只在夜间分泌」这一性质，是被光实时控制的。光照抑制褪黑素并非松果体直接感光，而是经过一条在上一篇已经预告的神经链路：

**SCN → 室旁核（PVN）→ 脊髓中间外侧柱 → 颈上神经节 → 松果体**。<span class="marginnote">注意这条链路的奇妙之处：视网膜感光后，信号先到 SCN，再沿交感神经系统一路「绕道」到颈部的交感神经节，最后才抵达大脑深处的松果体。解剖上绕了一大圈，换来的却是「光能实时关掉褪黑素」这一精确开关。</span>光线照进眼睛 → ipRGC 把「明亮」信号送给 SCN → SCN 抑制交感输出 → 松果体的去甲肾上腺素释放减少 → AANAT 失活 → 褪黑素合成停止。

这条链路的两个推论极其重要：

**第一，抑制是即时的**。夜间只要开灯，褪黑素水平几分钟内就开始下降——这是「半夜刷手机」为什么扰乱睡眠的直接机制。

**第二，抑制不是全或无，而是剂量依赖的**。室内灯光（100–200 勒克斯）只能部分抑制，户外强光（数千勒克斯）几乎完全压掉夜间褪黑素。光谱也很关键：**蓝光（约 480 nm，与黑视素峰值重合）抑制最强**。

## 3 公式解析：光照强度与褪黑素抑制的剂量-反应关系

光照抑制褪黑素遵循典型的剂量-反应曲线，可以用一条希尔函数近似描述。设抑制率 $S$（0 到 1），光照强度 $I$（勒克斯），则：

$$
S = \frac{S_{\max}}{1 + (I_{50} / I)^n}
$$

其中 $S_{\max}$ 是最大抑制率，$I_{50}$ 是达到半最大抑制所需的光强，$n$ 是希尔系数。分三步理解：

- **第一步，强度轴**：$I_{50}$ 约在 **100–200 勒克斯**量级——这正好是普通室内照明的亮度。也就是说，**我们在房间里开着灯工作，就已经在对夜间褪黑素施加半强度的抑制**；只有降到昏暗（<30 勒克斯，即「暗光」），褪黑素才能完整分泌。
- **第二步，形状**：希尔系数 $n>1$ 让曲线在 $I_{50}$ 附近呈陡峭的 S 形——低光（<10 勒克斯）几乎无抑制，高光（>1000 勒克斯）接近完全抑制，中间段是最敏感的过渡区。光谱因素则体现在「等效光强」上：蓝光在相同勒克斯数下等效光强更高。
- **第三步，为什么是 S 形**：这条 S 形曲线来自 ipRGC 光敏色素（黑视素）的饱和反应与下游信号整合——受体在低光下线性响应、高光下饱和，叠加多级放大后就成了阈值样反应。它保证了授时系统**既能对微弱晨光敏感，又不会在强光下失控**。

这条剂量-反应曲线直接支撑了「睡眠卫生」的两条建议：**睡前把灯光调暗、减少蓝光；晨起尽量接触自然光**——前者减少夜间褪黑素抑制，后者用高亮光把相位提前。

## 4 褪黑素反过来拨钟：MT 受体与褪黑素 PRC

褪黑素不仅是授时系统的「输出」，它还会**反过来作用于 SCN**，成为一个重要的反馈信号。SCN 上表达两种褪黑素受体 **MT1** 与 **MT2**（都是 G 蛋白偶联受体）：MT1 调控神经元兴奋性，MT2 介导对 SCN 放电节律的**相位移动**。<span class="marginnote">褪黑素对 SCN 的相位作用与光<strong>相反</strong>：在傍晚（内源褪黑素尚未上升前）给褪黑素，相位提前；在清晨给褪黑素，相位推迟。药理褪黑素因此被称为「化学时钟拨片」——它的 PRC 大致是光 PRC 的镜像。</span>

这带来两个重要应用：

**给药时机决定一切**。褪黑素的相位效应高度依赖给药时间：同样是 0.5–3 mg 的剂量，傍晚服「拨快」时钟，清晨服「拨慢」时钟，白天服几乎无效甚至可能造成不良相位。**「什么时候吃」比「吃多少」重要得多**——这是时间药理学（chronopharmacology）的第一课，也是市面上「白天随便吃褪黑素」最普遍的误区。

**它也是主钟的授时信号之一**。母体褪黑素可以穿过胎盘，把母体的「黑夜」告知胎儿——这是胎儿钟在出生前就与环境同步的一条重要途径（呼应上一篇《视交叉上核主钟》的母体授时）。

光与褪黑素是一对互补的授时信号，把它们并排比较能加深理解：

| 特征 | 光 | 褪黑素 |
| --- | --- | --- |
| 来源 | 环境（经 ipRGC 进入） | 内源（松果体）或外源补充 |
| 拨钟方向 | 清晨提前、夜间推迟 | 傍晚提前、清晨推迟（与光相反） |
| 作用受体/通路 | 黑视素 → SCN | MT1/MT2 → SCN |
| 临床代表应用 | 光照治疗（SAD、时差） | 傍晚服用于东向旅行、节律后移 |
| 类比 | 「对表」的外部标准 | 「报时」的内部广播 |

这张表也说明：**授时的本质是「用外界周期校准内源相位」**，光提供外界标准，褪黑素则把校准结果广播出去——两者配合，才构成完整的授时闭环。

## 5 DLMO：临床上的时相金标准

光与褪黑素的研究直接催生了睡眠医学最重要的诊断工具之一：**暗光褪黑素起始（dim light melatonin onset, DLMO）**。

测量方法是：让受试者处于暗光环境（<30 勒克斯），傍晚起每隔 20–30 分钟采一次唾液或血浆，测定褪黑素开始显著上升的那个时刻。DLMO 通常出现在习惯入睡前约 **2 小时**，它与 SCN 相位高度相关，是目前判断「你的生物钟现在几点」最可靠的指标。<span class="marginnote">DLMO 的价值在于它测的是「体内相位」而非「主观作息」：晚睡晚起的人如果 DLMO 也后移，说明是真正的「生物钟型」（delayed phase），而不是单纯的懒惰或行为问题——这个区别在《轮班、时差与健康》一篇的昼夜节律睡眠障碍诊断里是核心依据。</span>

**辨析｜易错点：** 睡眠研究里常把「困意出现的时间」当作息型，但困意受睡眠债、咖啡因、情绪影响很大。DLMO 是**相位的内源性指标**，两者可能分离——比如长期熬夜的人困意后移，但 DLMO 可能已经适应或仍在挣扎。临床与科研都以 DLMO（或核心体温最低点）为准。

## 6 褪黑素的一生：从出生到老年

褪黑素的昼夜分泌模式不是一成不变的，它随年龄走过一条清晰的生命曲线：

**婴儿期**：出生后数周内松果体才开始建立明显的昼夜褪黑素节律——这与新生儿 SCN 尚未成熟、睡眠分散在一天的现象同步。到 3 个月左右，夜间褪黑素峰值逐步成形，昼夜节律也随之「显形」。

**成年期**：夜间褪黑素分泌量在青壮年达到顶峰，DLMO 与睡眠时相的关系最稳定。

**老年期**：松果体随年龄钙化，夜间褪黑素分泌量逐渐下降，峰值可能降到青年时的一半甚至更低；DLMO 常提前，睡眠随之「前移 + 变浅」——这正是老年人早睡早起、夜间易醒的部分生理基础。<span class="marginnote">这解释了两个常见现象：一是老年人对夜间灯光的抑制更敏感、睡眠更容易被打断；二是补充褪黑素在老年人身上的研究证据比年轻人更一致——因为补的是「本就缺少」的信号。不过褪黑素是激素类产品，长期使用的获益与风险仍需遵医嘱权衡。</span>

把这条生命曲线与本篇的主线连起来：**褪黑素不仅告诉你「现在几点」，还告诉你「你多大了」**——它是年龄相关睡眠变化的可测量窗口，也是老年睡眠医学里最常被讨论的干预靶点。

## 7 光与褪黑素在现代生活

把光与褪黑素的机制放回现代场景，很多睡眠困扰就有了统一的解释：

**屏幕蓝光**：夜间使用冷白 LED 屏幕（富含 480 nm 蓝光）会部分抑制褪黑素并推迟 DLMO——这就是「睡前刷手机 → 越刷越精神 → 越睡越晚」的因果链。<span class="marginnote">对策不止「早睡」：把屏幕调到暖色调、把室内灯换成低色温、睡前 1–2 小时进入「暗光模式」，都能显著减弱对褪黑素的抑制。夜班人士使用琥珀色护目镜（滤除蓝光）已被多项研究证实可以部分保护夜间褪黑素分泌。</span>

**时差**：跨越时区后，SCN 的相位与环境时间脱节，褪黑素相位跟着错位。标准对策是「光 + 褪黑素」双管齐下：白天按目的地时间接触自然光（拨快/拨慢相位），在目的地就寝前 30–60 分钟服用小剂量褪黑素辅助「告知黑夜开始」。

**季节性情绪障碍（SAD）**：冬季日照缩短、光强减弱，部分人的昼夜节律相位后移、褪黑素时段拉长，出现情绪低落。**光照治疗**（清晨高亮度白光，约 10000 勒克斯，20–30 分钟）通过提前相位、压缩褪黑素时段起效——其机制正是本节的剂量-反应曲线。

## 8 小结

- **褪黑素是黑暗的化学信使**：由松果体夜间分泌，AANAT 是限速酶，昼夜曲线「白天近零、夜间达峰」。
- 光照经 **ipRGC → SCN → PVN → 交感链 → 松果体** 的神经链实时抑制褪黑素，抑制呈**剂量依赖**。
