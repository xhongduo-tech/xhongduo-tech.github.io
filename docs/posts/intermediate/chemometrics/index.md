# 化学计量学

化学计量学是分析化学的数据科学分支，融合统计学、数学与信息科学，以多元校正、模式识别和实验设计为核心手段，从紫外-可见、红外、近红外、色谱等复杂化学量测数据中提取组分信息与结构规律，是现代分析化学、过程控制与品质检验不可或缺的方法学基础。

## 对标教材

- Richard G. Brereton, "Chemometrics: Data Analysis for the Laboratory and Chemical Plant" (2nd ed., Wiley, 2003)
- 梁逸曾、俞汝勤，《化学计量学方法》，科学出版社
- D. L. Massart et al., "Chemometrics: A Textbook" (Elsevier)
