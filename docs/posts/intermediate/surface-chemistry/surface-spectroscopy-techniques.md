## 为什么从表面光谱技术开始

前七篇我们讲了表面的结构与性质，但这一切知识从何而来？一个致命困难：表面只有几个原子厚，而电子、光子、离子的探测束要穿过它、或从它身上弹出来，才能在检测器里留下信号。**表面光谱技术**是表面科学的方法论——它告诉我们，前面每一章的每一个概念（覆盖度、功函数、重构、台阶密度）到底是怎么被测量的。<span class="marginnote">测量的核心矛盾是「表面 0.5 nm 的信息，被体相 1 cm 的噪音淹没」。全部表面分析技术的共同策略就一句话：把探测束的能量、角度、种类调到只让「最表层」参与——要么用很快逃逸的电子（只有表面层能逃出），要么用只能看到外层的极慢电子（低能电子衍射）。</span>更重要的是，这些仪器不是考古工具——它们是现代材料、芯片、催化剂研发的质检线。

表面分析还有一个容易被忽视的价值：**它把「洁净」与「污染」变成可量化的事**。超高真空下的样品表面一旦被杂质覆盖，所有测量都会失真——所以「表面分析」与「表面制备」永远是一对连体婴。

## 1 电子逃逸深度：一切表面谱学的「尺子」

为什么电子谱学天然是表面敏感的？因为电子在固体里走不远。**非弹性平均自由程（IMFP）** $\lambda_e$ 描述了电子在材料里行进时被散射前的平均距离。经验「通用曲线」显示：在 30–300 eV 这个区间，$\lambda_e$ 只有 0.5–2 nm——**凡是用这个能量范围逃出的电子，必然来自最表层几个原子层**。这条曲线是表面分析的物理地基。<span class="marginnote">不同探针的「表面敏感度」差异极大：X 光能穿进几微米（所以 X 射线衍射看的是体相），电子只能逃出纳米（所以 XPS/AES/LEED 都是表面敏感）；而同步辐射下的掠射角可以把探针深度进一步压到单层。</span>

**数值感受**：在 $\lambda_e \approx 1$ nm 的窗口里，出射电子强度随深度 $z$ 按 $e^{-z/\lambda_e}$ 衰减。取 $z = 3\lambda_e = 3$ nm，出射强度只剩 $e^{-3} \approx 5\%$——也就是说，XPS 信号 95% 来自最表层的 3 nm。**「表面敏感」不是魔法，是「短自由程」这条物理规律的必然结果。**

电子逃逸深度的第二个工程含义是**深度剖析**：用较高能量的电子或 X 光得到体相信息，用较低能量得到表面信息，二者结合就能逐层「剥」出元素的深度分布。AES 配 Ar⁺ 溅射正是利用这一原理做逐层分析——每溅射一层，探针就看见更深一层。

这条通用曲线还有一个实用的记忆点：它呈「U 形」——极低能与极高能电子的自由程都长，中间 30–300 eV 最短。所以表面谱学要么用中能电子（XPS/AES/LEED），要么刻意避开自由程长的能量区，让信号只来自最表层。

## 2 电子谱学：XPS 与 AES

**XPS（X 射线光电子谱）** 是成分与化学态分析的王者。用 X 光（光子能量如 Al Kα，1486.6 eV）打出内层电子，测量其动能，由能量守恒

$$
E_{\rm kin} = h\nu - E_B - \Phi
$$

反解结合能 $E_B$。$E_B$ 有两个指纹价值：**定性**——不同元素的芯能级位置互不相同；**化学态**——同一元素在不同化学环境（氧化态、配位）下 $E_B$ 会偏移零点几到几 eV（化学位移）。一条 XPS 谱就能回答「表面有什么元素、以什么价态存在」。

**AES（俄歇电子谱）** 用电子束激发原子，内层空穴被外层电子填充时，多余能量把另一个电子打出（俄歇过程）。俄歇电子的能量只取决于元素本身，与激发束无关，空间分辨率好，广泛用于元素分布成像。<span class="marginnote">「俄歇」纪念法国物理学家 Pierre Auger（1925 年独立发现，早于朗缪尔等人的同类工作）。AES 常与 Ar⁺ 溅射联用，一层层剥开样品做深度剖析——芯片失效分析的「逐层找断点」就是靠它。</span>

XPS 的定量还有一个加分项：**峰面积正比于元素浓度**。原子分数 $\approx \dfrac{A_i/S_i}{\sum_j A_j/S_j}$，其中 $S_i$ 是灵敏度因子——所以 XPS 不只是「有没有」，还能给出「各占百分之几」。这是它在材料研发里比质谱更受青睐的原因之一。

XPS 有个著名的麻烦：**荷电效应**。绝缘样品在光电子不断飞出后表面带正电，使所有峰整体向高结合能偏移——所以测绝缘体前要先镀一层很薄的导电膜或用中和枪，并用已知峰（如 C 1s 284.8 eV）做内标校准。不校准，XPS 的化学位移读数就不可信。

## 3 结构谱学：LEED 与表面显微镜

**LEED（低能电子衍射）** 用 30–200 eV 的电子垂直打到表面上，衍射花样的**斑位**给出表面原胞的尺寸与对称性（前文提到的重构证据，如 Si(111)-(7×7)，就是 LEED 测出来的）；斑点的**强度**随电子能量变化（I–V 曲线），经动力学计算可反推原子在法向上的精确位置——这是表面结构测定的权威工具。

而**表面显微镜**让原子直接可见：**STM（扫描隧道显微镜）** 靠量子隧穿电流成像，空间分辨率达到埃级，是第一个「看见原子」的仪器（1986 年诺贝尔奖）；**AFM（原子力显微镜）** 用悬臂针尖探测力，不需要导电样品，绝缘体、生物分子都能看。STM 甚至能在吸附原子层面「看着」分子跳位点——这正是我们讲表面扩散时说的直接证据。<span class="marginnote">STM 的图像其实不是「原子照片」，而是「隧穿电流地形图」——它测的是局部电子态密度。真实原子位置要结合理论模拟解读。AFM 则进一步细分接触/非接触/轻敲模式，是非导电表面的唯一选择。</span>

**辨析｜易错点：LEED 的「点」是倒易空间信息。** 衍射斑点的位置对应的是表面**倒格子**，不是实空间原子像——初学者常把 LEED 花样当成「原子怎么排的照片」。真实原子位置要靠「花样 + I–V 曲线 + 动力学拟合」三步反推。真正直接成像的是 STM/AFM，两者分工完全不同。

LEED 与 STM 还有个配合点：LEED 给出「平均结构」（大范围的原胞与对称性），STM 给出「局部真实」（缺陷、台阶、单个吸附原子）。经典用法是：LEED 先确认表面重建为 (7×7)，STM 再直接看这 7×7 的原子排列细节——两种空间尺度互补，正是组合拳的样板。

## 4 振动谱与热脱附：看分子怎么站在表面

电子谱学看「有什么元素」，但要问「分子以什么姿势、什么键合站在表面」，需要另两套技术：

**HREELS（高分辨电子能量损失谱）** 用单能电子束轰击表面，电子把能量交给吸附分子的振动模式后减速，测能量损失谱——损失峰对应分子的振动频率，直接给出**成键类型与吸附构型**。它几乎能测所有吸附物，代价是分辨率有限。

**RAIRS（反射吸收红外谱）** 用红外光以掠射角照表面，吸附分子的偶极跃迁吸收红外——金属表面还有「表面选择定则」：只有偶极变化垂直于表面的振动才吸收，**峰的有无恰好暴露分子的取向**。HREELS 与 RAIRS 常被拿来对比：HREELS 灵敏度高、可测所有分子但分辨率粗；RAIRS 分辨率高（能分辨 C–H 与 C–D 键）、但有表面选择定则这个「取向探测器」。两者互补，是「吸附物显微镜」的两半。

振动谱学的解释有个天然拐杖：<strong>同位素标记</strong>。把 $\ce{H}$ 换成 $\ce{D}$，C–H 键振动频率按 $\sqrt{m_H/m_D} \approx \sqrt{1/2}$ 下移——所以对比 $\ce{C-H}$ 与 $\ce{C-D}$ 谱峰，就能确认某个峰确实来自含氢基团，而不是仪器伪峰。这是谱学归峰的黄金标尺。

**TPD（温度程序脱附）** 则回答「吸附有多强、有几种位点」：升温时记录脱附流，一个峰就是一个吸附态，峰位对应脱附活化能——它把上一节讲的「吸附态」从概念变成可直接计数的谱峰。

## 5 表格式辨析：每个技术回答什么问题

| 技术 | 探针 → 检测 | 表面深度 | 能回答什么 |
| --- | --- | --- | --- |
| XPS | X 光 → 电子 | 2–10 nm | 元素组成、化学态（价态） |
| AES | 电子 → 电子 | 1–3 nm | 元素组成、逐层深度剖析 |
| LEED | 低能电子 → 衍射 | 1–2 nm | 表面原胞、重构、原子位置 |
| STM / AFM | 针尖 → 电流/力 | 原子级 | 原子级形貌、吸附、操纵 |
| HREELS / RAIRS | 电子/红外 → 能量损失 | 表面层 | 吸附物种的振动指纹、成键 |
| TPD | 升温 → 脱附气体 | 表面层 | 吸附态、吸附能、覆盖度 |
| SIMS | 离子 → 离子 | 1 nm 内 | 痕量元素、同位素、分子碎片 |

**这一表提醒我们：没有全能仪器。** 结构找 LEED，成分找 XPS，振动找 HREELS，吸附能找 TPD——把几种技术在同一台超高真空系统里联用（UHV 环境下原位表征），才是现代表面研究的常态。

这条表格还有一层实践含义：它对应了表面研究里「先成分、再结构、后吸附」的提问顺序。拿到一块未知样品，第一步永远是 XPS/AES 问「是什么」，第二步 LEED 问「长什么样」，第三步才轮到 HREELS/TPD 问「怎么反应」——顺序颠倒，常会对着错仪器浪费时间。<span class="marginnote">超高真空（UHV，压力 < 10⁻⁹ mbar）是这些技术的共同前提：在 10⁻⁶ mbar 下，一秒钟就有约一层杂质分子撞上样品表面，表面会被污染到无法测量——所以表面科学实验几乎都在「真空城堡」里进行。</span>

## 6 表面分析的工作流：从制样到解读

一套完整的表面分析不是「放进去就测」，而是三步走：

1. **制样**：切割、抛光，在 UHV 里离子溅射 + 退火（反复循环）得到原子级干净、有序的表面——任何残留污染都会污染数据。
2. **表征**：先用 LEED 确认结构有序、用 AES/XPS 确认成分干净，再针对科学问题选谱学（吸附研究上 HREELS/TPD，电子结构研究上 UPS/ARPES）。
3. **解读**：把谱峰位置、强度、随覆盖度的演化与理论（DFT 计算、谱学模拟）对照，才能得出「吸附在哪个位、以什么姿势」的结论。

<span class="marginnote">这一步与「从极限到大模型」的映射值得点破：表面分析里的「制样—表征—解读」三步，与机器学习里的「数据清洗—特征提取—模型解释」是同一套科研范式——先保证输入干净，再谈信号，最后回到物理。</span>表面科学之所以能在几十页论文里讲清一个吸附故事，靠的正是这套纪律化的工作流。

还有一个把整套流程串起来的量：**覆盖度标定**。TPD 的峰面积、XPS 的峰强度比，最终都要换算成「每平方厘米多少个吸附分子」，才能在不同实验间比较。覆盖度一旦校准好，前面所有谱学的相对信号就都变成了可比的绝对值——这是表面分析从「看图说话」走向定量科学的最后一步。

用一句话总结全篇的立场：**表面光谱技术的价值不在某台仪器多先进，而在它们合起来能回答「表面是什么、长什么样、怎么反应」这一连串问题。** 学会按需选谱、按组合拳出牌，比背下一百种仪器的缩写更有用。

## 7 公式解析：XPS 的一条能量守恒

**XPS 方程 $E_{\rm kin} = h\nu - E_B - \Phi$ 是全部光电子谱学的母式，值得逐项拆解。** 拆三步：

**第一步，认符号**：$h\nu$ 是入射光子能量，$E_B$ 是电子相对 Fermi 能级的结合能，$\Phi$ 是谱仪功函数，$E_{\rm kin}$ 是谱仪测到的动能。它把「仪器读数」翻译成「材料本性」。
- **第二步，理解为什么是差式**：光子把能量 $h\nu$ 全部交给电子；电子要付两笔「路费」——挣脱原子核（$E_B$）与越过表面偶极/到达检测器（$\Phi$）。剩下的才变成可测动能。
- **第三步，注意测量约定**：实际谱仪中，样品与谱仪导电相接、Fermi 能级对齐，$\Phi$ 用的是**谱仪**的功函数而非样品——这样 $E_B$ 的数值才可跨仪器比较。这也正是「结合能」成为元素指纹的前提。<span class="marginnote">把这条式子与「功函数」一篇里光电发射阈值对照：那里的 $E_B = 0$（Fermi 电子），于是 $E_{\rm kin}^{\max} = h\nu - \Phi$。XPS 是它的一般化版本——「量子能级 + 表面势垒」同一个物理，一套读法。</span>

**数值算例**：用 Al Kα（$h\nu = 1486.6$ eV）测碳，谱仪测得 $E_{\rm kin} = 1201.8$ eV，谱仪功函数 $\Phi = 4.3$ eV，则 $E_B = 1486.6 - 1201.8 - 4.3 = 280.5$ eV——这是 C 1s 的典型结合能位置。若同样碳材料表面被氧化，C 1s 峰向高结合能偏移约 2–3 eV，出现在 283–284 eV——**一次测量，不仅认出碳，还认出它是「被氧化的碳」**。这正是化学位移让 XPS 成为表面化学「验尸官」的原因。

## 8 小结

- 表面谱学都建立在**电子逃逸深度**上：30–300 eV 电子只能从最表层逃出，天然表面敏感。
- **XPS** 靠结合能指纹定元素与化学态（化学位移）；**AES** 靠俄歇电子定成分并可逐层剖析。
- **LEED** 定表面结构与重构；**STM/AFM** 实现原子级成像与操纵。
- **HREELS/RAIRS** 看吸附分子的振动与取向；**TPD** 数吸附态、测吸附能。
- 技术选择是组合拳：结构找 LEED、成分找 XPS、振动找 HREELS、吸附能找 TPD，全程 UHV。
- 工作流是「制样—表征—解读」三步走；同位素标记是谱学归峰、荷电校正是 XPS 可信度的前提。
- 探测顺序是「先成分（XPS/AES）、再结构（LEED）、后吸附（HREELS/TPD）」，顺序颠倒会对着错仪器浪费时间。

在下一节，我们要把学过的所有概念（吸附、表面能、电子结构、动力学）汇聚到最大的应用现场：为什么表面能催化工业反应、火山型曲线为何存在——这就是 **多相催化原理**。
