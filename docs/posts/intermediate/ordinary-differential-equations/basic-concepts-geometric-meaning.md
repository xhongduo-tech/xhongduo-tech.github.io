## 为什么从基本概念开始

上一级我们学完了《数学分析》：极限、导数、积分已经教会我们「如何求一个函数的瞬时变化率」。现在问题反过来——**如果我们只知道变化率本身，如何把函数找回来？** 这正是微分方程（differential equation）研究的问题。<span class="marginnote">牛顿 1687 年在《原理》中把行星运动写成一个含导数的方程，微分方程由此诞生；它从此成了力学、电学、化学、生物学的共同语言。</span>

在第二级《常微分方程》里，我们要系统回答：哪些方程能写出精确公式解，哪些方程只能用数值或几何方法逼近，以及解的存在性、唯一性如何保证。而这一切的第一步，是先学会**分辨一个对象是不是微分方程、它几阶、它线性与否**。这些名词看起来只是分类学，实际上决定了后面每一招解法的适用边界。

## 1 微分方程的定义与阶

**微分方程（differential equation）**：含有未知函数的导数（或微分）的等式。若未知函数是一元函数，导数只涉及一元，则称为**常微分方程（ordinary differential equation, ODE）**；若未知函数是多元函数、等式含偏导数，则称为**偏微分方程（partial differential equation, PDE）**。<span class="marginnote">PDE 在本博客有独立专题《偏微分方程》（第二级）承接；本专题只处理 ODE。</span>

所谓「阶」，指方程中出现的**最高阶导数**的阶数：

$$y' = 2x \quad (\text{一阶}), \qquad y'' - 3y' + 2y = 0 \quad (\text{二阶})$$

$$\left(y''\right)^2 + y' = \sin x \quad (\text{二阶，但非线性})$$

**辨析｜易错点：** 「阶」看的是**最高导数阶数**，不是导数项的个数，也不是方程里最高次幂。$y''' + (y'')^2 = 0$ 是三阶，因为最高出现三阶导数 $y'''$；$(y')^2 + y = 0$ 虽然含平方，仍是一阶。<span class="marginnote">幂次只影响线性与否，不影响阶——这是初学最容易混的两把尺子。</span>

## 2 线性与非线性

一个 $n$ 阶 ODE 的**一般形式**是

$$F\left(x,\ y,\ y',\ \dots,\ y^{(n)}\right) = 0$$

若它能写成如下形状，就称为 **$n$ 阶线性微分方程**：

$$a_n(x)\,y^{(n)} + a_{n-1}(x)\,y^{(n-1)} + \cdots + a_1(x)\,y' + a_0(x)\,y = g(x)$$

线性方程的两条铁律：**① $y$ 及其各阶导数都只出现一次、一次幂；② 各项系数不含 $y$ 或 $y'$ 等**。系数 $a_k(x)$ 只允许依赖自变量 $x$。不满足的方程一律归入非线性。<span class="marginnote">为什么「线性」如此重要？因为线性方程满足叠加原理：解可线性叠加，后面第二篇整套解法（特征根、待定系数）都建立在这条性质上。非线性则没有这种福气，只能进入第三篇的定性理论。</span>

一个快速判别表：

| 方程 | 阶 | 线性？ |
| --- | --- | --- |
| $y' + xy = e^x$ | 一阶 | ✅ 线性 |
| $y' = x^2 + y^2$ | 一阶 | ❌ 非线性（$y^2$） |
| $y'' + \sin y = 0$ | 二阶 | ❌ 非线性（$\sin y$） |
| $x^2 y'' + y = 0$ | 二阶 | ✅ 线性 |
| $y\,y' + y = x$ | 一阶 | ❌ 非线性（$yy'$） |

## 3 通解、特解与初值问题

**通解（general solution）**：含有 $n$ 个任意常数（对 $n$ 阶方程）的解，这 $n$ 个常数独立到无法互相吸收。**特解（particular solution）**：给这些常数取定一组值后得到的解。

$$\text{一阶方程 } y' = 2x \quad\Longrightarrow\quad \text{通解 } y = x^2 + C$$

这里 $C$ 是任意常数。若再加上**初始条件（initial condition）** $y(0) = 1$，代入得 $C = 1$，便得到特解 $y = x^2 + 1$。<span class="marginnote">「初值」指的是在<strong>一个</strong>自变量取值处给定函数值（乃至高阶导数值）的定解条件；与之相对，在<strong>两个或更多</strong>端点处给条件的叫边值条件，见第三篇《边值问题与格林函数》。</span>

**初值问题（initial value problem, IVP）**：一个 ODE 配上足够多个初值条件，目的是把任意常数全部锁定，得到唯一一条特解。

**辨析｜易错点：** 一阶方程需要 $1$ 个初值，$n$ 阶方程需要 $n$ 个初值。少给一条，得到的仍是含任意常数的解族；多给一条，可能无解（条件之间互相矛盾）。初值条数 = 方程的阶，这是定解条件数量上的硬约束。

## 4 几何意义：斜率场与积分曲线

ODE 给出的是「每一点的切线斜率」。对一阶显式方程 $y' = f(x, y)$，点 $(x, y)$ 处的切线方向完全由 $f(x,y)$ 决定。把平面上足够多点处的**小短线（斜率元，line element）** 都画出来，就得到**斜率场（direction field / slope field）**。

解曲线 $y = \varphi(x)$ 在每一点都与该处的小短线相切，因此**解就是斜率场中处处相切的曲线**——这样的曲线称为**积分曲线（integral curve）**。<span class="marginnote">当方程写不出显式公式解时，斜率场是「看图说话」的第一武器：定性地看出解的增减、走向、是否被某条水平线挡住。欧拉折线法（数值解）就是沿着小短线一步步走，见第三级《数值分析》。</span>

**几何视角给我们的三条直觉：**

- 通解是一族**彼此不交**的积分曲线；解族填满有定义的区域。
- 初值条件选定其中**一条**曲线。
- 若 $f$ 足够光滑，过每点有且仅有一条积分曲线——这正是下一节《解的存在唯一性定理》的几何直觉。

## 5 公式解析：通解公式 $y = x^2 + C$

我们从最简单的方程 $y' = 2x$ 出发，拆解「求通解」这整条链子：

- **第一步，读出问题**：$y' = 2x$ 是一个一阶线性方程，未知函数 $y(x)$ 的导数等于已知函数 $2x$。问题变成「谁求导等于 $2x$？」
- **第二步，逆向求导**：$y = x^2$ 求导恰为 $2x$。但 $y = x^2 + 1$、$x^2 - 5$ 也满足——因为**常数的导数为零**。
- **第三步，装入任意常数**：$y = x^2 + C$。$C$ 吸收了所有「求导后消失的信息」，所以通解里永远跟着一个任意常数。
- **第四步，用初值锁定 $C$**：给 $y(0)=1$，得 $0 + C = 1$，即 $C=1$，特解 $y = x^2 + 1$。

一句话：**积分是求导的逆运算，而「+C」正是积分逆运算丢信息的代价**。这条直觉将贯穿整个第一篇——分离变量、积分因子，本质上都在设法把方程变成「直接两边积分」的样子。

## 6 建模：从物理定律到微分方程

学微分方程最终是为了把真实世界「翻译」成方程。翻译的语法只有三条：

- **牛顿第二定律**：$m\,\ddot{x} = \sum F$。加速度是位置的二阶导数，于是力学问题天然长成二阶方程。弹簧-质量系统 $m\ddot{x} = -kx$（胡克定律）即 $m\ddot{x} + kx = 0$。
- **守恒律**：电路的基尔霍夫定律、化学反应的质量守恒、流体的连续性方程，都把「总量的变化率 = 进出之和」写成方程。RC 电路 $RC\,u' + u = E$ 就是这么来的。
- **比例律**：变化率与当前量成正比（指数增长/衰减）、与差值成正比（牛顿冷却），直接给出可分离或线性方程。

把这三条用熟，任何物理课本里的「建立微分方程」问题都有了着手点。<span class="marginnote">三条语法分别对应一阶与二阶方程最常见的来源：比例律给一阶，牛顿第二定律给二阶，守恒律给一阶线性。第三级《物理》与《数学物理方法》专题会把它们反复演练。</span>

**辨析｜易错点：** 建模最容易错的是「符号」。力是恢复力还是驱动力、电流方向取哪边为正，都会让方程差一个负号，进而把「稳定」变成「发散」。每步都问一句「这个符号对吗？量纲对吗？」，是建模的第一素养。

**量纲检查小技巧**：$x''$ 的量纲是「长度/时间²」，方程每一项都必须与它同量纲。某项明显「量纲不匹配」，八成是系数或变量写错了——这是不靠验算也能抓住低级错误的最快方式。

**读到这里，你应该能立刻回答三个问题**：① 怎么判断阶与线性？② 通解该含几个任意常数？③ 初值问题需要几个定解条件？三问都对，说明本节骨架立住了。后面每一节的解法，都建立在「先认方程、再定阶、再配条件」这个顺序之上——认错方程，一切白算。

**再补一个术语**：若一阶方程右端不含自变量 $x$（如 $y' = y^2$），称**自治方程（autonomous equation）**；含 $x$ 则称非自治。自治方程在第三篇《相平面与奇点分类》里是主角——因为右端不显含时间，轨道的形状不随起点平移而改变，定性分析可以脱离具体时刻进行。

**两个好习惯**：① 写通解时注明定义区间——解是区间上的对象，不是单点上的巧合；② 拿到方程先默念「几阶、线性否」，再决定解法，顺序反了招式全乱。

**再补一个细节**：微分方程的解是「区间上的函数」，而初值只是「区间里一个点处的条件」。写 $y = x^2 + C$ 时，习惯性跟一句「$x \in \mathbb{R}$」，严谨性立涨。

## 7 小结

- **微分方程**是含未知函数导数的等式；只有一元函数导数的是**常微分方程**。
- **阶** = 方程中最高阶导数的阶数；**线性** = $y$ 及导数只以一次幂、且系数不含 $y$ 的形式出现。
- **通解**含 $n$ 个任意常数，**特解**是常数取定后的解；ODE + 初值 = **初值问题（IVP）**。
- 几何上，$y' = f(x,y)$ 定义了一个**斜率场**，解曲线处处与其相切，称为**积分曲线**。
- 初值的个数必须等于方程的阶，这是定解的基本纪律。

在下一节，我们将学会第一类能求出公式解的方程——**可分离变量方程**，它是整个一阶方程解法的「母版」。
