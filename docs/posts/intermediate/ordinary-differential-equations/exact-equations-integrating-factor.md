# 全微分方程与积分因子

## 为什么有「全微分」这条捷径

把一阶方程写成微分形式 $M(x,y)\,dx + N(x,y)\,dy = 0$，是在问：**这个微分组合是不是某个二元函数 $F(x,y)$ 的全微分？** 如果是，方程直接变成 $dF = 0$，解就是等高线 $F(x, y) = C$——不需要任何积分技巧，只要求出一个原函数。<span class="marginnote">这等于把「解微分方程」降维成「求原函数」。而求原函数的本质是解偏微分方程 $F_x = M,\ F_y = N$，与第二级《偏微分方程》和《数学分析》的重积分换序天然相连。</span>

可惜绝大多数方程一开始并不「全微分」。好在很多时候乘上一个适当的函数 $\mu$，就能把它变全微分——**这个函数也叫积分因子**。上一节积分因子让「$y'+py$」变整导，这一节积分因子让「$Mdx + Ndy$」变全微分，两条路殊途同归。

## 1 全微分方程与判定条件

**全微分方程（exact differential equation）**：若存在二元函数 $F(x,y)$，使

$$dF = \frac{\partial F}{\partial x}\,dx + \frac{\partial F}{\partial y}\,dy = M(x,y)\,dx + N(x,y)\,dy$$

则 $M\,dx + N\,dy = 0$ 称为全微分方程，其解为 $F(x, y) = C$。

**充要判定条件**（在单连通区域内，$M, N$ 一阶偏导连续）：

$$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$$

这是「混合偏导相等」定理的推论：$M = F_x,\ N = F_y$，则 $M_y = F_{xy} = F_{yx} = N_x$。<span class="marginnote">「单连通区域」在此可理解为「没有洞的区域」，保证 $F$ 能沿任意路径积分定义而不产生多值性。这个条件在第二级《数学分析》的格林公式、第三级《偏微分方程》里会反复出现。</span>

**例子**：$2xy\,dx + (x^2 - 1)\,dy = 0$。这里 $M = 2xy$，$N = x^2 - 1$。检查：$M_y = 2x$，$N_x = 2x$，相等——是全微分方程。解 $F$：由 $F_x = 2xy$ 得 $F = x^2 y + \varphi(y)$；再由 $F_y = x^2 + \varphi'(y) = x^2 - 1$，得 $\varphi'(y) = -1$，$\varphi(y) = -y$。故 $F = x^2 y - y$，通解 $x^2 y - y = C$，即 $y = \dfrac{C}{x^2 - 1}$。

## 2 求 $F$ 的两种姿势

**姿势一：依次积分**。先对 $x$ 积分 $F = \int M\,dx + \varphi(y)$，把 $\varphi(y)$ 当作「待定函数」；再用 $F_y = N$ 定出 $\varphi$。上面例子用的就是这条路。对称地，也可以先对 $y$ 积分再加 $\psi(x)$。

**姿势二：曲线积分**。在矩形区域内从 $(x_0, y_0)$ 出发，先沿水平再沿竖直走到 $(x,y)$：

$$F(x,y) = \int_{x_0}^{x} M(t, y_0)\,dt + \int_{y_0}^{y} N(x, t)\,dt$$

这条公式的好处是**完全机械**，不依赖你「猜对」积分次序。

**辨析｜易错点：** 姿势一里最容易犯的错是漏了「待定函数」$\varphi(y)$——把 $F$ 直接写成 $\int M\,dx$，然后发现 $F_y$ 对不上。另一个错是**没检查条件就硬解**：条件不满足时，按「全微分」求出的 $F$ 必然自相矛盾（$F_{xy} \neq F_{yx}$），白白浪费计算。先查 $M_y = N_x$ 再动笔，是这一节的第一纪律。

## 3 积分因子：把「不全」变「全」

当 $M_y \neq N_x$ 时，方程不是全微分。若存在函数 $\mu(x,y)$ 使

$$\mu M\,dx + \mu N\,dy = 0$$

成为全微分方程，则 $\mu$ 叫该方程的**积分因子（integrating factor）**。

找积分因子没有万能公式，但有两类**只依赖单变量**的常见情形：

- 若 $\dfrac{M_y - N_x}{N}$ 只含 $x$（记为 $P(x)$），则 $\mu = e^{\int P(x)\,dx}$。<span class="marginnote">推导：设 $\mu$ 只依赖 $x$，要求 $(\mu M)_y = (\mu N)_x$，即 $\mu M_y = \mu' N + \mu N_x$，移项得 $\mu'/\mu = (M_y - N_x)/N$，右端必须与 $y$ 无关才有解。这条「检验 + 积分」流程是考场上最快的手感。</span>
若 $\dfrac{N_x - M_y}{M}$ 只含 $y$，则 $\mu = e^{\int Q(y)\,dy}$。

**例子**：$y\,dx - x\,dy = 0$。$M = y,\ N = -x$，$M_y = 1,\ N_x = -1$，不相等。计算 $\dfrac{M_y - N_x}{N} = \dfrac{1 - (-1)}{-x} = -\dfrac{2}{x}$，只含 $x$，于是 $\mu = e^{\int -\frac{2}{x}dx} = x^{-2}$。乘上后方程变为 $\dfrac{y}{x^2}dx - \dfrac{1}{x}dy = 0$，检查：$M_y = 1/x^2$，$N_x = 1/x^2$，成了。解出 $F = -y/x$，通解 $y = Cx$——一条过原点的直线族。<span class="marginnote">有趣的是原方程也可以直接分离变量：$dy/y = dx/x$。同一方程两个解法殊途同归，说明各招不是孤岛，而是互相印证的检查网。</span>

## 4 公式解析：判定条件 $\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}$

这条条件是全微分方程的门票，拆开看它的来历：

**第一步，全微分的结构**：若 $F(x,y)$ 存在且光滑，$dF = F_x\,dx + F_y\,dy$。对照 $M\,dx + N\,dy$，应当有 $F_x = M,\ F_y = N$。
**第二步，混合偏导相等**：对光滑函数，求导次序可交换：$F_{xy} = F_{yx}$。把 $F_x = M$ 对 $y$ 求导得 $M_y$，把 $F_y = N$ 对 $x$ 求导得 $N_x$，两者必须相等。
**第三步，充分性（反向）**：反之，若 $M_y = N_x$ 在单连通区域成立，则可以构造出 $F$（用 2 节的两条姿势）。因此条件是充要的。<span class="marginnote">「充分性需要单连通区域」不是空话：在环形区域里，绕圈积分可能差一个周期项，$F$ 会变成多值函数。第三级《复变函数》里的 Cauchy 定理正是这件事的复变版本。</span>
- **第四步，直觉**：条件说的是「两个偏导互相咬合得严丝合缝」——就像拼图的两条边必须长度吻合，否则无法严丝合缝拼出 $F$。

## 5 积分因子的系统求法

单变量积分因子有清晰套路。设 $\mu$ 只依赖 $x$，由 $(\mu M)_y = (\mu N)_x$ 展开：

$$\mu\,M_y = \mu' N + \mu\,N_x \quad\Longrightarrow\quad \frac{\mu'}{\mu} = \frac{M_y - N_x}{N}$$

右端若只含 $x$（记为 $P(x)$），则 $\mu = e^{\int P(x)\,dx}$。对称地，若 $\mu$ 只依赖 $y$，则

$$\frac{\mu'}{\mu} = \frac{N_x - M_y}{M} \quad\Longrightarrow\quad \mu = e^{\int Q(y)\,dy}$$

右端须只含 $y$。**实操口诀**：先算 $M_y - N_x$，若它除以 $N$ 后不含 $y$，走 $x$ 路；若除以 $M$ 后不含 $x$，走 $y$ 路；两路都走不通，再考虑更复杂的 $\mu(x,y)$（一般超出本科范围）。

**例子**：$y\,dx + (2x + 3y)\,dy = 0$。$M = y,\ N = 2x+3y$，$M_y - N_x = 1 - 2 = -1$。$(M_y-N_x)/N = -1/(2x+3y)$ 含 $x,y$，两条路都依赖；但 $(N_x-M_y)/M = 1/y$ 只含 $y$！取 $\mu = e^{\int dy/y} = y$。乘 $y$ 后方程变为全微分，可解。<span class="marginnote">这一例说明「先检查哪条路可行」的价值：$\mu = y$ 并不难猜，但系统性流程让你不必靠运气。</span>

**辨析｜易错点：** 千万别把两条路的分母记反——$x$ 路除以 $N$，$y$ 路除以 $M$。记反之后算出的「积分因子」大概率不是因子，代回一验就露馅。验算永远是保险丝。

### 从曲线积分看 $F$ 的求法

第二种求 $F$ 的姿势——曲线积分——值得展开。对全微分方程，$F$ 可以沿任意路径从 $(x_0,y_0)$ 积到 $(x,y)$：

$$F(x,y) = \int_{(x_0,y_0)}^{(x,y)} M\,dx + N\,dy$$

**关键事实**：全微分的路径无关性（$M_y = N_x$ 正是它的保证）意味着**走哪条路都行**。于是聪明人先水平走（$y$ 固定，只积 $M\,dx$）再竖直走（$x$ 固定，只积 $N\,dy$），每条腿都退化成单变量积分：

$$F = \int_{x_0}^{x} M(t, y_0)\,dt + \int_{y_0}^{y} N(x, t)\,dt$$

**路径无关 ⇔ 全微分**，这是第二级《数学分析》格林公式与线积分理论在 ODE 里的化身。若你学过线积分，「全微分方程」就是「保守场」，$F$ 就是势函数——同一个故事，两套术语。<span class="marginnote">「保守场有势函数」在第三级《电磁学》里对应电场可写为 $-\nabla V$；在《理论力学》里对应保守力与机械能守恒。全微分方程是这套「场 → 势」思想的最小舞台。</span>

**辨析｜易错点：** 用曲线积分时，**积分的腿要选在 $M, N$ 的连续区域内部**，别穿越 $M,N$ 无定义的线（如分母为零处）。路径无关保证任何合法路径结果相同，但「合法」两字不能省。

### 全微分与梯度场的再确认

全微分方程与多元微积分的梯度场是一回事：$M = F_x$，$N = F_y$，$F$ 就是势函数。物理里「力场 $\boldsymbol{F} = -\nabla V$ 是保守场」的判定（$\nabla \times \boldsymbol{F} = \boldsymbol{0}$），在二维 ODE 里退化成 $M_y = N_x$——条件完全同构。

**推论**：沿闭合路径积分全微分得零（$\oint dF = 0$），这正是「能量守恒」的雏形：势函数绕一圈回到原点，功为零。<span class="marginnote">这套「保守场 ⇔ 有势函数」的对应，在第三级《电磁学》《理论力学》里会反复出现。全微分方程是它最便宜的练习场。</span>

**一句话收束**：判定条件 $M_y = N_x$ 是全微分方程的护照——没有它，一切「求 $F$」的努力都是无源之水。

## 6 小结

- **全微分方程**：$M\,dx + N\,dy = 0$ 若存在 $F$ 使 $dF = Mdx + Ndy$，则解为 $F = C$。
- **判定条件**：$M_y = N_x$（单连通区域内充要）。
- **求 $F$**：先对 $x$（或 $y$）积分加待定函数，再用另一个偏导定出待定函数；或用曲线积分公式机械求之。
- **积分因子** $\mu$ 使 $\mu Mdx + \mu Ndy = 0$ 成全微分；常用单变量检验式 $\dfrac{M_y - N_x}{N}$（只含 $x$）或 $\dfrac{N_x - M_y}{M}$（只含 $y$）。
- 解出后 $F = C$ 往往已是隐式解，不必强行反解 $y$。
