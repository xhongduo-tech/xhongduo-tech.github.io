## 为什么变系数也有「熟人」

常系数方程靠 $e^{rx}$ 一招吃遍天。但系数一旦随 $x$ 变化，指数试探立刻失效——那是不是又得从头学一套？不必。有一类变系数方程是「披着变系数外衣的常系数」：**欧拉方程（Euler equation）**。它的系数是 $x$ 的幂次，恰好和导数的阶数严丝合缝，这给了我们一条偷渡通道——换元 $t = \ln x$。<span class="marginnote">欧拉方程也叫「等维方程」（equidimensional equation）：把 $x$ 换成 $kx$，方程的形式不变。这种「尺度不变性」在偏微分方程里对应拉普拉斯方程与位势理论，第三级《偏微分方程》还会重逢。</span>

工程里它在不少地方自然出现：圆柱坐标下的拉普拉斯方程分离变量、某些扩散问题、以及本博客后续《偏微分方程》里圆的边界值问题。学会它，等于提前拿到一张通往高维问题的门票。

## 1 欧拉方程的标准形

**二阶欧拉方程**：

$$x^2 y'' + a\,x\,y' + b\,y = 0$$

其中 $a, b$ 为常数。更一般地，$n$ 阶欧拉方程形如

$$x^n y^{(n)} + a_1 x^{n-1} y^{(n-1)} + \cdots + a_{n-1} x\,y' + a_n y = 0$$

**关键观察**：每一项里 $x$ 的幂次 = 导数的阶数。正是这个「幂次与阶数同步」的结构，让换元能奏效。<span class="marginnote">对比一般变系数方程 $x^2 y'' + p(x)y' + q(x)y = 0$ 只有当 $p, q$ 恰好是 $ax, b$ 这样的常数倍幂次时才是欧拉方程。判别口诀：<strong>系数是「常数 × $x^{阶数}$」</strong>。</span>

方程在 $x = 0$ 处退化（最高阶系数 $x^2 = 0$），所以求解区域一般取 $x > 0$ 或 $x < 0$ 的半轴。我们以下默认 $x > 0$。

## 2 换元 $t = \ln x$ 的全过程

设 $t = \ln x$（即 $x = e^t$），则 $\dfrac{dt}{dx} = \dfrac{1}{x}$。用链式法则算导数：

$$\frac{dy}{dx} = \frac{dy}{dt}\cdot\frac{dt}{dx} = \frac{1}{x}\,\dot{y} \quad\Longrightarrow\quad x\,\frac{dy}{dx} = \dot{y}$$

其中 $\dot{y} = dy/dt$。再看二阶：

$$\frac{d^2y}{dx^2} = \frac{d}{dx}\left(\frac{1}{x}\dot{y}\right) = -\frac{1}{x^2}\dot{y} + \frac{1}{x}\cdot\frac{d\dot{y}}{dx} = -\frac{1}{x^2}\dot{y} + \frac{1}{x^2}\ddot{y}$$

于是 $x^2 y'' = \ddot{y} - \dot{y}$。代入欧拉方程得

$$\ddot{y} + (a - 1)\,\dot{y} + b\,y = 0$$

**变成了常系数方程！** 接下来用上一节的 $e^{rt}$ 试探法即可。<span class="marginnote">换元的本质是「把乘 $x$ 的微分算子翻译成加法的差分」：$x\frac{d}{dx}$ 对应 $\frac{d}{dt}$，幂次运算被对数坐标拉直了。这种「对数尺度下找对称」的招数，在信号处理的频率域、幂律分布的直线上处处可见。</span>

**例子**：解 $x^2 y'' + xy' + y = 0$（$a = 1, b = 1$）。换元后 $\ddot{y} + 0\cdot\dot{y} + y = 0$，特征方程 $r^2 + 1 = 0$，$r = \pm i$，解 $y = C_1\cos t + C_2\sin t$。回代 $t = \ln x$：

$$y = C_1\cos(\ln x) + C_2\sin(\ln x)$$

振荡随着 $\ln x$ 走——在 $x$ 轴上越靠近 $0$，「周期」被压缩得越紧。

## 3 欧拉方程的特征方程

不换元也能直接得到特征方程：设 $y = x^r$，则 $xy' = r x^r$，$x^2 y'' = r(r-1)x^r$，代入二阶欧拉方程得

$$r(r-1) + a\,r + b = 0 \quad\Longleftrightarrow\quad r^2 + (a-1)\,r + b = 0$$

这与换元后的特征方程**完全一致**。三种根型对应基本解组（注意自变量是 $x$ 而非 $e^t$）：

| 特征根 | 基本解组（$x>0$） |
| --- | --- |
| 相异实根 $r_1 \neq r_2$ | $x^{r_1},\ x^{r_2}$ |
| 重根 $r_0$ | $x^{r_0},\ x^{r_0}\ln x$ |
| 共轭复根 $\alpha \pm i\beta$ | $x^{\alpha}\cos(\beta\ln x),\ x^{\alpha}\sin(\beta\ln x)$ |

**辨析｜易错点：** 复根情形里的 $x^\alpha$ 别丢，且三角函数**里是 $\ln x$ 不是 $x$**。$y = x^\alpha\cos(\beta\ln x)$ 的振荡发生在 $\ln x$ 的尺度上——这正是上一节例子里「周期被压」的原因。重根补的是 $\ln x$（不是 $x$），因为 $\ln x$ 与 $x^{r_0}$ 在线性空间里独立，而 $x\cdot x^{r_0} = x^{r_0+1}$ 会与另一支根撞车。<span class="marginnote">背后的逻辑仍是「换元后按 $t$ 处理重根补 $t$」，再把 $t$ 换成 $\ln x$。记不住 $x^{r_0}\ln x$ 时，从 $t$ 视角重推一遍是最稳的。</span>

**n 阶欧拉方程**：同样换元 $t = \ln x$，利用算子等式 $x^k \frac{d^k}{dx^k} \leftrightarrow \frac{d}{dt}\left(\frac{d}{dt}-1\right)\cdots\left(\frac{d}{dt}-k+1\right)$，化为常系数 $n$ 阶方程，再按 10 节的特征根法处理。

## 4 公式解析：$x^2 y'' = \ddot{y} - \dot{y}$

这是换元链路上最关键的一环，逐层拆：

**第一步，一阶换元**：$dy/dx = (dy/dt)(dt/dx) = \dot{y}/x$。于是 $x y' = \dot{y}$——「乘 $x$」恰好把 $dy/dx$ 变成 $dy/dt$，系数 $x$ 被吸收干净。
**第二步，二阶换元用乘积法则**：$y'' = d/dx(y') = d/dx(\dot{y}/x)$。$1/x$ 对 $x$ 求导得 $-1/x^2$；$\dot{y}$ 对 $x$ 求导要再用链式法则：$d\dot{y}/dx = \ddot{y}\cdot(dt/dx) = \ddot{y}/x$。合并得 $y'' = -\dot{y}/x^2 + \ddot{y}/x^2$。
**第三步，为什么是「减」**：$-1/x^2 \dot{y}$ 来自「$1/x$ 的导数」与「$\dot{y}$ 的链式」，它的存在让 $x^2 y''$ 里出现 $-\dot{y}$——这一项在常系数化之后变成 $(a-1)\dot{y}$ 里的 $-1$。
**第四步，与 $y = x^r$ 的呼应**：若设 $y = e^{rt}$（即 $x^r$），$x^2 y'' = \ddot{y} - \dot{y} = (r^2 - r)y$，而 $r(r-1)$ 正是「幂次降一阶」的系数。两条路殊途同归。<span class="marginnote">「换元公式 + 特征方程双入口」是欧拉方程防呆的保险：用 $y = x^r$ 直接设解更快，用 $t = \ln x$ 换元更不容易在复根/重根处翻车。考试里两个方法互为验算。</span>

## 5 高阶欧拉方程一例

三阶欧拉方程 $x^3 y''' + 3x^2 y'' + xy' - y = 0$（$x > 0$）。换元 $t = \ln x$ 需要三阶导数公式，由算子等式逐层推导：

$$x\frac{dy}{dx} = \dot{y}, \qquad x^2\frac{d^2y}{dx^2} = \ddot{y} - \dot{y}, \qquad x^3\frac{d^3y}{dx^3} = \dddot{y} - 3\ddot{y} + 2\dot{y}$$

代入得 $\dddot{y} - y = 0$，特征方程 $r^3 - 1 = (r-1)(r^2+r+1) = 0$，根 $r = 1,\ -\frac12 \pm i\frac{\sqrt3}{2}$。解

$$y = C_1 x + C_2 x^{-1/2}\cos\left(\frac{\sqrt3}{2}\ln x\right) + C_3 x^{-1/2}\sin\left(\frac{\sqrt3}{2}\ln x\right)$$

**观察**：$x^{-1/2}$ 是衰减因子，$\ln x$ 是振荡变量——离 $x=0$ 越近，振荡被「压」得越密，越远越稀疏。<span class="marginnote">这种「幂衰减 × 对数振荡」的结构在圆柱/球对称的径向问题里反复出现（贝塞尔、勒让德函数的亲缘），是幂次与对数坐标结合的典型长相。</span>

**辨析｜易错点：** 换元到高阶时，$x^k\frac{d^ky}{dx^k}$ 的公式不再是简单的 $\frac{d^ky}{dt^k}$——中间会混入低阶导的线性组合（$-\dot{y}$、$-3\ddot{y}+2\dot{y}$）。**直接设 $y = x^r$ 往往更快**：代入原方程逐项约去 $x^r$ 得关于 $r$ 的多项式，一步到位，不用背公式。

### 定义域：$x < 0$ 的一侧

欧拉方程在 $x=0$ 处奇异，解分成 $x>0$ 与 $x<0$ 两支。对 $x<0$，换元 $t = \ln|x|$ 一样奏效；幂函数 $x^r$ 写成 $|x|^r$。若初值给在 $x_0<0$，就在负半轴上做全套操作，最后用 $|x|$ 表达。

**例子（定初值）**：$x^2y'' + xy' + y = 0$，$y(1) = 1,\ y'(1) = 0$。通解 $y = C_1\cos(\ln x) + C_2\sin(\ln x)$，$y' = \dfrac{-C_1\sin(\ln x) + C_2\cos(\ln x)}{x}$。代入 $y(1) = C_1 = 1$，$y'(1) = C_2 = 0$，特解 $y = \cos(\ln x)$。

**辨析｜易错点：** 幂函数 $x^r$ 对非整数 $r$ 只在 $x>0$ 有实数意义；$x<0$ 时要么用 $|x|^r$，要么限制在正半轴求解。别在 $x<0$ 时直接写 $x^r$，引发负数非整数幂的争议。<span class="marginnote">「定义域分两支」是奇点附近解的一般规律：每个以 $x=0$ 为奇点的方程，解都各自活在 $x>0$ 与 $x<0$ 两侧，只有解本身可解析延拓时才跨过去。第三篇《正则奇点》会从弗罗贝尼乌斯方法的去心邻域视角重申这一点。</span>

**小结延伸**：欧拉方程与常系数方程只差一次换元 $t = \ln x$——把「幂次结构」翻译成「平移结构」。会解常系数，就会解欧拉；这条「换元归化」的思路正是本篇一贯的方法论。

**再验**：换元后常系数的特征方程与直接设 $y = x^r$ 得到的特征方程完全一致——两条路互相印证，是检验计算的免检牌。

## 6 小结

- **欧拉方程**：$x^2 y'' + axy' + by = 0$，特征是「系数 = 常数 × $x^{阶数}$」。
- **解法一**：换元 $t = \ln x$，把方程化为常系数 $\ddot{y} + (a-1)\dot{y} + by = 0$。
- **解法二**：直接设 $y = x^r$，得特征方程 $r(r-1) + ar + b = 0$。
- 三种根型对应解：实根 $x^{r_i}$；重根补 $\ln x$；复根 $\alpha\pm i\beta$ → $x^\alpha\cos(\beta\ln x),\ x^\alpha\sin(\beta\ln x)$。
- 定义域默认半轴 $x>0$（或 $x<0$），$x=0$ 是方程的奇点。
