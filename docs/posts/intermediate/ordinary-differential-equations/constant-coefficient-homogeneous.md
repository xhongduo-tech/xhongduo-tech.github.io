## 为什么从指数函数猜起

结构定理告诉我们：齐次方程的解空间是 $n$ 维的，找到 $n$ 个线性无关的解就大功告成。但「找解」本身仍需办法。对**常系数**方程，有个天才的猜测：指数函数 $e^{rx}$ 求导只是「乘 $r$」，$n$ 阶求导只是「乘 $r^n$」——代入方程后，所有项都提取出公因子 $e^{rx}$，剩下一个关于 $r$ 的多项式。**问指数函数是不是解，变成问多项式有没有根。**<span class="marginnote">这个「$e^{rx}$ 试探法」把微分方程变代数方程，正是欧拉的贡献。常系数一词指 $p_1,\dots,p_n$ 全是常数——系数不变，才让「试指数」成为可能；若系数随 $x$ 变化，此法即刻失效（那是第 13 节《变系数方程与降阶法》的事）。</span>

这根弦从牛顿力学一直弹到现代控制论：弹簧振动、电路振荡、火箭姿态稳定的全部动力学，第一问都是「特征根落在复平面的哪里」。

## 1 特征方程与指数解

考虑 $n$ 阶常系数齐次线性方程

$$y^{(n)} + a_1 y^{(n-1)} + \cdots + a_{n-1} y' + a_n y = 0, \qquad a_i \text{ 为常数}$$

设 $y = e^{rx}$，代入得 $e^{rx}\left(r^n + a_1 r^{n-1} + \cdots + a_{n-1} r + a_n\right) = 0$。因 $e^{rx} \neq 0$，得**特征方程（characteristic equation）**

$$r^n + a_1 r^{n-1} + \cdots + a_{n-1} r + a_n = 0$$

它的每一个根 $r_k$ 都给出一个解 $e^{r_k x}$。<span class="marginnote">「$e^{rx}$ 不为零」是关键一笔：实数指数恒正，复数指数 $|e^{rx}| = e^{\operatorname{Re}(r)x} > 0$。于是多项式方程与微分方程解之间一一对应，$n$ 次多项式有 $n$ 个根（计重数），基本解组就这么凑齐。</span>

## 2 二阶方程的三种根型

二阶方程 $y'' + a y' + b y = 0$ 的特征方程 $r^2 + ar + b = 0$，判别式 $\Delta = a^2 - 4b$。三种根型对应三种基本解组：

**① 两个相异实根 $r_1 \neq r_2$**：

$$y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$$

**② 共轭复根 $r_{1,2} = \alpha \pm i\beta$**（$\beta \neq 0$）：复解 $e^{(\alpha \pm i\beta)x}$，用**欧拉公式** $e^{i\theta} = \cos\theta + i\sin\theta$ 取实部与虚部，得实值基本解组：

$$y = e^{\alpha x}\left(C_1 \cos \beta x + C_2 \sin \beta x\right)$$

**③ 二重实根 $r_1 = r_2 = r_0$**：只有一个指数解 $e^{r_0 x}$ 不够。第二个解用**降阶法**（或直接背结论）为 $x\,e^{r_0 x}$：

$$y = (C_1 + C_2 x)\,e^{r_0 x}$$

**辨析｜易错点：** 复根情形常见的错是丢掉 $\alpha$。$y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$ 中，**指数因子 $e^{\alpha x}$ 必须有**——它携带根的实部（增长/衰减趋势），$\cos,\sin$ 只负责振荡。漏掉 $e^{\alpha x}$，解就完全错了。<span class="marginnote">物理直觉：$\alpha<0$ 是阻尼振荡（振幅衰减）、$\alpha>0$ 是增幅振荡（自激）、$\alpha=0$ 是无阻尼简谐运动（等幅振荡）。第三级《信号与系统》里极点的位置决定响应形态，与此完全同构。</span>

## 3 重根与高阶推广

对 $m$ 重根 $r_0$，线性无关的解组是

$$e^{r_0 x},\quad x\,e^{r_0 x},\quad x^2 e^{r_0 x},\quad \dots,\quad x^{m-1} e^{r_0 x}$$

共 $m$ 个。直觉：重根意味着「同一个指数频率被叠加了 $m$ 次」，需要用 $x^k$ 把「退化」的方向补齐。

**高阶例子**：$y^{(4)} - 2y'' + y = 0$。特征方程 $r^4 - 2r^2 + 1 = (r^2-1)^2 = 0$，根为 $r = 1, 1, -1, -1$（两个二重实根）。基本解组：

$$e^x,\quad x e^x,\quad e^{-x},\quad x e^{-x}$$

通解 $y = (C_1 + C_2 x)e^x + (C_3 + C_4 x)e^{-x}$。<span class="marginnote">这条方程在力学里对应「梁的振动」模型：特征根的成对出现（$\pm$）反映系统的对称性。特征方程能不能分解，取决于是否掌握因式分解的技巧——$r^4 - 2r^2 + 1$ 一眼看出平方差，是省时的关键。</span>

**复根也计重数**：若 $\alpha \pm i\beta$ 是 $m$ 重共轭复根，则对应 $2m$ 个实解

$$e^{\alpha x}\cos\beta x,\ e^{\alpha x}\sin\beta x,\ x e^{\alpha x}\cos\beta x,\ x e^{\alpha x}\sin\beta x,\ \dots$$

## 4 公式解析：特征方程 $r^2 + ar + b = 0$ 的根与解型对照

这张对照表是二阶常系数方程的「解码器」：

- **第一步，$r$ 的三个身份**：判别式 $\Delta = a^2 - 4b$ 的符号决定根型——$\Delta>0$ 两实根，$\Delta=0$ 重根，$\Delta<0$ 共轭复根。根的实部 $\alpha = -a/2$ 由系数 $a$ 直接决定：**$a>0$ 时 $\alpha<0$，系统必然衰减**——这就是阻尼项的意义。
- **第二步，为什么重根要补 $x$**：把 $y = x e^{r_0 x}$ 代入二阶方程可验证是解。更深的理由在 10 节的换元视角：重根对应「特征多项式的导数也为零」，需要从参数族里「挤」出新的独立方向。
- **第三步，复根如何变实**：$e^{(\alpha+i\beta)x} = e^{\alpha x}(\cos\beta x + i\sin\beta x)$。由于系数为实数，方程的解空间对共轭封闭：实部 $e^{\alpha x}\cos\beta x$ 与虚部 $e^{\alpha x}\sin\beta x$ 各自都是实解，且线性无关。
- **第四步，定解初值**：$n$ 阶方程配 $n$ 个初值 $y(x_0), y'(x_0), \dots, y^{(n-1)}(x_0)$，代入通解解出 $C_1,\dots,C_n$——一个 $n$ 元线性方程组。朗斯基在 $x_0$ 处非零，保证解存在唯一。

## 5 物理背景：阻尼谐振子

二阶常系数方程最经典的物理样本是**阻尼谐振子**

$$m\,\ddot{x} + c\,\dot{x} + k\,x = 0$$

写成 $x'' + \frac{c}{m}x' + \frac{k}{m}x = 0$，特征方程 $r^2 + \frac{c}{m}r + \frac{k}{m} = 0$，判别式 $\Delta = \left(\frac{c}{m}\right)^2 - \frac{4k}{m}$。

三种运动形态与三种根型一一对应：

- **欠阻尼**（$\Delta < 0$）：共轭复根，$x = e^{-\gamma t}(C_1\cos\omega_d t + C_2\sin\omega_d t)$——衰减振荡，来回摆但幅度递减；
- **临界阻尼**（$\Delta = 0$）：二重根，$x = (C_1 + C_2 t)e^{-\gamma t}$——最快回到平衡、不振荡；
- **过阻尼**（$\Delta > 0$）：两个负实根，$x = C_1 e^{r_1 t} + C_2 e^{r_2 t}$——缓慢爬回平衡、永不过冲。

**辨析｜易错点：** 临界阻尼是「不振荡」与「振荡」的分界，常被误记成「临界 = 振荡」。物理上临界阻尼是减震器设计的理想目标（门、仪表指针），阻尼再小一点就会来回摆。从特征根的重数理解它（二重根），就不会记反。<span class="marginnote">把三种形态对应到特征根平面：复根对在左半平面呈一对共轭点，越靠左衰减越快；重根是复根对「合并」的临界。第二级《理论力学》与第三级《自动控制》会从相平面与控制视角再画这张图。</span>

### 复根重数的处理

高阶方程里，共轭复根也可能重。若 $\alpha + i\beta$ 是 $m$ 重根（则 $\alpha - i\beta$ 也是 $m$ 重），对应 $2m$ 个线性无关实解：

$$e^{\alpha x}\cos\beta x,\ x e^{\alpha x}\cos\beta x,\ \dots,\ x^{m-1} e^{\alpha x}\cos\beta x$$

$$e^{\alpha x}\sin\beta x,\ x e^{\alpha x}\sin\beta x,\ \dots,\ x^{m-1} e^{\alpha x}\sin\beta x$$

**例子**：$y^{(4)} + 2y'' + y = 0$。特征方程 $r^4 + 2r^2 + 1 = (r^2+1)^2 = 0$，根 $\pm i$ 各为二重。基本解组

$$\cos x,\ \sin x,\ x\cos x,\ x\sin x$$

通解 $y = (C_1 + C_2x)\cos x + (C_3 + C_4x)\sin x$。

**直觉**：重根的「$x^k$ 因子」与实根重根完全同理——每重一次，就在原指数/三角外多乘一个 $x$。写成「多项式 × 指数 × 三角」的框架，四阶、五阶都不怕。<span class="marginnote">这条规律背后的结构定理是：特征方程的每个根贡献的「独立方向数」等于它的重数。重数 2 给两个方向，重数 3 给三个——这正是解空间维数 $n$ 的另一种计数方式。</span>

**速记**：$y'' + ay' + by = 0$ 的类型只看判别式 $\Delta = a^2 - 4b$——正负决定根型，$a$ 的符号决定稳定。这棵「判别式决策树」是二阶问题的万能起手式。

## 6 小结

- **常系数齐次线性方程**用指数试探 $y = e^{rx}$ 化为**特征方程** $r^n + a_1 r^{n-1} + \cdots = 0$。
- 相异实根 → 指数解线性组合；共轭复根 $\alpha \pm i\beta$ → $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$；**重根 $m$ 重** → 补 $x^k e^{rx}$（$k=0,\dots,m-1$）。
- 复根情形**别丢指数因子 $e^{\alpha x}$**；根的实部决定增长/衰减，虚部决定振荡频率。
- $n$ 阶方程配 $n$ 个初值即可定解，基本解组的朗斯基恒非零保证唯一。
