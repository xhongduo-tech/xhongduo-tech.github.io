## 为什么这两类方程放在一起

可分离、齐次是「形状凑巧」才能用的招。可现实里大量一阶方程形如

$$y' + p(x)\,y = q(x)$$

既分离不了，也未必齐次，却无处不在：RC 电路充电、物体下落受空气阻力、连续复利叠加——都是这个形状。<span class="marginnote">RC 电路：电容两端电压满足 $RC\,u' + u = E$，电阻、电容、电源参数全藏进 $p(x)$ 与 $q(x)$。一阶线性方程是物理、电路、生物建模的「万金油」。</span>

而**伯努利方程** $y' + p(x)y = q(x)y^n$ 只比线性多了一个 $y^n$——正是这个 $n$ 破坏了线性，但一次换元就能把它「打回」线性。所以两兄弟同节登场：一个引入核心武器**积分因子**，一个展示「换元归化」的通用套路。

## 1 一阶线性方程与积分因子

**一阶线性方程（标准形式）**：$y' + p(x)\,y = q(x)$。$q(x) \equiv 0$ 时叫**齐次**（线性意义），此时方程 $y' + p y = 0$ 本身就是可分离的：

$$\frac{dy}{y} = -p(x)\,dx \quad\Longrightarrow\quad y = C\,e^{-\int p(x)\,dx}$$

$q(x) \not\equiv 0$ 时叫**非齐次**，这是本节的主战场。<span class="marginnote">标准形式必须把 $y'$ 的系数化成 $1$。若题目给的是 $a(x)y' + b(x)y = c(x)$，先整体除以 $a(x)$，再识别 $p, q$。漏掉这步是初学者最常见的第一步错。</span>

**关键思想——找积分因子**：如果给方程两边同乘一个函数 $\mu(x)$，使得左端恰好是某个乘积的导数，就能「积回去」：

$$\mu(x)\big(y' + p\,y\big) = \mu(x)\,q(x) \quad\Longrightarrow\quad \text{希望} \quad \big(\mu\,y\big)' = \mu\,y' + \mu'\,y$$

对比两边，需要 $\mu' = p\,\mu$，解得

$$\mu(x) = e^{\int p(x)\,dx}$$

这个 $\mu$ 称为**积分因子（integrating factor）**。<span class="marginnote">为什么一定存在？因为 $\mu'/p = \mu$ 是线性齐次方程，通解就是 $e^{\int p}$。积分因子的思想来自莱布尼茨与欧拉：不直接解方程，而是「乘一个因子把左边凑成整导」。</span>

## 2 积分因子法的完整流程

求解 $y' + p(x)\,y = q(x)$ 的三步走：

**第一步**：算积分因子 $\mu = e^{\int p\,dx}$（**不写任意常数**，因为只需要一个）。

**第二步**：两边乘 $\mu$，左端收成整导：

$$\big(e^{\int p\,dx}\,y\big)' = e^{\int p\,dx}\,q(x)$$

**第三步**：两边积分，解出 $y$：

$$y = e^{-\int p\,dx}\left[\int e^{\int p\,dx}\,q(x)\,dx + C\right]$$

这条通解公式值得背下来——它是本章最重要的一条「成品公式」。

**例子**：解 $y' + \dfrac{1}{x}\,y = x^2$（$x>0$）。$p = 1/x$，$\int p\,dx = \ln x$，积分因子 $\mu = e^{\ln x} = x$。两边乘 $x$：

$$(xy)' = x^3 \quad\Longrightarrow\quad xy = \frac{x^4}{4} + C \quad\Longrightarrow\quad y = \frac{x^3}{4} + \frac{C}{x}$$

验证：直接代回原方程确实成立。<span class="marginnote">注意 $\mu = e^{\ln x}$ 我们取了正的 $x$。若定义域含负数，$\int \frac{dx}{x} = \ln|x|$，$\mu = |x|$，但习惯上仍写 $x$——因为差一个常数因子不影响解族，这正是积分因子「一个就够」的原因。</span>

## 3 伯努利方程：换元归化

**伯努利方程（Bernoulli equation）**：

$$y' + p(x)\,y = q(x)\,y^n, \qquad n \neq 0, 1$$

当 $n = 0$ 它退化为线性非齐次；$n = 1$ 退化为线性齐次。真正的挑战是 $n \geq 2$ 或 $n \leq -1$。

**解法**：两边除以 $y^n$，再换元 $u = y^{1-n}$：

$$\frac{y'}{y^n} + p(x)\,y^{1-n} = q(x)$$

令 $u = y^{1-n}$，则 $u' = (1-n)\,y^{-n}\,y'$，于是

$$u' + (1-n)\,p(x)\,u = (1-n)\,q(x)$$

**这是一阶线性方程！** 用积分因子解出 $u$，再代回 $y = u^{1/(1-n)}$。

**例子**：解 $y' + y = xy^2$。$n=2$，除 $y^2$ 得 $y^{-2}y' + y^{-1} = x$。令 $u = y^{-1}$，$u' = -y^{-2}y'$，得

$$-u' + u = x \quad\Longrightarrow\quad u' - u = -x$$

线性方程，$\mu = e^{-x}$，解得 $u = x + 1 + C e^{x}$，故 $y = \dfrac{1}{x + 1 + Ce^{x}}$。<span class="marginnote">这里 $u$ 可正可负可过零，$y = 1/u$ 在 $u$ 过零处无定义——解的存在区间是「不碰到 $u = 0$ 的区间」，下一节《解的存在唯一性定理》会给这个说法严谨的版本。</span>

**辨析｜易错点：** 伯努利换元的三个坑——① 忘记讨论 $n=0,1$ 退化情形；② 除以 $y^n$ 时可能丢 $y \equiv 0$ 的解（$n>0$ 时 $y=0$ 使右端为零，是解）；③ $u$ 的指数算错：$u = y^{1-n}$，不是 $y^n$ 的倒数（除非 $1-n$ 恰为 $-n$）。

## 4 公式解析：$y = e^{-\int p\,dx}\left[\int e^{\int p\,dx}\,q\,dx + C\right]$

这条通解公式是一阶线性方程的全部精华，逐层拆开：

- **第一步，$\mu = e^{\int p\,dx}$ 是什么**：它是「把 $y' + py$ 变回 $( \mu y)'/\mu$」的修正因子。凡左端能被凑成整导的函数，都叫这个方程的一个积分因子。
- **第二步，为什么公式里有「两层指数」**：外层 $e^{-\int p}$ 负责把 $(\mu y)'$ 里的 $\mu y$ 还原成 $y$；内层 $\int e^{\int p} q\,dx$ 是「整导的原函数」。一进一出，结构对称，像脱衣服再穿回来。
- **第三步，$C$ 落在哪里**：$C$ 出现在中括号里，最后被外层指数乘出来。若把 $C$ 移到括号外会改变形式但不改变解族——数学上等价，书写上不美观。
- **第四步，与齐次解的关系**：$C=0$ 时得到一个特解；$C$ 前的部分 $e^{-\int p\,dx}$ 正是对应齐次方程 $y' + py = 0$ 的通解。**非齐次通解 = 对应齐次通解 + 一个特解**——这条结构定理会在第二篇《线性方程解的结构》再次大放异彩。

## 5 工程例：RL 电路

RL 电路（电阻 + 电感串联）的电流 $i(t)$ 满足

$$L\,i' + R\,i = E(t), \qquad L, R \text{ 为常数}$$

化成标准形 $i' + \frac{R}{L}i = \frac{E(t)}{L}$，积分因子 $\mu = e^{(R/L)t}$。两边乘 $\mu$ 得 $\left(e^{(R/L)t} i\right)' = \frac{E(t)}{L} e^{(R/L)t}$。直流电源 $E \equiv E_0$ 时积分：

$$i(t) = \frac{E_0}{R} + C\,e^{-(R/L)t}$$

电流从初值指数趋稳到 $E_0/R$，时间常数 $\tau = L/R$——电感越大，趋稳越慢。<span class="marginnote">这就是积分因子法的第一现场：没有积分因子，这条方程虽然也可分离，但先分离再凑公式反而绕远路；有了 $\mu$，一阶线性方程「乘、收、积」三步成型。</span>

**辨析｜易错点：** 特解要猜对：$i' + (R/L)i = E_0/L$ 的常数特解是 $i^* = E_0/R$（不是 $E_0$ 也不是 $E_0/L$）。猜特解时把 $i^* = A$ 代入，解出 $A$——「特解 + 齐次通解」的结构定理在这里再次立功。

## 6 小结

- **一阶线性方程** $y' + p(x)y = q(x)$ 用**积分因子** $\mu = e^{\int p\,dx}$ 求解：两边乘 $\mu$，左端凑成 $(\mu y)'$，两边积分即得通解。
- **标准形式优先**：先把 $y'$ 系数化为 1，再识别 $p, q$。
- **伯努利方程** $y' + py = qy^n$：除以 $y^n$ 后换元 $u = y^{1-n}$，化为线性方程求解。
- $n=0,1$ 是退化情形；$y \equiv 0$ 可能是被「除掉」的解，要单独检查。
- 非齐次通解 = 齐次通解 + 特解，这条结构性质是第二篇所有线性理论的地基。

在下一节，我们转向另一种「能积回去」的方程——**全微分方程**，并学会当它差一步时如何找**积分因子**补上这一步。
