## 为什么奇点反而更常见

上一节要求系数在展开点附近「解析」。可物理里最重要的方程偏偏在奇点上展开：**贝塞尔方程（Bessel equation）**

$$x^2 y'' + x\,y' + (x^2 - \nu^2)y = 0$$

在 $x=0$ 处系数 $x^2$ 的「导引」让 $y''$ 项系数为零——$x=0$ 是奇点。贝塞尔方程描述圆形鼓膜振动、光纤中的模式、热传导的圆柱对称解，无处不遇。<span class="marginnote">为什么奇点附近重要？因为「圆的中心」「柱的轴心」天然是坐标的奇点。把坐标原点放在圆心上，方程就在 $x=0$ 有奇性——我们必须在奇点处求解，逃不开。</span>

弗罗贝尼乌斯发现：只要奇点是「正则」的（奇性不高于某个门槛），解仍能写成 $x^r$ 乘幂级数的**广义幂级数**。本节给奇点分类、给广义级数定形、给出指标方程这把钥匙。

## 1 奇点分类：普通点、正则奇点、非正则奇点

对 $y'' + p(x)y' + q(x)y = 0$，在 $x_0$ 处：

- **普通点（ordinary point）**：$p, q$ 在 $x_0$ 解析。
- **正则奇点（regular singular point）**：$p$ 至多一阶极点、$q$ 至多二阶极点——即 $(x-x_0)p(x)$ 与 $(x-x_0)^2 q(x)$ 在 $x_0$ 解析。
- **非正则奇点（irregular singular point）**：奇性更剧烈，例如 $p \sim 1/(x-x_0)^2$。

判别例：方程 $x^2 y'' + xy' + (x^2-\nu^2)y = 0$ 中 $p = 1/x$，$xp = 1$ 解析 ✓；$q = (x^2-\nu^2)/x^2$，$x^2 q = x^2 - \nu^2$ 解析 ✓。故 $x=0$ 是正则奇点。<span class="marginnote">非正则奇点的典型例子是 $y'' + \frac{1}{x^2}y' + y = 0$：$p$ 有二阶极点，$xp = 1/x$ 不解析。这类方程在奇点附近解的行为可能极其狂暴（本质奇点），弗罗贝尼乌斯方法失效。</span>

**辨析｜易错点：** 判正则奇点，只看「乘上最少的 $(x-x_0)^k$ 后是否解析」。$p$ 的分母次数 ≤ 1 且 $q$ 的分母次数 ≤ 2 是硬标准。$q$ 若含 $\ln$、含 $(x-x_0)^{-3}$，都不是正则奇点。

## 2 弗罗贝尼乌斯方法

在正则奇点 $x_0$（平移后可设 $x_0 = 0$）处，设**广义幂级数**

$$y = x^r \sum_{n=0}^{\infty} a_n x^n = \sum_{n=0}^{\infty} a_n x^{n+r}, \qquad a_0 \neq 0$$

其中 $r$ 待定。代入方程，**最低次幂 $x^{r-2}$（或对应首项）的系数**给出关于 $r$ 的方程：

**指标方程（indicial equation）**：

$$r(r-1) + p_0 r + q_0 = 0$$

其中 $p_0 = \lim_{x\to 0} x\,p(x)$，$q_0 = \lim_{x\to0} x^2 q(x)$。指标方程的两个根 $r_1, r_2$ 决定解的结构。<span class="marginnote">指标方程的直觉：在奇点附近，$x^r$ 主导解的奇性，而 $p_0, q_0$ 是「奇点强度的读数」。$r$ 的两个根就像「奇点处的特征值」，刻画解在 $x\to 0$ 时以何种幂次起跳。</span>

**求解流程**：先解指标方程得 $r_1, r_2$（设 $\operatorname{Re} r_1 \ge \operatorname{Re} r_2$），再按下列情形构造。

## 3 三种情形与第二个解

**情形一：两根差非整数**（$r_1 - r_2 \notin \mathbb{Z}$）。两个线性无关解都形如广义幂级数：

$$y_1 = x^{r_1}\sum a_n x^n, \qquad y_2 = x^{r_2}\sum b_n x^n$$

分别代入递推即可。

**情形二：两根相等**（$r_1 = r_2 = r$）。第二个解含 $\ln x$：

$$y_2 = y_1 \ln x + x^{r}\sum b_n x^n$$

**情形三：两根差为整数**（$r_1 - r_2 = N \in \mathbb{Z}^+$）。$y_1 = x^{r_1}\sum a_n x^n$ 照常；$y_2$ 可能含 $\ln x$：

$$y_2 = C\,y_1 \ln x + x^{r_2}\sum b_n x^n$$

其中 $C$ 可能为零（此时就是普通级数），需代入递推具体判断。<span class="marginnote">「差为整数」是弗罗贝尼乌斯方法最烦的情形：较小的根 $r_2$ 代入递推可能遇到分母 $(r_2 + n)(\cdots)$ 在某处为零而中断，逼出 $\ln x$ 项。降到二阶的具体处理见降阶法——$y_2 = y_1\int e^{-\int p dx}/y_1^2 dx$ 总是兜底。</span>

**例子（贝塞尔方程 $\nu = 0$）**：$x^2 y'' + xy' + x^2 y = 0$。$p_0 = 1, q_0 = 0$，指标方程 $r(r-1) + r = r^2 = 0$，重根 $r = 0$。代入广义级数得 $y = J_0(x) = \sum_{n=0}^\infty \frac{(-1)^n}{(n!)^2}\left(\frac{x}{2}\right)^{2n}$（第一类贝塞尔函数），第二个解含 $\ln x$ 的是第二类贝塞尔函数 $Y_0$。

## 4 公式解析：指标方程 $r(r-1) + p_0 r + q_0 = 0$

这把钥匙决定了奇点附近解的形状，逐层拆：

- **第一步，$p_0, q_0$ 是什么**：$p_0 = \lim x\,p(x)$，$q_0 = \lim x^2 q(x)$。在正则奇点处这两个极限都存在有限——它们把「系数的奇性」压缩成两个数。
- **第二步，从代入哪里来**：把 $y = x^r\sum a_n x^n$ 代入，最低次项（$n=0$）来自 $y''$ 的 $r(r-1)a_0 x^{r-2}$、$py'$ 的 $p_0 r a_0 x^{r-2}$、$qy$ 的 $q_0 a_0 x^{r-2}$。合并得 $a_0 x^{r-2}\big[r(r-1)+p_0 r+q_0\big]$。
- **第三步，为什么 $a_0 \neq 0$**：$a_0$ 是首项系数，约定非零；于是中括号必须为零，这正是指标方程。<span class="marginnote">指标方程的本质：<strong>最低幂次的系数匹配</strong>。它不像普通点那样自动给出 $r=0$，而是让 $r$ 从「自由参数」变成「被指标方程锁定的特征值」。</span>
- **第四步，根的类型决定结构**：$r$ 的两个根差非整数 → 双纯广义级数；重根/差整数 → 引入 $\ln x$。$r$ 的取值还直接影响收敛区间：解在 $0<|x|<R$（挖掉奇点的去心邻域）内收敛。

## 5 贝塞尔函数的应用与性质

贝塞尔方程在 $\nu$ 为整数时，解 $J_\nu(x)$ 描述**圆柱对称**的振动与波动：圆形鼓膜的低频振动模式、圆柱波导中的电磁波、光纤的模式场、热传导在圆柱体中的径向分布。工程手册里处处是 $J_0, J_1$ 的表。

$J_\nu$ 的几个基础性质（都可从级数推出）：

- **收敛半径**：级数 $J_\nu(x) = \sum_{k=0}^\infty \frac{(-1)^k}{k!\,\Gamma(k+\nu+1)}\left(\frac{x}{2}\right)^{2k+\nu}$ 对一切 $x$ 收敛（分母含阶乘，收敛半径无限）。
- **零点**：$J_\nu$ 在正半轴有可数无穷多个零点且交错排列——对应鼓膜的不同振动模式。
- **递推**：$xJ_\nu' = \nu J_\nu - xJ_{\nu+1}$，一族 $J_\nu$ 可以互相生成。<span class="marginnote">当 $\nu$ 非整数时 $J_\nu$ 与 $J_{-\nu}$ 构成基本解组；$\nu$ 为整数时两者线性相关（$J_{-n} = (-1)^n J_n$），第二个解换成含 $\ln x$ 的第二类贝塞尔函数 $Y_\nu$——正是「指标根差为整数」情形的具体实现，回头印证第 3 节的理论。</span>

**辨析｜易错点：** 别把「$\nu$ 整数时的 $J_\nu$ 与 $J_{-\nu}$」当成两个独立解——它们线性相关，缺一个维度。需要第二解时用 $Y_n$，而不是 $J_{-n}$。

### 指标根差为整数的处理细则

情形三（$r_1 - r_2 = N$ 正整数）最容易翻车，这里给一套保险流程。先按较大根 $r_1$ 正常求出 $y_1 = x^{r_1}\sum a_n x^n$；再对较小根 $r_2$ 代入广义级数：

- 若递推在 $n = N$ 处分子也为零（恰好不矛盾），则 $r_2$ 也给出一个纯广义级数解 $y_2$，**不需要 $\ln$ 项**；
- 若递推在 $n = N$ 处遇到「$0 \times a_N = $ 非零常数」的矛盾，则 $r_2$ 路走不通，$y_2$ 必须含 $\ln x$。

**例子**：$x^2y'' + x^2 y' - 2y = 0$ 在 $x=0$。指标方程 $r(r-1) - 2 = 0$，根 $r = 2, -1$，差 $3$。对 $r=2$ 求 $y_1$；对 $r=-1$ 代入，递推到 $n=3$ 时矛盾，于是 $y_2 = y_1\ln x + x^{-1}\sum b_n x^n$。<span class="marginnote">「分子恰好为零」的情形对应贝塞尔方程 $\nu$ 半整数时的表现——$J_{1/2}$ 与 $J_{-1/2}$ 线性无关，给出闭式解。判定靠的是代入后的具体递推，不是根本身。</span>

**辨析｜易错点：** 差为整数 ≠ 一定有 $\ln$ 项——要实际代入递推才知道。两条支路的判据是「$n=N$ 处的系数方程是恒等式还是矛盾式」，这一判据必须在每个具体方程里重算，不能背结论。

**对照记忆**：普通点 ↔ $r=0$ 的「退化指标方程」（自动成立）；正则奇点 ↔ 指标方程真正起作用；非正则奇点 ↔ 指标方程无定义。三个台阶，一套思想。

**练习建议**：每解一个弗罗贝尼乌斯问题，都先把指标方程写出来、把三情形列出来，再动笔代入——先把结构看穿，再埋头计算。

**历史注记**：弗罗贝尼乌斯 1873 年提出这套方法时，正值特殊函数研究的高潮；它一举统一了贝塞尔、勒让德、超几何方程的求解。

**前瞻**：正则奇点理论在第三级《偏微分方程》里将以「Fuchs 定理」的形式继续出现；下一节我们则先进入一阶方程组的新世界。

## 6 小结

- **奇点三分**：普通点（$p,q$ 解析）、正则奇点（$xp$、$x^2q$ 解析）、非正则奇点（奇性更强）。
- **弗罗贝尼乌斯方法**：$y = x^r\sum a_n x^n$，由最低次幂得到**指标方程** $r(r-1)+p_0r+q_0=0$。
- 指标根差非整数 → 两个纯广义幂级数；根相等或差整数 → 第二个解含 $\ln x$。
- 贝塞尔方程 $x^2y'' + xy' + (x^2-\nu^2)y=0$ 是正则奇点理论的旗舰案例，解为贝塞尔函数。
- 非正则奇点方法失效，需换用渐近展开等其他工具。
