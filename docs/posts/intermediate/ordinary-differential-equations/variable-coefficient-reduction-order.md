## 为什么变系数方程要靠「借力」

常系数与欧拉方程是「结构凑巧」的特例。一般的变系数方程

$$y'' + p(x)\,y' + q(x)\,y = 0$$

既没有 $e^{rx}$ 的好运，也没有 $x^r$ 的对称，通常写不出初等函数的通解。那怎么办？数学家的策略很实际：**如果你已经知道一个解，就能把方程降一阶**。这叫**降阶法（reduction of order）**——把一个「不会解的方程」交给「已经会解的方程」。

更广义地，「降阶」还指两类特殊结构的变系数方程可以靠换元降低阶数：缺 $y$ 的方程（$F(x,y',y'')=0$）与缺 $x$ 的方程（$F(y,y',y'')=0$）。本节把这两张牌都打出来。<span class="marginnote">降阶思想在数值方法里也有回声：求解二阶边值问题常化为两个一阶问题迭代（打靶法），第三级《数值分析》会细说。</span>

## 1 已知一个解，求第二个解

**降阶法核心命题**：若 $y_1$ 是 $y'' + p(x)y' + q(x)y = 0$ 的一个非零解，则令 $y = y_1 u$（$u$ 待定），代入方程可化为关于 $u'$ 的一阶方程。

推导一遍：$y = y_1 u$，则 $y' = y_1' u + y_1 u'$，$y'' = y_1'' u + 2y_1'u' + y_1 u''$。代入并用 $y_1'' + p y_1' + q y_1 = 0$ 消去含 $u$ 的项，得

$$y_1 u'' + (2y_1' + p y_1)u' = 0$$

令 $v = u'$，它是关于 $v$ 的一阶线性齐次方程。解出 $v$ 再积分得 $u$。最终**公式**：

$$y_2 = y_1(x) \int \frac{e^{-\int p(x)\,dx}}{y_1^2(x)}\,dx$$

**例子**：已知 $y'' - \dfrac{2}{x^2} y = 0$（即 $y'' + 0\cdot y' - \frac{2}{x^2}y=0$）有一个解 $y_1 = x^{-1}$（代入验证：$y_1'' = 2x^{-3}$，$2x^{-3} - \frac{2}{x^2}\cdot\frac{1}{x} = 0$ ✓）。用公式，$p = 0$：

$$y_2 = x^{-1}\int \frac{dx}{(x^{-1})^2} = x^{-1}\int x^2\,dx = x^{-1}\cdot\frac{x^3}{3} = \frac{x^2}{3}$$

取常数因子 $3$，$y_2 = x^2$。通解 $y = C_1 x^{-1} + C_2 x^2$。<span class="marginnote">注意 $y_2$ 里的常数因子 $1/3$ 被吸收进 $C_2$，所以写基本解组时可任意缩放。降阶法的全部意义：<strong>一条已知解，换一个线性无关的解。</strong></span>

## 2 缺 $y$ 与缺 $x$ 的两类降阶

### 缺 $y$：$F(x,\ y',\ y'') = 0$

方程不含 $y$，只含 $y'$ 及其导数。令 $p = y'$，则 $y'' = p'$，方程化为关于 $p$ 的一阶方程。

**例子**：$x y'' + y' = 0$。令 $p = y'$，得 $x p' + p = 0$，分离变量得 $p = C_1/x$，再积分 $y = C_1 \ln|x| + C_2$。<span class="marginnote">这条方程其实是「$y'$ 满足一阶线性方程」：先解出 $y'$，再积分一次。物理里常见——比如电场沿径向的方程常缺 $y$ 项。</span>

### 缺 $x$：$F(y,\ y',\ y'') = 0$

方程不含自变量 $x$。此时把 $y$ 当自变量，令 $p = y'$，则

$$y'' = \frac{dp}{dx} = \frac{dp}{dy}\cdot\frac{dy}{dx} = p\,\frac{dp}{dy}$$

方程化为关于 $p$（以 $y$ 为自变量）的一阶方程。

**例子**：$y y'' - (y')^2 = 0$。令 $p = y'$，$y'' = p\,dp/dy$，代入得 $y p \frac{dp}{dy} = p^2$。$p\neq 0$ 时约去 $p$：$y\frac{dp}{dy} = p$，分离得 $\frac{dp}{p} = \frac{dy}{y}$，$p = C_1 y$。再由 $y' = C_1 y$ 得 $y = C_2 e^{C_1 x}$。<span class="marginnote">缺 $x$ 方程的物理母版是<strong>单摆</strong>：$\ddot\theta + (g/l)\sin\theta = 0$ 不含时间 $t$，可令 $p = \dot\theta$ 积分一次得到能量守恒式。这个手法在第三篇《相平面与奇点分类》里是主角。</span>

**辨析｜易错点：** 缺 $x$ 时 $y'' = p\,dp/dy$ 而非 $dp/dx$。$p$ 是「$y'$」，但换自变量后 $p$ 是 $y$ 的函数，求导必须用链式法则在 $y$ 坐标下进行。这是本节翻车率最高的点。

## 3 已知特解与非齐次情形

降阶法不仅处理齐次方程，也给非齐次方程提供弹药。若已知齐次方程的一个解 $y_1$，用**参数变易法**（11 节）设 $y = u_1 y_1 + u_2 y_2$，其中 $y_2$ 由降阶法得出，即可求解 $y'' + p y' + qy = g(x)$。

更妙的是，对非齐次方程若**碰巧知道一个特解 $y^*$**，则令 $y = y^* + z$，$z$ 满足对应的齐次方程——求解又回到降阶法的射程。<span class="marginnote">工程里「先猜一个特解再化齐次」是常用试探：电路里已知稳态解，瞬态部分就是齐次解。这种「特解分离」思想与线性代数里「特解 + 零空间」完全一致。</span>

**降阶法公式也可用于求参数变易的 $y_2$**：若你只有一个齐次解 $y_1$，用本节公式构造 $y_2$，再套用 11 节的 $u_1', u_2'$ 公式，非齐次方程就被完整拿下。两节内容在此汇合。

## 4 公式解析：$y_2 = y_1 \displaystyle\int \frac{e^{-\int p\,dx}}{y_1^2}\,dx$

降阶法最浓缩的成果，逐层拆：

**第一步，为什么设 $y = y_1 u$**：把一个未知函数换成「已知解 × 待定因子」。由于 $y_1$ 已经满足方程，代入后含 $u$ 的项全部抵消——这就是「借力」的机制。
**第二步，为什么只剩 $u'$ 的一阶方程**：$y'' + py' + qy = 0$ 代入 $y_1u$ 后，$u$ 的系数恰为 $y_1'' + py_1' + qy_1 = 0$（清零）；$u''$ 的系数为 $y_1$；$u'$ 的系数为 $2y_1' + py_1$。于是方程退化为 $y_1 u'' + (2y_1' + py_1)u' = 0$，**不含 $u$ 本身**——一阶化成功。
**第三步，解一阶方程**：令 $v = u'$，$y_1 v' + (2y_1'+py_1)v = 0$。这是可分离/线性齐次方程，解出 $v = \dfrac{C e^{-\int p\,dx}}{y_1^2}$。
**第四步，积分回代**：$u = \int v\,dx$，$y_2 = y_1 u$。公式里的 $C$ 被吸收，所以直接写 $y_2 = y_1\int\frac{e^{-\int p dx}}{y_1^2}dx$。<span class="marginnote">这个公式也验证了 Abel 公式：$W(y_1,y_2) = y_1^2 \cdot \frac{e^{-\int p dx}}{y_1^2} = e^{-\int p dx}$，与 9 节的 $W' = -pW$ 自洽。</span>

## 5 综合例：给定一个解的降阶全程

方程 $x^2 y'' - xy' + y = 0$（$x>0$）有一个解 $y_1 = x$（代入：$0 - x + x = 0$ ✓）。用降阶法求 $y_2$。

先把方程化成标准形 $y'' + py' + qy = 0$：除以 $x^2$ 得 $y'' - \frac1x y' + \frac1{x^2} y = 0$，$p = -1/x$。套公式：

$$y_2 = y_1 \int \frac{e^{-\int p\,dx}}{y_1^2}dx = x \int \frac{e^{\ln x}}{x^2}dx = x \int \frac{1}{x}dx = x\ln x$$

通解 $y = C_1 x + C_2 x\ln x$。**验证**：$y_2' = \ln x + 1$，$y_2'' = 1/x$，代入 $x^2y'' - xy' + y = x - x\ln x - x + x\ln x = 0$ ✓。<span class="marginnote">对照看，这条方程也是欧拉方程（$a = -1, b = 1$），特征方程 $(r-1)^2 = 0$ 重根 $r = 1$，基本解组 $x,\ x\ln x$——与降阶法结果完全一致。两条路互相印证，是检验计算的标准姿势。</span>

**辨析｜易错点：** 降阶公式要求先化成**标准形**（$y''$ 系数为 1）。直接拿原始系数套公式会错——$p$ 必须是「除以最高阶系数之后」的那个函数。上面若误把 $p$ 当 $0$，会算出错误的 $y_2$。

### 二阶线性方程的可解性一览

把第二篇的方法按「系数结构」归位，画一张地图：

| 方程结构 | 解法 | 关键前提 |
| --- | --- | --- |
| 常系数 $ay'' + by' + cy = g$ | 特征根 + 待定系数/参数变易 | 系数为常数 |
| 欧拉 $x^2y'' + axy' + by = 0$ | 设 $y = x^r$ 或换元 $t=\ln x$ | 系数是「常数 × $x^{阶数}$」 |
| 已知一个解 | 降阶法 | 有一个 $y_1$ |
| 普通点 | 幂级数解法 | 系数在展开点解析 |
| 正则奇点 | 弗罗贝尼乌斯方法 | 奇点正则 |
| 其余 | 定性/数值 | 不求公式解 |

**读图**：降阶法是「已知一个解时的杠杆」；幂级数与弗罗贝尼乌斯是「无解可借时的兜底」。前三行靠「代数化」求闭式，后三行靠「级数/几何」求表示。<span class="marginnote">这张表也是第二篇的复习提纲：遇到新方程，先问「系数什么结构」，再选解法。工程里七成二阶方程落在前两行。</span>

**辨析｜易错点：** 降阶法不是独立解法，而是「借用已知解的杠杆」——它必须搭配一个来源（猜解、欧拉、级数）。空手起家想用降阶法，等于没有支点撬地球。

**收束**：降阶法、换元、级数——变系数方程三件套各有各的适用窗口；认准系数结构，就能选对武器。第二篇在此收官，下一节进入方程组与定性理论。

## 6 小结

- **降阶法**：已知一个解 $y_1$，设 $y = y_1 u$ 可把二阶方程化为一阶，得 $y_2 = y_1\int \frac{e^{-\int p dx}}{y_1^2}dx$。
- **缺 $y$ 的方程**：令 $p = y'$，直接降一阶。
- **缺 $x$ 的方程**：令 $p = y'$ 且 $y'' = p\,dp/dy$，以 $y$ 为自变量降一阶；单摆方程即此型。
- 已知特解时令 $y = y^* + z$ 化齐次；降阶法 + 参数变易法配合可解一般非齐次变系数方程。
- 降阶法不是「解出来」，而是「把不会的变会」——它把问题转移给一阶方程。

在下一节，我们换一种完全不同的思路：不再求初等函数解，而是把解写成**幂级数**——幂级数解法。
