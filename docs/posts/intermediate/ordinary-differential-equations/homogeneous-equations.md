## 为什么需要换元

上一节的分离变量法只认一种形状：右端能拆成「$x$ 函数 × $y$ 函数」。可现实中的方程往往拆不开——$y' = \dfrac{x + y}{x - y}$ 右端既不能写成纯 $x$ 乘纯 $y$，也没有明显的因子结构。<span class="marginnote">这类方程的共同特征是：右端只依赖比值 $y/x$。把坐标系「缩放到能看见比值」的角度看，问题就豁然开朗。</span>

解法思路是**换元**：引入新未知函数 $u = y/x$，把「绕不动的 $y$」换成「好算的 $u$」。换元不是新解法，而是把新方程**翻译回**可分离变量的老朋友。这一招换元，后面还会反复出现——伯努利方程换 $u = y^{1-n}$，欧拉方程换 $t = \ln x$，靠的都是同一个哲学：**改换视角，让结构显形**。

## 1 什么是齐次方程（一阶意义）

**一阶齐次方程**：形如

$$y' = f\left(\frac{y}{x}\right)$$

的方程。它只依赖比值 $y/x$。等价地，$y' = f(x,y)$ 中 $f(x,y)$ 是**零次齐次函数**：对任意 $\lambda \neq 0$，

$$f(\lambda x,\ \lambda y) = f(x,\ y)$$

即 $x, y$ 同时缩放时，右端不变。<span class="marginnote">「齐次」一词还有另一重含义：在线性方程里，「齐次」指右端 $g(x) \equiv 0$。同一个词两副面孔，是术语史留下的旧账——一阶这里的「齐次」指次数齐次，第二篇里的「齐次」指自由项为零。上下文判断，别无他法。</span>

**辨析｜易错点：** 「齐次方程」有两个完全不同但都叫「齐次」的概念。① 本节的 $y' = f(y/x)$（关于 $x,y$ 零次齐次）；② 线性方程 $y'' + py' + qy = 0$ 的右端为零。考试里若题干只写「齐次」，要靠方程形状推断含义——**含 $y/x$ 比值结构的是本节主角，右端为 0 的线性方程是第二篇主角**。

## 2 换元 $u = \dfrac{y}{x}$ 的完整流程

设 $u = \dfrac{y}{x}$，即 $y = ux$。两边对 $x$ 求导（**注意 $u$ 也是 $x$ 的函数**）：

$$\frac{dy}{dx} = u + x\,\frac{du}{dx}$$

代入原方程 $y' = f(y/x) = f(u)$，得

$$u + x\,u' = f(u) \quad\Longrightarrow\quad x\,\frac{du}{dx} = f(u) - u$$

右端只含 $u$，左端是 $x \cdot u'$——**这正是可分离变量方程**：

$$\frac{du}{f(u) - u} = \frac{dx}{x}$$

积分后再把 $u = y/x$ 代回，得到原方程的解。

**完整走例**：解 $y' = \dfrac{y}{x} + \tan\dfrac{y}{x}$。换 $u = y/x$ 得

$$u + xu' = u + \tan u \quad\Longrightarrow\quad x\,\frac{du}{dx} = \tan u$$

$$\int \frac{\cos u}{\sin u}\,du = \int \frac{dx}{x} \quad\Longrightarrow\quad \ln|\sin u| = \ln|x| + C$$

$$\sin u = C x \quad\Longrightarrow\quad \boxed{\,\sin\frac{y}{x} = Cx\,}$$

这是一条隐式解。<span class="marginnote">注意最后一步的 $C$：$\ln|\sin u| = \ln|x| + C_1$ 两边取指数得 $|\sin u| = e^{C_1}|x|$，把 $e^{C_1}$ 与符号一起写成新常数 $C$。反复出现的「常数洗牌」是解方程的老手艺。</span>

## 3 实操：化齐次的标准套路

若方程是 $y' = \dfrac{a_1 x + b_1 y + c_1}{a_2 x + b_2 y + c_2}$ 这种「线性分式」形状，先尝试**平移消去常数项**再化齐次：

- **情形 A**：$\Delta = a_1 b_2 - a_2 b_1 \neq 0$（两直线不平行）。解线性方程组
  $$a_1 x + b_1 y + c_1 = 0, \qquad a_2 x + b_2 y + c_2 = 0$$
  得交点 $(x_0, y_0)$。令 $X = x - x_0,\ Y = y - y_0$，常数项消失，方程化为 $dY/dX = f(Y/X)$——回到齐次。
- **情形 B**：$\Delta = 0$（两直线平行或重合），此时 $a_1x+b_1y$ 与 $a_2x+b_2y$ 成比例，直接设 $u = a_1x + b_1y$ 一次换元即可分离。

**例子**：解 $y' = \dfrac{x - y + 1}{x + y - 3}$。交点满足 $x - y + 1 = 0,\ x + y - 3 = 0$，解得 $x_0 = 1,\ y_0 = 2$。令 $X = x - 1,\ Y = y - 2$，则 $dY/dX = \dfrac{X - Y}{X + Y}$。再设 $v = Y/X$，继续化齐次并分离。整个过程是一套「平移 → 比值换元 → 分离」的组合拳。<span class="marginnote">这类题的价值不在计算量，而在让你记住「常数项挡路 → 先平移清障」的决策树。到了工程里，把系统状态平移到平衡点再研究，正是《非线性方程与线性化》一节的雏形。</span>

## 4 公式解析：换元求导 $y' = u + x\,u'$

这条公式是齐次方程解法的引擎。逐项拆解：

- **第一步，从哪里来**：$y = u(x)\cdot x$ 是**两个 $x$ 的函数相乘**，对它求导必须用乘积法则：$(uv)' = u'v + uv'$，即 $y' = u' \cdot x + u \cdot 1$。
- **第二步，为什么 $u$ 也是函数**：$u = y/x$，而 $y$ 是 $x$ 的未知函数，故 $u$ 依赖 $x$。若把它误当常数求导，会得到 $y' = u$（少了 $xu'$），整个方程就解错了——**这是本小节头号丢分点**。<span class="marginnote">「换元之后别忘了新变量仍是 $x$ 的函数」这条纪律，在伯努利、欧拉、降阶法里会反复考验你。</span>
- **第三步，结构意义**：$u + xu'$ 恰好把「比值 $u$」和「比值的变化率 $u'$」分开，使得代入 $y' = f(u)$ 后，未知部分只剩 $u'$——分离变量法就此接管。
- **第四步，解完回代**：求出 $u(x)$ 后必须代回 $u = y/x$ 写回 $y$，否则答非所问。回代时注意常数 $C$ 的书写形式（$C$ 还是 $\ln C$）会影响最终表达式的美观。

## 5 换元思想的统一视角

走到这里，我们把一阶方程的换元法整理成一张地图：

| 方程形状 | 换元 | 变成 |
| --- | --- | --- |
| $y' = f(y/x)$（齐次） | $u = y/x$ | 可分离 |
| $y' + py = qy^n$（伯努利） | $u = y^{1-n}$ | 一阶线性 |
| $y' = f(ax + by + c)$ | $u = ax+by+c$ | 可分离 |
| $M\,dx + N\,dy = 0$（不全微分） | 积分因子 $\mu$ | 全微分 |

共同点：**换元的目的是让方程「结构显形」**——把陌生形状翻译成已会解的三种母版（可分离、线性、全微分）。做题时先辨认形状、再选换元，比硬算高效得多。

一个综合例：$y' = \dfrac{y^2}{xy}$ 看着吓人，其实右端 $= \dfrac{(y/x)^2}{1}$ 是齐次型。换 $u = y/x$ 后 $u + xu' = u^2$，得 $\dfrac{du}{u^2-u} = \dfrac{dx}{x}$，分离积分 $\ln\left|\frac{u-1}{u}\right| = \ln|x| + C$，回代即得隐式解。<span class="marginnote">这张表会在第二篇的欧拉方程（$t = \ln x$）、第三篇的降阶（$p = y'$）里再次扩容——换元是微分方程里出现频率最高的「降维手术」。</span>

**辨析｜易错点：** 换元后的**回代**是最后一道必过关卡。算出 $u$ 的函数却忘了 $u = y/x$，等于答非所问；回代时把 $C$ 整理成最简形式（$\ln C$、$\pm e^C$ 的合并）能避免很多无谓的符号错误。

### 线性分式方程完整算例

解 $y' = \dfrac{x - y + 1}{x + y - 3}$。两条直线 $x - y + 1 = 0$ 与 $x + y - 3 = 0$ 交于 $(1, 2)$。平移 $X = x - 1,\ Y = y - 2$，得

$$\frac{dY}{dX} = \frac{X - Y}{X + Y}$$

令 $v = Y/X$，$v + X\frac{dv}{dX} = \dfrac{1 - v}{1 + v}$，整理

$$X\frac{dv}{dX} = \frac{1 - 2v - v^2}{1 + v}$$

分离积分 $\int \frac{1+v}{1-2v-v^2}dv = \int \frac{dX}{X}$。分子恰是分母的 $-\frac12$ 导数，积分得 $-\frac12\ln|1-2v-v^2| = \ln|X| + C$，回代 $v = (y-2)/(x-1)$ 得隐式解。<span class="marginnote">整条链路展示了「平移 → 齐次化 → 分离 → 回代」四步走的完整闭环。每一步的换元都是一次「翻译」，把陌生方程逐步送回可分离的老家。</span>

**辨析｜易错点：** 平移的落点是两直线交点；若忘了平移直接设 $u = y/x$，常数项 $+1, -3$ 会挡住分离变量，整个换元白费。先清常数项，再谈换元。

## 6 小结

- **一阶齐次方程**：$y' = f(y/x)$，即 $f(\lambda x, \lambda y) = f(x,y)$ 的零次齐次型。
- **核心换元** $u = y/x$，配合求导公式 $y' = u + xu'$，把方程化成可分离变量型。
- 求解链：换元 → 分离 → 积分 → **回代 $u = y/x$**。
- 「齐次」一词有**双重含义**（比值型 vs 自由项为零），必须按上下文区分。
- 线性分式方程 $y' = \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2}$：先平移消常数项（交点），再化齐次；直线平行时直接设 $u = a_1x + b_1y$。

在下一节，我们将处理一类既非可分离、也非齐次，却同样重要的方程——**一阶线性方程与伯努利方程**，它们将引入积分因子与另一类换元。
