## 为什么从可分离变量开始

上一节我们学会了「认方程」：看阶、看线性。现在开始**解方程**。第一类能干净利落地求出公式解的方程，就是**可分离变量方程**。它只有一条要求——把 $x$ 与 $y$ 分开放在等号两侧。别小看这个「分开」，人类历史上第一个微分方程解（牛顿的行星运动、马尔萨斯的人口模型）都长这个样子，而细菌培养、放射性衰变、利息复利至今仍靠它。<span class="marginnote">可分离变量方程之所以是「母版」，是因为它的解法流程——分离、两边积分、解出 $y$——会被后面几乎所有一阶解法继承，只是「如何凑到可分离」的手段不同。</span>

## 1 什么是可分离变量方程

**可分离变量方程**：一阶方程若能写成

$$\frac{dy}{dx} = g(y)\, f(x)$$

即右端能拆成「只含 $y$ 的因子」乘「只含 $x$ 的因子」，就称其为可分离变量的。更对称的写法是

$$M(x)\,dx + N(y)\,dy = 0$$

即 $x$ 的微分项与 $y$ 的微分项各归一边。<span class="marginnote">第二种写法叫<strong>微分形式</strong>。它提醒我们 $dy/dx$ 不只是记号——在分离变量法里，我们把 $dy$ 与 $dx$ 当<strong>独立的微分</strong>来搬移，这种「形式运算」在物理与工程里屡试不爽。</span>

**辨析｜易错点：** 判断「可分离」要看能不能**因式分解**。$y' = xy + y$ 可分离，因为 $xy + y = y(x+1)$；但 $y' = x + y$ 不能写成「$x$ 函数 × $y$ 函数」的形式（$x+y$ 无法因式分解），它不是可分离变量方程，得等下一节《齐次方程》换一招。<span class="marginnote">检验小技巧：若 $\partial^2/\partial x\partial y \ln$ 式能拆分……实践中最可靠的办法就是直接试：能凑成 $g(y)f(x)$ 吗？不能就换路。</span>

## 2 解法：分离、积分、回代

解法只有三步，但每一步都藏着坑：

**第一步，分离。** 把方程改写成 $g(y)\,dy = f(x)\,dx$（更规范：$\dfrac{dy}{g(y)} = f(x)\,dx$，要求 $g(y)\neq 0$）。

**第二步，两边积分。** $\displaystyle\int \frac{1}{g(y)}\,dy = \int f(x)\,dx + C$。注意**只在一边加一个任意常数**，因为两个任意常数可以合并。

**第三步，解出 $y$。** 若积分结果能反解出 $y = \varphi(x, C)$，就得显式解；解不出来就保留隐式形式 $H(y) = F(x) + C$。<span class="marginnote">隐式解不是失败：很多方程（如 $y' = \frac{y^2-1}{x}$）反解出的表达式很丑，保留隐式既准确又美观，后面《隐式方程与奇解》一节会专门讨论这种解。</span>

以标准例 $y' = ky$（指数增长/衰减模型，$k$ 为常数）走一遍：

$$\frac{dy}{dx} = k\,y \quad\Longrightarrow\quad \frac{dy}{y} = k\,dx \quad\Longrightarrow\quad \ln|y| = kx + C_1 \quad\Longrightarrow\quad y = C\,e^{kx}$$

其中 $C = \pm e^{C_1}$。$k>0$ 是指数爆炸（人口、复利），$k<0$ 是指数衰减（放射性衰变、药物半衰期）。

## 3 实操：牛顿冷却定律

**牛顿冷却定律（Newton's law of cooling）**：物体温度 $T(t)$ 的变化率正比于它与环境温度 $T_a$ 的温差：

$$\frac{dT}{dt} = -k\,(T - T_a), \qquad k > 0$$

令 $u = T - T_a$，则 $du/dt = dT/dt$，方程化为 $\dfrac{du}{dt} = -k\,u$——正好是可分离的：

$$\frac{du}{u} = -k\,dt \quad\Longrightarrow\quad u = C e^{-kt} \quad\Longrightarrow\quad T(t) = T_a + C e^{-kt}$$

设初始温度 $T(0) = T_0$，则 $C = T_0 - T_a$，得

$$T(t) = T_a + (T_0 - T_a)\,e^{-kt}$$

**读这条公式**：温差按指数衰减归零，物体温度单调趋近环境温度，永远不「过头」——$e^{-kt}$ 恒正，$(T_0-T_a)$ 的符号决定它是从上往下还是从下往上逼近。<span class="marginnote">这就是为什么刚煮好的咖啡先用几分钟降很多、之后越来越慢：温差越小，冷却越慢。一条微分方程把「冷却」这个直觉变得可计算、可预测。</span>

## 4 公式解析：$\displaystyle\int \frac{dy}{g(y)} = \int f(x)\,dx + C$

这条公式是整个分离变量法的核心。拆成四步理解：

**第一步，为什么能两边积分**：等式 $y' = g(y)f(x)$ 两边对 $x$ 积分本应写成 $\int y'\,dx = \int g(y)f(x)\,dx$，但右端含 $y$，无法直接算。于是利用 $dy = y'\,dx$ 把变量换干净：$\int \frac{dy}{g(y)} = \int f(x)\,dx$。<span class="marginnote">这里的「乘 $dx$」其实是换元法（链式法则）的简写：$\int \frac{y'(x)}{g(y(x))}\,dx = \int \frac{1}{g(y)}\,dy$。形式运算的背后是严格的变量替换。</span>
- **第二步，$g(y) \neq 0$ 的限制**：分离时要除以 $g(y)$。若 $g(y_0) = 0$，则常数函数 $y \equiv y_0$ 是方程的解（右端为零），但被除法**弄丢了**——必须单独补回。这是经典丢解陷阱。
- **第三步，常数怎么加**：两边分别得 $\ln|y| = kx + C_1$，一个 $C$ 足够。常数合并后，$e^{C_1}>0$ 与绝对值、$\pm$ 一起打包成新的任意常数 $C$（可正可负可零）。
- **第四步，唯一性**：若 $g$ 在某区间上不为零且连续，分离法得到的解在使 $f,g$ 连续的区域里是唯一的——唯一性定理会在《解的存在唯一性定理》一节严格证明。

**辨析｜易错点：** 三个高频错误——① 忘了补 $g(y)=0$ 的常数解；② $\ln|y|$ 丢了绝对值，导致解错；③ 一边积分加了一个常数、另一边又加一个，两个常数没合并。每一条都会让答案「看起来对、判卷错」。

## 5 应用：逻辑斯谛方程

指数增长 $y' = ky$ 的毛病是「无限增长」。真实种群受资源限制，于是有**逻辑斯谛方程（logistic equation）**

$$y' = k\,y\left(1 - \frac{y}{K}\right)$$

其中 $K$ 是**环境容纳量（carrying capacity）**。$y \ll K$ 时近似指数增长；$y$ 接近 $K$ 时右端趋零，增长停止。它是可分离的：

$$\int \frac{dy}{y(1-y/K)} = \int k\,dt \quad\Longrightarrow\quad \ln\left|\frac{y}{K-y}\right| = kt + C$$

反解得

$$y(t) = \frac{K}{1 + C\,e^{-kt}}, \qquad C = \frac{K - y_0}{y_0}$$

**读公式**：$t\to\infty$ 时 $y \to K$，种群单调逼近容纳量；$y_0 < K/2$ 时曲线先凹后凸，在 $K/2$ 处出现**拐点**——增长最快的时刻。这条 $S$ 形（sigmoid）曲线是生态学、传染病的 SI/SIR 模型，以及机器学习里 sigmoid 激活函数的数学祖先。<span class="marginnote">逻辑斯谛曲线在 1838 年由费尔哈斯特（Verhulst）提出，用来修正马尔萨斯的人口灾难预言；如今它出现在种群生态、新产品扩散（Bass 模型）与神经网络的激活函数里，是一条「从生物到算法」的曲线。</span>

**辨析｜易错点：** 解出后分母 $1+Ce^{-kt}$ 在 $y_0<K$ 时恒正，但当 $y_0 > K$（初始就超载）时 $C<0$，分母可能在有限时刻过零——解在那里失去意义，只能定义在分母不为零的区间上，不能盲目外延。

### 隐式解与图像直觉

可分离方程经常得到隐式解 $H(y) = F(x) + C$，比如 $y' = \dfrac{1 - y^2}{x}$ 积分得 $\ln\left|\dfrac{1+y}{1-y}\right| = 2\ln|x| + C$。隐式解的图像是等高线族 $H(y) - F(x) = C$——每一条对应一个 $C$。

**读图技巧**：在等高线图上，沿水平方向（$x$ 增大）穿越的斜率就是 $y'$。若 $H$ 在某点竖直（$H_y = 0$），隐式解在那里可能**多值**（一个 $x$ 对应多个 $y$），需要分支出显式解——这就是为什么反解时常要带 $\pm$ 与分段。

**例子**：$\ln\left|\frac{1+y}{1-y}\right| = \ln x^2 + C$ 反解 $y = \dfrac{Cx^2 - 1}{Cx^2 + 1}$。解在 $Cx^2 = -1$ 处无定义，图像分成上下两支，由 $y = \pm 1$ 两条水平渐近线隔开——当初分离时约掉的 $y = \pm 1$ 恰好是这两条线的位置。<span class="marginnote">这个例子里「丢掉的常数解」与「隐式解的分支线」严丝合缝地对上了——丢解不是意外，而是隐式解曲线的天然组成部分。回到《隐式方程与奇解》一节，你会看到这个现象的完整理论形态。</span>

**辨析｜易错点：** 隐式解多值时，别把它当「一条函数」。写明 $C$ 的取值区间与分支，或直接保留隐式，都是合法且更安全的表达。

### 为什么分离变量是「母版」

回看可分离变量的三步——分离、积分、回代——你会发现后面所有一阶解法都在复用同一个骨架：把方程变形到「两边各自只含一个变量」，再直接积分。齐次靠换元凑出 $u = y/x$，线性靠积分因子凑出 $(\mu y)'$，全微分靠找势函数——都是在「凑一个可以整体积分的形式」。

**所以**：先把可分离变量练到条件反射，再学其他解法，事半功倍。它不只是第一招，更是所有招式的共同底座。<span class="marginnote">这种「识别共同骨架」的学习方式值得推而广之：每一节新解法，都问一句「它把方程变成了哪种可积形式」——答案几乎总是「可分离」或「全微分」。抓住骨架，细节就不散。</span>

## 6 小结

- **可分离变量方程**：$y' = g(y)f(x)$，解法是分离 → 两边积分 → 解出 $y$。
- 分离时**若 $g(y_0)=0$，常数解 $y \equiv y_0$ 要单独补回**，防止丢解。
- 通解可写**显式** $y = \varphi(x,C)$ 或**隐式** $H(y) = F(x)+C$，隐式同样是合法解。
- 指数模型 $y' = ky$ 与牛顿冷却定律是最重要的两个实际应用。
- 两边积分只在一边加一个常数，$C$ 把符号与绝对值全部吸收。
