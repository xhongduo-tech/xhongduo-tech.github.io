## 为什么隐式方程值得单独一章

前五节处理的方程都能写成 $y' = f(x,y)$ 这种**显式**形式。可真实世界给的常常不是「斜率公式」，而是「斜率、位置、自变量混在一起的一个等式」：

$$F(x,\ y,\ y') = 0$$

比如 $y = (y')^2 + xy'$，你没法直接解出 $y'$。这类方程叫**隐式方程**。解它的思想不是「解出 $y'$」，而是**把 $y'$ 当作新的参数 $p$**，把方程看成 $x,y,p$ 之间的一个曲面关系，再想办法参数化求解。<span class="marginnote">这种「降维/参数化」的思路与第二级《微分几何》里用参数曲线表示曲面完全同构——把曲线写成 $(x(t), y(t))$，斜率只是众多参数中的一个。</span>

更妙的是，隐式方程会孕育出**奇解（singular solution）**——一种不属于通解族的解，它是整族积分曲线的**包络线**。奇解是微分方程理论里第一道「解的概念」裂缝：存在唯一性定理在这类解上会失效。

## 1 可解出 $y$ 或 $x$ 的隐式方程

### 情形一：方程可解出 $y$，即 $y = f(x, p)$，其中 $p = y'$

对 $x$ 求导（$p$ 视为 $x$ 的函数）：

$$p = f_x(x, p) + f_p(x, p)\,\frac{dp}{dx}$$

整理成 $x$ 与 $p$ 之间的一阶方程。若解得 $x = \varphi(p, C)$，代回 $y = f(x,p)$ 得参数形式通解：

$$\begin{cases} x = \varphi(p, C) \\ y = f\big(\varphi(p, C),\ p\big) \end{cases}$$

**例子**：$y = (y')^2$。设 $p = y'$，$y = p^2$。两边对 $x$ 求导：$p = 2p\,p'$。若 $p \neq 0$，约去 $p$ 得 $p' = 1/2$，$p = x/2 + C$，代回得 $y = \left(\frac{x}{2} + C\right)^2$。<span class="marginnote">注意上面约去 $p$ 时偷偷丢掉了 $p = 0$ 的情形。$p \equiv 0$ 给出 $y \equiv 0$——这是一条不属于通解族的解，正是奇解的雏形。所以求隐式方程时，每约一次分式都要回头问：约掉的东西等于零会怎样？</span>

### 情形二：方程可解出 $x$，即 $x = f(y, p)$

同理，对 $y$ 求导（$p$ 视为 $y$ 的函数），用 $\dfrac{dx}{dy} = \dfrac{1}{p}$ 得到 $y$ 与 $p$ 的方程，解出后参数化。

## 2 克莱罗方程与奇解

**克莱罗方程（Clairaut equation）**：

$$y = x\,p + \varphi(p), \qquad p = y'$$

对 $x$ 求导：

$$p = p + x\,p' + \varphi'(p)\,p' \quad\Longrightarrow\quad p'\big(x + \varphi'(p)\big) = 0$$

由此分出两支：

- **支一**：$p' = 0$，即 $p = C$，得通解 **$y = Cx + \varphi(C)$**——一族直线。
- **支二**：$x + \varphi'(p) = 0$，与方程联立消去 $p$，得一条曲线 $y = Y(x)$。

支二得到的曲线就是**奇解**。<span class="marginnote">直观上，通解是一族直线，奇解是这族直线共同相切的「包络」。想象把一堆直线画在一起，会看到一条弯弯的曲线被所有直线吻过——这条吻线就是包络，就是奇解。</span>

**例子**：$y = xp + \dfrac{1}{p}$。通解 $y = Cx + \dfrac{1}{C}$；奇解由 $x - \dfrac{1}{p^2} = 0$ 与 $y = xp + \dfrac{1}{p}$ 消去 $p$ 得 $y^2 = 4x$（$p = 1/\sqrt{x}$ 代入验证）。抛物线族与直线族的关系：每条切线 $y = Cx + 1/C$ 都相切于抛物线 $y^2 = 4x$。

## 3 什么是奇解

**奇解（singular solution）**：方程的某条解曲线，若在其上每一点，**过该点的积分曲线的唯一性被破坏**（即还有另一条积分曲线也过该点且在此相切），则称这条解为奇解。

三个判定抓手：

- **不来自通解**：无论 $C$ 取何值，奇解都不等于通解里的任何一条（除非退化）。
- **几何上**：奇解是通解族积分曲线的**包络线（envelope）**——每点与族中某条曲线相切，但自身不在族中。
- **求法上**：由通解 $y = \Phi(x, C)$ 消去 $C$ 于方程组
  $$y = \Phi(x, C), \qquad \frac{\partial \Phi}{\partial C} = 0$$
  得包络（$C$-判别曲线），再代回方程验证。

**辨析｜易错点：** 不是所有「解不出 $y'$ 的地方」都是奇解。求出的 $C$-判别曲线中，可能混入「与方程无关的」曲线或「退化为通解特例」的曲线。**必须把候选曲线代回原方程逐条验证**，满足方程且不在通解族中的才是奇解。<span class="marginnote">「验证」不是可选项。奇解的判定天然带着假阳性的风险，这条纪律保护你不被「看起来像」骗到。</span>

## 4 公式解析：克莱罗求导 $p = p + (x + \varphi'(p))p'$

这条看似恒等式的式子，是奇解理论的钥匙。逐项拆：

- **第一步，$y = xp + \varphi(p)$ 对 $x$ 求导**：左端是 $y'$，即 $p$；右端 $xp$ 用乘积法则得 $p + xp'$；$\varphi(p)$ 用链式法则得 $\varphi'(p)p'$。合并得 $p = p + xp' + \varphi'(p)p'$。
- **第二步，为什么 $p$ 会抵消**：因为原方程里 $xp$ 项与 $y' = p$ 恰好在求导后互为镜像。这种抵消是克莱罗方程特有的结构，也是它如此好解的原因。
- **第三步，因式分解**：移项得 $p'(x + \varphi'(p)) = 0$。两个因式必有一个为零——「积为零」在实数里就是「至少一个因子为零」，把问题劈成两条路。
- **第四步，两条路的语义**：$p' = 0$ 给出常数斜率 → 直线通解；$x + \varphi'(p) = 0$ 给出「每点斜率与位置咬合」的曲线 → 包络奇解。<span class="marginnote">「一个方程劈出通解与奇解」的戏剧性，正是奇解如此吸引数学家的原因：解的结构不再是一个简单集合，而有了「族 + 包络」的分层。</span>

## 5 求包络：C-判别曲线的完整流程

从通解 $y = \Phi(x, C)$ 求包络的标准动作：

**第一步**：把通解对 $C$ 求偏导，得 $\dfrac{\partial\Phi}{\partial C} = 0$。

**第二步**：联立 $y = \Phi(x,C)$ 与 $\partial\Phi/\partial C = 0$，消去 $C$，得到一条候选曲线 $y = \psi(x)$。

**第三步（必做）**：把 $y = \psi(x)$ 代回原微分方程验证它是解；再确认它不在通解族中（没有哪个 $C$ 恰好等于它）。

**例子**：通解 $y = Cx + C^2$。$\partial\Phi/\partial C = x + 2C = 0$，得 $C = -x/2$，代回 $y = Cx + C^2 = -\dfrac{x^2}{4}$。验证：$y = -x^2/4$ 确实满足 $y = xy' + (y')^2$（克莱罗方程），且不在直线族 $y = Cx + C^2$ 中——包络成立。<span class="marginnote">这条抛物线是「所有切线都吻过它」的包络：每条直线 $y = Cx + C^2$ 与 $y = -x^2/4$ 相切于 $x = -2C$ 处。几何直觉与代数验证在这里互相印证。</span>

**辨析｜易错点：** C-判别曲线得到的候选线可能有三种命运：① 真包络（奇解）；② 通解族中某条曲线（$C$ 取特殊值时的退化，不是奇解）；③ 与方程无关的「额外曲线」（通解表达式的奇异处）。**第三步验证不可省略**——三个结局，只有第一个是奇解。

### 参数化解的一个完整例子

方程 $y = (y')^2 + 1$。设 $p = y'$，$y = p^2 + 1$。对 $x$ 求导：$p = 2p\,p'$。

- 若 $p \neq 0$：约去 $p$ 得 $p' = \frac12$，$p = \frac{x}{2} + C$，代回 $y = \left(\frac{x}{2} + C\right)^2 + 1$——通解。
- 若 $p = 0$：$y = 1$，代入原方程 $1 = 0 + 1$ ✓。而通解中 $C$ 取任何值都得不到常数 $y = 1$，所以 $y = 1$ 是**奇解**——它恰是通解族（抛物线族）的包络，顶点轨迹 $y = 1$ 被每条抛物线相切于顶点。

**辨析｜易错点：** 分叉时的 $p=0$ 分支不是「丢掉」就完事——要代回原方程验证它是否真是解、是否在通解族中。本例两条路都要走完，漏一个都不算完整解。<span class="marginnote">「约分丢根要回头」这条纪律在隐式方程里被放到最大：每一处除以 $p$ 的地方，都对应一个可能被错过的分支。养成「每除必回头」的习惯，奇解就不容易漏。</span>

**归纳**：隐式方程的核心动作是「引入 $p = y'$ 参数化」与「每除必回头」——前者打开求解空间，后者守住奇解。这套「分叉 + 回头验证」的节奏，是隐式方程区别于显式方程的全部秘密。

## 6 小结

- **隐式方程** $F(x,y,y') = 0$：设 $p = y'$，若能解出 $y$（或 $x$），对 $x$（或 $y$）求导化为 $x,p$（或 $y,p$）的一阶方程，用参数形式表示通解。
- **克莱罗方程** $y = xp + \varphi(p)$：求导后因式分解，$p'=0$ 给直线通解，$x + \varphi'(p)=0$ 给奇解。
- **奇解**：不在通解族中、破坏唯一性、是积分曲线的**包络线**。
- 求奇解常用 $C$-判别曲线 $\{y = \Phi(x,C),\ \partial\Phi/\partial C = 0\}$，**候选必须代回原方程验证**。
- 约分时丢掉的 $p=0$、$y=0$ 等分支要逐个回头检查，它们常是奇解或常解。

在下一节，我们不再关心「怎么解」，而转向一个更根本的问题：**这个方程到底有没有解？解是不是唯一的？**——解的存在唯一性定理。
