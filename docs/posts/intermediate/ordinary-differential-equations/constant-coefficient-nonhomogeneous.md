## 为什么「非齐次」是真实世界

上一节的齐次方程描述的是「没有外力」的系统：弹簧自己振、电路自己放。可现实总有外力——风推着桥、信号驱动电路、肌肉拽着骨骼。描述这些的正是**非齐次方程**

$$y'' + a y' + b y = g(x)$$

结构定理已经给了总纲：**通解 = 齐次通解 + 特解**。齐次通解上节已会求，本节的核心任务只剩一个：**怎么求出一个特解 $y^*$**。<span class="marginnote">两条路线：<strong>待定系数法</strong>（右端是多项式、指数、三角这类「好人」时，猜特解的形式）；<strong>参数变易法</strong>（万金油，什么右端都能扛，但积分更苦）。工程中前者快、后者稳。</span>

## 1 待定系数法：猜出特解的形状

当 $g(x)$ 是三类基本函数（或其乘积组合）时，特解有固定的「猜法」。设

$$g(x) = P_m(x)\,e^{\alpha x}\cos\beta x \quad \text{或} \quad P_m(x)\,e^{\alpha x}\sin\beta x$$

其中 $P_m$ 是 $m$ 次多项式，则特解形如

$$y^* = x^s\,e^{\alpha x}\Big[Q_m(x)\cos\beta x + R_m(x)\sin\beta x\Big]$$

- $Q_m, R_m$ 是**待定**的 $m$ 次多项式（次数与 $P_m$ 相同）；
- $s$ 是「$\alpha + i\beta$ 作为特征方程根的重数」——若 $\alpha + i\beta$ 是**单根**则 $s=1$，**二重根**则 $s=2$，**不是根**则 $s=0$。<span class="marginnote">$s$ 的确定是整个猜法的机关：它保证猜出的特解与齐次通解线性无关。忘掉 $s$ 会得到「解为 0」的废等式；$s$ 取太大则无谓地多算。口诀：<strong>先查特征根，再定 $x^s$</strong>。</span>

常见退化情形速查：

| 右端 $g(x)$ | 特解形状（$s$ 见规则） |
| --- | --- |
| $m$ 次多项式 $P_m(x)$ | $x^s Q_m(x)$ |
| $e^{\alpha x}$ | $x^s C e^{\alpha x}$ |
| $\cos\beta x$ 或 $\sin\beta x$ | $x^s (A\cos\beta x + B\sin\beta x)$ |
| $P_m(x) e^{\alpha x}$ | $x^s Q_m(x) e^{\alpha x}$ |
| $e^{\alpha x}\cos\beta x$ 等 | $x^s e^{\alpha x}(A\cos\beta x + B\sin\beta x)$ |

**例子**：解 $y'' + y = 2\sin x$。齐次特征方程 $r^2 + 1 = 0$，根 $\pm i$。右端 $\sin x$ 对应 $\alpha + i\beta = i$，恰是单根，故 $s=1$。猜 $y^* = x(A\cos x + B\sin x)$。代入求得 $A = -1,\ B = 0$，特解 $y^* = -x\cos x$。通解

$$y = C_1\cos x + C_2\sin x - x\cos x$$

**辨析｜易错点：** 这里的 $x\cos x$ 项是「共振」的标志——外力频率与系统固有频率重合，振幅随时间线性增长（$x$ 乘振荡项）。若漏掉 $x$（取 $s=0$），猜 $A\cos x + B\sin x$ 代回左端恒为零，永远求不出特解，这正是「共振必须乘 $x$」的试错式验证。

## 2 参数变易法：万能后备

右端 $g(x)$ 长得不规整（如 $\tan x$、$\sec x$）时，待定系数法猜不动，改用**参数变易法（variation of parameters）**。对二阶方程 $y'' + p(x)y' + q(x)y = g(x)$：

已知齐次基本解组 $y_1, y_2$，**设 $y^* = u_1(x)\,y_1 + u_2(x)\,y_2$**——把常数 $C_1, C_2$「升级」成函数。这是把解的形状保持不变、只放松参数。<span class="marginnote">「把常数变成函数」的哲学贯穿分析：傅里叶级数、常数变易、乃至量子力学里的含时微扰，都是同一个动作。</span>

令 $u_1' y_1 + u_2' y_2 = 0$（人为加的一个规范条件，消去二阶导的麻烦），代入方程得方程组：

$$\begin{cases} u_1'\,y_1 + u_2'\,y_2 = 0 \\ u_1'\,y_1' + u_2'\,y_2' = g(x) \end{cases}$$

由克莱默法则解出 $u_1', u_2'$，积分即得 $u_1, u_2$：

$$u_1' = -\frac{y_2\,g(x)}{W(y_1,y_2)}, \qquad u_2' = \frac{y_1\,g(x)}{W(y_1,y_2)}$$

其中 $W$ 是朗斯基行列式。

**例子**：$y'' + y = \tan x$。齐次解 $y_1 = \cos x,\ y_2 = \sin x$，$W = 1$。于是

$$u_1' = -\sin x \tan x = -\frac{\sin^2 x}{\cos x}, \qquad u_2' = \cos x \tan x = \sin x$$

积分 $u_1 = \int -\frac{\sin^2 x}{\cos x}dx = \sin x - \ln|\sec x + \tan x|$，$u_2 = -\cos x$，特解为 $y^* = u_1\cos x + u_2\sin x$。这个右端若用待定系数法根本无法下笔——参数变易法完胜。

## 3 叠加原理的应用

若 $g(x) = g_1(x) + g_2(x)$，则可分别求特解再相加。这极大简化了「混合右端」：

$$y'' + y = x + \sin x \quad\Longrightarrow\quad y^*_1 = x \text{（对应 $g_1=x$）}, \quad y^*_2 = -\frac{x}{2}\cos x \text{（对应 $g_2=\sin x$）}$$

通解 $y = C_1\cos x + C_2\sin x + x - \frac{x}{2}\cos x$。<span class="marginnote">工程里把复杂激励拆成谐波叠加（傅里叶级数），逐频率求响应再求和，正是叠加原理的规模化应用——第三级《信号与系统》的线性时不变系统理论的地基。</span>

## 4 公式解析：参数变易 $u_1' = -\dfrac{y_2\,g}{W}$

这条公式是参数变易法的「输出端」，拆开看：

- **第一步，为什么设 $y^* = u_1 y_1 + u_2 y_2$**：把特解锁定在「齐次解张成的空间」里，只是让系数随 $x$ 流动。这样特解永远不会与齐次通解「撞衫」。
- **第二步，两个未知、两个方程**：$u_1', u_2'$ 是两个未知函数。约束一来自「设 $u_1'y_1 + u_2'y_2 = 0$」（人为规范），约束二来自「$y^*$ 须满足原方程」。恰好两个方程定两个未知。
- **第三步，为什么除 $W$**：克莱默法则的分母正是 $W = y_1 y_2' - y_2 y_1'$。$W \neq 0$（基本解组的保证）使方程组**总是可解**——这是参数变易法能成为万能法的根基。<span class="marginnote">对照待定系数法需要猜对形式、需要 $s$ 查根；参数变易法只要求「齐次基本解组在手」，任何 $g(x)$ 都能积分出答案（只要积分算得动）。</span>
- **第四步，为什么不丢任意常数**：$u_1, u_2$ 积分会各出一个常数，但那恰好被吸收进齐次通解 $C_1, C_2$——所以求特解时**不需要加常数**。

## 5 受迫振动与共振

无阻尼受迫振动

$$y'' + \omega_0^2 y = F_0\cos\omega t$$

齐次解是 $\omega_0$ 的简谐振动；特解由待定系数法：$\omega \neq \omega_0$ 时 $y^* = \dfrac{F_0}{\omega_0^2 - \omega^2}\cos\omega t$，振幅

$$A(\omega) = \frac{F_0}{|\omega_0^2 - \omega^2|}$$

当 $\omega \to \omega_0$，振幅 $A \to \infty$——这就是**共振（resonance）**。若加入阻尼 $y'' + 2\gamma y' + \omega_0^2 y = F_0\cos\omega t$，振幅在 $\omega \approx \sqrt{\omega_0^2 - 2\gamma^2}$ 处取有限峰值，但峰值仍远大于静态响应。<span class="marginnote">共振不只是课本玩具：塔科马海峡大桥 1940 年因风致共振倒塌，歌手的声带与胸腔共振放大音量，收音机靠调谐电路共振选台。共振 = 能量在频率匹配时被最有效地注入系统。</span>

**辨析｜易错点：** 共振频率不是固有频率本身（有阻尼时略低）。$\omega_0$ 是**固有频率**（无阻尼自由振动频率），共振峰值发生在**驱动频率**接近固有频率附近。把两者画在振幅-频率曲线上看，峰值略向左偏，别把两个概念划等号。

**路线小结**：求特解按「右端的丑度」分级——右端是多项式/指数/三角的乘积，用待定系数法（快）；右端是分式、对数、正切等，用参数变易法（通用）。考试与工程里八成题都在「好人」范围内，待定系数法用得多，但参数变易法是你永远的后备——两手都要会，别只练一招。

**验证习惯**：求完特解随手代回原方程验一遍，左端是否等于右端——三秒钟能防住八成的符号错误。

**辨析补充**：参数变易法的 $W$ 若在区间内某点为零，公式失效；但基本解组的 $W$ 恒非零，所以只要解组选对，这个方法永远可用。

## 6 小结

- **非齐次通解 = 齐次通解 + 特解**；求特解有**待定系数法**与**参数变易法**两条路线。
- **待定系数法**：右端为多项式/指数/三角时，按「形状表」猜特解，$s$ = 特征根的匹配重数，**先查根再定 $x^s$**。
- **共振**：右端频率等于固有频率时特解要乘 $x$（$s \ge 1$），振幅线性增长。
- **参数变易法**：$y^* = u_1 y_1 + u_2 y_2$，解方程组得 $u_1' = -y_2 g/W$，$u_2' = y_1 g/W$，任何右端通用。
- **叠加原理**：右端可拆分逐个求解再相加，工程上配合傅里叶分解使用。
