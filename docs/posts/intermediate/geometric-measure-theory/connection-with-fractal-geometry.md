## 为什么从分形几何收尾

本专题从 Hausdorff 测度出发，一路走到整流集、面积公式、Frostman、电流与正则性——这些工具看似抽象，却在**分形几何**里找到最直观的落点。分形（fractal）是「处处不光滑、但在无穷小尺度下有精细结构」的集合：康托尔尘、科赫雪花、Julia 集、布朗运动的像。它们不是本专题的旁枝，而是几何测度论的**测试场**：Hausdorff 测度是给分形「称重」的尺子，Frostman 引理是「算维数下界」的锤子，射影定理是「看分形投影」的透镜，整流/不可分是对分形「是否可求长」的裁判。<span class="marginnote">本专题第 1 篇开篇即提到分形，如今我们带着整套工具回来，把「自相似集维数」从猜测升级为定理——这是几何测度论与分形几何交汇点上的收官之笔。</span>

## 1 自相似集与迭代函数系统

分形几何最核心的构造是**迭代函数系统（IFS，iterated function system）**。

**核心概念（IFS 与自相似集）**：$\mathbb{R}^n$ 上的一族压缩相似映射 $S_1, \dots, S_N$（每个 $S_i(x) = r_i R_i x + t_i$，$0 \lt  r_i \lt  1$，$R_i$ 是正交变换）构成一个 **IFS**。唯一的非空紧集 $F$ 满足

$$
F \;=\; \bigcup_{i=1}^{N} S_i(F)
$$

称为该 IFS 的**吸引子 / 自相似集**。

**Hutchinson 定理**：每个 IFS 都有唯一的吸引子 $F$。证明用**压缩映射定理**：把「集合」看作完备度量空间（$\mathbb{R}^n$ 的紧子集配 Hausdorff 距离），映射 $S \mapsto \bigcup_i S_i(S)$ 是压缩映射，不动点即 $F$。<span class="marginnote">Hausdorff 距离（两紧集互为 $\varepsilon$-邻域的最小 $\varepsilon$）让「集合的空间」成为完备度量空间，压缩映射原理在此成立——这是分形存在性的抽象保证，也把第 1 篇的「覆盖语言」用到极致。</span>

自相似集里最熟悉的例子：康托尔三分集（$N=2$，$r_1=r_2=1/3$）、科赫曲线（$N=4$，$r_i=1/3$）、Sierpiński 三角（$N=3$，$r_i=1/2$）。

## 2 相似维数与 Moran 公式

对「恰好分离」的自相似集，维数有闭式公式。

**核心概念（相似维数）**：IFS 的**相似维数** $s$ 是满足

$$
\sum_{i=1}^{N} r_i^{s} \;=\; 1
$$

的唯一实数。对满足**开集条件（OSC，open set condition）**的 IFS（存在非空开集 $O$ 使 $S_i(O) \subset O$ 且 $S_i(O)$ 互不相交），Hutchinson 定理 + 测度论可以证明：

$$
\dim_{\mathrm{H}} F \;=\; s
$$

且 $0 \lt  \mathcal{H}^{s}(F) \lt  \infty$。<span class="marginnote">开集条件排除「重叠太多」的病态（如 $S_1, S_2$ 同时覆盖同一区域）。等比例情形 $r_i \equiv r$ 时，$s = \log N / \log(1/r)$——康托尔集 $\log2/\log3$、Sierpiński 三角 $\log3/\log2$ 都是这一公式的特例，第 1 篇的猜测在此得到严格证明。</span>

**Moran 公式**是相似维数的推广：当压缩比 $r_i$ 各不相同时，维数 $s$ 满足 $\sum_i r_i^s = 1$（同样是隐式方程）。这套「从自相似方程解维数」的框架，把第 1 篇的自相似方程 $\mathcal{H}^s(C) = 2\cdot 3^{-s}\mathcal{H}^s(C)$ 推广成一般的 $\sum r_i^s = 1$。

**辨析｜易错点：** 相似维数不是「测得的」维数，而是「猜的」维数。它只在开集条件下等于 Hausdorff 维数；对重叠的 IFS，$\dim_{\mathrm{H}} F$ 可能严格小于相似维数。例如 $S_1, S_2$ 都把 $[0,1]$ 映到 $[0,1/2]$（完全重叠），相似维数 $\log2/\log2 = 1$ 而实际 $\dim_{\mathrm{H}} F = \dim_{\mathrm{H}}[0,1/2] = 1$——恰巧相等；但更精细的重叠可以造成严格不等。判定「何时相似维数 = Hausdorff 维数」是活跃课题（Furstenberg 猜想等）。

## 3 公式解析：从自相似方程到 Moran 公式

用第 1 篇的康托尔集做模板，把「自相似方程」严格化。设 $F$ 是满足 $F = \bigcup_i S_i(F)$ 的自相似集，$S_i$ 压缩比为 $r_i$。

**第一步，维数上界**：对任意 $\delta > 0$，用第 $k$ 代的小拷贝 $S_{i_1}\circ\cdots\circ S_{i_k}(F)$ 覆盖 $F$。每个拷贝直径 $\le (r_{\max})^k \le \delta$，其 $s$-维成本为 $\left(\prod r_{i_j}\right)^s$。对所有 $N^k$ 个拷贝求和，得 $\mathcal{H}^s_\delta(F) \le \sum_{i_1,\dots,i_k} \prod_j r_{i_j}^s = \left(\sum_i r_i^s\right)^k$。若 $\sum_i r_i^s = 1$，则成本 $\le 1$，故 $\dim_{\mathrm{H}} F \le s$。

**第二步，维数下界（需开集条件）**：利用开集条件构造 Frostman 测度：在 $F$ 上定义测度 $\mu$，使每个 $k$ 级拷贝质量 $\mu(S_{i_1}\cdots S_{i_k}(F)) = \left(\prod r_{i_j}\right)^s$。由于开集条件保证不同拷贝「几乎不相交」、且相似性缩放质量，可证 $\mu(B(x,r)) \le C r^s$。由 Frostman 引理，$\dim_{\mathrm{H}} F \ge s$。

**第三步，合成**：上界 + 下界 = $\dim_{\mathrm{H}} F = s$。<span class="marginnote">这个三步证明完美串联了本专题三件工具：覆盖（第 1 篇）给上界、Frostman 测度（第 7 篇）给下界、开集条件保证测度的均匀性。自相似集的维数公式是「覆盖与测度对偶」最干净的展示。</span>

**重点：开集条件的作用是「让构造的 Frostman 测度真的满足球质量控制」。** 没有开集条件，重叠的拷贝会让质量堆积、破坏 $\mu(B(x,r)) \le C r^s$，下界论证崩溃。

## 4 分形几何与几何测度论的工具互通

把本专题的工具与分形的概念逐项对照，能看到一条清晰的「工具-对象」图谱：

**Hausdorff 测度 / 维数**（第 1 篇）→ 自相似集的维数公式（Moran 公式）；
**覆盖定理**（第 2 篇）→ 分形集的测度逼近、$\mathcal{H}^s$ 的正则性；
**密度定理**（第 3 篇）→ 分形测度的局部结构、密度不为 0/1 的分形（与 Lebesgue 密度定理的 0/1 二值性形成对比）；
- **Frostman 引理**（第 7 篇）→ 分形维数下界、能量与容量的位势论；
- **整流 / 不可分**（第 5 篇）→ 分形的可求长性判定：康托尔尘纯不可分，圆周可求长；
- **射影定理**（第 11 篇）→ 自相似集投影的维数、Kakeya 型问题。

**比较表**：可求长分形与纯不可分分形的测度论对照。

| 性质 | 可求长分形（如圆周、科赫的局部） | 纯不可分分形（如康托尔尘） |
| --- | --- | --- |
| Hausdorff 维数 | 与拓扑维数相关 | 可高于拓扑维数任意多 |
| 切空间 | 几乎处处存在 | 几乎处处不存在 |
| 密度 | 几乎处处 = 重数 | 几乎处处 0 或发散 |
| 投影 | 保维（几乎处处） | 投影维数由 Marstrand/Kaufman 控制 |
| 复动力系统 | Julia 集可求长的情形 | Julia 集纯不可分的情形 |

## 5 分形几何的开放前沿与本专题的接口

分形几何的现代前沿与几何测度论深度交织，几个方向值得留下路标：

- **重叠 IFS 的维数**：当自相似集严重重叠时，维数公式是否仍为 $\min\{s, n\}$？Furstenberg 猜想与相交性质相关，用射影定理与例外集分析。
- **动力系统吸引子的维数**：Julia 集、Lorenz 吸引子的 Hausdorff 维数常需「不变量测度」与「维数 = 熵 / Lyapunov 指数」型的公式（Ledrappier–Young 公式），本质是测度论 + 遍历理论。
- **随机分形**：布朗运动的像、随机康托尔集的维数，用覆盖与 Frostman 的「随机版」计算——集中不等式替代确定性估计。<span class="marginnote">布朗运动 $B$ 在 $\mathbb{R}^n$（$n \ge 2$）的像的 Hausdorff 维数是 2（几乎必然），这个经典结果同时用到覆盖（上界）与 Frostman/能量（下界），是随机版工具的样板。</span>
**PDE 与分形**：奇异测度的能量有限性决定变分问题的适定性（第 7 篇的能量判据），分形的位势论因此进入椭圆方程与自由边界问题。

**辨析｜易错点：** 「分形」没有公认的唯一定义（Mandelbrot 给出的是启发式特征：精细结构、不可求长、自相似或自仿射、维数常高于拓扑维数）。在严谨的几何测度论里，「分形」作为一个范畴不如「$s$ 维测度为正的集合」「纯不可分集」这些精确定义的对象好用——研究者通常绕过「分形」这个词，直接谈论维数、测度、可求长性。这本身就是一个重要的方法论提示：**把形容词换成可测的数量，是数学成熟的第一步。**

## 6 分形几何在「从极限到大模型」主线上的位置

分形几何不仅是几何测度论的测试场，它还与这条博客主线——从极限到大模型——有实际的接口。

**与动力系统的接口**：迭代函数系统的吸引子、Julia 集的维数，本质是「压缩映射迭代的长期几何」。动力系统理论中，维数公式（如 $\dim_{\mathrm{H}} = \text{熵}/\text{Lyapunov 指数}$）把「信息增长率」与「几何复杂度」相连——这与深度学习中「表征的维度随层数增长」在精神上相通：复杂结构的维数常由「逐层放大或收缩的速率」决定。<span class="marginnote">熵公式的直观：每次迭代把不确定性放大约 $e^h$ 倍（$h$ 是拓扑熵），把尺度缩小约 $e^{-\lambda}$ 倍（$\lambda$ 是 Lyapunov 指数），两者相除得到「信息维数」$h/\lambda$。几何维数由此与信息论接通。</span>

**与数据科学的接口**：高维数据的「本征维数」（intrinsic dimension）估计，就是用几何测度论的维数概念去度量「数据点云铺在多低维的流形上」。流形学习（manifold learning）假设数据落在低维整流流形附近，而噪声、离群点对应纯不可分部分——第 5 篇的「整流 + 纯不可分」分解正是这一假设的数学表述。深度学习里「数据流形假设」与「维度灾难」都共享同一套测度论语言：低维流形在高维空间里测度为 0，却承载全部概率质量——Frostman 条件式的「质量集中在低维集」正是它的严格化。

**与物理的接口**：分形的自相似性与相变临界现象的联系（重整化群）、湍流的多分形描述，都用 Hausdorff 维数与测度密度刻画「多尺度结构」——几何测度论提供了「在无穷多尺度上同时成立」的精确语言。

## 7 小结

- **IFS 与自相似集**：$F = \bigcup_i S_i(F)$ 的唯一紧解（Hutchinson），Hausdorff 距离 + 压缩映射定理保证存在性。
- **相似维数 / Moran 公式**：$\sum_i r_i^s = 1$ 的根 $s$；开集条件下 $\dim_{\mathrm{H}} F = s$ 且 $\mathcal{H}^s(F)$
