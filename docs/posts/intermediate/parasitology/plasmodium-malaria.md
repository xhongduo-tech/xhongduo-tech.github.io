# 疟原虫：形态、生活史与疟疾防治

## 为什么从疟原虫开始

疟原虫（*Plasmodium\*）是人类寄生虫学中最重要的一种——它曾与人类纠缠百万年，至今每年仍致全球约 2 亿例感染、数十万人死亡（多为非洲儿童）。它是**蚊媒传播、红细胞内寄生、周期性发热**三个标签的集大成者，也是第1篇「终宿主在蚊、中间宿主在人」反直觉规则的完美例证。更重要的是，疟疾的防治史——从奎宁到青蒿素，从灭蚊到疫苗——是一部完整的「基础科学 → 公共卫生」转化史。

在「从极限到大模型」的谱系里，疟原虫的红细胞内增殖是一个天然的**周期性动力系统**：裂体增殖的同步化产生周期性发热，这是把「生物学节奏」翻译成「数学周期」的绝佳样例。

## 1 疟原虫的种类与形态

寄生于人体的疟原虫主要有四种，各有形态与临床特征：

| 种 | 中文名 | 发热周期 | 临床特点 |
| --- | --- | --- | --- |
| *P. falciparum\* | 恶性疟原虫 | 36–48 h（不规则） | 最凶险，可致脑型疟、黑尿热 |
| *P. vivax\* | 间日疟原虫 | 48 h（间日） | 常见，有复发现象（休眠子） |
| *P. ovale\* | 卵形疟原虫 | 48 h | 少见，有休眠子 |
| *P. malariae\* | 三日疟原虫 | 72 h（三日） | 慢性，可致肾病综合征 |

<span class="marginnote"><strong>恶性疟与间日疟的鉴别是疟疾学第一课</strong>：恶性疟原虫在血中仅见环状体与配子体（晚期滋养体被隔在内脏血管），红细胞内可见<strong>多寄生</strong>与<strong>蓝状点彩（Maurer 裂）</strong>；间日疟可见各期滋养体，红细胞胀大并见<strong>薛氏点（Schüffner 点）</strong>。红细胞形态的「胀大/不胀大」是快速分种的关键。</span>

**血中常见形态**：**环状体（ring form）**——小环状、核一偏于一侧（早期滋养体）；**滋养体**——阿米巴样增大、疟色素出现；**裂殖体（schizont）**——核分裂为多个裂殖子；**配子体（gametocyte）**——雌雄配子体，是感染蚊的阶段。

## 2 生活史：人与蚊的双宿主循环

疟原虫生活史跨越两个宿主，是第1篇「世代交替」与「终/中间宿主」概念的完美应用：

**人体内（无性生殖，中间宿主）**：

1. **红外期（exo-erythrocytic stage）**：按蚊叮咬注入**子孢子（sporozoite）** → 随血流至肝细胞 → 在肝细胞内行**裂体增殖**（红外期裂殖体），形成**红外期裂殖子** → 释放入血。
2. **红内期（erythrocytic stage）**：裂殖子侵入红细胞 → 依次经历**环状体→滋养体→裂殖体** → 红细胞破裂，裂殖子释放再侵入新红细胞，循环进行（48/72 h 一个周期）。部分裂殖子发育为**配子体**，雌雄配子体进入血液。<span class="marginnote">间日疟与卵形疟原虫在肝内还形成<strong>休眠子（hypnozoite）</strong>——潜伏数月后可激活引起<strong>复发（relapse）</strong>，这是「治好血中虫、却治不净肝中虫」的根源。根治必须加用杀休眠子的药物（伯氨喹）。</span>

**按蚊体内（有性生殖，终宿主）**：

3. 按蚊吸血吸入雌雄配子体 → 在蚊胃内**配子生殖**（雌雄配子结合成合子）→ 合子发育为**动合子（ookinete）** → 穿出胃壁，在胃壁外侧形成**卵囊（oocyst）** → 卵囊内行**孢子增殖**，产生大量**子孢子** → 子孢子逸出，移行至唾液腺 → 再次叮咬时注入新宿主。

**辨析｜易错点：** 又一次印证总论规则——**疟原虫在蚊体内行有性生殖，所以按蚊是终宿主；人体内行无性生殖，人是中间宿主。**「蚊子传播疟疾」这句话在通俗语境没错，但在严格术语里，蚊不是「传播者」而是「有性生殖的终点站」。此外，**红外期感染有潜伏期**：恶性疟潜伏期约 9–14 天，间日疟更长。

## 3 致病机制与临床表现

**周期性发热的机制**：红内期裂殖体成熟、红细胞破裂、裂殖子释放时，虫体代谢产物（疟色素、GPI 锚定物）与红细胞碎片一并入血，刺激单核-巨噬细胞释放**内源性致热原（TNF-α、IL-1、IL-6）**，引起发热。**同步裂解 → 同步发热**，故发热呈周期性：间日疟隔日寒战-高热-大汗，三日疟隔两日。<span class="marginnote">发热的「三期」（寒战期、高热期、大汗期）对应病理事件：寒战 = 红细胞同步破裂 + 致热原释放的瞬间；高热 = 下丘脑调定点升高；大汗 = 体温骤降散热。异时破裂（初次感染多批次）时热型紊乱，是诊断的干扰项。</span>

**贫血与脾大**：裂体增殖直接破坏红细胞；免疫机制（抗体致敏红细胞被脾清除）加重贫血。长期感染致脾大、脾功能亢进。

**凶险型疟疾（主要为恶性疟）**：

**脑型疟（cerebral malaria）**：感染红细胞通过 PfEMP1 蛋白黏附于脑微血管内皮（**sequestration**），堵塞微血管 + 局部炎症 → 昏迷、抽搐，病死率高——非洲儿童疟疾死亡的主因。
**黑尿热（blackwater fever）**：大量溶血致血红蛋白尿（酱油色尿）、急性肾衰竭。<span class="marginnote">脑型疟的病理核心是<strong>黏附</strong>而非单纯虫体数量：恶性疟原虫感染的红细胞表面表达 PfEMP1，与内皮受体（CD36、ICAM-1）结合，把血管「堵」成血栓样阻塞。这同时是「解剖隔离型免疫逃避」的极致——虫体躲过脾脏清除，代价是宿主脑缺血。</span>

**孕妇与儿童**：孕妇疟疾致低出生体重、流产；儿童反复感染致贫血与营养不良。

## 4 诊断

**血涂片镜检（金标准）**：发热时采血，**薄血膜定种、厚血膜找虫**（厚血膜溶血后浓缩虫体）。注意采血时机：在发热前（红细胞破裂前）虫体密度最高时检出率最高。

**快速诊断试纸（RDT）**：检测恶性疟原虫富组氨酸蛋白 2（HRP-2）等抗原，数分钟内出结果，适用于基层与无镜检条件地区。

**分子检测**：PCR 敏感特异，用于定种与低密度感染、疗效考核。<span class="marginnote">RDT 的短板值得记住：<strong>HRP-2 抗原在治疗后可在血中残留数周</strong>，导致「假阳性」——已治愈者 RDT 仍阳性。这是「抗原检测用于疗效判断」的经典陷阱，与第6节「查抗体不能分现症/既往」互为补充。</span>

## 5 公式解析：疟疾传播的媒介学门槛

疟疾能否在人群中维持，取决于一个简洁的阈值条件——**媒介能量（vectorial capacity）**的门槛：

$$R_0 = \frac{ma^2 bc \, p^n}{-\ln p}$$

- $m$：媒介密度（蚊/人）；$a$：蚊叮人频率；$b$：蚊对疟原虫的易感性；$c$：人对蚊的传染性。
- $p$：蚊**日存活率**（每日活到次日的概率）；$n$：疟原虫在蚊体内**外潜伏期（孢子增殖期）**天数。
- 直观理解：分母 $-\ln p$ 与指数 $p^n$ 共同反映**蚊必须活得够久，疟原虫才能发育到可传播阶段**。若蚊寿命太短（$p$ 小）或潜伏期太长（$n$ 大），$p^n$ 急剧衰减，$R_0$ 跌破 1，疟疾无法维持。

**这条公式是防蚊灭蚊的数学根基**：即使不能消灭全部蚊子，只要**缩短蚊寿命**（杀虫剂滞留喷洒）或**延长外潜伏期**（让蚊活不到传播期），$R_0$ 就会骤降。中国消除疟疾正是「压低媒介密度 + 缩短媒介寿命 + 治疗传染源」三管齐下的结果。

## 6 防治

**治疗**：以**青蒿素为基础的联合疗法（ACT）**为一线——青蒿素快速杀灭血中无性期虫体，联合药清除残余虫体并延缓耐药。青蒿素源自中国药学家屠呦呦对青蒿的现代发掘，2015 年获诺贝尔生理学或医学奖。<span class="marginnote">青蒿素的故事是「传统药物 + 现代方法」的典范：屠呦呦从东晋《肘后备急方》「青蒿一握，以水二升渍，绞取汁」得到低温提取的启发，用乙醚低温萃取获得青蒿素。抗疟活性强、起效快，但<strong>单药半衰期短、易复发</strong>，故必须与长效药联合成 ACT——药物动力学的缺陷要靠联合用药弥补。</span>

**间日疟/卵形疟根治**：加用**伯氨喹**杀肝内休眠子，防止复发。

**预防**：

- **防蚊灭蚊**：蚊帐（长效杀虫蚊帐 ITN）、室内滞留喷洒（IRS）、清除积水孳生地——对应媒介能量公式的 m 与 p。
- **药物预防**：赴疫区旅行者口服氯喹或多西环素等。
- **疫苗**：**RTS,S/AS01（Mosquirix）**——全球首款获批疟疾疫苗，针对子孢子期，保护效力有限（约 30–40%，儿童重症保护更佳）；新一代 R21 疫苗在推进。疫苗进展缓慢的根本原因仍是**抗原变异性与免疫逃避**。

## 延伸：青蒿素与现代抗疟药物史

疟疾的药物史是医学史上最跌宕的篇章之一，也是「从天然产物到现代药理」的完整案例，值得在这里作一次速览：

**奎宁（quinine）**：源自南美金鸡纳树皮，17 世纪传入欧洲，曾是抗疟的唯一特效药。二战时盟军靠它保住了东南亚战场，也因供应被切断而催生了合成替代。

**氯喹（chloroquine）**：1940 年代合成的喹啉类药，便宜、安全、高效，一度让「根除疟疾」成为全球雄心。但 1960 年代起，**恶性疟原虫对氯喹的抗药性从东南亚和南美扩散到全球**——单药时代的经典教训：**抗药性是单药策略的必然宿命**。

**青蒿素（artemisinin）**：屠呦呦团队从《肘后备急方》「青蒿一握，以水二升渍，绞取汁」获得低温提取启发，用乙醚低温萃取得到青蒿素，2015 年获诺贝尔奖。青蒿素含**过氧桥**结构，在虫体内被铁激活生成自由基、破坏虫体蛋白——**机制独特、起效极快**，但单药半衰期短、易复发。

**ACT（青蒿素联合疗法）**：为对抗抗药性，青蒿素必须与长效药（如苯芴醇、哌喹）**联合使用**——青蒿素快速清除血中虫体、长效药清除残留并延缓耐药。**「联合用药」成为抗疟治疗的金标准**，也是应对微生物/寄生虫抗药性的通用策略（与结核病 DOTS、HIV 鸡尾酒疗法同源）。

**抗药性的最新警报**：大湄公河次区域已出现**青蒿素部分抗药性**（延迟清除型）——这提醒我们，**药物研发与抗药性监测是一场永无止境的赛跑**。理解这条药物史，你就理解了为什么「单药」在寄生虫病里几乎总是次优解。

## 7 小结

- 四种人体疟原虫，**恶性疟最凶险**；发热周期（48/72 h）源于红内期**同步裂体增殖**。
- 生活史：人体**红外期→红内期→配子体**（无性生殖），蚊体内**配子生殖→孢子增殖**（有性生殖）——**蚊是终宿主，人是中间宿主**。
- 恶性疟的重症机制是**红细胞黏附 sequestration**（脑型疟）与**大量溶血**（黑尿热）。
- 诊断：**血涂片定种找虫**（金标准）、RDT 快检、PCR 定种。
- 媒介能量公式 $R_0 = ma^2bc\,p^n/(-\ln p)$：压低媒介寿命与密度、延长外潜伏期，即可让传播自然崩溃。

疟原虫是「蚊媒传播 + 红细胞内寄生 + 周期性发热」的集大成者，也是免疫逃避与防治博弈的完整体。结束疟疾篇，第2篇原虫学还剩最后一员——弓形虫与机会致病性孢子虫，它们的共同敌人是免疫力低下的宿主。
