## 为什么从钩虫与蛲虫开始

肠道线虫的另一对主角：**钩虫**（*Ancylostoma duodenale*、*Necator americanus*）与**蛲虫**（*Enterobius vermicularis*）。它们与蛔虫、鞭虫同为土源性线虫，但走的是**另一条感染路线**——**钩虫的幼虫经皮肤钻入**（赤脚下田），靠**吸食肠壁血液**引起缺铁性贫血；**蛲虫则是「儿童病」的代名词**——肛周产卵、夜间瘙痒、家庭聚集，靠**肛门—手—口**自身体外重复感染。一个「田间病」、一个「家庭病」，把土源性线虫的传播谱系补全。

在「从极限到大模型」的谱系里，这一节是「**感染途径决定一切**」的对照组：蛔虫/鞭虫「吃卵」、钩虫「钻皮」、蛲虫「手口」——**三条都属土源性，却因入口不同，防治措施（穿鞋 vs 洗手）完全不同**。

## 1 钩虫：形态与生活史

**钩虫**：体小（长 7–13 mm），**细长、前端弯曲如钩**（故名钩虫）。两种主要种：

**十二指肠钩虫**（*Ancylostoma duodenale*，口囊腹侧有 2 对齿）与**美洲钩虫**（*Necator americanus*，口囊腹侧有 1 对切板）——「**齿 vs 切板**」是定种关键。

**生活史（直接型、经皮肤钻入、有肺移行）**：

1. **感染**：钩虫卵随粪排出，在**温暖湿润的土壤**中孵出幼虫，蜕皮 2 次后发育为**丝状蚴（感染期幼虫）**。
2. **钻入**：人**赤脚/皮肤接触土壤**时，丝状蚴**经皮肤主动钻入**（引起**钩蚴性皮炎**，局部瘙痒丘疹）→ 入血 → 经**肺**（肺移行）→ 沿气管至咽 → 吞入小肠。
3. **定居**：幼虫在小肠发育为成虫，**以口囊吸附肠壁**，**吸食血液**并分泌抗凝物质，产卵随粪排出。<span class="marginnote">钩虫的感染场景很「农业」：<strong>农民赤脚下田、儿童赤脚玩耍</strong>，丝状蚴从土壤钻入足部皮肤——「赤脚接触土壤」是钩虫传播的核心画面。它的<strong>肺移行与蛔虫类似</strong>（幼虫须经肺到咽再吞下），而「<strong>经皮肤钻入 + 吸食血液</strong>」则是钩虫的独门标签。</span>

## 2 钩虫：致病与临床

**幼虫期**：

**钩蚴性皮炎**：丝状蚴钻皮处出现**瘙痒性红色丘疹、水疱**（「粪毒」「着土痒」）——田间劳动者的经典皮损。
**肺移行症状**：咳嗽、哮喘样发作（较轻）。

**成虫期（核心致病）**：

**缺铁性贫血（钩虫病的主要危害）**：钩虫吸附肠壁、**吸血 + 抗凝**，使伤口持续渗血——**慢性失血是钩虫贫血的机制**。轻者面色苍白、乏力、头晕；重者**贫血性心脏病、水肿（「大肚病」）**，孕妇可致早产、低体重。

**营养不良与消化道症状**：上腹隐痛、食欲异常（**异食癖：喜食生米、泥土、煤渣**——钩虫病的特征性表现）、腹泻、消瘦。<span class="marginnote">「<strong>异食癖（吃土、吃煤渣）</strong>」是钩虫病最著名的临床标志：重度钩虫感染患儿常表现出对泥土、墙灰、纸张的异常嗜好。<strong>异食癖 + 缺铁性贫血</strong>是钩虫病的双人组合，两者互为因果（缺铁本身也与异食相关）——看到「爱啃墙皮、面色苍白」的儿童，先想到钩虫。</span>

**贫血机制的量级**：美洲钩虫每日每条吸血约 0.03 ml、十二指肠钩虫约 0.2 ml，**虫数多时每日失血可达数毫升甚至更多**——积少成多，遂成贫血。

## 3 公式解析：钩虫性贫血的每日失血量

钩虫致贫血的强度，可用一个简单的**失血估算式**来定量理解：

$$V_\text{day} = n \cdot v \cdot f$$

- $V_\text{day}$：每日失血量（ml/日）。
- $n$：寄生成虫数；$v$：每条虫的**实际吸血量**（十二指肠钩虫约 0.2 ml/条·日，美洲钩虫约 0.03 ml/条·日）；$f$：失血放大系数（抗凝物使伤口持续渗血，实际失血 > 单纯吸血量）。

- 直觉：若体内有 **500 条十二指肠钩虫**，即使按每条 0.2 ml、$f=1$ 估算，每日失血即达 **100 ml**——而人体每天红细胞生成量有限，长期如此必然严重贫血。**虫负荷是贫血的决定变量**，这也解释了为什么「钩虫病的严重程度 = 感染度」——防治的关键之一就是降低虫负荷（驱虫）。

**临床含义**：这条公式让「钩虫病查虫数（EPG）→ 评估贫血风险」有了量化依据，也解释了为何**集体驱虫 + 补铁**是钩虫病治疗的标准组合——**既要杀虫（断失血源头），又要补铁（补回造血原料）**。

## 4 蛲虫：形态与生活史

**蛲虫（*Enterobius vermicularis*）**：体小（雌虫长 8–13 mm），**白色细线状**。特征：**虫体尾部尖细、头端有头翼**；雌虫子宫内充满虫卵。

**生活史（直接型、经口、无肺移行、肛周产卵）**：

1. **感染**：人**经口摄入虫卵**（污染的手、食物、床单）。
2. 虫卵在小肠孵出幼虫 → 下行至**盲肠、结肠**，发育为成虫。
3. **肛周产卵（独特）**：**雌虫于夜间爬出肛门，在肛周皮肤皱襞处产卵**（可产卵数千枚）——引起**肛周瘙痒**，患儿搔抓时虫卵污染手指、床单，经**肛门—手—口**循环再感染。<span class="marginnote">蛲虫的「<strong>夜间肛周产卵</strong>」是整个线虫学里最独特的习性：雌虫不入土壤、不随粪排出，而是<strong>夜爬肛门在肛周产卵</strong>。卵在此处约 6 小时即发育为感染期卵——患儿一搔抓，卵就上了手指，再入口即再感染。<strong>家庭内「一人感染、全家传染」</strong>由此而来，蛲虫病因此是典型的<strong>聚集性、家庭性</strong>寄生虫病。</span>

## 5 蛲虫：致病与临床

**肛周瘙痒（核心症状）**：**夜间肛门及会阴部瘙痒**，是蛲虫病最突出的表现——影响睡眠、烦躁不安、夜惊。

**消化道与全身症状**：食欲减退、腹痛、恶心；长期反复感染可致消瘦。

**异位损害（少见）**：蛲虫误入**女性生殖道**引起**阴道炎、输卵管炎**；入**阑尾**致**蛲虫性阑尾炎**；**泌尿系**引起尿频（女孩）。

**家庭聚集与再感染**：**蛲虫病是「全家病」**——患儿搔抓后卵污染手、床单、玩具，家庭内反复交叉感染；**单一治疗患儿而不处理家庭环境，几乎必然复发**。

**诊断与治疗**：**肛周拭子法（透明胶带法）**——夜间或晨起未排便时，用透明胶带粘贴肛周，镜检找虫卵（**蛲虫卵多在肛周而非粪便中**，粪检常阴性）；治疗**阿苯达唑/甲苯咪唑**，**全家同治 + 两周后复治**。

## 6 核心对比表：钩虫 vs 蛲虫

| 特征 | 钩虫 | 蛲虫 |
| --- | --- | --- |
| 学名 | *A. duodenale* / *N. americanus* | *Enterobius vermicularis* |
| 形态 | 细长、前端钩曲，齿/切板 | 白色细线状，尾尖、有头翼 |
| 寄生部位 | **小肠** | **盲肠、结肠** |
| 感染途径 | **经皮肤钻入**（赤脚） | **经口食卵**（肛门—手—口） |
| 有无肺移行 | 有 | 无 |
| 产卵方式 | 粪便排出（常规粪检） | **夜间肛周产卵**（肛周拭子查） |
| 核心症状 | **缺铁性贫血**、异食癖 | **肛周瘙痒**（夜间） |
| 主要人群 | 田间农民、儿童（赤脚） | **儿童**（家庭聚集） |

**辨析｜易错点：** 三条最易混的线——其一，**感染入口不同**：钩虫「钻皮」、蛲虫「吃卵」——**防钩虫靠穿鞋、防蛲虫靠洗手**；其二，**诊断窗口不同**：钩虫查**粪**、蛲虫查**肛周（透明胶带法）**——蛲虫卵几乎不进粪、粪检常阴性，用错方法就漏诊；其三，**蛲虫是「全家病」**，须全家同治，而钩虫是个体田间感染、无需全家。**「钩虫是鞋的问题，蛲虫是手的问题」**——一条总括。

## 延伸：钩虫贫血与「土壤—健康」的系统观

钩虫病是把「土壤」与「人的健康」直接连起来的病，值得展开一层系统视角：**钩虫的感染强度（EPG）与土壤的卫生状况强相关**——没有厕所、随地排便的社区，土壤里丝状蚴密度高，赤脚接触的感染风险就大。从系统论看，钩虫病不是「个体卫生问题」，而是**「粪便处理系统」的失败**：改厕不仅改善钩虫病，还同时降低蛔虫、鞭虫、痢疾、伤寒等一系列粪口传播病的负担——**一处改厕，多病同治**，这正是「从极限到大模型」里「系统级干预优于逐点修补」的公共卫生版本。

而蛲虫则相反，它基本与土壤无关——**家庭内、手与口之间的循环**。它的防治重心从「环境工程」转向「行为工程」：勤洗手、剪指甲、床单烫洗、全家同治。**同样是土源性线虫，一个靠工程（改厕）、一个靠行为（洗手）**——把「防治手段跟着传播途径走」讲到了最后一步。

## 本节自测

1. **钩虫与蛲虫的感染入口分别是什么？防治措施为何不同？** 提示：钩虫经皮肤钻入（防赤脚、穿鞋）、蛲虫经口食卵（防手口、勤洗手）。

2. **为什么钩虫病要「驱虫 + 补铁」双管齐下？** 提示：驱虫断失血源头、补铁补回造血原料——两者缺一不可。

3. **蛲虫的「透明胶带法」为什么优于粪检？** 提示：蛲虫卵夜间产在肛周、几乎不进粪便——粪检常阴性，须刮肛周拭子查卵。

4. **为什么蛲虫病「一人感染、全家都要治」？** 提示：夜间肛周产卵 → 搔抓 → 手指/床单带卵 → 家庭内交叉再感染——单治一人必然复发。

**再提醒**：「钩虫是鞋的问题（钻皮）、蛲虫是手的问题（吃卵）」——一条总括两条防治主线。

## 7 小结

- 钩虫：**经皮肤钻入 + 肺移行 + 小肠吸血**；核心危害是**缺铁性贫血**（失血公式 $V_\text{day}=n\cdot v\cdot f$）与**异食癖**；诊断靠粪检、治疗阿苯达唑 + 补铁。
- 蛲虫：**经口食卵 + 肛周夜间产卵**；核心症状**肛周瘙痒**；诊断靠**透明胶带法**、治疗阿苯达唑、**全家同治**。
- 两条感染主线对照：**钩虫靠脚（钻皮）、蛲虫靠手（口）**——防治措施随之不同。
- 治疗共性：**阿苯达唑/甲苯咪唑**；蛲虫须家庭同治与复治，钩虫须加补铁。

钩虫与蛲虫把土源性线虫的「钻皮」与「手口」两条路走完。结束肠道线虫，下一节进入**组织线虫**——**丝虫：班氏丝虫与马来丝虫**。
