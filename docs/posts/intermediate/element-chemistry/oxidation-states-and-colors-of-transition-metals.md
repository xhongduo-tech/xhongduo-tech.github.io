## 为什么从氧化态开始

过渡金属最醒目的个性是**一个元素、多张面孔**：铁既能以 Fe²⁺ 的淡绿出现，也能以 Fe³⁺ 的黄色出现，还能在 $\ce{FeO4^2-}$ 中达 +6；锰更是从 +2 到 +7 一路变色。本节把「氧化态的谱系」与「颜色的来源」这两件事讲透：前者决定一个金属在什么条件下以什么身份存在（比什么更能还原、什么更能氧化），后者则用上一节的晶体场理论给出定量解释。<span class="marginnote">氧化态不是空泛的「数数游戏」：它直接对应着化合物的氧化还原能力、颜色、磁性甚至生物毒性。把过渡金属的「氧化态地图」记在心里，就等于握住了它们化学行为的总索引。</span>

## 1 氧化态的谱系

第一过渡系各金属的常见氧化态构成一张从低到高的阶梯：

| 金属 | 常见氧化态 | 稳定环境 |
| --- | --- | --- |
| Sc | +3 | 仅此一种（d⁰） |
| Ti | +3、+4 | +4 最常见（$\ce{TiO2}$） |
| V | +2 ~ +5 | +5 以氧钒基 $\ce{VO2^+}$、$\ce{VO4^3-}$ 存在 |
| Cr | +2、+3、+6 | +6 以铬酸根 $\ce{CrO4^2-}$ |
| Mn | +2 ~ +7 | +7 以高锰酸根 $\ce{MnO4^-}$ |
| Fe | +2、+3 | +3 更稳定（+2 易被氧化） |
| Co | +2、+3 | 配位后 +3 常见 |
| Ni | +2 | 主战场 |
| Cu | +1、+2 | +2 水溶液中为主 |
| Zn | +2 | 仅此一种（d¹⁰） |

规律浮出水面：**最高氧化态总在含氧酸根里出现**（$\ce{CrO4^2-}$、$\ce{MnO4^-}$、$\ce{VO4^3-}$），因为氧的强电负性「压住」了金属的高价；而水溶液中的简单阳离子则偏爱低价。另一条规律：**随着 3d 轨道越填越满，最高氧化态先升后降**——Mn 在中间（+7）达到顶峰，往后 Fe、Co、Ni 的最高价依次回落，Zn 只剩 +2。<span class="marginnote">最高氧化态「中间高、两头低」的曲线，反映的是 d 电子数对成键能力的贡献：d 电子太少（Sc）没有足够轨道参与高价成键，太多（Zn）又填满不再容易失去。这与《结构化学》中电负性、电离能的趋势互为表里。</span>

**辨析｜易错点：** 「最高氧化态」≠「最常见的氧化态」。Mn 的最高价 +7 只在强氧化性的 $\ce{MnO4^-}$ 中出现，水溶液里 Mn 的日常是粉色的 Mn²⁺。考试与实验中遇到「锰的稳定形态」，先问「在什么介质、什么电位下」。

## 2 稳定性与还原电位

判断一个氧化态是否稳定，靠的是**电极电势**：它度量「高氧化态 + 电子 → 低氧化态」的倾向。以锰在酸性介质中的电势序列为例：

$$\ce{MnO4^- \xrightarrow{+1.70\ V} MnO2 \xrightarrow{+1.23\ V} Mn^{2+} \xrightarrow{-1.18\ V} Mn}$$

- +1.70 V 说明高锰酸根**极想被还原**，是强氧化剂（酸性下）；
- −1.18 V 说明 Mn²⁺ 极不情愿被还原成金属 Mn，所以锰金属活泼、离子稳定；
- 电势是**强度**量（每摩尔电子的倾向），不是**容量**量——还原剂能否把 MnO₄⁻ 还原到底，还要看电子数目，这正是下节公式解析的对象。

**核心概念：电极电势（electrode potential）$E^\circ$**：标准状态下，半反应相对标准氢电极的电位，度量氧化还原倾向的强度。$E^\circ$ 越正，氧化态越「急不可耐」地要被还原。

## 3 公式解析：Latimer 图与电位的算术

把某一元素各氧化态按降序排成一行、标上相邻氧化态间的 $E^\circ$，就得到 **Latimer 图（Latimer diagram）**。它的威力在于：**任意两步之间的电势，可以由相邻电势按电子数加权平均**。

设一步转移 $n_1$ 个电子、电势 $E_1$，下一步转移 $n_2$ 个电子、电势 $E_2$，合并电势为：

$$E = \frac{n_1 E_1 + n_2 E_2}{n_1 + n_2}$$

以锰从 $\ce{MnO4^-}$（Mn +7）直接到 Mn²⁺（Mn +2）为例：第一步 +7→+4 转移 3 个电子，第二步 +4→+2 转移 2 个电子：

$$E(\ce{MnO4^-/Mn^{2+}}) = \frac{3 \times 1.70 + 2 \times 1.23}{3 + 2} = \frac{5.10 + 2.46}{5} = 1.51\ \text{V}$$

- $n_1 = 3$：+7 到 +4 需要 3 个电子；
- $n_2 = 2$：+4 到 +2 需要 2 个电子；
- 加权平均的物理意义：总反应的自由能 $\Delta G = -nFE$ 可以分步相加，$5E = 3E_1 + 2E_2$ 正是**自由能守恒**的翻译。

**这一步代数是氧化还原分析的通用工具**：Latimer 图上任何一个「跳级」的电势都能这样算出来，不必查表。同时它还能诊断**歧化**：若右侧电势高于左侧（$E_\text{右} > E_\text{左}$），中间氧化态会自发歧化为两侧——比如 $\ce{Cu^+}$ 在水中歧化为 $\ce{Cu^{2+}}$ 与 $\ce{Cu}$，正是这一判断的经典应用。<span class="marginnote">Cu⁺ 在酸性水溶液中自发歧化（$\ce{2Cu+ <=> Cu^{2+} + Cu}$，K 约 10⁶），所以铜的 +1 价只能靠沉淀或配位稳定。判断「中间价态会不会分身」，Latimer 图一算便知——这是《分析化学》氧化还原滴定与《电化学》的共同语法。</span>

**辨析｜易错点：** 加权平均用的是**电子数 n 作权重**，不是电势的平均值。$E_1$、$E_2$ 的符号与方向必须与图中箭头一致，且电子数等于氧化态差值（+7→+4 是 3 个电子，不是 7−4 之外的其他算法）。把「n·E 相加、总 n 相除」写清楚，就不会错。

## 4 颜色：一杯水的光谱学

过渡金属水溶液的颜色是化学最直观的风景。把第一过渡系的二价水合离子排成一排，颜色依次是：

| 离子 | d 电子数 | 颜色 |
| --- | --- | --- |
| $\ce{Ti^{3+}}$ | d¹ | 紫 |
| $\ce{V^{3+}}$ | d² | 绿 |
| $\ce{Cr^{3+}}$ | d³ | 紫绿 |
| $\ce{Mn^{2+}}$ | d⁵ | 淡粉（极浅） |
| $\ce{Fe^{3+}}$ | d⁵ | 淡黄 |
| $\ce{Fe^{2+}}$ | d⁶ | 淡绿 |
| $\ce{Co^{2+}}$ | d⁷ | 粉 |
| $\ce{Ni^{2+}}$ | d⁸ | 绿 |
| $\ce{Cu^{2+}}$ | d⁹ | 蓝 |
| $\ce{Zn^{2+}}$ | d¹⁰ | 无色 |

颜色在元素间跳跃，而非单调渐变——这正是晶体场理论的预言：颜色由 **d-d 跃迁的能量**决定，而能量取决于 d 电子数与配体场。**d⁰（Sc³⁺、Ti⁴⁺）与 d¹⁰（Zn²⁺、Cu⁺）没有可激发的 d 电子，因此无色**；中间构型各有各的吸收带，于是各有各的颜色。<span class="marginnote">「玻璃为什么有颜色」就是这张表的工业版：钴蓝（Co²⁺）、锰紫（Mn²⁺/Mn³⁺）、铬绿（Cr³⁺）、铜蓝（Cu²⁺）——古代匠人无意中在用晶体场理论调色。《材料科学》与《陶瓷工艺》至今沿用这份「离子颜色手册」。</span>

**辨析｜易错点：** 无色 ≠ 没有 d 电子。d⁰ 与 d¹⁰ 都没有可跃迁的 d 电子，因此都无色——但一个「一个 d 电子都没有」，另一个「d 轨道全满」，两者原因不同。把「d⁰ 无色」与「d¹⁰ 无色」各自说清，才是真懂。

## 5 颜色的起源：d-d 与电荷转移

颜色定量地来自能量守恒：离子吸收可见光中特定波长，把 d 电子从低能级激发到高能级。

$$\Delta E = \Delta_o = h\nu = \frac{hc}{\lambda}$$

以 $\ce{[Ti(H2O)6]^3+}$ 为例：它的 $\Delta_o$ 对应吸收绿光（约 510 nm），透射的互补色就是紫色。代入数值检验：

$$
\lambda = 510\ \text{nm} \quad\Rightarrow\quad E = \frac{6.626\times10^{-34}\times3.00\times10^8}{510\times10^{-9}} \approx 3.9\times10^{-19}\ \text{J} \approx 2.4\ \text{eV}
$$

- $h$：普朗克常数，$c$：光速，$\lambda$：吸收峰波长；
- 2.4 eV 正是八面体场劈裂能 $\Delta_o$ 在可见光范围内的量级；
- 配体场越强（Δo 越大），吸收峰越蓝移，颜色随之变化——这正是光谱化学序列的实验来源。

另一类更鲜艳的颜色来自**电荷转移（charge transfer, CT）**：电子从配体轨道直接跳到金属 d 轨道（配体到金属 LMCT）或反向。$\ce{MnO4^-}$ 的深紫、$\ce{CrO4^2-}$ 的橙黄、普鲁士蓝的深蓝都是 CT 跃迁——强度比 d-d 跃迁大几个数量级，因此「艳丽得刺眼」。<span class="marginnote">d-d 跃迁因 Laporte 与自旋定则而弱（消光系数小），电荷转移不受此限、极强。判别：弱而日常的颜色多为 d-d，浓烈鲜亮的颜色多为 CT。这条规则在《光谱学》的紫外-可见表征里是首要判断步骤。</span>

## 6 小结

- 过渡金属的**氧化态谱系**从 d⁰ 到 d¹⁰ 递增再回落，最高氧化态总在含氧酸根中现身。
- 电极电势 $E^\circ$ 度量氧化还原倾向；**Latimer 图**把相邻电势按电子数加权平均，一步算出任意跳级电势。
- 歧化判断：右侧电势大于左侧，中间氧化态自发分身（如 $\ce{Cu+}$）。
- 颜色由 **d-d 跃迁**决定：d⁰ 与 d¹⁰ 无色，其余各有各的 Δo 与吸收峰。
- $\Delta E = hc/\lambda$ 定量连接颜色与劈裂能；**电荷转移**带来强而鲜艳的颜色。

在下一节，我们将离开 d 区，进入周期表底部的 f 区。镧系与锕系将告诉我们：当 4f 电子躲在原子深处，化学将呈现出怎样「相似得惊人」的面貌。
