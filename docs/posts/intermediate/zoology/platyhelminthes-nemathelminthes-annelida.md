## 为什么把这三个门放在一起

腔肠动物是辐射对称的两胚层动物。从扁形动物开始，动物界迈出了两条决定性的脚步：**两侧对称**与**三胚层**。<span class="marginnote">两侧对称 + 三胚层 + 头化（cephalization）三位一体：身体有了前后左右，运动有明确方向，前端集中感觉器官与神经节，形成「头」。这一身体构型的出现，直接为后续所有的自由生活动物铺平了道路。</span>而扁形、线形、环节三门恰好构成一部「体腔演化史」：从无体腔、到假体腔、再到真体腔，一层层递进。放在一起读，才能看清演化如何逐步「释放」内脏器官的自由。

## 1 扁形动物门：两侧对称的起点

**扁形动物门（Platyhelminthes）**：身体背腹扁平、两侧对称、三胚层、无体腔（**无体腔动物，acoelomate**）的动物。中胚层首次出现，并分化出肌肉层——这使得扁形动物第一次具备了真正的运动能力。

三胚层的意义需要展开：**中胚层（mesoderm）**夹在外胚层与内胚层之间，分化出肌肉、结缔组织、生殖器官等。有了肌肉，动物才能主动蠕动爬行；有了生殖腺，生殖才能摆脱对水环境的完全依赖。扁形动物的消化系统仍是**不完全消化系统**（有口无肛门），但身体已扁平到可以靠体表扩散交换气体与废物——扁平是「无循环系统」的补偿策略。

扁形动物最引人注目的是它的**寄生代表**：

**华枝睾吸虫（肝吸虫）**：寄生在人肝胆管内，生活史需经过淡水螺与鱼两个中间宿主。
**猪带绦虫**：成虫寄生人小肠，节片（proglottid）不断成熟脱落；头节有吸盘与顶突小钩固定宿主。
**涡虫（planarian）**：自由生活，再生能力极强，是研究再生的模式动物。<span class="marginnote">涡虫被切成多段后每段都能再生出完整个体——再生生物学长期用它做实验材料。这一「身体重构」能力在动物界并非普遍，正是扁形动物低分化程度的另一种体现。</span>

**辨析｜易错点：**寄生扁形动物的消化系统往往**退化甚至消失**（如绦虫没有消化系统，直接经体表吸收宿主营养）。因此「消化系统退化」与「生殖系统极端发达」是寄生动物的一体两面——凡是寄生生活，这两条几乎同时出现。

## 2 线形动物门：假体腔与完全消化系统的诞生

**线形动物门（Nemathelminthes）**：身体圆柱形、两侧对称、三胚层，体壁与消化道之间出现**假体腔（pseudocoelom）**，又称原体腔或初生体腔。

假体腔的关键在于它的**来源**：它不是由中胚层完全包裹的腔，而是**胚胎期的囊胚腔（blastocoel）**遗留并扩大而成。体腔与体壁之间没有中胚层形成的体腔膜（peritoneum），内脏器官悬浮在充满体腔液的假体腔中。<span class="marginnote">体腔液是身体的「液压骨架」：线虫靠体壁纵肌与体腔液互相推挤，产生特有的蛇形摆动。假体腔首次让内脏有了「活动空间」，但还没有真体腔那样的循环腔与器官悬挂系统。</span>

线形动物完成了消化系统的关键升级：**口与肛门分离，消化道两端开口**，食物单向通过——这是**完全消化系统（complete digestive system）**的首次出现。食物消化与废渣排出互不干扰，吸收效率大幅提升。

线虫类群庞杂且与我们关系密切：

**蛔虫（Ascaris）**：寄生人小肠，雄虫尾端弯曲、雌虫产卵量极大，虫卵经粪-口途径传播。
**蛲虫、钩虫、丝虫**：分别是儿童肛周瘙痒、贫血与象皮肿的病原。
**自由生活的线虫**：土壤与海洋中数量惊人，一平方米农田土壤可含数百万条。<span class="marginnote">线虫是动物界个体数量最庞大的类群之一。秀丽隐杆线虫（<strong>C. elegans</strong>）更是现代发育生物学与神经科学的模式生物——它只有 959 个细胞、302 个神经元，却拥有完整的神经系统与行为。微观动物，成了理解复杂生命的关键钥匙。</span>

## 3 环节动物门：真体腔与分节现象

**环节动物门（Annelida）**：身体由许多相似的**体节（metamere）**组成，具有**真体腔（coelom）**与**闭管式循环系统**的动物。

环节动物的两项创新意义深远：

**真体腔**：由中胚层内部的腔（体腔囊）发育而成，完全被中胚层（体腔膜）包裹。真体腔提供了更大的活动空间、更好的液压支撑，也参与形成循环系统与排泄器官。**体腔的演化序列——无体腔 → 假体腔 → 真体腔——是动物演化史上最经典的进步阶梯之一。**
**分节现象（metamerism）**：身体沿纵轴分成一系列重复的体节，各节在结构上相似、功能上分工。分节让身体在损伤时损失可控，也让运动更加灵活——这是**环节动物到节肢动物再到脊索动物**都保留的重大构型。<span class="marginnote">分节是「模块化设计」在生物界的完美体现：蚯蚓每一节都有一套神经节与排泄管（肾管），如同工厂里重复的工位。第6篇节肢动物将进一步把分节推向极致——异律分节与附肢特化。</span>

环节动物的代表类群：

**寡毛纲**：蚯蚓，土壤改良的功臣，闭管式循环、体表黏液呼吸。
**多毛纲**：沙蚕，海产，具疣足（parapodium）与成对刚毛，运动敏捷。
**蛭纲**：水蛭，体节数固定，前后端有吸盘，营暂时性体外寄生。

**核心要点：三门体腔与系统对照表**

| 维度 | 扁形动物 | 线形动物 | 环节动物 |
| --- | --- | --- | --- |
| 体腔 | 无体腔 | 假体腔 | 真体腔 |
| 消化系统 | 不完全（口无肛门） | 完全（口 + 肛门） | 完全 |
| 循环系统 | 无 | 无 | 闭管式 |
| 分节 | 无 | 无 | 分节 |
| 运动 | 纤毛 + 皮肌囊蠕动 | 纵肌 + 体腔液液压 | 肌层 + 刚毛/疣足 |

## 4 寄生生活：适应的代价与交换

扁形动物与线形动物中的大量寄生种类，把「寄生」这一生活策略演化到了极致。理解寄生，就是理解一套**「以退为进」**的适应逻辑。

### 寄生带来的系统性改造

寄生动物（寄生虫）与自由生活近亲相比，身体发生一系列规律性的变化：

| 系统 | 自由生活者 | 寄生虫 |
| --- | --- | --- |
| 消化系统 | 完整 | 常退化甚至消失（经体表吸收） |
| 生殖系统 | 常规 | 极度发达，产卵量惊人 |
| 附着器官 | 无或简单 | 吸盘、钩、小钩（固着宿主） |
| 神经系统 | 相对简单 | 相对退化 |
| 运动系统 | 发达 | 常退化（不必主动觅食） |

<span class="marginnote">这套「寄生改造清单」几乎在所有寄生虫类群中重复出现：消化退、生殖盛、吸附强。它说明自然选择在「依赖宿主」这条路上高度收敛——不同谱系独立演化出相似的寄生形态，是趋同演化（第14篇）的又一例证。</span>

### 生活史中的宿主转换

许多寄生虫的生活史跨越多个宿主：

**终宿主（definitive host）**：寄生虫成虫或有性生殖所寄生的宿主。
**中间宿主（intermediate host）**：幼虫或无性生殖阶段寄生的宿主。

华枝睾吸虫的生活史是典型链条：虫卵随粪便入水 → 被淡水螺吞食、发育 → 释放尾蚴 → 侵入鱼体成囊蚴 → 人食未煮熟的鱼被感染 → 成虫寄生于肝胆管。<span class="marginnote">宿主转换的意义在于「放大传播」：一个虫卵经过螺体内的无性增殖，可释放出成千上万尾蚴——寄生生活靠「以量取胜」弥补个体存活率低。</span>

### 寄生虫病与防治

寄生虫病在卫生条件较差的地区仍是重大公共健康问题：

**血吸虫病**：日本血吸虫经皮肤钻入人体，虫卵在肠壁沉积引发肉芽肿与肝脾肿大。钉螺是中间宿主，「灭螺 + 粪便管理 + 安全用水」是防控核心。<span class="marginnote">血吸虫病的防治史与中国公共卫生史深度交织——新中国早期的血吸虫病防治运动，就是「灭螺 + 查治 + 改水改厕」的综合实践。寄生虫病是「社会-生态」交织的疾病，光靠药物治不好。</span>
- **蛔虫病**：蛔虫卵经粪-口传播，儿童感染率高，影响营养吸收。饭前便后洗手、无害化处理粪便即可有效预防。

**辨析｜易错点：**「有寄生虫 = 一定致病」不准确——许多寄生虫与宿主长期「和平共处」（无症状携带），只有当虫荷大、营养差或免疫低下时才显病症。寄生虫-宿主关系是一把连续谱：从互利到偏害，中间存在大片灰色地带。

**补充阅读提示**：这三门的「体腔演化阶梯」与「寄生适应」是动物学入门最经典的比较解剖学素材——它们把「结构—功能—环境」的三角关系讲得最透彻。理解了这个三角，后面每一门都能用同一套方法去读。

无论是自由蠕动的蚯蚓，还是深藏宿主的绦虫，身体的每一处构造都在回答同一个问题：这套结构，是为哪种生活方式服务的？

## 5 小结

- **扁形动物**是两侧对称 + 三胚层的起点，**无体腔**、不完全消化；寄生种类消化系统退化、生殖系统发达。
- **线形动物**首次拥有**假体腔**与**完全消化系统**（口肛分离），靠体腔液液压运动。
- **环节动物**拥有**真体腔**、**闭管式循环**与**分节现象**，代表演化上的重大跃升。
- 三门连起来正是**无体腔 → 假体腔 → 真体腔**的经典进步阶梯。

在下一节，我们将看到两侧对称与真体腔的进一步胜利——**软体动物门**，一个把贝壳、外套膜与专职呼吸器官打磨到极致的庞大门类。
