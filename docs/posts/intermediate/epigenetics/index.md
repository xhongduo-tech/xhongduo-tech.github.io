# 表观遗传学

表观遗传学研究在不改变 DNA 序列的前提下、通过可遗传的染色质修饰来调控基因表达的学科，是遗传学的现代核心分支。从 DNA 甲基化、组蛋白修饰到染色质结构，贯通其写入、读取与擦除机制，即可理解从干细胞分化、基因组印迹到肿瘤发生与衰老的完整调控链条。

## 对标教材

- C.D. Allis, T. Jenuwein & D. Reinberg, "Epigenetics" (2nd ed., Cold Spring Harbor Laboratory Press, 2015)
- 薛京伦主编，《表观遗传学》（高等教育出版社）
