# X 染色体失活与剂量补偿

<div class="epigraph">

## 为什么从 X 失活开始

哺乳动物雌性（XX）有两条 X 染色体、雄性（XY）只有一条。
如果两条 X 都表达，雌性的 X 连锁基因剂量就是雄性的两倍——这会带来严重的剂量失衡。
进化给出的解决方案是**剂量补偿**：雌性把其中一条 X 染色体几乎完全沉默。
这个现象被称为 **X 染色体失活（X chromosome inactivation, XCI）**，其失活的 X 在显微镜下可见为深染的**巴氏小体（Barr body）**。

X 失活是表观遗传学的「皇冠明珠」：一整条染色体（约 150 Mb、上千个基因）被永久沉默，却几乎不改变 DNA 序列；
它靠 `Xist` lncRNA 顺式覆盖、
`H3K27me3` 与 DNA 甲基化多重叠印锁死，
还能在每次细胞分裂中忠实维持。
<span class="marginnote">为什么雌性没有「双倍 X 中毒」而死？
答案是剂量补偿无处不在——果蝇靠雄性 X 转录翻倍，线虫靠两条 X 各减半，哺乳动物靠雌性关掉一条 X。
三种机制不同，目的相同：让 XX 与 XY 的 X 剂量持平。
</span>

## 1 计数与选择：为什么只失活一条、失活哪一条

失活必须满足两个「精确性」要求：**只失活一条**（不能都失活或都不失活），且**随机**（父源/母源等概率）。

**计数机制**：
在早期雌性胚胎的每个细胞里，
存在一个「X 染色体数 : 常染色体组数 = 2 : 2」的信号，
触发失活「一条」X。
关键分子是 **`Xist`** 与其反义调控因子 **`Tsix`**。
`Xist` 只在「即将失活」的那条 X 上上调表达；
`Tsix`（Xist 的反义转录）保护另一条不被失活。
<span class="marginnote">`Tsix` 是一条「保护性反义 RNA」：
在保持活跃的 X（Xa）上持续转录，
抑制 `Xist` 的累积；
而失活的 X（Xi）上 `Tsix` 关闭，`Xist` 得以爆发式表达。
一方压过另一方，决定这条 X 的宿命。
</span>

**随机性**：在胚胎极早期（约囊胚期），每个细胞**独立随机**决定失活父源还是母源 X。
细胞分裂后，这个决定被**克隆性继承**——后代细胞保持同样的失活选择。
结果：成年雌性个体是**X 嵌合体**，身体由「父源 X 失活」与「母源 X 失活」两类细胞拼成。
<span class="marginnote">这个嵌合体正是「三色猫」的原因：
橙色与黑色毛色基因都在 X 上（不同等位基因），
细胞随机失活一条 X，
于是毛色呈斑块分布。
三色猫几乎都是雌性——因为只有雌性才有两条 X 可失活。
</span>

**辨析｜易错点：** X 失活不是「每个细胞都失活同一条」。
它是**随机的、克隆性维持的**——不同细胞系失活不同亲本来源的 X。
所以「父源 X 失活」与「母源 X 失活」在同一个体内共存。

## 2 Xist 的顺式作用：从启动到覆盖

失活的执行者是 **`Xist`**（X-inactive specific transcript），
一条约 17 kb 的 lncRNA：

**启动**：
失活信号的细胞里，
`Tsix` 关闭 → `Xist` 在将要失活的 X 上被激活转录 → `Xist` RNA 从转录位点开始，
**顺式覆盖整条 X 染色体**。
**覆盖与改造**：
`Xist` RNA 沿 X 铺开后，
招募一系列复合物：
`PRC2`（写 `H3K27me3`）、
`PRC1`（泛素化 H2AK119）、
`SMRT/HDAC3`（去乙酰化）、
`SMCHD1` 与 `H3K9me3` 通路。
染色质被逐级压实成异染色质。
**RNA 的定位机制**：`Xist` 如何在 150 Mb 上「铺开」而不掉下来？
它通过 `SPEN` 蛋白（识别 Xist 的 A 重复区）结合核基质/染色质，
以及一系列含 RNA 结合结构域的蛋白（`HNRNPK` 等）锚定在染色质上，
像「雨布」一样盖住整条染色体。
<span class="marginnote">`SPEN` 是近年 Xist 机制研究的核心：
敲除 `SPEN`，
Xist 仍能转录但无法沉默基因——`SPEN` 把 Xist 的覆盖与「下游沉默执行（招募 HDAC、
PRC2）」连起来。
一个 lncRNA，靠一个蛋白"中介"，撬动整条染色体的关闭。
</span>

## 3 失活的建立与维持：三个阶段的「多重叠印」

X 失活不是一步到位，而是分阶段、多层次的「锁定」：

**启动/建立期（囊胚期）**：`Xist` 表达、`H3K27me3`/`H2AK119ub` 快速铺满，染色质开始关闭。
此时失活尚不完全稳定。
**巩固期**：`H3K9me3`、`macroH2A` 沉积，DNA 甲基化开始在 X 连锁基因启动子上建立（迟到但持久）。
**维持期（体细胞）**：一旦稳定，失活状态**不再依赖持续的 `Xist` 表达**——在体细胞里敲除 `Xist` 基因，失活的 X **不会**重新激活。
<span class="marginnote">这是一个重要发现：
`Xist` 负责「建立」，
但「维持」靠后来建立的稳定修饰（DNA 甲基化、
macroH2A、
异染色质）——即使始作俑者消失，
锁已换成了更硬的锁。
这完美体现了表观遗传「建立-维持」的两阶段设计。
</span>

**重点：** 失活 X 上并非所有基因都被沉默。
**逃逸基因（escape genes）**约占 X 基因的 15%（人类）——它们能部分表达，避免两性剂量完全相等；
逃逸基因的分布与 X 上的「失活中心」距离及染色质状态相关。
所以剂量补偿是「基本持平，允许局部差异」。

## 4 公式解析：剂量平衡的「比率」

剂量补偿的定量目标可以写成：让 XX 与 XY 个体的 X 连锁基因产物量相等。
设 $X_{\text{活性}}$ 为一条 X 的活性表达量，则：

$$
\text{雌性（XX）}:\; 2 X_{\text{活性}} \xrightarrow{\text{XCI 关掉一条}} 1 X_{\text{活性}} \;\approx\; \text{雄性（XY）}:\; 1 X_{\text{活性}}
$$

三步拆解：

- **第一步，看失衡**：若无剂量补偿，XX 表达 $2X$、XY 表达 $1X$，X 连锁基因产物相差一倍。对某些剂量敏感的蛋白（如复合物组分），1.5 倍偏差就足以致病。
- **第二步，看补偿手段**：哺乳动物把 $2X \to 1X$（失活一条）；果蝇把雄性的 $1X$ 转录翻倍成 $2X$
