## 为什么从疾病、衰老与环境开始

前一篇讲了肿瘤。
但表观机制远不止癌症——它参与**免疫病、代谢病、神经病、精神障碍**，也贯穿**衰老**全过程。
更重要的是，表观遗传提出了一个诱人的可能：**环境（饮食、毒素、压力）可以"刻进"表观基因组，进而影响健康**。
这让表观遗传从「基础机制」上升到「环境-健康」的桥梁学科。

但正因如此，这一领域也最容易产生**夸大与误导**（"你的饮食能改变你孙辈的基因"这类说法）。
本节的目标是把事实与流言分开：哪些环境-表观联系有坚实证据，哪些仍在争议中。
<span class="marginnote">本节与前面的关系：
表观机制（甲基化、
组蛋白、
染色质）都已在前 16 篇讲完，
这里讨论它们如何<strong>在疾病、
年龄、
环境</strong>三个场景中集体出场。
它也是本专题从「机制」转向「应用与批判」的收束。
</span>

## 1 单基因表观病：当「读写擦」本身出错

有一类疾病由**表观机制直接突变**引起，机制最清楚，称为**表观遗传病**：

**读/写/擦组件的遗传突变**：
**Rett 综合征**：`MECP2`（读 `5mC`）突变，神经发育障碍（第8篇）。
**Rubinstein-Taybi 综合征**：`CBP`/`EP300`（写乙酰化）突变，智力障碍 + 面容异常 + 拇指宽大。
- **Kabuki 综合征**：`KMT2D`（写 `H3K4me`）或 `KDM6A`（擦 `H3K27me3`）突变，多器官发育异常。
- **Weaver 综合征**：`EZH2`（写 `H3K27me3`）突变，过度生长。
- **Sotos 综合征**：`NSD1`（写 `H3K36me2`）突变，过度生长 + 大头。

**印记疾病（第17篇）**：
`ICR` 甲基化异常导致 Beckwith-Wiedemann、
Silver-Russell、
Prader-Willi/Angelman 等综合征。

**重点：** 这类疾病证明**表观机制本身是发育的必需硬件**——不是「锦上添花的调控」，而是「写错的硬件直接致病」。
它们也是理解「表观组件的剂量敏感」的最佳窗口。
<span class="marginnote">一个共性：
许多表观病的基因是<strong>单倍剂量不足</strong>（haploinsufficiency）——一个拷贝丢失就致病。
这提示这些酶的活性是「限量」的，半量不足以维持正常发育。
</span>

## 2 复杂疾病中的表观异常：是「因」还是「果」

对于糖尿病、自身免疫病、精神分裂等复杂疾病，患者中常能检测到**表观差异**（如特定基因的甲基化改变）。
但这些差异需要谨慎解读：

**区分「驱动」与「伴随」**：
**伴随（epiphenomenon）**：疾病本身改变细胞状态，连带改变甲基化（例如炎症导致免疫细胞比例变化，甲基化谱随之改变）。多数「疾病相关甲基化」属于此类。
**驱动（causal）**：少数情况下，表观改变直接参与发病（如 `MLH1` 甲基化导致 Lynch 样结直肠癌、`FMR1` 甲基化导致脆性 X 综合征）。

**方法学挑战**：
组织异质性（血液甲基化 ≠ 病变组织甲基化）、
因果方向不明（先有病还是先有甲基化改变）、
混杂因素——这是「表观关联研究」的三大陷阱。
<span class="marginnote">破解「因/果」的一个工具是孟德尔随机化（Mendelian randomization）：
利用遗传变异作为工具变量推断「甲基化 → 疾病」的因果方向。
把 GWAS 与 EWAS（表观组关联研究）结合，才能从相关走向因果。
</span>

**辨析｜易错点：** 「疾病里有表观差异」 ≠ 「表观差异导致疾病」。
新闻报道常把二者混为一谈。
严格检验需要：表观改变先于疾病发生、干预表观能改变病程、机制上可解释。
**大多数"疾病表观"还没通过这三级检验**——这是面对这类研究时应有的审慎。

## 3 衰老：表观时钟与表观漂移

衰老是表观研究最活跃的领域之一。
两个核心概念：

**表观漂移（epigenetic drift）**：随年龄增长，全基因组 DNA 甲基化逐渐改变——整体**低甲基化**（重复序列、基因体）+ 局部**高甲基化**（某些启动子）。
漂移的速率与方向因人而异，与遗传、环境、生活方式都相关。
<span class="marginnote">为什么重复序列低甲基化随龄？
一种解释是维持机制（DNMT1/UHRF1）在长期复制中逐渐"漏补"累积；
而局部高甲基化可能与衰老中转录因子结合变化、Polycomb 靶基因的"锁"相关。
</span>

**表观时钟（epigenetic clock）**：特定 CpG 位点的甲基化水平随年龄高度规律地变化，可用来**精确预测生物学年龄**。
著名的有 Horvath 时钟（跨组织通用）、
Hannum 时钟（血液）、
PhenoAge/GrimAge（预测死亡率与健康）。

**表观时钟的意义**：
预测「生物学年龄」与**实际年龄**的差距——差距大（表观年龄比实际老）与死亡率、慢性病风险相关。
可作为**干预评价的读数**：健康生活方式、运动、部分药物被认为能「减慢表观时钟」。
- **辨析｜易错点：** 表观时钟是**统计预测器**，不是「衰老原因」的清单。它预测年龄靠的是甲基化位点组合，这些位点本身不一定驱动衰老。**"表观年龄"是衰老的读数计，不是调节旋钮**。

**H3K9me3/H4K16ac 与细胞衰老**：
衰老细胞（senescent cells）中异染色质丢失（`H3K9me3` 下降）、
`H4K16ac` 改变，
与「衰老相关异染色质灶（SAHF）」等表型相关。
表观失稳本身可能促进衰老（基因组不稳定 → 衰老）。

## 4 环境暴露与表观：从荷兰饥荒到营养遗传

环境如何影响表观基因组？
最经典的研究是**荷兰饥荒（Dutch Hunger Winter, 1944-45）**：胎儿期经历饥荒的人，几十年后检测到 `IGF2` 等基因的**DNA 甲基化差异**，且与代谢疾病风险相关。
<span class="marginnote">这项研究第一次为「早期环境 → 持久表观变化 → 远期健康」提供了人类证据。
注意：效应量中等、研究规模有限、且「饥荒」包含多重暴露（营养、压力）——它建立了一个假说，而非定论。
</span>

**已知较坚实的环境-表观联系**：
**吸烟**：与全基因组大量 CpG 甲基化改变相关（`AHRR` 等位点），部分改变在戒烟后仍持续多年——是「环境留下分子痕迹」最可重复的证据。
**饮食与营养**：叶酸/甲基供体（SAM 通路）影响甲基化；某些饮食干预在动物中改变印记基因甲基化。
- **宫内环境**：母体糖尿病、肥胖与子代表观改变相关（关联而非确证因果）。
- **毒物**：砷暴露与 DNA 甲基化改变相关（砷干扰 SAM 代谢与 TET 活性）。

**跨代遗传（transgenerational inheritance）争议**：动物实验中，某些环境暴露（毒物、饮食）的表观效应可传 2–4 代。
但**人类与哺乳动物的两轮重编程**（第19篇）是强有力的"清除机制"，因此**大多数"跨代表观遗传"证据仍存争议**。
真正得到较一致支持的少数案例（如某些小鼠 `agouti`/`axin` 位点的甲基化变体）依赖"逃过重编程"的特殊序列（IAP 等）。
<span class="marginnote">这是本节最重要的"辨析"：
新闻报道常渲染"创伤可以遗传给孙辈"，
但科学共识是——<strong>跨代表观遗传在哺乳动物中证据薄弱且机制不明</strong>；
重编程就是进化设计来防止这种"环境记忆过度传递"的。
把"表观遗传"当作"拉马克式遗传"来传播，是常见的误读。
</span>

## 5 公式解析：表观时钟与生物学年龄

表观时钟的原理可以抽象成一个预测模型。
设第 $i$ 个 CpG 位点的甲基化水平为 $m_i$，生物学年龄（表观年龄）$\hat{A}$ 是它们的一个加权组合：

$$
\hat{A} = \beta_0 + \sum_{i=1}^{n} \beta_i \, m_i
$$

三步拆解：

- **第一步，看变量**：$m_i$ 是数百个 CpG 位点的甲基化值（0–1）；$\beta_i$
