## 为什么从椭圆曲线开始

前两篇我们在模 $p$ 乘法群上搭了 Diffie-Hellman 与 ElGamal。
这一篇把「群模板」换成椭圆曲线群——它把公钥密码的密钥尺寸从 3072 位压到 256 位，现代 HTTPS、比特币、TLS 1.3 都在用。
为什么能省这么多？
因为**离散对数困难的程度不一样**：素数域上的 DLP 有亚指数攻击（索引演算），而椭圆曲线群上的 ECDLP 目前只有指数级攻击（Pollard ρ），同等安全强度下需要的位长就少一个量级。
<span class="marginnote">椭圆曲线密码学（ECC）的独立提出者是 Victor Miller（1985）与 Neal Koblitz（1987）。
它的诞生比 RSA 晚十年，却彻底改变了「安全强度 = 密钥长度」的账本：2048 位 RSA ≈ 224 位椭圆曲线 ≈ 128 位安全强度。
</span>

## 1 几何对象：椭圆曲线方程

**核心概念：** 椭圆曲线（elliptic curve）是满足形如

$$
y^2 = x^3 + ax + b, \qquad 4a^3 + 27b^2 \neq 0
$$

的所有点 $(x,y)$ 的集合，外加一个特殊的「无穷远点」$\mathcal{O}$。
条件 $4a^3 + 27b^2 \neq 0$ 保证曲线**没有尖点或自交点**（即非奇异），这保证了切线与加法的良定义。
这里的系数 $a,b$ 在密码学里取自有限域 $\mathbb{F}_p$（大素数 $p$），我们记作 $E(\mathbb{F}_p)$。

**辨析｜易错点：** 椭圆曲线不是「椭圆」，两者只共享积分学的一段历史——椭圆的弧长积分无法用初等函数表示，而计算它的椭圆积分把问题引向这类三次曲线的反函数，故得名。更重要的是：**在有限域上，曲线不再是光滑的几何图像，而是一张密密麻麻的离散点集**，但这不影响「加法定则」——它只依赖代数公式，不依赖图像。

## 2 群结构：点加法与切线

曲线上的点配上**点加法**构成一个阿贝尔群，单位元是无穷远点 $\mathcal{O}$。
加法定则用一句话概括：**过 $P$、$Q$ 两点作直线，它与曲线相交于第三个点 $-R$；把这个点关于 $x$ 轴反射，得到 $R = P+Q$。** 如图：$P+Q = R$。

- **$P = Q$（点倍乘）**：退化为过该点的**切线**，切线与曲线交于第三点 $-R$，反射得 $2P = R$。
- **$P = -Q$**：连线是竖直线，它与曲线「交于」无穷远点，于是 $P + (-P) = \mathcal{O}$——这保证每个元素都有逆元。
- **$P = \mathcal{O}$**：$\mathcal{O}$ 是单位元，$P + \mathcal{O} = P$。

整个群的运算规则就是**弦与切法（chord-and-tangent law）**。
无穷远点 $\mathcal{O}$ 是这个结构的粘合剂：没有它，加法就没有单位元，也就不是群。
**为什么要抽象成群？** 因为 DH 协议需要的全部性质就是「有单位元、有逆元、结合律」——只要这三条成立，上一篇文章的密钥交换协议就能原封不动地搬过来。

**群运算的代数公式**（在 $\mathbb{F}_p$ 上，除法即乘以模逆元）：对 $P=(x_1,y_1)$、$Q=(x_2,y_2)$，$P \neq \pm Q$ 时
$$
\lambda = \frac{y_2 - y_1}{x_2 - x_1}, \qquad x_3 = \lambda^2 - x_1 - x_2, \qquad y_3 = \lambda(x_1 - x_3) - y_1
$$
点倍乘时（$P=Q$）斜率换成 $\lambda = (3x_1^2 + a)/(2y_1)$。
<span class="marginnote">「群是密码学的最小可行抽象」这句话在这里得到完美示范：实数曲线、有限域点集、乃至后面 NTRU 里的格，都只是满足同一组公理的实例。
你在第二级《抽象代数》里学的群论，第一次有了真实工业价值。
</span>

## 3 公式解析：点倍乘公式里发生了什么

以 $P=(x_1,y_1)$ 求 $2P$ 为例，拆四步：

$$
\lambda = \frac{3x_1^2 + a}{2y_1}, \qquad x_3 = \lambda^2 - 2x_1, \qquad y_3 = \lambda(x_1 - x_3) - y_1
$$

- **第一步，斜率**：$\lambda = \frac{3x_1^2+a}{2y_1}$ 是曲线 $y^2 = x^3+ax+b$ 在 $P$ 处的导数（隐式求导：$2y\,dy = (3x^2+a)\,dx$）。
  几何上它就是切线的斜率；
  代数上它是有限域里的一个数。
- **第二步，交点横坐标**：把切线 $y = \lambda(x-x_1)+y_1$ 代入曲线，得到一个关于 $x$ 的三次方程。
  它有三个根：$x_1$（二重，切点）和第三个交点 $x_3$。
  由韦达定理（根之和等于 $x^2$ 项系数），解出 $x_3 = \lambda^2 - 2x_1$。
- **第三步，交点纵坐标取负**：第三个交点其实是 $-2P$，把它关于 $x$ 轴对称，纵坐标取相反数，得 $y_3 = \lambda(x_1-x_3)-y_1$。
- **第四步，直觉**：点倍乘不是「把一个点坐上去」，而是**沿着切线滚动**：切线、滚动、翻转。
  每倍乘一次，点的坐标都在有限域里剧烈「搅拌」——这正是「给定 $k$ 容易算 $kP$，给定 $kP$ 难找 $k$」的几何直觉来源。

## 4 椭圆曲线离散对数与 ECDH

**核心概念：** 给定椭圆曲线群 $E(\mathbb{F}_p)$ 上的点 $P$ 与 $Q$，如果存在整数 $k$ 使 $Q = kP$（即 $P$ 连加 $k$ 次），求 $k$ 就是**椭圆曲线离散对数问题（ECDLP）**。这里的 $kP$ 是标量乘法，由 $O(\log k)$ 次点加与点倍乘构成（复用平方-乘的模板，只是「平方」换成「倍乘」）。

**ECDH 密钥交换**就是把 DH 模板套上：公开椭圆曲线 $E$、基点 $P$ 与阶 $n$；Alice 随机选 $a$ 发 $aP$，Bob 随机选 $b$ 发 $bP$，共享密钥 $abP$。完全复用前文的分析：Eve 只看到 $aP$、$bP$，求 $abP$ 需要解 ECDLP。

为什么这比素数域 DH 安全？
关键在于**没有索引演算**。
素数域 DLP 之所以有亚指数攻击，是因为 $(\mathbb{Z}/p\mathbb{Z})^\times$ 有「光滑元素」这类可分解结构；
而椭圆曲线群是**通用群**，已知最好的 ECDLP 算法是 Pollard ρ 与 BSGS，都是约 $\sqrt{n}$ 步的指数级。
**群的「结构少」反而意味着「破解慢」**——这是密码学里一个反直觉而深刻的教训。
<span class="marginnote">Hasse 界告诉我们 $\#E(\mathbb{F}_p) \approx p+1$（误差 $\le 2\sqrt p$），所以取 256 位素数 $p$ 时群阶约 256 位，Pollard ρ 需要约 $2^{128}$ 步——正好 128 位安全强度。
素数域 DH 要同等强度则需 3072 位 $p$。
</span>

## 5 参数选择：Hasse 界、MOV 攻击与曲线家族

- **Hasse 界**：$\bigl|\#E(\mathbb{F}_p) - (p+1)\bigr| \le 2\sqrt{p}$。
  群阶落在以 $p+1$ 为中心的窄区间内，这保证「选的曲线点不会太多或太少」。
- **防 Pohlig–Hellman**：群的阶 $n$ 必须有大素因子（最好 $n$ 本身就是素数）。
  用**点计数算法**（Schoof 算法，多项式时间）算出 $\#E$ 后检查即可。
- **MOV 攻击与异常曲线**：若曲线有「小嵌入度」，可用双线性配对把 ECDLP 归约到小域上的普通 DLP（可能变弱）；
  若 $\#E = p$（异常曲线），也有特殊攻击。
  对策是参数生成时排除这两类——这正是后文《配对与基于身份的密码》里「配对」的双刃剑属性的伏笔。
- **经典曲线 vs 现代曲线**：NIST P-256 用 Weierstrass 形式；
  但 Daniel Bernstein 的 **Curve25519**（Montgomery 形式）与 **Ed25519**（Edwards 形式）采用**常数时间**公式，杜绝了时序侧信道，已是 TLS 1.3 与主流库（OpenSSH、Signal）的默认选择。
  实际协议里 ECC 通常配合 ECDSA 签名使用——那是下一篇文章的主题。

## 6 小结

- **椭圆曲线** = 满足 $y^2 = x^3+ax+b$（非奇异）的点集 + 无穷远点 $\mathcal{O}$；
  配**弦与切法**构成阿贝尔群。
- **点加法**：过 $P,Q$ 的直线交曲线于 $-R$，反射得 $R$；
  点倍乘用切线；
  $\mathcal{O}$ 是单位元。
- **代数公式**：$\lambda = (y_2-y_1)/(x_2-x_1)$ 或 $(3x_1^2+a)/(2y_1)$，$x_3=\lambda^2-x_1-x_2$，$y_3=\lambda(x_1-x_3)-y_1$。
- **ECDLP**：已知 $P,kP$ 求 $k$，只有 $\sqrt{n}$ 级攻击；
  256 位曲线 ≈ 128 位安全，3072 位 RSA 才同等强度。
- **参数纪律**：Hasse 界保证群阶合理；
  群阶须有大素因子；
  排除小嵌入度曲线（MOV 攻击）；
  现代实现用 Curve25519/Ed25519 这类常数时间曲线。

在下一篇，我们把椭圆曲线落到一个具体的签名协议上：**ECDSA**。
它会示范一个反复出现的命题——「用私钥做标量乘法，用公钥验证一个方程」，以及签名里那个必须先随机的 $k$ 为什么一不小心就会泄露私钥。
