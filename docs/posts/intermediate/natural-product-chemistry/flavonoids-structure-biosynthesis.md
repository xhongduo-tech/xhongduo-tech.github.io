## 为什么从黄酮开始

苯丙素家族走到这里，迎来了结构最丰富、分布最广、也是与植物颜色关系最密切的一类——**黄酮类化合物（flavonoids）**。茶叶的苦涩、红酒的单宁感、花与果实的红紫蓝三色、大豆的异黄酮……背后都是黄酮类。它的骨架 C6-C3-C6 由「一个苯丙素单体 + 三个乙酸单元」拼合而成，是第1篇三大途径首次大规模「联合作战」的产物。这一节我们既讲结构分类（黄酮、黄酮醇、黄烷酮、花青素……），也讲生源装配（查尔酮合酶如何把三分子前体缩合成骨架），为后续鞣质、以及第5篇生物碱里出现的黄酮杂合体打底。<span class="marginnote">黄酮类的「黄」字来自 flavone（取自拉丁语 flavus = 黄色），但家族成员的颜色从无色到红蓝紫都有。颜色差异几乎全部来自同一件事：<strong>B 环的羟基化程度与 pH 环境</strong>。一个羟基之差，花色就从粉变蓝——这也是园艺与分子生物学交汇的浪漫课题。</span>

## 1 黄酮类的结构基础

**黄酮类化合物（flavonoids）**：以 2-苯基色原酮（C6-C3-C6）为母核、由两个芳香环（A 环与 B 环）经一个三碳桥（C 环）相连的酚类化合物。

![黄酮类化合物的 C6-C3-C6 骨架](/images/natural-product-chemistry/flavonoids-skeleton.svg)

看图可知黄酮母核的三段来源：**A 环来自三个乙酸单元（聚酮式缩合），B 环连同 C 环的三个碳来自苯丙素单体**。C 环的氧化程度把家族分成不同成员：

| 类型 | C 环特征 | 例子 |
| --- | --- | --- |
| 黄酮（flavone） | 2,3-双键 + 4-羰基 | 芹菜素、木犀草素 |
| 黄酮醇（flavonol） | 黄酮 + 3-羟基 | 槲皮素、山柰酚 |
| 黄烷酮（flavanone） | 2,3-饱和 + 4-羰基 | 柚皮素 |
| 黄烷醇（flavanol） | 无羰基，2,3-饱和 | 儿茶素（茶多酚） |
| 花青素（anthocyanidin） | 吡喃阳离子（花色苷苷元） | 天竺葵素、飞燕草素 |
| 异黄酮（isoflavone） | B 环连到 C-3 | 大豆素、染料木素 |

**重点**：C 环的氧化态 + B 环连接位置，决定了黄酮的「身份」与颜色。花青素呈色的吡喃阳离子（flavylium）让它在酸性下显红、中性偏紫、碱性变蓝，这就是花色随 pH 变化的化学根源。<span class="marginnote">花青素是「颜色即结构」的最佳示范：它的阳离子共轭体系吸收可见光，而羟基取代与 pH 进一步调色。同一种飞燕草素在不同植物里因细胞液 pH 不同而显出红、紫、蓝——化学结构 + 微环境，共同决定你眼中花的颜色。</span>

## 2 生源：查尔酮合酶的三合一装配

黄酮生源的核心酶是**查尔酮合酶（chalcone synthase, CHS）**——它是 III 型 PKS 的代表，直接把三分子前体缩合成查尔酮骨架：

$$
\ce{4-香豆酰CoA + 3 \times 丙二酰CoA ->[\text{CHS}] 查尔酮 + 3 CO2}
$$

对这条式子做三步拆解：

- **第一步，看原料**：起始单元是 **4-香豆酰CoA**（苯丙素：香豆酸活化成硫酯），延伸单元是三个丙二酰CoA（乙酸-丙二酸途径）。**莽草酸与乙酸两大途径在此第一次正面合作**。
