## 为什么从莽草酸途径开始

第2篇我们把乙酸-丙二酸途径讲完，它负责制造脂肪酸、聚酮这类「氧官能团丰富」的分子。现在进入第二条主线——**莽草酸途径（shikimate pathway）**。它的重要性在于一个惊人的事实：**植物和微生物能自己合成芳香环，而动物不能**。芳香环的六碳骨架在生物界有两条来源——聚酮的醛醇环化，以及莽草酸途径的独特七步装配。莽草酸途径是苯丙氨酸、酪氨酸、色氨酸三大芳香族氨基酸的源头，而这三者又通向苯丙素、木脂素、香豆素、黄酮、生物碱等海量天然产物。从这一节起，我们将用整整一篇的篇幅把这条「芳香工厂」的入口摸清。<span class="marginnote">「动物不能合成芳香氨基酸」这一条，解释了许多日常现象：人的必需氨基酸里包含苯丙氨酸与色氨酸，必须靠吃；而植物靠莽草酸途径自给自足。进化把这条途径留在了植物与微生物，却也让它成为除草剂与抗菌药的热门靶点。</span>

## 1 莽草酸途径概览

把莽草酸途径放进第1篇的框架里看：它是一条「初级代谢」途径（生产芳香氨基酸供蛋白质合成），却又几乎整条被「次级代谢」借用。这种「一身二任」的性质，让它成为代谢化学里最值得精读的枢纽之一。它的名字来自中间体莽草酸（shikimic acid），而这个七碳环醇酸本身也极有商业价值——它是抗流感药奥司他韦（oseltamivir）合成的重要手性原料。

**莽草酸途径（shikimate pathway）**：由磷酸烯醇式丙酮酸（PEP）与赤藓糖-4-磷酸（E4P）出发，经七步酶促反应合成莽草酸（shikimate），再通向芳香族氨基酸的生物合成通路。它只在植物、真菌与微生物中存在。

整条途径可以压缩成一张流程图：

$$
\ce{PEP + E4P ->[\text{七步}] 莽草酸 -> 分支酸 -> {苯丙氨酸, 酪氨酸, 色氨酸}}
$$

- **入口原料**：PEP 来自糖酵解，E4P 来自戊糖磷酸途径——两者都是初级代谢的分支。
- **关键中间体**：莽草酸（7 碳）、分支酸（chorismate，最后的分岔点）。
- **三大出口**：从分支酸分别通往苯丙氨酸、酪氨酸（经预苯酸）与色氨酸（经邻氨基苯甲酸）。<span class="marginnote">这又是「初级代谢提供原料、次级代谢分叉」的范例：莽草酸途径本身属初级代谢（产芳香氨基酸用于蛋白质合成），但它的中间体与产物被次级代谢大量借用——肉桂酸、木质素、花青素、吗啡都从这里分叉。第1篇那张「进料图」正在一步步被填满。</span>

## 2 七步流水线中的关键步骤

莽草酸途径的七步各由一个酶催化，其中三处最值得记住：

**第一步缩合（DAHP 合酶）**：PEP 与 E4P 缩合成 3-脱氧-D-阿拉伯庚酮糖酸-7-磷酸（DAHP），丢失磷酸。这一步是途径的入口与限速点，受芳香氨基酸的反馈抑制调控。<span class="marginnote">DAHP 合酶同时受苯丙氨酸、酪氨酸、色氨酸的反馈抑制——三种产物「联手」关闸门，避免过度合成。这是代谢调控的经典例子：产物反噬第一步。理解这个闸门，就理解了为什么营养过剩时微生物会下调芳香族合成。</span>

**环化与芳构化的前奏（第5步）**：脱水引入双键，形成 3-脱氢莽草酸。

**还原（第6步）**：3-脱氢莽草酸被还原为莽草酸，获得最终骨架。<span class="marginnote">莽草酸本身是七碳环醇酸，它的名字来自日本植物「莽草」（shikimi，即八角属植物），最早由那里分离。如今莽草酸因成为抗流感药奥司他韦（达菲）合成的重要手性原料而闻名，八角种植也因此牵动全球药市。</span>

**第五至七步的全景**：从 3-脱氢奎尼酸 → 3-脱氢莽草酸 → 莽草酸 → 莽草酸-3-磷酸 → EPSP → 分支酸，一共完成「脱水、还原、磷酸化、与 PEP 缩合」等关键转化。值得记住的只有两件事：**第一步（DAHP 合酶）是限速门，最后一步（分支酸合酶）是出口枢纽**。中间那些步骤的名字（EPSP 合酶、分支酸合酶）会在除草剂草甘膦的故事里再次出现——草甘膦抑制的正是 EPSP 合酶。

## 3 分支：从分支酸到三大芳香氨基酸

分支酸是途中的「交通枢纽」，从这里分出三条支路：

**苯丙氨酸路线**：分支酸 → 预苯酸（prephenate）→ 苯丙酮酸 → 苯丙氨酸。关键在于**脱羧 + 脱水的芳构化**，把预苯酸的环变成苯环。

**酪氨酸路线**：分支酸 → 预苯酸 → 对羟基苯丙酮酸 → 酪氨酸。

**色氨酸路线**：分支酸 → 邻氨基苯甲酸（anthranilate）→ 经吲哚甘油磷酸 → 色氨酸。这一步在 C 上引入吲哚环（苯并吡咯）。<span class="marginnote">三条支路共享分支酸这个「三通阀」，但机制不同：苯丙/酪氨酸经预苯酸脱羧芳构化，色氨酸经邻氨基苯甲酸上吲哚。记住「分支酸 → 预苯酸 / 邻氨基苯甲酸」这个分岔，后面讲各类生物碱时还会反复回到这里。</span>

**重点**：芳香氨基酸的合成价值远超「蛋白质原料」。苯丙氨酸经苯丙氨酸解氨酶（PAL）脱氨生成**肉桂酸**，是第3篇所有苯丙素类产物的总入口；酪氨酸与色氨酸则是众多生物碱的骨架来源。<span class="marginnote">PAL 是植物次生代谢的「总开关」：它把蛋白质氨基酸转出到次生代谢池。肉桂酸再经一系列羟基化、甲基化，生成香豆酸、阿魏酸、芥子酸——这些名字在后几节会反复出现。记住 PAL = 次级代谢大门。</span>

**三条支路的「分流」逻辑**：为什么要有三条支路而不是一条？因为产物用途不同——苯丙氨酸与酪氨酸主要流向苯丙素与木质素（结构 + 防御），色氨酸主要流向生物碱与激素（信号 + 防御）。**分支是功能分工的化学体现**。同时，三支的产量也受不同调控：苯丙氨酸支路在木质化组织中高表达，色氨酸支路在受胁迫时被诱导——「哪个支路开大，取决于植物当下需要什么」。

## 4 公式解析：碳数守恒与芳构化

莽草酸途径的「碳账本」与聚酮不同——它不靠反复缩合同一单元，而是**一次缩合 + 重排**搭建七碳环。看第一步缩合的碳数：

$$
\ce{PEP（3C） + E4P（4C） -> DAHP（7C）}
$$

- **第一步，看原料碳数**：PEP 有 3 个碳，E4P 有 4 个碳，相加恰好 7 个碳。DAHP 因此是 7 碳骨架，这 7 个碳最终全部进入莽草酸与分支酸，再经重排进入芳香环与侧链。
- **第二步，看磷酸的去留**：缩合时 PEP 的高能磷酸键被利用，一个磷酸基以无机磷形式释放。这一步是途径的能量来源，也是「活化-缩合」通则的又一次体现。
- **第三步，看芳构化的碳重排**：从分支酸到苯丙氨酸，预苯酸的环经脱羧脱水芳构化，**侧链的一个碳以 $\ce{CO2}$ 形式离去**。芳香环的 6 个碳加上 3 碳侧链，正好解释苯丙氨酸（$\ce{C9H11NO2}$）的碳骨架来源。<span class="marginnote">这条碳账也是同位素标记验证的依据：用 $^{13}\ce{C}$ 标记的葡萄糖/莽草酸喂养，$^{13}\ce{C}$ 在苯丙氨酸环上的富集模式能与「莽草酸途径」的预期吻合——<strong>碳数守恒 + 标记实验，再次构成生源结论的双保险</strong>。这也呼应第1篇「生源途径研究与同位素标记法」的方法论。</span>

**重点**：莽草酸途径的「碳账本」与聚酮不同——**它不是反复缩合同一单元，而是「一次缩合 + 重排」把 PEP 与 E4P 拼成七碳环**。记住「3 + 4 = 7，环是六碳 + 侧链三碳」这条算术，苯丙氨酸的碳骨架来源就一目了然。

## 5 莽草酸途径的调控与药用意义

莽草酸途径既是植物防御的枢纽，也是药物靶点的富矿，值得单独梳理其「调控与应用」两面：

**途径调控**：DAHP 合酶受三种芳香氨基酸的反馈抑制——**产物联手关闸门，避免碳流浪费**。同时，途径与木质素合成、防御反应耦合：病原侵染时，PAL 与相关基因被诱导上调，苯丙素流量激增。<span class="marginnote">「反馈抑制 + 防御诱导」是莽草酸途径调控的两只手：平时靠产物反馈「限流」，战时靠信号诱导「放量」。理解这套调控，你就理解了植物为什么「受伤就变苦、变硬、变涩」——那都是苯丙素途径被点火的化学后果。</span>

**药物靶点**：**草甘膦（glyphosate）**抑制 EPSP 合酶——植物与微生物独有的酶，动物没有，因此是高效除草剂；**对氨基苯甲酸合成**是磺胺类药物的靶点（细菌合成叶酸的第一步，人靠饮食获取叶酸）——**「动物没有的途径，就是抗菌/除草靶点」这条逻辑，在莽草酸途径上体现得淋漓尽致**。<span class="marginnote">把两个「靶点」连起来看：草甘膦（除草剂）与磺胺（抗菌药）都攻击「动物没有的代谢步骤」——一个打植物、一个打细菌，靠的却是同一套「选择性毒性」逻辑。<strong>理解「途径分布差异 = 药物选择性来源」</strong>，是第2、5篇反复出现的主题，莽草酸途径是它的原始教材。</span>

**食品与药源**：莽草酸本身是抗流感药**奥司他韦（达菲）**合成的重要原料（八角茴香提取），八角种植因此牵动全球药市。

**重点**：莽草酸途径的「一身二任」——既是初级代谢（供芳香氨基酸）又是次级代谢的入口（苯丙素/生物碱）——让它既是植物的「芳香工厂」，也是人类药物的「靶点富矿」。**理解这一条途径，等于同时理解了植物防御、除草剂、抗菌药与抗流感药四条线**。

## 6 三大芳香氨基酸的用途分化

苯丙氨酸、酪氨酸、色氨酸虽是「同一出口的三大产物」，但它们在代谢中的角色完全不同，值得用一张表钉清：

| 氨基酸 | 生源路线 | 主要去向 |
| --- | --- | --- |
| 苯丙氨酸 | 分支酸→预苯酸→苯丙酮酸 | 苯丙素、木质素、部分生物碱（麻黄碱） |
| 酪氨酸 | 分支酸→预苯酸→对羟基苯丙酮酸 | 苄基异喹啉生物碱（吗啡）、多巴胺、黑色素 |
| 色氨酸 | 分支酸→邻氨基苯甲酸→吲哚 | 吲哚生物碱、生长素（IAA）、血清素/褪黑素 |

**重点**：三大芳香氨基酸的分化体现了「**同一途径、不同出口、不同功能**」的代谢逻辑——苯丙氨酸管结构（木质素），酪氨酸管信号与防御（生物碱），色氨酸管信号与激素（IAA、吲哚胺）。**记住「苯丙→苯丙素、酪→异喹啉、色→吲哚」三个对应，第3、5篇的生物碱与苯丙素你都能对上号**。<span class="marginnote">这三条「氨基酸 → 次级代谢」的分岔，正是「从初级代谢到次级代谢」的活地图：同一个莽草酸途径出口，三个氨基酸各自流向不同的天然产物家族。<strong>这也是为什么生物碱会横跨「苯丙/酪型」与「色氨酸型」两大类</strong>——它们的源头都在这条途径的出口。</span>

## 7 莽草酸途径与农业、营养的接口

莽草酸途径还延伸到农业与营养，是「代谢化学走出实验室」的又一窗口：

**除草剂靶点**：草甘膦（农达）抑制 EPSP 合酶，是最畅销的除草剂之一——**「只杀植物不伤动物」的奥秘，就在这条动物没有的途径上**。草甘膦的广谱与低毒（对动物），是「途径分布差异 → 选择性毒性」的最经典农业案例。<span class="marginnote">草甘膦的低毒「真相」值得说清：它对动物的急性毒性很低，主要因为动物没有莽草酸途径（EPSP 合酶），这与「为什么磺胺能杀细菌不伤人」是同一逻辑。<strong>理解途径分布，就理解了选择性毒性的化学基础</strong>——这是贯穿第2、5篇的核心思维。</span>

**必需氨基酸营养**：苯丙氨酸、色氨酸是人类**必需氨基酸**——人体不能合成（缺莽草酸途径），必须从膳食（蛋白质）获取。**「动物不能合成芳香氨基酸」这一条，直接决定了人类的营养需求**。<span class="marginnote">把这条与营养学连接：大豆蛋白、谷物蛋白的「氨基酸评分」里，必需氨基酸（含苯丙/色）是核心指标。<strong>进化把莽草酸途径留给了植物与微生物，也把「必须吃」写进了人类的基因里</strong>——一条代谢途径的分布差异，最终决定了我们的餐桌。</span>

**香料与工业**：莽草酸是八角茴香的主成分之一，也是达菲（奥司他韦）合成的手性原料——**八角种植曾因流感疫情而价格暴涨**，莽草酸从「香料成分」变身「抗流感药原料」。

**重点**：莽草酸途径的意义远超「一条代谢通路」——它是除草剂靶点、必需氨基酸来源、抗流感药原料的「三合一」。**理解这条途径，等于同时理解了农业化学、营养学与制药工业的底层逻辑**。

## 8 小结

- 莽草酸途径 = **PEP + E4P → 莽草酸 → 分支酸 → 三大芳香氨基酸**，只存在于植物/真菌/微生物。
- 关键酶：**DAHP 合酶（入口限速）+ EPSP 合酶（草甘膦靶点）**。
- 分支点：**分支酸 → 预苯酸（苯丙/酪）/ 邻氨基苯甲酸（色）**。
- 与次级代谢衔接：**PAL 把苯丙氨酸转出到苯丙素**，是第3篇的总入口。
- 碳账本：**3 + 4 = 7**，芳构化脱羧解释苯丙氨酸 C9 骨架。
- 药用意义：**草甘膦（除草）、磺胺（抗菌）、莽草酸（达菲原料）**——「动物没有的途径 = 药物靶点」。

在下一节，我们将从三大芳香氨基酸的出口出发，看苯丙氨酸如何被「解氨」进入次生代谢——**苯丙素类与肉桂酸衍生物**，一个 C6-C3 骨架撑起木质素与香豆素家族。
