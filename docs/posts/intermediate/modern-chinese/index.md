# 现代汉语（汉语言文字学：语音、词汇、语法、修辞）

以黄伯荣、廖序东《现代汉语》为主纲，系统学习现代汉语在语音、词汇、语法、修辞各层面的结构与规律。这是普通话规范（汉语拼音方案、通用规范汉字表）的学科根基，也是中文系一切语言应用与研究的入门基石。

## 对标教材

- 黄伯荣、廖序东主编《现代汉语》（增订版，高等教育出版社）
- 北京大学中文系现代汉语教研室《现代汉语》（增订本，商务印书馆）
- 吕叔湘主编《现代汉语八百词》（增订本，商务印书馆）
