## 为什么从 CDG 开始

上一节说「糖链写错了会生病」。那么，**如果糖链工厂的核心零件——某个酶——天生是坏的，会怎样？** 答案是一个病族：**先天性糖基化障碍（CDG）**。它由 1980 年一个比利时小儿的「奇怪综合征」开始，如今已扩展到一百多个基因、覆盖 N-糖基化、O-糖基化与糖鞘脂通路，是人类「糖基化即健康基础设施」的最直接证据。CDG 也是本专题前十二篇知识的总检验：读懂了糖链的装配流水线，才能看懂这些疾病坏在哪一环。

## 1 一种「新综合征」：1980 年的发现

1980 年，Jaeken 与同事描述了一组患儿：**精神运动发育迟缓、血清蛋白在电泳图上明显波动、多种内分泌激素异常**。起初病因不明，只能叫「碳水化物缺陷糖蛋白综合征」（CDGS）；二十多年后人们才明白，这些孩子血清蛋白电泳异常，是因为**血清蛋白没被正确糖基化**——糖链太短、缺唾液酸，导致蛋白等电点改变、电泳迁移异常。<span class="marginnote">这就是 CDG 诊断的敲门砖：用等电聚焦或质谱看血清<strong>转铁蛋白（transferrin）</strong>的糖基化模式——缺一个 N-聚糖、缺唾液酸，会让转铁蛋白的谱带整体向碱性端偏移。检测的对象不是某个蛋白的「量」，而是它的「糖衣完整度」——一个「分子质量/电荷」层面的检查。</span>

### 从 CDGS 到 CDG：命名与分类的演进

这一病族的名字本身就是一部科学史：最早叫「碳水化物缺陷糖蛋白综合征」（CDGS），1999 年后改为「先天性糖基化障碍」（CDG），并按「I 型（前体缺陷）/II 型（加工缺陷）」分型；再后来为了兼容不断增多的基因型，改为**「基因名 + CDG」**的命名（如 PMM2-CDG、MPI-CDG）。**命名的变化反映了认知的升级：从「症状 + 电泳现象」走向「基因 + 通路」**——这也让「型」不再是终点，而是通往具体基因的检索入口。从 1980 年一篇「新综合征」到今天的 100+ 基因，CDG 的历史正是糖生物学从「电泳异常」走向「分子通路」的缩影。

**核心概念：CDG（先天性糖基化障碍，congenital disorders of glycosylation）**：由糖基化相关基因突变导致的一组遗传病，累及聚糖的合成、加工或转运。它们大多是常染色体隐性遗传。

## 2 糖链工厂的零件失灵

CDG 可以按「工厂哪条流水线坏了」来分类：

**I 型（N-糖基化前体缺陷）**：问题出在 ER 里 **N-聚糖前体的装配或转移**——多糖醇循环、OST、PMM2 等。这类最典型，**PMM2-CDG（曾称 CDG-Ia）最常见**，占全部 CDG 病例的多数。
- **II 型（N-聚糖加工缺陷）**：问题出在**高尔基体里后续修剪与延伸**——各种 GlcNAc-T、半乳糖基转移酶、唾液酸转移酶。
- **O-糖基化型**：问题出在 O-聚糖、O-Xyl（蛋白聚糖）、O-Fuc/O-GlcNAc 通路，如 PROS1/凝血缺陷、肌营养不良型。
- **糖鞘脂型**：GPI 锚相关（见第 8 篇的 PIG 基因）、神经节苷脂合成缺陷。

**重点：CDG 的「型」对应着「工厂的工位」**——I 型坏在装配线前端（ER），II 型坏在延伸线（高尔基体）。分清型，才能推断该查哪个基因、该怀疑哪个通路。

### 其他重要的 CDG 类型

PMM2-CDG 之外，几个「名片级」CDG 值得记住：

- **MPI-CDG（CDG-Ib）**：磷酸甘露糖异构酶缺陷，主要累及肠与肝（反复呕吐、低血糖、肝纤维化），是**少数可用甘露糖治疗**的 CDG。
- **ALG1/ALG3-CDG**：N-聚糖前体装配步骤的酶缺陷，常伴严重神经发育问题与感染。
- **SLC35C1-CDG（CDG-IIc）**：GDP-岩藻糖转运体缺陷 → 白细胞缺乏 sLe^x → **白细胞黏附缺陷（LAD-II）**样表现，补岩藻糖部分有效。
- **PGM1-CDG**：磷酸葡萄糖变位酶缺陷，累及糖原与糖蛋白两套系统，**补半乳糖有效**。

**从这些例子能看出治疗策略的谱系：断点越「上游」、越接近糖供体，越可能被外源糖「接线」成功**——这也是 CDG 治疗研究的一条主线。<span class="marginnote">临床上 CDG 的表型谱极广：从致命的严重畸形到轻微的发育迟缓、肝病、凝血异常、免疫缺陷、惊厥——因为糖基化几乎影响每个器官。很多 CDG 最初被误诊为「不明原因综合征」，直到血清转铁蛋白检查把它揪出来。</span>

### 诊断流程：从筛查到定基因

CDG 的现代诊断走一条「漏斗」：

1. **线索**：不明原因的多系统表现（发育迟缓 + 肝病 + 凝血异常 + 畸形），或伴小脑、眼、免疫症状。
2. **筛查**：血清**转铁蛋白等电聚焦/质谱**——看 N-聚糖的「缺糖/缺唾液酸」程度，区分 I 型与 II 型。
3. **定基因**：全外显子/全基因组测序，在候选基因里找致病变异。
4. **验证**：功能实验（酶活性、转铁蛋白糖型在细胞里「重现」），确认不是「VUS（意义未明变异）」。

**这条流程把「分子表型」（糖型）与「基因型」焊在一起**——先看糖谱缩小范围，再用测序锁定基因，是「表型驱动」诊断的现代模板。

## 3 从基因到表型：PMM2 的故事

PMM2-CDG 是最好的「一个酶 → 一串症状」案例。**PMM2** 编码**磷酸甘露糖变位酶（phosphomannomutase）**，它催化

$$\ce{Man-6-P <=> Man-1-P}$$

Man-1-P 再与 GTP 结合成 **GDP-Man**——这是 N-聚糖装配、GDP-Fuc 合成共同需要的「糖电池」。PMM2 活性不足 → GDP-Man 短缺 → **N-聚糖前体装配不足 → 大量糖蛋白欠糖基化** → 全身症状。

PMM2-CDG 的临床谱从轻度到重度：小脑发育不良、共济失调、生长迟缓、脂营养不良、凝血异常、肝功能异常、反复感染。<span class="marginnote">PMM2-CDG 目前没有根治手段——因为 PMM2 把 Man-6-P 变成 Man-1-P，直接补糖（mannose 疗法）需要的是<strong>磷酸甘露糖异构酶（MPI）缺陷的 CDG-Ib</strong>：MPI 把葡萄糖代谢的 Fru-6-P 转成 Man-6-P，缺 MPI 时补糖绕过了这个障碍、效果显著。同一个「缺糖电池」病，一个能补、一个不能补——区别就在酶的位点。</span>

### 可治疗型 CDG：一张「补糖地图」

把「能不能补」画成一张地图，就能看出 CDG 治疗的逻辑：

- **补甘露糖**：MPI-CDG（绕过 Fru-6-P → Man-6-P 的缺口）。
- **补岩藻糖**：SLC35C1-CDG（绕过 GDP-Fuc 转运缺口）。
- **补半乳糖**：PGM1-CDG、部分 SLC35A2-CDG（糖供体前体不足）。

**共同原理：外源糖「灌溉」被阻断的供体合成/转运**。这类「代谢底物治疗」是 CDG 领域最贴近可及治疗的路线——但也再次证明，治疗可及性取决于**断点在供体链的哪个环节**，这正是「分子病理决定治疗策略」的缩影。

## 4 公式解析：从葡萄糖到 GDP-Man

把「糖电池的制造链」写成一条完整的反应链，PMM 的位置就一目了然：

$$\ce{Fru-6-P <=>[MPI] Man-6-P <=>[PMM2] Man-1-P ->[{\text{GMPP, GTP}}] GDP-Man + PPi}$$

三步拆解：

- **第一步，认 MPI（CDG-Ib）**：磷酸甘露糖异构酶把糖酵解中间物 **Fru-6-P** 转成 **Man-6-P**。这一步坏了，补吃甘露糖就能绕过去——因为甘露糖会被己糖激酶磷酸化、直接供给 Man-6-P。
- **第二步，认 PMM2（CDG-Ia）**：磷酸甘露糖变位酶把 **Man-6-P** 变位为 **Man-1-P**。这一步坏了，补糖也无法绕过——甘露糖只能变成 Man-6-P，跨不过这一步。
- **第三步，看产物**：Man-1-P 与 **GTP** 结合成 **GDP-Man**（糖核苷酸供体）。GDP-Man 既供 N-聚糖装配，也供 GDP-Fuc 合成，是整条流水线的「总电闸」之一。

一句话直觉：**CDG = 「糖电池」供应链上的一个断点**；断点位置决定疾病类型、也决定能不能用补糖来「接线」。PMM2-CDG 断在不可绕过的位置，所以格外棘手。

## 5 易错辨析

**辨析｜易错点：** CDG 的「糖基化障碍」不等于「缺乏糖」本身。患者血中葡萄糖通常是正常的——**坏的不是「有糖没有」，而是「糖装不到糖蛋白上」**（缺的是糖核苷酸供体、酶或转运体）。

**辨析｜易错点：** 血清转铁蛋白检测是筛查工具，**不能定位到具体基因**。等电聚焦/质谱能看到「缺糖蛋白」，但「哪个基因坏了」要靠**二代测序（全外显子/全基因组）**确定。**筛查与诊断是两个层次**——这也是本专题一直强调的「读结构」与「读序列」的协作。

**辨析｜易错点：** 别把 PMM2-CDG 与 MPI-CDG 当成「同一病」——它们相差一个酶（PMM2 变位酶 vs MPI 异构酶）、表型也差（PMM2 以神经/多系统为主，MPI 以肠肝为主），**治疗更有天壤之别**（MPI 可补甘露糖、PMM2 不能）。**CDG 的「型」与「型」之间，可能是两种完全不同的病**。

**辨析｜易错点：** CDG 不全是常染色体隐性。多数经典 CDG 是 AR（隐性），但**部分基因在 X 染色体上（如 GPI 锚合成的 PIG-A）**，可呈 X-连锁遗传；少数还可能是显性新生突变。**「都是遗传病」≠「都是隐性遗传病」**——询问遗传模式要逐基因判断。

## 6 小结

- **CDG** 是糖基化相关基因突变导致的遗传病族，多为常染色体隐性；1980 年 Jaeken 首报，如今覆盖 100+ 基因。
- 分类对应工厂工位：**I 型**（ER 前体装配缺陷）、**II 型**（高尔基体延伸缺陷）、O-糖基化型与糖鞘脂型。
- **PMM2-CDG** 最常见：PMM2 缺陷 → Man-1-P 短缺 → GDP-Man 不足 → 欠糖基化 → 多系统症状。
- 诊断：**血清转铁蛋白糖基化分析（筛查）+ 全外显子测序（定基因）**；治疗因断点而异，CDG-Ib 可用甘露糖疗法。
- 治疗逻辑是「分子病理决定策略」：补甘露糖（MPI）、补岩藻糖（SLC35C1）、补半乳糖（PGM1），断点在供体链越上游越可能被外源糖「接线」。
- CDG 命名已走向「基因名 + CDG」；PMM2-CDG 与 MPI-CDG 相差一个酶，表型与治疗却天差地别。
- 遗传模式不全是常染色体隐性——PIG-A 等基因在 X 染色体上，可呈 X-连锁遗传。
- 分子病理决定治疗策略：断点越上游、越接近糖供体，越可能被外源糖「接线」。
- CDG 的「型」对应「工厂的工位」：I 型坏在 ER 装配、II 型坏在高尔基体延伸。
