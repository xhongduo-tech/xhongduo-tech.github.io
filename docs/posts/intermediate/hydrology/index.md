# 水文学

水文学研究地球上水的循环、分布与运动规律，是理解水资源可持续利用、预测洪水与干旱、量化气候变化水文响应的核心基础学科。以地球系统水循环为主线，从水分循环与水量平衡出发，贯通降水、蒸散发、下渗、地下水、径流与河流，直至水环境与水资源评价。

## 对标教材

- Dingman, "Physical Hydrology" (3rd ed., Waveland Press)
- Hornberger et al., "Elements of Physical Hydrology" (2nd ed., Johns Hopkins University Press)
- 黄锡荃等，《水文学》（高等教育出版社）
