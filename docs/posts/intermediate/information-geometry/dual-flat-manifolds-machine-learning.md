## 为什么从应用收束

十篇铺垫，回到初心：信息几何不是为了给统计学换一套漂亮说法，而是要解决机器学习里那些「谁都能跑、谁都说不清为什么有效」的算法。对偶平坦流形是这一切的公共舞台——指数族、KL、投影、自然梯度、Bregman 散度，在此合流成一张统一地图。<span class="marginnote">Amari 的 2016 教材最后两章正是把信息几何应用到神经网络、强化学习、Boosting 与贝叶斯推断。本专题以「应用篇」收束，把前面每一篇的工具挂回具体算法。</span>

本篇把对偶平坦结构应用到四类机器学习问题：聚类与矩阵分解、Boosting 与在线学习、变分推断，以及深度学习中的自然梯度与参数空间几何。

## 1 聚类：Bregman 硬聚类

k-means 在欧氏空间里找簇中心、最小化点到中心的平方距离。**Bregman 硬聚类**把它推广：用任意 Bregman 散度替代欧氏距离，迭代地（a）把每个点分给散度最小的中心；（b）更新中心为簇内点的 Bregman 意义下的「中点」。<span class="marginnote">Banerjee 等人在 2005 年证明了 Bregman 聚类的普适性：每个 Bregman 散度对应一个指数族分布，Bregman 聚类就是该指数族的硬 EM。这使「指数族 ↔ Bregman ↔ 聚类」三位一体。</span>

对偶平坦的功劳在于**中点有闭式**：在指数族上，Bregman 散度的中点就是「期望参数的平均」——$\eta$ 坐标下的算术平均自动落在流形内。这是对偶坐标 $\eta$ 兑现的又一处红利：**凸几何里的中点运算，搬到统计流形上依然闭合。**

**一个工程提醒**：Bregman 聚类与 k-means 的差别不止在距离函数——当数据点落在流形边界（概率接近 0 或 1）时，KL 类的 Bregman 散度会惩罚「跨界」的点，聚类边界随之更贴合分布的几何；而欧氏 k-means 把边界画成欧氏垂直平分线。**选哪种散度，本质上是选「你相信什么样的簇形状」**。

### 数值算例：Bregman 质心

「中点有闭式」这句话落到数字上。设离散分布空间里的两个点 $p = (0.6, 0.4)$、$q = (0.2, 0.8)$，用 KL 对应的 Bregman 散度（生成元为负熵）。对离散指数族，期望参数就是 $\eta = p$ 本身，所以 Bregman 意义下的质心是**期望参数的算术平均**：

$$r = \frac{p + q}{2} = (0.4, 0.6)$$

检验它确实「居中」：以「到两点的散度之和」为准则，$D_{KL}[p : r] \approx 0.081$，$D_{KL}[q : r] \approx 0.092$，总和约 $0.173$；而任何偏离 $r$ 的候选都会让总和变大（例如 $r' = (0.42, 0.58)$ 给出约 $0.174$）。**η 坐标的算术平均正是使总散度最小的 Bregman 质心**——注意两侧散度不必相等，因为 KL 本身不对称；被平分的是「梯度」而非「散度值」。<span class="marginnote">若改用 m-测地线定义中点，得到算术平均（混合）；用 e-测地线定义中点，得到几何平均 $r_i \propto \sqrt{p_i q_i}$。Bregman 质心夹在这两者之间，位置由生成元 $\varphi$ 的曲率决定。</span>

## 2 Boosting 与在线学习：Bregman 投影

AdaBoost 的训练过程，几何上是「在指数族（弱学习器的加权组合）上反复做 I-projection」。每轮的权重更新

$$w^{(t+1)}_i \propto w^{(t)}_i e^{-y_i f_t(x_i)}$$

正是沿 e-测地线的更新——指数加权保证权重始终留在单纯形（m-平坦族）里。<span class="marginnote">Boosting 与 Bregman 投影的联系由 Collins、Schapire 与 Singer（2002）给出：AdaBoost 的每步都是「沿熵正则化方向的最大似然投影」，而熵正是指数族的势函数。这说明「几何证明」与「算法设计」在 Boosting 上完全吻合。</span>

在线学习里，**online mirror descent** 每步先做梯度下降、再做 Bregman 投影回可行域——这恰是「e 一步、m 一步」的另一个翻版。对偶平坦结构保证投影点的解析表达式与收敛界同时干净。

### Boosting 的几何速览

AdaBoost 与 online mirror descent 在几何上几乎是同一件事：

| 算法 | e 一步 | m 一步 |
| --- | --- | --- |
| AdaBoost | 指数加权更新权重 $w \propto e^{-y f}$ | 归一化回单形（m-投影） |
| Mirror descent | 沿梯度方向更新原空间 | Bregman 投影回可行域 |

两者的共同点：**更新一步发生在对偶坐标里，投影一步把结果拉回原坐标**——这正是对偶平坦流形上「两步走」的标准形态。

## 3 变分推断：KL 投影到简化流形

贝叶斯后验 $p(\theta \mid x)$ 通常不可计算，变分推断（VI）的做法是：**在简化分布族 $\mathcal{Q}$（如均值场族）上找一个 $q^*$，使 $D_{KL}[q : p]$ 最小**——这是把 M-投影反向使用：不是向数据投影，而是向「可计算的子流形」投影。

均值场 VI 是对偶平坦流形上向「因子化子流形」的投影，坐标上升即坐标方向上的投影迭代。
- 期望传播（EP）用**矩匹配**近似正交投影，等价于「按各阶矩逐一对齐」。
- 自然梯度变分推断把 Fisher 度量装进 VI 的梯度步，正是第 8 篇工具的直接套用。<span class="marginnote">VI 与 EP 的差别在几何上非常清晰：VI 做的是「固定一阶矩」的 KL 投影（保守），EP 做的是「匹配所有矩」的矩投影（激进）。这种差别用语言说不清，用投影方向一说就明。</span>

## 4 深度学习：参数空间的几何

把神经网络看作「参数 → 预测分布」的映射，参数空间上的 Fisher 度量就描述了「参数变化对预测分布的影响」。这带来一系列几何洞察：

**自然梯度与近似 Fisher**：K-FAC、Shampoo、SWA 都试图逼近 $F^{-1}$，本质都在逼近第 8 篇的 $g^{-1}$。<span class="marginnote">近年「参数空间几何与泛化」的研究发现：平坦极小（Hessian 小特征值）与 Fisher 度量下的大体积相关，而 Sharpness-Aware Minimization（SAM）显式惩罚 Hessian 特征值——可视为在统计流形上「避开尖锐谷」的几何正则化。</span>
- **特征演化与神经正切核（NTK）**：在无限宽极限下，训练轨迹的 Fisher 度量趋于恒定，参数演化线性化——这解释了深度网络训练早期的「线性 regime」。
- **模式坍缩与散度**：GAN 的模式坍缩在 f-散度的几何里是「生成分布与真实分布的 f-散度在支持集上的塌缩」，理解它需要意识到散度在分布边界附近的敏感度差异。

### 几何正则化的三类面孔

| 方法 | 几何操作 | 目标 |
| --- | --- | --- |
| 权重衰减 | 欧氏惩罚远离原点 | 控制坐标范数 |
| 自然梯度 + 先验 | Fisher 度量下的 KL 正则 | 控制分布变化量 |
| SAM | 惩罚 Hessian 大特征值 | 向平坦极小移动 |

三者对「什么是好解」给出了不同的几何答案——选哪个，取决于你相信损失面在 Fisher 度量下长什么样。

**辨析｜易错点：** 不要把「参数空间的欧氏平坦」误当成「分布空间的平坦」。深度学习参数空间在欧氏坐标里看似平凡，但在 Fisher 度量下弯曲严重——这正是普通 SGD 有时「跑很远却改变不了分布」、而自然梯度更有统计效率的几何原因。二者差异在高维下被放大，不可混为一谈。

**一个值得记住的对照**：均值场 VI 的坐标上升每次更新一个因子的变分参数，这正是一个坐标方向上的 m-投影；而自然梯度 VI 把「坐标方向」换成「Fisher 度量下的最陡方向」，从而摆脱坐标选取的影响——后者在高维后验里通常收敛更快。这些几何洞察也反向启示架构设计：既然 Fisher 度量刻画参数空间的信息结构，那么「度量近似的质量」就决定了优化器对网络规模的扩展性——K-FAC 的分块近似之所以有效，正是因为神经网络的 Fisher 矩阵天然接近分块对角。理解这一点，比记住某个优化器的超参更有迁移价值。

## 5 统一地图：一条主线

回顾整条线索，机器学习算法在对偶平坦流形上的位置一目了然：

| 算法 | 几何操作 | 用的结构 |
| --- | --- | --- |
| k-means / Bregman 聚类 | 中点投影迭代 | Bregman 散度 + 对偶坐标 |
| AdaBoost / 在线学习 | e-测地线更新 | 指数族 + I-projection |
| EM / 变分推断 | e/m 两步投影 | Pythagoras + 子流形投影 |
| 自然梯度 / K-FAC | 度量逆旋转梯度 | Fisher 度量 + 近似 |
| SAM / 泛化分析 | 平坦区正则化 | 曲率 + Fisher 度量 |

这张表就是本专题十一篇的压缩：**每一行背后都是同一个对偶平坦舞台，只是换了一套道具。**

**方法论收尾**：信息几何不承诺「更快的常数」，它承诺的是**结构**——告诉你每个算法在做什么样的投影、为什么收敛、瓶颈在哪。带着这张地图去读新论文，比多背十个 trick 更值钱。非参数情形（全体密度的无穷维流形）、量子信息几何（密度矩阵的推广）、以及 α-联络族在因果推断里的最新应用，都是从这里出发的自然岔路。

### 术语速查表

| 术语 | 一句话含义 |
| --- | --- |
| 对偶平坦流形 | 两套联络都无曲率、测地线是直线的流形 |
| Bregman 散度 | 由凸函数 $\varphi$ 定义的「切平面差距」 |
| 对偶坐标 | $(\theta, \eta)$ 由 Legendre 变换互锁的坐标对 |
| I-projection | 最小化 $D_{KL}[q : p]$，对应最大熵 |
| M-projection | 最小化 $D_{KL}[\hat p : p_\theta]$，对应极大似然 |
| 自然梯度 | 用 Fisher 度量逆校正的最陡下降方向 |

这张表把十一篇的工具一次性收拢：**指数族、KL、投影、自然梯度、Bregman，全部住在同一张对偶平坦地图上**。

## 6 小结

- **Bregman 聚类**：欧氏 k-means 的散度推广，对偶坐标让中点有闭式。
- **Boosting 与在线学习**：e-测地线更新 + Bregman 投影，投影定理保证收敛。
- **变分推断**：向可计算子流形的 KL 投影；VI 与 EP 的差别在投影方向上一目了然。
- **深度学习**：Fisher 度量刻画参数空间几何，解释自然梯度、NTK 与 SAM 的动机。
- **统一主线**：指数族、KL、投影、自然梯度、Bregman 在对偶平坦流形上合流。

至此，从「分布是流形上的点」到「优化是流形上的投影」，信息几何的全部主干已经走完。如果还有兴致继续深入，可以沿三条岔路前进：非参数信息几何（全体密度的无穷维流形）、量子信息几何（密度矩阵的推广），或把 α-联络族的几何贯彻到因果推断与生成模型的最新研究里。
