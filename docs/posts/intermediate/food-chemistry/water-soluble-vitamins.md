## 为什么从水溶性维生素开始

上一篇的脂溶性维生素「跟着油走」，这一篇的水溶性维生素「跟着水走」——**B 族维生素与维生素 C** 共同的特征是：溶于水、吸收后多余的随尿排出、**体内蓄积很少，必须靠每日饮食持续供给**。<span class="marginnote">水溶性维生素的加工命运也由此注定：<strong>水洗流失、热水溶出、烹煮沥水——一次不合理的烹饪就能丢掉大半</strong>。理解水溶性维生素，等于理解「为什么蔬菜要急火快炒、先洗后切」背后的化学。</span>

这一篇先给 B 族全家福，再重点讲维生素 C（食品中最娇贵的维生素），最后落到加工损失规律。核心线索：**水溶性维生素的稳定，取决于「怕什么」——怕水、怕热、怕氧、怕光、怕碱**，各有各的命门。

## 1 维生素 C：抗坏血酸

**维生素 C（ascorbic acid，抗坏血酸）**：六碳糖酸内酯，结构上是一个**烯二醇（enediol）**，这个结构让它既是强还原剂、又极易被氧化。

**功能**：胶原蛋白合成的辅因子（脯氨酸/赖氨酸羟化）、抗氧化、促进铁吸收、参与免疫。**缺乏**导致坏血病（牙龈出血、伤口难愈）——历史上远洋航海者因缺新鲜果蔬而大量死于坏血病，后来库克船长靠酸菜与柑橘解决了这个问题，是「食品化学挽救生命」的经典案例。

**核心化学：可逆氧化还原对**——抗坏血酸（还原型）与**脱氢抗坏血酸（dehydroascorbic acid, DHA，氧化型）**可以互相转化，两者都有维生素 C 活性：

$$\ce{AscH2 \lt => DHA + 2H+ + 2e-}$$

但 DHA 一旦进一步水解为**二酮古洛糖酸（diketogulonic acid）**，就**永久失去活性**——这是维 C 损失的「不可逆终点」。<span class="marginnote"><strong>这条氧化链是理解维 C 稳定性的钥匙</strong>：抗坏血酸先被可逆地氧化成 DHA（活性还在），再水解开环就彻底失效。食品加工要做的，是<strong>把体系停在 DHA 之前</strong>——加抗氧化剂、隔氧、避光、避金属。</span>

**维 C 是食品中最娇贵的维生素之一**：怕氧（尤其铜、铁催化）、怕热、怕光、怕碱性、**还溶于水（水洗流失）**。柑橘类因酸性环境较稳定，而叶菜在室温存放与烹煮中损失最快。

## 2 B 族维生素：一个「辅酶」大家庭

B 族维生素的共同身份：**绝大多数是辅酶（coenzyme）的前体**，在代谢中承担基团搬运工。它们水溶性高，**极易在清洗与烹煮中流失**。

| 维生素 | 辅酶形式 | 承担的任务 | 主要来源 | 特殊弱点 |
| --- | --- | --- | --- | --- |
| B₁ 硫胺素 | TPP | 糖代谢脱羧 | 谷物、猪肉、豆类 | 怕热、怕碱、亚硫酸盐 |
| B₂ 核黄素 | FMN/FAD | 氧化还原（氢转运） | 乳、蛋、绿叶菜 | 怕光（尤其碱性） |
| B₃ 烟酸 | NAD⁺/NADP⁺ | 氧化还原 | 肉类、谷物、花生 | 较稳定 |
| B₆ 吡哆醇 | PLP | 氨基酸代谢 | 肉类、谷物、香蕉 | 怕光、怕热 |
| B₉ 叶酸 | THF | 一碳代谢、造血 | 绿叶菜、肝、豆类 | 怕热、怕氧、怕光 |
| B₁₂ 钴胺素 | AdoCbl/MeCbl | 造血、神经 | 动物性食品 | 怕光、怕碱、怕氧化 |

**重点：** 两条食品教训贯穿全家福。**其一，B₁ 怕亚硫酸盐**——亚硫酸盐常用于保鲜，却会裂解硫胺素，所以**含 B₁ 丰富的食品（谷物、肉）禁用亚硫酸盐处理**；**其二，B₂ 怕光**——牛奶用透明玻璃瓶放阳光下，核黄素光解且催生「日光味」（光氧化蛋氨酸的异味），**所以牛奶要用避光包装**。<span class="marginnote"><strong>牛奶的「日光味」</strong>是食品光化学的经典案例：核黄素吸收光能后敏化光氧化，把蛋氨酸残基氧化成含硫异味物。纸盒与褐色瓶阻光，正是为了同时保护 B₂ 与风味。</span>

**B₁₂ 的特殊性**：**几乎只存在于动物性食品**，植物性食品几乎没有（除发酵产物、强化食品）。纯素食者若不补充 B₁₂ 制剂或强化食品，有缺乏风险——这是「植物性饮食」营养设计的头号议题。

## 3 叶酸的加工敏感性

**叶酸（folate）** 在绿叶蔬菜、肝、豆类中丰富，但**极不稳定**：加热煮汤可损失 50%～90%，还怕氧、怕光、怕酸败。食品工业常在谷物、面粉中**强化叶酸**，以预防新生儿神经管畸形——美国等国自 1998 年起强制强化，效果显著。

**辨析｜易错点：** 「合成的叶酸（folic acid）」与「天然叶酸（folate）」化学形式不同，吸收利用率也不同。**合成叶酸更稳定、生物利用率更高**，因此在强化食品与补剂中常用。设计强化配方时，两者不能直接按 μg 等价替换——营养学有专门的「膳食叶酸当量（DFE）」换算。

## 4 加工损失：水溶性维生素的「流失清单」

水溶性维生素在加工中损失的主要途径，按可防性排序：

**水溶流失**：清洗、焯水、蒸煮沥水——维生素溶进水里被倒掉。**对策**：先洗后切、减少水量、利用煮汁（做汤、勾芡）。

**热降解**：温度与时间越长，损失越大。**对策**：急火快炒、蒸汽代替水煮、缩短加热。

**氧化**：维 C、叶酸、B₁₂ 对氧敏感，金属离子催化。**对策**：隔氧包装、加抗氧化剂、避免铁铜器皿。

**光降解**：B₂、维 C、叶酸怕光。**对策**：避光包装、避光储存。

**酶促降解**：切碎后抗坏血酸氧化酶等继续破坏维 C。**对策**：尽快加工、热烫灭酶。

**辨析｜易错点：** **「加工越多损失越大」不是均匀的**——不同维生素的脆弱程度差一个数量级：维 C 和叶酸几乎「一煮就没」，烟酸和泛酸却相对皮实。**设计保营养的工艺，先分清「怕什么的维生素」**：怕水的用水少、怕热的用温低、怕氧的用隔氧——一药不能治百病。

## 5 公式解析：维生素 C 保留率

评估工艺对维 C 的伤害，常用**保留率（retention）**：

$$\text{保留率} = \frac{C_{\text{处理后}}}{C_{\text{原料}}} \times 100\%$$

进一步，维 C 的热降解常近似**一级反应**：

$$\ln\frac{C_t}{C_0} = -k\,t$$

逐项拆解：

- **$C_{\text{处理后}} / C_{\text{原料}}$（保留率）**：直观「还剩多少」。冻豌豆热烫后维 C 保留率可 >90%，而长时间水煮菠菜可能仅剩 40%～60%。
- **$k$（降解速率常数）**：随温度指数上升（Arrhenius）。**温度每升 10°C，维 C 降解往往加快 2 倍以上**——所以「低温快煮」优于「高温久煮」。
- **一级反应的推论**：$t$ 在指数上，**时间与温度是「乘法」不是「加法」**——煮 10 分钟与煮 20 分钟的损失不是两倍关系，而是指数级的差别。
- **工程含义**：**短时高温（快速烫漂、瞬时杀菌）比长时低温更能保住维 C**——因为维 C 的活化能相对较低，高温下品质损失速度虽然快，但总时间极短，净损失反而小。这与第 11 篇「UHT 保品质」的动力学逻辑完全同构。<span class="marginnote"><strong>保留率是一切保营养工艺的「成绩单」</strong>：工厂验收工艺、法规标注营养成分、消费者比较产品，都看这个数。营养标签上的「维生素 C 含量」本质上就是「原料含量 × 保留率」。</span>

## 6 烹饪方式对水溶性维生素的影响

「怎么煮」直接决定维生素的最终去向。以蔬菜的维 C 为例，不同烹饪方式的保留率差异显著：

| 烹饪方式 | 维 C 保留率（约） | 原因 |
| --- | --- | --- |
| 急火快炒 | 60%～90% | 时间短、水少 |
| 蒸 | 50%～80% | 不接触大量水、时间短 |
| 微波 | 50%～85% | 加热快、水少 |
| 水煮（弃汤） | 30%～60% | 溶出 + 热降解，汤被倒掉 |
| 长时间炖煮 | 20%～50% | 时间长、温度高 |

<span class="marginnote"><strong>数据的通用启示</strong>：保留率是「水溶 + 热 + 氧 + 光」四种损失的合计数。<strong>急火快炒与蒸是「低损失」操作，水煮弃汤是「高损失」操作</strong>——不是「熟食不如生食」，而是「怎么熟」决定营养去向。把煮汤喝掉（做汤、勾芡），能回收溶出的维生素。</span>

**延伸的操作原则**：

- **先洗后切**：切丁后水洗，切面直接泡水，维 C 溶出更多。
- **整棵/大块烹煮**：减少暴露面积，缩短受热时间。
- **带皮蒸煮**：皮层阻挡溶出。
- **酸性环境**：加醋/柠檬酸，维 C 在酸性中更稳定（氧化受抑制）。
- **出锅再调味、现吃现做**：减少存放中的持续损失。

**辨析｜易错点：** **「生吃一定比熟吃有营养」不成立**。加热灭活了抗坏血酸氧化酶，反而**减少了存放与消化过程中的酶促维 C 损失**；同时加热提高 β-胡萝卜素等脂溶性成分的吸收（第 16 篇）。**「该生则生、该熟则熟」**——没有一刀切的答案，只有针对具体营养素的权衡。

**核心概念：** 把这一节的烹饪原则与第 3 节「损失清单」合起来，就是一套**「保营养烹饪」的完整决策树**：先看怕什么（水/热/氧/光），再选手段（少水/短时/隔氧/避光），最后用保留率验证。

## 7 小结

- 水溶性维生素（**B 族 + 维 C**）溶于水、不蓄积、**需每日供给**，加工中极易流失。
- **维 C** 靠烯二醇结构做还原剂，氧化链 $\ce{AscH2 -> DHA -> 二酮古洛糖酸}$，前两步可逆、第三步永久失活。
- **B 族维生素多为辅酶前体**；B₁ 怕亚硫酸盐、B₂ 怕光（日光味）、B₁₂ 几乎只在动物性食品。
- **叶酸**是加工损失最重的维生素之一，常需强化进面粉。
- 损失四大途径——**水溶、热、氧、光**——各有对策，先分清「怕什么的维生素」再设计工艺。
- **保留率** $\dfrac{C_{\text{处理后}}}{C_{\text{原料}}}\times 100\%$ 与**一级降解动力学** $\ln(C_t/C_0)=-kt$
