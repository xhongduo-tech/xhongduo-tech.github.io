## 为什么从电解质溶液开始

电化学研究「电荷如何在化学体系中转移」：电池放电、电解生产、金属腐蚀，本质都是**电极表面的电荷转移**。而电荷要转移，就必须有一条供离子「走动」的通道——那就是**电解质溶液**。离子在溶液里怎么分布、怎么受力、怎么迁移，决定了电极上的一切后续行为。<span class="marginnote">如果把电极反应比作一场交易，电解质溶液就是资金（离子）流动的市场：市场里资金怎么定价（活度）、怎么流动（迁移），直接决定交易的效率。这也解释了为什么本专题把溶液放在第一篇。</span>

这一篇是整个「电化学原理」的地基。后续的 Nernst 方程、Butler–Volmer 动力学、传质理论，全都建立在对电解质溶液的理解之上；同时它也与第二级《物理化学》《电分析化学》、第一级《化学》形成纵向衔接——那里讲「是什么」，这里讲「为什么」。

## 1 电解质与电离

**电解质（electrolyte）**：在水溶液或熔融状态下能够导电的化合物。导电的本质是它在溶剂中**电离**成带正电的阳离子与带负电的阴离子，离子携带电荷定向移动形成电流。

按电离程度，电解质分为两类：

**强电解质**：在溶液中几乎完全电离。如 $\ce{NaCl}$、$\ce{HCl}$、$\ce{KOH}$，它们在水中几乎以离子形态存在。

**弱电解质**：在溶液中仅部分电离，存在电离平衡。如醋酸 $\ce{CH3COOH \lt => H+ + CH3COO-}$、氨水 $\ce{NH3 + H2O \lt => NH4+ + OH-}$。

**电离度（degree of dissociation）** $\alpha$：已电离的分子数占原有分子总数的分数。强电解质的 $\alpha$ 接近 1；弱电解质的 $\alpha$ 随浓度稀释而增大——这是 Le Chatelier 原理的直接推论。<span class="marginnote">把「电离度随稀释增大」记牢，后面学电导时你会发现：弱电解质的摩尔电导率随稀释而增大的原因，一半来自电离度上升，一半来自离子间相互作用减弱。</span>

这里埋着一个重要区分：**电解质溶液的导电能力 ≠ 电解质本身的「强」**。导电能力还取决于离子浓度与离子淌度，一个浓度极低的强电解质溶液，导电能力可能还不如浓的弱电解质溶液。

## 2 活度与离子强度：真实溶液的「有效浓度」

理想溶液中，浓度 $c$ 直接决定热力学性质。但真实电解质溶液中，离子间存在长程库仑作用，每个离子都被符号相反的离子云包围，实际「发挥作用的有效浓度」偏离标称浓度。

**活度（activity）** $a$：把真实浓度折算成能代入热力学公式的有效浓度。对离子 $i$：

$$a_i = \gamma_i \frac{c_i}{c^\ominus}$$

其中 $\gamma_i$ 为**活度系数（activity coefficient）**，$c^\ominus$ 为标准浓度（通常 1 mol/L）。理想溶液 $\gamma_i = 1$，非理想溶液 $\gamma_i \lt  1$。

单个离子的活度系数原则上**不可单独测量**——因为任何实验测得的都是阳离子与阴离子共同贡献的净效应。于是引入**平均活度系数（mean activity coefficient）**：

$$\gamma_\pm = \left( \gamma_+^{\nu_+} \gamma_-^{\nu_-} \right)^{1/(\nu_+ + \nu_-)}$$

其中 $\nu_+$、$\nu_-$ 是电离出一个化学式单位所产生的阳、阴离子个数。例如 $\ce{Na2SO4 -> 2Na+ + SO4^2-}$，$\nu_+ = 2$，$\nu_- = 1$。<span class="marginnote">「单个离子活度不可测量」是整个电解质溶液热力学的分水岭：所有教材里凡出现单离子活度的公式都是约定性假设，而可测的热力学量永远配对出现——这就是平均活度系数存在的根本原因。</span>

**离子强度（ionic strength）** $I$ 刻画溶液中离子电场的总体强度：

$$I = \frac{1}{2}\sum_i c_i z_i^2$$

离子的电荷数 $z_i$ 是平方贡献，因此高价离子对离子强度的影响远大于同浓度的一价离子。<span class="marginnote">离子强度只由「每个离子的浓度 × 电荷平方」求和决定，与离子种类无关——相同离子强度下，不同电解质的活度系数往往接近，这就是「离子强度」这个标度比浓度更本质的原因。</span>

## 3 离子的迁移与迁移数

把外电场加到溶液两端，离子便受到静电力，开始定向运动——这称为**电迁移（electromigration）**。离子的迁移速度 $v_i$ 与电场强度 $E$ 成正比：

$$v_i = u_i E$$

比例系数 $u_i$ 称为**离子淌度（ionic mobility）**，单位 $\mathrm{m^2\,V^{-1}\,s^{-1}}$。淌度取决于离子半径、电荷与溶剂化程度——水合离子半径越小、电荷越高，淌度越大。典型顺序：$\ce{H+}$ 与 $\ce{OH-}$ 的淌度异常地大，因为它们通过质子跳跃机制（Grotthuss 机制）迁移，远快于普通离子的整体漂移。

电流由阳离子与阴离子共同承担，各自的份额用**迁移数（transport number）** 描述：

$$t_+ = \frac{I_+}{I_+ + I_-} = \frac{c_+ z_+ u_+}{c_+ z_+ u_+ + c_- |z_-| u_-}, \qquad t_+ + t_- = 1$$

迁移数刻画的是「每种离子搬运了多少电荷」，它取决于浓度与淌度的乘积，而非单纯的浓度。<span class="marginnote">迁移数是个实验可测的量：希托夫法（Hittorf）通过测定电解前后电极区浓度的变化来推算 $t_+$ 与 $t_-$——这个实验是「电荷搬运份额」最直观的测量，也是理解法拉第定律在溶液内部如何落地的基础。</span>

**辨析｜易错点：** 迁移数描述的是**电荷的份额**，不是**物质的量份额**。$\ce{NaCl}$ 溶液中 $\ce{Cl-}$ 的物质的量浓度是 $\ce{Na+}$ 的一半，但两者的迁移数之和仍为 1，各自份额由「浓度 × 电荷 × 淌度」共同决定。

## 4 电导与摩尔电导率

溶液的导电能力用**电导（conductance）** $G$ 描述，它是电阻的倒数，单位 $\pu{S}$（西门子）。**电导率（conductivity）** $\kappa$ 是单位电导，相当于「边长为 1 m 的立方体溶液的电导」，单位 $\pu{S/m}$，它只取决于溶液本身的性质，与电极几何无关。

不同电解质的导电能力无法用 $\kappa$ 直接比较——因为 $\kappa$ 随浓度升高而升高。为此引入**摩尔电导率（molar conductivity）**：

$$\Lambda_m = \frac{\kappa}{c}$$

含义：把「1 mol 电解质」全部拆成离子，这些离子在相距 1 m 的两极板间所能搬运的电荷能力。摩尔电导率才是比较「每个电解质分子导电能力」的公平标尺。

实验上发现两类规律：

**强电解质**（Kohlrausch 经验定律）：浓度不高时，摩尔电导率与浓度平方根成线性关系：

$$\Lambda_m = \Lambda_m^\infty - A\sqrt{c}$$

**弱电解质**：$\Lambda_m$ 随稀释急剧上升，且永远无法直接外推到 $\Lambda_m^\infty$——因为稀释在改变离子间作用力的同时，还在不断推高电离度。<span class="marginnote">「强电解质外推、弱电解质不能外推」是电导测量的核心区分：$\Lambda_m^\infty$ 对强电解质可由 $\Lambda_m$ 对 $\sqrt{c}$ 作图截距直接得到，对弱电解质则必须借助离子独立运动定律间接求出。</span>

弱电解质的 $\Lambda_m^\infty$ 用 **Kohlrausch 离子独立运动定律** 求得：无限稀释时，离子间相互作用消失，每种离子的摩尔电导率独立贡献：

$$\Lambda_m^\infty = \nu_+ \lambda_+^\infty + \nu_- \lambda_-^\infty$$

其中 $\lambda_+^\infty$、$\lambda_-^\infty$ 为离子的**无限稀释摩尔电导率**，是只与离子本性有关的常数。

### 典型离子的无限稀释摩尔电导率

| 离子 | $\lambda^{\infty} / \pu{S cm^2 mol^{-1}}$（25 °C） | 说明 |
| --- | --- | --- |
| $\ce{H+}$ | 349.8 | 质子跳跃机制，异常高 |
| $\ce{OH-}$ | 198.3 | 质子跳跃机制，异常高 |
| $\ce{K+}$ | 73.5 | 水合半径小，淌度较高 |
| $\ce{Cl-}$ | 76.3 | 普通阴离子 |
| $\ce{Na+}$ | 50.1 | 水合半径较大，淌度较低 |

$\ce{H+}$ 与 $\ce{OH-}$ 的数值是普通离子的 4–7 倍，这直接来自 **Grotthuss 质子跳跃机制**：它们并非整体漂移，而是沿氢键链做质子接力传递——水分子只需原地转动、质子一棒接一棒，等效迁移速度远大于普通离子的整体位移。这解释了为什么强酸强碱溶液的电导率显著高于同浓度的盐溶液，也提示了燃料电池质子交换膜「只有质子能飞快穿梭」的材料设计逻辑。

## 5 公式解析：摩尔电导率为何随 $\sqrt{c}$ 线性下降

**Kohlrausch 定律 $\Lambda_m = \Lambda_m^\infty - A\sqrt{c}$ 是强电解质溶液电导行为的第一定律，拆解它，等于拆解离子间相互作用的本质。**

这条公式看似经验，背后是三步物理图像：

- **第一步，读清两个极限**：$c \to 0$ 时，$\sqrt{c} \to 0$，$\Lambda_m \to \Lambda_m^\infty$，即无限稀释时离子间毫无相互作用，摩尔电导率达到上限。$A$ 是只与溶剂、温度和电解质价型有关的常数。
- **第二步，理解 $\sqrt{c}$ 的来源**：离子间的库仑作用由 Debye–Hückel 离子氛（ionic atmosphere）描述——每个离子周围存在电荷相反、时间平均分布的「离子云」。离子云的半径 $\kappa^{-1}$（Debye 长度）与 $\sqrt{I}$ 成反比，故离子浓度越大，离子氛越密、对离子迁移的阻滞越强，这种阻滞以 $\sqrt{c}$ 的方式进入摩尔电导率。这是「根号浓度」之所以出现的物理根源。
- **第三步，把阻碍翻译成电导损失**：迁移中的离子要拖着自己的离子氛一起运动，离子氛的存在等效于增加介质黏度，即产生**电泳效应（electrophoretic effect）** 与**松弛效应（relaxation effect）**。两种效应都与 $\sqrt{c}$ 成正比，合起来就是经验式中的 $-A\sqrt{c}$ 项。因此「$\Lambda_m$ 随 $\sqrt{c}$ 线性下降」不是凑出来的拟合线，而是 Debye–Hückel 离子氛理论在迁移问题上的必然结果。

**辨析｜易错点：** 摩尔电导率 $\Lambda_m = \kappa / c$ 随稀释**增大**，而电导率 $\kappa$ 在低浓度区随稀释**减小**。二者趋势相反，原因是浓度 $c$ 同时出现在分子与分母：$\kappa$ 度量绝对导电能力，浓度降低必然削弱它；$\Lambda_m$ 是「每个电解质分子」的导电能力，稀释解除了离子间阻滞，反而让它上升。

## 6 小结

- 电解质分为**强电解质**（几乎完全电离）与**弱电解质**（存在电离平衡）；电离度 $\alpha$ 描述电离程度。
- 真实溶液用**活度** $a_i = \gamma_i c_i / c^\ominus$ 修正；单离子活度不可测，必须用**平均活度系数** $\gamma_\pm$；**离子强度** $I = \frac{1}{2}\sum c_i z_i^2$ 是控制活度系数的核心标度。
- 离子在电场中**电迁移**，速度 $v_i = u_i E$；**迁移数** $t_i$ 刻画每种离子承担的电荷份额，且 $t_+ + t_- = 1$。
- **电导率** $\kappa$ 与几何无关，**摩尔电导率** $\Lambda_m = \kappa / c$ 才是比较导电能力的标尺；强电解质满足 Kohlrausch 定律，弱电解质需借助**离子独立运动定律**求 $\Lambda_m^\infty$。
