## 为什么从代数曲线开始

前面我们用**解析**的方法研究了黎曼曲面：坐标卡、全纯映射、微分、层。本篇建立黎曼曲面理论最惊人的桥梁：**紧黎曼曲面「就是」射影代数曲线**——即多项式方程组在射影空间中的光滑解集。这不是「类比」而是**同构**：每一条紧黎曼曲面都全纯等价于某条光滑射影曲线，反之亦然。<span class="marginnote">这条「对偶原理」（GAGA 的精神，Serre 1956）让黎曼曲面的研究者可以在两个世界之间自由切换：要算积分，用解析侧；要做算术，用代数侧。数论里的「算术曲线」——定义在数域上的光滑曲线——正是这条桥梁的延伸，是怀尔斯证明费马大定理的舞台。</span>

为什么重要？因为代数曲线的「原料」是多项式方程——**可计算、可算术化、可推广到任意域**。黎曼曲面作为复分析对象，只在 $\mathbb{C}$ 上有意义；但写成方程后，可以在 $\mathbb{Q}$、$\mathbb{F}_p$ 上「定义」，从而被数论接管。**紧黎曼曲面 ↔ 代数曲线 的字典，是现代数学最大的一本字典之一**。

## 1 什么是代数曲线

**射影平面（projective plane）** $\mathbb{P}^2$：所有比例 $(x:y:z)$（不全为零）构成的二维复流形，$(x:y:z) \sim (\lambda x:\lambda y:\lambda z)$。它有三个仿射卡 $z \ne 0$（坐标 $x/z, y/z$）、$y\ne 0$、$x \ne 0$。<span class="marginnote">为什么用射影而非仿射？仿射曲线 $f(x,y)=0$ 不是紧的（在无穷远漏点）；射影化（加齐次化变量）把「无穷远」也包进来，得到紧对象。<strong>「紧 = 代数完备」</strong>是射影几何的根本动机。</span>

**射影代数曲线（projective algebraic curve）**：$\mathbb{P}^n$ 中由齐次多项式组 $F_1 = \cdots = F_k = 0$ 定义的、维数为 1 的**光滑**子簇。对曲线，「光滑」指每点的切空间维数为 1（Jacobian 矩阵满秩）。**光滑性**排除奇点（自交点、尖点），是「曲线是流形」的充要条件。

**例子**：
直线 $ax+by+cz = 0$（亏格 0）；
圆锥曲线 $x^2 + y^2 = z^2$（亏格 0，有理等价于 $\mathbb{P}^1$）；
三次曲线 $y^2 z = x^3 + axz^2 + bz^3$（亏格 1，即椭圆曲线）；
- Fermat 曲线 $x^n + y^n = z^n$（亏格 $\frac{(n-1)(n-2)}{2}$）。

**辨析｜易错点：** 「代数曲线」不是「代数方程的图像」——它是**光滑**的、在**射影**空间里的对象。方程 $y^2 = x^3$ 在原点有尖点，不是代数曲线（作为复流形）而是带奇点的代数簇；它的**正规化**（desingularization）才是黎曼曲面。**「黎曼曲面 = 光滑化后的代数曲线」**——奇点要修，这是两门学科相遇时最需要留神的差异。

## 2 紧黎曼曲面是代数曲线

**定理（存在嵌入）**：任何紧黎曼曲面 $X$ 都全纯等价于 $\mathbb{P}^n$ 中某条光滑射影代数曲线。

**证明的骨干**（Riemann–Roch 的直接应用）：
- 取充分大的 $n$ 与充分大的除子 $D$（如 $D = mP$，$m$ 大），使 $l(D)$ 足够大且「无基点」（$L(D)$ 的函数不同时在一点消失）。
- 令 $f_0, \ldots, f_N$ 是 $L(D)$ 的一组基，映射 $\varphi_D: X \to \mathbb{P}^N$，$p \mapsto (f_0(p):\cdots:f_N(p))$。
- 选 $D$ 使 $\varphi_D$ 是**嵌入**（分离点与切线，由「无基点」与「$l(D-2P)$ 的亏缺」控制）。像 $\varphi_D(X)$ 是 $\mathbb{P}^N$ 中的光滑紧复曲线子流形。
- **Chow 定理**：$\mathbb{P}^N$ 中的紧复子流形都是代数子簇。故 $\varphi_D(X)$ 是射影代数曲线。

**这就是「每条紧黎曼曲面都能写成多项式方程的解集」**——但要注意，这条定理**没有给出显式的方程**，只保证存在性。求「显式方程」需要典范嵌入或其它构造（对一般曲线，典范嵌入 $X \to \mathbb{P}^{g-1}$ 给出的方程就是「插值多项式」）。<span class="marginnote">Chow 定理是「解析 ↔ 代数」桥梁的一半：紧复子流形自动是代数的。另一半是「代数对象自动是复流形」（光滑 ⇒ 复流形）。GAGA 定理（Serre）把「解析凝聚层」与「代数凝聚层」的上同调等同起来，彻底焊死两座大陆。</span>

**低亏格的显式几何**：典范映射给出「最小嵌入」的线索——亏格 $g$ 的**一般**曲线典范嵌入到 $\mathbb{P}^{g-1}$：
$g = 2$：$\mathbb{P}^1$ 中嵌入不可能，典范映射是 $2:1$ 到 $\mathbb{P}^1$（超椭圆），无嵌入；
$g = 3$：$\mathbb{P}^2$ 中的光滑四次曲线（典范嵌入是平面曲线，$g=3$ 与 $d=4$ 一致）；
$g = 4$：$\mathbb{P}^3$ 中四次曲线与二次曲面的交；
- $g \ge 5$：一般曲线是「交不出为单纯曲线」的——需要用更复杂的理想生成。**低亏格的这些具体方程，是「曲线 = 方程」的最直观样本**。

## 3 代数曲线是紧黎曼曲面

反方向同样干净。$\mathbb{P}^n$ 自身是紧复流形（$n$ 维复射影空间），其复结构来自仿射卡的 $\mathbb{C}^n$。**光滑射影代数曲线 $C \subset \mathbb{P}^n$** 作为 $\mathbb{P}^n$ 的复子流形，自动是**紧黎曼曲面**：光滑性保证每点有局部复坐标，紧性来自 $\mathbb{P}^n$ 的紧性，连通性来自「曲线」的定义。

于是两句话合起来：

**定理（对偶原理）**：紧黎曼曲面 $\cong$ 光滑射影代数曲线，双射（模双全纯/双有理等价）。<span class="marginnote">严格说，「紧黎曼曲面」与「光滑射影代数曲线」之间是<strong>等价范畴</strong>：全纯映射对应多项式映射（GAGA），全纯线丛对应代数线丛。这个等价让「曲线」这个词在解析与代数两侧同义，也让「亏格」成为一个纯粹的代数不变量。</span>

**算例**：平面光滑曲线 $C: F(x,y,z) = 0$（齐次，次数 $d$）是亏格
$$ g = \frac{(d-1)(d-2)}{2} $$
的紧黎曼曲面。$d=1$：$g=0$（直线）；$d=2$：$g=0$（圆锥曲线，有理等价于 $\mathbb{P}^1$）；$d=3$：$g=1$（三次曲线 = 椭圆曲线）；$d=4$：$g=3$（四次平面曲线）。这个公式下节推导。

## 4 公式解析：亏格—次数公式

**公式（平面曲线亏格）**：光滑平面射影曲线 $F(x,y,z)=0$ 次数 $d$ 的亏格为
$$ g = \frac{(d-1)(d-2)}{2} $$

用 Riemann–Hurwitz 推导，是最干净的路径之一：

- **第一步，投影**。取一点 $P_0$（不在 $C$ 上），把 $C$ 从 $P_0$ 投影到直线 $\mathbb{P}^1$：$\pi: C \to \mathbb{P}^1$，把每个点 $p$ 映到「$P_0 p$ 与直线的交点」。因为 $C$ 与过 $P_0$ 的直线交 $d$ 次（Bezout 定理），$\pi$ 的次数 $= d$。
- **第二步，数分歧**。$C$ 光滑，投影的切线即「与 $C$ 相切的过 $P_0$ 直线」。一条一般切线切于一个点（切点），但在特殊切点（拐点）处切线「切得更高阶」。过 $P_0$ 的切线共有 $d(d-1)$ 条（次数的经典数切线的公式），每条贡献一个分歧点；**总分歧 $\sum(e_p - 1) = d(d-1)$**。
- **第三步，代入 Riemann–Hurwitz**。$Y = \mathbb{P}^1$（$g_Y = 0$），$d$ 层覆盖：
$$ 2g - 2 = -2d + d(d-1) \quad\Longrightarrow\quad 2g = d^2 - 3d + 2 = (d-1)(d-2) $$
即 $g = \frac{(d-1)(d-2)}{2}$。**公式得证**。
- **第四步，检查**：$d=3$ 给 $g=1$，与椭圆曲线一致；$d=4$ 给 $g=3$。**「次数决定亏格」**——平面曲线的复杂性完全由它的次数读出。

**另一种看法（邻接公式）**：$g = \frac{(d-1)(d-2)}{2}$ 也可由「典范除子的自交数」推出（$\deg K_C = (d-2)\cdot d = d(d-2) = 2g - 2$），这正是代数几何里「邻接公式（adjunction）」的曲线版本。两种推导的答案一致，暴露了 Riemann–Hurwitz 与交点数「同宗同源」。

**算例（三次曲线 = 数 6 条切线）**：对光滑三次曲线（$d=3$），过外部一点 $P_0$ 的切线共有 $d(d-1) = 6$ 条——这是平面曲线的「类」（class）：从一点引向曲线的切线数，对次数 $d$ 的光滑平面曲线恒为 $d(d-1)$。于是总分歧 $\sum(e_p - 1) = 6$，代入 $2g - 2 = -6 + 6 = 0$ 得 $g = 1$——「数切线」重新发现了椭圆曲线的亏格。取 $C: x^3 + y^3 = z^3$（Fermat 三次）时，这 6 条切线可以用 $P_0$ 的坐标显式解出，是检验 Riemann–Hurwitz 投影证明的好练习。

## 5 例子：超椭圆曲线与椭圆曲线

- **超椭圆曲线**：$y^2 = \prod_{i=1}^{2g+2}(z - a_i)$ 射影化后是次数 $d = 2g+2$ 的曲线吗？不是——它不是平面 $d$ 次曲线（方程不是齐次的），它的射影化是 $\mathbb{P}^2$ 中的曲线 $Y^2 Z^{2g} = \prod (X - a_i Z)$，次数 $2g+2$，但**不是光滑平面曲线**（在 $\infty$ 处有奇点）。正确理解：它是 $\mathbb{P}^1$ 的二重分歧覆盖（见《Riemann–Hurwitz 公式》），亏格 $g$。<span class="marginnote">这提醒我们：<strong>不是每条亏格 $g$ 曲线都能光滑地放进 $\mathbb{P}^2$</strong>。亏格公式 $g=\frac{(d-1)(d-2)}{2}$ 给光滑平面曲线的亏格一个强约束（如 $g=2$ 无光滑平面模型：$(d-1)(d-2)=4$ 无整数解）。「曲线 → 嵌入的最小射影空间」是「坎普克-松山/哈茨霍恩问题」的源头。</span>
**椭圆曲线**：$y^2 = x^3 + ax + b$（$4a^3 + 27b^2 \ne 0$ 保证光滑）射影化后是 $\mathbb{P}^2$ 中的光滑三次曲线，亏格 1。它是「既是黎曼曲面，又是代数曲线，又是复环面」的三位一体（见《椭圆曲线作为黎曼曲面》）。
**Fermat 曲线**：$x^n + y^n = z^n$ 光滑、次数 $n$，亏格 $\frac{(n-1)(n-2)}{2}$。$n=3$ 是椭圆曲线；$n \ge 4$ 亏格 $\ge 3$，是费马大定理的几何语言（「费马曲线无有理点」对 $n \ge 3$）。

## 6 字典：解析与代数

把两边的词一一对应，是学习本条目的最佳总结：

| 解析侧（黎曼曲面） | 代数侧（代数曲线） | 关键桥梁 |
| --- | --- | --- |
| 紧黎曼曲面 | 光滑射影曲线 | 嵌入 + Chow |
| 全纯映射 | 多项式（正则）映射 | GAGA |
| 亚纯函数 | 有理函数 | Riemann–Roch |
| 全纯微分 | 正则微分（代数微分） | 双线性对偶 |
| 线丛 / 除子 | 代数线丛 / Cartier 除子 | 指数正合列 |
| Riemann–Roch | 代数 Riemann–Roch | Serre 对偶 |
| Jacobi 簇 | Picard 簇 | Abel 定理 |
| 模空间 $M_g$ | 曲线模叠 | 单值化 |

**辨析｜易错点：** 解析侧的对象带着「紧」与「连通」；代数侧的对象带着「射影」「光滑」。翻译时必须检查这两组性质是否对得上：**解析紧 ⟷ 代数射影，解析流形 ⟷ 代数光滑**。若代数曲线「光滑但不射影」（仿射的），它对应解析侧的「非紧黎曼曲面」；若「射影但不光滑」，对应「带奇点的对象」。

## 7 影响：从复分析到数论

「紧黎曼曲面 = 代数曲线」的最大受益者是**数论**。定义在 $\mathbb{Q}$ 上的光滑射影曲线（如 $y^2 = x^3 - x$）既是黎曼曲面（复点），又能在有限域 $\mathbb{F}_p$ 上约化（模 $p$）。**每条算术曲线的「复几何」与「模 $p$ 几何」被 Hasse–Weil 的 L 函数绑在一起**——而证明 L 函数的解析性质（Hasse–Weil 猜想/Weil 猜想）是现代数论的核心问题。怀尔斯证明费马大定理的路线，正是「椭圆曲线（亏格 1 的黎曼曲面）是模的」——模性定理——这条由 Taniyama–Shimura–Weil 猜想支撑、建立在「曲线 = 黎曼曲面 = 模曲面商」这张大网上的结果。<span class="marginnote">更进一步：Grothendieck 把「曲线」推广到「曲线上的一切」——étale 上同调、动机、Abel 簇。黎曼曲面理论提供的「解析直观」始终是这些抽象构造的指南针。对初学者，记住一件事：<strong>多项式方程把复分析变成了算术</strong>，而亏格是连接两者的不变量。</span>

## 8 小结

- **紧黎曼曲面 ↔ 光滑射影代数曲线**：双射（模等价），由嵌入 + Chow 定理（解析→代数）与「光滑 ⇒ 复流形」（代数→解析）构成。
- **亏格—次数公式**：光滑平面曲线次数 $d$ 的亏格 $g = \frac{(d-1)(d-2)}{2}$，由投影 + Riemann–Hurwitz 推出。
- 奇点必须修：带奇点的代数方程对应「带奇点的曲线」，其正规化才是黎曼曲面。
- 例：直线/圆锥曲线 $g=0$，三次曲线 $g=1$，四次平面曲线 $g=3$；超椭圆曲线不一定是光滑平面曲线。
- **词典**：解析侧与代数侧逐词对应（映射、微分、线丛、Riemann–Roch、Jacobi）。
- 意义：曲线可以在任意域上定义，复分析变成算术——费马大定理、Weil 猜想的舞台。
- 低亏格：$g=2$ 无光滑平面模型、$g=3$ 是平面四次曲线、$g=4$ 是 $\mathbb{P}^3$ 中曲线与二次曲面的交。
- 阅读锚点：亏格—次数公式 $g=\frac{(d-1)(d-2)}{2}$ 是「代数曲线 = 黎曼曲面」的第一张计算表；Chow + GAGA 是两座大陆之间的桥。
