## 为什么从光滑性继续

微分几何里你问一个流形「在一点是否光滑」，用 Jacobi 矩阵的秩来回答；代数几何里同一件事有它自己的版本，而且答案比微积分情形更微妙。圆 $x^2 + y^2 = 1$ 处处光滑；但尖点曲线 $y^2 = x^3$ 在原点就「折断」了，那里的切空间维数比曲线维数高。这多出来的维数，正是**奇异性**的定量刻画。

本节系统建立三件套：**切空间**（几何版的"微分子空间"）、**光滑性**（切空间维数恰到好处）、**正规簇**（奇点的弱形式被排除）。维数则在多种等价定义之间游走，最后汇成一条主线：$\dim X = \operatorname{trdeg} K(X) = \operatorname{Krull}\dim A(X)$。这套理论是后续概形理论中「正则局部环」概念的种子，也是第 13 篇曲线分类里「光滑曲线 vs 奇异曲线」分野的基础。

## 1 切空间：几何的"一阶近似"

**核心概念：局部环（local ring）**：仿射簇 $X$ 在点 $P$ 处的**局部环**是

$$\mathcal{O}_{P, X} = \{ \text{在 } P \text{ 附近正则的函数} \} = A(X)_{\mathfrak{m}_P}$$

其中 $\mathfrak{m}_P = I(\{P\})$ 是对应点 $P$ 的极大理想，$A(X)_{\mathfrak{m}_P}$ 是局部化。局部环捕捉「点 $P$ 无穷小邻域上的全部代数信息」。<span class="marginnote">「无穷小邻域」在代数上就是「对极大理想局部化」：除以 $\mathfrak{m}_P$ 得留数域 $k$，而 $\mathfrak{m}_P / \mathfrak{m}_P^2$ 记录一阶信息、$\mathfrak{m}_P^2/\mathfrak{m}_P^3$ 记录二阶信息……整套信息叠加在 $\mathcal{O}_{P,X}$ 里。这正是微分几何「泰勒展开」的代数版：阶数 = 理想幂次。</span>

**核心概念：Zariski 切空间（tangent space）**：点 $P \in X$ 处的**切空间**定义为

$$T_P X = \left( \mathfrak{m}_P / \mathfrak{m}_P^2 \right)^*$$

即 $\mathfrak{m}_P/\mathfrak{m}_P^2$ 的对偶 $k$-向量空间。<span class="marginnote">$\mathfrak{m}_P/\mathfrak{m}_P^2$ 叫「余切空间」，对偶后得到切空间。为什么这样定义？因为"在 $P$ 附近为零且被 $P$ 处一阶数据"杀掉的东西，恰是"微分"——一阶量。这和微积分里 $df = \sum \partial f/\partial x_i \, dx_i$ 同构。</span>

在标准情形 $X = V(f_1, \dots, f_r) \subseteq \mathbb{A}^n$，$P = (a_1, \dots, a_n)$，切空间有显式形状：

$$T_P X = \left\{ (v_1, \dots, v_n) \in k^n \;\middle|\; \sum_{j=1}^n \frac{\partial f_i}{\partial x_j}(P) \, v_j = 0, \quad i = 1, \dots, r \right\}$$

这正是微积分里切平面的方程，只是"微分"换成了"形式偏导"。例如 $y^2 = x^3$ 在原点：$f = y^2 - x^3$，$\partial f/\partial x = -3x^2$、$\partial f/\partial y = 2y$，原点处偏导全为零，约束全空，故 $T_0 X = k^2$——二维切空间，比曲线本身维数（1）高。这就是"奇异"的信号。

## 2 光滑性与 Jacobi 判别法

**核心概念：光滑点 / 奇异点（smooth / singular point）**：不可约簇 $X$ 在点 $P$ 处称为**光滑（非奇异）**的，如果 $\dim_k T_P X = \dim X$；否则称为**奇异**的。$X$ 处处光滑则称 $X$ 为光滑簇。

为什么"切空间维数恰好等于簇维数"就是光滑？因为奇异点必然让切空间"胀大"（约束不够、切空间超维）。判别法落到偏导数上：设 $X = V(f_1, \dots, f_r) \subseteq \mathbb{A}^n$ 的每个不可约分支维数为 $n - r$（即 $f_i$ 相互独立定义），则

**重点：Jacobi 判别法（Jacobian criterion）**：$P \in X$ 光滑 ⟺ Jacobi 矩阵

$$J(P) = \left( \frac{\partial f_i}{\partial x_j}(P) \right)_{1 \le i \le r,\, 1 \le j \le n}$$

在 $P$ 处**秩为 $r$**（行满秩）。<span class="marginnote">秩满 ⟺ 约束方程在 $P$ 处线性独立 ⟺ 切空间维数 $\dim T_P X = n - r = \dim X$。这与微分流形里的正则值定理 $f^{-1}(c)$ 是光滑子流形（当 $c$ 是正则值）同构，只是完全代数化。</span>

例子：圆 $x^2 + y^2 - 1 = 0$，$J = (2x, 2y)$。处处 $(x,y) \neq (0,0)$，故秩恒为 1，圆处处光滑。尖点曲线 $y^2 - x^3 = 0$，$J = (-3x^2, 2y)$，原点处为零矩阵秩 0，奇异；其余点秩 1，光滑。<span class="marginnote">奇异点的集合本身是 $X$ 的真闭子簇 $\operatorname{Sing} X$（由所有 r 阶子式同时为零定义），它的维数严格小于 $\dim X$。于是「光滑点全体」是 $X$ 的稠密开子集——奇异点是"极少"的，但往往决定了簇的算术本质。</span>

**辨析｜易错点：** Jacobi 判别法成立的前提是 $f_1, \dots, f_r$ 定义了**纯 $r$ 维完全交**（每个分支维数 $= n - r$）。若 $f_i$ 有冗余（如 $f_1 = x, f_2 = 2x$），行列秩永远不可能是 r，会误判处处奇异。正确做法是先消去冗余（用理想生成元的最小素链）再算秩。初学者最常见的错误：拿一个不是完全交的定义方程直接套秩条件。

## 3 正规簇：把奇点"修好"的弱版本

有的簇不光滑，但它的奇点并不"太坏"。**核心概念：正规簇（normal variety）**：不可约簇 $X$ 称为**正规**的，如果它的坐标环 $A(X)$ 是**整闭**的——即 $K(X)$ 中每个在 $A(X)$ 上整的元素都在 $A(X)$ 里。<span class="marginnote">整闭（integrally closed）是「在代数上封闭」：域 $K(X)$ 中凡"满足一个以 $A(X)$ 系数为整首一的方程"的元素，都必须已经在 $A(X)$ 里。与「代数闭域」是同一精神的环版本。</span>

**重点：光滑 ⟹ 正规 ⟹ 整坐标环。** 事实是：**光滑簇必正规**（正规是光滑的必要条件）；而正规簇的奇异点集维数至多 $\dim X - 2$。反过来，正规簇在余维 1 处是光滑的——"正规"正是要求奇点不能埋在余维 1 的子簇里。<span class="marginnote">余维 1 的子簇叫「超曲面」或「素除子」。正规性排除的是"整条曲线都是奇点"的极端病态：比如锥面 $xy = z^2$ 在原点有孤立的奇异点，但它余维 2，允许；而 $x^3 + y^3 = 0$ 分解成的三条直线的并，每条线都是奇异集，不正规。</span>

正规性是"把双有理等价类里的代表修好"的关键概念：**每个双有理等价类里有唯一（在恰当意义下）的正规簇代表**（取函数域在坐标环中的整闭包）。这解释了为什么奇点理论如此重要：不光滑没关系，只要能"正规化"，几何信息就还是好的。第 14 篇的 blow-up 就是最常用的"修奇点"手术。

## 4 维数：多种定义殊途同归

**核心概念：维数（dimension）**：不可约簇 $X$ 的维数 $\dim X$ 有三种等价定义：<span class="marginnote">这三种定义分别来自拓扑、代数、域论三个视角，其等价性是一条深刻定理（Hartshorne Ch. I §1 Theorem 1.8A 等）。知道它们等价，就能在不同场合挑最顺手的用。</span>

1. **拓扑维数**：$X$ 中严格降的闭不可约链 $\varnothing \subsetneq Z_0 \subsetneq \cdots \subsetneq Z_r$ 的最大长度 $r$。
2. **Krull 维数**：$\dim A(X)$ = $A(X)$ 中严格升的素理想链的最大长度。
3. **函数域超越度**：$\dim X = \operatorname{trdeg}_k K(X)$。

对 $V(f) \subseteq \mathbb{A}^2$：链 $\{P\} \subsetneq V(f) \subsetneq \mathbb{A}^2$ 给出维数 2，即 $\dim = 2$ 指 $\mathbb{A}^2$ 本身，$V(f)$ 的维数 = 1（曲线）。一般约定：**空集的维数 = $-1$**。<span class="marginnote">对射影簇同样成立，且射影空间 $\dim \mathbb{P}^n = n$。维数最小的非空对象是点（维数 0），其上自然是常数函数环——与第 2 篇「射影簇上正则函数为常数」的直觉呼应。</span>

维数还与切空间有基本不等式：**对任意点 $P \in X$，有 $\dim X \le \dim_k T_P X$**。光滑点取等号，奇异点严格不等号。于是「奇异点 = 切空间超维的点」。这条不等式是第 2 节 Jacobi 判别法最深层的几何来源，也贯穿后续一切"奇点计数"。

## 5 公式解析：切空间维数与光滑性

$$
\dim_k T_P X = n - \operatorname{rank} J(P), \qquad P \text{ 光滑 } \iff \dim_k T_P X = \dim X
$$

分三步拆解：

- **第一步，切空间由线性方程定义**：$T_P X$ 由 $r$ 个线性方程 $\sum_j \partial f_i/\partial x_j(P) \, v_j = 0$ 定义，其维数 $= n - \operatorname{rank} J(P)$——线性代数里"方程独立多少、自由度就剩多少"。<span class="marginnote">这正是「切空间 = 对超平面约束取核」：在微积分里，光滑曲面的切平面由梯度方程给出；代数几何把它代数化为"偏导矩阵的核"。</span>
- **第二步，什么时候取到维数**：若 $X$ 的每个分支都是 $n - r$ 维完全交，则 $\dim X = n - r$。于是 $\dim_k T_P X = \dim X$ ⟺ $\operatorname{rank} J(P) = r$——Jacobi 判别法。
- **第三步，超维意味着奇异**：若 $\operatorname{rank} J(P) < r$，则 $T_P X$ 比 $X$ 本身"高维"。直观上：$P$ 处的一阶信息不足以确定 $X$ 的形状，曲线在此"折弯"甚至"穿透"，局部环 $\mathcal{O}_{P,X}$ 退化为奇异环。几何退化被一阶数据（偏导）捕获——这正是奇异性的定量语言。

一句话直觉：**光滑 = 一阶近似精确匹配真实维数**；奇异 = 一阶近似"胀破"了真实维数，必须用更高阶信息（理想幂次）才能看清局部形状。

## 6 小结

- **局部环** $\mathcal{O}_{P,X} = A(X)_{\mathfrak{m}_P}$：点处的"无穷小代数邻域"，阶数 = 理想幂次。
- **切空间** $T_P X = (\mathfrak{m}_P/\mathfrak{m}_P^2)^*$：一阶近似的向量空间，显式为偏导矩阵的核。
- **光滑性**：$\dim_k T_P X = \dim X$；**Jacobi 判别法**：$\operatorname{rank} J(P) = r$。奇异点集是低维闭子簇。
- **正规簇**：坐标环整闭；光滑 ⟹ 正规；正规的奇点余维 ≥ 2。每个双有理类有正规代表。
- **维数**：拓扑维数 = Krull 维数 = 函数域超越度；$\dim X \le \dim_k T_P X$ 处处成立。

在下一节，我们开始第二轮抽象，把「簇」升级为「概形」（scheme）——用层的语言统一仿射与射影、统一"点"与"理想"，这是 Grothendieck 革命的起点。
