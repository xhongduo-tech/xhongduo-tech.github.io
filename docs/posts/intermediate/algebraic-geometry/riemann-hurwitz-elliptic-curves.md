## 为什么从 Riemann-Hurwitz 继续

Riemann-Roch 告诉我们"单条曲线能装多少个函数"。现在问下一个问题：**两个曲线之间的映射 $f: C \to C'$ 会怎样改变亏格？** 若 $f$ 是"有限覆盖"（每点纤维有限），覆盖的层数 $n$ 与"分支点"（纤维少于 $n$ 的点）的行为，完全决定了亏格的变化。这就是 **Riemann-Hurwitz 公式**：

$$2g - 2 = n(2g' - 2) + \deg R$$

它把"拓扑的亏格"、"覆盖的层数"与"分支的严重程度"写成一条精确等式。<span class="marginnote">直觉：$f$ 把 $C$ "缠绕"到 $C'$ 上 $n$ 层。亏格差 = 层数乘以基的"弯曲" + 分支点处的"折痕"。欧拉示性数版本 $2 - 2g = n(2 - 2g') - \deg R$ 在复几何里是"纤维化 = 分层纠缠"的拓扑事实；在代数几何里则是除子理论的算术事实。</span>

本节最后一部分把亏格 0、1、2 的曲线彻底分类，尤其给出**椭圆曲线**（$g = 1$）的完整图像：群结构、$j$-不变量、以及"椭圆曲线分类 = 模空间 $X(1) \cong \mathbb{P}^1$"这一现代模空间理论的起点。这部分是"曲线论深化"的收束，也直接连接第 16 篇 GAGA 的复解析视角。

## 1 有限态射、次数与分支

**核心概念：有限态射（finite morphism）**：态射 $f: X \to Y$ 是**有限的**，如果 $f_* \mathcal{O}_X$ 是 $Y$ 上的凝聚层（即"局部是有限环扩张"）。对曲线间的非平凡态射，这等价于"每个纤维都有限且各纤维的大小有界"。曲线 $C$ 到 $C'$ 的非常数态射 $f: C \to C'$ 自动是有限态射。<span class="marginnote">非常数曲线态射为什么自动有限？因为像的闭包是 $C'$ 的闭子簇，维数只能小于等于 1；像维数 1（非常数）时，$C'$ 本身就是像，$f$ 于是是"在函数域层面有限扩张"的——代数上"有限生成 + 整 = 有限"。</span>

**核心概念：次数（degree）**：有限态射 $f: C \to C'$ 的**次数**是

$$\deg f = [K(C) : K(C')]$$

（函数域的扩张次数），也是"一般纤维的大小"：对一般点 $Q \in C'$，纤维 $f^{-1}(Q)$ 恰有 $\deg f$ 个点。<span class="marginnote">两个定义一致：函数域扩张次数 = 一般纤维的大小（代数几何的"计数 = 域的维数"原理）。例子：$\mathbb{P}^1 \to \mathbb{P}^1$，$[t:1] \mapsto [t^2:1]$，次数 2，一般纤维两个点（$t$ 与 $-t$）。</span>

**核心概念：分歧指数（ramification index）**：点 $P \in C$ 处，令 $v_P$ 为 $C$ 在 $P$ 的离散赋值。**分歧指数**

$$e_P = v_P(f^\#(t_{f(P)}))$$

其中 $t_{f(P)}$ 是 $C'$ 在 $f(P)$ 处的一致化参数（uniformizer）。若 $e_P > 1$，称 $P$ 是**分支点（ramified point）**，$f(P)$ 是**支点（branch point）**；$e_P = 1$ 称 $P$ 未分歧。<span class="marginnote">直觉：$e_P$ 是"在 $P$ 处 $f$ 缠绕 $f(P)$ 的次数"。$z \mapsto z^2$ 在 $z=0$ 的 $e = 2$——原点被"叠"了两层。对代数闭域上的曲线态射，$e_P = 1$ 除有限多个点外都成立（"一般点未分支"），且分支集是有限的——这正是公式里 $\deg R$ 可数的基础。</span>

**核心概念：分歧除子（ramification divisor）**：$R = \sum_P (e_P - 1) P$，称为**分歧除子**。$\deg R = \sum_P (e_P - 1)$ 是"分支的总严重程度"。对无分支态射（如 $\deg f$ 与特征互素的循环覆盖的未分歧部分），$\deg R = 0$。

## 2 Riemann-Hurwitz 公式

**重点：Riemann-Hurwitz 公式。** 设 $f: C \to C'$ 是光滑射影曲线间的 $n$ 次有限态射，$g, g'$ 分别为 $C, C'$ 的亏格，则

$$2g - 2 = n(2g' - 2) + \deg R$$

其中 $R$ 是分歧除子。<span class="marginnote">等价地用欧拉示性数 $\chi = 2 - 2g$ 写：$\chi(C) = n\,\chi(C') - \deg R$。拓扑版（Riemann 面覆盖理论）由"把 $C$ 沿分支点切开再叠 $n$ 层"的计数直接得到；代数版由"$K_C = f^*K_{C'} + R$"（典范除子拉回 + 分歧）取次数得到。两条路殊途同归。</span>

证明骨架（代数版）：**相对微分的标准正合列**给出典范层关系

$$K_C = f^* K_{C'} + R$$

两端取次数：$\deg K_C = 2g - 2$，$\deg f^* K_{C'} = n \cdot \deg K_{C'} = n(2g' - 2)$，$\deg R = \deg R$。这正是公式。<span class="marginnote">$K_C = f^*K_{C'} + R$ 是"子对象典范 + 分支修正"——与伴随公式 $K_C = (K_X + C)|_C$（第 9 篇）同源。微分形式的拉回"有极点"，$R$ 就是"极点预算"：$f^*\omega$ 在分支点有额外零点，用 $R$ 记下。</span>

**例子：超椭圆曲线。** 设 $C \to \mathbb{P}^1$ 是 $2:1$ 覆盖（$g' = 0$），由方程 $y^2 = p(x)$（$\deg p = 2g + 2$，无重根）给出。R-H：$2g - 2 = 2(-2) + \deg R = -4 + \deg R$，故 $\deg R = 2g + 2$。每个"$y = 0$"的点（$p$ 的根）是分支点，$e = 2$，$R = \sum_{p(x)=0} 1 \cdot P$——正好 $2g + 2$ 个分支点。<span class="marginnote">例：$g = 1$ 的超椭圆曲线 $y^2 = x^3 + ax + b$（$\deg p = 4 = 2 \cdot 1 + 2$）有 4 个分支点；$g = 2$ 的 $y^2 = x^5 + \cdots$（$\deg p = 6$）有 6 个分支点。R-H 精确数出它们。</span>

**推论：小亏格的分类骨架。** 若 $g' = 0$（覆盖 $\mathbb{P}^1$），R-H 给 $2g - 2 = -2n + \deg R$，即

$$\deg R = 2g + 2n - 2$$

"分支总重"由亏格与层数唯一决定。<span class="marginnote">特别地：$g = 0$、$n = 2$ 的 $\mathbb{P}^1 \to \mathbb{P}^1$ 有 $\deg R = 0$——$\mathbb{P}^1$ 的 2:1 覆盖未分支（这正是 $\mathbb{P}^1$ 单连通的表现）；而 $g \ge 1$ 的曲线"必须有分支"，因为 $\pi_1$ 非平凡。R-H 是"拓扑单连通性"的代数证据。</span>

## 3 曲线的亏格分类

把 R-R 与 R-H 合起来，曲线按亏格分类的图景浮现：

**亏格 0**：唯一的（$k$ 代数闭）是 $\mathbb{P}^1$（$K = -2P$，$\deg K < 0$，无全纯微分）。任何有理曲线（与 $\mathbb{P}^1$ 同构）= "有参数化"的曲线。<span class="marginnote">"$g = 0$ ⟹ 有理"由 R-R 立即推出：$\deg K = -2$，取 $D = -K$，$\ell(D) \ge \deg D + 1$，得到"非常数有理函数" $C \to \mathbb{P}^1$，由"次数 1 的射影态射 = 同构"完成。</span>

**亏格 1：椭圆曲线**。$K \sim 0$、$\ell(D) = \deg D$（$D > 0$）、$\ell(P) = 1$ 等全部由 R-R 得到。这些曲线有**群结构**（见下节）。

**亏格 ≥ 2**：$\deg K > 0$，典范映射 $\varphi_K$ 起决定作用（第 12 篇）。$g = 2$：超椭圆，$K$ 给 $\mathbb{P}^1$ 上的 2:1 覆盖，6 个分支点（R-H）。

## 4 椭圆曲线：群结构与 $j$-不变量

**核心概念：椭圆曲线（elliptic curve）**：亏格 1 的完备光滑曲线带上一个基点 $O$ 的配对 $(E, O)$。椭圆曲线都有**群结构**：任取两点 $P, Q$，由 R-R（$\ell(P+Q) = 2$，即存在"通过 $P, Q$ 且有指定极点"的线性系）保证存在唯一有理函数连接结构，使"弦-切"法则（三次曲线情形）或一般除子理论定义出 $E$ 上的 Abel 群。<span class="marginnote">群结构的本质：$E$ 的每个次数 0 除子类"恰好"对应一个点（R-R：$\ell(D) = 0$ 当 $\deg D = 0$ 非主，$\ell(D) = 1$ 当 $D$ 主），于是 $\operatorname{Cl}^0(E) \cong E$——"曲线自己就是自己的 Jacobian"。</span>

**重点：椭圆曲线都可写成 Weierstrass 形式。** 用 Riemann-Roch 精确计算 $\ell(nO)$ 可得 $\ell(2O) = 2$、$\ell(3O) = 3$，从而存在 $x, y$ 满足

$$y^2 = x^3 + ax + b, \qquad \Delta = 4a^3 + 27b^2 \neq 0$$

（$\Delta$ 非零 = 光滑）。<span class="marginnote">R-R 的计数直接给出 $x$（极点 $2O$）与 $y$（极点 $3O$）的存在与唯一性（比例意义下），并迫出 Weierstrass 方程的形状。椭圆曲线论的大部分算术都写在 $a, b$ 里。</span>

**核心概念：$j$-不变量。** 对椭圆曲线 $y^2 = x^3 + ax + b$，定义

$$j = 1728 \cdot \frac{4a^3}{4a^3 + 27b^2}$$

**重点：$k$ 代数闭时，两条椭圆曲线同构 ⟺ $j$ 相等。** 于是椭圆曲线（带基点，$\operatorname{char} \neq 2, 3$）由 $j \in k$ 完全分类。<span class="marginnote">$j$-不变量是"模空间"的第一个非平凡例子：<strong>椭圆曲线的同构类 = $j$-线的点</strong>。$j \mapsto \mathbb{A}^1$ 的对应给现代模空间理论定下基调——"几何对象族 ↔ 参数空间"，与第 16 篇 GAGA 里"对象族随参数变化"的解析视角接上。</span>

**辨析｜易错点：** 椭圆曲线是**代数**曲线，不是"椭圆函数"图像。命名来自"椭圆积分"：$\int \frac{dx}{\sqrt{x^3 + ax + b}}$ 的周期给出格 $\Lambda \subseteq \mathbb{C}$，椭圆曲线 = $\mathbb{C}/\Lambda$（复情形），而 $\mathbb{C}/\Lambda$ 的群结构是"加法模格"。**"群"是外加于曲线自身的，来自除子理论，不是从图像"画"出来的**——初学者常把椭圆曲线的"群"与"方程的图像"混淆。

## 5 公式解析：Riemann-Hurwitz

$$
2g - 2 = n(2g' - 2) + \deg R
$$

分三步拆解：

- **第一步，$2g - 2$ 是欧拉亏损**：对曲线，$2g - 2 = \deg K_C$（第 9 篇）。它是"曲线弯曲程度"的代数测度，等价于拓扑的欧拉示性数 $\chi(C) = 2 - 2g$。<span class="marginnote">为什么用 $2g-2$ 不用 $g$？因为它是<strong>可加的</strong>（沿覆盖相加），而 $g$ 本身不可加。R-H 是"加性量"的守恒律——正如能量守恒要求用"总能"而非"温度"。</span>
- **第二步，$n(2g' - 2)$ 是"叠起来的弯曲"**：拉回 $f^*K_{C'}$ 的次数 = 层数 × 基底次数。若 $f$ 无分支（$\deg R = 0$），则"曲率叠 $n$ 层"是全部：$C$ 的弯曲 = $n$ 倍的 $C'$ 弯曲。
- **第三步，$\deg R$ 是"分支折痕"**：分歧除子 $R = \sum (e_P - 1) P$ 记下每处"重叠多出的层"；$e_P - 1$ 是"超出正常一层的量"。总折痕 $\deg R$ 参与守恒：$C$ 的弯曲 = 叠层弯曲 + 折痕。

一句话直觉：**亏格差守恒 = 层数×基底弯曲 + 分支折痕**——覆盖把"弯曲"复制 $n$ 份，分支点再额外贡献"折痕"。

## 6 小结

- **有限态射 / 次数**：$n = [K(C) : K(C')]$ = 一般纤维大小；**分歧指数** $e_P$、**支点**与**分支点**。
- **Riemann-Hurwitz**：$2g - 2 = n(2g' - 2) + \deg R$，来自 $K_C = f^*K_{C'} + R$ 取次数。
- **应用**：超椭圆曲线 $\deg R = 2g + 2$（$y^2 = p(x)$，$\deg p = 2g+2$）；$g=0$ 单连通（$\deg R = 0$）。
- **亏格分类**：$g=0$ 唯一是 $\mathbb{P}^1$；$g=1$ 是椭圆曲线（$K \sim 0$）；$g \ge 2$ 由典范映射控制。
- **椭圆曲线**：群结构、Weierstrass 方程 $y^2 = x^3 + ax + b$、$j$-不变量分类（$E_1 \cong E_2 \iff j_1 = j_2$）。
