## 为什么从复数与三角法开始

复数常被误当成「解方程的副产品」，但在竞赛数学里，它是一台**旋转与放缩的几何机器**。<span class="marginnote">复数 $z = re^{i\theta}$ 同时携带「长度 $r$」与「转角 $\theta$」两种信息；复数相乘 = 长度相乘、角度相加。正是这「角度相加」，让复数成为处理三角恒等式的最强武器。</span>

**三角法**指用三角恒等式、棣莫弗定理、单位根来解代数与几何问题的方法。它把「求和」「求积」「证恒等」三类难题统一到复数乘法之下：三角函数的多倍角公式来自复数幂，$\sum \cos kx$ 型求和来自等比数列求和公式，正多边形的顶点坐标来自单位根。复数与三角法的结合，是竞赛代数「降维打击」的典范——很多在实数世界里绕弯的题，搬到复平面就是一行乘法。

## 1 复数的几何表示

**复数（complex number）**：形如 $z = x + yi$（$x,y\in\mathbb{R}$，$i^2=-1$）的数。它对应复平面上的点 $(x,y)$，也对应从原点到该点的向量。<span class="marginnote">复平面也叫阿甘图（Argand diagram）。把数看成「平面上的点」，是复数几何化的第一步：加减复数 = 向量加减，乘以 $i$ = 逆时针转 $90°$。</span>

三个基本量：

**模**：$|z| = \sqrt{x^2 + y^2}$，即向量的长度。
**辐角**：$\arg z = \theta$，即向量与正实轴的夹角（约定取 $(-\pi,\pi]$ 的主值）。
**共轭**：$\bar z = x - yi$，关于实轴对称；$z\bar z = |z|^2$。

复数与复数的乘法有几何解读：

$$z_1 z_2 = r_1 r_2 e^{i(\theta_1+\theta_2)}, \qquad |z_1z_2| = |z_1||z_2|, \quad \arg(z_1z_2) = \arg z_1 + \arg z_2$$

**重点：复数的模是「乘法保长度的精确语言」**——$|zw| = |z||w|$、$|\frac{z}{w}| = \frac{|z|}{|w|}$。这使复数成为「证明长度乘积关系」的利器，后面第2篇几何里会用它在圆幂定理、托勒密定理的证明中大显身手。

## 2 棣莫弗定理与单位根

**棣莫弗定理（De Moivre's formula）**：

$$(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta), \qquad n \in \mathbb{Z}$$

它直接来自「角度相加」：连乘 $n$ 个模为 $1$ 的复数，模仍为 $1$，辐角相加 $n$ 次。棣莫弗定理把「$n$ 倍角公式」从记忆负担变成乘法的直接推论：$\cos 2\theta + i\sin 2\theta = (\cos\theta + i\sin\theta)^2$，展开右端比较实部虚部，立即得到 $\cos 2\theta = \cos^2\theta - \sin^2\theta$。

**单位根（root of unity）**：方程 $z^n = 1$ 的 $n$ 个复数解，记作

$$\omega_k = \cos\frac{2\pi k}{n} + i\sin\frac{2\pi k}{n}, \qquad k = 0,1,\dots,n-1$$

它们均匀分布在单位圆上，构成正 $n$ 边形的顶点。<span class="marginnote">设 $\omega = e^{2\pi i/n}$，则 $\omega^0, \omega^1, \dots, \omega^{n-1}$ 就是全部 $n$ 次单位根。它们满足两条黄金性质：和为零 $\sum_{k=0}^{n-1}\omega^k = 0$（$n>1$），且关于乘法构成循环群——后者到第二级《抽象代数》会被抽象成「循环群」概念。</span>

单位根的两条黄金性质：

$$\sum_{k=0}^{n-1} \omega^k = 0, \qquad \prod_{k=0}^{n-1} (x - \omega^k) = x^n - 1$$

第一条来自等比数列求和公式：$\sum_{k=0}^{n-1}\omega^k = \frac{1-\omega^n}{1-\omega} = 0$。它把「$n$ 个对称分布的点」的和瞬间算成零，是许多求和问题的终点。

## 3 三角法：用复数统一三角恒等式

**三角法（trigonometric method）**在竞赛里的核心形态，是用**欧拉公式**把三角函数翻译成复数指数：

$$e^{ix} = \cos x + i\sin x, \qquad \cos x = \frac{e^{ix}+e^{-ix}}{2}, \qquad \sin x = \frac{e^{ix}-e^{-ix}}{2i}$$

这一翻译的威力在于：三角函数的**乘积**变成复指数的**求和**，而「积化和差」公式 $2\cos A\cos B = \cos(A+B) + \cos(A-B)$ 只是复数指数乘法与加法的家常便饭。看一个经典求和：

$$S_n = \sum_{k=1}^{n} \cos(kx)$$

把每一项看成 $e^{ikx}$ 的实部，于是 $S_n = \mathrm{Re}\left(\sum_{k=1}^{n} e^{ikx}\right)$。括号内是首项 $e^{ix}$、公比 $e^{ix}$ 的等比数列，用求和公式：

$$\sum_{k=1}^{n} e^{ikx} = e^{ix}\cdot\frac{1-e^{inx}}{1-e^{ix}}$$

再取实部，就得到 $\frac{\sin(nx/2)\cos((n+1)x/2)}{\sin(x/2)}$ 这类闭式。**「求和 → 等比数列 → 取实部」是三角求和的万能流水线。**<span class="marginnote">注意分母出现 $\sin(x/2)$，说明 $x$ 为 $2\pi$ 的整数倍时公式要单独处理——这类「分母为零」的边界情形是竞赛阅卷的扣分点。</span>

**辨析｜易错点：** 取实部/虚部时，$\mathrm{Re}(z_1 z_2)$ 并不等于 $\mathrm{Re}(z_1)\mathrm{Re}(z_2)$。所以「先求和再取实部」的顺序不能颠倒——必须先算完整个复数的和，最后才取实部，中途每一步都保留虚部信息。

## 4 公式解析：欧拉公式为何成立

欧拉公式 $e^{ix} = \cos x + i\sin x$ 是复数三角法的基石，用级数展开拆解它：

- **第一步，回忆指数级数**：$e^{u} = 1 + u + \frac{u^2}{2!} + \frac{u^3}{3!} + \cdots$ 对一切复数 $u$ 收敛。
- **第二步，代入 $u = ix$**：$e^{ix} = 1 + ix + \frac{(ix)^2}{2!} + \frac{(ix)^3}{3!} + \cdots = 1 + ix - \frac{x^2}{2!} - i\frac{x^3}{3!} + \frac{x^4}{4!} + \cdots$，其中 $i^2=-1,\ i^3=-i,\ i^4=1$ 不断循环。
- **第三步，按实部虚部分组**：实部 $1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots = \cos x$；虚部 $x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots = \sin x$。
- **第四步，合成**：$e^{ix} = \cos x + i\sin x$。特别地 $x=\pi$ 时得 $e^{i\pi} + 1 = 0$——把 $e$、$i$、$\pi$、$1$、$0$ 五个常数装进一个等式。

**重点：欧拉公式是把「旋转」与「指数增长」统一起来的桥。** 模长不再是 $e$ 的实部决定，而是 $|e^{ix}| = \sqrt{\cos^2x+\sin^2x} = 1$——纯虚指数对应单位圆上的匀速旋转。

## 5 竞赛视角：复数降维几何与代数

复数在竞赛里最大的价值是**降维**。看两个经典运用：

**例 1（几何）**：正 $n$ 边形顶点 $A_1,\dots,A_n$ 在单位圆上，证明 $\sum_{k=1}^{n} |A_k A_1|^2 = n \cdot 2$。

把顶点写成单位根 $\omega^k$，则 $|A_kA_1|^2 = |\omega^k - 1|^2 = (\omega^k-1)(\omega^{-k}-1) = 2 - \omega^k - \omega^{-k}$。求和：

$$\sum_{k=1}^{n}|A_kA_1|^2 = \sum_{k=1}^{n}(2 - \omega^k - \omega^{-k}) = 2n - 0 - 0 = 2n$$

中间两个和都为零，靠的正是单位根「和为零」的黄金性质。**一段代数证明，取代了一整页几何推理。**<span class="marginnote">单位根「和为零」在几何里的直觉是：正多边形各顶点关于中心对称，向量和必为零。复数把这条几何直觉变成了自动运行的代数规则。</span>

**例 2（代数）**：证明 $\sin\frac{\pi}{7}\sin\frac{2\pi}{7}\sin\frac{3\pi}{7} = \frac{\sqrt7}{8}$。

这类「正弦连乘积」题是复数三角法的招牌：考虑 $z^7=1$ 的除 $1$ 外的六个根，用因式分解 $x^7-1 = (x-1)(x^6+x^5+\cdots+1)$，把乘积表达式与 $\prod (1-\omega^k)$ 挂钩，再对模长开方，最后用到 $7$ 次单位根的对称结构。**关键手法：连乘积 ← 因式分解 ← 单位根。** 这一类「$n$ 次单位根打包三角函数连乘积」的题，几乎都有固定的拆解剧本。

### 补充：复数几何的进阶应用

**例 1（复数与等边三角形）**：$z_1,z_2,z_3$ 是复数，$\triangle z_1z_2z_3$ 是等边三角形当且仅当 $z_1 + \omega z_2 + \omega^2 z_3 = 0$（$\omega = e^{2\pi i/3}$ 是三次单位根）。

理由：等边三角形意味着 $z_2 - z_1$ 是 $z_3 - z_1$ 旋转 $±60°$ 的结果，即 $z_2 - z_1 = \omega(z_3 - z_1)$ 或 $\omega^2(z_3-z_1)$，整理即得。**单位根把「几何旋转」变成「代数乘 $\omega$」，等边三角形的判定变成了一个线性关系。**

**例 2（复数证垂直）**：$AB \perp CD$ 当且仅当 $\frac{b-a}{d-c}$ 是纯虚数（即其实部为零）。

理由：两个向量的夹角等于它们复数商的辐角；垂直即辐角为 $±90°$，即商为纯虚数。**「垂直 ⇔ 商纯虚」「平行 ⇔ 商实数」是复数几何的翻译表**，让垂直平行问题变成实部虚部计算。

**例 3（单位根求和）**：证明 $\sum_{k=0}^{n-1}\cos\frac{2\pi k}{n} = 0$（$n>1$）。

$\sum_{k=0}^{n-1}\omega^k = 0$（单位根和为零），取实部即得余弦和为零。<span class="marginnote">这个结论在几何里对应「正 $n$ 边形的顶点关于中心对称，向量和为零」；在信号处理里对应「等间隔采样的直流分量」。单位根的和为零，是「对称性」最浓缩的代数表达。</span>

**心法：复数几何题的翻译表**——模长=距离、辐角=转角、共轭=关于实轴对称、商纯虚=垂直、商实数=平行、单位根=正多边形顶点。把几何条件逐条翻译成复数语言，剩下的就是复数代数。

## 6 小结

- 复数 = **模**（长度）+ **辐角**（转角）；乘法对应旋转与放缩。
- **棣莫弗定理**：$(\cos\theta+i\sin\theta)^n = \cos n\theta + i\sin n\theta$，多倍角公式由此而来。
- **单位根**：$z^n=1$ 的 $n$ 个解均匀分布单位圆；黄金性质**和为零**、**积为 $x^n-1$**。
- **欧拉公式** $e^{ix}=\cos x+i\sin x$ 让三角求和在复数世界变成等比数列求和。
- 易错点：**先求和再取实部**；分母含 $\sin(x/2)$
