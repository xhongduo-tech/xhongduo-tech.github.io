## 为什么从恒等变形开始

竞赛数学的第一课，往往不是某个惊艳的定理，而是一项不起眼却贯穿始终的手艺：**恒等变形**。<span class="marginnote">「恒等」指对一切允许的取值都成立，区别于只在特定条件下成立的等式。变形不改本质，只换姿势。</span>

一个式子从一个形态变成另一个等价形态，看起来只是「换个写法」，但换得巧，难题就变成易题；换得拙，简单题也能绕进死胡同。代数、几何、数论、组合四大板块的解法，最后几乎都要落到「算得动」上，而算得动的起点就是变形。学完高中课程的读者已经认得一堆公式，本课把它们的来龙去脉、使用场景与易错点系统化，为整门竞赛课程铺路——它也直接接续第一级《基础数学》里的整式运算，并将在第二级《抽象代数》中被提升为「多项式环」的语言。

## 1 恒等变形的武器库

**恒等变形（identity manipulation）**：在不改变式子取值的前提下改写式子。竞赛里最常用的变形武器是乘法公式——它们本质上是多项式乘法的结果被反着用。

$$(a \pm b)^2 = a^2 \pm 2ab + b^2, \qquad a^2 - b^2 = (a+b)(a-b)$$

$$a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2), \qquad (a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3$$

这些公式初中就会背，竞赛的差别在于**使用频率与组合方式**。平方差公式不只是「两个平方相减」，它更是「创造平方差」的工具：

| 场景 | 目标形状 | 经典手法 |
| --- | --- | --- |
| 四项式 $a^4 + a^2 + 1$ | 拆成两个二次因式 | 添 $a^2$ 凑完全平方再减，套平方差 |
| 二项式 $a^4 + 4$ | 拆成两个整系数二次因式 | 配方 $(a^2+2)^2 - (2a)^2$ 后平方差 |
| 循环式 $x^2y + y^2z + z^2x$ 之差 | 提取差因式 | 判断是否为 $(x-y)(y-z)(z-x)$ 的倍数 |
| 分式 $\frac{a}{b} + \frac{b}{a}$ | 制造 $\frac{a}{b} + \frac{b}{a} \ge 2$ 的结构 | 通分后配方成平方和 |

<span class="marginnote">把 $a^4 + 4$ 配成 $(a^2+2)^2 - (2a)^2$，再套平方差得 $(a^2-2a+2)(a^2+2a+2)$——这是竞赛经典技巧「配方 + 平方差」，在复数范围内它对应四次单位根的分裂，到第二级《复数》还要再见。</span>

**重点：恒等变形的目标只有一个——让目标结构显形。** 见到分子分母都含根号的式子，目标是约掉根号；见到高次多项式，目标是拆成低次因式之积；见到分式，目标是通分约分留下最简形态。先问「我想要什么形状」，再选武器。

## 2 因式分解的常用手法

**因式分解（factorization）**：把一个多项式写成若干个不可再分的整式之积。它是恒等变形的「逆向题」，也是竞赛代数里出现频率最高的操作之一。常用手法有五种：

**提公因式**：$ax + ay = a(x+y)$，最朴素也最容易被忽略——先看各项有没有公共因子，永远值得先试。<span class="marginnote">分组分解可以看作「连续提公因式」：先按某种方式分组，组内提，组间再提。分组方式的选取往往取决于「配方」或「凑完全平方式」的线索。</span>

**公式法**：套用武器库里的乘法公式。看见三项想到完全平方，看见两项想到平方差或立方和差。

**十字相乘法**：$x^2 + (p+q)x + pq = (x+p)(x+q)$，处理二次三项式。竞赛里更常见的是**双十字相乘**，处理二元二次式 $ax^2 + bxy + cy^2 + dx + ey + f$。

**拆项与添项**：把一项拆成两项，或补上又减掉一项，以制造公式。例如分解 $x^4 + x^2 + 1$：

$$x^4 + x^2 + 1 = x^4 + 2x^2 + 1 - x^2 = (x^2+1)^2 - x^2 = (x^2+x+1)(x^2-x+1)$$

<span class="marginnote">$x^4 + x^2 + 1 = (x^2+x+1)(x^2-x+1)$ 这个结果在竞赛里反复出现，它与「三阶循环行列式」「三次单位根」都有联系，值得当结论记下。</span>

**换元法**：把长得复杂的整体换成一个新字母，化简后再代回。例如分解 $(x^2+x)^2 - 8(x^2+x) + 12$，令 $t = x^2+x$，问题变成分解 $t^2 - 8t + 12 = (t-2)(t-6)$，再代回。

**辨析｜易错点：** 因式分解要求「分解到底」，但「到底」取决于系数允许的范围。实数范围内 $x^2 - 2$ 可分解为 $(x+\sqrt{2})(x-\sqrt{2})$；若题目约定在有理数范围内，它就是不可分的既约式。**分解范围没说清，是竞赛答题的大忌。** 同理，$x^4 + 4$ 在实数范围内分解出的两个因式系数已经全是整数，就不要再往下分了。

## 3 对称式与换元思想

竞赛代数里有一族特别重要又特别「优雅」的式子——**对称式**。交换其中任意两个变量后式子不变，例如 $a^2 + b^2 + c^2$、$ab + bc + ca$、$(a-b)^2 + (b-c)^2 + (c-a)^2$。

对称式之所以可爱，是因为**它们的值往往只依赖于少数几个「基本对称式」**。三个变量的基本对称式是：

$$p = a + b + c, \qquad q = ab + bc + ca, \qquad r = abc$$

**任何一个关于 $a,b,c$ 的多项式对称式，都可以用 $p,q,r$ 表示**——这是对称多项式基本定理的三元版本，也是竞赛「换元」的深层根据。两个立刻可用的例子：

$$a^2 + b^2 + c^2 = p^2 - 2q, \qquad a^3 + b^3 + c^3 = p^3 - 3pq + 3r$$

<span class="marginnote">「用 $p,q,r$ 表示一切对称式」的思想，在竞赛里叫「对称化」，到高等代数就是「对称多项式基本定理」，在第二级《抽象代数》与《交换代数》里会以更一般的形式重逢。</span>

**换元（substitution）**：把对称式整体换元后，原本纠缠不清的多元关系变成一元或二元关系。例如已知 $a+b+c=3$、$ab+bc+ca=2$、$abc=1$，求 $a^2+b^2+c^2$——硬代三个未知数会卡住，用 $p=3,q=2$ 套 $p^2-2q = 9-4=5$ 一步出结果。换元还有另一重身份：**降次数**。遇到 $(x^2+x+1)(x^2-x+1)$ 这类乘积，设 $u=x^2$、$v=1$，乘积变成 $(u+v)^2 - u$，也即换元后套公式。

## 4 公式解析：$a^3+b^3+c^3-3abc$ 的分解

这条恒等式是竞赛代数的「镇店之宝」，值得逐项拆解：

$$a^3+b^3+c^3-3abc = (a+b+c)(a^2+b^2+c^2-ab-bc-ca)$$

- **第一步，看左边**：$a^3+b^3+c^3-3abc$ 是对称式。当 $a+b+c=0$ 时左边等于零，这强烈暗示 $a+b+c$ 是它的一个因式——「代数基本定理视角」：把左边看成以 $a$ 为变元的式子，$a=-(b+c)$ 是它的根。
- **第二步，看右边结构**：右边是两因式之积，第一因式正是 $a+b+c$；第二因式是二次齐次式 $a^2+b^2+c^2-ab-bc-ca$，它还有一个漂亮身份——$\frac{1}{2}\big[(a-b)^2+(b-c)^2+(c-a)^2\big]$，恒非负，且仅当 $a=b=c$ 时为零。
- **第三步，验证**：把右边展开，$a^3$ 来自第一因式乘 $a^2$，$-3abc$ 来自 $-ab \cdot c$、$-bc \cdot a$、$-ca \cdot b$ 三组交叉项，其余 $12$ 项两两抵消，恰好回到左边。
- **第四步，记推论**：当 $a+b+c=0$ 时立即有 $a^3+b^3+c^3 = 3abc$——这是频率极高的竞赛结论。例如「三数成等差数列且其和为 $0$」「三圆半径满足……」「三角恒等式 $\sin A + \sin B + \sin C$」类问题常靠它一步化简。

**重点：看到三次方和与乘积的混合结构，优先想到这条公式。** 它把三次结构降成二次结构，往往紧接着配合平方差或配方法继续化简，最终把「对称」这个约束翻译成「两两相等」或「和为 $0$」。

## 5 竞赛视角：从变形到巧解

恒等变形的功力，最终体现在「敢不敢拆、往哪拆」的判断上。看一个经典例子：

**例**：实数 $x,y,z$ 满足 $x^2y + y^2z + z^2x = xy^2 + yz^2 + zx^2$，证明 $x,y,z$ 中至少有两个相等。

把两边移到一侧并分解：

$$x^2y + y^2z + z^2x - xy^2 - yz^2 - zx^2 = -(x-y)(y-z)(z-x)$$

这是竞赛中著名的「循环差」恒等式：**循环和的差总能分解成三个差因式的乘积**。于是题设等价于 $(x-y)(y-z)(z-x)=0$，即 $x,y,z$ 中至少有两个相等。<span class="marginnote">「循环式之差分解成差因式之积」的结论，在不等式、数列、代数式求值里反复出场。见到循环排列的对称式，先想它是不是 $(x-y)(y-z)(z-x)$ 的倍数——用「变量相等时代数式为零」来检验最高效。</span>

再看一个「拆」出路的例子。求 $\frac{1}{x^2+3x+2} + \frac{1}{x^2+5x+6}$ 在 $x=-1.5$ 处的值。分母恰可分解为 $(x+1)(x+2)$ 与 $(x+2)(x+3)$，于是：

$$\frac{1}{(x+1)(x+2)} = \frac{1}{x+1} - \frac{1}{x+2}, \qquad \frac{1}{(x+2)(x+3)} = \frac{1}{x+2} - \frac{1}{x+3}$$

两项相加，中间项 $\frac{1}{x+2}$ 抵消，只剩 $\frac{1}{x+1} - \frac{1}{x+3}$，代入 $x=-1.5$ 得 $2 - (-2) = 4$。这种**裂项**手法是「拆项」在分式世界的投影，也是后续数列求和里裂项相消的源头。

**总结一条心法：变形前先问目标形状，变形中时刻检查等价性（不能增根也不能丢根），变形后回头看是否真的变简单了。**

## 6 小结

- **恒等变形**是不改变取值地改写式子；武器库以乘法公式为核心，搭配「配方 + 平方差」的创造手法。
- 因式分解五大手法：**提公因式、公式法、十字相乘、拆项添项、换元**。
- 对称式可以用基本对称式 $p,q,r$ 整体表示，**换元**因此成为竞赛利器。
- 高频结论要背熟：$x^4+x^2+1$、$a^4+4$、$a^3+b^3+c^3-3abc$、循环差 $(x-y)(y-z)(z-x)$
