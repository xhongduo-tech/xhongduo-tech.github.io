## 为什么从数列与递推开始

数列是「离散世界的函数」：把定义域从连续区间换成自然数，微积分的语言全部失效，取而代之的是**递推**。<span class="marginnote">递推（recurrence）是「后一项由前若干项决定」的规则。它把连续世界里的微分方程翻译成了离散世界的差分方程——数列，正是竞赛数学里衔接「代数」与「组合」的枢纽。</span>

递推数列之所以在竞赛里地位极高，是因为它同时连接三条线：**代数**（求解递推要解方程、用特征根）、**组合**（许多计数问题的答案天然是递推数列，如斐波那契）、**分析**（数列极限与不等式估计）。它也是后面第4篇《排列组合与计数原理》的直接预备——数一数「走台阶的方法数」，答案就是斐波那契。学好递推，等于同时给代数与组合两座堡垒装上了梯子。

## 1 数列的基本盘

**数列（sequence）**：把正整数按顺序映射到实数，记作 $\{a_n\}$。竞赛里先要熟练的基本盘有三个概念：

**有界性**：存在 $M$ 使 $|a_n| \le M$ 对所有 $n$ 成立。有界 + 单调 ⇒ 收敛——这是数列分析的发动机，也是后面第3篇数论、组合里「估计」的依据。

**单调性**：$a_{n+1} \ge a_n$（递增）或 $\le$（递减）。证明单调性常用**作差或作商**：比较 $a_{n+1}-a_n$ 的符号，或 $\frac{a_{n+1}}{a_n}$ 与 $1$ 的大小。

**周期性**：存在正整数 $T$ 使 $a_{n+T}=a_n$ 恒成立。<span class="marginnote">周期数列在竞赛里是「送分题」也是「陷阱题」：先算前几项找周期，再对 $n$ 取模。常见陷阱是周期未从第一项开始（从第 $k$ 项后才循环），这时要写清「从第几项起」。</span>

三种基本盘之外，最常考的是**裂项求和**：$\frac{1}{n(n+1)} = \frac1n - \frac{1}{n+1}$，$\frac{1}{\sqrt{n+1}+\sqrt{n}} = \sqrt{n+1}-\sqrt n$。裂项的精髓在第一节《恒等变形》已经种下——把一项拆成两项的差，求和时中间项全部抵消，只剩首尾。

## 2 一阶递推

**一阶递推**是「后一项只由前一项决定」的规则，最典型的是**线性型**：

$$a_{n+1} = p a_n + q$$

当 $p \ne 1$ 时，标准的解法是**配常数**：找一个数 $c$ 使 $a_{n+1} - c = p(a_n - c)$。代入得 $c - pc = q$，即 $c = \frac{q}{1-p}$。于是 $\{a_n - c\}$ 是公比为 $p$ 的等比数列，立刻写出通项：

$$a_n = c + (a_1 - c)p^{\,n-1}$$

**重点：配常数的本质是找不动点。** 解方程 $x = px + q$ 得 $x = \frac{q}{1-p}$，这个 $x$ 就是不动点——迭代的固定点。让递推「绕着不动点转」，就把它变成了干净的等比形式。这与上一节《函数方程与迭代》里的不动点思想完全同源。

另一个经典的一阶递推是**分式线性型**：

$$a_{n+1} = \frac{\alpha a_n + \beta}{\gamma a_n + \delta}$$

它的解法是**求不动点**：解 $x = \frac{\alpha x + \beta}{\gamma x + \delta}$，得到一或两个不动点，然后作变换 $b_n = \frac{a_n - x_1}{a_n - x_2}$，可以验证 $b_n$ 是等比数列——因为分式线性变换的复合对应矩阵乘法（上一节的机制），而不动点对应特征向量。

**辨析｜易错点：** 配常数前必须检查 $p=1$ 的情形。$p=1$ 时递推变成 $a_{n+1} = a_n + q$，这是等差数列，通项 $a_n = a_1 + (n-1)q$；若硬套配常数，分母 $1-p$ 会为零。**分类讨论，是所有带「参数 $p$」的递推题的必修课。**

## 3 二阶线性递推

**二阶线性递推**是竞赛的主力题型：

$$a_{n+2} = p a_{n+1} + q a_n, \qquad q \ne 0$$

它对应的**特征方程**是 $x^2 = px + q$，即 $x^2 - px - q = 0$。<span class="marginnote">为什么叫「特征方程」？把「猜测 $a_n = x^n$」代入递推，得到 $x^{n+2} = p x^{n+1} + q x^n$，约去 $x^n$ 就是 $x^2 = px+q$。这个「代入指数形式的候选解」的思路，是求解一切线性递推的总纲。</span>

设特征方程两根为 $\lambda_1, \lambda_2$：

- **两相异实/复根**：通项 $a_n = A\lambda_1^{n} + B\lambda_2^{n}$，常数 $A,B$ 由前两项 $a_1,a_2$ 定出。
- **重根 $\lambda$**：通项 $a_n = (A + Bn)\lambda^{n}$——因为重根情形需要「乘以 $n$」才能得到第二个线性无关的解。
- **共轭复根**：用三角形式表达，通项会是「模长 $\times$ 三角函数的组合」，周期性由此显现。

最著名的二阶线性递推是**斐波那契**：$F_{n+2} = F_{n+1} + F_n$，$F_1 = F_2 = 1$。特征方程 $x^2 = x + 1$，两根 $\varphi = \frac{1+\sqrt5}{2}$ 与 $\psi = \frac{1-\sqrt5}{2}$，于是有**比内公式**：

$$F_n = \frac{1}{\sqrt5}\left[\left(\frac{1+\sqrt5}{2}\right)^{n} - \left(\frac{1-\sqrt5}{2}\right)^{n}\right]$$

## 4 公式解析：比内公式的三步拆解

比内公式是「用代数公式表达离散递归」的典范，逐项拆：

- **第一步，写特征方程**：$x^2 - x - 1 = 0$，解得 $\varphi = \frac{1+\sqrt5}{2}$（黄金比）、$\psi = \frac{1-\sqrt5}{2}$。注意 $\varphi + \psi = 1$、$\varphi\psi = -1$。
- **第二步，设通项**：$F_n = A\varphi^n + B\psi^n$。这是「两根相异」情形的标准形式。
- **第三步，定常数**：代入 $F_1=1$、$F_2=1$，解二元一次方程组得 $A = \frac{1}{\sqrt5}$、$B = -\frac{1}{\sqrt5}$。
- **第四步，验证合理性**：$\psi = \frac{1-\sqrt5}{2} \approx -0.618$，其绝对值小于 $1$，故 $n$ 大时 $\psi^n \to 0$，$F_n \approx \frac{\varphi^n}{\sqrt5}$——这解释了对数增长 $F_n \sim \frac{\varphi^n}{\sqrt5}$，也解释了相邻两项之比趋于黄金比。

**辨析｜易错点：** 二阶递推的通项公式依赖**前两项确定常数**。若题目只给 $a_1$ 和一个「$a_0$ 或 $a_2$」形式的初始值，务必先弄清下标约定（斐波那契有 $F_0=0,F_1=1$ 与 $F_1=F_2=1$ 两种惯例），否则 $A,B$ 会算错。**读题先看初始条件的下标从几开始。**

## 5 竞赛视角：从递推到不等式

递推数列的竞赛题往往把「求通项」与「证不等式」结合。看一个典型套路：

**例**：设 $a_1 = 2$，$a_{n+1} = \frac12\left(a_n + \frac{2}{a_n}\right)$（$n \ge 1$），证明 $a_n > \sqrt2$ 且 $\{a_n\}$ 收敛。

这个递推是**牛顿法求 $\sqrt2$**的离散版本：$a_{n+1}$ 是「过 $(a_n, \frac{2}{a_n})$ 的切线与 $x$ 轴交点」。证明分两步：

**第一步，证下有界**：由均值不等式，$a_{n+1} = \frac12\left(a_n + \frac{2}{a_n}\right) \ge \sqrt{a_n \cdot \frac{2}{a_n}} = \sqrt2$。注意这里**无法推出单调递减**，因为 $a_{n+1} \ge \sqrt2$ 只给了下界。
**第二步，证单调**：$a_{n+1} - a_n = \frac12\left(\frac{2}{a_n} - a_n\right) = \frac{2 - a_n^2}{2a_n}$。由第一步知 $a_n \ge \sqrt2$（对 $n\ge2$），故差非正，单调递减。
**第三步，收敛**：单调递减且有下界 $\sqrt2$ ⇒ 收敛，设极限为 $L$，两边取极限得 $L = \frac12(L + \frac{2}{L})$，解得 $L = \sqrt2$。<span class="marginnote">「递推两边取极限」是求极限值的关键手法：先证收敛，再设极限 $L$ 代回递推。若递推函数 $g$ 连续，$L$ 必满足 $L = g(L)$，即 $L$ 是 $g$ 的不动点——又一次回到不动点思想。</span>

**竞赛心法：递推题的万能四问**——① 能求出通项吗（特征方程 / 配常数 / 不动点）？② 求不出通项，能证单调有界吗？③ 能估计出上下界参与放缩吗？④ 涉及模运算时，能找周期吗？按顺序问，绝大多数递推题都能找到入口。

### 补充：递推与求和的常见综合

**例 1（裂项 + 递推）**：求 $S_n = \sum_{k=1}^{n}\frac{1}{k(k+2)}$。

裂项 $\frac{1}{k(k+2)} = \frac12\left(\frac1k - \frac1{k+2}\right)$。求和：

$$S_n = \frac12\left[\left(1-\frac13\right) + \left(\frac12-\frac14\right) + \left(\frac13-\frac15\right) + \cdots + \left(\frac1n - \frac1{n+2}\right)\right]$$

中间项 $\frac13,\frac14,\dots,\frac1n$ 两两抵消，剩 $S_n = \frac12\left(1 + \frac12 - \frac1{n+1} - \frac1{n+2}\right)$。**「裂项但不相邻」时，留头和留尾各两项**——先写几项观察抵消模式，再写通式。

**例 2（递推转求和）**：设 $a_{n+1} - a_n = 3n+1$，$a_1=1$，求 $a_n$。

把 $n$ 个等式累加：$a_n - a_1 = \sum_{k=1}^{n-1}(3k+1) = 3\cdot\frac{(n-1)n}{2} + (n-1)$，故 $a_n = 1 + \frac{3n(n-1)}{2} + (n-1) = \frac{3n^2 - n}{2}$。**「一阶差为已知式」的递推，累加法（把差全加起来）是标准解。**

**例 3（分式线性递推实战）**：$a_{n+1} = \frac{2a_n+1}{a_n+2}$，$a_1=1$，求 $a_n$ 的通项。

求不动点：$x = \frac{2x+1}{x+2}$ 即 $x^2 = 1$，$x=\pm1$。作变换 $b_n = \frac{a_n - 1}{a_n + 1}$，代入计算得 $b_{n+1} = \frac13 b_n$（等比），$b_1 = 0$……$b_n \equiv 0$，说明 $a_n \equiv 1$？代入原递推 $a_2 = \frac{3}{3}=1$，确实恒等于 $1$。<span class="marginnote">这个例子说明「不动点法」的边界：当初始值落在不动点上时，数列恒为常数，变换会退化（$b_n$ 恒 $0$）。遇到退化，说明数列本来就是常数列，直接写出即可——<strong>不动点法要先检查「初始值是不是不动点」。</strong></span>

**心法：递推与求和是一家人**——「累加」就是一阶差的逆运算，「裂项」就是求和的凑项技巧；两者配合几乎覆盖竞赛数列求和的全部基础题型。

## 6 小结

- 数列基本盘：**有界性、单调性、周期性**；裂项求和是求和题的第一工具。
- 一阶线性递推 $a_{n+1}=pa_n+q$：**配常数找不动点**；$p=1$ 要单独分类。
- 二阶线性递推：**特征方程** $x^2-px-q=0$，两根相异 / 重根 / 共轭复根三种情形。
- **斐波那契**与其**比内公式**是二阶递推的招牌；$F_n \sim \frac{\varphi^n}{\sqrt5}$
