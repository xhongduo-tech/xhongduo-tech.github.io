# 竞赛数学（数学奥林匹克：初等数学深化与解题理论）

以系统化的初等数学深化为纲，围绕代数、几何、数论、组合四大板块与经典解题方法，构建从国内联赛到国际数学奥林匹克（IMO）的完整训练体系。学完这些章节，就掌握了竞赛数学的全部主干内容与核心思想方法。
