## 为什么从排列组合开始

组合数学是「数一数有多少种」的学问。它的基本工具——**加法原理与乘法原理**——简单得像是废话，却能层层叠加出最复杂的计数题。<span class="marginnote">计数（counting）的终极困难在于「不重不漏」：既不能多数，也不能漏数。竞赛计数的所有技巧，本质都是为「不重不漏」服务的策略。</span>

排列组合在竞赛四大板块里是「性价比之王」：不需要很深的知识储备，入门快，但陷阱极多、区分度高。它是后面《抽屉原理》《容斥原理与算两次》《组合恒等式与母函数》《图论与组合极值》的共同地基，也是概率论的计数基础——「古典概型 = 有利情况数 ÷ 总情况数」。这一节与第一级《概率》衔接，并为第二级《组合数学》的系统化铺路。

## 1 加法原理与乘法原理

**加法原理（addition principle）**：做一件事有 $k$ 类办法，第 $i$ 类有 $n_i$ 种方式，且各类互不重叠，则总方式数为 $n_1 + n_2 + \cdots + n_k$。

**乘法原理（multiplication principle）**：做一件事要分 $k$ 步，第 $i$ 步有 $m_i$ 种方式，则总方式数为 $m_1 m_2 \cdots m_k$。<span class="marginnote">口诀：「分类用加，分步用乘。」加法的关键是各类<strong>互斥</strong>（不能同时发生），乘法的关键是各步<strong>独立</strong>（前一步不影响后一步的可选数）。竞赛里「分类」与「分步」经常嵌套，写题时先分清层次。</span>

**重点：加法/乘法原理不只是「计数公式」，更是「拆解策略」。** 一道复杂的计数题，先想「按什么分类」再用加法，每一类内部「分几步」再用乘法。分层拆解的能力，直接决定计数的正确率。

例：从 $A$ 到 $C$ 有两条路线，$A\to C$ 直通 $3$ 种方式，$A\to B\to C$ 先 $2$ 种再到 $3$ 种，问从 $A$ 到 $C$ 共有几种方式？

**辨析｜易错点：** 这是「分类加、分步乘」的经典陷阱。$A\to C$ 的两类（直通 vs 经 $B$）是**互斥**的，用加法：$3 + 2\times3 = 9$。若把直通的 $3$ 与经 $B$ 的 $2\times3$ 用乘法相乘就大错特错——它们不是先后发生的两步，而是互相替代的两条路线。

## 2 排列

**排列（permutation）**：从 $n$ 个不同元素中取出 $k$ 个并按一定顺序排成一列，方式数为

$$P(n,k) = A_n^k = n(n-1)(n-2)\cdots(n-k+1) = \frac{n!}{(n-k)!}$$

**重点：排列的识别特征——「顺序有关」。** 同一组元素，顺序不同算不同的排法。$(1,2)$ 与 $(2,1)$ 是两个排列。

$k=n$ 时得到全排列 $P(n,n) = n!$——$n$ 个元素的全排列数。

**环排列**：$n$ 个元素排成一个圆圈，方式数为 $(n-1)!$——因为圆圈没有「起点」，先把圆「断开」成一排有 $n!$ 种，而每个圆排列被重复数了 $n$ 次（$n$ 个不同的断点）。

**辨析｜易错点：** 元素有无区别、是否允许重复、顺序是否重要，是排列题的三大变量。**允许重复**的 $k$ 位序列是 $n^k$（每一步 $n$ 种选择）；**不允许重复且顺序重要**是 $P(n,k)$；**不允许重复且顺序无关**是 $C(n,k)$（下一节）。先答这三问，再动笔。

## 3 组合

**组合（combination）**：从 $n$ 个不同元素中取出 $k$ 个（不计顺序），方式数为

$$C(n,k) = \binom{n}{k} = \frac{P(n,k)}{k!} = \frac{n!}{k!(n-k)!}$$

**重点：组合的识别特征——「顺序无关」。** $\{1,2\}$ 与 $\{2,1\}$ 是同一个组合。排列到组合的转化：先排列（顺序重要）再除以 $k!$（消除顺序）。

组合数的四条黄金性质（竞赛必背）：

**对称性**：$\binom{n}{k} = \binom{n}{n-k}$。
**吸收律**：$k\binom{n}{k} = n\binom{n-1}{k-1}$。
**帕斯卡公式**：$\binom{n}{k} = \binom{n-1}{k} + \binom{n-1}{k-1}$。
**二项式定理**：$(1+x)^n = \sum_{k=0}^{n}\binom{n}{k}x^k$。<span class="marginnote">帕斯卡公式是「杨辉三角」的代数形式：每个数是它肩上两个数之和。二项式定理则把组合数与多项式展开焊接——它将在《组合恒等式与母函数》一节大显身手。</span>

## 4 公式解析：$\binom{n}{k}$ 的三种理解

$$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$

- **第一步，从排列出发**：从 $n$ 个元素取 $k$ 个排成一列有 $P(n,k)=\frac{n!}{(n-k)!}$ 种。
- **第二步，消顺序**：每一种「组合」（无序的 $k$ 元子集）对应 $k!$ 种「排列」（给它排个序）。所以组合数 = 排列数 ÷ $k!$。
- **第三步，代数整理**：$\frac{n!}{(n-k)!} \div k! = \frac{n!}{k!(n-k)!}$。
- **第四步，三种视角**：① 选择视角——$n$ 里选 $k$ 个；② 划分视角——把 $n$ 个分成「选中的 $k$ 个」与「没选的 $n-k$ 个」；③ 路径视角——网格中从 $(0,0)$ 到 $(k,n-k)$ 的最短路条数 $\binom{n}{k}$（向右 $k$ 步、向上 $n-k$ 步）。

**重点：组合数的「路径视角」是竞赛计数的隐藏武器**——很多看起来毫不相干的计数题，翻译成网格路径后答案就是 $\binom{n}{k}$。多一种视角，多一条解题路。

## 5 竞赛视角：三大计数技巧

竞赛计数题最常用的三个技巧：

**① 捆绑法（处理「相邻」）**：$n$ 个元素中有几个必须相邻，先把它们绑成一个整体再排列。例：$5$ 人排队，甲、乙必须相邻——把甲乙绑成整体，$4$ 个「对象」全排列 $4!$，内部甲乙再排 $2!$，共 $4!\cdot2! = 48$ 种。

**② 插空法（处理「不相邻」）**：先把其他元素排好，再把特殊元素插进空隙。例：$5$ 人排队，甲、乙不相邻——先排其余 $3$ 人 $3!$，形成 $4$ 个空位，甲乙插空 $P(4,2)$，共 $3!\cdot P(4,2) = 36$ 种。<span class="marginnote">捆绑与插空是「相邻/不相邻」问题的标准对。判断用哪个：题里说「必须相邻」→ 捆绑；「不能相邻」→ 插空。它们还能叠加使用：多个约束同时出现时，先捆绑再插空。</span>

**③ 隔板法（处理「正整数解个数」）**：方程 $x_1 + x_2 + \cdots + x_r = n$（$x_i$ 为正整数）的正整数解个数为 $\binom{n-1}{r-1}$——把 $n$ 个「球」排成一列，在 $n-1$ 个空隙中选 $r-1$ 个插隔板。例：$x_1+x_2+x_3=10$ 的正整数解有 $\binom{9}{2}=36$ 个。若允许非负（$x_i\ge0$），先给每个变量加 $1$，转化为正整数解，得 $\binom{n+r-1}{r-1}$。

**心法：计数题四问**——① 分类还是分步？（先加后乘）② 顺序重不重要？（排列还是组合）③ 有没有相邻/不相邻约束？（捆绑/插空）④ 是不是「分配/方程解」？（隔板）按顺序问，陷阱基本都能避开。

### 补充：多条件计数的综合演练

**例 1（捆绑 + 插空叠加）**：$6$ 人排成一列，甲、乙相邻，且丙、丁不相邻，有多少种排法？

先处理「相邻」：把甲、乙捆绑成一个整体 $X$（内部 $2!$），于是对象是 $X$、丙、丁、戊、己共 $5$ 个。再处理「丙丁不相邻」：先排其余 $3$ 个对象（$X$、戊、己）$3!$ 种，形成 $4$ 个空位，丙、丁插空 $P(4,2)$ 种。总排法 $2!\cdot3!\cdot P(4,2) = 2\cdot6\cdot12 = 144$。

**例 2（隔板法变式）**：求 $x_1+x_2+x_3 = 10$ 且 $x_i \ge 2$ 的整数解个数。

先给每个变量「预支」$2$，令 $y_i = x_i - 2 \ge 0$，则 $y_1+y_2+y_3 = 4$，其非负整数解个数为 $\binom{4+3-1}{3-1} = \binom{6}{2} = 15$。**「下限不是 $0$」时，先平移变量到非负再隔板。**

**例 3（含特殊元素）**：从 $0,1,2,3,4,5$ 六个数字中取 $4$ 个组成无重复的四位数（首位不能为 $0$），有多少个？

分类：首位从 $1,2,3,4,5$ 中选，$5$ 种；其余三位从剩余 $5$ 个数字中取 $3$ 排列，$P(5,3)$ 种。共 $5\cdot P(5,3) = 5\cdot60 = 300$ 个。**「$0$ 不能作首位」这类题，把 $0$ 单独分类是最稳的做法。**

| 题型 | 识别特征 | 工具 |
| --- | --- | --- |
| 相邻 | 「必须挨着」 | 捆绑 |
| 不相邻 | 「不能挨着」 | 插空 |
| 分配 / 方程解 | 「分给几个人」「正整数解」 | 隔板 |
| 含 $0$ 的位数 | 「首位不为 $0$」 | 分类 / 补集 |

**辨析补充：「至少」题优先想补集**——先数「全部」，再减去「一个都没有」。例：$n$ 个元素的排列中，「至少有一个元素留在原位」的个数 $= n! - D_n$（$D_n$ 是错排数，见《容斥原理与算两次》）。当「至少一个」的正面分类需要讨论「恰好一个、恰好两个……」时，补集常常只有一种情况，一步到位。**「至少」→「补集」是计数题的通用转换开关。**

**收尾口诀**：先答三问（有无区别、是否重复、顺序是否重要），再选工具（排列 / 组合 / 隔板 / 捆绑 / 插空），最后写过程（分类分步写清层次）——三问定方向，工具定招式。

## 6 小结

- **加法原理**：分类互斥用加；**乘法原理**：分步独立用乘。
- **排列** $P(n,k)=\frac{n!}{(n-k)!}$：顺序重要；全排列 $n!$；环排列 $(n-1)!$。
- **组合** $\binom{n}{k}=\frac{n!}{k!(n-k)!}$
