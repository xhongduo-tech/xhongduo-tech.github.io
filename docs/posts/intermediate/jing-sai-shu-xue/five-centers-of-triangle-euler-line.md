## 为什么从五心与欧拉线开始

三角形是平面几何的「原子」，而它的五个「心」——重心、内心、外心、垂心、旁心——是藏在原子内部的引力中心。<span class="marginnote">「心」是三角形内（或旁）几个特殊点：重心是三条中线的交点、也是质量的平衡点；内心是角平分线交点、内切圆圆心；外心是外接圆圆心；垂心是三条高的交点；旁心是旁切圆圆心。五个心背后各有一整族性质。</span>

五心在竞赛几何里的地位无可替代：它们是辅助线的基本落点、是塞瓦定理的标准练兵场，而**欧拉线**（外心—重心—垂心共线）则是「三角形内部还藏着一条线」的惊人事实。学完五心，你会获得一种「几何直觉的锚点」：看到一个三角形，先想它的心在哪——绝大多数复杂图形问题，都能归结到某个「心」的性质上。

## 1 五个心各归其位

五个心的定义与基本性质先摆一张总表：

| 心 | 定义（交点） | 半径关系 | 关键性质 |
| --- | --- | --- | --- |
| **重心** G | 三条中线 | 无 | 分中线 $2:1$；是三顶点向量的算术平均 $\vec{OG}=\frac{\vec{OA}+\vec{OB}+\vec{OC}}{3}$ |
| **内心** I | 三条角平分线 | 内切圆 $r$ | 到三边距离相等；$S = \frac12(a+b+c)r$ |
| **外心** O | 三条垂直平分线 | 外接圆 $R$ | 到三顶点距离相等 $OA=OB=OC=R$ |
| **垂心** H | 三条高 | 无 | $\angle BHC = 180° - \angle A$（及循环） |
| **旁心** I$_a$ | 两条外角平分线与一条内角平分线 | 旁切圆 $r_a$ | 到三边（含延长线）距离相等 |

<span class="marginnote">「五心」在更细的分类里还会加上「等心」「界心」，但竞赛主战场就是这五个。它们不是孤立的点：重心、外心、垂心由「对称性」直接定义，内心、旁心由「距离相等」定义，前者是代数的、后者是几何的。</span>

两个立刻有用的关系：

**重心分中线**：$AG : GD = 2 : 1$（$D$ 为 $BC$ 中点）。重心把每条中线分成 $2:1$ 两段，靠近顶点的那段更长。

**内心与面积**：设内切圆半径为 $r$，则面积 $S = \frac12 r(a+b+c)$——把三角形按内心切成三个小三角形，每个小三角形以一边为底、$r$ 为高。

**外心与垂心的对偶**：$\angle BHC = 180° - \angle A$。垂心的角关系与外心互补，这是「四心」之间最深刻的对称之一，也是许多共圆问题的出发点。

## 2 塞瓦定理一网打尽共点性

五个心的「共点性」——三条中线交于一点、三条角平分线交于一点、三条高交于一点、三条垂直平分线交于一点——都可以用**塞瓦定理**一次证明。<span class="marginnote">垂直平分线那一条需要「换底」：垂直平分线交于外心，等价于「三条中垂线的交点到三顶点等距」，用共圆或勾股说明。</span>

以重心为例：三条中线 $AD,BE,CF$ 交于 $G$，对 $\triangle ABC$ 用塞瓦：

$$\frac{BD}{DC}\cdot\frac{CE}{EA}\cdot\frac{AF}{FB} = 1\cdot1\cdot1 = 1$$

因为 $D,E,F$ 分别是中点，三段比全是 $1$，乘积为 $1$，塞瓦保证三线共点。**重心共点的证明，一句话。**

内心同理：$AD,BE,CF$ 是角平分线，由角平分线定理 $\frac{BD}{DC}=\frac{AB}{AC}$，$\frac{CE}{EA}=\frac{BC}{BA}$，$\frac{AF}{FB}=\frac{CA}{CB}$，三式相乘：

$$\frac{AB}{AC}\cdot\frac{BC}{BA}\cdot\frac{CA}{CB} = 1$$

分子分母两两约去，得 $1$。**三个比例循环约分，内心共点也一句话。**

垂心：$AD,BE,CF$ 是高。由三角形面积相等关系或相似可证 $\frac{BD}{DC}=\frac{AB\cos B}{AC\cos C}$ 之类的循环式，再相乘约去。三组「共点性」共享同一个塞瓦框架——这就是定理的威力：**把三种不同的几何事实，压缩进同一个代数计算。**

## 3 欧拉线与九点圆

**欧拉线（Euler line）**：外心 $O$、重心 $G$、垂心 $H$ 三点共线，且

$$\vec{OG} = \frac{1}{3}\vec{OH}, \qquad OG : GH = 1 : 2$$

即重心 $G$ 位于 $OH$ 上、距 $O$ 为全长三分之一处。<span class="marginnote">欧拉（Leonhard Euler，1707—1783）在 1765 年发现这一事实。它说明：三角形的外心、重心、垂心不是三个孤立点，而是坐在同一条直线上的三个「锚点」。</span>

欧拉线为什么成立？用向量证明最干净。取外心 $O$ 为原点，设顶点向量为 $\vec a,\vec b,\vec c$。重心 $\vec g = \frac{\vec a+\vec b+\vec c}{3}$。垂心有一个优美的向量身份：

$$\vec h = \vec a + \vec b + \vec c$$

这是因为 $\vec h - \vec a = \vec b + \vec c$ 与 $BC$ 垂直（$(\vec b+\vec c)\cdot(\vec b-\vec c) = |\vec b|^2 - |\vec c|^2 = 0$，因 $|\vec b|=|\vec c|=R$）。于是 $\vec g = \frac13\vec h$，三点共线且重心把外心到垂心的距离分成 $1:2$。

**重点：向量是证明「共线、共点、比例」的现代武器。** 五心的位置关系用坐标向量表示后，几何事实变成代数恒等式，可算可证。这与第一节《复数与三角法》里「用复数降维几何」是同一条路线。

**九点圆（nine-point circle）**：三角形三边的中点、三条高的垂足、以及三顶点到垂心的三个中点，这九点共圆，圆心是 $OH$ 的中点，半径是外接圆半径的一半 $R/2$。九点圆是欧拉线的「孪生兄弟」——它们的圆心都在 $OH$ 这条线上。

## 4 公式解析：重心向量公式的几何含义

$$\vec{OG} = \frac{1}{3}\left(\vec{OA} + \vec{OB} + \vec{OC}\right)$$

- **第一步，选原点**：原点可取任意点 $O$（通常是外心，使 $|\vec{OA}|=|\vec{OB}|=|\vec{OC}|=R$ 简化计算）。
- **第二步，看右边**：三个顶点向量的**算术平均**。物理直觉：把三个质量相等的质点放在 $A,B,C$，质心就是重心 $G$——所以重心也叫「质心」。
- **第三步，看左边**：$\vec{OG}$ 是重心相对原点的位置向量。等式说「质心坐标 = 顶点坐标的平均」，这是质心定义的坐标形式。
- **第四步，推性质**：取 $O$ 为外心，若 $\triangle ABC$ 是直角三角形，外心是斜边中点、垂心是直角顶点，代入 $\vec h=\vec a+\vec b+\vec c$ 立即验证。

**辨析｜易错点：** 重心向量公式要求三个质量**相等**。若题目换成「三顶点质量不同」（物理重心），公式变为加权平均 $\frac{m_1\vec a+m_2\vec b+m_3\vec c}{m_1+m_2+m_3}$。竞赛里「质量相等」是默认，但遇到「加权」表述时别套错公式。

## 5 竞赛视角：五心是辅助线的锚点

五心的价值，最终体现在「辅助线往哪画」。看一道典型题：

**例**：$\triangle ABC$ 中，$O$ 是外心，$H$ 是垂心，$D$ 是 $BC$ 中点。证明 $OD \perp AH$ 且 $AH = 2OD$。

**思路**：这是一道「欧拉线家族」题。取 $BC$ 中点 $D$，$OD \perp BC$（垂直平分线）。而 $AH$ 也是垂直于 $BC$ 的高——所以 $OD \parallel AH$ 且都在 $BC$ 的垂线方向上。剩下证 $AH = 2OD$：

**法一（向量）**：以 $O$ 为原点，$\vec h = \vec a+\vec b+\vec c$，$\vec{OD} = \frac{\vec b+\vec c}{2}$，$\vec{AH} = \vec h - \vec a = \vec b+\vec c = 2\vec{OD}$。模长即 $AH = 2OD$。

**法二（几何）**：作 $BE \perp AC$ 交 $AC$ 于 $E$，$O$ 是外心，$D$ 是 $BC$ 中点，中位线思想：$OD$ 是 $\triangle B C X$ 的中位线（$X$ 为某点），构造后与 $AH$ 平行且为其一半。<span class="marginnote">这类「垂心与外心之间的线段关系」题，几乎都指向同一个辅助线家族：取中点、连中位线、找平行四边形。欧拉线、九点圆、$AH=2OD$ 都在这个家族里。</span>

**心法：看到外心想中点，看到垂心想高，看到重心想 $2:1$。** 三个「心」各带一套辅助线习惯，组合起来就是解几何题的脚手架。

**再补一个高频结论——重心与向量**：对平面上任意点 $P$，有 $\vec{PA} + \vec{PB} + \vec{PC} = 3\vec{PG}$。取 $P$ 为原点即回到重心公式；取 $P$ 为某顶点，可得「以任一顶点为起点的三条向量之和等于 $3$ 倍重心向量」的漂亮形式。这类「$\vec{PA}+\vec{PB}+\vec{PC}=3\vec{PG}$」的式子，在「已知重心证共线」「已知向量和求点」的题里是直接可用的公式。

## 6 小结

- 五心：**重心**（中线，分 $2:1$）、**内心**（角平分线，$S=\frac12(a+b+c)r$）、**外心**（垂直平分线，$OA=OB=OC=R$）、**垂心**（高）、**旁心**（旁切圆）。
- 五心的共点性全部可用**塞瓦定理**一次验证：三个比例循环约分得 $1$。
- **欧拉线**：$O,G,H$ 共线，$\vec{OG}=\frac13\vec{OH}$，$OG:GH=1:2$；向量身份 $\vec h=\vec a+\vec b+\vec c$。
- **九点圆**：九点共圆，圆心为 $OH$ 中点，半径 $R/2$。
- 心法是辅助线锚点：**外心想中点、垂心想高、重心想 $2:1$**；内心想角平分线。
- 向量身份：重心 $\vec g=\frac{\vec a+\vec b+\vec c}{3}$、垂心 $\vec h=\vec a+\vec b+\vec c$、$\vec{OG}=\frac13\vec{OH}$。

在下一节，我们将学几何变换：平移、旋转与对称——「五心」是静止的锚点，变换则让图形动起来。
