## 为什么从不定方程开始

不定方程（Diophantine equation）是「方程的个数少于未知量的个数、却只求整数解」的方程。它们常常看起来简单到荒谬，却藏着数论最深的问题。<span class="marginnote">名字来自古希腊数学家丢番图（Diophantus of Alexandria，约公元 250 年），他的《算术》一书专门研究整数解问题。费马正是在《算术》书边的空白处写下了著名的「费马大定理」。</span>

竞赛里的不定方程，是数论四件套（整除、同余、素数、分解）的**集大成考场**：解 $ax+by=c$ 要用裴蜀与同余，解勾股数组要用分解与参数化，解佩尔方程要用递推与逼近，而「无穷递降法」则是拉马努金式灵感的代名词。学完这一节，数论篇就完成了一半以上的「硬核」部分。

## 1 二元一次不定方程

最基本的不定方程是 $ax + by = c$（$a,b,c$ 为整数）。它的完整理论：

**有解判据**：$ax+by=c$ 有整数解当且仅当 $\gcd(a,b) \mid c$。此时解有无穷多个。

**通解结构**：设 $x_0,y_0$ 是一组特解，则全部整数解为

$$x = x_0 + \frac{b}{d}t, \qquad y = y_0 - \frac{a}{d}t \qquad (t \in \mathbb{Z}, \ d = \gcd(a,b))$$

<span class="marginnote">「差一个 $t$」的结构来自齐次方程 $ax+by=0$ 的解：$x = \frac{b}{d}t,\ y = -\frac{a}{d}t$。特解 + 齐次解的全体，就是非齐次方程的全部解——这与线性代数里「非齐次 = 特解 + 齐次通解」完全同构。</span>

**求特解的方法**：用**辗转相除法回溯**（扩展欧几里得算法）。例：解 $3x + 5y = 1$。

$$5 = 1\cdot3 + 2, \quad 3 = 1\cdot2 + 1$$

回溯：$1 = 3 - 2 = 3 - (5-3) = 2\cdot3 - 1\cdot5$。所以 $x_0 = 2, y_0 = -1$ 是一组特解。通解 $x = 2+5t,\ y = -1-3t$。

**重点：二元一次不定方程的两种考法**——① 给方程求全部解（用扩展欧几里得）；② 给约束（如 $x,y$ 非负、求 $xy$ 最大）选合适的 $t$。

## 2 勾股数组

**勾股数组（Pythagorean triple）**：满足 $x^2 + y^2 = z^2$ 的正整数三元组，如 $(3,4,5)$。**本原勾股数组**指 $\gcd(x,y,z)=1$ 的勾股数组。

本原勾股数组的完整参数化（古典结论）：

$$x = m^2 - n^2, \qquad y = 2mn, \qquad z = m^2 + n^2$$

其中 $m > n > 0$，$\gcd(m,n)=1$，且 $m,n$ 一奇一偶；反之，任何这样的一组 $(m,n)$ 都给出一个本原勾股数组。<span class="marginnote">「一奇一偶」的要求保证 $x$ 是奇数、$y$ 是偶数，避免出现非本原的重复计数。例如 $m=2,n=1$ 给出 $(3,4,5)$；$m=3,n=2$ 给出 $(5,12,13)$。</span>

参数化的证明思路分四步：先证 $x,y$ 一奇一偶且 $z$ 为奇，再设 $z+y = u^2$、$z-y = v^2$（利用 $z^2 - y^2 = x^2$ 与互素），令 $m = \frac{u+v}{2}$、$n = \frac{u-v}{2}$ 即可。

**竞赛运用**：勾股数组常以「求 $x^2+y^2 = z^2$ 满足某附加条件」出现。附加条件往往把「通解参数 $m,n$」约束成有限的——比如 $xyz$ 最小、$z$ 是某个定值等。

## 3 佩尔方程

**佩尔方程（Pell's equation）**：形如 $x^2 - dy^2 = 1$（$d$ 是非平方正整数）的方程。它有无穷多组正整数解，且有漂亮的递推结构。

设 $x_1 + y_1\sqrt d$ 是 $x^2-dy^2=1$ 的**最小正整数解**（基本解），则全部解由

$$x_n + y_n\sqrt d = (x_1 + y_1\sqrt d)^n$$

给出。<span class="marginnote">把解写成「$x+y\sqrt d$」，方程的乘法结构瞬间显形：$(x_1+y_1\sqrt d)(x_2+y_2\sqrt d)$ 仍满足方程，因为范数 $x^2-dy^2$ 在乘法下保持（$(x^2-dy^2)(u^2-dv^2)=(xu+dyv)^2-d(xv+yu)^2$）。这是「用扩域看整数方程」的第一次惊艳。</span>

例：$x^2 - 2y^2 = 1$ 的最小解是 $x_1=3, y_1=2$（$3^2-2\cdot2^2=1$）。于是第二组解 $(3+2\sqrt2)^2 = 17+12\sqrt2$，即 $(17,12)$。第三组 $(99,70)$……全部正整数解由此递推而出。

**求基本解**：通常用「连分数」或直接枚举 $y$ 从 $1$ 开始找最小使 $1+dy^2$ 为平方数。竞赛里基本解常作为已知条件给出，重点是理解「幂结构生成全部解」。

## 4 公式解析：勾股数组参数化的原理

$$x = m^2 - n^2, \qquad y = 2mn, \qquad z = m^2 + n^2$$

- **第一步，验证**：$(m^2-n^2)^2 + (2mn)^2 = m^4 - 2m^2n^2 + n^4 + 4m^2n^2 = m^4 + 2m^2n^2 + n^4 = (m^2+n^2)^2$。**「$m^2-n^2, 2mn, m^2+n^2$ 永远构成勾股数组」是代数恒等式，无需任何数论**。
- **第二步，为什么覆盖所有本原解**：任给本原 $(x,y,z)$，令 $u = z+y$、$v = z-y$。由 $x^2 = (z+y)(z-y) = uv$ 且 $\gcd(u,v)$ 很小（本原性保证），可推出 $u,v$ 都是平方数：$u = m^2, v = n^2$。
- **第三步，解出参数**：$m^2 = z+y$，$n^2 = z-y$，于是 $z = \frac{m^2+n^2}{2}$，$y = \frac{m^2-n^2}{2}$——注意这里出现「除以 $2$」，本原性要求 $m,n$ 一奇一偶正是为了保证整数。
- **第四步，收尾**：$x = mn$，但标准形式取 $x = m^2-n^2,\ y=2mn$ 只是 $m,n$ 的角色互换（或同乘 $2$ 的等价形式）。**参数化不是唯一写法，关键是「一个参数对 ↔ 一个本原解」的双向对应。**

**重点：参数化的本质是「用自由参数消灭约束方程」。** 一个方程 $x^2+y^2=z^2$ 有三个未知量，参数化用两个参数表示，自由度从「约束后的 $2$ 维」变成「参数的 $2$ 维」——这是解不定方程最优雅的姿势。

## 5 竞赛视角：无穷递降法

**无穷递降法（method of infinite descent）**：由费马发展的反证技术——假设某正整数方程有解，取「最小」的一组解，再从中构造出「更小」的一组解，矛盾。它特别适合「证某类方程无解」。

**经典例**：证明 $\sqrt2$ 是无理数（无穷递降版）。假设 $\sqrt2 = \frac{p}{q}$（最简分数），则 $p^2 = 2q^2$，$p$ 为偶，$p=2r$，得 $q^2 = 2r^2$，$q$ 也为偶——与「最简」矛盾。

**竞赛例**：证明 $x^2 + y^2 + z^2 = 2xyz$ 无非零整数解（除全零）。<span class="marginnote">取最小的一组正整数解，观察模 $4$：平方数模 $4$ 只能是 $0$ 或 $1$，而 $2xyz$ 模 $4$ 视奇偶……穷追不舍会发现解必全为偶数，除以 $2$ 得到更小的一组解——矛盾。递降 + 模分析是「证无解」的双引擎。</span>

**心法：不定方程的四个工具按序问**——① 是一次/二次的？一次用裴蜀+通解；② 有平方结构？用参数化或模 $4/8$ 分类；③ 是佩尔型？找基本解、用幂结构；④ 证无解？无穷递降或模矛盾。

### 补充：三类不定方程的速览对照

把三种主要类型放在一张表里，方便「见题分型」：

| 类型 | 标准形 | 解法主线 | 解的个数 |
| --- | --- | --- | --- |
| 二元一次 | $ax+by=c$ | 扩展欧几里得求特解 + 齐次通解 | 有解则无穷多 |
| 勾股型 | $x^2+y^2=z^2$ | 本原参数化 $m,n$ | 无穷多（本原） |
| 佩尔型 | $x^2-dy^2=1$ | 基本解 $(x_1+y_1\sqrt d)$ 的幂 | 无穷多，幂结构 |
| 高次 / 混合 | 视题而定 | 模分析、分解、递降、不等式夹 | 常为有限或零 |

**例（不等式夹逼）**：求满足 $x^2 + y^2 \le 10$ 的正整数解 $(x,y)$。

因为 $x,y \ge 1$，$x^2 \le 10 - 1 = 9$，故 $x \le 3$；同理 $y \le 3$。枚举 $x,y \in \{1,2,3\}$ 检查 $x^2+y^2 \le 10$：得 $(1,1),(1,2),(1,3),(2,1),(2,2),(2,3),(3,1),(3,2),(3,3)$ 去掉 $>10$ 的 $(3,3)$（和为 $18$）……逐一核验。**「不等式把范围夹成有限个，再枚举」是不定方程的压轴手段**——当数论工具都用尽时，夹逼枚举往往兜底。

**例（模分析否定）**：证明 $x^2 - 3y^2 = 2$ 无整数解。模 $3$ 看：$x^2 \equiv 2 \pmod 3$，但平方数模 $3$ 只能是 $0$ 或 $1$——矛盾。**「选一个模，使一边余数不可能」是证无解的捷径**：平方选模 $3,4,8$，立方选模 $7,9$，依系数而定。

**心法补充：解不定方程的「工具箱」顺序**——① 先看次数：一次用裴蜀；② 有平方/立方结构就模分析；③ 可分解就分解成因子乘积式；④ 佩尔型找基本解；⑤ 全失败就不等式夹逼枚举；⑥ 证无解优先「选模」。

**收尾提醒**：无论用哪条路线得到解，**最后都要「验根」**——把参数化或枚举出的解代回原方程逐一确认；特别是「模分析否定」得到的无解结论，无需验根但要把「模的选择」写清楚，让阅卷者看到你选模的依据。

## 6 小结

- **二元一次不定方程** $ax+by=c$：有解 $\iff \gcd(a,b)\mid c$；通解 = 特解 + 齐次解。
- **勾股数组**：本原解参数化 $x=m^2-n^2,\ y=2mn,\ z=m^2+n^2$（$m,n$ 互素、一奇一偶）。
- **佩尔方程** $x^2-dy^2=1$：全部解由基本解 $(x_1+y_1\sqrt d)^n$ 生成。
- **无穷递降法**：假设有解取最小解，构造更小的解导出矛盾，专证「无解」。
- 工具按序问：一次用裴蜀、平方用模分析、佩尔找基本解、证无解用递降、兜底用夹逼枚举。
