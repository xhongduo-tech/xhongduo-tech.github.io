## 为什么从组合恒等式与母函数开始

上一节的算两次给出了一条条恒等式，这一节要把整个「恒等式家族」系统化，并引入一个把它们统一起来的超级工具——**母函数**。<span class="marginnote">母函数（generating function）把数列 $a_0,a_1,a_2,\dots$ 打包成一个形式幂级数 $G(x) = \sum a_n x^n$。数列的运算（求和、卷积、递推）在母函数里变成幂级数的运算（加、乘、解方程）——「晾衣绳」把数字挂上后，代数就替你做组合。</span>

母函数是竞赛组合的「压舱石」：它把「求第 $n$ 项」变成「求某个幂级数的第 $n$ 个系数」，把「证恒等式」变成「两个幂级数相等」——后者只需比较系数。斐波那契通项、隔板计数、分拆数、递推求解，全部在母函数的框架下得到统一处理。它也是通往第二级《组合数学》与《概率论》的重要桥梁。

## 1 组合恒等式的武器库

先盘点竞赛里最常用的组合恒等式（它们大多已经在前面章节见过）：

**帕斯卡公式**：$\binom{n}{k} = \binom{n-1}{k} + \binom{n-1}{k-1}$。

**二项式定理**：$(1+x)^n = \sum_{k=0}^{n}\binom{n}{k}x^k$。

**范德蒙德恒等式（Vandermonde's identity）**：$\sum_{k=0}^{r}\binom{m}{k}\binom{n}{r-k} = \binom{m+n}{r}$。<span class="marginnote">范德蒙德恒等式的组合证明：从 $m$ 个男生和 $n$ 个女生中选 $r$ 个人。左边按「男生选 $k$ 个、女生选 $r-k$ 个」分类求和；右边直接是「$m+n$ 里选 $r$」。同一件事两种数法——算两次的又一场胜利。</span>

**主席恒等式**：$\sum_{k=1}^{n}k\binom{n}{k} = n2^{n-1}$（上一节的委员会主席例）。

**平方和**：$\sum_{k=0}^{n}\binom{n}{k}^2 = \binom{2n}{n}$（范德蒙德恒等式取 $m=n$、$r=n$ 的特例）。

**重点：证恒等式的三条路线**——① 代数变形（阶乘展开、帕斯卡递推）；② 组合论证（算两次，构造两个计数故事）；③ 母函数（比较系数）。三条路线各有优劣，母函数路线最「机械化」。

## 2 母函数的基本概念

**普通母函数（ordinary generating function）**：数列 $a_0, a_1, a_2, \dots$ 的母函数是形式幂级数

$$G(x) = \sum_{n \ge 0} a_n x^n$$

「形式」意味着我们**不关心收敛**，只把它当代数对象。系数提取记号：$[x^n]G(x) = a_n$。

两个最基本的母函数：

**等比级数**：$1 + x + x^2 + \cdots = \frac{1}{1-x}$，所以 $\frac{1}{1-x}$ 是「全 $1$ 数列」的母函数。

**二项式系数的母函数**：$(1+x)^n$ 展开，$[x^k](1+x)^n = \binom{n}{k}$——**二项式定理本身就是母函数**。

**卷积与乘法**：若 $G(x)$ 是 $\{a_n\}$ 的母函数、$H(x)$ 是 $\{b_n\}$ 的母函数，则 $G(x)H(x)$ 的系数是

$$[x^n]G(x)H(x) = \sum_{k=0}^{n} a_k b_{n-k}$$

这是**卷积（convolution）**：母函数相乘 = 序列做卷积。它把「从两堆里各取若干个」的计数自动完成。

**重点：母函数乘法 = 组合选择的「自动计数机」。** 一个因子对应「一种物品」，「选 $k$ 个」由 $x^k$ 的系数承载，多类物品的联合选择就是因子相乘。

## 3 母函数求解计数问题

**例 1（隔板计数重解）**：方程 $x_1+x_2+x_3 = n$ 的非负整数解个数。

母函数视角：每个变量 $x_i$ 可以取 $0,1,2,\dots$，对应因子 $1+x+x^2+\cdots = \frac{1}{1-x}$。三个变量相乘：

$$\left(\frac{1}{1-x}\right)^3 = \sum_{n\ge0}\binom{n+2}{2}x^n$$

系数 $\binom{n+2}{2}$ 正是非负整数解的个数——与《排列组合》里隔板法的 $\binom{n+r-1}{r-1}$ 一致。<span class="marginnote">母函数的妙处在于「约束自动融入因子」：若要求 $x_i \ge 1$，因子改成 $x+x^2+\cdots = \frac{x}{1-x}$；若要求 $x_i$ 是偶数，因子改成 $1+x^2+x^4+\cdots = \frac{1}{1-x^2}$。每条约束都是一个因子。</span>

**例 2（斐波那契）**：$F_{n+2} = F_{n+1}+F_n$，$F_0=0,F_1=1$。设 $G(x) = \sum F_n x^n$，由递推：

$$G(x) = F_0 + F_1x + \sum_{n\ge2}F_n x^n = x + \sum_{n\ge2}(F_{n-1}+F_{n-2})x^n = x + xG(x) + x^2G(x)$$

解得 $G(x) = \frac{x}{1-x-x^2}$。对这个有理函数做部分分式分解，就得到比内公式（《数列与递推》里的 $F_n = \frac{1}{\sqrt5}(\varphi^n - \psi^n)$）。**递推方程变成了母函数的代数方程。**

## 4 公式解析：$G(x) = \frac{x}{1-x-x^2}$ 如何讲出斐波那契的一切

- **第一步，写出母函数方程**：$G = x + xG + x^2G$，解得 $G(x) = \frac{x}{1-x-x^2}$。推导过程只有「把递推代入定义」。
- **第二步，分母因式分解**：$1-x-x^2 = (1-\varphi x)(1-\psi x)$，其中 $\varphi = \frac{1+\sqrt5}{2}$、$\psi = \frac{1-\sqrt5}{2}$——它们满足 $\varphi\psi = -1$，正是特征方程 $x^2=x+1$ 的两根。
- **第三步，部分分式**：$\frac{x}{1-x-x^2} = \frac{A}{1-\varphi x} + \frac{B}{1-\psi x}$，解得 $A = \frac{1}{\sqrt5}$、$B = -\frac{1}{\sqrt5}$。
- **第四步，展回级数**：$\frac{1}{1-\varphi x} = \sum \varphi^n x^n$，于是 $F_n = [x^n]G = \frac{1}{\sqrt5}(\varphi^n - \psi^n)$——比内公式「自动」掉出来。

**重点：母函数路线与特征方程路线是同一枚硬币的两面**——特征方程出现在「分母的根」，通项系数来自「部分分式」。学会其中一条，另一条就是翻译。

**辨析｜易错点：** 处理「形式幂级数」时，$G(x) = \frac{x}{1-x-x^2}$ 中的等式是「形式恒等」，不需要收敛域。但在竞赛书写里，若真的代入数值求值，需注明 $|x|$ 足够小以保证收敛——**形式等式与函数等式在「是否谈收敛」上不同。**

## 5 竞赛视角：母函数证恒等式与解递推

**例 1（用母函数证范德蒙德）**：$(1+x)^m(1+x)^n = (1+x)^{m+n}$，两边展开比较 $x^r$ 系数：

$$\sum_{k=0}^{r}\binom{m}{k}\binom{n}{r-k} = \binom{m+n}{r}$$

**一行「幂级数乘法」取代了整页代数。**<span class="marginnote">母函数证恒等式的通用剧本：① 把两个恒等式翻译成「两个母函数相等」；② 用代数操作（乘法、分解、微分）证明母函数相等；③ 比较系数得到恒等式。第②步的代数往往是最短的。</span>

**例 2（解递推）**：$a_{n+2} = 5a_{n+1} - 6a_n$，$a_0=1,a_1=4$。设 $G = \sum a_n x^n$：

$$G = 1 + 4x + \sum_{n\ge2}(5a_{n-1}-6a_{n-2})x^n = 1 + 4x + 5x(G-1) - 6x^2G$$

解得 $G = \frac{1 - x}{1 - 5x + 6x^2} = \frac{1-x}{(1-2x)(1-3x)}$。部分分式得 $G = \frac{1}{1-2x} + \frac{0}{1-3x}$……整理后 $a_n = 2^{n+1} - 1$（或类似闭式），直接读出通项。**任何「线性常系数递推」都可以这样机械化求解。**

**心法：什么时候用母函数？** ① 要证一堆组合恒等式——母函数最省力；② 线性递推求通项——母函数机械可靠；③ 带约束的计数（$x_i$ 有范围）——约束化作因子。而「一道题只数一次」的简单题，直接计数更快，不必祭出母函数。

### 补充：指数型母函数与「带标签」计数

竞赛里还常出现**指数型母函数（exponential generating function, EGF）**：

$$\hat G(x) = \sum_{n\ge0} a_n \frac{x^n}{n!}$$

普通母函数管「无标签」的计数（组合、隔板），指数型母函数管「有标签」的计数（排列、带序）。一条关键对应：EGF 里 $\frac{x^n}{n!}$ 的系数恰是「把 $n$ 个有区别的东西分成若干有结构的组」的方式数。<span class="marginnote">判断用 OGF 还是 EGF：物品之间无区别（球、隔板）用普通母函数；物品有编号、有顺序（人、排列）用指数型母函数。EGF 里 $n!$ 的出现，正是「给组合加顺序」的记号。</span>

**例（错排的 EGF 视角）**：错排数 $D_n$ 满足 $D_n = n!\sum_{k=0}^{n}\frac{(-1)^k}{k!}$，其 EGF 是 $\frac{e^{-x}}{1-x}$。因为 $\frac{e^{-x}}{1-x} = \left(\sum \frac{(-x)^k}{k!}\right)\left(\sum x^m\right)$，展开取 $x^n$ 系数即得 $D_n$ 的公式——**容斥（上一节）与母函数在此再次握手。**

**例（OGF 求递推闭式）**：$a_{n+2} = a_{n+1} + 2a_n$，$a_0=1,a_1=1$。设 $G=\sum a_nx^n$，由递推：$G = 1 + x + x(G-1) + 2x^2G$，解得 $G = \frac{1}{1-x-2x^2} = \frac{1}{(1+x)(1-2x)}$。部分分式 $\frac{1}{3(1+x)} + \frac{2}{3(1-2x)}$，故 $a_n = \frac{1}{3}(-1)^n + \frac{2}{3}\cdot2^n$。**递推 → 母函数方程 → 部分分式 → 通项，一条龙。**

**心法：母函数题的四个产出**——① 计数问题给出闭式；② 递推问题给出通项；③ 恒等式问题给出证明；④ 分拆问题给出「生成」直觉。一个工具，四个用途，这就是它配得上「晾衣绳」比喻的原因。

## 6 小结

- **组合恒等式武器**：帕斯卡、二项式定理、范德蒙德、主席恒等式；证法有代数、组合、母函数三路。
- **母函数**：$G(x)=\sum a_n x^n$；系数提取 $[x^n]G = a_n$；**乘法 = 卷积**。
- 约束化为因子：$x_i$ 的非负/下限/奇偶限制对应不同因式。
- 斐波那契母函数 $\frac{x}{1-x-x^2}$
