## 为什么从整除性与带余除法开始

数论是竞赛数学里「最像数学的数学」：它的问题往往一句话就能读懂，却要动用整座智力堡垒。而这座堡垒的第一块砖，是**带余除法**。<span class="marginnote">带余除法说：任何整数除以一个正整数，商与余数都是唯一的。看似平凡，它却是「同余」「最大公因数」「辗转相除」乃至整个初等数论的出发点——欧几里得《几何原本》里已经出现了它的身影。</span>

整除性是整数之间最基本的关系：$a$ 整除 $b$，记作 $a \mid b$。竞赛里几乎所有数论题，最终都落到「某个整除关系成立/不成立」上。这一节把整除的定义、性质、判定标准系统化，并给出核心算法（辗转相除法），为后面《同余与剩余类》《素数与唯一分解定理》铺路。它也是第一级《初等数论》的自然深化。

## 1 整除的定义与基本性质

**整除（divisibility）**：设 $a,b$ 是整数且 $a \ne 0$，若存在整数 $q$ 使 $b = aq$，则称 $a$ **整除** $b$，记作 $a \mid b$；否则 $a \nmid b$。

整除的性质大多平凡却高频：

**传递性**：$a \mid b$ 且 $b \mid c$，则 $a \mid c$。
**线性组合**：$a \mid b$ 且 $a \mid c$，则 $a \mid (mb + nc)$ 对任意整数 $m,n$ 成立。
**有界性**：$a \mid b$ 且 $b \ne 0$，则 $|a| \le |b|$。
**交错性**：$a \mid b$ 且 $b \mid a$，则 $a = \pm b$。<span class="marginnote">「交错性」是整除关系在「带符号整数」里最像相等的地方：双向整除就是相差一个符号。这个性质在证明「两数相等」时经常被调用——先证互相整除，再比较正负。</span>

**重点：$a \mid b$ 的记号方向别搞反**——$a$ 整除 $b$（$a$ 是除数），$b$ 被 $a$ 整除（$b$ 是被除数）。中文里「$b$ 能被 $a$ 整除」和「$a$ 能整除 $b$」是同一件事。

**辨析｜易错点：** 关于 $0$ 的三个约定要分清——任何非零整数都整除 $0$（因为 $0 = a\cdot 0$）；$0$ 不整除任何非零整数；$0 \mid 0$ 按定义不成立（除数不能为 $0$）。

## 2 带余除法

**带余除法（division algorithm）**：对任意整数 $a$ 与正整数 $b$，存在**唯一**的整数对 $(q,r)$，使得

$$a = bq + r, \qquad 0 \le r \lt  b$$

其中 $q$ 叫**商**，$r$ 叫**余数**。<span class="marginnote">余数的范围 $0 \le r \lt  b$ 是「唯一性」的关键：若允许 $r$ 取负或过大，$(q,r)$ 就不唯一了。竞赛里还常见「最小非负剩余」与「最小绝对值剩余」两种约定，读题时注意余数的范围。</span>

带余除法的三个推论：

**① 整除判定**：$b \mid a$ 当且仅当带余除法中 $r = 0$。
**② 按余数分类**：每个整数被 $b$ 除后，余数只能是 $0,1,\dots,b-1$ 之一——于是整数被分成 $b$ 个类，这就是后面《同余》的种子。
**③ 奇偶与模 $3$ 分类**：偶数 $2k$、奇数 $2k+1$；模 $3$ 分类为 $3k, 3k+1, 3k+2$。竞赛里「对 $n^2$ 讨论」时，常利用「平方数模 $4$ 只能是 $0$ 或 $1$」这类分类结论。

**平方数的模性质**：$n^2$ 被 $4$ 除余 $0$ 或 $1$；被 $8$ 除余 $0,1,4$；被 $3$ 除余 $0$ 或 $1$。这些「平方数能取哪些余数」的结论，是数论竞赛题的高频判据，比如证明「$x^2+y^2=3$ 无整数解」只需检查模 $4$ 余数。

## 3 最大公因数与辗转相除法

**最大公因数（greatest common divisor）**：$a,b$ 不全为零，它们的最大公因数记作 $\gcd(a,b)$，是不超过 $|a|,|b|$ 且同时整除两者的最大正整数。$a,b$ 互素记作 $\gcd(a,b)=1$。

求 $\gcd$ 的黄金算法是**辗转相除法（Euclidean algorithm）**：反复用带余除法，直到余数为零，最后一步的除数就是最大公因数。

$$a = bq_1 + r_1, \quad b = r_1q_2 + r_2, \quad r_1 = r_2q_3 + r_3, \quad \dots, \quad r_{k-2} = r_{k-1}q_k + r_k, \quad r_{k-1} = r_k q_{k+1} + 0$$

则 $\gcd(a,b) = r_k$（最后一个非零余数）。<span class="marginnote">辗转相除法的核心观察：$\gcd(a,b) = \gcd(b, a \bmod b)$——最大公因数在「被除数换成余数」后不变。这个观察使算法每步把数字大幅缩小，复杂度 $O(\log\min(a,b))$，是现代密码学里 RSA 求逆元的基石。</span>

例：求 $\gcd(1078, 462)$。

$$1078 = 462 \times 2 + 154, \quad 462 = 154 \times 3 + 0$$

所以 $\gcd(1078, 462) = 154$。只需两步。

**重点：辗转相除法不仅是算法，更是性质来源。** 由它可推出最大公因数的「线性组合表示」：

$$\gcd(a,b) = ax + by$$

对某些整数 $x,y$ 成立。这是**裴蜀定理（Bézout's identity）**。它说明：两个数的最大公因数，等于它们整系数的线性组合——这一结论是后面解不定方程、证互素性质的万能钥匙。

## 4 公式解析：$a = bq + r$ 的唯一性

带余除法的公式看似显然，它的「唯一性」值得拆开看：

- **第一步，存在性**：固定 $b$，让 $q$ 取遍整数，数轴上的点 $bq$ 把数轴等分成间隔 $b$ 的网格。$a$ 必然落在某两个相邻网格点之间：$bq \le a \lt  b(q+1)$。
- **第二步，定义余数**：取 $r = a - bq$，则 $0 \le r \lt  b$。存在性得证——几何上，$r$ 是 $a$ 到「左边最近网格点」的距离。
- **第三步，唯一性**：若有两组 $(q_1,r_1),(q_2,r_2)$，相减得 $b(q_1-q_2) = r_2 - r_1$。两边同时被夹在 $(-b, b)$ 内，故只能为 $0$：$r_1=r_2$ 且 $q_1=q_2$。
- **第四步，用处**：唯一性意味着「余数」是一个良定义的函数 $a \bmod b$——它是后续一切模运算的基础。

**重点：带余除法的唯一性让「余数」可作运算对象。** 一旦确认 $a \bmod b$ 是唯一的，就可以问「$(a+b) \bmod c$ 等于多少」「$a^2 \bmod c$ 等于多少」，同余理论就此展开。

## 5 竞赛视角：整除判定与数位

整除性在竞赛里最常见的形态是**数位问题**与**表达式整除**。

**例 1（数位）**：证明 $2^{n+2} + 3^{n+2}$ 被……不行，先看更经典的：求所有正整数 $n$，使 $n^2 + 1$ 能被 $n+1$ 整除。

用「降次」思路：$n^2 + 1 = (n+1)(n-1) + 2$。所以 $n+1 \mid n^2+1$ 当且仅当 $n+1 \mid 2$。于是 $n+1 \in \{1,2\}$，$n \in \{0,1\}$，正整数解 $n=1$。<span class="marginnote">「把分子写成除数的倍数加余数」是整除题的默认手法：$f(x) = q(x)\cdot(x-a) + r$，于是 $x-a \mid f(x) \iff x-a \mid r$。被除式除以除式的「余数」往往是常数或低次式，整除条件瞬间变小。</span>

**例 2（余数判定）**：证明 $n^3 - n$ 能被 $6$ 整除，对所有整数 $n$ 成立。

$n^3 - n = n(n-1)(n+1)$——三个连续整数之积。三个连续整数中必有一个被 $3$ 整除，至少一个被 $2$ 整除，故乘积被 $6$ 整除。**「连续整数乘积」的整除结论，是数论竞赛的第一招杀手锏**：$n$ 个连续整数之积被 $n!$ 整除。

**心法：整除题四问**——① 能写成「除数 × 商 + 余数」吗？（降次）② 能分解因式找连续因子吗？③ 能转成模运算分类吗？（下节同余）④ 有「平方数余数」限制吗？

### 补充：裴蜀定理与逆元的求法

**裴蜀定理（Bézout's identity）**：$\gcd(a,b) = d$ 时，存在整数 $x,y$ 使 $ax + by = d$。特别地，$a,b$ 互素时存在 $x,y$ 使 $ax+by=1$。

**求 $x,y$ 的实用方法——扩展欧几里得**：在辗转相除的同时记录系数。例：求 $x,y$ 使 $47x + 30y = 1$。

$$47 = 1\cdot30 + 17, \quad 30 = 1\cdot17 + 13, \quad 17 = 1\cdot13 + 4, \quad 13 = 3\cdot4 + 1$$

回溯：$1 = 13 - 3\cdot4 = 13 - 3(17-13) = 4\cdot13 - 3\cdot17 = 4(30-17) - 3\cdot17 = 4\cdot30 - 7\cdot17 = 4\cdot30 - 7(47-30) = 11\cdot30 - 7\cdot47$

故 $x = -7, y = 11$，验证 $-7\times47 + 11\times30 = -329 + 330 = 1$。<span class="marginnote">扩展欧几里得的回溯过程就是「把余数代回」，直到表达成 $a,b$ 的线性组合。它也是下一节《同余》里「求逆元」的唯一标准算法：$ax\equiv1\pmod m$ 的逆元 $x$ 正是 $ax+my=1$ 的解。</span>

**求逆元例**：求 $47$ 模 $30$ 的逆元。由上面的 $47\cdot(-7) \equiv 1 \pmod{30}$（$30$ 的倍数被模掉），故 $47$ 模 $30$ 的逆元是 $-7 \equiv 23 \pmod{30}$。**逆元往往是负的，转成正的用「加模数」：$-7+30=23$。**

**心法：见「存在整数 $x,y$ 使 $ax+by=c$」先问 $c$ 是不是 $\gcd(a,b)$ 的倍数**——是则有解，否绝无解；有解时通解为 $x=x_0+\frac{b}{d}t$、$y=y_0-\frac{a}{d}t$。这一套「裴蜀判据 + 扩展欧几里得」在《不定方程》一节还会完整登场。

## 6 小结

- **整除** $a \mid b$：定义、传递性、线性组合、有界性、交错性；注意 $0$ 的约定。
- **带余除法**：$a = bq + r$（$0 \le r \lt  b$），商余唯一；是余数与分类的基础。
- **平方数模性质**：$n^2 \bmod 4 \in \{0,1\}$、$\bmod 8 \in \{0,1,4\}$、$\bmod 3 \in \{0,1\}$。
- **辗转相除法**：$\gcd(a,b)=\gcd(b, a\bmod b)$；最后非零余数即最大公因数。
- **裴蜀定理**：$\gcd(a,b) = ax+by$；互素即存在 $x,y$ 使 $ax+by=1$
