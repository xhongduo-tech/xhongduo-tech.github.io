## 为什么从函数方程与迭代开始

普通方程解的是「数」，**函数方程**解的是「函数」——未知量是一个映射，已知条件是一族恒等式。这是竞赛数学里最「高阶」的代数题型之一，因为它同时考验三件事：对函数结构的想象力、代换的技巧、以及归纳与极限的功底。<span class="marginnote">函数方程的第一道坎是「敢猜」：先猜出 $f(x)=x$、$f(x)=kx$、$f(x)=x^2$ 这类候选解，再证明没有别的。猜，在数学里从来不是丢人的事。</span>

**迭代（iteration）**则是把函数作用在自身上的过程：$f(f(x)), f(f(f(x))), \dots$。它既出现在函数方程里（用迭代产生新等式），也独立成题（求迭代函数、找周期、研究不动点）。这两块内容紧密相连：函数方程往往靠迭代「繁殖」出足够多的信息，而迭代的规律又常常由函数方程的线性/平移结构决定。它们共同构成了竞赛代数从「静态等式」迈向「动态过程」的关键一跃。

## 1 函数方程的基本方法

**函数方程（functional equation）**：未知量是函数、条件是恒等式的方程。例如「求所有满足 $f(x+y)=f(x)+f(y)$ 的函数 $f:\mathbb{R}\to\mathbb{R}$」就是一个函数方程。解它，不是求某个数，而是求出**所有**符合条件的函数。

解函数方程的第一板斧是**代值**——把特殊值代入，榨出函数在这些点的值：

**代入 $x=y=0$**：$f(0) = f(0) + f(0)$，得 $f(0)=0$。
**代入 $y=-x$**：$f(0) = f(x) + f(-x)$，得 $f(-x) = -f(x)$，即 $f$ 是奇函数。
**代入 $x=y$**：$f(2x) = 2f(x)$；迭代地，$f(nx) = nf(x)$ 对正整数 $n$ 成立。

第二板斧是**换元**：把式中的变量替换成别的量，制造「两个等式相减」的机会。例如在 $f(xy) = f(x) + f(y)$（对数型方程）里，固定 $y$ 换 $x \mapsto xy$，得到新的等式与旧等式比较，常能逼出 $f$ 的具体形态。

第三板斧是**假设连续/单调**：竞赛题常附带「$f$ 在 $\mathbb{R}$ 上连续」或「单调」的条件——它们是把「有理数点上的值」推广到「全部实数」的桥梁。没有这个条件，柯西方程会有病态解，这一点我们在下一节专门讲。

**辨析｜易错点：** 函数方程要求的是「所有解」，找到一个解不算做完。写出候选解后，必须**代回原方程验证**，并说明「唯一性」——先证「任意解必长这样」，再证「长这样的确实满足」。

## 2 柯西方程与四胞胎

最重要的函数方程是**柯西方程**：

$$f(x+y) = f(x) + f(y), \qquad x,y \in \mathbb{R}$$

在「连续」或「单调」的假设下，它的解只有一种形态：$f(x) = cx$，其中 $c = f(1)$。<span class="marginnote">证明路线：先用代值法证 $f(q)=cq$ 对一切有理数 $q$ 成立，再用连续性把无理数点「夹逼」出来。若缺少连续性，利用选择公理可构造「非正常解」——这在高等数学里叫 Hamel 基病态解，竞赛里不讨论。</span>

由柯西方程可以繁衍出「四胞胎」——四个结构相似、解法相同的经典方程：

| 方程 | 形态条件 | 连续解 |
| --- | --- | --- |
| $f(x+y)=f(x)+f(y)$ | 加法 | $f(x)=cx$ |
| $f(x+y)=f(x)f(y)$ | 加法→乘法 | $f(x)=a^x$（$a=f(1)>0$） |
| $f(xy)=f(x)+f(y)$ | 乘法→加法 | $f(x)=c\ln x$ |
| $f(xy)=f(x)f(y)$ | 乘法 | $f(x)=x^c$ |

**重点：四胞胎的关键是「变形」**。$f(x+y)=f(x)f(y)$ 两端取对数就变成加法方程；$f(xy)=f(x)+f(y)$ 令 $x=e^u$ 也回到加法方程。认出结构、做代换，是解函数方程最重要的元技能。

## 3 迭代、不动点与周期

**迭代（iterate）**：$f$ 作用 $n$ 次记作 $f^{\,n}$，即 $f^{\,n}(x) = \underbrace{f(f(\cdots f(x)\cdots))}_{n\text{ 次}}$。<span class="marginnote">注意 $f^{-1}$ 在迭代记号下是「逆映射」还是「负一次迭代」，两种记法在竞赛里都出现过——读题时先确认记号约定，避免歧义。</span>

与迭代绑定的两个概念：

**不动点（fixed point）**：满足 $f(x_0) = x_0$ 的点。不动点之所以重要，是因为它在迭代下**永不改变**：若 $f(x_0)=x_0$，则 $f^{\,n}(x_0)=x_0$ 对所有 $n$ 成立。求不动点只需解方程 $f(x)=x$，而许多函数方程题的关键，正是先找出不动点再围绕它展开。

**周期（period）**：若存在 $T>0$ 使 $f(x+T)=f(x)$ 恒成立，则 $f$ 是周期函数，$T$ 是周期。迭代与周期结合的一个经典结论：若 $f(f(x)) = x$（$f$ 是自身的逆，称为**对合**），则 $f$ 的图形关于直线 $y=x$ 对称。

对合是迭代里最迷人的结构：$f(x) = -x$、$f(x) = \frac{1}{x}$、$f(x) = \frac{1}{1-x}$ 都是对合或三阶循环。研究这类「有限阶迭代」，核心工具是**算它的阶**：$f^{\,2}=\mathrm{id}$ 是二阶，$f^{\,3}=\mathrm{id}$ 是三阶。阶数一确定，函数的整体形状就被锁死了。

## 4 公式解析：线性分式迭代的标准套路

竞赛里出现频率最高的迭代对象是**线性分式变换**：

$$f(x) = \frac{ax+b}{cx+d}, \qquad ad-bc \ne 0$$

它对应矩阵 $M = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$，而**复合迭代对应矩阵乘法**：$f \circ g$ 对应的矩阵是 $M_f M_g$。这是「用线性代数解函数迭代」的核心机制。

- **第一步，翻译**：把 $f$ 写成矩阵，迭代 $f^{\,n}$ 就变成矩阵幂 $M^n$。
- **第二步，对角化**：求 $M$ 的特征值 $\lambda_1, \lambda_2$。若相异，$M^n$ 有闭式表达式——这正是「迭代 $n$ 次后长什么样」的答案。
- **第三步，回译**：把 $M^n$ 写回分式形式，就得到 $f^{\,n}(x)$ 的显式公式。
- **第四步，特殊情形**：若 $\lambda_1 = \lambda_2$（重根），矩阵不可对角化，此时 $f^{\,n}(x)$ 含「线性项」，需另用待定系数或共形变换处理。

<span class="marginnote">「函数 ↔ 矩阵」的翻译不是偶然：线性分式变换作用于复平面上的广义圆，正好构成射影线性群 $\mathrm{PGL}(2,\mathbb{C})$。到第二级《线性代数》与《抽象代数》，这条「几何变换 = 矩阵群作用」的主线会被完整展开。</span>

**辨析｜易错点：** 矩阵 $M$ 与 $kM$（$k\ne0$）对应同一个分式变换，所以矩阵表示不唯一。求特征值时无论用哪个表示，特征值的**比**不变，迭代的闭式也一致。**别把矩阵的「缩放」当作「不同的函数」。**

## 5 竞赛视角：构造与反推

函数方程题最考验「构造能力」。看一道典型题：

**例**：求所有满足 $f(x) + f\left(\frac{1}{x}\right) = x + \frac{1}{x}$（$x\ne0$）的函数 $f:\mathbb{R}\setminus\{0\}\to\mathbb{R}$。

把 $x$ 换成 $\frac{1}{x}$，得第二个等式：

$$f\left(\frac{1}{x}\right) + f(x) = \frac{1}{x} + x$$

咦——两个等式一模一样！这说明题目给的信息是「自洽但不足」的：任何满足 $f(x) = \frac12\left(x + \frac1x\right) + g(x)$ 且 $g(x) = -g\left(\frac1x\right)$ 的函数都是解。**解不唯一**，因为函数方程的解空间可以很大。<span class="marginnote">「方程个数 vs 未知量自由度」的直觉在这里重现：一个函数方程未必唯一确定一个函数。竞赛里「求出所有满足……的函数」的题，答案有时是一个族，这时要用通解 + 自由函数的形式表达。</span>

**构造反例**也是竞赛常考的能力：给你一个「看起来对」的解答，让你指出漏洞。例如有人声称「$f(x+y)=f(x)+f(y)$ 的解只有 $f(x)=cx$」，却没提连续性——那么 $f(x)=x$ 在有理数上成立、在无理数上任意「线性」（借助 Hamel 基）的函数就是反例。**读题时盯住条件清单：函数方程几乎从不单独出现，它总带着「连续」「单调」「有界」之类的紧箍咒。**

### 补充：两类高频函数方程的完整解法

**例 1（柯西型）**：求所有满足 $f(x+y) = f(x) + f(y)$ 且「在 $x=0$ 处连续」的函数 $f:\mathbb{R}\to\mathbb{R}$。

**第一步，整数**：由 $f(2x)=2f(x)$ 反复，$f(n)=nf(1)$ 对整数 $n$ 成立。
**第二步，有理数**：$f(\frac1n) = \frac{f(1)}{n}$（因为 $f(1) = f(\frac1n + \cdots + \frac1n) = nf(\frac1n)$），故 $f(\frac mn) = \frac mn f(1)$。
**第三步，实数**：任取无理数 $x$，取有理数列 $q_k \to x$，由连续性 $f(x) = \lim f(q_k) = \lim q_k f(1) = x f(1)$。
**第四步，结论**：$f(x) = cx$（$c=f(1)$）。**「整数 → 有理数 → 实数」的三级跳，是柯西方程的完整剧本，连续性在最后一级才出场。**

**例 2（对合型）**：求所有满足 $f(f(x)) = x$ 且 $f(x+y)=f(x)+f(y)$ 的函数。由例 1 知 $f(x)=cx$，代入 $f(f(x))=c^2x=x$ 得 $c^2=1$，$c=\pm1$。于是 $f(x)=x$ 或 $f(x)=-x$。<span class="marginnote">「先求通解，再代入附加条件定参数」是函数方程的标准收尾：附加条件（对合、周期、单调）的作用是把「一个函数族」筛选成「具体几个函数」。</span>

**例 3（递推变体）**：求满足 $f(x) = 1 + x f(x-1)$（$x$ 为整数）且 $f(1)=1$ 的函数值 $f(n)$。

这是「递推式函数方程」：$f(n) = 1 + n f(n-1)$，迭代得 $f(n) = 1 + n + n(n-1) + n(n-1)(n-2) + \cdots + n!$（到 $f(1)=1$ 为止）——它本质是「不完全阶乘和」。**函数方程与递推在离散情形完全互通：函数方程管连续、递推管离散，方法互相借用。**

## 6 小结

- 函数方程解的是**函数**而非数；三板斧：**代值、换元、设连续/单调**。
- **柯西方程** $f(x+y)=f(x)+f(y)$ 及其四胞胎，是函数方程的「总开关」。
- **迭代**把函数作用在自身上；**不动点**在迭代下不变，是解方程与迭代的钥匙。
- 线性分式变换 ↔ **矩阵**，迭代 $n$ 次 = 矩阵 $n$
