## 为什么从 X 射线源开始

前面四节我们建立了描述晶体与衍射的数学框架：点阵、对称、空间群、倒易点阵。但衍射实验是**物理实验**——需要有光。X 射线从哪来？它有什么样的波长与强度？怎么把「能用的光」挑出来？这些问题决定了一张衍射图的质量，也决定了实验的可行性。

本节讲三大光源与一道关键工序：**X 射线管（特性辐射）、同步辐射、滤波（单色化）**。Massa 把这章放在理论之前，用意很清楚：理解光源，才能理解为什么衍射数据长成那样，也才能理解为什么同步辐射能测蛋白、能解一般晶体测不了的结构。<span class="marginnote">X 射线波长约 0.1–3 Å，与原子间距同量级——这正是它能「看见」原子排列的原因。可见光波长 4000–7000 Å，比原子间距大三个量级，所以光学显微镜永远看不到原子；而 X 射线波长与晶面间距匹配，才发生 Bragg 衍射。</span>

## 1 密封 X 射线管：最经典的实验室光源

实验室最常见的 X 射线源是**密封 X 射线管（sealed X-ray tube）**。它的构造像一个特殊的高压真空二极管：

**阴极**：钨丝加热发射热电子。
**阳极（靶）**：通常是铜（Cu）、钼（Mo）或银（Ag）等金属块，承受高压电子轰击。
- 电子在高压（通常 40–50 kV）加速下撞击靶面，被减速并产生两种辐射（见下节）。

**转靶 X 射线源（rotating anode）** 是它的增强版：阳极做成高速旋转的圆筒，把电子束的烧蚀分散到整个圆周，从而承受更高的功率（可达 18 kW 甚至更高），亮度比密封管高一个量级以上——现代实验室单晶衍射仪多用转靶或微焦斑源。<span class="marginnote">微焦斑源（microfocus source）是近年的主流：把焦斑从毫米级缩到几十微米，配合多层膜镜聚焦，在桌面级功率下达到接近转靶的亮度。蛋白质晶体学小晶体（几十微米）也能测——这是「实验室蛋白质晶体学」兴起的硬件基础。</span>

X 射线管产生的辐射包含两种成分，下面的公式解析会仔细拆。

## 2 特性辐射：原子内层的指纹

**特性辐射（characteristic radiation）** 是 X 射线管里最有用的成分。高速电子把靶材原子内层（K 层）的电子击出，外层电子（L 或 M 层）跃迁回填空位，同时发射光子。因为能级差是原子特有的，发射的光子波长也是特有的——故称「特性」。

**Kα 线**：L 层电子跃迁到 K 层，通常是最强线。Kα 实际是一对靠得很近的线：$Kα_1$ 与 $Kα_2$（对应 L 层两个精细能级），波长差很小，很多实验当一条用。
**Kβ 线**：M 层电子跃迁到 K 层，波长更短、强度约为 Kα 的 1/5。
- 对铜靶，$Kα$ 波长约 1.5418 Å；对钼靶约 0.7107 Å；对银靶约 0.5608 Å。

这些数值由莫塞莱定律（Moseley's law）决定：$\sqrt{\nu} \propto (Z - \sigma)$，X 射线频率的平方根与原子序数近似成正比——靶越重，特征 X 射线波长越短。<span class="marginnote">为什么选铜靶还是钼靶？看样品与实验目的：铜靶波长短于大多数过渡金属的吸收边，但会被含铁、含钴样品强烈吸收（荧光背景）；钼靶波长更短、穿透更深，适合大分子与高吸收样品；银靶最短，适合高压与极小样品。选靶是一场「波长 vs 吸收」的权衡。</span>

## 3 韧致辐射与滤波

**韧致辐射（bremsstrahlung，德语「制动辐射」）** 是高速电子被靶核库仑场急剧减速时发出的连续谱辐射。它从某个最短波长（对应电子全部动能转为光子，$\lambda_{\min} = hc/(eV)$）一直延伸到长波方向，构成背景。

连续谱对衍射实验基本无用（会模糊衍射斑点），所以必须**滤波或单色化**。三种常见办法：

**Kβ 滤波片（β filter）**：在光路上放一片吸收边恰好在 Kα 与 Kβ 之间的金属箔（如铜靶配镍箔）。它强烈吸收 Kβ，而 Kα 透过率高，把 Kα/Kβ 比从约 5:1 提到 500:1。<span class="marginnote">选滤波片的经验法则：滤波片的原子序数比靶小 1 或 2（铜靶 Z=29 配镍 Z=28，钼靶 Z=42 配锆 Z=40）。它的 K 吸收边正好落在靶的 Kα 与 Kβ 之间——Kβ 被吃光，Kα 幸存。</span>

**晶体单色器（monochromator）**：用一块石墨或锗晶体按 Bragg 条件把单一波长的 X 射线反射出来。单色性远好于滤波片，是现代衍射仪的标准配置。

**能量分辨探测器**：现代半导体探测器（如硅漂移探测器）能按能量分辨光子，直接软件上剔除 Kβ 与荧光——滤波片在高端实验里正在被取代。

## 4 同步辐射：第四代光源的威力

**同步辐射（synchrotron radiation）** 是相对论电子在磁场中偏转时发出的电磁辐射。电子在同步加速器或储存环中做圆周运动，沿切线方向辐射出从红外到硬 X 射线的连续光谱。它有几个令实验室光源望尘莫及的优点：

**高亮度**：比转靶高 6–10 个数量级。
**可调谐**：用单色器任选波长——这对反常散射（第5篇多波长定相）至关重要。
- **准直性好**：光束发散极小，可聚焦到微米级。
- **脉冲结构**：天然的时间结构，可用于时间分辨实验。

第四代光源（自由电子激光 XFEL）更进一步，能产生飞秒级、相干性极高的 X 射线脉冲，实现了「衍射前样品就被辐射损伤」的时间尺度测量——这就是单颗粒衍射与时间分辨晶体学的前沿。<span class="marginnote">中国上海光源（SSRF）、北京高能同步辐射光源（HEPS）、欧洲 ESRF、美国 APS、日本 SPring-8 都是国际知名的同步辐射设施。蛋白质晶体学里「去同步辐射线站测数据」几乎是复杂结构测定的必经之路。</span>

同步辐射的光谱是**连续的**（类似黑体但红移压缩到 X 射线区），配合单色器任选波长，还能做**能量扫描**——这正是反常散射（利用原子吸收边的共振增强）的数据基础。

## 5 公式解析：最短波长与莫塞莱定律

两条公式决定了 X 射线源的「边界」。第一条，韧致辐射的最短波长：

$$\lambda_{\min} = \frac{hc}{eV}$$

拆解：

- **第一步，物理图像**：一个电子被加速电压 $V$ 加速，动能 $E = eV$。若它把全部动能一次性交给一个光子，光子能量 $h\nu = eV$。
- **第二步，波长转化**：由 $\nu = c/\lambda$，$hc/\lambda = eV$，解得 $\lambda = hc/(eV)$。
- **第三步，代数量级**：$hc ≈ 1.24\ \mathrm{keV·nm}$，$e = 1$（以 keV 为单位时），所以 $\lambda_{\min}[\mathrm{nm}] ≈ 1.24/V[\mathrm{kV}]$。50 kV 高压下最短波长约 0.25 Å——连续谱从这里开始向长波延伸。<span class="marginnote">这条公式说明：提高管电压能把连续谱推向更短波长，但特性线（如 Cu Kα 1.54 Å）的位置由靶材能级决定、不随电压变。所以选波长靠选靶，选强度上限靠调电压。</span>

第二条，**莫塞莱定律**：

$$\sqrt{\nu_{Kα}} = C(Z - \sigma)$$

拆解：

- **第一步，现象**：Kα 频率的平方根随原子序数线性增大——靶越重，特性线频率越高、波长越短。
- **第二步，常数**：$C$ 与 $σ$ 是经验常数（对 Kα，$σ ≈ 1$，$C$ 由里德伯常数等决定）。这反映了内层电子的屏蔽效应：有效核电荷 $Z - σ$ 决定能级大小。
- **第三步，意义**：莫塞莱定律在 1913–1914 年首次确立了「原子序数」这一概念，也为选靶提供了定量依据：知道靶材的 $Z$，就知道它的 Kα 波长落在哪里。<span class="marginnote">莫塞莱定律还有一个重要的「副作用」：它预言了元素周期表按原子序数而非原子量排列——这修正了门捷列夫表里按原子量排的错位（如 Ni 与 Co），是现代元素周期表的基础之一。</span>

## 6 如何选择合适的光源

选光源是实验设计的第一步。几个判断维度：

| 考虑因素 | 实验室（转靶/微焦斑） | 同步辐射 |
| --- | --- | --- |
| 样品尺寸 | 需 ≥ 50–100 μm 单晶 | 可测 1–50 μm 微晶 |
| 波长选择 | 固定（Cu/Mo/Ag 靶） | 连续可调 |
| 数据收集时间 | 分钟–小时 | 秒–分钟 |
| 辐射损伤 | 较低 | 高（需低温/分片收集） |
| 典型应用 | 常规小分子结构 | 蛋白质、微晶、反常散射 |

**Massa 的忠告**：先想清「我要测什么结构」，再选光源与波长。测常规配位化合物，实验室铜靶 + 转靶足够；测蛋白质或需要反常散射定相，则必须同步辐射。<span class="marginnote">晶体学的一条经验规则：若晶胞边长超 60–80 Å（大分子），实验室光源的倒易点太密、难以分辨，必须用同步辐射的短波长 + 高准直来分开相邻衍射点。晶胞越大，对光源亮度的要求越高。</span>

## 7 辨析｜易错点：特性线 vs 连续谱

**辨析｜易错点：** 最常混淆的是这两者：

**特性辐射**：离散线谱，波长由靶材决定，是衍射实验「正主」。
**韧致辐射**：连续谱，波长连续分布，是「噪声」，必须滤除或单色化。

另外两处高频错误：

- **Kα 与 Kβ 混淆**：Kα 波长更长、强度更强；Kβ 波长更短、强度弱。滤波片的任务是压掉 Kβ，让 Kα 近乎单色。
- **误以为电压改变波长**：改变管电压只改变强度与最短波长，不改变特性线波长（由靶材能级固定）。要换波长只能换靶。<span class="marginnote">还有一个物理直觉值得建立：X 射线管效率极低——约 99% 的能量变成热，只有约 1% 变成 X 射线。所以转靶必须高速旋转散热，微焦斑靠小焦斑集中功率。理解「产热」才能真正理解 X 射线管的设计。</span>

## 8 小结

- **密封 X 射线管**与**转靶**是实验室常规光源；微焦斑源让桌面级蛋白质晶体学成为可能。
- **特性辐射**是内层电子跃迁的指纹谱，$Kα_1/Kα_2$ 最强、$Kβ$ 较弱；波长由靶材（Cu/Mo/Ag）决定。
- **韧致辐射**是连续背景谱，必须用滤波片、单色器或能量分辨探测器清除。
- **同步辐射**亮度高、波长可调、准直佳，是蛋白质晶体学与反常散射的标配。
- 最短波长 $\lambda_{\min} = hc/(eV)$；莫塞莱定律 $\sqrt{\nu} = C(Z-\sigma)$ 给出特性线位置。
- 选光源：常规样品用实验室转靶，微晶/蛋白质/反常散射用同步辐射。
