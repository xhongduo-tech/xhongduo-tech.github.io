## 为什么从倒易点阵继续

前三节都在实空间里描述晶体：点阵、晶胞、对称操作、空间群。但 X 射线衍射得到的是一张**衍射图样**——一张布满斑点的照片。斑点不是实空间原子的直接照片，而是晶体周期性在另一套坐标系里的投影。这套坐标系叫**倒易空间（reciprocal space）**，它的骨架就是**倒易点阵（reciprocal lattice）**。

倒易点阵是晶体学中最「反直觉」却最核心的工具：它把「晶面间距」变成「一个点」，把「衍射条件」变成「一个点在倒空间里的位置」，把「原子位置」变成「相位」。没有它，衍射几何寸步难行；有了它，整个衍射理论浓缩成一句话：**衍射图样 = 倒易点阵被 Ewald 球切出来的截面**。<span class="marginnote">倒易点阵的「倒」字源于量纲：它的轴长是实空间轴长的倒数（乘 $\lambda$）。这并非故弄玄虚——衍射测量的本来就是「周期」，而周期的倒数是频率；倒空间就是周期的「频率空间」。你在第一级傅里叶变换那里学到的直觉，在这里全部兑现。</span>

本节先定义倒易点阵，再导出它的几何意义，最后把它与 Ewald 球结合，讲清衍射发生的几何条件。

## 1 倒易点阵的定义

给定实空间三基矢 $\mathbf{a}$、$\mathbf{b}$、$\mathbf{c}$，定义倒空间三基矢 $\mathbf{a}^*$、$\mathbf{b}^*$、$\mathbf{c}^*$ 满足：

$$\mathbf{a}^* = \frac{\mathbf{b} \times \mathbf{c}}{V}, \qquad \mathbf{b}^* = \frac{\mathbf{c} \times \mathbf{a}}{V}, \qquad \mathbf{c}^* = \frac{\mathbf{a} \times \mathbf{b}}{V}$$

其中 $V = \mathbf{a}\cdot(\mathbf{b}\times\mathbf{c})$ 是晶胞体积。由这个定义立刻得到**正交关系**：

$$\mathbf{a}^* \cdot \mathbf{a} = 1, \quad \mathbf{a}^* \cdot \mathbf{b} = 0, \quad \mathbf{a}^* \cdot \mathbf{c} = 0 \qquad (\text{交叉项全为零})$$

倒易基矢 $\mathbf{a}^*$ 垂直于 $\mathbf{b}$ 与 $\mathbf{c}$ 张成的平面，长度为该平面方向「每单位长度一个周期」的倒数。由整数组合 $G = h\mathbf{a}^* + k\mathbf{b}^* + l\mathbf{c}^*$（$h,k,l$ 为整数）张成的点阵，就是**倒易点阵**。每个倒易点阵点对应一组整数 $(h,k,l)$——也就是一组晶面（Miller 指数）。<span class="marginnote">正交关系的含义：倒易点阵是实空间点阵的「对偶空间」——把实空间的平移周期映射成倒空间里整数指标。这与第一级《向量与空间解析几何》里的对偶基、以及线性代数里的正交补空间是一脉相承的。</span>

一个立刻可见的性质：实空间与倒空间互为倒数关系是**对称的**——倒易点阵的倒易点阵又回到实空间点阵。这说明晶体结构的信息在两边是等价的：实空间看原子，倒空间看衍射。

## 2 倒易点阵的几何意义：晶面变点

倒易点阵最漂亮的几何性质，是把一族晶面映射成一个倒易点：

**设一族晶面 $(hkl)$ 的面间距为 $d_{hkl}$，其法线方向为 $\mathbf{n}$，则倒易向量 $\mathbf{g}_{hkl} = h\mathbf{a}^* + k\mathbf{b}^* + l\mathbf{c}^*$ 垂直于这族晶面，且 $|\mathbf{g}_{hkl}| = 1/d_{hkl}$。**

这个定理是衍射几何的支柱。拆开看：

**方向对应**：$\mathbf{g}_{hkl}$ 的方向就是晶面族 $(hkl)$ 的法线方向——倒易点指向晶面法线。
**长度对应**：倒易点离原点的距离等于该晶面面间距的倒数。面间距越大，倒易点越靠近原点。<span class="marginnote">这解释了「倒易」的直观：密排面（大 $d$）对应靠近原点的倒易点，稀松面（小 $d$）对应远离原点的倒易点。低指数面间距大，落在倒空间中心附近——这正好是衍射图上靠近直射束的那些强斑点。</span>

对正交晶系，面间距公式简化为熟悉的 $1/d^2 = h^2/a^2 + k^2/b^2 + l^2/c^2$；对一般晶系，需要把倒易基矢的长度与夹角代入完整公式。倒易点阵的基矢长度按晶系不同而异，例如立方晶系 $|\mathbf{a}^*| = 1/a$，而六方晶系 $|\mathbf{a}^*| = 2/(a\sqrt{3})$。

## 3 Ewald 球：衍射的几何判据

有了倒易点阵，衍射条件可以写成极其优美的几何。考虑一束波长为 $\lambda$ 的 X 射线。定义**衍射向量** $\mathbf{s} = \mathbf{k} - \mathbf{k}_0$，其中 $\mathbf{k}_0$ 是入射波矢（$|\mathbf{k}_0| = 1/\lambda$），$\mathbf{k}$ 是散射波矢。

**衍射发生的条件**（Laue 方程）：

$$\mathbf{k} - \mathbf{k}_0 = \mathbf{g}_{hkl}，\qquad |\mathbf{k}| = |\mathbf{k}_0| = \frac{1}{\lambda}$$

这组条件说：**入射波矢与散射波矢之差，恰好等于某个倒易点阵向量**。几何画法如下——**Ewald 球（Ewald sphere / sphere of reflection）**：

1. 把倒易点阵放在空间中，取倒空间原点 $O$。
2. 以入射波矢 $\mathbf{k}_0$ 的终点为球心，$|\mathbf{k}_0| = 1/\lambda$ 为半径作球，让球面经过 $O$ 点。
3. **凡是落在球面上的倒易点 $\mathbf{g}$，就满足衍射条件**——从球心指向该点的方向就是衍射束方向。

于是「寻找衍射」变成「转动晶体，让倒易点扫过球面」。<span class="marginnote">Ewald 球半径 $1/\lambda$ 与波长有关：波长越短，球越大，切到的倒易点越多。这就是为什么同步辐射（短波、强光）能一次收集海量衍射数据——大球横扫更多倒易点。而电子衍射波长极短，Ewald 球近似为平面，衍射图样直接逼近倒易平面的截面。</span>

衍射几何因此一目了然：**衍射图样的每个斑点，都对应一个倒易点；整张图就是 Ewald 球扫过的倒易空间截面**。

## 4 劳厄条件与 Bragg 方程的等价

把向量方程 $\mathbf{k} - \mathbf{k}_0 = \mathbf{g}$ 取模平方，能直接导出 Bragg 方程。设入射角与晶面夹角为 $\theta$（掠射角），衍射角也是 $\theta$（镜面反射式衍射），有 $|\mathbf{k} - \mathbf{k}_0| = 2\sin\theta/\lambda$。代入 $|\mathbf{g}| = 1/d$：

$$\frac{2\sin\theta}{\lambda} = \frac{1}{d} \quad\Longrightarrow\quad 2d\sin\theta = n\lambda$$

**Bragg 方程**。这告诉我们一个深刻的等价：**Laue 向量条件 ⟺ Bragg 标量条件**。前者在倒空间里看，后者在实空间里看，两者描述的物理完全一致——X 射线被晶面族「反射」，只有满足 Bragg 角才相干叠加。我们在第2篇还会专节讲 Bragg 方程，这里先立住它与倒易点阵的桥梁。

从 Ewald 球看 Bragg 方程更清楚：倒易点落在球面上，等价于「晶面法线方向与入射方向成 $90° - \theta$」，也就是实空间里入射角等于掠射角 $\theta$。倒空间与实空间在此互相印证。<span class="marginnote">一个高频考点：为什么衍射用「反射」而不用「折射」？因为衍射发生在晶面族上，且只在 Bragg 角成立——它是多晶面相干叠加的结果，不是单面镜面反射。衍射方向由晶面族确定，强度由结构因子确定，两者分开。</span>

## 5 公式解析：倒易向量与面间距

把第 2 节的定理写成可计算的形式。对任意晶系，倒易向量 $\mathbf{g}_{hkl}$ 的模平方：

$$|\mathbf{g}_{hkl}|^2 = h^2|\mathbf{a}^*|^2 + k^2|\mathbf{b}^*|^2 + l^2|\mathbf{c}^*|^2 + 2hk\,\mathbf{a}^*\!\cdot\!\mathbf{b}^* + 2kl\,\mathbf{b}^*\!\cdot\!\mathbf{c}^* + 2lh\,\mathbf{c}^*\!\cdot\!\mathbf{a}^*$$

拆解这条公式：

- **第一步，认识形式**：这是一般的「平方展开」——类比 $|x\mathbf{u}+y\mathbf{v}|^2 = x^2|\mathbf{u}|^2 + y^2|\mathbf{v}|^2 + 2xy\,\mathbf{u}\cdot\mathbf{v}$，这里三基矢互相不正交，所以出现三个交叉项。
- **第二步，代入正交晶系**：正交晶系 $\mathbf{a}^*\cdot\mathbf{b}^* = 0$ 等交叉项全为零，$|\mathbf{a}^*| = 1/a$，于是退化为 $1/d^2 = h^2/a^2 + k^2/b^2 + l^2/c^2$——回到教科书里的标准公式。
- **第三步，意义**：$d_{hkl}$ 是一切衍射数据的「母量」：由 Bragg 方程 $2d\sin\theta = n\lambda$ 从衍射角反推 $d$，再与倒易点阵对照，就能指标化衍射点。倒易向量把「面间距」与「倒易点位置」焊在一起，使衍射数据处理可以直接用倒空间语言进行。<span class="marginnote">晶体学里习惯用 $d$ 值而不用 $\theta$ 报告衍射数据——因为 $d$ 与波长无关，是纯晶体的性质。PDF 数据库里每条物相条目都以 $d$ 值列表，正是这个原因。</span>

## 6 衍射几何：四种基本实验方式

倒易点阵 + Ewald 球不仅解释衍射，还直接设计实验。四种基本方式对应不同的「倒空间扫描」策略：

**劳厄法（Laue method）**：固定晶体，用连续波长 X 射线。Ewald 球半径连续变化（波长范围扫出半径区间），倒易点在一段球壳范围内被同时切到——适合快速定向与对称性测定。
**旋转法（rotation method）**：固定波长，绕一根轴旋转晶体，让倒易点依次扫过 Ewald 球。面探（CCD / 像素探测器）一次记录一层倒易面，是现代单晶衍射的基础。
- **粉末法（powder method）**：无数小晶粒取向随机，倒易点阵在所有方向上均匀分布——等效于把 Ewald 球「淹没」在球壳里，衍射退化为同心圆环。第4篇专讲。
- **前倾/进动法（precession method）**：晶体作进动运动，让倒易平面直接成像在底片上——经典的倒空间直接摄影，如今多被面探取代。

在现代面探仪器上，常用 **$\omega$ 扫描**（绕一根轴步进旋转）与 **$\varphi$ 扫描**，配合多轴测角仪，把倒空间半球逐层采集。<span class="marginnote">「倒空间覆盖度」是衍射实验质量的核心指标：完整覆盖 Ewald 球半球的独立倒易点越多，数据冗余度越高，结构解析越可靠。现代同步辐射线站能在几分钟内完成近全倒空间的覆盖。</span>

## 7 辨析｜易错点：实空间与倒空间的「倒」字

**辨析｜易错点：** 初学倒易点阵最易犯三个错：

**把倒易点当成「反点阵」**：倒易点阵的每个点不是原子位置，而是一族晶面的代表。倒易点的指标 $(h,k,l)$ 就是 Miller 指数。
**混淆晶面族 $(hkl)$ 与倒易点**：晶面族是实空间概念，倒易点是倒空间概念；二者通过「法线 + 面间距倒数」一一对应，但不是一个东西。
- **面间距公式张冠李戴**：$1/d^2 = h^2/a^2 + k^2/b^2 + l^2/c^2$ 只在**正交晶系**成立。单斜、三斜必须用完整公式（含交叉项），否则算出的 $d$ 值是错的——这是指标化错误的常见来源。<span class="marginnote">一个实用自查：对单斜晶系，$\mathbf{a}^*$ 与 $\mathbf{c}^*$ 的夹角是 $180° - \beta$，交叉项 $2hl\,\mathbf{a}^*\cdot\mathbf{c}^*$ 不能省略。许多初学者的指标化脚本因偷懒只写对角线项而失败。</span>

还有一个观念性易错：**Ewald 球里的球心不在倒空间原点**。球心在 $\mathbf{k}_0$ 的终点（即入射波矢终点），只有这一点让球面经过原点。误把球心当原点，衍射几何就全乱了。

## 8 小结

- **倒易点阵**由 $\mathbf{a}^* = (\mathbf{b}\times\mathbf{c})/V$ 等定义，满足 $\mathbf{a}^*\!\cdot\mathbf{a}=1$、交叉项为零。
- 倒易向量 $\mathbf{g}_{hkl}$ 垂直晶面族 $(hkl)$，且 $|\mathbf{g}_{hkl}| = 1/d_{hkl}$——晶面变点。
- 衍射条件 = **Laue 方程** $\mathbf{k}-\mathbf{k}_0 = \mathbf{g}$；几何上等价于倒易点落在 **Ewald 球**面上。
- Laue 向量条件 ⟺ **Bragg 方程** $2d\sin\theta = n\lambda$，两者等价、视角不同。
- 四种实验方式（劳厄、旋转、粉末、进动）对应不同的倒空间扫描策略。
- 面间距完整公式含交叉项；正交晶系才可简化为三项。

在下一节，我们离开几何，转向光源：**X 射线源：特性辐射、同步辐射与滤波**——衍射实验的第一束光从哪里来。
