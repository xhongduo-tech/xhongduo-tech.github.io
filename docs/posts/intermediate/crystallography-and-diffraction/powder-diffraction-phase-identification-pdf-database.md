## 为什么从物相鉴定继续

上一节建立了粉末衍射的几何与实验基础。现在进入它最广泛、最日常的应用：**物相鉴定（phase identification）**——「我的样品里到底有什么？」。

物相鉴定的原理朴素得像字典查词：每种晶体物相有一组特征 $d$ 值与相对强度，如同指纹。把样品的粉末谱与已知物相的标准谱比对，命中即识别。这套「指纹库」就是 **PDF（Powder Diffraction File）数据库**——由国际衍射数据中心（ICDD）维护，收录了几十万种物相的标准粉末数据。<span class="marginnote">物相鉴定是粉末衍射的「看家本领」：<strong>从地质矿物鉴定、水泥熟料分析，到电池电极失效分析、考古文物材质，都用同一招「谱图比对」</strong>。它的价值在工业界不可估量——因为「知道样品是什么」往往是解决一切问题的第一步。</span>

本节讲物相鉴定的原理、PDF 数据库的构成、以及检索匹配的方法与陷阱。

## 1 为什么粉末谱能当「指纹」

每种晶体物相的粉末谱由其晶胞参数与原子排布唯一决定：

**峰位置**（$2\theta$，即 $d$ 值）由晶胞参数决定——晶胞是物相的「身份证号」。
**峰相对强度**由结构因子（原子种类与位置）决定——同晶胞不同原子排布，强度不同。

两种物相（即使元素相同）若晶胞或原子排列不同，粉末谱必不同；反之，谱相同则几乎必是同一物相。这正是「粉末衍射指纹」的理论基础。<span class="marginnote">同素异构体/多晶型的区分是物相鉴定的经典场景：<strong>石墨与金刚石、锐钛矿与金红石（TiO₂）、α 石英与方石英——化学相同、物相不同，粉末谱判然有别</strong>。这也是药物多晶型鉴定的原理。</span>

但要注意：粉末谱是「一维投影」，不同物相可能**谱相似甚至重叠**（尤其峰多时）。所以鉴定不是「看像不像」，而是系统化比对（见第 3 节）。

## 2 PDF 数据库：指纹字典

**PDF（Powder Diffraction File）** 是 ICDD 维护的权威数据库，每条记录（PDF 卡片）含：

化学式、物相名、矿物名。
晶系、空间群、晶胞参数。
- 全部 $d$ 值、相对强度（$I/I_1$）、$hkl$ 指标。
- 来源文献、实验条件、质量标记。

PDF 数据库从 1938 年起积累，如今已含**几十万条**物相记录。现代 PDF 卡片还包含**完整图谱**（full pattern）数据，可直接用于 Rietveld 等全谱拟合的参考。<span class="marginnote">PDF 卡片的传统用法是「三强线检索」：<strong>取样品谱最强的三条峰（$d$ 值 + 相对强度），在数据库中找匹配的卡片</strong>——早期手工检索就这么做。现代计算机检索则比对整张谱（或前若干强峰），给出候选命中及匹配度评分。</span>

**ICDD 与数据库使用**：PDF 数据库需订阅（学术机构常备）。免费替代品有：ICSD（无机晶体结构数据库，含理论粉末谱）、Crystallography Open Database（COD）、美国矿物学家数据库等——理论上由结构数据可计算粉末谱，所以「结构数据库 → 理论粉末谱」是常用路径。

## 3 检索匹配：从峰到命中

现代物相鉴定流程（以 Bruker DIFFRAC.EVA、MDI Jade 等软件为例）：

1. **寻峰（peak search）**：软件自动找出谱中所有峰（位置 + 强度），按强度排序。
2. **检索**：把峰列表（$d$ 值 + 相对强度）与数据库比对，候选物相按匹配度（score）排序。
3. **人工核对**：看候选的**全部峰**是否都能在样品谱里找到（不止三强线）；强峰对得上、弱峰也要对得上才算真命中。
4. **逐步剔除**：一个物相确认后，从谱中扣除其贡献，再看剩余峰找下一个物相——多相混合逐相剥离。

**匹配度评分**：软件给出 FOM（figure of merit）、d 值误差等量化指标。评分高不保证正确——**必须人工核对「全峰覆盖」**。<span class="marginnote">鉴定的黄金规则：<strong>命中物相必须解释样品谱的「每一个峰」</strong>。若谱上还有强峰无法归属，说明还有未识别物相、或候选错误。反过来，若候选物相预测的强峰在样品谱里缺失，也要警惕——可能是择优取向、无定形、或检索错误。</span>

## 4 多相混合与定量分析

真实样品常是**多相混合物**（水泥、陶瓷、矿物、电池电极……）。物相鉴定给出「有哪些相」，更进一步的问题是「各占多少」——**定量相分析（quantitative phase analysis, QPA）**。

定量原理：混合物中某相的衍射强度正比于其质量分数。但直接正比受吸收、晶粒尺寸、择优取向影响。常用方法：

**RIR 法（Reference Intensity Ratio）**：用参考强度比（样品相与刚玉 α-Al₂O₃ 的强度比）校正吸收差异，做内标/外标定量。
**K 值法**：RIR 的工程化版本。
- **Rietveld 定量**：全谱拟合，把各相质量分数直接作为精修参数——现代首选（下下节展开）。
- **全谱拟合（Pawley/Le Bail）**：不依赖结构模型，纯数学分解峰重叠后再定量。<span class="marginnote">RIR 法的直觉：<strong>不同物相吸收 X 射线的能力不同，直接比强度会失真</strong>。RIR 用「该相强度 / 刚玉强度」的固有比值（查表或实测）把吸收差异归一化，从而由峰强度比反推质量比。精度一般 ±2–5%（Rietveld 可更好）。</span>

定量分析的可靠性前提：无择优取向、无微吸收差异（粗细晶粒吸收不同）、样品研磨充分、各相晶粒尺寸相近。制样规范决定定量成败。

## 5 公式解析：RIR 定量的基本关系

RIR 定量的核心关系把「峰强度比」与「质量分数」联系起来：

$$W_{\alpha} = \frac{I_{\alpha} / RIR_{\alpha}}{\sum_{j} I_j / RIR_j}$$

拆解这条式子：

- **第一步，$I_j$ 是各相的特征峰强度**：通常取各相的最强峰强度（扣除背景）。
- **第二步，$RIR_j$ 是参考强度比**：$RIR_j = I_j/I_{\text{corundum}}$（同条件下该相最强峰与刚玉最强峰之比），是物相的固有常数（查 PDF 卡或实测）。<span class="marginnote">RIR 的物理含义：<strong>它把「吸收能力不同」的物相拉到同一把尺上</strong>——某相吸收强、峰天然弱，RIR 大，除回去就把强度「复原」成质量份额。查不到 RIR 时需实测（同条件测该相纯样与刚玉）。</span>
**第三步，归一化求和**：分母对所有相求和，保证 $\sum W_j = 1$（忽略非晶时）。若样品含非晶相，$\sum W_j \lt  1$，可估算非晶含量——但此时需要内标。

**精度与局限**：RIR 法假设峰强度无择优取向、无微吸收；对强择优取向样品会严重失真。要求不高时是快速定量的利器；要求高时用 Rietveld。

## 6 物相鉴定的实战陷阱

物相鉴定看似「查字典」，实战里暗礁密布：

**峰重叠掩盖弱相**：少量次要相（< 1–5%）的峰被主相强峰淹没，鉴定漏相。
- **固溶体/非化学计量**：峰位置随组成漂移（如合金、掺杂氧化物），与标准卡片对不上——需要「d 值漂移」意识。
- **择优取向**：强取向使峰强度比失真，三强线检索会错配。
- **无定形相**：非晶背景无尖峰，鉴定只识别结晶相——非晶含量要用内标法定。
- **同型相混淆**：晶胞相近的物相（如某些尖晶石族）谱极相似，需结合元素分析/EDS 确认。<span class="marginnote">一个经验：<strong>鉴定的最终确认往往不是「谱图」，而是「谱图 + 元素组成」</strong>——先知道样品含哪些元素（XRF/EDS/ICP），再在候选物相里按元素筛选，能排除大量假命中。谱图比对 + 化学约束双保险，才是可靠的鉴定流程。</span>

## 7 辨析｜易错点：物相鉴定的五个坑

**辨析｜易错点：** 物相鉴定五个高频失误：

**只对三强线就下结论**：三强线命中 ≠ 物相正确。必须核对候选物相**全部强峰**都在样品谱里，弱峰也不冲突。
**忽略峰位置系统漂移**：样品高度误差、零点漂移会让所有峰整体平移，检索前先校正（内标或仪器校准）。
- **把 Kα₂ 峰当独立相峰**：Kα 双线分裂的伴峰被当新峰，误判出「新物相」。
- **择优取向导致的「假缺失」**：某物相因取向强导致某峰异常弱，被认为不存在。结合多个峰判断，别凭单一峰。
- **把「检索评分高」当「确认」**：评分高可能是巧合（尤其峰少时）。人工核对全峰覆盖 + 元素约束，才是确认。<span class="marginnote">工作流建议：<strong>先元素分析缩范围 → 检索 → 全峰核对 → 定量（RIR/Rietveld）</strong>。把鉴定当「侦探破案」而不是「查字典」，漏相、错配的概率就大大降低。这套流程在工业实验室里每天都在跑，是一台真正的「材料体检仪」。</span>

## 8 数据库的质量标记与检索的「坑」

PDF 数据库不是「越全越好」——每条卡片的**质量标记**决定你可信它到什么程度：

**质量标记（quality mark）**：ICDD 给每条记录标质量（如 * 优秀、I 良好、O 一般、C 计算）。高标记卡片来自实验验证、结构已知；低标记（尤其「计算」）可能含误差。
**来源**：实验测量（可靠但受样品影响）vs 理论计算（由结构数据算出，准确但依赖结构正确）。
- **版本**：数据库随年份更新，同一条目不同版本可能修正过 d 值或强度——引用时注明数据库版本。

检索时的经典「坑」：**近同型物相的区分**——晶胞相近的物相（如某些同构尖晶石、掺杂固溶体）粉末谱几乎重合，数据库给出多个高评分候选。<span class="marginnote">对策：<strong>用「元素约束 + 晶格约束」把候选列表收窄</strong>——结合 EDS/XRF 的元素组成、已知晶系/晶胞（可先粗指标化），候选往往只剩一两个，再靠全峰核对定案。数据库是「工具」，把工具用对才算鉴定成功。</span>

**开放替代**：ICSD、COD、Materials Project 等提供由结构计算的理论粉末谱，可以互补 PDF——结构数据库的谱更「干净」（无实验噪声），适合指标化与 Rietveld 参考。

## 9 小结

- **物相鉴定** = 粉末谱「指纹」与 **PDF 数据库**标准谱比对；峰位给晶胞、强度给结构。
- **PDF 数据库**（ICDD）含几十万条物相记录；免费替代有 ICSD、COD。
- 检索流程：寻峰 → 检索 → 全峰核对 → 逐相剥离；评分高 ≠ 正确，全峰覆盖才算命中。
- **定量分析**：RIR/K 值法、全谱拟合、Rietveld；前提是无择优取向与微吸收。
- RIR 公式 $W_\alpha = (I_\alpha/RIR_\alpha)/\sum_j(I_j/RIR_j)$ 用参考强度比校正吸收差异。
- 陷阱：峰重叠漏相、固溶体漂移、择优取向、无定形、同型相混淆——配元素分析双保险。
