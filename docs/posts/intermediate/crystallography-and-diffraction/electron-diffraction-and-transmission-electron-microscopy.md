## 为什么从电子衍射继续

X 射线衍射测的是「平均结构」——X 射线穿深、样品必须是晶体、信息来自整个晶胞。但真实材料常常是**纳米颗粒、界面、缺陷、薄膜**——它们不是「大块晶体」，而是「局部的晶体」。要看清这些，需要把波长压到更短、把探针聚焦到更小。**电子**就是答案：电子的德布罗意波长是 X 射线的约千分之一，还能用电磁透镜轻松聚焦到纳米甚至亚埃尺度。

**透射电子显微镜（TEM）** 把电子衍射与实空间成像结合：既能拍出原子的像（高分辨 TEM），也能在同一区域打出电子衍射图（选区衍射 SAED）。它是材料科学家「既看形貌、又看晶体学」的万能显微镜。<span class="marginnote">电子的波长：<strong>加速电压 100 kV 时约 0.037 Å，300 kV 时约 0.0197 Å</strong>——比 Cu Kα（1.54 Å）短两个量级。短波长的直接后果（回忆 Ewald 球）：衍射球半径极大、倒易点阵「摊平」，衍射图样几乎就是倒易平面的直接投影——这让电子衍射的几何格外直观。</span>

本节讲电子的散射特性、电子衍射几何、TEM 的高分辨成像、以及电子晶体学的新进展。

## 1 电子与物质的相互作用：强散射的双刃剑

电子与物质作用远比 X 射线强（约强 10⁴–10⁶ 倍），这是把双刃剑：

**优点**：
灵敏度极高——极小体积（纳米立方）就能给出衍射。
可以在单个纳米颗粒、单个界面、单根纳米线上做衍射。
- 电子可聚焦成原子级探针（STEM 模式），做元素分析（EDS、EELS）。

**缺点**：
- 穿透力弱——样品必须极薄（< 100 nm，最好几十 nm）。
- 多重散射严重——动力学效应强，运动学近似（$I \propto |F|^2$）常失效。
- 样品损伤——高能电子辐照破坏结构（尤其有机物/生物样品）。<span class="marginnote">动力学散射的后果：<strong>电子衍射强度不能简单当作 $|F|^2$</strong>——多重散射让弱反射变强、强反射变弱，结构解析（若想定量）必须用动力学理论。这就是为什么「电子晶体学」在定量上比 X 射线难，但近年「三维电子衍射（3D ED）」靠运动学近似的修正已能解小分子结构。</span>

## 2 电子衍射几何：几乎「摊平」的 Ewald 球

因为电子波长极短，$1/\lambda$ 极大，Ewald 球半径极大——在倒易空间里，球面在原点附近**近似为一个平面**。这意味着：

**一束电子穿过单晶**，同时满足衍射条件的倒易点很多——衍射图样是倒易空间的一个**二维截面**（近似 Ewald 球切面）。
转动样品（倾转）时，衍射图样「像翻倒易平面」——这让电子衍射的几何解释非常直观。

**选区衍射（SAED）**：在 TEM 里插入选区光阑，只让样品上某一小区域（如 1 μm 或更小）的衍射通过——「选哪里、看哪里的晶体学」。这是 TEM 里最常用的晶体学操作。

**衍射点 vs 环**：单晶区给衍射点阵（二维倒易截面）；多晶区给同心环（粉末衍射的电子版，Debye 环）；非晶区给弥散环。

## 3 高分辨 TEM：直接「看见」原子

**高分辨透射电子显微术（HRTEM / HREM）** 让电子显微镜的分辨率达到亚埃，能直接拍出晶格条纹、甚至单原子像。原理：

- 物镜把样品下方衍射的电子束重新组合成实空间像。
- 相位差（电子束穿过样品时受晶格势调制）被转换为强度衬度。
- 当分辨率足以分辨晶面间距时，像上出现**晶格条纹（lattice fringes）**——间距等于晶面间距。

**HRTEM 像的解读要小心**：像上的「黑点/白点」并不直接等于原子——它们受**像差（球差）**、离焦量、样品厚度强烈影响。只有用模拟（multislice 计算）对照，才能把像「翻译」成原子排列。<span class="marginnote">「看得见」≠「直接读」：<strong>HRTEM 像必须靠像模拟（模拟 HRTEM 图像）才能可靠解释</strong>——同样的像可能对应不同的厚度/离焦组合。球差校正器（aberration corrector）的出现大幅改善了像的可靠性，让「原子直接可读」成为现实（如单原子成像）。</span>

**STEM（扫描透射）**：用会聚电子束逐点扫描样品，配合环形暗场（HAADF）探测器，可达到原子级 Z 衬度成像——重原子更亮，直接反映原子列的位置。搭配 EDS/EELS 还能做原子级元素分布。

## 4 三维电子衍射：粉末/纳米晶的新希望

传统电子衍射只能看二维截面，但近年兴起的**三维电子衍射（3D ED / MicroED）**改变了格局：

把纳米晶体连续倾转，采集一系列电子衍射图，重构出三维倒易空间。
用类似 X 射线单晶的方法（指标化、积分、直接法）解出结构。
- **优势**：可以测定 X 射线测不了的微小晶体（< 1 μm）——蛋白质微晶、MOF 纳米晶、共价有机框架（COF）等。

**MicroED**（蛋白质微晶三维电子衍射）尤其惊艳：用低剂量电子束 + 连续倾转，从亚微米蛋白质晶体解出原子级结构——2020 年代已产出多个重要结构。这是「电子晶体学」复兴的核心。<span class="marginnote">三维电子衍射的意义：<strong>它把「电子衍射 = 只能看花样」升级为「电子衍射 = 也能解结构」</strong>。对 X 射线束手无策的纳米晶/微晶（MOF、COF、蛋白质微晶），MicroED 提供了新通道。代价是动力学散射与辐射损伤的挑战，方法仍在快速发展。</span>

## 5 公式解析：电子波长与衍射几何

电子的德布罗意波长由加速电压决定（相对论修正）：

$$\lambda = \frac{h}{\sqrt{2 m_0 e V \left(1 + \frac{eV}{2m_0 c^2}\right)}}$$

拆解这条式子：

- **第一步，非相对论极限**：$eV \ll m_0c^2$ 时括号项 ≈ 1，$\lambda = h/\sqrt{2m_0eV}$——加速电压越高，波长越短（经典德布罗意关系）。
- **第二步，相对论修正**：电子在 kV 量级已显著相对论（100 kV 时动能/静能 ≈ 0.2），括号项把质量增加纳入，波长比非相对论值更短。
- **第三步，代数量级**：100 kV → 0.037 Å；200 kV → 0.025 Å；300 kV → 0.0197 Å。<span class="marginnote">一个实用换算：<strong>$\lambda[\text{Å}] \approx \sqrt{1.5 / V[\text{kV}]}$（非相对论近似）</strong>——200 kV 给约 0.027 Å，够快估算。衍射几何里 Ewald 球半径 $1/\lambda$ 极大，所以「球面 ≈ 平面」，衍射图近似倒易平面截面。</span>

## 6 电子衍射与 X 射线衍射的互补

电子与 X 射线各有所长，实际研究常互补使用：

| 特性 | X 射线衍射 | 电子衍射 |
| --- | --- | --- |
| 波长 | 0.5–2.5 Å | 0.02–0.04 Å |
| 散射强度 | 弱（运动学近似好） | 强（动力学效应明显） |
| 样品 | 大块晶体/粉末 | 极薄样品/纳米晶 |
| 空间分辨 | 宏观平均 | 纳米局域（选区/纳米束） |
| 结构定量 | 成熟（高精度） | 3D ED 新兴 |
| 成像 | 无（不聚焦） | HRTEM 直接成像 |

**典型配合**：先用 X 射线粉末衍射确认物相与整体结构，再用 TEM/电子衍射看形貌、晶粒取向、缺陷、纳米相分布。<span class="marginnote">一个常见误区：<strong>电子衍射「花样好看」不等于能定量定结构</strong>。看取向、看晶系、看单晶/多晶，电子衍射又快又直观；要精确键长、占有率，还是 X 射线（或 3D ED 精修）说了算。工具各有分工。</span>

## 7 辨析｜易错点：电子衍射的五个坑

**辨析｜易错点：** 电子衍射与 TEM 使用五个高频失误：

**把运动学强度当 $|F|^2$ 定量**：动力学散射让强度严重偏离，别用电子衍射强度直接做结构精修（除非用动力学理论/3D ED 专门处理）。
**样品太厚**：厚样品多重散射 + 吸收，衍射图浑浊、像模糊。制样（离子减薄/研磨/FIB）是 TEM 的功夫。
- **辐照损伤忽略**：电子束会破坏样品——尤其有机、生物、MOF 样品。低剂量模式 + 低温（cryo-EM）是标准对策。
- **像差/离焦误读**：HRTEM 像不直接等于原子排列，务必做像模拟对照。别「看着像原子就下结论」。
- **选区光阑选错区域**：SAED 的「选区」不是无限小——光阑边缘可能混入相邻区域，衍射图「不纯」。检查选区是否真的只在目标相上。<span class="marginnote">一个进阶提醒：<strong>电子衍射标定（确定衍射点对应的 $hkl$ 与晶带轴）要用相机常数校准</strong>——用标准样品（金、铝）标定相机长度，否则 $d$ 值会系统性偏差。这跟 X 射线粉末的仪器校准是同一件事。</span>

## 8 电子晶体学的历史轨迹

电子衍射的历史几乎与 X 射线晶体学一样长，但命运曲折：

**1927 年**：戴维森（C. Davisson）与革末（L. Germer）发现电子在镍晶体上的衍射——证明了电子的波动性（与德布罗意预言互相印证），共享 1937 年诺贝尔物理学奖。
**1930s–1970s**：电子衍射主要用作「花样分析」——看晶系、取向、多晶环，定性为主。
- **1980s–2000s**：高分辨 TEM 与像模拟成熟，HRTEM 成为材料微观结构「眼见为实」的主力；电子晶体学（用电子衍射解小结构）偶有突破但动力学散射是拦路虎。
- **2010s 至今**：三维电子衍射（3D ED / MicroED）与低剂量、连续倾转技术结合，让纳米晶/微晶（MOF、COF、蛋白质微晶）也能解出原子级结构——电子晶体学迎来复兴。<span class="marginnote">电子衍射「起起伏伏」的教训：<strong>方法的价值取决于「它解决了谁解决不了的问题」</strong>。X 射线垄断了「大晶体高精度」，电子衍射就深耕「小晶体、局域、成像」——直到 3D ED 把「小晶体解结构」也打开，电子衍射才从配角变成主角。</span>

理解这段历史，就能理解今天「X 射线 + 电子 + 中子」三足鼎立的格局：各有所长、各守边界、又在边界处互相渗透。

## 9 小结

- **电子衍射**：电子波长极短、Ewald 球近似平面，衍射图 = 倒易平面截面；选区衍射（SAED）看局域晶体学。
- **强散射是双刃剑**：灵敏度高、可测纳米晶，但穿透弱、动力学效应明显、易辐照损伤。
- **HRTEM** 亚埃分辨直接成像，但像需模拟对照；**STEM** 提供原子级 Z 衬度与元素分析。
- **三维电子衍射（3D ED / MicroED）**：从纳米晶解出三维结构，是电子晶体学的新方向。
- 电子波长 $\lambda = h/\sqrt{2m_0eV(1+eV/2m_0c^2)}$；100 kV ≈ 0.037 Å。
- 与 X 射线互补：X 射线管平均高精度，电子看局域与纳米晶。

在下一节，我们回到「看氢原子」的黄金标准：**中子衍射与氢原子位置测定**——一种看不见电子却看得见原子核的探针。
