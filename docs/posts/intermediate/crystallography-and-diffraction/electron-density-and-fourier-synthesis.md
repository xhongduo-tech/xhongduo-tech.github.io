## 为什么从电子密度继续

上一节我们把晶体学的一切收敛到一对傅里叶变换：**实空间的电子密度 $\rho(\mathbf{r})$ ⟷ 倒空间的结构因子 $F(\mathbf{h})$**。这一节把这层关系推到底——如果我们在实空间里把 $\rho$ 求出来，原子就现形了，结构就解出来了。

**电子密度（electron density）** 是单位体积内的电子数（单位 e⁻/Å³），它在原子核附近达到峰、在原子间几乎为零。晶体结构解析的终极目标，就是算出一张电子密度图，从峰的**位置**读出原子坐标、从峰的**高度**读出原子种类。而算出它的工具，正是**傅里叶合成（Fourier synthesis）**——把测到的衍射数据逐项叠加回实空间。<span class="marginnote">把「电子密度」当「原子影像」是最自然的直觉：<strong>电子密度图的高峰 = 原子的位置，峰高 ≈ 原子序数</strong>。看一张好的电子密度图，就能直接数出晶胞里有哪些原子、它们怎么连接——这是所有结构解析工作的「眼见为实」时刻。</span>

本节讲清傅里叶合成的公式、它为什么能重建电子密度、以及它的一切困难都浓缩在相角里。

## 1 电子密度是傅里叶级数

晶体的电子密度是**周期函数**（周期 = 晶胞平移），所以它可以展成三维傅里叶级数：

$$\rho(x,y,z) = \frac{1}{V} \sum_{h}\sum_{k}\sum_{l} F(hkl)\; e^{-2\pi i\,(hx+ky+lz)}$$

**电子密度 = 全部结构因子带相角后的复数叠加**。拆解这条公式：

- **第一步，$F(hkl)$ 是系数**：每个倒易点贡献一项，权重是它的结构因子（含振幅与相角）。
- **第二步，指数项是基函数**：$e^{-2\pi i(hx+ky+lz)}$ 是周期为 $1/h、1/k、1/l$（分数坐标单位）的正弦波。求和就是把这些波按 $F$ 加权叠加。
- **第三步，$1/V$ 是归一化**：保证积分 $\int_V \rho\,dV = $ 晶胞总电子数。<span class="marginnote">这公式与第一级《傅里叶变换》的「信号 = 各频率分量之和」完全同构：<strong>电子密度是「信号」，结构因子是它的「频谱」</strong>。衍射实验测频谱（振幅），傅里叶合成重建信号（密度）——无非多了一个维度与一个相角问题。</span>

实践中求和不可能到无穷，只取测得的那一批 $(hkl)$。截断越多，电子密度图越「糊」，分辨率越低。**分辨率 = 傅里叶级数截断到多高的频率**——这正好呼应上一节「$d_{\min}$ 决定分辨率」的结论。

## 2 相角：傅里叶合成的「拦路虎」

傅里叶合成需要**完整的复数 $F$**，但实验只给振幅 $|F|$。没有相角 $\phi$，每个基函数 $e^{-2\pi i(hx+ky+lz)}$ 前乘的因子 $F = |F|e^{i\phi}$ 就缺了一半——叠加出来的 $\rho$ 是错的。

这是晶体学一百年的核心困境，**相角问题（phase problem）**。它的严重性可以这样感受：把 $|F|$ 全测对、却把相角随机乱猜，合成的电子密度图会是「噪声」；把少数强反射的相角猜对、其余用弱反射的相角，图里已经能看出原子骨架。<span class="marginnote">相角比振幅「重」：经验上，$|F|$ 给到大致正确、$\phi$ 完全正确，密度图就相当干净；$|F|$ 精确、$\phi$ 随机，图完全无用。这也解释了为什么直接法、Patterson、重原子、分子置换等所有方法都把矛头对准相角。</span>

我们将在第3篇看到相角问题的几条解法：**Patterson 法**（用强度直接算自相关函数，不需要相角）、**直接法**（靠统计关系猜相角）、**重原子法 / 同晶置换**（用重原子的已知位置当「灯塔」推全部相角）、**反常散射**（利用 $f'$ 与 $f''$ 的共振信息）。本节先建立「差一点就能合成」的直觉。

## 3 傅里叶合成与差分傅里叶

有了初始相角（无论来自哪种方法），就能做第一版 $\rho(x,y,z)$ 合成。结构解析在精修阶段几乎每一步都在做**差分傅里叶（difference Fourier）**：

$$\Delta\rho(x,y,z) = \frac{1}{V}\sum_{\mathbf{h}} (|F_{\text{obs}}| - |F_{\text{calc}}|)\, e^{i\phi_{\text{calc}}}\; e^{-2\pi i\,\mathbf{h}\cdot\mathbf{r}}$$

其中 $|F_{\text{obs}}|$ 是实测振幅，$|F_{\text{calc}}|$ 与 $\phi_{\text{calc}}$ 由当前结构模型算出。拆解：

- **第一步，模型提供相角**：用当前模型算出的 $\phi_{\text{calc}}$ 代替未知真相角——这是所有精修的通用前提。
- **第二步，取振幅差**：$|F_{\text{obs}}| - |F_{\text{calc}}|$ 表示「模型与真实的差距」。模型某处多了电子（$F_{\text{calc}}$ 过大），$\Delta\rho$ 在该处为负；少了电子则为正。
- **第三步，正峰加原子、负峰删原子**：差分图上的正峰提示「这里还缺一个原子」，负峰提示「这里多放了一个原子」。结构精修里靠反复「算差分 → 修正模型 → 再算差分」逼近真实结构。<span class="marginnote">差分傅里叶是小分子结构解析最常用的「找氢工具」：把重原子位置精修后，$F_{\text{calc}}$ 已相当准，差分图上剩下的正峰往往就是氢原子——尤其当氢对强度贡献不可忽略时。</span>

## 4 公式解析：一维傅里叶合成的直观示范

用一维例子建立直觉。设沿 $x$ 方向周期为 1（分数坐标），只有三个结构因子：

$$F(0) = 2, \qquad F(1) = 1, \qquad F(-1) = 1$$

则电子密度为：

$$\rho(x) = \frac{1}{V}\left[2 + 1\cdot e^{-2\pi i x} + 1\cdot e^{+2\pi i x}\right] = \frac{1}{V}\left[2 + 2\cos(2\pi x)\right]$$

逐项拆解：

- **第一步，合并共轭项**：$F(1)e^{-2\pi ix} + F(-1)e^{2\pi ix}$，若 $F(1)=F(-1)=1$，利用 $e^{iθ}+e^{-iθ}=2\cos θ$，合并成 $2\cos(2\pi x)$。
- **第二步，读出形状**：$\rho(x) \propto 2 + 2\cos(2\pi x)$，在 $x=0$ 处最大（$\cos 0 = 1$，$\rho=4/V$），在 $x=1/2$ 处最小（$\cos\pi = -1$，$\rho=0$）。——电子密度在 $x=0$ 处有一个峰。
- **第三步，推广**：真实的电子密度就是「许多个这样的一维/二维/三维余弦波叠加」。峰出现在各项波**相位一致**的地方，峰高由叠加的 $|F|$ 决定。傅里叶合成把所有衍射数据「聚焦」回原子位置——这就是它能重建结构的本质。<span class="marginnote">相角的作用在这里看得最清楚：若把 $F(1)$ 的相角从 0 改成 $\pi$，叠加项变 $2\cos(2\pi x + \pi) = -2\cos(2\pi x)$，峰从 $x=0$ 移到 $x=1/2$——<strong>相角错了，峰就「搬错家」，整个结构就错了</strong>。</span>

## 5 分辨率与电子密度图的质量

傅里叶合成的项数决定分辨率，分辨率决定你「看得见什么」：

| 分辨率 $d_{\min}$ | 电子密度图可见信息 |
| --- | --- |
| ~6 Å | 分子轮廓、二级结构大致走向 |
| ~3 Å | 二级结构元素、侧链大方向 |
| ~2 Å | 侧链原子基本可见 |
| ~1.5 Å | 大部分原子清晰、可建精细模型 |
| ≤1.2 Å | 原子「各就各位」，可定位氢 |

小分子晶体学通常做到 $d_{\min} = 0.7–0.8$ Å 以上（Cu/Mo 靶），电子密度图「山峦分明」，几乎直接读出结构。蛋白质晶体学做到 1.5–3 Å，图上有等高线起伏，需要结合已知氨基酸序列建模型。<span class="marginnote">看图经验：电子密度图画成「等高线」（像地图），等高线值（如 1σ、3σ）决定显示灵敏度。原子峰远高于噪声背景，用 $\ge 3\sigma$ 截断能干净地显示原子；1σ 以下多是噪声与未建模水分子。</span>

## 6 从电子密度到结构模型

有了电子密度图，结构解析进入「读图建模型」阶段：

1. **找峰**：在高密度区域标出峰位——它们是候选原子。
2. **配原子**：按峰高与化学知识（键长、键角、配位数）把峰指认为 C、N、O、金属等。峰高 ≈ $Z$，重原子峰极高、氢几乎看不见。
3. **连键**：把距离合理（如 C–C ≈ 1.5 Å）的原子连成分子骨架。
4. **精修**：把坐标、温度因子、占有率作最小二乘精修，让计算强度逼近实测强度（第3篇最小二乘精修专讲）。<span class="marginnote">「读图」在蛋白质晶体学里是一门手艺：自动化建模型软件（如 ARP/wARP、Buccaneer）能从电子密度图自动搭出多肽链，再靠人工修正。但小分子晶体学由于分辨率高，常可由软件直接生成近乎完整模型。</span>

电子密度图的「质量」除了分辨率，还受相角质量、完整性、异常值影响。一张好的密度图是结构解析的通行证——**分辨率高 + 相角准 = 几乎必然解出结构**。

## 7 辨析｜易错点：傅里叶合成的五个坑

**辨析｜易错点：** 傅里叶合成是把概念缝起来的地方，五个高频错误：

**相角符号**：合成用 $e^{-2\pi i\mathbf{h}\cdot\mathbf{r}}$ 还是 $e^{+2\pi i\mathbf{h}\cdot\mathbf{r}}$？两种约定都存在，但必须与结构因子定义自洽（若 $F$ 定义为 $\int \rho e^{+2\pi i\mathbf{h}\cdot\mathbf{r}}dV$，则 $\rho$ 用 $e^{-}$ 号合成）。混用符号会得到镜像/错位结构。
**把 $|F|$ 当 $F$ 用**：直接用 $|F|$ 合成（忽略相角）得到的是**Patterson 函数**（自相关），不是电子密度。两者形状完全不同——Patterson 里没有原子，只有「原子间向量」的峰。
- **分辨率截断的误解**：把合成截断在低分辨率，不是「模糊一点」，而是**丢失细节**——峰变宽、相邻原子重叠。报分辨率时必须说明对应哪个 $d_{\min}$。
- **忽略 $F(000)$**：$F(000)$（正前向散射）等于晶胞总电子数，是密度图的「直流项」——它决定背景高度。忘掉它，整个图的基准就错了。
- **峰高 ≠ 原子数**：峰高与 $Z$ 相关但不严格成比例，还受温度因子影响。热振动大的原子峰更低更宽——看峰高判断原子种类时要谨慎。<span class="marginnote">实用对照：<strong>峰位决定坐标，峰高（积分强度）决定电子数，峰宽反映热运动</strong>。三者分别是位置、种类、温度三个信息的载体，精修时分别对应坐标、占有率、各向异性温度因子三个参数。</span>

## 8 相角错误的一个直观演示

再回看一维例子的「相角敏感性」。同样两个结构因子 $F(1) = 1$、$F(-1) = 1$，但若相角全取反（$F(1) = e^{i\pi}$、$F(-1) = e^{i\pi}$）：

$$\rho(x) = \frac{1}{V}\left[2 + e^{i\pi}e^{-2\pi ix} + e^{i\pi}e^{2\pi ix}\right] = \frac{1}{V}\left[2 - 2\cos(2\pi x)\right]$$

峰从 $x=0$ 移到了 $x=\tfrac12$——**相角反号，整个密度图「搬了家」**。<span class="marginnote">这个演示的教训：<strong>相角错误不是「模糊一点」，而是「结构错位」</strong>。密度图上看到的位置、连接、手性，全都依赖相角。这也解释了为什么相角问题解决后，结构解析「一锤定音」——相角对了，密度图几乎直接给出答案。</span>

再推广一步：真实结构有成百上千个结构因子，每个相角都带误差。密度图是「所有误差的平均」——个别相角错影响局部，系统相角错则全局失真。这就是「分辨率 + 相角质量」共同决定密度图可靠性的完整图景。

## 9 小结

- **电子密度**是周期函数，可展成傅里叶级数；**傅里叶合成** = 全部结构因子带相角加权叠加。
- 实验只给振幅 $|F|$、丢失相角——**相角问题**是傅里叶合成的拦路虎，一切解析方法都在找相角。
- **差分傅里叶**用模型相角 + 振幅差找「缺原子 / 多原子」，是精修的核心工具。
- 分辨率 = 傅里叶级数截断频率；$d_{\min}$ 越小，密度图越清晰，可见信息越细。
- 从电子密度到结构：找峰 → 配原子 → 连键 → 最小二乘精修。
- 相角符号、$|F|$ vs $F$、$F(000)$、分辨率截断、峰高解读是五个易错点。

在下一节，我们补齐结构因子公式里最后一项物理修正：**温度因子、消光与衍射强度修正**——原子在动、光在衰减，精修前得先把它们算清。
