## 为什么从绝对构型继续

一个分子若有手性中心，它有两种互为镜像的**绝对构型（absolute configuration）**——R/S（或 D/L）。X 射线衍射能区分它们吗？在大多数情况下，Friedel 定律让 $I(hkl) = I(\bar h\bar k\bar l)$，衍射图看似中心对称，似乎分不出左右手。但**只要有一个反常散射原子，这个「看似」就被打破**——左右手会给出可测量的强度差异。

绝对构型的确定，是手性药物、天然产物、不对称合成里至关重要的一步：构型错了，药效可能天差地别（沙利度胺的教训）。而确定它的标准工具，就是**Flack 参数**。最后，一个结构从数据到解析的全部信息，都要装进 **CIF 文件**——晶体学数据交换与发表的通用档案。<span class="marginnote">沙利度胺（thalidomide）是绝对构型的经典教训：<strong>R 对映体是镇静剂，S 对映体却有致畸性</strong>。20 世纪 50 年代末的悲剧让「手性药物的每个对映体都要单独表征」成为药品监管的铁律——而 X 射线晶体学的 Flack 参数正是最权威的表征手段之一。</span>

本节讲反常散射如何打破 Friedel 定律、Flack 参数怎么读、以及 CIF 报告的规范。

## 1 反常散射：让左右手现形

**反常散射（anomalous scattering）** 发生在 X 射线能量接近原子吸收边时。此时原子散射因子不再是实数，而变成复数：

$$f = f_0 + f' + i f''$$

其中 $f'$（色散修正，通常为负）与 $f''$（吸收修正）在吸收边附近显著增大。<span class="marginnote">$f'$ 与 $f''$ 的物理来源：<strong>入射光子能量与原子内层电子跃迁共振，电子被「囚禁」在激发态，散射波带上了相位滞后</strong>。铜靶的 Cu Kα（1.54 Å）恰好激发硫、氯、铁等原子的 K 吸收边——很多含这些元素的小分子用铜靶就能做反常散射。</span>

反常散射打破了 **Friedel 定律**：$|F(hkl)| \ne |F(\bar h\bar k\bar l)|$。两者的差异（Bijvoet 差）虽然很小（通常 1–10%），但可以精确测量。这些差异里编码着原子的绝对位置——也就是绝对构型。

**为什么能定构型**：反常散射原子在晶格里的位置是手性的；它的散射相位滞后又依赖原子的绝对位置，于是「左手结构」与「右手结构」给出的 Bijvoet 差符号相反。对比实测与两种构型的计算值，就能判定哪个正确。

## 2 Flack 参数：绝对构型的数值判据

**Flack 参数 $x$**（1983 年由 Flack 提出）是精修中的一个参数，描述晶体中「正确构型」与「对映体构型」的混合程度。对倒反结构 $(\bar h\bar k\bar l)$ 的强度：

$$|F_{\text{calc}}(hkl)|^2 = (1-x)\,|F_{\text{true}}(hkl)|^2 + x\,|F_{\text{true}}(\bar h\bar k\bar l)|^2$$

拆解这条式子：

- **第一步，$x$ 的物理意义**：$x = 0$ 表示晶体纯是「正确构型」；$x = 1$ 表示纯是「对映体构型」（即你模型把左右手搞反了）；$x = 0.5$ 表示外消旋混合（左右手各半）。<span class="marginnote">Flack 参数是「构型的正确率表」：<strong>$x \approx 0$（误差 < 0.04）→ 绝对构型确定正确；$x \approx 1$ → 构型反了；$x \approx 0.5$ → 外消旋</strong>。发表时 Flack 参数必须带标准差 $\sigma(x)$ 一起报，无 $\sigma$ 的 $x$ 没有意义。</span>
**第二步，精修得到 $x$**：把 $x$ 作为自由参数加入最小二乘精修，拟合实测的 Bijvoet 差。
**第三步，判读**：$x$ 接近 0 且 $\sigma(x)$ 小 → 绝对构型确定；$x$ 接近 1 → 反转结构再精修；$x$ 在 0.3–0.7 → 可能是外消旋/孪晶，需进一步检查。

**注意事项**：Flack 参数只有在有足够反常散射信号时才可靠。对纯轻原子（C、H、N、O）且用钼靶（无共振），Bijvoet 差太小，$x$ 不可靠——此时要么换铜靶、要么引入重原子（含硫、碘等）、要么用同步辐射在吸收边测。

## 3 绝对构型的可靠性判据

如何知道「Flack 参数确定的构型」可信？三个判据：

1. **$x$ 值 + 标准差**：$x = 0.01(2)$ 表示 $x$ 接近 0 且误差小——高度可信；$x = 0.3(3)$ 表示误差太大，不可信。
2. **Bijvoet 差是否显著**：若实测的反常差信噪比高（很多反射的 $|F(hkl)|$ 与 $|F(\bar h\bar k\bar l)|$ 明显不同），Flack 参数就有力。
3. **与已知化学知识对照**：天然产物、已知手性中心的构型是否与文献一致、合成路线的立体化学是否合理。<span class="marginnote">现代判据还有「倒空间法」：用 Hooft 参数、Bijvoet 对统计等更精细的手段。核心思想一致：<strong>反常散射差异的符号与大小，必须在两个对映体模型之间自洽地「二选一」</strong>。换用两个对映体分别精修，看 Flack 参数是否在 0 与 1 之间跳——跳对了就是真确定。</span>

## 4 CIF：晶体学的通用语言

**CIF（Crystallographic Information File）** 是晶体学数据的标准交换格式，由 IUCr 维护。一个结构解完后，全部信息都要装进 CIF 文件，投稿、存档、进数据库（CSD、PDB、ICSD）都以它为准。

CIF 的语法是**键值对**（data item: 值），用循环（loop_）组织表格数据。典型内容：

晶胞参数、空间群、温度、波长等实验信息。
原子坐标、温度因子、占有率（`_atom_site_*` 字段）。
- 键长键角、几何参数（由软件自动生成）。
- 精修指标（R 因子、GooF、Flack 参数）、衍射数据统计。
- 参考文献、作者、化合物信息。<span class="marginnote">CIF 的哲学：<strong>一篇文章的数据，必须足以让任何人独立重做并验证</strong>。国际表、PLATON 的输出、发表前的 checkCIF 校验，都围绕 CIF 展开。你看到的每个 CSD 条目、每篇小分子结构论文的 SI，背后都是一个 CIF。</span>

**checkCIF**：把 CIF 上传到 IUCr 的 checkCIF 服务（或本地 PLATON），会自动检查几何合理性、对称性、消光、A/B/C 级警报。投稿前跑一遍是标配。

## 5 公式解析：Bijvoet 差与 Flack 参数的关系

Flack 参数的信号来自 Bijvoet 对的不对称。定义**Bijvoet 差**：

$$\Delta_{\text{Bijvoet}} = |F(hkl)|^2 - |F(\bar h\bar k\bar l)|^2 \approx -4\,|F''_h|\,|F''_a|\,\sin(\phi_h - \phi_a)$$

拆解这条式子：

- **第一步，物理来源**：反常散射的 $f''$ 给结构因子加了一个「虚部」分量 $F''$。$|F(hkl)|^2$ 与 $|F(\bar h\bar k\bar l)|^2$ 之差正比于虚部与正常部分的交叉项。
- **第二步，符号携带手性**：$\sin(\phi_h - \phi_a)$ 的符号由反常散射原子的**绝对位置**决定——左右手结构给出相反的 $\Delta_{\text{Bijvoet}}$。这就是「测 Bijvoet 差 → 定构型」的链条。<span class="marginnote">一句话：<strong>反常散射把原子的绝对位置「编码」进强度差异，Flack 参数把差异翻译成构型判定</strong>。没有 $f''$（无反常散射），$\Delta_{\text{Bijvoet}} = 0$，Flack 参数就失去信号。</span>
**第三步，精度**：$\Delta_{\text{Bijvoet}}$ 通常只有总强度的 1–10%，必须高冗余、高精度测量才能可靠。这也解释了为什么绝对构型确定需要「高质量反常散射数据」而非随便一套数据。

## 6 报告与归档规范

结构解析完成后，向期刊投稿/向数据库归档的规范：

**CIF 文件**：主档案，含全部数据与精修结果。
- **checkCIF 报告**：随 CIF 一起提交，A 级警报要解释。
- **结构因子（FCF）文件**：衍射数据本身（$|F|$ 与 $\sigma$），可申请/存档，便于他人复核。
- **发表参数表**：晶胞、空间群、R 因子、GooF、Flack 参数、收集温度、波长等——论文正文的表格与 CIF 必须一致。
- **数据库登记**：小分子进 **CSD（剑桥结构数据库）**（有机物/配合物）或 **ICSD**（无机物）；蛋白质进 **PDB**。<span class="marginnote">归档是学术诚信的一部分：<strong>没有 CIF 与结构因子，审稿人和读者无法验证你的结构</strong>。现代期刊（如 Acta Cryst. E）把「CIF + checkCIF + 结构因子」作为投稿必需——这既是标准，也是数据共享的文化。</span>

## 7 辨析｜易错点：绝对构型与报告的五个坑

**辨析｜易错点：** 绝对构型确定与 CIF 报告五个高频失误：

**无反常散射硬报 Flack 参数**：纯轻原子 + Mo 靶时 Bijvoet 差接近零，Flack 参数只是「噪声拟合」，报 $x$ 无意义。要么换 Cu 靶/同步辐射，要么如实声明「绝对构型无法确定」。
**不报 $\sigma(x)$**：Flack 参数不带标准差等于没报。$x = 0.02$ 与 $x = 0.02(18)$ 的可信度天差地别。<span class="marginnote">经验：<strong>报告 Flack 参数时，$\sigma(x) \lt  0.04$ 才算「确定」</strong>；$\sigma(x)$ 在 0.04–0.1 是「疑似」；更大则不可靠。审稿人会看这个数。</span>
**对映体晶体的空间群用错**：手性分子的晶体必属 65 种手性空间群，若软件报了中心对称空间群，多半是模型/数据有问题（或确实是外消旋共晶——需检查 Flack 参数是否 ~0.5）。
**CIF 与论文表格不一致**：晶胞参数、R 因子在不同文件里对不上，是审稿高频意见。用 CIF 为唯一真源，生成论文表格。
- **省略溶剂/无序处理说明**：溶剂（SQUEEZE）、无序、孪晶处理不在 CIF 里写清，审稿人无法复核。如实、完整地记录。

## 8 Flack 参数之外的现代绝对构型方法

Flack 参数是经典判据，但现代还有更精细的手段：

**Hooft 参数与 Bayesian 分析**：Hooft 等人提出用全部 Bijvoet 对的统计分布（而非单个精修参数）来判定绝对构型——给出「构型正确/相反/外消旋」的概率。Bayesian 方法（如 PLATON 的 Bijvoet 对分析）比 Flack 参数对弱反常信号更敏感，常用于 Flack 参数不确定时的补充判定。

**倒空间残差法（Rogers 参数）**：把「构型正确 vs 相反」作为两个模型，分别精修并比较 R 因子——更直观，但需两个完整精修。

**反常散射对统计**：现代软件（如 SHELXL 的 `MERG 4` 与 `TWIN` 配合、olex2 的构型分析）直接给出「绝对结构」的置信概率——比单一 $x$ 值信息更全。<span class="marginnote">判定的现代共识：<strong>把 Flack 参数、Hooft 参数、Bijvoet 对统计三者放在一起看</strong>——若一致指向同一构型，绝对构型基本「铁案」；若互相矛盾，多半是数据里还有未处理的反常散射信号或孪晶。报告时给出方法名与数值，审稿人自会评估。</span>

**CIF 里怎么写**：绝对构型信息记在 `_refine_ls_abs_structure_*` 字段；发表时在正文注明「绝对构型由 Flack 参数 $x = 0.01(2)$ 确定（含硒反常散射，Cu Kα）」——把「怎么定的、信号从哪来」写清楚，是审稿与复现的最低要求。

## 9 小结

- **反常散射**（$f = f_0 + f' + if''$）打破 Friedel 定律，使 $|F(hkl)| \ne |F(\bar h\bar k\bar l)|$——左右手因此可分。
- **Flack 参数 $x$**：$x≈0$ 构型正确、$x≈1$ 构型反了、$x≈0.5$ 外消旋；必须带 $\sigma(x)$ 报告。
- Bijvoet 差 $\Delta \approx -4|F''_h||F''_a|\sin(\phi_h-\phi_a)$，符号携带绝对位置信息。
- 绝对构型可靠判据：$x$ 值 + $\sigma$ + Bijvoet 差信噪比 + 化学知识对照。
- **CIF** 是晶体学通用档案：全部数据 + 精修指标 + Flack 参数；checkCIF 是发表前质检。
- 归档规范：CIF + 结构因子 + checkCIF + 数据库登记（CSD/ICSD/PDB）。
