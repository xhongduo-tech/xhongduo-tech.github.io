## 为什么从系统消光继续

前面我们在结构因子里看到：当基元内原子错开半个格距，某些指标的反射会整体消失——**系统消光（systematic absences）**。这一节把它做成一个真正的工具：从衍射图上「哪些点消失了」，反推出晶体含哪些螺旋轴与滑移面，最终**判定空间群**。

这是结构解析流程中承上启下的一步：上承数据收集（测哪些点）、下启结构求解（在哪个空间群里解）。Mass 教材里，这一步与空间群（第3章）并列——因为消光规律本质上是空间群对称性在倒空间的投影。<span class="marginnote">直觉：<strong>实空间里的螺旋轴/滑移面，在倒空间里表现为「某些反射类被系统性删掉」</strong>。这是傅里叶变换对偶性的又一次显现：实空间的平移对称，映射到倒空间就是周期性的零值。把消光规律查表，就能反向读出空间群。</span>

本节先给消光规律的总表，再讲判定流程，最后落到「从消光到空间群候选」的完整链条。

## 1 消光规律总表

空间群对称元素对应的消光条件如下（$h,k,l$ 为 Miller 指数，$m,n,p$ 为整数）：

| 对称元素 | 受影响的反射类 | 出现条件 | 例子 |
| --- | --- | --- | --- |
| 2₁ 螺旋轴（沿 $x$） | $h00$ | $h = 2m$（偶） | $P2_1$ |
| 4₁、4₃ 螺旋轴（沿 $z$） | $00l$ | $l = 4m$ | $P4_1$、$P4_3$ |
| 4₂ 螺旋轴（沿 $z$） | $00l$ | $l = 2m$ | $P4_2$ |
| 6₃ 螺旋轴（沿 $z$） | $00l$ | $l = 3m$ | $P6_3$ |
| $a$ 滑移面（垂直 $z$） | $hk0$ | $h = 2m$ | $P2/a$ |
| $c$ 滑移面（垂直 $z$） | $hk0$ | $l$ 无约束，$h,k$ 均偶或奇？—见下 | $P2/c$ |
| $n$ 滑移面（垂直 $z$） | $hk0$ | $h+k = 2m$（偶） | $Pn$ |
| $d$ 滑移面（垂直 $z$） | $hk0$ | $h+k = 4m$ | $Fdd2$ |

注意表格里的细节：**$a$ 滑移面让 $hk0$ 中 $h$ 为奇数的消失**；**$c$ 滑移面（垂直 $z$）让 $hk0$ 中 $h+k$ 为奇数的消失**（不是 $l$！）；**$n$ 滑移面让 $h+k$ 为偶数的出现**。<span class="marginnote">最容易记错的是 $c$ 滑移：垂直 $z$ 的 $c$ 滑移面，消光条件落在 $hk0$ 类的 $h+k$ 奇偶上，与 $l$ 无关。逐条背表不如理解来源：$c$ 滑移沿 $c$ 方向平移 1/2，所以只影响指标 $l$——但垂直 $z$ 时平移沿 $z$（$c$ 轴），影响的其实是…需按国际表逐项核对。</span>

**心子（centring）的消光**：Bravais 点阵本身也有消光规律——$C$ 底心让 $hkl$ 中 $h+k$ 为奇数的消失，$F$ 面心让 $h,k,l$ 奇偶不全相同的消失，$I$ 体心让 $h+k+l$ 为奇数的消失。定心子是判定空间群的第一步。

## 2 判定流程：从强度数据到空间群

空间群判定的标准流程是「排除法」：

1. **定晶系**：由晶胞参数（轴长、夹角）与衍射对称（劳厄群）确定晶系。例如 $a=b\ne c$ 且 $\gamma=90°$ 可能是四方；$a=b=c$ 且全为 90° 可能是立方。
2. **定劳厄群（Laue group）**：衍射图样的对称群（含中心对称），由数据合并时的对称等价关系确定。这是「点群倒空间版」——它告诉你晶体的宏观对称是 11 个劳厄群中的哪个。
3. **看心子消光**：从 $hkl$ 全反射类中找出消失模式，定出 Bravais 点阵（$P/C/F/I/R$）。
4. **看轴向消光**：从 $h00、0k0、00l$ 中找出消失条件，定出螺旋轴（如 2₁、4₁）。
5. **看面带消光**：从 $hk0、h0l、0kl$ 中找出消失条件，定出滑移面。
6. **合并候选**：把「点阵 + 螺旋轴 + 滑移面」与空间群表对照，得到 1 个或几个候选空间群。<span class="marginnote">候选不止一个时怎么办？先看是否互为「对映对」（如 $P4_12_12$ 与 $P4_32_12$——结构解析软件会分别尝试，最后靠 R 因子与 Flack 参数定）；再看强度统计（E 值分布）判断是否有反演中心；最后直接进结构解析验证。空间群「唯一确定」往往在结构解出来之后才宣告完成。</span>

## 3 从消光到空间群的「证据链」

用一个具体例子走完整条链。设测得晶胞：单斜（$a\ne b\ne c$，$\beta\approx 105°$），指标化后数据完整。现在看消光：

**心子**：$hkl$ 无消光 → 点阵为 $P$。
**$0k0$ 类**：$k$ 为奇数的全部消失 → 存在沿 $b$ 的 2₁ 螺旋轴。
- **$h0l$ 类**：$l$ 为奇数的消失 → 存在垂直 $b$ 的 $c$ 滑移面。

于是候选空间群为 $P2_1/c$。这是单斜晶系最常见（约占有机物/金属配合物晶体的一半）的空间群。<span class="marginnote">$P2_1/c$ 的 Wyckoff 表在第三节讲过：一般位置重数 4、特殊位置 $a,b$ 在反演中心。一旦确定 $P2_1/c$，你立刻知道晶胞含 4 个对称等效的分子单元（$Z=4$ 时），这直接约束分子数、密度与后续建模。</span>

从这条链可以看到系统消光的「证据强度」：**每个消光条件是对称元素存在的硬证据**——不是猜，是数据里的结构性「空缺」告诉你的。

## 4 劳厄群与点群的连接

劳厄群是衍射数据的对称群。它有 11 种（每个晶系 1–2 种），且**必须与晶系兼容**：

| 晶系 | 劳厄群 |
| --- | --- |
| 三斜 | $\bar{1}$ |
| 单斜 | $2/m$ |
| 正交 | $mmm$ |
| 四方 | $4/m$，$4/mmm$ |
| 三方 | $\bar{3}$，$\bar{3}m$ |
| 六方 | $6/m$，$6/mmm$ |
| 立方 | $m\bar{3}$，$m\bar{3}m$ |

劳厄群与点群的关系：**劳厄群 = 点群加上反演中心**（若点群本来就含 $\bar{1}$ 则就是它自己）。例如点群 $222、mm2、mmm$ 的劳厄群都是 $mmm$。所以**从衍射数据只能确定到劳厄群，点群要结合晶胞对称（或物理性质）再细分**。<span class="marginnote">这正是「衍射定不出手性」在对称层面的表达：非中心对称点群与它的中心对称化版本共享同一劳厄群。要区分 $P222$ 与 $Pmmm$ 之类，得靠强度统计或结构解析本身。</span>

判定劳厄群靠数据合并：把等效反射（对称相关的 $(hkl)$）归并，比较它们的强度一致性。强度一致好的合并方案对应的劳厄群就是正确候选。

## 5 公式解析：消光的结构根源

用结构因子公式把一条消光规律「证」一遍。以沿 $c$ 的 2₁ 螺旋轴为例：它把 $(x,y,z)$ 映到 $(-x,-y,z+\tfrac12)$。设晶体只有这个对称元素、且原点取在轴上，则原子成对出现：

$$\rho(\mathbf{r}) = \rho(-\mathbf{r} + \tfrac12 \mathbf{c})$$

对 $00l$ 类反射（$h=k=0$），结构因子化为：

$$F(00l) = \sum_j f_j \left[ e^{2\pi i l z_j} + e^{2\pi i l (z_j + 1/2)} \right] = \sum_j f_j\, e^{2\pi i l z_j}\left(1 + e^{\pi i l}\right)$$

拆解这条式子：

- **第一步，配对**：每个原子 $(x_j,y_j,z_j)$ 必有一个孪生原子 $(-x_j,-y_j,z_j+\tfrac12)$。两者对 $F(00l)$ 的贡献是 $e^{2\pi i l z_j}$ 与 $e^{2\pi i l(z_j+1/2)} = e^{2\pi i l z_j} e^{\pi i l}$。
- **第二步，提公因子**：合并得 $e^{2\pi i l z_j}(1 + e^{\pi i l})$。
- **第三步，判别奇偶**：$e^{\pi i l} = (-1)^l$。若 $l$ 为奇数，$1+(-1)^l = 0$，$F(00l) = 0$——**$00l$ 类 $l$ 为奇数的反射全部消失**；$l$ 为偶数则保留。<span class="marginnote">这个推导是「对称元素 → 消光规律」的标准模板：<strong>把对称元素作用在原子对上，代入结构因子，看指数奇偶</strong>。任何螺旋轴/滑移面的消光条件都能这样推出来——记住模板，就不必死背表格。</span>

关键要义：**消光不是「碰巧弱」，而是结构因子的精确零**。只要对称元素存在，对应的反射类就严格为 0（忽略反常散射等小效应）——所以它是硬判据。

## 6 消光判定时的「例外」

系统消光有几种必须知道的例外，否则会误判空间群：

**反常散射打破 Friedel 定律**：接近吸收边时 $I(hkl) \ne I(\bar h \bar k \bar l)$，某些本应消光的反射可能出现极弱强度——严格消光仍成立（结构因子仍为零），但测量上要留意。

**多重散射 / 背景**：弱消光反射被散射背景或多次散射污染，测得「伪强度」。判定时用 3σ 准则：低于 3σ 的视为消光，高于 3σ 才算出现。

**衍射群不一致**：实际数据的晶系对称可能因吸收、偏心误差而「降级」（看似三斜）。处理办法是用更高对称的劳厄群做数据合并，看 R(merge) 是否改善。<span class="marginnote">经验法则：<strong>先假设高对称劳厄群合并，若 R(merge) 明显恶化（如 > 10%），再降级</strong>。宁可先高后低，避免因低估对称性而丢失等价数据。</span>

## 7 辨析｜易错点：四条易错规则

**辨析｜易错点：** 系统消光判定里四个高频坑：

**把「心子消光」与「轴向消光」混在一起**：心子消光（$hkl$ 类）定 Bravais 点阵，轴向消光（$h00$ 等）定螺旋轴，面带消光（$hk0$ 等）定滑移面——三层各自独立，别用 $h00$ 的规则去判断 $hkl$。
**$c$ 滑移面「垂直 $z$」≠ 看 $00l$**：垂直 $z$ 的滑移面影响 $hk0$ 类，看的是 $h,k$ 的组合奇偶，不是 $l$。方向与反射类要严格对应。
- **螺旋轴 4₁ 与 4₃ 的区分**：$4_1$ 与 $4_3$ 有相同消光（$l=4m$），单靠消光分不开——需靠对映体结构解析（Flack 参数）区分。<span class="marginnote">同理，$3_1$ 与 $3_2$、$6_1$ 与 $6_5$ 互为对映螺旋，消光相同。这些「左右手」对在绝对构型确定里才见分晓。</span>
- **把「消光」误读为「没数据」**：消光反射是「本应为零」，而「没测到」可能是实验遗漏。判定前先确认数据覆盖完整（合并完整度足够），避免把「没测」当成「消光」。

## 8 小结

- **系统消光**是空间群对称元素在倒空间的硬证据：螺旋轴/滑移面/心子各有对应消光规则。
- 判定流程：定晶系 → 定劳厄群 → 定心子（$hkl$）→ 定螺旋轴（$h00/0k0/00l$）→ 定滑移面（$hk0$ 等）→ 合并候选。
- **劳厄群** 11 种，= 点群 + 反演中心；衍射只能确定到劳厄群，点群需结合其他信息细分。
- 消光的根源是结构因子精确为零；$00l$ 中 2₁ 螺旋让 $l$ 奇数消失（推导模板通用）。
- 判定要留意反常散射、背景污染、对称性降级等例外。
- 四条易错规则：分层消光、方向-反射类对应、对映螺旋不可分、消光 ≠ 未测。
