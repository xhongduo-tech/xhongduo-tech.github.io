# 中学地理课程（区域地理体系：地球与地图、中国地理、世界地理与高中自然人文地理）

中学地理课程以《义务教育地理课程标准（2022年版）》与《普通高中地理课程标准（2017年版2020年修订）》为纲，依托人教版统编《地理》教材，形成从地球与地图、世界地理、中国地理到高中自然地理与人文地理的完整知识链，是系统认识地表格局、区域差异与人地关系的学科基础。学完这些章节，就写完了中学阶段地理课程的全部内容。

## 对标教材

- 中华人民共和国教育部《义务教育地理课程标准（2022年版）》
- 中华人民共和国教育部《普通高中地理课程标准（2017年版2020年修订）》
- 人民教育出版社《地理》统编教材（七年级上册、七年级下册、八年级上册、八年级下册）
- 人民教育出版社《高中地理》必修第一册、必修第二册与选择性必修一、二、三
