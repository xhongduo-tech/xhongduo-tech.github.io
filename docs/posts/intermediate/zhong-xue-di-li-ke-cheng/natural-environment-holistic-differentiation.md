## 为什么从整体性与差异性开始

自然地理的最后一章，站在高处回望全部自然要素——岩石、土壤、大气、水、生物。它提炼出自然环境的两大基本属性：**整体性**（各要素相互联系、牵一发动全身）与**差异性**（空间上分异出不同的自然带）。<span class="marginnote">这一章是高中自然地理的「收束之笔」：前面学的地貌、气候、水、土壤、植被，在此统一进「自然环境」这个整体。第八级《景观生态学》《环境科学》与第九级《地理信息系统》会把这个整体用系统科学与现代技术进一步展开。</span>理解了整体性与差异性，就理解了「人与自然和谐共生」的地理基础。

## 1 自然环境的组成要素

**自然环境**由五大要素构成：**地貌（岩石圈）、气候（大气圈）、水文（水圈）、生物（生物圈）、土壤（土壤圈）**。

这五大要素不是孤立的，而是通过**水循环、生物循环、岩石圈物质循环**等纽带联系在一起，构成一个有机整体。

**三大循环纽带**：

- **水循环**：把大气圈、水圈、岩石圈、生物圈联系起来（见第 20 篇）。
- **生物循环**：植物吸收养分、动物取食、微生物分解，实现物质在生物与环境间的往复。
- **岩石圈物质循环**：岩石经风化、搬运、沉积、变质、重熔，在三大类岩石间转化。

## 2 自然环境的整体性：牵一发动全身

**整体性**是指自然环境各要素相互联系、相互制约、相互渗透，**一个要素的变化会导致其他要素乃至整个环境的变化**。

**整体性的表现**：

1. **要素间相互联系**：气候影响植被、植被影响土壤、土壤影响水文……环环相扣。如亚马孙雨林：高温多雨的气候 → 茂密雨林 → 枯枝落叶多 → 但分解快，土壤反而贫瘠——一个要素不能脱离整体去理解。
2. **牵一发动全身**：某一要素变化会连锁引发一系列变化。经典的例子是「黄土高原水土流失」——植被破坏 → 水土流失加剧 → 土壤肥力下降 → 河流含沙量增大 → 下游淤积抬升 → 洪涝风险增大。
3. **统一的演化过程**：自然环境具有统一的演化过程，各要素协同演化。如青藏高原隆起 → 高原气候变冷 → 冰川发育 → 河流源头改变 → 生物多样性演替。

**公式解析：环境的连锁反应链**

整体性的本质是要素间的因果传递，可以抽象为一条反应链：

$$
\text{要素 } A \uparrow \Rightarrow B \ \text{变化} \Rightarrow C \ \text{变化} \Rightarrow \cdots
$$

- **第一步，找起点**：找出被改变的那个要素（如植被被破坏）。
- **第二步，追传递**：沿水循环、生物循环、物质循环追踪连锁影响（植被 → 土壤 → 水文 → 气候）。
- **第三步，判终局**：最终波及整个自然环境与人类社会（生态退化 → 生产受影响）。
- **应用示例**：长江源区植被退化 → 水土保持能力下降 → 入江泥沙增多 → 中下游河道淤积 → 防洪压力增大。这正是「整体性」在流域治理中的体现。

**整体性的实践意义**：人类开发活动必须尊重整体性规律——「砍伐一片森林」不只是少了一片树，而是引发整条生态链的连锁反应。这为可持续发展（第 27 篇）提供了自然基础。

## 3 自然环境的差异性：地域分异规律

**差异性**指自然环境在空间上存在地域分异。自然地理环境的差异表现为**自然带**（气候 + 植被 + 土壤的综合体）在空间上有规律的更替。

**三大地域分异规律**：

**（1）纬度地带性（从赤道向两极的地域分异）**：

- **主导因素**：热量。
- **分布规律**：自然带沿纬线方向延伸、沿纬度变化方向更替。
- **实例**：从赤道到两极，依次出现热带雨林带 → 热带草原带 → 亚热带常绿阔叶林带 → 温带落叶阔叶林带 → 亚寒带针叶林带 → 苔原带 → 冰原带。

**（2）经度地带性（从沿海向内陆的地域分异）**：

- **主导因素**：水分。
- **分布规律**：自然带沿经线方向延伸、沿经度变化方向更替。
- **实例**：我国从东到西（华北到西北），依次出现森林带 → 草原带 → 荒漠带——正是第 18 篇「北方到西北」景观变化的深层规律。

**（3）垂直地带性（山地垂直地域分异）**：

- **主导因素**：水热组合随海拔的变化。
- **分布规律**：自然带沿山地海拔的升高依次更替。
- **实例**：乞力马扎罗山从山麓的热带雨林到山顶的冰雪带；珠峰南坡从亚热带常绿阔叶林直到高山冰雪带。<span class="marginnote">垂直带谱的基带与山体所处的水平自然带一致：乞力马扎罗山基带是热带雨林，因为它在赤道附近。山地垂直带谱的丰富程度与纬度、海拔、相对高度有关——「一山有四季，十里不同天」正是垂直地带性的生动写照。</span>

## 4 非地带性因素

在上述地带性规律之外，还存在**非地带性现象**——由局部因素引起的规律之外的差异：

- **地形**：南美洲南端安第斯山脉东侧为荒漠、西侧为温带海洋性气候（山脉阻挡西风）。
- **洋流**：暖流增温增湿（北大西洋暖流使欧洲西岸偏暖），寒流降温减湿（秘鲁寒流使沿岸形成沙漠）。
- **海陆分布**：南半球高纬因缺少陆地而无亚寒带针叶林带、苔原带。

**辨析｜易错点：** 地带性与非地带性要分清主导因素——**纬度地带性看热量，经度地带性看水分，垂直地带性看水热组合**；而地形、洋流、海陆分布造成的「意外」属于非地带性。考试常以「某地应为某带却出现异象」考查非地带性。

## 5 核心对比：三大地域分异规律

| 分异规律 | 主导因素 | 更替方向 | 典型实例 |
| --- | --- | --- | --- |
| 纬度地带性 | 热量 | 沿纬度（南北） | 赤道到两极的自然带 |
| 经度地带性 | 水分 | 沿经度（东西） | 我国东部森林到西部荒漠 |
| 垂直地带性 | 水热组合 | 沿海拔（垂直） | 乞力马扎罗山垂直带谱 |

### 常见误区与考点速记

- 纬度地带性看**热量**、经度地带性看**水分**、垂直地带性看**水热组合**。
- 我国从东部森林到西部荒漠是**经度地带性**（水分主导）。
- 垂直带谱的**基带**与山地所在水平自然带一致。
- 非地带性由**地形、洋流、海陆分布**引起。
- 黄土高原水土流失是**整体性**「牵一发动全身」的典型。

## 8 小结

- 自然环境五大要素：**地貌、气候、水文、生物、土壤**，通过三大循环联系为整体。
- **整体性**：要素相互联系、**牵一发动全身**；黄土高原水土流失是典型链条。
- **纬度地带性**看热量（赤道到两极）、**经度地带性**看水分（沿海到内陆）、**垂直地带性**看水热组合（山麓到山顶）。
- **非地带性**因素：地形、洋流、海陆分布造成的规律之外的分异。
- 整体性为可持续发展提供自然基础，差异性要求因地制宜。
