## 为什么从树与二叉树计数开始

树是图论里最重要的结构，也是组合数学计数理论的试金石。同样是「$n$ 个节点的树」，加不加标签、有没有根、子树有没有顺序，答案完全不同：

- **有标号树**：$n^{n-2}$（凯莱公式）；
- **无标号树**：没有简单闭式，靠生成函数（奥特方程）；
- **有序有根树**：卡特兰数 $C_{n-1}$；
- **二叉树**：卡特兰数 $C_n$。

树计数最迷人的地方，是它把前两篇的所有工具——乘法原理、双射、生成函数、卡特兰数——全部拧成一股绳。而且「树」与「二叉树」之间那个看起来毫不相关的等价（首孩子/右兄弟变换），是理解递归结构的关键钥匙。<span class="marginnote">「树」几乎就是组合递归结构的同义词：任何「由根 + 若干子树构成」的对象都长成树的样子。数据结构里的一切（二叉树、堆、B 树、语法树、决策树、随机森林），机器学习的随机森林与 XGBoost 的树模型，都是这棵「组合树」的具体投影。计数树，就是在数「递归结构共有多少种形态」。</span>

## 1 有标号树：凯莱公式再回顾

**凯莱公式（Cayley）**：$n$ 个顶点的有标号树 $n^{n-2}$ 棵。给它加一个根，得到**有根有标号树** $n \cdot n^{n-2} = n^{n-1}$ 棵——因为根有 $n$ 种选择。

**矩阵树定理的一个预览。** 凯莱公式其实可以用**矩阵树定理**（Kirchhoff）证明：完全图 $K_n$ 的生成树数等于其拉普拉斯矩阵的任意主子式，算出 $n^{n-2}$。这个定理把「数生成树」变成「算一个行列式」——**从计数到线性代数**的又一次跨越，第三级《图论算法》会专门处理。<span class="marginnote">矩阵树定理说：图的生成树数 = 拉普拉斯矩阵任一余子式的行列式。对 $K_n$，拉普拉斯矩阵的特征值是 $0, n, n, \ldots, n$，由「特征值乘积 / n」得 $n^{n-2}$。凯莱公式只是这个普遍定理的第一个小样。</span>

## 2 有序树与二叉树：卡特兰的王国

**有序有根树（ordered rooted tree）**：根固定、且每个节点的子树**有左右/先后顺序**。$n$ 个顶点（$n-1$ 条边）的有序有根树共有

$$C_{n-1}$$

棵。**二叉树**（每个节点 0 或 2 个子节点的有序树）有 $n$ 个内点时共 $C_n$ 棵——两种树共用卡特兰数，因为它们的计数结构一模一样：**根 + 左子树 + 右子树**。

**验证小例。** 有 3 个内点的满二叉树有 $C_3 = 5$ 棵——上一节我们已经见过。有序有根树 $n=3$（2 条边）有 $C_2 = 2$ 棵：根下挂「两条链」或「一根分叉」。

**卡特兰递推的树版本。** $C_{n+1} = \sum_{i=0}^n C_i C_{n-i}$ 读作「根的一个孩子固定为左子树（$i$ 个内点）+ 右子树（$n-i$ 个内点）」——**树的递归结构 = 递推的递归结构**，卡特兰数的递推在树上找到了它的原乡。<span class="marginnote">二叉树的计数公式 $C_n = \frac{1}{n+1}\binom{2n}{n}$ 在算法分析里的经典用途：$n$ 个关键字能构成 $C_n$ 棵二叉搜索树（BST）的形态。这直接解释了为什么「随机 BST 的平均深度」是一道经典考题——形态数 $C_n$ 给了我们「先均匀随机一棵形态」的模型基础。</span>

## 3 首孩子/右兄弟：树与二叉树的一一对应

为什么「有序树」与「二叉树」会共享卡特兰数？因为存在一个**双射**——**首孩子/右兄弟变换（first-child / next-sibling）**：

- 在有序树中，每个节点指定「第一个孩子」和「下一个兄弟」；
- 把「第一个孩子」当作二叉树的**左子**，「下一个兄弟」当作二叉树的**右子**；
- 得到的是一棵二叉树，且变换可逆。

**例。** 根 $A$ 有三个孩子 $B, C, D$（从左到右）。变换后：$A$ 的左子是 $B$，$B$ 的右子是 $C$，$C$ 的右子是 $D$——有序树的一条「横排孩子链」被拉成了二叉树的「右链」。**水平关系变右子、垂直关系变左子**，一切顺序信息被保留，双向唯一。

**更具体的走一遍。** 考虑有序树：根 $R$，左孩子 $A$，$A$ 有一个孩子 $P$，$R$ 的第二个孩子 $Q$。变换规则逐点执行：
- $R$ 的第一个孩子是 $A$ → $R$ 的左子 $= A$；$R$ 的下一个兄弟无 → $R$ 的右子 $=$ 空；
- $A$ 的第一个孩子是 $P$ → $A$ 的左子 $= P$；$A$ 的下一个兄弟是 $Q$ → $A$ 的右子 $= Q$；
- $P$ 无孩子无兄弟、$Q$ 无孩子无兄弟 → 各自左、右子为空。

得到的二叉树：$R$ 左子 $A$，$A$ 左子 $P$、右子 $Q$。**还原**只需反过来读「左子 = 第一个孩子、右子 = 下一个兄弟」——双向都是机械执行，无歧义。<span class="marginnote">这个双射揭示了「树」与「二叉树」本质是同一个对象的不同姿势：一棵有序树左转 45° 就变成二叉树。它在编译器设计（语法树与表达式的二元化）、计算几何（区间树的旋转）里反复出现——「旋转」是树的灵魂操作。</span>

**推论。** $n$ 个顶点的有序有根树与「$n$ 个内点的满二叉树」一一对应，都数 $C_{n-1}$ / $C_n$（具体对应取决于边数/节点数的取法）。**「两个对象共享卡特兰数」的答案，永远是某个双射。**

## 4 公式解析：无标号树的奥特方程

无标号树没有闭式，但它的生成函数满足一个漂亮的**函数方程**（奥特，Otter 1948）。设 $t(x) = \sum_{n\ge1} t_n x^n$ 是无标号树（$t_n$ 为 $n$ 个顶点的无标号树数），则

$$t(x) = x + \frac{t(x)^2 + t(x^2)}{2}$$

**拆解这个方程：**
- **根 + 子树**：一棵树 = 根 + 若干无标号有根子树。无标号时「若干子树」是**多重集**（无序）。
- **$t(x)^2$ 的由来**：两棵子树组成的多重集，若先「有顺序」数是 $t(x)^2$，除以 2 修正无序；但若两棵子树**同构**（互相换位后不变），则「除以 2」多除了——要加回 $t(x^2)$ 这一项。
- **$t(x^2)$ 的修正**：$x^2$ 表示「把一棵树整体加倍」——两棵一模一样的子树，本来只有一种（无序）组合，$t(x)^2/2$ 把它算成半份，于是补 $t(x^2)/2$。

**一句话：$x$ 是根，$t(x)^2/2$ 是「两棵子树的无序组合」，$t(x^2)/2$ 是「同构双子树的补偿」。** 这类「平方减半再加镜像」的技巧，是处理**无标号（无序）组合结构**的核心语法——有标号用 EGF 的指数，无标号用这种「对称化」修正。<span class="marginnote">「除以 2 再补 $t(x^2)$」的手法，在波利亚计数里对应「多重集的循环指标」：元素互换（$S_2$ 群作用）的轨道计数。它比 EGF 里的 $e^{(\cdot)}$（那是「无序集合」的 EGF 版本）更精细——因为无标号结构还要考虑「子树彼此同构」造成的重复。</span>

**怎么解？迭代凑系数。** 把 $t(x) = x + \frac{t(x)^2 + t(x^2)}{2}$ 从 $t(x) = x$ 起步逐轮迭代，可逐项凑出系数：$t_1 = 1$（单个点）、$t_2 = 1$（一条边）、$t_3 = 1$（只有「根下挂两个孩子」一种形状）、$t_4 = 2$（一条链 vs 根下三孩子）、$t_5 = 3$。无标号树序列开头：$1, 1, 1, 2, 3, 6, 11, 23, 47, \ldots$——与有标号树 $1, 1, 3, 16, 125, \ldots$ 的悬殊一望便知。

**渐近。** 解出 $t_n$ 后，$t_n \sim C \cdot \alpha^n \cdot n^{-5/2}$，其中 $\alpha \approx 2.9558$、$C \approx 0.5349$。对比有标号树的 $n^{n-2}$，无标号树少了一个 $n!$ 的因子，但**指数增长的本质不变**。注意 $n^{-5/2}$ 这个幂律尾巴——它与「无标号结构」如影随形，从无标号图到无标号树、到无标号分拆，都是同一个「群作用尺寸」的痕迹。<span class="marginnote">「有标号」与「无标号」的增长之比是 $n!$：有标号树的 $n^{n-2}$ 约等于无标号树的 $t_n$ 乘上 $n!$ 的「对称性平均」。这个「差一个阶乘」的规律遍布组合学：标号带来 $n!$ 的自由度，无标号把它平均压缩掉。Ramanujan 与哈代的「圈法」能够统一处理这两族，是 20 世纪组合分析的巅峰之一。</span>

## 5 二叉搜索树与随机 BST

二叉树的计数在算法分析里有直接的舞台：$n$ 个不同关键字能构成 $C_n$ 棵**二叉搜索树（BST）**的形态（卡特兰数）。随机 BST 的统计因此都是卡特兰数的「派生问题」：

- **平均深度**：随机 BST 的平均查找深度约为 $2\ln n - 2$（常数约 $2 \times 0.693 \approx 1.386$）——这比平衡树的最优 $O(\log n)$ 差一个常数因子；
- **期望高度**：随机 BST 的期望高度约为 $4.311\ln n$——这是 1960 年代由雷耶斯（Régnier）等人分析的著名结果；
- **成功/失败查找的比较次数**：分别约为 $2\ln n$ 与 $2\ln n + 1$。

**这些数字为什么来自计数？** 因为「随机 BST」定义成「$C_n$ 种形态等概率」，而卡特兰数的递推 $C_{n+1} = \sum C_i C_{n-i}$ 恰好描述了「根把 $n$ 个关键字按大小分成左右两半」的概率结构——**递归结构的概率 = 递归计数的归一化**。<span class="marginnote">随机 BST 的平均深度 $2\ln n$ 是一个被反复引用的经典常数。它说明：哪怕输入随机，普通 BST 的期望性能也比「红黑树」「AVL 树」这些平衡结构差一个常数——但插入更简单。第三级《数据结构》会比较各平衡树的取舍，而这里的「卡特兰树形态计数」正是那个比较的数学底座。</span>

**二叉树与括号的最后一缕联系。** $n$ 个内点的满二叉树 ↔ $n$ 对合法括号 ↔ $C_n$。把二叉树的「前序遍历 + 叶子/内部」编码成括号串，就是一个经典双射——「树的形态」与「括号的嵌套」是同一枚硬币。**一切「递归嵌套」的结构都共享卡特兰数**，这是本章最重要的整体直觉。

## 6 四类树的对照总表

把「同一棵树」的四种标签制度并排，是理解「标签 × 顺序 × 根」三个维度如何相乘的最佳方式：

| 树的类型 | 顶点标号 | 子树顺序 | 根 | $n$ 个顶点的数量 |
| --- | --- | --- | --- | --- |
| 无标号树 | 无 | 无 | 无 | $t_n$（奥特方程，无闭式） |
| 有标号树 | 有 | 无 | 无 | $n^{n-2}$（凯莱） |
| 有序有根树 | 无 | 有 | 有 | $C_{n-1}$（卡特兰） |
| 有标号有根树 | 有 | 无 | 有 | $n^{n-1}$（凯莱 × 根） |

三个开关——**标号（$n!$）、顺序（卡特兰）、根（$\times n$）**——分别决定计数难度与答案形状。最难的组合是「无标号 + 无根 + 无序」，即第一行，它没有闭式；最容易的「有标号 + 有根」也只有 $n^{n-1}$。**计数难度 = 对称性丰富程度**，这是贯穿本节的判断标尺。<span class="marginnote">这张表还回答了「为什么卡特兰数这么常见」：只要结构是「递归嵌套且子树有序」，它的计数就是卡特兰；只要顶点「有身份」，答案就带 $n!$ 或 $n^n$。机器学习里树模型的「结构多样性」估计，通常也要先想清楚这三个开关的状态。</span>

## 7 小结

- **有标号树**：$n^{n-2}$（凯莱）；有根有标号树 $n^{n-1}$；矩阵树定理给出普遍化。
- **有序有根树 / 二叉树**：卡特兰数 $C_n$，递推 = 根 + 左子树 + 右子树。
- **首孩子/右兄弟双射**：有序树与二叉树一一对应，「水平变右子、垂直变左子」。
- **无标号树**：无闭式，奥特函数方程 $t(x) = x + \frac{t(x)^2 + t(x^2)}{2}$。
- 「除以 2 再补 $t(x^2)$」是处理无序组合结构的通用语法。
- 树是组合递归结构的原型：数据结构的树、机器学习的树模型都是它的投影。
- 随机 BST 的期望高度约 $4.311\ln n$、平均深度约 $2\ln n$，源自卡特兰数的形态计数。
- 三个开关（标号 / 顺序 / 根）决定计数难度：无标号+无序最难，有标号+有根最易。
- 满二叉树 ↔ 合法括号 ↔ 卡特兰数：一切递归嵌套结构共享同一计数。
- 无标号树的奥特方程用「除以 2 再补镜像」处理无序性，是波利亚思想的雏形。

在下一节，我们离开「数树」，转向组合设计的另一极：**组合设计**——如何在有限集合上安排对象，使得任意两个对象恰好相遇一次？这是拉丁方、有限域与图论的交叉路口。
