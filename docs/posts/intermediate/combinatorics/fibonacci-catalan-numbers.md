## 为什么从斐波那契与卡特兰数开始

在组合数学的「明星数列排行榜」上，斐波那契数与卡特兰数稳居前二。斐波那契数列 $1, 1, 2, 3, 5, 8, 13, 21, \ldots$ 从兔子繁殖问题诞生，却无处不在：花瓣、蜂巢、松果的螺旋、跳台阶、铺地砖、帕斯卡三角的对角线和。卡特兰数列 $1, 1, 2, 5, 14, 42, \ldots$ 则是一台「结构计数器」：括号配对、二叉树形态、多边形三角剖分、格点路径——几十种看似无关的结构，答案都是同一个卡特兰数。

这一节要做两件事：一是把斐波那契从「数列」升格为「计数工具」（铺砖、跳台阶），二是认识卡特兰数——它的公式里藏着一个「除以 $n+1$」的奇迹，值得单独拆解。<span class="marginnote">斐波那契与卡特兰还有一个微妙的亲缘：$F_{n+1}$ 数的是「用 1×1 与 1×2 砖铺 1×n 地板」的方法数，而卡特兰数数的是「用括号把 $n+1$ 项完全括起来」的方法数——一个靠「线性拼接」，一个靠「递归嵌套」，恰好代表了组合结构的两种基本语法：序列与递归树。机器学习里 RNN 的序列展开与 Transformer 的分层结构，也隐约对应这两种语法。</span>

## 1 斐波那契：从数列到计数工具

**斐波那契数列（Fibonacci sequence）**：$F_0 = 0,\ F_1 = 1,\ F_{n} = F_{n-1} + F_{n-2}$。它的通项是比内公式（上一节），但更重要的是**它数东西**。

**铺砖定理。** 用 $1\times1$ 方砖和 $1\times2$ 多米诺砖铺一条 $1\times n$ 的地板，铺法数为 $F_{n+1}$。

**证明。** 记铺法数为 $t_n$。看第一格：要么放一块 $1\times1$ 方砖，剩 $n-1$ 格，$t_{n-1}$ 种；要么放一块 $1\times2$ 多米诺，占满前两格，剩 $n-2$ 格，$t_{n-2}$ 种。两类互斥，故 $t_n = t_{n-1} + t_{n-2}$，且 $t_0 = t_1 = 1$——**与斐波那契同递推**，$t_n = F_{n+1}$。<span class="marginnote">「看第一步分两种情况」正是递推计数的最标准动作，与错排递推、卡特兰递推同源。铺砖问题在算法里是「爬楼梯（每次 1 或 2 阶）」的换皮版——爬 $n$ 级台阶、每步 1 或 2 级，方法数 $F_{n+1}$。LeetCode 上这道题每年都会被无数人刷到。</span>

**帕斯卡三角的对角和。** 沿帕斯卡三角的「次对角线」求和：$1;\ 1;\ 1+1;\ 1+2;\ 1+3+1;\ \ldots$，得到 $1,1,2,3,5,8,\ldots$——**组合恒等式**

$$\sum_{k} \binom{n-k}{k} = F_{n+1}$$

它的组合证明又是「算两次」：$n+1$ 种跳台阶方案中，恰用 $k$ 个「2 级跳」的方案数为 $\binom{n-k}{k}$（在 $n-k$ 个跳位里挑 $k$ 个合并成双跳）。

## 2 卡特兰数：一个公式，几十种结构

**卡特兰数（Catalan number）$C_n$**：第 $n$ 个卡特兰数为

$$C_n = \frac{1}{n+1}\binom{2n}{n} = \frac{(2n)!}{(n+1)!\, n!}$$

前几项：$C_0 = 1,\ C_1 = 1,\ C_2 = 2,\ C_3 = 5,\ C_4 = 14,\ C_5 = 42,\ C_6 = 132$。

**卡特兰数的两种等价定义：**
- **封闭公式**：$C_n = \frac{1}{n+1}\binom{2n}{n}$；
- **递推定义**：$C_{n+1} = \sum_{i=0}^{n} C_i\, C_{n-i}$，$C_0 = 1$。

递推式读作：**一个结构 = 左半结构 + 右半结构**，这是递归嵌套结构的通用递推。

**卡特兰数的生成函数。** 设 $C(x) = \sum_{n\ge0} C_n x^n$，递推式 $C_{n+1} = \sum C_i C_{n-i}$ 翻译成代数方程是 $C(x) = 1 + x\, C(x)^2$——「整体 = 空结构 + 一个根（$x$）把左子树和右子树套起来」。解一元二次方程得

$$C(x) = \frac{1 - \sqrt{1 - 4x}}{2x} = 1 + x + 2x^2 + 5x^3 + 14x^4 + \cdots$$

**「递推 → 生成函数 → 二次方程 → 根号」是一条完整的生产线**，这也解释了卡特兰为什么出现 $\binom{2n}{n}$：$\sqrt{1-4x}$ 的展开系数就是 $\binom{2n}{n}$ 的形状。<span class="marginnote">卡特兰数以比利时数学家欧仁·卡特兰（Eugène Charles Catalan）命名，但欧拉早在 1751 年就发现了「凸多边形三角剖分」的递推，这个数列其实叫「欧拉—卡特兰数」更公平。它出场的地方之多，以至于维基百科有专门的「应用列表」词条。</span>

## 3 卡特兰数的经典计数对象

几十种结构共享同一个卡特兰数，记下最常用的四种：

| 对象 | 描述 | 数量 |
| --- | --- | --- |
| 括号配对 | $n$ 对括号的合法排列 | $C_n$ |
| 二叉树 | $n+1$ 个叶子的满二叉树 / $n$ 个内点的二叉搜索树 | $C_n$ |
| 三角剖分 | 凸 $(n+2)$ 边形的不相交对角剖分 | $C_n$ |
| Dyck 路径 | 从 $(0,0)$ 到 $(2n,0)$ 的格点路径，每步 $(1,+1)$ 或 $(1,-1)$，始终不落 $x$ 轴下方 | $C_n$ |

**例：括号。** $n=3$ 时 $C_3 = 5$：`((()))`、`(()())`、`(())()`、`()(())`、`()()()`。<span class="marginnote">括号配对的合法性判据：从左往右数，任何前缀里「左括号数 ≥ 右括号数」。这个「前缀约束」正是 Dyck 路径「不落 $x$ 轴下方」的翻译。编译原理里的语法分析、LISP 的括号世界、JSON 的嵌套结构，都由卡特兰数统治。</span>

**例：二叉树。** 有 $n$ 个内点的**有序二叉树**（每个结点 0 或 2 个子结点）共 $C_n$ 棵。$n=2$ 时有 2 棵（根左子树一个叶、或根右子树一个叶）。

## 4 公式解析：为什么是 $\frac{1}{n+1}\binom{2n}{n}$

卡特兰公式里那个 $n+1$ 的分母是最神秘的部分。用 **Dyck 路径 + 反射原理** 讲清它：

**数 Dyck 路径。** 从 $(0,0)$ 到 $(2n,0)$、每步 $\pm1$ 的路径，若不设约束，总数是 $\binom{2n}{n}$（$2n$ 步中 $n$ 步向上）。约束「不落 $x$ 轴下方」把它砍成 $C_n$——砍掉的比例恰好是 $1 : (n+1)$。

**反射原理（reflection principle）。** 统计「坏路径」：首次落到 $-1$ 的路径。把这条坏路径在首次触 $-1$ 之后的部分关于直线 $y=-1$ 反射，得到一条从 $(0,0)$ 出发、**终点在 $(2n, -2)$** 的路径。反之亦然——这是双射。而到 $(2n,-2)$ 的路径有 $n+1$ 步向下，共 $\binom{2n}{n+1}$ 条。于是

$$C_n = \binom{2n}{n} - \binom{2n}{n+1} = \binom{2n}{n}\left(1 - \frac{n}{n+1}\right) = \frac{1}{n+1}\binom{2n}{n}$$

**拆解：**
- **坏路径数** $=\binom{2n}{n+1}$：反射构造的「向下步数 $n+1$」路径；
- **反射是双射**：坏路径 ↔ 终点在 $-2$ 的路径，一一对应；
- **相减即得**：好路径 = 全部 $-$ 坏路径，化简出 $\frac{1}{n+1}$。

**「除以 $n+1$」不是巧合**：它来自「$(n+1)$ 个循环对称的等价类」——这正是循环引理（cycle lemma）的思想。$n=4$：$C_4 = \frac{1}{5}\binom{8}{4} = 14$。<span class="marginnote">反射原理的威力远超卡特兰数：任何「前缀和 ≥ 0」的计数，都可以用「反射掉坏路径」的套路。它在随机游走、赌徒破产问题、选票问题（Bertrand 的 ballot theorem）中反复出现，是概率论与组合数学共享的利器。</span>

## 5 公式解析：递推的「第一刀」

卡特兰递推 $C_{n+1} = \sum C_i C_{n-i}$ 为什么成立？以「$n+1$ 个叶子、每点 0 或 2 子」的满二叉树为例：

**看根**：根要么没有子（$n=0$），要么有左、右两个子树。
**切第一刀**：设左子树有 $i$ 个内点、右子树有 $n-i$ 个内点，$i$ 从 $0$ 到 $n$。
**相乘求和**：左子树 $C_i$ 种、右子树 $C_{n-i}$ 种，乘法原理得 $C_i C_{n-i}$；对不同 $i$ 分类相加（加法原理），得递推。

「**一分为二，各管各的，分类求和**」——这十二个字是递推计数的灵魂，从铺砖到错排到卡特兰，屡试不爽。<span class="marginnote">这个「第一刀」拆分与快速排序、归并排序的「分成两半递归处理」如出一辙：计算机算法里的递归分治，正是组合结构中「左半 × 右半」的同构。卡特兰数因此出现在随机二叉搜索树的期望深度分析里——平均情况性能的推导总能看到 $C_n$ 的身影。</span>

## 6 斐波那契与卡特兰：两种语法对照

| 维度 | 斐波那契 | 卡特兰 |
| --- | --- | --- |
| 递推 | $F_n = F_{n-1}+F_{n-2}$（一维、线性） | $C_{n+1} = \sum C_i C_{n-i}$（卷积、非线性） |
| 结构语法 | 线性拼接（序列） | 递归嵌套（树） |
| 通项 | $\varphi^n/\sqrt5$（指数，基 $\approx1.618$） | $\frac{4^n}{n^{3/2}\sqrt\pi}$（指数 ÷ 幂律） |
| 增长 | $O(\varphi^n)$ | $O(4^n n^{-3/2})$ |
| 典型对象 | 铺砖、跳台阶、蜂巢 | 括号、二叉树、三角剖分 |

**增长对比**：两者都以指数增长，但卡特兰除了一道 $n^{-3/2}$ 的「幂律尾巴」——嵌套结构的方案数增长比线性拼接更快。**斐波那契的 $\varphi \approx 1.618$ 与卡特兰的 $4$，分别是「序列」与「树」两种结构的「增长常数」。**

## 7 小结

- **斐波那契** $F_n = F_{n-1}+F_{n-2}$：比内公式 $\frac{\varphi^n - \psi^n}{\sqrt5}$；铺 $1\times n$ 地板有 $F_{n+1}$ 种。
- 帕斯卡三角对角线和：$\sum_k \binom{n-k}{k} = F_{n+1}$。
- **卡特兰数** $C_n = \frac{1}{n+1}\binom{2n}{n}$：括号、二叉树、三角剖分、Dyck 路径四种经典对象。
- **反射原理**把「坏路径」反射成可数路径，得 $\binom{2n}{n+1}$，相减即得卡特兰公式。
- **第一刀递推** $C_{n+1} = \sum C_i C_{n-i}$：左半 × 右半，分类求和。
- 斐波那契 = 序列语法，卡特兰 = 树语法；两者是组合结构的两大基本范式。

在下一节，我们处理另一对「以数学家命名」的数列：**斯泰林数与贝尔数**——它们分别数「把 $n$ 个元素分成 $k$ 个环」与「分成若干子集」，是 EGF 舞台上的压轴主角。
