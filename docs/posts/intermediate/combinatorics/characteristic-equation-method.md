## 为什么从特征方程法开始

上一节我们认识了常系数线性递推，并首次见到「特征方程」这个词。这一节把**特征方程法**本身放大成一件趁手的工具：它把「解递推」这个看起来要靠灵感的问题，压缩成一套**只要会解多项式方程就能照做的流程**——列特征方程、求根、写通解、代入初值。更重要的是，我们要把重根、复根这两类「麻烦情形」逐个击破，并回答一个根本问题：**为什么这个方法一定有效？**

特征方程法的地位，相当于常微分方程里的「$e^{rx}$ 试探解」、线性代数里的「特征向量」、生成函数里的「部分分式」——它是同一套「指数分解」思想在递推世界的化身。<span class="marginnote">波利亚的引语恰好点中特征方程法的本质：把「解递推」这个难问题，分解成「解多项式」「解线性方程组」两个简单问题。「求根」与「定系数」各自机械，组合起来却能处理几乎所有常系数递推。</span>

## 1 方法的全貌：三步走

**特征方程法（method of characteristic equation）** 求解 $k$ 阶常系数齐次递推 $a_n = c_1 a_{n-1} + \cdots + c_k a_{n-k}$ 的标准流程：

**第一步，列特征方程。** 令 $a_n = r^n$ 代入，得 $r^k - c_1 r^{k-1} - \cdots - c_k = 0$。

**第二步，写通解。** 根据根的「种类」分别处理：

| 根的类型 | 通解中对应的部分 |
| --- | --- |
| 互异实根 $r_i$ | $A_i r_i^{\,n}$ |
| $m$ 重实根 $r$ | $(A_0 + A_1 n + \cdots + A_{m-1} n^{m-1})\, r^n$ |
| 共轭复根 $\rho e^{\pm i\theta}$ | $\rho^n\bigl(B\cos n\theta + C\sin n\theta\bigr)$ |

**第三步，代入初值定系数。** 解一个 $k$ 元线性方程组，得到 $A_i$（或 $B, C$）。方程组的系数矩阵是**范德蒙德矩阵**（第 $j$ 列为 $r_j^{i}$），行列式 $\prod_{i<j}(r_j - r_i) \neq 0$——只要根互异，初值就**唯一确定**系数，这正是「$k$ 个初值定 $k$ 个系数」的代数保证。

**一个综合例子。** 解 $a_n = 2a_{n-1} + a_{n-2} - 2a_{n-3}$，初值 $a_0=1,\ a_1=2,\ a_2=0$。
特征方程 $r^3 - 2r^2 - r + 2 = 0 = (r-2)(r-1)(r+1)$，根 $2, 1, -1$；
通解 $a_n = A\cdot 2^n + B\cdot 1^n + C\cdot(-1)^n$；
初值：$A + B + C = 1$，$2A + B - C = 2$，$4A + B + C = 0$；
解得 $A = -\tfrac13,\ B = \tfrac43,\ C = 0$，故 $a_n = \tfrac13(4 - 2^n)$。<span class="marginnote">注意 $r = 1$ 时 $1^n = 1$ 恒为常数——特征方程有根 1 意味着数列含「常数分量」，这在非齐次问题里尤其要当心（常数右端会与它撞根）。</span>

## 2 重根：补 $n$ 的多项式

重根的处理规则（上一节已见）：$m$ 重根 $r$ 在通解中贡献

$$(A_0 + A_1 n + \cdots + A_{m-1} n^{m-1})\, r^n$$

**为什么恰好是「乘 $n$ 的多项式」而不是别的？** 从生成函数看最清楚：递推的分母是 $\prod(1 - r_i x)^{m_i}$，其中 $m_i$ 是 $r_i$ 的重数。部分分式中 $\frac{1}{(1-rx)^m}$ 的系数是 $\binom{n+m-1}{m-1}r^n$，是「$r^n \times (n$ 的 $m-1$ 次多项式)」——与特征方程的通解完全对应。<span class="marginnote">「重根乘 $n$」可以这样直觉记忆：$m$ 重根相当于「$m$ 个基本解长得太像」，需要补 $n, n^2, \ldots, n^{m-1}$ 让它们「分开」。类似地，微分方程 $y'' - 2y' + y = 0$ 的通解是 $e^x(A + Bx)$——离散与连续的重根补救如出一辙。</span>

**例子。** $a_n = 6a_{n-1} - 12a_{n-2} + 8a_{n-3}$：特征方程 $r^3 - 6r^2 + 12r - 8 = (r-2)^3$，根 2 是三重根。通解 $a_n = (A + Bn + Cn^2)2^n$——三重根配二次多项式。

## 3 复根：周期与振荡

当特征方程有**共轭复根**，通解里的 $r^n$ 可以写成三角函数形式，数列呈现振荡甚至周期性。

**例子。** $a_n = a_{n-1} - a_{n-2}$，$a_0 = a_1 = 1$。特征方程 $r^2 - r + 1 = 0$，根 $r = \frac{1 \pm i\sqrt3}{2} = e^{\pm i\pi/3}$。通解可写为

$$a_n = B\cos\frac{n\pi}{3} + C\sin\frac{n\pi}{3}$$

代入初值得 $a_n = \cos\frac{n\pi}{3} + \frac{1}{\sqrt3}\sin\frac{n\pi}{3}$，数列为 $1, 1, 0, -1, -1, 0, 1, 1, \ldots$——**周期 6 的振荡序列**。<span class="marginnote">「递推会给出周期序列」看起来不可思议，其实只是复根的模 $|\rho| = 1$（在单位圆上）：模为 1 的根给出纯周期，模小于 1 给出衰减振荡，模大于 1 给出爆炸振荡。<strong>根的模决定了振荡是「死」是「活」</strong>，这是控制论里「系统稳定性 ⇔ 极点都在单位圆内」的离散版。</span>

**如何从根直接看出周期。** 若 $r = e^{i\theta}$ 是根，则 $\theta$ 的有理数性质决定周期：$\theta = \pi/3$ 时 $2\pi/\theta = 6$ 是整数，序列周期为 6。**复根不是「麻烦」，而是「周期」的代数签名。**

## 4 公式解析：为什么特征方程法有效

把「为什么 $r^n$ 是基本解」用生成函数严格化，是理解整件事的钥匙。设 $a_n$ 满足递推，$A(x) = \sum a_n x^n$。上一节我们算过：

$$A(x) = \frac{P(x)}{Q(x)}, \qquad Q(x) = 1 - c_1 x - c_2 x^2 - \cdots - c_k x^k$$

- **$Q(x)$ 与特征多项式的对偶**：$Q(x) = x^k \cdot \left(x^{-k} - c_1 x^{-(k-1)} - \cdots - c_k\right)$，把它乘 $x^k$ 再反转系数，正好是特征多项式 $r^k - c_1 r^{k-1} - \cdots - c_k$。**$Q(x)$ 的根是特征根的倒数**。
- **部分分式**：$A(x)$ 拆成 $\sum \frac{c_{i,j}}{(1-r_i x)^j}$，每项都是 $\binom{n+j-1}{j-1} r_i^n$ 的生成函数。
- **系数合成**：不同根、重根分别贡献 $A_i r_i^n$ 与多项式 × $r^n$，正是通解表。

**结论：特征方程法 = 生成函数法的「代数投影」**。生成函数先求和再分解分母，特征方程直接对分母求根——两条路殊途同归，前者适合证明，后者适合手算。<span class="marginnote">这个「$Q(x)$ 的根 = 特征根的倒数」的对应，让两套方法的术语可以互相翻译：生成函数说「分母的奇异点」，特征方程说「特征值」，矩阵说「伴随矩阵的特征值」，三个词一个意思。掌握翻译，就掌握了递推的全部地形图。</span>

## 5 特征方程法的边界

方法虽强，也有明确的天花板——认清边界才能选对工具：

| 情形 | 特征方程法 | 更合适的工具 |
| --- | --- | --- |
| 常系数线性 | ✓ 首选 | 生成函数（证明方便） |
| 变系数（系数含 $n$） | ✗ 失效 | EGF（求导对应） |
| 非齐次右端复杂 | 特解猜测繁琐 | 生成函数（直接求和） |
| 分治型 $T(n)=2T(n/2)+n$ | ✗ 下标减半 | 主定理（第三级《算法》） |
| 非线性（如 $a_n = a_{n-1}a_{n-2}$） | ✗ | 换元 / 对数化 |

**易错点｜辨析：** 特征方程法**只对常系数线性递推**成立。看到系数含 $n$（如 $n a_{n-1}$）、或下标减半（如 $a_{n/2}$）、或非线性（如乘积），立刻停止套用——**先看结构，再选方法**，是递推问题的第一原则。

## 6 三个实战例：从易到难

把方法在不同「题型」上各跑一遍，巩固手感。

**例一（互异根，送分）。** $a_n = a_{n-1} + 6a_{n-2}$，$a_0 = 2,\ a_1 = 3$。$r^2 - r - 6 = (r-3)(r+2) = 0$，根 $3, -2$。通解 $a_n = A3^n + B(-2)^n$；初值得 $A + B = 2,\ 3A - 2B = 3$，解 $A = \tfrac75,\ B = \tfrac35$。答案 $a_n = \tfrac15(7\cdot 3^n + 3(-2)^n)$。注意 $(-2)^n$ 的正负交替——**负根制造震荡**。

**例二（重根，警惕）。** $a_n = 2a_{n-1} - a_{n-2}$，$a_0 = 1,\ a_1 = 2$。特征 $(r-1)^2 = 0$，根 1 是二重根。通解 $a_n = A + Bn$（因为 $1^n = 1$）。初值 $A = 1,\ A + B = 2 \Rightarrow B = 1$，故 $a_n = n + 1$。**特征根 1（二重）给出线性数列**——这正是「等差数列」的递推版本。

**例三（复根，周期）。** $a_n = \sqrt2\, a_{n-1} - a_{n-2}$，$a_0 = 1,\ a_1 = 1$。特征 $r^2 - \sqrt2 r + 1 = 0$，根 $e^{\pm i\pi/4}$。通解 $a_n = \cos\frac{n\pi}{4} + C\sin\frac{n\pi}{4}$，初值定出 $C = 0$，故 $a_n = \cos\frac{n\pi}{4}$：$1, \tfrac{\sqrt2}{2}, 0, -\tfrac{\sqrt2}{2}, -1, \ldots$，周期 8。**纯振荡且不衰减**——因为根在单位圆上。<span class="marginnote">三个例子覆盖三种根型：互异实根（指数 + 交替）、二重根（多项式）、单位圆复根（纯周期）。<strong>「根的形状」直接决定「数列的形状」</strong>——读懂根，就预知了数列的一生。</span>

## 7 小结

- **特征方程法三步**：列特征方程 → 按根的类型写通解 → 代入初值定系数。
- 通解三表：互异根 $A_i r_i^n$、$m$ 重根 $\times(n$ 多项式$)$、共轭复根 $\rho^n(B\cos n\theta + C\sin n\theta)$。
- **重根补 $n$**：部分分式中 $\frac{1}{(1-rx)^m}$ 系数是 $\binom{n+m-1}{m-1}r^n$。
- **复根 = 周期/振荡**：根的模决定衰减还是爆炸，角度 $\theta$ 决定周期。
- **有效性来源**：生成函数分母 $Q(x)$ 的根是特征根的倒数，部分分式自动生成通解。
- 边界：变系数、分治、非线性不适用——先看结构再选方法。
- 负根制造正负交替，二重根 1 给出等差数列，单位圆复根给出纯周期——根的形状预告数列的形状。
- 求解完务必验证前两三项：代回原递推核对，是成本最低的「测试」。
- 范德蒙德矩阵的非零行列式保证「$k$ 个初值唯一确定 $k$ 个系数」。
- 三例实战：互异根（指数+交替）、二重根（多项式）、单位圆复根（纯周期）覆盖全部根型。
- 特征方程与生成函数、矩阵幂、差分方程四角相通，是递推世界的「中心枢纽」。

- 「求根 + 定系数」的机械流程背后，是生成函数分母与特征多项式的一一对应。
- 三例实战对应三种数列性格：指数增长（互异根）、线性增长（二重根 1）、纯周期（单位圆复根）。

在下一节，我们把「递推」的视角从「数列」切换到「**差分方程**」：把递推看成对函数做差分运算，用算子代数统一处理——这是通向高阶差分与数值分析的门。
