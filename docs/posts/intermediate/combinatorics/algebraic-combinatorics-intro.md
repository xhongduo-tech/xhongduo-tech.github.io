## 为什么从代数组合初步开始

走到这一节，我们其实已经悄悄用了大量代数：生成函数把数列变成函数、特征方程把递推变成多项式求根、斯泰林数把幂换成下降阶乘、多项式方法把计数变成「次数够不够」。**代数组合（algebraic combinatorics）**把这些线索正式命名为一门学科：用**代数结构**——群、环、多项式、矩阵、表示论——来解决组合问题。

这一节做三件事：第一，用**波利亚计数定理**把「数轨道」系统性升级（它统摄圆排列、伯恩赛德、项链问题）；第二，用**矩阵与谱**看图的秘密（$A^n$ 的元素就是游走数）；第三，用**格与莫比乌斯反演**把容斥原理推广到一般偏序集。三者都是「代数组合」的经典支柱，也是你日后读现代组合学论文的通行证。<span class="marginnote">代数组合是组合数学与现代代数的交叉学科，20 世纪中期由 Rota、Stanley 等人奠定。它最迷人的地方是「互相成就」：代数给组合提供工具（矩阵、多项式、群作用），组合给代数提供问题与例子（格、置换群、多项式恒等式）。斯坦利的名著《枚举组合学》（Enumerative Combinatorics）是这门学科的地图。</span>

## 1 波利亚计数定理：数轨道的总开关

从圆排列到无标号图，我们反复在做同一件事：**数「群作用下的轨道」**。圆排列除以 $n$、项链除以 $2n$、无标号图除以对称群的平均——这些都是**伯恩赛德引理**的实例。**波利亚计数定理（Pólya's enumeration theorem）**把它推广成一套系统化的机器。

**伯恩赛德引理**：群 $G$ 作用在集合 $X$ 上，轨道数为

$$\#\text{轨道} = \frac{1}{|G|} \sum_{g \in G} |\mathrm{Fix}(g)|$$

其中 $\mathrm{Fix}(g)$ 是 $g$ 固定的元素数。

**波利亚的循环指标**。若要数「用 $c$ 种颜色给对象染色（旋转/翻转后相同算一种）」，把置换按循环类型打包：群 $G$ 的**循环指标**为

$$Z_G(a_1, a_2, \ldots) = \frac{1}{|G|} \sum_{g \in G} a_1^{c_1(g)} a_2^{c_2(g)} \cdots$$

其中 $c_i(g)$ 是置换 $g$ 中长为 $i$ 的循环个数。则**染色方案数 = $Z_G(c, c, \ldots, c)$**（把每个 $a_i$ 换成颜色数 $c$）。

**例（项链）。** 4 颗珠子的项链（旋转视为同一种），用 3 种颜色：旋转群 $\mathbb{Z}_4$ 的 4 个置换分别有循环类型 $(4)$、$(1,3)$、$(2,2)$、$(1,1,1,1)$，循环指标

$$Z = \frac{1}{4}\left(a_1^4 + a_1^2 a_2 + a_2^2 + a_4\right)$$

代入 $a_i = 3$：$\frac{1}{4}(81 + 9 + 9 + 3) = \frac{102}{4} = 25.5$？——**不对**，需重查循环类型：旋转 $0°$ 固定全部 $3^4$；旋转 $90°/270°$ 各固定 $3$（所有珠子同色）；旋转 $180°$ 固定 $3^2$。故 $\frac{1}{4}(3^4 + 3 + 3^2 + 3) = \frac{81+3+9+3}{4} = \frac{96}{4} = 24$。<span class="marginnote">这里演示了循环指标的两个易错点：<strong>旋转 $90°$ 的循环类型是 $(4)$（一个 4-循环），对应「所有 4 颗同色」</strong>；旋转 $180°$ 是 $(2,2)$（两个 2-循环）。把每个置换的循环数清了，代入颜色数 $c$ 即可——波利亚定理把「手工数对称」升级成「查循环指标」。</span>

**回顾统一。** 圆排列 $= Z_{\mathbb{Z}_n}(1,1,\ldots)$ 代入 $a_i=1$（「1 种颜色」=「结构无染色」）退化为伯恩赛德；项链再除翻转是二面体群 $D_n$。**一整片「除以对称性」的领地，被波利亚一个公式圈了进来。**

**再算一条手链。** 5 颗珠子、2 种颜色的手链（旋转与翻转都算同一条）：二面体群 $D_5$ 有 10 个置换——5 个旋转（含恒等）与 5 个翻转。循环指标

$$Z_{D_5} = \frac{1}{10}\left(a_1^5 + 4a_5 + 5a_1 a_2^2\right)$$

代入 $a_i = 2$：$\frac{1}{10}(32 + 4\cdot2 + 5\cdot 2\cdot 4) = \frac{32+8+40}{10} = 8$。8 条手链——用枚举手工核对是笨办法，波利亚一行给出。**旋转群与二面体群的循环指标是两张可查的「标准表」**，工程里做对称计数时直接取用。

## 2 矩阵与谱：图的代数面孔

给图 $G$ 写**邻接矩阵** $A$（$A_{ij} = 1$ 若 $i \sim j$，否则 0），图的性质就藏在矩阵里。

**游走计数。** $(A^n)_{ij}$ 恰好等于「从 $i$ 到 $j$ 的长度为 $n$ 的游走数」。证明是「分步相乘」：$(A^2)_{ij} = \sum_k A_{ik}A_{kj}$ 数「$i\to k\to j$」；$n$ 次幂就是 $n$ 步的笛卡尔积计数——**矩阵乘法 = 组合的乘法原理**。

**矩阵树定理（Kirchhoff）。** 图 $G$ 的生成树数 $\tau(G)$ 等于其拉普拉斯矩阵 $L = D - A$（$D$ 为度矩阵）的任意一个余子式（代数余子式）。这一定理把「数树」变成「算行列式」，凯莱公式 $n^{n-2}$ 只是它对完全图 $K_n$ 的特例。<span class="marginnote">拉普拉斯矩阵的谱（特征值）携带图的大量信息：连通性、二部性、扩展性质。谱图论（spectral graph theory）研究「图的特征值 ↔ 图的结构」，在网页排序（PageRank 的本质是随机游走）、谱聚类、图神经网络（GNN 的消息传递）里都是核心工具。矩阵是图在代数世界的「全息照片」。</span>

**例。** 路径图 $P_3$（顶点 $1-2-3$）的邻接矩阵 $\begin{pmatrix}0&1&0\\1&0&1\\0&1&0\end{pmatrix}$。$(A^2)_{13} = A_{12}A_{23} = 1$：从 1 到 3 的长度 2 游走只有 $1\to2\to3$ 一条——矩阵乘积自动数出来了。

## 3 格与莫比乌斯反演：容斥原理的推广

**容斥原理**（第二篇）可以看作「在子集格上做反演」。把它推广到一般偏序集，得到 **莫比乌斯反演（Möbius inversion）**。

**偏序集上的莫比乌斯函数。** 对偏序集 $P$，定义 $\mu(x, y)$（$x \le y$）：

$$\mu(x,x) = 1, \qquad \sum_{x \le z \le y} \mu(x, z) = 0 \ (x < y)$$

**反演公式**：若 $g(y) = \sum_{x \le y} f(x)$，则

$$f(y) = \sum_{x \le y} \mu(x, y)\, g(x)$$

**数论版。** 取偏序集为「整除格」（$x \le y \iff x \mid y$），莫比乌斯函数就是数论里的 $\mu$：$\mu(1)=1$、$\mu(p_1\cdots p_k) = (-1)^k$、含平方因子则 $\mu = 0$。于是

$$g(n) = \sum_{d \mid n} f(d) \iff f(n) = \sum_{d \mid n} \mu(d)\, g\!\left(\frac{n}{d}\right)$$

这正是第二级《数论》里莫比乌斯反演的标准形式——它在「容斥原理的数论化身」的位置上闪闪发光。

**一个完整反演例。** 用反演重算欧拉函数。已知 $\sum_{d \mid n} \varphi(d) = n$（$\varphi$ 的经典求和公式），令 $g(n) = n$、$f(d) = \varphi(d)$，反演得

$$\varphi(n) = \sum_{d \mid n} \mu(d)\, \frac{n}{d}$$

以 $n = 12$ 验证：约数 $d = 1,2,3,4,6,12$，$\mu$ 分别为 $1, -1, -1, 0, 1, 0$，故 $\varphi(12) = 12 - 6 - 4 + 2 = 4$——与第二篇容斥算出的 $\varphi(12) = 4$ 完全一致。**同一个数，容斥一条路、反演另一条路，殊途同归**——反演就是「有组织的容斥」。<span class="marginnote">莫比乌斯反演把容斥原理从「集合」推广到「任意偏序集」：集合的包含关系、整除关系、格上的次序，共用同一套反演骨架。欧拉函数 $\varphi(n)$ 由 $\varphi = \mu * \mathrm{id}$ 给出，即 $\varphi(n) = \sum_{d|n}\mu(d)\frac{n}{d}$——一个公式同时覆盖「容斥」与「数论」两大场景。第二级《数论》会详细展开，这里先埋下「反演是容斥的推广」这枚种子。</span>

## 4 公式解析：三个支柱如何互相咬合

把本专题的所有「代数化」工具在最终视角下再看一遍：

| 支柱 | 代数工具 | 组合对象 | 关键等式 |
| --- | --- | --- | --- |
| 波利亚计数 | 群作用 / 循环指标 | 轨道、染色、项链 | $Z_G(c,\ldots,c)$ |
| 谱图论 | 矩阵 / 特征值 | 图、游走、生成树 | $(A^n)_{ij}$、$\tau(G)$ |
| 莫比乌斯反演 | 偏序集 / 反演 | 容斥、数论函数 | $f = \mu * g$ |

**它们有一条共同的「代数化」逻辑：把组合对象变成代数对象，用代数的运算（群平均、矩阵乘、反演和）一次性处理所有对称与嵌套。** 生成函数是「把数列变成函数」，特征方程是「把递推变成求根」，斯泰林数是「在两组基之间换基」，多项式方法是「用次数判定存在性」——**全部是「代数化」的同一场运动**。

**总结性回顾全专题的主线：**
**第一篇**：计数原理 → 排列组合 → 鸽巢拉姆齐（组合的「骨」）；
**第二篇**：容斥 → 生成函数 → 经典数列（组合的「肉」）；
**第三篇**：递推 → 差分 → 图与树 → 设计 → 匹配 → 多项式 → 代数组合（组合的「魂」）。

学完这三篇，你拥有的是：**一套计数语言（生成函数）、一套存在性工具（鸽巢/拉姆齐/多项式）、一套对称性武器（波利亚/伯恩赛德）、一套递归语法（递推/卡特兰）、以及通向现代组合学（代数组合、谱理论、零和理论）的地图**。<span class="marginnote">「从极限到大模型」的主线里，组合数学是离散世界的总入口：极限与连续由分析学负责，而「有限结构的计数、存在与优化」由组合数学负责。大模型里的 token 序列计数、Attention 的排列结构、深度学习的状态空间大小估计，最终都会落回这二十五节的某一条定理上——这门课到此，离散的脚手架已经搭好。</span>

## 5 小结

- **代数组合**：用群、环、多项式、矩阵、表示论解决组合问题——「代数化」是贯穿本专题的主线。
- **波利亚计数定理**：循环指标 $Z_G$ 代入颜色数 $c$ 即得染色轨道数，统摄圆排列、项链、无标号结构。
- **谱图论**：$(A^n)_{ij}$ 数游走、Kirchhoff 矩阵树定理算生成树、特征值承载图的结构信息。
- **莫比乌斯反演**：容斥原理在任意偏序集上的推广；整除格上正是数论版 $\mu$。
- **三大支柱互咬合**：群平均、矩阵乘、反演和，都是「用代数运算一次性处理对称与嵌套」。
- 全专题回顾：计数语言（生成函数）＋ 存在性工具（鸽巢/拉姆齐/多项式）＋ 对称性武器（波利亚）＋ 递归语法（递推/卡特兰）。
- 手链示例：$D_5$ 循环指标 $Z = \frac{1}{10}(a_1^5 + 4a_5 + 5a_1a_2^2)$，2 色手链共 8 条。
- 欧拉函数 $\varphi(n) = \sum_{d|n}\mu(d)\frac nd$ 是莫比乌斯反演与容斥殊途同归的样板。
- 谱图论的三件套：$(A^n)_{ij}$ 数游走、$L$ 的余子式数生成树、特征值决定扩展性。

- 代数组合的三支柱——群平均（Pólya）、矩阵乘（谱图）、反演和（Möbius）——是「代数化」的三副面孔。

从《加法与乘法原理》到《代数组合初步》，这二十五节把组合数学的骨、肉、魂都搭了一遍。下一站，你可以带着这套离散语言，去啃《概率论与数理统计》（组合计数在那里变成概率分布），或进入《离散数学》把逻辑、关系与图论系统地再走一遍——组合数学的大门，从此向你敞开。
