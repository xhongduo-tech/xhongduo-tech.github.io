## 为什么从多项式定理开始

上一节的二项式定理只处理两个字母 $(a+b)^n$。现实世界的展开很少只有两项：掷一枚骰子有 6 种面，$(x_1 + x_2 + \cdots + x_6)^n$ 才是骰子问题的正确舞台；统计文本时把词表 $V$ 个词各展开一维，$(p_1 + p_2 + \cdots + p_V)^n$ 描述了「$n$ 个词按概率分布抽样」的模型。

**多项式定理（multinomial theorem）** 把二项式定理推广到任意 $m$ 个变量，它给出的系数——**多项式系数** $\dfrac{n!}{k_1!\,k_2!\cdots k_m!}$——正是我们在《圆排列与可重排列》里见过的那个「重复排列」公式。一次展开，三重身世：它是二项式系数的推广、是可重排列数的别名、是概率论里**多项分布**的权重。这一节要把这三层身份打通。<span class="marginnote">从二项式系数到多项式系数，公式结构几乎不变——分母从 $k!(n-k)!$ 变成 $k_1!\cdots k_m!$。这正应了希尔伯特那句「数学是整体」：推广往往不是发明新东西，而是看清旧东西的结构可以容纳更多角色。</span>

## 1 多项式定理：二项式定理的推广

**多项式定理**：对任意 $m$ 个变量 $x_1, x_2, \ldots, x_m$ 与非负整数 $n$，

$$(x_1 + x_2 + \cdots + x_m)^n = \sum_{k_1 + k_2 + \cdots + k_m = n} \binom{n}{k_1, k_2, \ldots, k_m} x_1^{k_1} x_2^{k_2} \cdots x_m^{k_m}$$

其中求和跑遍所有满足 $k_1 + \cdots + k_m = n$ 的非负整数 $k_i$，而**多项式系数**为

$$\binom{n}{k_1, k_2, \ldots, k_m} = \frac{n!}{k_1!\, k_2!\, \cdots\, k_m!}$$

**例：三项式。** $(x + y + z)^2$ 的展开：次数组合 $k_x + k_y + k_z = 2$ 有 6 种，系数分别是 $\binom{2}{2,0,0}=1,\ \binom{2}{1,1,0}=2,\ \binom{2}{0,0,2}=1$ 等，故

$$(x+y+z)^2 = x^2 + y^2 + z^2 + 2xy + 2xz + 2yz$$

「十字相乘」里那个 $2xy$ 的系数 2，正是 $\binom{2}{1,1,0} = 2$：从两个因子中选一个取 $x$、另一个取 $y$，有 2 种方式。

**项数有多少？** $(x_1+\cdots+x_m)^n$ 的项数等于「把 $n$ 拆成 $m$ 个非负整数之和」的方式数，即多重集组合 $\binom{n+m-1}{m-1}$。当 $m=3,n=3$ 时 $\binom{5}{2}=10$ 项；当 $m=6,n=10$ 时 $\binom{15}{5}=3003$ 项——展开全部写出来已经不现实，这正是「多项式定理描述结构、计算机处理数值」的分工由来。

**再看三项立方。** $(x + y + z)^3$ 的展开有 $\binom{3+3-1}{3-1} = 10$ 项（次数组合数），按多项式定理：

$$(x+y+z)^3 = x^3+y^3+z^3 + 3x^2y+3x^2z+3xy^2+3xz^2+3y^2z+3yz^2 + 6xyz$$

系数分成三档：$x^3$ 这类「三同」的系数 1，$x^2y$ 这类「两同一异」的系数 $\binom{3}{2,1,0}=3$，$xyz$ 这类「三异」的系数 $\binom{3}{1,1,1}=6$。**系数完全由「次数分布的形状」决定，与具体字母无关**——这正是多项式系数最省心的特性。<span class="marginnote">三变量情形就已经不是「背公式」能应付的：$(x+y+z)^2$ 的 6 个项、系数 1,1,1,2,2,2，靠多项式系数一句话全部说清。这也是为什么多项式定理是「多项式展开」的终极大纲。</span>

## 2 多项式系数的三重身份

**身份一：可重排列数。** 设 $n$ 个元素共 $m$ 类，第 $i$ 类有 $k_i$ 个（$k_1 + \cdots + k_m = n$），则这 $n$ 个元素的排法数是 $\dfrac{n!}{k_1!\,k_2!\cdots k_m!}$——这正是《圆排列与可重排列》的可重排列公式，一字不差。**多项式系数就是「同类不可区分」的排列数。**

**身份二：分组数。** 把 $n$ 个**互不相同**的对象分到 $m$ 个有标签的组，第 $i$ 组放 $k_i$ 个，方案数也是 $\dfrac{n!}{k_1!\,k_2!\cdots k_m!}$。理由：先把 $n$ 个对象排成一列（$n!$ 种），前 $k_1$ 个归第一组、接着 $k_2$ 个归第二组……但每组内部 $k_i!$ 种顺序都对应同一分组，故除以 $\prod k_i!$。<span class="marginnote">这解释了为什么「排列」和「分组」会共享同一个公式：先排队再切段，段内重排不算新方案。「切段」是分组，「段内重排不计数」是可重排列——两个故事共用一把尺子。</span>

**身份三：二项式系数的推广。** 当 $m = 2$ 时，$\binom{n}{k_1, k_2} = \dfrac{n!}{k_1!\,k_2!} = \binom{n}{k_1}$——多项式系数自动退化为二项式系数。所以多项式定理是二项式定理的**严格推广**，后者只是前者在 $m=2$ 时的特例。

**身份四：合作与分工。** 设想一个团队有 $n$ 人，要分成 $m$ 个部门、第 $i$ 个部门正好 $k_i$ 人。多项式系数 $\binom{n}{k_1,\ldots,k_m}$ 就是分部门方案数。当部门只有两个（去 A 或不去 A），它就是 $\binom{n}{k}$——「选 $k$ 人」不过是「分成两拨」的别名。四种身份其实是同一颗钻石的不同切面，看见任何一面，就能转出另外三面。

## 3 公式解析：为什么是 $\dfrac{n!}{k_1!\,k_2!\cdots k_m!}$

把多项式系数的推导拆成三步：

$$(x_1 + \cdots + x_m)^n = \underbrace{(x_1+\cdots+x_m)\cdots(x_1+\cdots+x_m)}_{n \text{ 个因子}}$$

- **第一步，理解项的来源。** 展开时从每个因子中取一个变量相乘。要得到 $x_1^{k_1}x_2^{k_2}\cdots x_m^{k_m}$，必须恰有 $k_1$ 个因子取 $x_1$、$k_2$ 个因子取 $x_2$……$k_m$ 个因子取 $x_m$。
- **第二步，数「谁取什么」。** 把 $n$ 个因子想象成 $n$ 个有标签的位子，第 1 类位子取 $x_1$（$k_1$ 个）、第 2 类取 $x_2$（$k_2$ 个）……于是「指定哪 $k_1$ 个因子取 $x_1$、哪 $k_2$ 个取 $x_2$……」的方式数，就是「把 $n$ 个有标签对象分成 $m$ 个大小分别为 $k_1,\ldots,k_m$ 的有标签组」的组数——上节已算，等于 $\dfrac{n!}{k_1!\cdots k_m!}$。
- **第三步，验证边界。** 当某个 $k_i = n$（其余为 0），系数为 $1$（全取 $x_i$）；当 $m=2$，退化为二项式系数；当 $k_i = 0$ 时按惯例 $0! = 1$，含 0 次幂的项自动「隐身」。

**易错点｜辨析：** 求和条件是 $k_1 + \cdots + k_m = n$（次数和为 $n$），不是「每个 $k_i$ 都非零」。像 $(x+y+z)^3$ 里 $x^2y$ 这一项，$k_z = 0$，系数 $\binom{3}{2,1,0} = 3$，照样在和中。初学者常漏掉「允许 $k_i = 0$」这一点，导致展开少项。

## 4 多项式系数的帕斯卡式递推

二项式系数有帕斯卡恒等式，多项式系数也有类似的「帕斯卡式」递推——它是动态规划计算多项式系数的依据。考察 $\binom{n}{k_1,\ldots,k_m}$，盯住一个特殊变量 $x_j$：

$$\binom{n}{k_1,\ldots,k_j,\ldots,k_m} = \sum_{j=1}^{m} \binom{n-1}{k_1,\ldots,k_j - 1,\ldots,k_m}$$

**证明是「分情况」**：在展开式中，含 $x_1^{k_1}\cdots x_m^{k_m}$ 的项，必由某个因子贡献 $x_j$、其余 $n-1$ 个因子贡献剩下的次数。若最后贡献的是 $x_j$，则前 $n-1$ 个因子要给出次数分布 $(k_1,\ldots,k_j-1,\ldots,k_m)$，有 $\binom{n-1}{k_1,\ldots,k_j-1,\ldots,k_m}$ 种。$j$ 取遍 $1,\ldots,m$ 是互斥情形，相加即得。<span class="marginnote">当 $m=2$，这个递推退化为帕斯卡恒等式 $\binom{n}{k}=\binom{n-1}{k}+\binom{n-1}{k-1}$。所以帕斯卡三角形只是这张更高维「多项式帕斯卡图」的一个二维切片。</span>

**计算实例。** 用递推算 $\binom{3}{1,1,1}$：
- $\binom{2}{0,1,1} = \frac{2!}{0!1!1!} = 2$，$\binom{2}{1,0,1}=2$，$\binom{2}{1,1,0}=2$；
- 求和：$2+2+2 = 6$，与直接 $\frac{3!}{1!1!1!}=6$ 一致。

递推的价值在程序里：逐层填表、只算需要的大小，避免反复算大阶乘，也天然处理了 $k_i$ 可能为 0 的边界。

## 5 全部多项式系数的和：$m^n$

把 $(x_1 + \cdots + x_m)^n$ 中所有系数加起来，会得到什么？代入 $x_1 = x_2 = \cdots = x_m = 1$：

$$\sum_{k_1 + \cdots + k_m = n} \binom{n}{k_1, \ldots, k_m} = m^n$$

这是「$n$ 个有标签对象各自由主选择 $m$ 个盒子之一」的映射数（$n$ 次独立选择、每次 $m$ 种），与「按各组人数分类求和」两种数法的对撞——又一个「算两次」实例。<span class="marginnote">这个恒等式有个经典用法：它把「$n$ 个球随机落入 $m$ 个盒子」的总情形拆成「各类人数恰好是 $k_1,\ldots,k_m$」的互斥子情形。多项分布 $P(\boldsymbol{k}) = \binom{n}{k_1,\ldots,k_m}p_1^{k_1}\cdots p_m^{k_m}$ 的概率和为 1，正是此式在 $p_i = 1/m$ 时的加权版。</span>

**多项分布连接。** 掷 $n$ 次骰子，各面出现次数恰为 $k_1,\ldots,k_6$ 的概率是 $\binom{n}{k_1,\ldots,k_6}(1/6)^n$。抛硬币是 $m=2$ 的特例，得到二项分布 $\binom{n}{k}p^k(1-p)^{n-k}$——多项式系数把二项分布的整个框架搬到了多分类情形，第二级《概率论与数理统计》的多项分布一节会用到这里的全部公式。

再往前看一步：当 $n$ 很大、$m$ 固定时，$(p_1 + \cdots + p_m)^n = 1$ 是「所有抽样序列的概率和」。自然语言处理里，语言模型的 softmax 输出层每一次采样正是一个多项试验——「从 $V$ 个词的词表中抽一个」；生成一句 $n$ 个词的话，整句概率就是多项式分布中的一个项。多项式系数就这样从代数的书架走进了大模型的地基。<span class="marginnote">严格说，语言模型生成一句「$n$ 个词」时各步概率并不同（自回归的每一步分布都在变化），所以要用乘积而非单一多项分布；但「词表大小为 $V$、每步从 $V$ 项中抽一」的框架，正是从多项式分布推广而来。理解多项式系数，等于理解了词级生成模型最基本的计数背景。</span>

## 6 从展开到算法：多项式系数的计算

多项式系数看起来要算阶乘，但实际计算有更稳的办法：

| 方法 | 思路 | 复杂度 |
| --- | --- | --- |
| 直接阶乘 | $\dfrac{n!}{k_1!\cdots k_m!}$ | 需避免大数溢出 |
| 递推（帕斯卡式） | $\binom{n}{k_1,\ldots,k_m} = \binom{n-1}{k_1-1,\ldots,k_m} + \cdots$（去掉 $x_i$ 所在因子） | 动态规划，逐层填表 |
| 对数求和 | 对阶乘取对数再求和取指数 | 数值稳定 |

**例。** 计算 $\binom{10}{3,2,5} = \dfrac{10!}{3!\,2!\,5!} = \dfrac{3628800}{6 \cdot 2 \cdot 120} = 2520$。手工算时先把阶乘约分再相乘，避免先乘出天文数字。<span class="marginnote">在机器学习里，多项式系数出现在「词袋模型的状态计数」「多项式朴素贝叶斯」的估计中，也出现在深度学习「把 $n$ 个 token 分配到 $m$ 个类别」的归一化常数推导里。数值稳定性（对数空间）是工程实现的关键词。</span>

## 7 小结

- **多项式定理**：$(x_1+\cdots+x_m)^n = \sum_{k_1+\cdots+k_m=n} \binom{n}{k_1,\ldots,k_m} x_1^{k_1}\cdots x_m^{k_m}$。
- **多项式系数** $\binom{n}{k_1,\ldots,k_m} = \dfrac{n!}{k_1!\cdots k_m!}$ 有三重身份：可重排列数、分组数、二项式系数的推广。
- 全部系数之和为 $m^n$；当 $m=2$ 时退化为二项式定理。
- 求和中允许 $k_i = 0$，对应「某个变量一次也没被选」的项。
- 多项式分布是二项分布向多分类的推广，概率和为 1 由「算两次」保证。
- 递推 $\binom{n}{k_1,\ldots,k_m} = \sum_j \binom{n-1}{k_1,\ldots,k_j-1,\ldots,k_m}$ 是计算与证明的又一利器，也是帕斯卡恒等式的高维推广。
- 多项分布 / 语言模型词表采样，都是多项式系数在「多次独立多分类试验」中的现身。

- 展开式项数为 $\binom{n+m-1}{m-1}$，随 $m,n$ 增长极快——多项式定理负责「描述」，计算机负责「计算」。

- 通过「先排队再切段」的双射，可重排列数、分组数与多项式系数这三个看似无关的对象被统一成一个数。

在下一节，我们从「数多少种」转向「保证存在」：**鸽巢原理**——把 $n+1$ 只鸽子放进 $n$ 个笼子，一定有两个笼子至少住进两只鸽子。它朴素得近乎常识，却是一整片理论的起点。
