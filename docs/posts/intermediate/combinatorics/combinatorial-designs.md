## 为什么从组合设计开始

前几节的计数问题是「有多少种」；**组合设计（combinatorial design）** 关心的是「怎么排才平衡」。一个典型的例子：一场锦标赛有 $v$ 支球队，要安排若干个「小组」（每场小组赛恰好 $k$ 支同场），使得**任意两支球队恰好同场 $\lambda$ 次**。这种「不多不少、恰好一次/恰好 $\lambda$ 次」的平衡安排，就是设计理论的研究对象。

组合设计看似冷门，却是现代科技的隐秘地基：实验设计（农业试验怎么安排地块）、纠错码（怎么设计码字使容错最大）、密码学（秘密分享方案）、甚至神经网络里的「正交试验设计」都与它同源。设计理论里最出名的一个对象——**法诺平面**——只有 7 个点 7 条线，却是有限几何、编码理论与量子信息里的常客。<span class="marginnote">「设计」这个名字来自英文 design，原意是「（试验）安排」：农业统计学家费希尔（R. A. Fisher）为了安排田间试验，发明了实验设计，组合设计由此成为统计学的数学基础之一。它给「怎么安排最公平」提供了一套精确语言——「损有余而补不足」的数学化。</span>

## 1 平衡不完全区组设计

**平衡不完全区组设计（BIBD）** 有五个参数 $(v, b, r, k, \lambda)$：

- $v$ 个点（对象），$b$ 个区组（组）；
- 每个区组恰含 $k$ 个点；
- 每个点恰出现在 $r$ 个区组中；
- 任意一对点恰好在 $\lambda$ 个区组中同时出现。

「平衡」指每点每对出现的次数恒定，「不完全」指 $k < v$（区组不是全集）。

**两个必要条件**（由「算两次」立刻得到）：

$$vr = bk, \qquad \lambda(v-1) = r(k-1)$$

- **第一个**：数「（点，含它的区组）」对——每点 $r$ 个，共 $vr$；每个区组 $k$ 个点，共 $bk$。
- **第二个**：固定一个点 $P$，数「（其他点 $Q$，含 $P,Q$ 的区组）」对——$P$ 在 $r$ 个区组里，每区组还有 $k-1$ 个其他点，共 $r(k-1)$；而每个 $Q$（共 $v-1$ 个）与 $P$ 恰好同区组 $\lambda$ 次，共 $\lambda(v-1)$。

**例。** 7 个点的完全图，每条边「恰好属于一个三角形」，7 条边？不——是 7 个区组每区组 3 个点、每对点恰好共线一次。这是**斯坦纳三元系** $STS(7)$，即法诺平面。

**参数核对。** 对法诺平面 $(v,b,r,k,\lambda) = (7,7,3,3,1)$ 验证两条必要条件：$vr = 7\cdot3 = 21 = bk = 7\cdot3$ ✓；$\lambda(v-1) = 1\cdot6 = 6 = r(k-1) = 3\cdot2$ ✓。两条都饱和，说明这组参数「自洽」——而「自洽」在这里恰好「可实现」，正是设计理论的运气时刻。<span class="marginnote">「数同一组对、两种数法」正是我们反复使用的「算两次」。设计理论的两条必要条件只是算两次的直接产物，但很多设计问题（是否存在、唯一与否）至今没有简单答案——设计理论把「算两次」用到了极限，也撞上了它的天花板。</span>

## 2 斯坦纳三元系与法诺平面

**斯坦纳三元系（Steiner triple system）$STS(v)$**：$v$ 个点、每个区组 $3$ 个点、任意两点恰好同时出现在一个区组中——即 $(v, b, r, 3, 1)$ 设计。

**存在性定理**：$STS(v)$ 存在当且仅当 $v \equiv 1$ 或 $3 \pmod 6$。例如 $v = 7, 9, 13, 15, \ldots$ 存在，$v = 5, 6, 8$ 不存在。<span class="marginnote">「$v \equiv 1, 3 \pmod 6$」可以从必要条件推出：$k=3, \lambda=1$ 时 $r = \frac{v-1}{2}$ 须为整数（$v$ 奇数），且 $b = \frac{vr}{3} = \frac{v(v-1)}{6}$ 须为整数（$v(v-1) \equiv 0 \pmod 6$）。两条合起来正是 $v \equiv 1, 3 \pmod 6$——必要条件恰好也是充分条件，这个「必要 = 充分」是设计理论里难得的漂亮结果。</span>

**法诺平面（Fano plane）。** $v = 7$ 的斯坦纳三元系：7 个点、7 条线、每条线 3 个点、任意两点恰有一条连线。它还是有限射影平面 $\mathrm{PG}(2,2)$：7 个点 + 7 条线，每条线 3 点、每点 3 线。它的 7 条线可以显式写出来（以 $\{1,2,3,4,5,6,7\}$ 为点）：

$$\{1,2,3\},\ \{1,4,5\},\ \{1,6,7\},\ \{2,4,6\},\ \{2,5,7\},\ \{3,4,7\},\ \{3,5,6\}$$

验证任意两点（如 4 与 7）恰好落在一条线上（$\{3,4,7\}$）——设计参数 $(7,7,3,3,1)$ 全部满足。法诺平面有两个惊人的身份：
- 作为 $2$ 元域上的射影平面，它是「最小的有限几何」；
- 它的 7 个点可以当作**汉明码** $[7,4,3]$ 的非零码字集合——**设计 ↔ 码**的第一次握手。<span class="marginnote">法诺平面的 7 条线是「任意两点恰有一条线、任意两条线恰交于一点」的最小实例——这是射影平面的定义，也是「对偶性」的展示：点的角色与线的角色完全对称。在量子信息里，法诺平面还编码着「7 个量子比特的稳定子码」，是设计理论通向量子纠错的桥梁。</span>

## 3 拉丁方：另一种平衡

**拉丁方（Latin square）** 阶为 $n$：$n\times n$ 方阵，每行每列都恰好包含 $1, 2, \ldots, n$ 各一次。它保证「每个符号每行每列出现一次」——另一种意义的平衡。

**正交拉丁方。** 两个同阶拉丁方若「叠放后每对符号恰好出现一次」，称正交。**欧拉的 36 军官问题**：6 个军衔 × 6 个军团共 36 名军官，能否排成 6×6 方阵使每行每列都含每个军衔与每个军团各一次？答案是否——**不存在一对正交的 6 阶拉丁方**。欧拉 1782 年猜想「阶数为 $4k+2$ 时不存在」，但 1959 年这个猜想被推翻：除 2 与 6 之外，所有阶都存在正交拉丁方对。<span class="marginnote">36 军官问题是设计理论最著名的「悬案」之一：欧拉猜对了 6、猜错了 22。它直接催生了「有限域上的正交拉丁方构造法」——当 $n$ 是素数幂时，用有限域的加法与乘法表就能造出 $n-1$ 个两两正交的拉丁方。第二级《数论》与《抽象代数》的有限域，在这里变成组合构造的发动机。</span>

## 4 从拉丁方到有限域：一种构造法

36 军官问题的一个关键教训是：**正交拉丁方的存在性高度依赖 $n$ 的算术性质**。当 $n$ 是素数幂时，有限域给出系统构造法：

**构造（$n$ 为素数幂）。** 取有限域 $\mathbb{F}_n$（元素 $0,1,\ldots,n-1$，$n = p^m$）。对每个 $a \in \mathbb{F}_n \setminus \{0\}$，定义拉丁方 $L^{(a)}$，其第 $(i,j)$ 格填 $a\cdot i + j$（域运算）。对任意两个不同的 $a, a'$，$L^{(a)}$ 与 $L^{(a')}$ 正交——因为叠放后若两格相同，则 $ai + j = a'i + j'$ 且 $a''i + j = a''i' + j'$，相减得 $(a-a')i = (a-a')i'$，由 $a \neq a'$ 推出 $i = i'$，再推 $j = j'$——两格必是同一格。

**结论**：$n$ 为素数幂时，存在 $n-1$ 个两两正交的拉丁方。而 36 军官问题（$n = 6$）不是素数幂，恰好落在「不存在」的一侧——**正交拉丁方是否存在，由 $n$ 的素因子结构决定**。<span class="marginnote">「域运算造正交拉丁方」是设计理论里「有限域即万能构造器」的第一次亮相。类似的「$\mathbb{F}_n$ 造设计」技巧，还会出现在斯坦纳三元系、射影平面、纠错码的构造中——第二级《抽象代数》学完有限域，组合设计的构造题会豁然开朗。</span>

## 5 公式解析：两条必要条件的「算两次」解剖

把 $vr = bk$ 与 $\lambda(v-1) = r(k-1)$ 各用一次「数对」讲透：

**$vr = bk$——数（点，区组）对：**

$$vr = \underbrace{\sum_{\text{点 } P} \deg(P)}_{v \text{ 个点，每个 } r \text{ 次}} = \underbrace{\sum_{\text{区组 } B} |B|}_{b \text{ 个区组，每个 } k \text{ 个点}} = bk$$

- **左往右看**：每个点「属于 $r$ 个区组」，点×区组的「关联对」总数是 $vr$；
- **右往左看**：每个区组「含 $k$ 个点」，同一个关联对总数是 $bk$；
- **两个数法描述的是同一组关联对**，故相等。

**$\lambda(v-1) = r(k-1)$——固定一点 $P$，数（其他点，区组）对：**

$$\lambda(v-1) = \underbrace{\sum_{Q \neq P} \lambda}_{v-1 \text{ 个 } Q} = \underbrace{\sum_{\text{含 } P \text{ 的区组}}(k-1)}_{r \text{ 个区组，每个含 } k-1 \text{ 个其他点}} = r(k-1)$$

- **左**：每个 $Q \neq P$ 与 $P$ 同区组 $\lambda$ 次，共 $\lambda(v-1)$；
- **右**：$P$ 所在的每个区组还含 $k-1$ 个其他点，共 $r(k-1)$；
- **两个数法描述的是同一组「$P$ 与其他点共区组」的事件**，故相等。

**这两条是设计的「身份证」**：给定 $(v,k,\lambda)$，$r = \frac{\lambda(v-1)}{k-1}$、$b = \frac{vr}{k}$ 都必须自动是整数——不满足就不存在，**先查身份证再谈构造**。

## 6 设计的应用：从试验到纠错码

**实验设计。** 农业试验要比较 $k$ 种肥料、在 $v$ 块地里安排，每块地受多种因素影响。「平衡」保证每对肥料在相同条件下比较——BIBD 正是为此而生。现代 A/B 测试、正交试验设计（Taguchi 方法）都是它的工业后裔。

**纠错码。** 设计理论给出「任意两个对象共享信息量恒定」的结构，天然适合构造码：法诺平面的 7 点给出**汉明码** $[7,4,3]$，能纠 1 个错误；一般 BIBD 关联矩阵的线性码直接继承设计的距离性质。**「平衡」翻译成「码距」，设计的优美变成纠错的能力**——通信领域的信道编码由此与组合设计合流。<span class="marginnote">「设计 → 码」的桥梁是关联矩阵：设计 $(v,b,r,k,\lambda)$ 的关联矩阵 $M$（$v\times b$，$M_{i,j}=1$ 当且仅当点 $i$ 在区组 $j$ 中）满足 $MM^T = (r-\lambda)I + \lambda J$——特征值谱完全由参数决定。这个代数事实让设计的谱性质可以一次算出，是代数组合的核心内容。第三级《信息论与编码》会深入。</span>

**秘密共享。** 把「秘密」拆成若干「份额」，要求任意 $k$ 份能还原、少于 $k$ 份不能——Shamir 方案用有限域上的插值实现，其组合骨架也是设计式的「任意 $k$ 个点确定一条曲线」。

## 7 小结

- **BIBD** $(v,b,r,k,\lambda)$：每区组 $k$ 点、每点 $r$ 次、每对点 $\lambda$ 次共现。
- **必要条件**：$vr = bk$、$\lambda(v-1) = r(k-1)$——两条都是「算两次」。
- **斯坦纳三元系** $STS(v)$：$k=3,\lambda=1$，存在当且仅当 $v \equiv 1, 3 \pmod 6$。
- **法诺平面**：7 点 7 线的最小有限几何，与汉明码 $[7,4,3]$ 同源。
- **拉丁方与正交拉丁方**：欧拉 36 军官问题，素数幂阶用有限域构造。
- 应用：实验设计、纠错码、秘密共享——「平衡」是设计给世界的礼物。
- 法诺平面 7 条线可显式写出，任意两点恰共线一次，是「点线对偶」的最小剧场。
- 正交拉丁方存在性由 $n$ 的素因子结构决定：素数幂用有限域构造 $n-1$ 个正交对。
- 关联矩阵 $MM^T = (r-\lambda)I + \lambda J$：设计的谱性质由参数直接决定，是通向代数组合的桥。
- A/B 测试、正交试验设计（Taguchi 方法）是 BIBD 在工程与互联网的现代后裔。
- 「先查身份证」：$r = \frac{\lambda(v-1)}{k-1}$、$b = \frac{vr}{k}$ 必须为整数，否则设计不存在。
- 对称设计（$v=b$）与射影平面、强正则图紧密相连，是代数组合的中心课题之一。
- 「平衡」= 任意两点恰好相遇 $\lambda$ 次，是锦标赛、试验、码字共享信息的统一语言。
- 设计的存在性常是「必要参数自洽 + 有限域构造」两步：先查身份证，再请出 $\mathbb{F}_q$。
