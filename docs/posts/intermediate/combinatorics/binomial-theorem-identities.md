## 为什么从二项式定理开始

从初中开始你就背过 $(a+b)^2 = a^2 + 2ab + b^2$，甚至 $(a+b)^3$ 的展开。但组合数学给了它一个全新的解读：**$(a+b)^n$ 的展开式系数，就是一个一个「数出来」的组合数**。把「展开」理解成「从每个因子中选一个乘起来」，系数自然就是 $\binom{n}{k}$——代数与组合在这里合流，帕斯卡三角的每一行同时是代数展开式的系数表。

更进一步，二项式系数的各种恒等式——$\sum \binom{n}{k} = 2^n$、范德蒙德恒等式、曲棍球棒恒等式——都不是靠代数展开硬证的，而是**各自讲了一个计数故事**。这一节要培养的核心能力是：**看到一个恒等式，能讲出它背后的两个计数视角**。这个「双视角证明」的习惯，在第二篇生成函数里会升级成更有威力的工具。<span class="marginnote">二项式系数的恒等式在机器学习里俯拾即是：二项分布的概率 $\binom{n}{k}p^k(1-p)^{n-k}$ 求和为 1 正是 $\sum \binom{n}{k} = 2^n$ 的加权版；神经网络的「组合特征爆炸」、贝叶斯网络的条件独立计数，也都与二项式系数相伴。它是离散世界的「乘法表」。</span>

## 1 二项式定理：展开就是选因子

**二项式定理（binomial theorem）**：对非负整数 $n$ 与任意数 $a, b$，

$$(a + b)^n = \sum_{k=0}^{n} \binom{n}{k} a^{\,n-k} b^{\,k}$$

**为什么系数是组合数？** 把 $(a+b)^n$ 写成 $n$ 个因子连乘：

$$(a+b)^n = \underbrace{(a+b)(a+b) \cdots (a+b)}_{n \text{ 个因子}}$$

展开时，从每一个因子中**要么选 $a$、要么选 $b$**。要想得到 $a^{\,n-k}b^{\,k}$，必须恰好从 $k$ 个因子中选 $b$、从其余 $n-k$ 个因子中选 $a$。「从 $n$ 个因子中选哪 $k$ 个取 $b$」有 $\binom{n}{k}$ 种方式，于是这一项出现了 $\binom{n}{k}$ 次。<span class="marginnote">这个证明只用了一个词——「选」。$(a+b)^n$ 的展开是一个纯计数问题，这也是为什么牛顿把它推广到分数指数后，级数展开的系数依然由「广义组合数」主宰。选择计数是整个定理的发动机。</span>

**例子。** $(a+b)^4 = \binom{4}{0}a^4 + \binom{4}{1}a^3b + \binom{4}{2}a^2b^2 + \binom{4}{3}ab^3 + \binom{4}{4}b^4 = a^4 + 4a^3b + 6a^2b^2 + 4ab^3 + b^4$。系数 $1,4,6,4,1$ 正是帕斯卡三角第 4 行。

## 2 从定理到恒等式：代数的组合证明

令 $a = b = 1$，得 **恒等式（一）**：

$$\sum_{k=0}^{n} \binom{n}{k} = 2^n$$

左边把「所有大小的子集数」加起来，右边是「$n$ 个元素的子集总数」——**同一个东西，两种数法**。这就是恒等式的第一种证明：**算两次（double counting）**。<span class="marginnote">「算两次」是组合恒等式最常用也最优雅的方法：对同一个量，用两种方式计数，然后令两者相等。$\sum_k \binom{n}{k} = 2^n$ 是它的第一次登场，后面范德蒙德恒等式、曲棍球棒恒等式，乃至第二篇的生成函数技巧，都是算两次的花样变体。</span>

令 $a = 1, b = -1$，得 **恒等式（二）**：

$$\sum_{k=0}^{n} (-1)^k \binom{n}{k} = 0 \qquad (n \geq 1)$$

即偶数大小子集数与奇数大小子集数相等。它有一个漂亮的组合证明：取一个特殊元素 $x$，把所有子集两两配对（$S \leftrightarrow S \triangle \{x\}$），每对恰好一奇一偶——所以奇偶子集一样多。

## 3 公式解析：范德蒙德与曲棍球棒

两个更深刻的恒等式值得单列，因为它们将反复出现在概率与算法分析中。

**范德蒙德恒等式（Vandermonde's identity）：**

$$\sum_{k=0}^{r} \binom{m}{k}\binom{n}{r-k} = \binom{m+n}{r}$$

拆解这个公式：
- **左右各讲一个故事。** 右边：从 $m+n$ 个元素里选 $r$ 个。左边：先把这 $m+n$ 个元素分成**两组**——前 $m$ 个一组、后 $n$ 个一组；从第一组选 $k$ 个、从第二组选 $r-k$ 个，再把 $k$ 从 $0$ 到 $r$ 全部加起来。
- **加法原理在这里工作。** 「从第一组选 $k$ 个」与「从第二组选 $r-k$ 个」是分步（乘法），而不同 $k$ 之间是互斥的选法（加法）。分类求和，正是恒等式成立的骨架。
- **特例**：$m = n = r$ 时，$\sum_k \binom{n}{k}^2 = \binom{2n}{n}$——「从 $n$ 个男、$n$ 个女中选 $n$ 人」与「选 $n$ 人中恰好 $k$ 男」的计数殊途同归。<span class="marginnote">范德蒙德恒等式在概率论里就是「超几何分布的概率和为 1」的证明工具，在算法分析里用于化简卷积。卷积、生成函数、离散卷积——计算机系学生熟悉的「卷积和」，本质就是范德蒙德恒等式左边的形态。</span>

**曲棍球棒恒等式（hockey stick identity）：**

$$\sum_{k=r}^{n} \binom{k}{r} = \binom{n+1}{r+1}$$

直觉：从 $n+1$ 个元素里选 $r+1$ 个，盯住被选中的**最大编号元素**。若最大编号是 $k+1$，则其余 $r$ 个须从编号 $\leq k$ 的元素中选，有 $\binom{k}{r}$ 种。$k$ 从 $r$ 取到 $n$，互斥相加即得。帕斯卡三角形里，沿着一列往下加，和落在「曲棍球棒」的柄端——名字由此而来。

## 4 恒等式的证明工具箱

把这一节出现的证明方法归类，它们会陪你走完整个组合数学：

| 方法 | 一句话 | 例 |
| --- | --- | --- |
| **算两次** | 同一量两种数法，令其相等 | $\sum_k \binom{n}{k} = 2^n$ |
| **双射** | 构造一一对应，两边自动相等 | 奇偶子集数相等 |
| **代数代入** | 对 $(a+b)^n$ 代入特殊值 | 令 $a=1,b=-1$ 得符号和 |
| **加法原理** | 按某种标准分类求和 | 范德蒙德、曲棍球棒 |

**易错点｜辨析：** 用代数代入得到恒等式时，容易忽略「这是多项式恒等式」的前提。$(1-x)^n = \sum (-1)^k\binom{n}{k}x^k$ 之所以可以代入任何 $x$，是因为两边是同一个多项式、系数逐项相等；但对**任意函数**（如 $\sqrt{x}$）不能随意做系数替换。代数方法只对多项式成立，组合方法则对计数本身成立，两者互补。

## 5 用恒等式化简求和

恒等式最大的用处之一，是**化简看起来很凶的求和**。看两个例子。

**例 1。** 求 $\displaystyle\sum_{k=0}^{n} \frac{\binom{n}{k}}{k+1}$。

思路是「把分母吞进组合数」：注意到 $\dfrac{\binom{n}{k}}{k+1} = \dfrac{1}{n+1}\binom{n+1}{k+1}$，因为两者都等于 $\dfrac{n!}{(k+1)!\,(n-k)!}$。于是

$$\sum_{k=0}^{n}\frac{\binom{n}{k}}{k+1} = \frac{1}{n+1}\sum_{k=0}^{n}\binom{n+1}{k+1} = \frac{2^{n+1} - 1}{n+1}$$

这里只用了两条旧知识：组合数的「邻行变换」$\binom{n}{k} = \frac{n+1}{k+1}\binom{n}{k}$ 与全行求和 $\sum_j \binom{n+1}{j} = 2^{n+1}$。**化陌生为熟悉的路径，往往是先改写组合数，再看成某个已知求和。**<span class="marginnote">这个例子是「组合恒等式化简」的标准动作：<strong>先把组合数改写成带 $\frac{1}{n+1}$ 的邻行形式，使分母的 $k+1$ 被吸收，再套用全行求和</strong>。概率论里它对应「均匀分布的期望 $\int_0^1 (1+x)^n dx$」的离散版本——算两次的又一例。</span>

**例 2。** 证明 $\displaystyle\sum_{k=0}^{n} k\binom{n}{k} = n2^{n-1}$ 的另一个路径：利用恒等式 $k\binom{n}{k} = n\binom{n-1}{k-1}$，把求和的指标平移：

$$\sum_{k=1}^{n} k\binom{n}{k} = n\sum_{k=1}^{n}\binom{n-1}{k-1} = n \sum_{j=0}^{n-1}\binom{n-1}{j} = n\cdot 2^{n-1}$$

与上一节「选班委再选班长」的双射得到同一个结果——**一个恒等式，代数证法与组合证法双保险**。碰到问题先想组合故事；故事想不出来，就退而求其次做代数改写。两条路都要会走。

## 6 一个完整的算两次演示

**问题：** 证明 $\sum_{k=1}^{n} k \binom{n}{k} = n \cdot 2^{\,n-1}$。

- **左边讲的故事**：从 $n$ 人中选一个「班委」，再在班委中选一位「班长」。对每个固定的班委大小 $k$：先选 $k$ 人当班委（$\binom{n}{k}$），再从这 $k$ 人中选班长（$k$ 种），求和即左边。
- **右边讲的故事**：先选班长（$n$ 种），其余 $n-1$ 人每人「进班委或不进」（$2^{n-1}$ 种），得 $n \cdot 2^{n-1}$。
- **两种选法一一对应**（先定班长再定其余，或先定班委再定班长），恒等式成立。

这个恒等式还有概率论版本：二项分布 $\mathrm{Bin}(n, \tfrac12)$ 的期望 $= \sum k\binom{n}{k}/2^n = n/2$，正是「抛 $n$ 枚硬币正面数的期望」——算两次在概率里叫「线性期望」，同一件事的又一顶帽子。<span class="marginnote">「先选班委再选班长」与「先选班长再补班委」这两个故事，把 $k\binom{n}{k}$ 与 $n2^{n-1}$ 接在了一起。以后遇到「$k$ 乘组合数求和」，先想「多选一个特殊对象」，往往立刻有解。</span>

## 7 小结

- **二项式定理**：$(a+b)^n = \sum_k \binom{n}{k} a^{n-k}b^k$，系数来自「从 $n$ 个因子中选 $k$ 个取 $b$」的计数。
- **三个基础恒等式**：$\sum_k \binom{n}{k} = 2^n$、$\sum_k (-1)^k \binom{n}{k} = 0$、$\sum_k \binom{m}{k}\binom{n}{r-k} = \binom{m+n}{r}$。
- **曲棍球棒恒等式**：$\sum_{k=r}^n \binom{k}{r} = \binom{n+1}{r+1}$，按「最大编号」分类证明。
- 证明工具：**算两次、双射、代数代入、加法原理**——四件套齐备，恒等式不再需要背。
- 二项式系数在第二级《概率论与数理统计》中化身二项分布，在第三级《算法设计与分析》中进入递归复杂度分析，是横跨多门课的「公共常数」。
- 化简求和的套路：先改写组合数（邻行变换、吸收 $k$），再套用已知求和（全行和、范德蒙德），最后验证边界。

在下一节，我们把二项式定理推广到**多项**：$(a_1 + a_2 + \cdots + a_m)^n$ 展开后，每一项的系数长什么样？——这是**多项式定理**。
