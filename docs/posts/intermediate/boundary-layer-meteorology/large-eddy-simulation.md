## 为什么从大涡模拟开始

边界层研究有三条腿：观测、理论与模拟。观测受制于探头与塔架，相似理论受制于假设，而数值模拟——尤其是**大涡模拟（large eddy simulation, LES）**——几乎像一台「数值风洞」，可以把对流边界层的热泡、稳定边界层的低空急流、层积云的夹卷一个个「长」出来给人看。<span class="marginnote">LES 的定位很特别：它不完全靠参数化（那是天气模式的边界层方案），也不完全靠解析（那是理论），而是把尺度最大的含能涡旋老老实实算出来，把耗散的小涡交给亚网格模型——是「解析一半、参数化一半」的折中。</span>

## 1 为什么不能全解析，也不能全参数化

要理解 LES 的位置，先看它的两个邻居。

**直接数值模拟（DNS）** 把湍流从含能涡到耗散涡全部解析。可边界层的尺度跨度令人绝望：含能涡数百米、耗散涡毫米级，雷诺数高达 $10^7$–$10^8$，所需网格数与 $Re^{9/4}$ 成正比——DNS 解一个边界层需要 $10^{15}$ 量级的网格，即便超级计算机也只能在极小域、低雷诺数下望洋兴叹。<span class="marginnote">$Re^{9/4}$ 来自科莫哥罗夫微尺度与积分尺度的比值：$\eta/L \sim Re^{-3/4}$，三维网格数就是 $Re^{9/4}$。这就是第 2 节说「七个量级跨度」换算成计算代价后的残酷现实。</span>

把账算具体一点：取 $z_i = 1000$ m、耗散尺度 1 mm，垂直方向就需要约 $10^6$ 层网格，水平再乘上 $10^6$——总网格数 $10^{12}$–$10^{15}$，远超当前最强超算的存储与算力。LES 用「只解析大涡」的妥协，把代价砍到 $10^7$–$10^8$，是目前唯一可行的路径。

**雷诺平均模拟（RANS）** 走到另一极端：所有尺度全参数化，只算平均场。代价是上一节的闭合问题——反梯度输运、夹卷、间歇湍流这些「非局地」现象，参数化很难捕捉。

**大涡模拟** 居中：把网格切到几十米，解析出占湍能绝大部分的含能涡（边界层里主要是大涡），只有亚网格（subgrid-scale, SGS）的小涡交给模型。由于小涡的行为更接近普适的统计规律（惯性子区、−5/3 律），SGS 模型的误差远比 RANS 的闭合假设可控。

天气预报里的边界层方案本质上仍是 RANS 家族的粗网格闭合——LES 太贵，无法实时预报。但模式边界层方案的系数大量由 LES 标定，LES 因此以「离线校准器」的身份进入了预报链条。从这个意义说，LES 离天气预报并不远，只是换了工作方式。

## 2 滤波与亚网格模型：把方程剪一刀

LES 的做法是给控制方程做一次**空间滤波（spatial filtering）**：把物理量在网格尺度的邻域上平均，大尺度保留、小尺度抹掉。滤波后的动量方程多出一项——**亚网格应力（SGS stress）**，它代表被抹掉的小涡对已解析大涡的拖曳：

$$\tau_{ij}^{sgs} = \overline{u_i u_j} - \bar{u}_i \bar{u}_j$$

它需要模型闭合。最经典的闭合同样走「涡黏」路线——**斯马戈林斯基模型（Smagorinsky model）**：

$$\nu_t = (C_s \Delta)^2 \sqrt{2 \bar{S}_{ij} \bar{S}_{ij}}$$

$C_s$ 是斯马戈林斯基常数（约 0.2），$\Delta$ 是网格尺度，$\bar{S}_{ij}$ 是已解析速度的应变率张量。<span class="marginnote">斯马戈林斯基模型的基本逻辑：小涡也「沿梯度下坡」，其黏性正比于网格尺度的平方乘应变率——网格越粗、剪切越强，越要加重黏性来抑制小涡的伪积累。它是 K 理论思想在 SGS 尺度上的延续。</span>

更精细的模型用亚网格湍动能（SGS-TKE）方程动态闭合，或用**动态方法（dynamic model）**由已解析场通过 Germano 恒等式现场标定 $C_s$，让它自适应流动的局部状态——近地面与强剪切区 $C_s$ 自动减小，避免过度耗散。动态模型已成为现代边界层 LES 的主流选择，代价是计算量略增与数值不稳定风险。

SGS 模型的另一个家族是**谱空间模型**：把滤波在谱空间完成，直接参数化谱尾端的能量输运。这类模型数学上更优雅，但计算与存储成本高，实际 LES 中不如涡黏模型常用。

边界层 LES 还有一个常被低估的软肋：**次网格地形与地表异质性**。真实下垫面在几十米尺度上变化剧烈（森林斑块、城市街区、起伏地形），网格装不下这些细节，只能参数化——可这些细节恰恰是边界层能量注入的源头。LES 因此长期偏好「理想化均匀地表」个例，真实复杂地形的 LES 仍是前沿课题。

## 3 边界层 LES 的搭建：从方程到「数值风洞」

一个典型的边界层 LES 需要精心布置：

**计算域**：水平向取几公里见方（要装得下最大的含能涡），垂直向从地面到 2–3 倍 $z_i$，网格几十米，总网格数 $10^7$ 量级。
**边界条件**：水平向常用**周期边界**（假设水平均匀）；顶部用辐射或刚性边界加海绵层吸波；底部是关键——近地面最小涡无法解析，用莫宁—奥布霍夫相似理论做**地表通量边界**，把 $u_*$、$\theta_*$、$q_*$ 换算成底面应力与热通量。<span class="marginnote">「用相似理论当底面、用 LES 当主体」是边界层 LES 的标准配方：地面层的物理用第 4 节的 $\phi_m$、$\phi_h$ 参数化，其上的一切由大涡解析。这既是 LES 的省力处，也是近地面层误差的来源。</span>
**外强迫**：给定地转风（驱动切变）、地面温度或通量（驱动对流）、初始探空与云微物理。
**统计**：LES 场随湍流脉动涨落，要得到统计量必须做**时间平均 + 水平平均**；采样时长必须覆盖低频大涡的若干次翻转，通常要模拟数小时的真实时间并丢弃初始的自旋（spin-up）段。
**数值格式**：LES 多采用谱方法或高阶有限差分，配合显式时间积分；时间步长受 CFL 条件限制，随风速与网格尺度而定（分钟量级）。关键在低数值耗散——数值格式自带的耗散会「吃掉」本应保留的小涡，让结果偏离真实湍流，这是 LES 与普通数值天气预报格式的一大区别。
- **计算规模**：单次边界层 LES 通常需数百万到上亿网格，并行计算数小时到数天；对流云与台风边界层个例更重，往往动用顶级超算。百亿亿次（exascale）时代正把 LES 从理想化个例推向更真实、更大域的计算。
- **初始与强迫**：给真实探空可重算历史个例，给理想化均匀场做理想化研究；外强迫随时间变化让 LES 逼近真实天气，也让结果更难归因——理想化与真实化之间的权衡，是每个 LES 研究者都要做的选择。

## 4 边界层 LES 的收获：理论的新试验台

LES 问世以来，改写了边界层的许多「常识」：

- **夹卷比的普适性**：大量对流边界层的 LES 反复给出 $\beta \approx 0.2$，既验证了板状模式的假设，也揭示了 $\beta$ 对风切变、逆温强度的依赖——比观测更能系统地扫描参数空间。
- **反梯度输运的可视化**：LES 直接展示了热泡如何把热量「逆梯度」抬升，为修正 K 理论提供了微观依据。
- **稳定边界层的间歇性**：LES 重现了 SBL 的湍流间歇爆发，让「强稳定条件下湍流如何维持」第一次有了可重复的数值实验。
- **云顶过程的还原**：云解析 LES 把层积云顶的夹卷、辐射冷却与毛毛雨过程逐个还原，成为云物理与气候模式之间的桥梁。<span class="marginnote">边界层 LES 的角色很像高能物理里的「数值加速器」：观测给不出、理论算不动的问题，先让 LES 跑一遍，把结论当作「虚拟真值」去标定更粗糙的参数化方案——气象模式边界层方案的很多系数，就是被 LES「标」出来的。</span>

LES 最被低估的贡献，是它把「不可观测」的物理变成了「可检验」的物理：气压输运、三阶矩、夹卷层内部分布——这些通量塔测不到的量，在 LES 里一望可知，成为检验与改进相似理论的显微镜。没有 LES，很多边界层的「常识」至今仍是猜测。

LES 的另一个重要用途是**发展闭合模型**：把 LES 的三阶矩、协方差当作「真值」，检验二阶矩闭合与 K 理论的各项假设，看看哪一项错了、错多少。边界层参数化的改进史，一半是观测推动，一半是 LES 推动。

**辨析｜易错点：** LES 是「可信的近似」，不是「精确的真值」：SGS 模型、近壁处理、周期边界都会留下指纹。判断 LES 结果的可信度，要看四点——分辨率是否解析了含能涡、SGS 占比是否小、采样时长是否够、是否与观测或相似理论交叉验证。逐条不满足，结论就要打折扣。

## 5 验证与诊断：如何检验一次 LES

LES 算出的场可以很美，但怎么知道它算对了？标准流程是层层验证：

**与相似理论对照**：中性/弱稳定条件下，LES 的近地面风廓线应与莫宁—奥布霍夫积分式吻合，$u_*$ 与 $\zeta$ 是校核量。
**与谱对照**：LES 的湍能谱应在惯性子区贴近 −5/3 直线；谱形在含能区的偏差提示网格或边界条件的毛病。
**与通量收支对照**：检验 TKE 收支各项是否平衡，耗散是否与产生相当，夹卷比是否落在 0.2 附近。
- **与观测对照**：理想化个例与实际观测（飞机穿云、通量塔）的直接对比，是最终的「真值检验」。<span class="marginnote">LES 与观测的对照常做「个例重构」：用当天的探空、地表通量与地转风重算同一时刻，再与飞机或雷达剖面逐点比较。吻合得上，说明模式的物理过程齐全；对不上，则逐一排查辐射、微物理与边界层方案。</span>

**辨析｜易错点：** 一次 LES 的「成功」只代表该个例、该分辨率的成功。换个层结、换个云型、换套 SGS 模型，结论可能不同。严谨的 LES 研究都会做**分辨率收敛性检验**（在更细网格上重算，确认关键量不变），这是判断结果是否可信的底线。

LES 的验证还有一层「盲测」传统：多个 LES 代码用同一套初始条件与物理设置跑同一个个例，再对比结果（如夹卷比、通量廓线）。这类代码互比（code intercomparison）暴露出的差异，往往比任何单一代码与观测的偏差更能说明问题——它把「模式自身的脆弱性」与「物理过程的不确定性」分开。

## 6 公式解析：斯马戈林斯基涡黏 $\nu_t = (C_s\Delta)^2\sqrt{2\bar{S}_{ij}\bar{S}_{ij}}$

逐项拆解：

**第一步，看 $\Delta$**：网格尺度。$C_s\Delta$ 相当于「小涡的有效混合长度」——网格越粗，被参数化的涡越大，混合长度越长。$\Delta$ 取 $( \Delta x \Delta y \Delta z)^{1/3}$ 或 $\sqrt{\Delta x \Delta y}$，各实现不同。
**第二步，看 $\bar{S}_{ij}$**：已解析应变率，$\bar{S}_{ij} = \tfrac{1}{2}(\partial \bar{u}_i/\partial x_j + \partial \bar{u}_j/\partial x_i)$。它度量已解析流的剪切强度。
**第三步，看 $\sqrt{2\bar{S}_{ij}\bar{S}_{ij}}$**：应变率的标量范数，通常记 $|\bar{S}|$。剪切强的地方，SGS 黏性自动加大——与 K 理论的「通量随梯度」同构。
- **第四步，看常数 $C_s \approx 0.2$**：由惯性子区理论推得：若小涡谱服从 −5/3 律，则涡黏必然是这个量级的常数。它把第 2 节的谱理论直接「翻译」成了模型参数。
- **第五步，看局限**：近地面 $|\bar{S}|$ 极大，$C_s\Delta$ 的公式会过度耗散——因此 LES 常在近壁处衰减 $C_s$，或改用动态模型。这一近壁修正，正是边界层 LES 与工程 LES 最常踩的坑。

**辨析｜易错点：** LES 的网格必须「解析含能涡」，即 $\Delta$ 远小于能量峰对应尺度，否则大涡也被参数化，退化成 RANS；反过来 $\Delta$ 太小则网格数爆炸。判断 LES 是否「真 LES」，常看亚网格湍能占比是否远小于解析部分。<span class="marginnote">水平周期边界假设下，LES 无法模拟「真实地形随高度变」的次网格地形效应，也无法处理长期缓慢演变的天气尺度背景——所以 LES 多用于理想化个例（理想热泡、理想层积云），用它做真实城市/复杂地形个例要格外谨慎。</span>

## 7 小结

- **三条腿**：观测、相似理论、数值模拟；LES 是其中「解析大涡 + 参数化小涡」的折中。
- **为何不 DNS**：$Re$ 高达 $10^8$，全解析需 $10^{15}$ 网格；**为何不 RANS**：非局地现象（夹卷、反梯度）难闭合。
- **滤波与 SGS**：空间滤波切出亚网格应力，斯马戈林斯基模型用涡黏闭合。
- **标准配方**：水平周期 + 底部莫宁—奥布霍夫通量边界 + 地转强迫 + 时间/水平平均。
- **局限**：近壁耗散、周期边界、理想化个例——LES 是研究工具，不是天气预报。
- **收获**：夹卷比普适性、反梯度输运可视化、SBL 间歇性重现、云顶过程还原——LES 是参数化的「虚拟真值」试验台。
- **验证**：与相似理论、谱、收支、观测逐层对照，分辨率收敛性检验是可信度的底线。
- **动态模型**：Germano 恒等式现场标定 $C_s$
