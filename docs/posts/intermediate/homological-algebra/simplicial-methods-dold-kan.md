## 为什么从单纯方法开始

回顾整条路线：我们先是把空间翻译成链复形（《复形与同调群》），又把群、Lie 代数装进环后翻译成模（《群同调与 Lie 代数同调》）。这一切的底层都站着一个古老的几何直觉：**三角形**。把空间切成三角形（**单纯剖分**），再让这些三角形自行生成代数——这就是**单纯方法（simplicial methods）**。

而它带来的最大惊喜是 **Dold-Kan 等价**：**单纯阿贝尔群的世界 与 非负链复形的世界，是同一个世界。** 换言之，我们从第一篇就在用的「链复形」，不过是「单纯阿贝尔群」的另一副面孔。这条等价把组合（simplex）与代数（chain）焊接在一起，也是下一节《导出范畴》里「同伦范畴」的温床。

## 1 单纯集合：用三角形拼出空间

**单纯集合（simplicial set）** $X_\bullet$：一族集合 $X_n$（$n \ge 0$）连同两组映射——

- **面映射** $d_i : X_n \to X_{n-1}$（$0 \le i \le n$）：把第 $n$-单纯形「删掉第 $i$ 个面」，得到 $n-1$ 维单纯形；
- **退化映射** $s_i : X_n \to X_{n+1}$（$0 \le i \le n$）：把第 $i$ 个顶点「复制」，得到一个被压扁的 $n+1$ 维单纯形。

它们满足一组**单纯恒等式**（$d_i d_j = d_{j-1} d_i$ 等，$i < j$ 时），保证「先后删两个面」与顺序无关。简洁而严格的定义：**$X_\bullet$ 是反变函子 $\Delta^{\mathrm{op}} \to \mathbf{Set}$**，其中 $\Delta$ 是以有序集合 $[n] = \{0, 1, \dots, n\}$ 及其保序映射为对象的**单纯范畴**。

单纯恒等式不必死记：只需记住「$d_i$ 删第 $i$ 个位置、$s_i$ 复制第 $i$ 个位置」，所有恒等式都在说「删的顺序可交换」「删掉刚复制的点 = 没发生」。它们的作用是保证 $|X_\bullet|$ 的粘合不依赖「先粘哪一面」——单纯形的胶水必须一致，否则拼出的是歧义空间。

<span class="marginnote">面与退化像「剪刀与胶水」：$d_i$ 剪掉一维，$s_i$ 粘回一维。剪了再粘的次序被恒等式管住，否则数学就乱了套。<strong>记住三件套：一个 $n$-单纯形有 $n+1$ 个面、$n+1$ 种退化；退化单纯形在几何实现里不该被「看见」</strong>。</span>

**几何实现（geometric realization）** $|X_\bullet|$：把每个 $X_n$ 的元素换成标准 $n$-单纯形 $\Delta^n$，再按面与退化映射粘合——得到的是一个真正的拓扑空间。**单纯集合 = 「拓扑空间的手写乐谱」**，而 $|X_\bullet|$ 是它的演奏。经典例子：

- 标准单纯形 $\Delta[n]_\bullet$：实现为 $\Delta^n$；
- **范畴的神经（nerve）** $N(\mathcal{C})_\bullet$：$N_n$ 是 $\mathcal{C}$ 中 $n$ 个可复合箭头的串，面映射由复合给出，实现为分类空间 $B\mathcal{C}$。**范畴自己就是一个「空间」**——这条线索直通同伦论与 $\infty$-范畴。

一个具体的单纯集合（最简单的圆）：$S^1_\bullet$ 取 $S^1_0 = \{v_0, v_1\}$（两个顶点）、$S^1_1 = \{e_0, e_1\}$（两条边，$d_0 e_0 = v_0$、$d_1 e_0 = v_1$，另一条边方向相反），$S^1_n$（$n \ge 2$）全部由退化映射生成。它的几何实现正是圆周。这个例子虽小，却展示了单纯集合的全部语法：**高维单纯形不一定是「新形状」，多数只是低维的退化影像**。

**几何实现与单纯集合是「谱-空间」对偶**：一个 $X_\bullet$ 有多个实现方式（几何实现、半单纯实现），但同伦意义下唯一。这就像「一个代数对象可以有多种几何代言」——同调代数与现代同伦论共享这个世界观。

## 2 单纯对象：把代数也单纯化

把集合换成任意范畴里的对象（群、阿贝尔群、环），就得到**单纯群、单纯阿贝尔群**等。**单纯阿贝尔群**尤其重要：此时 $X_n$ 是阿贝尔群，面与退化是群同态，于是可对每个 $n$ 定义

$$d := \sum_{i=0}^{n} (-1)^i d_i : X_n \to X_{n-1}$$

由单纯恒等式推出 $d^2 = 0$，所以**每个单纯阿贝尔群自动携带一个链复形**——而取同调后得到的 $H_n(X_\bullet) = \ker d_n / \operatorname{im} d_{n+1}$，就是「这个单纯对象的同调」。

这个 $d = \sum (-1)^i d_i$ 与《复形与同调群》里的边界映射是同一个配方：**每一项删掉一个面，正负号让「删两次」抵消**。唯一的新意是「删」被公理化成了范畴 $\Delta$ 的面映射——代数（链复形）与组合（单纯形）在此首次同框。

**同伦群**也可单纯化：对单纯集合 $X_\bullet$ 定义 $\pi_n(X_\bullet, x)$，做法是「填充带洞的球面」。如果每个「洞」都能填（**Kan 复形**的扶子条件），同伦群就有漂亮的表现。**拓扑里同伦等价、同调同构等全部概念，在单纯世界里都有逐条逐项的翻译**——这就是现代同伦论（Quillen 的模型范畴）的立足点。

一个常被问起的细节：同伦群 $\pi_n$ 与同调群 $H_n$ 的区别，在单纯语言里看得更清。$\pi_n$ 要求「球面能填、填了又能填」的每一层扶子条件（Kan 复形），$H_n$ 只要求「循环模边界」的代数条件。**同伦群是「逐层都能填」的全信息记录，同调群是「阿贝尔化后」的廉价记录**——Dold-Kan 之后，两者的精确关系将由规范化复形给出。

一个具体的单纯阿贝尔群：$X_\bullet = \mathbb{Z}$（每个 $X_n = \mathbb{Z}$，$d_i = s_i = \mathrm{id}$）。这是「单点」的单纯模型，其规范化复形 $N(X)_0 = \mathbb{Z}$、$N(X)_n = 0$（$n \ge 1$），同调只有 $H_0 = \mathbb{Z}$——**平凡的输入给出平凡的输出，验证了机器的底线**。

如果把 $N$ 换成「完全规范化」还可得到更强的对比：同伦群 $\pi_n$ 对应「$N(X)_n$ 中模某类边界的商」——同调与同伦的差距，被精确地量化为「循环与同伦圈的商」。

## 3 Dold-Kan 等价：两个世界是同一个世界

**定理（Dold-Kan，1958）**：令 $\mathbf{sAb}$ 为单纯阿贝尔群范畴，$\mathbf{Ch}_{\ge 0}$ 为非负链复形范畴。**规范化复形函子**

$$N : \mathbf{sAb} \longrightarrow \mathbf{Ch}_{\ge 0}, \qquad N(X)_n = \bigcap_{i=0}^{n-1} \ker d_i, \quad d = \sum (-1)^i d_i$$

是范畴**等价**：每个非负链复形都「同构于」某个单纯阿贝尔群的规范化复形，且该对应保持同调。

**怎么理解**：规范化复形把「退化单纯形」的贡献切除，只留「真正的骨架」，于是 $N(X)_n$ 的循环/边界/同调与 $X_\bullet$ 的 $\pi_n$（$n \ge 1$ 时）同构。反向函子（Dold-Kan 的逆）则从一条链复形**重新拼出一个单纯阿贝尔群**——用的正是 Eilenberg-Zilber 洗牌（shuffle）积，把「$n$ 个单纯形的卷积」组合成 $n$-单纯形。

**Dold-Kan 的一次实战**：取非负链复形 $A[n]$（只在第 $n$ 维是 $A$、其余为 0）。它没有同调以外的信息，但 Dold-Kan 的逆把它变成一个「几乎纯退化」的单纯阿贝尔群，几何实现后得到 Eilenberg-MacLane 空间 $K(A, n)$。当 $n = 1$、$A = \mathbb{Z}$ 时，$K(\mathbb{Z}, 1) = S^1$——**一条单薄的链复形 $A[1]$，被翻译成了圆周**。「组合与代数合一」在此上演了最直观的一幕。

再补一句证明的直觉：$N$ 是「去掉退化」，逆函子 $\Gamma$ 是「用洗牌补回退化」。$N\Gamma = \mathrm{id}$ 与 $\Gamma N \cong \mathrm{id}$ 两个方向都靠 Eilenberg-Zilber 洗牌积实现——**等价不是巧合，而是洗牌构造的必然**。

<span class="marginnote">这条等价的深刻性常被低估：它意味着<strong>同调代数里「复形 + 同伦」的全部理论，等价于「单纯阿贝尔群 + 单纯同伦」的理论</strong>。谱序列、导出函子、乃至下一篇《导出范畴》里的三角结构，都可以从两个方向互相验证。Dold-Kan 是「代数与组合合一」的注册证书。</span>

## 4 应用：bar 解析、分类空间与 Eilenberg-MacLane 空间

单纯方法不是花瓶，它把前八篇的很多「抽象对象」重新铸造成「几何对象」：

- **bar 解析就是神经**：上一篇《群同调》里那个写满 $[g_1 \mid g_2 \mid \cdots]$ 的 bar 解析，正是群的**分类空间 $BG = |N(G)|$ 的链复形**。于是 $H_n(G, \mathbb{Z}) = H_n(BG; \mathbb{Z})$ 的几何证明路线被打通：**群同调 = 群的神经空间同调**。
- **Eilenberg-MacLane 空间** $K(A, n)$：要求 $\pi_n = A$、其余同伦群为 0。Dold-Kan 的逆把「只在 $n$ 维非零的链复形 $A[n]$」变回一个单纯阿贝尔群，其几何实现正是 $K(A, n)$。**同调代数的对象成了空间的化身。**
- **同伦与同调的对照**：Dold-Kan 之后，「$\pi_n$（同伦群）与 $H_n$（同调群）差在哪」有了精确答案——同伦群是「单纯群的原生不变量」，同调群是「阿贝尔化后的不变量」，两者经规范化复形精确对应。

再补一条贯穿全专题的注脚：**bar 解析（《群同调与 Lie 代数同调》）其实是「$\mathbb{Z}G$ 上自由模的单纯复形」的规范化复形**——群 $G$ 的 bar 链 $[g_1 \mid \cdots \mid g_n]$ 正是神经 $N(G)_n$ 的规范形式。也就是说，第八篇里那个写满公式的 bar 复形，不过是「群的单纯空间」经 Dold-Kan 落地的坐标纸。**同调代数的「解析」与几何的「剖分」，在此第三次、也是最后一次握手。**

单纯方法的第三个「免费定理」：**单纯集合同伦群与实现空间的同伦群一致**（$|X_\bullet|$ 的同伦结构完全由 $X_\bullet$ 的组合数据决定）。这使得「空间的同伦」可以被纯组合地研究，是代数拓扑史上「有限生成」叙事的顶点。

另一个「免费」结果：**奇异同调与单纯同调等价**——空间单纯剖分复形的同调就是奇异同调。单纯方法因此不是「另一种拓扑」，而是「拓扑的默认坐标系」。

## 5 公式解析：规范化复形 N(X)_n

把 Dold-Kan 的定义拆成四步：

$$
N(X)_n = \bigcap_{i=0}^{n-1} \ker d_i, \qquad d = d_0 - d_1 + d_2 - \cdots + (-1)^n d_n
$$

- **第一步，读懂面映射**：$d_i : X_n \to X_{n-1}$ 删掉第 $i$ 个面。对 $n$-单纯形而言，$d_0$ 删「底」，$d_1, \dots, d_n$ 删各「斜边」。
- **第二步，为什么取交**：$\bigcap_{i=0}^{n-1} \ker d_i$ 是「所有面映射都为零」的链——退化单纯形全在这里被剔除，留下的正是**非退化骨架**。**规范化 = 去掉「压扁的赘肉」，只留真实形状。**
- **第三步，交替和是微分**：$d = \sum (-1)^i d_i$ 是「边界取带符号和」——与第一篇三角形边界的「正负抵消」同一机理。单纯恒等式保证 $d^2 = 0$。
- **第四步，等价怎么用**：Dold-Kan 的逆把任意 $C_\bullet \in \mathbf{Ch}_{\ge 0}$ 送回一个单纯阿贝尔群 $X_\bullet$ 使 $N(X) \cong C_\bullet$。于是**「算一个复形的同调」永远可以换成「算一个单纯对象的同调」**，两条路在需要时互相救济。

**一图流总结**：$X_\bullet$（单纯阿贝尔群）$\xrightarrow{\;N\;}$ $C_\bullet$（链复形）$\xrightarrow{\;H\;}$ $H_*(X_\bullet)$；而 $C_\bullet$ 的任意同调类，都可沿 Dold-Kan 的逆路回到某个 $X_\bullet$。**同调论与单纯同伦论，从 Dold-Kan 起正式合并为一家。**

最后一句话：**Dold-Kan 是「把代数写成几何」的通行证**，而下一篇《导出范畴简介》会告诉我们：这张通行证通往的，正是三角与锥的世界。

## 6 小结

- **单纯集合** = 一族带面映射 $d_i$ 与退化映射 $s_i$ 的集合（函子 $\Delta^{\mathrm{op}} \to \mathbf{Set}$）；几何实现把它粘回拓扑空间。
- 每个单纯阿贝尔群带一个链复形（交替和 $d$），取同调得同调群。
- **Dold-Kan 等价**：$N : \mathbf{sAb} \to \mathbf{Ch}_{\ge 0}$ 是范畴等价，规范化复形 = 去掉退化部分。
- **bar 解析 = 神经**：群同调 = 分类空间同调；Dold-Kan 造出 Eilenberg-MacLane 空间 $K(A,n)$。
- 单纯方法是「组合与代数合一」的桥梁，也是下一篇导出范畴的入口。
- $N$ 去掉退化、$\Gamma$ 用洗牌补回，两个方向都靠 Eilenberg-Zilber 洗牌积实现。
- 奇异同调 = 单纯同调；单纯集合同伦群 = 实现空间同伦群，纯组合即可研究同伦。

在最后一节，我们将问出十篇以来一直悬着的问题：既然「链复形」与「单纯阿贝尔群」是同构的两个世界，那同调不变量真正生活的地方——**导出范畴**——长什么样？三角结构、映射锥与拟同构的局部化，答案就在那里。
