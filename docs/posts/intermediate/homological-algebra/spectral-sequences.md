## 为什么从谱序列开始

前几篇都在处理「一条复形的同调」。可现实中，我们最想算的常常是「两条复形复合、一个双复形、一个纤维化」这类**庞大而分层**的对象。这时候再想一鼓作气取同调，往往算不动。

**谱序列（spectral sequence）**的哲学是：**别急着一步取同调，先按层逼近，逐页修正。** 它把「算同调」拆成一个极限过程：第 1 页给一个粗糙的近似，第 2 页修正一点，第 3 页再修正……在合适的条件下逐页收敛到真正答案。

这与本站标题的「**极限**」是同一个词的两种姿态：分析学的极限逼近一个数，谱序列逼近一个同调群。**谱序列 = 同调世界的极限过程**——这句话值得背下来，它也是最后一篇《导出范畴》里「导出」概念的起点。

## 1 从筛网到逼近：过滤与逐页

一切从一个**过滤（filtration）**开始：给复形 $C$ 装一组递增子复形

$$\cdots \subseteq F_{p-1} C \subseteq F_p C \subseteq F_{p+1} C \subseteq \cdots, \qquad C = \bigcup_p F_p C$$

过滤就像一台筛子，把 $C$ 按「前 $p$ 层」切开。**过滤带来的近似**：如果我们暂时忽略 $F_{p-1} C$ 内部的信息，只看「层片」

$$E^0_{p,q} := F_p C_{p+q} / F_{p-1} C_{p+q}$$

就得到一族「切片」。谱序列的全部工作，就是把这些切片不断重整，直到它们拼回 $H_*(C)$ 的真实模样。

注意这里有两个层次的「近似」：$E^1$ 是「逐层切片后的同调」，$E^\infty$ 是「收敛后的分级片」，而 $H_*$ 是它们的总和。**谱序列像一张连续对焦的底片：越对焦（$r$ 越大），越接近真实影像（$H$）。**

**一次近似（第 1 页）**：层片上的边界映射诱导 $d^0 : E^0_{p,q} \to E^0_{p,q-1}$，取它的同调得到

$$E^1_{p,q} = H_{p+q}(E^0_{p,\bullet}), \qquad d^1 : E^1_{p,q} \to E^1_{p-1,q}$$

——「先对每一层切片取同调」是廉价的第一口。但它忽略了「层与层之间如何串起来」，所以要继续。

## 2 谱序列的定义：逐页进化

**谱序列**由一族页 $(E^r_{p,q}, d^r)_{r \ge 1}$ 组成，其中 $E^r$ 是双分次对象，$d^r$ 是其上的微分，且

$$E^{r+1}_{p,q} = H_{p,q}(E^r, d^r), \qquad d^{r+1} : E^{r+1}_{p,q} \to E^{r+1}_{p-r-1,\, q+r}$$

写成最简形式：**下一页 = 这一页以 $d^r$ 为边界映射的同调**。逐页演进中，微分越拉越「斜」，信息被一遍遍筛洗。

<span class="marginnote">这里的双分次 $(p,q)$ 乍看唬人，其实是「两套账本」：$p$ 记过滤层，$q$ 记维度偏移，两者和 $p+q$ 才是总维度。<strong>一行里 $p$ 与 $q$ 永远把总和守恒在 $p+q$</strong>——这是双复形与纤维化的内在结构，下一篇《双复形与 Künneth 公式》会把这层含义讲透。</span>

**收敛（convergence）**：对**第一象限谱序列**（$p,q \ge 0$ 时才非零），每个点 $(p,q)$ 至多被有限多个 $d^r$ 触碰，故从足够大的 $r$ 起该点不再变化，可定义**极限页**

$$E^\infty_{p,q} = \lim_{r \to \infty} E^r_{p,q}$$

**谱序列收敛到 $H_*$**（记作 $E^2_{p,q} \Rightarrow H_{p+q}(C)$）指

$$E^\infty_{p,q} \cong F_p H_{p+q}(C)/F_{p-1} H_{p+q}(C)$$

**极限页不是 $H$ 本身，而是 $H$ 的「分级片」**——把 $H$ 按过滤切成片，逐片拼回即得 $H$（第一象限时无扩展问题，逐片同构）。<span class="marginnote">为什么强调第一象限？因为若负象限也有非零点，微分可以从四面八方「射进来」，收敛就成问题；只有第一象限 + 每点至多被有限个微分触碰，才能保证 $E^r$ 在每个格子上最终稳定、$E^\infty$ 良定义。</span>

**一个真实用例（Grothendieck 谱序列）**：设 $F : \mathcal{A} \to \mathcal{B}$、$G : \mathcal{B} \to \mathcal{C}$ 都是左正合函子，且 $F$ 把内射对象送到 $G$-acyclic 对象，则

$$E^{pq}_2 = (R^p G)(R^q F)(A) \;\Rightarrow\; R^{p+q}(GF)(A)$$

**「两个函子复合的高阶导子，由各自高阶导子按谱序列拼装」**——这是 Leray-Serre 谱序列（纤维化 $F \to E \to B$ 时 $E_2^{pq} = H^p(B; H^q(F)) \Rightarrow H^{p+q}(E)$）的代数母版，也是代数几何里一切「谱序列力学」的总开关。

**一个能算到底的例子（Hopf 纤维化）**：$S^1 \to S^3 \to S^2$。Leray-Serre 谱序列第 2 页为 $E_2^{pq} = H^p(S^2; H^q(S^1))$，取 $\mathbb{Q}$ 系数则 $H^0(S^1) = H^1(S^1) = \mathbb{Q}$、$H^0(S^2) = H^2(S^2) = \mathbb{Q}$，其余为 0，于是第 2 页只有四格非零：

$$E_2^{00} = E_2^{01} = E_2^{20} = E_2^{21} = \mathbb{Q}$$

总维数 $p+q$ 只有 $0, 1, 2, 3$ 四档，每档恰好一格，没有空间容纳非平凡微分，谱序列在第 2 页就退化，直接读出 $H^0(S^3) = H^3(S^3) = \mathbb{Q}$、$H^1 = H^2 = 0$。**当第 2 页每个对角线至多一格时，谱序列白送答案**——这套「数格子」的心法，正是实践里用谱序列的常态。

谱序列还有一条常被忽视的副产物：**边缘同态**（edge homomorphism）$H^{p+q}(E) \to E_2^{0,p+q}$ 与 $E_2^{p,0} \to H^{p+q}(E)$。它给「已知近似、未知真相」的问题提供第一手的比较渠道——例如 Leray-Serre 中底空间的类如何拉回全空间，正是 $E_2^{p,0}$ 格的边缘同态在说话。

## 3 谱序列怎么用：三条公理式的心法

面对一个具体谱序列，实践者按固定套路出牌：

1. **算第 2 页**：$E^2$ 通常由「已掌握的定理」给出（例如 Leray-Serre 中 $H^p(B; H^q(F))$ 可由基础同调直接算）。**谱序列的价值是「把难题转化为算 $E^2$ 再加一个微分」**。
2. **找「真空区」**：若目标总维度 $n$ 很小，第一象限里对应 $p+q=n$ 的斜线只有少数几格，此时 $E^2$ 的孤立格子直接就是 $E^\infty$——**谱序列白送答案**。
3. **追边缘微分**：真正要动手的往往是边缘区的 $d^r$。一个非零 $d^r$ 的存在，会让第 $r+1$ 页比第 $r$ 页「消失」一批格子——**每消失一个非平凡类，就是一次真实的信息修正**。

第四条心法（读懂退化）是最常用的一招：若 $E^2$ 的某些行或列全为 0，谱序列在那里「没戏可唱」，对应的 $H$ 部分就是零。**行/列真空 = 同调真空**——例如 Leray-Serre 里若纤维 $F$ 满足 $H^*(F) = 0$（$* > 0$），则 $H^*(E) \cong H^*(B)$ 直接被谱序列白送。

**辨析｜易错点**：谱序列**不**自动告诉你「扩展问题」。$E^\infty$ 是 $H$ 的分级片，若 $H$ 的相邻过滤商「错位」了（非分裂），拼回 $H$ 时还会有扩展群 $\operatorname{Ext}^1$ 出面调停。**「谱序列收敛到 X」与「谱序列等于 X」之间隔着一个扩展问题**，切莫划等号。

## 4 公式解析：E^{r+1} = H(E^r, d^r)

把谱序列的「进化律」拆成四步：

$$
E^{r+1}_{p,q} = \frac{\ker\bigl(d^r : E^r_{p,q} \to E^r_{p-r,\,q+r-1}\bigr)}{\operatorname{im}\bigl(d^r : E^r_{p+r,\,q-r+1} \to E^r_{p,q}\bigr)}
$$

- **第一步，读懂方向**：$d^r$ 从 $(p,q)$ 指向 $(p-r,\,q+r-1)$，同时把 $p$ 减 $r$、把 $q$ 增 $r-1$，而**总维数 $p+q$ 守恒**（$p + q = (p-r) + (q+r-1) + 1$，取的是一维同调的「下一维」口径）。$r$ 越大，箭头越斜。
- **第二步，这仍是一次普通同调**：分子分母分别是「$d^r$ 的核与像」，商出的东西就是「以 $d^r$ 为边界映射的同调」——和我们第一篇学的 $H = \ker/\operatorname{im}$ 一模一样，只是换了脚下这页 $E^r$。
- **第三步，为何是「进化」**：$E^{r+1}$ 是 $E^r$ 的商-子模配对，每一页都是上一页的「浓缩」；凡是被 $d^r$ 杀掉的东西，就不再参与以后各页。
- **第四步，什么时候停**：第一象限里对固定 $(p,q)$ 只有有限个 $r$ 让 $d^r$ 真的「够得到」，于是点稳定，得 $E^\infty_{p,q} = F_pH_{p+q}/F_{p-1}H_{p+q}$。**「逐页求同调，终归于 $H$ 的分级片」**，这就是全部机制。

由此得到一个实用的心理模型：**$E^2$ 是「一次近似」，$E^\infty$ 是「最终答案的分级」，中间的每一页都在修正**。设计一个谱序列，等于设计一条「从好算的近似通向真答案」的收敛通道。

## 5 小结

- **过滤 → 层片 → 第 1 页近似 → 逐页修正 → 极限页**，谱序列是把同调计算变成极限过程的装置。
- 进化律 $E^{r+1} = H(E^r, d^r)$，微分 $d^r$ 越来越斜，总维数 $p+q$ 守恒。
- **收敛**：$E^\infty_{p,q} \cong F_pH_{p+q}/F_{p-1}H_{p+q}$（第一象限无扩展问题）。
- 典型用例：**Grothendieck 谱序列** $R^pG\circ R^qF \Rightarrow R^{p+q}(GF)$，Leray-Serre 是其拓扑化身。
- **易错**：$E^\infty$ 是 $H$ 的分级片而非 $H$；拼回时可能遇到扩展问题。
- 边缘同态给出「近似与真相」之间的第一手比较渠道（如 Leray-Serre 中底空间类的拉回）。
- 行/列真空 = 同调真空：$E^2$ 的零行零列直接对应 $H$ 的消失部分。

在下一节，我们将把谱序列的舞台搭起来：**双复形**有两个天然的过滤器，从而给出两个「走向同一个答案」的谱序列——这正是 Künneth 公式背后那双看不见的手。
