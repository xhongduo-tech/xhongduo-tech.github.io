## 为什么从复形开始

同调代数是「以代数之力问几何之形」的学科。它的全部机器——导出函子、谱序列、导出范畴——都由一个看似朴素的概念启动：**复形**。一条链复形只是「一串向量空间加上一组平方为零的线性映射」，然而就是这组平凡到近乎无聊的 $d^2 = 0$，在一次求商之后，竟然能测出圆周上的洞、球面里的空洞，甚至能说出两个空间在何时「有相同的洞」。

这与本站的主线暗合：**极限**告诉我们用什么来逼近，而同调则负责回答「逼近不到的地方剩下了什么」——它把「差一点精确」翻译成一个代数不变量。我们先学好这第一课：什么是复形，什么是它的同调，以及为什么这组东西能测洞。

## 1 复形：搭一座可以取差分的梯子

**链复形（chain complex）**：一族 $R$-模 $C_n$（$n \in \mathbb{Z}$）连同模同态 $d_n : C_n \to C_{n-1}$，满足**每一个边界映射平方为零**：

$$d_{n-1} \circ d_n = 0, \qquad \text{记作 } d^2 = 0$$

我们把 $C_n$ 的元素称为 $n$-**维链（chain）**，$d_n$ 称为**边界映射（boundary map）**。写开就是：

$$\cdots \xrightarrow{\;d_{n+1}\;} C_n \xrightarrow{\;d_n\;} C_{n-1} \xrightarrow{\;d_{n-1}\;} \cdots$$

<span class="marginnote">记号统一约定：指标下降的复形叫「链复形」，指标上升的叫「上链复形」，后者见第三篇《导出函子》。两者的全部性质完全平行，我们先用链复形建立直觉。</span>

$d^2 = 0$ 是一条**守恒律**：**一个边界的边界永远是空的**。打个比方——线段的边界是两个端点，端点的边界是空集；三角形面的边界是三条边，三条边围成闭合的圈，闭合圈的边界是空集。每一层 $d$ 都是在「取一层边界」，取两次必然取到空。这正是**边界定理（boundary of a boundary is empty）**，拓扑中 Stokes 定理的代数内核。

一个具体例子：设 $X$ 是一个三角形（两个顶点加三条边再加一个面），令 $C_2 = R$（一个面），$C_1 = R^3$（三条边），$C_0 = R^2$（两个顶点），$d_2$ 把面送到三条边的「带符号边界」，$d_1$ 把每条边送到两端顶点的差。你会算出来 $d_1 d_2 = 0$：三条边首尾相接，正负端点彼此抵消。

名字里的「链」来自拓扑的剖分：$C_n$ 是 $n$ 维小面拼成的「链」，$d$ 把链送到它的「边界」。于是 $H_n$ 可以读作「$n$ 维循环中被边界抵消后剩余的部分」——这个说法贯穿全篇，也是后续一切概念（导出函子、谱序列）的记忆锚点。

## 2 同调群：用商来测洞

有了复形，测洞就只需一次除法。定义两个子模：

- **闭链 / 循环（cycle）**：$Z_n(C) = \ker d_n \subseteq C_n$，即「边界取完为零」的链；
- **边界（boundary）**：$B_n(C) = \operatorname{im} d_{n+1} \subseteq C_n$，即「能充当别人边界」的链。

由 $d^2 = 0$ 立刻得到 $B_n \subseteq Z_n$：边界一定是循环，反之不一定。于是可以求商：

$$\boxed{\,H_n(C) = Z_n(C)\,/\,B_n(C)\,}$$

$H_n(C)$ 就是复形 $C$ 的**第 $n$ 个同调群（homology group）**。两个循环 $z, z' \in Z_n$ 若差一个边界（$z - z' \in B_n$），就说它们**同调（homologous）**，在 $H_n$ 中代表同一个元素。下面这幅图把「边界」与「洞」的区别一次画清：

![循环与边界：圆如果是某区域的边界则同调为零，独立圆周则测出一个洞](/images/homological-algebra/complexes-and-homology-1.svg)

<span class="marginnote">「闭但不为边界」正是「洞」的代数化身：圆周这个闭链圈住了一个洞，它不是任何二维填充的边界，因此在 $H_1$ 里给出非零类；而赤道圆是球面（上半球面）的边界，它在球面的 $H_1$ 里就是零类。同调不数「有多少个点」，只数「有多少个圈」。</span>

**为什么是「商」而不是「差」**：$B_n \subseteq Z_n$ 给出一套「等价关系」，商掉之后留下来的 $H_n$ 就是「循环中真正独立、不再被边界抵消的那部分」——通俗地说，就是「洞的个数」。维数若有限，$\dim H_n = \dim Z_n - \dim B_n$ 即「闭的减去可以补的」。

以拓扑空间为例：圆的 $H_1 = R$（一个洞），环面 $T^2$ 的 $H_1 = R^2$（两个独立的大圈：经线、纬线），实心球的 $H_1 = 0$（每个圈都能补）。**同调群的大小、秩、自由部分，直接编码了几何形状的信息。**

## 3 链映射与链同伦：如何比较两个形状

光有单条复形还不够，我们要比较。**链映射（chain map）** $f : C \to D$ 是一族同态 $f_n : C_n \to D_n$，使得与边界映射可交换：

$$f_{n-1} \circ d_n = d'_n \circ f_n, \qquad \text{即 } f d = d' f$$

可交换性保证链映射把循环送到循环、边界送到边界，因而**诱导出同调群之间的同态** $f_* : H_n(C) \to H_n(D)$。两个链映射若要诱导出相同的 $f_*$，更精细的判据是**链同伦（chain homotopy）**：存在一族映射 $s_n : C_n \to D_{n+1}$ 使得

$$f_n - g_n = d'_{n+1} s_n + s_{n-1} d_n$$

直觉上，$s$ 给出了一条「把 $f$ 逐层滑向 $g$」的棱柱，就像拓扑里的同伦「把一张纸片连续弯成另一张」。链同伦的两个链映射在同调群上无差别：$f_* = g_*$。由此得到同调的第一条威力定理：

**定理（同伦不变性）**：若两个拓扑空间同伦等价，则它们的奇异性同调群同构。

<span class="marginnote">一个拓扑不变量指「同胚不变」的量。同调甚至更强：它在<strong>同伦等价</strong>下都不变，是所谓同伦不变量。这让我们可以先自由地把空间变形到更简单的形状，再算同调。例如「点」与「实心球」同伦等价，所以 $H_n(\text{实心球}) = 0$（$n \ge 1$）。</span>

## 4 精确列与长正合列：同调真正的引擎

同调之所以有用，不在于单独一个 $H_n$，而在于它们如何被「精确列」组织起来。**正合列（exact sequence）**：一串同态 $A \xrightarrow{f} B \xrightarrow{g} C$ 满足 $\operatorname{im} f = \ker g$。短正合列（SES）形如

$$0 \to A \xrightarrow{\;f\;} B \xrightarrow{\;g\;} C \to 0$$

**核心命题（同调的长正合列）**：复形的短正合列 $0 \to A \to B \to C \to 0$ 诱导一条**无穷长的、精确的**同调序列

$$\cdots \to H_{n}(A) \to H_{n}(B) \to H_{n}(C) \xrightarrow{\;\delta_n\;} H_{n-1}(A) \to \cdots$$

其中 $\delta_n$ 叫**连接同态（connecting homomorphism）**，它把 $C$ 的洞「连接」回 $A$ 的低维洞——这个 $\delta$ 的出现需要一次「绕回」（diagram chasing），正是下一篇《蛇引理与连接同态》的主题。

长正合列是把「整体信息」与「局部信息」互相换算的桥梁：只要知道三者之二，往往能推出第三个的大部分。这是整个学科反复使用的第一件工具。

## 5 公式解析：H_n(C) = ker d_n / im d_{n+1}

把最核心的公式拆成三步：

$$
H_n(C) = \frac{\ker d_n}{\operatorname{im} d_{n+1}}
$$

- **第一步，读懂符号**：$\ker d_n$ 是 $C_n$ 中「取边界为零」的子模，即**循环** $Z_n$；$\operatorname{im} d_{n+1}$ 是 $C_n$ 中「能由更高一维链的边界得到」的子模，即**边界** $B_n$。$d^2 = 0$ 保证 $B_n \subseteq Z_n$，所以商有定义。
- **第二步，为什么商**：商掉 $B_n$ 就是把「差一个边界」的循环等同起来。两个循环的差若是某个三维块的边界，它们圈住的就是同一个洞。**同调类 = 洞的等价类。**
- **第三步，几何直觉**：$Z_n$ 太大——它把「真洞」和「能补上的圈」混在一起；$B_n$ 正是「能补上的圈」。$Z_n/B_n$ 只留下「补不上的圈」，也就是洞。每多一个独立生成元，就多一个洞。

再看链复形的一个标准例子：设 $C_2 = R$，$C_1 = R^2$，$C_0 = R$，$d_2 = \binom{1}{1}$，$d_1 = \begin{pmatrix} 1 & 1 \end{pmatrix}$。则 $d_1 d_2 = 1 + 1 = 2 \ne 0$——这不是复形！要让它成为复形必须 $d_1 d_2 = 0$，这个「**必须有东西抵消**」的刚性约束，正是同调代数里一切巧合与定理的源头。反过来，若取 $d_1 = \begin{pmatrix} 1 & -1 \end{pmatrix}$ 且 $d_2 = \binom{1}{1}$，则 $d_1 d_2 = 1 - 1 = 0$，复形成立，且 $H_1 = \ker d_1 / \operatorname{im} d_2 = 0$，$H_0 = R$——一条实心的弧，两端连通，没有一维洞。数字虽小，但「闭合性与恰好抵消」的机理一望即明。

再算一次带几何意义的经典例子：把圆周 $S^1$ 剖分成三条边围成的三角形。取 $C_2 = 0$（没有面），$C_1 = R^3$（三条边 $e_0, e_1, e_2$），$C_0 = R^3$（三个顶点 $v_0, v_1, v_2$），边界映射 $d_1 e_i = v_{i+1} - v_i$（下标模 3）。先看 $Z_1 = \ker d_1$：满足 $d_1(a e_0 + b e_1 + c e_2) = (b - a)v_0 + (c - b)v_1 + (a - c)v_2 = 0$，解出 $a = b = c$，所以 $Z_1 = R$。再看 $B_1 = \operatorname{im} d_2 = 0$（因为 $C_2 = 0$）。于是

$$H_1(S^1) = R / 0 = R$$

——**一个洞，不多不少**。再算 $H_0 = Z_0/B_0$：$Z_0 = C_0 = R^3$，而 $B_0 = \operatorname{im} d_1$ 由 $v_1 - v_0,\ v_2 - v_1,\ v_0 - v_2$ 张成，恰是「坐标之和为零」的二维子空间，故 $H_0 = R$——**连通**。这套「剖分 → 列复形 → 求商」的三步流程，就是未来一切同调计算的模板；下一篇《蛇引理》里，它还要与短正合列联合作战。

## 6 小结

- **链复形**是「模 + 平方为零的边界映射」，$d^2 = 0$ 是测洞的守恒律。
- **循环** $Z_n = \ker d_n$，**边界** $B_n = \operatorname{im} d_{n+1}$，$B_n \subseteq Z_n$。
- **同调群** $H_n = Z_n/B_n$ 数「洞的个数」，是链映射、链同伦作用下的不变量。
- 链同伦的映射诱导相同同调同态；同调是**同伦不变量**。
- 复形的短正合列给出**长正合列**，连接同态 $\delta_n$ 是全场的关键人物。

在下一节，我们将直面长正合列里那个神秘莫测的连接同态：它究竟如何被构造、凭什么精确，答案就是同调代数里最著名的一幅「通勤图」——**蛇引理**。
