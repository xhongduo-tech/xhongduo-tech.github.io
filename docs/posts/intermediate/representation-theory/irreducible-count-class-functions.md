## 为什么从类函数空间开始

前面的正交关系告诉我们「不可约特征标相互正交」，但还没有回答一个计数问题：**不可约表示一共有多少个？** 特征标表上该画几行？这一篇给出简洁而优美的答案：**不可约表示的个数等于共轭类的个数**。证明的关键是把视角从「具体的群」抬高到「类函数空间」——一个以共轭类为「坐标轴」的有限维空间，其中的正交规范基恰好就是不可约特征标。

从「从极限到大模型」主线看，这是「选择正确的工作空间」的示范。<span class="marginnote">正如傅里叶分析要先选定函数空间 $L^2$ 再谈基，表示论要选定类函数空间 $H$ 再谈分解。空间选对了，难问题变成「求一组基」；选错了，问题停留在逐元计算。</span>类函数空间还有一个直接用途：**特征标表是方阵**（行数 = 列数），这让特征标表成为「群的数值身份证」，甚至可以在不知道群结构的情况下反推信息——这正是有限群分类与分子光谱学里的常规操作。<span class="marginnote">两个群即使不同构，也可能有「一样形状」的特征标表（称为等谱/isospectral）；但反过来，特征标表的自洽性检查能证伪很多「假装是群」的候选结构。表示论把「群是什么」部分转化为「表是什么」。</span>

## 1 类函数空间的维数

回顾类函数空间：

$$H = \{ f : G \to \mathbb{C} \mid f(tgt^{-1}) = f(g) \ \forall g, t \in G \}$$

**类函数空间以共轭类为「坐标」**：一个类函数由它在每个共轭类上的取值决定，而共轭类之间互不影响，因此

$$\dim H = \#\{\text{共轭类}\} =: h$$

更精确地说，对每个共轭类 $C$，定义它的**类函数基元** $\delta_C$（在 $C$ 上取 $1$、其余为 $0$），则 $\{\delta_C\}$ 是 $H$ 的一组基。<span class="marginnote">这个基太平凡，以至于容易被忽略——但它立刻说明「$H$ 有多大」完全由群的「共轭结构」决定。$S_3$ 有 3 个共轭类，$H$ 就是三维空间；可解释为「三个类上各取一个复数值」的自由度。</span>这个「以类为坐标」的视角，是后面一切「数一数」论证的基础：把群论问题翻译成「$h$ 维向量空间里的线性代数问题」。

## 2 不可约特征标是一组正交规范基

**定理（不可约特征标基定理）**：设 $\chi_1, \dots, \chi_s$ 是 $G$ 的全部两两不等价不可约特征标，则它们构成 $H$ 的一组**正交规范基**：

1. （正交规范）$\langle \chi_i, \chi_j \rangle = \delta_{ij}$——上篇已证；
2. （张成）每个类函数 $f \in H$ 可唯一写成

$$f = \sum_{i=1}^{s} \langle f, \chi_i \rangle\, \chi_i$$

第二条是关键的新内容：不可约特征标不仅正交，还**张满** $H$。<span class="marginnote">证明要点：若 $f$ 与所有不可约特征标正交，则 $f$ 与一切表示的特征标正交（因为特征标是 $\chi_i$ 的整系数组合）；取正则表示，用 $\langle \chi_{\mathrm{reg}}, f \rangle = f(e)$ 等恒等式可推出 $f \equiv 0$。所以「正交补里只有零」，即张成。</span>由此立刻得到本节的核心计数：

$$s = \#\{\text{不可约表示}\} = \dim H = h = \#\{\text{共轭类}\}$$

**不可约表示的数量等于共轭类的数量**——这个等式把「表示的目录」与「群的共轭结构」绑定，是表示论最常用的计数工具之一。<span class="marginnote">例：$S_3$ 有 3 个共轭类，所以恰有 3 个不可约表示；$S_4$ 有 5 个共轭类（对应 5 种置换型），恰有 5 个不可约表示（维数 $1,1,2,3,3$）。「数类」替代「构造表示」，是这条定理最直接的用法。</span>

## 3 公式解析：张成公式与分解

把「类函数按不可约特征标展开」写全：

$$f(g) = \sum_{i=1}^{s} \langle f, \chi_i \rangle\, \chi_i(g), \qquad \langle f, \chi_i \rangle = \frac{1}{|G|}\sum_{x \in G} f(x)\,\overline{\chi_i(x)}$$

- **第一步，读系数**：$\langle f, \chi_i \rangle$ 是 $f$ 在「坐标轴 $\chi_i$」上的投影。因为 $\chi_i$ 正交规范，投影公式与普通欧氏空间完全一致——这是「正交规范基」四个字的全部含义。
- **第二步，读还原**：把投影系数代回去，$f(g)$ 被还原成各分量之和。这与傅里叶反演公式 $f(x) = \sum_k \hat{f}(k) e^{ikx}$ 形式相同，只是「频率 $k$」换成了「不可约表示 $i$」。
- **第三步，读唯一性**：正交规范基的展开系数唯一。特别地，**一个特征标 $\chi$ 若与另一个特征标在所有 $g$ 处相等，则它们的展开系数全相等，从而对应同一个表示**——这正是「特征标完全决定表示」的严格版本。
- **第四步，读维度匹配**：左边「$f$ 有 $h$ 个自由度」，右边「$s$ 项求和、每项一个系数」，若要恒等式对一切 $f$ 成立必须 $s = h$。这是「个数相等」的另一种直观。

**辨析｜易错点：** 正交规范基里的「规范」指 $\langle \chi_i, \chi_i \rangle = 1$，不是 $\chi_i$ 在某点取值 $1$。两者勿混：$\chi_i(e) = n_i$（维数，可能大于 $1$），而「与自身内积为 $1$」。计算内积时 $\chi_i$ 是函数、要与自身共轭相乘再对群元平均——在 $S_3$ 的标准表示上我们已经验证过 $\langle \chi_{\mathrm{std}}, \chi_{\mathrm{std}} \rangle = 1$ 而 $\chi_{\mathrm{std}}(e) = 2$，两者数值不同、含义不同。

## 4 类函数空间带来的三个应用

把「不可约特征标张成 $H$」这个事实用于实践：

**应用一（特征标表是方阵）**：特征标表以不可约表示（$s$ 个）为行、共轭类（$h$ 个）为列，$s = h$，所以表是**方阵**。第一正交关系说行向量正交规范，第二正交关系说列向量也正交（按类阶加权后）。<span class="marginnote">一个方阵的行列同时正交，意味着它的<strong>行列式非零</strong>——特征标表是可逆矩阵。这个「表可逆」的事实是计算群论里用表反解类结构的基础：已知表，能解出类的大小与中心化子的阶。</span>

**应用二（不等价表示的判据）**：两个表示等价当且仅当特征标相等；而特征标相等可通过「与基展开系数相等」检验。于是「判别表示是否等价」变成「比较展开系数向量」——线性代数问题。<span class="marginnote">实践中更常用的是判不可约：算 $\langle \chi, \chi \rangle$。若得 $1$ 则不可约；得大于 $1$ 的整数则说明有重数，$\sum m_i^2$ 给出「复杂度」。</span>

**应用三（类函数的卷积结构）**：$H$ 上除内积外还带有「卷积」$f \ast f'$（按群代数乘法）。不可约特征标不仅正交，还是卷积意义下的「本征函数」：$\chi_i \ast f = \frac{|G| \chi_i(f)}{n_i} \chi_i$。这使类函数空间成为「卷积代数的谱理论」——与信号处理里「函数按特征函数展开」完全平行。<span class="marginnote">这个应用把前三篇的内容串成一条线：特征标正交性 ↔ 傅里叶正交性，类函数展开 ↔ 傅里叶反演，卷积本征方程 ↔ 线性时不变系统的特征响应。表示论确实是「抽象傅里叶分析」。</span>

**例：固定点数函数按特征标展开。** 设 $f(g)$ 为「置换 $g$ 在 $\{1,2,3\}$ 上的固定点数」——它是 $S_3$ 的类函数，取值 $f = (3, 1, 0)$（在类 $e, (12), (123)$ 上）。把它按不可约特征标展开：

$$f = \langle f, \chi_{\mathbf 1} \rangle \chi_{\mathbf 1} + \langle f, \chi_{\varepsilon} \rangle \chi_{\varepsilon} + \langle f, \chi_{\mathrm{std}} \rangle \chi_{\mathrm{std}}$$

逐项计算系数：$\langle f, \chi_{\mathbf 1} \rangle = \tfrac16(1\cdot 3 \cdot 1 + 3\cdot 1 \cdot 1 + 2\cdot 0 \cdot 1) = 1$；$\langle f, \chi_{\varepsilon} \rangle = \tfrac16(3 - 3 + 0) = 0$；$\langle f, \chi_{\mathrm{std}} \rangle = \tfrac16(6 + 0 + 0) = 1$。故

$$f = \chi_{\mathbf 1} + \chi_{\mathrm{std}}$$

固定点数函数恰是「平凡 + 标准」两个特征标之和。这验证了「类函数按正交基展开」的实操流程，也解释了为何置换表示含平凡分量恰好一次——不动点均值 $\langle f, \mathbf{1} \rangle = 1$ 正是 Burnside 引理的重数语言。

**通向 Frobenius 行列式公式。** 类函数展开的威力在对称群上达到顶峰：Frobenius 发现 $S_n$ 的不可约特征标可写成「轮换指标多项式的行列式商」，从而把特征标计算完全组合化。这条公式与杨图、hook 长度公式同源（见下一篇），是「类函数空间基」思想在 $S_n$ 上的极致演绎。

**在量子化学里的化身。** 类函数空间的基对应「对称化投影算子」：把任意函数按不可约表示投影，得到该对称类型的分量。分子轨道对称性匹配（Woodward–Hoffmann 规则的群论版）正是这一套——先把轨道按不可约表示分类，再按「对称性是否匹配」判断反应是否允许。

**与表示环的关联。** 类函数空间与「表示环」$R(G)$（不可约特征标的整系数组合）对偶；$R(G)$ 上的乘法就是张量积，$R(G) \otimes \mathbb{C} \cong H$。表示环在代数 K-理论与代拓扑中是基本对象——「按特征标加法计算」的日常操作，其实是在一个环上做加法。

**一条记忆锚点。** 本篇的全部内容可以浓缩为一句：「特征标表是方阵，行按第一正交、列按第二正交，行列式非零」。方阵（$s = h$）、正交（基）、可逆（行列式非零）——三个词就是类函数空间理论的骨架。

下一篇将走出单个群的内部，研究表示如何在子群与群之间传递。

## 5 特征标表能告诉我们什么

既然不可约特征标张成 $H$，它们就「分得开」所有共轭类。

**分离定理**：对任意两个非共轭的群元 $g \not\sim h$，存在某个不可约特征标 $\chi_i$ 使 $\chi_i(g) \neq \chi_i(h)$。<span class="marginnote">证明：若对所有 $i$ 都有 $\chi_i(g) = \chi_i(h)$，则两个「类指示函数」$\delta_{[g]}, \delta_{[h]}$ 在基 $\{\chi_i\}$ 下的展开系数全部相同，从而是同一个函数，矛盾于 $g \not\sim h$。基之所以是基，就是因为不同向量有不同的坐标。</span>这条定理说明：特征标表不是「丢了很多信息后的残影」，而是「足够复现群的大量结构」的完整账本。

从表上可以直接读出的量：

**类的大小可反解。** 由第二正交关系（取 $h = g$）：

$$|C_G(g)| = \sum_{i=1}^{s} |\chi_i(g)|^2, \qquad |C(g)| = \frac{|G|}{|C_G(g)|}$$

仅凭特征标表就能还原每个共轭类里有多少个群元——这是「表可逆」的第一次实战。<span class="marginnote">上篇我们在 $S_3$ 上验证过这条：$|C_G((12))| = 1^2 + 1^2 + 0^2 = 2$，与中心化子 $\{e,(12)\}$ 大小吻合。类的大小、类的个数、群的阶，全部藏在表里。</span>

**阿贝尔性可判定。** $G$ 阿贝尔当且仅当 $s = |G|$（每个元素自成共轭类），当且仅当所有不可约表示都是一维的（平方和公式 $|G| = \sum n_i^2$ 此时每一项为 $1$）。从表上一眼看出：不可约维数全为 $1 \iff$ 阿贝尔。

**例：用约束锁定 $S_4$ 的维数。** $S_4$ 有 $|G| = 24$、$5$ 个共轭类（对应 5 种置换型），故 $5$ 个不可约表示，维数 $n_1 \le \cdots \le n_5$ 满足平方和 $n_1^2 + \cdots + n_5^2 = 24$、整除条件 $n_i \mid 24$、且 $n_1 = 1$（平凡表示必在）。满足全部约束的组合只有 $(1,1,2,3,3)$——**不构造任何表示，维数已被锁定**。这个「预告维数组合」的流程，是特征标表理论的招牌技法。

**例：再用 $A_5$ 检验一次。** 交错群 $A_5$ 有 $|G| = 60$、$5$ 个共轭类，故也是 $5$ 个不可约表示。同样的约束——维数整除 $60$、平方和 $1^2 + n_2^2 + \cdots + n_5^2 = 60$、平凡表示维数 $1$——唯一地锁定组合 $(1, 3, 3, 4, 5)$：$1 + 9 + 9 + 16 + 25 = 60$。<span class="marginnote">$A_5$ 是最小的非阿贝尔单群：它的交换化平凡，故不存在非平凡一维表示，维数组合里「最小非平凡维数直接跳到 $3$」正是单性的痕迹。相比之下 $S_4$ 有符号表示 $\varepsilon$（维数 $1$），组合从 $1, 1$ 开头。整除性还顺手排除了含 $2$ 或 $6$ 的候选——平方 $4$、$36$ 一旦参与，其余各项就凑不满 $60$。</span>构造还没开始，维数已经定型——「数一数」替代「构造出来」的价值，正在于此。

**边界：特征标表不决定群。** 值得警惕的是，特征标表再丰富，也**不能**唯一决定群的同构类：存在不同构但特征标表相同的群（称为等谱群，如 $D_8$ 与 $Q_8$）。表示论给的是「表示层面的完整信息」，未必是「乘法表层面的完整信息」。「表可逆」指的是可从表反解类结构，而非反解整个群结构——这两件事要分清。

## 6 小结

- **类函数空间** $H$ 以共轭类为坐标，$\dim H = h$ = 共轭类个数。
- **基定理**：不可约特征标构成 $H$ 的正交规范基，每个类函数可展开 $f = \sum_i \langle f, \chi_i \rangle \chi_i$。
- **核心计数**：不可约表示个数 $s$ = 共轭类个数 $h$。
- **特征标表是方阵**（$s \times h$，$s = h$），行按第一正交、列按第二正交；表可逆。
- 应用：等价判据（特征标相等）、不可约判据（$\langle \chi,\chi\rangle = 1$）、卷积谱理论（$\chi_i \ast f$ 是 $\chi_i$ 的本征向量）。
- **分离定理**：任意两个非共轭群元都能被某个不可约特征标区分，故特征标表足以复现群的共轭结构。

在下一节，我们将走进群代数的内部：正则表示里每种不可约表示各出现 $\dim \rho_i$ 次——类函数空间的基理论在那里变成表示论的计数武器，那就是《群代数与正则表示的分解》。
