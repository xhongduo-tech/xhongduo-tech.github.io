## 为什么从 SU(2) 与 SO(3) 开始

在量子力学里，「旋转对称性」不是抽象概念：氢原子波函数、自旋、角动量相加，全部由 $SO(3)$ 与 $SU(2)$ 的表示论支配。本篇把前一篇的 Peter–Weyl 框架落实到这两个最实用的紧群上，并回答三个问题：它们的不可约表示长什么样？两个表示「相乘」（张量积）怎么分解？这跟「角动量量子数 $j$」「自旋」「Clebsch–Gordan 系数」怎么对上？<span class="marginnote">答案概览：$SU(2)$ 的不可约表示 $V_j$ 由半整数 $j = 0, \tfrac12, 1, \tfrac32, \dots$ 标记，$\dim V_j = 2j+1$；$SO(3)$ 只留下整数 $j$ 的 $V_l$（球谐函数的 $l$）。「自旋 $j$」就是「$V_j$ 上的一组态」。</span>

从「从极限到大模型」主线看，这是表示论第一次直接「接管」一个物理理论的内部语言。<span class="marginnote">量子力学里的「好量子数」「能级简并」「选择定则」本质上都是表示论概念：简并度 = 不可约表示维数，选择定则 = 张量积分解中哪一块不出现。学会本篇，你就拥有了「用群说话」的物理直觉。</span>更深一层，$SU(2) \to SO(3)$ 的双覆盖结构预演了规范理论中「自旋对旋转」的关系——旋量（half-integer）之所以存在，正是因为 $SU(2)$ 比 $SO(3)$ 多出一层。<span class="marginnote">历史上，泡利用 2×2 矩阵描写自旋 $\tfrac12$ 时并不知道自己在构造 $SU(2)$ 的表示；Weyl 后来指出这正是双覆盖的表示。数学领先于物理的又一个注脚。</span>

## 1 双覆盖：SU(2) 是 SO(3) 的「旋转二重身」

**$SU(2)$** 是行列式为 $1$ 的 $2 \times 2$ 酉矩阵群：

$$SU(2) = \Big\{ \begin{pmatrix} a & b \\ -\bar b & \bar a \end{pmatrix} : |a|^2 + |b|^2 = 1 \Big\}$$

**$SO(3)$** 是行列式为 $1$ 的正交 $3 \times 3$ 实矩阵群（三维旋转）。它们之间有一个 $2:1$ 的覆盖同态：<span class="marginnote">映射这样构造：把 $SU(2)$ 元素 $g$ 作用在「迹零埃尔米特矩阵」空间（基为泡利矩阵）上，$X \mapsto gXg^{-1}$ 保持迹零与行列式，从而给出 $SO(3)$ 的一个元素。核恰为 $\{\pm I\}$，故为二对一。</span>

$$1 \to \{\pm I\} \hookrightarrow SU(2) \xrightarrow{\ \Phi\ } SO(3) \to 1$$

**$SU(2)$ 双覆盖 $SO(3)$**：$\Phi$ 满、核为 $\{\pm I\}$。<span class="marginnote">物理意义：绕同一轴转 $2\pi$ 回到恒等，但在 $SU(2)$ 层面转到 $-I$。旋转 360° 后自旋 $\tfrac12$ 态变号——这正是「旋量在旋转下变号」的数学源头，也是费米子统计的几何解释。</span>

**表示的分类关系**：$SO(3)$ 的表示 = 在 $\{\pm I\}$ 上平凡的 $SU(2)$ 表示；$SU(2)$ 的表示要么来自 $SO(3)$（整数 $j$），要么是「半整数自旋」表示（$j = \tfrac12, \tfrac32, \dots$，在 $-I$ 上取 $(-1)^{2j} = -1$）。<span class="marginnote">这是量子力学「$l$ 必须取整数、$j$ 可取半整数」的群论根源：轨道角动量 $l$ 来自 $SO(3)$（整数），自旋 $j$ 来自 $SU(2)$ 的覆盖（允许半整数）。</span>

## 2 SU(2) 的不可约表示 $V_j$

$SU(2)$ 的全部不可约表示用半整数 $j$ 标记：$j = 0, \tfrac12, 1, \tfrac32, \dots$

$$V_j = \mathrm{Sym}^j(\mathbb{C}^2), \qquad \dim V_j = 2j + 1$$

其中 $V_j$ 是 $\mathbb{C}^2$ 的 $j$ 次**对称张量幂**：$V_0 = \mathbb{C}$（平凡），$V_{1/2} = \mathbb{C}^2$（基本表示，泡利矩阵），$V_1 = \mathrm{Sym}^2 \mathbb{C}^2$（三维），依此类推。<span class="marginnote">$\mathbb{C}^2$ 上的标准基写成一列；$j$ 次对称张量幂的基可写成「次数为 $j$ 的二元齐次多项式」$z_1^m z_2^{j-m}$，共 $2j+1$ 个——这就是 $V_j$ 的<strong>权基</strong>（weight basis），$m = -j, -j+1, \dots, j$ 是权量子数。</span>

**生成元与对易关系**：$su(2)$ 的生成元 $J_1, J_2, J_3$ 满足

$$[J_i, J_j] = i \varepsilon_{ijk} J_k$$

$V_j$ 上 $J_3$ 的本征值恰为 $m = -j, \dots, j$（各一次），升降算子 $J_\pm = J_1 \pm iJ_2$ 在权之间移动：$J_+ |j, m\rangle \propto |j, m+1\rangle$。<span class="marginnote">这套「权/根」结构是李代数表示论的标准骨架：$J_3$ 对角化（一个 Cartan 子代数），$J_\pm$ 是根算子。$V_j$ 的全部信息由最高权 $j$ 决定——「最高权定理」在此以最简单形式现身。</span>

## 3 张量积分解：Clebsch–Gordan 级数

表示论的「乘法」在这里开出最美的花。**Clebsch–Gordan 级数**：对 $j \ge k$，

$$V_j \otimes V_k \cong V_{j-k} \oplus V_{j-k+1} \oplus \cdots \oplus V_{j+k}$$

共 $2k+1$ 项，步长 $1$。<span class="marginnote">例：$V_{1/2} \otimes V_{1/2} \cong V_0 \oplus V_1$——两个自旋 $\tfrac12$ 合成单态（$j=0$，反对称）与三重态（$j=1$，对称）；维数 $2 \times 2 = 1 + 3$。例：$V_1 \otimes V_{1/2} \cong V_{1/2} \oplus V_{3/2}$，维数 $3 \times 2 = 2 + 4$。</span>

这就是**角动量相加法则**：两个角动量 $j_1, j_2$ 相加，可能的合成量子数为 $j = |j_1 - j_2|, |j_1 - j_2| + 1, \dots, j_1 + j_2$，且每个出现一次。<span class="marginnote">物理解释：两个子系统的复合态空间是张量积，而张量积按 CG 级数分解为「不同总角动量的块」。每个块 $V_j$ 对应总角动量 $j$ 的一族简并态——这就是「总角动量量子数」的表示论定义。</span>

把 $V_j \otimes V_k$ 的基换成各 $V_l$ 的基，基变换系数就是 **Clebsch–Gordan 系数（CG 系数）**：$\langle j_1 m_1, j_2 m_2 \mid j m \rangle$。<span class="marginnote">CG 系数是一组（通常查表的）实数，把「耦合基 $|j_1 m_1\rangle |j_2 m_2\rangle$」线性组合成「总角动量基 $|j m\rangle$」。它的正交性、递推计算与对称性是原子物理的常备工具，而其存在性本身只是「张量积分解成不可约直和」这件事。</span>

**例：$V_1 \otimes V_1 = V_0 \oplus V_1 \oplus V_2$。** 两个轨道角动量 $l = 1$ 的系统（如两个 $p$ 电子）合成：维数 $3 \times 3 = 9$，分解为 $1 + 3 + 5 = 9$。总角动量可为 $0, 1, 2$——单态、三重态、五重态。这套分解正是原子物理里 $p^2$ 组态的能级结构：$V_0$（单态）、$V_1$（三重态）、$V_2$（五重态）各对应一族简并态。<span class="marginnote">「合成态 = 张量积，总角动量 = 张量积分解出的块」——这套对应把角动量相加法则变成一个「查表」操作，而不再需要解微分方程。这也是为什么量子化学教科书里满页都是 CG 系数表。</span>

**Casimir 算子与量子数。** $V_j$ 上总角动量平方 $J^2 = J_1^2 + J_2^2 + J_3^2$ 是群二次 Casimir：它不与任何单个 $J_i$ 交换，但与所有群元交换，故在每个不可约块 $V_j$ 上是常数：

$$J^2\big|_{V_j} = j(j+1)\, \mathrm{id}$$

这就是「角动量平方本征值 $j(j+1)$」的群论来源：不可约块是 $J^2$ 的本征空间，量子数 $j$ 标记块。<span class="marginnote">把「找不可约表示」变成「对角化 Casimir」，是李代数表示论中「最高权」思想的雏形。对 $SU(2)$ 一个 Casimir 就够；对更大的紧群（如 $SU(3)$）需要多个独立 Casimir 才能完全标记不可约块——这是量子色动力学里 $SU(3)$ 量子数的数学根基。</span>

## 4 公式解析：CG 级数与维数核对

把张量积分解与维数核对写在一起：

$$\dim(V_j \otimes V_k) = (2j+1)(2k+1) = \sum_{l = |j-k|}^{j+k} (2l+1)$$

- **第一步，读左边**：张量积的维数等于两维数相乘 $(2j+1)(2k+1)$——克罗内克积矩阵的阶。
- **第二步，读求和**：右边对 $l$ 从 $|j-k|$ 到 $j+k$ 求和，每项是 $V_l$ 的维数 $2l+1$。这是一串**连续奇数**的和。
- **第三步，读核对**：$2j+1, 2j+3, \dots, 2(j+k)+1$ 共 $2k+1$ 项，用等差求和得 $\frac{2k+1}{2}\big((2(j-k)+1) + (2(j+k)+1)\big) = (2k+1)(2j+1)$，与左边相等。**维数自动闭合**——这是 CG 级数形式正确性的第一道检验。
- **第四步，读意义**：维数闭合说明「分量没丢也没多」，张量积被完全拆开。这个「维数核对」在物理里常被用来验证耦合计算是否漏项——合成态数必须等于耦合前态数。

**辨析｜易错点：** 两处高频错误。其一，**CG 级数是张量积、不是直和**：$V_j \otimes V_k$ 是张量积（维数相乘），分解后才是直和（维数相加）。把「$\otimes$ 展开为 $\oplus$」的写法 $V_j \otimes V_k = \bigoplus V_l$ 是**分解后的结果**，不是定义。其二，**$j$ 是半整数还是整数要分清**：$SO(3)$ 只允许整数 $l$，$SU(2)$ 允许半整数 $j$。把自旋 $\tfrac12$ 混进 $SO(3)$ 表示会得出矛盾——$SO(3)$ 没有 $V_{1/2}$。

## 5 应用到量子力学：球谐函数与选择定则

**球谐函数**：$SO(3)$ 在单位球面上的自然作用给出 $L^2(S^2)$ 的表示，Peter–Weyl 分解为

$$L^2(S^2) \cong \bigoplus_{l=0}^{\infty} V_l, \qquad \dim V_l = 2l+1$$

每个 $V_l$ 的基就是**球谐函数** $Y_l^m$（$m = -l, \dots, l$）。<span class="marginnote">$Y_l^m$ 满足「角动量平方」本征方程 $L^2 Y_l^m = l(l+1) Y_l^m$ 与「$z$ 分量」方程 $L_z Y_l^m = m Y_l^m$——这两条正是「$V_l$ 中 $J_3$ 权为 $m$」在函数语言里的说法。球谐函数就是 $SO(3)$ 的矩阵系数。</span>

**选择定则**：光子吸收/发射时角动量改变 $\Delta l = \pm 1$，其群论根源是张量积分解

$$V_l \otimes V_1 \cong V_{l-1} \oplus V_l \oplus V_{l+1}$$

初态 $V_l$ 与光子 $V_1$ 合成后，只含 $V_{l-1}, V_l, V_{l+1}$，**不含其它块**——所以终态角动量只能是这三个值之一。<span class="marginnote">「$\Delta l = \pm 1, 0$」这个看似经验的规则，其实由「$V_1 \otimes V_l$ 里有哪些块」完全决定。表示论把「允许跃迁」变成「查直和分解」，一劳永逸。</span>

**自旋**：$j = \tfrac12$ 时 $V_{1/2} = \mathbb{C}^2$，$J_i = \tfrac12 \sigma_i$（泡利矩阵 $\sigma_i$）。<span class="marginnote">泡利矩阵 $\sigma_1, \sigma_2, \sigma_3$ 与恒等一起张成 $2 \times 2$ 埃尔米特矩阵空间，是 $V_{1/2} \otimes V_{1/2}^* \cong V_0 \oplus V_1$ 在物理中的化身：常数部分（$V_0$）与矢量化部分（$V_1$，泡利矩阵）正好各占一块。</span>电子、夸克按 $V_{1/2}$ 变换，这是「自旋为 $\tfrac12$」的严格含义。

**矩阵系数与 Wigner–Eckart 定理（预览）。** $V_j$ 的矩阵系数 $D^j_{mn}(g) = \langle j\,m | \rho(g) | j\,n \rangle$ 构成 $L^2(SU(2))$ 的正交基（Peter–Weyl），物理里称为 **Wigner $D$-函数**；球谐函数 $Y_l^m$ 恰是 $D^l_{m0}$ 的特例。更一般地，「算符矩阵元 $\langle j' m' | T^k_q | j m \rangle$ 按 CG 系数分解」正是 **Wigner–Eckart 定理**：矩阵元 = CG 系数（几何部分） × 约化矩阵元（物理部分），几何与内容彻底分离——这是表示论「把结构从内容中剥离」的教科书级示范。<span class="marginnote">Wigner–Eckart 的直接推论：若初态总角动量 $j$、算符秩 $k$，则终态 $j'$ 只可能是 $|j-k|$ 到 $j+k$ 之间的值——选择定则又一次从「张量积分解」里冒出来。</span>

**通向洛伦兹群（预览）。** 相对论性角动量由 $SL(2,\mathbb{C})$（洛伦兹群的双覆盖）的表示支配，不可约表示 $(j_1, j_2)$ 由两个半整数标记，$\dim = (2j_1+1)(2j_2+1)$。自旋 $\tfrac12$ 场对应 $(\tfrac12, 0) \oplus (0, \tfrac12)$，四维矢量对应 $(\tfrac12, \tfrac12)$——本篇 $SU(2)$ 的语言在此无缝升级为量子场论的语言，通往第四级《量子场论》。

**$SU(2)$ 与杨图的暗线。** $SU(2)$ 的张量积分解（CG 级数）其实是杨图 Littlewood–Richardson 规则在「两行杨图」情形的化身；$V_j$ 与杨图 $(\dim = 2j+1)$ 的对应，是「紧群表示论 ↔ 对称群表示论」这条暗线的一环。下一篇对称群与杨图的内容，在这里埋下了回响。

**一张值得记住的表。** $j = 0, \tfrac12, 1, \tfrac32, 2$ 对应维数 $1, 2, 3, 4, 5$，分别刻画标量、旋量、矢量、旋量-矢量混合、二阶张量……每种「自旋-统计」类型都在 $V_j$ 家族里有位置。物理里「玻色子取整数 $j$、费米子取半整数 $j$」的规律，正是「$SO(3)$ 只留整数表示」这一数学事实的物理回声。

**权重图。** $j$ 也可看作李代数表示论里的「最高权」；$V_j$ 的权图是一条从 $-j$ 到 $j$ 的链、步长 $1$，$J_3$ 的每个本征值 $m$ 恰是权图上的一个点。这张最简单的权图，是理解一般紧群「根与权」图景的起点——$SU(3)$ 的权图是六边形，$G_2$ 的是十二边形，层层复杂。

「自旋」一词的双重含义也在这里汇合：量子数 $j$ 既标记 $SU(2)$ 的不可约表示，又标记角动量的数值——表示论的标签与物理的观测量，在 $j$ 上完全重合。

## 6 小结

- **双覆盖**：$SU(2) \twoheadrightarrow SO(3)$，核为 $\{\pm I\}$；$SO(3)$ 的表示 = $SU(2)$ 的整数 $j$ 表示，半整数 $j$ 是纯 $SU(2)$ 现象。
- **不可约表示**：$SU(2)$ 的 $V_j = \mathrm{Sym}^j \mathbb{C}^2$，$\dim V_j = 2j+1$；$J_3$ 权谱 $m = -j, \dots, j$。
- **CG 级数**：$V_j \otimes V_k = \bigoplus_{l=|j-k|}^{j+k} V_l$，即角动量相加法则；基变换系数为 CG 系数。
- 维数恒等式 $(2j+1)(2k+1) = \sum (2l+1)$ 是分解自洽性的第一道检验。
- **应用**：$L^2(S^2) = \bigoplus V_l$ 给出球谐函数；$V_l \otimes V_1$ 的分解给出 $\Delta l = \pm 1, 0$ 选择定则；$V_{1/2}$
