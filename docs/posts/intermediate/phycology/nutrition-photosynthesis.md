## 为什么从营养与能量入手

上一课我们认识了藻类的色素与贮存物——那是「硬件清单」。这一课要回答一个更根本的问题：
<strong>这些色素组装起来，到底怎样把阳光变成生物质？</strong> 藻类是地球上最古老的产氧
光合生物的后裔，光合作用既是它们的主业，也是整个地球生态系统的引擎。
<span class="marginnote">你每天烧掉的化石燃料，本质是亿万年前藻类与植物固下来的太阳能
；而今天「微藻生物燃料」产业试图把这条链路在工业尺度上重走一遍（见第5篇「生物燃料」课）。</span>
这一课同时要破除一个常见误解：<strong>藻类不是只会光合自养</strong>——它们的营养方式远比
「吃光喝水」丰富。

## 1 营养方式：从纯自养到完全异养

按碳源与能源的来源，藻类的营养方式可以排成一条谱系：

<strong>光自养（photoautotrophy）</strong>。绝大多数藻类的主业：以光为能源、以
$\ce{CO2}$ 为碳源，把无机物合成有机物。这是「标准藻类」的生活方式。

<strong>混合营养（mixotrophy）</strong>。一些藻类在光照不足或缺氮时，
<strong>同时进行光合与吸收/摄食有机营养</strong>。典型如部分甲藻：白天光合，夜里或低光时用
鞭毛摄食细菌与其他微藻；裸藻、金藻中也有捕食性类群。<span class="marginnote">混合营养
让藻类从「初级生产者」跨界成「兼性消费者」——在寡营养水域，摄食带来的氮磷可能比光合本身更解渴，这也是赤潮甲
藻能在寡营养外海暴发的关键能力之一。</span>

<strong>异养（heterotrophy）</strong>。少数藻类完全或几乎完全丢掉光合能力，靠
<strong>腐生（吸收溶解有机物）</strong>或<strong>寄生</strong>过活。例如某些无色裸藻
靠渗透吸收有机碳，丝藻中的寄生种类附着在其他藻体上吸取养分。它们仍被算作藻类，是因为保留了光合祖先的形态
与遗传印记。

<strong>辨析｜易错点：</strong> 「藻类是自养生物」这句话在大多数场合成立，但
<strong>不是所有藻类都自养</strong>。考试或写作时若强调普适性，请写「多数藻类以光自养为主，
兼具混合营养甚至异养」，避免绝对化。

这套营养谱系有一个实用推论：<strong>判断一个水体里藻类「吃」什么，能反推它的营养状态</strong>
——富有机质水体里裸藻、隐藻多，寡营养清水里金藻多；而混合营养藻类的存在，提醒我们在建模水体能量流时不能
把藻类一律当作纯生产者。这份「营养弹性」在后续门类课（裸藻、甲藻）里还会反复出现。

## 2 光合作用：把光子变成糖

藻类的光合作用在机制上与高等植物高度一致，都在叶绿体内分两阶段进行。

<strong>光反应</strong>发生在类囊体膜上：叶绿素 a 吸收光子后激发电子，经光系统 II（PSII）
→ 电子传递链 → 光系统 I（PSI）的传递，同时泵出质子、建立质子梯度，驱动
<strong>ATP 合酶</strong>合成 ATP；电子最终交给 $\ce{NADP+}$ 生成 $\ce{NADPH}$。
水被裂解释放电子、质子与氧气——<strong>氧气的来源是水，不是二氧化碳</strong>，这个常识性反转
是光合作用史上有名的「希尔反应」结论。

<strong>暗反应（卡尔文循环）</strong>发生在叶绿体基质中：利用 ATP 与 NADPH 把
$\ce{CO2}$ 固定进有机物。RuBisCO 催化 $\ce{CO2}$ 与 RuBP 结合，生成两分子三碳
化合物（3-PGA），再经还原与再生，净产出三碳糖。总反应式：

$$\ce{6CO2 + 6H2O ->[光照] C6H12O6 + 6O2}$$

这是中学化学就写过的式子的生物学翻版。但藻类面对的环境有一个高等植物少有的难题：
<strong>水里的二氧化碳远比空气稀薄</strong>，于是藻类演化出了碳浓缩机制。

## 3 碳浓缩机制：淡水与海洋里的「吸碳泵」

水中溶解 $\ce{CO2}$ 浓度低、扩散慢，单靠 RuBisCO 那点低速与低亲和力，光合会饿肚子。许
多藻类演化出<strong>碳浓缩机制（carbon concentrating mechanism, CCM）</strong>：
主动把无机碳（$\ce{CO2}$ 与 $\ce{HCO3^-}$）泵进细胞，再用碳酸酐酶（carbonic
anhydrase, CA）在 RuBisCO 附近把它释放成 $\ce{CO2}$，使酶活性位点处的 $\ce{CO2}$
浓度远高于水体。<span class="marginnote">CCM 是藻类「逆境生存」的范本：蓝藻用羧酶体
（carboxysome）、绿藻用蛋白核、硅藻与褐藻用胞质酶库——殊途同归，都是为了同一件事：让 RuBisCO
吃饱二氧化碳。</span>

CCM 的存在带来一个重要的生态推论：许多藻类在检测藻华时呈现「<strong>溶解无机碳限制</strong>
」——水华爆发到后期，碳源被消耗，光合速率由碳而非光决定（详见第5篇「藻华」课）。

## 4 公式解析：光响应曲线

<strong>描述「光合速率随光强如何变化」的曲线，是藻类生理学的第一张标准图。</strong> 常用非直角
双曲线或矩形双曲线模型拟合，后者写作：

$$P = P_{\max}\cdot\frac{I}{K_I + I} - R$$

对这条式子做四步拆解：

- <strong>第一步，$P$ 是净光合速率</strong>（单位时间、单位叶绿素或单位细胞的 $\ce{O2}$
释放 / $\ce{CO2}$ 吸收），纵轴读的就是它。
- <strong>第二步，$P_{\max}$ 是最大总光合速率</strong>：当光强 $I$ 极大时，
$\dfrac{I}{K_I + I} \to 1$，总光合趋于饱和值 $P_{\max}$。光合再强也受 RuBisCO 与
电子传递链的物理上限约束，这正是「光饱和」的含义。
- <strong>第三步，$K_I$ 是半饱和光强</strong>：当 $I = K_I$ 时，总光合恰为 $P_{\max}/2$。
$K_I$ 越小，说明藻类对弱光的利用效率越高——<strong>深水/底层藻类的 $K_I$ 通常较小</strong>
，这是对低光环境的适应性读数。
- <strong>第四步，减去呼吸项 $R$</strong>：细胞同时还在呼吸耗氧，净光合 = 总光合 − 呼吸。当
$P=0$ 时对应的光强叫<strong>补偿点（compensation point）</strong>，此时光合刚好抵掉呼吸；
低于补偿点，藻类入不敷出，无法长期存活。<span class="marginnote">补偿点与半饱和光强是一对
容易混淆的量：前者是「盈亏平衡的光强」，后者是「达到半饱和的光强」；前者跟呼吸快慢有关，后者跟光系统效率有
关。做题时先问自己在读哪个。</span>

## 5 光合作用的测定：把看不见的过程数字化

光合作用看不见摸不着，藻类学家靠什么「测量」它？答案是抓住它两头的化学结果——放氧与吸碳。

<strong>放氧法（oxygen evolution）</strong>。光合产氧、呼吸耗氧，用氧电极或瓦氏呼吸计测密闭
体系中溶氧变化，即可算净光合。若再测暗中的呼吸耗氧，把净光合加回呼吸，就得到
<strong>总光合（gross photosynthesis）</strong>——这是最经典的测定路线，也是第 4 节光响
应曲线里 $P = P_g - R$ 的实验来源。

<strong>$\ce{CO2}$ 吸收法</strong>。用红外气体分析仪测 $\ce{CO2}$ 浓度变化，或在培养液中
加 $^{14}\ce{C}$ 标记的碳酸氢盐，看放射性如何进入有机碳——<strong>$^{14}\ce{C}$ 示踪法
</strong>是测初级生产力的经典手段，把「固定了多少碳」直接变成可数的放射性计数。
<span class="marginnote">$^{14}\ce{C}$ 法测出的就是「净固碳」的近似，因为同位素会同时被呼吸
与排泄损失一部分；野外初级生产力调查至今仍在用这个「老办法」，因为它简单、灵敏、可批量。</span>

<strong>叶绿素荧光（chlorophyll fluorescence）</strong>。现代生态学的宠儿。叶绿素吸收光能后，
一部分用于光合、一部分以热耗散、一部分重新发出荧光——三者的比例由<strong>调制荧光仪（PAM）</strong>
测定。光能越接近饱和，荧光越低，因此荧光可以当作「光合活跃度」的即时探针。
<strong>实际光量子效率（$\Phi_{PSII}$）</strong>与<strong>最大量子效率（$F_v/F_m$）</strong>
两个指标，被用来快速评估藻类的健康与胁迫状态。<span class="marginnote">PAM 荧光仪是目前藻类
生态学的「标配仪表」：不用破坏样品，探头一照几秒钟就出读数。现场测到的 $F_v/F_m$ 若从健康值（约
0.6–0.7）掉下来，多半是营养限制或光抑制——藻华暴发前的「预警信号」常先出现在荧光指标上。</span>

<strong>遥感反演</strong>。从卫星看海洋与湖泊：叶绿素 a 在蓝绿波段有特征吸收，卫星传感器据此反演
水面叶绿素浓度，从而绘制初级生产力的宏观分布图。地面测定解决「点」，遥感解决「面」，两者结合才构成完整
的监测体系。

<strong>辨析｜易错点：</strong> 放氧法与 $^{14}\ce{C}$ 法测的是「净」还是「总」容易混淆——放
氧法直接测净产氧，需加暗呼吸校正得总光合；$^{14}\ce{C}$ 法更接近净固碳。荧光测的则是光化学效率，
不是直接的碳固定量。三种方法各有口径，写结论时必须注明用的是哪个口径。

## 6 小结

- 藻类营养方式呈谱系分布：<strong>光自养为主，混合营养与异养为辅</strong>，不能把藻类一概说成自养。
- 光合分<strong>光反应</strong>（类囊体膜上产 ATP/NADPH，水裂解释氧）与
<strong>暗反应</strong>（基质中卡尔文循环固碳）；$\ce{O2}$ 来自水而非 $\ce{CO2}$。
- 水环境低 $\ce{CO2}$ 催生了<strong>碳浓缩机制（CCM）</strong>，通过主动泵碳 + 碳酸酐酶让
RuBisCO 吃饱碳。
- <strong>光响应曲线</strong> $P = P_{\max}\cdot\dfrac{I}{K_I + I} - R$ 是藻类生理学的
标准工具：$K_I$ 反映弱光适应，补偿点反映盈亏平衡。
- 测定手段四件套：放氧法、$^{14}\ce{C}$
