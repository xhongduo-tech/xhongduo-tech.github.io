# 藻类学

藻类学是植物学的重要分支学科，系统研究藻类的形态结构、分类演化、繁殖生殖、生态分布及其与人类的关系，涵盖淡水藻与海藻、藻华生态、藻类生物技术等核心领域，是连接植物学、生态学与生物技术应用的桥梁学科。对标权威教材按章节逐节写成博文，学完一个学科 = 写完该学科权威教材对应的全部博文。

## 对标教材

- Robert Edward Lee, *Phycology* (5th ed., Cambridge University Press)
- 《藻类学》上海科学技术出版社
