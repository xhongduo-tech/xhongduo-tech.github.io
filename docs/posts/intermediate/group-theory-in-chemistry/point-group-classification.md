## 为什么从点群分类开始

上一节我们把水分子、氨分子、苯环的对称操作逐个认了出来。可分子千千万万，如果每个分子都要重新数一遍操作，群论就毫无威力。点群分类的妙处在于：**形状千差万别的分子，对称类型却只有有限多种**。就像动物分类把亿万生物归入门纲目科属种，点群把分子归入一张有限的名表——一旦查清分子属于哪个点群，后面所有群论结论（能否成键、哪个振动有红外活性）都能直接查特征标表得到。<span class="marginnote">有限种类的直觉来自一个深刻事实：三维空间里，绕一点的全部有限旋转对称组合只有可数个类型。数学上点群是有限群，化学中常见的不超过几十种。</span>

这一节要解决两件事：**点群的名字怎么读**，以及**怎么把任意分子准确归入某个点群**。判断流程是本章的核心技能，请务必亲手对着分子模型走几遍。

## 1 点群：分子的对称指纹

**点群（point group）**：分子全部对称操作的集合，连同复合运算构成的群。因为所有对称元素交于一点（见第 1 篇），故称「点」群。

**群的阶（order）** $h$：群中对称操作的总数。<span class="marginnote">例：水的点群 $C_{2v}$ 有四个操作 $E, C_2, \sigma_v, \sigma_v'$，阶 $h = 4$；氨的 $C_{3v}$ 有六个操作，阶 $h = 6$。操作数越多，分子对称性越高。</span>

点群的记号分两套：化学常用 **Schoenflies 记号**，晶体学常用 **Hermann–Mauguin 记号**。分子点群几乎全用 Schoenflies 记号；Hermann–Mauguin 用于空间群，见本专题第 11 篇。

## 2 Schoenflies 记号：点群的名字怎么读

点群按「含有哪些对称元素」命名，规则可以拆成几族：

**无轴群**：只有镜面或反演中心。$C_s$（仅一个镜面）、$C_i$（仅反演中心）、$C_1$（仅 $E$，无对称性）。

**旋转群**：以 $C_n$ 为唯一旋转轴。$C_n$（仅 $C_n$ 轴）、$C_{nv}$（$C_n$ 轴 + $n$ 个竖直镜面 $\sigma_v$）、$C_{nh}$（$C_n$ 轴 + 水平镜面 $\sigma_h$）。<span class="marginnote">水是 $C_{2v}$，氨是 $C_{3v}$，直线极性分子如 $\ce{HCl}$ 是 $C_{\infty v}$。判断口诀：$n$ 是主轴阶数，$v$ 表示有竖直镜面，$h$ 表示有水平镜面。</span>

**二面群**：$C_n$ 轴外还有 $n$ 条垂直于它的 $C_2$ 轴。$D_n$（只有 $C_n$ + 垂直 $C_2$）、$D_{nh}$（再加 $\sigma_h$）、$D_{nd}$（再加 $n$ 个二面镜面 $\sigma_d$）。<span class="marginnote">乙烯是 $D_{2h}$，苯是 $D_{6h}$，乙烷交叉构象是 $D_{3d}$、重叠构象是 $D_{3h}$。</span>

**立方群**：有多个高阶轴（$C_3, C_4$ 或 $C_5$）。正四面体分子（$\ce{CH4}$）是 $T_d$，正八面体分子（$\ce{SF6}$）是 $O_h$，二十面体分子（如 $B_{12}$ 簇）是 $I_h$。

**线性群**：$C_{\infty v}$（无对称中心的直线分子）与 $D_{\infty h}$（有对称中心的直线分子）。<span class="marginnote">$\ce{CO2}$ 是 $D_{\infty h}$，$\ce{HCN}$ 是 $C_{\infty v}$。区别就在有没有反演中心 $i$。</span>

## 3 公式解析：点群判断决策树

给分子定点的过程可以浓缩成一条从粗到细的判断链。设分子共有 $N$ 个原子，先用肉眼找最高阶对称元素：

$$
\text{分子} \xrightarrow{\text{特殊形状?}} T_d / O_h / I_h \xrightarrow{\text{直线?}} C_{\infty v} / D_{\infty h} \xrightarrow{\text{主轴?}} \cdots
$$

对非特殊、非直线的分子，按下述顺序逐层判断：

- **第一步，找主轴**：确定最高阶旋转轴 $C_n$。没有 $C_n$ 轴的分子归入无轴群 $C_s, C_i, C_1$。
- **第二步，查垂直 $C_2$**：主轴之外是否有 $n$ 条垂直的 $C_2$ 轴？有则进入 $D$ 族，没有则留在 $C$ 族。
- **第三步，查 $\sigma_h$**：有没有垂直于主轴的镜面？有则在名字后加 $h$（如 $D_{3h}$、$C_{3h}$）。
- **第四步，查 $\sigma_v / \sigma_d$**：有没有含主轴的竖直镜面？有则 $C_{nv}$ 或 $D_{nd}$；$D$ 族没有 $\sigma_h$ 时，有 $\sigma_d$ 就归 $D_{nd}$。
- **第五步，查象转轴**：以上都判不出时，检查 $S_n$。甲烷这类有 $S_4$ 却无 $C_4$ 的分子归 $T_d$ 一族。

分四步拆解这条链背后的逻辑：

- **第一步，特殊形状优先**：正四面体、正八面体、二十面体有多个高阶轴，直觉上「太对称」，直接认领 $T_d, O_h, I_h$，不必再走下面的细规则。
- **第二步，线性分子单独处理**：直线分子有无穷阶轴，记 $C_\infty$，不可能落入有限阶分类；只需看有没有 $i$。
- **第三步，$C$ 与 $D$ 是分水岭**：有没有垂直 $C_2$ 轴决定了分子是「转起来像风车」（$D$）还是「只有一根轴」（$C$），这一步最值得先判断。
- **第四步，$h$ 与 $v$ 补齐后缀**：$\sigma_h$ 与 $\sigma_v$ 加不加到名字里，取决于分子有没有这类镜面；没有镜面就停在 $C_n$、$D_n$。

**辨析｜易错点：主轴的选取。** 主轴是「最高阶」旋转轴。若分子有多个同阶轴（如 $D_{2h}$ 的三条互相垂直 $C_2$），任选其一为主轴，其余按「垂直 $C_2$」处理；但 $\sigma_v$ 与 $\sigma_d$ 的命名以所选主轴为参照——换主轴会改变后缀写法，点群本身不变。判断时先问「最高阶轴是哪根」，再问「垂直它的 $C_2$ 有几条」。

## 4 点群判断自查表

| 分子 | 主轴 | 垂直 $C_2$ | $\sigma_h$ | $\sigma_v/\sigma_d$ | 点群 |
| --- | --- | --- | --- | --- | --- |
| $\ce{H2O}$ | $C_2$ | 无 | 无 | 2 个 $\sigma_v$ | $C_{2v}$ |
| $\ce{NH3}$ | $C_3$ | 无 | 无 | 3 个 $\sigma_v$ | $C_{3v}$ |
| $\ce{CO2}$ | $C_\infty$ | 无穷 | 有 | — | $D_{\infty h}$ |
| $\ce{HCN}$ | $C_\infty$ | 无 | 无 | 无穷 $\sigma_v$ | $C_{\infty v}$ |
| $\ce{C6H6}$ | $C_6$ | 有 | 有 | — | $D_{6h}$ |
| $\ce{C2H4}$ | $C_2$ | 有 | 有 | — | $D_{2h}$ |
| $\ce{CH4}$ | 无 $C_4$，有 $S_4$ | — | — | — | $T_d$ |
| $\ce{SF6}$ | $C_4$（多个） | 有 | 有 | — | $O_h$ |

<span class="marginnote">易错点：判断点群必须用「<strong>分子平衡构型</strong>」，不能用某个瞬间的振动构型。乙烷的交叉与重叠构象分属 $D_{3d}$ 与 $D_{3h}$，就是构象不同、点群不同的经典例子。</span>

## 5 对称性高低的含义

对称性高低直接预告分子的物理性质：

**是否有偶极矩**：分子有偶极矩，当且仅当它不属于任何一个「所有操作都把它送到自身」的对称性太高的点群。$C_{2v}, C_{3v}, C_{\infty v}$ 可以有偶极矩；$D_{2h}, D_{6h}, O_h, T_d, D_{\infty h}$ 因存在把分子翻转的操作，偶极矩必为零。<span class="marginnote">判断偶极矩的口诀：<strong>有 $i$、或有垂直于主轴且使分子翻转的 $\sigma_h$、或有多根 $C_2$ 轴互相垂直的对称性，偶极矩必为零</strong>。苯没有偶极矩，正因 $D_{6h}$ 里有反演中心。</span>
**是否有手性**：一个分子是手性的（不能与其镜像重合），当且仅当它的点群**不含 $S_n$ 象转轴**。$C_1, C_2, D_2$ 都是手性点群；$C_s, C_i, S_n, C_{nv}, D_{nh}$ 都含镜面或象转轴，是非手性的。

手性分子必须属于**只含旋转操作**的点群（$C_n, D_n$），因为镜面、反演、象转轴任一存在都会提供「镜像重合」的可能。连着一个手性碳的分子通常整体只有 $C_1$ 对称；而 $C_2$ 点群（如某些联苯衍生物）虽含旋转轴仍可手性——旋光实验与群论结论在此互为印证。<span class="marginnote">化学里「旋光性」与「点群不含 $S_n$」是同一件事的两种说法：实验上测旋光，理论上查点群。教材《立体化学》里手性碳的判据，在群论里只是「有没有 $S_n$」的特例。</span>

## 6 常见分子点群速查

把前几节的规则汇总成一张速查表，练习时先查表对答案，再回头走决策树：

| 分子 | 形状 | 点群 | 判据要点 |
| --- | --- | --- | --- |
| $\ce{H2O}$ | V 形 | $C_{2v}$ | $C_2$ + 两个 $\sigma_v$ |
| $\ce{NH3}$ | 三角锥 | $C_{3v}$ | $C_3$ + 三个 $\sigma_v$ |
| $\ce{BF3}$ | 平面三角形 | $D_{3h}$ | $C_3$ + 垂直 $C_2$ + $\sigma_h$ |
| $\ce{CH4}$ | 正四面体 | $T_d$ | 无 $C_4$，有 $S_4$ |
| $\ce{SF6}$ | 正八面体 | $O_h$ | 三个 $C_4$ + $i$ |
| $\ce{C6H6}$ | 平面六角 | $D_{6h}$ | $C_6$ + 垂直 $C_2$ + $\sigma_h$ + $i$ |
| $\ce{C2H4}$ | 平面 | $D_{2h}$ | 三根垂直 $C_2$ + $i$ |
| $\ce{反-N2F2}$ | 平面 | $C_{2h}$ | $C_2$ + $\sigma_h$ + $i$ |
| $\ce{PCl5}$ | 三角双锥 | $D_{3h}$ | $C_3$ + 垂直 $C_2$ + $\sigma_h$ |
| $\ce{S8}$ | 皇冠 | $D_{4d}$ | $C_4$ + 垂直 $C_2$ + $\sigma_d$ |

<span class="marginnote">速查表的价值在于建立「形状 → 点群」的直觉；真正考试或研究中遇到新分子，仍要回到第 3 节的决策树逐层判断。同一形状可能对应不同点群（如 $T_d$ 与 $O_h$ 都有「四面体」外观），查表不能替代判断。</span>

## 7 小结

- **点群**是分子全部对称操作构成的群，阶 $h$ 是操作总数；命名用 Schoenflies 记号。
- 点群分族：**无轴群（$C_s, C_i, C_1$）、旋转群（$C_n, C_{nv}, C_{nh}$）、二面群（$D_n, D_{nh}, D_{nd}$）、立方群（$T_d, O_h, I_h$）、线性群（$C_{\infty v}, D_{\infty h}$）**。
- 判断决策树按「特殊形状 → 线性 → 主轴 → 垂直 $C_2$ → $\sigma_h$ → $\sigma_v/\sigma_d$」逐层下钻。
- 对称性预告性质：**含反转类对称的操作则无偶极矩；含 $S_n$
