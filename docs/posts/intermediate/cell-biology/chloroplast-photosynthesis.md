## 为什么从叶绿体与光合作用开始

上一节线粒体把有机物氧化成水与二氧化碳，这一节把反应翻过来：**叶绿体（chloroplast）**用光能把二氧化碳和水还原成糖，并释放氧气。
这两套反应构成地球生命能量的闭环——光合作用把太阳能固定进有机物，呼吸作用再把它释放出来。
理解叶绿体，不只是理解植物学，而是理解**整个生物圈的能源从哪里来**：我们烧的煤、吃的粮食、呼吸的氧气，追根溯源都是叶绿体的产物。

上一节的线粒体是「把有机物烧成能量」，这一节的叶绿体是「把光能变成有机物」——它们是生物圈能量的「一进一出」：**光合作用把太阳能存进有机物，呼吸作用再把它取出来**。
理解了这两套机制，你就掌握了地球生命能量的完整闭环。
可以说，叶绿体是「线粒体的镜像」——同样的双层膜、同样的内共生起源（蓝细菌）、同样用化学渗透造 ATP，只是方向相反、能量来源不同。

学习光合作用，先破除一个「顺理成章」的误区：**光合作用 ≠ 「植物吃掉光」**。它是一个精密的流水线，分两个车间：

- **光反应**（类囊体膜）：用光能拆水、产氧、生成 ATP 与 NADPH——**这是「取能」车间**；
- **卡尔文循环**（基质）：用 ATP 与 NADPH 固定 CO₂、生成糖——**这是「储能」车间**。

两个车间靠「电子与质子」联系：光反应把光能转成「还原力（NADPH）+ 能量（ATP）」，卡尔文循环再把它们花掉去还原 CO₂。
**光反应「充电」，卡尔文循环「耗电」**。
<span class="marginnote">一个最容易误解的点：光合作用放出的氧气不是来自 CO₂，而是来自<strong>水</strong>——光反应拆开 H₂O 放出 O₂，卡尔文循环只是把 CO₂ 的碳「装进」糖里。
用同位素标记实验（范尼尔）才确认了这一点。
「氧从水来」这条，几乎每次考试都会考到。
</span>

本节还有一处「物理-化学-生物」三合一的漂亮计算：**一个光子的能量 $E = hc/\lambda$**，红光光子约 175 kJ/mol。
它把「叶绿素为什么吸收红光和蓝光、反射绿光」解释得清清楚楚——植物是绿的，不是「喜欢绿色」，而是「用不上绿光」。
学完本节，你应当能同时回答三个问题：氧从哪来？
碳从哪进？为什么叶子是绿的？

## 1 结构：光反应的车间

叶绿体与线粒体结构上高度相似，都是内共生来源的双层膜细胞器，但叶绿体多了一套独有的膜系统：

**外膜与内膜**：包住整个细胞器；
**类囊体（thylakoid）**：内膜系统折叠成的扁平囊，堆叠成**基粒（granum）**。类囊体膜上嵌着光合作用的全部装置——光系统、电子传递链、ATP 合酶；
**基质（stroma）**：类囊体周围的流体，含卡尔文循环的酶与叶绿体 DNA。

类囊体膜把空间分成**类囊体腔（lumen）**与**基质**，正如内膜把空间分成膜间隙与基质——**质子梯度的建立同样依赖膜的封闭性**，化学渗透在这里再次登场。
<span class="marginnote">叶绿体的「账本」和线粒体正好互补：线粒体内膜把质子泵到膜间隙（高能侧在外），叶绿体类囊体膜把质子泵到类囊体腔内（高能侧在内），方向相反，但原理完全一致——质子回流驱动同一个 ATP 合酶。
</span>

## 2 光反应：把光能变成 ATP 与 NADPH

**光反应（light reactions）**发生在类囊体膜上，把光能转化为化学能，产物是 ATP 与 NADPH（外加氧气）。
主角是两套光系统：

**光系统 II（PSII）**：吸收红光（约 680 nm）后，激发电子交给电子传递链；失去电子的叶绿素从水分子夺取电子——**水被裂解，放出氧气**：$\ce{2H2O -> O2 + 4H+ + 4e-}$；
电子沿类囊体膜上的传递链（质体醌、细胞色素 b₆f 复合体）下行，能量用于把质子泵入类囊体腔；
**光系统 I（PSI）**：吸收远红光（约 700 nm），把电子再度激发，最终交给 **NADP⁺** 还原成 **NADPH**；
质子经 ATP 合酶回流，合成 ATP。<span class="marginnote">范尼尔（van Niel）用同位素实验证明了一个反直觉的事实：光合作用放出的氧气来自<strong>水</strong>，而不是二氧化碳。他用 $\ce{^{18}O}$ 标记的 $H_2^{18}O$ 培养藻类，放出的氧气带 $\ce{^{18}O}$；标记 $\ce{CO2}$ 则不带。光反应「拆水解氧、固碳产糖」的分工由此确立。</span>

这个「电子先上 PSII 再上 PSI」的路径叫 **Z 型方案（Z-scheme）**，因为电子的能量轨迹画出来像一个 Z 字。

## 3 暗反应（卡尔文循环）：把 CO₂ 变成糖

**卡尔文循环（Calvin cycle）**发生在基质，用光反应提供的 ATP 与 NADPH，把二氧化碳固定成三碳糖（G3P）。三步：

1. **羧化（carbon fixation）**：$\ce{CO2}$ 与核酮糖-1,5-二磷酸（RuBP）在 **RuBisCO** 催化下结合，裂解成两分子 3-磷酸甘油酸（3-PGA）——这是大气碳进入生物圈的入口；
2. **还原（reduction）**：3-PGA 用 ATP 与 NADPH 还原成 G3P（三碳糖磷酸）；
3. **再生（regeneration）**：大部分 G3P 经一系列反应再生成 RuBP，循环继续；少部分净产出被用来合成葡萄糖等。<span class="marginnote">RuBisCO 是地球上最丰富的蛋白质——因为它是固碳的唯一主要途径，且效率低、还会「开小差」。它偶尔把 $\ce{O2}$ 当成 $\ce{CO2}$ 结合，产生光呼吸（photorespiration），浪费能量。C4 植物（玉米、甘蔗）用空间分隔来避开光呼吸，CAM 植物（仙人掌）用时间分隔——同一种酶，逼出了三类适应策略。</span>

总反应写作 $\ce{6CO2 + 6H2O + 光能 -> C6H12O6 + 6O2}$，但**要清醒：氧来自光反应的水裂解，碳来自卡尔文循环的二氧化碳固定**，两件事发生在不同膜系统、由不同反应驱动。

## 4 公式解析：一个光子的能量

光合作用的起点是光子。单个光子的能量由**普朗克关系**给出：

$$E = h\nu = \frac{hc}{\lambda}$$

- **$E$**：单个光子能量（J）；**$h$**：普朗克常数 $6.626\times10^{-34}$ J·s；
- **$c$**：光速 $3\times10^{8}$ m/s；**$\lambda$**：波长（m）；
- 对红光 $\lambda = 680$ nm：$E = \dfrac{6.626\times10^{-34} \times 3\times10^{8}}{680\times10^{-9}} \approx 2.9\times10^{-19}$ J。

换算成摩尔能量：乘以阿伏伽德罗常数 $N_A \approx 6.02\times10^{23}$，得约 **175 kJ/mol**。
这告诉我们两件事：

- 一个红光光子携带的能量，比合成一个 ATP 所需（约 30–50 kJ/mol）多得多，但电子传递不是「一击即中」——它要把几个光子的能量**逐级积聚**成质子梯度和 NADPH；
- 蓝光波长更短（约 450 nm），每个光子能量更高（约 265 kJ/mol），但光合的量子效率却受限于反应中心的化学——**光系统吸收蓝光和红光都行，绿光却被反射，所以叶子看起来是绿的**。<span class="marginnote">「为什么植物是绿色」是最容易被忽视的问题：叶绿素吸收红光与蓝光、反射绿光，是因为它只需要这两段光谱的能量就足以驱动电子跃迁，多吸收绿光反而不划算。地球植物的绿，是光化学「够用就好」的结果。</span>

## 5 叶绿体与线粒体的镜像

把前两节放在一起，能看到一个漂亮的**对称结构**：

| 维度 | 线粒体 | 叶绿体 |
| --- | --- | --- |
| 能量方向 | 有机物 → ATP（放能） | 光 → ATP + NADPH（吸能） |
| 内共生祖先 | α-变形菌 | 蓝细菌 |
| 主要膜系统 | 内膜嵴 | 类囊体膜 |
| 质子泵方向 | 泵向膜间隙 | 泵向类囊体腔 |
| 终产物 | ATP、$\ce{CO2}$、水 | ATP、NADPH、$\ce{O2}$ |

两者都用**化学渗透**这一套核心机器，只是方向与供能相反。
**这套机器的普适性，是内共生学说之外、细胞能量学的又一条主线**：只要隔开两层空间，就能攒下梯度，梯度就是能量。

**易错点｜「暗反应就是黑暗中进行的反应」是误解**：卡尔文循环的酶不直接需要光，但它们需要的 ATP 与 NADPH 只能在光下产生，所以**实际的光合作用主要在白天进行**。
「暗反应」的「暗」只是「不直接依赖光子」，不是「在黑暗中运行」。

## 6 光合作用的适应策略与全球碳循环

光合作用不是只有一套流程——不同环境压力下，植物演化出多种「变体」，而它们在宏观上共同驱动着全球碳循环：

**C3、C4 与 CAM 三种固碳策略**：**C3 植物**（水稻、小麦）直接由 RuBisCO 固定 CO₂，但 RuBisCO「分心」结合 O₂ 的光呼吸会浪费能量；**C4 植物**（玉米、甘蔗）先在叶肉细胞把 CO₂ 固定成四碳化合物，再运到束鞘细胞释放 CO₂「喂」RuBisCO，从而**避开光呼吸**、在高温强光下效率更高；**CAM 植物**（仙人掌、菠萝）则在夜间开气孔吸 CO₂、白天关闭气孔固碳，把「时间」当隔离——适应干旱。<span class="marginnote">C4 与 CAM 是「空间隔离」与「时间隔离」两种解法：C4 用两个细胞分工，CAM 用昼夜分工。同样一个「RuBisCO 爱出错」的问题，植物给出了两套工程学答案——这提醒我们，进化没有唯一解，只有适配解。</span>
**RuBisCO 的低效是全球固碳的瓶颈**：RuBisCO 催化速率慢（每秒约 3 个 CO₂），所以细胞要用巨大的量来补偿——它是地球最丰富的蛋白质。**改造 RuBisCO、提高固碳效率，是农业增产与气候工程的热门课题**。
**全球初级生产力**：地球每年光合作用固定的碳约 $10^{11}$–$10^{12}$ 吨。海洋里的**浮游植物（藻类与蓝细菌）**贡献了约一半的初级生产力——它们生活在光照有限的表层，却是海洋食物链与碳汇的基础。<span class="marginnote">「一半的氧气来自海洋浮游植物」是常被引用的近似：陆地上森林与草原，海洋里浮游植物，各撑起半壁生物圈。藻华（浮游植物暴发）既为海洋供碳，也能在近海造成缺氧区——光合作用是地球碳循环的引擎，也是环境变化的敏感指示器。</span>
- **光合作用与气候**：光合作用吸收 CO₂、呼吸作用释放 CO₂，二者平衡决定了大气 CO₂ 的长期水平；人类燃烧化石燃料打破了这个平衡，植物碳汇不足以抵消——**理解光合作用，是理解全球变暖的第一块基石**。

**易错点｜「C3 植物比 C4 植物低等」是误区**：C3 是祖先策略，C4/CAM 是**在特定环境（高温、强光、干旱）下的适应性升级**。
在凉爽湿润环境里 C3 完全够用——水稻、小麦养活了大半人类，它们就是 C3。
策略没有高下，只有适配。

## 7 小结

- 叶绿体含**类囊体**（堆成基粒）与**基质**：光反应在类囊体膜，卡尔文循环在基质。
- **光反应**：PSII 裂解水放氧 → 电子经传递链泵质子 → PSI 还原 NADP⁺ → 质子回流合成 ATP。
- **卡尔文循环**三步：**羧化**（RuBisCO 固碳）、**还原**（ATP/NADPH 耗能）、**再生**（RuBP 重建）。
- 光子能量 $E = hc/\lambda$：红光约 175 kJ/mol；叶子是绿的因为叶绿素反射绿光。
- 叶绿体与线粒体是**能量镜像**：同一套化学渗透机器，反向运行。
