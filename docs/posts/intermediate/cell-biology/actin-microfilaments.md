## 为什么从肌动蛋白与微丝开始

微管解决了「长距离运输与分裂」，而细胞的**运动**——爬行、变形、吞噬、肌肉收缩——几乎都靠**肌动蛋白微丝（actin filament）**。
肌动蛋白是真核细胞里最丰富的蛋白质之一，它组成的微丝直径只有约 7 nm，却是细胞皮层（cell cortex）的骨架、细胞前沿推进的推土机、以及肌肉收缩的滑动机构。
理解微丝，就理解了「细胞为什么会动」——从伤口愈合时细胞的爬行，到免疫细胞追杀细菌，再到每一次心跳，都是微丝在驱动。

如果说微管是细胞的「高铁轨道」，那么**肌动蛋白微丝**就是细胞的「肌肉与手脚」：它驱动细胞爬行、吞噬、收缩，也是肌肉收缩的分子基础。
肌动蛋白是真核细胞里最丰富的蛋白质之一，一个细胞里可有数十万到数百万个肌动蛋白分子——它既是结构蛋白，也是「发动机」。

学习微丝，核心是理解它的**动态聚合**：单体 G-actin 聚合成纤维 F-actin，聚合的开关由**临界浓度（Cc）**决定。
这个「临界浓度」概念贯穿整节，也贯穿微管与中间丝的对比——**细胞骨架纤维都是「浓度驱动的可逆聚合物」**，与膜的「自组装」不同，骨架纤维能拆能建、可快可慢，正是这种可逆性支撑了细胞运动。
<span class="marginnote">一个值得玩味的对照：膜靠「疏水效应自组装」、骨架靠「浓度驱动聚合」、DNA 靠「碱基配对」——生命的三大「结构体系」，各有各的组装规则。
学细胞生物学，常在这三层「组装逻辑」之间切换视角，这正是「分子如何变成结构」的总主题。
</span>

微丝还有个与微管共同、却又不同的「极性故事」：微丝也有 + 端（刺端）与 − 端（尖端），但它的特殊本领是**踏车（treadmilling）**——在合适浓度下，亚基在刺端不断加上、在尖端不断掉下，微丝整体不移动，亚基却像传送带一样流过。
这套「原地踏步却高速周转」的机制，是细胞前沿推进的分子引擎：前缘不断加长顶出，后端不断拆短回收，细胞就这么「自己把自己推着走」。

本节把「肌动蛋白动力学」与「细胞运动」两条线并着讲：前半讲聚合、临界浓度、踏车（机制），后半讲肌动蛋白结合蛋白、迁移与肌球蛋白（应用）。
学完后你应能用一句话回答：**为什么细胞能爬？
——因为微丝在前缘「长」、在后方「拆」，肌球蛋白在后面「拉」**。

## 1 肌动蛋白的聚合：G-actin 到 F-actin

肌动蛋白以两种形态存在：

- **G-肌动蛋白（G-actin，球状）**：单体的肌动蛋白，约 43 kDa；
- **F-肌动蛋白（F-actin，纤维状）**：G-actin 头尾相接聚合成的双螺旋微丝。

微丝有**极性**：生长快的一端叫**刺端（barbed end，+ 端）**，慢的一端叫**尖端（pointed end，− 端）**——名字来自肌球蛋白 S1 片段结合后箭头般的装饰外观。
<span class="marginnote">用肌球蛋白 S1 片段「装饰」微丝，在电镜下看起来像一支支箭——箭头指向刺端。
这个经典实验同时给了我们两样东西：知道了微丝的方向性，也证明了肌球蛋白确实能与微丝结合。
</span>

聚合分三步：**成核（nucleation）**（三个以上单体形成稳定核心，最慢的一步）、**延长（elongation）**（单体在两端添加，刺端更快）、**稳态（steady state）**（聚合与解聚速率相等，微丝长度不变但单体持续周转）。

## 2 公式解析：临界浓度与聚合的开关

微丝聚合的开关由**临界浓度（critical concentration, $C_c$）**决定。
在稳定状态下，微丝端上的添加速率与脱落速率平衡：

$$C_c = \frac{k_{\mathrm{off}}}{k_{\mathrm{on}}}$$

- **$k_{\mathrm{on}}$**：单体与微丝端结合的速率常数；**$k_{\mathrm{off}}$**：单体从端上脱落的速率常数；
- 当溶液中 G-actin 浓度 $[G] > C_c$：净聚合（微丝生长）；
- 当 $[G] = C_c$：动态平衡（长度不变）；
- 当 $[G] < C_c$：净解聚（微丝缩短）。

微丝两端的 $C_c$ 并不相同：刺端的 $C_c$ 更低，意味着在同样的单体浓度下，**刺端倾向添加、尖端倾向脱落**——当单体浓度介于两端临界浓度之间时，会出现**踏车（treadmilling）**：单体在刺端加上、在尖端掉下，微丝本身位置不动，但亚基像「传送带」一样流过微丝。
<span class="marginnote">踏车现象是理解细胞运动的关键：细胞前沿的微丝在刺端不断加长（顶着膜向前），同时后端微丝在尖端解聚回收单体，单体再被运回前沿复用。
细胞就这么「把前面的路铺好，把后面的路拆掉」——不需要凭空制造材料。
</span>

**易错点｜ATP 水解不是聚合的能量来源**：肌动蛋白结合 ATP，但水解发生在亚基**已经**聚合之后。
ATP 水解的功能是「标记旧亚基」——让老亚基更易脱落，从而把微丝的寿命限制在特定窗口。
聚合靠的是浓度差驱动，水解只是「时钟」。

## 3 微丝的动态：从踏车到细胞迁移

细胞的爬行（cell migration）是一台由微丝驱动的机器：

1. **前缘突出**：细胞前沿（前缘）的 Arp2/3 复合体在现有微丝侧壁「长新枝」，形成扇形的**片状伪足（lamellipodium）**；平行捆扎的微丝束伸出**丝状伪足（filopodium）**探路；
2. **黏附**：整合素把前缘「钉」到基质上（见「细胞连接与细胞外基质」一节）；
3. **收缩**：细胞后方的肌球蛋白拉着微丝把细胞体向前收；
4. **脱离**：后缘黏附解开，细胞整体前移。

<span class="marginnote">致病菌李斯特菌（Listeria）把这一套劫持了：它表达 ActA 蛋白，在细菌表面不断招募 Arp2/3 组装「肌动蛋白彗尾」，靠彗尾的推力在宿主细胞内横冲直撞、直接挤进相邻细胞——细胞内「火箭推进器」，是细菌对微丝动态性的恶性利用。
</span>

## 4 肌动蛋白结合蛋白：微丝的管理者

微丝的形态与行为完全由一组**肌动蛋白结合蛋白（actin-binding protein）**调控：

| 蛋白 | 作用 |
| --- | --- |
| 前纤维蛋白（profilin） | 促进刺端添加，供单体 |
| 丝切蛋白（cofilin） | 切断旧微丝，制造新刺端 |
| Arp2/3 复合体 | 在侧壁分支成核，造片状伪足 |
| 成核因子（formin） | 生成直的、捆扎的微丝束 |
| 封端蛋白（capping protein） | 封住刺端，阻止继续生长 |
| 交联蛋白（α-肌动蛋白、细丝蛋白） | 把微丝连成束或网状 |

<span class="marginnote">鬼笔环肽（phalloidin）来自毒蘑菇，能特异性地结合并稳定 F-actin——荧光标记的鬼笔环肽是实验室里「照」微丝的标准工具；而细胞松弛素（cytochalasin）抑制聚合、阻断微丝动态。
一正一反两把钥匙，让研究者能拆装细胞骨架来验证功能。
</span>

## 5 肌球蛋白与肌肉收缩

微丝的专属马达是**肌球蛋白（myosin）**家族，最著名的成员是**肌球蛋白 II**——肌肉收缩的执行者。

骨骼肌的收缩用**滑动丝模型（sliding filament model）**解释：

- 粗丝由肌球蛋白 II 组成，细丝由 F-actin 组成；
- 肌球蛋白头部与微丝结合后发生**构象变化（power stroke）**，把细丝朝肌节中央拉动；
- 一个**交叉桥循环（cross-bridge cycle）**= 结合 → 摆动 → 释放 → 复位，每轮水解一个 ATP，细丝被推进约 5–10 nm；
- 大量肌球蛋白头同步循环，整块肌肉缩短。<span class="marginnote">肌肉的收缩由钙离子「点火」：神经冲动让肌质网释放钙，钙结合肌钙蛋白、推动原肌球蛋白让出肌球蛋白的结合位点，交叉桥循环才启动。前面肌浆网「钙库」的伏笔在这里兑现——钙不是收缩的能量，而是收缩的扳机。</span>

**易错点｜肌球蛋白不是「微管马达」**：肌球蛋白走**微丝**，驱动蛋白/动力蛋白走**微管**——两条轨道、三套马达，各有分工。
肌球蛋白 II 在胞质分裂时还组成**收缩环（contractile ring）**，在两姐妹细胞之间收紧、把细胞一分为二——细胞分裂的最后一刀，也是微丝砍的。

## 6 微丝与疾病：运动系统失灵之后

微丝驱动着细胞运动、免疫追杀与肌肉收缩，它的故障因此以「动不了」的方式呈现在不同组织：

- **肌肉病**：肌球蛋白或肌动蛋白相关蛋白突变导致**肌病（myopathy）**——心肌病、骨骼肌无力。肥厚型心肌病常由肌球蛋白或肌钙蛋白突变引起，这是年轻人猝死的常见原因之一。<span class="marginnote">肥厚型心肌病是「收缩机器过劳」的典型：突变让肌小节收缩异常、心肌代偿性肥厚，心室壁变厚、泵血受阻。运动时心肌需氧陡增，常诱发恶性心律失常——这也是运动员猝死筛查的重点对象。一个收缩蛋白的突变，直接写在心脏的每一次搏动里。</span>
- **免疫细胞迁移缺陷**：白细胞要「爬」向感染灶吞噬病原，靠微丝前沿推进。**Wiskott-Aldrich 综合征**由 WASP（激活 Arp2/3 的蛋白）突变引起，T 细胞、血小板功能异常——免疫细胞「爬不动、聚不齐」，患者易感染、易出血。<span class="marginnote">WASP 的故事把这一节的关键分子全串了起来：WASP 激活 Arp2/3 → Arp2/3 在旧微丝侧壁分支成核 → 前沿片状伪足推出 → 细胞爬行。一个「让微丝长枝」的开关坏了，整个免疫系统的运动能力就塌了——分子、通路、疾病在这里严丝合缝。</span>
- **转移性癌的微丝利用**：癌细胞靠丝状伪足「探路」、靠片状伪足「爬行」侵入组织——抑制微丝动态（细胞松弛素等）能抑制体外侵袭，这是抗癌研究的靶区之一。
- **病原劫持**：李斯特菌（见正文）用肌动蛋白彗尾在细胞内横冲直撞；沙门氏菌则触发宿主微丝「环绕」形成吞噬样的内化。**微丝既是防御工具，也是被攻击的弱点**。
- **血小板与止血**：血小板活化后靠肌动蛋白聚合**伸展（spreading）**、形成血栓。血小板无力症等出血病与整联蛋白/肌动蛋白连接异常有关——「动不了的血小板」，就是止不住的血。

**辨析｜「微丝病 = 肌肉病」是以偏概全**：微丝遍布所有细胞，微丝病因此是**全身性的**——肌肉（收缩）、免疫（迁移）、皮肤（伤口愈合）、血小板（止血）、神经发育（生长锥导向）都会受累。
看一个细胞骨架分子，要看它在所有「需要动」的地方的失职。

## 7 小结

- 肌动蛋白由 **G-actin 聚合为 F-actin**，微丝有极性（刺端 +、尖端 −），成核是最慢的一步。
- 临界浓度 $C_c = k_{\mathrm{off}}/k_{\mathrm{on}}$ 决定聚合/解聚方向；两端 $C_c$ 差异导致**踏车**。
- ATP 水解是「时钟」而非聚合能源：标记旧亚基、促其解聚。
- 细胞迁移四步：**前缘突出 → 黏附 → 收缩 → 脱离**；李斯特菌劫持微丝彗尾传播。
- 肌球蛋白 II 驱动**肌肉滑动**与**胞质分裂收缩环**；钙离子是收缩的扳机。

在下一节，我们来看细胞骨架里最「安静」的一族——**中间丝**，它不像微管微丝那样动态，却是细胞与组织抗拉的定海神针。
