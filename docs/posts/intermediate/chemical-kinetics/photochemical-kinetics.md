## 为什么从光化学开始

光合作用把阳光变成糖与氧气，视觉把光子变成神经信号，摄影把光子变成银颗粒，臭氧层的光化学决定了地球生命的生存环境。热反应靠加热翻越活化能垒；光反应则完全绕开这条路径——**光子把电子直接踢上激发态，化学反应从此发生在能量远远更高的电子态上**，反应通道与热化学迥异。<span class="marginnote">光化学与热化学的根本区别：热反应沿基态势能面走，反应物与产物在同一个电子态；光反应先垂直跃迁到激发态，再在激发态上发生化学反应，最后可能落回基态的不同产物。所以「光催化的反应，加热不一定能发生」。</span>这一篇我们立住光化学动力学的三根柱子：光吸收的基本定律、激发态的失活途径、以及刻画「光子利用效率」的量子产率。

## 1 光化学的两条基本定律

**Grotthuss-Draper 定律（光化学第一定律）**：**只有被体系吸收的光才能引发光化学变化**。透射过去的光是「看过热闹就走了」，没起作用。这决定了光化学实验必须用吸收谱去对齐光源波长。

**Stark-Einstein 定律（光化学第二定律，光当量定律）**：**一个光子最多激活一个分子**（激发态经由单光子过程生成）。它不要求「每个被吸收的光子都导致反应」——那正是量子产率要度量的差距。注意它说的是「激活」，不是「反应」：吸收光子只是把分子送上激发态，后文看到，激发态有大量「空转」出路。<span class="marginnote">Stark-Einstein 定律在今天仍是光化学的基石，但被激光时代「升级」了一次：强激光场下可能发生双光子、多光子吸收（一个分子同时吃进两个光子），此时定律不再成立。飞秒激光（第十六篇）正是玩转这种非线性吸收的高手。</span>

这两条定律合起来奠定了「光子计数」的框架：光化学实验的起点是「每秒有多少光子被吸收」，而 Beer-Lambert 定律给出吸收随深度的分布——这正是后面推导量子产率的原料。

把它们记成一句话：**光化学的第一步是「吸收」，而吸收是按光子计的**。这个「按光子计」的视角，让光化学动力学天然是统计的——我们测量的是大量分子对光子的平均响应，正如《反应速率与速率方程》一篇里速率本身也是系综平均。

## 2 激发态与它的五条出路

光吸收把电子从基态 $S_0$ 激发到单重激发态 $S_1$（或更高 $S_n$），随后分子面临一场「能量竞争」：

1. **振动弛豫**：在同一个电子态内迅速把多余振动能量交给周围分子，降温回到该电子态的振动基态。
2. **荧光（fluorescence）**：从 $S_1$ 辐射跃迁回 $S_0$，寿命约纳秒，光速快而弱。
3. **系间窜越（intersystem crossing，ISC）**：电子自旋翻转，从单重态 $S_1$ 跳到三重态 $T_1$。
4. **磷光（phosphorescence）**：从 $T_1$ 辐射回 $S_0$，自旋禁阻导致寿命长（微秒到秒），这正是「夜光」的来源。
5. **非辐射失活 / 化学转化**：把激发能转成热（内转换），或者在激发态上直接发生化学反应。

**激发态寿命越短，留给化学反应的时间窗口越窄。** 光化学动力学的一半工作，就是弄清激发态能量到底流向哪条出路、各占多少比例。<span class="marginnote">把上述路径画成能级图（Jablonski 图），是光化学的标准语言：纵轴能量、横轴无关，$S_0,S_1,T_1$ 三个横线 + 各类箭头。荧光分析、光动力治疗、有机发光二极管的原理都在这张图上。</span>

五条出路之间不是固定比例，而是竞争关系：温度升高，非辐射失活加速，荧光、磷光相应减弱；重原子（如碘）的存在增强系间窜越，把激发态「引导」向三重态。所以光化学家常通过改溶剂、改取代基来「调控」激发态的去向——这与《催化》一篇「调控速率」的思路完全一致，只是对象换成了激发态。

## 3 量子产率：光子的「命中率」

**量子产率（quantum yield）** $\Phi$ 定义为单位吸收光子数对应的某过程发生次数：

$$
\Phi = \frac{\text{生成产物的分子数}}{\text{吸收的光子数}}
$$

它是光化学动力学的总纲指标：$\Phi \le 1$ 说明多数光子空转，$\Phi > 1$ 说明一个光子引发了连锁反应（光引发的链反应，见《链反应与爆炸机理》），$\Phi \ll 1$ 则说明激发态几乎全部走失活路径。<span class="marginnote">光化学中测 $\Phi$ 用「化学露光计」（如草酸铁钾）标定光子通量。一个著名例子：$\ce{H2 + Cl2 -> 2HCl}$ 的光反应 $\Phi$ 可高达 $10^6$——一个光子引发一条自由基链，生成百万个 HCl 分子。这既是链反应，又是光量子产率超标的教科书。</span>

由稳态近似可直接写出量子产率与机理的联系：若机理为激发 → 失活（速率 $k_{\mathrm{d}}[\ce{A^*}]$）→ 反应（速率 $k_{\mathrm{r}}[\ce{A^*}]$）竞争，则稳态下

$$
\Phi = \frac{k_{\mathrm{r}}}{k_{\mathrm{r}} + k_{\mathrm{d}}}
$$

**测 $\Phi$ 随温度、浓度的变化，就是在给激发态的失活通道「称重」**——这是光化学机理研究的定量抓手。

## 4 公式解析：$\Phi = \dfrac{k_{\mathrm{r}}}{k_{\mathrm{r}} + k_{\mathrm{d}}}$

拆解这条「量子产率 = 竞争份额」公式：

- **第一步，建立激发态浓度**。设单位时间吸收光产生 $\ce{A^*}$ 的速率为 $I_{\mathrm{abs}}$（单位：光子 $\mathrm{M\,s^{-1}}$ 折算）。$\ce{A^*}$ 只有两条出路：反应（$k_{\mathrm{r}}$）与失活（$k_{\mathrm{d}}$）。
- **第二步，稳态近似**。$\ce{A^*}$ 寿命极短，令 $\dfrac{\mathrm{d}[\ce{A^*}]}{\mathrm{d}t} = I_{\mathrm{abs}} - (k_{\mathrm{r}} + k_{\mathrm{d}})[\ce{A^*}] = 0$，解得 $[\ce{A^*}] = \dfrac{I_{\mathrm{abs}}}{k_{\mathrm{r}} + k_{\mathrm{d}}}$。
- **第三步，算产物速率**。产物生成速率 $= k_{\mathrm{r}}[\ce{A^*}] = \dfrac{k_{\mathrm{r}}I_{\mathrm{abs}}}{k_{\mathrm{r}} + k_{\mathrm{d}}}$。
- **第四步，除以上镜**。$\Phi = \dfrac{\text{产物速率}}{I_{\mathrm{abs}}} = \dfrac{k_{\mathrm{r}}}{k_{\mathrm{r}}+k_{\mathrm{d}}}$。

直觉：**量子产率是「反应通道在全部通道中的份额」**。若失活远快于反应（$k_{\mathrm{d}} \gg k_{\mathrm{r}}$），$\Phi \to 0$，激发态白吸收；反之若反应是唯一出路，$\Phi \to 1$。

**辨析｜易错点：** 不要把量子产率与反应速率混淆：$\Phi$ 是「比例」，无量纲；速率是「$\mathrm{M\,s^{-1}}$」。另一个易错点：光化学里「吸收截面 × 光强」决定激发速率，而**光强分布通常随溶液深度指数衰减（Beer-Lambert）**，所以光化学动力学常是「表层快、深层慢」的空间不均匀问题。

## 5 数值算例：用量子产率拆机理

设某光反应测得量子产率 $\Phi = 0.25$，已知失活速率常数 $k_{\mathrm{d}} = 3.0\times10^{7}\,\mathrm{s^{-1}}$。

- **第一步，代入公式**：$0.25 = \dfrac{k_{\mathrm{r}}}{k_{\mathrm{r}} + 3.0\times10^{7}}$。
- **第二步，解出 $k_{\mathrm{r}}$**：$0.25\,k_{\mathrm{r}} + 7.5\times10^{6} = k_{\mathrm{r}}$，故 $0.75\,k_{\mathrm{r}} = 7.5\times10^{6}$，$k_{\mathrm{r}} = 1.0\times10^{7}\,\mathrm{s^{-1}}$。
- **第三步，读含义**：反应速率常数与失活速率常数同量级——说明「反应通道与失活通道势均力敌」，$\Phi = 0.25$ 不是激发态「不反应」，而是「四分之三的空转」。<span class="marginnote">这个例子展示了量子产率作为「探针」的用法：$\Phi$ 本身只是比例，但配合一个已知的 $k_{\mathrm{d}}$（可由荧光寿命测出），就能反推出反应通道的 $k_{\mathrm{r}}$——比例变成了速率常数，这正是动力学式的思维方式。</span>

## 6 荧光与磷光对照

| 特征 | 荧光 | 磷光 |
| --- | --- | --- |
| 跃迁 | $S_1 \to S_0$（允许） | $T_1 \to S_0$（自旋禁阻） |
| 寿命 | 纳秒量级 | 微秒到秒 |
| 强度 | 较快、较弱 | 较慢、可持续 |
| 温度影响 | 较小 | 低温常增强（抑制碰撞失活） |
| 典型应用 | 荧光标记、传感 | 夜光材料、光动力 |

## 7 常见误区与辨析

**辨析｜易错点（汇总）：**

- 「吸收光子越多，$\Phi$ 越大」是误读：$\Phi$ 是比例而非绝对量，强光只增加激发速率，不改各通道的份额（除非饱和）。
- 「光化学 = 热化学 + 光」过于简化：激发态是全新的电子态，产物分布、立体化学都可能与热反应完全不同。
- 「磷光 = 慢荧光」不准确：二者涉及不同的自旋多重度，磷光的「慢」源于自旋禁阻。
- 「量子产率只能 ≤ 1」只对单分子过程成立：链反应让 $\Phi$ 轻易超过 1，甚至到 $10^6$。
- 「激发态一定发生反应」是错的：多数激发态走失活通道，反应只是竞争中的一条路。
- 双光子/多光子吸收只在强激光下显著，弱光下 Stark-Einstein 定律依然准确。

## 8 小结

- **Grotthuss-Draper**：只有被吸收的光才起作用；**Stark-Einstein**：一光子最多激活一分子。
- 激发态五条出路：振动弛豫、荧光、系间窜越、磷光、化学转化；**寿命决定反应窗口**。
- **量子产率** $\Phi$ = 产物分子数 / 吸收光子数；$\Phi>1$ 意味着链反应。
- $\Phi = \dfrac{k_{\mathrm{r}}}{k_{\mathrm{r}}+k_{\mathrm{d}}}$：量子产率是反应通道在全部失活通道中的竞争份额。
- 数值直觉：$\Phi = 0.25$ 配合已知 $k_{\mathrm{d}}$，可反解出反应通道的 $k_{\mathrm{r}}$——比例变常数。
- 关联阅读：$\ce{H2 + Cl2}$ 的超高 $\Phi$ 与《链反应与爆炸机理》互为印证；Jablonski 图里的激发态寿命在《快速反应技术》《飞秒化学》中都是可测对象。
- 五条出路是竞争关系：温度、重原子、溶剂都能改写份额——光化学家靠这些「旋钮」调控激发态去向。
- 六大易错辨析的核心提醒：$\Phi$ 是比例不是速率，链反应可破 1，弱光下 Stark-Einstein 依然准确。
- 数值直觉：$\Phi = 0.25$ 对应「反应与失活势均力敌」，比例背后是可反解的速率常数。
- 荧光与磷光的寿命差异（ns vs ms-s）是区分两类辐射跃迁的最锋利判据。
- 一句收束：光化学 = 光子计数 + 激发态竞争，动力学工具在这里从「浓度」换成了「布居」。
- 延伸阅读提示：激发态动力学的时间分辨率话题，在《快速反应技术》与《飞秒化学》两篇各有专攻。
