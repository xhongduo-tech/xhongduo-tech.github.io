## 为什么从机理开始

上一篇我们把复合反应当作「由几步拼成的黑箱」，用速控步与稳态近似凑出表观速率方程。但真正的问题是反过来的：**面对一条实验速率方程，化学家想把它翻译成「分子到底怎么一步步变成产物」的叙事——这就是反应机理（reaction mechanism）。** 机理不是哲学，而是可以被实验判决的假设：它由一串**基元反应**组成，每个基元反应的分子性、中间体的身份、每一步的速率常数，全部要在实验里过堂。Espenson 用整整一章（第 4 章）讲机理的建立，因为它是动力学从「记录现象」升级到「解释世界」的枢纽。<span class="marginnote">费曼这句话放在这里是本义：理解一个反应 = 能从头按机理「造出」它的动力学。这与大模型研究里「可复现、可解释」的要求同构——你不能重现的现象，就没有真正理解。</span>

## 1 基元反应与分子性

**基元反应（elementary reaction）**：在分子层面上真正一步完成的反应，没有中间体。它的速率方程可以直接从方程式读出——**对基元反应，化学计量数就是级数**。描述基元反应的另一个量是**分子性（molecularity）**：

**单分子反应（unimolecular）**：一个分子孤立地发生异构化或分解，如 $\ce{CH3NC -> CH3CN}$、放射性衰变。
- **双分子反应（bimolecular）**：两个分子碰撞反应，动力学上最重要的一类，如 $\ce{H + H2 -> H2 + H}$。
- **三分子反应（termolecular）**：三个分子同时碰撞，概率极低，几乎只出现在原子复合这类「无第三条路」的场合，如 $\ce{2I + M -> I2 + M}$。

**分子性是「一步之内」，级数是「全机理之上」；前者永远小（1 或 2，罕见 3），后者可以任意大。** 一个表观四级反应绝不是四级分子碰撞，而是若干步串联的伪装。

## 2 中间体：真实存在却短命的分子

**反应中间体（reactive intermediate）**：机理中生成又随即消耗的、寿命较短的真实化学物种。它与**过渡态（transition state）**有本质区别：中间体是**能够被光谱捕获、甚至隔离**的真实分子（自由基、碳正离子、卡宾、配合物等），在势能面上有自己浅浅的「井」；过渡态则是能量峰顶的鞍点，只代表「旧键将断未断、新键将成未成」的临界构型，不存在「几飞秒寿命」之外的实体。<span class="marginnote">中间体与过渡态的分界是化学动力学里最容易被外行混淆的一对概念。判断口诀：中间体可以「抓出来」（稳定到足以被观测或捕获），过渡态只能「算出来」。飞秒化学（第十六篇）的成就之一，正是把若干中间体从「假设」变成了「亲眼所见」。</span>

中间体的存在证据分两类：**间接证据**（从速率方程推断、从同位素标记推断、从产物分布推断）与**直接证据**（用光谱当场抓住）。第五条碳正离子、自由基的发现史，就是间接证据如何逼出直接证据的教科书。

## 3 如何给一个机理定罪：可证伪性

一个机理成立，至少要过四道关：

1. **速率方程关**：机理导出的表观速率方程必须与实验实测完全一致——包括级数、分数级数、抑制项（如 HBr 速率方程里分母的 $[\ce{HBr}]$）。
2. **中间体关**：机理声称的中间体要么被直接观测，要么其存在导致的速率方程特征（诱导期、分数级数）被实验证实。
3. **微观可逆关**：正向机理的逆过程必须也是合法机理（这是 detailed balance 的要求）。
4. **独立关**：中间体若能单独制备，应能按机理预言的方式发生后续反应（自由基引发实验正是这样设计）。

**一个「通过全部实验」的机理仍然是假设——只是至今未被证伪的假设。** 这种态度与科学哲学中波普尔的证伪主义一脉相承：机理不能「被证明」，只能「被暂时接受」。<span class="marginnote">这也是本篇与整个动力学大厦的方法论底色：速率方程是实验事实，机理是模型。模型永远可以被更精细的实验推翻——飞秒化学就曾当场推翻过好几个「公认」的机理。</span>

## 4 公式解析：从机理到速率方程——臭氧层机理

大气臭氧层的 Chapman 机理（1930）是机理推导的经典例题。简化为：

$$
\ce{O3 <=>[k_1][k_{-1}] O2 + O}, \qquad \ce{O + O3 ->[k_2] 2O2}
$$

推导 $\ce{O3}$ 的消耗速率：

- **第一步，写中间体 $\ce{O}$ 的净生成速率**：$\dfrac{\mathrm{d}[\ce{O}]}{\mathrm{d}t} = k_1[\ce{O3}] - k_{-1}[\ce{O2}][\ce{O}] - k_2[\ce{O}][\ce{O3}]$。
- **第二步，稳态假设** $\mathrm{d}[\ce{O}]/\mathrm{d}t = 0$：$k_1[\ce{O3}] = (k_{-1}[\ce{O2}] + k_2[\ce{O3}])[\ce{O}]$，解得 $[\ce{O}] = \dfrac{k_1[\ce{O3}]}{k_{-1}[\ce{O2}] + k_2[\ce{O3}]}$。
- **第三步，代回**：$v = -\dfrac{\mathrm{d}[\ce{O3}]}{\mathrm{d}t} = k_1[\ce{O3}] - k_{-1}[\ce{O2}][\ce{O}] = k_2[\ce{O}][\ce{O3}] = \dfrac{k_1 k_2[\ce{O3}]^2}{k_{-1}[\ce{O2}] + k_2[\ce{O3}]}$。
- **第四步，读机理信息**：分母中 $[\ce{O2}]$ 出现在抑制项里——**产物 $\ce{O2}$ 会「回堵」臭氧分解**。这一条预言后来被紫外大气化学的实测所支持，也让「臭氧分解速率随氧气浓度变化」成为判定 Chapman 机理的实验指纹。

**辨析｜易错点：** 写 $\ce{O}$ 的速率方程时不要漏掉「第一步是快速可逆」里的逆向项 $k_{-1}[\ce{O2}][\ce{O}]$——漏了它，中间体的稳态方程和最终速率方程就全错了。另一个易错点：中间体稳态方程里，参与该中间体的**每一步**都要写进去。

## 5 小结

- **基元反应**的级数等于化学计量数；**分子性**（1、2、罕见 3）是一步之内的概念，与全局表观级数无关。
- **中间体**是真实但短命的物种，可被观测；**过渡态**是势能面鞍点，只能计算。
- 机理验证四关：速率方程、中间体、微观可逆、独立实验；**机理是可证伪的模型，不是定理**。
- 从机理导出速率方程的流水线：写各基元步 → 对中间体做稳态 → 代数求解 → 极限化简。
