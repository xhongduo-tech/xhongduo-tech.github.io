## 为什么从催化开始

工业上约九成化学品的生产涉及催化，汽车尾气净化、固氮、聚合、药物合成无一例外；生命体更是一台精密的酶催化机器。催化是动力学最成功的应用分支，也是理解它的反命题——**动力学如何被主动操控**。<span class="marginnote">「调控速率」正是动力学的终极价值。热力学说了「能不能」，动力学说了「多快」，而催化就是那个把「不够快」变成「足够快」的杠杆——大模型推理加速、编译器优化，本质都是在做同样的事。</span>本篇把催化分成均相与多相两大战场，核心都指向同一动力学结构：**催化剂改变的是路径，不是终点**。理解这条主线，你就能解释为什么哈伯固氮能在低压下推动、为什么汽车三元催化器怕含铅汽油——它们共享同一套动力学逻辑。

## 1 催化剂的基本特征

**催化剂（catalyst）**：加入后能改变反应速率、但不出现在计量方程式中的物质。奥斯特瓦尔德（Wilhelm Ostwald）1894 年给出了近代定义：催化剂是「不改变产物而改变反应速率」的物质，且**不改变反应的热力学平衡**。<span class="marginnote">「不改变平衡」可由 $K = k_1/k_{-1}$ 直接看出：催化剂把 $k_1$ 和 $k_{-1}$ 按同一比例放大，二者之比即平衡常数不变。因此催化绝不能把热力学上不允许的反应「催成」——它只帮快慢，不帮方向。</span>

催化剂提速的动力学本质是**开辟低活化能的新路径**：在能量剖面上，一条经过催化剂参与中间络合物的新通道，其能垒比无催化通道更低，于是 $k = Ae^{-E_{\mathrm{a}}/RT}$ 里的指数因子大增。催化剂参与机理却又在反应末了原样再生——这正是「不出现在计量式里」的微观含义。它同样意味着催化剂不改变反应的焓变、熵变与平衡常数，只改变到达平衡的快慢。

## 2 均相催化：催化剂与反应物同相

**均相催化（homogeneous catalysis）**：催化剂与反应物处于同一相（多为液相）。典型的动力学结构是「催化剂 + 反应物 ⇌ 中间络合物 → 产物 + 催化剂」，中间络合物用稳态或平衡近似处理。

**酸碱催化**是最经典的均相催化：酯水解在酸或碱存在下速率大幅提升。进一步区分为**专属酸碱催化（specific）**与**广义酸碱催化（general）**：前者只有 $\ce{H+}$（或 $\ce{OH-}$）本身是活性物种，速率只依赖 pH；后者任何给质子/受质子物种都参与催化，速率与缓冲液浓度相关。<span class="marginnote">区分两者的实验方法是「改变缓冲剂浓度但保持 pH 不变」：专属催化速率不变，广义催化速率随缓冲浓度线性上升。酶化学中大量应用广义酸碱催化——酶的氨基酸侧链就是一台给质子/受质子的机器。</span>

均相催化的优势是机理清晰、选择性高、活性位均一；代价是产物与催化剂分离困难。过渡金属配合物催化（如 Wilkinson 加氢、Sharpless 环氧化）把均相催化推向工业与制药的高峰。近年发展的「固载化均相催化剂」试图兼顾两边的优点：把均相催化剂的活性分子锚定到固体载体上，既保留机理清晰的选择性，又获得多相催化易分离的便利。

## 3 多相催化：表面上的反应

**多相催化（heterogeneous catalysis）**：催化剂为固体，反应物在表面吸附后反应。哈伯-博施固氮、汽车三元催化、Fischer-Tropsch 合成都是多相催化。其动力学核心是**表面吸附**：

**Langmuir 吸附等温式**：表面吸附位被吸附物覆盖的比例 $\theta = \dfrac{K[\ce{A}]}{1 + K[\ce{A}]}$。低压时 $\theta \approx K[\ce{A}]$（正比），高压时 $\theta \to 1$（饱和）。
- **Langmuir-Hinshelwood 机理**：两种反应物都先吸附到表面，表面相遇反应，速率 $\propto \theta_{\mathrm{A}}\theta_{\mathrm{B}}$。
- **Eley-Rideal 机理**：一种反应物从气相直接与已吸附的另一物种反应。

多相催化的表观级数因此充满「怪味」：高气压下速率趋于与压力无关（表面饱和，零级），低气压下随压力线性（一级）。**表面覆盖度是理解多相动力学一切怪象的总开关。**<span class="marginnote">催化剂「中毒」也是表面现象：毒物（如 $\ce{Pb}$、$\ce{S}$）占据吸附位，覆盖度骤降，速率崩塌。贵金属催化剂怕硫、怕铅，本质上是一场「吸附位争夺战」。</span>正是这个原因，无铅汽油的普及救了汽车三元催化器——铅一吸附，催化剂就「哑」了。

多相催化的另一个工业现实是**烧结**：高温下小金属颗粒聚并成大颗粒，表面位总数 $N_s$ 骤降，速率随之崩塌。催化剂失活的管理（防毒、控温、再生）其实是「表面位经济学」——谁保住了活性位，谁就保住了产能。

## 4 公式解析：Langmuir-Hinshelwood 速率方程

设机理：$\ce{A(g) <=> A(ads)}$，$\ce{B(g) <=> B(ads)}$，表面反应 $\ce{A(ads) + B(ads) ->[k_s] 产物}$。

- **第一步，写覆盖度**：$\theta_{\mathrm{A}} = \dfrac{K_{\mathrm{A}}p_{\mathrm{A}}}{1 + K_{\mathrm{A}}p_{\mathrm{A}} + K_{\mathrm{B}}p_{\mathrm{B}}}$，$\theta_{\mathrm{B}}$ 同理。分母里含对方分压，因为吸附位是共享的。
- **第二步，写表面反应速率**：$v = k_s \theta_{\mathrm{A}} \theta_{\mathrm{B}} N_s$（$N_s$ 为表面位总数）。
- **第三步，极限一**：低压且 $K_{\mathrm{A}}p_{\mathrm{A}}, K_{\mathrm{B}}p_{\mathrm{B}} \ll 1$，则 $v \propto p_{\mathrm{A}}p_{\mathrm{B}}$——表观二级。
- **第四步，极限二**：$\ce{A}$ 强吸附、$\ce{B}$ 弱吸附，则 $\theta_{\mathrm{A}} \approx 1$，$v \approx k_s K_{\mathrm{B}}p_{\mathrm{B}}$——表观一级于 B，**与 A 无关**；若 B 也强吸附，则速率被 B 抑制，$v$ 随 $p_{\mathrm{B}}$ 先升后降。**同一个表面机理，四种极限给出四种表观速率方程——这就是多相催化「形迹可疑」的数学根源。**

**辨析｜易错点：** 不要把「催化剂参与机理」等同于「催化剂被消耗」。催化循环要求催化剂净再生；若再生速率跟不上主反应，催化剂就被「失活」而非「催化」。另一个易错点：多相催化的表观活化能是「真实活化能 + 吸附焓」的复合值，符号甚至可为负。

## 5 数值算例：覆盖度怎么算

设 $\ce{CO}$ 在某铂表面上吸附，$K_{\ce{CO}} = 2.0\times10^4\,\mathrm{bar^{-1}}$，$p_{\ce{CO}} = 1.0\times10^{-4}\,\mathrm{bar}$（约 0.1 mbar）。

- **第一步，代入单组分 Langmuir 式**：$\theta = \dfrac{Kp}{1+Kp} = \dfrac{2.0\times10^4\times1.0\times10^{-4}}{1 + 2.0\times10^4\times1.0\times10^{-4}} = \dfrac{2.0}{3.0}\approx 0.67$。
- **第二步，读结果**：表面约三分之二被 CO 占据。把压力翻十倍到 $1.0\times10^{-3}\,\mathrm{bar}$，则 $\theta = \dfrac{20}{21}\approx 0.95$——**压力只升 10 倍，覆盖度却从 0.67 逼近 0.95，增速大幅放缓**，这正是吸附等温线「趋于饱和」的形状。

这个例子解释了一个反直觉现象：**多相催化在高分压下速率对压力越来越不敏感**。当覆盖度已经接近 1，再加压几乎不增加表面上的反应物，速率自然「封顶」——零级行为的微观来源。

## 6 均相与多相催化对照

| 维度 | 均相催化 | 多相催化 |
| --- | --- | --- |
| 相态 | 催化剂与反应物同相（多为液相） | 固体催化剂，表面反应 |
| 典型代表 | 酸碱、过渡金属配合物 | 哈伯固氮、三元催化、Fischer-Tropsch |
| 机理清晰度 | 高，可用稳态/平衡近似写出速率方程 | 表面覆盖度使表观级数漂移 |
| 活性位 | 均一、单一分子 | 表面缺陷、晶面各异，位不均一 |
| 分离回收 | 困难，需萃取/蒸馏 | 容易，过滤即可 |
| 温度窗口 | 相对温和 | 常需高温高压 |
| 特有问题 | 配体中毒、溶剂效应 | 吸附中毒（硫、铅）、烧结失活 |

## 7 三组易错辨析

**辨析｜易错点（汇总）：**

- 「催化剂不参与反应」是错的——它参与机理、只是净再生；「催化剂改变平衡常数」也是错的，$K = k_1/k_{-1}$ 两端同比放大。
- 专属催化与广义催化靠「固定 pH 改变缓冲浓度」的实验区分，别只看 pH 这一个变量。
- 多相催化的表观级数会随压力漂移，零级不意味着「反应物不参与」，而是「表面已饱和」。
- 中毒与失活不同：中毒是被毒物占据活性位（可逆或不可逆），失活是催化循环自身断裂（如烧结、流失）。
- 表观活化能可能是「真实活化能 + 吸附焓」的复合，甚至为负——别把表观值当成基元反应的固有属性。
- 表面机理的「反应速率项」要用覆盖度乘表面位总数，不要直接用气相分压去凑速率方程。

这些辨析合起来，就是催化动力学最容易被误读的六个陷阱；带着它们去看化工与生物化学文献，会顺很多。

## 8 术语速查

| 术语 | 含义 |
| --- | --- |
| 催化剂 | 改变速率、不进计量式、不移动平衡的物质 |
| 覆盖度 $\theta$ | 表面吸附位被占据的比例，$0 \le \theta \le 1$ |
| Langmuir 等温式 | $\theta = \dfrac{K[\ce{A}]}{1+K[\ce{A}]}$，低压线性、高压饱和 |
| 专属酸碱催化 | 只有 $\ce{H+}$/$\ce{OH-}$ 是活性物种，速率只看 pH |
| 广义酸碱催化 | 一切给质子/受质子物种都参与，速率随缓冲浓度 |
| Langmuir-Hinshelwood | 两物种都吸附后在表面相遇反应 |
| Eley-Rideal | 气相物种直接与已吸附物种反应 |
| 催化剂中毒 | 毒物（$\ce{Pb}$、$\ce{S}$）占据吸附位导致失活 |

## 8 小结

- **催化剂**改变速率、不进计量式、不移动平衡；本质是开辟低活化能路径，$K = k_1/k_{-1}$ 不变。
- **均相催化**（酸碱、金属络合物）：催化剂与反应物同相，机理由中间络合物 + 稳态/平衡近似刻画。
- **多相催化**：表面吸附是总开关，Langmuir 覆盖度导致表观级数随压力漂移。
- **Langmuir-Hinshelwood**：$v = k_s\theta_{\mathrm{A}}\theta_{\mathrm{B}}$，四种极限给出截然不同的表观速率方程。
- 覆盖度的数值例子说明「饱和」从何而来：压力翻十倍，覆盖度只从 0.67 升到 0.95。
- 均相催化机理清晰但难分离，多相催化易分离但表观级数漂移；工业用「固载化均相」两全其美。
- 六大易错辨析归纳了催化动力学的全部常见陷阱：再生、平衡、级数漂移、中毒 vs 失活、复合活化能、覆盖度写法。
- 催化改变的是路径（活化能），不是终点（平衡），所以它只能「加速」，不能「创造」热力学上不可能的反应。
- 记住标志性数字：吸附平衡常数越大，低压区越早进入饱和；覆盖度公式是换算分压与速率的桥梁。
- 关联阅读：均相催化的「中间络合物 + 稳态」结构与《复合反应与稳态近似》一脉相承；多相催化的饱和则呼应《酶动力学》的零级段。
- 方法论收获：把「不可观测的表面」翻译成「可测的覆盖度」，再用覆盖度写出速率——这是把微观机理落到宏观速率的标准动作。
- 工业启示：选择性与活性是一对需要平衡的指标，催化剂设计的全部艺术在于同时调控两者。
