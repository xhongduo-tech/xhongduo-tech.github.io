## 为什么从平稳随机过程开始

第十三章研究一类「统计特性不随时间平移而变」的过程——**平稳随机过程（stationary stochastic process）**：噪声、股价收益、无线信道衰落、稳态运行的系统输出，它们的统计规律不因「你从几点开始观察」而改变。平稳性是信号处理与时间序列分析的基石假设，它让「观察一段就能推断整体」成为可能。

平稳过程在课程里是随机过程章的收官：它与马尔可夫链（离散时间、强调状态转移）形成互补——平稳过程（连续时间、强调统计对称）。它的核心工具是**功率谱密度**（下一节），而严平稳/宽平稳之分是理解一切的前提。<span class="marginnote">「平稳」的直觉：<strong>看一段过程的统计特性，与从哪个时刻开始看无关</strong>——下午 2 点开始的噪声记录与下午 5 点开始的记录，统计规律相同。这不是说过程「不变」，而是说它的「随机规律」不随时间原点漂移。平稳性让「时间平均」可以替代「概率平均」（各态历经），是工程上能用一段数据推断过程的关键。</span>

## 1 严平稳（狭义平稳）

**严平稳（strictly stationary）**：若随机过程 $\{X(t)\}$ 的任意有限维分布对时间平移不变——对任意 $n$、任意 $t_1, \ldots, t_n$ 与任意 $\tau$，

$$F_{t_1, \ldots, t_n}(x_1, \ldots, x_n) = F_{t_1 + \tau, \ldots, t_n + \tau}(x_1, \ldots, x_n)$$

则称 $\{X(t)\}$ 为**严平稳过程**。全部有限维分布都不随平移改变——这是「最严格的平稳」。

**推论**：严平稳 ⇒ 一维分布与 $t$ 无关（$\mu(t)$、$\sigma^2(t)$ 为常数），二维分布只依赖 $t_2 - t_1$。<span class="marginnote">严平稳的要求「所有有限维分布平移不变」在理论上很美，但实践中几乎无法验证——你永远不知道「所有 n 维分布」。于是工程上退而求其次，只要求「一阶、二阶矩的平移不变」，这就是宽平稳。严平稳是理论标杆，宽平稳是工程语言。</span>

## 2 宽平稳（广义平稳）

**宽平稳（weakly / wide-sense stationary）**：若 $\{X(t)\}$ 满足：

1. **均值函数为常数**：$E[X(t)] = \mu$（与 $t$ 无关）；
2. **自相关函数只依赖时间差**：$E[X(s) X(t)] = R_X(t - s)$（只依赖 $\tau = t - s$，不依赖绝对时刻）；
3. **二阶矩有限**：$E[X^2(t)] < \infty$。

则称 $\{X(t)\}$ 为**宽平稳过程**。<span class="marginnote">宽平稳只约束「一、二阶矩」，不管分布形状——所以条件远比严平稳宽松。这是信号处理、时间序列的默认「平稳」含义：只说「平稳过程」，通常指宽平稳。两条核心：均值常数、相关只差「时间差」。这也解释了为什么第十三章后面全在研究 $R_X(\tau)$——宽平稳下，相关函数从「两变量函数」退化成「单变量函数」，分析一下子简化。</span>

**例（白噪声的积分）**：平稳高斯过程、稳态滤波输出、长时间观测的噪声——都是宽平稳。而「带趋势的股价」均值随 $t$ 增长，不是宽平稳（先差分去趋势才能用平稳工具）。

## 3 严平稳与宽平稳的关系

| | 严平稳 | 宽平稳 |
| --- | --- | --- |
| 要求 | 全部有限维分布平移不变 | 均值常数 + 相关只差时间差 + 二阶矩有限 |
| 验证 | 几乎无法验证 | 工程可验证 |
| 关系 | 严平稳 + 二阶矩有限 ⇒ 宽平稳 | 宽平稳 ⇏ 严平稳 |
| 例外 | — | **正态过程：宽平稳 ⇔ 严平稳** |

**关键结论**：①严平稳（且二阶矩存在）必为宽平稳；②宽平稳一般不严平稳；③**正态过程例外**——正态过程的宽平稳与严平稳等价（因为正态分布完全由均值与协方差决定）。<span class="marginnote">「正态过程：宽 ⇔ 严」是最重要的例外：正态过程的任意有限维分布只由均值与协方差决定，而宽平稳恰好保证了「均值常数 + 协方差只差时间差」——于是所有有限维分布自动平移不变，严平稳成立。这条结论让「正态假设 + 宽平稳」在信号处理里可以放心当作「全平稳」用。</span>

**例（宽而不严）**：构造 $X(t)$ 使 $X(0)$ 与 $X(\pi)$ 的分布相同但 $X(0)$ 与 $X(2\pi)$ 不同（高阶矩不平移不变）——均值与相关满足宽平稳，但三阶矩破坏严平稳。现实中「宽而不严」的例子不少，工程上常忽略（因为我们只关心二阶统计量）。

## 4 公式解析：宽平稳的「相关只差时间差」

宽平稳的核心条件是「$R_X(s,t)$ 退化为 $R_X(t-s)$」，拆开它的意义：

$$

R_X(s, t) = E[X(s)X(t)] = R_X(t - s) = R_X(\tau), \qquad \tau = t - s

$$

- **第一步，两变量函数**：一般过程的自相关是「两个时刻」的函数 $R_X(s,t)$——需要二维信息。
- **第二步，平移对称**：宽平稳要求它只依赖差 $\tau = t - s$——「两个时刻的关联只由它们相隔多远决定」。
- **第三步，降维**：$R_X(s,t)$ 从「$s,t$ 两个轴」缩成「$\tau$ 一个轴」——分析维度降一半，这正是功率谱密度（傅里叶变换 $R_X(\tau)$）可行的前提。

「相关只差时间差」把过程从「二维描述」降为「一维描述」，是宽平稳的全部威力所在。它让 $R_X(\tau)$ 成为过程的「二阶签名」，也让下一节的功率谱成为可能。

## 5 平稳过程的深入辨析与应用

宽平稳是信号处理的基础假设，它的检验、变换保持性与工程意义值得展开。

### 例：判断是否平稳

| 信号 | 是否宽平稳 | 原因 |
| --- | --- | --- |
| 恒定噪声 | 是 | 均值常数、相关只差时差 |
| 带线性趋势 | 否 | 均值随 $t$ 增长 |
| 周期信号 | 是（宽） | 均值常数、相关周期 |
| 突发脉冲 | 否 | 统计特性随时间剧变 |

**「均值常数 + 相关只差时差」**是宽平稳的两条判据——逐条检查即可判断。

### 平稳性与各态历经的关系

| | 宽平稳 | 各态历经 |
| --- | --- | --- |
| 定义 | 均值常数、相关只差时差 | 时间平均 = 概率平均 |
| 条件 | 二阶矩性质 | 需协方差衰减 |
| 关系 | 各态历经 ⇒ 平稳 | 平稳 ⇏ 各态历经 |

**平稳是「统计不变」、各态历经是「一条轨道够用」**——平稳保证「规律存在」，各态历经保证「能测到规律」。

### 例：平稳过程的线性变换

**例**：$X(t)$ 宽平稳，$Y(t) = aX(t) + b$。$E[Y] = a\mu + b$（常数）、$R_Y(\tau) = a^2 R_X(\tau) + b^2$（只差时差）——$Y$ 仍宽平稳。**「宽平稳经线性变换保持」**是信号处理里滤波、放大的合法性基础。

### 应用：谱分析的入口

宽平稳的「相关只差时差」让 $R_X(\tau)$ 成为单变量函数，从而可以做傅里叶变换得功率谱——**「宽平稳是功率谱存在的前提」**。非平稳信号必须先处理（去趋势、分帧）再分析。

**易错点｜辨析：** ① 严平稳 ⇏ 宽平稳（若二阶矩不存在）；宽平稳 ⇏ 严平稳（除非正态过程）；② 「平稳」在工程里默认指「宽平稳」——别跟严平稳混淆；③ 趋势、季节性是破坏平稳性的常见来源——去趋势（差分、回归残差）是让数据平稳的标准操作。

再补一张「严平稳 vs 宽平稳」速查：

| | 严平稳 | 宽平稳 |
| --- | --- | --- |
| 要求 | 全部有限维分布平移不变 | 均值常数、相关只差时差 |
| 验证 | 几乎不可能 | 工程可验 |
| 关系 | 严 + 二阶矩 ⇒ 宽 | 宽 ⇏ 严 |
| 正态例外 | — | 宽 ⇔ 严 |

「理论看严、工程用宽」——正态过程里两者合一。

## 6 小结

- **严平稳**：全部有限维分布平移不变——理论标杆，几乎无法验证。
- **宽平稳**：均值常数 + 相关只差时间差 + 二阶矩有限——工程默认的「平稳」。
- 严平稳（二阶矩存在）⇒ 宽平稳；宽平稳 ⇏ 严平稳；**正态过程例外（宽 ⇔ 严）**。
- 宽平稳把自相关从「两变量函数」降为「单变量函数 $R_X(\tau)$」——维度减半。
- 平稳性是信号处理、时间序列、谱分析的基石假设。
