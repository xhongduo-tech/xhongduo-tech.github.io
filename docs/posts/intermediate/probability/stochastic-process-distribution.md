## 为什么从分布函数族开始

上一节说随机过程是「一族随机变量」，那么它的「分布」就是一族分布——**分布函数族（family of distribution functions）**。单个随机变量有一个分布函数；随机过程有「每个时刻一个一维分布 + 每两个时刻一个二维分布 + ……」的整套分布。这套「分布函数族」是过程的完整统计描述，也是推导一切数字特征的源头。

分布函数族在随机过程章的地位，相当于「分布函数」在前几章的地位——它是「总纲」。本章后面所有概念（均值函数、相关函数、平稳性、马尔可夫性）都能从分布函数族「投影」出来。理解它，等于拿到阅读随机过程文献的通用语言。<span class="marginnote">分布函数族「族」字的关键：过程有无穷多个时刻，所以有无穷多个一维分布、无穷多对二维分布……它们不是孤立的——二维分布的一维边缘必须与一维分布相容（一致性条件）。这个「族内自洽」要求，正是科尔莫戈罗夫扩展定理的前提：给出一族相容的有限维分布，就唯一确定了某个随机过程。</span>

## 1 一维分布函数族

**一维分布函数族**：对每个时刻 $t$，$X(t)$ 有一维分布函数

$$F_t(x) = P\{X(t) \le x\}, \qquad t \in T$$

它描述「在时刻 $t$，过程的状态分布」。$t$ 动起来，$F_t$ 就是一族「随 $t$ 变化的一维分布」。

**例**：泊松过程 $X(t)$ 在时刻 $t$ 服从 $\pi(\lambda t)$，一维分布族为 $F_t(x) = \sum_{k \le x} e^{-\lambda t}(\lambda t)^k/k!$——每个时刻的分布不同（参数随 $t$ 增长）。<span class="marginnote">一维分布族只给「单点信息」：它说 $X(t)$ 在时刻 $t$ 大概在哪，但完全不含「$X(s)$ 与 $X(t)$ 的关系」——两个时刻是否联动，必须看二维分布族。这是「一维不够、二维起步」的过程统计：要捕捉过程的「时间关联」，至少需要二维分布。</span>

## 2 二维分布函数族

**二维分布函数族**：对任意两个时刻 $s < t$，$(X(s), X(t))$ 有二维联合分布

$$F_{s,t}(x_1, x_2) = P\{X(s) \le x_1,\ X(t) \le x_2\}, \qquad s < t$$

二维分布族携带「两个时刻的关联」信息——它是相关函数、平稳性、马尔可夫性的基础。随机过程的统计描述一般取到二维就够用（更高维理论完备、工程少用）。

**例**：泊松过程的二维分布由独立增量给出：$P\{X(s) = i, X(t) = j\}$（$s < t$）可分解为「$s$ 时刻 $i$ 个」与「$(s,t]$ 区间新增 $j-i$ 个」之积——因为增量独立。<span class="marginnote">「二维分布族的兼容性」：$F_{s,t}$ 的边缘分布必须退回一维族——$F_{s,t}(x, +\infty) = F_s(x)$，$F_{s,t}(+\infty, y) = F_t(y)$。这个「边缘退回」的一致性条件是构造任何过程统计描述的纪律：任意二维分布都不能与已有的一维分布矛盾。检验一个「候选分布族」是否合法，就看这些一致性。</span>

## 3 n 维分布函数族与扩展定理

**n 维分布函数族**：对任意 $n$ 个时刻 $t_1 < \cdots < t_n$，

$$F_{t_1, \ldots, t_n}(x_1, \ldots, x_n) = P\{X(t_1) \le x_1, \ldots, X(t_n) \le x_n\}$$

**科尔莫戈罗夫扩展定理（Kolmogorov extension theorem）**：若一族有限维分布满足两条一致性条件（边缘相容、置换相容），则存在一个随机过程，其有限维分布族恰为给定族。**理论意义**：分布的家族在逻辑上完整自洽，就「存在」对应的过程——无需手工构造每条轨道。

<span class="marginnote">扩展定理是随机过程的「存在性定理」：它告诉我们「指定了所有有限维分布，就等于指定了一个过程」。实践中没人真的指定无穷多个分布——我们指定「一维分布 + 相关性结构」就够推导出工程上需要的一切。这个「理论存在性 + 实践够用性」的分层，是随机过程章节最值得记住的认识论。</span>

## 4 公式解析：一维族、二维族、n 维族的关系

分布函数族的结构是「逐层包含、边缘退回」，以二维为例拆开：

$$

F_{s,t}(x_1, x_2) \xrightarrow{x_2 \to +\infty} F_s(x_1), \qquad F_{s,t}(x_1, x_2) \xrightarrow{x_1 \to +\infty} F_t(x_2)

$$

- **第一步，二维给全信息**：$F_{s,t}(x_1, x_2)$ 描述两个时刻的联合分布——比一维多出「关联」。
- **第二步，边缘退回**：把 $x_2 \to +\infty$（放开对 $X(t)$ 的约束），二维分布退化为 $X(s)$ 的一维分布——**n 维族包含低维族作为边缘**。
- **第三步，一致性**：所有低维分布都必须是高维分布的边缘——族内自洽的检查标准。

「高维含低维、低维是边缘」是分布函数族的纵向结构。它保证过程统计描述不矛盾，也是扩展定理的检查清单：构造任意维分布族，先验「低维能否退回」。

## 5 分布函数族的深入实例

抽象的「族」概念在具体过程上会「长出」具体的形状——看三个例子，分布函数族就从名词变成了画面。

### 例：独立增量过程的有限维分布

独立增量过程（泊松、维纳）的有限维分布有特殊结构：对 $t_1 < \cdots < t_n$，把 $X(t_k)$ 拆成增量之和

$$X(t_k) = X(t_1) + \sum_{j=2}^{k}\big(X(t_j) - X(t_{j-1})\big)$$

增量独立，故 $n$ 维联合分布 = 各增量分布的乘积。泊松过程的有限维分布是「泊松增量的乘积」，维纳过程的是「正态增量的乘积」——**「独立增量」让 n 维分布从「联合」退化为「乘积」**，这是这两类过程可解析的关键。

### 例：正态过程的有限维分布

正态过程 $(X(t_1), \ldots, X(t_n))$ 服从 $n$ 维正态——由均值向量与协方差矩阵完全决定。这就是「正态过程 = 均值函数 + 协方差函数」的原因，也是高斯过程回归（GPR）的数学地基。

### 例：马尔可夫过程的有限维分布

马尔可夫过程的有限维分布可以由「一维分布 + 转移分布」逐步拼出：

$$P\{X(t_1) \le x_1, \ldots, X(t_n) \le x_n\} = \int P\{X(t_n) \le x_n \mid X(t_{n-1}) = x_{n-1}\}\, dF(x_1, \ldots, x_{n-1})$$

**「马尔可夫性让 n 维分布由一维分布 + 转移核递归生成」**——这就是马尔可夫链只需「初始分布 + 转移矩阵」的原因。

### 三类过程的结构对照

| 过程类型 | n 维分布的结构 | 由什么决定 |
| --- | --- | --- |
| 独立增量 | 增量分布之积 | 增量分布 |
| 正态过程 | n 维正态 | 均值 + 协方差函数 |
| 马尔可夫过程 | 一维 + 转移递归 | 初始分布 + 转移核 |

「分布函数族」不是空架子——它决定了「描述一个过程最少需要多少信息」，也就决定了每种过程「能算多少、好算多少」。

最后回到「从极限到大模型」的主线：大模型的自回归生成（根据上文预测下一个 token）本质是一个「条件分布族」——对每一段历史，给出下一个 token 的条件分布。这与随机过程的「转移核」、马尔可夫链的「转移矩阵」是同一思想：**用条件分布族描述「随时间/序列演化的随机性」**。理解分布函数族，等于拿到了读懂序列模型（HMM、RNN、Transformer 的概率视角）的第一把钥匙。

再补一张「分布函数族 vs 数字特征」的对照，明确两者的分工：

| | 分布函数族 | 数字特征函数 |
| --- | --- | --- |
| 内容 | 一切有限维联合分布 | 均值、方差、相关函数 |
| 信息量 | 完备 | 二阶以内的部分信息 |
| 适用 | 理论定义、严格推导 | 工程应用、信号处理 |
| 对正态过程 | 完整 | 也完整（正态由二阶决定） |

「理论要族、工程要特征」是随机过程描述的基本分工——两者不是竞争而是互补，何时用哪个由问题决定。

## 6 小结

- **分布函数族**：过程在一切时刻组合的联合分布——一维族（单点）、二维族（关联）、n 维族（完备）。
- 一维分布族给「单点信息」，二维起步才能捕捉「时间关联」。
- **一致性条件**：n 维分布的边缘必须退回低维分布——族内自洽。
- **科尔莫戈罗夫扩展定理**：相容的有限维分布族唯一确定一个随机过程（存在性）。
- 实践中「一维分布 + 相关性」通常够用；理论上 n 维族完备描述过程。
