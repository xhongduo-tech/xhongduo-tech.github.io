## 为什么从无偏性开始

矩估计给了答案，MLE 也给了答案——但同一个参数 $\theta$ 可以有无数个估计量（$\bar X$、$X_1$、$\frac{X_1 + X_n}{2}$……），到底该选谁？这需要**评选标准**。第七章后半的主题，就是给估计量打分。第一个、也是最基本的标准：**无偏性（unbiasedness）**——估计量的期望等于被估参数，「平均而言不打偏」。

无偏性是估计量的「及格线」：它保证重复抽样下，估计量的分布以参数为中心，不系统性地高估或低估。第七章用「$S^2$ 的 $n-1$」讲清了无偏的代价与回报；第八章假设检验、第九章回归的系数估计，处处以无偏为前提。<span class="marginnote">无偏性的直观：一个估计量像一把反复使用的尺子，无偏意味着「多次测量的平均 = 真值」，可能有随机误差但无系统性偏差。有偏估计则像一把「刻度错位的尺子」，每次测都差同一个量。无偏性是「系统性正确」，是比「这次碰巧对」更可贵的品质。</span>

## 1 无偏性的定义

**无偏估计量（unbiased estimator）**：设 $\hat\theta = \hat\theta(X_1, \ldots, X_n)$ 是参数 $\theta$ 的估计量，若

$$E[\hat\theta] = \theta$$

对一切可能的 $\theta$ 成立，则称 $\hat\theta$ 为 $\theta$ 的**无偏估计量**；否则称其**有偏**，$E[\hat\theta] - \theta$ 称为**偏差（bias）**。

**例**：总体均值 $\mu$ 的估计量 $\bar X$ 是无偏的——$E[\bar X] = \mu$（期望线性性，无需分布假设）。总体方差 $\sigma^2$ 的估计量 $S^2 = \frac{1}{n-1}\sum(X_i-\bar X)^2$ 是无偏的，而 $B_2 = \frac1n\sum(X_i-\bar X)^2$ 是有偏的（偏差 $-\sigma^2/n$）。<span class="marginnote">「$E[\bar X] = \mu$ 无条件成立」是无偏性的第一个示范：它只需要期望线性性，连独立、正态都不需要。而方差的无偏要麻烦得多——$B_2$ 平均而言偏低 $\sigma^2/n$，这就是矩估计与 MLE 给出 $n$ 版方差时「系统性低估」的数学根源。</span>

## 2 例：为什么除以 n-1

样本方差 $S^2$ 的除数 $n-1$ 是无偏性的经典一课。$B_2 = \frac1n\sum(X_i-\bar X)^2$ 的期望：

$$E[B_2] = \frac{n-1}{n}\sigma^2$$

**低于 $\sigma^2$！** 于是除以 $n-1$ 修正：

$$E\left[\frac{n}{n-1}B_2\right] = E[S^2] = \sigma^2$$

**直觉**：$B_2$ 用 $\bar X$ 代替 $\mu$，而 $\bar X$ 本身就偏离 $\mu$——「离样本均值」平均比「离真均值」小一点，所以 $B_2$ 系统性低估。除以 $n-1$ 恰好补回这一份偏差。<span class="marginnote">「用 $\bar X$ 代替 $\mu$ 会让平方和偏小」可以更直觉地看：样本均值是「让 $\sum(X_i - c)^2$ 最小的 $c$」，所以 $\sum(X_i - \bar X)^2 \le \sum(X_i - \mu)^2$——用样本中心代替真中心，距离平均偏小。$n-1$ 正是对这个「低估」的补偿，它也叫「自由度的损失」。</span>

## 3 无偏性不是唯一标准

**易错点｜辨析：** 无偏性 ≠ 一切。它只是「平均正确」，不保证「这次估计接近真值」。两个无偏估计量里，波动大的那个并不好——这引出下一节「有效性」；一个轻微有偏但方差小很多的估计量，可能整体优于无偏但方差巨大的估计量。**「偏差—方差权衡」是估计理论的永恒主题**：无偏是及格线，不是终点线。<span class="marginnote">「无偏但不稳定」的极端例子：用 $X_1$（第一个观测）估计 $\mu$，它是无偏的（$E[X_1] = \mu$），但方差是 $\sigma^2$，远大于 $\bar X$ 的 $\sigma^2/n$。无偏性只保证「平均位置对」，完全不约束「散布」。所以要等到下一节的「有效性」来补完评选。</span>

**例（无偏估计量的比较）**：$\mu$ 的两个无偏估计 $\bar X$ 与 $X_1$：$E[\bar X] = E[X_1] = \mu$ 都无偏，但 $\mathrm{Var}(\bar X) = \sigma^2/n \ll \mathrm{Var}(X_1) = \sigma^2$——$\bar X$ 更优。评选需要「无偏 + 有效」两个维度。

## 4 公式解析：B₂ 的期望为什么偏低

$E[B_2] = \frac{n-1}{n}\sigma^2$ 的推导是无偏性计算的标准流程，拆开：

$$

E[B_2] = \frac{1}{n}E\left[\sum_i (X_i - \bar X)^2\right] = \frac{1}{n}E\left[\sum_i X_i^2 - n\bar X^2\right]

$$

- **第一步，平方和分解**：$\sum(X_i - \bar X)^2 = \sum X_i^2 - n\bar X^2$（第六章的恒等式）。
- **第二步，逐项期望**：$E[X_i^2] = \sigma^2 + \mu^2$；$E[\bar X^2] = \mathrm{Var}(\bar X) + \mu^2 = \frac{\sigma^2}{n} + \mu^2$。
- **第三步，相减**：$E[B_2] = \frac{1}{n}\left[n(\sigma^2+\mu^2) - n\left(\frac{\sigma^2}{n} + \mu^2\right)\right] = \frac{1}{n}\left[n\sigma^2 - \sigma^2\right] = \frac{n-1}{n}\sigma^2$。

「$E[\bar X^2]$ 含 $\sigma^2/n$」是偏低来源——样本均值自身的波动渗进了方差估计。除以 $n-1$ 后偏差清零，$S^2$ 无偏。

## 5 无偏性的深入讨论

无偏性看起来只是「期望打中目标」，但它背后有一整套构造理论、评估体系与边界条件——这些才让「无偏」成为一个有血有肉的概念。

### 无偏估计的构造：充分统计量

**充分统计量（sufficient statistic）**是携带样本全部信息的统计量：给定充分统计量后，样本的其余部分对参数毫无增量信息。经典结论（Rao–Blackwell 定理）：**把任何无偏估计量对充分统计量取条件期望，得到的仍是无偏估计量，且方差更小**。

**例**：对正态总体的 $\mu$，$\bar X$ 是充分统计量。用「第一个观测 $X_1$」估计 $\mu$（无偏但方差大），对 $\bar X$ 取条件期望 $E[X_1 \mid \bar X] = \bar X$——得到无偏且方差更小的 $\bar X$。**Rao–Blackwell 定理说「无偏估计量总能通过充分统计量改良」**，这解释了为什么好的无偏估计几乎总以充分统计量为基础。

### 无偏性的边界：不可估的参数

有些参数**不存在无偏估计**。例如二项分布 $B(n, p)$ 的 $1/p$：可以证明不存在「对一切 $p$ 无偏」的估计量——因为无偏性要求对参数空间内每个值都「平均打中」，而这个函数在 $p \to 0$ 处无法用有界估计量平均逼出。这类「无偏估计不存在」的案例提醒我们：无偏性是「想有就能有」的奢侈品。

### 渐近无偏：MLE 的入场券

严格无偏是稀有的，统计学家退而求其次接受**渐近无偏（asymptotically unbiased）**：$E[\hat\theta_n] \to \theta$ 当 $n \to \infty$。最大似然估计通常渐近无偏、且在大样本下无偏偏差趋于 0——配合相合性，MLE 在大样本下「足够无偏」。实际中「样本量大时，把有偏估计当无偏用」是常见工程近似。

**易错点｜辨析：** 无偏性针对的是「估计量」（随机变量），不是「估计值」（具体数）。一次抽样的估计值 $\hat\theta(x_1,\ldots,x_n)$ 当然不等于 $\theta$——无偏说的是「平均而言」：反复抽样，估计值的平均趋向 $\theta$。把「无偏」误解为「每次都对」，是无偏性最常见的误读。



## 6 典型例题：无偏性的判断

**例 1（均值）**：$E[X_1] = \mu$——单个观测也是 $\mu$ 的无偏估计（虽然方差大）。$E[(X_1 + X_n)/2] = \mu$——两端平均同样无偏。**无偏不唯一，方差才分高下**。

**例 2（方差的两个估计）**：$B_2 = \frac1n\sum(X_i-\bar X)^2$ 有偏（$E[B_2] = \frac{n-1}{n}\sigma^2$），$S^2 = \frac{n}{n-1}B_2$ 无偏。

**例 3（均匀分布的最大值）**：$X \sim U(0,\theta)$，$\hat\theta = X_{(n)}$。$E[X_{(n)}] = \frac{n}{n+1}\theta \ne \theta$——有偏。修正版 $\frac{n+1}{n}X_{(n)}$ 无偏：$E[\frac{n+1}{n}X_{(n)}] = \theta$。

**例 4（无偏性不保证好）**：用 $X_1$ 估 $\mu$ 无偏但方差 $\sigma^2$；$\bar X$ 无偏且方差 $\sigma^2/n$。两者都无偏，$\bar X$ 明显更优——**无偏只是及格线，有效性才是择优尺**。

这四个例子的共同教训：无偏性是一个「平均性质」，它不能单独评判一个估计量。判断估计量好坏的正确顺序是「先看无偏（是否系统性打偏），再看方差（是否足够集中），最后看样本量（能否相合）」——三条标准（第七章）缺一不可。而「无偏估计不唯一」这件事本身就预告了：选择估计量不是「找无偏的」，而是「在无偏里找方差最小的」。

最后补一个现实提醒：无偏性是一个「频率学派」概念，它依赖「反复抽样取平均」的视角。在贝叶斯视角下，评价估计量看的是「后验分布」而非「抽样分布」，无偏性退居次要。两种视角各有侧重——频率学派问「长期平均是否打中」，贝叶斯问「给定这次数据，参数的后验集中在哪」——理解这个差异，你就能读懂统计文献里「无偏 vs 后验」之争的来龙去脉。

再补一张「无偏估计的修正方法」速查表：

| 有偏估计 | 偏差 | 无偏修正 |
| --- | --- | --- |
| $B_2 = \frac1n\sum(X_i-\bar X)^2$ | $-\sigma^2/n$ | $S^2 = \frac{n}{n-1}B_2$ |
| $X_{(n)}$（$U(0,\theta)$） | $-\theta/(n+1)$ | $\frac{n+1}{n}X_{(n)}$ |
| 样本标准差 $S$ | 微负 | 无简单修正（非线性） |

「找到偏差的解析式，就能构造无偏修正」——但像 $S$ 这类非线性统计量，无偏修正往往不存在或极复杂，这也是「无偏性并非总是可达」的现实注脚。

## 7 小结

- **无偏性**：$E[\hat\theta] = \theta$——估计量平均而言不打偏，是「系统性正确」。
- $\bar X$ 对 $\mu$ 无条件无偏；$S^2$ 对 $\sigma^2$ 无偏（$n-1$ 版），$B_2$（$n$ 版）偏低 $\sigma^2/n$。
- **$n-1$ 的来源**：用 $\bar X$ 代 $\mu$ 使平方和系统性偏小，除以 $n-1$ 补偿这份偏差（自由度损失）。
- 无偏只是及格线：无偏但方差大的估计量未必好，「偏差—方差权衡」永恒存在。
- 评选估计量需要无偏性 + 有效性 + 相合性三个维度，下一节讲后两个。
