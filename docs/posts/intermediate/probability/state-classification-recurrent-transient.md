## 为什么从状态的分类开始

马尔可夫链的状态不是「平起平坐」的：从某个状态出发，有的状态会反复回来（像「家」），有的走了就再难回来（像「驿站」）。判断「从 $i$ 出发是否（几乎必然）会回到 $i$」——**常返（recurrent）**与**暂留（transient）**——是马尔可夫链状态分类的第一课。它决定了链的长期行为：会不会「定居」、能不能有稳态分布。

状态分类是马尔可夫链理论从「计算」转向「结构」的转折点：常返/暂留、周期/非周期、互通/闭集（后续两节）共同决定极限分布与遍历性。它是理解「链最终走到哪、怎么走」的地基。<span class="marginnote">常返与暂留的直观：<strong>常返状态 = 从它出发，最终几乎必然回到它（无限次）；暂留状态 = 从它出发，可能再也不回（回来的总次数有限）</strong>。用概率语言：从 $i$ 出发回到 $i$ 的概率记为 $f_{ii}$，$f_{ii} = 1$ 则常返，$f_{ii} < 1$ 则暂留。</span>

## 1 常返与暂留的定义

设 $\{X_n\}$ 是马尔可夫链，$f_{ii}$ 为「从 $i$ 出发最终回到 $i$」的概率。

- **常返（recurrent）**：$f_{ii} = 1$——从 $i$ 出发几乎必然回到 $i$，且会无限次返回；
- **暂留（transient）**：$f_{ii} < 1$——从 $i$ 出发有正概率不再返回，返回总次数有限（期望有限）。

**判定定理**：设 $N_i$ 为访问 $i$ 的次数，则

- $i$ 常返 ⇔ $P\{N_i = \infty \mid X_0 = i\} = 1$ ⇔ $\sum_{n=0}^\infty p^{(n)}_{ii} = \infty$；
- $i$ 暂留 ⇔ $E[N_i \mid X_0 = i] < \infty$ ⇔ $\sum_{n=0}^\infty p^{(n)}_{ii} < \infty$。

**「回来概率的级数」是常返性的判据**：常返状态被访问无限次（级数发散），暂留状态只被访问有限次（级数收敛）。<span class="marginnote">判定定理的直觉：「$p^{(n)}_{ii}$ 之和」=「访问 $i$ 次数的期望」（每次访问贡献一个 $p^{(n)}_{ii}$）。若期望无穷，说明会无限次回来（常返）；若期望有限，说明终究离开（暂留）。「常返 = 无限次回归」这个判定比 $f_{ii} = 1$ 更便于计算——算级数 $\sum p^{(n)}_{ii}$ 就行。</span>

**例（两状态天气）**：$P = \begin{pmatrix} 0.8 & 0.2 \\ 0.4 & 0.6 \end{pmatrix}$。$\sum_n p^{(n)}_{00}$：$p^{(0)}_{00}=1$，$p^{(1)}_{00}=0.8$，$p^{(2)}_{00}=0.72$，……趋于 $2/3$，级数发散 → 状态 0 常返。直观：两状态都常返（有限状态链无暂留，见下）。

## 2 有限链的性质与分类

**有限状态马尔可夫链的重要结论**：有限状态链中，**至少有一个常返状态**；且暂留状态不可能「永远停留」（最终必然进入常返类并定居）。

**分类法则**：
- 若链的每个状态都能从任何其他状态到达（互通，下一节），则全部状态同为常返或同为暂留；
- 有限状态 + 互通 ⇒ 全部常返；
- 暂留状态存在于「离开后不再回」的链中（如吸收链、无限状态链）。

<span class="marginnote">「有限状态 + 互通 ⇒ 全常返」是一条超实用的结论：只要状态数有限且互相能到达，就不用逐个判断常返性——全链都是常返的。暂留状态通常出现在「有去无回」的结构（吸收态旁、无限状态链的漂移方向）。判断常返/暂留，先看状态有限与否、再看互通结构，多数题秒解。</span>

**例（吸收链）**：状态 0、1、2，其中 2 是吸收态（$p_{22} = 1$），从 0、1 能到 2。则状态 0、1 是暂留（离开后可能不再回），状态 2 常返——有限链有常返态，暂留态最终被吸收。

## 3 常返性在现实中的意义

常返/暂留的区分有直接的实际含义：

- **排队系统**：队长状态的常返性决定「队列是否会清空」——常返则反复清空，暂留则越积越长（不稳定）；
- **随机游走**：一维随机游走是常返的（$f_{00} = 1$），二维也是，三维开始变为暂留——「醉汉找得到家，小鸟找不到」；
- **网页排名（PageRank）**：网页跳转链的常返性决定排名算法是否收敛。

**例（一维随机游走）**：$X_n$ 在整数上随机游走，$\sum_n p^{(n)}_{00} \sim \frac{1}{\sqrt n}$ 发散 → 常返；三维游走 $\sum p^{(n)}_{00}$ 收敛 → 暂留。**维度改变常返性**——这个结论是概率论最著名的「维度奇迹」之一。<span class="marginnote">「醉汉找得到家，小鸟找不到」是随机游走常返性的著名直观：一维、二维随机游走常返（几乎必然回家），三维及以上暂留（有正概率永远不回来）。波利亚 1921 年证明了这个结果。它说明「常返性」是链的深刻几何属性，不只是计算细节——状态空间的结构决定长期命运。</span>

## 4 公式解析：级数判据的直觉

常返性的级数判据 $\sum_n p^{(n)}_{ii}$ 的直觉，拆开：

$$

E[N_i \mid X_0 = i] = \sum_{n=0}^{\infty} p^{(n)}_{ii}

$$

- **第一步，指示函数**：$N_i = \sum_{n=0}^\infty \mathbf{1}\{X_n = i\}$——访问次数 = 各时刻「是否在 $i$」的指示和。
- **第二步，期望线性性**：$E[N_i] = \sum_n E[\mathbf{1}\{X_n = i\}] = \sum_n P\{X_n = i \mid X_0 = i\} = \sum_n p^{(n)}_{ii}$。
- **第三步，判据**：期望无穷 → 无限次访问 → 常返；期望有限 → 有限次访问 → 暂留。

「访问次数的期望 = 返回概率级数」把常返性翻译成可计算的级数。它示范了「指示函数 + 期望线性性」在马尔可夫链里的又一次应用——第四章的技巧在过程世界继续发光。

## 5 状态分类的深入应用与实例

常返/暂留是马尔可夫链长期行为的基石，它们的判定、意义与延伸值得展开。

### 例：级数判据的应用

**例**：一维对称随机游走，$p^{(n)}_{00} \approx \frac{1}{\sqrt{\pi n}}$，$\sum_n p^{(n)}_{00}$ 发散 → 常返；三维游走 $\sum p^{(n)}_{00}$ 收敛 → 暂留。**「维数决定常返性」**——波利亚定理的经典结论。

### 常返与暂留的判定

| 判据 | 常返 | 暂留 |
| --- | --- | --- |
| 回来概率 $f_{ii}$ | 1 | < 1 |
| 返回次数期望 | 无穷 | 有限 |
| 级数 $\sum p^{(n)}_{ii}$ | 发散 | 收敛 |

**「回来概率、返回次数、级数三判据等价」**——用哪个方便用哪个。

### 例：有限链的分类

**例**：有限状态不可约链必常返（状态有限、总能回来）——「有限 + 互通 ⇒ 全常返」是超实用结论。暂留状态只出现在「有去无回」的结构（吸收链、无限链漂移）。

### 应用：排队与游走

| 场景 | 常返性 | 含义 |
| --- | --- | --- |
| 排队队长 | 常返 | 队列反复清空 |
| 排队队长 | 暂留 | 队列越积越长 |
| 一维游走 | 常返 | 几乎必然回家 |
| 三维游走 | 暂留 | 可能永不回家 |

**「常返性决定系统是否『稳定』」**——排队系统稳定与否，就看队长状态是否常返。

**易错点｜辨析：** ① 常返要求「$f_{ii} = 1$」——「概率为 1 地回来」不等于「必定回来」；② 暂留状态「返回次数期望有限」但可能回来很多次——不是「回来一次就走」；③ 有限链必有常返态，别误判「全部暂留」。

## 6 小结

- **常返**：$f_{ii} = 1$，从 $i$ 出发几乎必然无限次返回；**暂留**：$f_{ii} < 1$，返回次数有限。
- **级数判据**：常返 ⇔ $\sum_n p^{(n)}_{ii} = \infty$；暂留 ⇔ 级数收敛——「访问次数期望」的等价。
- 有限状态链至少有一个常返态；有限 + 互通 ⇒ 全常返。
- 实际意义：排队清空、随机游走（1、2 维常返、3 维暂留）、PageRank 收敛。
- 常返/暂留是状态分类的第一层，下一节看「周期与互通」第二层。
