## 为什么从双因素等重复方差分析开始

上一节的无重复双因素只能检验两个主效应。可两个因素常常会**协同发力**：某种品种（A）搭配特定施肥量（B）的产量，比「品种效应 + 施肥效应」之和还高——这种「配合的额外收益」叫**交互作用（interaction）**。要检验它，每个「A 水平 × B 水平」组合必须有多个重复观测——这就是**双因素等重复试验的方差分析**。

交互作用不是锦上添花，而是真实世界的常态：药效因性别而异、材料强度因温度而异、广告效果因平台而异。「是否存在交互」决定了能否「单独讨论各因素」——有显著交互时，必须分组合讨论，单看主效应会误导。本节是方差分析的最高形态，也是读实验文献必须掌握的模型。<span class="marginnote">交互作用的通俗定义：<strong>因素 A 的效应大小是否依赖于因素 B 的水平</strong>。画图看最直观：以 B 为横轴画 A 各水平的响应曲线，曲线若平行则无交互（A 效应在各 B 水平下相同），交叉或发散则有交互。这是数据分析里「交互作用图」的来源。</span>

## 1 模型设定与平方和分解

设因素 A 有 $a$ 个水平、B 有 $b$ 个水平，每个组合重复 $t$ 次观测 $X_{ijk}$（$i=1..a$，$j=1..b$，$k=1..t$）。等重复双因素模型：

$$X_{ijk} = \mu + \alpha_i + \beta_j + \gamma_{ij} + \varepsilon_{ijk}$$

其中 $\gamma_{ij}$ 是**交互项**，$\varepsilon_{ijk} \sim N(0, \sigma^2)$ 独立。总平方和分解为**四块**：

$$S_T = S_A + S_B + S_{A\times B} + S_E$$

- $S_A$、$S_B$：两个主效应；
- $S_{A\times B}$：交互作用（$t\sum_{i,j}(\bar X_{ij\cdot} - \bar X_{i\cdot\cdot} - \bar X_{\cdot j\cdot} + \bar X_{\cdot\cdot\cdot})^2$）；
- $S_E$：纯误差（组内重复间的波动）。

**自由度**：$df_A = a-1$，$df_B = b-1$，$df_{A\times B} = (a-1)(b-1)$，$df_E = ab(t-1)$，四者相加 $= abt - 1$。<span class="marginnote">「交互平方和」的构造：$\bar X_{ij\cdot} - \bar X_{i\cdot\cdot} - \bar X_{\cdot j\cdot} + \bar X_{\cdot\cdot\cdot}$——「单元格均值 − A 均值 − B 均值 + 总均值」，剥掉两个主效应后剩下的，就是「配合的额外偏离」。这是交互项的标准定义，也解释了为什么交互项在加法模型里天然与主效应正交。</span>

## 2 三个检验：主效应 × 2 + 交互

等重复双因素给出**三个** F 检验：

$$F_A = \frac{MS_A}{MS_E} \sim F(a-1,\ ab(t-1)), \qquad F_B = \frac{MS_B}{MS_E} \sim F(b-1,\ ab(t-1))$$

$$F_{A\times B} = \frac{MS_{A\times B}}{MS_E} \sim F\big((a-1)(b-1),\ ab(t-1)\big)$$

三个检验共用误差均方 $MS_E = S_E/[ab(t-1)]$——重复试验给了「纯误差」的独立估计，这正是与无重复设计的本质差别。<span class="marginnote">「有重复才有纯误差」：无重复设计的 $S_E$ 里其实混着交互与误差（无法区分）；有重复后，单元格内部的重复波动 $S_E$ 是纯误差，交互项被干净地分离出来。所以「要不要重复」的决策，本质是「要不要检验交互」——要就重复。</span>

**例**：研究材料配比（A，2 水平）与固化温度（B，3 水平）对强度的影响，每组合重复 3 次。$a=2, b=3, t=3$，$n=18$。算得 $S_A = 60$，$S_B = 120$，$S_{A\times B} = 45$，$S_E = 90$。自由度：$df_A = 1$，$df_B = 2$，$df_{A\times B} = 2$，$df_E = 18 - 6 = 12$。均方：$MS_A = 60$，$MS_B = 60$，$MS_{A\times B} = 22.5$，$MS_E = 7.5$。$F_A = 8$，$F_B = 8$，$F_{A\times B} = 3$。查表 $F_{0.05}(1,12) = 4.75$、$F_{0.05}(2,12) = 3.89$：$F_A, F_B$ 都拒绝对应 $H_0$（主效应显著），$F_{A\times B} = 3 < 3.89$ 不拒绝交互为 0——两因素主效应显著但无交互，可以分别讨论。

## 3 有显著交互时怎么解读

**易错点｜辨析：** 交互显著时，**不能**简单地说「A 有效果」——因为 A 的效果随 B 的水平而变。正确的解读：

有显著交互 → **分开各 B 水平讨论 A 的效应**（或反之），必要时做简单效应分析；
交互不显著 → 主效应的 F 检验可以直接解读；
**主效应显著 ≠ 各水平都好**：有交互时，A 的某个水平在特定 B 下才最优，单独看 A 平均可能误导。

<span class="marginnote">「交互显著时主效应会骗人」的经典例子：药物 A 平均效果不显著（男女平均后抵消），但分组看——对女性有效、对男性有害。如果只报告「平均无效果」，就埋没了真实的交互信息。这也是「为什么现代医学报告总是按性别/年龄分组」的统计根源。</span>

## 4 公式解析：交互项为何「剥两层」

交互平方和的构造是「单元格均值减去两个主效应」的净剩余，拆开：

$$

\bar X_{ij\cdot} - \bar X_{i\cdot\cdot} - \bar X_{\cdot j\cdot} + \bar X_{\cdot\cdot\cdot}

$$

- **第一步，单元格均值**：$\bar X_{ij\cdot}$——该「A 水平 × B 水平」组合的平均响应。
- **第二步，减 A 效应**：$-\bar X_{i\cdot\cdot}$——去掉「A 第 $i$ 水平」整体的位置（它对所有 B 水平一致）。
- **第三步，减 B 效应、加总均值**：$-\bar X_{\cdot j\cdot} + \bar X_{\cdot\cdot\cdot}$——再去掉「B 第 $j$ 水平」的位置，并补回被减两次的总均值。剩余的就是「A、B 各自解释不了的协同偏离」。

「单元格均值 − A 效应 − B 效应 + 总均值」与第七章「矩形概率公式」的加加减减同一血统：都是「容斥」——被减两次的要加回一次。交互项是主效应之后剩下的那块「合谋」。

## 5 交互作用方差分析的深入应用

交互是双因素分析的灵魂，它的识别、解读与实务值得完整展开。

### 例：交互作用的图形识别

**例**：因素 A（2 水平）× 因素 B（3 水平）的响应均值。以 B 为横轴画 A 的两条曲线：

- **平行** → 无交互（A 效应在各 B 水平下相同）；
- **交叉/发散** → 有交互（A 效应随 B 水平而变）。

**「交互作用图看曲线是否平行」**是判断交互的第一直观工具。

### 平方和分解的对照

| 设计 | 平方和分解 | 检验数 |
| --- | --- | --- |
| 无重复 | $S_T = S_A + S_B + S_E$ | 2 |
| 等重复 | $S_T = S_A + S_B + S_{A\times B} + S_E$ | 3 |

**「有重复才有交互项」**——无重复设计的 $S_E$ 混着交互与误差，无法分离。

### 例：有交互时怎么解读

**例**：药物 A 对女性有效、对男性有害——主效应可能「平均后不显著」，但交互显著。正确做法：**分性别分别讨论 A 的效应**（简单效应分析），不能只看主效应。

### 例：等重复的检验表

| 来源 | SS | df | F |
| --- | --- | --- | --- |
| A | $S_A$ | $a-1$ | $MS_A/MS_E$ |
| B | $S_B$ | $b-1$ | $MS_B/MS_E$ |
| A×B | $S_{A\times B}$ | $(a-1)(b-1)$ | $MS_{A\times B}/MS_E$ |
| 误差 | $S_E$ | $ab(t-1)$ | |

**「三个 F 共享 $MS_E$」**——重复试验给了纯误差估计，三个检验各自裁决。

**易错点｜辨析：** ① 交互显著时「主效应不可直接解读」——必须分组讨论；② 无重复设计「检验不了交互」——要检验交互就得重复；③ 交互平方和的构造是「单元格均值 − A − B + 总均值」——容斥原理的四项加减。

## 6 小结

- **等重复双因素模型**：$X_{ijk} = \mu + \alpha_i + \beta_j + \gamma_{ij} + \varepsilon_{ijk}$——多一个交互项 $\gamma_{ij}$。
- **平方和分解** $S_T = S_A + S_B + S_{A\times B} + S_E$——四块，自由度相加 $= abt-1$。
- **三个检验**：$F_A$、$F_B$、$F_{A\times B}$，共用纯误差均方 $MS_E$。
- **交互显著**时不能只看主效应，要分组合讨论（简单效应分析）。
- 交互作用图（曲线平行则无交互）是解读交互的第一可视化工具。
