## 为什么从方差开始

期望回答了「随机变量大概在哪个位置」，可位置相同不代表分布相同：两支队伍平均分都是 80，一支全员 79–81，另一支从 40 到 100——「集中」程度天差地别。衡量这种**离散程度（波动性）**的数字特征，就是**方差（variance）**。它是概率论给「不确定性」量的尺寸，也是统计学里「信噪比」「标准误」「显著性」一切概念的根基。

方差在本书中的地位举足轻重：切比雪夫不等式用它给出「偏离均值多远」的概率界；大数定律、中心极限定理都以方差为尺度；第七章的估计量评估（有效性）比的就是方差大小。可以说，期望与方差是随机变量的「位置 + 尺度」双子星。<span class="marginnote">「用平方来量偏离」是方差的关键设计：为什么不直接用 $E[|X - \mu|]$？因为绝对值不便求导、不便代数运算，而平方既非负又可展开（$E[X^2] - \mu^2$）。代价是方差对离群点极敏感——一个极值就能让方差暴涨。后来统计学家用「绝对偏差」「四分位距」来补救，但方差因数学便利仍是默认首选。</span>

## 1 定义：偏离均值的平方的平均

**方差（variance）**：设随机变量 $X$ 的期望为 $\mu = E[X]$，则

$$\mathrm{Var}(X) = E\left[(X - \mu)^2\right]$$

即**方差 = 偏离均值的平方的期望**。它的算术平方根称为**标准差（standard deviation）**

$$\sigma = \sqrt{\mathrm{Var}(X)}$$

标准差与 $X$ 同量纲，因此比方差更「可读」：身高数据的标准差是「厘米」，方差却是「平方厘米」。

**易错点｜辨析：** 方差是「偏离均值的平方的平均」，不是「偏离均值的平均」。若用 $E[|X - \mu|]$（平均绝对偏差），正负抵消的问题没了，但它不是方差。另一种常见混淆：把「平方的平均」与「平均的平方」搞混——它们恰好差出一个方差，见下一节的计算公式。<span class="marginnote">方差的值永远非负，且 $\mathrm{Var}(X) = 0$ 当且仅当 $X$ 几乎处处等于常数——「零方差 = 无波动」是一条重要的判据，检验估计量是否退化时常用它。</span>

## 2 计算公式：平方的平均 − 平均的平方

方差的计算常用一条展开公式：

$$\mathrm{Var}(X) = E[X^2] - \big(E[X]\big)^2$$

**推导**：$\mathrm{Var}(X) = E[X^2 - 2X\mu + \mu^2] = E[X^2] - 2\mu E[X] + \mu^2 = E[X^2] - \mu^2$。<span class="marginnote">「$E[X^2] - (E[X])^2$」读作「平方的平均减平均的平方」——这个顺口溜是方差的全部记忆点。上一节「期望不穿函数」的教训在这里兑现：$E[X^2] \ne (E[X])^2$，二者的差正是方差。若二者相等，说明 $X$ 没有波动。</span>

**例**：$X$ 取 $-1, 0, 1$，概率各 $1/3$。$E[X] = 0$，$E[X^2] = \frac13 + 0 + \frac13 = \frac23$，故 $\mathrm{Var}(X) = \frac23 - 0 = \frac23$，$\sigma = \sqrt{2/3}$。

## 3 常见分布的方差

用「$E[X^2] - (E[X])^2$」可以系统地推出各分布的方差：

**0-1 分布**：$E[X] = p$，$E[X^2] = p$，$\mathrm{Var}(X) = p(1-p)$；
**二项分布** $B(n,p)$：$\mathrm{Var}(X) = np(1-p)$（第四章会证明，也可由「独立 0-1 之和」推得）；
**泊松分布** $\pi(\lambda)$：$\mathrm{Var}(X) = \lambda$（均值 = 方差）；
**均匀分布** $U(a,b)$：$\mathrm{Var}(X) = \frac{(b-a)^2}{12}$；
**指数分布** $E(\lambda)$：$\mathrm{Var}(X) = \frac{1}{\lambda^2}$（标准差 = 均值）；
**正态分布** $N(\mu,\sigma^2)$：$\mathrm{Var}(X) = \sigma^2$（参数本身就是方差）。<span class="marginnote">记住两个「方差 = 均值」的特例：泊松分布 $\mathrm{Var} = \lambda$，指数分布 $\mathrm{Std} = \mu$。它们都是「散度随位置自动缩放」的分布，在第七章矩估计里会成为检验模型是否合适的小线索（若样本方差明显不等于样本均值，泊松假设存疑）。</span>

**例（二项的方差直觉）**：$B(10, 0.5)$ 的方差 $10 \times 0.25 = 2.5$，$\sigma \approx 1.58$；而 $B(10, 0.1)$ 的方差 $0.9$，$\sigma \approx 0.95$。**$p$ 越接近 0.5，波动越大**——最不确定的硬币波动最剧烈，与直觉吻合。

## 4 公式解析：二项分布方差的拆解

二项分布 $X \sim B(n,p)$ 的方差是「把 $X$ 写成 $n$ 个独立 0-1 之和」的教科书示范：

$$

\mathrm{Var}(X) = \mathrm{Var}(X_1 + \cdots + X_n) = \sum_{i=1}^{n} \mathrm{Var}(X_i) = n\, p(1-p)

$$

- **第一步，分解**：$X = X_1 + \cdots + X_n$，每个 $X_i \sim B(1, p)$ 独立。这是「计数 = 指示变量之和」的又一次登场。
- **第二步，独立方差可加**：$\mathrm{Var}(X_1+\cdots+X_n) = \sum \mathrm{Var}(X_i)$——**这正是独立性的作用**，相关时还要加协方差项（下一节）。
- **第三步，逐项计算**：$\mathrm{Var}(X_i) = p(1-p)$，乘 $n$ 得 $np(1-p)$。

对比「期望的线性性不需要独立」，**方差的可加性必须独立**——这是两者最重要的分界线，也是「为什么相关会改变波动」的数学入口。

## 5 方差的深入辨析与应用

方差是「波动」的标准尺，但它的定义动机、计算方法与直觉值得展开。

### 为什么用平方

| 度量 | 定义 | 缺点 |
| --- | --- | --- |
| 方差 | $E[(X-\mu)^2]$ | 对离群敏感 |
| 平均绝对偏差 | $E[\|X-\mu\|]$ | 不便求导 |
| 极差 | $\max - \min$ | 只用两端 |

**「平方方便代数、绝对偏差更稳健、极差最简」**——方差因「可导 + 可展开」成为默认。

### 例：用「平方的平均减平均的平方」

**例**：$X$ 取 $\{-1, 0, 1\}$ 各 1/3。$E[X] = 0$，$E[X^2] = 2/3$，$\mathrm{Var}(X) = 2/3 - 0 = 2/3$——「平方的平均减平均的平方」一步到位。

### 例：线性变换对方差的影响

**例**：$Y = aX + b$。$\mathrm{Var}(Y) = a^2 \mathrm{Var}(X)$——系数平方提出、平移不影响。$X \sim B(10, 0.5)$（方差 2.5），$Y = 2X + 3$ 的方差 $= 4 \times 2.5 = 10$。

### 方差与风险的直觉

| 分布 | 方差 | 直觉 |
| --- | --- | --- |
| $B(10, 0.5)$ | 2.5 | 最不确定的硬币 |
| $B(10, 0.1)$ | 0.9 | 稀有事件波动小 |
| 常数 | 0 | 无波动 |

**「方差 = 不确定性的量」**——$p$ 居中时最散，越确定波动越小。

**易错点｜辨析：** ① 方差单位是「原单位的平方」——要可读用标准差；② 「平方的平均」与「平均的平方」相差方差——别混；③ 方差的可加性以独立为前提，相关时要加协方差项。

再补一张「常见分布方差」速查：

| 分布 | 方差 |
| --- | --- |
| 0-1 | $p(1-p)$ |
| 二项 | $np(1-p)$ |
| 泊松 | $\lambda$ |
| 均匀 | $(b-a)^2/12$ |
| 指数 | $1/\lambda^2$ |
| 正态 | $\sigma^2$ |

「背熟这张表，方差计算与矩估计都顺手」——第四章汇总表的核心六行。

## 6 小结

- **方差** $\mathrm{Var}(X) = E[(X-\mu)^2] = E[X^2] - (E[X])^2$——「平方的平均减平均的平方」。
- **标准差** $\sigma = \sqrt{\mathrm{Var}(X)}$，与 $X$ 同量纲，更可读。
- 方差非负，$\mathrm{Var}(X) = 0$ ⇔ $X$ 几乎处处为常数。
- 常见方差：二项 $np(1-p)$、泊松 $\lambda$、均匀 $(b-a)^2/12$、指数 $1/\lambda^2$、正态 $\sigma^2$。
- 方差的可加性**以独立为前提**；期望线性性则无条件——「加法随便拆，方差须独立」。
