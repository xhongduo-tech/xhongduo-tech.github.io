## 为什么从 χ² 分布开始

第六章的前半是「统计量」，后半是「抽样分布」——统计量自己的分布。而所有抽样分布的老家，就是**χ² 分布（chi-square distribution）**：**$n$ 个独立标准正态变量平方和**的分布。它之所以无处不在，是因为样本方差（偏离均值的平方和）天然是「一堆标准正态的平方和」，于是 χ² 分布成了「方差类统计量」的通用分布。

χ² 分布在本书中管着三件大事：样本方差的分布（本节）、正态总体方差的区间估计（第七章）、正态总体方差的假设检验与拟合优度检验（第八章）。它在第二章的伏笔——标准正态的平方服从 $\chi^2(1)$——今天正式兑现。<span class="marginnote">χ² 分布由皮尔逊在 1900 年提出，最初用于「拟合优度检验」——检验观察频数与理论频数是否相符。它是统计学史上第一个「以检验为目的」专门设计的分布，也是「卡方检验」这个名字的来源。读音注意：χ 读作「卡」（kai），χ² 是「卡方」。</span>

## 1 定义与记号

**χ² 分布（chi-square distribution）**：设 $X_1, \ldots, X_n$ 相互独立且都服从标准正态分布 $N(0,1)$，则称

$$\chi^2 = X_1^2 + X_2^2 + \cdots + X_n^2$$

服从自由度为 $n$ 的 **χ² 分布**，记作 $\chi^2 \sim \chi^2(n)$。

**自由度（degrees of freedom）** $n$ 是「独立标准正态的个数」，它是 χ² 分布唯一的参数，决定了分布的形状：$n$ 越大，分布越往右移、越接近正态。<span class="marginnote">「自由度」的直观理解：$n$ 个自由变动的标准正态平方，能独立变化的方向有 $n$ 个。但样本方差里的 $\sum(X_i - \bar X)^2$ 因 $\bar X$ 约束，自由度是 $n-1$——「扣掉一个用来估计均值的约束」。这个 $n-1$ 是统计里最著名的自由度，也是样本方差除数 $n-1$ 的另一面。</span>

**χ²(1) 的特例**：$n = 1$ 时 $\chi^2 = X_1^2$（$X_1 \sim N(0,1)$），其密度正是第二章「随机变量的函数的分布」算出的 $\frac{1}{\sqrt{2\pi x}} e^{-x/2}$（$x > 0$）——伏笔兑现。

## 2 密度、期望与方差

χ²(n) 的密度为

$$f(x) = \frac{1}{2^{n/2}\,\Gamma(n/2)}\, x^{n/2 - 1}\, e^{-x/2}, \qquad x > 0$$

其中 $\Gamma(\cdot)$ 是伽马函数。它有两条极重要的数字特征：

- **期望**：$E[\chi^2(n)] = n$；
- **方差**：$\mathrm{Var}(\chi^2(n)) = 2n$。

**「期望 = 自由度、方差 = 2×自由度」**是 χ² 分布的特征方程，也是验证「某量是否像 χ²」的快速判断。<span class="marginnote">期望与方差来自「χ² = $n$ 个独立平方和」：每个 $X_i^2$ 的期望是 1、方差是 2（可验算 $E[X^2]=1$，$E[X^4]=3$），独立相加得 $n$ 与 $2n$。这再次演示了「独立和」的万能推法——不查表也能推特征。</span>

**可加性**：若 $\chi_1^2 \sim \chi^2(n_1)$、$\chi_2^2 \sim \chi^2(n_2)$ 独立，则 $\chi_1^2 + \chi_2^2 \sim \chi^2(n_1 + n_2)$——**自由度相加**。这条可加性在「合并两组样本」时反复使用。

## 3 上侧分位点与查表

χ² 分布的实际使用靠**上侧分位点（upper quantile）**：对 $0 < \alpha < 1$，称满足

$$P\{\chi^2 > \chi_\alpha^2(n)\} = \alpha$$

的 $\chi_\alpha^2(n)$ 为 χ² 分布的上 $\alpha$ 分位点。教材附表给出常用 $\alpha$ 下的 $\chi_\alpha^2(n)$。<span class="marginnote">χ² 表与正态表的方向相反：正态表给 $\Phi(z)$（左尾累积），χ² 表给「右尾概率 = $\alpha$」对应的分位点。查表时先定自由度 $n$ 与显著性水平 $\alpha$，再读交叉值。由于 χ² 分布不对称，左右两侧的分位点不同，双侧情形要分别查 $\chi^2_{\alpha/2}(n)$ 与 $\chi^2_{1-\alpha/2}(n)$。</span>

**例**：查表得 $\chi^2_{0.05}(10) \approx 18.31$——自由度为 10 的 χ² 变量超过 18.31 的概率是 5%。

## 4 公式解析：为什么期望 = 自由度

χ²(n) 的期望 $n$ 是「独立和」推法的又一次示范，拆开看：

$$

E[\chi^2(n)] = E\left[\sum_{i=1}^n X_i^2\right] = \sum_{i=1}^n E[X_i^2] = \sum_{i=1}^n 1 = n

$$

- **第一步，期望线性性**：和式的期望 = 期望之和，无条件成立。
- **第二步，$E[X_i^2]$ 是多少**：$\mathrm{Var}(X_i) = E[X_i^2] - (E[X_i])^2$，而 $X_i \sim N(0,1)$，$\mathrm{Var} = 1$、$E[X_i] = 0$，故 $E[X_i^2] = 1$。
- **第三步，求和**：$n$ 个 1 相加得 $n$。

「标准正态平方的期望是 1」是全部推演的核心。方差 $2n$ 同理需要 $E[X^4] = 3$（标准正态的四阶矩），可后续用矩法验证。**把「独立和」当作 χ² 的算术工具，期望方差随手可推**。

## 5 χ² 分布的深入应用与实例

χ² 分布是「方差类推断」的通用分布，它的构造、性质与应用值得展开。

### 例：从标准正态平方开始

**例**：$Z_1, Z_2, Z_3 \sim N(0,1)$ 独立，$Q = Z_1^2 + Z_2^2 + Z_3^2 \sim \chi^2(3)$。$E[Q] = 3$，$\mathrm{Var}(Q) = 6$。**「χ²(n) = n 个独立标准正态平方和」**是它的唯一构造。

### χ² 分布的性质速查

| 性质 | 内容 |
| --- | --- |
| 支撑 | $x > 0$ |
| 期望 | $n$ |
| 方差 | $2n$ |
| 可加性 | $\chi^2(n_1)+\chi^2(n_2) = \chi^2(n_1+n_2)$ |
| $n \to \infty$ | 近似正态 |

**「均值 $n$、方差 $2n$、可加」**是 χ² 的三张名片。

### 例：样本方差的分布应用

**例**：$X_1, \ldots, X_{16} \sim N(\mu, \sigma^2)$，$s^2 = 25$。$\frac{15 \times 25}{\sigma^2} \sim \chi^2(15)$。求「$\sigma^2 > 30$」的概率：$P\{\frac{375}{\sigma^2} < 12.5\} = P\{\chi^2(15) < 12.5\} \approx 0.36$——用 χ² 给方差做概率陈述。

### 应用：方差区间与检验

| 用途 | 统计量 |
| --- | --- |
| 方差置信区间 | $\frac{(n-1)S^2}{\chi^2_{\alpha/2}}$、$\frac{(n-1)S^2}{\chi^2_{1-\alpha/2}}$ |
| 方差检验 | $\frac{(n-1)S^2}{\sigma_0^2}$ |
| 拟合优度 | $\sum \frac{(f-e)^2}{e}$ |

**「凡涉及方差的推断，几乎都落在 χ² 上」**——第七章、第八章的方差工具全以它为基础。

**易错点｜辨析：** ① 自由度 $n-1$ 而非 $n$（样本方差吃一个自由度）；② χ² 分布不对称，双侧区间的上下分位点都要查；③ χ² 检验对正态性敏感——非正态总体的样本方差不再服从 χ²。

## 6 小结

- **χ² 分布** $\chi^2(n)$ = $n$ 个独立标准正态平方之和，自由度 $n$ 决定形状。
- 密度含伽马函数，$x > 0$；**期望 $n$、方差 $2n$**——特征方程。
- **可加性**：独立 χ² 之和自由度相加，合并样本时用。
- **上侧分位点** $\chi^2_\alpha(n)$ 满足 $P\{\chi^2 > \chi^2_\alpha(n)\} = \alpha$，查表方向与正态相反。
- 样本方差与 χ² 的关系是下一节 $t$、$F$ 分布及第七章方差区间估计的桥梁。
