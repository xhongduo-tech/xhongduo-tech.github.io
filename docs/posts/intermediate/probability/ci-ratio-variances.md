## 为什么从两个正态总体方差比的区间估计开始

双总体比较的第二站：**比较两个总体的方差 $\sigma_1^2$ 与 $\sigma_2^2$**。与均值差「相减」不同，方差比较用的是「**相除**」——$\sigma_1^2/\sigma_2^2$，因为方差是「平方单位」，用比才能消除量纲。这个比值的推断工具是第六章的 **F 分布**：两个独立 χ² 之比。

方差比的区间估计在实务里非常关键：它回答「两条产线谁的波动更大」「两组数据的稳定性是否可比」，也是上一节「合并方差 t」能否使用的**前提检验**（方差相等性）的区间版。第八章的 F 检验、第九章方差分析的「方差齐性」检查，都从这里出发。<span class="marginnote">「方差比较用比而不用差」的理由：方差带着量纲的平方（如 mm²），差的量纲无法解释；而比值 $\sigma_1^2/\sigma_2^2$ 无量纲，「谁的波动大几倍」一目了然。这也决定了它的分布是 F 而非正态——比值天然是「两个 χ² 之比」的形状。</span>

## 1 方差比的置信区间

设 $X_1,\ldots,X_{n_1} \sim N(\mu_1, \sigma_1^2)$ 与 $Y_1,\ldots,Y_{n_2} \sim N(\mu_2, \sigma_2^2)$ 独立，$S_1^2$、$S_2^2$ 为样本方差。由第六章：

$$\frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1 - 1,\ n_2 - 1)$$

取 $F_{1-\alpha/2}(n_1-1, n_2-1)$ 与 $F_{\alpha/2}(n_1-1, n_2-1)$ 使

$$P\left\{F_{1-\alpha/2} \le \frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \le F_{\alpha/2}\right\} = 1 - \alpha$$

反解得 $\sigma_1^2/\sigma_2^2$ 的置信区间：

$$\left(\frac{S_1^2}{S_2^2}\cdot\frac{1}{F_{\alpha/2}(n_1-1, n_2-1)},\ \ \frac{S_1^2}{S_2^2}\cdot\frac{1}{F_{1-\alpha/2}(n_1-1, n_2-1)}\right)$$

<span class="marginnote">左尾分位点 $F_{1-\alpha/2}$ 用「倒数对称」从右尾表读出：$F_{1-\alpha/2}(n_1-1, n_2-1) = 1/F_{\alpha/2}(n_2-1, n_1-1)$——查表时把两个自由度对调再取倒数。这是 F 分布最常用的查表技巧，第八章方差比检验、第九章方差分析都会用到。</span>

**例**：两批材料各测 $n_1 = 12$、$n_2 = 10$，$s_1^2 = 0.8$、$s_2^2 = 0.5$。95% 置信区间：$F_{0.025}(11, 9) = 3.91$，$F_{0.975}(11, 9) = 1/F_{0.025}(9, 11) = 1/3.59 = 0.279$。则

$$\frac{0.8}{0.5}\cdot\frac{1}{3.91} = 0.409, \qquad \frac{0.8}{0.5}\cdot\frac{1}{0.279} = 5.73$$

$\sigma_1^2/\sigma_2^2$ 的 95% 区间约 $(0.409, 5.73)$——**包含 1，不能拒绝两方差相等**。

## 2 区间是否包含 1

方差比的置信区间有一个比「含不含 0」更自然的判据：**含不含 1**。

- 区间包含 1：$\sigma_1^2/\sigma_2^2$ 可能等于 1，两方差可能相等；
- 区间整体大于 1：$\sigma_1^2 > \sigma_2^2$，第一个总体波动更大；
- 区间整体小于 1：$\sigma_1^2 < \sigma_2^2$，第一个总体波动更小。

**例（接上）**：区间 $(0.409, 5.73)$ 包含 1，所以数据不足以证明两批材料波动不同。<span class="marginnote">「均值差看 0、方差比看 1」是双总体区间判读的口诀：均值差是相减（差为 0 表示相等），方差比是相除（比为 1 表示相等）。记住这个对照，第八章两类检验的「零假设值」也不会再搞混——z/t 检验的原假设是 $\mu_1-\mu_2 = 0$，F 检验的原假设是 $\sigma_1^2/\sigma_2^2 = 1$。</span>

## 3 与均值推断的关系：方差齐性检查

方差比的区间估计还有一个重要应用：**为上一节「合并方差 t」做前提检查**。

用合并方差 t 区间/检验时，前提是 $\sigma_1^2 = \sigma_2^2$。用方差比区间验证这个前提：若 $\sigma_1^2/\sigma_2^2$ 的置信区间包含 1，则方差相等假设合理，可以用合并方差；若区间明显偏离 1，则方差不等，应改用 Welch 方法。<span class="marginnote">「先查方差齐性，再选均值比较方法」是双总体分析的规范流程——虽然统计学家常提醒「方差齐性检验本身也不完美」（样本小时检验力不足），但教材与经典流程仍以它为第一步。第八章 F 检验给出这一步的正式检验版，本节是它的区间版。</span>

**易错点｜辨析：** 方差比区间公式中分子的自由度与分母的自由度**不可颠倒**——$F(n_1-1, n_2-1)$ 的第一个参数永远对应分子 $S_1^2$、第二个对应分母 $S_2^2$。若你写成了 $F(n_2-1, n_1-1)$，分位点数值就错了。查表与代入时都按「分子→第一自由度」核对。

## 4 公式解析：反解时如何用倒数对称

方差比区间的反解流程有一个 F 分布专属的技巧，拆开：

$$

F_{1-\alpha/2}(n_1-1, n_2-1) = \frac{1}{F_{\alpha/2}(n_2-1, n_1-1)}

$$

- **第一步，原始区间**：枢轴量 $Q = \frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1-1, n_2-1)$ 落在 $[F_{1-\alpha/2}, F_{\alpha/2}]$，概率 $1-\alpha$。
- **第二步，反解 $\sigma_1^2/\sigma_2^2$**：$Q \le F_{\alpha/2} \iff \frac{\sigma_1^2}{\sigma_2^2} \ge \frac{S_1^2}{S_2^2}\cdot\frac{1}{F_{\alpha/2}}$；$Q \ge F_{1-\alpha/2}$ 给出上限方向。
- **第三步，左尾分位点**：$F_{1-\alpha/2}$（左尾）通常不在表上，用倒数对称换算成 $1/F_{\alpha/2}(n_2-1, n_1-1)$——分子分母对调、分位点方向不变。

「左尾靠倒数、查表只查右尾」是 F 分布反解的全部技巧。每一步都在把「含 $F$ 的不等式」翻译成「含 $\sigma_1^2/\sigma_2^2$ 的区间」。

## 5 方差比区间估计的深入应用

方差比区间是「比较波动」的工具，它的判读、查表与实务值得展开。

### 例：完整计算

**例**：$n_1 = 12$、$n_2 = 10$，$s_1^2 = 0.8$、$s_2^2 = 0.5$。$F_{0.025}(11, 9) = 3.91$、$F_{0.975}(11, 9) = 1/F_{0.025}(9, 11) = 1/3.59 = 0.279$：

$$\frac{0.8}{0.5}\cdot\frac{1}{3.91} = 0.409, \qquad \frac{0.8}{0.5}\cdot\frac{1}{0.279} = 5.73$$

区间 $(0.409, 5.73)$ 含 1 → 不能拒绝方差相等。

### 判读口诀

| 区间 | 结论 |
| --- | --- |
| 含 1 | 方差可能相等 |
| 全 > 1 | 第一总体波动大 |
| 全 < 1 | 第二总体波动大 |

**「方差比看 1、均值差看 0」**——两类区间的判读口诀。

### 查表技巧

$F_{1-\alpha/2}(n_1-1, n_2-1) = \frac{1}{F_{\alpha/2}(n_2-1, n_1-1)}$——**「左尾靠倒数、自由度对调」**是 F 表查询的标准技巧。

### 应用：方差齐性检查

方差比区间是「合并方差 t」的前提检查：区间含 1 → 可用合并方差；区间偏离 1 → 改用 Welch。**「先查方差齐性，再选均值方法」**是双总体分析的标准流程。

**易错点｜辨析：** ① 自由度顺序「分子→第一」不可颠倒；② 双侧的左右分位点不同（F 不对称）；③ 方差比区间对正态性敏感——非正态样本方差比不再服从 F。

再补一张「均值差 vs 方差比」区间对照：

| | 均值差 | 方差比 |
| --- | --- | --- |
| 运算 | 相减 | 相除 |
| 判读 | 看 0 | 看 1 |
| 分布 | z/t | F |
| 前提 | 方差齐性 | 正态性 |

「差看 0、比看 1」——两类双总体区间的判读口诀。

## 6 小结

- **方差比区间**：$\frac{S_1^2}{S_2^2}\left(\frac{1}{F_{\alpha/2}(n_1-1,n_2-1)},\ \frac{1}{F_{1-\alpha/2}(n_1-1,n_2-1)}\right)$。
- 枢轴量 $\frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1-1, n_2-1)$；自由度顺序「分子→第一」不可颠倒。
- **判读看 1**：区间含 1 则方差可能相等，整体 > 1 则第一总体波动大。
- 左尾分位点用倒数对称 $F_{1-\alpha/2}(n_1-1,n_2-1) = 1/F_{\alpha/2}(n_2-1,n_1-1)$ 查表。
- 方差比区间是「合并方差 t」的方差齐性前提检查，也是第八章 F 检验的区间版。
