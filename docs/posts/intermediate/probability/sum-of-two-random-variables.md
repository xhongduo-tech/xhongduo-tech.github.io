## 为什么从 Z = X + Y 开始

第二章我们学过 $Y = g(X)$ 的分布——一个变量经过函数变换。现在问题升级：**已知 $(X,Y)$ 的联合分布，求 $Z = X + Y$ 的分布**。两个随机变量的和是「函数的分布」里最重要的一类，因为现实里到处都是「和」：一组测量值的总和、多次射击的总环数、若干独立误差的总误差。而「独立随机变量之和」更是第五章大数定律与中心极限定理的直接研究对象。

本节的核心工具是**卷积（convolution）**——独立变量之和的密度等于边缘密度的卷积。卷积在信号处理、图像处理、神经网络里无处不在，而概率论给了它一个最自然的直觉：**把一堆概率「滑过、相乘、求和」**。<span class="marginnote">卷积是本章（乃至全书）最出圈的数学工具：深度学习里的卷积网络、信号处理里的滤波、图像模糊——名称都来自同一个积分运算。在概率论里它「出生」得朴素：独立变量之和的密度公式 $\int f_X(z-y) f_Y(y)\,dy$，就是一次卷积。</span>

## 1 一般公式：卷积积分

设 $(X,Y)$ 的联合密度为 $f(x,y)$，则 $Z = X + Y$ 的密度为

$$f_Z(z) = \int_{-\infty}^{+\infty} f(x,\ z-x)\, dx = \int_{-\infty}^{+\infty} f(z-y,\ y)\, dy$$

**推导思路**：先求分布函数 $F_Z(z) = P\{X + Y \le z\} = \iint_{x+y \le z} f(x,y)\,dx\,dy$，再对 $z$ 求导。<span class="marginnote">公式直觉：$Z = z$ 的「机会」来自所有「$X = x$ 且 $Y = z - x$」的组合。把 $x$ 固定，$Y$ 必须取 $z - x$；把所有 $x$ 的可能性积分相加，就得到 $Z = z$ 的密度。一条斜线 $x + y = z$ 上的联合密度「扫」成 $z$ 轴上的一个值。</span>

**独立情形（卷积公式）**：若 $X$ 与 $Y$ 独立，则 $f(x,y) = f_X(x) f_Y(y)$，公式简化为

$$f_Z(z) = \int_{-\infty}^{+\infty} f_X(z - y)\, f_Y(y)\, dy = \int_{-\infty}^{+\infty} f_X(x)\, f_Y(z - x)\, dx$$

这是**卷积（convolution）**的标准形式，记作 $f_Z = f_X * f_Y$。

## 2 独立正态之和仍正态

最著名的结论：**独立正态变量之和仍服从正态分布**。设 $X \sim N(\mu_1, \sigma_1^2)$、$Y \sim N(\mu_2, \sigma_2^2)$ 且独立，则

$$X + Y \sim N(\mu_1 + \mu_2,\ \sigma_1^2 + \sigma_2^2)$$

均值相加、方差相加——正态的「可加性」是它在统计分析中如此得宠的原因之一。推广到 $n$ 个：独立正态变量之和仍是正态，均值与方差分别求和。<span class="marginnote">这条「正态 + 正态 = 正态」是一条强结论，值得记住它的两个前提：<strong>独立</strong>与<strong>正态</strong>。缺一个都不成立——两个相关正态之和仍正态（但方差项要加协方差），而两个独立非正态变量的和通常不是正态（除非样本量足够大，由中心极限定理接管）。</span>

**例**：$X \sim N(1, 4)$，$Y \sim N(2, 9)$ 独立，则 $X + Y \sim N(3, 13)$，$X - Y \sim N(-1, 13)$。注意 $X - Y = X + (-Y)$，$-Y \sim N(-2, 9)$，方差仍相加（方差无方向）。

## 3 独立泊松、二项的可加性

「独立之和」在离散世界里同样有漂亮的结论：

**泊松可加**：$X \sim \pi(\lambda_1)$、$Y \sim \pi(\lambda_2)$ 独立 ⇒ $X + Y \sim \pi(\lambda_1 + \lambda_2)$；
**二项可加**：$X \sim B(n_1, p)$、$Y \sim B(n_2, p)$ 独立且 $p$ 相同 ⇒ $X + Y \sim B(n_1 + n_2, p)$；
**$\chi^2$ 可加**：$X \sim \chi^2(n_1)$、$Y \sim \chi^2(n_2)$ 独立 ⇒ $X + Y \sim \chi^2(n_1 + n_2)$（第六章主角）。

三条「可加性」共享同一个直觉：**独立计数/独立波动合起来，参数相加**。这也解释了二项分布名字的由来——$B(n_1,p) + B(n_2,p) = B(n_1+n_2,p)$，与「做两批独立试验」等价。<span class="marginnote">可加性还有一个统一点：这些都来自「矩母函数相乘」。$X+Y$ 的矩母函数是 $M_X(t)M_Y(t)$，若 $M_X(t)M_Y(t)$ 恰好仍是某族分布的形状（正态、泊松、二项、$\chi^2$），就得到可加性结论。第七章参数估计里，独立同分布样本的和 $S_n$ 的结构也全靠这些可加性。</span>

## 4 公式解析：连续卷积的计算

以 $X, Y$ 独立且都服从 $U(0,1)$ 为例，求 $Z = X + Y$ 的密度。这是卷积的经典例题：

$$

f_Z(z) = \int_{-\infty}^{+\infty} f_X(x)\, f_Y(z - x)\, dx

$$

- **第一步，确定被积函数非零区间**：$f_X(x) \ne 0$ 要求 $0 \le x \le 1$；$f_Y(z-x) \ne 0$ 要求 $0 \le z - x \le 1$，即 $z - 1 \le x \le z$。
- **第二步，取交集**：被积函数非零 ⇔ $x \in [0,1] \cap [z-1, z]$。$z$ 不同，交集不同，分段讨论：
  - $0 \le z \le 1$：交集 $[0, z]$，$f_Z(z) = \int_0^z 1\,dx = z$；
  - $1 < z \le 2$：交集 $[z-1, 1]$，$f_Z(z) = \int_{z-1}^{1} 1\,dx = 2 - z$；
  - 其余：交集为空，$f_Z(z) = 0$。
- **第三步，拼装**：$f_Z(z) = \begin{cases} z, & 0 \le z \le 1 \\ 2 - z, & 1 < z \le 2 \\ 0, & \text{其他} \end{cases}$——**三角分布（三角形密度）**。

两个均匀变量之和的密度是三角形，这是卷积的第一课：**分段的关键是找出积分区间的交集随 $z$ 如何变化**。画图辅助，边界一目了然。

**易错点｜辨析：** 卷积里 $f_X(z-y)$ 中的自变量是 $z-y$ 而非 $y$——代入时别写反。另一常见错误：忘了分段。只要 $X$、$Y$ 的支撑不是全直线，卷积就必须按 $z$ 的取值区间分段；若不管分段直接积分，会得到荒谬的负概率。

## 5 和分布的深入应用与实例

「两个随机变量之和」是概率论的高频操作，卷积、可加性、计算技巧值得展开。

### 例：均匀之和的卷积

**例**：$X, Y \sim U(0,1)$ 独立，$Z = X + Y$。卷积分段：

$$f_Z(z) = \begin{cases} z, & 0 \le z \le 1 \\ 2 - z, & 1 < z \le 2 \end{cases}$$

**「两个均匀之和是三角分布」**——卷积的第一课，分段的关键是积分区间交集。

### 例：正态可加性

**例**：$X \sim N(1, 4)$、$Y \sim N(2, 9)$ 独立，$X + Y \sim N(3, 13)$——「均值方差各相加」。$X - Y \sim N(-1, 13)$——方差仍相加（方差无方向）。

### 可加性家族

| 分布 | 可加性 |
| --- | --- |
| 正态 | 均值方差相加 |
| 泊松 | 参数相加 |
| 二项（同 $p$） | $n$ 相加 |
| χ² | 自由度相加 |

**「独立同族的和，参数相加」**——可加性是「独立和」最漂亮的推论。

### 例：卷积的几何

卷积 $\int f_X(x) f_Y(z-x) dx$ 是「把 $f_X$ 翻转滑过 $f_Y$，重叠面积作为 $f_Z$」——**「卷积 = 翻转、平移、相乘、积分」**四步，信号处理与概率论共用同一运算。

**易错点｜辨析：** ① 卷积公式独立时才成立——不独立的和要用联合密度 $\int f(x, z-x)dx$；② 分段是卷积的常态——支撑有界就要按 $z$ 分段；③ 「独立正态之和正态」的反面是「独立非正态之和未必正态」——CLT 才给近似。

再补一张「和分布的计算方法」速查：

| 方法 | 适用 |
| --- | --- |
| 卷积 | 独立、连续 |
| 求和 | 独立、离散 |
| 联合积分 | 不独立 |
| 可加性 | 同族独立分布 |

「独立用卷积/求和、不独立用联合、同族看可加」——按条件选方法。

## 6 小结

- **$Z = X + Y$ 的密度**：$f_Z(z) = \int f(x, z-x)\, dx$；独立时是**卷积** $f_Z = f_X * f_Y$。
- **正态可加**：独立正态之和仍正态，均值、方差分别相加。
- **泊松/二项/$\chi^2$ 可加**：独立同族变量之和参数相加，源于矩母函数相乘。
- 卷积计算三步：定非零区间 → 取交集分段 → 逐段积分；画图是分段的关键。
- 「和」的分布是第五章大数定律与中心极限定理的原料。
