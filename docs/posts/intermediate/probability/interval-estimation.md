## 为什么从区间估计开始

点估计用 $\hat\theta$ 猜 $\theta$，可单点总让人不安：这次抽样恰好偏差大怎么办？**区间估计（interval estimation）**换个思路——给出一个区间 $[\hat\theta_1, \hat\theta_2]$，并承诺「这个区间以 95% 的概率覆盖真参数」。区间连同它的置信水平，构成对点估计的「不确定性格外声明」。

区间估计是统计推断的「成熟形态」：它把「估计」从「一个数」升级为「一个带把握的区间」，是科研论文、新闻民调、工程验收里「结论」的标准形式（「支持率 52% ± 3%」「95% 置信区间」）。第七章后半的全部内容，都是把第六章的抽样分布应用到区间构造上。<span class="marginnote">置信区间由内曼在 1937 年严格建立。它的哲学值得反复咀嚼：<strong>「95% 置信区间」不是说「参数有 95% 的概率落在区间里」——参数是固定常数，没有概率</strong>；而是说「反复抽样，约 95% 的区间会盖住参数」。频率学派的概率在「区间」上，不在「参数」上。这一区分是贝叶斯与频率学派的著名分水岭。</span>

## 1 置信区间与置信水平

**置信区间（confidence interval）**：设总体分布含未知参数 $\theta$，由样本构造两个统计量 $\hat\theta_1$、$\hat\theta_2$（$\hat\theta_1 < \hat\theta_2$），若对给定的 $0 < \alpha < 1$ 有

$$P\{\hat\theta_1 \le \theta \le \hat\theta_2\} = 1 - \alpha$$

则称随机区间 $[\hat\theta_1, \hat\theta_2]$ 为 $\theta$ 的**置信水平为 $1 - \alpha$ 的置信区间**。$\hat\theta_1$、$\hat\theta_2$ 分别叫**置信下限**与**置信上限**，$1 - \alpha$ 叫**置信水平（confidence level）**。<span class="marginnote">置信区间里的两个端点是随机变量（样本的函数），所以「区间覆盖参数」是一个随机事件，概率 $1-\alpha$ 有意义。而参数 $\theta$ 本身是固定的未知常数——它要么在区间里，要么不在，「概率」不适用于参数。把「随机的是区间、固定的是参数」这层关系捋清，就抓住了置信区间的全部哲学。</span>

**例**：$X \sim N(\mu, 1)$，$\mu$ 未知。因为 $\bar X \sim N(\mu, 1/n)$，标准化后 $\frac{\bar X - \mu}{1/\sqrt n} \sim N(0,1)$，于是

$$P\left\{-1.96 \le \frac{\bar X - \mu}{1/\sqrt n} \le 1.96\right\} = 0.95 \implies P\left\{\bar X - \frac{1.96}{\sqrt n} \le \mu \le \bar X + \frac{1.96}{\sqrt n}\right\} = 0.95$$

区间 $[\bar X \pm 1.96/\sqrt n]$ 就是 $\mu$ 的 95% 置信区间。

## 2 置信区间的解读与常见误区

**正确解读**：反复独立抽样，构造的约 95% 的区间会包含 $\mu$——「置信水平是长期频率」。

**易错点｜辨析：** 三个常见误区——

1. **「$\mu$ 有 95% 的概率落在这个区间里」✗**：$\mu$ 是固定常数，区间已由本次抽样算出（不再是随机），只能说「本次抽样得到的区间恰是那 95% 之一」；
2. **「区间越窄越好」不绝对**：窄区间需要大样本或高精度，但保证的是「覆盖概率」而非「窄」——过度追求窄可能牺牲置信水平；
3. **「95% 置信区间覆盖 95% 的数据」✗**：置信区间覆盖的是**参数**，不是数据。数据落在哪是另一回事（那是预测区间）。<span class="marginnote">「置信区间 vs 预测区间」是另一个常被混淆的边界：置信区间承诺「参数大概在这」，预测区间承诺「下一个观测值大概落在这」。预测区间永远比置信区间宽（它要同时容纳参数不确定性与个体波动）。第九章回归的置信区间与预测带，正是这对概念的第一次正面对决。</span>

## 3 区间估计的基本步骤

构造置信区间的通用流程（枢轴量法）：

1. **选枢轴量**：找一个含未知参数 $\theta$、但分布已知且不含其他未知参数的样本函数 $Q(X_1, \ldots, X_n; \theta)$——叫**枢轴量（pivot）**；
2. **写区间**：利用 $Q$ 的分布，找 $a < b$ 使 $P\{a \le Q \le b\} = 1 - \alpha$；
3. **反解**：把 $a \le Q \le b$ 反解成 $\hat\theta_1 \le \theta \le \hat\theta_2$，即得置信区间。

**枢轴量是区间估计的核心工具**：$\frac{\bar X - \mu}{\sigma/\sqrt n}$（方差已知时）是 $\mu$ 的枢轴量，$\frac{\bar X - \mu}{S/\sqrt n}$（方差未知时）也是——它们分布已知（$N(0,1)$ 或 $t$），含 $\mu$ 但可反解。<span class="marginnote">「枢轴量」这个名字取自机械工程：枢轴（pivot）固定住一个点，让其余部分可以转动。统计里的枢轴量同样「固定住分布、转动反解参数」——它的分布不依赖未知参数，从而可以查表定分位点，再反解出参数区间。第六章的抽样分布定理，就是枢轴量的工厂。</span>

**例**：方差已知的正态均值。枢轴量 $Z = \frac{\bar X - \mu}{\sigma/\sqrt n} \sim N(0,1)$。取 $z_{\alpha/2}$ 使 $P\{|Z| \le z_{\alpha/2}\} = 1-\alpha$，反解得

$$\bar X \pm z_{\alpha/2}\,\frac{\sigma}{\sqrt n}$$

## 4 公式解析：置信区间的反解流程

以方差已知的正态均值置信区间为例，走一遍「枢轴量 → 反解」：

$$

\left[\bar X - z_{\alpha/2}\frac{\sigma}{\sqrt n},\ \ \bar X + z_{\alpha/2}\frac{\sigma}{\sqrt n}\right]

$$

- **第一步，定枢轴量**：$Z = \frac{\bar X - \mu}{\sigma/\sqrt n} \sim N(0,1)$——分布已知，含 $\mu$ 但可解。
- **第二步，定分位点**：$P\{|Z| \le z_{\alpha/2}\} = 1 - \alpha$，$z_{\alpha/2}$ 是标准正态的上 $\alpha/2$ 分位点（$\alpha = 0.05$ 时 $z_{0.025} = 1.96$）。
- **第三步，反解**：$-z_{\alpha/2} \le \frac{\bar X - \mu}{\sigma/\sqrt n} \le z_{\alpha/2}$ 等价于 $\bar X - z_{\alpha/2}\frac{\sigma}{\sqrt n} \le \mu \le \bar X + z_{\alpha/2}\frac{\sigma}{\sqrt n}$。

「随机区间以概率 $1-\alpha$ 覆盖参数」的完整链条：枢轴量分布 → 分位点 → 反解。这个三连是第七章全部区间估计（均值、方差、双总体）的统一模板。

## 5 区间估计的深入应用与实例

置信区间的「枢轴量法」在各类参数上通用，它的步骤、解读与边界值得展开。

### 例：枢轴量法的完整流程

**例**：方差已知的正态均值。枢轴量 $Z = \frac{\bar X - \mu}{\sigma/\sqrt n} \sim N(0,1)$，取 $z_{\alpha/2}$ 使 $P\{|Z| \le z_{\alpha/2}\} = 1-\alpha$，反解：

$$\bar X \pm z_{\alpha/2}\frac{\sigma}{\sqrt n}$$

**「枢轴量 → 分位点 → 反解」**三连是区间估计的统一模板。

### 各类参数的枢轴量

| 参数 | 枢轴量 | 分布 |
| --- | --- | --- |
| $\mu$（$\sigma$ 已知） | $\frac{\bar X - \mu}{\sigma/\sqrt n}$ | $N(0,1)$ |
| $\mu$（$\sigma$ 未知） | $\frac{\bar X - \mu}{S/\sqrt n}$ | $t(n-1)$ |
| $\sigma^2$ | $\frac{(n-1)S^2}{\sigma^2}$ | $\chi^2(n-1)$ |
| $\mu_1-\mu_2$ | 均值差标准化 | $N/t$ |
| $p$ | $\frac{\hat p - p}{\sqrt{p(1-p)/n}}$ | 近似 $N$ |

**「每个参数都有一个枢轴量」**——枢轴量是区间估计的公共钥匙。

### 区间的三个常见误读

1. **「参数有 95% 概率落在区间里」✗**——参数固定，随机的是区间；
2. **「区间覆盖 95% 的数据」✗**——覆盖的是参数不是数据；
3. **「区间越窄越准」不绝对**——窄区间可能以牺牲置信水平为代价。

### 例：区间与样本量的联动

**例**：区间半宽 $\Delta = z_{\alpha/2}\sigma/\sqrt n$。想减半 $\Delta$，$n$ 乘 4——「精度换样本量」的平方代价。样本量公式 $n \ge (z_{\alpha/2}\sigma/\Delta)^2$ 是实验设计的标准工具。

**易错点｜辨析：** ① 枢轴量必须「分布已知 + 不含其他未知参数」——分布未知就不是枢轴量；② 反解时要小心不等式方向（取倒数翻转）；③ 置信水平与显著性水平配对使用（95% 区间 ↔ 5% 检验）——别混搭。

## 6 小结

- **置信区间** $[\hat\theta_1, \hat\theta_2]$ 以概率 $1-\alpha$ 覆盖参数；**置信水平**是长期覆盖频率。
- 正确解读：随机的是区间、固定的是参数；「参数有 95% 概率落区间内」是错误说法。
- **枢轴量法**：选分布已知的样本函数 → 定分位点 → 反解出参数区间。
- 三个误区：把概率安在参数上、混淆置信区间与数据范围、误把置信区间当预测区间。
- 区间估计是第七章后半的全部主题：单总体均值、方差、双总体比较，一节一节的公式都是这套模板的实例。
