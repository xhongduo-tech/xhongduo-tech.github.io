## 为什么从数字特征函数开始

分布函数族是完整但笨重的描述。工程上更常用的是几个「数字特征函数」——把「族」压缩成**均值函数、方差函数、自相关函数**。就像单个随机变量用均值、方差概括，随机过程用「随 $t$ 变的函数」概括：每个时刻一个中心、一个波动，外加「两个时刻的联动」。

这三个函数是随机过程章（第十一至十三章）的公共地基：泊松过程的均值与相关、平稳过程的「均值常数 + 相关只差 $t-s$」、功率谱密度（第十三章）全部从相关函数出发。它们是「从分布函数族到工程应用」的减负工具。<span class="marginnote">数字特征函数的定位：<strong>均值与方差函数给「每时刻的状态」，相关函数给「不同时刻的关联」</strong>。对正态过程（如维纳、平稳高斯），这三个函数甚至<strong>完全决定</strong>过程分布（正态过程由其均值函数与相关函数唯一确定）——这是三个函数够用的最好理由。</span>

## 1 均值函数与方差函数

**均值函数（mean function）**：

$$\mu_X(t) = E[X(t)], \qquad t \in T$$

描述过程在时刻 $t$ 的「中心位置」。

**方差函数（variance function）**：

$$\sigma_X^2(t) = \mathrm{Var}(X(t)) = E\left[(X(t) - \mu_X(t))^2\right], \qquad t \in T$$

描述过程在时刻 $t$ 的「波动大小」。（也可先定义「平方均值函数」$\psi_X^2(t) = E[X^2(t)]$，则 $\sigma^2(t) = \psi^2(t) - \mu^2(t)$。）

**例**：泊松过程 $X(t) \sim \pi(\lambda t)$，均值函数 $\mu_X(t) = \lambda t$，方差函数 $\sigma_X^2(t) = \lambda t$——都随时间线性增长（泊松的均值 = 方差指纹）。<span class="marginnote">均值与方差函数「固定 $t$ 就是普通数字特征、让 $t$ 动就是函数」——这就是上一节「先固定再动」的构造法。对泊松过程，$\mu_X(t) = \lambda t$ 说明「平均呼叫数随时间线性涨」；$\sigma_X^2(t) = \lambda t$ 说明「波动也随 $t$ 线性涨」——位置越远，不确定性越大。</span>

## 2 自相关函数：过程的「时间记忆」

**自相关函数（autocorrelation function）**：对任意 $s, t$，

$$R_X(s, t) = E\left[X(s)\, X(t)\right], \qquad s, t \in T$$

（教材另定义**协方差函数** $C_X(s, t) = E[(X(s) - \mu(s))(X(t) - \mu(t))] = R_X(s,t) - \mu(s)\mu(t)$。）

**相关函数回答**：「$X(s)$ 与 $X(t)$ 是否联动？」——它是过程「记忆」的度量：

- $R_X(s,t)$ 大：两个时刻强关联，过去影响未来；
- $R_X(s, t) \approx \mu(s)\mu(t)$（协方差 $\approx 0$）：两个时刻无关，过程「失忆」。

**例（独立增量过程）**：泊松过程 $s < t$ 时，$\mathrm{Cov}(X(s), X(t)) = \mathrm{Var}(X(s)) = \lambda s$——只依赖较小时刻 $s$，因为增量独立使「过去完全固化」。<span class="marginnote">相关函数 vs 协方差函数：相关函数 $R = E[X(s)X(t)]$ 是「未中心化」的，协方差函数 $C = R - \mu(s)\mu(t)$ 是「中心化」的。两者差一个均值乘积项。对零均值过程（$\mu \equiv 0$），二者相等——这也是维纳过程、平稳过程常默认零均值的原因：省一个记号。</span>

## 3 例：泊松过程的数字特征

以泊松过程 $X(t)$（强度 $\lambda$）为例，把三个函数一次算清：

- **均值函数**：$\mu_X(t) = \lambda t$；
- **方差函数**：$\sigma_X^2(t) = \lambda t$；
- **协方差函数**：对 $s < t$，$\mathrm{Cov}(X(s), X(t)) = \lambda s$（独立增量）。

**推导**：$X(s)$ 与 $X(t) - X(s)$ 独立，故 $\mathrm{Cov}(X(s), X(t)) = \mathrm{Cov}(X(s), X(s)) + \mathrm{Cov}(X(s), X(t)-X(s)) = \mathrm{Var}(X(s)) + 0 = \lambda s$。<span class="marginnote">这个推导示范了「独立增量」的威力：把 $X(t) = X(s) + (X(t) - X(s))$ 拆成「已发生的」与「新增的」两块，独立性让交叉协方差归零，协方差函数立刻算出。泊松过程的全部统计特性——均值、方差、相关——都从「独立增量 + 泊松分布」两条公理推出，逻辑链极干净。</span>

## 4 公式解析：相关函数与方差函数的关系

相关函数与方差函数是「对角」关系，拆开：

$$

R_X(t, t) = E[X(t)^2] = \psi_X^2(t), \qquad C_X(t, t) = \sigma_X^2(t)

$$

- **第一步，取 $s = t$**：相关函数在「同一时刻」退化为「平方均值」$E[X(t)^2]$。
- **第二步，中心化版本**：协方差函数在 $s = t$ 时退化为方差 $\sigma_X^2(t)$——协方差函数「对角线 = 方差函数」。
- **第三步，对角信息**：相关函数/协方差函数的对角线承载「每时刻的波动」，非对角线承载「两时刻的关联」——一个函数，两种信息。

「协方差函数的对角线是方差函数」是三个数字特征的内在联系：它们不是三个独立对象，而是一个「矩阵的各个部分」——均值是中心、对角线是方差、非对角线是相关。

## 5 过程数字特征的深入应用与实例

均值、方差、相关三个函数是过程的「体检指标」，它们的计算、解读与应用值得展开。

### 例：泊松过程的三个函数

**例**：泊松过程强度 $\lambda$。$\mu_X(t) = \lambda t$、$\sigma_X^2(t) = \lambda t$、$\mathrm{Cov}(s,t) = \lambda\min(s,t)$——**「独立增量 + 泊松」**一次性推出全部特征。

### 三个函数的角色

| 函数 | 回答 | 工程用途 |
| --- | --- | --- |
| $\mu_X(t)$ | 每时刻的中心 | 趋势预测 |
| $\sigma_X^2(t)$ | 每时刻的波动 | 风险估计 |
| $R_X(s,t)$ | 两时刻的关联 | 记忆、谱 |

**「中心、波动、关联」**——过程的三维画像。

### 例：相关函数与过程的记忆

$R_X(s,t)$ 随 $|t-s|$ 衰减快 → 过程「失忆」快、近白噪声；衰减慢 → 记忆长、平滑。**「相关衰减速度 = 记忆长度」**是解读相关函数的第一直觉。

### 例：正态过程由两个函数决定

正态过程的有限维分布完全由 $\mu_X(t)$ 与 $C_X(s,t)$ 决定——**「正态过程 = 两个函数」**是高斯过程回归（GPR）的理论依据。

### 应用：谱分析的入口

宽平稳的「相关只差时差」让 $R_X(\tau)$ 成为单变量函数，从而可做傅里叶变换得功率谱——**「相关函数是谱的时域化身」**，第十三章的全部内容从这里出发。

**易错点｜辨析：** ① 相关函数 $R = E[X(s)X(t)]$ 与协方差函数 $C = R - \mu(s)\mu(t)$ 差一个均值乘积项；② 对角 $C_X(t,t) = \sigma_X^2(t)$——协方差函数的对角线是方差函数；③ 零均值过程 $R = C$——这是常见简化。

## 6 小结

- **均值函数** $\mu_X(t) = E[X(t)]$——过程的「中心线」；**方差函数** $\sigma_X^2(t)$——过程的「摆动」。
- **自相关函数** $R_X(s,t) = E[X(s)X(t)]$——两时刻的联动（过程「记忆」）；协方差函数是它的中心化版本。
- 泊松过程：$\mu(t) = \lambda t$、$\sigma^2(t) = \lambda t$、$\mathrm{Cov}(s,t) = \lambda\min(s,t)$——全部由独立增量推出。
- 对角关系：$R_X(t,t) = E[X^2(t)]$，$C_X(t,t) = \sigma_X^2(t)$。
- 正态过程由其均值函数与相关函数唯一确定——三个函数够用的最好理由。
