## 为什么从成对数据的检验开始

上一节的双总体检验要求两组样本**独立**。但许多实验设计天然是**成对（paired）**的：同一个人服药前与后的血压、同一批材料处理前与后的强度、同一位裁判对两名选手的打分。这些数据两两相关——「处理前的张三」与「处理后的张三」是同一个人，不是两个独立个体。若仍用独立样本公式，会把个体差异误当随机波动，方差被高估，检验灵敏度下降。

**成对检验（paired t-test）**的处理方式极优雅：**先逐对求差 $D_i = X_i - Y_i$，把双总体问题化归为「差值 $D$ 的均值为 0」的单总体问题**。配对把「个体差异」消掉，只留下「处理效应」——这正是实验设计追求的效率。<span class="marginnote">成对设计比独立设计「更省样本」的本质：<strong>配对消除了个体间的变异来源</strong>。同一人服药前后的差值，波动只来自处理效应与随机误差；而两组独立样本的差，还要叠上个体间固有差异（张三血压本来就比李四高）。所以成对 t 检验的方差通常远小于独立样本 t——更容易检测出显著差异。</span>

## 1 成对检验的构造

设 $n$ 对数据 $(X_1, Y_1), \ldots, (X_n, Y_n)$，逐对求差

$$D_i = X_i - Y_i, \qquad i = 1, \ldots, n$$

把 $D_1, \ldots, D_n$ 看成来自总体 $D \sim N(\mu_D, \sigma_D^2)$ 的样本。检验 $H_0: \mu_1 = \mu_2$（即 $\mu_D = 0$）等价于**单总体均值检验**：

$$T = \frac{\bar D}{S_D/\sqrt n} \sim t(n-1) \quad (\text{当 } H_0 \text{ 真})$$

其中 $\bar D = \frac1n\sum D_i$，$S_D^2 = \frac{1}{n-1}\sum(D_i - \bar D)^2$。拒绝域按 $H_1$ 方向定（双侧/右/左）。<span class="marginnote">成对检验的统计量与单总体 t 完全同构：分子是 $\bar D$（差值的均值，$H_0$ 真时为 0 附近），分母是 $S_D/\sqrt n$（差值的标准误）。自由度 $n-1$ 用的是「对数」$n$，不是两组总样本量 $2n$——因为化成单样本后只有 $n$ 个独立观测。</span>

**例（减肥实验）**：10 名受试者记录减肥前后的体重差（前减后）：$\bar D = 2.4$ kg，$S_D = 2.8$ kg。检验减肥是否有效（$H_1: \mu_D > 0$），$\alpha = 0.05$，$t_{0.05}(9) = 1.833$。

$$T = \frac{2.4}{2.8/\sqrt{10}} = \frac{2.4}{0.885} = 2.71$$

$T = 2.71 \ge 1.833$ → 拒绝 $H_0$——减肥效果显著（平均减 2.4 kg）。

## 2 成对检验 vs 独立样本检验

| | 成对检验 | 独立样本 t |
| --- | --- | --- |
| 适用 | 两组不独立（配对/前后） | 两组独立 |
| 对象 | 差值 $D_i = X_i - Y_i$ | 两样本均值差 |
| 自由度 | $n - 1$（$n$ 为对数） | $n_1 + n_2 - 2$ |
| 优势 | 消除个体差异，灵敏度高 | 无需配对设计 |

**易错点｜辨析：** 判断「成对 vs 独立」看数据来源：**同一批个体/配对的个体 → 成对**；**两批独立抽取的个体 → 独立样本**。把成对数据误用独立样本公式，会高估方差、区间变宽、检验力下降；反之把独立数据强行配对，则错误地消除了本不该消的变异。<span class="marginnote">「同一批人测两次」与「两批人各测一次」是成对与独立的分水岭。常见的误判：某实验用 10 只老鼠做对照组、10 只做实验组——两组是独立样本；若同一只老鼠先给安慰剂再给药物（交叉设计）——那是成对。看「对象是否同一个」，答案立现。</span>

## 3 为什么配对更高效：方差对比

配对检验之所以更敏感，数学原因是方差的对比。设 $D = X - Y$，则

$$\mathrm{Var}(D) = \mathrm{Var}(X) + \mathrm{Var}(Y) - 2\,\mathrm{Cov}(X, Y)$$

- 独立时 $\mathrm{Cov} = 0$：$\mathrm{Var}(D) = \sigma_1^2 + \sigma_2^2$——个体差异全部计入；
- 正相关时 $\mathrm{Cov} > 0$：$\mathrm{Var}(D) < \sigma_1^2 + \sigma_2^2$——**共同的部分被减掉**。

配对利用了「处理前后高度正相关」这一事实：体重高的人前后体重都高，差值只反映变化，个体间差异被抵消。<span class="marginnote">「$\mathrm{Var}(X-Y) = \mathrm{Var}X + \mathrm{Var}Y - 2\mathrm{Cov}(X,Y)$」是配对检验效率的数学心脏：正相关的两组，差值方差小于独立情形，检验统计量 $T$ 的分子（同样的效应量）除以更小的分母，$|T|$ 更大，更容易显著。这就是「配对省样本」的定量依据——第四章协方差公式在这里迎来高光时刻。</span>

## 4 公式解析：配对 → 单样本的归约

成对检验的全部智慧在「归约」这一步，拆开：

$$

T = \frac{\bar D}{S_D/\sqrt n} \sim t(n-1), \qquad D_i = X_i - Y_i

$$

- **第一步，逐对求差**：$D_i = X_i - Y_i$——把「两个变量的比较」变成「一个变量的值」。配对效应（个体差异）从差值里消失。
- **第二步，单样本化**：$D_1, \ldots, D_n$ 成为新的单样本，检验「$\mu_D = 0$」就是单总体均值检验——套用单样本 t 的全套流程。
- **第三步，自由度**：$n - 1$（对数减 1），因为归约后只有 $n$ 个独立的差值。

「双总体 → 差值 → 单总体」是成对检验的归约哲学：把「比较两个相关变量」翻译成「检验一个变量的均值是否为 0」。这套翻译在第十章 bootstrap 的成对版、以及面板数据、纵向研究里被反复使用。

## 5 成对检验的深入应用与实例

成对设计是「自己当自己对照」的实验智慧，它的优势、判断与延伸值得展开。

### 例：成对 t 的完整计算

**例**：10 人减肥前后体重差（前减后）：$\bar D = 2.4$ kg、$S_D = 2.8$ kg。$T = \frac{2.4}{2.8/\sqrt{10}} = 2.71$，$t_{0.05}(9) = 1.833$，$2.71 > 1.833$ → 减肥效果显著。

### 成对 vs 独立：方差对比

| | 成对 | 独立 |
| --- | --- | --- |
| 方差 | $\mathrm{Var}(X-Y) = \sigma_1^2+\sigma_2^2-2\mathrm{Cov}$ | $\sigma_1^2+\sigma_2^2$ |
| 协方差项 | 抵消个体差异 | 无 |
| 自由度 | $n-1$ | $n_1+n_2-2$ |

**「正相关让成对方差更小、检验更灵敏」**——这就是成对设计「省样本」的数学根源。

### 判断「成对 or 独立」

| 数据来源 | 类型 |
| --- | --- |
| 同一人测两次 | 成对 |
| 两批独立个体 | 独立 |
| 配对的个体（夫妻、双胞胎） | 成对 |

**「看『对象是否同一个或配对』」**——判断成对 vs 独立的唯一标准。

### 例：成对误用独立的后果

**例**：把成对数据当独立样本，方差被个体差异抬高，$T$ 变小、区间变宽——**「该成对的误用独立会降低检验力，甚至漏掉真实差异」**。

### 延伸：符号秩检验

成对差值非正态时，用**威尔科克森符号秩检验**（对 $|D_i|$ 排秩赋号）——**「成对 t 的非参数版」**，分布假设更宽松。

**易错点｜辨析：** ① 成对检验的对象是「差值 $D$」，不是两组原始数据；② 自由度用「对数」$n-1$；③ 把独立数据强行配对会错误消除变异——成对与否由实验设计决定，不能事后乱配。

## 6 小结

- **成对检验**：逐对求差 $D_i = X_i - Y_i$，检验 $\mu_D = 0$ 化为单样本 t：$T = \bar D/(S_D/\sqrt n) \sim t(n-1)$。
- **成对 vs 独立**：同一批对象测两次 → 成对；两批独立个体 → 独立样本；误用会改变方差与结论。
- 配对更高效：$\mathrm{Var}(X-Y) = \mathrm{Var}X + \mathrm{Var}Y - 2\mathrm{Cov}(X,Y)$——正相关消掉个体差异，检验力更高。
- 自由度用「对数」$n-1$，不是 $2n-2$。
- 成对检验是「归约」思想的典范：双总体 → 差值 → 单总体。
