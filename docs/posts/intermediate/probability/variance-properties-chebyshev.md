## 为什么从方差的性质与切比雪夫不等式开始

方差不只是个「描述性」的数字，它的运算性质让「复杂随机变量的波动」可以被系统地拆解和重组；而**切比雪夫不等式（Chebyshev's inequality）**更是概率论第一张「硬性承诺」：不需要知道分布的具体形状，只要知道均值与方差，就能对「偏离均值多远」给出一个通用的概率上界。

这两个主题看似独立，实为一体：方差的性质负责「把波动拆成块」，切比雪夫不等式负责「用波动去约束概率」。它们合起来构成第五章大数定律的完整武器库——没有切比雪夫不等式，依概率收敛无从谈起。<span class="marginnote">切比雪夫不等式是「分布无关」的：它对任何有有限方差的分布都成立，无论正态、均匀还是完全未知。这种「极弱假设下仍有普适结论」的风格，正是俄罗斯学派（切比雪夫 → 马尔可夫 → 李雅普诺夫）在 19 世纪给概率论打下的烙印，也预告了大数定律的普适性。</span>

## 1 方差的性质

设 $a, b$ 为常数，$X, Y$ 为随机变量，则

1. $\mathrm{Var}(C) = 0$——常数无波动；
2. $\mathrm{Var}(aX) = a^2\,\mathrm{Var}(X)$——常数平方提出；
3. $\mathrm{Var}(X + b) = \mathrm{Var}(X)$——平移不改变波动；
4. $\mathrm{Var}(aX + b) = a^2\,\mathrm{Var}(X)$——合写；
5. $X, Y$ 独立时 $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$——**独立方差可加**；
6. 一般情形 $\mathrm{Var}(X \pm Y) = \mathrm{Var}(X) + \mathrm{Var}(Y) \pm 2\,\mathrm{Cov}(X, Y)$——相关时补上协方差项。

**易错点｜辨析：** 性质 2 中系数提出要**平方**：$\mathrm{Var}(2X) = 4\mathrm{Var}(X)$。标准差则是 $\mathrm{Std}(2X) = 2\mathrm{Std}(X)$——标准差线性、方差平方，二者系数不同。另一陷阱：$\mathrm{Var}(-X) = \mathrm{Var}(X)$，负号不影响方差（平方吸收）。<span class="marginnote">性质 5 是「独立方差可加」的准确表述，它直接来自 $E[XY] = E[X]E[Y]$：$\mathrm{Var}(X+Y) = \mathrm{Var}X + \mathrm{Var}Y + 2(E[XY] - E[X]E[Y])$，独立时交叉项为零。这个「交叉项 = 协方差」的结构，是下一节协方差与相关系数的前奏。</span>

**例**：$X \sim B(n, p)$ 由 $n$ 个独立 0-1 组成，$\mathrm{Var}(X) = np(1-p)$；若每件产品的利润是 $Y = 2X + 5$，则 $\mathrm{Var}(Y) = 4np(1-p)$，$\mathrm{Std}(Y) = 2\sqrt{np(1-p)}$。

## 2 切比雪夫不等式：分布的普适承诺

**切比雪夫不等式**：设随机变量 $X$ 的期望 $\mu$、方差 $\sigma^2$ 均存在，则对任意 $\varepsilon > 0$，

$$P\{|X - \mu| \ge \varepsilon\} \le \frac{\sigma^2}{\varepsilon^2}$$

等价地，取 $\varepsilon = k\sigma$：

$$P\{|X - \mu| \ge k\sigma\} \le \frac{1}{k^2}$$

**解读**：偏离均值超过 $k$ 个标准差的概率不超过 $1/k^2$。无论什么分布，偏离 2 个标准差以上的概率 ≤ 1/4，偏离 3 个标准差以上 ≤ 1/9。<span class="marginnote">对比一下：正态分布下「偏离 3 个标准差」的概率约 0.003，切比雪夫只保证 ≤ 1/9 ≈ 0.111。差距巨大——因为切比雪夫对一切分布都成立，只能用「最坏情况」的松散上界。它的价值不在紧，而在「无条件」：不知道分布时，它仍给你一道安全网。</span>

**例**：某产品的重量 $X$ 期望 100g、标准差 2g。则重量偏离均值超过 6g（即 $k = 3$）的概率 $P\{|X - 100| \ge 6\} \le 1/9$。「至少 8/9 的产品重量落在 $[94, 106]$」——只知道均值方差，就能对几乎所有产品给出保证。

## 3 切比雪夫不等式的证明：马尔可夫不等式

切比雪夫不等式由更基本的**马尔可夫不等式（Markov's inequality）**推出：对非负随机变量 $Z$（$E[Z]$ 存在），对任意 $a > 0$，

$$P\{Z \ge a\} \le \frac{E[Z]}{a}$$

**证明要点**：$a \cdot \mathbf{1}_{\{Z \ge a\}} \le Z$ 对一切样本点成立（当 $Z < a$ 时左边为 0；当 $Z \ge a$ 时左边等于 $a \le Z$），取期望得 $a P\{Z \ge a\} \le E[Z]$。<span class="marginnote">马尔可夫不等式的证明只用了「把指示函数塞进期望」——$a\mathbf{1}_{Z\ge a} \le Z$ 逐点成立，期望保持不等号。这种「逐点比较 + 取期望」的手法极朴素却极有力，是概率论不等式证明的入门模板，第五章、第八章还会再见。</span>

由马尔可夫不等式推切比雪夫：令 $Z = (X - \mu)^2$，$a = \varepsilon^2$。则

$$P\{|X - \mu| \ge \varepsilon\} = P\{(X-\mu)^2 \ge \varepsilon^2\} \le \frac{E[(X-\mu)^2]}{\varepsilon^2} = \frac{\sigma^2}{\varepsilon^2}$$

**一步完成**——非负变量 $Z$ 取 $X$ 的平方偏离，马尔可夫立即给出切比雪夫。

## 4 公式解析：为什么是 σ²/ε²

切比雪夫不等式里「方差除以偏差平方」的结构值得逐项拆解：

$$

P\{|X - \mu| \ge \varepsilon\} \le \frac{\sigma^2}{\varepsilon^2}

$$

- **第一步，事件改写**：$\{|X-\mu| \ge \varepsilon\}$ 等价于 $\{(X-\mu)^2 \ge \varepsilon^2\}$——绝对值不等式转成平方不等式，把「距离」翻译成「平方偏离」。
- **第二步，马尔可夫接管**：对非负变量 $(X-\mu)^2$ 用马尔可夫不等式，$P\{Z \ge a\} \le E[Z]/a$。
- **第三步，代入**：$E[(X-\mu)^2] = \sigma^2$，$a = \varepsilon^2$，比值即 $\sigma^2/\varepsilon^2$。

「分子是波动（$\sigma^2$），分母是容忍度平方（$\varepsilon^2$）」——波动越大承诺越松，容忍度越高承诺越紧。这个「波动作分子」的结构，让切比雪夫成为「方差越小、越可信」这一直觉的严格化，也是第五章大数定律「$\bar X$ 的方差 $\sigma^2/n$ 趋于 0」所以 $\bar X$ 收敛到 $\mu$ 的机制所在。

## 5 方差性质与切比雪夫的深入应用

方差的性质是「波动代数」，切比雪夫是「无分布约束」，两者的结合价值值得展开。

### 例：方差性质的应用

**例**：$X \sim B(100, 0.5)$，$Y = 2X + 10$。$\mathrm{Var}(Y) = 4\times 25 = 100$、$\mathrm{Std}(Y) = 10$——「系数平方提出、平移不影响」。

### 方差性质的速查

| 性质 | 公式 | 条件 |
| --- | --- | --- |
| 常数 | $\mathrm{Var}(C) = 0$ | 无 |
| 线性 | $\mathrm{Var}(aX+b) = a^2\mathrm{Var}(X)$ | 无 |
| 和 | $\mathrm{Var}(X+Y)$ 可加 | 独立 |
| 和一般 | $+2\mathrm{Cov}$ | 相关 |

**「常数零、系数平方、和要独立」**——方差代数三口诀。

### 例：切比雪夫不等式的应用

**例**：期望 100、标准差 2。$P\{|X-100| \ge 6\} \le 1/9$——「至少 8/9 落在 $[94,106]$」，只知道均值方差就能给普适保证。

### 切比雪夫 vs 正态

| | 切比雪夫 | 正态（3σ） |
| --- | --- | --- |
| $P\{\|X-\mu\| \ge 3\sigma\}$ | $\le 1/9$ | $\approx 0.003$ |
| 假设 | 仅方差存在 | 正态 |
| 用途 | 兜底 | 精确 |

**「切比雪夫松但无条件、正态紧但要假设」**——分布未知时切比雪夫是安全网。

### 例：证明大数定律的桥梁

切比雪夫把「$\mathrm{Var}(\bar X) = \sigma^2/n \to 0$」翻译成「$\bar X \to \mu$ 依概率」——**「切比雪夫是大数定律的引擎」**，第五章的证明全靠它。

**易错点｜辨析：** ① 方差可加的前提是独立（或协方差为 0）——别无条件套用；② 切比雪夫上界 $1/k^2$ 是最坏情况——实际远小；③ 标准差线性（$\mathrm{Std}(aX) = |a|\mathrm{Std}(X)$）与方差平方不同——两者系数别混。

## 6 小结

- **方差的性质**：$\mathrm{Var}(aX+b) = a^2\mathrm{Var}(X)$；独立时 $\mathrm{Var}(X+Y)$ 可加；相关时补协方差项。
- **切比雪夫不等式** $P\{|X-\mu| \ge k\sigma\} \le 1/k^2$——分布无关的普适上界。
- **马尔可夫不等式** $P\{Z \ge a\} \le E[Z]/a$（$Z \ge 0$）是切比雪夫的上游定理，证明靠「逐点比较 + 取期望」。
- 切比雪夫上界较松（正态实际值远小于 $1/k^2$），但胜在无条件成立。
- 切比雪夫是大数定律的核心引擎：方差随 $n$ 缩为 0，$\bar X$ 依概率收敛到 $\mu$。
