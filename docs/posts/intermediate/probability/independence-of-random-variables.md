# 相互独立的随机变量

<div class="epigraph">
<p>两个变量相互独立，意味着关于一个的一切知识，都不能让另一个的分布挪动分毫。</p>

## 为什么从相互独立开始

第一章我们定义了事件的独立：$P(AB) = P(A)P(B)$。现在把它升级到随机变量层面：**什么时候「知道 $Y$ 的取值」对 $X$ 的分布毫无影响？** 若无论 $Y$ 取什么，$X$ 的条件分布都等于它的边缘分布，那 $X$ 与 $Y$ 就是**相互独立**的。独立性是概率论中最常用的假设，也是「统计推断能从数据中提炼信息」的前提——正因为独立重复的观测彼此不干扰，我们才能把 $n$ 次观测视为 $n$ 份可叠加的证据。

独立性在本课程中无处不在：二项分布要求各次试验独立；第六章「独立同分布样本」是整个数理统计的地基；大数定律、中心极限定理都建立在独立随机变量之和上。<span class="marginnote">独立性是概率论里「最强也最脆弱」的假设：强到足以导出全套极限定理，脆到现实里处处被违反（相邻观测常相关）。统计学家花了整整一章学习如何检验独立性、如何在不独立时改用配对检验或时间序列方法——但理解和用好「独立」，永远是第一步。</span>

## 1 定义：联合 = 边缘之积

**相互独立的随机变量（independent random variables）**：设 $(X,Y)$ 的联合分布函数为 $F(x,y)$，边缘分布函数为 $F_X(x)$、$F_Y(y)$。若对一切 $x, y$ 有

$$F(x, y) = F_X(x)\, F_Y(y)$$

则称 $X$ 与 $Y$ **相互独立**。

这个定义与事件的独立一脉相承：$P\{X \le x, Y \le y\} = P\{X \le x\}P\{Y \le y\}$——「两个事件 $\{X\le x\}$ 与 $\{Y \le y\}$ 对一切 $x,y$ 同时独立」。<span class="marginnote">定义中「对一切 $x,y$」是关键：不是某一对 $x,y$ 成立，而是全部实数对都成立。也正因如此，独立性的验证通常要验证一个恒等式，而不是代入几个点——下面两种写法正是把恒等式落到密度/分布律上的版本。</span>

**等价形式**（在密度/分布律存在的场合）：

- **离散**：$p_{ij} = p_{i\cdot}\, p_{\cdot j}$ 对一切 $i, j$；
- **连续**：$f(x, y) = f_X(x)\, f_Y(y)$ 对一切 $x, y$。

「**联合密度 = 两个边缘密度之积**」是最常用的判据。上一节见过的 $f(x,y) = 4xy = (2x)(2y)$ 正是独立：联合密度恰好拆成 $f_X(x) \cdot f_Y(y)$。

## 2 独立 ⇒ 条件分布等于边缘分布

独立性最直观的「翻译」：**独立时，条件分布退化为边缘分布**。

$$X \text{ 与 } Y \text{ 独立} \iff f_{X \mid Y}(x \mid y) = f_X(x) \text{（对一切使 } f_Y(y) > 0 \text{ 的 } y\text{）}$$

验证只需一步：$f_{X\mid Y}(x\mid y) = \frac{f(x,y)}{f_Y(y)} = \frac{f_X(x)f_Y(y)}{f_Y(y)} = f_X(x)$。反过来，若条件分布恒等于边缘分布，则 $f(x,y) = f_{X\mid Y}(x\mid y) f_Y(y) = f_X(x)f_Y(y)$，独立成立。<span class="marginnote">「独立 ⇔ 条件 = 边缘」是理解独立性的最佳直觉：知道 $Y = y$ 后 $X$ 的分布一点没变。现实里的「独立」对应「这个信息对我判断 $X$ 毫无帮助」——比如两次独立抛硬币的结果。反过来，知道 $Y$ 让 $X$ 的分布改变，就说明二者相关。</span>

**易错点｜辨析：** 「不独立」不等于「有线性关系」。$Y = X^2$（$X \sim U(-1,1)$）时，$X$ 与 $Y$ 明显不独立（$Y$ 完全由 $X$ 决定），但 $X$ 与 $Y$ 的相关系数为 0——非线性依赖可以不被相关系数察觉。**独立是「毫无依赖」，相关只是「线性依赖」**。这个区别是第四章《不相关与独立的关系》的核心，此处先埋下伏笔。

## 3 独立随机变量的性质与检验

独立随机变量有一系列重要推论（第四章会证明其中部分）：

**函数也独立**：若 $X$ 与 $Y$ 独立，则对任意函数 $g, h$，$g(X)$ 与 $h(Y)$ 也独立；
**可加性（期望）**：$E[XY] = E[X]\,E[Y]$；
**可加性（方差）**：$\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$；
**矩母函数乘积**：$M_{X+Y}(t) = M_X(t) M_Y(t)$。

**例（可加性）**：$X \sim B(n_1, p)$、$Y \sim B(n_2, p)$ 独立，则 $X + Y \sim B(n_1 + n_2, p)$——「把两次试验合并」仍是二项，这是二项分布可加性的来源。<span class="marginnote">独立变量的「函数仍独立」是极其好用的一条：$X_1, \ldots, X_n$ 独立同分布时，样本均值 $\bar X$ 与某个样本点 $X_i$ 的任意可测函数往往独立。这条性质在证明抽样分布定理（第六章）时是隐藏主角。</span>

**如何判断两个变量是否独立？** 三步走：

1. **看背景**：是否来自互不干扰的两个试验/机制？
2. **看联合是否拆积**：$f(x,y) \stackrel{?}{=} f_X(x) f_Y(y)$；
3. **看支撑**：若联合密度的支撑不是「矩形」（即 $x$ 与 $y$ 的范围互相牵制），则**必不独立**——因为可拆积的密度，其支撑必为矩形（或矩形并）。

第 3 条是性价比最高的速判法：**联合密度的支撑不是矩形 ⇒ 不独立**。反过来，支撑是矩形还不足以保证独立，还要验恒等式。

## 4 公式解析：独立性判据的几何直觉

独立性判据 $f(x,y) = f_X(x) f_Y(y)$ 的几何含义值得点透：

$$

f(x, y) = \underbrace{f_X(x)}_{\text{只依赖 } x} \cdot \underbrace{f_Y(y)}_{\text{只依赖 } y}

$$

- **第一步，分离变量**：右边是「只含 $x$ 的因子 × 只含 $y$ 的因子」。凡能写成这种「乘积分离」形式的联合密度，都是独立。
- **第二步，支撑必须是矩形**：若 $x$ 与 $y$ 的取值范围互相牵制（如三角域 $0 \le y \le x \le 1$），则无论怎么写都写不成「$x$ 的函数乘 $y$ 的函数」——因为支撑边界本身就把变量缠在一起。
- **第三步，分离的必然是边缘**：若 $f(x,y) = g(x)h(y)$ 成立，则归一化后 $g(x) \propto f_X(x)$、$h(y) \propto f_Y(y)$，比例常数由归一性确定。于是「分离变量」与「独立」完全等价。

「**联合密度能否分离成两个单变量函数之积**」是独立性的终极判据，也是很多难题的突破口——先看支撑是否矩形，再试分离变量，两步就能对多数题给出答案。

## 5 独立性的深入应用与实例

独立性是概率论最常用的假设，它的判据、性质与误用风险值得完整展开。

### 例：独立性判据

**例**：联合密度 $f(x,y) = 4xy$（$0\le x,y\le 1$）。$f_X(x) = 2x$、$f_Y(y) = 2y$，$f = f_X f_Y$——独立。**「联合 = 边缘之积」**是独立性判据。

### 独立性判据速查

| 类型 | 判据 |
| --- | --- |
| 分布函数 | $F = F_X F_Y$ |
| 离散 | $p_{ij} = p_{i\cdot}p_{\cdot j}$ |
| 连续 | $f = f_X f_Y$ |
| 条件 | $f_{X\mid Y} = f_X$ |

**「联合可拆成边缘之积」**是独立性的统一判据。

### 例：支撑不矩形 ⇒ 不独立

**例**：三角域 $0 \le y \le x \le 1$ 上，$x$、$y$ 范围互相牵制——密度写不成「$x$ 函数 × $y$ 函数」，必不独立。**「支撑不是矩形 ⇒ 不独立」**是最快的速判。

### 独立的推论

| 推论 | 公式 |
| --- | --- |
| 期望可拆 | $E[XY] = E[X]E[Y]$ |
| 方差可加 | $\mathrm{Var}(X+Y) = \mathrm{Var}X + \mathrm{Var}Y$ |
| 函数独立 | $g(X) \perp h(Y)$ |
| 矩母可乘 | $M_{X+Y} = M_X M_Y$ |

**「独立带来一系列可拆性」**——这是它如此有用的原因。

### 例：独立但不相关之外

独立 ⇒ 不相关，不相关 ⇏ 独立——$Y = X^2$ 是反例。**「独立强、不相关弱」**在二维正态里才重合。

**易错点｜辨析：** ① 独立性是「全部 $x,y$」的恒等式，不是代入几个点；② 支撑矩形是「必要不充分」——矩形内还要验恒等式；③ 「不相关」≠「独立」——别把两者当一回事。

## 6 小结

- **相互独立** $F(x,y) = F_X(x)F_Y(y)$；离散版 $p_{ij} = p_{i\cdot}p_{\cdot j}$，连续版 $f(x,y) = f_X(x)f_Y(y)$。
- **独立 ⇔ 条件分布 = 边缘分布**——知道 $Y$ 不改变 $X$ 的分布。
- 独立 ⇒ 函数仍独立、$E[XY] = E[X]E[Y]$、$\mathrm{Var}(X+Y) = \mathrm{Var}\,X + \mathrm{Var}\,Y$。
- **支撑不是矩形 ⇒ 必不独立**；支撑是矩形还要验恒等式。
- 不独立 ≠ 相关：非线性依赖可能相关系数为 0，区别在第四章揭晓。
