## 为什么从 0-1 分布开始

上一章我们认识了伯努利试验：只有成功/失败两个结果的试验。这一章又建立了分布律：用一张表描述离散型随机变量的全部取值概率。把两者一碰撞，就得到**所有分布中最简单的一个——0-1 分布**。它只取两个值，却几乎是一切后续分布的「细胞」：二项分布是它的 $n$ 次独立副本之和，几何分布是它的「等待时间」，而机器学习的逻辑回归输出层，正是对它的概率建模。先把这个最小的积木打磨光滑，后面组装大厦时才不会散架。

**0-1 分布（zero-one distribution / Bernoulli distribution）**：设随机变量 $X$ 只取 0 与 1 两个值，且

$$P\{X = 1\} = p, \qquad P\{X = 0\} = 1 - p, \qquad 0 < p < 1$$

则称 $X$ 服从**0-1 分布**（又称**伯努利分布**），记作 $X \sim B(1, p)$。<span class="marginnote">记号 $B(1, p)$ 把它看成二项分布 $B(n, p)$ 在 $n = 1$ 的特例，即「只做一次试验」。事实上，$n$ 重伯努利试验的成功总数正是 $n$ 个独立 0-1 随机变量之和——分布与试验两条线索在这里汇合。</span>

## 1 分布律与归一性的检查

0-1 分布的分布律表格只有两行：

| $X$ | 0 | 1 |
| --- | --- | --- |
| $p_k$ | $1-p$ | $p$ |

两条判据立刻可验：非负性——$p \in (0,1)$ 时两项皆非负；归一性——$(1-p) + p = 1$。**这是最简单的概率账本，也是验证任何复杂分布是否正确的最小样板**：你的公式能不能在 $n=1$ 时退化成这张表？若能，大概率结构是对的。

**例**：一枚不均匀硬币，正面朝上的概率 $p = 0.6$。令 $X = 1$ 表示正面、$X = 0$ 表示反面，则 $P\{X=1\} = 0.6$，$P\{X=0\} = 0.4$。一次试验的全部信息被两个数 $0.4, 0.6$ 完整携带。<span class="marginnote">0-1 分布的「参数」只有一个 $p$。一个参数决定一张表，这是所有分布里最经济的——越复杂的分布参数越多，如正态分布有两个参数、多元正态有参数矩阵。</span>

## 2 0-1 分布的事件语言：成功与失败

在伯努利试验的语言里，$\{X = 1\}$ 就是「成功」，$\{X = 0\}$ 就是「失败」。于是概率计算的常见操作都可以用 $p$ 直接表达：

- 成功的概率：$P\{X = 1\} = p$；
- 失败的概率：$P\{X = 0\} = 1 - p$；
- 对立事件关系：$\{X = 0\}$ 与 $\{X = 1\}$ 互斥且互补，概率之和为 1。

**易错点｜辨析：** $p$ 代表「1 的概率」，不是「0 的概率」。凡涉及「把哪个结果编码为 1」的选择，必须先说清楚，否则后续的期望、方差都会跟着错——$E[X] = p$ 这件事只在「1 代表成功」时才成立。若把成功编码为 0，则一切公式要重新对位。<span class="marginnote">现实中「1 编码什么」往往有惯例：电子开关 1 表导通、医学里 1 表患病、机器学习里 1 表正类。但数学上 0/1 可以互换，只要全程一致。这种「编码一致」的要求，在后端把分类标签喂进损失函数时同样关键。</span>

## 3 公式解析：0-1 分布是二项分布的细胞

把 $n$ 重伯努利试验的成功总数记作 $S_n = X_1 + X_2 + \cdots + X_n$，其中每个 $X_i$ 都服从 0-1 分布且相互独立。$S_n$ 服从二项分布 $B(n, p)$，且它的概率公式与 0-1 分布的关系可以这样看：

$$

P\{S_n = k\} = \binom{n}{k} p^k (1-p)^{n-k}

$$

- **第一步，$n = 1$ 退化为 0-1 分布**：$P\{S_1 = 0\} = \binom{1}{0}(1-p)^1 = 1-p$，$P\{S_1 = 1\} = \binom{1}{1}p = p$，与 0-1 分布完全一致。
- **第二步，$n > 1$ 的计数**：$k$ 次成功需要在 $n$ 个位置上选择 $k$ 个放「1」，$\binom{n}{k}$ 种选法；每种选法的概率都是 $p^k(1-p)^{n-k}$。
- **第三步，独立性做乘法**：$X_i$ 相互独立，所以「这次成功、那次失败」的联合概率直接连乘；独立性一旦失效（如不放回抽样），这个公式就退场，换超几何分布登场。

这一拆解说明：**0-1 分布是「一次试验」的概率，二项分布是「$n$ 次独立试验」的概率**，两者共享同一个参数 $p$，只是「重复次数」不同。理解这一层，比死记公式有用得多——遇到「掷 100 次硬币求成功次数」时，你会自动知道该搬 $B(100, p)$。

## 4 0-1 分布在哪都出现

0-1 分布单薄，却几乎是无处不在的开关：

- **抽检**：一件产品合格（1）或不合格（0）；
- **医学检测**：一名患者阳性（1）或阴性（0）；
- **机器学习**：二分类标签 $y \in \{0, 1\}$，逻辑回归直接建模 $P\{y=1\} = \sigma(\theta^\top x)$；
- **概率论自身**：指示函数 $\mathbf{1}_A$——事件 $A$ 发生取 1，否则取 0。任一个事件 $A$ 都可升级为随机变量 $\mathbf{1}_A$，而 $E[\mathbf{1}_A] = P\{A\}$，这把「事件概率」统一进「期望」的框架。<span class="marginnote">指示函数是连接事件语言与随机变量语言的一座便桥：后续证明大数定律、计算期望时，「概率 = 指示函数的期望」这条等式会被反复调用。</span>

**例（指示函数的力量）**：设事件 $A$ 的概率为 $P\{A\}$，定义 $I = \mathbf{1}_A$。则 $I$ 服从 0-1 分布，参数恰为 $P\{A\}$。于是「$A$ 发生的概率」等价于「$I$ 的期望」——把集合问题变成函数问题，这是概率论高级化的重要一步。

## 5 0-1 分布的深入应用与实例

0-1 分布是最小的分布，却撑起一大片应用——从概率的本质到机器学习的分类。

### 例：期望与方差

**例**：$X \sim B(1, p)$。$E[X] = p$，$E[X^2] = p$，$\mathrm{Var}(X) = p(1-p)$——「期望与方差都只由 $p$ 决定」。$p = 0.5$ 时方差最大（$1/4$）——最不确定。

### 0-1 分布的地位

| 概念 | 与 0-1 的关系 |
| --- | --- |
| 伯努利试验 | 随机变量化 |
| 二项分布 | $n$ 个独立 0-1 之和 |
| 指示函数 | $\mathbf 1_A$ 服从 0-1 |
| 概率 | $P\{A\} = E[\mathbf 1_A]$ |

**「0-1 分布是概率论的积木」**——一切「成功/失败」的计数都从它拼起。

### 例：指示函数的应用

**例**：$X_1, \ldots, X_n$ 独立 0-1，$E[\sum X_i] = np$、$\mathrm{Var}(\sum X_i) = np(1-p)$——二项分布的期望方差从「独立和」推出，无需直接算组合。

### 应用：逻辑回归的建模

机器学习二分类：$y \in \{0,1\}$，模型预测 $P\{y=1\} = \sigma(\theta^\top x)$（sigmoid）。**「逻辑回归 = 对 0-1 分布参数 $p$ 的条件建模」**——这是 0-1 分布在大模型时代的直接后裔。

**易错点｜辨析：** ① 编码选择要一致：$X = 1$ 表「成功」还是「失败」，期望、方差公式随之对位；② $p \in (0,1)$ 是参数——$p = 0$ 或 $1$ 是退化情形（无随机性）；③ 「0-1 分布」与「指示函数」是同一对象——前者看概率、后者看函数，视角不同。

再补一张「0-1 分布 vs 二项 vs 几何」对照：

| | 0-1 | 二项 | 几何 |
| --- | --- | --- | --- |
| 问什么 | 单次成功 | $n$ 次成功次数 | 首次成功次数 |
| 取值 | $0,1$ | $0..n$ | $1,2,\ldots$ |
| 期望 | $p$ | $np$ | $1/p$ |

「0-1 是最小积木、二项是它的 $n$ 次和、几何是它的等待」——三个分布血脉相连。

## 6 小结

- **0-1 分布**（伯努利分布）只取 0、1 两个值，一个参数 $p$ 决定整张分布律表，$X \sim B(1, p)$。
- 分布律 $P\{X=1\}=p$，$P\{X=0\}=1-p$，满足非负性与归一性。
- 0-1 分布是二项分布 $B(n,p)$ 在 $n=1$ 的退化，也是 $n$ 重伯努利试验成功总数的组成细胞。
- 指示函数 $\mathbf{1}_A$ 是 0-1 分布的应用形式，它把「事件的概率」统一成「随机变量的期望」。
- 编码选择（1 表成功还是 0 表成功）必须全程一致，否则期望、方差全部错位。

在下一节，我们把这个「细胞」复制 $n$ 份、加起来，研究**二项分布**的完整形状——最可能值、分布的峰，以及它为何是「重复试验」的天然语言。
