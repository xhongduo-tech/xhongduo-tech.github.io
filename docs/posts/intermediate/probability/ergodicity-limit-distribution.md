## 为什么从遍历性与极限分布开始

状态分类的三大坐标（常返、周期、互通）在这里汇聚成一个大问题：**链跑足够久，状态分布会怎样？** 答案分两种——若是**遍历（ergodic）**的链，分布会**收敛到唯一的极限分布**（与初始分布无关）；若链有周期或多个互通类，极限分布可能不存在或不唯一。**遍历性与极限分布**是马尔可夫链理论的高潮，也是它的实际价值所在：长期预测、稳态分析、PageRank 都建立在这里。

极限分布是马尔可夫链的「长期稳态」：天气的长期下雨概率、队列的长期平均队长、网页排名的稳态分数——都是从极限分布读出。它是本章理论「总决算」，也是平稳分布（下一节）的兄弟概念。<span class="marginnote">「忘掉起点」是遍历性的哲学精髓：<strong>遍历链的极限分布不依赖初始状态 $X_0$</strong>——无论从哪开始，跑得足够久，状态分布趋同。这个「记忆消失」是马尔可夫性的终极体现：过去的影响被逐步冲刷，只剩链自身的「宪法」决定长期命运。</span>

## 1 极限分布的定义

**极限分布（limiting distribution）**：设 $p^{(n)}_{ij} = P\{X_n = j \mid X_0 = i\}$，若对一切 $i, j$，极限 $\lim_{n\to\infty} p^{(n)}_{ij}$ 存在且与 $i$ 无关，记为 $\pi_j$，则称 $\{\pi_j\}$ 为链的**极限分布**。

**关键点**：极限分布 $\pi_j$ 不依赖起点 $i$——「$\lim_n p^{(n)}_{ij} = \pi_j$ 对一切 $i$」。用矩阵写：$P^n$ 的每一行都收敛到同一个分布 $\pi$。

**例（两状态天气）**：$P = \begin{pmatrix} 0.8 & 0.2 \\ 0.4 & 0.6 \end{pmatrix}$，$P^n \to \begin{pmatrix} 2/3 & 1/3 \\ 2/3 & 1/3 \end{pmatrix}$——两行相同，极限分布 $\pi = (2/3, 1/3)$：长期下雨概率 1/3。<span class="marginnote">「$P^n$ 的行收敛到相同向量」是极限分布的矩阵语言：从任何状态出发，$n$ 步后的分布都一样——起点被「遗忘」。注意这与「$P^n$ 本身收敛」是一回事：$P^n$ 的第 $i$ 行就是「从 $i$ 出发的 $n$ 步分布」，各行趋于相同即起点无关。</span>

## 2 遍历定理

**遍历定理（ergodic theorem）**：设马尔可夫链 $\{X_n\}$ 满足：①**不可约**（一个互通类）；②**非周期**；③**常返**（有限链自动满足）。则链存在唯一的极限分布 $\pi$，且：

1. $\pi$ 是**平稳分布**：$\pi = \pi P$（即 $\pi_j = \sum_i \pi_i p_{ij}$）；
2. $\lim_{n\to\infty} p^{(n)}_{ij} = \pi_j$ 对一切 $i, j$；
3. $\pi_j > 0$ 对一切 $j$（所有状态都被正概率访问）。

**三个条件缺一不可**：不可约保证唯一，非周期保证收敛（不振荡），常返保证存在（不流失）。<span class="marginnote">三个条件的「分工」值得记牢：<strong>不可约（互通）→ 唯一；非周期 → 收敛不振荡；常返 → 分布不流失</strong>。缺周期会「振荡不收敛」（如确定性二态循环在两种分布间摆）；多互通类会「按类定居」（极限依赖起点所在类）。遍历定理把所有条件打包，是马尔可夫链最常用的「一键结论」。</span>

**例（判定）**：两状态天气链——互通（不可约）、$p_{00} > 0$（非周期）、有限（常返）——遍历，极限分布存在唯一。

## 3 求极限分布：解平稳方程

遍历链的极限分布 $\pi$ 是平稳方程 $\pi = \pi P$ 的解（加上归一 $\sum \pi_j = 1$）。解方程组：

$$\pi_j = \sum_i \pi_i p_{ij}, \qquad \sum_j \pi_j = 1$$

**例（两状态天气）**：$\pi = (\pi_0, \pi_1)$ 满足

$$\pi_0 = 0.8\pi_0 + 0.4\pi_1, \qquad \pi_0 + \pi_1 = 1$$

由第一式：$0.2\pi_0 = 0.4\pi_1 \Rightarrow \pi_1 = 0.5\pi_0$；代入归一：$\pi_0 + 0.5\pi_0 = 1 \Rightarrow \pi_0 = 2/3$，$\pi_1 = 1/3$。<span class="marginnote">解平稳方程的小技巧：方程组 $\pi = \pi P$ 的秩只有「状态数 − 1」（行和为 1 造成线性相关），所以必须补上归一条件 $\sum \pi_j = 1$ 才能定出唯一解。实践中「写 $n-1$ 个方程 + 1 个归一」是标准操作——漏掉归一，解只能定到比例。</span>

## 4 公式解析：极限分布与时间占比

极限分布还有一个重要的「时间平均」含义（各态历经性），拆开：

$$

\pi_j = \lim_{n\to\infty} P\{X_n = j\} = \lim_{n\to\infty} \frac{\text{前 } n \text{ 步中访问 } j \text{ 的次数}}{n}

$$

- **第一步，概率视角**：$\pi_j$ = 链在 $n$ 步后的分布极限——「长期落在 $j$ 的概率」。
- **第二步，时间视角**：对遍历链，时间平均 = 概率平均——「长期里待在 $j$ 的时间比例」也收敛到 $\pi_j$。
- **第三步，合一**：两个视角的收敛结果相同——「长期概率」与「长期时间占比」是同一个数。这是**各态历经性（ergodicity）**在马尔可夫链里的体现。

「极限分布 = 长期时间占比」让 $\pi_j$ 有了可观测的含义：跑足够久，统计「在 $j$ 花了多少时间比例」，就估计出 $\pi_j$——这是 PageRank（网页长时间浏览的比例）与蒙特卡洛采样（MCMC）的理论根据。

## 5 遍历性的深入应用与实例

极限分布定理把「收敛」讲清楚了，但工程上真正要用的是它的「时间平均」版本——各态历经性让「一段轨道」就能估计稳态。

### 极限分布 vs 时间占比

对遍历链，除了「概率极限」还有「时间平均极限」：

$$\pi_j = \lim_{n\to\infty} P\{X_n = j\} = \lim_{n\to\infty} \frac{\text{前 } n \text{ 步访问 } j \text{ 的次数}}{n}$$

**「长期概率」与「长期时间占比」是同一个 $\pi_j$**——这是各态历经性在马尔可夫链里的体现，也是 MCMC 采样的理论基础：跑一条足够长的链，统计各状态的访问比例，就得到平稳分布。

### 例：解两状态链的极限分布

$P = \begin{pmatrix} 0.8 & 0.2 \\ 0.4 & 0.6 \end{pmatrix}$。平稳方程 $\pi = \pi P$ 与归一条件：

$$\begin{cases} \pi_0 = 0.8\pi_0 + 0.4\pi_1 \\ \pi_0 + \pi_1 = 1 \end{cases} \implies \pi = (2/3,\ 1/3)$$

**长期有 2/3 的时间晴**——无论从晴还是雨开始，跑得足够久，晴的时间占比都趋近 2/3。这就是「忘掉起点」的时间平均版本。

### 遍历链的三条件回顾

| 条件 | 缺失时的后果 |
| --- | --- |
| 不可约 | 极限依赖起点所在互通类，不唯一 |
| 非周期 | 分布振荡，极限不存在 |
| 常返 | 概率流失（无限链），无极限分布 |

### 例：MCMC 的收敛直觉

Metropolis–Hastings 算法构造一条以目标分布为平稳分布的链——跑足够久后，链的访问频率 ≈ 目标分布，这就是「从复杂分布采样」的全部原理。**「收敛诊断」就是检查链是否已进入平稳**：多跑几条不同起点的链，看访问分布是否趋同（R 的 Gelman–Rubin 诊断）。

**易错点｜辨析：** ① 极限分布存在需要「非周期」——周期链只有「按周期子链分别看」的极限；② 时间占比收敛需要「各态历经」——不可约非周期常返链自动满足；③ MCMC 的「预热期（burn-in）」就是等链从初始分布收敛到平稳分布的阶段，别把预热期的样本计入估计。

再补一张「概率极限 vs 时间平均」的对照表：

| | 概率极限 | 时间平均 |
| --- | --- | --- |
| 对象 | $P\{X_n = j\}$ | 访问 $j$ 的次数比例 |
| 条件 | 遍历（不可约+非周期+常返） | 各态历经 |
| 结果 | $\pi_j$ | 同为 $\pi_j$ |
| 应用 | 理论计算 | MCMC 采样、模拟估计 |

「两种收敛殊途同归」是遍历链的深刻性质——理论算出来的平稳分布，用一条长轨道数一数也能得到，这正是模拟方法的底气。

## 6 小结

- **极限分布** $\pi_j = \lim_n p^{(n)}_{ij}$ 与起点无关——链「忘掉起点」。
- **遍历定理**：不可约 + 非周期 + 常返 ⇒ 唯一极限分布，是平稳方程 $\pi = \pi P$ 的解。
- 三条件分工：不可约→唯一、非周期→收敛、常返→存在。
- 求 $\pi$：解 $\pi = \pi P$ + 归一 $\sum \pi_j = 1$（$n-1$ 个方程 + 1 个归一）。
- 极限分布 = 长期时间占比（各态历经）——PageRank、MCMC 的理论根据。
