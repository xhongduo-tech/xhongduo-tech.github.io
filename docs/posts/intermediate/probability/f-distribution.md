## 为什么从 F 分布开始

t 分布处理「均值比较」，F 分布处理「**方差比较**」：两条生产线的产品波动谁大谁小？两个总体方差是否相等？两组回归模型的解释力是否有显著差别？这些「比较波动」的问题，都归结为**两个独立 χ² 变量之比**的分布——**F 分布**。

F 分布在本书中管三件大事：两个正态总体方差比的区间估计（第七章）、方差比的假设检验（第八章）、以及第九章方差分析的整个检验体系（组间方差 / 组内方差之比）。它由费希尔在 20 世纪初系统提出，以他的名字命名。<span class="marginnote">F 分布的名字来源很直白：R. A. Fisher（费希尔）的首字母。费希尔是「方差分析」「实验设计」「最大似然估计」的奠基人，第九章的方差分析与回归理论几乎全部出自他手——F 分布只是他庞大贡献的一小块，却撑起了「比较波动」的整个体系。</span>

## 1 定义：两个 χ² 之比

**F 分布（F distribution）**：设 $V_1 \sim \chi^2(n_1)$、$V_2 \sim \chi^2(n_2)$ 且相互独立，则称

$$F = \frac{V_1 / n_1}{V_2 / n_2}$$

服从自由度为 $(n_1, n_2)$ 的 **F 分布**，记作 $F \sim F(n_1, n_2)$。$n_1$ 叫**第一自由度**（分子的自由度），$n_2$ 叫**第二自由度**（分母的自由度）。<span class="marginnote">「商的分布」章节的另一个伏笔在此兑现：F 分布就是「两个独立 χ² 各自除以自由度后的比值」。注意自由度顺序不能颠倒——$F(n_1, n_2)$ 与 $F(n_2, n_1)$ 是不同的分布。写作时务必标清哪个自由度属于分子。</span>

**密度**：$f(x) = \frac{\Gamma\left(\frac{n_1+n_2}{2}\right)\left(\frac{n_1}{n_2}\right)^{n_1/2}}{\Gamma\left(\frac{n_1}{2}\right)\Gamma\left(\frac{n_2}{2}\right)} \cdot \frac{x^{n_1/2 - 1}}{\left(1 + \frac{n_1}{n_2}x\right)^{(n_1+n_2)/2}}$，$x > 0$——正偏、只取正值。

## 2 F 分布的性质

F 分布三条核心性质：

1. **只取正值**：$F > 0$（方差比非负），密度右偏；
2. **倒数对称**：$F \sim F(n_1, n_2) \implies \frac{1}{F} \sim F(n_2, n_1)$——分子分母对调，自由度也换位；
3. **与 t 的关系**：若 $t \sim t(n)$，则 $t^2 \sim F(1, n)$——t 的平方服从第一自由度 1 的 F 分布。

性质 2 是查表的利器：F 表通常只给右侧大值（如 $\alpha = 0.05$ 或 $0.025$），求左侧小值时用 $\frac{1}{F} \sim F(n_2, n_1)$ 倒过来查。<span class="marginnote">F 表只列右尾、用倒数查左尾，是最容易卡住的查表技巧：要求 $F_{0.95}(n_1, n_2)$（左尾分位点）时，先查 $F_{0.05}(n_2, n_1)$ 再取倒数——$F_{0.95}(n_1,n_2) = 1/F_{0.05}(n_2,n_1)$。第八章方差比检验、第九章方差分析都要用这个技巧。</span>

**例**：若 $F \sim F(5, 10)$，则 $1/F \sim F(10, 5)$；查 $F_{0.05}(10, 5) = 4.74$，则 $F_{0.95}(5, 10) = 1/4.74 \approx 0.211$。

## 3 F 分布在哪里出现：方差比

F 分布的标准应用场景：

- **两个总体方差比**：设 $X_1,\ldots,X_{n_1} \sim N(\mu_1, \sigma_1^2)$、$Y_1,\ldots,Y_{n_2} \sim N(\mu_2, \sigma_2^2)$ 独立，$S_1^2, S_2^2$ 为样本方差，则
  $$\frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1 - 1,\ n_2 - 1)$$
  若 $\sigma_1^2 = \sigma_2^2$，则 $S_1^2/S_2^2 \sim F(n_1 - 1, n_2 - 1)$——**样本方差比直接服从 F 分布**，用来检验方差相等性。
- **方差分析**：组间方差与组内方差之比服从 F 分布，第九章据此检验「各组均值是否相同」。

<span class="marginnote">「$S_1^2/S_2^2 \sim F(n_1-1, n_2-1)$」是第八章 F 检验（方差相等性）与第九章方差分析（组间比较）的共同统计量。它来自样本方差的 χ² 分布：$\frac{(n_i-1)S_i^2}{\sigma_i^2} \sim \chi^2(n_i-1)$，两式相除得 F。方差相等时 $\sigma_1^2/\sigma_2^2$ 抵消，只剩样本方差之比。</span>

**例（方差比检验雏形）**：两条生产线各抽 10 与 12 件，样本方差 $s_1^2 = 4.2$、$s_2^2 = 2.1$。若总体方差相等，$F = s_1^2/s_2^2 = 2.0$，与 $F_{0.05}(9, 11) \approx 2.90$ 比较——$2.0 < 2.90$，不能拒绝方差相等。第八章会完整展开。

## 4 公式解析：F 统计量的「比值」结构

F 统计量的构造「分子 χ² 除以自由度、分母 χ² 除以自由度」拆开看：

$$

F = \frac{V_1 / n_1}{V_2 / n_2}, \qquad \frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1 - 1, n_2 - 1)

$$

- **第一步，各自 χ² 化**：$\frac{(n_1-1)S_1^2}{\sigma_1^2} \sim \chi^2(n_1 - 1)$，$\frac{(n_2-1)S_2^2}{\sigma_2^2} \sim \chi^2(n_2 - 1)$——样本方差的 χ² 分布结构（下下节证明）。
- **第二步，相除**：两式相除，$(n_1-1)$、$(n_2-1)$ 各归各的自由度，得 $F = \frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2}$。
- **第三步，约去未知**：若假设 $\sigma_1^2 = \sigma_2^2$，未知参数抵消，$F = S_1^2/S_2^2$ 可实际计算——这就是「方差相等性检验」的统计量。

「先各自 χ² 化，再相除消去未知参数」是 F 统计量构造的通用思路。第九章方差分析的 F 统计量（组间均方 / 组内均方）遵循完全相同的逻辑。

## 5 F 分布的深入应用与实例

F 分布是「方差比」与「方差分析」的公共统计量，它的性质、查表与判断值得展开。

### 例：方差比检验的完整计算

**例**：两组各 $n_1 = 12$、$n_2 = 10$ 件，$s_1^2 = 0.8$、$s_2^2 = 0.5$。检验方差是否相等（$\alpha = 0.05$ 双侧）：

$$F = \frac{0.8}{0.5} = 1.6$$

$F_{0.025}(11, 9) = 3.91$，$1.6 < 3.91$ 且 $1.6 > 1/F_{0.025}(9,11) = 0.279$ → 不拒绝——两产线方差无显著差异。

### F 分布的性质速查

| 性质 | 内容 |
| --- | --- |
| 取值 | $F > 0$ |
| 倒数对称 | $1/F \sim F(n_2, n_1)$ |
| 与 t 关系 | $t^2 \sim F(1, n)$ |
| 均值 | $\frac{n_2}{n_2 - 2}$（$n_2 > 2$） |

**「倒数对称 + 查右尾表」是 F 分布查表的全部技巧**——左尾分位点用倒数。

### F 分布与卡方、t 的关系

| 分布 | 关系 |
| --- | --- |
| $\chi^2$ | 两个独立 $\chi^2$ 之比 |
| $t$ | $t^2 \sim F(1, n)$ |
| 正态 | 方差比的推断基础 |

**「F 是 χ² 的商、t 的平方」**——三个抽样分布家族血脉相连。

### 例：方差分析中的 F

**例**：单因素 ANOVA，组间均方 $MS_A = 5.2$、组内均方 $MS_E = 1.3$，$F = 4.0$。与 $F_{0.05}(3, 20) = 3.10$ 比较，$4.0 > 3.10$ → 拒绝「各组均值相等」——「组间波动相对组内足够大」时拒绝。

**易错点｜辨析：** ① 自由度顺序「分子→第一」不可颠倒——$F(n_1-1, n_2-1)$ 的 $n_1$ 属分子；② 双侧检验的左尾用倒数对称查表；③ F 检验对「总体正态 + 独立」敏感——非正态或相关样本下结论需谨慎。

## 6 小结

- **F 分布** $F = \frac{V_1/n_1}{V_2/n_2}$（两个独立 χ² 之比），自由度 $(n_1, n_2)$，只取正值。
- **倒数对称**：$1/F \sim F(n_2, n_1)$——左尾分位点用倒数查右尾表。
- **$t^2 \sim F(1, n)$**——t 与 F 的桥梁。
- 方差比检验：$\sigma_1^2 = \sigma_2^2$ 时 $S_1^2/S_2^2 \sim F(n_1-1, n_2-1)$。
- F 分布是方差比检验与第九章方差分析的全部检验统计量的家。
