## 为什么从回归系数的分布开始

上一节用最小二乘估出了 $\hat a$、$\hat b$，但它们是基于样本的**估计量**——换个样本，斜率和截距会变。要做区间估计、显著性检验（下一节），必须先知道**$\hat a$、$\hat b$ 的抽样分布**。同时，模型里的误差方差 $\sigma^2$ 也是未知的，需要从残差估计。本节就是回归推断的「抽样分布」章节。

回归系数的分布理论是第九章回归推断的地基：它决定了系数置信区间怎么构造、显著性检验用哪个统计量、预测区间怎么算。它也是「最小二乘估计量是最佳线性无偏估计（BLUE）」这一现代统计重要结论的展示场。<span class="marginnote">本节的一个小背景：$\hat b$ 是 $y_i$ 的线性组合（$\hat b = \sum c_i y_i$，系数 $c_i = (x_i - \bar x)/S_{xx}$），而 $y_i$ 是正态变量，所以 $\hat b$ 也是正态——「正态变量的线性组合仍正态」在这里第三次出场（前两次是样本均值、$\bar X - \bar Y$）。一切回归推断都建立在这条性质上。</span>

## 1 回归系数的分布

在模型 $y_i = a + bx_i + \varepsilon_i$（$\varepsilon_i \sim N(0,\sigma^2)$ 独立）下：

$$\hat b \sim N\left(b,\ \frac{\sigma^2}{S_{xx}}\right), \qquad \hat a \sim N\left(a,\ \sigma^2\left(\frac{1}{n} + \frac{\bar x^2}{S_{xx}}\right)\right)$$

- **$\hat b$ 无偏**：$E[\hat b] = b$——样本斜率平均打中真实斜率；
- **方差**：$\mathrm{Var}(\hat b) = \sigma^2/S_{xx}$——$x$ 越分散（$S_{xx}$ 大），斜率估计越准；
- **$\hat a$ 无偏**：$E[\hat a] = a$，方差随 $\bar x$ 偏离 0 而增大（远离数据中心的截距更难估准）。

<span class="marginnote">「$S_{xx}$ 越大，$\hat b$ 方差越小」有极强的直觉：自变量覆盖范围越广，直线「放哪」的信息越足，斜率越稳。反过来，若所有 $x_i$ 挤在一起，斜率几乎无法确定——这也是实验设计里「扩大 $x$ 的范围」能提升回归精度的原因。</span>

## 2 σ² 的估计：残差方差

误差方差 $\sigma^2$ 用**残差平方和（residual sum of squares）**估计：

$$\hat\sigma^2 = \frac{1}{n-2}\sum_{i=1}^n (y_i - \hat a - \hat b x_i)^2 = \frac{S_E}{n-2}$$

其中 $S_E = \sum(y_i - \hat y_i)^2$ 是残差平方和，自由度 $n - 2$（两个回归系数各吃掉一个自由度）。**无偏性**：$E[\hat\sigma^2] = \sigma^2$，且 $\frac{S_E}{\sigma^2} \sim \chi^2(n-2)$。<span class="marginnote">自由度 $n-2$ 与第六章「$n-1$」一脉相承：样本方差是估计 1 个均值吃 1 个自由度，回归残差是估计 2 个系数（截距 + 斜率）吃 2 个自由度。这个「估计多少参数，就减多少自由度」的规律，是自由度理论的统一线索——第九章多元回归会变成 $n-p-1$。</span>

## 3 用 t 分布做回归推断

把 $\sigma^2$ 用 $\hat\sigma^2$ 代替，得到 t 统计量。$\hat b$ 的标准化：

$$T = \frac{\hat b - b}{\sqrt{\hat\sigma^2 / S_{xx}}} \sim t(n-2)$$

$\hat a$ 同理：$T = \frac{\hat a - a}{\sqrt{\hat\sigma^2(1/n + \bar x^2/S_{xx})}} \sim t(n-2)$。这两条 t 分布是下一节「回归系数显著性检验」与「系数置信区间」的全部统计量。<span class="marginnote">「用 $\hat\sigma^2$ 代替 $\sigma^2$，正态变 t」与第六章样本均值推断完全同构：分母标准误里换入估计值，分布从 $N$ 变 $t(n-2)$。回归推断的自由度 $n-2$ 与单样本 t 的 $n-1$ 只差在「多估一个斜率」。这套「先正态、换估计、变 t」的流程贯穿回归推断。</span>

## 4 公式解析：为什么斜率方差是 σ²/Sxx

$\hat b$ 的方差公式是本节最重要的一个数，拆开它：

$$

\mathrm{Var}(\hat b) = \frac{\sigma^2}{S_{xx}} = \frac{\sigma^2}{\sum (x_i - \bar x)^2}

$$

- **第一步，$\hat b$ 是 $y$ 的线性组合**：$\hat b = \sum_i c_i y_i$，其中 $c_i = (x_i - \bar x)/S_{xx}$。
- **第二步，方差传播**：$y_i$ 独立、方差 $\sigma^2$，故 $\mathrm{Var}(\hat b) = \sum c_i^2 \sigma^2 = \sigma^2 \sum c_i^2$。
- **第三步，算 $\sum c_i^2$**：$\sum \frac{(x_i - \bar x)^2}{S_{xx}^2} = \frac{S_{xx}}{S_{xx}^2} = \frac{1}{S_{xx}}$。

「方差传播 + 系数平方和」是 $\mathrm{Var}(\hat b)$ 的推导路径。它示范了估计量方差的通用算法：把估计量写成观测的线性组合，方差 = 各系数平方 × $\sigma^2$ 之和。

## 5 最小二乘估计量的深入性质

$\hat a$、$\hat b$ 的分布理论只是冰山一角——它们还有一组「最优性」性质，解释了为什么最小二乘是回归估计的默认选择。

### 高斯—马尔可夫定理：BLUE

**高斯—马尔可夫定理（Gauss–Markov theorem）**：在误差「零均值、同方差、不相关」的假设下（不需要正态），最小二乘估计量是所有**线性无偏估计量（BLUE, Best Linear Unbiased Estimator）**中方差最小的。

**解读**：只要误差满足「零均值、等方差、互不相关」，$\hat b$、$\hat a$ 就是「线性无偏家族」里的冠军——任何其他线性无偏估计量（如加权平均、删除部分数据的估计）方差都不小于最小二乘。这条定理让最小二乘在「不知道误差分布」时依然是最佳线性选择——鲁棒与高效兼得。

**注意**：BLUE 的「最佳」是在**线性无偏**范围内；若允许非线性估计或有偏估计，可能有更好的（如岭回归在偏态下有更小均方误差）。正态假设额外带来的是「估计量正态分布」与「最小二乘 = 最大似然」，这使区间与检验成为可能。

### 残差分析：检验模型假设

拟合后应检查**残差（residual）** $e_i = y_i - \hat y_i$，它们应「像随机噪声」：

- 残差 vs 拟合值 $\hat y$ 的散点应无规律（否则暗示非线性或异方差）；
- 残差应近似正态（用第八章偏度峰度/拟合优度检验）；
- 残差不应随时间/顺序漂移（否则暗示遗漏变量或相关）。

**例**：若残差随 $\hat y$ 增大而「扇形展开」（方差增大），说明**异方差**——$y$ 的方差不是常数，正态假设与 BLUE 的前提受损，需考虑加权最小二乘或对 $y$ 取对数。

### 决定系数 R² 与估计精度的联系

$R^2 = S_R/S_{yy} = 1 - S_E/S_{yy}$ 度量「$x$ 解释掉多少 $y$ 的波动」。它与 $\hat b$ 的标准误有直接联系：

$$S_{\hat b} = \hat\sigma\sqrt{\frac{1}{S_{xx}}} = \frac{\hat\sigma}{s_x\sqrt{n-1}}$$

$R^2$ 越大（$x$ 解释越多），$S_E$ 越小，$\hat\sigma$ 越小，$\hat b$ 越准——**「$x$ 解释力强」与「斜率估计准」是同一件事**。这也是为什么回归报告总是同时给出 $R^2$ 与系数标准误：它们共同描述「这条线有多可信」。

**易错点｜辨析：** BLUE 的前提是「误差不相关、同方差」——若误差序列相关（时间序列数据常见），最小二乘不再是 BLUE，需用广义最小二乘（GLS）。另外，$R^2$ 高不代表「因果」——回归只描述关联，混淆变量可以同时驱动 $x$ 与 $y$，使 $R^2$ 高却无因果意义。



## 6 典型例题：回归估计的分布计算

**例 1（斜率区间）**：$\hat b = 6$，$S_{\hat b} = 1.5$，$n = 12$。$b$ 的 95% 置信区间（$t_{0.025}(10) = 2.228$）：$6 \pm 2.228\times 1.5 = (2.66, 9.34)$——区间不含 0，斜率显著。

**例 2（σ² 的估计）**：残差平方和 $S_E = 800$，$n = 12$，$\hat\sigma^2 = 800/10 = 80$，$\hat\sigma = 8.94$——误差的典型幅度。

**例 3（方差的结构）**：若 $S_{xx} = 40$，则 $\mathrm{Var}(\hat b) = 80/40 = 2$，$S_{\hat b} = \sqrt2 \approx 1.41$——与例 1 的 1.5 同量级（例 1 用了不同数据）。

**例 4（预测的分布）**：$\hat y_0 = 56$ 的置信区间需 $\sqrt{1/n + (x_0-\bar x)^2/S_{xx}}$——$x_0$ 越远离 $\bar x$，$\hat y_0$ 越不稳，区间越宽。这就是「回归直线在数据中心最可靠」的定量表达。

四个例子的共同主线是「分布决定推断」：$\hat b$ 正态、$\hat\sigma^2$ 服从 χ²、$\hat y_0$ 的波动由 $S_{xx}$ 与 $x_0$ 位置共同决定——回归的每个结论都从「估计量的分布」读出，这正是第六章抽样分布思想在回归里的延续。

## 7 小结

- **回归系数分布**：$\hat b \sim N(b, \sigma^2/S_{xx})$，$\hat a \sim N(a, \sigma^2(1/n + \bar x^2/S_{xx}))$——无偏、正态。
- **误差方差估计**：$\hat\sigma^2 = S_E/(n-2)$，无偏，$\frac{S_E}{\sigma^2} \sim \chi^2(n-2)$。
- **t 统计量**：$\frac{\hat b - b}{\sqrt{\hat\sigma^2/S_{xx}}} \sim t(n-2)$——回归推断的引擎。
- $S_{xx}$ 越大斜率估计越准；$x$ 范围广 = 信息多。
- 自由度 $n-2$：「估计两个系数，吃掉两个自由度」。
