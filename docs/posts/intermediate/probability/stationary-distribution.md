## 为什么从平稳分布开始

上一节的极限分布是「$n \to \infty$ 的极限」，而**平稳分布（stationary distribution）**是更基本的对象：**一个满足 $\pi = \pi P$ 的分布**——如果链的初始分布是 $\pi$，则之后每个时刻的分布都是 $\pi$（「不动点」）。遍历链的极限分布恰是平稳分布，但平稳分布的概念更宽（周期链也可能有平稳分布）。

平稳分布是马尔可夫链理论的「收尾概念」，也是应用的入口：PageRank 的网页排名、MCMC 采样的目标分布、排队系统的稳态分布，全部是马尔可夫链的平稳分布。本节把它讲透，并用几个经典例子收束马尔可夫链章。<span class="marginnote">「平稳分布 vs 极限分布」的辨析：<strong>平稳分布是「静态解」——$\pi = \pi P$，一旦到达不再变；极限分布是「动态极限」——$n \to \infty$ 时到达</strong>。遍历链二者重合；周期链有平稳分布但无极限分布（分布振荡）；不可约链的平稳分布若存在则唯一。先想清楚「你在解哪个」，再动笔。</span>

## 1 平稳分布的定义与存在性

**平稳分布（stationary distribution）**：若概率分布 $\pi = (\pi_0, \pi_1, \ldots)$ 满足

$$\pi_j = \sum_i \pi_i \, p_{ij} \quad \text{（即 } \pi = \pi P\text{）}, \qquad \sum_j \pi_j = 1$$

则称 $\pi$ 为链的**平稳分布**。

**含义**：若 $X_0 \sim \pi$，则 $X_n \sim \pi$ 对一切 $n$——「分布不再流动」。它是状态分布更新的**不动点**：$\pi^{(n+1)} = \pi^{(n)}P$ 在 $\pi$ 处「定格」。

**存在与唯一性**：
- 有限状态不可约链：平稳分布**存在且唯一**（常返性保证）；
- 可约链：可能有多个平稳分布（各闭类各一个）；
- 无限状态链：可能不存在（如漂移游走）。<span class="marginnote">平稳分布的存在性判据：<strong>不可约常返链有唯一的平稳分布；有限不可约链必有平稳分布</strong>。周期不影响平稳分布的存在（只影响极限收敛），所以「求平稳分布」比「求极限分布」适用更广——周期链照求不误。工程上多数模型是有限不可约，平稳分布「自动存在」。</span>

## 2 例：PageRank 与平稳分布

**例（网页排序）**：把网页看成状态，浏览者按转移概率在网页间跳转（等概率点击链接）。若跳转链构成遍历马尔可夫链，则平稳分布 $\pi$ 给出「长时间浏览者落在每个网页的时间比例」——**PageRank 分数正是这个平稳分布**。

转移矩阵 $P$：从页面 $i$ 等概率跳到它的所有出链；
平稳方程 $\pi = \pi P$ 的解 = 每个页面的排名；
实际 PageRank 加入「随机跳转」（以概率 $\alpha$ 跳到任意页面）保证不可约非周期——即遍历。

<span class="marginnote">PageRank 是马尔可夫链理论最著名的工业应用：拉里·佩奇 1998 年把「网页排名」翻译成「马尔可夫链的平稳分布」，一举解决了「用链接结构给网页排序」的问题。其中「随机跳转项」就是在工程上制造遍历性（防止悬挂节点让链可约）——理论（遍历定理）与工程（随机跳转）在这里完美对接。</span>

## 3 例：MCMC 采样与 Metropolis 算法

**例（马尔可夫链蒙特卡洛，MCMC）**：要从复杂分布 $f$ 采样（如贝叶斯后验），直接采样困难。MCMC 构造一条以 $f$ 为平稳分布的马尔可夫链，链跑足够久后，采样值 ≈ 从 $f$ 采样。

**Metropolis 算法**的关键——**细致平衡（detailed balance）**：

$$\pi_i \, p_{ij} = \pi_j \, p_{ji} \quad \text{（对一切 } i \ne j\text{）}$$

细致平衡 ⇒ 平稳：若 $\pi_i p_{ij} = \pi_j p_{ji}$ 对一切 $i,j$，则 $\sum_i \pi_i p_{ij} = \sum_i \pi_j p_{ji} = \pi_j$——$\pi$ 是平稳分布。**构造满足细致平衡的转移概率，就能让链以目标分布为平稳分布**。<span class="marginnote">「细致平衡 ⇒ 平稳」是 MCMC 的理论核心：<strong>细致平衡保证「每对状态的净流量为零」——$\pi_i$ 流向 $j$ 的量等于 $\pi_j$ 流向 $i$ 的量，分布不流动</strong>。Metropolis 算法通过「提议 + 接受/拒绝」构造满足细致平衡的转移，让任意目标分布都成为平稳分布。这一节学到的不只是概念，更是现代贝叶斯计算的方法论基石。</span>

## 4 公式解析：细致平衡如何推出平稳

细致平衡是「平稳性的充分条件」，推导只有三步：

$$

\pi_i p_{ij} = \pi_j p_{ji} \ \forall i,j \quad \Longrightarrow \quad \sum_i \pi_i p_{ij} = \pi_j

$$

- **第一步，细致平衡**：对固定的 $j$，$\pi_i p_{ij} = \pi_j p_{ji}$ 对一切 $i$ 成立。
- **第二步，对 $i$ 求和**：$\sum_i \pi_i p_{ij} = \sum_i \pi_j p_{ji} = \pi_j \sum_i p_{ji} = \pi_j \cdot 1 = \pi_j$（行和为 1）。
- **第三步，识别平稳**：$\sum_i \pi_i p_{ij} = \pi_j$ 正是 $\pi = \pi P$——$\pi$ 是平稳分布。

「细致平衡 → 平稳」的证明是「求和 + 行归一」的一行式。它示范了马尔可夫链理论最常用的构造套路：要造「以 $\pi$ 为平稳分布的链」，只需设计满足细致平衡的转移——MCMC 的全部艺术都在这条思路上。

## 5 平稳分布的深入应用与实例

平稳分布是马尔可夫链的「归宿」，它的计算、应用与哲学意义值得展开。

### 例：解平稳方程

**例**：$P = \begin{pmatrix} 0.8 & 0.2 \\ 0.4 & 0.6 \end{pmatrix}$。解 $\pi = \pi P$ + 归一：

$$\begin{cases} \pi_0 = 0.8\pi_0 + 0.4\pi_1 \\ \pi_0 + \pi_1 = 1 \end{cases} \implies \pi_0 = \frac{2}{3},\ \pi_1 = \frac{1}{3}$$

长期 2/3 时间晴——无论起点，跑得足够久分布固定。

### 平稳分布 vs 极限分布

| | 平稳分布 | 极限分布 |
| --- | --- | --- |
| 定义 | $\pi = \pi P$ | $\lim_n P^n$ 的行 |
| 存在 | 常返链必有 | 需非周期 |
| 关系 | 静态解 | 动态极限 |

**遍历链二者重合；周期链有平稳无极限**——「求平稳」比「求极限」适用更广。

### 应用：PageRank

网页跳转链的平稳分布 = 每个页面的长期浏览比例 = **PageRank 分数**。「随机跳转」项保证不可约非周期，让平稳分布唯一存在——理论（遍历定理）与工程（随机跳转）在此对接。

### 应用：MCMC 与细致平衡

Metropolis 算法构造满足细致平衡 $\pi_i p_{ij} = \pi_j p_{ji}$ 的转移，使目标分布成为平稳分布——链跑足够久，采样 ≈ 从目标分布采样。**「细致平衡 ⇒ 平稳」是 MCMC 的全部理论**。

### 例：细致平衡的验证

**例**：$\pi = (2/3, 1/3)$，$P$ 如上述。细致平衡检查：$\pi_0 p_{01} = \frac23 \times 0.2 = 0.133$；$\pi_1 p_{10} = \frac13 \times 0.4 = 0.133$——相等 ✓（此链满足细致平衡）。

**易错点｜辨析：** ① 平稳分布不唯一出现在「可约链」——每个闭类各有一个；② 周期链有平稳分布但无极限分布（分布振荡）；③ 解平稳方程需补归一条件 $\sum \pi_j = 1$——漏掉它解只能定到比例。

再补一张「平稳分布的求法」速查：

| 方法 | 适用 |
| --- | --- |
| 解 $\pi = \pi P$ + 归一 | 小规模链 |
| 特征向量（左特征向量） | 解析解 |
| 长轨道统计（MCMC） | 大规模链 |

「小链解方程、大链跑模拟」——平稳分布的可计算性随规模切换。

## 6 小结

- **平稳分布** $\pi = \pi P$：状态分布更新的不动点——一旦到达，不再流动。
- 存在唯一性：有限不可约链平稳分布存在唯一；可约链多个；无限链可能没有。
- **PageRank** = 网页跳转链的平稳分布——马尔可夫链最著名的工业应用。
- **MCMC / Metropolis**：用「细致平衡」构造以目标分布为平稳分布的链——现代贝叶斯计算的基石。
- 平稳分布是极限分布的「静态版本」，两者在遍历链下重合。
