## 为什么从棣莫弗—拉普拉斯中心极限定理开始

中心极限定理的一般形式（Lindeberg–Lévy）是大一统的，但它的**第一个历史版本**——棣莫弗—拉普拉斯定理——专门针对二项分布：**当 $n$ 很大时，二项分布 $B(n,p)$ 逼近正态分布 $N(np, np(1-p))$**。它既是 CLT 的特例（二项 = $n$ 个独立 0-1 之和），又是 CLT 的起点（1733 年棣莫弗在求解赌博问题时首次算出了正态密度）。

这一定理的价值远超「历史情怀」：当 $n$ 大到阶乘没法手算时，二项概率的正态近似是唯一的可行之路。掷 10000 次硬币求「正面在 4900–5100 之间的概率」，精确公式无从下手，正态近似两分钟出答案。<span class="marginnote">历史细节：棣莫弗只处理了 $p = 1/2$ 的情形（对称硬币），并惊讶地发现 $e^{-x^2/2}$ 这条曲线的渐近常数含 $\sqrt{2\pi}$。拉普拉斯后来把它推广到任意 $p$，并把这个结果嵌进他 1812 年的巨著《分析概率论》——「棣莫弗—拉普拉斯」这个联合署名正是这段接力史。</span>

## 1 定理陈述

**棣莫弗—拉普拉斯定理（de Moivre–Laplace theorem）**：设 $X \sim B(n, p)$，$0 < p < 1$，则对任意 $a < b$，

$$\lim_{n \to \infty} P\left\{a \le \frac{X - np}{\sqrt{np(1-p)}} \le b\right\} = \Phi(b) - \Phi(a)$$

即 $\frac{X - np}{\sqrt{np(1-p)}} \xrightarrow{d} N(0, 1)$，等价地 $X \approx N(np, np(1-p))$。<span class="marginnote">对比一般 CLT：二项的均值是 $np$、方差是 $np(1-p)$（第四章汇总表），代入「$\frac{X - \mu}{\sigma}$」就是 $\frac{X - np}{\sqrt{np(1-p)}}$。定理不过是「二项 = $n$ 个独立 0-1 之和」再套 CLT，但历史上它先于一般 CLT 一百多年出现——这正是「特殊先于一般」的科学史常态。</span>

## 2 用正态近似二项的计算

把二项概率 $\sum_{k=a}^{b}\binom{n}{k}p^k(1-p)^{n-k}$ 用正态近似，需要**连续性校正（continuity correction）**：

$$P\{a \le X \le b\} \approx \Phi\left(\frac{b + 0.5 - np}{\sqrt{np(1-p)}}\right) - \Phi\left(\frac{a - 0.5 - np}{\sqrt{np(1-p)}}\right)$$

「把离散的柱子半格外扩」：$P\{X = k\}$ 对应连续区间的 $[k - 0.5, k + 0.5]$。<span class="marginnote">连续性校正的必要性来自离散与连续的「地板」差异：离散的 $X = 3$ 在连续世界里对应 $[2.5, 3.5]$ 的整段面积。不做校正，误差在小 $n$、边界事件上明显；$n$ 很大时校正影响变小，但规范做法永远是「先外扩半格再标准化」。</span>

**例（掷硬币）**：掷一枚均匀硬币 10000 次，求正面次数在 4900 到 5100 之间的概率。$X \sim B(10000, 0.5)$，$\mu = 5000$，$\sigma = \sqrt{2500} = 50$。

$$P\{4900 \le X \le 5100\} \approx \Phi\left(\frac{5100.5 - 5000}{50}\right) - \Phi\left(\frac{4899.5 - 5000}{50}\right) = \Phi(2.01) - \Phi(-2.01) \approx 0.956$$

**直觉**：偏离均值 2 个标准差以内有约 95.6% 的概率——与正态「±2σ ≈ 95%」的三 σ 法则完全合拍。

## 3 适用条件与误差控制

**易错点｜辨析：** 正态近似的适用条件：$np \ge 5$ 且 $n(1-p) \ge 5$（或更宽松的 $np \ge 10$）。当 $p$ 接近 0 或 1 时，二项分布严重偏斜，正态近似失效——这时应改用**泊松近似**（第二章泊松定理）。两者的分工清晰：

| 情形 | 近似工具 | 理由 |
| --- | --- | --- |
| $n$ 大、$p$ 居中（$np, n(1-p)$ 均较大） | 正态 $N(np, np(1-p))$ | 二项峰居中、对称性好 |
| $n$ 大、$p$ 很小、$np$ 适中 | 泊松 $\pi(np)$ | 二项严重右偏，正态失效 |

<span class="marginnote">「$p$ 居中用正态、$p$ 偏小用泊松」是二项近似的黄金分工。判据是「峰在哪」：峰在中间（$np$ 和 $n(1-p)$ 都不小）才谈得上对称；峰贴边（$np$ 小）就乖乖用泊松。这个选择直接影响假设检验里小概率事件的 p 值计算。</span>

**例（选择判断）**：$B(200, 0.5)$：$np = 100 \ge 5$，用正态 ✓。$B(1000, 0.001)$：$np = 1$，用正态失败 ✗，应近似泊松 $\pi(1)$。

## 4 公式解析：连续性校正为何「半格外扩」

连续性校正的「0.5」看起来神秘，拆开就懂了：

$$

P\{X = k\} \approx P\left\{k - 0.5 \le X_c \le k + 0.5\right\}

$$

- **第一步，离散柱子的宽度**：$X = k$ 在柱状图里是一个以 $k$ 为中心、宽度 1 的矩形，覆盖区间 $[k - 0.5, k + 0.5]$。
- **第二步，用连续面积代柱子面积**：把「单柱概率」换成「正态曲线在 $[k-0.5, k+0.5]$ 下的面积」——二者近似相等。
- **第三步，累加与边界**：$P\{a \le X \le b\}$ 对应连续区间 $[a - 0.5, b + 0.5]$，两端的半格都算进去，标准化后查 $\Phi$。

「离散矩形 ↔ 连续面积」是校正的全部机理。它把「柱子的和」翻译成「曲线的面积」，而曲线面积正是正态近似能算的东西。

## 5 棣莫弗—拉普拉斯定理的深入应用

二项的正态近似在工程计算里无处不在，它的精度、校正与替代方案值得展开。

### 例：区间概率的近似计算

**例**：掷硬币 10000 次，$X \sim B(10000, 0.5)$，求 $P\{4900 \le X \le 5100\}$。$\mu = 5000$，$\sigma = 50$。带连续性校正：

$$P\{4900 \le X \le 5100\} \approx \Phi\left(\frac{5100.5-5000}{50}\right) - \Phi\left(\frac{4899.5-5000}{50}\right) = \Phi(2.01) - \Phi(-2.01) \approx 0.956$$

### 校正 vs 不校正的对比

| 计算方式 | 结果 |
| --- | --- |
| 精确（软件） | $\approx 0.9562$ |
| 正态 + 校正 | $\approx 0.9556$ |
| 正态不校正 | $\approx 0.9545$ |

**校正让误差从 ~0.002 降到 ~0.0006**——单点概率的边界事件上校正更重要。

### 适用条件与替代

| 情形 | 工具 |
| --- | --- |
| $np \ge 5$、$n(1-p) \ge 5$ | 正态近似 |
| $n$ 大、$p$ 小、$np$ 适中 | 泊松近似 |
| 精确小样本 | 直接查二项分布表 |

**「p 居中用正态、p 偏小用泊松」**——这是二项近似的黄金分工。

### 例：质量控制的应用

**例**：产品不合格率 $p = 0.02$，抽 $n = 400$ 件，求次品数 $\le 4$ 的概率。$np = 8 \ge 5$，用正态：$P\{X \le 4.5\} \approx \Phi\left(\frac{4.5 - 8}{\sqrt{8\times 0.98}}\right) = \Phi(-1.25) \approx 0.106$——「400 件中次品 ≤ 4」的概率约 10.6%。

**易错点｜辨析：** ① 连续性校正是「先外扩半格再标准化」——端点 +0.5 或 -0.5 不能漏；② $np$ 或 $n(1-p)$ 小于 5 时正态近似严重失真，改用泊松或精确计算；③ 标准化分母 $\sqrt{np(1-p)}$ 是二项标准差，不是 $np$。

再补一张「二项近似的三工具」对照：

| 工具 | 适用 | 参数 |
| --- | --- | --- |
| 精确二项 | 小 $n$ | $n, p$ |
| 正态近似 | $np, n(1-p) \ge 5$ | $np, np(1-p)$ |
| 泊松近似 | $n$ 大、$p$ 小、$np$ 适中 | $np$ |

「p 居中正态、p 偏小泊松、小样本精确」——按条件选工具。

## 6 小结

- **棣莫弗—拉普拉斯定理**：$X \sim B(n,p)$ 标准化后 $\frac{X - np}{\sqrt{np(1-p)}} \xrightarrow{d} N(0,1)$，即 $X \approx N(np, np(1-p))$。
- **连续性校正**：$P\{a \le X \le b\}$ 用 $[a-0.5, b+0.5]$ 的连续区间近似，先外扩半格再标准化。
- 适用条件 $np \ge 5$、$n(1-p) \ge 5$；$p$ 很小时改用**泊松近似**。
- 它是 CLT 的第一个历史版本，1733 年棣莫弗从赌博问题中首次看到正态曲线。
- 二项的正态近似让「大 $n$ 的二项概率」不再依赖阶乘暴力计算。
