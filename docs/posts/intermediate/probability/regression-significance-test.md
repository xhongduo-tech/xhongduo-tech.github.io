## 为什么从线性假设的显著性检验开始

最小二乘总能画出一条回归直线，哪怕是毫无关系的数据。所以回归之后的第一问是：**这条直线真的有意义吗？斜率 $b$ 是否显著不为 0？** 若 $b = 0$，$y$ 与 $x$ 没有线性关系，回归直线等于水平线 $\bar y$——预测毫无价值。检验 $H_0: b = 0$ 就是**线性假设的显著性检验**。

这个检验是回归分析的「意义审计」：它决定回归方程能不能用、$R^2$（决定系数）该不该被信任。它有两种等价形式——t 检验与 F 检验（方差分析视角），两条路径给出相同结论，却各自揭示了回归的不同侧面。<span class="marginnote">检验 $H_0: b = 0$ 的实质是「$x$ 对 $y$ 有没有预测力」。用第八章的语言：斜率显著非 0 → 拒绝「无线性关系」；斜率不显著 → 数据不足以证明 $y$ 随 $x$ 变化。注意「不显著」仍可能是「关系存在但太弱/样本太小」，不是「肯定无关系」。</span>

## 1 t 检验：斜率除以标准误

上一节得到 $\hat b \sim N(b, \sigma^2/S_{xx})$，用 $\hat\sigma^2$ 代替 $\sigma^2$ 后，检验 $H_0: b = 0$：

$$T = \frac{\hat b - 0}{\sqrt{\hat\sigma^2 / S_{xx}}} = \frac{\hat b}{S_{\hat b}} \sim t(n-2) \quad (\text{当 } H_0 \text{ 真})$$

拒绝域：$|T| \ge t_{\alpha/2}(n-2)$（双侧，$H_1: b \ne 0$）；单侧看方向。

**例**：广告与销售额回归，$\hat b = 6$，$S_{\hat b} = 1.5$，$n = 12$。$T = 6/1.5 = 4.0$。$t_{0.025}(10) = 2.228$，$4.0 > 2.228$ → 拒绝 $H_0$——斜率显著非 0，$x$ 对 $y$ 有显著线性影响。<span class="marginnote">t 检验的解读补充：$\hat b$ 与 $S_{\hat b}$ 的关系——$|T|$ 越大，斜率离 0 越远（相对于它的标准误），证据越强。这个「估计 ÷ 标准误」的结构与第八章单样本 t 完全同构，只是自由度 $n-2$。统计软件输出的回归表里，每一行系数都带一个 t 值与 p 值——就是这个检验。</span>

## 2 F 检验：方差分析的回归版

回归也可以用方差分析的框架检验：把 $y$ 的总波动分解为「回归解释」与「残差」两块。

$$S_{yy} = \sum(y_i - \bar y)^2 = \underbrace{\sum(\hat y_i - \bar y)^2}_{S_R\ \text{回归平方和}} + \underbrace{\sum(y_i - \hat y_i)^2}_{S_E\ \text{残差平方和}}$$

$S_R$ 是「被 $x$ 解释的波动」，$S_E$ 是「解释不了的残差」。检验 $H_0: b = 0$：

$$F = \frac{S_R / 1}{S_E / (n-2)} = \frac{MS_R}{MS_E} \sim F(1,\ n-2)$$

拒绝域：$F \ge F_\alpha(1, n-2)$。<span class="marginnote">「$y$ 的总波动 = 回归解释 + 残差」与单因素 ANOVA 的「$S_T = S_A + S_E$」结构完全一致——回归本质上是「$x$ 连续取值」的方差分析。$S_R$ 度量「$x$ 解释掉多少 $y$ 的波动」，$S_R/S_{yy}$ 正是决定系数 $R^2$（下一节会用）。这里 $F(1, n-2)$ 与 t 检验的 $t^2 = F$ 呼应——一元回归里两者等价。</span>

## 3 t 检验与 F 检验的等价

一元回归中，t 检验与 F 检验给出**完全相同**的结论：

$$T^2 = F, \qquad t_{\alpha/2}^2(n-2) = F_\alpha(1, n-2)$$

**直觉**：$T = \hat b/S_{\hat b}$ 检验「斜率离 0 多远」；$F = MS_R/MS_E$ 检验「$x$ 解释了 $y$ 多少波动」。两者是同一件事的两种说法——斜率的平方正是「被解释波动」的化身。

**易错点｜辨析：** 多元回归里 t 与 F 不再等价（F 检验「整个模型」，t 检验「单个系数」），但一元里等价是重要的自检手段：算完 F 可以验 $T^2 = F$，对不上说明计算有误。<span class="marginnote">「一元回归 t 与 F 等价、多元回归分道」是回归推断的里程碑：$t^2 = F(1,\cdot)$ 是一条恒等式（自由度为 1 的 F 分布平方根就是 t 分布）。进入多元回归后，t 管「某个系数是否显著」（其他变量已进模型），F 管「整组变量是否显著」——两个问题不同，工具也不同。</span>

## 4 公式解析：回归平方和的几何含义

回归平方和 $S_R = \sum(\hat y_i - \bar y)^2$ 是「$x$ 解释掉的波动」，拆开它：

$$

S_R = \sum_{i=1}^{n} (\hat y_i - \bar y)^2 = \hat b^2 S_{xx}

$$

- **第一步，把 $\hat y_i$ 写开**：$\hat y_i = \hat a + \hat b x_i = \bar y + \hat b(x_i - \bar x)$（直线过 $(\bar x, \bar y)$）。
- **第二步，偏离总均值**：$\hat y_i - \bar y = \hat b(x_i - \bar x)$——预测值偏离均值 = 斜率 × $x$ 的偏离。
- **第三步，平方求和**：$S_R = \hat b^2 \sum(x_i - \bar x)^2 = \hat b^2 S_{xx}$。

「回归平方和 = 斜率平方 × 自变量波动」是 $S_R$ 的简洁公式。它说明：斜率越陡（$\hat b^2$ 大）、$x$ 覆盖越广（$S_{xx}$ 大），$x$ 解释的波动越多——$R^2$ 的定义就藏在 $S_R/S_{yy}$ 里。

## 5 线性显著性检验的深入与实例

「斜率是否为零」的检验是回归的体检，但它的用法、边界与统计软件的输出格式值得展开。

### t 检验与 F 检验的等价再确认

一元回归中 $T^2 = F$，$t_{\alpha/2}^2(n-2) = F_\alpha(1, n-2)$。**两法结论必一致**——若手算的 t 与 F 对不上（$T^2 \ne F$），说明计算有误。这是回归检验的第一自检。

### 统计软件的输出格式

| 输出项 | 含义 | 对应本章 |
| --- | --- | --- |
| Estimate（$\hat b$） | 斜率估计 | §9.3 |
| Std. Error（$S_{\hat b}$） | 斜率标准误 | §9.3 |
| t value | $\hat b/S_{\hat b}$ | 本节的 t 检验 |
| Pr(>|t|) | 双侧 p 值 | §8.2 |
| Residual standard error | $\hat\sigma$ | §9.3 |

**读得懂回归表**，就等于掌握了一元回归的全部推断——每个数字都能对应到本书的一个公式。

### 例：完整的显著性检验

**例**：$n = 20$，$\hat b = 2.5$，$S_{\hat b} = 0.8$，$S_E = 120$。t 检验：$T = 2.5/0.8 = 3.125$，$t_{0.025}(18) = 2.101$，$3.125 > 2.101$ → 拒绝 $H_0: b = 0$，$x$ 对 $y$ 有显著线性影响。

F 检验交叉验证：$S_R = \hat b^2 S_{xx}$。若 $S_{xx} = 30$，$S_R = 2.5^2 \times 30 = 187.5$，$F = (187.5/1)/(120/18) = 187.5/6.67 = 28.1$。$T^2 = 3.125^2 = 9.77$... 等等，这里 $F \ne T^2$？——因为 $S_{xx}$ 与 $S_{\hat b}$ 必须自洽（$S_{\hat b}^2 = \hat\sigma^2/S_{xx}$）。本例 $S_{\hat b}^2 = 0.64$，$\hat\sigma^2 = 120/18 = 6.67$，需 $S_{xx} = 6.67/0.64 = 10.4$ 而非 30。代入 $S_R = 2.5^2 \times 10.4 = 65$，$F = 65/6.67 = 9.75 \approx T^2$ ✓。

**易错点｜辨析：** ① t 检验是「控制其他后单个系数」的检验，多元回归里与整体 F 不再等价；② 「显著」只说明「斜率非零有统计证据」，不代表「效应大」——看置信区间判断幅度；③ $R^2$ 与 F 的关系：$F = \frac{R^2/1}{(1-R^2)/(n-2)}$——$R^2$ 越大 F 越大，两者同向。

再补一张「回归 ANOVA 表」的速查：

| 来源 | SS | df | MS | F |
| --- | --- | --- | --- | --- |
| 回归 | $S_R$ | 1 | $S_R$ | $S_R/(S_E/(n-2))$ |
| 残差 | $S_E$ | $n-2$ | $S_E/(n-2)$ | |
| 总和 | $S_{yy}$ | $n-1$ | | |

「回归平方和 + 残差平方和 = 总平方和」，F = 回归均方/残差均方——这张表与第九章方差分析同构。

再补一张「t vs F」检验对照：

| | t 检验 | F 检验 |
| --- | --- | --- |
| 对象 | 单个系数 | 整个模型 |
| 统计量 | $\hat b/S_{\hat b}$ | $MS_R/MS_E$ |
| 一元等价 | $T^2 = F$ | — |
| 多元分工 | 单系数 | 整体显著 |

「一元里 t 与 F 等价、多元里分工」——两种检验的适用范围要分清。

## 6 小结

- **t 检验**：$T = \hat b/S_{\hat b} \sim t(n-2)$——斜率离 0 多远（相对标准误）。
- **F 检验**：$F = MS_R/MS_E \sim F(1, n-2)$——$x$ 解释的波动 vs 残差波动。
- **一元等价**：$T^2 = F$，$t_{\alpha/2}^2(n-2) = F_\alpha(1,n-2)$——两种检验同一结论。
- $S_{yy} = S_R + S_E$：总波动 = 回归解释 + 残差，$S_R = \hat b^2 S_{xx}$。
- 检验 $b = 0$ 是回归的「意义审计」：不显著说明线性关系缺乏证据。
