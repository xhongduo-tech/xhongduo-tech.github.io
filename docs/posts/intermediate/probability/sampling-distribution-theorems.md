## 为什么从抽样分布基本定理开始

第六章的 χ²、t、F 三节各自引入一个分布，上一节又给出了样本均值与样本方差的具体分布。**抽样分布基本定理**把这套内容收拢成一张全景图：在正态总体下，样本统计量的精确分布究竟是什么。它是「抽样分布」章的收官，也是第七章参数估计、第八章假设检验的「出发港」。

这张全景图的意义在于「**选择**」：针对「推断均值」还是「推断方差」、「方差已知」还是「方差未知」、「单样本」还是「双样本」，该用哪种分布——全部由本节这张图决定。读懂了它，后面七、八章的无数公式就不再是孤立记忆，而是一张地图上的不同路线。<span class="marginnote">把第六章想成一张「抽样分布驾照考试」：χ² 管方差、t 管未知方差的均值、F 管方差比。本节是总复习——三张表（单总体均值、单总体方差、双总体）把所有情形归档。考试与实务里「该用哪个分布」的题，答案全在本节这张表里。</span>

## 1 单正态总体的抽样分布

设 $X_1, \ldots, X_n$ 来自 $N(\mu, \sigma^2)$，样本均值 $\bar X$、样本方差 $S^2$。核心结论三件套：

| 统计量 | 分布 | 用途 |
| --- | --- | --- |
| $\dfrac{\bar X - \mu}{\sigma/\sqrt n}$ | $N(0, 1)$ | 方差已知时的均值推断（z 区间/z 检验） |
| $\dfrac{\bar X - \mu}{S/\sqrt n}$ | $t(n-1)$ | 方差未知时的均值推断（t 区间/t 检验） |
| $\dfrac{(n-1)S^2}{\sigma^2}$ | $\chi^2(n-1)$ | 方差的推断（χ² 区间/检验） |

且 $\bar X$ 与 $S^2$ 相互独立。<span class="marginnote">这张表的「选择逻辑」是第七章、第八章所有公式的决策树：<strong>推断均值 → 问方差已知吗 → 已知用 z、未知用 t；推断方差 → 用 χ²</strong>。三个统计量里只有第一个是 CLT 型（大样本近似），后两个在正态假设下是精确分布。</span>

## 2 两个正态总体的抽样分布

设 $X_1,\ldots,X_{n_1} \sim N(\mu_1, \sigma_1^2)$ 与 $Y_1,\ldots,Y_{n_2} \sim N(\mu_2, \sigma_2^2)$ 独立，$\bar X, \bar Y$ 与 $S_1^2, S_2^2$ 为各自的样本均值与方差。核心结论：

- **均值差**（$\sigma_1^2, \sigma_2^2$ 已知）：
  $$\frac{(\bar X - \bar Y) - (\mu_1 - \mu_2)}{\sqrt{\dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2}}} \sim N(0, 1)$$
- **均值差**（$\sigma_1^2 = \sigma_2^2 = \sigma^2$ 未知）：用合并样本方差
  $$S_w^2 = \frac{(n_1 - 1)S_1^2 + (n_2 - 1)S_2^2}{n_1 + n_2 - 2}$$
  则 $\frac{(\bar X - \bar Y) - (\mu_1 - \mu_2)}{S_w\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} \sim t(n_1 + n_2 - 2)$；
- **方差比**：$\frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1 - 1,\ n_2 - 1)$。

<span class="marginnote">「均值差」的统计量结构值得注意：分子是两个样本均值之差减期望差，分母是「差的方差开方」——$\mathrm{Var}(\bar X - \bar Y) = \frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}$（独立时方差相加，第四章）。两总体情形的关键假设是<strong>两组样本独立</strong>；若两组不独立（成对数据），第八章《基于成对数据的检验》另有更精细的做法。</span>

## 3 抽样分布的决策树

把单总体与双总体的结论合起来，得到一张「推断该用哪个分布」的决策树：

| 推断对象 | 条件 | 统计量 | 分布 |
| --- | --- | --- | --- |
| 单总体均值 | $\sigma$ 已知 | $\dfrac{\bar X - \mu}{\sigma/\sqrt n}$ | $N(0,1)$ |
| 单总体均值 | $\sigma$ 未知 | $\dfrac{\bar X - \mu}{S/\sqrt n}$ | $t(n-1)$ |
| 单总体方差 | — | $\dfrac{(n-1)S^2}{\sigma^2}$ | $\chi^2(n-1)$ |
| 双总体均值差 | $\sigma$ 已知 | 标准化均值差 | $N(0,1)$ |
| 双总体均值差 | $\sigma$ 未知且相等 | 合并方差版 | $t(n_1+n_2-2)$ |
| 双总体方差比 | — | $\dfrac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2}$ | $F(n_1-1, n_2-1)$ |

**易错点｜辨析：** 三个最常踩的坑——① 均值推断时忘了「方差已知/未知」决定 z 还是 t；② 双总体均值差用「方差未知」时，前提是两总体方差相等，否则要用近似的 Welch 校正；③ 自由度算错：t 的自由度 $n_1 + n_2 - 2$，F 的 $(n_1-1, n_2-1)$，χ² 的 $n-1$。<span class="marginnote">双总体方差不等时的处理（Welch's t）教材常略过，但它是真实数据分析的常态：两组样本方差明显不同，仍强行用合并方差 t 会偏。实践中软件（R、Python）默认多给一个「不假设方差相等」的选项，背后正是这套抽样分布的延伸。</span>

## 4 公式解析：合并样本方差为何取加权平均

双总体均值差里合并样本方差 $S_w^2$ 的构造值得拆开：

$$

S_w^2 = \frac{(n_1 - 1)S_1^2 + (n_2 - 1)S_2^2}{n_1 + n_2 - 2}

$$

- **第一步，分子的自由度加权**：两个 χ² 变量 $(n_1-1)S_1^2/\sigma^2$ 与 $(n_2-1)S_2^2/\sigma^2$ 独立且自由度各为 $n_1-1$、$n_2-1$，相加减自由度相加（χ² 可加性）。
- **第二步，分母是总自由度**：$n_1 + n_2 - 2$——「样本量之和 − 2 个被估计的均值」。除以它使 $E[S_w^2] = \sigma^2$（无偏）。
- **第三步，权重**：$S_w^2$ 是 $S_1^2$ 与 $S_2^2$ 按自由度加权的平均——样本量大的那组贡献更大，直觉合理。

「自由度加权 + 无偏化」是合并方差的全部设计。它保证 $t$ 统计量服从精确的 $t(n_1+n_2-2)$，从而第七章的双样本 t 区间、第八章的双样本 t 检验得以成立。

## 5 抽样分布定理的深入应用与实例

抽样分布定理是「正态总体的推断总表」，它的使用、前提与软件对应值得展开。

### 例：单总体三件套

**例**：$n = 25$、$\bar x = 50$、$s = 4$，总体正态。$\mu$ 的 95% 区间 $50 \pm t_{0.025}(24)\times 4/5$；$\sigma^2$ 的区间用 $\frac{24\times 16}{\chi^2}$——**「查表选分布」**是抽样分布的应用。

### 双总体三件套

| 对象 | 条件 | 分布 |
| --- | --- | --- |
| 均值差 | 方差已知 | $N$ |
| 均值差 | 方差相等未知 | $t(n_1+n_2-2)$ |
| 方差比 | — | $F(n_1-1, n_2-1)$ |

**「双总体的三个分布」**与单总体一一对应，只是自由度与结构扩展。

### 决策树：选哪个分布

| 问 | 答 |
| --- | --- |
| 推断均值？方差已知？ | z |
| 推断均值？方差未知？ | t |
| 推断方差？ | χ² |
| 比较两方差？ | F |

**「均值看 z/t、方差看 χ²、比方差看 F」**——一张决策树收齐所有场景。

### 例：自由度的一致性

单总体 t 自由度 $n-1$、双总体 $n_1+n_2-2$、回归 $n-p-1$——**「估计多少参数就减多少自由度」**是自由度理论的统一规律。

### 正态性的前提检查

所有抽样分布定理都以总体正态为前提——**「先验正态性（偏度峰度/QQ 图），再用抽样分布」**是非正态风险的防线。

**易错点｜辨析：** ① 统计量与其分布必须配套（z 配 $N$、t 配 $t$）——别张冠李戴；② 双总体方差相等是合并方差的前提；③ 大样本可近似（CLT），但「近似」与「精确」要分清。

## 6 小结

- **单总体**：$\bar X$ 标准化（$\sigma$ 已知）~ $N(0,1)$；$\sigma$ 未知用 $S$ 则 ~ $t(n-1)$；$(n-1)S^2/\sigma^2$ ~ $\chi^2(n-1)$。
- **双总体**：均值差已知方差 ~ $N(0,1)$；方差相等未知时 ~ $t(n_1+n_2-2)$（合并方差）；方差比 ~ $F(n_1-1, n_2-1)$。
- 选择决策树：**推断均值看方差已知否（z/t），推断方差用 χ²，方差比用 F**。
- 双总体均值差的前提是两方差相等，不等时应改用 Welch 近似。
- 抽样分布基本定理是第七章区间估计、第八章假设检验的出发港。
