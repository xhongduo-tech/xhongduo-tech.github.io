## 为什么从单侧置信区间开始

到目前为止的置信区间都是**双侧**的：$[\hat\theta_1, \hat\theta_2]$，两头都顾。但现实里许多问题只关心**一边**：材料的抗拉强度「至少不低于」多少？平均寿命「至少不低于」多少小时？产品缺陷率「至多不超过」百分之几？这些「至少」「至多」型问题需要的不是双侧区间，而是**单侧置信区间（one-sided confidence interval）**——只给出上限或只给出下限。

单侧区间与第八章的「单边检验」是一对孪生兄弟：单侧置信下限对应「检验参数是否小于某值」的单边检验。掌握它，等于拿到了「只问一边」这类工程问题的标准回答格式。<span class="marginnote">单侧区间与双侧区间的取舍原则：<strong>双侧区间问「参数大概在哪」，单侧区间问「参数保证不低于（或不高于）多少」</strong>。工程验收（材料强度下限、寿命下限）、安全审查（缺陷率上限）几乎只用单侧——因为「太强没关系，太弱才要命」。选错单双侧会让区间承诺的把握与实际不符。</span>

## 1 单侧置信下限与上限

**单侧置信下限（lower confidence bound）**：若统计量 $\hat\theta_1$ 满足

$$P\{\hat\theta_1 \le \theta\} = 1 - \alpha$$

则称 $\hat\theta_1$ 为 $\theta$ 的**置信水平 $1-\alpha$ 的单侧置信下限**——「$\theta$ 至少不低于 $\hat\theta_1$」的把握是 $1-\alpha$。

**单侧置信上限（upper confidence bound）**：若 $\hat\theta_2$ 满足 $P\{\theta \le \hat\theta_2\} = 1-\alpha$，则称 $\hat\theta_2$ 为 $\theta$ 的**单侧置信上限**——「$\theta$ 至多不超过 $\hat\theta_2$」的把握是 $1-\alpha$。

**关键差别**：双侧区间把 $\alpha$ 分成两半（两侧各 $\alpha/2$），单侧区间把整个 $\alpha$ 放在一侧——所以单侧分位点用 $z_\alpha$（或 $t_\alpha$）而非 $z_{\alpha/2}$。<span class="marginnote">单侧与双侧的分位点区别是本节唯一的「技术差别」，也是最容易错的地方：<strong>双侧用 $z_{\alpha/2}$（把 $\alpha$ 均分两侧），单侧用 $z_\alpha$（$\alpha$ 全给一侧）</strong>。例如 95% 置信水平：双侧用 1.96，单侧用 1.645。记住「单侧更靠近中心」——因为风险只朝一边看。</span>

## 2 正态总体均值的单侧区间

**方差已知**：$\mu$ 的单侧置信下限与上限分别为

$$\bar X - z_\alpha\frac{\sigma}{\sqrt n} \quad(\text{下限}), \qquad \bar X + z_\alpha\frac{\sigma}{\sqrt n} \quad(\text{上限})$$

**方差未知**：把 $z_\alpha$ 换成 $t_\alpha(n-1)$、$\sigma$ 换成 $S$：

$$\bar X - t_\alpha(n-1)\frac{S}{\sqrt n} \quad(\text{下限}), \qquad \bar X + t_\alpha(n-1)\frac{S}{\sqrt n} \quad(\text{上限})$$

**例（寿命下限）**：灯泡寿命 $X \sim N(\mu, \sigma^2)$，$\sigma$ 未知，抽查 $n = 25$，$\bar x = 2400$ 小时，$s = 100$ 小时。求 $\mu$ 的 95% 单侧置信下限（$t_{0.05}(24) = 1.711$）：

$$2400 - 1.711 \times \frac{100}{\sqrt{25}} = 2400 - 34.2 = 2365.8\ \text{小时}$$

**结论：以 95% 的把握，平均寿命不低于 2365.8 小时**——比双侧区间「更有底气」（双侧下限更低、上限更高），因为单侧把全部风险压向一边。<span class="marginnote">对比双侧：同样的数据，双侧 95% 区间是 $2400 \pm 2.064\times 20 = (2358.7, 2441.3)$，下限 2358.7 低于单侧下限 2365.8。为什么？双侧要在两侧各留 2.5% 风险，单侧只在一侧留 5%——所以单侧对「那一侧」的承诺更紧。这也是「单边问题用单侧区间」的理由：你只关心下限，就别让上限分摊风险。</span>

## 3 方差与比例的单侧区间

**方差 $\sigma^2$ 的单侧上限**（用于「波动不能超过多少」）：

$$\sigma^2 \le \frac{(n-1)S^2}{\chi^2_{1-\alpha}(n-1)}$$

**比例 $p$ 的单侧上限**（用于「缺陷率不能超过多少」）：

$$p \le \hat p + z_\alpha\sqrt{\frac{\hat p(1-\hat p)}{n}}$$

**例（缺陷率上限）**：抽检 $n = 200$ 件，5 件次品，$\hat p = 0.025$。95% 单侧上限：

$$0.025 + 1.645\sqrt{\frac{0.025 \times 0.975}{200}} = 0.025 + 1.645 \times 0.011 = 0.025 + 0.018 = 0.043$$

**结论：以 95% 的把握，缺陷率不超过 4.3%**——若验收标准是 5%，则通过。<span class="marginnote">「缺陷率上限」是单侧区间的典型应用：质检合同常写「缺陷率须以 95% 把握不超过 5%」。此时双侧区间反而不合适——我们根本不在乎缺陷率「太低」，只担心它「太高」。工程与合规场景里，单侧区间几乎总是比双侧更贴切。</span>

**易错点｜辨析：** 单侧区间里「$\alpha$ 全给一侧」意味着分位点是 $z_\alpha$ 而非 $z_{\alpha/2}$。另一个常见错误：写单侧区间时误写成「$\bar X \pm z_\alpha \frac{\sigma}{\sqrt n}$」——**单侧没有 $\pm$**，只有一个方向的端点。单侧下限只有「减」，单侧上限只有「加」。

## 4 公式解析：单侧区间从哪里来

单侧区间的推导与双侧完全同源，只是把风险集中到一侧，以正态均值（方差已知）为例：

$$

P\left\{\frac{\bar X - \mu}{\sigma/\sqrt n} \ge -z_\alpha\right\} = 1 - \alpha \iff P\left\{\mu \le \bar X + z_\alpha\frac{\sigma}{\sqrt n}\right\} = 1 - \alpha

$$

- **第一步，枢轴量**：$Z = \frac{\bar X - \mu}{\sigma/\sqrt n} \sim N(0,1)$。
- **第二步，单侧概率**：$P\{Z \ge -z_\alpha\} = 1 - \alpha$——把 $\alpha$ 全部留在左尾（$Z < -z_\alpha$ 的概率是 $\alpha$）。
- **第三步，反解**：$Z \ge -z_\alpha \iff \mu \le \bar X + z_\alpha\frac{\sigma}{\sqrt n}$——得到 $\mu$ 的单侧上限。

「枢轴量的单侧概率区间 → 反解」与双侧的区别只有一处：分位点从 $z_{\alpha/2}$（双侧）变成 $z_\alpha$（单侧）。理解了这一点，单侧区间的所有公式都可以从双侧「现改」。

## 5 单侧区间的深入应用与实例

单侧区间是「只问一边」的工程语言，它的构造、判读与实务值得展开。

### 例：单侧下限的应用

**例**：灯泡寿命，$n = 25$、$\bar x = 2400$、$s = 100$。95% 单侧下限（$t_{0.05}(24) = 1.711$）：

$$2400 - 1.711\times\frac{100}{5} = 2365.8$$

「以 95% 把握，平均寿命不低于 2365.8 小时」——工程验收的标准句。

### 单侧 vs 双侧

| | 单侧 | 双侧 |
| --- | --- | --- |
| 分位点 | $z_\alpha$ | $z_{\alpha/2}$ |
| 风险 | 全给一侧 | 两侧均分 |
| 承诺 | 只保一边 | 两边都保 |
| 宽度 | 一边更紧 | 两边更宽 |

**「单侧更紧、双侧更全」**——只问一边就用单侧，别让另一侧分摊风险。

### 例：单侧上限

**例**：缺陷率 $\hat p = 0.025$、$n = 200$。95% 单侧上限 $0.025 + 1.645\sqrt{0.025\times0.975/200} = 0.043$——「以 95% 把握，缺陷率不超过 4.3%」。

### 应用场景

| 场景 | 单侧 |
| --- | --- |
| 材料强度 | 下限 |
| 寿命验收 | 下限 |
| 缺陷率 | 上限 |
| 污染排放 | 上限 |

**「只担心一边的工程场景」**几乎都用单侧区间。

### 与单边检验的对偶

单侧区间与单边检验互为对偶——「检验 $\mu > \mu_0$」=「$\mu_0$ 低于单侧下限」。**「单侧区间 = 单边检验的区间版」**，第七章与第八章呼应。

**易错点｜辨析：** ① 单侧无「$\pm$」——只有一端；② 分位点 $z_\alpha$ 不是 $z_{\alpha/2}$；③ 「至少」「至多」的措辞决定下限还是上限——看题目问哪边。

## 6 小结

- **单侧置信下限** $P\{\hat\theta_1 \le \theta\} = 1-\alpha$；**单侧上限** $P\{\theta \le \hat\theta_2\} = 1-\alpha$。
- 分位点用 $z_\alpha$（或 $t_\alpha$）而非 $z_{\alpha/2}$——**$\alpha$ 全给一侧**；单侧无 $\pm$。
- 均值单侧：$\bar X \mp t_\alpha(n-1)\frac{S}{\sqrt n}$（下限用减、上限用加）。
- 方差上限 $\frac{(n-1)S^2}{\chi^2_{1-\alpha}(n-1)}$；比例上限 $\hat p + z_\alpha\sqrt{\hat p(1-\hat p)/n}$。
- 工程验收、安全合规「只问一边」时用单侧区间，双侧会稀释对那一侧的承诺。
