## 为什么从 bootstrap 置信区间开始

第七章的置信区间全靠解析公式（z、t、χ²、F），它们要求总体正态、或 CLT 近似。可一旦统计量复杂（中位数、比值、相关系数）或分布未知，解析区间就没了。**bootstrap 置信区间**直接从 $B$ 个 bootstrap 复制里取分位数——不需要任何分布假设，是最通用的区间构造法。

bootstrap 置信区间是现代推断的「万金油」：它适用于任何统计量、任何分布，是数据科学报告「不确定性」的标准做法。本节介绍最常用的两种——**百分位法**与**标准误法**，并辨析它们的适用与局限。<span class="marginnote">bootstrap 置信区间的思想一句话：<strong>既然 bootstrap 复制的分布 ≈ $\hat\theta$ 的抽样分布，那「复制的 2.5% 与 97.5% 分位数」就构成了 $\hat\theta$ 的 95% 区间</strong>。它不需要枢轴量、不需要分布表、不需要 CLT——直接从模拟分布「切一刀」。</span>

## 1 百分位法：直接取分位数

**百分位区间（percentile interval）**：把 $B$ 个 bootstrap 复制 $\hat\theta^{*1}, \ldots, \hat\theta^{*B}$ 从小到大排序，取第 $\alpha/2$ 与 $1-\alpha/2$ 分位数：

$$\left(\hat\theta^*_{(\alpha/2)},\ \ \hat\theta^*_{(1-\alpha/2)}\right)$$

**例（中位数区间）**：50 个家庭年收入的 bootstrap 复制 2000 个中位数，排序后取 2.5% 与 97.5% 分位，得中位数的 95% 置信区间 $(34.1,\ 41.8)$ 万元。<span class="marginnote">百分位法的前提：bootstrap 复制分布近似 $\hat\theta$ 的分布。若 $\hat\theta$ 的分布近似对称，百分位区间表现很好；若分布偏斜（中位数、比例常偏），百分位区间仍能「跟着偏」，比对称的解析区间更贴切。它是「分布不对称时区间跟着不对称」的天然解法。</span>

## 2 标准误法：bootstrap 版 z 区间

**标准误区间（bootstrap-t / normal interval）**：沿用正态近似的形式，把解析标准误换成 bootstrap 标准误：

$$\left(\hat\theta - z_{\alpha/2}\,\widehat{se}_B,\ \ \hat\theta + z_{\alpha/2}\,\widehat{se}_B\right)$$

即「估计值 ± 正态分位点 × bootstrap 标准误」。它假设 $\hat\theta$ 的分布近似正态——比百分位法多一个正态假设，但计算更简单（只需标准误）。<span class="marginnote">「标准误法」与第七章 z 区间的唯一区别：标准误从解析公式换成 bootstrap 模拟。它保留了「对称区间」的形式——适合 $\hat\theta$ 分布近似正态时；若分布明显偏斜，标准误法可能给出「一边超界」的区间（如比例的区间跑出 $[0,1]$），这时百分位法更稳健。</span>

## 3 两种方法的对比与选择

| | 百分位法 | 标准误法 |
| --- | --- | --- |
| 原理 | 复制分布的分位数 | 估计值 ± 正态分位 × bootstrap 标准误 |
| 分布假设 | 复制分布 ≈ 真实分布 | 复制分布近似正态 |
| 偏斜处理 | 自动跟随偏斜 | 假设对称，偏斜时失真 |
| 计算 | 只需排序取分位 | 需先算 bootstrap 标准误 |

**易错点｜辨析：** ① 百分位法不需要算标准误，直接取分位数——「排序」是关键动作；② 标准误法的区间以 $\hat\theta$ 为中心对称，偏斜分布下可能「含负值」等荒谬结果；③ 两者都需要 $B$ 足够大（≥1000）保证分位数稳定；④ bootstrap 区间是近似的——样本量太小或统计量极不稳定时，bootstrap 也可能不靠谱。<span class="marginnote">「$B$ 越大区间越稳」是模拟精度问题：$B = 1000$ 时百分位区间已较稳定，$B = 10000$ 更稳。但注意——$B$ 只影响模拟误差，不影响统计误差（那由原始样本量 $n$ 决定）。增大 $B$ 不会让「错误的近似」变正确，只会让「正确的近似」更精确。</span>

**例（相关性的 bootstrap 区间）**：样本相关系数 $r = 0.62$，$n = 30$。bootstrap 复制 5000 个相关系数，2.5% 与 97.5% 分位为 $(0.31, 0.81)$——**相关系数的 95% 置信区间 $(0.31, 0.81)$**，不含 0，说明相关显著。而 $r$ 的解析区间公式（费希尔 z 变换）还要额外变换——bootstrap 一步到位。

## 4 公式解析：百分位法的排序

百分位法的全部操作是「排序 + 取位」，拆开：

$$

\hat\theta^*_{(1)}, \ldots, \hat\theta^*_{(B)} \quad \longrightarrow \quad \left(\hat\theta^*_{(\lfloor B\alpha/2\rfloor)},\ \hat\theta^*_{(\lceil B(1-\alpha/2)\rceil)}\right)

$$

- **第一步，排序**：$B$ 个复制从小到大排成 $\hat\theta^*_{(1)} \le \cdots \le \hat\theta^*_{(B)}$——模拟分布的形状就此可见。
- **第二步，定位**：第 $\alpha/2$ 分位在位置 $\lfloor B\alpha/2\rfloor$，第 $1-\alpha/2$ 分位在 $\lceil B(1-\alpha/2)\rceil$。
- **第三步，读出区间**：这两个位置的值就是区间的上下限——「模拟分布的两尾各切 $\alpha/2$」。

「排序取位」是百分位法的全部计算，几乎不需要任何分布理论。它把「构造置信区间」从「查表」变成「数模拟分布的分位数」——这是 bootstrap 最朴素也最通用的一击。

## 5 bootstrap 区间的深入比较与实务

百分位法与标准误法是 bootstrap 区间的两大基本款，但实务中还有更精细的版本与更需警惕的陷阱。

### 偏差校正与加速区间（BCa）

百分位法假设「bootstrap 复制分布 ≈ $\hat\theta$ 的真实分布」，但若 $\hat\theta$ 有偏，这个近似会偏。**BCa 区间（bias-corrected and accelerated）**在百分位法基础上加入两个修正参数：偏差校正（应对 $\hat\theta$ 中位数偏移）与加速参数（应对方差随参数变化）。BCa 区间比普通百分位区间**覆盖更准确**，是现代统计软件（R 的 $\hat\theta$）的推荐默认。

### 覆盖概率的模拟检查

**覆盖概率（coverage probability）**是评估区间的黄金标准：反复从真实分布抽样、构造区间，统计「区间盖住真参数」的比例，应接近名义置信水平（如 95%）。

**例（模拟检查）**：从 $N(0,1)$ 抽 $n = 20$，构造中位数的 95% bootstrap 区间，重复 10000 次，统计覆盖比例。若比例明显低于 95%（如 89%），说明该方法在该场景下覆盖不足——需换 BCa 或增大 $n$。**「模拟验证覆盖」是判断任何 bootstrap 方法是否可靠的最终手段**。

### bootstrap 区间的局限

三个必须警惕的场景：

1. **小样本**：$n$ 很小时，经验分布 $F_n$ 与总体 $F$ 差距大，bootstrap 区间偏差明显——bootstrap 是渐近方法，需要「样本量够大」；
2. **极端统计量**：最小值、最大值等「边界统计量」的 bootstrap 复制分布严重失真（如 min 的 bootstrap 复制恒等于原最小值），区间不可靠；
3. **重尾分布**：重尾下样本矩不稳定，bootstrap 复制的方差爆炸，区间过宽或过窄。

### 与解析区间的对照

| | 解析区间（z/t） | bootstrap 区间 |
| --- | --- | --- |
| 分布假设 | 正态/CLT | 经验分布近似总体 |
| 统计量范围 | 均值、方差等常规量 | 任意统计量 |
| 精度 | 模型正确时精确 | 渐近近似，$n$ 大时接近 |
| 计算 | 查表 | 需 $B$ 次重算 |

**易错点｜辨析：** bootstrap 不是「万能的免费午餐」——它用「计算」换「通用」，但统计误差仍由样本量 $n$ 决定，$B$ 只控制模拟误差。样本量小、统计量极端、分布重尾时，bootstrap 区间可能误导，务必用覆盖模拟检验其可靠性。



## 6 典型例题：bootstrap 区间的构造

**例 1（相关系数）**：样本相关系数 $r = 0.62$，$n = 30$。放回抽样 $B = 5000$ 个 bootstrap 样本，各算 $r^*$，排序后取 2.5% 与 97.5% 分位：

$$(r^*_{(0.025)},\ r^*_{(0.975)}) = (0.31,\ 0.81)$$

区间不含 0 → 相关显著。而 $r$ 的解析区间需费希尔 z 变换——bootstrap 一步到位。

**例 2（中位数）**：50 个家庭收入的中位数 $\hat\theta = 38$ 万元，bootstrap 标准误 $\widehat{se}_B = 2.1$ 万元。标准误法 95% 区间：$38 \pm 1.96\times 2.1 = (33.9, 42.1)$ 万元。

**例 3（偏斜数据的比较）**：中位数分布偏斜时，标准误法区间可能「左端为负」（荒谬），百分位法自动跟随偏斜更合理——**偏斜分布优先用百分位法**。

**例 4（覆盖验证）**：模拟 10000 次「抽样 → 构造 95% 区间」，统计覆盖比例。若显著低于 95%，换 BCa 区间或增大 $n$——**覆盖模拟是 bootstrap 区间的最终质检**。

## 7 小结

- **百分位法**：$\left(\hat\theta^*_{(\alpha/2)},\ \hat\theta^*_{(1-\alpha/2)}\right)$——bootstrap 复制的分位数，无需分布假设，自动跟随偏斜。
- **标准误法**：$\hat\theta \pm z_{\alpha/2}\,\widehat{se}_B$——正态假设 + bootstrap 标准误，形式与 z 区间同构。
- 偏斜分布用百分位法更稳；近似正态用标准误法更简。
- $B \ge 1000$ 保证分位数稳定；$B$ 只影响模拟精度，不影响统计精度。
- bootstrap 区间适用于任何统计量、任何分布，是数据科学报告不确定性的标准做法。
