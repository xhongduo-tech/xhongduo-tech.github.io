## 为什么从平方和分解与检验开始

上一节立起了方差分析的思想：总波动 = 组间 + 组内。本节把它变成**可执行的计算流程**——怎么算三个平方和、怎么填方差分析表、怎么下结论。这是一套「机械但必须熟练」的手艺：无论是考试手算，还是日后读软件输出（R 的 `aov`、SPSS 的 ANOVA 表），读得懂这张表才算真正掌握了方差分析。

方差分析表是 ANOVA 的标准「收据」：它把「平方和 → 自由度 → 均方 → F → p 值」完整陈列，是统计软件输出的通用格式。学会填它、读它，等于学会了整个方差分析的计算语法。<span class="marginnote">方差分析表的通用结构：<strong>来源（组间/组内/总计）、平方和（SS）、自由度（df）、均方（MS）、F 值、p 值</strong>。总平方和通常不算均方也不做检验（它只是分解的起点）。这张表的行结构在任何软件的输出里都长得一样——会填就会读。</span>

## 1 三个平方和的计算公式

用公式化写法（便于手算），记 $n = \sum_i n_i$、总均值 $\bar X_{\cdot\cdot}$：

- **总平方和**：$S_T = \sum_{i=1}^{m}\sum_{j=1}^{n_i} (X_{ij} - \bar X_{\cdot\cdot})^2$
- **组间平方和**：$S_A = \sum_{i=1}^{m} n_i (\bar X_{i\cdot} - \bar X_{\cdot\cdot})^2$
- **组内平方和**：$S_E = \sum_{i=1}^{m}\sum_{j=1}^{n_i} (X_{ij} - \bar X_{i\cdot})^2 = S_T - S_A$

**计算技巧**：用展开式省事。记 $T_{i\cdot} = \sum_j X_{ij}$（第 $i$ 组和）、$T_{\cdot\cdot} = \sum_{i,j} X_{ij}$（总和），则

$$S_T = \sum_{i,j} X_{ij}^2 - \frac{T_{\cdot\cdot}^2}{n}, \qquad S_A = \sum_i \frac{T_{i\cdot}^2}{n_i} - \frac{T_{\cdot\cdot}^2}{n}$$

$S_E = S_T - S_A$——**用「平方和展开」只需算 $\sum X^2$、各组和、总和**，比逐项偏离省力得多。<span class="marginnote">「$S_T = \sum X_{ij}^2 - T_{\cdot\cdot}^2/n$」这套展开式与第六章样本方差的「$\sum X_i^2 - n\bar X^2$」一脉相承：都是「原始平方和 − 修正项」。组间平方和同理，只是把「各组均值」当数据。记住「平方和 = 原始平方和 − 修正项」，三个平方和手算都不慌。</span>

## 2 例：三组数据的完整计算

**例**：三种饲料喂鸡，增重数据（克）如下，检验三种饲料效果是否相同（$\alpha = 0.05$）。

| 饲料 | 数据 |
| --- | --- |
| A | 1073, 1058, 1071, 1037 |
| B | 1023, 1036, 1005 |
| C | 1004, 1062, 1009 |

$n_1 = 4, n_2 = 3, n_3 = 3$，$n = 10$。组和：$T_1 = 4239$，$T_2 = 3064$，$T_3 = 3075$，$T_{\cdot\cdot} = 10378$。$\sum X_{ij}^2 = 1073^2 + \cdots + 1009^2 = 10775559$。

$$S_T = 10775559 - \frac{10378^2}{10} = 10775559 - 10770288.4 = 5270.6$$

$$S_A = \frac{4239^2}{4} + \frac{3064^2}{3} + \frac{3075^2}{3} - \frac{10378^2}{10} = 4492802.25 + 3130245.33 + 3151875 - 10770288.4 = 4634.2$$

$$S_E = 5270.6 - 4634.2 = 636.4$$

$MS_A = 4634.2/2 = 2317.1$，$MS_E = 636.4/7 = 90.9$，$F = 2317.1/90.9 = 25.5$。$F_{0.05}(2, 7) = 4.74$，$25.5 > 4.74$ → 拒绝 $H_0$——三种饲料效果显著不同。<span class="marginnote">这个例子里 $F = 25.5$ 远超临界值 4.74，p 值极小（远小于 0.001）。注意「显著不同」≠「哪组最好」——ANOVA 只告诉你「组间有差异」，要找出具体哪两组不同，还需做多重比较（LSD、Tukey 等），那是方差分析的后续步骤，教材常在补充部分介绍。</span>

## 3 方差分析表

把计算结果填入**方差分析表（ANOVA table）**：

| 方差来源 | 平方和 SS | 自由度 df | 均方 MS | F 值 | 显著性 |
| --- | --- | --- | --- | --- | --- |
| 因素 A（组间） | 4634.2 | 2 | 2317.1 | 25.5 | ** |
| 误差（组内） | 636.4 | 7 | 90.9 | | |
| 总和 | 5270.6 | 9 | | | |

其中「**」表示 p < 0.01，差异高度显著。<span class="marginnote">自由度校验：组间 $m-1 = 2$、组内 $n - m = 7$、总计 $n - 1 = 9$——三个自由度相加等于 $n-1$。同理三个平方和相加 $S_A + S_E = S_T$。这张表的「对角线可加」是自检手段：<strong>平方和相加、自由度相加、均方与 F 从它们算出</strong>——任何一步对不上，说明计算有误。</span>

## 4 公式解析：组间平方和的「均值看离散」

组间平方和为什么用「$n_i(\bar X_{i\cdot} - \bar X_{\cdot\cdot})^2$」这种加权形式，拆开：

$$

S_A = \sum_{i=1}^{m} n_i (\bar X_{i\cdot} - \bar X_{\cdot\cdot})^2 = \sum_i \frac{T_{i\cdot}^2}{n_i} - \frac{T_{\cdot\cdot}^2}{n}

$$

- **第一步，组均值对总均值的偏离**：$\bar X_{i\cdot} - \bar X_{\cdot\cdot}$——第 $i$ 组的均值差总均值多少。
- **第二步，按样本量加权**：乘 $n_i$——组越大，它的均值越「有分量」，对组间平方和的贡献越大。直觉：样本量大的组，其均值估计更可靠，偏离更值得「算账」。
- **第三步，展开式**：$\sum_i n_i \bar X_{i\cdot}^2 - n \bar X_{\cdot\cdot}^2 = \sum_i T_{i\cdot}^2/n_i - T_{\cdot\cdot}^2/n$——用组和与样本量直接算。

「组间平方和 = 各组均值（加权）的离散度」是 $S_A$ 的实质：它测量「组均值彼此差多远」，组均值差得越开，$S_A$ 越大，F 越大，越倾向拒绝。

## 5 单因素方差分析计算的深入应用

平方和分解是 ANOVA 的计算核心，它的技巧、表格与自检值得完整展开。

### 例：展开式计算

**例**：三组数据，组和 $T_1 = 4239$、$T_2 = 3064$、$T_3 = 3075$、$T_{\cdot\cdot} = 10378$，$n = 10$，$\sum X^2 = 10775559$：

$$S_T = 10775559 - \frac{10378^2}{10} = 5270.6$$

$$S_A = \frac{4239^2}{4} + \frac{3064^2}{3} + \frac{3075^2}{3} - \frac{10378^2}{10} = 4634.2$$

$$S_E = S_T - S_A = 636.4$$

**「原始平方和 − 修正项」**是手算三平方和的通用公式。

### 方差分析表的自检

| 行 | SS | df | MS | F |
| --- | --- | --- | --- | --- |
| 组间 | $S_A$ | $m-1$ | $MS_A$ | $MS_A/MS_E$ |
| 组内 | $S_E$ | $n-m$ | $MS_E$ | |
| 总和 | $S_T$ | $n-1$ | | |

**「SS 相加、df 相加、MS 由除法得」**——三行自检，任何对不上说明算错。

### 例：F 的判读

$F = MS_A/MS_E$ 大 → 组间波动远超随机误差 → 拒绝「均值全相等」。**「信号/噪声」**是 F 统计量的心智模型。

### 平方和分解的几何

$S_T = S_A + S_E$ 是「总波动 = 组间 + 组内」的正交分解——**「每个观测偏离总均值 = 组效应 + 随机误差」**，第九章回归的平方和分解是它的亲戚。

### 例：不等重复

$n_i$ 不等时，$S_A = \sum n_i(\bar X_{i\cdot} - \bar X_{\cdot\cdot})^2$ 仍按 $n_i$ 加权——**「样本量大的组权重高」**，公式不变、计算照做。

**易错点｜辨析：** ① 自由度 $m-1$ 与 $n-m$ 别混；② 三平方和必须满足 $S_A + S_E = S_T$——用它自检；③ 展开式的「修正项 $T^2/n$」每个平方和都出现——别漏。

## 6 小结

- 平方和计算：$S_T = \sum X^2 - T^2/n$，$S_A = \sum T_i^2/n_i - T^2/n$，$S_E = S_T - S_A$。
- **方差分析表**：来源 | SS | df | MS | F | p——三个平方和、三个自由度各自可加。
- $F = MS_A/MS_E$，拒绝域 $F \ge F_\alpha(m-1, n-m)$。
- ANOVA 显著 ≠ 知道哪组不同——后续需多重比较。
- 会填表就会读软件输出：R、SPSS、Python 的 ANOVA 表都是这个结构。
