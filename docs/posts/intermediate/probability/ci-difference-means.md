## 为什么从两个正态总体均值差的区间估计开始

单总体区间回答「这个均值是多少」，可现实里更常问的是**比较**：新药与旧药的疗效差多少？两条生产线平均重量差多少？男女平均身高的差是多少？这类问题的对象是**均值差 $\mu_1 - \mu_2$**，需要两个独立样本的区间估计。它是第七章「双总体」三部曲（均值差、方差比、成对数据）的第一站。

均值差的区间估计在医学、工程、社会科学里是最常用的推断工具——「差异是否有统计学意义」几乎总是先被问成「差异的置信区间」。本节的两个公式（方差已知/未知）是第八章双样本检验、第九章回归对比的模板。<span class="marginnote">「区间包含 0 吗」是均值差区间最重要的判读：若 $\mu_1 - \mu_2$ 的 95% 置信区间包含 0，说明「两个均值可能相等」——差异不显著；若区间整体为正（或负），说明一个显著大于另一个。这个「看区间含不含 0」的动作，是第八章假设检验的置信区间版预览。</span>

## 1 方差已知的情形

设 $X_1,\ldots,X_{n_1} \sim N(\mu_1, \sigma_1^2)$ 与 $Y_1,\ldots,Y_{n_2} \sim N(\mu_2, \sigma_2^2)$ 独立，$\sigma_1^2, \sigma_2^2$ 已知。则

$$\bar X - \bar Y \sim N\left(\mu_1 - \mu_2,\ \frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}\right)$$

标准化后得枢轴量，反解得 $\mu_1 - \mu_2$ 的置信区间：

$$\left((\bar X - \bar Y) \pm z_{\alpha/2}\sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}\right)$$

**方差为什么相加**：$\mathrm{Var}(\bar X - \bar Y) = \mathrm{Var}(\bar X) + \mathrm{Var}(\bar Y)$（独立，方差可加）——「两个均值的差，波动是两个波动之和」。<span class="marginnote">「$\bar X - \bar Y$ 的方差是两个方差之和」是双总体区间最基础的结构：因为两组样本独立，差值的波动 = 两组波动之和（第四章 $\mathrm{Var}(X-Y)$ 公式）。若两组相关（如成对数据），这个公式不成立，要用下一节之后的「成对法」——判断「独立样本 vs 成对样本」是双总体题的第一分水岭。</span>

## 2 方差未知但相等的情形

设 $\sigma_1^2 = \sigma_2^2 = \sigma^2$（未知），用**合并样本方差**

$$S_w^2 = \frac{(n_1 - 1)S_1^2 + (n_2 - 1)S_2^2}{n_1 + n_2 - 2}$$

枢轴量 $\frac{(\bar X - \bar Y) - (\mu_1 - \mu_2)}{S_w\sqrt{\frac1{n_1} + \frac1{n_2}}} \sim t(n_1 + n_2 - 2)$，反解得置信区间：

$$\left((\bar X - \bar Y) \pm t_{\alpha/2}(n_1 + n_2 - 2)\, S_w\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}\right)$$

**易错点｜辨析：** 用合并方差 t 区间的前提是**两总体方差相等**。若 $\sigma_1^2 \ne \sigma_2^2$（可用 F 检验验证），合并方差不再合适，应改用近似方法（Welch 校正）——自由度与标准误都要修正。<span class="marginnote">「方差相等吗？」是双总体均值推断的第一道判断题：相等 → 合并方差 t；不等 → Welch 近似。教材通常假设相等（简化），但真实数据里两组方差常不同。现代统计软件默认输出 Welch 结果——它不做「方差相等」假设，更稳健。考试按教材走，实务按软件走，两条路线都该认识。</span>

**例**：两组学生各 20 人，方法 A 平均分 $\bar x_1 = 78$、$s_1 = 8$；方法 B $\bar x_2 = 74$、$s_2 = 7$。设方差相等，求 $\mu_1 - \mu_2$ 的 95% 区间。$S_w^2 = \frac{19\times 64 + 19\times 49}{38} = 56.5$，$S_w = 7.52$。标准误 $= 7.52\sqrt{1/20+1/20} = 2.38$。$t_{0.025}(38) \approx 2.024$。区间：$4 \pm 2.024 \times 2.38 = 4 \pm 4.82 = (-0.82, 8.82)$——**包含 0，不能断定 A 优于 B**。

## 3 成对数据 vs 独立样本

**易错点｜辨析：** 两组数据若**不独立**（同一批人在两种条件下的测量、同一批产品处理前后的对比），不能直接用本节的独立样本公式。此时应转化为**成对数据（paired data）**：逐对求差 $D_i = X_i - Y_i$，把双总体问题化归为**单总体问题**——对差值 $D$ 做单样本 t 区间：

$$\bar D \pm t_{\alpha/2}(n-1)\frac{S_D}{\sqrt n}$$

其中 $\bar D$、$S_D$ 是差值样本的均值与标准差。<span class="marginnote">成对数据比独立样本「更精细」：它通过逐对求差，把个体间差异（如体质、批次）消掉了，只留下处理效应。若误用独立样本公式，会高估方差（个体差异混进来），区间变宽，检验灵敏度下降。第八章《基于成对数据的检验》会专章展开，本节先记住「不独立就配对」。</span>

## 4 公式解析：合并方差的逻辑

合并方差 $S_w^2$ 的构造是「自由度加权平均」，拆开：

$$

S_w^2 = \frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1 + n_2 - 2}

$$

- **第一步，各自 χ² 化**：$\frac{(n_1-1)S_1^2}{\sigma^2} \sim \chi^2(n_1-1)$，$\frac{(n_2-1)S_2^2}{\sigma^2} \sim \chi^2(n_2-1)$，独立。
- **第二步，相加**：两式相加，分子合并、自由度相加（χ² 可加性）：$\frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{\sigma^2} \sim \chi^2(n_1 + n_2 - 2)$。
- **第三步，除以自由度**：$\frac{\text{χ²}}{\text{自由度}}$ 的形式出现在 t 统计量分母，自由度即 $n_1 + n_2 - 2$。

「两组的方差信息合并成一份更稳的估计」是合并方差的全部意义：样本量越大的一组，权重越高；两组样本都少时，合并仍能拼出一份可用的 $\sigma^2$ 估计。

## 5 均值差区间估计的深入应用

均值差区间是「双总体比较」的第一站，三个实务细节——方差齐性、样本量、判读——决定结论质量。

### 例：完整计算

**例**：两组各 20 人，$\bar x_1 = 78$、$s_1 = 8$；$\bar x_2 = 74$、$s_2 = 7$。设方差相等：

$$S_w^2 = \frac{19\times 64 + 19\times 49}{38} = 56.5, \qquad S_w = 7.52$$

标准误 $= 7.52\sqrt{1/20+1/20} = 2.38$，$t_{0.025}(38) = 2.024$。区间 $4 \pm 2.024\times 2.38 = (-0.82, 8.82)$——含 0，不能断言 A 优于 B。

### 方差齐性检查的作用

| 两方差关系 | 方法 | 标准误 |
| --- | --- | --- |
| 相等（可验 F 检验） | 合并方差 t | $S_w\sqrt{1/n_1+1/n_2}$ |
| 不等 | Welch 近似 | $\sqrt{S_1^2/n_1 + S_2^2/n_2}$ |

**先验方差齐性再选方法**——第八章 F 检验或方差比区间（第七章）是齐性检查的工具。

### 区间宽度与样本量的权衡

| 想缩窄区间 | 手段 |
| --- | --- |
| 增 $n_1$、$n_2$ | 标准误 ∝ $\sqrt{1/n_1+1/n_2}$ |
| 减 $S_w$（控制噪声） | 实验设计更精细 |
| 降低置信水平 | 代价是把握变小 |

**「区间宽度 = 样本量 + 噪声 + 置信水平」**——三者的平衡是实验设计的核心。

### 判读的口诀

**易错点｜辨析：** ① 均值差区间「含不含 0」决定差异是否显著——含 0 不显著，全正/全负则显著；② 「不显著」≠「无差异」——小样本区间宽，「不显著」常是证据不足；③ 独立样本 vs 成对样本的选择在数据收集前就要定——同一批人测两次必须用成对法。

### 例：双侧与单侧

**例**：区间 $(-0.82, 8.82)$ 是双侧 95%。若只关心「A 是否优于 B」（单侧），看单侧下限 $\bar x_1 - \bar x_2 - t_{0.05}(38)S_w\sqrt{2/20} = 4 - 1.686\times 2.38 = -0.01$——单侧下限接近 0，仍不能断言优于。「单侧区间比双侧更接近 0」是方向性问题的正常现象。

## 6 小结

- **方差已知**：$(\bar X - \bar Y) \pm z_{\alpha/2}\sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}$——差值的方差 = 两方差之和。
- **方差相等未知**：$(\bar X - \bar Y) \pm t_{\alpha/2}(n_1+n_2-2)\, S_w\sqrt{\frac1{n_1}+\frac1{n_2}}$，$S_w^2$ 是自由度加权合并方差。
- 前提检查：**两总体方差是否相等**（不等用 Welch）；**两组是否独立**（不独立用成对法）。
- **成对数据**：$D_i = X_i - Y_i$ 化归单总体，$\bar D \pm t_{\alpha/2}(n-1)S_D/\sqrt n$。
- 「区间含不含 0」决定差异是否显著——这是第八章假设检验的置信区间预览。
