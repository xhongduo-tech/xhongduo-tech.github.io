## 为什么从单个正态总体均值的区间估计开始

第七章「区间估计」的实战从最常用的一个开始：**估计单个正态总体的均值 $\mu$**。它有两种情形——总体方差 $\sigma^2$ 已知（用 z 分布）与 $\sigma^2$ 未知（用 t 分布）。这两条公式是整个统计推断里被用得最多的两条，也是「置信区间」概念的第一个完整落地。

均值区间是第七章的「母题」：它的推导流程（枢轴量 → 分位点 → 反解）会被照搬到方差区间、双总体区间、单侧区间每一节。掌握了它，等于掌握了区间估计的全部语法。<span class="marginnote">为什么「均值」永远被放在第一位？因为现实里最常问的问题就是「这个量平均是多少」——产品的平均寿命、人群的平均血压、班级的平均分。而且均值的区间估计有一条美好性质：<strong>由 CLT，即使总体非正态，大样本下 $\bar X$ 近似正态，均值区间仍然近似成立</strong>——所以均值区间是「最不容易用错」的区间。</span>

## 1 情形一：方差已知 → z 区间

设 $X_1, \ldots, X_n$ 来自 $N(\mu, \sigma^2)$，$\sigma^2$ 已知。枢轴量

$$Z = \frac{\bar X - \mu}{\sigma/\sqrt n} \sim N(0, 1)$$

对置信水平 $1 - \alpha$，取 $z_{\alpha/2}$ 使 $P\{|Z| \le z_{\alpha/2}\} = 1 - \alpha$，反解得 $\mu$ 的**置信区间**：

$$\left(\bar X - z_{\alpha/2}\,\frac{\sigma}{\sqrt n},\ \ \bar X + z_{\alpha/2}\,\frac{\sigma}{\sqrt n}\right)$$

也常写作 $\bar X \pm z_{\alpha/2}\frac{\sigma}{\sqrt n}$。常用的 $z_{\alpha/2}$：90% → 1.645，95% → 1.96，99% → 2.576。<span class="marginnote">「$z_{\alpha/2}$ 的三个常用值」值得背：$z_{0.10} = 1.645$（90%）、$z_{0.05} = 1.96$（95%）、$z_{0.01} = 2.576$（99%）。这些数字会伴随你读完后面所有章节——第八章 z 检验、第九章回归的置信区间都回来找它们。</span>

**例**：某厂灯泡寿命 $X \sim N(\mu, 400)$（$\sigma = 20$），抽查 $n = 36$ 只，$\bar x = 2400$ 小时。95% 置信区间：

$$2400 \pm 1.96 \times \frac{20}{\sqrt{36}} = 2400 \pm 6.53 = (2393.47,\ 2406.53)$$

## 2 情形二：方差未知 → t 区间

设 $\sigma^2$ 未知，用样本方差 $S^2$ 代替。枢轴量

$$T = \frac{\bar X - \mu}{S/\sqrt n} \sim t(n-1)$$

对置信水平 $1 - \alpha$，取 $t_{\alpha/2}(n-1)$ 使 $P\{|T| \le t_{\alpha/2}(n-1)\} = 1 - \alpha$，反解得 $\mu$ 的**置信区间**：

$$\left(\bar X - t_{\alpha/2}(n-1)\,\frac{S}{\sqrt n},\ \ \bar X + t_{\alpha/2}(n-1)\,\frac{S}{\sqrt n}\right)$$

**易错点｜辨析：** 方差未知时绝不能再用 $z_{\alpha/2}$——必须用 $t_{\alpha/2}(n-1)$。两者的差别在 $n$ 小时显著（t 的尾巴厚），$n$ 大时趋同。判据很简单：**$\sigma$ 已知用 z，$\sigma$ 未知用 t**。<span class="marginnote">选择 z 还是 t 是本章最高频的考点：<strong>看题目给的是「总体方差 $\sigma^2$ 已知」还是「用样本方差 $S^2$」</strong>。前者查标准正态表，后者查自由度为 $n-1$ 的 t 表。$n \ge 30$ 时 t 与 z 几乎相等，很多教材允许大样本下用 z 近似——但严格做法永远是「未知就用 t」。</span>

**例**：测量 10 次得到 $\bar x = 50$，$s = 2$。95% 置信区间（$t_{0.025}(9) = 2.262$）：

$$50 \pm 2.262 \times \frac{2}{\sqrt{10}} = 50 \pm 1.43 = (48.57,\ 51.43)$$

若误用 z（$z_{0.025} = 1.96$），区间变窄为 $50 \pm 1.24$——**低估了不确定性**。

## 3 区间宽度与样本量

区间半宽 $\Delta = z_{\alpha/2}\frac{\sigma}{\sqrt n}$（或 $t_{\alpha/2}\frac{S}{\sqrt n}$）有三个决定性因素：

- **置信水平**：$1-\alpha$ 越高，$z_{\alpha/2}$ 越大，区间越宽；
- **样本量**：$\sqrt n$ 在分母，$n$ 越大区间越窄（想减半宽度，$n$ 乘 4）；
- **波动**：$\sigma$（或 $S$）越大区间越宽——数据越散，承诺越保守。

**样本量公式**：若要求区间半宽不超过 $\Delta$（方差已知），所需样本量

$$n \ge \left(\frac{z_{\alpha/2}\,\sigma}{\Delta}\right)^2$$

<span class="marginnote">样本量公式是抽样设计的核心工具：想以 95% 把握把估计误差控制在 $\Delta$ 内，至少需要 $n = (1.96\sigma/\Delta)^2$ 个样本。注意它需要先知道 $\sigma$——实践中用预实验的样本标准差代替。这个「误差预算 → 样本量」的换算，是医学试验、民调设计的第一步。</span>

**例**：$\sigma = 10$，要 95% 置信区间的半宽不超过 2：$n \ge (1.96 \times 10 / 2)^2 = 96.04$，取 $n = 97$。

## 4 公式解析：t 区间为什么用 S

t 区间的构造是「用 $S$ 代替 $\sigma$」的完整闭环，拆开看：

$$

T = \frac{\bar X - \mu}{S/\sqrt n} \sim t(n-1)

$$

- **第一步，已知方差版本**：$Z = \frac{\bar X - \mu}{\sigma/\sqrt n} \sim N(0,1)$——枢轴量，分布已知。
- **第二步，$\sigma$ 未知怎么办**：用 $S$ 代替 $\sigma$。但 $S$ 是随机变量，替换后分布不再是正态——由第六章抽样分布定理，$\frac{\bar X - \mu}{S/\sqrt n} \sim t(n-1)$。
- **第三步，查 t 表反解**：$\bar X \pm t_{\alpha/2}(n-1)\frac{S}{\sqrt n}$。

「$\sigma$ 未知的代价」是分布从 z 换成 t、分位点从 $z_{\alpha/2}$ 换成更大的 $t_{\alpha/2}(n-1)$——区间相应变宽，诚实反映了「$\sigma$ 也要估计」带来的额外不确定性。

## 5 均值区间估计的深入应用与实例

单总体均值区间是最常用的推断，它的两种情形、样本量设计与软件实践值得展开。

### 例：方差已知（z 区间）

**例**：$X \sim N(\mu, 400)$，$n = 36$、$\bar x = 2400$。95% 区间 $2400 \pm 1.96\times 20/6 = (2393.5, 2406.5)$。

### 例：方差未知（t 区间）

**例**：$n = 10$、$\bar x = 50$、$s = 2$。95% 区间 $50 \pm 2.262\times 2/\sqrt{10} = (48.57, 51.43)$——比误用 z（$50\pm 1.24$）更诚实。

### z vs t 的选择

| 条件 | 工具 | 分位点 |
| --- | --- | --- |
| $\sigma$ 已知 | z | $z_{\alpha/2}$ |
| $\sigma$ 未知 | t | $t_{\alpha/2}(n-1)$ |

**「$\sigma$ 已知用 z、未知用 t」**——本章最高频的选择。

### 例：样本量设计

**例**：$\sigma = 10$，要 95% 区间半宽 ≤ 2：$n \ge (1.96\times 10/2)^2 = 96$。**「误差预算 → 样本量」**是实验设计的标准换算。

### 区间宽度的三杠杆

| 杠杆 | 效果 |
| --- | --- |
| 置信水平 ↑ | 区间变宽 |
| 样本量 ↑ | 区间变窄 |
| $\sigma$（或 $S$）↓ | 区间变窄 |

**「水平、样本、波动」**三因素决定区间宽窄。

**易错点｜辨析：** ① 自由度 $n-1$ 别写成 $n$；② 「区间含不含 $\mu_0$」决定检验结论（对偶）；③ 大样本下 t ≈ z，但严格口径「未知用 t」。

## 6 小结

- **方差已知**：$\bar X \pm z_{\alpha/2}\frac{\sigma}{\sqrt n}$，用标准正态（z 区间）。
- **方差未知**：$\bar X \pm t_{\alpha/2}(n-1)\frac{S}{\sqrt n}$，用 t 分布（t 区间）。
- 选择判据：**$\sigma$ 已知用 z，$\sigma$ 未知用 t**；$n$ 大时二者接近，但严格做法未知就用 t。
- 区间宽度 ∝ $z \cdot \sigma/\sqrt n$；想减半宽度样本量乘 4；样本量公式 $n \ge (z\sigma/\Delta)^2$。
- 均值区间是第七章所有区间估计的母题：同一套「枢轴量 → 分位点 → 反解」流程。
