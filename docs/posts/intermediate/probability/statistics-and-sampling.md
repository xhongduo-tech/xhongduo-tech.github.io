## 为什么从统计量开始

样本 $X_1, \ldots, X_n$ 是一堆原始数据，信息太散。**统计量（statistic）**是样本的函数——$\bar X$、$S^2$、样本极差、样本中位数——它们把原始数据压缩成几个有意义的数字，是「用样本说话」的词汇表。统计量的分布叫**抽样分布（sampling distribution）**，是整个第六章的主题：只有知道了统计量的分布，才能用它去推断总体参数。

统计量在本书中的地位：它们是第七章参数估计的「估计量」（用统计量去估计参数）、第八章假设检验的「检验统计量」（用统计量做裁决）、第九章回归的「回归统计量」。可以说，**整个数理统计就是「选择合适的统计量 + 确定它的分布 + 用它做推断」**。<span class="marginnote">统计量与总体参数的关键区别：<strong>统计量是样本的函数，只依赖样本，不含未知参数</strong>；参数是总体的常数。比如样本均值 $\bar X$ 是统计量（可以算出），总体均值 $\mu$ 是参数（永远未知、只能估计）。「统计量 → 估计参数」就是推断的全部动作。</span>

## 1 定义与常用统计量

**统计量（statistic）**：设 $X_1, \ldots, X_n$ 是来自总体 $X$ 的样本，称不含未知参数的样本函数 $g(X_1, \ldots, X_n)$ 为**统计量**。

最常用的统计量：

**样本均值**：$\bar X = \frac1n \sum_{i=1}^n X_i$；
**样本方差**：$S^2 = \frac{1}{n-1} \sum_{i=1}^n (X_i - \bar X)^2$；
**样本标准差**：$S = \sqrt{S^2}$；
**样本 $k$ 阶原点矩**：$A_k = \frac1n \sum_i X_i^k$；
**样本 $k$ 阶中心矩**：$B_k = \frac1n \sum_i (X_i - \bar X)^k$；
**样本极差**：$R = \max X_i - \min X_i$。

<span class="marginnote">注意样本方差的除数：$S^2 = \frac{1}{n-1}\sum(X_i-\bar X)^2$，用 $n-1$ 而非 $n$。原因在下一节与无偏性章节揭晓——用 $n$ 会让 $S^2$ 平均偏低（有偏），除以 $n-1$ 恰好修正，使 $E[S^2] = \sigma^2$。这是统计里最著名的「自由度」修正之一。</span>

## 2 样本均值与样本方差的基本性质

样本均值 $\bar X$ 与样本方差 $S^2$ 有两个基础结论（设总体均值 $\mu$、方差 $\sigma^2$）：

1. **样本均值的期望与方差**：$E[\bar X] = \mu$，$\mathrm{Var}(\bar X) = \frac{\sigma^2}{n}$；
2. **样本方差的期望**：$E[S^2] = \sigma^2$（**无偏性**——用 $n-1$ 除的目的所在）。

$E[\bar X] = \mu$ 与 $E[S^2] = \sigma^2$ 说明：**样本均值和样本方差（无偏版）分别「打中」总体均值与总体方差**。这是第七章「无偏估计」概念的第一次亮相。<span class="marginnote">「$E[\bar X] = \mu$ 和 $E[S^2] = \sigma^2$」是一对黄金组合：它们保证「平均而言，统计量不骗人」。虽然单次抽样可能偏，但反复抽样取平均，统计量会指向总体参数——这就是无偏性（unbiasedness），第七章会系统化它，并说明它为什么是估计量的最低标准。</span>

**例（样本方差的期望验证）**：计算 $E[S^2]$ 需要一点代数：

$$S^2 = \frac{1}{n-1}\left[\sum_i X_i^2 - n\bar X^2\right], \qquad E[S^2] = \frac{1}{n-1}\left[n(\mu^2 + \sigma^2) - n\left(\mu^2 + \frac{\sigma^2}{n}\right)\right] = \sigma^2$$

「$\sum(X_i - \bar X)^2 = \sum X_i^2 - n\bar X^2$」这条平方和分解恒等式，是样本方差计算的核心，也是第九章方差分析的起点。

## 3 经验分布函数与矩统计量

除均值方差外，还有两个「整体型」统计量：

**经验分布函数（empirical distribution function）**：对样本 $X_1, \ldots, X_n$，定义

$$F_n(x) = \frac{1}{n} \sum_{i=1}^n \mathbf{1}_{\{X_i \le x\}}$$

它是「样本中 ≤ x 的比例」，是总体分布函数 $F(x)$ 的样本版本。**格利文科定理**：$n$ 充分大时，$F_n(x)$ 一致逼近 $F(x)$——经验分布以概率 1 收敛到总体分布，这是「样本代表总体」的最强表述（下一节详讲）。<span class="marginnote">经验分布函数是「非参数统计」的基石：它不需要假设分布形状，直接从数据构造「样本分布」。第十章 bootstrap 的全部思想——「样本分布 ≈ 总体分布，于是可以在样本上重复抽样」——就建立在这条定理上。</span>

**样本矩**：$A_k = \frac1n\sum X_i^k$ 是总体 $k$ 阶矩 $\mu_k = E[X^k]$ 的样本版本。由大数定律，$A_k \xrightarrow{P} \mu_k$——**样本矩一致估计总体矩**，这正是第七章「矩估计法」的依据：用 $A_1$ 估 $\mu$，用 $A_2 - A_1^2$ 估 $\sigma^2$。

## 4 公式解析：平方和分解恒等式

样本方差的计算核心是 $\sum(X_i - \bar X)^2 = \sum X_i^2 - n\bar X^2$，拆开它：

$$

\sum_{i=1}^n (X_i - \bar X)^2 = \sum_{i=1}^n X_i^2 - 2\bar X \sum_i X_i + n\bar X^2 = \sum_i X_i^2 - n\bar X^2

$$

- **第一步，展开平方**：$(X_i - \bar X)^2 = X_i^2 - 2X_i\bar X + \bar X^2$，对 $i$ 求和。
- **第二步，交叉项化简**：$\sum_i 2X_i\bar X = 2\bar X \cdot n\bar X = 2n\bar X^2$，与 $\sum \bar X^2 = n\bar X^2$ 合并。
- **第三步，净结果**：$\sum X_i^2 - n\bar X^2$——「平方和 = 总平方 − 修正项」。只需算两个量（$\sum X_i^2$ 与 $\bar X$），计算量比逐项偏离更省。

这条恒等式还有几何解释：把样本看成 $\mathbb{R}^n$ 里的向量，$\sum(X_i - \bar X)^2$ 是「投影到垂直于全 1 向量的子空间」后的长度平方。第九章方差分析里它会被拆成「组间 + 组内」两块的平方和分解。

## 5 统计量与抽样分布的深入应用

统计量是「样本的代言人」，它的构造、性质与应用值得完整展开。

### 例：常用统计量一览

| 统计量 | 公式 | 估计对象 |
| --- | --- | --- |
| 样本均值 | $\bar X = \frac1n\sum X_i$ | $\mu$ |
| 样本方差 | $S^2 = \frac{1}{n-1}\sum(X_i-\bar X)^2$ | $\sigma^2$ |
| 样本标准差 | $S = \sqrt{S^2}$ | $\sigma$ |
| 样本矩 | $A_k = \frac1n\sum X_i^k$ | $\mu_k$ |

**「统计量 = 估计参数的候选工具」**——第七章估计理论从这里起步。

### 无偏性速查

| 统计量 | 期望 | 无偏? |
| --- | --- | --- |
| $\bar X$ | $\mu$ | 是 |
| $S^2$ | $\sigma^2$ | 是 |
| $B_2$（$n$ 版） | $\frac{n-1}{n}\sigma^2$ | 否 |
| $A_k$ | $\mu_k$ | 是 |

**「$n-1$ 版方差无偏、$n$ 版有偏」**是抽样理论最重要的细节之一。

### 例：经验分布函数

$F_n(x) = \frac1n\sum \mathbf 1_{\{X_i \le x\}}$——**「样本版的分布函数」**，格利文科定理保证它收敛到真分布，是 bootstrap 与非参数统计的地基。

### 抽样分布的意义

统计量的分布（抽样分布）是推断的桥梁——**「知道统计量的分布，才能做区间与检验」**，第六章的全部内容都是抽样分布。

**易错点｜辨析：** ① 统计量不含未知参数——含 $\mu$、$\sigma^2$ 的不是统计量；② 样本方差除数 $n-1$ 别写成 $n$；③ 统计量是随机变量、观测值是数值——「随机变量推断、数值落地」。

## 6 小结

- **统计量**是不含未知参数的样本函数；**抽样分布**是统计量的分布，是推断的桥梁。
- 常用统计量：$\bar X$、$S^2$（除数 $n-1$）、$S$、样本矩、极差。
- 无偏性：$E[\bar X] = \mu$、$E[S^2] = \sigma^2$——样本均值与样本方差平均而言打中总体参数。
- **经验分布函数** $F_n(x)$ 是总体分布的样本版，格利文科定理保证它收敛。
- 样本矩 $\xrightarrow{P}$ 总体矩，是第七章矩估计法的依据。
