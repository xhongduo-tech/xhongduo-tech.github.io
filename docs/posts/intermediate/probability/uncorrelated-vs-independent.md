## 为什么从不相关与独立的关系开始

上一节我们得到两个概念：**独立**（联合分布 = 边缘之积）与**不相关**（$\rho = 0$）。直觉上它们似乎差不多——两个变量既然没关系，怎么会相关？但数学给出的答案是：**独立 ⇒ 不相关，不相关 ⇏ 独立**。独立是极强的条件（彻底无关），不相关只是弱条件（无线性的牵绊）。本节专门解剖这条「单向蕴含」，并构造出让人大跌眼镜的反例。

这条辨析不是咬文嚼字：它在统计实践里有真金白银的影响。第七章估计量评估里「无偏 + 不相关」不等于「最优」；机器学习里特征与标签「不相关」不代表「无预测力」；而在二维正态的特殊世界里，「不相关 = 独立」是唯一的例外。<span class="marginnote">「独立是强条件、不相关是弱条件」这件事，最好的记忆钩子是：<strong>独立管「一切函数关系」，不相关只管「线性关系」</strong>。$Y = X^2$ 这种完全确定的关系，线性相关系数是 0——它俩不相关，但显然不独立。记住这个反例，本节的结论就立住了。</span>

## 1 独立 ⇒ 不相关：证明

**定理**：若 $X$ 与 $Y$ 独立，则 $\mathrm{Cov}(X, Y) = 0$，即 $\rho = 0$（不相关）。

**证明**：独立时 $E[XY] = E[X]E[Y]$（第三章性质），于是 $\mathrm{Cov}(X,Y) = E[XY] - E[X]E[Y] = 0$。<span class="marginnote">证明只有一行，但意义深远：独立性是「无协方差」的充分条件。这也让「检验相关」成为「检验独立」的必要不充分替代——数据里没发现相关，不代表就是独立的。</span>

**推论**：独立时 $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$，因为协方差项消失——这就是方差可加性。

## 2 不相关 ⇏ 独立：标准反例

反例一抓一大把，最经典的是 $Y = X^2$：

**例（抛物线反例）**：设 $X \sim U(-1, 1)$，$Y = X^2$。则 $Y$ 完全由 $X$ 决定，$X$ 与 $Y$ 显然不独立。但

$$E[X] = 0, \quad E[XY] = E[X^3] = \int_{-1}^1 x^3 \cdot \frac12\, dx = 0$$

故 $\mathrm{Cov}(X, Y) = E[XY] - E[X]E[Y] = 0 - 0 = 0$，$\rho = 0$——**不相关，却不独立**。$Y$ 是 $X$ 的确定性函数，相关系数却为零，因为抛物线关于 0 对称，正负偏离的线性投影互相抵消。

**另一个反例（联合分布离散版）**：设 $(X,Y)$ 的联合分布律为 $P\{(-1,1)\} = P\{(1,1)\} = P\{(0,-1)\} = \frac13$。可验证 $E[X] = 0$、$E[Y] = 1/3$、$E[XY] = 0$，故 $\mathrm{Cov} = 0$（不相关）；但 $P\{X=0, Y=1\} = 0 \ne \frac13 \cdot \frac23 = P\{X=0\}P\{Y=1\}$，不独立。<span class="marginnote">离散版反例的价值在于「可见」：三个点的概率表一列，$\mathrm{Cov}=0$ 却不独立，毫无模糊空间。这也说明「不相关 ⇏ 独立」不是连续分布的病理特例，而是概率结构的普遍现象——凡是「对称抵消」的依赖关系都长这样。</span>

## 3 唯一的例外：二维正态分布

一个重要而美丽的例外：**若 $(X, Y)$ 服从二维正态分布，则「不相关 ⇔ 独立」**。

回顾二维正态密度的指数项：$\rho = 0$ 时交叉项 $-2\rho\frac{(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2}$ 消失，密度退化为

$$f(x,y) = \frac{1}{2\pi\sigma_1\sigma_2}\exp\left\{-\frac{(x-\mu_1)^2}{2\sigma_1^2} - \frac{(y-\mu_2)^2}{2\sigma_2^2}\right\} = f_X(x)\, f_Y(y)$$

即「$\rho = 0$ ⇒ 密度可分离变量 ⇒ 独立」。反过来独立 ⇒ 不相关早已证明。故在二维正态世界里，两个概念重合。<span class="marginnote">这条例外让二维正态成为「唯一可以放心用 $\rho$ 检验独立性」的分布。这也是为什么第七章检验「二元正态数据是否相关」时，$\rho = 0$ 的检验同时就是独立性检验——别把这条特例错误推广到别的分布。</span>

**易错点｜辨析：** 二维正态是例外，**不是**普遍规律。任何「两个变量分别正态」都不能推出「联合正态」——联合分布才是决定因素。两个边缘正态但联合不正态的例子存在（如联合集中在两条对角线段上的分布）。「边缘正态 + $\rho = 0$」只能说「联合若正态则独立」，不能反推。

## 4 公式解析：反例为什么能「骗过」相关系数

把 $Y = X^2$ 反例的机制拆开看：

$$

\mathrm{Cov}(X, X^2) = E[X^3] - E[X]\,E[X^2] = 0 - 0 = 0

$$

- **第一步，代入**：$Y = X^2$，$\mathrm{Cov}(X, X^2) = E[X \cdot X^2] - E[X]E[X^2] = E[X^3] - E[X]E[X^2]$。
- **第二步，利用对称性**：$X \sim U(-1,1)$ 的密度是偶函数，$x^3$ 是奇函数，$\int_{-1}^1 x^3 dx = 0$，故 $E[X^3] = 0$；又 $E[X] = 0$。
- **第三步，结果**：$0 - 0 = 0$——相关系数为零，因为「正 $x$ 与负 $x$ 的线性协变」在对称抛物线上完全抵消。

相关系数只能「看见」直线方向的协变；$Y = X^2$ 的依赖沿抛物线，恰好落在它的盲区。**不相关是「线性投影为零」，独立是「一切函数关系皆无」**——这是两者之间永远横亘着的距离。

## 5 不相关与独立的深入辨析

「不相关 ≠ 独立」是概率论最常考也最常错的辨析，值得用更多反例与场景把边界钉死。

### 更多反例：从离散到连续

**例（离散反例）**：$(X, Y)$ 取 $(-1,0),(1,0),(0,-1),(0,1)$ 各 1/4。可验 $E[X] = E[Y] = E[XY] = 0$，故 $\mathrm{Cov} = 0$（不相关）；但 $P\{X=0, Y=0\} = 0 \ne P\{X=0\}P\{Y=0\} = \frac12 \times \frac12$，不独立。

**例（连续反例）**：$X \sim U(-1,1)$，$Y = X^2$——不相关（$E[X^3]=0$）但不独立（$Y$ 完全由 $X$ 决定）。「对称依赖」是构造不相关反例的通用配方：正负依赖对称抵消，线性投影为零。

### 四种组合的关系总结

| 情形 | 是否独立 | 是否不相关 | 例子 |
| --- | --- | --- | --- |
| 独立 | 是 | 是 | 两枚独立骰子 |
| 不相关但不独立 | 否 | 是 | $Y = X^2$ |
| 相关 | 否 | 否 | $Y = X$（$\rho = 1$） |
| 独立且相关为 0 | 是 | 是 | 独立正态 |

**只有二维正态让「不相关 ⇔ 独立」**——这是特例，不是通则。

### 例：相关系数为 0 但有关联的检验

**例**：样本 $(x_i, y_i)$ 计算 $r = 0.02$（几乎不相关），但散点图呈清晰的 U 形——$y$ 与 $x$ 有非线性关联，线性相关系数看不见。**「先画散点图，再信相关系数」**是数据分析的铁律——相关系数只捕捉线性，图能看见非线性。

### 实践含义：特征选择与建模

机器学习里「特征与标签不相关」不代表「无预测力」——非线性模型（树、神经网络）能利用相关系数看不见的依赖。反过来，「强相关」也不保证「因果」——混淆变量可同时驱动两者。

**易错点｜辨析：** ① 「不相关」只说「线性无关」，不承诺「独立」；② 检验相关是否为零（第八章）与检验独立是两件事——相关检验只是独立的「必要不充分」筛查；③ 报告「相关性」时注明是「皮尔逊线性相关」，非线性关联需另算（秩相关、互信息）。

再补一张「相关程度」的解读表：

| $|\rho|$ | 线性关联强度 |
| --- | --- |
| 0–0.3 | 弱 |
| 0.3–0.6 | 中等 |
| 0.6–0.8 | 较强 |
| 0.8–1 | 强 |

「相关系数的强度分级」只是经验参考——具体场景的「强/弱」要结合实际判断，别机械套表。

## 6 小结

- **独立 ⇒ 不相关**：$E[XY] = E[X]E[Y]$ 推出 $\mathrm{Cov} = 0$，证明只有一行。
- **不相关 ⇏ 独立**：$Y = X^2$（$X \sim U(-1,1)$）与离散三点分布都是标准反例。
- **二维正态是唯一例外**：$\rho = 0$ ⇔ 独立，因密度在 $\rho=0$ 时可分离变量。
- 相关系数只度量线性关联，非线性依赖可能完全逃过它。
- 「边缘正态 + $\rho = 0$」不能推出联合正态，更不能推出独立。
