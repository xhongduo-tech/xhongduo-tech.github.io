## 为什么从指数分布开始

寿命、等待时间、通话时长、放射性衰变——这些「从零开始数到事件发生」的随机变量，大多服从同一种分布：**指数分布（exponential distribution）**。它和几何分布一样拥有那颗概率论里最著名的「宝石」——**无记忆性**，而且是连续版。指数分布还是泊松分布的「孪生兄弟」：泊松数「一段时间内发生几次」，指数等「从开始到第一次发生要多久」，两者共享同一个参数 $\lambda$。

指数分布的现实分量极重：可靠性工程里用「浴盆曲线」描述产品寿命，其随机失效段常被指数近似；排队论里服务时间的指数假设让整个理论可解；马尔可夫过程的连续时间版——第十一章的泊松过程、第十三章的线性系统——全都以指数分布为砖瓦。<span class="marginnote">指数分布与泊松分布由同一个 $\lambda$ 绑定：若单位时间发生次数 $N(t) \sim \pi(\lambda t)$，则「第一次发生的等待时间」$T \sim$ 指数分布，密度 $f(t) = \lambda e^{-\lambda t}$。一个数次数，一个数时间，是同一枚硬币的两面。</span>

## 1 定义与密度

**指数分布（exponential distribution）**：若随机变量 $X$ 的概率密度为

$$f(x) = \begin{cases} \lambda e^{-\lambda x}, & x > 0 \\[4pt] 0, & x \le 0 \end{cases} \qquad (\lambda > 0)$$

则称 $X$ 服从参数为 $\lambda$ 的指数分布，记作 $X \sim E(\lambda)$ 或 $\mathrm{Exp}(\lambda)$。

密度在 $x = 0$ 处从 $\lambda$ 开始单调递减，像一根从高到低快速塌落的曲线。参数 $\lambda$ 的含义是**速率（rate）**：单位时间内事件平均发生 $\lambda$ 次，因此平均等待时间正是 $1/\lambda$。<span class="marginnote">参数约定的两个版本：有的教材写密度 $\frac{1}{\theta} e^{-x/\theta}$，其中 $\theta = 1/\lambda$ 直接就是均值。看题目时先分清给的是 $\lambda$（速率）还是 $\theta$（平均等待时间），否则期望、方差会差一个倒数。</span>

**例**：某设备无故障工作时间 $X \sim E(0.01)$（单位：小时），即平均 100 小时坏一次。则「工作 100 小时仍正常」的概率 $P\{X > 100\} = e^{-0.01 \times 100} = e^{-1} \approx 0.368$。

## 2 分布函数与尾巴公式

对密度积分得分布函数：

$$F(x) = \begin{cases} 1 - e^{-\lambda x}, & x > 0 \\[4pt] 0, & x \le 0 \end{cases}$$

由此得到最常用的**尾巴公式**——「存活/继续等待」的概率：

$$P\{X > x\} = 1 - F(x) = e^{-\lambda x}, \qquad x > 0$$

这条公式指数级简洁：等待超过 $x$ 的概率是 $e^{-\lambda x}$。它贯穿可靠性（存活函数）、排队论（等待超过某时长）、寿命分析（生存分析）的全部推导。<span class="marginnote">尾巴公式的推导只需一步：$P\{X > x\} = \int_x^{\infty} \lambda e^{-\lambda t} dt = e^{-\lambda x}$。指数分布的密度选得妙——它的积分和本身同形，求一次还是同一个函数，这为后续所有解析计算提供了极大的便利。</span>

**例**：接上例，$P\{X > 200 \mid X > 100\} = \frac{e^{-2}}{e^{-1}} = e^{-1} = 0.368$。注意结果与「从 0 开始等 100 小时」的概率完全相同——这正是无记忆性。

## 3 无记忆性：过去不欠未来

**无记忆性（memorylessness）**：对 $s, t > 0$，恒有

$$P\{X > s + t \mid X > s\} = P\{X > t\}$$

「已经等了 $s$ 还没发生」这个信息，对未来毫无帮助——剩余等待时间与已经等过的时间无关。证明只需一步：

$$P\{X > s+t \mid X > s\} = \frac{P\{X > s+t\}}{P\{X > s\}} = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P\{X > t\}$$

**易错点｜辨析：** 无记忆性**只有**指数分布（连续）与几何分布（离散）具备，其余分布统统「记仇」。若数据服从威布尔分布或对数正态（现实里很多寿命数据如此），剩余寿命会随已用时间改变——或越用越糟（磨损），或越用越稳（磨合）。**拿指数分布建模时，必须先问：这个系统真的「无记忆」吗？** 灯泡的随机失效近似无记忆，但机械轴承的磨损寿命绝不服从指数分布。<span class="marginnote">现实里「无记忆」往往是被近似出来的：元件的失效率在某个时段内近似恒定（浴盆曲线的水平段），于是该时段可用指数近似。这也是为什么指数分布在可靠性工程里如此普及——不是因为它最真实，而是因为它最可算，且在这些时段内足够准确。</span>

## 4 公式解析：指数分布是泊松过程的「等待时间」

指数分布与泊松分布最深刻的联系在于：**指数分布的「速率」$\lambda$，正是泊松过程的到达率**。设电话在单位时间内到达数 $N(t) \sim \pi(\lambda t)$，则首次到达的时间 $T$ 满足

$$

P\{T > t\} = P\{N(t) = 0\} = \frac{(\lambda t)^0}{0!} e^{-\lambda t} = e^{-\lambda t}

$$

- **第一步，翻译事件**：「首次到达时间超过 $t$」等价于「到时刻 $t$ 为止一个电话都没来」，即 $\{N(t) = 0\}$。
- **第二步，套泊松分布**：$N(t)$ 服从参数为 $\lambda t$ 的泊松分布，$k = 0$ 的概率是 $e^{-\lambda t}$。
- **第三步，识别指数**：$P\{T > t\} = e^{-\lambda t}$ 正是指数分布的尾巴公式，故 $T$ 服从指数分布，速率 $\lambda$。

由此得到一条漂亮的链条：**泊松过程 ↔ 指数等待时间 ↔ 无记忆性**。三个概念被同一根线穿起，这正是第十一章《泊松过程》里等待时间理论的预览——在那里我们将证明更一般的结论：泊松过程的到达间隔是独立同分布的指数变量。

## 5 指数分布的深入应用与实例

指数分布是「等待时间」的默认模型，它的无记忆性、应用与局限值得完整展开。

### 例：无记忆性的计算

**例**：设备寿命 $X \sim E(\lambda)$。已用 500 小时未坏，求「再用 500 小时」的概率：

$$P\{X > 1000 \mid X > 500\} = \frac{e^{-1000\lambda}}{e^{-500\lambda}} = e^{-500\lambda} = P\{X > 500\}$$

**「已用的时间不影响剩余寿命」**——无记忆性让「旧设备与新设备一样可靠」，这既是便利也是警示。

### 无记忆性的数学特征

| 分布 | 无记忆性 | 说明 |
| --- | --- | --- |
| 指数（连续） | 有 | $P\{X>s+t \mid X>s\} = P\{X>t\}$ |
| 几何（离散） | 有 | 等待首次成功 |
| 其余分布 | 无 | 「记仇」 |

**「无记忆性是指数与几何独有」**——这是它们能被解析推导的根本原因。

### 例：可靠性的浴盆曲线

| 阶段 | 失效率 | 模型 |
| --- | --- | --- |
| 早期 | 高（磨合） | 威布尔 |
| 平稳期 | 恒定 | 指数 |
| 磨损期 | 升高 | 威布尔/正态 |

**「平稳期可用指数近似」**——浴盆曲线的水平段正是无记忆性的适用区。

### 例：与泊松过程的联系

| 量 | 分布 |
| --- | --- |
| $N(t)$（计数） | 泊松 $\pi(\lambda t)$ |
| $T_1$（首个到达） | 指数 $E(\lambda)$ |
| $S_n$（第 $n$ 个到达） | 伽马 $\Gamma(n,\lambda)$ |

**「泊松数次数、指数等时间」**——同一 $\lambda$ 串起三个分布。

**易错点｜辨析：** ① 参数约定：密度 $\lambda e^{-\lambda x}$ 与 $\frac1\theta e^{-x/\theta}$ 是两种写法（$\theta = 1/\lambda$）——看清题目；② 磨损、老化数据（失效率递增）不服从指数——误用会高估可靠性；③ $P\{X > x\} = e^{-\lambda x}$ 是尾巴公式，正偏分布的关键工具。

## 6 小结

- **指数分布** $X \sim E(\lambda)$：密度 $\lambda e^{-\lambda x}$（$x>0$），速率 $\lambda$，均值 $1/\lambda$。
- 分布函数 $F(x) = 1 - e^{-\lambda x}$，**尾巴公式** $P\{X > x\} = e^{-\lambda x}$。
- **无记忆性** $P\{X > s+t \mid X > s\} = P\{X > t\}$：指数与几何分布独有，其余分布「记仇」。
- 指数分布是泊松过程的**等待时间**，与泊松分布共享速率 $\lambda$。
- 建模前先确认系统「无记忆」是否成立；磨损、老化类数据慎用指数分布。

在下一节，我们见到整个概率论最重要的分布——**正态分布**。它统治着测量误差、身高体重与一切「大量微小因素叠加」的随机现象。
