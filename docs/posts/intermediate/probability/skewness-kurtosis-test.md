## 为什么从偏度、峰度检验开始

χ² 拟合优度检验能检验「数据是否正态」，但分组、合并、算期望频数相当繁琐。有没有更轻便的正态性体检？**有——看偏度与峰度**。正态分布的偏度为 0（对称）、峰度为 3（特定尖峭程度）；若样本的偏度、峰度明显偏离这两个值，就可以怀疑数据不来自正态。这就是**偏度、峰度检验（skewness–kurtosis test）**，也叫 **Jarque–Bera 检验**。

偏度峰度检验是现代统计软件里最常用的正态性快速检验（`scipy.stats.normaltest`、EViews 的 JB 检验都基于它）。它不需要分组，直接用样本的三、四阶矩计算，是「分布形状检验」里最轻便的一把尺子。<span class="marginnote">偏度（skewness）刻画对称性、峰度（kurtosis）刻画「尖峭与厚尾」——这两个量在第四章「矩」一节已经定义：偏度 $= \nu_3/\nu_2^{3/2}$，峰度 $= \nu_4/\nu_2^2$。现在轮到它们「当检验统计量」：用样本矩估计它们，再与正态的理论值（0 与 3）比较。矩的伏笔在这里兑现。</span>

## 1 偏度与峰度的定义回顾

对总体 $X$，偏度与峰度为

$$\text{偏度}\ g_1 = \frac{\nu_3}{\nu_2^{3/2}} = \frac{E[(X-\mu)^3]}{\sigma^3}, \qquad \text{峰度}\ g_2 = \frac{\nu_4}{\nu_2^2} = \frac{E[(X-\mu)^4]}{\sigma^4}$$

- **正态的偏度 $= 0$**：左右对称，三阶中心矩为 0；
- **正态的峰度 $= 3$**：特定尾部厚度（有些软件定义超额峰度 $= g_2 - 3$，正态时为 0）。

**直觉**：偏度 > 0 表示右尾长（正偏），< 0 表示左尾长（负偏）；峰度 > 3 表示尾部比正态厚（尖峰厚尾，极端值更常见），< 3 表示尾部更薄。<span class="marginnote">「峰度 > 3 = 厚尾」这个直觉要小心：峰度衡量的是「尾部概率」而非「峰尖」。名字里的「峰」会误导——真正区分正态与非正态的，是四阶矩对尾部的敏感度。厚尾分布（如 t 分布低自由度）峰度远大于 3；薄尾分布（如均匀）峰度小于 3。</span>

## 2 样本偏度与峰度

用样本中心矩估计总体偏度峰度（$n$ 较大时）：

$$\hat g_1 = \frac{\frac1n\sum (X_i - \bar X)^3}{\left[\frac1n\sum (X_i - \bar X)^2\right]^{3/2}}, \qquad \hat g_2 = \frac{\frac1n\sum (X_i - \bar X)^4}{\left[\frac1n\sum (X_i - \bar X)^2\right]^2}$$

**大样本近似**：总体正态时，$\hat g_1$ 近似服从 $N(0, 6/n)$，$\hat g_2$ 近似服从 $N(3, 24/n)$。据此可检验：

- $|\hat g_1|$ 过大 → 偏度偏离正态；
- $|\hat g_2 - 3|$ 过大 → 峰度偏离正态。

**例**：$n = 100$，$\hat g_1 = 0.8$。正态下 $\mathrm{Std}(\hat g_1) = \sqrt{6/100} = 0.245$，$z = 0.8/0.245 = 3.27$——远超 1.96，偏度显著非零，数据偏态明显。<span class="marginnote">「$\hat g_1 \approx N(0, 6/n)$、$\hat g_2 \approx N(3, 24/n)$」是偏度峰度检验的分布依据，来自 CLT 对样本矩的近似（由大样本下样本矩联合渐近正态）。$n$ 不够大（如 < 50）时这个近似较差——所以偏度峰度检验适合「中等以上样本」的正态性快速筛查。</span>

## 3 Jarque–Bera 检验

把偏度与峰度合二为一的 **Jarque–Bera（JB）检验**，统计量为

$$\mathrm{JB} = \frac{n}{6}\left(\hat g_1^2 + \frac{(\hat g_2 - 3)^2}{4}\right)$$

$H_0$（正态）下 JB 近似服从 $\chi^2(2)$——拒绝域 $JB \ge \chi^2_\alpha(2)$。**它同时检查偏度与峰度**：两项只要一项偏离，JB 就变大，拒绝正态。<span class="marginnote">JB 统计量把「偏度偏离 + 峰度偏离」合并成一个 χ² 量：$\hat g_1^2$（偏度平方）与 $(\hat g_2-3)^2/4$（峰度偏离平方）各自除以渐近方差（$6/n$、$24/n$）再相加——正是「两个标准正态的平方和 = χ²(2)」的结构。用一次检验同时盯住两个特征，是它的设计精髓。</span>

**例**：$n = 200$，$\hat g_1 = 0.6$，$\hat g_2 = 4.5$。

$$\mathrm{JB} = \frac{200}{6}\left(0.36 + \frac{(4.5-3)^2}{4}\right) = 33.33 \times (0.36 + 0.5625) = 30.75$$

$\chi^2_{0.05}(2) = 5.99$，$30.75 \gg 5.99$ → 拒绝正态——数据显著偏离正态（偏度与峰度都超）。

## 4 公式解析：JB 统计量的「两通道」

JB 统计量为什么是「$\hat g_1^2$ + $(\hat g_2-3)^2/4$」的形状，拆开：

$$

\mathrm{JB} = \frac{n}{6}\left[\underbrace{\hat g_1^2}_{\text{偏度通道}} + \underbrace{\frac{(\hat g_2 - 3)^2}{4}}_{\text{峰度通道}}\right]

$$

- **第一步，标准化各通道**：正态下 $\hat g_1 / \sqrt{6/n} \approx N(0,1)$，$(\hat g_2 - 3)/\sqrt{24/n} \approx N(0,1)$——各自除以渐近标准差，得到两个近似标准正态。
- **第二步，平方相加**：两个近似独立的 $N(0,1)$ 的平方和服从 $\chi^2(2)$——正态性假设下 JB 的分布。
- **第三步，化简系数**：$\hat g_1^2 / (6/n) = n\hat g_1^2/6$，$(\hat g_2-3)^2 / (24/n) = n(\hat g_2-3)^2/24$，相加提公因子 $n/6$ 得 $[ \hat g_1^2 + (\hat g_2-3)^2/4 ]$。

「两个标准化矩的平方和 = 一个 χ²」是 JB 检验的数学骨架——它把「偏度与峰度是否同时为 0 与 3」翻译成「两个标准正态是否同时为 0」，再用 χ²(2) 做裁决。

## 5 偏度峰度检验的深入应用

偏度与峰度不只是「检验正态」，它们是「分布形状的语言」，应用远超正态性测试。

### 例：偏度的解读

| 偏度 | 形状 | 含义 |
| --- | --- | --- |
| 0 | 对称 | 左右均衡 |
| > 0 | 右偏（正偏） | 长尾在右 |
| < 0 | 左偏（负偏） | 长尾在左 |

**「偏度符号 = 长尾方向」**——收入、房价正偏（少数富豪拉长右尾），是重尾分布的常见标志。

### 例：峰度的解读

| 峰度 | 尾部 | 例子 |
| --- | --- | --- |
| > 3 | 厚尾 | t 分布、金融收益 |
| = 3 | 正态 | 正态分布 |
| < 3 | 薄尾 | 均匀分布 |

**「峰度 > 3 = 极端值比正态常见」**——金融「黑天鹅」的统计根源。

### 例：正态性检验的完整流程

| 步骤 | 工具 |
| --- | --- |
| 画直方图/QQ 图 | 直观判断 |
| 算偏度峰度 | 快速筛查 |
| JB 检验 | 正式检验 |
| χ² 拟合优度 | 备选 |

**「先看图、再算偏度峰度、最后正式检验」**——多层检查比单看一个 p 值可靠。

### 偏度峰度与数据变换

若数据右偏，取对数/开方常可拉正；检验变换后数据的偏度峰度是否接近正态——**「偏度峰度也是『数据变换效果』的度量」**，Box–Cox 变换正是以「让数据更接近正态」为目标。

**易错点｜辨析：** ① 样本偏度峰度的方差随 $n$ 缩小——小样本下估计不可靠，检验判据要谨慎；② 「峰度 > 3 是厚尾」指四阶矩对尾部的敏感——不是「峰更尖」；③ 偏度峰度检验是「必要不充分」——通过它们不保证正态，还需看 QQ 图等。

## 6 小结

- **偏度** $g_1 = \nu_3/\nu_2^{3/2}$、**峰度** $g_2 = \nu_4/\nu_2^2$；正态的偏度 0、峰度 3。
- 样本偏度峰度大样本近似：$\hat g_1 \approx N(0, 6/n)$，$\hat g_2 \approx N(3, 24/n)$。
- **JB 检验** $\mathrm{JB} = \frac n6[\hat g_1^2 + (\hat g_2-3)^2/4] \sim \chi^2(2)$——偏度峰度二合一。
- 适用：中等以上样本的正态性快速筛查；小样本时近似较差。
- 峰度 > 3 表示厚尾（极端值更常见），是与正态的关键分野。
