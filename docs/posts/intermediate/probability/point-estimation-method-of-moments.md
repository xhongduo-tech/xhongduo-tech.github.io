## 为什么从点估计与矩估计开始

第六章我们把「样本统计量的分布」研究透了，现在要做正事：**用样本去猜总体参数**。总体 $X$ 的分布里有未知参数 $\theta$（比如 $N(\mu, \sigma^2)$ 里的 $\mu$ 与 $\sigma^2$），我们手里只有样本 $X_1, \ldots, X_n$。**点估计（point estimation）**就是用样本构造一个统计量 $\hat\theta(X_1, \ldots, X_n)$ 去「猜」$\theta$ 的值，这个 $\hat\theta$ 叫**估计量**。

点估计是参数估计的「先头部队」：第七章前半全是点估计（矩估计、最大似然估计、估计量评选），后半才是区间估计。而**矩估计法（method of moments）**是点估计中最朴素的一种——**用样本矩去代替总体矩**，几乎是「直觉的直接翻译」。<span class="marginnote">矩估计的思想一句话：<strong>样本矩收敛到总体矩（大数定律），所以「让样本矩 = 总体矩」解出的参数就是好估计</strong>。它由皮尔逊在 1894 年提出，是统计学最早的参数估计方法之一——朴素、直观、几乎总会给一个答案，代价是常常不是最优。</span>

## 1 点估计问题

**点估计（point estimation）**：设总体 $X$ 的分布函数 $F(x; \theta)$ 含未知参数 $\theta$，从样本 $X_1, \ldots, X_n$ 构造统计量 $\hat\theta = \hat\theta(X_1, \ldots, X_n)$，用它作为 $\theta$ 的估计，称为 $\theta$ 的**估计量**（estimator）；代入样本观测值后得到的数 $\hat\theta(x_1, \ldots, x_n)$ 叫**估计值**（estimate）。

**例**：总体 $X \sim N(\mu, \sigma^2)$，$\mu$、$\sigma^2$ 未知。样本均值 $\bar X$ 是 $\mu$ 的一个估计量，样本方差 $S^2$ 是 $\sigma^2$ 的一个估计量。估计量与估计值之别：**估计量是随机变量（抽样前），估计值是具体数（抽样后）**。<span class="marginnote">估计量 vs 估计值这对概念是第七章的第一课：<strong>估计量 $\hat\theta$ 是样本的函数（随机变量，有自己的分布），估计值是把观测代进去得到的数</strong>。因为估计量是随机变量，才有「无偏」「有效」这些统计性质可言——那是「估计量的分布」的性质，不是「估计值」的。</span>

## 2 矩估计法：让样本矩 = 总体矩

**矩估计法（method of moments, MoM）**的步骤：

1. **写出总体矩**：用参数表达总体前 $k$ 阶矩 $\mu_k = E[X^k]$（$k = 1, 2, \ldots$），每个 $\mu_k$ 是 $\theta_1, \ldots, \theta_m$ 的函数；
2. **写出样本矩**：$A_k = \frac1n \sum_i X_i^k$；
3. **令其相等**：解方程组 $\mu_k(\theta_1, \ldots, \theta_m) = A_k$（$k = 1, \ldots, m$），解出 $\hat\theta_j$ 即矩估计量。

**原理**：大数定律保证 $A_k \xrightarrow{P} \mu_k$——样本矩收敛到总体矩，所以「让它们相等」解出的参数是合理的。<span class="marginnote">矩估计的本质是「<strong>用样本矩方程组反解参数</strong>」。它不需要知道分布的精细形状，只要会算总体矩就行。缺点是解往往不是最有效的——它不利用分布的完整信息，只用了前 $m$ 阶矩。对正态、指数等「低维参数」分布，矩估计常与最大似然估计一致。</span>

## 3 例：正态与指数总体的矩估计

**例 1（正态）**：$X \sim N(\mu, \sigma^2)$。总体矩：$\mu_1 = \mu$，$\mu_2 = \sigma^2 + \mu^2$。令其等于样本矩：

$$\mu = A_1 = \bar X, \qquad \sigma^2 + \mu^2 = A_2 = \frac1n\sum X_i^2$$

解得 $\hat\mu = \bar X$，$\hat\sigma^2 = A_2 - \bar X^2 = \frac1n \sum (X_i - \bar X)^2$——**矩估计的 $\hat\sigma^2$ 用 $n$ 做除数（有偏版）**，与样本方差 $S^2$（$n-1$ 版）略有差别。

**例 2（指数）**：$X \sim E(\lambda)$，$E[X] = 1/\lambda$。令 $1/\lambda = \bar X$，得 $\hat\lambda = 1/\bar X$——「用样本均值倒推速率」。<span class="marginnote">矩估计里「$\hat\sigma^2$ 用 $n$ 而非 $n-1$」是个值得记住的细节：矩估计天然给出有偏的方差估计（偏低）。下一节最大似然估计同样给 $n$ 版。要到「无偏性」一节，我们才会看到统计学家为何偏爱 $S^2$ 的 $n-1$ 版——矩估计与最大似然不保证无偏，只是「通常渐进无偏」。</span>

## 4 公式解析：矩估计方程组的两步

矩估计的核心动作是「列方程、解方程」，以「$\mu$ 与 $\sigma^2$ 两个未知数的矩估计」为例：

$$

\begin{cases} \mu = A_1 \\ \sigma^2 + \mu^2 = A_2 \end{cases} \implies \hat\mu = A_1,\ \ \hat\sigma^2 = A_2 - A_1^2

$$

- **第一步，列第一个方程**：一阶矩 $\mu_1 = E[X] = \mu$，令其等于 $A_1 = \bar X$，直接得 $\hat\mu = \bar X$——「用样本均值估总体均值」。
- **第二步，列第二个方程**：二阶矩 $\mu_2 = E[X^2] = \sigma^2 + \mu^2$（因为 $E[X^2] = \mathrm{Var}(X) + (E[X])^2$），令其等于 $A_2$。
- **第三步，解方程组**：代入 $\hat\mu$ 得 $\hat\sigma^2 = A_2 - \bar X^2 = \frac1n\sum X_i^2 - \bar X^2 = \frac1n\sum(X_i - \bar X)^2$。

「几个未知参数 → 列几个矩方程」是矩估计的配平原则。参数越多，需要越高的矩，计算越繁——这也是矩估计在实际复杂模型里逐渐让位给最大似然的原因。

## 5 矩估计的深入讨论

矩估计朴素，但它的性质、局限与边界值得展开——它们解释了「矩估计何时够用、何时该让位」。

### 矩估计的渐近性质

矩估计满足两条漂亮的**大样本性质**（由大数定律与 CLT 推出）：

- **相合性**：样本矩 $A_k \xrightarrow{P} \mu_k$（大数定律），故矩估计 $\hat\theta \xrightarrow{P} \theta$——样本越多越准；
- **渐近正态性**：矩估计近似服从正态分布，方差可由「样本矩的渐近方差」通过链式法则传递——这是「用矩估计做区间」的依据。

这两条性质说明矩估计「大样本下总是可用的」，代价是「效率可能不是最高」。

### 矩估计与最大似然的对比

| | 矩估计 | 最大似然估计 |
| --- | --- | --- |
| 原理 | 令样本矩 = 总体矩 | 最大化似然函数 |
| 计算 | 解矩方程组（常简单） | 解似然方程（可能复杂） |
| 效率 | 一般（不用全部分布信息） | 高（用全部信息，渐近有效） |
| 适用 | 任何分布都能「硬解」 | 需要写出似然函数 |

**例（均匀分布的对比）**：$U(0, \theta)$ 的矩估计 $\hat\theta = 2\bar X$（用一阶矩 $E[X] = \theta/2$），而 MLE $\hat\theta = X_{(n)}$（样本最大值）。当 $n$ 较大时，$X_{(n)}$ 比 $2\bar X$ 更高效（方差更小）——**同一个参数，矩估计与 MLE 给出不同、质量不同的估计**。

### 矩估计的局限

三个典型局限：①**效率低**——它只用前 $m$ 阶矩的信息，丢掉了分布的「精细形状」；②**可能无解或解不合法**——矩方程组可能无实解，或解出超出参数空间的 $\hat\theta$；③**重尾分布下不稳**——二阶矩可能不存在（如柯西分布），矩方程失效。

**易错点｜辨析：** 矩估计的方程个数必须等于未知参数个数——一个参数列一个矩方程，两个参数列两个。另外「用哪几阶矩」有自由度：理论上用低阶矩更稳（方差小），但低阶矩不一定能解出所有参数——这是矩估计「配平」的艺术。



## 6 典型例题：矩估计的完整计算

**例 1（正态）**：$n = 20$ 样本，$\sum x_i = 200$、$\sum x_i^2 = 2200$。$A_1 = 10$、$A_2 = 110$，矩估计：

$$\hat\mu = A_1 = 10, \qquad \hat\sigma^2 = A_2 - A_1^2 = 110 - 100 = 10$$

**例 2（泊松）**：$\hat\lambda = \bar x$——泊松的均值 = 方差 = 参数，矩估计与 MLE 一致。

**例 3（均匀）**：$U(0,\theta)$，$E[X] = \theta/2$，矩估计 $\hat\theta = 2\bar x$；MLE $\hat\theta = x_{(n)}$。样本 $\{1.2, 2.8, 3.5\}$ 时矩估计 $= 5$、MLE $= 3.5$——两种方法不同答案。

**例 4（两个参数）**：$X \sim \Gamma(\alpha, \beta)$（$E[X] = \alpha\beta$、$\mathrm{Var} = \alpha\beta^2$）：

$$\hat\beta = \frac{A_2 - A_1^2}{A_1}, \qquad \hat\alpha = \frac{A_1^2}{A_2 - A_1^2}$$

「几个参数、几个矩方程」的配平原则在四例中完整呈现。

## 7 小结

- **点估计**：用统计量 $\hat\theta(X_1,\ldots,X_n)$ 猜未知参数；估计量是随机变量，估计值是具体数。
- **矩估计法**：令总体矩 = 样本矩，解方程组得参数估计，依据是大数定律。
- 正态的矩估计：$\hat\mu = \bar X$，$\hat\sigma^2 = \frac1n\sum(X_i-\bar X)^2$（$n$ 版、有偏）。
- 矩估计朴素直观、几乎总能给答案，但通常不是最有效，且不保证无偏。
- 矩估计是点估计的「第一家族」，下一节迎来它的对手——**最大似然估计法**。
