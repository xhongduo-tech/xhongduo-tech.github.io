## 为什么从一元线性回归开始

方差分析处理「分类因素」，回归分析处理「数值变量之间的关系」：身高与体重、施肥量与产量、广告投入与销售额。**一元线性回归（simple linear regression）**研究一个自变量 $x$ 与因变量 $y$ 之间的线性关系——它是全部回归、机器学习的起点，也是「最小二乘法」这个伟大思想的发源地。

回归分析在整个课程里的位置特殊：它综合运用了前面几乎一切工具——期望方差（数字特征）、正态分布（模型假设）、抽样分布（系数分布）、假设检验（显著性检验）、置信区间（系数区间与预测）。高斯 1809 年用最小二乘法做天体轨道拟合，至今仍是统计建模的第一课。<span class="marginnote">「回归」（regression）一词来自高尔顿对「父高子高」遗传数据的研究：他发现极端身高的父亲的儿子们身高普遍「向均值回归」——不是变得更极端，而是趋向平均。他称这个现象为 regression（回归），从此「回归分析」成了研究变量关系的代名词，尽管现代回归早已不限「回归均值」。</span>

## 1 模型设定

设 $y$ 与 $x$ 的关系近似线性，$n$ 组观测 $(x_i, y_i)$ 满足**一元线性回归模型**：

$$y_i = a + b x_i + \varepsilon_i, \qquad i = 1, 2, \ldots, n$$

其中 $a$ 是截距、$b$ 是斜率（回归系数），$\varepsilon_i \sim N(0, \sigma^2)$ 独立同分布——**误差独立、同方差、正态**三假设。$x_i$ 视为固定值（非随机，或给定条件下），$y_i$ 是随机变量。<span class="marginnote">模型的关键是「$y$ 随机、$x$ 固定」：给定 $x_i$，$y_i$ 的分布是 $N(a + bx_i, \sigma^2)$——均值沿直线、方差恒定。所以回归不是「$y$ 和 $x$ 的对称关系」，而是「用 $x$ 预测 $y$ 的条件期望」：$E[Y \mid x] = a + bx$。这正是第三章「条件均值是线性函数」的二维正态性质在一般情形的推广。</span>

## 2 最小二乘估计

**最小二乘法（method of least squares）**：选 $a, b$ 使「残差平方和」最小：

$$\min_{a, b}\ \sum_{i=1}^{n} (y_i - a - b x_i)^2$$

对 $a, b$ 求偏导令零，得正规方程，解出：

$$\hat b = \frac{\sum (x_i - \bar x)(y_i - \bar y)}{\sum (x_i - \bar x)^2} = \frac{S_{xy}}{S_{xx}}, \qquad \hat a = \bar y - \hat b \bar x$$

其中 $S_{xx} = \sum(x_i - \bar x)^2$，$S_{xy} = \sum(x_i - \bar x)(y_i - \bar y)$。**回归直线 $\hat y = \hat a + \hat bx$ 必然经过点 $(\bar x, \bar y)$**。<span class="marginnote">最小二乘的几何直觉：它找的直线使「各点到直线的竖直距离（残差）平方和」最小。为什么用「平方」不用「绝对值」？——平方方便求导（可解正规方程）、惩罚大残差更重，且在高斯误差假设下等价于最大似然估计。这是一个「数学便利 + 统计合理」的绝妙重合。</span>

**例**：广告投入 $x$（万元）与销售额 $y$（万元）的 5 组数据。算得 $\bar x = 4$，$\bar y = 50$，$S_{xx} = 40$，$S_{xy} = 240$。则 $\hat b = 240/40 = 6$，$\hat a = 50 - 6\times 4 = 26$。回归方程 $\hat y = 26 + 6x$——每多投 1 万元广告，销售额平均增加 6 万元。

## 3 最小二乘与最大似然的等价

**易错点｜辨析：** 最小二乘与最大似然在正态误差假设下**给出相同估计**。在 $y_i \sim N(a + bx_i, \sigma^2)$ 下，似然函数

$$L = \prod_i \frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(y_i - a - bx_i)^2}{2\sigma^2}\right)$$

最大化 $L$ ⇔ 最小化 $\sum (y_i - a - bx_i)^2$——**高斯误差假设下，最小二乘就是最大似然**。但若误差非正态，两者分道扬镳（最小二乘仍可用，但失去似然最优性）。<span class="marginnote">「最小二乘 = 正态下的最大似然」是一条深刻的桥：它把「几何上找最近直线」与「概率上找最合理参数」缝合起来。这也是为什么回归的推断（系数区间、检验）可以建立在正态假设上——最小二乘估计量的分布理论以误差正态为前提。第七章的最大似然在这里与第九章的回归正式会师。</span>

## 4 公式解析：斜率的「协变 ÷ 方差」

回归斜率 $\hat b$ 的结构是「$x$ 与 $y$ 的协变程度 ÷ $x$ 自身的波动」，拆开：

$$

\hat b = \frac{S_{xy}}{S_{xx}} = \frac{\sum (x_i - \bar x)(y_i - \bar y)}{\sum (x_i - \bar x)^2}

$$

- **第一步，分子 $S_{xy}$**：$x$ 偏离均值与 $y$ 偏离均值的乘积之和——「$x$ 高时 $y$ 是否也高」的累积度量，本质是 $x$、$y$ 的协方差的 $n$ 倍。
- **第二步，分母 $S_{xx}$**：$x$ 偏离均值的平方和——$x$ 自身的波动。
- **第三步，比值**：$x$ 每变动一单位，$y$ 平均变动多少。$S_{xy}$ 越大斜率越陡（关联越强），$S_{xx}$ 越大斜率越缓（$x$ 太散稀释了关联）。

「斜率 = 协变/自变」是回归的第一公式。它与相关系数 $\rho$ 的关系 $\hat b = \rho \frac{s_y}{s_x}$ 揭示了：斜率 = 相关系数 × 两变量标准差之比——把「关联强度」换算成「预测尺度」。

## 5 最小二乘的深入理解

最小二乘不只是「求导令零」——它背后有几何、统计与最优性的三重意义，逐一展开能让「为什么用最小二乘」这个问题有完整的答案。

### 残差的两个代数性质

最小二乘残差 $e_i = y_i - \hat y_i$ 自动满足两条恒等式：

1. **残差和为零**：$\sum_i e_i = 0$——回归直线「平均地」穿过数据；
2. **残差与 $x$ 正交**：$\sum_i e_i x_i = 0$——残差与自变量不相关。

这两条来自正规方程，是「残差平方和最小」的直接推论。它们也是模型诊断的起点：若残差与 $x$ 仍有明显模式（如弯曲、漏斗形），说明线性模型不够。

### 决定系数 R² 与相关系数

**决定系数** $R^2 = S_R/S_{yy} = 1 - S_E/S_{yy}$ 度量「$x$ 解释掉 $y$ 的波动比例」，$0 \le R^2 \le 1$。在一元回归里，$R^2$ 恰等于 $x$ 与 $y$ 样本相关系数的平方：

$$R^2 = r^2$$

**解读**：$r = 0.8$ 时 $R^2 = 0.64$——「$x$ 解释了 $y$ 波动的 64%」。$R^2 = 1$ 表示所有点都在直线上（完全线性），$R^2 = 0$ 表示 $x$ 毫无解释力（直线水平）。注意 $R^2$ 高不代表因果：混淆变量可能同时驱动 $x$ 与 $y$。

### 最小二乘 vs 其他拟合准则

| 准则 | 目标 | 特点 |
| --- | --- | --- |
| 最小二乘 | $\min\sum e_i^2$ | 解析可解、对离群点敏感 |
| 最小绝对偏差 | $\min\sum\|e_i\|$ | 对离群鲁棒、无解析解 |
| 最小最大偏差 | $\min\max\|e_i\|$ | 极小化最坏残差 |

最小二乘之所以是默认，因为它既解析可解（正态方程），又在高斯误差下等价于最大似然——「数学便利 + 统计合理」的双重优势。

### 例：完整的一元回归计算

数据 $(x,y)$：$(1,3),(2,5),(3,6),(4,8)$。$\bar x = 2.5$，$\bar y = 5.5$，$S_{xx} = 5$，$S_{xy} = 8.5$，则 $\hat b = 8.5/5 = 1.7$，$\hat a = 5.5 - 1.7\times 2.5 = 1.25$。回归方程 $\hat y = 1.25 + 1.7x$——$x$ 每增 1，$y$ 平均增 1.7。

最后提醒一句贯穿全书的话：**回归描述的是「条件期望」$E[Y \mid x] = a + bx$，不是「$Y$ 等于 $a + bx$」**。给定 $x$，$Y$ 的真实值是直线上的均值叠加随机误差——所以「预测值」是「平均预测」，实际观测会围绕它波动。理解了「回归线是条件均值线」这一层，你就不容易把回归结果误读成「确定性的函数关系」，这也是它与「函数」的根本区别。

再补充一张「最小二乘 vs 均值填充」的对照表，看回归为何优于「只用均值预测」：

| 预测方式 | 预测公式 | 残差平方和 | 解释力 |
| --- | --- | --- | --- |
| 只用均值 $\bar y$ | $\hat y = \bar y$ | $S_{yy}$ | 0（$R^2=0$） |
| 回归直线 | $\hat y = \hat a + \hat b x$ | $S_E = S_{yy} - S_R$ | $R^2 = S_R/S_{yy}$ |

$S_R \ge 0$ 保证回归的残差平方和总不超过均值填充——「用 $x$ 的信息总不会更差」，这就是「回归至少不亏」的数学保证。

## 6 小结

- **一元线性回归模型**：$y_i = a + bx_i + \varepsilon_i$，$\varepsilon_i \sim N(0,\sigma^2)$ 独立——线性、独立、同方差、正态。
- **最小二乘估计**：$\hat b = S_{xy}/S_{xx}$，$\hat a = \bar y - \hat b\bar x$，直线过 $(\bar x, \bar y)$。
- 最小二乘 = 正态误差下的最大似然；误差非正态时二者分道。
- 斜率「协变 ÷ 自变」，与相关系数 $\hat b = \rho\, s_y/s_x$ 直接挂钩。
- 回归分析是方差分析之外的「数值变量关系」推断，第九章后半全部建立在此。
