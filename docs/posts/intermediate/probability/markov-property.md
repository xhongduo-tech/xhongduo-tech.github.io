## 为什么从马尔可夫过程与马尔可夫性开始

泊松与维纳过程都假设「独立增量」——过去与未来完全无关。但更多现实过程是「有记忆」的：今天的天气影响明天的天气，当前的状态影响下一步的走向。**马尔可夫过程（Markov process）**是这类「一步记忆」过程的统称，其灵魂是**马尔可夫性（Markov property）**：**给定现在，未来与过去条件独立**——「预测未来只需知道当下，历史可以放下」。

马尔可夫性是概率论最重要的简化原则之一：它让无穷维的过程退化为一族一步转移规律，让计算从「不可能」变成「可行」。它是马尔可夫链（第十二章）、隐马尔可夫模型、强化学习（马尔可夫决策过程）、乃至大模型自回归生成的共同骨架。<span class="marginnote">马尔可夫性可以用条件分布精确写：<strong>$P\{X(t_{n+1}) \le x \mid X(t_1), \ldots, X(t_n)\} = P\{X(t_{n+1}) \le x \mid X(t_n)\}$——给定「最近的历史」，未来只依赖「最后的状态」</strong>。这条等式是全部马尔可夫理论的起点：一个条件，把「与全部过去相关」降为「与最后一个状态相关」。</span>

## 1 马尔可夫过程的定义

**马尔可夫过程（Markov process）**：设 $\{X(t), t \in T\}$ 是随机过程，若对任意 $t_1 < t_2 < \cdots < t_n$ 与任意状态，有

$$P\{X(t_n) \le x \mid X(t_1) = x_1, \ldots, X(t_{n-1}) = x_{n-1}\} = P\{X(t_n) \le x \mid X(t_{n-1}) = x_{n-1}\}$$

则称 $\{X(t)\}$ 为**马尔可夫过程**——**过去与未来在给定现在下条件独立**。

**马尔可夫性（Markov property）**：给定当前状态，未来与过去独立。用记号写：$P\{未来 \mid 过去, 现在\} = P\{未来 \mid 现在\}$。<span class="marginnote">「过去与未来关于现在条件独立」是马尔可夫性的两种等价表述——条件概率等式与条件独立。它的直观：状态 $X(t)$ 已经「总结」了历史对未来的全部影响，再往前翻旧账没有增量信息。这像下棋——下一步只取决于当前棋局，不需要回忆每一手是怎么走来的。</span>

**例（天气）**：明天是否下雨，只取决于今天的天气（今天晴 → 明天雨的概率 0.2），与昨天、前天无关——马尔可夫假设。现实里天气其实有更长记忆，但马尔可夫近似让「天气预测」可以计算。

## 2 马尔可夫链：离散时间离散状态的马尔可夫过程

当时间 $T$ 离散（$t = 0, 1, 2, \ldots$）、状态空间离散（$i, j = 0, 1, 2, \ldots$）时，马尔可夫过程称为**马尔可夫链（Markov chain）**，记为 $\{X_n, n \ge 0\}$。它的马尔可夫性写作：

$$P\{X_{n+1} = j \mid X_0 = i_0, \ldots, X_n = i_n\} = P\{X_{n+1} = j \mid X_n = i_n\}$$

**齐次（时齐）马尔可夫链**：若一步转移概率与时间 $n$ 无关——$P\{X_{n+1} = j \mid X_n = i\} = p_{ij}$ 与 $n$ 无关——称**齐次马尔可夫链**（本专题第十二章主要研究它）。<span class="marginnote">「齐次」（时齐）指转移规律不随时间变：今天从状态 $i$ 到 $j$ 的概率与明天、后天完全相同。非齐次链的转移概率随 $n$ 变（如季节因素），分析复杂得多。教材第十二章默认齐次链——矩阵方法（转移矩阵的幂）只在齐次下成立。</span>

**例（随机游走）**：$X_n$ 是 $n$ 步后随机游走的位置，$X_{n+1} = X_n + \varepsilon_{n+1}$（$\varepsilon$ 独立）。则 $\{X_n\}$ 是马尔可夫链——下一步只依赖当前位置，不依赖走过的路径。

## 3 马尔可夫链的分类

按状态空间与时间分类，马尔可夫家族有四大类：

| | 离散状态 | 连续状态 |
| --- | --- | --- |
| **离散时间** | 马尔可夫链（本专题） | 离散时间马尔可夫过程（少见） |
| **连续时间** | 连续时间马尔可夫链 / 生灭过程 | 扩散过程（如维纳过程也具马尔可夫性） |

有趣的是，**泊松过程与维纳过程都满足马尔可夫性**（独立增量 ⇒ 马尔可夫性，因为过去不影响未来的增量）。所以马尔可夫性是比独立增量更宽的性质——独立增量是马尔可夫性的特例。<span class="marginnote">「独立增量 ⇒ 马尔可夫性」值得证明：若增量独立，则 $X(t_{n+1}) = X(t_n) + \text{独立增量}$，给定 $X(t_n)$ 后，未来增量的分布与更早的 $X(t_1), \ldots$ 无关——马尔可夫性成立。所以泊松、维纳、随机游走都是马尔可夫过程；但马尔可夫过程远不止这些（有记忆但「一步记忆」的更多）。</span>

## 4 公式解析：马尔可夫性的「条件」结构

马尔可夫性的核心是「条件的对象变了」，拆开：

$$

P\{X_{n+1} = j \mid X_0 = i_0, \ldots, X_n = i_n\} = P\{X_{n+1} = j \mid X_n = i_n\}

$$

- **第一步，左式（全历史条件）**：已知整条历史 $X_0 = i_0, \ldots, X_n = i_n$，预测下一步到 $j$ 的概率。
- **第二步，右式（只要现在）**：把条件压缩成「最后的状态 $X_n = i_n$」——概率完全相同。
- **第三步，意义**：历史里的 $i_0, \ldots, i_{n-1}$ 对预测「多余」——$X_n$ 已携带全部相关信息。计算量从「历史的所有组合」塌缩到「当前状态」。

「条件的对象从『全部过去』压缩到『现在』」是马尔可夫性的全部机制。它把无穷维的依赖结构简化成一步转移，让一切马尔可夫计算（转移矩阵、稳态分布）成为可能。

## 5 马尔可夫性的深入辨析与应用

马尔可夫性是概率论最有力的简化假设，但它的应用边界、检验方法与现代意义值得展开。

### 马尔可夫性的三种等价表述

| 表述 | 形式 |
| --- | --- |
| 条件概率等式 | $P\{未来 \mid 过去,现在\} = P\{未来 \mid 现在\}$ |
| 条件独立 | 过去 ⊥ 未来 ｜ 现在 |
| 转移核刻画 | 有限维分布由初始 + 转移递归生成 |

**三种表述是同一件事**——理解「条件独立」视角，马尔可夫性从「一条公式」升格为「一种结构」。

### 例：天气的马尔可夫建模

**例**：把天气分为晴/雨，假设「明天只取决于今天」。$P = \begin{pmatrix} 0.8 & 0.2 \\ 0.4 & 0.6 \end{pmatrix}$——马尔可夫假设让「天气预测」可计算。若明天还取决于「昨天也下雨」（二阶马尔可夫），状态空间要扩展为「昨天×今天」的组合——**「记忆越长，状态空间越大」**是马尔可夫建模的代价。

### 隐马尔可夫模型（HMM）

**隐马尔可夫模型（Hidden Markov Model）**：状态 $X_n$ 不可观测，只观测到与状态相关的输出 $Y_n$。它由「转移矩阵 + 发射分布 + 初始分布」三个要素决定，是语音识别、词性标注、基因注释的标准模型——**「马尔可夫链在隐状态上 + 观测被发射」**是 HMM 的全部结构。

### 强化学习：马尔可夫决策过程

**马尔可夫决策过程（MDP）** = 马尔可夫链 + 动作 + 奖励：智能体在状态 $s$ 选动作 $a$，环境以 $P(s' \mid s, a)$ 转移到 $s'$ 并给奖励——**「下一状态只依赖当前状态与动作」正是马尔可夫性**。大模型、机器人的「序列决策」全部建在 MDP 上。

### 例：马尔可夫性的检验

数据 $\{X_1, \ldots, X_n\}$，想检验「是否马尔可夫」：比较「用全部历史」与「只用最后状态」的预测误差。若用全部历史显著更好，说明记忆超过一步，马尔可夫假设存疑——用第八章的模型比较或信息准则（AIC/BIC）判断。

**易错点｜辨析：** ① 马尔可夫性 ≠ 独立——马尔可夫允许「现在依赖过去」（通过现在间接依赖），独立则完全无关；② 「一阶马尔可夫」与「二阶」的区别是记忆长度，不是有无记忆；③ 马尔可夫性是「模型假设」，现实几乎从不严格成立——它是有用的近似，不是铁律。

再补一张「马尔可夫家族」的关系速查：

| 概念 | 记忆 | 结构 |
| --- | --- | --- |
| 独立过程 | 无记忆 | 增量独立 |
| 马尔可夫过程 | 一步记忆 | 未来只靠现在 |
| 二阶马尔可夫 | 两步记忆 | 未来靠近两步 |
| HMM | 一步（隐状态） | 状态隐、观测发射 |

「独立 ⊂ 马尔可夫 ⊂ 更高阶记忆」——记忆深度决定状态空间的复杂度，也决定计算的代价。

## 6 小结

- **马尔可夫性**：$P\{未来 \mid 过去, 现在\} = P\{未来 \mid 现在\}$——给定现在，未来与过去条件独立。
- **马尔可夫过程**：满足马尔可夫性的随机过程；**马尔可夫链** = 离散时间 + 离散状态的马尔可夫过程。
- **齐次链**：转移概率与时间无关，$p_{ij} = P\{X_{n+1}=j \mid X_n = i\}$。
- 独立增量 ⇒ 马尔可夫性（泊松、维纳都是马尔可夫过程），马尔可夫性更宽。
- 马尔可夫性是 HMM、强化学习（MDP）、大模型自回归生成的共同骨架。
