## 为什么从协方差与相关系数开始

方差衡量「一个变量偏离均值多少」，现在问「**两个变量是否同步偏离**」：身高高的人是不是通常更重？股票涨的时候债券是不是常跌？这种「一起波动的倾向」就是**协方差（covariance）**，而把它标准化成 $[-1, 1]$ 区间的就是**相关系数（correlation coefficient）**。

协方差与相关系数是统计推断的核心概念：它们衡量「线性关联」，是回归分析里 $R^2$ 的原料，也是多元统计、金融组合理论的基石。理解它们，等于掌握「两个随机变量之间关系」的第一把尺子。<span class="marginnote">历史小注：相关系数由高尔顿与皮尔逊在 19 世纪末为研究「父高子高」的遗传数据而提出——这正是回归（regression）一词的起源：身高有「向均值回归」的倾向。皮尔逊相关系数至今仍是机器学习和数据科学里 `np.corrcoef` 背后的同一个公式。</span>

## 1 协方差的定义与含义

**协方差（covariance）**：设 $X, Y$ 的期望分别为 $\mu_X, \mu_Y$，称

$$\mathrm{Cov}(X, Y) = E\left[(X - \mu_X)(Y - \mu_Y)\right]$$

为 $X$ 与 $Y$ 的**协方差**。

**符号的直觉**：当 $X$ 高（$X > \mu_X$）时 $Y$ 也常高（$Y > \mu_Y$），乘积 $(X-\mu_X)(Y-\mu_Y) > 0$，期望为正——**正相关**；反向联动时乘积常为负——**负相关**；无关时正负抵消，协方差接近 0。<span class="marginnote">协方差是「同步偏离」的平均：两个变量同时高于各自均值（同向）记正分，一高一低（反向）记负分，全部样本点求和取期望。正负号告诉你方向，大小则依赖量纲——这也是为什么需要相关系数来「去量纲」。</span>

**计算公式**（用展开式更方便）：

$$\mathrm{Cov}(X, Y) = E[XY] - E[X]\,E[Y]$$

由期望线性性直接得到。特别地，$\mathrm{Cov}(X, X) = \mathrm{Var}(X)$——**方差是协方差的特例：变量与自己的协方差**。

## 2 协方差的性质

协方差的运算规则（可直接验证）：

1. $\mathrm{Cov}(X, Y) = \mathrm{Cov}(Y, X)$——对称；
2. $\mathrm{Cov}(aX, bY) = ab\,\mathrm{Cov}(X, Y)$；
3. $\mathrm{Cov}(X_1 + X_2, Y) = \mathrm{Cov}(X_1, Y) + \mathrm{Cov}(X_2, Y)$——双线性；
4. $\mathrm{Cov}(X, X) = \mathrm{Var}(X)$；
5. $\mathrm{Var}(X \pm Y) = \mathrm{Var}(X) + \mathrm{Var}(Y) \pm 2\,\mathrm{Cov}(X, Y)$——上节方差的补全版。

性质 5 是方差可加性的完整形态：独立时 $\mathrm{Cov} = 0$，退回「方差相加」；相关时补上「两倍协方差」。<span class="marginnote">推广到 $n$ 个变量的和：$\mathrm{Var}\left(\sum a_i X_i\right) = \sum a_i^2 \mathrm{Var}(X_i) + 2\sum_{i<j} a_i a_j \mathrm{Cov}(X_i, X_j)$。组合投资里「分散风险」的数学依据就藏在交叉项里——负相关的资产贡献负的交叉项，压低组合总方差。</span>

**例**：$X$ 与 $Y$ 的方差都是 1，协方差 0.5。则 $\mathrm{Var}(X + Y) = 1 + 1 + 2 \times 0.5 = 3$，$\mathrm{Var}(X - Y) = 1 + 1 - 2 \times 0.5 = 1$——**同向加、反向减，协方差决定「组合波动」的增减**。

## 3 相关系数：标准化的协方差

协方差的大小依赖量纲（身高的「厘米×公斤」），没法跨变量比较。把协方差除以两个标准差，得到无量纲的**相关系数（correlation coefficient）**：

$$\rho_{XY} = \frac{\mathrm{Cov}(X, Y)}{\sqrt{\mathrm{Var}(X)\, \mathrm{Var}(Y)}} = \frac{\mathrm{Cov}(X, Y)}{\sigma_X \sigma_Y}$$

相关系数的关键性质：

- **取值范围**：$-1 \le \rho \le 1$；
- **$\rho = 1$**：$Y = aX + b$ 且 $a > 0$（完全正线性相关）；
- **$\rho = -1$**：$Y = aX + b$ 且 $a < 0$（完全负线性相关）；
- **$\rho = 0$**：称 $X$ 与 $Y$ **不相关（uncorrelated）**。

$|\rho|$ 越接近 1，点越聚集在一条直线上；越接近 0，线性关系越弱。<span class="marginnote">相关系数是「线性关联」的尺子：它只度量「点是否分布在一条直线附近」。曲线关系（如 $Y = X^2$）即使完全确定，$\rho$ 也可能为 0。这一点在下一节《不相关与独立的关系》里会成为重点辨析——「不相关」不等于「无关」，只是「没有线性关系」。</span>

**例**：$X$ 与 $Y$ 的方差为 $\sigma_X^2 = 4, \sigma_Y^2 = 9$，$\mathrm{Cov}(X,Y) = 3$。则 $\rho = 3/(2 \times 3) = 0.5$——中等正相关。若协方差改为 $-3$，则 $\rho = -0.5$。

## 4 公式解析：协方差展开式为何好用

协方差 $E[XY] - E[X]E[Y]$ 是计算的主力公式，逐项拆开：

$$

\mathrm{Cov}(X, Y) = \iint (x - \mu_X)(y - \mu_Y)\, f(x,y)\, dx\,dy = \iint xy\, f\, dx\,dy - \mu_X \mu_Y

$$

- **第一步，定义式**：$\mathrm{Cov} = E[(X-\mu_X)(Y-\mu_Y)]$，展开乘积得 $XY - \mu_X Y - \mu_Y X + \mu_X\mu_Y$。
- **第二步，期望线性性**：$E[XY] - \mu_X E[Y] - \mu_Y E[X] + \mu_X\mu_Y = E[XY] - \mu_X\mu_Y - \mu_X\mu_Y + \mu_X\mu_Y = E[XY] - \mu_X\mu_Y$。
- **第三步，实用化**：算协方差只需「$E[XY]$」与「两个边缘期望」，不必算二维二阶中心矩。这通常省掉一重积分。

「$E[XY] - E[X]E[Y]$」是协方差的第一公式，几乎所有协方差计算都从它出发。顺带一提：$E[XY] = E[X]E[Y]$ 当且仅当 $\mathrm{Cov} = 0$，即不相关——这也是独立性（$E[XY] = E[X]E[Y]$）与不相关的联系点。

## 5 协方差与相关系数的深入应用

协方差与相关系数是「线性关联」的度量，它们的计算、解读与延伸值得展开。

### 例：协方差的计算

**例**：$X$、$Y$ 的联合分布已知。$\mathrm{Cov}(X,Y) = E[XY] - E[X]E[Y]$——先算三个期望再组合，通常比定义式省力。

### 例：相关系数的解读

**例**：$\mathrm{Cov} = 3$、$\sigma_X = 2$、$\sigma_Y = 3$，$\rho = 3/(2\times 3) = 0.5$——中等正相关。**「相关系数无量纲，$[-1,1]$ 区间可比」**是它优于协方差之处。

### 协方差的性质速查

| 性质 | 公式 |
| --- | --- |
| 对称 | $\mathrm{Cov}(X,Y) = \mathrm{Cov}(Y,X)$ |
| 双线性 | $\mathrm{Cov}(aX, bY) = ab\,\mathrm{Cov}$ |
| 方差特例 | $\mathrm{Cov}(X,X) = \mathrm{Var}(X)$ |
| 和的方差 | $\mathrm{Var}(X\pm Y) = \mathrm{Var}X+\mathrm{Var}Y\pm 2\mathrm{Cov}$ |

**「双线性 + 对称 + 方差是特例」**——协方差的代数三件套。

### 例：组合波动

**例**：两只股票收益 $X, Y$，$\mathrm{Var}X = \mathrm{Var}Y = 1$、$\mathrm{Cov} = 0.5$。组合 $X + Y$ 的方差 $= 1+1+2\times0.5 = 3$——**「负相关压低组合波动」是分散投资的数学依据**。

### 相关 ≠ 因果

**例**：冰淇淋销量与溺水人数高度相关——都受「夏天」驱动，无关因果。**「相关 ≠ 因果」**是数据解读的铁律，混淆变量是罪魁。

**易错点｜辨析：** ① 协方差带量纲（单位相乘）、相关系数无量纲；② 相关系数只度量线性关联——曲线关系可能 $\rho = 0$；③ 相关强度分级（0.3/0.6/0.8）是经验参考，别机械套用。

## 6 小结

- **协方差** $\mathrm{Cov}(X,Y) = E[(X-\mu_X)(Y-\mu_Y)] = E[XY] - E[X]E[Y]$，衡量同步偏离的倾向。
- **协方差性质**：双线性、对称、$\mathrm{Cov}(X,X) = \mathrm{Var}(X)$，方差可加性由它补全。
- **相关系数** $\rho = \mathrm{Cov}(X,Y)/(\sigma_X\sigma_Y)$，取值 $[-1,1]$，无量纲。
- $\rho = \pm 1$ ⇔ 完全线性相关；$\rho = 0$ ⇔ 不相关。
- 相关系数只度量**线性**关联，曲线关系即使完全确定也可能 $\rho = 0$。
