## 为什么从 Z 检验与 t 检验开始

第八章「假设检验」的第一场实战：**检验单个正态总体的均值 $\mu$ 是否等于某值 $\mu_0$**。这是「达标检验」的标准形态——灯泡寿命是否达标、学生平均分是否达标、产品平均重量是否符合规格。与区间估计一样，它分两路：总体方差 $\sigma^2$ 已知用 **Z 检验**，未知用 **t 检验**。

均值检验是整章检验的「母题」：双侧、单侧、Z 与 t 的切换、p 值计算，全在这一节立规矩。学会它，后面双总体、成对、方差检验都只是「换统计量」的重演。<span class="marginnote">「Z 检验 vs t 检验」的选择逻辑与第七章区间估计完全同构：<strong>$\sigma$ 已知用 Z（标准正态），$\sigma$ 未知用 t（$n-1$ 自由度）</strong>。区别只在查哪张表。大样本（$n \ge 30$）时两者临界值几乎相等，所以有些教材在 $n$ 大时统一用 Z——但严格做法「未知就用 t」永远正确。</span>

## 1 Z 检验：方差已知

设 $X \sim N(\mu, \sigma^2)$，$\sigma^2$ 已知，检验 $H_0: \mu = \mu_0$。检验统计量：

$$Z = \frac{\bar X - \mu_0}{\sigma/\sqrt n} \sim N(0, 1) \quad (\text{当 } H_0 \text{ 真})$$

拒绝域由 $H_1$ 方向决定：

| $H_1$ | 拒绝域（$\alpha$ 水平） |
| --- | --- |
| $\mu \ne \mu_0$ | $\|Z\| \ge z_{\alpha/2}$ |
| $\mu > \mu_0$ | $Z \ge z_\alpha$ |
| $\mu < \mu_0$ | $Z \le -z_\alpha$ |

**例**：灯泡寿命 $X \sim N(\mu, 100^2)$（$\sigma = 100$ 已知），标准 2000 小时，抽查 $n = 25$，$\bar x = 1960$。检验 $H_0: \mu = 2000$ vs $H_1: \mu \ne 2000$，$\alpha = 0.05$。

$$Z = \frac{1960 - 2000}{100/\sqrt{25}} = \frac{-40}{20} = -2.0$$

$|Z| = 2.0 \ge z_{0.025} = 1.96$ → **落入拒绝域，拒绝 $H_0$**——平均寿命显著低于标准。<span class="marginnote">注意这个例子的微妙处：$|Z| = 2.0$ 恰好跨过 1.96 的门槛，拒绝 $H_0$；若 $\bar x = 1962$（$|Z| = 1.9$），就不拒绝。拒绝与否往往取决于「统计量离临界值多远」——这正是 p 值要量化的「有多显著」。</span>

## 2 t 检验：方差未知

设 $\sigma^2$ 未知，用 $S$ 代替 $\sigma$。检验统计量：

$$T = \frac{\bar X - \mu_0}{S/\sqrt n} \sim t(n-1) \quad (\text{当 } H_0 \text{ 真})$$

拒绝域（$\alpha$ 水平）：

| $H_1$ | 拒绝域 |
| --- | --- |
| $\mu \ne \mu_0$ | $\|T\| \ge t_{\alpha/2}(n-1)$ |
| $\mu > \mu_0$ | $T \ge t_\alpha(n-1)$ |
| $\mu < \mu_0$ | $T \le -t_\alpha(n-1)$ |

**例**：新工艺处理后测 10 个零件的平均寿命 $\bar x = 2100$ 小时，$s = 120$ 小时，问是否显著高于旧工艺的 2000 小时。$H_0: \mu = 2000$ vs $H_1: \mu > 2000$，$\alpha = 0.05$，$t_{0.05}(9) = 1.833$。

$$T = \frac{2100 - 2000}{120/\sqrt{10}} = \frac{100}{37.95} = 2.635$$

$T = 2.635 \ge 1.833$ → 拒绝 $H_0$——新工艺平均寿命显著更高。<span class="marginnote">「显著性」这个词要谨慎理解：$T = 2.635$ 说明「平均寿命显著高于 2000」是统计意义上的显著——它只意味着「差异不像随机波动」，<strong>不代表「差异很大或有实际意义」</strong>。统计显著 ≠ 实际重要，这个区分是读懂一切检验结论的前提。</span>

## 3 Z 检验与 t 检验的对照

| | Z 检验 | t 检验 |
| --- | --- | --- |
| 适用 | $\sigma^2$ 已知 | $\sigma^2$ 未知 |
| 统计量 | $Z = \dfrac{\bar X - \mu_0}{\sigma/\sqrt n}$ | $T = \dfrac{\bar X - \mu_0}{S/\sqrt n}$ |
| 分布 | $N(0,1)$ | $t(n-1)$ |
| 大样本 | 精确 | 接近 $N(0,1)$ |

**易错点｜辨析：** ① 方差已知与否决定用 Z 还是 t，别凭印象；② 自由度 $n-1$ 别写成 $n$；③ 单侧检验的分位点是 $t_\alpha$ 不是 $t_{\alpha/2}$——「$H_1$ 的方向决定拒绝域的形状与临界值」；④ 大样本（$n \ge 30$）下 t 与 z 几乎一致，可用 z 近似，但严格口径是「未知用 t」。<span class="marginnote">「自由度 $n-1$ 还是 $n$」在 t 检验里是高频失分点：$T$ 的分母用 $S$（样本方差），而 $S^2$ 的 χ² 自由度是 $n-1$，所以 $T \sim t(n-1)$。第七章 t 区间、第八章 t 检验、第九章回归 t 检验，全部统一为「$n-1$ 或 $n-p-1$」——因为每个被估计的均值都吃掉一个自由度。</span>

## 4 公式解析：检验统计量的「标准化偏离」

Z/t 检验统计量都源于同一个结构「观测偏离假设值 ÷ 标准误」：

$$

T = \frac{\bar X - \mu_0}{S/\sqrt n}

$$

- **第一步，分子**：$\bar X - \mu_0$——样本均值与假设均值的偏离。$H_0$ 真时它围绕 0 波动。
- **第二步，分母**：$S/\sqrt n$——$\bar X$ 的标准误，即「偏离的典型量级」。$H_0$ 真时 $T$ 的典型量级是 1 左右。
- **第三步，判读**：$|T|$ 远超 1（相对临界值）说明「偏离远超随机波动」，数据与 $H_0$ 不符。

「标准化偏离」是检验统计量的统一语法：把「偏离假设的量」除以「随机波动的量级」，得到一个无量纲的裁判数。所有检验（z、t、χ²、F）都是这个结构的变体。

## 5 均值检验的深入应用与实例

Z 检验与 t 检验是「均值达标」的裁决工具，它们的计算、选择与实务值得展开。

### 例：Z 检验

**例**：$\sigma = 100$ 已知，$n = 25$、$\bar x = 1960$。检验 $H_0: \mu = 2000$：$Z = \frac{1960-2000}{20} = -2.0$，$|Z| = 2.0 \ge 1.96$ → 拒绝——平均寿命显著低于标准。

### 例：t 检验

**例**：$\sigma$ 未知，$n = 10$、$\bar x = 2100$、$s = 120$。检验 $H_0: \mu = 2000$（单侧）：$T = \frac{2100-2000}{120/\sqrt{10}} = 2.635$，$t_{0.05}(9) = 1.833$ → 拒绝——新工艺显著更高。

### 选择与分布

| | Z 检验 | t 检验 |
| --- | --- | --- |
| 前提 | $\sigma$ 已知 | $\sigma$ 未知 |
| 分布 | $N(0,1)$ | $t(n-1)$ |
| 大样本 | 精确 | ≈ $N$ |

**「$\sigma$ 已知用 Z、未知用 t」**——判据一句话。

### 例：单侧 vs 双侧

$H_1: \mu \ne 2000$ 用 $|Z| \ge z_{\alpha/2}$；$H_1: \mu > 2000$ 用 $Z \ge z_\alpha$——**「$H_1$ 方向决定拒绝域形状」**，方向必须看数据前定。

### 与置信区间的对偶

检验「$\mu = \mu_0$」=「$\mu_0$ 是否在 $\mu$ 的区间内」——**「检验与区间互为镜像」**，报告区间自动携带检验结论。

### 统计显著 vs 实际重要

$n$ 大时微小差异也显著——**「显著 ≠ 重要」**，看置信区间与效应量判断实际意义。

**易错点｜辨析：** ① 自由度 $n-1$；② 单侧用 $z_\alpha$ 不是 $z_{\alpha/2}$；③ 「不显著」≠「无差异」——可能检测力不足。

## 6 小结

- **Z 检验**（$\sigma$ 已知）：$Z = \frac{\bar X - \mu_0}{\sigma/\sqrt n} \sim N(0,1)$，拒绝域由 $H_1$ 方向定（双侧/右/左）。
- **t 检验**（$\sigma$ 未知）：$T = \frac{\bar X - \mu_0}{S/\sqrt n} \sim t(n-1)$，临界值查 t 表。
- 单侧检验分位点用 $t_\alpha$，双侧用 $t_{\alpha/2}$；自由度 $n-1$。
- 统计显著 ≠ 实际重要：显著只说明「不像随机波动」。
- 均值检验是整章检验的母题，四步流程（设假设→选统计量→定拒绝域→下结论）通用于所有检验。
