## 为什么从概率密度开始

到目前为止我们研究的都是离散型随机变量：掷骰子、数成功次数、数呼叫。可现实里大量随机现象是**连续**的——身高、体重、测量误差、等待时间、寿命，它们可以取某个区间内的任意实数值。对于连续量，「取某个精确值」的概率天然是 0（精确到无穷小位是几乎不可能的），所以不能像离散那样逐点赋概率。概率论为此换了一把尺子：不再量「点」，而量「密度」——**概率密度函数**。

概率密度是概率论里第一个真正需要微积分的对象：概率 = 密度曲线下的面积。若你学过《高等数学》或《数学分析》里的定积分，这一节几乎是「把面积换成概率」的翻译练习；若还没学，本节会给你足够自洽的直觉。<span class="marginnote">「单点概率为零」听起来荒谬却千真万确：连续型随机变量取任何特定精确值的概率都是 0，但落在区间内的概率可以很大。这就引出一个反直觉结论——概率为 0 的事件并非不可能发生，它只是「几乎不发生」。</span>

## 1 定义：密度与概率的积分关系

**连续型随机变量（continuous random variable）**：若随机变量 $X$ 的分布函数 $F(x)$ 可表示为某个非负函数 $f(x)$ 的积分

$$F(x) = \int_{-\infty}^{x} f(t)\, dt, \qquad -\infty < x < +\infty$$

则称 $X$ 为连续型随机变量，$f(x)$ 称为 $X$ 的**概率密度函数（probability density function, PDF）**，简称为**概率密度**。

概率密度的两条基本性质：

1. **非负性**：$f(x) \ge 0$，对一切 $x$；
2. **归一性**：$\int_{-\infty}^{+\infty} f(x)\, dx = 1$。

归一性说的是「密度曲线下的总面积是 1」——$X$ 总得落在数轴上某处，正像离散情形所有 $p_k$ 之和为 1。<span class="marginnote">这两条性质与离散分布律的非负性、归一性完全平行：<strong>离散求和对应连续积分</strong>。判断「给定函数能否当密度」就用这两条，这是本章最常见的判断题。</span>

## 2 概率的三种等价算法

有了密度，一切区间概率都是定积分：

- 区间概率：$P\{a < X \le b\} = \int_{a}^{b} f(x)\, dx$；
- 一点概率：$P\{X = a\} = \int_a^a f(x)\, dx = 0$；
- 补事件：$P\{X > a\} = \int_{a}^{+\infty} f(x)\, dx = 1 - F(a)$。

**易错点｜辨析：** 连续型 $P\{X = a\} = 0$，所以区间的开闭**无影响**：$P\{a < X < b\} = P\{a \le X \le b\}$。这与离散型截然相反（离散型开闭差一个单点概率）。做题时先判断随机变量类型，再决定端点是否重要——这是连续型最容易丢分的细节。<span class="marginnote">还有一个常见误解：$f(a)$ 本身不是「$X$ 取 $a$ 的概率」。$f(a)$ 是<strong>密度</strong>，单位是「每单位 $x$ 的概率」，可以大于 1；概率必须乘上区间长度再积分才得到。把密度当概率，是初学连续型的第一大误区。</span>

**例**：设 $X$ 的密度为 $f(x) = \begin{cases} 2x, & 0 \le x \le 1 \\ 0, & \text{其他} \end{cases}$。验证归一：$\int_0^1 2x\, dx = x^2 \big|_0^1 = 1$。求 $P\{X \le 1/2\} = \int_0^{1/2} 2x\, dx = 1/4$。

## 3 密度、分布函数与微积分基本定理

在连续情形，密度 $f$ 与分布函数 $F$ 的关系由微积分基本定理完整给出：

$$f(x) = F'(x), \qquad F(x) = \int_{-\infty}^{x} f(t)\, dt$$

即在 $f$ 连续处，**分布函数的导数就是密度函数**。于是：

- 已知密度求分布函数：做一次积分；
- 已知分布函数求密度：做一次求导；
- $F$ 的几何含义：曲线 $y = f(t)$ 在 $(-\infty, x]$ 段下的面积，随 $x$ 增大而累积。

这张「积分 ↔ 求导」的对偶，正是连续型概率论与微积分合体的核心。<span class="marginnote">这解释了为什么本课程把你放在《高等数学》之后：没有定积分工具，连续型概率论寸步难行。反过来，概率论也给了积分一个鲜活直觉——积分不是抽象的符号游戏，而是「随机变量落在某段里的概率」。</span>

**例**：由 $F(x) = \int_{-\infty}^{x} f(t)\, dt$ 立得 $P\{X = a\} = F(a) - F(a - 0)$；对连续型 $F$ 连续，$F(a-0) = F(a)$，差为 0——又一次印证单点概率为零。

## 4 公式解析：从密度到概率的两步

任何「已知密度求区间概率」的问题都走同一个流程，以 $f(x) = \begin{cases} \frac{1}{2} e^{-x/2}, & x > 0 \\ 0, & x \le 0 \end{cases}$（参数为 2 的指数分布）为例，求 $P\{1 < X \le 3\}$：

$$

P\{1 < X \le 3\} = \int_{1}^{3} \frac{1}{2} e^{-x/2}\, dx = -e^{-x/2}\Big|_{1}^{3} = e^{-1/2} - e^{-3/2}

$$

- **第一步，圈定积分区间**：事件 $\{1 < X \le 3\}$ 决定积分上下限 $1$ 到 $3$；注意题目给的密度在 $x \le 0$ 处为零，故积分只在有效区间进行。
- **第二步，做定积分**：$\int \frac12 e^{-x/2} dx = -e^{-x/2} + C$，代入上下限相减。
- **第三步，化简结果**：$e^{-1/2} - e^{-3/2} \approx 0.607 - 0.223 = 0.384$。

若求 $P\{X > 1\}$，可积分 $\int_1^{\infty}$，或用补事件 $1 - F(1) = 1 - (1 - e^{-1/2}) = e^{-1/2}$——**指数密度「$P\{X > x\} = e^{-x/\theta}$」这个漂亮的尾巴公式，会在指数分布一节大放异彩**。

## 5 连续型随机变量的深入应用与实例

连续型是「概率密度」的世界，它的计算、直觉与常见陷阱值得完整展开。

### 例：验证密度合法性

**例**：$f(x) = 2x$（$0\le x\le 1$）。非负 ✓，$\int_0^1 2x dx = 1$ ✓——合法密度。任何候选密度都要过「非负 + 归一」两关。

### 例：区间概率的计算

**例**：$f(x) = \begin{cases} \frac12 e^{-x/2}, & x > 0 \\ 0, & x \le 0 \end{cases}$，求 $P\{1 < X \le 3\}$：

$$\int_1^3 \frac12 e^{-x/2}dx = e^{-1/2} - e^{-3/2} \approx 0.384$$

**「先圈区间、再积分」**是连续概率的标准动作。

### 连续 vs 离散对照

| | 离散 | 连续 |
| --- | --- | --- |
| 概率载体 | 分布律 $p_k$ | 密度 $f(x)$ |
| 单点概率 | 可非零 | 恒 0 |
| 区间概率 | 求和 | 积分 |
| 分布函数 | 阶梯 | 连续 |

**「离散求和、连续积分」**是两条路的统一对偶。

### 例：密度不是概率

$f(a)$ 是「每单位 $x$ 的概率」，可以大于 1——必须积分后才是概率。**「密度 ≠ 概率」**是连续型第一大误区。

### 例：从密度到分布函数

$F(x) = \int_{-\infty}^x f(t)dt$、$f = F'$——**「积分 ↔ 求导互逆」**，微积分基本定理是连续概率的引擎。

**易错点｜辨析：** ① 连续型 $P\{X = a\} = 0$，区间开闭无影响——与离散截然相反；② 分布函数右连续、密度可任意改单点值——单点不影响概率；③ 混用「密度当概率」会得出荒谬结论（如 $f > 1$ 处说概率 > 1）。

## 6 小结

- **连续型随机变量**由概率密度 $f(x) \ge 0$ 描述，满足 $\int_{-\infty}^{+\infty} f(x)\, dx = 1$。
- 概率是密度曲线下的面积：$P\{a < X \le b\} = \int_a^b f(x)\, dx$；**单点概率恒为 0**，区间开闭无影响。
- $f$ 与分布函数 $F$ 通过微积分基本定理互逆：$F' = f$，$f$ 积分得 $F$。
- 密度不是概率：$f(a)$ 可大于 1，必须积分后才得到概率。
- 连续型与离散型的对照：「求和 ↔ 积分」「分布律 ↔ 密度」「阶梯 ↔ 曲线」，是全章的主线对偶。

在下一节，我们见到第一个连续分布——**均匀分布**：密度在区间内恒为常数，是「几何概型的随机变量化」。
