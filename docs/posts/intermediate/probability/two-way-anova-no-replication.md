# 双因素试验的方差分析：无重复试验

<div class="epigraph">
<p>当两个因素同时作用，方差分析的平方和不再是一分为二，而是一分为三——因素 A、因素 B、误差。</p>

## 为什么从双因素方差分析开始

现实里的实验往往不止一个因素：作物的产量同时受「品种」与「施肥量」影响，材料的强度同时受「温度」与「压力」影响。**双因素方差分析（two-way ANOVA）**同时考察两个因素对响应变量的影响，比单因素更贴近真实，也更省实验（一次实验同时回答两个问题）。

无重复试验（每个「因素 A 水平 × 因素 B 水平」组合只做一次观测）是双因素方差分析的最简形态：平方和分解从「组间 + 组内」升级为「因素 A + 因素 B + 误差」三块。它比单因素多一个「因素效应」的检验，是「多因素设计」的入门课。<span class="marginnote">无重复 vs 有重复的差别：无重复的每个单元格只有一个观测，无法估计「交互作用」（两因素协同的特殊效应），总平方和只能分解成 A + B + 误差三块；有重复（等重复）的每个单元格多个观测，能额外分解出「交互项」——下一节的主题。本节先打地基。</span>

## 1 模型设定

设因素 A 有 $a$ 个水平、因素 B 有 $b$ 个水平，每个组合做一次观测 $X_{ij}$（$i = 1, \ldots, a$；$j = 1, \ldots, b$）。无重复双因素模型：

$$X_{ij} = \mu + \alpha_i + \beta_j + \varepsilon_{ij}, \qquad \varepsilon_{ij} \sim N(0, \sigma^2) \text{ 独立}$$

其中 $\alpha_i$ 是因素 A 第 $i$ 水平的效应，$\beta_j$ 是因素 B 第 $j$ 水平的效应，约束 $\sum \alpha_i = 0$、$\sum \beta_j = 0$。两个检验：

- $H_{0A}$：$\alpha_1 = \cdots = \alpha_a = 0$（因素 A 无效应）；
- $H_{0B}$：$\beta_1 = \cdots = \beta_b = 0$（因素 B 无效应）。

<span class="marginnote">模型里没有「交互项」$\gamma_{ij}$——因为每个单元格只有一个观测，交互项与误差不可区分。这是无重复设计的代价：<strong>能检验两个主效应，但无法检验交互作用</strong>。若怀疑两因素会「配合发力」（如某种品种特别吃肥），需要重复试验来分离交互项。</span>

## 2 平方和分解：一分为三

记总均值 $\bar X_{\cdot\cdot}$、A 第 $i$ 水平均值 $\bar X_{i\cdot}$、B 第 $j$ 水平均值 $\bar X_{\cdot j}$。平方和分解：

$$S_T = S_A + S_B + S_E$$

其中

- $S_A = b\sum_{i=1}^{a}(\bar X_{i\cdot} - \bar X_{\cdot\cdot})^2$——因素 A 的主效应（按 B 的水平数 $b$ 加权）；
- $S_B = a\sum_{j=1}^{b}(\bar X_{\cdot j} - \bar X_{\cdot\cdot})^2$——因素 B 的主效应（按 A 的水平数 $a$ 加权）；
- $S_E = S_T - S_A - S_B$——剩余误差。

**自由度**：$df_A = a - 1$，$df_B = b - 1$，$df_E = (a-1)(b-1)$，$df_T = ab - 1$。<span class="marginnote">自由度分配有个漂亮的恒等式：$df_T = df_A + df_B + df_E$，即 $(ab-1) = (a-1) + (b-1) + (a-1)(b-1)$。误差自由度 $(a-1)(b-1)$ 看起来神秘，实为「总自由度 − 两个因素自由度」后的剩余。所有自由度加起来等于 $n-1 = ab-1$，是双因素方差分析表自检的第一条。</span>

## 3 检验与方差分析表

两个因素的检验统计量：

$$F_A = \frac{MS_A}{MS_E} = \frac{S_A/(a-1)}{S_E/(a-1)(b-1)} \sim F(a-1,\ (a-1)(b-1))$$

$$F_B = \frac{MS_B}{MS_E} = \frac{S_B/(b-1)}{S_E/(a-1)(b-1)} \sim F(b-1,\ (a-1)(b-1))$$

**方差分析表**：

| 来源 | SS | df | MS | F |
| --- | --- | --- | --- | --- |
| 因素 A | $S_A$ | $a-1$ | $MS_A$ | $F_A$ |
| 因素 B | $S_B$ | $b-1$ | $MS_B$ | $F_B$ |
| 误差 | $S_E$ | $(a-1)(b-1)$ | $MS_E$ | |
| 总和 | $S_T$ | $ab-1$ | | |

$F_A \ge F_\alpha(a-1, (a-1)(b-1))$ 拒绝 $H_{0A}$，$F_B$ 同理。<span class="marginnote">两个因素共用同一个误差均方 $MS_E$ 作分母——「效应 vs 噪声」的比值各自独立裁决。这就是双因素设计的效率：一次实验，两个结论。注意两个 F 的分子自由度不同（$a-1$ 与 $b-1$），查表时别用错行。</span>

**例**：研究温度（A，3 水平）与压力（B，4 水平）对材料强度的影响，$a = 3, b = 4, n = 12$。算得 $S_A = 420$、$S_B = 540$、$S_E = 240$。$MS_A = 210$，$MS_B = 180$，$MS_E = 240/6 = 40$。$F_A = 210/40 = 5.25$，$F_B = 180/40 = 4.5$。查 $F_{0.05}(2, 6) = 5.14$、$F_{0.05}(3, 6) = 4.76$：$F_A = 5.25 > 5.14$ 拒绝 A 无效；$F_B = 4.5 < 4.76$ 不拒绝 B 无效——**温度影响显著，压力影响不显著**。

## 4 公式解析：为什么 S_A 乘 b

因素 A 的平方和 $S_A = b\sum_i(\bar X_{i\cdot} - \bar X_{\cdot\cdot})^2$ 里的「乘 $b$」值得拆开：

$$

S_A = b\sum_{i=1}^{a}(\bar X_{i\cdot} - \bar X_{\cdot\cdot})^2

$$

- **第一步，A 水平均值的离散**：$\bar X_{i\cdot}$ 是第 $i$ 个 A 水平下对 B 取平均的均值，$\bar X_{i\cdot} - \bar X_{\cdot\cdot}$ 度量 A 效应的强弱。
- **第二步，乘 $b$**：每个 A 水平下有 $b$ 个观测（对应 B 的 $b$ 个水平），所以「该水平均值的偏离」要按观测数 $b$ 加权——与单因素「乘 $n_i$」同构。
- **第三步，对称性**：$S_B$ 同理乘 $a$。两因素的平方和「各自按对方水平数加权」，结构完全对称。

「按对方水平数加权」是双因素平方和的关键直觉：某因素的平方和 = 该因素各水平均值（加权）的离散度，权重等于每个水平下的观测数。对称、可加、自由度守恒，三件事一起记。

## 5 无重复双因素方差分析的深入应用

无重复双因素设计是「一次实验、两个因素」的入门，它的计算、限制与实例值得展开。

### 例：完整计算

**例**：温度（A，3 水平）× 压力（B，4 水平），$n = 12$。算得 $S_A = 420$、$S_B = 540$、$S_E = 240$。$MS_A = 210$、$MS_B = 180$、$MS_E = 240/6 = 40$。$F_A = 5.25$、$F_B = 4.5$。查 $F_{0.05}(2,6) = 5.14$、$F_{0.05}(3,6) = 4.76$：温度显著、压力不显著。

### 平方和分解

$$S_T = S_A + S_B + S_E$$

其中 $S_A = b\sum(\bar X_{i\cdot} - \bar X_{\cdot\cdot})^2$、$S_B = a\sum(\bar X_{\cdot j} - \bar X_{\cdot\cdot})^2$——**「各自按对方水平数加权」**，两因素对称。

### 自由度分配

| 来源 | df |
| --- | --- |
| A | $a-1$ |
| B | $b-1$ |
| 误差 | $(a-1)(b-1)$ |
| 总和 | $ab-1$ |

**「$(a-1)(b-1)$ 是剩余自由度」**——$(ab-1) - (a-1) - (b-1)$ 的自动结果。

### 无重复设计的限制

无重复设计**无法检验交互作用**——每个单元格一个观测，交互与误差不可区分。**「要检验交互，就得等重复（下一节）」**是设计的代价。

### 例：与单因素的对照

| | 单因素 | 双因素无重复 |
| --- | --- | --- |
| 因素数 | 1 | 2 |
| 平方和分解 | 2 块 | 3 块 |
| 检验数 | 1 | 2 |

**「双因素一次实验回答两个问题」**——效率更高，但代价是无法分离交互。

**易错点｜辨析：** ① 权重按对方水平数（$S_A$ 乘 $b$）——别搞反；② 自由度 $(a-1)(b-1)$ 别写成 $ab$；③ 无重复设计「检验不了交互」——需要交互就必须重复。

## 6 小结

- **无重复双因素模型**：$X_{ij} = \mu + \alpha_i + \beta_j + \varepsilon_{ij}$，两个主效应各带一个检验。
- **平方和分解** $S_T = S_A + S_B + S_E$，权重按对方水平数（$S_A$ 乘 $b$、$S_B$ 乘 $a$）。
- 自由度：$a-1$、$b-1$、$(a-1)(b-1)$，三者相加 $= ab-1$。
- 检验：$F_A = MS_A/MS_E \sim F(a-1, (a-1)(b-1))$，$F_B$ 同理。
- 无重复设计能检验两个主效应，但**无法检验交互作用**——那是下一节等重复试验的任务。
