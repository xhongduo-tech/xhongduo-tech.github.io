## 为什么从维纳过程开始

泊松过程是「离散状态」的连续时间过程（数个数），而**维纳过程（Wiener process）**是「连续状态」的连续时间过程——它描述**布朗运动（Brownian motion）**：悬浮微粒受分子碰撞的随机游走，是股票价格、扩散现象、金融随机分析的标准模型。

维纳过程在整个课程里是「连续随机过程」的典范：它的增量是正态分布（而非泊松）、轨道连续但处处不可导、独立增量 + 平稳增量的结构与泊松对称。它是中心极限定理的动态版——大量微小随机扰动之和随时间演化。现代金融学（Black–Scholes）、随机微分方程、强化学习探索噪声都以它为基础。<span class="marginnote">历史：1827 年植物学家布朗用显微镜观察到花粉微粒的无规则运动；1905 年爱因斯坦用分子运动论导出其统计规律（扩散方程）；1923 年维纳首次严格构造了这个数学过程——从此「布朗运动 = 维纳过程」。物理直觉先于数学严格近百年，是「现象 → 理论 → 严格化」的经典剧本。</span>

## 1 定义

**维纳过程（Wiener process）**：随机过程 $\{W(t), t \ge 0\}$ 满足：

1. $W(0) = 0$；
2. **独立增量**：不重叠区间内的增量独立；
3. **平稳正态增量**：$W(t) - W(s) \sim N(0, \sigma^2 (t - s))$；
4. **轨道连续**：$W(t)$ 是 $t$ 的连续函数（以概率 1）。

当 $\sigma^2 = 1$ 时称为**标准维纳过程 / 标准布朗运动**，增量 $W(t) - W(s) \sim N(0, t-s)$。<span class="marginnote">维纳过程与泊松过程是一对「对称的极端」：泊松过程增量离散（泊松分布）、轨道跳跃；维纳过程增量连续（正态分布）、轨道连续。两者共享「独立增量 + 平稳增量」的骨架——这个骨架叫「莱维过程（Lévy process）」，泊松与维纳是它的两大成员。理解这对对称，就抓住了连续时间独立增量过程的全部图景。</span>

## 2 维纳过程的性质

**性质 1（数字特征）**：$E[W(t)] = 0$，$\mathrm{Var}(W(t)) = \sigma^2 t$，$\mathrm{Cov}(W(s), W(t)) = \sigma^2 \min(s, t)$——与泊松过程结构同构（$\lambda t$ 换成 $\sigma^2 t$）。

**性质 2（正态性）**：任意有限个时刻的 $(W(t_1), \ldots, W(t_n))$ 服从多元正态分布——**维纳过程是正态过程**（其均值函数与协方差函数完全决定它）。

**性质 3（轨道特征）**：$W(t)$ 的轨道连续，但**处处不可导**——「几乎每一条样本路径都像被放大镜放大后的雪花」；它的二次变差 $\sum (\Delta W)^2 \to \sigma^2 t$（非零）——这是随机积分（伊藤积分）理论的起点。<span class="marginnote">「处处不可导」是维纳过程最反直觉的性质：布朗运动微粒的速度在数学上不存在（无穷大）。物理上这是「分子碰撞频繁到无法定义瞬时速度」的极限；数学上它让维纳过程无法用普通微积分处理——必须发展新的积分（伊藤积分、斯特拉托诺维奇积分），那是第二级《随机过程》深化与金融数学的接口。此处只需记住：连续 ≠ 可导。</span>

## 3 例：从随机游走到维纳过程

维纳过程是**随机游走的连续极限**：设每次以概率 1/2 走 $\pm\Delta$，每步时间 $\Delta t$，则 $n$ 步后的位置

$$S_n = \sum_{i=1}^n \varepsilon_i \Delta, \qquad \varepsilon_i = \pm 1 \text{ 等概率}$$

由 CLT，当 $\Delta \to 0$、$n \to \infty$（保持 $n\Delta t = t$）时，$S_n/\sqrt{\Delta t}$ 收敛到维纳过程。**维纳过程 = 微小随机游走的极限**——这正是它成为「股价」「扩散」标准模型的理由：无数小随机扰动的累积。<span class="marginnote">「随机游走 → 维纳过程」的极限关系是中心极限定理的「动态版」：CLT 说「很多独立小量之和 ≈ 正态」，维纳过程说「很多独立小步的累积 ≈ 布朗运动」——$t$ 固定看 $W(t)$ 是正态（CLT），让 $t$ 流动就是整个过程。理解这条链，维纳过程的「无处不在」就有了根源。</span>

## 4 公式解析：为什么增量方差 ∝ t-s

维纳过程「增量方差 $\sigma^2(t-s)$」的结构是「独立小步累积」，拆开：

$$

\mathrm{Var}(W(t) - W(s)) = \sigma^2 (t - s)

$$

- **第一步，独立增量**：$W(t) - W(s)$ 是 $(s, t]$ 内无穷多个独立小扰动的累积，方差可加（独立性）。
- **第二步，单位时间方差**：令 $\sigma^2$ = 单位时间增量的方差，则时长 $t-s$ 的方差 = $\sigma^2 \times (t-s)$——「方差随时长线性增长」。
- **第三步，与随机游走对照**：$n$ 步随机游走方差 = $n \Delta^2$，若 $\Delta^2 = \sigma^2 \Delta t$，则 $= \sigma^2 \cdot n\Delta t = \sigma^2 t$——极限正是 $\sigma^2 t$。

「方差随时长线性增长」是维纳过程的标志性结构：波动不是按 $\sqrt{t}$ 缩放（那是标准差），而是按 $t$ 累积。这也解释了为什么股价长期波动的不确定性按 $\sqrt{t}$ 增长——标准差 $\sigma\sqrt{t}$。

## 5 维纳过程的深入性质与应用

维纳过程之所以无处不在，是因为它拥有一组其他过程难以企及的深层结构——马尔可夫性、鞅性、自相似性与扩散方程的联系。

### 马尔可夫性与鞅性

**维纳过程是马尔可夫过程**：给定 $W(t)$，未来增量 $W(t+h) - W(t) \sim N(0, \sigma^2 h)$ 与过去独立——预测未来只需当前位置。

**维纳过程是鞅（martingale）**：对 $s < t$，$E[W(t) \mid \text{过去}] = W(s)$——**已知过去，未来位置的最优预测就是现在的位置**。鞅性意味着「布朗运动没有趋势、方向不可预测」，这是有效市场假说与随机分析（伊藤积分）的基石。

### 缩放自相似性

维纳过程满足**自相似**性质：

$$W(ct) \stackrel{d}{=} \sqrt{c}\, W(t), \qquad c > 0$$

**解读**：时间轴拉长 $c$ 倍、振幅缩为 $\sqrt{c}$，得到的是同一个过程——「怎么看都像自己」。这解释了布朗运动轨道的分形粗糙度，也是金融里「波动率随 $\sqrt{t}$ 增长」的根源：$\mathrm{Std}(W(t)) = \sigma\sqrt t$。

### 扩散方程与爱因斯坦关系

布朗运动的密度函数满足**扩散方程**（热传导方程）：

$$\frac{\partial f}{\partial t} = \frac{\sigma^2}{2}\frac{\partial^2 f}{\partial x^2}$$

这正是爱因斯坦 1905 年的核心结果：布朗运动的统计规律由扩散方程控制，扩散系数 $D = \sigma^2/2$ 与温度、黏度、粒子尺寸相关——**微观的随机碰撞，在宏观上表现为确定性的扩散方程**。这条「微观随机 → 宏观确定」的桥梁，是统计物理与随机过程的经典交汇。

### 股价模型与模拟

**几何布朗运动**（股价对数模型）$\ln S(t) = \ln S(0) + \mu t + \sigma W(t)$ 假设对数收益含正态噪声，是 Black–Scholes 期权定价的随机基础。模拟股价路径只需把 $[0,T]$ 分 $n$ 段、每段累加独立正态增量——这是蒙特卡洛金融模拟的标准做法，也是「随机游走 → 维纳过程」极限的数值版。

**易错点｜辨析：** 维纳过程的「处处不可导」意味着它不能用普通微积分处理——对 $W(t)$ 做「$dW$」需要用伊藤引理（随机链式法则），而非普通链式法则。这是随机微积分与普通微积分的分水岭：进入金融随机分析前，必须先接受「$dW$ 的平方是 $dt$」这类非常规运算。



## 6 典型例题：维纳过程的计算

**例 1（增量概率）**：求 $P\{W(4) - W(1) \le 2\}$。增量 $\sim N(0, 3)$：

$$P\{W(4)-W(1) \le 2\} = \Phi(2/\sqrt3) = \Phi(1.155) \approx 0.876$$

**例 2（协方差）**：$\mathrm{Cov}(W(2), W(5)) = \sigma^2 \min(2,5) = 2\sigma^2$——「较小时刻的方差」决定协方差。

**例 3（自相似）**：$\mathrm{Var}(W(9)) = 9$、$\mathrm{Var}(3W(1)) = 9$——两者同分布，正是 $W(ct) \stackrel{d}{=} \sqrt{c}W(t)$（$c = 9$）的实例。

**例 4（鞅性）**：$W(t) = W(s) + (W(t) - W(s))$，增量独立且零均值：

$$E[W(t) \mid W(s)] = W(s) + 0 = W(s)$$

四个例子覆盖增量、协方差、自相似、鞅——维纳过程的四张面孔各算一遍。

## 7 小结

- **维纳过程**：$W(0)=0$ + 独立增量 + 平稳正态增量 $N(0, \sigma^2(t-s))$ + 轨道连续。
- 数字特征：$\mu(t) = 0$，$\sigma^2(t) = \sigma^2 t$，$\mathrm{Cov}(s,t) = \sigma^2\min(s,t)$。
- **正态过程**：有限维分布都是多元正态，由均值与协方差函数完全决定。
- 轨道**连续但处处不可导**；二次变差非零——随机积分（伊藤）的起点。
- 维纳过程 = 随机游走的连续极限（CLT 的动态版），是扩散、股价、金融随机分析的标准模型。
