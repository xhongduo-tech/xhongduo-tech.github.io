## 为什么从正态分布开始

人类的身高、考试的分数、测量的误差、仪器读数的扰动——这些量画成频率图，几乎都是同一个形状：中间高、两边低、左右对称的钟形。这个形状背后的分布，就是**正态分布（normal distribution）**，概率论里最重要的分布，没有之一。它之所以无处不在，是因为一个深刻的定理——**中心极限定理**：大量独立微小随机因素之和，无论各自服从什么分布，总和都趋向正态。第五章我们将严格证明它，而本章先用好它。

正态分布在本书的地位是「枢纽」：它是所有抽样分布（$\chi^2$、$t$、$F$）的老家，是参数估计与假设检验里一切区间与检验的基准，也是从大数定律到回归分析全部章节的公共背景。<span class="marginnote">正态分布的历史堪称传奇：棣莫弗 1733 年用它逼近二项分布，拉普拉斯推广为「中心极限定理」，高斯 1809 年用最小二乘法引出它，于是欧洲常称「高斯分布」——而「正态（normal）」这个带有「常规、标准」意味的名字，更凸显它在统计中的统治地位。</span>

## 1 定义：两个参数决定一条钟形

**正态分布（normal distribution）**：若随机变量 $X$ 的概率密度为

$$f(x) = \frac{1}{\sqrt{2\pi}\,\sigma} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right), \qquad -\infty < x < +\infty$$

则称 $X$ 服从参数为 $\mu, \sigma$ 的正态分布，记作 $X \sim N(\mu, \sigma^2)$。其中 $\mu$ 是均值（曲线的对称轴、峰的位置），$\sigma$ 是标准差（曲线的胖瘦）。

两个参数的几何含义清晰直观：

- $\mu$ 决定**位置**：整个钟形沿 $x$ 轴平移；
- $\sigma$ 决定**形状**：$\sigma$ 越大曲线越矮胖（数据越散），$\sigma$ 越小越尖瘦（数据越聚）。

<span class="marginnote">记号习惯：分布写作 $N(\mu, \sigma^2)$，第二个参数是<strong>方差</strong> $\sigma^2$ 而非标准差 $\sigma$。看到 $N(0, 1)$ 就知是「均值 0、方差 1」，而 $N(0, 0.25)$ 的标准差是 0.5。参数是方差还是标准差，是最容易看错的第一处。</span>

## 2 标准正态分布与标准化

当 $\mu = 0$、$\sigma = 1$ 时，得到**标准正态分布（standard normal distribution）** $N(0,1)$，其密度与分布函数分别记为 $\varphi(x)$ 与 $\Phi(x)$：

$$\varphi(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}, \qquad \Phi(x) = \int_{-\infty}^{x} \varphi(t)\, dt$$

标准正态分布之所以重要，是因为任何正态分布都能通过**标准化（standardization）** 化成它。设 $X \sim N(\mu, \sigma^2)$，令

$$Z = \frac{X - \mu}{\sigma}$$

则 $Z \sim N(0, 1)$。这把「任意参数的正态概率」全部归结为「查一张标准正态表」——正是教材附表所用的方法。<span class="marginnote">标准化的直觉：$X - \mu$ 把对称轴搬到原点，$\div \sigma$ 把「胖瘦」压成标准瘦。于是「$X$ 距均值几个标准差」的问题，变成「$Z$ 是多少」的问题——这也是「$z$ 分数」「$z$ 检验」名称的来源，第六章抽样分布将反复用它。</span>

**例**：$X \sim N(2, 4)$（即 $\mu=2, \sigma=2$）。求 $P\{X \le 4\}$：

$$P\{X \le 4\} = P\left\{\frac{X-2}{2} \le \frac{4-2}{2}\right\} = P\{Z \le 1\} = \Phi(1) \approx 0.8413$$

## 3 三σ 法则与区间概率

正态分布的区间概率可以由 $\Phi$ 查表得到，其中三个「标杆值」务必背下来——这就是著名的**三 σ 法则（68-95-99.7 规则）**：

| 区间 | 概率 |
| --- | --- |
| $P\{\mu - \sigma < X < \mu + \sigma\}$ | $\approx 0.683$ |
| $P\{\mu - 2\sigma < X < \mu + 2\sigma\}$ | $\approx 0.954$ |
| $P\{\mu - 3\sigma < X < \mu + 3\sigma\}$ | $\approx 0.997$ |

![标准正态分布曲线与 ±σ 区间](/images/probability/normal-distribution-1.svg)

几乎全部概率（99.7%）都落在均值左右各 3 个标准差之内。这条规则是质量管理的灵魂：**6σ 管理**把规格限设在均值 ±6σ，使得缺陷率低至十亿分之几——日常所说「六西格玛」即源于此。<span class="marginnote">查表 $\Phi(x)$ 时注意教材附表通常只列 $x \ge 0$，负侧用对称性 $\Phi(-x) = 1 - \Phi(x)$。另外 $\Phi(x)$ 的值常以「$x$ 保留两位小数」索引，标准化后要四舍五入到两位再去查。</span>

## 4 公式解析：标准化为什么总是可行

标准化公式是正态分布全部计算的钥匙，值得逐项拆解：

$$

Z = \frac{X - \mu}{\sigma} \sim N(0, 1)

$$

- **第一步，平移去中心**：$X - \mu$ 把钟形从「以 $\mu$ 为轴」搬到「以 0 为轴」。均值变为 0，标准差不变。
- **第二步，缩放定标**：除以 $\sigma$ 把「胖瘦」压成标准。方差由 $\sigma^2$ 变为 $1$，于是 $Z$ 的标准差恰为 1。
- **第三步，为什么仍正态**：正态分布在「线性变换」下保持正态——$aX + b$ 仍是正态变量。这是因为密度的指数里，$(x-\mu)^2/\sigma^2$ 经线性替换后仍是 $x$ 的二次型。这个「线性变换封闭性」是正态分布最宝贵的性质之一，第三章的 $Z = X + Y$、第四章的多元正态都要靠它。

标准化的本质，是把「任意刻度的正态问题」翻译成「标准正态问题」，从而复用一张表解决一切——**查表的艺术，就是标准化的艺术**。

## 5 正态分布为什么「无处不在」

正态分布的统治地位不是巧合，而是三个机制的共同结果：

- **中心极限定理**：大量独立小随机量之和趋向正态（第五章严格证明）。测量误差是无数微小扰动的叠加，故正态。
- **二项分布的极限**：$n$ 大且峰不在边界时，$B(n,p)$ 逼近 $N(np, np(1-p))$（棣莫弗—拉普拉斯定理）。
- **分布的稳定性**：正态变量经线性组合、加减运算后仍是正态，使它在多元情形（第三章）与抽样分布（第六章）中保持自洽。

**易错点｜辨析：** 正态分布虽然普遍，但**不是**万能的。收入、房价、地震震级呈重尾偏态，服从对数正态或幂律，而非正态——它们「均值附近概率高」的直觉成立，但「尾部按指数瘦下去」的假设彻底失效。用正态模型拟合重尾数据，会系统性低估极端事件概率（金融上的「黑天鹅」）。<span class="marginnote">重尾与正态的差别是统计建模的分水岭：正态说「极端值几乎不可能」，幂律说「极端值虽少但远比你想象的常见」。学完本书后，你会遇到「厚尾」的概念在金融风险、网络科学里反复出现——那时回看本节，你会感激这个提醒。</span>

## 6 正态分布的深入应用与实例

正态分布是概率论的「贵族」，它的计算、标准化与三 σ 法则值得完整展开。

### 例：标准化的计算

**例**：$X \sim N(2, 4)$（$\mu=2, \sigma=2$）。$P\{X \le 4\} = \Phi(\frac{4-2}{2}) = \Phi(1) \approx 0.8413$——「先标准化、再查表」是正态计算的标准流程。

### 三 σ 法则

| 区间 | 概率 |
| --- | --- |
| $\mu \pm \sigma$ | 68.3% |
| $\mu \pm 2\sigma$ | 95.4% |
| $\mu \pm 3\sigma$ | 99.7% |

**「68-95-99.7 规则」**是质量管理的灵魂——6σ 管理源于此。

### 例：标准化公式

$$Z = \frac{X - \mu}{\sigma} \sim N(0,1)$$

**「平移去中心、缩放定标」**——任何正态都化成标准正态，查一张表解决一切。

### 正态的封闭性

| 操作 | 结果 |
| --- | --- |
| 线性组合 | 仍正态 |
| 独立和 | 均值方差相加 |
| 样本均值 | 精确正态 |

**「正态在线性变换下封闭」**——这是它被广泛使用的原因。

### 例：正态 vs 重尾

**例**：收入、房价、地震震级重尾偏态——正态假设会低估极端事件概率（「黑天鹅」）。**「正态普遍但非万能」**——建模前先看数据形状。

**易错点｜辨析：** ① 记号 $N(\mu, \sigma^2)$ 第二参数是方差；② 查表只给 $\Phi$，负侧用对称性；③ 「中心极限定理」让大量和近似正态，但不是「一切皆正态」。

## 7 小结

- **正态分布** $X \sim N(\mu, \sigma^2)$：钟形、对称，$\mu$ 定位置、$\sigma$ 定胖瘦。
- **标准正态分布** $N(0,1)$：密度 $\varphi(x)$、分布函数 $\Phi(x)$，一切正态概率经**标准化** $Z = (X-\mu)/\sigma$ 后查表可得。
- **三 σ 法则**：$\mu\pm\sigma$、$\mu\pm2\sigma$、$\mu\pm3\sigma$ 分别覆盖约 68.3%、95.4%、99.7% 的概率。
- 正态分布在**线性变换下封闭**：$aX+b$ 仍正态——这是它与众不同的代数特质。
- 正态的「无处不在」源于中心极限定理，但重尾数据不可滥用正态假设。
