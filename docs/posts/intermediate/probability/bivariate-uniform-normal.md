## 为什么从二维均匀分布与二维正态分布开始

二维连续分布无穷无尽，但教材重点考察两个样板：**二维均匀分布**与**二维正态分布**。前者是「几何概型在平面上的标准形态」——概率正比于面积，概念极简却算遍各种区域；后者是「二维世界的正态分布」——以均值向量为中心、以协方差矩阵定形状，统治着多元统计、回归分析与机器学习中的高斯模型。

这两个分布一简一繁，恰好覆盖二维连续分布的两极：一个把计算负担全压在「求区域面积」上，一个把全部精妙藏在「参数 $\rho$ 与独立性」的关系里。理解它们，等于把第三章的联合/边缘/条件/独立性四大概念在一个具体的分布上完整演练一遍。<span class="marginnote">二维正态分布的地位在一维之上：它是「高斯过程」「多元正态」的最小非平凡版本，也是第十一章随机过程里「正态过程」的静态切面。机器学习里最经典的高斯混合模型（GMM）、卡尔曼滤波的观测方程，都以多元正态为基本积木。</span>

## 1 二维均匀分布：概率 = 面积比

**二维均匀分布**：设 $G$ 是平面上面积为 $A$ 的有界区域，若 $(X,Y)$ 的联合密度为

$$f(x, y) = \begin{cases} \dfrac{1}{A}, & (x,y) \in G \\[6pt] 0, & (x,y) \notin G \end{cases}$$

则称 $(X,Y)$ 在 $G$ 上服从二维均匀分布。于是对任意区域 $D \subseteq G$，

$$P\{(X,Y) \in D\} = \frac{\text{面积}(D)}{\text{面积}(G)}$$

——**概率完全由面积比决定**，这正是几何概型。<span class="marginnote">二维均匀分布的边缘分布不一定是均匀的：在三角域上均匀时，边缘密度 $f_X(x)$ 正比于「该 $x$ 处区域的高度」，往往是个三角形或梯形。这提醒我们——联合均匀，边缘未必均匀；边缘的形状由区域的「横截面」决定。</span>

**例**：$(X,Y)$ 在单位圆 $x^2 + y^2 \le 1$ 上均匀分布。求 $P\{X^2 + Y^2 \le 1/4\}$：这是半径 $1/2$ 的圆内，面积比 $(1/4) / 1 = 1/4$。

## 2 二维正态分布：密度与参数

**二维正态分布（bivariate normal distribution）**：若 $(X,Y)$ 的联合密度为

$$f(x,y) = \frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}} \exp\left\{-\frac{1}{2(1-\rho^2)}\left[\frac{(x-\mu_1)^2}{\sigma_1^2} - \frac{2\rho(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2} + \frac{(y-\mu_2)^2}{\sigma_2^2}\right]\right\}$$

则称 $(X,Y)$ 服从参数为 $\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho$ 的二维正态分布，记作 $(X,Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$。其中 $\mu_1,\mu_2$ 是均值，$\sigma_1^2,\sigma_2^2$ 是方差，$\rho \in (-1, 1)$ 是相关系数。<span class="marginnote">五个参数各司其职：前四个描述两个分量各自的「位置与胖瘦」，$\rho$ 描述「倾向性」——$\rho > 0$ 时山丘沿直线 $y \approx x$ 的方向被拉长，$\rho$ 越接近 ±1 山脊越窄，$\rho = 0$ 时等高线是正圆。密度指数里的交叉项 $\frac{2\rho(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2}$ 是 $\rho$ 唯一的藏身处。</span>

## 3 二维正态的三大经典性质

二维正态分布是「性质最丰富」的二维分布，三条性质在考试与后续章节中反复出现：

**性质 1（边缘仍正态）**：$X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$——边缘分布都是（一维）正态，且参数直接被读出。

**性质 2（独立 ⇔ $\rho = 0$）**：$X$ 与 $Y$ 独立当且仅当 $\rho = 0$。这是全书最重要的结论之一：**对二维正态，「不相关」与「独立」完全等价**。<span class="marginnote">这条性质在第四章会被放大为一个「反例收藏家」——对一般分布，不相关 ≠ 独立；唯独二维正态是个例外，因为它的密度指数里，$\rho = 0$ 时交叉项消失，$f(x,y)$ 恰好拆成 $f_X(x)f_Y(y)$。记住「正态里独立 = 不相关」，做题时能省一半力气。</span>

**性质 3（条件分布仍正态）**：给定 $Y = y$ 时，$X$ 的条件分布是正态：

$$X \mid Y = y \sim N\left(\mu_1 + \rho\frac{\sigma_1}{\sigma_2}(y - \mu_2),\ \sigma_1^2(1 - \rho^2)\right)$$

条件均值 $\mu_1 + \rho\frac{\sigma_1}{\sigma_2}(y - \mu_2)$ 是 $y$ 的**线性函数**——这正是回归分析「条件期望是直线」的理论根源；条件方差 $\sigma_1^2(1-\rho^2)$ 不含 $y$，且被 $\rho$ 压缩（$|\rho|$ 越大，条件方差越小，$Y$ 对 $X$ 的预测越准）。<span class="marginnote">性质 3 的意义远超本章：它给出了「最优线性预测」的完整理论——知道 $Y$ 后，$X$ 的最佳估计是那条回归直线，误差方差是 $\sigma_1^2(1-\rho^2)$。第九章《一元线性回归》的最小二乘线、$R^2$ 的解释力，都能追溯到这一行条件分布。</span>

## 4 公式解析：二维正态密度为什么难算

二维正态密度的计算之难，在于指数里的二次型。把它拆开看：

$$

Q = \frac{1}{1-\rho^2}\left[\frac{(x-\mu_1)^2}{\sigma_1^2} - \frac{2\rho(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2} + \frac{(y-\mu_2)^2}{\sigma_2^2}\right]

$$

- **第一步，识别二次型**：方括号里是「$(x-\mu_1)$ 与 $(y-\mu_2)$」的齐二次函数，含平方项与交叉项。交叉项 $-\frac{2\rho(\cdot)(\cdot)}{\sigma_1\sigma_2}$ 的存在，使等值线不再是圆，而是倾斜的椭圆。
- **第二步，对角化视角**：令 $u = \frac{x-\mu_1}{\sigma_1}$、$v = \frac{y-\mu_2}{\sigma_2}$（标准化），则 $Q = \frac{u^2 - 2\rho uv + v^2}{1-\rho^2}$。这是一个关于 $u,v$ 的正定二次型——它的等值线是椭圆，长短轴方向由 $\rho$ 决定。
- **第三步，归一化系数**：$2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}$ 保证总体积为 1。$\sqrt{1-\rho^2}$ 出现在分母，说明 $|\rho| \to 1$ 时山丘越窄越尖、密度峰值越高，$|\rho| \to 0$ 时回到圆形。

**实战策略**：做题时几乎不需要直接展开密度计算，而是**背性质**——边缘正态、独立⇔$\rho=0$、条件正态。二维正态的题目大多是「给参数，问边缘/条件/独立」，用三条性质即可秒解，不必碰密度本身。

## 5 二维均匀与二维正态的深入应用

两个样板分布的「为什么重要」值得展开——均匀看面积、正态看相关，各有各的看家本事。

### 例：二维均匀的面积计算

**例**：$(X,Y)$ 在三角域 $\{0 \le x \le 1, 0 \le y \le x\}$ 均匀。密度 $f = 2$（面积 $1/2$ 的倒数）。$P\{X \le 1/2\} = 2 \times \frac{1}{8} = 1/4$（小三角面积 $1/8$）。**「概率 = 面积比」**是二维均匀的全部计算。

### 例：二维正态的条件分布应用

**例**：$(X,Y) \sim N(0, 0, 1, 1, \rho)$。给定 $Y = y$，$X$ 的条件分布 $N(\rho y, 1 - \rho^2)$——条件均值 $\rho y$ 是直线、条件方差 $1-\rho^2$ 是常数。**「$\rho$ 越接近 ±1，条件方差越小，预测越准」**——这正是回归分析的种子。

### 二维均匀 vs 二维正态对照

| | 二维均匀 | 二维正态 |
| --- | --- | --- |
| 密度 | 常数 $1/A$ | 高斯钟面 |
| 参数 | 区域 | $\mu_1,\mu_2,\sigma_1,\sigma_2,\rho$ |
| 边缘 | 区域投影 | 正态 |
| 独立判据 | 支撑是矩形且可拆 | $\rho = 0$ |
| 用途 | 几何概率 | 多元统计、回归 |

**「均匀管几何、正态管统计」**——两个分布各司其职。

### 例：$\rho$ 与等高线的形状

| $\rho$ | 等高线 |
| --- | --- |
| 0 | 正圆 |
| 0.5 | 东北—西南倾斜椭圆 |
| 0.9 | 窄长椭圆（近似直线） |
| -0.8 | 西北—东南窄椭圆 |

**「$\rho$ 决定椭圆的方向与胖瘦」**——等高线图一眼看出相关结构。

**易错点｜辨析：** ① 二维正态「$\rho = 0$ ⇔ 独立」是特例，别推广；② 二维均匀的边缘通常不均匀（三角域的边缘是三角形）；③ 二维正态的边缘正态但「边缘正态的联合未必正态」——两者不等价。

## 6 小结

- **二维均匀分布**：$f = 1/\text{面积}$，概率 = 面积比；边缘不一定均匀。
- **二维正态分布**：五参数 $(\mu_1,\mu_2,\sigma_1^2,\sigma_2^2,\rho)$，等高线是倾斜椭圆。
- **三大性质**：边缘仍正态；独立 ⇔ $\rho = 0$；条件分布仍正态（条件均值是 $y$ 的线性函数）。
- 条件方差 $\sigma_1^2(1-\rho^2)$ 揭示「知道 $Y$ 能把 $X$ 的不确定性压掉多少」——回归分析的种子。
- 二维正态的题目走「背性质」路线，直接展开密度的收益很低。
