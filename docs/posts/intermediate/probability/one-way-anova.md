## 为什么从单因素方差分析开始

第八章的 t 检验比较两个均值。可现实里常常要**同时比较三个以上**：四种肥料哪种产量最高？五种温度哪种效果最好？如果两两做 t 检验，$m$ 组要比较 $\binom{m}{2}$ 次——不仅繁琐，还会犯**多重比较**的错误（比较次数越多，至少一次误判的概率越高）。**方差分析（analysis of variance, ANOVA）**用一个 F 检验同时回答「$m$ 组均值是否全相等」，是单因素（一个分类因素）试验的标准工具。

方差分析（ANOVA）是费希尔 1920 年代在罗萨姆斯泰德农业试验站创立的，名字虽叫「方差分析」，核心问题却是「**均值是否相等**」——它通过分解「总波动」为「组间波动」与「组内波动」，用两者的比值做检验。<span class="marginnote">「方差分析」这个名字很反直觉：明明比较均值，为什么叫「方差」？因为手段是「分解方差」——把总波动拆成「组间的」（由组均值差异引起）与「组内的」（随机误差），若组间波动相对组内显著偏大，说明组均值确实不同。名字来自手段，问题来自目的。</span>

## 1 模型设定

设因素有 $m$ 个水平（组），第 $i$ 组有 $n_i$ 个观测，观测值为 $X_{ij}$（$i = 1, \ldots, m$；$j = 1, \ldots, n_i$）。单因素方差分析的模型：

$$X_{ij} = \mu + \alpha_i + \varepsilon_{ij}$$

其中 $\mu$ 是总平均，$\alpha_i$ 是第 $i$ 组的效应（$\sum_i n_i \alpha_i = 0$ 或 $\sum_i \alpha_i = 0$），$\varepsilon_{ij} \sim N(0, \sigma^2)$ 独立同分布。**检验**：

$$H_0: \alpha_1 = \alpha_2 = \cdots = \alpha_m = 0 \quad(\text{各组均值相等})$$

vs $H_1$：至少有一个 $\alpha_i \ne 0$。<span class="marginnote">模型的假设条件（方差分析三假设）：①各观测<strong>独立</strong>；②各组<strong>方差相等</strong>（方差齐性）；③误差<strong>正态</strong>。三个假设缺一不可——方差分析的 F 检验对这些假设敏感。第八章学过的方差齐性检验（F 检验）、正态性检验（偏度峰度/拟合优度）正是用来检查这些前提的。</span>

## 2 方差分解的思想：组间与组内

方差分析的核心是把「总波动」拆成两块。记总均值 $\bar X_{\cdot\cdot}$、第 $i$ 组均值 $\bar X_{i\cdot}$，则

$$\underbrace{\sum_{i,j}(X_{ij} - \bar X_{\cdot\cdot})^2}_{S_T\ \text{总平方和}} = \underbrace{\sum_i n_i(\bar X_{i\cdot} - \bar X_{\cdot\cdot})^2}_{S_A\ \text{组间平方和}} + \underbrace{\sum_{i,j}(X_{ij} - \bar X_{i\cdot})^2}_{S_E\ \text{组内平方和}}$$

- **$S_A$（组间）**：各组均值对总均值的偏离——「效应」引起的波动；
- **$S_E$（组内）**：组内观测对组均值的偏离——「随机误差」引起的波动。

**$S_T = S_A + S_E$**：总波动 = 效应波动 + 误差波动。若效应不存在（$H_0$ 真），$S_A$ 应该只反映随机误差，与 $S_E$ 相当；若 $S_A$ 明显大于 $S_E$，说明组间确有差异。<span class="marginnote">平方和分解 $S_T = S_A + S_E$ 的证明只靠「加一项减一项」：$X_{ij} - \bar X_{\cdot\cdot} = (X_{ij} - \bar X_{i\cdot}) + (\bar X_{i\cdot} - \bar X_{\cdot\cdot})$，平方展开后交叉项求和为零。这个「组内 + 组间」的正交分解，是方差分析所有公式的几何基础——第九章回归的平方和分解也是它的亲戚。</span>

## 3 均方与 F 检验

把平方和除以各自的**自由度**，得到**均方（mean square）**：

- 组间均方：$MS_A = \dfrac{S_A}{m - 1}$（自由度 $m-1$）；
- 组内均方：$MS_E = \dfrac{S_E}{n - m}$（自由度 $n - m$，$n = \sum n_i$）。

$H_0$ 真时，$MS_A$ 与 $MS_E$ 都是 $\sigma^2$ 的无偏估计，比值接近 1。检验统计量：

$$F = \frac{MS_A}{MS_E} \sim F(m - 1,\ n - m) \quad (\text{当 } H_0 \text{ 真})$$

**拒绝域**：$F \ge F_\alpha(m-1, n-m)$——组间均方显著大于组内均方，说明组间差异不只是随机波动。<span class="marginnote">「$F = MS_A/MS_E$」的分量意义：分子 $MS_A$ 是「效应 + 误差」的混合均方，分母 $MS_E$ 是「纯误差」均方。$H_0$ 真时两者都只含误差，比值 ≈ 1；$H_0$ 假时分子额外含效应，比值 > 1。所以「F 越大越拒绝」——组间波动相对组内越占优，越说明组均值不同。这个「信号/噪声」结构贯穿 ANOVA 与回归。</span>

## 4 公式解析：组间组内的「信号 vs 噪声」

F 统计量是「组间信号 ÷ 组内噪声」，拆开它的构造：

$$

F = \frac{MS_A}{MS_E} = \frac{\dfrac{1}{m-1}\sum_i n_i(\bar X_{i\cdot} - \bar X_{\cdot\cdot})^2}{\dfrac{1}{n-m}\sum_{i,j}(X_{ij} - \bar X_{i\cdot})^2}

$$

- **第一步，分子 = 效应信号**：$S_A$ 度量「组均值之间差多远」，除以自由度 $m-1$ 得均方。$H_0$ 假时这里塞满了组间差异。
- **第二步，分母 = 误差噪声**：$S_E$ 度量「组内观测多散」，除以自由度 $n-m$ 得均方。它只含随机误差，是「噪声基准」。
- **第三步，比值判读**：$F$ 大说明信号压过噪声——组间差异不只是偶然；与 $F(m-1, n-m)$ 的临界值比较定拒绝。

「信号 / 噪声」是方差分析（乃至全部检验统计量）的统一心智模型：分子是「你想找的效应」，分母是「你不想要的波动」，比值超过临界值就说明效应真实存在。

## 5 单因素方差分析的深入应用

ANOVA 的思想、假设与后续分析构成完整体系，三个关键点值得展开。

### 例：完整计算的流程

**例**：三组数据，$n_1 = n_2 = n_3 = 5$。算得 $S_A = 30$、$S_E = 24$。$MS_A = 30/2 = 15$，$MS_E = 24/12 = 2$，$F = 7.5$。$F_{0.05}(2, 12) = 3.89$，$7.5 > 3.89$ → 拒绝「各组均值相等」。

### ANOVA 的三假设与检查

| 假设 | 含义 | 检查工具 |
| --- | --- | --- |
| 独立性 | 观测互不影响 | 实验设计 |
| 方差齐性 | 各组方差相等 | F 检验/Levene |
| 正态性 | 误差正态 | 偏度峰度/拟合优度 |

**三假设缺一不可**——第八章的检验工具正是为检查它们准备的。

### 例：两两比较（多重比较）

ANOVA 拒绝「全相等」后，还需知道「哪两组不同」。两两 t 检验会犯**多重比较错误**（比较 $m$ 次，至少一次误判概率 $1-(1-\alpha)^m$）：

| 方法 | 校正 |
| --- | --- |
| Bonferroni | 阈值 $\alpha/m$ |
| Tukey HSD | 分布校正 |
| LSD | 不校正（仅计划比较） |

**「ANOVA 拒绝 → 多重比较找差异」**是完整流程——多重比较的校正不可省略。

### 效应量与组内相关

$R^2 = S_A/S_T$ 度量「因素解释的波动比例」，$\eta^2$ 是其 ANOVA 版。**「显著 ≠ 效应大」**——$n$ 大时微小差异也显著，报告时要附 $\eta^2$ 或置信区间。

**易错点｜辨析：** ① 方差分析比较的是「均值」——名字里的「方差」指手段（分解方差）；② F 大才拒绝——组间波动相对组内足够大才说明有差异；③ 不拒绝「全相等」≠ 「各组都相同」——样本量小可能检测力不足。

再补一张「t 检验 vs ANOVA」对照：

| | 两样本 t | 单因素 ANOVA |
| --- | --- | --- |
| 组数 | 2 | $\ge 2$ |
| 统计量 | $t$ | $F$ |
| 关系 | $t^2 = F$（两组时） | 多组推广 |
| 多重比较 | 无 | 需要校正 |

「ANOVA 是两样本 t 的多组推广」——两组时 $t^2 = F$，多组时 ANOVA 一票裁决。

## 6 小结

- **单因素 ANOVA**：比较 $m \ge 3$ 组均值是否全相等，模型 $X_{ij} = \mu + \alpha_i + \varepsilon_{ij}$，$H_0$: 全部 $\alpha_i = 0$。
- **平方和分解** $S_T = S_A + S_E$：总波动 = 组间（效应）+ 组内（误差）。
- **F 检验** $F = MS_A/MS_E \sim F(m-1, n-m)$，拒绝域 $F \ge F_\alpha$。
- 三假设：独立、方差齐性、正态——检验前需用第八章工具检查。
- 方差分析解决「多组均值比较」的多重比较之困，一个 F 检验全盘裁决。
