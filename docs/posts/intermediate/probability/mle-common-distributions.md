## 为什么从常见分布的最大似然估计开始

上一节我们建立了 MLE 的通用流程，本节把它落到具体分布上，练成「条件反射」：二项、泊松、正态、指数、均匀——这些最常用分布的 MLE 分别是什么，为什么长那样。这张「MLE 速查表」是第七章后半区间估计、第八章假设检验里反复引用的基础，也是你以后读文献、跑统计软件时判断「软件在估什么」的底层知识。

更重要的是，逐个分布练 MLE，你会看清一条规律：**MLE 几乎总是「用样本均值去匹配某个参数」**——因为似然方程的本质就是「让观测与参数对齐」。看完本节，MLE 不再是神秘黑箱，而是一套可以随时「手推」的工具。<span class="marginnote">常见分布的 MLE 大多有闭式解（显式公式），因为它们的分布族属于「指数族」——对数似然是参数的线性函数，求导后方程可解。这也解释了为什么这些分布在统计学里如此常用：<strong>有闭式 MLE 的分布才「好估」，好估才被广泛用</strong>。这是分布家族之间的达尔文选择。</span>

## 1 离散分布的 MLE

**二项分布**：$X \sim B(m, p)$（$m$ 已知，$p$ 未知）。$n$ 次试验观测到 $x_1, \ldots, x_n$（每次做 $m$ 次子试验）：

$$L(p) = \prod_i \binom{m}{x_i} p^{x_i}(1-p)^{m-x_i}, \qquad \hat p = \frac{\bar x}{m} = \frac{\sum x_i}{nm}$$

**直觉**：成功的总体比例是 $p$，样本里成功的比例是 $\frac{\sum x_i}{nm}$——让两者对齐，$\hat p$ 就是样本成功比例。<span class="marginnote">「用样本比例估 $p$」是离散分布 MLE 的共同主题：二项估 $p$ 用平均成功率，泊松估 $\lambda$ 用样本均值，几何估 $p$ 用 $1/\bar x$。MLE 在这些情形下几乎等于「矩估计」——因为「让观测与参数对齐」和「让矩相等」殊途同归。</span>

**泊松分布**：$X \sim \pi(\lambda)$。$L(\lambda) = \prod_i \frac{\lambda^{x_i} e^{-\lambda}}{x_i!}$，对数似然 $\ln L = \sum_i (x_i \ln\lambda - \lambda - \ln x_i!)$。求导令零：

$$\frac{d}{d\lambda}\ln L = \frac{\sum x_i}{\lambda} - n = 0 \implies \hat\lambda = \bar x$$

**泊松的 MLE 就是样本均值**——与「$\lambda$ 既是均值又是方差」的指纹完全吻合。

## 2 连续分布的 MLE：正态与指数

**正态分布**（$\mu, \sigma^2$ 均未知，上节已推）：

$$\hat\mu = \bar x, \qquad \hat\sigma^2 = \frac{1}{n}\sum_{i=1}^n (x_i - \bar x)^2$$

**指数分布**：$X \sim E(\lambda)$，$\hat\lambda = 1/\bar x$（上节已推）。

**均匀分布**：$X \sim U(0, \theta)$（$\theta$ 未知）。似然：

$$L(\theta) = \begin{cases} \dfrac{1}{\theta^n}, & 0 \le x_i \le \theta \ \forall i \\[4pt] 0, & \text{否则} \end{cases}$$

**注意：这里不能直接求导！** 对 $\theta$ 求导 $\frac{d}{d\theta}\theta^{-n} = -n\theta^{-n-1} < 0$ 恒为负——$L$ 随 $\theta$ 单调递减，但 $\theta$ 不能小于样本最大值（否则有的 $x_i > \theta$，$L = 0$）。因此：

$$\hat\theta = \max(x_1, \ldots, x_n) = x_{(n)}$$

**均匀分布的 MLE 是样本最大值**——因为 $\theta$ 必须「罩住」所有观测，最小能罩住的就是最大值。<span class="marginnote">均匀分布的 MLE 是 MLE 家族里最「反直觉」的一个：它不在「导数等于 0」处取到，而在「支撑边界」处取到——因为参数控制了支撑（$x$ 的取值范围），似然在支撑边界处跳变。这提醒我们：<strong>MLE 求导解方程不是万能流程，参数影响支撑时要在边界上找</strong>。</span>

## 3 MLE 汇总表

| 分布 | 未知参数 | 最大似然估计 |
| --- | --- | --- |
| 二项 $B(m, p)$ | $p$ | $\hat p = \dfrac{\bar x}{m}$ |
| 泊松 $\pi(\lambda)$ | $\lambda$ | $\hat\lambda = \bar x$ |
| 正态 $N(\mu, \sigma^2)$ | $\mu, \sigma^2$ | $\hat\mu = \bar x$，$\hat\sigma^2 = \frac1n\sum(x_i-\bar x)^2$ |
| 指数 $E(\lambda)$ | $\lambda$ | $\hat\lambda = 1/\bar x$ |
| 均匀 $U(0, \theta)$ | $\theta$ | $\hat\theta = x_{(n)}$ |

**规律观察**：前四个分布（二项、泊松、正态、指数）的 MLE 都是「样本均值」的函数——因为它们的参数恰是均值或其单调函数；均匀分布的参数是支撑端点，MLE 变为样本极值。<span class="marginnote">「参数 = 均值的函数」与「参数 = 支撑端点」是 MLE 的两大类型：前者求导可解（指数族），后者在边界取到（非指数族）。考试里先判断参数性质再决定走哪条路，可以省掉大量弯路。这条「指数族 vs 非指数族」的分野，也是现代统计里「充分统计量」理论的开端。</span>

**易错点｜辨析：** ① 均匀分布不能直接求导——先判断参数是否约束支撑；② 二项分布的 $m$（子试验数）与 $n$（观测次数）别混：似然里是 $n$ 个观测、每个含 $m$ 次子试验；③ 泊松 $x_i!$ 项不含 $\lambda$，求导时可忽略，但写似然时别漏。

## 4 公式解析：均匀分布的边界极值

均匀分布 MLE 的「非求导」解法值得细看，它是 MLE 流程的重要例外：

$$

L(\theta) = \frac{1}{\theta^n}\,\mathbf{1}\{\theta \ge x_{(n)}\}, \qquad \hat\theta = x_{(n)}

$$

- **第一步，写支撑条件**：$x_i \le \theta$ 对一切 $i$ 成立，等价于 $\theta \ge x_{(n)} = \max x_i$。用指示函数写进似然。
- **第二步，看单调性**：$\theta > x_{(n)}$ 时 $L(\theta) = \theta^{-n}$ 严格递减——$\theta$ 越大似然越小。
- **第三步，取边界**：$L$ 在 $\theta = x_{(n)}$ 处最大（$\theta$ 再小就跳出支撑、$L$ 归零）。故 $\hat\theta = x_{(n)}$。

「在支撑边界取最大」与「求导等于 0」是完全不同的机制。识别「参数进入支撑」的标志：密度/分布律的支撑含 $\theta$——遇到这种，直接想边界，别求导。

## 5 常见分布 MLE 的深入应用

「每个分布的 MLE 长什么样」是一张速查表，但背后的规律与边界更值得展开。

### 例：MLE 速查表

| 分布 | 参数 | MLE |
| --- | --- | --- |
| 二项 | $p$ | $\bar x/m$ |
| 泊松 | $\lambda$ | $\bar x$ |
| 正态 | $\mu, \sigma^2$ | $\bar x$、$\frac1n\sum(x_i-\bar x)^2$ |
| 指数 | $\lambda$ | $1/\bar x$ |
| 均匀 | $\theta$ | $x_{(n)}$ |

**「前四个都是样本均值的函数、均匀是样本最大值」**——MLE 的两大类型。

### 两大类型的判据

| 类型 | 参数位置 | MLE 方式 |
| --- | --- | --- |
| 指数族 | 均值或其函数 | 求导解方程 |
| 非指数族 | 支撑边界 | 边界取极值 |

**「参数进支撑 → 求导失效，改边界」**——均匀分布是经典警示。

### 例：均匀分布的 MLE

**例**：$U(0,\theta)$，$L(\theta) = 1/\theta^n$（当 $\theta \ge x_{(n)}$）。$L$ 随 $\theta$ 递减，但 $\theta$ 不能小于 $x_{(n)}$——$\hat\theta = x_{(n)}$。**「最小罩住所有观测的 $\theta$」**是支撑型 MLE 的直觉。

### 例：MLE 与矩估计的对比

| | MLE | 矩估计 |
| --- | --- | --- |
| 原理 | 最大化似然 | 令矩相等 |
| 效率 | 渐近有效 | 一般 |
| 均匀 | $x_{(n)}$ | $2\bar x$ |

**「MLE 更优但可能无闭式解」**——两者各有取舍。

**易错点｜辨析：** ① 二项的 $m$（子试验）与 $n$（观测）别混；② 均匀不能直接求导；③ MLE 不保证无偏——$\hat\sigma^2$ 用 $n$ 版（有偏）。

## 6 小结

- **离散 MLE**：二项 $\hat p = \bar x/m$，泊松 $\hat\lambda = \bar x$——「样本均值对齐参数」。
- **连续 MLE**：正态 $\hat\mu = \bar x$、$\hat\sigma^2 = \frac1n\sum(x_i-\bar x)^2$；指数 $\hat\lambda = 1/\bar x$。
- **均匀 $U(0,\theta)$ 的 MLE = 样本最大值 $x_{(n)}$**——参数约束支撑时在边界取极值，不能求导。
- MLE 两大类型：参数 = 均值函数（求导可解）vs 参数 = 支撑端点（边界取值）。
- 常见分布 MLE 多为闭式解，因为它们是「好估的指数族」。
