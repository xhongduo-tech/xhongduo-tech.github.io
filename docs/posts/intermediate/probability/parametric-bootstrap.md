# 参数 bootstrap 方法

## 为什么从参数 bootstrap 开始

前几节的非参数 bootstrap 完全依赖「从样本再抽样」——它不假设任何分布形状。但有时我们**知道总体属于某个分布族**（如正态、泊松、指数），只是参数未知。此时可以用**参数 bootstrap（parametric bootstrap）**：先从样本估出参数 $\hat\theta$，再从「参数为 $\hat\theta$ 的已知分布」里反复抽样——用「已知分布的模拟」代替「未知分布的再抽样」。

参数 bootstrap 与非参数版的区别是「抽样的来源」：前者从**拟合好的参数分布**抽，后者从**经验分布**抽。参数版在模型正确时更高效（模拟的分布更光滑），但模型错了就会误导——「用错误的分布模拟，模拟得再精确也错」。<span class="marginnote">参数 bootstrap 的核心流程一句话：<strong>①用样本估计参数 $\hat\theta$；②从 $F(\cdot;\hat\theta)$ 反复抽样生成 bootstrap 样本；③每个样本算统计量，得复制分布</strong>。它与非参数版唯一的不同是第 ② 步——抽样的「母体」从经验分布 $F_n$ 换成了参数分布 $F(\cdot;\hat\theta)$。</span>

## 1 参数 bootstrap 的流程

设总体分布 $F(x; \theta)$ 已知族、参数 $\theta$ 未知，样本 $x_1, \ldots, x_n$：

1. **估计参数**：用最大似然（或矩估计）得 $\hat\theta$；
2. **参数抽样**：从 $F(\cdot; \hat\theta)$ 独立抽 $n$ 个，得参数 bootstrap 样本 $x_1^*, \ldots, x_n^*$；
3. **算统计量**：$\hat\theta^* = T(x_1^*, \ldots, x_n^*)$；
4. **重复 $B$ 次**：得 $B$ 个复制，用于标准误、区间、偏差估计。

**例（正态）**：总体假设 $N(\mu, \sigma^2)$，样本估计 $\hat\mu = \bar x$、$\hat\sigma^2 = s^2$。参数 bootstrap：从 $N(\bar x, s^2)$ 反复抽 $n$ 个，各算样本中位数，得中位数分布——比非参数版更光滑（从光滑分布抽样，复制里没有重复值）。<span class="marginnote">参数 bootstrap 相对非参数版的优势：抽样母体是光滑的已知分布，复制分布更稳定、更少「离散跳动」；在模型正确时，标准误估计更高效（收敛更快）。代价是模型风险——若假设的正态是错的，参数 bootstrap 从「错误的分布」抽样，结论系统性偏离。选择的关键：<strong>对分布族有信心，用参数版；没信心，用非参数版</strong>。</span>

## 2 参数 vs 非参数 bootstrap

| | 参数 bootstrap | 非参数 bootstrap |
| --- | --- | --- |
| 抽样母体 | 拟合的参数分布 $F(\cdot;\hat\theta)$ | 经验分布 $F_n$ |
| 分布假设 | 需要（知道分布族） | 不需要 |
| 样本重复 | 无重复（从光滑分布抽） | 有重复（放回原样本） |
| 模型正确时 | 更高效、更光滑 | 稍低效 |
| 模型错误时 | 系统性偏离 | 仍基本可靠 |

**易错点｜辨析：** 参数 bootstrap 的「参数」指「假设了分布族」，但参数仍是估计出来的（$\hat\theta$ 含不确定性）——**参数 bootstrap 没有「免费午餐」**：它把「分布形状的不确定」排除在外，只模拟「给定形状下的参数不确定」。若分布形状本身就错，区间会过分自信（太窄）。<span class="marginnote">「参数 bootstrap 的区间可能太窄」是它最大的陷阱：它假设「总体是某个已知族」，等于替统计量「作弊」——排除了「族选错」的不确定性。实务上常做「双保险」：先做正态性检验（第八章偏度峰度/拟合优度），确认族假设合理后再用参数 bootstrap。这也是「参数方法要用假设检验护航」的又一例。</span>

## 3 参数 bootstrap 的应用

**小样本下的参数区间**：正态总体小样本时，某些复杂统计量（如变异系数 $CV = \sigma/\mu$）的解析区间难求，参数 bootstrap 从 $N(\bar x, s^2)$ 抽复制直接给区间；
**回归模型**：从拟合回归模型里按参数误差结构抽样，评估预测区间；
**混合模型/复杂统计量**：解析推断无能为力时，参数 bootstrap 是标准替代。

**例（变异系数）**：正态数据 $n = 15$，$\bar x = 100$，$s = 20$，样本变异系数 $\widehat{CV} = 0.2$。参数 bootstrap：从 $N(100, 400)$ 抽 15 个，算 $CV$，重复 2000 次，取分位数得 $CV$ 的 95% 区间——解析公式极其复杂，bootstrap 直接给出。<span class="marginnote">变异系数的例子说明参数 bootstrap 的「甜点区」：解析推断难、但有合理的分布假设。这类「无公式可依、有模型可循」的统计量，正是参数 bootstrap 的舞台。第七、八章的解析方法覆盖不到的角落，参数 bootstrap 是补位者。</span>

## 4 公式解析：参数 bootstrap 的抽样

参数 bootstrap 的抽样动作是「从拟合分布抽样」，以正态为例：

$$

x_i^* \sim N(\bar x, s^2), \qquad i = 1, \ldots, n

$$

- **第一步，估计参数**：$\hat\mu = \bar x$、$\hat\sigma^2 = s^2$——把未知参数替换成样本估计（第七章点估计）。
- **第二步，按拟合分布抽样**：$n$ 个独立样本从 $N(\bar x, s^2)$ 抽取——这是「参数化后的总体」的模拟样本。
- **第三步，统计量计算**：对每个 bootstrap 样本算 $\hat\theta^*$——之后的标准误、区间、偏差与非参数版完全一样。

「把总体分布的参数换成估计值，再从估计分布抽样」是参数 bootstrap 的全部。它把「从未知总体抽样」替换成「从拟合分布抽样」——模型假设给了模拟的「母体形状」。

## 5 参数 bootstrap 的深入比较与实例

参数与非参数 bootstrap 的选择不只是「想不想假设分布」——它牵涉效率、稳健性与模型风险的权衡，值得用对比与实例讲透。

### 参数 vs 非参数：完整对照

| 维度 | 参数 bootstrap | 非参数 bootstrap |
| --- | --- | --- |
| 抽样母体 | 拟合的参数分布 | 经验分布 |
| 分布假设 | 需要（知道族） | 不需要 |
| 复制中的重复值 | 无（光滑分布抽样） | 有（放回原样本） |
| 模型正确时效率 | 更高 | 略低 |
| 模型错误时 | 系统性偏离 | 基本稳健 |
| 计算 | 需先估参数 | 直接重采样 |

**选型口诀**：对分布族有信心 → 参数版（更高效）；没信心 → 非参数版（更稳健）。「先做分布检验再决定」是规范流程。

### 例：变异系数的参数 bootstrap

正态数据 $n = 15$，$\bar x = 100$、$s = 20$，样本变异系数 $\widehat{CV} = 0.2$。参数 bootstrap：从 $N(100, 400)$ 反复抽 15 个，算 $CV$，$B = 2000$ 次得复制分布，取 2.5% 与 97.5% 分位得 95% 区间。解析公式极其复杂，参数 bootstrap 十行代码给出——「有模型、无公式」场景的标准补位。

### 模型风险：参数 bootstrap 的软肋

参数 bootstrap 的最大隐患是**模型错配**：若假设正态而真实分布重尾，参数 bootstrap 从「错误的正态」抽样，区间系统性过窄（过度自信）。缓解办法：

1. 先用第八章正态性检验（偏度峰度/拟合优度）验证族假设；
2. 对参数区间做「覆盖模拟」——反复抽样验证覆盖比例是否 ≈ 名义水平；
3. 拿不准时退回到非参数 bootstrap。

### 例：回归模型的参数 bootstrap

拟合 $y = \hat a + \hat b x$ 后，从残差分布（参数版假设正态残差）重新抽样 $y^* = \hat a + \hat b x + \varepsilon^*$，重拟合得系数复制——这是「评估回归预测区间」的标准做法，也是 bootstrap 在回归里的典型应用。

还有一个「半参数」折中方案值得一提：**残差 bootstrap**——先从拟合模型算残差 $e_i$，再从残差（经验分布）有放回抽样生成 $y^* = \hat y_i + e_i^*$。它保留了参数模型的结构（预测值 $\hat y_i$），又用非参数方式引入误差（从残差抽样，不假设正态）。在「模型结构可信、误差分布未知」时，残差 bootstrap 是参数版与非参数版之间最实用的中间地带——理解这个「参数结构 + 非参数误差」的混合思路，你就能灵活应对大多数实战场景。

最后补一张「三种 bootstrap」的选型总表：

| 方法 | 抽样母体 | 分布假设 | 适用场景 |
| --- | --- | --- | --- |
| 非参数 bootstrap | 经验分布 | 无 | 分布未知、稳健优先 |
| 参数 bootstrap | 拟合的参数分布 | 需要（知道族） | 模型可信、追求效率 |
| 残差 bootstrap | 模型残差 | 误差分布未知 | 回归/结构模型 |

「没把握用非参数、有把握用参数、结构可信误差未知用残差」——三种方法各有所长，选对是关键。

## 6 小结

- **参数 bootstrap**：从拟合的参数分布 $F(\cdot;\hat\theta)$ 抽样，而非从经验分布——多一步「先估参数」。
- 流程：估参数 → 按拟合分布抽样 → 算统计量 → 重复 $B$ 次。
- 模型正确时更高效、更光滑；模型错误时系统性偏离（区间可能过窄）。
- 参数 vs 非参数：知道分布族用参数版，没信心用非参数版。
- 参数 bootstrap 是「解析推断难 + 有合理模型」场景的标准补位工具。
