## 为什么从二维离散型随机变量开始

上一节我们建立了二维分布函数的框架，但分布函数太「重」——一个二元函数，看着不直观。当两个分量都是离散型时，概率的全部信息可以被压缩成**一张双行的表格**：行对应 $X$ 的取值，列对应 $Y$ 的取值，格子里是联合概率。这就是**联合分布律**，二维离散世界最直观的概率账本。

二维离散型是理解「联合」概念的最佳入口：它把「联合分布包含边缘分布」「如何求条件分布」「独立性意味着表格中的什么」全部变成了表格上的加减乘除，不需要积分。<span class="marginnote">二维离散型的联合分布律是所有二维分布的「教学原型」：一旦你在表格上理解了求和、条件化、独立性，连续型只是把「求和」换成「积分」，思想完全相同。所以这一节值得慢下来，把表格玩熟。</span>

## 1 联合分布律：一张双行表格

**二维离散型随机变量**：设 $(X, Y)$ 的所有可能取值是有限个或可列无穷个点 $(x_i, y_j)$，称

$$P\{X = x_i,\ Y = y_j\} = p_{ij}, \qquad i, j = 1, 2, \ldots$$

为 $(X,Y)$ 的**联合分布律（joint probability distribution）**。它通常写成表格，行列交界处是 $p_{ij}$：

| $X \backslash Y$ | $y_1$ | $y_2$ | $\cdots$ | $y_j$ | $\cdots$ | $P\{X=x_i\}$ |
| --- | --- | --- | --- | --- | --- | --- |
| $x_1$ | $p_{11}$ | $p_{12}$ | $\cdots$ | $p_{1j}$ | $\cdots$ | $p_{1\cdot}$ |
| $x_2$ | $p_{21}$ | $p_{22}$ | $\cdots$ | $p_{2j}$ | $\cdots$ | $p_{2\cdot}$ |
| $\vdots$ | $\vdots$ | $\vdots$ | | $\vdots$ | | $\vdots$ |
| $x_i$ | $p_{i1}$ | $p_{i2}$ | $\cdots$ | $p_{ij}$ | $\cdots$ | $p_{i\cdot}$ |
| $P\{Y=y_j\}$ | $p_{\cdot 1}$ | $p_{\cdot 2}$ | $\cdots$ | $p_{\cdot j}$ | $\cdots$ | 1 |

联合分布律同样满足两条判据：**非负性** $p_{ij} \ge 0$ 与**归一性** $\sum_i \sum_j p_{ij} = 1$。<span class="marginnote">表格右下角的 1 是全局归一：所有格子概率之和等于 1。这张表在后续计算里价值极高——边缘分布是行和/列和，条件分布是「某行除以行和」或「某列除以列和」，独立性是「每格等于行和乘列和」。一张表，三个问题的答案都在里面。</span>

**例**：掷两枚骰子，令 $X$ 为第一枚点数，$Y$ 为两枚点数之和。联合分布律的 $p_{ij}$ 仅在 $j \ge i + 1$ 且 $j \le i + 6$ 时非零，$p_{ij} = 1/36$。

## 2 边缘分布律：行和与列和

从联合分布律求 $X$ 或 $Y$ 各自的分布律，只需在表格上**求和**：

$$P\{X = x_i\} = \sum_j p_{ij} = p_{i\cdot}, \qquad P\{Y = y_j\} = \sum_i p_{ij} = p_{\cdot j}$$

行和 $p_{i\cdot}$ 是 $X$ 的边缘分布律，列和 $p_{\cdot j}$ 是 $Y$ 的边缘分布律——它们就写在表格最右一列和最下一行。**边缘（marginal）这个名字的由来**：把联合表的行和或列和写在页边，就是边缘分布。<span class="marginnote">术语「边缘分布」直译自英文 marginal distribution，来源于「写在表格边缘的和」。这个历史细节提醒我们：边缘分布就是从联合分布里「抹掉」一个变量的信息——把所有 $Y$ 的可能性都并进来，只剩 $X$。抹掉的过程就是求和。</span>

**易错点｜辨析：** 行和 $\sum_j p_{ij}$ 是对所有 $j$ 求和，别只加到表格最后一列——最后一列本身就是行和，直接读即可，不需要重算。同理列和读最底行。真正要小心的是：**若题目只给部分格子（条件分布场景），行和必须对已知的完整 $j$ 求和**，缺格子会导致边缘分布归一性失败，可用 $\sum_i p_{i\cdot} = 1$ 自检。

## 3 条件分布律：行除以行和

给定 $Y = y_j$ 时，$X$ 的条件分布律是「固定第 $j$ 列，把列内概率归一化」：

$$P\{X = x_i \mid Y = y_j\} = \frac{P\{X = x_i, Y = y_j\}}{P\{Y = y_j\}} = \frac{p_{ij}}{p_{\cdot j}}, \qquad p_{\cdot j} > 0$$

这就是条件概率公式 $P(A \mid B) = P(AB)/P(B)$ 在二维表格上的化身：分子是格子概率，分母是列和。同理 $P\{Y = y_j \mid X = x_i\} = p_{ij}/p_{i\cdot}$。

**例**：设联合分布律中某列 $j$ 的行和 $p_{\cdot j} = 0.4$，格子 $p_{1j} = 0.1$，则在 $Y = y_j$ 条件下 $X = x_1$ 的概率是 $0.1/0.4 = 0.25$。<span class="marginnote">条件分布把「二维信息」折叠成「一维视角」：固定一个变量看另一个变量，就是沿表格的行或列切片再归一化。这种「切片视角」在统计推断里处处可见——第八章假设检验里给定检验统计量下的抽样分布，本质上就是条件分布。</span>

## 4 公式解析：表格上的全概率公式

联合分布律里藏着全概率公式的离散版。设 $B_1, B_2, \ldots$ 是一组互斥完备事件，则由 $P\{X = x_i\} = \sum_j p_{ij}$ 与条件分布律的定义：

$$

P\{X = x_i\} = \sum_j P\{X = x_i \mid Y = y_j\} \, P\{Y = y_j\}

$$

- **第一步，把行和拆成条件与边缘的乘积**：$p_{ij} = P\{X=x_i \mid Y=y_j\} \cdot P\{Y=y_j\}$，这是条件概率公式的反写。
- **第二步，对 $j$ 求和**：$\sum_j p_{ij}$ 本就是 $X$ 的边缘分布律，因此全概率公式自动成立。
- **第三步，物理解读**：$X = x_i$ 可能发生在各种 $Y$ 的取值下，把「各 $Y$ 条件下的概率」按「$Y$ 取该值的概率」加权求和，就是 $X = x_i$ 的总概率。

这张「先条件化、再按 $Y$ 分布加权」的配方，是第一章全概率公式在二维表格上的重述，也是贝叶斯公式（下一节条件分布里会出现它的表格版）的垫脚石。

## 5 二维离散分布的深入应用与实例

联合分布律表格是二维离散的全部，它的计算、独立性判定与实例值得展开。

### 例：从联合表读信息

**例**：联合分布律表，行和 $p_{i\cdot}$、列和 $p_{\cdot j}$ 是边缘分布律——**「行和列和写在页边，就是边缘」**，条件分布是「列内归一」（$p_{ij}/p_{\cdot j}$）。

### 例：独立性的表格判据

| 判据 | 内容 |
| --- | --- |
| 联合 = 边缘之积 | $p_{ij} = p_{i\cdot}p_{\cdot j}$ 对一切 $i,j$ |
| 条件 = 边缘 | $P\{X=x_i \mid Y=y_j\} = p_{i\cdot}$ |

**「每格 = 行和 × 列和」**是离散独立性的表格判据——验证恒等式，不是看几个格子。

### 例：表格计算

**例**：联合表 $p_{11} = 0.1$、$p_{12} = 0.2$、$p_{21} = 0.3$、$p_{22} = 0.4$。$P\{X=1\} = 0.3$、$P\{Y=1\} = 0.4$——但 $0.1 \ne 0.3 \times 0.4$，不独立。

### 应用：分类数据的结构

二维离散分布是列联表（吸烟 × 患病）的概率基础——**「联合分布律表格 → 列联表」**，第八章独立性检验的对象就是它。

### 例：条件分布的全概率

$P\{X = x_i\} = \sum_j P\{X=x_i \mid Y=y_j\} P\{Y=y_j\}$——**「全概率公式的表格版」**，条件化再按 $Y$ 分布加权。

**易错点｜辨析：** ① 表格右下角必须是 1（归一自检）；② 条件分布的分子是格子概率、分母是行/列和——别写反；③ 边缘分布的「求和范围」要完整——缺格子会破坏归一。

再补一张「二维离散 vs 二维连续」对照：

| | 离散 | 连续 |
| --- | --- | --- |
| 联合 | $p_{ij}$ 表格 | $f(x,y)$ 密度 |
| 边缘 | 行和/列和 | 积分 |
| 条件 | 列内归一 | 密度比 |
| 独立性 | $p_{ij}=p_{i\cdot}p_{\cdot j}$ | $f=f_X f_Y$ |

「离散求和、连续积分」——二维的两种版本结构完全同构。

## 6 小结

- **联合分布律** $p_{ij} = P\{X = x_i, Y = y_j\}$ 用双行表格表示，满足非负性与归一性。
- **边缘分布律**是行和 $p_{i\cdot} = \sum_j p_{ij}$ 与列和 $p_{\cdot j} = \sum_i p_{ij}$。
- **条件分布律** $P\{X=x_i \mid Y=y_j\} = p_{ij}/p_{\cdot j}$，是「固定列、列内归一化」。
- 表格右下角为 1，可作为一切计算的全局自检。
- 联合表同时携带边缘信息与关联信息——求和抹掉一个变量即得边缘。

在下一节，我们把同样的「联合/边缘/条件」三元组搬到连续世界，主角变成**二维连续型随机变量与联合概率密度**。
