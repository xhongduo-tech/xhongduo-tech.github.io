## 为什么从非参数 bootstrap 开始

前九章的统计推断（标准误、置信区间、检验）几乎都依赖「解析公式」——正态的 z、未知方差的 t、方差的 χ²。可一旦统计量复杂（中位数、相关系数、比值、自编指标），或者分布未知，解析公式就求不出来。**bootstrap（自助法）**是埃夫隆 1979 年提出的通用替代：**用计算机从样本里反复「有放回地再抽样」，模拟「从总体里反复抽样」，从而直接估计统计量的分布**。它把「解析推导」换成「暴力模拟」。

bootstrap 是统计学与计算结合的分水岭：它让「任何统计量的分布」都能在不需要解析公式的情况下得到，是数据科学、机器学习时代最常用的推断工具之一。它的思想基础是第六章的格利文科定理——**样本的经验分布足够像总体分布，所以从样本再抽样 ≈ 从总体抽样**。<span class="marginnote">bootstrap 的核心哲学一句话：<strong>「样本是从总体里抽的，经验分布 $F_n$ 近似总体分布 $F$（格利文科定理），所以在 $F_n$ 里再抽样 ≈ 在 $F$ 里抽样」</strong>。它用「一次抽样得到的样本」替代「未知的总体」，再用计算机穷举「如果重新抽样会发生什么」——把推断问题转成模拟问题。</span>

## 1 再抽样：从样本里抽样本

**非参数 bootstrap 的基本步骤**：

1. **原始样本**：$x_1, \ldots, x_n$ 来自未知总体 $F$，要估计统计量 $\hat\theta = T(x_1, \ldots, x_n)$（如中位数、相关系数）的分布；
2. **bootstrap 样本**：从 $x_1, \ldots, x_n$ 中**有放回**地抽 $n$ 个，得到 bootstrap 样本 $x_1^*, \ldots, x_n^*$（会有重复）；
3. **bootstrap 复制**：计算 $\hat\theta^* = T(x_1^*, \ldots, x_n^*)$；
4. **重复 $B$ 次**：得到 $B$ 个 $\hat\theta^{*1}, \ldots, \hat\theta^{*B}$，它们的分布近似 $\hat\theta$ 的抽样分布。

**例**：估计中位数的标准误。原始样本 100 个观测，从中放回抽 100 个（很多重复），算中位数；重复 $B = 1000$ 次，得到 1000 个 bootstrap 中位数，其样本标准差就是中位数标准误的估计。<span class="marginnote">「有放回」是 bootstrap 的生命线：只有放回，同一个观测才能被抽中多次，bootstrap 样本才可能「像」新样本（有随机波动）。不放回抽出的还是原样本本身（只是重排），毫无信息增益。一次有放回抽样中，每个观测约 $1 - (1-1/n)^n \approx 0.632$ 的概率被抽到——「约 63% 出现」是检查再抽样是否正确的直观标记。</span>

## 2 为什么 bootstrap 有效：格利文科的承诺

bootstrap 的有效性建立在「经验分布 ≈ 总体分布」上：

- 第六章**格利文科定理**：$n$ 大时 $F_n$ 在全实数轴上一致逼近 $F$；
- 于是「从 $F_n$ 放回抽样」的机制与「从 $F$ 抽样」几乎一样；
- 统计量 $T$ 是样本的连续函数时，$\hat\theta^*$ 的分布逼近 $\hat\theta$ 的真实分布。

**直观**：样本量越大，$F_n$ 越像 $F$，bootstrap 越准——所以 bootstrap 的精度随 $n$ 提高，是「$n \to \infty$」型的渐近方法。<span class="marginnote">bootstrap 的收敛速度通常是 $O(1/\sqrt n)$ 量级，与 CLT 近似同级，但适用范围远广：CLT 只能近似「和/均值」型统计量，bootstrap 对「任何统计量」（中位数、分位数、相关系数、复杂指标）都适用。它把「解析渐近」换成「数值渐近」，用计算换通用性。</span>

## 3 bootstrap 的三种用法

bootstrap 的基本流程可服务于三类目标：

- **估计标准误**：$se_B(\hat\theta) = \sqrt{\frac{1}{B-1}\sum_{b=1}^B (\hat\theta^{*b} - \bar{\hat\theta}^*)^2}$——bootstrap 复制的样本标准差；
- **估计偏差**：$\widehat{bias} = \bar{\hat\theta}^* - \hat\theta$——bootstrap 均值与原始估计之差；
- **构造置信区间**：用 bootstrap 复制的分位数直接给区间（下一节详讲）。

**例**：估计相关系数 $r$ 的标准误（解析公式复杂）。从样本放回抽 $B = 1000$ 个 bootstrap 样本，各算相关系数，1000 个 $r^*$ 的标准差 ≈ $r$ 的标准误。<span class="marginnote">「bootstrap 估计标准误」的威力在复杂统计量上最明显：相关系数、比值、回归系数非线性函数的解析标准误要么复杂要么不存在，bootstrap 一律用「反复重算」搞定。这也是它在机器学习里受欢迎的原因——模型性能指标（AUC、F1）的波动，都能用 bootstrap 估计。</span>

**易错点｜辨析：** ① bootstrap 样本大小应等于原始样本量 $n$（不是越大越好，也不是越小）；② $B$（复制次数）是「模拟精度」，通常取 1000–10000，$B$ 大只减少模拟误差，不减少统计误差（统计误差由 $n$ 决定）；③ 有放回抽样的比例约 63%——若发现重复极少，说明抽样写错了（可能误用不放回）。

## 4 公式解析：bootstrap 标准误

bootstrap 估计标准误的公式结构，拆开：

$$

se_B(\hat\theta) = \sqrt{\frac{1}{B-1}\sum_{b=1}^{B}\left(\hat\theta^{*b} - \frac{1}{B}\sum_{b'=1}^{B}\hat\theta^{*b'}\right)^2}

$$

- **第一步，生成复制**：$B$ 个 bootstrap 样本各算一个 $\hat\theta^{*b}$——它们是「$\hat\theta$ 的分布的模拟样本」。
- **第二步，求模拟均值**：$\bar{\hat\theta}^* = \frac1B\sum \hat\theta^{*b}$——模拟分布的中心。
- **第三步，算样本标准差**：$\hat\theta^{*b}$ 对模拟均值的偏离平方平均开方——就是 $\hat\theta$ 标准误的 bootstrap 估计。除以 $B-1$ 与样本方差同构。

「把 $B$ 个模拟复制当『样本』，算它们的标准差」是 bootstrap 标准误的全部。分母 $B-1$（不是 $B$）与第六章 $n-1$ 同源——模拟复制也需无偏修正。

## 5 非参数 bootstrap 的深入应用与实例

bootstrap 的「再抽样」看似简单，但每一步都有讲究——样本量、复制次数、统计量选择，处处影响结果。

### 例：完整的标准误估计流程

**例**：估计相关系数 $r$ 的标准误。样本 $n = 30$，$r = 0.62$。放回抽样 $B = 1000$ 个 bootstrap 样本，各算 $r^*$，得 1000 个复制：

$$\widehat{se}_B = \sqrt{\frac{1}{999}\sum_{b=1}^{1000}(r^{*b} - \bar r^*)^2}$$

若 $\widehat{se}_B = 0.12$，则 $r$ 的典型误差约 0.12——相关系数的解析标准误公式复杂，bootstrap 十行代码搞定。

### 样本量与复制次数的分工

| 参数 | 控制什么 | 增大它的效果 |
| --- | --- | --- |
| 样本量 $n$ | 统计误差 | 经验分布更近总体 |
| 复制次数 $B$ | 模拟误差 | 复制分布更稳 |

**$n$ 管「准不准」、$B$ 管「稳不稳」**——bootstrap 不会用 $B$ 弥补 $n$ 的不足，$B$ 大只是让模拟更精确。

### bootstrap 的适用与不适

| 场景 | bootstrap 表现 |
| --- | --- |
| 均值、中位数、分位数 | 好 |
| 相关系数、回归系数 | 好 |
| 最大值、最小值 | 差（复制失真） |
| 极重尾分布 | 差（复制不稳定） |

**「平滑统计量 bootstrap 好、边界统计量 bootstrap 差」**——判断依据是统计量对样本扰动的连续性。

### 例：偏差估计与校正

**例**：估计量 $\hat\theta$，bootstrap 复制的均值 $\bar{\hat\theta}^* = 0.48$，原始估计 $\hat\theta = 0.45$。偏差估计 $\widehat{bias} = 0.48 - 0.45 = 0.03$——估计量平均偏高 0.03。偏差校正估计 $2\hat\theta - \bar{\hat\theta}^* = 0.90 - 0.48 = 0.42$。

**易错点｜辨析：** ① bootstrap 样本大小必须等于 $n$（不是越大越好）；② 有放回抽样约 63% 的原始观测会出现——重复太少说明误用了不放回；③ bootstrap 是渐近方法，$n$ 太小（如 < 20）时结论要谨慎。

再补一张「bootstrap 三步法」速查：

| 步骤 | 动作 | 关键点 |
| --- | --- | --- |
| ① 再抽样 | 从样本放回抽 $n$ 个 | 有放回、$n$ 不变 |
| ② 算统计量 | 对每个 bootstrap 样本算 $\hat\theta^*$ | 统计量任意 |
| ③ 汇总复制 | 标准差/分位数/偏差 | $B$ 次复制构成分布 |

「抽、算、汇总」三步，就是非参数 bootstrap 的全部——任何统计量的不确定性都可由此估计。

## 6 小结

- **非参数 bootstrap**：从原始样本放回抽 $n$ 个，算统计量，重复 $B$ 次——用「从样本抽样」模拟「从总体抽样」。
- 理论基础：**格利文科定理**（$F_n \approx F$），因此 bootstrap 复制 ≈ 统计量的真实抽样分布。
- 三种用法：估标准误、估偏差、构造置信区间；统计量越复杂，bootstrap 越显优势。
- 关键细节：样本大小 = $n$、放回、约 63% 重复、$B$ 通常 1000+。
- bootstrap 用计算换通用性，是数据科学时代最常用的推断工具之一。
