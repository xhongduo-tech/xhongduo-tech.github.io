## 为什么从功率谱密度开始

平稳过程在时间域由相关函数 $R_X(\tau)$ 描述——它说「相隔 $\tau$ 的两个时刻多相关」。可工程师更常问「**信号的能量集中在哪些频率**」：这段噪声是低频为主还是高频为主？滤波器该让哪些频率通过？答案藏在**功率谱密度（power spectral density, PSD）** $S_X(\omega)$ 里——它是相关函数的傅里叶变换，把「时间域的关联」翻译成「频率域的能量分布」。

功率谱密度是信号处理、通信、控制的灵魂概念：滤波器设计、噪声分析、频谱估计、系统辨识全以它为核心。它是第十三章「从时域到频域」的枢纽，也是维纳—辛钦公式（下一节）的主角。<span class="marginnote">「谱」的直觉：<strong>相关函数说「不同时刻怎么联动」，功率谱说「不同频率有多少功率」——二者是同一信息的两个视角（时域 vs 频域），由傅里叶变换连接</strong>。快变的过程（相关衰减快）谱宽（能量铺满高频），慢变的过程（相关衰减慢）谱窄（能量聚在低频）。「白噪声」谱平坦——所有频率等能量，故名「白」（像白光含所有颜色）。</span>

## 1 功率谱密度的定义

设 $\{X(t)\}$ 是宽平稳过程，自相关函数 $R_X(\tau)$ 满足绝对可积条件，则其**功率谱密度（PSD）**定义为相关函数的傅里叶变换：

$$S_X(\omega) = \int_{-\infty}^{+\infty} R_X(\tau)\, e^{-i\omega\tau}\, d\tau$$

**逆变换**（相关函数从谱还原）：

$$R_X(\tau) = \frac{1}{2\pi}\int_{-\infty}^{+\infty} S_X(\omega)\, e^{i\omega\tau}\, d\omega$$

**$S_X(\omega) \ge 0$**（功率谱非负），且是偶函数 $S_X(-\omega) = S_X(\omega)$（因为 $R_X$ 偶对称）。<span class="marginnote">「功率谱密度 = 相关函数的傅里叶变换」是它的定义式，读作「$R_X$ 与 $S_X$ 是傅里叶变换对」。物理含义：$S_X(\omega)d\omega$ 近似是「频率落在 $[\omega, \omega + d\omega]$ 内的那部分功率」——$S_X$ 是功率在频率轴上的「密度」。积分 $\frac1{2\pi}\int S_X d\omega = R_X(0) = E[X^2]$ 即「总功率 = 谱下的总面积」。</span>

## 2 总功率与谱的关系

**总功率公式**：过程的总功率（均方值）等于谱的积分：

$$E[X^2(t)] = R_X(0) = \frac{1}{2\pi}\int_{-\infty}^{+\infty} S_X(\omega)\, d\omega$$

**解读**：谱下的面积 = 总功率。若把 $X(t)$ 看成「电流/电压」，$R_X(0) = E[X^2]$ 就是平均功率（单位电阻上），$S_X(\omega)$ 是功率在各频率上的分配。

**例（白噪声）**：白噪声的相关函数 $R_X(\tau) = N_0 \delta(\tau)$（只在原点有尖峰），谱 $S_X(\omega) = N_0$（常数）——**白噪声的功率谱是平坦的**，所有频率等功率。总功率 $= \frac1{2\pi}\int N_0 d\omega$ 发散——理想白噪声「功率无穷」，现实只有有限带宽的近似白噪声。<span class="marginnote">「白噪声谱平坦」是它名字的由来（白光含所有颜色）。它的相关函数是 $\delta$ 函数——任意两个不同时刻都不相关（$R(\tau) = 0$ 对 $\tau \ne 0$）——「彻底失忆」。现实噪声总有带宽限制（有限谱宽），常建模为「带限白噪声」——在带宽内平坦、带外为零。</span>

## 3 常见信号的谱

| 过程 | 相关函数 $R_X(\tau)$ | 功率谱 $S_X(\omega)$ |
| --- | --- | --- |
| 白噪声 | $N_0\delta(\tau)$ | $N_0$（平坦） |
| 一阶低通输出 | $\sigma^2 e^{-\alpha\|\tau\|}$ | $\dfrac{2\alpha\sigma^2}{\omega^2 + \alpha^2}$（洛伦兹型） |
| 单频正弦 | $\cos(\omega_0\tau)$ | $2\pi\delta(\omega - \omega_0)$（谱线） |

**谱的形状反映相关**：指数衰减相关 → 洛伦兹谱（低频为主）；周期相关 → 谱线（能量集中在 $\omega_0$）；$\delta$ 相关 → 平坦谱。<span class="marginnote">「$e^{-\alpha|\tau|}$ 的傅里叶变换是 $\frac{2\alpha}{\omega^2+\alpha^2}$（洛伦兹型）」是谱分析最常用的变换对：它对应一阶 RC 电路/AR(1) 过程的输出谱——低频高、高频衰减，是「平滑噪声」的经典谱形。背熟几个「时域 ↔ 频域」对（$\delta$↔平坦、指数↔洛伦兹、余弦↔谱线），谱分析就通了。</span>

## 4 公式解析：从相关到谱的变换

功率谱密度定义的「傅里叶变换」是时域到频域的翻译，拆开：

$$

S_X(\omega) = \int_{-\infty}^{+\infty} R_X(\tau)\, e^{-i\omega\tau}\, d\tau

$$

- **第一步，相关函数**：$R_X(\tau)$ 描述「时间差 $\tau$ 的关联」——时域对象。
- **第二步，傅里叶核**：$e^{-i\omega\tau} = \cos(\omega\tau) - i\sin(\omega\tau)$——把「时间差」分解成「各频率的振荡分量」。
- **第三步，积分**：对 $\tau$ 全积分，得到「每个频率 $\omega$ 的权重」$S_X(\omega)$——把时域的关联翻译成频域的能量分布。

「相关函数在 $\tau$ 上做傅里叶变换得谱」是时域↔频域的核心操作。逆变换把「谱积分」还原成「相关」——两个域互为镜像，这正是维纳—辛钦公式（下一节）的实质。

## 5 功率谱密度的深入与实例

功率谱密度不是抽象定义——它有物理测量、工程计算与谱估计的完整链条，逐一展开。

### 谱的物理测量：频谱仪

频谱分析仪直接显示 $S_X(\omega)$：它把信号经过一系列窄带滤波器，测每个频带的功率。**「谱 = 各频率的功率分配」**是频谱仪的物理原理，与「相关函数的傅里叶变换」互为表里——测相关可得谱（维纳—辛钦），直接测谱也成。

### 常见信号的谱计算

| 信号/过程 | 相关函数 | 功率谱 |
| --- | --- | --- |
| 白噪声 | $N_0\delta(\tau)$ | $N_0$（常数） |
| 指数相关 | $\sigma^2 e^{-\alpha\|\tau\|}$ | $\frac{2\alpha\sigma^2}{\omega^2+\alpha^2}$ |
| 余弦 | $\cos(\omega_0\tau)$ | $2\pi\delta(\omega-\omega_0)$ |
| 带限白噪声 | $\mathrm{sinc}$ 型 | 矩形谱 |

**背熟变换对**是谱分析的看家本领——看到相关写谱、看到谱还原相关，全靠这几对。

### 例：正弦信号 + 噪声的谱

**例**：$X(t) = A\cos(\omega_0 t) + N(t)$（$N$ 为白噪声）。谱为 $S_X(\omega) = \frac{\pi A^2}{2}\delta(\omega - \omega_0) + \frac{N_0}{2}$——「一条谱线（信号）+ 平坦底（噪声）」。**在谱上「信号是尖峰、噪声是平底」**，这就是滤波器「选频去噪」的物理依据。

### 例：总功率的验证

**例**：$R_X(\tau) = 4e^{-|\tau|}$，谱 $S_X(\omega) = \frac{8}{\omega^2+1}$。验证总功率：

$$\frac{1}{2\pi}\int_{-\infty}^{\infty}\frac{8}{\omega^2+1}\,d\omega = \frac{1}{2\pi}\cdot 8\pi = 4 = R_X(0)$$

✓——谱下面积恰为均方值，维纳—辛钦公式的两个方向相互印证。

**易错点｜辨析：** ① 功率谱是「密度」（单位频率的功率），不是「功率」本身——积分才得功率；② 对实信号 $S_X$ 是偶函数，负频率的功率折半到正频率（单边谱约定）——不同教材/软件的单双边约定要看清；③ 谱估计（周期图）有方差大、不光滑的毛病，需加窗平滑——「测到的谱要平滑才可信」。

再补一张「功率谱 vs 频谱」的对照：

| | 功率谱 $S_X(\omega)$ | 频谱 $X(\omega)$ |
| --- | --- | --- |
| 对象 | 平稳随机过程 | 确定信号 |
| 定义 | 相关的傅里叶变换 | 信号的傅里叶变换 |
| 相位信息 | 无（模方） | 有 |
| 随机性 | 统计量（集合平均） | 确定量 |

「随机过程用功率谱、确定信号用频谱」——两者名字像、对象不同，别混用。

## 6 小结

- **功率谱密度** $S_X(\omega) = \int R_X(\tau)e^{-i\omega\tau}d\tau$——相关函数的傅里叶变换，频率域的能量分布。
- **总功率** $E[X^2] = R_X(0) = \frac1{2\pi}\int S_X(\omega)d\omega$——谱下的面积。
- 常见对：白噪声 $N_0\delta(\tau) \leftrightarrow N_0$（平坦）；指数相关 $\leftrightarrow$ 洛伦兹谱；正弦 $\leftrightarrow$ 谱线。
- 谱的形状反映相关：衰减快 → 谱宽（近白）；衰减慢 → 谱窄（低频为主）。
- 功率谱是信号处理、通信、控制的枢纽概念，也是维纳—辛钦公式的主角。
