## 为什么从经验分布函数与直方图开始

拿到一份样本后，第一件事永远是「看数据长什么样」。两个最基础的工具：**经验分布函数**——样本的累积分布，一条从 0 爬到 1 的阶梯；**直方图**——样本的密度估计，一排高度随频数变化的柱子。它们都是「总体分布」在样本上的可视化投影，也是「样本代表总体」这个信念最直观的载体。

这两个工具看起来朴素，却是现代统计两大分支的源头：经验分布函数是**非参数统计**与**bootstrap 方法**（第十章）的地基；直方图是**密度估计**（现代机器学习里核密度估计 KDE 的近亲）的原型。<span class="marginnote">直方图是统计可视化的元老：17 世纪英国经济学家格兰特（John Graunt）在《关于死亡公报的观察》里就用类似的表格揭示人群死亡规律——被后人视为统计学的奠基之作。今天 R 的 `hist()`、Excel 的柱状图，都是这个 350 年前的思路的数字化。</span>

## 1 经验分布函数：样本的累积阶梯

设样本 $x_1, \ldots, x_n$，把它们从小到大排成 $x_{(1)} \le x_{(2)} \le \cdots \le x_{(n)}$（次序统计量）。**经验分布函数（empirical distribution function, EDF）**定义为

$$F_n(x) = \frac{1}{n}\sum_{i=1}^n \mathbf{1}_{\{X_i \le x\}} = \begin{cases} 0, & x < x_{(1)} \\ \dfrac{k}{n}, & x_{(k)} \le x < x_{(k+1)} \\ 1, & x \ge x_{(n)} \end{cases}$$

它是「样本中不超过 $x$ 的比例」，一条在每次观测处向上跳 $1/n$ 的阶梯。<span class="marginnote">经验分布函数与理论分布函数 $F(x)$ 的结构完全同构：$F(x) = P\{X \le x\}$ 是「总体中不超过 $x$ 的比例」（概率），$F_n(x)$ 是「样本中不超过 $x$ 的比例」（频率）。「频率逼近概率」在函数层面被精确复制——$F_n$ 逐点逼近 $F$。</span>

**例**：样本为 $\{1, 2, 2, 4\}$（$n = 4$）。则 $F_4(x)$ 在 $x < 1$ 时为 0，$1 \le x < 2$ 时为 1/4，$2 \le x < 4$ 时为 3/4，$x \ge 4$ 时为 1——每个取值点跳 $1/4$。

## 2 格利文科定理：样本代表总体的保证

**格利文科定理（Glivenko–Cantelli theorem）**：设 $F_n(x)$ 是来自分布函数 $F(x)$ 的样本的经验分布函数，则

$$\sup_{-\infty < x < +\infty} \left|F_n(x) - F(x)\right| \xrightarrow{\,a.s.\,} 0$$

即**当 $n$ 足够大时，经验分布函数在全体实数上一致逼近总体分布函数**（几乎必然收敛）。这是「样本代表总体」最强形式的数学表述——不是逐点近似，而是整条曲线的「最大偏差」都趋于 0。<span class="marginnote">「几乎必然一致收敛」是统计里最强的样本保证之一：它说明只要样本量够大，用样本的经验分布去代替总体的理论分布，误差在整条数轴上都趋于零。这正是第十章 bootstrap「把样本当成总体再来抽样」的合法性根源——样本分布够像总体，才能在样本上模拟总体。</span>

**实际意义**：当总体分布未知（非参数问题），可以用 $F_n$ 代替 $F$ 做推断——分位数、均值、概率都能从 $F_n$ 读出。bootstrap 正是「反复从 $F_n$ 抽样」来模拟「从 $F$ 抽样」。

## 3 直方图：样本的密度视角

**直方图（histogram）**：把数据的取值范围分成若干小区间（组），统计落在每组的数据个数（频数），用高度为频数（或频率/组距）的矩形表示。

构造步骤：

1. **分组**：确定组距 $h$ 与组数 $k$，通常组数取 $\sqrt{n}$ 的量级或依数据范围调整；
2. **计数**：统计落在各组的数据个数 $m_j$；
3. **画图**：以矩形高度 $m_j/n$（频率）或 $m_j/(nh)$（频率密度）作图。

**组距的选择是直方图的灵魂**：组距太窄，柱子毛糙（欠平滑）；组距太宽，细节被抹平（过平滑）。这个「偏差—方差权衡」是统计建模的永恒主题。<span class="marginnote">直方图与概率密度的关系：把组距 $h$ 缩小、数据无限增多，直方图的包络会收敛到总体的概率密度曲线——直方图是「密度估计」的非参数原型。现代核密度估计（KDE）把「硬边界」的组距换成「光滑的核函数」，本质是同一个思路的打磨。</span>

**易错点｜辨析：** 直方图不同于条形图：直方图的横轴是**连续数值区间**、相邻柱子无缝；条形图的横轴是**类别**、柱子间留空隙。另外，「频率/组距」作为纵轴（即面积 = 频率）比「频数」更接近密度含义——做密度估计时务必用前者。

## 4 公式解析：频率密度与面积

直方图作为密度估计，纵轴的「频率密度」概念是关键：

$$

\text{频率密度} = \frac{\text{频率}}{\text{组距}} = \frac{m_j / n}{h}, \qquad \sum_j (\text{频率密度} \times h) = 1

$$

- **第一步，频率**：第 $j$ 组的频率 $m_j/n$——数据落在该组的比例。
- **第二步，除以组距**：除以 $h$ 得「每单位长度的频率」——与概率密度 $f(x)$ 同构（密度 = 单位长度的概率）。
- **第三步，面积归一**：每组「频率密度 × 组距 = 频率」，所有组频率之和为 1——**直方图总面积恒为 1，与概率密度归一性完全一致**。

「直方图的面积（而非高度）代表概率」是理解直方图的关键：矩形越高、组距越宽，面积越大，概率越大。这条「面积 = 概率」的约定，让直方图可以直接和理论密度曲线画在同一张图里比较。

## 5 经验分布与直方图的深入应用

两个「看数据」的工具背后有统计推断的深度——收敛、密度估计与选择法则，逐一展开。

### 例：经验分布的分位数

**例**：样本 $\{1, 2, 3, 4, 5, 6\}$，$F_6(3.5) = 3/6 = 0.5$——样本中 ≤ 3.5 的比例。样本中位数 = $F_n$ 的 0.5 分位点 = 3.5。**「经验分布读出样本分位数」**是非参数推断的日常操作。

### 直方图组距的选择：偏差—方差权衡

| 组距 | 效果 |
| --- | --- |
| 太小 | 毛糙、过拟合噪声（方差大） |
| 适中 | 捕捉主要形状 |
| 太大 | 平滑过度、细节丢失（偏差大） |

**组距是「偏差—方差权衡」的第一课**——与现代机器学习里的模型复杂度选择同源。

### 例：从直方图到密度估计

**例**：直方图用「频率/组距」作纵轴，面积 = 频率。$n \to \infty$、组距 $\to 0$ 时，直方图包络收敛到真实密度——直方图是「密度估计」的原型。现代**核密度估计（KDE）**把「硬分组」换成「光滑核」，是直方图的平滑升级。

### 经验分布 vs 理论分布

| | 经验分布 $F_n$ | 理论分布 $F$ |
| --- | --- | --- |
| 来源 | 样本 | 模型/假设 |
| 形状 | 阶梯 | 光滑曲线 |
| 估计 | 已知 | 待估 |
| 用途 | 非参数推断 | 参数推断 |

**「$F_n$ 是 $F$ 的样本版」**——格利文科定理保证 $n$ 大时两者在全实数轴上几乎重合，这是「用 $F_n$ 代替 $F$」的合法性。

### 例：KS 检验的思想

**柯尔莫戈罗夫–斯米尔诺夫（KS）检验**比较 $F_n$ 与 $F$ 的最大偏差 $\sup|F_n - F|$——偏差大则拒绝「样本来自 $F$」。它是经验分布函数的直接应用，也是第八章拟合优度检验的非参数版本。

**易错点｜辨析：** ① 直方图纵轴用「频率」还是「频率/组距」要看目的——比较密度必须用后者；② 直方图是条形图的近亲但不同——横轴连续无缝的是直方图；③ 经验分布的 0.5 分位点（样本中位数）对离群值鲁棒，比样本均值更适合偏态数据。

## 6 小结

- **经验分布函数** $F_n(x)$ 是样本中 $\le x$ 的比例，一条每观测跳 $1/n$ 的阶梯，是 $F(x)$ 的样本版。
- **格利文科定理**：$n$ 大时 $F_n$ 在全实数轴上一致逼近 $F$——样本代表总体的最强保证，bootstrap 的根基。
- **直方图**是密度估计的非参数原型，纵轴用「频率/组距」则面积 = 概率、总面积 = 1。
- 组距选择是「偏差—方差权衡」的雏形，组数通常取 $\sqrt n$ 量级。
- 直方图 ≠ 条形图：前者连续区间无缝，后者类别留隙。
