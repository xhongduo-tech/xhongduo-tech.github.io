## 为什么从回归系数的置信区间与预测开始

上一节检验了「斜率是否显著为 0」，但检验只给「是/否」。回归推断的完整答案需要**数字区间**：斜率 $b$ 大概在哪个区间（系数置信区间）？给定新的 $x_0$，$y$ 会落在哪里（预测）？本节把第七章的区间估计技术应用到回归，并区分两个常被混淆的概念——**回归直线的置信区间**与**新观测的预测区间**。

回归系数的区间与预测是回归分析的「产出物」：系数区间告诉你「$x$ 每增加一单位，$y$ 平均增加多少（带把握）」，预测区间告诉你「新数据点可能在哪」。它们也是决定系数 $R^2$ 与回归报告的标准内容。<span class="marginnote">「置信区间 vs 预测区间」是本节的灵魂区别：<strong>置信区间承诺「$E[Y \mid x_0]$（平均响应）大概在这」；预测区间承诺「$y_0$（下一个观测值）大概落在这」</strong>。预测区间永远更宽——因为它除了「估计均值的不确定」，还要叠上「单个观测自身的波动 $\sigma^2$」。第七章埋的伏笔在这里正式引爆。</span>

## 1 回归系数的置信区间

由上一节，$\hat b \sim N(b, \sigma^2/S_{xx})$，用 $\hat\sigma^2$ 代替 $\sigma^2$ 后：

$$b \text{ 的置信区间：}\ \hat b \pm t_{\alpha/2}(n-2)\sqrt{\frac{\hat\sigma^2}{S_{xx}}}$$

$$a \text{ 的置信区间：}\ \hat a \pm t_{\alpha/2}(n-2)\sqrt{\hat\sigma^2\left(\frac{1}{n} + \frac{\bar x^2}{S_{xx}}\right)}$$

**例**：广告与销售额回归，$\hat b = 6$，$S_{\hat b} = 1.5$，$n = 12$，$t_{0.025}(10) = 2.228$。$b$ 的 95% 置信区间：$6 \pm 2.228 \times 1.5 = 6 \pm 3.34 = (2.66, 9.34)$——**每多投 1 万元广告，销售额平均增加 2.66 到 9.34 万元**。区间不含 0，与上一节「斜率显著」一致（对偶关系）。<span class="marginnote">系数区间是否含 0 与显著性检验互为镜像（第八章对偶关系）：$b$ 的 95% 区间含 0 ⇔ $H_0: b = 0$ 在 5% 水平不拒绝。所以「报告区间」自动携带「检验结论」——这是现代回归报告「区间优先」的又一理由。</span>

## 2 回归直线的置信区间

给定 $x_0$ 时，回归直线的均值 $E[Y \mid x_0] = a + bx_0$ 的置信区间：

$$\hat y_0 \pm t_{\alpha/2}(n-2)\,\hat\sigma\sqrt{\frac{1}{n} + \frac{(x_0 - \bar x)^2}{S_{xx}}}$$

其中 $\hat y_0 = \hat a + \hat b x_0$。**关键特征**：区间宽度随 $(x_0 - \bar x)^2$ 增大而增大——**在 $x_0 = \bar x$ 处最窄，越远离数据中心越宽**。这是「对均值的估计，离数据越远越没底」的定量表达。<span class="marginnote">「置信带在 $\bar x$ 处收成蜂腰」是回归的经典图像：直线在数据中心「最可靠」，往两端延伸时不确定性像喇叭口一样张开。这也解释了「外推（extrapolation）」为什么危险——预测 $x_0$ 远离观测范围时，区间宽到几乎无意义。统计学的金律：回归只适合在观测范围内插值。</span>

## 3 新观测的预测区间

给定 $x_0$，新观测 $y_0$ 的预测区间（比置信区间多一项 $\sigma^2$）：

$$\hat y_0 \pm t_{\alpha/2}(n-2)\,\hat\sigma\sqrt{1 + \frac{1}{n} + \frac{(x_0 - \bar x)^2}{S_{xx}}}$$

**与置信区间的唯一区别**：根号里多了「1」——这 1 对应「单个新观测自身的波动 $\sigma^2$」。因为 $y_0 = a + bx_0 + \varepsilon_0$，预测误差 = 估计误差 + 个体误差。<span class="marginnote">预测区间与置信区间的宽度差：预测区间根号里多一个「1」，所以永远比置信区间宽——即使在 $\bar x$ 处，预测区间也至少宽 $\hat\sigma$ 的量级。直觉：<strong>置信区间问「平均情况在哪」，预测区间问「单次情况在哪」——单次必然更散</strong>。这正是第七章「置信 vs 预测」伏笔的完整兑现。</span>

**例**：广告 $x_0 = 5$ 万元时，$\hat y_0 = 26 + 6\times 5 = 56$ 万元。若 $n = 12$，$\bar x = 4$，$S_{xx} = 40$，$\hat\sigma = 8$，$t_{0.025}(10) = 2.228$：

- 均值置信区间：$56 \pm 2.228 \times 8\sqrt{1/12 + (5-4)^2/40} = 56 \pm 2.228 \times 8 \times 0.306 = 56 \pm 5.45 = (50.55, 61.45)$；
- 预测区间：$56 \pm 2.228 \times 8\sqrt{1 + 0.0937} = 56 \pm 2.228 \times 8 \times 1.046 = 56 \pm 18.65 = (37.35, 74.65)$。

**预测区间比置信区间宽 3 倍多**——「平均销售额约 56 万」vs「下一笔销售额可能落在 37–75 万」。

## 4 公式解析：置信区间与预测区间的差

两条公式的差别全在根号里的「1」，把它拆开看：

$$

\hat y_0 \pm t_{\alpha/2}\,\hat\sigma\sqrt{\frac{1}{n} + \frac{(x_0-\bar x)^2}{S_{xx}}} \quad \text{vs} \quad \hat y_0 \pm t_{\alpha/2}\,\hat\sigma\sqrt{1 + \frac{1}{n} + \frac{(x_0-\bar x)^2}{S_{xx}}}

$$

- **第一步，估计误差的来源**：$\hat y_0 = \hat a + \hat b x_0$ 的波动来自 $\hat a$、$\hat b$ 的估计误差，方差是 $\sigma^2(\frac1n + \frac{(x_0-\bar x)^2}{S_{xx}})$——这就是置信区间根号里的部分。
- **第二步，预测误差 = 估计 + 个体**：新观测 $y_0 = a + bx_0 + \varepsilon_0$，$\varepsilon_0$ 的波动 $\sigma^2$ 独立于估计误差，方差相加，多出「1」。
- **第三步，宽度结论**：根号里多 1 → 预测区间恒宽于置信区间；$n$ 越大、$x_0$ 越近 $\bar x$，两者差距越小但永不为零。

「置信区间量『知道的均值』，预测区间量『未知的个体』」——一个多出来的 1，就是「个体随机性」的价格。

## 5 置信区间与预测的深入应用

「区间含不含 0」「预测带有多宽」——回归推断的每个结论都牵涉这几个实操细节。

### 例：系数区间与显著性

**例**：$\hat b = 6$、$S_{\hat b} = 1.5$、$n = 12$，$b$ 的 95% 区间 $6 \pm 2.228\times 1.5 = (2.66, 9.34)$——区间不含 0，斜率显著（与 t 检验对偶）。若区间为 $(-1.2, 3.4)$，含 0 → 不显著——「区间含 0 ⇔ 检验不拒绝 $H_0: b = 0$」。

### 置信带与预测带的对照

| | 置信带 | 预测带 |
| --- | --- | --- |
| 承诺对象 | $E[Y \mid x_0]$（平均） | $y_0$（新观测） |
| 根号内 | $\frac1n + \frac{(x_0-\bar x)^2}{S_{xx}}$ | $1 + \frac1n + \frac{(x_0-\bar x)^2}{S_{xx}}$ |
| 宽度 | 窄 | 恒宽（多 1） |
| 形状 | 中间窄两端宽 | 中间窄两端宽（更宽） |

**「预测带永远包住置信带」**——个体波动恒在，区间就恒宽。

### 例：预测区间的完整计算

**例**：$n = 12$、$\bar x = 4$、$S_{xx} = 40$、$\hat\sigma = 8$，$x_0 = 5$ 时 $\hat y_0 = 56$。置信区间 $56 \pm 2.228\times 8\sqrt{1/12 + 1/40}$；预测区间 $56 \pm 2.228\times 8\sqrt{1 + 1/12 + 1/40}$——预测区间约宽 3 倍，「下一笔销售可能落 37–75 万」vs「平均约 56 万」。

### 外推的危险

**易错点｜辨析：** 预测 $x_0$ 远离观测范围时，$(x_0 - \bar x)^2/S_{xx}$ 暴增，区间宽到无意义——**外推（extrapolation）不可靠**。回归只适合在观测范围内插值；越出范围，线性假设本身都可能失效。

### 例：样本量对区间的影响

$n$ 增大时：$\frac1n \to 0$、$t_{\alpha/2}(n-2)$ 趋近 $z_{\alpha/2}$、$\hat\sigma$ 趋近 $\sigma$——区间宽度趋于理论下限。**「想区间窄，靠增大 $n$ 与控制残差（提高 $R^2$）」**是回归设计的两大杠杆。

再补一张「三类回归区间」对照：

| 对象 | 公式（半宽） | 用途 |
| --- | --- | --- |
| 系数 $b$ | $t_{\alpha/2}\sqrt{\hat\sigma^2/S_{xx}}$ | 斜率范围 |
| 均值 $E[Y\mid x_0]$ | $t_{\alpha/2}\hat\sigma\sqrt{1/n+(x_0-\bar x)^2/S_{xx}}$ | 平均响应 |
| 新观测 $y_0$ | $t_{\alpha/2}\hat\sigma\sqrt{1+1/n+(x_0-\bar x)^2/S_{xx}}$ | 单次预测 |

「系数、均值、预测」三种区间半宽逐级增大——越「具体」的对象区间越宽。

## 6 小结

- **系数区间**：$\hat b \pm t_{\alpha/2}(n-2)\sqrt{\hat\sigma^2/S_{xx}}$（$b$）、$\hat a \pm t_{\alpha/2}(n-2)\sqrt{\hat\sigma^2(1/n + \bar x^2/S_{xx})}$（$a$）。
- **回归直线置信区间**：$\hat y_0 \pm t_{\alpha/2}\hat\sigma\sqrt{1/n + (x_0-\bar x)^2/S_{xx}}$——在 $\bar x$ 处最窄，越远越宽。
- **预测区间**：$\hat y_0 \pm t_{\alpha/2}\hat\sigma\sqrt{1 + 1/n + (x_0-\bar x)^2/S_{xx}}$——多一个「1」，恒宽于置信区间。
- 置信区间承诺「平均响应」，预测区间承诺「新观测」；外推危险，区间在观测范围外张开。
- 系数区间是否含 0 与显著性检验互为对偶。
