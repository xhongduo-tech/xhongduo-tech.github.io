## 为什么从正态总体方差的检验开始

均值检验管「大约多少」，方差检验管「波动是否合规」：机器的一致性是否下降（$\sigma^2$ 是否超标）、两条产线的波动是否可比。检验单个方差用 **χ² 检验**，比较两个方差用 **F 检验**——它们分别是第七章方差区间与方差比区间的检验版。

方差检验的统计量直接来自第六章抽样分布：$\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$ 与 $\frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1-1, n_2-1)$。它是「双总体均值检验」的方差伴侣，也是第九章方差分析「方差齐性检查」的前奏。<span class="marginnote">方差检验的两个重要场景：<strong>①质量管理里「过程能力」的验收——要求 $\sigma^2$ 不超过规格值；②方差分析/合并方差 t 的前提检查——要求两个 $\sigma^2$ 相等</strong>。第二个场景让它成为「元检验」：方差检验往往是为后面的均值检验铺路。</span>

## 1 单个正态总体方差的 χ² 检验

设 $X \sim N(\mu, \sigma^2)$，检验 $H_0: \sigma^2 = \sigma_0^2$。检验统计量：

$$\chi^2 = \frac{(n-1)S^2}{\sigma_0^2} \sim \chi^2(n-1) \quad (\text{当 } H_0 \text{ 真})$$

拒绝域按 $H_1$ 方向：

| $H_1$ | 拒绝域 |
| --- | --- |
| $\sigma^2 \ne \sigma_0^2$ | $\chi^2 \ge \chi^2_{\alpha/2}(n-1)$ 或 $\chi^2 \le \chi^2_{1-\alpha/2}(n-1)$ |
| $\sigma^2 > \sigma_0^2$ | $\chi^2 \ge \chi^2_\alpha(n-1)$ |
| $\sigma^2 < \sigma_0^2$ | $\chi^2 \le \chi^2_{1-\alpha}(n-1)$ |

**例（一致性检验）**：某工序要求直径方差 $\sigma^2 \le 0.01$ mm²，抽 $n = 21$ 件，$s^2 = 0.016$。检验 $H_0: \sigma^2 = 0.01$ vs $H_1: \sigma^2 > 0.01$，$\alpha = 0.05$。

$$\chi^2 = \frac{20 \times 0.016}{0.01} = 32$$

$\chi^2_{0.05}(20) = 31.41$，$32 \ge 31.41$ → 拒绝 $H_0$——方差显著超标，工序一致性不合格。<span class="marginnote">χ² 检验的拒绝域<strong>不对称</strong>（χ² 分布右偏）：双侧检验的左右临界值 $\chi^2_{1-\alpha/2}$ 与 $\chi^2_{\alpha/2}$ 离中心距离不同。这与均值 z/t 检验的对称拒绝域形成鲜明对比——凡检验对象是方差，拒绝域就开始「偏心」。左侧临界值常用倒数技巧？不——χ² 无倒数对称，必须直接查左尾（教材附表会给出下侧分位点）。</span>

## 2 两个正态总体方差的 F 检验

设两组独立样本，检验 $H_0: \sigma_1^2 = \sigma_2^2$。检验统计量（把较大的方差放分子，或按 $H_1$ 定）：

$$F = \frac{S_1^2}{S_2^2} \sim F(n_1 - 1,\ n_2 - 1) \quad (\text{当 } H_0 \text{ 真})$$

$H_0$ 真时 $S_1^2/S_2^2$ 接近 1；偏离 1 越大，越倾向拒绝。拒绝域：

| $H_1$ | 拒绝域 |
| --- | --- |
| $\sigma_1^2 \ne \sigma_2^2$ | $F \ge F_{\alpha/2}(n_1-1, n_2-1)$ 或 $F \le F_{1-\alpha/2}(n_1-1, n_2-1)$ |
| $\sigma_1^2 > \sigma_2^2$ | $F \ge F_\alpha(n_1-1, n_2-1)$ |

左尾临界值用倒数对称：$F_{1-\alpha/2}(n_1-1, n_2-1) = 1/F_{\alpha/2}(n_2-1, n_1-1)$。<span class="marginnote">F 检验的实务技巧：很多教材/软件把较大的样本方差放分子、直接做单侧「$\sigma_1^2 > \sigma_2^2$」检验——这等价于双侧检验。左尾用倒数对称查表（第七章方差比区间已练过）。F 检验是「合并方差 t」与「方差分析」的方差齐性前置，第九章方差分析还要它。</span>

**例**：两条产线各抽 $n_1 = 12$、$n_2 = 10$ 件，$s_1^2 = 0.8$、$s_2^2 = 0.5$。检验方差是否相等（$\alpha = 0.05$，双侧）：

$$F = \frac{0.8}{0.5} = 1.6$$

$F_{0.025}(11, 9) = 3.91$，$1.6 < 3.91$ 且 $1.6 > 1/F_{0.025}(9,11) = 1/3.59 = 0.279$ → 不拒绝 $H_0$——两产线方差无显著差异（与第七章区间含 1 的结论一致）。

## 3 χ² 检验与 F 检验的对照

| | χ² 检验 | F 检验 |
| --- | --- | --- |
| 对象 | 单个方差 | 两个方差之比 |
| 统计量 | $\frac{(n-1)S^2}{\sigma_0^2}$ | $\frac{S_1^2}{S_2^2}$ |
| 分布 | $\chi^2(n-1)$ | $F(n_1-1, n_2-1)$ |
| 拒绝域 | 不对称 | 不对称（左尾用倒数） |

**易错点｜辨析：** ① χ² 检验的分母是**假设值** $\sigma_0^2$，F 检验没有分母假设值（$H_0$ 下比值为 1）；② χ² 拒绝域不对称，双侧时左右临界值都要查；③ F 检验自由度顺序「分子→第一」不可颠倒；④ 方差检验对**正态性敏感**——总体明显非正态时，χ²/F 检验的结论不可靠（这是第八章后面「偏度峰度检验」的用武之地）。<span class="marginnote">「方差检验对正态性敏感」是容易被忽略的隐患：χ²/F 检验的分布推导建立在总体正态上，非正态总体的样本方差不再服从 χ²/F。所以正态性检验（后面的偏度峰度、拟合优度）常是方差检验的「保险」——先用正态性检验确认假设成立，再信方差检验的结论。</span>

## 4 公式解析：χ² 检验统计量的构成

χ² 检验统计量的「样本方差 ÷ 假设方差」结构拆开：

$$

\chi^2 = \frac{(n-1)S^2}{\sigma_0^2} = \frac{\dfrac{(n-1)S^2}{\sigma^2}}{\sigma_0^2/\sigma^2}

$$

- **第一步，已知分布的量**：$\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$（第六章定理，$\sigma^2$ 是真实方差）。
- **第二步，$H_0$ 替换**：$H_0: \sigma^2 = \sigma_0^2$ 下，用 $\sigma_0^2$ 代替 $\sigma^2$，统计量 $\frac{(n-1)S^2}{\sigma_0^2}$ 服从 $\chi^2(n-1)$。
- **第三步，偏离方向**：真实方差大于 $\sigma_0^2$ 时，$S^2$ 偏大，$\chi^2$ 偏大——右单侧拒绝域。

「把第六章已知分布的枢轴量，在 $H_0$ 下代入假设值」是构造检验统计量的通用手法——χ²、F、t 检验全部如此：**枢轴量 + $H_0$ 替换 = 检验统计量**。

## 5 方差检验的深入应用与实例

χ² 检验与 F 检验是「波动管控」的工具，它们的计算、选择与前提值得展开。

### 例：χ² 检验

**例**：工序要求方差 ≤ 0.01，$n = 21$、$s^2 = 0.016$。$\chi^2 = 20\times 0.016/0.01 = 32$，$\chi^2_{0.05}(20) = 31.41$，$32 > 31.41$ → 拒绝——方差超标。

### 例：F 检验

**例**：两组 $s_1^2 = 0.8$、$s_2^2 = 0.5$，$n_1 = 12$、$n_2 = 10$。$F = 1.6$，$F_{0.025}(11, 9) = 3.91$，$1.6 < 3.91$ → 不拒绝方差相等。

### 两个检验的对照

| | χ² 检验 | F 检验 |
| --- | --- | --- |
| 对象 | 单方差 | 两方差比 |
| 统计量 | $\frac{(n-1)S^2}{\sigma_0^2}$ | $S_1^2/S_2^2$ |
| 分布 | $\chi^2(n-1)$ | $F(n_1-1, n_2-1)$ |
| 拒绝域 | 不对称 | 不对称（左尾倒数） |

**「单方差用 χ²、比方差用 F」**——方差检验的分工。

### 例：方差齐性检查

F 检验（或方差比区间）是「合并方差 t」的前提——**「先验方差齐性，再用合并方差」**是双总体均值分析的标准流程。

### 正态性的前提

方差检验对正态性敏感——**「非正态总体的样本方差不再服从 χ²/F」**，先验正态性（偏度峰度/QQ 图）再信方差检验。

**易错点｜辨析：** ① χ² 拒绝域不对称，双侧左右临界值都要查；② F 自由度顺序「分子→第一」；③ 左尾用倒数对称查表。

## 6 小结

- **χ² 检验**（单方差）：$\chi^2 = \frac{(n-1)S^2}{\sigma_0^2} \sim \chi^2(n-1)$，拒绝域不对称。
- **F 检验**（两方差）：$F = S_1^2/S_2^2 \sim F(n_1-1, n_2-1)$，左尾临界值用倒数对称查表。
- 统计量构造 = 枢轴量 + $H_0$ 替换假设值；$H_1$ 方向决定拒绝域形状。
- 方差检验对正态性敏感，非正态时结论需谨慎。
- χ²/F 检验是质量管理（过程能力）、方差齐性检查、方差分析的前提工具。
