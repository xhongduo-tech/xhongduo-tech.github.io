## 为什么从二维连续型随机变量开始

上一节我们用双行表格处理二维离散情形，可现在要考虑连续的两个量——身高与体重的联合、横纵坐标的联合。连续量的「单点概率为零」在二维依然成立，甚至更强：**平面上的单点概率为零，一条曲线上的概率也为零**。于是二维连续情形下的概率必须用**体积**来度量——联合概率密度函数 $f(x,y)$ 是定义在平面上的「概率高度」，落在某区域 $D$ 里的概率是 $f$ 在 $D$ 上的二重积分。

二维连续型是二维理论的「重头戏」：联合密度、边缘密度、条件密度、独立性全部以二重积分为工具。若你学过《高等数学》的二重积分，这一节是顺理成章的翻译；若没有，本节会用「分步积两次」的办法让你顺利完成全部计算。<span class="marginnote">连续情形的核心对照：一维的 $P\{X \le x\} = \int_{-\infty}^x f(t)dt$ 升维成 $F(x,y) = \int_{-\infty}^x\int_{-\infty}^y f(u,v)\,dv\,du$——先积内层 $v$，再积外层 $u$，顺序可以交换（富比尼定理保证）。「两次单积分」而不是「一次神秘的二重积分」，是初学者最该记住的操作。</span>

## 1 联合概率密度：曲面与体积

**二维连续型随机变量**：若存在非负函数 $f(x,y)$ 使对任意实数 $x,y$，$(X,Y)$ 的分布函数可写成

$$F(x, y) = \int_{-\infty}^{x} \int_{-\infty}^{y} f(u, v)\, dv\, du$$

则称 $(X,Y)$ 为二维连续型随机变量，$f(x,y)$ 称为其**联合概率密度（joint probability density function）**。

联合密度满足两条性质：

1. **非负性**：$f(x,y) \ge 0$；
2. **归一性**：$\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} f(x,y)\, dx\, dy = 1$——曲面下的总体积为 1。

**任意区域概率是体积**：对平面区域 $D$，

$$P\{(X,Y) \in D\} = \iint_{D} f(x, y)\, dx\, dy$$

<span class="marginnote">一维的「单点概率为 0」在二维升级为「任意面积为零的集合概率为 0」——不仅单点，连一条曲线、一条线段上的概率都是 0。这与「几何概型里落在直线上的概率为零」一脉相承，也解释了为什么二维连续变量可以在圆域、三角域上定义密度而毫无矛盾。</span>

## 2 联合密度的几何直觉与例题

联合密度 $f(x,y)$ 的图像是一片起伏的「山」：高处的 $f$ 值表示该处概率密集。**密度越高，概率越「厚」**——这正与一维相同。

**例**：设 $(X,Y)$ 在三角形区域 $D = \{0 \le x \le 1,\ 0 \le y \le x\}$ 上均匀分布，即 $f(x,y) = c$（常数）于 $D$ 内，$D$ 外为 0。由归一性：

$$1 = \iint_D c\, dx\,dy = c \cdot \text{面积}(D) = c \cdot \frac12 \implies c = 2$$

「二维均匀分布」的密度 = 1/区域面积，与一维 $1/(b-a)$ 完全同构。<span class="marginnote">求均匀分布的常数 $c$ 是二维连续型最经典的入门题：<strong>归一性 = 常数 × 区域面积</strong>。难点全在求区域面积——三角形、圆、抛物线围成的区域，都需要平面几何或定积分。把区域画出来，是这类题的胜负手。</span>

求 $P\{X \le 1/2\}$：事件对应 $D$ 内 $x \le 1/2$ 的部分（小三角形，面积 $1/8$），故概率 $= 2 \times 1/8 = 1/4$。

## 3 联合分布函数与密度的互推

与一维一样，二维的密度与分布函数通过「积分↔求导」互逆。若 $f$ 在 $(x,y)$ 连续，则

$$f(x, y) = \frac{\partial^2 F(x, y)}{\partial x\, \partial y}$$

即**联合密度是联合分布函数的混合二阶偏导**。已知 $F$ 求 $f$ 只需两次偏导；已知 $f$ 求 $F$ 只需两次积分。<span class="marginnote">「先对 $x$ 偏导、再对 $y$ 偏导」的顺序无关紧要——只要 $f$ 连续，混合偏导可交换。这也印证了二重积分可换序的富比尼定理：二维情形下的「先后」只是记法习惯，数学上等价。</span>

**易错点｜辨析：** 联合密度 $f(x,y)$ 的**支撑**（非零区域）通常不是全平面，而是某个区域 $D$。写积分上下限时必须按 $D$ 的形状定界——「先 $y$ 后 $x$」还是「先 $x$ 后 $y$」要随区域形状选。常见的错误是上下限写成常数，导致把 $D$ 外的概率也积进来，破坏了归一性。

## 4 公式解析：区域概率的两步定界

以密度 $f(x,y) = \begin{cases} 6xy, & 0 \le x \le 1,\ 0 \le y \le 1 \\ 0, & \text{其他} \end{cases}$ 为例，求 $P\{X + Y \le 1\}$：

$$

P\{X + Y \le 1\} = \int_{0}^{1} \int_{0}^{1-x} 6xy\, dy\, dx

$$

- **第一步，定区域**：事件 $X + Y \le 1$ 在单位正方形内截出一个三角形 $D'$：$0 \le x \le 1$、$0 \le y \le 1-x$。
- **第二步，选积分顺序**：先积内层 $y$，范围由 $x$ 决定，$0$ 到 $1-x$；再积外层 $x$，$0$ 到 $1$。顺序的选择准则是「让内层上限由外层变量表达」。
- **第三步，逐层积分**：$\int_0^1 6x \cdot \frac{(1-x)^2}{2}\, dx = \int_0^1 3x(1 - 2x + x^2)\, dx = 3\left[\frac{x^2}{2} - \frac{2x^3}{3} + \frac{x^4}{4}\right]_0^1 = 3 \cdot \frac{1}{12} = \frac14$。

「画区域 → 按区域定界 → 逐层积分」是二维连续型概率计算的通用三连。区域画错，后面全错——所以每道题的第一步永远是画图。

## 5 二维连续分布的深入应用与实例

二维连续分布是「概率体积」的数学，它的计算、几何与技巧值得展开。

### 例：归一化常数

**例**：$f(x,y) = c$ 在三角域 $0 \le y \le x \le 1$，求 $c$。区域面积 $1/2$，$c = 1/\text{面积} = 2$——**「二维均匀的密度 = 面积倒数」**，归一化即「常数 × 面积 = 1」。

### 例：区域概率的分步积分

**例**：$f(x,y) = 6xy$（$0\le x,y\le 1$），求 $P\{X + Y \le 1\}$：

$$P = \int_0^1\int_0^{1-x} 6xy\, dy\, dx = \int_0^1 3x(1-x)^2 dx = \frac14$$

**「画区域 → 定界 → 逐层积分」**是二维概率计算的通用三连。

### 二维连续的计算要点

| 步骤 | 要点 |
| --- | --- |
| 画区域 | 定积分上下限的依据 |
| 选顺序 | 内层上限由外层变量表达 |
| 逐层积分 | 先内后外 |
| 验证 | 总面积 = 1 |

**「区域画错，后面全错」**——画图是二维积分的胜负手。

### 例：边缘与条件

$f_X(x) = \int f(x,y)dy$、$f_{X\mid Y}(x\mid y) = f(x,y)/f_Y(y)$——**「积分得边缘、比值得条件」**是二维连续的两个基本操作。

### 几何直觉：概率是体积

$P\{(X,Y) \in D\} = \iint_D f(x,y)dxdy$——**「密度曲面下的体积」**，与一维「曲线下的面积」同构，只是升了一维。

**易错点｜辨析：** ① 支撑（非零区域）决定积分上下限——别积到 $D$ 外；② 单点、曲线上的概率为 0——区域面积才承载概率；③ 二重积分可换序（富比尼），但上下限要随换序改写。

## 6 小结

- **二维连续型随机变量**由联合密度 $f(x,y) \ge 0$ 描述，归一性为 $\iint_{\mathbb{R}^2} f = 1$。
- 任意区域概率 $P\{(X,Y) \in D\} = \iint_D f(x,y)\,dx\,dy$——概率是曲面下的**体积**。
- 联合密度与分布函数互逆：$f = \partial^2 F / \partial x \partial y$。
- **画区域 → 定界 → 逐层积分**是二维概率计算的通用流程；上下限必须随区域形状而定。
- 二维均匀分布密度 $= 1/\text{区域面积}$，归一性即「常数 × 面积 = 1」。
