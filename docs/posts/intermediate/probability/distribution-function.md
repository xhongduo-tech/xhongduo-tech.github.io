## 为什么从分布函数开始

到目前为止，离散型有分布律、连续型有概率密度——但两者是两套语言，且都存在各自的「盲点」：离散型的单点概率非零，连续型的单点概率为零，哪种都不能描述对方。**分布函数（distribution function）** 是跳出这个困境的统一工具：它不问「$X$ 取某值的概率」，而问「$X$ 不超过 $x$ 的概率」，对所有实数 $x$ 给出一个累积的答案。这一问，离散、连续一网打尽。

分布函数是概率论的「全局对象」：一切的分布信息（分布律、密度、数字特征）都能从它导出，而它本身又满足三个简单的分析性质。理解分布函数，等于理解了「概率是测度」的雏形——它是通往第五章大数定律、实变函数与测度论的一座桥。<span class="marginnote">教科书常把分布函数写成「$F(x)$」。它与第二级《实变函数与测度论》里的「累积分布测度」一脉相承：概率论最严格的形式化，正是科尔莫戈罗夫在 1933 年用测度论完成的，$F(x)$ 就是测度在区间 $(-\infty, x]$ 上的值。</span>

## 1 定义与三种表达

**分布函数（distribution function / cumulative distribution function, CDF）**：设 $X$ 是一个随机变量，$x$ 是任意实数，称函数

$$F(x) = P\{X \le x\}, \qquad -\infty < x < +\infty$$

为 $X$ 的**分布函数**。

与分布律、概率密度相比，分布函数是「累积」的：它把所有「$\le x$」的概率攒起来。三种表达方式的关系：

| 随机变量类型 | 分布函数 | 与分布律/密度的关系 |
| --- | --- | --- |
| 离散型 | 阶梯函数 | $F(x) = \sum_{x_k \le x} p_k$ |
| 连续型 | 连续函数 | $F(x) = \int_{-\infty}^{x} f(t)\, dt$ |
| 混合型 | 一般右连续函数 | 兼有跳跃与连续部分 |

**例（离散）**：$X$ 取 $1, 2, 3$，概率各 $0.2, 0.3, 0.5$。则 $F(1.5) = 0.2$，$F(2.5) = 0.5$，$F(4) = 1$——每一个 $x$ 都是「把表中 $\le x$ 的概率加起来」。<span class="marginnote">「$X \le x$」里的等号至关重要：$F(x)$ 在 $x$ 恰为取值点时包含该点的概率，所以离散分布函数在取值点处<strong>右连续</strong>（从右侧趋近含跳跃，从左侧趋近不含）。左连续还是右连续，是概率论教材的第一个约定陷阱。</span>

## 2 分布函数的三大性质

一个函数 $F(x)$ 能成为某个随机变量的分布函数，当且仅当满足：

1. **有界性**：$0 \le F(x) \le 1$，且 $\lim_{x \to -\infty} F(x) = 0$，$\lim_{x \to +\infty} F(x) = 1$；
2. **单调不减**：若 $x_1 < x_2$，则 $F(x_1) \le F(x_2)$；
3. **右连续**：$F(x + 0) = F(x)$，即 $F(x) = \lim_{\varepsilon \to 0^+} F(x + \varepsilon)$。

三条性质分别对应概率的**非负、单调与完备**，也构成判断「给一个函数是不是分布函数」的完备判据。<span class="marginnote">这三条性质在后续章节反复出场：检验分布函数、构造新分布、证明极限定理都要用它。特别是右连续性，在随机过程与马尔可夫链的转移矩阵理论里会再次成为「技术性但不含糊」的约定。</span>

**易错点｜辨析：** 右连续 vs 左连续。设 $X$ 取值 2 的概率为 0.3，则 $F(2) = P\{X \le 2\}$ 含「$X = 2$」，包含跳跃；而 $F(2 - \varepsilon)$ 不含它。因此 $F$ 在 2 处右连续、左极限少一跳。有的教材定义 $F(x) = P\{X < x\}$（左连续版），两者只差端点的约定——**做题前先看清教材用哪版**。

## 3 用分布函数算区间概率

分布函数的最大实用价值：**任何区间概率都能写成 $F$ 的差**。对任意实数 $a < b$：

$$P\{a < X \le b\} = F(b) - F(a)$$

更有用的四种「区间公式」要能随手写出：

- $P\{X \le a\} = F(a)$；
- $P\{X > a\} = 1 - F(a)$；
- $P\{X < a\} = F(a - 0)$（左极限）；
- $P\{a < X \le b\} = F(b) - F(a)$。

**例**：已知 $F(x)$，求 $P\{1 < X \le 3\} = F(3) - F(1)$，$P\{X > 2\} = 1 - F(2)$。区间的「开」「闭」只影响端点处是否有跳跃：连续型两端概率为 0，开闭无所谓；离散型则必须逐点核对。<span class="marginnote">这组公式里藏着概率论与微积分的类比：$F$ 相当于「累积量」，区间概率相当于「增量」，而下一节的密度函数 $f$ 正是 $F$ 的导数——「累积量」与「增量」的关系在连续情形下被微积分基本定理完整接管。</span>

## 4 公式解析：离散分布函数为什么是阶梯

把离散分布函数画出来，是一级级向上的「台阶」。它的构造值得逐项拆解：

$$

F(x) = \sum_{x_k \le x} p_k

$$

- **第一步，枚举**：把 $X$ 的全部取值 $x_1, x_2, \ldots$ 从小到大排好。
- **第二步，筛选**：只保留满足 $x_k \le x$ 的那些取值——这是「累积」二字的来源。
- **第三步，累加**：把选中的 $p_k$ 全部加起来。$x$ 每越过一个取值点，$F$ 就向上跳一步，跳跃高度恰为该点的 $p_k$；两值之间没有新增，$F$ 保持水平。

于是「$F$ 的跳跃高度 = 单点概率」：已知 $F$，反推分布律只需读出各跳跃点的高度。**分布律与分布函数互为可逆表示**——这是离散情形里最常用的双向翻译，后面估计最大似然、做假设检验时都要频繁在这两种语言间切换。

## 5 分布函数的深入应用与实例

分布函数是「一切随机变量的统一语言」，它的性质、计算与检验值得完整展开。

### 例：区间概率的差

**例**：已知 $F(x)$，$P\{1 < X \le 3\} = F(3) - F(1)$、$P\{X > 2\} = 1 - F(2)$——「区间概率 = 分布函数之差」是分布函数的第一用途。

### 三大性质的验证

| 性质 | 检查 |
| --- | --- |
| 有界 | $F(-\infty)=0$、$F(\infty)=1$ |
| 单调 | $x_1 < x_2 \Rightarrow F(x_1) \le F(x_2)$ |
| 右连续 | $F(x+0) = F(x)$ |

**「函数是分布函数 ⇔ 三条性质全满足」**——判断题的判据。

### 例：从分布函数到分布律/密度

| 类型 | 反推 |
| --- | --- |
| 离散 | 跳跃高度 = $p_k$ |
| 连续 | $f = F'$ |

**「分布函数是母版」**——分布律与密度都从它导出。

### 例：离散分布函数的阶梯

$F(x)$ 在取值点跳跃 $p_k$、两值间水平——**「阶梯函数是离散分布函数的画像」**，跳跃高度即单点概率。

### 与随机过程的联系

分布函数是「随机过程的有限维分布」的基础——**「$F(x,y)$ 联合分布函数是二维过程的公共语言」**，第三章与第十一章在此交汇。

**易错点｜辨析：** ① 右连续 vs 左连续的约定——教材用 $P\{X \le x\}$（右连续），看清版本；② 连续型端点概率 0、离散型端点概率非零——区间公式的端点处理不同；③ 「$F(x)$ 单调不减」别写成「单调递增」——平段是合法的（离散）。

## 6 小结

- **分布函数** $F(x) = P\{X \le x\}$ 对所有随机变量通用，是离散与连续的统一描述。
- 三条判据：**有界**（两端极限 0 与 1）、**单调不减**、**右连续**——函数是分布函数当且仅当满足这三条。
- 区间概率 $P\{a < X \le b\} = F(b) - F(a)$，四种区间公式要随手能写。
- 离散型分布函数是**阶梯函数**，跳跃高度 = 单点概率；连续型是连续函数，可对密度积分。
- 分布函数是期望、方差、分位数与一切极限定理的共同地基。
