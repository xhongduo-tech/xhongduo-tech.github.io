## 为什么从泊松过程开始

第二章学过的泊松分布数「一段时间内发生几次」，现在把它升级为**随时间的完整过程**：电话交换台从时刻 0 开始，每分钟到多少通电话——$\{X(t), t \ge 0\}$ 就是**泊松过程（Poisson process）**。它是连续时间、离散状态随机过程的最经典代表，是排队论、可靠性、物理计数的通用模型。

泊松过程在整个随机过程章的地位是「第一个具体的连续时间过程」：它的定义、性质、等待时间理论（下一节）构成随机过程应用的完整样板。它也与第二章泊松分布、指数分布（无记忆性）完成闭环——一个过程把三个概念串成一条线。<span class="marginnote">泊松过程的三条公理（第二章泊松分布三条件的动态版）：<strong>①平稳性——等长时段内到达数分布相同；②独立增量——不重叠时段相互独立；③普通性——同一瞬间至多一个到达</strong>。从这三条公理出发，可以推导出「$N(t) \sim \pi(\lambda t)$」这一整套性质——过程的整个理论都是这三条公理的逻辑展开。</span>

## 1 泊松过程的定义

**泊松过程（Poisson process）**：计数过程 $\{N(t), t \ge 0\}$（$N(t)$ = 到时刻 $t$ 为止的到达数）满足：

1. $N(0) = 0$；
2. **独立增量**：不重叠区间内的到达数相互独立；
3. **平稳性**：对任意 $s, t \ge 0$，$N(t+s) - N(s)$ 的分布只依赖 $t$，不依赖 $s$；
4. **普通性**：$P\{N(h) \ge 2\} = o(h)$（$h \to 0$）。

则称 $\{N(t), t \ge 0\}$ 为强度（速率）$\lambda$ 的泊松过程。

**核心结论**：$N(t) \sim \pi(\lambda t)$，即 $P\{N(t) = k\} = \frac{(\lambda t)^k}{k!} e^{-\lambda t}$。<span class="marginnote">「强度 $\lambda$」的含义：单位时间内平均到达 $\lambda$ 个，$E[N(t)] = \lambda t$。四条公理中「普通性」最常被现实违反——若事件经常「成对挤在同刻」（地震余震、雪崩请求），泊松假设崩塌。判断现实计数能否用泊松过程，先查「会不会同一瞬间来俩」。</span>

**例（电话呼叫）**：交换台平均每分钟 3 通电话，$\lambda = 3$。则 $N(t) \sim \pi(3t)$，5 分钟内到 10 通的概率 $= \frac{(15)^{10}}{10!}e^{-15}$。

## 2 泊松过程的性质

泊松过程拥有三组重要性质：

**性质 1（增量分布）**：$N(t+s) - N(s) \sim \pi(\lambda t)$——任意等长时段的增量都是泊松分布，参数 $\lambda t$。

**性质 2（数字特征）**：$\mu(t) = \lambda t$，$\sigma^2(t) = \lambda t$，$\mathrm{Cov}(N(s), N(t)) = \lambda\min(s,t)$——均值 = 方差 = 相关（上一节算过）。

**性质 3（到达间隔）**：第 $i$ 个与第 $i+1$ 个到达的间隔 $T_i$ 相互独立且都服从**指数分布** $E(\lambda)$——**泊松过程 ↔ 指数到达间隔 ↔ 无记忆性**（下一节详讲）。<span class="marginnote">性质 3 是泊松过程最漂亮的结果：独立增量 + 平稳 + 普通 ⟹ 到达间隔是独立同分布的指数变量。这也解释了第二章的预告——指数分布是泊松过程的「等待时间」：$P\{T_1 > t\} = P\{N(t) = 0\} = e^{-\lambda t}$。指数分布的无记忆性，正是泊松过程「过去的到达不影响未来」的公理在等待时间上的投影。</span>

## 3 例：泊松过程的数字特征验证

**例**：某服务站每小时平均到达 12 名顾客（$\lambda = 12$/小时）。求：

1. **半小时内到达 5 名的概率**：$N(0.5) \sim \pi(6)$，$P\{N(0.5)=5\} = \frac{6^5}{5!}e^{-6} \approx 0.161$；
2. **平均到达间隔**：$E[T] = 1/\lambda = 1/12$ 小时 = 5 分钟；
3. **间隔超过 10 分钟的概率**：$P\{T > 1/6\} = e^{-12/6} = e^{-2} \approx 0.135$。

三个问题分别用泊松分布、指数均值、指数尾巴公式——一个过程、三个工具，环环相扣。<span class="marginnote">「平均 5 分钟来一个」与「间隔超过 10 分钟的概率 13.5%」的直觉核对：指数分布标准差 = 均值 = 5 分钟，「超过 2 倍均值」的概率 $e^{-2} \approx 13.5\%$——与「无记忆」的指数尾巴一致。这类「估算核对」是检验过程模型是否合理的手感训练。</span>

## 4 公式解析：从公理到泊松分布

泊松过程最核心的推导是「四条公理 → $N(t) \sim \pi(\lambda t)$」，用微分方程法：

$$

\frac{d}{dt}P\{N(t) = k\} = \lambda P\{N(t) = k-1\} - \lambda P\{N(t) = k\}

$$

- **第一步，写 $t + h$ 时刻的概率**：$N(t+h) = k$ 可由「$N(t) = k$ 且 $h$ 内无到达」或「$N(t) = k-1$ 且 $h$ 内到 1 个」得到（普通性忽略 ≥ 2）。
- **第二步，普通性展开**：$P\{\text{1 个到达}\} \approx \lambda h$，$P\{\text{0 个}\} \approx 1 - \lambda h$，$P\{\ge 2\} = o(h)$。
- **第三步，取 $h \to 0$ 极限**：得到关于 $k$ 的微分方程，解之得 $P\{N(t)=k\} = \frac{(\lambda t)^k}{k!}e^{-\lambda t}$。

「普通性把事件分解成「0 或 1」，微分方程把概率变化写成递推」是泊松过程推导的标准招式。它示范了随机过程理论的核心方法：**用无穷小增量（$o(h)$ 近似）建立微分方程，解方程得分布**。

## 5 泊松过程的深入应用与实例

泊松过程是排队论与可靠性的基础模型，它的三个核心应用——排队、可靠性、模拟——值得展开。

### 例：排队系统的到达建模

**例**：银行平均每分钟到 2 名顾客（$\lambda = 2$）。求「5 分钟内至少到 8 名」的概率：$N(5) \sim \pi(10)$，$P\{N \ge 8\} = 1 - \sum_{k=0}^7 \frac{10^k}{k!}e^{-10} \approx 0.78$。泊松到达是排队论 M/M/1 等模型的输入假设。

### 例：可靠性的故障建模

**例**：设备故障率 $\lambda = 0.001$/小时。求「1000 小时内无故障」概率：$P\{N(1000) = 0\} = e^{-1} \approx 0.368$——「平均 1000 小时坏一次」的系统，恰好 1000 小时不出故障的概率仅 37%。

### 泊松过程的性质汇总

| 性质 | 内容 |
| --- | --- |
| 增量分布 | $N(t+s)-N(s) \sim \pi(\lambda t)$ |
| 均值/方差 | 均为 $\lambda t$ |
| 到达间隔 | $T_i \sim E(\lambda)$ 独立 |
| 第 $n$ 个到达 | $S_n \sim \Gamma(n, \lambda)$ |

**「计数 ↔ 等待」双视角**——泊松分布看数量、指数/伽马看时间，一枚硬币两面。

### 例：模拟泊松过程

模拟到达时刻：生成独立指数 $T_i \sim E(\lambda)$，累加 $S_n = \sum T_i$——$S_n$ 就是第 $n$ 个到达时刻。这是事件驱动模拟的标准做法，也是「泊松 ↔ 指数」性质的数值体现。

**易错点｜辨析：** ① 三条公理（平稳、独立增量、普通）缺一不可——「同刻到达两个」违反普通性；② 泊松的均值 = 方差——样本方差明显不等于均值时，泊松假设存疑；③ 强度 $\lambda$ 是「单位时间平均到达数」，不是「每两次到达间隔」。

再补一张「泊松 vs 二项」对照：

| | 二项分布 | 泊松分布 |
| --- | --- | --- |
| 场景 | $n$ 次试验计数 | 时段内计数 |
| 参数 | $n, p$ | $\lambda$ |
| 均值 | $np$ | $\lambda$ |
| 关系 | $n$ 大 $p$ 小趋近泊松 | — |

「二项是「有界试验」的计数、泊松是「无限可能」的计数」——稀有事件下二项让位给泊松。

## 6 小结

- **泊松过程**：$N(0)=0$ + 独立增量 + 平稳增量 + 普通性；强度 $\lambda$。
- **核心结论**：$N(t) \sim \pi(\lambda t)$，$E[N(t)] = \lambda t$，$\mathrm{Var}(N(t)) = \lambda t$。
- 到达间隔 $T_i$ 独立同分布 $\sim E(\lambda)$——泊松过程 ↔ 指数等待 ↔ 无记忆性。
- 协方差函数 $\mathrm{Cov}(N(s), N(t)) = \lambda\min(s,t)$。
- 从公理到泊松分布靠「无穷小微分方程」，这是随机过程推导的标准方法。
