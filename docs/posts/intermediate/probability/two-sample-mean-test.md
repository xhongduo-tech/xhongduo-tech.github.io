## 为什么从两个正态总体均值差的检验开始

单总体均值检验回答「这个均值是否达标」，双总体均值差检验回答「**两个均值是否相等**」——新药 vs 旧药、方法 A vs 方法 B、男生 vs 女生。这是医学、工程、社会科学里最高频的检验问题，也是第七章「均值差区间估计」的检验版。

双总体均值差检验的两条路线（方差已知/未知且相等）与区间估计完全对应，统计量都是「均值差 − 假设差」除以标准误。它的核心技巧是**合并方差**（方差未知且相等时）与**前提检查**（方差是否相等）。<span class="marginnote">双总体均值差检验的标准流程：<strong>先确认两组样本独立（不独立→成对检验）；再看方差是否相等（相等→合并方差 t；不等→近似 t / Welch）</strong>。这套「独立性检查 + 方差齐性检查」的双重前置，是双总体检验与单总体检验最大的不同，也是真实数据分析里最容易踩坑的地方。</span>

## 1 方差已知的情形：Z 检验

设 $X_1,\ldots,X_{n_1} \sim N(\mu_1, \sigma_1^2)$ 与 $Y_1,\ldots,Y_{n_2} \sim N(\mu_2, \sigma_2^2)$ 独立，$\sigma_1^2, \sigma_2^2$ 已知，检验 $H_0: \mu_1 = \mu_2$（即 $\mu_1 - \mu_2 = 0$）。检验统计量：

$$Z = \frac{\bar X - \bar Y}{\sqrt{\dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2}}} \sim N(0, 1) \quad (\text{当 } H_0 \text{ 真})$$

拒绝域按 $H_1$ 方向：双侧 $\mu_1 \ne \mu_2$ 用 $|Z| \ge z_{\alpha/2}$，右侧 $\mu_1 > \mu_2$ 用 $Z \ge z_\alpha$，左侧类似。<span class="marginnote">分母「$\sqrt{\sigma_1^2/n_1 + \sigma_2^2/n_2}$」是 $\bar X - \bar Y$ 的标准误——「差值的波动 = 两波动之和」（方差可加）。这个结构与第七章均值差区间的分母完全一致，只是把「已知的 $\sigma$」换成「假设差 0」的目标。区间与检验在这里完成汇合：区间「含不含 0」与检验「拒不拒绝 $H_0$」互为镜像。</span>

## 2 方差未知但相等的情形：t 检验

设 $\sigma_1^2 = \sigma_2^2 = \sigma^2$（未知），用合并样本方差

$$S_w^2 = \frac{(n_1 - 1)S_1^2 + (n_2 - 1)S_2^2}{n_1 + n_2 - 2}$$

检验 $H_0: \mu_1 = \mu_2$。检验统计量：

$$T = \frac{\bar X - \bar Y}{S_w\sqrt{\dfrac{1}{n_1} + \dfrac{1}{n_2}}} \sim t(n_1 + n_2 - 2) \quad (\text{当 } H_0 \text{ 真})$$

**例**：两班各 20 人，A 班 $\bar x_1 = 78$、$s_1 = 8$；B 班 $\bar x_2 = 74$、$s_2 = 7$。检验两班平均分是否相等（$\alpha = 0.05$，设方差相等）。

$$S_w^2 = \frac{19\times 64 + 19\times 49}{38} = 56.5, \quad S_w = 7.52$$

$$T = \frac{78 - 74}{7.52\sqrt{1/20 + 1/20}} = \frac{4}{2.38} = 1.68$$

$t_{0.025}(38) \approx 2.024$，$|T| = 1.68 < 2.024$ → **不拒绝 $H_0$**——数据不足以证明两班平均分不同。<span class="marginnote">注意这个例子的启示：$|T| = 1.68$ 距临界值 2.024 差一步，结论是「不显著」——但 78 比 74 高了 4 分。统计不显著不代表「无差异」，只代表「这个样本量下差异不够清晰」。想确认小差异，需要更大样本——「不显著」是证据不足，不是结论为无。</span>

## 3 方差不等的情形：近似 t 检验

若 $\sigma_1^2 \ne \sigma_2^2$（方差齐性检验 F 检验表明不等），合并方差不合适，改用**近似 t 检验（Welch 检验）**：

$$T' = \frac{\bar X - \bar Y}{\sqrt{\dfrac{S_1^2}{n_1} + \dfrac{S_2^2}{n_2}}}, \qquad \text{近似} \sim t(\nu)$$

其中自由度由 **Welch–Satterthwaite 公式**给出：

$$\nu = \frac{\left(\dfrac{S_1^2}{n_1} + \dfrac{S_2^2}{n_2}\right)^2}{\dfrac{(S_1^2/n_1)^2}{n_1 - 1} + \dfrac{(S_2^2/n_2)^2}{n_2 - 1}}$$

<span class="marginnote">Welch 检验「不假设方差相等」，用各组的 $S_i^2/n_i$ 直接作标准误，自由度按近似公式修正（通常不是整数）。它比合并方差 t 更稳健——即使方差真的相等，结果也几乎一样。现代统计软件默认输出 Welch 结果。考试按教材走合并方差版，实务按软件走 Welch 版，两条路都该认识。</span>

**易错点｜辨析：** 双总体均值差检验的三个高频错误——① 两组不独立却用独立样本公式（应改配对检验）；② 方差不等仍用合并方差（应改 Welch）；③ 合并方差的自由度 $n_1 + n_2 - 2$ 写错成 $n_1 + n_2$。

## 4 公式解析：合并方差与 t 的拼装

合并方差 t 统计量是「双总体方差合成 + 单总体 t 结构」的组合，拆开：

$$

T = \frac{(\bar X - \bar Y) - 0}{S_w\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} \sim t(n_1 + n_2 - 2)

$$

- **第一步，分子**：$\bar X - \bar Y - 0$——均值差与假设差 0 的偏离。
- **第二步，分母的标准误**：$S_w\sqrt{\frac1{n_1} + \frac1{n_2}}$——差值的标准误，由合并方差 $S_w^2$ 与两个样本量给出。
- **第三步，分布**：$H_0$ 真时 $T \sim t(n_1 + n_2 - 2)$——自由度是总样本量减 2（两个均值各吃掉一个自由度）。

「分子是差值的偏离、分母是差值的标准误、分布由总自由度定」——这条结构与单总体 t 完全同构，只是「对象从 $\bar X$ 变成 $\bar X - \bar Y$、自由度从 $n-1$ 变成 $n_1+n_2-2$」。记住这个同构，双总体检验无需另记。

## 5 双样本均值检验的深入应用

「两组均值是否相等」是检验的高频问题，它的统计量、前提与实务值得完整展开。

### 例：完整计算

**例**：两班各 20 人，$\bar x_1 = 78$、$s_1 = 8$；$\bar x_2 = 74$、$s_2 = 7$。$S_w^2 = 56.5$、$S_w = 7.52$，$T = \frac{4}{7.52\sqrt{0.1}} = 1.68$，$t_{0.025}(38) = 2.024$，$1.68 < 2.024$ → 不拒绝「均值相等」。

### 统计量的三种情形

| 情形 | 统计量 | 分布 |
| --- | --- | --- |
| 方差已知 | $Z = \frac{\bar X-\bar Y}{\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}}$ | $N$ |
| 方差相等未知 | $T$（合并方差） | $t(n_1+n_2-2)$ |
| 方差不等 | Welch $T'$ | 近似 $t$ |

**「先查方差齐性，再选合并或 Welch」**——方差关系决定用哪个统计量。

### 易错辨析

| 错误 | 后果 |
| --- | --- |
| 不独立却用独立样本 | 方差被高估 |
| 方差不等仍合并 | 检验失真 |
| 自由度写错 | 临界值错 |

### 例：与置信区间的关系

检验「均值相等」等价于「$\mu_1-\mu_2$ 的区间含 0」——**「检验与区间互为对偶」**，报告区间自动携带检验结论。

### 功效与样本量

功效随「均值差与样本量」增大——想检测小差异，需大样本。**「样本量设计 = 定功效 + 定效应量 + 反解 $n$」**是双样本试验的前置工作。

**易错点｜辨析：** ① 合并方差的前提是「方差相等」——不满足用 Welch；② 「不显著」≠「无差异」——可能样本量不足；③ 自由度 $n_1+n_2-2$ 而非 $n_1+n_2$。

## 6 小结

- **方差已知**：$Z = \frac{\bar X - \bar Y}{\sqrt{\sigma_1^2/n_1 + \sigma_2^2/n_2}} \sim N(0,1)$。
- **方差相等未知**：$T = \frac{\bar X - \bar Y}{S_w\sqrt{1/n_1 + 1/n_2}} \sim t(n_1 + n_2 - 2)$，$S_w^2$ 为合并方差。
- **方差不等**：改用 Welch 近似 t，自由度用 Satterthwaite 公式修正。
- 前置检查：**两组独立？方差相等？**——不独立用配对，不等用 Welch。
- 不显著 ≠ 无差异：小样本下「证据不足」与「确实相同」是两回事。
