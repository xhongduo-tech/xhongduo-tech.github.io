## 为什么从假设检验的基本思想开始

第七章用区间估计「猜参数是多少」，第八章换一种问法：**「先立一个说法，看数据支持不支持」**。这说法就是**假设（hypothesis）**，检验假设的过程就是**假设检验（hypothesis testing）**。比如：「新药与旧药疗效相同」「灯泡平均寿命 ≥ 2000 小时」「缺陷率 ≤ 5%」——每一项都是一个待检验的假设。

假设检验是统计推断的另一半：区间估计说「参数可能在哪」，假设检验说「某个说法是否可信」。它的思想源于一个反证逻辑——**「小概率事件在一次试验中几乎不会发生」**：若在假设成立的条件下，观测到的数据出现的概率极小，就质疑这个假设。<span class="marginnote">假设检验的雏形可以追溯到 17 世纪的「无理数之争」，但现代框架由费希尔（显著性检验）与内曼—皮尔逊（两类错误、检验功效）在 1920–1933 年间奠定。前者是「这个数据有多不寻常」，后者是「这个判决有多可靠」——两种视角的融合，就是今天教材里的假设检验。</span>

## 1 原假设与备择假设

**假设检验**的起手式是设定两个对立的假设：

- **原假设（null hypothesis）** $H_0$：被检验的、默认成立的说法，通常是「没有差异」「没有效果」——「null」就是「零效应」；
- **备择假设（alternative hypothesis）** $H_1$：与原假设对立的说法，是「有差异」「有效果」。

**例**：检验某灯泡平均寿命是否达标（标准 2000 小时）：

$$H_0:\ \mu = 2000 \quad\text{vs}\quad H_1:\ \mu \ne 2000$$

**原则**：原假设通常是「保守的、需要证据才能推翻的」——把「指控」放在 $H_1$，把「无辜」放在 $H_0$。数据异常强时才能拒绝 $H_0$，就像「疑罪从无」。<span class="marginnote">为什么默认 $H_0$ 是「没效果」而不是「有效果」？因为<strong>「没有证据表明有效」≠「有效」</strong>——把「没有效果」设为默认，要求数据提供充分证据才肯承认「有效果」，是对「新结论」最苛刻的门槛。这也是医学试验里「新药 vs 安慰剂」用 $H_0$: 无差异的哲学依据：没有过硬证据，不轻信新药。</span>

## 2 拒绝域与检验规则

检验的依据是样本构造一个**检验统计量** $T$，并划定**拒绝域（rejection region）** $W$：若 $T$ 落入 $W$，拒绝 $H_0$；否则不拒绝 $H_0$。

**例（灯泡检验）**：设 $\sigma = 100$ 已知，样本量 $n = 25$。检验 $H_0: \mu = 2000$ vs $H_1: \mu \ne 2000$。检验统计量 $Z = \frac{\bar X - 2000}{100/\sqrt{25}} = \frac{\bar X - 2000}{20}$。显著性水平 $\alpha = 0.05$ 时，拒绝域 $W = \{|Z| \ge 1.96\}$——**若 $\bar X$ 偏离 2000 超过 $1.96 \times 20 = 39.2$ 小时，就拒绝 $H_0$**。

**「不拒绝」≠「接受」**：$T$ 不在 $W$ 里只能说「没有足够证据拒绝 $H_0$」，不能说「$H_0$ 是真的」——证据不足与事实为真，是两回事。<span class="marginnote">「不拒绝 $H_0$」≠「接受 $H_0$」是假设检验最重要的语言习惯：就像法庭「证据不足、罪名不成立」不等于「确认无罪」。统计上，我们只能说「数据与 $H_0$ 不矛盾」，不能说「$H_0$ 被证实」——因为检验的效力有限，样本量小可能掩盖真实差异。</span>

## 3 两类错误

检验可能犯两种错误，内曼—皮尔逊把它系统化：

| | $H_0$ 为真 | $H_0$ 为假 |
| --- | --- | --- |
| **不拒绝 $H_0$** | 正确 | **第二类错误（取伪）** $\beta$ |
| **拒绝 $H_0$** | **第一类错误（弃真）** $\alpha$ | 正确 |

- **第一类错误（弃真，Type I error）**：$H_0$ 为真却拒绝了——「冤枉好人」，概率记为 $\alpha$；
- **第二类错误（取伪，Type II error）**：$H_0$ 为假却没拒绝——「放过坏人」，概率记为 $\beta$。

**显著性水平（significance level）** $\alpha$ 就是我们**允许犯第一类错误的最大概率**——通常取 0.05 或 0.01。**检验的功效（power）** $= 1 - \beta$，是「正确拒绝假 $H_0$」的概率。<span class="marginnote">两类错误的紧张关系是检验理论的中心矛盾：样本量固定时，压低 $\alpha$（严格不冤枉好人）必然抬高 $\beta$（容易放过坏人）——就像法院「宁可错放也不枉判」必然导致「漏网率」上升。唯一的出路是增大样本量：样本越多，两类错误能同时变小。这个「$\alpha$–$\beta$ 权衡 + 样本量」的三角关系，是整个假设检验设计的骨架。</span>

## 4 例：两类错误的计算

**例**：$X \sim N(\mu, 100)$，$n = 25$，检验 $H_0: \mu = 2000$ vs $H_1: \mu \ne 2000$，$\alpha = 0.05$。拒绝域 $|\bar X - 2000| \ge 39.2$。

第一类错误概率（$H_0$ 真时）：
$$\alpha = P\{|\bar X - 2000| \ge 39.2 \mid \mu = 2000\} = 0.05 \quad (\text{由构造保证})$$

第二类错误概率（设真实 $\mu = 2050$ 时）：
$$\beta = P\{|\bar X - 2000| < 39.2 \mid \mu = 2050\} = P\{1960.8 < \bar X < 2039.2 \mid \mu = 2050\}$$

$\bar X \sim N(2050, 4)$（$\sigma/\sqrt n = 2$），标准化：$\beta = \Phi\left(\frac{2039.2 - 2050}{2}\right) - \Phi\left(\frac{1960.8 - 2050}{2}\right) = \Phi(-5.4) - \Phi(-44.6) \approx 0$。

真实均值偏离 50 小时时，几乎不会漏判。若真实 $\mu = 2005$（偏离很小），$\beta$ 会接近 1——**差异越小越难检测，第二类错误越大**。<span class="marginnote">「功效随真实差异增大而提高」是检验力设计的核心：想检测出「小差异」，需要大样本。医学试验的「样本量计算」就是在定「想以 80% 功效检出多大的疗效差异」——确定 $\alpha$、$\beta$、效应量，反解所需 $n$。这是临床试验设计的第一步，也是「样本量」在检验语境下的意义。</span>

## 5 假设检验的深入辨析与实例

检验的基本思想之外，有四个必须吃透的细节：两类错误的计算、功效的直觉、显著性 vs 实际重要性、以及检验的哲学前提。

### 两类错误的计算实例

**例**：$X \sim N(\mu, 100)$，$n = 25$，$H_0: \mu = 2000$ vs $H_1: \mu \ne 2000$，$\alpha = 0.05$。拒绝域 $|\bar X - 2000| \ge 39.2$。

第一类错误（$H_0$ 真）：$\alpha = P\{|\bar X - 2000| \ge 39.2 \mid \mu = 2000\} = 0.05$——由构造保证。

第二类错误（真实 $\mu = 2040$）：$\beta = P\{1960.8 < \bar X < 2039.2 \mid \mu = 2040\} = \Phi(\frac{2039.2-2040}{2}) - \Phi(\frac{1960.8-2040}{2}) = \Phi(-0.4) - \Phi(-39.6) \approx 0.345$——真实均值偏离 40 时，约 34.5% 的概率漏判。

### 功效随差异与样本量变化

| 真实 $\mu$ | 功效 $1-\beta$ |
| --- | --- |
| 2005 | 低（约 0.09） |
| 2020 | 中（约 0.52） |
| 2040 | 较高（约 0.65） |
| 2060 | 高（约 0.80） |

**功效随「真实差异」增大而提高**——想检测小差异，需大样本或更精细的设计。

### 统计显著 vs 实际重要

「p < 0.05」只说明「差异不像随机波动」，**不代表「差异重要」**：样本量大时微小差异也显著，样本量小时大差异也可能不显著。判断「重要」要看效应量与置信区间，不能只看 p 值。

### 检验的哲学：频率学派的前提

假设检验的结论是「在反复抽样意义下」的概率陈述——「拒绝 $H_0$」意为「若 $H_0$ 真，出现如此极端数据的概率 < α」。它不回答「$H_0$ 为真的概率是多少」（那是贝叶斯问题，需要先验）。理解这个前提，才不会被「p 值 = $H_0$ 成立概率」的误读带偏。

**易错点｜辨析：** ① 「不拒绝」≠「接受」——证据不足不等于事实为真；② $\alpha$ 与 $\beta$ 不能同时任意小——增大样本量是唯一双赢出路；③ 检验前必须「先定 $H_0$、$H_1$、$\alpha$」，看完数据再定是舞弊。

再补一张「两类错误」的记忆卡：

| | $H_0$ 真 | $H_0$ 假 |
| --- | --- | --- |
| 不拒绝 | 正确 | 第二类错误 $\beta$ |
| 拒绝 | 第一类错误 $\alpha$ | 正确（功效 $1-\beta$） |

「α 管冤枉、β 管放过、n 管两者」——三类错误的记忆口诀，检验设计的全部权衡。

## 6 小结

- **假设检验**：设 $H_0$（默认/无效应）与 $H_1$（对立/有效应），用样本判「证据是否足够推翻 $H_0$」。
- **拒绝域** $W$：检验统计量落入即拒绝 $H_0$；「不拒绝」≠「接受」。
- **第一类错误（弃真）** $\alpha$ = 冤枉好人的概率，即**显著性水平**；**第二类错误（取伪）** $\beta$ = 放过坏人的概率，功效 $= 1-\beta$。
- $\alpha$ 与 $\beta$ 此消彼长，增大样本量可同时压低两者。
- 原假设默认「无效应」，要求数据提供充分证据才肯推翻——「疑罪从无」的统计版。
