## 为什么从 bootstrap-t 开始

经典的 t 检验建立在「统计量服从 t 分布」上——这要求正态总体（或 CLT）。当分布未知、统计量复杂时，t 分布不适用。**bootstrap-t 方法**用 bootstrap 模拟出检验统计量的分布，从而把 t 检验的框架推广到任意情形：**用「模拟的分位点」替代「解析表的临界值」**。

bootstrap-t 是 bootstrap 在假设检验里的主力形态，它让「t 检验、均值差检验、比例检验」都能在解析公式失效时照常进行。它把第八章的检验思想与第十章的模拟工具缝合在一起，是「计算时代的假设检验」。<span class="marginnote">bootstrap 检验的思想一句话：<strong>检验「$\theta = \theta_0$」时，把样本平移/重标定到满足 $H_0$，再 bootstrap 模拟出统计量在 $H_0$ 下的分布，用模拟分布算 p 值</strong>。关键在「构造 $H_0$ 下的样本」——这是 bootstrap 检验与 bootstrap 区间的根本区别。</span>

## 1 bootstrap-t 方法

**bootstrap-t（studentized bootstrap）** 的流程：

1. **构造检验统计量**：$t = \frac{\hat\theta - \theta_0}{\widehat{se}(\hat\theta)}$（对假设值 $\theta_0$）；
2. **bootstrap 复制**：对每个 bootstrap 样本算「学生化」统计量 $t^{*b} = \frac{\hat\theta^{*b} - \hat\theta}{\widehat{se}^*(\hat\theta^{*b})}$——用 bootstrap 样本估计标准误；
3. **模拟分布**：$B$ 个 $t^{*b}$ 构成「$t$ 的 bootstrap 分布」；
4. **p 值**：p 值 = $t^{*b}$ 中比观测 $t$ 更极端的比例。

**与普通 t 检验的区别**：临界值不查 t 表，而取自 bootstrap 模拟分布——更适应非正态、复杂统计量。<span class="marginnote">「学生化」=「除以自己的标准误估计」：$t^{*b} = (\hat\theta^{*b} - \hat\theta)/\widehat{se}^*$ 模仿了 $t = (\hat\theta - \theta)/se(\hat\theta)$ 的「标准化偏离」结构。通过学生化，bootstrap 复制的分布更接近「枢轴量」的分布，p 值更准。这是 bootstrap-t 比普通 bootstrap 区间更精确的原因——它把「标准误的波动」也模拟进去了。</span>

## 2 bootstrap 假设检验的通用套路

对一般检验「$H_0: \theta = \theta_0$」，bootstrap 检验的通用流程：

1. **构造 $H_0$ 下的样本**：把样本平移（或重标定）使其满足 $H_0$——例如检验均值 $\mu = \mu_0$，构造 $x_i' = x_i - \bar x + \mu_0$（样本均值变成 $\mu_0$）；
2. **从 $H_0$ 样本 bootstrap**：对 $x_i'$ 放回抽样，算统计量，得 $H_0$ 下的复制分布；
3. **算 p 值**：观测统计量在 $H_0$ 复制分布中的位置决定 p 值。

**关键**：bootstrap 样本必须从「满足 $H_0$ 的数据」抽，否则模拟的分布不对应 $H_0$，p 值失真。<span class="marginnote">「先让数据服从 $H_0$ 再 bootstrap」是 bootstrap 检验最容易出错的一步：直接对原始样本 bootstrap 得到的是「$\hat\theta$ 的分布」（对应观测数据），不是「$H_0$ 下的分布」。平移修正（$x_i' = x_i - \bar x + \mu_0$）确保模拟抽样时「$\theta = \theta_0$」——这一步叫「以 $H_0$ 为中心化」。遗漏它，p 值完全错误。</span>

## 3 bootstrap 检验的应用

**均值检验（非正态）**：总体明显偏态，t 检验的分布假设存疑——bootstrap t 照常检验；
**比例检验**：小样本比例的精确 p 值，bootstrap 直接模拟；
**复杂统计量的显著性**：相关系数、中位数差、比值等，解析检验不存在，bootstrap 是标准替代。

**例（中位数差的检验）**：两组收入中位数之差 $\hat d = 3$ 万元。检验「中位数无差异」：把两组数据合并、重排（置换的思想），或平移后 bootstrap，模拟 $d^*$ 的分布，算「$|d^*| \ge 3$」的比例得 p 值。若 p < 0.05，中位数差显著。<span class="marginnote">「中位数差」是 bootstrap 检验的典型舞台：解析的检验统计量几乎不存在（中位数的抽样分布难以解析），但 bootstrap 三行代码就给出 p 值。这类「解析无解、模拟可解」的问题，是 bootstrap 检验存在的全部理由——第八、九章的解析检验覆盖不到的角落，由它补位。</span>

**易错点｜辨析：** ① 检验必须用「$H_0$ 化的样本」bootstrap，不能直接用原样本；② p 值 =「复制比观测更极端的比例」——方向（单侧/双侧）与检验的 $H_1$ 一致；③ bootstrap 检验是近似（$n$ 需足够大），样本过小时结论要谨慎；④ 置换检验（permutation test，无放回重排）是 bootstrap 检验的亲戚，两者常被并列使用。

## 4 公式解析：p 值的 bootstrap 计算

bootstrap 检验的 p 值计算，拆开它的结构：

$$

p = \frac{1}{B}\sum_{b=1}^{B} \mathbf{1}\left\{|t^{*b}| \ge |t_{\text{obs}}|\right\}

$$

- **第一步，观测统计量**：$t_{\text{obs}}$——由原始样本算出的检验统计量。
- **第二步，$H_0$ 复制**：$t^{*1}, \ldots, t^{*B}$——从「$H_0$ 化的样本」bootstrap 得到的统计量复制。
- **第三步，计数比例**：$p$ = 「复制比观测更极端」的比例——用指示函数求和再平均。p 值小说明观测值在 $H_0$ 分布里罕见，拒绝 $H_0$。

「数一数模拟里有多少个比观测更极端」是 bootstrap 检验 p 值的全部机制。它把「查表定 p 值」变成「数模拟比例」——同样的 $H_0$ 逻辑，换成计算机来执行。

## 5 bootstrap 检验的深入与对照

bootstrap 检验不是孤立的技巧，它与经典检验、置换检验构成一个「检验工具谱系」，理解它们在谱系中的位置才能选对工具。

### 置换检验：bootstrap 检验的亲戚

**置换检验（permutation test）**与 bootstrap 检验思想同源、做法略异：它不「放回抽样」，而是「无放回重排」——把两组数据合并后随机重排，反复计算统计量，用「重排后比观测更极端的比例」做 p 值。差别在于：

| | bootstrap 检验 | 置换检验 |
| --- | --- | --- |
| 重抽样方式 | 有放回 | 无放回重排 |
| 适用 | 单样本/双样本、任意统计量 | 两样本比较（组标签重排） |
| 原理 | 经验分布 ≈ 总体 | 重排后「组无差异」成立 |

置换检验在「两样本差异」检验里尤其自然——它直接模拟「组标签随机打乱」，p 值精确（无需大样本近似）。

### bootstrap 检验 vs 解析检验

| | 解析检验（t/z） | bootstrap 检验 |
| --- | --- | --- |
| 分布假设 | 正态/CLT | 经验分布近似总体 |
| p 值 | 查表 | 模拟计数 |
| 适用范围 | 常规统计量 | 任意统计量（中位数差、比值等） |
| 功效 | 模型正确时高 | 相近（$n$ 足够大时） |

**选型原则**：数据接近正态、统计量常规 → 用解析检验（更精确高效）；分布未知、统计量复杂、小样本 → 用 bootstrap/置换。

### 两类错误与功效的 bootstrap 视角

bootstrap 检验同样受「$\alpha$–$\beta$ 权衡」支配：样本量小时功效不足，「不显著」可能只是「检测力不够」。用模拟可以估计 bootstrap 检验的功效——反复在「真实存在差异」的假设下抽样，统计「拒绝 $H_0$」的比例即为功效。这个「模拟估计功效」的做法让 bootstrap 检验的使用者能清楚知道自己「能不能检测出想要的差异」。

### 例：中位数差的 bootstrap 检验

两组收入中位数差 $\hat d = 3$ 万元。把两组数据合并、反复重排（或平移后 bootstrap），得 $d^*$ 的分布，统计「$|d^*| \ge 3$」的比例。若 p = 0.03 < 0.05，中位数差显著——解析检验对此无从下手，bootstrap 三行代码搞定。

最后补一个实务提醒：bootstrap/置换检验的 p 值有「模拟误差」——$B$ 有限时 p 值的精度约 $1/\sqrt B$，$B = 1000$ 时 p 值约 ±0.016。若 p 值恰在 0.05 附近，增大 $B$（如 10000）再确认，别让模拟噪声决定结论。另外，置换检验的 p 值更「精确」（重排是穷举的抽样），bootstrap 的 p 值更「通用」（适合任意统计量）——两者互补，理解差异才能各取所长。

再补一张「三类检验工具」的选型表，把检验方法的谱系一次收齐：

| 方法 | 假设 | 最适用场景 | p 值来源 |
| --- | --- | --- | --- |
| 解析检验（t/z） | 正态/CLT | 常规统计量、模型可信 | 查表 |
| bootstrap 检验 | 经验分布≈总体 | 任意统计量、分布未知 | 模拟计数 |
| 置换检验 | 组标签无差异 | 两样本比较、小样本 | 重排计数 |

「模型可信用解析、分布未知用 bootstrap、两样本重排用置换」——选对工具，检验结论才站得住。

## 6 小结

- **bootstrap-t**：学生化统计量 $t^* = (\hat\theta^* - \hat\theta)/\widehat{se}^*$ 的模拟分布替代 t 表，p 值从模拟比例读出。
- **$H_0$ 化**：先平移/重标定样本使其满足 $H_0$，再从 $H_0$ 样本 bootstrap——检验与区间的关键区别。
- 应用：非正态均值、比例、中位数差、相关系数等「解析无解」的检验。
- p 值 =「复制比观测更极端的比例」，方向随 $H_1$ 定。
- bootstrap 检验用计算换普适，是解析检验失效时的标准补位工具。
