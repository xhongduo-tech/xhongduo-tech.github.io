## 为什么从期望的性质开始

会算单个期望还不够，统计问题里期望往往带着一大堆参数与运算：$E[aX + b]$、$E[XY]$、$E[X + Y + Z]$。这些「期望的运算规则」就是**期望的性质**——一组极简却威力无穷的代数法则，让复杂期望能够拆成简单期望的组合。学好本节，等于给「算期望」装上了一套自动化的流水线。

期望的性质是全章的数字引擎：方差、协方差、矩的计算全部从这里起步；第五章大数定律的核心证明也只依赖期望线性性与切比雪夫不等式。<span class="marginnote">期望的运算规则可以浓缩成一句话：<strong>加法线性无条件，乘法可拆须独立</strong>。加法随时拆，常数随便提，而 $E[XY] = E[X]E[Y]$ 只在 $X,Y$ 独立时成立——这是期望性质里唯一需要「看条件」的一条，也是出题人最爱设的陷阱。</span>

## 1 常数与线性：无条件可拆

设 $a, b$ 为常数，$X$ 为随机变量，则

1. $E[C] = C$——常数的期望就是它自己；
2. $E[aX] = a\,E[X]$——常数可提出，无需任何条件；
3. $E[X + b] = E[X] + b$——常数平移直接加；
4. $E[aX + b] = a\,E[X] + b$——合写。

这些规则全部来自期望的线性性，且**对任何随机变量成立**，不管独立与否。它们让「把期望里的常数与系数剥离」变得机械化。

**例**：某商品的日销量 $X$ 的期望 $E[X] = 120$，每件利润 5 元、固定成本 200 元，日利润 $Y = 5X - 200$。$E[Y] = 5 \times 120 - 200 = 400$ 元——常数与系数一次剥离，无需知道销量分布。

## 2 和与差的期望：线性性

对任意随机变量 $X, Y$（**不要求独立**）：

$$E[X + Y] = E[X] + E[Y], \qquad E[X - Y] = E[X] - E[Y]$$

推广到 $n$ 个变量：$E[X_1 + \cdots + X_n] = E[X_1] + \cdots + E[X_n]$。这条「和的期望 = 期望的和」是无条件成立的，是统计推断里最常用的武器。<span class="marginnote">一个让人惊讶的推论：即使 $X$ 与 $Y$ 强烈正相关，$E[X+Y] = E[X] + E[Y]$ 依然成立。比如 $Y = X$，则 $E[X + Y] = 2E[X] = E[X] + E[Y]$——没问题。线性性对「相关」完全免疫，这正是它比方差强大的地方。</span>

**例（指示函数）**：设事件 $A_1, \ldots, A_n$，$I_i = \mathbf{1}_{A_i}$ 为指示函数。则 $E[I_i] = P\{A_i\}$，于是「$A_i$ 中发生个数的期望」为

$$E\left[\sum_i I_i\right] = \sum_i P\{A_i\}$$

即使 $A_i$ 相互依赖，这个期望仍成立——**期望线性性让「相关事件的计数期望」无需独立性也能算**。这是组合概率题里「线性期望法」的根基。

## 3 乘积的期望：独立才可拆

乘法的规则是唯一的例外：

$$X \text{ 与 } Y \text{ 独立} \implies E[XY] = E[X]\, E[Y]$$

若 $X$、$Y$ 不独立，一般 $E[XY] \ne E[X]E[Y]$——差 $E[XY] - E[X]E[Y]$ 正是第四章第三节**协方差**的定义。<span class="marginnote">记住这条对比就抓住了期望性质的精髓：加法无需条件，乘法需要独立。更一般地，$E[g(X)h(Y)] = E[g(X)]\,E[h(Y)]$ 在 $X,Y$ 独立时成立——它是「函数也独立」的期望版本，在计算协方差、矩母函数时反复使用。</span>

**例**：$X \sim B(n_1, p)$、$Y \sim B(n_2, p)$ 独立。则 $E[XY] = E[X]E[Y] = n_1p \cdot n_2p = n_1 n_2 p^2$。若不独立，这个式子没有意义——这也是为什么独立假设在计算里如此珍贵。

**易错点｜辨析：** $E[XY] = E[X]E[Y]$ 的**逆命题不成立**。$E[XY] = E[X]E[Y]$（即协方差为 0、不相关）推不出独立——第三章见过的 $Y = X^2$（$X \sim U(-1,1)$）就是反例：$E[XY] = E[X^3] = 0 = E[X]E[Y]$，但 $Y$ 完全由 $X$ 决定。**独立 ⇒ 不相关，不相关 ⇏ 独立**，除了二维正态这个例外。

## 4 公式解析：把复杂期望拆成小块的套路

期望性质的真正威力在「**拆解**」：把复杂随机变量表示成「小块的线性组合」，逐块取期望。以「无放回抽样的次品数」为例：

$$

E[X] = E\left[\sum_{i=1}^{n} I_i\right] = \sum_{i=1}^{n} E[I_i] = \sum_{i=1}^{n} P\{I_i = 1\}

$$

- **第一步，定义指示变量**：$I_i$ =「第 $i$ 次抽到次品」，$X = \sum I_i$。这是把「计数」翻译成「指示变量之和」的万能手法。
- **第二步，逐项取期望**：$E[I_i] = P\{\text{第 } i \text{ 次抽到次品}\} = M/N$，与第几次无关（不放回也不影响对称性）。
- **第三步，线性求和**：$E[X] = n \cdot \frac{M}{N}$——不放回抽 $n$ 件的次品数期望就是 $n \times$ 次品率，**与是否放回无关**。

注意：这里全程没碰超几何分布的复杂组合式，也没用独立性——纯靠线性期望法一步到位。这种「指示变量 + 线性性」是全书最优雅的计算工具之一，第五章大数定律、第七章估计量评估都会复用。

## 5 期望性质的深入应用与实例

期望的性质是「算期望的流水线」，它们的证明、直觉与陷阱值得完整展开。

### 例：线性性无条件成立

**例**：$X$、$Y$ 任意（不要求独立），$E[X + Y] = E[X] + E[Y]$——「和的期望 = 期望的和」永远成立，哪怕 $X$ 与 $Y$ 完全相关。**「加法线性无条件」**是期望区别于方差的最大优点。

### 例：乘法需要独立

**例**：$X, Y$ 独立时 $E[XY] = E[X]E[Y]$；不独立时一般不等。差 $E[XY] - E[X]E[Y]$ 正是**协方差**——「乘法可拆的缺口就是协方差」。

### 期望性质的速查

| 性质 | 条件 | 公式 |
| --- | --- | --- |
| 常数 | 无 | $E[C] = C$ |
| 线性 | 无 | $E[aX+b] = aE[X]+b$ |
| 和 | 无 | $E[\sum X_i] = \sum E[X_i]$ |
| 积 | 独立 | $E[XY] = E[X]E[Y]$ |
| 函数 | 无 | $E[g(X)]$ 用 LOTUS |

**「加法、常数、线性无条件；乘法要独立」**——一张表记全。

### 例：线性期望法

**例**：$n$ 次独立试验，$X$ = 成功次数。$X = \sum I_i$，$E[X] = \sum E[I_i] = np$——**「指示变量 + 线性性」算出二项期望，无需组合求和**。

### 例：证明技巧

**例**：证明「不相关时 $E[XY] = E[X]E[Y]$ 推不出独立」——用 $Y = X^2$（$X \sim U(-1,1)$）：$E[XY] = E[X^3] = 0 = E[X]E[Y]$，但 $Y$ 完全由 $X$ 决定。**「期望等式是弱条件」**——不相关 ≠ 独立。

**易错点｜辨析：** ① $E[g(X)] \ne g(E[X])$——期望不穿函数，方差公式 $E[X^2]-(E[X])^2$ 正建在这个差别上；② 乘法公式的「独立」前提不可省略；③ 线性期望法适用于「相关事件的计数」——独立不必要，线性性就够。

## 6 小结

- **期望的性质**：常数 $E[C] = C$，线性 $E[aX+b] = aE[X]+b$，和的线性性 $E[\sum X_i] = \sum E[X_i]$ **全部无条件成立**。
- **乘法的期望** $E[XY] = E[X]E[Y]$ **仅在独立时成立**；差 $E[XY] - E[X]E[Y]$ 就是协方差。
- **不相关 ⇏ 独立**：$E[XY] = E[X]E[Y]$ 是「不相关」，独立性更强。
- **指示变量 + 线性性**是计算「计数期望」的万能武器，无需独立、无需枚举。
- 期望性质是方差、协方差、矩以及大数定律证明的公共地基。
