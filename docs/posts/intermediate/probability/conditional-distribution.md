## 为什么从条件分布开始

第一章我们学过条件概率 $P(A \mid B)$：知道 $B$ 发生后，$A$ 的概率被重新评估。现在把同样的思想升级到随机变量层面：**给定 $Y = y$ 之后，$X$ 的分布是什么？** 这就是**条件分布（conditional distribution）**——它是条件概率在「整条分布」上的推广。

条件分布的价值在统计推断里是根本性的：贝叶斯公式的核心对象是「后验分布」——一种条件分布；回归分析建模的「$Y$ 关于 $X$ 的条件期望」也来自条件分布；甚至大模型里的「给定上文预测下一个 token」，本质就是条件分布。可以说，**条件分布是概率论从「描述随机性」走向「用信息做推断」的转折点**。<span class="marginnote">一句话抓住条件分布的本质：它是「切片」。联合分布是整座山，$X \mid Y = y$ 是沿直线 $Y = y$ 切一刀后，把切面上的密度归一化得到的截面分布。固定 $y$，重新归一，剩下的就是 $X$ 在知道 $Y=y$ 后的分布。</span>

## 1 离散情形的条件分布律

设 $(X,Y)$ 的联合分布律为 $p_{ij}$，边缘分布律为 $p_{i\cdot}$、$p_{\cdot j}$。则在 $Y = y_j$ 条件下 $X$ 的**条件分布律（conditional distribution law）**为

$$P\{X = x_i \mid Y = y_j\} = \frac{p_{ij}}{p_{\cdot j}}, \qquad p_{\cdot j} > 0$$

条件分布律仍满足分布律的两条性质：非负且 $\sum_i P\{X=x_i \mid Y=y_j\} = \frac{\sum_i p_{ij}}{p_{\cdot j}} = 1$——**列内归一**。<span class="marginnote">条件分布律的归一化是自动的：分子 $p_{ij}$ 在该列上求和等于分母 $p_{\cdot j}$，比值之和为 1。这也给出一个实用的自检：固定 $y_j$ 后把该列所有条件概率加起来，必须得 1，否则说明算错了。</span>

**例**：设联合分布律某列为 $p_{1j} = 0.1, p_{2j} = 0.3$，列和 $p_{\cdot j} = 0.4$。则 $P\{X=x_1 \mid Y=y_j\} = 0.25$，$P\{X=x_2 \mid Y=y_j\} = 0.75$，和为 1 ✓。

## 2 连续情形的条件密度

连续情形没有「$P\{Y = y\}$」（单点概率为零），但可以用密度定义条件。设联合密度为 $f(x,y)$，边缘密度为 $f_Y(y) > 0$，则给定 $Y = y$ 时 $X$ 的**条件概率密度（conditional density）**为

$$f_{X \mid Y}(x \mid y) = \frac{f(x, y)}{f_Y(y)}$$

它满足密度的两条性质：非负且 $\int_{-\infty}^{+\infty} f_{X\mid Y}(x \mid y)\, dx = \frac{\int f(x,y)\,dx}{f_Y(y)} = \frac{f_Y(y)}{f_Y(y)} = 1$。**分母 $f_Y(y)$ 起着「归一化常数」的作用**——把切面上的密度调整到总面积为 1。<span class="marginnote">这里藏着连续情形最细腻的一点：$P\{Y = y\}$ 明明是 0，为什么还能定义「给定 $Y=y$」？答：条件密度 $f_{X\mid Y}(x\mid y)$ 不是在「概率为 0 的事件」上取条件，而是对每个 $y$ 定义了一个密度函数——它是 $y$ 的一个连续族。这正是「以密度代概率」的功力所在。</span>

**例**：设 $f(x,y) = \begin{cases} 2, & 0 \le x \le 1,\ 0 \le y \le x \\ 0, & \text{其他} \end{cases}$（三角形域上的均匀分布）。先求 $f_Y(y) = \int_y^1 2\,dx = 2(1-y)$（$0\le y \le 1$），则

$$f_{X\mid Y}(x \mid y) = \frac{2}{2(1-y)} = \frac{1}{1-y}, \qquad y \le x \le 1$$

给定 $Y = y$ 后，$X$ 在区间 $[y, 1]$ 上均匀——「固定 $y$ 的切面是均匀的」，这是二维均匀分布的条件分布保持均匀的漂亮结论。

## 3 条件分布与全概率、贝叶斯公式

条件分布把第一章的两个公式升级到「分布」层面。**全概率公式（连续版）**：

$$f_X(x) = \int_{-\infty}^{+\infty} f_{X \mid Y}(x \mid y)\, f_Y(y)\, dy$$

「$X$ 的密度 = 各 $Y$ 条件下的密度按 $Y$ 的边缘密度加权积分」。**贝叶斯公式（连续版）**：

$$f_{Y \mid X}(y \mid x) = \frac{f_{X \mid Y}(x \mid y)\, f_Y(y)}{f_X(x)} = \frac{f_{X \mid Y}(x \mid y)\, f_Y(y)}{\int f_{X \mid Y}(x \mid y')\, f_Y(y')\, dy'}$$

后验密度 ∝ 似然 × 先验密度。这是贝叶斯统计的发动机：**先验 $f_Y(y)$ 被观测数据（似然 $f_{X\mid Y}(x\mid y)$）更新为后验 $f_{Y\mid X}(y\mid x)$**。<span class="marginnote">贝叶斯公式的连续版是理解「机器学习里模型参数推断」的最小模型：参数 $\theta$ 有先验分布，看到数据 $x$ 后用似然更新，得到参数的后验分布。第八章假设检验的贝叶斯解读、大模型里「后验概率」的提法，源头都在这一行公式。</span>

**易错点｜辨析：** 条件密度 $f_{X\mid Y}(x\mid y)$ 与边缘密度 $f_X(x)$ 是两回事，不要混写分母。常见错误：把 $f_{Y}(y)$ 的位置写成 $f_Y(x)$，或在贝叶斯公式里忘了分母是积分（归一化）。另一个坑：**条件密度在给定 $y$ 处**作为 $x$ 的函数要归一，作为 $y$ 的函数则不需要——归一化的轴要看清。

## 4 公式解析：从联合到条件的归一化

条件密度公式的推导只有一行，但值得逐层拆开：

$$

f_{X \mid Y}(x \mid y) = \frac{f(x, y)}{f_Y(y)}

$$

- **第一步，为什么是比**：把「给定 $Y=y$」理解为「只看直线 $Y = y$ 上的联合密度」。$f(x,y)$ 沿这条直线的取值大小不一，直接当分布用不合法（面积不一定为 1）。
- **第二步，分母是积分**：$f_Y(y) = \int f(x,y)\,dx$ 恰是「该直线上的总密度」，把它当归一化常数，比值 $\frac{f(x,y)}{f_Y(y)}$ 对 $x$ 积分恰好为 1。
- **第三步，与离散对照**：离散版 $p_{ij}/p_{\cdot j}$ 分子是格子概率、分母是列和；连续版分子是联合密度、分母是边缘密度。**两个版本结构完全同构，只是求和换积分**。

这套「固定一个变量 → 取截面 → 除以截面总质量」的操作，是条件分布的唯一构造方法，也是贝叶斯公式、回归分析里反复出现的骨架。

## 5 条件分布的深入应用与实例

条件分布是「信息更新」的工具，它的计算、贝叶斯联系与回归意义值得展开。

### 例：离散条件分布律

**例**：联合分布律某行：$p_{1j} = 0.1$、$p_{2j} = 0.3$，列和 $p_{\cdot j} = 0.4$。给定 $Y = y_j$：

$$P\{X = x_1 \mid Y = y_j\} = \frac{0.1}{0.4} = 0.25, \qquad P\{X = x_2 \mid Y = y_j\} = 0.75$$

**「列内归一」**——条件分布律的和恒为 1。

### 例：连续条件密度

**例**：$f(x,y) = 2$（三角域 $0 \le y \le x \le 1$）。$f_Y(y) = 2(1-y)$，则 $X \mid Y = y \sim U(y, 1)$：

$$f_{X\mid Y}(x \mid y) = \frac{2}{2(1-y)} = \frac{1}{1-y}, \qquad y \le x \le 1$$

**「固定 $y$ 的切面是均匀的」**——二维均匀的条件保持均匀。

### 条件分布与回归

| 概念 | 条件分布的视角 |
| --- | --- |
| 回归线 | $E[Y \mid x]$ 是条件均值 |
| 残差 | $Y - E[Y\mid x]$ 的分布 |
| 独立性 | $f_{Y\mid X} = f_Y$ |
| 贝叶斯 | 后验 = 条件分布 |

**「条件期望 = 回归」**是条件分布最重要的应用——第九章回归的本质是条件均值建模。

### 贝叶斯公式的条件分布版

$$f_{Y\mid X}(y \mid x) = \frac{f_{X\mid Y}(x \mid y)\, f_Y(y)}{\int f_{X\mid Y}(x\mid y')\, f_Y(y')\, dy'}$$

**「后验 ∝ 似然 × 先验」**——贝叶斯推断的全部核心在这一行，大模型的「给定上文预测下文」也是条件分布。

**易错点｜辨析：** ① 条件密度作为 $x$ 的函数要归一，作为 $y$ 的函数不归一——归一化的轴要看准；② 连续条件分布是「密度比」，不是「事件概率」（$P\{Y=y\}$ 为零）；③ 「条件分布 = 边缘分布」当且仅当独立——别想当然。

## 6 小结

- **离散条件分布律** $P\{X=x_i \mid Y=y_j\} = p_{ij}/p_{\cdot j}$——列内归一。
- **连续条件密度** $f_{X\mid Y}(x\mid y) = f(x,y)/f_Y(y)$——切面除以边缘密度归一。
- **全概率公式（连续）**：$f_X(x) = \int f_{X\mid Y}(x\mid y) f_Y(y)\,dy$。
- **贝叶斯公式（连续）**：后验 ∝ 似然 × 先验，是贝叶斯统计与机器学习推断的发动机。
- 条件分布是「信息介入后概率的重排」：知道 $Y=y$，$X$ 的分布随之更新。

在下一节，我们问一个关键问题：什么时候「知道 $Y$ 的值」**不改变** $X$ 的分布？那就是**相互独立的随机变量**。
