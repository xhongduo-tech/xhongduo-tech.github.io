## 为什么从随机变量函数的数学期望开始

上一节我们学会了求 $E[X]$。可现实中我们更常需要的是「**函数的期望**」：$E[X^2]$（方差的前奏）、$E[\sqrt{X}]$、$E[e^{tX}]$（矩母函数）、$E[\mathbf{1}_A]$（概率）。按定义，求 $E[g(X)]$ 似乎要先求 $Y = g(X)$ 的分布，再对它算期望——但这里有一条著名的**免积分捷径**：直接用 $X$ 的分布计算，无需先求出 $g(X)$ 的分布。

这条定理叫**期望的「直接公式」（law of the unconscious statistician, LOTUS）**，名字带着幽默——统计学家「不自觉地」跳过了求函数分布的一步。它是计算期望的日常工具，也是方差、协方差、矩、矩母函数的公共发动机。<span class="marginnote">「无意识统计学家定律」这个诙谐名字说明它有多常用：统计学家算 $E[g(X)]$ 时都不假思索直接用 $X$ 的分布积分。它的正确性需要证明（用分布函数或测度论），但使用上完全无脑——先定位 $X$ 的类型，再套对应公式。</span>

## 1 直接公式：离散与连续

**定理（LOTUS）**：设 $Y = g(X)$，则

**离散**：$E[g(X)] = \sum_k g(x_k)\, p_k$，其中 $p_k = P\{X = x_k\}$；
**连续**：$E[g(X)] = \int_{-\infty}^{+\infty} g(x)\, f(x)\, dx$，其中 $f$ 是 $X$ 的密度。

两式都要求级数/积分绝对收敛。**关键洞察**：计算 $E[g(X)]$ 时，权函数用的是 $X$ 的分布（$p_k$ 或 $f(x)$），而不是 $g(X)$ 的分布——省去了求 $Y$ 分布的全部工作。<span class="marginnote">这条公式为什么成立？因为 $E[g(X)]$ 本质是对「样本点 $e$ 处 $g(X(e))$ 的平均」：$g(X(e))$ 是 $X(e)$ 的复合，仍定义在原样本空间上，所以按 $X$ 的分布加权求和/积分即可。分布函数法求 $Y$ 的分布只是「换了个自变量」，数值上两者必然相等。</span>

**例**：$X$ 取 $-2, 0, 2$，概率各 $1/3$。$E[X^2] = (-2)^2\cdot\frac13 + 0^2\cdot\frac13 + 2^2\cdot\frac13 = \frac83$。若先求 $Y = X^2$ 的分布（取 $0, 4$，概率 $1/3, 2/3$），再算 $E[Y] = 0\cdot\frac13 + 4\cdot\frac23 = \frac83$——结果一致，但直接公式快得多。

## 2 二维情形的直接公式

LOTUS 直接推广到二维：设 $(X,Y)$ 的联合密度为 $f(x,y)$，则对任意函数 $g$，

$$E[g(X, Y)] = \int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} g(x, y)\, f(x, y)\, dx\, dy$$

离散版 $\sum_i \sum_j g(x_i, y_j) p_{ij}$。这是计算 $E[XY]$（协方差的原料）、$E[\max(X,Y)]$、$E[X+Y]$ 的统一入口。<span class="marginnote">二维 LOTUS 的威力在「期望的线性性」证明里看得最清楚：$E[X+Y] = \iint (x+y) f(x,y)\,dx\,dy = \iint x f + \iint y f = E[X] + E[Y]$——不需要任何独立假设。期望线性性是无条件成立的，这正是它比方差强大之处。</span>

**例（$E[XY]$ 的一个小算例）**：$(X,Y)$ 在正方形 $[0,1]^2$ 上均匀，$f(x,y) = 1$。$E[XY] = \int_0^1\int_0^1 xy\,dx\,dy = \frac14$。而 $E[X] = E[Y] = \frac12$，乘积 $\frac14$ 相等——这暗示 $X,Y$ 独立（确实独立），$E[XY] = E[X]E[Y]$ 正是独立性的指纹之一。

## 3 期望的线性性：无条件成立

LOTUS 的最重要推论是**期望的线性性（linearity of expectation）**：对任意常数 $a, b$ 与随机变量 $X, Y$（不要求独立），

$$E[aX + bY + c] = a\,E[X] + b\,E[Y] + c$$

推广到 $n$ 个：$E\left[\sum_i a_i X_i\right] = \sum_i a_i E[X_i]$，同样不需要独立性。<span class="marginnote">线性性是无条件成立的，这是期望区别于方差的根本优点：方差的可加性要求独立，期望的线性性则百无禁忌。这个「不公平的便利」让统计学家敢把复杂量拆成「一堆小量的和」再逐项取期望——第五章证明大数定律时 $E[S_n] = np$ 就是这么拆的。</span>

**例**：$X_1,\ldots,X_n$ 独立同分布，$E[X_i] = \mu$。则 $E[\bar X] = E[\frac1n\sum X_i] = \frac1n \sum E[X_i] = \mu$——样本均值无偏地估计总体均值。这里只用了线性性，连独立都不需要。

## 4 公式解析：LOTUS 为什么「免积分」也能对

以连续情形为例，拆解 LOTUS 与「先求 $g(X)$ 分布」两条路径为何殊途同归：

$$

E[g(X)] = \int g(x)\, f_X(x)\, dx \quad\longleftrightarrow\quad E[Y] = \int y\, f_Y(y)\, dy

$$

- **第一步，左式**：按 $X$ 的密度对 $g(x)$ 加权积分。每个 $x$ 处「函数值 $g(x)$ × 该处密度 $f_X(x)$」。
- **第二步，右式**：若硬要先求 $Y = g(X)$ 的密度 $f_Y(y)$（第二章单调变换 $f_Y(y) = f_X(h(y))|h'(y)|$），再算 $\int y f_Y(y) dy$。
- **第三步，换元等价**：令 $y = g(x)$ 代入右式，$dy = |g'(x)| dx$，$f_Y(g(x)) = f_X(x)/|g'(x)|$，恰好消掉雅可比因子，回到左式——**两条路严格相等**。

「先求分布再积分」与「直接按 $X$ 加权」结果一致，但 LOTUS 省去求分布的全套工作。除非你确实需要 $Y$ 的分布本身（如求分位数），否则一律走 LOTUS。

**易错点｜辨析：** LOTUS 里被积函数是 $g(x) f(x)$，不是 $g(f(x))$ 或 $f(g(x))$——把 $g$ 作用在「取值」上，不是作用在「密度」上。另一常见错误：忘了验证绝对收敛。当 $g(x)$ 增长比 $f(x)$ 衰减快得多时（如 $g(x) = e^{x^2}$ 配正态），$E[g(X)]$ 可能发散。

## 5 LOTUS 的深入应用与实例

LOTUS 是期望计算的主力工具，它的三种形态、常见误区与工程应用值得完整展开。

### LOTUS 的三种形态

| 情形 | 公式 |
| --- | --- |
| 一元离散 | $E[g(X)] = \sum_k g(x_k)p_k$ |
| 一元连续 | $E[g(X)] = \int g(x)f(x)dx$ |
| 二维连续 | $E[g(X,Y)] = \iint g(x,y)f(x,y)dxdy$ |

**「用 $X$ 的分布加权 $g$ 的取值」**是三种形态的共同骨架——不需要先求 $g(X)$ 的分布。

### 例：用 LOTUS 算矩

**例**：$X \sim U(0,1)$。$E[X^2] = \int_0^1 x^2 dx = 1/3$，$E[X^3] = \int_0^1 x^3 dx = 1/4$——各阶矩一次积分搞定。方差 $\mathrm{Var}(X) = 1/3 - (1/2)^2 = 1/12$，与第四章汇总一致。

### 例：指示函数的期望

**例**：$g(X) = \mathbf 1_{\{X > a\}}$，则 $E[\mathbf 1_{\{X>a\}}] = \int_a^\infty f(x)dx = P\{X > a\}$——**「概率 = 指示函数的期望」**，这把事件概率统一进期望框架，是大数定律证明的常用手法。

### 例：非线性函数的期望

**例**：圆的半径 $R \sim U(0, 1)$，面积 $S = \pi R^2$。$E[S] = \pi E[R^2] = \pi/3 \approx 1.047$。注意 $E[S] \ne \pi(E[R])^2 = \pi/4$——**「期望不穿函数」再次现身**：$E[g(X)] \ne g(E[X])$。

**易错点｜辨析：** ① LOTUS 的被积函数是 $g(x)f(x)$，别写成 $g(f(x))$ 或 $f(g(x))$——$g$ 作用在「取值」上；② 绝对收敛条件不可忽略——$g$ 增长比 $f$ 衰减快时 $E[g(X)]$ 可能发散；③ 「先求 $g(X)$ 分布再算期望」与 LOTUS 结果必然一致（可用它验证计算）。

再补一张「常用函数的期望」速查（供对照检验）：

| $g(X)$ | $E[g(X)]$ 的含义 | 用途 |
| --- | --- | --- |
| $X$ | 期望 | 位置 |
| $X^2$ | 二阶原点矩 | 方差原料 |
| $(X-\mu)^2$ | 方差 | 波动 |
| $X^k$ | $k$ 阶原点矩 | 矩估计 |
| $e^{tX}$ | 矩母函数 | 分布识别 |

「LOTUS 配速查表」——算期望时先想「这是什么矩、什么函数」，再套公式。

## 6 小结

- **LOTUS 直接公式**：$E[g(X)] = \sum g(x_k) p_k$（离散）/ $\int g(x) f(x)\, dx$（连续），免求 $g(X)$ 的分布。
- **二维版**：$E[g(X,Y)] = \iint g(x,y) f(x,y)\, dx\,dy$，是协方差、$E[XY]$ 的入口。
- **期望线性性** $E[aX+bY+c] = aE[X]+bE[Y]+c$，**无条件成立**，无需独立。
- 线性性让复杂量可拆成小量之和再逐项取期望，是大数定律证明的引擎。
- 别把 $g$ 作用在密度上；注意绝对收敛条件。

在下一节，我们把线性性系统地整理成**数学期望的性质**，并见识「期望的乘法只在独立时成立」这条重要分界线。
