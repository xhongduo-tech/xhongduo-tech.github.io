## 为什么从对偶关系开始

第七章给了置信区间，第八章给了假设检验——它们看起来是两套工具。但实际上，**它们是同一枚硬币的两面**：置信水平 $1-\alpha$ 的置信区间恰好是「在显著性水平 $\alpha$ 下不拒绝 $H_0$ 的参数值集合」。这就是**假设检验与置信区间的对偶关系（duality）**。

这一对偶关系是统计推断的「统一场论」：它让你可以从区间直接读出检验结论（区间含 $\mu_0$ → 不拒绝），也可以从检验反推区间。更重要的是，它揭示了「p 值」「拒绝域」「置信区间」三个概念其实是同一套几何的不同投影。<span class="marginnote">对偶关系的精确定义：<strong>设 $[\hat\theta_L, \hat\theta_U]$ 是 $\theta$ 的 $1-\alpha$ 置信区间，则「检验 $H_0: \theta = \theta_0$（$\alpha$ 水平双侧）」不拒绝 $H_0$ 当且仅当 $\theta_0$ 落在区间内</strong>。反过来，「拒绝 $H_0$」⇔「$\theta_0$ 落在区间外」。一句话：区间里的值都是「数据不反对的假设值」。</span>

## 1 为什么对偶成立

对偶关系的成立来自「枢轴量」这同一个数学对象。以方差已知的正态均值为例：

- **置信区间**：$\bar X \pm z_{\alpha/2}\frac{\sigma}{\sqrt n}$——由枢轴量 $Z = \frac{\bar X - \mu}{\sigma/\sqrt n} \sim N(0,1)$ 反解 $\mu$ 得到；
- **检验**：$H_0: \mu = \mu_0$ 拒绝当 $|Z| = \left|\frac{\bar X - \mu_0}{\sigma/\sqrt n}\right| \ge z_{\alpha/2}$。

两者共用同一个分位点 $z_{\alpha/2}$：**拒绝域里的 $|Z| \ge z_{\alpha/2}$ 恰好就是「$\mu_0$ 落在置信区间外」**。同一个不等式，换个角度看就是区间，换个角度就是拒绝域。<span class="marginnote">把对偶关系写成形式：$H_0: \mu = \mu_0$ 在 $\alpha$ 水平被拒绝 $\iff \mu_0 \notin [\bar X \pm z_{\alpha/2}\frac{\sigma}{\sqrt n}]$。这个「检验 = 区间不包含」的等价，让「读检验结果」变成了「看区间含不含假设值」——还记得均值差区间「含不含 0」的判读吗？那正是对偶关系在起作用。</span>

## 2 双侧检验 ↔ 双侧区间

最标准的对偶：**双侧检验 $H_0: \theta = \theta_0$ vs $H_1: \theta \ne \theta_0$ 与双侧置信区间**。

**例**：灯泡寿命 $X \sim N(\mu, 100^2)$，$n = 25$，$\bar x = 1960$。$\mu$ 的 95% 置信区间：

$$1960 \pm 1.96 \times \frac{100}{5} = 1960 \pm 39.2 = (1920.8, 1999.2)$$

检验 $H_0: \mu = 2000$：$\mu_0 = 2000 \notin$ 区间 → 拒绝 $H_0$。与直接算 $Z = -2.0$、$|Z| \ge 1.96$ 拒绝的结论完全一致。<span class="marginnote">「看区间含不含假设值」往往比「算统计量」更快：一个 95% 区间就能同时回答「$\mu = 2000$ 显著吗」「$\mu = 1950$ 显著吗」「$\mu$ 可能在哪」三个问题。这也是为什么现代论文越来越爱「报告置信区间而非只报 p 值」——一个区间携带的信息远超一个 p 值。</span>

## 3 单侧检验 ↔ 单侧区间

对偶关系同样适用于单侧：**单侧检验 $H_0: \mu \le \mu_0$ vs $H_1: \mu > \mu_0$ 与单侧置信下限**。

$H_0: \mu \le \mu_0$ 在 $\alpha$ 水平被拒绝，当且仅当 $\mu_0$ 小于 $\mu$ 的 $1-\alpha$ 单侧置信下限 $\bar X - z_\alpha\frac{\sigma}{\sqrt n}$。**「要证明 $\mu$ 足够大，就看单侧下限是否大于目标值」**——工程验收里「平均寿命不低于 2000」就是「2000 是否落在 $\mu$ 的单侧下限之外」。<span class="marginnote">单侧对偶的口诀：<strong>「检验 $\mu$ 是否大于 $\mu_0$」=「看 $\mu_0$ 是否低于单侧下限」；「检验 $\mu$ 是否小于 $\mu_0$」=「看 $\mu_0$ 是否高于单侧上限」</strong>。第七章的单侧区间在这里找到了检验伴侣——它们本来就是同一对。</span>

## 4 公式解析：对偶的同一不等式

对偶关系本质上是「同一个不等式被解读两次」，以双侧为例：

$$

|Z| = \left|\frac{\bar X - \mu_0}{\sigma/\sqrt n}\right| < z_{\alpha/2} \iff \bar X - z_{\alpha/2}\frac{\sigma}{\sqrt n} < \mu_0 < \bar X + z_{\alpha/2}\frac{\sigma}{\sqrt n}

$$

- **第一步，检验视角**：$|Z| < z_{\alpha/2}$ 意味着「统计量没落进拒绝域」，不拒绝 $H_0: \mu = \mu_0$。
- **第二步，解不等式**：$\left|\frac{\bar X - \mu_0}{\sigma/\sqrt n}\right| < z_{\alpha/2} \iff \bar X - z_{\alpha/2}\frac{\sigma}{\sqrt n} < \mu_0 < \bar X + z_{\alpha/2}\frac{\sigma}{\sqrt n}$。
- **第三步，区间视角**：右侧正是 $\mu_0$ 落在 $\mu$ 的 $1-\alpha$ 置信区间内。

「同一个关于 $\mu_0$ 的不等式，左边读作检验、右边读作区间」——对偶关系的全部秘密就在这一行恒等变换里。它没有新数学，却把两个看似独立的工具缝合成了一个。

## 5 对偶关系的深入应用

对偶关系不是教材里的装饰品，它是统计实务里「看结论」的快捷方式，也是一条贯穿全书的方法论线索。

### 用区间快速做检验

对偶关系最实用的形式：**要判断「$H_0: \theta = \theta_0$」是否被拒绝，只需看 $\theta_0$ 是否落在 $\theta$ 的置信区间里**。

- $\theta_0$ 在区间内 → 不拒绝（差异不显著）；
- $\theta_0$ 在区间外 → 拒绝（差异显著）。

**例**：某药疗效的 95% 置信区间为 $(1.2, 4.8)$（单位：分）。判断「疗效为零（$\mu = 0$）」：$0 \notin (1.2, 4.8)$ → 拒绝 $H_0$——疗效显著非零。若区间改为 $(-0.5, 2.5)$：$0$ 在区间内 → 不拒绝——证据不足。**一个区间同时回答「显著吗」「可能多大」**，这正是现代统计「报告区间优先」的原因。

### 区间宽度与检验功效的关联

对偶关系还揭示了**检验功效与区间宽度**的深层联系：样本量越大，置信区间越窄，「拒绝 $H_0$」所需的差异越小——检验越灵敏。反之，小样本的区间宽，「不拒绝」常常只是「检测力不足」，而非「确实无差异」。这也是「不显著 ≠ 无效果」的数学根源。

### 从双侧到单侧的一以贯之

对偶关系在单侧同样成立（第七章单侧区间 ↔ 第八章单边检验），在方差（χ²）、方差比（F）、回归系数（t）等一切「枢轴量可反解」的场景全部适用。可以说，**只要一个参数的推断有枢轴量，检验与区间就是同一枚硬币**。

**易错点｜辨析：** 用对偶关系做判断时，注意「置信水平」与「显著性水平」的对应：95% 区间对应 $\alpha = 0.05$ 的检验，99% 区间对应 $\alpha = 0.01$。用 95% 区间去回答「$\alpha = 0.01$ 的检验」会得到错误结论——**区间宽度对应的显著性水平必须匹配**。



## 6 典型例题：对偶关系实战

**例 1**：灯泡寿命 $X \sim N(\mu, 100^2)$，$n = 25$，$\bar x = 2045$。$\mu$ 的 95% 置信区间：

$$2045 \pm 1.96 \times \frac{100}{5} = (2005.8, 2084.2)$$

$H_0: \mu = 2000$？$2000 \notin$ 区间 → 拒绝。$H_0: \mu = 2020$？$2020$ 在区间内 → 不拒绝。

**例 2（均值差）**：$\mu_1 - \mu_2$ 的 95% 区间为 $(2.1, 5.8)$。$0 \notin$ 区间 → 拒绝「两均值相等」——差异显著。

**例 3（置信水平匹配）**：$\mu$ 的 99% 区间为 $(2000.1, 2089.9)$。$H_0: \mu = 2000$ 在 $\alpha = 0.01$ 下被拒绝（$2000$ 不在 99% 区间内）。**必须用与 $\alpha$ 匹配的置信水平**：$\alpha = 0.05$ 配 95% 区间、$\alpha = 0.01$ 配 99% 区间——混用会得出错误结论。

这三个例子的启示是统计报告的一条现代原则：**与其报一个孤立的 p 值，不如报置信区间**。一个区间同时携带「点估计、精度、显著性判断」三层信息——读者一眼看出「参数大概在哪、有多确定、假设是否被拒」。当论文里出现「差异显著（95% CI 不含 0）」时，它用的正是本节的对偶关系：区间不含 0 ⇔ 检验拒绝「无差异」。

对偶关系还有一个被低估的用途——**样本量设计**：要「以 95% 把握拒绝某个 $\theta_0$」，等价于让置信区间「以 95% 概率不覆盖 $\theta_0$」——这取决于区间宽度，而宽度由样本量决定。于是「检验功效计算」与「区间宽度预算」是同一件事：想同时得到「窄区间」与「灵敏检验」，都得增大 $n$。这再次印证：检验与区间是同一枚硬币，投入（样本量）也共享。

再补一张「检验 ↔ 区间」的完整对照速查：

| 推断对象 | 检验 $H_0$ | 置信区间 | 分位点 |
| --- | --- | --- | --- |
| 单均值（$\sigma$ 已知） | $z$ 检验 | $\bar X \pm z_{\alpha/2}\sigma/\sqrt n$ | $z$ |
| 单均值（$\sigma$ 未知） | $t$ 检验 | $\bar X \pm t_{\alpha/2}S/\sqrt n$ | $t(n-1)$ |
| 单方差 | $\chi^2$ 检验 | 方差区间 | $\chi^2$ |
| 双方差比 | $F$ 检验 | 方差比区间 | $F$ |

「每类检验都配一个对偶区间」——记住这个表，第七章与第八章就能互相印证、互相验证。

## 7 小结

- **对偶关系**：$H_0: \theta = \theta_0$（$\alpha$ 水平双侧）被拒绝 ⇔ $\theta_0$ 落在 $1-\alpha$ 置信区间外。
- 对偶来自同一个枢轴量：同一不等式，解读为拒绝域或置信区间。
- 双侧检验 ↔ 双侧区间；单侧检验 ↔ 单侧区间（下限/上限按方向对应）。
- 「看区间含不含假设值」是快速做检验判断的捷径，也是论文报告区间的价值所在。
- 置信区间携带的信息量远超单个 p 值——这也是现代统计「区间优先」的原因。
