## 为什么从二维随机变量开始

现实里我们几乎从不只关心一个量：调查一个人，同时记他的身高与体重；掷一颗骰子，同时看点数与是否偶数；测量一个零件，同时记长度与直径。**两个随机变量同时出现，就成了二维随机变量**，而描述它们的方式不是「两条独立的分布」，而是一张更精细的「联合分布」——它不仅包含每个分量的信息，更包含**两个分量之间的关联**。

联合分布是本书从一维走向多维的关键一步：本章的联合分布函数、边缘分布、条件分布，第四章的协方差与相关系数，乃至第七章多元正态分布，全部从这里生长。它是「一维看线、二维看面、多维看超面」的起点。<span class="marginnote">二维随机变量 $(X, Y)$ 本质上是把样本空间映到平面 $\mathbb{R}^2$ 上的一个向量值函数。它的分布函数 $F(x,y)$ 回答「$X$ 不超过 $x$ 且 $Y$ 不超过 $y$」的联合概率——比一维的「不超过 $x$」多了一个维度，也多了一整类新问题。</span>

## 1 二维随机变量与联合分布函数的定义

**二维随机变量（two-dimensional random variable）**：设 $E$ 是随机试验，$X = X(e)$、$Y = Y(e)$ 是定义在同一样本空间上的两个随机变量，则称 $(X, Y)$ 为二维随机变量（或二维随机向量）。

**联合分布函数（joint distribution function）**：对任意实数 $x, y$，称函数

$$F(x, y) = P\{X \le x,\ Y \le y\}$$

为 $(X, Y)$ 的**联合分布函数**。逗号表示「且」——两个不等式同时成立，即 $X$ 落在 $(-\infty, x]$、$Y$ 落在 $(-\infty, y]$ 的联合概率。<span class="marginnote">联合分布函数在几何上是「左下角概率」：以点 $(x,y)$ 为右上角的左下无穷矩形内，$(X,Y)$ 落入的概率。$F$ 把平面上的每个点变成一个概率值，恰如等高线地图把平面上的每点标成高度。</span>

联合分布函数满足四条性质（与一维三条类比）：

1. $0 \le F(x,y) \le 1$，且 $F(+\infty, +\infty) = 1$，$F(-\infty, y) = F(x, -\infty) = 0$；
2. **对每个变量单调不减**：$x_1 < x_2$ 时 $F(x_1,y) \le F(x_2,y)$，对 $y$ 亦然；
3. **对每个变量右连续**；
4. **矩形非负**：对 $a < b$、$c < d$，$P\{a < X \le b,\ c < Y \le d\} = F(b,d) - F(a,d) - F(b,c) + F(a,c) \ge 0$。

第四条是二维新增的：它保证「落在任意矩形里的概率非负」，也给出了二维区间概率的计算公式。<span class="marginnote">矩形公式 $F(b,d) - F(a,d) - F(b,c) + F(a,c)$ 的直观是「先加左下无穷矩形，再减去两个多余长条，再加回被减两次的角落」。这是一维「$F(b)-F(a)$」在平面上的推广——多一个维度，减两次、加一次。</span>

## 2 二维区间概率：矩形公式

一维的「区间概率 = 分布函数之差」在二维升级为「矩形概率 = 分布函数的交错差」：

$$P\{a < X \le b,\ c < Y \le d\} = F(b, d) - F(a, d) - F(b, c) + F(a, c)$$

**易错点｜辨析：** 这条公式的正负号是经典陷阱。四个项分别是 $F$ 在四个角点的值，符号按「右上加、左上减、右下减、左下加」。若只写 $F(b,d) - F(a,c)$，会漏掉两块长条，导致概率偏小或甚至为负。建议画个矩形：以 $(b,d)$ 为右上角的左下矩形太大，减掉左侧竖条 $F(a,d)$ 和下方横条 $F(b,c)$，又因为重叠的角 $F(a,c)$ 被减了两次，要加回一次。

**例**：设 $F(x,y)$ 已知，求 $P\{1 < X \le 2,\ 0 < Y \le 3\} = F(2,3) - F(1,3) - F(2,0) + F(1,0)$。代入 $F$ 的具体表达式即可。

## 3 联合分布与边缘分布的关系

联合分布函数的一个关键推论：**把 $Y$ 的上限推到 $+\infty$，就得到 $X$ 自己的分布函数**。称

$$F_X(x) = P\{X \le x\} = P\{X \le x,\ Y < +\infty\} = \lim_{y \to +\infty} F(x, y)$$

为 $X$ 的**边缘分布函数（marginal distribution function）**；同理 $F_Y(y) = \lim_{x \to +\infty} F(x, y)$。**联合分布包含边缘分布，但反之不然**——知道两个分量各自的分布，推不出联合分布，因为联合还携带「关联」信息。这一不对称性，正是下一节起边缘分布、条件分布层层展开的动机。<span class="marginnote">「联合决定边缘、边缘决定不了联合」是本章最重要的认识之一。举个极端的例子：$(X,Y)$ 可能以概率 1 落在直线 $Y = X$ 上，此时 $X$、$Y$ 各自的分布完全相同，但联合分布集中在一条对角线上——边缘分布完全看不出这层关系。</span>

**例**：设 $F(x,y) = \begin{cases} (1 - e^{-x})(1 - e^{-y}), & x, y > 0 \\ 0, & \text{其他} \end{cases}$。则 $F_X(x) = \lim_{y\to\infty} F(x,y) = 1 - e^{-x}$（$x>0$）——这是指数分布的分布函数。这里联合恰好是边缘之积，预示着「独立」的特例，我们会在第三章第六节专门研究。

## 4 公式解析：矩形概率公式的几何拆解

矩形公式的推导其实只有一行，关键是画图配合：

$$

P\{a < X \le b,\ c < Y \le d\} = F(b,d) - F(a,d) - F(b,c) + F(a,c)

$$

- **第一步，从右上角出发**：$F(b,d) = P\{X \le b, Y \le d\}$ 是「左下无穷矩形」，比目标矩形多了左竖条 $(-\infty,a] \times (-\infty,d]$ 和下横条 $(-\infty,b] \times (-\infty,c]$。
- **第二步，减去多余**：减 $F(a,d)$（左竖条）与 $F(b,c)$（下横条），但左下角的 $(-\infty,a] \times (-\infty,c]$ 被减了两次。
- **第三步，加回重叠**：加回 $F(a,c)$ 补上被重复减去的角落。四项交错即得目标矩形。

这个「加加减减」的模式在数学里反复出现：二维矩形用四项、三维长方体用八项（$\pm$ 交替）、高维用容斥原理。**理解的锚点是几何**——每次看到 $F$ 的四个角点项，先画出那个被减两次的角落。

## 5 联合分布函数的深入应用与实例

联合分布函数是二维随机变量的「总账本」，它的性质、计算与解读值得展开。

### 例：矩形概率公式

**例**：已知 $F(x,y)$，求 $P\{1 < X \le 2, 0 < Y \le 3\}$：

$$F(2,3) - F(1,3) - F(2,0) + F(1,0)$$

**「右上加、左上减、右下减、左下加」**——矩形公式的正负号是经典陷阱。

### 联合分布函数的四条性质

| 性质 | 内容 |
| --- | --- |
| 有界 | $0 \le F \le 1$，$F(-\infty,\cdot) = 0$ |
| 单调 | 对每个变量单调不减 |
| 右连续 | 对每个变量右连续 |
| 矩形非负 | 矩形概率 $\ge 0$ |

**「四条性质是『函数是联合分布函数』的完整判据」**——判断题靠它。

### 例：联合、边缘、条件的关系

| 量 | 定义 |
| --- | --- |
| 联合 $F(x,y)$ | $P\{X\le x, Y\le y\}$ |
| 边缘 $F_X(x)$ | $\lim_{y\to\infty} F(x,y)$ |
| 条件 | $\frac{P\{X\le x, Y=y\}}{P\{Y=y\}}$ |

**「联合是总账、边缘是投影、条件是切片」**——三个视角看同一分布。

### 例：独立的联合分布函数

**例**：$F(x,y) = (1-e^{-x})(1-e^{-y})$（$x,y > 0$）——恰好是 $F_X(x)F_Y(y)$ 的形式，$X$ 与 $Y$ 独立（指数分布）。**「联合 = 边缘之积 ⇔ 独立」**是联合分布函数最重要的判据。

**易错点｜辨析：** ① 矩形公式漏项会得出负概率——务必按「加、减、减、加」四项写全；② 「联合决定边缘、边缘不决定联合」——仅凭边缘推不出联合；③ 分布函数取极限得边缘（$y \to \infty$），密度用积分——两种操作别混。

## 6 小结

- **二维随机变量** $(X,Y)$ 是两个随机变量组成的向量，联合分布函数 $F(x,y) = P\{X \le x, Y \le y\}$。
- 联合分布函数四条性质：有界、双单调、双右连续、**矩形非负**。
- 矩形概率公式 $P\{a < X \le b, c < Y \le d\} = F(b,d) - F(a,d) - F(b,c) + F(a,c)$，符号按「右上加、左上减、右下减、左下加」。
- **边缘分布函数**由联合取极限得到：$F_X(x) = \lim_{y\to\infty} F(x,y)$；联合决定边缘，边缘决定不了联合。
- 二维分布是理解关联、协方差、多元正态的起点。
