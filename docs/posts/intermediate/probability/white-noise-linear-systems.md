## 为什么从白噪声与线性系统开始

第十三章的最后一块拼图，把「平稳过程」与「工程系统」接上：**白噪声**是最基础的平稳过程（谱平坦、全频率等功率），**线性时不变系统**把输入的白噪声加工成有色的平稳输出。这一节回答两个问题：白噪声长什么样？平稳过程经过线性系统后还是不是平稳的？功率谱如何变化？

这一节是随机过程章（也是本专题）的收官：它把平稳性、相关函数、功率谱、维纳—辛钦公式全部用在一个现实场景里——「噪声过滤波器」。信号处理、通信、控制里的「成形滤波器」「系统辨识」都建立在这节的理论上。<span class="marginnote">「白噪声 → 线性系统 → 有色噪声」是随机信号处理的标准故事：白噪声像「随机白面」，线性系统像「染色滤镜」——输出保留了白噪声的随机性，但谱被系统「塑形」成特定形状。反过来，任何平稳过程都能看作「白噪声过某个成形滤波器」——这是建模的万能视角，也是本节最深远的应用。</span>

## 1 白噪声

**白噪声（white noise）**：宽平稳过程 $\{W(t)\}$，其功率谱为常数：

$$S_W(\omega) = \frac{N_0}{2} \quad (\text{常数，对一切 } \omega)$$

由维纳—辛钦公式，相关函数为

$$R_W(\tau) = \frac{N_0}{2}\,\delta(\tau)$$

——**任意两个不同时刻都无关**（$R(\tau) = 0$ 对 $\tau \ne 0$），只在原点有尖峰。<span class="marginnote">白噪声的两条特征：<strong>谱平坦（全频率等功率）+ 相关为 $\delta$（不同时刻无关）</strong>——它们是同一回事（维纳—辛钦对）。「白」来自光学类比：白光含所有颜色，白噪声含所有频率。理想白噪声总功率无穷（谱积分发散）——它是「数学理想化」，现实中只有「带限白噪声」（在有限带宽内谱平坦）。</span>

**例**：热噪声、散粒噪声近似白噪声——它们的功率谱在极宽频带内几乎平坦。电子学里噪声分析常以「白噪声 + 滤波」为起点。

## 2 线性系统对平稳过程的响应

设线性时不变（LTI）系统的**频率响应**为 $H(\omega)$（冲激响应 $h(t)$ 的傅里叶变换），输入平稳过程 $X(t)$，输出

$$Y(t) = \int_{-\infty}^{+\infty} h(u)\, X(t - u)\, du \quad (\text{卷积})

若 $X(t)$ 宽平稳，则输出 $Y(t)$ 也宽平稳，且其数字特征由输入与系统完全决定：

- **均值**：$\mu_Y = \mu_X \cdot H(0)$（$H(0)$ 是直流增益）；
- **功率谱**：$S_Y(\omega) = |H(\omega)|^2\, S_X(\omega)$——**输出的谱 = 输入的谱 × 系统的功率传递函数**；
- **相关函数**：$R_Y(\tau) = \int\int h(u)h(v) R_X(\tau + u - v)\, du\, dv$。

**「平稳性在 LTI 系统下保持」**是本节最重要的结论——平稳过程过线性系统仍是平稳过程。<span class="marginnote">「$S_Y = |H|^2 S_X$」是随机信号处理的第一公式：它把「系统对随机信号的作用」从「复杂卷积」化为「谱的乘法」。$|H(\omega)|^2$ 叫功率传递函数——系统按频率「放大/缩小」功率。这条公式让「噪声过滤波器」的谱计算变成一次乘法，是滤波、成形、系统辨识的全部基础。</span>

## 3 例：白噪声过 RC 低通滤波器

**例**：白噪声 $S_W(\omega) = N_0/2$ 输入 RC 低通滤波器，频率响应

$$H(\omega) = \frac{1}{1 + i\omega RC}$$

输出谱：

$$S_Y(\omega) = |H(\omega)|^2 \cdot \frac{N_0}{2} = \frac{N_0/2}{1 + (\omega RC)^2}$$

**洛伦兹谱**——低频平坦、高频衰减，正是上一节「指数相关」过程的谱。输出相关函数 $R_Y(\tau) = \frac{N_0}{4RC}e^{-|\tau|/(RC)}$——白噪声被滤波成「有色噪声」，记忆时间 $RC$。<span class="marginnote">这个例子是「白噪声 → 有色噪声」的教科书演示：<strong>白噪声过一阶低通，谱从「平坦」变成「洛伦兹」，相关从「$\delta$」变成「指数衰减」</strong>——系统把「无记忆」的输入塑造成「有记忆」的输出，记忆长度就是滤波器的时间常数 $RC$。现实中「噪声不是白的，是被系统染过色的」——理解这条链路，就理解了噪声分析的半壁江山。</span>

**易错点｜辨析：** ① $S_Y = |H|^2 S_X$ 用的是**功率传递函数** $|H|^2$（幅值的平方），不是 $H$ 本身——相位信息在谱乘法中消失（功率谱不关心相位）；② 输出仍是平稳的（LTI + 平稳输入），但一般不是「白」的——除非 $|H|^2$ 也是常数；③ 输出谱非负由 $|H|^2 \ge 0$、$S_X \ge 0$ 自动保证。

## 4 公式解析：谱乘法从哪来

「$S_Y = |H|^2 S_X$」的推导是「相关函数的双重卷积 + 维纳—辛钦」，拆开关键步：

$$

R_Y(\tau) = \int\int h(u)h(v)\, R_X(\tau + u - v)\, du\, dv \quad \xrightarrow{\text{傅里叶}} \quad S_Y(\omega) = |H(\omega)|^2 S_X(\omega)

$$

- **第一步，时域卷积**：$Y(t) = h * X(t)$，输出相关 = 输入相关经过 $h$ 的双重卷积。
- **第二步，傅里叶变换**：对 $R_Y(\tau)$ 做傅里叶变换，双重卷积变成「$h$ 的傅里叶 × $h$ 的傅里叶共轭 × $S_X$」——卷积变乘法。
- **第三步，合成**：$H(\omega) \cdot H^*(\omega) = |H(\omega)|^2$——幅值平方，相位相消。$S_Y = |H|^2 S_X$。

「时域卷积 ↔ 频域乘法」是傅里叶变换的黄金法则，谱分析全靠它。它把「随机信号过系统」从「双重积分」化为「一次乘法」，也让「系统的频率整形」变得一目了然。

## 5 白噪声与线性系统的深入应用

「白噪声过系统」是随机信号处理的标准故事，它的谱计算、成形与实例值得展开。

### 例：RC 低通的白噪声输出

**例**：白噪声 $S_W(\omega) = N_0/2$ 过 $H(\omega) = 1/(1+i\omega RC)$：

$$S_Y(\omega) = \frac{N_0/2}{1 + (\omega RC)^2}, \qquad R_Y(\tau) = \frac{N_0}{4RC}e^{-|\tau|/(RC)}$$

**「白噪声被滤波成有色噪声」**——谱从平坦变洛伦兹、相关从 $\delta$ 变指数衰减。

### 谱乘法公式速查

| 量 | 公式 |
| --- | --- |
| 输出谱 | $S_Y(\omega) = |H(\omega)|^2 S_X(\omega)$ |
| 输出相关 | $R_Y$（双重卷积） |
| 输出均值 | $\mu_Y = \mu_X H(0)$ |
| 平稳性 | LTI + 平稳输入 ⇒ 平稳输出 |

**「$|H|^2$ 是功率传递函数」**——相位在谱乘法中消失，功率谱不管相位。

### 例：成形滤波器

**例**：想让输出谱为 $S_Y(\omega)$，选 $H$ 使 $|H|^2 = S_Y/S_X$——**「任何平稳过程都能看成白噪声过某个成形滤波器」**，这是建模的万能视角。

### 例：白噪声的理想化

理想白噪声总功率无穷（谱积分发散）——现实中用**带限白噪声**（带宽内平坦、带外为零）。**「白」是数学理想化，「带限白」是工程现实」。

### 系统辨识的联系

输入白噪声、测输出互相关，可识别系统的冲激响应——**「白噪声是系统辨识的理想探针」**（Wiener–Hopf 方法）。

**易错点｜辨析：** ① 输出谱用 $|H|^2$ 不是 $H$——别忘幅值平方；② 输出平稳但不「白」——除非 $|H|^2$ 常数；③ 白噪声的 $\delta$ 相关在数值计算里要离散化处理（采样间隔内积分）。

## 6 小结

- **白噪声**：$S_W(\omega) = N_0/2$（谱平坦）、$R_W(\tau) = \frac{N_0}{2}\delta(\tau)$（不同时刻无关）——数学理想化，现实用带限近似。
- **LTI 系统下的平稳性保持**：平稳输入过线性时不变系统，输出仍平稳。
- **谱乘法公式** $S_Y(\omega) = |H(\omega)|^2 S_X(\omega)$——输出的谱 = 输入谱 × 功率传递函数。
- 白噪声过 RC 低通 → 洛伦兹谱 + 指数相关——「白噪声被染成有色噪声」的经典演示。
- 任何平稳过程可视为「白噪声过成形滤波器」——本节是随机信号处理与系统辨识的理论出口。
