## 为什么从可化为一元线性回归的曲线回归开始

现实里 $x$ 与 $y$ 的关系很少恰好是直线：人口增长呈指数、学习曲线呈幂律、药物浓度随时间指数衰减。但「曲线回归」不必从零开始——**许多常见的曲线关系经过变量替换（取对数、取倒数、平方），就能化成一元线性回归**。用线性回归的整套工具（最小二乘、区间、检验）处理曲线，是「曲线回归」的经典路线。

这个「化曲为直」的思想在统计与机器学习里无处不在：对数线性模型、幂律拟合、Box–Cox 变换、乃至深度学习里对特征取对数——都是「先变换，再线性」。学会本节，等于掌握了「处理非线性关系的第一个工具箱」。<span class="marginnote">「化曲为直」的适用范围有一条清晰的边界：<strong>能化成线性的非线性，是「对参数线性、对变量非线性」的模型</strong>（如 $y = ae^{bx}$：对参数 $a,b$ 线性，对变量 $x$ 非线性）。对参数也非线性的模型（如 $y = \frac{x}{\beta_1 x + \beta_2}$ 的某些形式）无法这样化，需要非线性最小二乘——那是教材的进阶内容。</span>

## 1 指数函数：取对数变直线

**指数模型** $y = ae^{bx}$（$a > 0$）两边取自然对数：

$$\ln y = \ln a + b x$$

令 $y' = \ln y$，$a' = \ln a$，则 $y' = a' + bx$——**对 $(\ln y, x)$ 做一元线性回归**，得到 $\hat b$ 与 $\hat a'$，再 $a = e^{\hat a'}$。

**例（人口增长）**：人口随时间指数增长，数据 $y$（百万）与年份 $x$。取 $y' = \ln y$，对 $y'$ 与 $x$ 做线性回归，得 $\hat b = 0.02$、$\hat a' = 1.5$，则 $a = e^{1.5} = 4.48$。模型 $\hat y = 4.48 e^{0.02x}$——每年约增长 2%。<span class="marginnote">对数变换的实质：把「乘法关系」变成「加法关系」——$y = ae^{bx}$ 意味着 $y$ 的增长率恒定（每单位 $x$ 乘 $e^b$ 倍），取对数后「增长率恒定」变成「$\ln y$ 随 $x$ 线性增长」。这也是金融里「对数收益」优于「算术收益」的原因：对数把复利乘法变成可加。</span>

## 2 幂函数：双对数变直线

**幂模型** $y = ax^b$（$a > 0$，$x > 0$）两边取对数：

$$\ln y = \ln a + b \ln x$$

令 $y' = \ln y$，$x' = \ln x$，则 $y' = \ln a + b x'$——**对 $(\ln y, \ln x)$ 做线性回归**。斜率 $b$ 就是幂指数（弹性）。

**例（学习曲线）**：完成第 $x$ 件产品所需时间 $y$，服从幂律 $y = ax^b$。取双对数后线性回归，若 $\hat b = -0.3$，说明「产量翻倍，单位时间降为 $2^{-0.3} \approx 0.81$ 倍」——81% 学习曲线。<span class="marginnote">幂律（幂函数）在自然界无处不在：地震震级与频次、城市规模与排名、词频分布（齐普夫定律）都近似幂律。双对数图里幂律是一条直线，所以「画 log-log 图看是否直线」是识别幂律的标准方法——这也是「化曲为直」在科学发现里的经典用法。</span>

## 3 其他常见变换

| 模型 | 变换 | 线性化后 |
| --- | --- | --- |
| $y = ae^{bx}$ | $y' = \ln y$ | $y' = \ln a + bx$ |
| $y = ax^b$ | $y' = \ln y$，$x' = \ln x$ | $y' = \ln a + b x'$ |
| $y = a + \dfrac{b}{x}$ | $x' = \dfrac{1}{x}$ | $y = a + b x'$ |
| $y = a + b\sqrt{x}$ | $x' = \sqrt{x}$ | $y = a + b x'$ |
| $y = \dfrac{x}{a + bx}$（某些形式） | $y' = \dfrac{1}{y}$，$x' = \dfrac{1}{x}$ | $y' = a + b x'$ |

**易错点｜辨析：** 变换后做的是「$y'$ 对 $x'$」的线性回归，得到的是「变换空间的」最优直线。**误差假设也跟着变**：原模型要求误差在 $y$ 上加性正态，取对数后实际假设的是「$\ln y$ 的误差正态」（即 $y$ 的误差乘性）。变换改变了误差结构——这在严格推断里要意识到，但工程上常接受近似。<span class="marginnote">「变换改变误差结构」的提醒：若原始模型是 $y = ae^{bx} + \varepsilon$（加性误差），取对数后 $y'$ 的误差不再是加性正态；严格做法应直接在原模型上做非线性最小二乘。但实践中，只要数据「对数下散布均匀」，对数变换的近似就足够好——「画图检查对数化后的残差是否均匀」是判断变换是否合适的实用标准。</span>

## 4 公式解析：对数变换的两步

以指数模型为例，把「化曲为直」的完整链条拆开：

$$

y = ae^{bx} \implies \ln y = \ln a + bx \implies y' = a' + bx

$$

- **第一步，两边取对数**：$\ln y = \ln a + bx$——指数关系在对数下变线性。$b$ 在指数上，对数后掉到系数位。
- **第二步，重命名变量**：$y' = \ln y$，$a' = \ln a$——新变量是原变量的对数，新截距是原参数的函数。
- **第三步，线性回归**：对 $(x, y')$ 做最小二乘得 $\hat b$、$\hat a'$，回代 $a = e^{\hat a'}$——参数从「变换空间」翻译回「原空间」。

「取对数 → 重命名 → 线性回归 → 回代」是曲线回归的完整配方。它把「曲线拟合」降级为「直线拟合」，复用前面全部回归工具——最小二乘、区间、检验、预测，一应俱全。

## 5 曲线回归的深入与实例

「化曲为直」不只是技巧，它背后有一套「什么能化、化完怎么用、何时该放弃」的完整判断。

### 可线性化 vs 不可线性化的分界

| 模型 | 变换 | 线性化后 | 参数 |
| --- | --- | --- | --- |
| $y = ae^{bx}$ | $y' = \ln y$ | $y' = \ln a + bx$ | 对 $a,b$ 线性 |
| $y = ax^b$ | 双对数 | $\ln y = \ln a + b\ln x$ | 对 $a,b$ 线性 |
| $y = a + b/x$ | $x' = 1/x$ | $y = a + bx'$ | 对 $a,b$ 线性 |
| $y = \frac{1}{a + bx}$ | $y' = 1/y$ | $y' = a + bx$ | 对 $a,b$ 线性 |

**分界标准**：模型是否「对参数线性」——是则可线性化，否（如 $y = \frac{x}{a+bx}$ 的某些参数形式、逻辑斯蒂 $y = \frac{L}{1+e^{-a-bx}}$ 对 $L$）则需非线性最小二乘。

### 例：指数衰减的完整拟合

**例**：放射性衰变，测得 $t$ 时刻活度 $y$。假设 $y = ae^{-bt}$，取 $\ln y = \ln a - bt$，对 $(\ln y, t)$ 线性回归。若得斜率 $\hat b = -0.0693$、截距 $\hat a' = 4.6$，则 $a = e^{4.6} = 99.5$，模型 $\hat y = 99.5 e^{-0.0693t}$——半衰期 $T_{1/2} = \ln 2/b \approx 10$ 单位。

### 变换的代价：误差结构改变

**易错点｜辨析：** 取对数后，回归的误差假设从「$y$ 的误差加性正态」变成「$\ln y$ 的误差加性正态」——等价于「$y$ 的误差乘性」。若原始数据的误差确实加性（如测量误差恒定），对数变换会扭曲误差结构。实践判断：**看对数化后的残差是否均匀**——若残差在 $\ln y$ 空间均匀散布，变换合适；若出现「漏斗形」，说明变换不当。

### 例：选择变换的流程

数据 $(x, y)$ 散点呈「向上弯」的曲线。试三种变换：

| 变换 | 图是否变直 |
| --- | --- |
| $y$ vs $\ln x$ | 若直 → 对数模型 $y = a + b\ln x$ |
| $\ln y$ vs $x$ | 若直 → 指数模型 $y = ae^{bx}$ |
| $\ln y$ vs $\ln x$ | 若直 → 幂模型 $y = ax^b$ |

「哪种变换把图拉直，就用哪种模型」——这是曲线回归选模型的实操标准，也解释了为什么散点图与残差图在建模里如此重要。

再补一张「变换前 vs 变换后」的残差对照，理解变换对误差的影响：

| | 原空间（$y$） | 变换空间（$y' = \ln y$） |
| --- | --- | --- |
| 误差假设 | 加性正态 | 乘性误差 |
| 残差均匀 | 在 $y$ 均匀 | 在 $\ln y$ 均匀 |
| 拟合最优 | 最小化 $\sum(y-\hat y)^2$ | 最小化 $\sum(\ln y - \widehat{\ln y})^2$ |
| 含义 | 绝对误差最小 | 相对误差最小 |

「变换空间最优 ≠ 原空间最优」——取对数后拟合的是「相对误差」，这在指数/幂律数据里往往更合理，但必须意识到误差含义变了。

## 6 小结

- **可线性化的曲线**：指数 $y = ae^{bx}$（单对数）、幂 $y = ax^b$（双对数）、$a + b/x$、$a + b\sqrt{x}$ 等。
- **流程**：取对数/倒数变换 → 重命名变量 → 对变换后的变量做线性回归 → 参数回代。
- 双对数图上幂律是直线——「log-log 直线」是识别幂律的标准方法。
- 变换改变了误差结构（加性变乘性），严格推断需注意，工程上常接受近似。
- 「化曲为直」是对非线性关系的第一个工具箱，也是特征工程里取对数的思想源头。
