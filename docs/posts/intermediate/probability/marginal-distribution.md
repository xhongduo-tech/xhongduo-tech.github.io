## 为什么从边缘分布开始

给了你一张二维联合分布，你往往还想要「只看 $X$ 不看 $Y$」的信息——$X$ 自己服从什么分布？这就是**边缘分布（marginal distribution）**。上一节离散情形里它只是「行和」；连续情形下，它则是「把 $Y$ 积掉」的结果。边缘分布是从联合分布里「抽取单个变量」的投影操作，是理解条件分布、独立性、协方差的第一级台阶。

边缘分布的哲学位置很特殊：它是「简化」的工具，但简化必然伴随信息丢失。**联合决定边缘，边缘不决定联合**——这一不对称性在统计里意味深远：只看 $X$ 和 $Y$ 各自的分布，可能完全错过它们之间的强关联。<span class="marginnote">「投影」的比喻最贴切：联合密度是一座立体山丘，边缘密度 $f_X(x)$ 就是把这个山丘沿 $y$ 方向「压扁」到 $x$ 轴上——每个 $x$ 处的高度变成该处 $y$ 方向所有高度的积分，即「累积面积投影成高度」。</span>

## 1 连续情形的边缘密度：积掉一个变量

设 $(X,Y)$ 的联合密度为 $f(x,y)$，则 $X$ 与 $Y$ 各自的**边缘概率密度（marginal density）**为

$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y)\, dy, \qquad f_Y(y) = \int_{-\infty}^{+\infty} f(x, y)\, dx$$

「积掉 $Y$」：对每个固定的 $x$，把 $y$ 方向的所有 $f(x,y)$ 累加，得到 $X$ 在 $x$ 处的密度。它与离散的「行和」$\sum_j p_{ij}$ 完全对应——求和变积分。<span class="marginnote">边缘密度的归一性自动成立：$\int f_X(x)\,dx = \iint f(x,y)\,dx\,dy = 1$。所以算完 $f_X$ 后可以立刻验证它是不是合法的密度——若积分不等于 1，说明定界或计算有误。</span>

**例**：设 $f(x,y) = \begin{cases} 6xy, & 0 \le x \le 1,\ 0 \le y \le 1 \\ 0, & \text{其他} \end{cases}$。则

$$f_X(x) = \int_0^1 6xy\, dy = 6x \cdot \frac{y^2}{2}\Big|_0^1 = 3x, \qquad 0 \le x \le 1$$

且 $\int_0^1 3x\,dx = 3/2 \ne 1$——等等，这里错了！原来 $6x \cdot \frac12 = 3x$，$\int_0^1 3x dx = \frac32$。实际上正确的归一应为 $f_X(x) = 3x$ 且 $\int_0^1 3x = 1.5$，说明我举的例子密度归一性不成立。<span class="marginnote">这个反例教训极佳：$f(x,y) = 6xy$ 在单位正方形上归一吗？$\int_0^1\int_0^1 6xy\,dx\,dy = 6 \cdot \frac12 \cdot \frac12 = 3/2 \ne 1$——它根本不是合法密度！正确的归一密度应为 $f(x,y) = 4xy$（$\int\int 4xy = 4 \cdot 1/2 \cdot 1/2 = 1$），此时 $f_X(x) = \int_0^1 4xy\,dy = 2x$，$\int_0^1 2x = 1$ ✓。做题时先验归一，避免整套白算。</span>

**修正后的例**：$f(x,y) = 4xy$（$0\le x,y\le 1$），则 $f_X(x) = \int_0^1 4xy\,dy = 2x$（$0\le x\le 1$），$f_Y(y) = 2y$。两个边缘都是「锥形密度」，联合是它们的乘积——$4xy = 2x \cdot 2y$，这正是独立性的预告。

## 2 边缘分布函数：极限与积分

边缘分布函数也可以从联合分布函数取极限得到，或从边缘密度积分得到，两条路殊途同归：

$$F_X(x) = F(x, +\infty) = \int_{-\infty}^{x} f_X(t)\, dt, \qquad F_Y(y) = F(+\infty, y)$$

- **从联合分布函数**：$F_X(x) = \lim_{y \to +\infty} F(x,y)$，即把 $Y$ 的约束完全放开；
- **从边缘密度**：$F_X(x) = \int_{-\infty}^{x} f_X(t)\, dt$，与一维完全一样。

**易错点｜辨析：** 边缘密度不是「把联合密度取极限 $y \to \infty$」——那会得到 0。正确操作是**积分**（离散是求和），不是取极限。只有分布函数才用取极限。把「密度用积分、分布函数用极限」这对规则记牢，是二维边缘分布题不丢分的关键。<span class="marginnote">再辨析一处：边缘密度 $f_X(x)$ 的量纲也与联合不同。联合密度 $f(x,y)$ 是「每单位面积的概率」，边缘密度 $f_X(x)$ 是「每单位长度的概率」——积掉一个变量，量纲就降一维。这解释了为什么二者数值上不可直接比较。</span>

## 3 联合决定边缘，边缘不决定联合

这是本章最重要的认识之一，用表格语言说：

- **联合分布律 → 边缘分布律**：行和/列和，一步求和；
- **边缘分布律 ↛ 联合分布律**：仅有 $p_{i\cdot}$ 和 $p_{\cdot j}$，无法确定 $p_{ij}$——还缺「关联」信息。

连续情形同理：仅知 $f_X$ 与 $f_Y$，有无数种 $f(x,y)$ 与它们兼容。**唯一例外是独立的情形**：若 $X$ 与 $Y$ 独立，则 $f(x,y) = f_X(x) f_Y(y)$，联合被边缘唯一确定——这是下一节条件分布与独立性的核心入口。

**例（反直觉）**：设 $X \sim U(-1,1)$，$Y = X^2$。$Y$ 的分布完全由 $X$ 决定，但 $X$、$Y$ 各自的边缘分布都正常存在。若只看边缘，你会以为它们是两个无关变量；实际 $Y$ 是 $X$ 的确定性函数，联合分布集中在抛物线 $y = x^2$ 上。<span class="marginnote">$Y = X^2$ 的联合分布落在一条曲线上，说明「曲线上的概率」在连续二维里可以是 1——又一个「概率为 1 的事件可以很窄」的例子。它直观地展示了：边缘分布完全无法反映两个变量的函数依赖关系，必须靠联合分布或相关系数。</span>

## 4 公式解析：边缘密度的投影计算

边缘密度的计算流程用「先画区域、再定积分界」展开，以三角形域 $D: 0 \le x \le 1, 0 \le y \le x$ 上的均匀分布（密度 $f(x,y) = 2$）为例：

$$

f_X(x) = \int_{0}^{x} 2\, dy = 2x, \qquad 0 \le x \le 1

$$

- **第一步，固定 $x$ 定 $y$ 界**：$D$ 中 $y$ 的范围是 $0$ 到 $x$（下界是 $y=0$，上界是斜边 $y = x$）。于是内层积分从 $0$ 积到 $x$，被积函数是常数 2。
- **第二步，积内层**：$\int_0^x 2\,dy = 2x$。结果只含 $x$，正是 $f_X$ 的表达式。
- **第三步，检查支撑与归一**：$x \in [0,1]$，$\int_0^1 2x\,dx = 1$ ✓。而 $f_Y(y) = \int_y^1 2\,dx = 2(1-y)$（$0 \le y \le 1$）——注意 $Y$ 的积分界与 $X$ 完全不同，因为区域形状不同。

**注意 $X$ 与 $Y$ 的积分界是「不对称」的**：求 $f_X$ 时 $y$ 从 0 到 $x$；求 $f_Y$ 时 $x$ 从 $y$ 到 1。每次都按区域图重新定界，是边缘分布计算的基本功。

## 5 边缘分布的深入应用与实例

边缘分布是「从联合投影到单变量」的操作，它的计算、解读与意义值得展开。

### 例：离散边缘分布

**例**：联合分布律表，行和 $p_{i\cdot} = \sum_j p_{ij}$ 是 $X$ 的边缘分布律、列和 $p_{\cdot j}$ 是 $Y$ 的——**「行和列和写进页边，就是边缘分布」**（marginal 之名由此而来）。

### 例：连续边缘密度

**例**：$f(x,y) = 4xy$（$0 \le x,y \le 1$）。$f_X(x) = \int_0^1 4xy\,dy = 2x$，$f_Y(y) = 2y$。**「积掉一个变量」**是连续边缘的全部操作。

### 联合决定边缘、边缘不决定联合

| 信息 | 能否推出联合 |
| --- | --- |
| 联合 $f(x,y)$ | 能（积掉得边缘） |
| 边缘 $f_X, f_Y$ | 否（缺关联信息） |
| 边缘 + 独立 | 能（相乘） |

**「联合 → 边缘唯一，边缘 → 联合不唯一」**——除非独立，边缘拼不出联合。

### 例：边缘分布的反直觉

**例**：$X \sim U(-1,1)$，$Y = X^2$。$X$、$Y$ 的边缘分布都正常，但联合集中在抛物线 $y = x^2$ 上——**「只看边缘以为无关，实际 $Y$ 完全由 $X$ 决定」**。边缘分布看不见关联。

### 边缘密度与条件密度的关系

$$f_{X\mid Y}(x\mid y) = \frac{f(x,y)}{f_Y(y)}, \qquad f_X(x) = \int f_{X\mid Y}(x\mid y) f_Y(y)\, dy$$

**「条件 × 边缘 = 联合，积掉边缘 = 全概率」**——三个密度互为表里。

**易错点｜辨析：** ① 边缘密度用「积分」、边缘分布函数用「极限 $y \to \infty$」——别混；② 边缘密度的积分界按区域形状定（不对称是常态）；③ 联合均匀的边缘不必均匀——三角域上边缘是三角形。

再补一张「一维 vs 二维分布」对照：

| | 一维 | 二维 |
| --- | --- | --- |
| 分布函数 | $F(x)$ | $F(x,y)$ |
| 边缘 | — | 积掉一个变量 |
| 条件 | — | 固定一个变量 |
| 独立判据 | — | $F = F_X F_Y$ |

「二维多出边缘与条件两个操作」——理解二维，一维是它的投影。

## 6 小结

- **边缘密度**：$f_X(x) = \int_{-\infty}^{+\infty} f(x,y)\,dy$，$f_Y(y) = \int_{-\infty}^{+\infty} f(x,y)\,dx$——把另一个变量「积掉」。
- **边缘分布函数**：$F_X(x) = F(x,+\infty)$（取极限）或对 $f_X$ 积分；**密度用积分、分布函数用极限**。
- **联合决定边缘，边缘不决定联合**；唯有独立时联合 $=$ 边缘之积。
- 边缘密度须验归一（$\int f_X = 1$），做题前先验联合密度是否合法。
- 「画区域 → 逐变量定界 → 逐层积分」是边缘分布计算的三板斧。

在下一节，我们固定一个变量看另一个——**条件分布**，它把「给定 $Y = y$ 时 $X$ 的分布」变成条件概率公式的连续版本。
