## 为什么从多步转移概率开始

一步转移矩阵 $P$ 描述「走一步」，可现实常问「走 $n$ 步」：三天后下雨的概率、第 10 次访问落在哪个页面。**多步转移概率（n-step transition probability）** $p^{(n)}_{ij} = P\{X_{m+n} = j \mid X_m = i\}$ 解决这个问题，而计算它的钥匙是 **C-K 方程（Chapman–Kolmogorov equation）**——**多步转移 = 中途经过某个中间状态的所有路径概率之和**。

C-K 方程是马尔可夫链的「路径求和」法则：它把「$n$ 步转移」拆成「$r$ 步到中间态 + $n-r$ 步到终点」，用全概率公式缝合。它是转移矩阵幂运算的理论基础，也是理解状态分类、极限分布的关键。<span class="marginnote">C-K 方程的精髓一句话：<strong>$p^{(n+m)}_{ij} = \sum_k p^{(n)}_{ik} p^{(m)}_{kj}$——从 $i$ 到 $j$ 走 $n+m$ 步，等于先走 $n$ 步到某个中间状态 $k$，再走 $m$ 步到 $j$，对所有可能的 $k$ 求和</strong>。中间状态 $k$ 是「桥」——一切路径都要在某个时刻经过某个 $k$。</span>

## 1 多步转移概率与矩阵幂

**n 步转移概率**：$p^{(n)}_{ij} = P\{X_{m+n} = j \mid X_m = i\}$（齐次链下与 $m$ 无关）。它们组成的矩阵 $P^{(n)} = (p^{(n)}_{ij})$。

**核心结论**：$P^{(n)} = P^n$——**n 步转移矩阵 = 一步转移矩阵的 $n$ 次幂**。于是「$n$ 步概率」全部由矩阵幂给出，$P^n$ 的第 $(i,j)$ 元素就是 $p^{(n)}_{ij}$。<span class="marginnote">「$P^{(n)} = P^n$」是马尔可夫链最漂亮的计算结论：多步转移不需要「另外的公式」，只需要「矩阵自乘」。这也解释了为何马尔可夫链理论与线性代数（矩阵对角化、谱分解）如此紧密——求 $P^n$ 的解析形式常常依赖矩阵的特征值分解，那是「计算」与「理论」的交汇点。</span>

## 2 C-K 方程的推导

**Chapman–Kolmogorov 方程**：对任意非负整数 $r$（$0 \le r \le n$）与状态 $i, j$，

$$p^{(n)}_{ij} = \sum_k p^{(r)}_{ik}\, p^{(n-r)}_{kj}$$

**推导**：把「从 $i$ 出发 $n$ 步到 $j$」按「第 $r$ 步在哪」分类——第 $r$ 步必在某状态 $k$，于是用全概率公式拆成「先 $r$ 步到 $k$」×「再 $n-r$ 步到 $j$」，对 $k$ 求和。<span class="marginnote">C-K 方程的推导只用了一步「全概率公式 + 马尔可夫性」：事件「$X_{r} = k$」构成互斥完备分类；马尔可夫性保证「到 $k$ 后怎么走」只依赖 $k$、不依赖更早的历史——于是两项概率相乘。$r$ 可以取 $0$ 到 $n$ 任意值，都成立——这是「路径求和」的普适性。</span>

**矩阵形式**：$P^{(n)} = P^{(r)} P^{(n-r)}$——C-K 方程就是「矩阵幂的可分性」：$P^n = P^r P^{n-r}$。

## 3 例：用 C-K 方程算多步转移

**例（两状态天气）**：$P = \begin{pmatrix} 0.8 & 0.2 \\ 0.4 & 0.6 \end{pmatrix}$，求「今天晴，两天后雨」的概率 $p^{(2)}_{01}$。

方法一（矩阵幂）：$P^2 = \begin{pmatrix} 0.72 & 0.28 \\ 0.56 & 0.44 \end{pmatrix}$，$p^{(2)}_{01} = 0.28$。

方法二（C-K 方程，$r = 1$）：$p^{(2)}_{01} = p^{(1)}_{00}p^{(1)}_{01} + p^{(1)}_{01}p^{(1)}_{11} = 0.8\times0.2 + 0.2\times0.6 = 0.16 + 0.12 = 0.28$——「晴→晴→雨」与「晴→雨→雨」两条路径相加，结果一致。<span class="marginnote">「方法二」展示了 C-K 方程的物理含义：从晴到两天后雨，只有两条「一天中转」的路径——晴→晴→雨、晴→雨→雨，各自概率相乘再加总。这就是「路径求和」：多步转移 = 所有可能路径的概率之和。记住「走两步 = 先到中间态再到终点」，C-K 方程不证自明。</span>

## 4 公式解析：C-K 方程为何成立

C-K 方程的推导是「条件分解」的标准示范，拆开：

$$

p^{(n)}_{ij} = P\{X_n = j \mid X_0 = i\} = \sum_k P\{X_n = j, X_r = k \mid X_0 = i\} = \sum_k p^{(r)}_{ik}\, p^{(n-r)}_{kj}

$$

- **第一步，全概率分解**：事件「$X_n = j$」按「$X_r = k$」分类（$k$ 互斥完备），拆成联合概率之和。
- **第二步，乘法公式**：$P\{X_n = j, X_r = k \mid X_0 = i\} = P\{X_r = k \mid X_0 = i\} \cdot P\{X_n = j \mid X_r = k, X_0 = i\}$。
- **第三步，马尔可夫性化简**：给定 $X_r = k$，$X_n$ 与 $X_0$ 条件独立——第二因子 $= P\{X_n = j \mid X_r = k\} = p^{(n-r)}_{kj}$（齐次链）。两项即 $p^{(r)}_{ik} p^{(n-r)}_{kj}$。

「全概率分解 + 乘法公式 + 马尔可夫性化简」是 C-K 方程的完整推导链。它示范了马尔可夫链证明的通用手法：用马尔可夫性砍掉多余的历史，把多步问题拆成可乘的块。

## 5 C-K 方程的深入应用

C-K 方程不只是理论工具，它撑起马尔可夫链计算的半边天——从矩阵对角化求 $P^n$，到吸收概率、随机游走的分布，处处是它的身影。

### 用特征值分解求 Pⁿ

当转移矩阵 $P$ 可对角化时，$P = Q\Lambda Q^{-1}$，则 $P^n = Q\Lambda^n Q^{-1}$——**多步转移矩阵的解析形式由特征值决定**。若 $P$ 的特征值为 $\lambda_0 = 1, \lambda_1, \ldots$（$|\lambda_k| < 1$ 对 $k \ge 1$），则 $P^n$ 的每个元素收敛到极限分布相关的常数，且收敛速度由第二大特征值 $|\lambda_1|$ 决定——$|\lambda_1|$ 越接近 1，链「混合」越慢。

**例（两状态天气）**：$P = \begin{pmatrix} 0.8 & 0.2 \\ 0.4 & 0.6 \end{pmatrix}$ 的特征值为 $\lambda_0 = 1$、$\lambda_1 = 0.4$。于是 $P^n \to \begin{pmatrix} 2/3 & 1/3 \\ 2/3 & 1/3 \end{pmatrix}$，收敛速度按 $0.4^n$——「记忆」每步衰减 0.4 倍。这正是「第二大特征值控制混合速度」的具体演示。

### 随机游走的 n 步分布

对简单随机游走（每步 $\pm 1$ 等概率），$n$ 步后位置的分布可用 C-K 方程或组合计数直接给出：

$$P\{X_n = k\} = \binom{n}{(n+k)/2}\left(\frac12\right)^n \quad (\text{当 } n+k \text{ 为偶数})$$

这是「$n$ 步里 $k$ 步净向上」的计数，与第二章二项分布同构。C-K 方程在这里的作用是「把多步问题分解成一步组合」——每步独立时，多步概率就是组合计数。

### 吸收概率与期望到达时间

C-K 方程还是求**吸收概率**的工具：设链有吸收状态，从暂留态 $i$ 出发最终被吸收到某吸收态的概率满足一组线性方程（由「走一步后重新分析」写出）。这套「首达步分析」本质上是 C-K 方程在「最终事件」上的应用，在排队论（顾客最终被服务）、赌博（最终破产）里是标准方法。

**易错点｜辨析：** 用特征值求 $P^n$ 只适用于可对角化的矩阵（教材多数例题满足）；含重特征值或不可对角化时需改用 Jordan 标准形。另外，$P^n$ 的元素必须仍非负且行和为 1——算完用「行和 = 1」自检，若出现负数或行和偏差，说明对角化或代入有误。



## 6 典型例题：C-K 方程与矩阵方法实战

**例 1（三状态链）**：$P = \begin{pmatrix} 0.5 & 0.5 & 0 \\ 0.5 & 0 & 0.5 \\ 0 & 0.5 & 0.5 \end{pmatrix}$，求 $p^{(2)}_{02}$。用 C-K 方程（$r=1$）：

$$p^{(2)}_{02} = p_{00}p_{02} + p_{01}p_{12} + p_{02}p_{22} = 0.5\times 0 + 0.5\times 0.5 + 0 = 0.25$$

**例 2（随机游走）**：一维简单随机游走，求 $P\{X_4 = 2 \mid X_0 = 0\}$。4 步净向上 2 步 = 3 上 1 下，路径数 $\binom{4}{1} = 4$：

$$P\{X_4 = 2\} = 4\left(\frac12\right)^4 = 0.25$$

**例 3（吸收概率）**：赌徒本金 1 元，每局 ±1 元等概率，到 0 或 3 元停止。设 $u_i$ 为从 $i$ 元出发最终到 3 元的概率，则 $u_0 = 0$、$u_3 = 1$，且 $u_i = \frac12 u_{i-1} + \frac12 u_{i+1}$（首达步方程）。解得 $u_1 = 1/3$、$u_2 = 2/3$——这套方程正是 C-K 方程在吸收问题上的应用。

三个例子的共同结构值得点破：**把「多步/最终」问题翻译成「走一步后重新分析」的方程**——例 1 用中间状态求和（C-K），例 3 用首达步方程。这背后是同一条全概率思想：马尔可夫性保证「走到 $k$ 后，剩下的路只从 $k$ 重新开始」，于是多步概率、吸收概率都能写成「一步转移 + 递归」的形式。理解了这条主线，C-K 方程就不再是孤立的公式，而是「路径求和 + 递归」这一马尔可夫链通用方法的第一次亮相。

值得一提：这套「递归方程」方法在连续时间同样成立——生灭过程的微分方程、布朗运动的首达时问题，都是「无穷小时间步 + 递归」的变体。所以本节练熟的不是「一个公式」，而是「把动态概率问题改写成递归方程」的通用技能，它会在随机过程与随机分析的更深处反复出现。

再补一张「三种多步概率算法」的对照，明确何时用哪种：

| 方法 | 工具 | 适用 |
| --- | --- | --- |
| C-K 方程（$r=1$） | $\sum_k p_{ik} p^{(n-1)}_{kj}$ | 手算小规模 |
| 矩阵幂 $P^n$ | 矩阵乘法/对角化 | 通用、可编程 |
| 特征值分解 | $Q\Lambda^n Q^{-1}$ | 求解析式、看收敛速度 |

「小规模手算用 C-K、通用计算用矩阵幂、求解析解用特征值」——三种算法是同一数学的不同实现。

## 7 小结

- **n 步转移概率** $p^{(n)}_{ij}$ 组成矩阵 $P^{(n)} = P^n$——多步转移 = 矩阵幂。
- **C-K 方程** $p^{(n)}_{ij} = \sum_k p^{(r)}_{ik} p^{(n-r)}_{kj}$——多步转移 = 经过中间状态的路径概率之和。
- 矩阵形式 $P^n = P^r P^{n-r}$；推导靠「全概率 + 乘法公式 + 马尔可夫性」。
- 「走两步 = 先到中间态再到终点」是 C-K 方程的物理直觉。
- C-K 方程是状态分类、极限分布、稳态分析的理论地基。
