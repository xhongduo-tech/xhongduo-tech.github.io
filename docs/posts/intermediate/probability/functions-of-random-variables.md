## 为什么从函数的分布开始

到目前为止，我们研究的都是「$X$ 本身的分布」。但现实里我们常常关心的是**经过加工的量**：已知圆的半径 $R$ 服从某分布，问面积 $S = \pi R^2$ 的分布；已知测量误差 $E$ 的分布，问误差平方 $E^2$ 的分布；已知电压 $V$ 的分布，问功率 $V^2/R$ 的分布。这些问题的共同点：**输入随机变量 $X$，输出 $Y = g(X)$，求 $Y$ 的分布**。这就是「随机变量的函数的分布」，本章最后一个、也是最富技巧性的主题。

这条技能的价值远超本章：第三章的 $Z = X + Y$、第六章的样本均值与样本方差、第七章最大似然估计里的对数似然——全部是「函数的分布」的应用。可以说，掌握了「从 $X$ 的分布推出 $g(X)$ 的分布」，你就拿到了概率论里最通用的「分布传送带」。<span class="marginnote">「函数的分布」还有一个工程层面的名字——<strong>不确定性传播（uncertainty propagation）</strong>。工程师关心「输入有随机扰动，输出有多大的不确定性」，本质就是求 $g(X)$ 的分布或至少它的均值方差。本节的方法论在误差分析、传感器标定里天天在用。</span>

## 1 离散情形：把概率原样搬过去

设 $X$ 是离散型随机变量，$Y = g(X)$。则 $Y$ 也是离散型，其分布律直接从 $X$ 的分布律「搬运」得到：

$$P\{Y = y_j\} = \sum_{g(x_i) = y_j} P\{X = x_i\}$$

也就是：$Y$ 取 $y_j$ 的概率，等于所有「映射到 $y_j$ 的 $x_i$」的概率之和。**若 $g$ 是一一对应，概率原样搬家；若多个 $x_i$ 映到同一个 $y_j$，概率要相加**。<span class="marginnote">「多对一」是这里唯一需要小心的点：$g(x) = x^2$ 时，$Y = 4$ 可以由 $X = 2$ 或 $X = -2$ 触发，两者概率相加。若遗漏一个来源，分布律之和就不为 1——可用归一性自检。</span>

**例**：$X$ 取 $-2, 0, 2$，概率各 $1/3$。令 $Y = X^2$，则 $Y$ 取 $0, 4$，且 $P\{Y=0\} = 1/3$，$P\{Y=4\} = 1/3 + 1/3 = 2/3$。注意 $Y$ 的取值个数从 3 个压缩到 2 个，概率随之合并。

## 2 连续情形：分布函数法

连续型的情形不能直接搬密度，而要用**分布函数法**——先求 $Y$ 的分布函数，再求导得密度。三步流程：

1. **写出定义**：$F_Y(y) = P\{Y \le y\} = P\{g(X) \le y\}$；
2. **解不等式**：把 $\{g(X) \le y\}$ 翻译成 $X$ 的取值范围（一个或几个区间）；
3. **积分或套 $F_X$**：用 $X$ 的分布函数表达出来，再对 $y$ 求导得 $f_Y(y)$。

**例（线性函数）**：$Y = aX + b$（$a > 0$）：

$$F_Y(y) = P\{aX + b \le y\} = P\left\{X \le \frac{y-b}{a}\right\} = F_X\left(\frac{y-b}{a}\right)$$

求导得 $f_Y(y) = \frac{1}{a} f_X\left(\frac{y-b}{a}\right)$——**线性变换把密度横向压缩/拉伸并除以 $a$ 保持面积归一**。<span class="marginnote">这个「除以 $a$」是连续情形独有的关键：$g(X)$ 把 $x$ 轴拉伸后，密度若不变，积分面积就会改变。要维持总面积 1，必须乘上雅可比因子 $1/a$。这一思想到第三章二维变换时会长成真正的雅可比行列式。</span>

**例（单调函数一般式）**：若 $g$ 严格单调且可导，$g'$ 不变号，$h = g^{-1}$ 为反函数，则

$$f_Y(y) = f_X\big(h(y)\big)\,\big|h'(y)\big|$$

这个「反函数 + 导数绝对值」公式是分布函数法的速成版，可省去每回重解不等式。但**必须确认 $g$ 单调**——非单调时（如 $g(x)=x^2$）不能直接套，要回到分布函数法分段处理。

## 3 非单调情形的处理：以平方为例

设 $X \sim N(0,1)$，求 $Y = X^2$ 的密度。$g(x) = x^2$ 在 $(-\infty, 0)$ 与 $(0, \infty)$ 上分别单调，但整体不单调。用分布函数法：

$$F_Y(y) = P\{X^2 \le y\} = P\{-\sqrt{y} \le X \le \sqrt{y}\} = \Phi(\sqrt{y}) - \Phi(-\sqrt{y})$$

对 $y$ 求导（注意 $y > 0$，且 $\Phi(-\sqrt{y}) = 1 - \Phi(\sqrt{y})$）：

$$f_Y(y) = \varphi(\sqrt{y})\cdot\frac{1}{2\sqrt{y}} + \varphi(\sqrt{y})\cdot\frac{1}{2\sqrt{y}} = \frac{1}{\sqrt{2\pi y}}\, e^{-y/2}, \qquad y > 0$$

这个分布叫**$\chi^2$ 分布**在自由度 1 时的特例——标准正态的平方服从 $\chi^2(1)$。它在第六章抽样分布里是绝对的明星。<span class="marginnote">「标准正态的平方 = $\chi^2_1$」是本节的第一个彩蛋：它预告了第六章 $\chi^2$ 分布的真正来历——$n$ 个独立标准正态的平方和。到那时，本节算出的 $\frac{1}{\sqrt{2\pi y}}e^{-y/2}$ 会作为 $n=1$ 的特例被重新遇见。</span>

**易错点｜辨析：** 求密度前先确定 $Y$ 的**支撑**（取值范围）。$Y = X^2 \ge 0$，所以密度只在 $y > 0$ 有定义，$y \le 0$ 处为 0。忽略支撑、对全体实数写密度，是函数分布题最常见的失分点。另外，变换后一定要验证 $\int f_Y(y)\, dy = 1$。

## 4 公式解析：分布函数法的三步

以 $X \sim U(0, 1)$、$Y = -\frac{1}{\lambda}\ln(1-X)$ 为例——这是「用均匀分布造指数分布」的逆变换采样法：

$$

F_Y(y) = P\{Y \le y\} = P\{-\tfrac{1}{\lambda}\ln(1-X) \le y\}

$$

- **第一步，解不等式**：$-\frac{1}{\lambda}\ln(1-X) \le y \iff \ln(1-X) \ge -\lambda y \iff 1 - X \ge e^{-\lambda y} \iff X \le 1 - e^{-\lambda y}$（注意 $\ln$ 是增函数且不等号方向两次翻转）。
- **第二步，套 $F_X$**：$X \sim U(0,1)$ 的分布函数 $F_X(x) = x$（$0<x<1$），故 $F_Y(y) = 1 - e^{-\lambda y}$（$y > 0$）。
- **第三步，求导得密度**：$f_Y(y) = \lambda e^{-\lambda y}$（$y>0$）——正是指数分布 $E(\lambda)$。

**「均匀分布经对数变换生成指数分布」**，这条公式是蒙特卡洛采样与随机模拟的起点：计算机只要会造 $U(0,1)$ 随机数，就能造任意分布的样本。它也是第十一章随机过程模拟、第七章统计抽样的技术地基。

## 5 函数分布的深入应用与实例

「已知 $X$ 的分布，求 $g(X)$ 的分布」是概率论的通用技能，它的方法、实例与边界值得展开。

### 例：分布函数法

**例**：$X \sim U(0,1)$，$Y = -\frac1\lambda\ln(1-X)$。$F_Y(y) = P\{Y \le y\} = P\{X \le 1-e^{-\lambda y}\} = 1 - e^{-\lambda y}$——$Y \sim E(\lambda)$。**「均匀经对数变换生成指数」**是逆变换采样的标准例。

### 方法对照

| 方法 | 适用 | 关键 |
| --- | --- | --- |
| 分布函数法 | 一般 | 先 $F_Y$ 再求导 |
| 单调变换 | $g$ 单调可导 | $f_Y = f_X(h)|h'|$ |
| 逐点求和 | 离散 | 多对一相加 |

**「非单调回退分布函数法、单调用反函数公式」**——方法选择看 $g$ 的形状。

### 例：标准正态平方

**例**：$X \sim N(0,1)$，$Y = X^2$。$F_Y(y) = \Phi(\sqrt y) - \Phi(-\sqrt y)$，求导得 $f_Y(y) = \frac{1}{\sqrt{2\pi y}}e^{-y/2}$——**$\chi^2(1)$ 分布**，第六章的伏笔。

### 例：线性变换

**例**：$X \sim N(\mu, \sigma^2)$，$Y = aX + b$，$f_Y(y) = \frac{1}{|a|}f_X(\frac{y-b}{a})$——**「线性变换横向拉伸 + 除以 $|a|$ 保面积」**。

### 易错辨析

| 陷阱 | 后果 |
| --- | --- |
| 忘了支撑 | 密度定义域错 |
| 非单调套公式 | 密度错 |
| 忘了验归一 | 概率丢失 |

**「先定支撑、再选方法、最后验归一」**——函数分布三步走。

## 6 小结

- **离散情形**：$P\{Y = y_j\} = \sum_{g(x_i)=y_j} P\{X = x_i\}$，多对一时概率相加。
- **连续情形·分布函数法**：先 $F_Y(y) = P\{g(X) \le y\}$，解不等式、套 $F_X$、求导得 $f_Y$。
- **单调可导情形**：$f_Y(y) = f_X(h(y))\,|h'(y)|$，$h$ 为反函数；非单调必须回退分布函数法。
- **先定支撑**：$Y$ 的取值范围决定密度定义域，变换后必须验归一。
- 本节彩蛋：$N(0,1)$ 的平方服从 $\chi^2(1)$——第六章抽样分布的种子。

在下一节，我们进入第三章：当随机变量的个数从一个变成两个，分布从「一条线」变成「一张面」——**二维随机变量与联合分布函数**。
