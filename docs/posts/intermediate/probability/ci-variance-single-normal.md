## 为什么从方差的区间估计开始

均值的区间估计用 z 或 t，方的区间估计则换主角——**χ² 分布**。方差 $\sigma^2$ 的置信区间在工程与质检里极其重要：「这批产品的重量波动是否在允许范围内」，「这台机器的一致性是否达标」——这些问的是**波动**，不是均值。而在第六章我们已经看到，$\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$——它就是方差区间估计的枢轴量。

方差区间的特殊之处在「不对称」：χ² 分布不是对称的，所以方差的置信区间不以 $\hat\sigma^2$ 为中心——上下限到估计量的距离不相等。这与均值区间的对称形态形成鲜明对比，也是本节最需要适应的新感觉。<span class="marginnote">「方差区间不对称」的直觉：χ² 分布右偏，所以它的两个分位点 $\chi^2_{1-\alpha/2}$ 与 $\chi^2_{\alpha/2}$ 到中心的距离不同，反解出的区间自然不等宽。这是「分布不对称 ⇒ 区间不对称」的第一次现身——到第八章方差的假设检验、第九章回归里 $\sigma^2$ 的区间，这套不对称感会一直跟随。</span>

## 1 方差的置信区间

设 $X_1, \ldots, X_n$ 来自 $N(\mu, \sigma^2)$，$\mu$ 未知（通常如此），$S^2$ 为样本方差。枢轴量

$$\chi^2 = \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$$

取 $\chi^2_{1-\alpha/2}(n-1)$ 与 $\chi^2_{\alpha/2}(n-1)$ 使

$$P\left\{\chi^2_{1-\alpha/2}(n-1) \le \frac{(n-1)S^2}{\sigma^2} \le \chi^2_{\alpha/2}(n-1)\right\} = 1 - \alpha$$

反解得 $\sigma^2$ 的**置信区间**：

$$\left(\frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)},\ \ \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right)$$

**注意分母的位置**：上限用 $\chi^2_{1-\alpha/2}$（小分位点），下限用 $\chi^2_{\alpha/2}$（大分位点）——因为反解时不等式方向翻转。<span class="marginnote">方差区间公式里的「分母颠倒」是最容易出错的地方：$\frac{(n-1)S^2}{\chi^2_{\alpha/2}}$ 是下限、$\frac{(n-1)S^2}{\chi^2_{1-\alpha/2}}$ 是上限——<strong>大分位点在分母给出下限，小分位点在分母给出上限</strong>。先记住「$\sigma^2$ 落在里层的概率」，再反解一次，就不容易搞反。</span>

**标准差区间**：对 $\sigma^2$ 的区间开平方，得 $\sigma$ 的置信区间：

$$\left(\sqrt{\frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)}},\ \ \sqrt{\frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}}\right)$$

## 2 例：方差区间计算

**例**：某车间零件直径 $X \sim N(\mu, \sigma^2)$，抽查 $n = 16$ 件，$s^2 = 0.04$ mm²。求 $\sigma^2$ 的 95% 置信区间。查 χ² 表：$\chi^2_{0.025}(15) = 27.49$，$\chi^2_{0.975}(15) = 6.26$。则

$$\text{下限} = \frac{15 \times 0.04}{27.49} = 0.0218, \qquad \text{上限} = \frac{15 \times 0.04}{6.26} = 0.0958$$

$\sigma^2$ 的 95% 置信区间约 $(0.0218, 0.0958)$，$\sigma$ 的约 $(0.148, 0.310)$ mm。<span class="marginnote">注意这里的上下限并不对称于 0.04：上限 $0.0958$ 离 $0.04$ 比下限 $0.0218$ 远得多——χ² 右偏造成的「右端拉长」。这个不对称是方差区间的标志性特征，也是判断「这条区间算得对不对」的直觉检查：方差区间几乎总是右侧更长。</span>

## 3 易错点辨析

**易错点｜辨析：** 方差区间估计有三个高频陷阱：

1. **分位点方向搞反**：$\chi^2_{\alpha/2}$（上 $\alpha/2$ 分位点，较大）在分母时是下限；别与均值的 z 区间搞混（那里是对称的，上下限用同一个 $z_{\alpha/2}$）；
2. **自由度写错**：$n-1$ 不是 $n$——$S^2$ 的 χ² 自由度是 $n-1$；
3. **开方与平方混淆**：求 $\sigma^2$ 的区间不要开方，求 $\sigma$ 的区间必须开方——看清题目问的是方差还是标准差。

<span class="marginnote">「求 $\sigma^2$ 的区间还是 $\sigma$ 的区间」是文字题陷阱：题目若说「求方差的置信区间」直接套公式；若说「求标准差的置信区间」，先算方差区间再开方，端点的平方根就是标准差的端点。开方会改变区间形状（不再对称），但端点对应关系保持单调。</span>

## 4 公式解析：枢轴量反解的两步

方差区间的推导用「反解枢轴量」的标准流程，拆开看分母颠倒的来由：

$$

P\left\{\chi^2_{1-\alpha/2} \le \frac{(n-1)S^2}{\sigma^2} \le \chi^2_{\alpha/2}\right\} = 1 - \alpha

$$

- **第一步，原不等式**：枢轴量 $\frac{(n-1)S^2}{\sigma^2}$ 落在两个 χ² 分位点之间，概率 $1-\alpha$——分位点按「下尾 $\alpha/2$、上尾 $\alpha/2$」截取。
- **第二步，反解 $\sigma^2$**：对不等式取倒数（注意不等式方向翻转）：$\frac{1}{\chi^2_{\alpha/2}} \le \frac{\sigma^2}{(n-1)S^2} \le \frac{1}{\chi^2_{1-\alpha/2}}$。
- **第三步，乘 $(n-1)S^2$**：$\frac{(n-1)S^2}{\chi^2_{\alpha/2}} \le \sigma^2 \le \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}}$——大分位点出现在下限分母。

「先写枢轴量落在区间里，再取倒数翻转、乘回分子」是方差区间反解的全部。χ² 不对称导致取倒数时两端距离改变，这正是区间不对称的来源。

## 5 方差区间估计的深入应用

方差区间是「波动管控」的工具，它的计算、解读与实务值得展开。

### 例：完整计算

**例**：$n = 16$，$s^2 = 0.04$。$\chi^2_{0.025}(15) = 27.49$、$\chi^2_{0.975}(15) = 6.26$。95% 区间：

$$\left(\frac{15\times 0.04}{27.49},\ \frac{15\times 0.04}{6.26}\right) = (0.0218,\ 0.0958)$$

$\sigma$ 的 95% 区间 $(0.148, 0.310)$——「标准差约在 0.15–0.31 之间」。

### 区间不对称的解读

| 分位点 | 位置 | 作用 |
| --- | --- | --- |
| $\chi^2_{\alpha/2}$ | 右尾大值 | 分母 → 下限 |
| $\chi^2_{1-\alpha/2}$ | 左尾小值 | 分母 → 上限 |

**「χ² 右偏 ⇒ 区间右端长」**——方差区间几乎总是「右侧更长」，这是不对称分布的标志。

### 方差区间的应用场景

| 场景 | 问题 |
| --- | --- |
| 质量控制 | 波动是否超标 |
| 一致性验收 | 批次间波动 |
| 实验设计 | 方差预估计 |

**「均值管水平、方差管一致」**——方差区间是「一致性验收」的标准工具。

### 与均值区间的对照

| | 均值区间 | 方差区间 |
| --- | --- | --- |
| 分布 | z/t | χ² |
| 对称 | 对称 | 不对称 |
| 端点 | 等距 | 不等距 |

「均值区间对称、方差区间偏心」——记住这个差异，方差区间的计算就不易搞反。

**易错点｜辨析：** ① 分母分位点方向别搞反（大分位点在分母给下限）；② 自由度 $n-1$ 而非 $n$；③ 问方差开平方、问标准差开平方——看清题目对象。

## 6 小结

- **方差置信区间**：$\left(\frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)},\ \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right)$，枢轴量 $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$。
- **标准差区间**：对方差区间端点开平方。
- 由于 χ² 右偏，方差区间**不对称**（右端更长）——与均值的对称 z/t 区间形成对比。
- 三个陷阱：分位点方向、自由度 $n-1$、方差/标准差开方混淆。
- 方差区间是质检与一致性评估的标准工具，第八章方差检验的孪生兄弟。
