## 为什么从相关函数的性质开始

宽平稳过程的自相关函数 $R_X(\tau)$ 是它的「二阶签名」——所有二阶统计信息都浓缩在这一个单变量函数里。而它本身还有一组漂亮的**性质**：对称、有界、原点取最大、非负定。这些性质不只是理论装饰——它们是判断「给一个函数能不能当相关函数」的判据，也是推导功率谱（下一节）的工具。

相关函数的性质是第十三章从「描述」走向「分析」的关键：它把「自相关」从「一个定义」升级为「一个有结构的数学对象」，让傅里叶变换（维纳—辛钦）和谱分析成为可能。<span class="marginnote">相关函数的地位相当于「随机变量的方差」在静态世界的地位——一个数字概括波动，一个函数概括「时间关联结构」。它是平稳过程的完整二阶画像：$R_X(0)$ 是功率（方差），$R_X(\tau)$ 的形状描述「记忆的长度」，$R_X(\tau) \to \mu^2$ 反映长期均值。</span>

## 1 相关函数的基本性质

设 $\{X(t)\}$ 是宽平稳过程，自相关函数 $R_X(\tau)$ 满足：

1. **偶对称**：$R_X(\tau) = R_X(-\tau)$——相关性对「超前/滞后」对称；
2. **有界**：$|R_X(\tau)| \le R_X(0)$——**原点处取最大值**；
3. **非负定**：对任意 $n$、任意 $t_i$ 与复数 $a_i$，$\sum_{i,j} a_i \bar a_j R_X(t_i - t_j) \ge 0$；
4. **原点值 = 均方值**：$R_X(0) = E[X^2(t)] \ge 0$——过程的总功率。

**性质 2 的直觉**：$X(t)$ 与 $X(t)$ 的相关最大（自己与自己最相关），隔得越远相关性越弱——$R_X(\tau)$ 在 $\tau = 0$ 处达到峰顶。<span class="marginnote">「原点取最大」的证明只需一个不等式：$E[(X(t+\tau) - X(t))^2] \ge 0$，展开得 $2R_X(0) - 2R_X(\tau) \ge 0$，即 $R_X(\tau) \le R_X(0)$。这个「平方非负 → 相关有界」的推导是相关函数性质的标准示范——用「方差非负」这种基本事实推出「相关有界」。</span>

## 2 归一化相关与相关系数

把相关函数归一化，得**自相关系数（correlation coefficient function）**：

$$\rho_X(\tau) = \frac{C_X(\tau)}{C_X(0)} = \frac{R_X(\tau) - \mu^2}{R_X(0) - \mu^2}$$

其中 $C_X(\tau) = R_X(\tau) - \mu^2$ 是协方差函数。自相关系数满足 $|\rho_X(\tau)| \le 1$、$\rho_X(0) = 1$——它把「关联强度」标准化到 $[-1, 1]$，是第四章相关系数的动态版。

**例**：$C_X(\tau) = \sigma^2 e^{-\alpha|\tau|}$（指数衰减相关），则 $\rho_X(\tau) = e^{-\alpha|\tau|}$——$\tau = 0$ 时 1，随 $\tau$ 指数衰减，$\alpha$ 越大记忆越短。<span class="marginnote">「$e^{-\alpha|\tau|}$ 型相关」是最常用的相关模型（一阶 AR / RC 电路的输出）：它简单、衰减快、各态历经性好。$\alpha$ 的倒数 $1/\alpha$ 叫「相关时间」——「过程记住自己多久」。相关时间短的噪声「白」（谱平坦），长的「有色」（谱集中）——这是从相关函数到谱的直觉跳板。</span>

## 3 相关函数的信息解读

相关函数的形状透露过程的「性格」：

**$R_X(0)$ 大**：过程功率大（波动剧烈）；
**衰减快**：过程「记忆短」，各时刻关联弱——接近白噪声；
**衰减慢**：过程「记忆长」，缓慢漂移——低频为主；
**振荡衰减**：过程含周期性成分。

**例**：$R_X(\tau) = e^{-\alpha|\tau|}\cos(\beta\tau)$——指数衰减包络 × 余弦振荡：过程有「准周期」成分（以 $\beta$ 为频率），记忆随 $\alpha$ 衰减。相关函数的振荡直接对应功率谱的谱峰（下一节）。<span class="marginnote">「相关振荡 ↔ 谱峰」是相关函数最实用的解读：周期信号的 $R_X(\tau)$ 在 $\tau$ 增大时不衰减（纯周期），在功率谱里形成尖峰；噪声叠加后相关衰减、谱峰变宽。工程师「看相关函数的形状猜谱的形状」靠的就是这层对应——相关函数与功率谱是傅里叶变换对（维纳—辛钦），一个域的形态决定另一个域的形态。</span>

## 4 公式解析：原点取最大的证明

相关函数「原点取最大」是它最重要也最好证的性质，完整走一遍：

$$

E\left[(X(t+\tau) - X(t))^2\right] \ge 0 \quad \Longrightarrow \quad R_X(\tau) \le R_X(0)

$$

- **第一步，平方非负**：任意随机变量的平方期望非负——$E[(X(t+\tau) - X(t))^2] \ge 0$。
- **第二步，展开**：$E[X(t+\tau)^2] + E[X(t)^2] - 2E[X(t+\tau)X(t)] = R_X(0) + R_X(0) - 2R_X(\tau) \ge 0$（宽平稳：$E[X^2]$ 与 $t$ 无关）。
- **第三步，整理**：$2R_X(0) - 2R_X(\tau) \ge 0 \Rightarrow R_X(\tau) \le R_X(0)$——原点处相关最大。

「平方非负 → 相关有界」是一行式证明的典范。它示范了概率论证明的通用武器：**从一个「显然非负」的量出发，展开、整理，得到深刻的结论**——与切比雪夫不等式、马尔可夫不等式的证明手法同源。

## 5 相关函数的深入性质与实例

相关函数的四条基本性质之外，还有一组「结构性质」和一套实际解读方法，让 $R_X(\tau)$ 成为真正可用的工具。

### 相关函数的非负定性

对任意 $n$、任意时刻 $t_i$ 与实数 $a_i$：

$$\sum_{i,j} a_i a_j R_X(t_i - t_j) \ge 0$$

**非负定性**是相关函数与「任意函数的傅里叶变换」之间的分水岭：一个函数能成为相关函数，当且仅当它非负定。这也等价于功率谱 $S_X(\omega) \ge 0$（维纳—辛钦）——「时域非负定」与「频域非负」是同一件事。

### 相关函数的典型形状

| 相关函数 | 谱特征 | 过程性格 |
| --- | --- | --- |
| $e^{-\alpha\|\tau\|}$ | 洛伦兹谱 | 平滑、有记忆 |
| $e^{-\alpha\|\tau\|}\cos(\beta\tau)$ | 双峰谱 | 准周期振荡 |
| $\delta(\tau)$ | 平坦谱 | 白噪声、无记忆 |
| $\mathrm{sinc}$ 型 | 带限谱 | 带限信号 |

**「相关形状 ↔ 谱形状」**是信号处理的核心对应——看相关衰减就知道谱的宽窄。

### 例：从相关函数推断过程

**例**：测得某过程相关函数 $R_X(\tau) = 9e^{-2|\tau|}$。可读出：$R_X(0) = 9 = E[X^2]$（均方值/功率）、相关时间 $1/\alpha = 0.5$ 单位（记忆约半单位时长）、谱为洛伦兹型 $\frac{36}{\omega^2 + 4}$。三个信息一次读出——相关函数确实是过程的「二阶签名」。

### 例：两个过程的对比

过程 A：$R_A(\tau) = e^{-|\tau|}$（快速衰减）；过程 B：$R_B(\tau) = e^{-0.1|\tau|}$（慢速衰减）。B 的记忆比 A 长 10 倍，谱比 A 窄——A 更像噪声，B 更像慢漂移。**「相关衰减快 ↔ 过程像白噪声」**是判断信号性质的快捷方式。

**易错点｜辨析：** ① 相关函数非负定，但「非负」不等于「非负定」——只查 $R(\tau) \ge 0$ 不够；② 相关时间 $1/\alpha$ 不是「相关消失的时间」，而是「相关衰减到 $1/e$」的时间——是量级参考不是硬边界。

再补一张「相关函数性质」的速查表：

| 性质 | 数学表述 | 直觉 |
| --- | --- | --- |
| 偶对称 | $R(\tau) = R(-\tau)$ | 超前/滞后对称 |
| 有界 | $\|R(\tau)\| \le R(0)$ | 原点相关最大 |
| 原点值 | $R(0) = E[X^2]$ | 均方值/功率 |
| 非负定 | $\sum a_i a_j R(t_i-t_j) \ge 0$ | 谱非负的前提 |
| 衰减 | 通常 $R(\tau) \to \mu^2$ | 长时记忆消失 |

「偶、有界、原点峰、非负定」——四条性质 + 一条衰减规律，是相关函数的完整画像。

## 6 小结

- **相关函数性质**：偶对称 $R(\tau)=R(-\tau)$、有界 $|R(\tau)| \le R(0)$、非负定、$R(0) = E[X^2] \ge 0$。
- **自相关系数** $\rho_X(\tau) = C_X(\tau)/C_X(0)$，满足 $|\rho| \le 1$、$\rho(0) = 1$。
- 形状解读：$R(0)$ 大 → 功率大；衰减快 → 记忆短（近白噪声）；振荡 → 含周期成分。
- 「相关振荡 ↔ 谱峰」：相关函数与功率谱是傅里叶变换对。
- 「平方非负 → 相关有界」示范了概率论「从显然非负出发」的证明手法。
