## 为什么从均匀分布开始

上一节我们建立了概率密度的框架：连续型随机变量的概率等于密度曲线下的面积。现在问：密度曲线长什么样才叫「最公平」？答案是——**在某个区间内水平的一条直线**。这就是**均匀分布（uniform distribution）**，连续世界里「等可能」的化身。

均匀分布虽然简单，却是理解连续概率的第一块跳板：它是几何概型的随机变量形态，是随机数生成器的理想模型，也是蒙特卡洛方法的基石。更关键的是，后续几乎每个「从均匀到其他分布」的变换（如逆变换法采样）都以它为起点。<span class="marginnote">「均匀」两字大有来头：古典概型里每个样本点等可能；连续情形没有「样本点」，于是改成「任意等长子区间等概率」。等可能从「离散的点」推广到「连续的长度」，正是几何概型一章的思想在此处的回响。</span>

## 1 定义与密度

**均匀分布（uniform distribution）**：若随机变量 $X$ 的概率密度为

$$f(x) = \begin{cases} \dfrac{1}{b-a}, & a \le x \le b \\[4pt] 0, & \text{其他} \end{cases}$$

则称 $X$ 在区间 $(a, b)$ 上服从**均匀分布**，记作 $X \sim U(a, b)$。

密度在区间内是常数 $1/(b-a)$，它保证总面积为 1：$(b-a) \times \frac{1}{b-a} = 1$。**「均匀」的含义**：任意等长子区间被 $X$ 落中的概率相等，等于该子区间长度与全长之比。<span class="marginnote">注意区间端点的写法：$U(a,b)$ 通常指开区间 $(a,b)$，但因为是连续型，端点概率为 0，写作闭区间 $[a,b]$ 也无差别。教材里 $U(a,b)$ 与 $[a,b]$ 混用是常态，不影响计算。</span>

**例**：公交车每 10 分钟一班，乘客随机到达，等车时间 $X \sim U(0, 10)$，密度 $f(x) = 1/10$（$0 \le x \le 10$）。则「等 3 到 7 分钟」的概率是 $\frac{7-3}{10} = 0.4$——纯粹是长度比。

## 2 分布函数：一条斜线

对均匀分布求积分，得到分布函数：

$$F(x) = \begin{cases} 0, & x < a \\ \dfrac{x - a}{b - a}, & a \le x \le b \\[4pt] 1, & x > b \end{cases}$$

它在 $[a,b]$ 内是一条从 $(a,0)$ 升到 $(b,1)$ 的斜线。**密度是水平线，分布函数是斜线**——又一次体现「密度积分得分布函数」的微积分关系。

区间概率的简洁形式：对 $a \le c < d \le b$，

$$P\{c < X < d\} = \frac{d - c}{b - a}$$

这是**几何概型公式的连续版**：「落在子区间的概率 = 子区间长度 / 总长度」。<span class="marginnote">这一公式让均匀分布成为最易算的连续分布：不需要积分表，只需要长度的四则运算。正因如此，均匀分布常被用作「先验」（prior）——对参数一无所知时，假设它在某个范围内均匀分布，是贝叶斯统计里最朴素的中立选择。</span>

## 3 均匀分布的应用：随机数与蒙特卡洛

均匀分布最重要的应用不是建模，而是**制造随机性**：

**随机数发生器**：计算机产生的「随机数」通常先模拟 $U(0,1)$ 的样本，再经变换得到其他分布——这是逆变换采样法的思想，第六、七章的抽样理论也要靠它。
**舍选法/几何概率**：在正方形内均匀撒点，数落在圆内的比例，可估计 $\pi$——这就是**蒙特卡洛方法**的雏形。
**随机化算法**：快速排序随机选择枢轴、随机梯度下降里的随机性，底层都源于均匀随机数。

**例（估计 $\pi$）**：在 $[0,1]\times[0,1]$ 内均匀投点，落入四分之一单位圆（$x^2 + y^2 \le 1$）的比例趋于 $\pi/4$。投 1 万点，统计比例再乘 4，可得 $\pi$ 的粗糙估计——误差随投点数按 $1/\sqrt{n}$ 量级缩小，这是大数定律与中心极限定理的直观预览。<span class="marginnote">蒙特卡洛方法的威力在于：把「求面积/求积分」转化为「统计命中率」，就能绕过解析困难。这在后续「用 bootstrap 估计标准误」「用模拟做假设检验」的章节里会正式登场，其数学依据正是第五章的大数定律。</span>

**易错点｜辨析：** $U(0,1)$ 的密度在端点 0 与 1 处仍是 $1$，不是「端点概率」——连续型端点概率为零。而「$U(a,b)$ 的期望是 $(a+b)/2$」这个事实（第四章证明）常被用于估算均值，但要小心它只在均匀假设成立时才对；数据若严重偏斜，均匀假设会给出错误结论。

## 4 公式解析：均匀分布的逆变换采样

「给定一个 $U(0,1)$ 样本 $u$，如何得到 $U(a,b)$ 样本？」——这个变换是蒙特卡洛的起点：

$$

X = a + (b - a)\, U, \qquad U \sim U(0,1)

$$

- **第一步，线性拉伸**：$U$ 在 $[0,1]$ 上均匀，乘上区间长度 $b-a$ 后，$X' = (b-a)U$ 在 $[0, b-a]$ 上均匀，长度之比不变。
- **第二步，平移**：再加上 $a$，把区间搬移到 $[a, b]$，等长性保持。
- **第三步，验证密度**：线性变换不改变「等长等概率」的性质，故 $X$ 的密度仍为常数 $1/(b-a)$——均匀分布在仿射变换下仍均匀。

这条公式虽简单，却示范了概率论里最重要的思想：**分布的变换是研究随机变量的基本手段**。第二章最后一节《随机变量的函数的分布》、第三章的 $Z = X + Y$，全部建立在这条思路上——「已知 $U$ 的分布，求 $g(U)$ 的分布」。

## 5 均匀分布的深入应用与实例

均匀分布是「最简单的连续分布」，却是一切随机数与模拟的地基，值得完整展开。

### 例：区间概率的计算

**例**：$X \sim U(0, 10)$，求 $P\{3 \le X \le 7\}$：$\frac{7-3}{10} = 0.4$——**「概率 = 长度比」**是均匀分布的全部计算。

### 例：期望与方差

**例**：$X \sim U(a, b)$。$E[X] = (a+b)/2$、$\mathrm{Var}(X) = (b-a)^2/12$——「中点 + 长度平方/12」。$U(0,1)$ 的均值 1/2、方差 1/12。

### 均匀分布的应用场景

| 场景 | 用法 |
| --- | --- |
| 随机数生成 | $U(0,1)$ 是一切随机数的源头 |
| 蒙特卡洛 | 均匀撒点估计面积 |
| 先验分布 | 参数「一无所知」时的中性先验 |
| 舍选法 | 均匀采样 + 接受/拒绝 |

**「均匀分布是随机性的原料」**——计算机的随机数先从 $U(0,1)$ 开始。

### 例：逆变换采样

**例**：$U \sim U(0,1)$，$X = F^{-1}(U)$——对任意分布函数 $F$，$X$ 服从该分布。**「用均匀随机数生成任意分布样本」**是蒙特卡洛与统计模拟的通用配方。

### 例：从均匀到指数

**例**：$U \sim U(0,1)$，$X = -\frac1\lambda\ln(1-U) \sim E(\lambda)$——第二章「函数的分布」的直接应用，也是模拟指数等待时间的标准做法。

**易错点｜辨析：** ① 连续型端点概率为 0——$U(a,b)$ 与 $[a,b]$ 无差别；② 均匀分布的边缘不必均匀（三角域）；③ 「均匀假设」要验证——数据明显偏斜时，均匀假设会给出错误估计。

再补一张「均匀分布 vs 其他连续分布」对照：

| | 均匀 | 指数 | 正态 |
| --- | --- | --- | --- |
| 形状 | 矩形 | 递减 | 钟形 |
| 记忆 | 无偏好 | 无记忆 | 有记忆 |
| 应用 | 随机数、几何概率 | 等待时间 | 误差、大量和 |

「均匀是「最中性」、指数是「等待」、正态是「叠加」」——三个连续分布各司其职。

## 6 小结

- **均匀分布** $X \sim U(a,b)$：密度在区间内为常数 $1/(b-a)$，区间外为 0。
- 区间概率是长度比 $P\{c<X<d\} = (d-c)/(b-a)$——几何概型的连续版。
- 分布函数在区间内是斜线 $F(x) = (x-a)/(b-a)$，密度与分布函数互为「水平 ↔ 斜线」。
- 均匀分布是**随机数发生器与蒙特卡洛方法**的地基，$X = a + (b-a)U$ 是第一个分布变换。
- 端点概率为零，区间开闭写法不影响计算。

在下一节，我们见到均匀分布最重要的「亲戚」——**指数分布**，它描述等待时间，并且带着连续世界里著名的**无记忆性**。
