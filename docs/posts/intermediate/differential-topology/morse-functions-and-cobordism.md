## 为什么从 Morse 函数开始

本专题从「什么是光滑流形」出发，一路走到「向量场的零点指标」。最后这一讲把两个看似无关的线索拧在一起：**用实值函数扫描流形**（Morse 理论）与**把流形之间的「换形」当作研究对象**（配边理论）。Morse 函数的威力在于：流形上随便放一个「足够一般」的实值函数，它的临界点就带出流形的拓扑骨架——临界点的个数、指标与排序，直接决定流形能被「装配」成什么样。而配边理论问的是更哲学的问题：**两个流形能不能「平滑地变形」成彼此**（由一个中间流形把它们接起来）？Milnor 的《从微分观点看拓扑》以配边（framed cobordism）收尾，本讲把这两件大事各开一个头。<span class="marginnote">回顾第三讲的「正则值分层」：实值函数 $f: M \to \mathbb{R}$ 的正则值是稠密的，$f^{-1}(t)$ 是 $M$ 的子流形；Morse 理论把「$t$ 穿过临界值的瞬间，$f^{-1}(t)$ 怎么变」这件事讲透——它把「切片」变成「动态扫描」。</span>

## 1 Morse 函数与临界点

**临界点与指标**：设 $f: M \to \mathbb{R}$ 光滑，$p$ 是 $f$ 的临界点（$df_p = 0$）。$p$ 处 $f$ 的**Hessian** $D^2 f_p$（坐标下是二阶偏导矩阵）如果**非退化**（行列式非零），则 $p$ 叫**非退化临界点**；Hessian 的负特征值个数称为 $p$ 的**指标**（index），记作 $\lambda(p)$。

**Morse 函数**：若 $f$ 的所有临界点都非退化，且临界值互不相同，则 $f$ 称为**Morse 函数**。

两个基本事实让 Morse 函数成为标准工具：

- **存在性（通有性）**：任何紧流形上，Morse 函数不仅存在，而且几乎处处如此——上一讲的高度函数例子已经证明，随机取一个方向作高度函数，几乎必然得到 Morse 函数。这是「通有思维」（第四讲）的又一次兑现。
- **局部标准型（Morse 引理）**：在非退化临界点 $p$ 附近，存在局部坐标使

$$f = f(p) - (x^1)^2 - \dots - (x^\lambda)^2 + (x^{\lambda+1})^2 + \dots + (x^n)^2.$$

即 $f$ 局部上就是一个「$\lambda$ 个负号、$n-\lambda$ 个正号」的二次型。**Morse 引理把每个临界点局部标准化成「一个可辨认的鞍」**——指标 $\lambda$ 就是「有多少个下降方向」。<span class="marginnote">对比第一讲的坐标转换：Morse 引理是在「保持 $f$ 形状」的意义下选坐标（把 $f$ 化成二次型），而非任意坐标。它是「把函数和坐标一起化简」的典范，也是后续一切「临界点分类」的出发点。指标 0 是极小（源）、指标 $n$ 是极大（汇）、中间指标是各类鞍点。</span>

**与指标定理的呼应**：上一讲向量场的指标，与这里临界点的指标，都是「下降方向个数」的亲戚。$f$ 的梯度场（对某个度量取）在临界点处的零点指标等于 $(-1)^{\lambda(p)}$，于是 Poincaré–Hopf 对梯度场给出

$$\chi(M) = \sum_{p \text{ 临界点}} (-1)^{\lambda(p)}.$$

**Morse 不等式把临界点个数与拓扑连接起来**：临界点个数 ≥ 各阶 Betti 数之和，这是「临界点个数下界」的最经典结论。

**具体流形上的 Morse 函数**：$S^2$ 上取高度函数 $f(x,y,z) = z$，临界点只有南北极：南极指标 0（极小）、北极指标 2（极大），于是 $\chi(S^2) = (-1)^0 + (-1)^2 = 2$——与三角剖分 $V - E + F = 2$ 一致。$T^2$ 竖放的高度函数给出 4 个临界点：指标 $0, 1, 1, 2$，和为 $1 - 1 - 1 + 1 = 0 = \chi(T^2)$。**每算一个流形，Morse 求和与欧拉公式互相验证**，这是「两套语言讲同一个数」的最直观体现。

## 2 临界点如何改变拓扑：把手接上去

Morse 理论的核心画面是「扫描」：看水平集 $M_a = f^{-1}((-\infty, a])$ 随 $a$ 增大如何变化。

**正则段不改变拓扑**：若 $[a, b]$ 内没有临界值，则 $M_b$ 微分同胚于 $M_a$——**光滑函数在无临界点的区间里，水平集只是「光滑变形」，拓扑不变**。这与「正则值的原像光滑变化」（第三讲）一脉相承。

证明靠梯度流的「拉动」：取一个度量，让梯度场 $\nabla f$ 在无临界值区间的水平集之间生成流，把 $M_a$ 沿 $\nabla f$「推到」$M_b$——这是第八讲「流」的直接应用。**「无临界点 ⇒ 同胚」的全部证明，就是「沿着梯度流走」这一句话**，可见前几讲的工具在这里全都排上了用场。

**穿过临界值改变拓扑**：若 $b$ 恰跨过一个指标 $\lambda$ 的临界值，则 $M_b$ 是由 $M_a$ **「粘上一个 $\lambda$-柄」** 得到的——所谓 $\lambda$-柄，就是 $D^\lambda \times D^{n-\lambda}$（一个 $\lambda$ 维圆盘乘一个 $n-\lambda$ 维圆盘），沿边界 $S^{\lambda-1} \times D^{n-\lambda}$ 粘到 $M_a$ 上。指标 $\lambda$ 决定「这个柄朝哪个方向长出」。<span class="marginnote">「粘把手」的直观：在环面 $T^2$ 上放一个高度函数（竖直方向），极小值点给一个 0-柄，两个鞍点给两个 1-柄，极大值点给一个 2-柄——环面 = 「1 个 0-柄 + 2 个 1-柄 + 1 个 2-柄」。柄分解（handle decomposition）把「流形的拓扑结构」翻译成「柄的清单」，是 Morse 理论最有用的产出。</span>

**示例（环面的高度扫描）**：$T^2$ 竖着放，高度函数 $f(x, y, z) = z$。从下往上：最低点（极小，指标 0）→ 第一个鞍点（指标 1）→ 第二个鞍点（指标 1）→ 最高点（极大，指标 2）。水平集从「一点」到「一个小圆」到「8 字形」到「两个环并拢」再到「环面」——**每跨一个临界值，拓扑就动一次**。这个「扫描电影」是 Morse 理论的标准开场。

**辨析｜易错点：临界点的「存在」是流形的性质，不是函数的性质。** 同一个流形上可以放不同的 Morse 函数，临界点位置会变、临界值会变，但「指标之和」（以及「各指标的临界点个数满足 Morse 不等式」）不变——因为指标和为 $\chi(M)$，而 $\chi$ 是拓扑不变量。

做题时若算出不同的指标和，说明不是流形算错，就是「非退化性/互异性」没验证到位（退化临界点会破坏公式）。**先验证 Morse 性，再谈临界点，是标准流程。**

**柄分解的「装配手册」视角**：从最下往上读 Morse 函数，$M$ 就是「从空集开始，按指标从小到大依次粘柄」的产物。于是「$M$ 的拓扑」被翻译成「一串柄的清单」，而「清单」满足 $\chi = \sum (-1)^\lambda$。反过来，给一张「合法清单」就能造出流形——这是高维流形分类（$n \ge 5$）里手术（surgery）理论的入口：**把流形拆成柄，再按新规则重装，就得到手术。**

## 3 配边理论初步：流形之间的「换形」

Morse 理论告诉我们「流形可以被柄分解」，而柄分解反过来给出「流形之间的桥梁」——这就是配边。

**配边（cobordism）**：两个紧流形 $M_0, M_1$（同维数）称为**配边**的，若存在紧流形 $W$ 使 $\partial W = M_0 \sqcup M_1$，$W$ 称为**配边流形**。配边是等价关系（自反、对称、传递），商掉之后的类构成**配边群**（如模 2 配边群 $\mathfrak{N}_n$）。<span class="marginnote">直觉：$M_0$ 与 $M_1$ 配边，就是「$M_0$ 能平滑地成长为 $M_1$，中间由 $W$ 过渡」。两个圆盘配边（中间是一个柱面 $S^1 \times [0,1]$）；$S^2$ 与 $\emptyset$ 配边（中间是 $D^3$，边界是 $S^2$）。「配边」把「同伦」的关系放宽成「能互相长出来」的关系。</span>

**为什么配边是「正确」的关系**：两个同伦的流形一定配边，但反过来不必——$S^1$ 与 $S^1 \# S^1$（双环）不同伦，却都配边于 $T^2$（沿 $S^1$ 切开）。配边类对「手术」（沿嵌入球面切割再重粘）保持不变，这使它成为高维流形分类的核心语言。Milnor 以「框定配边 + Pontryagin 构造」证明「$S^3$ 的框定配边类 ↔ $\pi_3(S^2)$」，把配边与同伦群接上了线。

**配边的经典例子**：$M_0 = S^1$，$M_1 = S^1$，取 $W = S^1 \times [0,1]$（柱面），$\partial W = S^1 \times \{0\} \sqcup S^1 \times \{1\}$——**同一个流形与自己配边**（自反性）。$M_0 = S^2$，$M_1 = \emptyset$，取 $W = D^3$，$\partial D^3 = S^2$——**$S^2$ 配边于空集**，所以 $S^2$ 的配边类是零元。

$M_0 = T^2$，$M_1 = T^2$，取 $W = T^2 \times [0,1]$——自反性又一次现身。这些「平凡例子」虽然简单，却是配边关系「自反、对称、传递」的直接验证，也是理解「配边群」加法与零元的锚点。

**配边与指标**：Morse 函数在配边上的推广是「$W$ 上的 Morse 函数以 $M_0$ 为最小值边界、$M_1$ 为最大值边界」，其临界点的指标与配边的柄分解一一对应。**配边 = 柄分解的宏观叙事，Morse 函数 = 柄分解的微观日志**——两套语言，同一件事。

**Milnor 的框定配边与 Pontryagin 构造**：把配边升级为「带标架」的版本——每个边界分支带一个「法标架」，就得到**框定配边**。Milnor 证明框定配边类与同伦群一一对应：$S^n$ 的框定配边类构成一个群，且与 $\pi_n$ 同构。这是配边理论第一次显示出「代数化」的威力，也是 Milnor 1962 年菲尔兹奖工作的先声（微分拓扑领域的里程碑）。本讲只给出「框定配边」这个词，把它钉在知识树的「代数拓扑衔接点」上。

## 4 公式解析：Morse 引理与配边的维数

两条公式各代表本讲的一半。

**第一条：Morse 引理的局部标准型。**

$$
f = f(p) - (x^1)^2 - \dots - (x^\lambda)^2 + (x^{\lambda+1})^2 + \dots + (x^n)^2.
$$

- **第一步，为什么能化成二次型**：非退化临界点处，$f$ 的 Taylor 展开是「常数 + 二次项 + 高阶项」。Morse 引理说：通过合适的光滑坐标变换，高阶项可以全部消掉——这靠「逐阶消去」的归纳：每消去一个高阶项，都用一个保持 $f$ 形式的新坐标吸收它。要点是「坐标跟着函数走」，而非「坐标固定函数再展开」。
- **第二步，指标从哪来**：二次型的负号个数（Hessian 负特征值个数）就是指标 $\lambda$。它是不变量：任何把 $f$ 化为二次型的坐标下，负号个数都相同（Sylvester 惯性律，线性代数结论）。
- **第三步，几何含义**：指标 0 = 极小（像碗底），指标 $n$ = 极大（像碗顶），指标 $\lambda$ = 「$\lambda$ 个方向向下、$n-\lambda$ 个方向向上」的鞍。**每个临界点的「形状」被指标完全标注**，而「形状清单」由 Morse 函数读出、由流形本身决定。

**第二条：配边群里的加法规则。**

$$
[M_0] + [M_1] = [M_0 \sqcup M_1], \qquad 0 = [\text{某可配边到空集的流形}].
$$

- **第一步**：配边类的和就是「不交并的类」；零元由「配边于空集」的流形代表（如 $S^2$，因为 $\partial D^3 = S^2$）。
- **第二步**：每个类有加法逆（$[M] + [M] = 0$ 在模 2 意义下，因为 $M \times [0,1]$ 给出 $M$ 与 $M$ 的配边），所以模 2 配边类构成 $\mathbb{Z}/2$-向量空间 $\mathfrak{N}_n$。
- **第三步**：$\mathfrak{N}_n$ 的维数有著名的 Thom 结果：$\mathfrak{N}_*$ 是有理多项式环的模 2 版本，由 $\mathbb{RP}^2$、$\mathbb{RP}^4$、…… 生成。**配边类不是「有/无」而是「可数的结构」，它把「流形换形」变成线性代数。**

**一个可算的配边练习**：$\mathfrak{N}_1$ 里只有 $S^1$（及若干个不相交并）。$S^1$ 是 $D^2$ 的边界（$\partial D^2 = S^1$），所以 $S^1$ 配边于空集，$[S^1] = 0$。于是 $\mathfrak{N}_1 = 0$——**一维没有配边不变量**。这个「空集配边检查」是理解配边群零元的最佳练习：**一个流形是零类 ⇔ 它是某个紧流形的边界。** $S^2 = \partial D^3$ 是零类，而 $\mathbb{RP}^2$ 不是任何三维紧流形的边界（Thom 的 $\mathfrak{N}_2 = \mathbb{Z}/2$ 由 $[\mathbb{RP}^2]$ 生成），所以 $\mathbb{RP}^2$ 在 $\mathfrak{N}_2$ 中非零——**第一个非平凡的配边不变量，正由这个「不可定向」的曲面提供。**

## 5 小结

- **Morse 函数**：非退化临界点 + 临界值互异；紧流形上通有。
- **Morse 引理**：临界点局部化为二次型 $f = -\sum_{\lambda}(x^i)^2 + \sum_{n-\lambda}(x^j)^2$；指标 $=$ 下降方向个数。
- **扫描**：穿过临界值 ⇔ 粘 $\lambda$-柄；正则段拓扑不变。
- **指标定理的呼应**：$\chi(M) = \sum_p (-1)^{\lambda(p)}$。
- **配边**：$M_0 \sim M_1$ ⇔ 存在 $W$，$\partial W = M_0 \sqcup M_1$；模 2 配边群 $\mathfrak{N}_n$ 是线性空间。
- 柄分解 = 配边的微观日志；Morse 函数 = 柄分解的驱动。
- **应用闭环**：$S^2$ 高度函数给出指标 $0, 2$ 与 $\chi = 2$；$T^2$ 给出 $0, 1, 1, 2$ 与 $\chi = 0$
