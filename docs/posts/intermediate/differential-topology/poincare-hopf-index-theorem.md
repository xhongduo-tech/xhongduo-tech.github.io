## 为什么从指标定理开始

上一讲的 Brouwer 不动点定理证明了「连续自映射必有不动点」，是「存在性」的皇冠。本讲的问题换一个主角、却殊途同归：**给一个紧流形上随便一个向量场，它的零点（向量场为零的点）该有多少？** 答案是惊人的——零点总和（计指标）不取决于向量场，只取决于流形自身的拓扑：**Poincaré–Hopf 指标定理**说，任何向量场的零点指标之和等于流形的 Euler 示性数 $\chi(M)$。于是「球面 $S^2$ 上任何向量场必有零点」（毛球定理）成为「$\chi(S^2) = 2 \neq 0$」的现成推论；而环面 $T^2$ 上存在处处非零向量场（$\chi(T^2) = 0$）。**「能不能找无零点向量场」这个问题，被一个整数完全回答。**<span class="marginnote">Euler 示性数从中学的「多面体：顶点 − 棱 + 面 = 2」一路走来（第一级《空间几何体》讲欧拉公式），如今在微分拓扑里变成一个拓扑不变量 $\chi(M)$。它是「组合（三角剖分）→ 拓扑（同调）→ 微分（向量场）」三座桥交汇的枢纽。</span>

## 1 场零点的指标

先给「一个零点该记几」定一个数。设 $X$ 是 $n$ 维流形 $M$ 上的向量场，$p$ 是 $X$ 的孤立零点。

**指标（index）**：取 $p$ 的一个小坐标邻域（不包含其他零点），在边界小球 $S^{n-1}_\varepsilon$ 上，把向量场「归一化」成方向映射

$$\hat X: S^{n-1}_\varepsilon \longrightarrow S^{n-1}, \qquad \hat X(q) = \frac{X(q)}{\lVert X(q) \rVert},$$

$p$ 的**指标**定义为该映射的映射度：

$$\operatorname{ind}_p X = \deg \hat X.$$

换句话说：**绕 $p$ 走一圈，向量场的方向转了多少圈（计定向），就是 $p$ 的指标。** 指标是整数，不依赖小球半径 $\varepsilon$（同伦不变）。<span class="marginnote">「归一化方向映射的度数」是「指标」的现代定义（Milnor 用的小球边界映射）。它在 $n = 2$ 时最直观：绕孤立零点一圈，看场的方向在单位圆上绕了几圈——绕一圈指数 $+1$，绕负一圈指数 $-1$，不绕指数 $0$。</span>

**三个基本零点的指标（$n = 2$）**：

**源（source）**：$X = (x, y)$（向外辐散）。绕原点一圈，方向在单位圆上正向绕一圈，$\operatorname{ind} = +1$。
**汇（sink）**：$X = (-x, -y)$（向内汇聚）。方向反向绕一圈，$\operatorname{ind} = +1$（仍是整圈）。
**鞍点（saddle）**：$X = (x, -y)$。绕原点一圈，方向「先指右、再指下、再指左、再指上」，在单位圆上正向绕**半圈**再反向绕半圈，净转 $0$ 圈，$\operatorname{ind} = -1$。

记住结论：**源与汇指标 $+1$，鞍点指标 $-1$**。这个「+1/−1」是后面求和定理的算术基础。

**「用线性化算指标」的通用办法**：若零点 $p$ 处 $X$ 的线性化（Jacobi 矩阵 $DX_p$）可逆，则 $\operatorname{ind}_p X = \operatorname{sgn} \det DX_p$——指标的符号由线性部分行列式的符号给出。因为在小球边界上，$X$ 与 $DX_p$ 之间可同伦（把非线性部分线性收缩掉），而 $DX_p$ 的归一化方向的度数正是 $\operatorname{sgn}\det DX_p$。于是「源/汇（两个负特征值或两个正特征值）$\to \det > 0 \to +1$；鞍点（一正一负）$\to \det \lt  0 \to -1$」的直觉，被严格化为一条公式。退化零点（$DX_p$ 奇异）则需要更精细的处理，这正是后面 Morse 理论里「非退化临界点」概念的预演。<span class="marginnote">为什么鞍点方向净转 $-1$？把 $X = (x, -y)$ 想成「沿水平轴走，遇到竖轴反号」：参数角 $\theta$ 从 $0$ 到 $2\pi$ 时，$X$ 的辐角是 $-\theta$，恰好反向转一整圈，但定向约定使净指标为 $-1$。多算几次这个例子，指标的「定向」含义就清楚了。</span>

## 2 Euler 示性数：从三角剖分到拓扑

指标定理的和的另一端是 Euler 示性数。它的经典定义来自**三角剖分**：把紧曲面剖成 $V$ 个顶点、$E$ 条棱、$F$ 个三角形面，则

$$\chi(M) = V - E + F.$$

关键性质：**$\chi$ 不依赖剖分方式**（两个不同的三角剖分算出同一个数）。这是欧拉公式「多面体 $V - E + F = 2$」向任意曲面的推广——$S^2$ 的 $\chi = 2$，$T^2$ 的 $\chi = 0$，Möbius 带（紧化）的 $\chi = 0$，$\mathbb{RP}^2$ 的 $\chi = 1$。对高维紧流形，$\chi$ 用「各阶 Betti 数的交错和」定义：$\chi(M) = \sum_k (-1)^k \dim H_k(M; \mathbb{R})$（第二级《代数拓扑》会给出），与三角剖分版本一致。

**为什么「不依赖剖分」如此重要**：三角剖分是「组合数据」（多少个顶点、棱、面），乍看像是人为选择——换个剖法数字就变。欧拉的洞见是 $V - E + F$ 的组合差恰好抵消掉剖法的自由度，留下拓扑数据。这个「交错和的拓扑不变性」在代数拓扑里被推广成「Euler 示性数 = Betti 数交错和」，同调群本身是拓扑不变量，所以 $\chi$ 也是。**一句话：$\chi$ 是「组合容易算、拓扑它不变」的量**，这正是它能在 Poincaré–Hopf 里充当「整体端」的原因。

**为什么 $\chi$ 是「洞」的计数器**：$\chi = 2 - 2g$（紧可定向曲面，$g$ 是亏格），$g = 0$ 球面、$g = 1$ 环面、$g = 2$ 双环面……每多一个「洞」，$\chi$ 就减 $2$。**$\chi$ 直接数「洞有多少个」**，这与上一讲「$S^{n-1}$ 有洞所以不可缩」是同一条直觉的量化。

**高维情形的统一**：对 $n$ 维紧流形，$\chi(M) = \sum_k (-1)^k b_k$（$b_k$ 是第 $k$ 个 Betti 数 = $H_k$ 的维数）。偶数维球面 $S^{2m}$ 只有一个非零 Betti 数 $b_{2m} = 1$，故 $\chi = 1$（按 $(-1)^{2m} = +1$）？——不对：$\chi(S^{2m}) = 1 + (-1)^{2m} \cdot 1 = 2$，因为 $b_0 = b_{2m} = 1$。奇数维 $S^{2m+1}$：$b_0 = b_{2m+1} = 1$，交错和为 $1 - 1 = 0$。**偶数维球面 $\chi = 2$、奇数维球面 $\chi = 0$** 这一对事实，是后面「哪些球面有非零向量场」问题的全部答案。

## 3 Poincaré–Hopf 指标定理

**Poincaré–Hopf 指标定理**：设 $M$ 是紧光滑流形，$X$ 是 $M$ 上只有孤立零点的光滑向量场，则

$$\sum_{p:\, X(p) = 0} \operatorname{ind}_p X = \chi(M).$$

**这个和与 $X$ 无关**——任意向量场给出同一个数，而那个数由 $M$ 的拓扑决定。它一次回答了三个「玄学」问题：零点是否必须有？(若 $\chi \neq 0$ 必须有)；能没有吗？(若 $\chi = 0$ 可以，例如 $T^2$ 的常向量场处处非零)；零点能「造」出来吗？(总指标恒为 $\chi$，造出鞍点就得补源/汇)。<span class="marginnote">Milnor §5 的证明用「把一个球面场搬到 $M$ 上」的构造：取 $M$ 的嵌入（Whitney 定理），定义「从北极指向每个点的向量场」，在其零点（恰为 $M$ 上的关键点）处统计指标，再用映射度的同伦不变性做两处抵消。证明的形态是「$\deg$ 的两端分别算出 $\chi$ 与指标和」。</span>

**毛球定理（hairy ball theorem）**：$S^2$ 上任何连续向量场必有零点。由 $\chi(S^2) = 2 \neq 0$，指标和 $= 2$，若场无零点则和为 $0$，矛盾。俗语「你无法梳理一个满是毛的球而不留下发旋」——那个发旋就是零点。$S^{2k}$ 偶数维球面同理必有无零点场（$\chi = 2$）；而 $S^{2k+1}$ 奇数维球面 $\chi = 0$，存在处处非零向量场（沿某方向平移即可）。

**为什么「球面必有发旋」不平凡**：中学里「毛球」的直觉是「你没法把球毛全梳平」，但严格地需要证明「任何连续的做法都会卡壳」。指标定理把「任何做法」抽象成「任何向量场」，再把「卡壳」量化成「至少一个零点」。注意定理允许「场只有孤立零点」，所以发旋可以是有限个；而「处处非零场」在 $S^2$ 上被完全排除。

这条定理也是「气候学」里的著名结论：地球上水平风速不可能处处非零——总有地方风平浪静（相对地球表面）。

**定向与边界的提醒**：定理对**紧、无边界**的流形成立。带边流形需加「沿边界向外指」的条件（Milnor 把它归入「$X$ 沿 $\partial M$ 横截」情形）。本讲先锁死无边界情形。

## 4 公式解析：指标 = 局部映射度

指标定义的公式值得逐项拆解，它是「局部计算」与「整体不变量」之间的桥梁。

$$
\operatorname{ind}_p X = \deg\!\left( \hat X: S^{n-1}_\varepsilon \to S^{n-1} \right), \qquad \hat X(q) = \frac{X(q)}{\lVert X(q) \rVert}.
$$

- **第一步，为什么能归一化**：$p$ 是孤立零点，故在小球 $S^{n-1}_\varepsilon$ 上 $X(q) \neq 0$，$\lVert X(q) \rVert \neq 0$，除法良定义。$\hat X$ 把「球边界上的场方向」规范化成「指向单位球面上的点」——场的「大小」被丢掉，只留「方向」。
- **第二步，为什么度数定义指标**：$\hat X: S^{n-1} \to S^{n-1}$ 是两个同维紧定向流形间的映射，映射度（上一讲）良定义。$p$ 的指标就是「$X$ 的方向绕 $p$ 转的圈数」。$n = 2$ 时，$\hat X$ 是「绕圈数」，源/汇 $\to +1$，鞍点 $\to -1$，一步可得。
- **第三步，为什么指标与小球半径无关**：半径 $\varepsilon$ 变小，只是把 $\hat X$ 的定义域缩成更小的同心球；两球之间用「径向收缩」给出同伦，映射度同伦不变。于是「$p$ 的指标」是 $p$ 的局部固有属性，不依赖半径选择——**这保证求和 $\sum \operatorname{ind}_p X$ 是一个不变量。**

**一个计算演示**：$M = S^2$，取高度梯度场（从南极到北极的经线场，$z$ 方向的投影）。零点是南北极两个：南极是源（指标 $+1$），北极是汇（指标 $+1$），和 $= +2 = \chi(S^2)$。再换一个场：$S^2$ 上「绕竖轴旋转」的场，只有两个零点（南北极），各为源/汇或退化情形，指标和仍是 $+2$。**怎么换场，总和不动**——这就是定理「和与场无关」的现场验证。

**辨析｜易错点：指标和是「总指标」，不是「零点个数」。** 一个源（指标 $+1$）配一个鞍点（指标 $-1$）可以净指标为 $0$，但零点有 $2$ 个。

所以「$\chi = 0$」说的是「可以构造无零点场」，不等于「随便一个场都无零点」——$T^2$ 上也可以造出既有源又有鞍点的场，总指标为 $0$ 但不代表没有零点。**定理约束的是「指标之和」，不是「零点个数」**，这一字之差是考试与理解里的高频失分点。

## 5 指标定理的现场验证

把定理用到几个标准流形上，每个都是「$\chi$ 预言 + 构造验证」的完整循环：

| 流形 | $\chi$ | 指标和的预言 | 实际构造 | 验证 |
| --- | --- | --- | --- | --- |
| $S^2$ | $2$ | 必有零点，总指标 $2$ | 高度梯度场：南北极各一个源/汇 | $+1+1 = 2$ ✓ |
| $T^2$ | $0$ | 可以无零点 | 常向量场处处非零 | $0 = 0$ ✓ |
| $S^3$ | $0$ | 可以无零点 | 沿某坐标方向平移 | $0 = 0$ ✓ |
| $\mathbb{RP}^2$ | $1$ | 必有零点，总指标 $1$ | 旋转场（奇点 + 一个鞍点抵消后净 $1$） | 和 $= 1$ ✓ |
| 亏格 $g$ 曲面 | $2-2g$ | 零点指标和 $= 2-2g$ | 每个「洞」配一对鞍点 | 源 $+1$、鞍点 $-2g$、汇 $+1$ |

读表时注意两件反直觉的事。第一，**$T^2$ 与 $S^3$ 的 $\chi = 0$ 让「处处非零场」成为可能**——这是「流形有向量场⇔ $\chi = 0$」的直观来源（充分性需 Frobenius/平行化讨论，但紧致情形的「必要性」由指标定理直接给出）。第二，**$\mathbb{RP}^2$ 这样不可定向的流形，指标定理仍然成立**——指标只依赖局部的定向比较，不要求全局定向，这正是它比「映射度」更宽厚的地方。<span class="marginnote">「必要」的方向（有非零场 ⇒ $\chi = 0$）由指标定理免费赠送；「充分」的方向（$\chi = 0$ ⇒ 有非零场）在可平行化或低维情形是真的（Hopf 定理），但在高维需要更深的工具。本表已经足够让你对「指标定理回答场的问题」建立信心。</span>

**延伸到动力系统**：指标定理在微分方程理论里还有另一副面孔——平面系统的孤立平衡点按指标分类：指标 $+1$ 的点局部是源/汇/中心，指标 $-1$ 是鞍点。Poincaré 在他关于平面自治系统拓扑结构的工作里正是用这套指标给奇点分类；而「闭轨内平衡点指标和必为 $+1$」这条 Poincaré 指标公式，是平面动力系统拓扑分析的基石。**微分拓扑的指标，与常微分方程的奇点分类，是同一个整数。**

**为什么指标定理要求「紧」**：非紧流形上零点可以「跑向无穷」。$\mathbb{R}^2$ 上 $X = (x, y)$ 只在原点有一个源，指标和 $= +1$，恰好等于 $\chi(\mathbb{R}^2) = 1$——居然对得上；但 $\mathbb{R}^2$ 上的常向量场 $X \equiv (1, 0)$ 处处非零，指标和 $= 0 \neq \chi(\mathbb{R}^2)$。非紧时「场可以向无穷远处流走」，指标定理的「总和守恒」被边界冲淡。所以紧致性不是学究要求，而是「所有零点都被数到」的保证。

## 6 小结

- **指标** $\operatorname{ind}_p X = \deg \hat X$：绕孤立零点场方向转的圈数；源/汇 $+1$、鞍点 $-1$。
- **Euler 示性数** $\chi(M)$：三角剖分的 $V - E + F$，不依赖剖分；$\chi(S^2) = 2$、$\chi(T^2) = 0$、$\chi(\mathbb{RP}^2) = 1$。
- **Poincaré–Hopf**：$\sum_p \operatorname{ind}_p X = \chi(M)$，与 $X$ 无关。
- **毛球定理**：$S^2$ 上任何向量场有零点（$\chi = 2 \neq 0$）。
- 指标可用线性化计算：非退化零点处 $\operatorname{ind}_p X = \operatorname{sgn} \det DX_p$。
- 指标定理把「局部的场」与「整体的拓扑」用加法接通，是微分拓扑「局部→整体」方法论的巅峰展示。
- **与映射度的连接**：$\operatorname{ind}_p X = \deg \hat X$；指标的算术（源/汇 $+1$、鞍点 $-1$）完全继承映射度的符号约定。
- 定理约束「指标之和」而非「零点个数」；$\chi = 0$ 只保证「可以造无零点场」，不代表「随便一个场都无零点」。

在下一节，我们将换一种「扫描」流形的方式：用实值函数的高度去切流形，看切片随高度如何变化——这就是 **Morse 函数与配边理论初步**。
