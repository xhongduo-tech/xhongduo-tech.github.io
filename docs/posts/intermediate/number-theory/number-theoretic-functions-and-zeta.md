## 为什么数论会「长出」一个复变函数

乘性函数一节我们认识了 $\varphi, \tau, \sigma, \mu$ 等数论函数。
但它们只是零散的对象；
把它们组织起来的工具是**狄利克雷级数（Dirichlet series）**——把数论函数变成「生成函数」：

$$\sum_{n=1}^{\infty} \frac{f(n)}{n^s}$$

当 $f(n) = 1$ 时，这个级数就是**黎曼 ζ 函数（Riemann zeta function）**：

$$\zeta(s) = \sum_{n=1}^{\infty} \frac{1}{n^s} = 1 + \frac{1}{2^s} + \frac{1}{3^s} + \cdots$$

一个纯整数求和，怎么会和「素数分布」扯上关系？
答案是**欧拉乘积**：把求和重写成对所有素数的乘积，素数的信息就长在了 ζ 函数里。
而黎曼做了一件让整个数论改头换面的事——把 $s$ 从实数推广到复数，让素数的分布规律变成「复平面上零点位置」的问题。<span class="marginnote">把实函数「解析延拓」到复数域，是复变函数的看家本领（第二级《复变函数与积分变换》的主题）。
黎曼 1859 年的论文《论小于给定值的素数个数》只有短短八页，却同时定义了解析延拓、函数方程、以及日后无人能证的黎曼猜想——这是数学史上密度最高的一页纸。</span>

## 1 狄利克雷级数与欧拉乘积

**狄利克雷级数**：形如 $\sum_{n=1}^{\infty} f(n)/n^s$ 的级数，把数论函数 $f$ 编码成关于 $s$ 的函数。
它的意义在于：**数论函数的卷积在级数里变成普通乘法**——若 $h = f * g$，则

$$\sum_{n=1}^{\infty} \frac{h(n)}{n^s} = \left(\sum_{n=1}^{\infty} \frac{f(n)}{n^s}\right)\left(\sum_{n=1}^{\infty} \frac{g(n)}{n^s}\right)$$

这条「卷积 → 乘积」的对应，让数论函数之间的关系变成级数之间的代数关系，是解析数论最有力的翻译机。

**欧拉乘积（Euler product）**：若 $f$ 是乘性函数，则狄利克雷级数可以写成对所有素数的乘积：

$$\sum_{n=1}^{\infty} \frac{f(n)}{n^s} = \prod_{p} \left(1 + \frac{f(p)}{p^s} + \frac{f(p^2)}{p^{2s}} + \cdots\right)$$

取 $f \equiv 1$ 得到 ζ 函数的最重要等式：

$$\zeta(s) = \prod_{p} \frac{1}{1 - p^{-s}}$$

**重点：** 这个乘积是「算术基本定理」的分析翻版——每个整数唯一分解为素数幂，所以求和（遍历所有整数）可以按素数逐项展开成乘积。<span class="marginnote">欧拉乘积是连接「离散整数」与「连续分析」的第一座桥。
黎曼深谙此道：素数的一切信息都「封装」在 $\prod_p (1 - p^{-s})^{-1}$ 里，而研究这个乘积的最短路径是研究它的分析性质。</span>

## 2 ζ 函数的解析延拓与函数方程

级数 $\sum 1/n^s$ 只在 $\mathrm{Re}(s) > 1$ 时收敛。
但黎曼证明了：ζ 函数可以**解析延拓**到整个复平面（除 $s = 1$ 一个极点外），并且满足一个漂亮的**函数方程**：

$$\zeta(s) = 2^s \pi^{s-1} \sin\left(\frac{\pi s}{2}\right) \Gamma(1-s)\, \zeta(1-s)$$

这个方程把 $\zeta(s)$ 与 $\zeta(1-s)$ 联系起来——它告诉你：知道了右半平面，左半平面全知道。<span class="marginnote">$\Gamma$ 函数是阶乘的连续推广（$\Gamma(n) = (n-1)!$），它在第二级《数学分析》与《复变函数》中都会出现。
函数方程里的 $\sin(\pi s/2)$ 项在负偶数处为 0，于是 $\zeta(-2) = \zeta(-4) = \cdots = 0$——这些是 ζ 函数的「平凡零点」。</span>

**平凡零点与临界带**：由 $\sin(\pi s/2)$ 可知 $\zeta(-2) = \zeta(-4) = \cdots = 0$，这些是平凡零点。
函数方程还暗示非平凡零点只能落在**临界带** $0 \le \mathrm{Re}(s) \le 1$ 内——而它们的精确位置，就是黎曼猜想的对象。

## 3 黎曼猜想与素数定理

**黎曼猜想（Riemann hypothesis）**：ζ 函数的所有非平凡零点都落在**临界线** $\mathrm{Re}(s) = 1/2$ 上。

![黎曼 ζ 函数的关键结构：临界带 0 ≤ Re(s) ≤ 1、临界线 Re(s) = 1/2、极点 s = 1 与平凡零点（负偶数）](/images/number-theory/zeta-critical-line-1.svg)

这个猜想至今未证（千禧年七大难题之一），但它几乎统治了解析数论。
一个惊人的事实是：**素数定理的「强形式」等价于「ζ 函数在临界线上无零点」**——黎曼猜想正是把素数分布误差从「亚指数」压到「平方根」的关键。

用公式看：素数定理的余项可以用 ζ 的零点表达

$$\pi(x) = \mathrm{li}(x) - \sum_{\rho} \mathrm{li}(x^{\rho}) + \text{（小项）}$$

其中 $\rho$ 遍历非平凡零点。
零点越「规整」（都在 $1/2$ 上），$\pi(x)$ 与 $\mathrm{li}(x)$ 的误差就越小。<span class="marginnote">数值验证已经进行到超过 $10^{13}$ 个零点，全部在临界线上，且首次零点的虚部约 $14.1347$。
但「全部」这两个字，至今无人能证。2026 年的今天，黎曼猜想仍是数学最贵的悬赏之一。</span>

## 4 公式解析：欧拉乘积

$$\zeta(s) = \prod_{p} \frac{1}{1 - p^{-s}} = \frac{1}{1-2^{-s}} \cdot \frac{1}{1-3^{-s}} \cdot \frac{1}{1-5^{-s}} \cdots$$

- **第一步，展开一个因子**：$\frac{1}{1-p^{-s}} = 1 + p^{-s} + p^{-2s} + p^{-3s} + \cdots$（等比级数，$|p^{-s}| < 1$ 时收敛）。
- **第二步，全部因子相乘**：乘开所有因子，每一项是「若干素数幂的 $-s$ 次方」之积，即 $n^{-s}$ 其中 $n$ 是这些素数幂的乘积。
- **第三步，算术基本定理登场**：每个正整数 $n$ 唯一分解成素数幂，所以每个 $n^{-s}$ 恰好出现一次——乘积恰好等于求和 $\sum n^{-s}$。
- **第四步，读出素数信息**：ζ 的零点与极点通过这个乘积与素数绑定；$\mathrm{Re}(s) > 1$ 时乘积收敛，$s = 1$ 时发散（$\sum 1/n$ 发散），对应 $s=1$ 是极点。

**辨析｜易错点：**欧拉乘积只在 $\mathrm{Re}(s) > 1$ 时严格成立；
在临界带内需要用解析延拓后的 ζ 函数，乘积形式不再适用。
把「级数 = 乘积」的等式盲目用到 $\mathrm{Re}(s) \le 1$，会得到发散级数的无意义结论——必须先解析延拓，再谈零点。

## 5 数论函数与 ζ 的联系

狄利克雷级数与数论函数的关系网，是解析数论的常规弹药：

| 数论函数 $f(n)$ | 狄利克雷级数 | 与 ζ 的关系 |
| --- | --- | --- |
| $\mathbf{1}(n) = 1$ | $\zeta(s)$ | 定义本身 |
| $\mu(n)$ | $1/\zeta(s)$ | $\mu$ 是 $\mathbf{1}$ 的卷积逆元 |
| $\varphi(n)$ | $\zeta(s-1)/\zeta(s)$ | $\varphi = \mathrm{Id} * \mu$ |
| $\mathrm{Id}(n) = n$ | $\zeta(s-1)$ | 平移一个单位 |
| $\sigma(n)$ | $\zeta(s)\zeta(s-1)$ | $\sigma = \mathrm{Id} * \mathbf{1}$ |

例如 $\sigma = \mathrm{Id} * \mathbf{1}$ 翻译成级数就是 $\zeta(s-1)\zeta(s)$——数论函数之间的一条卷积等式，对应着 ζ 函数之间的一条代数等式。<span class="marginnote">「卷积 ↔ 乘法」这条字典是狄利克雷级数存在的全部意义。
乘性函数一节的结论（$\mu$ 是 $\mathbf{1}$ 的逆元、$\varphi = \mathrm{Id}*\mu$）在这里全部变成 ζ 函数之间的简单公式——抽象的群论结构在分析里有了血肉。</span>

## 6 例题演练：狄利克雷级数与 ζ 的联系

**例一：$\varphi$ 的级数。** 由 $\varphi = \mathrm{Id} * \mu$，得 $\sum \varphi(n)/n^s = \zeta(s-1)/\zeta(s)$。
验算特值 $s = 2$：左边 $\sum \varphi(n)/n^2 = \frac{1}{1} + \frac{1}{4} + \frac{2}{9} + \frac{2}{16} + \frac{4}{25} + \cdots$，右边 $\frac{\zeta(1)}{\zeta(2)}$——但 $\zeta(1)$ 发散，$s = 2$ 不在收敛域内。
这个例子提醒：级数恒等式要在收敛域（$\mathrm{Re}(s) > $ 某阈值）内使用。

**例二：$\sigma$ 的级数。** $\sigma = \mathrm{Id} * \mathbf{1}$ 给出 $\sum \sigma(n)/n^s = \zeta(s)\zeta(s-1)$。
验证系数：展开右侧前几项 $\zeta(s)\zeta(s-1) = \left(1 + 2^{-s} + 3^{-s} + \cdots\right)\left(1 + 2^{1-s} + 3^{1-s} + \cdots\right)$，$n = 2$ 的系数是 $1 \cdot 2^{1-s} + 2^{-s} \cdot 1 = 2/2^s + 1/2^s = 3/2^s$，而 $\sigma(2) = 3$ ✓。<span class="marginnote">「把数论函数关系翻译成级数恒等式，再按系数比对验证」——这是解析数论最基本的验算方式。
系数匹配证明了卷积等式在级数层面的正确性。</span>

**例三：$\mu$ 的级数。** $\mu * \mathbf{1} = \varepsilon$ 给出 $\sum \mu(n)/n^s = 1/\zeta(s)$。
于是当 $\zeta(s) \to \infty$（$s \to 1^+$）时 $1/\zeta(s) \to 0$，这意味着「$\sum \mu(n)/n$ 收敛到 $0$」——它其实等价于素数定理。
数论函数的级数恒等式不是把戏，而是通往素数分布定理的钥匙。

**例四：欧拉乘积验算。** $\zeta(2) = \prod_p (1 - p^{-2})^{-1} = \frac{1}{1-\frac14} \cdot \frac{1}{1-\frac19} \cdot \frac{1}{1-\frac1{25}} \cdots$。
前几个因子相乘约等于 $\frac43 \times \frac98 \times \frac{25}{24} = \frac{4 \times 9 \times 25}{3 \times 8 \times 24} = \frac{900}{576} = 1.5625$，而 $\zeta(2) = \pi^2/6 \approx 1.6449$——乘积逐步逼近，正是欧拉 1735 年发现 $\sum 1/n^2 = \pi^2/6$ 的路径。

**辨析｜易错点：**狄利克雷级数的收敛域不是全平面。$\sum 1/n^s$ 在 $\mathrm{Re}(s) > 1$ 收敛，$s = 1$ 处发散；
用它去算 $\zeta(1)$ 或负整数处会得到无意义的发散结果。
只有经过解析延拓的 ζ 函数才在左半平面有定义——「级数」与「延拓后的函数」是两回事。

## 7 小结

- **狄利克雷级数** $\sum f(n)/n^s$：把数论函数编码为生成函数；卷积变成普通乘法。
- **欧拉乘积** $\zeta(s) = \prod_p (1 - p^{-s})^{-1}$：算术基本定理的分析翻版，素数与 ζ 的桥梁。
- **解析延拓与函数方程**：ζ 延拓到全复平面（$s=1$ 为极点），平凡零点在负偶数处。
- **黎曼猜想**：非平凡零点全在 $\mathrm{Re}(s) = 1/2$ 上；它等价于素数定理误差的最优界。
- 数论函数的狄利克雷级数都由 ζ 的简单组合表达——一条「卷积 ↔ 乘法」字典贯穿全局。
