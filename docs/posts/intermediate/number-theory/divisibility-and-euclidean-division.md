## 为什么从整除开始

数论研究的是整数的结构：哪些数能整除哪些数、素数如何分布、同余方程怎么解。
而这一切的第一步，是回答一个小学三年级就接触过的问题——**一个整数能不能被另一个整数除尽**。
这个「能不能除尽」的判断，在数学里被提炼成一个精确的关系：**整除**。

整除听起来简单，但它正是整座数论大厦的地基。
辗转相除法由它而来，算术基本定理由它而来，RSA 密码学里那个让全世界网页加密的「大整数分解难题」也由它而来。<span class="marginnote">RSA 的安全性依赖「分解大整数困难、但验证整除很容易」这一不对称。
等你学到第四级《密码学与信息安全》，会看到整除是全部公钥密码的第一性原理。</span>本节的另一个主角**带余除法**，则把「除不尽」的情况也纳入严格框架——它保证了任何整数相除都能写成一个商加一个余数，这个「余数」就是后面整个同余理论的种子。

## 1 整除的定义

**整除（divisibility）**：设 $a, b$ 为整数，且 $a \neq 0$。
如果存在整数 $q$，使得 $b = aq$，那么称 **$a$ 整除 $b$**，记作 $a \mid b$；
称 $a$ 是 $b$ 的**因数**或**约数**，$b$ 是 $a$ 的**倍数**。

$$a \mid b \iff \exists\, q \in \mathbb{Z},\ b = aq$$

这里有几个字面容易忽略、实则关键的约定：

- **$a \neq 0$**：除数不能为 0，否则「$0$ 整除 $b$」没有意义。
- **$b$ 可以是 0**：因为 $0 = a \cdot 0$，所以任何非零整数 $a$ 都整除 0。
- **$q$ 必须是整数**：$2 \mid 6$ 成立（$6 = 2 \cdot 3$），但 $2 \nmid 5$ 不成立，因为不存在整数 $q$ 使 $5 = 2q$。

**辨析｜易错点：**「整除」与「被整除」的读法经常被念反。$a \mid b$ 读作「$a$ 整除 $b$」，意思是 $b$ 能被 $a$ 除尽；
而「$b$ 整除 $a$」写出来是 $b \mid a$，含义完全不同。$2 \mid 4$ 是真命题，$4 \mid 2$ 是假命题，一字之差，方向颠倒。

## 2 整除的基本性质

整除作为整数间的关系，有几条立刻能用、后面反复出场的性质。

**性质一（传递性）：** 若 $a \mid b$ 且 $b \mid c$，则 $a \mid c$。

证明是一行的事：$b = aq_1$，$c = bq_2$，代入得 $c = a(q_1 q_2)$，而 $q_1 q_2$ 仍是整数。
传递性让「整除」像链子一样一环扣一环，是后面判断大数整除关系时的常用推理。

**性质二（线性组合）：** 若 $a \mid b$ 且 $a \mid c$，则对任意整数 $x, y$，有

$$a \mid (bx + cy)$$

$b = aq_1$、$c = aq_2$，于是 $bx + cy = a(q_1 x + q_2 y)$。
这个性质说明：**一个数的倍数做任意整数线性组合，仍是它的倍数**。
它是后面最大公因数理论中「贝祖等式」的雏形。<span class="marginnote">贝祖等式（Bézout's identity）：存在整数 $x, y$ 使 $ax + by = \gcd(a,b)$，是线性代数里「整数格点」的源头。
下一节会详细展开。</span>

**性质三（乘积与带符号）：** 若 $a \mid b$，则对任意非零整数 $c$ 有 $ac \mid bc$；
且 $-a \mid b$ 与 $a \mid -b$ 恒同于 $a \mid b$。

符号不影响整除：$a \mid b$ 与 $|a| \mid |b|$ 等价，所以研究整除只需关注**正因数**。
这也是为什么数论里「因数」通常默认指正因数，最大公因数也总是取正的。

**辨析｜易错点：**「$a \mid b$」与「$b/a$ 是整数」是一回事，但与「$a \le b$」没有必然关系。
例如 $3 \mid 0$ 成立（$0 = 3\cdot 0$），但 $3 > 0$；
反过来 $2 \mid 6$，$2 < 6$ 也成立。
判断整除只能看「是否能写成整数倍」，不能看大小。

## 3 带余除法：除不尽的严格说法

生活中「$7$ 个苹果分给 $3$ 个人，每人 $2$ 个还剩 $1$ 个」——这个「每人 $2$ 个还剩 $1$ 个」，在数学里被提炼成一条最重要的定理。

**带余除法（division algorithm）**：设 $a, b$ 为整数，$b > 0$，则存在**唯一**的一对整数 $q, r$，使得

$$a = bq + r, \qquad 0 \le r < b$$

其中 $q$ 称为**不完全商**，$r$ 称为**余数（remainder）**。<span class="marginnote">余数 $r$ 的取值范围 $0 \le r < b$ 被死死限定——它必须「小到不能再减一次 $b$」。
这个唯一性约束是整个同余理论能够成立的前提。</span>

为什么必须是 $0 \le r < b$ 而不是别的区间？
因为只要 $r$ 落在 $[0, b)$ 内，$q$ 和 $r$ 就都被唯一确定。
若允许 $r$ 取 $[-b, b)$ 甚至更大的范围，同一对 $a, b$ 就能写出很多种「商 + 余数」，性质就乱套了。

**存在性**的思路很直白：从 $a$ 里反复减去 $b$，直到剩下的数小于 $b$ 且不小于 $0$；**唯一性**则靠反证——若有两组 $(q_1, r_1)$、$(q_2, r_2)$ 都满足条件，相减得 $b(q_1 - q_2) = r_2 - r_1$，左边是 $b$ 的倍数，右边绝对值小于 $b$，唯一的可能是两边都是 $0$，即两组相同。

## 4 公式解析：带余除法

$$a = bq + r, \qquad 0 \le r < b$$

- **第一步，认符号**：$a$ 是被除数，$b$ 是除数（要求 $b > 0$），$q$ 是商，$r$ 是余数。四者全是整数。
- **第二步，看余数区间**：$0 \le r < b$ 是这条公式的「灵魂」。它把「除不尽」标准化：余数永远在 $0$ 到 $b-1$ 之间，绝不与 $b$ 等大，也不为负。
- **第三步，理解商与余数的分工**：$q$ 负责「整数倍部分」，$r$ 负责「多出来的零头」。写成 $a \bmod b = r$ 时，$r$ 就是同余记号 $a \equiv r \pmod{b}$ 的雏形——同余理论的全部内容，都建立在这个「除 $b$ 留余」的机制上。
- **第四步，负数也要管**：若 $a = -7, b = 3$，则应取 $q = -3, r = 2$，因为 $0 \le 2 < 3$；而不是 $q = -2, r = -1$。**余数恒非负**是这条公式在负数情形下的硬约束。<span class="marginnote">这里与多数编程语言的取模不同：数学上余数必须非负，而 C/Python 等语言对负数取模的符号各有约定。写代码时「余数」与数学里的 $r$ 可能差一个 $b$，初学最容易踩坑。</span>

## 5 带余除法到哪里去

带余除法看起来平淡，它却是数论中**最重要的底层工具**，三条主线从它出发：

- **辗转相除法**：反复做带余除法 $a = bq_1 + r_1$、$b = r_1 q_2 + r_2$……最终得到最大公因数。下一节就是它。
- **同余理论**：$a \equiv r \pmod{b}$ 把「两个数除以 $b$ 余数相同」做成等价关系，整章同余、剩余系、中国剩余定理都建立在带余除法上。
- **进位制与进制转换**：把整数按基底展开，本质就是反复带余除法。计算机里的二进制、十六进制转换，底层就是这条公式在循环。<span class="marginnote">到第三级《计算机组成原理》你会看到，CPU 做除法就是硬件化的带余除法；而哈希、伪随机数、循环冗余校验（CRC）都在用「取余」这一操作。</span>

**辨析｜易错点：**带余除法的「余数」与「模运算」的概念容易混。$a \bmod b = r$ 中，$r$ 就是带余除法里那个唯一的非负余数；
但「同余」关系 $a \equiv c \pmod{b}$ 强调的是「$a$ 与 $c$ 除以 $b$ 的余数相等」，是两个数的关系，而非一个数到余数的运算。
前者是函数，后者是关系——下一步同余理论会精确区分这两者。

## 6 例题演练：带余除法的实战

把带余除法放到具体问题里，才知道它的边界在哪。

**例一：负数的余数。** 求 $-17$ 除以 $5$ 的商与余数。
按规则 $a = bq + r$、$0 \le r < b$，需要找 $q, r$ 使 $-17 = 5q + r$ 且 $0 \le r < 5$。$5 \times (-4) = -20$，$-17 - (-20) = 3$，所以 $q = -4$，$r = 3$，即 $-17 = 5 \times (-4) + 3$。
余数 $3$ 落在 $[0, 5)$ 内，正确。

**辨析｜易错点：**若先取 $q = -3$，则 $r = -2$，不满足 $0 \le r < 5$——**商往负方向多取一点，余数才能为正**。
这是负数带余除法的统一取法。

**例二：判断整除。** $a = 123456$，$b = 8$。
是否 $8 \mid 123456$？
用整除定义：$123456 \div 8 = 15432$ 恰好整除，故 $8 \mid 123456$。
再看 $9 \nmid 123456$，因为 $1+2+3+4+5+6 = 21$ 不被 $9$ 整除（数位和判据）——这个判据的证明正是「$10^k \equiv 1 \pmod 9$」，是整除性质的推论。

**例三：余数相同判定。** 判断 $47$ 与 $11$ 除以 $6$ 的余数是否相同。$47 = 6 \times 7 + 5$，$11 = 6 \times 1 + 5$，两者余数都是 $5$。
用同余语言就是 $47 \equiv 11 \pmod 6$，因为 $47 - 11 = 36$ 被 $6$ 整除——整除与同余是同一件事的两种说法。

**例四：由余数反推整数。** 一个整数除以 $7$ 余 $3$，除以 $9$ 余 $2$，求最小的正整数。
列出除以 $7$ 余 $3$ 的数：$3, 10, 17, 24, 31, 38, \ldots$；
其中除以 $9$ 余 $2$ 的最小正数是 $38$（$38 = 9 \times 4 + 2$）。
这里我们用带余除法生成候选、再逐一筛选——这是下一章同余方程与中国剩余定理的朴素形态。

## 7 小结

- **整除**：$a \mid b$ 当且仅当存在整数 $q$ 使 $b = aq$；要求 $a \neq 0$，但 $b$ 可以是 $0$。
- **整除的传递性**与**线性组合性质**：$a \mid b, a \mid c \Rightarrow a \mid (bx + cy)$，是证明与化简的利器。
- **带余除法**：$a = bq + r$，$0 \le r < b$，商与余数**唯一**；余数恒非负，负数情形须注意。
- 整除只看「是否能写成整数倍」，与大小无关；$a \mid b$ 与 $b \mid a$ 方向相反、含义完全不同。

在下一节，我们将问一个更深的问题：给了两个数，如何快速找出它们公共的因数里最大的那个？
答案就是**最大公因数与辗转相除法**——它是人类历史上最古老的算法之一。
