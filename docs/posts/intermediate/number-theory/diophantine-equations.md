## 为什么方程要限定「整数解」

普通方程 $x + y = 5$ 有无数个实数解；
但若要求 $x, y$ 是整数，解就只有有限个 $(0,5), (1,4), \ldots, (5,0)$。
限定「整数解」看似是加了紧箍咒，实则打开了一个全新的数学世界——**丢番图方程（Diophantine equation）**：只求整数解的（多变量）多项式方程。

丢番图在 3 世纪用「算术」给出了许多整数解的配方；
费马在这本书的页边写下了著名的费马大定理（$x^n + y^n = z^n$ 无正整数解），三百多年后怀尔斯才证明了它。
丢番图方程是数论的核心战场：线性方程有完整理论，佩尔方程有连分数解，高次方程则通向椭圆曲线与代数数论——甚至图灵机的停机问题都可以编码进丢番图方程（希尔伯特第十问题的否定答案）。<span class="marginnote">希尔伯特第十问题问：「是否存在算法判定任意丢番图方程是否有整数解？」1970 年马季亚谢维奇（Matiyasevich）结合图灵与戴维斯-普特南-鲁滨逊的工作证明：<strong>没有这样的算法</strong>。
可判定性理论由此与数论激烈碰撞——这是《离散数学》里可计算性与本节的隐秘连接。</span>

## 1 一次（线性）丢番图方程

最基础也最完整的理论：二元一次方程

$$ax + by = c$$

其中 $a, b, c$ 是给定整数。它的完整理论已在最大公因数一节铺垫好。

**有解判据**：方程有整数解 $\iff \gcd(a, b) \mid c$。
证明依赖贝祖等式：$ax + by$ 的所有取值恰是 $\gcd(a,b)$ 的倍数。<span class="marginnote">「$ax + by$ 的取值集合 = $\gcd(a,b)$ 的倍数全体」这一事实，是「最大公因数 = 整数线性组合的最小正元」的直接推论。
它把贝祖等式从「存在性」升级成「完整性」：不止能配出 $\gcd$，还能配出它的所有倍数。</span>

**解的结构**：若有特解 $(x_0, y_0)$，则全部解为

$$x = x_0 + \frac{b}{d}\, t, \qquad y = y_0 - \frac{a}{d}\, t, \qquad d = \gcd(a, b), \ t \in \mathbb{Z}$$

**求特解**：扩展欧几里得求出 $a s + b t = d$，再乘 $c/d$ 得 $x_0 = s \cdot \frac{c}{d}$，$y_0 = t \cdot \frac{c}{d}$。

例：$6x + 15y = 9$。$d = \gcd(6,15) = 3 \mid 9$，有解。$6(-2) + 15(1) = 3$，乘 $3$ 得特解 $(-6, 3)$。
全部解 $x = -6 + 5t$，$y = 3 - 2t$。

**辨析｜易错点：**通解里 $x$ 的步长是 $b/d$、$y$ 的步长是 $a/d$，方向相反（保证 $a \Delta x + b \Delta y = 0$）。
把步长写成 $b$ 或 $a$ 而忘掉除以 $d$，会漏掉一半解。

## 2 佩尔方程

二次丢番图方程里最有名的一个：

$$x^2 - dy^2 = 1$$

其中 $d$ 是非平方正整数。它总有正整数解吗？**有，而且无穷多**。解法藏在连分数里：

**定理：** 设 $\sqrt{d}$ 的连分数周期长度为 $L$，渐近分数为 $p_k/q_k$。
则 $x^2 - dy^2 = 1$ 的所有正整数解是 $x = p_{kL-1}$，$y = q_{kL-1}$（$k = 1, 2, \ldots$）的某个子列（取决于周期长度奇偶）。

以 $d = 2$ 为例：$\sqrt{2} = [1; 2, 2, 2, \ldots]$，渐近分数 $1/1, 3/2, 7/5, 17/12, \ldots$。
检验：$3^2 - 2 \cdot 2^2 = 1$ ✓；$17^2 - 2 \cdot 12^2 = 289 - 288 = 1$ ✓。
所以 $(x, y) = (3, 2), (17, 12), \ldots$ 都是解。<span class="marginnote">佩尔方程的解构成一个无限序列，相邻解之间由「最小解」的乘法递推生成：若 $(x_1, y_1)$ 是最小解，则 $(x_k, y_k)$ 满足 $x_k + y_k\sqrt{d} = (x_1 + y_1\sqrt{d})^k$——这是二次域 $\mathbb{Q}(\sqrt{d})$ 里的单位群理论，通向代数数论。</span>

**为什么重要**：佩尔方程是最简单的「非线性丢番图方程却有完整理论」的例子，也是逼近论、密码学（某些公钥方案）与数论工具（连分数）的练兵场。

## 3 勾股数与费马大定理

**勾股方程** $x^2 + y^2 = z^2$ 的正整数解 $(x, y, z)$ 叫**勾股数组**。
它有无穷多组，且所有本原解（$\gcd(x,y,z)=1$）可由公式给出：

$$x = m^2 - n^2, \qquad y = 2mn, \qquad z = m^2 + n^2$$

其中 $m > n > 0$，$\gcd(m, n) = 1$，$m, n$ 一奇一偶。<span class="marginnote">$m=2,n=1$ 给出 $(3,4,5)$；$m=3,n=2$ 给出 $(5,12,13)$。
这条公式来自「在复平面上把 $(m+in)^2$ 展开」——$|m+in|^2 = m^2+n^2$，实虚部恰好构成勾股三元组。
几何与复数的第一次相遇就藏在初中就熟的公式里。</span>

**费马大定理**：方程 $x^n + y^n = z^n$（$n > 2$）没有正整数解。
费马声称「我发现了绝妙的证明，但页边太小写不下」，此后三百五十年无人能解，直到 1994 年怀尔斯用椭圆曲线与模形式完成证明。
它从「丢番图方程」升华为「一座学科的交汇点」。

**辨析｜易错点：**「$n > 2$ 无解」针对的是**正整数**解。$x^n + y^n = z^n$ 在整数（含负）或实数里显然有解（$0^n + 1^n = 1^n$ 等）。
费马大定理的精确表述是「没有**非零整数**解」，边界情形 $x=0$ 或 $y=0$ 不算。

## 4 公式解析：佩尔方程与连分数

$$x^2 - dy^2 = 1 \ \Rightarrow\ x = p_{kL-1}, \ y = q_{kL-1}$$

- **第一步，展开 $\sqrt{d}$**：计算 $\sqrt{d}$ 的连分数与渐近分数 $p_k/q_k$，周期长度为 $L$。
- **第二步，识别最小解**：第一个满足 $p^2 - dq^2 = 1$ 的渐近分数就是最小解 $(x_1, y_1)$。
- **第三步，递推全部解**：$x_k + y_k\sqrt{d} = (x_1 + y_1\sqrt{d})^k$——乘方生成所有解。
- **第四步，核对**：$d = 2$ 时最小解 $(3, 2)$，$(3+2\sqrt2)^2 = 17 + 12\sqrt2$，下一解 $(17, 12)$ ✓。

**重点：** 佩尔方程的意义在于展示了**「解的存在性与结构」如何由连分数的周期结构完整给出**——这是连分数理论（上一节）最好的应用之一，也解释了为什么把两节放在一起。

**辨析｜易错点：**$x^2 - dy^2 = -1$（负佩尔方程）不一定有解。$\sqrt{2}$ 对应的 $-1$ 方程有解 $(1,1)$；
但 $d$ 使 $\sqrt{d}$ 的连分数周期长度为奇数时有解、偶数时无解。
见到负号佩尔方程，先查周期长度，别默认有解。

## 5 例题演练：丢番图方程的求解

**例一：线性方程的通解。** 解 $12x + 18y = 30$。$d = \gcd(12, 18) = 6$，$6 \mid 30$，有解。
扩展欧几里得：$12 \times (-1) + 18 \times 1 = 6$，两边乘 $5$ 得 $12 \times (-5) + 18 \times 5 = 30$，特解 $(x_0, y_0) = (-5, 5)$。
全部解：$x = -5 + \frac{18}{6}t = -5 + 3t$，$y = 5 - \frac{12}{6}t = 5 - 2t$。
取 $t = 2$ 得 $x = 1, y = 1$：$12 + 18 = 30$ ✓。

**例二：佩尔方程的最小解。** 求 $x^2 - 3y^2 = 1$ 的最小正整数解。$\sqrt{3} = [1; 1, 2, 1, 2, \ldots]$，渐近分数 $1, 2, \frac53, \frac74, \ldots$。
逐个检验 $p^2 - 3q^2$：$1^2 - 0 = 1$（$q=0$ 平凡解不计）；$2^2 - 3 \times 1^2 = 1$ ✓。
最小解 $(x, y) = (2, 1)$。
下一解：$(2 + \sqrt3)^2 = 7 + 4\sqrt3$，即 $(7, 4)$，$7^2 - 3 \times 16 = 49 - 48 = 1$ ✓。<span class="marginnote">佩尔方程的解序列 $(2,1), (7,4), (26,15), \ldots$ 由「最小解乘方」生成，每一项都精确满足方程。
这个「乘法生成」结构来自二次域 $\mathbb{Q}(\sqrt3)$ 的单位群。</span>

**例三：勾股数组。** 用 $m = 4, n = 1$ 生成勾股数组：$x = 16 - 1 = 15$，$y = 2 \times 4 \times 1 = 8$，$z = 16 + 1 = 17$。$15^2 + 8^2 = 225 + 64 = 289 = 17^2$ ✓。
用 $m = 4, n = 2$ 会得到 $(12, 16, 20)$，这是 $(3, 4, 5)$ 的 4 倍——因为 $\gcd(4, 2) = 2 \ne 1$，生成的数组不本原。

**例四：费马方程的无解性感受。** $x^3 + y^3 = z^3$ 有没有非零整数解？
费马大定理说没有。
反观 $x^3 + y^3 = z^3 + w^3$（四元三次）却有无穷多解，例如 $3^3 + 4^3 = 27 + 64 = 91 = 3^3 + 4^3$，而 $1^3 + 6^3 = 1 + 216 = 217 = 3^3 + 5^3 + 5^3$？——「少一个变量，从有解变无解」，正是丢番图方程最迷人的脆弱性。

**辨析｜易错点：**佩尔方程的最小解未必是「第一个渐近分数」。$x^2 - 2y^2 = -1$ 的最小解是 $(1, 1)$；
但 $x^2 - 2y^2 = 1$ 的最小解是 $(3, 2)$ 而非 $(1, 1)$。
求佩尔方程的解必须逐个检验渐近分数，不能想当然取前几个。

## 6 小结

- **丢番图方程**：只求整数解的多项式方程；线性方程有完整判据与解结构，高次方程难度骤升。
- **线性方程** $ax + by = c$：有解 $\iff \gcd(a,b) \mid c$；通解是「特解 + 步长平移」。
- **佩尔方程** $x^2 - dy^2 = 1$：解由 $\sqrt{d}$ 的连分数渐近分数给出，最小解乘方生成全部解。
- **勾股数组**：$x = m^2-n^2$，$y = 2mn$，$z = m^2+n^2$；费马大定理是丢番图方程皇冠上的明珠。
- 希尔伯特第十问题证明：判定任意丢番图方程有解是不可判定的。
