# 高次同余方程

## 为什么高次同余方程更难

上一节的一次同余方程 $ax \equiv b \pmod m$ 有一个完美的判据与显式解法。但一旦次数升高，比如

$$x^2 \equiv -1 \pmod p, \qquad x^3 \equiv 2 \pmod m$$

问题立刻变得棘手。原因很本质：一次方程的解结构是「平移」——所有解相差一个步长；
而高次方程的解结构是「代数结构」——它取决于多项式在模 $p$ 下的根，与素数 $p$ 的算术性质纠缠在一起。<span class="marginnote">「模 $p$ 下多项式有多少根」这个问题，在《抽象代数》里有一个漂亮的答案：模 $p$ 的整环 $\mathbb{Z}_p$ 里，$n$ 次多项式至多有 $n$ 个根（拉格朗日定理在域上的推论）。
但「有几个根、根是多少」则是数论特有的难题。</span>

不过，高次同余方程并非铁板一块。
本节给出一个**降维武器库**：模数可分解（归约到素数幂情形）、次数可用欧拉定理压低、素数幂情形可用亨泽尔提升（Hensel's lemma）。
掌握这三个工具，「高次」就不再可怕。

## 1 归约：模数分解

高次同余方程最难处理的是「模数合数」。第一个降维工具是**中国剩余定理**：

**策略：** 解 $f(x) \equiv 0 \pmod m$，其中 $m = m_1 m_2 \cdots m_k$ 且 $m_i$ 两两互素，等价于解方程组

$$f(x) \equiv 0 \pmod{m_1}, \quad f(x) \equiv 0 \pmod{m_2}, \quad \cdots, \quad f(x) \equiv 0 \pmod{m_k}$$

每个「小方程」的解集 $S_i$ 求出来后，任取 $x_i \in S_i$ 组合，用 CRT 拼出 $x$，就得到原方程的解。<span class="marginnote">这一归约的代价极小、收益极大：$m = 100 = 4 \times 25$，解模 $4$ 与模 $25$ 的方程远比解模 $100$ 的方程容易，最后 CRT 合并即可。
工业密码学里所有模合数的高次方程都走这条路。</span>

把 $m$ 分解成两两互素的因子（通常是素数幂），问题就归约为「模素数幂 $p^k$」的情形。

## 2 模素数：次数压低与根的结构

先看最简单的模素数 $p$。设 $f(x)$ 是整系数多项式，次数为 $n$。

**降次工具一：费马小定理的「归一化」**。
在模 $p$ 意义下，$x^p \equiv x \pmod p$（费马小定理，下一节正式证明）。
所以高于 $p$ 次的项都能化简：$x^{p} \equiv x$，$x^{p+1} \equiv x^2$，……每个多项式都等价于一个次数 $\le p-1$ 的多项式。
这一手能立刻压低方程的「名义次数」。

**根数的上界**：若 $f$ 次数为 $n$ 且 $p \nmid$ 各项系数的公因子，则 $f(x) \equiv 0 \pmod p$ 至多有 $n$ 个根——因为模 $p$ 是一个域，域里 $n$ 次多项式至多有 $n$ 个根（用「因式定理 + 归纳」证明）。<span class="marginnote">这条「域里 $n$ 次方程至多 $n$ 个根」的定理，在《离散数学》《抽象代数》里都会作为域论的基本事实出现。
它解释了为什么 $x^2 \equiv a \pmod p$ 的解最多 2 个、$x^2 \equiv a \pmod p$ 才可能「无解」。</span>

**模素数高次方程的特殊例子**：$x^2 \equiv -1 \pmod p$ 有解当且仅当 $p = 2$ 或 $p \equiv 1 \pmod 4$——这是二次剩余理论的先声（第三篇首节），也是「高次同余方程的解与素数本身的同余类挂钩」的第一个实例。

## 3 模素数幂：亨泽尔提升

模 $p^k$ 的方程，关键的观察是：**模 $p^k$ 的解「收缩」成模 $p$ 的解**。
若 $x$ 满足 $f(x) \equiv 0 \pmod{p^k}$，则 $x$ 必满足 $f(x) \equiv 0 \pmod p$。
反过来，能否把一个模 $p$ 的解「提升」为模 $p^k$ 的解？
这就是**亨泽尔引理（Hensel's lemma）**。

**亨泽尔引理：** 设 $f(x)$ 是整系数多项式，$a$ 满足 $f(a) \equiv 0 \pmod p$ 且 $f'(a) \not\equiv 0 \pmod p$（$f'$ 是形式导数），则存在**唯一的**模 $p^k$ 的解 $a_k$，使得 $a_k \equiv a \pmod p$ 且 $f(a_k) \equiv 0 \pmod{p^k}$。<span class="marginnote">条件 $f'(a) \not\equiv 0 \pmod p$ 叫「非退化」条件。
若 $f'(a) \equiv 0$，可能无提升、可能多个提升，需要逐层讨论——这与《数值分析》里牛顿法「导数非零才收敛」的条件惊人相似，亨泽尔提升在结构上正是模 $p$ 版本的牛顿迭代。</span>

提升的迭代构造与牛顿法同构：

$$x_{k+1} \equiv x_k - \frac{f(x_k)}{f'(x_k)} \pmod{p^{k+1}}$$

从模 $p$ 的根 $x_0 = a$ 出发，每步把解的精度从模 $p^k$ 提到模 $p^{k+1}$。

## 4 公式解析：亨泽尔提升的一步

$$x_{k+1} \equiv x_k - f(x_k) \cdot \big(f'(x_k)\big)^{-1} \pmod{p^{k+1}}$$

- **第一步，已知 $x_k$**：$x_k$ 是模 $p^k$ 的根，即 $f(x_k) \equiv 0 \pmod{p^k}$，所以 $f(x_k) = p^k t$ 是 $p^k$ 的倍数。
- **第二步，猜测修正**：设 $x_{k+1} = x_k + p^k c$（在模 $p^k$ 下同余于 $x_k$，只多了 $p^k$ 的修正量）。代入 $f$ 用一阶泰勒展开：$f(x_k + p^k c) \approx f(x_k) + p^k c f'(x_k)$。
- **第三步，解出 $c$**：要求 $f(x_{k+1}) \equiv 0 \pmod{p^{k+1}}$，即 $p^k t + p^k c f'(x_k) \equiv 0 \pmod{p^{k+1}}$，两边除 $p^k$：$t + c f'(x_k) \equiv 0 \pmod p$，解得 $c \equiv -t \cdot (f'(x_k))^{-1} \pmod p$。
- **第四步，归纳推进**：每层修正量 $c$ 由上一层确定，逐层提升到任意精度 $p^k$。

这个公式是「在模 $p$ 意义下解一个小方程，然后逐层放大」——每次只提升一个 $p$ 的数量级，直到达到想要的 $p^k$。<span class="marginnote">与《数值分析》牛顿法的对照不是巧合：牛顿法用导数线性化逼近根，亨泽尔提升在 $p$-进数里做同样的事。$p$-进数（$p$-adic numbers）正是把「模 $p^k$ 的所有精度」合在一起的对象，它在《抽象代数》与代数几何里是核心工具。</span>

**辨析｜易错点：**亨泽尔引理的前提是「模 $p$ 先有根」且「导数非退化」。
若 $f'(a) \equiv 0 \pmod p$，不能保证提升唯一，甚至不能保证可提升。
初学者常把「模 $p$ 有解」当成「模 $p^k$ 有解」的充分条件——**它只是必要条件，非退化时才是充分条件**。

## 5 例题演练：高次同余方程的降维打击

**例一：归约到素数幂。** 解 $x^2 \equiv 1 \pmod{15}$。$15 = 3 \times 5$，拆成 $x^2 \equiv 1 \pmod 3$ 与 $x^2 \equiv 1 \pmod 5$。
模 $3$ 的解：$x \equiv \pm 1$，即 $x \equiv 1, 2 \pmod 3$；
模 $5$ 的解：$x \equiv 1, 4 \pmod 5$。
四种组合用 CRT 合并：$(1,1) \to 1$，$(1,4) \to 4$，$(2,1) \to 11$，$(2,4) \to 14$。
所以 $x^2 \equiv 1 \pmod{15}$ 有四个解：$x \equiv 1, 4, 11, 14 \pmod{15}$。<span class="marginnote">注意解数从「模素数最多 2 个」涨到「模合数最多 $2^k$ 个」——因为每种组合都给出一个不同的模 $15$ 解。
这就是合数模数方程比素数模数方程解更多的原因。</span>

**例二：模素数降次。** 解 $x^5 \equiv x^3 \pmod 7$。
移项 $x^3(x^2 - 1) \equiv 0 \pmod 7$，即 $x^3(x-1)(x+1) \equiv 0$。
模 $7$ 是域，逐个因子看：$x \equiv 0, 1, -1$ 是解，共 $3$ 个。
也可以用费马小定理压低次数：$x^7 \equiv x$，把高次项化掉。

**例三：亨泽尔提升。** 解 $x^2 \equiv -1 \pmod{25}$。
先解模 $5$：$x^2 \equiv 4$，解 $x \equiv \pm 2 \pmod 5$。
从 $x_0 = 2$ 提升：设 $x_1 = 2 + 5c$，$f(x) = x^2 + 1$，$f'(x) = 2x$，$f'(2) = 4 \not\equiv 0 \pmod 5$。
令 $x_1 = 2 + 5c$ 代入 $f(x_1) \equiv 0 \pmod{25}$：$(2+5c)^2 + 1 = 4 + 20c + 25c^2 + 1 = 5 + 20c + 25c^2 \equiv 5 + 20c \pmod{25}$，即 $5(1 + 4c) \equiv 0 \pmod{25}$，$1 + 4c \equiv 0 \pmod 5$，$4c \equiv 4$，$c \equiv 1$。
故 $x \equiv 7 \pmod{25}$ 是一个解，另一个解 $x \equiv -7 \equiv 18 \pmod{25}$。<span class="marginnote">手算亨泽尔提升的每一步都对应牛顿迭代：从模 $5$ 的根出发，修正量 $c$ 在模 $5$ 意义下解一个小一次方程，精度从模 $5$ 提到模 $25$。
若要模 $125$，就再迭代一轮。</span>

**辨析｜易错点：**提升前必须确认 $f'(x_0) \not\equiv 0 \pmod p$。
若 $f'(x_0) \equiv 0$（退化情形），可能无提升、可能多个提升——$x^2 \equiv 0 \pmod 5$ 的根 $x_0 = 0$ 导数也为 $0$，提升到模 $25$ 变成 $x \equiv 0, 5, 10, 15, 20$ 五个解，与「唯一提升」的典型情形完全不同。

## 6 小结

- **归约到素数幂**：用中国剩余定理把合数模数的高次方程拆成素数幂方程组。
- **模素数降次**：费马小定理 $x^p \equiv x$ 压低名义次数；域中 $n$ 次方程至多 $n$ 个根。
- **亨泽尔提升**：模 $p$ 的根在非退化条件下可逐层提升到模 $p^k$，迭代公式与牛顿法同构。
- 「模 $p$ 有解」≠「模 $p^k$ 有解」，提升需要导数非退化条件。
- 高次同余方程是二次剩余理论、$p$-进数与代数数论的入口。

在下一节，我们回到模素数这个最简单的舞台，却要证明一个看似巧合的定理：$(p-1)!$ 模 $p$ 的余数竟是 $-1$。
这就是**威尔逊定理**。
