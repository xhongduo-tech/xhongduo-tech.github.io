## 为什么函数会被「乘性」打动

算术基本定理告诉我们，每个整数都由素因子唯一搭建。
顺着这个思路，一个很自然的想法是：如果有个函数只看「每个整数的结构」，那么只要知道它在素数幂上的取值，是不是就能知道它在所有整数上的取值？**乘性函数（multiplicative function）** 正是把「素数分解 → 全函数值」这条翻译链路形式化的工具。

我们其实已经遇见了两个乘性函数：欧拉函数 $\varphi(n)$ 与因数个数函数 $\tau(n)$。
它们对互素的输入满足 $f(mn) = f(m)f(n)$——这个性质让它们的计算可以「逐素数独立进行」。
本节系统建立乘性函数的理论：定义、例子、以及一条神奇的**狄利克雷卷积**，它能从旧函数造出新函数，并把「乘性」像遗传密码一样传递下去。<span class="marginnote">狄利克雷卷积把数论函数变成某种「群」：有了卷积与单位元，就能谈逆元，就能从 $\zeta$ 与默比乌斯函数的关系导出反演公式。
它将在第三篇《数论函数与 ζ 函数》中成为主角；这里先立好「乘性」这个地基。</span>

## 1 定义与基本例子

**乘性函数（multiplicative function）：** 定义在正整数上的函数 $f$，若对任意互素的正整数 $m, n$ 都有

$$f(mn) = f(m) f(n)$$

则称 $f$ 是乘性函数。
若**不要求互素**，即对任意 $m, n$ 都有 $f(mn) = f(m)f(n)$，则称 $f$ 是**完全乘性**的。

**重点：** 乘性函数的全部秘密在于：只要知道它在素数幂 $p^k$ 上的取值，就能算出它在任意 $n$ 上的值——由 $n = \prod p^{\alpha}$ 得 $f(n) = \prod f(p^{\alpha})$。
这是「算术基本定理」的函数论翻版。

经典例子：

| 函数 | 定义 | 是否乘性 | 关键值 |
| --- | --- | --- | --- |
| $\varphi(n)$ | 与 $n$ 互素的小于 $n$ 的正整数个数 | 乘性 | $\varphi(p^k) = p^k - p^{k-1}$ |
| $\tau(n)$ | 正因数个数 | 乘性 | $\tau(p^k) = k+1$ |
| $\sigma(n)$ | 正因数之和 | 乘性 | $\sigma(p^k) = \frac{p^{k+1}-1}{p-1}$ |
| $\mathrm{Id}(n) = n$ | 恒等 | 完全乘性 | $p^k \mapsto p^k$ |
| $\mu(n)$ | 默比乌斯函数 | 乘性 | $\mu(p^k)$：$k=0$ 时 $1$，$k=1$ 时 $-1$，$k\ge2$ 时 $0$ |

<span class="marginnote">默比乌斯函数 $\mu(n)$ 是数论里最「狡黠」的函数：它只在「无平方因子数」上取 $\pm 1$，有平方因子的位置取 $0$。它看似随意，却是狄利克雷卷积的「幺元」，也是第三篇反演公式的核心。</span>

## 2 如何判断一个函数是乘性的

判断乘性，往往回到定义与算术基本定理。

**例一：$\tau(n)$ 是乘性的。** $n = \prod p_i^{\alpha_i}$ 时 $\tau(n) = \prod(\alpha_i + 1)$。
若 $m, n$ 互素，它们的素因子集合不交，$\tau(mn)$ 的指数乘积等于 $\tau(m)\tau(n)$ 的指数乘积——立即成立。<span class="marginnote">「素因子集合不交」是互素的关键作用：$mn$ 的分解是 $m$ 与 $n$ 分解的「并集」，指数互不干扰，于是「逐素数相乘」的性质自然成立。
这也解释了为什么乘性必须限定互素。</span>

**例二：$\varphi(n)$ 是乘性的。** 用既约剩余系证：$\varphi(m)\varphi(n) = \varphi(mn)$ 当 $\gcd(m,n)=1$。
一个更快的路是公式 $\varphi(n) = n\prod_{p\mid n}(1-\frac1p)$——$m, n$ 互素时素因子集合不交，乘积公式逐因子分解。

**反例提醒：** 函数「因数个数 $+$ 1」不乘性；「$n$ 的素因子个数 $\Omega(n)$」也不乘性（$\Omega(2 \times 3) = 2 \ne \Omega(2) + \Omega(3)$ 若是完全乘性应等于 $1+1=2$，恰好乘性？$\Omega$ 是完全加性的，不乘性）。
判断时务必回到定义逐条验证，别凭直觉。

**辨析｜易错点：**「完全乘性」比「乘性」更强、更罕见。$\varphi, \tau, \sigma, \mu$ 都是乘性但**不是**完全乘性。
例如 $\varphi(4) = 2 \ne \varphi(2)\varphi(2) = 1$。
完全乘性的典型只有 $n \mapsto n^k$ 这种「幂」函数。
见到「乘性」二字，先默认「只对互素成立」。

## 3 狄利克雷卷积

乘性函数之间有一种自然的「乘法」，叫**狄利克雷卷积（Dirichlet convolution）**。

**定义：** 两个数论函数 $f, g$ 的卷积为

$$(f * g)(n) = \sum_{d \mid n} f(d)\, g\!\left(\frac{n}{d}\right)$$

卷积把「对所有因数求和」作为基本运算。
例如 $(\mathrm{Id} * \mu)(n) = \sum_{d \mid n} d\, \mu(n/d)$。

卷积的两条核心性质：

- **封闭性**：若 $f, g$ 都是乘性函数，则 $f * g$ 也是乘性函数——卷积把乘性传递下去。
- **单位元**：$\varepsilon(n) = [n = 1]$（$n=1$ 时 $1$，否则 $0$）满足 $f * \varepsilon = f$，是卷积的单位元。

**重点：** 有了单位元就可以谈**逆元**。最重要的逆元关系是

$$\sum_{d \mid n} \mu(d) = \begin{cases} 1, & n = 1 \\ 0, & n > 1 \end{cases}$$

即 $\mu * \mathbf{1} = \varepsilon$，其中 $\mathbf{1}(n) \equiv 1$ 是常数函数。**默比乌斯函数 $\mu$ 是常数函数 $1$ 的卷积逆元**。
这条关系是下一节默比乌斯反演公式的命脉。<span class="marginnote">「$\mu$ 是 $\mathbf{1}$ 的逆元」一句话浓缩了无数计算：$\varphi = \mathrm{Id} * \mu$（后面会证），$\sigma = \mathrm{Id} * \mathbf{1}$，$\tau = \mathbf{1} * \mathbf{1}$。
卷积分割把数论函数织成一张网，第三篇会在这张网上走得更远。</span>

## 4 公式解析：$\varphi = \mathrm{Id} * \mu$

$$\varphi(n) = \sum_{d \mid n} d\, \mu\!\left(\frac{n}{d}\right)$$

- **第一步，先看 $n = p^k$**：$\varphi(p^k) = p^k - p^{k-1}$。右边 $\sum_{d \mid p^k} d\, \mu(p^k/d)$：$d = p^k$ 时 $\mu(1) = 1$，贡献 $p^k$；$d = p^{k-1}$ 时 $\mu(p) = -1$，贡献 $-p^{k-1}$；其余 $d$ 的 $\mu$ 为 $0$。合计 $p^k - p^{k-1}$ ✓。
- **第二步，乘性传递**：两边都是乘性函数（$\varphi$ 是，右边是 $\mathrm{Id}$ 与 $\mu$ 的卷积也是），所以对任意 $n$ 成立。
- **第三步，验证特例**：$n = 12 = 2^2 \cdot 3$，$\varphi(12) = 4$。右边 $\sum_{d \mid 12} d\,\mu(12/d)$：$d=12$ 时 $\mu(1)=1$，$12$；$d=6$ 时 $\mu(2)=-1$，$-6$；$d=4$ 时 $\mu(3)=-1$，$-4$；$d=2$ 时 $\mu(6)=1$（6 无平方因子），$2$；$d=1$ 时 $\mu(12)=0$。合计 $12-6-4+2 = 4$ ✓。
- **第四步，读出意义**：$\varphi$ 可以「由 $\mu$ 筛出来」——每个因数的贡献被 $\mu$ 加权，非平方因子的贡献相互抵消。这预告了默比乌斯反演：想从「因数和」恢复「原函数」，就用 $\mu$ 做卷积。

**辨析｜易错点：**卷积里的求和是对**所有正因数** $d \mid n$，不是对素数因子。$\mu$ 在含平方因子的自变量上取 $0$，会让很多项消失，但求和本身必须遍历全部因数。
漏项是常见错误。

## 5 例题演练：乘性函数与卷积

**例一：计算 $\varphi$、$\tau$、$\sigma$。** 对 $n = 72 = 2^3 \times 3^2$：
- $\varphi(72) = 72(1-\frac12)(1-\frac13) = 72 \times \frac12 \times \frac23 = 24$；
- $\tau(72) = (3+1)(2+1) = 12$；
- $\sigma(72) = \frac{2^4-1}{2-1} \cdot \frac{3^3-1}{3-1} = 15 \times 13 = 195$。

验算 $\tau(72) = 12$：正因数 $1,2,3,4,6,8,9,12,18,24,36,72$ 恰好 $12$ 个 ✓。<span class="marginnote">$\sigma$ 的公式 $\frac{p^{\alpha+1}-1}{p-1}$ 是等比数列求和：$1 + p + p^2 + \cdots + p^{\alpha}$。
乘性函数的所有公式，本质都是「把素数幂上的等比求和乘起来」。</span>

**例二：判别乘性。** $f(n) = n^2$ 是乘性吗？$(mn)^2 = m^2 n^2$，对任意 $m, n$（不要求互素）成立，是完全乘性。$g(n) = n + 1$ 呢？$g(2) = 3$，$g(3) = 4$，$g(6) = 7 \ne 3 \times 4 = 12$，不乘性。

**例三：卷积计算。** 求 $(\mu * \mathbf{1})(10)$。$\sum_{d \mid 10} \mu(d) \cdot 1 = \mu(1) + \mu(2) + \mu(5) + \mu(10) = 1 - 1 - 1 + 1 = 0$。
这验证了「$\mu * \mathbf{1} = \varepsilon$」在 $n = 10$ 上的表现（$n > 1$ 时为 $0$）。

**例四：$\varphi = \mathrm{Id} * \mu$ 的验算。** 求 $\sum_{d \mid 10} d \cdot \mu(10/d)$：$d = 1$ 时 $\mu(10) = 1$（$10$ 无平方因子，偶个素因子），贡献 $1$；$d = 2$ 时 $\mu(5) = -1$，贡献 $-2$；$d = 5$ 时 $\mu(2) = -1$，贡献 $-5$；$d = 10$ 时 $\mu(1) = 1$，贡献 $10$。
合计 $1 - 2 - 5 + 10 = 4 = \varphi(10)$ ✓。

**辨析｜易错点：**计算卷积时 $\mu(n/d)$ 里的 $n/d$ 是「$n$ 除以 $d$ 的商」，不是「$n$ 减去 $d$」。$d$ 取遍 $n$ 的所有正因数，$n/d$ 也随之取遍所有正因数（反向）。
把「整除」看成「减法」是卷积计算里最荒诞也最常见的错误。

## 6 小结

- **乘性函数**：$\gcd(m,n)=1 \Rightarrow f(mn) = f(m)f(n)$；完全乘性不要求互素。
- 乘性函数由其在素数幂上的取值完全决定：$f(n) = \prod f(p^{\alpha})$。
- 经典乘性函数：$\varphi, \tau, \sigma, \mu$ 以及恒等、常数、幂函数。
- **狄利克雷卷积** $(f*g)(n) = \sum_{d \mid n} f(d)g(n/d)$：保持乘性、有单位元 $\varepsilon$、$\mu$ 是 $\mathbf{1}$ 的逆元。
- $\varphi = \mathrm{Id} * \mu$ 是「用 $\mu$ 筛 $\varphi$」的典范，通向默比乌斯反演。
