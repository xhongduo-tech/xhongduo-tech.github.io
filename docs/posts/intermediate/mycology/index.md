# 真菌学

真菌学系统研究真菌这一与动物界、植物界并立的独立真核生物类群，涵盖其形态结构、生长发育、繁殖方式、分类与系统演化、生理遗传及生态应用，是连接微生物学、植物学与医学、食品工业和农林实践的桥梁学科。对标权威教材体系，按章节逐节写成博文，学完一个学科 = 写完该学科权威教材对应的全部博文。

## 对标教材

- C. J. Alexopoulos, C. W. Mims & M. Blackwell, *Introductory Mycology* (4th ed., Wiley)
- 邢来君、李明春《普通真菌学》（第2版，高等教育出版社）
