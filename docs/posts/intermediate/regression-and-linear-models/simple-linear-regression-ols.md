## 为什么从最小二乘开始

上一课我们把统计关系写成了带误差的模型 $y = \beta_0 + \beta_1 x + \varepsilon$，但模型里的 $\beta_0$ 与 $\beta_1$ 是未知的总体参数。这一课回答最关键的问题：**给出一堆样本点 $(x_i, y_i)$，如何画出一条「最好的」直线？** 答案是高斯在 1801 年前后完善的最小二乘法（method of least squares）——它不要求任何概率假设就能给出直线的计算公式，是回归分析全部技术的地基，也是机器学习里所有「用误差函数拟合参数」方法的思想原型。

## 1 模型假设：简单线性回归的框架

**简单线性回归（simple linear regression）** 指只有一个自变量 $x$、且 $y$ 与 $x$ 的关系近似为直线的模型。对 $n$ 组样本 $(x_1,y_1),\ldots,(x_n,y_n)$，模型写成：

$$
y_i = \beta_0 + \beta_1 x_i + \varepsilon_i, \qquad i = 1, 2, \ldots, n
$$

对误差 $\varepsilon_i$ 的基本假设有四项，它们决定了后续估计与检验能否成立：

- **零均值**：$E(\varepsilon_i) = 0$，即误差平均起来不偏不倚；
- **等方差**：$\mathrm{Var}(\varepsilon_i) = \sigma^2$ 对所有 $i$ 相同；
- **不相关**：$\mathrm{Cov}(\varepsilon_i, \varepsilon_j) = 0$ 对 $i \neq j$；
- **（推断时）正态性**：$\varepsilon_i \sim N(0, \sigma^2)$。

<span class="marginnote">$x_i$ 在这里被视为<strong>固定已知</strong>（实验设计值）而非随机变量；若 $x$ 本身随机，则模型解读为「给定 $x$ 下的条件模型」，公式不变。</span>

注意：我们并没有假设 $x$ 是非随机的，也没有要求误差一定正态——最小二乘的**计算**不依赖正态性，正态性只用于检验与区间估计。

## 2 最小二乘原理：把「拟合得好」翻译成数学

什么算「最好的直线」？直觉是让直线尽量靠近所有点。每个点 $(x_i,y_i)$ 到直线上对应位置的竖直距离叫作**残差（residual）**：

$$
e_i = y_i - \hat{y}_i = y_i - (\hat{\beta}_0 + \hat{\beta}_1 x_i)
$$

**最小二乘原则**：选择 $\hat{\beta}_0, \hat{\beta}_1$，使残差平方和（sum of squared errors, SSE）最小：

$$
\text{SSE} = \sum_{i=1}^{n} e_i^2 = \sum_{i=1}^{n} (y_i - \hat{\beta}_0 - \hat{\beta}_1 x_i)^2 \longrightarrow \min
$$

<span class="marginnote">为什么用「平方」而不是绝对值？平方是光滑可导的函数，求导就能解出显式公式；且平方对大残差的惩罚更重，避免个别离群点主导拟合。缺点是它对离群点过于敏感——这是第 3 篇讨论稳健方法的伏笔。</span>

因为 SSE 是 $\hat{\beta}_0, \hat{\beta}_1$ 的**二次函数**（开口向上的抛物面），极小值存在且唯一。对 $\hat{\beta}_0$ 与 $\hat{\beta}_1$ 分别求偏导并令其为零，得到**正规方程（normal equations）**。

## 3 公式解析：最小二乘估计量的显式公式

解正规方程得到两个估计量的闭式解：

$$
\hat{\beta}_1 = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2}, \qquad
\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}
$$

逐步拆解：

- **$\bar{x}$ 与 $\bar{y}$**：自变量与因变量的样本均值。所有点都平移到以均值点为原点后，斜率只由「点相对均值的位置」决定。
- **分子 $S_{xy} = \sum (x_i - \bar{x})(y_i - \bar{y})$**：$x$ 与 $y$ 的**协方差型交叉和**。当 $x$ 偏离均值的同时 $y$ 也同向偏离（分子为正），说明 $x$ 大时 $y$ 倾向大，斜率为正；反向则斜率为负。它捕捉的是 $x$、$y$ 共同变动的程度。
- **分母 $S_{xx} = \sum (x_i - \bar{x})^2$**：$x$ 的**离差平方和**，衡量 $x$ 的取值有多分散。分母越大，$\hat{\beta}_1$ 的方差越小——$x$ 铺得越开，斜率估得越准。
- **$\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}$**：截距由「均值点必在直线上」这一性质决定——最小二乘线总是穿过点 $(\bar{x}, \bar{y})$。

**重点结论**：估计量 $\hat{\beta}_1$ 是两个「$x$ 驱动的加权平均」，分子把 $y$ 的信息按 $x$ 离均值的远近加权，分母负责归一化。这条公式在后面多元回归的矩阵版 $\hat{\boldsymbol{\beta}} = (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\mathbf{y}$ 中是同一个思想的推广。

## 4 三个平方和与方差估计

拟合出一条直线后，$y$ 的总变动可分解为「被直线解释的部分」与「残留下来的部分」：

- **总平方和** $\mathrm{SST} = \sum (y_i - \bar{y})^2$：$y$ 相对其均值的总离差平方和；
- **回归平方和** $\mathrm{SSR} = \sum (\hat{y}_i - \bar{y})^2$：直线预测值相对均值的离差，即被模型解释的部分；
- **残差平方和** $\mathrm{SSE} = \sum (y_i - \hat{y}_i)^2$：未被解释的部分。

三者满足**平方和分解** $\mathrm{SST} = \mathrm{SSR} + \mathrm{SSE}$。<span class="marginnote">这一分解是后续 $R^2$、$F$ 检验与方差分析表的共同母体；「总变动 = 可解释 + 不可解释」的思想会原样复现于 ANOVA。</span>

由 SSE 得到误差方差 $\sigma^2$ 的无偏估计：

$$
\hat{\sigma}^2 = \frac{\text{SSE}}{n - 2}
$$

分母是 $n - 2$ 而非 $n$：因为我们已用数据估了两个参数（$\beta_0$ 与 $\beta_1$），自由度减少 2。**辨析｜易错点：** 初学者常误写成 $n$。用 $n$ 会系统低估噪声方差，导致后续置信区间过窄、检验过于乐观。

## 5 为什么不是「竖直距离最短」与「垂直距离」

最小二乘最小化的是**竖直**残差 $y_i - \hat{y}_i$。一个自然的问题：为什么不最小化点到直线的**垂直距离**（欧氏距离）？

- 竖直距离对应「给定 $x$，预测 $y$」的误差——这正是回归的预测任务，把误差归因于 $y$ 方向的噪声；
- 垂直距离把 $x$ 与 $y$ 的误差同等对待，那是另一种方法（总最小二乘 / 正交回归），用于 $x$ 与 $y$ 都有测量误差的场合；
- 若交换 $x$ 与 $y$ 的角色重新回归，两条线一般不重合；竖直距离框架下「回归 $y$ 对 $x$」与「回归 $x$ 对 $y$」是两回事。<span class="marginnote">这一点常让人困惑：散点图上直觉「对称」的直线其实不在最小二乘意义下最优。对称的做法是第 4 篇提到的正交回归，其斜率是主成分方向。</span>

## 6 计算示例：五步跑出回归线

设 5 个样本点：$(1,3), (2,5), (3,4), (4,7), (5,6)$。按公式计算：

$\bar{x} = 3$，$\bar{y} = 5$；
$S_{xx} = (1-3)^2+(2-3)^2+(3-3)^2+(4-3)^2+(5-3)^2 = 10$；
- $S_{xy} = (1-3)(3-5)+(2-3)(5-5)+(3-3)(4-5)+(4-3)(7-5)+(5-3)(6-5) = 8$；
- $\hat{\beta}_1 = 8/10 = 0.8$，$\hat{\beta}_0 = 5 - 0.8 \times 3 = 2.6$。

得回归线 $\hat{y} = 2.6 + 0.8x$：$x$ 每增 1，$y$ 平均增加 0.8。验证：直线穿过 $(\bar{x},\bar{y}) = (3,5)$，且各点残差为 $-0.4, 0.8, -1.0, 1.2, -0.6$（和为 0），平方和 SSE $= 0.16+0.64+1.00+1.44+0.36 = 3.6$。<span class="marginnote">手算一遍比读十遍公式更有用：你会亲眼看到「均值点必在线上」「残差之和必为零」这两条最小二乘的内在性质。</span>

## 7 小结

- 简单线性回归模型 $y_i = \beta_0 + \beta_1 x_i + \varepsilon_i$，误差假设为**零均值、等方差、不相关**（推断时再加正态）。
- **最小二乘原则**：最小化残差平方和 SSE；解正规方程得 $\hat{\beta}_1 = S_{xy}/S_{xx}$，$\hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x}$。
- 最小二乘线必过均值点 $(\bar{x},\bar{y})$，且残差之和为零。
- 平方和分解 $\mathrm{SST} = \mathrm{SSR} + \mathrm{SSE}$；误差方差的无偏估计 $\hat{\sigma}^2 = \mathrm{SSE}/(n-2)$。
- 最小化的是**竖直残差**，与交换 $x,y$ 的回归线不同。
