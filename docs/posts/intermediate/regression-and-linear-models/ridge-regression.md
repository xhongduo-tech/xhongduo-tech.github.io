## 为什么从岭回归开始

第 2 篇的 Gauss-Markov 定理承诺 OLS 在「线性无偏」类中最优，但当设计矩阵病态（共线性、高维）、或 $p$ 接近 $n$ 时，无偏的代价是方差爆炸——系数巨大、符号乱飞、预测翻车。**岭回归（ridge regression）** 主动放弃无偏性，用一个小的惩罚把系数向零压缩，换取方差的大幅收敛。它是「有偏估计」家族的旗手，也是 LASSO、弹性网与现代机器学习正则化的思想源头。本课讲透岭回归的动机、解、岭迹图与选择惩罚参数的方法。

## 1 病态问题：为什么 OLS 会「飘」

回顾 OLS 解 $\hat{\boldsymbol{\beta}} = (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\mathbf{y}$。当 $\mathbf{X}'\mathbf{X}$ 接近奇异（特征值接近 0），其逆的元素会**爆炸**——$\hat{\boldsymbol{\beta}}$ 的分量变得极大且极不稳定。从方差公式看：

$$
\mathrm{Var}(\hat{\boldsymbol{\beta}}) = \sigma^2 \sum_{j=1}^{p} \frac{1}{\lambda_j} \mathbf{v}_j\mathbf{v}_j'
$$

其中 $\lambda_j$、$\mathbf{v}_j$ 是 $\mathbf{X}'\mathbf{X}$ 的特征值与特征向量。**$\lambda_j$ 越小，对应方向上的方差越大**——病态方向上的系数几乎由噪声决定。<span class="marginnote">几何直觉：数据在某些方向「几乎没铺开」，这些方向的斜率就无从谈起。OLS 对这些方向给出「巨大的、不稳定的」答案——就像用一把失衡的秤称重。</span>

## 2 岭回归的估计：给对角线加一点盐

**岭回归** 在最小二乘目标上加一个系数平方的惩罚：

$$
\hat{\boldsymbol{\beta}}_{\text{ridge}} = \arg\min_{\boldsymbol{\beta}} \Big\{ \sum_{i=1}^{n}(y_i - \mathbf{x}_i'\boldsymbol{\beta})^2 + k\sum_{j=1}^{p}\beta_j^2 \Big\}, \qquad k \ge 0
$$

解为：

$$
\hat{\boldsymbol{\beta}}_{\text{ridge}} = (\mathbf{X}'\mathbf{X} + k\mathbf{I})^{-1}\mathbf{X}'\mathbf{y}
$$

**公式解析：$k\mathbf{I}$ 的魔力**——逐项拆解：

- **$k \ge 0$**：岭参数（惩罚强度）。$k = 0$ 时退化为 OLS；
- **$\mathbf{X}'\mathbf{X} + k\mathbf{I}$**：给 $\mathbf{X}'\mathbf{X}$ 的对角元素统一加上 $k$，把接近 0 的特征值 $\lambda_j$ 抬升到 $\lambda_j + k$，**矩阵不再病态**，求逆稳定；
- **压缩效应**：$\hat{\beta}_j^{\text{ridge}} = \frac{\lambda_j}{\lambda_j + k} \cdot \hat{\beta}_j^{\text{OLS}}$（在特征向量坐标系下）——每个方向上的估计被**按比例收缩**，小特征值方向收缩最狠；
- **偏差与方差**：$k$ 增大 → 偏差增大、方差减小。总误差 MSE = 方差 + 偏差² 在某个 $k$ 处取最小——这就是「有偏但更准」。

**重点结论**：岭回归不删变量，只是把系数**整体往 0 收缩**。它稳定了病态设计下的估计，让预测误差（尤其是病态方向）大幅下降。注意惩罚只作用于斜率，不作用于截距（截距不收缩）。

## 3 岭迹图与岭参数的选择

怎么选 $k$？经典工具是**岭迹图（ridge trace）**：横轴为 $k$，纵轴为各 $\hat{\beta}_j(k)$，画出系数随 $k$ 的变化轨迹。

- $k$ 很小处：系数如脱缰野马（OLS 的病态表现）；
- $k$ 增大：系数逐渐向 0 靠拢并趋于稳定；
- 选择原则：找一个**系数已趋稳定、又不至于收缩过头**的 $k$——通常在曲线「刚变平」的地方。<span class="marginnote">岭迹图的经典用法是「看稳定」：病态方向的系数在 OLS 处大起大落，随 $k$ 增加迅速稳定到合理区间。选择让整体系数「安分」的最小 $k$，兼顾偏差与方差。</span>

更客观的选择：**交叉验证（CV）**——把数据分折，对每个候选 $k$ 计算验证误差，选误差最小的 $k$。这是现代实践的标准做法（第 4 篇《交叉验证》详述）。

**辨析｜易错点：** 岭回归前必须先**标准化所有自变量**（中心化 + 尺度化）。因为惩罚 $\sum\beta_j^2$ 对变量的尺度敏感——量纲大的变量会被惩罚得更狠。不标准化，岭回归结果毫无意义。

## 4 核心对比：OLS 与岭回归

| 维度 | OLS | 岭回归 |
| --- | --- | --- |
| 目标 | 最小化 SSE | 最小化 SSE + $k\sum\beta_j^2$ |
| 偏差 | 无 | 有（$k>0$） |
| 方差 | 病态时爆炸 | 被 $k$ 压制 |
| 解 | $(\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\mathbf{y}$ | $(\mathbf{X}'\mathbf{X}+k\mathbf{I})^{-1}\mathbf{X}'\mathbf{y}$ |
| 变量选择 | 不删 | 不删（只收缩） |
| 适用 | 良态设计 | 病态 / 高维 / 共线 |

<span class="marginnote">一句话：OLS 是「宁折不弯」的偏执，岭回归是「懂得退让」的务实。当数据支撑不住 $p$ 个自由方向时，收缩是更聪明的选择——这在机器学习里演化为「正则化 = 给复杂度付费」的普适法则。</span>

## 5 从岭回归到 LASSO 与弹性网

岭回归用 $L_2$ 惩罚（$\sum\beta_j^2$）；把它换成 $L_1$ 惩罚，就得到 **LASSO**：

$$
\hat{\boldsymbol{\beta}}_{\text{lasso}} = \arg\min \Big\{ \sum_{i=1}^{n}(y_i - \mathbf{x}_i'\boldsymbol{\beta})^2 + \lambda\sum_{j=1}^{p}|\beta_j| \Big\}
$$

两者的几何差别带来质的差别：<span class="marginnote">$L_2$ 惩罚的约束域是圆角（球），最优解很少落在坐标轴上——系数被压缩但不为零；$L_1$ 惩罚的约束域是菱形（尖角），最优解容易撞在尖角上——<strong>系数被精确置零</strong>。这就是「LASSO 能做变量选择，岭回归只做收缩」的几何原因。</span>

**弹性网（elastic net）** 两者结合：$\lambda_1\sum|\beta_j| + \lambda_2\sum\beta_j^2$，兼得选择与群组稳定。<span class="marginnote">这三个惩罚估计构成现代统计学习的「正则化三兄弟」，也是「从极限到大模型」路线中机器学习课程的前哨。它们的共同祖先，就是本节那个小小的 $k\mathbf{I}$。</span>

## 6 岭回归的实践流程

1. **标准化**所有自变量（中心化 + 缩放）；
2. 设定 $k$ 的候选网格（常用对数网格）；
3. 对每个 $k$ 拟合岭回归，记录验证误差（CV）或看岭迹图；
4. 选最优 $k$，得到最终估计；
5. **解释注意**：系数是「收缩后」的，不能按 OLS 的「单位效应」直读；预测则直接用。

**辨析｜易错点：** 岭回归系数的标准误与检验不标准——惩罚引入了偏差，经典的 $t/F$ 检验不再有效。若需要推断，用 bootstrap 或改用其它框架（如惩罚似然的推断）。以预测为主时则无需纠结。

## 7 岭回归的数值演示

用一个极小的二维例子感受「收缩」。设 $n=2$ 个观测、$p=1$ 个自变量：$(x,y) = (1, 2), (2, 4)$。无截距模型 $y = \beta x$。

OLS：$\hat\beta = \sum x_i y_i / \sum x_i^2 = (2+8)/(1+4) = 2.0$；
岭回归（$k=1$）：$\hat\beta_{\text{ridge}} = \sum x_i y_i / (\sum x_i^2 + k) = 10/(5+1) \approx 1.667$；
- 岭回归（$k=4$）：$\hat\beta_{\text{ridge}} = 10/(5+4) \approx 1.111$。

可见 $k$ 越大，系数向 0 收缩越多。在病态设计中，这个收缩能把「被噪声放大的巨大系数」拉回合理区间。<span class="marginnote">「$k$ 就是给分母加盐」：$\sum x_i^2$ 太小（病态）时求倒数会爆炸，加上 $k$ 后分母被托住，商不再失控。这是岭回归全部技术的核心直觉。</span>

**辨析｜易错点：** 注意岭回归系数的「单位」——因为惩罚项把系数压向 0，$\hat\beta_{\text{ridge}}$ 与 OLS 的 $\hat\beta$ 直接比较会显得「缩小了」，这是**设计如此**而非估计偏差；预测时统一用收缩后的系数即可。

## 8 小结

- 病态设计下 OLS 方差爆炸：$\mathrm{Var}(\hat{\boldsymbol{\beta}})$ 沿小特征值方向趋于无穷。
- **岭回归**：最小化 SSE + $k\sum\beta_j^2$，解 $(\mathbf{X}'\mathbf{X}+k\mathbf{I})^{-1}\mathbf{X}'\mathbf{y}$，$k=0$ 时退化为 OLS。
- 系数沿特征方向按 $\lambda_j/(\lambda_j+k)$ 收缩，小方向收缩最狠；**换偏差、降方差**。
- 选 $k$：岭迹图看稳定，或交叉验证取最小预测误差。
- **必须标准化**自变量后再做岭回归。
- 岭回归（$L_2$）→ LASSO（$L_1$，可置零）→ 弹性网（$L_1+L_2$）：正则化家族一脉相承。
- 推断注意：惩罚引入偏差，经典 $t/F$ 检验失效；要推断用 bootstrap。
