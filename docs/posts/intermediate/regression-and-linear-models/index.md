# 回归分析与线性模型

回归分析与线性模型是统计学最核心的基础课程，研究变量间的统计依赖关系，既是传统统计推断的延伸，也是机器学习预测建模的基石。本专题从简单线性回归出发，系统覆盖多元回归、估计理论、模型诊断、变量选择直至方差分析，建立完整的线性建模体系。

## 对标教材

- Douglas C. Montgomery, Elizabeth A. Peck & G. Geoffrey Vining, "Introduction to Linear Regression Analysis" (5th ed., Wiley, 2012)
- 王松桂、杨虎, 《线性模型引论》(科学出版社, 2004)
- George A.F. Seber & Alan J. Lee, "Linear Regression Analysis" (2nd ed., Wiley, 2003)
