## 为什么从残差分析开始

前两篇讲完了「怎么把模型建出来、怎么推断」。但有一句统计界的格言：**所有模型都是错的，但有些是有用的**。模型建好后，最重要的问题是「它错在哪、错得多严重」。残差（residual）$e_i = y_i - \hat{y}_i$ 是数据中模型未能解释的部分，是检验模型假设的天然探针。本课系统讲授残差分析的图形工具与检验方法，回答四个关键问题：模型形式对吗？误差正态吗？方差恒定吗？有没有异常值？——这套诊断程序是任何严肃回归分析的必经关卡。

## 1 残差的定义与两种变体

普通残差 $e_i = y_i - \hat{y}_i$ 直接衡量预测误差。但它有两个缺陷：方差各观测不同，且观测之间相关。于是引入两种标准化残差：

**标准化残差（standardized residual）**：

$$
d_i = \frac{e_i}{\hat{\sigma}} = \frac{y_i - \hat{y}_i}{\sqrt{\mathrm{SSE}/(n-p-1)}}
$$

**学生化残差（studentized residual）**：

$$
r_i = \frac{e_i}{\hat{\sigma}\sqrt{1 - h_{ii}}}
$$

其中 $h_{ii}$ 是帽子矩阵对角元（杠杆值）。<span class="marginnote">$r_i$ 的分母含 $\sqrt{1-h_{ii}}$，把「该观测自身杠杆导致的小残差」修正掉——高杠杆点即使真实偏差很大，普通残差也可能很小。学生化残差是更公平的「哨兵」。</span>

**辨析｜易错点：** 普通残差 $e_i$ 的方差并不恒定（与 $h_{ii}$ 有关），直接用 $\hat{\sigma}$ 标准化并不彻底；学生化残差才能在不同观测间公平比较。诊断时应优先看 $r_i$。

## 2 四张残差图：模型假设的照妖镜

残差分析的核心是**看图**，四张图覆盖四个假设：

**图 1：残差对拟合值（$e_i$ vs $\hat{y}_i$）**——最核心的一张。
随机散布在零线附近 → 模型形式合理、方差恒定；
喇叭形（残差随 $\hat{y}$ 增大而扩散）→ **异方差**；
- 系统性弯曲 → **模型形式错误**（漏了非线性项）。

**图 2：残差的正态概率图（Q-Q plot）**——检验正态性。
- 点沿对角线排布 → 近似正态；
- 两端上翘（重尾）或 S 形 → 偏离正态。

**图 3：残差对时间（或观测序）**——检验相关性。
- 呈现「跑动」模式（一串正、一串负）→ **自相关**；
- 时间序列数据尤其要画这张。

**图 4：残差对某个未入模的变量**——检查是否漏变量。
- 出现趋势 → 该变量应纳入模型。<span class="marginnote">四张图的共同哲学：残差里若有「结构」（形状、趋势、模式），就说明模型漏掉了什么。理想残差应该是「一堆纯噪声」，没有结构可看。</span>

## 3 残差分析的数值检验

图有主观性，配数值检验更稳。三个常用检验：

**正态性**——Shapiro–Wilk 检验或 Kolmogorov–Smirnov 检验，检验 $H_0$：残差来自正态分布。$p$ 值小则怀疑正态性。

**异方差**——Breusch–Pagan 检验：先把 $e_i^2$ 对自变量回归，检验该回归是否显著。<span class="marginnote">Breusch–Pagan 的思想很妙：如果方差随自变量变化，那么「残差平方」就应该能被自变量解释。检验「$e_i^2 \sim x$ 是否有趋势」就间接检验了方差是否恒定。</span>

**自相关**——Durbin–Watson 检验：统计量 $DW = \sum(e_i - e_{i-1})^2/\sum e_i^2$，取值 0–4，接近 2 表示无自相关，接近 0 表示正自相关。<span class="marginnote">$DW$ 的直觉：相邻残差如果同号（正自相关），它们的差就小，$DW$ 就小。反之反号频繁，$DW$ 接近 4。这比眼盯散点图更客观。</span>

**辨析｜易错点：** 数值检验对小样本功效不足、对大样本又过于敏感（微小偏离也显著）。正确姿势是**图形 + 检验并用**，以图为先，检验佐证——教科书反复强调这一点。

## 4 公式解析：学生化残差的方差结构

理解 $r_i$ 的分母需要回到帽子矩阵。残差向量 $\mathbf{e} = (\mathbf{I}-\mathbf{H})\mathbf{y}$，其协方差为：

$$
\mathrm{Var}(\mathbf{e}) = \sigma^2(\mathbf{I} - \mathbf{H})
$$

逐步拆解：

- **$\mathbf{H}$ 的对称幂等性**：$\mathbf{H} = \mathbf{H}' = \mathbf{H}^2$，于是 $(\mathbf{I}-\mathbf{H})$ 也是幂等阵；
- **单个残差的方差**：$\mathrm{Var}(e_i) = \sigma^2(1 - h_{ii})$——残差方差**小于** $\sigma^2$，且杠杆越高、方差越小；
- **直觉**：高杠杆点「把回归线拉向自己」，所以它的残差天然偏小、方差偏小；若直接与普通残差比较，会低估其异常程度；
- **修正**：$r_i = e_i/\sqrt{\hat{\sigma}^2(1-h_{ii})}$ 用该观测自己的方差标准化，使所有 $r_i$ 方差接近 1，可公平比较。

**重点结论**：$h_{ii}$ 不仅关乎影响力（第 3 篇杠杆点），还关乎残差本身的可比性——它是诊断分析中反复出现的「枢纽量」。

## 5 残差分析的完整流程

一次规范的模型充分性检查按以下顺序执行：

1. **先画残差 vs 拟合值**：最优先，形态问题一眼见；
2. **画正态 Q-Q 图**：评估正态性，影响后续检验有效性；
3. **查杠杆与异常值**：标记 $|r_i| > 2$（或 3）的观测与高杠杆点；
4. **跑关键数值检验**：异方差、自相关按需；
5. **若发现问题，回模型修正**：变换变量（第 3 篇）、加项、加权重（GLS/WLS）——诊断的价值在于**指导修模**，而非仅仅标记问题。

<span class="marginnote">诊断是一条闭环：建模 → 诊断 → 修正 → 再诊断。许多人把诊断当成「跑完回归后走个过场」，恰恰忽略了它才是决定模型可信度的关卡。跳过诊断的回归结论，像没体检的健康证明。</span>

## 6 残差诊断的数值示例

继续用 5 个样本点的例子：$\hat{y} = 2.6 + 0.8x$，残差 $e = (-0.4, 0.8, -1.0, 1.2, -0.6)$，$\hat\sigma \approx 1.095$。

先算各点的杠杆值。$\mathbf{H} = \mathbf{X}(\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'$，对第 $i$ 个点 $h_{ii} = (1/n) + (x_i-\bar{x})^2/S_{xx}$。以第 5 个点（$x=5$）为例：$h_{55} = 1/5 + (5-3)^2/10 = 0.2 + 0.4 = 0.6$——样本边缘点，杠杆偏高。平均杠杆为 $(p+1)/n = 2/5 = 0.4$，$2\times 0.4 = 0.8$，$h_{55} = 0.6 \lt  0.8$，尚不算高杠杆。

再看学生化残差（用第 1 个点 $x=1$）：$h_{11} = 0.2 + (1-3)^2/10 = 0.6$，于是 $r_1 = e_1/\sqrt{\hat\sigma^2(1-h_{11})} = -0.4/\sqrt{1.2\times 0.4} \approx -0.4/0.693 \approx -0.577$。$|r_1| \ll 2$，完全正常。

这个手算过程演示了诊断的「单元操作」：先算杠杆、再算学生化残差、最后对照阈值。<span class="marginnote">注意边缘点的杠杆 $h_{ii}$ 与中心点相同（这里恰好都是 0.6），因为 $n=5$ 太小、$x$ 取值均匀；真正的高杠杆通常出现在「多数点挤在一边、个别点单独在另一边」时。</span>

## 7 小结

- 残差 $e_i = y_i - \hat{y}_i$ 是模型未解释部分；**学生化残差** $r_i = e_i/\sqrt{\hat{\sigma}^2(1-h_{ii})}$ 便于公平比较。
- 四张残差图：vs 拟合值（形式/异方差）、Q-Q 图（正态）、vs 时序（自相关）、vs 漏变量。
- 数值检验：Shapiro–Wilk（正态）、Breusch–Pagan（异方差）、Durbin–Watson（自相关）。
- $\mathrm{Var}(e_i) = \sigma^2(1-h_{ii})$：杠杆高的残差方差小，标准化时必须修正。
- 诊断的目的是**指导修模**，图形为主、检验为辅，形成「建模—诊断—修正」闭环。
