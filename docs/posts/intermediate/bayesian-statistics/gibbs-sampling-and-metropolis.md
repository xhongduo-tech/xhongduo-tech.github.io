## 为什么从「两种走法」开始

上一节我们确立了 MCMC 的目标：造一条平稳分布 = 后验的链。这一节回答工程问题：**链具体怎么走？** 两条主流路线——**Metropolis(-Hastings) 算法**与 **Gibbs 抽样**——对应两种不同的「步法」。

Metropolis 像一个投石问路的探险者：从当前位置随机猜一个候选点，按接受概率决定「去」还是「留」。Gibbs 则像一个分块推进的装配线：模型有几个参数，就逐个参数、在**条件分布**里更新。理解这两者的设计思想与接受/拒绝机制，是之后读懂 Stan、PyMC 诊断输出的基础，也是给《分层模型》一节写条件更新代码的前提。<span class="marginnote">Metropolis 算法 1953 年出自洛斯阿拉莫斯国家实验室，是「原子弹物理」的副产物——用它模拟中子扩散。哈斯廷斯 1970 年把接受概率推广成非对称提议分布，就是我们今天用的 Metropolis-Hastings 形式。</span>

## 1 Metropolis 算法：猜一猜，再决定

**Metropolis 算法**用于目标分布 $p(\theta)$（比如后验核，只需计算到常数倍）。算法只有四步：

1. 从初始点 $\theta^{(0)}$ 出发；
2. 在**对称提议分布** $J(\theta^* \mid \theta^{(s)})$ 里抽一个候选 $\theta^*$，常见取 $\theta^* \sim \mathrm{N}(\theta^{(s)}, \sigma^2)$（随机游走提议）；
3. 计算**接受概率**
$$\alpha = \min\left(1,\ \frac{p(\theta^*)}{p(\theta^{(s)})}\right)$$
4. 掷均匀随机数 $u$，若 $u < \alpha$ 则移动到 $\theta^{(s+1)} = \theta^*$，否则原地不动 $\theta^{(s+1)} = \theta^{(s)}$。

**为什么这个接受概率能让链平稳分布等于 $p$？** 关键在**细致平衡（detailed balance）**条件：对任意两个状态 $a, b$，转移概率 $T$ 要满足 $p(a)T(a \to b) = p(b)T(b \to a)$。对称提议下，$J(b\mid a)=J(a\mid b)$，于是

$$p(a)\,T(a\to b) = p(a)J(b\mid a)\min\!\left(1,\tfrac{p(b)}{p(a)}\right) = \min(p(a)J, p(b)J)$$

与 $p(b)T(b \to a)$ 对称相等。细致平衡推出 $p$ 是平稳分布。<span class="marginnote">细致平衡是一把「验算钥匙」：只要验证链的转移核满足它，就立刻知道目标分布是链的平稳分布，不用解矩阵方程。它是 MCMC 设计里最常用的构造性证明工具。</span>

**Metropolis-Hastings（MH）推广**：当提议分布不对称（如 $J(\theta^*\mid\theta) \ne J(\theta\mid\theta^*)$）时，接受概率修正为

$$\alpha = \min\left(1,\ \frac{p(\theta^*)\,J(\theta^{(s)} \mid \theta^*)}{p(\theta^{(s)})\,J(\theta^* \mid \theta^{(s)})}\right)$$

分子分母多出的比值称为 **Hastings 修正**，把「提议方向偏差」抵消掉。

## 2 Gibbs 抽样：在条件分布里轮流走

分层与多参数模型里，联合后验 $p(\theta_1, \theta_2, \ldots, \theta_k \mid y)$ 很难直接采样，但每个参数的**满条件分布（full conditional）**——给定其余所有参数和数据的分布——常常非常简单（正是共轭配方的形状）。Gibbs 抽样利用这一点：

**Gibbs 抽样**：在每一轮迭代里，依次从每个参数的满条件分布中采样并更新：

$$\theta_1^{(s+1)} \sim p(\theta_1 \mid \theta_2^{(s)}, \ldots, \theta_k^{(s)}, y), \quad \theta_2^{(s+1)} \sim p(\theta_2 \mid \theta_1^{(s+1)}, \theta_3^{(s)}, \ldots, y), \ldots$$

**为什么可用？** 每一步采样都服从**当前条件下的条件分布**，而条件分布是后验在「切片」上的投影；当所有参数都被更新一遍后，链的平稳分布正是联合后验——这是标准马尔可夫链理论的结果，不依赖接受/拒绝。<span class="marginnote">Gibbs 抽样由 Geman 与 Geman 1984 年在图像处理（吉布斯随机场）中命名，Gelfand 与 Smith 1990 年把它引入贝叶斯统计并引爆计算热潮。它本质上是「分块坐标更新」的随机化版本。</span>

**与 Metropolis 的对照**：

| 算法 | 每一步做什么 | 优点 | 代价 |
| --- | --- | --- | --- |
| Metropolis(-Hastings) | 猜候选 + 接受/拒绝 | 通用，几乎不限分布 | 需调步长；接受率要监视 |
| Gibbs | 在满条件分布里直接采 | 无需调参、无拒绝 | 满条件分布必须能采样；参数强相关时走得慢 |

## 3 公式解析：Gibbs 的满条件分布从哪来

Gibbs 的用法是「先写条件分布，再逐个采」。以两参数正态-逆伽马模型为例，$y_i \mid \mu, \sigma^2 \overset{\text{iid}}{\sim} \mathrm{N}(\mu, \sigma^2)$，先验 $\mu \sim \mathrm{N}(\mu_0, \sigma_0^2)$、$\sigma^2 \sim \mathrm{Inv-Gamma}(a, b)$。联合后验核：

$$
p(\mu, \sigma^2 \mid y) \propto (\sigma^2)^{-n/2} \exp\!\left(-\frac{\sum(y_i-\mu)^2}{2\sigma^2}\right) \exp\!\left(-\frac{(\mu-\mu_0)^2}{2\sigma_0^2}\right) (\sigma^2)^{-a-1} e^{-b/\sigma^2}
$$

- **第一步，取 $\mu$ 的条件**：把 $\sigma^2$ 视为已知常数，凡是「不含 $\mu$ 的因子」全部并入归一化常数，剩下的部分关于 $\mu$ 是二次型 → $\mu \mid \sigma^2, y \sim \mathrm{N}(\cdot,\cdot)$。具体地，后验均值是 $\bar{y}$ 与 $\mu_0$ 的**精度加权平均**（呼应共轭节的公式）。
- **第二步，取 $\sigma^2$ 的条件**：把 $\mu$ 视为已知，关于 $\sigma^2$ 的项形如 $(\sigma^2)^{-n/2-a-1}\exp(-[\sum(y_i-\mu)^2/2 + b]/\sigma^2)$，正是 $\mathrm{Inv-Gamma}(a+n/2,\ b+\sum(y_i-\mu)^2/2)$。
- **第三步，轮流采**：先采 $\mu^{(s+1)} \mid \sigma^{2(s)}, y$，再采 $\sigma^{2(s+1)} \mid \mu^{(s+1)}, y$，如此循环。<span class="marginnote">「把一个参数当作已知常数、看联合核关于它的形状」——这就是推导满条件分布的手艺。它只是贝叶斯定理 + 二次配方，不需要新知识，需要的是耐心与代数。这也是为什么贝叶斯教材里 Gibbs 常被称为「conditioning 的艺术」。</span>

**辨析｜易错点：** 满条件分布里「条件」的对象必须包含**全部**其他参数与数据，不能只含一部分，否则链不收敛到正确分布。Gibbs 也没有「接受率」可以体检——正因如此，**自相关与 R-hat 诊断对 Gibbs 尤其重要**。

## 4 混合、步长与实用诊断

无论用哪种算法，事后必须做诊断，三条实用准则：

**看迹图**：一条健康的链，迹图应该是「毛茸茸的胖毛虫」，快速上下抖动；若呈「爬坡-平台-爬坡」的阶梯状，说明混合差。<span class="marginnote">「胖毛虫」是 MCMC 实践者的行话：链的自相关低、ESS 高，说明它把状态空间逛得很充分。阶梯状迹图则意味着链在峰谷间艰难跋涉，多半是步长调错或参数强相关。</span>
- **调步长**：Metropolis 随机游走的步长 $\sigma$ 太小→接受率高但走得慢；太大→频繁拒绝。经验目标接受率：一维目标约 0.44，高维约 0.23。

一次小实验感受步长的两极：目标 $\mathrm{N}(0,1)$，若步长取 0.05，几乎每次都接受，但链游走极慢——5000 步下来自相关高达 0.99 以上、ESS 不足 100；若步长取 20，链几乎永远拒绝、原地打转。中间值约 0.7–1.2 时接受率在 40% 上下、ESS 显著更大。**「接受率」不是越高越好，而是「高得恰当」才好**——这正是自适应 MCMC（如 NUTS 在预热期自动调步长）存在的原因。

**一个手算的 Metropolis 步**让机制完全透明。目标 $p(\theta) \propto \exp(-\theta^2/2)$（即标准正态的核），当前点 $\theta^{(s)} = 0.5$，提议从 $\mathrm{N}(0.5, 1)$ 里抽出 $\theta^* = 0.8$。按接受概率公式：

$$\alpha = \min\!\left(1,\ \frac{p(0.8)}{p(0.5)}\right) = \min\!\left(1,\ \frac{e^{-0.8^2/2}}{e^{-0.5^2/2}}\right) = \min\!\left(1,\ \frac{e^{-0.32}}{e^{-0.125}}\right) = \min(1,\ e^{-0.195}) \approx 0.823$$

也就是说，链有 82% 的概率移动到 0.8，18% 的概率原地停留。这里 $p(0.8) < p(0.5)$（0.8 离 0 更远），所以 $\alpha < 1$——**朝向密度更低的提议要被「打折」，但打折不等于拒绝**。这正是 Metropolis 让链能「爬坡」去探索低密度区、同时保持平稳分布为目标的机制：接受概率等于「新旧密度比」，天然把目标分布写进了转移核。

此外，Metropolis 与 Gibbs 可以**混合使用**：模型里某些参数的条件分布可采（用 Gibbs）、另一些不可采（用 MH），就「可采的采，不可采的猜」。这种「Metropolis-within-Gibbs」是分层模型与潜变量模型里最常见的实用组合——我们在《分层模型》的超参数 $\tau$（Half-Cauchy 先验）上就会遇到。
- **算 ESS 与 R-hat**：$\hat{R} < 1.1$ 视为收敛；有效样本量 ESS 过低则多跑样本。诊断工具（Stan 输出、PyMC 的 `az.summary`）会一并给出，务必先看诊断再下结论。

**初始化与预热（burn-in）**：链从任意起点出发，前几百步通常还没「走进」后验的主体区域，这段被丢弃的早期样本叫**预热期**。实用建议：**多链、分散起点**（Stan 默认取后验最值区域的随机点）比单条长链更可靠——多条链从不同角落出发，最终都要混到同一个平稳分布，若某条链「走不进去」，恰恰暴露了初始化或参数化的问题。<span class="marginnote">预热期样本弃用不是「浪费」：它保证了你留下的样本来自平稳分布，而不是来自「正在爬坡」的过渡段。判断预热是否足够，最直接的办法还是<strong>多链 R-hat</strong>——它比较链间与链内方差，链若没混匀，R-hat 一定偏大。</span>弃掉预热样本后，是否「稀疏化（thinning）」只每 k 步存一个样本？现代观点是**通常没必要**：只要内存装得下，留全部样本能保留最多信息，ESS 才是更诚实的效率指标；过度稀疏反而丢信息。

把本节「何时选谁」的工程判断收进一张速查表：

| 情形 | 推荐算法 | 理由 |
| --- | --- | --- |
| 满条件分布都能采样 | Gibbs | 无调参、无拒绝 |
| 只有部分参数可采 | Metropolis-within-Gibbs | 可采的采、不可采的猜 |
| 分布形状怪异、需通用性 | Metropolis-Hastings | 几乎不限分布 |
| 高维 / 强相关后验 | HMC / NUTS | 用梯度大步滑动（见《贝叶斯计算与 Stan》） |

## 5 从算法到模型：下一站分层模型

Gibbs 抽样之所以是贝叶斯的主力，是因为它在**分层模型**里自然展开：分层模型把「参数之上的参数」引入模型，而每一层的条件分布恰好又是共轭形状——上一层的后验恰好是下一层的先验。于是分层模型的推断，天然是一个「从下往上、再从上往下」的 Gibbs 大循环。

**重点：MCMC 不是贝叶斯本身，而是贝叶斯计算的通用引擎。** 学会了引擎，接下来就能把任何「先验 × 似然」的模型交给它跑——分层、回归、缺失数据，莫不如此。这也是我们下一节开始进入「模型设计与计算相结合」的转折点。

## 6 小结

- **Metropolis**：对称提议 + 接受概率 $\min(1, p(\theta^*)/p(\theta^{(s)}))$，细致平衡保证平稳分布 = 目标。
- **MH 推广**：非对称提议加 **Hastings 修正** $\min\big(1,\ \tfrac{p(\theta^*)J(\theta\mid\theta^*)}{p(\theta)J(\theta^*\mid\theta)}\big)$。
- **Gibbs 抽样**：逐参数在**满条件分布**中轮流采样，无需调参、无拒绝；推导满条件分布 = 固定其余参数、看核的形状。
- **公式解析**：正态-逆伽马模型的两个满条件分布，都是共轭配方的直接产物。
- 实用诊断：**迹图**、**自相关/ESS**、**多链 R-hat**；Metropolis 步长按接受率经验窗口调。
- **易错点**：满条件必须包含全部其他参数与数据；Gibbs 没有接受率，诊断更靠自相关与 R-hat。

在下一节，我们把这些算法开进第一片真正的战场：当个体之上还有总体、各组数据共享一个先验时，怎样建模与计算——这就是**分层模型**。
