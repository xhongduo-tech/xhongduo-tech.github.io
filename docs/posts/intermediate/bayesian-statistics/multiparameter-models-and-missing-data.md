## 为什么从「一个参数走向一群参数」开始

到目前为止的例子大多「低维友好」：单个均值、单个比例。真实数据几乎从不是这样：一份临床数据同时记录血压、血脂、年龄、用药；一份用户行为数据天然带着大量缺失——没填的表单、没点开的页面、中途放弃的问卷。**多参数模型**处理「参数之间互相牵扯」：协方差结构、联合先验、非对角后验。而**缺失数据**处理「观测不完整」：数据里有洞时，洞也是需要建模的对象。

这两个主题看似并列，实则连成一条线：**多参数后验的联合结构是「参数相关」问题，缺失数据是「观测相关」问题**——而它们的求解手法高度同构：都靠「数据增强 / 潜变量」把难问题变成一轮轮可采样的条件分布。<span class="marginnote">缺失数据理论在频率派与贝叶斯派各有支脉。鲁宾 1976 年提出 MAR/MCAR/NMAR 分类，是缺失数据研究的宪章；贝叶斯派的「数据增强（data augmentation）」由 Tanner 与 Wong 1987 年系统化，把缺失值当作额外的「参数」放进后验采样循环——这为后续《贝叶斯计算》与分层模型里的潜变量技术埋下伏笔。</span>

## 1 多参数模型：先验与后验的联合结构

单个参数时，后验是一条曲线。$k$ 个参数时，后验是一张 $k$ 维联合分布 $p(\theta_1,\ldots,\theta_k \mid y)$——**联合结构与边缘结构是两回事**。

以均值向量 $\mu$ 与协方差矩阵 $\Sigma$ 都未知的多元正态为例（Gelman BDA3 Ch. 3 的标准案例）：

$$y_i \mid \mu, \Sigma \sim \mathrm{N}_d(\mu, \Sigma), \qquad p(\mu, \Sigma) \propto |\Sigma|^{-(d+1)/2}$$

后者是**杰弗里斯先验**（$p(\mu,\Sigma)\propto |\Sigma|^{-(d+1)/2}$，在《先验分布与共轭先验》里提到的不变量）。后验的关键性质：

- **条件结构**：给定 $\Sigma$，$\mu \mid \Sigma, y \sim \mathrm{N}(\bar{y}, \Sigma/n)$；给定 $\mu$，$\Sigma \mid \mu, y$ 是逆威沙特（Inverse-Wishart）分布——**又是共轭配方**，于是 Gibbs 循环可用：先采 $\Sigma$ 再采 $\mu$。
- **边缘后验**：把 $\Sigma$ 积分掉后，$\mu$ 的边缘后验是多元 t 分布——**尾部比正态厚**，这是「协方差未知」自动带来的稳健性。<span class="marginnote">多元 t 的出现不是巧合：未知 $\Sigma$ 引入额外不确定性，边缘化后必然加厚尾部。这个「未知辅助参数让目标参数尾部变厚」的现象在贝叶斯里反复出现——它提醒我们，把「推断 $\mu$」与「估计 $\Sigma$」割裂开是有代价的。</span>

**辨析｜易错点：** 别把「分别对每个变量做单变量正态」当成「多变量正态」。多变量正态的价值全在**协方差结构**——变量间的相关、以及相关的后验不确定性。单独建模会丢掉「相关」这个信息，预测与推断都会失真。

## 2 协方差矩阵的先验：逆威沙特的问题

$\Sigma$ 的先验看似照抄共轭配方（Inverse-Wishart）即可，实则翻车名场面：**逆威沙特先验把「尺度」与「相关」耦合，默认把相关推向 0 或 ±1，且对标准差过紧。**<span class="marginnote">Gelman 在 BDA3 里明确建议：对协方差矩阵，尽量别用 Inverse-Wishart。替代方案是<strong>分解法</strong>：$\Sigma = D\,R\,D$，$D$ 是各变量的标准差（独立给半 Cauchy 先验），$R$ 是相关矩阵（给 LKJ 先验，参数 $\eta>0$，$\eta=1$ 均匀、$\eta>1$ 偏向单位阵）。Stan 正是用 LKJ 分解实现协方差建模的。</span>

现代做法（Stan 里的标准写法）：

$$\Sigma = \mathrm{diag}(\tau)\, \Omega\, \mathrm{diag}(\tau), \qquad \tau_j \sim \mathrm{Half\text{-}Cauchy}(0, 2), \qquad \Omega \sim \mathrm{LKJ}(2)$$

把「尺度」与「相关」解耦：$\tau_j$ 管每个变量的变异，$\Omega$ 管变量间的关系，各自给干净的先验——既避免了逆威沙特的耦合问题，也让先验的直觉解释更清楚。

## 3 缺失数据：三种机制与一个原则

数据 $y$ 分两块：**观测到的 $y_{\text{obs}}$** 与**缺失的 $y_{\text{mis}}$**。真正决定分析方式的，是「缺失」与「数据值」的关系——**缺失机制**：

**完全随机缺失（MCAR）**：缺失与任何变量都无关——如问卷随机丢页。可作忽略缺失直接分析（listwise 删除也行，只是浪费）。

**随机缺失（MAR）**：缺失取决于**已观测**的变量，不取决于缺失值本身——如「年龄越大，收入项越可能不填」，而缺失的收入与（已观测的年龄+其他）无关。<span class="marginnote">MAR 是统计推断的默认战场：<strong>缺失机制可忽略（ignorable）</strong>。可忽略的意义是：只要模型包含「决定缺失的观测变量」，推断就可以只建立在 $y_{\text{obs}}$ 的似然上，不必给缺失机制建模。MCAR 是可忽略的特例。</span>

**非随机缺失（NMAR）**：缺失与缺失值本身相关——如「收入越高的人越不填收入」。此时**必须**显式建模缺失机制，否则推断有偏。NMAR 极难处理，实践中要靠领域知识 + 灵敏度分析。

**原则（贝叶斯版）**：把缺失值当作**额外的未知量**，放进后验一起推断——**数据增强**。

用一个直观例子区分三种机制：一份「月收入与年龄」的调查数据，$y_2$（收入）存在缺失。

- **MCAR**：缺失纯粹随机，比如问卷在运输途中随机损毁了几页。删除缺失行后，观测到的收入仍是全体的无偏样本——分析可以直接做。
- **MAR**：缺失取决于年龄——年轻人更不爱填收入，而年龄被完整观测。此时若模型里包含年龄变量，缺失的收入与「已观测到的变量」条件独立，缺失机制可忽略，直接对观测数据建模即可。
- **NMAR**：缺失取决于收入本身——收入高的人故意不填。此时「没填」这个事实本身就携带「收入可能偏高」的信息，忽略它会让估计系统性偏低。**必须**把「是否缺失」也建模（如给缺失行加一个「高收入倾向」的潜变量），否则推断有偏。

**核心判断口诀**：缺失是否「只取决于看得见的东西」？答「是」→ MAR（可忽略）；答「否」→ NMAR（必须建模）。这个判断要靠领域知识，不能靠数据本身验证——所以缺失数据分析的第一义务，是向领域专家问清「为什么缺失」。

## 4 公式解析：数据增强的双层采样

以双变量正态 + 部分缺失为例：$y_i = (y_{i1}, y_{i2})$，第二分量有缺失。设 $z$ 表示所有缺失的 $y_{i2}$。联合后验：

$$
p(\theta, z \mid y_{\text{obs}}) \propto p(\theta)\, \underbrace{p(y_{\text{obs}}, z \mid \theta)}_{\text{把缺失值当数据填进似然}}
$$

- **第一步，视缺失值为未知参数**：把 $z$ 与 $\theta$ 并列进后验。目标从「$p(\theta\mid y_{\text{obs}})$」升级为「$p(\theta, z \mid y_{\text{obs}})$」——表面变量多了，但联合后验的形状更简单。
- **第二步，条件采样（Gibbs 数据增强）**：循环两步——① 从 $p(z \mid \theta, y_{\text{obs}})$ 按当前 $\theta$ **插补缺失值**（对正态模型就是从条件正态分布采）；② 从 $p(\theta \mid y_{\text{obs}}, z)$ 更新参数（用「补齐了的数据」做完整数据的贝叶斯更新）。
- **第三步，收敛**：链收敛后，$z$ 的样本分布就是「缺失值的后验预测」；把 $z$ 积分（平均）掉，就得到 $p(\theta\mid y_{\text{obs}})$ 的估计。<span class="marginnote">两步循环的每一次「插补 + 更新」都同时在做两件事：用当前参数猜缺失值、用猜完的数据再修正参数。这正是「把缺失当潜变量」的机制——它与《Gibbs 抽样与 Metropolis 算法》里的条件采样完全同构，也是混合模型、隐变量模型的通用骨架。</span>

**辨析｜易错点：** 数据增强插补出的「完整数据」只是**中间工具**，不能直接当真实数据统计。多重插补（multiple imputation）的教训：一次插补低估不确定性；正确做法要么在模型里让 $z$ 参与整个采样（贝叶斯路径），要么做多重插补并合并组间方差（Rubin 规则）。

**一个带数字的插补-更新循环**让机制透明。设双变量正态，当前参数 $\mu = (0, 5)$、$\Sigma = \begin{pmatrix}1 & 1\\ 1 & 2\end{pmatrix}$，某一行观测为 $y_1 = 1$、$y_2$ 缺失。

- **插补步（imputation）**：在给定 $y_1=1$ 的条件下，$y_2$ 的条件分布是正态，均值为 $5 + 1\times\frac{1}{2}(1-0) = 5.5$（用 $y_2 = \mu_2 + \frac{\Sigma_{21}}{\Sigma_{11}}(y_1-\mu_1)$），条件方差为 $2 - \frac{1^2}{1} = 1$。于是从 $\mathrm{N}(5.5, 1)$ 采一个 $y_2^*$，比如 $5.8$——**缺失值被「猜」成 5.8**；
- **更新步（posterior update）**：把 $(1, 5.8)$ 当作完整观测，重新计算 $\mu, \Sigma$ 的后验（对完整数据做一次贝叶斯更新）；
- **循环**：重复「插补 → 更新」直到收敛。链收敛后，$y_2^*$ 的所有采样值构成缺失值的**后验预测分布**——它不只是一个点，而是一整条分布（本例中心约在 5.5 附近、宽度约 1）。<span class="marginnote">注意插补值 $y_2^* = 5.8$ 只是<strong>这一轮</strong>的猜测，下一轮会用更新后的 $\mu, \Sigma$ 重新猜。正因为每轮都猜、每轮都更新，缺失值的不确定性才被完整保留在最终分布里——这是「一次插补当完整数据用」永远给不了的东西。</span>

把缺失机制的「怎么办」收进一张速查表，分析前先对号入座：

| 机制 | 判断标志 | 处理方式 |
| --- | --- | --- |
| MCAR | 缺失与一切无关 | 可删除缺失行（仅浪费），或直接分析 |
| MAR | 缺失只取决于已观测变量 | 模型含相关变量即可忽略缺失机制，对 $y_{\text{obs}}$ 建模 |
| NMAR | 缺失与缺失值本身相关 | 必须显式建模缺失机制 + 灵敏度分析 |

**一个判断口诀**：缺失「只取决于看得见的东西」→ 可忽略（MAR）；「取决于看不见的东西」→ 不可忽略（NMAR）。口诀要配领域知识使用——「为什么缺失」只有专家能答。

## 5 多参数 + 缺失：实战中的连锁结构

把前两节合起来，一个真实问题常是：**多元正态 + 相关结构 + 多处缺失**。此时模型要同时写进协方差分解（LKJ）与数据增强插补，一轮迭代做三件事：插补缺失值 → 更新均值 → 更新协方差。<span class="marginnote">这正是 Stan 处理「长格式数据 + 随机效应 + 缺失协变量」类模型的日常形态。工业界例子：推荐系统的协同过滤（评分缺失 = 用户没打分）、临床试验的纵向数据脱落（患者中途退出），都是「缺失机制 + 相关结构」的双重考验。见第三级《机器学习》推荐系统专题。</span>

**重点：多参数与缺失数据并不可怕，因为它们的解法是同一条**——用「潜变量/缺失值 + 条件分布」把难题拆成一轮轮简单采样。理解了这条主线，你在任何「数据不完整、变量相互依赖」的真实场景里，都能把贝叶斯工具箱稳稳架起来。

在 Stan / PyMC 里，这条主线的落地方式各不相同，值得对照：Stan 是「把缺失值当参数声明、用 `~` 或 `target +=` 写进对数后验」，引擎自动做数据增强；PyMC 则通常用 `pm.MutableData` + `pm.ConstantData` 配合缺失值掩码。**无论哪种工具，你只需要告诉它「哪些是缺失的、缺失值属于哪个参数」，采样引擎会替你完成「插补 + 更新」的循环**——理解本节的手工推导，是读懂这些工具文档、以及判断它们输出的后验预测插补值是否合理的前提。

注意「把缺失当参数」与「多重插补」其实是同一条原理的两种实现：前者把 $z$ 放进一次采样，后者把「插补 + 完整数据推断」重复多次再合并（Rubin 规则）。**在样本量中等、缺失比例不高时，两者结果几乎一致**；缺失比例高或模型复杂时，模型内的数据增强更自洽——因为它把「插补的不确定性」与「参数的不确定性」同步传播，不依赖 Rubin 规则的近似合并。

**补一个工程提醒**：当缺失比例很高（如超过 40%）时，数据增强的收敛会变慢，因为 $z$ 的维度大、后验在缺失子空间里「靠猜测交流信息」。此时建议：降低缺失变量的维度（如先做主成分）、给缺失值更紧的先验、或多跑诊断确认 $\hat{R}$ 与 ESS（见《贝叶斯计算与 Stan》）。缺失数据问题没有「一劳永逸」的开关，只有「机制判断 + 模型选择 + 计算诊断」的组合。

**回望本节的主题句**：多参数与缺失数据看起来是两件不同的事——一个是「参数之间相关」，一个是「观测有洞」——但它们共享同一把钥匙：**把「不知道的东西」（协方差、缺失值）写进模型，再用条件分布一轮轮拆解**。多元正态的协方差、缺失数据的 $z$、分层模型里的 $\theta_j$，在贝叶斯眼里都是「待推断的量」，没有本质区别。理解了这一点，你就能把贝叶斯工具箱从「单参数玩具」升级为「真实数据」级——这也正是通往下一节《模型检验与后验预测检验》的过渡：模型变复杂之后，更要学会检查它有没有辜负数据。

## 6 小结

- **多参数模型**关注联合后验：协方差结构决定一切；杰弗里斯先验 + 逆威沙特配方给出 Gibbs 循环。
- **边缘后验是多元 t**：未知 $\Sigma$ 自动加厚尾部，这是「辅助参数不确定」的普遍现象。
- **协方差先验选 LKJ 分解**（$\Sigma = D \Omega D$），避开逆威沙特的尺度-相关耦合问题。
- **缺失机制三分类**：MCAR、MAR（可忽略）、NMAR（必须显式建模）；MAR 下建模只须关注 $y_{\text{obs}}$ 的似然。
- **公式解析**：数据增强把缺失值当作额外未知量，循环「插补 $z$ → 更新 $\theta$」，收敛后即得正确推断。
- **易错点**：插补只是中间工具，须在模型内让 $z$ 参与全采样或多重插补合并方差，不能「插一次当完整数据」。

在下一节，我们把「模型写完了」之后的问责环节补上：怎么检查模型有没有辜负数据——这就是**模型检验与后验预测检验**。
