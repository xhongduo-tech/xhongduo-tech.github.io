# 贝叶斯决策理论

## 为什么从「推断到决策」开始

到目前为止，贝叶斯统计都在回答「**参数是什么**」：后验分布、可信区间、模型比较。但统计的终极目的往往不是知道，而是**行动**：医生要不要给病人用药、公司要不要上线新功能、自动驾驶模型要不要刹车。行动的后果有代价——误诊、亏钱、事故。把「代价」纳入统计决策，正是**决策理论（decision theory）**，而贝叶斯决策理论给出一个极简的原则：

**在知道后验之后，选择「期望代价最小的行动」。**

这条原则统一了整个统计学科：点估计、区间估计、假设检验、模型选择，全都是「某个损失函数下的贝叶斯决策」的特例。它是把贝叶斯从「认识论」推向「行动论」的桥梁，也是理解统计推断「为什么这么定义」的钥匙。<span class="marginnote">统计决策理论的现代形式由沃尔德（Abraham Wald）在 1939-1940 年代建立——他在哥伦比亚大学与数学圈子把「统计推断」整体重铸为「决策问题」。贝叶斯决策是其中立场最自然的一支：后验一有，最优决策即「后验期望损失最小化」。</span>

## 1 决策问题的三要素

任何决策问题都可以抽象成三件套：

**行动空间（action space）$\mathcal{A}$**：决策者能做的全部选择 $a$。例如诊断问题里「用药 $a_1$」与「不用药 $a_2$」。

**状态空间（state space）$\Theta$**：世界真实的、但我们不知道的状态 $\theta$（参数）。

**损失函数（loss function）$L(\theta, a)$**：当真实状态是 $\theta$、你却采取行动 $a$ 时付出的代价。<span class="marginnote">损失函数是决策理论的「价值观输入」——它由决策者根据后果设定，数学只负责在给定损失下求最优。同一个后验分布，配不同的损失会得到不同的最优行动：平方损失给均值，绝对损失给中位数，0-1 损失给众数。这是「点估计为什么有这么多定义」的底层答案。</span>

经典损失：

- **平方损失** $L(\theta,a) = (\theta-a)^2$：惩罚偏离，对称且对大偏离痛罚；
- **绝对损失** $L(\theta,a) = |\theta-a|$：对偏离线性惩罚；
- **0-1 损失** $L(\theta,a) = \mathbb{1}_{\{\theta \ne a\}}$：只要没猜中就罚 1——适合分类/假设检验。

## 2 贝叶斯决策法则：最小化后验期望损失

给定后验 $p(\theta \mid y)$，行动 $a$ 的**后验期望损失（posterior expected loss）**为

$$
\rho(a \mid y) = E_{p(\theta \mid y)}[L(\theta, a)] = \int L(\theta, a)\,p(\theta \mid y)\,d\theta
$$

**贝叶斯决策法则（Bayes rule）**：选择使后验期望损失最小的行动

$$
a^* = \arg\min_{a \in \mathcal{A}} \rho(a \mid y)
$$

**直觉**：损失 $L(\theta, a)$ 已知，后验 $p(\theta \mid y)$ 给出了我们对每个 $\theta$ 的相信程度——把「每个状态下的代价」按「相信程度」加权求和，取总和最小者。这就是把不确定性纳入决策的标准动作。<span class="marginnote">为什么用期望而不是最坏情形？贝叶斯决策默认「按平均代价行事」。最坏情形优化对应 minimax 决策——那是频率派与博弈论路线的立场。两者的选择本质上取决于风险偏好，贝叶斯决策把风险偏好封装进损失函数的形态里。</span>

**三种损失 → 三个经典估计**，这是本节最值得记住的一张表：

| 损失函数 | 最优行动 | 例子 |
| --- | --- | --- |
| 平方损失 $(\theta-a)^2$ | **后验均值** $E[\theta\mid y]$ | 连续参数的点估计 |
| 绝对损失 $|\theta-a|$ | **后验中位数** | 对离群值稳健的估计 |
| 0-1 损失 $\mathbb{1}_{\{\theta\ne a\}}$ | **后验众数（MAP）** | 分类、假设检验 |

**重点：点估计没有「天然正确」，它随损失函数而定。** 这也是为什么 MAP 并不总是「最合理」的点估计——它对应 0-1 损失，若你的真实代价是平方型的，MAP 反而次优。

## 3 公式解析：平方损失下「最优 = 后验均值」

为什么平方损失的最优解是后验均值？一步求导即可：

$$
\rho(a \mid y) = E[(\theta-a)^2 \mid y] = E[\theta^2 \mid y] - 2aE[\theta \mid y] + a^2
$$

- **第一步，展开平方**：期望是线性算子，$(θ-a)^2 = θ^2 - 2aθ + a^2$ 的期望逐项写开。
- **第二步，对 $a$ 求导**：$\frac{d}{da}\rho = -2E[\theta\mid y] + 2a$。
- **第三步，令导数为 0**：$a^* = E[\theta \mid y]$。二阶导 $= 2 > 0$，确为极小。
- **第四步，直觉收束**：平方损失「宁可偏差小也不要大错」，于是最优解天然把「所有可能的 $\theta$ 的加权中心」作为答案——加权权重就是后验密度。<span class="marginnote">这套「求导 + 凸性」的证明是贝叶斯决策的标准手法：凸损失（二次）的期望在「后验均值」处取最小。它背后是更一般的「贝叶斯估计是后验分布的位置参数」思想——不同位置参数对应不同损失。</span>

**再看分类**：0-1 损失下，$E[\mathbb{1}_{\{\theta\ne a\}}\mid y] = 1 - p(\theta=a \mid y)$，最小化即最大化 $p(\theta=a\mid y)$——**选择后验概率最大的类别**。这正是贝叶斯分类器的全部原理，与《机器学习》里的朴素贝叶斯分类器同源。

一个带不对称损失的医疗决策把它落到实处：设 $\theta$ 为患病状态（1 病 / 0 无病），后验 $P(\theta=1\mid y) = 0.3$。行动空间 $\mathcal{A} = \{\text{用药},\ \text{不用药}\}$，损失矩阵：

| 行动 $\setminus$ 真实状态 | $\theta=1$（病） | $\theta=0$（无病） |
| --- | --- | --- |
| 用药 | 0 | 2 |
| 不用药 | 10 | 0 |

**不用药的期望损失**：$0.3\times 10 + 0.7\times 0 = 3.0$；
- **用药的期望损失**：$0.3\times 0 + 0.7\times 2 = 1.4$。

贝叶斯决策选「用药」——尽管患病后验概率只有 0.3，但「漏治」的代价（10）远大于「过度用药」的代价（2）。**决策不是「哪个状态更可能」，而是「哪个行动的风险更小」**——后验提供状态概率，损失提供价值判断，两者结合才产生行动。若把漏治代价改成 3，则不用药（0.9）优于用药（1.4），结论反转——这个敏感性正是决策分析必须「先把损失讲清楚」的原因。

## 4 频率决策与贝叶斯决策：一致性

贝叶斯决策规则与频率派决策理论的关系，有一个漂亮的结果——**一致性（admissibility）**。

**频率风险（frequentist risk）**：$R(\theta, \delta) = E_y[L(\theta, \delta(y))]$——在重复抽样意义下，决策规则 $\delta$ 在真实状态 $\theta$ 上的平均损失。

**贝叶斯风险（Bayes risk）**：$r(\delta) = E_\theta[R(\theta,\delta)]$——再按先验对 $\theta$ 加权。

**重点结论（Bayes 定理的决策版本）**：对任意先验，**贝叶斯决策规则的一致风险不超过任何其他规则（在“几乎处处”的意义下）——贝叶斯决策规则是可容许的（admissible）**。反过来，在正则条件下，任何可容许规则都可以表示为某个（广义）先验的贝叶斯规则。这条「可容许规则 ≈ 贝叶斯规则」的对应，把频率派的「最小化风险」与贝叶斯派的「最小化期望损失」焊在了一起。<span class="marginnote">著名的反例：在 $\theta$ 的平方损失估计里，样本均值 $\bar{y}$ 是频率派的无偏最优，但施泰因（Stein）1956 年证明——当维度 ≥ 3 时，收缩估计（如 James-Stein）风险严格更小，而样本均值<strong>不可容许</strong>。这个震动统计界的「施泰因悖论」正是「合并信息（收缩）优于独立估计」的频率派等价物，与分层模型的收缩同根。</span>

**辨析｜易错点：** 别把「贝叶斯决策」与「频率决策」机械对立。同一把伞下，贝叶斯规则是最小化先验加权风险，minimax 规则是最小化最坏情形风险。当先验很宽、信息很弱时两者趋同；当先验强时，贝叶斯决策会「牺牲一部分最坏情形表现，换取平均表现更优」——这是用信息换风险的权衡，不是逻辑矛盾。

## 5 决策理论回看全书：一切推断都是决策

把决策理论的透镜转回来，会发现本专题之前的内容全是它的特例：

**点估计**：平方/绝对/0-1 损失下的贝叶斯行动；
- **可信区间**：可看作区间型行动、区间损失（区间套住参数则 0 否则 1）下的决策；
- **假设检验**：0-1 损失（或带不对称代价的损失）下的分类决策——贝叶斯因子就是「两个行动的后验机会比」的派生物；
- **模型选择**：模型比较可视为「选择模型」这个行动的决策。

**这条主线串起来就是：先验 × 似然 → 后验；后验 × 损失 → 行动。**<span class="marginnote">对大模型时代，决策透镜尤其有用：离线评测（accuracy/latency 指标）相当于设定损失；在线部署的选择（该上哪个模型、要不要回退）就是一次贝叶斯决策。把「评估指标」想成「损失函数」，把「不确定性」想成「后验」，贝叶斯决策就是一套统一的「负责任地上线」框架。</span>

## 6 小结

- 决策问题三要素：**行动空间、状态空间、损失函数**；损失由决策者的价值观设定。
- **贝叶斯决策法则**：最小化**后验期望损失** $\rho(a\mid y) = \int L(\theta,a)p(\theta\mid y)\,d\theta$。
- 三种损失 → 三种估计：平方→**后验均值**、绝对→**后验中位数**、0-1→**后验众数**；点估计随损失而定，无天然正确。
- **公式解析**：平方损失下求导得「最优 = 后验均值」；0-1 损失下「最优 = 后验众数（贝叶斯分类器）」。
- 与频率决策的桥梁：**贝叶斯规则可容许**；可容许规则 ≈ 贝叶斯规则；Stein 悖论说明收缩（分层）优于独立估计。
- 回看全书：点估计、区间、检验、模型选择**全是贝叶斯决策的特例**——推断给知识，决策给行动。
