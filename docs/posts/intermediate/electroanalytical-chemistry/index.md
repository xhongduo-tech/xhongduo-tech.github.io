# 电分析化学

电分析化学以电极/溶液界面上的电子转移过程为分析信号来源，是伏安法、极谱、电位分析与电化学生物传感等技术共同依赖的分析化学核心分支。对标权威教材体系，按章节逐节写成博文，学完一个学科 = 写完该学科权威教材对应的全部博文。

## 对标教材

- Allen J. Bard, Larry R. Faulkner, *Electrochemical Methods: Fundamentals and Applications* (2nd ed., Wiley)
- Joseph Wang, *Analytical Electrochemistry* (3rd ed., Wiley-VCH)
