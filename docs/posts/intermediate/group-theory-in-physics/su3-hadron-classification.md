## 为什么从 SU(3) 开始

上一节我们用 $SU(2)$ 描述了同位旋：质子和中子是一个二重态，π 介子是一个三重态。但到了 1960 年前后，实验发现的「奇异粒子」越来越多（$K$ 介子、$\Sigma$、$\Xi$、$\Lambda$），简单的 $SU(2)$ 框架装不下了。盖尔曼与奈曼在 1961 年独立提出：把对称群扩大为 $SU(3)$，让「上、下、奇异」三种夸克味道组成一个三重态，于是所有强子都能按 $SU(3)$ 的不可约表示分类——这就是著名的**八重法（Eightfold Way）**。<span class="marginnote">「八重法」的名字借用佛家「八正道」，因为最漂亮的几个分类图案恰好有八个成员。它把一团乱麻的强子谱整理成干净的几何图案，还预言了未知粒子——群论第一次在粒子物理中扮演「预言者」而不是「解释者」。</span>

## 1 从 SU(2) 到 SU(3)：把奇异数纳入对称

同位旋 $SU(2)$ 只把质子和中子等同看待，但 $K$ 介子等粒子携带一个全新的量子数——**奇异数（strangeness）$S$**。奇异粒子质量偏大，说明这个量子数在强作用中守恒（成对产生、关联衰变）。盖尔曼的洞见是：**把「上下」二重态扩成「上下奇异」三重态**，即让对称群从 $SU(2)$ 升为 $SU(3)$。

称这种对称性为**味道 $SU(3)$（flavor SU(3)）**。它只是近似的对称——三夸克质量不同（$m_u \approx 2.2$ MeV、$m_d \approx 4.7$ MeV、$m_s \approx 95$ MeV），所以 $SU(3)$ 对称被质量差「破缺」了。<span class="marginnote">近似的对称性仍然非常有用：破缺把原本简并的多重态「劈开」成质量有差别、但内部规律一致的粒子族。物理学家学会了先按对称性分类、再计入破缺修正——这个「对称 + 破缺」的范式，从分子谱一直延伸到标准模型。</span>

为什么恰巧是 $SU(3)$？一个物理的提示：实验上稳定粒子的守恒量子数（电荷、重子数、奇异数）恰好能用一个「三维」的标记系统编码——$SU(3)$ 的三重态是容纳 $(I_3, Y)$ 两个守恒量子数的最小选择。更深一层，三维来自三种轻夸克的味道，而轻夸克恰好是三种。群论没有「证明」为什么是 $SU(3)$，它只是把实验给出的维度诚实记录下来。

把视野再拉开：$SU(3)$ 是所谓**秩 2** 的李群——它的嘉当子代数有两个生成元，所以态的量子数要用两个数（$I_3, Y$）标记；$SU(2)$ 秩 1 只需一个量子数（$m$）。「秩 = 独立量子数的个数」这个对应，是李群表示论给物理学家最实用的礼物：看到群，就知道要准备几个量子数。

## 2 SU(3) 的结构：生成元与量子数

$SU(3)$ 是 $3\times3$ 幺模幺正矩阵群，生成元数目 $= 3^2 - 1 = 8$。标准生成元是**盖尔曼矩阵（Gell-Mann matrices）** $\lambda_1, \dots, \lambda_8$，其中只有两个彼此对易且可同时对角化：

$$
\lambda_3 = \begin{pmatrix} 1 & 0 & 0 \\ 0 & -1 & 0 \\ 0 & 0 & 0 \end{pmatrix}, \qquad \lambda_8 = \frac{1}{\sqrt3} \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & -2 \end{pmatrix}
$$

$\lambda_3$ 与 $\lambda_8$ 张成**嘉当子代数（Cartan subalgebra）**，它们的同时本征值给出标记每个态的两个量子数。物理上，这两个量子数取为**同位旋第三分量 $I_3$** 与**超荷（hypercharge）$Y$**：

其余六个盖尔曼矩阵 $\lambda_1, \lambda_2, \lambda_4, \lambda_5, \lambda_6, \lambda_7$ 分别对应「改变 $u \leftrightarrow d$」「改变 $u \leftrightarrow s$」等味道混合的无穷小生成元——它们与 $\lambda_3, \lambda_8$ 一起撑起 $SU(3)$ 的八维李代数 $\mathfrak{su}(3)$。对易关系 $[\lambda_a/2, \lambda_b/2] = if_{abc}\lambda_c/2$ 中的结构常数 $f_{abc}$ 完全类比 $\mathfrak{su}(2)$ 的 $\varepsilon_{ijk}$，只是指标更多。

$I_3$ 与 $Y$ 并非任意组合都允许：权图上允许的格点由根系统决定。对 $SU(3)$，允许的 $(I_3, Y)$ 恰好是正三角形格点——这就是为什么八重态画出来是规整的六边形、三重态是规整的三角形：几何的规整不是巧合，而是根系统的结晶。

$$
I_3 = \frac{\lambda_3}{2}, \qquad Y = \frac{\lambda_8}{\sqrt3}
$$

于是 $SU(3)$ 的每个态都可画在 $(I_3, Y)$ 平面上——这就是**权图（weight diagram）**。<span class="marginnote">权图把抽象的表示理论变成纸上的几何：三重态是三角形，八重态是六边形，十重态是三角形带。粒子物理学家直接在这些图上「摆放」实验粒子，看它们是否拼成完整图案——不完整的图案就预言缺失的粒子。</span>

## 3 不可约表示：3、3̄、8、10

$SU(3)$ 的低维不可约表示正好覆盖实验看到的强子族：

- **基础表示 3**：三个夸克 $(u, d, s)$。权图是三角形，顶点对应 $(I_3, Y) = (\tfrac12, \tfrac13)$、$(-\tfrac12, \tfrac13)$、$(0, -\tfrac23)$。
- **共轭表示 3̄**：三个反夸克 $(\bar u, \bar d, \bar s)$，权图是倒三角形。
- **伴随表示 8**：八重态，权图是正六边形。介子八重态与重子八重态都在这里。
- **十重态 10**：权图是底边加长的三角形，$J^P = \tfrac32^+$ 的重子共振态在这。

这些表示之间由**张量积分解**联系。夸克-反夸克组成介子：$3 \otimes \bar 3 = 8 \oplus 1$（八重态 + 单重态）；三个夸克组成重子：

$$
3 \otimes 3 \otimes 3 = 10 \oplus 8 \oplus 8 \oplus 1
$$

八重法名字里的「八」，正是 $3 \otimes \bar 3$ 和 $3 \otimes 3 \otimes 3$ 分解中反复出现的 $8$。<span class="marginnote">为什么强子「恰好」按这些表示出现？因为当时还没有夸克模型——八重法纯粹是「用对称性整理粒子」的经验分类。直到 1964 年盖尔曼和茨威格提出夸克，人们才明白 3 就是夸克的基本表示，八重法才获得动力学解释。对称性分类先于动力学机制，是这段历史最迷人的地方。</span>

注意 $3\otimes\bar 3 = 8 \oplus 1$ 里那个单重态 $1$：它是完全对称的 $\tfrac{1}{\sqrt3}(u\bar u + d\bar d + s\bar s)$，对应 $\eta'$ 介子。单重态在所有 $SU(3)$ 变换下不变——它是「全体味道平均」的态，正因如此它与八重态里的 $\eta$ 质量相近却必须分开，是检验夸克模型细节的好例子。

## 4 公式解析：盖尔曼-西岛关系

八重法把量子数与电荷联系起来，其核心是**盖尔曼-西岛关系（Gell-Mann–Nishijima formula）**：

$$
Q = I_3 + \frac{Y}{2}, \qquad Y = B + S
$$

- **第一步，认识两个量子数**：$I_3$ 是同位旋第三分量（来自 $\lambda_3$），$Y$ 是超荷（来自 $\lambda_8$），$B$ 是重子数（重子为 $+1$，介子为 $0$），$S$ 是奇异数。它们都在强作用中守恒。
- **第二步，代入三重态验证**：夸克 $u$：$I_3 = \tfrac12$，$B = \tfrac13$，$S = 0$，故 $Y = \tfrac13$、$Q = \tfrac12 + \tfrac16 = \tfrac23$——正确，上夸克带电荷 $+\tfrac23$。夸克 $s$：$I_3 = 0$，$B = \tfrac13$，$S = -1$，故 $Y = -\tfrac23$、$Q = 0 - \tfrac13 = -\tfrac13$——正确，奇异夸克带 $-\tfrac13$。
- **第三步，读出预言力**：对任意强子，只要知道 $I_3$ 与 $Y$，电荷就被固定。$K^+$（$I_3 = \tfrac12$，$S = +1$，$Y = 1$）给出 $Q = \tfrac12 + \tfrac12 = 1$；$\Sigma^-$（$I = 1$，$I_3 = -1$，$S = -1$，$Y = 0$）给出 $Q = -1$。全部核对无误。
- **第四步，回看权图**：$Q$ 正是权图上沿 $I_3$ 与 $Y$ 两个方向的线性组合——电荷在权图上表现为一族「等电荷线」，这正是 $SU(3)$ 几何里暗藏的电磁信息。

盖尔曼-西岛关系不是新假设，而是「$SU(3)$ 的量子数语言」与「电荷」的对接：群论把零散的实验数据变成了自洽的网格。

## 5 八重法：介子八重态与重子十重态

把实验粒子按 $(I_3, Y)$ 摆进权图，图案立刻清晰：

- **介子八重态**：$(\pi^+, \pi^0, \pi^-)$、$(K^+, K^0)$、$(\bar K^0, K^-)$ 与 $\eta$ 拼成六边形——正是 $3 \otimes \bar 3$ 的 $8$。
- **重子八重态**：$(p, n)$、$(\Sigma^+, \Sigma^0, \Sigma^-)$、$(\Xi^0, \Xi^-)$ 与 $\Lambda$ 拼成另一个六边形——正是 $3 \otimes 3 \otimes 3$ 的一个 $8$。
- **重子十重态**：$(\Delta^{++}, \Delta^+, \Delta^0, \Delta^-)$、$(\Sigma^{*+}, \Sigma^{*0}, \Sigma^{*-})$、$(\Xi^{*0}, \Xi^{*-})$ 与 **Ω⁻** 拼成三角形——正是 $10$。

重子八重态八个成员的量子数如下，可直接对照权图：

| 粒子 | $I$ | $I_3$ | $Y$ | $Q$ | $S$ |
| --- | --- | --- | --- | --- | --- |
| $p$ | $1/2$ | $+1/2$ | $1$ | $+1$ | $0$ |
| $n$ | $1/2$ | $-1/2$ | $1$ | $0$ | $0$ |
| $\Sigma^+$ | $1$ | $+1$ | $0$ | $+1$ | $-1$ |
| $\Sigma^0$ | $1$ | $0$ | $0$ | $0$ | $-1$ |
| $\Sigma^-$ | $1$ | $-1$ | $0$ | $-1$ | $-1$ |
| $\Lambda$ | $0$ | $0$ | $0$ | $0$ | $-1$ |
| $\Xi^0$ | $1/2$ | $+1/2$ | $-1$ | $0$ | $-2$ |
| $\Xi^-$ | $1/2$ | $-1/2$ | $-1$ | $-1$ | $-2$ |

表中 $Q$ 由盖尔曼-西岛关系给出，$S = Y - B$（重子 $B = 1$）。注意 $\Lambda$ 与 $\Sigma^0$ 有相同的 $(I_3, Y, Q)$，却属于不同的同位旋多重态——它们通过电磁衰变 $\Sigma^0 \to \Lambda + \gamma$ 相连，是八重法里最微妙的一对。

八重法最辉煌的成就在 **Ω⁻ 的预言**：1962 年盖尔曼注意到十重态的三角图案在 $\Xi^{*}$ 处缺一个顶点，预言了存在一个电荷 $-1$、奇异数 $-3$、质量约 $1672$ MeV 的粒子 Ω⁻；1964 年，布鲁克海文实验室在气泡室照片里找到了它，质量 $1672.5$ MeV，与预言几乎一致。<span class="marginnote">Ω⁻ 的发现被视为群论在粒子物理中的「新行星」式胜利——正如海王星被「算出来」一样，Ω⁻ 是被对称性「算出来」的。它让物理界彻底相信：$SU(3)$ 不是巧合的数学，而是强相互作用内在结构的反映。</span>

八重法还给出定量的质量规律：**盖尔曼-大久保质量公式** $M = M_0 + aY + b\,[I(I+1) - \tfrac14 Y^2]$ 对同一多重态内粒子成立。它解释了为什么 $\Sigma$ 比 $\Lambda$ 重、$\Xi$ 更重——质量差不是随机的，而是由 $(I_3, Y)$ 在权图上的位置决定。代入质子与 $\Xi$ 的质量可反推公式参数，再用来预言 $\Sigma^0$ 的质量，与实验符合得极好。

## 6 夸克模型：八重法的动力学解释

1964 年盖尔曼与茨威格提出夸克假设：强子由更基本的**夸克**组成。三个轻夸克 $u, d, s$ 就是 $SU(3)$ 的基础表示 3，反夸克是 3̄。于是：

- **介子** = 夸克 + 反夸克：$3 \otimes \bar 3 = 8 \oplus 1$，八重态 + 一个单重态 $\eta'$。
- **重子** = 三个夸克：$3 \otimes 3 \otimes 3 = 10 \oplus 8 \oplus 8 \oplus 1$，正对应十重态、两个八重态与一个单重态 $\Lambda$ 的内部结构。

夸克模型不仅「拼出」了八重法的图案，还解释了图案里每个成员的质量规律（盖尔曼-大久保质量公式），并预言了 $\Omega^-$ 的存在与质量。群论的表示分解，在这里直接变成了「物质由什么构成」的动力学答案。

颜色的由来也有群论的逻辑：若要构造 $\Delta^{++} = uuu$（三个全同上夸克）这样一个自旋平行、空间对称的重子，夸克模型的原始形式会与泡利不相容原理冲突——于是引入第三种自由度「颜色」，每个夸克带三色之一，三重色让 $uuu$ 在颜色指标上完全反对称，冲突解除。这就是颜色 $SU(3)$ 的历史起源：它从一开始就是「让夸克模型自洽」的数学需要。

**辨析｜易错点：**味道 $SU(3)$ 与颜色 $SU(3)$ 是完全不同的两个群。味道 $SU(3)$ 是**近似**对称（夸克质量不同，用于分类强子），颜色 $SU(3)$ 是**精确**对称（量子色动力学 QCD 的规范群，决定夸克之间的强相互作用力）。记号上两者都写 $SU(3)$，但物理内容毫不相干——读文献时务必分清。

## 7 小结

- **八重法**：盖尔曼与奈曼（1961）用 $SU(3)$ 给强子分类，图案多为八成员，故名。
- $SU(3)$ 有 **8 个生成元**（盖尔曼矩阵 $\lambda_1$–$\lambda_8$），嘉当子代数由 $\lambda_3, \lambda_8$ 张成，给出量子数 $I_3$ 与超荷 $Y$。
- 关键表示：**3**（夸克）、**3̄**（反夸克）、**8**（伴随）、**10**；张量积分解 $3\otimes\bar 3 = 8 \oplus 1$、$3\otimes 3\otimes 3 = 10 \oplus 8 \oplus 8 \oplus 1$。
- **盖尔曼-西岛关系** $Q = I_3 + Y/2$（$Y = B + S$）把量子数与电荷网格化。
- **Ω⁻ 预言**（1962 → 1964 实验证实）是群论预言的标志性胜利。
- 夸克模型把八重法的图案解释为「强子 = 夸克组合」，并区分**味道 $SU(3)$**（近似）与**颜色 $SU(3)$**（精确，QCD 规范群）。
- **八重法图案**由权图给出：介子八重态与重子八重态是六边形，重子十重态是三角形；质量规律由盖尔曼-大久保公式定量描述。
- 颜色 $SU(3)$ 最初是为了调和 $\Delta^{++} = uuu$
