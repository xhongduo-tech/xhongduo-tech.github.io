## 为什么从龙贝格求积开始

上一节我们「顺手」得到一个惊人结论：$\dfrac{4T_{2n}-T_n}{3}$ 竟然把梯形结果的精度从 $O(h^2)$ 提升到 $O(h^4)$——**几乎不花额外成本**。这个动作叫**理查森外推（Richardson extrapolation）**：把两个不同步长的结果按特定比例线性组合，消掉误差展开里的低阶项。龙贝格（Romberg）把外推反复做下去，从一串便宜的复化梯形值出发，**逐层合成出高精度结果**。它是「低阶方法 × 外推 = 高阶方法」的教科书式案例。<span class="marginnote">外推的思想源头是 1910 年理查森（Richardson）的「外插法」（deferred approach to the limit）；龙贝格（Werner Romberg）1955 年把它系统化为求积算法。今天的外推仍是科学计算的通用武器：<strong>收敛慢的序列，用两个相邻项「合成」出更快收敛的新序列</strong>——下面你会看到这个套路有多万能。</span>

本节从欧拉-麦克劳林公式出发，建立外推的理论依据，再给出龙贝格算法的完整递推表。

## 1 欧拉-麦克劳林公式：外推的理论地基

复化梯形的误差为什么「好外推」？因为它的误差展开是**只含偶数次幂**的幂级数：

$$
I - T_n = c_1 h^2 + c_2 h^4 + c_3 h^6 + \cdots
$$

这是**欧拉-麦克劳林公式（Euler-Maclaurin formula）**的推论——当 $f$ 光滑时，复化梯形误差严格按 $h^2$ 的幂次展开（含 $f^{(2k-1)}$ 边界项），**没有 $h^1,h^3,\dots$ 的奇次项**。这个「奇次项消失」是外推能消项的根源。<span class="marginnote">欧拉-麦克劳林公式本身是数值分析里的珍宝：<strong>它把 $\sum f(x_k)$ 与 $\int f$ 的差用端点的奇数阶导数展开</strong>。对周期函数，边界项全为零，梯形公式甚至以超线性速度收敛——这个「周期函数用梯形不亏」的结论在谱方法里很值钱。</span>

误差里只有 $h^2,h^4,h^6\dots$，意味着我们可以**逐项消**：组合 $T_n$ 与 $T_{2n}$ 消 $h^2$ 项，再组合消 $h^4$ 项，依此类推。

## 2 理查森外推：一次外推的核心公式

由欧拉-麦克劳林：

$$
T_n = I + c_1h^2 + c_2h^4 + \cdots, \qquad T_{2n} = I + c_1\frac{h^2}{4} + c_2\frac{h^4}{16} + \cdots
$$

构造组合 $\dfrac{4T_{2n}-T_n}{3}$：

$$
\frac{4T_{2n}-T_n}{3} = I + 0\cdot h^2 + \left(\frac{4c_2}{16}-\frac{c_2}{3}\right)h^4 + \cdots = I + c_2' h^4 + \cdots
$$

**$h^2$ 项被精确消除，剩余误差从 $O(h^2)$ 升到 $O(h^4)$。** 记一次外推结果为

$$
T_n^{(1)} = \frac{4T_{2n} - T_n}{3}
$$

**它就是复化辛普森公式！** 这不是巧合：外推「免费」找到了更高阶的公式。数学上，$\dfrac{4T_{2n}-T_n}{3}$ 与复化辛普森 $S_{2n}$ 是**恒等式**——你甚至不用单独实现辛普森，梯形 + 外推就够了。

## 3 龙贝格算法：反复外推的递推表

把外推递归做下去。定义**龙贝格表（Romberg table）** $R_{j,k}$，其中 $j$ 是网格层数、$k$ 是外推层数：

- **第 0 层**：$R_{j,0}=T_{2^j}$——复化梯形（$2^j$ 段）。
- **递推**：$R_{j,k}=\dfrac{4^k R_{j,k-1} - R_{j-1,k-1}}{4^k-1}$，$k=1,2,\dots$

表格形态（横向外推、纵向加密）：

| 段数 | 梯形 $T$ | 一次外推 $O(h^4)$ | 二次外推 $O(h^6)$ | 三次外推 $O(h^8)$ |
| --- | --- | --- | --- | --- |
| 1 | $R_{0,0}$ | | | |
| 2 | $R_{1,0}$ | $R_{1,1}$ | | |
| 4 | $R_{2,0}$ | $R_{2,1}$ | $R_{2,2}$ | |
| 8 | $R_{3,0}$ | $R_{3,1}$ | $R_{3,2}$ | $R_{3,3}$ |

**每一次外推把收敛阶提高 2**：$R_{j,k}$ 的误差 $O(h^{2k+2})$。$R_{j,1}$ 是辛普森级、$R_{j,2}$ 是 $O(h^6)$ 级、$R_{j,3}$ 是 $O(h^8)$ 级……**用梯形一个方法，外推出任意高阶结果**。<span class="marginnote">实践体会：龙贝格表里 <strong>纵向是「加密」（复用旧节点），横向是「外推」（复用旧结果）</strong>——两个方向都在榨干已有计算的价值。最终表中右下角的结果误差极小，却只付出「梯形分半」的成本。</span>

## 4 公式解析：龙贝格递推的构造逻辑

以 $R_{1,1}=\dfrac{4R_{1,0}-R_{0,0}}{3}$ 为例，拆解外推「为什么用 4 和 3」：

**第一步，设误差关系。** $R_{0,0}=T_1=I+c_1h^2+\cdots$，$R_{1,0}=T_2=I+c_1(h/2)^2+\cdots=I+\tfrac{c_1h^2}{4}+\cdots$。
**第二步，解组合。** 想找 $\alpha R_{1,0}+\beta R_{0,0}=I+O(h^4)$，令 $h^2$ 项系数为零：$\alpha\cdot\tfrac14+\beta\cdot1=0$，且系数和归一 $\alpha+\beta=1$。解得 $\alpha=\tfrac43,\beta=-\tfrac13$。
**第三步，规范化。** $\tfrac43R_{1,0}-\tfrac13R_{0,0}=\dfrac{4R_{1,0}-R_{0,0}}{3}$。分母 3 来自 $4-1=4^1-1$。一般地，消 $h^{2k}$ 项的分母是 $4^k-1$——**第 $k$ 次外推消第 $k$ 个偶数次项**。

**核心洞察：外推把「已知收敛阶的序列」组合成「更高收敛阶的序列」，组合系数由收敛阶比唯一确定。** 这套逻辑适用于任何收敛序列——后文数值微分、常微分方程里，理查森外推还会反复出场。

## 5 实现与收敛行为

龙贝格算法的实现：

```python
import numpy as np

def romberg(f, a, b, max_j=10):
    """龙贝格求积：纵向加密复用旧节点，横向外推逐层升阶。"""
    R = np.zeros((max_j + 1, max_j + 1))
    R[0, 0] = (b - a) / 2 * (f(a) + f(b))        # 1 段梯形
    for j in range(1, max_j + 1):
        n = 2 ** (j - 1)                         # 旧段数
        h = (b - a) / n
        mid = (h / 2) * sum(f(a + (i + 0.5) * h) for i in range(n))  # 新增中点
        R[j, 0] = 0.5 * R[j - 1, 0] + mid
        for k in range(1, j + 1):
            R[j, k] = (4 ** k * R[j, k - 1] - R[j - 1, k - 1]) / (4 ** k - 1)
    return R[max_j, max_j]

print(romberg(np.sin, 0, np.pi))   # ≈ 2.0，误差 ~1e-14
```

**收敛行为**：$f$ 光滑时，$R_{j,k}$ 随外推层数 $k$ 增长指数收敛——**6~8 次外推即可达到双精度极限**。对比纯梯形分半需要 $10^5$ 节点，龙贝格用约 100 个节点就达到同样精度——外推的威力可见一斑。<span class="marginnote">工程注意：外推是「赌博」——它假设误差展开严格成立（$f$ 够光滑）。<strong>$f$ 有奇点时，欧拉-麦克劳林展开失效，外推结果可能反而更差</strong>。用龙贝格前先确认被积函数光滑，或用自适应方法处理奇点。</span>

## 6 小结

- **欧拉-麦克劳林公式**给出复化梯形误差的偶次幂展开 $I-T_n=c_1h^2+c_2h^4+\cdots$——外推的理论地基。
- **理查森外推** $\dfrac{4T_{2n}-T_n}{3}$ 消去 $h^2$ 项，得到 $O(h^4)$ 结果，且**恒等于复化辛普森**。
- **龙贝格递推** $R_{j,k}=\dfrac{4^kR_{j,k-1}-R_{j-1,k-1}}{4^k-1}$：纵向加密、横向外推，$R_{j,k}$ 的误差 $O(h^{2k+2})$。
- 收敛阶比决定组合系数（分母 $4^k-1$）；外推适用于任何已知收敛阶的序列。
- 光滑函数下指数收敛，但**奇点会破坏外推前提**——用前先确认光滑性。
