## 为什么从误差度量开始

上一节《[误差的来源与分类](./error-sources-classification)》把误差分了类，但分类只告诉我们误差「从哪来」，没告诉我们误差「有多大」。而数值分析的一切结论——误差界、条件数、稳定性——最终都要落实到一句话：「这个结果可以信任到第几位」。要说出这句话，就需要把误差量化。本节引入三件工具：**绝对误差、相对误差、有效数字**。它们是整个数值分析的度量衡，后面每一个算法的误差定理，都在这把尺子上读数。<span class="marginnote">开尔文勋爵（1824—1907）这段话常被科学家引用：测量的价值在于把「感觉」换成「数字」。数值分析的误差度量正是如此——把「大概差不多」换成「误差不超过某值」，结论才可被检验、可被复现。</span>

## 1 为什么需要两把尺子

设 $x$ 是准确值，$x^*$ 是 $x$ 的一个近似值。误差的大小有两种度量方式，各有各的适用场景。

**绝对误差（absolute error）**：$e^* = x^* - x$，衡量「差了多少」。
**相对误差（relative error）**：$e_r^* = \dfrac{x^* - x}{x}$（$x\neq 0$），衡量「差了多少比例」。

同样差 1 厘米：测量一根 1 米的木棒，误差是 1%；测量一座 1000 米的大桥，误差是 0.001%。**绝对误差相同，可靠程度完全不同**——所以比较不同量级的近似好坏必须用相对误差。<span class="marginnote">这也是为什么衡量浮点数精度要用「相对误差上界」（单位舍入 $u=2^{-53}$）而不用绝对误差：机器精度对每个数量级都是约 $10^{-16}$ 的相对误差，用绝对误差就没法统一描述。</span>

## 2 绝对误差与误差限

在实际问题里，准确值 $x$ 通常是未知的，因此绝对误差 $e^*$ 本身也算不出来。我们能做的是给出它的一个**上界**。

**误差限（error bound）**：若存在正数 $\varepsilon^*$，使得 $|e^*| = |x^* - x| \le \varepsilon^*$，则称 $\varepsilon^*$ 为近似值 $x^*$ 的**绝对误差限**，并记作

$$
x = x^* \pm \varepsilon^*
$$

意思是「真值落在以 $x^*$ 为中心、半径 $\varepsilon^*$ 的区间内」。误差限是数值分析的主角：我们不承诺误差恰好是多少，只承诺**它不超过多少**——后者才是可计算、可传递的。<span class="marginnote">「$x = x^* \pm \varepsilon^*$」是约定俗成的简写，表示 $x^* - \varepsilon^* \le x \le x^* + \varepsilon^*$，并不表示 $x$ 恰好等于两个端点中的某一个。</span>

## 3 相对误差与相对误差限

**相对误差**定义为 $e_r^* = \dfrac{e^*}{x} = \dfrac{x^* - x}{x}$。由于 $x$ 未知，常以 $x^*$ 近似代替分母，得 $\dfrac{e^*}{x^*}$；两者之差是高阶小量，在误差估计中可忽略。相应地：

**相对误差限**：若 $|e_r^*| \le \varepsilon_r^*$，则称 $\varepsilon_r^*$ 为相对误差限。由 $|e_r^*| = \dfrac{|e^*|}{|x^*|}$，常用

$$
\varepsilon_r^* = \frac{\varepsilon^*}{|x^*|}
$$

作为相对误差限的估计。**辨析｜易错点：** 绝对误差限有单位、随量级变化；相对误差限无量纲、可跨量级比较。衡量算法好坏时，请一律使用相对误差——例如「解向量相对误差 $10^{-8}$」是有意义的，「解向量绝对误差 $10^{-8}$」必须连同解的尺度一起说才有效。

## 4 有效数字：把信任一位一位钉死

**有效数字（significant digits）** 是工程里最常用的精度语言。把 $x^*$ 写成规范浮点形式

$$
x^* = \pm\,0.a_1a_2\cdots a_n\cdots \times 10^m, \qquad a_1 \neq 0
$$

其中 $a_1,\dots$ 是 0 到 9 的数字，$m$ 是整数。若 $x^*$ 的误差限不超过第 $n$ 位的半个单位，即

$$
|x^* - x| \;\le\; \frac{1}{2}\times 10^{\,m-n}
$$

则称 $x^*$ 作为 $x$ 的近似具有 **$n$ 位有效数字**。<span class="marginnote">直观地说：从第一个非零数字开始数，直到「误差可能波及的那一位」为止，中间的位数就是有效数字。误差限「半个单位」对应四舍五入的舍入规则——四舍五入得到的近似值，其误差限恰好不超过保留位的半个单位。</span>

三个细节必须钉死：

- **有效数字从第一个非零数字开始数**，前面的 0 只占位、不算有效数字。$0.0012340$ 有 5 位有效数字，不是 8 位。
- **末尾的 0 是否算，取决于它是否由测量决定。** $1.50 \times 10^2$ 与 $1.5\times 10^2$ 精度不同：前者 3 位有效数字（误差限 $0.5$），后者 2 位（误差限 $5$）。
- **有效数字位数越多，相对误差限越小**——这是下一节公式解析要证明的定量结论。

## 5 公式解析：有效数字如何换算成相对误差限

有效数字与相对误差限可以互相换算。关键定理是：

$$
x^* \text{ 有 } n \text{ 位有效数字} \;\Longrightarrow\; \varepsilon_r^* \le \frac{1}{2a_1}\times 10^{-(n-1)}
$$

对这条定理做三步推导：

- **第一步，写出绝对误差限。** 由有效数字定义：$|e^*| \le \tfrac{1}{2}\times 10^{m-n}$。
- **第二步，估计 $|x^*|$ 的下界。** 因为 $a_1\ge 1$，所以 $|x^*| = 0.a_1a_2\cdots\times 10^m \ge a_1\times 10^{m-1}$。
- **第三步，相除。** 

$$
\varepsilon_r^* = \frac{|e^*|}{|x^*|} \;\le\; \frac{\frac{1}{2}\times 10^{m-n}}{a_1\times 10^{m-1}} \;=\; \frac{1}{2a_1}\times 10^{-(n-1)}
$$

以 $x^* = 3.1416$（$\pi$ 的近似）为例：$a_1=3$，$n=5$，于是 $\varepsilon_r^* \le \dfrac{1}{6}\times 10^{-4} \approx 1.7\times10^{-5}$。真实相对误差 $\dfrac{|3.1416-\pi|}{\pi}\approx 2.3\times10^{-6}$，确实在界内。

**这条公式给出一个工程直觉：每多一位有效数字，相对误差限大约缩小 10 倍。** 反过来，若知道相对误差限，也能反推至少有多少位有效数字（教材给出对称的逆定理：$\varepsilon_r^*\le\dfrac{1}{2(a_1+1)}\times10^{-(n-1)}$ 蕴含至少 $n$ 位有效数字）。从大模型训练到航天轨道计算，「用多少位有效数字」等价于「我能承受多大的相对误差」。

## 6 Python：让代码来数有效数字

把定义翻译成代码，亲自验证几个数：

```python
import math

def significant_digits(x_approx, x_true):
    """按定义数有效数字：误差限不超过第 n 位的半个单位。"""
    err = abs(x_approx - x_true)
    m = math.floor(math.log10(abs(x_approx))) + 1    # 规范浮点形式阶数
    return max(math.floor(m - math.log10(2 * err)), 0)

print(significant_digits(3.1416, 3.14159265))    # 5 位
print(significant_digits(3.14, 3.14159265))      # 3 位
print(significant_digits(1.1, 1.0))              # 1 位（绝对误差 0.1）
print(significant_digits(1000.1, 1000.0))        # 4 位（绝对误差同为 0.1）
```

最后一个对照尤其值得品：**1.1 与 1000.1 都近似到绝对误差 0.1**，但前者的相对误差是后者的 1000 倍，于是有效数字位数也不同——**绝对误差相同，有效数字可以不同；有效数字真正度量的是相对精度。**

## 7 小结

- **绝对误差** $e^*=x^*-x$ 有单位、随量级变化；**相对误差** $e_r^*=(x^*-x)/x$ 无量纲、可跨量级比较。
- **误差限** $\varepsilon^*$ 承诺「误差不超过它」，是传递误差的基本单元；$x = x^* \pm \varepsilon^*$。
- **有效数字**：从第一非零数字数起，误差限不超过第 $n$ 位半个单位，则有 $n$ 位有效数字。
- 每多一位有效数字，**相对误差限缩小约 10 倍**：$\varepsilon_r^* \le \dfrac{1}{2a_1}\times 10^{-(n-1)}$。
- 末尾的 0、前置的 0 是否算有效数字，要严格按定义判断。
