## 为什么从列主元消去法开始

朴素高斯消去法有个致命弱点：**主元即使不为零，只要很小，消去就会把误差放大成灾难**。对付的办法朴素得惊人——**每次消去前，先在这一列里挑绝对值最大的元素，把它换到主元位置**。这个操作叫**选主元（pivoting）**，具体做「每列挑最大」的叫**列主元（partial pivoting）**。它几乎不增加成本，却把消去法的稳定性提到实践可用的水平。<span class="marginnote">直观理解主元问题：<strong>除法的误差放大倍数由「被除数的相对大小」决定</strong>——除以一个很小的主元，等于把误差放大很多倍。列主元保证「每次都除以当前列最大的数」，把放大倍数压到可控。这个「先看大小再决定」的谨慎，是数值算法稳不稳的分水岭。</span>

本节用一个反例说明问题，再给出列主元与全主元的机制与对比。

## 1 反例：小主元如何毁掉结果

解方程组（用 3 位十进制浮点运算模拟）

$$
\begin{cases}
0.001x_1 + 2.000x_2 = 1.000 \\
1.000x_1 + 2.000x_2 = 3.000
\end{cases}
$$

真解 $x_1=2.002\dots,\ x_2=0.499\dots$。朴素消去：第 2 行减去第 1 行的 $1/0.001=1000$ 倍，得

$$
-1998x_2 = -997 \quad\Rightarrow\quad x_2 = \dfrac{997}{1998}\approx0.499
$$

$x_2$ 尚可。但回代 $x_1=\dfrac{1-2\times0.499}{0.001}=\dfrac{0.002}{0.001}=2.0$——若中间结果舍入成 $0.001$，$x_1$ 变成 $1.0$，**误差百分之百**。根因：除以小主元 $0.001$ 时，舍入误差被放大 $1000$ 倍。

**列主元修复**：第 1 列最大元是第 2 行的 $1.000$，交换两行：

$$
\begin{cases}
1.000x_1 + 2.000x_2 = 3.000 \\
0.001x_1 + 2.000x_2 = 1.000
\end{cases}
$$

消去：第 2 行减去第 1 行的 $0.001$ 倍，得 $1.998x_2=0.997$，$x_2\approx0.499$，回代 $x_1=3-2\times0.499=2.002$——**精确**。<span class="marginnote">这个例子是数值分析的标准开场白：<strong>同一个问题、同一种消去法，只差「交换两行」，结果从全错变成全对</strong>。列主元的全部价值就在这一个动作里。</span>

## 2 列主元消去法的机制

**列主元消去法（Gaussian elimination with partial pivoting）** 的每一步：

1. 在第 $k$ 步，查看第 $k$ 列从 $k$ 行到 $n$ 行的元素 $a_{ik}^{(k)}$。
2. 找到绝对值最大者 $\lvert a_{pk}^{(k)}\rvert=\max_{i\ge k}\lvert a_{ik}^{(k)}\rvert$。
3. **交换第 $k$ 行与第 $p$ 行**（连同右端项 $\mathbf{b}$）。
4. 以新主元消去，计算乘子 $m_{ik}=\dfrac{a_{ik}^{(k)}}{a_{kk}^{(k)}}$（此时 $|m_{ik}|\le1$）。

**乘子不超过 1**——这是列主元的理论果实：每一步的放大倍数被限制在 1 以内，误差无法因除法而爆炸。结合矩阵语言，列主元等价于带置换矩阵 $P$ 的分解：

$$
PA = LU
$$

$P$ 记录行交换的置换矩阵。<span class="marginnote">列主元的「免费午餐」：<strong>找最大元是 $O(n^2)$ 的扫描，相对消去的 $O(n^3)$ 微不足道</strong>。用几乎零成本，把消去法的增长因子（growth factor）限制在温和水平——这是数值稳定性里性价比最高的投资。</span>

## 3 全主元消去法：更强的保险，更高的代价

**全主元（complete pivoting）** 不仅在当前列选，而是在**右下方的整个子矩阵**里选绝对值最大的元素作主元，同时进行行交换与列交换。它的稳定性理论性质更好（增长因子上界更紧），但**每次选主元是 $O(n^2)$ 扫描 × $n$ 步 = $O(n^3)$ 总成本**，且列交换打乱未知量顺序、需要记录列置换来还原 $\mathbf{x}$。

| 判据 | 朴素消去 | 列主元 | 全主元 |
| --- | --- | --- | --- |
| 选主元范围 | 无（直接用 $a_{kk}$） | 当前列 | 右下子矩阵 |
| 交换 | 无 | 行交换 | 行 + 列交换 |
| 增长因子 | 可指数爆炸 | 温和 | 更温和（理论最优） |
| 额外成本 | — | $O(n^2)$ 可忽略 | $O(n^3)$ 不可忽略 |
| 工程使用 | 几乎不用 | **默认** | 极少数病态场景 |

**工程结论：列主元是标准配置，全主元是理论保险。** LAPACK、MATLAB、SciPy 的默认 LU 都是「部分主元」（列主元）。全主元只在对增长因子极度敏感的病态问题里用，且要处理列置换的记账。

## 4 公式解析：为什么选「最大」而不是「恰好非零」

**第一步，误差放大模型。** 消去时除以主元 $a_{kk}$，若主元带舍入误差 $\delta$，解带误差 $\delta/|a_{kk}|$——**主元越小，放大越狠**。
**第二步，换最大主元。** 列主元把每一步的除数换成「当前列绝对值最大」，保证 $|m_{ik}|\le1$，任何一步的相对放大不超过数据本身的规模。
**第三步，增长因子。** 定义 $\rho=\dfrac{\max|a_{ij}^{(\text{最终}U)}|}{\max|a_{ij}^{(0)}|}$。朴素消去 $\rho$ 可随 $n$ 指数增长（病态矩阵），列主元下 $\rho$ 通常温和（但理论上仍可到 $2^{n-1}$ 量级的构造反例）。**列主元不是「绝对安全」，而是「工程安全」。**

**增长的直觉**：$U$ 里的元素可能比 $A$ 大，若大得离谱，说明消去过程中信息被「内爆」了。列主元通过每次选最大主元，把这种内爆限制住。<span class="marginnote">警惕：即使列主元，也存在特意构造的「坏矩阵」让增长因子指数化（Wilkinson 反例）。实践中这几乎不出现；<strong>真正的风险源是「矩阵本身病态」（条件数大）而不是「算法增长」</strong>——前者再好的主元策略也救不了。</span>

## 5 实现与验证

列主元消去法的 Python 实现：

```python
import numpy as np

def lu_partial_pivot(A):
    """列主元 LU 分解：返回 P, L, U，满足 PA = LU。"""
    A = np.array(A, dtype=float)
    n = A.shape[0]
    P = np.eye(n)
    L = np.zeros_like(A)
    U = A.copy()

    for k in range(n - 1):
        p = k + np.argmax(np.abs(U[k:, k]))     # 第 k 列绝对值最大的行
        if p != k:
            U[[k, p], :] = U[[p, k], :]         # 交换 U 的两行
            P[[k, p], :] = P[[p, k], :]         # 记录行置换
            L[[k, p], :k] = L[[p, k], :k]       # L 已写好的前 k 列同步换行
        for i in range(k + 1, n):
            L[i, k] = U[i, k] / U[k, k]         # 乘子，|m_ik| <= 1
            U[i, k:] -= L[i, k] * U[k, k:]
    np.fill_diagonal(L, 1.0)
    return P, L, U

# 验证：对随机矩阵检查 PA = LU
rng = np.random.default_rng(0)
A = rng.standard_normal((5, 5))
P, L, U = lu_partial_pivot(A)
print(np.allclose(P @ A, L @ U))                # True
```

**验证技巧**：对随机矩阵做 $PA=LU$，然后检查 $k$。置换矩阵 $P$ 参与的正确记账（交换已生成的 $L$ 列）是最容易写错的地方。<span class="marginnote">实现细节陷阱：行交换时，<strong>$L$ 里已经写好的前 $k$ 列也必须同步交换</strong>——因为 $L$ 按行生成，换行会打乱已存的乘子位置。这是手写 LU 的经典 bug 来源，对照 $L$ 的返回结构可自查。</span>

## 6 小结

- **小主元放大误差**：除以小主元等于放大舍入误差，可能让结果完全错误。
- **列主元**：每步在列内选最大主元并换行，保证 $|m_{ik}|\le1$，对应 $PA=LU$——**工程默认配置**。
- **全主元**：整个子矩阵选最大，理论更稳，但 $O(n^3)$ 选主元成本 + 列置换记账，仅病态场景使用。
- 增长因子量化消去的放大：列主元把它控制在工程安全范围。
- 病态矩阵（条件数大）靠主元救不了——那是问题的固有难度。

在下一节，我们用一个「消到最彻底」的变体解决矩阵求逆：**高斯-若尔当消去法与矩阵求逆**——消去不仅消下方，还消上方，直接得到简化行阶梯形。
