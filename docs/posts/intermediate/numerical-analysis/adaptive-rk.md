## 为什么从变步长 RK 开始

固定步长 RK4 的尴尬：**步长按「最坏处」选，平缓段浪费计算，陡峭段精度不够**。**变步长（自适应）RK** 每步用**嵌入式方法**估计误差，动态调整步长——平缓处大步、陡峭处小步，总步数大幅减少且精度有保证。这是现代 ODE 求解器的标准形态（`solve_ivp` 的 RK45、MATLAB 的 ode45）。<span class="marginnote">自适应步长的核心工具：<strong>嵌入式 RK（embedded RK）——一个公式算两个不同阶的结果</strong>：高阶值 $y_{k+1}$（推进用）与低阶值 $\hat{y}_{k+1}$（误差参考），两者之差就是局部误差的估计。多算一次求值，白得一个误差传感器。</span>

本节给出嵌入式 RK、步长控制公式（PI 控制）与完整自适应算法。

## 1 嵌入式 RK：一次算两个阶

**嵌入式 RK（如 RK45 / Dormand-Prince）** 的 Butcher 表含两行 $b$ 系数：$b_i$（五阶）与 $\hat{b}_i$（四阶）。每步：

$$
y_{k+1} = y_k + h\sum b_ik_i \quad \text{（高阶，推进用）}
$$

$$
\hat{y}_{k+1} = y_k + h\sum \hat{b}_ik_i \quad \text{（低阶，参考）}
$$

**局部误差估计**：

$$
e_{k+1} \approx \left|y_{k+1} - \hat{y}_{k+1}\right| = h\left|\sum(b_i-\hat{b}_i)k_i\right|
$$

**关键**：两组 $k_i$ **共享**（同一批采样斜率），所以嵌入式方法**只比单方法多一次加权和**，几乎零额外成本。<span class="marginnote">记忆：<strong>「嵌入式 = 一组斜率、两套权重」</strong>——$b$（高阶）与 $\hat b$（低阶）共用 $k_i$。误差估计 $\approx h\sum(b_i-\hat b_i)k_i$ 免费到手，这是 Dormand-Prince 方法统治现代求解器的工程理由。</span>

## 2 步长控制：PI 控制器

得到误差估计 $e$ 后，如何调步长？核心公式（**步长控制律**）：

$$
h_{\text{new}} = h \cdot \left(\frac{\mathrm{tol}}{e}\right)^{1/(p+1)}
$$

其中 $p$ 是高阶方法的阶（RK45 的 $p=5$），$\mathrm{tol}$ 是用户容许误差。

**公式解析：为什么指数是 1/(p+1)。**

- **第一步，误差与步长的关系。** 局部误差 $\approx C h^{p+1}$（$p$ 阶方法局部 $p+1$ 阶）。
- **第二步，反解 $h$。** 要 $e_{\text{new}}\approx C h_{\text{new}}^{p+1}=\mathrm{tol}$，解出 $h_{\text{new}}=(\mathrm{tol}/C)^{1/(p+1)}$。而 $e=C h^{p+1}$ 给出 $C=e/h^{p+1}$，代入得 $h_{\text{new}}=h(\mathrm{tol}/e)^{1/(p+1)}$。
- **第三步，工程安全。** 实际乘一个安全因子 $0.9$，且限制缩放范围（如 $0.2\sim5$ 倍），防过冲。

**接受/拒绝策略**：

- $e\le\mathrm{tol}$：**接受**步，$h\leftarrow h_{\text{new}}$，推进。
- $e>\mathrm{tol}$：**拒绝**步，$h\leftarrow h_{\text{new}}$（更小），**重算当前步**。

**更精细的 PI 控制**：现代求解器用「上一误差记忆」的 PI 控制器（$h$ 的缩放还参考上一步的 $\mathrm{tol}/e_{\text{prev}}$），减少步长振荡——这是 ode45 内部的做法。

## 3 数值例子：自适应如何省步数

解 $y'=y$ 到 $t=1$，容许误差 $\mathrm{tol}=10^{-6}$：

| 方法 | 步数 | 实际误差 |
| --- | --- | --- |
| 固定 RK4（$h=0.001$） | 1000 | $10^{-14}$（过度保守） |
| **自适应 RK45** | **~15 步** | $10^{-6}$（恰在容差） |

**自适应用 15 步达到「固定 1000 步的精度承诺」**——省了 98% 的计算。<span class="marginnote">对比要害：<strong>固定步长为了「最坏处」买单，自适应只在「需要处」花钱</strong>。真实问题解常是「平缓区 + 陡峭区」交替——自适应把步长按解的曲率动态分配，这是效率的根本来源。`solve_ivp` 默认 `rtol=1e-3, atol=1e-6` 就是这种「相对 + 绝对」容差。</span>

## 4 自适应算法的完整骨架

```python
def rk45_adaptive(f, t0, y0, t_end, tol=1e-6, h0=0.01, safety=0.9):
    t, y = t0, y0
    h = h0
    ys, ts = [y0], [t0]
    while t < t_end:
        if h > t_end - t: h = t_end - t   # 最后一步对齐终点
        # RK45 的 k_i（Dormand-Prince 表，此处示意用 RK4/改进欧拉嵌入）
        k1 = f(t, y)
        k2 = f(t + h/2, y + h/2*k1)
        k3 = f(t + h/2, y + h/2*k2)
        k4 = f(t + h, y + h*k3)
        y5 = y + h/6*(k1 + 2*k2 + 2*k3 + k4)   # 四阶（示意）
        # ...（真实实现用五阶 b 与四阶 b_hat 两组权重）
        e = abs(y5 - y4_hat)                      # 误差估计
        if e <= tol:
            y, t = y5, t + h                       # 接受
            ys.append(y); ts.append(t)
        # 步长控制（无论接受与否都更新 h）
        h = safety * h * (tol / (e + 1e-30))**(1/5)
    return ts, ys
```

**真实 RK45 用 7 级（6 阶嵌入式）**：Dormand-Prince 表有 7 组 $k_i$，$b$ 为五阶、$\hat b$ 为四阶。**「嵌入对」的选择是门艺术**——要共享斜率、稳定域匹配、误差常数小。

## 5 辨析：自适应不是免费的

| 优点 | 代价 |
| --- | --- |
| 自动控制精度 | 每步多算一次加权和 |
| 平缓处大步省算 | 步长振荡（PI 控制缓解） |
| 陡峭处小步保精度 | 容差设置影响效率 |
| 用户无需调 $h$ | 需设 $\mathrm{tol}$（相对/绝对） |

**辨析｜易错点：** 自适应 RK 的误差估计是「局部」的——它保证**每步**误差 $\le\mathrm{tol}$，但**不保证整体误差**（误差会累积）。「局部控制 ≠ 全局保证」——长期积分需额外的全局检查（如双倍精度对照）。<span class="marginnote">一句话：<strong>「自适应管住局部，全局精度靠核对」</strong>——求解器保证每步误差，但长时间演化的漂移要靠物理守恒量、半程重算等手段监控。工程上从不只信求解器报告的步数。</span>

## 6 小结

- **嵌入式 RK**：一组斜率、两套权重（$b$ 高阶 + $\hat b$ 低阶），误差估计 $e\approx h|\sum(b_i-\hat b_i)k_i|$ 几乎免费。
- **步长控制律**：$h_{\text{new}}=h(\mathrm{tol}/e)^{1/(p+1)}$，配安全因子与缩放限制。
- **接受/拒绝**：$e\le\mathrm{tol}$ 接受推进，否则拒绝重算——误差每步可控。
- 自适应 15 步达到固定 1000 步的精度承诺——省 98% 计算。
- 局部误差控制 ≠ 全局精度保证——长期积分需额外监控。
