## 为什么从勒让德多项式开始

上一节引入了内积与正交性，却没给出任何一族正交函数。本节给出第一族最经典的：**勒让德多项式（Legendre polynomials）**——它在 $[-1,1]$ 上、权函数 $\rho(x)=1$ 下两两正交。它是「函数空间的坐标轴」：任何在 $[-1,1]$ 上的函数都能按这些轴分解，且分解系数彼此独立。勒让德多项式同时是高斯-勒让德求积的节点来源，是数值分析里被引用最多的特殊函数之一。<span class="marginnote">勒让德（1752—1833）是法国大数学家，以数论与椭圆积分著称。勒让德多项式最初来自勒让德在引力位势理论中研究「两个质量的相互作用位势展开」，后来成为正交多项式理论的起点。他的名字还挂在「勒让德变换」上——那是分析力学与热力学的核心工具。</span>

本节从定义、正交性、三项递推、到应用，把勒让德多项式这条线索走通。

## 1 定义：罗德里格斯公式与显式表达式

**勒让德多项式** $P_n(x)$ 是 $[-1,1]$ 上权函数 $\rho=1$ 的正交多项式族，次数为 $n$。最优雅的定义是**罗德里格斯公式（Rodrigues' formula）**：

$$
P_n(x) = \frac{1}{2^n n!}\,\frac{d^n}{dx^n}\left[(x^2-1)^n\right]
$$

展开得到前几项：

$$
P_0(x)=1, \qquad P_1(x)=x, \qquad P_2(x)=\frac{3x^2-1}{2}, \qquad P_3(x)=\frac{5x^3-3x}{2}
$$

几个直接可读的性质：

- $P_n$ 是**首一多项式乘以常数**：最高次项系数为 $\dfrac{(2n)!}{2^n(n!)^2}$。
- $P_n$ 的**奇偶性**与 $n$ 一致：$P_n(-x)=(-1)^n P_n(x)$（$(x^2-1)^n$ 是偶函数，求 $n$ 阶导后奇偶性取决于 $n$）。
- $P_n(1)=1,\ P_n(-1)=(-1)^n$——端点值恒定，与 $n$ 无关。

**正交性**是它的灵魂：对 $m\neq n$，

$$
(P_m, P_n) = \int_{-1}^{1} P_m(x) P_n(x)\, dx = 0
$$

且 $\lVert P_n\rVert_2^2=\int_{-1}^{1}P_n^2(x)\,dx=\dfrac{2}{2n+1}$。<span class="marginnote">为什么定义在 $[-1,1]$？因为这是「最对称」的区间——任何有限区间 $[a,b]$ 经线性变换 $t=\dfrac{2x-a-b}{b-a}$ 都能映射到 $[-1,1]$。后文高斯求积正是在 $[-1,1]$ 上布节点，再变换回任意区间。</span>

## 2 三项递推公式：计算的主力

直接算 $n$ 阶导数不经济。勒让德多项式满足**三项递推（three-term recurrence）**：

$$
(n+1)P_{n+1}(x) = (2n+1)\,x\,P_n(x) - n\,P_{n-1}(x)
$$

即

$$
P_{n+1}(x) = \frac{2n+1}{n+1}\,x\,P_n(x) - \frac{n}{n+1}\,P_{n-1}(x)
$$

由 $P_0=1,\ P_1=x$ 出发，$P_2=\dfrac{3x^2-1}{2}$ 一步可得。**三项递推把 $O(n^2)$ 的逐阶求导变成 $O(n)$ 的迭代**，是程序里生成任意阶勒让德多项式的标准做法。<span class="marginnote">三项递推几乎是所有正交多项式的共性：<strong>勒让德、切比雪夫、拉盖尔、埃尔米特都满足形如 $a_n P_{n+1}=(b_n+c_n x)P_n - d_n P_{n-1}$ 的递推。</strong> 区别只在系数——这背后是「正交多项式=给定权函数的格施密特正交化」的统一结构。</span>

Python 实现：

```python
def legendre(n, x):
    """用三项递推求 P_n(x)，x 可以是数组"""
    p0, p1 = 1.0, x
    if n == 0: return p0
    if n == 1: return p1
    for k in range(1, n):
        p2 = ((2*k+1)*x*p1 - k*p0) / (k+1)
        p0, p1 = p1, p2
    return p1
```

## 3 公式解析：为什么 {1, x, x², …} 正交化后就是 Pₙ

正交多项式族的本质是「对朴素基 $\{1,x,x^2,\dots\}$ 做 Gram-Schmidt 正交化」。以 $P_2$ 为例拆解：

- **第一步，从 $P_0,P_1$ 出发。** $P_0=1$ 已「归一」；$P_1=x$ 与 $P_0$ 正交因为 $\int_{-1}^1 x\,dx=0$（奇函数在对称区间积分）。前两项直接就是。
- **第二步，正交化 $x^2$。** 令 $P_2=x^2-\alpha P_1-\beta P_0$，要求 $(P_2,P_1)=0$ 且 $(P_2,P_0)=0$。由奇偶性，$\alpha=0$；$\beta=\dfrac{(x^2,P_0)}{(P_0,P_0)}=\dfrac{\int_{-1}^1x^2dx}{2}=\dfrac{1}{3}$。
- **第三步，归一化。** $P_2=x^2-\tfrac13=\dfrac{3x^2-1}{3}$。把它乘以常数 $3/2$ 使 $P_2(1)=1$，得到教科书形式 $\dfrac{3x^2-1}{2}$。**「端点归一化」让勒让德多项式在 $x=\pm1$ 处取值恒定——这个约定（而非范数归一）定义了 $P_n$ 的「大小」。**

这个三步流程（正交化 + 端点归一）就是所有经典正交多项式的生产流水线。权函数改变，只改变正交化里的内积。

## 4 勒让德多项式的零点与最佳平方逼近

两个最重要的应用藏在零点里：

- **$P_n$ 在 $(-1,1)$ 内有 $n$ 个互异的实零点**，且都落在开区间内部。这些零点是**高斯-勒让德求积公式的节点**——用 $P_n$ 的零点作求积节点，$n$ 个点就能精确积分到 $2n-1$ 次多项式。这是后文《高斯求积》的预告。
- 用 $\{P_0,\dots,P_n\}$ 作基做最佳平方逼近，系数由投影公式给出：

$$
p^*(x) = \sum_{k=0}^{n} c_k P_k(x), \qquad c_k = \frac{(f, P_k)}{(P_k, P_k)} = \frac{2k+1}{2}\int_{-1}^{1} f(x)P_k(x)\,dx
$$

**系数 $c_k$ 之间互不依赖**——这就是正交基的威力：普通基（如 $\{1,x,\dots\}$）下要求解 $n+1$ 阶法方程组，正交基下每个系数是独立的投影。<span class="marginnote">类比傅里叶级数：<strong>勒让德展开就是「区间上的多项式傅里叶级数」。</strong> 傅里叶系数是 $f$ 与三角函数的内积，勒让德系数是 $f$ 与 $P_k$ 的内积——同一种「投影哲学」。</span>

## 5 辨析：勒让德与切比雪夫的对照

两组正交多项式容易混，提前对照：

| 项目 | 勒让德 $P_n$ | 切比雪夫 $T_n$（下一节） |
| --- | --- | --- |
| 权函数 | $\rho=1$ | $\rho=1/\sqrt{1-x^2}$ |
| 端点行为 | $P_n(1)=1$ 有界 | $T_n(1)=1$，权在端部爆炸 |
| 零点位置 | 中部略密 | 两端很密 |
| 擅长 | 平方逼近、高斯求积 | 一致逼近、节点优化 |
| 恒等式 | 递推 $(n+1)P_{n+1}=(2n+1)xP_n-nP_{n-1}$ | $T_n=\cos(n\arccos x)$ |

**辨析｜易错点：** 勒让德节点在区间**中部**比端部密（零点是 $P_n$ 的根，集中在 $0$ 附近），而切比雪夫节点在**两端**密。搞反这个分布，就搞反了「该在哪儿布点」——前者服务平方逼近，后者服务一致逼近，切不可张冠李戴。

## 6 小结

- **勒让德多项式** $P_n$ 是 $[-1,1]$ 上权函数 $\rho=1$ 的正交多项式族，罗德里格斯公式给出显式定义。
- **正交性** $\int_{-1}^1 P_mP_n dx=0\ (m\neq n)$，$\lVert P_n\rVert_2^2=\dfrac{2}{2n+1}$。
- **三项递推** $(n+1)P_{n+1}=(2n+1)xP_n-nP_{n-1}$ 提供 $O(n)$ 计算。
- $P_n$ 的 $n$ 个互异实零点是**高斯-勒让德求积节点**，落在 $(-1,1)$ 内。
- 正交基使最佳平方逼近系数**解耦**：$c_k=\dfrac{2k+1}{2}\int_{-1}^1 fP_k dx$。

在下一节，我们认识与勒让德「形似而神不同」的**切比雪夫多项式**——它对应两端加重的权函数，是解决龙格现象、构造最优一致逼近的核心工具。
