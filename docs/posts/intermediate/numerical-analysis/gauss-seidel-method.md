## 为什么从高斯-赛德尔迭代法开始

雅可比迭代有个「浪费」：算 $x_2^{(k+1)}$ 时，$x_1^{(k+1)}$ 已经算好了，却还只用 $x_1^{(k)}$。**高斯-赛德尔迭代（Gauss-Seidel method）** 把这份「新值」用起来——逐个分量更新，每个分量立刻用前面分量的最新值。结果：存储省一半（一组 $x$ 就够），收敛通常快一倍。它是工程串行环境里迭代法的默认选择。<span class="marginnote">高斯与赛德尔（Philipp Ludwig von Seidel）都在 19 世纪用过这个迭代；「Gauss-Seidel」之名由后人合称。它与雅可比的核心差别只有一句：<strong>「雅可比全体看旧值，高斯-赛德尔逐个用新值」</strong>——一个「同步」、一个「异步」，代价与收益都在于此。</span>

本节给出公式、矩阵形式、收敛定理，并与雅可比做彻底对比。

## 1 分量形式：边更新边用

高斯-赛德尔迭代的分量形式：

$$
x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j=1}^{i-1}a_{ij}x_j^{(k+1)} - \sum_{j=i+1}^{n}a_{ij}x_j^{(k)}\right)
$$

**注意下标**：$j<i$ 的部分用**本轮新值** $x_j^{(k+1)}$（已经算好了），$j>i$ 的部分用旧值 $x_j^{(k)}$。**每个分量立刻享用前面分量的最新信息。**

**数值例子**（同上一节方程组，初值 $(0,0,0)$）：

- $x_1^{(1)}=\dfrac{6-0-0}{10}=0.6$
- $x_2^{(1)}=\dfrac{8-0.6-0}{10}=0.74$ ← 用到了新算的 $x_1^{(1)}=0.6$
- $x_3^{(1)}=\dfrac{8-0.6-0.74}{10}=0.666$ ← 用到 $x_1,x_2$ 的新值

对比雅可比第一轮 $(0.6,0.8,0.8)$——**高斯-赛德尔每步都更早地吸收了新信息**。<span class="marginnote">观察关键差异：高斯-赛德尔里 $x_3^{(1)}$ 用了 $x_2^{(1)}$（本轮新值），而雅可比里 $x_3^{(1)}$ 只能看 $x_2^{(0)}$。<strong>「信息流速」快一倍，收敛通常也快一倍</strong>。</span>

## 2 矩阵形式与分裂

用分裂 $A=D-L-U$（注意 $-L$ 是严格下三角、$-U$ 严格上三角），高斯-赛德尔取

$$
M = D - L, \qquad N = U
$$

迭代格式 $(D-L)\mathbf{x}^{(k+1)}=U\mathbf{x}^{(k)}+\mathbf{b}$，即

$$
\mathbf{x}^{(k+1)} = (D-L)^{-1}U\,\mathbf{x}^{(k)} + (D-L)^{-1}\mathbf{b}
$$

迭代矩阵 $G_{GS}=(D-L)^{-1}U$。**每步要解一个下三角系统（前代）**——但 $D-L$ 是下三角，前代只需 $O(n)$（逐行往前推）。<span class="marginnote">对比雅可比 $M=D$：高斯-赛德尔的 $M=D-L$ 更接近 $A$（少了 $U$），分裂更「好」，所以谱半径通常更小、收敛更快。<strong>「$M$ 越接近 $A$，收敛越快」这条直觉在这里兑现。</strong></span>

## 3 公式解析：收敛定理

**定理（充分条件）。** 若 $A$ 严格对角占优，则高斯-赛德尔迭代对任意初值收敛。

**更强的定理（SPD）。** 若 $A$ **对称正定（SPD）**，则高斯-赛德尔迭代对任意初值收敛。

**为什么 SPD 时高斯-赛德尔必收敛？** 直观论证：高斯-赛德尔的每步更新等价于「沿着坐标方向做精确线性搜索」——SPD 保证目标函数 $\phi(\mathbf{x})=\tfrac12\mathbf{x}^\top A\mathbf{x}-\mathbf{b}^\top\mathbf{x}$ 是凸的，每次分量更新都**严格减小** $\phi$。单调下降 + 有下界 ⇒ 收敛到极小点（即 $A\mathbf{x}=\mathbf{b}$ 的解）。

**收敛速度对比**：对 SPD 矩阵，高斯-赛德尔的谱半径满足 $\rho(G_{GS})=\rho(G_J)^2$（在一定条件下）——**谱半径是雅可比的平方，收敛快一倍**（每步误差压缩比更好）。<span class="marginnote">「$\rho_{GS}=\rho_J^2$」只对特定矩阵类成立（如二阶椭圆 PDE 的离散），但「高斯-赛德尔通常显著快于雅可比」是普遍经验。<strong>工程默认：能用高斯-赛德尔就别用雅可比（除非要并行）</strong>。</span>

## 4 实现：一组 x 就够

```python
import numpy as np

def gauss_seidel(A, b, x0, tol=1e-10, max_iter=1000):
    """高斯-赛德尔迭代：逐个分量更新，立即用前面分量的最新值。"""
    x = np.array(x0, dtype=float)
    for it in range(max_iter):
        x_old = x.copy()
        for i in range(len(b)):
            s = A[i] @ x - A[i, i] * x[i]     # j<i 用本轮新值，j>i 用旧值
            x[i] = (b[i] - s) / A[i, i]
        if np.linalg.norm(x - x_old, ord=np.inf) < tol:
            return x, it + 1
    return x, max_iter
```

**工程注意**：内层循环天然串行（$x[i]$ 依赖 $x[0..i-1]$ 的新值），无法直接并行——这就是它比雅可比「慢一维」的地方。稀疏矩阵下每轮 $O(n)$，与雅可比同阶。

## 5 雅可比 vs 高斯-赛德尔：最终对照

| 判据 | 雅可比 | 高斯-赛德尔 |
| --- | --- | --- |
| 更新 | 全体同步（旧值） | 逐个串行（新值） |
| 存储 | 两组 $x$ | 一组 $x$ |
| 分裂 $M$ | $D$ | $D-L$ |
| 每步成本 | $O(n)$ | $O(n)$（前代） |
| 并行性 | **强** | 弱 |
| 收敛（SPD） | $\rho_J$ | $\rho_J^2$（通常） |
| 适用 | GPU、分布式 | 串行、通用 |

**辨析｜易错点：** 高斯-赛德尔**不总是**比雅可比快——存在矩阵类（非对角占优、非 SPD）使雅可比收敛而高斯-赛德尔发散，或反之。**「谁快」没有无条件答案，SPD/对角占优只是充分条件**。工程做法：两个都试几步，看谱半径或实际收敛曲线。<span class="marginnote">一句话：<strong>「串行上高斯-赛德尔、并行上雅可比，收敛不放心就 SOR」</strong>——下一节 SOR 在高斯-赛德尔上再加一个松弛参数，把谱半径进一步压小。</span>

## 6 完整数值例子：三轮迭代的收敛过程

用前面的方程组（$10x_1+x_2+x_3=6$ 等）追踪高斯-赛德尔三轮迭代，看它如何逼近真解 $(0.6,0.74,0.666)$：

| 轮次 $k$ | $x_1$ | $x_2$ | $x_3$ | 残差范数 |
| --- | --- | --- | --- | --- |
| 0 | 0 | 0 | 0 | 8.0 |
| 1 | 0.6000 | 0.7400 | 0.6660 | 0.014 |
| 2 | 0.6594 | 0.6675 | 0.6673 | $6\times10^{-4}$ |
| 3 | 0.6666 | 0.6667 | 0.6667 | $\approx0$ |

两轮后误差降到 $10^{-3}$ 以下——**每轮约收敛一位十进制**。对照：同一方程组雅可比第一轮是 $(0.6,0.8,0.8)$，第二轮才到 $(0.6,0.74,0.666)$——高斯-赛德尔第一轮就已超过雅可比第二轮。

**辨析｜易错点：** 上面的「快一倍」来自相邻分量信息被立即复用；注意实现里 `s = A[i] @ x - A[i,i]*x[i]` 这一行，$j<i$ 处自动取到本轮的**新值**——千万不要先复制一份 $x$ 再统一更新，那会悄悄退回雅可比。

## 7 小结

- **高斯-赛德尔迭代**：$x_i^{(k+1)}=\dfrac{1}{a_{ii}}\left(b_i-\sum_{j<i}a_{ij}x_j^{(k+1)}-\sum_{j>i}a_{ij}x_j^{(k)}\right)$，逐个用新值。
- 分裂 $M=D-L$、$N=U$，迭代矩阵 $G_{GS}=(D-L)^{-1}U$；每步前代 $O(n)$。
- **收敛充分条件**：严格对角占优，或 $A$ 对称正定。
- SPD 下收敛的直觉：每次分量更新单调降低二次目标函数。
- 通常快于雅可比（谱半径平方）、省一半存储，但串行、不并行。

在下一节，我们给迭代加一个「油门」：**逐次超松弛迭代法（SOR）**——用松弛因子加速收敛，找到最优 $\omega$。
