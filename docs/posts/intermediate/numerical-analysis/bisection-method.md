## 为什么从二分法开始

二分法（bisection method）是求根方法里「最笨」也「最可靠」的：给定含根区间，不断取中点、判断根在左半还是右半、缩小区间。它每次把区间减半，**只要 $f$ 连续且 $f(a)f(b)<0$，就必定收敛**——没有任何意外。虽然它收敛慢（线性），但它是一切求根流程的「保底方案」与「最后防线」。<span class="marginnote">二分法的资格：<strong>「唯一一个『只要初始区间正确就必然收敛』的求根方法」</strong>。牛顿、弦截都可能发散，二分法不会。工程上常用它给牛顿法「暖机」——先二分几轮把区间缩到根附近，再让牛顿快速收敛。</span>

本节给出二分法算法、收敛速度的精确刻画（这是它最大的优点——可预算步数）。

## 1 算法：反复对半

**二分法**：设 $[a,b]$ 含根（$f(a)f(b)<0$）。

1. 取中点 $c=\dfrac{a+b}{2}$，算 $f(c)$。
2. 若 $f(c)=0$，$c$ 就是根（概率为零，实际很少发生）。
3. 若 $f(a)f(c)<0$，根在 $[a,c]$：$b\leftarrow c$。
4. 否则根在 $[c,b]$：$a\leftarrow c$。
5. 重复直到 $b-a<\varepsilon$。

**不变量**：每步保持 $f(a)f(b)<0$（含根性质），区间长度每次减半。

**数值例子**：$f(x)=x^3-x-1$，区间 $[1,1.5]$（上节搜索所得）。

| 步数 | $a$ | $b$ | $c$ | $f(c)$ |
| --- | --- | --- | --- | --- |
| 1 | 1.0 | 1.5 | 1.25 | −0.297 |
| 2 | 1.25 | 1.5 | 1.375 | 0.225 |
| 3 | 1.25 | 1.375 | 1.3125 | −0.052 |
| 4 | 1.3125 | 1.375 | 1.3438 | 0.083 |
| 5 | 1.3125 | 1.3438 | 1.3281 | 0.014 |

根约 $1.3247$，5 步后区间宽 $0.03$，中点误差约 $0.004$。<span class="marginnote">观察区间长度：$1.5-1.0=0.5\to0.25\to0.125\to0.0625\to0.0313$——<strong>每步精确减半</strong>。这就是「线性收敛（比 1/2）」的直观：误差每一步乘 $1/2$。</span>

## 2 公式解析：误差与步数预算

**误差估计**：第 $k$ 步后的区间长度 $b_k-a_k=\dfrac{b_0-a_0}{2^k}$，取中点 $c_k$ 作为根的近似，误差满足

$$
|c_k - r| \le \frac{b_k - a_k}{2} = \frac{b_0 - a_0}{2^{k+1}}
$$

**步数预算**：要求误差 $\le\varepsilon$，需要

$$
\frac{b_0-a_0}{2^{k+1}} \le \varepsilon \quad\Longrightarrow\quad k \ge \log_2\frac{b_0-a_0}{\varepsilon} - 1
$$

**每秒约 3.3 步（$\log_2 10\approx3.32$）获得一位十进制精度。**

- **第一步，区间减半**。每步 $b-a$ 减半，误差随区间减半。
- **第二步，反解步数**。从 $\dfrac{b-a}{2^{k+1}}\le\varepsilon$ 解 $k$，得到 $\log_2$ 关系的步数公式。
- **第三步，读数**。$\varepsilon=10^{-12}$、初始区间 $1$，需约 $39$ 步——**不多不少，预先可算**。

**收敛阶**：二分法是**线性收敛**，误差比 $1/2$。它的「慢」是结构性的（只用函数值符号），但它的「可预算」也是结构性的——**误差上界与函数形状无关，只看区间**。

## 3 二分法的唯一风险：初始区间不含根

二分法**只在一个前提下失败**：初始区间 $[a,b]$ 不含根（$f(a)f(b)>0$）。这发生在：

- 区间内根数为偶数（0、2、4…个），变号次数偶数。
- 区间内含偶重根（$f$ 在根处不变号）。

**应对**：搜索阶段就要确保 $f(a)f(b)<0$；遇到偶重根，改搜 $f'$ 或用其他方法。<span class="marginnote">工程检查：<strong>「$f(a)f(b)<0$ 是二分法生效的唯一前提」</strong>——不满足就先去搜索（上一节），别硬用二分法「碰运气」。这个前提检查是求根代码的第一行。</span>

## 4 实现与终止准则

```python
def bisection(f, a, b, tol=1e-10, max_iter=100):
    if f(a) * f(b) > 0:
        raise ValueError("区间内无根或根数非奇数")
    for k in range(max_iter):
        c = (a + b) / 2
        if f(a) * f(c) < 0:
            b = c
        elif f(c) * f(b) < 0:
            a = c
        else:
            return c, k   # f(c)=0，恰好命中
        if (b - a) < 2 * tol:
            return (a + b) / 2, k
    return (a + b) / 2, max_iter
```

**终止准则**：区间宽度 $\le$ 容差（二分法的标准终止），或 $|f(c)|$ 足够小。**注意：二分法对「函数值平坦」（重根）不敏感**——它用符号而非数值，重根处 $f(c)$ 可能都接近零，但区间照样收缩到根。<span class="marginnote">对比预告：<strong>二分法线性收敛（每步 1/2），牛顿法二次收敛（每步平方）</strong>——但二分法永不失败，牛顿法可能发散。工程智慧：用二分法「起步」，用牛顿法「冲刺」，是求根的标准组合。</span>

## 5 二分法 vs 其他求根法：定位

| 方法 | 收敛阶 | 需要 | 失败风险 |
| --- | --- | --- | --- |
| **二分法** | 线性（比 1/2） | 含根区间 | 几乎为零 |
| 不动点迭代 | 线性（比 $\varphi'$） | 压缩映射 | 发散 |
| 牛顿法 | 二次 | 导数 | 发散 |
| 弦截法 | $\approx1.618$ | 两个初值 | 发散 |

**工程结论：二分法是「保底」，不是「首选」**——默认用它锁定区间，再切快方法；或精度要求不高时直接用到底。

## 6 小结

- **二分法**：取中点、判符号、缩区间，保持 $f(a)f(b)<0$，每步区间减半。
- **误差** $|c_k-r|\le\dfrac{b_0-a_0}{2^{k+1}}$；步数预算 $k\ge\log_2\dfrac{b_0-a_0}{\varepsilon}-1$。
- **线性收敛**（比 $1/2$），每秒约 3.3 步获得一位十进制精度——慢但可预算。
- **唯一失败前提**：初始区间不含根（含偶数个根或偶重根）——先搜索保证 $f(a)f(b)<0$。
- 二分法用符号不用数值，对重根不敏感；是「保底方案」，常给牛顿法暖机。
