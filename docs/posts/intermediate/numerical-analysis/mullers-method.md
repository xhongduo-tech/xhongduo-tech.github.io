## 为什么从抛物线法开始

弦截法用两个点拟合**直线**找根；**抛物线法（Müller's method）** 更进一步，用三个点拟合**抛物线**，求抛物线与 x 轴的交点作为下一个近似。它有两个独特优势：**收敛阶约 1.84（比弦截更快）**，以及**能直接求出复根**（抛物线与 x 轴的交点可以不是实数）——这对多项式求根（包括复根）特别有价值。<span class="marginnote">抛物线法 1956 年由 Müller 提出，是多项式求根器的常用内层迭代。它的关键特质：<strong>「用抛物线而不是直线，让方法看到『弯曲』的信息」</strong>——弯曲信息带来更高收敛阶，也让复根自然浮现。</span>

本节给出抛物线法公式、收敛阶与复根能力。

## 1 公式：三点拟合抛物线

给定三个点 $(x_{k-2},f_{k-2})$、$(x_{k-1},f_{k-1})$、$(x_k,f_k)$，过三点作抛物线 $P(x)$，求 $P$ 与 x 轴的交点得 $x_{k+1}$。

用**牛顿形式的插值**（以 $x_k$ 为基准）：

$$
P(x) = f_k + (x-x_k)f[x_{k-1},x_k] + (x-x_k)(x-x_{k-1})f[x_{k-2},x_{k-1},x_k]
$$

令 $P(x_{k+1})=0$，解二次方程。定义

$$
\omega = f[x_{k-2},x_{k-1},x_k] \quad \text{（二阶均差）}, \qquad g = f[x_{k-1},x_k] + (x_k-x_{k-1})\omega
$$

则迭代公式为

$$
x_{k+1} = x_k - \frac{2f_k}{g \pm \sqrt{g^2 - 4f_k\omega}}
$$

**符号选择**：取「分母绝对值较大」的那个（$\pm$ 使 $\lvert g\pm\sqrt{g^2-4f_k\omega}\rvert$ 最大），保证分母不近零、迭代稳定。<span class="marginnote">分母的选择技巧：<strong>二次方程求根用「数值稳定的配方」——选使分母绝对值最大的那个根</strong>（避免「大数减小数」的相消）。这与一元二次方程的稳定求根是同一个细节。</span>

**数值例子**：$f(x)=x^3-x-1$，初值 $x_0=0,\ x_1=1,\ x_2=2$。三个点的抛物线交点给出 $x_3\approx1.33$，很快收敛到 $1.3247$——**约 5 步到 $10^{-8}$**（对比弦截约 8 步）。

## 2 收敛阶：1.84

**定理。** 若 $f$ 充分光滑、$r$ 是简单根、三个初值足够靠近，则抛物线法收敛，收敛阶为

$$
p \approx 1.8393
$$

（三次方程 $p^3=p^2+p+1$ 的唯一实根，介于弦截的 1.618 与牛顿的 2 之间）。

**公式解析：收敛阶从哪来。**

- **第一步，误差递推。** 抛物线法用三个点，误差满足三阶递推 $e_{k+1}\approx C e_k e_{k-1} e_{k-2}$（三个历史误差的乘积）。
- **第二步，设 $p$ 阶。** $|e_{k+1}|\approx C|e_k|^p$，代入递推并利用 $|e_k|\approx C|e_{k-1}|^p$、$|e_{k-1}|\approx C|e_{k-2}|^p$，得 $p$ 满足 $p^3=p^2+p+1$。
- **第三步，解方程。** 数值解 $p\approx1.8393$——**比弦截的 1.618 高，逼近牛顿的 2**。

**规律**：用 $n$ 个点拟合 $n-1$ 次多项式，收敛阶是方程 $p^n=p^{n-1}+\cdots+p+1$ 的根——弦截（2 点）$1.618$，抛物线（3 点）$1.839$，越多点越接近 2。<span class="marginnote">规律记忆：<strong>「点越多，越接近二次，但每步成本也越高」</strong>——抛物线法 3 点换 1.839，性价比在「要复根」的场景才划算。</span>

## 3 复根能力：抛物线法的独家本领

**为什么抛物线法能求复根？** 抛物线与 x 轴的交点可能是**一对共轭复根**——当判别式 $g^2-4f_k\omega<0$ 时，公式里出现 $\sqrt{\text{负数}}$，$x_{k+1}$ 自动变成复数。**三个实初值，可以收敛到复根**——这是牛顿、弦截（直线）做不到的。

**应用**：多项式求根（如求解特征方程、控制系统极点）常需复根。抛物线法配复算术，能直接从实初值「钻」进复根。<span class="marginnote">对比：<strong>牛顿与弦截用「直线」，永远停在实轴上；抛物线法用「抛物线」，能脱离实轴找到共轭复根</strong>。这使它在多项式求根器（如 MATLAB 的 `roots`、经典 `zroots`）里有一席之地。</span>

## 4 实现要点与收敛保护

```python
import cmath

def muller(f, x0, x1, x2, tol=1e-10, max_iter=100):
    x = [x0, x1, x2]
    for k in range(max_iter):
        f0, f1, f2 = f(x[-3]), f(x[-2]), f(x[-1])
        # 均差
        h1, h2 = x[-1]-x[-2], x[-2]-x[-3]
        d1 = (f2-f1)/h1 if h1 else 0
        d2 = (f1-f0)/h2 if h2 else 0
        w = (d1-d2)/(h1+h2) if (h1+h2) else 0
        g = d1 + h1*w
        disc = cmath.sqrt(g*g - 4*f2*w)
        denom = g + disc if abs(g+disc) > abs(g-disc) else g - disc
        if abs(denom) < 1e-300:
            break
        x_new = x[-1] - 2*f2/denom
        if abs(x_new - x[-1]) < tol:
            return x_new, k+1
        x.append(x_new)
    return x[-1], max_iter
```

**工程注意**：抛物线法**不保证收敛**（与弦截一样），且数值上可能除零（分母接近零）。**保护**：分母过小时取别的根/二分兜底；监测残差。**实根场景通常不首选它**——它贵（每步 3 个点）+ 不稳（无区间保证），只在「要复根」时值得。

## 5 抛物线法在求根家族中的定位

| 判据 | 二分 | 弦截 | 抛物线 | 牛顿 |
| --- | --- | --- | --- | --- |
| 拟合 | 无 | 直线（2 点） | 抛物线（3 点） | 切线（导数） |
| 收敛阶 | 1 | 1.618 | **1.839** | 2 |
| 每步 $f$ 求值 | 1 | 1 | 1（新点） | 2 |
| 复根 | 否 | 否 | **是** | 可（复域） |
| 可靠性 | 极高 | 中 | 中 | 低（发散风险高） |

**辨析｜易错点：** 抛物线法不是「更快就更好」——它的可靠性低于二分，成本高于弦截，**复根能力是它独有的价值**。实根问题默认弦截/Brent；需要复根时再上抛物线法。<span class="marginnote">工程判断：<strong>「实根靠弦截+Brent，复根找抛物线法」</strong>——把方法绑到问题形态，是求根选型的第一原则。</span>

## 6 小结

- **抛物线法**：三点拟合抛物线，求抛物线与 x 轴交点；公式 $x_{k+1}=x_k-\dfrac{2f_k}{g\pm\sqrt{g^2-4f_k\omega}}$。
- **收敛阶 1.839**：三阶误差递推 $p^3=p^2+p+1$ 的唯一实根——比弦截快、接近牛顿。
- **复根能力**：判别式 <0 时自动进入复域，可求共轭复根——独有的本领。
- 不保证收敛、有除零风险——需保护与监测；实根问题默认弦截/Brent。
- 工程定位：实根用弦截+Brent，复根用抛物线法。
