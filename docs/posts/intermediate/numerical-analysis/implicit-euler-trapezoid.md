## 为什么从隐式方法开始

显式欧拉用「当前斜率」$f(t_k,y_k)$ 推进，简单但**稳定域极小**——刚性问题（本课程最后）会让它彻底失败。**后退欧拉方法（backward Euler）** 改用「未来斜率」$f(t_{k+1},y_{k+1})$：

$$
y_{k+1} = y_k + h\,f(t_{k+1}, y_{k+1})
$$

注意 $y_{k+1}$ 出现在**两边**——它是**隐式方法**，需要每步解方程。隐式的代价是「每步更贵」，回报是**稳定性的大幅提升**。**梯形方法（trapezoidal rule）** 取两端斜率的平均，二阶且更稳定，是「隐式但不贵」的平衡点。<span class="marginnote">隐式方法的核心特征：<strong>「$y_{k+1}$ 藏在方程里，要解出来」</strong>。对线性 $f$，每步解线性方程；对非线性 $f$，每步用牛顿法迭代。这个「每步多花钱」换来的「无条件稳定」，是刚性问题的救命稻草——最后硬性问题一章会彻底展开。</span>

本节给出两个隐式方法、它们的局部截断误差与稳定性直觉。

## 1 后退欧拉方法

**后退欧拉**：$y_{k+1}=y_k+h f(t_{k+1},y_{k+1})$。

**几何**：用「右端点切线」代替「左端点切线」——右端点矩形积分。局部截断误差仍是 $O(h^2)$（一阶方法），但**误差方向与显式欧拉相反**（对凸函数高估而非低估）。

**为什么叫「隐式」？** 公式里 $y_{k+1}$ 出现在 $f$ 内部，无法直接算。求解方式：

- **线性 $f$**（如 $y'=\lambda y$）：$y_{k+1}=y_k+h\lambda y_{k+1}$ ⇒ $y_{k+1}=\dfrac{y_k}{1-h\lambda}$——闭式。
- **非线性 $f$**：每步用牛顿法解 $y_{k+1}-y_k-hf(t_{k+1},y_{k+1})=0$。

**数值例子**：$y'=y,\ y(0)=1$，$h=0.1$。$y_1=\dfrac{1}{1-0.1}=1.111$（$e^{0.1}=1.105$——这次**高估**）。显式欧拉给 $1.1$（低估）——**两个一阶方法从两侧逼近真值**。

## 2 梯形方法：两端斜率的平均

**梯形方法（隐式梯形）**：

$$
y_{k+1} = y_k + \frac{h}{2}\left(f(t_k,y_k) + f(t_{k+1},y_{k+1})\right)
$$

**几何**：用两端斜率的平均——对应数值积分的**梯形公式**。局部截断误差 $O(h^3)$，**整体二阶**——比欧拉（一阶）高一个量级，且仍是隐式（稳定）。

**数值例子**：$y'=y,\ y(0)=1$，$h=0.1$：

$$
y_1 = 1+\frac{0.1}{2}(1+y_1) \Rightarrow y_1=\frac{1.05}{0.95}=1.10526 \quad (e^{0.1}=1.10517)
$$

**误差 $9\times10^{-5}$——比欧拉（$5\times10^{-3}$）好两个数量级**，且这是二阶方法的体现。<span class="marginnote">梯形方法的「魔法」：<strong>把两端斜率平均，误差里的 $y''$ 项对称相消，只剩下 $y'''$ 项——从一阶跳到二阶</strong>。这和辛普森公式「对称性白送精度」是同一种机制。</span>

## 3 公式解析：梯形方法的局部截断误差

**定理。** 梯形方法局部截断误差

$$
\tau_{k+1} = y(t_{k+1}) - \hat{y}_{k+1} = -\frac{h^3}{12}\,y'''(\xi)
$$

**整体二阶。**

- **第一步，展开两端。** $y(t_{k+1})=y(t_k)+hy'+\dfrac{h^2}{2}y''+\dfrac{h^3}{6}y'''+\cdots$；$f(t_{k+1},y(t_{k+1}))=y'(t_k)+hy''+\dfrac{h^2}{2}y'''+\cdots$。
- **第二步，梯形组合。** $\hat{y}_{k+1}=y(t_k)+\dfrac{h}{2}(y'+ (y'+hy''+\cdots))=y+hy'+\dfrac{h^2}{2}y''+\cdots$。
- **第三步，相减。** 平方项 $h^2y''/2$ 精确相消，剩 $-\dfrac{h^3}{12}y'''$——**$O(h^3)$，二阶方法**。

**关键洞察：隐式性贡献了「平均」，平均贡献了「相消」**——梯形方法既稳（隐式）又准（二阶），是「隐式不亏」的典范。

## 4 稳定性直觉：隐式为什么更稳

对试验方程 $y'=\lambda y$（$\lambda<0$，真实解衰减到 0）：

| 方法 | 迭代 | 稳定性条件 |
| --- | --- | --- |
| 显式欧拉 | $y_{k+1}=(1+h\lambda)y_k$ | $|1+h\lambda|<1$ ⇒ $h<-\dfrac{2}{\lambda}$（有限） |
| 后退欧拉 | $y_{k+1}=\dfrac{y_k}{1-h\lambda}$ | $|1-h\lambda|^{-1}<1$ 恒成立（$\lambda<0$）⇒ **无条件** |
| 梯形 | $y_{k+1}=\dfrac{1+h\lambda/2}{1-h\lambda/2}y_k$ | $|(1+h\lambda/2)/(1-h\lambda/2)|<1$ 恒成立（$\lambda<0$）⇒ **无条件** |

**后退欧拉与梯形对 $\lambda<0$ 无条件稳定**——无论步长多大，数值解都衰减（不振荡爆炸）。显式欧拉只在 $h<2/|\lambda|$ 时稳定——**步长受稳定域限制**。<span class="marginnote">这就是刚性问题（$\lambda$ 很大负）的症结：显式方法要求 $h\le2/|\lambda|$ 极小，而解本身变化平缓——<strong>「解要慢，步长却被迫极小」，步数爆炸</strong>。隐式方法绕开稳定域，大步长也能稳定——代价是每步解方程。</span>

## 5 实现：线性与非线性情形

```python
def backward_euler_linear(lam, y0, h, n):
    """y' = lam*y 的后退欧拉（线性，闭式解）"""
    y, ys = y0, [y0]
    for _ in range(n):
        y = y / (1 - h*lam)
        ys.append(y)
    return ys

def backward_euler_general(f, t0, y0, h, n, tol=1e-12):
    """一般 f 的后退欧拉（每步牛顿迭代）"""
    from scipy.optimize import newton
    t, y = t0, y0
    ys = [y0]
    for k in range(n):
        t_next = t + h
        F = lambda yy: yy - y - h*f(t_next, yy)
        y = newton(F, y)          # 牛顿解隐式方程
        t = t_next
        ys.append(y)
    return ys
```

**工程注意**：非线性隐式方法每步要迭代（牛顿），**成本高**——但刚性问题上，稳定域带来的收益远超成本。现代库（`solve_ivp` 的 BDF/LSODA）在检测刚性时自动切隐式。

## 6 小结

- **后退欧拉**：$y_{k+1}=y_k+h f(t_{k+1},y_{k+1})$——一阶、隐式、无条件稳定（$\lambda<0$）。
- **梯形方法**：$y_{k+1}=y_k+\dfrac{h}{2}(f_k+f_{k+1})$——**二阶**、隐式、无条件稳定。
- 梯形局部截断误差 $-\dfrac{h^3}{12}y'''$：两端斜率平均使 $y''$ 项相消。
- **隐式性换稳定性**：每步解方程，但步长不再受稳定域限制——刚性问题解药。
- 显式欧拉稳定域 $h<2/|\lambda|$，隐式无条件——「解要慢但步长被迫极小」的刚性困境由此展开。

在下一节，我们把「预测 + 校正」思想实体化：**改进的欧拉方法与预测-校正格式**——用显式预测、隐式修正，低成本获得二阶精度。
