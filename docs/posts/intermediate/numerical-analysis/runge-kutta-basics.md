## 为什么从龙格-库塔基本思想开始

改进欧拉用「两个斜率平均」达到二阶。**龙格-库塔方法（Runge-Kutta methods）** 把这个思想一般化：**在步长内采样多个斜率（$s$ 个），加权组合**，得到任意高阶的显式方法。RK4（经典四阶）是工程默认，但它的设计思想——「采样斜率、加权组合、泰勒匹配」——是理解全部 RK 家族的钥匙。<span class="marginnote">龙格（Runge，1856—1927）1895 年给出二阶 RK，海涅（Heun）1900 年推广，卡尔·龙格的学生库塔（Kutta，1867—1944）1901 年给出四阶公式。<strong>「RK」两个字母是对这两位数值分析先驱的纪念</strong>——我们在龙格现象与数值微分章节已见过龙格的名字。</span>

本节建立 RK 的统一框架、加权条件，以及「为什么采样越多阶越高」的机制。

## 1 一般形式：s 级 RK

**s 级显式 RK 方法**：

$$
k_1 = f(t_k, y_k)
$$

$$
k_2 = f(t_k + c_2h,\ y_k + h a_{21}k_1)
$$

$$
k_3 = f(t_k + c_3h,\ y_k + h(a_{31}k_1 + a_{32}k_2))
$$

$$
\vdots
$$

$$
k_s = f\left(t_k + c_sh,\ y_k + h\sum_{j=1}^{s-1}a_{sj}k_j\right)
$$

$$
y_{k+1} = y_k + h\sum_{i=1}^{s} b_i k_i
$$

**结构**：$k_i$ 是「$i$ 号采样斜率」（在步长内不同位置、用已算斜率的组合预测的 $y$ 处计算）；最终用权重 $b_i$ 加权组合。**系数矩阵（Butcher 表）决定方法**：

| $c_2$ | | |
| $c_3$ | $a_{31}$ | $a_{32}$ |
| $\vdots$ | | |
| $c_s$ | $\cdots$ | |
| --- | --- | --- |
| | $b_1$ | $\cdots$ | $b_s$ |

**Butcher 表**是 RK 方法的「身份证」——给定表，方法完全确定。

## 2 核心思想：泰勒匹配

RK 方法的设计目标：让加权组合 $y_k+h\sum b_ik_i$ 的泰勒展开与真解 $y(t_{k+1})$ 的泰勒展开**匹配到尽可能高的阶**。

**公式解析：为什么匹配决定阶。**

- **第一步，展开真解。** $y(t_{k+1})=y+hy'+\dfrac{h^2}{2}y''+\dfrac{h^3}{6}y'''+\cdots$，其中 $y'=f,\ y''=f_t+f_yf,\ y'''=\cdots$（链式法则展开）。
- **第二步，展开 RK 组合。** $\sum b_ik_i$ 的泰勒展开含参数 $a_{ij},c_i,b_i$。逐阶与真解比较。
- **第三步，匹配条件。** 要二阶，需 $\sum b_i=1,\ \sum b_ic_i=\tfrac12$ 等条件；要更高阶，更多条件（如三阶需 8 个条件、四阶需 11 个条件）。

**每个阶数对应一组「阶条件（order conditions）」**——RK 方法的阶越高，Butcher 表参数被约束得越紧。

**关键事实**：**$s$ 级显式 RK 的最高阶是 $s$**（$s=1,2,3,4$ 时最高阶 $=s$；$s\ge5$ 时最高阶小于 $s$，因为阶条件数超过自由参数数）。**RK4 是「每级一阶」的甜蜜点**——四级 RK 达到四阶，五级以上效率下降。

## 3 二阶 RK 家族：一个自由度

二阶 RK 的一般形式（$s=2$）：

$$
k_1 = f(t_k,y_k), \qquad k_2 = f(t_k+c_2h,\ y_k+h c_2 k_1)
$$

$$
y_{k+1} = y_k + h\left((1-\lambda)k_1 + \lambda k_2\right)
$$

**一个自由参数 $\lambda$**，不同取值给出不同二阶方法：

| $\lambda$ | 方法 | 名称 |
| --- | --- | --- |
| $1/2$ | $y_k+\tfrac{h}{2}(k_1+k_2)$ | 改进欧拉（Heun） |
| $1$ | $y_k+h k_2$（$c_2=1$） | 中点法（改进多边形） |
| $2/3$ | Ralston 方法 | 优化常数 |

**二阶 RK 是一族方法，不是单个**——改进欧拉只是其中 $\lambda=1/2$ 的特例。<span class="marginnote">认识这个家族很重要：<strong>「RK 不是一种方法，而是一个方法族」</strong>——不同 Butcher 表给出不同方法，但共享「采样斜率 + 加权组合」的骨架。三阶、四阶 RK 同样是一族（下节给代表）。</span>

## 4 为什么 RK 是工程主力

RK 方法的优点：

1. **显式**：无需解方程，每步只算 $f$。
2. **自起步**：不需要额外初值（对比多步法）。
3. **自适应容易**：步长随时可调（对比多步法）。
4. **精度可控**：$s$ 级换 $s$ 阶（$s\le4$）。

**代价**：每步算 $s$ 次 $f$——比多步法贵，但换来实现简单与稳定性改善。

**对比预告**：多步法（Adams）每步算 1 次 $f$ 也能高阶——但需要起步、难自适应。**「RK 的简单 vs Adams 的高效」**是下一章的核心权衡。

## 5 实现骨架

```python
def rk4(f, t0, y0, h, n):
    """经典四阶 RK：y_{k+1} = y_k + h/6·(k1 + 2k2 + 2k3 + k4)。"""
    t, y = t0, y0
    for _ in range(n):
        k1 = f(t, y)
        k2 = f(t + h/2, y + h/2 * k1)
        k3 = f(t + h/2, y + h/2 * k2)
        k4 = f(t + h, y + h * k3)
        y += h / 6 * (k1 + 2*k2 + 2*k3 + k4)
        t += h
    return y

# 例：y' = y, y(0) = 1 → y(1) = e ≈ 2.718281828
print(rk4(lambda t, y: y, 0.0, 1.0, 0.1, 10))   # ≈ 2.71827974，误差约 2×10⁻⁶
```

**工程注意**：Butcher 表是实现与查阅 RK 方法的标准语言——**看懂表 = 会实现任何 RK 方法**。MATLAB 的 ode45 用的就是带嵌入式误差估计的 RK 表。

## 6 小结

- **RK 方法**：在步长内采样 $s$ 个斜率 $k_i$，加权组合 $y_{k+1}=y_k+h\sum b_ik_i$。
- **Butcher 表**（$c,a,b$）是方法的「身份证」——给定表即定方法。
- **泰勒匹配**决定阶：$s$ 级显式 RK 最高 $s$ 阶（$s\le4$），由阶条件约束。
- 二阶 RK 是一族（改进欧拉、中点法、Ralston 是不同参数的特例）。
- RK 显式、自起步、易自适应——工程默认；代价是每步多次 $f$ 求值。
