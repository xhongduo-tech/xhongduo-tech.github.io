## 为什么从 Adams 预测-校正系统开始

Adams-Moulton（隐式）又准又稳，但每步要解隐式方程；Adams-Bashforth（显式）便宜，但精度与稳定性逊色。**预测-校正系统（predictor-corrector, PECE）** 把两者组合：**用 AB 预测 $y_{k+1}^{(p)}$，再用 AM 校正一次**——不迭代、不解方程，同时拿到「显式的便宜」与「隐式的精度」。这是工程上使用多步法的标准姿势（MATLAB `ode113` 的祖先）。<span class="marginnote">预测-校正的精髓：<strong>「校正器不必迭代——预测器已经够好，校正一次就把阶提上去」</strong>。改进欧拉是 PECE 的特例（AB1 预测 + AM2 校正）。这里把「猜修」做到高阶，是多步法最优雅的工程形态。</span>

本节给出经典的 AB-AM PECE 格式、阶分析（为什么校正一次就升阶）与工程收益。

## 1 经典 PECE：AB4 + AM4

**PECE（Predict-Evaluate-Correct-Evaluate）四步**：

1. **P（预测）**：用 AB4 预测 $\tilde{y}_{k+1}=y_k+\dfrac{h}{24}(55f_k-59f_{k-1}+37f_{k-2}-9f_{k-3})$。
2. **E（求值）**：$\tilde{f}_{k+1}=f(t_{k+1},\tilde{y}_{k+1})$。
3. **C（校正）**：用 AM4 校正 $y_{k+1}=y_k+\dfrac{h}{24}(9\tilde{f}_{k+1}+19f_k-5f_{k-1}+f_{k-2})$。
4. **E（求值）**：$f_{k+1}=f(t_{k+1},y_{k+1})$（供下一步用）。

**每步只算两次 $f$**（E 与 E），却达到**四阶**——比 RK4 的四次求值省一半。<span class="marginnote">注意结构：<strong>「P-E-C-E」四个字母是工程节奏——预测、求值、校正、再求值</strong>。最后一次 E 不是为了当前步，而是为下一步准备 $f_{k+1}$。这个「为下一步做准备」的细节，是多步法工程的标志。</span>

**数值例子**：$y'=y$，$h=0.1$。AB4 预测 + AM4 校正一步后，误差约 $10^{-7}$ 量级（四阶）；且 AM4 的校正把 AB4 的误差再压一个量级。

## 2 公式解析：为什么校正一次就升阶

关键理论结果：**AB$r$ 预测（$r$ 阶）+ AM$r$ 校正（$r$ 阶）的 PECE 整体仍是 $r$ 阶，且误差常数大幅改善。**

- **第一步，预测误差。** 预测值 $\tilde{y}_{k+1}$ 与真值差 $O(h^{r+1})$（AB 的局部误差）。
- **第二步，预测值进校正器。** AM 校正器的公式是「$f_{k+1}$ 的线性组合」；预测值带入使 $\tilde{f}_{k+1}$ 与 $f(t_{k+1},y(t_{k+1}))$ 差 $O(h^{r+1})$。
- **第三步，AM 本身是 $r$ 阶。** AM 对真值精确到 $O(h^{r+2})$；预测值的 $O(h^{r+1})$ 误差被 $h\beta$ 因子压成 $O(h^{r+2})$——**校正一次保持 $r$ 阶，误差常数从 AB 的「大」变 AM 的「小」**。

**结论：PECE 的阶 = 校正器的阶（也 = 预测器的阶），但误差常数接近校正器**——「预测器的粗糙被校正器的精确覆盖」。

**PECE 的误差估计（免费福利）**：预测值与校正值之差提供了**局部误差估计**：

$$
y_{k+1} - \tilde{y}_{k+1} \approx \frac{\gamma_r}{(\text{常数})}\,h^{r+1}y^{(r+1)}
$$

**这个差是「免费误差传感器」**——可用于步长控制（变步长 Adams 的机制）。<span class="marginnote">工程亮点：<strong>「PECE 白送误差估计」</strong>——预测值 $\tilde y$ 与校正值 $y$ 的差，就是局部误差的近似（因为两者阶相同、误差常数不同）。这使变步长多步法不用额外算嵌入对——<code>ode113</code> 的步长控制正是基于此。</span>

## 3 预测-校正 vs 纯隐式

| 判据 | 纯 AM（隐式） | PECE（AB+AM） | 纯 AB（显式） |
| --- | --- | --- | --- |
| 每步 $f$ 求值 | 迭代求解（贵） | 2 次 | 1 次 |
| 阶 | $r$ | $r$ | $r$ |
| 稳定性 | 最好 | 好 | 差 |
| 误差常数 | 最小 | 中 | 最大 |
| 工程 | 刚性 | **通用默认** | 很少单独用 |

**工程结论：PECE 是「精度/成本/稳定」的甜蜜点**——除非刚性（用纯隐式 BDF），否则 PECE 是 Adams 家族的默认形态。

## 4 实现

```python
import numpy as np

def ab4_am4_pece(f, t0, y0, h, n):
    """Adams PECE：AB4 预测 + AM4 校正，每步两次函数求值。"""
    # 起步：用 RK4 生成前 4 个历史点
    ts, ys = [t0], [y0]
    for _ in range(3):
        k1 = f(ts[-1], ys[-1])
        k2 = f(ts[-1] + h/2, ys[-1] + h/2 * k1)
        k3 = f(ts[-1] + h/2, ys[-1] + h/2 * k2)
        k4 = f(ts[-1] + h, ys[-1] + h * k3)
        ys.append(ys[-1] + h/6 * (k1 + 2*k2 + 2*k3 + k4))
        ts.append(ts[-1] + h)
    fs = [f(t, y) for t, y in zip(ts, ys)]

    for _ in range(n - 3):
        # P：AB4 预测
        yp = ys[-1] + h/24 * (55*fs[-1] - 59*fs[-2] + 37*fs[-3] - 9*fs[-4])
        fp = f(ts[-1] + h, yp)                 # E：预测点求值
        # C：AM4 校正
        y = ys[-1] + h/24 * (9*fp + 19*fs[-1] - 5*fs[-2] + fs[-3])
        ts.append(ts[-1] + h)
        ys.append(y)
        fs.append(f(ts[-1], y))                # E：为下一步准备
    return np.array(ts), np.array(ys)
```

**工程注意**：起步需要前 4 个 $y$（用 RK4 填），步长变化需重新插值历史——**多步法的工程复杂度在此**。现代库（SciPy 的 LSODA 方法、MATLAB 的 `ode113`）把这些细节封装好，用户只需选方法。

## 5 辨析：PECE 何时失效

**辨析｜易错点：** PECE 的预测-校正只校正**一次**——若预测值很差（步长太大、解变化剧烈），一次校正不够，误差仍偏大。**此时要么缩小步长，要么迭代校正多次（逼近纯隐式）**。另外，PECE **不改变阶**（预测与校正同阶）——「校正」改善误差常数而非阶，别指望校正能「免费升阶」。（校正器阶比预测器高时才能升阶，但这很罕见。）<span class="marginnote">一句话：<strong>「PECE 的校正修常数、不修阶」</strong>——它让误差从 AB 的水平降到 AM 的水平，但阶由两者中较低的（通常相同）决定。理解这一点，就不会对 PECE 抱不切实际的期待。</span>

## 6 小结

- **PECE 四步**：P（AB 预测）→ E（求值）→ C（AM 校正）→ E（求值备下步）——每步 2 次 $f$。
- **阶 = 预测/校正的阶**，误差常数接近校正器（AM）——「预测的粗糙被校正覆盖」。
- **免费误差估计**：预测值 − 校正值 ≈ 局部误差——变步长多步法的传感器。
- PECE 是 Adams 的通用默认（精度/成本/稳定折中）；纯隐式留给刚性。
- 校正修常数不修阶；预测太差时需缩步长或迭代校正。
