## 为什么从埃特肯加速开始

线性收敛的迭代（$\varphi'(r)\neq0$）每秒只加固定位数——慢。**埃特肯 Δ² 方法（Aitken's Δ² method）** 用三个连续迭代值「外推」出一个更好的近似，**不改变迭代本身，只改变如何读结果**。进一步，把外推「嵌入」每次迭代，得到**斯特芬森迭代（Steffensen's method）**——它把线性收敛的不动点迭代改造成**二次收敛**，且不需要导数！这是「外推」思想在求根领域的又一次胜利（龙贝格那里已经见过一次）。<span class="marginnote">外推的通用模式：<strong>「两个（或三个）近似值，按误差结构线性组合，消去低阶项」</strong>。理查森外推消 $h^2$ 项，埃特肯外推消「线性误差项」——同一个配方，不同场景。这个思想贯穿整个数值分析，值得单独咀嚼。</span>

本节给出埃特肯公式、斯特芬森迭代与它们的收敛阶分析。

## 1 埃特肯 Δ² 方法

设线性收敛迭代 $x_{k+1}=\varphi(x_k)$，$e_k\approx C^k e_0$（误差按几何比 $C$ 衰减）。相邻三次迭代 $x_k,x_{k+1},x_{k+2}$ 中，根 $r$ 大致满足等比插值关系，解出：

$$
r \approx x_k - \frac{(x_{k+1}-x_k)^2}{x_{k+2}-2x_{k+1}+x_k}
$$

记 $\Delta x_k=x_{k+1}-x_k$（一阶差分）、$\Delta^2x_k=x_{k+2}-2x_{k+1}+x_k$（二阶差分），则**埃特肯公式**

$$
\boxed{\,r \approx \hat{x}_k = x_k - \frac{(\Delta x_k)^2}{\Delta^2 x_k}\,}
$$

**名字的由来**：Δ² 是二阶差分——公式就是「$x_k$ 减去一阶差分的平方除以二阶差分」。

**公式解析：为什么这样外推。**

- **第一步，设误差几何比。** 线性收敛时 $\dfrac{r-x_{k+1}}{r-x_k}\approx\dfrac{r-x_{k+2}}{r-x_{k+1}}\approx C$（相邻误差比恒定）。
- **第二步，解等比方程。** 由 $\dfrac{r-x_{k+1}}{r-x_k}=\dfrac{r-x_{k+2}}{r-x_{k+1}}$ 解出 $r$，交叉相乘整理得 $r\approx x_k-\dfrac{(\Delta x_k)^2}{\Delta^2 x_k}$。
- **第三步，误差结构。** $\hat{x}_k$ 对线性误差「免疫」——消去了主线性项，误差从 $O(C^k)$ 变成 $O(C^{2k})$，**收敛阶翻倍**。

**数值例子**：$x=\sqrt[3]{x+1}$（$|\varphi'(r)|\approx0.19$，线性收敛）。

| $k$ | $x_k$（迭代） | $\hat{x}_k$（埃特肯） |
| --- | --- | --- |
| 0 | 1.0000 | — |
| 1 | 1.2599 | — |
| 2 | 1.3123 | 1.3240 |
| 3 | 1.3224 | 1.3247 |

3 步迭代 + 外推就达到 $10^{-4}$，而纯迭代要 15 步以上——**外推免费提速**。

## 2 斯特芬森迭代：把加速嵌入循环

埃特肯是「事后」处理（跑几步再外推）；**斯特芬森迭代（Steffensen's method）** 把外推「嵌入」每一步，每次迭代用三个函数值：

$$
y_k = \varphi(x_k), \qquad z_k = \varphi(y_k), \qquad x_{k+1} = x_k - \frac{(y_k-x_k)^2}{z_k-2y_k+x_k}
$$

即每步算两次 $\varphi$，再套埃特肯公式得新近似。**斯特芬森迭代是二次收敛的**（对 $\varphi'(r)\neq1$ 的简单不动点），而且**不需要导数**——这是它与牛顿法平起平坐的资本。

**关键区别**：斯特芬森**替代**原迭代（每步都外推），埃特肯**补强**原迭代（迭代照跑、结果外推）。<span class="marginnote">记忆：<strong>「埃特肯是事后诸葛亮，斯特芬森是随时外推」</strong>——前者不动迭代本身，后者把每次迭代都换成了「迭代 + 外推」。斯特芬森每步两次函数求值换二次收敛，性价比极高。</span>

## 3 收敛阶分析：为什么斯特芬森是二次的

设 $x_k$ 逼近不动点 $r$，误差 $e_k$。

**第一步，写出三值。** $y_k=\varphi(x_k)$，误差 $e_k^{(y)}\approx\varphi'(r)e_k+\cdots$；$z_k=\varphi(y_k)$，误差 $\approx\varphi'(r)^2e_k+\cdots$。
**第二步，套埃特肯。** 埃特肯公式消线性项，剩下 $e_{k+1}\approx\dfrac{\varphi''(r)}{2}\,e_k^2\cdot(\text{组合系数})$——**二次项主导**。
**第三步，收敛阶。** $|e_{k+1}|\le C|e_k|^2$——**二次收敛**。

**对比牛顿法**：牛顿法每步 2 次求值（$f$ 与 $f'$），二次收敛；斯特芬森每步 2 次求值（$\varphi$ 两次），也二次收敛。**两者「效率指数」相当，但斯特芬森不需要算导数**——这就是它的价值。<span class="marginnote">效率对照：<strong>牛顿「二次收敛但每步要导数」，斯特芬森「二次收敛且免导数」</strong>——在导数难算或不可得时（黑箱函数），斯特芬森是牛顿的完美替身。它是「免导数牛顿法」的经典代表。</span>

## 4 实现与适用边界

```python
def steffensen(phi, x0, tol=1e-10, max_iter=100):
    """斯特芬森迭代：每步两次 φ 求值，套埃特肯公式，二次收敛且免导数。"""
    x = x0
    for _ in range(max_iter):
        y = phi(x)
        z = phi(y)
        denom = z - 2*y + x                 # Δ²x
        if abs(denom) < 1e-15:              # 防止除零（奇异不动点）
            break
        x_new = x - (y - x)**2 / denom      # 埃特肯公式
        if abs(x_new - x) < tol:
            return x_new
        x = x_new
    return x

# 例：x = (x+1)^(1/3)，根 ≈ 1.32472，两步即到 10⁻¹⁰ 量级
print(steffensen(lambda x: (x + 1) ** (1/3), 1.0))
```

**适用边界**：

| 情形 | 行为 |
| --- | --- |
| $\varphi'(r)\neq1$（简单不动点） | 二次收敛 |
| $\varphi'(r)=1$（奇异不动点） | 降速或失败（分母 $\Delta^2x\to0$） |
| 重根 | 需要修正 |

**辨析｜易错点：** 埃特肯公式分母 $\Delta^2x_k$ 接近零时（如已接近根），外推不稳定——**数值上要防止除零**。且斯特芬森要求 $\varphi$ 足够光滑，$\varphi'(r)\neq1$。**「外推不是万能的：对奇异不动点（$\varphi'(r)=1$）外推会失败**。<span class="marginnote">工程提示：<strong>埃特肯/斯特芬森适合「迭代本身线性收敛且 $\varphi$ 便宜」</strong>的场景。若 $\varphi$ 计算贵，每步两次求值的代价可能抵消二次收敛的收益——先算效率指数再决定。</span>

## 5 小结

- **埃特肯 Δ² 方法**：$\hat{x}_k=x_k-\dfrac{(\Delta x_k)^2}{\Delta^2x_k}$，用三个迭代值外推，线性收敛变「双倍速」。
- 原理：线性收敛的误差按等比衰减，外推消去主线性项。
- **斯特芬森迭代**：每步 $y=\varphi(x)$、$z=\varphi(y)$、再套埃特肯——**二次收敛且免导数**。
- 埃特肯「事后外推」、斯特芬森「随时外推」——一个不动迭代、一个嵌入迭代。
- 适用：$\varphi$ 便宜 + 简单不动点；$\varphi'(r)=1$ 或重根时需谨慎。

在下一节，我们进入求根家族的「天王」：**牛顿迭代法（Newton's method）及其局部收敛性**——用切线逼近根，二次收敛，但需要导数且可能发散。
