## 为什么从不动点迭代开始

求根 $f(x)=0$ 有个巧妙的改写：**把它变成 $x=\varphi(x)$**——根 $r$ 是 $\varphi$ 的**不动点**（$\varphi(r)=r$）。然后从一个初值出发，反复代入：

$$
x_{k+1} = \varphi(x_k)
$$

**这就是不动点迭代（fixed-point iteration）**。它的价值不止在于「又一种方法」——它是求根方法的统一框架：牛顿法、弦截法、迭代加速都是不动点迭代的**特例**。理解不动点，就理解了整个求根家族的共同骨架。<span class="marginnote">不动点思想是数学的通用工具：<strong>压缩映射原理（Banach 不动点定理）不仅证明解存在，还给出收敛性与误差界</strong>。从方程求根到微分方程初值问题（Picard 迭代）、再到深度学习里求解不动点，这套思想无处不在。</span>

本节给出不动点迭代、收敛的几何直觉与压缩映射条件。

## 1 改写与迭代

把 $f(x)=0$ 改写为 $x=\varphi(x)$ 有多种方式：

- $f(x)=x^3-x-1=0$：可改写为 $x=\sqrt[3]{x+1}$ 或 $x=x^3-1$ 或 $x=\dfrac{x^3-1}{x}$……

**同一方程的根，不同的 $\varphi$，收敛性天差地别**——这是不动点迭代最重要的教训：**改写的选择决定成败**。

**不动点迭代**：初值 $x_0$，迭代 $x_{k+1}=\varphi(x_k)$，若收敛到 $r$，则 $r=\varphi(r)$（连续性），即 $f(r)=0$——**极限就是根**。

**数值例子**：对 $x=\sqrt[3]{x+1}$，取 $x_0=1$：

$$
x_1=\sqrt[3]{2}=1.26, \quad x_2=\sqrt[3]{2.26}=1.31, \quad x_3=1.32, \dots \to 1.3247
$$

**收敛**。但若改写为 $x=x^3-1$，取 $x_0=1.5$：$x_1=2.375$，$x_2=12.4$，$x_3=1900$——**爆炸发散**。<span class="marginnote">同一个根，两个改写，一个收敛一个发散——<strong>「改写」不是形式游戏，而是决定生死的选择</strong>。下一节会给出「什么时候收敛」的严格判据（$|\varphi'(r)|<1$）。</span>

## 2 几何直觉：蛛网图

不动点迭代的几何是**蛛网图（cobweb diagram）**：交替使用「竖直投影到曲线 $y=\varphi(x)$」与「水平投影到直线 $y=x$」。

从 $(x_0,0)$ 出发：竖直打到曲线得 $(x_0,\varphi(x_0))$ → 水平打到直线得 $(\varphi(x_0),\varphi(x_0))=(x_1,x_1)$ → 竖直打回曲线 → ……——**每一步把 $x$ 更新为 $\varphi(x)$**。

**收敛**：曲线在不动点附近比直线 $y=x$ 平缓（$|\varphi'(r)|<1$），蛛网「螺旋/阶梯」收向交点。
**发散**：曲线比直线陡峭（$|\varphi'(r)|>1$），蛛网越跑越远。<span class="marginnote">画蛛网图是理解不动点迭代最快的途径：<strong>「平缓收敛、陡峭发散」</strong>——曲线在交点处的斜率决定命运。$|\varphi'(r)|<1$ 收敛（斜率平缓），$>1$ 发散（斜率陡峭）。</span>

## 3 公式解析：收敛条件（预告与直觉）

不动点迭代收敛的严格判据是**压缩映射定理**：若 $\varphi$ 在 $[a,b]$ 上把区间映到自身，且

$$
|\varphi'(x)| \le L < 1, \qquad \forall x\in[a,b]
$$

则 $\varphi$ 在 $[a,b]$ 内有**唯一**不动点 $r$，且迭代 $x_{k+1}=\varphi(x_k)$ 从任意 $x_0\in[a,b]$ 出发收敛到 $r$。

**误差估计（预告）**：

$$
|x_{k}-r| \le \frac{L}{1-L}|x_k-x_{k-1}|, \qquad |x_k-r|\le\frac{L^k}{1-L}|x_1-x_0|
$$

**为什么 $|\varphi'|<1$ 就够了？**

- **第一步，中值定理。** $|x_{k+1}-r|=|\varphi(x_k)-\varphi(r)|\le|\varphi'(\xi)||x_k-r|\le L|x_k-r|$。
- **第二步，压缩。** 每步误差乘 $\le L<1$，误差几何级数收缩到 0——收敛。
- **第三步，局部版。** 只要 $|\varphi'(r)|<1$（在根处），就能选一个含根的小区间满足压缩条件——**局部收敛**。$|\varphi'(r)|>1$ 则局部发散。

**对 $x=\sqrt[3]{x+1}$**：$\varphi'(x)=\dfrac{1}{3(x+1)^{2/3}}$，在根 $r\approx1.3247$ 处 $\varphi'(r)\approx\dfrac{1}{3\times(2.3247)^{2/3}}\approx0.19<1$——收敛。对 $x=x^3-1$：$\varphi'(r)=3r^2\approx5.26>1$——发散。

## 4 收敛阶：线性

不动点迭代的收敛阶由 $|\varphi'(r)|$ 决定：

- $0<|\varphi'(r)|<1$：**线性收敛**，误差比 $L$。
- $|\varphi'(r)|=0$：可能更高阶（至少二阶）——**「导数为零」的迭代点可以加速**。

**收敛阶公式**：设 $\varphi$ 在 $r$ 处 $p$ 阶导数为零（$p\ge1$），则迭代 $p$ 阶收敛。**这是后文埃特肯加速与牛顿法（$p=2$）的理论基础**。<span class="marginnote">一句话：<strong>「不动点迭代的速度，写在 $\varphi'(r)$ 里」</strong>——$|\varphi'|<1$ 保命（收敛）、$=0$ 加速（高阶）、$>1$ 送命（发散）。牛顿法之所以二次收敛，正是因为它构造的 $\varphi$ 满足 $\varphi'(r)=0$。</span>

## 5 实现与终止

```python
def fixed_point(phi, f, x0, tol=1e-10, max_iter=200):
    """不动点迭代 x_{k+1}=φ(x_k)：终止同时检查相邻差与残差 |f(x)|。"""
    x = x0
    for _ in range(max_iter):
        x_new = phi(x)
        if abs(x_new - x) < tol and abs(f(x_new)) < tol:   # 双保险
            return x_new
        x = x_new
    return x

# 例：f(x) = x³ - x - 1 = 0，改写为 x = (x+1)^(1/3)，根 ≈ 1.32472
f = lambda x: x**3 - x - 1
phi = lambda x: (x + 1) ** (1/3)
print(fixed_point(phi, f, 1.0))                 # ≈ 1.32472
```

**终止准则**：相邻差 $|x_{k+1}-x_k|$ 小（注意：$\varphi'$ 接近 1 时相邻差会「假收敛」，需用 $\dfrac{L}{1-L}$ 修正或检查 $|f(x)|$）。**发散检测**：相邻差暴增或超出预设范围，立即停止。

**辨析｜易错点：** 相邻差小 ≠ 收敛（$L$ 接近 1 时误差比相邻差大很多）。**同时检查「相邻差」与「$|f(x)|$」**——前者看迭代稳定，后者看是否真接近根。

## 6 小结

- **不动点迭代**：$f(x)=0$ 改写为 $x=\varphi(x)$，迭代 $x_{k+1}=\varphi(x_k)$，极限即根。
- **改写选择决定成败**：同一方程不同 $\varphi$，一个收敛一个发散。
- **收敛判据**（压缩映射）：$|\varphi'(x)|\le L<1$ ⇒ 唯一不动点 + 收敛；局部判据 $|\varphi'(r)|<1$。
- 收敛阶线性（比 $L$），$|\varphi'(r)|=0$ 时高阶——牛顿法的来源。
- 蛛网图：平缓收敛、陡峭发散；终止看相邻差 + $|f(x)|$ 双保险。
