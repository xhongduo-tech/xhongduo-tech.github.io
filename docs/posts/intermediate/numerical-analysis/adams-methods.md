## 为什么从线性多步法开始

RK 方法每步算 $s$ 次 $f$——贵。但**信息不是每步都从零开始**：$y'=f$ 告诉我们 $y(t)$ 是 $f$ 的积分，而积分可以用**已算过的多个斜率**外推。**线性多步法（linear multistep methods）** 用历史多步的 $f$ 值构造高精度积分，**每步只算一次 $f$**——以「起步麻烦 + 零稳定性需检查」为代价，换来每步效率。**阿当姆斯方法（Adams methods）** 是最常用的线性多步法。<span class="marginnote">线性多步法的一般形式：$y_{k+1}=\sum_{j=0}^{r}\alpha_j y_{k-j}+h\sum_{j=-1}^{r}\beta_j f_{k-j}$。<strong>阿当姆斯方法取「纯积分型」（$y$ 项只用 $y_k$），用多项式插值 $f$ 再积分</strong>——它是「插值 + 求积」在 ODE 上的直接应用，与前面插值/求积章节血脉相连。</span>

本节给出 Adams-Bashforth（显式）与 Adams-Moulton（隐式）格式，以及它们的阶。

## 1 思想：积分 f 的插值多项式

$y(t_{k+1})=y(t_k)+\int_{t_k}^{t_{k+1}}f(t,y(t))\,dt$。若已有多个斜率的近似值 $f_j=f(t_j,y_j)$，**用多项式插值这些 $f$ 值，再积分**，得到 Adams 公式。

**Adams-Bashforth（显式）**：用 $f_k,f_{k-1},\dots,f_{k-r}$（历史斜率，$r+1$ 个点）插值，外推到 $[t_k,t_{k+1}]$ 积分——**$y_{k+1}$ 不依赖 $f_{k+1}$**（显式）。
**Adams-Moulton（隐式）**：用 $f_{k+1},f_k,\dots$（含未来斜率 $f_{k+1}$）插值——**$y_{k+1}$ 依赖 $f_{k+1}$**（隐式）。

## 2 阿当姆斯显式格式：Adams-Bashforth

**r+1 步 Adams-Bashforth（AB）**，用 $f_k,\dots,f_{k-r}$：

**AB1**（$r=0$）：$y_{k+1}=y_k+h f_k$——**就是显式欧拉**，一阶。
**AB2**（$r=1$）：$y_{k+1}=y_k+\dfrac{h}{2}(3f_k-f_{k-1})$——**二阶**。
**AB3**：$y_{k+1}=y_k+\dfrac{h}{12}(23f_k-16f_{k-1}+5f_{k-2})$——**三阶**。
**AB4**：$y_{k+1}=y_k+\dfrac{h}{24}(55f_k-59f_{k-1}+37f_{k-2}-9f_{k-3})$——**四阶**。

**规律**：AB 方法每多用一个历史斜率，阶 +1。**AB4 用 4 个历史斜率（每步只算一个新 $f_k$）达到四阶——对比 RK4 每步要算 4 次 $f$，效率翻 4 倍**。<span class="marginnote">效率对照：<strong>「RK4 每步 4 次求值 vs AB4 每步 1 次求值，都是四阶」</strong>——多步法的「信息复用」让每步成本骤降。但 AB 的代价是：起步需先算 $y_1,y_2,y_3$（用 RK4 或其他单步法）、步长变化时插值麻烦、零稳定性要检查。</span>

**数值例子**：$y'=y$，$h=0.1$，用 AB2：$y_2=y_1+\dfrac{0.1}{2}(3f_1-f_0)=1.105+\dfrac{0.1}{2}(3\times1.105-1)=1.21075$（真值 $e^{0.2}=1.2214$，误差 $0.01$，二阶合理）。

**AB4 与 RK4 的同精度实测。** 同在 $y'=y,\ y(0)=1$、$[0,1]$ 上取 $h=0.1$：AB4 末端误差约 $2.5\times10^{-6}$，RK4 约 $6.3\times10^{-7}$——精度同量级，但 AB4 每步只算 1 次 $f$，RK4 要算 4 次。**四倍求值差距换来的只是略低的精度**，多步法的效率优势一目了然；当然，RK4 不用额外起步、步长变化也顺手，所以「默认值」仍是 RK4。

## 3 阿当姆斯隐式格式：Adams-Moulton

**r+1 步 Adams-Moulton（AM）**，含 $f_{k+1}$：

**AM1**：$y_{k+1}=y_k+h f_{k+1}$——**就是后退欧拉**，一阶。
**AM2**（梯形）：$y_{k+1}=y_k+\dfrac{h}{2}(f_k+f_{k+1})$——**二阶**（前面已见）。
**AM3**：$y_{k+1}=y_k+\dfrac{h}{12}(5f_{k+1}+8f_k-f_{k-1})$——**三阶**。
**AM4**：$y_{k+1}=y_k+\dfrac{h}{24}(9f_{k+1}+19f_k-5f_{k-1}+f_{k-2})$——**四阶**。

**AM 比同阶 AB 更准**（误差常数更小）且更稳（隐式），但**每步要解隐式方程**（非线性 $f$ 时需迭代）。

## 4 公式解析：阶的确定

Adams 方法的阶由「插值多项式积分」精确决定。以 AB2 为例：

**第一步，线性插值 $f$。** 用 $(t_{k-1},f_{k-1})$ 与 $(t_k,f_k)$ 线性插值 $f(t,y(t))$ 在 $[t_k,t_{k+1}]$ 上的外推：$P(t)=f_k+\dfrac{f_k-f_{k-1}}{h}(t-t_k)$。
**第二步，积分。** $y(t_{k+1})-y(t_k)=\int_{t_k}^{t_{k+1}}f\,dt\approx\int_{t_k}^{t_{k+1}}P(t)\,dt=\dfrac{h}{2}(3f_k-f_{k-1})$。
**第三步，误差。** 线性插值误差 $O(h^2)$（在 $h$ 长的区间上积分）→ 局部 $O(h^3)$ → 整体二阶。

**AB$r$ 的局部截断误差**：$\tau=\dfrac{\gamma_r}{(r+1)!}h^{r+2}y^{(r+2)}(\xi)$，其中 $\gamma_r$ 是常数（AB2：$\gamma_1=\tfrac14$ 等）。**AM 的误差常数通常比同阶 AB 小**（隐式「多用一个点」的信息）。

## 5 多步法的零稳定性：根条件

多步法（一般形式含多个 $y_{k-j}$ 项）**必须检查零稳定性**（单步法天然满足，多步法不一定）：

**根条件（root condition）**：特征多项式 $\rho(\lambda)=\lambda^{r+1}-\sum\alpha_j\lambda^{r-j}$ 的全部根满足 $|\lambda_i|\le1$，且模 1 的根是单根。

**定理（Dahlquist）**：线性多步法收敛 ⇔ **相容 + 零稳定**（根条件）。且**阶受限于稳定**：**零稳定的 $r+1$ 步线性多步法的最高阶是 $r+2$**（若 $r+1$ 偶数）或 $r+1$（若奇数）——**Dahlquist 第一障碍**。<span class="marginnote">多步法的「隐藏税」：<strong>「想更高阶的多步法，稳定性先亮红灯」</strong>。Dahlquist 障碍说明：步数无限增多并不能无限提阶——这是多步法与 RK 家族（可自由升阶）的本质区别。工程上多步法通常控制在 $r\le5$ 左右。</span>

## 6 隐式格式的稳定优势

零稳定性保证「$h\to0$ 时收敛」，但工程关心的是「$h$ 固定时误差会不会被放大」——这由**绝对稳定域（absolute stability region）** 决定。对试验方程 $y'=\lambda y$，记 $z=h\lambda$：

**AB2 的绝对稳定域约为 $(-1,0)$**——$z$ 的实部必须落在 $(-1,0)$ 这个狭窄区间内，步长稍大就失稳。**AM2（梯形）的绝对稳定域覆盖整个左半平面 $(-\infty,0)$**——对任何「衰减型」问题都稳定。<span class="marginnote">对照记忆：<strong>显式方法把 $h\lambda$ 关进一个小邻域，隐式方法通常放行整个左半平面</strong>——同阶 AB 比 AM 对步长挑剔得多。这与单步法里「显式欧拉 vs 后退欧拉」的差距是同一个根源。</span>

| 判据 | AB（显式） | AM（隐式） |
| --- | --- | --- |
| $y_{k+1}$ 依赖 | 历史 $f$，直接代入 | 含 $f_{k+1}$，解隐式方程 |
| 同阶误差常数 | 较大 | 较小 |
| 绝对稳定域 | 有限小邻域（如 $(-1,0)$） | 常含整左半平面 |
| 每步成本 | 低（1 次求值） | 高（迭代求解） |
| 刚性问题 | 不适合 | 适合（配 AM4 或 BDF） |

**这就是为什么刚性问题的求解器几乎全是隐式的**——显式方法为了稳定被迫把步长压到极小，成本反超隐式方法的迭代求解。《刚性问题与绝对稳定域》一节会对这张表给出完整的推导与图像。

## 7 实现与工程注意

```python
import numpy as np

def adams_bashforth2(f, t0, y0, t_end, h):
    """AB2（二阶显式阿当姆斯）：起步用显式欧拉。"""
    n = int(round((t_end - t0) / h))
    t = t0 + h * np.arange(n + 1)
    y = np.zeros(n + 1)
    y[0] = y0
    y[1] = y0 + h * f(t[0], y[0])               # 起步：欧拉
    for k in range(1, n):
        y[k+1] = y[k] + h/2 * (3*f(t[k], y[k]) - f(t[k-1], y[k-1]))
    return t, y

# 例：y' = y, y(0) = 1, h = 0.1 → e^1 ≈ 2.71828
t, y = adams_bashforth2(lambda t, y: y, 0, 1, 1, 0.1)
print(y[-1])
```

**工程注意**：多步法起步需要额外方法（RK4 跑几步填历史）、**步长变化时插值系数要重算**（麻烦）——这是多步法不如 RK「顺手」的地方。现代库用「变阶变步长 Adams」（如 MATLAB 的 `ode113`）或「BDF」（刚性）封装这些复杂度。

## 8 小结

- **Adams-Bashforth（显式）**：用历史斜率外推积分，AB$r$ 阶 $r$；AB1=欧拉，AB2 二阶，AB4 四阶。
- **Adams-Moulton（隐式）**：含 $f_{k+1}$，比同阶 AB 更准更稳；AM2=梯形。
- 多步法每步只算 1 次 $f$——效率数倍于 RK，但起步、变步长、零稳定性都是成本。
- **根条件**：多步法收敛 ⇔ 相容 + 零稳定（Dahlquist 定理）；阶受 Dahlquist 障碍限制。
- 工程：RK 简单自适应、多步法高效——`Adams`/BDF 封装多步复杂度。
