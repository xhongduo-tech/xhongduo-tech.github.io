## 为什么从牛顿法开始

牛顿法是求根方法的「天王」：**用切线逼近曲线，从切线与 x 轴的交点跳到下一个近似**。它二次收敛（误差每秒翻倍有效位数），是现代求根与优化的基础——从方程求根到深度学习里的海森阵牛顿步，名字贯穿始终。但它有两个性格：**需要导数**、**可能发散**（初值不够近时）。理解牛顿法，是理解「快速但不免费」的代价。<span class="marginnote">牛顿法 1669 年用于解多项式方程，拉夫森（Raphson）1690 年给出更实用的形式——所以常称「牛顿-拉夫森法」（Newton-Raphson）。它的思想至今统治科学计算：<strong>求解器、优化器、隐式时间步进的内部核心几乎都是牛顿迭代</strong>。</span>

本节给出牛顿公式、几何直觉、二次收敛证明与发散风险。

## 1 公式与几何

对 $f(x)=0$，在 $x_k$ 处作切线 $y=f(x_k)+f'(x_k)(x-x_k)$，令 $y=0$ 解出下一个点：

$$
x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}
$$

**几何**：从 $(x_k,f(x_k))$ 沿切线走，切线与 x 轴的交点就是 $x_{k+1}$。**每次用「当前的切线」跳跃，越靠近根切线越准，跳得越准**——这就是二次收敛的几何来源。

**不动点视角**：牛顿法是 $\varphi(x)=x-\dfrac{f(x)}{f'(x)}$ 的不动点迭代。检查：$\varphi'(x)=1-\dfrac{f'(x)^2-f(x)f''(x)}{f'(x)^2}=\dfrac{f(x)f''(x)}{f'(x)^2}$，在根处 $f(r)=0$ ⇒ $\varphi'(r)=0$——**导数为零，二次收敛**（上一节的理论兑现）。

**数值例子**：$f(x)=x^3-x-1$，$x_0=1.5$：

$$
x_1=1.5-\frac{f(1.5)}{f'(1.5)}=1.5-\frac{0.875}{5.75}=1.3478
$$

$$
x_2=1.3478-\frac{0.1007}{4.4498}=1.3252, \qquad x_3=1.32472
$$

**3 步到 $10^{-4}$，4 步到机器精度**——对比二分法要 40 步。<span class="marginnote">观察有效位数：1.5→1.35（1 位）→1.325（3 位）→1.3247（5 位）——<strong>每秒有效位数翻倍</strong>。这就是二次收敛的现场。</span>

## 2 二次收敛的证明

**定理。** 设 $f\in C^2$，$r$ 是 $f$ 的**简单根**（$f'(r)\neq0$），初值 $x_0$ 充分靠近 $r$。则牛顿迭代二次收敛：

$$
|e_{k+1}| \le C\,|e_k|^2, \qquad C\approx\left|\frac{f''(r)}{2f'(r)}\right|
$$

**公式解析：证明三步。**

- **第一步，泰勒展开。** $f(r)=f(x_k)+f'(x_k)(r-x_k)+\dfrac{f''(\xi)}{2}(r-x_k)^2$。因 $f(r)=0$，两边整理。
- **第二步，代入牛顿公式。** $x_{k+1}=x_k-\dfrac{f(x_k)}{f'(x_k)}$，相减得

$$
r-x_{k+1} = r-x_k+\frac{f(x_k)}{f'(x_k)} = \frac{f''(\xi)}{2f'(x_k)}(r-x_k)^2
$$

- **第三步，取绝对值。** $|e_{k+1}|=\left|\dfrac{f''(\xi)}{2f'(x_k)}\right||e_k|^2\le C|e_k|^2$（初值够近时 $f'(x_k)\neq0$ 且 $\xi$ 靠近 $r$）。

**为什么是「局部」收敛**：证明要求 $x_k$ 一直落在「$f'\neq0$ 且 $f''$ 有界」的邻域内——**初值必须足够靠近根**。离远了，$f'(x_k)$ 可能很小（切线近乎水平），跳跃巨大，直接飞走。

## 3 发散风险：牛顿法的另一面

**发散情形**：

1. **$f'(x_k)=0$（切线水平）**：公式除零，崩溃。
2. **初值太远**：切线指向错误方向，迭代飞出。
3. **振荡**：某些函数下牛顿迭代在两点间循环，永不收敛。
4. **收敛到别的根**：牛顿法只保证收敛到「某个根」，不保证是你要的那个。

**经典反例**：$f(x)=x^3-2x+2$，取 $x_0=0$——牛顿迭代陷入 2-循环（$0\to1\to0\to1\cdots$），永不收敛。<span class="marginnote">牛顿法的「脾气」：<strong>「快是快，但只有初值够近才保证到你要的根」</strong>。工程上从不「裸用」牛顿法——总是先二分/搜索锁定区间，再用牛顿冲刺。这个「先稳后快」的组合是求根的黄金标准。</span>

## 4 实现与工程实践

```python
def newton(f, fp, x0, tol=1e-10, max_iter=100):
    x = x0
    for k in range(max_iter):
        fx, fpx = f(x), fp(x)
        if abs(fpx) < 1e-14:          # 切线水平，危险
            raise RuntimeError("导数接近零")
        x_new = x - fx / fpx
        if abs(x_new - x) < tol:
            return x_new, k + 1
        x = x_new
    raise RuntimeError("不收敛")
```

**工程三件套**：

1. **搜索/二分锁定区间**，把初值送进「收敛盆地」。
2. **监测**：$|f(x_k)|$ 或 $|x_{k+1}-x_k|$ 不降反升 → 立即切回二分。
3. **保护**：导数接近零时改用弦截法或二分法。

**终止准则**：$|f(x_k)|<\varepsilon$（残差）或 $|x_{k+1}-x_k|<\varepsilon$（相邻差）。注意重根附近 $f$ 平坦，残差准则可能「过早成功」——双准则更稳。

## 5 牛顿法的变体预览

| 变体 | 改了什么 | 用途 |
| --- | --- | --- |
| 牛顿-拉夫森 | 标准牛顿 | 简单根 |
| 重根修正 | $m\dfrac{f}{f'}$ | 重根恢复二次 |
| 弦截法 | 差商代替导数 | 免导数 |
| 简化牛顿 | 导数固定 | 每步省求导 |

**辨析｜易错点：** 牛顿法二次收敛**只对简单根**（$f'(r)\neq0$）成立；**重根时退化为线性收敛**（$C=1-1/m$，$m$ 是重数）——下一节专门处理。**别把「二次收敛」当成无条件承诺**。

## 6 小结

- **牛顿法**：$x_{k+1}=x_k-\dfrac{f(x_k)}{f'(x_k)}$——用切线跳跃逼近根。
- **二次收敛**：$|e_{k+1}|\le\left|\dfrac{f''(r)}{2f'(r)}\right||e_k|^2$，每秒有效位数翻倍——但仅对简单根、初值够近。
- 牛顿法是不动点迭代的特例：$\varphi'(r)=0$ ⇒ 二次。
- **发散风险**：切线水平、初值太远、振荡、收敛到别根——需「先搜索后冲刺」。
- 工程三件套：二分锁区间、监测残差、导数保护；重根用修正牛顿。
