## 为什么从根的搜索开始

求 $f(x)=0$ 的根是数值分析最古老的问题（牛顿、巴比伦人都做过）。但所有迭代法（二分、牛顿、弦截）都有一个共同前提：**你得先知道「根在哪」**——至少知道一个包含根的区间。**根的搜索（root bracketing）** 是求根流程的「第一步」，它的任务是用最便宜的手段把根「圈」进若干小区间，为后续精细迭代提供起点。<span class="marginnote">求根的完整流程：<strong>搜索（圈区间）→ 迭代（收敛到根）</strong>。搜索阶段追求「广撒网 + 便宜」，迭代阶段追求「精定位 + 快收敛」。把两个阶段分开，是求根工程的第一课——<strong>先粗后精、先全局后局部</strong>。</span>

本节讲根的搜索方法（步进搜索、零点定理）、根的分离与重根等基本概念。整节的技术含量不算高，但**它决定后续所有迭代法的成败前提**——二分、牛顿、弦截、抛物线法的收敛性分析再漂亮，也都要从一个「不空手」的初始区间出发。

## 1 根的搜索：步进法

最简单的搜索是**步进搜索（incremental search）**：从区间左端出发，按步长 $h$ 逐步移动检查点，看 $f$ 是否**变号**。

**算法**：对 $x=a,a+h,a+2h,\dots$，检查 $f(x_k)$ 与 $f(x_{k-1})$ 是否异号。异号 ⇒ 区间 $[x_{k-1},x_k]$ 内含根。

**理论依据（零点定理）**：$f$ 在 $[a,b]$ 上连续且 $f(a)f(b)<0$，则 $[a,b]$ 内**至少有一个根**。

**数值例子**：$f(x)=x^3-x-1$，从 $x=0$ 以步长 $0.5$ 搜索：

| $x$ | 0 | 0.5 | 1.0 | 1.5 | 2.0 |
| --- | --- | --- | --- | --- | --- |
| $f(x)$ | −1 | −0.875 | −1 | 0.875 | 5 |

在 $[1.0,1.5]$ 变号（$f(1)<0<f(1.5)$）——**根落在 $[1,1.5]$ 内**（实际约 1.3247）。

**步长的取舍**：步长太小搜索慢，太大可能漏根（两个根都落在同一大步内、符号没变）。**步进搜索不保证不漏根**——它是启发式的。<span class="marginnote">漏根风险：<strong>偶数重根（$f(x)=(x-r)^2$）在根处不变号</strong>，步进搜索直接漏掉。步进搜索只能可靠地找到「奇数重根」；重根检测要另想办法（下面会讲）。</span>

**步进搜索的变体**：为兼顾「不漏根」与「不浪费」，常用**自适应步长**——先用大步快速扫描，检测到符号变化或函数值异常后，回退半步细分。更稳妥的工程做法是把区间等分后再对每段递归细分，等价于一个隐式的二分树。这些变体的共同点，是把搜索的粗粒度与后续迭代的细粒度用一条递归链接起来。<span class="marginnote">递归细分的思想在数值积分里叫<strong>自适应求积</strong>、在偏微分方程里叫<strong>自适应网格加密</strong>——「先粗后精」是数值方法里出现频率最高的模式。</span>

## 2 根的分离与重根

**根的分离（root isolation）**：把区间划分成若干子区间，每个子区间至多含一个根。用步进搜索 + 变号判断，通常能得到一组「单根区间」。

**重根（multiple root）**：若 $f(r)=f'(r)=\cdots=f^{(m-1)}(r)=0$ 且 $f^{(m)}(r)\neq0$，则 $r$ 是 $m$ 重根。重根的特征：

**偶重根在根处不变号**（$f$ 在 $r$ 两侧同号）——变号搜索会漏。
**重根处 $f$ 与 $f'$ 都有零点**（$r$ 是 $f'$ 的根）。
数值上，重根「难求准」：$f$ 在根附近几乎平坦，函数值对位置不敏感。

**检测重根的技巧**：搜索 $f$ 与 $f'$ 的公共零点；或观察 $f$ 是否在疑似根处「切而不穿」（$f$ 在根处触及 x 轴但不变号）。

**辨析｜易错点：** 重根会让许多迭代法「降速」——牛顿法对重根从二次收敛降为一次收敛（下一节详述）。**搜索阶段识别重根，是为了迭代阶段对症下药**（用重根修正的牛顿法）。<span class="marginnote">工程经验：<strong>「先搜 $f$ 变号，再搜 $f'$ 变号」</strong>——前者找单根，后者找重根的候选（重根处 $f'$ 也过零）。两者结合，重根不再漏网。</span>

**数值上如何判断重根**：观察 $f$ 在疑似根两侧的符号变化时，若函数值连续多个点都接近零（而不是干净利落地穿越零），多半是重根。更定量地，可以比较相邻网格点上 $|f|$ 的衰减方式：重根处 $f$ 以 $(x-r)^m$ 的量级趋于零，$|f|$ 呈「幂式平坦」而非「线性穿越」。配合 $f'$ 的零点，就能把「疑似根」升级为「已确认的重根」。

## 3 搜索的实用策略

| 场景 | 策略 | 理由 |
| --- | --- | --- |
| 根的大致范围未知 | 大步进 + 变号 | 快速圈定全局 |
| 已有一个含根区间 | 二分法（下一节） | 线性但绝对可靠 |
| 需要全部根 | 网格 + 变号 + 细分 | 逐个隔离 |
| 函数在根处平坦 | 搜索 $f'$ 或改尺度 | 检测重根 |

**画图是最强搜索**：先画 $f$ 的图像，肉眼定位根的所在区间，再数值精化——**「先画图、再算数」是求根的第一工程原则**。<span class="marginnote">现代实践：<code>scipy.optimize.brentq</code>`、<code>root_scalar</code>` 都要求先给「含根区间」（bracket）。<strong>把搜索做扎实，迭代就只需少量步数</strong>——搜索是投入产出比最高的求根步骤。</span>

**软件里的搜索**：MATLAB 的 `fzero`、Python 的 `scipy.optimize.brentq` 与 `root_scalar` 都要求先提供 bracket——搜索这一步已经被算法内置要求「显式化」。部分库（如 `scipy.optimize.root` 的若干迭代器）允许从单个初值出发，但代价是可能收敛到意外方向。工程惯例是：能用 bracket 就用 bracket，搜索成本远低于发散后重新开始。<span class="marginnote">「给迭代器一个好起点」是几乎所有数值软件的使用守则——<strong>好的搜索让后续每一步都便宜</strong>。这个观念在优化、方程求解、ODE 初值里反复出现。</span>

## 4 数值例子：完整求根流程

求 $f(x)=e^x-3x=0$ 的全部根。

**第一步，搜索**。$f(0)=1$，$f(1)=e-3\approx-0.28$（变号，根在 $[0,1]$）；$f(1.5)=e^{1.5}-4.5\approx-0.02$，$f(2)=e^2-6\approx1.39$（变号，根在 $[1.5,2]$）。**两个根已圈定**。

注意这里有个值得观察的细节：$f(1.5)\approx-0.02$ 已经非常接近零，但它不是根——$f$ 在此处只是穿过了 x 轴附近后又折返。若搜索步长是 1，这两个根会被并进同一个区间 $[0,2]$，仅靠一次变号判断无法区分它们是「两个根」还是「一个二重根」。**搜索的分辨率由步长决定**：要用更小的步长才能把两个根分开隔离，这正是根的分离阶段要做的工作。

**第二步，迭代（预告）**。对 $[0,1]$ 用二分/牛顿，得根 $\approx0.619$；对 $[1.5,2]$ 得根 $\approx1.512$。

**第三步，验证**。代入 $f$ 检查接近零；检查是否漏根（$f$ 在搜索区间外是否还有变号点）。<span class="marginnote">完整流程的教训：<strong>先圈区间（搜索）→ 再精化（迭代）→ 最后验证</strong>。跳过搜索直接迭代，牛顿法可能发散到未知方向；不验证，可能漏掉重根或把局部极值当根。</span>

## 5 零点定理与搜索的失效边界

步进搜索的可靠性完全建立在**零点定理（介值定理）**之上：$f$ 连续且 $f(a)f(b)<0 \Rightarrow$ 区间内至少有一个根。这里有两个隐藏前提，各自对应一类失效：

**连续性失效**：$f$ 有间断（如 $1/x$ 在 0 处），即便 $f(a)f(b)<0$，区间内也可能没有根——间断点「跳过」了 x 轴。反例：$f(x)=1/x$，取区间 $[-1,1]$，$f(-1)f(1)=(-1)(1)=-1<0$，但区间内没有根，只有无穷间断。所以搜索之前先确认 $f$ 的连续性。

**变号失效**：偶重根处 $f$ 不变号，变号搜索漏根（前文已述）。奇数重根变号，但 $f$ 在根附近可能极平坦，函数值接近零，受舍入误差干扰后符号可能反复横跳——这是「数值上的失效」，需要结合 $f'$ 或更高精度重算来确认。

一句话总结：**搜索能保证的是「连续 + 变号 ⇒ 有根」，不能保证的是「不连续或偶重根 ⇒ 有根」**。把这两类失效背下来，求根就不会在搜索阶段翻车。<span class="marginnote">「必要条件 ≠ 充分条件」在数值分析里反复上演：<strong>$f(a)f(b)<0$ 是「有根」的充分条件，不是必要条件</strong>——偶重根处 $f$ 两侧同号，却照样有根。判定方向搞反，是初学者的常见错误。</span>

## 6 术语速查表

| 术语 | 英文 | 一句话含义 |
| --- | --- | --- |
| 步进搜索 | incremental search | 按步长扫过区间、检测 $f$ 变号以定位含根区间 |
| 根的分离 | root isolation | 把区间剖分成每个至多含一个根的子区间 |
| 重根 | multiple root | $f(r)=f'(r)=\cdots=0$ 的根；偶重根在根处不变号 |
| 零点定理 | intermediate value theorem | 连续 + 变号 $\Rightarrow$ 区间内至少有一个根 |
| 含根区间 | bracket | 端点函数值异号的区间，迭代法的输入前提 |
| 根的搜索 | root bracketing | 用便宜手段把根圈进若干小区间，为精细迭代提供起点 |

记住这些术语在后文会反复出现——尤其 **bracket**：二分法、弦截法、`fzero`、`brentq` 的接口里都有它。

## 7 小结

- **求根流程**：搜索（圈含根区间）→ 迭代（精化）→ 验证（检查与补漏）。
- **步进搜索** + **零点定理**（$f(a)f(b)<0$ ⇒ 区间含根）：连续函数上可靠圈根。
- **重根**：偶重根不变号（变号搜索会漏）、根处平坦（难求准）；搜索 $f'$ 辅助检测。
- 搜索的工程原则：**先画图再算数**；步长权衡（小步慢、大步漏）。
- 搜索做扎实，迭代步数就少——求根的投入产出比最高的一步。
- 整体定位：搜索是求根流程的「第一性前提」，后续二分/牛顿/弦截的收敛性都以它为起点。
- 搜索的失效边界：**连续失效**（间断点跳过 x 轴）与**变号失效**（偶重根不变号）两类要牢记。
- 判定方向别搞反：$f(a)f(b)<0$ 是「有根」的**充分条件**，不是必要条件。
- 自适应步长/递归细分把「先粗后精」的节奏延伸到了数值积分与自适应网格。
- 搜索的分辨率由步长决定：大步长会把相邻两个根并进同一区间，根的分离要靠细分。
- 工程惯例：能用 bracket 就用 bracket（`fzero`、`brentq` 均如此），搜索成本远低于发散后重来。

在下一节，我们从「有区间」到「有根」：**二分法（bisection method）及其收敛性**——最可靠、最朴素、永不失败的求根方法。
