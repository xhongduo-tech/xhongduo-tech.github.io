## 为什么从分段低次插值开始

高次多项式插值有一个致命的性格缺陷：**节点越多、次数越高，曲线反而越可能在区间端部失控地振荡**（这就是著名的龙格现象，下一节专门解剖）。而工程上节点往往非常多——一条温度曲线可能有上千个采样点。用一条上千次的多项式去穿过它们，不仅计算笨重，结果还可能剧烈抖动。出路是什么？**不追求「一条多项式管到底」，而是把整个区间切成很多小段，每段只用低次（一次、三次）多项式插值。** 这就是**分段低次插值（piecewise interpolation）**。<span class="marginnote">分而治之的朴素思想在这里大放异彩：<strong>全局高次 → 局域低次</strong>。计算机图形学、有限元、科学绘图里那些「看上去很光滑」的曲线，几乎全是分段多项式拼出来的——只是拼接处做了光滑处理，让你看不出来。</span>

本节介绍两条最基础的分段路线：**分段线性插值**与**分段三次埃尔米特插值（PCHIP）**，并重点比较它们的连续性、光滑性与收敛性。

## 1 分段线性插值：折线图背后的数学

把节点 $x_0<x_1<\cdots<x_n$ 排好，在每个小区间 $[x_i,x_{i+1}]$ 上用一次插值（直线连接两点），得到分段线性插值函数：

$$
I_h(x) = \frac{x-x_{i+1}}{x_i-x_{i+1}}\,y_i + \frac{x-x_i}{x_{i+1}-x_i}\,y_{i+1}, \qquad x\in[x_i,x_{i+1}]
$$

它就是数据点之间连直线——**我们画折线图时早已见过的插值**。它的性质：

- **连续性**：$C^0$ 连续（相邻折线段在节点处相接），但**一阶导数不连续**——节点处出现「折角」。
- **误差**：若 $f\in C^2[a,b]$，步长 $h=\max_i(x_{i+1}-x_i)$，则

$$
|f(x) - I_h(x)| \le \frac{M_2}{8}\,h^2, \qquad M_2 = \max_{[a,b]}|f''(x)|
$$

$h\to0$ 时误差以 $h^2$ 阶收敛——**分段线性插值是收敛的，且不会振荡**。这是它对高次插值最重要的胜利：无论节点怎么加，它都老老实实逼近。<span class="marginnote">对比普通高次插值：龙格现象表明某些 $f$ 下，$n\to\infty$ 时全局插值不收敛；而分段线性插值对任何 $f\in C^2$ 都按 $O(h^2)$ 收敛。<strong>「低次 + 加密」保证收敛，「高次 + 加节点」可能不收敛</strong>——这个对照值得反复体会。</span>

代价也很直白：分段线性只有 $C^0$ 连续，曲线在节点处「有棱有角」，对光滑性要求高的场合（如 CAD、动画）不够用。要光滑，就得升级次数。

## 2 分段三次埃尔米特插值（PCHIP）：折线升级为光滑曲线

在小区间 $[x_i,x_{i+1}]$ 上用**两点三次埃尔米特插值**，把每个节点处的斜率 $m_i$ 也带进来。上一节的基函数公式直接逐段套用，得到**分段三次埃尔米特插值（piecewise cubic Hermite interpolation，简称 PCHIP）**：

$$
H(x) = y_i\,\alpha_0(t) + y_{i+1}\,\alpha_1(t) + m_i\,h_i\,\beta_0(t) + m_{i+1}\,h_i\,\beta_1(t), \qquad t=\frac{x-x_i}{h_i}
$$

其中 $h_i = x_{i+1}-x_i$，$\alpha,\beta$ 是上一节定义的三次埃尔米特基函数。

PCHIP 的性质：

- **光滑性**：$C^1$ 连续——函数值和一阶导数在节点处都连续，曲线光滑无折角，但**二阶导数一般不连续**。
- **局部性**：每段插值只依赖本段两个节点及其斜率，**改一个节点只影响相邻两段**，计算量 $O(n)$，天然支持局部修改。
- **斜率来源**：$m_i$ 通常由相邻节点差分估计（如三点均值斜率），不必事先给定真实导数。

**辨析｜易错点：** PCHIP 的 $C^1$ 光滑是「拼接保证」的，不是「插值条件保证」的。相邻两段在节点处共享同一个斜率 $m_i$，所以导数连续；但二阶导数由各段三次式独立决定，节点两侧一般不同，于是曲线在节点处「曲率突变」——肉眼看去很光滑，求二阶导就会发现台阶。<span class="marginnote">这也是后续《三次样条》的动机：样条把约束升级为「二阶导数也连续」，换来 $C^2$ 光滑，代价是每段插值不再局部独立，而要解一个全局三对角方程组。</span>

## 3 收敛性与误差：低次为什么更可靠

把两条分段路线的误差与连续性放一起对比：

| 方法 | 连续阶 | 误差阶（$f\in C^2$） | 光滑性 | 局部性 |
| --- | --- | --- | --- | --- |
| 分段线性插值 | $C^0$ | $O(h^2)$ | 有折角 | 强 |
| 分段三次埃尔米特 | $C^1$ | $O(h^4)$ | 光滑无折角 | 强 |
| 全局高次插值 | $C^\infty$ | 未必收敛 | 可能剧烈振荡 | 无（全局耦合） |

注意 PCHIP 的误差阶：若斜率 $m_i$ 取到真实导数值，则每段误差 $O(h^4)$；若 $m_i$ 用差分近似，误差略降到 $O(h^3)$，仍是低次里的优等生。

**为什么分段低次「不振荡」？** 直觉来自余项公式。分段线性余项 $R_h(x)=\dfrac{f''(\xi)}{2}(x-x_i)(x-x_{i+1})$，在小区间里 $|x-x_i|,|x-x_{i+1}|\le h$，两个小因子相乘把误差压住；全局高次插值的余项 $\dfrac{f^{(n+1)}(\xi)}{(n+1)!}\omega_{n+1}(x)$ 里，$\omega_{n+1}$ 在区间端部可能因「多个节点距离累乘」而巨大——当 $f$ 的高阶导数又被等距节点放大时，就爆出龙格振荡。**低次把「误差炸弹」限制在每段 $h^2$ 的尺度内，高次把它放大到全局。**

## 4 数值实验：分段线性 vs 全局插值

对 $f(x)=1/(1+25x^2)$ 在 $[-1,1]$ 上取 $n+1=11$ 个等距节点（这个函数是龙格现象的经典主角），比较三种做法在 $x$ 处的误差：

```python
import numpy as np
import matplotlib.pyplot as plt

f = lambda x: 1 / (1 + 25 * x**2)
n = 10
x_nodes = np.linspace(-1, 1, n + 1)
y_nodes = f(x_nodes)
x_fine = np.linspace(-1, 1, 2001)

# 全局高次插值（用牛顿/拉格朗日实现，这里用 numpy 多项式拟合代替）
poly = np.polynomial.polynomial.Polynomial.fit(x_nodes, y_nodes, n)

# 分段线性插值
piece = np.interp(x_fine, x_nodes, y_nodes)

err_global = np.abs(poly(x_fine) - f(x_fine))
err_piece  = np.abs(piece - f(x_fine))

print("全局插值最大误差:", err_global.max())   # 约 1.9，端部剧烈振荡
print("分段线性最大误差:", err_piece.max())    # 约 0.048，量级小两个数量级
```

结果令人警醒：**11 个节点下，全局高次插值的误差峰值接近 2（完全失真），而分段线性的误差峰只有约 0.05。** 低次胜出不是因为聪明，而是因为它不给自己「越权」的机会——每段只管一小段，误差无法蔓延。<span class="marginnote">注意代码里用了 `numpy` 的 `Polynomial.fit` 走正规方程拟合，数值上等价于高次插值多项式；真正实现时拉格朗日/牛顿公式在 $n=10$ 时数值病态，但趋势一致。这个「用简单实现看趋势」的实验习惯，是数值分析学习里的常态。</span>

## 5 小结

- **分段线性插值**：每小区间用直线，$C^0$ 连续、$O(h^2)$ 收敛，永远不振荡，但有折角。
- **分段三次埃尔米特插值（PCHIP）**：每区间用两点三次埃尔米特，$C^1$ 连续、$O(h^4)$ 收敛、局部性强，但二阶导数在节点处不连续。
- 分段低次插值的核心思想是**分而治之**：把「全局一条多项式」换成「局域小多项式拼接」，换来收敛保证与局部可修改性。
- 低次不振荡的根源：余项被限制在 $O(h^k)$ 的小尺度内，误差无法跨节点累积。
- 曲线要更光滑（$C^2$）且仍保局域思想，就要进入下一节的主角：**三次样条插值**。
