## 为什么从雅可比特征值方法开始

QR 算法是特征值计算的现代主流，但**雅可比方法（Jacobi eigenvalue method）** 用更朴素的思想解决同一问题：对实对称矩阵，反复用**平面旋转**（吉文斯旋转）消灭非对角元，每次挑**最大的那个**消灭。它实现极简、数值极稳，对小规模与需要**高精度特征向量**的场景仍是优选。<span class="marginnote">雅可比方法 1846 年由雅可比提出（就是迭代法那位雅可比）。它的思想与 QR 殊途同归，但更「贪心」：<strong>每步消灭当前最大的非对角元，非对角元平方和单调下降</strong>——这个「每次解决最坏问题」的贪心策略最终收敛到对角阵。</span>

本节给出平面旋转、雅可比迭代算法与收敛性。

## 1 平面旋转：一个正交变换消灭一个元素

对实对称矩阵 $A$，选下标 $p<q$，构造**平面旋转** $J=J(p,q,\theta)$（吉文斯旋转）：

$$
J_{pp}=J_{qq}=\cos\theta, \qquad J_{pq}=-J_{qq}=-J_{qp}=-\sin\theta, \qquad J_{ij}=\delta_{ij}\ \text{其余}
$$

**目标**：做相似变换 $A\leftarrow J^\top A J$ 后，$A$ 的 $(p,q)$ 与 $(q,p)$ 元素变成零。**旋转角 $\theta$ 由下式决定**：

$$
\tan 2\theta = \frac{2a_{pq}}{a_{pp}-a_{qq}}, \qquad \text{即 } \cot 2\theta = \frac{a_{pp}-a_{qq}}{2a_{pq}}
$$

**为什么能消成零？** 2×2 对称矩阵 $\begin{pmatrix}a_{pp}&a_{pq}\\a_{pq}&a_{qq}\end{pmatrix}$ 用旋转角 $\theta$ 对角化——这正是「2×2 对称矩阵的特征分解」的几何动作。<span class="marginnote">直觉：<strong>平面旋转就是「在 $(p,q)$ 平面上转坐标轴，让这个 2×2 子块对角化」</strong>。一次旋转消灭一对非对角元，但会「碰脏」$p,q$ 行/列的其它元素——所以需要迭代。</span>

## 2 雅可比迭代：贪心消灭非对角元

**经典雅可比方法**：

1. **找最大非对角元**：$(p,q)=\arg\max_{i<j}|a_{ij}|$。
2. **旋转**：构造 $J(p,q,\theta)$ 消灭 $a_{pq},a_{qp}$。
3. **更新**：$A\leftarrow J^\top A J$，累积 $V\leftarrow VJ$（记录旋转，得特征向量）。
4. **重复**直到最大非对角元 $<\varepsilon$。

**关键不变式（单调下降）**：记 $\mathrm{off}(A)=\sum_{i\neq j}a_{ij}^2$（非对角元平方和）。一次旋转消灭一对非对角元，同时只把能量转移到同行/列的其他非对角元，可以证明

$$
\mathrm{off}(J^\top A J) = \mathrm{off}(A) - 2a_{pq}^2
$$

**非对角元平方和每步严格下降**——这是雅可比收敛的保证。

**公式解析：为什么 off(A) 单调降。**

- **第一步，写旋转前后。** 平面旋转只在 $(p,q)$ 平面作用，$p,q$ 行/列之外的非对角元不变；$p,q$ 行/列内的非对角元平方和从「包含 $2a_{pq}^2$」变为「不包含」。
- **第二步，守恒。** 对称矩阵旋转是正交相似，**所有元素的平方和不变**（Frobenius 范数保持）。对角元平方和增加 $2a_{pq}^2$，非对角元平方和减少 $2a_{pq}^2$。
- **第三步，收敛。** 每步消灭「当前最大」的非对角元，$\mathrm{off}$ 至少降 $2\max^2$——按比例收缩，最终 $\mathrm{off}\to0$，$A\to$ 对角阵，对角元是特征值。

## 3 收敛速度与变体

**收敛速度**：经典雅可比（每步挑最大非对角元）**二次收敛**——误差每步平方级收缩。实际中「轮换雅可比（cyclic Jacobi）」按固定顺序轮转所有 $(p,q)$ 对，也二次收敛，且无查找最大元的开销。

**复杂度**：每步 $O(n)$（只动 $p,q$ 行/列），总步数约 $O(n^2)$，总成本 $O(n^3)$——与 QR 同阶，但常数较大（每步开销重）。

| 判据 | 雅可比方法 | 位移 QR（三对角） |
| --- | --- | --- |
| 每步成本 | $O(n)$ | $O(n)$ |
| 收敛 | 二次 | 三次 |
| 实现 | 极简 | 复杂（位移、隐式） |
| 特征向量精度 | **极高**（累积旋转） | 好 |
| 适用 | 中小规模、要特征向量 | 大规模默认 |

**辨析｜易错点：** 雅可比消灭的 $a_{pq}$ 会在后续旋转中「复活」（被其他旋转碰脏）——**不要以为一次消灭就永久为零**。收敛靠的是「$\mathrm{off}$ 单调降」的整体趋势，不是单个元素的永久归零。<span class="marginnote">一个常见的困惑：<strong>「既然旋转会把非对角元弄脏，为什么还收敛？」</strong>答案在 $\mathrm{off}$ 单调降定理：整体趋势下降，即便个别元素反复「复活」。理解「单调不变量」是看懂雅可比的关键。</span>

## 4 数值例子与实现

**例子**：$A=\begin{pmatrix}2&1\\1&3\end{pmatrix}$。$a_{12}=1$，$\cot 2\theta=\dfrac{2-3}{2}=-0.5$，$2\theta\approx116.6°$，$\theta\approx58.3°$，$\cos\theta\approx0.526,\sin\theta\approx0.851$。旋转后 $J^\top AJ$ 为对角，特征值 $2.618,2.382$?——手算验证：$\det=5$、迹 $=5$，特征值 $\dfrac{5\pm\sqrt{1+4}}{2}=3.618,1.382$。旋转后对角元应给出这两个值。

```python
import numpy as np

def jacobi_eigen(A, tol=1e-12, max_sweeps=100):
    A = A.astype(float).copy()
    n = A.shape[0]
    V = np.eye(n)
    for _ in range(max_sweeps):
        # 找最大非对角元
        i, j = np.unravel_index(np.argmax(np.abs(A - np.diag(np.diag(A)))), A.shape)
        if abs(A[i, j]) < tol:
            break
        # 算旋转角
        tau = (A[j, j] - A[i, i]) / (2 * A[i, j])
        t = np.sign(tau) / (abs(tau) + np.sqrt(1 + tau**2))
        c = 1 / np.sqrt(1 + t**2); s = t * c
        # 更新 A 与 V（对称更新，只动 i,j 行/列）
        J = np.eye(n)
        J[i, i], J[j, j] = c, c
        J[i, j], J[j, i] = s, -s
        A = J.T @ A @ J
        V = V @ J
    return np.diag(A), V
```

**验证**：随机对称矩阵跑完，`np.sort(diag) == np.sort(np.linalg.eigvalsh(A))`。<span class="marginnote">写雅可比比写 QR 容易得多——<strong>它不需要约化、位移、隐式技巧，几十行就能得到高精度特征值与特征向量</strong>。这就是为什么它作为「教学友好、实现可靠」的方法至今未被淘汰。</span>

## 5 雅可比 vs QR 的工程选型

- **小规模（$n\lesssim 100$）+ 需要特征向量**：雅可比——实现快、特征向量精度极高。
- **大规模**：三对角化 + 位移 QR（或分治）——更快、更省内存。
- **特殊需求**：只要部分特征值 → 幂法/反幂法/位移反幂法；条件数 → 只需极值特征值。

**工程结论：雅可比不是「过时」而是「特化」**——它在「要全部特征值且精度优先、规模适中」时依旧能打。

## 6 小结

- **雅可比方法**：反复用平面旋转 $J(p,q,\theta)$ 消灭非对角元，$A\leftarrow J^\top AJ$，非对角元平方和单调降。
- 旋转角：$\cot 2\theta=\dfrac{a_{pp}-a_{qq}}{2a_{pq}}$——2×2 子块对角化的几何动作。
- **$\mathrm{off}(A)$ 单调降**（Frobenius 范数守恒）是收敛保证；消灭的元素会被「复活」，但整体趋势下降。
- 二次收敛；轮换雅可比免查找；总成本 $O(n^3)$。
- 中小规模 + 要特征向量 → 雅可比；大规模 → 三对角化 + 位移 QR。
