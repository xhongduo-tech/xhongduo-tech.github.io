## 为什么从雅可比迭代法开始

雅可比迭代是迭代法家族最朴素的一员：把 $A$ 分裂成对角部分与其余部分，**每一轮用「旧值」独立更新每个未知量**。它的结构极其简单、天然可并行，虽然收敛常常偏慢，但它是理解迭代收敛机制、以及高斯-赛德尔/SOR 为何改进的起点。<span class="marginnote">雅可比（1804—1851）是德国数学家，雅可比行列式、雅可比椭圆函数都出自他手。他的迭代法在现代仍有用武之地：<strong>GPU 并行与分布式系统里，「每点独立更新再全局同步」的结构正是雅可比式</strong>——并行友好是它最大的现代卖点。</span>

本节给出雅可比迭代的公式、矩阵形式、实现与收敛条件。

## 1 分量形式：每个方程解一个未知数

设 $A=D-L-U$（$D$ 对角、$-L$ 严格下三角、$-U$ 严格上三角）。雅可比迭代的分量形式：

$$
x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j\neq i} a_{ij}x_j^{(k)}\right), \qquad i=1,2,\dots,n
$$

**直觉**：第 $i$ 个方程 $a_{ii}x_i+\sum_{j\neq i}a_{ij}x_j=b_i$ 中，把其他未知数固定为旧值 $x_j^{(k)}$，解出 $x_i$ 的新值。**每个分量用「上一轮的全体旧值」独立更新。**

**关键特征：全体分量同时更新**——计算 $x_i^{(k+1)}$ 只用到 $x^{(k)}$，不依赖本轮的 $x_j^{(k+1)}$。这让雅可比**天然可并行**（GPU 友好），但也让信息传播慢（收敛慢）。

**数值例子**：解
$$
\begin{cases}
10x_1 - x_2 - x_3 = 6 \\
-x_1 + 10x_2 - x_3 = 8 \\
-x_1 - x_2 + 10x_3 = 8
\end{cases}
$$

初值 $\mathbf{x}^{(0)}=(0,0,0)$。第一轮：
$$
x_1^{(1)}=\frac{6-0-0}{10}=0.6, \quad x_2^{(1)}=\frac{8-0-0}{10}=0.8, \quad x_3^{(1)}=\frac{8-0-0}{10}=0.8
$$
第二轮 $x_1^{(2)}=\dfrac{6-0.8-0.8}{10}=0.44$，…逐步逼近真解 $(1,1,1)$。<span class="marginnote">注意雅可比每轮用「上一轮的全体值」——三个分量同步更新，互不依赖本轮。这个「同步」既是并行的优势，也是收敛慢的原因（信息每轮只传播一格）。</span>

## 2 矩阵形式与分裂

用分裂 $A=D-L-U$，雅可比的分裂为 $M=D$、$N=L+U$：

$$
\mathbf{x}^{(k+1)} = D^{-1}(L+U)\mathbf{x}^{(k)} + D^{-1}\mathbf{b}
$$

迭代矩阵 $G_J=D^{-1}(L+U)$。**每步只需一次矩阵-向量乘与一次对角求逆**——$O(n)$ 成本（若稀疏），对角求逆是逐元素除法。<span class="marginnote">D 的对角元素不能为零——若某个 $a_{ii}=0$，雅可比直接崩。对角占优或主对角非零是雅可比可行的前提。</span>

## 3 公式解析：收敛条件

**定理（充分条件）。** 若 $A$ **严格对角占优**（$|a_{ii}|>\sum_{j\neq i}|a_{ij}|$ 对所有 $i$），则雅可比迭代对任意初值收敛。

**直觉**：严格对角占优意味着「主对角元素支配整行」，每轮更新里「自己那项」主导、误差每轮被压缩。更一般的收敛条件由迭代矩阵谱半径给出：$\rho(D^{-1}(L+U))<1$。

**为什么严格对角占优保证 $\rho<1$？** 用 $\infty$-范数：对任意 $\mathbf{x}$，$\lVert D^{-1}(L+U)\mathbf{x}\rVert_\infty$ 的分量

$$
\left|\sum_{j\neq i}\frac{a_{ij}}{a_{ii}}x_j\right| \le \left(\sum_{j\neq i}\frac{|a_{ij}|}{|a_{ii}|}\right)\lVert\mathbf{x}\rVert_\infty < \lVert\mathbf{x}\rVert_\infty
$$

严格对角占优使每行系数和 $<1$，故 $\lVert G_J\rVert_\infty<1$，进而 $\rho(G_J)\le\lVert G_J\rVert_\infty<1$。**收敛。**

**数值演示**：上面例子的迭代矩阵 $G_J=D^{-1}(L+U)$ 的特征值为 $0, \pm0.1\sqrt2$，谱半径 $\rho\approx0.141$——收敛很快，每步误差压缩约 0.14 倍，2~3 步精度就很好。<span class="marginnote">对角占优是「充分」条件，不是必要——很多非对角占优矩阵也收敛。但工程上「先检查对角占优」是廉价的第一道筛子：<strong>对角占优 → 放心迭代；不占优 → 考虑重排或换方法</strong>。</span>

## 4 实现与收敛判断

```python
import numpy as np

def jacobi(A, b, x0, tol=1e-10, max_iter=1000):
    """雅可比迭代：全体分量用上一轮旧值同步更新。"""
    n = len(b)
    x = np.array(x0, dtype=float)
    for it in range(max_iter):
        x_new = np.empty_like(x)
        for i in range(n):
            s = sum(A[i, j] * x[j] for j in range(n) if j != i)
            x_new[i] = (b[i] - s) / A[i, i]
        if np.linalg.norm(x_new - x, ord=np.inf) < tol:
            return x_new, it + 1
        x = x_new
    return x, max_iter

# 例：10x1 - x2 - x3 = 6 等三方程，初值 (0,0,0)，约 16 步收敛到 1e-10
A = np.array([[10., -1, -1], [-1, 10, -1], [-1, -1, 10]])
b = np.array([6., 8, 8])
print(jacobi(A, b, [0, 0, 0]))
```

**工程注意**：每步迭代的成本 $O(n^2)$（稠密）或 $O(n)$（稀疏，矩阵-向量乘）。**雅可比的价值在稀疏与并行**；稠密矩阵上它比直接法慢得多。

## 5 雅可比 vs 高斯-赛德尔：先看预告

| 判据 | 雅可比 | 高斯-赛德尔（下一节） |
| --- | --- | --- |
| 更新方式 | 全体同步（用旧值） | 逐个更新（用最新值） |
| 存储需求 | 需两组 $x$ | 一组即可 |
| 并行性 | **强**（无依赖） | 弱（串行依赖） |
| 收敛速度 | 慢（信息传播慢） | 通常快一倍 |
| 适用 | 并行环境、GPU | 串行、通用 |

**辨析｜易错点：** 雅可比**不一定**比高斯-赛德尔慢——存在反例（非对角占优时）。工程上默认高斯-赛德尔更快，但**并行场景雅可比是唯一选择**（高斯-赛德尔的分量依赖串行）。<span class="marginnote">一个直觉：雅可比每轮「全体看旧值」，信息传播一格；高斯-赛德尔「边更新边用新值」，信息传播多格。<strong>所以高斯-赛德尔通常快，但代价是丢失并行性</strong>——并行 vs 收敛速度，又是一对权衡。</span>

## 6 小结

- **雅可比迭代**：$x_i^{(k+1)}=\dfrac{1}{a_{ii}}\left(b_i-\sum_{j\neq i}a_{ij}x_j^{(k)}\right)$，全体分量用旧值同步更新。
- 矩阵形式：分裂 $M=D$、$N=L+U$，迭代矩阵 $G_J=D^{-1}(L+U)$。
- **严格对角占优 ⇒ 收敛**（$\lVert G_J\rVert_\infty<1\Rightarrow\rho<1$）；一般判据看 $\rho(G_J)$。
- 每步 $O(n)$（稀疏）+ 天然并行——GPU 友好，但收敛慢。
- 并行选雅可比，串行选高斯-赛德尔；对角占优是廉价第一筛。

在下一节，我们让更新「用上最新值」：**高斯-赛德尔迭代法**——逐分量更新、省一半存储，通常更快收敛。
