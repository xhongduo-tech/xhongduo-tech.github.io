## 为什么从复化求积开始

单段梯形、辛普森公式在区间长时误差巨大——辛普森余项含 $(b-a)h^4$，区间一大误差就失控。而且高次牛顿-柯特斯又不稳定。**出路和插值里一样：分段**。把 $[a,b]$ 切成 $n$ 个小区间，每个小区间用低阶公式，再全部加起来——这就是**复化求积（composite quadrature）**。它是工程上最常用的数值积分主力，误差随步长稳定收敛，实现简单。<span class="marginnote">「复化」（composite）是数值分析的分而治之范式的又一例证：<strong>单段高精度换不来稳定，多段低精度却稳扎稳打</strong>。这与分段插值、龙格现象的教训一脉相承——全局 vs 局部，永远要掂量。</span>

本节给出复化梯形与复化辛普森公式、它们的余项与收敛阶，并讨论步长如何选。

## 1 复化梯形公式

把 $[a,b]$ 等分 $n$ 段，步长 $h=\dfrac{b-a}{n}$，节点 $x_k=a+kh$。每段 $[x_{k-1},x_k]$ 用梯形公式，求和：

$$
T_n = \sum_{k=1}^{n} \frac{h}{2}\left(f(x_{k-1})+f(x_k)\right) = \frac{h}{2}\left(f(a) + 2\sum_{k=1}^{n-1}f(x_k) + f(b)\right)
$$

**内部节点出现两次（两侧各一次），合并为系数 2**——这是复化梯形公式的招牌结构：端点系数 1、内部系数 2。

**余项**：每段误差 $-\dfrac{h^3}{12}f''(\xi_k)$，累加得

$$
R_T = -\frac{b-a}{12}\,h^2\,f''(\xi), \qquad \xi\in(a,b)
$$

**收敛阶 $O(h^2)$**：步长减半，误差缩为 $1/4$。注意余项从单段的 $O(h^3)$ 变成复化的 $O(h^2)$——多乘了一个「段数」因子，但换来的是「加密必收敛」。

## 2 复化辛普森公式

对**偶数** $n=2m$ 段（每两段合并成一组套辛普森，因为辛普森需要三个点），步长 $h=\dfrac{b-a}{2m}$：

$$
S_n = \frac{h}{3}\left(f(a) + 4\sum_{k=0}^{m-1}f(x_{2k+1}) + 2\sum_{k=1}^{m-1}f(x_{2k}) + f(b)\right)
$$

**系数模式：端点 1、奇数下标 4、偶数下标 2**（首尾 1，奇 4 偶 2）。**余项**：

$$
R_S = -\frac{b-a}{180}\,h^4\,f^{(4)}(\xi)
$$

**收敛阶 $O(h^4)$**：步长减半，误差缩为 $1/16$。<span class="marginnote">记忆钩子：复化辛普森系数 <strong>「1,4,2,4,…,2,4,1」</strong>——中间奇数位都是 4、偶数位都是 2。实现时用两个求和循环（奇、偶分开）最不容易错。</span>

**代码对比**：

```python
import numpy as np

def composite_trapezoid(f, a, b, n):
    h = (b - a) / n
    x = np.linspace(a, b, n + 1)
    return h * (0.5*f(x[0]) + np.sum(f(x[1:-1])) + 0.5*f(x[-1]))

def composite_simpson(f, a, b, m):
    # 2m 段，需要 2m+1 个节点
    h = (b - a) / (2 * m)
    x = np.linspace(a, b, 2*m + 1)
    y = f(x)
    return h/3 * (y[0] + 4*np.sum(y[1::2]) + 2*np.sum(y[2:-1:2]) + y[-1])

f = lambda x: np.exp(x)
I = np.exp(1) - 1
print("复化梯形 n=10:", composite_trapezoid(f, 0, 1, 10), "误差", I - composite_trapezoid(f, 0, 1, 10))
print("复化辛普森 m=5:", composite_simpson(f, 0, 1, 5), "误差", I - composite_simpson(f, 0, 1, 5))
```

同样的节点预算，辛普森误差小两个量级——光滑函数上复化辛普森是默认选择。

## 3 公式解析：余项的推导与收敛阶

以复化梯形为例拆解余项：

- **第一步，逐段套单段余项。** 每段 $[x_{k-1},x_k]$ 误差 $-\dfrac{h^3}{12}f''(\xi_k)$，其中 $\xi_k\in(x_{k-1},x_k)$。总误差 $-\dfrac{h^3}{12}\sum_{k=1}^n f''(\xi_k)$。
- **第二步，把和写成「平均 × n」。** $\sum_{k=1}^n f''(\xi_k)=n\cdot\bar{f''}$，其中 $\bar{f''}$ 是 $n$ 个采样值的平均。由连续性，$\bar{f''}$ 介于 $\min f''$ 与 $\max f''$ 之间，可写成某个 $\xi$ 处的 $f''(\xi)$。
- **第三步，合并 $h^3$ 与 $n$。** $n\cdot h^3=(b-a)h^2$，故 $R_T=-\dfrac{b-a}{12}h^2f''(\xi)$。**复化使误差从 $h^3$ 降到 $h^2$，但换来确定性收敛**——因为 $h\to0$ 时 $n\to\infty$，$\bar{f''}\to$ 平均二阶导，误差稳定按 $h^2$ 收缩。

辛普森同理：每对区间误差 $O(h^5)$，共 $m$ 对，$m h^5=(b-a)h^4$，得 $O(h^4)$。<span class="marginnote">注意一个细节：复化辛普森要求段数 $n=2m$ <strong>为偶数</strong>——因为辛普森每组要 3 个点。段数选奇数时，最后一段要特殊处理或干脆加一段。</span>

## 4 收敛阶与节点数的关系

两种复化公式的「性价比」：

| 公式 | 节点数 | 收敛阶 | 误差缩水（$h\to h/2$） |
| --- | --- | --- | --- |
| 复化梯形 | $n+1$ | $O(h^2)$ | $1/4$ |
| 复化辛普森 | $2m+1$ | $O(h^4)$ | $1/16$ |

**用节点数说话**：要达到误差 $\varepsilon$，复化梯形约需 $O(\varepsilon^{-1/2})$ 节点，复化辛普森约需 $O(\varepsilon^{-1/4})$ 节点。**精度要求越高，辛普森的优势越碾压**——误差缩水比是平方级的差距。

**辨析｜易错点：** 复化梯形「段数加密」时，**新节点复用旧节点**（旧节点是子网格的子集）——这是龙贝格外推算法的关键。而如果从复化梯形 $T_n$ 升级到复化辛普森，要特别注意段数奇偶与节点复用策略，否则等于推倒重算。

## 5 复化 vs 单段高次：工程判断

| 情形 | 推荐 | 理由 |
| --- | --- | --- |
| 区间不长、函数光滑 | 单段辛普森 | 一步到位 |
| 区间长 / 精度要求高 | 复化辛普森 | 稳定收敛 |
| 函数不光滑（$f''$ 无界） | 复化梯形（或自适应加密） | 不依赖高阶导数 |
| 未知积分值、动态控误差 | 自适应复化（逐次加密） | 下一节逐次分半法 |

**工程结论：默认复化辛普森，特殊情形降级复化梯形或升格自适应**——这是绝大多数数值积分库（scipy 的 `quad` 类）的内部哲学。

## 6 小结

- **复化梯形** $T_n=\dfrac{h}{2}\bigl(f(a)+2\sum f(x_k)+f(b)\bigr)$：系数「端点 1、内部 2」，$O(h^2)$。
- **复化辛普森** $S_n=\dfrac{h}{3}\bigl(f(a)+4\sum f(x_{2k+1})+2\sum f(x_{2k})+f(b)\bigr)$：系数「1,4,2,…,4,1」，$O(h^4)$。
- 复化余项由「单段余项累加 + 平均值代替」得到：$R_T=-\tfrac{b-a}{12}h^2f''(\xi)$，$R_S=-\tfrac{b-a}{180}h^4f^{(4)}(\xi)$。
- 步长减半，梯形误差缩 $1/4$、辛普森缩 $1/16$；精度要求高时辛普森碾压。
- 默认复化辛普森，不光滑函数用复化梯形，动态控误差用自适应。
