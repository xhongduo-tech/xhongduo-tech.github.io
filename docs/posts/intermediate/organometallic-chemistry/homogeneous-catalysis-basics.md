## 为什么从均相催化开始

前 20 篇把金属有机化学的「积木」全部搭好了：成键、配体、配合物家族、基础反应（OA/RE/插入/消除/取代/进攻）。现在到验收时刻——**把这些积木组装成催化循环**。均相催化（homogeneous catalysis）是金属有机化学最伟大的应用出口：催化剂与底物在同一相（溶液）里，每个金属中心都是明确的分子，机理可以精确研究，配体可以精确微调。<span class="marginnote">与均相相对的是异相催化（固体催化剂，如铂网、铁催化剂）。均相催化的优势是「分子级可控」：每个活性中心都长一样，可以研究、可以改性、可以优化；劣势是「回收难」——催化剂溶解在产物里，工业上要蒸馏或萃取分离。</span>

这一节建立催化语言：什么是催化循环、怎么度量活性、基础反应怎么组装、以及催化剂为什么会死。

## 1 催化循环：从「两步反应」到「环形流水线」

**催化循环（catalytic cycle）**：催化剂（通常为低价、不饱和的金属配合物）依次完成一组基元反应，底物转化为产物，催化剂回到初始状态——周而复始。<span class="marginnote">循环的本质是「催化剂被消耗吗」——不消耗，只周转。每转一圈，底物变成产物，催化剂变回原样。所以催化剂写得越「不变量」，循环越健康。</span>

基础反应组装成循环的经典模板（加氢为例）：

1. **配体解离**：18 电子催化剂解离一个配体 → 16 电子（腾位）。
2. **氧化加成 $\ce{H2}$**：16 电子 + $\ce{H2}$ → 18 电子 M(H)₂。
3. **烯烃配位与插入**：烯烃插入 M–H → 18 电子 M–烷基。
4. **还原消除**：M–H 与 M–C 偶联 → 放出烷烃，金属回 16 电子。

**重点：催化循环 = 基元反应的「首尾相接」**。你在第 3 篇学的每一个反应（OA、RE、插入、取代、β-消除、进攻），都可能在任何循环的某一步出现。**会读循环 = 能在任意催化机理里逐个标出每步属于哪类基元反应**——这是金属有机化学最重要的分析技能。<span class="marginnote">读循环的练习方法：拿到一个催化机理图，先数「氧化态变了没有」把 OA/RE 挑出来，再找「配体流动」（插入/消除/取代），最后看「进攻」步骤。三步分类法能把任何复杂循环拆成你认识的积木。</span>

## 2 公式解析：活性度量 TOF 与 TON

催化剂的活性与寿命用两个数衡量，公式定义必须精确：

$$
\text{TON} = \frac{\text{产物物质的量}}{\text{催化剂物质的量}}, \qquad
\text{TOF} = \frac{\text{TON}}{\text{时间}}
$$

- **TON（turnover number，周转数）**：一分子催化剂最多转化的底物分子数。度量「寿命」与「效率上限」。工业催化 TON 常在 $10^3$–$10^6$。<span class="marginnote">TON 高说明催化剂耐活：工业上 TON 直接决定催化剂成本——每克催化剂能产多少吨产物。制药合成常要求 TON > 10³ 才划算。</span>
**TOF（turnover frequency，周转频率）**：单位时间内每分子催化剂的周转次数，单位常用 $\mathrm{h^{-1}}$ 或 $\mathrm{s^{-1}}$。度量「速度」。
**关系**：TOF = TON / 时间；两者分开报告，因为「快而不久」（高 TOF 低 TON）与「久而不快」（高 TON 低 TOF）都是可能的失败模式。<span class="marginnote">工业选催化剂要在 TOF 与 TON 间权衡：连续生产要 TOF（快），间歇釜式要 TON（耐用）。一个极端例子：酶是「极高 TOF + 适中 TON」；而一些稀有金属催化剂 TON 极高但 TOF 一般。</span>

**活化能视角**：催化剂降低的是**反应的活化能**，不改变热力学（ΔG）。催化循环里每个基元步骤都有各自的活化能，**决速步（rate-determining step）**是活化能最高的那一步，决定整体速率。

## 3 均相 vs 异相：一张对比表

| 维度 | 均相催化 | 异相催化 |
| --- | --- | --- |
| 相态 | 催化剂与底物同相（溶液） | 固相催化剂 + 液相/气相底物 |
| 活性中心 | 明确、单一（每个分子都同） | 表面多位点、分布不均 |
| 机理研究 | 可直接做动力学、光谱、同位素 | 难，需要表面表征 |
| 选择性 | 高（配体可精细调） | 较低（位点混杂） |
| 回收 | 难（溶解在产物里） | 易（过滤/离心） |
| 耐热 | 较低（配体怕高温） | 高 |
| 典型例 | Wilkinson 加氢、Monsanto 醋酸 | 铂重整、铁催化合成氨 |

**重点：均相催化是「把异相的表面问题搬进分子尺度」**——每一个金属中心都像异相表面的一个「理想位点」，可以精确设计。这也是为什么均相催化常被用来「理解」异相催化。

## 4 催化剂的失活与副反应

催化剂不是永动机，最常见的失活机制有五种，值得记住：

1. **配体解离 + 金属聚集**：16 电子金属不稳定，两个金属碰到一起形成二聚体/金属沉淀（失活）。
2. **β-氢消除副反应**：把本该链增长/转金属的中间体「偷走」，生成烯烃副产物。
3. **配体氧化/分解**：膦配体被氧化成氧化膦（失去给电子能力）。
4. **毒化**：杂质（$\ce{O2}$、$\ce{H2O}$、含 S/N 化合物）抢占配位位。
5. **产物抑制**：产物与催化剂结合太紧，循环卡壳。

**辨析｜易错点：** 别把「催化剂失活」误当成「催化剂用完」。催化剂的量**不变**（循环内守恒），失活是**循环外**的消耗路径——失活反应的活化能低，循环跑得越快，失活相对越少。**设计催化剂时，稳定「循环外的空位态」与加速「循环内的基元步」同样重要**。<span class="marginnote">实践中常用「大位阻配体 + 富电子配体」双保险：大位阻阻止金属-金属聚集，富电子促进 OA——这正是 Buchwald 型配体、NHC 配体受宠的根本原因：它们让金属「既忙得过来（循环内）又死不了（循环外）」。</span>

## 5 均相催化的工业版图

均相催化把「基础反应积木」做成了工业：**加氢**（Wilkinson、BINAP 不对称加氢）、**氢甲酰化**（Co/Rh，全球千万吨级）、**醋酸合成**（Monsanto/Cativa，Rh/Ir）、**交叉偶联**（Pd，制药核心）、**烯烃聚合**（Ziegler-Natta、茂金属）、**烯烃复分解**（Grubbs）。<span class="marginnote">据统计，全球约 20–30% 的工业化学品生产至少经过一个金属催化步骤。均相催化不仅是金属有机化学的应用出口，更是现代化学工业的「隐形支柱」。</span>

接下来几节会逐个深挖这些工业反应——但请记住它们的共同骨架：**配体解离腾位 → 氧化加成/配位吃底物 → 插入/转移构建新键 → 还原消除放产品**，然后周而复始。

### 催化循环的「读图」训练法

催化机理图看起来复杂，其实可以用一个固定流程拆解：

**第一步，找氧化态变化**：图里哪几步金属氧化态变？那必然是 OA 或 RE（电子过户），标出来。

**第二步，找配体流动**：剩下不变氧化态的步骤，是取代（配体进出）、插入/消除（配体重组）、还是进攻（外来试剂打位点）？

**第三步，连线成环**：把步骤按顺序串成环，检查「催化剂回到起点没有」——如果没回起点，说明你漏了一步或机理图画错了。<span class="marginnote">这个「三步读图法」对任何催化循环通用：加氢、氢甲酰化、偶联、复分解都能套。练过十几个循环之后，你看到机理图的反应会从「天书」变成「积木」。这正是均相催化基础原理最该练成的技能。</span>

### 决速步与催化效率的杠杆

循环里每步都快，唯独决速步最慢——整体速率被它卡住。怎么找决速步、怎么加速它：

- **实验找**：改变某底物浓度看整体速率变不变；测同位素效应（KIE）；观察中间体积累（决速步前中间体浓度最高）。
- **理论加速**：针对决速步做配体设计——决速步是 OA，就加富电子配体；是 RE，就加吸电子/大位阻配体；是取代，就调解离速度。
- **工业含义**：决速步决定「反应要多大的釜、多长的时间」。优化决速步，等于优化整条生产线的产能。

**要点**：催化优化的本质是「找到最慢的那一步，然后只改它」。泛泛地「提高催化剂活性」常常无效，精准打击决速步才有效——这个「定位-打击」思维与调优任何复杂系统都是相通的。

### 均相催化的「绿色」与「可持续」面向

均相催化还有一个常被忽视的价值——绿色化学：

- **原子经济**：催化反应不产生化学计量副产物（对比：化学计量氧化剂/还原剂会留下大量废盐）。
- **温和条件**：低压、低温的催化工艺（如 Rh 氢甲酰化）能耗远低于老式高压工艺。
- **可再生原料**：催化把 $\ce{CO2}$、生物质等廉价碳源转化为燃料与化学品——「碳中性循环」的分子学基础。<span class="marginnote">绿色化学不是口号：均相催化让「原子经济 + 温和条件 + 可再生原料」三者同时成立，这在传统化学计量反应里几乎不可想象。未来「电催化 + 金属有机」结合，可能是把 $\ce{CO2}$ 变燃料的最终答案。</span>

**一句话收束绿色面向**：均相催化是绿色化学的「天然盟友」——它不产生计量废盐、不依赖高温高压、能利用可再生原料。学这一节的绿色视角，是为了让你在「催化剂活性」之外，永远记得「催化剂对环境的影响」这一维。

## 6 小结

- **催化循环 = 基元反应的首尾相接**：配体解离腾位 → OA/配位吃底物 → 插入/转移建键 → RE 放产品。
- **两个度量**：TON 度量寿命与效率上限，TOF 度量速度；两者分开报告，「快而不久」与「久而不快」都是失败模式。
- **均相 vs 异相**：均相「分子级可控、可研究、选择性高」，异相「易回收、耐热」——工业上两者互补。
- **失活五机制**：配体解离 + 金属聚集、β-消除、配体氧化、毒化、产物抑制——稳定循环外的空位态同样重要。
- **三步读图法**：找氧化态变化（OA/RE）→ 找配体流动（取代/插入/进攻）→ 连线成环验起点。
- **决速步思维**：找到最慢的那一步，只改它——「定位-打击」是催化优化的第一原则。
