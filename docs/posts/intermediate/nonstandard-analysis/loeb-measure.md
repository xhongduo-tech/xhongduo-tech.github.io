## 为什么从 Loeb 测度开始

超有限概率空间给我们一幅诱人的画面：$\Omega = \{1, 2, \dots, N\}$，每个点的概率都是 $1/N$（一个无穷小），总共 $N \cdot (1/N) = 1$。它有 $N$ 个「等可能」的结果，听起来像极了有限概率论——但问题是，**$1/N$ 不是标准实数**，我们不能直接拿它做概率计算。除非……把整个结构「取标准部分」，铸成一个真正的、标准的概率测度。这就是**Loeb 测度**做的事。

1975 年，Loeb 证明了：**任何超有限空间上的内测度，取标准部分后都能扩张成一个标准的 $\sigma$-可加测度**。<span class="marginnote">这条定理的重要性怎么强调都不过分：它把非标准分析从「微积分的另类证明工具」升级为「构造新数学对象的工厂」。概率论里最核心的对象——布朗运动、维纳测度、Lévy 过程——都可以从超有限随机游走「取标准部分」得到。非标准概率论就此诞生。</span>本篇的目标是把 Loeb 构造讲清楚，并说明它为什么是「免费」的——几乎不用新的技术装备，靠 Carathéodory 扩张定理就够了。

## 1 内测度：超有限空间的「概率」

先明确我们要取标准部分的对象。设 $\Omega$ 是一个**超有限集**，$|\Omega| = \nu$（超自然数）。对任意内集 $A \subseteq \Omega$，定义它的**内概率**（internal probability）

$$P(A) = \frac{|A|}{\nu}$$

其中 $|A|$ 是 $A$ 的超有限基数。<span class="marginnote">$P$ 是「内」的：它由公式定义，参数是 $\nu$，受转移原理管辖。对 $A$ 超有限，$|A|$ 是超自然数，$P(A)$ 是一个 $[0,1]$ 内的超实数。它满足有限可加性：$P(A \cup B) = P(A) + P(B)$ 对互斥的 $A, B$ 成立——这是「有限概率的加法规则」转移过来的。</span>

**核心概念：内测度（internal measure）**。更一般地，设 $\mathcal{A}$ 是 $\Omega$ 上的一个**内代数**（由内集组成的布尔代数，对有限并、交、补封闭），$P: \mathcal{A} \to {}^*[0,1]$ 满足：$P(\emptyset) = 0$，$P(\Omega) = 1$，且对 $\mathcal{A}$ 中互斥的有限个 $A_1, \dots, A_k$ 有 $P(\bigcup A_i) = \sum P(A_i)$。这样的 $P$ 称为 $\Omega$ 上的**内概率测度**。

**要点：内测度只有有限可加性，没有 $\sigma$-可加性。** 这来自转移原理：$\mathbb{R}$ 里「有限可加概率」转移成「${}^*\!\mathbb{R}$ 里的有限可加内概率」，而「可数可加」是不可一阶表达的（涉及可数并），因此不转移。**Loeb 构造的全部工作，就是把「有限可加的内测度」升级成「可数可加的标准测度」**。<span class="marginnote">这里能看到非标准方法的核心张力：超有限世界只有「有限数学」，而概率论需要「可数可加」这个无穷数学。Loeb 的伟大在于指出——<strong>取标准部分这个「外部动作」恰好把有限可加升级成了可数可加</strong>。有限与无穷之间不是鸿沟，而是一个 $\operatorname{st}$ 的距离。</span>

## 2 Loeb 构造：四步走

给定超有限空间 $(\Omega, \mathcal{A}, P)$，构造标准测度分四步。

**第 1 步：取标准部分得到实值函数。** 对每个 $A \in \mathcal{A}$，$P(A)$ 是 $[0,1]$ 里的超实数，故有标准部分 $\operatorname{st}(P(A)) \in [0,1]$。记 $P_L(A) = \operatorname{st}(P(A))$。

**第 2 步：验证 $P_L$ 是 $\mathcal{A}$ 上的有限可加测度。** 对互斥的 $A, B \in \mathcal{A}$：

$$P_L(A \cup B) = \operatorname{st}\bigl(P(A \cup B)\bigr) = \operatorname{st}\bigl(P(A) + P(B)\bigr) = \operatorname{st}(P(A)) + \operatorname{st}(P(B)) = P_L(A) + P_L(B)$$

中间那步用的是标准部分映射的加法性（$x, y$ 有限时 $\operatorname{st}(x+y) = \operatorname{st}(x) + \operatorname{st}(y)$，见《标准部分映射》）。**$P_L$ 是 $\mathcal{A}$ 上的标准有限可加测度**，取值于标准 $[0,1]$。<span class="marginnote">加法性在取标准部分后保持，是因为加法只涉及<strong>两个</strong>量，是「有限代数」。这就是为什么 Loeb 构造的门槛只是有限可加：标准部分的代数性质刚好覆盖有限步运算，而可数运算则要交给下一步的扩张定理。</span>

**第 3 步：Carathéodory 扩张。** $P_L$ 定义在 $\mathcal{A}$（一个代数）上、有限可加、非负、归一化。**Carathéodory 扩张定理**保证：它可以唯一扩张到 $\sigma(\mathcal{A})$（由 $\mathcal{A}$ 生成的最小 $\sigma$-代数）上的一个**$\sigma$-可加**测度，且扩张方式与 Carathéodory 外测度一致。<span class="marginnote">Carathéodory 扩张是测度论的标准机器，详见本站《实变函数与测度论》。它的内容：代数上的有限可加非负测度，可以扩张成 $\sigma$-代数上的 $\sigma$-可加测度，扩张由外测度技巧实现。Loeb 构造在这里直接调用现成的定理，不发明新工具。</span>

**第 4 步：完备化。** 通常再取一次完备化（把测度为 0 的集合的子集也纳入可测），得到的 $\sigma$-代数称为 **Loeb 代数**，记作 $\mathcal{L}(\mathcal{A})$；扩张后的测度称为 **Loeb 测度**，记作 $P_L$（或 $\mu_L$）。完成后的空间 $(\Omega, \mathcal{L}(\mathcal{A}), P_L)$ 称为 **Loeb 空间（Loeb space）**。

## 3 公式解析：为什么标准部分能把「有限」升级成「可数」

**这是整篇最关键的一步**：$P_L$ 在代数 $\mathcal{A}$ 上只是有限可加，扩张到 $\sigma(\mathcal{A})$ 后凭什么变成可数可加？Carathéodory 定理给出的是「扩张存在」，但我们要看清「为什么无穷个超有限和能塌缩成标准值」。

设 $A_1, A_2, \dots$ 是 $\mathcal{A}$ 中两两不交的可数族，且 $\bigcup_{n} A_n \in \sigma(\mathcal{A})$。我们要验证 $P_L(\bigcup_n A_n) = \sum_n P_L(A_n)$。关键在于比较**内有限并**与**可数并**：

- 对每个标准自然数 $m$，有限并 $\bigcup_{n=1}^{m} A_n$ 是内集，且

$$P_L\!\left(\bigcup_{n=1}^m A_n\right) = \sum_{n=1}^m P_L(A_n) \quad \text{（有限可加）}$$

- 由 Carathéodory 扩张的内外包夹性质，$P_L(\bigcup_n A_n) = \sup_m P_L(\bigcup_{n=1}^m A_n)$（单调收敛）。右边正是 $\sum_n P_L(A_n)$。

**公式解析，分三步：**

1. **有限可加打底**：对任意有限 $m$，等式成立，这是 $P_L$ 在代数上的属性。
2. **超有限补刀**：把「$\bigcup_{n=1}^\infty$」与「$\bigcup_{n=1}^m$」的差压到任意小——Carathéodory 扩张保证单调收敛 $\sup_m$ 与 $\sigma(\mathcal{A})$ 上的值一致。
3. **标准部分兜底**：$P_L$ 的每一项都是标准实数，级数 $\sum_n P_L(A_n)$ 是标准级数，其收敛性由 $\leq 1$ 保证。

最终，**可数可加不是被「发明」的，而是被「补全」的**——有限可加的代数测度在扩张到 $\sigma$-代数时，自动获得可数可加性。<span class="marginnote">直觉：超有限空间里「$N$ 个点每个概率 $1/N$」在标准视角下就是「均匀分布」；把可数多个不相交的「标准事件」加起来，其标准部分恰好是每个事件的概率之和——因为可数级数的部分和是有限可加给出的，而它们的上确界就是标准部分能看到的全部。</span>

## 4 关键性质与第一个应用：均匀 Loeb 测度

设 $\Omega = \{1, 2, \dots, N\}$（$N$ 无穷大），$P$ 是均匀内概率。它的 Loeb 测度 $P_L$ 是什么？直觉告诉我们应该是 $[0,1]$ 上的勒贝格测度——但它定义在 $\Omega$ 上，而 $\Omega$ 是离散的超有限集！

**答案的妙处**：考虑标准单位区间 $[0,1]$，把标准可测集 $B$ 对应到「$B$ 附近的超有限点集」$B^\wedge = \{k/N \in \Omega \mid k/N \approx x \text{ 对某 } x \in B\}$ 的某个内近似，则

$$P_L(B^\wedge) = \operatorname{st}\!\left(\frac{|B^\wedge|}{N}\right) = \lambda(B)$$

其中 $\lambda$ 是勒贝格测度。<span class="marginnote">换句话说：<strong>超有限格点上的均匀 Loeb 测度，透过「标准部分」投影回 $[0,1]$，就是勒贝格测度</strong>。离散的超有限空间，竟承载着连续的标准测度——这是 Loeb 构造最令人称奇的「化离散为连续」。</span>更严谨的表述要用到**非标准延拓**与 **Loeb 映射**：$P_L$ 在「$B$ 的标准部分原像」上的限制与 $\lambda(B)$ 一致。这说明 Loeb 构造不是旁门左道，而是与标准测度论无缝衔接的。

**Loeb 空间的三条通用性质**，值得钉进记忆：

1. **完备**：测度为 0 的集合的子集都可测（完备化保证了这一点）。
2. **每个内集都可测**：$\mathcal{A}$ 里的所有内集都是 Loeb 可测的（它们本来就在代数里）。
3. **与外测度相容**：对任意集合 $C$（不一定是内集），$P_L^*(C) = \inf\{P_L(B) \mid C \subseteq B, B \in \sigma(\mathcal{A})\}$，与外测度的经典定义一致。

## 5 应用速览：布朗运动的非标准构造

Loeb 测度最重要的应用，是用超有限随机游走造出布朗运动。思路一句话：**把布朗运动「离散化」成超有限步随机游走，再用 Loeb 测度把路径空间做成标准概率空间**。

**构造草图**：固定无穷大 $N$，令 $dt = 1/N$（无穷小时间步），$dx = 1/\sqrt{N}$（无穷小空间步——注意 $\sqrt{N}$ 的选择来自中心极限定理的尺度，$N$ 步随机游走的涨落是 $\sqrt{N}$ 量级）。取路径空间

$$\Omega = \left\{\omega = (\omega_1, \dots, \omega_N) \mid \omega_k = \pm 1\right\}$$

这是超有限集，$|\Omega| = 2^N$。配均匀内概率：每个单点路径概率 $2^{-N}$（一个无穷小）。随机游走定义为

$$X_t(\omega) = dx \sum_{k \leq t/dt} \omega_k, \qquad t \in [0, T]$$

**核心观察**：对每个标准时刻 $t$，$X_t$ 是 $t/dt = Nt$ 个独立 $\pm dx$ 之和；由转移的中心极限定理，$X_t$ 的分布「几乎」是方差为 $t$ 的正态分布。于是把 $X_t$ 的 Loeb 路径测度「压」回连续路径空间 $C[0,T]$，得到的标准测度**正是维纳测度**——布朗运动就是这样从「等概率的超有限硬币序列」里长出来的。<span class="marginnote">这个构造的美感在于：布朗运动的一切连续性、不可微性、马尔可夫性，全都编码在「$N$ 枚公平硬币」这个最简单的超有限对象里。<strong>离散硬币 + Loeb 测度 = 连续随机过程</strong>，非标准概率论的座右铭。</span>

**要点**：这里 $2^{-N}$ 个等概率路径的 Loeb 测度，是一个真正定义在「不可数多个连续路径」上的 $\sigma$-可加测度——用标准方法，构造维纳测度需要科尔莫戈罗夫扩展定理、紧性论证等一大套；Loeb 路线把它化成「均匀硬币的超有限化」。<span class="marginnote">随机过程在《随机过程》与《随机分析》里有标准构造。这里展示的是非标准路线：<strong>更短、更直观，且与标准理论完全等价</strong>。对于需要在无穷维空间上搭测度的问题（如路径积分、随机偏微分方程），Loeb 空间常常是最省力的工具。</span>

## 6 辨析：Loeb 测度的三个陷阱

**辨析｜易错点：**

1. **Loeb 测度不是「逐点取标准部分」**。$\operatorname{st}(P)$ 作为函数只在**内集**上有定义；对非内集 $C$，$P(C)$ 根本不存在，谈不上取标准部分。正确做法是通过 Carathéodory 扩张从内代数延拓到 $\sigma(\mathcal{A})$。**「先扩张，后取标准」的顺序不能颠倒**。
2. **Loeb 可测 ≠ 内集**。$\mathcal{L}(\mathcal{A})$ 包含许多非内集（如 $\mathbb{N}$、所有单子），它们是「内集的极限」。**Loeb 测度覆盖了内集之外的广阔外集世界**——这正是它能测「连续对象」的原因。
3. **$P_L$ 不总是「均匀的」**。若原始内测度非均匀（各点权重不同），Loeb 测度也不是均匀的。**Loeb 构造保留内测度的「形状」，只是把取值从超实数规整成标准实数**。<span class="marginnote">最后一个陷阱的正面表述：Loeb 构造是「保结构的规整化」。它不创造新的测度结构，只把超有限内测度的「影子」落到标准世界里——所以从概率论的角度，超有限模型与标准模型的「信息量」是一样的。</span>

## 7 小结

- **内测度**：超有限空间上的有限可加、取值 $[0,1]$ 内超实数的测度；只有有限可加，没有 $\sigma$-可加。
- **Loeb 构造**：$\operatorname{st}(P)$ → 标准有限可加 → Carathéodory 扩张 → 完备化，得到 $\sigma$-可加的标准测度。
- **关键机制**：标准部分把「有限可加」升级成「可数可加」，全靠 Carathéodory 扩张补全 + 标准级数收敛。
- **均匀例**：超有限格点上的均匀 Loeb 测度 = 勒贝格测度；**离散承载连续**。
- **布朗运动**：$N$ 枚公平硬币 + Loeb 测度 = 维纳测度；随机过程从超有限里长出来。
- **陷阱**：不能逐点取标准部分；Loeb 可测 ≠ 内集；内测度的形状决定 Loeb 测度的形状。

Loeb 测度是非标准概率论的根基，也是「超有限方法」的集大成者。但到目前为止，我们讨论的对象都局限在超实数域 $\mathbb{R}$ 的扩张内部。在下一节，我们把视野拉开：**非标准拓扑**——用单子重新刻画开集、紧致、连续，让整个点集拓扑也沐浴在 $\approx$ 的微光之下，届时你会看到紧致性在非标准语言里几乎长成一个平凡的事实。
