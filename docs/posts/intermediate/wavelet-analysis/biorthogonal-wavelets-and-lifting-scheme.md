## 为什么从双正交开始

上一讲的 Daubechies 小波达到了「紧支撑 + 光滑」的最优，却留下一个遗憾：**不对称**。图像处理、信号压缩里，对称滤波器保证线性相位、避免重建时的相位畸变——这是一项实打实的工程需求。要对称，就得付出代价：放弃正交性，改用**双正交（biorthogonal）**小波。这一讲先讲双正交的数学结构，再讲它的王牌实现——**提升格式（lifting scheme）**。<span class="marginnote">对称性的价值在图像里一眼可见：对称滤波器对左右边缘一视同仁，重建不产生「相位扭曲」的波纹；不对称滤波器会让图像细节像被风吹歪了一样。JPEG 2000 最终选择双正交 9/7 小波，正是工程对数学的务实让步。</span>

## 1 正交性为什么容不下对称

回忆正交小波的约束：高通滤波器 $g[n] = (-1)^{1-n}h[1-n]$ 由低通镜像而来。这个镜像关系强制了某种「交替」结构，与「对称」不可兼得。

**Daubechies 定理（对称性版本）**：紧支撑、正交、且滤波器对称（或反对称）的小波，只能是 Haar 小波。<span class="marginnote">这条定理是 1993 年由 Daubechies 本人与 Cohen 等人在研究「紧支撑正交小波与对称性」时确立的。它把工程师堵在墙角：要么正交 + 不对称（Daubechies），要么对称 + 放弃正交（双正交），没有第三个选项。</span>

**重点：** 唯一例外是 Haar（db1），它既正交又反对称，但代价是只有 1 阶消失矩、不连续。想同时要「对称 + 光滑 + 紧支撑」，就必须把「同一族基完成分解与合成」这个限制放掉。

## 2 双正交小波：两套基，各司其职

双正交的思路是：**分解用一族基，合成用另一族对偶基**，两族都不必正交，但彼此「双正交」：

$$\langle \psi_{j,n},\; \tilde\psi_{j',n'}\rangle = \delta_{j,j'}\, \delta_{n,n'}$$

这里 $\tilde\psi$ 是**对偶小波（dual wavelet）**。<span class="marginnote">回忆第 3 讲的框架理论：双正交小波就是「刚好冗余为 1」的框架——分解框架 $\{\psi_{j,n}\}$ 与其对偶框架 $\{\tilde\psi_{j,n}\}$ 一一配对，重建公式退化为最简形式。框架理论在这里从「允许冗余」走到「临界非冗余」。</span>

对应的滤波器有两套：分析端（分解）用 $\tilde h, \tilde g$，合成端（重构）用 $h, g$。它们不再是镜像关系，而是满足**完美重建条件**：

$$\sum_n h[n]\, \tilde h[n+2m] = \delta_m, \qquad \sum_n h[n]\, \tilde g[n+2m] = 0, \qquad \ldots$$

**重点：** 双正交给了设计者两个独立旋钮：分解小波 $\tilde\psi$ 可以设计得光滑、对称、适合分析；合成小波 $\psi$ 也可以独立取舍。代价是**两族之间只有双正交、没有正交**——系数能量与信号能量不再严格相等（Parseval 式守恒破裂），但实际压缩去噪中这点偏差无伤大雅。

**辨析｜易错点：** 双正交 ≠ 分解合成用完全无关的滤波器。它们必须满足「交叉归一化」条件，否则重建会失真。工程上总是成对出现（如 9/7 的分解端与合成端），不要单独取一端。

### 完美重建的四个条件

双正交滤波器组能逐位重建，靠的是下面四条交叉约束（约定 $m$ 为任意整数）：

| 约束 | 数学表达 | 含义 |
| --- | --- | --- |
| 低通-低通 | $\sum_n h[n]\,\tilde h[n+2m] = \delta_m$ | 逼近支路内部归一、隔点正交 |
| 高通-高通 | $\sum_n g[n]\,\tilde g[n+2m] = \delta_m$ | 细节支路内部归一、隔点正交 |
| 低通-高通 | $\sum_n h[n]\,\tilde g[n+2m] = 0$ | 两支互不泄漏（对齐时） |
| 高通-低通 | $\sum_n g[n]\,\tilde h[n+2m] = 0$ | 两支互不泄漏（错位时） |

四条合起来保证「分解彻底分开、重构无损拼回」。<span class="marginnote">对照第 5 讲：正交小波里 $\tilde h = h$、$\tilde g = g$，四条约束退化成两条（低通自正交 + 高通是镜像）。双正交只是把「两端用同一组滤波器」放宽成「两端各自满足条件」，自由度从一组系数变成两组。</span>

## 3 CDF 9/7 与 5/3 小波

双正交小波家族里有两个名角：

**CDF 9/7 小波**：由 Cohen–Daubechies–Feauveau 构造，分解端滤波器长 9、合成端长 7，4 阶消失矩，几乎对称。<span class="marginnote">CDF 9/7 的 4 阶消失矩换来的是对光滑区域极强的压缩能力，配合它的近线性相位，使它成为 JPEG 2000 有损压缩的<strong>默认小波</strong>。图像压缩里它几乎是「事实标准」。</span>
**CDF 5/3 小波**：分解端长 5、合成端长 3，2 阶消失矩，滤波器系数是简单分数 $(\tfrac14, \tfrac12, \tfrac14)$ 一类，可精确实现。JPEG 2000 把它用于**无损模式**，因为整数到整数的变换可以逐位精确逆回。

**重点：** 5/3 小波之所以能无损，是因为它的提升实现是**整数到整数**的映射——这正是下一节提升格式的招牌能力。

## 4 提升格式：把变换拆成三步

1996 年，Sweldens 提出**提升格式（lifting scheme）**，把任何双正交小波变换重写为三个阶段：<span class="marginnote">提升格式的意义远超「换个实现」：(1) 完全 in-place，不额外占用内存；(2) 整数版本可逆，支持无损压缩；(3) 用「提升的改进」可以现场定制新小波。它把小波从「系数表格」解放为「算法配方」。</span>

**第一步，分裂（Split）**：把信号按奇偶位置分成两路——偶数样本 $x_e$（逼近候选）与奇数样本 $x_o$（细节候选）。这只是重排，无损。

**第二步，预测（Predict）**：用偶数样本预测奇数样本，预测误差就是细节系数：

$$d[n] = x_o[n] - P(x_e)[n]$$

预测器 $P$ 通常取偶数样本的局部平均（如相邻中点），预测越准，$d$ 的能量越小——**信号越光滑，细节越稀疏**。

**第三步，更新（Update）**：用细节修正偶数样本，得到逼近系数，保持低频均值不变：

$$a[n] = x_e[n] + U(d)[n]$$

更新器 $U$ 通常取细节的局部平均。整个变换完成后，**$a$ 与 $d$ 各占原信号一半，可以原位存放**，重构就是反序执行三步并反号。<span class="marginnote">预测-更新结构有个优雅性质：无论 $P$、$U$ 怎么选（甚至非线性、自适应），变换都是<strong>可逆的</strong>——因为每一步都是「用另一路减去一路」的三角形操作，反着来即可。这就是整数小波变换（IWT）能无损的数学根源。</span>

**重点：** 任何用 Mallat 滤波器实现的小波变换，都可以改写成提升实现，且**计算量约为滤波器实现的一半**（结构上的分而治之）。提升版本把「滤波器系数」转化为「预测器 + 更新器」两个更直观的算子。

### 一个手算的小例子：8 点信号走一遍提升

设输入信号 $x = [2, 2, 2, 2, 3, 3, 3, 3]$（前段平、后段高，中间有一处阶跃），用 5/3 提升走一遍：

- **分裂**：偶数样本 $x_e = [2, 2, 3, 3]$，奇数样本 $x_o = [2, 2, 3, 3]$。奇偶两路内容恰好相同。
- **预测**：$d[n] = x_o[n] - \tfrac{x_e[n] + x_e[n+1]}{2}$。逐点算：$d = [2 - 2, 2 - 2.5, 3 - 3, 3 - 3] = [0, -0.5, 0, 0]$。
- **更新**：$a[n] = x_e[n] + \tfrac{d[n-1]+d[n]}{4}$。得 $a = [2, 2 - 0.125, 3 - 0.125, 3] \approx [2, 1.875, 2.875, 3]$。

**读出含义：** 细节系数 $d$ 几乎全为零——唯一非零的 $-0.5$ 正好落在阶跃处，正是信号「不平滑」的所在；逼近系数 $a$ 则忠实保留了「前半 2、后半 3」的轮廓，且均值不变（$a$ 之和 $= 9.75$，$x_e$ 之和也是 $9.75$）。**一次提升就完成了「结构→大逼近系数 + 边缘→小细节系数」的分离**——这正是小波压缩、去噪在滤波器层面看到的景象。

**辨析｜易错点：** 例子里 $d$ 出现 $-0.5$，说明边界处的预测未必完美。工程上边界样本的预测常需特殊处理（对称延拓、边界预测器），否则边界细节会残留「假边缘」——这与第 6 讲边界问题的讨论是同一个问题在提升语境下的回声。

## 5 公式解析：提升三步

以 5/3 小波为例，写出完整的提升公式：

$$
d[n] = x_o[n] - \frac{x_e[n] + x_e[n+1]}{2}, \qquad a[n] = x_e[n] + \frac{d[n-1] + d[n]}{4}
$$

- **第一步，看分裂**：$x_o[n] = x[2n+1]$，$x_e[n] = x[2n]$。把序列按奇偶劈开，偶数支路暂作低频候选，奇数支路暂作高频候选。这一步只是重排，信息一点没丢。
- **第二步，看预测**：$d[n] = x_o[n] - \tfrac{x_e[n] + x_e[n+1]}{2}$。用左右两个偶数点平均去猜中间的奇数点，猜不准的部分就是细节。对光滑信号，奇数点几乎等于邻点平均，$d[n]\approx 0$——**细节被预测器「榨干」了**。这正是 $h$ 端消失矩在提升语言里的体现。
- **第三步，看更新**：$a[n] = x_e[n] + \tfrac{d[n-1]+d[n]}{4}$。把相邻细节的 $\tfrac14$ 加回偶数点，是为了**保持全信号均值不变**：$\sum a[n] = \sum x_e[n] + \tfrac14\sum(d[n-1]+d[n]) = \sum x_e[n]$（细节和为 0）。均值守恒是低频逼近的合格证。
- **第四步，看可逆**：重构就是反序：先 $x_e[n] = a[n] - \tfrac{d[n-1]+d[n]}{4}$，再 $x_o[n] = d[n] + \tfrac{x_e[n]+x_e[n+1]}{2}$，最后奇偶归位。每步都是直接解方程，**没有除不尽的数**——系数都是 $\tfrac12$、$\tfrac14$ 这类二进制分数，整数输入得整数输出，所以无损。
- **第五步，整体直觉**：提升把「全局卷积」换成「局部预测-修正」。它不依赖 Fourier 变换，因此**可以推广到任意采样、任意边界、甚至任意维数**——这正是 JPEG 2000 与新一代标准选它的深层原因。

## 6 小结

- **正交 + 紧支撑 + 对称不可兼得**：除 Haar 外，紧支撑正交小波必不对称；要对称就得双正交。
- **双正交小波**用分解/合成两套滤波器 $\tilde h,\tilde g$ 与 $h,g$，彼此满足交叉归一化（完美重建条件），分解与合成各司其职。
- **CDF 9/7 与 5/3** 是两大名角：9/7 用于 JPEG 2000 有损模式，5/3 的整数提升支持无损模式。
- **提升格式**三步走：分裂 → 预测 → 更新；无论 $P$、$U$ 怎么选都可逆，且计算量约为滤波器实现的一半。
- 提升实现是 in-place 的，整数到整数可逆——这是 5/3 小波能无损压缩的根源。

在下一节，我们将回到「选基」问题：标准小波只沿低频分解，小波包让高低频都继续分裂，用动态规划挑最稀疏的基——这就是**小波包与最优基选择**。
