## 为什么从 Mallat 算法开始

多分辨分析把小波分解讲成了「空间套空间」的理论，但真要在计算机上跑，需要把理论翻成迭代公式。1989 年，Mallat 给出了漂亮答案：**小波分解与重构可以写成一对离散滤波器组的递归**——本质就是「卷积 + 抽稀」和「插值 + 卷积」。这一讲把这条算法链拆到能直接抄成代码的程度。<span class="marginnote">Mallat 算法也叫「金字塔算法」「滤波器组算法」。它与快速 Fourier 变换（FFT）地位相当：FFT 让 Fourier 谱可算，Mallat 算法让小波系数可算——两者复杂度都是 $\mathcal{O}(N)$ 级，小波常数更小。</span>

## 1 从内积系数到滤波与抽稀

假设信号已经离散化为最细分辨率上的尺度系数 $a_J[n] = \langle f, \varphi_{J,n}\rangle$。Mallat 的核心观察：**相邻两层尺度的系数之间，存在简单的卷积关系。**

由双尺度方程 $\varphi(t) = \sqrt2 \sum_k h[k]\varphi(2t-k)$ 与 $V_j$、$V_{j-1}$ 的嵌套结构，可以推出分解关系：

$$a_{j-1}[n] = \sum_k h[k-2n]\, a_j[k] = (a_j \ast \bar{h})[2n]$$

$$d_{j-1}[n] = \sum_k g[k-2n]\, a_j[k] = (a_j \ast \bar{g})[2n]$$

其中 $\bar{h}[n] = h[-n]$ 是翻转（镜像）滤波器。<span class="marginnote">两个公式结构相同：先把 $a_j$ 与镜像滤波器做卷积，再<strong>隔点取样本</strong>（下采样，记为 $\downarrow 2$）。$a_{j-1}$ 是逼近系数（低通路径，走 $h$），$d_{j-1}$ 是细节系数（高通路径，走 $g$）。一次分解把序列长度减半，信息量守恒（两份半长序列 = 一份全长序列）。</span>

**重点：** 分解的每一步成本是 $\mathcal{O}(N)$（卷积）+ 一次下采样，而信号长度每层减半，所以**总复杂度是 $\mathcal{O}(N)$**——线性时间，比 FFT 的 $\mathcal{O}(N\log N)$ 还快一个量级。这正是小波能嵌入实时系统的底气。

### 一个手算例子：Haar 一步分解

拿最短的正交小波 Haar（滤波器 $h = [\tfrac1{\sqrt2}, \tfrac1{\sqrt2}]$，$g = [\tfrac1{\sqrt2}, -\tfrac1{\sqrt2}]$）对四信号 $x = [1, 2, 3, 4]$ 做一步分解：

**逼近**：$a[0] = \tfrac{x_0 + x_1}{\sqrt2} = \tfrac{3}{\sqrt2}$，$a[1] = \tfrac{x_2 + x_3}{\sqrt2} = \tfrac{7}{\sqrt2}$。偶数位是「相邻两点平均」，即局部平滑；
**细节**：$d[0] = \tfrac{x_0 - x_1}{\sqrt2} = -\tfrac{1}{\sqrt2}$，$d[1] = \tfrac{x_2 - x_3}{\sqrt2} = -\tfrac{1}{\sqrt2}$。奇数位是「相邻两点之差」，即局部斜率。

重构验证：$x_0 = \tfrac{a_0 + d_0}{\sqrt2} = 1$，$x_1 = \tfrac{a_0 - d_0}{\sqrt2} = 2$，依此类推逐位还原。<span class="marginnote">Haar 一步分解 = 「平均 + 差分」：$a$ 存平滑轮廓，$d$ 存相邻差异。这几乎是所有小波分解的最小模型——只要把「平均」换成更聪明的低通、「差分」换成更高阶的高通，就长成 dbN、9/7 等一切滤波器组。</span>

## 2 递归分解：二叉树

把分解递归套用：对逼近系数 $a_{J-1}$ 再分解，又得到 $a_{J-2}$ 与 $d_{J-2}$，如此反复 $L$ 层，得到：

$$a_{J-L},\quad d_{J-L},\; d_{J-L+1}, \ldots, d_{J-1}$$

这组序列就是信号 $f$ 的**小波表示**。<span class="marginnote">把分解过程画出来，是一棵「二叉树」：每层节点分裂成低通（左）与高通（右）两支。若只沿低通继续分裂，就是标准的小波分解树；若两路都继续分裂，就得到第 8 讲的小波包。</span>与原始信号相比，总样本数不变：$N = \tfrac{N}{2} + \tfrac{N}{4} + \cdots + \tfrac{N}{2^L} + \tfrac{N}{2^L}$，最后一项是余下的低频逼近。

**辨析｜易错点：** 分解到第 $L$ 层时，余下的 $a_{J-L}$ 也是「信号的一部分」，不能扔掉。很多初学者只存细节系数而丢弃最终逼近，重构时信息就残缺了。**完整表示 = 各级细节 + 最粗一层逼近。**

### 伪代码：L 层分解与完整重构

把 Mallat 算法写成可抄的伪代码，逻辑就一目了然：

```
# 分解（输入：最细尺度系数 a_J，长度 N）
for j = J, J-1, ..., J-L+1:
    a[j-1] = downsample( conv(a[j], fliplr(h)) )   # 低通支路
    d[j-1] = downsample( conv(a[j], fliplr(g)) )   # 高通支路

# 重构（输入：a[J-L], d[J-L..J-1]）
for j = J-L, J-L+1, ..., J-1:
    a[j+1] = conv(upsample(a[j]), h) + conv(upsample(d[j]), g)
```

每步 `downsample` 只取偶数位，`upsample` 在相邻样本间插零。滤波器的翻转 `fliplr` 对应分解用的镜像 $\bar h, \bar g$。<span class="marginnote">这段伪代码就是 PyWavelets 等库 `wavedec` / `waverec` 的骨架。实际的库还会处理延拓方式、滤波器边界截断与系数对齐——理解骨架后，读库文档就像读自己的代码。</span>

**重点：** 分解与重构的循环**层数相同、方向相反**，滤波器互为镜像、下采样与上采样互逆——只要滤波器满足完美重建条件（第 7 讲的双正交约束），循环迭代多少次都不会积累误差（理论层面）。

## 3 重构：插值与卷积回加

重构是分解的精确逆操作。给定 $a_{j-1}$ 与 $d_{j-1}$，先**隔点插零**（上采样，记为 $\uparrow 2$），再分别与滤波器 $h$、$g$ 卷积，最后相加：

$$a_j[n] = \sum_k h[n-2k]\, a_{j-1}[k] + \sum_k g[n-2k]\, d_{j-1}[k]$$

写成工程记号：$a_j = \uparrow 2\,(a_{j-1}) \ast h + \uparrow 2\,(d_{j-1}) \ast g$。<span class="marginnote">重构是分解的<strong>镜像</strong>：分解先滤波再抽稀，重构先插值再滤波；分解用 $\bar h,\bar g$，重构用 $h,g$；高通、低通角色互换方向。这个「分析/合成滤波器组」的完美对偶性，是正交小波独有的红利——双正交情形（第 7 讲）里分析与合成滤波器会不同。</span>

**重点：** 正交情形的分解-重构满足**完美重建（perfect reconstruction）**：重构出来的 $a_j$ 与分解前的输入逐位相等（忽略浮点舍入）。这不是近似而是恒等——滤波器系数由双尺度方程严格导出，信息在每个环节都无损转移。

**复杂度为什么重要：** 一次 $L$ 层分解总成本约 $2LN$ 次乘加（每层滤波 $2N$ 量级），与信号长度**线性**相关；而直接按定义算小波系数是 $\mathcal{O}(N^2)$。对 1 秒的 44.1 kHz 音频（$N = 44100$），线性算法毫秒级完成，二次算法要算几十秒——**复杂度从平方降到线性，小波才从理论变成可以实时跑的工具**。

## 4 边界问题：信号有限长怎么办

理论假定信号无限长，实际信号有限长。卷积在边界处会「越界」，常用的处理有三种：<span class="marginnote">教科书常用「周期延拓」讲理论；工程实现里「对称延拓」几乎总是更优——它不引入边界跳变，细节系数在边界处小得多，压缩与去噪效果更好。JPEG 2000 默认就采用对称延拓。</span>

- **零延拓**：越界处补 0。简单，但边界跳变会在最细细节里制造伪迹。
- **周期延拓**：把信号首尾相接成环。适合周期性信号，一般信号会引入边界不连续。
- **对称延拓**：把信号关于边界镜像翻转。保持连续性，是工程默认选择。

**辨析｜易错点：** 延拓方式不是实现细节，而是会影响系数的「内容」。两种延拓得到的边缘细节系数可能差异巨大——在去噪或压缩里，这直接决定边缘处的重建质量。选错延拓，边界上会冒出一圈「小波鬼影」。

## 5 公式解析：一步 Mallat 分解

$$
a_{j-1}[n] = \sum_k h[k-2n]\, a_j[k]
$$

- **第一步，看 $h[k-2n]$**：这是镜像滤波器 $\bar h$ 的采样。固定输出位置 $n$，卷积核被平移到 $2n$ 处——$2n$ 里的 2 就是下采样的来源：输出第 $n$ 个点只用到输入的偶数位置。
- **第二步，看求和下标 $k$**：$k$ 遍历输入 $a_j$ 的所有位置。但 $h$ 只有有限支撑（比如 db2 的 4 个非零系数），实际求和只有滤波器长度项——**每个输出点只做常数次乘加**，这就是 $\mathcal{O}(N)$ 的来源。
- **第三步，看输入输出长度**：$a_j$ 有 $N$ 个点，$a_{j-1}$ 有 $N/2$ 个点（取偶数样本）。每层减半，$L$ 层后长度 $N/2^L$。
- **第四步，整体直觉**：把「做内积（算小波系数）」这个重活，拆成了「局部卷积」与「隔点取半」两个轻动作。**复杂的高维积分被摊平成一次滤波器递归**——这就是 Mallat 算法把 MRA 从纸上搬到芯片上的全部秘密。
- **第五步，重构对照**：逆操作 $a_j[n] = \sum_k h[n-2k]a_{j-1}[k] + \sum_k g[n-2k]d_{j-1}[k]$ 在偶数位由低通支路贡献、奇数位由高通支路贡献，两路互补——若丢掉高通支路，就是最朴素的**低通平滑（多分辨率模糊）**，这正是图像金字塔的做法。

## 6 小结

- **Mallat 分解**：$a_{j-1} = (a_j\ast \bar h)\!\downarrow\!2$，$d_{j-1} = (a_j\ast \bar g)\!\downarrow\!2$，即「镜像滤波 + 抽稀」。
- **递归 L 层**得到 $a_{J-L}, d_{J-L}, \ldots, d_{J-1}$，总样本数守恒；复杂度 $\mathcal{O}(N)$。
- **Mallat 重构**：插值 + 滤波 + 相加，是分解的精确逆；正交情形满足**完美重建**。
- 有限长信号需选**延拓方式**：零、周期、对称三种，对称延拓是工程默认。
- 边界延拓影响边缘系数的内容与重建质量，不是实现琐事。
- Haar 一步分解 = 「平均 + 差分」；一切更复杂的滤波器组都是这个最小模型的推广。
- 每层长度减半、总样本守恒；总复杂度 $\mathcal{O}(N)$，比 FFT 的 $\mathcal{O}(N\log N)$ 还快一个量级，是小波能实时运行的关键。
- 分解与重构互为镜像：分解先滤波再抽稀，重构先插值再滤波；滤波器镜像、上下采样互逆，构成「分析/合成滤波器组」。
- 完整表示 = 各级细节 + 最粗一层逼近；丢弃最终逼近会丢失信息，重构必然残缺。
- 延拓方式（零、周期、对称）不是实现琐事，它直接影响边缘细节系数与重建质量，JPEG 2000 默认对称延拓。
- 一步分解 = 卷积 + 隔点取半：每个输出点只做常数次乘加，这就是线性复杂度的来源。

在下一节，我们将面对现实：Daubechies 小波不对称、整数精度难保证——用双正交与提升格式来解决，这就是**双正交小波与提升格式**。
