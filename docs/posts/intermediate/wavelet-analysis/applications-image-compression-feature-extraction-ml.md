## 为什么从应用开始

前九讲完成了一条完整的理论链：从 Fourier 的局限 → 窗口 Fourier → 连续小波 → 框架 → MRA → 正交基构造 → Mallat 算法 → 双正交与提升 → 阈值去噪。这一讲把整条链收束到两个真实的落地点：**图像压缩（JPEG 2000）**与**特征提取 + 机器学习**。看懂这两个应用，就真正理解了小波为什么「值得学」。<span class="marginnote">小波的应用远不止这两处：地震勘探、心电分析、语音编码、视频压缩、指纹识别、湍流分析……它们共享同一条底层逻辑——<strong>多尺度局部化</strong>。本讲选压缩与 ML 作为代表，因为它们各自押中了小波最重要的两个性质：稀疏表示与多分辨率。</span>

## 1 JPEG 2000：从 DCT 到 DWT 的压缩革命

传统 JPEG（1992）把图像切成 $8\times 8$ 的块，逐块做离散余弦变换（DCT），再量化高频系数。分块带来两个顽疾：**块效应**（块边界可见的格子）与**无法渐进传输**（低码率下整幅图一起糊）。

JPEG 2000（2000）用**离散小波变换（DWT）**替换 DCT，做了三件事：<span class="marginnote">JPEG 2000 标准在 2000 年底发布，名字里的「2000」就是发布年份。它技术全面领先，却因专利、解码复杂度与 DCT 生态惯性，未能在消费市场取代 JPEG——这是「技术最优」敌不过「生态惯性」的经典案例。但在医学影像、卫星遥感、数字影院这些重视质量与可伸缩性的领域，它站稳了脚跟。</span>

1. **全域小波变换，不分块**：整幅图像做 $L$ 层 DWT（水平/垂直交替），天然无块效应；
2. **量化 + 嵌入式熵编码（EBCOT）**：小波系数按重要性分层编码，支持**渐进传输**——先传大系数（整体轮廓），再传小系数（细节），接收端可以「先看到模糊版，再慢慢变清晰」；
3. **双正交小波**：有损模式用 **CDF 9/7**（第 7 讲），无损模式用 **CDF 5/3** 的整数提升实现。

**重点：** DWT 的多分辨率结构天然支持**分层码流**：最低频子带（逼近）是一张缩小 N 倍的缩略图，逐级叠加细节子带就还原更高分辨率。JPEG 2000 的渐进传输、感兴趣区域（ROI）优先编码、以及无损/有损同流，全都建立在这个多分辨率金字塔上。<span class="marginnote">这就是「一个文件，多种用途」：同一码流既可当缩略图预览，又可解出全分辨率原图，还能截取局部放大——DCT 的分块结构做不了这件事。</span>

## 2 小波域编码的基本盘：量化 + 熵编码

JPEG 2000 的压缩流程可以概括为：**DWT → 量化 → 嵌入式编码**。

**DWT**：图像变成 1 个低频逼近子带 + $3L$ 个高频细节子带（水平、垂直、对角各 $L$ 层）；
**量化**：细节系数除以量化步长再取整——这一步丢掉的正是「视觉不敏感」的高频细微差别；
**嵌入式编码**：把量化后的系数按「显著性」排序编码，先传最重要的位平面。

嵌入式编码的祖先是 **EZW**（Shapiro，1993）与 **SPIHT**（Said & Pearlman，1996），它们利用小波系数的**跨尺度自相似**：若某低频系数很小，它对应的更深层高频后代也大概率很小——于是可以整棵子树一起判死（零树）。<span class="marginnote">EZW 的洞见是「小波系数的父-子关系」：DWT 后，位置 $(i,j)$ 的低频系数在下一层高频里有对应的三个后代。用一个标志位标记「整个子树都小于阈值」，就能跳过一大片系数——压缩率的关键就在这种结构性跳跃。</span>

**辨析｜易错点：** 很多人以为 JPEG 2000 靠「小波比 DCT 好」取胜。严格说，DWT 与 DCT 各自都只是**能量集中工具**；真正的码率优势来自紧随其后的**嵌入式编码**如何利用小波的多分辨率结构。工具（小波）与算法（EZW/EBCOT）是两回事。

### 一张图的一生：二维 DWT 的四子带结构

二维 DWT 是「先沿行、再沿列」各做一维分解的结果。图像 $I$ 先按行低通/高通滤波并抽稀，得到左（低）、右（高）两半；再对每一半按列同样操作一次，最终切成四个子带：

| 子带 | 行方向 | 列方向 | 承载信息 |
| --- | --- | --- | --- |
| $LL$ | 低通 | 低通 | 低频逼近，下一层缩略图 |
| $LH$ | 低通 | 高通 | 水平细节，捕捉竖直边缘 |
| $HL$ | 高通 | 低通 | 垂直细节，捕捉水平边缘 |
| $HH$ | 高通 | 高通 | 对角细节，捕捉斜向纹理 |

对 $LL$ 子带再递归做同样分解，就是完整的 $L$ 层二维小波金字塔。<span class="marginnote">能量分布极不均匀：$LL$ 子带往往占据图像总能量的 95% 以上，三个细节子带则稀疏、幅值小。这正是「量化的火力要集中在细节、低频要精确保留」的工程依据。</span>

这个四子带结构解释了 JPEG 2000 的两个招牌能力：**ROI 编码**——对 $LL$ 与若干细节子带中对应某区域的系数优先细化，就能局部放大而不损全局；**渐进传输**——$LL$ 一到位就是清晰的缩略图，细节子带逐层追加则逐步锐化。

## 3 特征提取：小波能量特征与纹理分析

小波在特征提取里最经典的一招：**用各子带的能量分布做特征向量**。对图像做 $L$ 层 DWT，得到 $3L+1$ 个子带，每个子带算一个特征：

$$E_{j,o} = \frac{1}{N_{j,o}} \sum_{(i,j') \in \text{subband}(j,o)} |c_{j,o}[i,j']|^p$$

常用 $p=2$（能量）或 $p=1$（绝对值和）。把各子带能量拼成一个向量，就是这幅图的**多尺度纹理特征**。<span class="marginnote">纹理（texture）是图像里没有明显边缘、却有一定统计规律的区域——草地、布纹、皮肤。小波的多尺度能量恰好抓住「不同尺度下的起伏强度」，这一特征在遥感地物分类、医学组织切片分析、材料表面检测里都是经典基线。</span>

**重点：** 相比直接在像素域统计，小波特征有三个优点：**尺度信息显式**（不同 $j$ 对应不同粒度）、**方向信息分离**（水平/垂直/对角子带各自独立）、**对光照稳健**（能量是平移不变量）。这些性质让它在机器学习里成了「手工特征时代」的常青树。

## 4 机器学习与深度学习中的小波

进入深度学习时代，小波没有退场，而是换了角色：

**预处理与数据增强**：用 DWT 分离低频逼近与高频细节，把「去噪」「去模糊」作为分类/检测前的净化步骤；
**多尺度输入**：把 DWT 的各级逼近当作图像金字塔输入网络，模拟人类「先轮廓后细节」的视觉；<span class="marginnote">卷积神经网络（CNN）本身就在学「多尺度局部滤波器」——卷积核像小波一样局部且多通道。小波是「手工设计的滤波器组」，CNN 是「数据学出来的滤波器组」，两者殊途同归，这解释了为什么小波直觉在深度网络里依然有用。</span>
**小波散射网络（wavelet scattering）**：Mallat 2012 年提出，用多层「小波分解 + 取模 + 平均」构造平移不变、形变稳定的特征，是小波思想在表示学习里的正规军——它不用训练就有可证明的稳定性保证，曾被用于音频分类、纹理识别。

**辨析｜易错点：** 小波散射网络 ≠ 深度卷积网络。散射网络的小波与取模是**固定、可证明**的（不学习），而 CNN 的核是**数据训练**的。散射网络的价值在于「不训练也能拿到好特征」与「理论可解释」，而非替代 CNN。

### 为什么小波直觉在深度学习里依然有用

如果把小波与深度网络放在一起看，会发现它们共享同一套「配方」：

**局部性**：小波基紧支撑，卷积核是局部感受野——两者都「只看一小块」；
**多尺度**：小波逐层细分尺度，CNN 逐层加大感受野——两者都「由细到粗地看世界」；
- **方向性**：小波分离水平/垂直/对角，CNN 的不同卷积核自动学出不同方向边缘探测器。

区别只在于：小波的设计来自数学（可证明的消失矩、正交性），CNN 的设计来自数据（用梯度把核调成最优）。在数据稀缺、需要可解释性、或要严格稳定性保证的场景，小波方法依然是 CNN 的有力替代或补充——这也是散射网络、小波-卷积混合结构仍在持续出成果的原因。<span class="marginnote">这条脉络延续到更广的「表示学习」：从手工特征（小波、Gabor、SIFT）到学习特征（CNN、Transformer），不变的是「多尺度 + 方向 + 局部」这组先验——它根植于自然信号的统计结构，不因工具更迭而消失。</span>

对机器学习工程师，小波提供的是一份「可信赖的基线」：新任务不知道用什么特征时，先用小波多尺度能量特征跑一版，往往能给出不弱于随意搭的浅层网络的结果，而且**完全可解释、零训练成本**。

## 5 公式解析：小波能量特征

$$
E_{j,o} = \frac{1}{N_{j,o}} \sum_{(i,j') \in \text{subband}(j,o)} |c_{j,o}[i,j']|^p
$$

- **第一步，看 $c_{j,o}[i,j']$**：DWT 后第 $j$ 层、方向 $o$（水平/垂直/对角）子带里位置 $(i,j')$ 的小波系数。它记录「这个位置、这个尺度、这个方向上的细节强度」。
- **第二步，看 $|\cdot|^p$**：对系数取模的 $p$ 次幂。$p=2$ 时是能量（与 Parseval 恒等式呼应），$p=1$ 时是 L1 强度。取幂让大系数主导特征，体现「少数大系数代表主要结构」。
- **第三步，看求和与 $N_{j,o}$**：对整个子带求和再除以子带尺寸 $N_{j,o}$，得到**平均能量**。归一化让特征不随图像尺寸缩放——不同大小的图可以公平比较。
- **第四步，看整体**：$E_{j,o}$ 度量「第 $j$ 尺度、第 $o$ 方向的起伏有多强」。把 $\{E_{j,o}\}$ 排成向量，就是图像的**多分辨率签名**——同一类纹理在不同尺度下的能量分布有稳定的形状，这正是分类器学会分辨的依据。
- **第五步，连接全文**：这条特征正是「小波稀疏性」的正向利用：信号结构越规则，能量越集中在少数子带；噪声则摊平在所有子带——第 9 讲用它去噪，这一讲用它辨类，同一性质的两种用法。

## 6 小结

- **JPEG 2000**：全域 DWT + 量化 + EBCOT，消灭块效应、支持渐进传输与 ROI；有损用 9/7、无损用 5/3 整数提升。
- **嵌入式编码**（EZW/SPIHT/EBCOT）利用小波系数的**跨尺度自相似**做零树跳跃，才是码率优势的真正来源。
- **小波能量特征** $E_{j,o}$ 提供尺度、方向分离的多分辨率纹理签名，适合分类与检索。
- **深度学习时代**：小波用于预处理、多尺度输入，并催生了可证明稳定的**小波散射网络**。
- 从 Fourier 到小波再到 CNN：本质是「全局 → 多尺度局部 → 数据自适应局部」的滤波观演进。
- 二维 DWT 的四子带结构（$LL, LH, HL, HH$）是图像压缩与纹理特征的公共骨架：$LL$ 是下一层缩略图，$LH/HL/HH$ 分别捕捉水平、垂直、对角细节。
- **一个文件，多种用途**：JPEG 2000 的分层码流既可当缩略图预览，又可解出全分辨率原图，还能截取局部放大——DCT 分块结构做不到。
- 码率优势的真正来源是嵌入式编码（EZW/SPIHT/EBCOT）对跨尺度自相似的利用，而非小波本身。
- 小波能量特征 $E_{j,o}$ 是「手工特征时代」的常青树：尺度显式、方向分离、对光照稳健、零训练成本。
- 深度学习时代小波换了角色：预处理去噪、多尺度输入、小波散射网络的固定小波 + 取模 + 平均构造平移不变特征。
- 小波散射网络与 CNN 的区别：前者滤波器固定且可证明稳定，后者滤波器由数据训练——两者共享「局部 + 多尺度 + 方向」的先验。
- 二维 DWT 能量分布极不均匀：$LL$ 常占图像总能量 95% 以上，细节子带稀疏且幅值小，量化火力应集中在细节。
- 「工具（DWT）与算法（EBCOT）是两回事」：DCT 与 DWT 都只是能量集中工具，真正的压缩增益来自后续编码。
- 工程选型三条经验：无损压缩首选 5/3 整数提升，有损压缩首选 9/7，特征提取首选多尺度能量特征——同一套数学，三种用法。

在下一节，我们完成了「从极限到大模型」里信号处理这一支的闭环：从 Fourier 的全局谱到小波的多尺度局部，再到数据自适应的深度网络——这条主线将通往更高一级的稀疏表示与压缩感知。
