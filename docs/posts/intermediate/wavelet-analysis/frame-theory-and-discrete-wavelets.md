## 为什么从框架理论开始

连续小波变换要遍历**所有**尺度 $s>0$ 与**所有**平移 $u\in\mathbb{R}$，这在计算上不可能，物理上也过度冗余。那么问题来了：能不能只取一组**可数**的子波 $\{\psi_{j,k}\}$，仍然让信号可以精确重建？框架理论（frame theory）给出了最一般的答案——它既保留了冗余的稳健性，又给出了严格的重建公式。<span class="marginnote">框架理论是调和分析家族的重要分支，本专题只取它服务离散小波的那部分；想系统学完整理论，可去第二级《调和分析》与《泛函分析》看 Hilbert 空间的表示论。</span>

## 1 从基到框架：允许冗余的完备表示

回想线性代数的正交基：一组向量 $\{e_k\}$ 满足 $\langle e_k, e_m\rangle = \delta_{k,m}$，任何向量 $f$ 都能唯一写成 $f = \sum_k \langle f, e_k\rangle\, e_k$。正交基干净，但**零冗余**——少一个元素就残缺，多一个元素就线性相关。

小波分析需要的是一种更宽容的结构：**允许重复、允许冗余，但必须仍能精确重建**。这正是**框架（frame）**。

**框架（frame）**：Hilbert 空间 $\mathcal{H}$ 中的一族向量 $\{\phi_k\}_{k\in\mathbb{Z}}$，若存在常数 $0 \lt  A \le B \lt  \infty$，使得对一切 $f \in \mathcal{H}$：

$$A\, \lVert f \rVert^2 \le \sum_{k} |\langle f, \phi_k\rangle|^2 \le B\, \lVert f \rVert^2$$

则称 $\{\phi_k\}$ 为一个**框架**，$A$、$B$ 分别是**下、上框架界**。<span class="marginnote">框架概念由 Duffin 与 Schaeffer 在 1952 年研究非调和 Fourier 级数时提出，沉寂多年后，由 Daubechies、Grossmann、Meyer 在 1986 年重新发掘，成为小波理论的第一块基石。</span>

**直觉：** 中间那个和 $\sum_k |\langle f, \phi_k\rangle|^2$ 度量的是「框架对 $f$ 的覆盖总量」。下界 $A$ 保证**每个方向都被看到**（信息不丢失），上界 $B$ 保证**不会过度放大**（数值稳定）。正交基是最简框架，$A = B = 1$。

**辨析｜易错点：** 框架**不一定**线性无关。正交基里删去任一元素就坍缩，而框架可以扔掉若干元素仍是框架（只要上下界仍为正）。这种**冗余性**（redundancy）正是框架的卖点：个别系数损坏或噪声污染时，重建依然稳健——这是它在小波、压缩感知、相位恢复中大显身手的原因。

## 2 框架算子与对偶框架

有了框架，怎么重建 $f$？定义**框架算子（frame operator）**：

$$S f = \sum_k \langle f, \phi_k\rangle\, \phi_k$$

$S$ 是正定可逆算子，它把每个框架元素重新「装配」回去。<span class="marginnote">$S$ 的正定性来自框架不等式：$\langle Sf, f\rangle = \sum_k |\langle f,\phi_k\rangle|^2 \ge A\lVert f\rVert^2 > 0$（对 $f\ne 0$），所以 $S$ 有界逆存在。这是重建一切合法性的源泉。</span>利用 $S^{-1}$，可以把 $\{\phi_k\}$ 变成**对偶框架（dual frame）** $\{\tilde\phi_k\}$：

$$\tilde\phi_k = S^{-1} \phi_k$$

**重点：** 对偶框架给出**通用重建公式**：任何 $f \in \mathcal{H}$ 都成立

$$f = \sum_k \langle f, \phi_k\rangle\, \tilde\phi_k = \sum_k \langle f, \tilde\phi_k\rangle\, \phi_k$$

也就是说，**用原框架分解（取内积）、用对偶框架合成（加权叠加）**，就能精确还原信号。当框架冗余时，对偶框架不是唯一的——这正是「非唯一表示」的来源：同一个小波系数组合可以对应不同信号，选择对偶框架就是选择一种最方便的「解码字典」。

## 3 紧框架：最好的情形

当上下框架界相等 $A = B$ 时，框架叫**紧框架（tight frame）**。此时框架算子退化成一个数乘：$S = A\, I$，对偶框架就是 $\tilde\phi_k = \phi_k / A$，重建公式简化为：

$$f = \frac{1}{A} \sum_k \langle f, \phi_k\rangle\, \phi_k$$

特别的，$A = B = 1$ 时得到 **Parseval 框架**（也叫标准正交框架）：<span class="marginnote">与 Fourier 级数的 Parseval 恒等式 $\sum |\hat f(n)|^2 = \lVert f\rVert^2$ 同名同构：都是「表示系数的能量 = 信号的能量」。Parseval 框架里，分解与合成用的是同一族函数，不用算 $S^{-1}$，工程上最省事。</span>

$$f = \sum_k \langle f, \phi_k\rangle\, \phi_k$$

**重点：** 紧框架兼得两全——既像正交基一样有简单重建公式，又保留冗余的稳健性。它在线性代数里也有对应物：列向量构成紧框架的矩阵，正是「列数多于行数且行正交」的矩阵。下一讲的多分辨分析要构造的**正交小波基**，就是 $A=B=1$ 且元素线性无关的特例——非冗余的 Parseval 框架。

### 冗余度：框架到底「多」多少

**冗余度（redundancy ratio）** 定义为 $r = \tfrac{M}{D}$，其中 $M$ 是框架元素个数、$D$ 是空间维数。它定量回答「框架比基多了几倍」：

- $r = 1$：恰是基（如正交基、Riesz 基），无冗余；
- $r > 1$：过完备框架，例如 3 个向量张成 2 维平面时 $r = 1.5$；
- $r$ 越大，表示越稳健，但存储与计算成本越高。

**一个二维算例**：平面上取三根互成 $120^\circ$ 的单位向量 $\phi_1, \phi_2, \phi_3$。任一 $f \in \mathbb{R}^2$ 都满足 $\sum_{k=1}^3 |\langle f, \phi_k\rangle|^2 = \tfrac32 \lVert f\rVert^2$——三根向量构成紧框架，$A = B = \tfrac32$，冗余度 $1.5$。<span class="marginnote">手算验证：把 $f = (\cos\theta, \sin\theta)$ 代入，$\sum_k \cos^2(\theta - \theta_k)$ 与 $\theta$ 无关，恒等于 $\tfrac32$。三根向量「多一根」，但正因多这一根，丢任何一根都不至于信息崩溃——这就是冗余的保险功能。</span>

**重点：** 紧框架里 $A = B = \tfrac32$ 恰好等于冗余度。更一般地，对任何 Parseval 框架，$A = B = 1$ 但 $r$ 仍可大于 1——**冗余与「方正程度」是两回事**：紧框架可以冗余（$r>1$）而不病态（$B/A=1$），这是它比一般框架优越的地方。

## 4 离散小波框架：如何挑选 $(u, s)$

现在回到连续小波。要把它变成可数的离散框架，关键在于**采样策略**。时间 $u$ 与尺度 $s$ 不能都均匀采样：尺度跨度大（从精细到粗糙差好几个数量级），均匀采样会爆炸式增长。标准做法是**对数采样**：

$$s = a^{j},\quad u = n\, b\, a^{j}, \qquad j, n \in \mathbb{Z}, \quad a > 1,\ b > 0$$

于是子波族离散化为 $\psi_{j,n}(t) = a^{-j/2}\, \psi\!\big(\tfrac{t - n b a^j}{a^j}\big)$。<span class="marginnote">这个采样方案很自然：尺度 $a^j$ 越大（低频），子波越宽，平移步长 $b a^j$ 也随之加大——「宽波走得远，窄波迈小步」。低频处平移点稀疏，高频处平移点密集，与信号的物理需求匹配。</span>

**离散小波变换（discrete wavelet transform, DWT）** 取系数：

$$W f(j, n) = \langle f, \psi_{j,n}\rangle$$

问题变成：怎样的 $(a, b)$ 与母小波 $\psi$ 能使 $\{\psi_{j,n}\}$ 构成框架？Daubechies 证明了：**只要 $\psi$ 满足容许条件且 $b$ 足够小，$\{\psi_{j,n}\}$ 就构成框架。** <span class="marginnote">$b$ 相当于香农采样定理里的采样间隔：采样足够密（$b$ 足够小）就信息不丢。但小波框架的冗余还允许「采样超过临界密度」——这正是上一节「允许冗余」的用武之地。</span>

**辨析｜易错点：** 连续小波里尺度 $s$ 可以取任意正实数，离散小波只取 $s = a^j$ 的**对数阶梯**。$a$ 越接近 1，框架越冗余；$a=2$ 的「二进采样」是经典选择——它正好对应下一讲多分辨分析里「频率逐倍细分」的结构。而「$a=2, b=1$ 且恰好是正交基」的情形，就是 Daubechies 构造的著名正交小波，后面两讲会专门展开。

## 5 公式解析：框架不等式

把框架定义这条「黄金不等式」拆透：

$$
A\, \lVert f \rVert^2 \le \sum_{k} |\langle f, \phi_k\rangle|^2 \le B\, \lVert f \rVert^2
$$

- **第一步，看左边 $\sum_k |\langle f,\phi_k\rangle|^2$**：这是所有投影系数模的平方和，衡量「$\{\phi_k\}$ 看到了多少 $f$」。若某个方向的 $f$ 与所有 $\phi_k$ 都几乎正交，这个和就趋近 0，信息就丢了。
- **第二步，看下界 $A\lVert f\rVert^2$**：它强迫「无论 $f$ 取哪个方向，覆盖量都有正的下限」。$A > 0$ 是「完备性」的定量表达——没有任何方向被漏掉。若 $A=0$，框架退化，重建不唯一或不可能。
- **第三步，看上界 $B\lVert f\rVert^2$**：它限制覆盖量的增长速度。$B\lt \infty$ 保证「任何 $f$ 的表示系数不会爆炸」，否则数值计算会病态。$A$、$B$ 的比值 $B/A$ 度量框架的**病态程度**，越接近 1 越「方正」。
- **第四步，看整体**：上下界把「表示系数能量」钉在「信号能量」的常数倍之间——**这保证内积测量既不失真也不放大**，是逆算子 $S^{-1}$ 有界、重建稳定的充分必要条件。

**直观小结：** 框架不等式回答的是「一族函数够不够格当『解码字典』」——既不能漏方向（$A>0$），又不能失真（$B\lt \infty$）。字典允许冗余（不是基也可以），只要覆盖均匀有界。<span class="marginnote">今天「稀疏表示」「压缩感知」的核心思想正是框架思想的延伸：字典可以很大、很冗余，但只要信号在字典里「稀疏」，用少量原子就能精确表示——这是本专题应用篇《小波阈值去噪》的理论底气。</span>

## 6 小结

- **框架**是允许冗余的完备表示：上下框架界 $0<A\le B\lt \infty$ 保证信息不丢、数值稳定。
- **框架算子** $S = \sum_k \langle\cdot,\phi_k\rangle\phi_k$ 正定可逆；**对偶框架** $\tilde\phi_k = S^{-1}\phi_k$ 给出通用重建公式 $f = \sum_k \langle f,\phi_k\rangle \tilde\phi_k$。
- **紧框架** $A=B$ 时 $S = A I$，重建公式简化；**Parseval 框架**（$A=B=1$）分解与合成用同一族函数。
- **离散小波框架**用对数采样 $s=a^j$、$u=nba^j$ 得到可数子波族；$b$ 足够小即构成框架。
- $a=2$ 的二进采样对应「频率逐倍细分」，为下一讲多分辨分析铺路。
- 冗余度 $r = M/D$ 度量框架的过完备程度；紧框架允许冗余而不病态。
- 离散小波框架用对数采样 $s = a^j$、$u = nba^j$ 逼近连续小波，$a=2$ 是最经典选择。
- 框架算子 $S$ 的正定性来自框架下界：$\langle Sf, f\rangle \ge A\lVert f\rVert^2 > 0$
