# Gauss-Bonnet 定理（局部形式）

<div class="epigraph">
<p>沿着一条曲线的测地曲率，加上它围成的区域里的高斯曲率，恰好等于一个固定的转角——几何与拓扑在此第一次握手。</p>

## 为什么从 Gauss-Bonnet 开始

我们学了两类曲率：**高斯曲率 $K$**（曲面内部的弯曲）与**测地曲率 $k_g$**（曲线上「侧向」的弯曲）。它们看似独立。**Gauss-Bonnet 定理**把它们缝在一起——对一个区域 $R$，它的边界 $\partial R$ 的测地曲率积分，加上区域内部的高斯曲率积分，等于边界的外角之和：

$$
\iint_R K\,dA + \int_{\partial R} k_g\,ds = 2\pi
$$

**重点：局部曲率的总量居然只依赖「转角」——一个只与边界拐弯有关的量。** 这是微分几何最伟大的定理之一。它连接了三个世界：高斯曲率（几何）、测地曲率（曲线论）、角度（拓扑）。从这一节开始，我们踏上「整体几何」之路。<span class="marginnote">Gauss-Bonnet 的历史：Gauss 1827 年证明了测地三角形的版本，Bonnet 1848 年推广到一般区域，最终的整体形式（连通闭曲面）由 Hopf 与 Rinow 等人在 20 世纪初完成。它标志着「局部几何 ⟹ 整体拓扑」这个现代几何主题的正式确立。</span>

## 1 局部形式的陈述

**定理（Gauss-Bonnet，局部形式）**：设 $R$ 是正则曲面 $S$ 上的**简单区域**（单连通、逐段光滑边界），边界 $\partial R$ 由逐段光滑的简单闭曲线组成，外角为 $\theta_i$（$i=1,\dots,n$，转角为 $\pi - \theta_i$ 之类，见下）。则

$$
\iint_R K\,dA + \int_{\partial R} k_g\,ds + \sum_{i=1}^n \theta_i = 2\pi
$$

其中 $\sum \theta_i$ 是边界转角（外角）之和。

**重点：三项之和恒为 $2\pi$。** 不论区域多大、曲面多弯，这三项的总和是固定的——这是「局部几何受整体约束」的第一个精确陈述。<span class="marginnote">符号约定：转角 $\theta_i$ 是「外角」（$0$ 到 $\pi$ 之间）。对光滑边界段，$k_g$ 沿弧长积分；在角点处，测地曲率积分换成外角。若边界是光滑闭曲线（无角点），$n=0$，$\sum\theta_i = 0$。</span>

## 2 特例：测地三角形

最重要的特例是**测地三角形**——三条边都是测地线（$k_g \equiv 0$）的三角形。Gauss-Bonnet 局部形式退化为：

$$
\iint_R K\,dA + \sum_{i=1}^3 \theta_i = 2\pi
$$

若用内角 $\alpha_i = \pi - \theta_i$（内角与外角互补），则 $\sum\theta_i = 3\pi - (\alpha_1+\alpha_2+\alpha_3)$，代入得：

$$
\alpha_1 + \alpha_2 + \alpha_3 = \pi + \iint_R K\,dA
$$

**重点：测地三角形的内角和 = $\pi$ + 高斯曲率的积分。** 这是 Euclid 第五公设的曲面版：

- **$K > 0$**（球面）：内角和 $> \pi$——椭圆几何。
- **$K = 0$**（平面）：内角和 $= \pi$——欧氏几何。
- **$K < 0$**（马鞍/双曲）：内角和 $< \pi$——双曲几何。<span class="marginnote">这个式子直接把「三角形内角和是否等于 $\pi$」与「高斯曲率是否为零」挂钩。它首次证明：<strong>非欧几何不是逻辑游戏，而是曲面几何的实在内容</strong>。球面三角形内角和大于 $\pi$、伪球面三角形小于 $\pi$——第五篇应用节会专门展开与双曲几何的联系。</span>

## 3 公式解析：为什么三项之和是 $2\pi$

Gauss-Bonnet 的证明线索（对简单区域），拆成四步：

- **第一步，切向量的转角**：边界 $\partial R$ 上的切向量绕一圈，其转角是 $2\pi$（绕完整一圈）。这是「旋转数」（winding number）的平凡事实。
- **第二步，把转角拆开**：切向量的总转角 = 沿边界的「测地曲率积分」+ 角点的「外角」+ 曲面自身的「贡献」。曲线在曲面上的方向变化，一部分来自曲线自己在侧向弯（$k_g$），一部分来自曲面的弯曲。
- **第三步，曲面贡献 = $K$ 的积分**：切向量沿边界平行移动回到起点，其转角 = 区域 $R$ 上 $K$ 的积分（和乐定理，平行移动一节已见）。
- **第四步，合并**：总转角 $2\pi$ = $k_g$ 积分 + 外角 + $K$ 积分，整理即得 Gauss-Bonnet 公式。

**重点：Gauss-Bonnet 是「切向量绕一圈转 $2\pi$」的精确展开。** 所有曲率都被「配平」进这个 $2\pi$ 的账本——几何的深刻性来自这个简单的守恒。<span class="marginnote">平行移动与曲率的联系（第四篇）在此成为核心工具：沿边界平行移动切向量，回到起点的转角恰好是 $\iint_R K\,dA$。所以 Gauss-Bonnet 可以看成「平行移动和乐」与「边界几何」的恒等式——两条线索在此合流。</span>

## 4 例：球面上的测地三角形

单位球面上的测地三角形（三条大圆弧）。设内角为 $\alpha,\beta,\gamma$，面积 $A$。由球面的 $K=1$：

$$
\alpha + \beta + \gamma = \pi + A
$$

**球面三角形内角和 = $\pi$ + 面积。** 这是球面三角学最著名的公式（Harriot 1613 年）。

- 赤道为底、北极为一顶的「三面角」：若三个角都是直角，内角和 $= 3\pi/2$，面积 $= \pi/2$（球面八分之一）——代入验证 $\pi + \pi/2 = 3\pi/2$ ✓。
- 内角和可以到 $3\pi$（三条大圆围出整个半球的一半边界时）——**内角和最大 $3\pi$，对应面积最大 $2\pi$（半球）**。<span class="marginnote">球面三角内角和公式是导航与天文的古老工具（球面距离、方位角计算），早在 Gauss-Bonnet 之前就独立发现。Gauss-Bonnet 的价值是把这些零散公式统一成一个定理——「内角和 = $\pi$ + 曲率积分」适用于任何曲面的测地三角形。</span>

## 5 局部形式的意义

局部 Gauss-Bonnet 的意义远超「一个公式」：

- **曲率的可测性**：$K$ 的积分可以被「边界几何」（测地曲率 + 转角）间接测量——不需要在内部逐点测曲率。
- **非欧几何的桥梁**：测地三角形内角和公式是椭圆/双曲几何的入口（第五篇应用）。
- **整体形式的起点**：把局部区域拼成整个闭曲面，取极限得整体 Gauss-Bonnet（下一节）——**局部版本是整体的积木**。<span class="marginnote">工程直觉：在网格曲面上，把每个三角形区域用 Gauss-Bonnet 局部形式处理（角度亏量 ≈ $K$ 积分），累加起来就逼近整体 Gauss-Bonnet——这就是离散微分几何里「角度亏量 = 高斯曲率」的思想（mesh 曲率估计的基础）。</span>

**重点：局部 Gauss-Bonnet 是「$2\pi$ 守恒」——曲率的账本在每个简单区域都结平。** 它告诉我们局部曲率不是任意的，必须与边界的拐弯行为协调。

### 例：一般区域验证「$2\pi$ 守恒」

用一个非三角形区域验证局部 Gauss-Bonnet。在平面（$K=0$）上取一个由三段直线构成的「直角 L 形区域」（外角分别是 $90^\circ$、$90^\circ$、$180^\circ$ 之类）：

- $K$ 积分：平面 $K=0$，$\iint_R K\,dA = 0$。
- $k_g$ 积分：边界是直线（平面上的测地线），$k_g = 0$，积分为零。
- 外角之和：绕一圈的外角总和 $= 2\pi$（凸多边形外角和定理）。

三项加和：$0 + 0 + 2\pi = 2\pi$ ✓。**无论区域多复杂，Gauss-Bonnet 的「$2\pi$ 守恒」恒成立。**

**重点：局部 Gauss-Bonnet 是「几何量的账本」——曲率、测地曲率、转角三项无论怎么分布，总和固定 $2\pi$。** 平面多边形「外角和 $= 2\pi$」是这个账本在 $K=0$ 时的退化——Gauss-Bonnet 把它推广到任何弯曲曲面。

### 局部形式的「积分读法」

Gauss-Bonnet 局部形式可以读成一条「积分等式」：

$$
\iint_R K\,dA = 2\pi - \int_{\partial R} k_g\,ds - \sum\theta_i
$$

**左边（内部曲率）由右边（边界几何）完全决定——这是「内部量可被边界量测量」的精确陈述。** 它说明：不需要在区域内逐点测 $K$，只需测量边界（测地曲率 + 转角），就能得到内部的曲率积分。这个「边界决定内部」的思想，是 Stokes 定理（第七篇）的核心——局部 Gauss-Bonnet 正是 Stokes 在曲面上的化身。

## 6 小结

- **Gauss-Bonnet（局部）**：$\iint_R K\,dA + \int_{\partial R} k_g\,ds + \sum\theta_i = 2\pi$。
- **测地三角形**：内角和 $= \pi + \iint_R K\,dA$——非欧几何的量化。
- 证明线索：切向量绕一圈转角 $2\pi$ = $k_g$ 积分 + 外角 + $K$ 积分（和乐）。
- 球面例：内角和 $= \pi$ + 面积。
- 意义：曲率可测、非欧桥梁、整体形式的积木。

在下一节，我们把局部形式推向整个曲面：**Gauss-Bonnet 定理（整体形式）**——全局曲率积分等于 $2\pi$ 乘欧拉示性数，几何与拓扑完成史诗级握手。
