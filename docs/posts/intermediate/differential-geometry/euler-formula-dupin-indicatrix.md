## 为什么从 Euler 公式开始

我们已经知道：每一点有主曲率 $\kappa_1,\kappa_2$ 与主方向，法曲率随方向按「加权平均」变化。现在把这个规律做成**完整公式与完整图像**。

**Euler 公式**给出法曲率随方向角的精确分布：$k_n(\theta) = \kappa_1\cos^2\theta + \kappa_2\sin^2\theta$。**Dupin 标线（Dupin indicatrix）**把这条公式画成一张图：在切平面上取极坐标 $(\rho, \theta)$，令 $\rho^2 = 1/|k_n(\theta)|$，得到的曲线（椭圆、双曲线或两平行线）就是标线。**一图胜千言：弯曲的符号与大小全在标线的形状里。**<span class="marginnote">Dupin 标线是「可视化曲率」的鼻祖：把「方向的函数」$k_n(\theta)$ 画成切平面上的一条曲线。它是现代「曲率玫瑰图」「曲率椭圆」的祖先——在曲面处理、形态分析里，把张量场画成椭圆/椭球是标配做法。</span>

## 1 Euler 公式：法曲率的分布规律

**定理（Euler 公式）**：设 $p\in S$，$\mathbf{e}_1,\mathbf{e}_2$ 是单位主方向（对应主曲率 $\kappa_1,\kappa_2$）。对任意单位切方向 $v = \cos\theta\,\mathbf{e}_1 + \sin\theta\,\mathbf{e}_2$，有

$$
k_n(v) = \kappa_1\cos^2\theta + \kappa_2\sin^2\theta
$$

**重点：法曲率是主曲率的「余弦平方加权和」。** 三个典型读数：

- $\theta = 0$（沿 $\mathbf{e}_1$）：$k_n = \kappa_1$。
- $\theta = \pi/2$（沿 $\mathbf{e}_2$）：$k_n = \kappa_2$。
- $\theta = \pi/4$：$k_n = (\kappa_1 + \kappa_2)/2 = H$（恰为平均曲率）。

这条公式把「每点的全部弯曲信息」压缩进主曲率与一个角度——**知道了 $\kappa_1,\kappa_2$，就重构了法曲率函数**。<span class="marginnote">Euler 1760 年证明这条公式时，主曲率概念尚未命名——他是先发现「法曲率分布像加权余弦平方」，再反推出「存在极值方向」。历史顺序与我们学习的顺序相反：公式先行，概念后立。</span>

## 2 Dupin 标线的定义

**定义（Dupin 标线）**：在切平面 $T_pS$ 上取极坐标 $(\rho,\theta)$，定义曲线

$$
\rho(\theta) = \frac{1}{\sqrt{|k_n(\theta)|}}
$$

（$\theta$ 沿主轴从 $\mathbf{e}_1$ 起量，$\rho \ge 0$。$k_n = 0$ 时 $\rho = \infty$，即渐近方向。）这条曲线称为 $S$ 在 $p$ 处的 **Dupin 标线（indicatrix）**。

标线随 $K$ 的符号呈现三种形状：

- **$K > 0$（椭圆点）**：$k_n$ 恒正（或恒负），$\rho(\theta) = 1/\sqrt{\kappa_1\cos^2\theta + \kappa_2\sin^2\theta}$ 是一条**椭圆**——标线是椭圆。<span class="marginnote">椭圆的长半轴 $= 1/\sqrt{\kappa_2}$（沿 $\mathbf{e}_2$，曲率最小方向）、短半轴 $= 1/\sqrt{\kappa_1}$（沿 $\mathbf{e}_1$，曲率最大方向）。曲率越大，半径越小——「弯得越急，标线越扁」。球面标线是圆（$\kappa_1=\kappa_2$）。</span>
- **$K < 0$（双曲点）**：$k_n$ 在某方向为零（渐近方向），$\rho$ 发散——标线是**双曲线**，其渐近线正是两个渐近方向。
- **$K = 0$（抛物点）**：一个主曲率为零，标线退化为一对**平行直线**（圆柱面标线是两平行线）。

**重点：Dupin 标线是「切平面上的曲率地图」——椭圆点、双曲点、抛物点一眼分辨。** 这也是「indicator」（指标/指示器）名字的由来。

## 3 公式解析：为什么标线是椭圆/双曲线/平行线

把 $\rho(\theta) = 1/\sqrt{|k_n(\theta)|}$ 转成直角坐标 $(\xi,\eta) = (\rho\cos\theta, \rho\sin\theta)$，看看标线方程变成什么：

- **第一步，代入 Euler 公式**：$k_n = \kappa_1\cos^2\theta + \kappa_2\sin^2\theta$，故
  $$
  \rho^2 = \frac{1}{|\kappa_1\cos^2\theta + \kappa_2\sin^2\theta|}
  $$
- **第二步，转直角坐标**：$\xi = \rho\cos\theta$、$\eta = \rho\sin\theta$，则 $\rho^2 = \xi^2+\eta^2$，且
  $$
  \kappa_1\xi^2 + \kappa_2\eta^2 = \rho^2(\kappa_1\cos^2\theta + \kappa_2\sin^2\theta) = \rho^2\cdot k_n = \rho^2\cdot\frac{1}{\rho^2} = 1
  $$
- **第三步，读形状**：标线方程是
  $$
  \kappa_1\xi^2 + \kappa_2\eta^2 = \pm 1
  $$
  由 $\kappa_1,\kappa_2$ 的符号决定：同号正定 → 椭圆；异号 → 双曲线；一个为零 → 两平行线。**Dupin 标线就是二次曲线 $Q(v) = \pm1$，其中 $Q(v) = II(v,v)$。**<span class="marginnote">结论可以一句话说清：<strong>Dupin 标线 = 第二基本形式的「水平集」$II(v,v)=\pm1$</strong>。这与正则值定理里「$f^{-1}(c)$ 是曲面」完全同构——在切平面这个二维空间里，二次型 $II$ 的水平集就是圆锥曲线。二次型理论（第二级《线性代数》的对称矩阵分类）在这里直接投影成几何图像。</span>

## 4 标线的几何应用

Dupin 标线不只是好看的图，它有实在用途：

- **局部形状分类**：给一个曲面点，画标线即知是椭圆/双曲/抛物点——比算 $K$ 的符号更直观。
- **法曲率的可视化**：标线上任一点到原点的距离平方 = 该方向法曲率的倒数。曲率越大的方向，标线离原点越近。
- **曲率方向的读取**：标线的长短轴方向 = 主方向；渐近方向 = 双曲线标线的渐近线方向。
- **变分与几何处理**：现代曲面处理里，「曲率椭圆」是各向异性平滑、特征提取、曲面重建的标准量——它是 Dupin 标线的数值后继。<span class="marginnote">工程里，「曲率椭圆」（curvature ellipse）通常画成「主曲率方向的椭圆」而非严格定义 $II=\pm1$ 的标线，但思想一脉相承：用椭圆/椭球编码各向异性的弯曲。在医学图像、地质形态分析中，用标线分类曲面点是常见步骤。</span>

## 5 例：三类典型点的标线

- **球面点**：$\kappa_1 = \kappa_2 = 1/R$，标线方程 $(\xi^2+\eta^2)/R = 1$——**圆**（半径 $\sqrt{R}$）。各向同性。
- **马鞍面 $z=xy$ 原点**：$\kappa_1 = 1,\ \kappa_2 = -1$，标线 $\xi^2 - \eta^2 = \pm1$——**等轴双曲线**，渐近线 $\xi = \pm\eta$（正是渐近方向，成 $45^\circ$）。<span class="marginnote">等轴双曲线（hyperbola）出现在 $H=0$ 的情形：$\kappa_1=-\kappa_2$ 时标线的两条渐近线互相垂直。极小曲面（$H=0$）上每点标线都是直角双曲线——一个漂亮的对偶：$H=0$ ⟺ 标线的渐近线正交。</span>
- **圆柱面**：$\kappa_1 = 1,\ \kappa_2 = 0$，标线 $\xi^2 = \pm1$——**两平行线** $\xi = \pm1$。一个方向弯曲（有限半径）、一个方向平直（无限半径）。

### 例：椭球面的标线

三轴椭球 $\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1$（$a>b>c$）上，主曲率随位置变化。在某点 $p$，标线是椭圆（$K>0$ 的凸区），长轴沿「曲率较小」的主方向。

- 在「最圆」处（脐点附近）：$\kappa_1 \approx \kappa_2$，标线近圆。
- 在「最扁」处：$\kappa_1 \gg \kappa_2$，标线是细长椭圆——「弯得急的方向半径小」。

**重点：标线的形状随曲率分布而变化——它是「每点曲率地图」的动态图像。** 椭球面只有 4 个脐点（标线退化为圆），其余点标线是椭圆。用标线「扫描」整个椭球面，就看到曲率如何随位置变化——这正是几何处理里「曲率椭圆场」可视化的原理。

### Dupin 标线与曲率椭圆

现代曲面处理里，Dupin 标线的思想被「曲率椭圆」继承：在每个曲面点画一个椭圆，长轴沿「曲率最小」主方向（半径 $1/\sqrt{|\kappa_2|}$）、短轴沿「曲率最大」主方向。曲率椭圆场让「曲率如何分布」一目了然。

**重点：Dupin 标线是「每点曲率的地图」——现代曲率椭圆场是它的直接后继。** 从 19 世纪的几何作图到 21 世纪的曲面可视化，标线的核心洞见不变：**把「方向的函数」（$k_n$）画成平面上的曲线，弯曲的形状与大小一眼可见。** 理解标线，就理解了现代曲率可视化的几何根源。

### Euler 公式的「平均」读法

$k_n(\theta) = \kappa_1\cos^2\theta + \kappa_2\sin^2\theta$ 本质是「**加权平均**」：$\cos^2\theta$ 与 $\sin^2\theta$ 非负且和为 1，所以 $k_n$ 落在 $\kappa_2$ 与 $\kappa_1$ 之间。**任意方向的法曲率是主曲率的凸组合。**

**这个「凸组合」读法让一切方向的性质「夹」在两主曲率之间：$k_n \in [\kappa_2, \kappa_1]$。** 也解释了 $H = (\kappa_1+\kappa_2)/2$ 为什么在 $\theta = \pi/4$ 处出现（权重各半）。「法曲率是主曲率的平均」——Euler 公式的统计读法。

### 一点易错提醒

应用 Euler 公式时，$\theta$ 必须从主方向起量，且主方向 $\{\mathbf{e}_1,\mathbf{e}_2\}$ 要取**单位**向量。若用非单位方向或从非主方向起量，公式不成立。**「主轴基 + 单位向量 + 从主方向起角」是 Euler 公式的三要素。**

**「公式成立的坐标前提要记牢」——Euler 公式只对主方向基成立。** 这是公式应用的常见陷阱：随意取方向代入会得到错误结果。先找主方向（形状算子对角化），再代 Euler 公式——顺序不可乱。

## 6 小结

- **Euler 公式**：$k_n(\theta) = \kappa_1\cos^2\theta + \kappa_2\sin^2\theta$——法曲率的余弦平方加权分布。
- **Dupin 标线**：$\rho = 1/\sqrt{|k_n|}$，等价于二次曲线 $\kappa_1\xi^2 + \kappa_2\eta^2 = \pm 1$。
- 形状由 $K$ 的符号决定：椭圆点（椭圆）、双曲点（双曲线，渐近线 = 渐近方向）、抛物点（平行线）。
- 标线的长短轴 = 主方向，距原点距离平方 = 法曲率倒数。
- 应用：局部形状分类、曲率可视化、曲面处理中的「曲率椭圆」。
