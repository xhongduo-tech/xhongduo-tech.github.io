# 高斯曲率与平均曲率

## 为什么从高斯曲率与平均曲率开始

主曲率 $\kappa_1, \kappa_2$ 是两个数，信息完整但有点「散」。曲面论的实际需求更喜欢把它们压缩成**两个组合量**：

- **高斯曲率（Gaussian curvature）**：$K = \kappa_1\kappa_2$。
- **平均曲率（mean curvature）**：$H = \tfrac{1}{2}(\kappa_1 + \kappa_2)$。

为什么偏偏选「乘积」与「平均」？因为它们是特征值的**对称多项式**——不依赖主方向的选择，是曲面形状的最本质不变量。更重要的是：**高斯曲率 $K$ 是一个「内蕴」量**——只依赖第一基本形式就能计算，不依赖曲面如何嵌入 $\mathbb{R}^3$。这就是著名的 **Gauss 绝妙定理（Theorema Egregium）** 的内容，也是本专题第四篇的高潮。这一节先立住 $K$ 与 $H$ 的定义与直觉。<span class="marginnote">$K$ 与 $H$ 的区分是曲面论最重要的概念之一：$K$ 描述「内在弯曲」（曲面居民能量到的），$H$ 描述「外在弯曲」（嵌入带来的）。橘子皮内蕴弯曲为正，纸卷成圆柱内蕴弯曲为零（$K=0$）但外在弯曲 $H\neq0$。抓住「$K$ 内蕴、$H$ 外蕴」这条线，第四篇就通了。</span>

## 1 定义与几何直觉

**定义（高斯曲率 / 平均曲率）**：设 $S$ 是正则曲面，$p\in S$，主曲率为 $\kappa_1,\kappa_2$。定义

$$
K(p) = \kappa_1(p)\,\kappa_2(p), \qquad H(p) = \frac{1}{2}\big(\kappa_1(p) + \kappa_2(p)\big)
$$

从形状算子看：$K = \det(S_p)$、$2H = \mathrm{tr}(S_p)$——**行列式与迹**，正是线性代数里最稳定的两个不变量。

- **$K$ 的符号**：$\kappa_1,\kappa_2$ 同号则 $K>0$（凸/凹点，两个方向同向弯）；异号则 $K<0$（马鞍点）；其一为零则 $K=0$（抛物点，圆柱面的点）。
- **$H$ 的符号**：取法向翻转则 $H$ 变号（$H$ 依赖定向）；$H=0$ 的点/曲面叫**极小曲面**——肥皂膜！

**重点：$K$ 是「乘性」的，$H$ 是「加性」的。** $K$ 回答「弯曲的乘积」，区分凸/鞍/抛物三种本质形状；$H$ 回答「弯曲的平均」，度量「平均弯多急」。**$K$ 抓住拓扑/内蕴，$H$ 抓住嵌入/外蕴。**

## 2 坐标公式：直接用 $E,F,G,L,M,N$ 算

用 Weingarten 方程 $[S] = \mathcal{I}^{-1}\mathcal{II}$ 的行列式与迹：

$$
K = \det(S_p) = \frac{LN - M^2}{EG - F^2}
$$

$$
2H = \mathrm{tr}(S_p) = \frac{GL + EN - 2FM}{EG - F^2}
$$

**重点：$K$ 的分子是 $LN-M^2$（第二基本形式的行列式），分母是 $EG-F^2$（第一基本形式的行列式）——「两个基本形式的行列式之比」。** $H$ 的分子 $GL + EN - 2FM$ 是「加权对角和」。<span class="marginnote">$K = \dfrac{LN-M^2}{EG-F^2}$ 是曲面论使用频率最高的公式之一。它的一个直接推论：$K$ 的符号完全由 $LN-M^2$ 决定——若 $M=0$（正交参数化），$K = LN/EG$，符号由 $LN$ 决定。判断「凸/鞍/抛物」常常只看这两个数的乘积。</span>

### 例：三个原型的 $K$ 与 $H$

| 曲面 | $\kappa_1$ | $\kappa_2$ | $K$ | $H$ |
| --- | --- | --- | --- | --- |
| 平面 | 0 | 0 | 0 | 0 |
| 球面 $S^2_R$ | $1/R$ | $1/R$ | $1/R^2$ | $1/R$ |
| 圆柱面 | 1 | 0 | 0 | $1/2$ |
| 马鞍面 $z=xy$（原点） | 1 | $-1$ | $-1$ | 0 |

一眼看出：**圆柱 $K=0$（可展平）、$H\neq0$（外在弯曲）；马鞍 $K<0$（内在双向反向弯）、$H=0$（外在平均不弯）。** $K$ 与 $H$ 从两个正交的视角解剖弯曲。

## 3 公式解析：为什么 $K$ 是「内蕴」的

这是整门曲面论最深刻的观察，拆开看：

- **第一步，$K = \det(S_p)$ 的「外蕴」面目**：$S_p = -dN_p$ 依赖法向 $\mathbf{N}$，而 $\mathbf{N}$ 依赖曲面如何嵌入 $\mathbb{R}^3$。表面上看，$K$ 应该是外蕴的——它由 $II$（外蕴量）计算，而 $II$ 由嵌入决定。
- **第二步，奇迹发生**：Gauss 证明了一个惊人事实：$K$ 可以**只用 $E,F,G$ 及其一阶、二阶导数**算出（虽然公式很长）。也就是说，$K$ 其实**不依赖嵌入**——平面卷成圆柱，$E,F,G$ 不变，$K$ 不变（都是 0）。
- **第三步，绝妙定理**：
  $$
  K = \frac{1}{EG-F^2}\Big[\cdots\Big]
  $$
  括号内是 $E,F,G$ 及其导数的组合（含 Christoffel 记号，第四篇会写完整）。**$K$ 是「第一基本形式」的函数——内蕴量。** 这就是 **Gauss 绝妙定理（Theorema Egregium）**。<span class="marginnote">「Egregium」拉丁文意为「杰出的、惊人的」。Gauss 在 1827 年发现 $K$ 内蕴时自己也极为惊讶——他把曲面「钉」在三维空间里的弯法都忘记了，曲面居民还能用自己的度量算出 $K$。这条定理让「曲面内在几何」成为一门独立学科，也是现代黎曼几何的出生证。</span>

**辨析｜易错点：$H$ 不是内蕴的。** 平均曲率 $H$ 依赖嵌入：平面卷成圆柱，$H$ 从 0 变成 $1/2$。**$K$ 内蕴、$H$ 外蕴——这是两个量最本质的区别**，做题和直觉都要时刻分清。

## 4 $K$ 与 $H$ 的几何意义：局部形状的指纹

两个量合起来，几乎决定了曲面每一点的局部形状：

**$K > 0$**：凸点（或凹点）。两个主曲率同号，所有法截线朝同一侧弯。球面上的点、椭球面上的点。
**$K < 0$**：鞍点（双曲点）。一个方向弯上、一个方向弯下，法截线朝两侧弯。马鞍面、双曲抛物面的点。
**$K = 0$**：抛物点。至少一个主曲率为零，某方向不弯。圆柱、锥面（除顶点）、平面。
**$H = 0$**：极小曲面（如肥皂膜、悬链面）。平均弯曲为零——「一个方向凸多少，另一个方向凹多少，正好抵消」。
**$K$ 恒为常数**：常曲率曲面（球面、平面、伪球面）——第八篇的系统主题。

**重点：$K$ 的符号是「形状的指纹」，$H$ 的零点定义「极小曲面」。** 这两条判据在几何建模、物理、图形学里无处不在。<span class="marginnote">肥皂膜（$H=0$）与橘子皮（$K>0$）是理解两量的最佳直觉：肥皂膜外在平均不弯（两侧弯向抵消），橘子皮内在处处同向弯。极小曲面 = 最小面积曲面，是「拉紧」的曲面；$H=0$ 是它的微分方程（第 11 节与变分法衔接）。</span>

## 5 $K$ 与 $H$：通向整体几何

$K$ 与 $H$ 不只是局部量，它们是曲面的「体检指标」，整体意义深远：

**$K$ 的整体积分**：$\iint_S K\,dA$ 只依赖曲面的拓扑（Gauss-Bonnet 定理，第五篇）——**局部曲率的积分居然等于 $2\pi$ 乘欧拉示性数**，这是几何与拓扑的第一次握手。
**$H$ 与极小曲面**：肥皂膜问题、肥皂泡形状、Plateau 问题——最小面积曲面的经典物理与变分问题，全部以 $H=0$ 为核心方程。
**$K$ 与非欧几何**：$K > 0$ 的曲面（球面）与 $K < 0$ 的曲面（伪球面）分别是椭圆几何与双曲几何的模型（第五篇应用）。<span class="marginnote">对 AI 与工程的读者：$K$ 与 $H$ 是三维重建、网格简化、形状分析的标配特征。深度学习中「几何深度学习」（Geometric Deep Learning）把「局部形状指纹」提升为「等变特征」——同一个曲面无论怎么摆放，$K$ 不变，这正是「等变性」的经典先例。</span>

### 例：环面的 $K$ 与 $H$ 分布

用环面感受 $K$ 与 $H$ 如何「分工」。环面（管半径 $r$、管心半径 $R$，$R>r$）的曲率分布：

- **外侧（远离轴）**：$\kappa_1 = 1/(R+r\cos u)$、$\kappa_2 = 1/r$（同号），$K > 0$——凸区。
- **内侧（靠近轴）**：$\kappa_1 < 0$（向轴弯）、$\kappa_2 > 0$，$K < 0$——马鞍区。
- **上下两条「分界圆」**：$K = 0$——抛物区（$R + r\cos u = \pm$ 使 $\kappa_1 = 0$）。

**重点：环面的 $K$ 在内外侧之间变号，但 $H$ 始终为正（两个主曲率之和除 2）——$K$ 描述「本质形状」，$H$ 描述「总体朝向」。** 环面 $\iint K\,dA = 0$（内外抵消，Gauss-Bonnet：$\chi=0$），而 $\iint H$ 非零——「$K$ 的整体积分是拓扑，$H$ 的整体积分是几何」。这个例子把「$K$ 内蕴、$H$ 外蕴」落到具体的曲面上。

### $K$ 与 $H$ 的直观分工

用一句话记住 $K$ 与 $H$ 的区别：

- **$K$**：问「曲面在这里的本质形状」——凸、鞍还是平？它是**内在**的（不随嵌入变）。
- **$H$**：问「曲面在这里平均弯多少」——它是**外在**的（随嵌入变）。

一张纸摊平（$K=0,H=0$）卷成圆柱（$K=0,H=1/2$）——$K$ 没变（本质没变），$H$ 变了（外形变了）。**「$K$ 管本质，$H$ 管外形」**——这是两量的终极分工，也是「内蕴 vs 外蕴」的最短版本。

## 6 小结

- **高斯曲率** $K = \kappa_1\kappa_2 = \det(S_p) = \dfrac{LN-M^2}{EG-F^2}$：乘积、内蕴、区分凸/鞍/抛物。
- **平均曲率** $H = \tfrac{1}{2}(\kappa_1+\kappa_2) = \tfrac12\mathrm{tr}(S_p) = \dfrac{GL+EN-2FM}{2(EG-F^2)}$：平均、外蕴、依赖定向。
- **Gauss 绝妙定理**：$K$ 只依赖第一基本形式（内蕴），不随嵌入改变——$K$ 是「曲面居民能量到的」。
- $H=0$ 定义极小曲面；$K$ 的符号是局部形状指纹。
- 原型：平面 $(K=0,H=0)$、球面 $(K=1/R^2,H=1/R)$、圆柱 $(K=0,H=1/2)$、马鞍 $(K<0,H=0)$。
