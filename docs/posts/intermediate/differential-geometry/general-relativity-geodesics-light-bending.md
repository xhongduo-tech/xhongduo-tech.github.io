# 广义相对论的几何语言：测地线与光线弯曲

## 为什么从测地线开始

Einstein 场方程决定了时空的弯曲（度量 $g$），但「弯曲的时空如何影响物质与光」由**测地线**决定。这一节研究广义相对论里的运动学：**自由粒子沿类时测地线走，光线沿类光测地线走。**

测地线方程我们在第八篇已经学过（$\nabla_{\gamma'}\gamma' = 0$）。在时空里，它给出「弯曲时空中的惯性运动」——引力不是力，而是「时空弯曲让测地线偏折」。这一节把这个思想展开，重点研究**光线弯曲**——广义相对论最著名的验证之一。<span class="marginnote">「引力 = 时空弯曲」的完整逻辑链：物质（$T$）→ 场方程 → 度量 $g$（曲率）→ 测地线 → 自由落体与光的路径。粒子不知道「力」，只知道「沿最直的路线走」——而最直的路线在弯曲时空里是弯的。这就是「时空告诉物质如何运动」的机制。</span>

## 1 类时测地线：自由落体

**定义（自由落体）**：只受引力作用的粒子，其世界线 $\gamma$ 是**类时测地线**：

$$
\nabla_{\gamma'}\gamma' = 0, \qquad g(\gamma', \gamma') = -1
$$

（第二式是「归一化」：固有时参数化，$c^2$ 取 1 的约定。）

**重点：自由落体 = 沿类时测地线运动——「最直的路线」在弯曲时空里就是「自由落体的轨道」。** 这就是等效原理：自由落体参考系是局部惯性系，那里「引力消失」。<span class="marginnote">牛顿 vs 爱因斯坦：牛顿说「引力是力，让物体偏离直线」；爱因斯坦说「没有引力，物体沿测地线（最直的路线）走，而时空弯曲让这条最直的路看起来像被引力拉着弯」。两者预测相同（弱场），但「引力是力」与「引力是几何」是根本不同的世界观。</span>

## 2 类光测地线：光线传播

**定义（光线路径）**：光（或任何无质量粒子）沿**类光测地线**传播：

$$
\nabla_{\gamma'}\gamma' = 0, \qquad g(\gamma', \gamma') = 0
$$

**重点：光沿类光测地线走——「光速不变」+「沿最直路线」。** 在弯曲时空里，类光测地线是弯曲的——光被弯曲时空「折射」。这就是**引力透镜**的机制：质量使时空弯曲，光经过时偏折。<span class="marginnote">「光速不变」在几何里是「类光 = $g(\gamma',\gamma')=0$」——它在任何参考系都是零间隔，所以「光速恒定」。光沿测地线 = 费马原理（光走「最短时间」路径）的广义相对论版——「最直」与「最快」在弯曲时空里再次握手。</span>

## 3 公式解析：Schwarzschild 时空中的光线偏折

最著名的例：点质量（太阳）外部的时空——**Schwarzschild 度量**：

$$
ds^2 = -\Big(1 - \frac{2GM}{c^2 r}\Big)dt^2 + \Big(1 - \frac{2GM}{c^2 r}\Big)^{-1}dr^2 + r^2(d\theta^2 + \sin^2\theta\,d\phi^2)
$$

**光线偏折角**的推导要点：

- **第一步，写下类光测地线方程**：$\nabla_{\gamma'}\gamma' = 0$（$g(\gamma',\gamma')=0$）。对 Schwarzschild 度量展开，利用守恒量（能量与角动量）化简。
- **第二步，解轨道方程**：光在赤道面（$\theta = \pi/2$）传播，轨道方程化为
  $$
  \frac{d^2 u}{d\phi^2} + u = 3GM\,u^2
  $$
  其中 $u = 1/r$。这是「受扰动的圆轨道方程」——$3GM u^2$ 项正是广义相对论的修正。
- **第三步，求偏折角**：远距离处解近似 $u \approx \frac{1}{b}\cos\phi + \frac{GM}{b^2}(\dots)$，光线从无穷远来、到无穷远去，总偏折角
  $$
  \Delta\phi = \frac{4GM}{c^2 b}
  $$
  其中 $b$ 是碰撞参数（光线到太阳的最短距离）。

**重点：偏折角 $\Delta\phi = \dfrac{4GM}{c^2 b}$ 与牛顿预言（$\frac{2GM}{c^2b}$）差一个因子 2——广义相对论预言两倍的偏折。** 1919 年 Eddington 在日全食时测得 $\sim1.75$ 角秒，与广义相对论吻合，一战成名。<span class="marginnote">「因子 2」的故事：牛顿引力（光线受引力作用偏折 $\frac{2GM}{c^2b}$）与广义相对论（$\frac{4GM}{c^2b}$）差一倍。1919 年日全食观测（Eddington 带队）测得接近 $1.75''$（爱因斯坦值），让广义相对论获得决定性验证。「一个因子 2」区分了两套引力理论——精确测量的力量。</span>

## 4 光线弯曲的现代应用：引力透镜

光线偏折在宇宙尺度上产生壮观的**引力透镜（gravitational lensing）**：

**强透镜**：大质量星系/星系团把背景星系的光弯成「爱因斯坦环」「十字」。
**弱透镜**：背景星系的形状被统计性扭曲——测量暗物质分布。
**微透镜**：恒星经过时的短暂放大——寻找系外行星。

**重点：光线弯曲 = 时空曲率的「探照灯」——通过测量光的偏折，反推质量分布与时空曲率。** 引力透镜是当代宇宙学的核心观测工具（暗物质、暗能量、星系质量测量）。<span class="marginnote">引力透镜把「几何曲率」变成「望远镜图像」：爱因斯坦环、十字像、星系弧——全是「光沿测地线偏折」的宏观显现。暗物质的分布图、哈勃常数测量（时间延迟透镜）、暗能量的约束——光线弯曲是现代天文学的第一生产力。</span>

## 5 测地线在时空中的更多预言

测地线理论在时空里还有更多可观测结果：

**水星近日点进动**：类时测地线的轨道修正——每世纪额外进动 $43$ 角秒。
**引力时间延迟（Shapiro 效应）**：光经过太阳附近「变慢」，雷达回波延迟——测地线的「弯曲路径更长」。
**GPS 修正**：卫星钟与地面钟的速率差（引力红移 + 狭义相对论）——时空度量的直接后果。
**黑洞**：Schwarzschild 半径 $r_s = 2GM/c^2$ 内的类时/类光测地线无法逃逸——事件视界。

**重点：测地线理论给出引力的一切经典预言——从太阳系到黑洞，从光线偏折到 GPS 修正。** 这些预言全部被实验精确验证——广义相对论是「几何 = 物理」的终极确认。<span class="marginnote">GPS 是广义相对论最「日常」的应用：卫星钟每天比地面快约 38 微秒（广义相对论引力红移 +38、狭义相对论运动 -7），不修正则定位每天偏差数公里。「测地线、度量、曲率」这些微分几何概念，在每个人的手机导航里工作。</span>

**重点：广义相对论的测地线 = 「最直路线」= 「惯性运动」——引力不是力，而是时空的几何。** 光线弯曲、行星轨道、GPS 修正、黑洞，全是同一条测地线方程在弯曲时空中的不同显现。

### 例：GPS 与时空几何

广义相对论测地线理论最「日常」的应用是 GPS。卫星钟与地面钟的速率差：

- **引力红移（广义相对论）**：卫星在高处（引力弱、时空弯曲小），钟比地面快约 $+45$ 微秒/天。
- **运动效应（狭义相对论）**：卫星高速运动，钟比地面慢约 $-7$ 微秒/天。
- **净差**：约 $+38$ 微秒/天——不修正则定位每天偏差数公里。

**重点：GPS 的精度依赖「时空度量」的精确修正——这正是测地线、度量的工程实现。** 卫星的位置由「时空测地线」确定，信号传播由「类光测地线」决定，时钟校准由「固有时」（度量沿世界线积分）决定。微分几何不是书本概念——它在每个人的手机定位系统里实时工作。「时空弯曲可测量」最有力的日常证据。

### 等效原理与测地线

爱因斯坦的**等效原理**（自由落体参考系中引力「消失」）在几何里就是「测地线的局部直线性」：在任何测地线点附近，可以用局部惯性坐标（测地坐标）让 $\Gamma$ 为零——引力（联络）局部「消失」，但曲率（潮汐）不消失。

**重点：等效原理 = 「测地线局部看起来是直线」——引力可局部消除（联络为零），曲率不可（潮汐为常）。** 这精确区分了「引力」（可局部消除的联络效应）与「潮汐力」（不可消除的曲率效应）。电梯自由落体的「失重感」与地球轨道的「无引力感」，都是测地线局部直线性的物理体验。「等效原理 + 曲率不可消除」是广义相对论的双重几何根基。

### 黑洞与测地线的「终点」

Schwarzschild 半径 $r_s = 2GM/c^2$ 内的类时/类光测地线全部「坠入奇点」——事件视界内没有任何测地线能逃出。**黑洞 = 「测地线无法逃离的区域」**。

**「事件视界 = 类光测地线的不可逆边界」——黑洞的几何定义完全由测地线给出。** 光子球（$r = 3r_s/2$，类光测地线的圆轨道）、吸积盘、引力透镜的阴影——全是测地线理论在极端时空的表现。「黑洞不是天体，是时空的几何结构」——测地线理论给黑洞研究提供了完整语言。

## 6 小结

- **自由落体** = 类时测地线（$\nabla_{\gamma'}\gamma'=0$，$g(\gamma',\gamma')=-1$）——惯性运动。
- **光线** = 类光测地线（$g(\gamma',\gamma')=0$）——光速不变 + 最直路线。
- **Schwarzschild 时空**：轨道方程 $u''+u = 3GMu^2$，偏折角 $\Delta\phi = \frac{4GM}{c^2b}$（牛顿的两倍）。
- **引力透镜**：光线偏折测量质量分布——暗物质、暗能量的观测工具。
- 更多预言：水星进动、Shapiro 延迟、GPS 修正、黑洞视界。
- 引力 = 时空几何；测地线 = 运动的全部。
