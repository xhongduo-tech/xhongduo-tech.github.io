## 为什么从测地线方程开始

上一节我们把测地线定义为「测地曲率为零的曲线」，这是几何定义。但实际求解测地线——给定一个起点和一个方向，把它画出来——需要**微分方程**。这一节推导测地线的坐标方程，它是整门内蕴几何最常用的「工作方程」。

测地线方程的样子简洁而深刻：

$$
u'' + \Gamma^1_{11}(u')^2 + 2\Gamma^1_{12}u'v' + \Gamma^1_{22}(v')^2 = 0
$$

**「坐标的二阶导 + Christoffel 修正」= 0**——这就是「沿最直的路，加速度为零（在曲面自己的坐标里）」。它是牛顿第二定律「$F = ma$」在曲面的无外力版本：测地线是「没有力作用」的惯性运动。<span class="marginnote">这条方程与「平面上的直线 $x''=0$」完全同构——平面里 $\Gamma=0$，方程退化为「二阶导为零」，即直线。曲面的弯曲被 $\Gamma$ 项「补偿」：在曲面坐标里要保持「直」，就必须按 $\Gamma$ 校正坐标加速度。爱因斯坦把引力场方程也写成类似的「测地线方程」，引力 = 时空的 $\Gamma$。</span>

## 1 从测地曲率到测地线方程

**测地线定义**：$\alpha$ 是测地线 ⟺ $k_g \equiv 0$ ⟺ 切向量的协变导数为零：

$$
\frac{D\alpha'}{dt} = 0
$$

**重点：测地线 = 「速度向量沿自身平行移动」的曲线。** 沿测地线走，切向量不改变方向（在曲面内看来）——这就是「直」的含义。

在坐标下，设 $\alpha(t)$ 的坐标分量 $(u(t), v(t))$，速度 $\alpha' = u'\mathbf{x}_u + v'\mathbf{x}_v$。把 $D\alpha'/dt = 0$ 展开（用协变导数坐标公式），得：

$$
\begin{aligned}
u'' + \Gamma^1_{11}(u')^2 + 2\Gamma^1_{12}u'v' + \Gamma^1_{22}(v')^2 &= 0,\\
v'' + \Gamma^2_{11}(u')^2 + 2\Gamma^2_{12}u'v' + \Gamma^2_{22}(v')^2 &= 0
\end{aligned}
$$

**这就是测地线方程组。** 它是关于 $(u(t), v(t))$ 的二阶 ODE 组——给定初值（起点 $u(0),v(0)$ 与初始方向 $u'(0),v'(0)$），唯一确定一条测地线。<span class="marginnote">「速度的协变导数为零」展开就是这两条方程，关键步骤是把 $D\alpha'/dt=0$ 用 $\Gamma$ 展开——上一节的协变导数坐标公式直接代入即可。注意这里 $t$ 是任意参数（测地线方程对仿射参数成立）；若要求「弧长参数」，方程结构不变（$\Gamma$ 项仍适用，因为测地线在弧长参数下满足同一条方程）。</span>

## 2 测地线方程从变分而来

测地线还有一个深刻的等价来源：**它是「连接两点最短曲线」的变分结果**。考虑曲面上从 $p$ 到 $q$ 的曲线族，长度

$$
L = \int \sqrt{E(u')^2 + 2Fu'v' + G(v')^2}\;dt
$$

**求 $L$ 的极小值（变分法）**：设 $\delta L = 0$，欧拉-拉格朗日方程给出的极值曲线方程正是测地线方程组。<span class="marginnote">「测地线 = 最短线（局部）」的严格证明：长度泛函的临界点正是 $D\alpha'/dt = 0$。这是第一级《数学分析》变分法、第二级《最优化理论》欧拉-拉格朗日方程的直接应用。测地线的「几何定义」（$k_g=0$）与「变分定义」（长度临界点）等价——一条线的两面。</span>

**重点：测地线方程 = 长度泛函的欧拉-拉格朗日方程。** 这个「几何最直 = 变分极值」的等价，是变分法在几何里的第一次正式登场，后面第八篇的黎曼几何会反复使用。

## 3 公式解析：为什么测地线方程长这样

以第一个分量方程为例，逐项理解每一项：

$$
u'' + \Gamma^1_{11}(u')^2 + 2\Gamma^1_{12}u'v' + \Gamma^1_{22}(v')^2 = 0
$$

- **$u''$：坐标加速度**。若曲面是平面且用直线坐标，$u''=0$ 就是「匀速直线」。这一项是「惯性」。
- **$\Gamma^1_{11}(u')^2$：纯 $u$ 方向的曲率补偿**。沿 $u$-方向走，坐标网格本身的弯曲要用 $\Gamma^1_{11}$ 修正。就像经纬度里沿经线走，需要校正「经线在极点汇聚」的效应。
- **$2\Gamma^1_{12}u'v'$：$u,v$ 混合的补偿**。两个方向同时走时，坐标系在 $u$-$v$ 交叉处的弯曲用 $\Gamma^1_{12}$ 修正（系数 2 来自对称性）。
- **$\Gamma^1_{22}(v')^2$：纯 $v$ 方向的补偿**。沿 $v$-方向走时的曲率修正。

**重点：方程是「坐标加速度 = -（曲率补偿）」。** 测地线上的点，其坐标速度看似在变（$u''\neq0$），但那只是坐标系弯曲的假象——在曲面的内蕴几何里，它正沿着「直路」走。$\Gamma$ 项正是「把坐标系弯曲算进去」的补偿。<span class="marginnote">物理直觉：在地球经纬度里，赤道上沿经线匀速直走，$u''$（经度加速度）不为零——因为经度坐标在两极汇聚，坐标系自己在弯。测地线方程说：这是坐标效应，不是真实弯曲。GPS 导航自动做这种「坐标校正」。</span>

## 4 例：球面上的测地线

用测地线方程验证球面的测地线是大圆。

球面 $S^2_R$ 用经纬度 $(\theta,\phi)$（$u=\theta$、$v=\phi$），$E=R^2\cos^2\phi$、$F=0$、$G=R^2$，非零 $\Gamma$：$\Gamma^1_{12} = -\tan\phi$、$\Gamma^2_{11} = \sin\phi\cos\phi$。测地线方程：

$$
\begin{aligned}
\theta'' - 2\tan\phi\,\theta'\phi' &= 0,\\
\phi'' + \sin\phi\cos\phi\,(\theta')^2 &= 0
\end{aligned}
$$

**解：$\phi$ = 常数（纬线）是测地线当且仅当 $\phi=0$（赤道）**——因为第二式要求 $\sin\phi\cos\phi=0$。而「倾斜的大圆」（$\phi$ 不恒定）也是解——它们正是大圆。**球面的测地线恰是大圆**，测地线方程严格验证了这个经典结论。<span class="marginnote">大圆是「球面与过球心的平面相交的圆」。经纬度下，赤道是 $k_g=0$ 的纬线，倾斜大圆则在 $(\theta,\phi)$ 里「蜿蜒」。测地线方程的解给出全部大圆——这是「最短航线走大圆」的数学来源，也是飞行路径规划的基础。</span>

## 5 测地线方程的地位

测地线方程是内蕴几何的「主力方程」：

- **存在唯一性**：二阶 ODE 初值问题 ⟹ 给定起点与初始方向，测地线唯一存在（下一节详述）。
- **指数映射**：把「初始方向」映射到「走单位时间的终点」——测地线方程的解定义指数映射（后面章节）。
- **物理与优化**：牛顿第二定律 $F = ma$ 在曲面上推广为 $m(D\alpha'/dt) = F$；无外力时即测地线。黎曼优化（第九篇）里「沿测地线走」是流形上梯度下降的黄金路径。<span class="marginnote">在广义相对论里，测地线方程写为 $\ddot x^\mu + \Gamma^\mu_{\alpha\beta}\dot x^\alpha \dot x^\beta = 0$——正是这里公式的 4 维版本。自由落体、行星轨道、光线弯曲全是这条方程的解。「引力 = 时空的 $\Gamma$」由此成为几何化物理的纲领。</span>

**重点：测地线方程是「曲面上最直的路」的可计算表述。** 掌握了它，测地线的存在性、唯一性、最短性、指数映射全部由此展开。

### 例：平面的测地线方程退化为直线

用最简单的例子验证测地线方程的正确性。平面 $E=G=1$、$F=0$，全部 $\Gamma = 0$——测地线方程退化为

$$
u'' = 0, \qquad v'' = 0
$$

解是 $u(t) = a + bt$、$v(t) = c + dt$——**匀速直线运动**。这正是「平面上的直线」：测地线 = 直线，$\Gamma$ 项消失后方程回到「加速度为零」。

**重点：测地线方程在平坦坐标下退化为一阶导数的线性函数——「最直的路 = 匀速直线」在平面情形严格成立。** 这个退化是测地线方程正确性的「检验基准」：任何正确的推广都必须回到直线。曲面上 $\Gamma$ 项承担「坐标弯曲补偿」，让「直线」的概念在弯曲坐标里延续。

## 6 小结

- **测地线方程**：$D\alpha'/dt = 0$ 展开为 $u'' + \Gamma^1_{11}(u')^2 + 2\Gamma^1_{12}u'v' + \Gamma^1_{22}(v')^2 = 0$（两个分量）。
- **等价来源**：长度泛函的欧拉-拉格朗日方程——「最直 = 极值」。
- 每项含义：坐标加速度 + 曲率补偿（$\Gamma$ 项）。
- 球面例子：方程解出大圆（赤道是唯一测地纬线）。
- 地位：存在唯一性、指数映射、黎曼优化、广义相对论的共同方程。
