# 常曲率空间简介：球面、欧氏空间与双曲空间

<div class="epigraph">
<p>空间可以像球面一样弯曲，可以像平面一样平坦，也可以像马鞍一样反弯——三种空间，三种几何，同一条度量公式。</p>

## 为什么从常曲率空间开始

黎曼几何把「空间」统一成一个概念：带度量的流形。而最对称、最干净的流形是**常曲率空间（constant curvature space）**——截面曲率处处为同一个常数 $K_0$ 的流形。它们只有三种：

$$
K_0 > 0:\ \text{球面 } S^n, \qquad K_0 = 0:\ \text{欧氏空间 } \mathbb{R}^n, \qquad K_0 < 0:\ \text{双曲空间 } H^n
$$

这一节把三种空间放在同一个框架里研究——它们的度量公式、测地线、几何性质，以及它们如何统一三种几何（椭圆/欧氏/双曲，第五篇已见二维版）。**常曲率空间是黎曼几何的「标准模型」**：它们对称性最高、计算最干净，也是宇宙学与几何的基石。<span class="marginnote">瑟斯顿的几何化猜想（2003 年 Perelman 证明）说：每个三维流形可以「切成」八种几何的拼图，其中三种常曲率（球面、欧氏、双曲）是最重要的。常曲率空间不只是漂亮模型——它们是理解一般流形的「积木」。</span>

## 1 三种空间的模型

**定义（三类常曲率空间）**：

- **球面 $S^n_R$**：$S^n_R = \{x\in\mathbb{R}^{n+1}: \|x\| = R\}$，诱导度量，$K_0 = 1/R^2$。
- **欧氏空间 $\mathbb{R}^n$**：标准度量，$K_0 = 0$。
- **双曲空间 $H^n$**：带负曲率度量的流形，$K_0 = -1/R^2$。模型：**上半平面** $H^n = \{x\in\mathbb{R}^n: x_n > 0\}$ 带度量
  $$
  g = \frac{dx_1^2 + \cdots + dx_n^2}{x_n^2}
  $$
  或 **Poincaré 圆盘** $D^n = \{x: \|x\|<1\}$ 带度量 $g = \frac{4\,dx_1^2+\cdots}{(1-\|x\|^2)^2}$。

**重点：三种空间 = 三种度量，曲率符号不同、几何迥异。** 同一套黎曼几何框架，三种选择产出三种宇宙。<span class="marginnote">上半平面/圆盘模型让双曲几何「可计算」：$H^2$ 里的「直线」是垂直于边界 $x_n=0$ 的半圆（或竖直射线），测地距离有显式公式，平行性「过一点无穷多条」。Beltrami、Poincaré、Klein 给出了等价模型——双曲几何从此有了严格的实现。</span>

## 2 三种空间的测地线

**$\mathbb{R}^n$**：测地线 = 直线。
**$S^n_R$**：测地线 = 大圆（球面与过球心平面的交线）。
**$H^n$**（上半平面）：测地线 = 垂直于边界 $x_n = 0$ 的半圆或竖直射线。

**重点：测地线在三种空间里分别是「直线、大圆、垂直半圆」——都是「最直的路」，只是空间的弯曲让它们形态各异。** 三角形内角和：$\mathbb{R}^n$ 为 $\pi$，$S^n$ 大于 $\pi$（正曲率），$H^n$ 小于 $\pi$（负曲率）——与第五篇的二维结论完全一致。<span class="marginnote">球面三角形内角和 $> \pi$（$K>0$）、双曲三角形内角和 $< \pi$（$K<0$）——这是「曲率符号 ⟹ 几何性质」最直观的证据。欧氏/椭圆/双曲三大几何的区分，在常曲率空间里被曲率符号一锤定音。</span>

## 3 公式解析：双曲空间的度量为什么是 $g = dx^2/x_n^2$

以 $H^2$ 上半平面模型为例，拆开「为什么分母是 $x_n$」：

**第一步，边界是无穷远**：$x_n \to 0$ 时 $g$ 的分母趋于零、度量「爆炸」——边界 $x_n=0$ 是**无穷远点**（双曲空间在边界处「发散」，像球面在无穷远收拢的反面）。
**第二步，$x_n \to \infty$ 度量收缩**：$x_n$ 越大，度量越小——远离边界，空间「变密」，使总「直径」无穷。
**第三步，曲率为常数 $-1$**：计算这个度量的截面曲率，处处 $K = -1$——正是「常负曲率」。**分母 $x_n$ 的选取就是为了让曲率恒为 $-1$。**<span class="marginnote">验证曲率需要算 Christoffel 记号与曲率张量——对 $g = dx^2/x_2^2$ 可以逐项算（只有少数非零 $\Gamma$），最终 $R_{1212} = -1\cdot(g_{11}g_{22}-g_{12}^2)$，即 $K = -1$。这个「算例」是练习黎曼几何计算的好题——读教材时可自行走一遍。</span>

## 4 三种空间的对称性：等距群

常曲率空间的另一个特征：**它们都有极大的对称群（等距群）**：

$\mathbb{R}^n$：欧氏群 $E(n)$（平移 + 旋转 + 反射）。
$S^n$：正交群 $O(n+1)$（旋转高维球）。
$H^n$：洛伦兹群 $O(1,n)$（双曲等距群）。

**重点：常曲率空间是「最对称」的空间——任意点、任意方向都等价（均匀且各向同性）。** 这是「常曲率」的另一种表述：曲率在所有点、所有平面都相同，所以没有「特殊点」。<span class="marginnote">「均匀各向同性」正是宇宙学原理（宇宙在大尺度上处处相同、各向同性）的数学表述——Friedmann-Lemaître-Robertson-Walker（FLRW）宇宙模型的几何基础就是「三维常曲率空间随时间的演化」。宇宙可能是球面、欧氏或双曲的——常曲率空间直接进入宇宙学。</span>

## 5 常曲率空间的地位

常曲率空间是黎曼几何的「标准模型」，地位多面：

**几何的三种范式**：欧氏、椭圆、双曲——两千年的几何之争在常曲率空间里和解。
**比较几何的基准**：一般流形的曲率界都「对照」常曲率空间（球面定理、曲率比较）。
**宇宙学的模型**：FLRW 宇宙 = 常曲率空间 + 时间演化。
**双曲几何的现代应用**：双曲嵌入（层级数据）、网络科学、几何深度学习（第九篇）。<span class="marginnote">双曲空间在机器学习里近年很热：树状/层级数据（知识图谱、语法树、社交网络）的「负曲率」结构天然适合嵌入双曲空间——「树的平均曲率为负，故双曲空间是树的自然几何」（Gromov）。双曲嵌入（Poincaré 嵌入）在表征学习中表现优异——常曲率空间是几何深度学习的「三选一」基底（球面/欧氏/双曲）。</span>

**重点：常曲率空间是「曲率恒定的宇宙」——三种空间、三种几何、三种对称，全部由同一个黎曼几何框架统一。** 它是本专题从「曲面」到「任意维几何」的完美收束。

### 例：双曲空间中的圆周长

用「圆周公式」感受负曲率空间的异常。双曲平面 $H^2$（$K=-1$）中，半径 $r$ 的圆（测地圆）周长

$$
C = 2\pi\sinh r
$$

- $r$ 小时：$\sinh r \approx r$，$C \approx 2\pi r$——局部像欧氏。
- $r$ 大时：$C \approx \pi e^r$——**指数增长，远大于 $2\pi r$**。

**对比三种空间**：欧氏 $C = 2\pi r$；球面 $C = 2\pi R\sin(r/R) < 2\pi r$（收缩）；双曲 $C = 2\pi\sinh r > 2\pi r$（膨胀）。**「圆周收缩/膨胀」是曲率符号的直接读数。**

**重点：双曲空间的周长「超指数膨胀」——负曲率的空间「空间过大」。** 这个异常在双曲几何、双曲流形、双曲嵌入（机器学习）里都有深远后果：「树状结构天然负曲率」——树的叶子随深度指数增多，正像双曲空间周长随半径指数增长。「双曲空间 = 树状数据的自然几何」由此而来。

### 三种空间的统一视角

把三种常曲率空间放进「同一个公式」：

$$
g = \frac{dx_1^2 + \cdots + dx_n^2}{\big(1 + \frac{K_0}{4}(x_1^2+\cdots+x_n^2)\big)^2}
$$

- $K_0 > 0$：球面模型（分母在有限处为零）。
- $K_0 = 0$：欧氏（分母为 1）。
- $K_0 < 0$：双曲模型（分母处处为正）。

**重点：一个公式、一个参数 $K_0$，统一三种空间——常曲率空间的「共形模型」。** 这个统一是「曲率决定几何」的终极演示：改变 $K_0$ 的符号，空间从球面「连续」变形到平面再到双曲。三种几何不是三套理论，而是「同一个度量的三个曲率值」——几何的统一在常曲率空间达到完美。

### 双曲空间与现代应用

双曲空间在数据科学里近年爆发：

- **双曲嵌入**：把树状/层级数据（知识图谱、词义、社交网络）嵌入双曲空间——「树的负曲率」匹配双曲空间的几何，嵌入误差大幅降低。
- **层级分类**：ImageNet 的层级类别用双曲空间表示优于欧氏。
- **图神经网络**：双曲 GNN 处理无标度/层级图结构。

**「层级数据天然适合负曲率空间」——双曲几何是树状结构的自然几何。** 欧氏空间擅长「平坦结构」，球面擅长「圆环结构」，双曲空间擅长「树状结构」——三种常曲率空间给数据表征三种「几何宿主」。「选对空间几何」是几何深度学习的核心决策。

## 6 小结

- **三类常曲率空间**：球面 $S^n$（$K>0$）、欧氏 $\mathbb{R}^n$（$K=0$）、双曲 $H^n$（$K<0$）。
- 测地线：直线 / 大圆 / 垂直半圆——「最直的路」因曲率而异。
- 三角形内角和：$=\pi$ / $>\pi$ / $<\pi$——曲率符号决定几何。
- 双曲模型：上半平面 $g = dx^2/x_n^2$、Poincaré 圆盘——负常曲率的显式实现。
- 对称性：等距群 $E(n)$ / $O(n+1)$ / $O(1,n)$——均匀各向同性。
- 地位：几何三种范式、比较基准、宇宙学模型、双曲嵌入。
