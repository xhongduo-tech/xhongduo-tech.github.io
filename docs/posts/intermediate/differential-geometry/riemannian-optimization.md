## 为什么从黎曼优化开始

机器学习里大量优化问题带「结构约束」：参数是正交矩阵（$X^TX = I$）、单位范数（$\|x\|=1$）、对称正定矩阵、低秩矩阵、概率单纯形。这些约束集合都是**黎曼流形**——于是优化问题变成「流形上的最优化」。

**黎曼优化（Riemannian optimization）**把梯度下降从欧氏空间搬到流形上：**在切空间里算梯度，沿测地线走一步，再把新点放回流形上。** 它的核心思想是：**约束流形不是「限制」，而是「自然的家」——优化应尊重流形的几何，而非把欧氏算法硬塞进约束。**<span class="marginnote">黎曼优化 = 微分几何 + 优化：把约束优化「几何化」。它的优势：① 自动满足约束（沿流形走，永不离开）；② 坐标无关（与参数化无关）；③ 利用曲率加速收敛。Absil 等人的《Optimization Algorithms on Matrix Manifolds》（2008）是其标准教材。</span>

## 1 欧氏梯度下降 vs 黎曼梯度下降

对比两种优化：

- **欧氏梯度下降**：$x_{k+1} = x_k - \eta\nabla f(x_k)$——在 $\mathbb{R}^n$ 的「直线」上走。
- **黎曼梯度下降**：
  $$
  x_{k+1} = \exp_{x_k}\big(-\eta\,\operatorname{grad} f(x_k)\big)
  $$
  其中 $\operatorname{grad} f$ 是流形上的梯度（切向量），$\exp$ 是**指数映射**（沿测地线走）——在流形的「测地线」上走。

**重点：黎曼梯度下降 = 欧氏梯度下降 + 把「直线更新」换成「测地线更新」。** $\operatorname{grad} f$ 是「黎曼梯度」——它把普通梯度投影到切空间，保证「沿流形下降」。<span class="marginnote">「黎曼梯度」：普通梯度 $\nabla f$ 不一定在切空间里（$\mathbb{R}^D$ 的方向可能指向流形外）。黎曼梯度 = $\nabla f$ 投影到切空间 $T_x\mathcal{M}$。它与普通梯度的关系：$\operatorname{grad} f = \mathcal{P}_{T_x\mathcal{M}}(\nabla f)$（或带度量 $g^{-1}df$）。「沿切空间走，才是沿流形走」。</span>

## 2 公式解析：为什么用指数映射而非「欧氏步 + 投影」

常见疑问：为什么不用「$x_{k+1} = \text{Proj}_{\mathcal{M}}(x_k - \eta\nabla f)$」（先欧氏走再投影回流形）？

**第一步，投影法的缺陷**：欧氏步可能「离流形很远」，投影回流的点「绕过」流形的弯曲——步长受曲率限制，收敛慢，甚至走错方向。
**第二步，指数映射的优势**：$\exp_x(v)$ 沿测地线走——**永远在流形上、步长与流形几何自洽**。测地线是最直的路线，尊重流形曲率。
**第三步，实用替代（retraction）**：指数映射计算贵，常用**回缩（retraction）**近似（一阶近似于指数映射，如「欧氏步 + 投影」其实也是一种回缩）。**回缩是「够用」的指数映射替代品。**

**重点：黎曼优化用「沿流形行走」替代「走出流形再拉回」——曲率被计入步进，收敛更快更稳。** 指数映射（或回缩）是「尊重几何的更新规则」。<span class="marginnote">工程实践：矩阵流形（正交群、Stiefel 流形）上的回缩有闭式（QR 分解、极分解），计算便宜。深度学习里的大多数「流形优化」实际用回缩而非精确指数映射——「几何理念 + 计算务实」的平衡。</span>

## 3 例子：正交约束优化

最常见的黎曼优化是**正交约束**：$\min f(X)$ subject to $X^TX = I$（$X \in \mathbb{R}^{n\times p}$ 是 Stiefel 流形 $\mathrm{St}(n,p)$）。

**黎曼梯度**：$\operatorname{grad}f(X) = \mathcal{P}_{T_X}(\nabla f(X)) = \nabla f - X\,\mathrm{sym}(X^T\nabla f)$（投影到切空间 $\{X^T\Delta + \Delta^TX = 0\}$）。
**更新**：$X_{k+1} = \exp_{X_k}(-\eta\operatorname{grad}f)$——用 QR/极分解实现回缩。
**应用**：PCA、LDA、联合对角化、正交神经网络（Orthogonal RNN/CNN 保持范数稳定）。

**重点：正交约束 = Stiefel 流形上的黎曼优化——自动保持正交性，无需投影惩罚。** 这是黎曼优化最成熟的落地场景。<span class="marginnote">正交性在深度学习的价值：正交 RNN/CNN 保持梯度范数（缓解梯度消失/爆炸）、保持信息量（残差网络的正交初始化）。「把正交性作为流形约束优化」比「罚函数」更干净——正交永远精确保持。「结构即流形」的工程威力。</span>

## 4 例子：对称正定流形与低秩流形

**对称正定矩阵（SPD）流形**：$S^n_{++}$（正定矩阵），度量为 $g_X(A,B) = \mathrm{tr}(X^{-1}AX^{-1}B)$——这是**仿射不变度量**。应用：协方差矩阵回归、扩散张量成像、高斯分布的参数空间。
**低秩流形**：秩固定为 $r$ 的矩阵流形 $\{X: \text{rank}(X) = r\}$——矩阵补全、推荐系统、低秩表征。
**概率单纯形**：$p_i \ge 0, \sum p_i = 1$——带 Fisher 度量成为信息几何的流形（下一节）。

**重点：许多「带结构约束的优化」都是黎曼优化——SPD、低秩、正交、概率单纯形各有自然的黎曼结构。** 结构约束 = 流形约束，优化在流形上「自由」进行。<span class="marginnote">SPD 流形的「仿射不变度量」让协方差矩阵的均值、插值（几何均值）与坐标无关——这是「流形度量决定几何性质」的实例。扩散张量成像（DTI）里，每个体素一个 SPD 矩阵，沿流形做平滑/插值比欧氏更正确。「度量是流形上的『正确距离』」。</span>

## 5 黎曼优化在机器学习中的地位

黎曼优化是现代优化与深度学习的交汇点：

**自然梯度**：参数流形带 Fisher 度量，自然梯度 = 黎曼梯度（$g^{-1}\nabla f$）——坐标无关的梯度下降（下一节信息几何）。
**流形约束的深度学习**：正交网络、归一化、谱归一化、低秩适应（LoRA 的「低秩流形」视角）。
**数值线性代数**：特征值问题、SVD 是流形上的优化（在 Grassmann/Stiefel 流形上）。
**贝叶斯与统计**：变分推断在概率单纯形/统计流形上优化。

**重点：黎曼优化把「约束」变成「几何」——约束不再是障碍，而是优化的自然舞台。** 它让微分几何（本专题的切空间、指数映射、度量、测地线）成为现代优化的日常工具。<span class="marginnote">LoRA（低秩适应）的几何视角：权重更新限制在低秩流形上——这本身就是「低秩流形约束」的隐式优化。谱归一化把参数限制在球面上（范数约束）。深度学习里的「结构先验」正在越来越多地被翻译成「流形约束」——黎曼优化是这门翻译的语法。</span>

### 例：单位球面上的优化

最简单的黎曼优化：在单位球面 $S^{n-1}$ 上最小化 $f(x) = x^T A x$（二次型）。

- **约束**：$\|x\| = 1$——球面流形。
- **黎曼梯度**：$\operatorname{grad} f(x) = 2Ax - 2(x^TAx)x$（投影到切空间 $\{v: x\cdot v = 0\}$）。
- **更新**：$x_{k+1} = \exp_{x_k}(-\eta\operatorname{grad}f) = \frac{x_k - \eta\operatorname{grad}f}{\|x_k - \eta\operatorname{grad}f\|}$（回缩 = 归一化）。

**重点：球面约束优化用「黎曼梯度 + 归一化回缩」——每一步都精确落在球面上。** 这个例子是「特征值问题 = 球面优化」的雏形：最小化 $x^TAx$ 在球面上，得到最小特征值对应的特征向量——PCA、谱聚类的核心计算。黎曼优化把「约束优化」变成「流形上的自由运动」——约束不再是障碍，而是几何的家。

### 回缩（retraction）与指数映射

指数映射计算昂贵（要解测地线 ODE），工程上用**回缩**替代：它是「一阶逼近指数映射」的映射，把切向量 $v \in T_x\mathcal{M}$ 映回流形上，且 $R_x(0) = x$、$dR_x(0) = \text{id}$。

**重点：回缩 = 「够用的指数映射」——一阶精度相同，计算便宜得多。** 矩阵流形上的回缩有闭式：Stiefel 流形用 QR 分解、球面用归一化。深度学习里的「谱归一化」「权重归一化」本质是回缩到约束流形。「指数映射是理想，回缩是现实」——黎曼优化的工程平衡。

### 黎曼优化的收敛性直觉

为什么黎曼优化收敛好？因为它在「正确」的几何里走：

- **欧氏优化**：把流形当平面走——跨过曲率、走弯路。
- **黎曼优化**：沿测地线走——「直线」在流形上最短，曲率被计入。

**「尊重几何的走法收敛更快」——黎曼优化用流形自身的曲率校正步进。** 这解释了为什么约束优化用「流形方法」优于「罚函数 + 投影」：几何正确的路径少走冤枉路。「优化器的几何自觉」——从欧氏梯度下降到自然梯度，几何是收敛性的底层逻辑。

### 黎曼优化的工具箱

黎曼优化的标准组件（Absil 框架）：

- **切空间投影**：$\mathcal{P}_x$（把梯度/向量投到切空间）。
- **回缩**：$R_x(v)$（从切空间映射回流形，近似指数映射）。
- **向量搬运**：$\mathcal{T}$（把向量沿流形搬动，平行移动的近似）。
- **梯度 / Hessian**：$\operatorname{grad} f$、$\operatorname{Hess} f$（黎曼梯度与海森）。

**「投影 + 回缩 + 搬运」是黎曼优化的三件套——每个欧氏算法都能翻译成流形版。** 梯度下降、牛顿法、共轭梯度都有黎曼版本。学会三件套，任何欧氏优化算法都能「流形化」——这是黎曼优化的工程方法论。

### 与自然梯度的联系

黎曼优化与自然梯度（信息几何）相通：自然梯度是「Fisher 度量下的黎曼梯度」——它是统计流形上的黎曼优化。**「自然梯度 = 信息几何 + 黎曼优化」——两条线在优化处交汇。**

**「选择正确的度量，就有正确的梯度」——黎曼优化的核心信条。** 欧氏梯度依赖坐标，黎曼梯度依赖度量——选对度量（Fisher、诱导度量）则梯度坐标无关。从普通梯度到自然梯度，几何是「正确方向」的裁决者。

## 6 小结

- **黎曼优化**：在约束流形上做优化——切空间算梯度、指数映射/回缩更新。
- 黎曼梯度下降：$x_{k+1} = \exp_{x_k}(-\eta\operatorname{grad}f(x_k))$。
- 指数映射（尊重曲率）vs 欧氏步+投影（忽略曲率）；回缩是务实替代。
- 例子：正交约束（Stiefel 流形）、SPD 流形、低秩流形、概率单纯形。
- 地位：自然梯度、结构约束深度学习、数值线性代数、变分推断。
