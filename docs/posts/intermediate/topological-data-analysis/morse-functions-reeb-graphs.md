# Morse 函数与 Reeb 图

<div class="epigraph">

## 为什么从 Morse 函数开始

上一篇 Mapper 算法被反复称作「Reeb 图的离散近似」，但 Reeb 图本身尚未登场。这篇把它补上：从**Morse 函数**出发，研究「水平集随高度如何变形」，再定义 Reeb 图——把流形按「同一水平集的同一连通分量」塌缩成的骨架图。它同时是 Mapper 的理论母体（第八篇）与持续同调的重要灵感（持续性定理常借 Morse 语言的论证），也是「用一维骨架捕捉高维形状」这条 TDA 主线的关键一环。<span class="marginnote">Morse 理论由玛斯顿 · 莫尔斯（Marston Morse）在 1920–30 年代创立，米尔诺的经典小册子让它在拓扑与几何之间走红。对 TDA 而言最重要的一句是：<strong>流形的拓扑由它的（任意）Morse 函数的临界点完全决定</strong>——于是「形状」可以被「临界点的位置与指标」编码，而这正是可计算的。</span>

## 1 Morse 函数：临界点都要「干净」

设 $M$ 是光滑紧流形，$f: M \to \mathbb{R}$ 是光滑函数。$f$ 的**临界点（critical point）**是梯度为零的点；在临界点处的二阶信息存于 **Hessian 矩阵** $H_f = (\partial^2 f / \partial x_i \partial x_j)$。

**Morse 函数（Morse function）**：所有临界点都是**非退化（non-degenerate）**的，即 Hessian 处处可逆。非退化意味着临界点彼此孤立，且每个临界点有一个明确的**指标（index）**——Hessian 负特征值的个数：指标 0 是极小，指标 1 是鞍点，指标 2 是极大（在二维曲面上），指标 $d$ 是 $d$ 维流形上的「峰」。<span class="marginnote">「Morse 函数」不是少数派：光滑函数的「几乎所有」（一个开稠集）都是 Morse 函数——非退化性可以微扰得到。对 TDA 的实际意义是：给数据随便选一个「高度方向」，几乎总是一个好滤镜。这也解释了为什么 Mapper 常用投影或偏心度这类简单函数当滤镜也有效。</span>

**Morse 引理（Morse lemma）**：在指标为 $i$ 的临界点附近，存在局部坐标使

$$
f(x) = -x_1^2 - \cdots - x_i^2 + x_{i+1}^2 + \cdots + x_d^2 + c,
$$

即函数在临界点附近「就是这个样子」——沿 $i$ 个方向下弯、沿 $d-i$ 个方向上弯。它说明临界点的局部拓扑类型只有「指标」一个参数在起作用。

## 2 水平集的变形：基本定理

考察**子水平集** $M_a = f^{-1}(-\infty, a]$。当 $a$ 穿过一个非临界值时，$M_a$ 的同伦型不变（水平集光滑变形）；当 $a$ **穿过临界点**时，$M_a$ 的同伦型只在「挂上一个胞腔」的意义下改变。

**Morse 理论基本定理**：穿过指标为 $i$ 的临界点时，$M_a$ 的同伦型相当于粘上一个 **$i$-胞腔** $e^i$。<span class="marginnote">例：二维球面 $S^2$ 取高度函数。极小值处 $M_a$ 从一个点开始；穿过鞍点后（球面没有鞍点）——换成环面：极小处生出一个点，第一个鞍点把一条「桥」接上（挂 1-胞腔），第二个鞍点接第二条桥，极大处挂上 2-胞腔封顶。逐层「挂胞腔」的序列恰好重演出环面的 CW 结构，与第二级《拓扑学》的 CW 复形语言完全吻合。</span>

这个定理是「拓扑只由临界点决定」的严格版本。它顺带给出了计算同调的**Morse 不等式**：第 $k$ 个 Betti 数不超过指标为 $k$ 的临界点数——数鞍点就能得到 $H_1$ 维数的上界。

**重点：持续同调与 Morse 理论同构**。子水平集 $M_a$ 的同调随 $a$ 变化，恰好就是 $f$ 的持续同调；临界值就是持续图里点的出生/死亡坐标。这是「持续性 = Morse 式的分层分析」这一看法的严格表述。

Morse 不等式给出一个可以手算的约束。对环面取高度函数：指标 0 的临界点 1 个（极小）、指标 1 的 2 个（鞍点）、指标 2 的 1 个（极大）。Morse 不等式说 $\beta_0 \le 1$、$\beta_1 \le 2$、$\beta_2 \le 1$——环面的 Betti 数 $(1, 2, 1)$ 恰好全部取到上界。反过来，若某流形的 Morse 函数有 3 个指标 1 的临界点，那么 $\beta_1 \le 3$：**数鞍点，就能给一维洞的个数一个上界**，完全不需要解同调。

## 3 Reeb 图：把流形塌成骨架

**Reeb 图（Reeb graph）** 是在流形上定义等价关系得到的商空间：$x \sim y$ 当且仅当

$$
f(x) = f(y) \quad \text{且} \quad x, y \text{ 属于同一水平集 } f^{-1}(f(x)) \text{ 的同一连通分量}.
$$

商空间 $R_f = M / \sim$ 是一个一维 CW 复形（图）。它的几何意义：把每个水平集的每个连通分量缩成一个点——连通分量合并/分裂的地方（恰是临界点）成为顶点，其余部分是边。<span class="marginnote">经典例：环面直立，高度函数有 4 个关键点——一个极小、两个鞍点、一个极大。其 Reeb 图呈「叶形」：底部一条茎通到第一个鞍点，两条平行边构成中间一环（两个鞍点之间的两条「路」），再收拢成一条茎到顶部的极大。图中这一环，正是环面的一维洞在骨架上的遗留。</span>

**Reeb 图的性质**：它是比流形本身小得多的对象，却保留了 $f$ 的水平集连通性结构；顶点度数与临界点一一对应；$R_f$ 的 $H_1$ 维数给出流形的一部分拓扑信息。它的普适应用是**形状骨架化（skeletonization）**——三维模型的 Reeb 图（取高度或曲率为 $f$）直接给出模型的「骨架线」，广泛用于形状匹配与检索。

### 水平集演化对照

把三种经典形状的演化并排看，Reeb 图的构造规则一目了然：

| 空间 | 临界点（指标） | 水平集演化 | Reeb 图 |
| --- | --- | --- | --- |
| 球面 $S^2$ | 极小(0)、极大(2) | 单圆 → 缩成点 → 单圆 | 一条线段 |
| 环面 $T^2$ | 极小(0)、鞍×2(1)、极大(2) | 单圆 → 两圆 → 两圆 → 单圆 | 中段分成两条平行边的环 |
| 两个不连通圆盘 | 极小×2、鞍×1、极大×1 | 双圆 → 合并成单圆 | 一条带合并顶点的单边 |

第三行提醒我们：Reeb 图是「水平集连通性」的忠实摘要——两个分离的圆盘在上方合并后只剩一棵简单的树，骨架保留了合并事件，却丢掉了两个圆盘各自的形状。这正是第九篇强调的：**骨架读拓扑，不读形状**。

### 一个能全程算完的例子：球面

球面 $S^2$ 是 Reeb 图最干净的起点。取单位球面，$f$ = 高度 $z$。临界点只有两个：南极（$z = -1$，指标 0 的极小）与北极（$z = 1$，指标 2 的极大），没有鞍点——这正是球面 $H_1 = 0$ 在 Morse 语言里的体现。

对 $-1 < c < 1$，水平集 $\{z = c\}$ 是纬线圆，一个连通分量，随 $c$ 上升先放大、过赤道后缩小，到两极缩成一点。于是商空间把「每条纬线圆」缩成一个点：$R_f$ 就是**一条从南极到北极的线段**——两个顶点（临界点）、一条边。

用 Morse 理论核对：穿过南极（指标 0）挂上 0-胞腔，穿过北极（指标 2）挂上 2-胞腔，Betti 数 $(1, 0, 1)$ 恰好由这两个胞腔各贡献一个。再对比环面（见边注）：多了两个鞍点，Reeb 图里就多出一个环——**Reeb 图的环与 $H_1$ 的一维洞一一对应**，骨架与同调互相印证。

## 4 公式解析：$R_f = M\big/{\sim},\qquad x \sim y \iff f(x)=f(y) \wedge x \sim_f y$

这条定义式有两重结构，拆开看：

**第一步，条件 $f(x) = f(y)$**：只允许「同一高度」的点互相等同——Reeb 图不跨越高度粘连，图的纵向位置仍由 $f$ 值排序。
- **第二步，条件 $x \sim_f y$（同一水平集的同一分量）**：同高还不够，还要在同一个连通分量里。同高的两个分离圈（环面中段的左右两环）是不同点；合并成环的点才能并成一个顶点。
- **第三步，为什么商掉后是图**：把每个「水平集分量」缩成一点后，各分量按高度上下相接，$f$ 诱导出图上的单调函数——图的每个顶点（临界点）之外，结构都是简单的「线」。一维性来自「一个参数（高度）上分量的并/分事件」天然只能是一维的。

## 5 从 Reeb 图到 Mapper

Mapper 与 Reeb 图的关系现在是精确的：**Mapper 图 = 用有限重叠覆盖离散化后的 Reeb 图**。区间 $I$ 的预像的连通分量，对应 Reeb 图中「高度在 $I$ 内」的一段子图；区间重叠保证相邻子图连边。当覆盖越细、重叠越密，Mapper 图越逼近 $R_f$。<span class="marginnote">这个「离散化收敛」是 Mapper 可信性的理论保证，也提示了 Mapper 的改进方向：用更聪明的滤镜（而非任意投影），让 $f$ 是「真正 Morse 的」——临界点少而干净——Mapper 骨架就越可靠。反之，若滤镜高度退化（如常数函数），Mapper 图塌成一点，信息尽失。</span>这也回答了上一篇末尾的问题：**Mapper 不是在发明新的拓扑对象，它是在数值化地近似 Reeb 图**。

## 6 辨析：三处易混

**辨析｜易错点：**

- **Reeb 图 ≠ 流形本身**：$R_f$ 只保留「水平集连通性」，丢失了水平集内的形状（环变成点）。用它做形状匹配靠的是「骨架」，不是「形状」。
- **临界点 ≠ 拐点**：Morse 临界点是梯度为零（水平切线），与一元函数的拐点（二阶导为零）不是一回事；判断时用 Hessian 而非导数符号变化。
- **Reeb 图与持续图互补**：Reeb 图是「每一条高度处的全局连通信息」，持续图是「各维同调的生灭」。二者都是 $f$ 的拓扑摘要，但前者是图、后者是多重集，不可互相替代——实际项目常两者都算。

## 7 小结

- **Morse 函数**：临界点全非退化，Hessian 可逆；每个临界点有指标 $i$（负特征值数）。
- **Morse 引理**：临界点附近 $f = -\sum_{i} x_i^2 + \sum_{j} x_j^2 + c$，局部类型只由指标决定。
- **基本定理**：过指标 $i$ 的临界点，子水平集同伦地挂上 $i$-胞腔——拓扑由临界点决定。
- **Reeb 图**：$x \sim y \iff f(x)=f(y)$ 且同在一水平集分量，商空间是一维图；环面直立得「叶形」骨架。
- **Mapper = Reeb 图的有限覆盖离散化**；滤镜选得好，骨架就可信。

### 术语速查

| 术语 | 一句话定义 |
| --- | --- |
| 临界点 | 梯度为零的点；非退化时由 Hessian 判别 |
| 指标 | Hessian 负特征值个数：0=极小、1=鞍点、2=极大 |
| Morse 函数 | 所有临界点非退化的光滑函数（「几乎所有」函数都如此） |
| 子水平集 | $M_a = f^{-1}(-\infty, a]$，随 $a$ 演化的对象 |
| Reeb 图 | 把水平集的每个连通分量缩成一点得到的商图 |
| Morse 不等式 | $\beta_k \le$（指标为 $k$ 的临界点数），数鞍点即得 $H_1$ 上界 |

实践里 Reeb 图的取值提醒：它的顶点只携带「连通分量何时并/分」的信息，不携带分量内部的形状——形状匹配用骨架、同调分析用持续图，两者各司其职、互不替代。
