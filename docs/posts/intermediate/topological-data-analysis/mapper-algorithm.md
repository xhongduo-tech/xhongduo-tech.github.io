## 为什么从 Mapper 开始

持续同调告诉数据**有多少个洞**，却不告诉你洞在**哪里**、数据如何**组织**。对很多场景——基因表达谱的病人分组、材料数据库的物相识别——研究者要的不是数字，而是一张**看得懂的地图**：谁和谁是一伙的、边界在哪儿、有没有意外的桥。**Mapper 算法**（Singh, Mémoli, Carlsson, 2007）正是这样一把「形状雕刻刀」：它把高维点云雕刻成一个低维图，图的连通性、环路、分支结构直接可读。它不追求同调群的完整信息，而是追求**可解释的骨架**。<span class="marginnote">Mapper 是 TDA 里工业落地最多的算法：图的结构（节点=数据簇，边=簇间有共享数据点）可以直接用于探索性数据分析。它的理论根基是神经定理与 Reeb 图——Mapper 图可以理解为「Reeb 图被有限覆盖离散化后的神经」，第九篇《Morse 函数与 Reeb 图》会给出严格对应。</span>

## 1 算法三件套

Mapper 的输入是点云 $X$，输出是图。流程可以概括为「选函数、盖区间、分簇连边」：

**① 选一个滤镜函数（filter / lens）** $f: X \to \mathbb{R}$。它是「从哪个角度看数据」的决定性选择：

到某个基点（质心、一个地标点）的距离——揭示数据以该点为中心的层状结构；
- **密度估计**——把高密度区域 vs 稀疏尾巴分开；
- PCA 主轴坐标、t-SNE 坐标——用流行降维先「摊开」数据；
- 偏心度（到第 $k$ 远邻居的平均距离）——无监督、尺度无关。

**② 盖住 $f$ 的值域**：用若干**互相重叠的区间**覆盖 $f(X) \subseteq \mathbb{R}$。区间个数与重叠率是两个关键旋钮。<span class="marginnote">重叠率的直觉：重叠为 0 时，相邻区间的预像互不相交，Mapper 图必是一堆孤立节点——图就「散架」了；重叠越大，图越连通。实践中重叠率常取 30%–60%，区间数从几十到上百。Morse 函数取值在 $\mathbb{R}$，可推广到 $\mathbb{R}^k$（多维滤镜），但计算与解释成本都骤增。</span>

**③ 对每个区间 $I$，取预像 $f^{-1}(I)$，在预像内部做聚类**。每一簇成为一个**节点**；两个簇（节点）共享至少一个数据点时连一条**边**。

**重点：Mapper 输出的是「数据的分层聚类谱系图」**——同一区间的多个簇是「并列的子群」，跨区间的边是「相邻子群的过渡带」。数据里的环（如周期性行为）会表现为图里的环，连通分量会表现为图的连通块。

## 2 数学形式：滤镜覆盖的神经

设 $\mathcal{U} = \{U_1, \dots, U_n\}$ 是 $f(X)$ 的一个开覆盖，$\pi_0(S)$ 记集合 $S$ 的连通分量集合。**Mapper 图**定义为

$$
M(\mathcal{U}, f, X) = \mathrm{Nerve}\Big(\big\{\pi_0(f^{-1}(U_i))\big\}_{i=1}^{n}\Big),
$$

即：对每个区间取预像、取连通分量作为「集合族」，再取这个集合族的**神经（nerve）**——每个分量为顶点，分量两两相交（等价地，共享数据点）时连边。神经定理保证：如果每个 $f^{-1}(U_i)$ 的各分量都可缩（聚类出的簇通常近似如此），则 $M$ 在弱意义下逼近 Reeb 图的离散版。<span class="marginnote">「神经」一词我们在第三篇 Čech 复形处见过：Čech 复形是「球覆盖的神经」，Mapper 是「预像覆盖的神经」。两个地方用同一个构造，不是巧合——神经定理是 TDA 最通用的「把连续变离散而不丢拓扑」的工具，见第二级《拓扑学》专题的神经定理专节。</span>

## 3 判读与典型案例

Mapper 图判读有一套成熟的心智模型：

**节点** = 一个局部同质的子群；节点的大小/颜色可编码簇内统计量（平均年龄、平均表达量）。
- **边** = 两个子群有过渡数据；**长链** = 数据呈连续渐变（如疾病严重程度谱系）；
- **环** = 数据的循环结构（周期、闭环过程）；**星型** = 一个中心簇连接多个独立亚群。

**经典案例：乳腺癌分子分型**（Nicolau, Levine, Carlsson, 2011）。对乳腺癌基因表达谱跑 Mapper，图里出现一个**独立的「元簇」**（小分支远离主体），它对应一类低复发、对激素治疗反应极好的病人亚型。这个亚型在传统聚类下很难被发现，因为它在多个方向上都是「少数派」——而 Mapper 的**重叠区间 + 神经图**恰好让「少数派簇被可见地孤立出来」。<span class="marginnote">Mapper 的另一个知名应用是运动数据分析（用投影坐标做滤镜，重建棒球投手动作的空间），以及材料科学（用实验参数作滤镜，发现合金相变边界）。共同点：数据有「连续变化 + 意外分支」的结构，而 Mapper 擅长让分支与环显形。它与持续同调互补：持续同调回答「有没有环」，Mapper 回答「环在结构上长什么样」。</span>

## 4 公式解析：$M(\mathcal{U}, f, X) = \mathrm{Nerve}\big(\big\{\pi_0(f^{-1}(U_i))\big\}_{i=1}^{n}\big)$

这条定义式只有四层嵌套，逐层剥开：

- **第一步，$f^{-1}(U_i)$**：滤镜值落在区间 $U_i$ 内的全部数据点——「看这个区间的视角下，谁被选中」。
- **第二步，$\pi_0(\cdot)$**：取这些点的**连通分量**。聚类算法（单链接、DBSCAN 等）执行的就是这一步：把「看同一个区间的点」按邻近性拆成簇。
- **第三步，族 $\{\pi_0(f^{-1}(U_i))\}$**：把所有区间产生的簇并成一个**集合族**——元素是簇，簇之间「相交」指共享数据点。
- **第四步，$\mathrm{Nerve}(\cdot)$**：按「相交则连边」规则把簇变成顶点与边——这正是 ③ 步的精确表述。整条式子的意义：**Mapper 图 = 「滤镜诱导的簇」的相交图**。

## 5 辨析：旋钮与坑

**辨析｜易错点：**

- **滤镜是最关键的选择**：坏滤镜 = 单射 = 每个点一簇 = 图退化成原数据；好滤镜应让「重要的结构方向」与滤镜方向一致。选滤镜时应多试几个并对比。
- **区间数与重叠率的敏感性**：区间太多→每簇点太少，图破碎；重叠太少→图断裂；都需做**参数扫描**，看结论是否稳健。
- **聚类方法的选择**：预像内用密度聚类（DBSCAN）通常比 $k$-means 好——簇数未知，且要容忍噪声。
- **图 ≠ 流形**：Mapper 图是 Reeb 图的**离散近似**，节点坐标无几何含义，只能读拓扑（连通、环、分支），不能读「距离」。
- **环的误读**：图的环既可能是真实循环，也可能来自滤镜区间覆盖与重叠的伪影——用多重参数组合验证。

## 6 小结

- **Mapper 三步**：选滤镜 $f$、盖重叠区间、分簇连边；输出可读的拓扑骨架图。
- **数学内核**：$M = \mathrm{Nerve}\big(\{\pi_0(f^{-1}(U_i))\}\big)$——滤镜诱导的簇的相交图，是 Reeb 图的离散版。
- **判读词汇表**：节点=子群、边=过渡带、环=循环结构、星型=中心-辐射。
- **成功案例**：乳腺癌基因谱发现隐蔽的预后亚型；持续同调数洞、Mapper 画结构，二者互补。
- 关键旋钮：**滤镜、区间数、重叠率、聚类法**，全部要做敏感性验证。
