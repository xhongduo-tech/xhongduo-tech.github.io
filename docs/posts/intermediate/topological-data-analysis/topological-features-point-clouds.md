## 为什么从特征提取开始

前六篇把理论部件一件件造好了：复形、同调、持续同调、持续图、距离。现在把它们拧成一条**流水线**，对真实点云端到端地产出可用的「拓扑特征」。这是 TDA 从「数学玩具」走向「数据科学工具」的最后一公里——也恰恰是最容易出错的一段：每一步都有一个或几个「旋钮」，选错旋钮，理论再漂亮也无济于事。<span class="marginnote">「特征」在机器学习里是模型的输入：一组能区分类别的数值。拓扑特征的特殊之处在于它捕捉的是<strong>全局形状信息</strong>——孔、分支、连通性——这是传统统计特征（均值、方差、相关）完全看不见的。因此拓扑特征常作为「互补通道」与几何/统计特征拼接，而不是替代。</span>

## 1 端到端管线

标准点云 TDA 管线由四个环节组成：

**第一步：点云预处理。** 去噪、归一化尺度、必要时采样。点云只是流形的**采样**，不是流形本身——采样密度决定了可分辨特征的尺度下限。

**第二步：建过滤。** 选复形（Rips 是默认，α-复形要几何精确，见第三篇）与过滤驱动方式：纯尺度（$r$ 递增）或密度加权（先纳入高密度点）。<span class="marginnote">密度加权过滤是处理噪声的关键技巧：把点云先估局部密度（如 k 近邻距离倒数），再把「点出现时刻」与密度挂钩——低密度离群点最后才进入复形，它们的短命特征自然落在对角线附近，后续可裁剪。这让「噪声」在特征层面被结构性排除，而不是靠事后阈值。</span>

**第三步：算持续同调。** 对过滤全程计算 $H_0, H_1, H_2$（甚至 $H_3$）的持续配对，输出条形码/持续图。

**第四步：向量化。** 把持续图转成固定长度的特征向量，交给下游分类/回归/聚类。可选的方向：

**Betti 曲线（Betti curves）**：对每个 $r$ 统计 $\beta_k^{r,\text{alive}}$，得一条曲线，采样成向量；
- **持续熵（persistent entropy）**：把全部寿命归一化成概率分布，取香农熵——一个数概括「特征的复杂度」；
- **持续景观采样**（第五篇）：沿 $t$ 轴采样 $\lambda_k(t)$，拼接成向量；
- **持久影像（persistence images）**：把持续图高斯平滑后栅格化成图像。

## 2 尺度的艺术：哪些特征可信

持续图会同时给出成百上千个点，绝大多数是噪声。<span class="marginnote">工程经验法则：寿命超过「最大点间距离的相当比例」的环才值得当作真实特征；短命点先按寿命排序后统一剪枝。更严谨的做法是先用扰动/bootstrap 估计噪声尺度，再据此定寿命阈值——把「选阈值」从拍脑袋变成统计决策。</span>判断「哪个点是真的」有三个信号：

1. **寿命长**：跨越多尺度仍存活；
2. **离对角线远**：寿命 $d - b$ 远大于典型噪声特征；
3. **可重复**：对数据加扰动/再抽样后仍然出现——这是最诚实的检验。

**重点：单张持续图的「绝对值」不可轻信，多张图的「相对比较」才可信**。稳定性定理保证比较是稳健的，但绝对值依赖尺度归一化——所以在实践中，通常把点云先归一化到单位直径，再谈绝对寿命阈值。

「阈值怎么定」可以量化。以 200 点采样在半径为 1 的圆上、叠加 $\sigma = 0.02$ 的高斯噪声为例：归一化后噪声特征（短命点）的寿命集中在 $0.01$–$0.05$，真实环的寿命约 $0.7$。取寿命阈值 $0.15$ 即可把两者干净分开，且对阈值在 $[0.1, 0.3]$ 内的移动完全不敏感——**结论对阈值鲁棒**是「这个环是真的」的强信号。若不知道噪声尺度，就做 bootstrap：对点云重采样 50 次，看每个持续点的寿命方差，方差大者多为噪声。

三个信号按可信度排序，**可重复性 > 寿命长 > 离对角线远**。寿命长是必要条件但不充分——一个长寿点可能只是「噪声恰好连续」；扰动后仍出现才是真正的结构。实践中把「扰动 50 次、出现 ≥ 40 次」当作筛选标准，误报率会显著下降。这条标准也被称为 bootstrap 检验，是 TDA 报告里最常被要求的稳健性证据。

把阈值、bootstrap 与鲁棒性连起来，TDA 实践者的心智模型只有一句话：**先问「这个特征换参数后还在吗」，再问「它在讲什么」**。前一句是统计纪律，后一句才是科学解释——顺序不能反。

## 3 案例：时间序列与形状

两个最经典的端到端应用，用来体会管线长什么样：

**形状检索 / 分类。** 对三维物体扫描点云（如 ModelNet、ShapeNet），对每件物体算 $H_1, H_2$ 持续图，向量化后进分类器。环/空腔数量与寿命直接编码「形状家族」：杯子的 $H_2$ 空腔、轮胎的 $H_1$ 大环，都会产生长寿特征。用景观向量做 SVM 分类，准确率常与纯几何描述子相当或更稳。

**时间序列分析（Takens 嵌入）。** 对一维时间序列做滑动窗口，把每个窗口排成 $d$ 维向量，得到高维点云；对该点云算持续同调，就得到序列的**拓扑指纹**。<span class="marginnote">Takens 嵌入定理保证：对确定性动力系统，延迟嵌入在足够大维度下与系统状态空间拓扑等价——于是「序列有没有周期、有几个频率分量」变成「嵌入点云里有没有环、几个环」。这是 TDA 应用最广、成果最多的领域之一，见《非线性动力学与混沌》专题对嵌入定理的详细展开。</span>周期信号→一个长寿环；准周期→两个；混沌→一堆短命环。由此可以对 ECG、地震波、股票序列做拓扑诊断。

### 一条端到端跑通：200 点的圆

把四个环节拧在一起，用一组具体的数走完。取 200 个点均匀采样在半径为 1 的圆上，叠加 $\sigma = 0.02$ 的高斯噪声：

1. **预处理**：归一化到直径 1（整体除以 2），估计噪声尺度 $\approx 0.01$；
2. **建过滤**：Rips 复形，半径从 0 到 1，步长 0.005（200 步）——步长要小于噪声尺度，否则两个临界事件之间的演化会被跳过；
3. **持续同调**：$H_1$ 出现一条寿命约 0.7 的环（出生约 0.02、死亡约 0.72），其余 $H_1$ 点寿命均小于 0.05；
4. **向量化**：取持续熵——寿命分布高度集中在这条长环上，熵接近 0；同时取 Betti 曲线在 20 个半径处的值拼成特征向量，喂给分类器。

下游做一个最简单的检验：同样的 200 点，一半采样在圆上、一半采样在椭圆上（长短轴 1.6 与 0.6）。圆的 $H_1$ 环寿命约 0.7，椭圆的环寿命约 0.25——两组持续熵分布明显分离，置换检验给出 $p < 0.01$。**一个数字就能区分「圆」与「椭圆」**，这就是拓扑特征作为判别信号的威力：它不数点、不数距离，数的是「环能活多久」。

计算成本上要留个心眼：Rips 复形的规模随点数增长很快（$n$ 个点全连接时单形数量级可达 $2^n$，实际因半径截断而小得多）。200 点完全无压力，10 万点就要改用 α-复形（第三篇）或抽样降采样。经验法则：**Rips 适合万点以内，超过就用几何精化的 α-复形或分块计算**。

最后提醒一句「何时不要用 TDA」：当数据没有明显的形状结构（纯均匀噪声、完全随机点）时，拓扑特征只会给出噪声水平的短命条，白费算力。先做一次快速持续同调，看一眼有没有长寿命特征，再决定是否投入完整的管线——这个「先探后投」的检查能省下大量无效计算。

## 4 公式解析：$\mathrm{PE} = -\sum_{i} p_i \log p_i, \quad p_i = \frac{d_i - b_i}{\sum_j (d_j - b_j)}$

这四个环节各自有一个「先想清楚再动手」的问题：预处理问「尺度怎么归一化」，建过滤问「复形类型与步长」，持续同调问「算到哪一维」，向量化问「特征维度取多大」。把四个问题写进实验计划，比事后补救省时得多。一个可复用的经验：**先拿 20% 的子采样把四步全部走通，确认每个环节的输出尺度合理，再放大到全量数据**——这能把参数错误的影响缩小 5 倍。

**持续熵（persistent entropy）** 用一个数概括整张持续图，公式拆三步：

- **第一步，算每个点的寿命**：$l_i = d_i - b_i$（不含 $d_i = \infty$ 的类，或对它们单独处理）。寿命越长，越代表「真实结构」。
- **第二步，归一化成概率**：$p_i = l_i / \sum_j l_j$。所有点寿命之和作为分母，把寿命分布变成概率分布 $\{p_i\}$——长寿点概率大。
- **第三步，取香农熵**：$\mathrm{PE} = -\sum_i p_i \log p_i$。分布越均匀（所有特征寿命差不多），熵越大；若只有一个长寿环支配一切，熵接近 0。**持续熵高 = 结构复杂分散，持续熵低 = 少数几个特征主导**——单变量、稳定、可直接进回归，是拓扑特征里最「轻」的摘要。

持续熵的极端情形值得记住：全部寿命相等时 $p_i$ 均匀，熵取最大值 $\log N$（$N$ 为点数）；只有一个长寿环时熵趋近 0。于是熵本身可以当「结构复杂度」的代理——做分类时先扫一眼两组的熵分布，往往比直接上模型更快给出信号。

## 5 辨析：六处高频坑

**辨析｜易错点：**

- **点云不是流形**：采样密度低于特征尺度时，特征根本看不见——先问「最细可分辨的结构是什么」再选参数。
- **尺度未归一化**：不同样本的绝对尺度不同，直接比寿命等于拿米尺和厘米尺比——先归一化。
- **只用 Rips 全默认**：Rips 计算要选过滤范围与步数，步数太少会把关键事件之间的演化丢光。
- **把 $H_0$ 当无关紧要**：$H_0$ 连通分量的合并模式（Elder 规则的死亡序列）本身就是丰富的聚类信号。
- **忽略参数敏感性分析**：一个环在 3 组参数下出现、1 组下消失，多半是参数假象——做扰动分析。
- **把持续图当「免费午餐」**：它反映的是数据的**采样结构**，不是因果。拓扑特征要与其他特征联合解释，不能单独下因果结论。

参数敏感性的标准工作流值得写成清单：固定其他参数，逐个扫描「步长、过滤最大半径、噪声阈值、向量化采样点数」，画出指标（如分类准确率）随参数变化的曲线。若指标在参数区间中部有宽阔的稳定平台，结论可信；若只在某个尖点达到最好，多半是过拟合参数而非数据信号。一套稳健的 TDA 实验，报告里应当包含这条「参数-指标」曲线，而不仅是最好的一组数字——这条曲线本身就是实验可复现性的最好证据。

### 术语速查

| 术语 | 一句话定义 |
| --- | --- |
| 预处理 | 去噪、归一化、采样，决定可分辨特征的尺度下限 |
| 过滤 | 尺度或密度驱动的嵌套复形列 |
| 向量化 | 把持续图转成固定长度特征向量 |
| Betti 曲线 | $\beta_k^r$ 随半径 $r$ 变化的曲线 |
| 持续熵 | 寿命分布归一化后的香农熵，一个数概括图的复杂度 |
| Takens 嵌入 | 延迟坐标重建状态空间，使时序拓扑化 |

## 6 小结

- 管线四步：**预处理 → 建过滤 → 持续同调 → 向量化**，任何一环的旋钮都影响下游。
- 特征可信的三个信号：**寿命长、离对角线远、扰动可重复**；比较比绝对值更可信。
- 经典应用：**形状分类**（环/空腔描述子）与 **Takens 嵌入时序分析**（周期→环）。
- **持续熵**把图压成一个数：分布均匀则熵高，少数长寿特征主导则熵低。
- 高频坑：尺度未归一化、参数不扰动、把采样当流形、忽略 $H_0$。
