# 持续同调

<div class="epigraph">
<p>拓扑学的力量在于把局部几何信息组织成全局形状，而持续同调把这种组织从单一尺度推广到所有尺度。</p>

## 为什么从持续同调开始

前三篇都在「固定一个尺度 r」下做事。但真实数据的正确尺度是未知的：r 太小，点云还是一团离散点；r 太大，一切并成一团，形状消失。**持续同调（persistent homology）**解决的正是这个根本困境——它不挑尺度，而是让 r 从 0 连续扫到 ∞，把「每个同调类在哪一刻诞生、在哪一刻消亡」完整记录成一本账。生存得久的特征（如真正的环）穿越了几乎所有尺度，自然比转瞬即逝的噪声更可信。这是 TDA 至今影响力最大的工具，也是后面持续图、距离、算法诸篇的共同舞台。<span class="marginnote">持续同调有两条独立的发明脉络：Edelsbrunner、Letscher 与 Zomorodian 在 2002 年从计算几何角度提出；几乎同时，Barannikov 在俄罗斯用「Morse 复形」给出等价框架，之后 Carlsson 与 Zomorodian 把理论推广到任意系数的代数层面。「持久性」的核心直觉其实更早——对 0 维同调（连通分量），等价于经典的并查集（union-find）合并过程，见第 4 节的 Elder 规则。</span>

## 1 过滤：给复形排时间线

**过滤（filtration）**：一族嵌套的复形

$$
K^0 \subseteq K^1 \subseteq K^2 \subseteq \cdots \subseteq K^m.
$$

对 Rips 与 Čech 复形，过滤自然来自尺度：$K^j = \mathrm{Rips}_{r_j}(P)$，$r_j$ 递增。当 $r$ 增大，新的单形不断加入——先是 1-单形（边），再是 2-单形（面）——每一步都是一个**单纯复形**，且每一步都包含上一步的全部单形。<span class="marginnote">过滤也可以直接由数据函数定义：给每个点配一个「出现时刻」（如密度值），先把高密度的点纳入复形，再逐步加入低密度的点。这就是密度过滤（density filtration），在第七篇点云特征提取中很常用——它把「哪里更重要」编码进过滤本身。</span>

**重点：过滤是持续同调的输入，而单个复形的同调只是过滤的一个横截面**。同一个复形 $K^j$ 出现在众多过滤里，其同调的意义完全不同——过滤才携带「演化」的信息，持续同调正是对演化过程本身取不变量。

### 三种常见过滤对照

| 过滤类型 | 驱动参数 | 典型用途 |
| --- | --- | --- |
| 尺度过滤 | 半径 $r$ 递增 | Rips / Čech 的默认路线 |
| 密度过滤 | 局部密度递减 | 去噪：低密度点最后进入 |
| 子水平集过滤 | 函数值 $f^{-1}(-\infty, a]$ | Morse / 图像数据分析 |

三者的共同结构都是「嵌套复形列」，区别只在驱动参数的语义——这让持续同调成为一整套可复用的「多分辨率望远镜」。

## 2 持续同调群：跨尺度的圈

固定两个时刻 $i \le j$，包含映射 $K^i \hookrightarrow K^j$ 诱导同调群之间的映射 $H_k(K^i) \to H_k(K^j)$。凡在 $K^i$ 中出现的 $k$-圈，在 $K^j$ 中要么继续存在、要么被填成边界而「死亡」。由此定义**持续同调群（persistent homology group）**：

$$
H_k^{i,j} = Z_k(K^i) \big/ \big(B_k(K^j) \cap Z_k(K^i)\big),
$$

其维数 $\beta_k^{i,j}$ 称为**持续 Betti 数（persistent Betti number）**——「在 $K^i$ 里诞生、直到 $K^j$ 还活着的 $k$-维类」的个数。<span class="marginnote">严格说，「同一类从 $K^i$ 活到 $K^j$」需要用 image 描述：$\beta_k^{i,j} = \operatorname{rank}\, \operatorname{im}\big(H_k(K^i) \to H_k(K^j)\big)$。两种定义等价，后者更直白。关键点：持续同调不是「每个时刻的同调」，而是「一个类跨越多个时刻被同一条连续性追踪」。</span>

**持续配对（persistence pair）**：每个同调类有一个诞生时刻 birth 和一个消亡时刻 death，记作有序对 $(b, d)$。比如 $H_1$ 的一个圈在 $r = 1.2$ 时闭上，在 $r = 2.0$ 时被一个 2-单形填掉，就记作 $(1.2, 2.0)$。寿命 $d - b$ 越大，特征越「持久」。永远不死的类记作 $(b, \infty)$。

## 3 读持续性的两件武器

全部配对可以画成两种等价图形：

**条形码（barcode）**：每个类画一条从 $b$ 到 $d$ 的横条，按同调维数分排。$H_0$ 一排、$H_1$ 一排、$H_2$ 一排，直观又紧凑。
- **持续图（persistence diagram）**：把每个 $(b, d)$ 画成平面上的点（$b$ 为横坐标，$d$ 为纵坐标）。长寿命点远离对角线，噪声点紧贴对角线。

**辨析｜易错点：** 持续图上所有点都满足 $b \le d$（只可能出生后才死亡），所以点全部落在对角线 $y = x$ 上方或对角线上。初学者常把「离对角线越远越重要」记反成「离得越近越重要」——正好相反：**寿命 $d - b$ = 点到对角线的竖直距离，距离越大越持久**。<span class="marginnote">持续图是下一篇的主题，那里会正式引入两种距离（Bottleneck 与 Wasserstein），并给出「持续同调对噪声稳定」的定量陈述。眼下只需建立直觉：barcode 是「直方图版本」，持续图是「散点图版本」，信息完全一样。</span>

### 方形四点：一个能直接读的条形码

取单位圆上等距分布的 4 个点 $p_0, p_1, p_2, p_3$（正方形的四个顶点），跑 Rips 过滤。相邻顶点距离为 $\sqrt{2}$，对角距离为 $2$：

- $r < \sqrt{2}$：四条边都还没出现，$H_0$ 有四条 $\infty$ 条，$H_1$ 为空；
- $r = \sqrt{2}$：四条边同时出现，四边形的环闭上——$H_1$ 的第一个类**出生**于 $r = \sqrt{2}$；$H_0$ 也在这条时刻两两合并，只剩一条；
- $r = 2$：两条对角线出现，正方形被两个三角形填实，$H_1$ 的类**死亡**于 $r = 2$。

于是条形码上 $H_1$ 只有一根横条 $(\sqrt{2}, 2)$，寿命 $\approx 0.59$；$H_0$ 有四条，三条短（合并事件）、一条 $\infty$。换成「圆上随机 200 点」，同样的 $H_1$ 长条依然出现——**长条 = 真实的圆环结构，短条 = 噪声**。这就是持续同调最朴素的用法：数长条，不数短条。

## 4 公式解析：$H_k^{i,j} = Z_k(K^i) \big/ \big(B_k(K^j) \cap Z_k(K^i)\big)$

这个公式比单尺度同调多了一层时间，拆成三步：

**第一步，分子 $Z_k(K^i)$**：$K^i$ 时刻的所有 $k$-圈。分子把「调查范围」限定在出生时刻 $i$——只统计在 $i$ 之前就已出现的类。
- **第二步，分母 $B_k(K^j) \cap Z_k(K^i)$**：$K^j$ 时刻的 $k$-边界中，恰好也是 $K^i$ 的圈的那些。它们曾经是圈，但到 $j$ 时已被填掉——所以从分子中商掉。分子没被商掉的部分，就是「从 $i$ 活到 $j$」的类。
- **第三步，为什么这样能数寿命**：对固定的类，从 $i = $ birth 到 $j = $ death 之前，它一直在 $\beta_k^{i,j}$ 里计数；一旦 $j$ 越过 death，它落入分母，计数归零。于是「寿命」被编码进了「$\beta_k^{i,j}$ 何时归零」。

## 5 零维情形：Elder 规则

$H_0$（连通分量）有一个漂亮的组合化定理，也是工程实现的地基。过滤里每加入一条边，至多把两个分量连成一个。

**Elder 规则（Elder rule）**：当两个连通分量合并时，**出生较晚的那个消亡，出生较早的那个存活**。<span class="marginnote">直觉：较早出现的分量已经「证明了自己」，拥有更多历史；较晚的则被并入。这恰好就是并查集（union-find）数据结构在做的事——每个分量维护一个「出生时间」，合并时总是让出生更早的代表存活。因此 0 维持续同调可以在近线性时间内对任意规模点云算完。</span>

Elder 规则给出 0 维条形码的完整算法：按出现时刻扫描单形，维护并查集，合并时记录死亡配对。它在工程上几乎是免费的——这也是为什么 TDA 管线里 0 维结果最稳定、最可靠。

用一个具体过滤把配对「看见」：四个点 $p_0, p_1, p_2, p_3$ 在 $r = 0.1$ 时仍是四个孤立点，$H_0$ 有四条 $\infty$ 条；$r = 0.5$ 时边 $p_0p_1$ 出现，$p_1$ 并入 $p_0$（配对 $(0.1, 0.5)$）；$r = 0.6$ 时边 $p_0p_2$ 出现，$p_2$ 并入（配对 $(0.1, 0.6)$）；$r = 0.7$ 时边 $p_1p_2$ 出现，但此时 $p_1, p_2$ 已在同一分量，这条边不产生新配对；$r = 1.0$ 时边 $p_0p_3$ 出现，$p_3$ 并入（配对 $(0.1, 1.0)$）。最后 $p_0$ 幸存为唯一 $\infty$ 条——四条 $H_0$ 条的寿命分别为 $\infty, 0.4, 0.5, 0.9$，恰好反映「谁最晚被并入谁最孤立」。

## 6 持续同调为何「稳」

持续同调最重要的理论支撑是**稳定性定理（Stability Theorem）**：数据的微小扰动只会引起持续图的微小移动。定量地说，两个函数 $f, g$ 的持续图之间的 Bottleneck 距离，不超过 $f$ 与 $g$ 的最大逐点差：

$$
d_B\big(Dgm(f), Dgm(g)\big) \le \|f - g\|_\infty.
$$

这条定理在第六篇《Bottleneck 与 Wasserstein 距离》正式证明。它回答了 TDA 最常被质疑的问题——「你的结论对测量噪声敏感吗？」——答案：**不敏感，至少在同调意义下是 Lipschitz 连续的**。这使持续同调从「漂亮理论」升级为「可信任的统计工具」。

工程上有一个配套的经验提醒：过滤的**步长**（$r$ 的采样密度）也要纳入稳定性考量——步长太粗会漏掉两个临界事件之间的演化，等价于给持续图叠加一个量级的抖动。选步长时先跑一遍粗过滤看寿命分布，再在最活跃的尺度段加密。

## 7 小结

- **过滤**：嵌套复形列 $K^0 \subseteq \cdots \subseteq K^m$，由尺度或密度驱动，是持续同调的输入。
- **持续同调群** $H_k^{i,j}$：追踪「出生在 $i$、活到 $j$」的同调类；配对 $(b, d)$ 记录每类的生死。
- **两种画法**：条形码与持续图，信息等价；寿命 = 离对角线的距离。
- **Elder 规则**：0 维合并时，老的分量赢、新的死——等价于并查集，可近线性实现。
- **稳定性**：持续图随数据扰动 Lipschitz 连续变化，这是 TDA 可信性的基石。
