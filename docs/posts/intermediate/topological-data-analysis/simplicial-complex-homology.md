## 为什么从单纯复形开始

拓扑数据分析（TDA）的全部工程起点，是把「形状」变成「可计算的有限对象」。连续空间有无穷多个点，计算机不可能逐个处理；但如果我们同意用一个由**三角形、边、顶点**拼成的骨架来近似形状，一切就变得可算。**单纯复形（simplicial complex）**正是这套骨架的正式名称，而**同调（homology）**是刻在骨架上的「计数器」——它把「有没有洞」「洞有多少个」翻译成向量空间的维数。这一篇先立起这两个概念，下一篇再用 Betti 数与 Euler 特征给出第一个定量结论。<span class="marginnote">这套「有限骨架 + 代数不变量」的路线是庞加莱 1895 年开创的，他称之为 Analysis Situs（位置分析）。严格地说，同调不变量属于单纯复形，但它们在空间同胚下保持不变，所以对空间同样有效——这就是「组合拓扑」这一名称的由来。</span>

## 1 单形：从点到四面体

**单形（simplex）**是单纯复形的建材。取 $k+1$ 个仿射无关的点 $v_0, v_1, \dots, v_k$，它们的凸包就是一个 **k-单形（k-simplex）**：

**0-单形**：一个点 $[v_0]$；
- **1-单形**：一条线段 $[v_0 v_1]$；
- **2-单形**：一个三角形 $[v_0 v_1 v_2]$；
- **3-单形**：一个四面体 $[v_0 v_1 v_2 v_3]$。

各维单形的「分量」可以汇总成一张速查表：

| 单形 | 顶点数 | 边界由几个面构成 | 几何直觉 |
| --- | --- | --- | --- |
| 0-单形 $[v_0]$ | 1 | 空 | 一个点 |
| 1-单形 $[v_0 v_1]$ | 2 | 1（两个端点） | 一条线段 |
| 2-单形 $[v_0 v_1 v_2]$ | 3 | 3（三条边） | 一个三角形 |
| 3-单形 $[v_0 v_1 v_2 v_3]$ | 4 | 4（四个面） | 一个四面体 |

规律一望即知：**$k$-单形的边界由 $k+1$ 个 $(k-1)$-单形构成**，对应边界算子里「删掉每一个顶点」的 $k+1$ 项。这张表是后面一切数字计算的基础，值得先背下来。

单形的**面（face）**，是它顶点的任意子集张成的低维单形。<span class="marginnote">注意「面」不只是三角形的那种二维面：一条边的两个端点、一个三角形的三条边和三个顶点，都是它的面。所有真面合起来称为边界，这正是下一节边界算子的直观来源。</span>把单形当建材，按两条规则粘起来，就得到单纯复形：

**单纯复形（simplicial complex）** $K$：一族有限单形，满足两条公理——**闭包性**：$K$ 中任意单形的所有面仍在 $K$ 中；**交性**：$K$ 中任意两个单形的交，是它们各自的一个面（或空）。

**辨析｜易错点：** 交性是最容易被忽略的一条。下图「两个三角形共享一条边的中点」之所以不行，是因为中点不是整条边的面——两个单形只能整面共享，不能「半个面共享」。这是单纯复形与一般 CW 复形、Delta 复形的关键区别：后者允许更松的粘合方式。

<span class="marginnote">单纯复形有两种写法。上面定义的是<strong>几何单纯复形</strong>（点带坐标，存在具体的欧氏空间里）；如果把每个单形只当作顶点的集合、只保留「子集包含」关系，就叫<strong>抽象单纯复形（abstract simplicial complex）</strong>。数据科学里用的几乎都是抽象版本，见第三篇《Vietoris-Rips 与 Čech 复形》。</span>

## 2 链群与边界算子

现在给骨架装上代数。选定一个域 $\mathbb{F}$（通常取 $\mathbb{Z}_2$ 或 $\mathbb{Q}$），以 $K$ 的所有 $k$-单形为基张成向量空间 $C_k(K)$，其中的元素叫 **k-链（k-chain）**——直观上就是「若干 $k$-单形的（加权）组合」。<span class="marginnote">取系数域 $\mathbb{Z}_2$ 有个好处：系数只有 0 和 1，链就是「单形的子集」，同调变成纯组合问题。代价是丢失方向信息——$\mathbb{Z}_2$ 同调无法区分「绕洞的方向」。具体用哪个域，由后面持续同调一节再讨论。</span>

链与链之间由**边界算子（boundary operator）**连接。对定向的 $k$-单形 $[v_0 v_1 \cdots v_k]$，

$$
\partial_k[v_0 v_1 \cdots v_k] = \sum_{i=0}^{k} (-1)^i\,[v_0 \cdots \hat{v}_i \cdots v_k],
$$

其中 $\hat{v}_i$ 表示去掉顶点 $v_i$。用线性的方式推广到整个 $C_k$，得到 $\partial_k : C_k(K) \to C_{k-1}(K)$。例如三角形的边界：

$$\partial_2[v_0 v_1 v_2] = [v_1 v_2] - [v_0 v_2] + [v_0 v_1].$$

**重点：边界算子的核心性质是「边界的边界是空的」，即 $\partial_{k-1} \circ \partial_k = 0$**。对一个三角形先取边、再对每条边取端点，每条顶点恰好出现两次且正负抵消，总和为零。这一条恒等式是整个同调理论的发动机——它保证后面的商空间有意义。

## 3 同调群：用商空间数洞

由 $\partial^2 = 0$ 可以推出 $\operatorname{im}\partial_{k+1} \subseteq \ker\partial_k$，即「边界」是「圈」的子集。于是可以定义：

- **k-圈（k-cycle）** $Z_k = \ker\partial_k$：边界为零的 $k$-链，闭合成一个「封闭的 $k$ 维回路」；
- **k-边界（k-boundary）** $B_k = \operatorname{im}\partial_{k+1}$：本身就是某个 $(k+1)$-链的边界，即「能填成 $(k+1)$ 维实体的 $k$-圈」。

圈有两种：能填的（边界）和不能填的（**真正的洞**）。同调群就把这两者区分开：

$$
H_k(K) = Z_k / B_k = \ker\partial_k / \operatorname{im}\partial_{k+1}.
$$

**k-同调群（k-th homology group）**的直观含义：$H_k$ 的维数 $\dim H_k$，等于「$k$ 维洞」的个数。$H_0$ 数**连通分支**，$H_1$ 数**一维洞**（圆环孔），$H_2$ 数**空腔**（球壳内的空洞）。

**辨析｜易错点：** 初学者常把「圈」与「洞」混为一谈。实际上**圈总是存在的**——一个正方形边界就是一个圈；它是不是洞，取决于复形里**有没有三角形把它填上**。填上了，它在同调里等于零（是边界）；没填上，它就是 $H_1$ 里的非零元。同调不是「圈有多大」，而是「圈能不能被填」——这是持续同调里「生死对」直觉的总根源。

## 4 公式解析：$\partial_k[v_0 v_1 \cdots v_k] = \sum_{i=0}^{k} (-1)^i\,[v_0 \cdots \hat{v}_i \cdots v_k]$

这条边界公式看着啰嗦，拆开其实只有三步：

- **第一步，认清单形**：$k$-单形由 $k+1$ 个有序顶点 $[v_0, v_1, \dots, v_k]$ 决定。括号里顶点顺序代表**定向**：$[v_0 v_1]$ 与 $[v_1 v_0]$ 相差一个符号。
- **第二步，看求和**：对每个 $i$，把顶点 $v_i$ 删掉，剩下的 $k$ 个顶点给出一个 $(k-1)$-单形 $[v_0 \cdots \hat{v}_i \cdots v_k]$。所以 $k$-单形的边界由 $k+1$ 个面拼成——三角形有 3 条边，四面体有 4 个面，一一对应。
- **第三步，理解符号 $(-1)^i$**：符号保证「公共面在相邻两个单形里方向相反」，这样相邻单形共面处的边界互相抵消。这正是 $\partial^2 = 0$ 能成立的原因，也正是圈与边界能区分的前提。若取 $\mathbb{Z}_2$ 系数，$(-1)^i$ 与 $+1$ 等价，公式退化成「去掉每个顶点」的纯组合规则。

## 5 为什么同调是可计算的

同调的价值在于它把连续问题彻底离散化了。选定 $\mathbb{F}$ 后，$\partial_k$ 是一个**矩阵**（行是 $(k-1)$-单形，列是 $k$-单形，第 $i$ 列是第 $i$ 个单形的边界在基下的坐标）；$Z_k$、$B_k$ 分别是它的**零空间**与**像空间**，维数 $\dim Z_k$、$\dim B_k$ 用行化简即可算出。于是

$$\dim H_k = \dim Z_k - \dim B_k = (\text{$k$-单形数}) - \text{rank}\,\partial_k - \text{rank}\,\partial_{k+1}.$$

矩阵运算是线性代数第一级就会的技能，所以**同调可以在多项式时间内对有限复形算出来**——这就是它能成为数据科学工具的根本原因。<span class="marginnote">「可计算」在世纪初是个大新闻：计算同调的算法（如 incremental algorithm）的核心是高斯消元 + 判别式维护，复杂度对小型复形基本是线性的。第十二篇《持续同调的矩阵化简算法》会把这条计算路线讲透。</span>对照第一级《线性代数》中零空间与秩的语言，这里只是换了场景：几何问题，被翻译成了秩的计算。

拿数字验证一遍。取四面体的边界复形：4 个顶点、6 条边、4 个三角形面（不含实体）。$c_0 = 4, c_1 = 6, c_2 = 4$，于是 $\chi = 4 - 6 + 4 = 2$——与球面的 Euler 特征一致，直觉上四面体边界确实同胚于球面。再算同调：$\beta_0 = 1$（整张边界连通成一块）、$\beta_1 = 0$（每条圈都能被某个三角形面填掉）、$\beta_2 = 1$（闭合曲面围出一个空腔）。$1 - 0 + 1 = 2$，交错和与 $\chi$ 对上了——这枚「数字互相咬合」的例子，正是下一篇 Euler–Poincaré 公式的预习。

### 术语速查

| 术语 | 一句话定义 |
| --- | --- |
| 单纯复形 | 满足闭包性与交性的单形族 |
| 链群 $C_k$ | 以 $k$-单形为基的向量空间 |
| 边界算子 $\partial_k$ | $C_k \to C_{k-1}$，且恒有 $\partial_{k-1}\partial_k = 0$ |
| 圈 $Z_k$ | $\ker\partial_k$：封闭的 $k$ 维回路 |
| 边界 $B_k$ | $\operatorname{im}\partial_{k+1}$：能填成实体的圈 |
| 同调群 $H_k$ | $Z_k / B_k$：圈模去边界，剩下的维数就是洞数 |

## 6 小结

- **单形**：$k$ 个独立点的凸包，是建造空间的建材；**单纯复形**由闭包性与交性两条公理约束。
- **边界算子** $\partial_k$ 把 $k$-链打到 $(k-1)$-链，且**恒有 $\partial_{k-1}\partial_k = 0$**。
- **同调群** $H_k = \ker\partial_k / \operatorname{im}\partial_{k+1}$：圈模去边界，商掉「能填的」，剩下的就是「洞」。
- 用 $\mathbb{Z}_2$ 系数，全部计算退化为纯组合；用域上的矩阵秩，同调即可高效计算。
- $\dim H_0$ 数连通分支，$\dim H_1$ 数一维洞，$\dim H_2$ 数空腔——这正是下一节 Betti 数的来历。

在下一节，我们将给这些维数起正式的名字——**Betti 数**——并证明一个漂亮的恒等式：Euler 特征等于 Betti 数的交错和。这是拓扑不变量第一次给出可验证的数字。
