## 为什么从 Betti 数开始

上一篇我们建立了单纯复形与同调群，但「维数」与「秩」还只是抽象的语言。数据科学要的是**一个数字**：这个形状有几个洞？**Betti 数（Betti number）**就是同调群维数这个数字的正式名字，它把「形状」压缩成一个很短的向量；而 **Euler 特征（Euler characteristic）**比它更古老、更廉价——只靠数三角形、边、顶点就能算。这一篇把这两个量讲透，你会发现一个惊人的恒等式把它们连在一起：$\chi = \beta_0 - \beta_1 + \beta_2 - \cdots$。<span class="marginnote">Betti 数得名于意大利数学家恩里科 · 贝蒂（Enrico Betti），他在 1871 年首次定义了「高阶连通性」；庞加莱后来用他自己的同调理论重新严格化了这个概念。Euler 特征的历史更久：1750 年欧拉发现多面体公式 V − E + F = 2，这其实是 Euler 特征在球面上的特例。</span>

## 1 Betti 数：数洞的向量

**k-阶 Betti 数（k-th Betti number）**定义为第 $k$ 个同调群的维数：

$$\beta_k = \dim H_k(K).$$

每个 $\beta_k$ 都有明确的几何含义——**$\beta_0$ 数连通分量，$\beta_1$ 数「隧道」或一维洞，$\beta_2$ 数「空腔」**：

| 空间 | $\beta_0$ | $\beta_1$ | $\beta_2$ | 解读 |
| --- | --- | --- | --- | --- |
| 圆 $S^1$ | 1 | 1 | 0 | 一个连通块，一个洞 |
| 圆盘 $D^2$ | 1 | 0 | 0 | 洞被填掉了 |
| 环面 $S^1\times S^1$ | 1 | 2 | 1 | 两个独立隧道，一个空腔 |
| 球面 $S^2$ | 1 | 0 | 1 | 没有隧道，有一个空腔 |
| 实心球 $B^3$ | 1 | 0 | 0 | 空腔也被填掉了 |

把 $\beta_k$ 排成序列 $(\beta_0, \beta_1, \beta_2, \dots)$，就得到一个「形状指纹」：<span class="marginnote">环面 $\beta_1 = 2$ 是一个经典直觉陷阱：环面看起来只有「中间一个大孔」，为什么有两个洞？因为一维洞对应的是<strong>独立的一维回路</strong>——一个是绕「赤道」的圈，一个是绕「经线」（穿过孔的圈），它们互相独立、不能由一个填成另一个。这就是「隧道」这个叫法的来源。</span>圆 $(1,1,0,\dots)$、环面 $(1,2,1,0,\dots)$、球面 $(1,0,1,0,\dots)$。两个形状的 Betti 序列不同，它们就**不可能同胚**——这是最廉价的「形状判伪」工具。

在数据科学里，Betti 序列常被当作「廉价的第一特征」：它只有几个整数，却能快速区分形状族——圆、环面、球面对应互不相同的序列。许多 TDA 管线先拿它做粗筛，只对少数可疑对象再跑完整的持续同调，因为后者的计算成本高一个量级。这就是「先数洞，再深挖」的两段式习惯。

Betti 序列还可以做「寿命加权」：把每个配对的贡献乘上它的寿命 $d - b$，得到寿命加权的曲线——它比裸 Betti 数更抗噪，因为短命特征被自动压低。这是第七篇特征提取的前奏，先记住一句：**裸 Betti 数管「有没有」，寿命加权管「多牢靠」**。

## 2 Euler 特征：数单形就够

Euler 特征的定义完全不涉及同调，只需要数 $k$-单形的个数 $c_k = |K_k|$：

$$
\chi(K) = c_0 - c_1 + c_2 - c_3 + \cdots = \sum_{k \geq 0} (-1)^k c_k.
$$

它操作起来极其便宜：对圆（1 顶点 1 边）$\chi = 1 - 1 = 0$；对三角形边界的复形（3 顶点 3 边）$\chi = 3 - 3 = 0$；对实心三角形（3 顶点 3 边 1 面）$\chi = 1$。你几乎可以在脑子里直接算出来。

拿一个剖分算例确认：取正方形，画两条对角线把它分成 4 个三角形。顶点 5 个（四个角加中心交点）、边 8 条（四条外边加四条被交点分开的对角线段）、面 4 个，$\chi = 5 - 8 + 4 = 1$。再把每个三角形细分成 4 个小三角形：顶点 13、边 28、面 16，$\chi = 13 - 28 + 16 = 1$——单形的个数全变了，交错和纹丝不动。这就是「拓扑不变量」最直白的体验：**数字在变，差值不变**。

**重点：Euler 特征在复形细分（subdivision）下不变**。把一个三角形剖成四个小三角形，$c_0, c_1, c_2$ 都变了，但 $\chi$ 不变。这正是它配得上「拓扑不变量」之名的原因——它不依赖具体的剖分方式。<span class="marginnote">欧拉多面体公式 V − E + F = 2 正是这个不变性在凸多面体上的体现：任意凸多面体，顶点减边加面恒等于 2。把多面体沿面三角化并摊平，就得到球面的三角剖分，$\chi = 2$。</span>

再算一个三维的例子确认边界情况。取一个实心四面体：顶点 4 个、边 6 条、面 4 个、3-单形 1 个，$\chi = 4 - 6 + 4 - 1 = 1$——与它可缩（同伦于一个点）一致。若只取四面体的表面（球面的三角剖分）：$c_0 = 4, c_1 = 6, c_2 = 4$，$\chi = 4 - 6 + 4 = 2$，正是球面。同一个几何体，「实心」与「表面」的 $\chi$ 相差 1，因为差了一整层的 3-单形。这个「填满一层，$\chi$ 减一」的直觉在点云的空腔检测里非常有用：空腔的边界是球面（$\chi = 2$），把它填实就变成实心（$\chi = 1$）。

把同样的数数搬到数据上：对 $n$ 个点采样，Rips 复形在不同半径 $r$ 下各做一次计数，连成 $\chi(r)$ 曲线。以 100 个点均匀分布在半径为 1 的圆上为例：$r$ 很小时 $c_0 = 100, c_1 = 0$，$\chi = 100$；$r$ 增大到边逐渐连上，$c_1$ 迅速增加，$\chi$ 一路下降；$r$ 再增大，面把环填掉，$\chi$ 降到 1 后保持稳定。曲线的谷值与平台期对应形状的层次——这条曲线就是第七篇「Euler 特征曲线」的雏形，也是持续同调算不动时的廉价替代。

## 3 Euler–Poincaré 定理：连接两座山

两个量——一个靠数单形、一个靠算同调——看似风马牛不相及，但它们是同一个数的两种算法：

$$
\chi(K) = \sum_{k \geq 0} (-1)^k c_k = \sum_{k \geq 0} (-1)^k \beta_k.
$$

**Euler–Poincaré 公式**：Euler 特征等于 Betti 数的交错和。它的证明用线性代数第一级的内容就能讲完：把 $\partial_k$ 看成矩阵，$c_k = \dim C_k = \dim Z_k + \dim B_{k-1}$（秩-零化度定理），代入求和后 $\dim Z_k$ 与 $\dim B_{k-1}$ 互相抵消，最后只剩 $\sum_k (-1)^k (\dim Z_k - \dim B_k) = \sum_k (-1)^k \beta_k$。<span class="marginnote">这个恒等式还有一个重要的推论：$\chi$ 不依赖同调取哪个系数域（$\mathbb{Z}_2$ 或 $\mathbb{Q}$ 都一样），而单个 $\beta_k$ 会因系数不同而不同——因为存在「挠」（torsion）现象。这一点在下一节「辨析」里细说。推论的另一面是：知道 $\chi$ 不等于知道 Betti 数——环面与「两个互相粘起来的环面环」可以 $\beta_0,\beta_2$ 相同，靠 $\beta_1$ 才区分开。</span>

在最小的例子上验算一遍：圆 $S^1$ 有 $c_0 = 1, c_1 = 1$，$\chi = 0$；而 $\beta_0 = 1, \beta_1 = 1$，交错和 $\beta_0 - \beta_1 = 0$，两边相等。再看环面，用它的 CW 结构 $c_0 = 1, c_1 = 2, c_2 = 1$，$\chi = 1 - 2 + 1 = 0$；Betti 侧 $1 - 2 + 1 = 0$。两个世界永远对得上——这不是巧合，而是同一条恒等式在起作用。

## 4 公式解析：$\chi(K) = \sum_{k \geq 0} (-1)^k c_k = \sum_{k \geq 0} (-1)^k \beta_k$

这条双等号是本节的心脏，分三步理解：

**第一步，$c_k$ 是什么**：$c_k$ 是复形中 $k$-单形的个数，只需对骨架做一次计数。它对三角剖分方式敏感——细分会改变 $c_0,c_1,c_2$——但交错和抵消了这种依赖。
- **第二步，为什么是交错和 $(-1)^k$**：$k$-单形的面由 $(k+1)$-维单形共享，交错符号恰好让「每个顶点、每条边、每个面」在计数中净贡献一致。这是上一节边界算子 $(-1)^i$ 符号在宏观层面的回声。
- **第三步，等号成立的理由**：$c_k = \dim Z_k + \dim B_{k-1}$ 来自秩-零化度；代入 $\chi$ 后，除了 $\dim Z_k$ 与 $\dim B_k$ 的差，其余项全部两两相消，而 $\dim Z_k - \dim B_k = \beta_k$。于是「数单形」与「算同调」殊途同归。

## 5 辨析：系数与挠

**辨析｜易错点：** Betti 数是「在某个系数域上的维数」，不同系数会给出不同答案。最经典的例子是射影平面 $\mathbb{RP}^2$：它的 $\beta_1 = 0$（在 $\mathbb{Q}$ 上），却存在一条「转两圈才是零」的圈。这条圈在 $\mathbb{Z}_2$ 系数下是零同调的，于是 $\dim_{\mathbb{Z}_2} H_1(\mathbb{RP}^2) = 1$。这类现象称为**挠（torsion）**，它藏在整数系数同调的 $\mathbb{Z}/2$ 直和项里，用域系数算同调时会被无视。<span class="marginnote">TDA 的多数应用都取 $\mathbb{Z}_2$ 系数：理由很实际——无需定向、矩阵化简最快、且点云数据中挠结构极少见。代价是我们主动放弃了检测挠的能力，换来全部计算可并行、可简化。这是一个「精度换速度」的工程决策，不是数学必需。</span>

这也解释了为什么 Euler 特征在 TDA 中仍有位置：**它不依赖系数**，因此是最鲁棒、最便宜的「形状汇总」。在实践中，Euler 特征曲线（沿尺度轴逐帧算 $\chi$）常被用作特征的快速近似，见第七篇《点云数据的拓扑特征提取》。它不需要解任何方程组，只需对每一帧复形做一次单形计数——在点云规模巨大、持续同调算不动时，这条曲线往往是性价比最高的退路。

### 常用空间的 $\chi$ 速查

| 空间 | $\chi$ | Betti 序列 |
| --- | --- | --- |
| 圆 $S^1$ | 0 | $(1, 1, 0, \dots)$ |
| 圆盘 $D^2$ | 1 | $(1, 0, 0, \dots)$ |
| 球面 $S^2$ | 2 | $(1, 0, 1, 0, \dots)$ |
| 环面 $T^2$ | 0 | $(1, 2, 1, 0, \dots)$ |
| 射影平面 $\mathbb{RP}^2$ | 1 | $\mathbb{Z}_2$ 下 $(1, 1, 1, 0, \dots)$ |

这张表把本篇的结论压缩成几行：$\chi$ 与 Betti 序列互相印证，而 $\mathbb{RP}^2$ 一行提醒我们——**系数换了，$\beta_1$ 就从 0 变 1**，这正是挠的现场。手工速算时只需三步：先数清顶点、边、面的个数，再交替加减，最后换个剖分重算一遍确认结果不变。

把这套速算用到数据上：给定点云，Rips 复形在某个半径下的 $\chi$ 可以这样手算——先数顶点数 $n$，再数边长（或交给程序），面数按三角剖分计。例如 10 个点完全连接（完全图）时 $c_0 = 10$、$c_1 = 45$，若暂不填面，$\chi = 10 - 45 = -35$。负数完全正常，不必惊讶——$\chi$ 可以是任意整数，关键是它在不同半径之间**怎么变**。正因为 $\chi$ 便宜（只做三次计数），它才被广泛用于点云规模巨大时的粗筛：先扫 $\chi(r)$ 曲线锁定关键半径区间，再只对那些区间跑完整的持续同调，把昂贵的计算留给值得的地方。

### 术语速查

| 术语 | 一句话定义 |
| --- | --- |
| Betti 数 | $\beta_k = \dim H_k$，第 $k$ 个同调群的维数 |
| Euler 特征 | $\chi = \sum_k (-1)^k c_k$，单形个数的交错和 |
| 细分 | 把单形再剖开，不改变 $\chi$ |
| 挠 | 域系数下看不见的扭转结构，藏在整数系数的直和项里 |
| 拓扑不变量 | 同胚不变的量，可用于「判伪」但一般不能「判定」 |

回到射影平面收尾：$\mathbb{RP}^2$ 在 $\mathbb{Z}_2$ 下的 Betti 序列是 $(1,1,1)$，交错和 $1-1+1 = 1$，恰好等于 $\chi$；同一个空间在 $\mathbb{Q}$ 下 $\beta_1 = 0$，非可定向又使 $\beta_2 = 0$，序列 $(1,0,0)$，交错和仍是 $1-0+0 = 1$。两套序列完全不同，$\chi$ 却纹丝不动——这是「$\chi$ 与系数无关」最漂亮的一次现场演示。

## 6 小结

- **Betti 数** $\beta_k = \dim H_k$：$\beta_0$ 数连通块，$\beta_1$ 数隧道，$\beta_2$ 数空腔；序列 $(1,2,1)$ 认出一个环面。
- **Euler 特征** $\chi = \sum_k (-1)^k c_k$：只需数单形个数，在细分下不变。
- **Euler–Poincaré 公式** $\chi = \sum_k (-1)^k \beta_k$：把「计数」与「同调」两个世界用一条恒等式缝合。
- $\chi$ 与系数无关，而单个 $\beta_k$ 依赖系数；$\mathbb{Z}_2$ 是 TDA 的默认选择。
- 两个量都是拓扑不变量，都可判伪「不同形状不可能同胚」，但都不能完全判定同胚（是「必要不充分」）。

在下一节，我们将回答第一篇留下的问题：面对**离散的点云**，怎样把它建成单纯复形？这就是 **Vietoris–Rips 与 Čech 复形**——TDA 正式从数学走进数据。
