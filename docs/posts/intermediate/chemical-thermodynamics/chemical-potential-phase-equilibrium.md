## 为什么需要化学势

我们有了能量（第一定律）、有了方向判据（第二定律），
但还缺一个**「往哪个方向变」的指示器**。
熵判据只对孤立体系好用；实际化学反应大多在恒温恒压、
与外界交换能量的开放环境中发生，体系的熵并不能独自决定方向。<span class="marginnote">吉布斯在 1876—1878 年的《论多相物质的平衡》中提出：真正的方向判据要同时照顾「体系」与「环境」。他把熵判据改造为适用于恒温恒压条件的判据，并由此定义了化学势——他称之为「势能」（potential），与电学的电势、力学的引力势类比。</span>这个「往哪个方向变」的指示器，就是**吉布斯自由能**，而它对每个组分的「微分形式」——**化学势**，将成为相平衡、溶液、化学平衡、电化学全部章节的通用语言。

## 1 吉布斯自由能：恒温恒压下的方向判据

定义**吉布斯自由能（Gibbs energy）**：

$$G = H - TS$$

对恒温恒压、只做体积功的封闭体系，第二定律给出：**自发过程要求 $G$ 减少，平衡时 $G$ 达到极小**。数学上：

$$\Delta G < 0 \ \text{自发}, \qquad \Delta G = 0 \ \text{平衡}$$

为什么「减 $TS$」就行？因为 $G$ 的减少已经暗中把环境的熵增算进去了——体系放热给环境（$H$ 减少）和环境获得熵这两笔账，被一起折进了 $G$ 这一个函数里。<span class="marginnote">把 $G$ 与焓的配方对照看：$H = U + pV$ 是为恒压过程「配」出的守恒量，$G = H - TS$ 是为恒温恒压自发方向「配」出的判据。热力学的历史几乎就是一连串「为特定约束条件配一个合适的势」的历史。</span>恒温恒压下，「$G$ 减小」是方向的主宰；$G$ 对物质的量再求导，就得到化学势。

## 2 化学势的定义

**化学势（chemical potential）$\mu$**：在恒温、恒压下，加入 1 mol 组分 $i$ 时体系吉布斯自由能的增量：

$$\mu_i = \left(\frac{\partial G}{\partial n_i}\right)_{T, p, n_{j\neq i}}$$

**化学势是「推动物质迁移」的势**。一杯溶液里溶质会从高浓度扩散到低浓度，直到各处化学势相等——正如电荷从高电势流向低电势。因此化学势给出一个普适的平衡条件：

$$\mu_i^{\alpha} = \mu_i^{\beta}$$

**同一组分在两个相中化学势相等，就是两相平衡的判据**。这也是后面相平衡、溶液、化学平衡统一的判据——任何「东西该往哪跑」的问题，都可以翻译成「谁的化学势高，谁就在损失物质」。

## 3 温度、压强对化学势的影响

化学势对温度与压强的偏导数有明确的物理含义：

$$\left(\frac{\partial \mu_i}{\partial T}\right)_p = -S_{m,i}, \qquad \left(\frac{\partial \mu_i}{\partial p}\right)_T = V_{m,i}$$

第一条说：熵越大（越无序）的物质，其化学势随温度上升下降得越狠；第二条说：体积越大，化学势随压强上升涨得越快。<span class="marginnote">这两条偏导来自「麦克斯韦关系」：$(\partial \mu/\partial T)_p = -S_m$ 即 $(\partial G/\partial T)_p = -S$，而 $(\partial G/\partial p)_T = V$。它们的价值在于：温度、压强的数据（热容、体积、焓）可以被翻译成化学势的变化——这就是后面算平衡移动方向的工具。</span>由这两条，可以导出**化学势随压强的积分关系**：

$$\mu(p_2) = \mu(p_1) + \int_{p_1}^{p_2} V_m\,\mathrm{d}p$$

对理想气体 $V_m = RT/p$，于是化学势与分压成对数关系：

$$\mu = \mu^{\ominus} + RT\ln\frac{p}{p^{\ominus}}$$

**「对数」开始登场的这一刻，是整个化学热力学运算的枢纽**：它让压强、浓度、活度可以指数式地影响化学势，也让后面的平衡常数、能斯特方程都长成「对数」的模样。

## 4 相平衡的一般条件与吉布斯相律

把化学势判据应用到多组分多相体系，得到**相平衡条件**：恒温恒压下，每个组分在所有相中的化学势分别相等。系统化之后就是**吉布斯相律（phase rule）**：

$$F = C - P + 2$$

其中 $F$ 是**自由度**（可独立改变的强度变量数），$C$ 是**组分数**，$P$ 是**相数**。<span class="marginnote">相律为什么是「$+2$」？因为强度变量里有两个独立者——温度与压强；在特殊条件下（如恒压相图）它就变成 $F = C - P + 1$。相律第一次让「一张图里可以画几条曲线、几个区、几个点」这件事可以事先数出来——纯水的相图有三个单相区、三条边界线、一个三相点，都由 $F = 1 - P + 2$ 精确给出。</span>相律不告诉我们具体怎么画相图，但精确地告诉你图上能有多少种「花样」，它是《纯物质相变》与《相图》两篇的序章。

## 5 公式解析：$\mu = \mu^{\ominus} + RT \ln(p / p^{\ominus})$

**这条公式是化学势「落地」的第一步，也是化学势向一切平衡公式延伸的母版。** 逐步拆解：

$$\mu = \mu^{\ominus} + RT \ln\frac{p}{p^{\ominus}}$$

- **第一步，看懂参考态 $\mu^{\ominus}$**：$\mu^{\ominus}$ 是标准态（分压 $p^{\ominus} = 1\ \mathrm{bar}$）下的化学势，对给定物质是常数。公式把化学势拆成「基准值 + 偏离值」两段。
- **第二步，看懂对数项来源**：$\mathrm{d}\mu = V_m\,\mathrm{d}p = (RT/p)\,\mathrm{d}p$，积分得 $RT\ln(p/p^{\ominus})$。理想气体的 $V_m$ 与 $p$ 成反比，是「积分出对数」的根本原因——只要「势对量的导数 ∝ 1/量」，积分就是对数。
- **第三步，读出单调性**：分压越高，化学势越高。物质永远从 $\mu$ 高的地方向 $\mu$ 低的地方迁移——于是高压端的气体分子会自发流到低压端，这就是扩散的化学势解读。
- **第四步，预告推广**：把 $p/p^{\ominus}$ 换成「活度」$a$，就得到溶液中化学势的表达式 $\mu = \mu^{\ominus} + RT\ln a$；把「$a$ 之比的对数」写成平衡常数 $K$，就得到 $\Delta_r G^{\ominus} = -RT\ln K$。**一条对数式，串起本专题半本书。**

### 辨析｜易错点：判据的适用面与自由度的身份

1. **$\Delta G < 0$ 自发只对「恒温恒压 + 只做体积功」**：恒容场景要用亥姆霍兹能
   $A$，绝热场景用熵判据——判据与约束条件是逐一配对的，别拿 $G$ 到处用。
2. **「$\mu$ 相等」不等于「浓度相等」**：两相里同组分的浓度可以差很多，
   只要 $\mu$ 相等就平衡——分配平衡中溶质在两相的浓度不同，但化学势相同。
3. **相律里的 $C$ 是独立组分数**：有化学平衡约束时要减掉约束数，例如
   $\ce{NH4Cl(s) <=> NH3(g) + HCl(g)}$ 中独立组分数是 1 而非 2。

### 数值算例：水的三相点与相律

对单组分水，相律 $F = C - P + 2 = 3 - P$ 直接给出图的拓扑：

- **单相区** $P = 1 \to F = 2$：$T$、$p$ 两个强度量都可独立改变；
- **共存线** $P = 2 \to F = 1$：给定温度，蒸气压随之确定（这就是
   Clausius-Clapeyron 方程描述的那条线）；
- **三相点** $P = 3 \to F = 0$：$T$、$p$ 全被锁死（$0.01\,^{\circ}\mathrm{C}$、
   $6.1\ \mathrm{mbar}$）。

相律不告诉你点在哪，但告诉你「三相点只能是一个点」——这张 $p$–$T$ 图的
全部拓扑结构，在动手画之前就已被相律固定。

### 历史与延伸：吉布斯与「最简洁的视角」

1876 年吉布斯发表《论多相物质的平衡》，提出化学势与相律，但当时几乎无人
读懂；1892 年奥斯特瓦尔德把文章译成德文后，吉布斯才被世界看见。他的
「势」概念——温度、压强、化学势三种势驱动三种迁移——成为今天统一处理
传热、扩散、相变与反应的语言：本专题过半的公式，都是这三种「势」的小型应用。

## 6 小结

- **吉布斯自由能 $G = H - TS$** 是恒温恒压自发方向的判据：$\Delta G < 0$ 自发、$\Delta G = 0$ 平衡。
- **化学势** $\mu_i = (\partial G/\partial n_i)_{T,p,n_j}$ 是物质迁移的「势」，组分两相化学势相等即相平衡。
- 化学势对 $T$、$p$ 的偏导分别给 $-S_{m,i}$ 与 $V_{m,i}$，由此可积分出 $\mu$ 的压强依赖。
- 理想气体化学势 $\mu = \mu^{\ominus} + RT\ln(p/p^{\ominus})$：对数关系是后续平衡常数与电化学的母版。
- **吉布斯相律** $F = C - P + 2$ 预先告诉一张相图上能有多少区、线、点。

在下一节，我们把「化学势相等」用于液体混合物，回答溶液的第一个基本问题：一杯含溶质的液体，它上方的蒸气压到底是多少？——这就是**理想与实际溶液：Raoult 与 Henry 定律**。
