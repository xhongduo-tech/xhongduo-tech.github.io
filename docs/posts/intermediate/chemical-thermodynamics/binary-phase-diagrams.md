## 为什么从二元相图讲起

纯物质的相图是一条条曲线；真实材料——合金、盐湖、石油、半导体——
几乎都是**混合物**，它们的相行为必须用二维甚至三维的相图来刻画。
上一节我们学会了纯物质的三条共存线，本节把化学势判据与相律
$F = C - P + 2$ 用到二元体系，画出**温度—组成相图**：
它决定了「把 A、B 按某个比例加热到某温度，体系是什么形态、
有几相、各相组成如何」——冶金、化工分离、晶体生长的全部工艺设计
都建立在这张图上。<span class="marginnote">吉布斯相律诞生于 1876 年，但直到 1890 年代 Roozeboom 才把它系统应用到合金与盐类的相图研究。相律的神奇之处在于它不需要知道任何具体化学细节，只凭「组分数、相数」就能预言一张图上能有几条线、几个点——信息论意义上的「先验约束」。</span>

## 1 二元体系的自由度与相图类型

二元体系 $C = 2$，相律给出 $F = 4 - P$：
单相区 $F = 3$（$T$、$p$、组成三个自由度）——常在恒压下画，变成 $T$–$x$ 平面；
两相区 $F = 2$（一条 $T$–$x$ 曲线）；
三相共存 $F = 1$（一个固定温度的水平线）。<span class="marginnote">二元体系里「恒压」是个重要约定：压成常数后自由度减一，相图缩成 $T$–$x$ 平面。冶金大多恒 1 atm，盐湖蒸发恒温恒压看组成——不同约束切出相图的不同截面，读图前先确认「这张图是什么量固定在什么值」。</span>

二元体系相图主要有三大类：**完全互溶固溶体**（一组分连续成固溶体，形状像「梭子」）、**共晶型**（完全互溶液相、互不相溶固相，出现共晶点）、以及**部分互溶 / 化合物型**（出现中间相与共晶混合物）。其中共晶型是理解一切复杂相图的基础，也是本节的主角。

## 2 共晶相图的读法

![二元共晶体系的温度—组成相图](/images/chemical-thermodynamics/binary-eutectic-diagram-1.svg)

以上图为例，读图分四步：

**第一步，认轴线**：横轴是组成 $x_B$（左端纯 A、右端纯 B），纵轴是温度；曲线上方是**液相区**。
- **第二步，认三条关键线**：两条**液相线**（liquidus）从纯组分熔点下降到**共晶点**，液相同此上方；水平**固相线 / 共晶温度线**把两相区与固相区隔开。
- **第三步，分区**：液相线上方「液」；液相线与固相线之间分别是「固溶体 A + 液」「固溶体 B + 液」两个两相区；固相线下方是「固溶体 A + 固溶体 B」两相区。<span class="marginnote">共晶点之所以特殊，是因为在这一点上液相对两种固相同时饱和，冷却到共晶温度时液相一次性析出「A 相 + B 相」的紧密共晶组织——焊锡（Sn-Pb 共晶约 183 °C）、低熔点合金都靠共晶成分获得「整体同时凝固」的工艺优势。</span>
**第四步，用杠杆定则算组成**：对两相区内任意一点，两相的**相对量**
由**杠杆定则（lever rule）**给出：像跷跷板一样，
某一相的份额正比于「整体组成点到另一相端点之间的距离」。
例如在「固溶体 A + 液」区某点，液相分数 $w_l = \dfrac{x_s - x_0}{x_s - x_l}$，
其中 $x_s$、$x_l$ 是固、液两相的边界组成，$x_0$ 是整体组成。<span class="marginnote">杠杆定则是「质量守恒」的几何化：整体组成必须落在两端点之间，距一端越近、那一端的相越多。它不需要任何热力学方程，却支配着所有两相区的定量计算——掌握它，读图就完成了一半。</span>

## 3 恒沸与偏离理想：温度—组成图

上一节讲过真实溶液偏离理想（活度系数 $\gamma_i \neq 1$）。
当正偏差足够强，气液相图会出现**恒沸点（azeotrope）**：
在该组成下，液相与气相的组成相同，沸腾时组成不再变化——
蒸馏无法越过它分离。<span class="marginnote">乙醇—水在约 95.6%（质量分数）乙醇处形成最低恒沸物，蒸出的永远是这个组成的混合物——普通蒸馏造不出无水乙醇。要破除恒沸，需引入第三组分（共沸蒸馏）或变压精馏。恒沸点是「活度偏差」最直接的宏观后果：$p_A$、$p_B$ 都偏离 Raoult 线，总蒸气压出现极值，极值点就是恒沸点。</span>正偏差（$p_A$ 偏高）给出最低恒沸点，负偏差（如硝酸—水）给出最高恒沸点。**恒沸组成与总蒸气压极值一一对应**，这再次说明：相图不是猜出来的，而是活度—组成的直接投影。

## 4 三元相图入门

三元体系 $C = 3$，恒温恒压下 $F = 5 - P$，
相图需要**三角坐标**表示组成（三个顶点分别代表纯 A、B、C）。<span class="marginnote">三角坐标读法：任何一点到三条边的距离分别代表三种组分的摩尔分数，三个分数之和恒为 1。边的平行线与「某组分含量恒定」一一对应——把二维平面上「到三边的距离」编码为三个分量，是「约束 $x_A + x_B + x_C = 1$」的几何实现。</span>三元相图的经典应用是**盐湖蒸发与溶剂萃取**：
盐—水—有机溶剂三相体系里，相的数目与组成由三角相图上的分相区决定；
三元共晶比二元共晶温度更低，
正因如此「冰盐混合物」能降到远低于纯水冰点。<span class="marginnote">三元共晶温度低于任一二元共晶，是相图最常见的考点之一：增加组分数相当于增加了「成分自由度」，体系的自由度增加，共晶点可在更低温度成立——冰盐（NaCl 水溶液共晶约 −21 °C）、冬天撒盐融雪，都是这个原理的日常版本。</span>三元相图的读法完全是二元读法的推广：先认分区，再用「结线（tie line）」连接共存的相组成点，用量（杠杆/重心）定则分配各相的量——工具不变，维度加一。

## 5 公式解析：杠杆定则

**杠杆定则是相图定量计算的万能钥匙，值得用一个具体式子吃透。** 设两相区某点整体组成为 $x_0$，两相端点组成为 $x_\alpha < x_0 < x_\beta$，则：

$$w_\alpha = \frac{x_\beta - x_0}{x_\beta - x_\alpha}, \qquad w_\beta = \frac{x_0 - x_\alpha}{x_\beta - x_\alpha}$$

- **第一步，把式子读成距离**：$w_\alpha$ 是「整体点到 $\beta$ 端的距离」除以「两端距离」，$w_\beta$ 反之。距谁近，谁的量就多——这就是「杠杆」：支点在 $x_0$，力矩平衡。
- **第二步，验证极限**：$x_0 = x_\alpha$ 时 $w_\alpha = 1$、$w_\beta = 0$（整体就是纯 $\alpha$ 相）；$x_0$ 在中点则各一半。两个端点自动给出正确边界，式子没有反直觉的例外。
- **第三步，理解它从哪来**：质量守恒 $x_0 = w_\alpha x_\alpha + w_\beta x_\beta$ 且 $w_\alpha + w_\beta = 1$，两式联立解出上面两个表达式——**杠杆定则就是「质量守恒」的代数变形**。
- **第四步，看懂使用条件**：必须处于**两相区**、且两相组成分别是两端点（由水平结线与相边界相交得到）。三相共存区里要改用「重心定则」——思路相同，约束加一。

### 辨析｜易错点：读图三宗罪

1. **忘了恒压前提**：二元相图通常是一张恒压截面，图上的 $T$–$x$ 关系只在那个
   压强下成立——换压强要换图，不能把 1 atm 的共晶图用到高压工艺上。
2. **把「液相线上方 = 液」当普适**：这只对完全互溶液相成立；有中间化合物、
   部分互溶时相区结构完全不同，读图前先认清体系类型。
3. **杠杆定则用错位置**：它只用于两相区，且两端点由「过整体点的水平结线与
   相边界交点」给出；三相共存（共晶水平线）上要用重心定则。

### 数值算例：Sn–Pb 合金的两相量

设整体组成 $x_0 = 0.5$（Pb 摩尔分数），在固溶体区两相端点 $x_\alpha = 0.2$、
$x_\beta = 0.9$：

$$w_\alpha = \frac{0.9 - 0.5}{0.9 - 0.2} = 0.571, \qquad w_\beta = \frac{0.5 - 0.2}{0.9 - 0.2} = 0.429$$

两种固相各占约 57% 与 43%——离哪端近就富哪端，「杠杆」两字的几何直觉在此
落地。这个数字直接决定合金的显微组织与机械性能，是冶金读图的第一笔账。

### 历史与延伸：从青铜到钢的相图

19 世纪冶金学家靠「淬火—回火」的经验工艺，却说不清钢为何会变硬；1863 年
索比把金属表面抛光腐蚀后在显微镜下看到珠光体组织，相图研究由此起步。
二十世纪铁—碳相图成为人类用得最多的相图：淬火、退火、析出强化全部是
「在相图上走一条冷却路径」。今天电池、半导体材料的配方设计，同样依赖相图。

### 读图工作流：三步法

遇到任意一张二元相图，按固定的三步走，能避开绝大多数误读：

- **第一步，识别体系类型**：完全互溶固溶体、共晶型，还是部分互溶/化合物型？
  看液相线下方的相区结构即可判断——出现水平线（共晶、包晶）就意味着有三相反应。
- **第二步，读单相区与边界**：单相区用字母或汉字标出；两相区边界就是结线的
  端点轨迹——任何水平线交到边界上的点，就是该温度下共存相的实际组成。
- **第三步，在目标点上应用杠杆定则**：先确认点落在两相区，再过点画水平线
  读出两个端点组成，最后按 $w_\alpha = (x_\beta - x_0)/(x_\beta - x_\alpha)$ 求量。
- **收尾检查**：各相分数之和为 1，且所有读数都落在物理意义范围内
  （$0 \le x \le 1$）——自洽性检查是读图不出错的最后一道保险。

这套三步法同样适用于三元相图：维度加一，但「分区 → 定端点 → 求量」的逻辑不变。

## 6 小结

- **二元相图**由相律 $F = 3 - P$（恒压下）决定维度：单相区是面、两相区是线、三相共存是一条水平线。
- **共晶相图**的关键结构：两条液相线、水平固相线、一个共晶点；共晶组成冷却时整体同时凝固。
- **杠杆定则**由质量守恒推出：两相区里各相的量正比于「整体组成到对方端点的距离」。
- **恒沸点**来自活度偏差：总蒸气压极值对应气液同组成，正偏差出最低恒沸、负偏差出最高恒沸。
- **三元相图**用三角坐标，读法推广自二元：分相区、结线、重心定则；三元共晶温度低于二元共晶。
