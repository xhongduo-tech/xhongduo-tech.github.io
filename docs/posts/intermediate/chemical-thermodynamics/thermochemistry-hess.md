## 为什么从热化学讲起

前两节我们建立了焓（第一定律）与平衡常数（化学势），但化学家最常问的问题却朴素得多：**一个反应到底放热还是吸热？放多少？** 回答这个问题的是**热化学（thermochemistry）**——热力学在「测量与计算反应热」上的全部应用。它的主角是**标准摩尔生成焓**与**键焓**，工具是 **Hess 定律**：焓是状态函数，所以反应焓只由初末态决定，可以像代数一样「加减方程式」求未知反应的焓变。<span class="marginnote">1840 年赫斯发表热化学三大定律中的第一条（焓的路径无关性），比焦耳测热功当量还早，也早于第一定律的成熟表述——热化学的许多规律其实是热力学的「先导」。赫斯本人是瑞士裔俄国化学家，在圣彼得堡做了一辈子量热实验。</span>这一节把「量热实验」与「查表计算」两条路接起来，也补上「反应焓随温度怎么变」的最后一块拼图——为化工设计、能源评估、乃至人体代谢估算提供日常工具。

## 1 标准摩尔生成焓

**标准摩尔生成焓 $\Delta_f H^{\ominus}$**：在标准态（1 bar）、指定温度下，由**最稳定的单质**生成 1 mol 该化合物的焓变。规定最稳定单质的 $\Delta_f H^{\ominus} = 0$（例如 $\ce{O2}$、$\ce{C}$（石墨）、$\ce{H2}$ 都取 0）。<span class="marginnote">「最稳定单质为零点」是一条约定而非自然法则：它把焓的零点锚定在元素的标准形态上，让所有化合物的 $\Delta_f H^{\ominus}$ 可以直接查表、直接相减。生成焓越负，化合物相对单质越「稳」——这是「热力学稳定性」的第一个量化指标。</span>查表得到各物质的 $\Delta_f H^{\ominus}$ 后，任何反应的**标准摩尔反应焓**就是「产物生成焓之和减反应物生成焓之和」：

$$\Delta_r H^{\ominus} = \sum_{\text{产物}} \nu_i\,\Delta_f H^{\ominus}_i - \sum_{\text{反应物}} \nu_i\,\Delta_f H^{\ominus}_i$$

例如 $\ce{2H2 + O2 -> 2H2O(l)}$ 的 $\Delta_r H^{\ominus} = 2\times(-285.8) - 0 - 0 = -571.6\ \mathrm{kJ\,mol^{-1}}$——生成焓表让「放热还是吸热」变成一次算术。

## 2 Hess 定律：焓的路径无关性

**Hess 定律（Hess's law）**：反应的焓变与反应进行的路径（经过哪些中间步骤）无关，只由始态与终态决定。它是「$\Delta H$ 是状态函数」的直接推论，也是第一定律 $\Delta U = q + w$ 的恒压版本。<span class="marginnote">Hess 定律的威力在于「组合」：很多反应无法直接量热（太慢、太危险、有副反应），但可以把它们拆成一组可测的子反应，用代数加减求出目标反应焓——就像解方程组。工业上难以实现的反应，热化学照样能精确预报它的焓变。</span>它的操作法则是：目标反应 = 若干已知反应经系数乘除、正反方向拼接而成；目标反应焓也按同样规则由已知反应焓线性组合。<span class="marginnote">一个关键注意点：线性组合的对象是<strong>反应方程式</strong>（连同配平系数与焓变），不是随意代数式。方向反转要改号，系数倍乘要同步倍乘焓变——错一步，全盘皆错，这是热化学计算的头号易错点。</span>用 Hess 定律还能「构造」出实验做不了的反应：例如 $\ce{C(s) + \frac12 O2 -> CO(g)}$（CO 不易纯化、燃烧不完全）可由 $\ce{C -> CO2}$ 与 $\ce{CO -> CO2}$ 两个可测反应相减得出。

## 3 键焓：从分子结构估算反应热

比查生成焓更「分子化」的估算工具是**键焓（bond enthalpy）**：把分子拆成「一根根键」，假设键能可加，则气相反应的焓变约等于「断裂键焓之和减生成键焓之和」：

$$\Delta_r H^{\ominus} \approx \sum_{\text{断键}} \mathrm{BE} - \sum_{\text{成键}} \mathrm{BE}$$

其中 BE 是平均键焓（例如 $\ce{C-H}$ 约 $412\ \mathrm{kJ\,mol^{-1}}$、$\ce{C=C}$ 约 $612$）。<span class="marginnote">键焓是「平均数」而非精确值：同一根 $\ce{C-H}$ 在不同分子里实际强度略有不同，教材数据给出的是平均。所以键焓法用于<strong>估算</strong>（误差可达 $10\ \mathrm{kJ\,mol^{-1}}$ 量级），精算仍以生成焓为准——它最大的价值是「不查表也能粗估反应热」，并给「反应热来源于化学键重组」一个直观模型。</span>键焓法的另一贡献是**预测放热/吸热方向**：生成键越多、键越强（键焓越大），体系越稳、越放热——爆炸物、燃料的设计直觉全部来自这套「拆键—成键」的能量账。

## 4 反应焓随温度变化：Kirchhoff 定律

Hess 定律给的是「同温度下的加减」，但数据表常是 298 K，反应却常在别的温度进行。由 $C_p = (\partial H/\partial T)_p$，反应焓随温度的变化由**Kirchhoff 定律（Kirchhoff's law）**给出：

$$\Delta_r H^{\ominus}(T_2) = \Delta_r H^{\ominus}(T_1) + \int_{T_1}^{T_2} \Delta_r C_p^{\ominus}\,\mathrm{d}T$$

其中 $\Delta_r C_p^{\ominus} = \sum \nu_i C_{p,i}^{\ominus}$ 是反应的热容变化。<span class="marginnote">Kirchhoff 定律是「状态函数 + 热容」的标准套路：既然焓是状态函数，从 $T_1$ 到 $T_2$ 的 $\Delta_r H$ 变化就等于「把反应物升到 $T_2$、反应、再把产物带回来」这条闭合路径的净热容贡献。工程上它把 298 K 的表格数据外推到任意工艺温度——锅炉、反应器、焙烧炉的设计都靠它。</span>若区间内 $\Delta_r C_p^{\ominus}$ 近似常数，简化为 $\Delta_r H^{\ominus}(T_2) \approx \Delta_r H^{\ominus}(T_1) + \Delta_r C_p^{\ominus}(T_2 - T_1)$。<span class="marginnote">一个实用提醒：反应焓对温度的依赖通常远小于焓变本身（$C_p$ 量级 $10^1$–$10^2$，$\Delta_rH$ 量级 $10^3$–$10^5\ \mathrm{J\,mol^{-1}}$），所以粗略估算时常可近似认为 $\Delta_r H^{\ominus}$ 与温度无关——但涉及相变、或温度跨度大时必须用 Kirchhoff 修正。</span>

## 5 公式解析：Hess 定律的组合计算

**Hess 定律的运算规则，用一条完整例子最能说明白。** 目标：求 $\ce{C(s) + \frac12 O2(g) -> CO(g)}$ 的 $\Delta_r H^{\ominus}$。已知：

$$\ce{C(s) + O2(g) -> CO2(g)},\quad \Delta_rH_1^{\ominus} = -393.5\ \mathrm{kJ\,mol^{-1}}$$

$$\ce{CO(g) + \frac12 O2(g) -> CO2(g)},\quad \Delta_rH_2^{\ominus} = -283.0\ \mathrm{kJ\,mol^{-1}}$$

- **第一步，把第二个方程反向**：$\ce{CO2(g) -> CO(g) + \frac12 O2(g)}$，焓变取负号 $+283.0$。方向反转是 Hess 运算最常出错的一步，务必逐项核对化学式。
- **第二步，两式相加并约掉公共项**：两个方程相加，$\ce{CO2}$ 与 $\ce{O2}$ 出现在两侧相同位置，抵消后恰好得到目标方程 $\ce{C(s) + \frac12 O2(g) -> CO(g)}$。
- **第三步，焓变同步相加**：$\Delta_r H^{\ominus} = -393.5 + 283.0 = -110.5\ \mathrm{kJ\,mol^{-1}}$。
- **第四步，检验物理意义**：结果接近由生成焓表查得的一氧化碳 $\Delta_f H^{\ominus} \approx -110.5\ \mathrm{kJ\,mol^{-1}}$——两条独立路径给出同一数字，这正是「焓是状态函数」的实验证词。

### 辨析｜易错点：Hess 运算三处高危

1. **方向反转必须改号**：把已知反应倒过来用，焓变加负号——漏掉这步是
   Hess 计算的第一大事故源。
2. **系数倍乘必须同步**：配平系数乘 2，焓变也乘 2——「反应焓是每摩尔反应的
   量」，系数变，基准就变。
3. **键焓是平均值、只适合估算**：同一根 $\ce{C-H}$ 在不同分子里强度不同，
   键焓法误差可达 $10\ \mathrm{kJ\,mol^{-1}}$ 量级；精算以生成焓为准。

### 数值算例：甲烷燃烧焓的两种算法

$\ce{CH4(g) + 2O2(g) -> CO2(g) + 2H2O(l)}$：

- **生成焓法**：$\Delta_r H^{\ominus} = (-393.5) + 2\times(-285.8) - (-74.8)
  = -890.3\ \mathrm{kJ\,mol^{-1}}$；
- **键焓法**：断键约 $4\times412 + 2\times496 = 2640$，成键约
  $2\times799 + 4\times463 = 3450$，$\Delta_r H^{\ominus} \approx 2640 - 3450
  = -810\ \mathrm{kJ\,mol^{-1}}$。

两种方法符号一致、量级相同，但数值差约 $80\ \mathrm{kJ\,mol^{-1}}$——键焓法
估方向、估量级，精算看生成焓。这就是「快速直觉」与「精确查表」的分工。

### 历史与延伸：从冰量热计到弹式量热计

1783 年拉瓦锡与拉普拉斯用冰量热计（溶冰量 = 热量）测燃烧热；1878 年贝特洛
发明弹式量热计，高压氧弹让燃烧完全进行，量热精度大幅提升。Hess 1840 年
的路径无关性，正是在一代代量热数据里归纳出来的——「状态函数」这个观念，
其实是量热实验逼出来的规律。

## 6 小结

- **标准摩尔生成焓** $\Delta_f H^{\ominus}$ 以最稳定单质为零点，反应焓 = 产物生成焓之和 − 反应物生成焓之和。
- **Hess 定律**：反应焓只由初末态决定，可用已知反应按「方向反转改号、系数倍乘改焓」线性组合求未知反应焓。
- **键焓法** $\Delta_r H^{\ominus} \approx \sum \mathrm{BE}(\text{断}) - \sum \mathrm{BE}(\text{成})$ 是分子级估算工具，误差量级约 $10\ \mathrm{kJ\,mol^{-1}}$，适合粗估与方向判断。
- **Kirchhoff 定律** $\Delta_r H^{\ominus}(T_2) = \Delta_r H^{\ominus}(T_1) + \int \Delta_r C_p^{\ominus}\,\mathrm{d}T$ 把表格数据外推到任意温度。
- 生成焓表 + Hess 定律 + Kirchhoff 修正，构成热化学「查表—组合—外推」的完整工作流。
