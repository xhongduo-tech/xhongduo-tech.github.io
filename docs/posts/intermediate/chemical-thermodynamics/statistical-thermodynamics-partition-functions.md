## 为什么从统计力学讲起

前十一节我们都在宏观层面工作：状态方程、焓、熵、化学势、相图——
一切由实验定律和公理支撑。
但「为什么熵会增」「为什么 $K$ 长成那样」「为什么热容是那样」
这些「为什么」最终都要下潜到分子层面回答。<span class="marginnote">1877 年玻尔兹曼用 $S = k\ln W$ 把熵翻译成「微观态数目的对数」，但玻尔兹曼生前饱受争议，1906 年自杀，墓碑上只留下这条公式。他没能看到：二十年后吉布斯、爱因斯坦把这套思想建成「统计热力学」的大厦，而今天它在从蛋白质折叠到大模型采样的所有领域都是主角。</span>**统计热力学的目标：从分子的能级与简并度出发，推导出宏观热力学量。** 它的全部魔法浓缩在一个对象里——**配分函数（partition function）**。这一节我们建立配分函数与 Boltzmann 分布，并看它如何一次算出 $U$、$S$、$G$ 与平衡常数——把前十一节的经验定律逐条「证明」给你看。

## 1 微观态、能级与 Boltzmann 分布

体系的每个分子有量子化的能级 $\varepsilon_i$，
第 $i$ 个能级的**简并度**（能级上互不相同的量子态数）为 $g_i$。
热平衡下，粒子在各能级上的占据按**Boltzmann 分布**：

$$N_i = \frac{N}{q}\,g_i\,e^{-\varepsilon_i/kT}$$

其中 $N_i$ 是能级 $i$ 上的粒子数，$N$ 是总粒子数，$q$ 是分子配分函数，$k = R/N_A$ 是玻尔兹曼常数。<span class="marginnote">Boltzmann 分布的两个因子各自讲一个故事：$e^{-\varepsilon_i/kT}$ 是「能量惩罚」——能级越高，占据越稀少；$g_i$ 是「状态数量奖赏」——简并度越高，越容易被占据。能量与简并度在指数与系数两个位置互相竞争，这正是「熵（数状态）与能量（守能量）的平衡」在分子层面的形态。</span>温度升高，指数惩罚变缓，高能级占据增多，分子「摊开」到更多状态——
这就是「升温增加可及微观态数、从而增加熵」的定量源头。

## 2 配分函数：统计力学的总开关

**配分函数（partition function）**定义为对所有分子态求和——
它是「把所有可能的分子状态连同其权重逐项加起来」的总数：

$$q = \sum_i g_i\,e^{-\varepsilon_i/kT}$$

对独立无相互作用的体系，分子配分函数可**因子分解**为平动、转动、振动、电子四个部分：$q = q_t\,q_r\,q_v\,q_e$。<span class="marginnote">因子分解是「配分函数之母」威力所在：平移、转动、振动、电子激发的能量分别可加，指数因子分别相乘，于是 $q$ 拆成四个独立因子，每个都可用分子光谱数据（能级）算出来——统计力学就这样与光谱学直接接轨。</span>配分函数的名字取得贴切：它「分配」了总粒子数到各能级的比例（$N_i/N = g_i e^{-\varepsilon_i/kT}/q$），也「分配」了体系的能量与熵。

## 3 从配分函数到热力学量

配分函数 $q$ 一旦到手，全部宏观热力学量都由它导出——
配分函数的名字取得贴切：它「分配」了粒子数，也「分配」了能量与熵：

**内能**：$U = NkT^2\left(\dfrac{\partial \ln q}{\partial T}\right)_V$
- **熵**：$S = k\ln q + \dfrac{U}{T}$（或 $S = Nk\ln q + \dfrac{U}{T}$）
- **亥姆霍兹能**：$A = -NkT\ln q$
- **压强**：$p = NkT\left(\dfrac{\partial \ln q}{\partial V}\right)_T$

<span class="marginnote">这几条式子把「实验测的量」与「分子算的量」合而为一：只要知道分子的能级（来自光谱），配分函数就给出比热、熵、化学势——不需要做任何宏观实验。这是统计力学相对热力学最大的承诺：宏观规律是微观能级的「宏观投影」。</span>以单原子理想气体为例，$q_t$ 由粒子盒中自由粒子的能级算出，
代入可精确得到 $U = \frac{3}{2}NkT$、$C_{V,m} = \frac{3}{2}R$、
以及 $pV = NkT$——**理想气体状态方程被「证明」了，而不是「假设」了**。
这是统计力学最动人的时刻：我们前十一节当作公理的东西，在这一节成为定理。

## 4 公式解析：$S = k\ln q + U/T$

**熵的配分函数表达式，是理解「统计熵」与「热力学熵」如何合一的枢纽。** 逐步拆解：

$$S = k\ln q + \frac{U}{T}$$

- **第一步，看懂第一项 $k\ln q$**：$q$ 是「体系可能到达的状态数」的加权和，$k\ln q$ 是「状态空间有多宽广」的度量——这就是玻尔兹曼 $S = k\ln W$ 在热平衡下的推广：平衡时体系不再停留在单个 $W$ 里，而是摊在配分函数描述的整个状态分布上。
- **第二步，看懂第二项 $U/T$**：能量 $U$ 除以温度 $T$，是「能量在状态间如何分配」的贡献。$U$ 越高，粒子占据越多的激发态，状态分布的「宽度」越大——这部分熵来自能量在不同能级间的铺开。
- **第三步，把两项合并看**：$q$ 管「能级空间有多大」，$U/T$ 管「粒子把空间占据得多开」。二者相加才是完整熵——它同时统计了「可及状态数」与「实际占据的分散度」，这正是热力学第二定律「体系总往状态更分散处走」的精确表述。
- **第四步，联系前面的宏观篇**：把这条 $S$ 代入 $G = H - TS$、$\Delta_r G^{\ominus} = -RT\ln K$，就能从分子能级一步步推出平衡常数——**宏观平衡的整个链条，在这里被统计力学重新焊死。**

## 5 配分函数如何给出平衡常数

利用「分子配分函数可乘、体系的 Helmholtz 能 $A = -kT\ln Q$」与
「化学势 = 每增加一个分子的 $A$ 变化」，可以推出气体反应的平衡常数：

$$\ln K = -\frac{\Delta_r \varepsilon_0}{RT} + \ln\frac{\prod (q_i/N_A)^{\nu_i}_{\mathrm{prod}}}{\prod (q_i/N_A)^{\nu_i}_{\mathrm{reac}}}$$

其中 $\Delta_r \varepsilon_0$ 是 0 K 时的反应能变，$q_i$ 是各组分分子配分函数，$\nu_i$ 是化学计量数。<span class="marginnote">这条式子揭示了 $K$ 的本质：平衡常数不是「浓度碰巧凑出的常数」，
而是「各分子的配分函数之比」——反应物与产物的分子自由度
（转动、振动、电子态）越丰富，平衡越偏往那边。
从光谱数据就能预报化学平衡，是统计热力学最有成就感的应用之一。</span>它对「为什么放热反应更彻底、而增熵反应也占优」给出了分子级解释：焓项来自能级差 $\Delta_r\varepsilon_0$，熵项来自各组分配分函数的相对大小——两股力量在 $K$ 里对撞，与《化学平衡》篇的 $\Delta_rG^{\ominus} = \Delta_rH^{\ominus} - T\Delta_rS^{\ominus}$ 完全一致。

### 辨析｜易错点：$q$、$Q$ 与简并度

1. **分子配分函数 $q$ 与体系配分函数 $Q$ 不同**：对 $N$ 个可区分粒子
   $Q = q^N$；对不可区分的同种分子要除以 $N!$——统计熵、混合熵的推导都卡在
   这个 $1/N!$ 上。
2. **别漏简并度 $g_i$**：$q = \sum g_i e^{-\varepsilon_i/kT}$，漏乘 $g_i$ 会少算
   「状态数」，熵直接偏低——简并度是「状态空间」的度量，不是可省的小量。
3. **「升温占据更高能级」要结合简并度读**：能量惩罚指数变缓，而高简并度能级
   天然「名额多」，两者竞争——这正是「温度 → 熵」的微观机制。

### 数值算例：双能级体系的占据比

设能级 $\varepsilon_0 = 0$（$g_0 = 1$）、$\varepsilon_1 = 2kT$（$g_1 = 2$）：

$$q = 1 + 2e^{-2} = 1 + 0.271 = 1.271, \qquad \frac{N_1}{N} = \frac{2e^{-2}}{1.271} \approx 0.213$$

高能级虽有明显的能量惩罚（$e^{-2} \approx 0.135$），但简并度 2 把它占比拉到
两成以上——「高能级 + 高简并度」的组合常比「低能级 + 低简并度」更常见，
这是统计力学最反直觉也最重要的教训。

### 历史与延伸：从玻尔兹曼到语言模型

Boltzmann 分布 $p_i \propto e^{-\varepsilon_i/kT}$ 与机器学习里的 softmax 同构：
softmax 的「温度参数」越高，分布越平——正是升温「摊开占据」的统计直觉。
能量模型、扩散模型采样、大模型解码时的 temperature 超参数，全部继承自
1877 年这条公式。统计力学不是百年前的化石，而是「从微观到宏观」方法论的
当代活体——这也是本博客「从极限到大模型」主线上最直接的一次呼应。

## 6 小结

- **Boltzmann 分布** $N_i \propto g_i e^{-\varepsilon_i/kT}$：高能级惩罚与简并度奖赏互相竞争，温度升高占据更分散。
- **配分函数** $q = \sum_i g_i e^{-\varepsilon_i/kT}$ 可因子分解为 $q_t q_r q_v q_e$，是统计力学的总开关。
- **从 $q$ 导一切**：$U = NkT^2(\partial\ln q/\partial T)_V$、$S = k\ln q + U/T$、$A = -NkT\ln q$、$p = NkT(\partial\ln q/\partial V)_T$。
- 单原子理想气体的 $pV = NkT$、$U = \frac{3}{2}NkT$ 由配分函数严格推出——**状态方程从假设升级为定理**。
- **平衡常数**来自各组分配分函数之比：分子自由度越丰富的一方，在 $K$ 中越占优。

在下一节，我们把统计与量热的结果用于「化学反应的热账」：Hess 定律为什么能用加加减减处理反应焓，键焓又是怎么被平均出来的？——这就是**热化学（Hess 定律 / 键焓）**。
