## 为什么从溶液讲起

气体研究的是「真空里的孤单分子」，而化学世界里真正的舞台是**溶液**——
反应在溶液里进行，生命在溶液里运转，工业流程在溶液里完成分离。
上一节的化学势告诉我们「物质往化学势低的地方跑」，
这一节就要回答：溶液里各组分的化学势如何由组成决定？
答案分两层：**理想溶液**给出最干净的基准（Raoult 定律），
**实际溶液**在稀溶液极限给出通用的修正（Henry 定律）。<span class="marginnote">历史小注：拉乌尔（François-Marie Raoult）1887 年发现「溶剂的蒸气压正比于它的摩尔分数」；亨利（William Henry）早在 1803 年就发现「气体在液体中的溶解度正比于其分压」。两条定律相差八十年，却只是「对溶液里不同组分（溶剂/溶质）各自成立」的两半——拉乌尔定律对溶剂，亨利定律对溶质。</span>这两条定律，加上化学势的对数形式，将给出「理想溶液混合熵」「依数性」「活度」等一系列后续武器。

## 1 理想溶液的 Raoult 定律

**理想溶液（ideal solution）**：组分之间分子间相互作用与纯组分内部完全相同，混合时无热效应、无体积变化。对理想溶液中组分 $i$：

**Raoult 定律（Raoult's law）**：$i$ 的蒸气压等于纯组分蒸气压乘以它在液相中的摩尔分数：

$$p_i = x_i p_i^{*}$$

其中 $x_i$ 是摩尔分数，$p_i^{*}$ 是纯组分的蒸气压。<span class="marginnote">拉乌尔定律的微观直觉：蒸气压取决于「液体表面有多少溶剂分子想逃逸」。加入溶质后，表面被「稀释」，溶剂分子逃逸的机会按比例下降——$p_A$ 从 $p_A^{*}$ 线性降到更低。摩尔分数 $x$ 就是「稀释度」的度量。</span>从化学势看，理想溶液中组分 $i$ 的化学势取：

$$\mu_i = \mu_i^{*} + RT\ln x_i$$

把理想气体化学势与 Raoult 定律拼在一起，可以严格推出这条式子——
**理想溶液的偏差全部来自「混合」这一动作带来的熵增**
（混合熵 $\Delta_{\mathrm{mix}}S = -nR(x_A\ln x_A + x_B\ln x_B)$），而混合焓为零。

## 2 Henry 定律：稀溶液里溶质的通用法则

当溶质很稀，溶质分子被溶剂分子包围、几乎不与同类接触，
它的逸出行为不再按 Raoult 的「比例于自己摩尔分数」走，
而服从 **Henry 定律（Henry's law）**：

$$p_B = K_B x_B$$

$K_B$ 是**Henry 常数**，量纲与压强相同，数值由溶质—溶剂相互作用决定（温度有关）。<span class="marginnote">亨利常数的地位相当于溶质的「虚拟纯态蒸气压」：它是 $p_B$ 对 $x_B$ 曲线的斜率，代表「稀到溶质互不接触」时的逸出能力。气体溶解（碳酸饮料冒泡）、低压下溶质挥发，都按亨利定律描述。</span>**亨利定律与拉乌尔定律是同一张「分压—组成」图上两条不同的直线**：溶剂端（$x_A\to 1$）走拉乌尔线，溶质端（$x_B\to 0$）走亨利线——中间区域则是一条弯曲的实线，这就是下一节要引入「活度」来描述的偏差区。

## 3 实际溶液与活度

真实溶液中分子间相互作用不相等，Raoult 与 Henry 都只是极限近似。
为保留「$\mu = \mu^{\ominus} + RT\ln(\cdots)$」这个漂亮结构，
化学家引入**活度（activity）$a_i$**：

$$\mu_i = \mu_i^{\ominus} + RT\ln a_i, \qquad a_i = \gamma_i\, x_i$$

其中 $\gamma_i$ 是**活度系数**。当 $\gamma_i = 1$，$a_i = x_i$，回到理想情形；$\gamma_i < 1$ 表示组分间「互相吸引更黏」（负偏差，如乙醇—水之外的氯仿—丙酮），$\gamma_i > 1$ 表示「互相排斥更散」（正偏差，如苯—乙醇）。<span class="marginnote">活度的价值是「结构不变、内容换掉」：把理想定律里的摩尔分数 $x_i$ 全部换成活度 $a_i$，理想溶液的所有公式就自动升级为适用于实际溶液——Raoult 定律变成 $p_i = a_i p_i^*$，化学势、平衡常数、能斯特方程全部照此办理。查表、测活度，是化学热力学实验的半壁江山。</span>活度系数随浓度偏离 1，是「实际」二字在数学上的全部体现。

## 4 依数性：只看颗粒数，不看颗粒种类

溶质不挥发的稀溶液有四种**依数性（colligative properties）**：
蒸气压降低、沸点升高、凝固点降低、渗透压。
它们只依赖溶质的「颗粒数目」，不依赖其化学性质：

**蒸气压降低**：$\Delta p_A = -x_B p_A^{*}$（由 Raoult 定律直接推出）。
- **沸点升高**：$\Delta T_b = K_b\, b_B$，$b_B$ 是质量摩尔浓度，$K_b$ 是沸点升高常数。
- **凝固点降低**：$\Delta T_f = K_f\, b_B$。
- **渗透压**：$\pi V = n_B RT$，即 $\pi = [B]RT$——**范特霍夫方程**，与理想气体方程同形，这正是本节引言的来源。<span class="marginnote">依数性给了我们「数颗粒」的实验室工具：测渗透压可以测高分子的摩尔质量，测凝固点降低可以测未知溶质的摩尔质量，还能检验电解质是否完全解离（解离会倍增颗粒数）。「颗粒数」这个朴素概念，是这些测量全部威力的来源。</span>电解质溶液必须用**离子总数**代替分子数，由此引出**范特霍夫因子** $i$——$i$ 偏离化学式给出的解离数，就是「不完全解离」的信号。

## 5 公式解析：$p_A = x_A p_A^{*}$（Raoult 定律）

**Raoult 定律是全专题最容易「背下来却不懂」的公式之一，值得把每一步想透。** 逐步拆解：

$$p_A = x_A p_A^{*}$$

- **第一步，分清谁的定律**：$A$ 是溶剂，定律对「溶剂端」成立；$p_A$ 是溶液中溶剂上方气相里的分压，$x_A$ 是液相中溶剂的摩尔分数，$p_A^{*}$ 是纯溶剂蒸气压。三个量必须对应同一个组分。
- **第二步，读出线性**：$p_A$ 随 $x_A$ 线性下降；纯溶剂时 $x_A=1$、$p_A=p_A^{*}$；$x_A\to 0$ 时 $p_A\to 0$——溶质多了，溶剂几乎不再挥发。这条直线是「理想」的全部含义：没有相互作用差异，蒸气压就是简单的份额分配。
- **第三步，接上化学势**：气相里溶剂化学势 $\mu_A = \mu_A^{\ominus} + RT\ln(p_A/p^{\ominus})$，液相里 $\mu_A = \mu_A^{*} + RT\ln x_A$。气相—液相化学势相等，推出 $p_A/p_A^{*} = x_A$——**Raoult 定律是「两相化学势相等」的直接推论**，不是一条独立假设。
- **第四步，为活度做准备**：真实溶液中把 $x_A$ 换成 $a_A$，则 $p_A = a_A p_A^{*}$。**测蒸气压，就是测活度**——依数性、活度测量的所有实验设计都从这里出发。

### 辨析｜易错点：两条定律的分工与单位的陷阱

1. **Raoult 定律管溶剂、Henry 定律管溶质，别搞反**：把溶质浓度代进 Raoult
   式子会得到荒谬结果——溶质的逸出能力由 $K_B$ 描述，不是按 $x_B p_B^*$ 下降。
2. **Henry 常数 $K_B$ 有压强单位，且依赖组成标度**：用摩尔分数、质量摩尔
   浓度还是体积摩尔浓度，$K_B$ 数值不同——查表前先确认标度一致。
3. **依数性「只数颗粒」有前提**：溶质必须不挥发、不解离。电解质（如 $\ce{NaCl}$
   解离成两个离子）要乘范特霍夫因子 $i$，可挥发溶质则要进气相，都不再「只数颗粒」。

### 数值算例：苯—甲苯理想溶液的蒸气组成

$25\,^{\circ}\mathrm{C}$ 时纯苯 $p_A^{*} = 100\ \mathrm{mmHg}$、纯甲苯
$p_B^{*} = 30\ \mathrm{mmHg}$，液相组成 $x_A = 0.40$：

- $p_A = 0.40 \times 100 = 40\ \mathrm{mmHg}$，$p_B = 0.60 \times 30 = 18\ \mathrm{mmHg}$；
- 总蒸气压 $p = 58\ \mathrm{mmHg}$；
- 气相组成 $y_A = p_A/p = 40/58 \approx 0.69$。

气相比液相更富易挥发组分——「蒸馏富集」的数字根源，也解释了为什么理想
溶液是分离工艺的基准曲线。

### 历史与延伸：范特霍夫与物理化学的诞生

1887 年范特霍夫用半透膜测渗透压，得到 $\pi V = nRT$；同年他和奥斯特瓦尔德
创办《物理化学杂志》，「物理化学」学科由此得名。1887 年还是拉乌尔发表
蒸气压定律、阿伦尼乌斯提出电离理论的一年——这一年被后世称为「物理化学
元年」。渗透压、蒸气压、电离三条线索同年汇合，正是溶液理论成形的时刻。

## 6 小结

- **Raoult 定律** $p_A = x_A p_A^{*}$ 描述理想溶液中溶剂的蒸气压，由「液相—气相化学势相等」推出。
- **Henry 定律** $p_B = K_B x_B$ 描述稀溶液里溶质的分压，$K_B$ 是溶质—溶剂相互作用的指纹。
- **理想溶液**无混合热、无体积变化，混合熵 $= -nR\sum x_i\ln x_i$，是「混合天然熵增」的数学表达。
- **活度** $a_i = \gamma_i x_i$ 把实际溶液的偏差收进活度系数 $\gamma_i$，让理想公式整体升级。
- **依数性**（蒸气压降低、沸点升高、凝固点降低、渗透压）只依赖颗粒数；范特霍夫方程 $\pi = [B]RT$ 与理想气体同形。

在下一节，我们不再满足于「溶液的气—液平衡」，而要追问：当化学反应在恒温恒压下达到平衡，反应进度停在哪儿？平衡位置与热力学量之间隔着哪条等式？——这就是**化学平衡与平衡常数**。
