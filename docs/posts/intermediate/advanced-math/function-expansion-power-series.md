## 为什么从函数展开成幂级数开始

幂级数是「无限多项式」，那么问题来了：**哪些函数可以写成幂级数？怎么写？** 答案就在泰勒公式——如果余项趋于零，泰勒多项式就「长出」泰勒级数，函数在自己的收敛区间内被幂级数精确表示。**函数展开成幂级数**（泰勒级数/麦克劳林级数）把「用多项式逼近函数」推到极致：从「有限项近似」升级为「无限项精确」。它是整个级数理论的目的地——计算机算函数靠它、微分方程级数解靠它、信号处理的傅里叶级数也是它的「三角版」。<span class="marginnote">函数展开成幂级数 = 「用函数的各阶导数在一点的信息，重建整个函数」。<strong>泰勒级数的系数 $\frac{f^{(n)}(x_0)}{n!}$ 全由 $x_0$ 处的导数决定</strong>——一点的「无限阶导数信息」竟能重构整条函数曲线，这是分析学最深刻的奇迹之一。它背后是「解析函数」的概念：函数在一点的性质「传染」到整个收敛区域。</span>

## 1 泰勒级数

设 $f$ 在含 $x_0$ 的区间内具有各阶导数，则它的**泰勒级数**为

$$f(x) \sim \sum_{n=0}^{\infty}\frac{f^{(n)}(x_0)}{n!}(x - x_0)^n$$

记号 $\sim$ 表示「形式级数」——级数写出来了，但**是否等于 $f$ 还要看余项**。

**函数展开成泰勒级数的充要条件**：$\lim_{n\to\infty}R_n(x) = 0$，其中 $R_n(x)$ 是泰勒公式的余项（拉格朗日型 $\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$）。**只有当余项趋于零，泰勒级数才等于函数本身**。

**麦克劳林级数**：$x_0=0$ 时的泰勒级数 $f(x) = \sum\frac{f^{(n)}(0)}{n!}x^n$。

**辨析｜易错点：** ① 泰勒级数收敛不一定等于 $f$——经典反例 $f(x) = e^{-1/x^2}$（$f(0)=0$）的各阶导数在 0 处都是 0，泰勒级数恒为 0，但 $f\neq0$——「光滑但不解析」的函数。② 展开前要确认「余项趋于零」，不能只写级数就认为「等于」$f$。<span class="marginnote">「泰勒级数收敛但和不是 $f$」的反例（$e^{-1/x^2}$）说明：<strong>光滑（无穷阶可导）≠ 解析（等于自己的泰勒级数）</strong>。这个区别在复变函数里消失——复解析函数自动等于自己的泰勒级数。到《复变函数》你会看到「复可导 ⇒ 无穷次可导 ⇒ 解析」的美妙连锁。</span>

## 2 常用函数的麦克劳林展开式

五个「原子展开」（均在 $x=0$ 处，收敛区间已注明）：

$$e^x = \sum_{n=0}^{\infty}\frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \cdots, \quad x \in \mathbb{R}$$

$$\sin x = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots, \quad x \in \mathbb{R}$$

$$\frac{1}{1-x} = \sum_{n=0}^{\infty}x^n = 1 + x + x^2 + \cdots, \quad |x| < 1$$

$$\ln(1+x) = \sum_{n=1}^{\infty}\frac{(-1)^{n-1}x^n}{n} = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots, \quad -1 < x \le 1$$

$$(1+x)^\alpha = \sum_{n=0}^{\infty}\binom{\alpha}{n}x^n, \quad |x| < 1$$

<span class="marginnote">五条展开是「泰勒机器」的标准输出：$e^x$ 所有导数在 0 处都是 1；$\sin$ 只有奇次项（偶阶导数为 0）；$\frac{1}{1-x}$ 是几何级数（系数全是 1）；$\ln(1+x)$ 由几何级数逐项积分而来；$(1+x)^\alpha$ 是二项式定理的无限版（$\alpha$ 非整数时也成立）。<strong>每一条都是「从定义出发的作业」，但记住它们能让后续展开「搭积木」</strong>。</span>

## 3 间接展开法

不每次都从定义算系数，而是**利用已知展开做四则、求导、积分、代换**——**间接展开法**是实战主角：

**代换**：$e^{-x^2} = \sum\frac{(-1)^n x^{2n}}{n!}$——把 $x$ 换成 $-x^2$；
**逐项积分**：$\arctan x = \int_0^x\frac{dt}{1+t^2} = \sum\frac{(-1)^n x^{2n+1}}{2n+1}$；
**逐项求导**：$\frac{1}{(1-x)^2} = \left(\frac{1}{1-x}\right)' = \sum (n+1)x^n$；
**四则运算**：$\frac{x}{1+x^2} = x\sum(-1)^n x^{2n} = \sum(-1)^n x^{2n+1}$。

**公式解析：用间接法展开**

展开 $f(x) = \arctan x$ 为麦克劳林级数：

**第一步，求导找已知级数**：$f'(x) = \frac{1}{1+x^2} = \frac{1}{1-(-x^2)} = \sum_{n=0}^{\infty}(-1)^n x^{2n}$（几何级数代换，$|x|<1$）。
**第二步，逐项积分**：$\arctan x = \int_0^x\sum(-1)^n t^{2n}dt = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{2n+1}$。
**第三步，定端点**：$x=\pm1$ 时级数为交错级数，收敛。故收敛域 $[-1,1]$，且在端点处 $\arctan(\pm1) = \pm\frac{\pi}{4}$。

**关键**：间接展开的套路——**「求导/代换/积分到已知级数」再「逆运算回来」**。$\arctan x$ 的展开由「$\frac1{1+x^2}$ 的几何级数逐项积分」一步得出——比从定义算系数快百倍。

## 4 函数展开的应用

**计算函数值**：$e^x$、$\sin x$ 等用展开截断计算，精度由余项控制。<span class="marginnote">用泰勒级数算 $\sin 1$ 到小数点后 6 位：取前若干项，余项 $|\frac{x^{2n+1}}{(2n+1)!}|<10^{-6}$ 即可——「级数截断 + 余项控制」是数值计算的标准精度策略。计算器与 CPU 里的数学函数，底层正是这套「查表 + 多项式逼近」。</span>
- **极限与近似**：用展开求 $\frac{0}{0}$ 型极限（比洛必达更「干净」），估计 $\sqrt{1.01}$、$e^{0.1}$ 等。
- **证明不等式**：如 $e^x > 1+x+\frac{x^2}{2}$（$x>0$），展开后各项为正。
- **微分方程级数解**：把 $y=\sum a_nx^n$ 代入方程解递推——求 Bessel、Legendre 方程的解。
- **组合与概率**：生成函数、矩母函数都是「展开成级数再运算」。

## 5 小结

- **泰勒级数**：$f(x) = \sum\frac{f^{(n)}(x_0)}{n!}(x-x_0)^n$，成立当且仅当余项 $R_n\to0$。
- 光滑 ≠ 解析（反例 $e^{-1/x^2}$）；麦克劳林级数是 $x_0=0$ 的特例。
- **五个原子展开**：$e^x$、$\sin x$、$\frac1{1-x}$、$\ln(1+x)$、$(1+x)^\alpha$。
- **间接展开**：代换、逐项求导、逐项积分、四则——从已知展开「搭积木」。
- 应用：函数计算、极限、不等式、微分方程级数解、生成函数。
