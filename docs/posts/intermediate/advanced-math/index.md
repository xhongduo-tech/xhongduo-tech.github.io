# 高等数学

严格化的微积分体系，是概率论、物理与机器学习的公共语言。

## 主题规划

- [ ] 极限的严格定义（ε-δ 语言）与连续性
- [ ] 一元函数微分学：中值定理与泰勒公式
- [ ] 一元函数积分学：换元、分部与反常积分
- [ ] 多元函数微分学：偏导数、全微分与链式法则
- [ ] 多元极值与拉格朗日乘数法
- [ ] 重积分：二重与三重积分的计算
- [ ] 曲线积分与曲面积分
- [ ] 格林公式、高斯公式与斯托克斯公式
- [ ] 无穷级数：收敛判别与幂级数展开
- [ ] 傅里叶级数初步
- [ ] 常微分方程：一阶方程与线性方程组
- [ ] 向量分析：梯度、散度与旋度
