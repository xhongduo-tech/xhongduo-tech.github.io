## 为什么从二重积分的概念与性质开始

一元定积分算「曲线下的面积」，二重积分算「曲面下的体积」——把平面区域切成小块，每块上「曲面高度 × 小块面积」求和，取极限。这完全是定积分「分割 → 近似 → 求和 → 取极限」的二维版。二重积分是多元积分的入口：曲顶柱体体积、平面薄片质量、概率二维积分，全是二重积分。它的概念与性质与一元定积分高度平行，但定义域从区间升级为平面区域，这带来了「区域」结构（$x$-型、$y$-型）的计算复杂性——那是下一节的主角。<span class="marginnote">二重积分的直观：<strong>$\iint_D f(x,y)\,dA$ = 区域 $D$ 上的「高度 $f$ 的总体积」</strong>。若 $f\equiv1$，则 $\iint_D dA$ 恰是区域 $D$ 的面积——积分是「面积/体积」的通用语言，$f$ 是「密度」。这个「密度 × 微元」的视角与第六章元素法一脉相承。</span>

## 1 二重积分的定义

设 $z = f(x,y)$ 在有界闭区域 $D$ 上有界。将 $D$ 任意分成 $n$ 个小闭区域 $\Delta\sigma_1, \ldots, \Delta\sigma_n$（$\Delta\sigma_i$ 也表示其面积），在每块内任取一点 $(\xi_i, \eta_i)$，作**二重和（黎曼和）**

$$\sum_{i=1}^{n} f(\xi_i, \eta_i)\,\Delta\sigma_i$$

若当各小区域的最大直径 $\lambda \to 0$ 时，该和的极限存在且与分割方式、取点方式无关，则称该极限为 $f$ 在 $D$ 上的**二重积分**：

$$\iint_D f(x,y)\,d\sigma = \lim_{\lambda \to 0}\sum_{i=1}^{n} f(\xi_i,\eta_i)\,\Delta\sigma_i$$

其中 $D$ 是**积分区域**，$f(x,y)$ 是**被积函数**，$d\sigma$ 是**面积微元**（直角坐标下 $d\sigma = dx\,dy$）。<span class="marginnote">与一元定积分对照：区间 $[a,b]$ 换成平面区域 $D$，长度微元 $dx$ 换成面积微元 $d\sigma$，划分方式从「分点」变成「分小块」。二元黎曼和的极限定义完全复刻一元——只是「维数」升了一级。可积的充分条件与一元平行：$f$ 在 $D$ 上连续（或有界且间断点集「足够小」）时可积。</span>

**几何意义**：$f(x,y) \ge 0$ 时，$\iint_D f(x,y)\,d\sigma$ = 以 $D$ 为底、$z=f(x,y)$ 为顶的**曲顶柱体体积**；$f$ 可正可负时，是有向体积的代数和。

## 2 二重积分的性质

二重积分继承定积分的全部基本性质（$D$ 为有界闭区域）：

**线性性**：$\iint_D [\alpha f + \beta g]\,d\sigma = \alpha\iint_D f\,d\sigma + \beta\iint_D g\,d\sigma$；
**区域可加性**：$D = D_1 \cup D_2$（内部不重叠）时 $\iint_D = \iint_{D_1} + \iint_{D_2}$；
**保序性**：$f \ge g$ ⇒ $\iint_D f \ge \iint_D g$；
**估值定理**：$m \le f \le M$ 时 $m\,S_D \le \iint_D f\,d\sigma \le M\,S_D$（$S_D$ 是 $D$ 的面积）；
**中值定理**：$f$ 在连通闭区域 $D$ 上连续时，存在 $(\xi,\eta)\in D$ 使 $\iint_D f\,d\sigma = f(\xi,\eta)\,S_D$。

**重点：$\iint_D d\sigma = S_D$**——被积函数恒为 1 时，二重积分就是区域面积。这条性质是面积计算的「积分语言」，也是估值的基准。<span class="marginnote">区域可加性是二重积分的实用利器：把复杂区域沿边界拆成几块分别积分，再相加。这与你解分段函数、分段积分完全平行。中值定理则是「区域内某点的函数值 × 面积 = 积分」——「存在性」与「估值」的又一次结合。</span>

## 3 公式解析：用二重积分表达曲顶柱体体积

设 $f(x,y) = 1 - x^2 - y^2$，$D = \{(x,y) \mid x^2 + y^2 \le 1\}$，求曲顶柱体体积 $V$：

**第一步，写积分**：$V = \iint_D (1 - x^2 - y^2)\,d\sigma$。
**第二步，拆成常数减两项**：$V = \iint_D d\sigma - \iint_D (x^2 + y^2)\,d\sigma = S_D - \iint_D (x^2+y^2)\,d\sigma$。
**第三步，利用几何**：$S_D = \pi$（单位圆面积）。第二项用极坐标（下一节）：$\iint_D (x^2+y^2)\,d\sigma = \int_0^{2\pi}\int_0^1 r^2\cdot r\,dr\,d\theta = \frac{\pi}{2}$。
**第四步，得结果**：$V = \pi - \frac{\pi}{2} = \frac{\pi}{2}$。

**关键**：二重积分把「曲顶柱体体积」表达为一个区域上的积分——这是「重积分的应用」的起点。把积分解出值还需要计算方法（直角坐标累次积分、极坐标），下一节展开。这里先立住「体积 = 二重积分」的概念对应。

## 4 二重积分与元素法的统一

二重积分是「元素法」的二维推广——第六章的元素法是「沿一维切微元」，二重积分是「沿二维切微元」：

**面积元素法**：$dA = dx\,dy$，区域面积 $S = \iint_D dA$；
**体积元素法**：$dV = f(x,y)\,dx\,dy$，曲顶柱体体积 $V = \iint_D f\,dA$；
**质量元素法**：面密度 $\rho(x,y)$ 的薄片质量 $M = \iint_D \rho(x,y)\,dA$。

<span class="marginnote">「密度 × 面积微元」的统一模板再次出现：面积、体积、质量、电荷……凡是「区域上的分布量」，都能写成 $\iint_D (\text{密度})\,dA$。这张「密度 × 微元」的思维表（一维 $dx$、二维 $dA$、三维 $dV$）将贯穿第十、十一章，也是概率论里二维随机变量的联合密度积分的直接原型。</span>

## 5 二重积分与概率

二重积分是概率论的二维语言：

**二维连续随机变量**：联合密度 $p(x,y)$ 满足 $\iint_{\mathbb{R}^2} p(x,y)\,dx\,dy = 1$，落在区域 $D$ 内的概率 $P((X,Y)\in D) = \iint_D p(x,y)\,dx\,dy$。<span class="marginnote">「概率 = 密度曲面下的体积」是二维概率的核心：一维是「密度曲线下的面积」，二维是「密度曲面下的体积」。你在《概率论与数理统计》里算二维随机变量的概率、边缘分布、协方差，处处都是二重积分。</span>
- **期望与方差**：$E[g(X,Y)] = \iint g(x,y)p(x,y)\,dx\,dy$。
- **机器学习**：高斯分布、贝叶斯推断中的归一化常数都是二重（乃至高维）积分。

## 7 数值算例：估值定理的实际应用

估计 $I = \iint_D (x^2 + 4y^2 + 9)\,dA$，其中 $D$ 是圆盘 $x^2 + y^2 \le 4$。

**第一步，定函数范围**：在 $D$ 上 $x^2 + y^2 \le 4$，故 $x^2 + 4y^2$ 介于 $0$ 与 $4(x^2+y^2) \le 16$ 之间，$f = x^2 + 4y^2 + 9$ 满足 $9 \le f \le 25$。
**第二步，算区域面积**：$D$ 是半径 $2$ 的圆，$S_D = 4\pi$。
**第三步，套估值定理**：$m\cdot S_D \le I \le M\cdot S_D$，即 $9\cdot 4\pi \le I \le 25\cdot 4\pi$，$36\pi \le I \le 100\pi$。

**意义**：不真正计算积分，先锁定 $I$ 的数量级。估值定理在证明与近似中极有用——它告诉你在求精确值之前，结果该落在哪个区间。<span class="marginnote">估值定理 + 中值定理构成「<strong>先夹后定</strong>」的两件套：估值给上下界，中值给「恰等于某点函数值 × 面积」的等式。它们在误差估计、级数审敛、积分不等式里反复出场，是「不求解先定性」这一分析学思维的微型样板。</span>

## 8 对照表：一元定积分与二重积分

| 一元定积分 | 二重积分 |
| --- | --- |
| 区间 $[a,b]$ | 平面区域 $D$ |
| 长度微元 $dx$ | 面积微元 $d\sigma = dx\,dy$ |
| 分点划分 | 分成小闭区域 |
| 黎曼和 $\sum f(\xi_i)\Delta x_i$ | 二重黎曼和 $\sum f(\xi_i,\eta_i)\Delta\sigma_i$ |
| 曲线下面积 | 曲面下体积 |

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 把 $d\sigma$ 当成可随便改的量 | $d\sigma = dx\,dy$，且必须在区域 $D$ 内积分 |
| 忘了 $f\equiv1$ 时是面积 | $\iint_D d\sigma = S_D$ 是面积计算的积分语言 |
| 估值定理用错面积 | $m\,S_D \le \iint f \le M\,S_D$，$S_D$ 是 $D$ 的面积 |
| 区域可加时边界重叠 | 分块要求内部不重叠，否则重复积分 |

## 10 二重积分的统一图景

二重积分把「密度 × 微元」的思维模板升级到二维：

| 对象 | 一维 | 二维 |
| --- | --- | --- |
| 长度 / 面积 | $dx$ | $dA = dx\,dy$ |
| 杆的质量 | $\int \rho(x)dx$ | 薄片质量 $\iint \rho(x,y)dA$ |
| 曲线下面积 | $\int f(x)dx$ | 曲面下体积 $\iint f\,dA$ |
| 概率 | $\int p(x)dx$ | $\iint p(x,y)dA$ |

面积、体积、质量、电荷、概率——凡是「区域上的分布量」都能写成 $\iint(\text{密度})\,dA$。这张表将贯穿第十、十一章，也是概率论联合密度、机器学习高维积分（归一化常数、期望）的起点。

## 11 小结

- **二重积分**：$\iint_D f(x,y)\,d\sigma = \lim\sum f(\xi_i,\eta_i)\Delta\sigma_i$，是定积分的二维版。
- 几何意义：曲顶柱体体积；$f\equiv1$ 时 $\iint_D d\sigma = S_D$。
- 性质：线性、区域可加、保序、估值、中值定理——与一元定积分平行。
- 估值定理给出「先夹后定」的数量级工具。
- 二重积分是元素法的二维推广：「密度 × 面积微元」的积分。
- 应用：体积、质量、二维概率——概率论与机器学习的基础积分工具。
