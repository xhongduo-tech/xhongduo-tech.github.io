## 为什么从傅里叶级数开始

泰勒级数用「多项式」逼近函数；**傅里叶级数**换了一种「基底」——用「三角函数」（正弦、余弦）逼近周期函数。傅里叶的洞见：**任何周期信号都可以分解成「基频 + 各次谐波」的正弦/余弦叠加**。声音是许多频率的叠加（音色=谐波结构）、音乐、地震波、语音、图像——一切「信号」都可以用傅里叶级数分解。它是现代信号处理、语音技术、图像压缩（JPEG）、乃至大模型里注意力机制「位置编码」的数学根基。<span class="marginnote">傅里叶级数的核心思想：<strong>「用正交三角函数系作基底，把函数投影到各频率上」</strong>。就像坐标 $(x,y,z)$ 把向量分解到三个正交轴上，傅里叶级数把函数分解到无穷多个正交的 $\sin(nx)$、$\cos(nx)$ 上。「谐波分解」让「分析信号」变成「看各频率的振幅」——频谱分析由此诞生。</span>

## 1 三角函数系的正交性

**三角函数系**：$1, \cos x, \sin x, \cos 2x, \sin 2x, \ldots, \cos nx, \sin nx, \ldots$

**正交性**：在区间 $[-\pi, \pi]$ 上，三角函数系中任意两个不同函数的内积为零：

$$\int_{-\pi}^{\pi}\cos nx\,dx = 0, \quad \int_{-\pi}^{\pi}\sin nx\,dx = 0, \quad \int_{-\pi}^{\pi}\cos nx\cos mx\,dx = 0\ (n\neq m)$$

$$\int_{-\pi}^{\pi}\sin nx\sin mx\,dx = 0\ (n\neq m), \quad \int_{-\pi}^{\pi}\sin nx\cos mx\,dx = 0$$

且「自内积」$\int_{-\pi}^{\pi}\cos^2 nx\,dx = \pi$、$\int_{-\pi}^{\pi}\sin^2 nx\,dx = \pi$、$\int_{-\pi}^{\pi}1^2\,dx = 2\pi$。<span class="marginnote">正交性是傅里叶级数的基石：<strong>「不同频率的波形互不干扰」</strong>——$\sin nx$ 与 $\sin mx$ 在积分意义下「垂直」。这使「求系数」变成「投影」：$a_n = \frac{1}{\pi}\int f(x)\cos nx\,dx$ 就是「把 $f$ 投影到 $\cos nx$ 这个方向上取分量」。傅里叶系数 = 函数在「频率轴」上的坐标——与线性代数里「正交基上的坐标 = 内积」完全同构。</span>

## 2 傅里叶级数与傅里叶系数

设 $f(x)$ 是周期为 $2\pi$ 的周期函数，其**傅里叶级数**为

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty}(a_n\cos nx + b_n\sin nx)$$

**傅里叶系数**（由正交性「投影」得到）：

$$a_n = \frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\cos nx\,dx \quad (n = 0, 1, 2, \ldots)$$

$$b_n = \frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\sin nx\,dx \quad (n = 1, 2, \ldots)$$

记号 $\sim$ 表示「傅里叶级数」，它是否收敛到 $f$ 由收敛定理（下一节）决定。<span class="marginnote">系数公式的来源：把 $f$ 的傅里叶展开代入 $\int f(x)\cos nx\,dx$，由正交性所有交叉项消失，只剩 $a_n\int\cos^2 nx\,dx = a_n\pi$——解出 $a_n$。这就是「<strong>正交性让系数一个个解耦</strong>」：每个系数只依赖 $f$ 与该频率的「重合度」，互不干扰。这是整个傅里叶分析的算术引擎。</span>

## 3 公式解析：方波的傅里叶级数

求周期 $2\pi$ 的方波 $f(x) = \begin{cases}-1 & -\pi < x < 0\\ 1 & 0 < x < \pi\end{cases}$ 的傅里叶级数：

**第一步，算 $a_n$**：$f$ 是奇函数，$f(x)\cos nx$ 是奇函数，$a_n = \frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\cos nx\,dx = 0$（对称区间奇函数积分为 0）。$a_0 = 0$。
**第二步，算 $b_n$**：$b_n = \frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\sin nx\,dx = \frac{2}{\pi}\int_0^{\pi}\sin nx\,dx = \frac{2}{\pi}\cdot\frac{1-\cos n\pi}{n}$。
**第三步，化简**：$\cos n\pi = (-1)^n$，故 $b_n = \frac{2}{n\pi}\left[1-(-1)^n\right]$——$n$ 偶数时 $b_n=0$，$n$ 奇数时 $b_n = \frac{4}{n\pi}$。
**第四步，写展开**：$f(x) = \frac{4}{\pi}\left(\sin x + \frac{1}{3}\sin 3x + \frac{1}{5}\sin 5x + \cdots\right)$。

**关键**：方波的傅里叶级数只含奇次正弦——「方波 = 基频正弦 + 越来越弱的高次奇谐波」。这个「方波频谱」是信号处理的教科书案例：谐波振幅 $\frac{4}{n\pi}$ 按 $\frac1n$ 衰减。<span class="marginnote">「方波只有奇次谐波」的直觉：方波是奇函数（$\sin$ 也是奇函数），奇函数的傅里叶级数不含余弦（偶分量）——<strong>「奇偶对称性决定频谱结构」</strong>。偶函数只有余弦项，奇函数只有正弦项。先看对称性再算系数，能省一半计算量。</span>

## 4 收敛定理（狄利克雷条件）

**狄利克雷收敛定理**：设 $f(x)$ 是周期为 $2\pi$ 的周期函数，在一个周期内①只有有限个第一类间断点；②只有有限个极值点，则 $f$ 的傅里叶级数在每点收敛，且

在连续点 $x$ 处收敛到 $f(x)$；
在间断点 $x_0$ 处收敛到 $\frac{f(x_0^-) + f(x_0^+)}{2}$（左右极限的平均值）。

**重点：傅里叶级数在间断点收敛到「跳跃中点」**——这是傅里叶级数与幂级数的重要区别：幂级数在收敛域内等于函数，傅里叶级数只在连续点等于函数，在间断点「取平均」。<span class="marginnote">「间断点收敛到左右极限平均」的物理意义：方波在跳跃处，傅里叶级数给出的值是「跳变的中点」——这是「吉布斯现象」（截断近似在间断点附近过冲）的理论背景。收敛定理的条件（有限间断、有限极值）相当宽松——<strong>几乎一切实际周期信号都能傅里叶展开</strong>，这正是傅里叶分析应用广泛的原因。</span>

**公式解析：收敛定理的应用**

方波 $f$ 在 $x=0$ 处（间断点）的傅里叶级数收敛到 $\frac{f(0^-)+f(0^+)}{2} = \frac{-1+1}{2} = 0$。而展开式在 $x=0$ 处为 $\frac{4}{\pi}(\sin 0 + \frac13\sin 0 + \cdots) = 0$——一致。利用 $x=\frac{\pi}{2}$（连续点）可推出 $\frac{\pi}{4} = 1 - \frac13 + \frac15 - \cdots$——**莱布尼茨级数**，圆周率的著名级数表示。

**关键**：收敛定理把「傅里叶级数的值」落实为「函数值或跳跃中点」——它既是理论保证，也是「级数求值」的工具。

## 5 傅里叶级数的意义

**信号与频谱**：语音、音乐、图像信号分解成频率分量——音色由谐波结构决定，音频均衡器调的是各频率振幅。<span class="marginnote">傅里叶级数是「频谱分析」的理论根：<strong>把时间信号变成频率的振幅分布</strong>。语音识别、图像压缩（JPEG 用 DCT）、音频编解码（MP3）全建立在「分解到频率、按重要性取舍」上。到第三级《信号与系统》与第四级《语音技术》，你会系统使用这套「时域 ↔ 频域」的双语。</span>
- **偏微分方程**：波动方程、热传导方程的解用傅里叶级数展开——分离变量法的核心（《数学物理方程》）。
- **机器学习**：Transformer 的**位置编码**用正弦/余弦函数——不同频率的位置信号让模型感知序列顺序。
- **逼近理论**：傅里叶级数截断 = 「低通滤波」——只保留低频分量。

## 7 数值算例：锯齿波的傅里叶级数

求周期 $2\pi$ 的锯齿波 $f(x) = x$（$-\pi < x \le \pi$）的傅里叶级数。

**第一步，判奇偶**：$f(x)=x$ 是奇函数，$a_n = 0$。
**第二步，算 $b_n$**：$b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} x\sin nx\,dx = \frac{2}{\pi}\int_0^{\pi} x\sin nx\,dx$，分部积分得 $b_n = \frac{2}{n}(-1)^{n+1}$。
**第三步，写展开**：$f(x) \sim 2\sum_{n=1}^{\infty}\frac{(-1)^{n+1}}{n}\sin nx = 2\left(\sin x - \frac{\sin 2x}{2} + \frac{\sin 3x}{3} - \cdots\right)$。

**要点**：锯齿波的谐波振幅 $\frac{2}{n}$ 按 $\frac1n$ 衰减（比方波的 $\frac1n$ 同阶）——「尖锐的信号含高次谐波更多」，这是频谱分析的直觉基础。<span class="marginnote">在 $x = \pi$（间断点），锯齿波左右极限是 $\pi$ 与 $-\pi$，傅里叶级数收敛到平均值 $0$。代入 $x = \frac{\pi}{2}$ 可得 $\frac{\pi}{4} = 1 - \frac13 + \frac15 - \cdots$（莱布尼茨级数）——<strong>傅里叶级数又一次「算」出圆周率</strong>，这正是「级数求值」作为理论工具的价值。</span>

## 8 对照表：泰勒级数与傅里叶级数

| 泰勒级数 | 傅里叶级数 |
| --- | --- |
| 基底：幂函数 $x^n$ | 基底：三角函数 $\sin nx, \cos nx$ |
| 逼近非周期函数 | 逼近周期函数 |
| 在一点展开 | 在区间上展开 |
| 系数：导数 $f^{(n)}(x_0)$ | 系数：积分（内积） |
| 收敛域内等于 $f$ | 连续点等于 $f$，间断点取平均 |

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 系数公式忘 $\frac1\pi$ | $a_n, b_n$ 都带 $\frac1\pi$，$a_0$ 公式带 $\frac1\pi$ 而非 $\frac1{2\pi}$ |
| 奇偶对称性没用 | 偶函数 $b_n=0$，奇函数 $a_n=0$，省一半 |
| 间断点误判为「等于 $f$」 | 间断点收敛到左右极限平均值 |
| 混淆 $a_0$ 的系数 | 常数项是 $\frac{a_0}{2}$ |

## 10 傅里叶分析与现代技术

傅里叶级数是现代技术的数学底座：

- **音频**：MP3 编码把信号分解成频率分量、按人耳敏感度取舍——「感知编码」建立在频谱分析上；
- **图像**：JPEG 用 DCT（离散余弦变换），能量集中于低频系数，高频细节舍去；
- **深度学习**：Transformer 位置编码用不同频率的正弦/余弦——「用频率编码位置」；
- **物理**：分离变量法解波动/热传导方程，解就是傅里叶级数。

「时域 ↔ 频域」的双语能力，是你理解信号处理、语音技术、图像压缩与位置编码的钥匙——而这一切的起点，就是本节的「用正交三角函数系分解周期信号」。

## 11 小结

- **三角函数系正交**：不同频率内积为 0——「不同频率互不干扰」。
- **傅里叶级数**：$f \sim \frac{a_0}{2} + \sum(a_n\cos nx + b_n\sin nx)$，系数是「投影」（内积）。
- **系数公式**：$a_n = \frac1\pi\int f\cos nx\,dx$、$b_n = \frac1\pi\int f\sin nx\,dx$。
- **收敛定理**：连续点收敛到 $f$，间断点收敛到「左右极限平均」。
- 锯齿波/方波的谐波振幅按 $\frac1n$ 衰减，可代入求 $\frac{\pi}{4}$ 级数。
- 应用：频谱分析、JPEG/MP3、偏微分方程、Transformer 位置编码。
