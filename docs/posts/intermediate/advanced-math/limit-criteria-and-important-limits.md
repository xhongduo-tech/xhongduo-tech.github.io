## 为什么从极限存在准则开始

前面我们定义了数列与函数的极限，但定义只回答「极限是什么」，不回答「极限怎么求」。大量极限根本无法直接算出——比如 $\lim\limits_{n\to\infty} \left(1+\frac{1}{n}\right)^n$，你既不能代 $n=\infty$，也无法一眼看出它收敛到哪。<span class="marginnote">这个极限的答案正是自然常数 $e \approx 2.71828$。它不只是教材里的一个数字——后续讲指数函数、对数函数、洛必达、泰勒展开都以它为地基，而深度学习里的 softmax、交叉熵、注意力权重里处处是 $e^x$ 的身影。</span>这一节给出两把「存在性钥匙」：**夹逼准则**与**单调有界准则**。它们不告诉你极限等于几，只负责在无法直接计算时判定「极限存在」，并常能顺手把极限值夹出来。两把钥匙再配上本节的两个重要极限，就构成了整个微积分里最常用的极限弹药库。

## 1 夹逼准则

**夹逼准则（squeeze / sandwich theorem）**：若在 $x_0$ 的某个去心邻域内 $g(x) \le f(x) \le h(x)$，且 $\lim\limits_{x\to x_0} g(x) = \lim\limits_{x\to x_0} h(x) = A$，则 $\lim\limits_{x\to x_0} f(x) = A$ 且等于 $A$。

直觉上，这相当于把 $f$ 夹在上下两块板之间；两块板一起挤到同一个高度 $A$，被夹在中间的那块必然也落在 $A$。<span class="marginnote">夹逼的严格证明靠的是 ε-δ 定义：对任意 $\varepsilon$，上下两块各自进入 $(A-\varepsilon, A+\varepsilon)$，夹在中间的 $f$ 只能跟着进去。这说明「准则」不是新假设，而是极限定义的推论。</span>

数列版本完全类似：若 $a_n \le b_n \le c_n$ 且 $\lim a_n = \lim c_n = A$，则 $\lim b_n = A$。夹逼准则最擅长处理「带振荡」的项，因为振荡项常能被常数夹住。例如求 $\lim\limits_{n\to\infty} \frac{\sin n}{n}$：由 $-1 \le \sin n \le 1$，得 $-\frac{1}{n} \le \frac{\sin n}{n} \le \frac{1}{n}$，两侧都趋于 0，故极限为 0。

## 2 单调有界准则

**单调有界准则**：单调递增且有上界的数列必收敛；单调递减且有下界的数列必收敛。

这条准则的美妙之处在于，它只用「单调」和「有界」两个容易检验的性质就换来了「收敛」——**不需要知道极限值是什么**。单调上升的数列如果永远不会超过某条天花板，那么它的增长空间是有限的，必然在逼近某处停下来。这个「某处」就是极限，而极限值是后面才去求的事。<span class="marginnote">这是分析学里第一类「存在性定理」：先证明存在，再另行计算。后面闭区间上连续函数的性质、级数审敛、方程解的存在性，走的都是这条「先存在、后求值」的路。</span>

单调有界准则的经典舞台是数列 $\left(1+\frac{1}{n}\right)^n$：可证它单调递增且 $<3$，因此收敛——它收敛到的新数就被命名为 $e$。

**辨析｜易错点：** 单调是「有界 ⇒ 收敛」的**充分条件而非必要条件**。例如 $a_n = \frac{(-1)^n}{n}$ 不单调，但它依然收敛到 0。「不单调」绝不能说「发散」。

## 3 两个重要极限

**第一个重要极限**：

$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$

它的关键是「$x \to 0$」且分子分母同趋于 0，属 $\frac{0}{0}$ 型。直觉上，当 $x$ 很小时，$\sin x$ 几乎等于 $x$，比值趋近于 1。

**第二个重要极限**：

$$\lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e, \qquad \lim_{x \to 0} (1 + x)^{1/x} = e$$

两种写法是同一个极限的换装：令 $t = \frac{1}{x}$，第一种中的 $x \to \infty$ 就换成第二种中的 $t \to 0$。它是复利、人口增长、放射性衰变等一切指数过程的理论源头。<span class="marginnote">e 的命名来自欧拉（Euler），也有人说是「指数」（exponential）的缩写。利息按更小的间隔复利、取极限，正是 $(1+\frac{1}{n})^n$ 这个式子的现实原型。</span>

## 4 公式解析：第一个重要极限

$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$

- **第一步，看清结构**：这是 $\frac{0}{0}$ 型，不能直接代值；但 $\sin x$ 与 $x$ 是同阶的小量，比值应当有限。真正要证明的是「比值恰好是 1」。
- **第二步，几何夹逼**：在单位圆上取圆心角 $x$（$0<x<\frac{\pi}{2}$），比较扇形面积 $\frac{x}{2}$、三角形面积 $\frac{\tan x}{2}$ 与内部三角形面积 $\frac{\sin x}{2}$，得 $\sin x < x < \tan x$。除以 $\sin x$ 后取倒数，得到 $1 > \frac{\sin x}{x} > \cos x$。
- **第三步，夹逼收尾**：当 $x \to 0$ 时 $\cos x \to 1$，上下两边都挤向 1，于是中间的 $\frac{\sin x}{x}$ 被夹逼为 1。负半轴由奇偶性自动补上。

第二个重要极限的证明则走单调有界：数列 $\left(1+\frac{1}{n}\right)^n$ 单调递增且以 3 为上界，故收敛，其极限定义为 $e$；再借助夹逼把 $x \to \infty$ 的实数情形与 $n \to \infty$ 的数列情形衔接。

## 5 重要极限的换装技巧

两个重要极限之所以「重要」，是因为大量极限可以经过换元、变形，装进它们的壳里：

- **凑第一个重要极限**：$\lim\limits_{x \to 0} \frac{\sin 2x}{x} = \lim\limits_{x\to 0} 2\cdot \frac{\sin 2x}{2x} = 2$。原则是「让分母与 $\sin$ 的括号里变成同一个趋于 0 的量」。
- **凑第二个重要极限**：$\lim\limits_{x \to 0} (1+3x)^{1/x} = \lim\limits_{x\to 0} \big[(1+3x)^{1/(3x)}\big]^3 = e^3$。原则是「括号里的 1 加小量，指数与这个小量互为倒数」。

**辨析｜易错点：** ① $\lim\limits_{x \to 0} \frac{\sin 2x}{x}$ 不是 1，而是 2——必须把括号内外的 $x$ 配平成 $2x$；② $\lim\limits_{x \to \infty} \left(1+\frac{1}{x^2}\right)^x$ 应化为 $\big[\left(1+\frac{1}{x^2}\right)^{x^2}\big]^{1/x} \to e^0 = 1$，不是 $e$——指数要与小量严格互为倒数；③ $\left(1+\frac{1}{x}\right)^x$ 与 $\left(1+\frac{1}{x}\right)^{2x}$ 的极限分别是 $e$ 与 $e^2$，指数不同答案不同。

## 6 数值算例：准则与重要极限的综合运用

**例 1**：求 $\lim_{n\to\infty}(\sqrt{n^2+1}-n)$。有理化：$\frac{(\sqrt{n^2+1}-n)(\sqrt{n^2+1}+n)}{\sqrt{n^2+1}+n} = \frac{1}{\sqrt{n^2+1}+n}\to 0$。
**例 2**：求 $\lim_{x\to0}\frac{1-\cos x}{x^2}$。用 $1-\cos x = 2\sin^2\frac{x}{2}$，原式 $= \lim_{x\to0} 2\cdot\frac{\sin^2(x/2)}{x^2} = \lim 2\cdot\frac14\cdot\left(\frac{\sin(x/2)}{x/2}\right)^2 = \frac12$。
**例 3**：求 $\lim_{n\to\infty}\left(1+\frac{2}{n}\right)^n$。改写成 $\left[\left(1+\frac{2}{n}\right)^{n/2}\right]^2 \to e^2$——指数与小量 $\frac{2}{n}$ 互为倒数。
**例 4**：夹逼求 $\lim_{n\to\infty}\frac{n\sin n}{n^2+1}$。由 $|\sin n|\le1$，得 $\left|\frac{n\sin n}{n^2+1}\right| \le \frac{n}{n^2+1}\to 0$，故极限为 0。

四个例子各示范一招：有理化、半角公式、指数配平、夹逼。<span class="marginnote">处理极限的完整工具箱到本节已经齐备：<strong>四则运算法则（上节）、夹逼、单调有界、两个重要极限</strong>。剩下的未定型 $\frac00,\frac\infty\infty$ 等，要等到第三章洛必达法则用导数再解。这些「先备弹药」正是为那些更复杂的极限准备的。</span>

## 7 对照表：夹逼准则与单调有界准则

| 夹逼准则 | 单调有界准则 |
| --- | --- |
| 上下夹住目标 | 单调 + 有界 |
| 需要构造 $g$ 与 $h$ | 需要验证单调性与有界性 |
| 结论：极限存在且等于夹住的值 | 结论：极限存在，值待求 |
| 擅长带振荡的项 | 擅长递推数列、$e$ 的构造 |

两把钥匙分工明确：**夹逼给出「极限值」，单调有界给出「存在性」**。前者用于能夹、后者用于能证单调。

## 8 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 重要极限括号内外不配平 | 让 $\sin$ 内部与分母、指数与小量严格匹配 |
| 把 $\left(1+\frac{1}{x^2}\right)^x$ 当 $e$ | 指数要与小量互为倒数，否则是 $e^0=1$ |
| 夹逼方向写反或夹不紧 | 保证 $g \le f \le h$ 且两侧极限相等 |
| 单调有界只验一半 | 递增验上界、递减验下界，缺一不可 |
| 用重要极限时不看 $x$ 的趋势 | $\frac{\sin x}{x}$ 要 $x\to0$，$(1+\frac1x)^x$ 要 $x\to\infty$ |

## 9 两个重要极限为什么「重要」

**第一个**：$\lim_{x\to0}\frac{\sin x}{x}=1$ 给出小角近似 $\sin x \approx x$——单摆周期、工程振动、声学分析全建立在它之上；它是「局部线性化」最早的实例。

**第二个**：$\lim_{n\to\infty}(1+\frac1n)^n = e$ 定义自然常数——连续复利 $A = P(1+\frac{r}{n})^{nt} \to Pe^{rt}$ 就是它的直接应用。更远地看，$e^x$ 是指数族的基底，softmax、交叉熵、高斯函数里处处是它的身影。你在这里建立的「$e$ 是极限过程逼近出来的」，是后续整个指数与对数理论的起点。

## 10 小结

- **夹逼准则**：$g \le f \le h$ 且两侧极限同为 $A$，则 $f$ 的极限为 $A$；专治「带振荡」的式子。
- **单调有界准则**：单调有界 ⇒ 收敛，是「只证存在、不求值」的第一把钥匙；单调是充分条件而非必要条件。
- **第一个重要极限**：$\lim\limits_{x\to 0}\frac{\sin x}{x}=1$，用扇形面积夹逼证明。
- **第二个重要极限**：$\lim\limits_{x\to\infty}(1+\frac{1}{x})^x = e$，由单调有界准则确立，是复利与指数过程的理论源头。
- 使用重要极限的核心是**换装**：让结构严格匹配 $\frac{0}{0}$ 或 $1^\infty$ 的壳，再套公式。
- 夹逼给「极限值」，单调有界给「存在性」，两把钥匙分工互补。
- 极限工具箱已齐：四则、夹逼、单调有界、两大重要极限；未定型留给洛必达。
- 连续复利 $Pe^{rt}$ 是第二个重要极限的直接化身。
- 「先判存在、后求值」的两准则思想，会在微分中值定理与级数审敛里反复登场。
