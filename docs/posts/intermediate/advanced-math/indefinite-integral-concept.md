## 为什么从不定积分开始

前三章是微积分的「微分篇」：已知函数，求它的变化率。现在把镜头倒转——**已知变化率，求原来的函数**。已知瞬时速度求位移、已知边际成本求总成本、已知曲线上每点的切线斜率求曲线方程，都是「已知导数、反求原函数」。这个逆运算就是**不定积分**。它与微分互为逆运算，就像加法与减法、乘法与除法。这一节建立的「原函数 + 积分常数」概念，是整个积分学的出发点：第五章的定积分（求面积）靠它，第七章的微分方程（求满足条件的曲线族）也靠它。<span class="marginnote">「已知导数求原函数」比「已知函数求导数」难得多：求导有机械法则可循，求积分则需要识别「哪个函数的导数长这样」——这正是「求导是科学、求积分是艺术」的含义。积分技巧（换元、分部）的核心都是逆向识别。</span>

## 1 原函数与不定积分

**原函数（antiderivative）**：若在区间 $I$ 上 $F'(x) = f(x)$，则称 $F(x)$ 是 $f(x)$ 在 $I$ 上的一个**原函数**。

**不定积分（indefinite integral）**：$f$ 的全部原函数构成的集合，记作

$$\int f(x)\,dx = F(x) + C$$

其中 $F(x)$ 是 $f$ 的一个原函数，$C$ 为**积分常数**。

**重点：原函数不是唯一的，但彼此只差一个常数。** 若 $F$ 与 $G$ 都是 $f$ 的原函数，则 $G(x) = F(x) + C$——因为 $(G-F)' = 0$，由拉格朗日中值定理推论知 $G-F$ 是常数。<span class="marginnote">「原函数族 = 一条曲线的全体竖直平移」：$\int 2x\,dx = x^2 + C$ 是一族抛物线，彼此只是上下平移。每个具体的 $C$ 对应一条曲线，而「求满足 $F(x_0)=y_0$ 的那一条」就是第七章微分方程初值问题的雏形。</span>

**辨析｜易错点：** ① 不定积分**必须带 $+C$**——写 $\int 2x\,dx = x^2$ 是错的，因为它漏掉了无穷多个原函数。② 原函数存在的前提是 $f$ 在某区间上连续（原函数存在定理，第五章严格化），但在间断点处仍可能没有原函数。③ 记号 $\int f(x)\,dx$ 中的 $dx$ 是积分号的一部分，标明积分变量是 $x$——换变量时不可省略。

## 2 基本积分表

由求导公式「逆读」，得到**基本积分表**（$x$ 在相应区间内）：

| 积分 | 结果 | 积分 | 结果 |
| --- | --- | --- | --- |
| $\int x^\mu\,dx$ | $\frac{x^{\mu+1}}{\mu+1}+C\ (\mu\neq-1)$ | $\int \frac{dx}{x}$ | $\ln|x|+C$ |
| $\int e^x\,dx$ | $e^x+C$ | $\int \sin x\,dx$ | $-\cos x+C$ |
| $\int \cos x\,dx$ | $\sin x+C$ | $\int \sec^2 x\,dx$ | $\tan x+C$ |
| $\int \frac{dx}{1+x^2}$ | $\arctan x+C$ | $\int \frac{dx}{\sqrt{1-x^2}}$ | $\arcsin x+C$ |

<span class="marginnote">这张表是求导公式表的「反向索引」：每一个求导公式 $(F'(x)=f(x))$ 都对应一个积分公式 $\int f(x)\,dx = F(x)+C$。特别提醒 $\int\frac{dx}{x}=\ln|x|+C$ 带<strong>绝对值</strong>——这是从 $(\ln|x|)'=\frac{1}{x}$ 逆读来的，最容易写漏。</span>

## 3 不定积分的线性性质

**不定积分的线性性质**：

$$\int [f(x) \pm g(x)]\,dx = \int f(x)\,dx \pm \int g(x)\,dx$$

$$\int k f(x)\,dx = k \int f(x)\,dx \quad (k \text{ 为常数})$$

两条合起来就是「**逐项积分**」：和差的积分 = 积分的和差，常数因子可以提出积分号。它们直接来自导数运算的线性性——$(F+G)' = F' + G'$、$(kF)' = kF'$。

例：

$$\int (3x^2 + 2\cos x)\,dx = \int 3x^2\,dx + \int 2\cos x\,dx = x^3 + 2\sin x + C$$

**辨析｜易错点：** ① 常数因子可以提出，但**含变量的因子不能随便提出**——$\int x\cos x\,dx \neq x\int\cos x\,dx$，因为 $x$ 是积分变量相关的量。② 两个不定积分相加时，**多个积分常数可以合并成一个 $C$**——不必写 $C_1 + C_2$。③ 逐项积分只对**有限项**的线性组合成立，不能推广到无穷级数（要等到第十二章讨论逐项积分的条件）。

## 4 公式解析：先化简再积分

求 $\int \frac{x^3 - 3x^2 + 2x + 1}{x^2}\,dx$：

- **第一步，先化简（拆项）**：$\dfrac{x^3}{x^2} - \dfrac{3x^2}{x^2} + \dfrac{2x}{x^2} + \dfrac{1}{x^2} = x - 3 + \dfrac{2}{x} + \dfrac{1}{x^2}$。
- **第二步，逐项积分**：$\int x\,dx - 3\int dx + 2\int\frac{dx}{x} + \int x^{-2}\,dx$。
- **第三步，套基本积分表**：$\dfrac{x^2}{2} - 3x + 2\ln|x| + \dfrac{x^{-1}}{-1} + C = \dfrac{x^2}{2} - 3x + 2\ln|x| - \dfrac{1}{x} + C$。

**关键心法**：遇到分式、根式、乘积，**先在积分号内做代数化简，再逐项用积分表**。很多「不会积」的式子，其实只是没先拆开。这与你解复杂方程先化简再套公式的习惯完全一致。<span class="marginnote">「化简优先」在积分里尤其重要，因为积分没有乘积法则——$\int uv$ 没有简单公式。把乘积、分式拆成和差，是唯一的出路。记住：<strong>积分前的代数变形，往往比积分技巧本身更关键</strong>。</span>

## 5 不定积分为什么重要

不定积分看似只是「求导的逆运算」，却牵动整个学科：

**定积分的基石**：第五章的微积分基本定理将证明「$\int_a^b f(x)\,dx = F(b)-F(a)$」——求面积的定积分，靠的正是找原函数。**不定积分是定积分的计算引擎**。
**微分方程的解**：第七章的微分方程「求满足 $y' = f(x)$ 的 $y$」直接就是不定积分；更复杂的方程也以「能积出原函数」为求解前提。
**物理与工程的逆运算**：由加速度求速度、由速度求位移，就是两次积分；由电流求电量、由功率求能量，同理。<span class="marginnote">计算机里的「求积分」走的是另一条路——数值积分（把区间切成小段求和）。两种方法的分工：<strong>解析积分</strong>给公式，<strong>数值积分</strong>给数字。到第九级《数值分析》你会看到，许多解析积不出（或太繁琐）的积分，靠数值方法反而更实际。</span>
- **概率与统计**：概率密度函数的归一化（$\int_{-\infty}^{+\infty} p(x)\,dx = 1$）与期望、方差的计算，全是积分。

## 7 数值算例：先化简再积分的综合运用

**例 1**：$\int\frac{x^4 - 1}{x^2 + 1}\,dx$。分子 $x^4-1 = (x^2-1)(x^2+1)$，约分得 $\int(x^2-1)dx = \frac{x^3}{3} - x + C$——**先因式分解，积分就简单了**。

**例 2**：$\int\frac{1+\cos^2 x}{1+\cos 2x}\,dx$。用 $\cos 2x = 2\cos^2x-1$，分母 $= 2\cos^2x$，原式 $= \int\frac{1+\cos^2x}{2\cos^2x}dx = \int\left(\frac12\sec^2x + \frac12\right)dx = \frac12\tan x + \frac{x}{2} + C$。

**例 3**：$\int e^x(2 + e^{-x})\,dx$。展开 $= \int(2e^x + 1)dx = 2e^x + x + C$。

**要点**：三例的共同心法——「积分前先做代数变形（因式分解、三角恒等、展开）」，把难题降级成基本积分表能直接套的形式。<span class="marginnote">「先化简再积分」的直觉：<strong>积分没有乘法法则，所以一切乘积、分式、复合都要先「拆」成和差</strong>。因式分解、三角恒等、部分分式——这些代数工具在积分里比在代数里还重要。记住这条「化简优先」原则，很多积分题就不难了。</span>

## 8 对照表：求导与积分

| 求导（微分） | 积分（不定积分） |
| --- | --- |
| 有机械法则（四则、链式） | 靠识别与技巧（无乘积法则） |
| 结果唯一 | 结果是一族（+C） |
| 把函数「压缩」 | 把函数「展开」 |
| 简单、机械 | 艺术、需经验 |

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 漏写 $+C$ | 不定积分必带积分常数 |
| 含变量因子提出积分号 | 只有常数因子能提出 |
| 忘 $\int\frac{dx}{x}=\ln|x|+C$ 的绝对值 | 绝对值是 $(\ln|x|)'$ 逆读的必然 |
| 不化简直接「套」 | 先因式分解/三角恒等/展开，再积分 |

## 10 不定积分与计算

不定积分是「反向微分」的完整理论：

- **定积分的引擎**：微积分基本定理把定积分化为找原函数——不定积分是求面积的钥匙；
- **微分方程的解**：$y' = f(x)$ 的解就是不定积分——积分学的第一应用；
- **物理**：速度积分得位移、功率积分得能量——「累积」靠不定积分；
- **数值对照**：解析积分给公式、数值积分给数字，两者互补。

「已知变化率求总量」是人类最常用的数学操作——不定积分正是它的理论框架。

## 11 小结

- **原函数**：$F'(x)=f(x)$；全部原函数写成 $\int f(x)\,dx = F(x)+C$，**积分常数不可漏**。
- 原函数之间只差一个常数，几何上是曲线的竖直平移族。
- **线性性质**：逐项积分、常数因子提出；但含变量的因子不能提出。
- **基本积分表**：由求导公式逆读而来，$\int\frac{dx}{x}=\ln|x|+C$ 别忘绝对值。
- 积分前的**代数化简**往往比积分技巧更重要。
- 求导是科学、求积分是艺术——技巧来自「反向识别 + 化简优先」。
