## 为什么从换元积分法开始

基本积分表只覆盖「正好是某个函数导数」的简单情形，而实际积分大多是「换了一层皮」的复合函数。$\int 2x e^{x^2}\,dx$ 初看无从下手——但注意 $2x$ 恰是 $x^2$ 的导数，而 $e^{x^2}$ 是 $e^u$ 在 $u=x^2$ 处的复合。**换元积分法**利用链式法则的逆向，把「复合函数的积分」还原为「基本积分表」：让 $u = x^2$，则 $du = 2x\,dx$，原式变成 $\int e^u\,du = e^u + C$。这是积分的第一套核心技巧，也是反向传播思想在微积分里的「兄弟」——链式法则的正向用来求导，逆向用来积分。<span class="marginnote">换元法与链式法则互为镜像：$[F(g(x))]' = F'(g(x))g'(x)$ 正向读是求导，反向读就是第一类换元 $\int f(g(x))g'(x)\,dx = \int f(u)\,du$。掌握换元，本质上是掌握「把被积函数看作某个复合函数的导数」的能力。</span>

## 1 第一类换元法（凑微分法）

**第一类换元法**：若 $\int f(u)\,du = F(u) + C$ 且 $u = \varphi(x)$ 可导，则

$$\int f(\varphi(x))\,\varphi'(x)\,dx = \int f(u)\,du = F(\varphi(x)) + C$$

操作上，我们把 $\varphi'(x)dx$「凑」成 $d\varphi(x)$——这就是「凑微分」名字的由来：

$$\int f(\varphi(x))\,\varphi'(x)\,dx \xrightarrow{u=\varphi(x)} \int f(u)\,du$$

例：$\int 2x e^{x^2}\,dx$，令 $u = x^2$，$du = 2x\,dx$，则 $\int e^u\,du = e^u + C = e^{x^2} + C$。

**辨析｜易错点：** 凑微分需要「恰到好处」——被积函数里必须已经藏着 $\varphi'(x)$ 这个因子（或只差一个常数）。$\int e^{x^2}\,dx$ 缺少 $2x$ 因子，就无法直接凑——这正说明凑微分不是万能的，缺因子时就要考虑别的路（或承认积不出来，用误差函数表示）。<span class="marginnote">「差一个常数」可以补：$\int 2x e^{x^2}\,dx$ 若写成 $\int e^{x^2}\,d(x^2)$ 缺了因子，可先观察有没有多余的导数因子。常见的凑微分模式：$\frac{1}{x}dx = d\ln x$、$\cos x\,dx = d\sin x$、$e^x dx = de^x$——把「某个函数」整体看作新变量 $u$。</span>

## 2 第二类换元法

**第二类换元法**：当被积函数含根式等「难积」结构时，反过来引入新变量 $x = \psi(t)$，把积分变成关于 $t$ 的形式：

$$\int f(x)\,dx \xrightarrow{x = \psi(t)} \int f(\psi(t))\,\psi'(t)\,dt$$

要求 $\psi(t)$ 单调可导且 $\psi'(t) \neq 0$，最终结果还要代回 $t = \psi^{-1}(x)$。常用于消去根号：

- 含 $\sqrt{a^2 - x^2}$：令 $x = a\sin t$；
- 含 $\sqrt{a^2 + x^2}$：令 $x = a\tan t$；
- 含 $\sqrt{x^2 - a^2}$：令 $x = a\sec t$。

例：$\int \sqrt{1 - x^2}\,dx$，令 $x = \sin t$（$-\frac{\pi}{2}\le t\le\frac{\pi}{2}$），则 $dx = \cos t\,dt$，$\sqrt{1-x^2} = \cos t$，积分变为 $\int \cos^2 t\,dt$——降幂后用积分表可解，最后代回 $t = \arcsin x$。<span class="marginnote">三角换元的几何直觉：$\sqrt{a^2-x^2}$ 是「以 $a$ 为半径的圆的纵坐标」，令 $x=a\sin t$ 相当于把圆参数化，根号变成纯粹的 $\cos t$——几何结构被三角恒等式吸收。第二类换元是「把积分的困难搬给三角恒等式」去解决。</span>

## 3 换元法的选择策略

两种换元方向相反，如何选择是初学者最大的困惑：

| 情形 | 选择 | 思路 |
| --- | --- | --- |
| 被积函数是「复合函数 × 内层导数」 | 第一类（凑微分） | 令 $u$ = 内层函数 |
| 被积函数含根式、难处理的结构 | 第二类（代换） | 令 $x = $ 某种函数消根式 |
| 含 $\sqrt{a^2-x^2}$ | $x=a\sin t$ | 根号变 $\cos t$ |
| 含 $\sqrt{x^2\pm a^2}$ | $x=a\tan t$ 或 $a\sec t$ | 根号变 $\sec t$ 或 $\tan t$ |

<span class="marginnote">判别口诀：<strong>「导数因子在、内层清出来」用凑微分；「根式挡路、变量替换」用第二类</strong>。第一类换元是「换变量等于内层函数」，第二类是「换变量等于整体 $x$」——方向相反，但都是把积分表外的情况变回积分表内。</span>

**辨析｜易错点：** 第二类换元代回时容易错：结果是用 $t$ 表示的，必须把 $t = \psi^{-1}(x)$ 代回去，有时还要画「直角三角形」还原三角函数的复合表达式（如 $\sin t = x$ 时 $\cos t = \sqrt{1-x^2}$）。

## 4 公式解析：含根式的第二类换元

求 $\int \frac{dx}{x^2\sqrt{x^2 + 1}}$：

**第一步，选代换**：含 $\sqrt{x^2+1}$，令 $x = \tan t$（$-\frac{\pi}{2}<t<\frac{\pi}{2}$），则 $dx = \sec^2 t\,dt$，$\sqrt{x^2+1} = \sec t$。
**第二步，代入化简**：$\int \dfrac{\sec^2 t\,dt}{\tan^2 t \cdot \sec t} = \int \dfrac{\sec t}{\tan^2 t}\,dt = \int \dfrac{\cos t}{\sin^2 t}\,dt$。
**第三步，凑微分**：$\int \dfrac{d(\sin t)}{\sin^2 t} = -\dfrac{1}{\sin t} + C$。
**第四步，代回**：$\sin t = \dfrac{x}{\sqrt{x^2+1}}$（由 $\tan t = x$ 画直角三角形可得），故原式 $= -\dfrac{\sqrt{x^2+1}}{x} + C$。

这四步展现了第二类换元的完整循环：**代换 → 化简 → 积分 → 代回**。最后一步的「直角三角形还原」是高频出错点——务必画图确认各三角函数的表达式。

## 5 换元法的应用图景

换元法不只是积分技巧，它的思想贯穿更广：

**微分方程**：可分离变量方程 $\frac{dy}{dx} = g(x)h(y)$ 的解法本质就是两边分别凑微分——$\frac{dy}{h(y)} = g(x)dx$ 后各自积分。
**概率论**：计算正态分布、指数分布的期望与方差时，换元（特别是「凑 $\sigma\sqrt{2\pi}$」的标准正态变换）是核心操作。<span class="marginnote">标准正态变换 $z = \frac{x-\mu}{\sigma}$ 是统计学的头号换元——它把任意正态分布「搬」到标准正态，让查表与数值计算成为可能。你在《概率论与数理统计》里会频繁使用这个换元。</span>
- **数值积分**：高斯求积公式的「换元到标准区间 $[-1,1]$」同样是换元思想——把积分区间标准化，才能套用固定的求积节点与权重。
- **计算机科学**：变量替换在算法复杂度分析（主定理）、组合计数（生成函数）里也频繁出现——「换个变量让问题变简单」是普遍的数学策略。

## 6 小结

- **第一类换元（凑微分）**：$\int f(\varphi(x))\varphi'(x)dx = \int f(u)du$，令 $u$ = 内层函数。
- **第二类换元**：$x = \psi(t)$ 消根式，常用三角代换，结果要代回。
- 两种换元方向相反：凑微分「内层提出来」，第二类「整体代进去」。
- 三角代换的三种模式：$\sqrt{a^2-x^2}\to\sin$、$\sqrt{a^2+x^2}\to\tan$、$\sqrt{x^2-a^2}\to\sec$。
- 换元法通向微分方程、概率统计与数值积分，是「变量替换简化问题」的普遍智慧。
