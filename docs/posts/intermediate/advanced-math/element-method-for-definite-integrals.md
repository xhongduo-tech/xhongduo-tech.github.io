## 为什么从元素法开始

第五章学会了「算定积分」，但面对新问题——求体积、求弧长、求功、求压力——怎么知道该用哪个积分？**元素法（微元法）**就是连接「实际问题」与「定积分」的翻译器：它教你如何把一个连续变化的量拆成「无穷多个微元」，每个微元用局部近似算出，再积分加总。它是定积分应用的通用方法论，也是「微分→积分」双向思维的集大成：先微分（切微元），再积分（加总）。<span class="marginnote">元素法的工作流程：<strong>分割 → 取微元 → 近似 → 求和（积分）</strong>。它与定积分定义的黎曼和四步完全对应——微元 $dU = f(x)\,dx$ 是「一个薄片的贡献」，$\int_a^b dU$ 是「所有薄片的和」。学会元素法，等于掌握了把任何「连续总量」问题翻译成定积分的通用语法。</span>

## 1 元素法的基本思想

要求某个量 $U$，它「分布在」区间 $[a,b]$ 上且随 $x$ 连续累积。元素法四步：

1. **选变量定区间**：确定哪个变量驱动 $U$ 的变化（如 $x$），写出 $U$ 对应的区间 $[a,b]$；
2. **取微元**：任取小区间 $[x, x+dx]$，把 $U$ 在这个区间内的增量记为 $dU$；
3. **近似表达**：用「局部近似」写出 $dU = f(x)\,dx$，其中 $f(x)$ 是 $U$ 在 $x$ 处的「密度」（单位长度贡献）；
4. **积分求和**：$U = \int_a^b f(x)\,dx$。

**关键：$dU = f(x)\,dx$ 中的 $f(x)$ 必须是「易算的局部量」**——薄片的面积、质量、功等，在微元尺度上用常量的近似公式即可。

**辨析｜易错点：** ① 微元 $dU$ 的近似必须精确到「一阶」——丢掉的 $o(dx)$ 在积分取极限后不影响结果（与微分定义里 $\Delta y = dy + o(\Delta x)$ 同构）。② 微元的「密度」$f(x)$ 要与积分变量一致，不要混用不同的变量（如用 $x$ 作积分变量却把 $y$ 方向的量当密度）。③ 写微元前先确认「单位」——积分的量纲 = $f(x)$ 量纲 × $dx$ 量纲，是自检的第一道关。

## 2 元素法从哪里来：回顾面积

面积是元素法最直观的样板。曲边梯形面积 $A = \int_a^b f(x)\,dx$ 的元素法视角：

**取微元**：区间 $[x, x+dx]$ 上的面积微元 $dA = f(x)\,dx$——一个高 $f(x)$、宽 $dx$ 的细矩形；
**积分加总**：$A = \int_a^b dA = \int_a^b f(x)\,dx$。

矩形微元在「无穷细」的极限下逼近曲线下的薄片——这正是定积分的定义本身。<span class="marginnote">元素法把定积分的定义「倒过来用」：先相信「切成薄片再求和」能给出正确总量，再具体找出每个薄片的贡献表达式 $dU$。它比定义更灵活，因为它允许你为不同问题定制不同的「薄片形状」——面积用矩形、体积用薄饼、弧长用弦段。</span>

## 3 公式解析：元素法的「密度」如何确定

用元素法求：把区间 $[0,1]$ 上的「密度函数 $\rho(x) = x$」的细杆质量。

**第一步，选变量**：质量沿 $x$ 分布，区间 $[0,1]$，密度 $\rho(x)=x$。
**第二步，取微元**：微元段 $[x, x+dx]$ 的质量 $dM = \rho(x)\,dx = x\,dx$——**密度 × 长度**，在微元尺度上密度视为常数。
**第三步，积分**：$M = \int_0^1 x\,dx = \frac{1}{2}$。

这里「密度」就是单位长度的贡献 $f(x)$。若密度恒定（$\rho$ 常数），则 $M = \rho\int_0^1 dx = \rho$——退化为「密度 × 长度」。**元素法的普适性：任何「沿一维连续分布的量」都能用「密度 × 微元长」写出微元。**

## 4 元素法与黎曼和的统一

元素法看起来像「猜」，其实是定积分的逆用。两者的关系可以用一张对照表看清：

| 定积分定义 | 元素法 |
| --- | --- |
| 分割区间 | 选变量定区间 |
| 近似 $f(\xi_i)\Delta x_i$ | 写出微元 $dU = f(x)dx$ |
| 求和 $\sum$ | 积分 $\int$ |
| 取极限 $\lambda\to0$ | 微元取到无穷细 |

<span class="marginnote">理解这层对应后，元素法不再是「碰巧对」，而是黎曼和的形式化缩写：$dU = f(x)dx$ 就是「第 $i$ 块贡献」$f(\xi_i)\Delta x_i$ 的连续版写法，积分号就是取极限后的求和号。这也解释了为什么「把 $dx$ 当小量来乘」在物理推导里合法——它严格对应着黎曼和的极限过程。</span>

现代意义上的元素法还被「无限细分」思想推广到多变量：重积分（第十章）把一个薄片推广为面积微元 $dA$，曲线曲面积分（第十一章）推广为弧长微元 $ds$、面积微元 $dS$——**元素法是你理解全书积分应用的通用钥匙**。

## 5 小结

- **元素法四步**：选变量定区间 → 取微元 → 局部近似 $dU=f(x)dx$ → 积分加总。
- 微元是「单位长度的贡献 × $dx$」，近似必须精确到一阶。
- 元素法是黎曼和的「连续版缩写」，两者完全对应。
- 面积、体积、弧长、功、压力等一切「连续总量」问题，都可用元素法翻译成定积分。
- 它是理解重积分与曲线曲面积分微元 $dA$、$ds$、$dS$ 的通用钥匙。

在下一节，我们将用元素法处理几何量——平面面积、体积与弧长，即**定积分在几何学上的应用**。
