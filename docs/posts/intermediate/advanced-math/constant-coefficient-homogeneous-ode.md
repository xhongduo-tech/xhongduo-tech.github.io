## 为什么从常系数齐次线性微分方程开始

上一节建立了通解结构理论，但「找基本解组」还要具体算。当方程系数是**常数**时，出现了一个惊人的简化：解一定是指数函数 $y = e^{rx}$ 的线性组合——代入方程后，$e^{rx}$ 被约掉，剩下一个**代数方程**（特征方程）。于是「解微分方程」变成了「解代数方程」，这是整个微积分里最漂亮的降维之一。<span class="marginnote">为什么 $e^{rx}$ 是常系数线性方程的「万能试解」？因为 $e^{rx}$ 求导后仍是同类（$(e^{rx})^{(k)} = r^k e^{rx}$），代入 $y''+py'+qy=0$ 后每一项都变成「常数 × $e^{rx}$」，提出 $e^{rx}$ 就只剩特征方程 $r^2+pr+q=0$。<strong>微分被翻译成了代数</strong>。</span>振动、电路、人口、控制系统，处处是常系数方程——本节是这些应用的计算引擎。

## 1 特征方程与通解

**常系数齐次线性方程**：

$$y'' + p\,y' + q\,y = 0, \qquad p, q \text{ 为常数}$$

设 $y = e^{rx}$，代入得 $e^{rx}(r^2 + pr + q) = 0$，因为 $e^{rx}\neq0$，得到**特征方程**

$$r^2 + p r + q = 0$$

特征方程是二次方程，其根分三种情形，对应三种通解：

| 特征根 | 通解 |
| --- | --- |
| 两个不等实根 $r_1 \neq r_2$ | $y = C_1e^{r_1x} + C_2e^{r_2x}$ |
| 二重实根 $r_1 = r_2 = r$ | $y = (C_1 + C_2x)e^{rx}$ |
| 共轭复根 $r = \alpha \pm i\beta$ | $y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$ |

<span class="marginnote">三种情形的通解都来自「两个线性无关解」：实根情形是 $e^{r_1x}$ 与 $e^{r_2x}$；重根情形第一解 $e^{rx}$、第二解 $xe^{rx}$（用常数变易或极限推导）；复根情形用欧拉公式 $e^{(\alpha\pm i\beta)x}$ 的实虚部重组。三个公式不要死背，理解「基本解组怎么来」就能推。</span>

**辨析｜易错点：** 重根时第二解是 $xe^{rx}$ 而非另一个 $e^{rx}$（两个 $e^{rx}$ 线性相关，不构成基本解组）。「乘 $x$」是对重根的修正——它的来源可理解为 $\lim_{r_2\to r_1}\frac{e^{r_2x}-e^{r_1x}}{r_2-r_1}$。

## 2 高阶常系数齐次方程

$n$ 阶常系数齐次方程 $y^{(n)} + p_1y^{(n-1)} + \cdots + p_ny = 0$ 的特征方程为

$$r^n + p_1r^{n-1} + \cdots + p_{n-1}r + p_n = 0$$

基本解组由特征根的**重数**决定：

- **单重实根** $r$：贡献一个解 $e^{rx}$；
- **$k$ 重实根** $r$：贡献 $k$ 个解 $e^{rx}, xe^{rx}, \ldots, x^{k-1}e^{rx}$；
- **单重复根** $\alpha \pm i\beta$：贡献 $e^{\alpha x}\cos\beta x$ 与 $e^{\alpha x}\sin\beta x$；
- **$k$ 重复根**：贡献 $e^{\alpha x}\cos\beta x, xe^{\alpha x}\cos\beta x, \ldots$ 等共 $2k$ 个解。

基本解组的总个数 = 方程阶数 $n$。<span class="marginnote">「根的重数决定解的个数与形态」——每个特征根都「发」出等于其重数的线性无关解。这与矩阵特征值的代数重数、广义特征向量完全同构：<strong>代数方程根的「多重性」翻译成解空间的「维度」</strong>。到《线性代数》与《常微分方程》你会看到这背后的矩阵指数理论。</span>

## 3 公式解析：三种情形的完整例题

**情形一：不等实根。** 解 $y'' - 3y' + 2y = 0$：

**第一步，写特征方程**：$r^2 - 3r + 2 = (r-1)(r-2) = 0$，根 $r=1, 2$。
**第二步，套通解**：$y = C_1e^{x} + C_2e^{2x}$。

**情形二：二重根。** 解 $y'' - 2y' + y = 0$：

**第一步，特征方程**：$r^2 - 2r + 1 = (r-1)^2 = 0$，二重根 $r=1$。
**第二步，通解**：$y = (C_1 + C_2x)e^{x}$。

**情形三：共轭复根。** 解 $y'' + y = 0$：

**第一步，特征方程**：$r^2 + 1 = 0$，根 $r = \pm i$，即 $\alpha=0$、$\beta=1$。
**第二步，通解**：$y = e^{0\cdot x}(C_1\cos x + C_2\sin x) = C_1\cos x + C_2\sin x$。

**关键**：复根情形 $\alpha=0$ 说明没有指数放大/衰减——纯振荡，这正是简谐振动的数学表述（$y'' + \omega^2 y = 0$ 的解是 $\cos\omega x$ 与 $\sin\omega x$）。

把通解接上初始条件，就是完整的初值问题。求解 $y'' - 3y' + 2y = 0$ 满足 $y(0)=1$、$y'(0)=3$：

**第一步，写通解**：由特征根 $r=1,2$ 得 $y = C_1e^x + C_2e^{2x}$。
**第二步，代初始条件**：$y(0) = C_1 + C_2 = 1$；$y' = C_1e^x + 2C_2e^{2x}$，$y'(0) = C_1 + 2C_2 = 3$。
**第三步，解方程组**：相减得 $C_2 = 2$，于是 $C_1 = -1$，特解 $y = -e^x + 2e^{2x}$。

**关键**：通解含两个任意常数，需要两个条件（$y$ 与 $y'$）定出——**「先通解、再定常数」是初值问题的标准流程**，与一阶情形一脉相承。

## 4 特征方程的物理解读

特征根的类型直接决定解的物理行为，这是常系数方程在物理里最有价值的地方：

**实根（正）**：$e^{rx}$ 指数爆炸——不稳定系统（如正反馈）；
**实根（负）**：$e^{rx}$ 指数衰减——稳定系统（如 RC 放电）；
**共轭复根（$\alpha<0$）**：衰减振荡——阻尼振动；
**共轭复根（$\alpha=0$）**：等幅振荡——无阻尼简谐振动；
**共轭复根（$\alpha>0$）**：增幅振荡——系统失稳。

<span class="marginnote"><strong>特征根的实部定稳定性（衰减还是增长），虚部定振荡频率</strong>——这是控制理论、信号系统里「极点位置决定系统行为」的全部内容。控制系统的极点（特征根）落在复平面左半平面则稳定，右半平面则发散。你在这里学的一阶知识，到《自动控制原理》会以「根轨迹」「稳定性判据」的面目回归。</span>

**应用实例**：弹簧-质量系统 $my'' + ky = 0$（无阻尼），特征方程 $mr^2 + k = 0$，根 $r = \pm i\sqrt{k/m}$，通解 $y = C_1\cos\omega t + C_2\sin\omega t$，其中 $\omega = \sqrt{k/m}$ 是固有角频率——周期 $T = 2\pi\sqrt{m/k}$，正是高中物理的简谐振动公式。

若加入阻尼项 $my'' + cy' + ky = 0$，特征根可能从纯虚根变为「负实部复根」（欠阻尼）或「两个负实根」（过阻尼）：前者是衰减振荡，后者是单调回归平衡——**阻尼大小决定特征根类型，进而决定系统「抖几下才停」还是「不抖直接停」**，这是 §4 物理解读表在真实系统上的第一次落地。

## 5 常系数齐次方程的求解流程

**四步流程**：

1. **写特征方程**：把 $y^{(k)}$ 换成 $r^k$；
2. **解特征方程**：求根（实根、重根、复根）；
3. **按根的类型写基本解组**：每种根「发」出对应个数的线性无关解；
4. **线性组合出通解**：$y = \sum C_i y_i$。

**辨析｜易错点：** ① 特征方程写错符号最常见——把 $y''+py'+qy=0$ 换成 $r^2+pr+q=0$ 时，$y'$ 的系数 $p$ 要原样搬进一次项，勿丢符号；② 复根写成 $\alpha\pm i\beta$ 时，通解是 $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$，**不要把 $\beta$ 与 $\alpha$ 位置互换**；③ 重根情形第二个解是 $xe^{rx}$，若误写成 $e^{rx}$（与第一个线性相关）则「通解」少了自由度，无法满足任意初值。

<span class="marginnote">这套流程把「微分方程」彻底代数化：求解过程不需要任何积分——只做代数因式分解与线性组合。这就是常系数方程的「红利」：<strong>指数函数是线性常微分方程的特征函数</strong>。到第十二章你会看到，$e^{rx}$ 也是傅里叶级数与拉普拉斯变换的基函数，同一主角在不同舞台反复登场。</span>

## 6 小结

- **常系数齐次方程** $y''+py'+qy=0$：设 $y=e^{rx}$ 得**特征方程** $r^2+pr+q=0$。
- 三种通解：不等实根（两指数和）、二重根（$(C_1+C_2x)e^{rx}$）、共轭复根（$e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$）。
- 高阶方程：每个特征根按重数「发」出线性无关解，解总数 = 阶数。
- 特征根实部定稳定性、虚部定频率——控制理论与物理的「极点语言」。
- 求解流程：写特征方程 → 解根 → 按根写基本解组 → 线性组合。
- 初值问题：通解 + 两个初始条件定出 $C_1,C_2$；特征根符号与重根第二解是高频易错点。
