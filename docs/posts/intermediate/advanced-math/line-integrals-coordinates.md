## 为什么从对坐标的曲线积分开始

第一型曲线积分沿曲线累加「标量密度」，但变力沿曲线做的功需要「矢量点积」：力 $\mathbf{F}$ 沿位移 $d\mathbf{s}$ 的分量 × 弧长微元。**对坐标的曲线积分（第二型曲线积分）**就是「沿带方向的曲线，把矢量场与切向量点积后累加」的积分。它是「功」的正确数学表述，也是通向格林公式、高斯公式、斯托克斯公式——本章后半部分的三大公式——的入口。物理中的环路功、环流量、电势差，全是对坐标曲线积分。<span class="marginnote">第二型曲线积分的物理原型：<strong>$W = \int_L \mathbf{F}\cdot d\mathbf{s}$ 是变力沿曲线做的功</strong>。力沿路径切向的分量做功，法向分量不做功——所以积分里是「点积」。方向反转，位移反向，功变负——这正是「对坐标」积分的「方向敏感」来源。</span>

## 1 对坐标曲线积分的定义

设 $L$ 为从 $A$ 到 $B$ 的有向光滑曲线，$\mathbf{F} = P(x,y)\mathbf{i} + Q(x,y)\mathbf{j}$ 是平面向量场。将 $L$ 分成 $n$ 小段，第 $i$ 段沿方向的位移微元为 $(\Delta x_i, \Delta y_i)$，取点 $(\xi_i,\eta_i)$，作和

$$\sum_{i=1}^{n}\left[P(\xi_i,\eta_i)\Delta x_i + Q(\xi_i,\eta_i)\Delta y_i\right]$$

取极限得**对坐标的曲线积分**：

$$\int_L P\,dx + Q\,dy = \int_L P(x,y)\,dx + \int_L Q(x,y)\,dy$$

记向量形式：$\int_L \mathbf{F}\cdot d\mathbf{s} = \int_L \mathbf{F}\cdot(dx, dy)$。

**与方向的关系**：$\int_{-L} P\,dx + Q\,dy = -\int_L P\,dx + Q\,dy$——**反向变号**（$dx,dy$ 都改变符号）。<span class="marginnote">方向敏感是第二型积分的标志：功与路径方向有关，顺着力做正功、逆着力做负功。这也解释了为什么「闭合曲线积分」$\oint_L$ 可以非零——沿闭路转一圈，若力场「有旋」，净功不一定为零。这个「环路积分」正是下一节格林公式与第 69 节斯托克斯公式的主角。</span>

## 2 对坐标曲线积分的计算

设 $L$ 的参数方程 $\begin{cases}x = \varphi(t)\\ y = \psi(t)\end{cases}$（$t$ 从 $\alpha$ 到 $\beta$，对应起点到终点），则

$$\int_L P\,dx + Q\,dy = \int_\alpha^\beta\left[P(\varphi(t),\psi(t))\,\varphi'(t) + Q(\varphi(t),\psi(t))\,\psi'(t)\right]dt$$

**与第一型的计算差异**：第一型把 $ds$ 换成 $\sqrt{\varphi'^2+\psi'^2}dt$（正因子）；第二型把 $dx,dy$ 分别换成 $\varphi'dt, \psi'dt$——**$t$ 的积分限必须按「从起点到终点」的方向定**（可能 $\alpha>\beta$）。

**公式解析：变力做功的计算**

求 $\mathbf{F} = (x+y, x-y)$ 沿直线 $y=x$ 从 $(0,0)$ 到 $(1,1)$ 做的功：

- **第一步，参数化**：$x=t$、$y=t$，$0\le t\le1$。$dx = dt$、$dy = dt$。
- **第二步，代入**：$\int_L (x+y)dx + (x-y)dy = \int_0^1 (2t)\,dt + \int_0^1 (0)\,dt = \int_0^1 2t\,dt = 1$。
- **第三步，方向检查**：若从 $(1,1)$ 到 $(0,0)$（反向），$t$ 从 1 到 0，积分变为 $-1$——功变号，符合物理。

**关键**：第二型积分的计算步骤——**参数化 → 换 $dx,dy$ → 按起点终点定积分限 → 一元积分**。积分限的方向是第二型独有的「额外负担」，也是与第一型的核心区别。

## 3 两类曲线积分的联系

两类曲线积分通过「切向量」联系。设曲线 $L$ 在点 $(x,y)$ 处的单位切向量 $\mathbf{T} = (\cos\alpha, \cos\beta)$，则

$$\int_L P\,dx + Q\,dy = \int_L (P\cos\alpha + Q\cos\beta)\,ds$$

即 **$\mathbf{F}\cdot d\mathbf{s} = (\mathbf{F}\cdot\mathbf{T})\,ds$**——第二型积分 = 第一型积分中「力沿切向的分量」对弧长累加。这就是「功 = 切向力分量 × 弧长」的积分表述。<span class="marginnote">两类曲线积分的关系是「矢量场 × 切向量」：<strong>$\int\mathbf{F}\cdot d\mathbf{s} = \int(\mathbf{F}\cdot\mathbf{T})ds$</strong>。切向量 $\mathbf{T}$ 把「带方向的位移微元」与「不带方向的弧长微元」连接起来——这是理解「为什么第二型也叫『沿场做功』」的关键桥。</span>

## 4 应用：环流量与平面场

**环流量（circulation）**：沿闭曲线 $L$ 的第二型积分 $\oint_L \mathbf{F}\cdot d\mathbf{s}$ 称为场沿闭路的**环流量**——「绕一圈的净功/净环流」。环流量刻画了场的「旋转性」：

若 $\oint_L \mathbf{F}\cdot d\mathbf{s} = 0$ 对所有闭路成立，场是**保守场**（无旋），线积分与路径无关——这时积分只依赖起点终点，存在势函数（第 65 节格林公式将严格讨论）；
若环流量非零，场「有旋」，绕圈能获得净功（如漩涡水流推船绕一圈做功）。

<span class="marginnote">环流量的直觉：<strong>「绕一圈转下来的净效果」</strong>。稳定水流绕漩涡转一圈，沿途水流做功不抵消（有旋）；保守力（如重力）绕一圈净功为零（无旋）。「有旋 vs 无旋」的区分是场论的核心——下一节格林公式会把「环流量」与「区域内的旋度（散度）」精确相连。</span>

**空间曲线**：$\int_L P\,dx + Q\,dy + R\,dz$ 沿空间曲线，同样参数化计算，物理上是三维力场做功。

## 6 数值算例：沿不同路径的积分对比

求 $I = \int_L y\,dx + x\,dy$ 从 $(0,0)$ 到 $(1,1)$，分别沿两条路径。

**路径一（抛物线 $y=x^2$）**：参数化 $x=t$、$y=t^2$（$0\le t\le1$），$dx=dt$、$dy=2t\,dt$。$I = \int_0^1 t^2\,dt + \int_0^1 t\cdot 2t\,dt = \int_0^1 (t^2 + 2t^2)dt = \int_0^1 3t^2 dt = 1$。
**路径二（直线 $y=x$）**：$x=t$、$y=t$，$dx=dt$、$dy=dt$。$I = \int_0^1 t\,dt + \int_0^1 t\,dt = \int_0^1 2t\,dt = 1$。

**发现**：两条路径结果相同，因为 $y\,dx + x\,dy$ 恰好是 $xy$ 的全微分 $d(xy)$——积分值只取决于端点 $xy\big|^{(1,1)}_{(0,0)} = 1$，与路径无关。<span class="marginnote">「<strong>全微分形式的积分与路径无关</strong>」是保守场的第一课：若 $Pdx + Qdy = d\varphi$（某函数的全微分），则 $\int_L = \varphi(B) - \varphi(A)$，只依赖端点。重力、静电力都是这类「保守场」。到格林公式与《向量分析与场论》，「什么条件下积分与路径无关」会被彻底回答。</span>

## 7 对照表：第一型与第二型曲线积分

| 第一型（对弧长） | 第二型（对坐标） |
| --- | --- |
| $\int_L f\,ds$ | $\int_L P\,dx + Q\,dy$ |
| 标量场 × 弧长 | 向量场 · 位移微元 |
| 与方向无关 | 方向敏感，反向变号 |
| $ds = \sqrt{\varphi'^2 + \psi'^2}\,dt$ | $dx=\varphi'\,dt,\ dy=\psi'\,dt$ |
| 弧长、质量、电荷量 | 功、环流量 |

记法区分：**第一型「乘弧长」，第二型「点积位移」**；一个是「量」，一个是「功」。

## 8 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 第二型积分限写成 $\alpha<\beta$ | 按起点到终点定限，方向反向则 $\alpha>\beta$ |
| 参数化后忘换 $dx,dy$ | 每一步都写 $dx = \varphi'(t)dt,\ dy = \psi'(t)dt$ |
| 把第二型当第一型乘以 $\sqrt{\varphi'^2+\psi'^2}$ | 第二型不乘弧长因子，直接换 $dx,dy$ |
| 假定闭路积分必为零 | 只有保守场（全微分形式）闭路积分才为零 |

## 9 第二型积分：三大公式的入口

对坐标的曲线积分是本章后半部的真正主角：

- **环流量** $\oint_L \mathbf{F}\cdot d\mathbf{s}$ 经**格林公式**化为区域上的二重积分——「边界积分 ↔ 内部积分」的连接；
- **通量**与**环量**经**高斯公式、斯托克斯公式**推广到三维曲面与空间曲线。

物理上，功、环流量、电势差、磁通量全是对坐标的积分。理解「方向敏感 + 点积结构」，就握住了通向这些公式的钥匙。第一型与第二型的分工，也将在三重积分与曲面积分中再次出现。

## 10 小结

- **第二型曲线积分**：$\int_L P\,dx + Q\,dy = \int_L \mathbf{F}\cdot d\mathbf{s}$——矢量场沿曲线点积累加。
- **反向变号**：$\int_{-L} = -\int_L$，方向敏感是第二型的标志。
- 计算：参数化 → 换 $dx,dy$ → 按起点终点定限 → 一元积分。
- 两类联系：$\int \mathbf{F}\cdot d\mathbf{s} = \int(\mathbf{F}\cdot\mathbf{T})ds$——切向分量做功。
- **全微分形式与路径无关**：$Pdx+Qdy = d\varphi$ 时 $\int_L = \varphi(B)-\varphi(A)$。
- 保守场闭路积分为零，一般场则非零——这正是「有旋 vs 无旋」的由来。
- **环流量** $\oint_L \mathbf{F}\cdot d\mathbf{s}$ 刻画场的旋转性，是保守场判定与格林公式的入口。
