## 为什么从曲率开始

单调性和凹凸性描述了曲线的「走向」，但「弯得多厉害」还没有量化。同样的弯，高速铁路的转弯半径是几千米，而盘山公路的急弯半径只有几十米——**弯曲程度**是工程安全的生命线。曲率就是弯曲程度的精确度量：它回答「曲线上一点处，方向变化得有多快」。曲率半径则给出「在这一点，曲线近似于半径多大的圆」。铁路选线、公路设计、齿轮齿廓、汽车转向，处处用到曲率；而它还是微分几何——研究曲线曲面形状的学科——的第一块基石。<span class="marginnote">你已经在第二级的《微分几何》里见过曲线论的经典框架，本节是它的微积分版本：从「切线方向角对弧长的变化率」出发定义曲率。等进入微分几何，$K$、$\kappa$、曲率圆这些概念会从平面曲线推广到空间曲线乃至曲面。</span>

## 1 曲率的定义

设曲线 $y = f(x)$ 在点 $M$ 处的切线倾角为 $\alpha$，当点沿曲线移动一段弧长 $\Delta s$ 时，切线倾角变化 $\Delta \alpha$。**平均曲率**为 $\left|\dfrac{\Delta\alpha}{\Delta s}\right|$，**曲线在 $M$ 处的曲率**为

$$K = \lim_{\Delta s \to 0} \left|\frac{\Delta\alpha}{\Delta s}\right| = \left|\frac{d\alpha}{ds}\right|$$

直觉：曲率 = **切线方向角对弧长的变化率**。直线段方向角不变，曲率为 0；圆上每点方向角对弧长匀速变化，曲率为常数 $\frac{1}{R}$。<span class="marginnote">为什么用「对弧长」而不是「对 $x$」？因为弧长是曲线自身的长度参数，与坐标系无关——用弧长度量才能得到「曲线固有」的弯曲程度。这一点到微分几何里会发展为「弧长参数化」的思想。</span>

**辨析｜易错点：** 曲率与「斜率」「二阶导数」的区别必须分清。$y=x^2$ 在原点 $y''=2>0$，看似「很弯」，但曲线在原点附近接近直线，实际曲率 $K = \frac{2}{(1+0)^{3/2}} = 2$ 不算大；$y=\sin x$ 在零点 $y''=0$，曲率却为 0。**凹不凹看二阶导数，弯多弯少看曲率，两者不是一回事。**

## 2 曲率的计算公式

设 $y = f(x)$ 二阶可导，则曲率

$$K = \frac{|y''|}{(1 + y'^2)^{3/2}}$$

其中 $y'$、$y''$ 是对 $x$ 的导数。公式来源：$ds = \sqrt{1+y'^2}\,dx$（弧长微分），$\alpha = \arctan y'$，故 $\dfrac{d\alpha}{dx} = \dfrac{y''}{1+y'^2}$，相除取绝对值即得。

**曲率半径**定义为

$$R = \frac{1}{K} = \frac{(1 + y'^2)^{3/2}}{|y''|}$$

直觉：把曲线在该点「弯成的弧」近似为一个圆，这个圆的半径就是曲率半径 $R$，圆心称为**曲率中心**，圆称为**曲率圆**（密切圆）。<span class="marginnote">曲率圆的意义：它是与曲线在 $M$ 处「贴得最紧」的圆——不仅切线重合，二阶信息也重合。铁路弯道设计用的「缓和曲线」正是让曲率从 0 平滑过渡到目标值，避免离心力突变。密切圆的「最贴合」思想也是泰勒近似在几何里的对应物。</span>

若曲线由参数方程 $\begin{cases}x = \varphi(t)\\ y = \psi(t)\end{cases}$ 给出，则曲率

$$K = \frac{|\varphi'(t)\psi''(t) - \psi'(t)\varphi''(t)|}{[\varphi'^2(t) + \psi'^2(t)]^{3/2}}$$

## 3 公式解析：求 $y = x^3$ 在原点与 $x=1$ 处的曲率

- **第一步，求导数**：$y' = 3x^2$，$y'' = 6x$。
- **第二步，代公式**：$K = \dfrac{|6x|}{(1 + 9x^4)^{3/2}}$。
- **第三步，逐点代入**：
  - 在 $x=0$：$K = \dfrac{0}{(1+0)^{3/2}} = 0$——原点处曲线「平直如线」（这正是 $x^3$ 在原点有水平切线且不弯的体现，与它在那里是拐点一致）。
  - 在 $x=1$：$K = \dfrac{6}{(1+9)^{3/2}} = \dfrac{6}{10\sqrt{10}} = \dfrac{3}{5\sqrt{10}} \approx 0.19$，曲率半径 $R = \dfrac{5\sqrt{10}}{3} \approx 5.27$。

**关键观察**：$y=x^3$ 在原点曲率为 0——尽管 $y''=0$，但它与「凹不凹」在这里重合；而在 $x=1$ 处曲率虽小却非零，说明「拐点处曲率为 0」与「其他地方曲率大于 0」的规律。曲率公式把「弯」与「位置」精确挂钩。

## 4 曲率的工程应用

曲率不只是理论概念，它是工程设计的硬约束：

- **道路与铁路选线**：弯道曲率半径决定最高安全车速。圆周运动向心加速度 $a = \dfrac{v^2}{R}$ 与曲率半径 $R$ 成反比——$R$ 越小，同样速度下离心力越大。高速弯道半径动辄数千米，正是为了保证 $a$ 不超限。<span class="marginnote">车辆过弯的物理极限：$v_{\max} = \sqrt{\mu g R}$（$\mu$ 为摩擦系数）。这直接说明为什么「弯越急、速越慢」——曲率半径是安全速度的唯一调节旋钮。到《大学物理》与《交通工程》你会反复见到这个公式。</span>
**齿轮齿廓**：渐开线齿廓的曲率性质决定啮合时的接触应力分布。
**计算机图形学**：曲线曲面的光顺性检查——曲率连续（$C^2$ 连续）是工业设计曲面的基本要求，NURBS 曲线设计中「曲率梳」工具直观显示曲率变化。
**微分几何入口**：曲率是曲线论的核心不变量，空间曲线的曲率 $\kappa$ 与挠率 $\tau$ 完全决定曲线形状（曲线论基本定理）。<span class="marginnote">到《微分几何》你会学到更一般的 Frenet 标架：曲率与挠率刻画空间曲线的「弯」与「扭」。本节公式是平面情形，但直觉完全可迁移——曲率度量「方向变化的快慢」，挠率度量「弯曲平面翻转的快慢」。</span>

## 5 曲率与二阶导数的关系辨析

很多人初学时会问：二阶导数不就表示弯曲吗？为何还要曲率？答案在于**参考系**：

- $y''$ 度量的是「相对 $x$ 轴的弯曲」——它依赖坐标系的取法；
- 曲率 $K$ 度量的是「曲线自身的弯曲」——它不依赖坐标系，只依赖弧长方向变化率。

当切线接近水平（$y'\approx 0$）时，$K \approx |y''|$，两者近似相等——这正是 $y''$ 在「缓坡」场景下可以充当曲率近似的原因；但曲线越陡（$|y'|$ 越大），$y''$ 与曲率的分歧越大。分母 $(1+y'^2)^{3/2}$ 正是对「陡坡造成的视错觉」的修正。

## 7 数值算例：验证「圆的曲率 $= \frac{1}{R}$」

用参数方程验证半径为 $R$ 的圆处处曲率为 $\frac{1}{R}$。

**第一步，写参数方程**：$x = R\cos t$，$y = R\sin t$。
**第二步，求各阶导**：$x' = -R\sin t$，$x'' = -R\cos t$；$y' = R\cos t$，$y'' = -R\sin t$。
**第三步，套参数方程曲率公式**：$K = \frac{|x'y'' - y'x''|}{(x'^2+y'^2)^{3/2}} = \frac{|R^2\sin^2t + R^2\cos^2t|}{R^3} = \frac{R^2}{R^3} = \frac{1}{R}$。

**结论**：圆上每一点曲率都是常数 $\frac{1}{R}$，曲率半径恰为 $R$——公式与「圆是最简单的弯曲线」的直觉完全吻合。这也验证了曲率的定义一致性：**圆的曲率就是其半径的倒数**。<span class="marginnote">这个验证还有一层深意：<strong>曲率把「任意曲线在某点弯成什么样」翻译成「像多大半径的圆」</strong>。曲率半径 $R$ 告诉你「在这一点，曲线近似于半径 $R$ 的圆」——这是曲率最实用、最直观的读法，也是曲率圆（密切圆）的存在理由。</span>

## 8 对照表：曲率与二阶导数

| 量 | 定义 | 是否坐标无关 |
| --- | --- | --- |
| 二阶导数 $y''$ | 相对 $x$ 轴的弯曲 | 否 |
| 曲率 $K$ | 切线方向角对弧长的变化率 | 是 |
| 曲率半径 $R$ | $\frac{1}{K}$ | 是 |
| 曲率中心 | 密切圆的圆心 | 是 |

**一句话**：$y''$ 是「换个坐标系就会变的弯曲」，$K$ 是「曲线自身固有的弯曲」。缓坡时两者近似，陡坡时分歧拉大。

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 把 $y''$ 直接当曲率 | 曲率还有分母 $(1+y'^2)^{3/2}$ |
| 参数方程公式忘取分子绝对值 | 分子必须取绝对值，曲率非负 |
| 陡坡时用 $y''$ 近似 | 用完整公式，否则误差随 $|y'|$ 增大 |
| 曲率与曲率半径搞反 | $K = 1/R$，一个变大另一个变小 |

## 10 缓和曲线与现代设计

曲率是工程与设计的「隐形语言」：

- **缓和曲线（回旋线）**：铁路与公路的弯道入口处，曲率从 0 平滑过渡到目标值，避免离心力突变导致乘客不适与侧翻风险——「曲率连续」本身就是设计指标。
- **曲率梳**：CAD 软件里显示曲线曲率的梳状图，工业设计曲面（汽车外壳、飞机机身）要求曲率连续（$C^2$），「光顺」的本质就是曲率无突变。
- **NURBS**：现代计算机辅助几何设计（CAD/CAM）的核心数学，其「光顺性」判定依赖曲率分析。

「弯得漂亮」在数学里是有精确定义的——曲率连续。你在这里学的曲率，正是这条设计美学的度量标准。

## 11 小结

- **曲率定义**：$K = \left|\frac{d\alpha}{ds}\right|$——切线方向角对弧长的变化率，衡量「弯得多厉害」。
- **计算公式**：$K = \dfrac{|y''|}{(1+y'^2)^{3/2}}$，参数方程另有公式。
- **曲率半径** $R = 1/K$，曲率圆是与曲线「贴得最紧」的圆。
- 圆的曲率恒为 $\frac{1}{R}$，公式与直觉互相印证。
- 曲率与二阶导数不同：曲率是**坐标无关**的固有量，$y''$ 依赖坐标系。
- 应用：道路安全车速、缓和曲线、齿轮设计、曲线光顺性、微分几何入口。
