## 为什么从平面及其方程开始

解析几何的灵魂是「用代数方程描述几何对象」。空间中最基本的曲面是**平面**，而平面的方程极其优美：一个平面完全由「一个点 + 一个法向量」决定——法向量垂直于平面上一切向量，于是「平面 = 与法向量点积为常数的点的集合」。从点法式到一般式、截距式，平面方程的多种写法对应着不同的几何信息；点到平面的距离公式则是应用最广的公式之一。<span class="marginnote">「平面 = 点 + 法向量」是整个空间解析几何的起点：直线由「点 + 方向向量」决定，平面由「点 + 法向量」决定——<strong>两种基本几何对象都归结为「锚点 + 特征向量」</strong>。这个「锚点 + 方向」的范式在计算机图形学、机器人学里也是定义几何元素的标准方式。</span>

## 1 平面的点法式方程

**平面的点法式方程**：设平面 $\Pi$ 过点 $M_0(x_0, y_0, z_0)$，法向量 $\mathbf{n} = (A, B, C)$，则平面上任一点 $M(x,y,z)$ 满足 $\overrightarrow{M_0M} \perp \mathbf{n}$，即

$$\mathbf{n}\cdot\overrightarrow{M_0M} = 0$$

展开得**点法式方程**：

$$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$$

**重点：法向量 $\mathbf{n} = (A, B, C)$ 的坐标，恰好就是平面方程里 $x,y,z$ 的系数**——这是识别法向量的最快途径。<span class="marginnote">为什么「点 + 法向量」能唯一确定平面？因为平面上所有向量都垂直于 $\mathbf{n}$，于是「与 $\mathbf{n}$ 垂直」这条性质筛选出了平面上的全部点——一个约束（点积为零）就画出一个二维平面。这与「空间中一个线性方程定义一个平面」的线性代数观点完全一致。</span>

## 2 平面的一般方程

展开点法式方程，令常数项合并，得**平面的一般方程**：

$$Ax + By + Cz + D = 0$$

其中 $(A,B,C)$ 是法向量。特殊情形对应特殊平面：

- $D = 0$：平面**过原点**；
- $C = 0$：方程不含 $z$，平面**平行于 $z$ 轴**；
- $C = D = 0$：平面过 $z$ 轴；
- $A = B = 0$：平面 $Cz + D = 0$，即 $z = $ 常数——**平行于 $xOy$ 平面**。

**截距式**：若 $A,B,C,D$ 全非零，可写成

$$\frac{x}{a} + \frac{y}{b} + \frac{z}{c} = 1$$

其中 $a,b,c$ 分别是平面在三个坐标轴上的截距。<span class="marginnote">三种方程各有用途：<strong>一般式便于判法向量与几何位置，点法式便于「过定点 + 法向量」的构造，截距式便于看与坐标轴的交点</strong>。它们等价，只是「信息呈现方式」不同——像同一事物的三种视图。</span>

## 3 两平面的夹角

**两平面的夹角**：两平面的法向量夹角（取锐角）。平面 $\Pi_1: A_1x+B_1y+C_1z+D_1=0$ 与 $\Pi_2$ 的夹角 $\theta$ 满足

$$\cos\theta = \frac{|A_1A_2 + B_1B_2 + C_1C_2|}{\sqrt{A_1^2+B_1^2+C_1^2}\,\sqrt{A_2^2+B_2^2+C_2^2}}$$

这是两法向量点积公式的运用（加绝对值取锐角）。<span class="marginnote">夹角公式的直觉：<strong>平面夹角 = 法向量夹角（取锐角）</strong>——因为两个平面「张开」的角度，恰等于它们法线「张开」的角度。绝对值保证取锐角（夹角约定在 $[0,\pi/2]$）。这个「对偶」——平面与法向量、直线与方向向量——是空间解析几何反复出现的对应。</span>

**特殊位置**：$\Pi_1 \perp \Pi_2 \iff A_1A_2+B_1B_2+C_1C_2 = 0$；$\Pi_1 \parallel \Pi_2 \iff$ 法向量成比例 $\frac{A_1}{A_2}=\frac{B_1}{B_2}=\frac{C_1}{C_2}$。

## 4 公式解析：点到平面的距离

设点 $M_1(x_1,y_1,z_1)$，平面 $\Pi: Ax+By+Cz+D=0$，则距离

$$d = \frac{|Ax_1 + By_1 + Cz_1 + D|}{\sqrt{A^2 + B^2 + C^2}}$$

- **第一步，理解分子**：$Ax_1+By_1+Cz_1+D$ 是把点代入平面方程左端的值——平面上的点代入得 0，平面外的点代入得「偏离程度」。
- **第二步，几何来源**：设 $M_0$ 是平面上一点，则 $\overrightarrow{M_0M_1}$ 在法向量方向的投影长度即距离：$d = |\overrightarrow{M_0M_1}\cdot\mathbf{n}|/|\mathbf{n}|$，代入坐标即得公式。
- **第三步，绝对值与分母**：绝对值保证距离非负，分母是法向量模长「归一化」投影。

例：点 $(1,2,3)$ 到平面 $2x - y + 2z - 6 = 0$ 的距离：$d = \frac{|2 - 2 + 6 - 6|}{\sqrt{4+1+4}} = 0$——点在平面上（代入得 0）。<span class="marginnote">这个公式与二维「点到直线距离 $\frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$」是同一结构的推广：<strong>「代入方程左端绝对值 ÷ 系数模长」</strong>。从二维到三维，公式只是升维——这是「模式推广」的直观例证，也是机器学习的「超平面间隔」概念（支持向量机的几何）的来源。</span>

## 5 平面的应用

平面方程是空间几何与许多工程问题的基石：

**支撑向量机（SVM）**：分类超平面 $w^Tx + b = 0$ 正是平面一般式的向量写法，点到平面的距离公式定义了「间隔」。<span class="marginnote">SVM 的几何核心全在本节：超平面 $w\cdot x + b = 0$（法向量 $w$）、间隔 $\frac{2}{|w|}$（两平行支持平面间的距离）、点到平面距离公式——你在第四级《机器学习》学 SVM 时会发现，<strong>它的全部几何都在空间解析几何这一章里</strong>。</span>
- **计算机图形学**：平面裁剪、光照法向量、视锥体都依赖平面方程。
- **空间几何问题**：求直线与平面的交点、判断点与平面的位置关系、求两平面的交线——都从平面方程出发。
- **几何与线性代数**：$Ax+By+Cz+D=0$ 是「三维空间中的二维线性子空间（平移后）」——一个线性方程把三维压成二维。

## 6 小结

- **点法式**：$A(x-x_0)+B(y-y_0)+C(z-z_0)=0$，法向量 $\mathbf{n}=(A,B,C)$。
- **一般式**：$Ax+By+Cz+D=0$；截距式 $\frac{x}{a}+\frac{y}{b}+\frac{z}{c}=1$。
- 特殊系数对应特殊平面（过原点、平行坐标轴、平行坐标面）。
- **夹角** = 法向量夹角（取锐角）；垂直、平行判据由法向量给出。
- **点到平面距离**：$d = \frac{|Ax_1+By_1+Cz_1+D|}{\sqrt{A^2+B^2+C^2}}$，是 SVM 间隔与图形学的几何基础。
