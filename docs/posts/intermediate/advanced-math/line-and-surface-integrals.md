## 为什么需要「沿曲线和曲面的积分」

重积分在「区域内部」累加，但很多物理量沿**边界**或**路径**累积：变力沿曲线做的功、流经曲面的流量、环路上的环流量。第十一章把积分从「区域」推广到「曲线」与「曲面」，并给出三个把「内部」与「边界」联系起来的深刻定理：格林公式、高斯公式、斯托克斯公式。

这些工具在「从极限到大模型」主线中的回响同样深远：物理中的通量与旋度、机器学习中的「梯度流的守恒律」、以及数学物理中一切「边界条件 ↔ 体分布」的对偶——比如扩散模型的归一化、电磁场中的麦克斯韦方程组，本质上都是「内部积分与边界积分」的对话。第十一章的三大公式，正是这场对话的语法。

本章按「沿曲线」到「沿曲面」的顺序展开：先有两类曲线积分，再有两类曲面积分，最后用三大公式把内部与边界统一起来。每个对象都抓住「积的是标量还是向量」这一关键区别。<span class="marginnote">两类积分的划分依据是「被积的量是标量还是向量」：对弧长/面积的积分积的是标量（密度、长度），对坐标的积分积的是向量场沿路径/曲面的分量。抓住这一点，整章的分类就清晰了。</span>

## 1 对弧长的曲线积分：第一类

**第一类曲线积分** $\int_L f(x,y)\,ds$ 沿曲线 $L$ 累加标量 $f$，$ds$ 是弧长微元。物理意义是「沿线的质量（密度 $f$）总和」或「曲线的质量」。化为定积分计算：设 $L: x=\varphi(t), y=\psi(t)$（$a\le t\le b$），则

$$\int_L f(x,y)\,ds = \int_a^b f[\varphi(t),\psi(t)]\sqrt{\varphi'^2(t) + \psi'^2(t)}\,dt$$

关键特点：第一类曲线积分**与路径方向无关**——积分方向相反只是 $t$ 从 $b$ 积到 $a$，但 $ds$ 恒正，结果不变。它不依赖「场的方向」，只依赖「路径的几何长度」，所以又叫「对弧长的积分」。

**辨析｜易错点：** 计算时 $\sqrt{\varphi'^2+\psi'^2}$ 这个「弧长因子」是从 $ds = \sqrt{(dx)^2+(dy)^2}$ 导出的，不能省。对封闭曲线常记作 $\oint_L$。

### 例：计算 $\int_L \sqrt{x^2+y^2}\,ds$，其中 $L$ 为圆 $x^2+y^2=1$（$0\le t\le 2\pi$）

**第一步，参数化。** $x = \cos t$、$y = \sin t$，弧长微元 $ds = \sqrt{(-\sin t)^2 + (\cos t)^2}\,dt = dt$。

**第二步，代入被积函数。** $\sqrt{x^2+y^2} = 1$。

**第三步，积分。** $\int_0^{2\pi} 1\cdot dt = 2\pi$。

答案 $2\pi$ 恰是单位圆的周长——这验证了「被积函数恒为 $1$ 的第一类曲线积分等于曲线长度」，是自检第一类积分是否写对弧长因子的标准方法。若结果不是 $2\pi$，多半是 $ds$ 因子漏算或参数化错误。

## 2 对坐标的曲线积分：第二类与做功

**第二类曲线积分** $\int_L P\,dx + Q\,dy$ 沿曲线累加向量场 $(P,Q)$ 的切向分量，物理意义正是**变力沿曲线做的功**：

$$W = \int_L P(x,y)\,dx + Q(x,y)\,dy = \int_a^b \left[P\,\varphi'(t) + Q\,\psi'(t)\right]dt$$

第二类积分**与方向有关**：反向积分改变符号。它与第一类的关系是：$\int_L P\,dx + Q\,dy = \int_L (P\cos\alpha + Q\cos\beta)\,ds$，其中 $(\cos\alpha,\cos\beta)$ 是曲线单位切向量。

**与路径无关（保守场）**是第二类积分的核心性质：若在单连通区域 $G$ 内 $P,Q$ 及其偏导连续，则下列四件事等价：

1. $\int_L P\,dx + Q\,dy$ 与路径无关；
2. $\oint_L P\,dx + Q\,dy = 0$（任意闭路）；
3. 存在函数 $u(x,y)$ 使 $du = P\,dx + Q\,dy$；
4. $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$ 在 $G$ 内成立。

这条「四条等价」是格林公式的直接推论，也是判断「能不能用全微分求和」的万能钥匙。物理上它对应「保守力做功与路径无关」——重力、静电力的核心特性。<span class="marginnote">「与路径无关」在优化里对应「势函数存在」：如果一个向量场是某个函数的梯度，那么沿任何路径的积分只由端点决定。梯度下降沿梯度场走，损失的变化量正是「路径无关」积分——这是理解优化与守恒律共通的桥梁。</span>

## 3 公式解析：格林公式

**格林公式**把平面闭曲线上的第二类曲线积分与闭曲线所围区域上的二重积分联系起来：设 $D$ 由分段光滑闭曲线 $L$ 围成，$P,Q$ 在 $D$ 上有连续一阶偏导，则

$$\oint_L P\,dx + Q\,dy = \iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)d\sigma$$

其中 $L$ 取**正向**（沿边界走，区域在左手边，即逆时针）。把这条公式拆开看：

- **第一步，记内部量。** 右边被积函数 $\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}$ 是「旋度」的二维版——度量向量场在区域内的「旋转强度」。
- **第二步，记方向。** 闭路必须取正向；取反向则右边整体变号。方向与符号是格林公式最易错的两点。
- **第三步，算面积特例。** 取 $P=-y$、$Q=x$，得 $\oint_L x\,dy - y\,dx = 2\iint_D d\sigma = 2A$——**用边界曲线积分求面积** $A = \frac12\oint_L x\,dy - y\,dx$，这是「用路径替代体分布」的经典应用。

格林公式的三维推广是斯托克斯公式，它的「旋度」概念是流体涡旋与电磁感应的核心量。

## 4 两类曲面积分：对面积与对坐标

**第一类曲面积分** $\iint_\Sigma f(x,y,z)\,dS$ 在曲面 $\Sigma$ 上累加标量 $f$，$dS$ 是面积微元，物理意义是「曲面质量」。设曲面 $z = z(x,y)$，则

$$dS = \sqrt{1 + z_x^2 + z_y^2}\,dx\,dy$$

**第二类曲面积分** $\iint_\Sigma P\,dy\,dz + Q\,dz\,dx + R\,dx\,dy$ 积的是向量场通过曲面的**通量**。若取上侧，则 $\iint_\Sigma R\,dx\,dy = \iint_{D_{xy}} R[x,y,z(x,y)]\,dx\,dy$，符号由曲面法向量方向（上/下）决定。<span class="marginnote">第一类曲面积分与方向无关，第二类曲面积分与「侧」有关（上下、前后、左右）。「侧」决定了法向量的方向，也决定了二重积分前的符号——取错侧是整个章节最经典的翻车点。</span>

**两类曲面积分的联系**：$\iint_\Sigma P\,dy\,dz + Q\,dz\,dx + R\,dx\,dy = \iint_\Sigma (P\cos\alpha + Q\cos\beta + R\cos\gamma)\,dS$，其中 $(\cos\alpha,\cos\beta,\cos\gamma)$ 是曲面法向量的方向余弦。这可以看作是「向量场沿法向的分量 × 面积微元」的积分。

**辨析｜易错点：** 计算第二类曲面积分时，先确定曲面「侧」的方向（上侧、下侧、外侧、内侧），再据此定投影符号。例如 $z = z(x,y)$ 取上侧时，$\iint_\Sigma R\,dx\,dy = \iint_{D_{xy}} R\,dx\,dy$；取下侧时前面加负号。若曲面方程写成 $F(x,y,z)=0$，法向量用梯度 $\nabla F$ 确定，方向取与外法向一致的那个。

## 5 高斯公式与斯托克斯公式：内部 ↔ 边界的对话

**高斯公式（散度定理）**：设 $\Omega$ 由光滑闭曲面 $\Sigma$ 围成，则

$$\oiint_\Sigma P\,dy\,dz + Q\,dz\,dx + R\,dx\,dy = \iiint_\Omega \left(\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}\right)dV$$

右边被积函数是**散度** $\mathrm{div}\,\vec F$——度量向量场在体元内「源/汇」的强度。高斯公式说：**通过闭曲面向外的通量 = 体内散度的总和**。这就是「流量守恒」的数学表达：多出来的必须从边界流出。<span class="marginnote">高斯公式是「从体到面」的对偶——只要知道体内的散度，通量不用算边界积分。电磁学里高斯定律、流体里的质量守恒，都是这个定理的具体化。</span>

**斯托克斯公式**：设 $\Sigma$ 是以曲线 $L$ 为边界的曲面，则

$$\oint_L P\,dx + Q\,dy + R\,dz = \iint_\Sigma \left(\frac{\partial R}{\partial y}-\frac{\partial Q}{\partial z}\right)dy\,dz + \left(\frac{\partial P}{\partial z}-\frac{\partial R}{\partial x}\right)dz\,dx + \left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dx\,dy$$

右边是**旋度** $\mathrm{rot}\,\vec F$ 在曲面上的积分。斯托克斯公式说：**边界上的环流量 = 旋度在曲面上的总积分**。它是格林公式的推广（取 $\Sigma$ 为平面区域即回退到格林公式），也是流体环量、电磁感应定律的数学语言。

## 6 核心对比表：三大积分公式

| 公式 | 区域 | 边界 | 内部量 | 直观含义 |
| --- | --- | --- | --- | --- |
| 格林公式 | 平面区域 $D$ | 闭曲线 $L$ | 旋度（二维）$\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}$ | 环流量 = 旋转总和 |
| 高斯公式 | 空间区域 $\Omega$ | 闭曲面 $\Sigma$ | 散度 $\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}$ | 通量 = 源汇总和 |
| 斯托克斯公式 | 曲面 $\Sigma$ | 边界曲线 $L$ | 旋度（三维） | 环流量 = 旋度积分 |

三大公式是同一母题的三个化身：**内部某量的积分 = 边界上另一种量的积分**。它们合起来构成了向量分析的核心——梯度、散度、旋度三大微分算子，各自配一条积分定理。理解了这个统一模式，三个公式就不再是三条孤立的记忆负担，而是一个思想在不同维度下的投影。

## 7 小结

- 曲线积分分两类：对弧长（标量、与方向无关）与对坐标（向量、与方向有关、做功）。
- 「与路径无关」有四个等价表述，条件是 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$。
- 曲面积分分两类：对面积（$dS$，与侧无关）与对坐标（通量，与侧有关、符号敏感）。
- 格林公式：平面闭曲线积分 ↔ 区域内旋度积分；可由此用边界积分求面积。
- 高斯公式：闭曲面通量 ↔ 体内散度积分，是流量守恒的数学形式。
- 斯托克斯公式：边界环流量 ↔ 曲面上旋度积分，是格林公式的三维推广。
- 三大公式统一于「内部积分 = 边界积分」，是向量分析的核心结构。
