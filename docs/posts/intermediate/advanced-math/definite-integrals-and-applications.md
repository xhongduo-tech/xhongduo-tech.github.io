## 为什么需要「带上下限的积分」

第四章的不定积分是「求原函数」的纯逆运算，还没有「几何总量」的含义。第五章给它装上上下限，把「反求导」升级为「求总量」：曲线下面积、变力做功、流量、质量、概率——全都由一个叫**定积分**的对象统一刻画。

**定积分的定义**：设 $f$ 在 $[a,b]$ 上有界，把 $[a,b]$ 分成 $n$ 个小区间，任取点 $\xi_i$，作和式 $S = \sum_{i=1}^{n} f(\xi_i)\Delta x_i$，当最大区间长度趋于 $0$ 时若和式极限存在，则

$$\int_a^b f(x)\,dx = \lim_{\max\Delta x_i \to 0} \sum_{i=1}^{n} f(\xi_i)\Delta x_i$$

几何意义：$f \ge 0$ 时它是曲线下与 $x$ 轴围成的面积；$f$ 变号时它是「正面积减去负面积」的**净面积**。<span class="marginnote">定积分定义里的「分割、求和、取极限」三步骤，正是「从极限到大模型」思想路线的经典样板：把复杂总量拆成小片，每片近似成矩形，取极限消除近似。后面积分的所有计算都从这个定义出发。</span>

定积分的性质也顺理成章：线性性、可加性（$\int_a^b = \int_a^c + \int_c^b$）、保号性（$f\ge0$ 则积分非负）、估值定理与中值定理。它们共同保证：只要 $f$ 在闭区间连续，定积分就一定存在且「好算」。

## 1 微积分基本定理：两座大厦之间的桥

定积分的定义「能算但难算」——真按分割求和去算 $\int_0^1 x^2 dx$ 要取极限。第五章最核心的成果，是**牛顿–莱布尼茨公式（微积分基本定理）**：

**变上限积分函数** $\Phi(x) = \int_a^x f(t)\,dt$ 对连续 $f$ 可导，且 $\Phi'(x) = f(x)$。于是对任一原函数 $F$ 有

$$\int_a^b f(x)\,dx = F(b) - F(a)$$

这条公式把两件看似无关的事焊在一起：**算面积（定积分）与找原函数（不定积分）是一回事**。求定积分不再需要分割求和，只需找被积函数的一个原函数，再代入上下限相减。微积分从「两座独立的大厦」变成「一座」，其意义怎么强调都不过分。

**为什么要证明变上限积分**：因为「可导且导数为 $f$」说明 $\Phi$ 就是 $f$ 的一个原函数——这等于说「原函数一定存在」（对连续函数），且用面积构造出来。这个构造在概率论里就是「密度函数 → 累积分布函数」；在大模型里，任何「从密度积出概率」的操作都隐含这一定理。<span class="marginnote">对初学者，先用 $F(b)-F(a)$ 熟练计算；但要记住 $F$ 的存在性由变上限积分保证——这是「连续函数必有原函数」这个看似平凡结论的严格来源。</span>

## 2 公式解析：定积分的换元法与分部积分法

计算定积分有两种习惯：先求原函数再代上下限，或者「边换元边换限」。后者更高效也更容易错。

**定积分换元**：$x = \varphi(t)$ 单调，$\varphi(\alpha) = a$、$\varphi(\beta) = b$，则

$$\int_a^b f(x)\,dx = \int_\alpha^\beta f[\varphi(t)]\,\varphi'(t)\,dt$$

**定积分分部**：

$$\int_a^b u\,dv = [uv]_a^b - \int_a^b v\,du$$

把换元拆开看关键点：

- **第一步，换元的同时换上下限**：$x=a \to t=\alpha$，$x=b \to t=\beta$。上下限跟着变换走，绝不能在换元后还沿用旧的 $a$、$b$。
- **第二步，换元后无需回代**：因为上下限已经换成新变量，直接在新变量下代入 $\alpha$、$\beta$ 相减即可——这比不定积分「算完再回代」省一步。
- **第三步，对称性红利**：若 $f$ 为奇函数，$\int_{-a}^{a} f(x)dx = 0$；若 $f$ 为偶函数，$\int_{-a}^{a} f(x)dx = 2\int_0^a f(x)dx$。识别奇偶能瞬间消去一大片计算。

**辨析｜易错点：** 若选择「先求原函数再代限」路线，代的是原来的 $a$、$b$，而且要注意原函数在 $[a,b]$ 上连续（尤其遇到分段点或瑕点时），否则代限结果可能是错的。

## 3 反常积分：无穷与瑕点

第五章还处理两类「积分区间不完整」的情形，统称**反常积分（广义积分）**：

- **无穷区间**：$\int_a^{+\infty} f(x)dx = \lim_{b\to+\infty}\int_a^b f(x)dx$，极限存在则收敛，否则发散。
- **无界函数（瑕积分）**：$f$ 在 $b$ 处无界时，$\int_a^b f(x)dx = \lim_{\varepsilon\to0^+}\int_a^{b-\varepsilon} f(x)dx$。

两条基本结论必须记住：$\int_1^{+\infty}\frac{dx}{x^p}$ 当且仅当 $p>1$ 收敛；$\int_0^1\frac{dx}{x^p}$（瑕积）当且仅当 $p<1$ 收敛。它们来自比较审敛法，也是概率论中「分布是否有有限期望、有限方差」的判定模板——厚尾分布（如 Cauchy 分布）之所以没有期望，正是因为 $\int|x|f(x)dx$ 发散。

**审敛法**：比较审敛法（与 $1/x^p$ 比）、极限审敛法（比较的极限形式）、绝对收敛。**Γ 函数** $\Gamma(s) = \int_0^{+\infty}x^{s-1}e^{-x}dx$ 是反常积分的集大成者，满足 $\Gamma(s+1) = s\,\Gamma(s)$，对正整数 $\Gamma(n+1) = n!$——它把「阶乘」延拓到任意实数，是统计学中 $\chi^2$、$t$ 分布密度函数的共同出处。

## 4 定积分的应用：元素法

第六章节把定积分推向应用。核心方法论是**微元法（元素法）**：把目标量 $U$ 看成「在区间 $[a,b]$ 上连续累积的小量之和」，任取小区间 $[x, x+dx]$，写出微元 $dU = f(x)\,dx$，然后

$$U = \int_a^b f(x)\,dx$$

应用实例高度模板化：

- **平面面积**：$y=f(x)$ 与 $x$ 轴围成面积 $\int_a^b |f(x)|\,dx$；两曲线之间面积 $\int_a^b |f_1(x)-f_2(x)|\,dx$。
- **旋转体体积**：绕 $x$ 轴旋转，$V = \pi\int_a^b [f(x)]^2 dx$；绕 $y$ 轴或套筒法另有公式。
- **平面曲线弧长**：$s = \int_a^b\sqrt{1 + [f'(x)]^2}\,dx$。
- **旋转体侧面积**：$S = 2\pi\int_a^b f(x)\sqrt{1+[f'(x)]^2}\,dx$。
- **物理应用**：变力做功 $W = \int_a^b F(x)\,dx$、液体压力、质心、转动惯量。

**辨析｜易错点：** 应用题的难点在「正确写出微元」。画图 → 任取微元 → 写出该微元的量（长、宽、厚、力、体积）→ 积分，四步缺一不可。常见的错是把「面积微元」写成「高度」直接当体积，或忘记旋转体的半径是 $|f(x)|$（函数为负时要取绝对值）。

### 例：抛物线 $y=x^2$ 与直线 $y=x$ 围成的面积

**第一步，求交点。** $x^2 = x$ 得 $x=0$ 或 $x=1$，积分区间为 $[0,1]$，在此区间 $x \ge x^2$。

**第二步，写面积微元。** $dS = (x - x^2)\,dx$。

**第三步，积分。** $S = \int_0^1(x - x^2)\,dx = \left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1 = \frac{1}{2} - \frac{1}{3} = \frac{1}{6}$。

**第四步，复核。** 单位正方形 $[0,1]\times[0,1]$ 的面积为 $1$，抛物线弓形约为其六分之一，量级合理。这个「两曲线之间面积」的模板——先定上下、再作差、再积分——贯穿所有面积应用题。

## 5 核心对比表：定积分 vs 不定积分

| 维度 | 不定积分 | 定积分 |
| --- | --- | --- |
| 记号 | $\int f(x)\,dx$ | $\int_a^b f(x)\,dx$ |
| 结果 | 一族函数 $F(x)+C$ | 一个数 |
| 定义 | 原函数的全体 | 分割-求和-取极限的和式极限 |
| 意义 | 求导的逆运算 | 曲线下净面积 / 总量累积 |
| 连接 | 求导的反面 | 牛顿–莱布尼茨公式 $F(b)-F(a)$ |
| 用途 | 为定积分备原函数 | 面积、体积、弧长、做功、概率 |

这张表是全书「双轨制」的缩影：不定积分管「求原函数」，定积分管「求总量」，两轨由微积分基本定理合并。做定积分题，先找原函数（走不定积分轨），再代限（走定积分轨）。

## 6 小结

- 定积分由「分割、求和、取极限」定义，几何上是有向面积的代数和。
- 牛顿–莱布尼茨公式 $\int_a^bf(x)dx = F(b)-F(a)$ 是全书枢纽，把求面积与找原函数统一。
- 定积分换元「换元即换限」，可省去回代；奇偶对称性可大幅简化积分。
- 反常积分分「无穷区间」与「瑕点」两类，收敛性由 $p$ 幂法则与比较审敛法判定。
- 微元法是第六节应用题的总纲：微元 → 积分，面积、体积、弧长、做功、质心皆此一法。
- 定积分是后续多元积分（二重、三重、曲线、曲面）的原型，也是概率论中期望、方差的统一语言。

在下一节，我们将带着「求总量」的积分视角进入新的领域——**常微分方程**。方程中未知的是函数本身，而解方程的方法，很大程度上就是「认出这是哪个积分的逆过程」。
