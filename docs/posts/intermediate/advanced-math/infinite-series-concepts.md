## 为什么从常数项级数的概念和性质开始

「$1+\frac12+\frac14+\frac18+\cdots$ 等于多少？」无穷多个数相加，意义何在？直觉上它应该等于 2，但「无穷和」必须严格定义——否则会出现 $\sum(-1)^n$ 这样「不知道加到哪里」的悖论。**常数项级数**把「无穷求和」严格化：先算部分和 $S_n$，再看 $S_n$ 的极限。这一节建立级数的基本概念与性质，是整个无穷级数理论的入口——它回答「什么算收敛」「收敛有哪些基本规则」。级数是泰勒展开（第 73 节）、傅里叶级数（第 76-77 节）的共同地基，也是数值计算里一切「用有限逼近无限」的数学基础。<span class="marginnote">无穷求和的历史争议：芝诺悖论（阿喀琉斯追乌龟）就建立在「无限段路程能否走完」上。级数理论给出答案：<strong>「无穷项相加」不是真的逐项加到无穷，而是「部分和序列的极限」</strong>。$\frac12+\frac14+\frac18+\cdots$ 的部分和 $S_n = 1-\frac1{2^n} \to 1$——「无限过程，有限结果」的数学严格化。</span>

## 1 级数的定义

**级数（series）**：由数列 $\{u_n\}$ 的各项依次相加得到的表达式

$$\sum_{n=1}^{\infty} u_n = u_1 + u_2 + \cdots + u_n + \cdots$$

前 $n$ 项之和称为**部分和**：$S_n = u_1 + u_2 + \cdots + u_n$。部分和构成一个新的数列 $\{S_n\}$。

**收敛与发散**：若部分和数列 $\{S_n\}$ 收敛（$\lim_{n\to\infty}S_n = S$ 存在），则称级数**收敛**，$S$ 称为**级数的和**；否则称级数**发散**。

$$\sum_{n=1}^{\infty} u_n = \lim_{n\to\infty} S_n = S$$

**重点：级数收敛 ⟺ 部分和数列收敛。** 级数的「和」不是逐项相加的结果，而是部分和序列的极限——这是级数理论的全部基础。<span class="marginnote">「级数的和 = 部分和的极限」是级数最根本的定义，一切性质都由它推出。例如 $\sum_{n=1}^\infty q^{n-1}$（几何级数）的部分和 $S_n = \frac{1-q^n}{1-q}$，当 $|q|<1$ 时 $q^n\to0$，$S_n\to\frac{1}{1-q}$——「无限等比求和」得到有限和。$|q|\ge1$ 时发散。</span>

## 2 两个重要级数

**几何级数**：$\sum_{n=0}^{\infty} q^n = 1 + q + q^2 + \cdots$

$$|q| < 1 \Rightarrow \text{收敛，和为 } \frac{1}{1-q}; \qquad |q| \ge 1 \Rightarrow \text{发散}$$

**调和级数**：$\sum_{n=1}^{\infty} \frac{1}{n} = 1 + \frac12 + \frac13 + \cdots$——**发散**。

**辨析｜易错点：** 调和级数的发散并不直观——$u_n\to0$ 但级数却发散。直观理解：按 $1+(\frac12)+(\frac13+\frac14)+(\frac15+\cdots+\frac18)+\cdots$ 分组，每组都 $\ge\frac12$，无穷多个「$\ge\frac12$」的组加起来发散。**「通项趋于零」是级数收敛的必要条件，但不是充分条件**——$u_n\to0$ 不保证收敛（调和级数就是反例）。

**级数收敛的必要条件**：若 $\sum u_n$ 收敛，则 $u_n \to 0$。**逆否命题更常用**：若 $u_n \not\to 0$，则级数必发散（如 $\sum(-1)^n$、$\sum\frac{n}{n+1}$）。

## 3 级数的基本性质

- **线性性质**：$\sum (au_n + bv_n) = a\sum u_n + b\sum v_n$（两级数均收敛时）——收敛级数可逐项相加、提常数。
- **添加/去掉有限项不改变收敛性**：改变级数前有限项的值，不影响收敛与发散（只改变和的值）。
- **加括号**：收敛级数加括号后仍收敛且和不变；但**加括号后收敛，原级数不一定收敛**（反例：$1-1+1-1+\cdots$ 加括号成 $(1-1)+(1-1)+\cdots=0$，但原级数发散）。<span class="marginnote">「加括号不保证收敛」是级数最反直觉的性质之一：$1-1+1-1+\cdots$ 的部分和是 $1,0,1,0,\ldots$ 不收敛（震荡），但两两加括号后 $(1-1)+(1-1)+\cdots = 0$「看起来收敛」。这警示我们：<strong>级数的收敛性由部分和序列决定，不能靠加括号「猜」</strong>。条件收敛级数（第 71 节）的加括号/换序问题更为敏感。</span>
**必要条件**：$u_n \to 0$。

## 4 公式解析：判断级数是否收敛

判断 $\sum_{n=1}^{\infty}\left(\frac{1}{2^n} + \frac{1}{3^n}\right)$ 是否收敛并求和：

**第一步，拆成两个几何级数**：$\sum\frac{1}{2^n} = \sum\left(\frac12\right)^n$，$\sum\frac{1}{3^n} = \sum\left(\frac13\right)^n$。
**第二步，分别套几何级数公式**：$\sum_{n=1}^\infty\left(\frac12\right)^n = \frac{\frac12}{1-\frac12} = 1$（首项 $\frac12$、公比 $\frac12$）；$\sum_{n=1}^\infty\left(\frac13\right)^n = \frac{\frac13}{1-\frac13} = \frac12$。
**第三步，线性性质相加**：原级数 $= 1 + \frac12 = \frac32$，收敛。

**关键**：级数求和的常用策略是「**拆成已知级数（几何级数）再套公式**」——线性性质让「收敛级数的线性组合」可以直接分项求和。判断收敛优先看「是否已知级数类型」「通项是否趋于零」两个快检。

## 5 级数的意义与应用

级数是「用无限逼近有限」的通用语言，现代计算与理论都依赖它：

**十进制与浮点数**：$0.333\ldots = \frac{3}{10}+\frac{3}{100}+\cdots = \frac13$——小数的本质就是级数。<span class="marginnote">小数展开就是级数：任何十进制小数都是「各项之和」的极限。计算机的浮点数也只能精确表示「有限位小数」，其余靠近似——「用有限逼近无限」是数值计算的永恒主题。你在这里学的级数收敛，为「近似值有多接近真值」提供了理论尺度。</span>
- **泰勒级数与函数逼近**：$e^x = \sum\frac{x^n}{n!}$——函数展开成幂级数（第 73 节）让计算器能算任何初等函数。
- **傅里叶级数**：任何周期信号展开成三角级数（第 76-77 节）——信号处理、图像压缩的数学基础。
- **概率与统计**：几何分布的期望、矩母函数都涉及级数求和。
- **算法与复杂度**：算法分析里的求和公式（如 $\sum_{i=1}^n i = \frac{n(n+1)}2$、几何和）都是级数的有限版。

## 6 小结

- **级数** = 部分和序列的极限：$\sum u_n = \lim S_n$；收敛 ⟺ 部分和收敛。
- **几何级数**：$|q|<1$ 收敛（和 $\frac{1}{1-q}$），$|q|\ge1$ 发散。
- **调和级数** $\sum\frac1n$ 发散——通项趋于零但级数发散，说明「通项 $\to0$」只是必要条件。
- **性质**：线性、去有限项不变、加括号不保证；必要条件 $u_n\to0$。
- 级数是小数、函数逼近、信号处理与算法分析的共同地基。
