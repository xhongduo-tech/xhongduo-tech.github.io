## 为什么从空间曲线及其方程开始

空间直线是「直」的空间曲线，而真实轨迹——螺旋线、抛体轨迹、行星轨道——都是**弯曲**的空间曲线。空间曲线有几种描述方式：**参数方程**（最本质：用参数 $t$ 追踪运动）、**两曲面交线**（一般式）、**投影曲线**（到坐标面的投影）。其中参数方程是主角——它把「曲线是点的运动轨迹」变成「三个坐标函数随时间（参数）变化」。这直接通向多元函数微分学：切向量、切线、弧长（第十一章对弧长的曲线积分），以及物理中质点的运动学。<span class="marginnote">空间曲线的参数方程 $\mathbf{r}(t) = (x(t), y(t), z(t))$ 是最自然的描述：<strong>曲线是「时间」的函数</strong>，每个 $t$ 给一个位置向量。这与平面曲线的参数方程一脉相承，也是第十一章「对弧长的曲线积分」与微分几何「弧长参数化」的基础。</span>

## 1 空间曲线的参数方程

**空间曲线的一般式（两曲面交线）**：

$$\begin{cases}F(x,y,z) = 0\\ G(x,y,z) = 0\end{cases}$$

——两个曲面的交线。**参数方程**：

$$x = \varphi(t), \qquad y = \psi(t), \qquad z = \omega(t)$$

或写成向量形式 $\mathbf{r}(t) = (\varphi(t), \psi(t), \omega(t))$。

例：螺旋线 $x = a\cos t,\ y = a\sin t,\ z = bt$——绕 $z$ 轴匀速转 + 匀速上升，是弹簧、DNA 双螺旋的数学模型。<span class="marginnote">螺旋线的几何：在 $xOy$ 投影是圆（$x=a\cos t, y=a\sin t$），$z$ 坐标匀速上升——「圆 + 上升」的合成。它是「圆周运动 × 匀速直线」的复合轨迹，也是空间曲线最常见的例题，因为它的投影与曲率都容易算。</span>

**参数与一般式的转换**：一般式 → 参数式需要「解出」一条曲线上的点（常令某坐标为参数）；参数式 → 一般式用「消参」得到两个方程。

## 2 空间曲线在坐标面上的投影

**投影曲线**：空间曲线向坐标面投影得到的曲线。曲线 $\begin{cases}F(x,y,z)=0\\G(x,y,z)=0\end{cases}$ 向 $xOy$ 面投影的步骤：

1. 从两方程**消去 $z$**，得 $H(x,y) = 0$（一个柱面，含曲线的所有投影）；
2. 投影曲线为 $\begin{cases}H(x,y) = 0\\ z = 0\end{cases}$。

**辨析｜易错点：** 消去 $z$ 得到的柱面 $H(x,y)=0$ 是「投影柱面」，它**包含**曲线向 $xOy$ 面的投影，但投影曲线必须再加上 $z=0$ 才是在坐标面上的曲线。<span class="marginnote">投影柱面的直觉：把空间曲线「垂直往下照」，它在 $xOy$ 面上投出影子，而「照下来的过程」扫出一个垂直柱面——这个柱面的方程就是消去 $z$ 得到的 $H(x,y)=0$。投影是「去掉一个坐标」，柱面是「补回第三维」。</span>

例：球面 $x^2+y^2+z^2=R^2$ 与平面 $z=R/2$ 的交线是圆，向 $xOy$ 投影：消 $z$ 得 $x^2+y^2 = R^2 - \frac{R^2}{4} = \frac{3R^2}{4}$，投影为 $\begin{cases}x^2+y^2 = \frac{3R^2}{4}\\ z=0\end{cases}$。

## 3 空间曲线的切线与法平面

设空间曲线参数方程 $\mathbf{r}(t) = (x(t), y(t), z(t))$，各分量可导，则**切向量（速度向量）**

$$\mathbf{T} = \mathbf{r}'(t_0) = (x'(t_0),\ y'(t_0),\ z'(t_0))$$

**切线方程**（过点 $(x_0,y_0,z_0)$，方向 $\mathbf{T}$）：

$$\frac{x - x_0}{x'(t_0)} = \frac{y - y_0}{y'(t_0)} = \frac{z - z_0}{z'(t_0)}$$

**法平面**（过切点、法向量为 $\mathbf{T}$ 的平面）：

$$x'(t_0)(x - x_0) + y'(t_0)(y - y_0) + z'(t_0)(z - z_0) = 0$$

切线方向就是速度方向——曲线的「局部运动趋势」由导数向量完全刻画。<span class="marginnote">空间曲线的切向量 $=\mathbf{r}'(t)$ 正是运动学里的速度向量，法平面是「垂直速度的平面」。这与你学过的平面曲线切线（斜率 $y'$）一脉相承，只是升维成「向量」。到第九章，曲面 $F(x,y,z)=0$ 的切平面由梯度给出，与这里的「曲线的切线/法平面」互相呼应。</span>

## 4 公式解析：求螺旋线的切线与法平面

考察螺旋线 $x = a\cos t,\ y = a\sin t,\ z = bt$ 在 $t = t_0$ 处：

- **第一步，求切向量**：$\mathbf{r}'(t) = (-a\sin t,\ a\cos t,\ b)$，在 $t_0$ 处为 $(-a\sin t_0,\ a\cos t_0,\ b)$。
- **第二步，写切线**：$\frac{x - a\cos t_0}{-a\sin t_0} = \frac{y - a\sin t_0}{a\cos t_0} = \frac{z - bt_0}{b}$。
- **第三步，写法平面**：$-a\sin t_0\,(x - a\cos t_0) + a\cos t_0\,(y - a\sin t_0) + b(z - bt_0) = 0$。
- **第四步，特例检查**：当 $t_0 = 0$ 时，切点 $(a,0,0)$，切向量 $(0,a,b)$，法平面 $ay + bz = 0$——过切点且垂直切向的平面，合理。

**关键**：求空间曲线切线的流程完全机械化——**求导得切向量 → 写点向式切线 → 写点法式法平面**。切向量是这一切的枢纽。

## 5 空间曲线的应用

- **运动学**：$\mathbf{r}(t)$ 是位置，$\mathbf{r}'(t)$ 是速度，$\mathbf{r}''(t)$ 是加速度——空间曲线参数方程就是运动学的数学骨架。<span class="marginnote">物理与计算机动画中，轨迹、速度、加速度都写成参数曲线的向量函数：$\mathbf{v} = \mathbf{r}'(t)$、$\mathbf{a} = \mathbf{r}''(t)$。切向量、法向量、副法向量构成 Frenet 标架，描述曲线在每点的「弯」与「扭」——到《微分几何》你会系统学习这套理论。</span>
- **对弧长的曲线积分**（第十一章）：$\int_L f(x,y,z)\,ds$ 的第一型曲线积分，被积曲线就是本节的空间曲线，$ds$ 是弧长微元 $\sqrt{x'^2+y'^2+z'^2}\,dt$。
- **对坐标的曲线积分**：第二型曲线积分（变力沿曲线做功）也建立在空间曲线的参数方程上。
- **CAD/CAM 与图形学**：Bezier 曲线、样条曲线都是参数曲线的推广——空间曲线参数方程是计算机辅助设计的数学基础。

## 6 小结

- **空间曲线**：一般式（两曲面交线）与参数方程 $\mathbf{r}(t) = (x(t),y(t),z(t))$。
- **投影曲线**：消去一个坐标得投影柱面，再加「坐标面」条件。
- **切向量** $\mathbf{r}'(t_0)$，**切线**（点向式）与**法平面**（点法式）由切向量决定。
- 螺旋线 $x=a\cos t,\ y=a\sin t,\ z=bt$ 是典型空间曲线。
- 应用：运动学、曲线积分、计算机图形学的参数曲线。
