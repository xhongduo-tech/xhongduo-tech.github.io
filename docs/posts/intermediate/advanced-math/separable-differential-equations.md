## 为什么从可分离变量开始

微分方程千变万化，但最基础、最常见的一类有一个极简结构：方程能写成「$y$ 的表达式 × $dy$ = $x$ 的表达式 × $dx$」——**两个变量完全分开，各占一边**。这种**可分离变量**方程是微分方程求解的第一课：它把「解微分方程」降维成「两边分别积分」，而积分正是前面学了一整章的本领。可分离变量方程涵盖了指数增长/衰减、Logistic 人口模型、放射性衰变、冷却定律等几乎所有入门模型——它们都长着「变化率 = 当前量的函数」这张脸。<span class="marginnote">「分离变量」的本质是「解耦」：把两个纠缠在一起的变量拆开，各自积分。这种「解耦」思想贯穿数学——矩阵对角化、傅里叶分解、主成分分析都是「把纠缠的结构拆成独立分量」。你在微分方程里第一次真正动手用「分离」。</span>

## 1 可分离变量的形式与解法

**可分离变量方程**：一阶方程如果能写成

$$\frac{dy}{dx} = g(x)\,h(y)$$

的形式（右端是「只含 $x$ 的函数 × 只含 $y$ 的函数」），就称可分离变量。解法分三步：

1. **分离**：把 $h(y)$ 移到左边、$g(x)$ 留在右边，写成 $h(y)\,dy = g(x)\,dx$（$h(y) \neq 0$）；
2. **积分**：两边分别积分 $\int h(y)\,dy = \int g(x)\,dx$；
3. **解出**：由积分结果解出 $y$（或保留隐式解）。

例：$\frac{dy}{dx} = xy$。分离：$\frac{dy}{y} = x\,dx$。积分：$\ln|y| = \frac{x^2}{2} + C$，解得 $y = Ce^{x^2/2}$。<span class="marginnote">「分离 + 积分」看起来简单，但要小心：分离时 $h(y)=0$ 的解可能被漏掉。例如 $\frac{dy}{dx}=xy$ 中 $y=0$ 是常数解，在分离时被 $h(y)=y\neq0$ 的前提排除——写通解后要检查它是否包含在内（$C=0$ 时 $y=0$ 恰好包含）。</span>

## 2 初始值问题

可分离方程配上初值条件 $y(x_0)=y_0$，即**初值问题**。解法：先求通解，再代入初值定 $C$；或直接做「定积分版」——从 $x_0$ 积到 $x$：

$$\int_{y_0}^{y} h(y)\,dy = \int_{x_0}^{x} g(x)\,dx$$

定积分版的好处：初值自动嵌入积分限，省去「先求 $C$ 再代回」的步骤，且不需要显式解出 $C$。

**辨析｜易错点：** ① 分离时 $dy$、$dx$ 各自配好系数，不要写反；② 积分后记得处理 $\ln|y|$ 的绝对值与 $\pm$ 号——解出 $y$ 时常以「去掉绝对值」和「正负并入常数」收尾；③ 常数 $C$ 的形式可随需要改写（$e^C$、$\ln C$ 等），但要在代数变形后保持通解「含一个任意常数」的本质。<span class="marginnote">常数的「改写技巧」：$\ln|y| = x + C$ 两边取指数得 $|y| = e^C e^x$，把 $e^C$ 记为新的 $C$（可正可负），于是 $y = Ce^x$。这种「常数吸收入新常数」的整理是微分方程解的标准体操。</span>

## 3 公式解析：冷却定律的完整求解

牛顿冷却定律：物体温度 $T$ 与环境的温差变化率与温差成正比，$\frac{dT}{dt} = -k(T - T_s)$，其中 $T_s$ 是环境温度、$k>0$。设物体初始温度 $T(0) = T_0$：

- **第一步，识别类型**：右端 $-k(T-T_s)$ 是「只含 $T$」的函数，可分离。
- **第二步，分离**：$\frac{dT}{T - T_s} = -k\,dt$。
- **第三步，积分**：$\ln|T - T_s| = -kt + C$，故 $T - T_s = Ce^{-kt}$。
- **第四步，定初值**：$t=0$ 时 $T_0 - T_s = C$，得
  $$T(t) = T_s + (T_0 - T_s)e^{-kt}$$

**关键**：冷却定律的解是「指数追赶」——温度从 $T_0$ 按指数衰减地逼近环境温度 $T_s$，永远追到但不越过（除非 $k$ 无穷大）。这个「指数松弛」模式在热传导、电路充电、模型收敛中反复出现——**一个可分离方程，导出半部工程科学的「松弛过程」**。

## 4 可分离方程的应用模型

可分离变量方程是「一阶增长/衰减模型」的总开关：

- **Malthus 人口模型**：$\frac{dP}{dt} = rP$ ⇒ $P = P_0 e^{rt}$——无资源约束的指数爆炸。
- **Logistic 模型**：$\frac{dP}{dt} = rP\left(1 - \frac{P}{K}\right)$ ⇒ 解为 $P = \frac{K}{1 + Ce^{-rt}}$——**带承载力的 S 形增长**，人口、传染病、技术采纳都符合。<span class="marginnote">Logistic 方程的解是一条 S 形曲线：起初近指数增长，接近承载力 $K$ 时增速放缓，最终稳定在 $K$。这个「上限约束的增长」模式是生态学、流行病学与市场营销的公共语言——一条微分方程，三种学科共享。</span>
**放射性衰变**：$\frac{dN}{dt} = -\lambda N$ ⇒ $N = N_0 e^{-\lambda t}$，半衰期 $T_{1/2}=\frac{\ln 2}{\lambda}$。
**混合问题**：容器中盐水的浓度变化 $\frac{dQ}{dt} = \text{流入} - \text{流出}$，也是可分离或一阶线性。

这些模型共通的数学结构：**$\frac{dy}{dt} = (\text{变化率因子}) \times (\text{当前量})$**——只要「变化率与当前量成正比（或成 S 形关系）」，就落进可分离方程的框架。

## 5 从可分离到一般一阶方程

可分离方程是「一阶方程求解」的起点，但很多方程右端不是「$g(x)h(y)$」的形式。后续的求解策略是「变形到可分离」：

**齐次方程**（下一节）：$\frac{dy}{dx} = f\left(\frac{y}{x}\right)$，令 $u=\frac{y}{x}$ 化为可分离；
**一阶线性方程**（再下一节）：$y' + P(x)y = Q(x)$，乘积分因子化为「可分离」型。

<span class="marginnote">整个一阶方程的求解路线图：<strong>可分离 → 齐次（换元可分离）→ 一阶线性（积分因子可分离）</strong>。可分离是地基，其余方法是「把新问题变回可分离」。学微分方程最重要的能力不是背公式，而是识别「这属于哪一类、该往哪个方向变形」。</span>

## 7 数值算例：初值问题的完整求解

解 $\frac{dy}{dx} = 2xy$，$y(0) = 1$。

**第一步，分离变量**：$\frac{dy}{y} = 2x\,dx$（$y \neq 0$）。
**第二步，两边积分**：$\ln|y| = x^2 + C$。
**第三步，定初值**：$y(0) = 1$ 代入得 $\ln 1 = 0 + C$，故 $C = 0$。
**第四步，解出 $y$**：$y = e^{x^2}$（去绝对值、吸收常数后正号）。
**第五步，验证**：$y' = 2x e^{x^2} = 2xy$ ✓；$y(0) = 1$ ✓。

**意义**：初值条件从「解族」$y = Ce^{x^2}$ 中挑出经过 $(0,1)$ 的那一条。几何上，$y = e^{x^2}$ 是斜率场中唯一过该点的积分曲线——**解的存在与唯一由初值决定**。<span class="marginnote">解的存在唯一性是常微分方程理论的核心问题（Picard 定理）：<strong>在一定光滑性条件下，初值问题恰好有一条解曲线</strong>。物理上这意味着「给定初始状态，系统演化唯一确定」——从牛顿力学到深度学习，这条「初值决定轨迹」的信条贯穿一切确定性动力系统。</span>

## 8 对照表：三大增长模型

| 模型 | 方程 | 解 | 特征 |
| --- | --- | --- | --- |
| Malthus（指数增长） | $P' = rP$ | $P_0e^{rt}$ | 无上限、指数爆炸 |
| Logistic（受限增长） | $P' = rP(1-\frac{P}{K})$ | $\frac{K}{1+Ce^{-rt}}$ | S 形、收敛到承载力 $K$ |
| 衰变 | $N' = -\lambda N$ | $N_0e^{-\lambda t}$ | 指数衰减、半衰期 $\frac{\ln2}{\lambda}$ |

三种模型共享一个骨架——「变化率与当前量成（正或反）比」，都是可分离方程。

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 分离时漏掉 $h(y)=0$ 的常数解 | 检查 $y=0$ 等常数解是否在通解中（$C=0$ 时） |
| $\ln|y|$ 忘处理 | 去绝对值、正负吸收入常数 $C$ |
| 先代入初值再求通解 | 先求通解，再定常数 |
| 分离方向写反 | $h(y)\,dy = g(x)\,dx$，$dy$ 与 $dx$ 各配好因子 |

## 10 从分离变量到现代动力学

可分离方程是最小的「动力学单元」，而现代复杂系统是它的高维扩展：

- **SIR 流行病模型**：$\frac{dS}{dt} = -\beta SI$ 等三个耦合方程——多变量版的可分离思想；
- **洛伦兹方程**：三个方程描述混沌——初始条件的微小差异被放大；
- **扩散方程**：$\frac{\partial u}{\partial t} = \alpha\nabla^2u$——偏微分方程版的「变化率 = 当前状态函数」。

理解分离变量「解耦 + 逐块积分」的思想，是进入这些复杂动力系统的第一级台阶。你在本节建立的「变化率 = 当前量函数」直觉，将贯穿微分方程课程的全部内容。

## 11 小结

- **可分离变量方程**：$\frac{dy}{dx} = g(x)h(y)$，分离成 $h(y)dy = g(x)dx$ 再分别积分。
- 初值问题可用定积分版：$\int_{y_0}^{y} h(y)dy = \int_{x_0}^{x} g(x)dx$。
- 注意 $h(y)=0$ 的常数解、$\ln|y|$ 的绝对值、常数的吸收改写。
- 解的存在唯一由初值决定——Picard 定理的思想。
- 应用模型：指数增长/衰减、Logistic、冷却定律、混合问题。
- 可分离是地基：齐次与一阶线性都「变形回可分离」。
