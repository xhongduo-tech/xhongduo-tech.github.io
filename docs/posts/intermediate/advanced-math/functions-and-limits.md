## 为什么从这里开始

第一章是整个高等数学的入口，也是唯一一个「概念比计算更难」的章节。函数是研究对象，极限是研究工具，连续是函数与极限相遇时产生的第一种优良性质。后面所有章节——导数、微分、积分、级数、微分方程——全部建立在「极限」这一个概念之上：导数是差商的极限，定积分是和的极限，无穷级数本身就是「部分和的极限」。

从「从极限到大模型」这条主线的视角看，极限不只是教科书上的形式定义。大模型训练中处处是极限：随机梯度下降在无限多步下的收敛、softmax 在温度趋于零时退化为 one-hot、注意力权重的归一化之和恒等于 1——它们本质上都是「某一过程趋近某一定值」的故事。第一章教给你的，正是给这些故事提供严密地基的语言。

本篇作为第 1 章的综述，把十个小节串成一条主线：先有函数这块舞台，再建立极限这台显微镜，最后用连续性把「显微镜下的局部行为」接回「整体函数」。我们按这个顺序走，每步都标注它在后续章节中的用法。

## 1 函数：微积分的舞台

函数是从定义域到值域的一个对应法则，记号是

$$f: X \to Y, \qquad x \mapsto f(x)$$

其中 $X$ 叫定义域，值域 $Y^* = \{f(x) : x \in X\} \subseteq Y$。第 1 章先系统复习了函数的四种基本特性：**有界性**（$|f(x)| \le M$）、**单调性**、**奇偶性**（$f(-x) = \pm f(x)$）、**周期性**（$f(x+T) = f(x)$）。<span class="marginnote">初等函数（幂、指、对、三角、反三角）是微积分的「常用词表」。全书所有例子几乎都从这五类函数取材，把它们的基本图像与定义域背熟，后面每一章都受益。</span>

基本初等函数与它们的四则运算、复合运算构成了**初等函数**类。复合函数 $f \circ g$ 的定义域要取「$x$ 使得 $g(x)$ 落在 $f$ 的定义域内」的部分——这是最容易出错的一步：定义域不是自动继承的，必须逐层检查。反函数则是把「给定 $y$ 求 $x$」反过来：$y = f(x) \iff x = f^{-1}(y)$，单值函数要严格单调才有反函数。

**辨析｜易错点：** 反函数与逆映射的记号容易混淆。$f^{-1}$ 表示反函数（若存在），$f^{-1}(y)$ 表示「使 $f(x)=y$ 的原像集合」——二者只有在 $f$ 是单射时才一致。另外，反函数的定义域是原函数的值域，不是原函数的定义域。

## 2 极限：从直觉到 $\varepsilon$-$\delta$

极限是本章的重头戏。核心思想一句话：**当自变量无限接近某点（或无限增大）时，函数值无限接近某个常数 $A$。** 但「无限接近」不能停留在直觉，否则会造出芝诺悖论式的糊涂账。微积分用 $\varepsilon$-$\delta$（函数）与 $\varepsilon$-$N$（数列）语言把直觉精确化。

数列极限 $\lim_{n \to \infty} x_n = a$ 的定义是：对任意 $\varepsilon > 0$，存在自然数 $N$，使当 $n > N$ 时恒有 $|x_n - a| < \varepsilon$。函数极限 $\lim_{x \to x_0} f(x) = A$ 则写成：对任意 $\varepsilon > 0$，存在 $\delta > 0$，使当 $0 < |x - x_0| < \delta$ 时恒有 $|f(x) - A| < \varepsilon$。<span class="marginnote">注意函数极限的定义要求 $0 < |x - x_0|$，即<strong>只看 $x_0$ 的去心邻域</strong>，与 $f(x_0)$ 本身取何值无关。这一点在讨论间断点时至关重要。</span>

有了定义之后，第 1 章给出了两个极其有用的判定工具：

- **夹逼准则**：若在 $x_0$ 附近 $g(x) \le f(x) \le h(x)$ 且 $\lim g(x) = \lim h(x) = A$，则 $\lim f(x) = A$。
- **单调有界准则**：单调有界的数列必收敛。它是证明「$\lim_{n \to \infty} (1 + \frac{1}{n})^n$ 存在」的幕后功臣。

## 3 极限的四则运算法则

有了 $\varepsilon$-$N$ 与 $\varepsilon$-$\delta$ 定义之后，若每个极限都从定义硬算，微积分将寸步难行。四则运算法则把「整体极限」拆成「部分极限的运算」：设 $\lim f(x) = A$、$\lim g(x) = B$，则

$$\lim [f(x) \pm g(x)] = A \pm B, \qquad \lim [f(x)g(x)] = AB, \qquad \lim \frac{f(x)}{g(x)} = \frac{A}{B}\ (B \ne 0)$$

其中除法要求分母极限非零。这条法则的直观含义是：**两个「趋于某值」的量相加、相乘、相除，结果仍趋于对应的值**——只要不撞上 $\frac{0}{0}$、$\frac{\infty}{\infty}$ 这类未定式。

**辨析｜易错点：** 四则运算法则的前提是「每个因子各自的极限存在」。$\lim_{x \to 0} \sin\frac{1}{x}$ 不存在，就不能写 $\lim \frac{\sin\frac1x}{x} = \frac{\lim\sin\frac1x}{\lim x}$。另外，幂运算 $\lim f(x)^{g(x)}$ 不能简单套乘法的结论，需要先取对数转化为乘积形式，这一步到第 5 章学完对数后自然水到渠成。

## 4 公式解析：两个重要极限

两个重要极限是全书出现频率最高的极限，务必做到「见形即认」：

$$\lim_{x \to 0} \frac{\sin x}{x} = 1, \qquad \lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e$$

拆开看第一式为什么成立：

- **第一步，从单位圆看几何。** 在单位圆中取圆心角 $x$（弧度制），扇形面积 $\frac{x}{2}$、三角形面积 $\frac{\sin x}{2}$、外切三角形面积 $\frac{\tan x}{2}$，三者夹出不等式 $\sin x < x < \tan x$。
- **第二步，同除以 $\sin x$。** 得 $1 < \frac{x}{\sin x} < \frac{1}{\cos x}$，取倒数后是 $\cos x < \frac{\sin x}{x} < 1$。
- **第三步，夹逼。** 因为 $\cos x \to 1$，由夹逼准则 $\frac{\sin x}{x} \to 1$。整个证明只需要三角函数定义 + 夹逼，没有更「高级」的技巧。

第二式 $\left(1+\frac{1}{x}\right)^x \to e$ 的证明靠单调有界准则：数列 $x_n = (1+\frac{1}{n})^n$ 单调递增且有上界，所以收敛，其极限记为 $e \approx 2.71828$。**辨析｜易错点：** $\lim_{x \to 0}(1+x)^{\frac{1}{x}} = e$ 与 $\lim_{x \to \infty}(1+\frac{1}{x})^x = e$ 是同一极限的两种写法——识别关键在「括号里的 $1$ 加一个趋于零的小量，指数是该小量的倒数」。

## 5 无穷小的比较与等价代换

当 $x \to x_0$ 时极限为 $0$ 的变量叫**无穷小**。比较两个无穷小的快慢，定义了阶的概念：若 $\lim \frac{\alpha}{\beta} = 0$ 则 $\alpha$ 是比 $\beta$ 高阶的无穷小，记 $\alpha = o(\beta)$；若比值为非零常数则同阶；比值等于 $1$ 则等价，记 $\alpha \sim \beta$。

等价无穷小是简化极限计算的利器。当 $x \to 0$ 时有如下常用等价关系：

$$x \sim \sin x \sim \tan x \sim \arcsin x \sim \arctan x \sim e^x - 1 \sim \ln(1+x), \qquad 1 - \cos x \sim \frac{x^2}{2}$$

**定理（等价代换）**：若 $\alpha \sim \alpha'$、$\beta \sim \beta'$，则在乘除运算中可以用 $\alpha'$ 替换 $\alpha$、用 $\beta'$ 替换 $\beta$ 而不改变极限。**辨析｜易错点：** 等价代换**只能用于乘除**，不能直接用于加减——$\lim_{x \to 0}\frac{\tan x - \sin x}{x^3}$ 若把分子两项各自换成 $x$ 会得到 $0$，是错答案；正确做法是先提出 $\tan x(1-\cos x)$ 再用等价。这是本段最经典的一个坑。

### 例：$\lim_{x \to 0}\frac{\tan x - \sin x}{x^3}$

**第一步，提公因式。** $\tan x - \sin x = \sin x(\frac{1}{\cos x} - 1) = \sin x \cdot \frac{1 - \cos x}{\cos x}$。

**第二步，等价代换。** $x \to 0$ 时 $\sin x \sim x$、$1 - \cos x \sim \frac{x^2}{2}$、$\cos x \to 1$，于是原极限化为

$$\lim_{x \to 0} \frac{x \cdot \frac{x^2}{2}}{x^3} = \frac{1}{2}$$

**第三步，检查。** 答案 $\frac{1}{2}$ 与泰勒展开验证一致——这就反证了「分子两项各自代换成 $x$」为什么错：加法破坏了同步消去的阶数，只有提出公因式后乘法域内的代换才安全。

## 6 核心对比表：数列极限与函数极限

| 维度 | 数列极限 | 函数极限 |
| --- | --- | --- |
| 记号 | $\lim_{n \to \infty} x_n = a$ | $\lim_{x \to x_0} f(x) = A$ |
| 自变量 | $n$ 取正整数，离散 | $x$ 连续趋近 $x_0$ |
| 精确语言 | $\varepsilon$-$N$：$n > N \Rightarrow \|x_n - a\| < \varepsilon$ | $\varepsilon$-$\delta$：$0<\|x-x_0\|<\delta \Rightarrow \|f(x)-A\|<\varepsilon$ |
| 单向/双向 | 只往 $+\infty$ 跑 | 可从左右两侧逼近 |
| 判定工具 | 单调有界准则、夹逼 | 左右极限相等、夹逼、海涅定理 |
| 沟通桥梁 | — | 海涅定理：$x_n \to x_0$ 时 $f(x_n) \to A$ |

这张表告诉你：数列极限是函数极限的「离散采样版」，海涅定理把两者焊在一起，使「以离散验证连续」成为可能。判断函数在某点无极限，最常用手段就是挑两条不同的趋于 $x_0$ 的数列让函数值趋于不同极限。

## 7 连续性：把极限接回函数

**函数在 $x_0$ 处连续**的定义：$\lim_{x \to x_0} f(x) = f(x_0)$，即极限存在、函数有定义、且两者相等。若函数在区间内每点连续则称在该区间上连续。初等函数在其定义区间内都是连续的——这条结论让「求连续函数的极限」退化为「代点」。

间断点按极限行为分类：可去间断点（左右极限存在且相等但不等于函数值或函数无定义）、跳跃间断点（左右极限存在但不相等）、第二类间断点（至少一侧极限不存在，如无穷间断、振荡间断）。<span class="marginnote">分段函数在分界点的连续性是考试重点：先算左右极限，再看是否等于分段处的函数值，三处同时满足才连续。</span>

闭区间上连续函数有三条黄金性质：**最值定理**（有界并取到最大最小值）、**零点定理**（$f(a)f(b) < 0$ 则 $(a,b)$ 内存在零点）、**介值定理**。零点定理是「证明方程有根」的标准工具，也是后续数值解法（二分法）的理论依据。

## 8 小结

- 第一章给微积分立了两块基石：**函数**是研究对象，**极限**是研究工具；导数、积分、级数全由极限定义。
- 两个重要极限 $\lim_{x\to0}\frac{\sin x}{x}=1$ 与 $\lim_{x\to\infty}(1+\frac1x)^x=e$，靠夹逼与单调有界证明，靠「见形即认」使用。
- 等价无穷小代换只用于**乘除**，加减代换是高频错点。
- 连续性 = 极限存在 + 有定义 + 相等；闭区间连续函数保证最值与介值性质。
- 海涅定理在数列与函数极限之间架桥，是证明极限不存在的利器。

在下一节，我们将把「极限」这个工具对准函数的变化率，建立全书第二块基石——**导数与微分**。你会发现，导数定义里那个差商的极限，正是本章所有功夫的第一个用武之地。
