## 为什么从无穷小的比较开始

上一节我们认识了无穷小——极限为 0 的量，并借助夹逼准则求出了 $\lim\limits_{x\to0}\frac{\sin x}{x}=1$。细看这个极限：分子分母都是无穷小，而比值却不一定是 0 或 $\infty$，它可以是 1。这说明**无穷小与无穷小之间也有快慢之分**：$\sin x$ 趋零的速度和 $x$ 趋零的速度几乎一样快，所以比值收敛到 1；而 $x^2$ 趋零的速度比 $x$ 快得多，比值 $\frac{x^2}{x}$ 就趋于 0。把「谁比谁快」精确量化，就是**无穷小的比较**。它不仅是极限计算的分流器，更是下一章洛必达法则、泰勒公式的度量标尺。<span class="marginnote">「趋零速度」的直觉在数值上非常明显：$x=0.001$ 时 $x=10^{-3}$，而 $x^2=10^{-6}$——$x^2$ 比 $x$ 小了整整三个数量级。无穷小比较就是把这种「数量级差距」上升为数学语言。</span>

## 1 阶的概念

设 $\alpha, \beta$ 是 $x \to x_0$ 时的无穷小（即 $\lim \alpha = \lim \beta = 0$），用比值的极限来刻画它们趋零的相对快慢：

若 $\lim \dfrac{\beta}{\alpha} = 0$，则称 $\beta$ 是比 $\alpha$ **高阶的无穷小**，记作 $\beta = o(\alpha)$。<span class="marginnote">记作 $o(\alpha)$ 表示「$\beta$ 比 $\alpha$ 小一个量级」，读作「小欧」；$o$ 取自英文 order（阶）。$o(x)$ 是一类函数的集合记号，比如 $x^2 = o(x)$，$x^3 = o(x^2)$。</span>
若 $\lim \dfrac{\beta}{\alpha} = \infty$，则称 $\beta$ 是比 $\alpha$ **低阶的无穷小**。
若 $\lim \dfrac{\beta}{\alpha} = c \ne 0$（$c$ 为常数），则称 $\beta$ 与 $\alpha$ **同阶无穷小**。
特别地，若 $c = 1$，即 $\lim \dfrac{\beta}{\alpha} = 1$，则称 $\beta$ 与 $\alpha$ **等价无穷小**，记作 $\beta \sim \alpha$。
若 $\lim \dfrac{\beta}{\alpha^k} = c \ne 0$，则称 $\beta$ 是 $\alpha$ 的 **$k$ 阶无穷小**。

**重点：高阶、低阶、同阶、等价，全部由「比值的极限」这一个动作决定。** 判断两个无穷小谁快谁慢，永远回到 $\dfrac{\beta}{\alpha}$ 的极限，而不是凭直觉猜。

## 2 常见等价无穷小

当 $x \to 0$ 时，有一张高频使用的「等价无穷小表」：

| 等价关系 | 条件 |
| --- | --- |
| $\sin x \sim x$ | $x \to 0$ |
| $\tan x \sim x$ | $x \to 0$ |
| $\arcsin x \sim x$ | $x \to 0$ |
| $1 - \cos x \sim \dfrac{x^2}{2}$ | $x \to 0$ |
| $\ln(1+x) \sim x$ | $x \to 0$ |
| $e^x - 1 \sim x$ | $x \to 0$ |
| $(1+x)^a - 1 \sim a x$ | $x \to 0$ |
| $a^x - 1 \sim x \ln a$ | $x \to 0$ |

这张表不是背出来的，而是从重要极限与后续的泰勒公式里长出来的：$\lim\frac{\sin x}{x}=1$ 就是 $\sin x \sim x$；$\lim\frac{e^x-1}{x}=1$ 需要借助换元 $t = e^x -1$ 与重要极限。<span class="marginnote">表中大多数式子都是「一次项近似」：在 $x=0$ 附近，$e^x \approx 1+x$、$\ln(1+x) \approx x$、$\sin x \approx x$。这正是线性近似的雏形，到泰勒公式那一节会被推广成更高次的近似。</span>

## 3 等价无穷小代换

**等价无穷小代换定理**：在求**乘除**式极限时，无穷小因子可以用其等价无穷小替换，极限值不变。若 $\alpha \sim \alpha'$，$\beta \sim \beta'$，则

$$\lim \frac{\beta}{\alpha} = \lim \frac{\beta'}{\alpha'}$$

这条定理威力巨大，它把「含 $\sin x$、$\tan x$、$\ln(1+x)$ 的复杂极限」瞬间变成「多项式极限」。

$$\lim_{x \to 0} \frac{\tan x}{\sin 3x} = \lim_{x \to 0} \frac{x}{3x} = \frac{1}{3}$$

**辨析｜易错点：等价无穷小只能替换乘除中的因子，绝不能替换加减中的「项」。** 例如 $\lim\limits_{x\to0}\frac{\sin x - x}{x^3}$ 中，若把 $\sin x$ 替换成 $x$，分子变成 0，直接错杀——因为 $\sin x$ 与 $x$ 的差别（$-x^3/6$ 量级）恰恰被分母 $x^3$ 放大了。正确的做法是等学到泰勒公式后用 $\sin x = x - \frac{x^3}{6} + o(x^3)$。这条界限是本章最经典的坑。

## 4 公式解析：等价无穷小代换的边界

$$\lim_{x \to 0} \frac{\ln(1 + 2x)}{\sqrt{1 + x} - 1}$$

- **第一步，识别因子**：分子 $\ln(1+2x)$ 与分母 $\sqrt{1+x}-1$ 都是 $x \to 0$ 时的无穷小，且都出现在乘除位置，可考虑代换。
- **第二步，逐一代换**：$\ln(1+2x) \sim 2x$；对分母用 $(1+x)^a - 1 \sim ax$ 令 $a=\frac{1}{2}$，得 $\sqrt{1+x}-1 \sim \frac{1}{2}x$。
- **第三步，比值化简**：原式 $\to \lim\limits_{x\to0}\dfrac{2x}{\frac{1}{2}x} = 4$。

注意分子是 $2x$ 而非 $x$——代换时**必须连同系数一起换**。若误以为 $\ln(1+2x)\sim x$，答案就会错成 2。系数的保留，是这张代换表最常见的失分点。

## 5 为什么要给无穷小「排序」

无穷小比较并非极限计算的游戏，它直接服务于三件大事：

- **线性近似**：$\sin x \sim x$ 意味着在 $x=0$ 附近用直线 $y=x$ 替代曲线 $y=\sin x$，误差是更高阶无穷小。微分、切线、局部线性化全都建立在这一步。
- **精度分层**：说「$1-\cos x$ 与 $x^2/2$ 同阶」等价于说「$1-\cos x$ 是 $x$ 的二阶无穷小」——它告诉我们这个量在 $x \to 0$ 时按平方速度消失，为泰勒展开的截断误差提供依据。<span class="marginnote">数值分析里的「收敛阶」、计算复杂度里的「主项」、误差分析里的「主误差项」，都是同一套「谁先消失」的思维。到第九级《数值分析》我们会看到它以收敛速率的形式再次登场。</span>
- **求极限的优先级**：同一道极限题，等价无穷小代换通常比洛必达更快、更安全（洛必达求完还可能回到 $\frac{0}{0}$）。

## 6 小结

- 无穷小的高阶、低阶、同阶、等价，**全部由比值 $\frac{\beta}{\alpha}$ 的极限判定**。
- 等价无穷小记作 $\beta \sim \alpha$，含义是 $\lim \frac{\beta}{\alpha} = 1$。
- 常见等价无穷小表：$\sin x \sim x$、$\tan x \sim x$、$1-\cos x \sim \frac{x^2}{2}$、$\ln(1+x) \sim x$、$e^x - 1 \sim x$ 等，$x \to 0$ 时成立。
- **等价无穷小只能代换乘除因子，不可代换加减项**——这是本章最大的易错点。
- 无穷小比较是线性近似、精度分层与高效求极限的共同地基。

在下一节，我们将离开「极限过程」本身，转向「极限值等于函数值」的优良性质——这就是**函数的连续性与间断点**。
