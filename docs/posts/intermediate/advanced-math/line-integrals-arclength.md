## 为什么从对弧长的曲线积分开始

定积分沿直线累加，二重积分在平面上累加；但现实里有大量「沿弯曲路径累加」的场景——不均匀线密度细丝的质量、曲线的质心、沿路径的总热量。**对弧长的曲线积分（第一型曲线积分）**就是「沿曲线按弧长累加」的积分。它把一元定积分的「区间」换成了「空间曲线」，把「长度微元 $dx$」换成了「弧长微元 $ds$」。它是曲线积分的入门，也是理解第二型曲线积分（对坐标）与物理「沿路径积量」的基础。<span class="marginnote">第一型曲线积分的直观：<strong>$\int_L f(x,y)\,ds$ = 沿曲线 $L$ 把「线密度 $f$」逐段累加</strong>。$f$ 是「单位弧长的量」，$ds$ 是「弧长微元」，积分是「密度 × 弧长」的总和。若 $f\equiv1$，$\int_L ds$ 就是曲线长度——弧长是它的特例。</span>

## 1 对弧长曲线积分的定义

设 $L$ 是 $xOy$ 平面内的一条光滑曲线，$f(x,y)$ 在 $L$ 上有界。将 $L$ 任意分成 $n$ 个小弧段 $\Delta s_i$（也表示弧长），每段内任取 $(\xi_i, \eta_i)$，作和 $\sum f(\xi_i,\eta_i)\Delta s_i$。若 $\lambda\to0$ 时极限存在且与分割、取点无关，则称该极限为 $f$ 沿 $L$ 对弧长的曲线积分：

$$\int_L f(x,y)\,ds = \lim_{\lambda\to0}\sum_{i=1}^{n} f(\xi_i,\eta_i)\,\Delta s_i$$

**性质**：线性性；**与方向无关**（$\int_L f\,ds = \int_{-L} f\,ds$，因为 $ds>0$ 总是正的）；区域可加性（分段曲线分段积）。<span class="marginnote">第一型曲线积分与方向无关，因为 $ds$ 是「长度微元」——长度没有正负方向。这与第二型曲线积分（对坐标，方向相反则变号）形成鲜明对比。物理直觉：细丝的质量与「从哪头开始量」无关。空间曲线 $L$（三维）的定义完全类似，$\int_L f(x,y,z)\,ds$。</span>

## 2 对弧长曲线积分的计算

设曲线 $L$ 由参数方程 $\begin{cases}x = \varphi(t)\\ y = \psi(t)\end{cases}$（$\alpha \le t \le \beta$）给出，$\varphi,\psi$ 有连续导数且不同时为零，则弧长微元 $ds = \sqrt{\varphi'^2(t) + \psi'^2(t)}\,dt$，有

$$\int_L f(x,y)\,ds = \int_\alpha^\beta f(\varphi(t), \psi(t))\sqrt{\varphi'^2(t) + \psi'^2(t)}\,dt$$

**公式解析：弧长微元 $ds$ 的代入**

$$ds = \sqrt{\varphi'^2(t) + \psi'^2(t)}\,dt$$

- **第一步，回顾弧长微元**：第八章学过 $ds = \sqrt{(dx)^2 + (dy)^2}$——勾股合成的「弦长微元」。
- **第二步，参数化**：$dx = \varphi'(t)dt$、$dy = \psi'(t)dt$，代入得 $ds = \sqrt{\varphi'^2 + \psi'^2}\,dt$。
- **第三步，替换**：被积函数中 $x,y$ 换成 $\varphi(t),\psi(t)$，$ds$ 换成上式，积分化为对 $t$ 的一元定积分。

**关键**：计算第一型曲线积分的流程是「**参数化 → 代入 → 套 $ds$ 公式 → 一元积分**」。$y=f(x)$ 型曲线（$L: y=\varphi(x)$）对应 $ds = \sqrt{1+\varphi'^2}\,dx$，与第六章弧长公式一致。

## 3 公式解析：细丝质量

求线密度 $\rho(x,y) = x^2$ 的圆弧 $x^2+y^2 = a^2$（第一象限部分）的质量：

- **第一步，参数化**：$x = a\cos t$，$y = a\sin t$，$0 \le t \le \frac{\pi}{2}$。
- **第二步，算 $ds$**：$\varphi' = -a\sin t$，$\psi' = a\cos t$，$ds = \sqrt{a^2\sin^2 t + a^2\cos^2 t}\,dt = a\,dt$。
- **第三步，代被积函数**：$\rho = x^2 = a^2\cos^2 t$。
- **第四步，积分**：$M = \int_0^{\pi/2} a^2\cos^2 t\cdot a\,dt = a^3\int_0^{\pi/2}\cos^2 t\,dt = a^3\cdot\frac{\pi}{4}$。

**关键**：圆弧上 $ds = a\,dt$（半径 × 角微元），被积函数参数化后积分化为标准三角积分。这道「不均匀密度细丝质量」题展示了第一型曲线积分的典型流程——**先参数化，再算 $ds$，然后一元积分**。

## 4 第一型曲线积分的应用

第一型曲线积分是「沿曲线的总量累加」：

- **曲线质量**：$M = \int_L \rho(x,y)\,ds$——线密度不均匀的细丝/导线质量。
- **曲线质心**：$\bar x = \frac{1}{M}\int_L x\rho\,ds$、$\bar y = \frac{1}{M}\int_L y\rho\,ds$——沿曲线的质量加权平均。
- **转动惯量**：$I_x = \int_L y^2\rho\,ds$ 等。
- **曲线长度**：$s = \int_L ds$——$f\equiv1$ 的特例。
- **空间曲线**：$\int_L f(x,y,z)\,ds$——弹簧、螺线的质量与质心。

<span class="marginnote">这些应用与第六章、第十章「密度 × 微元」模板完全一致，只是「微元」换成了弧长 $ds$——第一型曲线积分就是「沿曲线的元素法」。从一维直线（$dx$）到平面区域（$d\sigma$）到空间立体（$dV$）到曲线（$ds$），「密度 × 微元」的思想贯穿全部积分学。</span>

## 5 曲线积分的两型之分

曲线积分有两型，理解它们的区别是本章的钥匙：

| | 第一型（对弧长） | 第二型（对坐标，下一节） |
| --- | --- | --- |
| 记号 | $\int_L f\,ds$ | $\int_L P\,dx + Q\,dy$ |
| 微元 | 弧长 $ds$（标量） | 坐标 $dx, dy$（带方向） |
| 与方向的关系 | 无关 | 反向变号 |
| 物理意义 | 线密度累加、质量 | 变力沿曲线做的功 |

<span class="marginnote">记忆锚：<strong>「弧长不看方向，坐标看方向」</strong>。第一型积分沿曲线「走过去再走回来」结果不变（长度累加），第二型「走过去再走回来」是负的（做功方向相反）。到下一节你会看到，第二型积分才是「功」的正确数学表述。</span>

## 7 数值算例：悬链线的弧长

求悬链线 $y = \cosh x$ 从 $x=0$ 到 $x=1$ 的弧长。

**第一步，算导数**：$y' = \sinh x$，$1+y'^2 = 1 + \sinh^2 x = \cosh^2 x$。
**第二步，写 $ds$**：$ds = \sqrt{1+y'^2}\,dx = \cosh x\,dx$——巧用恒等式 $\cosh^2 - \sinh^2 = 1$。
**第三步，积分**：$s = \int_0^1 \cosh x\,dx = \sinh x\Big|_0^1 = \sinh 1$。

**要点**：弧长积分的关键是「让 $\sqrt{1+y'^2}$ 变成可积的形式」——悬链线用双曲恒等式一步化出 $\cosh x$，这正是「$y=f(x)$ 型 $ds$ 公式」的典型应用。<span class="marginnote">弧长计算是「求积分」与「几何长度」的交汇点：$\int_L ds$ 是第一型曲线积分在 $f\equiv1$ 时的特例。悬链线是「两端悬挂的绳索」的平衡形状，它的弧长正是你用电线杆上的电缆时看到的几何——一条积分，连接了数学与工程。</span>

## 8 对照表：几种微元的来源

| 对象 | 微元 | 来源 |
| --- | --- | --- |
| 直线 $x$ 轴 | $dx$ | — |
| 平面曲线 | $ds = \sqrt{1+y'^2}\,dx$ | 勾股：$\sqrt{(dx)^2+(dy)^2}$ |
| 参数曲线 | $ds = \sqrt{\varphi'^2+\psi'^2}\,dt$ | $dx=\varphi'dt$ 代入 |
| 空间曲线 | $ds = \sqrt{x'^2+y'^2+z'^2}\,dt$ | 三维勾股 |

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 忘算 $ds$ 直接积分 | 必须先求 $\sqrt{\varphi'^2+\psi'^2}$ |
| $ds$ 与 $dx$ 混淆 | $ds \ge dx$，曲线越斜差距越大 |
| 参数化后积分限写错 | 按参数 $t$ 的范围定限 |
| 被积函数没参数化 | $f(x,y)$ 要换成 $f(\varphi(t),\psi(t))$ |

## 10 第一型曲线积分与现代应用

「沿曲线累加」的能力在工程与物理中广泛使用：

- **土木**：悬索桥主缆的受力与长度分析用曲线积分；
- **物理**：电荷沿导线的分布、细棒转动惯量；
- **计算几何**：样条曲线长度、路径规划中的「路径代价」；
- **图形学**：曲线渲染中的弧长参数化（等速插值）。

「密度 × 弧长微元」的模板，从一维直线延伸到空间曲线——第一型曲线积分是「沿几何对象积分」这个大家族在曲线维度的一环。

## 11 小结

- **第一型曲线积分**：$\int_L f\,ds$，沿曲线按弧长累加「线密度」。
- 与方向无关（$ds$ 恒正）；线性、分段可加。
- 计算：**参数化 → 代入 → $ds=\sqrt{\varphi'^2+\psi'^2}dt$ → 一元积分**。
- $ds$ 的三种来源：$y=f(x)$ 型、参数型、空间曲线型。
- 应用：曲线质量、质心、转动惯量、弧长——「沿曲线的元素法」。
- 与第二型对比：「弧长不看方向，坐标看方向」。

在下一节，我们将学习带方向的曲线积分——**对坐标的曲线积分**。
