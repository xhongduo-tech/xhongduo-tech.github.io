## 为什么需要「对区域积分」

第五章的定积分求「区间上的总量」，但真实对象往往是「平面区域上的总量」：平板的质量（密度随位置变化）、曲面下的体积、薄板的质心与转动惯量。**重积分**把定积分从一维区间推广到平面区域（二重）与空间区域（三重）。

**二重积分**的定义沿用定积分的「分割、求和、取极限」：把区域 $D$ 分成小片，取每片中一点作函数值，乘小片面积再求和，取极限得

$$\iint_D f(x,y)\,d\sigma = \lim \sum_{i=1}^{n} f(\xi_i,\eta_i)\,\Delta\sigma_i$$

几何上，$f \ge 0$ 时它是曲面 $z=f(x,y)$ 下方、区域 $D$ 上方的**曲顶柱体体积**；$f \equiv 1$ 时它就是区域 $D$ 的面积。性质与定积分平行：线性性、可加性、保号性、估值与中值定理。<span class="marginnote">「把平面区域切成小片再求和」正是计算图像直方图、把连续分布离散化的思维方式；二重积分是「二维累加」的原型，而三维的分布（如词向量分布）则是三重积分式的累加。</span>

## 1 二重积分的计算：化累次积分

二重积分的直接定义几乎无法用于计算，实用路径是**化成累次积分（先积一重再积一重）**。关键在于区域 $D$ 的两种刻画：

**X 型区域**：$D = \{(x,y) : a \le x \le b,\ \varphi_1(x) \le y \le \varphi_2(x)\}$，则

$$\iint_D f(x,y)\,d\sigma = \int_a^b \left[\int_{\varphi_1(x)}^{\varphi_2(x)} f(x,y)\,dy\right]dx$$

**Y 型区域**：$D = \{(x,y) : c \le y \le d,\ \psi_1(y) \le x \le \psi_2(y)\}$，则

$$\iint_D f(x,y)\,d\sigma = \int_c^d \left[\int_{\psi_1(y)}^{\psi_2(y)} f(x,y)\,dx\right]dy$$

**选择 X 型还是 Y 型，看哪边上下限更好写、内层积分更好算。** 若区域既非 X 型也非 Y 型，就拆成几块分别积分再相加。<span class="marginnote">内层积分的上下限是<strong>函数</strong>（随外层变量变化），外层积分的上下限是<strong>常数</strong>——这是累次积分最易写错的地方。画图 + 判断「先对谁积」是每次计算的第一步。</span>

**换序积分**是重要技巧：当一种顺序难算（如内层 $\int e^{x^2}dx$ 无初等原函数），换成另一种顺序常迎刃而解。换序的本质是「重新描述同一区域」——画出区域、换描述方式、再积。

### 例：交换 $I = \int_0^1\int_x^1 e^{y^2}dy\,dx$ 的积分次序

**第一步，画出区域。** 外层 $0\le x\le1$，内层 $x\le y\le1$——这是由 $y=x$、$y=1$、$x=0$ 围成的三角形。

**第二步，换 Y 型描述。** 同区域写成 $0\le y\le1$、$0\le x\le y$。

**第三步，换序后积分。** $I = \int_0^1\left[\int_0^y e^{y^2}dx\right]dy = \int_0^1 y\,e^{y^2}dy = \frac12(e - 1)$。

关键点：内层 $e^{y^2}$ 对 $y$ 无初等原函数，直接先对 $y$ 积会卡死；换序后内层对 $x$ 积只是乘个 $y$，外层 $\int ye^{y^2}dy$ 由凑微分一步完成。这个例子是「换序破死局」的经典演示。

### 例：计算 $I = \iint_D xy\,d\sigma$，其中 $D$ 为 $0\le x\le1$、$0\le y\le1$ 的单位正方形

**第一步，选顺序。** 两种顺序都可行，任选 X 型：内层对 $y$ 积，外层对 $x$ 积。

**第二步，写累次积分。** $I = \int_0^1\left[\int_0^1 xy\,dy\right]dx$。

**第三步，先内后外。** 内层 $\int_0^1 xy\,dy = \frac{x}{2}$；外层 $\int_0^1\frac{x}{2}\,dx = \frac{1}{4}$。

**第四步，对称校验。** 由于 $f(x,y) = xy$ 关于 $x$、$y$ 对称且区域是正方形，答案 $\frac14$ 也可由「独立积分相乘」$\left(\int_0^1 x\,dx\right)\left(\int_0^1 y\,dy\right) = \frac12\cdot\frac12$ 得到——矩形区域上可分离变量的函数，二重积分等于两个定积分之积，这一性质常用来快速验算。

## 2 极坐标下的二重积分：圆形区域的利器

当区域是圆、扇形、环，或被积函数含 $x^2+y^2$ 时，用**极坐标**：$x = r\cos\theta$、$y = r\sin\theta$，面积元素变为

$$d\sigma = r\,dr\,d\theta$$

积分公式为 $\iint_D f(x,y)\,d\sigma = \iint_{D'} f(r\cos\theta, r\sin\theta)\,r\,dr\,d\theta$。极坐标下的关键计算要点：

- **多一个因子 $r$**：这是极坐标换元的「雅可比行列式」——$d\sigma = r\,dr\,d\theta$ 中的 $r$ 不能丢。它反映了「远离极点的小片被放大」的几何事实。
- **区域刻画**：圆 $x^2+y^2 \le R^2$ 变为 $0 \le r \le R$、$0 \le \theta \le 2\pi$；扇形变为 $r$、$\theta$ 各取常值区间。
- **经典积分**：$\iint_{x^2+y^2\le R^2} e^{-(x^2+y^2)}d\sigma = 2\pi\int_0^R re^{-r^2}dr = \pi(1-e^{-R^2})$，取极限得 $\int_{-\infty}^{+\infty}e^{-x^2}dx = \sqrt{\pi}$——高斯积分的标准推导，正是借助极坐标二重积分完成，这是概率论与统计的基石。

**公式解析：为什么 $d\sigma = r\,dr\,d\theta$**。极坐标把平面分成「小圆环扇」：半径 $r$ 到 $r+dr$、角度 $\theta$ 到 $\theta+d\theta$。这个小片的面积近似为「弧长 $r\,d\theta$ × 径向宽 $dr$」，即 $r\,dr\,d\theta$。弧长之所以是 $r\,d\theta$ 而非 $d\theta$，是因为离原点越远，同样角度差对应的弧越长——这正是 $r$ 因子出现的根源，也是换元公式 $dx\,dy \to |J|\,dr\,d\theta$ 中雅可比行列式 $J = r$ 的直观解释。

## 3 三重积分：从平面走向空间

**三重积分** $\iiint_\Omega f(x,y,z)\,dV$ 在空间区域 $\Omega$ 上累加，体积元素 $dV = dx\,dy\,dz$。计算同样化累次积分，常用两种坐标：

**直角坐标**：把 $\Omega$ 描述为「外层 $(x,y)$ 区域 + 内层 $z$ 的上下限函数」：

$$\iiint_\Omega f\,dV = \iint_D \left[\int_{z_1(x,y)}^{z_2(x,y)} f(x,y,z)\,dz\right]d\sigma$$

**柱坐标**：$\begin{cases} x = r\cos\theta \\ y = r\sin\theta \\ z = z \end{cases}$，体积元素 $dV = r\,dr\,d\theta\,dz$——相当于「极坐标平面 × 竖轴」，适合圆柱、锥体、旋转体。**球坐标**：$\begin{cases} x = \rho\sin\phi\cos\theta \\ y = \rho\sin\phi\sin\theta \\ z = \rho\cos\phi \end{cases}$，体积元素 $dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta$，适合球、锥。

**辨析｜易错点：** 球坐标里 $\rho^2\sin\phi$ 是体积因子，其中 $\phi$ 是极角（与 $z$ 轴的夹角，$0\le\phi\le\pi$）、$\theta$ 是方位角（$0\le\theta\le2\pi$）。半径 $\rho$、极角 $\phi$、方位角 $\theta$ 三者各自的范围最容易写错，务必结合几何图形确认。

## 4 重积分的应用：质心、转动惯量与引力

重积分最实用的应用是物理量的「加权求和」：

- **质心**：$\bar x = \frac{1}{M}\iint_D x\,\rho\,d\sigma$（$\rho$ 为面密度，$M = \iint_D \rho\,d\sigma$ 为总质量）。均匀薄板的质心也叫**形心**。
- **转动惯量**：对 $x$ 轴 $I_x = \iint_D y^2\,\rho\,d\sigma$，对 $y$ 轴 $I_y = \iint_D x^2\,\rho\,d\sigma$，对原点的极转动惯量 $I_0 = I_x + I_y$。
- **平面薄片对质点的引力**：按「微元法」对每个小片写出引力微元，再积二重积分。
- **三重积分版**：空间立体的质心、转动惯量、引力同理，只是把区域换成 $\Omega$、密度写成 $\rho(x,y,z)$。

这些应用全部遵循「微元 → 积分」模板：先写出质量/力矩/惯量的微元，再在整个区域上积分。<span class="marginnote">「把密度乘上去再积分」正是「加权平均」的连续版——大模型中的归一化、期望、注意力加权平均，都可看作「以权重为密度的重积分」的离散化。</span>

**辨析｜易错点：** 质心公式里分母是总质量 $M$，分子是各分量的一阶矩——先算 $M$，再算 $\iint x\rho\,d\sigma$，最后相除。转动惯量里是「到轴距离的平方」乘密度，不要漏掉平方：对 $x$ 轴是 $y^2$，对 $y$ 轴是 $x^2$，平方写错是这类题最普遍的失误。用「均匀薄圆盘绕中心转动惯量 $\frac12 MR^2$」这类已知结果验算，能迅速暴露公式记错。

## 5 含参变量的积分

**含参变量的积分**形如 $I(\alpha) = \int_c^d f(x,\alpha)\,dx$，其中 $\alpha$ 是参数。它的微积分性质（对 $\alpha$ 的连续、可导、可积）是「把积分当作参数的函数」来研究：

$$\frac{d}{d\alpha}\int_c^d f(x,\alpha)\,dx = \int_c^d \frac{\partial f(x,\alpha)}{\partial \alpha}\,dx$$

即「积分号下求导」（莱布尼茨法则）——在适当条件下，导数可以穿进积分号。这是处理含参积分的核心工具：先对参数求导化简，再积分还原。典型操作如计算 $I(\alpha) = \int_0^1 x^\alpha dx$（$\alpha>-1$），先直接积出 $\frac{1}{\alpha+1}$；对 $\alpha$ 求导又可得到 $\int_0^1 x^\alpha\ln x\,dx = -\frac{1}{(\alpha+1)^2}$——用「对参数求导」这一招，就免去直接算含 $\ln x$ 的积分。它在概率论（矩生成函数对参数求导）、信号处理（傅里叶变换对频率求导）、统计物理（配分函数求导得期望）中都反复出现，是「以参数为桥梁」的高级积分技巧。

**辨析｜易错点：** 莱布尼茨法则对「积分区间含参数」的情形另有完整公式（需加入边界项），初学者常误用「导数直接穿进」处理可变上限的积分。正确做法是用变上限积分定理：$\frac{d}{dx}\int_a^{x}f(t,\alpha)dt = f(x,\alpha) + \int_a^x\frac{\partial f}{\partial\alpha}dt$——上下限是参数的函数时，边界贡献不可忽略。

## 6 小结

- 二重积分是「平面区域上的累加」，定义沿用分割-求和-取极限，$f\equiv1$ 时即面积。
- 计算靠化累次积分：X 型 / Y 型区域选好先后，内层限是函数、外层限是常数。
- 极坐标下 $d\sigma = r\,dr\,d\theta$ 的 $r$ 是雅可比因子，也是高斯积分 $\sqrt\pi$ 推导的钥匙。
- 三重积分用直角、柱（$r\,drd\theta dz$）、球（$\rho^2\sin\phi$）三种坐标，按区域形状选。
- 质心、转动惯量、引力都是「微元 → 积分」的加权求和模板。
- 含参变量积分允许「积分号下求导」，是高级积分技巧与概率统计的桥梁。

在下一节，我们将把积分从「区域内部」推广到「区域边界」——**曲线积分与曲面积分**。格林公式、高斯公式与斯托克斯公式会把「内部积分」与「边界积分」联系起来，展现微积分最深刻的结构之美。
