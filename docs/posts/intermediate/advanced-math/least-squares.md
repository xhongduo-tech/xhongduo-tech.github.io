## 为什么从最小二乘法开始

实验测得一组数据 $(x_i, y_i)$，想找一条直线「最好地」穿过它们——但数据有噪声，直线不可能穿过所有点。怎么定义「最好」？**最小二乘法**的回答：让所有点「竖直偏差的平方和」最小。它把「拟合」变成「求二次函数的最小值」——这正是上一节多元极值理论的直接应用。最小二乘法是统计学回归分析、科学实验数据拟合、以及机器学习线性回归的共同基础，也是「从数据中学习」的数学原点。<span class="marginnote">勒让德 1805 年正式发表最小二乘，高斯声称早在 1795 年就使用。它的思想极美：<strong>「最好」= 残差平方和最小</strong>。为什么用平方而不是绝对值？因为平方函数光滑（处处可导），能求导找最小值，而绝对值函数有尖点。这个「选光滑目标函数」的考量在机器学习里反复出现。</span>

## 1 问题的提出

设观测数据 $(x_1, y_1), (x_2, y_2), \ldots, (x_n, y_n)$，希望用直线 $y = ax + b$ 拟合。直线在 $x_i$ 处的预测值是 $ax_i + b$，与实测 $y_i$ 的**偏差（残差）**为

$$\varepsilon_i = y_i - (a x_i + b)$$

**最小二乘原则**：选择 $a, b$ 使**残差平方和**最小：

$$S(a, b) = \sum_{i=1}^{n} \varepsilon_i^2 = \sum_{i=1}^{n} (y_i - a x_i - b)^2$$

这是关于 $a, b$ 的**二元二次函数**——求它的最小值正是上一节多元极值问题。<span class="marginnote">「平方和最小」的选择理由：① 光滑可导，能求导找极值；② 对大偏差惩罚更重（平方放大），避免个别野点主导；③ 高斯从概率角度证明：误差服从正态分布时，最小二乘是最大似然估计——「平方和最小」天然与「正态误差」匹配。这第三条到《概率论与数理统计》会严格展开。</span>

「最优」的定义不止一种，比较三种候选：

| 目标函数 | 形式 | 特点 |
| --- | --- | --- |
| 最小二乘 | $\sum (y_i - \hat y_i)^2$ | 光滑可导、解析可解，放大野点 |
| 最小绝对值 | $\sum \lvert y_i - \hat y_i\rvert$ | 对野点鲁棒，但目标函数在 0 处不可导 |
| 最小最大偏差 | $\max_i \lvert y_i - \hat y_i\rvert$ | 让最大误差最小（切比雪夫逼近），计算复杂 |

**最小二乘胜在「可求导、可解析」**——它把拟合变成「解线性方程组」，这正是它在统计与机器学习中统治地位的数学根源；当数据含野点需要鲁棒性时，才退而求其次用绝对值类损失。

## 2 正规方程的推导

对 $S(a,b)$ 求偏导并令其为零（极值必要条件）：

$$\frac{\partial S}{\partial a} = -2\sum_{i=1}^{n}(y_i - ax_i - b)x_i = 0$$

$$\frac{\partial S}{\partial b} = -2\sum_{i=1}^{n}(y_i - ax_i - b) = 0$$

整理得**正规方程（normal equations）**：

$$\begin{cases}a\sum x_i^2 + b\sum x_i = \sum x_iy_i\\ a\sum x_i + bn = \sum y_i\end{cases}$$

解出

$$a = \frac{n\sum x_iy_i - \sum x_i\sum y_i}{n\sum x_i^2 - (\sum x_i)^2}, \qquad b = \frac{\sum y_i - a\sum x_i}{n} = \bar{y} - a\bar{x}$$

其中 $\bar{x}, \bar{y}$ 是均值。<span class="marginnote">正规方程的解很有结构：$b = \bar y - a\bar x$ 意味着拟合直线<strong>必过数据中心点 $(\bar x, \bar y)$</strong>——「回归直线穿过质心」。这个性质在统计里极重要：直线绕质心转动，斜率 $a$ 决定拟合形态。到《概率论与数理统计》你会看到 $a$ 与相关系数的关系。</span>

**公式解析：推导最小二乘的驻点方程**

$$\frac{\partial S}{\partial a} = -2\sum_{i=1}^{n}(y_i - ax_i - b)x_i = 0$$

- **第一步，展开 $S$**：$S = \sum(y_i^2 - 2ax_iy_i - 2by_i + a^2x_i^2 + 2abx_i + b^2)$。
- **第二步，对 $a$ 求偏导**：$-2\sum x_iy_i + 2a\sum x_i^2 + 2b\sum x_i = 0$，除以 2 移项得正规方程第一式。
- **第三步，对 $b$ 求偏导**：$-2\sum y_i + 2a\sum x_i + 2nb = 0$，得第二式。
- **第四步，验证是最小值**：$S$ 关于 $a,b$ 是凸二次函数（Hessian 正定），驻点即全局最小——这正是「最小二乘必有唯一最小解」的理论保证。

**关键**：最小二乘的求解本质是「二次函数求极小」——梯度为零的驻点就是最小值点，因为二次函数是凸的。多元极值理论在此完美落地。

## 3 示例：直线拟合

数据 $(1,2),\ (2,4),\ (3,5)$，求最小二乘拟合直线：

- **第一步，算求和**：$\sum x_i = 6$，$\sum y_i = 11$，$\sum x_i^2 = 14$，$\sum x_iy_i = 2+8+15 = 25$，$n=3$。
- **第二步，套公式**：$a = \frac{3\times25 - 6\times11}{3\times14 - 36} = \frac{75-66}{42-36} = \frac{9}{6} = 1.5$。
- **第三步，算截距**：$\bar x = 2$，$\bar y = \frac{11}{3}$，$b = \frac{11}{3} - 1.5\times2 = \frac{11}{3} - 3 = \frac{2}{3}$。
- **第四步，写直线**：$y = 1.5x + \frac{2}{3}$。

**关键**：拟合直线「尽可能靠近」三个点，但不穿过任何点（除数据中心）——它是「整体最优折中」。残差平方和 $S = (2-1.5-\frac23)^2 + (4-3-\frac23)^2 + (5-4.5-\frac23)^2$ 达到最小。

把每个点的预测值与残差列成表，能直观看到「整体最优折中」的含义：

| $x_i$ | $y_i$ | 预测 $\hat y_i = 1.5x_i + \frac23$ | 残差 $\varepsilon_i$ |
| --- | --- | --- | --- |
| 1 | 2 | $\frac{13}{6}\approx2.167$ | $-\frac16\approx-0.167$ |
| 2 | 4 | $\frac{11}{3}\approx3.667$ | $\frac13\approx0.333$ |
| 3 | 5 | $\frac{29}{6}\approx4.833$ | $\frac16\approx0.167$ |

三个残差有正有负、绝对值都很小——直线在三个点之间「摆动」求平衡，没有一个点被完美穿过。**残差和 $\sum\varepsilon_i = 0$ 是正规方程第二式的必然推论**（这就是 $b = \bar y - a\bar x$ 的「穿过质心」性质），它也是「拟合是否得当」的第一项快速检查。

## 4 从直线到一般模型

最小二乘思想可以推广到任意「参数线性」模型：

- **多项式拟合**：$y = a_0 + a_1x + \cdots + a_mx^m$——正规方程从二元推广为 $(m+1)$ 元线性方程组。
- **多元线性回归**：$y = \beta_0 + \beta_1x_1 + \cdots + \beta_p x_p$——用矩阵写成 $\mathbf{Y} = X\beta$，最小二乘解 $\hat\beta = (X^TX)^{-1}X^T\mathbf{Y}$。<span class="marginnote">矩阵形式 $\hat\beta = (X^TX)^{-1}X^TY$ 是线性回归的「闭式解」，它的推导正是「令梯度为零解正规方程」的矩阵版本。到《线性代数》你会理解 $X^TX$ 的可逆性与最小二乘解的存在唯一性；到《机器学习》这是线性回归的第一公式。</span>
**非线性模型**：非线性最小二乘（高斯-牛顿法、梯度下降）——迭代逼近。

**辨析｜易错点：** ① 「最小二乘」的名称：最小化的是**残差平方和**，不是误差绝对值之和；② 正规方程要求 $n\sum x_i^2 - (\sum x_i)^2 \neq 0$（数据不能全相同），否则直线不唯一；③ 最小二乘对**野点（outlier）**敏感——平方放大大偏差，这是它的固有弱点（鲁棒回归用绝对值或 Huber 损失缓解）。

## 5 最小二乘法与现代机器学习

最小二乘是「从数据学习」的起点，与后面的学科紧密相连：

**线性回归**：最小二乘是线性回归的经典估计，高斯-马尔可夫定理给出其最优性。<span class="marginnote">高斯-马尔可夫定理：在误差零均值、同方差、不相关的假设下，最小二乘估计是线性无偏估计中方差最小的（BLUE）。这是「平方和最小」为何在统计中如此重要的理论背书——到《概率论与数理统计》你会系统学习。</span>
- **损失函数视角**：最小二乘 = 均方误差（MSE）损失 $\frac{1}{n}\sum(y_i - \hat y_i)^2$ 最小化——机器学习回归任务的默认损失。
- **与最大似然的关系**：误差服从正态分布时，最小化平方和 = 最大化似然——「最小二乘」与「概率模型」在正态假设下合一。
- **推荐系统与矩阵分解**：评分预测的「最小化观测评分的残差平方和」——协同过滤的 SVD、梯度下降法。
- **非线性推广**：当模型不是参数的线性函数（如 $y = ae^{bx}$），先取对数线性化或改用高斯–牛顿法、梯度下降迭代——「最小化残差平方和」的目标不变，只是求解从「解方程组」升级为「迭代优化」。

## 6 小结

- **最小二乘原则**：选择参数使残差平方和 $\sum(y_i - ax_i - b)^2$ 最小。
- **正规方程**：对 $a,b$ 求偏导为零，解线性方程组得 $a = \frac{n\sum x_iy_i - \sum x_i\sum y_i}{n\sum x_i^2 - (\sum x_i)^2}$、$b = \bar y - a\bar x$。
- 拟合直线**必过数据中心点** $(\bar x,\bar y)$。
- 最小二乘是「二次函数极小值」问题——凸性保证全局最优。
- 推广：多项式拟合、多元线性回归 $\hat\beta = (X^TX)^{-1}X^TY$；机器学习中的 MSE 损失。
- 选择「平方」的原因：光滑可导、可解析解、与正态误差下的最大似然一致；代价是对野点敏感。
- 检验拟合：残差和 $\sum\varepsilon_i=0$、拟合直线过质心 $(\bar x,\bar y)$。
