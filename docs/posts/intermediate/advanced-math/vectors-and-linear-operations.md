## 为什么从向量及其线性运算开始

微积分处理「数」的变化，但世界是三维的：力的方向、速度的方向、空间中点的位置，都不能只用一个数描述。**向量**正是「既有大小又有方向」的量的数学化身。从本节开始，我们进入空间解析几何与多元微积分的世界——向量是描述三维空间的语言，也是多元函数微分（梯度、方向导数）与曲线曲面积分的基础工具。更重要的是，向量加法的「平行四边形法则」、数乘、坐标表示，是线性代数的第一课——你在第二级《线性代数》里学的向量空间，正是从这里抽象出来的。<span class="marginnote">向量的力量在于「把几何翻译成代数」：一个箭头可以用坐标 $(x,y,z)$ 表示，向量的加减与数乘就是坐标的对应运算。<strong>几何对象代数化</strong>是解析几何的纲领，也是你从「几何直观」走向「代数计算」的转折点。</span>

## 1 向量的概念与表示

**向量（vector）**：既有大小又有方向的量，用带箭头的线段 $\overrightarrow{AB}$ 表示，$A$ 为起点、$B$ 为终点。向量的**大小（模）**记为 $|\overrightarrow{AB}|$，是线段的长度。<span class="marginnote">向量与「数量（标量）」相对：标量只有大小（如温度、质量），向量还有方向（如速度、力）。日常区分：说「3 米/秒」是速率（标量），说「向东 3 米/秒」是速度（向量）。物理里这种「标量 vs 向量」的自觉至关重要。</span>

**相等向量**：大小相等且方向相同的向量。**自由向量**：与起点无关、只由大小和方向决定的向量——我们通常只关心自由向量，起点可任意平移。**零向量** $\mathbf{0}$：大小为零、方向任意。**单位向量**：模为 1 的向量，常记 $\mathbf{e}_a = \frac{\mathbf{a}}{|\mathbf{a}|}$ 为 $\mathbf{a}$ 方向上的单位向量。

**向量的坐标表示**：在空间直角坐标系中，点 $A(x_1,y_1,z_1)$ 到 $B(x_2,y_2,z_2)$ 的向量为

$$\overrightarrow{AB} = (x_2 - x_1,\ y_2 - y_1,\ z_2 - z_1)$$

模 $|\mathbf{a}| = \sqrt{x^2 + y^2 + z^2}$——三维勾股定理。

## 2 向量的线性运算

**向量加法**：$\mathbf{a} + \mathbf{b}$，用**三角形法则**（首尾相接）或**平行四边形法则**（共起点作对角线）。坐标形式：$(a_1,b_1,c_1) + (a_2,b_2,c_2) = (a_1+a_2, b_1+b_2, c_1+c_2)$。

**向量减法**：$\mathbf{a} - \mathbf{b} = \mathbf{a} + (-\mathbf{b})$，几何上是「从 $\mathbf{b}$ 终点指向 $\mathbf{a}$ 终点」。

**数乘**：$k\mathbf{a}$，当 $k>0$ 时方向相同、模放大 $k$ 倍；$k<0$ 时方向相反；$k=0$ 时为零向量。坐标形式：$k(a,b,c) = (ka,kb,kc)$。

**运算律**：加法交换律、结合律；数乘分配律 $k(\mathbf{a}+\mathbf{b}) = k\mathbf{a} + k\mathbf{b}$、$(k+l)\mathbf{a} = k\mathbf{a} + l\mathbf{a}$。这些运算律与实数的运算律完全平行——**向量的线性运算是对实数运算的「结构化」模仿**。<span class="marginnote">「向量空间」的八条公理（加法交换、结合、零元、负元、数乘分配等）就是把这些运算律抽象成公理。你在这里「用」的每条运算律，到《线性代数》都会成为定义向量空间的公理——<strong>从具体运算到抽象公理，是数学抽象的标准路径</strong>。</span>

## 3 向量的分解与基本单位向量

三个坐标轴方向的单位向量记为

$$\mathbf{i} = (1,0,0), \qquad \mathbf{j} = (0,1,0), \qquad \mathbf{k} = (0,0,1)$$

任何向量 $\mathbf{a} = (a_x, a_y, a_z)$ 都可唯一分解为

$$\mathbf{a} = a_x\mathbf{i} + a_y\mathbf{j} + a_z\mathbf{k}$$

这个分解说明：$\{\mathbf{i}, \mathbf{j}, \mathbf{k}\}$ 是空间向量的**一组基**，任何向量都能「按坐标拆开」。<span class="marginnote">分解到基向量上，是线性代数的核心思想：<strong>用一组「标准零件」表示任意对象</strong>。$\mathbf{i},\mathbf{j},\mathbf{k}$ 是最简单的标准正交基，任何向量都是它们的线性组合。到《线性代数》里基与坐标的概念、以及傅里叶级数的正交函数基，都是这个思想的延伸。</span>

**向量平行的判定**：$\mathbf{a} \parallel \mathbf{b}$ 且 $\mathbf{a}\neq\mathbf{0}$ ⟺ 存在实数 $\lambda$ 使 $\mathbf{b} = \lambda\mathbf{a}$，等价于对应坐标成比例：$\frac{b_x}{a_x} = \frac{b_y}{a_y} = \frac{b_z}{a_z}$。

## 4 公式解析：向量运算的坐标几何

设 $\mathbf{a} = (1, 2, 2)$，$\mathbf{b} = (-1, 0, 2)$：

**第一步，求和差**：$\mathbf{a} + \mathbf{b} = (0, 2, 4)$，$\mathbf{a} - \mathbf{b} = (2, 2, 0)$。
**第二步，求模**：$|\mathbf{a}| = \sqrt{1+4+4} = 3$，$|\mathbf{b}| = \sqrt{1+0+4} = \sqrt5$。
**第三步，求单位向量**：$\mathbf{e}_a = \frac{\mathbf{a}}{3} = \left(\frac13, \frac23, \frac23\right)$。
**第四步，判定平行**：$\mathbf{a}$ 与 $\mathbf{b}$ 是否平行？坐标不成比例（$\frac{-1}{1}\neq\frac02$），不平行。

**关键**：向量的每个运算都有坐标版本——加减速、数乘、模、单位化、平行判定，全部是「按坐标逐分量操作」。掌握了坐标运算，向量就从「几何箭头」变成了「数的三元组」，一切都能算。

## 5 向量与多元微积分

向量是多元微积分的语言基础，后面章节将反复使用：

**空间直线与平面**（第 44–45 节）：用向量表示方向与法向，直线写成「点 + 方向向量 × $t$」。
**多元函数微分**（第九章）：梯度 $\nabla f$ 是偏导数组成的向量，方向导数、切平面都用向量表述。
**曲线积分与曲面积分**（第十一章）：向量场 $\mathbf{F}(x,y,z)$、通量、散度、旋度——全是向量概念。<span class="marginnote">物理中最常见的向量场是力场、电场、速度场：空间中每点都「钉」着一个向量。本章的向量运算是你读懂「场」的第一块砖——到第十一章，通量（向量场穿过曲面的流量）与环流量将直接建立在向量的点积与叉积上。</span>
- **机器学习**：数据点、权重、梯度都是向量；「向量化运算」是深度学习框架（PyTorch、NumPy）性能的基础。你在这里学的基本运算，正是矩阵乘法的原子操作。

## 7 数值算例：用向量判定三点共线

设 $A(1,2,3)$、$B(2,4,5)$、$C(3,6,7)$，判定三点是否共线。

**第一步，作向量**：$\overrightarrow{AB} = (1,2,2)$，$\overrightarrow{AC} = (2,4,4)$。
**第二步，检查成比例**：$\overrightarrow{AC} = 2\cdot\overrightarrow{AB}$——存在实数 $2$ 使二者成比例，故 $\overrightarrow{AB} \parallel \overrightarrow{AC}$。
**第三步，共起点判断**：两向量同起点 $A$ 且平行，故三点 $A,B,C$ **共线**。

**配套技巧**：中点公式——若 $M$ 是 $AB$ 中点，则 $\overrightarrow{OM} = \frac{\overrightarrow{OA} + \overrightarrow{OB}}{2}$（坐标对应取平均）。这类「向量式」几何命题是空间解析几何的常用语言，也是第 44-45 节直线与平面方程的基础。

## 8 对照表：标量与向量

| 标量 | 向量 |
| --- | --- |
| 只有大小（温度、质量、速率） | 大小 + 方向（速度、力、位移） |
| 一个数 | 一个「数的三元组」$+$ 运算规则 |
| 加减是普通算术 | 加减按坐标逐分量 |
| 数乘是普通乘法 | 数乘改变模与方向 |

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 把向量当标量直接运算 | 一切运算按坐标逐分量做 |
| 模与坐标混淆 | 模是长度 $\sqrt{x^2+y^2+z^2}$，坐标是三元组 |
| 数乘负号时方向搞反 | $k<0$ 时方向相反，$k=0$ 时为零向量 |
| 平行判定只比大小 | 平行看坐标成比例（含负比例） |

## 10 向量与机器学习

向量是现代机器学习的原子语言：

- **数据与权重**：一个样本 $x$、一组参数 $w$、一条梯度 $\nabla L$，都是向量——神经网络的每一层输出都是向量。
- **向量化**：PyTorch、NumPy 用「向量运算」一次处理整批数据，性能的关键在于「逐分量运算的并行化」。
- **矩阵乘法**：权重矩阵 × 输入向量 = 神经元输出——你本节学的「加法 + 数乘」正是矩阵乘法的原子操作。

把「向量 = 带运算规则的数组」记牢，后续的梯度、批次、张量就都有了直觉基础。

## 11 小结

- **向量**：有大小有方向，坐标表示 $(x,y,z)$，模 $=\sqrt{x^2+y^2+z^2}$。
- **线性运算**：加法（三角形/平行四边形法则）、减法、数乘——全部按坐标逐分量做。
- 基本单位向量 $\mathbf{i},\mathbf{j},\mathbf{k}$ 构成一组基，任何向量可唯一分解。
- 平行判定：坐标成比例；单位向量 $\mathbf{e}_a = \mathbf{a}/|\mathbf{a}|$。
- 中点向量公式：$\overrightarrow{OM} = \frac{\overrightarrow{OA}+\overrightarrow{OB}}{2}$。
- 向量是空间解析几何与多元微积分的语言，也是线性代数与机器学习的起点。
