## 为什么从分部积分法开始

换元法解决「复合函数」型积分，但还有一大类问题它无能为力：**两个不同类型的函数相乘**——多项式乘指数、多项式乘三角函数、指数乘三角函数。乘积没有现成的积分公式，怎么办？答案是**分部积分法**——把「乘积求导法则」$(uv)' = u'v + uv'$ 反过来用：既然 $(uv)' = u'v + uv'$，那么 $uv' = (uv)' - u'v$，两边积分就得到

$$\int u\,dv = uv - \int v\,du$$

分部积分把「求 $\int u\,dv$」这个难题，转化为「求 $\int v\,du$」——**它把困难从一项转移到另一项**。选择谁当 $u$、谁当 $dv$，是这门艺术的精要所在。<span class="marginnote">分部积分的哲学：不直接攻克难题，而是把它「换一个更难也不一定、但通常更简单的形式」。这与你学过的「取对数把乘法变加法」「换元把根式变三角」是同一类策略——数学里大量技巧的本质都是「把困难重排」。</span>

## 1 分部积分公式的由来

由乘积求导法则 $(uv)' = u'v + uv'$，移项得 $uv' = (uv)' - u'v$。两边对 $x$ 积分：

$$\int uv'\,dx = uv - \int u'v\,dx$$

写成微分形式更常用：令 $dv = v'dx$、$du = u'dx$，则

$$\int u\,dv = uv - \int v\,du$$

**重点：分部积分的成功取决于 $\int v\,du$ 是否比 $\int u\,dv$ 好积。** 若新积分更简单，就成功了；若更复杂，说明 $u$ 与 $dv$ 选反了。

## 2 如何选择 $u$ 与 $dv$

选择的经验法则——**「反对幂三指」**：按以下优先级把优先项设为 $u$：

$$\text{反三角函数} > \text{对数函数} > \text{幂函数} > \text{三角函数} > \text{指数函数}$$

即「反、对、幂、三、指」：排在前面的当 $u$（求导后变简单），排在后面的当 $dv$（积分后不变得更难）。<span class="marginnote">口诀「反对幂三指」的直觉：$u$ 应该选「求导后变简单」的——$\ln x$ 求导变 $\frac{1}{x}$（变简单）、$x^n$ 求导降次（变简单）、反三角求导变分式（变简单）；$dv$ 则选「积分后不至于更糟」的——$e^x$、$\sin x$、$\cos x$ 积分后还是同类，不怕。</span>

典型搭配：

| 被积函数类型 | 令 $u$ | 令 $dv$ |
| --- | --- | --- |
| 多项式 × 指数 | 多项式 | $e^{ax}dx$ |
| 多项式 × 三角函数 | 多项式 | $\sin/\cos$ 的 $dx$ |
| 多项式 × 对数 | $\ln x$ | 多项式 $dx$ |
| 多项式 × 反三角 | 反三角 | 多项式 $dx$ |
| 指数 × 三角函数 | 任选，通常出现「回环」 | 另一项 |

**辨析｜易错点：换元法 vs 分部积分法的分工**——换元法处理「复合结构」（内层函数、根式、三角代换），分部积分法处理「乘积结构」（两类不同函数的乘积）。碰到 $\int x\sin(x^2)\,dx$ 用换元（$t=x^2$ 后 $\sin t$ 直接可积）；碰到 $\int x\sin x\,dx$ 用分部。**先问一句「这是乘积还是复合」，选法就对了**——不少同学把两者混用，根源是没先分类。

## 3 公式解析：多项式乘指数

求 $\int x e^x\,dx$：

**第一步，选 $u$ 与 $dv$**：按「反对幂三指」，幂函数排在指数前面，令 $u = x$、$dv = e^x\,dx$。
**第二步，求微分与积分**：$du = dx$，$v = e^x$。
**第三步，套公式**：$\int x e^x\,dx = x e^x - \int e^x\,dx = x e^x - e^x + C = e^x(x - 1) + C$。

检验：$(e^x(x-1))' = e^x(x-1) + e^x = x e^x$，正确。**分部积分后一定要能验算**——用求导验证积分结果，是成本最低的错误防线。<span class="marginnote">验算习惯在积分里尤其重要：积分的错误常常隐藏很深（差个负号、多个常数），而求导验算只需一两步。工程实践中「正变换验证逆变换」是普遍做法——就像用编解码往返检查来验证数据管线。</span>

再配一个定积分验算：$\int_0^1 x e^x\,dx = \left[e^x(x-1)\right]_0^1 = 0 - (-1) = 1$。而直接用分部积分 $\int_0^1 xe^x\,dx = \left[xe^x\right]_0^1 - \int_0^1 e^x\,dx = e - (e-1) = 1$——两条路线殊途同归，任何一条出错都能被另一条抓住。

若反过来令 $u = e^x$、$dv = x\,dx$，则 $v = \frac{x^2}{2}$，新积分 $\int \frac{x^2}{2}e^x\,dx$ 比原式更复杂——**选反了**。

再看一个「对数」例子：$\int \ln x\,dx$。这里没有显式的乘积，但 $\ln x = 1\cdot\ln x$，令 $u = \ln x$、$dv = dx$——对数排在幂函数之前，所以取 $u$：

$$du = \frac{dx}{x}, \qquad v = x, \qquad \int \ln x\,dx = x\ln x - \int x\cdot\frac{dx}{x} = x\ln x - x + C$$

$\int x\cdot\frac1x dx = \int dx = x$，一步化到只剩多项式——**对数函数当 $u$ 后，$du$ 是分式、积分难度骤降**，这是「反对幂三指」里对数靠前的根本原因。同理 $\int \arctan x\,dx$（反三角当 $u$）也能一步搞定。

## 4 分部积分的两种进阶模式

**降次模式（用于多项式 × 三角/指数）**：$u$ 取多项式时，每用一次分部，多项式的次数降 1，最终降到 0：

$$\int x^2 \cos x\,dx = x^2\sin x + 2x\cos x - 2\sin x + C$$

把过程拆开看，降次机制一目了然：

- **第一次**：$u=x^2$、$dv=\cos x\,dx$ → $x^2\sin x - 2\int x\sin x\,dx$，次数从 2 降到 1；
- **第二次**：$u=x$、$dv=\sin x\,dx$ → $-2\left(-x\cos x + \int\cos x\,dx\right) = 2x\cos x - 2\sin x$，次数从 1 降到 0；
- **收尾**：三次结果相加得 $x^2\sin x + 2x\cos x - 2\sin x + C$。

每轮都把「次数最高的多项式」设为 $u$，用一次分部换走一个次数——**「每分部一次，多项式降一次」，直到降成常数，剩下的积分就是纯三角或纯指数**。

**回环模式（用于指数 × 三角）**：设 $I = \int e^x\sin x\,dx$。分部两次后，$I$ 在右边以「负」的形式再现：

$$I = e^x\sin x - e^x\cos x - I \quad\Longrightarrow\quad I = \frac{e^x}{2}(\sin x - \cos x) + C$$

关键：第二次分部**不要换 $u$ 的选择方向**，让原积分在等式右侧重现，然后解方程。<span class="marginnote">回环模式是分部积分最有戏剧性的技巧：原积分在右边「绕一圈」回来后变了个符号，于是从「求积分」变成「解方程」。这种「自指 → 代数求解」的结构在数学中反复出现——从几何级数求和到不动点迭代，都是让未知量在方程里重现再解出它。</span>

**辨析｜易错点：** 回环模式中两次分部若选择方向不一致（一次令 $u=e^x$，另一次令 $u=\sin x$），就会陷入「回到原点」的循环出不来。务必保持两次都「让指数或三角当 $u$」，方向统一。

## 5 分部积分的应用图景

分部积分是积分学的通用底座，影响远超本节的练习：

**概率与统计**：计算指数分布、伽马分布的期望 $E[X] = \int_0^\infty x f(x)\,dx$ 时，$x$ 与指数项相乘正是标准的分部积分场景。<span class="marginnote">伽马函数 $\Gamma(\alpha) = \int_0^\infty x^{\alpha-1}e^{-x}\,dx$ 的递推式 $\Gamma(\alpha+1) = \alpha\Gamma(\alpha)$ 由分部积分一步导出——它连结了阶乘、贝塔分布与正态分布，是概率论与数理统计的常用道具。</span>

具体算一笔：指数分布密度 $f(x) = \lambda e^{-\lambda x}$（$x\ge0$），其期望

$$E[X] = \int_0^\infty x\lambda e^{-\lambda x}\,dx = \left[-x e^{-\lambda x}\right]_0^\infty + \int_0^\infty e^{-\lambda x}\,dx = 0 + \frac{1}{\lambda}$$

令 $u=x$、$dv=\lambda e^{-\lambda x}dx$，一次分部就把「平均寿命」$\frac1\lambda$ 算了出来——**分部积分是概率论里「期望可算」的通用扳手**，指数、正态、伽马分布的矩都靠它。
- **傅里叶分析**：计算傅里叶系数 $\int f(x)\sin(nx)\,dx$ 时，分部积分将「函数的光滑性」转化为「系数的衰减速度」——$f$ 越光滑，系数衰减越快。
- **物理学**：功、力矩、质心等物理量的积分，往往通过分部积分化简边界项。
- **期望的两种算法**：$E[X]$ 可用 $\int_0^\infty P(X>x)\,dx$ 计算，这个公式也靠分部积分证明——「积分换一种写法常常更易算」。
- **递推公式**：有些积分用分部可得「自身再现」的递推，如 $I_n = \int\sin^n x\,dx$——分部后把 $I_n$ 用 $I_{n-2}$ 表达，一次写出一族积分。

## 6 小结

- **分部积分公式**：$\int u\,dv = uv - \int v\,du$，来自乘积求导法则的逆向。
- **选 $u$ 的优先级**：「反对幂三指」——求导后变简单的当 $u$。
- **降次模式**：多项式当 $u$，连用分部把次数降到 0。
- **回环模式**：指数 × 三角，分部两次让原积分重现，解方程出结果。
- 分部积分后用**求导验算**，是最便宜的错误防线。
- **分工判断**：乘积结构用分部，复合结构用换元——先分类再选法。
- 分部积分也是递推关系与特殊函数（$\Gamma$、正态分布矩）推导的引擎。
