## 为什么从多元函数的极值及其求法开始

一元函数的极值问题（第三章）在多元里成倍复杂：候选点更多（驻点、偏导不存在的点、边界），判别要用二阶偏导组成的 **Hessian 矩阵**，还可能出现一元没有的**鞍点**。更实际的是**条件极值**——在约束下求最值（如固定预算求最大效用、固定材料求最大体积），它由**拉格朗日乘数法**解决。这一节是「从微积分到优化」的关键一跃：极值判定、条件极值、最值应用，构成了现代优化理论（凸优化、约束优化、SVM 对偶）的雏形。<span class="marginnote">多元极值的核心困难在于「维度」：一元驻点只有极大、极小、非极值三种可能；二元驻点多出「鞍点」——沿一个方向是谷、沿另一方向是峰（马鞍面的中心）。判别需要同时看 $f_{xx}$ 与判别式 $AC-B^2$，这比一元复杂得多。</span>

## 1 多元函数极值的定义与必要条件

**极值定义**：$f(x,y)$ 在 $(x_0,y_0)$ 的某邻域内恒有 $f(x,y) \le f(x_0,y_0)$ → 极大值；$\ge$ → 极小值。极大值与极小值统称极值。

**必要条件**：若 $f$ 在 $(x_0,y_0)$ 可导且取得极值，则

$$f_x(x_0,y_0) = 0, \qquad f_y(x_0,y_0) = 0$$

即 $\nabla f = \mathbf{0}$——梯度为零。满足 $\nabla f = \mathbf{0}$ 的点称为**驻点**（或稳定点）。**可导极值点必为驻点，但驻点不一定是极值点**（可能是鞍点）。

**重点：与一元情形的对应**——一元 $f'(x_0)=0$，多元 $\nabla f = \mathbf{0}$；一元驻点判别看 $f''$，多元看 Hessian 矩阵。<span class="marginnote">驻点的含义：曲面在该点切平面水平（法向量竖直）。梯度为零意味着「没有方向能让函数上升或下降」——至少在一阶意义上。但二阶信息（曲率）才能区分「峰、谷、马鞍」——这就要看 Hessian 矩阵的「正定/负定/不定」。</span>

## 2 极值的充分条件（Hessian 判别法）

设 $f$ 在驻点 $(x_0,y_0)$ 附近有二阶连续偏导，记

$$A = f_{xx}(x_0,y_0), \qquad B = f_{xy}(x_0,y_0), \qquad C = f_{yy}(x_0,y_0)$$

判别式 $\Delta = AC - B^2$：

- **$\Delta > 0$ 且 $A > 0$**：极小值（Hessian 正定）；
- **$\Delta > 0$ 且 $A < 0$**：极大值（Hessian 负定）；
- **$\Delta < 0$**：**鞍点**（Hessian 不定，非极值）；
- **$\Delta = 0$**：需另法判别（充分条件失效）。

这个判别法本质是「看二阶全微分 $d^2f = A\,dx^2 + 2B\,dx\,dy + C\,dy^2$ 的正定性」——二次型 $Ax^2+2Bxy+Cy^2$ 恒正/恒负/变号，分别对应极小、极大、鞍点。<span class="marginnote">$\Delta = AC - B^2$ 正是 Hessian 矩阵的行列式，$A$ 是左上角元素。判别法就是线性代数里「对称矩阵正定判别」的直接应用：<strong>Hessian 正定 → 局部极小，负定 → 局部极大，不定 → 鞍点</strong>。到《线性代数》你会系统学习正定性，这里先用二维版本。</span>

**公式解析：为什么 $AC-B^2$ 决定峰谷**

$$d^2f = A\,dx^2 + 2B\,dx\,dy + C\,dy^2$$

- **第一步，识别二次型**：$d^2f$ 是 $dx,dy$ 的二次齐次式，系数由 Hessian 给出。
- **第二步，配方**：$A\left(dx + \frac{B}{A}dy\right)^2 + \left(C - \frac{B^2}{A}\right)dy^2$——第一项符号由 $A$ 定，第二项符号由 $\frac{AC-B^2}{A}$ 定。
- **第三步，判定**：若 $AC-B^2>0$，两项同号——由 $A$ 定全局正负（$A>0$ 恒正=极小，$A<0$ 恒负=极大）；若 $AC-B^2<0$，两项异号——一个方向上升、另一个方向下降，鞍点。

**关键**：判别的几何本质是「二阶近似是碗、倒碗还是马鞍」——全由二次型决定。

## 3 多元函数的最值

**多元函数在有界闭区域上的最值**：与一元类似，最值只能在**驻点、不可导点、边界**三类候选点取得。步骤：

1. 求区域内的驻点（$\nabla f = \mathbf{0}$）与不可导点，算函数值；
2. 求边界上的最值（边界常化为条件极值问题）；
3. 比较所有候选值，取最大最小。

边界处理是最值问题的难点——边界可能是一条曲线（如圆、矩形边），需要转化为一元函数或条件极值。

**辨析｜易错点：** ① 无界开区域上多元函数可能无最值（如 $f(x,y)=x$ 在 $\mathbb{R}^2$ 上无上界）；② 有界闭区域上连续函数**必有最值**（多元最值定理，靠「紧致性」）；③ 区域内驻点不一定是最值点，边界贡献不能漏——比较候选值时边界候选必须算进去。

## 4 条件极值与拉格朗日乘数法

**条件极值**：求 $z = f(x,y)$ 在约束 $\varphi(x,y) = 0$ 下的极值。

**拉格朗日乘数法（Lagrange multipliers）**：构造**拉格朗日函数**

$$L(x, y, \lambda) = f(x, y) + \lambda\,\varphi(x, y)$$

令其对 $x, y, \lambda$ 的偏导全为零：

$$\begin{cases}L_x = f_x + \lambda\varphi_x = 0\\ L_y = f_y + \lambda\varphi_y = 0\\ L_\lambda = \varphi(x,y) = 0\end{cases}$$

解出可能的极值点，再代入判别。<span class="marginnote">拉格朗日乘数法的几何直觉：在约束曲线 $\varphi=0$ 上找 $f$ 的极值，意味着 $f$ 的等值线在极值点与约束曲线<strong>相切</strong>——于是 $\nabla f$ 与 $\nabla\varphi$ 平行，即 $\nabla f = -\lambda\nabla\varphi$。$\lambda$ 正是「两个梯度共线的比例系数」。这条「梯度平行」的几何观点，是 SVM 对偶、凸优化 KKT 条件的直接祖先。</span>

**公式解析：最大体积问题**

求内接于椭球面 $\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1$ 的、各边平行于坐标轴的长方体的最大体积：

**第一步，写目标与约束**：体积 $V = 8xyz$（第一卦限顶点 $(x,y,z)$），约束 $\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1$。
**第二步，建拉格朗日函数**：$L = 8xyz + \lambda\left(\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}-1\right)$。
**第三步，偏导为零**：$L_x: 8yz + \frac{2\lambda x}{a^2}=0$，$L_y: 8xz+\frac{2\lambda y}{b^2}=0$，$L_z: 8xy+\frac{2\lambda z}{c^2}=0$，$L_\lambda$：约束。
**第四步，解对称方程**：由前三式可推出 $\frac{x^2}{a^2}=\frac{y^2}{b^2}=\frac{z^2}{c^2}=\frac13$，故 $x=\frac{a}{\sqrt3}$、$y=\frac{b}{\sqrt3}$、$z=\frac{c}{\sqrt3}$。
**第五步，算体积**：$V_{\max} = 8\cdot\frac{abc}{3\sqrt3} = \frac{8abc}{3\sqrt3}$。

**关键**：拉格朗日乘数法的四步——**建 $L$、偏导为零、解方程组、回代验证**。方程组常具对称结构，可相除消 $\lambda$ 求解。

## 5 条件极值的现代应用

拉格朗日乘数法是现代优化的奠基技术：

**支持向量机（SVM）**：最大化间隔（约束最值）通过对偶问题用拉格朗日乘数法求解——支持向量就是约束「起作用」的点（$\lambda_i>0$）。<span class="marginnote">SVM 对偶问题的推导正是拉格朗日乘数法的推广（KKT 条件）：<strong>约束优化 → 拉格朗日函数 → 对偶问题</strong>。你在第四级《机器学习》学的 SVM、凸优化里的 KKT 条件，几何直觉全来自本节「梯度平行于约束梯度」。</span>
- **经济学**：效用最大化（预算约束下）、成本最小化（产量约束下）——消费者与厂商的最优决策标准范式。
- **最优控制**：带约束的动态优化（变分法 + 拉格朗日乘子）。
- **物理**：最小作用量原理、约束力学（虚功原理）。

## 6 小结

- **极值必要条件**：$\nabla f = \mathbf{0}$（驻点），可导极值点必为驻点。
- **充分条件**：$A=f_{xx}$、$\Delta = AC-B^2$——$\Delta>0$ 且 $A>0$ 极小、$\Delta<0$ 鞍点、$\Delta=0$ 失效。
- **多元最值**：候选 = 驻点 + 不可导点 + **边界**；有界闭区域上必有最值。
- **条件极值**：拉格朗日乘数法 $L=f+\lambda\varphi$，偏导为零解方程组。
- 拉格朗日乘数法是 SVM、经济学最优决策与约束优化的理论基础。
