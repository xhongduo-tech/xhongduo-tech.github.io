## 为什么从重积分的应用开始

二重积分累加平面上的量，三重积分累加空间中的量，但它们服务于哪些实际问题？这一节把这些「积分语言」翻译回物理世界：**面积与体积、平面薄片与空间立体的质心、转动惯量、引力**。这些应用与第六章一元积分应用一脉相承，只是「元素法」从一维升到二维、三维——把「切微元」从线段换成小面积、小体积。重积分的应用让「密度 × 微元 = 总量」这一思想达到顶峰，也是后续曲线积分、曲面积分（第十一章）与物理课程的接口。<span class="marginnote">重积分应用的方法论与第六章完全同源：<strong>「局部密度 × 微元，积分加总」</strong>。一维的密度是线密度 $\rho(x)$、微元 $dx$；二维是面密度 $\rho(x,y)$、微元 $d\sigma$；三维是体密度、微元 $dV$。学会「识别密度与微元的维数」，一切应用题都是同一个模板。</span>

## 1 面积与体积

**平面区域的面积**：

$$S = \iint_D d\sigma$$

**空间立体的体积**：$\Omega$ 若由曲面 $z = z_1(x,y)$ 与 $z = z_2(x,y)$ 夹成（$z_2 \ge z_1$），则

$$V = \iint_D [z_2(x,y) - z_1(x,y)]\,dx\,dy$$

或直接 $V = \iiint_\Omega dV$。

例：求平面 $z = x + y$ 在区域 $D$（$0\le x\le1$，$0\le y\le1$）上方的体积：$V = \int_0^1\int_0^1 (x+y)\,dx\,dy = \int_0^1\left[\frac{x^2}{2} + xy\right]_0^1 dy = \int_0^1\left(\frac12 + y\right)dy = 1$。<span class="marginnote">「用二重积分算体积」与「用二重积分算曲顶柱体体积」其实是同一件事：被积函数 $z_2 - z_1$ 是「上曲面减下曲面的高度」。当 $z_1=0$ 时退化为曲顶柱体体积。面积公式 $\iint_D d\sigma$ 是体积公式的「$f\equiv1$ 特例」——一整套公式由「高度 × 底面积」统一。</span>

再算一个需要选坐标系的例子：求抛物面 $z = x^2 + y^2$ 与平面 $z = 4$ 所围立体的体积。上曲面 $z_2 = 4$、下曲面 $z_1 = x^2+y^2$，交线在平面 $z=4$ 上满足 $x^2+y^2=4$，即底区域 $D$ 是圆盘 $x^2+y^2\le4$。被积函数与区域都含 $x^2+y^2$，改用极坐标：

$$V = \iint_D [4 - (x^2+y^2)]\,dx\,dy = \int_0^{2\pi}\int_0^2 (4 - r^2)\,r\,dr\,d\theta = 2\pi\left[2r^2 - \frac{r^4}{4}\right]_0^2 = 2\pi(8 - 4) = 8\pi$$

若坚持用直角坐标，内层会出现 $\sqrt{4-x^2}$ 一类的反三角函数积分——**「区域圆形、被积函数含 $x^2+y^2$」时果断换极坐标，是重积分计算的第一省力法则**（下一节会系统讲）。

## 2 质心（形心）

**平面薄片**：面密度 $\rho(x,y)$、区域 $D$，质量 $M = \iint_D \rho\,d\sigma$，质心

$$\bar{x} = \frac{1}{M}\iint_D x\rho(x,y)\,d\sigma, \qquad \bar{y} = \frac{1}{M}\iint_D y\rho(x,y)\,d\sigma$$

若 $\rho$ 恒为常数，质心即**形心（几何中心）**：

$$\bar{x} = \frac{\iint_D x\,d\sigma}{\iint_D d\sigma}, \qquad \bar{y} = \frac{\iint_D y\,d\sigma}{\iint_D d\sigma}$$

**空间立体**类似：$\bar{x} = \frac{1}{M}\iiint_\Omega x\rho\,dV$ 等。

**公式解析：质心公式为什么是「加权平均」**

$$\bar{x} = \frac{1}{M}\iint_D x\rho(x,y)\,d\sigma$$

- **第一步，看分母**：$M = \iint_D \rho\,d\sigma$ 是总质量——「权重之和」。
- **第二步，看分子**：$\iint_D x\rho\,d\sigma$ 是「每个位置 $x$ × 该处质量 $\rho d\sigma$」的总和——「位置 × 权重」的累积。
- **第三步，相除**：$\bar x$ = 位置按质量的加权平均——「重心 = 位置的平均，质量越大的地方越有发言权」。

**关键**：质心公式与期望公式 $E[X] = \int x\,p(x)dx$ 结构完全一致——**质心就是「质量分布的平均位置」，期望就是「概率分布的平均位置」**。同一个「加权平均」模板，物理与概率共用。

算一个形心练习：求半圆盘 $D = \{x^2+y^2\le R^2,\ y\ge0\}$（均匀薄片）的形心。由对称性 $\bar x = 0$（区域与密度都关于 $y$ 轴对称）；面积 $S = \frac{\pi R^2}{2}$，而

$$\iint_D y\,d\sigma = \int_{-R}^{R}\int_0^{\sqrt{R^2-x^2}} y\,dy\,dx = \frac12\int_{-R}^{R}(R^2 - x^2)\,dx = \frac{2R^3}{3}$$

于是 $\bar y = \frac{\frac{2R^3}{3}}{\frac{\pi R^2}{2}} = \frac{4R}{3\pi}\approx0.424R$——形心在几何中心（圆心）下方、但仍高于底边 $y=0$。**「对称性先消一维」是质心计算的第一招**：能消 $\bar x$ 就只算 $\bar y$，工作量减半。

## 3 转动惯量

**转动惯量**：质点对轴转动惯量 $I = mr^2$（$r$ 是到轴距离）。连续分布时：

$$I_x = \iint_D y^2\rho\,d\sigma, \qquad I_y = \iint_D x^2\rho\,d\sigma, \qquad I_O = \iint_D (x^2 + y^2)\rho\,d\sigma$$

（平面薄片分别对 $x$ 轴、$y$ 轴、原点的转动惯量）。空间立体对 $z$ 轴：

$$I_z = \iiint_\Omega (x^2 + y^2)\rho\,dV$$

**转动惯量的物理意义**：转动惯量越大，越难改变旋转状态（就像质量越大越难改变平动）——它是旋转运动的「惯性」度量。<span class="marginnote">转动惯量的结构：「质量 × 到轴距离平方」。$I_z$ 中的 $x^2+y^2$ 正是点 $(x,y,z)$ 到 $z$ 轴距离的平方。转动惯量决定飞轮储能、陀螺仪稳定、发动机曲轴的动力学行为——工程中无处不在，到《理论力学》与《机械原理》你会反复计算它。</span>

**平行轴定理**：$I = I_C + Md^2$——对过质心轴的转动惯量加上 $Md^2$（$d$ 是两平行轴间距），工程计算常用。

几种常见均匀薄片对过形心轴的转动惯量可作验算基准（$M$ 为总质量、$R$ 为半径）：

| 形状 | 转轴 | 转动惯量 |
| --- | --- | --- |
| 圆盘 | 过圆心垂直盘面 | $\frac{1}{2}MR^2$ |
| 圆环 | 过圆心垂直盘面 | $MR^2$ |
| 矩形薄片（$a\times b$） | 过形心平行 $b$ 边 | $\frac{1}{12}Ma^2$ |
| 细杆（长 $L$） | 过中点垂直杆 | $\frac{1}{12}ML^2$ |

这些值既可由本节积分公式推出，也可在《理论力学》里作为常用结论直接使用——**「会积分推导」与「记得住常用结果」两者结合，做题最快**。

## 4 引力

**薄片对质点的引力**：面密度 $\rho$ 的薄片 $D$ 对质量为 $m$ 的质点 $P_0(x_0,y_0,z_0)$ 的引力，由万有引力定律逐微元计算：

$$d\mathbf{F} = G\frac{m\,\rho\,d\sigma}{r^2}\,\mathbf{e}_r$$

分解为三个分量后分别积分（三重积分与二重积分的组合）。<span class="marginnote">引力计算的难点是「矢量积分」：每个微元产生的引力是矢量，需分解到三个坐标方向分别积分。对高度对称的区域（均匀球壳、均匀圆盘），对称性可以消去大部分分量——「先看对称性，再动手积分」是引力问题的第一原则。到《大学物理》你会用同样方法算球壳内外的引力场。</span>

**重点：重积分应用的「对称性红利」**——若密度与区域关于某轴对称，质心落在对称轴上、部分转动惯量可直接判断、引力分量为零——**先找对称性，能省去大量积分**。

## 5 重积分应用的通用流程

任何重积分应用问题按四步走：

1. **识别总量与密度**：求什么？质量/质心/惯量/引力/体积？密度是什么（线/面/体密度）？
2. **选坐标系与微元**：直角/极/柱/球？$d\sigma$/$dV$ 用什么形式？
3. **写积分**：按「密度 × 微元」模板写被积函数，定区域范围。
4. **计算并化简**：利用对称性、分离变量、合适次序/坐标系。

**辨析｜易错点：** ① 质心公式的分子分母都要积分，**分子漏掉坐标因子 $x$（或 $y$）是最常见的错误**——写成 $\iint_D \rho\,d\sigma$ 得到的是总质量而不是「质量 × 位置」；② 「形心」仅在 $\rho$ 恒为常数时才等于质心，密度不均时二者分离；③ 转动惯量必须写清转轴——对 $x$ 轴用 $y^2\rho$、对 $y$ 轴用 $x^2\rho$、对原点用 $x^2+y^2$，**轴选错则被积函数全错**。

<span class="marginnote">这张「四步走」与一元积分的「元素法四步」一脉相承，只是密度与微元升维。<strong>重积分的应用是「从公式到物理」的翻译练习</strong>——学会把「质量」「质心」「惯量」这些物理量翻译成积分，你就能在物理、力学、概率里自由使用重积分。到《概率论与数理统计》，同样的积分语言算期望与协方差。</span>

## 6 小结

- **面积/体积**：$S = \iint_D d\sigma$，$V = \iint_D(z_2-z_1)dx\,dy$ 或 $\iiint_\Omega dV$。
- **质心**：$\bar x = \frac{1}{M}\iint x\rho\,d\sigma$——位置的「质量加权平均」，与期望同构。
- **转动惯量**：$I = \int r^2\,dm$——「质量 × 到轴距离平方」，平行轴定理 $I=I_C+Md^2$。
- **引力**：逐微元用万有引力定律，矢量分解后积分；对称性可消分量。
- 通用四步：**识别密度 → 选坐标系 → 写积分 → 对称性化简**。
