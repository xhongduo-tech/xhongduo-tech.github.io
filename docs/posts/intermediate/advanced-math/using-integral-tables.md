## 为什么从积分表的使用开始

前三节我们学了换元、分部、部分分式——这些技巧的目标只有一个：**把未知积分化归到已知积分**。而「已知积分」的集合，就写在**积分表**里。积分表是历代数学家把「积得出来的积分」系统整理成的一张张查找表，包含数百条公式与递推式。学会用表，等于站在几百年的积累上解题：不必每次从定义出发，而是**识别模式、查表、代入**。<span class="marginnote">积分表的实用地位在计算机时代依然存在：你写的每一行 Python，`scipy.integrate` 背后既做解析查表也做数值逼近；而 SymPy 的 `integrate()` 底层实现的正是一套「模式匹配 + 查表 + 递推」的积分引擎——本节的流程与它几乎一模一样。</span>

## 1 积分表的结构

标准积分表（如教材附录的《积分表》）按被积函数类型分章，常用板块：

- 含 $a+bx$ 的积分；
- 含 $a^2 \pm x^2$、$x^2 - a^2$ 的积分；
- 含 $\sqrt{a^2 \pm x^2}$、$\sqrt{x^2 \pm a^2}$ 的积分；
- 含 $\sin$、$\cos$、$\tan$、$\cot$、$\sec$、$\csc$ 的积分；
- 含 $e^{ax}$、$\ln x$、反三角函数的积分；
- 含乘积与复合的积分。

每块之下是按「从简到繁」排列的具体公式。**查表的关键是识别「形如哪条公式」**——被积函数的代数结构决定它归入哪一类。<span class="marginnote">积分表的组织方式本身就是一个「分类学」：按函数族分类、按复杂度排序。这种「先分类、后查用」的结构在工程手册、API 文档、知识库组织里普遍存在——学会查积分表，也学会了如何高效使用任何工具书。</span>

## 2 查表前的预处理

积分表公式通常只覆盖「标准形」，实际积分要先**变形到标准形**再查表。三步预处理：

1. **代数化简**：拆项、有理化、配方。含二次式 $ax^2+bx+c$ 时先**配方**成 $a(x-h)^2+k$ 的形式，再代换 $u = x-h$ 归入标准形。
2. **换元归一**：把系数化为 1，如 $\sqrt{a^2-x^2}$ 提 $a$ 得 $a\sqrt{1-(x/a)^2}$。
3. **套公式**：查到对应公式，回代变量。

例：$\int \frac{dx}{x^2 + 2x + 5}$。配方 $x^2+2x+5 = (x+1)^2 + 4$，令 $u = x+1$，得 $\int\frac{du}{u^2+4} = \frac{1}{2}\arctan\frac{u}{2} + C = \frac{1}{2}\arctan\frac{x+1}{2} + C$——查「$\int\frac{dx}{x^2+a^2}$」这条公式。

**辨析｜易错点：** 配方时「配平方」的常数要算对——$x^2+2x+5 = (x+1)^2+4$，漏掉 $4$ 或用错常数，公式就套错。**查表前先验算变形，查表后回代变量**，两步缺一不可。

## 3 递推公式：让积分表自我延伸

积分表里最「高级」的工具是**递推公式（reduction formula）**——把「含参数 $n$ 的积分」用「$n-1$（或更小）的积分」表示，反复使用即可把高次降到低次：

$$\int \sin^n x\,dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int \sin^{n-2}x\,dx$$

$$\int x^n e^x\,dx = x^n e^x - n\int x^{n-1}e^x\,dx$$

递推公式把一张有限的表变成「无限长的表」——任意 $n$ 的积分都能归约到 $n=0$ 或 $n=1$ 的原子情形。<span class="marginnote">递推 = 「用自身的小号版本表达自己」，这是数学里最普遍的结构之一——从阶乘 $n! = n\cdot(n-1)!$ 到斐波那契数列，再到动态规划与递归算法，都是同一个「归约到更小规模」的模式。你在这里学的递推公式，是计算机科学里递归思想的最早启蒙。</span>

**公式解析：推导 $\int \sin^n x\,dx$ 的递推**

$$\int \sin^n x\,dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n-1}{n}\int \sin^{n-2}x\,dx$$

- **第一步，拆一个 $\sin x$**：$\sin^n x = \sin^{n-1}x\cdot\sin x$，用分部积分，令 $u=\sin^{n-1}x$、$dv=\sin x\,dx$。
- **第二步，展开**：$v=-\cos x$，$du=(n-1)\sin^{n-2}x\cos x\,dx$，得
  $$\int\sin^n x\,dx = -\sin^{n-1}x\cos x + (n-1)\int\sin^{n-2}x\cos^2 x\,dx$$
- **第三步，代 $\cos^2 x = 1-\sin^2 x$**：右端第二项拆成 $(n-1)\int\sin^{n-2}x\,dx - (n-1)\int\sin^n x\,dx$。
- **第四步，解方程**：把 $-(n-1)\int\sin^n x\,dx$ 移到左边，$(1+n-1)=n$ 倍的原积分 $= -\sin^{n-1}x\cos x + (n-1)\int\sin^{n-2}x\,dx$，除以 $n$ 即得递推式。

**关键**：第四步的「解方程」与分部积分的回环模式是同一招——积分在右边重现，移项解出即可。

## 4 查表与直接积分的分工

积分表不是「偷懒工具」，而是「标准答案库」。两者的分工原则：

| 情况 | 策略 |
| --- | --- |
| 基本积分表能直接套 | 直接积分 |
| 换元/分部两三条内能做 | 用技巧做 |
| 结构匹配标准形 | 查表 |
| 高次、带参数 | 用递推公式 |

<span class="marginnote">工程实践的真实写照：现代工程师 90% 的积分由软件完成，但「把积分化成软件能处理的形式」（配方、换元、识别结构）仍依赖人脑——这正是本节训练的能力。工具越强大，识别模式的人越值钱。</span>

现代计算机代数系统（CAS）做积分的方式：先做**模式匹配**（识别被积函数属于哪一类），再尝试换元与分部，必要时查内置表并用递推。这与你手算的流程完全同构——**你练的每道题，都是未来理解自动积分引擎的语法课**。

## 5 小结

- 积分表按**函数族分类**：多项式、根式、三角、指数、复合各有章节。
- 查表三步：**化简变形 → 换元归一 → 查表回代**。
- 二次式先**配方**再代换，是查表前最常见的预处理。
- **递推公式**把「含参数 $n$ 的积分」归约到 $n$ 更小的情形，让表无限延伸。
- 递推推导靠「分部积分 + 解方程」，与回环模式同源。

第四章至此收束：从不定积分的概念，到换元、分部、部分分式、查表，我们掌握了「求原函数」的完整工具箱。在下一章，我们将把积分从「求原函数」推进到「求面积」——**定积分**。
