## 为什么从格林公式及其应用开始

微积分基本定理说「区间端点的值 = 内部导数的积分」。二维世界里有没有对应的定理？**格林公式**给出了答案：平面区域边界上的曲线积分，等于区域内「偏导之差」的二重积分。它是二维的微积分基本定理，也是本章三大公式（格林、高斯、斯托克斯）的第一座里程碑。格林公式把「沿边界的环流量」与「区域内的旋度」相连，从而统一了「线积分」与「面积分」两个世界——它直接导出平面曲线积分与路径无关的判定（保守场），是物理中场论与机器学习中「势函数」概念的数学基础。<span class="marginnote">格林公式的精髓：<strong>「只看边界，就能知道内部」</strong>——边界上的环流量由区域内部某点的「局部旋转密度」决定。这与微积分基本定理「端点值由内部导数决定」是同一思想在二维的升华。格林（George Green）1828 年以自学的磨坊主身份发表，是数学史上最传奇的「素人数学家」之一。</span>

## 1 格林公式

设闭区域 $D$ 由分段光滑曲线 $L$ 围成，函数 $P(x,y)$、$Q(x,y)$ 在 $D$ 上具有一阶连续偏导数，则

$$\oint_L P\,dx + Q\,dy = \iint_D\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dx\,dy$$

其中 $L$ 取 **$D$ 的正向边界**：沿 $L$ 走，$D$ 始终在左边（即逆时针方向）。<span class="marginnote">「正向边界」约定：沿边界逆时针走，区域在左手边。若边界取反向，左边加负号。这个「方向约定」与第二型积分的方向敏感性配套——<strong>格林公式的左右两侧都依赖方向，方向一致才相等</strong>。环流量的「逆时针为正」约定是全场论的惯例。</span>

**记忆**：被积函数的「旋度」$\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}$——「$Q$ 对 $x$ 偏导减 $P$ 对 $y$ 偏导」。这个差正是二维旋度（curl）的 $z$ 分量。

用具体数值把「边界积分 = 内部积分」验算一遍。设 $D$ 是单位正方形 $0\le x\le1$、$0\le y\le1$，$P = x+y$、$Q = y$。右边二重积分：

$$Q_x - P_y = 0 - 1 = -1 \;\Longrightarrow\; \iint_D(-1)\,dx\,dy = -1$$

左边沿边界逆时针走一圈：下边（$y=0$，$0\le x\le1$）贡献 $\int_0^1 x\,dx=\frac12$；右边（$x=1$，$0\le y\le1$）贡献 $\int_0^1 y\,dy=\frac12$；上边（$y=1$，$x$ 从 1 到 0）贡献 $\int_1^0 (x+1)\,dx=-\frac32$；左边（$x=0$，$y$ 从 1 到 0）贡献 $\int_1^0 y\,dy=-\frac12$。四段合计

$$\frac12+\frac12-\frac32-\frac12 = 1-2 = -1$$

与右边 $-1$ 完全一致。**「沿边界的四段直线积分」与「内部一个常数二重积分」相互印证，格林公式的等号就活了起来**——边界上的环流量，等价于内部旋度的总累积。

## 2 格林公式的两种用法

**用法一：曲线积分 → 二重积分**。当曲线积分难算而区域易积时，用格林公式把环流量换成二重积分。

**用法二：二重积分 → 曲线积分（面积公式）**。取 $P = -y$、$Q = x$，则 $\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y} = 1-(-1) = 2$，于是

$$\iint_D dx\,dy = \frac{1}{2}\oint_L x\,dy - y\,dx$$

——**平面区域面积 = 边界曲线积分的一半**。这是格林公式最漂亮的推论：用「沿边界的积分」算面积。

**公式解析：用边界积分算面积**

$$S_D = \frac{1}{2}\oint_L x\,dy - y\,dx$$

- **第一步，验证旋度**：$P=-y$、$Q=x$ 时 $\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y} = 1+1 = 2$，故 $\oint_L x\,dy-y\,dx = 2\iint_D dx\,dy$。
- **第二步，解出面积**：$S_D = \iint_D dx\,dy = \frac12\oint_L x\,dy - y\,dx$。
- **第三步，验证特例**：单位圆 $x=\cos t$、$y=\sin t$：$\frac12\oint(x\,dy-y\,dx) = \frac12\int_0^{2\pi}(\cos^2 t + \sin^2 t)dt = \pi$——圆面积，正确。

**关键**：这条面积公式在 CAD、测绘中极实用——只要沿边界测坐标就能算面积，不必做二重积分。

更妙的是它还能「曲线积分算复杂区域面积」：椭圆 $x=a\cos t$、$y=b\sin t$，则 $S = \frac12\int_0^{2\pi}(a\cos t)(b\cos t\,dt) - (b\sin t)(-a\sin t\,dt) = \frac12\int_0^{2\pi}ab\,dt = \pi ab$——椭圆面积公式一步导出，不需要任何「定积分的几何应用」技巧。

## 3 平面曲线积分与路径无关

**平面曲线积分与路径无关**：若 $\oint_L P\,dx+Q\,dy = 0$ 对区域内任意闭路 $L$ 成立，则积分与路径无关——从 $A$ 到 $B$ 沿任何路径积分值相同，记作 $\int_A^B$。

**格林公式给出的判定**：若在单连通区域 $D$ 内 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$（即旋度为零），则

- 曲线积分与路径无关；
- $\oint_L P\,dx+Q\,dy = 0$ 对所有闭路成立；
- 存在势函数 $u(x,y)$ 使 $du = P\,dx + Q\,dy$（即 $u_x = P$、$u_y = Q$）。

<span class="marginnote">「旋度为零 ⟺ 路径无关 ⟺ 存在势函数」是平面场的「三等价」定理。物理直觉：重力场、静电场是保守场（旋度为零），绕一圈做功为零，所以有势能函数。而漩涡水流旋度非零，绕圈做功不抵消——没有势函数。这个「无旋 ⇔ 有势」的联系是物理场论的核心，下一节「全微分方程」直接建在这上面。</span>

**辨析｜易错点：** 「路径无关」要求区域**单连通**（无洞）。若 $D$ 内有洞（如挖掉原点），即使旋度为零，绕洞的闭路积分也可能非零——必须对每个洞单独算环流量。经典的例子 $\oint \frac{-y\,dx + x\,dy}{x^2+y^2}$ 绕原点一周 $=2\pi\neq0$，尽管除原点外旋度处处为零。

验算这个「挖洞」例子：在单位圆 $x=\cos t$、$y=\sin t$ 上，$\frac{-y\,dx+x\,dy}{x^2+y^2} = \frac{-\sin t(-\sin t\,dt) + \cos t(\cos t\,dt)}{1} = (\sin^2 t + \cos^2 t)dt = dt$，绕一圈积分 $=\int_0^{2\pi}dt = 2\pi$。而场在原点外旋度确为零——**矛盾来自原点使区域非单连通**。处理这类问题：把洞用一个小圆 $C_\varepsilon$ 挖掉，在原区域与挖洞区域的边界上分别用格林公式，两者之差恰是绕洞一周的环流量贡献。

## 4 全微分方程

**全微分方程**：若 $P\,dx + Q\,dy$ 是某个函数 $u$ 的全微分（$u_x=P$、$u_y=Q$），则方程

$$P(x,y)\,dx + Q(x,y)\,dy = 0$$

的通解是 $u(x,y) = C$。

**判定与求解**：若 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$，方程是全微分方程；求解 $u$ 的方法：$u = \int P\,dx + \varphi(y)$，再用 $u_y = Q$ 定 $\varphi(y)$。<span class="marginnote">全微分方程与「路径无关」是同一件事的方程视角：$Pdx+Qdy$ 有势函数 ⟺ 积分与路径无关 ⟺ 旋度为零。解全微分方程就是「找到势函数 $u$」——这与求保守场的势能函数、机器学习里「找损失函数的原函数」同构。若方程非全微分，可乘<strong>积分因子</strong>使其变全微分——与一阶线性方程的积分因子法同源。</span>

**公式解析：求解全微分方程**

求 $(2x + e^y)\,dx + (xe^y)\,dy = 0$ 的通解：

- **第一步，检验全微分**：$P_y = e^y$、$Q_x = e^y$，相等——全微分方程。
- **第二步，对 $x$ 积分求 $u$**：$u = \int(2x+e^y)dx = x^2 + xe^y + \varphi(y)$。
- **第三步，用 $u_y = Q$ 定 $\varphi$**：$u_y = xe^y + \varphi'(y) = xe^y$，得 $\varphi'(y) = 0$，$\varphi(y) = C_1$。
- **第四步，写通解**：$x^2 + xe^y = C$。

**关键**：全微分方程的四步流程——**检验 $\frac{\partial P}{\partial y}=\frac{\partial Q}{\partial x}$ → 对 $x$ 积分 → 对 $y$ 求导定 $\varphi$ → 写 $u=C$**。

## 5 格林公式的统一视角

格林公式是「微积分基本定理」的二维版，它统一了整个积分学：

$$\underbrace{\oint_{\partial D} P\,dx + Q\,dy}_{\text{边界上的积分}} = \underbrace{\iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dx\,dy}_{\text{内部导数的积分}}$$

- 一维版本：$F(b)-F(a) = \int_a^b f'(x)dx$——「端点值 = 内部导数积分」；
- 二维版本：格林公式——「边界环流量 = 内部旋度积分」；
- 三维版本：高斯公式（散度）、斯托克斯公式（旋度）——下一节和第 68、69 节。

<span class="marginnote">格林、高斯、斯托克斯三大公式是「广义斯托克斯定理」的特例：<strong>$\int_{\partial\Omega}\omega = \int_\Omega d\omega$——「边界的积分 = 内部微分形式的积分」</strong>。这一统一形式在微分几何与《数学物理方程》里是理解「场论」的总纲。你现在学的格林公式，是整个「微积分基本定理家族」在二维的代表。</span>

## 6 小结

- **格林公式**：$\oint_L P\,dx+Q\,dy = \iint_D(Q_x - P_y)\,dx\,dy$，$L$ 取正向（逆时针）。
- 两种用法：**曲线积分→二重积分**（算环流量）与**二重积分→边界积分**（面积公式 $S=\frac12\oint x\,dy-y\,dx$）。
- **路径无关**：单连通区域内 $Q_x = P_y$ ⟺ 积分与路径无关 ⟺ 存在势函数。
- **全微分方程**：$P_y=Q_x$ 时 $Pdx+Qdy=du$，通解 $u=C$。
- 格林公式是微积分基本定理的二维版，通向高斯与斯托克斯公式。
- 数值验算习惯：任取简单区域（正方形、圆）代入两边各算一遍，可快速检验公式方向与符号。
