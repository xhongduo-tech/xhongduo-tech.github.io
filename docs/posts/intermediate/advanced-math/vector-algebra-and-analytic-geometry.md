## 为什么需要「三维的舞台」

前七章都在一维数轴上活动：函数、导数、积分都只涉及一个自变量。但真实世界是三维的——力的分解、卫星轨道、晶体结构、图像像素都是向量。「从极限到大模型」里更不例外：参数空间是几十亿维的向量空间，词嵌入是向量，注意力打分是向量内积。第八章为这一切准备好了最基础的词汇：**向量运算**与**空间的解析表示**。

**向量**：既有大小又有方向的量，记作 $\vec{a}$。代数上它对应坐标 $(a_1, a_2, a_3)$，其模长为 $|\vec{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}$。向量的**线性运算**包括加法（平行四边形法则）与数乘，满足交换律、结合律、分配律。

本章的任务是把「三维几何」翻译成「坐标方程」：平面、直线、曲面、曲线都用方程刻画，几何问题转化为代数问题。这正是「解析几何」——用代数语言精确描述空间图形，为第九章的多元微积分搭好舞台。<span class="marginnote">空间直角坐标系是这套语言的基础：三个互相垂直的单位向量 $\vec{i},\vec{j},\vec{k}$ 张成整个空间，任何向量都唯一分解为它们的线性组合——这正是「基」的思想，也是线性代数与大模型向量空间共享的骨架。</span>

## 1 数量积、向量积与混合积：三种乘法

向量之间有三种乘积，用途截然不同：

**数量积（点积）**：$\vec{a}\cdot\vec{b} = |\vec{a}||\vec{b}|\cos\theta$，坐标式 $a_1b_1 + a_2b_2 + a_3b_3$。它是标量，度量「一个向量在另一个方向上的投影」，是**功**与**夹角判定**的数学形式。$\vec{a}\perp\vec{b} \iff \vec{a}\cdot\vec{b} = 0$。

**向量积（叉积）**：$\vec{a}\times\vec{b}$ 是向量，大小 $|\vec{a}||\vec{b}|\sin\theta$，方向满足右手法则、垂直于 $\vec a$ 与 $\vec b$。坐标式

$$\vec{a}\times\vec{b} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ a_1 & a_2 & a_3 \\ b_1 & b_2 & b_3 \end{vmatrix}$$

叉积的大小等于 $\vec a$、$\vec b$ 张成平行四边形的面积，因此**求平面法向量、求面积、判断平行**都靠它。$\vec{a}\parallel\vec{b} \iff \vec{a}\times\vec{b} = \vec{0}$。

**混合积**：$[\vec a\,\vec b\,\vec c] = (\vec a\times\vec b)\cdot\vec c$，是标量，绝对值等于三个向量张成的平行六面体的体积。$\vec a,\vec b,\vec c$ 共面 $\iff$ 混合积为 $0$。<span class="marginnote">三种乘积对 LLM 的意义：点积是 attention 的核心运算（$q\cdot k$ 度量查询与键的相似度）；叉积与混合积是三维几何与物理的常客；而「内积 + 正交」的语言贯穿高维空间的一切相似度度量。</span>

### 例：求过三点 $P(1,0,0)$、$Q(0,1,0)$、$R(0,0,1)$ 的平面方程

**第一步，构造两个向量。** $\vec{PQ} = (-1,1,0)$、$\vec{PR} = (-1,0,1)$。

**第二步，叉积求法向量。** $\vec n = \vec{PQ}\times\vec{PR} = \begin{vmatrix}\vec i & \vec j & \vec k \\ -1 & 1 & 0 \\ -1 & 0 & 1\end{vmatrix} = (1,1,1)$。

**第三步，写点法式。** 取点 $P$：$1\cdot(x-1) + 1\cdot(y-0) + 1\cdot(z-0) = 0$，即 $x + y + z = 1$。

这个例子的关键是「由三点造法向量」：先做差得共面向量，再叉积得垂直于它们的法向量。验证 $x+y+z=1$ 确实过三个截距点，答案无误。

### 例：已知 $\vec a = (1,2,2)$，求 $\vec a$ 的单位向量与 $\vec a\cdot\vec a$

**第一步，算模长。** $|\vec a| = \sqrt{1^2 + 2^2 + 2^2} = 3$。

**第二步，求单位向量。** $\frac{\vec a}{|\vec a|} = \left(\frac13, \frac23, \frac23\right)$，模长为 $1$，方向与 $\vec a$ 相同。

**第三步，点积自乘。** $\vec a\cdot\vec a = 1^2+2^2+2^2 = 9 = |\vec a|^2$。这是点积最重要的恒等式：**任何向量与自身的点积等于其模长平方**——它在范数、距离、正则化的所有场合反复出现。

## 2 平面与直线：用方程描述图形

**平面**由一点与一个法向量确定：过 $P_0(x_0,y_0,z_0)$、法向量 $\vec n = (A,B,C)$ 的平面方程

$$A(x-x_0) + B(y-y_0) + C(z-z_0) = 0, \qquad \text{即} \qquad Ax + By + Cz + D = 0$$

平面间的关系由法向量决定：平行 $\iff$ 法向量成比例；垂直 $\iff$ 法向量点积为零；两平面夹角等于法向量夹角。点到平面的距离公式是 $d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2+B^2+C^2}}$。

**直线**由一点与方向向量确定，有三种表示：

- **点向式（对称式）**：$\frac{x-x_0}{m} = \frac{y-y_0}{n} = \frac{z-z_0}{p}$（方向向量 $(m,n,p)$）；
- **参数式**：$\begin{cases} x = x_0 + mt \\ y = y_0 + nt \\ z = z_0 + pt \end{cases}$；
- **一般式**：两平面方程联立。

直线间关系、直线与平面的关系都可归结为方向向量与法向量的夹角/平行/垂直判断。**辨析｜易错点：** 直线与平面夹角的公式中用的是 $\sin\theta$（因为夹角取直线与平面内投影的夹角），而平面与平面、直线与直线用 $\cos\theta$——混淆者极多，务必区分。

判断空间直线与平面的位置关系是一套标准流程：设直线方向向量 $\vec s$、平面法向量 $\vec n$。

- **平行**：$\vec s \cdot \vec n = 0$（直线方向与法向量垂直）；此时若直线上一点在平面内则直线在平面内，否则平行无交点。
- **垂直**：$\vec s \parallel \vec n$（直线方向与法向量平行）。
- **相交**：其余情形，交点是「直线参数式代入平面方程解出 $t$」。

这套「方向向量 ↔ 法向量」的判定与平面上两直线的关系判定结构完全一致，只是维度升了一级。做题时把向量关系先想清楚，再套公式，就不会在夹角正余弦上出错。

## 3 公式解析：曲面与空间曲线

**曲面方程** $F(x,y,z) = 0$ 是空间点集的隐式描述。最典型的曲面：

- **球面**：$(x-a)^2 + (y-b)^2 + (z-c)^2 = R^2$；
- **圆柱面**：$x^2 + y^2 = R^2$（母线平行 $z$ 轴）；
- **椭球面**：$\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$；
- **抛物面**：$z = x^2 + y^2$（椭圆抛物面）；
- **锥面**：$z^2 = x^2 + y^2$（圆锥面）。

二次曲面靠「截痕法」理解：用坐标平面去截曲面，看得到的截线形状。把「绕轴旋转的曲线」生成旋转曲面的规则拆开看：

- **第一步**，认清旋转轴与生成曲线。$yz$ 平面上的曲线 $f(y,z)=0$ 绕 $z$ 轴旋转，生成旋转曲面。
- **第二步**，写旋转不变量。绕 $z$ 轴旋转时，距离 $z$ 轴的半径 $\sqrt{x^2+y^2}$ 不变。
- **第三步**，替换得到方程。把曲线方程中的 $y^2$ 换成 $x^2 + y^2$，得 $f(\pm\sqrt{x^2+y^2}, z) = 0$，即 $z$ 轴旋转面方程。

**空间曲线**由两曲面方程联立 $F(x,y,z)=0, G(x,y,z)=0$ 给出，也可写成参数式 $\vec r(t) = (x(t), y(t), z(t))$——它把曲线看成「向量值函数」，是下一章曲线积分的起点。空间曲线在坐标平面上的**投影**也是常考题型：消去一个坐标变量，得到投影柱面，再与坐标平面相交即得投影曲线。<span class="marginnote">二次曲面的分类（椭球、双曲、抛物）与二次型理论同构，而二次型正是损失函数局部近似（Hessian 矩阵）的核心对象。理解二次曲面，等于为「高维抛物面」的优化直觉铺路。</span>

## 4 核心对比表：解析几何的基本对象

| 对象 | 关键要素 | 典型方程 | 关系判定 |
| --- | --- | --- | --- |
| 平面 | 法向量 $\vec n$ | $Ax+By+Cz+D=0$ | 平行 $\iff$ 法向量成比例 |
| 直线 | 方向向量 $\vec s$ | $\frac{x-x_0}{m}=\frac{y-y_0}{n}=\frac{z-z_0}{p}$ | 平行 $\iff$ 方向向量成比例 |
| 球面 | 球心 + 半径 | $(x-a)^2+\cdots=R^2$ | 距离公式 |
| 圆柱面 | 轴 + 半径 | $x^2+y^2=R^2$ | 母线平行于缺的坐标轴 |
| 旋转曲面 | 旋转轴 + 母线 | 替换 $y^2\to x^2+y^2$ | 半径不变原则 |
| 空间曲线 | 两曲面交线 / 参数 | $F=G=0$ 或 $\vec r(t)$ | 与曲面关系由切向量定 |

这张表是第八章的「对象字典」：每个几何对象抓住「用一个代数要素刻画」即可——平面看法向量、直线看方向向量、曲面看方程形式、曲线看参数方程。抓住了要素，全部关系判定（平行、垂直、夹角、距离）就都是要素之间的代数运算。

### 例：母线为 $z$ 轴、半径 $2$ 的圆柱面与平面 $y=0$ 的交线

$y=0$ 平面截圆柱面 $x^2 + y^2 = 4$，代入 $y=0$ 得 $x^2 = 4$，即 $x = \pm 2$——交线是平面 $y=0$ 内的两条平行直线 $x=2$、$x=-2$。这个简单例子展示「截痕法」的操作：**把坐标平面方程代入曲面方程，剩下什么就是截线方程**。二次曲面的截痕分析（椭圆、双曲线、抛物线）全部按这个流程进行。

## 5 小结

- 向量是「大小 + 方向」，线性运算 + 模长 + 单位向量构成基本词汇。
- 点积度量投影与垂直，叉积给出法向量与面积，混合积给出体积与共面判定。
- 平面用「点 + 法向量」刻画，直线用「点 + 方向向量」刻画，几何关系全部化为代数条件。
- 曲面分两类：二次曲面（截痕法）与旋转曲面（半径不变替换）；空间曲线是两曲面交线或向量值函数。
- 本章的「坐标化几何」是多元微积分与向量分析（梯度、散度、旋度、曲线曲面积分）的几何地基。
- 内积、正交、向量空间的语言在嵌入空间、注意力机制与优化理论中反复出现。

在下一节，我们将把导数推广到多自变量情形——**多元函数微分学**。向量正是描述「多自变量同时变化」的天然工具：梯度、方向导数、全微分都建立在「向量 + 微积分」的结合上。
