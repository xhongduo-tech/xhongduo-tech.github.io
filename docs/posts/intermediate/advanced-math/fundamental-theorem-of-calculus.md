## 为什么从微积分基本公式开始

上一节用定义算 $\int_0^1 x^2\,dx$ 已经够繁琐，要算 $\int_0^\pi \sin x\,dx$ 更是噩梦。然而 17 世纪牛顿与莱布尼茨各自发现了一个惊人的事实：**定积分（面积）与不定积分（原函数）是同一枚硬币的两面**——求面积不必再「切条求和取极限」，只要找到被积函数的原函数，代入上下限相减即可。这就是**微积分基本定理**，是整个微积分大厦的拱顶石。它把「几何的面积」与「代数的求导」焊接成一个整体：导数与积分互为逆运算。<span class="marginnote">费曼在《费曼物理学讲义》里把微积分基本定理称为「人类智慧的最高成就之一」。它的意义：以前要算面积只能靠穷竭法（阿基米德式的一次次逼近），而现在只需一行计算。数学的进步往往不是「做得更快」，而是「换一条完全不同的路」。</span>

## 1 积分上限函数

**积分上限函数**：设 $f$ 在 $[a,b]$ 上连续，定义

$$\Phi(x) = \int_a^x f(t)\,dt, \qquad a \le x \le b$$

$\Phi(x)$ 是「从 $a$ 到 $x$ 的面积」关于上限 $x$ 的函数——上限动了，面积就变。它是定积分从「一个数」变成「一个函数」的关键桥梁。

**积分上限函数的求导定理**：若 $f$ 在 $[a,b]$ 上连续，则 $\Phi(x) = \int_a^x f(t)\,dt$ 在 $[a,b]$ 上可导，且

$$\Phi'(x) = f(x)$$

**导数 = 被积函数**——面积函数的变化率，恰好回到曲线的高度 $f(x)$。几何直觉：把上限 $x$ 往右推一点 $dx$，新增的面积约等于 $f(x)dx$，所以面积函数的导数就是 $f(x)$。<span class="marginnote">这个定理把「积分」和「微分」第一次直接相连：对面积函数求导，得到的是原来的曲线。它同时证明了「连续函数必有原函数」（$\Phi$ 就是 $f$ 的一个原函数），补齐了第四章悬而未决的「原函数存在性」问题。</span>

## 2 微积分基本定理

**微积分基本定理（牛顿–莱布尼茨公式）**：设 $F(x)$ 是连续函数 $f(x)$ 在 $[a,b]$ 上的一个原函数，则

$$\int_a^b f(x)\,dx = F(b) - F(a)$$

**重点：定积分的计算从此不再需要黎曼和**——只需两步：找到 $f$ 的一个原函数 $F$，然后「上限代入减下限代入」。记法上常写成

$$\int_a^b f(x)\,dx = \left[F(x)\right]_a^b = F(b) - F(a)$$

**证明梗概**：由积分上限函数 $\Phi(x) = \int_a^x f(t)\,dt$，$\Phi'(x)=f(x)$，故 $\Phi$ 与 $F$ 都是 $f$ 的原函数，差一个常数：$\Phi(x) = F(x) + C$。令 $x=a$：$\Phi(a)=0$，得 $C = -F(a)$；令 $x=b$：$\Phi(b) = F(b) - F(a)$，即 $\int_a^b f(x)\,dx = F(b)-F(a)$。<span class="marginnote">证明只用了三件武器：积分上限函数的求导定理、原函数相差常数、$\Phi(a)=0$。三句话推出一条划时代公式——数学定理的力量常常来自「简洁的组装」而非「复杂的推导」。</span>

**辨析｜易错点：** ① 牛顿–莱布尼茨公式要求 $f$ 在 $[a,b]$ 上**连续**，$F$ 是原函数。若 $f$ 有间断点，直接套公式可能出错（如 $f(x)=\frac{1}{x^2}$ 在包含 0 的区间上是反常积分，见第 4 节）。② 若原函数在区间内不存在（如分段函数的接缝），要**分段积分**再相加。

## 3 公式解析：微积分基本定理的两种题型

**题型 A：用基本定理算定积分**

$$\int_0^1 x^2\,dx = \left[\frac{x^3}{3}\right]_0^1 = \frac{1}{3}$$

- **第一步，找原函数**：$\frac{x^3}{3}$ 是 $x^2$ 的原函数。
- **第二步，上下限代入**：$\frac{1^3}{3} - \frac{0^3}{3} = \frac{1}{3}$。
- **对比上一节**：用黎曼和算同一题要求和、取极限，这里两行完成——基本定理的效率差距是「量级」级别的。

**题型 B：对积分上限函数求导**

求 $\frac{d}{dx}\int_0^{x^2} \sin t\,dt$。由复合函数 + 积分上限求导：

$$\frac{d}{dx}\int_0^{x^2}\sin t\,dt = \sin(x^2)\cdot 2x$$

- **第一步，看清结构**：上限是 $x^2$ 而非 $x$，是「积分上限函数与 $x^2$ 的复合」。
- **第二步，外层套定理**：先对上限整体求导得 $\sin(\text{上限})$。
- **第三步，链式乘内层**：再乘上限的导数 $2x$。

一般公式：$\dfrac{d}{dx}\int_{a}^{\varphi(x)} f(t)\,dt = f(\varphi(x))\,\varphi'(x)$。<span class="marginnote">这类「积分上限函数求导」题是基本定理的考察热点，也是「变分法」的雏形——变分法里「对含积分的目标泛函求导」正是这种操作的推广。到《最优化理论》与物理学的变分原理你会再见到它。</span>

## 4 基本定理的深远意义

牛顿–莱布尼茨公式的价值远超「计算方便」，它统一了整个微积分：

**微分与积分互逆**：$\dfrac{d}{dx}\int_a^x f(t)\,dt = f(x)$（先积后导回原函数），$\int f'(x)\,dx = f(x)+C$（先导后积回原函数）——两个方向都被基本定理统领。
**定积分的可计算性**：任何初等函数在连续区间上的定积分，理论上都能用原函数算出——尽管原函数未必是初等函数（如 $e^{-x^2}$ 的原函数是误差函数 $\mathrm{erf}$，只能数值算）。<span class="marginnote">「原函数不存在于初等函数」是重要现实：$\int e^{-x^2}dx$ 没有初等表达式，但 $\int_{-\infty}^{\infty} e^{-x^2}dx = \sqrt{\pi}$ 却可以精确算出（泊松积分）。定积分的值可以用技巧算出，即使原函数「写不出来」——这是积分学中最反直觉也最深刻的现象之一。</span>
- **微分方程的理论基石**：$y' = f(x)$ 的解就是 $\int f(x)\,dx$；更一般的方程解也依赖「积分是微分的逆」这一事实。
- **数值积分的参照**：梯形公式、辛普森公式等数值积分方法都是「用黎曼和的有限版近似真值」，而真值由基本定理确定——没有基本定理，数值方法的误差分析就失去参照。

## 6 数值算例：基本定理的两路应用

**例 1（算定积分）**：$\int_0^2 (3x^2 + 2x)\,dx = \left[x^3 + x^2\right]_0^2 = (8+4) - 0 = 12$——找原函数代入上下限，两行完成。

**例 2（上限函数求导）**：$\frac{d}{dx}\int_1^{\sin x}\sqrt{1+t^2}\,dt = \sqrt{1+\sin^2 x}\cdot\cos x$——先代入上限、再乘上限导数。

**例 3（上下限都含参）**：$\frac{d}{dx}\int_x^{x^2} e^{t^2}dt = e^{x^4}\cdot 2x - e^{x^2}\cdot 1$——上限项减下限项，各乘各的导数。

**要点**：三类题型共用同一套规则——「上限代入乘上限导，下限代入乘下限导，符号一正一负」。<span class="marginnote">例 3 是「积分上限函数 + 复合函数」的完整版，也是变分法与含参积分（第十章）里「对含积分对象求导」的最小单元。把「代入边界 + 链式」练熟，你在《最优化理论》里对积分式泛函求导时就能从容应对。</span>

## 7 对照表：积分上限函数与面积

| 积分上限函数 | 几何意义 |
| --- | --- |
| $\Phi(x) = \int_a^x f(t)dt$ | 从 $a$ 到 $x$ 的「累积面积」 |
| $\Phi'(x) = f(x)$ | 面积增长率 = 当前高度 |
| $\Phi(b) - \Phi(a)$ | 区间上的净面积 |
| $\Phi(a) = 0$ | 从 $a$ 到 $a$ 面积为零 |

## 8 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 上限函数求导忘乘上限导数 | 复合时乘 $\varphi'(x)$ |
| 上下限都含参时只算一边 | 上限项减下限项，都要算 |
| 被积函数有间断点直接套公式 | 需分段积分或按反常处理 |
| 把 $\frac{d}{dx}\int f(x)dx$ 写成 $f(x)$ | 是 $f(x)$（对被积函数本身求导会出错） |

## 9 基本定理与整个微积分

牛顿–莱布尼茨公式把微积分拧成一个整体：

- **微分与积分互逆**：先积后导回原函数、先导后积回原函数——两个方向都由基本定理统领；
- **微分方程**：$y' = f(x)$ 的解就是积分——「积分是微分的逆」是解方程的基础；
- **数值积分**：梯形、Simpson 等数值方法逼近的「真值」由基本定理定义；
- **物理**：位移 = 速度的积分、功 = 力的积分——「累积量由变化率积分得到」。

「变化率积分回总量」这条链条，是科学里最常用的数学操作——基本定理就是它合法性的依据。

## 10 小结

- **积分上限函数** $\Phi(x) = \int_a^x f(t)\,dt$，其导数 $\Phi'(x) = f(x)$——面积函数的变化率回到曲线本身。
- **微积分基本定理（牛顿–莱布尼茨公式）**：$\int_a^b f(x)\,dx = F(b)-F(a)$。
- 证明思路：积分上限函数与 $F$ 都是原函数，差常数；取 $x=a$、$x=b$ 两步完成。
- 积分上限函数求导：$\frac{d}{dx}\int_a^{\varphi(x)} f(t)\,dt = f(\varphi(x))\varphi'(x)$。
- 上下限都含参时：上限项减下限项，各乘导数。
- 基本定理统一了微分与积分，是定积分可计算性的根基。
