## 为什么从函数图形的描绘开始

前面几节把导数这件工具打磨成了三件套：单调、凹凸、极值拐点。现在轮到「总装配」——**把一座函数从方程变成一张精确的图**。手工绘图的能力在计算器与 Python 普及的今天看似过时，实则恰恰相反：只有先具备「读图」的微积分素养，你才能判断机器画出来的图是否可信、会不会漏掉尖峰与渐近行为。更重要的是，描绘函数图形的整套流程——定义域、对称性、渐近线、单调凹凸、极值拐点——是对函数「性格」的全面体检，每一条检查项都对应着理解一个函数所需的关键情报。<span class="marginnote">在机器学习里，「描绘函数图形」升级为「诊断损失曲面」：学习率该取多大、会不会振荡、收敛到哪个局部谷——全靠对损失函数几何形状的理解。你现在学的每一道画图题，都在为将来「读懂」高维优化地形做准备。</span>

## 1 绘图前的整体信息

画函数图不是「找点连线」，而是**先体检、后落笔**。信息按优先级排开：

**定义域**：函数在哪些 $x$ 上有意义。分母不为零、偶次根号下非负、对数的真数为正、$\tan$ 的排除点等。
**对称性**：若 $f(-x) = f(x)$，图形关于 $y$ 轴对称（偶函数）；若 $f(-x) = -f(x)$，关于原点对称（奇函数）；若 $f(x+T)=f(x)$，周期为 $T$，只需画一个周期。<span class="marginnote">对称性与周期性可以把绘图工作量减半甚至减到「一份」：偶函数画右半边，左半边镜像；周期函数画一个周期，其余平移。这是最早见到的「利用结构降低计算量」——与算法里利用对称性压缩计算是同一思想。</span>
**与坐标轴的交点**：$y$ 截距 $f(0)$；$x$ 截距（零点）解 $f(x)=0$。

## 2 渐近线

渐近线描述函数在「无穷远处」或「洞附近」的走势，共三类：

**垂直渐近线**：若 $\lim\limits_{x\to x_0^-} f(x) = \pm\infty$ 或 $\lim\limits_{x\to x_0^+} f(x)=\pm\infty$，则直线 $x = x_0$ 是垂直渐近线。它通常出现在分母为零、$\tan$ 的极点处。<span class="marginnote">垂直渐近线是函数的「洞」——图形在 $x_0$ 附近直线上升或直线下坠，永不越过这条竖直的墙。判断时只需看 $x_0$ 是否为函数的「无界奇点」。</span>

**水平渐近线**：若 $\lim\limits_{x\to+\infty} f(x) = b$ 或 $\lim\limits_{x\to-\infty} f(x) = b$，则直线 $y=b$ 是水平渐近线。它描述函数在无穷远处的「归宿」。

**斜渐近线**：若 $\lim\limits_{x\to\infty} [f(x) - (kx+b)] = 0$，则直线 $y = kx+b$ 是斜渐近线，其中

$$k = \lim_{x\to\infty}\frac{f(x)}{x}, \qquad b = \lim_{x\to\infty}[f(x) - kx]$$

斜渐近线出现在「分子比分母高一阶」的有理函数等处，例如 $f(x) = \frac{x^2+1}{x} = x + \frac{1}{x}$ 的斜渐近线是 $y=x$。

## 3 绘制步骤的总流程

**函数图形描绘的完整流程**（按顺序执行，缺一不可）：

1. **定定义域**，找不可导点与不连续点；
2. **查对称性、周期性**，缩小绘图范围；
3. **求渐近线**：垂直、水平、斜各就各位；
4. **求单调区间**：解 $f'(x)=0$ 与不可导点，划分区间试符号；
5. **求极值点**：用第一或第二充分条件；
6. **求凹凸区间与拐点**：解 $f''(x)=0$，看变号；
7. **求特殊点**：截距、驻点、拐点、渐近线交点；
8. **描点连线**：把骨架画齐，曲线自然浮现。

这八步是一个「先粗后细、先整体后局部」的过程：先知道函数大体往哪去（渐近线），再知道它怎么弯（凹凸），最后落实峰谷与关键点。

## 4 公式解析：描绘 $y = \frac{2x}{1+x^2}$

以这道经典题演示全套流程：

- **第一步，定义域**：分母 $1+x^2 > 0$ 恒成立，定义域 $\mathbb{R}$。
- **第二步，对称性**：$f(-x) = \frac{-2x}{1+x^2} = -f(x)$，**奇函数**，图形关于原点对称，只需画 $x \ge 0$。
- **第三步，渐近线**：无垂直渐近线；$\lim\limits_{x\to\pm\infty}\frac{2x}{1+x^2} = 0$，水平渐近线 $y=0$。
- **第四步，单调与极值**：$f'(x) = \frac{2(1-x^2)}{(1+x^2)^2}$。驻点 $x=\pm1$。$x\in(0,1)$ 时 $f'>0$（递增），$x>1$ 时 $f'<0$（递减）。$x=1$ 是极大值点，$f(1)=1$；由奇对称性 $x=-1$ 是极小值点，$f(-1)=-1$。
- **第五步，凹凸与拐点**：$f''(x) = \frac{4x(x^2-3)}{(1+x^2)^3}$。$x=\sqrt3$ 处变号，$(\sqrt3, \frac{\sqrt3}{2})$ 是拐点。
- **第六步，连线**：曲线从原点出发，一路爬升到 $(1,1)$ 的峰，再缓降到渐近线 $y=0$，途中在 $\sqrt3$ 处从凹转凸。

最终图形是一条「先凸后凹再缓落」的奇函数曲线，形似起伏的山丘，被称为**阿涅西箕舌线**的变体家族成员。

## 5 读图能力的现代意义

手工描绘函数图在现代的真正价值在于**反向技能——读图**：

- **判断工具输出是否可信**：用 Python/Matplotlib 画 $y=\frac{\sin x}{x}$，若采样点恰好都落在 $x=0$ 附近之外，图会在 0 处留下一个看似真实的空洞——只有知道「可去间断点」的你才能纠正它。<span class="marginnote">数值绘图的「陷阱」：采样越密，越难看出间断与尖峰；采样太疏，又会漏掉极值与拐点。理解函数的结构（渐近线、单调区间、凹凸）能让你预判「图哪里最容易骗人」，这正是数据可视化素养的数学内核。</span>
- **参数敏感度分析**：机器学习的损失函数随超参数变化的曲线，本质上就是一张函数图——极值点对应最佳超参数，拐点对应「边际收益骤减」的区域。
- **建模的第一性思考**：任何「把现象写成函数」的工作，第一步都是理解这个函数的形状——先看趋势（渐近线）、再看波折（单调凹凸）、最后定位极值。

## 7 数值算例：描绘 $y = \frac{x^3}{x^2 - 1}$

**第一步，定义域**：分母 $x^2 - 1 = 0$，$x = \pm1$，定义域 $\mathbb{R}\setminus\{\pm1\}$。
**第二步，对称性**：$f(-x) = \frac{-x^3}{x^2-1} = -f(x)$，奇函数，只需画 $x \ge 0$ 再镜像。
**第三步，渐近线**：垂直渐近线 $x = \pm1$（分母为零处极限 $\pm\infty$）；$\lim\frac{x^3}{x^2-1}$ 发散，但 $f(x) = x + \frac{x}{x^2-1}$，故**斜渐近线 $y = x$**。
**第四步，单调与极值**：$f'(x) = \frac{x^2(x^2-3)}{(x^2-1)^2}$，驻点 $x = \pm\sqrt3$，$x=0$ 处导数也为 0（但不变号，非极值）。$x=\sqrt3$ 是极小值点。
**第五步，凹凸**：$f''(x) = \frac{2x(x^2+3)}{(x^2-1)^3}$，$x=0$ 处变号，拐点 $(0,0)$。

**完整画像**：奇函数、两支、垂直渐近线 $x=\pm1$、斜渐近线 $y=x$、极小值在 $\sqrt3$、原点拐点——所有信息拼出可心的图形。<span class="marginnote">这道题综合了八步流程的全部要素：<strong>垂直 + 斜渐近线同时出现</strong>（分子比分母高一阶），还有「驻点但非极值」的陷阱（$x=0$）。完整走一遍流程，才能避免「只看导数就画图」的粗糙。</span>

## 8 对照表：三类渐近线

| 类型 | 判定 | 含义 | 例子 |
| --- | --- | --- | --- |
| 垂直 | $\lim_{x\to x_0} f = \pm\infty$ | 无界奇点 | $\frac1x$ 在 0 |
| 水平 | $\lim_{x\to\pm\infty} f = b$ | 无穷归宿 | $\frac{2x}{1+x^2} \to 0$ |
| 斜 | $f - (kx+b) \to 0$ | 无穷线性走势 | $\frac{x^2+1}{x}$，$y=x$ |

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 跳过定义域直接求导 | 定义域决定可讨论的区间 |
| 漏找垂直渐近线 | 检查分母零点等无界奇点 |
| 只看 $f'=0$ 漏不可导点 | 不可导点也可能是极值点 |
| 渐近线当作「不能穿越」 | 曲线可以穿过斜/水平渐近线（如振荡趋近） |

## 10 绘图流程 = 函数分析的通用框架

八步流程不只是「画图」，它是分析任意函数的通用框架：

- **建模**：把现象写成函数后，第一件事就是「体检」——定义域、趋势、极值；
- **优化**：单调与极值分析是找最值的基础（下一节专门讲）；
- **数据可视化**：判断机器绘图是否可信，靠的正是你对「函数结构」的预判。

「先整体后局部、先趋势后细节」的分析顺序，是你在本节获得的最大能力，它远超「会画图」本身。

## 11 小结

- 绘图前先取**整体信息**：定义域、对称性、周期性、截距。
- **三类渐近线**：垂直（无界奇点）、水平（无穷归宿）、斜（分子高一阶的有理函数）。
- 绘图八步流程：定义域 → 对称 → 渐近线 → 单调 → 极值 → 凹凸 → 拐点 → 描点连线。
- 奇偶性、周期性把绘图工作量减半甚至减到一份。
- 驻点不一定极值（需变号），不可导点也可能是极值。
- 读图能力让你**判断机器绘图的可信度**，是数据可视化的数学内核。
