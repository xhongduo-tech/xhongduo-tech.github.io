## 为什么从定积分的几何应用开始

上一节的方法论——元素法——现在要派上用场。几何学里三个最自然的「连续总量」问题：平面图形的面积、旋转体的体积、曲线的弧长。它们都能用「切微元、再积分」统一解决，而且微元的形状各不相同：面积用细矩形，体积用薄圆饼或薄壳，弧长用弦段。掌握这三种微元，你就掌握了「用积分做几何」的全部套路，也为第十章重积分（面积分）与第十一章曲线积分（弧长）打下直觉。<span class="marginnote">几何应用的魅力在于「同一个工具，三种微元」：面积 $dA = f(x)dx$、体积 $dV = \pi[f(x)]^2 dx$（圆饼）、弧长 $ds = \sqrt{1+y'^2}\,dx$（弦段）。微元形状不同，但「局部近似 + 积分加总」的骨架完全一致——这正是元素法的通用性所在。</span>

## 1 平面图形的面积

**直角坐标下的面积**：由曲线 $y=f(x)$、$y=g(x)$（$f \ge g$）与直线 $x=a$、$x=b$ 围成的图形面积为

$$A = \int_a^b [f(x) - g(x)]\,dx$$

微元：$dA = [f(x) - g(x)]\,dx$——高为「上曲线减下曲线」的细矩形。求面积的关键是**正确识别上下曲线**与积分区间。

例：求抛物线 $y = x^2$ 与直线 $y = 2x$ 围成的面积。先求交点：$x^2 = 2x \Rightarrow x=0,2$。区间 $[0,2]$ 上 $2x \ge x^2$，故

$$A = \int_0^2 (2x - x^2)\,dx = \left[x^2 - \frac{x^3}{3}\right]_0^2 = 4 - \frac{8}{3} = \frac{4}{3}$$

**辨析｜易错点：** ① 上下曲线要分清，减反了会得负面积；② 若曲线有交叉（$f$ 与 $g$ 谁上谁下会变），要在交点处**分段积分**；③ 有时对 $y$ 积分更简单——若图形沿 $y$ 方向「好描述」，可写 $x$ 为 $y$ 的函数、用 $dy$ 作微元。<span class="marginnote">「对 $x$ 还是对 $y$ 积分」的选择直接影响计算量：图形「上下函数明确」则对 $x$ 积，「左右函数明确」则对 $y$ 积。这与坐标选取的自由度——换元思想在积分几何里的体现。选择更简单的切片方向，往往让计算量减半。</span>

## 2 旋转体的体积

**绕 $x$ 轴旋转**：曲线 $y=f(x)$（$f\ge0$）与直线 $x=a$、$x=b$ 及 $x$ 轴围成的图形绕 $x$ 轴旋转，所得旋转体体积为

$$V = \pi\int_a^b [f(x)]^2\,dx$$

微元：$dV = \pi[f(x)]^2\,dx$——厚度 $dx$ 的**薄圆盘**，半径 $f(x)$。**绕 $y$ 轴旋转**（垫圈法/壳层法）有相应公式，如壳层法 $V = 2\pi\int_a^b x\,f(x)\,dx$。

例：$y = \sqrt{x}$ 在 $[0,1]$ 上绕 $x$ 轴旋转。$V = \pi\int_0^1 x\,dx = \frac{\pi}{2}$——半支抛物线转出的「锥形」体积恰是半径 1 高 1 圆锥（$\frac{\pi}{3}$）的 1.5 倍。<span class="marginnote">旋转体体积的直觉：把图形绕轴转一圈，每片薄圆盘的半径是曲线到轴的距离。圆盘法（切片垂直轴）与壳层法（切片平行轴）是两种互补视角——选择「谁当半径」通常由曲线的表达式决定，圆的面积 $\pi r^2$ 乘厚度就是微元。</span>

## 3 平面曲线的弧长

**弧长公式**：曲线 $y = f(x)$ 在 $[a,b]$ 上的弧长为

$$s = \int_a^b \sqrt{1 + y'^2}\,dx$$

微元：$ds = \sqrt{1 + y'^2}\,dx$——弧长微分。来源：弦段长的极限，$(ds)^2 = (dx)^2 + (dy)^2$，即 $ds = \sqrt{dx^2 + dy^2} = \sqrt{1 + y'^2}\,dx$。参数方程 $\begin{cases}x=\varphi(t)\\y=\psi(t)\end{cases}$ 的弧长为

$$s = \int_\alpha^\beta \sqrt{\varphi'^2(t) + \psi'^2(t)}\,dt$$

**公式解析：弧长微元 $ds$ 怎么来**

$$ds = \sqrt{1 + y'^2}\,dx$$

- **第一步，局部近似**：把曲线的一小段 $ds$ 近似为直角三角形斜边，直角边是 $dx$ 与 $dy$。
- **第二步，勾股定理**：$(ds)^2 = (dx)^2 + (dy)^2$，故 $ds = \sqrt{(dx)^2 + (dy)^2}$。
- **第三步，提取 $dx$**：$ds = \sqrt{1 + (dy/dx)^2}\,dx = \sqrt{1+y'^2}\,dx$。

**关键**：弧长微元是「勾股定理的微分版」——曲线微元由水平步进与竖直步进合成。这解释了为什么弧长公式里有 $\sqrt{1+y'^2}$：它正是「斜边 = 直角边合成」的量化。

例：$y = \frac{2}{3}x^{3/2}$ 在 $[0,4]$ 上的弧长：$y' = x^{1/2}$，$s = \int_0^4 \sqrt{1+x}\,dx = \frac{2}{3}(1+x)^{3/2}\Big|_0^4 = \frac{2}{3}(5\sqrt5 - 1)$。

## 4 三大几何量一览

| 几何量 | 微元 | 公式 | 关键直觉 |
| --- | --- | --- | --- |
| 面积 | 细矩形 $dA$ | $\int_a^b [f(x)-g(x)]dx$ | 高 × 宽 |
| 旋转体体积（绕 $x$ 轴） | 薄圆盘 $dV$ | $\pi\int_a^b f(x)^2 dx$ | 圆面积 × 厚 |
| 弧长 | 弦段 $ds$ | $\int_a^b \sqrt{1+y'^2}\,dx$ | 勾股合成 |

<span class="marginnote">记忆锚：<strong>面积看高度，体积看半径，弧长看勾股</strong>。三种微元都遵循「局部近似成好算的形状 + 积分加总」；区别只在于「好算的形状」是什么——矩形、圆盘还是斜边。到第十章重积分，微元会升级为 $dA = dx\,dy$ 与 $dV = dx\,dy\,dz$，但骨架依旧。</span>

## 5 从平面到空间：几何应用的延伸

**旋转体侧面积**：$S = 2\pi\int_a^b f(x)\sqrt{1+y'^2}\,dx$——把弧长微元当作「环带宽度」，乘圆周 $2\pi f(x)$。
**参数曲线与极坐标**：极坐标面积 $A = \frac{1}{2}\int_\alpha^\beta r^2(\theta)\,d\theta$（扇形微元），极坐标弧长 $s = \int_\alpha^\beta \sqrt{r^2 + r'^2}\,d\theta$。<span class="marginnote">极坐标面积微元 $\frac{1}{2}r^2\,d\theta$ 的直觉：半径 $r$ 的扇形微元，面积 = 弧长 $rd\theta$ × 半径的一半（三角形面积公式）。极坐标把「旋转对称」的图形描述得极简，是积分几何的第二个坐标系工具箱。</span>
- **重积分的铺垫**：平面面积 $\iint_D dx\,dy$、体积 $\iiint_\Omega dV$、曲面面积 $\iint_D \sqrt{1+z_x^2+z_y^2}\,dx\,dy$，都是本节微元的二维/三维升级——到第十章与第十一章将系统展开。
- **概率与统计**：计算概率密度的「曲线下面积」用的正是本节面积公式；正态曲线下 95% 的面积对应 $1.96\sigma$ 区间，即面积分应用。

## 7 数值算例：壳层法求旋转体体积

用**壳层法**求 $y = x^2$ 在 $[0,1]$ 上绕 $y$ 轴旋转所得体积。

**第一步，选微元**：绕 $y$ 轴旋转，用「薄壳」——半径为 $x$、高 $y=x^2$、厚 $dx$ 的圆柱壳。
**第二步，写微元**：$dV = 2\pi x\cdot f(x)\,dx = 2\pi x\cdot x^2\,dx = 2\pi x^3\,dx$——「周长 × 高 × 厚」。
**第三步，积分**：$V = 2\pi\int_0^1 x^3\,dx = 2\pi\cdot\frac14 = \frac{\pi}{2}$。

**要点**：壳层法的微元是「圆柱壳」（周长 $2\pi x$ × 高 × 厚），与圆盘法（$\pi f(x)^2 dx$）互补——「绕 $y$ 轴用壳层、绕 $x$ 轴用圆盘」通常是更方便的组合。<span class="marginnote">圆盘 vs 壳层的选择直觉：<strong>「谁的表达式简单就用谁」</strong>——绕 $y$ 轴时若 $f(x)$ 简单（本题 $x^2$）用壳层一步到位；若 $x$ 是 $y$ 的函数 $x=g(y)$ 简单，则绕 $y$ 轴也可用「水平圆盘」。两种方法本质相同，都是「切成好算的薄片再积分」。</span>

## 8 对照表：圆盘法与壳层法

| 圆盘法（washer） | 壳层法（shell） |
| --- | --- |
| 薄圆盘垂直旋转轴 | 圆柱壳平行旋转轴 |
| $dV = \pi r^2\,dx$ | $dV = 2\pi x f(x)\,dx$ |
| 半径是「曲线到轴的距离」 | 半径是「壳到轴的距离」 |
| 适合「上下边界明确」 | 适合「左右边界明确」 |

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 面积公式上下曲线写反 | $f \ge g$ 时用 $f-g$，否则负面积 |
| 圆盘法忘平方 | $dV = \pi f(x)^2 dx$，半径要平方 |
| 壳层法忘乘 $2\pi x$ | 薄壳的周长因子不能漏 |
| 弧长公式忘根号 | $ds = \sqrt{1+y'^2}\,dx$ 必带根号 |

## 10 几何应用与现代技术

定积分的几何应用是大量工程计算的基础：

- **工程设计**：储罐容积、旋转体零件体积、管道弧长——全是积分；
- **计算机图形**：曲线渲染的弧长、曲面建模的面积计算；
- **物理学**：转动惯量、质心、水压——第六章的「物理应用」与这里同源；
- **概率**：正态曲线下的面积（$1.96\sigma$ 区间 95%）是「曲线下面积」的统计版本。

「把几何量切成微元再积分」是计算一切连续量的万能模板——你在这里练的三类微元，是它在几何维度上的标准示范。

## 11 小结

- **面积**：$A = \int_a^b [f(x)-g(x)]dx$，细矩形微元，注意上下曲线与分段。
- **旋转体体积**：$V = \pi\int_a^b f(x)^2 dx$，薄圆盘微元（壳层法另算）。
- **壳层法**：$V = 2\pi\int_a^b x f(x)\,dx$，绕 $y$ 轴旋转的圆柱壳微元。
- **弧长**：$s = \int_a^b\sqrt{1+y'^2}\,dx$，弧长微元来自勾股定理的微分版。
- 参数方程与极坐标各有对应的面积、弧长公式。
- 三大几何量的共同骨架：**局部近似 + 积分加总**，是重积分与曲线积分的直觉基础。
