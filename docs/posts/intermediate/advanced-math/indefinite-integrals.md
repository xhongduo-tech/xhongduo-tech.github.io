## 为什么需要「已知导数求原函数」

前三章我们建立了「函数 → 导数」的方向：给定位置函数 $s(t)$，求速度 $v(t) = s'(t)$。但现实中更多是**逆问题**：已知加速度、速度或增长率，反推位置、位移或总量。已知 $f(x)$，求满足 $F'(x) = f(x)$ 的函数 $F(x)$——这就是**原函数**，而原函数全体构成的集合叫**不定积分**。

**定义**：若 $F'(x) = f(x)$，则 $f$ 的全体原函数记为

$$\int f(x)\,dx = F(x) + C$$

其中 $C$ 是任意常数。不定积分不是「一个函数」，而是「一族函数」——因为 $(F(x)+C)' = F'(x) = f(x)$，加任意常数仍是原函数。<span class="marginnote">$C$ 不是可以随手丢弃的装饰：它代表「初始条件」的自由度。后面微分方程里，$C$ 由初值 $y(x_0)=y_0$ 唯一确定；这也是「不定积分 + 初始条件 = 确定解」这条思路的雏形。</span>

从「从极限到大模型」主线看，不定积分是理解概率论、统计与深度学习理论的必备语言：概率密度函数的累积分布函数就是「对密度求原函数」；归一化常数（配分函数）往往是一个「难以求闭式原函数」的积分。第四章训练的正是「识别结构、选用方法」的积分直觉——这正是大模型论文中处处「积分技巧」所依赖的能力。

## 1 基本积分表：求导公式的「反着念」

不定积分与求导互为逆运算，所以**每一张求导公式表都对应一张积分公式表**。最常用的基本积分公式有：

$$\int x^\mu dx = \frac{x^{\mu+1}}{\mu+1} + C\ (\mu \ne -1), \qquad \int \frac{dx}{x} = \ln|x| + C$$

$$\int \cos x\,dx = \sin x + C, \qquad \int \sin x\,dx = -\cos x + C, \qquad \int e^x dx = e^x + C$$

积分是线性运算：$\int[af(x) + bg(x)]\,dx = a\int f(x)\,dx + b\int g(x)\,dx$。这意味着「被积函数是若干基本函数之和」时，可以**逐项积分**，把复杂积分拆成基本积分。

**重点：求导是确定的机械操作，求积分需要「看出」哪个函数求导会得到它。** 正因为这种「逆向性」，积分的难度远远大于求导，需要靠「大量练习形成模式识别」来掌握。求导会做，不等于会积分；反之，如果你会积分，求导基本不成问题。

## 2 换元积分法：把积分变回标准形

基本积分表只能处理「正好是标准形」的积分。绝大多数积分需要**变形**。换元积分法分两类，作用相反：

**第一类换元（凑微分）**：若 $f$ 有原函数，且 $u = \varphi(x)$ 可导，则

$$\int f[\varphi(x)]\,\varphi'(x)\,dx = \left[\int f(u)\,du\right]_{u=\varphi(x)}$$

核心动作是「凑」：把 $\varphi'(x)dx$ 看作 $d\varphi(x)$，把整个被积式整理成「对 $\varphi(x)$ 的某个已知积分」。例如 $\int 2x e^{x^2}dx$，看到 $2x$ 正是 $x^2$ 的导数，令 $u = x^2$，得 $\int e^u du = e^{x^2} + C$。

**第二类换元（变量代换）**：设 $x = \psi(t)$ 单调可导且 $\psi'(t) \ne 0$，则

$$\int f(x)\,dx = \left[\int f[\psi(t)]\,\psi'(t)\,dt\right]_{t=\psi^{-1}(x)}$$

用于被积函数含根式或复杂表达式的场合，典型代换：$\sqrt{a^2 - x^2}$ 用 $x = a\sin t$，$\sqrt{a^2 + x^2}$ 用 $x = a\tan t$，$\sqrt{x^2 - a^2}$ 用 $x = a\sec t$。<span class="marginnote">三角代换的本质是「用三角恒等式消去根号」：$\sin^2 t + \cos^2 t = 1$、$1 + \tan^2 t = \sec^2 t$ 把根号下的表达式化成完全平方。做完换元后别忘了「回代」——把 $t$ 变回 $x$。</span>

## 3 公式解析：分部积分法

当被积函数是**两类不同函数之积**时，换元常失效，改用**分部积分法**。由乘积求导公式 $(uv)' = u'v + uv'$ 反推：

$$\int u\,dv = uv - \int v\,du$$

拆开看这条公式的三个使用要点：

- **第一步，选 $u$ 与 $dv$。** 把被积式拆成「一部分当 $u$、另一部分进 $dv$」。$u$ 应选「求导后变简单」的，$dv$ 应选「积分后不复杂」的。
- **第二步，算 $du$ 与 $v$。** $du = u' dx$，$v = \int dv$。代入公式后，把原积分 $\int u\,dv$ 转化为新积分 $\int v\,du$。
- **第三步，验证新积分更简单。** 若 $\int v\,du$ 反而更难，说明 $u$、$dv$ 选反了。

**口诀「反对幂指三」** 帮助记忆选 $u$ 的优先级：反三角函数、对数函数、幂函数、指数函数、三角函数。例：$\int x e^x dx$ 中选 $u = x$（幂函数）、$dv = e^x dx$，得 $x e^x - \int e^x dx = x e^x - e^x + C$。<span class="marginnote">分部积分偶尔要「循环」：$\int e^x \sin x\,dx$ 连续分部两次会回到自身，此时把原积分当未知数解方程——这是积分技巧里最巧妙的一招。</span>

### 例：计算 $\int x\ln x\,dx$

**第一步，选 $u$ 与 $dv$。** 按「反对幂指三」，对数函数优先当 $u$：令 $u = \ln x$、$dv = x\,dx$。

**第二步，算 $du$ 与 $v$。** $du = \frac{dx}{x}$，$v = \frac{x^2}{2}$。

**第三步，代入分部积分公式。** 

$$\int x\ln x\,dx = \frac{x^2}{2}\ln x - \int \frac{x^2}{2}\cdot\frac{dx}{x} = \frac{x^2}{2}\ln x - \frac{1}{2}\int x\,dx = \frac{x^2}{2}\ln x - \frac{x^2}{4} + C$$

**第四步，自检。** 对结果求导：$\frac{1}{2}\cdot 2x\ln x + \frac{x^2}{2}\cdot\frac1x - \frac{2x}{4} = x\ln x + \frac{x}{2} - \frac{x}{2} = x\ln x$，得回被积函数，正确。

注意：这里 $u$ 若选成 $x$、$dv = \ln x\,dx$，新积分 $\int v\,du$ 会变成 $\int(\frac{x^2}{2}\cdot 1)dx$ 反而更麻烦——「对数优先当 $u$」正是为了让求导后的 $\frac{1}{x}$ 把幂降下来。

## 4 有理函数与三角有理式的积分

**有理函数积分**：被积函数是多项式之比 $\frac{P(x)}{Q(x)}$。标准流程是**部分分式分解**：

1. 若分子次数不低于分母，先做多项式除法，化出真分式。
2. 分母因式分解（实系数下分解为一次因式与二次因式）。
3. 每个因式对应一个或几个部分分式，用待定系数法求系数。
4. 逐项积分：一次因式给对数，重根给幂函数，二次因式配方后给反正切。

例如 $\int \frac{dx}{x^2 - 1} = \int\left(\frac{1/2}{x-1} - \frac{1/2}{x+1}\right)dx = \frac{1}{2}\ln\left|\frac{x-1}{x+1}\right| + C$。部分分式是工程中拉普拉斯反变换、信号与系统、控制理论的看家本领——任何传递函数都能拆成「简单环节之和」，正是这一节打下的基础。

部分分式分解的「待定系数法」操作很机械：设 $\frac{1}{x^2-1} = \frac{A}{x-1} + \frac{B}{x+1}$，通分后比较分子 $1 = A(x+1) + B(x-1)$。代入 $x=1$ 得 $1 = 2A$ 即 $A=\frac12$；代入 $x=-1$ 得 $1=-2B$ 即 $B=-\frac12$——通过「代特殊值」快速解出系数，比分等式恒等更方便。

**三角有理式积分**：被积函数是 $\sin x$、$\cos x$ 的有理式，可用**万能代换** $t = \tan\frac{x}{2}$，把积分化为 $t$ 的有理函数积分：

$$\sin x = \frac{2t}{1+t^2}, \qquad \cos x = \frac{1-t^2}{1+t^2}, \qquad dx = \frac{2\,dt}{1+t^2}$$

万能代换「无脑但繁」，适合没有更好结构的三角有理式；结构明显的（如 $\sin^n x\cos^m x$）往往有更快的专用代换。例如 $\int \sin^2 x\,dx$ 用倍角公式降幂：$\sin^2 x = \frac{1-\cos 2x}{2}$，一步化为基本积分；对 $\int \sin^3 x\,dx$ 则提一个 $\sin x$ 进 $d(\cos x)$，用 $\sin^2 x = 1 - \cos^2 x$ 处理。先看结构、再选方法，是积分题的通用心法。

## 5 积分表：最后的靠山

当换元、分部、部分分式都试过仍无闭式解时，就查**积分表**。同济《高等数学》附有常用积分表，工程中还有更完备的参考书（如 Gradshteyn & Ryzhik）。使用积分表的技巧是「先变形到表上有」——通过凑微分把被积式整理成表中标准形，再套用公式。<span class="marginnote">现代数值计算中，查表逐渐让位于「数值积分 + 计算机代数」（如 Mathematica、SymPy）。但「识别结构、判断该走哪条路」的思维，仍是人工与机器都需要的核心技能。</span>

**辨析｜易错点：** 分部积分法中，若被积函数含「对数或反三角」这样的慢变因子，务必把它当作 $u$，把「指数、幂、三角」这类快积因子放进 $dv$，否则新积分往往比原积分更复杂。

**辨析｜易错点：** 使用积分表或软件前，务必核实变量、系数与符号——表中的 $a^2$、$x^2$ 与题目的 $3x^2$ 往往差一个常数因子。养成「代回去求导验证」的习惯：算完不定积分，对它求导，若得回被积函数，则必正确。这条验证法对一切不定积分成立，是免检自检的黄金手段。

## 6 小结

- 不定积分是求导的逆运算：$\int f(x)dx = F(x) + C$，$C$ 不可省略。
- 基本积分表由求导公式「反着念」得到，积分是线性运算可逐项进行。
- 换元法（凑微分 / 变量代换）把积分变回标准形；三角代换靠恒等式消根号。
- 分部积分法 $\int u\,dv = uv - \int v\,du$，选 $u$ 按「反对幂指三」。
- 有理函数靠部分分式分解化整为零；查表前先变形到标准形。
- 万能自检：对结果求导验证，得回被积函数即正确。

在下一节，我们将走出「不定积分」的求解练习，进入**定积分**——带上下限的积分。微积分基本定理会把「求原函数」与「算面积」两件看似无关的事焊在一起，从此积分的意义不再只是「反求导」，而是「求总量」。
