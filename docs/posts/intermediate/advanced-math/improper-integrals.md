## 为什么从反常积分开始

定积分要求「有界函数 + 有限区间」两个条件。可现实中处处突破这两个条件：从地面发射的火箭要算「逃逸到无穷远需要多少能量」（无穷区间），概率密度在区间端可能发散（无界函数），物理学里的「整个空间的总场强」也是无穷区间积分。**反常积分（广义积分）**就是把这些「边界情形」纳入积分体系：把无穷区间看作有限区间的极限，把无界函数看作「挖掉坏点」的极限。它让「无限延伸的图形有没有面积」「无限高的尖峰有没有总量」这类问题有了精确答案。<span class="marginnote">反常积分的核心哲学：<strong>「无穷」不是终点，而是取极限的过程</strong>。$\int_1^\infty \frac{dx}{x^2}$ 不是「真的加到无穷」，而是「先把上限推到 $b$，再让 $b\to\infty$ 看极限」——把不可计算的对象定义为可计算过程的极限。这与数列极限的思想一脉相承。</span>

## 1 无穷限反常积分（第一类）

**无穷限反常积分**：设 $f$ 在 $[a,+\infty)$ 上连续，定义

$$\int_a^{+\infty} f(x)\,dx = \lim_{b \to +\infty}\int_a^b f(x)\,dx$$

若右端极限存在，则称该反常积分**收敛**，否则称**发散**。类似定义 $\int_{-\infty}^b f(x)\,dx$ 与 $\int_{-\infty}^{+\infty} f(x)\,dx$（后者 = 两段之和，且两段都要收敛）。

**重点：收敛 = 极限存在 = 有限值。** 例如 $\int_1^{+\infty}\frac{dx}{x^2}$：

$$\lim_{b\to\infty}\int_1^b \frac{dx}{x^2} = \lim_{b\to\infty}\left[-\frac{1}{x}\right]_1^b = \lim_{b\to\infty}\left(1 - \frac{1}{b}\right) = 1$$

「无限长的尾巴」竟然有有限面积——因为 $\frac{1}{x^2}$ 衰减得足够快，尾巴越远越细，总量收敛。<span class="marginnote">「无穷长但有穷面积」是反常积分最反直觉的结论。它取决于衰减速度：$\int_1^\infty\frac{dx}{x^p}$ 当 $p>1$ 收敛、$p\le1$ 发散——$p=1$ 时是调和积分，尾巴「慢吞吞」地累积到无穷。衰减速度决定收敛与否，这正是下一节审敛法的核心。</span>

**辨析｜易错点：** ① $\int_{-\infty}^{+\infty} f(x)\,dx$ 收敛要求**两个**单侧反常积分都收敛，不能只算「主值」。如 $\int_{-\infty}^{+\infty} x\,dx$ 的对称主值 $\lim\limits_{A\to\infty}\int_{-A}^A x\,dx = 0$，但真正的反常积分发散——正负两侧各趋向无穷，谈不上收敛。② 计算时用原函数代入无穷限要取极限：$F(+\infty) = \lim\limits_{b\to+\infty}F(b)$，不能直接写「$F(\infty)$」。

## 2 无界函数的反常积分（第二类）

**无界函数的反常积分**：设 $f$ 在 $(a,b]$ 上连续且 $\lim\limits_{x\to a^+} f(x) = \infty$（$a$ 是瑕点），定义

$$\int_a^b f(x)\,dx = \lim_{\varepsilon \to 0^+}\int_{a+\varepsilon}^b f(x)\,dx$$

若极限存在则收敛，否则发散。$f$ 在 $b$ 处无界或在内部点 $c$ 处无界的情况类似处理（后者需拆成两段）。这样的积分也叫**瑕积分**，$a$ 称为**瑕点**。

例：$\int_0^1 \frac{dx}{\sqrt{x}}$，瑕点在 $x=0$：

$$\lim_{\varepsilon\to0^+}\int_\varepsilon^1 x^{-1/2}\,dx = \lim_{\varepsilon\to0^+} 2\sqrt{x}\Big|_\varepsilon^1 = \lim_{\varepsilon\to0^+} 2(1 - \sqrt{\varepsilon}) = 2$$

函数在 0 处趋于无穷，但面积却收敛到 2——「无限高的尖峰」也能有有限面积，只要尖峰足够「细」。<span class="marginnote">类比 $\int_0^1 \frac{dx}{x^p}$：$p<1$ 收敛、$p\ge1$ 发散。与无穷限情形 $\int_1^\infty\frac{dx}{x^p}$（$p>1$ 收敛）恰好互补——这里 $p$ 越大，瑕点附近函数「越陡」，越容易发散。收敛与发散的判据，就藏在幂次的分界点上。</span>

## 3 公式解析：两种反常积分的统一处理

考察 $\int_0^{+\infty} e^{-x}\,dx$——它兼有「无穷区间」的特征，但无瑕点：

- **第一步，拆或直接取极限**：$\int_0^{+\infty} e^{-x}\,dx = \lim\limits_{b\to+\infty}\int_0^b e^{-x}\,dx$。
- **第二步，求定积分**：$\int_0^b e^{-x}\,dx = \left[-e^{-x}\right]_0^b = 1 - e^{-b}$。
- **第三步，取极限**：$\lim\limits_{b\to+\infty}(1 - e^{-b}) = 1$，收敛，值为 1。

再看兼有两种反常的 $\int_0^{+\infty}\frac{dx}{x^2}$：在 0 处无界（第二类）+ 无穷区间（第一类）。须**拆成两段** $\int_0^1 + \int_1^{+\infty}$，只要任一段发散，整体就发散。这里 $\int_0^1\frac{dx}{x^2}$ 发散（$p=2\ge1$），故整体发散——**两类反常的「雷区」叠加时，任何一个都会让整体爆炸**。

## 4 反常积分的概率意义

反常积分在概率论与物理里无处不在，它把「概率密度」与「总量」从有限延伸到无限：

- **概率密度归一化**：$p(x) \ge 0$ 且 $\int_{-\infty}^{+\infty} p(x)\,dx = 1$——这个无穷区间积分必须收敛到 1，才是合法的概率密度。<span class="marginnote">概率密度是「总面积必须等于 1」的积分约束，这全靠反常积分的收敛性保证。正态分布、柯西分布、指数分布都是无穷区间积分收敛的典型。期望 $E[X]=\int_{-\infty}^\infty x\,p(x)\,dx$ 也可能是反常积分——若它发散，说明该分布没有有限期望（如柯西分布）。</span>
- **指数衰减的生命统计**：$\int_0^\infty \lambda e^{-\lambda x}\,dx = 1$ 是指数分布密度的归一化，$\int_0^\infty \lambda x e^{-\lambda x}\,dx = \frac{1}{\lambda}$ 是期望——都靠「$e^{-x}$ 衰减快于任何多项式」的收敛性质。
- **物理中的无穷过程**：火箭逃逸功、电磁场总能量、扩散问题的时间积分，常以反常积分形式出现。
- **信号处理**：拉普拉斯变换 $\int_0^\infty f(t)e^{-st}\,dt$ 本身就是一个以收敛性为前提的反常积分——只有收敛，变换才存在。

## 5 小结

- **第一类反常积分**（无穷区间）：$\int_a^\infty f(x)\,dx = \lim\limits_{b\to\infty}\int_a^b f(x)\,dx$。
- **第二类反常积分**（无界函数）：$\int_a^b f(x)\,dx = \lim\limits_{\varepsilon\to0^+}\int_{a+\varepsilon}^b f(x)\,dx$。
- **收敛 ⟺ 极限存在（有限）**；两类兼有时要拆段，任一段发散则整体发散。
- 判别尺度：$\int_1^\infty\frac{dx}{x^p}$ 当 $p>1$ 收敛；$\int_0^1\frac{dx}{x^p}$ 当 $p<1$ 收敛。
- 概率密度的归一化、期望与拉普拉斯变换都依赖反常积分的收敛性。
