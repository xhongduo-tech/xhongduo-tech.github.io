## 为什么从可降阶的高阶微分方程开始

高阶方程（二阶及以上）直接求解极其困难，但有三类特殊的二阶方程可以通过**换元降阶**——把二阶降成一阶，用前面已经娴熟的一阶方法解决。这三类是：不显含 $y$ 的、不显含 $x$ 的、以及「可分离型」的。**降阶**是本章的核心思想：高阶问题的解法是「先降低阶数，再逐阶求解」。这个「把难问题拆成连续几步简单问题」的策略，也是数值方法与算法设计的通用原则。<span class="marginnote">「降阶」的直觉：微分方程的高阶难就难在「阶」——每高一阶，解的空间就多一个自由度。降阶就是「每次砍掉一个自由度」。这与算法里「递归降规模」「分治拆问题」共享同一个精神：<strong>把困难结构拆解为可重复的简单步骤</strong>。</span>

## 1 不显含 $y$ 的方程：$y'' = f(x, y')$

形如 $y'' = f(x, y')$ 的方程**不显含未知函数 $y$**。解法：令 $p = y'$，则 $y'' = p'$，方程降为一阶

$$p' = f(x, p)$$

解出 $p = \varphi(x, C_1)$ 后，再积分一次得 $y = \int \varphi(x, C_1)\,dx + C_2$。<span class="marginnote">降阶的机理：方程里没有 $y$ 本身，只有 $y'$ 及其导数，所以「把 $y'$ 当成新的未知函数 $p$」后，整个方程变成了关于 $p$ 的一阶方程。一次换元，阶数减一——这是「缺什么就把什么当变量」的典型操作。</span>

例：$y'' = 2x$。令 $p = y'$，$p' = 2x$，积分得 $p = x^2 + C_1$，再积分得 $y = \frac{x^3}{3} + C_1x + C_2$。

## 2 不显含 $x$ 的方程：$y'' = f(y, y')$

形如 $y'' = f(y, y')$ 的方程**不显含自变量 $x$**。解法不同：令 $p = y'$，但此时把 $y$ 当作新的自变量，由链式法则

$$y'' = \frac{dp}{dx} = \frac{dp}{dy}\cdot\frac{dy}{dx} = p\frac{dp}{dy}$$

方程化为关于 $p$ 与 $y$ 的一阶方程

$$p\frac{dp}{dy} = f(y, p)$$

解出 $p = \varphi(y, C_1)$ 后，再由 $\frac{dy}{dx} = \varphi(y, C_1)$ 分离变量解出 $y$。<span class="marginnote">这一型的关键是「换自变量」：因为方程不含 $x$，把 $y$ 升格为新自变量，$y''$ 用 $p\frac{dp}{dy}$ 表示——这是「链式法则」在换元中的再次大显身手。$y'' = p\frac{dp}{dy}$ 这个改写是整个降阶法的枢纽，务必记牢它的推导：$p$ 是 $x$ 的函数、$y$ 也是 $x$ 的函数，$dp/dx = (dp/dy)(dy/dx)$。</span>

例：$y'' + (y')^2 = 0$。令 $p = y'$，$y'' = p\frac{dp}{dy}$，得 $p\frac{dp}{dy} + p^2 = 0$。若 $p\neq0$：$\frac{dp}{dy} = -p$，分离积分 $\ln|p| = -y + C_1$，$p = C_1e^{-y}$。再由 $\frac{dy}{dx} = C_1e^{-y}$，分离积分 $e^y = C_1x + C_2$，得 $y = \ln(C_1x + C_2)$。

## 3 其他可降阶类型

除上述两大型外，还有几类降阶技巧：

**$y'' = f(y)$**（不含 $x$ 也不含 $y'$）：可用 $y'' = p\frac{dp}{dy}$，或两边乘 $y'$ 后用「能量法」（对物理问题尤其有效）。
**$y'' = f(x)$**：直接积两次分。
**缺 $y$ 的高阶**：$y^{(n)} = f(x, y^{(n-1)}, \ldots)$ 不显含 $y$ 及更低阶导数时，令 $p = y^{(n-1)}$ 逐阶降。
**对 $x,y$ 齐次的方程**：可令 $u = y/x$ 或 $v = y'$ 降阶。

**辨析｜易错点：** 两大型的区别要抓牢——**缺 $y$ 用「$p=y'$ 视 $x$ 为变量」，缺 $x$ 用「$p=y'$ 视 $y$ 为变量」**。前者换元后是一阶标准方程，后者换元后把 $y''$ 改写成 $p\frac{dp}{dy}$。把两型混淆、或用错换元，是这类题的主要失分点。<span class="marginnote">记忆锚：<strong>缺谁，谁就不当主角</strong>。缺 $y$——$y$ 不再出现，$p=y'$ 当主角，对 $x$ 积；缺 $x$——$x$ 不再出现，$y$ 升格当自变量，$y'' = p\frac{dp}{dy}$。抓住「谁被消掉、谁当变量」，就不会乱。</span>

## 4 公式解析：缺 $x$ 型的完整求解

求解 $y'' = (y')^2$，初值 $y(0)=1$、$y'(0)=2$：

**第一步，识别类型**：方程不含 $x$，属缺 $x$ 型。
**第二步，换元改写**：令 $p = y'$，$y'' = p\frac{dp}{dy}$，方程化为 $p\frac{dp}{dy} = p^2$。
**第三步，分离积分**：$p\neq0$ 时 $\frac{dp}{p} = dy$，积分 $\ln|p| = y + C_1$，故 $p = C_1e^y$。
**第四步，用初值定 $C_1$**：$y=1$ 时 $p=2$，得 $2 = C_1e$，$C_1 = \frac{2}{e}$。
**第五步，再积分**：$\frac{dy}{dx} = \frac{2}{e}e^y$，分离 $\int e^{-y}dy = \int\frac{2}{e}dx$，$-e^{-y} = \frac{2}{e}x + C_2$。
**第六步，定 $C_2$**：$x=0$ 时 $y=1$，$-e^{-1} = C_2$。解得 $e^{-y} = \frac{2}{e}x + \frac{1}{e}$，即 $y = -\ln\left(\frac{2x+1}{e}\right)$。

**关键**：缺 $x$ 型要经历「两次积分 + 两次定常数」——第一次定的是 $p$ 表达式里的常数，第二次定的是 $y$ 表达式里的常数。初值条件分别在对应阶段使用，顺序不能乱。

## 5 降阶思想的应用与延伸

降阶不只是三类方程的技巧，它有着更广的意义：

**数值方法的源头**：任何高阶常微分方程都可以通过引入新变量改写成一阶方程组——令 $y_1 = y$、$y_2 = y'$，则二阶方程 $y'' = f(x,y,y')$ 化为 $\begin{cases}y_1' = y_2\\ y_2' = f(x,y_1,y_2)\end{cases}$。<span class="marginnote">这个「高阶化一阶方程组」的操作是数值求解的关键：欧拉法、龙格-库塔法等标准数值方法都为一阶方程组设计，高阶方程先降阶再数值求解。到第九级《数值分析》你会看到所有 ODE 数值算法都建立在这个降阶之上。</span>
- **物理直觉**：缺 $x$ 型方程常对应「不含时间」的物理系统（能量守恒型），$p\frac{dp}{dy}$ 改写与「用位移做变量」的能量法一致。
- **控制理论**：状态空间表示把高阶系统写成一组一阶微分方程——正是降阶思想的工程化。
- **机器学习**：神经 ODE、残差网络的时间离散化，处理的都是一阶方程组形式——高阶系统先降阶再离散。

## 7 数值算例：缺 $y$ 型的完整求解

求 $y'' = \frac{y'}{x} + x$（$x>0$）的通解。

**第一步，识别类型**：方程含 $y'$、不含 $y$，缺 $y$ 型。令 $p = y'$，$p' = y''$。
**第二步，化一阶方程**：$p' = \frac{p}{x} + x$，即 $p' - \frac{p}{x} = x$——一阶线性方程。
**第三步，积分因子法**：积分因子 $\mu = e^{\int -\frac1x dx} = \frac1x$，得 $\left(\frac{p}{x}\right)' = 1$，积分 $\frac{p}{x} = x + C_1$，$p = x^2 + C_1x$。
**第四步，再积分**：$y = \int(x^2 + C_1x)dx = \frac{x^3}{3} + \frac{C_1}{2}x^2 + C_2$。

**关键**：缺 $y$ 型降阶后可能得到一阶线性方程（而非只是可分离）——降阶到「已经会解」的任何一阶类型都算成功。<span class="marginnote">降阶的通用口号：<strong>「只要降成一阶，就赢了」</strong>——因为一阶方程我们已经会解（可分离、齐次、线性）。降阶不是目的，把方程送回「已知解法库」才是目的。这正是算法设计里「递归到平凡情形」的思路。</span>

## 8 对照表：两类可降阶方程

| 特征 | 缺 $y$ 型 | 缺 $x$ 型 |
| --- | --- | --- |
| 方程形式 | $y'' = f(x, y')$ | $y'' = f(y, y')$ |
| 换元 | $p = y'$ | $p = y'$ |
| $y''$ 改写 | $p'$ | $p\frac{dp}{dy}$ |
| 自变量 | 仍为 $x$ | 换成 $y$ |
| 记忆 | 缺 $y$，$y$ 不当主角 | 缺 $x$，$y$ 升格 |

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 缺 $x$ 型把 $y''$ 写成 $p'$ | 用 $y'' = p\frac{dp}{dy}$，$y$ 当自变量 |
| 两型换元混淆 | 缺 $y$ 对 $x$ 积、缺 $x$ 对 $y$ 积 |
| 漏掉 $p=0$ 的解 | 分离时 $p=0$ 常被排除，需单独检查 |
| 初值顺序颠倒 | 先定 $p$ 的常数再定 $y$ 的常数 |

## 10 从降阶到高阶理论

降阶是理解高阶方程的「前传」：

- **高阶线性方程**（下一节）：用特征方程、通解结构直接处理，不再逐阶降——但降阶思想仍是理解「解含 $n$ 个常数」的直觉来源；
- **数值方法**：任何高阶方程都先化为一阶方程组再离散求解——降阶是数值计算的前置步骤；
- **状态空间**：控制理论把高阶系统写成一组一阶方程——工程化的降阶。

「把高阶拆成连续的一阶步骤」这一策略，贯穿微分方程的解析解与数值解两大路线。

## 11 小结

- **缺 $y$ 型** $y''=f(x,y')$：令 $p=y'$，对 $x$ 积分两次。
- **缺 $x$ 型** $y''=f(y,y')$：令 $p=y'$，用 $y''=p\frac{dp}{dy}$，把 $y$ 当自变量。
- 两型差异：**缺 $y$ 视 $x$ 为变量，缺 $x$ 视 $y$ 为变量**。
- 降阶可能落到一阶线性等任何已知类型——「降成一阶就赢了」。
- 初值条件分段使用：先定 $p$ 的常数，再定 $y$ 的常数。
- 降阶思想是数值方法「高阶化一阶方程组」的理论源头。
