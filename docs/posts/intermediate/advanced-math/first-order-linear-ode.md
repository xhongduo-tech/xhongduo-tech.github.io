## 为什么从一阶线性微分方程开始

可分离与齐次之外，还有一大类一阶方程无法用分离解决：**右端同时含「$y$ 的一次项」与「$x$ 的任意函数」**，如 $y' + 2xy = x$。这类**一阶线性方程**虽然不能直接分离，却有一个优美且通用的解法——**积分因子法**：乘上一个精心选择的因子，让方程左边恰好成为一个「乘积的导数」，然后两边积分即解。积分因子法是一阶方程求解理论的顶峰，也是「先解齐次、再求特解」这一通用策略的第一次登场——这个策略将贯穿整个高阶线性方程理论。<span class="marginnote">积分因子法的核心思想：<strong>制造「可积」的结构</strong>。方程 $y' + P(x)y = Q(x)$ 左边还不是某函数导数的形式，但乘上 $\mu(x)$ 后 $\mu y' + \mu P y = (\mu y)'$ 恰好成立——于是左边变成一个导数的完整体，积分一步到位。这与你学过的「凑微分」是同一招。</span>

## 1 一阶线性方程的标准形式

**一阶线性微分方程**的标准形式：

$$y' + P(x)\,y = Q(x)$$

其中 $P(x)$、$Q(x)$ 是已知函数。若 $Q(x) \equiv 0$，称**齐次一阶线性方程**；否则称**非齐次**。

- 齐次情形：$y' + P(x)y = 0$，即 $\frac{dy}{dx} = -P(x)y$——可分离，通解 $y = Ce^{-\int P(x)dx}$。
- 非齐次情形：$Q(x) \neq 0$，需要积分因子法。

**辨析｜易错点：** 使用公式前必须把方程化为标准形式——把 $y'$ 的系数化为 1。例如 $2y' + 4xy = 6x$ 要先除以 2 得 $y' + 2xy = 3x$，再套方法。$y'$ 系数不是 1 时直接套公式是高频错误。<span class="marginnote">「先标准化，再套工具」是微分方程求解的通用纪律：每个方法都对应一个标准形式，把方程化为标准形式是使用方法的先决条件。这与积分前先化简、线性代数里先化为阶梯形，是同一习惯。</span>

## 2 常数变易法与积分因子法

非齐次一阶线性方程 $y' + P(x)y = Q(x)$ 的求解有两条等价路径：

**路径一：积分因子法。** 乘积分因子 $\mu(x) = e^{\int P(x)\,dx}$，方程化为

$$\left(e^{\int Pdx} y\right)' = e^{\int Pdx} Q(x)$$

两边积分即得通解。关键验证：$(\mu y)' = \mu y' + \mu' y$，而 $\mu' = \mu P$（因为 $\mu = e^{\int Pdx}$），所以 $(\mu y)' = \mu(y' + Py) = \mu Q$——**左边恰是一个导数的完整体**。

**路径二：常数变易法。** 先解齐次得 $y = Ce^{-\int Pdx}$，把常数 $C$ 变为函数 $u(x)$：设 $y = u(x)e^{-\int Pdx}$，代入原方程解出 $u' = Q(x)e^{\int Pdx}$，再积分。**「先解齐次、常数变易求特解」**。

两条路径殊途同归，通解公式为

$$y = e^{-\int P(x)\,dx}\left(\int Q(x) e^{\int P(x)\,dx}\,dx + C\right)$$

<span class="marginnote">记忆上，积分因子法更「一步到位」，常数变易法更「循序渐进」。但两者背后是同一个通解结构——<strong>齐次通解 + 特解</strong>：$y = Ce^{-\int Pdx} + e^{-\int Pdx}\int Qe^{\int Pdx}dx$。第一项是齐次通解（含 $C$），第二项是非齐次特解。这个「齐次通解 + 特解」的结构，就是高阶线性方程理论的核心模式。</span>

## 3 公式解析：用积分因子法求解 $y' + 2xy = 2x$

**第一步，认出标准形式**：$P(x) = 2x$，$Q(x) = 2x$。
**第二步，算积分因子**：$\mu = e^{\int 2x\,dx} = e^{x^2}$。
**第三步，乘因子**：$e^{x^2}y' + 2xe^{x^2}y = 2xe^{x^2}$，左边是 $(e^{x^2}y)'$。
**第四步，两边积分**：$e^{x^2}y = \int 2xe^{x^2}\,dx = e^{x^2} + C$。
**第五步，解出 $y$**：$y = 1 + Ce^{-x^2}$。

**关键体会**：乘积分因子后，方程左边「自动」凑成一个导数的完整体，积分后只需除以因子解出 $y$。整个过程几乎机械——选因子、乘、积、解。

## 4 应用：一阶线性方程的实际模型

一阶线性方程是「有输入的增长过程」的模型：

**RL 电路**：$L\frac{di}{dt} + Ri = E(t)$，标准化为 $\frac{di}{dt} + \frac{R}{L}i = \frac{E(t)}{L}$——一阶线性，积分因子 $e^{Rt/L}$，描述电流如何被外电压驱动。<span class="marginnote">RL 电路方程的解结构：$i = \frac{E}{R}(1 - e^{-Rt/L})$（恒定电压时）——电流按指数逼近稳态 $\frac{E}{R}$。这个「一阶系统的指数逼近」模式是控制系统里的标准响应，也是「时间常数 $\tau = \frac{L}{R}$」的来源。</span>
**混合问题**：盐水池的盐量 $Q'(t) + \frac{\text{流出速率}}{V}Q = (\text{流入浓度} \times \text{流入速率})$——一阶线性。
**连续复利与投资**：$A' = rA + d$（本金增长 + 持续存款）——一阶线性，解包含指数增长与特解。
**logistic 与外部驱动**：带捕捞项的人口模型 $P' = rP - h$ 也是一阶线性。

共同模式：**$\frac{dy}{dt} + (\text{衰减率})y = (\text{外部输入})$**——「自身的自然演化 + 外部驱动」，一阶线性方程就是这个模式的数学表述。

## 5 一阶方程求解全景

至此，一阶方程的主要类型已经齐了，可以画一张「解法地图」：

| 方程类型 | 识别特征 | 解法 |
| --- | --- | --- |
| 可分离 | 右端 = $g(x)h(y)$ | 直接分离积分 |
| 齐次 | 右端 = $f(y/x)$ | 换元 $u=y/x$ |
| 一阶线性 | $y' + P(x)y = Q(x)$ | 积分因子 $e^{\int Pdx}$ |
| 伯努利 | $y' + P(x)y = Q(x)y^n$ | 换元 $z = y^{1-n}$ 化为一阶线性 |

<span class="marginnote">这张地图的用武之地在工程与科学建模：识别「现象属于哪类方程」往往比求解本身更重要。而这张地图的下一站是二阶及高阶方程——那里将出现「特征方程」与「叠加原理」这些更强大的结构。到《常微分方程》专题，你会看到完整的一阶理论、存在唯一性定理与稳定性分析。</span>

## 7 数值算例：积分因子法的完整流程

求 $y' + y = e^{-x}$ 的通解。

**第一步，标准形式**：$P(x) = 1$，$Q(x) = e^{-x}$。
**第二步，积分因子**：$\mu = e^{\int 1\,dx} = e^x$。
**第三步，乘因子**：$e^x y' + e^x y = 1$，左边是 $(e^x y)'$。
**第四步，积分**：$e^x y = \int 1\,dx = x + C$。
**第五步，解出**：$y = e^{-x}(x + C) = xe^{-x} + Ce^{-x}$。

**要点**：五步全程机械——「标准形式 → 积分因子 → 乘 → 积 → 解」。注意通解 $xe^{-x} + Ce^{-x}$ 中第一项是特解、第二项是齐次通解，完美体现「齐次通解 + 特解」结构。<span class="marginnote">验证特解结构：$Q = e^{-x}$ 恰好是齐次解 $e^{-x}$ 的「共振」情形（$Q$ 含 $e^{-x}$），特解 $xe^{-x}$ 要乘 $x$——这与二阶常系数方程的共振现象同源。<strong>「右端是齐次解时特解乘 $x$」的规则在这里已初见端倪</strong>。</span>

## 8 对照表：积分因子法与常数变易法

| 积分因子法 | 常数变易法 |
| --- | --- |
| 乘 $\mu = e^{\int Pdx}$ 一步凑整 | 先解齐次，再把 $C$ 变易为函数 |
| 一步到位 | 循序渐进 |
| 适合直接套公式 | 思路更通用 |
| 结果相同 | 结果相同 |

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| $y'$ 系数不是 1 就套公式 | 先标准化，$y'$ 系数化为 1 |
| 积分因子忘 $e^{\int Pdx}$ 的形式 | $\mu$ 必须是指数积分 |
| 常数变易把 $u$ 当常数 | $u$ 是 $x$ 的函数，代入后解 $u'$ |
| 通解漏「齐次通解」项 | 通解 = 齐次通解 + 特解 |

## 10 一阶线性方程与系统理论

一阶线性方程是「一阶系统」的数学骨架：

- **RL 电路**：$i' + \frac{R}{L}i = \frac{E}{L}$——时间常数 $\tau = L/R$ 决定响应速度；
- **控制系统**：一阶惯性环节 $T\dot y + y = Ku$ 的标准传递函数；
- **连续复利**：$A' = rA + d$——本金增长 + 持续存款；
- **生态**：带捕捞项的 Logistic、资源消耗模型。

「自身的自然演化 + 外部驱动」是无数系统的共同结构——一阶线性方程就是这个结构的最小完备模型，而它的解模式（指数逼近稳态）贯穿整个控制与动力学。

## 11 小结

- **一阶线性方程**：$y' + P(x)y = Q(x)$；先标准化（$y'$ 系数化为 1）。
- **积分因子法**：乘 $\mu = e^{\int Pdx}$ 使左边成 $(\mu y)'$，两边积分即解。
- **常数变易法**：先解齐次，把常数变易为函数求特解。
- 通解 = **齐次通解 + 特解**，这是高阶线性方程理论的核心模式。
- 右端是齐次解时特解乘 $x$——共振规则的雏形。
- 应用：RL 电路、混合问题、连续复利——「自然演化 + 外部驱动」模型。
