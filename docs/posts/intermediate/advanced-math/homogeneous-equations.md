## 为什么从齐次方程开始

可分离变量方程是「右端能拆成 $g(x)h(y)$」；但很多方程右端是**比值结构**——只依赖于 $\frac{y}{x}$ 的比值，如 $\frac{dy}{dx} = \frac{x^2 + y^2}{xy}$。它们无法直接分离，却有一个优雅的解法：**换元**。令 $u = \frac{y}{x}$，把 $y$ 换成 $ux$，方程就会奇迹般地变成关于 $u$ 和 $x$ 的可分离方程。这种「齐次方程」是「换元法」在微分方程里的第一次应用——它教你的不是一类方程，而是一种「**通过变换揭示隐藏结构**」的思维方式。<span class="marginnote">齐次方程解法的精髓：<strong>结构识别 → 换元降维</strong>。看到「只依赖 $\frac{y}{x}$」这个结构特征，就自动联想到 $u=\frac{y}{x}$ 的换元。这与你在积分里「看到 $\sqrt{a^2-x^2}$ 就想到三角代换」是同一种模式匹配能力——数学技巧的本质是「结构 → 变换」的反射弧。</span>

## 1 齐次方程的定义

**齐次方程**：一阶方程如果能写成

$$\frac{dy}{dx} = f\left(\frac{y}{x}\right)$$

的形式，即右端只依赖比值 $\frac{y}{x}$，就称为齐次方程。这里的「齐次」指右端是「关于 $x,y$ 的零次齐次函数」——把 $x,y$ 同时放大 $t$ 倍，右端不变（如 $\frac{x^2+y^2}{xy}$ 中分子分母都是二次，比值不变）。

例：$\frac{dy}{dx} = \frac{x^2 + y^2}{xy}$。右端分子分母同时除以 $x^2$：$\frac{1 + (y/x)^2}{y/x} = \frac{1+u^2}{u}$——是 $f\left(\frac{y}{x}\right)$ 的形式，齐次方程。

**辨析｜易错点：** 这里「齐次」与高阶线性方程里「齐次」的含义不同——前者指「比值结构」（换元可解），后者指「右端为零」（见高阶线性微分方程一节）。两个「齐次」是两套语境，不要混淆。<span class="marginnote">「齐次」这个词本身的意思是「次数相同」：分子分母同次、或方程各项同次。把握「齐次 = 某种对称/均匀性」，就能在不同语境里正确理解它——比值型齐次（本章）、线性方程齐次项（第 37 节）、$n$ 次齐次函数（多元微分）。</span>

## 2 齐次方程的解法

**解法（换元到可分离）**：

1. **换元**：令 $u = \frac{y}{x}$，则 $y = ux$；
2. **改写导数**：$\frac{dy}{dx} = u + x\frac{du}{dx}$（对 $y=ux$ 两边关于 $x$ 求导）；
3. **代入**：原方程变为 $u + x\frac{du}{dx} = f(u)$；
4. **分离**：$x\frac{du}{dx} = f(u) - u$，即 $\frac{du}{f(u)-u} = \frac{dx}{x}$；
5. **积分回代**：两边积分，把 $u$ 换回 $\frac{y}{x}$。

关键步骤是第 2 步的 $u + x\frac{du}{dx}$——它来自乘积求导法则 $(ux)' = u + xu'$，是换元的「发动机」。<span class="marginnote">第 2 步的本质：$y$ 和 $u$ 都是 $x$ 的函数，对 $y=ux$ 求导必须用乘积法则——$y' = u + xu'$ 而不是 $y'=u'x$。漏掉 $u$ 项是齐次方程最经典的错误，务必把 $u$ 当成「带 $x$ 依赖的函数」而不是常数。</span>

## 3 公式解析：求解 $\frac{dy}{dx} = \frac{x^2 + y^2}{xy}$

- **第一步，识别齐次**：右端分子分母都是二次，化为 $f(u) = \frac{1+u^2}{u}$ 的形式，齐次方程。
- **第二步，换元**：令 $y = ux$，则 $y' = u + xu'$，代入得
  $$u + x\frac{du}{dx} = \frac{1+u^2}{u} = \frac{1}{u} + u$$
- **第三步，分离**：约去 $u$，$x\frac{du}{dx} = \frac{1}{u}$，即 $u\,du = \frac{dx}{x}$。
- **第四步，积分**：$\frac{u^2}{2} = \ln|x| + C$。
- **第五步，回代**：$u = \frac{y}{x}$，得 $\frac{y^2}{2x^2} = \ln|x| + C$，即 $y^2 = 2x^2(\ln|x| + C)$。

**关键**：换元后的可分离方程比原方程「友好」得多——$u$ 项恰好被约掉，剩下干净的可分离形式。回代时把 $u$ 换成 $\frac{y}{x}$ 是收尾的必经步骤，常以隐式解呈现。

## 4 可化为齐次的方程

有些方程不是齐次，但通过**平移**可以化为齐次。形如

$$\frac{dy}{dx} = \frac{a_1x + b_1y + c_1}{a_2x + b_2y + c_2}$$

当 $c_1, c_2$ 不全为 0 时，令 $x = X + h$、$y = Y + k$，选取 $h,k$ 使常数项抵消（解线性方程组 $\begin{cases}a_1h + b_1k + c_1 = 0\\a_2h + b_2k + c_2 = 0\end{cases}$），方程就化为齐次 $\frac{dY}{dX} = \frac{a_1X + b_1Y}{a_2X + b_2Y}$。<span class="marginnote">平移消常数的直觉：把坐标系「挪」到两条直线的交点处——交点处常数项归零，方程恢复齐次结构。这与解析几何里「平移坐标轴化简曲线方程」是同一操作，也是「先找对称中心再简化」的通用思想。</span>

若 $a_1b_2 = a_2b_1$（两直线平行），则比值型退化为 $\frac{dy}{dx} = g(a_1x+b_1y)$，可令 $u = a_1x + b_1y$ 直接化为可分离——另一条换元路。

## 5 齐次方程的应用与延伸

齐次方程在应用与理论上都有位置：

- **几何问题**：求「曲线上任一点处切线满足某种比值条件」的曲线族，常导出齐次方程。例如：曲线上每点的切线在 $x$ 轴上的截距是横坐标的一半——列出方程即齐次型。
- **经济模型**：某些增长模型与「资本-产出比」成比值关系时，化为齐次方程求解。
- **换元思想**：齐次方程教你「观察结构、选择换元」，这个能力直接迁移到下一节的一阶线性方程（积分因子）、伯努利方程（$y^{-n}$ 换元）与第九章的多元隐函数。<span class="marginnote">「换元」是微分方程求解最通用的武器：齐次方程换 $u=\frac yx$，伯努利方程换 $z=y^{1-n}$，欧拉方程换 $t=\ln x$……每一种换元都对应一个「识别到的结构」。学会「看结构选换元」，你就掌握了微分方程的解法地图。</span>
- **偏微分方程**：解偏微分方程的「特征线法」中，比值型的常微分方程系统（$\frac{dy}{dx} = \frac{Q}{P}$）同样是齐次方程，换元思想直接沿用。

## 6 小结

- **齐次方程**：$\frac{dy}{dx} = f\left(\frac{y}{x}\right)$，右端只依赖比值。
- **解法**：令 $y = ux$，用 $y' = u + xu'$ 代入，化为可分离方程 $\frac{du}{f(u)-u} = \frac{dx}{x}$，积分后回代。
- 关键是 $y' = u + xu'$（乘积求导），别漏 $u$ 项。
- 平移变换把 $\frac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2}$ 化为齐次。
- 「结构识别 → 换元」是微分方程求解的通用思想。
