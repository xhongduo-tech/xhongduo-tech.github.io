# 对面积的曲面积分

## 为什么从对面积的曲面积分开始

第一型曲线积分沿「线」累加，对面积的曲面积分沿「面」累加——把「面密度」乘「面积微元」在曲面 $\Sigma$ 上积分，得到曲面薄壳的总量（质量、电荷）。它与第一型曲线积分的地位平行：**不关心方向，只沿面积累加标量密度**。对面积的曲面积分是曲面积分的入门，也是理解「为什么需要面积微元 $dS$」「如何把 $dS$ 投影到坐标面」的关键。它在物理里描述曲面薄壳的质量与质心，也是下一节「对坐标的曲面积分」（有方向的通量）的前奏。<span class="marginnote">对面积曲面积分的直观：<strong>$\iint_\Sigma f(x,y,z)\,dS$ = 曲面薄壳上「面密度 $f$」的总量</strong>。$f$ 是「单位面积的质量」，$dS$ 是曲面面积微元，积分是「密度 × 面积」的累积。若 $f\equiv1$，$\iint_\Sigma dS$ 就是曲面面积——它与第八章「曲面及其方程」、第十章重积分都有关联。</span>

## 1 对面积曲面积分的定义

设曲面 $\Sigma$ 光滑，$f(x,y,z)$ 在 $\Sigma$ 上有界。将 $\Sigma$ 任意分成 $n$ 个小曲面 $\Delta S_i$（也表示面积），每块内任取 $(\xi_i,\eta_i,\zeta_i)$，作和 $\sum f(\xi_i,\eta_i,\zeta_i)\Delta S_i$。若 $\lambda\to0$ 时极限存在且与分割、取点无关，则称该极限为 $f$ 在 $\Sigma$ 上**对面积的曲面积分**：

$$\iint_\Sigma f(x,y,z)\,dS = \lim_{\lambda\to0}\sum_{i=1}^{n}f(\xi_i,\eta_i,\zeta_i)\,\Delta S_i$$

**性质**：线性性；**与曲面侧无关**（$dS$ 恒正，第一型积分）；分段可加性。<span class="marginnote">与第一型曲线积分完全平行：<strong>第一型「只认面积、不认方向」</strong>——曲面的质量与「从哪面看」无关。这与下一节「对坐标的曲面积分」的方向敏感形成对比。曲面 $dS$ 是标量微元（面积），没有「正负侧」。</span>

## 2 对面积曲面积分的计算

设曲面 $\Sigma$ 由 $z = z(x,y)$ 给出，$D$ 是 $\Sigma$ 在 $xOy$ 面上的投影区域，$z(x,y)$ 有连续偏导数，则面积微元

$$dS = \sqrt{1 + z_x^2 + z_y^2}\,dx\,dy$$

$$\iint_\Sigma f(x,y,z)\,dS = \iint_D f(x,y,z(x,y))\,\sqrt{1 + z_x^2 + z_y^2}\,dx\,dy$$

**公式解析：面积微元 $dS$ 的投影公式**

$$dS = \sqrt{1 + z_x^2 + z_y^2}\,dx\,dy$$

- **第一步，回顾一维**：曲线弧长微元 $ds = \sqrt{1+y'^2}\,dx$——「曲线的斜率贡献」。
- **第二步，升维**：曲面微元 $dS$ 是「由 $dx,dy$ 张成的切平面小片」，其法向量 $\mathbf{n} = (-z_x, -z_y, 1)$。
- **第三步，求面积**：切平面小片的面积 = 底面积 $dx\,dy$ ÷ 法向量与 $z$ 轴夹角余弦的绝对值 $|\cos\gamma|$，而 $|\cos\gamma| = \frac{1}{\sqrt{1+z_x^2+z_y^2}}$，故 $dS = \frac{dx\,dy}{|\cos\gamma|} = \sqrt{1+z_x^2+z_y^2}\,dx\,dy$。

**关键**：$dS$ 比 $dx\,dy$ 大 $\sqrt{1+z_x^2+z_y^2}$ 倍——**曲面「斜」的程度越高（$z_x,z_y$ 越大），同样投影面积对应的曲面面积越大**。这是「倾斜放大」因子的又一生动实例（与极坐标的 $r$ 并列）。

## 3 公式解析：球壳质量

求面密度 $\rho = z$ 的上半球面 $z = \sqrt{a^2 - x^2 - y^2}$ 的质量：

- **第一步，算偏导**：$z_x = -\frac{x}{z}$、$z_y = -\frac{y}{z}$，故 $1+z_x^2+z_y^2 = 1 + \frac{x^2+y^2}{z^2} = \frac{a^2}{z^2}$。
- **第二步，写 $dS$**：$dS = \frac{a}{z}\,dx\,dy$（投影区域是圆盘 $x^2+y^2\le a^2$）。
- **第三步，代被积函数**：$\rho = z$，$\iint_\Sigma z\,dS = \iint_D z\cdot\frac{a}{z}\,dx\,dy = a\iint_D dx\,dy = a\cdot\pi a^2 = \pi a^3$。
- **第四步，几何检查**：上半球质量 $= \pi a^3$；球面面积 $= 4\pi a^2$、平均密度 $\frac{a}{2}$，质量 $= 2\pi a^2\cdot\frac{a}{2} = \pi a^3$，一致。

**关键**：球面的 $dS = \frac{a}{z}dx\,dy$ 巧妙地与 $\rho=z$ 中的 $z$ 相消——这是对称性的「红利」。本题展示了「**偏导 → $dS$ → 代被积函数 → 投影区域积分**」的完整流程。

## 4 对面积曲面积分的应用

- **曲面面积**：$S = \iint_\Sigma dS = \iint_D \sqrt{1+z_x^2+z_y^2}\,dx\,dy$——曲面面积的通用公式。
- **曲面薄壳的质量**：$M = \iint_\Sigma \rho\,dS$——不均匀面密度。
- **质心与转动惯量**：$\bar x = \frac{1}{M}\iint x\rho\,dS$、$I_z = \iint(x^2+y^2)\rho\,dS$ 等。
- **空间曲面**：$x=x(y,z)$ 或 $y=y(x,z)$ 形式时，用对应坐标面的投影公式。

<span class="marginnote">这些应用与「密度 × 微元」模板完全一致，微元换成了曲面面积 $dS$。<strong>对面积的曲面积分 = 「沿曲面的元素法」</strong>——从一维 $dx$ 到二维 $d\sigma$ 到三维 $dV$ 再到曲面 $dS$，「密度 × 微元」的思想贯穿全部积分学。到《数学物理方程》，曲面积分是位势理论与边界条件的语言。</span>

## 5 对面积 vs 对坐标：曲面积分的两型

与曲线积分一样，曲面积分也分两型：

| | 对面积（第一型） | 对坐标（第二型，下一节） |
| --- | --- | --- |
| 记号 | $\iint_\Sigma f\,dS$ | $\iint_\Sigma P\,dy\,dz + Q\,dz\,dx + R\,dx\,dy$ |
| 微元 | 面积 $dS$（标量） | 有向投影面积（带方向） |
| 与曲面侧的关系 | 无关 | 反向变号 |
| 物理意义 | 曲面薄壳质量 | 向量场穿过曲面的通量 |

<span class="marginnote">记忆锚：<strong>「面积不看侧，坐标看侧」</strong>——与曲线积分的「弧长不看方向，坐标看方向」完全平行。第一型量「总量」，第二型量「流量」。下一节对坐标的曲面积分（通量）才是「向量场穿过曲面」的正确表述，也是高斯公式（第 68 节）的载体。</span>

## 6 小结

- **对面积的曲面积分**：$\iint_\Sigma f\,dS$，沿曲面累加「面密度」。
- 与曲面侧无关（$dS$ 恒正）；线性、分段可加。
- 计算：$z=z(x,y)$ 时 $dS = \sqrt{1+z_x^2+z_y^2}\,dx\,dy$，投影到 $xOy$ 面。
- $dS$ 是「倾斜放大」因子：曲面越斜，同样投影面积对应越大曲面面积。
- 应用：曲面面积、薄壳质量、质心、转动惯量——「沿曲面的元素法」。
