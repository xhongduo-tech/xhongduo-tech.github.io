## 为什么从常系数非齐次线性微分方程开始

上一节的齐次方程描述「没有外力」的系统：自由振荡、自然衰减。但真实系统总有**外部驱动**——电路接上电源、弹簧被周期力推拉、系统被噪声扰动。这些「带右端项」的方程就是**非齐次**的。上一节已立下通解结构：**齐次通解 + 特解**。齐次通解上一节已经会求，本节只差一件事——**求一个特解**。对常系数方程，当右端是「多项式 × 指数 × 三角」这类特殊函数时，有高效的**待定系数法**（猜解 + 定系数）；右端任意时则用**常数变易法**兜底。这一节把「解非齐次方程」变成一件近乎机械的工作。<span class="marginnote">非齐次项的物理含义是「外部输入」，特解是「受迫响应」，齐次通解是「自由振动」。物理学的深刻洞见——<strong>系统的总响应 = 自由响应 + 受迫响应</strong>——正是通解结构定理的物理化身。共振现象（受迫频率 = 固有频率时振幅爆炸）就藏在特解的形式里。</span>

## 1 待定系数法：右端为 $e^{\lambda x}P_m(x)$ 型

若 $f(x) = e^{\lambda x} P_m(x)$（$P_m$ 是 $m$ 次多项式），则特解可设为

$$y^* = x^k Q_m(x) e^{\lambda x}$$

其中 $Q_m$ 是 $m$ 次多项式（系数待定），$k$ 是 $\lambda$ 作为特征根的重数：**若 $\lambda$ 不是特征根，$k=0$；是单根，$k=1$；是二重根，$k=2$**。

例：$y'' - 3y' + 2y = e^{3x}$。特征根 $r=1,2$，$\lambda=3$ 不是特征根，故设 $y^* = Ae^{3x}$。代入：$9Ae^{3x} - 9Ae^{3x} + 2Ae^{3x} = 2Ae^{3x} = e^{3x}$，得 $A = \frac12$，特解 $y^* = \frac12 e^{3x}$。

**辨析｜易错点：** $k$ 的选取是待定系数法的灵魂——**右端的指数 $\lambda$ 如果恰好是特征根，必须乘 $x^k$（$k$ = 重数）**，否则代入后左边会出现「共振」无法匹配。例如 $y'' - 2y' + y = e^{x}$，特征根 $r=1$ 是二重根，必须设 $y^* = Ax^2e^x$。<span class="marginnote">为什么必须乘 $x^k$？因为若 $\lambda$ 是特征根，$e^{\lambda x}$ 本身就是齐次解，代入后左边为 0，无法产生 $e^{\lambda x}$ 项；乘 $x$ 或 $x^2$ 后「踢开」一个自由度，才能配出非零右端。这正是物理共振的数学镜像——驱动力频率撞上固有频率，普通的「猜解」失效，必须升级猜测。</span>

## 2 右端为 $e^{\lambda x}[P_m(x)\cos\beta x + Q_n(x)\sin\beta x]$ 型

若右端含 $\cos\beta x$ 与 $\sin\beta x$，特解设为

$$y^* = x^k e^{\lambda x}\left[R_l(x)\cos\beta x + S_l(x)\sin\beta x\right]$$

其中 $l = \max\{m, n\}$，$R_l, S_l$ 是 $l$ 次多项式，$k$ 是 $\lambda + i\beta$ 作为特征根的次数（不是则 $k=0$）。

**核心思想：三角函数的出现，来自复特征根 $\lambda \pm i\beta$。** 若右端频率与固有频率重合（$\lambda+i\beta$ 是特征根），就会发生**共振**，必须乘 $x$。<span class="marginnote">复根与三角函数的连接：$e^{(\alpha+i\beta)x}$ 的实部与虚部是 $e^{\alpha x}\cos\beta x$ 与 $e^{\alpha x}\sin\beta x$（欧拉公式）。所以「三角型右端」在复数世界里就是「指数型右端」——用欧拉公式统一处理。到《复变函数与积分变换》，这个「三角函数 ↔ 复指数」的翻译会让你更熟练。</span>

## 3 叠加原理求特解

非齐次方程的右端若是多项之和 $f = f_1 + f_2$，则

分别求 $y'' + py' + qy = f_1$ 的特解 $y_1^*$ 与 $= f_2$ 的特解 $y_2^*$；
则 $y^* = y_1^* + y_2^*$ 是原方程的特解（叠加原理）。

例：$y'' + y = x + \sin x$。拆成两个方程：$y''+y=x$ 的特解 $y_1^* = x$；$y''+y=\sin x$ 中 $\lambda+i\beta = i$ 恰是特征根（共振），设 $y_2^* = x(A\cos x + B\sin x)$，代入解得 $A = -\frac12$、$B = 0$，故 $y_2^* = -\frac{x}{2}\cos x$。特解 $y^* = x - \frac{x}{2}\cos x$，通解 $y = C_1\cos x + C_2\sin x + x - \frac{x}{2}\cos x$。<span class="marginnote">「拆右端、分头求特解、再加起来」是叠加原理的直接运用——线性系统的「分而治之」。这与你学过的「逐项积分」（线性性）是同一条线：<strong>线性运算可以对输入分解再重组</strong>。控制系统里「分别求每个输入的响应再加总」正是同一原理。</span>

## 4 公式解析：待定系数法的完整流程

求 $y'' - 2y' - 3y = 3e^{2x}$ 的通解：

**第一步，解齐次**：特征方程 $r^2 - 2r - 3 = (r-3)(r+1)=0$，根 $r=3, -1$。齐次通解 $Y = C_1e^{3x} + C_2e^{-x}$。
**第二步，选特解形式**：$\lambda = 2$ 不是特征根，设 $y^* = Ae^{2x}$。
**第三步，代入定系数**：$y^{*\prime}=2Ae^{2x}$，$y^{*\prime\prime}=4Ae^{2x}$，代入得 $4A - 4A - 3A = -3A = 3$，$A = -1$。
**第四步，组合通解**：$y = Y + y^* = C_1e^{3x} + C_2e^{-x} - e^{2x}$。

**关键**：非齐次方程求解永远「两步走」——**先齐次通解，再特解**。待定系数法的「待定」就是设出含未知系数的特解形式，代入方程把系数解出来。

## 5 待定系数法与常数变易法的分工

| 方法 | 适用右端 | 成本 | 可靠性 |
| --- | --- | --- | --- |
| 待定系数法 | 多项式 × 指数 × 三角 | 低（解代数方程） | 高，但只对特殊 $f$ |
| 常数变易法 | 任意 $f(x)$ | 高（两次积分） | 万金油，总能用 |

<span class="marginnote">工程中的选择：右端是常见激励（阶跃、正弦、多项式）用待定系数法；右端是任意噪声或复杂函数用常数变易法。<strong>待定系数法「快而挑食」，常数变易法「慢而不挑」</strong>——这个权衡模式在数值方法里同样常见（专用快速算法 vs 通用稳健算法）。</span>

常数变易法也适用常系数方程：设 $y^* = u_1(x)y_1 + u_2(x)y_2$，解方程组再积分——它不需要「猜」特解形式，是真正的兜底方案。许多教材用「算子法」（把 $y^{(k)}$ 写成 $D^k$，用微分算子运算）也能统一处理，但待定系数法的直觉最直接。

## 7 数值算例：共振情形的完整流程

求 $y'' + 4y = \sin 2x$ 的特解。

**第一步，看特征根**：$r^2 + 4 = 0$，$r = \pm 2i$。
**第二步，判断共振**：右端对应 $\lambda + i\beta = 0 + 2i = 2i$，恰是特征根——**必须设** $y^* = x(A\cos 2x + B\sin 2x)$，普通设 $A\cos2x + B\sin2x$ 会失效（它是齐次解，代入左边得 0）。
**第三步，代入定系数**：计算 $y^{*\prime\prime} + 4y^* = -4A\sin 2x + 4B\cos 2x$（含 $x$ 的项全部抵消），令其 $= \sin 2x$，得 $A = -\frac14$，$B = 0$。
**第四步，写通解**：$y = C_1\cos 2x + C_2\sin 2x - \frac{x}{4}\cos 2x$。

**关键**：共振时特解带「增长因子 $x$」，振幅随 $x$ 线性放大——这正是物理共振的数学镜像。<span class="marginnote">为什么共振的答案「长得不一样」？因为普通猜测 $\cos2x,\sin2x$ 本身就是齐次解，代入非齐次方程左边恒为 0，永远配不出 $\sin2x$。乘上 $x$ 后，$x\cos2x$ 不再是齐次解，「自由度」被踢开，系数才能配出来。<strong>特解形式被齐次解「堵路」，必须升一级猜测</strong>——这是待定系数法里最本质的一条规则。</span>

## 8 对照表：待定系数法与常数变易法

| 待定系数法 | 常数变易法 |
| --- | --- |
| 仅适用特殊右端（多项式 × 指数 × 三角） | 适用任意右端 $f(x)$ |
| 设出特解形式、代入定系数 | 设 $y^* = u_1(x)y_1 + u_2(x)y_2$，解方程组再积分 |
| 计算量小（解代数方程） | 计算量大（两次积分） |
| 快而挑食 | 慢而不挑 |

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 右端指数是特征根时不乘 $x^k$ | $\lambda$ 是 $k$ 重特征根，特解必乘 $x^k$ |
| 三角型右端只设 $\cos$ 或只设 $\sin$ | $R_l\cos\beta x + S_l\sin\beta x$ 必须成对设 |
| 混淆「普通」与「共振」 | 只有 $\lambda+i\beta$ 是特征根时才乘 $x$ |
| 设出的特解与齐次解重复 | 排除与齐次通解形式相同的项 |

## 10 共振：乘 $x$ 的物理必然

共振不是数学怪癖，而是真实世界的普遍现象：秋千按固有频率推越荡越高、桥梁遇风的自激振荡、电路在谐振频率的响应峰值。当驱动力频率撞上系统固有频率，普通的「受迫响应」失效，振幅随时间**线性增长**——特解里的因子 $x$ 正是这段「线性增长」的数学表达。

1940 年塔科马海峡大桥在风中因共振坍塌，是现代工程史上最著名的共振案例之一。工程上处理共振靠阻尼（让特征根有负实部）、调频（避开共振频率）或限幅。你在这里学的「共振须乘 $x^k$」，是理解这些工程对策的数学起点，也是《常微分方程》《振动理论》里稳态响应的第一课。

## 11 小结

- **非齐次方程通解** = 齐次通解 + 一个特解。
- **待定系数法**：右端 $e^{\lambda x}P_m(x)$ 型，设 $y^* = x^k Q_m(x)e^{\lambda x}$，$k$ = $\lambda$ 的特征根重数。
- 三角型右端：用欧拉公式连接复特征根，共振时乘 $x^k$。
- **共振判据**：$\lambda + i\beta$ 是特征根 ⇒ 特解乘 $x$，振幅线性增长。
- **叠加原理**：右端拆成和，分别求特解再相加。
- 待定系数法「快而挑食」，常数变易法「慢而不挑」，按右端选择。
- 共振的工程对策（阻尼、调频、限幅）都以「乘 $x^k$」这一数学事实为起点。
- 特解形式一旦与齐次解「撞车」，就升一级猜测——这是待定系数法的灵魂规则。
