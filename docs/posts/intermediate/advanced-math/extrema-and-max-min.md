## 为什么从极值与最值开始

上一节的单调性告诉我们曲线「何时爬、何时降」；峰与谷——**极值**——就出现在升降的转折处。而比极值更实际的问题是**最值**：做蛋糕用多少纸最省？工厂怎样定价利润最大？训练神经网络怎样让损失最小？这些「最优化」问题的雏形，正是本节。极值是「局部」概念（邻域内的最高/最低），最值是「整体」概念（整个区间上的最高/最低），两者的求法与关系必须分得清清楚楚。这一节是整个微积分中「工程味道」最浓的一节——它教你如何把真实世界的权衡写成函数，再用导数把它解出来。<span class="marginnote">「求导找极值」是现代科学的第一优化工具，从经济学（边际成本 = 边际收益）到物理（能量最低原理）再到机器学习（梯度为零处损失最小）。梯度下降算法本质上就是在数值地执行本节的思想：沿着导数指向的下坡方向走，直到导数为零。</span>

## 1 极值的定义与必要条件

**极值（local extremum）**：设 $f$ 在 $x_0$ 的某邻域内有定义，若该邻域内恒有 $f(x) \le f(x_0)$，则称 $f(x_0)$ 为**极大值**，$x_0$ 为**极大值点**；若恒有 $f(x) \ge f(x_0)$，则称**极小值**与**极小值点**。极大值与极小值统称**极值**。

**费马引理**：若 $f$ 在 $x_0$ 处可导且取得极值，则 $f'(x_0) = 0$。<span class="marginnote">费马引理的几何直觉：峰顶或谷底的切线必定水平——否则沿切线方向还有上升或下降的空间，就不可能是极值。它是「可导极值点必为驻点」的严格表述，也是整个最优化理论的出发点。注意它只说「可导的极值点」，不可导点也可能是极值点，如 $|x|$ 在 0 处。</span>

**驻点（stationary point）**：$f'(x)=0$ 的点。**极值点 ⇒ 驻点或不可导点，但驻点不一定极值点。** $f(x)=x^3$ 在 0 处 $f'=0$ 却是拐点而非极值——$x^3$ 在 0 两侧同号。所以找到驻点只是第一步，还要**判别**。

## 2 极值的第一充分条件

**第一充分条件（用 $f'$ 变号）**：设 $f$ 在 $x_0$ 处连续，在 $x_0$ 的去心邻域内可导。

若 $x$ 从 $x_0$ 左侧到右侧，$f'$ 由正变负，则 $x_0$ 是**极大值点**；
若 $f'$ 由负变正，则 $x_0$ 是**极小值点**；
若 $f'$ 不变号，则 $x_0$ 不是极值点。

直觉：导数从正到负意味着曲线「先升后降」，经过一个峰；从负到正意味着「先降后升」，经过一个谷；符号不变则只是经过一个「平台」般的驻点。<span class="marginnote">第一充分条件需要的条件很宽松——$f$ 在 $x_0$ 处连续即可，不要求可导。这使它也能处理不可导的极值点（如 $f(x)=|x|$ 在 0 处：左导负、右导正，是极小值）。它是极值判别的「通用款」。</span>

## 3 极值的第二充分条件

**第二充分条件（用 $f''$ 符号）**：设 $f'(x_0) = 0$ 且 $f''(x_0)$ 存在。

若 $f''(x_0) < 0$，则 $x_0$ 是**极大值点**；
若 $f''(x_0) > 0$，则 $x_0$ 是**极小值点**。

直觉来自泰勒展开：$f(x) \approx f(x_0) + \frac{f''(x_0)}{2}(x-x_0)^2$，二阶项符号决定抛物线开口方向——$f''>0$ 开口向上（谷），$f''<0$ 开口向下（峰）。

**辨析｜易错点：** ① 第二充分条件要求 $f''(x_0)\neq0$；若 $f''(x_0)=0$，**方法失效**，必须回到第一充分条件。例如 $f(x)=x^4$ 在 0 处 $f'=f''=0$，但由第一充分条件知是极小值。② 两种方法的分工：$f''$ 容易算且不为 0 时用第二充分条件（一步出结果），否则用第一充分条件（看 $f'$ 变号）。

## 4 闭区间上的最大值与最小值

**求 $f$ 在 $[a,b]$ 上的最大最小值**：由最值定理，闭区间上连续函数必有最值。最值只能在**驻点、不可导点、端点**三类候选点中取得。流程：

1. 求 $f$ 在 $(a,b)$ 内的驻点与不可导点；
2. 计算 $f$ 在这些点与端点 $a,b$ 处的函数值；
3. 比较大小，最大的为最大值，最小的为最小值。

例：$f(x) = x^3 - 3x$ 在 $[0, 3]$ 上。驻点 $x=1$（$x=-1$ 不在区间内），计算 $f(0)=0$、$f(1)=-2$、$f(3)=18$，比较得最小值 $-2$（在 $x=1$ 处）、最大值 $18$（在 $x=3$ 处）。<span class="marginnote">注意：本例的最大值取在<strong>端点</strong>，而不是极值点。这提醒我们——<strong>最值候选点必须包含端点</strong>。闭区间的最值与开区间内的极值是两套概念：极值只在内部点取得，最值可能在端点。漏掉端点是最值问题的头号失分点。</span>

**辨析｜易错点：** 区间上的最大（小）值若在内部取得，则它一定是极值，从而可由驻点/不可导点捕获；但若在端点取得，则与极值无关。比较候选点函数值时，**必须逐一列出所有候选点**，不能只比较驻点。

## 5 最值应用问题：把现实写成分数

实际问题求最值的标准四步：**建模 → 求导 → 求驻点 → 判别并回答**。

经典问题：用一面墙和一段总长 $L$ 的篱笆围一个矩形菜园，怎样围面积最大？设垂直于墙的边长为 $x$，平行于墙的边长为 $L-2x$，面积

$$S(x) = x(L - 2x), \qquad 0 < x < \frac{L}{2}$$

求导 $S'(x) = L - 4x$，令为 0 得 $x = \frac{L}{4}$。此时 $S'' = -4 < 0$，是极大值；且区间两端 $S\to 0$，故该极大值即最大值——**正方形式的最优形状**（$\frac{L}{2}$ 与 $2\cdot\frac{L}{4}$ 形成半正方形）。

**公式解析：为什么 $x=L/4$ 是最大**

$$S(x) = x(L - 2x)$$

- **第一步，读建模**：$x$ 是垂直边，$L-2x$ 是平行边（总长 $L$ 减去两条垂直边），面积 = 两边乘积。定义域 $0<x<L/2$ 保证边长为正。
- **第二步，求驻点**：$S'(x)=L-4x=0 \Rightarrow x=L/4$，唯一驻点。
- **第三步，判别**：$S''(x)=-4<0$ 恒负，故驻点是极大值点；两端面积趋 0，因此也是全局最大值。最优形状是「两边为 $L/4$、一边为 $L/2$」的矩形。

<span class="marginnote">这道题的解法链条——建模、求导、驻点、判别、对比端点——就是一切「求最优化问题」的原型。无论是火箭燃料最少、广告投放最省还是模型超参最佳，本质都是在某个约束下「求导找零、再判峰谷」。到《最优化理论》与《运筹学》里，这个流程被推广到多变量与约束情形。</span>

## 7 数值算例：极值判别的完整流程

求 $f(x) = x^3 - 3x^2 - 9x + 5$ 的极值。

**第一步，求驻点**：$f'(x) = 3x^2 - 6x - 9 = 3(x-3)(x+1) = 0$，驻点 $x = -1, 3$。
**第二步，用第一充分条件**：$f'$ 在 $(-\infty,-1)$ 为正、$(-1,3)$ 为负、$(3,+\infty)$ 为正——$x=-1$ 处正变负（极大），$x=3$ 处负变正（极小）。
**第三步，用第二充分条件验证**：$f''(x) = 6x - 6$，$f''(-1) = -12 < 0$（极大），$f''(3) = 12 > 0$（极小）——两法一致。
**第四步，算极值**：$f(-1) = 10$（极大），$f(3) = -22$（极小）。

**要点**：一阶看变号、二阶看符号，两道判别互相印证——考试里用其中一种即可，但掌握两种可交叉检查。<span class="marginnote">这个例子还展示了「两法分工」：$f''\neq0$ 时第二充分条件一步出结果；$f''=0$ 时（如 $x^4$ 在 0 处）第二充分条件失效，必须回退第一充分条件看 $f'$ 变号。把两条路都练熟，极值题就稳了。</span>

## 8 对照表：两个充分条件

| 第一充分条件 | 第二充分条件 |
| --- | --- |
| 看 $f'$ 变号 | 看 $f''$ 符号 |
| 需 $f'$ 在去心邻域存在 | 需 $f''(x_0)$ 存在且 $f'(x_0)=0$ |
| 可处理不可导点 | 只能处理驻点 |
| 通用、可靠 | 快速、有失效情形 |

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 漏掉端点 | 闭区间最值候选点必含端点 |
| 驻点直接当极值 | 驻点需判别（变号/二阶符号） |
| $f''=0$ 硬用第二充分条件 | 失效，回退第一充分条件 |
| 建模时定义域没写 | 定义域决定驻点是否在候选范围内 |

## 10 极值思想与现代优化

「求导找极值」是优化的第一原理：

- **经济学**：边际成本 = 边际收益是利润最大化的一阶条件；
- **物理学**：能量最低原理、最小作用量原理都是「极值」思想的化身；
- **机器学习**：损失函数最小化——梯度下降数值地找驻点；凸函数的极值即全局最值；
- **运筹学**：线性规划、非线性规划把「求最值」系统化为学科。

「极值点处导数为零」这条费马引理，是整个优化理论的地基——从一元到多元（第九章）、从无约束到约束（拉格朗日乘数法），全部由此出发。

## 11 小结

- **极值**是局部概念，**最值**是整体概念；可导极值点必为驻点，驻点不一定极值点。
- **第一充分条件**：$f'$ 由正变负 ⇒ 极大，由负变正 ⇒ 极小，不变号 ⇒ 不是极值。
- **第二充分条件**：$f''(x_0)<0$ ⇒ 极大，$f''(x_0)>0$ ⇒ 极小；$f''(x_0)=0$ 时失效，回退第一充分条件。
- 闭区间最值 = 比较**驻点、不可导点、端点**三类的函数值。
- 两法分工：$f''\neq0$ 用第二、否则用第一，可交叉验证。
- 最值应用问题的四步：**建模 → 求导 → 求驻点 → 判别回答**。
