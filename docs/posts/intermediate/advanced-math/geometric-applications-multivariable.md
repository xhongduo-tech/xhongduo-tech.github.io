## 为什么从多元函数微分学的几何应用开始

空间曲线有切线与法平面，曲面有切平面与法线——而这些几何对象全部能用偏导数表达。本节把第八章的空间几何与第九章的微分学焊接起来：**曲面的切平面由梯度（偏导组成的法向量）给出，空间曲线的切线由切向量（导函数）给出**。这些公式不仅是解析几何的收尾，更是「局部线性化」几何化的顶点：曲面在每一点的局部被切平面替代，曲线在每一点的局部被切线替代。它们直接通向机器学习里的「决策边界」「流形」与物理里的「等势面」。<span class="marginnote">本节的统一观点：<strong>一阶导数信息完整描述了「局部几何」</strong>。对曲面 $F(x,y,z)=0$，梯度 $\nabla F=(F_x,F_y,F_z)$ 是法向量，法向量定切平面；对曲线 $\mathbf{r}(t)$，切向量 $\mathbf{r}'(t)$ 定切线。一切几何对象都由「导数向量」充当向导。</span>

## 1 曲面的切平面与法线

设曲面由 $F(x,y,z) = 0$ 给出，$M_0(x_0,y_0,z_0)$ 在曲面上，$F$ 在 $M_0$ 处偏导连续且不同时为零。则曲面在 $M_0$ 处的**法向量**

$$\mathbf{n} = (F_x(x_0,y_0,z_0),\ F_y(x_0,y_0,z_0),\ F_z(x_0,y_0,z_0)) = \nabla F(M_0)$$

**切平面方程**：

$$F_x(M_0)(x-x_0) + F_y(M_0)(y-y_0) + F_z(M_0)(z-z_0) = 0$$

**法线方程**：

$$\frac{x - x_0}{F_x(M_0)} = \frac{y - y_0}{F_y(M_0)} = \frac{z - z_0}{F_z(M_0)}$$

**重点：梯度垂直切平面**——曲面 $F=0$ 上过 $M_0$ 的一切曲线都在切平面内，而梯度 $\nabla F$ 垂直所有这些切线，因而是法向量。<span class="marginnote">「梯度垂直等值面」是本节最深刻的几何事实：对 $z=f(x,y)$，等值线 $f(x,y)=C$ 的法向量是 $(f_x,f_y)$——梯度沿等值线的法向、指向 $f$ 增长最快的方向。这个「梯度 ⊥ 等值面」的结论在第 54 节方向导数中会再次兑现。</span>

**辨析｜易错点：** ① 曲面 $z=f(x,y)$ 写成 $F = f(x,y)-z=0$ 后，法向量是 $(f_x, f_y, -1)$——**最后一个分量是 $-1$ 而非 $+1$**；② 法向量不唯一（可乘任意非零常数），方程方向不同不影响几何对象本身。

## 2 空间曲线的切线与法平面

设空间曲线参数方程 $\mathbf{r}(t) = (x(t), y(t), z(t))$，$M_0$ 对应 $t_0$，且 $\mathbf{r}'(t_0)\neq0$。**切向量**（方向向量）

$$\mathbf{T} = \mathbf{r}'(t_0) = (x'(t_0),\ y'(t_0),\ z'(t_0))$$

**切线方程**与**法平面方程**（点法式）：

$$\frac{x - x_0}{x'(t_0)} = \frac{y - y_0}{y'(t_0)} = \frac{z - z_0}{z'(t_0)}, \qquad x'(t_0)(x-x_0) + y'(t_0)(y-y_0) + z'(t_0)(z-z_0) = 0$$

曲线若以**一般式**（两曲面交线）给出：$\begin{cases}F(x,y,z)=0\\G(x,y,z)=0\end{cases}$，切向量为

$$\mathbf{T} = \nabla F \times \nabla G$$

——两曲面的法向量叉积给出交线方向，与直线一般式的方向向量公式完全平行。<span class="marginnote">「交线切向量 = 两法向量叉积」与第八章「直线方向 = 两平面法向量叉积」一脉相承：<strong>曲面的梯度是法向量，交线的方向是法向量的叉积</strong>。叉积「同时垂直两者」的性质在此反复立功。</span>

## 3 公式解析：曲面的切平面与法线

求曲面 $z = x^2 + y^2$ 在点 $(1, 1, 2)$ 处的切平面与法线：

- **第一步，化隐式**：$F = x^2 + y^2 - z = 0$。
- **第二步，求梯度**：$\nabla F = (2x, 2y, -1)$，在 $(1,1,2)$ 处 $\mathbf{n} = (2, 2, -1)$。
- **第三步，写切平面**：$2(x-1) + 2(y-1) - (z-2) = 0$，即 $2x + 2y - z = 2$。
- **第四步，写法线**：$\frac{x-1}{2} = \frac{y-1}{2} = \frac{z-2}{-1}$。

**关键**：$z=x^2+y^2$ 是旋转抛物面，其切平面法向量 $(2x,2y,-1)$ 的 $-1$ 分量来自「$F_z = -1$」——这正是「$z=f(x,y)$ 写隐式时法向量末分量为 $-1$」的实例。四个步骤全程机械：化隐式 → 求梯度 → 写切平面 → 写法线。

## 4 全微分与切平面的同一性

切平面方程与全微分本质是同一件事：

$$z - z_0 = f_x(x-x_0) + f_y(y-y_0)$$

这个方程右边就是全微分 $dz = f_x dx + f_y dy$（把 $dx = x-x_0$、$dy = y-y_0$ 代入）。**切平面 = 全微分的几何图像**——「函数值的局部变化 ≈ 全微分」正是「曲面 ≈ 切平面」。<span class="marginnote">这个同一性把三节内容串成一条线：<strong>全微分（代数）⟺ 切平面（几何）⟺ 局部线性化（思想）</strong>。学机器学习时，损失函数的「切平面近似」「梯度下降沿最陡下降走」都建立在这个同一性上——局部用线性替代非线性，再迭代逼近。</span>

## 5 几何应用的实际价值

- **等值线与梯度可视化**：地形图上的等高线就是 $f(x,y)=C$ 的等值线，梯度垂直等高线、指向最陡上坡——登山选路、气象图上气压梯度的直观都源于此。<span class="marginnote">「沿梯度走 = 最陡上升」是第 54 节方向导数的结论，也是梯度下降（取负梯度 = 最陡下降）的几何依据。你在这里建立的「梯度垂直等值面、指向最陡方向」直觉，是整个优化理论的出发点。</span>
- **法向量在图形学与物理**：光照计算需要曲面的法向量（面元 $dS$ 的法向）、流体通过曲面的通量也用法向量——第十一章曲面积分的几何基础。
- **决策边界与流形**：机器学习里分类边界 $f(x)=0$ 是特征空间中的「曲面」，其切平面与法向量刻画边界局部形态；数据流形 $z=f(x,y)$ 的切空间是「局部线性嵌入」类方法（LLE、t-SNE 直觉）的几何。

## 6 小结

- **曲面 $F=0$**：法向量 $\mathbf{n}=\nabla F$，切平面 $F_x(x-x_0)+F_y(y-y_0)+F_z(z-z_0)=0$。
- **$z=f(x,y)$ 写隐式**：法向量 $(f_x, f_y, -1)$，末分量为 $-1$。
- **曲线 $\mathbf{r}(t)$**：切向量 $\mathbf{r}'(t)$，切线 + 法平面；一般式曲线的切向量 = 两法向量叉积。
- **切平面 = 全微分的几何图像**：局部线性化三视图（代数/几何/思想）。
- 应用：等值线梯度、光照法向量、决策边界与流形的局部几何。
