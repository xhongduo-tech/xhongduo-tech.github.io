## 为什么从有理函数的积分开始

多项式之比——**有理函数**——是最「规整」的一类函数，但积分并不平凡：$\int \frac{dx}{x^2+2x-3}$ 表面上无公式可套。本节的方法论是：**把复杂分式拆成简单分式之和**，每个简单分式都有现成的积分公式。这把「有理函数积分」彻底机械化——任何有理函数，无论多复杂，都可以按固定流程积分到底。这是全章最具「算法味」的一节：它有一套完全确定的步骤，不依赖灵感，只要按部就班就能做完。工程里大量传输函数、系统响应都是有理函数，积分（拉普拉斯反变换）全靠这套分解。<span class="marginnote">部分分式分解是「线性代数」的提前预演：把一个向量（函数）在「基底」（简单分式）下展开。到《线性代数》你会看到，任何向量在完备基下分解、任何矩阵对角化，与「分式拆项」是同一个代数思想——「结构分解」让复杂对象变得可计算。</span>

## 1 有理函数与部分分式

**有理函数**：$R(x) = \dfrac{P(x)}{Q(x)}$，其中 $P$、$Q$ 是多项式。若 $\deg P \ge \deg Q$（分子次数不低于分母），先做**多项式除法**，把 $R$ 化为「多项式 + 真分式」：

$$\frac{P(x)}{Q(x)} = S(x) + \frac{R_0(x)}{Q(x)}, \qquad \deg R_0 < \deg Q$$

多项式部分直接积分，剩下的真分式再拆部分分式。例如 $\frac{x^3}{x^2+1} = x - \frac{x}{x^2+1}$。

**部分分式分解**：把真分式 $\frac{R_0(x)}{Q(x)}$ 按分母 $Q(x)$ 的因式分解拆成若干「原子分式」之和。分母的每个因子决定一种原子分式：

- **单重实根因子** $(x-a)$：对应 $\dfrac{A}{x-a}$；
- **$k$ 重实根因子** $(x-a)^k$：对应 $\dfrac{A_1}{x-a} + \dfrac{A_2}{(x-a)^2} + \cdots + \dfrac{A_k}{(x-a)^k}$；
- **不可约二次因子** $x^2+px+q$（判别式 < 0）：对应 $\dfrac{Mx+N}{x^2+px+q}$；
- **$k$ 重二次因子**：对应 $\dfrac{M_1x+N_1}{x^2+px+q} + \cdots + \dfrac{M_kx+N_k}{(x^2+px+q)^k}$。

<span class="marginnote">每种因子的原子分式都能积：$\int\frac{A}{x-a}dx = A\ln|x-a|$，$\int\frac{A}{(x-a)^k}dx = \frac{A}{(1-k)(x-a)^{k-1}}$，二次型分子是「$Mx+N$」是因为要让分母求导的「凑微分」有机会成立。</span>

## 2 待定系数法

**待定系数法**：按上述规则写出分解形式，把右边通分合并，比较两边分子的**同次幂系数**，得到线性方程组，解出待定系数。

例：$\dfrac{x+3}{(x-1)(x+2)} = \dfrac{A}{x-1} + \dfrac{B}{x+2}$。通分：

$$x+3 = A(x+2) + B(x-1) = (A+B)x + (2A - B)$$

比较系数：$\begin{cases}A + B = 1\\ 2A - B = 3\end{cases}$，解得 $A = \frac{4}{3}$、$B = -\frac{1}{3}$。

**赋值法**（更快）：对 $\dfrac{x+3}{(x-1)(x+2)}$，两边同乘 $(x-1)$ 后令 $x=1$，直接得 $A = \dfrac{1+3}{1+2} = \frac{4}{3}$；同乘 $(x+2)$ 令 $x=-2$，得 $B = \dfrac{-2+3}{-2-1} = -\frac{1}{3}$。赋值法对单重根特别高效，是「只看单点」的简化。

## 3 公式解析：含不可约二次因子的分解

求 $\int \frac{x^2 + 2x + 1}{x(x^2+1)}\,dx$：

- **第一步，检查是否真分式**：分子次数 $2$ < 分母次数 $3$，是真分式，直接拆。
- **第二步，写出分解形式**：分母有单根因子 $x$ 与不可约二次因子 $x^2+1$，故
  $$\frac{x^2+2x+1}{x(x^2+1)} = \frac{A}{x} + \frac{Mx+N}{x^2+1}$$
- **第三步，定系数**：通分得 $x^2+2x+1 = A(x^2+1) + (Mx+N)x$。展开：$(A+M)x^2 + Nx + A$。比较系数：$A+M=1$、$N=2$、$A=1$，得 $A=1$、$M=0$、$N=2$。
- **第四步，逐项积分**：$\int\frac{dx}{x} + \int\frac{2\,dx}{x^2+1} = \ln|x| + 2\arctan x + C$。

**关键技巧**：二次因子对应的分子设为 $Mx+N$（含一次项）——不能只设常数，否则凑不出 $x^2+1$ 型。

## 4 有理函数积分的通用流程

**有理函数积分的六步流程**（机械可执行）：

1. **判真分**：$\deg P \ge \deg Q$ 时先做多项式除法，拆出多项式部分。
2. **因式分解分母**：$Q(x)$ 分解为一次因式与不可约二次因式的乘积。
3. **写分解形式**：按「单根→单分式，重根→一串，二次→$Mx+N$」的规则写出待定式。
4. **求待定系数**：通分比较系数，或对单根用赋值法。
5. **逐项积分**：每个原子分式套积分表（$\ln$、幂、$\arctan$、$\ln$ 二次式）。
6. **合并结果**：把各分部的结果相加，常数合并。

<span class="marginnote">这套流程完全确定、无需求灵感，是「算法化数学」的绝佳样例——只要每步都不出错，任何有理函数都能积出初等函数形式。现代计算机代数系统（Mathematica、SymPy）实现的有理函数积分正是这条流程的自动化。</span>

## 5 有理函数积分的延伸

有理函数积分看似孤立，却是更大体系的中枢：

**三角有理式**：$\int R(\sin x, \cos x)\,dx$ 通过万能代换 $t = \tan\frac{x}{2}$ 化为有理函数积分，再走本节流程。<span class="marginnote">万能代换 $t=\tan\frac{x}{2}$ 把 $\sin x = \frac{2t}{1+t^2}$、$\cos x = \frac{1-t^2}{1+t^2}$、$dx = \frac{2dt}{1+t^2}$ 代入，任何三角有理式都变成有理函数——「三角积分 + 有理函数积分」两条线由此打通。</span>
- **欧拉代换**：含根式的 $\int R(x, \sqrt{ax^2+bx+c})\,dx$ 通过合适代换化为有理函数积分。
- **控制系统**：拉普拉斯反变换求系统时域响应，核心就是对有理函数做部分分式分解——每个原子分式对应一个「模态」（指数衰减、振荡等）。这是《自动控制原理》与《信号与系统》的必备运算。
- **数论**：部分分式分解与整数的「质因子分解」、模运算的「中国剩余定理」在结构上同源——都是「分解到不可再分的基本单元」。

## 7 数值算例：含重根的分解

求 $\int\frac{dx}{(x-1)^2(x+1)}$。

**第一步，写分解形式**：分母含二重根 $x=1$ 与单根 $x=-1$，故 $\frac{1}{(x-1)^2(x+1)} = \frac{A}{x-1} + \frac{B}{(x-1)^2} + \frac{C}{x+1}$。
**第二步，通分合并**：$1 = A(x-1)(x+1) + B(x+1) + C(x-1)^2$。
**第三步，赋值法定系数**：令 $x=1$：$1 = 2B$，$B=\frac12$；令 $x=-1$：$1 = 4C$，$C=\frac14$；再展开比较（或代入 $x=0$）：$1 = -A + B + C$，$-A = 1 - \frac12 - \frac14 = \frac14$，$A = -\frac14$。
**第四步，逐项积分**：$\int\left(-\frac{1}{4(x-1)} + \frac{1}{2(x-1)^2} + \frac{1}{4(x+1)}\right)dx = -\frac14\ln|x-1| - \frac{1}{2(x-1)} + \frac14\ln|x+1| + C$。

**要点**：重根的处理——「每个重根写一串分式，阶从 1 到 $k$」，赋值法对每个根直接代出对应系数。<span class="marginnote">重根分解的记忆：<strong>$(x-a)^k$ 要拆成 $k$ 项，次方从 1 到 $k$</strong>。赋值法的高效在于「每次只消掉一个根」——乘 $(x-1)^2$ 后令 $x=1$，只剩 $B$ 项；乘 $(x+1)$ 后令 $x=-1$，只剩 $C$ 项。重根项的系数往往靠「求导」或「比较次高次项」补全。</span>

## 8 对照表：四种因子的分解规则

| 分母因子 | 分解形式 |
| --- | --- |
| 单根 $(x-a)$ | $\frac{A}{x-a}$ |
| $k$ 重根 $(x-a)^k$ | $\frac{A_1}{x-a}+\cdots+\frac{A_k}{(x-a)^k}$ |
| 不可约二次 $x^2+px+q$ | $\frac{Mx+N}{x^2+px+q}$ |
| $k$ 重二次 | 每阶一项 $\frac{M_ix+N_i}{(x^2+px+q)^i}$ |

## 9 常见错误自查清单

| 错误 | 正确做法 |
| --- | --- |
| 假分式不先做多项式除法 | $\deg P \ge \deg Q$ 时先除 |
| 重根只设一项 | 每个重根拆 $k$ 项 |
| 二次因子分子只设常数 | 设 $Mx+N$ 才能凑微分 |
| 分母忘了因式分解 | 先分解分母再定分解形式 |

## 10 有理函数积分与现代工程

有理函数积分是控制与信号处理的必备运算：

- **拉普拉斯反变换**：系统响应的部分分式分解，每个原子分式对应一个「模态」（指数、振荡）；
- **滤波器设计**：传输函数是有理函数，其积分/反变换对应时域响应；
- **计算机代数**：SymPy、Mathematica 的有理函数积分模块实现的就是这套六步流程；
- **数论同源**：部分分式与质因子分解、中国剩余定理结构同源——「分解到基本单元」的普适思想。

「把复杂分式拆成可积的原子分式」是工程里最常用的分解之一——它把「系统响应」翻译成「基本模态的叠加」。

## 11 小结

- **有理函数积分** = 多项式除法（化真分式）→ 分母因式分解 → 部分分式 → 逐项积分。
- **分解规则**：单根对应 $\frac{A}{x-a}$，$k$ 重根对应 $k$ 项，二次因子对应 $\frac{Mx+N}{x^2+px+q}$。
- 求系数用**待定系数法**（通分比较）或**赋值法**（对单根代入）。
- 重根拆 $k$ 项，赋值法每次消掉一个根。
- 二次因子的分子要设成 $Mx+N$，不能只设常数。
- 流程完全机械化，是计算机代数与控制系统部分分式分解的理论基础。
