## 为什么从常系数线性微分方程组开始

真实的系统很少只由一个函数描述：弹簧上挂两个物体、两条电路耦合、捕食者与猎物的种群，都需要**多个未知函数**同时满足一组方程——**微分方程组**。当方程组是常系数线性时，有一类优雅的解法：**消元法**——把一组方程通过「求导、加减」消去一部分未知函数，化成一个高阶方程，解出后再代回求其余。<span class="marginnote">消元法的本质与线性代数里的高斯消元完全相同：<strong>用方程之间的运算消去变量</strong>。区别只是「变量」换成了「未知函数及其导数」。到《线性代数》你会看到更系统的矩阵形式 $X' = AX$，其解由矩阵指数 $e^{At}$ 给出——本节是那套理论的具体前奏。</span>

## 1 消元法解方程组的思路

**常系数线性微分方程组**的标准形式：

$$\begin{cases}x' = a_{11}x + a_{12}y + f_1(t)\\ y' = a_{21}x + a_{22}y + f_2(t)\end{cases}$$

**消元法四步**：

1. **选一个方程**，用算子 $D = \frac{d}{dt}$ 把导数写成算子形式；
2. **消元**：通过「对某方程求导后相加减」消去一个未知函数，得到一个关于单个未知函数的高阶方程；
3. **解高阶方程**：用常系数方法求其通解；
4. **代回求其余**：把解代入原方程（通常是「最方便」的一个），求出另一未知函数——**注意此时不能再引入新的任意常数**。

**辨析｜易错点：** 消元法最大的坑是第 4 步「代回」——代回求出的另一函数**不能**再出现新的积分常数。因为原方程组是 $n$ 个一阶方程，通解应含 $n$ 个任意常数；消元成 $n$ 阶方程后它恰含 $n$ 个常数，代回只是「用已定常数表达」另一个函数，不应产生新常数。若代回时做了积分而引入了 $C_3$，说明代数运算有误或代回对象选错。

## 2 公式解析：解方程组 $\begin{cases}x' = x + y\\ y' = 4x + y\end{cases}$

- **第一步，用算子改写**：$\begin{cases}(D-1)x - y = 0\\ -4x + (D-1)y = 0\end{cases}$。
- **第二步，消去 $y$**：由第一式 $y = (D-1)x$，代入第二式：$-4x + (D-1)^2x = 0$，即 $(D^2 - 2D - 3)x = 0$。
- **第三步，解高阶方程**：特征方程 $r^2 - 2r - 3 = (r-3)(r+1) = 0$，根 $r = 3, -1$，故 $x = C_1e^{3t} + C_2e^{-t}$。
- **第四步，代回求 $y$**：$y = (D-1)x = x' - x$。算 $x' = 3C_1e^{3t} - C_2e^{-t}$，故 $y = 2C_1e^{3t} - 2C_2e^{-t}$。

**关键**：$x$ 的通解含 $C_1, C_2$，$y$ 由「代回」直接用 $C_1, C_2$ 表达——**不再新增常数**。最终通解 $\begin{cases}x = C_1e^{3t} + C_2e^{-t}\\ y = 2C_1e^{3t} - 2C_2e^{-t}\end{cases}$ 恰含两个任意常数，与「两个一阶方程」的自由度匹配。

## 3 用特征向量视角理解

消元法给出的解其实揭示了一个更深的结构：方程组 $X' = AX$ 的解形如「**特征向量 × 指数**」。

设 $X = \begin{pmatrix}x\\y\end{pmatrix}$，$A = \begin{pmatrix}1 & 1\\4 & 1\end{pmatrix}$。试探解 $X = \xi e^{rt}$，代入得 $A\xi = r\xi$——**$\xi$ 是 $A$ 的特征向量，$r$ 是特征值**。$A$ 的特征值：$\det(A - rI) = (1-r)^2 - 4 = r^2 - 2r - 3 = 0$，得 $r = 3, -1$——正是消元法特征方程的根。<span class="marginnote">消元法的高阶特征方程 $r^2-2r-3=0$，与矩阵 $A$ 的特征多项式完全一致。这不是巧合：<strong>微分方程组 $X'=AX$ 的解由 $A$ 的特征值与特征向量决定</strong>——$r$ 是特征值，解的系数向量是特征向量。到《线性代数》，这个联系会被系统化为 $X = e^{At}X_0$（矩阵指数）与对角化。</span>

特征值 $r=3$ 对应特征向量解 $\begin{pmatrix}1\\2\end{pmatrix}$，$r=-1$ 对应 $\begin{pmatrix}1\\-2\end{pmatrix}$——与消元法得到的解一一对应。**消元法是「笨办法」，特征向量法是「聪明办法」**，两者殊途同归。

## 4 方程组的应用

常系数线性微分方程组是许多系统的自然模型：

- **耦合弹簧系统**：两个质块用弹簧相连，运动方程为二阶方程组——化为一阶方程组后即本节形式。
- **捕食者-猎物模型**：Lotka–Volterra 方程 $\begin{cases}x' = ax - bxy\\y' = -cy + dxy\end{cases}$——非线性，但线性化后（小扰动分析）用本节方法研究稳定性。<span class="marginnote">Lotka–Volterra 方程描述鲨鱼-小鱼、狐狸-兔子种群的周期性波动。它虽是非线性，但在平衡点附近线性化（雅可比矩阵）后，稳定性由特征值的实部决定——「特征值定稳定性」再次出场。到《常微分方程》《生态学》与《计算复杂性》你会反复用到这套线性化分析。</span>
- **电路网络**：耦合电感、互感电路的电流方程组是常系数线性方程组。
- **化学动力学**：多组分反应的浓度变化率方程组。
- **控制系统的状态方程**：现代控制理论把系统写成一阶方程组 $X' = AX + BU$——正是本节形式的向量化。

## 5 小结

- **常系数线性方程组**：多个未知函数、一组一阶线性方程。
- **消元法**：算子改写 → 消元化高阶 → 解高阶方程 → 代回求其余（**不再新增常数**）。
- 方程组的解形如「特征向量 × 指数」，特征方程与系数矩阵的特征多项式一致。
- 消元法对应特征向量法的「笨办法」，但结果一致、适合手工计算。
- 应用：耦合弹簧、捕食者-猎物、电路网络、控制系统状态方程。
