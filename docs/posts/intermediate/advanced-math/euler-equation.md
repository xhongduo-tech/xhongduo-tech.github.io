## 为什么从欧拉方程开始

前面的常系数方程靠「系数是常数」才能用 $e^{rx}$ 试探。但有一类**变系数**方程，虽然系数含 $x$，却可以通过换元 $x = e^t$（或 $t = \ln x$）神奇地变成常系数方程——这就是**欧拉方程**。它长着「$x^k y^{(k)}$」的整齐形状：每一项的阶数与 $x$ 的幂次恰好匹配。欧拉方程是「**换元把结构揭示为常系数**」的经典范例，也是微分方程求解中「观察结构与选择变换」能力的又一次升华。<span class="marginnote">欧拉方程的发现展示了欧拉的洞察：<strong>$x^k y^{(k)}$ 在换元 $x=e^t$ 下会变成「常数系数 × $y$ 对 $t$ 的导数」</strong>——因为 $x\frac{d}{dx} = \frac{d}{dt}$（链式法则）。变系数的「不规则」被换元抹平，露出常系数的「骨架」。这是微分算子记号 $x\frac{d}{dx} = D_t$ 的首次大显身手。</span>

## 1 欧拉方程的形式

**欧拉方程（Euler 方程）**：形如

$$x^n y^{(n)} + p_1 x^{n-1} y^{(n-1)} + \cdots + p_{n-1}x\,y' + p_n y = f(x)$$

的方程。其特征：**每一项中 $y$ 的导数阶数 $k$ 恰与 $x$ 的幂次 $k$ 相配**。最常见的二阶欧拉方程：

$$x^2 y'' + p x y' + q y = f(x)$$

其中 $p, q$ 为常数。<span class="marginnote">为什么这种形状可解？核心等式 $x\frac{d}{dx} = \frac{d}{dt}$（在 $x=e^t$ 下）。于是 $xy'$ 变成 $y$ 对 $t$ 的一阶导、$x^2y''$ 变成二阶导的组合——每个 $x^ky^{(k)}$ 都被「翻译」成关于 $t$ 的常系数微分算子。形状匹配保证了翻译后没有「漏网」的变系数。</span>

## 2 换元法与特征方程

**换元 $x = e^t$（$x>0$）**：记对 $t$ 的导数用点记号或 $D = \frac{d}{dt}$，则

$$xy' = \frac{dy}{dt}, \qquad x^2y'' = \frac{d^2y}{dt^2} - \frac{dy}{dt}$$

一般地 $x^k y^{(k)}$ 是关于 $D$ 的 $k$ 次多项式算子作用在 $y$ 上。代入欧拉方程后，变系数全部消失，得到一个**关于 $t$ 的常系数线性方程**，用上一节的常系数方法求解，最后把 $t = \ln x$ 代回。

**求特征方程的直接法**：设 $y = x^r$（$x>0$ 时试探解），代入齐次欧拉方程 $x^2y'' + pxy' + qy = 0$：

$$r(r-1) + pr + q = 0$$

即特征方程 $r^2 + (p-1)r + q = 0$。根的类型决定通解（$x>0$）：

| 特征根 | 通解 |
| --- | --- |
| 不等实根 $r_1 \neq r_2$ | $y = C_1x^{r_1} + C_2x^{r_2}$ |
| 二重根 $r$ | $y = (C_1 + C_2\ln x)x^{r}$ |
| 共轭复根 $r = \alpha \pm i\beta$ | $y = x^\alpha[C_1\cos(\beta\ln x) + C_2\sin(\beta\ln x)]$ |

<span class="marginnote">三种通解与常系数方程惊人地相似，只需把「$e^{rx}$」换成「$x^r$」、「$x$」换成「$\ln x$」。这背后的联系：换元 $x=e^t$ 后 $x^r = e^{rt}$，重根情形的 $x e^{rx}$ 换成 $(\ln x)x^r$，复根情形的 $\cos\beta t$ 换成 $\cos(\beta\ln x)$。<strong>欧拉方程就是「穿变系数外衣的常系数方程」</strong>。</span>

## 3 公式解析：求 $x^2y'' - 3xy' + 3y = 0$

**第一步，写特征方程**：这是齐次欧拉方程（$x>0$），设 $y = x^r$，代入得 $r(r-1) - 3r + 3 = r^2 - 4r + 3 = (r-1)(r-3) = 0$。
**第二步，读根**：$r_1 = 1$，$r_2 = 3$，不等实根。
**第三步，写通解**：$y = C_1x + C_2x^3$。

验证：$y = x$ 代入，$x^2\cdot0 - 3x\cdot1 + 3x = 0$，成立；$y=x^3$ 代入，$x^2\cdot6x - 3x\cdot3x^2 + 3x^3 = 6x^3 - 9x^3 + 3x^3 = 0$，成立。<span class="marginnote">验证「幂函数解」的可靠性：欧拉方程的齐次解恰是幂函数 $x^r$——这与常系数方程的指数解 $e^{rx}$ 互为镜像。因为 $x = e^t$，$x^r = e^{rt}$ 正是常系数方程在 $t$ 域的解。</span>

## 4 非齐次欧拉方程

非齐次欧拉方程 $x^2y'' + pxy' + qy = f(x)$ 的解法：**换元 $x=e^t$ 化为常系数非齐次方程**，用待定系数法或常数变易法求特解，再代回 $t = \ln x$。

例：$x^2y'' - 2xy' + 2y = x^2\ln x$（$x>0$）。换元 $x=e^t$，得 $\frac{d^2y}{dt^2} - 3\frac{dy}{dt} + 2y = te^{2t}$。齐次特征根 $r=1,2$；右端 $\lambda=2$ 是特征根（单根），设特解 $y^* = t(At+B)e^{2t}$，代入解得特解；通解 = 齐次通解 + 特解，最后代回 $t = \ln x$。<span class="marginnote">非齐次欧拉方程的流程与常系数非齐次完全平行：<strong>换元 → 常系数 → 齐次通解 + 特解 → 回代</strong>。右端 $f(x)$ 换元后变成 $f(e^t)$，再判断能否用待定系数法；若不能，用常数变易法兜底。</span>

**辨析｜易错点：** ① 换元后右端 $f(e^t)$ 可能与「多项式 × 指数」形态不符，此时待定系数法不适用，直接用常数变易法；② 回代时注意 $x>0$ 与 $x<0$ 的定义域——通常约定 $x>0$，$x<0$ 的情形可令 $t = \ln(-x)$ 类似处理；③ $x=0$ 是欧拉方程的奇点，解在 $x=0$ 处通常无定义，通解只在 $x>0$ 或 $x<0$ 的区间上成立。

## 5 欧拉方程的应用与延伸

欧拉方程虽然形式上「变系数」，却在多处以自然方式出现：

**拉普拉斯方程与调和函数**：用极坐标处理圆域问题时，径向部分常化为欧拉方程。<span class="marginnote">极坐标下 $\nabla^2 u = 0$ 分离变量后，径向方程是 $r^2R'' + rR' - n^2R = 0$——正是欧拉方程。所以欧拉方程是圆域边界值问题的常客，到下册《数学物理方程》你会反复遇到它。</span>
- **变系数线性的特例**：欧拉方程是「系数与阶数匹配」的变系数方程，这类可解的变系数方程极少——它是少数「看结构就能解」的幸运儿。
- **广义 Cauchy–Euler 方程**：$(ax+b)^n y^{(n)}$ 型的推广形式，换元 $ax+b = e^t$ 同样可解。
- **数值方法的测试场**：欧拉方程的精确解常作为数值算法的基准测试案例。

## 6 小结

- **欧拉方程**：$x^ny^{(n)} + p_1x^{n-1}y^{(n-1)} + \cdots + p_ny = f$，阶数与幂次匹配。
- **换元** $x = e^t$：变系数化为常系数（$x\frac{d}{dx} = \frac{d}{dt}$）。
- **特征方程**：设 $y=x^r$ 得 $r(r-1) + pr + q = 0$；通解与常系数平行（$x^r$ 代 $e^{rx}$、$\ln x$ 代 $x$）。
- 非齐次欧拉方程：换元 → 常系数非齐次 → 待定系数/常数变易 → 回代。
- 应用：极坐标下的径向方程、广义 Cauchy–Euler 方程。
