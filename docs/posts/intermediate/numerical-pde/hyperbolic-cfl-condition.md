# 双曲方程与 CFL 条件

## 为什么双曲方程需要新的稳定性思想

上一节的抛物方程把信息瞬间传遍全域，稳定性分析用「锯齿波是否衰减」就能覆盖。但还有一大类方程完全不同——**对流、波动、流体运动**：那里信息沿着**特征线（characteristics）**以有限速度传播，前面说过这是与抛物「性格相反」的方程族，统称**双曲方程**。<span class="marginnote">双曲方程的原型是波动方程 $u_{tt} = c^2 u_{xx}$ 与对流方程 $u_t + a u_x = 0$。它们像「广播站」：每个扰动都沿确定的方向线以确定速度前行。CFL 条件（Courant-Friedrichs-Lewy）1928 年首次提出时就来自对 $u_t + a u_x = 0$ 的差分离散研究，是数值 PDE 最古老、也最不可能绕开的条件。</span>

这里稳定性问题换了一张脸：不是「锯齿波爆炸」，而是「**信息根本来不及传到**」。直观地说，数值格式在 $t_{n+1}$ 层上的值只能依赖前一层有限个点——如果真实的波在一个时间步内跑的距离超过了格式能「看见」的范围，数值解就注定抓不住它。这就是 CFL 条件的全部灵魂。

## 1 精确解：沿特征线常数

先建立基准。对流方程

$$
u_t + a u_x = 0, \qquad a > 0
$$

有一个几乎平凡的精确解：**解在直线 $x - at = \text{常数}$ 上保持常值**。验证只需链式法则——把 $u(x,t) = f(x-at)$ 代入，$u_t + a u_x = -a f' + a f' = 0$。这些直线 $x = x_0 + a t$ 就是**特征线**，波以速度 $a$ 向右平移而不变形。

于是真解在点 $(x_j, t_{n+1})$ 处的值，等于它在 $t_n$ 层、$x_j - ak$ 处的值：

$$
u(x_j, t_{n+1}) = u(x_j - ak, t_n)
$$

这个「回溯一步」的等式是 CFL 条件推导的起点：**真解的依赖点**是 $x_j - ak$ 那一个点。<span class="marginnote">「解沿特征线常数」是对流方程最核心的直觉，也是后面 Riemann 问题、特征线法的地基。金融里 Black-Scholes 换成特征坐标后变成热方程，流体里的「顺流」算子 $\partial_t + a\partial_x$ 更是处处可见——特征线把「时间」和「空间」合并成了一条自然方向。</span>

**对一般双曲系统（如浅水、欧拉方程），CFL 条件里的 $a$ 要换成最大特征速度 $|a|_{\max}$：** $\nu = |a|_{\max} k / h \le 1$。原因是系统同时有多条特征线，只要最外沿的那条还落在数值依赖域内，其余自然都在里面。这条「用最坏速度定步长」的法则，在守恒律数值里被贯彻到每一种格式，也是后面自适应步长控制的依据。

## 2 迎风格式与 Courant 数

数值格式只能看到前一层的网格点。对 $a>0$，信息从左边来，所以用**迎风（upwind）差商**：空间导数取向后差商，得到迎风格式

$$
\frac{U_j^{n+1} - U_j^n}{k} + a\frac{U_j^n - U_{j-1}^n}{h} = 0
$$

记 **Courant 数** $\nu = ak/h$，整理成：

$$
U_j^{n+1} = (1 - \nu)\, U_j^n + \nu\, U_{j-1}^n
$$

**Courant 数 $\nu$ 是双曲方程的网格比**，对应抛物方程里的 $\mu$：它衡量「一个时间步内波跑过的网格数」。$\nu \le 1$ 是本节最重要的数字，其意义配图如下。

## 3 CFL 条件：依赖域必须覆盖依赖点

图里红线是迎风格式在 $t_n$ 层「看得见」的范围——**数值依赖域**：$U_j^{n+1}$ 只依赖 $U_j^n$ 与 $U_{j-1}^n$ 之间的整段。蓝线是特征线，它回溯到 $t_n$ 层的落点在 $x_j - ak$。

**CFL 必要条件：数值依赖域必须包含真解依赖点。** 即

$$
x_j - ak \in [x_{j-1},\, x_j] \iff 0 \le \nu \le 1
$$

当 $\nu > 1$（棕虚线），特征线落点偏出依赖域左侧：真解携带的信息在数值格式的「视野」之外，任何稳定化技巧都救不回来——这不是数值误差大小的问题，是**离散结构根本缺失了那个信息**。<span class="marginnote">CFL 只是必要条件而非充分条件：满足 CFL 的格式仍可能因其他原因（如锯齿波）不稳定。就像「考场上有笔」是考出好成绩的必要不充分条件——CFL 保证信息没丢，稳定性则保证误差不涨。</span>

用 von Neumann 分析迎风格式，放大因子 $G = 1 - \nu + \nu e^{-i\xi h}$，其模长的平方

$$
|G|^2 = 1 - 2\nu(1-\nu)\bigl(1 - \cos\xi h\bigr)
$$

在 $0 \le \nu \le 1$ 时恒 $\le 1$——**CFL 条件恰好也是迎风格式的稳定性条件**。两个视角（依赖域 + 傅里叶）殊途同归，这是数值 PDE 中最令人安心的一次「双重确认」。

**数值例：** 取 $a=1$、$h=0.01$、$k=0.005$，则 $\nu = ak/h = 0.5$，每步波走半格。迎风格式 $U_j^{n+1} = 0.5\,U_j^n + 0.5\,U_{j-1}^n$ 把高斯脉冲逐格右移，同时把相邻两点各取一半，波形轻微变钝——这就是一阶格式的数值耗散。把 $k$ 加到 $0.015$，$\nu = 1.5 > 1$：特征线落点 $x_j - 0.015$ 跑到格式视野之外，脉冲开始出现拖尾、振荡，误差向负方向扩散。同一份代码只改一个参数，收敛与爆炸立判。

## 4 公式解析：Courant 数与 CFL 不等式

$$
0 \le \nu = \frac{a k}{h} \le 1
$$

这条不等式值得逐项拆解：

- **$\nu$ 是什么**：波速 $a$（每单位时间走多远）乘时间步长 $k$（每步走多久）等于每步走的距离 $ak$；除以网格间距 $h$，得到每步跨过的网格数。$\nu = 0.5$ 表示「每步走半格」。
- **$ak \le h$ 的含义**：一个时间步内波移动的距离不得超过一个网格。这样波头在 $t_{n+1}$ 层的到来位置，一定落在上一层相邻两个节点之间——而这两个节点的值正是格式拥有的全部信息。
- **$0 \le \nu$ 的含义**：迎风方向要对。$a > 0$ 用左邻，$a < 0$ 就必须换成右邻（$U_j^{n+1} = (1+|\nu|)U_j^n - |\nu| U_{j+1}^n$）。**方向错了，$\nu$ 的符号就错，格式必炸**——这是双曲方程最常见的编程事故。

**辨析｜易错点：** 中心差分 + 显式时间（$U_j^{n+1} = U_j^n - \frac{\nu}{2}(U_{j+1}^n - U_{j-1}^n)$）也满足 CFL，但它对任何 $\nu$ 都 von Neumann 不稳定——因为它把锯齿波原样保留（$|G|=1$）还叠加了频散。结论：**满足 CFL 只是及格线**，一个可用的双曲格式还必须在傅里叶意义上稳定、不产生非物理振荡。下一节我们会看到，正是这些问题催生了 Lax-Friedrichs 的耗散与 Lax-Wendroff 的色散校正。

迎风、中心、Lax-Friedrichs、Lax-Wendroff 是四条最常被引用的路线，一次看全：

| 格式 | 更新式（$a>0$） | 稳定性 | 精度 |
| --- | --- | --- | --- |
| 迎风 | $(1-\nu)U_j^n + \nu U_{j-1}^n$ | $\nu \le 1$ | 一阶 |
| 中心（显式） | $U_j^n - \tfrac{\nu}{2}(U_{j+1}^n - U_{j-1}^n)$ | 恒不稳定 | 二阶（不可用） |
| Lax-Friedrichs | $\tfrac{1+\nu}{2}U_{j-1}^n + \tfrac{1-\nu}{2}U_{j+1}^n$ | $|\nu| \le 1$ | 一阶，耗散强 |
| Lax-Wendroff | $\tfrac{\nu(1+\nu)}{2}U_{j-1}^n + (1-\nu^2)U_j^n - \tfrac{\nu(1-\nu)}{2}U_{j+1}^n$ | $|\nu| \le 1$ | 二阶，有色散 |

Lax-Wendroff 的来历值得记住：它先用半时间步把 $U$ 推进到 $t_n + k/2$ 的辅助层，再在那里用中心差商补全时间演化，两步拼出二阶精度。用同样的点数，它比迎风多一阶精度，代价是波形出现轻微的前后振荡（色散）——**一阶耗散抹形状，二阶色散摆形状，两者都要在更高阶 TVD 格式里统一驯服。**

**辨析｜易错点：** 迎风方向写反是双曲方程最常见的「一次性 bug」，但更隐蔽的错误是**对特征速度符号的理解**。$a>0$ 时信息来自左边、用左邻；$a<0$ 时信息来自右边、用右邻。判断标准永远只有一个：**看特征线从哪个方向「看」过来**，而不是看波往哪边跑。对浅水、欧拉这类多方程系统，各特征速度符号不同，每一支都要各自挑方向——这正是后面 Godunov 格式「让 Riemann 解替人挑方向」的动机。

本课的关键量集中在一张速查表：

| 量 / 概念 | 含义 |
| --- | --- |
| 特征线 | $x - at = \text{常数}$，解沿其保持常值 |
| Courant 数 $\nu$ | $ak/h$，一个时间步内波跨越的网格数 |
| 数值依赖域 | 格式在上一层「看得见」的范围 |
| CFL 条件 | 依赖域必须覆盖真解依赖点，$0 \le \nu \le 1$ |
| 数值耗散 / 色散 | 一阶抹形状 / 二阶摆形状 |

## 5 小结

- 对流方程 $u_t + a u_x = 0$ 的解沿特征线 $x - at = \text{常数}$ 平移不变形。
- **迎风格式**取 $a>0$ 的向后差商，写作 $U_j^{n+1} = (1-\nu)U_j^n + \nu U_{j-1}^n$。
- **CFL 条件** $0 \le \nu = ak/h \le 1$：数值依赖域必须包含真解依赖点，否则信息丢失、必错无疑。
- CFL 与 von Neumann 分析对迎风格式给出同一个判据 $\nu \le 1$，双重确认。
- CFL 是必要非充分：满足它仍可能因耗散/色散而质量糟糕，方向错误则直接失稳。

在下一节，我们将把「相容 + 稳定 ⇒ 收敛」这个被反复预告的命题正式写成定理——**Lax-Richtmyer 等价定理**，它回答数值 PDE 中最基本的问题：格式何时是「可信的」。
