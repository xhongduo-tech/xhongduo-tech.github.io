## 为什么从重抽样开始

前面几节的分位点表、正态近似，都需要「知道统计量的零分布长什么样」——要么查表，要么套中心极限定理。但现代计算能力给了另一条路：**与其解析推导统计量的分布，不如用数据自己造出大量「替身样本」，直接观测统计量在这些替身上的分布。** 这就是重抽样（resampling）的两大支柱——置换检验与自助法。<span class="marginnote">思想转折点：传统统计把「数据 → 统计量 → 查分布表」当管线；重抽样把「抽样」本身程序化，用 Monte Carlo 代替查表。它是非参数统计从「公式驱动」走向「计算驱动」的分水岭，也是大模型时代一切不确定性量化方法的祖辈。</span>

## 1 置换检验（permutation test）

置换检验针对「两总体是否同分布」这类检验，思路极朴素：**如果 $H_0$（两组同分布）成立，那么把数据重新洗牌分配到两组，检验统计量的分布不会变。** 于是：

1. 计算原数据上的检验统计量 $T_{\text{obs}}$（如两组均值差、秩和 $W$、KS 距离）。
2. 把 $m+n$ 个观测随机打乱，任取 $m$ 个当「第一组」，其余当「第二组」，算出一个置换统计量 $T^*$。
3. 重复 $B$ 次（如 $10{,}000$ 次），得到 $T^*$ 的置换分布。
4. $p$ 值 = $\dfrac{\#\{T^* \ge T_{\text{obs}}\} + 1}{B + 1}$。

<b>置换检验的妙处</b>：它**精确**地在「条件于观测值、随机分配标签」的分布下控制第一类错误，不依赖任何总体分布假设——只要 $H_0$ 下标签可交换。<span class="marginnote">可交换性（exchangeability）：$H_0$ 下两组观测联合分布对任意重排标签都不变。这是置换检验唯一的前提，比正态性、方差齐都弱得多，也解释了为什么它几乎对任何检验统计量都能配。</span>理论上穷举全部 $\binom{m+n}{m}$ 种分法，实践中随机抽样足够逼近。

## 2 自助法（bootstrap）

置换检验服务的是「检验」，自助法服务的是「估计」——它回答：统计量 $\hat\theta = g(X_1,\dots,X_n)$（均值、中位数、回归系数、神经网络误差……）的**标准误和置信区间**是多少？

**非参数 bootstrap 的做法**：从观测数据**有放回**地重抽 $n$ 个（bootstrap 样本），算一个 $\hat\theta^*$；重复 $B$ 次，得到 $\hat\theta^*_1,\dots,\hat\theta^*_B$。用这 $B$ 个值的经验分布去近似 $\hat\theta$ 的抽样分布：

$$\widehat{\mathrm{se}}_B = \sqrt{ \frac{1}{B-1}\sum_{b=1}^{B}\big(\hat\theta^{*}_b - \bar\theta^{*}\big)^2 }, \qquad \bar\theta^{*} = \frac{1}{B}\sum_{b=1}^{B}\hat\theta^{*}_b$$

有放回是关键：每次重抽都可能漏掉某些观测、重复另一些，从而模拟「换一批样本」的变异性。<span class="marginnote">有放回 vs 无放回：无放回重抽只是把原样本重排（置换），信息量不变；有放回才会产生「重复/缺失」，才能逼近独立同分布新样本的随机性。一条规则：检验标签可交换用置换，估计分布形状用 bootstrap。</span>

**bootstrap 的合法理由**：经验分布 $\widehat F_n$ 以几乎必然一致收敛逼近真分布 $F$，所以「从 $\widehat F_n$ 有放回抽样」近似「从 $F$ 抽样」。$n$ 越大，$\widehat F_n$ 越接近 $F$，bootstrap 越准。

## 3 置信区间：百分位法与 $BC_a$

bootstrap 最受欢迎的输出是置信区间。**百分位区间（percentile interval）**最直接：取 $\hat\theta^*$ 的 $\alpha/2$ 与 $1-\alpha/2$ 分位数作为端点。若 $\hat\theta$ 的抽样分布大致对称、且偏差小，它工作得很好。

更稳健的是 **$BC_a$ 区间（bias-corrected and accelerated）**，它校正偏态与偏差两个方向，公式修正分位数：

$$q_{\text{low}} = \Phi\!\Big( z_{\alpha/2} + \frac{z_{\alpha/2}+\hat z_0}{1 - a(z_{\alpha/2}+\hat z_0)} \Big), \qquad \hat z_0 = \Phi^{-1}\!\Big(\frac{\#\{\hat\theta^*_b \lt  \hat\theta\}}{B}\Big)$$

其中 $\hat z_0$ 度量偏差，$a$ 度量加速（偏态）修正。<span class="marginnote">偏态数据下，简单置信区间 $[\hat\theta \pm z \cdot \hat{\mathrm{se}}]$ 会一端过宽一端过窄；$BC_a$ 通过在分位数上做单调变换把区间「压」向正确形状。它是 Efron 体系里值得记住的名字，哪怕平时只记「有偏就用 $BC_a$」这一条经验。</span>

### 算例：置换检验的穷举

设 $X$ 组（$m=4$）：5, 7, 9, 11；$Y$ 组（$n=3$）：8, 12, 15。原数据上的统计量取均值差

$$T_{\text{obs}} = \bar Y - \bar X = \frac{8+12+15}{3} - \frac{5+7+9+11}{4} = \frac{35}{3} - 8 \approx 3.67$$

$n=7$，把所有 $\binom{7}{3}=35$ 种「把 3 个观测分给 $Y$」的排法都算一遍均值差，得到 $T^*$ 的精确分布。检查发现只有 3 种排法给出 $T^* \ge 3.67$（都是把最大的三个数分给 $Y$），于是

$$p = \frac{3 + 1}{35 + 1} \approx 0.11$$

不显著。注意分子分母各加 1：这是「观测数据本身也算一次置换」的保守校正，保证 $p$ 值不小于 $1/(B+1)$，避免在小样本下报出 0。<span class="marginnote">$n=7$ 时穷举 35 种分法毫无压力；$n$ 稍大（$m+n > 20$）组合数就爆炸，改随机抽样 $B=10{,}000$ 次即可。穷举给的是<strong>精确</strong> $p$ 值，随机近似只差 Monte Carlo 噪声，两者都在可交换性下严格控制第一类错误。</span>

### 自助法的一个小样本例子

设 8 个观测：$3.1, 4.5, 5.0, 5.8, 6.2, 7.9, 8.4, 9.3$，估计中位数的标准误。原始样本中位数为 $(5.8+6.2)/2 = 6.0$。做 $B=1{,}000$ 次有放回重抽，每次算中位数，得到 $\hat\theta^*$ 的分布：其经验标准差约为 1.1。而朴素的做法（把样本当正态、套 $\text{IQR}/1.349$ 的公式）会给出约 1.3——两者接近，但 bootstrap 完全不假设分布，且能直接给出中位数分布的偏态形态。

### 与刀切法（jackknife）的关系

bootstrap 的近亲是**刀切法（jackknife）**：逐个删掉一个观测，用「留一估计」的波动估计方差：

$$\hat\theta_{(-i)} = g(X_1,\dots,X_{i-1},X_{i+1},\dots,X_n), \qquad \widehat{\mathrm{Var}}_{\text{jack}}(\hat\theta) = \frac{n-1}{n}\sum_{i=1}^{n}\Big(\hat\theta_{(-i)} - \bar\theta_{(\cdot)}\Big)^2$$

刀切法只需 $n$ 次重算，几乎零成本，对「光滑」统计量（均值、方差、回归系数）方差估计与 bootstrap 渐近等价；但遇到中位数这类非光滑统计量时会失效——这正是 bootstrap 的不可替代之处。<span class="marginnote">选择口诀：统计量光滑、想省算力用刀切；不光滑（中位数、分位数、排序统计）、或想要置信区间形状用 bootstrap。两者都吃「经验分布逼近真分布」这一口饭，是小数据推断的两件随身工具。</span>

### 辨析｜易错点

**「$B$ 越大越准」只说对了一半。** $B$ 只控制 Monte Carlo 误差：把「从 $\widehat F_n$ 重抽」这一步算得足够精确；但「$\widehat F_n$ 代替 $F$」的统计误差不随 $B$ 缩小。所以 $B=10{,}000$ 与 $B=100{,}000$ 的区别很小，真正决定 bootstrap 准不准的是原始样本量 $n$。另一个常见误区是**对相关数据做普通 bootstrap**：时序、聚类数据直接有放回重抽会破坏结构，需用区块 bootstrap 或分层重抽。

### 参数 bootstrap 与置换检验的对照

除了「从经验分布重抽」的非参数 bootstrap，还有**参数 bootstrap**：先假设一个分布族（如正态），用数据估出参数（$\hat\mu,\hat\sigma$），再从 $\mathcal{N}(\hat\mu,\hat\sigma^2)$ 反复抽样生成替身样本。它与非参数 bootstrap 的取舍很清晰：分布族靠谱时，参数 bootstrap 更高效；分布族可疑时，非参数 bootstrap 不赌形状、更稳。<span class="marginnote">对照记忆：置换检验重排<strong>标签</strong>（分组标记），bootstrap 重抽<strong>观测本身</strong>；置换检验换的是「谁在哪个组」，bootstrap 换的是「哪些观测出现、出现几次」。一个管检验、一个管估计，重抽样方法的两条腿就此分清。</span>

### bootstrap 的输出形态

bootstrap 不只给标准误，还能直接输出分布形状：把 $\hat\theta^*_b$ 的直方图当作 $\hat\theta$ 抽样分布的画像，能直观看到偏态、双峰与极端情形——这是解析公式给不了的诊断价值。报告中常用的「误差棒」就有三种做法：$\hat\theta \pm z\cdot\widehat{\mathrm{se}}$（对称区间）、百分位区间（$[\hat\theta^*_{(\alpha/2)},\ \hat\theta^*_{(1-\alpha/2)}]$）、$BC_a$ 区间（偏态校正）。三者在小样本下可能差别明显，建议默认用 $BC_a$。

### 重抽样在机器学习中的角色

重抽样思想是现代机器学习的日常燃料。**bootstrap** 用于评估模型性能的方差：对训练集重抽生成多份替身数据，观察同一模型在替身上的指标波动，比单次 train/test 划分更可靠。**置换重要性（permutation importance）**则用它做特征归因：把某个特征的取值随机打乱，看预测误差上升多少，上升越多说明该特征越重要——本质是一次「打乱标签/特征的可交换性检验」。<span class="marginnote">从统计教科书到大模型评测，重抽样的身影无处不在：删掉一个样本观察模型行为变化（影响函数，见半参数一篇）、对生成结果多次采样看方差、用 bootstrap 估计评测指标的置信区间——「用数据自己替自己说话」已成为工程标配。</span>

### 辨析｜何时不能用置换检验

置换检验的前提是**原假设下标签可交换**。以下情形不适用：数据存在时间或空间相关（可交换性被破坏）、观测不是独立同分布、或比较的对象是「模型复杂度」这类没有天然标签的东西。此时应改用带结构假设的方法（区块 bootstrap、分层检验）。<strong>判断标准始终只有一条：原假设下，把标签重排是否仍然说得通。</strong>

### bootstrap 的逐点精度

bootstrap 置信区间在极端统计量上会露馅：估计方差为零或接近边界（如相关 $\to 1$、概率 $\to 0$）时，替身分布被截断，百分位区间两端被「钉」在边界，区间宽度假性缩窄。处理办法是改用变换（Fisher z 变换、logit）后再 bootstrap，或直接报 bootstrap-$t$ 区间。<span class="marginnote">这类「边界附近区间失效」在参数方法里同样存在，但 bootstrap 因直接采样分布而暴露得更明显——这是它诚实的一面：数据挤到边界，它就告诉你区间不敢乱画。</span>

## 4 公式解析：bootstrap 为什么能估计方差

$$
\mathrm{Var}(\hat\theta) \approx \frac{1}{B-1}\sum_{b=1}^{B}\big(\hat\theta^{*}_b - \bar\theta^{*}\big)^2
$$

- **第一步，目标**：$\hat\theta$ 是数据的函数，它的抽样方差 =「换一批独立同分布样本，$\hat\theta$ 会晃多大」。我们只有一批样本，无法真换。
- **第二步，替代**：把观测看成一个小总体（经验分布 $\widehat F_n$），从它里面有放回地反复抽「替身样本」$\{X^*_{b1},\dots,X^*_{bn}\}$。
- **第三步，代入**：对每个替身样本算 $\hat\theta^*_b = g(X^*_{b1},\dots,X^*_{bn})$，$B$ 个值提供了「替身分布」。
- **第四步，为什么要除以 $B-1$**：替身样本间的标准差是无偏估计的标准做法；$B$ 是 Monte Carlo 次数而非样本量，增大 $B$ 只让估计更精确地逼近「$\widehat F_n$ 下真实的抽样方差」，而不会消除「用 $\widehat F_n$ 代替 $F$」带来的偏差。理解这两层误差，是正确使用 bootstrap 的关键。

## 5 小结

- **置换检验**重排标签生成统计量的零分布，精确控制第一类错误，只需**可交换性**，适合检验「两组是否同分布」。
- **bootstrap**有放回重抽样本、观测统计量的替身分布，用于估计标准误与置信区间；依据是 $\widehat F_n$ 一致逼近 $F$。
- 置信区间有百分位法与 $BC_a$ 法；偏态数据用后者，简单数据用前者。
- 置换检验管「假设检验」，bootstrap 管「不确定性量化」；$n$ 决定 bootstrap 的统计精度，$B$ 只决定 Monte Carlo 精度，两者别混。
- 重抽样的两个前提要分清：检验标签可交换用置换（精确控错），估计分布形状用 bootstrap（有放回才产生新变异）。
- 到机器学习里，bootstrap 是模型方差评估的燃料，置换重要性是特征归因的标准件——同一思想、两套用法。

在下一节，我们将回到统计量的结构：把均值、方差、秩和、Gini 装进同一个框架，看它们的方差为何都按 $1/n$ 衰减——这就是 **U 统计量**。
