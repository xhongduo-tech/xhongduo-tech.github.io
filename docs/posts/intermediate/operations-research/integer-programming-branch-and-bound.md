## 为什么从整数规划开始

上一节的单纯形法给出 $x_1 = 6, x_2 = 0$，巧得全是整数。但真实世界很少这么配合：**飞机不能起飞 1.5 架、仓库不能建 0.7 个、员工排班必须是整数。** 当决策变量被要求取整数（尤其只能取 0 或 1 时），线性规划就升级为**整数规划（Integer Programming，IP）**。<span class="marginnote">「取整」看似小事，实则天壤之别：LP 在多项式时间内可解，而一般 IP 是 NP-难问题——1950 年代人们一度以为 IP 只是 LP 的小修补，直到意识到连最简单的 0-1 背包都要指数级搜索。</span> 更反直觉的是：**把 LP 最优解四舍五入得到的不但往往不是最优，甚至可能不可行。** 这就是为什么我们需要专门的方法。而分支定界（branch and bound）正是求解 IP 最通用、最经典的框架——它是「分而治之 + 剪枝」的一次绝妙实践，也深刻影响了后面的动态规划与搜索算法。

## 1 整数规划的类型与舍入陷阱

按决策变量的约束，IP 分三类：

**纯整数规划**：全部变量取整数。**混合整数规划（MIP）**：部分变量连续、部分取整。**0-1 整数规划**：变量只取 0 或 1，用来表达「做不做」的决策——选址、排班、项目是否上马。<span class="marginnote">0-1 变量是建模的「瑞士军刀」：引入一个二元变量 $y$，就能把「要么全做要么全不做」「选了 A 才能选 B」这类逻辑关系翻译成线性约束，比如 $x_A \le M y,\; x_B \le M y$。</span>

**辨析｜易错点：** 初学者最常踩的坑是「先解 LP 再四舍五入」。有两个典型失败案例：一是舍入后目标值离最优很远；二是舍入后违反了某个隐蔽约束（例如容量刚好卡线）。更糟的是，**舍入方向选错了还可能导致无解假象**。把 IP 当作「LP + 取整」来解，在规模稍大时几乎必然翻车。

**一个可复算的舍入反例**：容量 6 的背包，物品 A（价值 10，重量 5）、物品 B（价值 9，重量 4）。按单位价值 A 为 2.0、B 为 2.25，LP 松弛先装满 B 再装 $\tfrac25$ 件 A，目标值 $9+4=13$（分数）。把它取整：B 全装、A 向下取 0，得价值 9 的解；A 若向上取 1，则重量 $5+4=9>6$ 直接不可行。而真正的整数最优是「只装 A」，价值 10——**比舍入解多 1，且舍入路径把「次优」与「不可行」踩了个遍**。三行就能复算，是「先解 LP 再取整」不可靠的最短证明。

**0-1 变量是建模的通用积木**。除「选不选」外，它还能把常见逻辑关系直接翻译成线性约束：「二者至少选一个」写作 $x_1 + x_2 \ge 1$；「选了 A 就必须选 B」写作 $x_A \le x_B$；「A、B 不可同时选」写作 $x_A + x_B \le 1$；「只有选中 A 才启用约束 $g(x) \le 0$」用大 M 方法写作 $g(x) \le M(1 - x_A)$。把这四条模式记熟，IP 建模的第一课就过关了。

为什么这么难？关键在于可行域从凸多面体「碎」成了离散格点：顶点理论失效，对偶强对偶失效，最优解可能藏在某个格点里，而格点是海量的。核心困难是**解空间离散且指数增长**。

## 2 分支定界法：分而治之 + 剪枝

分支定界（branch and bound）的基本思想极其朴素：把难题拆成小难题，逐一排除。

**松弛（relaxation）**：先忽略整数约束，解对应的 LP（称为**松弛问题**）。它的最优值给原问题提供一个**上界**（最大化时）。<span class="marginnote">松弛问题的最优解是 IP 的「天花板」：再好的整数解也不可能超过这个值，因为整数可行域是 LP 可行域的子集。</span>

**分支（branching）**：若松弛解里某个变量 $x_j = 5.4$ 不满足整数，就把可行域一分为二：加上约束 $x_j \le 5$ 与 $x_j \ge 6$ 两个子问题。两个子问题互斥且穷尽——任何整数解必落在其中一支。

**定界（bounding）与剪枝（pruning）**：维护一个全局**下界**（当前最好的整数可行解）。当某节点的上界 ≤ 下界时，这个节点不可能藏有更好的整数解，直接**剪枝**放弃。

**为什么剪枝是安全的？** 每个节点的松弛上界来自「放宽后的可行域」——任何藏在节点子树里的整数解必然也属于该节点松弛问题的可行域，故其目标值不可能超过该节点的上界。上界 ≤ 下界意味着「这棵子树里最好的可能」都不如手里已握的整数解，砍掉它绝无损失。**剪枝的正确性不是经验，而是放缩关系的必然。**

## 3 分支定界的完整流程

以 0-1 背包问题为例走一遍：容量 $W = 10$，物品有（价值，重量）：(8, 4)、(6, 3)、(5, 3)、(3, 1)，求价值最大。

1. **根节点**：解松弛 LP（允许分数取）。若最优为分数解，取上界。
2. **分支**：选一个分数变量（比如选第一个物品取 0.5 这类），拆成「取 1」与「取 0」两枝，各自解 LP 得子上界。
3. **比界**：若某枝上界 ≤ 当前已找到的整数解价值（下界），剪掉。
4. **更新下界**：一旦某枝解出整数解，用它更新下界。
5. 全部处理完，取最优整数解。

实际求解中还有三个关键工程技巧：**分支变量选择**（优先分「硬约束」变量）、**节点选择策略**（深度优先还是最好优先）、**初始下界**（先用贪心/启发式解一个好整数解，能剪掉大量节点）。这些细节决定同一棵树是秒解还是爆栈。<span class="marginnote">现代求解器（如 Gurobi、Cplex）在分支定界之外还叠加割平面（cutting planes，Gomory 割、混合整数割）——不断「切掉」不含整数点的部分，让界更紧，两者配合是工业级 IP 的灵魂。</span>

**节点选择的策略差异**：深度优先（DFS）内存占用小、容易快速找到新整数解来更新 $LB$；最好优先（best-first）则永远先处理上界最高的节点，理论上能剪得更多但内存开销大。工业求解器常两者混合：先用 DFS 冲出一个好下界，再转 best-first 收尾。

**工程细节：每棵节点都要重解一个 LP 吗？** 朴素实现是的，但现代求解器用「上一节点的热启动 + 对偶单纯形法」（见本专题《对偶理论与对偶单纯形法》）在几十毫秒内把新节点的最优解微调出来，不必从零重解。这正是对偶单纯形法在整数规划里成为主力的现实原因——它天生适合「切一刀约束再快速恢复最优」这类增量运算。

## 4 公式解析：定界与剪枝判据

分支定界的所有智慧浓缩在「上界、下界」两个量的比较上。先给一张速查，分清 IP 求解中四个量的角色：

| 量 | 记号 | 来源 | 角色 |
| --- | --- | --- | --- |
| 松弛上界 | $UB$ | 节点松弛 LP 最优值 | 天花板：该节点最好的可能 |
| 全局下界 | $LB$ | 已找到的最佳整数解 | 地板：已握在手的战果 |
| 最优性间隙 | $UB - LB$ | 两者之差 | 离最优还差多少 |
| 分数变量 | — | 松弛解的小数部分 | 决定分支的对象与方向 |

这四个量里，$LB$ 是「已握在手的战果」，$UB$ 是「理论上还能争多少」——分支定界全程就是在不断抬升 $LB$、压低 $UB$，直到两者相遇。

**上界（UB）与下界（LB）**：

$$
UB = \max \{ \text{各活动节点的松弛问题最优值} \}, \qquad LB = \text{当前最佳整数可行解的目标值}
$$

- **$UB$**：所有尚未剪枝节点中，松弛 LP 最优值的最大值——「天花板中的最高者」。
- **$LB$**：已找到的整数解中最好的目标值——「地板中的最高者」。
- **剪枝判据**：当某节点的上界 $UB_{\text{node}} \le LB$ 时，该节点最优也不会超过现有整数解，整棵子树作废。

**直觉读法**：$LB$ 是「已握在手里的战果」，$UB$ 是「理论上还能争多少」。当全树最高天花板 $UB$ 压到 $LB$ 之下（或相等），就没有任何隐藏机会了——**最优值的证明不是靠找到它，而是靠证明「没有更好的」**。这正是指数搜索能被驯服的关键：我们不需要遍历每个格点，只需要用界把不可能的区域整块整块地排除。

## 5 数值算例：亲手走一遍分支定界树

拿第 3 节的 0-1 背包（容量 $W=10$，物品价值/重量：(8,4)、(6,3)、(5,3)、(3,1)）把整棵树完整画一遍。先看一个关键数值：**把 LP 最优解四舍五入会得到什么？** 按单位价值贪心装（$3/1 > 8/4 > 6/3 > 5/3$），LP 松弛解取满 (3,1)、(8,4)、(6,3)，剩 2 单位容量装 2/3 件 (5,3)，松弛上界 $UB = 3+8+6+\tfrac{10}{3} \approx 20.33$——分数部分正是 (5,3) 这件物品的 2/3，于是先分支 $x_C \le 0$ 与 $x_C \ge 1$。

| 节点 | 约束 | 松弛 LP | UB | 处理 |
| --- | --- | --- | --- | --- |
| 根 | 无 | 值 ≈ 20.33，$x_C = 2/3$ 分数 | 20.33 | 分支 $x_C$ |
| C=0 | $x_C \le 0$ | 整数解 (3,1)(8,4)(6,3)，值 **17** | 17 | 更新下界 $LB = 17$ |
| C=1 | $x_C \ge 1$ | 值 20，$x_B = 2/3$ 分数 | 20 | 分支 $x_B$ |
| C=1,B=0 | $x_B \le 0$ | 值 16 | 16 | $16 \le 17$，**剪枝** |
| C=1,B=1 | $x_B \ge 1$ | 值 20，$x_A = 3/4$ 分数 | 20 | 分支 $x_A$ |
| C=1,B=1,A=0 | $x_A \le 0$ | 值 14 | 14 | $14 \le 17$，**剪枝** |
| C=1,B=1,A=1 | $x_A \ge 1$ | 整数解，值 **19** | 19 | 更新下界 $LB = 19$ |

把所有节点处理完：剩下的上界（20.33、20、20）都已 ≤ $LB = 19$，无须再展开，于是最优解为 **$x_A = x_B = x_C = 1, x_D = 0$，最优值 19**。这棵树一共只解了 7 个 LP，却穷举了 $2^4 = 16$ 个候选格点——**分支定界把「指数搜索」压缩成了「少数几次 LP」**，这就是它实用性的来源。<span class="marginnote">注意最优解 $(1,1,1,0)$ 恰好用满容量 10；而若当初直接对 LP 松弛解四舍五入（C 取 1 会把容量撑爆，取 0 则只剩 17），你会在 17 或「不可行」之间犯错——一个真实的、可以复算的教训。</span>

从这个例子还能读出分支定界的三个工程直觉：**分支变量的选择**（选「对容量影响大」的分数变量，这里先选 C）能更快收紧界；**初始下界越好**（若先用贪心得到 19，C=0 那枝 17 直接剪掉，树更小）；**节点顺序**影响内存占用——深度优先省内存，最好优先先找到好下界。这些都是让「同一个算法」表现出云泥之别的细节。

这套「先解松弛、按分数分支、靠界剪枝」的框架，对任何离散优化都适用——旅行商、排产、选址，只是变量含义不同。它也是后面《动态规划》一篇里「记忆子问题」思想的对照面：DP 靠「重叠子问题」省算力，分支定界靠「剪掉不可能」省算力，两种省法正好互补。

## 6 小结

- IP 分**纯整数、混合整数、0-1**三类；一般 IP 是 **NP-难** 问题。
- **四舍五入 LP 解不可靠**：可能次优、可能不可行。
- 分支定界三步：**松弛**求上界 → **分支**拆子问题 → **定界剪枝**。
- 剪枝的判据是 $UB_{\text{node}} \le LB$：界越紧，剪得越多。
- 工业级求解 = 分支定界 + **割平面**（Gomory 割、混合整数割）。
- 0-1 变量 + 大 M 法可表达全部常见逻辑约束（至少一、蕴含、互斥、条件启用）。
- 对偶单纯形法是分支定界内部「每节点快速重解」的引擎。
- 深度优先与最好优先的节点选择策略，决定同一棵树是秒解还是爆栈。

在下一节，我们换一种视角看待「结构」：很多整数问题其实长在**网络**上，而有网络结构就有多项式算法——**网络优化与最短路、最大流**。
