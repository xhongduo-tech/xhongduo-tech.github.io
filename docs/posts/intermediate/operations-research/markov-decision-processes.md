## 为什么从马尔可夫决策过程开始

之前的动态规划假设「决策后状态是确定的」。但现实是：**决策之后会发生什么是随机的**。投资决策后的市场波动、补货决策后的需求变化、机器人执行动作后的实际位移——都是随机的。**马尔可夫决策过程（Markov Decision Process, MDP）** 把「动态规划」与「随机过程」焊接在一起，成为现代强化学习的数学心脏。<span class="marginnote">MDP 的核心假设是<strong>马尔可夫性</strong>：未来只依赖于当前状态与当前决策，与更早的历史无关——「记忆只需要当前状态」。这个假设让问题可解，也是强化学习中「状态」设计的根本约束。</span> 从「从极限到大模型」的主线看，这一篇是**从运筹学跨入强化学习（第三级）的真正门槛**：值迭代、策略迭代就是 Q-learning、策略梯度在理论上的祖先。

## 1 MDP 的五元组与策略

一个 MDP 由五部分组成 $(S, A, P, R, \gamma)$：

- **状态集 $S$**：系统所有可能处的状态。
- **动作集 $A$**：在每个状态可做的决策。
- **转移概率 $P(s' \mid s, a)$**：在状态 $s$ 采取动作 $a$ 后转移到 $s'$ 的概率——这是「随机性」的来源。
- **报酬函数 $R(s, a, s')$**：转移发生后获得的立即回报。
- **折扣因子 $\gamma \in [0,1)$**：未来回报的折算率（1 单位未来的钱≈现在 $\gamma$ 单位）。

**策略（policy）$\pi$** 是「每个状态下该做什么」的完整规则：$\pi(s)$ 给出在状态 $s$ 应选择的动作。**MDP 的目标是找最优策略**，使**期望折扣总回报**最大化：

$$
V^\pi(s) = \mathbb{E}_\pi \left[ \sum_{t=0}^{\infty} \gamma^t R(s_t, a_t, s_{t+1}) \;\middle|\; s_0 = s \right]
$$

**辨析｜易错点：** 三大易错：一是**折扣因子 $\gamma=1$ 且无终止状态**时总回报发散，无法优化——必须 $\gamma < 1$ 或有终止状态；二是**混淆「状态」与「观测」**——MDP 假设状态完全可观测，若只能部分观测则要升级为 POMDP；三是**混淆策略与动作**——策略是「每个状态的动作映射」，不是一个动作。<span class="marginnote">折扣因子的两个解读：金融上是「时间价值」（未来的钱要贴现），学习上是「避免无限累加」（让无限时域的和收敛）。$\gamma$ 越小，越短视；$\gamma$ 越接近 1，越注重长远。库存补货里 $\gamma$ 决定了「现在多囤货 vs 未来少缺货」的权重。</span>

## 2 贝尔曼方程：把价值写成递归

**贝尔曼方程（Bellman equation）** 是 MDP 的核心递归关系：

$$
V^\pi(s) = \sum_{a} \pi(a \mid s) \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V^\pi(s') \right]
$$

- **$\pi(a \mid s)$**：策略在状态 $s$ 选动作 $a$ 的概率。
- **$P(s' \mid s,a)$**：转移概率。
- **$R(s,a,s') + \gamma V^\pi(s')$**：立即回报 + **折扣后的未来价值**。
- **直觉**：当前价值 = 「现在拿到的回报」 + 「搬到新状态后从那里继续的价值」。**贝尔曼方程把「无穷时域的和」压成了一个递推**——这正是动态规划最优性原理在随机世界的再现。

对最优策略，值函数满足**贝尔曼最优性方程**：

$$
V^*(s) = \max_a \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V^*(s') \right]
$$

## 3 公式解析：值迭代与策略迭代

解 MDP 的两大算法，都是贝尔曼方程的数值化。

**值迭代（value iteration）**：从任意初始 $V_0$ 出发，反复套贝尔曼最优性方程更新：

$$
V_{k+1}(s) = \max_a \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V_k(s') \right]
$$

- **$V_k$**：第 $k$ 轮的值函数估计。
- **右边**：对每个状态取「所有动作中期望回报最大的那个」。
- **直觉**：每一轮都把「未来能拿到的最好价值」向后传播一层。$V_k$ 收敛到 $V^*$，且收敛速率与 $\gamma$ 有关（$\gamma$ 越接近 1 收敛越慢）。<span class="marginnote">值迭代的收敛判定：当 $\max_s |V_{k+1}(s) - V_k(s)| < \varepsilon$ 时停止。这个「前后两次迭代的最大变化量」既是误差度量，也是停止准则——数值优化里「看相邻迭代的变化判断收敛」的标准套路，本质是柯西序列的思想。</span>

**策略迭代（policy iteration）**：两步交替——**策略评估**（固定策略 $\pi$，解贝尔曼方程求 $V^\pi$）与**策略改进**（在 $V^\pi$ 下贪心地选每个状态的最优动作，得到新策略 $\pi'$）。重复直到策略不再变化。策略迭代通常比值迭代收敛更快（迭代次数少），但每步要解一个线性方程组，代价更高。

**直觉**：值迭代是「不断修正对未来的估价」；策略迭代是「先锁定一个策略、评估它、再果断升级」。两者殊途同归到同一个 $V^*$。<span class="marginnote">强化学习中的 Q-learning 就是在<strong>没有模型 $P$</strong>（不知道转移概率）的情况下，用采样估计做「值迭代」；而 TD(λ)、Actor-Critic 则是值迭代与策略迭代在无模型世界的翻版——这就是「从极限到大模型」第三级《强化学习》的桥头堡。</span>

## 4 MDP 的应用：库存补货与机器人导航

**库存补货（inventory control）**：状态是当前库存量，动作是订货量，转移概率由随机需求给出，报酬是利润减订货与持有成本。MDP 解得最优补货策略——**多高补货、补到多少**，比静态的报童模型（本专题《库存论》）更能刻画「这一期的缺货影响下一期」的动态权衡。

**机器人导航**：状态是机器人位置，动作是移动方向，转移概率刻画「电机打滑导致偏离目标」，报酬是到达奖励减移动代价。MDP 求得的策略是「每个位置该往哪走」的完整地图——这正是强化学习在具身智能里的雏形。<span class="marginnote">一个值得记住的现实：MDP 的状态数随维度指数增长（维度灾难）。真实系统要么靠近似（函数近似、深度强化学习）要么靠问题分解，否则表格型值迭代在稍大的状态空间就会爆炸——这解释了为什么第三级要强化学习用神经网络替代查表。</span>

**回报设定的两个关键细节**：一是**终止状态**——到达终止状态后过程停止，此后不再累计回报，这让「有终点的任务」（一局棋、一次配送）也能在 $\gamma<1$ 的框架里定义有限总回报；二是**稀疏回报 vs 稠密回报**——只有终点给奖励（稀疏）训练极慢，每一步都给一点形状奖励（稠密）收敛更快但可能诱导「抄近路」行为。这两点直接延续到强化学习的奖励工程设计。

### MDP 术语速查表

| 术语 | 含义 |
| --- | --- |
| 马尔可夫性 | 未来只依赖当前状态与动作 |
| 策略 $\pi$ | 每个状态「做什么」的完整映射 |
| 折扣因子 $\gamma$ | 未来回报的折算率，$<1$ 保证收敛 |
| 值函数 $V^\pi$ | 策略 $\pi$ 下的期望折扣总回报 |
| 贝尔曼方程 | 把无穷和压成「立即回报 + 折扣未来」的递推 |
| 值迭代 | 反复套贝尔曼最优性方程直到收敛 |
| 策略迭代 | 评估-改进交替，收敛快但每步贵 |

## 5 数值算例：值迭代手算一个两状态 MDP

用一个足够小的例子把值迭代「跑一遍」。设一个两状态机器维护问题：状态 $S_1$ = 机器正常，$S_2$ = 机器故障。每个状态两个动作：$a_1$ = 继续生产，$a_2$ = 维护检修。在 $S_1$ 选 $a_1$：立即得 $R=+10$，下期 80% 概率留在 $S_1$、20% 掉到 $S_2$；在 $S_1$ 选 $a_2$：立即得 $R=+4$，100% 回到 $S_1$。在 $S_2$ 选 $a_1$：立即得 $R=0$，50% 概率仍是 $S_2$；选 $a_2$：立即得 $R=+2$，100% 修好回 $S_1$。折扣 $\gamma = 0.9$。

从 $V_0(S_1)=V_0(S_2)=0$ 出发。第 1 轮只看立即报酬：

- $V_1(S_1) = \max\{10 + 0.9(0.8\cdot0 + 0.2\cdot0),\ 4\} = \max\{10, 4\} = 10$
- $V_1(S_2) = \max\{0,\ 2\} = 2$

第 2 轮把未来的估价带进来（$V_1(S_1)=10, V_1(S_2)=2$）：

- 生产：$10 + 0.9(0.8\times10 + 0.2\times2) = 10 + 0.9\times 8.4 = 17.56$；维护：$4 + 0.9\times 10 = 13$。故 $V_2(S_1) = \max\{17.56, 13\} = 17.56$，$S_1$ 该选「生产」。
- $S_2$：生产 $0 + 0.9(0.5\times2 + 0.5\times10) = 5.4$；维护 $2 + 0.9\times10 = 11$。故 $V_2(S_2) = \max\{5.4, 11\} = 11$，$S_2$ 该选「维护」。

继续迭代，$V_k$ 会收敛到 $V^*$（本例约 $V^*(S_1)\approx 26$、$V^*(S_2)\approx 20$），每轮的最优动作也逐渐稳定——这就是「在 $S_2$ 修机器、在 $S_1$ 继续生产」的最优策略。**注意值迭代不需要事先知道最优策略，它在收敛途中自己把它「发现」出来**——这正是强化学习「从交互中逼近最优策略」的先声。<span class="marginnote">手算到这里可以做直觉核对：$S_2$ 里「生产」的期望未来值只有 5.4，远低于「维护」的 11，因为故障状态继续生产大概率继续恶化；而 $S_1$ 里「生产」的 17.56 远超「维护」的 13，说明正常状态的生产红利大于检修的稳健。最优策略完全由数值自然涌现，无需人工预设。</span>

## 6 小结

- **MDP** = 状态 + 动作 + 转移概率 + 报酬 + 折扣因子，是随机序贯决策的统一框架。
- **马尔可夫性**：未来只依赖当前状态，这是问题可解的前提。
- **贝尔曼方程**：$V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)[R + \gamma V^\pi(s')]$，把无穷和压成递推。
- **值迭代**：反复套贝尔曼最优性方程；**策略迭代**：评估-改进交替，收敛更快但每步更贵。
- MDP 是**强化学习**的数学心脏，库存、导航、推荐都是它的应用。
