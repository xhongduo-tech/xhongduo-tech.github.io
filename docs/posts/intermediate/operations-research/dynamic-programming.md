## 为什么从动态规划开始

前面我们解过的每个问题都有一个共同点：**把大问题拆成子问题**。最短路是「从源到某个点的最短路 + 一条边」，分支定界是「拆成两个子可行域」。1950 年代贝尔曼把这套直觉提炼成一种可以对付**非凸、离散、带顺序决策**问题的通用方法——**动态规划（Dynamic Programming，DP）**。<span class="marginnote">贝尔曼当时在兰德公司（RAND）工作，为给「multistage decision process」起个响亮的名字而发明了「dynamic programming」一词。他后来承认这个词更多是为了打动军方资助人，而非描述算法本质。</span> DP 是运筹学与计算机科学的交汇点：算法课上的斐波那契、背包、最长公共子序列，全是 DP；而人工智能里**强化学习的值函数方程，就是 DP 最优性原理的直接后代**。从「从极限到大模型」的路线看，这是「运筹学 → 强化学习」最重要的一座桥。

## 1 最优性原理

贝尔曼的最优性原理（principle of optimality）只有一句话：

**一个最优策略的任何部分（子策略）都必须是对相应子问题的最优策略。**

换句话说：如果全局最优路径经过了状态 $S_k$，那么从 $S_k$ 到终点的这段，也必须是从 $S_k$ 出发的最优路径。这看似平凡，却排除了一整类可能性——我们不必在每步重新全局搜索，只要记住「子问题的答案」，大问题就能从小问题「叠」出来。<span class="marginnote">反例意识很重要：不是所有问题都满足最优性原理。如果决策会影响未来状态（如「这次多买料，下回就没钱」这类非马尔可夫效应），DP 的前提就塌了。判断「子问题独立吗」是建模第一关。</span>

**辨析｜易错点：** 初学者常把 DP 与「贪心」混为一谈。贪心每步取「当下最优」，不回头看；DP 则在每步比较「所有可能选择的最优」。最短路里，Dijkstra 是贪心、Floyd-Warshall 是 DP；一旦边权为负，贪心崩溃而 DP 依旧成立——这就是区别的试金石。

## 2 DP 的四要素

任何一个 DP 问题都可以用四件套描述：

**阶段（stage）**：问题被划分成若干顺序步骤。**状态（state）**：某阶段开始时所处的情形（阶段内要决策所依赖的变量）。**决策（decision）**：在某个状态上做的选择。**转移（transition）**：决策如何把当前状态变为下一阶段的状态，并产生立即代价/收益。<span class="marginnote">「阶段、状态、决策、转移」四件套在强化学习里变成了「时间步、观测、动作、环境动力学」——换了个马甲，骨子里完全同构。见第三级《强化学习》。</span>

以背包问题为例：阶段 = 依次考虑每件物品；状态 = 当前剩余容量与已装价值；决策 = 装或不装；转移 = 消耗容量、累加价值。

## 3 动态规划与最短路、与背包

**最短路是 DP**：设 $d_i$ 为从起点到节点 $i$ 的最短路，则 $d_j = \min_{(i,j)} \{ d_i + w(i,j) \}$——这正是上一节网络篇里的松弛方程，只是现在有了名字。**Bellman-Ford 就是直接迭代这个方程**，即便边权为负也正确。

**0-1 背包是 DP 的教科书案例**：容量 $W$，物品 $i$ 重量 $w_i$、价值 $v_i$。定义

$$
f(i, c) = \max \{ f(i-1, c),\; f(i-1, c - w_i) + v_i \}
$$

- **$f(i, c)$**：只考虑前 $i$ 件物品、容量为 $c$ 时的最大价值。
- **第一支** $f(i-1, c)$：第 $i$ 件**不装**，价值继承前 $i-1$ 件。
- **第二支** $f(i-1, c-w_i) + v_i$：第 $i$ 件**装**，先用掉 $w_i$ 容量，再取前 $i-1$ 件在剩余容量下的最优。
- 两支取 max，就是「装或不装」的完整博弈；从 $f(0, \cdot) = 0$ 出发逐层填表，答案就是 $f(n, W)$。

这就是**重叠子问题**与**最优子结构**：同一个 $f(i,c)$ 会被多个更大问题反复需要，填表让每个只算一次。

## 4 公式解析：DP 的贝尔曼递归

DP 的一切浓缩为贝尔曼递归（Bellman recursion）：

$$
f_k(s_k) = \min_{x_k \in D_k(s_k)} \left\{ r_k(s_k, x_k) + f_{k+1}(s_{k+1}) \right\}, \qquad s_{k+1} = T_k(s_k, x_k)
$$

- **$k$**：阶段下标。**$s_k$**：第 $k$ 阶段的状态。
- **$x_k$**：在状态 $s_k$ 上可做的决策，取自决策集 $D_k(s_k)$。
- **$r_k(s_k, x_k)$**：这一步的立即代价/收益（如背包里装某件物品的价值）。
- **$s_{k+1} = T_k(s_k, x_k)$**：状态转移函数——做完决策后，下一阶段的状态。
- **整式**：当前阶段的最优值 = 「立即收益」与「未来（从下一状态开始）的最优值」之和的最小化。**过去与未来的分界就落在当前状态 $s_k$ 上**：过去已被 $f_k(s_k)$ 吸收，未来由 $f_{k+1}$ 给出，决策 $x_k$ 是连接二者的铰链。

**直觉读法**：DP 的核心不是「递归」，而是**「记住子问题」**。递归天然是自顶向下，DP 用一张表让每个子问题只算一次——这就是把指数时间压缩成多项式时间的那一下「魔术」。

## 5 小结

- **最优性原理**：全局最优的任何子策略，也是对应子问题的最优策略。
- DP 四要素：**阶段、状态、决策、转移**。
- **背包**是经典案例：$f(i,c) = \max\{f(i-1,c),\, f(i-1,c-w_i)+v_i\}$，填表消除重叠子问题。
- DP 与贪心的区别：贪心只看当下，DP 比较所有路径；负权边最短路是试金石。
- **最短路就是 DP**，Bellman-Ford 与 Floyd-Warshall 都是 DP 的直接应用。
