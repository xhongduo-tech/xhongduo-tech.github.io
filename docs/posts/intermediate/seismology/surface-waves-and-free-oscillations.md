## 为什么从面波与自由振荡开始

P 波与 S 波是体波，在地球内部穿行。但还有一类波被地表「困住」：**面波（surface waves）** 的能量沿着地球表面传播，随深度指数衰减。对大地震，面波振幅大、速度慢，常在体波之后姗姗来迟却震感最烈——远震强震害多由面波造成。而对 8 级以上巨震，整个地球会被激起**自由振荡（free oscillations）**，在震后数周内持续「响」下去。

为什么学它们？因为**面波的频散是浅层地球结构最灵敏的探针**，而自由振荡是唯一能直接约束整个地球三维平均结构的观测——它们把「地震学」从「看某几条射线」升级为「听整颗行星的心跳」<span class="marginnote">1960 年智利 $M_w$ 9.5 大地震首次让全球台站同时记录到自由振荡的本征模；这些模的频率由地球内部的弹性结构与密度唯一决定，于是成为约束行星内部模型（如 PREM）的黄金数据。</span>。

## 1 勒夫波与瑞利波

面波分两类，机制完全不同：

**勒夫波（Love wave）**：水平方向、垂直于传播方向的位移（SH 型）。它**只在表层存在**——需要一个速度随深度**增加**的低速覆盖层，波在地表与低速层底部之间反复全反射，能量被「囚禁」在表层里<span class="marginnote">勒夫波的存在本身就证明了地壳或沉积层相对下覆介质偏软/偏慢；若地表到深部速度不变，勒夫波将不存在。它的速度介于 $\beta_{surface}$ 与 $\beta_{deep}$ 之间。</span>。

**瑞利波（Rayleigh wave）**：由 P 波与 SV 波在自由表面耦合生成。质点在垂直面内沿传播方向做**逆行椭圆运动**——波峰处的质点运动方向与波的传播方向相反，与水面波的运动模式一致（只是方向相反）。

**重点：面波的相速度不是一个定值，而是频率的函数**——这就是**频散（dispersion）**。勒夫波、瑞利波的相速度 $c(\omega)$ 都从高频端（浅层速度）单调升到低频端（深层速度）。低频长周期波「看得更深」，跑得更快，于是在走时记录上长周期面波先到、短周期后到，形成面波特有的**长周期尾波拖尾**。

## 2 相速度与群速度

面对频散介质，必须区分两个速度：

**相速度（phase velocity）**：等相位面推进的速度，$c = \omega/k$。
**群速度（group velocity）**：能量包络传播的速度，$U = \frac{d\omega}{dk}$。

两者通过**瑞利公式（Rayleigh's formula）** 相连：

$$U = \frac{d\omega}{dk} = c + k\frac{dc}{dk}$$

**辨析｜易错点：** 在非频散介质中 $c$ 为常数，$dc/dk = 0$，于是 $U = c$，两者重合；但在频散介质中两者**分道扬镳**。地震记录上「看见的波列速度」是**群速度**（波形包络的移动），而「各频率分量的速度」是**相速度**。**常有人说「面波速度 3 km/s」，那是某个频率上的相速度，不是包络速度**——两者混用是初学面波时的头号混淆。

## 3 面波频散反演：浅层结构的探针

**重点：面波频散曲线 $c(f)$ 的形状，唯一对应表层速度结构 $v(z)$。** 高频端敏感于浅层，低频端敏感于深层，于是「先反演高频（浅部）、再反演低频（深部）」逐步剥离，就是经典的面波频散反演流程。

对**瑞利波**，还有一层优雅：相速度在空气层以上的地球表面自动满足自由边界条件，位移随深度指数衰减，衰减深度约一个波长。**波长越长，探得越深**——探测深度 ≈ 波长量级。因此：

- 短周期（~1 s）面波 → 地壳与沉积层结构；
- 中周期（~20 s）面波 → 上地幔速度结构；
- 长周期（100 s+）面波 → 全球尺度上地幔不均匀性，是层析成像的主力数据之一（见《地震层析成像》）。

## 4 地球自由振荡：把地球当一口钟

1960 年智利大地震后，人们在地震记录里看到体波早已衰减殆尽后，仍存在持续数日、周期约 53 分钟左右的规则振动——**地球自由振荡（free oscillations）**。整个地球像一口大钟被敲响，驻波在球体内来回震荡。

自由振荡分为两类**振型（normal modes）**：

**球型振型（spheroidal mode）** 记作 ${}_nS_l$：既有径向又有切向位移，对应 P+SV+重力耦合。
**环型振型（toroidal mode）** 记作 ${}_nT_l$：纯水平剪切振荡，对应 SH，$l=0$ 不存在。

下标 $l$ 是角阶数（类似球谐函数的阶数），$n$ 是径向节点数。**振型的本征频率由整个地球的 $(\rho, \lambda, \mu)$ 分布唯一决定**——只要给出内部结构模型，就能解出振型谱；反之，实测振型频率（最精确的观测之一，相对精度 $10^{-5}$ 量级）约束内部模型。**地球的平均模型 PREM（Preliminary Reference Earth Model）在很大程度上就是用振型频率约束出来的**<span class="marginnote">自由振荡与体波走时是互补的：走时只沿某条射线采样，振型是整球的全局平均。二者联合反演（"joint inversion of normal modes and body waves"）是现代全球模型的标配。</span>。

## 5 公式解析：群速度公式

$$U = \frac{d\omega}{dk} = c + k\frac{dc}{dk}$$

拆三步：

- **第一步，从定义出发**：能量以波包的**包络**速度传播。叠加个近邻频率的平面波，拍频的包络移动速度正是 $d\omega/dk$。
- **第二步，换回相速度**：$\omega = kc$，所以 $d\omega/dk = c + k\,dc/dk$——第一项是相速度本身，第二项是「相速度随波数的变化」的贡献。
- **第三步，读物理**：若 $dc/dk > 0$（短波快），则 $U > c$；反之 $U < c$。对地球面波，低频（长波）的 $c$ 更高，故**长周期面波总是先到**——正是观测现象。

**补充：频散面波在记录上的表现**。群速度为 $U(\omega)$ 的波列，某频率成分到达时间 $t = \text{距离}/U(\omega)$，于是台站记录上不同频率成分按群速度拉开，形成梳状波列。**由波列中不同「梳齿」的到达时间反推 $U(\omega)$，再积分反演 $v(z)$**——这是地球浅层结构研究最古老也最稳定的一条技术路线。

## 6 数值实例：一次频散曲线的测量

用一次「纸上测量」体会面波频散反演的全流程。假设一台站在 1000 km 外记录到瑞利波波列，某个波包中心频率 $f = 0.05$ Hz（周期 20 s）在 $t = 340$ s 到达。

- **群速度**：$U = 1000/340 \approx 2.94$ km/s——这是该频率能量包的传播速度。
- **相速度与波长**：瑞利波相速度通常略高于群速度，设该频率 $c = 3.2$ km/s，则波长 $\Lambda = c/f = 64$ km——**这个波包的「探测深度」约 64 km 量级，正落在上地幔顶部**。
- **反演第一步**：换一个更低的频率（如 $f = 0.02$ Hz，周期 50 s），群速度更大（约 3.6 km/s）——低频看更深、跑更快。把一系列 $U(f)$ 点连成频散曲线，就得到**表层速度结构的「指纹」**。

**重点：频散反演的每一步都是「对号入座」**——高频点约束浅层、低频点约束深层，逐频段反演 $v(z)$。一次典型的实测流程是「多重滤波（multiple filter）提取 $U(f)$ → 试错或反演 → 得到 $v(z)$ 模型」，这正是《地震层析成像》一节面波层析的前置动作。

再看自由振荡的一个数字：1960 年智利大地震后，地球基础振型 ${}_0S_2$ 的周期约 53 分钟——**整个地球像钟一样摆动的周期，与一台摆长等于地球半径的钟相当**。这个周期的数值直接约束了地球整体的刚度-密度平衡，是 PREM 模型的锚点数据之一。

**辨析｜易错点：** 面波比体波慢，但经常比体波「凶」——原因是几何扩散不同：体波在三维空间扩散（振幅 ∝ 1/距离），面波只沿二维表面扩散（振幅 ∝ 1/√距离）。**同样能量，面波衰减慢得多**，所以远震的强震动往往由面波主导。另一个常被混淆的点是勒夫波与瑞利波谁先到：在同样的浅层结构中，勒夫波（SH 型、无 P 耦合）通常比瑞利波快；而瑞利波因垂直与水平分量耦合、呈椭圆运动，在三分量记录上一眼可辨。

**重点：自由振荡的分辨率与体波互补**——体波走时「看到」的是沿射线的路径平均，自由振荡看到的是整球的加权平均。**把数千条走时 + 数千个振型频率放进同一个反演，就是现代全球模型的做法**；而地球内部各向异性，则要从振型的频率分裂（splitting）里读。

**补充：相速度怎么测**。台阵记录的波列在相邻台站间有时间差，同一频率成分的到达时间差直接给出相速度 $c = \Delta x/\Delta t$（两点法），多点拟合给出更稳的 $c(\omega)$。**群速度用「窄带滤波 + 包络」，相速度用「台站对相位」**——两种测量方法对应两种速度，正是「相/群之分」的观测落点。

**补充：面波在勘探地震里的亲戚**——瑞利波频散被用来测近地表剪切波速（多道面波分析 MASW），这正是「面波频散反演浅层 $v_S(z)$」在工程勘察中的直接翻版：公路、铁路、场地勘察全靠它。**同一套频散物理，从行星尺度用到场地尺度**，是理论「下放」的典型例子。

**易混速查：两类面波对照**

| 特征 | 勒夫波 | 瑞利波 |
| --- | --- | --- |
| 位移方向 | 水平、垂直传播方向 | 垂直面内逆行椭圆 |
| 机制 | SH 在低速层底部全反射囚禁 | P+SV 在自由面耦合 |
| 存在前提 | 需要低速覆盖层 | 均匀半空间即可存在 |
| 速度范围 | 介于 $\beta_{surface}$ 与 $\beta_{deep}$ | 约 $0.9\beta_{surface}$ |
| 在记录上 | 仅水平分量明显 | 垂直 + 水平分量都强 |

这张表把「为什么勒夫波没有时就不能测」、「为什么瑞利波三分量都看得见」一次讲清——**识别面波种类，是面波分析的第一步**。

**辨析｜易错点：** 勒夫波在液体中不存在（需要 SH 在刚性界面的全反射，液体 $\mu=0$），而瑞利波在流体界面（如水波）仍存在——**「有没有勒夫波」本身是探知浅层刚性的线索**，海洋地震学常据此判断洋壳是否含熔融层。

## 7 小结

- 面波两类：**勒夫波**（SH，囚禁于低速表层）与**瑞利波**（P+SV 耦合，逆行椭圆运动）。
- **面波强频散**：相速度 $c(\omega)$ 随频率变化，长周期探测更深、先到达。
- **相速度 $c=\omega/k$ 与群速度 $U=d\omega/dk$ 仅在非频散时相等**；记录上看到的是群速度。
- 频散曲线反演 $\Rightarrow$ 表层 $v(z)$；探测深度 ≈ 波长。
- **地球自由振荡**分球型 ${}_nS_l$ 与环型 ${}_nT_l$ 两类振型；振型频率约束整球内部模型（PREM）。
