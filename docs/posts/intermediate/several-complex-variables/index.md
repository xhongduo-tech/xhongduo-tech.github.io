# 多复变函数论

多复变函数论研究多个复变量的全纯函数，其核心对象是全纯域与伪凸域、解析层与上同调理论以及 ∂̄ 方程的存在性与正则性。从 Hartogs 现象、Levi 问题到 Cousin 问题与加权 L² 方法，多复变将单复变、PDE 与几何分析深度交织，是代数几何与复几何的公共语言，值得在打好单复变基础上系统研习。

## 对标教材

- Lars Hörmander, "An Introduction to Complex Analysis in Several Variables" (North-Holland, 3rd ed., 1990)
- Steven Krantz, "Function Theory of Several Complex Variables" (Wiley, 2nd ed., 2001)
- 史济怀, 《多复变函数论》（高等教育出版社）
