# 英语语法体系（英语词法句法、时体态式、综合教学语法）

以章振邦《新编英语语法》、Quirk《英语综合语法》与张道真《实用英语语法》三部权威教学语法为纲，系统覆盖英语词法、句法与「时·体·态·式」四大动词范畴。从初中到大学受众最广的分层科目，学完这些章节，就写完了英语教学语法的全部核心内容。

## 对标教材

- 章振邦《新编英语语法》
- Randolph Quirk et al., "A Comprehensive Grammar of the English Language"
- 张道真《实用英语语法》
