## 为什么从词类与句子成分开始

英语语法可以切成两半：**词法（morphology）**管词的形式变化——名词怎么变复数、动词怎么变形；**句法（syntax）**管词如何组句——哪些词凑在一起才成句、顺序如何。而无论词法还是句法，都建立在两个最基本的概念之上：**词类**与**句子成分**。词类是每个词的身份标签，句子成分是每个词在句中所扮演的职位。搞清「身份」与「职位」的区别，是读懂英语语法的第一道门：同一个词可以担任不同职位，不同词类的词也可以挤进同一个职位。本章先搭起这个总框架，后面每一节——名词、动词、时态、从句——都是在这个框架上盖楼。<span class="marginnote">这一节与第一级《现代汉语》的词类章节可以互参：汉英十大词类高度相似，但汉语靠虚词与语序表义，英语还叠加了词形变化，这是两种语言语法的根本分岔点。</span>

## 1 十大词类：实词与虚词

传统教学语法把英语的词分成**十大词类（parts of speech）**：

**名词（noun）**：人或事物的名称，如 `book`、`freedom`。
**代词（pronoun）**：代替名词的词，如 `he`、`it`。
**形容词（adjective）**：表示人或事物的性质、状态，如 `red`、`important`。
**数词（numeral）**：表示数目或顺序，如 `three`、`first`。
**动词（verb）**：表示动作或状态，如 `run`、`be`。
**副词（adverb）**：修饰动词、形容词或整个句子，如 `quickly`、`very`。
**冠词（article）**：用在名词前帮助限定名词，如 `a`、`the`。
**介词（preposition）**：表示名词与其他词的关系，如 `in`、`on`、`of`。
**连词（conjunction）**：连接词与词、句与句，如 `and`、`because`。
**感叹词（interjection）**：表示感叹或呼唤，如 `oh`、`hello`。

这十类再按功能分两大阵营：**实词（content words / notional words）**与**虚词（function words / structural words）**。

**实词**：有实在的词汇意义、能独立担任句子成分——名词、动词、形容词、副词、数词（代词较特殊，见下）。**虚词**：语法意义大于词汇意义、一般不能独立担任句子成分——冠词、介词、连词、感叹词，以及语法书中常另立一类的**助动词与情态动词**（`be`、`have`、`do`、`can`、`will` 等）。<span class="marginnote">动词体系里「实义动词」与「助动词/情态动词」的对立是理解动词形态的基础：实义动词有完整的词形变化，助动词则主要承担时态、语态、否定与疑问的「语法装配」。详见本章《动词的分类与主要动词句型》。</span>

**辨析｜易错点：** 代词到底算实词还是虚词？传统语法把它归入实词，因为它能独立充当主语、宾语；但 Quirk 的体系把它划入**封闭类（closed class）**功能词，因为它数量固定、几乎不接受新成员。**词类划分并非铁板一块，关键是理解「词汇意义」与「句法功能」两个维度**——代词在意义上「实」、在功能上「半虚」，处在两套分类体系的交界处。

## 2 句子成分：六种核心职位

句子不是词堆出来的，而是按**成分（sentence elements / clause elements）**组织起来的。英语的句子成分主要有六种：

**主语（subject，S）**：句子的主题，通常位于句首，是动作的发出者或被说明的对象。`She` sings well.
**谓语动词（predicate verb，V）**：句子的核心，说明主语的动作或状态。英语中**每个完整句子至少有一个限定动词（finite verb）**。She `sings` well.
**宾语（object，O）**：动作的承受者或结果。可分为**直接宾语（direct object，Od）**与**间接宾语（indirect object，Oi）**。He gave `me` `a book`.
**补语（complement，C）**：补充说明主语或宾语的身份、性质。**主语补语（subject complement，Cs）**俗称**表语**：She is `a teacher`；**宾语补语（object complement，Co）**与宾语合称**复合宾语**：We elected him `chairman`.
**定语（modifier / attribute，M）**：修饰名词或代词，说明其性质、所属等。a `red` apple.
**状语（adverbial，A）**：修饰动词、形容词、副词或整个句子，说明时间、地点、方式、原因等。He runs `fast`.<span class="marginnote">状语是「自由度」最高的成分：它可以在句首、句中、句尾多处安家，而主语、谓语、宾语、补语的位置相对固定。这种「状语漂移」在写作中常被用来变换节奏，也是理解倒装与强调结构（第4篇）的伏笔。</span>

判断一个成分靠两件事：**位置**和**词形**。英语词形变化少，位置就成了最强的信号——这正是下一节要展开的关键。

## 3 词类与句子成分的错位对应

初学者最容易踩的坑，是以为「名词当主语、动词当谓语」这种一一对应是铁律。**实际上词类与句子成分是多对多的关系：一个词类可以担任多种成分，一种成分也可以由多个词类担任。**

以名词为例，它几乎无处不在：

- 主语：`Water` boils at 100 °C.
- 宾语：I drink `water`.
- 表语：This is `water`.
- 定语（名词修饰名词）：a `water` bottle.

再看「定语」这个成分，名词、形容词、代词、介词短语、从句都能当：

| 成分 | 可担任的词类/结构 | 例 |
| --- | --- | --- |
| 主语 | 名词、代词、数词、不定式、动名词、从句 | `To err` is human. |
| 宾语 | 名词、代词、不定式、动名词、从句 | I enjoy `reading`. |
| 表语 | 名词、形容词、介词短语、从句 | He is `in trouble`. |
| 定语 | 形容词、名词、代词、介词短语、从句 | the book `on the desk` |
| 状语 | 副词、介词短语、不定式、分词、从句 | `Sadly`, he left. |

**辨析｜易错点：** 同一个词在不同句子里身份不同。`work` 在 `I work hard` 里是动词、担任谓语，在 `My work is fun` 里是名词、担任主语。**判断词类先看它在句中的功能和位置，而不是反过来**——这是英语区别于汉语「靠字典词性定终身」的思维习惯。

## 4 公式解析：七种基本句型

英语句子千变万化，但**主干结构只有七种基本句型（basic clause types）**。这是 Quirk《英语综合语法》给出的经典分类，也是把「成分」拼装成「句子」的全部配方：

$$
\begin{aligned}
\text{SVC} &\quad \text{She is } a\ teacher.\\
\text{SVA} &\quad \text{The sun rises } in\ the\ east.\\
\text{SV} &\quad \text{He } laughed.\\
\text{SVO} &\quad \text{She } loves\ music.\\
\text{SVOC} &\quad \text{We } elected\ him\ chairman.\\
\text{SVOA} &\quad \text{He } put\ the\ book\ on\ the\ desk.\\
\text{SVOO} &\quad \text{He } gave\ me\ a\ book.
\end{aligned}
$$
