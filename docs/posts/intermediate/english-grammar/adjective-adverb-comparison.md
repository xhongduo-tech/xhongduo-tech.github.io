## 为什么从形容词与副词开始

名词是句子骨架，形容词与副词则是给骨架「上色」的修饰系统：**形容词（adjective）**修饰名词（`a red apple`），**副词（adverb）**修饰动词、形容词、副词乃至整个句子（`runs fast`、`very red`、`luckily`）。如果说名词的功课在「形态」（数、格、性），形容词与副词的功课则在**「位置」**与**「等级」**：它们既要站对地方（定语还是表语、句中还是句尾），又要回答「修饰的程度」——`big`、`bigger`、`biggest` 的三级阶梯。比较等级（comparison）是这一节的核心，也是英语形容词副词最重要的「语法装置」：汉语说「更漂亮」「最漂亮」靠加字，英语靠词形变化或 `more/most`，规则与例外并存。<span class="marginnote">「等级」是个语义学概念：比较级标记「相对程度」，最高级标记「相对极值」。英语用<strong>词缀（-er/-est）</strong>与<strong>分析式（more/most）</strong>两种手段实现，选用哪套取决于音节的「身材」——这是本节最机械也最容易失分的地方。</span>

## 1 形容词：定语与表语的双重身份

形容词的核心功能是修饰名词，但在句中有两个不同的「站位」：

**定语（attributive position）**：直接放在名词前——`a happy child`、`the red car`。放在名词短语内部，是形容词的「默认位置」。

**表语（predicative position）**：放在系动词之后，说明主语的性状——`The child is happy.`、`The car looks red.`。此时形容词通过系动词（`be`、`become`、`seem`、`look`、`feel`、`taste`）与主语发生关系，是 SVC 句型里的主语补语。

**重点：** 绝大多数形容词两种位置都能站，但有少数「偏科生」。**只能作表语的形容词**（predicative-only）：`alive`、`afraid`、`alone`、`asleep`、`awake`——可以说 `The baby is asleep`，但不能说 `an asleep baby`（要说 `a sleeping baby`）。**只能作定语的形容词**（attributive-only）：`main`、`mere`、`utter`、`only`——可以说 `the main reason`，但 *The reason is main 不成立\*。**「身份决定站位」是形容词最重要的一条隐藏规则。**<span class="marginnote">这类「偏科」形容词多半是历史原因造成的：`asleep`、`alive` 源自古英语的介词短语（`a-` = 在……中），语义上偏「状态描述」，天然亲近表语位置。记忆时按「表示状态的 `a-` 开头词只作表语」这条线索成组记，事半功倍。</span>

**辨析｜易错点：** 形容词作定语时的**语序**也有讲究。多个形容词修饰同一名词时，大致按「限定词 → 数量 → 性质 → 大小 → 新旧 → 颜色 → 国籍 → 材料 → 用途 → 名词」排列：`a beautiful big new red Chinese wooden dining table`。考试与写作中，**「大小 + 颜色 + 国籍 + 名词」四件套**是最常考的子序列（`a small black Japanese car`）。

## 2 副词：给动词、形容词和句子化妆

**副词（adverb）**是修饰系统里最「多面手」的一个，按语义分五族：

| 副词类别 | 功能 | 例 |
| --- | --- | --- |
| 方式副词 | 修饰动词，说明「怎么做」 | `run fast`、`speak clearly` |
| 程度副词 | 修饰形容词或副词，说明「多深」 | `very hot`、`quite well` |
| 频度副词 | 说明「多经常」 | `always`、`usually`、`never` |
| 时间/地点副词 | 说明「何时何地」 | `yesterday`、`here`、`abroad` |
| 句子副词 | 修饰整个句子，表说话者态度 | `Fortunately`、`honestly`、`however` |

副词的位置相对灵活，但频度副词有相对固定的习惯位置：**在实义动词之前，在 `be` 动词与助动词之后**——`She always arrives early.`、`She is always kind.`、`I have never seen it.`<span class="marginnote">句子副词（如 `fortunately`、`actually`）常位于句首并用逗号隔开，作用相当于对整个命题表态——它是「情态意义」在副词层面的体现，与第2篇《情态动词与情态意义》形成呼应。</span>

**辨析｜易错点：** 形容词与副词的**形近异义**组合是高频考点：`hard`（努力地/坚硬的）与 `hardly`（几乎不）、`late`（迟）与 `lately`（最近）、`near`（近）与 `nearly`（几乎）、`high`（高）与 `highly`（高度地）。**带 `-ly` 的形式往往语义「偏离」了原词**——`He works hard.`（他努力工作）与 `He hardly works.`（他几乎不工作）意思完全相反。

## 3 比较等级的三级阶梯与构成规则

英语比较等级分**三级**：**原级（positive）**、**比较级（comparative）**、**最高级（superlative）**。`big — bigger — biggest`。构成规则以**音节数**与**词尾特征**为判据：

**规则构成**：

**单音节词**：加 `-er/-est`——`small → smaller → smallest`。
**以 `e` 结尾**：只加 `-r/-st`——`large → larger → largest`。
**重读闭音节（辅音+元音+辅音）**：双写末尾辅音——`big → bigger → biggest`、`hot → hotter`。
**以「辅音 + y」结尾**：改 `y` 为 `i` 加 `-er/-est`——`happy → happier → happiest`。
- **双音节词**：以 `-y`、`-er`、`-ow`、`-le` 结尾的常用词用词缀（`easy → easier`、`narrow → narrower`），其余双音节词多用 `more/most`（`more careful`）。
- **多音节词（≥3 音节）**：一律用 `more/most`——`more beautiful → most beautiful`。

**不规则构成**：数量少但高频，必须逐一记忆：

| 原级 | 比较级 | 最高级 |
| --- | --- | --- |
| `good/well` | `better` | `best` |
| `bad/ill` | `worse` | `worst` |
| `many/much` | `more` | `most` |
| `little` | `less` | `least` |
| `far` | `farther/further` | `farthest/furthest` |
| `old` | `older/elder` | `oldest/eldest` |

**辨析｜易错点：** 两组「同源双比较级」语义已分化：`farther/farthest` 表**实际距离**（`walk farther`），`further/furthest` 表**抽象程度**（`further discussion` 进一步讨论）；`older/oldest` 表**年龄大小**，`elder/eldest` 表**长幼关系**且只能作定语（`my elder brother`）。现代英语中 `further` 有吞并 `farther` 的趋势，但考试仍按严格区分。

## 4 比较句型：as…as 与 more…than 家族

比较等级不是孤立的词形，而是进入**句型**才发挥作用。比较句型分三大族：

**原级比较（as … as）**：表示「一样……」——`Tom is as tall as Jack.`；否定式 `not as/so … as` 表示「不如……」——`Tom is not as tall as Jack.`

**比较级比较（more … than）**：`This book is more interesting than that one.`；反向用 `less … than`（不如）。比较级前可加修饰语调节程度：`much / far / a lot / a little / even / still + 比较级`——`This box is much heavier than that one.`

**最高级**：`the + 最高级 + in/of/among`——`He is the tallest in his class.`（`in` 接范围）、`She is the best of all.`（`of` 接同类）；「最……之一」用 `one of the + 最高级 + 复数名词`——`It is one of the most beautiful cities in China.`<span class="marginnote">最高级前一般要 `the`（`the tallest`），但当最高级作表语且只与自身比较时，`the` 可省：`She is tallest in the morning.`（她早晨个子最高——与她自己不同时段比）。这个「比较对象决定冠词」的微妙差别，正是第1篇「词类与成分错位」精神的再现。</span>

**辨析｜易错点：** 两个比较级句型的变形：**「越……越……」结构**用 `the + 比较级, the + 比较级`——`The more you read, the more you know.`；**「两者中较……的一个」**用 `the + 比较级 + of the two`——`He is the taller of the two.`（注意这里即使是比较级也带 `the`）。这两种结构是最常考的「比较级特例」。

## 5 公式解析：比较级构成与「越……越……」

**比较级构成判定公式**：

$$
\text{比较级形式} = \begin{cases}
\text{词缀} -er & \text{单音节 / 部分双音节（}\ -y,\ -er,\ -ow\ \text{结尾）}\\
more + \text{原级} & \text{多音节 / 其余双音节}
\end{cases}
$$

对这条公式做三步拆解：

- **第一步，数音节**：`big`（1 音节）→ `-er`；`careful`（2 音节，非 `-y/-er/-ow`）→ `more`；`beautiful`（3 音节）→ `more`。**音节数是第一判据。**
- **第二步，查词尾**：单音节里再分三种微调——以 `e` 结尾只加 `-r`（`large → larger`）、重读闭音节双写辅音（`big → bigger`）、辅音 + `y` 改 `i`（`happy → happier`）。
- **第三步，对照不规则表**：`good/bad/many/little/far/old` 六组走「不规则表」，不走公式。**先查表，再套公式**是永远不会错的处理顺序。

**「越……越……」公式**：

$$
\text{The} + \text{比较级}_1,\ \text{the} + \text{比较级}_2 \quad\Rightarrow\quad \text{前件成立的程度越深，后件越强}
$$
