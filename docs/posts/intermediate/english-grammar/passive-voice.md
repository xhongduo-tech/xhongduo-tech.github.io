## 为什么从语态开始

时（tense）标记时间、体（aspect）标记状态、接下来是第三个动词范畴：**态（voice）**。语态回答的问题是「**谁当主语**」：动作的发出者（施事）当主语，是**主动语态（active voice）**；动作的承受者（受事）当主语，是**被动语态（passive voice）**。`The cat caught the mouse.`（猫抓了老鼠——主动）与 `The mouse was caught by the cat.`（老鼠被猫抓了——被动）描述同一件事，只是「镜头对准谁」不同。被动语态是中国学生最「顺手」也最「顺手错」的结构：它看似只是 `be + 过去分词` 的机械变换，实则牵扯时体搭配、句型变换与语篇选择。<span class="marginnote">奥威尔那句「绝不用被动」是<strong>文体劝诫</strong>，不是语法禁令：被动语态在科技写作、新闻报道与施事不明时完全正当。语态选择是「表达目的」问题，不是「对错」问题——这正是本节第 5 节要展开的内容。</span>

## 1 被动语态的构成：be + 过去分词

**被动语态 = `be` + 过去分词（+ `by` + 施事）**：

$$
\text{被动} = \underbrace{\text{be}}_{\text{时体载体}} + \underbrace{\text{过去分词}}_{\text{态载体}} + (\text{by} + \text{施事})
$$

`be` 携带时与体（`is`、`was`、`has been`、`is being`），过去分词标记「被动」这一语义。`The bridge was built (by the workers) in 1990.`——`was` 管过去时，`built` 管被动。

**重点：** 被动语态只适用于**及物动词**——只有「有宾语」的句子才有「宾语升格为主语」的资格。不及物动词（`happen`、`arrive`、`sleep`）没有宾语，也就没有被动形式：*`The accident was happened` 是典型错误（要说 `The accident happened`）。<span class="marginnote">这条「不及物动词无被动」规则的例外是「短语动词 + 介词」：`look at`、`laugh at`、`rely on` 这类「动词 + 介词」整体相当于一个及物动词，可以有被动——`The plan was relied on.`。介词在被动句中「悬空」（介词结尾），这是英语被动的独特景观。</span>

## 2 主动变被动的三步变换

把一个主动句变成被动句，只需三步：

$$
\underbrace{S}_{\text{施事}} + V + \underbrace{O}_{\text{受事}} \quad\Longrightarrow\quad \underbrace{O}_{\text{新主语}} + \underbrace{be + V\text{-ed}}_{\text{被动}} + (\text{by} + S)
$$

以 `Shakespeare wrote Hamlet.` 为例：

- **第一步，宾语升主语**：`Hamlet` 从宾语位置移到句首，成为新主语。
- **第二步，动词改被动**：原动词 `wrote` 按原时态变成 `be + 过去分词`——原句过去时，所以 `was written`。**时态保持不变，只是形态改成被动。**
- **第三步，主语降为 by 短语**：原主语 `Shakespeare` 变成 `by Shakespeare`，放在句末；**施事不明确或无需提及时，`by` 短语直接省略**——`Hamlet was written.`

**辨析｜易错点：** 变换中最易错的是**时体搭配**：被动句的 `be` 必须与主动句的时体完全一致。`They are building a bridge.`（现在进行）→ `A bridge is being built.`（`is being built`）；`They have finished the work.`（现在完成）→ `The work has been finished.`（`has been finished`）。**「主动的时体是什么，被动的 `be` 就长什么样」**——尤其是 `is being done`（进行被动）与 `has been done`（完成被动）这两种形态最易出错。

## 3 被动语态 × 时体 × 情态：全形态表

被动语态可以与时、体、情态自由组合，生成一张全形态表。以动词 `build` 为例：

| 时体 | 主动 | 被动 |
| --- | --- | --- |
| 一般现在 | `builds` | `is built` |
| 一般过去 | `built` | `was built` |
| 现在进行 | `is building` | `is being built` |
| 过去进行 | `was building` | `was being built` |
| 现在完成 | `has built` | `has been built` |
| 过去完成 | `had built` | `had been built` |
| 将来（will） | `will build` | `will be built` |
| 情态 | `must build` | `must be built` |

**重点：** 观察表里的规律——**被动形态永远比主动多一个 `be` 的「层」**：主动 `is building`（进行）→ 被动 `is being built`（`is` + `being` + 过去分词）；主动 `has built`（完成）→ 被动 `has been built`（`has` + `been` + 过去分词）。这个「多一层 `be`」的规律，可以帮你从主动形态直接推导被动形态。<span class="marginnote">把这张表与《动词的分类与主要动词句型》第 5 节的「动词短语组装公式」对照看：被动 `be` 恰好插入在情态/完成/进行与主动词之间——`has been being built`（完成 + 被动 + 进行）这类「多层叠」句正是两节知识点的交汇。</span>

**辨析｜易错点：** 一般将来时在中国教学语法里常写 `will be done`，但 `be going to be done`、`have to be done` 等半助动词结构同样常用：`The work is going to be finished tomorrow.`。**记住「情态/半助动词后接 `be + 过去分词`」即可通吃。**

## 4 特殊句型的被动化

有些句型变被动时有「坑」，需要单独处理：

**双宾语句型（SVOO）**：`He gave me a book.` 有两个宾语，可以生成**两种**被动句——间接宾语作主语（更常用）：`I was given a book (by him).`；直接宾语作主语：`A book was given to me (by him).`。**「给书」把 `me` 或 `a book` 谁推上主语位都行**，但「人作主语」的被动（`I was given...`）在英语中明显更自然。

**复合宾语句型（SVOC）**：`We elected him chairman.` 变被动时，**宾语 `him` 升为主语，宾语补语 `chairman` 变成主语补语**：`He was elected chairman.`——注意补语仍留在动词后，不需要 `by`。

**短语动词的被动**：`They laughed at him.` → `He was laughed at.`——介词 `at` 留在句末，这就是第 1 节说的「介词悬空」。<span class="marginnote">「介词悬空」在规范语法史上曾有争议（18 世纪曾被视为粗俗），如今已是完全标准的用法——`What is this made of?`、`He is a man to be relied on.`。这条「从被禁到规范」的演变，是语法规范随语言实际使用而漂移的活例证。</span>

**辨析｜易错点：** 三类动词**不能**变被动：**不及物动词**（`happen`、`occur`）、**系动词**（`be`、`become`、`seem`——*`A teacher is been by her` 不成立）、**宾语为反身代词/相互代词/同源宾语**的句子（*`Himself was hurt by him` 不成立，要还原为主动 `He hurt himself.`）。

## 5 语态选择：什么时候用被动

被动语态不是主动的「影子」，它有主动无法替代的语篇价值。什么时候该选被动？

**施事不重要或未知**：`The window was broken last night.`（谁打碎的不知道/不重要）。
**施事显而易见**：`He was born in 1990.`（施事必然是母亲，无需说）。
**受事需要强调**：`Your proposal was rejected.`（重点在「提案被拒」这件事，而非谁拒的）。
**科学/学术/科技文体**：`The mixture was heated to 80 °C.`——科技英语追求客观、非人化，被动是标准配置。
**行文衔接**：`My car was stolen. The thief was arrested the next day.`——被动让前后句的主语（car → thief）自然衔接。<span class="marginnote">学术写作的「被动偏好」并非绝对：现代科学写作越来越鼓励「主动 + 我们」来提升可读性（`We heated the mixture...`）。被动与主动的取舍，本质是「客观性 vs 可读性」的权衡——这与中文「被字句」在科技文体的使用逻辑高度相似。</span>

**辨析｜易错点：** 被动语态不改变**时体意义**，但会改变**句子的信息重心**：`The police arrested the thief.`（焦点在警察的行动）与 `The thief was arrested.`（焦点在贼的下场）。**选择被动，就是在告诉读者「谁值得当主语」**——这是语态选择的本质。
