## 为什么从常微分方程开始

上一节我们把连续模型搬上台面：$y' = f(t, y)$。现在要给它动真格。连续世界里，**大多数物理、化学、生态规律都以「变化率与当前状态的关系」的形式被写出来**——牛顿第二定律 $F = ma$ 写成 $m y'' = F$，化学反应的速率与浓度相关，尸体冷却的速度与温差相关。这些「规律」本身就是微分方程。数学建模在这里扮演的角色是：把一条定律翻译成方程、配好初始条件、解出行为、再拿现实核对。这一篇用一阶常微分方程（ODE）打满全场——它们是你能手解、能直觉化、能立刻拿去建真实模型的入门套餐，也是下一节《人口、生态与传染病模型》里方程组的地基。

## 1 一条定律的建模：牛顿冷却定律

先看一条 1701 年的定律。牛顿发现：**一个物体的温度变化率，与它和周围环境的温差成正比**。<span class="marginnote">直觉版本：沸水刚端上桌「滋滋冒气」凉得飞快，到 40°C 时半天也不降一度——因为温差小了，驱动力小了。牛顿把这条直觉写成了方程。</span>

设物体温度 $T(t)$，环境温度 $T_e$ 恒定，则

$$
\frac{dT}{dt} = k\,(T - T_e)
$$

其中 $k$ 是比例常数。注意：**冷却时 $T > T_e$，而温度在下降，所以 $dT/dt < 0$，于是 $k$ 必须是负数**。<span class="marginnote">这个符号检查是初学者最容易摔的坑：正负号不是数学装饰，它是物理方向。写方程时先问一句「它在变大还是变小」，符号就不会错。</span>

这条方程已经够格当一个「模型」：它有两个假设（温差是唯一驱动力、$T_e$ 恒定），一个参数 $k$，一个初始条件 $T(0) = T_0$。剩下的工作，是解它、用它回答问题。

## 2 求解：分离变量法

这类方程叫**可分离变量（separable）**方程，解法只有机械的四步。把 $dT/dt = k(T - T_e)$ 改写成分离形式：

$$
\frac{dT}{T - T_e} = k\, dt
$$

两边积分：$\ln|T - T_e| = kt + C$，再取指数：

$$
T(t) = T_e + (T_0 - T_e)\, e^{kt}
$$

再解一个物理味更浓的：物体下落，阻力与速度成正比，$m \frac{dv}{dt} = mg - kv$。改写为 $\frac{dv}{mg - kv} = \frac{dt}{m}$，分离变量积分得 $v(t) = \frac{mg}{k}\left(1 - e^{-(k/m)t}\right)$。$t \to \infty$ 时 $v \to mg/k$——**终极速度（terminal velocity）**。跳伞运动员的平衡速度就是这样算出来的：不再加速，重力被阻力吃平。

把「现象 → 方程 → 解」的映射做成一张常用速查表，是建 ODE 模型的第一步：

| 现象 | 方程 | 解的行为 |
| --- | --- | --- |
| 无限制增长 | $dP/dt = rP$ | 指数 $P_0 e^{rt}$ |
| 受上限增长 | $dP/dt = rP(1-P/M)$ | S 形，趋于 $M$ |
| 冷却/衰变 | $dT/dt = k(T-T_e)$ | 指数趋向 $T_e$ |
| 落体含阻力 | $m\,dv/dt = mg - kv$ | 趋于终极速度 $mg/k$ |
| 放射性衰变 | $dN/dt = -\lambda N$ | 半衰期 $T_{1/2} = \ln 2/\lambda$ |

同一个数学结构，一遍管冷却、一遍管放射、一遍管药物浓度——**一个方程，成串现象**。

**求解的要点在于「把变量分到等号两侧」：温度在一边，时间在一边，然后各积各的。**<span class="marginnote">分离变量法是整个 ODE 课程里最常用的入门刀法。判断标准很机械：能改写成 $\dfrac{dy}{dx} = g(x)h(y)$ 就能分离。这个模式在第二级《常微分方程》里会系统展开，今天先让它登场一次。</span>

**易错点｜辨析：** 分离变量时「分母不能为 0」必须检查。$T(t) \equiv T_e$（物体一开始就在环境温度）是方程的一个特解，而分离变量的推导要除以 $T - T_e$，这一步会悄悄丢掉它。解方程时先列特解、再积分，是防止丢解的常规动作。

## 3 公式解析：牛顿冷却解的行为

解 $T(t) = T_e + (T_0 - T_e)e^{kt}$ 藏着三个信号，逐步拆开：

- **第一步，认结构**：解 = 环境温度 $T_e$ + 温差初值 $(T_0 - T_e)$ 乘一个指数衰减因子 $e^{kt}$。系统先快后慢地「贴着」环境温度逼近。
- **第二步，看极限**：因 $k<0$，$t\to\infty$ 时 $e^{kt}\to 0$，故 $T(t)\to T_e$。**模型的终点是环境温度，这是物理世界的必然**——解自动复现了「热平衡」这一事实，是模型自洽的强证据。
- **第三步，估参数**：量出两次温度与对应时刻，就能反解 $k$。假设咖啡 $90°\text{C}$ 倒入 $20°\text{C}$ 房间，10 分钟后降到 $50°\text{C}$：$\ln\frac{30}{70} = 10k$，得 $k \approx -0.0847 \,\text{min}^{-1}$。于是 20 分钟后 $T \approx 20 + 70\,e^{-1.694} \approx 32.8°\text{C}$——**模型从两个实测点长出了一整条预测曲线**。

建模里这最后一步叫**参数估计**：定律给形状，数据给参数。上一节《拟合、回归与插值》的最小二乘，到这里就成了给 $k$ 定值的标准工具——两篇在此合流。

**易错点｜辨析：** $k$ 的单位是「时间倒数」，取决于你计时用分钟还是小时。把分钟换成小时，$k$ 数值直接变小 60 倍——**模型的结果必须换算到与数据同一套时间单位**，否则预测差一个数量级。

## 4 平衡点与稳定性：不解方程也能读走势

牛顿冷却这样的方程还不用解，就能读出它未来的格局。**平衡点（equilibrium / fixed point）**：使右端为零的状态，$dT/dt = 0 \Rightarrow T = T_e$。解一出来，平衡点就是它的极限。

再看一个更「不听话」的例子，**逻辑斯蒂（logistic）方程**：

$$
\frac{dP}{dt} = k P \left(1 - \frac{P}{M}\right)
$$

它描述带资源上限 $M$ 的种群：$P$ 小时近似指数增长（括号≈1），$P$ 接近 $M$ 时增长被「刹车」压向零。平衡点是 $P=0$ 与 $P=M$。<span class="marginnote">$P=0$ 是<strong>不稳定</strong>平衡点：稍微偏离一点，种群就会重新长回去（除非彻底灭绝）。$P=M$ 是<strong>稳定</strong>平衡点：无论从上面还是下面逼近，都被拉回 $M$。这种「哪是稳态、能不能守住」的分析，是微分方程建模最值钱的部分——第三级《动力系统》会把它升级成完整理论。</span>

**判定局部稳定性的朴素办法：在平衡点附近取一个微小偏离，看解是回来还是跑走。** 跑走的叫不稳定，回得来的叫稳定——这个直觉今天先用着，严格化留给《常微分方程》专题。

用数值把「稳定 vs 不稳定」钉牢。logistic 方程 $dP/dt = 0.5 P(1 - P/100)$，平衡点 $P^* = 100$。取 $P(0) = 90$：$dP/dt = 0.5 \times 90 \times 0.1 = 4.5 > 0$，种群爬向 100；取 $P(0) = 110$：$dP/dt = 0.5 \times 110 \times (-0.1) = -5.5 < 0$，种群滑回 100。**无论从哪个方向靠近，都被拉回承载力——这就是稳定平衡点的工作方式。**

**为什么稳定性值得单开一节？** 因为建模最常犯的错误，是算出一条「平衡点」却以为它会自动发生。平衡点只回答「停在哪」，稳定性回答「守不守得住」。一个不稳定的平衡点（比如种群 $P = 0$）理论上存在，现实中却几乎不可能待在上面——**建模报告写平衡点，必须同时写稳定性**。

## 5 建 ODE 模型的三道工序

把前面所有动作收成可复用的工序：

1. **写规律**：把定律翻译成 $y' = f(t,y)$，注意单位、符号与参数含义。规则：**先定性问方向（增/减），再定量写系数**。
2. **配定解条件**：初值 $y(t_0) = y_0$ 把一族解**筛成一条**。同一方程不同初值给出不同的曲线，初值错全盘错。<span class="marginnote">一个微分方程的解是一整族曲线（通解），定解条件像一张「出入证」只放行一条。这就是为什么建模报告里，初值必须和方程一起写、一起核。</span>
3. **验证与迭代**：解出来之后回到现实——极限是否符合常识？中间行为是否违反物理？不符合就回到假设去改模型。牛顿冷却的假设（$T_e$ 恒定）在咖啡凉透之后就不再成立，模型也该在适当范围收手。

**易错点｜辨析：** 不是所有 ODE 都像牛顿冷却能「漂亮地解出来」。很多真实模型（比如摆的大角度运动、摆锤的混沌）求不出闭式解——这时出路不是放弃，而是用上一节的 Euler 法做数值解，或者靠平衡点分析读定性行为。**解不出的方程照样是有用的模型。**

把解一阶 ODE 的三种主流手法并排，各管一块：

| 手法 | 适用形式 | 关键一步 |
| --- | --- | --- |
| 分离变量 | $\dfrac{dy}{dx} = g(x)h(y)$ | 移项、两边各自积分 |
| 积分因子 | $y' + p(x)y = q(x)$ | 乘 $\mu = e^{\int p\,dx}$ 化成 $(y\mu)' = q\mu$ |
| 数值法（Euler） | 任何一阶 ODE | 差商代替导数，逐步外推 |

**术语速查**：一阶 ODE（只含一阶导）；可分离变量（$\dfrac{dy}{dx} = g(x)h(y)$）；通解（一族曲线）与特解（一条曲线）；初值问题（方程 + 定解条件）；平衡点（右端为零）；稳定/不稳定平衡点；终极速度 $mg/k$；半衰期 $T_{1/2} = \ln 2/\lambda$。

## 6 小结

- 连续世界的规律天然是微分方程：$y' = f(t,y)$，建模从「写规律」开始。
- **牛顿冷却定律** $dT/dt = k(T-T_e)$：分离变量解得 $T(t) = T_e + (T_0 - T_e)e^{kt}$；$k<0$，$t\to\infty$ 趋于环境温度。
- **符号与单位**是 ODE 建模的两大杀手：先判方向再定符号，先统一单位再算数值。
- **平衡点与稳定性**：右端为零的状态是平衡点；微扰偏离后回来→稳定，跑走→不稳定；不解方程也能读走势。
- 建模工序：写规律 → 配初值 → 验证迭代；解不出的方程可用数值法与定性分析。
- 落体含阻力模型：$m\,dv/dt = mg - kv$，解趋于**终极速度** $mg/k$——平衡即稳态。
- 手法对照：**分离变量、积分因子、数值法（Euler）**三足鼎立，按方程形式选用。

在下一节，当模型里的量不再确定、而是「随机」时，数学要换一副眼镜。我们进入不确定性建模——**概率与蒙特卡洛模拟**。
