## 为什么从拟合开始

上一节的鲸鱼体重问题，我们拍脑袋假设了「重量 ∝ 长度³」。但现实里数据很少这么听话：测了 20 头鲸，长度和重量不会正好落在一条曲线上。这时建模者要回答的问题是：**从一堆带着噪声的数据里，怎么挖出一条「最能代表」它们的关系？** 这就是拟合与回归。而如果数据点是精确的（比如物理实验的理论值、工程图纸上的坐标），我们又想把点之间的曲线精确补出来——那是插值。一个把噪声磨平，一个把缺失补齐，方向相反却同属「从数据造函数」。这一篇是后续所有模型——微分方程、线性规划、时间序列——里「读数据」这一环的标准动作。

## 1 从数据到模型：先看形状

面对一组数据 $(x_i, y_i)$，第一步永远是**画散点图，用眼睛猜关系的形式**。先别急着套公式。<span class="marginnote">统计学家会开玩笑说「先画图，再谈检验」。数据像不像一条直线？像指数曲线？像幂曲线？形式猜对了，后面系数再估计也是对的形状；形式猜错了，系数再准也是错的方向。</span>

- 点在一条直线附近 → **线性关系** $y = a + bx$
- 增长越来越快，几乎垂直向上 → 可能是**指数关系** $y = a b^x$ 或幂关系 $y = a x^b$
- 先升后平（渐近线）→ 可能是**对数或分式**关系，也常见于生态与传染病的饱和段

指数与幂关系有一个利器叫**线性化（linearization）**：对 $y = a x^b$ 两边取对数，得

$$
\ln y = \ln a + b \ln x
$$

这就是以 $\ln x$ 为自变量、$\ln y$ 为因变量的**直线**。于是幂关系、指数关系都能先取对数、再用下面要学的线性回归一把解决——**很多非线性问题，一个对数变换就变成线性问题**。

## 2 最小二乘：让「误差平方和」最小

假设我们已经决定用直线 $y = a + bx$ 近似数据。**误差（error / residual）** 是实际值与拟合值之差：$e_i = y_i - (a + bx_i)$。单纯求和会让正负误差互相抵消，所以**最小二乘（least squares）**采用误差平方和作为目标：

$$
S(a, b) = \sum_{i=1}^{n} \left[y_i - (a + bx_i)\right]^2
$$

**找 $a,b$ 使 $S$ 取最小值**，这就是「回归」一词的操作定义。<span class="marginnote">「回归」这个词来自高尔顿（Francis Galton）1886 年关于身高的研究：高个父母的后代身高有「向均值回归」的倾向。回归分析这个说法从此沿用至今，虽然它的数学含义已经大不相同。</span>

为什么选平方而不是绝对值？因为 $S$ 是 $a,b$ 的二次函数，**可微、凸、处处光滑**，最小值点可以通过求偏导为零精确解出——这正是下一节的公式解析。

**易错点｜辨析：** 最小二乘假设误差大致「随机对称」，它不适合有明显系统性偏离的数据（比如异方差、有界数据的饱和段）。平方又让**离群点**的惩罚被放大——一个异常点可以霸道地拉动整条直线。所以先画图、先看离群点，再拟合。

## 3 插值：把点与点之间的空缺精确补上

与拟合不同，**插值（interpolation）**要求曲线**恰好穿过每一个已知数据点**。其基本定理是：

**给定 $n+1$ 个横坐标互不相同的点 $(x_0,y_0),\dots,(x_n,y_n)$，恰好存在唯一的次数不超过 $n$ 的多项式 $P(x)$，使得 $P(x_i) = y_i$ 对所有 $i$ 成立。**<span class="marginnote">这个唯一性很漂亮：$n+1$ 个条件（穿点）恰好确定 $n+1$ 个系数（多项式系数），一个不多一个不少。这是线性方程组「方程数与未知数相等」的经典场景。</span>

拉格朗日（Lagrange）给出了一种显式写法。先对每个 $i$ 造一个「只在 $x_i$ 处取值 1、其余取样点处取值 0」的基多项式：

$$
L_i(x) = \prod_{j \neq i} \frac{x - x_j}{x_i - x_j}
$$

再把它们按目标值加权拼起来：

$$
P(x) = \sum_{i=0}^{n} y_i\, L_i(x)
$$

**易错点｜辨析：** 插值多项式虽然穿过所有点，次数太高时会在端点附近剧烈振荡，这叫 **Runge 现象**——著名的例子是用高次多项式插值 $1/(1+25x^2)$ 的等距采样点，端点附近插值误差爆炸。<span class="marginnote">Runge 现象（1901）是数值分析里最有名的反直觉事实之一：插值点越多，多项式未必越接近原函数。补救办法是改用分段的低次插值（样条），或取切比雪夫节点。这直接通向第三级《数值分析》。</span>插值的正确使用场景是：数据本身精确、只需要补齐点之间的值；数据有噪声时，插值会把噪声当宝贝一样穿过——这时该用拟合。

**术语速查**：残差 $e_i = y_i - \hat y_i$（实际值与拟合值之差）；决定系数 $R^2$（解释力度）；插值节点 $x_i$（曲线穿过的横坐标）；样条（分段低次插值）；正规方程（最小二乘导出的线性方程组）；线性化（对数变换把幂/指数关系变直线）。

## 4 公式解析：最小二乘的正规方程

把 $S(a,b)$ 对 $a$、对 $b$ 求偏导并令其为零，就得到一组关于 $a,b$ 的线性方程，叫作**正规方程（normal equations）**：

$$
\begin{cases}
\displaystyle \sum y_i = n a + b \sum x_i \\[6pt]
\displaystyle \sum x_i y_i = a \sum x_i + b \sum x_i^2
\end{cases}
$$

推导只有两步：

- **第一步，对 $a$ 求偏导**：$\dfrac{\partial S}{\partial a} = -2\sum (y_i - a - bx_i) = 0$，除以 $-2$ 后展开得 $\sum y_i = n a + b\sum x_i$。
- **第二步，对 $b$ 求偏导**：$\dfrac{\partial S}{\partial b} = -2\sum x_i (y_i - a - bx_i) = 0$，展开得 $\sum x_i y_i = a\sum x_i + b\sum x_i^2$。

因为 $S$ 是凸二次函数，这两条方程的解就是全局最小值点——**不需要试探，直接解线性方程组**。算一个具体例子，数据 $(1,3.1),(2,4.9),(3,7.2),(4,8.8)$：

- $\sum x = 10,\ \sum y = 24,\ \sum x^2 = 30,\ \sum xy = 69.7,\ n = 4$
- 方程组：$24 = 4a + 10b$，$69.7 = 10a + 30b$
- 解得 $b = 1.94$，$a = 1.15$，拟合直线 $y \approx 1.15 + 1.94x$。

拟合的直线已经不只是「画出来好看」，它具备**预测力**：往 $x = 6$ 代入，$y \approx 12.8$。这正是上一节五步法里「求解 → 回答问题」的延续——**拟合的终点是预测**。

衡量这条直线「解释了数据多少变化」，用**决定系数（coefficient of determination）** $R^2 = 1 - \dfrac{\sum (y_i - \hat y_i)^2}{\sum (y_i - \bar y)^2}$：$R^2$ 接近 1 表示残差远小于总波动，拟合贴近；接近 0 表示直线几乎没有解释力。它是回归报告里与系数配套的标准数字，正规方程一解出来，顺手就算。

**易错点｜辨析：** 高 $R^2$ 不等于关系成立。两个无关序列（如年份与某销量）也可以有很高的 $R^2$，因为线性外推总能把散点「拉直」——**先问机制，再看 $R^2$**，顺序不能反。

## 5 拟合 vs 插值：一张对照表

把两条路线并排看，决策就清楚了：

| 判据 | 最小二乘拟合 | 多项式插值 |
| --- | --- | --- |
| 目标 | 误差平方和最小 | 恰好穿过每个数据点 |
| 适用数据 | 有噪声、存在测量误差 | 精确、必须复现的点 |
| 模型形式 | 可任意选（线性/幂/指数） | 次数 ≤ $n$ 的唯一多项式 |
| 预测区间外 | 可以外推（需谨慎） | 外推极不可靠 |
| 主要风险 | 离群点被放大、欠拟合 | Runge 现象、过拟合 |

**核心判断规则：有噪声 → 拟合；必须穿点 → 插值。** 两者常在同一问题里接力：先用拟合定出全局趋势，再用分段插值（样条）补细节。<span class="marginnote">机器学习里的「过拟合」本质就是「把噪声也当成了规律」——与高次插值的 Runge 现象同一病根。这一思想在你学第三级《机器学习》时会被反复敲打：模型要的是对规律的概括，不是对样本的死记。</span>

如果数据点很多，逐点的高次多项式插值既振荡又昂贵，工程上几乎只用**分段三次样条（cubic spline）**：每两个节点之间是一段三次多项式，接头处一阶、二阶导数连续，整条曲线光滑流畅——CAD 曲面、字体轮廓、动画缓动曲线全是它。样条把「全局高次」换成「局部低次」，Runge 现象随之消失，代价是表达式不再是一个多项式，而是一张「每段一个系数」的表。

## 6 小结

- **先画散点图再选形式**：线性、指数、幂，可用对数变换把非线性问题线性化。
- **最小二乘**：令误差平方和 $S$ 最小，因 $S$ 凸且光滑，求偏导得**正规方程**，解方程组即得最优 $a,b$。
- **插值**：$n+1$ 个点唯一确定次数 ≤ $n$ 的多项式；拉格朗日形式 $P(x)=\sum y_i L_i(x)$ 显式给出。
- **拟合 vs 插值**：有噪声用拟合（磨平噪声、外推预测），必须穿点用插值（警惕 Runge 现象与过拟合）。
- 拟合的终点是**预测**：把模型带出数据范围回答问题，是五步法第五步的落地。

在下一节，我们终于要把时间引入模型，让「下一个时刻」和「这一时刻」对话——时间取离散刻度还是连续刻度，将导出两种长相不同、血脉相连的模型：**离散与连续模型**。
