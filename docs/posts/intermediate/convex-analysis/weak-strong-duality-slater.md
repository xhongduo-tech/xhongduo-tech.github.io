## 为什么从强对偶开始

上一节证明了弱对偶 $d^* \le p^*$——对偶值永远是原值的下界。
但工程上真正值钱的是**等式** $d^* = p^*$：
那时求解对偶问题 = 求解原问题，且能拿到 KKT 条件、可分解结构、以及「对偶变量 = 影子价格」的全部红利。
什么时候等式成立？对**凸问题**，在温和的**约束规格**下——最著名的就是 **Slater 条件**——强对偶必然成立。
<span class="marginnote">在「从极限到大模型」主线上，SVM、LASSO、带约束回归的「对偶解法」全部依赖强对偶：没有它，对偶解就不是原解。
而 Slater 条件在工程里几乎总是被满足——只需存在一个「严格可行」的点，
即约束全部被严格满足。
</span>

## 1 弱对偶与对偶间隙

**弱对偶（weak duality）**：
$d^* \le p^*$ 恒成立（上一节已证，
无需任何假设）。

**对偶间隙（duality gap）**：
$p^* - d^* \ge 0$。
<span class="marginnote">对偶间隙度量「原问题与对偶问题之间的缝隙」。
对任何对偶可行点 $(\lambda, \nu)$，
$f(x) - g(\lambda,\nu) \ge 0$ 给出一个<strong>可计算的间隙</strong>：
把它当停机准则，就能在不知道 $p^*$ 的情况下给出「当前解离最优多远」的确定性上界——这是分支定界与对偶界方法的基石。
</span>

**重点：** 弱对偶与对偶间隙**不需要任何凸性**。
即便原问题非凸，对偶间隙也非负，且间隙本身携带信息——它告诉我们对偶松弛「损失了多少」。

## 2 强对偶

**强对偶（strong duality）**：
$d^* = p^*$，即对偶间隙为零。
<span class="marginnote">强对偶的几何本质（Rockafellar 视角）：原问题的最优值对应「目标上图与约束构成的集合」的支撑；
对偶问题则从「对偶方向」去看同一个几何对象。
强对偶意味着从两个方向看到的是同一条支撑线——这正是分离定理「两个不相交凸集可被超平面分开」的推论。
</span>

对一般（非凸）问题，强对偶**不一定成立**——例如非凸目标可能有非零对偶间隙。
但对**凸问题**，在约束规格下强对偶成立。
最常用、最简单的约束规格就是 Slater 条件。

**辨析｜易错点：** 强对偶对凸问题也**不是无条件**的。
病态的凸问题（如可行域只有边界、无相对内部点）可以 $d^* \lt  p^*$。
**「凸 ⟹ 强对偶」是错觉**；
正确的是「凸 + Slater（或其他约束规格）⟹ 强对偶」。

## 3 Slater 条件

**Slater 条件**：存在一个点 $x \in \operatorname{relint}(\operatorname{dom} f)$ 使

$$g_i(x) \lt  0, \qquad i = 1, \dots, m$$

即存在**严格可行点**——所有不等式约束被**严格**满足（等式约束不变）。<span class="marginnote">Slater 条件的直观：可行域必须有「肉」（内部），不能只是一层薄壳。它排除了「可行域退化到只有边界」的病态情形——那种情形下支撑超平面可能恰好「贴边」，对偶间隙非零。相对内部 $\operatorname{relint}$ 的使用（第3节）让低维可行域也能用。</span>

**松弛版本**：若某些不等式约束是**仿射**的（$g_i(x) = a_i^T x - b_i$），则只要求这些仿射约束**非严格**可行（$\le 0$）即可，Slater 条件只对**非线性**不等式要求严格。这条放松很重要——线性规划的可行域没有严格内点时（如超平面本身），强对偶依然成立。

**重点：** Slater 条件（对凸问题）⇒ 强对偶 $d^* = p^*$，且**对偶最优解可达到**（存在 $(\lambda^*, \nu^*)$ 取到 $d^*$）。「可达到」这一条非常关键：它不仅说值相等，还说最优对偶变量**存在**——KKT 条件的全部用途都建立在这上面。

## 4 公式解析：用分离定理看强对偶

设原问题凸、Slater 条件成立，用「几何版本」快速理解为什么 $d^* = p^*$。定义集合

$$\mathcal{A} = \{ (g(x), h(x), f(x)) \mid x \in \operatorname{dom} f \} + \mathbb{R}^m_+ \times \{0\}^p \times \mathbb{R}_+$$

（把「比某个 $x$ 更差」的点也并进来）。

- **第一步，最优值的位置**：$p^* = \inf\{ t \mid (u, v, t) \in \mathcal{A}, u \le 0, v = 0 \}$——原问题是在 $\mathcal{A}$ 上找「约束非正、等式为零」的最小 $t$。
- **第二步，凸性**：$f, g_i, h_j$ 凸（等式 $h$ 仿射），$\mathcal{A}$ 是凸集。
- **第三步，分离**：$p^*$ 对应的点 $(0, 0, p^*)$ 是 $\mathcal{A}$ 的边界点，用支撑超平面把它与「更好的点」$(0,0,p^*-\epsilon)$ 分开——分离超平面给出法向量 $(\lambda, \nu, 1)$，其中 $\lambda \ge 0$（因 $\mathcal{A}$ 沿 $\mathbb{R}^m_+$ 方向扩展）。
- **第四步，读成对偶**：分离不等式恰好就是「$g(\lambda,\nu) \ge p^*$」；结合弱对偶 $g(\lambda,\nu) \le p^*$，得 $d^* = p^*$。Slater 条件保证支撑超平面确实存在且 $\lambda$ 非负。

**这条几何证明把「强对偶」归结为「分离定理」**——对偶间隙非零的情形，
正是分离超平面「贴不到」的病态几何（可行域无内点）。

## 5 强对偶的实例与反例

强对偶成立与否，用两个例子一正一反看清边界：

**成立例：带等式约束的最小二乘。**
$\min \|x - a\|^2$ 满足 $c^T x = b$。
这是凸问题，可行域是超平面（非空），相对内部就是它自己——Slater 条件（对仿射等式约束自动满足）成立，
强对偶 $p^* = d^*$ 无条件成立。
事实上这个问题的对偶可以闭式解出：$\nu^*$ 调节约束的拉格朗日乘子，
最终 $p^* = \|a\|^2 - \frac{(c^T a - b)^2}{\|c\|^2}$。
<span class="marginnote">这个例子的要点：<strong>线性（仿射）约束天然满足强对偶的约束规格</strong>——不需要严格内点。
这也是 LP 强对偶无条件成立（第28节）的根源：
多面体可行域的相对内部条件自动满足。
</span>

**反例：强对偶可以失败（非凸）。**
$\min e^{-x}$ 满足 $x \le 0$ 且「$x$ 只能取整数」。
非凸（整数约束）导致对偶间隙。
更干净的反例：$\min x^2$ 满足 $x \le -1$ 且 $x \ge 1$——这个约束系统**不可行**，
但 Slater 显然不适用；
对偶问题给出一个「伪下界」，与原问题最优值 $+\infty$ 之间出现间隙。
<span class="marginnote">不可行情形下强对偶的讨论要进入「扩展值」域：$p^* = +\infty$ 而对偶可能给有限值。
<strong>强对偶定理要求「原始可行且有界 + Slater」这类前提——先检查可行性，再谈对偶。
</strong></span>

**凸但 Slater 不满足的例子。**
考虑 $\min x$ 满足 $x^2 \le 0$。
约束集只有 $\{0\}$（没有严格可行点 $x^2 \lt  0$），
Slater 不满足，但强对偶仍然成立（$p^* = 0 = d^*$）——**Slater 是充分条件，
不是必要条件**。
真正 Slater 失败且强对偶也失败的凸例子需要更病态的构造（如无穷维或退化多面体），
在有限维光滑情形很少见。
<span class="marginnote">「Slater 充分但不必要」是重要分寸：Slater 给出<strong>最方便检查</strong>的充分条件；
实际中即使 Slater 不满足，强对偶也常常成立。
工程上：先检查 Slater，不满足时不要慌，
多数时候强对偶还是成立，但<strong>对偶最优解可能不存在</strong>。
</span>

**辨析｜易错点：** **Slater 保证的是「存在对偶最优解」**，
这是比「$d^* = p^*$」更强的结论。
有些问题强对偶值相等但最优对偶变量不存在（sup 取不到）——这时 KKT 条件无从谈起。
**判断能否用 KKT，问的不是「强对偶成立吗」而是「对偶最优可达吗」**——后者才是 KKT 的前提。

## 6 小结

- **弱对偶** $d^* \le p^*$ 无条件成立；**对偶间隙** $p^* - d^* \ge 0$ 可作停机准则。
- **强对偶** $d^* = p^*$：对凸问题在约束规格下成立，对非凸问题一般不成立。
- **Slater 条件**：存在严格可行点 $g_i(x) \lt  0$
