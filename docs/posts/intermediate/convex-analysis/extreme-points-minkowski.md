## 为什么从极值表示开始

三角形由三个顶点决定，正十二面体由二十个顶点决定——**凸集能否用少数「骨架点」完全重建？** 答案是肯定的，这就是**极值表示理论**：紧凸集是它全部极点的凸包。它把「无穷多个点的集合」压缩成「一族关键点」，是线性规划单纯形法（顶点间移动）、对偶极值对应、以及机器学习里支撑向量的共同几何。<span class="marginnote">极值点的直觉：<strong>极点就是凸集的「角」</strong>——三角形三个顶点、立方体八个角、球面上每个点都是极点（球没有角，处处都是「顶点」）。关键是：极点不一定要有「角」，凡是「不能被写成另外两点的中点」的点都是极点。</span>这一篇把第1篇的凸包与 Carathéodory 理论、第5篇的 KKT 活动集思想，收拢成第7篇的「极值表示」综述。

在「从极限到大模型」的课程里，极值表示是「低维 → 高维」的桥梁：极限给了我们一维的函数观，这一篇则在 $\mathbb{R}^n$ 里告诉你「一个高维凸集可以用它最省的一组点理解」。这也是机器学习里「支撑向量」思想的几何源头。

值得注意的是，极值表示是**有限维凸几何与无穷维泛函分析的分水岭**。Minkowski 定理在有限维里说「紧凸集 = 极点的凸包」；而在无穷维，同样的结论要放宽为「紧凸集 = 极点的**闭**凸包」，且只有「紧致」的凸集才敢这么讲——这就是 Krein–Milman 定理小心翼翼写下的条件。<span class="marginnote">Krein–Milman 定理：局部凸拓扑向量空间中，紧致凸集的每个点都是极点的闭凸组合。之所以要加「闭」，是因为无穷维里需要取极限才能「拼回」全部点；有限维里有限组合就够，闭包多此一举。</span>这一界线正是泛函分析（第二级《泛函分析》）与凸分析衔接的接口。

## 1 极点与极值方向：凸集的「角」与「边」

**极点（extreme point）**：$x$ 是凸集 $C$ 的极点，若 $x$ 不能写成 $C$ 中两个不同点的凸组合——即「$x = \theta y + (1-\theta) z$ 且 $0 < \theta < 1$ 蕴含 $y = z = x$」。<span class="marginnote">等价定义：从 $C$ 中挖掉 $x$ 后 $C$ 仍是凸集。极点刻画「不可约」的点——它是凸组合表示里的「原子」。直觉检验：三角形去掉一个顶点会凹下去，所以顶点是极点；把一条边的中点挖掉，剩下的仍凸，所以边中点不是极点。</span>

**极值方向（extreme ray / direction）**：对无界凸集（如多面体锥、凸锥），除极点外还需要**极值方向**——不能写成另外两个不同方向的非负组合的方向。无界多面体的完整表示 = 「极点凸组合」+「极值方向的非负组合」：有限个点加上有限条「边」，就生成整个集合。<span class="marginnote">一个方向 $d$ 是极值方向，直观上就是「从某个极点出发向外的一条不可再拆的边」。多面体的表示定理：$C = \operatorname{conv}(\text{极点}) + \operatorname{cone}(\text{极值方向})$——<strong>点 + 射线 = 凸集</strong>。这条分解让无界可行域也能被有限描述。</span>

**重点：** 极点是「点」，极值方向是「方向」；紧凸集只有极点没有极值方向，无界凸集两者都要。线性规划的最优解若存在，总可以取在一个极点——这就是「顶点最优」定理，单纯形法在此上狂奔。

把三个易混概念并排比较，是理解这一章最快的捷径：

| 概念 | 定义要点 | 判定直觉 | 例子 |
| --- | --- | --- | --- |
| 极点 | 不能写成两个不同点凸组合的点 | 挖掉它凸性被破坏 | 三角形顶点、立方体角 |
| 极值方向 | 不能写成两个方向非负组合的方向 | 从极点出发的「不可拆边」 | 锥的生成元 |
| 相对边界点 | 属于仿射包边界但不一定是极点 | 可在某条弦的内部 | 正方形边的中点 |

三个概念中，**极点最「强」**：相对边界点不一定是极点（边的中点就是反例），而每个极点必在相对边界上。理解这一层包含关系，后面读多面体的面结构（面 = 极点集的凸包）就不费力了。

**辨析｜易错点：**「极点」「顶点」「基本可行解」三个词常被混用，但层次不同：**极点**是几何概念（不能写成两点的凸组合）；**顶点**只是极点在大众语境下的同义俗称；**基本可行解（basic feasible solution）**是代数概念——标准形多面体 $\{x : Ax = b, x \ge 0\}$ 里正分量至多 $m$ 个、且对应列线性无关的解。三者对 LP 的可行域恰好重合，但「极点 ⟺ 基本可行解」是需要代数证明的桥梁（正依赖第3节的活动约束判据）。分不清这三层，读单纯形法的表格实现时就会「几何一套、代数一套」地对不上号。

## 2 Minkowski 定理：用极点重建紧凸集

**Minkowski 定理（极点表示）**：$\mathbb{R}^n$ 中每个非空紧凸集 $C$ 都是其极点的凸包：

$$C = \operatorname{conv}(\operatorname{ext} C)$$

**Krein–Milman 定理**是其在无穷维的推广（紧致凸集 = 极点的闭凸包），在有限维两者重合。<span class="marginnote">Minkowski（Hermann Minkowski，1864—1909，爱因斯坦在苏黎世的老师）是凸几何与「Minkowski 和」的奠基人。定理的惊人处在于：<strong>一个可能有无穷多个点的紧凸集，只要知道它的极点（可能依然无穷多个，但结构极简），就能原样拼回</strong>——极点是最省的信息源。</span>球面 $\{x : \|x\| \le 1\}$ 的极点是单位球面上的一切点，所以 $\operatorname{conv}(\operatorname{ext} B) = B$ 说「球面上所有点都能由球面上其他点凸组合出来」——这看似废话，但对多面体却给出了有限表示。

极点表示的「信息量」随集合形状剧变，值得用一个对照表定格：

| 集合 | 极点个数 | 表示成本 | 说明 |
| --- | --- | --- | --- |
| 闭区间 $[0,1]$ | 2 | 有限 | 端点定一切 |
| 单位球 $B \subset \mathbb{R}^n$ | 无穷多 | 连续统 | 球面处处是极点 |
| 单位立方体 $[0,1]^n$ | $2^n$ | 指数多 | 见第3节 |
| 标准单纯形 $\Delta_n$ | $n+1$ | 线性多 | 最省的多面体 |

同一维数下，「最省」的凸集是单纯形（$n+1$ 个极点），「最费」的多面体可以达到 $2^n$ 个极点——Minkowski 定理保证都能拼回，但**拼回的成本由几何形状决定**，这正是第5节「极点个数即复杂度」的伏笔。

**证明骨架**（归纳于维数）：$\mathbb{R}^1$ 中紧凸集是闭区间，端点是极点，显然。对 $n$ 维：取 $x \in C$，若 $x$ 不是极点，则 $x$ 在 $C$ 的某条弦上；把弦延长到边界得 $x = \theta y + (1-\theta)z$，其中 $y, z$ 落在边界低维面上，对边界归纳。每条边界面的极点都是 $C$ 的极点——由此每个点都能写成极点的凸组合。<span class="marginnote">归纳法的关键是「沿弦走到边界」：非极点的点总夹在弦两端之间，而弦两端在更低的维数上。维数每降一层，凸组合的项数增加至多一个，最终项数 ≤ $n+1$——这正是 Carathéodory 定理的数字。</span>

**算一个直观例子**：单位正方形 $[0,1]^2$ 的极点是四个角 $(0,0),(1,0),(1,1),(0,1)$。取内部点 $(0.4, 0.4)$，可写成 $\tfrac25(1,1) + \tfrac35(0,0)$……更一般地 $(0.4,0.4) = 0.4(1,1) + 0.6(0,0)$，权重 $0.4 + 0.6 = 1$。**正方形里每个点都是四个顶点的凸组合**——这就是 Minkowski 定理在最小多面体上的显式验证。

## 3 多面体：极点的有限表示与单纯形法

**多面体（polyhedron）**：有限个半空间的交 $\{x : Ax \le b\}$。它的极点个数有限，且有维数判据：

**极点判据**：$x$ 是 $\{x : Ax \le b\}$ 的极点，当且仅当在 $x$ 处取等（活动）的不等式对应的行 $a_i$ 张成整个 $\mathbb{R}^n$（取到 $n$ 个线性无关的活动约束）。<span class="marginnote">几何直译：<strong>极点必须被至少 $n$ 个「不共面」的面钉住</strong>——在平面里要 2 条不平行的边；在三维要 3 个不共面的面。单纯形法正是沿着「从一个极点换到相邻极点」移动，因为目标函数在多面体上的最优值必在某个极点取到。</span>

**算一个极点判据**：多面体 $\{x \ge 0,\ x_1 + x_2 \le 1\} \subset \mathbb{R}^2$ 有三个极点 $(0,0)$、$(1,0)$、$(0,1)$。验证 $(1,0)$：活动约束是 $x_2 \ge 0$（即 $-x_2 \le 0$）与 $x_1 + x_2 \le 1$，两行 $(0,-1)$、$(1,1)$ 线性无关，张成 $\mathbb{R}^2$——是极点。$(0.5, 0.5)$ 只有一条活动约束，不是极点——它是「边中点」。**极点判据把「是不是角」变成「活动约束够不够 $n$ 条且线性无关」的代数检验**，这正是单纯形法找基本可行解的依据。

**算一个退化极点**：把上面多面体再加一条冗余约束 $2x_1 + x_2 \le 2$，得 $\{x_1 \ge 0,\ x_2 \ge 0,\ x_1 + x_2 \le 1,\ 2x_1 + x_2 \le 2\}$。在 $(1,0)$ 处取等的约束一下子有三条：$x_2 \ge 0$（行 $(0,1)$）、$x_1 + x_2 \le 1$（行 $(1,1)$）、$2x_1 + x_2 \le 2$（行 $(2,1)$）——三行张成 $\mathbb{R}^2$ 绰绰有余，$(1,0)$ 仍是极点，但它成了**退化极点**（活动约束严格多于 $n = 2$ 条）。退化极点是单纯形法「打转」（cycling）的温床，也是 Bland 规则、字典序扰动等防退化技巧的用武之地——极点的几何判据，在这里直接翻译成了数值实现的工程问题。

**极点的有限性**：多面体的极点、极值方向都只有有限个，所以表示定理给出**有限表示**：$P = \operatorname{conv}\{x^1,\dots,x^p\} + \operatorname{cone}\{d^1,\dots,d^q\}$。这是多面体理论（Rockafellar 第19章）的全部发动机：整数规划里「极点的个数可以指数多」，正因如此多面体的极点枚举才是 NP-难问题。

**重点：** 单纯形法最优性判据（检验数非正）本质上是「当前极点处，所有极值方向都不让目标下降」——极值表示理论给了算法一个终止判据。

**算一个高维极点清单**：单位立方体 $[0,1]^n = \{x : 0 \le x_i \le 1,\ i=1,\dots,n\}$ 有 $2^n$ 个极点——每个坐标要么取 0 要么取 1。用活动约束语言：在极点处，$n$ 个界约束 $x_i \ge 0$ 或 $x_i \le 1$ 取等且张成 $\mathbb{R}^n$，正好选出 $n$ 个线性无关的行。<span class="marginnote">立方体的 $2^n$ 个极点提醒我们：<strong>极点的个数可以随维数指数增长</strong>。$n = 10$ 时只有 1024 个顶点，$n = 100$ 时就是 $2^{100}$ 个——「顶点最优」不等于「枚举顶点可行」，这正是单纯形法沿边智能游走而非穷举的理由。</span>与之对照，标准单纯形 $\{x \ge 0,\ \sum x_i = 1\}$ 只有 $n$ 个极点 $e^1,\dots,e^n$，极点个数从指数暴跌到线性——同一维数下，多面体的「几何复杂度」差异极大。

## 4 公式解析：Carathéodory 到 Krein–Milman 的桥梁

两个定理的分工：**Carathéodory** 说「每点至多用 $n+1$ 个点表示」，**Krein–Milman** 说「这些点可以取成极点」。合起来：

$$C = \operatorname{conv}(\operatorname{ext} C) \quad\Longrightarrow\quad \forall\, x \in C,\ \exists\, x^1,\dots,x^{n+1} \in \operatorname{ext} C,\ \lambda_i \ge 0,\ \textstyle\sum \lambda_i = 1: \ x = \textstyle\sum_{i=1}^{n+1} \lambda_i x^i$$

- **第一步，拆目标**：先证 $C \subseteq \operatorname{conv}(\operatorname{ext} C)$。取 $x \in C$，用 Carathéodory：$x$ 是 $C$ 中至多 $n+1$ 个点的凸组合。问题变成「这 $n+1$ 个点能不能换成极点」。
- **第二步，逐点下沉**：若其中某个点 $y$ 不是极点，则 $y$ 在弦 $(y_1, y_2)$ 上、可写成 $y = \theta y_1 + (1-\theta) y_2$。把 $y$ 替换为 $y_1, y_2$，凸组合项数加一，但每个新点比 $y$ 更接近边界（更「极端」）。
- **第三步，终止论证**：沿此不断替换，每次项数增加但维数……不对——正确路径是沿弦走到边界降维。对维数归纳：边界上的点落在低维凸集里，归纳假设把它们写成低维的极点，而这些极点同时也是 $C$ 的极点。
- **第四步，合成**：逐层下沉后，$x$ 被写成 $C$ 的极点的凸组合（项数经 Carathéodory 可压回 $n+1$）。反向包含 $\supseteq$ 平凡（凸包包含 $C$）。定理成立。

**这条链路的要点**：<span class="marginnote"><strong>Carathéodory 控制「项数」，Krein–Milman 控制「用哪些点」</strong>——一个是数量定理，一个是质量定理。二者合用，才得到「紧凸集被极点的有限组合重建」的完整陈述。这也是为什么极值表示在数值优化里总以「有限 + 极点」的面貌出现。</span>

**辨析｜易错点：** Carathéodory 的上界 $n+1$ 是**可能**而非**必须**——它是说「至多用 $n+1$ 个点就够」，不是说「每次都要用满」。在 $\mathbb{R}^2$ 里，正方形内部点用 4 个顶点够（也可只用 2 个端点），但三角形的内部点**必须**用满 3 个顶点——因为三角形任意两点连线都落在边或外部，盖不住内部。$n+1$ 的「满」只在单纯形上被真正逼到；这正是「最省」与「最费」几何的又一对照，也是单纯形在多面体理论中地位特殊的几何原因。

这里补一个与第1篇「凸包」的对照：凸包 $\operatorname{conv}(S)$ 是把任意集合 $S$「凸化」的最小凸集，而极值表示定理反过来问「一个凸集要保留哪些点才够」。两个方向合起来构成完整的循环：**先取凸包补全，再抽极点压缩**——凸包的极端情形正是由极点构成的极简骨架。

## 5 连接：极点、对偶与算法

极值表示不是抽象几何，它直接决定了算法的形状。**单纯形法**在极点间转移：每次沿一条使目标下降的极值方向移动，检查检验数（极值方向上的下降率）决定是否终止；**对偶单纯形法**则在「对偶极点的退化问题」上工作。**分支定界**处理整数规划时，先解 LP 的极点松弛，再沿非整数分量切割——极点太少，问题就退化成平凡；极点太多（指数多），就触碰了 NP-难。<span class="marginnote"><strong>「极点的个数」成了算法复杂度的度量</strong>：多面体的极点个数可以是 $O(2^n)$，所以「枚举所有顶点」的算法必然不可行，而单纯形法沿可行方向智能游走，在实践中几乎总是多项式步数。极点几何为算法分析提供了精确的语言。</span>在「从极限到大模型」的算法课程里，你会再见到极值表示：它解释了「为什么顶点解在组合优化里如此重要」「为什么很多问题的最优解在角上」。

## 6 小结

- **极点**：不能被写成两个不同点凸组合的点——凸集的「原子」，挖掉即破坏凸性。
- **极值方向**：无界凸集的「不可拆边」；$C = \operatorname{conv}(\text{极点}) + \operatorname{cone}(\text{极值方向})$。
- **Minkowski / Krein–Milman**：紧凸集 = 其极点的凸包（有限维）；证明靠「沿弦到边界 + 维数归纳」。
- **多面体**：极点由 $n$ 个线性无关活动约束钉住；有限表示 → 单纯形法沿极点移动、检验数判停。
- Carathéodory 控项数、Krein–Milman 控点选，合起来才是完整的极值表示。
- 极点个数是算法复杂度的度量：有限可行（可枚举）与指数爆炸（NP-难）的分界。
