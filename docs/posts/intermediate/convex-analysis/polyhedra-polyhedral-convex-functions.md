## 为什么从多面体开始

凸分析里最「现实」的一族对象，是**多面体（polyhedron）**——有限个半空间的交。
线性规划的可行域、整数规划的线性松弛、博弈论中的策略单纯形，
全都是多面体。
多面体好算：它只有有限个顶点、有限条棱，
顶点搜索、单纯形法、Farkas 引理都建立在它身上。
而**多面体凸函数**（分片线性凸函数）则是多面体在函数世界的对应物——一堆仿射函数逐点取最大，
构成机器学习里最常见的非光滑凸目标。
<span class="marginnote">在「从极限到大模型」主线上，ReLU 网络、合页损失、L1 正则全是多面体凸函数。
它们「分片线性」的结构让优化有精确的几何（每个片是线性函数），
也让「泛化界、稀疏性、对偶结构」的分析特别干净。
</span>

## 1 多面体

**多面体（polyhedron）**：
有限个半空间（与超平面）的交：

$$P = \{ x \mid a_i^T x \le b_i,\ i = 1, \dots, m \} = \{ x \mid Ax \le b \}$$

**多胞形（polytope）**：**有界**的多面体。<span class="marginnote">多面体不要求有界：$\{x \mid x \ge 0\}$（非负象限）是多面体但不是多胞形。多胞形是「有限多个顶点的凸包」；多面体则是「有限个半空间的交」——这两个描述在下一节由表示定理统一起来。</span>

**重点：** 多面体是凸集（半空间交，第2节），且是**闭凸锥** $\{x \mid Ax \le 0\}$ 的平移加相交的推广。它是「凸 + 有限描述」的产物：有限条不等式就能定义，这让它成为计算机能精确处理的最大凸集类。

## 2 表示定理（Minkowski–Weyl）

**Minkowski–Weyl 表示定理**：$\mathbb{R}^n$ 中任何多面体 $P$ 都可写成

$$P = \operatorname{conv}\{v_1, \dots, v_k\} + \operatorname{cone}\{d_1, \dots, d_l\}$$

即「有限个顶点的凸包」加「有限个方向的锥」。
<span class="marginnote">这个分解给了多面体两副面孔：<strong>半空间视角</strong>（$Ax \le b$，外描述）与<strong>顶点-方向视角</strong>（顶点凸包 + 方向锥，内描述）。
对有界多胞形，$P = \operatorname{conv}\{v_1,\dots,v_k\}$——回到第7节的「多面体 = 顶点凸包」；
无界多面体额外挂上极值方向的锥。
</span>

**重点：** 表示定理把「无穷多个不等式」与「有限个顶点」统一：
多面体的**描述复杂度**（不等式个数）与**组合复杂度**（顶点个数）可以互相转换——这是线性规划理论「顶点 vs 半空间」双视角的基础，
也是高维多面体「顶点爆炸」现象的根源（$n$ 维立方体的顶点数是 $2^n$，
但只需 $2n$ 条不等式）。

**辨析｜易错点：** 一般凸集（如圆盘）**不是**多面体——圆盘有无穷多个「顶点」（边界每个点都是极值点），
无法用有限个不等式描述。
**「有限」是多面体的灵魂**：顶点有限、半空间有限、极值方向有限。
看到一个「圆滑」的凸集，先别叫它多面体。

## 3 多面体凸函数

**多面体凸函数（polyhedral convex function）**：
有限个仿射函数的逐点最大：

$$f(x) = \max\{ a_1^T x + b_1, \dots, a_m^T x + b_m \}$$

它也叫**分片线性凸函数（piecewise-linear convex function）**。<span class="marginnote">例：$|x| = \max\{x, -x\}$；$\|x\|_1 = \max_{s \in \{\pm 1\}^n} s^T x$（$2^n$ 片）；合页损失 $\max\{0, 1 - y w^T x\}$；以及任何多面体的<strong>支撑函数</strong> $\sigma_P(y) = \max_{v \text{ 顶点}} v^T y$——多面体的支撑函数正是其顶点的逐点最大。</span>

**核心对应**：$f$ 是多面体凸函数 ⟺ $\operatorname{epi} f$ 是多面体 ⟺ $f^*$ 的**有效域** $\operatorname{dom} f^*$ 是多面体且 $f^*$ 在其上是仿射分片的。<span class="marginnote">这最后一条尤其重要：多面体凸函数的共轭仍然是「多面体型的」——只是换了一组顶点/半空间。L1 正则 $\|x\|_1$ 的共轭是 $\delta_{\{\|y\|_\infty \le 1\}}$，一个多面体的指示函数。分片线性在对偶下保持，这正是「稀疏正则 + 对偶」能干净配对的代数原因。</span>

**重点：** 多面体凸函数的次微分处处非空且**多面体化**：$\partial f(x)$ 是「在 $x$ 处取到最大的那些仿射片的系数向量的凸包」（第15节逐点极大规则）——在分片内部是单点，在折线上是一个凸多面体。

## 4 公式解析：Minkowski–Weyl 分解

以二维有界多胞形为例说明分解的来源：

$$P = \{ x \mid Ax \le b \} = \operatorname{conv}\{v_1, \dots, v_k\}$$

- **第一步，顶点存在**：由第7节，有界闭凸集 $P$ 是极值点的凸包 $P = \operatorname{conv}(\operatorname{ext} P)$。多胞形只有有限个极值点 $v_1, \dots, v_k$（因为只有有限条边界面，顶点数有限）。
- **第二步，无界方向的补充**：若 $P$ 无界，极值点张出「有界部分」，沿极值方向 $d_1, \dots, d_l$ 可以无限延伸——$P = \operatorname{conv}\{v_i\} + \operatorname{cone}\{d_j\}$。
- **第三步，为什么有限**：$Ax \le b$ 只有有限条不等式，面、边、顶点的组合结构有限，故 $k, l$ 有限——这是「有限描述 ⇒ 有限骨架」的几何版。
- **第四步，对偶视角**：分解的每一项都能从 $P$ 的支撑函数读出来：$\sigma_P(y) = \max_i v_i^T y$（$y$ 在锥内）、$= +\infty$（$y$ 指向无界方向）——**支撑函数把「顶点 + 方向」翻译成「分片线性函数」**。

## 5 多面体实例对照表

把常见多面体及其「内描述 / 外描述」列成表，
一次看清 Minkowski–Weyl 分解：

| 多面体 | 外描述（半空间） | 内描述（顶点 + 方向） | 有界? |
| --- | --- | --- | --- |
| 箱 $[0,1]^n$ | $0 \le x_i \le 1$ | $2^n$ 个顶点，无方向 | 是 |
| 单形 $\{x \succeq 0, 1^Tx = 1\}$ | $n+1$ 条不等式 | $n+1$ 个顶点，无方向 | 是 |
| 多面体锥 $\{x : Ax \le 0\}$ | 半空间族 | 只含原点 + 方向锥 | 否 |
| 带形 $\{x : 0 \le x_1 \le 1\}$ | 两条不等式 | $2$ 个「顶点」+ 方向 $(0,1)$ | 否 |
| LP 可行域 | $Ax \le b$ | 顶点 + 极值方向 | 视约束而定 |

**重点：** 表格最值得注意的一行是**单形**——它是「最紧凑」的有界多面体：
$n+1$ 个顶点恰好是 $\mathbb{R}^n$ 里最少能张出一个 $n$ 维多面体的顶点数（呼应 Carathéodory 定理的 $n+1$）。
单形在优化里的地位特殊：**它是「均匀覆盖」的最佳多面体**，
混料设计、单纯形法、以及概率论里的 Dirichlet 分布全都建在单形上。
<span class="marginnote">单形 $\{x \succeq 0, 1^T x = 1\}$ 正是概率分布集合——它的 $n+1$ 个顶点是「独热向量」。
多面体理论给概率论提供的正是这种「分布空间 = 多面体」的几何视角。
</span>

**多面体凸函数的例子。**
$f(x) = \max_i (a_i^T x + b_i)$ 是分片线性凸函数。
它的上图 $\operatorname{epi} f = \{(x, t) \mid a_i^T x + b_i \le t,\ \forall i\}$ 是一个多面体——**「函数是多面体凸」等价于「上图是多面体」**。
<span class="marginnote">合页损失 $f(w) = \max(0, 1 - y w^T x)$ 就是一个「两片」的分片线性函数，其上图是楔形多面体。
SVM 的全部几何——间隔、支撑向量、KKT——都可以在这块楔形多面体上读出来。
</span>

**一个关键的工程事实：顶点爆炸。**
同一个多胞形，外描述（不等式数）可以很小，
内描述（顶点数）却可能指数爆炸。
$n$ 维单位立方体：$2n$ 条不等式，
$2^n$ 个顶点。
**这意味着「枚举顶点」在很多高维问题里不可行，
而「用不等式描述」可行**——线性规划能高效求解，
正是因为它始终用**外描述**（$Ax \le b$）而不是枚举顶点。
<span class="marginnote">「外描述便宜、内描述昂贵」是多面体计算的核心不对称：单纯形法在顶点之间走（碰顶点但不枚举全部），内点法完全避开顶点走内部。
所有高维多面体算法都在「不枚举顶点」的前提下工作。
</span>

**辨析｜易错点：** 多面体凸函数的「片数」可以远大于维数。
$f(x) = \|x\|_1$ 在 $\mathbb{R}^n$ 上有 $2^n$ 个「片」（每个象限一片）——它仍是多面体凸函数（$2^n$ 有限），
但片数指数增长。
**「有限片」不等于「少量片」**；
多面体凸函数的复杂度用片数/顶点数衡量，
可能很大。

## 6 小结

- **多面体** = 有限半空间之交 $Ax \le b$；**多胞形** = 有界多面体。
- **Minkowski–Weyl**：$P = \operatorname{conv}\{v_i\} + \operatorname{cone}\{d_j\}$，外描述（半空间）与内描述（顶点+方向）统一。
- **多面体凸函数** = 有限仿射函数的逐点最大（分片线性凸函数）。
- 对应关系：$f$ 多面体凸 ⟺ $\operatorname{epi} f$ 多面体 ⟺ $f^*$
