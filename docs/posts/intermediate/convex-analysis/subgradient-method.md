## 为什么从次梯度方法开始

理论装备齐了，该上算法。
**次梯度方法（subgradient method）** 是所有非光滑凸优化算法的原点：
更新规则只有一个式子「往任意一个次梯度的反方向走一步」，
却能保证收敛到全局最优。
它不要求目标可微、不要求 Lipschitz 梯度、甚至连方向都不用精心挑选——任意次梯度都行。
这种「粗糙却正确」的特质，让它成为 L1 正则、合页损失、约束松弛等非光滑问题的最朴素解法，
也是理解更精细方法（近端梯度、ADMM）的跳板。
<span class="marginnote">在「从极限到大模型」主线上，随机梯度下降（SGD）的收敛分析正是次梯度方法理论的翻版——把「任取一个次梯度」换成「取一个随机估计的梯度」，证明骨架完全一样。
理解次梯度方法，等于理解了一半的深度学习优化。
</span>

## 1 算法与投影

**次梯度方法**：给定凸目标 $f$（可选约束集 $C$），
任取初始点 $x_0$，迭代

$$x_{k+1} = x_k - \alpha_k\, g_k, \qquad g_k \in \partial f(x_k)$$

若带约束 $x \in C$，每一步后加一次**投影**：

$$x_{k+1} = P_C\big(x_k - \alpha_k g_k\big)$$

其中 $P_C$ 是到 $C$ 的欧氏投影。
<span class="marginnote">投影 $P_C$ 把「可能飞出约束集」的迭代点拉回 $C$ 里最近的点——对球、箱、半空间、多面体这些简单凸集，投影有闭式解，计算几乎免费。
次梯度方法 + 投影 = 约束非光滑优化的最简框架。
</span>

**重点：** 步长 $\alpha_k$ 的选择不依赖梯度的范数归一化——它是唯一的「旋钮」，
直接决定收敛与否。
这与梯度下降（同样一个式子，但梯度方向是「真正的下坡」）有本质差别：
**次梯度方向不一定是下坡方向**。

## 2 步长规则

次梯度方法的收敛性完全由步长规则驱动，三种常用选择：

- **恒定步长** $\alpha_k = \alpha$：能收敛到最优值的某个邻域内（误差正比于 $\alpha$），但一般达不到精确最优。
- **递减步长** $\alpha_k \to 0$ 且 $\sum_k \alpha_k = \infty$（如 $\alpha_k = 1/k$）：保证 $f \to f^*$ 收敛到精确最优。两个条件缺一不可：步长必须「足够慢」地衰减（和发散）才走得够远，又必须「足够快」地归零才不振荡。
- **Polyak 步长** $\alpha_k = \frac{f(x_k) - f^*}{\|g_k\|^2}$：当 $f^*$ 已知时给出最优收敛常数。

**辨析｜易错点：** 递减步长必须满足**两个**条件：
$\sum \alpha_k = \infty$（总步长「够长」）与 $\alpha_k \to 0$（末尾「够小」）。
只取 $\alpha_k = 1/k^2$ 虽然归零够快，
但 $\sum 1/k^2$ 收敛，步长总和有限——算法可能停在离最优很远的地方。
**这是步长设计里最常见的坑。**

## 3 收敛性质：为什么不是下降法

次梯度方法与梯度下降最反直觉的差别：**它不保证单调下降**。

$$f(x_{k+1}) \text{ 可能比 } f(x_k) \text{ 大}$$

因为次梯度 $g_k$ 只是「一个可行斜率」，不一定是「最陡下坡」。因此实践中要维护**历史最优**

$$f_{\text{best}}^{(k)} = \min_{0 \le i \le k} f(x_i)$$

用 $\min$ 序列的收敛性来评判算法。

**收敛定理**：设 $f$ 凸、$L$-Lipschitz（$\|g\| \le L$），
最优值 $f^*$，则递减步长下

$$f_{\text{best}}^{(k)} - f^* = O\left(\frac{1}{\sqrt{k}}\right)$$

这是非光滑优化的**最优收敛率**（对一般的次梯度方法），但比光滑梯度下降的 $O(1/k)$ 慢。<span class="marginnote">$O(1/\sqrt{k})$ 意味着要达到精度 $\epsilon$ 需要 $O(1/\epsilon^2)$ 次迭代——这个「平方」代价是非光滑性的固有税。要突破它，必须用近端梯度法（利用可分离光滑 + 非光滑结构）或对偶方法，而不是通用次梯度。</span>

**重点：** 次梯度方法收敛到**全局最优**（凸性的红利），但不快、不单调；**收敛的是 $f_{\text{best}}$ 而非 $f(x_k)$**。评估实验时必须跟踪最优历史，否则会误判算法「失败」。

## 4 公式解析：收敛不等式

设 $\|g_k\| \le L$、$\|x_0 - x^*\| \le R$，用递减步长 $\alpha_k$。核心估计：

$$\|x_{k+1} - x^*\|^2 \le \|x_k - x^*\|^2 - 2\alpha_k\, (f(x_k) - f^*) + \alpha_k^2 \|g_k\|^2$$

- **第一步，展开范数**：$\|x_{k+1} - x^*\|^2 = \|x_k - x^* - \alpha_k g_k\|^2 = \|x_k - x^*\|^2 - 2\alpha_k g_k^T (x_k - x^*) + \alpha_k^2\|g_k\|^2$。
- **第二步，次梯度不等式**：$g_k \in \partial f(x_k)$ 给出 $f(x^*) \ge f(x_k) + g_k^T (x^* - x_k)$，即 $g_k^T (x_k - x^*) \ge f(x_k) - f^*$。
- **第三步，代回**：把第二步的界代入第一步，得上面的递推不等式——它把「到最优点的距离」与「当前目标误差」绑定。
- **第四步，求和**：对 $k = 0, \dots, N-1$ 相加并夹逼，得 $\sum_{k} \alpha_k (f(x_k) - f^*) \le \frac{R^2}{2} + \frac{L^2}{2}\sum \alpha_k^2$，再配合步长规则推得 $O(1/\sqrt{N})$ 的速率。

**这条递推不等式是全部收敛证明的心脏**：
它量化了「每次迭代在目标误差上能挣回多少、在范数上要付出多少」——所有更精细的方法（加速、Polyak、投影）都在优化这条账目。

## 5 次梯度方法 vs 梯度下降：一张对照表

次梯度方法与梯度下降只差一个「次」字，但行为差得很远。
把两者并排对比：

| 维度 | 梯度下降 | 次梯度方法 |
| --- | --- | --- |
| 适用目标 | 可微凸函数 | 不可微凸函数 |
| 每步方向 | 唯一的负梯度 | 任意次梯度的负方向 |
| $f(x_k)$ 单调下降？ | 是（步长合适时） | **否**（可能上升） |
| 评估指标 | $f(x_k)$ | $f_{\text{best}}^{(k)} = \min_{i\le k} f(x_i)$ |
| 收敛率 | $O(1/k)$（光滑） | $O(1/\sqrt{k})$ |
| 步长策略 | 常数或回溯线搜索 | 恒定/递减/Polyak |
| 停机准则 | $\|\nabla f\|$ 小 | $f_{\text{best}}$ 不再改善 |

**重点：** 表格最关键的一行是「$f(x_k)$ 单调下降？
」——**梯度下降是下降法，次梯度方法不是**。
次梯度方向只是「某个可行斜率」，不是最陡下坡，
走一步后目标可能反而变大。
因此次梯度方法的评判必须跟踪 $f_{\text{best}}$，
用「历史最优」衡量进展。
<span class="marginnote">「历史最优」这一设计后来被各种随机优化算法继承：SGD 的 checkpoint、AdaGrad 的自适应、以及「学习率退火」都在做同一件事——别被单步的波动骗了，看累积的最优轨迹。
次梯度方法是这一思想的最朴素版本。
</span>

**一个数值演示。** 最小化 $f(x) = |x|$，
从 $x_0 = 1$ 出发。
若步长 $\alpha_k = 1/k$：
$x_1 = 1 - 1 \cdot 1 = 0$（取次梯度 $1$），
恰好到最优点。
但换一个次梯度选择或步长，$x_k$ 会在 $0$ 两侧振荡，
$f(x_k)$ 时大时小——而 $f_{\text{best}}$ 稳步逼近 $0$。
**收敛的是历史最优，不是当前点。**

**为什么 $O(1/\sqrt{k})$ 是下界。**
对「只有次梯度、没有梯度信息」的 oracle，
任何算法都需要 $\Omega(1/\epsilon^2)$ 次迭代才能达到精度 $\epsilon$——这是信息论意义上的下界（Nesterov 的结果）。
次梯度方法以极小的假设成本达到了这个下界，
因此「够好但不快」。
<span class="marginnote">要突破 $O(1/\sqrt{k})$，必须利用额外的结构：光滑部分（近端梯度法，$O(1/k)$）、强凸（线性收敛）、或坐标可分离（坐标下降）。
次梯度方法是「无结构非光滑凸优化」的基线，
所有更快的算法都在「多利用一点结构」。
</span>

**辨析｜易错点：** **步长递减的两个条件缺一不可**——$\sum \alpha_k = \infty$（总步长无限）与 $\alpha_k \to 0$（步长归零）。
$\alpha_k = 1/\sqrt{k}$ 满足两者（和发散、项归零），
可以；
$\alpha_k = 1/k^2$ 不满足第一个（和收敛），
算法可能停在半路。
**写步长规则时，先验证这两条。**

## 6 小结

- **更新式**：$x_{k+1} = x_k - \alpha_k g_k$（$g_k \in \partial f(x_k)$），带约束时加投影 $P_C$。
- **步长三规则**：恒定步长（收敛到邻域）、递减步长（$\sum \alpha_k = \infty$ 且 $\alpha_k \to 0$，精确收敛）、Polyak 步长。
- **不是下降法**：$f(x_k)$ 可能上升，须跟踪 $f_{\text{best}}$。
- 收敛率 $O(1/\sqrt{k})$
