## 为什么从凸函数开始

第1篇研究的是凸**集**，而从这一节起，
我们把凸性应用到**函数**上。
为什么函数也讲凸性？因为在优化里，被优化的对象几乎总是函数：
损失函数、能量函数、目标函数。
一个函数是凸的，意味着它没有「伪谷」——局部极小就是全局极小，
梯度下降不会被困住。
这正是深度学习里损失曲面「凸则好办、非凸则棘手」的理论根源。
<span class="marginnote">凸函数家族包含大量常见目标：最小二乘、逻辑回归的负对数似然、支持向量机的合页损失、以及大模型训练里广泛使用的交叉熵与加权损失——理解凸函数，就是理解「哪些目标有全局最优的保证」。
</span>

而进入函数世界的关键，是一座把「集」与「函数」连通的桥梁——**上图（epigraph）**。
凸函数定义成「上图是凸集」，于是第1篇的全部几何武器（分离定理、支撑函数、锥）全部自动可用到函数上。

## 1 凸函数的定义

设 $f: \mathbb{R}^n \to \mathbb{R} \cup \{+\infty\}$（允许取 $+\infty$，
取值在 $\mathbb{R}$ 上的部分构成有效域 $\operatorname{dom} f = \{x \mid f(x) \lt  +\infty\}$）。
**凸函数（convex function）**：
若

$$f(\theta x + (1-\theta) y) \le \theta f(x) + (1-\theta) f(y), \qquad \forall\, x, y \in \operatorname{dom} f,\ \theta \in [0,1]$$

则称 $f$ 是凸函数。<span class="marginnote">这条不等式的名字叫 <strong>Jensen 不等式</strong>，它说的是一句大白话：<strong>弦不落于图下</strong>——函数图像上任意两点的连线段，都站在函数图像的上方。若不等号反向，$f$ 称为凹函数（concave）；$f$ 凹当且仅当 $-f$ 凸。</span>

若不等号对所有 $x \ne y$、$\theta \in (0,1)$ 都**严格**成立，称 $f$ **严格凸**。严格凸保证极小点至多一个——这是「唯一最优解」的保证。

**重点：** 定义中的 $\le$ 方向是「弦在图上」；很多初学者把方向记反。**判定一个函数是不是凸的，画条弦试试：弦高于图 ⇔ 凸。**

## 2 上图：函数与集合的桥梁

**上图（epigraph）**：$f$ 的上图定义为

$$\operatorname{epi} f = \{ (x, t) \in \mathbb{R}^{n+1} \mid f(x) \le t \}$$

即「函数图像上方（含图像）的一切点」。
<span class="marginnote">上图把 $n$ 元函数变成 $\mathbb{R}^{n+1}$ 里的一个集合：横坐标是 $x$，纵坐标是 $t$，上图是「躺在图像上面的一块区域」。
图像本身是它的下边界。</span>

**核心判定定理：$f$ 是凸函数 ⟺ $\operatorname{epi} f$ 是凸集。**
这一条把两个世界完全打通：第1篇建立的凸集的一切性质——分离、支撑、锥、保运算——都自动迁移到凸函数上。
<span class="marginnote">这是凸分析最漂亮的「翻译」：函数凸 ⇔ 上图凸。
后面定义闭凸函数（上图闭）、共轭函数（支撑函数的孪生）、次微分（法锥的孪生），
全都可以从「上图」这一视角导出。
</span>

**辨析｜易错点：** 上图用的是 $\le$（含图像），
**不是** $\lt $。
取 $\lt $ 会得到开集，函数闭性讨论（第11节）就会出问题。
还要注意：**水平集（下水平集）凸** $\{x \mid f(x) \le \alpha\}$ 是凸的，
**并不等价于 $f$ 凸**——那只够得上「拟凸」（quasiconvex），
我们会在第13节专门辨析。

## 3 判定条件

除了直接验证定义，有三种实用的判定路径：

- **限制到直线**：$f$ 凸 ⟺ 对任意 $x, y$，一元函数 $\varphi(t) = f(x + t(y-x))$ 在 $t \in [0,1]$ 上是凸的。把多元问题化为沿每条直线的单变量问题，是很多证明的落点。
- **Jensen 不等式（有限形式）**：$f$ 凸 ⟺ 对任意有限个 $x_i$ 与 $\theta_i \ge 0$、$\sum \theta_i = 1$，有 $f(\sum \theta_i x_i) \le \sum \theta_i f(x_i)$。这是定义的归纳推广，也是概率论里 $f(\mathbb{E}[X]) \le \mathbb{E}[f(X)]$ 的来源。
- **可微时的判定**：$f$ 可微时，凸 ⟺ $f(y) \ge f(x) + \nabla f(x)^T (y-x)$ 对所有 $x,y$ 成立（一阶条件，图在切线之上）；二阶可微时，凸 ⟺ $\nabla^2 f(x) \succeq 0$（Hessian 半正定）。这两条在下一节专门展开。

**重点：** 判定路径的选择取决于 $f$ 的「光滑程度」：
不光滑函数用定义或 Jensen，可微函数用一阶条件，
二阶光滑用 Hessian。
**最省力的判定是找对的路径**——多数教科书函数（线性、二次凸、范数、指数、熵）都能直接套 Hessian 或已知结论。

## 4 公式解析：Jensen 不等式

$$f\big(\theta x + (1-\theta) y\big) \le \theta f(x) + (1-\theta) f(y)$$

- **第一步，读左边**：$\theta x + (1-\theta) y$ 是 $x, y$ 的凸组合——自变量在 $x$ 与 $y$ 的连线段上滑动，$\theta = \frac{1}{2}$ 是中点。
- **第二步，读右边**：$\theta f(x) + (1-\theta) f(y)$ 是函数值 $f(x), f(y)$ 的**同一个**凸组合——弦在两端点值之间线性插值。
- **第三步，比较**：函数在凸组合点的取值「不超过」函数值的凸组合，即「先组合后取 $f$」≤「先取 $f$ 后组合」。函数的凸性就是在说：**求值与求凸组合这两种运算的次序，对 $f$ 而言是不可交换的，且方向固定**。
- **第四步，概率解读**：把 $\theta$ 当概率，右边是 $\mathbb{E}[f]$，左边是 $f(\mathbb{E})$——Jensen 不等式 $f(\mathbb{E}[X]) \le \mathbb{E}[f(X)]$ 正是凸函数的定义在期望下的推广，是信息论（KL 散度非负）与统计学习的常客。

这条不等式是凸函数定义的全部内容，也是我们后面验证「损失是否凸」「某函数能否松弛成凸」的第一道工具。

## 5 常见凸函数画廊

判定凸性最快的方式，是熟悉一批「教科书凸函数」。下表按家族整理：

| 家族 | 例子 | 凸性 | 依据 |
| --- | --- | --- | --- |
| 仿射 | $a^T x + b$ | 凸且凹 | Jensen 恒等 |
| 二次凸 | $x^T P x$（$P \succeq 0$） | 凸 | Hessian $= 2P$ |
| 范数 | $\|x\|_p$（$p \ge 1$） | 凸 | 三角不等式 |
| 指数 | $e^{ax}$（$\mathbb{R}$ 上） | 凸 | $f'' \ge 0$ |
| 幂 | $x^p$（$x>0$, $p\ge1$ 或 $p\le0$） | 凸 | $f'' \ge 0$ |
| 负熵 | $x\log x$（$x>0$） | 凸 | $f'' = 1/x > 0$ |
| 对数 | $\log x$ | **凹** | $-f'' > 0$ |
| 最大分量 | $\max_i x_i$ | 凸 | 逐点最大 |
| 对数求和指数 | $\log\sum_i e^{x_i}$ | 凸 | 平滑最大 |

**重点：** 这张表蕴含一个实用规律——**「凸」在常见函数里是常态而非特例**：大多数「正则、度量、损失」的构建块都是凸的。而**「凹」往往以对数、以及「凸函数取反」的形式出现**：$\log x$ 凹、$-x^2$ 凹、概率密度取对数后通常凹（对数凹分布）。识别凹函数同样重要，因为很多建模技巧要求「外层凸 + 内层凹」的复合（第10节）。<span class="marginnote">对数求和指数 $\mathrm{lse}(x) = \log\sum_i e^{x_i}$ 是「可微化的 max」：它凸、光滑、且满足 $\max_i x_i \le \mathrm{lse}(x) \le \max_i x_i + \log n$。在大模型里，softmax 的对数归一化常数（log-partition）正是它——它既出现在注意力权重里，也出现在逻辑回归的归一化里。</span>

**辨析｜易错点：** 凸性的**局部验证**不等于全局验证。$f(x) = x^4 - x^2$ 在 $x$ 很大时凸（$f'' = 12x^2 - 2 > 0$），但在 $|x| \lt  \sqrt{1/6}$ 附近凹——**它整体不是凸函数**。用 Hessian 判定时，必须要求**处处**半正定，而不是「大多数地方」。单个点的曲率说明不了整体凸性。

**一个反直觉的例子。** $f(x) = \|x\|$ 在 $x = 0$ 处不可微，但它显然是凸函数（范数的三角不等式）。这个例子说明：**凸函数不必光滑**——不可微性（尖点）与凸性完全可以共存。这为第3篇的次梯度理论埋下了最直接的动机：连 $\|x\|$ 这么「友好」的函数都有尖点，严谨的凸分析必须容纳不可微点。

## 6 小结

- **凸函数**：$f(\theta x + (1-\theta)y) \le \theta f(x) + (1-\theta)f(y)$，即**弦不落于图下**；凹函数反向。
- **上图** $\operatorname{epi} f = \{(x,t) \mid f(x) \le t\}$；**$f$ 凸 ⟺ 上图凸**，这是函数与集合的桥梁。
- 判定路径三条：限制到直线、Jensen 有限形式、一阶/二阶可微条件。
- **易错**：水平集凸 ≠ 函数凸（只是拟凸）；上图用 $\le$ 而非 $\lt $。
- Jensen 不等式 $f(\mathbb{E}[X]) \le \mathbb{E}[f(X)]$
