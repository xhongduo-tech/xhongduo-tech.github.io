## 为什么从应用开始

凸分析的全部前七篇都在为这一刻攒料：**把理论变成可运行的算法**。强对偶告诉我们「原始与对偶殊途同归」，于是有了对偶分解与 ADMM；KKT 条件把「最优」写成可解的方程组，于是有了内点法与增广拉格朗日；次梯度与极值表示支撑起 LASSO、SVM 与深度学习优化的一整套分析。<span class="marginnote">这一篇是第6篇的收官，也是整个凸分析专题的出口。从这里的每一条应用，都能回溯到前面某一篇的某条定理——<strong>共轭→对偶分解、分离→KKT、极点→单纯形、次梯度→LASSO</strong>。全专题的路线图在此汇拢。</span>它同时把「从极限到大模型」的主线拉近：大模型优化里那些看起来全新的技巧，绝大多数是凸分析概念的近亲。

## 1 从对偶定理到对偶算法：为什么对偶有用

对偶为什么不止是「数学风景」？三个理由：**（1）下界**——对偶目标 $g(\lambda)$ 给出 $p^*$ 的可行下界，可作停机判据；**（2）结构性更简单**——对偶问题常比原始问题更光滑或更低维（LASSO 的对偶是带箱约束的二次规划）；**（3）可分解**——对偶往往「可分」，为并行算法开路。<span class="marginnote">以可分离结构为例：$\min_x f_1(x_1) + f_2(x_2)$ 满足 $x_1 + x_2 = b$ 这类问题，原始目标耦合在约束上，但对偶问题天然解耦成两块——<strong>对偶是让问题变「可分」的机器</strong>。这正是大规模分布式优化的第一原理。</span>

**对偶上升（dual ascent）**：对 $\min f(x)$ s.t. $Ax = b$，拉格朗日 $L(x, \nu) = f(x) + \nu^T(Ax - b)$。对偶上升迭代两步：

$$x^{k+1} = \arg\min_x L(x, \nu^k), \qquad \nu^{k+1} = \nu^k + \alpha^k (A x^{k+1} - b)$$

第一步对 $x$ 极小化（常可分解），第二步沿原始残差 $Ax - b$ 更新乘子——「残差即梯度」的思想是第4篇次梯度法的表亲。

**算一个对偶上升**：$\min \tfrac12 x_1^2 + \tfrac12 x_2^2$ s.t. $x_1 + x_2 = 1$。拉格朗日 $L = \tfrac12 x_1^2 + \tfrac12 x_2^2 + \nu(x_1 + x_2 - 1)$。$x$ 步：$\partial L/\partial x_1 = x_1 + \nu = 0 \Rightarrow x_1 = -\nu$，同理 $x_2 = -\nu$。$\nu$ 步：$\nu \leftarrow \nu + \alpha(-2\nu - 1)$。取 $\alpha = 1$：$\nu_{k+1} = \nu_k + (-2\nu_k - 1) = -\nu_k - 1$。从 $\nu_0 = 0$ 得 $\nu_1 = -1$、$\nu_2 = 0$、$\nu_3 = -1$……震荡，这就是对偶上升的「经典病症」——不收敛！<span class="marginnote">对偶上升的代价就藏在这个例子里：<strong>它对 $f$ 的强凸性敏感</strong>，步长选不好就震荡（这里 $f$ 强凸但步长过大的极端情形）。增广拉格朗日与 ADMM 正是为了治这个病而生的——加一个 $\tfrac{\rho}{2}\|Ax-b\|^2$ 项把震荡压住。</span>本例的真实最优解是 $x_1 = x_2 = \tfrac12$、$\nu^* = -\tfrac12$，对偶上升在 $\alpha = 1$ 时绕圈。增广项 $\tfrac{\rho}{2}(x_1 + x_2 - 1)^2$ 加入后，$x$ 步变成 $\min_x \tfrac12\|x\|^2 + \nu(x_1+x_2-1) + \tfrac{\rho}{2}(x_1+x_2-1)^2$，收敛性显著改善——这就是 ADMM 的前身「乘子法」。

**把同一道题算到底**，感受「增广」两个字的分量。取 $\rho = 2$，乘子按 $\nu \leftarrow \nu + \rho(x_1 + x_2 - 1)$ 更新，$x$ 步由对称性得 $x_1^k = x_2^k = \tfrac{\rho - \nu^k}{1 + 2\rho} = \tfrac{2 - \nu^k}{5}$。从 $\nu^0 = 0$ 出发：

| $k$ | $\nu^k$ | $x_1^k = x_2^k$ | 原始残差 $x_1^k + x_2^k - 1$ |
| --- | --- | --- | --- |
| 0 | 0 | — | — |
| 1 | $-0.4$ | $0.4$ | $-0.2$ |
| 2 | $-0.48$ | $0.48$ | $-0.04$ |
| 3 | $-0.496$ | $0.496$ | $-0.008$ |

每一轮残差缩到上一轮的 $\tfrac15$，线性收敛到 $0$，$\nu^k \to -\tfrac12 = \nu^*$。对比此前 $\alpha = 1$ 的震荡（$\nu_1 = -1$、$\nu_2 = 0$、$\nu_3 = -1$……），同一个问题、同一个乘子更新，只因为目标里多了一项「约束违反量的平方」，收敛性就从震荡翻转为线性收敛。<span class="marginnote">为什么 $\tfrac{\rho}{2}\|Ax - b\|^2$ 能治病？它让内层 $x$ 步不再「无视约束」：残差越大，代价越高，$x$ 步被推向可行方向。<strong>增广项 = 把约束违反量本身变成目标的一部分</strong>。这就是乘子法与 ADMM 的全部秘密起点。</span>

**辨析｜易错点：**「对偶可行」不等于「原始可行」。$g(\nu)$ 对任意 $\nu$ 都有定义，它给出的只是 $p^*$ 的下界；只有当原始残差 $Ax - b$ 同时趋于 0（原始可行被满足）时，下界才撞上真值。因此对偶算法停机不能只看对偶目标不动了，要盯住原始残差——这正是 ADMM 停机判据（原始残差 + 对偶残差两条都足够小）的设计逻辑。

## 2 对偶分解与 ADMM：把大问题拆小

**对偶分解**在原始问题可分、约束耦合时把对偶问题拆成若干独立子问题并行求解——第1节的可分性在这里兑现。但它对原始强凸性敏感，收敛慢；**增广拉格朗日**加入 $\frac{\rho}{2}\|Ax - b\|^2$ 项牺牲可分解性换鲁棒性。**ADMM（交替方向乘子法）**把两者结合：把变量劈成两组 $x, z$，交替对 $x$、对 $z$ 极小化增广拉格朗日，再更新乘子：

$$x^{k+1} = \arg\min_x L_\rho(x, z^k, \nu^k), \qquad z^{k+1} = \arg\min_z L_\rho(x^{k+1}, z, \nu^k), \qquad \nu^{k+1} = \nu^k + \rho(Ax^{k+1} + Bz^{k+1} - b)$$

ADMM 收敛到全局最优（对凸问题），$\mathcal{O}(1/k)$ 的收敛速率由凸分析的强对偶保证，而每步的 $x$、$z$ 更新常常有闭式解。<span class="marginnote">ADMM 的三个字母对应三种思想：<strong>A</strong>lternating（交替）、<strong>D</strong>irection（方向、即对偶乘子更新）、<strong>M</strong>ethod（乘子，来自增广拉格朗日）。它是 2010 年代分布式机器学习（如大规模 LASSO、矩阵补全、联邦学习雏形）的主力算法——每一行都能在凸分析里找到依据。</span>

**重点：** ADMM 不是「另一个算法」，而是「对偶 + 增广 + 交替」三件旧零件的拼装。理解它需要第4篇的对偶与第3篇的次梯度；它的收敛性分析又全部回到强对偶与次梯度最优性。

**辨析｜易错点：** ADMM 的收敛保证只在**凸**问题下成立，这是初学者最容易越界的地方——对非凸问题（如带 $\ell_0$ 或非凸正则的深度模型）跑 ADMM，经验上「似乎能收敛」，但那只是启发式，不是定理。此外三条常见误区：一是停机只看迭代次数，不看两条残差（原始残差与对偶残差）是否同时小；二是把 $\rho$ 当固定超参而不会自适应调节；三是以为 $x$、$z$ 两步可以随意换序——顺序错会导致乘子更新用的信息过期。正确姿势：把 ADMM 当作「强对偶下的分裂算法」，一切判断回到残差与凸性。

把本专题提到的主要算法排成一张对照表：

| 算法 | 每步做 | 收敛速率 | 凸分析依据 |
| --- | --- | --- | --- |
| 梯度下降 | $x \leftarrow x - t\nabla f(x)$ | $\mathcal{O}(1/k)$（光滑强凸） | 一阶条件 |
| 次梯度法 | $x \leftarrow x - t g$，$g \in \partial f(x)$ | $\mathcal{O}(1/\sqrt{k})$ | 次微分最优性 |
| 对偶上升 | 交替极小化 + 乘子更新 | 需强凸 | 强对偶、「残差即梯度」 |
| ADMM | 交替 $x,z$ + 乘子更新 | $\mathcal{O}(1/k)$ | 强对偶 + 增广 |
| 内点法 | 解 KKT 牛顿系统 | 超线性 | KKT 方程组 |

这张表是「从极限到大模型」数值优化部分的缩略地图：每个算法的「凸分析依据」一列，正是本专题前七篇的定理。

## 3 机器学习中的凸方法：SVM、LASSO 与松弛

机器学习的经典模型几乎全是凸问题，凸分析给出「为什么好解、解是什么」：

**SVM**：原始问题 $\min \frac{1}{2}\|w\|^2 + C \sum_i \xi_i$，s.t. $y_i(w^T x_i + b) \ge 1 - \xi_i$，$\xi_i \ge 0$。KKT 的互补松弛给出「支撑向量」的定义：$\alpha_i > 0$ 的样本恰落在间隔边界上。<span class="marginnote">支撑向量就是「活动约束」对应的样本——第5篇 KKT 的互补松弛直接解释了为什么只有少部分样本决定分类面。对偶变量 $\alpha_i \in [0, C]$ 的区间，正来自不等式乘子的对偶可行性 $\lambda \ge 0$ 与上限 $C$（来自 $\xi$ 的系数）。</span>对偶形式 $\max_\alpha \sum \alpha_i - \frac{1}{2}\sum\alpha_i\alpha_j y_i y_j x_i^T x_j$ 只含内积，核技巧由此而生。

**LASSO**：$\min \frac{1}{2}\|Ax - b\|^2 + \lambda \|x\|_1$。次梯度最优性 $0 \in A^T(Ax - b) + \lambda \partial \|x\|_1$ 给出软阈值闭式解；$\|x\|_1$ 在零点处的 $[-1,1]^n$ 次微分正是稀疏性的来源（第5篇）。<span class="marginnote">稀疏 = 「零分量处次微分含 0」：当梯度不足以把分量推出 $[-1,1]$ 区间，分量就停在 0。$\ell_1$ 诱导稀疏是次微分几何的直接后果，不是玄学。</span>

**算一个软阈值**：$\min_x \tfrac12(x - 2)^2 + \lambda |x|$。次梯度条件 $0 \in (x - 2) + \lambda \partial |x|$。若 $x > 0$：$x - 2 + \lambda = 0$，$x = 2 - \lambda$（需 $\lambda < 2$）；若 $x < 0$：$x = 2 + \lambda$（矛盾）；若 $x = 0$：需 $0 \in [-2] + \lambda[-1,1]$，即 $\lambda \ge 2$。于是

$$x^* = \begin{cases} 2 - \lambda & \lambda < 2 \\ 0 & \lambda \ge 2 \end{cases}$$

**这就是一维软阈值：$\lambda$ 足够大时解被「压」到 0**——稀疏性从次微分条件里直接长出来。

**凸松弛（convex relaxation）**：非凸问题（如秩极小化、组合问题）用凸代理替换——核范数代替秩、$\ell_1$ 代替 $\ell_0$。这正是第4篇「共轭 = 闭凸化」的思想：$f^{**}$ 是最接近的非凸目标的凸松弛，松弛解的好坏分析要回到 Fenchel–Moreau 定理。

**深度学习的一瞥**：ReLU 网络的损失函数非凸，但每层 ReLU 本质是分段线性的凸函数；训练中的 Adam/SGD 与凸分析的收敛分析（次梯度法 $\mathcal{O}(1/\sqrt{k})$）共享同一套「光滑 + 凸」工具箱。<span class="marginnote">「从极限到大模型」的主线在此交汇：微积分的极限给出梯度，凸分析的次梯度把梯度推广到尖点，而大模型优化处理的海量分段线性目标，正是凸/次凸结构的工业级形态。</span>

把本章几个模型的「原始 ↔ 对偶」与所用工具排成一张速查表，它们各自只是前七篇某条定理的不同着装：

| 模型 | 原始问题 | 对偶 / 等价形态 | 凸分析工具 |
| --- | --- | --- | --- |
| SVM | $\min \tfrac12\|w\|^2 + C\sum_i \xi_i$ | $\max_\alpha \sum_i\alpha_i - \tfrac12\sum_{i,j}\alpha_i\alpha_j y_i y_j x_i^Tx_j$，$\alpha \in [0,C]^n$ | 强对偶 + 互补松弛 |
| LASSO | $\min \tfrac12\|Ax-b\|^2 + \lambda\|x\|_1$ | 对偶变量 $u$ 带 $\infty$-范数球约束的二次问题 | 次微分 + 共轭 |
| 逻辑回归 | $\min \sum_i \log(1 + e^{-y_i w^Tx_i}) + \tfrac\lambda2\|w\|^2$ | 光滑凸、无闭式对偶，直接梯度类求解 | 一阶最优性 |
| 秩极小化 | $\min \operatorname{rank}(X)$（非凸） | 核范数 $\|X\|_*$ 松弛（凸） | 共轭 = 闭凸化 |

注意最后一行：**核范数不是「想出来的近似」，而是 $\ell_1$ 思想在奇异值上的移植**——$\|X\|_* = \sum_i \sigma_i(X)$ 正是对奇异值向量施加 $\ell_1$，而 $\operatorname{rank}(X) = \|\sigma(X)\|_0$。于是「核范数替代秩」与「$\ell_1$ 替代 $\ell_0$」在结构上完全同构，同一条次微分几何同时解释两处稀疏。

## 4 公式解析：从强对偶到对偶上升的收敛

对偶上升的每一步更新，其实都在逼近强对偶等式 $d^* = p^*$：

$$\max_\nu g(\nu), \qquad g(\nu) = \inf_x \big( f(x) + \nu^T(Ax - b) \big)$$

- **第一步，看成极大化**：对偶问题 $\max_\nu g(\nu)$ 是凹函数的无约束极大化——$g$ 是仿射函数族的下确界，天然凹。
- **第二步，梯度即残差**：若内层极小在 $x^*(\nu)$ 取到，则 $g$ 的（次）梯度是 $\nabla g(\nu) = Ax^*(\nu) - b$——**对偶变量的梯度恰是原始残差**。这就是「残差即梯度」。
- **第三步，梯度上升**：$\nu^{k+1} = \nu^k + \alpha^k \nabla g(\nu^k) = \nu^k + \alpha^k (Ax^{k+1} - b)$——对偶上升 = 对 $g$ 做梯度上升。
- **第四步，强对偶兜底**：约束规格（第4篇 Slater）保证 $\max g = p^*$；梯度上升在凸/凹情形收敛到全局最大，于是 $\nu^k \to \nu^*$、$x^k$ 的原始残差 $Ax^k - b \to 0$——收敛性全部由第4篇强对偶定理背书。

**这条链路的要点**：<span class="marginnote"><strong>算法的每一步（极小化、乘子更新）都能指认一条对偶理论定理</strong>——对偶上升靠「残差=梯度」，ADMM 靠「增广+交替」，内点法靠「KKT 方程组」。理论不是事后解释，而是算法设计的工程图纸。</span>这是「应用篇」的真正收获：读算法时，去问「它背后是哪一条凸分析定理」。

## 5 小结

- **对偶的三种用途**：下界停机、结构更简、可分解并行。
- **对偶上升**：$\nu$ 沿原始残差更新——「残差即梯度」，收敛由强对偶保证，但对强凸性敏感。
- **ADMM**：交替极小化 + 乘子更新，凸问题全局收敛 $\mathcal{O}(1/k)$，分布式友好的主力算法。
- **SVM / LASSO / 松弛**：互补松弛给支撑向量，$\ell_1$ 次微分给稀疏（软阈值闭式解），$f^{**}$ 给凸松弛——全是前面各篇定理的直接兑现。
- 深度学习优化与凸/次凸分析共享工具箱——这是「从极限到大模型」主线的交汇点。
- 读算法的正确姿势：问「每一步背后是哪一条凸分析定理」。
