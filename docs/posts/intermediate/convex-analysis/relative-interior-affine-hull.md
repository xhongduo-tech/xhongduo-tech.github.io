## 为什么从相对内部开始

平面里一条线段，它的「内部」是空集——欧氏拓扑里没有哪个开圆盘能整个装进一条线段。
可这条线段明明有一维的「厚度」，它的两端点和中间点是不同的：
中间点可以沿线段方向自由滑动，端点不能。
**凸分析需要一个比「内部」更贴合实际的内点概念**，
让退化情形（低维凸集躺在高维空间里）也能谈「内部」「边界」「开集」。
这个工具就是**相对内部（relative interior）**。

它是整门学科的技术基石。
<span class="marginnote">Rockafellar 的《Convex Analysis》在进入分离定理、次梯度理论之前，
先用第6章把相对内部讲透——因为「一个凸集的对偶锥的正锥」「可行域内部非空」这类条件全部建立在相对内部之上。
Slater 条件（第4篇）本质上就是在要求相对内部非空。
</span> 没有它，我们连「凸集有内点」都说不利索。

## 1 仿射包与凸集的维数

**仿射包（affine hull）**：
集合 $C$ 的仿射包 $\operatorname{aff} C$ 是包含 $C$ 的最小仿射子空间，
等于 $C$ 中元素的一切仿射组合：

$$\operatorname{aff} C = \left\{ \sum_{i=1}^{k} \theta_i x_i \;\middle|\; x_i \in C,\ \sum_{i=1}^k \theta_i = 1,\ k \ge 1 \right\}$$

**凸集的维数**定义为 $\dim C = \dim(\operatorname{aff} C)$——即它的仿射包作为子空间的维数。<span class="marginnote">这是「维数」概念第一次被严格安放到任意集合上：一条平面线段 $\dim = 1$，一个平面圆盘 $\dim = 2$，一个单点 $\dim = 0$，空集常约定 $\dim \emptyset = -1$。维数描述的是「集合铺开在哪一层空间里」，而非它所在的外围空间。</span>

**重点：** 维数是**内蕴**的：它不依赖集合躺在哪个空间里。同样是「一条线」，在 $\mathbb{R}^2$ 里是退化的，在 $\mathbb{R}^3$ 里还是维数 $1$——因为仿射包本身把坐标系统「转正」了。

**辨析｜易错点：** 仿射组合与凸组合的差别在上一节讲过：仿射组合允许权重为负，因此仿射包比凸包「大」——凸包 $\operatorname{conv} C$ 一定被装进仿射包 $\operatorname{aff} C$ 里，且两者仿射包相等。**一个凸集的凸包与其本身拥有同一个仿射包**，这是「维数」定义得好的关键：取凸包不改变维数。

## 2 相对内部的定义

**相对内部（relative interior）**：$C$ 的相对内部记作 $\operatorname{ri} C$，定义为

$$\operatorname{ri} C = \{ x \in C \mid \exists\, \varepsilon > 0,\ B(x, \varepsilon) \cap \operatorname{aff} C \subseteq C \}$$

其中 $B(x, \varepsilon)$ 是以 $x$ 为心、$\varepsilon$ 为半径的开球。
<span class="marginnote">把普通「内部」定义里的「存在开球含于 $C$」换成「存在开球与仿射包相交后含于 $C$」——多了一个「与仿射包相交」，就允许球在集合所在的低维子空间里「平铺展开」。
一条平面线段的相对内部是去掉两个端点后的开线段。
</span>

相对边界则是 $\operatorname{rbd} C = \overline{C} \setminus \operatorname{ri} C$（闭包去掉相对内部）。
对平面线段来说，相对边界就是两个端点。

**重点：** 与普通内部不同，**非空凸集的相对内部一定非空**——这是凸集特有的事实，
证明用的是「在一个点上取仿射包的一组基，
把点稍微往里挤一挤」。
相比之下，非凸集合的相对内部可能空（如两条交叉线段）。

## 3 相对内部的核心性质

凸集的相对内部有整串漂亮的性质，Rockafellar 第6章把它们系统化，
这里列出最常用的三条：

**闭包换等**：对凸集 $C$，有 $\overline{\operatorname{ri} C} = \overline{C}$ 且 $\operatorname{ri}(\overline{C}) = \operatorname{ri} C$。即相对内部与闭包互相「恢复」：取闭包不会引入新的相对内部点，取相对内部也不会丢掉闭包里的任何点。
**相对内部是凸的**：$\operatorname{ri} C$ 本身是凸集，且与 $C$ 的仿射包相同。
- **线段的相对内部**：$x, y \in C$ 时，连接它们的开线段 $(1-\theta)x + \theta y$（$\theta \in (0,1)$）整个落在 $\operatorname{ri} C$ 中，只要 $x \in \operatorname{ri} C$ 或 $y \in \operatorname{ri} C$。这条性质叫「线段进入性」，是证明很多凸性结论的抓手。<span class="marginnote">「从相对内部一点出发，走向闭包里任一点，整条线段（除端点）都在相对内部」——这条性质在后面证明分离定理的严格版本、以及次梯度存在性时，会一次又一次地被调用。</span>

**辨析｜易错点：** 普通「内部」与「相对内部」在非退化情形下重合，
但退化时差得很远。
正方体在 $\mathbb{R}^3$ 里的内部非空、相对内部就是内部；
可一个正方形躺在 $\mathbb{R}^3$ 的 $xy$ 平面上，
其普通内部为空（没有三维开球装得下），相对内部却非空（是去掉四条边的开正方形）。
**写条件「$x$ 是内点」时，先问清楚用的是哪个「内点」。**

## 4 公式解析：相对内部的定义式

$$\operatorname{ri} C = \{ x \in C \mid \exists\, \varepsilon > 0,\ B(x, \varepsilon) \cap \operatorname{aff} C \subseteq C \}$$

- **第一步，比较普通内部**：普通内部 $\operatorname{int} C$ 要求 $B(x, \varepsilon) \subseteq C$——球要**整个**落在 $C$ 里。对低维凸集这几乎不可能。
- **第二步，放宽为相交**：把条件改成 $B(x, \varepsilon) \cap \operatorname{aff} C \subseteq C$——球只要在仿射包**内部的那一层**落在 $C$ 里即可。球伸到仿射包之外的部分不作要求。
- **第三步，为什么合理**：仿射包是 $C$ 所在的「宇宙」，从 $C$ 的角度看，球超出仿射包的部分本来就不存在；约束只在仿射包内起作用。
- **第四步，几何形象**：在仿射包里画一个以 $x$ 为心的小球，它被整个含于 $C$，则 $x \in \operatorname{ri} C$。对线段：在直线上取 $x$ 为心的开区间，含于线段内部即可，端点被排除。

这条定义把「内部」从拓扑概念改写成了**相对化**的拓扑概念，代价是引入仿射包作参照系——换来的是「退化凸集也有内部」的普适性。

## 5 相对内部的计算与例子

把「相对内部」算一遍，比背定义更能建立手感。下表给出常见凸集的维数、仿射包、相对内部与普通内部：

| 集合 | $\dim$ | $\operatorname{aff} C$ | $\operatorname{ri} C$ | $\operatorname{int} C$ |
| --- | --- | --- | --- | --- |
| 单点 $\{0\}$ | $0$ | $\{0\}$ | $\{0\}$ | $\emptyset$ |
| 线段 $[0,1] \subset \mathbb{R}^2$ | $1$ | 过线段的直线 | 开线段 $(0,1)$ | $\emptyset$ |
| 圆盘 $\{x : \|x\|\le 1\} \subset \mathbb{R}^2$ | $2$ | $\mathbb{R}^2$ | 开圆盘 $\|x\|\lt 1$ | 开圆盘 |
| 正方形 $[0,1]^2$ | $2$ | $\mathbb{R}^2$ | 开正方形 | 开正方形 |
| 多面体 $Ax \le b$（满秩） | $n$ | $\mathbb{R}^n$ | $\{Ax \lt  b\}$ 内点 | 同上 |

这张表最能说明问题的是**线段**一行：它在 $\mathbb{R}^2$ 里「躺平」了，普通内部为空，但相对内部是一维的开线段——它有自己的「内部」，只是不在外围空间的拓扑意义下。

**重点：** 计算相对内部的实用口诀——**「把仿射包内部的约束变严格」**。对由不等式定义的多面体 $\{x \mid a_i^T x \le b_i\}$，其相对内部是「在仿射包内，把所有不等式变成严格」：$\operatorname{ri} C = \{x \in \operatorname{aff} C \mid a_i^T x \lt  b_i \text{ 对非绑定约束}\}$。等式约束（定义仿射包的）保持等式，不等式约束在仿射包内取严格。<span class="marginnote">例：$C = \{x \ge 0,\ x_1 + x_2 = 1\} \subset \mathbb{R}^2$ 是概率单形（一条线段）。它的仿射包是直线 $x_1 + x_2 = 1$，相对内部是「在此直线上且 $x_1, x_2 > 0$」——即去掉两端的开线段。这个例子里「$x_i \ge 0$」在仿射包内被严格化为 $x_i > 0$。</span>

**辨析｜易错点：** 相对内部**不等于**「去掉边界的集合」。对正方形，去掉边界是开正方形，恰好等于相对内部；但对多面体，去掉「所有边界」可能把集合拆散（如一条线段去掉两个端点）。**正确定义永远是「在仿射包内取内部」**，不要用「去掉边界」这种朴素的图像代替。

## 6 小结

- **仿射包**：包含集合的最小仿射子空间，由一切仿射组合张成；**维数** = 仿射包的维数，是内蕴的。
- **相对内部**：$\operatorname{ri} C = \{x \in C \mid \exists\, \varepsilon > 0,\ B(x, \varepsilon) \cap \operatorname{aff} C \subseteq C\}$，对非空凸集必非空。
- **三条核心性质**：$\overline{\operatorname{ri} C} = \overline{C}$、$\operatorname{ri} C$ 是凸集、线段进入性（从相对内部点走向闭包点，除端点外全在相对内部）。
- **实用口诀**：在仿射包内把不等式约束变严格，就得相对内部。
- **非空凸集的相对内部必非空**——退化情形也能谈「内部」，这是凸集的特权。
- **普通内部与相对内部**：低维凸集躺平在 $\mathbb{R}^3$ 里时普通内部为空、相对内部非空。
- **相对边界**：$\operatorname{rbd} C = \overline{C} \setminus \operatorname{ri} C$；线段去掉两端点即相对边界。
- **维数是内蕴的**：$\dim C = \dim(\operatorname{aff} C)$，不依赖集合躺在哪个空间。
- **Slater 条件**（第4篇）本质上就是要求 $\operatorname{ri}(\operatorname{dom} f)$ 非空。

在下一节，我们把「相对内部」当作舞台，上演本专题最锋利的几何定理：**分离定理**——两个不相交凸集之间存在超平面把它们分开，其严格版本（正值分离）恰恰要求相对内部的条件，这正是相对内部「非退化」意义的集中体现。
