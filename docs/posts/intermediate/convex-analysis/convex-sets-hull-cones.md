## 为什么从凸集开始

整个凸分析的全部建筑都立在一个几何对象之上：**凸集（convex set）**。线性规划解集的可行域是凸集，机器学习的参数空间常被约束成凸集，博弈论里的策略混合也落在凸集里——因为「混合两个可行策略仍是可行策略」正是凸性。<span class="marginnote">一句话记住凸性的本质：<strong>凸集对「连线」封闭</strong>——集合里任意两点的整条连线都还留在集合里。这和「混合、平均、期望」这些人类直觉完美对应，也是为什么概率论、经济学与优化理论最后都落在凸集上。</span>这一篇是第6篇的开门综述，把第1篇到第5篇已经铺开的凸集理论收拢成一张地图：凸组合、凸包与凸锥三个概念，就是从集合走向函数、走向对偶的全部脚手架。

凸分析不是从零开始的独舞：在「从极限到大模型」的课程线上，第一级的《基础数学》已经把数轴、区间与平面的点集讲成集合；这一篇要做的，是把「集合」从一维数轴推广到 $\mathbb{R}^n$，并把「凸」这个最普通也最深刻的性质钉在集合上。前面是数系，后面是函数，凸集正是中间的接缝。

## 1 凸集：直观、定义与第一族例子

**凸集（convex set）**：集合 $C \subseteq \mathbb{R}^n$ 是凸的，若对任意 $x, y \in C$ 与任意 $\theta \in [0, 1]$，都有

$$\theta x + (1 - \theta) y \in C$$

几何语言是「任意两点间的线段仍在 $C$ 内」。这个定义干净得近乎朴素，却自动包含了无数重要对象：超平面、半空间、多面体、球、椭球、半正定矩阵锥。<span class="marginnote">$\mathbb{R}^n$ 里最常见的凸集清单：超平面 $\{x \mid a^Tx = b\}$、半空间 $\{x \mid a^Tx \le b\}$、多面体 $\{x \mid Ax \preceq b\}$、范数球 $\{x \mid \|x\| \le r\}$、以及正半定锥 $\mathbb{S}^n_+$。后三者分别是第4篇多面体、第3篇范数方法与第5篇锥规划的主角。</span>

把最常见的凸集排成一张表，便于后续对照：

| 凸集 | 定义式 | 备注 |
| --- | --- | --- |
| 超平面 | $\{x \mid a^Tx = b\}$ | 仿射集，$n-1$ 维 |
| 半空间 | $\{x \mid a^Tx \le b\}$ | 凸、无界、非紧 |
| 多面体 | $\{x \mid Ax \preceq b\}$ | LP 的可行域 |
| 范数球 | $\{x \mid \|x\|_2 \le r\}$ | 凸、紧、对称 |
| 椭球 | $\{x \mid (x-c)^T P^{-1}(x-c) \le 1\}$ | $P \succ 0$ 时凸 |
| 正半定锥 | $\{X \in \mathbb{S}^n \mid X \succeq 0\}$ | 矩阵空间里的凸锥 |

这些例子几乎覆盖了本专题后面全部要处理的对象：多面体支撑起线性规划，范数球支撑起 $\ell_2$ 正则，正半定锥支撑起半定规划。**记住这张表，等于提前拿到了整个专题的取景框。**

**辨析｜易错点：** 空心集合的边界（如圆环 $1 \le \|x\| \le 2$）不是凸的——中间那条连接边界两点的弦穿过了空心区。凸性是「整条线段」都在集合里，不是「两头在」。另外空集与单点集都是凸的，这条「退化特例」在证明里经常被忽略。

**重点：** 凸集对**任意个数的求交**封闭，但不对并封闭。两个凸集之并不一定凸（两个分离的圆盘），而它们的交、仿射变换的像与原像、线性组合（Minkowski 和）都是凸的——这些保凸运算正是第2篇「凸集的保运算」的内容。

## 2 凸组合与凸包：从有限和到 Carathéodory

**凸组合（convex combination）**：点 $x$ 是 $x_1, \dots, x_m$ 的凸组合，若存在 $\lambda_i \ge 0$、$\sum_i \lambda_i = 1$，使

$$x = \sum_{i=1}^{m} \lambda_i x_i$$

凸组合是「带权平均」：权重非负且和为 1，等价于把各点「以概率混合」。由此可以重新刻画凸性：**一个集合是凸的，当且仅当它包含其任意有限点集的一切凸组合**——这比「两点的线段」更强大，是概率化表达的基础。<span class="marginnote">权重非负且和为 1，正是概率向量的定义。所以「凸组合」与「概率混合」「期望值」「风险中性定价」共享同一个数学内核——这是凸分析穿透经济学与统计学的隐蔽通道。</span>

**凸包（convex hull）**：集合 $S$ 的凸包 $\operatorname{conv} S$ 是包含 $S$ 的所有凸集的交，等价地，是 $S$ 中元素的一切凸组合：

$$\operatorname{conv} S = \left\{ \sum_i \lambda_i x_i \;\middle|\; x_i \in S,\ \lambda_i \ge 0,\ \sum_i \lambda_i = 1 \right\}$$

凸包把任意形状「填成」一个凸集，且是最小的那种——它是「凸化」操作，对应着数学里「闭包」的一般思想。三个有限点凸包是三角形，四个共面点凸包可能退化为四边形；更重要的是下面的维数估计。

**算一个具体的凸包**：平面上三点 $A = (0,0)$、$B = (2,0)$、$C = (1,2)$ 的凸包是三角形 $\triangle ABC$。取内部点 $P = (1, \tfrac12)$，可以验证 $P = \tfrac14 A + \tfrac12 B + \tfrac14 C$：$x$ 坐标 $0 + 1 + \tfrac14 = 1$，$y$ 坐标 $0 + 0 + \tfrac12 = \tfrac12$，权重和 $\tfrac14 + \tfrac12 + \tfrac14 = 1$。权重非负、和为 1——这就是一次货真价实的凸组合。若去掉「权重非负」，$P$ 还能写成 $A, B, C$ 的仿射组合（系数可负），那将得到整个平面而不是三角形——**凸性的「非负」限制，正是把仿射空间压缩成凸包的关键。**

**Carathéodory 定理**：设 $S \subseteq \mathbb{R}^n$，则 $\operatorname{conv} S$ 中每一点都可写成 $S$ 中**至多 $n+1$** 个点的凸组合。<span class="marginnote">为什么是 $n+1$？因为 $\mathbb{R}^n$ 中任意 $n+2$ 个点的凸组合，总可以消掉一个权重降到 $n+1$ 个——这是「线性方程组超定时有一组非正解」的几何版本。在平面上（$n=2$），任何一点都能写成至多 3 个点的凸组合，也就是说三角形就够了。</span>这条定理把「无穷个点的组合」压缩成「有限个点」，是多面体理论与极值点理论（第7篇）的共同起点。

**辨析｜易错点：** 「凸包」与「仿射包」「线性包」是三兄弟，别混用。线性包是「系数任意」的线性组合全体，仿射包是「系数和为 1」的仿射组合全体，凸包则再要求「系数非负」。三个集合层层嵌套：$\operatorname{conv} S \subseteq \operatorname{aff} S \subseteq \operatorname{lin} S$。求「点集的维数」时用仿射包，求「最小凸容器」时用凸包，求「张成的子空间」时用线性包——用途不同，称谓不能互换。

## 3 凸锥与对偶锥：放大镜下的凸性

**凸锥（convex cone）**：集合 $K$ 是凸锥，若它凸，且对任意 $x \in K$、$\lambda \ge 0$，有 $\lambda x \in K$。等价地：对任意 $x, y \in K$、$\alpha, \beta \ge 0$，$\alpha x + \beta y \in K$——「非负线性组合仍在集合里」。<span class="marginnote">凸锥 = 从原点发射的一组「不拐弯」的方向。区别在于：凸集要求权重和为 1（有界混合），凸锥要求权重非负即可（无界缩放）。把原点当作顶点，凸锥的截面是一个凸集——锥与凸集互相转化。</span>典型例子：非负象限 $\mathbb{R}^n_+$、二阶锥 $\{(x,t) \mid \|x\|_2 \le t\}$、半正定锥 $\mathbb{S}^n_+$——它们分别是 LP、SOCP、SDP 的「标准锥」，也是第5篇锥规划的核心对象。

**对偶锥（dual cone）**：锥 $K$ 的对偶锥是

$$K^* = \{ y \mid \langle x, y \rangle \ge 0,\ \forall\, x \in K \}$$

$K^*$ 由「与 $K$ 中所有元素内积非负」的方向组成——它是 $K$ 的「外法向谱」。常见锥与对偶锥的关系可以列成一张表：

| 锥 $K$ | 定义 | 对偶锥 $K^*$ |
| --- | --- | --- |
| 非负象限 $\mathbb{R}^n_+$ | $x_i \ge 0$ | 自身（自对偶） |
| 二阶锥 | $\|x\|_2 \le t$ | 自身（自对偶） |
| 半正定锥 $\mathbb{S}^n_+$ | $X \succeq 0$ | 自身（自对偶） |
| 过原点半空间 | $a^T x \ge 0$ | 射线 $\{t a : t \ge 0\}$ |

非负象限、二阶锥、半正定锥都**自对偶**（$K^* = K$），这是它们的普适地位的原因；而过原点半空间的对偶锥退化成一维射线，说明「约束越宽，对偶越窄」。<span class="marginnote">验证一下最后一行：$K = \{x : a^Tx \ge 0\}$，若 $y = t a$（$t \ge 0$），则对一切 $x \in K$，$y^T x = t a^T x \ge 0$，故 $ta \in K^*$；反过来任何不在该射线上的 $y$，都能找到 $x \in K$ 使 $y^T x < 0$（分离定理）。所以 $K^* = \{ta : t \ge 0\}$。</span>非负象限的对偶锥是它自己（自对偶），二阶锥与半正定锥也自对偶；一般凸锥的对偶锥仍是凸锥，且 $K^{**} = \operatorname{cl} K$。对偶锥是第4篇「极与对偶运算」的起点，Farkas 引理与对偶定理都从这里生长出来。

**重点：** 凸锥在偏序意义上给了 $\mathbb{R}^n$ 一个「方向结构」：$x \preceq_K y \iff y - x \in K$。广义不等式、锥规划的可行性、对偶锥的分离，全部建立在这条偏序上——这是把「锥」从集合理论推向应用优化的关键一步。

## 4 连接：从凸集到指示函数到凸函数

凸集与凸函数之间，有一条几乎免费的翻译管道：**指示函数**。对任意集合 $C$，定义

$$\delta_C(x) = \begin{cases} 0 & x \in C \\ +\infty & x \notin C \end{cases}$$

则 $C$ 是凸集，当且仅当 $\delta_C$ 是凸函数——「集合的凸性」与「函数的凸性」被一个指示函数焊死。<span class="marginnote">指示函数的几何意义：它把「点是否在 $C$ 里」翻译成「函数值是 0 还是 $+\infty$」。于是带约束的优化 $\min_{x \in C} f(x)$ 可以无约束地写成 $\min_x f(x) + \delta_C(x)$——<strong>约束的代数化</strong>，这是第4篇对偶理论的前提。</span>有了这条管道，这一篇的凸集理论就自动成为第2篇凸函数理论的预科：支撑超平面（第3篇）、共轭函数（第4篇）、次梯度（第5篇），全部可以在集合与函数两种语言之间来回切换。

**重点：** 这条翻译还有一层深意——**凸性与「取极小」相容**。凸集上做投影、凸函数上做最小化，结果唯一且稳定；这是为什么「凸」成了优化的通用语。下一节我们把「取极小」翻译成支撑语言，就得到凸分析的第一个分析定理。

## 5 公式解析：凸集判据与凸组合的充要条件

把「凸」翻译成一个可操作的充要判据，是这套理论最实用的产物。设 $C$ 非空凸集，则 $x \in \operatorname{cl} C$ 当且仅当下列性质对某个方向 $d \ne 0$ 成立：

$$\exists\, \lambda_k \in (0, 1],\ x_k = x + \lambda_k d \in C, \quad \lambda_k \to 0$$

- **第一步，读定义**：$x \in \operatorname{cl} C$ 意味着存在 $C$ 中的点列 $x_k \to x$。把 $x_k$ 写成 $x + \lambda_k d_k$，$d_k$ 是方向、$\lambda_k > 0$ 是步长。
- **第二步，提取方向**：把方向正规化（$\|d_k\| = 1$），再由 $\mathbb{R}^n$ 中单位球紧致，可取收敛子列 $d_k \to d \ne 0$。
- **第三步，凸性登场**：对 $\lambda \in (0,1]$ 的每个点，$\lambda_k$ 单调可控时，利用 $C$ 的凸性把 $x_k$ 与 $C$ 中某个锚点连起来，得到整条线段都在 $C$ 里——闭包里的点总可以「从内部沿某条方向逼近」。
- **第四步，判据化**：这条「沿方向逼近」的表述把抽象的闭包换成了可验证的「射线条件」。它是对偶理论里「支撑超平面存在性」的直接来源。

这条判据的用处在于：**判断一个点是不是凸集闭包的点，只需找一条「射线」**。它与第3篇支撑函数的「支撑超平面 = 边界点的外法线」完全对偶——一个是「找方向」，一个是「找法向」。

## 6 小结

- **凸集**：对任意两点的整条线段封闭；交、仿射像、线性组合保凸，并集不保。
- **凸组合**：$\sum \lambda_i x_i$，$\lambda_i \ge 0$、$\sum \lambda_i = 1$——本质是「概率混合」。
- **凸包** $\operatorname{conv} S$：包含 $S$ 的最小凸集，等于 $S$ 中元素一切凸组合；**Carathéodory**：$\mathbb{R}^n$ 中至多 $n+1$ 个点即可。
- **凸锥**：非负线性组合封闭；**对偶锥** $K^* = \{y \mid \langle x,y \rangle \ge 0,\, \forall x \in K\}$，且 $K^{**} = \operatorname{cl} K$。
- 凸锥定义了广义偏序 $\preceq_K$，是锥规划（LP/SOCP/SDP）的骨架。
- 指示函数把「集合凸」与「函数凸」焊死：约束优化 $\min_{x\in C} f(x)$ 等价于 $\min f(x) + \delta_C(x)$。

在下一节，我们将把凸性从集合搬到函数上——**凸函数**的定义、Jensen 不等式与下半连续性，是连接「几何直觉」与「分析工具」的桥梁。
