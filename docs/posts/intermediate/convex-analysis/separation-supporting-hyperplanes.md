## 为什么从分离定理开始

凸性最深刻的回报不在「集合本身」，而在「集合与其外部之间」：**只要两个凸集不相交，就能用一张超平面把它们从中间劈开**。这个朴素得近乎几何直觉的命题——分离定理——却是整个对偶理论的发动机：Farkas 引理、Lagrange 对偶、KKT 条件、次梯度的存在性，全部由它推出。<span class="marginnote">分离定理可以一句话理解：<strong>两个不相交的凸集，总能被一条直线（超平面）隔在两侧</strong>。直觉上这显然，难的是把「显然」写成可证的定理，并问清楚「隔到多开」——这正是第4篇对偶间隙为零的原因所在。</span>这一篇承接第1篇的凸集与第2篇的凸函数，把第3篇已展开的分离与支撑理论收拢成「一组定理 + 一种几何」，为第4篇对偶、第5篇 KKT 铺设共同地基。

分离定理也是「从极限到大模型」主线上的一枚关键齿轮：机器学习里的线性分类器——感知机、SVM、逻辑回归——本质上都是「找一张分离超平面」。理解了分离定理，你就理解了「为什么线性分类能成功」的几何原因。

分离定理在数学史上地位特殊：它是有限维几何与分析（Hahn–Banach）之间的那道窄门，也是凸分析能「双向翻译」几何与分析的关键。这一篇之后，你会看到同一条定理在 Farkas、Lagrange、KKT 三个位置以三种面貌重演——提前记住这条主线，后面的对偶之旅会顺畅得多。

## 1 超平面与分离：两族点集的「判官」

**超平面（hyperplane）**：形如 $\{ x \mid a^T x = b \}$（$a \ne 0$）的集合，把 $\mathbb{R}^n$ 切成两个**半空间** $\{x \mid a^T x \le b\}$ 与 $\{x \mid a^T x \ge b\}$。一个超平面可以当作「判官」：它用线性函数 $a^T x - b$ 的符号判定点落在哪一侧。

**分离（separating hyperplane）**：超平面 $a^T x = b$ **分离**集合 $C$ 与 $D$，若

$$a^T x \le b \ \ \forall\, x \in C, \qquad a^T x \ge b \ \ \forall\, x \in D$$

也就是 $C$ 整体在左侧（含边界）、$D$ 整体在右侧（含边界）。分离不要求「严格」——超平面可以恰好擦过两个集合。<span class="marginnote">「分离」这个词容易让人以为两个集合必须离得远远的。其实两个集合哪怕只在某点相切，那个「公共切线」仍是分离超平面——分离定理要的不是距离，而是「存在一个线性判别方向」。这正是线性分类器（SVM、感知机）的几何原型。</span>

**算一个具体例子**：把两个点集分开。设 $C = \{(x,y) \mid x^2 + y^2 \le 1\}$（单位圆盘）与 $D = \{(x,y) \mid x \ge 3\}$（右半平面）。取 $a = (1, 0)$、$b = 2$，则对 $x \in C$，$a^T x = x \le 1 \le 2$；对 $x \in D$，$a^T x = x \ge 3 \ge 2$——竖直超平面 $x = 2$ 把两者分开。注意 $x=2$ 并不「贴着」任何一集，这是分离超平面的一般情形。

**再算一个：何时只能「擦边」**。设 $C = \{x : x \le 0\}$（左半闭平面）与 $D = \{x : x \ge 0\}$（右半闭平面），两者共享边界 $x = 0$。超平面 $x = 0$ 把它们分离，但 $0 \in C \cap D$ 同时落在两边边界上——无法严格分开。**这就是「相对内部不相交」的几何含义**：两个集合可以相切，但不能把切点算进任何一方的相对内部。若把 $C$ 改为 $\{x < 0\}$（开），则 $C$ 与 $D$ 的相对内部仍不相交，弱分离依旧成立。

**重点：** 分离是用**线性泛函**把两族点分开。要求 $a \ne 0$（超平面不能退化成整个空间），且 $a$ 只差一个正标量——「分离方向」唯一决定了一族平行超平面，$b$ 决定具体位置。

## 2 分离定理族：从弱分离到严格分离、强分离

分离定理按「隔得有多开」分成三个强度，用途各不相同。

**弱分离（基本分离定理）**：设 $C$ 为非空闭凸集，$x_0 \notin C$，则存在 $a \ne 0$、$b$ 使 $a^T x_0 < b \le a^T x$（对所有 $x \in C$）——点与闭凸集之间必可分离。<span class="marginnote">证明思路先给直觉：取 $C$ 中离 $x_0$ 最近的点 $\bar x$（距离函数 $\|x - x_0\|$ 在紧集上的最小点），那么 $x_0 - \bar x$ 就是分离方向——因为若某个 $x \in C$ 与 $x_0 - \bar x$ 的内积更小，沿 $(1-t)\bar x + tx$ 走会把距离压得更小，矛盾。这条「最近点 = 分离法向」的论证会反复出现在对偶证明里。</span>

**两个凸集的分离**：设 $C, D$ 为非空凸集，相对内部不相交，则存在非零 $a$ 使 $\inf_{x \in C} a^T x \ge \sup_{x \in D} a^T x$。特别地，若 $C, D$ 都闭、其一紧、且互不相交，则存在**严格分离**：$a^T x < b < a^T y$ 对所有 $x \in C, y \in D$。<span class="marginnote">为什么需要「相对内部不相交」而不是「不相交」？因为两个凸集可以相切于同一边界点却不相交，此时只能用「擦边」的分离；相对内部不相交才能保证分离方向不退化。</span>

**强分离**：若 $\operatorname{dist}(C, D) = \inf\{\|x - y\| : x \in C, y \in D\} > 0$（比如 $C$ 紧、$D$ 闭、不相交），则存在超平面**严格分离**两者，且分离方向可归一化——距离本身的梯度就是分离方向。

三个强度可以写成显式的不等式链。弱分离只有非严格不等号，严格分离把等号排除：

$$\inf_{x \in C} a^T x \ \ge\ \sup_{y \in D} a^T y \quad\text{（弱）}, \qquad \inf_{x \in C} a^T x \ >\ \sup_{y \in D} a^T y \quad\text{（严格）}$$

三个强度的差别与适用条件可以汇总成一张表：

| 分离强度 | 成立条件 | 结论 | 典型应用 |
| --- | --- | --- | --- |
| 弱分离 | $C$ 闭凸，$x_0 \notin C$ | $a^T x_0 \le b \le a^T x$（可擦边） | 支撑超平面存在性 |
| 严格分离 | $\operatorname{ri} C \cap \operatorname{ri} D = \emptyset$ | $a^T x < b < a^T y$（严格不等） | Farkas 引理 |
| 强分离 | $\operatorname{dist}(C,D) > 0$ | 严格分离 + 归一化方向 | SVM 最大间隔 |

**重点：** 三个强度的依赖关系是「距离 > 0 ⟹ 严格分离 ⟹ 弱分离」。分离定理的价值不在强度，而在**存在性**：它保证「线性判别方向」总存在，不必真的去找。

**算一个强分离的数值例**：$C = \{x : \|x\|_2 \le 1\}$（单位圆盘）与 $D = \{(3, 0)\}$（单点）。$\operatorname{dist}(C, D) = 2 > 0$，最短连线方向是 $(1, 0)$，强分离超平面 $x = 2$：$C$ 上 $x \le 1 < 2$、$D$ 上 $x = 3 > 2$——严格分离成立。注意分离方向 $a = (1,0)$ 恰是「从 $C$ 指向 $D$」的方向，这正是第4节「距离梯度 = 分离方向」的现身。

**为什么用「相对内部」而非「内部」**：两个凸集若其一退化（如单点或线段），其内部为空，只能退到相对内部。相对内部的定义是「在仿射包内取内部」——一条线段作为 $\mathbb{R}^2$ 中的集合没有内部，但在它自己的仿射包里是开的。正是这个「在自己的壳里开」的概念，让分离定理在退化情形（点、线段、薄多面体）也能正常工作。这也是第1篇「相对内部、仿射包与凸集的维数」那一课在这里再次登场的原因。

## 3 支撑超平面：凸集边界上的切线

**支撑超平面（supporting hyperplane）**：超平面 $a^T x = a^T x_0$（$a \ne 0$）在边界点 $x_0$ 处**支撑**凸集 $C$，若 $a^T x \le a^T x_0$ 对所有 $x \in C$ 成立——超平面「托住」$C$，且只接触于 $x_0$（或接触于边界截面）。

$$\{x : a^T x = a^T x_0\} \ \text{支撑}\ C \quad\Longleftrightarrow\quad a^T x \le a^T x_0,\ \ \forall\, x \in C$$

**支撑超平面定理**：设 $C$ 为非空凸集，$x_0 \in \operatorname{bd} C$，则存在非零 $a$ 使 $a^T x \le a^T x_0$ 对所有 $x \in C$ 成立。<span class="marginnote">支撑超平面就是「边界点处的切平面推广」：可微曲面的切线在非光滑凸集上退化成「一簇支撑方向」，而不再是唯一一条。第3篇的次梯度正由此而生——凸函数在某点的次梯度集合，正是上图在该点支撑超平面的全部斜率。</span>它把「点的外部与集合分离」推广到「集合的边界与集合分离」：$x_0 \in \operatorname{bd} C$ 时，把 $x_0$ 当作「外部点」，用弱分离定理即得——这是凸分析里「以分离证支撑」的标准范式。

**算一个支撑的例子**：单位圆盘 $C$ 在边界点 $x_0 = (0, 1)$ 处，支撑超平面是水平线 $y = 1$（即 $a = (0,1)$、$b = 1$）。所有满足 $\|x\|_2 \le 1$ 的点都有 $x_2 \le 1$，且 $x_0 = (0,1)$ 恰在该线上——切线托住了圆盘。若 $x_0$ 换到内点 $(0,0)$，则不存在任何支撑超平面（任何过原点的直线都会把圆盘切成两半）——**支撑超平面只在边界点存在**。

**应用通道：** 支撑超平面 → 次梯度（第3篇）、支撑函数（第1篇）、Farkas 引理与对偶（第4、5篇）。一条几何定理，是五篇分析理论的共同引信。

**支撑超平面与支撑函数**：把「支撑」换成函数语言，就得到**支撑函数** $\sigma_C(a) = \sup_{x \in C} a^T x$——给定方向 $a$，支撑函数返回「把 $C$ 往方向 $a$ 推到底的值」。$C$ 与它的支撑函数互相决定（$C$ 是半空间 $\{x : a^T x \le \sigma_C(a)\}$ 对一切 $a$ 的交），这是第4篇共轭函数在集合上的雏形——**共轭函数就是「上图」的支撑函数**。记住这条连接，后面第4篇的整个共轭理论都能从支撑超平面这里顺藤摸瓜。

## 4 公式解析：强分离与距离的梯度假说

强分离的「分离方向」其实可以显式给出：两个凸集之间的最短连线，其方向就是分离方向。

$$x^* - y^* = \arg\min_{x \in C,\, y \in D} \|x - y\|, \qquad a = x^* - y^*, \qquad b = \tfrac{1}{2}\left(\|x^*\|^2 - \|y^*\|^2\right)$$

- **第一步，投影存在**：$C$ 紧、$D$ 闭且 $\operatorname{dist}(C,D) > 0$ 时，连续函数 $\|x-y\|$ 在 $C \times D$ 上取到最小点 $(x^*, y^*)$（紧集上的连续函数有最值）。
- **第二步，最优性条件**：$x^*$ 是 $y^* + (C)$ 与球……更直接地，$x^*$ 必须满足「投影不等式」：$\langle y^* - x^*, x - x^* \rangle \le 0$ 对一切 $x \in C$——否则沿 $x$ 走一点距离还会更短。
- **第三步，翻符号**：同样的论证对 $y^*$ 给出 $\langle x^* - y^*, y - y^* \rangle \le 0$ 对一切 $y \in D$。两个不等式相加整理，恰好说明 $a = x^* - y^*$ 满足 $a^T x \le b \le a^T y$ 对所有 $x \in C, y \in D$。
- **第四步，读出结论**：距离的梯度（最短连线方向）就是分离方向，$b$ 取在连线中点，得到严格分离。**「找最短距离」和「找分离超平面」是同一道题的两个侧面。**

**辨析｜易错点：** 弱分离允许超平面「擦边」，两个集合可以同时落在边界上——此时不能说它们「隔开了」，只能说不相交。**「存在分离方向」与「严格分开」是两回事**，后者要求 $\inf_C a^T x > \sup_D a^T y$，需要距离为正或其中一个集合相对内部不相交。做题时先问清楚要哪个强度。

**验算一次**：验证 $C = \{x : x \le 1\}$ 与 $D = \{x : x \ge 2\}$ 的强分离。$\operatorname{dist}(C, D) = 1 > 0$，取 $a = 1$、$b = 1.5$：$C$ 上 $x \le 1 < 1.5$，$D$ 上 $x \ge 2 > 1.5$。把 $b$ 换成 1.3 仍是分离超平面（$C$ 侧 $x \le 1 < 1.3$，$D$ 侧 $x \ge 2 > 1.3$）——**分离超平面不唯一，$b$ 在开区间 $(1,2)$ 里任意取都合法**。这印证了「分离方向决定一族平行超平面、$b$ 决定位置」的直觉。

## 5 连接：分离定理与线性分类器

分离定理在机器学习里最直接的化身是**线性可分性**：若两类样本的凸包不相交，就存在超平面把它们分开——这就是感知机收敛定理的几何前提。**SVM 更进一步**：它不只求「存在一个分离超平面」，还要求「间隔最大」。

$$w^* = \arg\max_{w, b} \ \min_i \frac{y_i (w^T x_i + b)}{\|w\|}$$

这个「最大间隔」问题等价于「找距离最大的强分离超平面」——两个类别的凸包距离 $\operatorname{dist}(C_+, C_-)$ 被最大化，而分离方向恰由最近样本对（支撑向量）决定。<span class="marginnote"><strong>支撑向量的名字就来自支撑超平面</strong>：让间隔边界「托住」样本的那几个点，正是决定最优超平面的极少数样本。强分离定理保证了这种「间隔最大化」超平面存在且唯一。</span>所以当你在第5篇再次见到 KKT 与对偶变量 $\alpha_i$ 时，请记住：它们分析的正是这一节分离定理已经画下的几何。

**从分离到感知机**：感知机（Perceptron）算法在训练样本**线性可分**时保证收敛——证明的几何心脏正是分离定理：若两类凸包不相交，存在分离超平面，感知机每步沿误分样本修正权重，权重向量与分离方向的夹角单调减小，最终收敛。分离定理给了这个 1957 年的算法一个「只要可分就一定停」的承诺。

## 6 分离定理的证明模式与历史

分离定理在数学里有两个面。分析学家认识它，是作为 **Hahn–Banach 定理**的几何版本：在无穷维空间里，「分离」需要把线性泛函从子空间延拓到全空间，几何直觉仍成立但证明更深。凸几何学家认识它，是作为 **Minkowski 的分离定理**：Minkowski 在 19 世纪末研究数的几何（Minkowski 和、凸体理论）时，分离超平面是最核心的引理。两条脉络在 20 世纪中叶由 Fenchel、Rockafellar 等人汇入凸分析，成为对偶理论的共同起点。

**证明的标准模式**：分离定理几乎总是「三步走」——（1）把要证的分离化为「某点到闭凸集的距离」或「两个凸集的距离」；（2）用最近点（投影）的存在性与投影不等式导出分离方向；（3）由分离方向反推出超平面的 $a, b$。这三步在 Farkas 引理、Lagrange 对偶、KKT 的证明里会反复出现，值得内化成肌肉记忆。<span class="marginnote">把分离定理想成一台「定理生成器」：输入「两个不相交的凸集」，输出「一个线性判别方向」。后面所有「存在 $a$ 使……」「存在 $\lambda$ 使……」的证明，本质上都是这台机器的一次调用。</span>

**为什么分离定理如此普遍**：因为它只用了「凸 + 线性」两种原料。凸保证「集合不外弯」，线性保证「方向可叠加」——两者的交集，正是「最优性条件」「对偶性」「次梯度存在性」这类结论能成立的最小共同点。这也是 Rockafellar 那句话「分水岭是凸与非凸」的深层原因。

## 7 小结

- **超平面** $a^T x = b$ 把空间劈成两个半空间，作为「线性判官」判定点在哪一侧。
- **分离**：$C$ 在左、$D$ 在右（$a^T x \le b \le a^T y$）——存在一个线性判别方向。
- **三个强度**：弱分离（凸即可）、严格分离（距离 > 0）、强分离（距离 > 0 且归一化）——强度由集合的「分开程度」决定。
- **支撑超平面定理**：边界点处存在超平面托住凸集；次梯度、支撑函数由此而生。
- 分离定理是**对偶理论的发动机**：Farkas、Lagrange 对偶、KKT、次梯度存在性全部从它推出。
- **线性分类器 = 找分离超平面**；SVM 的最大间隔正是强分离在距离意义下的最优版本。
