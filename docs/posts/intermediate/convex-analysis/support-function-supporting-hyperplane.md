## 为什么从支撑函数开始

上一节的分离定理给了我们一个视角的转变：
**一个凸集可以由它的全体支撑超平面重新刻画**。
把这一视角「函数化」，就得到**支撑函数（support function）**——它把每个方向 $y$ 对应到凸集在该方向上的「最远支撑位置」。
凸集的几何信息被完整地编码进了一个数值函数，
而函数是可以求导、可以组合、可以做对偶的。
<span class="marginnote">这是凸分析里「对偶观点」的第一次正式亮相：不再直接盯着集合本身，而是盯着「集合在所有方向上怎么看」。
这套「用所有线性泛函的取值刻画对象」的思路，
与泛函分析中 Hahn–Banach 定理、以及大模型表征学习中「用探针（linear probe）读取特征」的做法同出一辙。
</span>

## 1 支撑超平面

**支撑超平面（supporting hyperplane）**：
设 $C$ 是凸集，$x_0 \in C$。
若存在 $a \ne 0$ 使

$$a^T x \le a^T x_0, \qquad \forall\, x \in C$$

则超平面 $\{x \mid a^T x = a^T x_0\}$ 称为 $C$ 在 $x_0$ 处的支撑超平面。<span class="marginnote">几何上：这张超平面过边界点 $x_0$，且整个 $C$ 都落在它的一侧（$a$ 指向外侧）。圆盘在边界点的切线就是支撑超平面的 $\mathbb{R}^2$ 版本；多面体在每个顶点、每条棱上都有支撑超平面。</span>

**支撑超平面定理**（上一节已述）：对闭凸集 $C$ 边界上的任一点，存在支撑超平面。**重点：** 这条定理反过来也「几乎」成立——一个集合如果在其每一点都能被支撑超平面支撑住，那它必是凸集（对闭集而言）。支撑性 ⇔ 凸性，这正是「凸性可以被支撑性刻画」的精确表述。

## 2 支撑函数的定义

**支撑函数（support function）**：凸集 $C$ 的支撑函数 $\sigma_C : \mathbb{R}^n \to \mathbb{R} \cup \{+\infty\}$ 定义为

$$\sigma_C(y) = \sup_{x \in C} \langle x, y \rangle$$

其中 $\langle x, y \rangle = y^T x$ 是内积。
<span class="marginnote">把 $y$ 固定，$\langle x, y \rangle$ 是 $x$ 的线性函数，$\sigma_C(y)$ 就是它「在 $C$ 上能取到的最大值」。
若 $C$ 无界且在该方向无上界，$\sigma_C(y) = +\infty$——所以支撑函数的值域要带上 $+\infty$，
这是凸分析里「广义实值函数」第一次登场。
</span>

几何上，$\sigma_C(y)$ 回答了：
**沿方向 $y$ 看，$C$ 最深能伸到哪里。**
对单位球 $B = \{x \mid \|x\| \le 1\}$，
$\sigma_B(y) = \|y\|$——因为在 $y$ 方向最远点是 $y/\|y\|$，
内积恰为 $\|y\|$。
这条平凡的例子已经透出支撑函数与**范数**的亲缘关系。

## 3 支撑函数的性质

支撑函数有一套与凸集运算完全平行的代数，
这是它「好用」的原因：

- **刻画凸集**：若 $C$ 闭凸，则 $C = \{x \mid \langle x, y \rangle \le \sigma_C(y),\; \forall\, y\}$——集合被其支撑函数**完全决定**。
- **包含 ⇔ 逐点小**：$C_1 \subseteq C_2$ 当且仅当 $\sigma_{C_1}(y) \le \sigma_{C_2}(y)$ 对所有 $y$ 成立。
- **Minkowski 和拆开**：$\sigma_{C_1 + C_2}(y) = \sigma_{C_1}(y) + \sigma_{C_2}(y)$。
- **数乘**：$\sigma_{\lambda C}(y) = \lambda\, \sigma_C(y)$（$\lambda \ge 0$），以及 $\sigma_C(\lambda y) = \lambda \sigma_C(y)$。
- **凸包不改变支撑**：$\sigma_{\operatorname{conv} C}(y) = \sigma_C(y)$——支撑函数看不见集合的凹陷。

**重点：** 支撑函数是**正齐次**的（$\sigma_C(\lambda y) = \lambda \sigma_C(y)$ 对 $\lambda \ge 0$）且**次可加**的（$\sigma_C(y_1 + y_2) \le \sigma_C(y_1) + \sigma_C(y_2)$）。
正齐次 + 次可加 = **凸函数**（本质上是「闵可夫斯基泛函」结构），
这是支撑函数与范数、半范数共享的同一种代数身份。

**辨析｜易错点：** 支撑函数取 $+\infty$ 不表示集合「坏」——它只是说明集合沿某方向无界（如半空间 $\{x \mid a^T x \le 0\}$ 在 $y = a$ 方向的支撑为 $+\infty$）。
**只有闭凸集才能被支撑函数无信息损失地刻画**：
若 $C$ 不闭，$\sigma_C = \sigma_{\overline{C}}$，
开集与它的闭包共享同一个支撑函数。

## 4 公式解析：支撑函数与次可加性

$$\sigma_C(y_1 + y_2) = \sup_{x \in C} \langle x, y_1 + y_2 \rangle \le \sigma_C(y_1) + \sigma_C(y_2)$$

- **第一步，内积线性**：$\langle x, y_1 + y_2 \rangle = \langle x, y_1 \rangle + \langle x, y_2 \rangle$——内积对第二个变量是线性的，这一步把「和方向」拆成「两个方向」。
- **第二步，分别取上确界**：对固定 $x$，$\langle x, y_1 \rangle \le \sup_{x' \in C}\langle x', y_1\rangle = \sigma_C(y_1)$，另一项同理。
- **第三步，相加**：两式相加得 $\langle x, y_1 + y_2 \rangle \le \sigma_C(y_1) + \sigma_C(y_2)$。
- **第四步，再取上确界**：对左边关于 $x$ 取 $\sup$，右边与 $x$ 无关，即得次可加不等式。

注意证明里「分别放缩」会损失信息：使第一项取到 $\sigma_C(y_1)$ 的 $x$ 与使第二项取到 $\sigma_C(y_2)$ 的 $x$ 未必是同一个，所以不等式一般是严格的——这正是「上确界的和 ≥ 和的上确界」这一分析学基本事实。**次可加性让支撑函数成为天然的「度量函数」，也让 $\sigma_C$ 的共轭（第4篇）成为对偶理论的枢纽。**

## 5 常见凸集的支撑函数表

支撑函数是「凸集的对偶语言」，把常见凸集的支撑函数背下来，等于掌握了一套查表工具：

| 凸集 $C$ | 支撑函数 $\sigma_C(y)$ | 备注 |
| --- | --- | --- |
| 单位球 $\{x : \|x\|_2 \le 1\}$ | $\|y\|_2$ | 球自对偶 |
| 单位 $\ell_1$ 球 | $\|y\|_\infty$ | L1 球 ↔ 对偶范数 |
| 单位 $\ell_\infty$ 箱 | $\|y\|_1$ | 对偶再交换 |
| 椭球 $\{x : (x-x_0)^T P^{-1}(x-x_0) \le 1\}$ | $y^T x_0 + \sqrt{y^T P y}$ | $P \succ 0$ |
| 半空间 $\{x : a^T x \le b\}$ | $b$（若 $y = a$）否则 $+\infty$ | 仅在方向 $a$ 有限 |
| 多面体 $\{x : Ax \le b\}$ | $\max_{v \text{ 顶点}} v^T y$ | 分片线性（第26节） |
| 概率单形 $\{p \succeq 0, 1^T p = 1\}$ | $\max_i y_i$ | 取最大分量 |

这张表最值得记住的是**范数与对偶范数**三行：$\sigma_{\{\|x\| \le 1\}}(y) = \|y\|_*$——**单位球的支撑函数恰是对偶范数**。这一句把「支撑函数」「对偶范数」「Hölder 不等式」三个概念焊在一起：$\langle x, y \rangle \le \|x\| \|y\|_*$ 正是 Hölder 不等式在支撑函数语言下的形态。

**重点：** 支撑函数给出「凸集 = 一堆线性不等式的交集」的最优版本：$C = \{x \mid \langle x, y \rangle \le \sigma_C(y),\ \forall y\}$。对**每个方向** $y$ 用支撑函数值 $\sigma_C(y)$ 收紧一个不等式，全体方向的不等式之交恰好还原 $C$——这正是第5节「闭凸集被支撑函数决定」的展开形态。<span class="marginnote">这个「用所有方向的支撑不等式重构集合」的思想，在机器学习里以「对偶范数正则」「谱范数约束」的形式反复出现：约束权重的谱范数，等价于「对任意方向限制其投影」。</span>

**辨析｜易错点：** 支撑函数取 $+\infty$ 的集合**并不稀疏**——它说明「沿那个方向无界」。例如无界多面体在指向极值方向的方向上支撑为 $+\infty$。**$+\infty$ 不是「集合不存在」，而是「集合在那个方向没有墙」**——读支撑函数时，$+\infty$ 与有限值传达完全不同的几何信息。

## 6 小结

- **支撑超平面**：过边界点、整个凸集落在其一侧的超平面；闭凸集的支撑性 ⇔ 凸性。
- **支撑函数** $\sigma_C(y) = \sup_{x \in C} \langle x, y \rangle$：把凸集编码成「沿每个方向的最远位置」，值域含 $+\infty$。
- **闭凸集被支撑函数完全决定**；$C_1 \subseteq C_2 \iff \sigma_{C_1} \le \sigma_{C_2}$
