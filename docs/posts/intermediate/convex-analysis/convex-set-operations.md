## 为什么从保运算开始

上一节只验证了几个具体集合是凸的。
但现实中的凸集几乎从不「一次写清」——它们是**由若干基本凸集通过运算组装起来的**：
可行的资源分配集合是若干半空间的交，投资的组合空间是几个集合的线性和，
机器人的关节角约束是笛卡尔积。
要让「凸性」这门语言有用，必须回答一个问题：
**哪些运算保持凸性？**

这就是「保运算」的意义。
<span class="marginnote">在「从极限到大模型」的课程坐标里，
这节内容把线性代数的「线性映射」「子空间」翻译成集合的语言，
并直接喂养后面多面体理论（第5篇）与凸优化的建模能力。
大模型的注意力约束、token 池的凸包、可行策略集，
都靠这些运算拼装。
</span> 我们也将第一次看到一种不对称性——有些运算保凸，有些（如并集）不保，理解这组规则就是理解凸分析的「语法」。

## 1 保运算清单

把常用的保凸运算先陈列出来，再逐个解释：

**交**：任意多个凸集的交集是凸集。
**仿射映射**：凸集在 $f(x) = Ax + b$ 下的像与原像都是凸集。
- **线性和（Minkowski 和）**：$C_1 + C_2 = \{x_1 + x_2 \mid x_1 \in C_1, x_2 \in C_2\}$ 是凸集。
- **数乘与平移**：$\alpha C$ 与 $C + b$ 都是凸集（仿射映射的特例）。
- **笛卡尔积**：$C_1 \times C_2$ 是凸集。
- **投影与反投影**：凸集在坐标子空间上的投影（部分分量置零）是凸集。

**重点：** 这组运算的意义在于——**只要输入的集合是凸的，
输出就自动是凸的，不需要重新验证**。
这是「凸性可计算」的根本保证：构造与验证的复杂度被分离了。

## 2 交：从基本块构造一切

凸集的交保持凸性，且**对任意多个集合成立**（不限于有限个）。
证明是直线的：设 $x, y$ 属于所有 $C_\alpha$ 的交，
对任意 $\theta \in [0,1]$，
线段 $\theta x + (1-\theta)y$ 的每一点都同时属于每个 $C_\alpha$（因每个 $C_\alpha$ 都凸），
故属于交集。

**半空间是最基本的积木。**
一个线性不等式 $a^T x \le b$ 定义了一个闭半空间，
它是凸的；
$m$ 个线性不等式联立，其解集就是 $m$ 个半空间的交，
因此自动凸。
这正是线性规划可行域的几何来源。
<span class="marginnote">在第三级《线性代数》里你已经见过线性方程组 $Ax = b$ 的解集（一个仿射子空间，凸）；
现在把「等式」放宽为「不等式」，解集从仿射子空间拓宽为多面体，
但凸性保持——凸分析在此与线性代数无缝衔接。
</span>

**辨析｜易错点：** 交保凸，**并集不保凸**。
$\{[0,1]\} \cup \{[2,3]\}$ 是两个凸集（各是区间）的并，
但取 $x = 0.5 \in$ 第一个、$y = 2.5 \in$ 第二个，
线段中点 $1.5$ 不在并集里。
若实在需要「并出来的凸集」，得用凸包 $\operatorname{conv}(A \cup B)$ 代替——这是建模中常见的取舍。

## 3 仿射变换与逆像

设 $f(x) = Ax + b$ 是仿射映射，
$C$ 是凸集。
则：

**像** $f(C) = \{Ax + b \mid x \in C\}$ 是凸集；
**原像** $f^{-1}(C) = \{x \mid Ax + b \in C\}$ 是凸集。

这两条合起来的意思是：**凸性在仿射坐标变换下不变**。
<span class="marginnote">直觉上，仿射映射把直线映成直线、把线段映成线段——既然凸性只依赖「线段是否在内」，而线段的像仍是线段，凸性自然被保存。
把坐标系平移、旋转、拉伸，凸集依然凸。
</span>

几个重要特例：数乘 $\alpha C$（取 $A = \alpha I, b = 0$）、平移 $C + b$、以及**投影到子空间**（取 $A$ 为投影矩阵）。
后者说明：把凸集「压扁」到某个坐标平面或子空间上，
仍得到凸集——这是后面研究凸集结构时反复使用的工具。

**辨析｜易错点：** 仿射映射保凸，但**非线性映射一般不保凸**。
例如 $x \mapsto x^2$ 把区间 $[-1, 1]$（凸）映为 $[0, 1]$（凸），
好像没问题；
但 $x \mapsto x^3$ 仍把区间映为区间，
也保凸——真正危险的是「把凸集映成非凸集」的非线性映射，
如正弦映射把区间映成振荡的像。
**判定时不要凭直觉，要回到「线段像是否仍是线段」这个标准。**

## 4 线性和与投影

**Minkowski 和（线性和）**：
$C_1 + C_2 = \{x_1 + x_2 \mid x_1 \in C_1, x_2 \in C_2\}$。
<span class="marginnote">Minkowski 和的几何直觉是「以一个集合为模板，沿另一个集合扫过去」：区间 $[0,1] + [0,1] = [0,2]$；
一个圆盘加一个小圆盘还是一个更大的圆盘。
它把「叠加」从标量推广到集合。
</span> 它保持凸性：若 $x_1 + x_2$ 与 $y_1 + y_2$ 是 $C_1 + C_2$ 中两点，则

$$\theta(x_1+x_2) + (1-\theta)(y_1+y_2) = \big(\theta x_1 + (1-\theta)y_1\big) + \big(\theta x_2 + (1-\theta)y_2\big) \in C_1 + C_2$$

因为括号里的两项分别属于凸集 $C_1$、$C_2$。**这个「按分量分别组合再相加」的技巧是整个证明的关键。**

**投影**：设 $C$ 凸，$P_C$ 是到 $C$ 上的欧氏投影（对每个点取最近点）。投影算子的存在性（凸集上最近点唯一）本身就是凸性的深刻后果，这里先用一条较弱的：**凸集到仿射子空间的投影（把某些坐标清零）仍是凸集**。<span class="marginnote">完整的投影理论——投影算子的非扩张性、单调性、以及用它构造的投影梯度法——是凸优化算法的核心引擎，我们在第3篇讲次梯度方法时会再回到它。</span>

## 5 公式解析：Minkowski 和的凸性证明

以两点情形为模板，拆解上面那条恒等式：

$$z_\theta = \theta(x_1+x_2) + (1-\theta)(y_1+y_2)$$

- **第一步，目标**：要证 $z_\theta \in C_1 + C_2$，只需把它写成「$C_1$ 中一点 + $C_2$ 中一点」。
- **第二步，重组**：按 $C_1$、$C_2$ 分别归拢，$z_\theta = [\theta x_1 + (1-\theta)y_1] + [\theta x_2 + (1-\theta)y_2]$。两个方括号各自是凸组合。
- **第三步，用凸性**：$C_1$ 凸 ⇒ 第一个方括号属于 $C_1$；$C_2$ 凸 ⇒ 第二个方括号属于 $C_2$。
- **第四步，结论**：两项之和属于定义中的集合，故 $z_\theta \in C_1 + C_2$，Minkowski 和保凸。

这条证明的「重组」手法——**先按来源归拢，
再分别调用凸性**——在凸分析的运算规则（和的次微分、共轭的卷积等）里会反复出现。
记住这个模式，等于掌握了凸性证明的通用语法。

## 6 保运算的建模实战：从约束到可行域

保运算的价值不在理论上，而在建模时能「凭空造出」凸可行域。
三个最常出现的场景：

**场景一：资源分配。** 设你有 $n$ 种资源、$m$ 个项目，
$x_i$ 是投入项目 $i$ 的量，总量受预算 $b$ 约束。
可行域是「半空间交 + 非负象限」：

$$X = \{ x \ge 0 \mid 1^T x \le b,\ x_i \le u_i \}$$

它是 $m+1$ 个半空间与非负象限的交——**全部凸**，所以整个资源分配问题（无论目标多复杂）的可行域自动凸。<span class="marginnote">这是「交保凸」的直接工程红利：约束叠加得再多，只要每个约束都是线性/凸约束，可行域就始终是凸的，优化就有全局保证。</span>

**场景二：组合投资。** 资产组合 $x$ 的可行集是「权重和为 1 + 每项权重有上下限」：$\{x \mid 1^T x = 1,\ l \le x \le u\}$。仿射子空间（等式约束）与箱（区间）的交，凸。而**两个组合的 Minkowski 和** $x + y$ 对应「把两类头寸叠加」——它也是凸集，说明叠加后的组合空间仍合法。

**场景三：集合的「外包」与「投影」。** 当你面对一个非凸集合（如「整数可行域」$\mathbb{Z}^n \cap P$），建模的惯用招数是：**取凸包或投影**。整数变量的 LP 松弛就是把 $\mathbb{Z}^n$ 换成 $\mathbb{R}^n$——把非凸可行域「凸化」成超多面体。<span class="marginnote">凸化是有代价的（可能引入分数解、需要分支定界回补），但它是「把非凸问题变凸」的第一道工序。保运算告诉我们：投影、凸包、线性变换都不会破坏我们已经建好的凸性。</span>

**辨析｜易错点：** 保运算只能保「输入凸」的凸性，**不能把非凸输入变凸**。$C_1, C_2$ 都是凸时，$C_1 \times C_2$ 才自动凸；若其中一个是非凸的（比如含整数约束），结果不凸。**建模时先确认「每个原料集合都是凸的」，再谈保运算。**

## 7 小结

- 保凸运算清单：**交、仿射映射（像与原像）、Minkowski 和、数乘、平移、笛卡尔积、投影**。
- 凸性对**任意多集合的交**封闭，因此半空间之交所构成的多面体自动凸。
- **并集不保凸**，需要时用凸包 $\operatorname{conv}(A \cup B)$
