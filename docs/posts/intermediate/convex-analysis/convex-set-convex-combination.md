## 为什么从凸集开始

凸分析的全部武器——分离定理、次梯度、共轭函数、对偶性——都建在一个最朴素的对象之上：
**凸集（convex set）**。
它说穿了就一句话：集合里任意两点的连线段仍落在集合里。
可正是这条看似简单的性质，让「局部最优 = 全局最优」成为可能，
让优化算法拥有可证明的收敛保证。

在「从极限到大模型」的主线上，凸集是第一块关键的几何基石。
<span class="marginnote">第一级《集合的概念》确立了「点集」的语言，线性代数则给出 $\mathbb{R}^n$ 中直线与超平面的坐标描述；
凸集正是这两者交汇出的第一类有几何结构的集合。
</span> 大模型训练中的可行域、强化学习策略的约束集、以及一切优化问题的可行解集合，往往要么本身是凸的，要么需要被「凸松弛」成凸的——理解了凸集，你才真正看懂「为什么这些算法可行」。

## 1 凸集的定义

设 $C$ 是 $\mathbb{R}^n$ 中的集合。
**凸集（convex set）**：若对任意 $x, y \in C$ 与任意 $\theta \in [0, 1]$，
都有

$$\theta x + (1-\theta) y \in C$$

则称 $C$ 是凸集。<span class="marginnote">这里 $\theta$ 从 $0$ 取到 $1$，$\theta x + (1-\theta)y$ 恰好扫过以 $x, y$ 为端点的整条线段；$\theta = 1$ 时回到 $x$，$\theta = 0$ 时回到 $y$，中间值给出线段内部的点。</span> 直观地说：**凸集就是「怎么连，都不会漏出去」的集合**。

看几个典型例子：

- **线段、直线、超平面与半空间**：$\{x \mid a^T x = b\}$ 与 $\{x \mid a^T x \le b\}$ 都是凸集。
- **单位球** $\{x \mid \|x\| \le 1\}$ 是凸的，球面 $\{x \mid \|x\| = 1\}$ 不是。
- **整个空间** $\mathbb{R}^n$ 与**空集** $\emptyset$ 都是凸集——它们常被当作平凡但必要的极端情形。
- 有限点集 $\{x_1, x_2\}$ 一般不是凸集，除非两点重合。

**辨析｜易错点：** 「凸集」判定的要点是**任意**两点都要验证。画一个「月牙形」或「U 形」区域，只要你能找到一对点使连线段漏出区域，它就不是凸集。还要注意：**空集与单点集都是凸集**，很多初学者想当然地认为凸集必须「足够大」——判断凸性只问线段，不问大小。

## 2 凸组合与仿射组合

**凸组合（convex combination）**：设 $x_1, \dots, x_k \in \mathbb{R}^n$，$\theta_i \ge 0$ 且 $\sum_{i=1}^{k} \theta_i = 1$，则

$$x = \sum_{i=1}^{k} \theta_i x_i$$

称为 $x_1, \dots, x_k$ 的凸组合。
<span class="marginnote">凸组合把「加权平均」的思想推广到多点：$\theta_i$ 是权重，非负且总和为 $1$，结果是这些点的「质心」。
两点情形的凸组合就是线段；
三点情形的全体凸组合就是三角形区域。
</span>

与之相对的是**仿射组合（affine combination）**：
只要求 $\sum \theta_i = 1$，
不要求 $\theta_i \ge 0$。
二者一字之差，几何上差了一个维度——仿射组合张出整条直线或整个仿射包，
凸组合只张出夹在点之间的凸包区域。
<span class="marginnote">把「权重非负」放进去，就是「不往回走」的约束；
去掉它，就允许沿着直线的两端无限延伸。
这个差别会决定后面凸包与仿射包是两种不同的几何对象。
</span>

**重点：** 凸集的定义等价于——**凸集对「任意的凸组合」封闭**。
两点凸组合封闭 ⇔ 任意有限点凸组合封闭，
这是由数学归纳法保证的。

## 3 凸包

**凸包（convex hull）**：
集合 $C$ 的凸包记作 $\operatorname{conv} C$，
是包含 $C$ 的**最小凸集**。
等价地，它等于 $C$ 中元素的所有凸组合构成的集合：

$$\operatorname{conv} C = \left\{ \sum_{i=1}^{k} \theta_i x_i \;\middle|\; x_i \in C,\ \theta_i \ge 0,\ \sum_{i=1}^k \theta_i = 1,\ k \ge 1 \right\}$$

凸包是「把凹陷填平」的操作：它把 $C$ 外包一层凸壳，抹掉所有凹进去的部分。<span class="marginnote">给 $C$ 加上一个形如「凸性」的包裹，代价是集合可能变大；这个「变大」正是凸松弛（convex relaxation）的代价，后面在非凸问题里我们会用凸包换取可解性。</span>

**辨析｜易错点：** 凸包、仿射包、锥包是三个容易混淆的概念。仿射包 $\operatorname{aff} C$ 是包含 $C$ 的最小仿射子空间（两点连线无限延长）；锥包 $\operatorname{cone} C$ 是包含 $C$ 的最小凸锥（射线封闭）；凸包则只需线段封闭。三者关系是 $\operatorname{conv} C \subseteq \operatorname{aff} C$，且凸包一定包含在仿射包里。一个经典事实：**$\operatorname{conv}(C) = \operatorname{aff}(C) \cap \operatorname{cone}(C + \{x_0\})$ 当 $x_0 \in C$ 取适当点时成立**——但初学者不必纠缠这个恒等式，先分清三者的几何形象即可。

## 4 凸集的基本性质

凸集在多种「结构运算」下保持凸性，这一节先看最基本的几条，系统化的保运算规则在下一篇展开。

- **任意交**：一族凸集的交集是凸集。证明只需一句：取交集中两点，连线段的每一点都在每个成员集里，故在交集中。这个性质是「用约束刻划可行域」的理论基石——线性不等式组的解集就是半空间的交，天然凸。
- **闭包与内部**：若 $C$ 凸，则其闭包 $\overline{C}$ 与内部 $\operatorname{int} C$ 也凸。
- **连通性**：凸集必是连通集——它甚至更强，是「线段连通」的。
- **映射下的像与原像**：线性（仿射）映射把凸集映为凸集；凸集在线性映射下的原像也凸。这条性质使投影、伸缩、平移都不会破坏凸性。

**重点：** 凸性对**交、线性映射、闭包、内部**都封闭，但对**并集**不封闭——两个凸集的并一般不是凸集。这一「不对称」是全部分离理论、对偶理论反复使用的结构性事实。

## 5 公式解析：凸组合公式

把凸组合公式拆开看，它同时封装了「非负」与「归一」两个约束：

$$\theta x + (1-\theta) y, \qquad \theta \in [0,1]$$

- **第一步，两个系数非负**：$\theta \ge 0$ 与 $1-\theta \ge 0$ 保证组合不会「越过端点」向外延伸——点被夹在 $x$ 与 $y$ 之间。
- **第二步，系数归一**：$\theta + (1-\theta) = 1$ 使组合是「加权平均」而不是「放缩」——组合点不会整体漂移出两点的仿射包。
- **第三步，几何后果**：$\theta$ 从 $0$ 变到 $1$ 时，$\theta x + (1-\theta)y$ 沿直线匀速扫过线段。$\theta = \frac{1}{2}$ 即中点，$\theta = \frac{1}{3}$ 则更靠近 $y$（因为 $y$ 的系数更大）。
- **第四步，推广到多点**：多个点的凸组合 $\sum \theta_i x_i$ 是「非负权重下的质心」，当权重取 $0$ 或 $1$ 时退化为某个端点，取均匀权重时是所有点的算术平均。

这一公式是整门凸分析的语法基础：**凸集 = 对凸组合封闭**，
后面一切「凸函数」「凸包」「分离定理」的定义都从这里生长出来。

## 6 凸集实例：从几何到数据

把「凸 / 非凸」的直觉建立起来，最好的办法是看一批典型集合并逐一判别。
下面这张表覆盖了从几何到数据科学最常见的例子，
每一行都值得亲手验证一次「线段封闭性」：

| 集合 | 表达 | 凸性 | 理由 |
| --- | --- | --- | --- |
| 超平面 | $\{x \mid a^T x = b\}$ | 凸 | 线段在超平面上 |
| 半空间 | $\{x \mid a^T x \le b\}$ | 凸 | 线段不越界 |
| 单位球 | $\{x \mid \|x\|_2 \le 1\}$ | 凸 | 三角不等式 |
| 球面 | $\{x \mid \|x\|_2 = 1\}$ | **非凸** | 两点间弦穿过球内 |
| 正象限 | $\{x \mid x_i \ge 0\}$ | 凸 | 非负组合保持非负 |
| 仿射子空间 | $\{x \mid Ax = b\}$ | 凸 | 线性方程解集 |
| 单项锥 | $\{x \mid x_i \le x_1, i\ge 2\}$ | 凸 | 半空间之交 |
| 星形区域 | $\{x \mid x_1^2 \ge x_2\}$ | **非凸** | $x_1^2 \ge x_2$ 是凹区域 |
| 整数格点 | $\mathbb{Z}^n$ | **非凸** | 两整数点中点为分数 |

这张表里最有教学意义的一行是**球面**：
直觉上「圆滑」的东西并不自动凸——凸性看的是线段，
不是光滑。
球面处处圆滑，但任何两点的连线段都严格穿过球内，
线段中点不在球面上，所以非凸。

**重点：** 数据科学里的凸集无处不在。
概率单形 $\{p \in \mathbb{R}^n_+ \mid \sum p_i = 1\}$（概率分布集合）、以及经验风险最小化的可行域（半空间交）都是凸集。
<span class="marginnote">概率单形是「所有分布」的集合，它的凸性说明：两个分布的凸组合仍是分布——这正是混合模型、模型平均、以及大模型里的 token 采样（softmax 概率的混合）的几何基础。
</span>

**辨析｜易错点：** 「两个凸集的交集凸」这一性质让我们可以放心地用「多个线性/半空间约束」搭可行域；
但反过来，**「并集」或「差集」几乎必毁凸性**。
