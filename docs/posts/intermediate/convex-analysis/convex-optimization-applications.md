## 为什么从应用收束

凸分析的三十年兵器——凸集、分离定理、次梯度、共轭、对偶、KKT、锥规划——在这里统一检阅。
机器学习最经典的三类模型：**最小二乘（含岭回归与 LASSO）、逻辑回归、支持向量机**，
每一个都是凸优化问题：目标凸、约束凸（或无约束），
KKT 完备，全局最优有保证。
学完它们，等于亲眼看到「凸性」如何把「能解」变成「有理论保证地能解」。
<span class="marginnote">在「从极限到大模型」主线上，这三类模型是通向深度学习的最后一站：深度网络的非凸性让凸分析不能直接全局套用，但<strong>局部</strong>分析（凸片、梯度单调、正则化）依然处处借力。
凸优化在统计学习里的统治地位，正是大模型时代「为什么还要学凸分析」的答案——它是理解所有「更复杂的优化」的基线。
</span>

## 1 最小二乘与正则化

**线性最小二乘（least squares）**：

$$\min_x \| Ax - b \|_2^2$$

这是凸分析第一个「闭式解」案例：$f(x) = \|Ax - b\|^2$ 是凸二次函数，梯度 $\nabla f = 2A^T(Ax - b)$，令其为零得**正规方程（normal equations）**

$$A^T A x = A^T b$$

$A^T A$ 满秩时唯一解 $x^* = (A^T A)^{-1} A^T b$。
<span class="marginnote">这条闭式解是「梯度为零 + 凸性 ⇒ 全局最优」的最直接演示：不需要迭代，KKT 条件直接解出。
数值上一般不直接求逆，而是用 QR 分解或 SVD 求解——数值线性代数的内容，
但结论归功于凸性。
</span>

**岭回归（ridge, L2 正则）**：
$\min \|Ax - b\|^2 + \lambda \|x\|_2^2$，
正规方程变为 $(A^T A + \lambda I)x = A^T b$——加 $\lambda I$ 让 $A^T A$ 病态时也可逆，
且解被「收缩」。
**LASSO（L1 正则）**：$\min \|Ax - b\|^2 + \lambda \|x\|_1$，
目标不再可微，最优解在 $0$ 处有稀疏结构。
<span class="marginnote">LASSO 的稀疏性来自 $\|x\|_1$ 的「菱形」等值面：等高线与坐标轴相切的位置恰好产生零分量。
它的求解不再有闭式解，而要用次梯度/近端梯度/坐标下降——正是第3篇次梯度方法及其升级版的用武之地。
</span>

**辨析｜易错点：** L2 正则（岭）**收缩但不稀疏**，
L1 正则（LASSO）**稀疏但不收缩充分**——两者都是凸问题但几何完全不同。
**「加正则还是凸」成立的前提是正则项凸且权重非负**；
换成非凸惩罚（如 $L_0$ 的松弛不当）凸性就丢。

## 2 逻辑回归

**逻辑回归**：给定样本 $(x_i, y_i)$，
$y_i \in \{0, 1\}$，拟合条件概率 $P(y=1 \mid x) = \sigma(w^T x + b)$（$\sigma$ 是 sigmoid）。
**负对数似然**

$$\min_{w} \sum_{i=1}^{N} \Big( -y_i \log \sigma(w^T x_i + b) - (1-y_i)\log\big(1 - \sigma(w^T x_i + b)\big) \Big)$$

是**凸函数**（它是交叉熵，即 log-sum-exp 的复合，第10节的保凸运算保证）。<span class="marginnote">凸性说明逻辑回归没有局部极小陷阱，梯度下降/牛顿法都收敛到全局最优。它的 Hessian 是半正定矩阵 $\sum \sigma_i(1-\sigma_i) x_i x_i^T$——恰好是加权协方差结构，这也让「迭代重加权最小二乘」（IRLS）天然适用。</span>

**重点：** 逻辑回归同时是**广义线性模型**（GLM）的特例——GLM 的负对数似然对凸的链接函数都是凸的。它把「分类」这个看似离散的问题，变成了一个光滑凸优化问题，是「凸性让离散问题可微化」的教科书案例。

## 3 支持向量机（SVM）

**支持向量机（软间隔）**：在 $\mathbb{R}^n$ 上找最大间隔分类器

$$\min_{w, b} \frac{1}{2}\|w\|_2^2 + C \sum_{i=1}^{N} \max\big(0, 1 - y_i (w^T x_i + b)\big)$$

其中 $\max(0, 1 - y_i(w^T x_i + b))$ 是**合页损失（hinge loss）**——分对且间隔足够大时为 $0$，
否则线性惩罚。
<span class="marginnote">这个目标是「L2 正则 + 合页损失」，两项都凸，故整体凸。
合页损失是<strong>多面体凸函数</strong>（分片线性，
第26节），所以 SVM 是一个<strong>凸 QP</strong>：
引入松弛变量 $\xi_i \ge 0$ 后可写成二次目标 + 线性约束，
KKT 条件完备。
</span>

**SVM 对偶**：用 Lagrange 对偶（第21节）把 SVM 化为对偶问题

$$\max_\alpha \sum_i \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y_i y_j x_i^T x_j \quad \text{s.t.} \quad 0 \le \alpha_i \le C,\ \sum_i \alpha_i y_i = 0$$

**重点：** 对偶问题里样本只以内积 $x_i^T x_j$ 出现——这正是**核方法（kernel trick）**的入口：把内积换成核函数 $K(x_i, x_j)$，SVM 就线性地进入高维特征空间。互补松弛（第24节）给出支撑向量的刻画：**只有 $\alpha_i > 0$ 的样本（支撑向量）决定分类面，其余样本不参与**。

**辨析｜易错点：** SVM 的原问题包含合页损失（不可微），但把它写成 QP（含松弛变量 $\xi$）后就是光滑二次目标 + 线性约束——**不要直接对合页损失求梯度**。对偶问题的支撑向量结构来自互补松弛，不是来自「合页损失在边界等于 0」的直觉。**KKT 才是严格的支撑向量判据。**

## 4 公式解析：SVM 对偶的导出

从原始 SVM 到对偶，走一遍标准流程：

- **第一步，引入松弛**：$\min \frac{1}{2}\|w\|^2 + C \sum \xi_i$，约束 $y_i(w^T x_i + b) \ge 1 - \xi_i$、$\xi_i \ge 0$。
- **第二步，拉格朗日**：$L = \frac{1}{2}\|w\|^2 + C\sum \xi_i - \sum \alpha_i\big(y_i(w^T x_i + b) - 1 + \xi_i\big) - \sum \beta_i \xi_i$，$\alpha_i, \beta_i \ge 0$。
- **第三步，平稳性**：对 $w, b, \xi$ 求偏导置零：$w = \sum \alpha_i y_i x_i$、$\sum \alpha_i y_i = 0$、$\alpha_i + \beta_i = C$。
- **第四步，代回**：消去 $w, b, \xi, \beta$ 得对偶问题（上式），且 $0 \le \alpha_i \le C$（由 $\beta_i \ge 0$）。互补松弛再给出 $w$ 只用支撑向量表达：$w = \sum_{i: \alpha_i > 0} \alpha_i y_i x_i$。

**这条推导把凸分析的各件兵器串成一条链**：拉格朗日（21）→ 平稳性（16/24）→ 对偶变量消元（25）→ 互补松弛选支撑向量（24）。**SVM 是凸分析的一次完整阅兵。**

## 5 三种模型的对照与选择

最小二乘、逻辑回归、SVM 是统计学习的「三驾马车」，把它们并排比较是理解各自定位的最好方式：

| 维度 | 最小二乘 | 逻辑回归 | SVM（软间隔） |
| --- | --- | --- | --- |
| 任务 | 回归 | 分类（概率） | 分类（间隔） |
| 损失 | 平方损失 | 交叉熵（负对数似然） | 合页损失 |
| 正则 | 可选 L2/L1 | 可选 L2 | 内建 $\frac{1}{2}\|w\|^2$ |
| 可微性 | 光滑 | 光滑 | 不可微（分片线性） |
| 解的性质 | 闭式解 | 数值（IRLS/梯度） | QP 对偶 |
| 稀疏性 | L1 时稀疏 | 权重稀疏（L1） | 样本稀疏（支撑向量） |
| 概率输出 | 无 | 有 | 无（需校准） |

**重点：** 这张表揭示一个核心分工——**平方损失给闭式解，交叉熵给概率，合页损失给间隔与稀疏**。选模型不是选「谁更准」，而是选「你需要什么结构」：要闭式解和简单性，最小二乘；要概率输出，逻辑回归；要高维稀疏的分类器，SVM。<span class="marginnote">这三者在大模型时代并未过时：最小二乘是注意力机制的 softmax 之外的线性投影的回归子，逻辑回归是二分类头（如 reward model）的默认选择，而 SVM 的「对偶 + 核 + 支撑向量」思想直接启发了核方法在现代架构里的残余（如 transformer 的 attention 与核近似的关系）。</span>

**一个「凸性检查」的完整练习。** 判断带 L2 正则的逻辑回归是否凸：损失项是交叉熵（log-sum-exp 复合，凸，第8/10节），正则项 $\frac{\lambda}{2}\|w\|^2$ 凸，权重非负——由非负加权和规则，整体凸。<span class="marginnote">这个「拆成已知凸块 + 检查权重」的流程就是 DCP 判定：不必求 Hessian，只要语法树上的每一层都匹配保凸规则。工业级 ML 代码库里「梯度保证收敛」的自信，正来自这里。</span>

**当凸性失效时怎么办。** 深度网络的损失几乎总非凸（非线性激活复合引入非凸性）。此时凸分析提供的不是「全局最优保证」，而是**局部工具**：梯度单调性（第17节）保证 SGD 在凸片内稳定，正则化（L2/L1）在局部收紧曲率，而「鞍点、局部极小」的分类沿用第16节的驻点分析。**凸分析是理解非凸优化的基准——没有这个基准，非凸优化连「问题出在哪」都说不清。**<span class="marginnote">「凸性失效」不等于「理论失效」：非凸优化的现代理论（Polyak–Łojasiewicz 条件、锐度、神经切线核）本质上都是在刻画「问题距离凸有多远」。「从极限到大模型」的后续专题——优化算法、机器学习、深度学习——都会反复借用这张凸性基准。</span>

**辨析｜易错点：** LASSO 的 $\ell_1$ 正则保持凸性，但**「$\ell_1$ + 非负」的正则不一定**——若正则项换成 $\|w\|_1$ 的负号（$-\lambda\|w\|_1$，鼓励「大权重」），凸性立刻丢失。**任何「减去凸项」的操作都要警惕**：只有「加凸项」才保凸。
