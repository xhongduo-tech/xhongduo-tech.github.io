## 为什么从极值点开始

一个多面体有「角」，
一个圆盘有「边界上的每一寸」。
这些「不能写成两个不同点中间点」的点，
是凸集的**骨架**。
为什么骨架重要？
因为任何凸组合都可以逐步压缩，
直到只用骨架点就能表示——这就是有限维 Krein–Milman 定理的通俗形态。
而 Carathéodory 定理进一步告诉我们：
**表示一个点，最多需要 $n+1$ 个原集合的点**。
这两条定理共同保证了线性规划的顶点搜索法、以及「极值点法」在理论上的完备性。
<span class="marginnote">线性规划的最优解总在极值点取得——这是「在顶点处找最优」这一工程直觉的严格依据。
理解极值点，就是理解为什么单纯形法只在顶点间走动就能找到全局最优。
</span>

## 1 极值点

**极值点（extreme point）**：
设 $C$ 是凸集，
$x \in C$。
若 $x = \theta y + (1-\theta) z$（$y, z \in C$，
$0 \lt  \theta \lt  1$）必蕴含 $x = y = z$，
则称 $x$ 是 $C$ 的极值点。
<span class="marginnote">直观地说，极值点不是任何线段的「严格内点」——把它写成两个点的凸组合，两个点只能是它自己。
正方体的 8 个顶点是极值点，
棱上的非端点不是；
圆盘的所有边界点都是极值点（虽然有无穷多个）；
线段只有两个端点。
</span>

**重点：** 极值点的集合记作 $\operatorname{ext} C$。
对**有界闭凸集**，
有限维 Krein–Milman 定理说：
$C = \operatorname{conv}(\operatorname{ext} C)$——**每个点都是极值点的凸组合**。
圆盘由它的边界点张成，
多面体由它的顶点张成。
这一事实使极值点成为「生成元」。

## 2 极值方向

有界集才谈极值点，无界凸集（如无界多面体）需要用**极值方向（extreme direction）**补全骨架。

**极值方向**：非零向量 $d$ 使 $x + \lambda d \in C$ 对所有 $x \in C$、$\lambda \ge 0$ 成立（$d$ 是 $C$ 的**回收方向（recession direction）**），
且 $d$ 不能写成两个不同回收方向的正组合，
则称 $d$ 为极值方向。
<span class="marginnote">无界多面体的极值方向对应「射出去的棱」。
一个无界多面体的任何点可表示为「顶点凸组合 + 极值方向的非负组合」，
这是有限维 Krein–Milman 在无界情形的补全——线性规划里无界最优解就来自极值方向。
</span>

**辨析｜易错点：** 回收方向（recession direction）与极值方向是两个层次的概念：
前者只要求「沿 $d$ 走不离开集合」，
后者要求「$d$ 是最基本的不可分解方向」。
把「方向」误当成「点」是常见错误——方向没有长度，
$d$ 与 $\lambda d$（$\lambda>0$）是同一个方向。

## 3 Carathéodory 定理

**Carathéodory 定理**：
设 $C \subseteq \mathbb{R}^n$，
则 $\operatorname{conv} C$ 中任意一点都可写成 $C$ 中**至多 $n+1$ 个点**的凸组合：

$$\forall\, x \in \operatorname{conv} C,\quad \exists\, x_1, \dots, x_k \in C,\ k \le n+1,\ \text{使 } x \in \operatorname{conv}\{x_1, \dots, x_k\}$$

**重点：** 维数 $n$ 直接进入上界 $n+1$——这是「有限维」在凸几何里的第一份红利。在 $\mathbb{R}^2$ 里，任何凸包点都能用至多 3 个原集合点表示；在 $\mathbb{R}^n$ 里是 $n+1$。<span class="marginnote">直觉：$n$ 维空间里 $n+1$ 个点张成一个「单形」（simplex），凸组合的冗余度正好等于维数。若一个点需要 $k > n+1$ 个点表示，必然有「过度决定」，可以消去一个——这就是定理证明的核心压缩步骤。</span>

Carathéodory 定理还有一个**锥版本**：$\operatorname{cone} C$ 中任意点可写成 $C$ 中至多 $n$ 个点的非负组合（少了「归一化」的约束，故比 $n+1$ 少一个）。这个版本直接支撑 Farkas 引理的几何证明。

## 4 公式解析：Carathéodory 的压缩步骤

定理的证明核心是一个「消元」过程。设 $x \in \operatorname{conv}\{x_1, \dots, x_k\}$ 写成 $x = \sum_{i=1}^{k} \theta_i x_i$，$\theta_i \ge 0$，$\sum \theta_i = 1$。

**第一步，找线性相关**：若 $k > n+1$，则 $n$ 维空间里 $x_1, \dots, x_k$ 必然线性相关——存在不全为零的 $\mu_i$ 使 $\sum \mu_i x_i = 0$ 且 $\sum \mu_i = 0$。
**第二步，微扰不改变和**：对任意实数 $t$，$\sum (\theta_i + t \mu_i) x_i = \sum \theta_i x_i = x$ 仍等于 $x$（因为 $\sum \mu_i x_i = 0$、$\sum \mu_i = 0$），系数和仍为 $1$。
**第三步，压到一个系数为零**：取 $t$ 使某个系数 $\theta_j + t \mu_j$ 恰好变成 $0$ 而其余保持非负——这让表示式的项数减少 $1$。
**第四步，迭代**：重复直到只剩至多 $n+1$ 个点，证毕。

这个「线性相关的方向微扰，把系数压到 $0$」的手法，是凸几何中「降维」的通用技术，也是后面 Farkas 引理、多面体表示定理的证明引擎。

## 5 极值点与方向：实例对照

把「极值点」「极值方向」在不同凸集上的表现列成表，能一次看清概念边界：

| 凸集 | 极值点集 $\operatorname{ext} C$ | 极值方向 | 表示 |
| --- | --- | --- | --- |
| 线段 $[0,1]$ | $\{0, 1\}$ | 无 | 端点凸组合 |
| 圆盘 $\|x\| \le 1$ | 整个边界 $\|x\| = 1$ | 无 | 边界点凸组合 |
| 单位正方形 $[0,1]^2$ | 4 个顶点 | 无 | 顶点凸组合 |
| 非负象限 $\mathbb{R}^n_+$ | 仅原点 $0$ | 坐标轴方向 $e_i$ | 原点 + 方向锥 |
| 无界带 $\{x \ge 0\}$ | $\{0\}$ | $+1$ 方向 | 原点 + 方向 |
| 标准单形 | $n+1$ 个顶点 | 无 | 顶点凸组合 |

这张表浓缩了三种典型结构：**紧凸集**（圆盘、正方形、单形）只有极值点、没有极值方向，靠顶点/边界点凸组合重构；**无界凸集**（非负象限、带形）极值点退化到原点，靠极值方向表达「射出去」的部分；**混合情形**（无界多胞形）则两者都有。

**重点：** 圆盘一行值得反复玩味——它的极值点是**无穷多个**（整个边界），这并不违反任何定理，只是说明「极值点有限」是多胞形的特权（多面体有有限个顶点）。Carathéodory 定理不要求极值点有限，它只要求「表示某个点最多用 $n+1$ 个原集合点」——圆盘里任意点的表示都可以压缩到 $3$ 个边界点（在 $\mathbb{R}^2$ 中）。<span class="marginnote">「圆盘任意点用 3 个边界点表示」的几何含义：三角形内接原理——平面上任意点在某个以它为内点的三角形里，三角形顶点可取在圆上。这正是 Carathéodory 定理在 $\mathbb{R}^2$ 的直观。</span>

**Carathéodory 定理的数值威力。** 考虑「用最少个数的原子表示一个混合态」：若目标点 $x \in \operatorname{conv} C$ 用 $k$ 个点表示，Carathéodory 保证 $k \le n+1$。这一上界在**稀疏表示**、**组合优化**、**混料设计**（experimental design）里反复出现：任何凸包点都可以用不超过维数加一个的「原子」实现，不必枚举全部原子。

**辨析｜易错点：** 极值方向**不是**回收方向的同义词。回收方向要求「沿 $d$ 平移不离开集合」；极值方向额外要求「$d$ 不可分解成两个不同回收方向的正组合」。一个二维尖锥的「边界射线」是极值方向，但「内部方向」只是回收方向。**极值方向是回收方向的「生成元」，个数有限（多面体情形）。**

## 6 小结

- **极值点**：不能写成两个不同点凸组合的点；**有界闭凸集 = 极值点的凸包**（有限维 Krein–Milman）。
- **极值方向**：无界凸集的「射出去的棱」，补全无界情形的骨架。
- **Carathéodory 定理**：$\mathbb{R}^n$ 中凸包点可用至多 $n+1$ 个原集合点表示；锥版本上界为 $n$。
- 压缩证明的核心：**线性相关的方向微扰把多余系数压到 $0$
