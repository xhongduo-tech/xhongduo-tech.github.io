## 为什么从水平集开始

凸函数有个立刻可验证的推论：
它的**水平集**都是凸集。
但反过来呢？
水平集全凸的函数的集合，
其实比凸函数**大得多**——它叫**拟凸函数（quasiconvex function）**。
拟凸函数保留了一部分「凸的好运」——极小点仍构成凸集、局部最优仍是全局最优——却失去了 Jensen 不等式的全部力量。
<span class="marginnote">在「从极限到大模型」主线上，拟凸性在经济学（无差异曲线、需求函数）与分式规划（fractional programming，最大化「收益/成本」）里无处不在；
而「水平集凸 ⇎ 函数凸」这条辨析，
是理解凸性强度分层的第一个台阶。
</span>

## 1 水平集与次水平集

**次水平集（sublevel set）**：
函数 $f$ 的 $\alpha$-次水平集为

$$S_\alpha = \{ x \mid f(x) \le \alpha \}$$

**重点：** 若 $f$ 凸，则每个 $S_\alpha$ 都是凸集。证明一行：$x, y \in S_\alpha$ 时，$f(\theta x + (1-\theta)y) \le \theta \alpha + (1-\theta)\alpha = \alpha$。<span class="marginnote">直观：凸函数的等高线「往外鼓」，等高线内侧的区域（次水平集）永远凸。对凸函数而言，这几乎是免费的；但对一般函数，次水平集凸是<strong>额外</strong>信息。</span>

**辨析｜易错点：** **次水平集全凸 ⇏ 函数凸。** 经典反例：$f(x) = \sqrt{|x|}$。它的每个次水平集都是区间（凸），但 $f$ 在 $x=0$ 处有尖点，Jensen 不等式在 $0$ 附近反向——$f$ 不是凸函数。把「水平集凸」误当「函数凸」，是初学者最常见的混淆之一。正确的阶层是：**凸 ⇒ 次水平集凸；次水平集凸 ⇔ 拟凸。**

## 2 拟凸函数

**拟凸函数（quasiconvex function）**：若

$$f(\theta x + (1-\theta) y) \le \max\{ f(x), f(y) \}, \qquad \forall\, x, y,\ \theta \in [0,1]$$

则称 $f$ 拟凸。
<span class="marginnote">Jensen 要求「中间点的值 ≤ 两端值的加权平均」；
拟凸只要求「中间点的值 ≤ 两端值中较大者」——弱得多，
但保留了「中间不冒尖」的几何：
弦不越过两端点里较高的那个水平。
</span>

**核心判定定理：$f$ 拟凸 ⟺ 每个次水平集 $S_\alpha$ 都是凸集。**
这等价于凸函数「次水平集凸」的必要方向的完整化：
拟凸恰好是「次水平集凸」这一性质定义出的函数类。

常见拟凸函数：

凸函数全是拟凸（含线性函数、范数、指数）。
$f(x) = \sqrt{|x|}$ 拟凸但不凸。
- $f(x) = x^3$ 在 $\mathbb{R}$ 上拟凸但不凸。
- 拟凹（quasiconcave）函数类比定义：$f(\theta x + (1-\theta)y) \ge \min\{f(x), f(y)\}$，或 $-f$ 拟凸；$f(x) = \log x$ 拟凹（但不凹）。

**重点：** 拟凸函数保留了**凸的极小结构**——拟凸函数在凸集上的任何**局部极小也是全局极小**（极小点集合是凸集）。
这对经济学「无差异曲线凸 ⇒ 唯一消费束」与工程「单峰函数二分搜索」都够用了，
尽管拟凸函数没有 Jensen 不等式带来的强收敛保证。

## 3 分式规划与拟凸构造

拟凸函数最重要的构造：
**两个凸（凹）函数的商**。

**构造定理**：若 $f$ 凸、$g$ 凹且 $g > 0$，
则 $f(x)/g(x)$ 拟凸。
<span class="marginnote">证明要点：商函数 $\frac{f}{g}$ 的次水平集 $\{x \mid f(x)/g(x) \le \alpha\}$ 等价于 $\{x \mid f(x) - \alpha g(x) \le 0\}$（因 $g>0$），而 $f - \alpha g$ 是凸函数（凸 + 凹的负），其次水平集凸，故商的次水平集凸。
</span>

**辨析｜易错点：** 商里的条件必须配对：
**$f$ 凸、$g$ 凹（且 $g>0$）**，
商才拟凸。
若 $g$ 凸，$\frac{f}{g}$ 的次水平集不再自动凸。
分式规划（如最大化「信号/噪声」、投资「收益/风险」）能转成拟凸问题求解，
靠的正是这条构造。

## 4 公式解析：凸 ⇒ 拟凸

$$f(\theta x + (1-\theta)y) \le \theta f(x) + (1-\theta) f(y) \le \max\{f(x), f(y)\}$$

- **第一步，写凸性**：第一行是 Jensen 不等式——$f$ 在中间点的值不超过两端值的加权平均。
- **第二步，加权平均 ≤ 最大值**：$\theta f(x) + (1-\theta)f(y)$ 介于 $\min\{f(x), f(y)\}$ 与 $\max\{f(x), f(y)\}$ 之间，故 ≤ 最大值。
- **第三步，传递**：中间点的值 ≤ 加权平均 ≤ 最大值，得到拟凸定义。凸 ⇒ 拟凸。
- **第四步，观察损失**：反向不成立——拟凸把「加权平均」这个精细的界换成了「最大值」这个粗糙的界，失去了让 Taylor 展开、次梯度、强对偶成立的全部结构。**凸性损失的正是 Jensen 这个「平均值」的钳制力。**

## 5 凸、拟凸、伪凸对照表

把三个逐级放宽的「凸性」放到一张表里，是理解这个主题最有效的方式：

| 性质 | 定义要点 | 保凸运算 | 局部最优 = 全局 | 次梯度 | 强对偶 |
| --- | --- | --- | --- | --- | --- |
| **凸** | Jensen：中间 ≤ 加权平均 | 多（和、复合、最大） | 是 | 有 | 有 |
| **拟凸** | 中间 ≤ 两端最大 | 少（商等特殊构造） | 是 | 一般无 | 一般无 |
| **伪凸** | 梯度条件隐含最优 | 极少 | 是（可微） | 不适用 | 无 |

**重点：** 表格揭示了「凸性每放宽一步，工具箱就少几件」。从凸到拟凸，失去了 Jensen 不等式，也就失去了次梯度、共轭、强对偶这些「平均值驱动的结构」；但保留了**「局部最优 = 全局最优」**——因为拟凸的次水平集凸，任何局部极小都不会被「凹谷」包围。<span class="marginnote">伪凸（pseudoconvex）介于两者之间：它是可微情形下「满足一阶最优性条件即全局最优」的函数类，在分式规划与某些博弈论模型里出现，但工程上远不如凸与拟凸常用。这张表把「凸性强度」的完整光谱铺开了。</span>

**拟凸的实用价值：单峰搜索。** 一维拟凸函数是「单峰」的（有且仅有一个局部极小）。于是可以放心用**三分搜索**或**黄金分割**在 $O(\log n)$ 步内找到最小值，而不必担心「多峰」陷阱。这是拟凸在工程里最直接的用途——很多看似非凸的一维问题（如步长搜索、学习率调参）实际上是单峰/拟凸的。<span class="marginnote">「学习率搜索」「二分步长」这些深度学习里的常见操作，其有效性正依赖目标在步长这个一维方向上拟凸。理解拟凸，等于理解了「为什么这些朴素搜索有效」。</span>

**辨析｜易错点：** 拟凸的「商构造」$f/g$（$f$ 凸、$g$ 凹正）常被误用为「$f$ 凸、$g$ 凸 ⇒ $f/g$ 拟凸」——**错了**。$g$ 必须是凹的。例：$f = x^2$、$g = x$（$x > 0$）时 $f/g = x$ 是线性的（拟凸且凸）；但若 $g$ 换成凸函数，商的次水平集性质就崩。**构造拟凸函数时，商的分母必须凹。**

## 6 小结

- **次水平集** $S_\alpha = \{x \mid f(x) \le \alpha\}$；凸函数的次水平集全凸。
- **拟凸**：$f(\theta x + (1-\theta)y) \le \max\{f(x), f(y)\}$ ⟺ 次水平集全凸。
- 凸 ⇒ 拟凸，反向不成立（$\sqrt{|x|}$ 反例）。
- 拟凸保留「局部极小 = 全局极小」与凸极小集，但失去 Jensen/次梯度的强结构。
- **构造**：$f$ 凸 + $g$ 凹（$g>0$）⇒ $f/g$
