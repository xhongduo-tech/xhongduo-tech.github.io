## 为什么从凸函数的运算开始

真实的目标函数几乎从来不是「一个简单公式」——它是误差项、正则项、约束惩罚项、数据拟合项的叠加与复合。
能不能判定这种组合函数仍是凸的？
若能，优化就有了全局保证；
若不能，就得小心局部陷阱。
**凸函数的运算规则**回答了这个问题：
和、非负数乘、仿射复合、逐点最大与上确界，
全都保持凸性。
<span class="marginnote">这套规则在工程里被固化成了「可分解凸规划」（disciplined convex programming, DCP）：CVXPY、CVX 等工具靠语法树逐层匹配这些规则，自动判定一个目标是否凸、并生成求解器可用的标准形式。
理解本节，等于看懂这些工具为什么「敢」直接断言目标凸。
</span>

## 1 非负加权和

**规则 1（非负加权和）**：
若 $f_1, \dots, f_m$ 凸，
$\alpha_1, \dots, \alpha_m \ge 0$，
则

$$f(x) = \sum_{i=1}^m \alpha_i f_i(x)$$

凸。<span class="marginnote">证明几乎免费：每条 $f_i$ 都满足 Jensen 不等式，乘以非负 $\alpha_i$ 不改变不等号方向，逐项相加即可。若至少一个 $\alpha_i > 0$ 且对应 $f_i$ 严格凸，则 $f$ 严格凸。</span>

这是最常用的规则：**损失 + 正则**（最小二乘 $\|Ax-b\|_2^2 + \lambda \|x\|_1$）之所以凸，正因为两项各自凸、权重非负。

**辨析｜易错点：** 权重必须**非负**。$\alpha_i \lt  0$ 会翻转不等号方向——凸函数加负权得到的通常是**凹**函数。这是初学者最容易踩的坑：正则项系数写错符号，凸性瞬间消失，而优化器却毫无察觉。

## 2 仿射复合

**规则 2（仿射复合）**：若 $f$ 凸，$A \in \mathbb{R}^{n \times m}$，$b \in \mathbb{R}^n$，则

$$g(x) = f(Ax + b)$$

凸。直觉：仿射映射把直线映成直线，
凸性（弦在图上）在这种「坐标变换」下不变——与凸集在仿射映射下保凸（第2节）完全平行。
<span class="marginnote">这条规则让「把变量换成 $Ax+b$」成为免费操作：岭回归里 $f(w) = \|Xw - y\|_2^2$ 正是 $\|\cdot\|_2^2$ 与仿射映射 $w \mapsto Xw - y$ 的复合。
几乎一切「数据拟合 + 线性模型」的凸性都由此保证。
</span>

## 3 逐点最大与上确界

**规则 3（逐点最大）**：
若 $f_1, \dots, f_m$ 凸，
则 $f(x) = \max\{f_1(x), \dots, f_m(x)\}$ 凸。

**规则 4（上确界）**：
若 $\{f_y\}$ 是一族凸函数（指标 $y$ 任意多），
则

$$f(x) = \sup_{y} f_y(x)$$

凸。<span class="marginnote">「取最大」保持凸性，但「取最小」不保——$f(x) = \min\{x, -x\} = -|x|$ 是凹的。这个不对称与凸集「交保凸、并不保凸」同源：函数的上图经 $\sup$ 运算后仍是凸集。</span>

**重点：** 规则 4 是极强大的「造凸函数」机器——任意一族凸函数的上确界仍是凸函数。**分片线性函数** $f(x) = \max_i(a_i^T x + b_i)$、以及机器学习里的**支撑函数**、**最大特征值函数** $\lambda_{\max}(X) = \sup_{\|u\|=1} u^T X u$ 全部由这条规则覆盖。

## 4 复合规则与透视

当外层不是仿射时，复合要保持凸性需要方向匹配：

**规则 5（复合）**：若 $h$ 凸且**非降**，$f$ 凸，则 $h(f(x))$ 凸。若 $h$ 凸且**非增**，$f$ **凹**，则 $h(f(x))$ 凸。

这条规则的直觉：凸函数「向上弯」，经过非降凸函数 $h$ 的「继续向上弯」仍然向上弯；若 $h$ 非增，就需要 $f$ 凹（向下弯）来「抵消」翻转。<span class="marginnote">典型应用：$h(t) = e^t$（凸非降）复合凸 $f$ 得到 $\log\text{-}\mathrm{sum}\text{-}\exp$ 型函数的核心块；$h(t) = 1/t$（凸非增）复合凹 $g>0$ 得到凸函数 $1/g$。</span>

**辨析｜易错点：** 复合规则的方向是**易错高发区**。$h$ 凸非增 + $f$ 凸 → $h \circ f$ **不一定**凸（如 $h(t) = -t$，$f(x) = x^2$，得 $-x^2$ 凹）。**必须同时检查「$h$ 的单调方向」与「$f$ 的凹凸方向」是否匹配。** 另外还有透视函数 $\operatorname{persp}(f)(x, t) = t f(x/t)$（$t>0$）保持凸性——这是极大熵与相对熵建模的关键工具，此处先埋下伏笔。

## 5 公式解析：上确界保持凸性

$$\left(\sup_y f_y\right)\big(\theta x + (1-\theta)z\big) \le \theta \sup_y f_y(x) + (1-\theta) \sup_y f_y(z)$$

- **第一步，逐点套 Jensen**：对每个 $y$，$f_y(\theta x + (1-\theta)z) \le \theta f_y(x) + (1-\theta) f_y(z)$。
- **第二步，右边放缩到上确界**：$f_y(x) \le \sup_{y'} f_{y'}(x)$、$f_y(z) \le \sup_{y'} f_{y'}(z)$，于是右边的每一项都不超过对应的上确界。
- **第三步，左边也压到上确界**：左边 $f_y(\cdot) \le \sup_{y'} f_{y'}(\cdot)$，对每个 $y$ 成立，故 $\sup_y f_y(\theta x + (1-\theta)z) \le$ 右边。
- **第四步，交换次序的意义**：这个证明里「上确界」与「凸组合」的次序交换被不等式控制住——**先组合后求 sup ≤ 先求 sup 后组合**。这正是「最大」不破坏凸性的严格原因，也是支撑函数、最大特征值等构造合法性的根据。

## 6 运算规则实战：从积木到模型

保凸运算规则的价值在「组装」。
这里用三个机器学习里的真实目标演示组装过程：

**目标 1：L2 正则最小二乘（岭回归）。**

$$\min_x \underbrace{\|Ax - b\|_2^2}_{\text{凸：二次}} + \lambda \underbrace{\|x\|_2^2}_{\text{凸：范数}}$$

两项都凸、权重 $\lambda \ge 0$，由「非负加权和」规则整体凸。**凸性无需逐点验证，直接由运算规则断言。**

**目标 2：SVM 软间隔。** $\frac{1}{2}\|w\|^2 + C \sum_i \max(0, 1 - y_i(w^T x_i + b))$。第一项凸（二次）；第二项是**仿射复合 + 逐点最大**：$1 - y_i(w^T x_i + b)$ 是 $w$ 的仿射函数（凸），$\max(0, \cdot)$ 是凸函数（逐点最大），合页损失凸；再加非负权 $C$。整体凸。<span class="marginnote">注意这里只用了三条规则：<strong>非负加权和 + 仿射复合 + 逐点最大</strong>。DCP（可分解凸规划）工具正是把这些规则做成语法树，自动判定像 SVM 这样的复杂目标「为什么凸」。</span>

**目标 3：log-sum-exp 平滑化。** 想把 $\max_i x_i$ 变成光滑函数，用 $\mathrm{lse}(x) = \log\sum_i e^{x_i}$。它凸的理由：$e^{x_i}$ 凸（指数复合仿射），求和凸（非负加权和），$\log$ 非降且凹——**「凸非降 $h$ + 凸内层」不适用**（$\log$ 凹），正确路径是 $\log$ 是凸函数 $u \mapsto \log u$（凹）与凹函数的复合……需按第19节共轭/特殊处理。这里只提醒：**复合规则的方向要选对**，log 是凹的，不能拿它当「凸非降外层」。

**重点：** 三个目标展示了规则的组合拳——**单条规则平凡，组合起来能覆盖绝大多数机器学习目标**。这也是 DCP 库敢断言「你的目标凸」的底气：不是数值检验，而是语法树上的规则匹配。<span class="marginnote">一个有趣的边界：$\min_i x_i$ 是凹函数（逐点最小破坏凸性），所以「最大化多个凸函数的最小值」是凹问题——建模时把 min/max 位置搞反，凸性就丢。规则表就是你的「凸性守恒律」。</span>

**辨析｜易错点：** **「非负数乘」与「逐点最大」是两条最容易被误用的规则**。$\lambda$ 为负时凸性翻转；对「最小」取最大也不保凸（$\max_i \min_j$ 型的 min-max 结构几乎总非凸）。**组装模型前，把每条规则的方向（非负/非降/凸/凹）逐项核对一遍。**

## 7 小结

- 保凸的运算：**非负加权和、仿射复合、逐点最大、上确界、透视**。
- **权重必须非负**，负权把凸变凹；**取最大保凸、取最小不保**。
- 复合规则要求方向匹配：$h$ 凸非降 + $f$ 凸，或 $h$ 凸非增 + $f$ **凹**，复合才凸——方向不匹配则凸性丢。
- **非负加权和**：损失 + 正则（如岭回归）凸的根因；权重一旦为负，凸性瞬间翻转成凹。
- **逐点最大保凸、逐点最小不保**——与凸集「交保凸、并不保凸」同源，min-max 结构几乎总非凸。
- **规则 4 的威力**：任意一族凸函数的上确界仍凸——支撑函数、$\lambda_{\max}$、分片线性函数全由它覆盖。
- **DCP 语法树**：CVXPY 等工具正是把「非负加权和、仿射复合、逐点最大」做成规则库，自动判定目标是否凸。
- **透视函数** $\operatorname{persp}(f)(x, t) = t f(x/t)$（$t>0$）保持凸性，是极大熵与相对熵建模的关键工具。
