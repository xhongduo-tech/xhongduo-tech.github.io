## 为什么从分离定理开始

凸分析里最核心、最能「兑现价值」的一条定理，
就是把两个不相交的凸集用一张超平面隔开。
**分离定理（separation theorem）** 说：
两个不相交的凸集之间，总能找到一张超平面把它们分到两侧。
这条看似直观的几何事实，是后面一切对偶理论、最优性条件、Farkas 引理与共轭函数的发动机。
<span class="marginnote">把「一个凸集 $C$ 与它外面的一个点 $y$」这一最简情形想清楚：超平面恰好把 $y$ 隔在 $C$ 之外——这就是「$y \notin C$ 可以被证明」的几何形式，也是非成员资格判定、对偶间隙为零的根源。
</span>

在「从极限到大模型」主线上，分离定理是**优化理论的地基**：
拉格朗日对偶、KKT 条件、博弈论里的 minimax 定理全部从这里长出来。
直观地说，它把「可行性」翻译成「不等式」——每个被超平面隔开的半空间就是一个约束。

## 1 超平面与半空间

**超平面（hyperplane）**：
$\{x \in \mathbb{R}^n \mid a^T x = b\}$，
其中 $a \ne 0$ 是法向量，$b$ 是常数。
<span class="marginnote">在 $\mathbb{R}^2$ 中它是直线，在 $\mathbb{R}^3$ 中它是平面——超平面是 $n-1$ 维的「墙」，把空间切成两半。
$a$ 指向墙的一侧，$b$ 决定墙的位置（到原点的距离被 $b/\|a\|$ 度量）。
</span>

**半空间（halfspace）**：$\{x \mid a^T x \le b\}$ 与 $\{x \mid a^T x \ge b\}$。
两张半空间各占一边，交集正是超平面。

**重点：** 半空间是凸的（见第1篇），
所以「用超平面分离」等价于「把两个集合分别塞进两个互补的半空间」。

## 2 分离的三种强度

「分离」这个词有三个递增的强度，初学者最容易混：

- **弱分离（proper separation）**：存在 $a \ne 0$ 使 $\sup_{x \in C_1} a^T x \le \inf_{x \in C_2} a^T x$——两个集合在 $a$ 方向上被隔开，但可能恰好相切（不等式取等号）。
- **严格分离（strict separation）**：存在 $a, b$ 使 $a^T x \lt  b \lt  a^T y$ 对所有 $x \in C_1, y \in C_2$ 成立——两个集合之间留有正间隙。
- **强分离（strong separation）**：存在 $a$ 与 $\delta > 0$ 使 $\sup_{C_1} a^T x + \delta \le \inf_{C_2} a^T y$——两个集合之间有一道「厚度」为 $\delta$ 的缝隙。

**辨析｜易错点：** 弱分离太弱——两个**相切的**凸集（如圆盘与其一条切线）也能弱分离，
但严格分离失败。
严格分离要求两集合的「相对位置」有正距离；
若两个凸集只是**内部不相交但边界相触**，
一般只能弱分离，得不到严格分离。
**判断该用哪个版本，先问两个集合之间有没有正的间隙。**

## 3 分离定理：基本版本

**分离定理（基本形式）**：设 $C$ 是 $\mathbb{R}^n$ 中的凸集，
$y \notin \operatorname{int} C$（或 $y \notin C$ 且 $C$ 闭），
则存在非零 $a$ 与 $b$ 使

$$a^T x \le b \le a^T y, \qquad \forall\, x \in C$$

即 $y$ 与 $C$ 可被一张超平面分离。<span class="marginnote">这是「$y$ 在 $C$ 之外」的严格代数翻译：找一组系数 $a$，让 $C$ 里所有点在这组系数下的取值都「不大于」$y$ 的取值。存在性来自凸集与点之间的投影——$y$ 到 $C$ 的最近点给出法向量方向。</span>

这个定理的证明思路值得记住：取 $y$ 到 $C$ 的最近点 $x^* = P_C(y)$，令 $a = y - x^*$、$b = a^T x^*$，再利用凸性证明 $a^T (x - x^*) \le 0$ 对所有 $x \in C$ 成立——凸性在这里保证了最近点的法方向「全部指向 $y$」而不会翻转。

**重点：** 分离定理有一个漂亮的推论——**支撑超平面定理（supporting hyperplane theorem）**：对凸集边界上的任一点 $x_0$，存在过 $x_0$ 且 $C$ 完全落在其一侧的超平面。把 $x_0$ 与 $C \setminus \{x_0\}$ 分离即可。这个推论是第5节支撑函数的入口。

## 4 严格分离的条件

什么时候能升级为**严格分离**？关键是**两个集合之间要有正距离**：

- **点 vs 闭凸集**：$C$ 闭凸，$y \notin C$，则存在 $a, b, \delta$ 使 $a^T x \le b \lt  b + \delta \le a^T y$——严格分离成立。
- **两个紧凸集**：$C_1, C_2$ 紧凸且不相交，则存在严格分离的超平面。
- **相对内部不相交**：更精细的版本用相对内部表述——若 $\operatorname{ri} C_1 \cap \operatorname{ri} C_2 = \emptyset$，则存在**适当分离**（proper separation：超平面不过分退化，两个集合都在两侧「真」落下）。

**辨析｜易错点：** 两个**开**凸集若相交则无法分离（它们有公共点）；若不相交则可以严格分离。两个**闭**凸集若不相交但边界相触（如 $C_1 = [0,1], C_2 = [1,2]$），只能弱分离、不能严格分离——点 $1$ 同时属于两者边界，不等式必须取等。**「闭 + 不相交」仍不足以保证严格分离，还差一个「正距离」或「紧性」。**

## 5 公式解析：分离不等式

$$a^T x \le b \le a^T y \quad (\forall\, x \in C)$$

- **第一步，选方向**：法向量 $a$ 选成从最近点 $x^*$ 指向 $y$ 的方向，即 $a = y - x^*$。它天然「指向」$y$。
- **第二步，定位置**：$b = a^T x^*$，让超平面恰好过最近点 $x^*$——所以 $C$ 里离 $y$ 最近的点就在墙上。
- **第三步，凸性关门**：对任意 $x \in C$，凸性推出 $a^T (x - x^*) \le 0$，即 $a^T x \le a^T x^* = b$。左边不等式成立。
- **第四步，$y$ 在另一侧**：$a^T y = a^T(x^* + a) = b + \|a\|^2 > b$。右边不等式严格成立。

整条式子的含义：**$a$ 方向上的「取值」，
$C$ 整体不越过 $y$**。
这正是「$C$ 在 $y$ 的这一侧」的精确表达，
也是把「点不在凸集里」翻译成「存在一个线性函数把它俩分开」的机制。

## 6 分离定理的应用图景

分离定理是凸分析的「第一原理」，它的推论遍布整个学科。
这里把最重要的应用串成一张地图：

- **最优性条件**：$x^*$ 是最优点 ⟺ 存在分离超平面把「水平集之下」与「$x^*$ 之下」分开——这是 $0 \in \partial f(x^*)$（第16节）的几何来源。
- **Farkas 引理**：线性不等式组不可行 ⟺ 存在对偶方向的证书——分离定理在凸锥上的特化（第27节）。
- **强对偶**：$p^* = d^*$ 用分离超平面证明——对偶变量就是分离超平面的法向量（第22节）。
- **minimax 定理**：零和博弈的均衡存在性，本质是「两个凸集可分离」的博弈论翻译（第23节）。
- **凸包松弛**：点不在凸集里 ⟺ 存在线性函数把它与凸集分开——这给出「凸松弛不会漏掉最优」的保证。

**重点：** 分离定理的全部力量浓缩在一句话里：
**「凸集外的点可以被线性函数『指认』」**。
这一能力让「不属于凸集」变成一个**可验证**的代数事实（找得到 $a, b$），
而不是一个几何观察——这正是对偶理论、可行性判定、最优性证书全部可行性的根基。

**一个具体的判别实例。**
问：$y = (1, 1)$ 是否在凸集 $C = \{x \mid x_1^2 + x_2^2 \le 1\}$ 里？
显然不在（范数为 $\sqrt 2 > 1$）。
分离定理保证存在分离超平面——取法向量 $a = y = (1,1)$，
则对任意 $x \in C$，$a^T x \le \|a\| \|x\| \le \sqrt 2 = a^T y$，
分离不等式成立，超平面 $x_1 + x_2 = \sqrt 2$ 正好把 $y$ 与圆盘分开。
<span class="marginnote">这个例子虽平凡，却展示了完整套路：<strong>先猜一个法向量，再用 Cauchy–Schwarz 验证分离不等式</strong>。
真实应用（SVM 的间隔、对偶变量）里，
法向量往往是「最近点方向」或「约束梯度组合」，
与这里同构。
</span>

**辨析｜易错点：** 分离超平面**不唯一**，
也不需要唯一。
圆盘外一个点 $y$，有无穷多张超平面能把它与圆盘分离（法向量可以在某个锥范围内转动）。
**只要找到一张，分离就算成功**——不要试图找「最正的那张」（那是支撑超平面的最优化问题，
属于下一节）。

## 7 小结

- **超平面** $a^T x = b$ 与两**半空间** $a^T x \le b$、$a^T x \ge b$ 是分离的基本工具。
- 分离有三种强度：**弱、严格、强**，区别在于集合间有没有正间隙。
- **分离定理**：$y \notin C$（或 $y \notin \operatorname{int} C$）时存在非零 $a, b$ 使 $a^T x \le b \le a^T y$
