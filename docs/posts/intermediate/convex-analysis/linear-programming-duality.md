## 为什么从线性规划开始

线性规划（LP）是凸优化的**旗舰问题**：
目标线性、约束线性，
可行域是多面体，最优值在顶点取得。
它是 20 世纪应用数学最成功的模型之一——运输、排产、金融、物流、博弈论全覆盖，
Dantzig 的单纯形法让「求解 LP」成为工业级技能。
对凸分析而言，LP 是对偶理论最纯净的试验场：
对偶 LP、互补松弛、强弱对偶都能用 Farkas 与分离定理严格推出来。
<span class="marginnote">在「从极限到大模型」主线上，LP 是「可精确求解的凸优化」的基准：大规模线性回归、资源分配、以及许多组合问题的线性松弛都以 LP 为解算内核。
理解 LP 对偶，等于理解「为什么单纯形法的表里有一行检验数、为什么内点法能多项式收敛」。
</span>

## 1 标准形式与几何

**线性规划（标准形式）**：

$$\min c^T x \quad \text{s.t.} \quad Ax = b,\; x \ge 0$$

其中 $A \in \mathbb{R}^{m \times n}$、$b \in \mathbb{R}^m$、$c \in \mathbb{R}^n$。任何 LP（不等式、自由变量）都能通过引入松弛变量/变量拆分化为标准形式。<span class="marginnote">标准形式的几何：可行域 $P = \{x \ge 0 \mid Ax = b\}$ 是多面体（$Ax = b$ 是仿射子空间与非负象限的交）。$c^T x$ 沿 $c$ 方向推进，最优解出现在 $P$ 的一个顶点上——除非目标沿某个极值方向可以无限下降（无界）。</span>

**最优顶点定理**：若 LP 有最优解且有界，则最优解在某个**顶点**（basic feasible solution，基本可行解）取得。<span class="marginnote">这条定理（由第7节的极值点理论 + Minkowski–Weyl 表示定理推出）是单纯形法的合法性基石：只需在有限个顶点之间搜索，而不必扫描整个多面体。顶点数可能巨大（组合爆炸），但实际 LP 很少触发最坏情形。</span>

**重点：** LP 是「凸 + 多面体」的重合地带，所以它同时享受三份红利：局部最优 = 全局最优（凸性）、最优在顶点（多面体）、对偶无条件强（下面马上看到）。

## 2 对偶 LP

标准形式 LP 的对偶是

$$\max \big(-b^T \nu\big) \quad \text{s.t.} \quad A^T \nu + c \ge 0$$

或等价的 $\max b^T \nu$ 满足 $A^T \nu \le c$（符号习惯而定）。
<span class="marginnote">推导路径有两条，殊途同归：<strong>Lagrange 对偶</strong>（把 $Ax = b$ 罚进拉格朗日 $c^T x + \nu^T(Ax - b)$，对 $x \ge 0$ 取极小，得 $-b^T\nu + \inf_{x\ge0}(A^T\nu + c)^T x$，要求 $A^T\nu + c \ge 0$）或 <strong>Fenchel 对偶</strong>（把 LP 写成 $f + g \circ A$）。
两条路都导出同一个对偶 LP。
</span>

**LP 强对偶定理**：
若原问题与对偶问题都可行，
则 $p^* = d^*$（强对偶无条件成立）。
更完整的**对偶分类**：

| 原问题 | 对偶问题 | 结论 |
| --- | --- | --- |
| 有界最优 | 有界最优 | $p^* = d^*$ |
| 无界 | 不可行 | — |
| 不可行 | 无界 | — |
| 不可行 | 不可行 | 可能 |

**辨析｜易错点：** LP 的强对偶**不需要** Slater 条件——因为可行域是多面体（相对内部条件自动满足退化版本）。
但「无界 ⟺ 对偶不可行」「对偶无界 ⟺ 原不可行」这两条**不能反过来当充分条件**（两个都不可行的情况存在）。
**对偶分类要查完整表格，
不要只记一个方向。**

## 3 互补松弛与算法

**互补松弛（LP 版本）**：
若 $x^*$、$\nu^*$ 分别是原始与对偶最优，
则

$$\nu^*_i (A x^* - b)_i = 0, \qquad x^*_j (A^T \nu^* + c)_j = 0$$

即**原始松弛与对偶变量至少一者为零**。它让 LP 最优解自动满足 KKT（第24节）——LP 是 KKT 从充分到必要都无条件的少数情形之一。<span class="marginnote">互补松弛在 LP 里特别好用：给定一个对偶最优解，可以反推原始最优的支撑结构；给定原始最优，可以定位「哪些约束拉满」。经济学里，$\nu^*$ 是约束的<strong>影子价格</strong>——资源每多一个单位，最优值改善多少。</span>

**两类主流算法**：

**单纯形法（simplex）**：沿多面体的棱从一个顶点跳到更好的顶点，有限步终止；实践中极快，但最坏情形指数。它只依赖线性代数（表格运算），是稀疏大规模 LP 的主力。
**内点法（interior-point）**：走可行域**内部**的光滑曲线（中心路径），每步解 KKT 扰动方程组；多项式复杂度 $O(\sqrt{n} L)$ 级别，适合大规模/结构化 LP。

**重点：** 单纯形法基于「顶点 + 多面体组合」，内点法基于「KKT + 中心路径」——前者是离散组合视角，后者是连续分析视角。**两种算法各自兑现了凸分析的两条线索：极值点理论（第7节）与最优性条件（第16/24节）。**

## 4 公式解析：LP 强对偶的 Farkas 证明

用 Farkas 引理（第27节）证 LP 强对偶的一个方向：设对偶可行集非空，证明 $d^* \le p^*$ 且最优可达。

- **第一步，目标：对偶可行点与值**：取对偶可行 $\nu$，$A^T \nu + c \ge 0$。对任何原始可行 $x \ge 0$、$Ax = b$：$c^T x \ge (A^T\nu)^T x = \nu^T A x = \nu^T b$，故 $d^* = \sup_\nu \nu^T b \le p^*$——弱对偶一行证完。
- **第二步，反方向用 Farkas**：设 $d^* \lt  p^*$。取 $p^*$ 与 $d^*$ 之间的 $t$，构造系统「$c^T x \lt  t$、$Ax = b$、$x \ge 0$ 有解」——它由 $p^*$ 的定义无解。对「无解系统」用 Farkas，得到一组「证书」，与 $d^*$ 的最大性矛盾。
- **第三步，收紧**：矛盾说明 $d^* = p^*$；再取达到 $d^*$ 的对偶序列，用紧性与锥闭性取出极限点 $\nu^*$——对偶最优可达。
- **第四步，衔接**：这条证明展示了 Farkas 的「二选一」如何变成「强对偶」：**不可行性证书的反面，就是最优对偶点的存在性**。

## 5 一个完整的 LP 对偶实例

用一个可手算的小 LP，把对偶、互补松弛、影子价格一次串起来。

**原始问题（生产计划）**：$\max 3x_1 + 2x_2$，约束 $x_1 + x_2 \le 4$、$2x_1 + x_2 \le 5$、$x \ge 0$。写成最小化形式 $\min -3x_1 - 2x_2$。

**对偶问题**：由第2节（或 Fenchel 对偶），对偶为 $\min 4y_1 + 5y_2$ 满足 $y_1 + 2y_2 \ge 3$、$y_1 + y_2 \ge 2$、$y \ge 0$。<span class="marginnote">对偶变量 $y_1, y_2$ 分别对应两条约束，它们的经济学意义是<strong>资源影子价格</strong>：第一条约束（总工时）每多 1 单位，最优利润增加 $y_1$；第二条同理。对偶目标「最小化资源总成本」恰好是「用资源价格核算生产方案是否划算」。</span>

**解原始问题**：顶点 $A = (0,0)$、$B = (0,4)$（$x_1=0, x_2=4$，检查 $2\cdot0+4=4 \le 5$ 可行）、$C = (1,3)$（两约束都取等）、$D = (2.5, 0)$（第二约束取等）。目标值：$A: 0$，$B: 8$，$C: 9$，$D: 7.5$。最优 $x^* = (1, 3)$，$p^* = 9$。

**互补松弛验证**：最优处两条约束都取等（$x_1 + x_2 = 4$、$2x_1 + x_2 = 5$），所以 $y_1, y_2$ 都可能非零。解对偶方程组 $y_1 + 2y_2 = 3$、$y_1 + y_2 = 2$，得 $y^* = (1, 1)$，对偶值 $4 \cdot 1 + 5 \cdot 1 = 9 = p^*$——**强对偶成立，对偶间隙为零**。<span class="marginnote">$y^* = (1,1)$ 的解读：总工时和特殊材料各自的影子价格都是 1。若第一条约束的右端从 4 增到 5（多 1 单位工时），新最优利润变成 $10$——增加量恰好是 $y_1 = 1$ 乘以资源增量。影子价格是「边际价值」的最直接呈现。</span>

**这个例子展示的完整套路**：写对偶 → 解原始（顶点法）→ 用互补松弛求对偶最优 → 验证强对偶 → 读影子价格。**每一步都用上了本专题的兵器**：顶点法（第7节）、对偶构造（第21节）、互补松弛（第24节）、强对偶（第22节）。

**辨析｜易错点：** 对偶约束的符号要按标准形式严格推导。原始 $\max$ 有「$\le$」约束，对偶变量非负；若原始约束是「$\ge$」（如最低产量要求），对偶变量符号要翻转。**写对偶前先统一成标准形式（$\min$ + $\le$ + $x \ge 0$），再机械套用规则，别跳步。**

## 6 小结

- **LP**：$\min c^T x$ 满足 $Ax = b, x \ge 0$；最优在**顶点**取得，可行域是多面体。
- **对偶 LP**：$\max b^T \nu$ 满足 $A^T \nu \le c$；由 Lagrange 或 Fenchel 对偶导出。
- **强对偶**：原始与对偶都可行时 $p^* = d^*$ **无条件**成立；对偶分类表要记全。
- **互补松弛**：$\nu_i(Ax-b)_i = 0$、$x_j(A^T\nu + c)_j = 0$
