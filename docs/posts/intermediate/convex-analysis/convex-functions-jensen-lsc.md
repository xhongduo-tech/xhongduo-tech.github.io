## 为什么从凸函数开始

凸集告诉我们「连线落在集合里」，凸函数则告诉我们「弦落在曲线上方」。**凸函数（convex function）**是把几何的凸性搬到函数值上：函数值不大于两端值的内插。它几乎包揽了优化里一切「好消息」——局部极小即全局极小、次梯度处处存在、对偶间隙为零。大模型训练里那些「看起来棘手」的目标（$\ell_1$ 正则、合页损失、Logistic 回归的负对数似然）其实全是凸函数，只是非光滑而已。<span class="marginnote">凸函数是「碗」：从任何一点往下走，只要沿着下降方向总能到碗底，且不会掉进「假谷」——这就是为什么深度学习中能用 SGD 的系统性方法，其实大量借鉴自凸优化的收敛分析。</span>这一篇承接第1篇的凸集，把第2篇与第4篇的凸函数理论（上图、Jensen、闭包）收拢成可操作的三件套。

从「从极限到大模型」的主线看，这一篇是转折点：第一级的极限与导数给了我们「光滑」的函数观，这一篇则把「函数」从光滑推广到凸——**光滑靠极限定义，凸性靠弦定义**。凸函数是连接微积分（导数、Hessian）与最优化（极小、对偶）的那块跳板。

## 1 凸函数：上图视角与三种等价定义

**凸函数（convex function）**：$f: \mathbb{R}^n \to \mathbb{R} \cup \{+\infty\}$ 是凸函数，若 $\operatorname{dom} f$ 是凸集，且对任意 $x, y \in \operatorname{dom} f$、$\theta \in [0,1]$，

$$f(\theta x + (1-\theta) y) \le \theta f(x) + (1-\theta) f(y)$$

**几何翻译（上图）**：函数 $f$ 的**上图（epigraph）**

$$\operatorname{epi} f = \{ (x, t) \mid t \ge f(x) \}$$

是凸集。这是凸函数最优雅的几何刻画——**函数凸 ⟺ 上图凸**。它把「函数性质」翻译成「集合性质」，于是第1篇凸集的全部工具（支撑超平面、分离定理、凸包）都可以直接搬过来用。<span class="marginnote">「上图凸」是凸函数定义的真正内核：如果你只在图线的下方（下水平集）看，线性函数、拟凸函数的截片也会像凸的；只有把图线上方的整个区域看成一个凸集，才能抓住「碗形」的全部信息。</span>

**三种等价定义**：一阶条件（对可微 $f$）$f(y) \ge f(x) + \nabla f(x)^T (y-x)$；二阶条件（对二阶可微 $f$）$\nabla^2 f(x) \succeq 0$；以及**逐点判据**——对任意 $x, y$，一元函数 $\varphi(t) = f(x + t(y-x))$ 在 $[0,1]$ 上凸。最后这条最实用：**判断多元函数的凸性，只需验证任意直线上的截取是凸的**。

**算一个具体的判定**：$f(x) = \|x\|_2$。用直线截取判据：固定 $x, y$，$\varphi(t) = \|x + t(y-x)\|_2$ 是「向量的范数复合仿射函数」，范数的三角不等式保证 $\varphi$ 凸——所以 $\|x\|_2$ 凸。再看 $f(x) = \|x\|_2^2$：$\nabla^2 f = 2I \succeq 0$，也凸。两问的差别：一个靠「范数三角不等式」，一个靠「Hessian 半正定」——**不同函数要用最省力的判据**。

**保凸运算（operations preserving convexity）**：凸函数的「不动点」比想象的多。非负加权和（$\sum_i \alpha_i f_i$，$\alpha_i \ge 0$）、仿射复合（$f(Ax+b)$）、逐点极大与上确界（$\max_i f_i$、$\sup_\alpha f_\alpha$）、以及「凸函数复合单调凸函数」（$g \circ f$，$g$ 凸且单调不减）都保凸。有了这些运算，复杂的凸函数可以像搭积木一样拼出来：合页损失是逐点极大，LASSO 的目标是「平方损失 + $\ell_1$ 正则」的非负加权和，Logistic 损失是 $-\log$（凹）与仿射复合的组合。**工程上判断「新函数凸不凸」，先拆成已知块再用运算律拼装**，往往比逐个验证定义快得多。

| 保凸运算 | 成立条件 | 典型例子 |
| --- | --- | --- |
| 非负加权和 | $\alpha_i \ge 0$ | 损失 + 正则 |
| 仿射复合 | $A$ 任意矩阵 | $f(Ax + b)$ |
| 逐点极大 / 上确界 | 任意函数族 | $\max_i f_i(x)$ |
| 复合 | $g$ 凸且单调不减 | $e^f$、$-\log$ 复合 |
| 透视（上镜图） | $t > 0$ | $t f(x/t)$ |

**重点：** 「复合」这条最容易被误用——$g \circ f$ 凸需要 $g$ 凸且单调不减，缺了单调条件就不保凸。例如 $g(u) = e^u$（凸递增）、$f$ 凸 ⟹ $e^f$ 凸，正确；但 $g(u) = -u$（线性、单调不增）时 $g \circ f = -f$ 就变成凹函数。写保凸论证时，务必检查内外函数的单调方向。

**辨析｜易错点：** $f$ 凸但 $f$ 可以不可微（$|x|$），可以取到 $+\infty$（指示函数 $\delta_C$ 是凸函数）。**指示函数** $\delta_C(x) = 0$（$x \in C$）、$+\infty$（否则）是凸函数，它把「集合约束」编码进「函数语言」，是第4篇对偶理论的语法基础。

## 2 Jensen 不等式：凸性的解析指纹

**Jensen 不等式**：设 $f$ 凸，$x_1, \dots, x_m \in \operatorname{dom} f$，$\lambda_i \ge 0$、$\sum_i \lambda_i = 1$，则

$$f\!\left( \sum_{i=1}^m \lambda_i x_i \right) \le \sum_{i=1}^m \lambda_i f(x_i)$$

**函数值不大于加权平均，但函数作用在平均上**——「平均的函数」≤「函数的平均」。它是二元定义的归纳推广，也是凸性区别于其他性质（如线性：取等号；凹性：反向）的指纹。<span class="marginnote">把 $\lambda_i$ 解释成概率，Jensen 不等式写成 $f(\mathbb{E}X) \le \mathbb{E}f(X)$——随机变量的期望代进去不等式照成立。信息论里 KL 散度非负、方差不小于零、熵的上界，全都是 Jensen 的推论。这是凸函数与概率论之间最深的连接。</span>

**重点：** 反向不等式（$\ge$）成立时称 $f$ 为**凹函数（concave）**——$f$ 凹当且仅当 $-f$ 凸。Logistic 回归的似然是凹的，所以极大化似然等价于极小化它的负号（一个凸函数）。凸性与凹性只在符号上翻转，分析工具完全共享。

把三个典型类别排成表，方便一眼分辨：

| 函数 | 类别 | 判定依据 |
| --- | --- | --- |
| $f(x) = x^2$ | 凸 | $f'' = 2 > 0$ |
| $f(x) = e^x$ | 凸 | $f'' = e^x > 0$ |
| $f(x) = \log x$（$x>0$） | 凹 | $f'' = -1/x^2 < 0$ |
| $f(x) = \sqrt{x}$（$x\ge 0$） | 凹 | $f'' = -1/(4x^{3/2}) < 0$ |
| $f(x) = \|x\|_1$ | 凸、不可微 | 分段线性 |
| $f(x) = \sin x$ | 既非凸也非凹 | 在 $\mathbb{R}$ 上变号 |

这张表的最后一行提醒我们：**大部分函数既不凸也不凹**，「凸」在函数空间里是少数，但却是优化想要的全部。

**用 Jensen 看优化**：Jensen 不等式还解释了为什么「凸函数局部最优 = 全局最优」。若 $x^*$ 是 $f$ 的局部极小，取任意 $y$ 与充分小的 $\theta$，由凸性

$$f(x^* + \theta(y - x^*)) \le (1-\theta) f(x^*) + \theta f(y)$$

左侧在局部极小附近 ≥ $f(x^*)$，于是 $0 \le \theta(f(y) - f(x^*))$，即 $f(y) \ge f(x^*)$ 对一切 $y$ 成立——**局部极小自动是全局极小，只需 Jensen 一步**。这个「凸 = 无假谷」的结论，是一切凸优化算法（梯度下降、牛顿法、内点法）的存在理由。

## 3 下半连续与闭凸函数：让取极小「有处可去」

**下半连续（lower semicontinuous, lsc）**：$f$ 在 $x$ 处下半连续，若 $x_k \to x$ 时

$$\liminf_{k \to \infty} f(x_k) \ge f(x)$$

**重点：** $f$ 下半连续 ⟺ $\operatorname{epi} f$ 是闭集 ⟺ 每个下水平集 $\{x \mid f(x) \le \alpha\}$ 是闭集。<span class="marginnote">为什么优化必须关心 lsc？因为极小化序列的极限点必须「还停在函数上」：若 $f$ 不是 lsc，可能出现一列点 $x_k$ 让 $f(x_k) \to p^*$ 但 $f(\lim x_k) > p^*$——最优点「跑掉了」。lsc 保证下水平集闭合，极小化序列的聚点仍是可行点。</span>指示函数 $\delta_C$ 是 lsc 当且仅当 $C$ 闭；$\|x\|_1$、合页损失、一切闭集指示函数都 lsc。

**凸函数的闭包（closure）**：对凸函数 $f$，它的**闭包** $\operatorname{cl} f$ 是「不超过 $f$ 的最大的下半连续凸函数」，几何上等于「取 $\operatorname{epi} f$ 的闭包的支撑函数」。当 $f$ 处处有限（正常且 lsc），$\operatorname{cl} f = f$；当 $f$ 的定义域开而函数在边界附近爆破（如 $f(x) = 1/x$ 在 $x>0$），闭包把边界点按极限值补齐。**闭凸函数**（正常、凸、lsc）是整个第4篇对偶理论的前提——Fenchel 共轭的二次共轭 $\operatorname{cl} f = f^{**}$ 只在闭凸函数上恢复原函数。

**算两个闭包**：$f(x) = e^x$（定义域全空间、连续）本身已闭凸，$\operatorname{cl} f = f$；$f(x) = 1/x$（$x>0$）在边界 $0$ 处爆破，闭包把 $0$ 处的值补成 $+\infty$——$\operatorname{cl} f(x) = 1/x$（$x>0$）、$+\infty$（$x \le 0$）。再看指示函数 $\delta_{(0,1]}$（左端点开）：闭包是 $\delta_{[0,1]}$，把开边界点也收进来。**闭包运算 = 把「向上跳」的地方压平，但绝不在凸函数里制造「向下跳」**——这正是 lsc 定义在闭包运算中的回响。

**辨析｜易错点：** 下半连续与连续不同：$f(x) = \begin{cases} 0 & x \ne 0 \\ 1 & x = 0 \end{cases}$ 不 lsc（在 $0$ 处跳上去，$\liminf = 0 < 1 = f(0)$）；$f(x) = \begin{cases} 0 & x = 0 \\ 1 & x \ne 0 \end{cases}$ 却 lsc 且在 $0$ 处不连续。**lsc 只禁止「向上跳」，允许「向下跳」**——这恰好是极小化所需的性质。

## 4 公式解析：Jensen 不等式与凸性判据

把 Jensen 不等式从二元定义「推」出来，再把它「倒过来」当判据用：

$$f(\theta x + (1-\theta)y) \le \theta f(x) + (1-\theta) f(y), \qquad f\!\left(\textstyle\sum \lambda_i x_i\right) \le \sum \lambda_i f(x_i)$$

- **第一步，二元到多元**：对 $m$ 个点用数学归纳。$m=2$ 就是定义；假设 $m-1$ 成立，把 $\sum_{i=1}^m \lambda_i x_i$ 写成 $\theta z + (1-\theta) x_m$，其中 $z = \sum_{i=1}^{m-1} \frac{\lambda_i}{1-\lambda_m} x_i$、$\theta = 1 - \lambda_m$——两个部分的权重各自非负和为 1。
- **第二步，套用二元定义**：$f(\theta z + (1-\theta) x_m) \le \theta f(z) + (1-\theta) f(x_m)$，再对 $f(z)$ 用归纳假设，系数合并后正是 $\sum \lambda_i f(x_i)$。
- **第三步，当判据用**：反过来，若「对任意有限凸组合都有这个不等式」，取 $m=2$ 就回到定义。所以**Jensen 不等式与凸性等价**——它是定义的重写，却因为概率诠释变成了最常用的形式。
- **第四步，概率化**：把 $(\lambda_i)$ 看成离散分布，$f(\mathbb{E}X) \le \mathbb{E}f(X)$。取 $f(x) = x^2$ 得方差非负，取 $f(x) = -\log x$ 得几何均值 ≤ 算术均值——Jensen 一键生产一堆不等式。

**这条链路的要点**：凸性、Jensen 不等式、上图为凸、以及「任意直线截取凸」四个陈述互相等价，是同一枚硬币的四面。<span class="marginnote">遇到「证明某函数凸」的任务，四个等价判据里选最省力的那个：二次可微用 $\nabla^2 f \succeq 0$，复杂函数用「直线截取」或「保凸运算」，分段函数用上图。选对判据往往让证明从一场战役变成一次散步。</span>

**用 Jensen 推一个真不等式**：对 $x_1, x_2 > 0$，取 $f = -\log$（凹），Jensen 给出 $-\log\frac{x_1 + x_2}{2} \le -\frac{\log x_1 + \log x_2}{2}$，即 $\sqrt{x_1 x_2} \le \frac{x_1 + x_2}{2}$——**算术均值 ≥ 几何均值**。只需一次 Jensen，一条经典的初等不等式就落地了。信息论里的熵不等式、统计里的 Jensen 估计，走的都是同一条路。

**再算一个：证明 LASSO 目标凸**。$f(x) = \tfrac12\|Ax - b\|_2^2 + \lambda\|x\|_1$。

- **拆**：第一项是「$\tfrac12\|\cdot\|_2^2$（凸）复合仿射 $Ax - b$」——保凸；第二项 $\|x\|_1$ 是绝对值之和——凸。
- **合**：非负加权和（系数 $1$ 与 $\lambda \ge 0$）保凸。
- **判**：故 $f$ 凸——甚至不必写出 Hessian。

这就是「保凸运算」的实战价值：三步之内证明一个真实模型凸。若要用二阶判据，$\nabla^2$ 只在 $x \ne 0$ 分量处有意义，反而麻烦——**选对判据，证明的长度从一页纸缩成三行**。

## 5 凸函数在课程地图上的位置

凸函数不是孤立的定义，它是「从极限到大模型」课程线里把分析、几何与优化缝在一起的针脚。第一级的《函数与导数》把「凸」当作曲线的弯曲方向；本专题把「凸」升级成「上图是凸集 + Jensen 不等式」的双重刻画；再往后的最优化、变分分析、机器学习，则把凸函数当作「好问题的标志」。<span class="marginnote">回顾这条链：极限给出光滑，凸性给出「虽非光滑但仍可优化」——两者是互补的立场，而不是竞争。Logistic 回归、SVM、LASSO 的损失全是凸函数，而「为什么好解」的答案，早在 Jensen 不等式与下半连续里就已经写好了。</span>

## 6 小结

- **凸函数**：$\operatorname{dom} f$ 凸且 $f(\theta x + (1-\theta)y) \le \theta f(x) + (1-\theta)f(y)$；等价于**上图 $\operatorname{epi} f$ 凸**。
- **三种判据**：一阶（切线下界）、二阶（Hessian 半正定）、直线截取（一元化）。
- **Jensen 不等式**：$f(\mathbb{E}X) \le \mathbb{E} f(X)$——凸性的解析指纹，通向概率论与信息论。
- **下半连续**：$x_k \to x \Rightarrow \liminf f(x_k) \ge f(x)$，等价于下水平集闭、上图闭；保证极小化序列的聚点仍可达。
- **闭凸函数**：正常、凸、下半连续；$\operatorname{cl} f = f^{**}$ 是对偶理论的成立前提。
- 大部分函数既不凸也不凹；凸函数是「少数」，却是优化想要的全部。

在下一节，我们将把几何直觉升级成分析定理——**分离定理**：超平面如何把两个凸集隔开，支撑超平面又如何定义凸集的边界。
