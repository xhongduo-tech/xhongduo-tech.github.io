## 为什么从凸锥开始

在众多凸集里，有一类自带「方向」结构的特殊成员——**凸锥（convex cone）**。
它的几何特别干净：从原点出发的一簇射线构成。
更重要的是，锥在凸分析里扮演「正的界」的角色：
对偶锥、极锥、正常锥（normal cone）都是围绕「锥」展开的。
二次锥规划（SOCP）与半定规划（SDP）的可行域直接就是锥，
而它们在现代优化（包括大模型训练中的约束与鲁棒性建模）中无处不在。
<span class="marginnote">非负象限、二阶锥、半正定矩阵锥是三种「正经锥」（proper cone），分别对应线性规划、二次锥规划、半定规划三种渐强的模型——后面第5篇的锥规划会以本节为跳板。
</span>

## 1 凸锥的定义

**凸锥（convex cone）**：
集合 $K$ 满足：对任意 $x \in K$ 与 $\lambda \ge 0$ 有 $\lambda x \in K$，
且对任意 $x, y \in K$ 有 $x + y \in K$，
则称 $K$ 是凸锥。
<span class="marginnote">「数乘封闭」给出从原点射出的射线，「加法封闭」让射线之间的夹角被填满——两者合起来，凸锥恰好是「由一族射线张成的、含原点的凸集」。
注意凸锥不一定包含整条直线，也不要求含 0 之外的特殊点。
</span>

等价定义更优雅：**凸锥 = 同时满足「正齐次」与「加法」封闭的凸集**。
事实上，$K$ 是凸锥当且仅当 $K$ 是凸集且对 $x \in K$、$\lambda \ge 0$ 有 $\lambda x \in K$。

三个标准例子：

- **非负象限**：$K = \mathbb{R}^n_+ = \{x \mid x_i \ge 0\}$。
- **二阶锥（ice-cream cone）**：$K = \{(x, t) \in \mathbb{R}^{n+1} \mid \|x\|_2 \le t\}$。
- **半正定锥**：$K = \mathbb{S}^n_+ = \{X \in \mathbb{S}^n \mid X \succeq 0\}$。

**重点：** 若凸锥 $K$ 满足 $K \cap (-K) = \{0\}$（不含非零直线），
称 $K$ 为**尖锥（pointed cone）**；
闭、凸、尖、且有非空内部的锥称为**正经锥（proper cone）**。
正经锥定义了偏序 $x \preceq_K y \iff y - x \in K$——这是把「大于等于」推广到高维的正式语言。

## 2 对偶锥

**对偶锥（dual cone）**：设 $K$ 是锥，
其对偶锥为

$$K^* = \{ y \mid \langle x, y \rangle \ge 0,\; \forall\, x \in K \}$$

即与 $K$ 中所有向量内积都非负的方向 $y$ 的集合。<span class="marginnote">几何上，$y \in K^*$ 意味着 $y$ 与 $K$ 里每个方向的夹角都不超过 $90^\circ$——它站在「几乎对着 $K$ 来」的位置。非负象限的对偶锥还是非负象限；半正定锥的对偶锥仍是半正定锥（自对偶）；二阶锥也自对偶。</span>

**重点：** 对偶锥**永远是闭凸锥**，即使 $K$ 本身不是。这使对偶锥成为「正则化」工具：任何集合的锥包的对偶，总是一个规整的闭凸锥。自对偶锥（$K^* = K$）是对称几何的珍品，三个标准例子全是自对偶的。

## 3 极锥、双对偶与对偶运算

**极锥（polar cone）**：$K^\circ = \{ y \mid \langle x, y \rangle \le 0,\; \forall\, x \in K \} = -K^*$。极锥与对偶锥只差一个负号——对偶锥要求「角度不超过 $90^\circ$」，极锥要求「不小于 $90^\circ$」。二者经常被混用，读文献时先确认符号约定。

**双对偶定理（bipolar theorem）**：对任意集合 $K$，

$$(K^*)^* = \overline{\operatorname{conv}(\operatorname{cone} K)}$$

即双对偶恢复的是 $K$ 的**闭凸锥包**。
若 $K$ 本身是闭凸锥，则 $(K^*)^* = K$。
<span class="marginnote">这条定理与分离定理同构：它本质上是「用所有线性不等式刻画一个闭凸锥」的表述。
类比上一节支撑函数「闭凸集 = 全体支撑不等式之交」，
双对偶定理是它的锥版本。
</span>

对偶运算与集合运算的互动（Rockafellar 第16章）：

- $(K_1 + K_2)^* = K_1^* \cap K_2^*$
- $(K_1 \cap K_2)^* \supseteq K_1^* + K_2^*$（一般只有包含；闭性与凸性合适时取等）

**辨析｜易错点：** 锥的对偶「反转」了并集与交集：
求和的锥被对偶成交，求交的锥被对偶成和（加闭包）。
初学者常写错方向。**记法：对偶把「并/和」变成「交」，
把「交」变成「和」——与集合的德摩根律一脉相承。**

## 4 公式解析：双对偶定理

$$(K^*)^* = \overline{\operatorname{conv}(\operatorname{cone} K)}$$

- **第一步，理解单侧包含**：$K \subseteq (K^*)^*$ 是平凡的——$K$ 里每个点都与 $K^*$ 的所有成员内积非负（按 $K^*$ 定义），所以 $K$ 的点都落在双对偶里。
- **第二步，为什么要闭凸包**：反方向 $(K^*)^* \subseteq K$ 并不总成立。双对偶天然闭凸（$K^*$ 闭凸锥，再对偶仍闭凸锥），所以右边最多只能期望 $K$ 的闭凸锥包。
- **第三步，分离定理补上缺口**：若 $y \notin \overline{\operatorname{cone} K}$，用分离定理找一个 $z$ 使 $\langle x, z \rangle \ge 0$（$x \in K$）而 $\langle y, z \rangle \lt  0$——即 $z \in K^*$ 但 $y \notin (K^*)^*$。这说明双对偶里没有多余的点。
- **第四步，结论**：两个方向合起来得等式；当 $K$ 是闭凸锥时右边回到 $K$ 自身。

**这条定理的意义**：任何「内积非负」的约束族（$K^*$）所能界定的最大集合，恰好是原集合的闭凸锥包。它和支撑函数定理一起，构成了「凸对象 = 其全体线性不等的交集」这一哲学的两大支柱。

## 5 常见锥与其对偶锥对照表

把最常见的锥与它们的对偶列成表，是快速掌握「对偶锥」这一概念的最佳捷径：

| 锥 $K$ | 定义 | 对偶锥 $K^*$ | 是否自对偶 |
| --- | --- | --- | --- |
| 非负象限 $\mathbb{R}^n_+$ | $x_i \ge 0$ | $\mathbb{R}^n_+$ | 是 |
| 二阶锥 $Q^{n+1}$ | $\|u\|_2 \le t$ | $Q^{n+1}$ | 是 |
| 半正定锥 $\mathbb{S}^n_+$ | $X \succeq 0$ | $\mathbb{S}^n_+$ | 是 |
| 半平面锥 | $\{x : a^T x \ge 0\}$ | $\{y : y = \lambda a, \lambda \ge 0\}$ 的射线 | 否 |
| 单向射线 | $\{x : x = \lambda d, \lambda \ge 0\}$ | $\{y : d^T y \ge 0\}$ 半空间 | 否 |
| 多项式锥（低维） | 例：$\{(x,y) : x \ge |y|\}$ | 自身（$L^1$ 型锥） | 是 |

前三个「正经锥」全部自对偶，这并非巧合——它们对应三类最重要的优化模型（LP、SOCP、SDP），而自对偶性让这三类问题的对偶问题「长得和原问题一样」，极大简化了对偶理论。**记忆要点：非负象限、二阶锥、半正定锥是「自对偶三兄弟」。**

**重点：** 从表中可以看到对偶锥的一个几何规律——**锥越「细」（约束越紧），对偶锥越「粗」（方向越多）**。半平面锥（半个空间）的对偶退化成一条射线，而单向射线（最细）的对偶膨胀成整个半空间。这种「粗细对偶」是「约束与松弛的互换」在锥世界的镜像。<span class="marginnote">对偶锥的「粗细互换」直接对应优化里的「原问题约束越紧、对偶问题可行域越松」——比如 SDP 松弛把组合约束放宽成 $X \succeq 0$，对偶问题就多出半正定变量。理解粗细互换，就理解了「松弛」的几何含义。</span>

**辨析｜易错点：** 非凸锥也有对偶锥（定义里并不要求 $K$ 凸），但对偶锥 $K^*$ **永远闭凸**。初学者常误以为「$K$ 必须凸才能定义 $K^*$」——不对，对偶锥对任何集合都定义良好，只是当 $K$ 是闭凸锥时双对偶才回到自身（$(K^*)^* = K$）。**非闭或非凸的 $K$，其双对偶只会恢复它的闭凸锥包。**

## 6 小结

- **凸锥**：正数乘与加法双封闭的凸集；**正经锥** = 闭、凸、尖、内部非空，诱导偏序 $\preceq_K$。
- **对偶锥** $K^* = \{y \mid \langle x, y \rangle \ge 0,\ \forall x \in K\}$，永远闭凸；非负象限、二阶锥、半正定锥都自对偶。
- **极锥** $K^\circ = -K^*$；对偶与极只差负号。
- **双对偶定理**：$(K^*)^* = \overline{\operatorname{conv}(\operatorname{cone} K)}$
