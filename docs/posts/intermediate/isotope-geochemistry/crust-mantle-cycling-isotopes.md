## 为什么从壳幔循环开始

第 5 篇讲了地幔端元，但留下了关键问题：**富集端元的「富集」从哪来？** 主流答案是俯冲——洋壳、沉积物、大陆边缘物质被板块拖入地幔，经历深部储留后再被地幔柱带回。这构成了「壳幔循环」假说。本篇用三类证据（Pb 同位素悖论、Os 同位素、稀有气体）把这条循环链坐实，并指出它的边界条件。<span class="marginnote">「循环」不是简单回收：俯冲物质要在深部停留数亿年才能演化出观测到的同位素组成。所以壳幔循环研究实质上是「示踪 + 计时」的合体——同位素组成给出源区，衰变/演化模型给出储留时间。</span>这是前五篇示踪知识的大综合。

## 1 第一类证据：Pb 同位素悖论与 HIMU

**铅同位素悖论（lead paradox）**：地幔从地壳中分离时，U、Th 比 Pb 更不相容，理论上**地幔的 U/Pb（μ 值）应低于地壳**。但观测恰好相反：**MORB 源区（DMM）的 μ 值偏高**，且其 Pb 同位素比值随时间增长过快，无法用单一的地幔演化解释。

解法正是壳幔循环：俯冲进入地幔的**再循环洋壳**在脱水过程中优先失去 Pb（亲流体），留下高 U/Pb 的残余，形成 HIMU（高 μ）端元。因此：

DMM 与 HIMU 之间的 Pb 同位素差异，是「地幔中混入了再循环洋壳」的数值证据。
再循环洋壳在深部储留几亿年后，积累了极端放射成因 Pb（$^{206}\mathrm{Pb}/{}^{204}\mathrm{Pb}$ 可达 21–22），与 St. Helena、Cook-Austral 等 HIMU 型火山的实测吻合。<span class="marginnote">Pb 悖论的历史意义：它在 1980 年代促使地球化学界承认「地幔不是均一的」，而是至少包含一个含再循环洋壳的富集组分——从此地幔地球动力学有了同位素约束。</span>

## 2 第二类证据：Os 同位素与古老岩石圈

**锇同位素**：$^{187}\mathrm{Re} \xrightarrow{\beta^-} {}^{187}\mathrm{Os}$，半衰期 416 亿年。Re 比 Os 不相容，熔融提取时 Re 进入熔体、Os 留在残余——所以**亏损地幔的 Re/Os 低、$^{187}\mathrm{Os}/{}^{188}\mathrm{Os}$ 演化慢**，而地壳的比值高。

**关键优势**：Os 同位素对「熔融提取与再循环」的响应比 Sr-Nd-Pb 更极端，且 Os 富集于橄榄石、铬铁矿中，抗蚀变。观测发现部分 OIB 与大陆玄武岩携带**超低 $^{187}\mathrm{Os}/{}^{188}\mathrm{Os}$**，对应的模式年龄可达 20–35 亿年——这意味着地幔中存在**古老、难熔的再循环岩石圈残片**，它们自太古宙以来就未再被均一化。<span class="marginnote">「超低 Os 比值」几乎是古老亏损岩石圈的签名：它不像 Sr-Nd 那样容易被近地表混染，因而保留了最深、最老的地幔记忆——Os 是探访太古宙地幔的专用钥匙。</span>

## 3 第三类证据：稀有气体与原始储库

**氦同位素**：$\ce{^3He/^4He}$ 是壳幔循环研究的另一盏灯。$\ce{^3He}$ 主要来自**原始地幔**（地球形成时保留的宇宙组分），$\ce{^4He}$ 由 U、Th 衰变不断产生。因此：

**MORB**：$\ce{^3He/^4He} \approx 8\,R_A$（$R_A$ 为大气比值），代表被 U、Th 衰变「稀释」过的上地幔。
**部分 OIB（如冰岛、夏威夷）**：$\ce{^3He/^4He}$ 高达 30–50 $R_A$，提示源区保留了**未充分去气的原始组分**——它们没有被混匀进全球对流地幔。

**氩与氖**：$\ce{^40Ar/^36Ar}$、$\ce{^20Ne/^22Ne}$ 同样区分「原始 vs 再循环」组分，联合反演出地幔储层的体积与去气历史。<span class="marginnote">稀有气体是「惰性」的：它们几乎不参与矿物-熔体分配，因而成为纯粹的「示踪物」，不因化学过程而改变——但正因如此，它们的端元组成与储层体积只能靠反演估计，争议也集中于此。</span>

## 4 综合证据：同位素 + 地震层析成像

壳幔循环的地球化学证据，在近二十年与**地震学**合流，形成了更加立体的图像：

**地震层析成像（tomography）**发现两个巨大的低速异常体（LLSVP）坐落在核幔边界（太平洋与非洲下方），被称为「热化学堆」。同位素学家发现：**许多 HIMU 与富集型 OIB 的空间分布与 LLSVP 边界吻合**——这暗示 LLSVP 可能就是俯冲物质的长期归宿。<span class="marginnote">「地震看得到、同位素闻得到」的对应关系，是地球科学多学科交叉的范例：层析成像给结构，同位素给成分与年龄，两者互相校准——就像影像学与化验指标在医学诊断中的互补。</span>

**海沟输入-火山输出**：俯冲带之上的弧火山岩带着明确的「俯冲印记」（B 同位素、高 $\delta^{11}\mathrm{B}$ 与富集 Sr-Nd），证明地表物质确被带入地幔楔；而板片在深处转化为榴辉岩、最终沉入下地幔，则被 OIB 的端元信号接力记录。

**辨析｜易错点：** 壳幔循环不等于「完全混合」。俯冲物质进入地幔后，多数会被对流搅拌成背景，只有**部分以化学层/机械块体形式保存数亿年**。因此「OIB 含再循环组分」不意味着地幔整体富集——它只是众多储库中相对不易混匀的那一部分。<span class="marginnote">这个「搅拌 vs 保存」的平衡，是当前地幔地球动力学的核心争论：全地幔对流（大尺度混匀）与分层对流（保存储库）各有支持证据。同位素给出的是「必须有未混匀储库」，而混匀速率与对流模式还要靠动力学模拟配合。</span>

**常见疑问：壳幔循环是不是等于「地幔被完全混合」？**
不是。俯冲物质进入地幔后，大部分会被对流搅拌成背景组分，只有部分以化学层或机械块体形式保存数亿年。OIB 中的再循环信号恰恰来自「没被搅匀」的那一小部分——混匀与保存的比例，正是当前地幔动力学争论的焦点。

**三类证据如何互证：**
- Pb 同位素告诉你「有没有再循环洋壳」，Os 告诉你「残片有多老」，稀有气体告诉你「有没有原始储库」——三者分别回答物质来源、物质年龄、混合程度。
- 同位素数据通常成对出场：εNd–⁸⁷Sr/⁸⁶Sr 图看整体趋势，Pb 多比值图看端元，He-Ne 看原始组分。
- 解释一个 OIB 样品时，永远先问：它在哪些图上偏离主流、又靠近哪个端元？

| 体系 | 回答的问题 |
| --- | --- |
| U-Pb / HIMU | 有没有再循环洋壳？ |
| Re-Os | 残片有多老？ |
| He-Ne-Ar | 有没有原始储库？ |
| B-Sr-Nd | 俯冲物质进了地幔楔吗？ |
| 地震层析成像 | 储库埋在哪里？ |

**常见疑问：为什么有些研究说「地幔全对流」，另一些说「分层对流」？**
两派都有同位素证据：MORB 的均一性支持上地幔被快速搅拌，而 OIB 端元的多样性又要求有未混匀的深部储库。近年地球动力学模拟用「分层 + 局部板片穿层」兼容两者——同位素给的是约束，不是最终答案。

**思考题：** 如果一块 OIB 的 εNd 很高、⁸⁷Sr/⁸⁶Sr 很低、Pb 同位素极高，它最可能来自哪个端元的混合？（提示：DMM + HIMU。）

**延伸阅读**：Hofmann (1997) 的经典综述《Mantle geochemistry: the message from oceanic volcanism》把这套端元体系讲得最完整，适合进阶研读。

**一句话记忆：** 壳幔循环的证据链 = Pb 悖论（洋壳去 Pb）+ Os 残片（太古宙记忆）+ 稀有气体（原始组分）+ LLSVP（归宿）。

## 7 小结

- **Pb 悖论**：地幔 μ 值偏高的反常识观测，被「再循环洋壳去 Pb」解释，支撑 HIMU 端元。
- **Os 同位素**：超低 $^{187}\mathrm{Os}/{}^{188}\mathrm{Os}$ 记录太古宙亏损岩石圈残片，是地幔记忆的深井。
- **稀有气体**：高 $\ce{^3He/^4He}$
