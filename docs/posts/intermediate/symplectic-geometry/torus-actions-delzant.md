## 为什么从环面作用开始

约化是「用对称性造新流形」的手术，但对称性从哪来？最简单、最可控的紧致李群是**环面 $T^n$**——它的李代数是 $\mathbb{R}^n$，moment map 是 $M \to \mathbb{R}^n$，一切都「对角化」。而 Delzant 定理给出一个惊人的结果：**紧辛流形上，维数恰好为「环面作用自由度」的哈密顿环面作用，完全由它的动量像——一个凸多胞形——决定。** 多胞形就是流形的「指纹」：流形可以按多胞形重建，两个流形辛同胚当且仅当它们的多胞形相同。这一篇是辛几何与组合几何（多胞形、扇）交汇的典范，也通往后面的量子上同调（$T^n$ 作用在 $\mathbb{CP}^n$ 上的量子上同调可以完全显式算出）。<span class="marginnote">Delzant 分类把辛几何变成「多边形组合学」：$\mathbb{CP}^2$ 对应三角形，$\mathbb{CP}^1 \times \mathbb{CP}^1$ 对应正方形。读者可以全程「画图」理解——这是辛几何里少有的直观乐土。</span>

## 1 哈密顿环面作用与动量像

**有效哈密顿环面作用**：$T^k$ 有效（有效 = 作用核为平凡）且哈密顿地作用于 $(M^{2n}, \omega)$，moment map $\mu: M \to \mathbb{R}^k$（$\mathfrak{t}^* \cong \mathbb{R}^k$）。

**Atiyah-Guillemin-Sternberg 凸性定理**：若 $T^k$ 是环面（连通、紧、交换），则 $\mu$ 的像

$$
\Delta = \mu(M) \subset \mathbb{R}^k
$$

是**凸多胞形**，其顶点恰是 $T^k$-不动点的像。这是一个非常规的结论——一个「矩映射的像」自动是凸的，不动点自动是多胞形的顶点。<span class="marginnote">凸性定理的证明用的是 Morse 理论：$M$ 上关于 $\xi$ 的方向导数 $\langle\mu,\xi\rangle$ 是「Morse-Bott 函数」，其临界流形正是不动点集。凸性是 Morse 理论与辛几何联姻的赠品。</span>

**全维数情形**：当 $k = n$（$\dim T^n = \frac{1}{2}\dim M$），环面作用叫**全维环面作用（toric action）**，$M$ 叫**辛环面流形（symplectic toric manifold）**。此时 $\Delta$ 是 $\mathbb{R}^n$ 里的 $n$ 维多胞形，它的每个顶点处恰好 $n$ 条边——多胞形形状决定流形形状。

## 2 Delzant 多胞形

**Delzant 多胞形**：$\mathbb{R}^n$ 中的凸多胞形 $\Delta$，满足三条性质：

1. **单纯（simple）**：每个顶点恰有 $n$ 条边；
2. **有理（rational）**：每条边方向由 $\mathbb{Z}^n$ 中的向量给出（斜率是整数坐标）；
3. **光滑（smooth）**：每个顶点处的 $n$ 条边方向构成 $\mathbb{Z}^n$ 的一组整基（生成整个格）。

这三条是「流形光滑性」的组合翻译。对 $n=2$：Delzant 多边形是「所有角都是整数斜率且顶点边成整基」的凸多边形。<span class="marginnote">光滑性条件最严格：比如顶点处两条边 $(1,0)$、$(0,1)$ 是整基（合法）；$(1,0)$、$(1,2)$ 也是（行列式 2 的矩阵虽然行列式 $\ne \pm 1$ 但… 实际上要求生成整个格 $\mathbb{Z}^2$，即行列式 $\pm 1$）。非光滑多胞形对应有奇点的「环面栈」。初学者最易忽略「生成整格」——它不是「整数方向」，而是「方向张成整个格」。</span>

**例**：三角形 $\Delta_2 = \{x_1 \ge 0, x_2 \ge 0, x_1 + x_2 \le 1\}$（$n=2$）是 Delzant 的：顶点 $(0,0)$ 边方向 $(1,0),(0,1)$ ✓。正方形 $\{0 \le x_i \le 1\}$ 也是。但三角形 $\{x_1 \ge 0, x_2 \ge 0, x_1 + x_2 \le 2\}$ 顶点 $(0,0)$ 处仍是整基 ✓——**整基只看顶点处局部斜率，与整体尺寸无关**。

## 3 Delzant 定理

**Delzant 定理（1988）**：存在双射

$$
\left\{ \begin{array}{c} \text{维数 } 2n \text{ 的紧连通辛环面流形} \\ (M, \omega, T^n, \mu) / \text{辛同胚} \end{array} \right\}
\quad \longleftrightarrow \quad
\left\{ \mathbb{R}^n \text{ 中的 Delzant 多胞形} \right\}
$$

映射由「取动量像 $\Delta = \mu(M)$」给出；反过来，任何 Delzant 多胞形 $\Delta$ 都能构造出唯一的 $(M_\Delta, \omega_\Delta)$。

**构造方向（从多胞形到流形）**：这是辛约化的应用——用「推广的约化」把 $\mathbb{C}^d$（$d$ = 多胞形的面数）约化成 $M_\Delta$。骨架：

1. $\Delta$ 有 $d$ 个面，第 $j$ 个面的外法向 $\nu_j \in \mathbb{Z}^n$；
2. 在 $\mathbb{C}^d$ 上取 $T^d$ 作用，moment map $z \mapsto (|z_1|^2/2, \dots, |z_d|^2/2)$；
3. 用线性映射 $\pi: \mathbb{R}^d \to \mathbb{R}^n$（$\pi(e_j) = \nu_j$）约化：$M_\Delta = \mu^{-1}(\pi^{-1}(0) + c)/\ker\pi$ 的子商。整理后就是 $\mathbb{C}^d /\!/ T^{d-n}$ 型的约化。

**例（$\mathbb{CP}^n$）**：$\mathbb{CP}^n$ 有 $T^n$ 作用（对角旋转齐次坐标的比值），动量像是 $n$-单纯形。所以 $\mathbb{CP}^n$ 的「指纹」是单纯形；反过来，从单纯形用上述约化重建出的正是 $\mathbb{CP}^n$。<span class="marginnote">$\mathbb{CP}^n$ 的 Delzant 多胞形是 $n$-单纯形 $\Delta_n = \{x_i \ge 0, \sum x_i \le 1\}$。对 $n=1$：$\mathbb{CP}^1 = S^2$ 的动量像是线段 $[0,1]$，$S^2$ 的 $S^1$ 旋转对应「从北极到南极的高度函数」——这解释了 $\mu = |z|^2/(1+|z|^2)$ 之类的高度函数图。</span>

## 4 公式解析：约化构造的维数核对

**核心公式（约化重建流形的维数）：**

$$
\dim M_\Delta = 2n, \qquad \text{来自 } 2d - 2(d - n) = 2n
$$

拆解：

- **第一步，出发点**：$\mathbb{C}^d$ 是 $2d$ 维，带 $T^d$ 作用（$d$ 个独立旋转），moment map $\Phi(z) = (|z_1|^2/2, \dots)$。
- **第二步，砍掉面约束**：要求 $\Phi$ 落在 $\pi^{-1}(c) \subset \mathbb{R}^d$（$d-n$ 个线性方程），砍掉 $d-n$ 个维度——**这一步对应多胞形的 $d-n$ 个线性关系（顶点处 $n$ 条边的相容）**。
- **第三步，除以对称**：剩下的子流形上有 $T^{d-n} = \ker\pi$ 的约化（$T^{d-n}$ 是「多余对称」），商掉 $d-n$ 维——约化定理说这一步也砍掉 $d-n$ 维。
- **第四步，合并**：$2d - (d-n) - (d-n) = 2d - 2d + 2n = 2n$。总维数恰为 $2n$，与 $\dim M_\Delta$ 吻合。**每条「面」贡献两个自由度，每条「对称」吃掉两个自由度**，净剩 $2n$。

**直觉总结：** Delzant 构造 = 「用 $d$ 个复坐标拼出 $n$ 个独立自由度」：坐标数 $d$ 由多胞形的面数决定，多余的自由度由环面约化吃掉。多胞形的组合结构精确控制了这个「拼装」。

## 5 分类的应用与延伸

**从 Delzant 分类能读出什么**：

- **不动点个数 = 顶点个数**：$T^n$-不动点与多胞形顶点一一对应，每个不动点处的局部作用由顶点处边方向给出。
- **辛体积 = 多胞形的「辛体积」**：$\int_M \omega^n/n!$ 由 $\Delta$ 的组合数据（Fulton 的扇形体积公式）算出。
- **同伦类型可读**：多胞形的面格给出流形的同调（对环面流形，同调由「面→开扇」的配位完全确定，这就是 toric 拓扑）。

**相邻主题**：
- **Hirzebruch 曲面**：$n=2$ 时，由四边形分类——每个满足 Delzant 条件的四边形对应一个 Hirzebruch 曲面 $\mathbb{F}_k$。四边形「变形成梯形」对应流形的辛形变类。
- **toric 代数几何**：Delzant 多胞形的「对偶」是代数几何里的**扇（fan）**；辛环面流形 $M_\Delta$ 与复代数环面簇 $X_\Delta$（toric variety）是同流形。这是辛几何与代数几何的经典桥梁——Delzant 分类几乎就是「复环面簇理论」在辛世界的翻版。<span class="marginnote">几何量子化（第3篇）在环面流形上特别干净：$\Delta$ 的整点（格点）就是量子态空间的一组基——Bohr-Sommerfeld 态的个数 = $\Delta$ 的格点数。Delzant 分类因此直接服务于量子化。</span>

**辨析｜易错点：** Delzant 定理的前提是**有效**、**全维**（$k=n$）、**自由子作用**（约化处）的哈密顿环面作用。若环面维数不足（$k \lt  n$），动量像仍是凸多胞形但不再决定流形——信息不足。若作用不有效，像会「坍缩」。另外「辛同胚」在分类里是「辛同痕等价」的强版本，弱一点的「辛同胚」会对应多胞形的仿射等价类。

## 6 例：二维 Delzant 多边形一览

$n = 2$ 时，Delzant 分类把二维辛环面流形与平面凸多边形一一对应。几个基本图形与它们代表的流形：

| Delzant 多边形 $\Delta$ | 辛环面流形 $M_\Delta$ |
| --- | --- |
| 三角形 $\{x_1 \ge 0, x_2 \ge 0, x_1 + x_2 \le 1\}$ | $\mathbb{CP}^2$ |
| 正方形 $\{0 \le x_1 \le 1, 0 \le x_2 \le 1\}$ | $\mathbb{CP}^1 \times \mathbb{CP}^1 = S^2\times S^2$ |
| 梯形（上下底平行） | Hirzebruch 曲面 $\mathbb{F}_k$ |
| 等腰三角形（两腰对称） | 加权射影空间 $\mathbb{CP}(1,1,k)$（$k>1$ 时非光滑，需推广） |

读表要点：**多胞形的「形状」对应流形的「拓扑」**——三角形给 $\mathbb{CP}^2$（每个顶点处 $2$ 条边成整基），正方形给 $S^2\times S^2$（4 个顶点），梯形给 Hirzebruch 曲面（亏格 0、截面自交数由梯形「斜度」读出）。而**多胞形的「平移与整体缩放」对应辛结构的形变**——不改变拓扑，只改变辛体积与 Kähler 类。

**为何边界情形有趣**：让梯形的一条边「退化」（上下底重合），多边形变成三角形——对应 $\mathbb{F}_k \to \mathbb{CP}^2$ 的辛形变退化。**Delzant 分类的边界是流形变形的「相变点」**，这为「辛流形的形变类」提供了组合模型。

## 7 小结

- **哈密顿环面作用 + 凸性定理**：动量像 $\Delta = \mu(M)$ 是凸多胞形，顶点 = 不动点。
- **全维环面作用**（$k=n$）：**辛环面流形**，$\dim M = 2n$。
- **Delzant 多胞形**：单纯 + 有理 + 光滑（顶点边方向张成整格）。
- **Delzant 定理**：辛环面流形 ⟷ Delzant 多胞形，双射由动量像给出；构造靠辛约化 $\mathbb{C}^d/\!/T^{d-n}$。
- **例**：$\mathbb{CP}^n$ ⟷ 单纯形；$\mathbb{CP}^1\times\mathbb{CP}^1$
