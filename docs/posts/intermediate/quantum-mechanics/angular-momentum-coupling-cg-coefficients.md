## 为什么从角动量耦合开始

单个角动量已经讲透，但真实系统几乎总是**多个角动量并存**：氢原子有轨道角动量 $\hat{\mathbf{L}}$ 和自旋 $\hat{\mathbf{S}}$；多电子原子有多个电子的轨道与自旋；原子核、分子同样如此。这些角动量如何「加起来」？经典力学里矢量相加是普通的平行四边形法则，量子力学里却因为「分量不对易」而完全不同——相加的结果出现新的量子数，且满足三角不等式约束。<span class="marginnote">角动量耦合是原子光谱精细结构、塞曼效应、原子核能级、以及元素周期表结构的共同工具。它引出的 CG 系数（Clebsch–Gordan 系数）是「两个量子系统合成一个」的定量语言，也是量子信息里「两个量子比特合成纠缠态」的数学基础。</span>本篇讲清耦合规则、CG 系数的意义，以及两种常用耦合方案。

## 1 耦合的设定与总角动量

设有两个角动量 $\hat{\mathbf{J}}_1$（量子数 $j_1$）与 $\hat{\mathbf{J}}_2$（量子数 $j_2$），各自满足角动量代数。定义**总角动量**：

$$
\hat{\mathbf{J}} = \hat{\mathbf{J}}_1 + \hat{\mathbf{J}}_2
$$

关键事实：$\hat{\mathbf{J}}$ 也满足角动量代数（因为 $[\hat{\mathbf{J}}_1,\hat{\mathbf{J}}_2] = 0$，两者作用在不同自由度上），所以总角动量量子数 $j$ 与 $m$ 存在，且 $[\hat{\mathbf{J}}^2, \hat{J}_z] = 0$。<span class="marginnote">「两个角动量算符对易」是因为它们作用在不同粒子的不同自由度上（比如一个电子的轨道与自旋，或两个电子的自旋），彼此独立。因此 $\hat{\mathbf{J}}^2$、$\hat{J}_z$ 与 $\hat{\mathbf{J}}_1^2$、$\hat{\mathbf{J}}_2^2$ 可以同时对角化——这是整个耦合理论的出发点。</span>我们需要在「单粒子基」与「总角动量基」之间切换：

- **非耦合基**：$|j_1, m_1\rangle \otimes |j_2, m_2\rangle$，用 $m_1, m_2$ 标记。
- **耦合基**：$|j, m\rangle$，用总角动量 $j$ 与 $m$ 标记。

两套基都是完备的，其间由 CG 系数连接。

## 2 总角动量的取值：三角不等式

总角动量量子数 $j$ 的可能取值不是任意的，它受**三角不等式（triangle rule）**约束：

$$
|j_1 - j_2| \le j \le j_1 + j_2
$$

且 $j$ 取步长为 1 的整数（或半整数）序列：$j = |j_1-j_2|, |j_1-j_2|+1, \dots, j_1+j_2$。<span class="marginnote">三角不等式与经典矢量加法 $|\mathbf{J}_1 - \mathbf{J}_2| \le |\mathbf{J}| \le \mathbf{J}_1 + \mathbf{J}_2$ 形式上一致，但量子含义更深：$j$ 取<strong>分立</strong>值，中间的连续角度不可能——两个角动量的夹角被量子化。比如 $j_1 = j_2 = 1$ 时 $j$ 只能取 0、1、2，不可能取 0.5 或 1.5。</span>

维度检验（维格纳维数规则）：两边态数必须相等：

$$
\sum_{j=|j_1-j_2|}^{j_1+j_2}(2j+1) = (2j_1+1)(2j_2+1)
$$

这个等式恒成立，是耦合理论自洽性的保证。

## 3 CG 系数

两套基之间的变换由**克累布施—戈登系数（Clebsch–Gordan coefficients）**给出：

$$
|j, m\rangle = \sum_{m_1, m_2} C_{j_1 m_1; j_2 m_2}^{j m}\,|j_1, m_1\rangle \otimes |j_2, m_2\rangle
$$

其中 $C_{j_1 m_1; j_2 m_2}^{j m} = \langle j_1 m_1; j_2 m_2 | j m\rangle$ 是 CG 系数。它满足两个关键约束：

- **守恒律**：$m = m_1 + m_2$——$z$ 分量代数相加（因为 $\hat{J}_z = \hat{J}_{1z} + \hat{J}_{2z}$）。$m_1 + m_2 \neq m$ 的 CG 系数为零。
- **正交归一**：不同 $(j,m)$ 的耦合基互相正交归一，非耦合基亦然，CG 系数是两套正交基之间的**幺正变换矩阵元**。

<span class="marginnote">CG 系数的表在教科书与软件里都能查到，但理解它「是什么」比「怎么查」更重要：它就是「两个系统合成后，概率幅如何从单粒子基搬运到总角动量基」的换算系数。它的平方 $|C|^2$ 有清晰的物理意义——把处于 $|j_1,m_1\rangle|j_2,m_2\rangle$ 的系统测量总角动量，得到 $(j,m)$ 的概率。量子计算里，两个量子比特合成纠缠态时用到的就是同一套数学。</span>

## 4 公式解析：最简单的例子 $j_1 = j_2 = \frac12$

以两个自旋 $\frac12$ 合成总自旋为例，把抽象规则落到具体计算：

$$
\frac12 \otimes \frac12 = 0 \oplus 1
$$

- **第一步，态数盘点**：每个自旋 $\frac12$ 有 2 个态（$m = \pm\frac12$），两粒子共 $2\times2 = 4$ 个非耦合基态：$|\uparrow\uparrow\rangle$、$|\uparrow\downarrow\rangle$、$|\downarrow\uparrow\rangle$、$|\downarrow\downarrow\rangle$。
- **第二步，按三角不等式**：$j$ 可取 $|1/2-1/2| = 0$ 与 $1/2+1/2 = 1$，即 $j=0$（单重态）与 $j=1$（三重态）。
- **第三步，$j=1$ 的三个态（三重态）**：由 $m = m_1+m_2$ 得 $m = 1, 0, -1$。最高态 $|1,1\rangle = |\uparrow\uparrow\rangle$；用升降算符 $\hat{J}_- = \hat{J}_{1-} + \hat{J}_{2-}$ 依次降到 $|1,0\rangle$、$|1,-1\rangle$。
- **第四步，$j=0$ 的单重态**：与 $|1,0\rangle$ 正交的组合，$|0,0\rangle = \frac{1}{\sqrt2}(|\uparrow\downarrow\rangle - |\downarrow\uparrow\rangle)$——**这是著名的单重态（singlet）**，也是最大纠缠态（贝尔态）的雏形。

显式写出：

$$
|1,1\rangle = |\uparrow\uparrow\rangle, \qquad
|1,0\rangle = \frac{1}{\sqrt2}(|\uparrow\downarrow\rangle + |\downarrow\uparrow\rangle), \qquad
|1,-1\rangle = |\downarrow\downarrow\rangle, \qquad
|0,0\rangle = \frac{1}{\sqrt2}(|\uparrow\downarrow\rangle - |\downarrow\uparrow\rangle)
$$

这就是 CG 系数在 $j_1 = j_2 = 1/2$ 情形的全部内容——系数要么是 $1$ 要么是 $\pm 1/\sqrt2$。

## 5 耦合方案：L-S 耦合与 j-j 耦合

多电子原子的角动量耦合有两种标准方案：

- **L-S 耦合（罗素—桑德斯耦合）**：先把所有电子的轨道角动量合成 $\mathbf{L} = \sum\mathbf{l}_i$，所有自旋合成 $\mathbf{S} = \sum\mathbf{s}_i$，再合成总角动量 $\mathbf{J} = \mathbf{L} + \mathbf{S}$。适用于轻原子（$Z$ 小），自旋—轨道耦合弱。
- **j-j 耦合**：先把每个电子的轨道与自旋合成 $\mathbf{j}_i = \mathbf{l}_i + \mathbf{s}_i$，再把所有 $\mathbf{j}_i$ 合成 $\mathbf{J}$。适用于重原子（$Z$ 大），自旋—轨道耦合强。<span class="marginnote">两种方案给出的 $\mathbf{J}$ 量子数相同（都是总角动量），但中间的「中间量子数」不同（L-S 用 $L, S$，j-j 用各 $j_i$）。哪个方案适用，取决于自旋—轨道耦合相对电子间库仑作用的大小。周期表里轻元素（碳、氧）按 L-S 耦合定谱项，重元素（铅、铀）按 j-j 耦合定谱项——这是原子光谱学的分界线。</span>氢原子只有一个电子，L-S 与 j-j 退化为同一种耦合：$\mathbf{J} = \mathbf{L} + \mathbf{S}$，对应的谱项记作 $^{2S+1}L_J$（如基态 $^2S_{1/2}$）。

### 易错辨析

**辨析｜易错点：$j$ 的取值步长是 1，且只在三角不等式范围内。** $j = |j_1-j_2|, |j_1-j_2|+1, \dots, j_1+j_2$。对 $j_1 = 1, j_2 = 1$，$j$ 取 $0, 1, 2$——没有 $j = 0.5$ 或 $j = 1.5$。把 $j$ 当成连续区间（像经典矢量加法）就错了；它是分立的。

**辨析｜易错点：$m = m_1 + m_2$ 是严格约束，$m_1+m_2 \neq m$ 的 CG 系数为零。** 总角动量的 $z$ 分量是分量 $z$ 分量之和。所以耦合基 $|j,m\rangle$ 展开到非耦合基时，只保留满足 $m_1+m_2 = m$ 的项——查 CG 系数表前先核对这条「磁量子数守恒」。

**辨析｜易错点：CG 系数有「相位约定」，正负号随约定而变。** 同一条 $|0,0\rangle = \frac{1}{\sqrt2}(|\uparrow\downarrow\rangle - |\downarrow\uparrow\rangle)$ 的「减号」来自标准相位约定；不同教科书可能用相反约定。跨书查表时系数对不上，多半是相位约定不一致——先确认约定再比较。

**辨析｜易错点：两个全同粒子合成自旋时，要叠加「对称性」约束。** 若两个电子全同，总波函数（空间 × 自旋）必须反对称。三重态（自旋对称）要求空间部分反对称，单重态（自旋反对称）要求空间部分对称——单看自旋耦合而不看空间波函数，会漏掉泡利原理对可容许态的限制。

### 两种耦合方案对照表

L-S 与 j-j 是原子物理的「两条耦合路线」，用表对照：

| 特征 | L-S 耦合 | j-j 耦合 |
| --- | --- | --- |
| 顺序 | 先 $\mathbf{L}=\sum\mathbf{l}_i$、$\mathbf{S}=\sum\mathbf{s}_i$，再 $\mathbf{J}=\mathbf{L}+\mathbf{S}$ | 先 $\mathbf{j}_i=\mathbf{l}_i+\mathbf{s}_i$，再 $\mathbf{J}=\sum\mathbf{j}_i$ |
| 适用 | 轻原子（$Z$ 小） | 重原子（$Z$ 大） |
| 物理依据 | 自旋—轨道耦合弱 | 自旋—轨道耦合强 |
| 谱项记号 | $^{2S+1}L_J$ | 各 $j_i$ 合成 |
| 代表 | 碳、氧 | 铅、铀 |

**一表看清「耦合顺序」的分野**：先合「同类」再合「异类」是 L-S，先合「每个电子的轨道+自旋」再合全体是 j-j。选择哪种，取决于自旋—轨道耦合与电子间库仑作用谁占主导。总角动量 $\mathbf{J}$ 两种方案给同一结果，但中间的量子数不同——这正是「中间量子数不唯一、物理结果唯一」的体现。

## 6 小结

- **总角动量** $\hat{\mathbf{J}} = \hat{\mathbf{J}}_1 + \hat{\mathbf{J}}_2$ 满足角动量代数，$j$ 取值为**三角不等式** $|j_1-j_2| \le j \le j_1+j_2$。
- **维数规则**：$\sum_j(2j+1) = (2j_1+1)(2j_2+1)$，耦合自洽性的保证。
- **CG 系数**是单粒子基与总角动量基之间的幺正变换矩阵元，满足 $m = m_1 + m_2$ 与正交归一。
- 两个自旋 $\frac12$ 合成：**三重态**（$j=1$）与**单重态**（$j=0$），单重态 $\frac{1}{\sqrt2}(|\uparrow\downarrow\rangle-|\downarrow\uparrow\rangle)$ 是最小纠缠态的原型。
- 多电子耦合分 **L-S 耦合**（轻原子）与 **j-j 耦合**（重原子），取决于自旋—轨道耦合的强弱。

在下一节，我们引入电子最重要的内禀角动量——**自旋与泡利矩阵**，它没有经典对应物，却主宰了原子物理的精细结构与周期表。
