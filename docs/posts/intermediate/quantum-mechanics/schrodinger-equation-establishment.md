## 为什么从薛定谔方程开始

有了波函数和叠加原理，还差最后一块拼图：**波函数随时间如何演化？** 1926 年初，薛定谔写出了这个问题的主导方程——薛定谔方程。它与牛顿第二定律在经典力学里的地位相当：给定初始波函数和势能函数，方程唯一确定未来任意时刻的波函数。它是一把「决定论」的钥匙：**量子力学的概率性只出现在测量瞬间，而两次测量之间，波函数的演化是完全确定的**。<span class="marginnote">薛定谔写这个方程的灵感来自德布罗意的物质波假说：既然电子是波，就该有个波动方程来管它。他先把相对论版本写出来（后来由别人重新发现为克莱因—戈登方程），发现与氢原子光谱对不上，才退到非相对论版本——却成了量子力学的奠基之作。</span>

## 1 方程的形式

对于质量为 $m$ 的粒子在势能 $V(\mathbf{r}, t)$ 中运动，**含时薛定谔方程（time-dependent Schrödinger equation, TDSE）**为：

$$
i\hbar\frac{\partial \Psi(\mathbf{r}, t)}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2 \Psi(\mathbf{r}, t) + V(\mathbf{r}, t)\,\Psi(\mathbf{r}, t)
$$

其中 $\hbar = \dfrac{h}{2\pi}$（读作 h-bar），$\nabla^2$ 是拉普拉斯算子。<span class="marginnote">左侧 $i\hbar\partial\Psi/\partial t$ 含虚数单位 $i$，这保证了方程描述的是<strong>复</strong>波函数——波函数必须是复的，才能携带相位信息，而相位是干涉的来源。一个实波动方程（如声波方程）给不出干涉相位，这正是量子力学与经典波的本质差异。</span>方程右侧第一项是动能项，第二项是势能项。

可以简写为：

$$
i\hbar\frac{\partial \Psi}{\partial t} = \hat{H}\Psi
$$

其中 $\hat{H} = -\dfrac{\hbar^2}{2m}\nabla^2 + V$ 是**哈密顿算符（Hamiltonian）**，它对应系统的总能量（动能 + 势能）。这个简洁形式值得记住——它是量子力学「演化公设」的标准写法。

## 2 方程的建立：从经典到量子的对应

薛定谔方程并非严格推导而来，而是通过**对应原理**建立：在经典极限下，量子力学必须回到经典力学。核心的建立步骤是「把经典物理量换成算符」：

- **能量守恒**：经典哈密顿量 $H = \dfrac{p^2}{2m} + V(\mathbf{r}, t)$，其中 $p$ 是动量、$V$ 是势能。
- **对应规则**：动量 $p \to \hat{p} = -i\hbar\nabla$，能量 $E \to \hat{E} = i\hbar\dfrac{\partial}{\partial t}$，位置 $\mathbf{r} \to \hat{\mathbf{r}} = \mathbf{r}$（位置算符就是坐标本身）。<span class="marginnote">对应规则不是任意的，它要保证经典极限正确：把平面波 $\Psi \sim e^{i(kx - \omega t)}$ 代入，$\hat{p}\Psi = \hbar k\Psi = p\Psi$、$\hat{E}\Psi = \hbar\omega\Psi = E\Psi$，即算符作用在平面波上返回动量/能量的本征值——经典关系 $E = p^2/2m$ 得以恢复。这条对应是「波粒二象性」在算符语言里的体现。</span>
- **替换**：把 $H = p^2/2m + V$ 中的 $p$、$E$ 换成算符，作用在波函数上，即得 $\hat{E}\Psi = \hat{H}\Psi$，展开就是含时薛定谔方程。

所以薛定谔方程可以理解为：**「经典的能量守恒」+「波粒二象性的对应规则」= 量子动力学**。它从物理上「猜」出，但由所有后续实验验证。

## 3 定态薛定谔方程

当势能 $V$ 不显含时间（$V = V(\mathbf{r})$）时，可以用**分离变量法**：设 $\Psi(\mathbf{r}, t) = \psi(\mathbf{r})\,T(t)$，代入方程后两边分别只依赖 $\mathbf{r}$ 与 $t$，故都等于同一个常数 $E$。时间部分解得 $T(t) = e^{-iEt/\hbar}$，空间部分满足**定态薛定谔方程（time-independent Schrödinger equation, TISE）**：

$$
-\frac{\hbar^2}{2m}\nabla^2\psi(\mathbf{r}) + V(\mathbf{r})\,\psi(\mathbf{r}) = E\,\psi(\mathbf{r})
$$

即

$$
\hat{H}\psi = E\psi
$$

<span class="marginnote">「定态」（stationary state）这个名字容易误解——它不是说粒子不动，而是说 $|\Psi|^2 = |\psi(\mathbf{r})|^2$ 不随时间改变：概率分布、期望值都不变，只有相位 $e^{-iEt/\hbar}$ 在转。定态是量子力学的「驻波」，就像琴弦的固有振动模式。它是理解氢原子能级、一维势阱的基础。</span>这个方程是一个**本征值方程**：$\hat{H}$ 作用在 $\psi$ 上等于常数 $E$ 乘以 $\psi$。只有当 $E$ 取某些特定值时方程才有满足物理条件的解，这些 $E$ 就是**能级**，对应的 $\psi$ 是**本征函数**。能量量子化——普朗克黑体辐射里「能量一份一份」的谜——在这里自然地涌现为方程的可解条件。

## 4 公式解析：为什么方程里有个 $i\hbar$

拆解含时薛定谔方程最关键的一项——左侧的时间导数：

$$
i\hbar\frac{\partial\Psi}{\partial t} = \hat{H}\Psi
$$

- **第一步，$i$ 的作用**：虚数单位 $i$ 使演化成为**幺正（unitary）**的。它保证概率守恒：$\frac{d}{dt}\int|\Psi|^2\,\mathrm{d}^3r = 0$。若没有 $i$，方程变成扩散方程，波函数会衰减，概率不守恒。
- **第二步，$\hbar$ 的量纲**：$i\hbar\frac{\partial}{\partial t}$ 与能量同量纲（$[\hbar][t^{-1}] = [E]$），右侧 $\hat{H}$ 是能量算符，两边量纲一致——方程在量纲上自洽。
- **第三步，定态解**：对 $V$ 不显含时的情形，解为 $\Psi(\mathbf{r},t) = \psi(\mathbf{r})e^{-iEt/\hbar}$。代入验证：$i\hbar\partial_t\Psi = i\hbar \cdot (-iE/\hbar)\Psi = E\Psi$，而 $\hat{H}\psi = E\psi$ 保证右侧 $\hat{H}\Psi = E\Psi$，两边相等。
- **第四步，相位演化**：能量 $E$ 决定相位 $e^{-iEt/\hbar}$ 的转动速度。频率 $\omega = E/\hbar$——这正好回到普朗克—爱因斯坦关系 $E = h\nu = \hbar\omega$：**能量决定波的频率**。整条知识链在这里闭合了。

## 5 方程的物理内容与局限

薛定谔方程描述的是**非相对论性、单粒子**的量子力学。它一旦给定初始波函数 $\Psi(\mathbf{r}, 0)$，就唯一确定全部未来演化——这是决定论的。概率性只出现在测量时刻（波函数坍缩），这正是「演化决定论 + 测量概率性」的哥本哈根图景。<span class="marginnote">薛定谔方程的局限：它不满足洛伦兹不变性，无法描述高速（相对论）粒子和粒子产生湮灭。相对论化需要狄拉克方程（本专题第五篇），而量子场论则把波函数升级为场算符——那已是第三级之后的内容。</span>薛定谔本人一直不满于方程的统计诠释，他说「如果早知道它只能给出概率，我宁可不开这门课」——但这不妨碍方程本身成为量子力学最坚固的基石。

### 易错辨析

**辨析｜易错点：含时薛定谔方程不是「推导出来的」，是「建立/猜出来的」。** 它由对应原理与波粒二象性「拼」出，正确性靠实验验证而非数学证明。初学常误以为它是从经典力学严格推出的——实际上它是量子力学的基本公设，地位等同牛顿第二定律。

**辨析｜易错点：$\hat{H}$ 是「哈密顿算符」，不是「能量本征值」。** $\hat{H} = -\frac{\hbar^2}{2m}\nabla^2 + V$ 是作用在波函数上的算符；本征值 $E$ 才是能量。写 $\hat{H}\psi = E\psi$ 时左右两边不是「同一类东西」，而是「算符作用的结果 = 数乘波函数」——这是本征值方程的标准结构。

**辨析｜易错点：定态不是「静止的态」。** 定态 $\Psi = \psi e^{-iEt/\hbar}$ 的概率密度 $|\Psi|^2 = |\psi|^2$ 不随时间变，但波函数本身带着振荡相位 $e^{-iEt/\hbar}$ 在演化。说「定态=静止」会丢掉相位信息，而相位是干涉的载体——定态仍然是「动」的，只是概率分布不动。

**辨析｜易错点：分离变量只对「势能不显含时间」有效。** $V = V(\mathbf{r})$ 时才能写 $\Psi = \psi(\mathbf{r})T(t)$；若势还含 $t$（如含时光场），时间与空间无法分离，定态方程不适用，必须用含时薛定谔方程直接求解。这是本专题第五篇《含时微扰》的起点，也是「定态方法」适用边界的判据。

### 经典量 → 量子算符对照表

「对应规则」是理解薛定谔方程怎么来的钥匙，把最常用的对应列成表：

| 经典量 | 量子算符 | 备注 |
| --- | --- | --- |
| 位置 $x$ | $\hat{x} = x$ | 乘坐标本身 |
| 动量 $p$ | $\hat{p} = -i\hbar\frac{\partial}{\partial x}$ | 德布罗意关系定出 $-i\hbar$ |
| 动能 $p^2/2m$ | $-\frac{\hbar^2}{2m}\nabla^2$ | 动量算符平方 |
| 势能 $V(\mathbf{r})$ | $\hat{V} = V(\hat{\mathbf{r}})$ | 乘势函数 |
| 能量 $E$ | $\hat{E} = i\hbar\frac{\partial}{\partial t}$ | 时间导数 |
| 角动量 $\mathbf{L} = \mathbf{r}\times\mathbf{p}$ | $\hat{\mathbf{L}} = -i\hbar\,\mathbf{r}\times\nabla$ | 位置叉乘动量 |

**这张表是最小对应规则的完整清单**：经典哈密顿量 $H = p^2/2m + V$ 逐项替换即得薛定谔方程。注意「替换」不是随意的——每个算符都由「作用在平面波上必须还原德布罗意/普朗克关系」这一约束唯一确定。量子化的一切，都浓缩在这张「经典→算符」的翻译表里。

### 拓展衔接

薛定谔方程是「量子动力学的第一公设」，但它的适用范围有明确边界：非相对论、单粒子、无粒子数变化。这三个限制分别被狄拉克方程（相对论）、多体理论（多粒子）与量子场论（粒子产生湮灭）突破。在现代计算中，薛定谔方程本身几乎从不在真实多电子系统里被直接求解——它先被化为定态方程，再用变分、微扰与数值方法（如密度泛函）逼近。理解「方程的建立」，就是理解「为什么近似方法不可避免」的根源。

把方程与经典对应再对齐一遍：经典力学用牛顿第二定律 $F = ma$ 确定轨道，量子力学用薛定谔方程确定波函数——**一个是「加速度决定轨迹」，一个是「哈密顿量决定演化」**，这是「从极限到大模型」知识链里两种决定论的交接点。

## 6 小结

- **含时薛定谔方程** $i\hbar\partial_t\Psi = \hat{H}\Psi$ 是波函数的时间演化法则，对应经典力学里的运动方程。
- 通过**对应规则**（$p \to -i\hbar\nabla$，$E \to i\hbar\partial_t$）把经典能量守恒改写成量子方程。
- 势能不显含时间时用**分离变量法**得到定态方程 $\hat{H}\psi = E\psi$，时间因子为 $e^{-iEt/\hbar}$。
- 定态方程是**本征值方程**，能级由方程可解条件决定——能量量子化由此涌现。
- 方程是决定论的，概率性只在测量时出现；它是非相对论单粒子方程，相对论化需狄拉克方程。
