# 大中小学思政课一体化（道德与法治/思想政治课程体系）

思政课是落实立德树人根本任务的关键课程，也是国民教育的必修科目。大中小学思政课一体化建设以中共中央办公厅、国务院办公厅《关于深化新时代学校思想政治理论课改革创新的若干意见》为纲，按《义务教育道德与法治课程标准（2022年版）》与《普通高中思想政治课程标准》系统梳理从小学《道德与法治》、初中《道德与法治》到高中《思想政治》的完整课程体系，是理解我国德育与法治教育整体框架、学段衔接逻辑与教学评价改革的必经之路。

## 对标教材

- 中共中央办公厅、国务院办公厅《关于深化新时代学校思想政治理论课改革创新的若干意见》（人民出版社）
- 中华人民共和国教育部《义务教育道德与法治课程标准（2022年版）》（北京师范大学出版社）
- 中华人民共和国教育部《普通高中思想政治课程标准（2017年版2020年修订）》（人民教育出版社）
- 统编小学、初中《道德与法治》教材与高中《思想政治》教材（人民教育出版社）
