## 为什么从逻辑与思维开始

选择性必修 3《逻辑与思维》是高中思想政治中「最不像思政课」的一册——它不讲政治、经济、法治，而是训练**思维本身**：怎样合乎逻辑地思考、怎样运用辩证思维、怎样进行创新思维。这一册对应高中核心素养中的**科学精神**，也呼应了本博客「从极限到大模型」系列中逻辑学、批判性思维的主题——它是把「讲道理」变成「会讲道理」的学科。

## 1 科学思维：思维品质的总要求

《逻辑与思维》第一单元「树立科学思维观念」开篇讲**科学思维**：

- **科学思维的含义**：符合认识规律、遵循逻辑规则、能够达成正确认识的思维。
- **科学思维的特征**：追求真理、实事求是、善于创新。
- **学习科学思维的意义**：提升思维能力，正确认识世界与改造世界。

**重点：科学思维 = 合乎逻辑 + 符合实际 + 勇于创新。** 这一单元是整个模块的总纲，后面讲的形式逻辑、辩证思维、创新思维，都是科学思维的具体形态。<span class="marginnote">「科学思维」与必修四《哲学与文化》一脉相承：马克思主义哲学提供的世界观与方法论，在逻辑与思维模块中被具体化为思维规则与技术。哲学是「想得对」的立场，逻辑是「推得对」的工具。</span>

## 2 概念与判断：思维的基本形式

第二单元「遵循逻辑思维规则」讲逻辑学的核心内容，先看**概念**与**判断**：

- **概念**：反映事物本质属性的思维形式，有内涵与外延。
- **概念间的关系**：全同、包含、交叉、全异关系。
- **判断**：对事物情况有所断定的思维形式。
- **判断的种类**：简单判断（性质判断、关系判断）与复合判断（联言、选言、假言判断）。

**重点：概念要明确（内涵与外延清晰），判断要恰当（反映真实情况）。** 概念与判断是推理的原材料——推理是否有效，首先取决于概念是否明确、判断是否恰当。

## 3 公式解析：三段论推理的有效形式

逻辑学最经典的形式是**三段论**——由两个前提推出一个结论的演绎推理。它的标准形式是：

$$大前提：所有 \ M \ 是 \ P$$
$$小前提：所有 \ S \ 是 \ M$$
$$结论：所有 \ S \ 是 \ P$$

以经典例子代入：

$$所有公民都享有民事权利（M = 公民，P = 享有民事权利的人）$$
$$张某是公民（S = 张某，M = 公民）$$
$$所以张某享有民事权利（S 是 P）$$

对这条推理做三步拆解：

- **第一步，找中项**：中项 $M$（公民）出现在两个前提中但不出现在结论中，它是连接小项 $S$（张某）与大项 $P$ 的桥梁。
- **第二步，验规则**：中项至少周延一次、前提中不周延的项在结论中不得周延、两个否定前提推不出结论——本例满足全部规则。
- **第三步，定结论**：因大项、小项关系被中项锁定，结论必然成立。

三段论的价值在于：它把「从已知到未知」的推理过程显性化、规则化。掌握了它，就能识别日常论证中的偷换概念、中项不周延等逻辑错误。<span class="marginnote">一个经典的逻辑谬误示范：前提「所有中国人都是人」「所有日本人也都是人」，推不出「所有日本人都是中国人」——因为中项「人」在两句前提中都不周延，违反了「中项至少周延一次」的规则。记住这个反例，就记住了中项规则。</span>

## 4 复合判断与推理规则

《逻辑与思维》还系统讲复合判断的推理规则：

- **联言推理**：分解式与合成式。
- **选言推理**：相容选言与不相容选言推理。
- **假言推理**：充分条件、必要条件、充要条件假言推理。

| 判断类型 | 联结词 | 推理规则 |
| --- | --- | --- |
| 联言判断 | 且（并且） | 全真才真 |
| 相容选言判断 | 或 | 一真则真，否定一支可推另一支 |
| 不相容选言判断 | 要么…要么 | 只能一真 |
| 充分条件假言判断 | 如果…那么 | 肯定前件→肯定后件；否定后件→否定前件 |

**重点：假言推理是考试重点。** 充分条件假言推理只有两个有效式——「肯定前件式」与「否定后件式」；「否定前件→否定后件」「肯定后件→肯定前件」都是无效的。这个「顺真逆假、逆否等价」的逻辑，是训练严密思维的核心。

## 5 逻辑思维的基本规律

逻辑学还有三条基本规律，是思维正确性的底线：

- **同一律**：思想必须保持同一性，不能偷换概念或转移论题。
- **矛盾律**：不能同时肯定两个互相矛盾的思想。
- **排中律**：两个矛盾判断不能同假，必有一真。

三条规律分别保证思维的**确定性、一致性、明确性**。违反同一律会出现「跑题」，违反矛盾律会出现「自相矛盾」，违反排中律会「含糊其辞」。

## 6 辩证思维与创新思维

第三、四单元讲**辩证思维**与**创新思维**，与必修四辩证法呼应：

- **辩证思维**：整体性、动态性、矛盾性思维，坚持分析与综合相结合。
- **创新思维**：发散思维与聚合思维、逆向思维与超前思维。
- **创新思维的途径**：破除思维定势、联想、迁移、想象。

辩证思维把必修四的辩证法原理变成「思维操作」：用联系的观点看问题、用发展的眼光看趋势、用矛盾分析法找关键。创新思维则指向「与众不同但有根据」——与科学精神素养直接对应。

## 7 与初中、大学及其他专题的衔接

- **上承初中**：初中道德与法治涉及的「辨析」「议题讨论」是逻辑思维的萌芽。
- **横向呼应**：与哲学必修四、语文论述文阅读、数学证明训练协同。
- **下启大学**：大学阶段的逻辑学、论证方法课程在此基础上的深化。

<span class="marginnote">交叉视角：本模块与博客中《哲学逻辑》《批判性思维》等专题高度同源——三段论、真值表、逻辑谬误都是逻辑学的共同语言。高中思政课的《逻辑与思维》，正是把大学逻辑学的入门内容按高中生认知水平重新组织。</span>

## 8 教学建议：在推理中练逻辑

逻辑教学最忌「讲规则不练推理」：

- **实例辨析**：用生活中的论证实例辨析有效与无效。
- **真假判断**：设计真假推理题目训练复合判断。
- **谬误识别**：收集广告、新闻中的逻辑谬误让学生识别。
- **写作结合**：与议论文写作结合，训练论证的严密性。

**辨析｜易错点：** 本模块最易错的是充分条件假言推理的「否定前件」与「肯定后件」——学生凭直觉认为「没满足条件就一定不成立」「满足了结果就一定有该条件」，恰恰都是无效推理。规范训练是唯一解法。

## 10 小结

- 选择性必修 3《逻辑与思维》训练**科学思维**，对应「科学精神」素养。
- 思维的基本形式是**概念、判断、推理**。
- **三段论**是演绎推理的经典形式，中项规则是核心。
- 复合判断推理规则中，**假言推理的两种有效式**是考试重点。
- 逻辑基本规律**同一律、矛盾律、排中律**保证思维的确定性、一致性、明确性。
- **辩证思维与创新思维**把哲学辩证法转化为思维技术。
- 教学要**在推理中练逻辑**，警惕凭直觉推断的无效推理。
