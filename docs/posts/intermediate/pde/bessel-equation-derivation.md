## 为什么从柱坐标开始

分离变量法在矩形区域给出三角函数，在圆盘/圆柱区域则引出**贝塞尔函数**——这是特殊函数家族的第一位主角。圆柱无处不在：管道、烟囱、轴承、光缆。这一节从柱坐标下拉普拉斯算子的分离变量出发，逐步把角度方向、轴向分离掉，最后把径向方程写成**贝塞尔方程**。你会看到，贝塞尔方程不是凭空定义，而是「圆柱对称 + 分离变量」的必然产物——特殊函数都是某个区域上分离变量法的「本征函数」。

## 1 柱坐标的拉普拉斯算子

柱坐标 $(r, \theta, z)$ 中，拉普拉斯算子为

$$
\Delta u = u_{rr} + \frac{1}{r}u_r + \frac{1}{r^2}u_{\theta\theta} + u_{zz}
$$

<span class="marginnote">$1/r$ 与 $1/r^2$ 项是「面积元随 $r$ 变化」的代价：柱坐标的体元 $r\,dr\,d\theta\,dz$ 含 $r$，散度定理在柱坐标里就多出这些因子。这些因子最终决定了径向方程的形状——它们正是贝塞尔方程里「$r$ 的一次方与 $r^2$ 的系数」的来处。</span>对与 $z$ 无关的问题（圆盘、二维极坐标），$u_{zz}$ 项消失，回到第五篇圆盘热传导见过的形式。

## 2 分离变量：角度与轴向

设解可分离

$$
u(r,\theta,z) = R(r)\,\Theta(\theta)\,Z(z)
$$

代入 Helmholtz 方程（或拉普拉斯方程 $\Delta u + \lambda u = 0$，$\lambda$ 是本征值），除以 $R\Theta Z / r^2$：

$$
\frac{r^2 R'' + r R' + (\lambda r^2 + \kappa_z) R}{R} = -\frac{\Theta''}{\Theta} = \mu
$$

其中 $-\kappa_z = Z''/Z$ 是轴向的分离常数（对 $z$ 无关问题 $\kappa_z = 0$）。分离角度：

$$
\Theta'' + \mu\,\Theta = 0
$$

**周期性条件** $\Theta(\theta + 2\pi) = \Theta(\theta)$（柱坐标系下函数必须单值）给出

$$
\mu = m^2, \qquad \Theta_m(\theta) = A\cos m\theta + B\sin m\theta, \qquad m = 0,1,2,\dots
$$

**角度本征值 $m$ 是整数——由「闭合」的单值性强制。** 这是圆柱与矩形的关键差别：矩形靠端点条件给离散谱，圆柱靠周期性给离散谱。<span class="marginnote">$m$ 的物理含义是「角向波数」：$m=0$ 轴对称（无角向变化）、$m=1$ 一个完整周期、$m=2$ 两个周期。圆膜振动、圆柱热传导的「环向节线」数量就是 $m$。</span>

## 3 径向贝塞尔方程的导出

把 $\mu = m^2$ 代回径向方程，整理得

$$
r^2 R'' + r R' + \left(k^2 r^2 - m^2\right)R = 0
$$

其中 $k^2 = \lambda + \kappa_z$（若 $\lambda = 0$ 即拉普拉斯方程，$k$ 为轴向分离常数的平方根；若解 Helmholtz 方程则 $k^2 = \lambda$）。**这就是贝塞尔方程（Bessel equation）**，$m$ 称为**阶（order）**。<span class="marginnote">贝塞尔方程的标准形式是 $x^2y'' + xy' + (x^2 - \nu^2)y = 0$，其中 $\nu$ 是阶。这里只要做缩放 $x = kr$ 就得到标准形——$k$ 把「物理半径」换算成「无量纲自变量」。$\nu = m$ 整数阶对应圆柱区域的物理问题；半整数阶（如 $\nu = n + \frac12$）出现在球坐标（下一节）。</span>

**公式解析：缩放成标准贝塞尔方程**

- **第一步，写径向方程。** $r^2R'' + rR' + (k^2r^2 - m^2)R = 0$。
- **第二步，换元 $x = kr$。** 由链式法则 $R' = k\frac{dR}{dx}$、$R'' = k^2\frac{d^2R}{dx^2}$。代入：$r^2k^2R''_x + rkR'_x + (k^2r^2 - m^2)R = 0$。
- **第三步，约去 $k^2$。** 因 $r = x/k$，各项同乘后得
  $$ x^2 y'' + x y' + (x^2 - m^2)y = 0, \qquad y(x) = R(x/k) $$
- **第四步，读结构。** 系数在 $x=0$ 处**奇异**（$x^2y'' + xy'$ 的首项），故贝塞尔方程是**奇异微分方程**，其解不能用普通幂级数（泰勒）在原点展开，而要用**广义幂级数（Frobenius）**——这正是下一节的内容。

**贝塞尔方程的三个特征**：奇异点 $x=0$、参数 $x^2$（来自 $k^2r^2$）、阶 $m$。前两个来自柱坐标的几何，第三个来自角向的本征值。

## 4 贝塞尔方程出现的场景

贝塞尔方程在哪些物理问题中自然出现？凡是「圆柱对称 + 分离变量」都会遇到它：

| 问题 | 方程 | 阶 $m$ |
| --- | --- | --- |
| 圆膜振动 $u_{tt} = c^2\Delta u$ | Helmholtz 径向 | 角向波数 |
| 圆柱热传导（稳态/瞬态） | Helmholtz / 径向 | 角向波数 |
| 圆柱内拉普拉斯 | 轴向分离 | 角向波数 |
| 光纤模式分析 | Helmholtz（柱） | 整数阶 |
| 球坐标（下节） | 变换后半整数阶 | $n + \frac12$ |

**贝塞尔函数不是「一个函数」，而是一整族**——每个阶 $m$（甚至任意阶 $\nu$）对应一族解。这个「按阶分类」的结构，与三角函数族 $\{\cos m\theta\}$ 按 $m$ 分类完全平行，只是贝塞尔函数没有简单的「$\sin/\cos$ 口诀」，而要靠级数、递推与渐近公式（接下来三节）。

**辨析｜易错点：** 不要混淆「贝塞尔方程」与「贝塞尔函数」。方程是 $x^2y'' + xy' + (x^2-\nu^2)y = 0$，函数是它的解；方程因几何而来，函数因求解而生。另外，径向方程在 $r = 0$ 处奇异——**分离变量时必须额外要求「解在 $r=0$ 处有限」**，这个「隐藏边界条件」会丢弃一族在原点发散的解（第二类贝塞尔函数），下一节细讲。

## 5 数值算例：把物理方程化成标准形

取圆膜振动 $u_{tt} = c^2\Delta u$ 在圆盘 $0\le r\le R$ 上，分离变量 $u = e^{i\omega t}R(r)\Theta(\theta)$：

- **第一步，写出径向方程。** 代入后 $r^2R'' + rR' + (\frac{\omega^2}{c^2}r^2 - m^2)R = 0$——这里 $k^2 = \omega^2/c^2$。
- **第二步，缩放 $x = kr$。** 化成标准贝塞尔方程，$y(x) = R(x/k)$。
- **第三步，定阶。** $m$ 是角向本征值（整数），由周期性决定。
- **第四步，写解。** $R(r) = J_m(kr)$（取有界解），本征值条件由边界 $R(R) = 0$ 给出 $J_m(kR) = 0$，即 $k = j_{mn}/R$——**贝塞尔函数的零点就是本征值**。

**数值流程**：圆膜振动的「音高」由 $j_{mn}/R$ 决定——基模 $m=0$ 对应 $j_{01} \approx 2.405$，这是圆膜的基频。查贝塞尔零点表（下一节）就能得到整个音阶——这正是乐器声学里鼓的振动频率来源。

## 6 半整数阶与球坐标

圆柱给整数阶 $m$，球坐标则给出**半整数阶**：

- **球坐标分离**：$\Delta u = 0$ 在球坐标下，径向方程经变换 $R(r) = r^{-1/2}v(r)$ 化成贝塞尔方程，阶 $\nu = n + \frac12$。
- **半整数阶的特殊性**：$J_{n+1/2}(x)$ 可以用初等函数表出，如 $J_{1/2}(x) = \sqrt{\frac{2}{\pi x}}\sin x$、$J_{3/2}(x) = \sqrt{\frac{2}{\pi x}}\left(\frac{\sin x}{x} - \cos x\right)$。
- **物理含义**：球坐标的球函数（勒让德相关，第八篇末）的径向部分由半整数阶贝塞尔（球贝塞尔函数 $j_n = \sqrt{\frac{\pi}{2x}}J_{n+1/2}$）承担。

**辨析｜易错点：** 阶 $\nu$ 不必是整数——贝塞尔方程对任意复阶 $\nu$ 有解。整数阶来自「圆柱闭合」，半整数阶来自「球对称」，一般实阶出现在更一般的退化问题里。**「阶来自几何对称性」是理解特殊函数分类的关键线索。**<span class="marginnote">从「从极限到大模型」的视角，贝塞尔方程是「对称性决定解的形状」的又一例证：圆柱对称把自由度压缩到一条径向 ODE，贝塞尔函数就是这条 ODE 的本征函数。特殊函数不是要背的目录，而是「区域对称性 + 分离变量」自动长出来的语言——理解了对称性，就理解了特殊函数为何长成那样。</span>

## 7 小结

- 柱坐标拉普拉斯含 $1/r$ 与 $1/r^2$ 项，来自体元 $r\,dr\,d\theta\,dz$。
- 角度分离给出周期性本征值 $m^2$，本征函数 $\cos m\theta, \sin m\theta$。
- 径向方程化为贝塞尔方程 $r^2R'' + rR' + (k^2r^2 - m^2)R = 0$。
- 缩放 $x = kr$ 得标准形 $x^2y'' + xy' + (x^2-m^2)y = 0$。
- 贝塞尔方程在 $x=0$ 奇异，解需用广义幂级数——下一节的方法。
