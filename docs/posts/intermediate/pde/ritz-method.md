# 里兹（Ritz）方法

<div class="epigraph">

## 为什么从里兹方法开始

上一节的弱解/变分框架给出了「解 = 能量极小」，但无穷维空间里的极小仍然不好找。**里兹方法**做一件务实的事：把候选函数限制在一个**有限维子空间**（由少量基函数张成）里，在这个子空间里求能量极小——结果是一个**线性代数方程组**，直接可解。这是「把变分问题离散化」的第一种经典途径，也是有限元（本专题最后一节）的直系祖先。这一节建立里兹方法，看它如何把 PDE 变成矩阵方程。

## 1 有限维试探空间

选一组基函数 $\{\varphi_1, \dots, \varphi_N\}$（满足本质边界条件、线性无关），构造**试探函数**

$$
u_N(x) = \sum_{i=1}^{N}c_i\,\varphi_i(x)
$$

系数 $c_i$ 待定。把 $u_N$ 代入能量泛函，$J$ 变成 $N$ 元函数 $J(c_1,\dots,c_N)$。

**里兹方法**：在所有形如 $\sum c_i\varphi_i$ 的函数中找能量最小的那个——即**在有限维子空间 $V_N = \mathrm{span}\{\varphi_i\}$ 中极小化 $J$**。<span class="marginnote">基函数的选择是里兹方法的灵魂：它们必须满足本质边界条件（Dirichlet），且「能好地逼近真解」。经典选择是三角函数、多项式（谱方法的前身）、以及有限元的分片多项式。基函数越「贴近」解的形状，需要的 $N$ 越小。</span>

**对 Poisson 问题**：$J[v] = \frac12\int|\nabla v|^2dx - \int fv\,dx$。代入 $u_N$：

$$
J = \frac12\sum_{i,j}c_ic_j\int\nabla\varphi_i\cdot\nabla\varphi_j\,dx - \sum_ic_i\int f\varphi_i\,dx
$$

## 2 公式解析：离散化给出线性方程组

对 $c_k$ 求偏导并令为零（极小条件）：

$$
\frac{\partial J}{\partial c_k} = \sum_jc_j\int\nabla\varphi_j\cdot\nabla\varphi_k\,dx - \int f\varphi_k\,dx = 0
$$

整理成矩阵方程：

- **第一步，定义刚度矩阵。** $A_{kj} = \int_\Omega\nabla\varphi_k\cdot\nabla\varphi_j\,dx$——称为**刚度矩阵（stiffness matrix）**（名字来自结构力学：弹性系统的能量二次型）。
- **第二步，定义载荷向量。** $b_k = \int_\Omega f\,\varphi_k\,dx$——**载荷向量**（外力做功）。
- **第三步，写线性系统。** $\sum_jA_{kj}c_j = b_k$，即
  $$ \boxed{\;A\,\boldsymbol{c} = \boldsymbol{b}\;} $$
- **第四步，读结构。** $A$ 对称（$A_{kj} = A_{jk}$）正定（对非零 $\boldsymbol{c}$，$\boldsymbol{c}^TA\boldsymbol{c} = \int|\nabla u_N|^2 > 0$），故方程组**唯一可解**。

**里兹方法把「变分问题」变成「解一个对称正定的线性方程组」**——这是它最大的工程价值：对称正定矩阵有高效的求解算法（Cholesky 分解等）。

## 3 里兹近似是最优逼近

里兹近似 $u_N$ 与真解 $u$ 的关系有一个漂亮的变分刻画：**$u_N$ 是「能量内积」意义下 $u$ 在 $V_N$ 中的最佳逼近**。

- **第一步，写能量内积。** $B(u,v) = \int\nabla u\cdot\nabla v\,dx$ 是 $H_0^1$ 上的内积。
- **第二步，正交性。** 弱解满足 $B(u,v) = (f,v)$；里兹解满足 $B(u_N,\varphi_k) = (f,\varphi_k)$ 对所有基函数。相减得
  $$ B(u - u_N,\ \varphi_k) = 0, \qquad k = 1,\dots,N $$
  **误差 $u - u_N$ 与试探空间 $V_N$ 正交**（Galerkin 正交性，虽然里兹方法这里其实是同一回事）。
- **第三步，最优性。** 对任何 $v_N \in V_N$，$u_N - v_N \in V_N$ 与 $u - u_N$ 正交，由 Pythagoras：
  $$ \|u - v_N\|_B^2 = \|u - u_N\|_B^2 + \|u_N - v_N\|_B^2 \ge \|u - u_N\|_B^2 $$
- **第四步，结论。** $u_N$ 是 $u$ 在 $V_N$ 中的**最佳逼近**（能量范数意义下）。

**里兹近似的误差 = 「$u$ 到试探空间的能量距离」。** 误差分析归结为「基函数能否好地逼近真解」——这是有限元误差理论的种子（最后一节）。

## 4 一个完整的里兹计算

**例子**：$-\Delta u = 1$ 在 $\Omega = (0,1)$，$u(0) = u(1) = 0$。真解 $u = \frac{x(1-x)}{2}$。取基函数 $\varphi_1 = x(1-x)$、$\varphi_2 = x^2(1-x)^2$：

- **第一步，算刚度矩阵。** $\varphi_1' = 1-2x$，$\varphi_2' = 2x(1-x)(1-2x)$。$A_{11} = \int_0^1(1-2x)^2dx = \frac13$；$A_{22} = \int_0^1 4x^2(1-x)^2(1-2x)^2dx$；$A_{12} = \int(1-2x)2x(1-x)(1-2x)dx$。
- **第二步，算载荷。** $b_1 = \int_0^1x(1-x)dx = \frac16$、$b_2 = \int_0^1x^2(1-x)^2dx = \frac{1}{30}$。
- **第三步，解系统。** 解 $2\times2$ 方程组得 $c_1, c_2$，$u_2 = c_1x(1-x) + c_2x^2(1-x)^2$。
- **第四步，对比真解。** $u = \frac{x(1-x)}{2}$ 恰在 $V_2$ 中（$\frac12\varphi_1$），所以 $c_1 = \frac12$、$c_2 = 0$——**里兹精确还原**（本例真解恰在试探空间里）。

**辨析｜易错点：** 里兹方法的精度完全依赖试探空间「是否装得下真解」。本例真解恰在 $V_2$ 中所以零误差——这是特例。一般情况 $u_N$ 只是最佳逼近，误差由「基函数的分辨率」决定。**「换一组基 = 换一个近似质量」**——里兹方法的艺术在于选基，这也是它与有限元（自动生成基）的分野。

## 5 里兹方法的意义与局限

里兹方法的历史地位：

- **连接变分与数值**：它是「直接法」的鼻祖——不先解 PDE 再离散，而是直接离散变分问题；
- **与 Galerkin 的关系**：里兹从能量出发、Galerkin 从弱形式出发，两者对**对称问题**等价（下一节）；
- **与有限元的关系**：有限元 = 里兹方法 + 分片多项式基 + 局部支撑。里兹选全局基（三角函数/多项式），有限元选局部基（分片线性）。

**局限**：里兹方法要求能量泛函存在（即问题对称）——对非对称算子（如对流项 $b\cdot\nabla u$），能量不存在，里兹失效，需用 Galerkin 方法（下一节）。<span class="marginnote">「里兹需要能量、Galerkin 只要弱形式」是两者最本质的分工。对自伴椭圆问题（拉普拉斯、弹性），两者重合；对非自伴问题（对流扩散），Galerkin 独挑大梁。从「从极限到大模型」的主线看，里兹方法是「在函数空间里做有限维优化」——与机器学习中「在参数空间里优化损失」共享「限制空间 + 求极值」的心智模型。</span>

## 6 数值算例：逐步逼近收敛

继续一维问题 $-\Delta u = 1$、$u(0)=u(1)=0$，真解 $u = \frac{x(1-x)}{2}$，看试探空间维数如何影响结果：

- **第一步，$N=1$。** 只取 $\varphi_1 = x(1-x)$：$A_{11} = \frac13$、$b_1 = \frac16$，$c_1 = \frac{b_1}{A_{11}} = \frac{1/6}{1/3} = \frac12$。$u_1 = \frac12 x(1-x)$——**恰好等于真解**。
- **第二步，$N=2$。** $u_2 = c_1\varphi_1 + c_2\varphi_2$，解出 $c_2 = 0$（真解已在 $V_1$ 里，$V_2$ 多余）。
- **第三步，换更难的问题。** $-\Delta u = 1 + 2x$、$u(0)=u(1)=0$，真解 $u = \frac{x(1-x)(1+2x)}{6}$（三次多项式，不在 $V_2$ 里）。
- **第四步，观察误差。** $N=2$ 的里兹解是三次真解在二次空间里的最佳逼近——误差随 $N$ 增大迅速消失（谱基的误差是「超代数」衰减）。

**里兹解的收敛性**：试探空间越「贴近」真解，$N$ 个基函数给出的近似越好。对全局多项式基，误差随 $N$ 超快衰减（谱收敛）；对分片多项式基（有限元），误差随网格尺度 $h$ 多项式衰减。**「选基 = 选收敛速度」**是里兹方法最实用的结论。

## 7 基函数选择的艺术

里兹方法成败全在基函数：

- **本质边界条件必须满足**：$\varphi_i$ 须满足 Dirichlet 边界（$u=0$ 处 $\varphi_i = 0$），否则解在边界上「塌方」。
- **自然边界条件自动满足**：Neumann 型边界在变分弱形式里自动实现，无需强加给基函数——这是变分形式的红利。
- **谱基 vs 分片基**：三角函数 / 多项式（谱）光滑解高效；分片线性（有限元）复杂区域灵活。两者是里兹方法的两个极端。

**辨析｜易错点：** 里兹方法给出的是「能量范数」下的最佳逼近，不是逐点最佳。若 $N$ 太小，近似在局部可能明显偏离真解（能量误差小 ≠ 逐点误差小）。**误差要按应用关心的量来衡量**——关心梯度用 $H^1$ 误差、关心值用 $L^2$ 误差。

**从「从极限到大模型」的视角**：里兹方法是「先验空间 + 数据拟合」最纯粹的例子——基函数是先验（模型族），载荷是数据，系数是训练。机器学习的「归纳偏置选得准不准」，与里兹的「基函数选得准不准」，是同一个道理的两个面孔。

## 8 小结

- 里兹方法：在有限维子空间 $V_N = \mathrm{span}\{\varphi_i\}$ 中极小化能量泛函。
- 离散化给出对称正定线性系统 $A\boldsymbol{c} = \boldsymbol{b}$。
- 刚度矩阵 $A_{kj} = \int\nabla\varphi_k\cdot\nabla\varphi_j$，载荷 $b_k = \int f\varphi_k$。
- 里兹解是能量范数下的最佳逼近，误差 = 到试探空间的能量距离。
- 里兹需要能量（对称问题），非对称问题需转向 Galerkin 方法。
