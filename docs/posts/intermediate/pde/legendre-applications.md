## 为什么从球形位势问题开始

勒让德多项式的理论已经齐备，现在看它在球体位势问题中的实战。球形区域是「位势理论的最爱」：球对称让分离变量 + 勒让德展开成为通行的求解流水线。这一节通过三个经典问题——球面给定位势、两半球不同电位、均匀场中的导体球——把勒让德展开、径向解 $r^n/r^{-(n+1)}$、与物理图像（多极展开）串成完整的应用图谱。学完你会对「球上的边值问题怎么解」有完整的操作感。

## 1 球内/球外的位势解

**基本构件**：拉普拉斯方程在球坐标分离变量后，轴对称解为

$$
u(r,\theta) = \sum_{n=0}^{\infty}\big(A_n r^n + B_n r^{-(n+1)}\big)P_n(\cos\theta)
$$

- **球内解**（$r < R$，原点有限）：$B_n = 0$，$u = \sum A_n r^nP_n(\cos\theta)$；
- **球外解**（$r > R$，无穷远零）：$A_n = 0$，$u = \sum B_n r^{-(n+1)}P_n(\cos\theta)$。

**径向因子 $r^n$（增长）与 $r^{-(n+1)}$（衰减）是球坐标下 Euler 方程的两支**——内解要 $r^n$（原点有限）、外解要 $r^{-(n+1)}$（无穷远归零）。<span class="marginnote">$r^{-(n+1)}$ 的物理身份：它是「$2^n$ 极子」的势——$n=0$ 项是点电荷 $1/r$、$n=1$ 项是偶极 $1/r^2$、$n=2$ 项是四极 $1/r^3$。<strong>球外的任何位势都按「多极级数」展开</strong>，这是「多极展开」理论的几何起点。</span>

## 2 例子一：球面边值按勒让德展开

**问题**：半径为 $R$ 的球面给定轴对称位势 $u(R,\theta) = f(\theta)$，求球内位势。

**解**：设球内 $u = \sum A_nr^nP_n(\cos\theta)$，在 $r = R$ 处

$$
f(\theta) = \sum_{n=0}^{\infty}A_nR^nP_n(\cos\theta)
$$

**公式解析：定系数**

- **第一步，换元 $x = \cos\theta$。** $f$ 视为 $x$ 的函数 $F(x) = f(\arccos x)$，展开为 $F(x) = \sum A_nR^nP_n(x)$。
- **第二步，勒让德系数。** $A_nR^n = \frac{2n+1}{2}\int_{-1}^1F(x)P_n(x)dx$，即
  $$ A_n = \frac{2n+1}{2R^n}\int_0^\pi f(\theta)P_n(\cos\theta)\sin\theta\,d\theta $$
- **第三步，写解。** $u(r,\theta) = \sum A_nr^nP_n(\cos\theta)$。
- **第四步，物理朗读。** 边界值 $f$ 被拆成各阶「多极分量」，每一阶在球内按 $r^n$ 增长向内传播——低阶（$n$ 小）分量在球心附近占主导。

**特例**：$f(\theta) = \cos\theta = P_1(\cos\theta)$，则 $u = \frac{r}{R}\cos\theta$——偶极型位势（均匀场穿球）。

## 3 例子二：两半球不同电位（球电容器）

**问题**：球面分两半球，$u(R,\theta) = \begin{cases} V, & 0 \le \theta < \frac{\pi}{2} \\ -V, & \frac{\pi}{2} < \theta \le \pi\end{cases}$（上极板 $+V$、下极板 $-V$），求球内位势。

**解**：这是「阶梯边界」——不光滑，需全部阶展开。$f(\theta)$ 关于 $\theta \to \pi - \theta$ 反对称（$f(\pi-\theta) = -f(\theta)$），故只有奇 $n$ 分量：

$$
A_n = \frac{2n+1}{2R^n}\Big[\int_0^{\pi/2}V P_n(\cos\theta)\sin\theta\,d\theta + \int_{\pi/2}^{\pi}(-V)P_n(\cos\theta)\sin\theta\,d\theta\Big]
$$

计算得（$n$ 奇）$A_n = \frac{2n+1}{2R^n}V\Big[\int_0^1P_n(x)dx - \int_{-1}^0P_n(x)dx\Big]$。

- **第一步，化简。** 奇 $n$ 的 $P_n$ 是奇函数，$\int_0^1P_n - \int_{-1}^0P_n = 2\int_0^1P_n$。
- **第二步，用积分公式。** 对奇 $n$，$\int_0^1P_n(x)dx = \frac{1}{2}\int_{-1}^1P_n = \frac{1}{2}\cdot\frac{2}{2n+1}\delta_{n0}$ 不适用——需直接用递推积分，得到有限值。
- **第三步，写解。** $u(r,\theta) = \sum_{n\text{ 奇}}A_nr^nP_n(\cos\theta)$——在球心附近由 $n=1$ 项主导，趋近「均匀场」；靠近球面，高阶项抬起/压低电位，形成 $+V/-V$ 的阶梯。

**这个「两半球电位差」问题在物理上对应球形电容器**——两半球的电容可由位势算出。它在数学上示范了「阶梯边值 → 全阶展开 → 逐项求和」的完整流程。<span class="marginnote">球心处只有 $n=1$ 项（$r=0$ 时高阶全为零），所以球心位势 $u(0) = 0$（对称性），球内电场在球心处是均匀的（$n=1$ 项贡献 $\sim r\cos\theta$）。「球心看球面阶梯，只看到偶极」——这正是多极展开的精神：远处看细节被压到最低阶。</span>

## 4 例子三：均匀场中的导体球

**问题**：均匀外场 $\boldsymbol{E}_0$（沿 $z$ 方向）中放置一个接地导体球（半径 $R$），求球外位势。

**解**：无穷远边界 $u \to -E_0z = -E_0r\cos\theta$（均匀场的位势），球面 $u(R,\theta) = 0$。设

$$
u = \sum\big(A_nr^n + B_nr^{-(n+1)}\big)P_n(\cos\theta)
$$

- **第一步，配无穷远。** 只有 $n=1$ 项能在 $r\to\infty$ 保持线性增长：$A_1 = -E_0$，其余 $A_n = 0$。
- **第二步，配球面。** $u(R) = -E_0R\cos\theta + B_1R^{-2}\cos\theta = 0$，故 $B_1 = E_0R^3$。
- **第三步，写解。**
  $$ u(r,\theta) = -E_0r\cos\theta + E_0\frac{R^3}{r^2}\cos\theta $$
- **第四步，物理图像。** 第二项是**偶极势** $\sim \frac{\cos\theta}{r^2}$——均匀场在导体球表面感应出「等效偶极矩」，球的响应 = 均匀场 + 偶极场。球面上的电荷分布 $\sigma = -\varepsilon_0\frac{\partial u}{\partial r}\big|_{r=R} = 3\varepsilon_0E_0\cos\theta$——**感应电荷按 $\cos\theta$ 分布**（面对电场的一侧正、背侧负）。

**辨析｜易错点：** 无穷远边界条件（$u \sim -E_0r\cos\theta$ 不趋于零）让 $A_1 \ne 0$——**不是所有问题都要求无穷远位势为零**。均匀场中的问题要保留增长项 $A_1r\cos\theta$，而「孤立电荷」问题才要求 $A_n = 0$。读边界条件时先判断「无穷远是零还是给定场」，再决定保留哪支径向解。

## 5 勒让德应用的完整图谱

三个例子覆盖了球体位势问题的主要类型：

| 问题 | 边界 | 解法 | 关键物理 |
| --- | --- | --- | --- |
| 球面给定位势 | $u(R,\theta) = f(\theta)$ | 勒让德展开 | 多极分解 |
| 两半球电位差 | 阶梯边值 | 全阶展开 | 球电容器 |
| 均匀场中导体球 | $u\to-E_0z$ + 球面零 | 保留 $n=1$ | 感应偶极 |

**共同的三步走**：写出一般解（$r^nP_n$ 与 $r^{-(n+1)}P_n$ 的组合）→ 用边界条件（球面、无穷远）定系数 → 读出多极物理。这套「球坐标流水线」与矩形、圆柱的对应流程完全平行，只是本征函数换成了勒让德/球谐。<span class="marginnote">从本专题的方法论看，特殊函数（贝塞尔、勒让德）并不是孤立的「数学杂项」，而是「区域对称性 → 本征函数」的完整目录：矩形给三角函数、圆柱给贝塞尔、球给勒让德。第八篇到此收官，读者应能一眼认出「这个几何 → 该用哪族函数」。</span>

## 6 小结

- 球坐标轴对称解：$u = \sum(A_nr^n + B_nr^{-(n+1)})P_n(\cos\theta)$。
- 球面边值按勒让德展开定系数：$A_n = \frac{2n+1}{2R^n}\int fP_n\sin\theta d\theta$。
- 两半球电位差问题示范全阶展开（阶梯边值）与球电容器。
- 均匀场中导体球：$u = -E_0r\cos\theta + E_0R^3\cos\theta/r^2$，感应电荷 $\sim\cos\theta$。
- 「边界条件 → 保留哪些径向支 → 多极物理」是球坐标问题的标准三步。
