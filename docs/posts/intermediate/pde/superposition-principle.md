## 为什么从叠加原理开始

线性是数学送给物理最昂贵的礼物。上一节我们看到，适定性能不能保住，取决于解对数据的依赖是否连续；这一节我们拆解线性送来的第二件礼物——**叠加原理（superposition principle）**。一句话：**线性齐次方程的两个解相加，还是方程的解。** 这句近乎废话的话，却把「解方程」变成了「拼乐高」：复杂的振动是一堆简单振动的叠加，复杂的热分布是一堆简单热源的叠加，复杂的场是一堆点源的叠加。<span class="marginnote">莱布尼茨那句关于音乐的名言放在这里再贴切不过：一支交响乐之所以能被「拆成」一个个音符、一件件乐器的声部再重新拼合，正是因为它近似满足线性叠加——声波满足线性波动方程，多个声源同时发声时，各声场的位移直接相加。</span>

分离变量法、Fourier 级数、Green 函数、Duhamel 原理——后面几乎所有的求解方法，本质上都是叠加原理在不同层面的化身。这一节先把这块地基夯实。

## 1 线性算符：叠加原理的语法

把方程的「左边」抽象成一个算符。以波动方程为例，写

$$
Lu = 0, \qquad L := \frac{\partial^2}{\partial t^2} - c^2\frac{\partial^2}{\partial x^2}
$$

$L$ 把一个函数 $u$ 映到另一个函数 $Lu$。**线性算符（linear operator）**：满足两条性质的算符——可加性 $L(u+v) = Lu + Lv$ 与齐次性 $L(\lambda u) = \lambda Lu$（$\lambda$ 为常数）。这与第一级《线性代数》里的矩阵完全同构：矩阵对向量可加、可伸缩，线性算符对函数同样可加、可伸缩。<span class="marginnote">线性代数的「线性」指向量空间的运算，偏微分方程里的「线性」指方程对未知函数及其各阶导数做线性组合。两者本质是同一个概念：算符 $L$ 相当于作用在无穷维函数空间上的一个「矩阵」。</span>

为什么导数算符是线性的？因为导数本身的定义是线性极限：

$$
(u+v)_x = u_x + v_x, \qquad (\lambda u)_x = \lambda\, u_x
$$

可加性、齐次性一一代入，于是**任何「未知函数及其各阶导数的线性组合」构成的方程，只要组合系数不依赖 $u$ 本身，就是线性方程，就必然满足叠加原理**。由此得到叠加原理的标准陈述：

**叠加原理（superposition principle）**：若 $L$ 是线性算符，$u_1, u_2$ 都是齐次方程 $Lu = 0$ 的解，则它们的任意线性组合 $u = \alpha_1 u_1 + \alpha_2 u_2$ 仍是 $Lu = 0$ 的解。

## 2 叠加原理的四个层次

叠加原理不止「两个解相加」这一个形态。按「叠多少次、用什么方式叠」，它层层展开：

- **有限叠加**：$u = u_1 + u_2$。两列波相遇后穿过彼此、各自继续传播，互不干扰——这就是日常生活中「两拨人各自说话都能听清」的声学基础。
- **无穷级数叠加**：$u = \sum_{n=1}^{\infty} c_n u_n(t)$。把一个解展开成无穷多个「模式」（如正弦驻波）的和。分离变量法的产物——Fourier 级数——正是这一层。
- **连续叠加（积分叠加）**：$u(x) = \int G(x, \xi)\, f(\xi)\, d\xi$。把「点源产生的效应」当作被积函数积分起来。Green 函数方法属于这一层。
- **非齐次方程的分解**：$Lu = f$ 的通解 = 特解 + 齐次方程 $Lu = 0$ 的通解。把「外力驱动」与「自由振动」分开处理。

这四层不是并列的四个技巧，而是同一个原理在不同尺度的呈现：**有限 → 无穷级数 → 积分**，是把「拆解」推向极致的三步；最后一步则把「齐次」放松到「非齐次」。

## 3 公式解析：为什么线性齐次方程的解可以叠加

空口无凭，我们把「两个解之和仍是解」完整地走一遍验证。设 $u_1, u_2$ 都满足 $Lu = 0$，$L$ 是线性算符，要证 $u = u_1 + u_2$ 满足 $Lu = 0$。

- **第一步，对和施加算符，用可加性展开**。

$$
L(u_1 + u_2) = Lu_1 + Lu_2
$$

这一步没有任何假设，纯粹是线性算符的定义。

- **第二步，代入已知条件**。因为 $u_1, u_2$ 各自满足 $Lu_1 = 0,\ Lu_2 = 0$，于是

$$
L(u_1 + u_2) = 0 + 0 = 0
$$

- **第三步，对任意常系数线性组合 $\alpha_1 u_1 + \alpha_2 u_2$ 同理**。先提公因数再用可加性：

$$
L(\alpha_1 u_1 + \alpha_2 u_2)
= L(\alpha_1 u_1) + L(\alpha_2 u_2)
= \alpha_1 Lu_1 + \alpha_2 Lu_2
= 0
$$

第二步用到齐次性，第三步代回 $Lu_i = 0$。**证毕。**

对非齐次方程 $Lu = f$，叠加原理退化为如下「位移版」：若 $u_p$ 是 $Lu = f$ 的一个特解，而 $v$ 是齐次方程 $Lu = 0$ 的通解，则 $u_p + v$ 遍历 $Lu = f$ 的全部解。验证只多一步：

$$
L(u_p + v) = Lu_p + Lv = f + 0 = f
$$

**这一条是后面所有「先求特解、再补齐次通解」算法的总依据**，也是线性代数里「非齐次线性方程组 $Ax = b$ 的通解 = 特解 + 齐次解 $Ax = 0$ 的通解」在无穷维世界的孪生兄弟。<span class="marginnote">如果你在《线性代数》里学过「解空间」「基础解系」，这里完全是一一对应：齐次方程的解集构成一个线性空间（解空间），非齐次方程的解集是这个空间沿任意特解的「平移」。把常数矩阵换成微分算符，词语全部照搬。</span>

## 4 叠加原理的三个重大应用

叠加原理的价值不在证明本身，而在它撑起了三大方法论。

**分离变量法**。这是叠加原理最著名的应用。对线性齐次的初边值问题，先假定解可以「分离」成 $u(x,t) = X(x)T(t)$ 的形式代入方程，得到两个常微分方程；找出满足边界条件的一串「本征模式」$X_n(x)$；再由叠加原理把它们线性组合 $u = \sum_n c_n X_n(x) T_n(t)$，最后用初始条件定系数 $c_n$。<span class="marginnote">注意这个套路的两步都在用叠加原理：第 1 步「模式相加仍是解」用叠加原理，第 2 步「用初始条件定系数」本质上是在解空间里做线性拟合。有界弦振动、有界杆热传导，全靠这一招。</span>

**Duhamel 原理（齐次化原理）**。非齐次方程 $u_t = a^2 u_{xx} + f(x,t)$ 的求解，可以转化为一串「每个时刻释放一个冲击」的齐次问题，再把它们连续叠加（积分）起来。这个「把持续驱动拆成无穷多个瞬时冲击，再积分叠加」的思路，正是叠加原理在时间方向的展开。

**Green 函数方法**。把点源响应 $G(x,\xi)$ 作为基本积木，任意分布源 $f$ 产生的场就是 $u(x) = \int G(x,\xi)f(\xi)\,d\xi$——连续叠加原理的典型形态。它与杜哈梅原理合在一起，构成「先解点源问题，再积分」的通用反手。

这三者将在《波动方程》《热传导方程》与《拉普拉斯方程》各篇中反复登场。此刻只需牢牢记住它们共享的骨架：**找一个线性齐次的方程，找出一组基本解，叠加它们，用定解条件定系数。**

## 5 辨析｜易错点

**辨析｜易错点：** 叠加原理看似简单，用错的地方却不少：

- **易错 1：对非线性方程照搬叠加。** 若方程含 $u^2$、$uu_x$ 这类乘积项（如 KdV 方程 $u_t + 6uu_x + u_{xxx} = 0$），$L(u_1 + u_2) \neq Lu_1 + Lu_2$，两个解相加不再是解。判断一句口诀：**看方程里有没有「$u$ 与 $u$（或其导数）相乘」**，有则非线性、叠加失效。
- **易错 2：对非齐次方程叠加两个非齐次解。** 若 $Lu_1 = f,\ Lu_2 = f$，则 $L(u_1 + u_2) = 2f \neq f$。正确的组合是**特解加齐次解**，或「两个非齐次解之差是齐次解」：$L(u_1 - u_2) = f - f = 0$。
- **易错 3：把「叠加原理」与「线性方程」脱钩。** 叠加原理是线性方程的**特征**，不是独立于方程之外的额外假设。判断方程是否线性（系数是否依赖 $u$ 或其导数），是使用叠加原理的前提。
- **辨析：叠加原理与「本征展开」的关系。** 分离变量法里出现的本征函数族 $X_n$ 是线性算符的特征向量，特征值、特征函数这些词与《线性代数》的「特征值」一脉相承——它们在《泛函分析》里被系统化为「谱理论」。

## 6 小结

- **叠加原理**：线性齐次方程 $Lu = 0$ 的解的线性组合仍是解；验证只需可加性 + 齐次性两步。
- **线性算符**的判据：$L(u+v) = Lu + Lv$，$L(\lambda u) = \lambda Lu$；只要方程是未知函数及其导数的线性组合、系数不依赖 $u$，就线性、就叠加。
- **非齐次方程**的通解 = **特解 + 齐次方程通解**；两个非齐次解之差必为齐次解。
- 叠加原理的四个层次：**有限叠加 → 无穷级数叠加 → 积分叠加 → 非齐次分解**。
- 三大应用：**分离变量法**、**Duhamel 原理（齐次化）**、**Green 函数方法**，共享同一个骨架：找基本解、叠加、定系数。

在下一节，我们将离开具体方程，进入一般的二阶线性方程理论——先看它的**一般形式与特征方程**，这是给所有方程「分型定类」的第一块基石。
