# 极值原理（最大值原理）

<div class="epigraph">

## 为什么从极值原理开始

分离变量法、泊松公式给出了热方程的解，但都依赖「算得出来」。极值原理是另一类武器：**它不求解，却给出解的根本约束**——温度场的最大值与最小值，只会出现在「初始时刻」或「空间边界」上。这个看起来像常识的命题，威力巨大：它能证明唯一性、稳定性（下一节），能验证数值解的合理性，甚至不需要解的具体公式。它是抛物型方程理论与椭圆型极值原理（第六篇）并行的支柱。

## 1 抛物边界与极值原理的表述

考虑热方程在有界杆上的初边值问题，区域是时空圆柱

$$
Q_T = \{(x,t): 0 < x < L,\ 0 < t \le T\}
$$

**抛物边界（parabolic boundary）**$\Gamma_T$ 定义为 $Q_T$ 的「底」与「侧壁」：

$$
\Gamma_T = \{(x,0): 0 \le x \le L\} \cup \{(0,t),(L,t): 0 \le t \le T\}
$$

**极值原理（最大值原理）**：若 $u$ 在 $\bar Q_T$ 上连续、在 $Q_T$ 内满足 $u_t = a^2 u_{xx}$，则 $u$ 在 $\bar Q_T$ 上的最大值与最小值都在抛物边界 $\Gamma_T$ 上取得：

$$
\max_{\bar Q_T} u = \max_{\Gamma_T} u, \qquad \min_{\bar Q_T} u = \min_{\Gamma_T} u
$$

<span class="marginnote">对比椭圆型（拉普拉斯）的极值原理：那里极值在<strong>全部边界</strong>上取得；这里只在「底 + 侧壁」即抛物边界上取得——因为时间方向 $t=T$ 这一「顶盖」不在其中。温度的最高点可以出现在最后时刻 $t=T$ 的<strong>空间内部</strong>，但它的值已经被初始时刻或两端边界「预支」了。</span>

**物理直觉：温度不会创造新高。** 若某时刻内部某点温度超过了一切初始温度和边界温度，热量就该从哪里来？只能从邻近高温处流入——可邻近处的温度也超不过这个新高，矛盾。极值原理就是把这条热力学直觉写成严格定理。

## 2 最大值原理的证明思想

证明的核心是用**反证法 + 热方程的局部结构**。为证明最大值在边界，设 $u$ 在内部点 $(x_0, t_0)$（$0 < x_0 < L$，$0 < t_0 \le T$）达到最大值 $M$，且 $M$ 大于边界上的最大值：

**第一步，构造辅助函数。** 令 $v = u + \varepsilon x^2$（$\varepsilon > 0$ 很小）。$v$ 的最大值点与 $u$ 接近，但 $v$ 的「凸性」被增强，便于套用方程。
**第二步，在 $v$ 的最大值点分析。** 若 $v$ 在内部点达到最大，则该点处 $v_t \ge 0$（若 $t_0<T$，取 $t_0$ 为最大时刻，$v_t$ 非负）、$v_{xx} \le 0$（空间最大值处二阶导非正）。
**第三步，构造矛盾。** 由 $v_{xx} = u_{xx} + 2\varepsilon \ge 2\varepsilon > 0$，与 $v_{xx} \le 0$ 矛盾。故 $v$ 不能在内部达到超过边界的最大值。
**第四步，$\varepsilon \to 0$。** 让辅助项的凸性收缩到零，$u$ 的最大值也只能在边界。

<span class="marginnote">这一步的精髓是「加一个严格凸的干扰项 $\varepsilon x^2$」：它在最大值点强制 $v_{xx} > 0$，直接撞上热方程要求（内部最大处 $u_{xx} \le 0$）。「辅助函数 + 反证」是极值原理证明的标准套路，第六篇椭圆型的证明会再次使用。</span>

## 3 公式解析：为什么是「抛物边界」而非「全部边界」

关键在热方程 $u_t = a^2 u_{xx}$ 的结构。在内部最大值点 $(x_0,t_0)$：

**空间方向**：最大值处 $u_{xx}(x_0,t_0) \le 0$（二阶导非正）；
**时间方向**：若 $0 < t_0 < T$，则 $u_t(x_0,t_0) = 0$（内部极值）；若 $t_0 = T$，则 $u_t(x_0,T) \ge 0$（最后时刻可以还在上升）。

把这两条代入方程 $u_t = a^2 u_{xx}$：左端 $u_t \ge 0$，右端 $a^2 u_{xx} \le 0$，只能同时为零——**除非 $u$ 是常数，否则不可能在内部达到严格最大值**。推导的每一步：

**第一步，写局部条件。** 内部最大处 $u_t \ge 0$、$u_{xx} \le 0$。
**第二步，代入方程。** $0 \le u_t = a^2 u_{xx} \le 0$，被迫 $u_t = u_{xx} = 0$。
**第三步，排除非平凡情形。** 若最大值 $M$ 严格大于边界值，则内部最大值点处的局部条件与方程冲突，矛盾。
**第四步，结论。** 最大值只能在抛物边界。顶盖 $t=T$ 不被排除，是因为那里 $u_t$ 可以取正——所以「底 + 侧壁」而非「全边界」。

**时间一阶导数让「顶盖」格外宽大：最后时刻的内部温度可以是新的最大值，但它必须小于等于此前边界上已出现的温度。** 这是抛物型极值原理与椭圆型的唯一区别，也是「热方程不解出新极值」的精确定量。

## 4 极值原理的直接推论

极值原理一出手，就是一连串重要结论：

1. **比较原理**：若 $u_1 \le u_2$ 在抛物边界 $\Gamma_T$ 上成立，则在整个 $\bar Q_T$ 上 $u_1 \le u_2$。取差 $w = u_1 - u_2$ 用极值原理即得。
2. **有界性**：解被边界值夹住：$\min_{\Gamma_T}u \le u(x,t) \le \max_{\Gamma_T}u$——**温度永远在初始与边界温度之间**。
3. **正性保持**：初值非负则解非负（令 $u_2 = 0$）。
4. **无新极值**：解的局部最大值不会随时间被「造」出来，只会衰减。

**辨析｜易错点：** 极值原理要求 $u$ 在闭区域上**连续**、方程在内部**逐点**成立。若初值有间断（这是常见物理情形），需先等 $t>0$ 磨平再谈极值，或者用极限逼近——初值间断瞬间的「最大值」可能超过抛物边界值，但那是广义解的极限，不违背极值原理。另外，极值原理对**有界区域**是经典结论；对无界区域（柯西问题）需要额外的增长条件（见《柯西问题解的唯一性》一节）。

## 5 极值原理与数值验证

极值原理在数值计算中有实用价值：**一个合格的热方程数值格式，必须保持「无新极值」这个物理约束。** 显式差分格式若时间步长太大（违反 CFL 型条件），温度会在某些格点超过初始最大值——数值振荡，立刻被极值原理识破。检查数值解是否「超界」，是验证格式稳定性的第一道廉价测试。<span class="marginnote">极值原理因此是「物理直觉 → 数学定理 → 数值检验」的完美链路。第四级《数值分析》中，热方程的隐式格式「无条件稳定」的说法，本质上就是离散极值原理成立；而显式格式的条件稳定，就是离散极值原理时好时坏的数学投影。</span>

## 6 数值算例：用极值原理验证解

取 $\Omega = (0,\pi)$，$u_t = u_{xx}$，初值 $\varphi(x) = \sin x$，边界 $u(0,t) = u(\pi,t) = 0$。分离变量给出显式解 $u(x,t) = e^{-t}\sin x$，用极值原理核对：

- **第一步，算抛物边界值。** 底边 $t=0$ 上 $u = \sin x \le 1$；侧壁 $x=0,\pi$ 上 $u = 0$。
- **第二步，读最大值。** 最大值 1 恰在初始时刻 $(x=\pi/2,\ t=0)$ 取得；内部任意时刻 $u \le e^{-t} < 1$——**没有新极值被造出**。
- **第三步，读最小值。** 最小值 0 在侧壁 $x = 0,\pi$ 取得，内部恒正。
- **第四步，对数值格式设卡。** 若某个格点算出的温度 $u > 1$ 或 $u < 0$，极值原理立刻识破——「不超界」是硬标准。

**数值格式的第一道检验。** 对任意数值解，先查「是否落在 $[\min_\Gamma u,\ \max_\Gamma u]$ 内」，这是最廉价的正确性测试：越界意味着要么步长太大、要么格式不保单调。

## 7 极值原理的不等式形式与无界区域

**广义极值原理（有源情形）**：对 $u_t - a^2u_{xx} = f \le 0$（无热源），结论不变（最大值在抛物边界）。若 $f$ 变号，极值原理退化为不等式形式：

$$
\max_{\bar Q_T}u \le \max_{\Gamma_T}u + C\max_{\bar Q_T}|f|
$$

右端多出「源项量级 × 常数」——源越强，内部温度越可能超过边界值，但超出的量被源的大小控制。这是「源参与极值判定」的定量版本。

**无界区域的极值原理（柯西问题）**：经典极值原理要求区域有界。对整条直线 $-\infty < x < \infty$，需要补充增长条件（如 $u$ 不增长快于 $e^{Cx^2}$），才能保证「无穷远处不捣乱」——这正是后面《柯西问题解的唯一性》里 Tychonoff 反例的伏笔：没有增长条件，热方程的解可以有无穷多个。

把三类情形的极值原理收进一张表：

| 情形 | 极值原理 | 前提 |
| --- | --- | --- |
| 有界杆 | 极值在抛物边界 | 区域有界、$u$ 连续 |
| 无界直线 | 需增长条件 | 增长不超 $e^{Cx^2}$ |
| 有源 $f \le 0$ | 极值仍可在抛物边界 | 无热源 |
| 有源 $f$ 变号 | 不等式形式 | $\max u \le \max u_\Gamma + C\max\|f\|$ |

**从「从极限到大模型」的视角**，极值原理是「解不会创造信息」的数学表达：温度场的极值早已写在初始与边界数据里，演化只是「搬运」与「摊平」。这与深度学习里「输出不会超过训练分布的极端」同构——约束决定了可能性的边界。

## 8 小结

- 抛物边界 = 底边 $t=0$ + 侧壁 $x=$ 边界，不含顶盖 $t=T$。
- 极值原理：热方程解的最大最小值都在抛物边界上取得。
- 证明用辅助函数 $u+\varepsilon x^2$ + 反证，核心是「内部最大处 $u_t\ge0$、$u_{xx}\le0$」与方程冲突。
- 推论：比较原理、有界性、正性保持、无新极值。
- 极值原理为数值格式提供「不超界」的检验标准。
