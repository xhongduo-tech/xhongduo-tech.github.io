## 为什么从试探法开始

格林函数、泊松公式、镜像法都是「闭式装配」，但很多边值问题的数据结构简单——边界值恰好是某个低次多项式、某个 $\cos n\theta$、某个常数的源——这时**试探法**最直接：猜一个形状正确的候选解，用唯一性定理保证「猜对了就是答案」。这不是碰运气，而是有系统的艺术：**利用区域对称性与数据结构，选择「够格」的候选族，让边界条件确定参数**。这一节用几个经典例子把试探法讲成可操作的方法论。

## 1 试探法的两条原则

试探法成立依赖两条支柱：

1. **唯一性**：Dirichlet/Neumann 问题至多一个解（加常数对 Neumann）。只要候选解满足所有条件，它就是解——无需怀疑。
2. **候选族的正确性**：候选解的「形状」必须与数据结构匹配，否则永远凑不上。

**试探法的选择准则：**

- 边界值是**低次多项式** → 猜调和多项式（把多项式按调和部分分解）；
- 边界值是**单个角模** $\cos n\theta$ 或 $\sin n\theta$ → 猜 $r^n\cos n\theta$ 形式的调和函数；
- 源是**常数**且边界对称 → 猜关于 $r$ 的二次函数 $A r^2 + B$。

<span class="marginnote">「试探」不是瞎猜：候选族要<strong>自动满足方程</strong>，只剩边界待定。所以试探法的第一步永远是「写一族满足方程的参数化函数」，第二步才是「用边界定参数」。这两步的顺序不能反——先满足方程，再配边界。</span>

## 2 例子一：球上的多项式边界值

**问题**：求球 $|x| \le R$ 上的调和函数，边界 $u|_{|x|=R} = x_1 x_2$。

**试探**：$x_1 x_2$ 是调和多项式（$u_{x_1x_1} = u_{x_2x_2} = 0$，$u_{x_3x_3} = 0$）。猜 $u = c\,x_1x_2$：

**验证调和**：$\Delta(x_1x_2) = 0$ ✓；
**配边界**：$u|_{|x|=R} = c\,x_1x_2$，要等于 $x_1x_2$，取 $c = 1$；
**结论**：$u = x_1x_2$（在整个球内，不是只在边界）。

**关键洞察：调和多项式是「在边界上的值可以自由指定、在内部自动延伸」的函数。** 边界数据若是调和多项式，解就是它本身——零工作量的极端情形。

**更一般**：边界数据若是**一般多项式**，把它分解成「调和部分 + 非调和部分」，调和部分直接是解，非调和部分用「对 $r$ 的幂次修正」吸收。例如 $u|_{|x|=R} = x_1^2$：$x_1^2 = \frac{r^2}{3} + (x_1^2 - \frac{r^2}{3})$，其中第二项调和（$x_1^2 - x_2^2/2 - x_3^2/2$ 类）。猜 $u = A r^2 + B(x_1^2 - \frac{r^2}{3})$，边界定 $A, B$。

## 3 公式解析：圆盘上的角模试探

**问题**：求单位圆盘上的调和函数，边界 $u|_{r=1} = \cos 2\theta$。

**试探**：猜 $u = r^2\cos 2\theta$。

**第一步，写角模的调和函数族。** 极坐标下，$r^n\cos n\theta$ 与 $r^n\sin n\theta$ 都调和（它们对应复变量 $z^n$ 的实部与虚部）。对 $n=2$：$u = r^2\cos 2\theta$ 调和。
**第二步，配边界。** 在 $r = 1$：$u = \cos 2\theta$ ✓ 精确匹配。
**第三步，唯一性收口。** 单位圆盘 Dirichlet 问题解唯一，$u = r^2\cos 2\theta$ 就是答案。
**第四步，翻译回直角坐标。** $r^2\cos 2\theta = r^2(\cos^2\theta - \sin^2\theta) = x^2 - y^2$——正是上一节见过的调和多项式。角模试探与多项式试探在这里握手。

**角模试探的通用步骤：边界是 $\cos n\theta$（或 $\sin n\theta$）→ 猜 $r^n\cos n\theta$ → 边界匹配 → 唯一性收口。** 这个模式本质上是分离变量法的「单模特解」版本：边界数据只含一个角模，解就只含对应模，无需叠加。<span class="marginnote">若边界值是多个角模的叠加（如 $\cos\theta + 2\cos 2\theta$），用线性叠加：解 = 各模解之和。试探法对「单模」最省力，对「多模」退化为「先展开再逐模试探」——本质上又回到了分离变量法。试探法、分离变量法、泊松公式是同一枚硬币的三面。</span>

## 4 例子二：常源泊松方程的球对称试探

**问题**：求 $u$ 使 $\Delta u = -1$（常源）在球 $|x| < R$ 内、$u|_{|x|=R} = 0$。

**试探**：常数源 + 球对称 → 猜 $u = A(R^2 - r^2)$。

**验证方程**：$\Delta(R^2 - r^2) = \Delta R^2 - \Delta r^2 = 0 - 6 = -6$（三维），故 $\Delta[A(R^2 - r^2)] = -6A$，要等于 $-1$，取 $A = 1/6$。
**验证边界**：$r = R$ 时 $u = 0$ ✓。
**结论**：$u = \frac{R^2 - r^2}{6}$。

**这个解就是球内均匀热源的稳态温度**（中心最高、边界为零）。试探法把常源泊松问题化成一个「猜 $r$ 的二次函数」的代数题——比格林函数积分快得多。<span class="marginnote">注意 $R^2 - r^2$ 的系数随维数变化：$n$ 维下 $\Delta r^2 = 2n$，故 $u = \frac{R^2 - r^2}{2n}$。试探法的候选族「$\Delta$ 作用后是常数」的函数，恰好是 $r^2$ 的线性组合——这个「把拉普拉斯作用后归为常数」的思路可推广到更一般的源。</span>

## 5 试探法的边界与适用性

**辨析｜易错点：** 试探法的「边界数据简单」是硬前提。若边界数据是任意函数（不落在候选族内），试探必然失败——此时要回到分离变量（级数展开）、泊松公式（积分）或格林函数。另外，**试探解必须验证方程 + 边界 + 光滑性全部条件**，只验证边界不算完：有些「候选」满足边界却在区域内有奇点或违反方程，唯一性定理只对「真正的解」生效。

| 数据结构 | 候选族 | 区域 |
| --- | --- | --- |
| 多项式边界 | 调和多项式 + $r$ 幂修正 | 球、圆盘 |
| 单个角模 $\cos n\theta$ | $r^n\cos n\theta$ | 圆盘 |
| 常源 + 对称边界 | $A(R^2 - r^2)$ | 球、柱 |
| 分离的边界数据 $g_1(x)g_2(y)$ | 分离变量 $X(x)Y(y)$ | 矩形 |

**试探法的价值不在「省力」而在「洞察」：** 它逼你先想清「数据结构的对称性如何决定解的形状」。这个思维训练，是理解分离变量、特殊函数、变分方法的基础——候选族的每一次「猜」，都是对「解空间的形状」的一次感知。<span class="marginnote">从本专题的方法论看，试探法、分离变量法、格林函数、镜像法是一套「用结构换解」的家族：试探法用数据结构、分离变量用区域结构、镜像法用几何对称、格林函数用点源叠加。第六篇到此收官，读者应已能在这四种武器间自如切换。</span>

## 6 例子三：矩形的可分离边界试探

边界数据可以分离成 $g_1(x)g_2(y)$ 时，试探解也用分离的形式。取矩形 $0<x<a$、$0<y<b$，$u = 0$ 在三边，$u(x,b) = \sin\frac{\pi x}{a}$：

**试探**：猜 $u = X(x)Y(y)$。分离变量给出 $X''/X = -Y''/Y = -\lambda$。边界 $X(0)=X(a)=0$ 给 $X = \sin\frac{\pi x}{a}$、$\lambda = \pi^2/a^2$；$Y'' = \frac{\pi^2}{a^2}Y$、$Y(0)=0$ 给 $Y = \sinh\frac{\pi y}{a}$。于是

$$
u(x,y) = c\,\sin\frac{\pi x}{a}\,\sinh\frac{\pi y}{a}
$$

上边界 $u(x,b) = \sin(\pi x/a)$ 定 $c = 1/\sinh(\pi b/a)$。

**试探法在矩形上与分离变量法完全重合**——因为「分离数据 → 分离解」正是分离变量的第一原理。这里的洞察：**数据可分离，解就可分离**；数据不可分离（如 $x+y$），分离试探立即失败，说明问题需要级数。<span class="marginnote">矩形的分离试探依赖「数据只含单模」：上边界 $\sin(\pi x/a)$ 只有 $x$ 的基模，解自然只含单模。若上边界是 $\sin(\pi x/a) + \sin(2\pi x/a)$，试探解就要两项叠加——这时试探法退化为「先展开、再逐模试探」，分离变量法的级数框架才更顺手。</span>

## 7 试探法的局限与变分观

把试探法放在更大的方法谱系里定位：

- **试探法 vs 级数**：试探法一次猜出整个解，级数方法把解拆成无穷项逐项定系数。数据结构「简单到只有一项」时试探省事，「复杂」时级数是唯一出路。
- **试探法 vs 变分**：变分方法（第十篇 Ritz / Galerkin）是试探法的「机械版」——不再靠人猜形状，而是把解限制在一个有限维试函数空间，用「能量最小 / 残差正交」自动定系数。**试探法是人类版的 Ritz 方法**：人猜对的形状，Ritz 用线性组合逼近。

**辨析｜易错点：** 试探解「看起来满足边界」还不够。有些候选在边界上逐点正确、却在区域内有未检验的奇点或违反方程的点（如基本解型函数在内部某点发散）。**唯一性定理只对「真正的解」生效**——验证必须覆盖「方程 + 边界 + 正则性」三件事，缺一不可。

**从「从极限到大模型」的视角**，试探法的「候选族 + 边界定参」正是「先验 + 数据拟合」的原型：候选族是模型的先验结构（架构），边界数据是观测，定参是训练。数学里试探法的成败取决于「候选族选得多准」，机器学习里模型的成败同样取决于「归纳偏置选得多准」——这个类比贯穿整个方法论的灵魂。

## 8 小结

- 试探法 = 猜「满足方程的候选族」+ 用边界定参数 + 唯一性收口。
- 调和多项式是「边界可自由指定、内部自动延伸」的天然候选。
- 角模边界 $\cos n\theta$ → 猜 $r^n\cos n\theta$，本质是分离变量的单模版本。
- 常源 + 对称区域 → 猜 $r^2$ 的二次函数，系数由 $\Delta r^2 = 2n$ 确定。
- 试探法依赖边界数据简单；复杂数据需回到级数/积分/格林函数。
