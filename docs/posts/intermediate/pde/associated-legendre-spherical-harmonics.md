## 为什么从连带勒让德开始

勒让德多项式只管轴对称问题（$m=0$）。球面上的**一般**分布还依赖方位角 $\varphi$，对应的本征函数是**连带的勒让德函数** $P_n^m$ 与**球谐函数** $Y_{nm}$。球谐函数是「球面上的完备正交基」——地球重力场建模、原子轨道、天线方向图、宇宙微波背景分析，全都建立在它们之上。这一节建立 $P_n^m$ 与 $Y_{nm}$ 的定义、正交性与完备性，为下一节球体位势问题提供全套工具。

## 1 连带勒让德函数

**连带勒让德函数（associated Legendre function）**：对整数 $m$（$0 \le m \le n$），

$$
P_n^m(x) = (-1)^m\big(1 - x^2\big)^{m/2}\frac{d^m}{dx^m}P_n(x)
$$

它满足**连带勒让德方程**：

$$
(1-x^2)y'' - 2xy' + \Big[n(n+1) - \frac{m^2}{1-x^2}\Big]y = 0
$$

$m$ 就是球坐标分离变量时方位角的阶（$m=0$ 退化为勒让德多项式）。<span class="marginnote">因子 $(-1)^m$ 是 Condon–Shortley 相位约定，让 $m$ 与 $-m$ 的关系在角动量理论中干净。$P_n^m$ 不是多项式（除非 $m$ 偶），它含 $(1-x^2)^{m/2}$ 因子——因此本质上是「多项式乘 $(\sin\theta)^m$」的形式。</span>

**在 $\theta$ 语言下**：$P_n^m(\cos\theta) = (-1)^m(\sin\theta)^m\frac{d^m}{d(\cos\theta)^m}P_n(\cos\theta)$——$(\sin\theta)^m$ 因子在 $\theta \to 0, \pi$（两极）处给出零点，保证函数在两极有界。

**前几项**：$P_1^1 = -\sin\theta$（即 $-\sqrt{1-x^2}$）、$P_2^1 = -3\sin\theta\cos\theta$、$P_2^2 = 3\sin^2\theta$。

## 2 正交性与范数

连带勒让德函数对**固定 $m$** 满足正交性：

$$
\int_{-1}^{1}P_n^m(x)\,P_k^m(x)\,dx = \frac{2}{2n+1}\frac{(n+m)!}{(n-m)!}\,\delta_{nk}
$$

**范数平方** $\|P_n^m\|^2 = \frac{2}{2n+1}\frac{(n+m)!}{(n-m)!}$——比勒让德多了阶乘因子 $(n+m)!/(n-m)!$。<span class="marginnote">注意正交性要求<strong>同一个 $m$</strong>：$P_n^m$ 与 $P_k^{m'}$（$m \ne m'$）不正交——因为它们属于不同的 $m$ 子空间。球谐函数把「不同 $m$」也纳入正交（靠 $e^{im\varphi}$ 的傅里叶正交性），才凑成球面上的完备系。</span>

**连带勒让德方程也是 Sturm–Liouville 问题**，本征函数自动正交——与勒让德、贝塞尔同源。

## 3 球谐函数

**球谐函数（spherical harmonics）**：把 $P_n^m$ 与方位角因子合并，归一化

$$
Y_{nm}(\theta, \varphi) = \sqrt{\frac{2n+1}{4\pi}\frac{(n-m)!}{(n+m)!}}\,P_n^m(\cos\theta)\,e^{im\varphi}
$$

**完备规范正交系**：$Y_{nm}$（$n = 0,1,2,\dots$，$m = -n,\dots,n$）在单位球面上满足

$$
\iint_{\text{球面}}Y_{nm}\,\overline{Y_{n'm'}}\,\sin\theta\,d\theta\,d\varphi = \delta_{nn'}\delta_{mm'}
$$

**每个 $n$ 有 $2n+1$ 个球谐函数**（$m = -n,\dots,n$），对应拉普拉斯算子在球面上本征值 $-n(n+1)$ 的 $2n+1$ 重本征空间。<span class="marginnote">「$2n+1$ 重简并」是球对称的印记：旋转不改变本征值，同一 $n$ 的不同 $m$ 通过旋转互相转化。量子力学里角动量 $l$ 的 $2l+1$ 个磁量子数 $m$，正是这 $2n+1$ 重简并的物理化身——球谐函数是量子原子轨道的数学骨架。</span>

**前几个球谐函数**：$Y_{00} = \frac{1}{\sqrt{4\pi}}$、$Y_{10} = \sqrt{\frac{3}{4\pi}}\cos\theta$、$Y_{1\pm1} = \mp\sqrt{\frac{3}{8\pi}}\sin\theta e^{\pm i\varphi}$、$Y_{20} = \sqrt{\frac{5}{16\pi}}(3\cos^2\theta - 1)$。

## 4 公式解析：球面上的完备展开

任意球面上的函数（平方可积）按球谐展开：

$$
f(\theta,\varphi) = \sum_{n=0}^{\infty}\sum_{m=-n}^{n}c_{nm}Y_{nm}(\theta,\varphi), \qquad c_{nm} = \iint f\,\overline{Y_{nm}}\,\sin\theta\,d\theta\,d\varphi
$$

- **第一步，写系数。** $c_{nm}$ = $f$ 与 $Y_{nm}$ 的内积（带 $\sin\theta\,d\theta\,d\varphi$ 面积元）。
- **第二步，读结构。** 求和先按「阶 $n$」（角向分辨率）、再按「子阶 $m$」（方位角结构）展开——$n$ 越大，球面上的细节越多。
- **第三步，物理分层。** 地球重力场建模中：$n=2$ 项对应地球的扁率、$n=3$ 对应更细的不规则性——**每一阶 $n$ 描述一种「极型」的不均匀**。
- **第四步，加法定理。** 对固定 $n$，$m$ 求和有
  $$ \sum_{m=-n}^{n}\big|Y_{nm}(\theta,\varphi)\big|^2 = \frac{2n+1}{4\pi} $$
  即「同一阶的能量在球面上均匀分布」——旋转不变性的定量表达。

**加法定理的几何含义**：$P_n(\cos\gamma) = \frac{4\pi}{2n+1}\sum_m\overline{Y_{nm}}(\theta',\varphi')Y_{nm}(\theta,\varphi)$，其中 $\gamma$ 是两点间夹角——**勒让德多项式按夹角分解成各方位子阶之和**。这条公式在「点源势展开」「球面插值」中极其重要。

## 5 球谐函数的应用全景

球谐函数是「球面上的傅里叶基」，应用横跨物理与工程：

| 领域 | 用法 |
| --- | --- |
| 地球物理 | 重力场、地磁场按球谐展开（EGM96 模型） |
| 量子力学 | 原子轨道 $\psi_{nlm} = R_{nl}(r)Y_{lm}$ |
| 声学 | 空间声场分解、Ambisonics |
| 宇宙学 | CMB 温度涨落按 $Y_{lm}$ 展开，谱 $C_l$ |
| 计算机图形学 | 光照环境贴图（SH 光照） |
| 天文学 | 行星形状与引力场的球谐描述 |

**「球面 = 球谐基」是处理球面数据的默认选择**——正如「直线 = 傅里叶基」「圆周 = 傅里叶级数」。<span class="marginnote">从「从极限到大模型」的主线看，球谐函数是「对称性 → 自然基」的终极示例：球面旋转对称性决定了完备基只能是球谐，正如平移对称性决定了傅里叶基。现代机器学习中的「等变网络」（对旋转等变的神经网络）把球谐函数用作特征基底——同样的数学，从位势理论走进了深度学习。</span>

## 6 小结

- 连带勒让德 $P_n^m(x) = (-1)^m(1-x^2)^{m/2}\frac{d^m}{dx^m}P_n(x)$，满足连带勒让德方程。
- 固定 $m$ 的正交性带阶乘范数 $\frac{2}{2n+1}\frac{(n+m)!}{(n-m)!}$。
- 球谐 $Y_{nm} = \text{归一化}\cdot P_n^m(\cos\theta)e^{im\varphi}$，$n$ 对应 $2n+1$ 重简并。
- 球面展开 $f = \sum\sum c_{nm}Y_{nm}$，系数为面积元内积。
- 球谐是球面数据的完备基，应用覆盖地球物理、原子、声学、宇宙学与图形学。
