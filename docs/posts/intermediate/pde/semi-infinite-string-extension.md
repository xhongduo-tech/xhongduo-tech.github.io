## 为什么从半无界弦开始

达朗贝尔公式适用于整根无限弦。但真实的弦总有端点——琴弦的两端被琴桥固定。半无界弦（$x \ge 0$，一端在 $x=0$）是最简单的带边界模型，它的求解揭示了边界如何作用在波上：**反射**。这里的核心工具是延拓法：把半无界问题「镜像」成整根无限弦的问题，让镜像初值自动满足边界条件，然后直接用达朗贝尔公式。这个「镜像思想」在后面静电源像法（第六篇）中会以更华丽的方式再现。

## 1 半无界弦的两类端点

半无界弦 $0 \le x < +\infty$ 上的波动方程

$$
u_{tt} = a^2 u_{xx}, \qquad x > 0
$$

初值 $u(x,0) = \varphi(x)$、$u_t(x,0) = \psi(x)$（$x \ge 0$），在端点 $x = 0$ 处有两种典型约束：

- **固定端（Dirichlet）**：$u(0,t) = 0$，端点钉死不动。
- **自由端（Neumann）**：$u_x(0,t) = 0$，端点可上下滑动但无外力（弦在端点处水平）。

**两类端点对应不同的反射方式，而延拓法正是让「镜像」自动实现这两种反射。**

## 2 固定端：奇延拓

目标：把半无界问题变成全直线问题。做法是把初值**奇延拓**到 $x < 0$：

$$
\tilde\varphi(x) = \begin{cases} \varphi(x), & x \ge 0 \\ -\varphi(-x), & x < 0 \end{cases}, \qquad \tilde\psi(x) = \begin{cases} \psi(x), & x \ge 0 \\ -\psi(-x), & x < 0 \end{cases}
$$

延拓后的函数满足 $\tilde\varphi(-x) = -\tilde\varphi(x)$（奇函数），特别地 $\tilde\varphi(0) = 0$。<span class="marginnote">奇延拓的直觉：把 $x=0$ 当成一面镜子，镜外（$x<0$）的初值是镜内初值的「倒影 + 反号」。为什么反号？因为我们要让整根弦的解在 $x=0$ 处恒为零——奇函数在原点必为零，而波动方程的解由初值的奇偶性保持奇偶性。</span>

**关键引理：波动方程保持初值的奇偶性。** 若初值都是奇函数，则解 $u(x,t)$ 也关于 $x$ 奇：$u(-x,t) = -u(x,t)$，从而 $u(0,t) = 0$。对奇延拓的初值用达朗贝尔公式，得到的解限制回 $x \ge 0$，恰好是原问题的解。

**奇延拓 = 固定端反射，波在端点处相位反转。**

## 3 自由端：偶延拓

对自由端 $u_x(0,t) = 0$，改用**偶延拓**：

$$
\tilde\varphi(x) = \begin{cases} \varphi(x), & x \ge 0 \\ \varphi(-x), & x < 0 \end{cases}, \qquad \tilde\psi(x) = \begin{cases} \psi(x), & x \ge 0 \\ \psi(-x), & x < 0 \end{cases}
$$

偶延拓后初值是偶函数，解也保持偶性，故 $u_x(0,t) = 0$（偶函数在原点导数为零）。<span class="marginnote">为什么偶延拓给出自由端？对偶函数，$u_x(0,t) = \lim_{h\to 0}\frac{u(h,t) - u(-h,t)}{2h} = \lim_{h\to 0}\frac{u(h,t) - u(h,t)}{2h} = 0$。镜像对称保证端点处斜率恒为零，正是自由端的物理含义。</span>

**偶延拓 = 自由端反射，波在端点处原样返回、不倒相。**

## 4 公式解析：固定端反射的具体计算

看一个具体的半无界固定端问题：$u_{tt} = u_{xx}$，$u(x,0) = \varphi(x)$、$u_t(x,0) = 0$，$u(0,t) = 0$，其中 $\varphi(x) \ge 0$ 只在 $[0,1]$ 内非零（一个初始驼峰）。

- **第一步，奇延拓。** $\tilde\varphi$ 在 $x<0$ 上是 $-\varphi(-x)$——镜像反号。
- **第二步，套达朗贝尔公式（$a=1,\ \psi=0$）。** $u(x,t) = \frac{1}{2}[\tilde\varphi(x-t) + \tilde\varphi(x+t)]$。
- **第三步，追反射波。** 设观测点 $x>0$。当 $t < x$ 时，$x - t > 0$，两个宗量都在正半轴，$u = \frac{1}{2}[\varphi(x-t) + \varphi(x+t)]$——尚未受边界影响。当 $t > x$ 时，$x - t < 0$，$\tilde\varphi(x-t) = -\varphi(t-x)$，于是
  $$ u(x,t) = \frac{1}{2}\left[\varphi(x+t) - \varphi(t-x)\right] $$
- **第四步，读出反射。** 括号里第一项仍是「向右行、未反射」的部分，第二项 $-\varphi(t-x)$ 是一个**从边界返回、形状不变但反号**的驼峰——固定端把入射波颠倒送回。

**反射的物理解读：** 驼峰撞上固定端，返回时上下颠倒（相位反转 $\pi$）；若端点是自由端，返回时不颠倒。这个「反相/同相」的差别，正是驻波两端节点与波腹的根源，下一节有界弦的分离变量法会看到它的严格版本。

## 5 延拓法的适用边界

**辨析｜易错点：** 延拓法不是万能的。它只适用于**齐次边界条件**且**方程在 $x=0$ 处无外力和变系数**的情形。若边界非齐次（$u(0,t) = g(t)$）或端点处有集中力，镜像里要额外叠加源项；若方程系数在边界附近变化，镜像对称被破坏，延拓失效。此外，奇延拓后的初值在 $x=0$ 处可能不光滑（$\varphi(0) = 0$ 保证连续，但 $\tilde\varphi'$ 在 0 处可能跳变），导致解的导数沿特征线携带间断——这是「初值间断沿特征线传播」的又一例，与第九篇拟线性破碎、第四篇正则性传递一脉相承。

延拓法的真正价值在于：**它把「边界反射」这个看似新颖的现象，还原成了「无限弦上两列波叠加」的已知结果。** 这种「用已知问题求解未知问题」的策略，是数学物理方程方法的灵魂——延拓法（此处）、镜像法（第六篇）、Green 函数法（第九篇）都是它的不同化身。

## 6 小结

- 半无界弦问题用延拓法化为全直线问题：固定端奇延拓、自由端偶延拓。
- 波动方程保持初值奇偶性：奇初值 → 解奇，$u(0,t)=0$；偶初值 → 解偶，$u_x(0,t)=0$。
- 固定端反射使波相位反转，自由端反射不倒相。
- 反射波表现为延拓初值沿特征线的叠加，达朗贝尔公式直接可用。
- 延拓法限于齐次边界，非齐次边界需叠加源项处理。
