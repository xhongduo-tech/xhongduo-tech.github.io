# 一维波动方程的达朗贝尔（d'Alembert）公式

<div class="epigraph">
<p>任意形状的扰动，都分裂成两列相向而行的波。</p>

## 为什么从达朗贝尔公式开始

波动方程是双曲型的，而双曲型方程最漂亮的性质是：解沿特征线「传真」。一维弦振动问题可以**整体**解出来，得到一个闭式公式——达朗贝尔公式。它把任意初始位移与初始速度翻译成两列相向传播的波，一旦写出来，依赖区间、决定区域、Huygens 原理这些后续概念全都呼之欲出。这一节我们完成这个最重要的求解。

## 1 柯西问题的提法

考虑整根无限长弦（没有边界），给定初始位移与初始速度：

$$
u_{tt} = a^2 u_{xx}, \qquad -\infty < x < +\infty,\ t > 0
$$

$$
u(x, 0) = \varphi(x), \qquad u_t(x, 0) = \psi(x)
$$

这是波动方程的**柯西问题（初值问题）**。<span class="marginnote">为什么不加边界条件？无限长弦没有端点，信息从 $x \to \pm\infty$ 传来但永远到不了边界——只有初始条件参与。现实中「足够长且边界影响未到达」的弦，在有限时间内就可用这个模型。</span>

回想第二篇的结论：波动方程可分解为两个一阶传输算子

$$
\left(\partial_t - a\partial_x\right)\left(\partial_t + a\partial_x\right) u = 0
$$

这个因式分解是达朗贝尔公式的钥匙。

## 2 公式解析：达朗贝尔公式的推导

令 $v = u_t + a u_x$，则第一个因子给出 $v_t - a v_x = 0$——一阶线性齐次方程，特征线 $x + at = C$，故 $v = f(x + at)$ 只依赖 $x + at$。于是

$$
u_t + a u_x = f(x + at)
$$

再解这个非齐次一阶方程，或直接用第二篇的双曲特征坐标 $\xi = x + at$、$\eta = x - at$：波动方程化为 $u_{\xi\eta} = 0$，立即积分两次：

- **第一步，化标准形。** 特征坐标 $\xi = x + at$、$\eta = x - at$ 下，$u_{tt} - a^2 u_{xx} = -4a^2 u_{\xi\eta}$，方程成为 $u_{\xi\eta} = 0$。
- **第二步，逐次积分。** $u_\xi$ 不依赖 $\eta$，故 $u_\xi = F'(\xi)$ 只依赖 $\xi$；再积分得 $u = F(\xi) + G(\eta)$。
- **第三步，回代特征坐标。** $u(x,t) = F(x+at) + G(x-at)$。
- **第四步，用初始条件定 $F, G$。** 代入 $t=0$：
  $$ F(x) + G(x) = \varphi(x), \qquad aF'(x) - aG'(x) = \psi(x) $$
  解出 $F' = \frac{1}{2}\varphi' + \frac{1}{2a}\psi$，$G' = \frac{1}{2}\varphi' - \frac{1}{2a}\psi$，积分即得

$$
\boxed{\;u(x,t) = \frac{\varphi(x-at) + \varphi(x+at)}{2} + \frac{1}{2a}\int_{x-at}^{x+at} \psi(\xi)\,d\xi\;}
$$

这就是**达朗贝尔公式（d'Alembert formula）**。

**公式的物理朗读：** 解由三块拼成——左行波 $\frac{1}{2}\varphi(x+at)$、右行波 $\frac{1}{2}\varphi(x-at)$（初始位移各劈成两半朝相反方向走），加上初始速度在区间 $[x-at, x+at]$ 上的积分贡献。初始速度的「劈分」带有 $1/(2a)$ 因子，因为它除以了波速。

## 3 行波解：两列波相遇

达朗贝尔公式揭示了波动的本质：**任意扰动 = 一列右行波 + 一列左行波**。

**辨析｜易错点：** 很多人以为 $F(x+at)$ 是「沿 $x$ 方向传播」——恰好相反。固定一个相位 $x + at = \text{常数}$，当 $t$ 增大时 $x$ 必须**减小**才能保持相位不变，所以 $F(x+at)$ 是**左行波**（向 $-x$ 方向），而 $G(x-at)$ 是**右行波**（向 $+x$ 方向）。判断行波方向，永远是「让相位不变，看 $x$ 怎么变」。

两列波相遇时不会互相伤害：它们独立叠加（线性性），穿过彼此后形状完全恢复。这就是「波不互扰」原则，也是叠加原理的直接推论。<span class="marginnote">这也是为什么拨动琴弦中点，观察到的扰动分成两半各奔两端、在两端反射后回来会合——达朗贝尔公式在两端反射下仍需修正（见《半无界弦问题与延拓法》），但「分裂成两列」的结构始终不变。</span>

初始位移对解的贡献是「劈半双向跑」，初始速度的贡献是「在一段区间上累积」。两者共同构成解。

## 4 一个具体例子

解初值问题：$u_{tt} = u_{xx}$，$u(x,0) = \frac{1}{1+x^2}$，$u_t(x,0) = 0$。

代入达朗贝尔公式（$a = 1$，$\psi = 0$）：

$$
u(x,t) = \frac{1}{2}\left[\frac{1}{1+(x-t)^2} + \frac{1}{1+(x+t)^2}\right]
$$

- **$t = 0$：** 还原为 $\frac{1}{1+x^2}$，初值正确。
- **$t = 1$：** 两个驼峰中心分别在 $x = \pm 1$，各是原来的一半高度——初始驼峰分裂，左右各半。
- **$t$ 继续增大：** 两驼峰继续相向或反向分离，永不回头（对无限弦）。

**这条例子里，波速 $a = 1$ 把「位移」与「时间」在几何上直接对应起来：** 每过 1 单位时间，波峰移动 1 单位距离。而 $\frac{1}{1+x^2}$ 这个 Lorentz 型初值的妙处是：它沿特征线平移后形状不变，恰好演示「形状保持」——这是双曲型方程独有的、抛物型方程不具备的性质（对比热传导方程：初始驼峰会立刻被抹平）。

## 5 达朗贝尔公式的意义与局限

达朗贝尔公式的价值超出「一个闭式解」：

1. **它证明了柯西问题的适定性。** 公式本身给出存在性；由公式的连续性立得唯一性与稳定性（见《能量不等式与解的唯一性》）。
2. **它揭示了有限传播速度。** 解在 $(x,t)$ 的值只依赖初始区间 $[x-at, x+at]$——这就是下一节**依赖区间**的雏形。
3. **它是正则性传递的范本。** $\varphi \in C^2$、$\psi \in C^1$ 时解是 $C^2$ 的；初始数据的间断（如拔弦）会沿特征线传播成解的间断——这是后面 Huygens 原理、弱解理论的伏笔。

**局限也很明确：** 达朗贝尔公式只适用于无限直线上的柯西问题。半无限弦需要延拓法，有界弦需要分离变量法——这两者是接下来两节的主题。

## 6 小结

- 波动方程经特征坐标化为 $u_{\xi\eta} = 0$，通解 $u = F(x+at) + G(x-at)$。
- 达朗贝尔公式：$u = \frac{\varphi(x-at)+\varphi(x+at)}{2} + \frac{1}{2a}\int_{x-at}^{x+at}\psi\,d\xi$。
- $F(x+at)$ 是左行波、$G(x-at)$ 是右行波，方向判断看「相位不变时 $x$ 的变化」。
- 两列波独立叠加、穿过互不干扰。
- 公式同时给出解的存在性、唯一性、稳定性与有限传播速度。
