## 为什么从拉普拉斯变换开始

傅里叶变换处理空间（全直线），但 PDE 的**时间**变量天然是半无界的（$t \ge 0$），而且定解问题给的是**初始条件**而非边界条件。**拉普拉斯变换**正是为这种「半直线 + 初值」量身定做的谱工具：它对 $t$ 变换，把时间导数变成代数项、把初始条件直接编进公式。这一节建立拉普拉斯变换及其性质，并用它解波动方程与热传导的定解问题——它是「时间方向的谱方法」，与正弦/余弦变换在空间方向的工作正好互补。

## 1 定义与性质

**拉普拉斯变换（Laplace transform）**：对 $t \ge 0$ 的函数 $f$，定义

$$
F(s) = \mathcal{L}[f](s) = \int_0^{\infty}f(t)\,e^{-st}\,dt
$$

其中 $s = \sigma + i\tau$ 是复变量，要求 $f$ 的增长被 $e^{\sigma t}$ 控制（收敛半平面）。<span class="marginnote">拉普拉斯变换可以看成「傅里叶变换的解析延拓版」：把 $e^{-i\omega t}$ 换成 $e^{-st}$，并对半直线积分。$\sigma$ 的实部承担收敛性，$\tau$ 的虚部承担频率分解。工程里常简称「把 $t$ 域换到 $s$ 域」，解完再用逆变换（Mellin 反演或查表）回来。</span>

**核心性质（初值自动进入）：**

$$
\mathcal{L}[f'] = sF(s) - f(0), \qquad \mathcal{L}[f''] = s^2F(s) - s\,f(0) - f'(0)
$$

**证明**（分部积分）：$\int_0^\infty f'e^{-st}dt = \big[fe^{-st}\big]_0^\infty + s\int fe^{-st}dt = -f(0) + sF(s)$。二阶再套一次。

**与傅里叶变换的本质区别：初始条件 $f(0), f'(0)$ 被显式带入公式。** 这正是定解问题需要的——傅里叶变换处理「无穷远无边界」，拉普拉斯变换处理「起点有初值」。<span class="marginnote">「微分变乘法 + 初值进公式」让拉普拉斯变换天然适合初值问题：$u_{tt}$ 变换后变成 $s^2U - su(x,0) - u_t(x,0)$，初始条件 $\varphi, \psi$ 直接出现在方程里，无需另列条件——这是它比傅里叶方法少一步「代入初值」的省力之处。</span>

**卷积定理（时域版）**：$\mathcal{L}[f * g] = F(s)\,G(s)$，与傅里叶版本同构。

## 2 拉普拉斯变换解波动方程

**问题**：半无限或有限弦的初值问题 $u_{tt} = a^2 u_{xx}$（$x > 0$），$u(x,0) = 0$、$u_t(x,0) = 0$，边界 $u(0,t) = g(t)$（端点被驱动）。

- **第一步，对 $t$ 做拉普拉斯变换。** 记 $U(x,s) = \mathcal{L}[u(x,\cdot)](s)$。由二阶性质（初值零）：
  $$ s^2U = a^2\,U_{xx} \quad\Longrightarrow\quad U_{xx} = \frac{s^2}{a^2}U $$
- **第二步，解关于 $x$ 的 ODE。** 这是常系数二阶 ODE，通解 $U = A(s)e^{sx/a} + B(s)e^{-sx/a}$。物理上解在 $x\to\infty$ 有界，故 $A = 0$。
- **第三步，套边界。** $U(0,s) = G(s) = B(s)$，于是 $U(x,s) = G(s)e^{-sx/a}$。
- **第四步，逆变换。** 用位移性质 $\mathcal{L}[g(t - x/a)H(t - x/a)] = e^{-sx/a}G(s)$（$H$ 是 Heaviside 阶跃）：
  $$ u(x,t) = g\!\left(t - \frac{x}{a}\right)H\!\left(t - \frac{x}{a}\right) $$
- **第五步，读物理。** $t < x/a$ 时 $u = 0$——**驱动信号还没到**；$t \ge x/a$ 时 $u = g(t - x/a)$——**端点扰动以速度 $a$ 原样传过来**。这就是行波 $g(t - x/a)$ 的拉普拉斯变换推导。

**拉普拉斯变换把「行波传播」变成「指数乘法的逆变换」**——$e^{-sx/a}$ 的逆变换自动给出延迟 $x/a$ 与阶跃截断。初值为零时，解就是「边界信号按波速迟到的副本」。

## 3 公式解析：初值非零与热传导

对非零初值的完整问题，公式解析走一遍热传导 $u_t = a^2u_{xx}$（$x>0$），$u(x,0) = \varphi(x)$、$u(0,t) = g(t)$：

- **第一步，变换时间。** $sU - \varphi(x) = a^2 U_{xx}$，即
  $$ U_{xx} - \frac{s}{a^2}U = -\frac{1}{a^2}\varphi(x) $$
  初值 $\varphi$ 成了非齐次项——**初值不再需要事后代入，它已经坐在方程里**。
- **第二步，解空间 ODE。** 对 $x$ 求通解（用常数变易或直接猜特解），边界 $U(0,s) = G(s)$、$U \to 0$（$x\to\infty$）定常数。
- **第三步，逆变换（查表）。** 涉及 $e^{-x\sqrt{s/a^2}}$ 型的逆变换，对应误差函数 $\mathrm{erfc}$——半无限热传导的经典解。
- **第四步，Duhamel 结构。** 对边界驱动 $g(t)$ 的部分，逆变换给出 $\int_0^t g(t-\tau)\,\text{核}\,d\tau$——与第五篇 Duhamel 原理一致，拉普拉斯变换「自动」实现了齐次化原理。

**拉普拉斯变换的套路是「时间变量变成参数，PDE 变 ODE」**——与傅里叶变换把空间变参数完全对称。哪个方向「半无界 + 有初值/边界值」就用哪个变换。

## 4 为什么拉普拉斯变换在工程中流行

拉普拉斯变换在控制论与电路分析中地位极高，原因：

- **初值直接入式**：控制系统关心的就是「初始状态 + 输入 → 输出」，拉普拉斯变换把初值放进公式，一步到位；
- **阶跃/冲击信号**：$\mathcal{L}[H(t)] = \frac{1}{s}$、$\mathcal{L}[\delta] = 1$——工程信号（阶跃、脉冲、斜坡）都有整洁的像，且解中自动出现阶跃截断；
- **传递函数**：$\frac{Y(s)}{U(s)}$ 是系统的传递函数，$s$ 域代数运算（零极点分析）比时域卷积直观得多；
- **表驱动**：庞大的拉普拉斯变换表让「变换 → 代数 → 查表反变换」成为工程标配流程。

<span class="marginnote">本专题用它的场景是定解问题：半无限区域、带初值/边界的时间演化。相比傅里叶变换，拉普拉斯变换对「时间」尤其自然——时间只有一个方向，初值在起点，正好是半直线谱方法的甜区。第四级《自动控制原理》《信号与系统》会把 $s$ 域方法发展成完整的系统理论。</span>

## 5 拉普拉斯与傅里叶的对照

把两把「谱刀」并排看，分工就清晰了：

| 性质 | 傅里叶变换 | 拉普拉斯变换 |
| --- | --- | --- |
| 定义域 | 全直线 $(-\infty,\infty)$ | 半直线 $[0,\infty)$ |
| 核 | $e^{-i\omega x}$ | $e^{-st}$（$s$ 复） |
| 微分性质 | $f' \mapsto i\omega\hat f$ | $f' \mapsto sF - f(0)$ |
| 初值 | 无（需补边界） | 自动进入公式 |
| 适用 | 空间方向、稳态 | 时间方向、初值问题 |
| 反演 | 积分公式 | 查表 / Mellin 积分 |

**用对工具是谱方法的第一课：空间问题想傅里叶，时间问题想拉普拉斯，半空间想正弦/余弦，有界区间想级数。** 四把刀各管一类区域与边界，组合起来覆盖本专题全部定解问题。

**辨析｜易错点：** 拉普拉斯变换的收敛性依赖 $s$ 的实部——$f$ 增长快则收敛半平面靠右。查表时「反变换的唯一性」在连续函数类中成立，但间断函数需注意 Heaviside 截断。另外，把 $\mathcal{L}[f'] = sF - f(0)$ 与傅里叶版 $\mathcal{F}[f'] = i\omega\hat f$ 搞混是最常见错误——**拉普拉斯有初值尾巴、傅里叶没有**，这是两者最本质的差别。

## 6 小结

- 拉普拉斯变换 $\mathcal{L}[f] = \int_0^\infty fe^{-st}dt$ 处理半直线时间，初值自动入式。
- 微分性质：$\mathcal{L}[f'] = sF - f(0)$、$\mathcal{L}[f''] = s^2F - sf(0) - f'(0)$。
- 波动方程经拉普拉斯变换变 ODE，逆变换给出行波 $g(t - x/a)$ 与阶跃截断。
- 热传导的非零初值成为变换后方程的非齐次项，Duhamel 结构自动出现。
- 傅里叶管空间、拉普拉斯管时间，四把谱刀按区域与边界分工。
