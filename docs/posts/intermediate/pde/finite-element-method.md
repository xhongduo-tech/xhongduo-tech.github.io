## 为什么从有限元方法开始

里兹与伽辽金选的是全局基函数（三角函数、多项式）——对复杂几何区域无能为力。**有限元方法**把两者的思想与**分片多项式 + 局部支撑**结合：把区域切成许多小单元（三角形/四面体），在每个单元上用简单的分片线性函数，基函数只在相邻单元局部非零。这带来三个革命性好处：**处理任意复杂几何、矩阵稀疏、自动处理自然边界条件**。有限元是现代工程计算（结构、流体、电磁、热）的标准主力。这一节建立有限元的三大构件——网格、分片基函数、单元组装——并给出误差的基本图像。

## 1 网格剖分与分片线性基

**第一步，网格剖分。** 把区域 $\Omega$ 剖分为互不重叠的小单元（二维用三角形、三维用四面体），单元顶点称为**节点（node）**。网格越细（单元尺寸 $h$ 越小），逼近越准。

**第二步，分片线性基函数。** 对每个节点 $P_i$，定义**帽子函数（hat function）**$\varphi_i$：

$$
\varphi_i(P_j) = \begin{cases} 1, & j = i \\ 0, & j \ne i \end{cases}, \qquad \varphi_i \text{ 在相邻单元上线性、其余为零}
$$

**$\varphi_i$ 在节点 $P_i$ 取值 1、其他节点取值 0，只在与 $P_i$ 相邻的单元上非零。**<span class="marginnote">帽子函数是「局部」的化身：每个基函数只管自己周围的一小圈单元。这带来巨大的工程红利——刚度矩阵 $A_{ij} = \int\nabla\varphi_i\cdot\nabla\varphi_j$ 只在 $i, j$ 相邻（共享单元）时非零，矩阵<strong>稀疏</strong>（绝大多数元素为零）。稀疏矩阵可以高效存储与求解（$O(N)$ 量级的迭代法），这是有限元能处理百万节点问题的基础。</span>

**逼近性**：任意连续函数 $u$ 的线性插值 $u_h = \sum u(P_i)\varphi_i$ 是「把 $u$ 在节点上的值连成折面」——节点值精确、单元内线性逼近。$h \to 0$ 时插值收敛到 $u$。

## 2 有限元方程：组装

**有限元方法 = 伽辽金方法 + 分片线性基。** 取 $V_h = \mathrm{span}\{\varphi_i\}$，求 $u_h = \sum c_i\varphi_i$ 使弱形式对所有 $\varphi_k$ 成立：

$$
\sum_jc_j\underbrace{\int_\Omega\nabla\varphi_j\cdot\nabla\varphi_k\,dx}_{A_{kj}} = \underbrace{\int_\Omega f\varphi_k\,dx}_{b_k}
$$

**关键：$A_{kj}$ 与 $b_k$ 不用整体积分算，而按单元逐个贡献、再「组装」起来。**<span class="marginnote">「组装（assembly）」是有限元工程流程的核心：每个三角形单元只涉及 3 个顶点，单元刚度矩阵是 $3\times3$ 的「小矩阵」；把每个单元的贡献加到全局矩阵的对应位置，就得到 $A$。这个「逐单元贡献、局部到整体」的流程，让复杂几何变得可处理——单元形状只影响「单元刚度」，不改变组装逻辑。</span>

**组装流程**：

1. **单元刚度**：对单元 $T$（顶点 $P_i,P_j,P_k$），算 $A^{(T)}_{pq} = \int_T\nabla\varphi_p\cdot\nabla\varphi_q$（$p,q \in \{i,j,k\}$）——线性函数的梯度是常数，单元刚度为显式常数；
2. **贡献累加**：$A_{pq} \mathrel{+}= A^{(T)}_{pq}$ 对每个单元执行；
3. **载荷同理**：$b_k \mathrel{+}= \int_T f\varphi_k$；
4. **求解**：$A\boldsymbol{c} = \boldsymbol{b}$，$u_h = \sum c_i\varphi_i$。

**本质边界条件（Dirichlet）**：节点值已知的，直接代入消去（$c_i = g(P_i)$）；**自然边界条件（Neumann）**：无需处理，弱形式自动包含（第六/七节）。

## 3 公式解析：一维线性元的完整计算

**例子**：$-\Delta u = -u'' = 1$ 在 $(0,1)$，$u(0) = u(1) = 0$。用 3 个节点 $x_0 = 0, x_1 = \frac12, x_2 = 1$（两个单元），$h = \frac12$。

- **第一步，写基函数。** $\varphi_1$ 在 $[0,\frac12]$ 上 $= 2x$、在 $[\frac12,1]$ 上 $= 2-2x$、其余为零；$\varphi_1'$ 分段常数 $= 2$ 或 $-2$。
- **第二步，算刚度矩阵。** $A_{11} = \int_0^{1/2}(2)^2dx + \int_{1/2}^1(-2)^2dx = 4\cdot\frac12 + 4\cdot\frac12 = 4$（只有内部节点 $x_1$ 有未知数，边界节点消去）。
- **第三步，算载荷。** $b_1 = \int_0^1\varphi_1\,dx$ = 三角形面积 $= \frac12\cdot1\cdot\frac12 = \frac14$。
- **第四步，解。** $4c_1 = \frac14 \Rightarrow c_1 = \frac{1}{16}$。有限元解 $u_h = \frac{1}{16}\varphi_1$——在 $x_1$ 处 $= \frac{1}{16}$。
- **第五步，对比真解。** $u = \frac{x(1-x)}{2}$，在 $x = \frac12$ 处 $u = \frac18 = \frac{2}{16}$——**有限元解是精确解的一半**！为什么？因为分片线性函数无法表示抛物线真解，线性插值 $u_h$ 在节点之间是直线，真解是曲线——节点值相等，但单元内是「弦」而非「弧」。

**注意这个例子的教训**：有限元在**节点上精确、单元内线性近似**（对一维线性元 + 线性载荷，节点值恰好精确——这是「超收敛」现象）；误差来自单元内的弯曲，随 $h^2$ 减小。

## 4 误差估计

有限元误差的标准估计（对线性元、$H^1$ 范数）：

$$
\|u - u_h\|_{H^1} \le C\,h\,\|u\|_{H^2}
$$

**误差按单元尺寸 $h$ 的一阶收敛**——网格减半，误差减半（$H^1$ 范数）。对 $L^2$ 范数，阶数高一档：

$$
\|u - u_h\|_{L^2} \le C\,h^2\|u\|_{H^2}
$$

**推导骨架**（Céa 引理 + 插值误差）：

- **第一步，Céa。** $\|u - u_h\|_{H^1} \le \frac{C}{\alpha}\inf_{v_h\in V_h}\|u - v_h\|_{H^1}$（上节）；
- **第二步，插值估计。** 分片线性插值 $I_hu$（在节点取 $u$ 的值）满足 $\|u - I_hu\|_{H^1} \le Ch\|u\|_{H^2}$（逼近论：线性插值误差 $\sim h$ 阶）；
- **第三步，合并。** $\|u - u_h\| \le \frac{C}{\alpha}\cdot Ch\|u\|_{H^2}$——**一阶收敛**。

**收敛阶 = 单元多项式次数 + 1**（线性元一阶、二次元二阶……）。这个「升阶」规律是有限元精度设计的核心：想要更高精度，要么加密网格（$h$ 减小）、要么提高单元次数（$p$ 增大）——即 $h$ 法与 $p$ 法的选择。<span class="marginnote">误差估计的「收敛阶」概念与数值分析（第四级）完全衔接：有限元、有限差分、谱方法的精度都按「误差随网格/自由度数下降的速度」衡量。自适应网格加密（哪里误差大哪里加密）是现代有限元工程的关键技术，其理论依据就是逐区域误差估计。</span>

## 5 有限元方法的优势与全景

**有限元方法为什么成为工程标准？**

| 优势 | 原因 |
| --- | --- |
| 复杂几何 | 三角形/四面体网格贴合任意区域 |
| 稀疏矩阵 | 局部支撑基函数 |
| 自然边界 | Neumann 条件自动处理 |
| 变系数 | 单元刚度逐单元算，材料属性任意分布 |
| 自适应 | 局部加密、$h$/$p$ 细化 |
| 通用性 | 椭圆、抛物、双曲、非线性、耦合全适用 |

**有限元的家族图谱**：里兹（能量）→ 伽辽金（弱形式）→ 有限元（局部基）= 伽辽金 + 分片多项式 + 网格。它把前两节的方法论全部吸收，并用「局部化」解决了全局基的致命弱点。<span class="marginnote">从「从极限到大模型」的主线看，有限元是「分而治之 + 局部表示」的经典工程实现：复杂整体由简单局部拼成，全局方程由局部贡献组装——这与卷积神经网络「局部感受野 + 逐层组装」的架构哲学惊人地一致。学完本专题的最后一节，回头看整条路：从物理定律导出方程，到分离变量/变换求解，到适定性理论，再到变分与数值——一部完整的「数学物理方程」总览到此收官。</span>

## 6 数值算例：网格加密看收敛

对 $-\Delta u = 1$、$u(0)=u(1)=0$（真解 $u = \frac{x(1-x)}{2}$），逐步加密网格看误差：

- **第一步，$N=1$ 单元（$h=1$）。** 有限元解是直线，误差显著。
- **第二步，$N=2$ 单元（$h=1/2$）。** 内部节点 $x=1/2$ 处 $u_h = \frac{1}{16}$，真解 $\frac18$——误差 $\frac{1}{16}$。
- **第三步，$N=4$ 单元（$h=1/4$）。** 节点值趋向精确（线性元 + 线性载荷的节点超收敛），单元内误差按 $h^2$ 减小。
- **第四步，读收敛表。** $H^1$ 误差 $\sim h$、$L^2$ 误差 $\sim h^2$——网格减半，$H^1$ 误差减半、$L^2$ 误差减到四分之一。

**数值意义**：收敛阶决定「加密网格值不值」——$h^2$ 收敛意味着「网格减半、误差小四倍」，性价比极高。这是有限元成为工程标准的原因之一。

## 7 有限元的家族与延伸

有限元不是单一方法，而是一整个家族：

- **按单元次数**：线性元、二次元、高阶元（$p$ 法）——次数越高收敛越快。
- **按问题**：椭圆、抛物（时间离散 + 空间有限元）、双曲（间断 Galerkin）、非线性（牛顿迭代 + 有限元）。
- **按基函数**：标准 Lagrange 元、Hermite 元（含导数自由度）、混合元（多场变量）。

**辨析｜易错点：** 有限元是「弱形式的离散化」，不是「强形式的」。直接用强形式（逐点方程）做离散会得到错误结果——必须先用弱形式（分部积分）再离散。**「先弱化、再离散」是有限元的铁律**，初学者最易忽略。<span class="marginnote">从「从极限到大模型」的视角，有限元是「用局部拼整体」的集大成——网格 = 局部模型，组装 = 全局合成。这正如深度学习「卷积层 + 全连接」的组合：局部特征提取 + 全局决策。有限元与深度网络的「局部性假设」是同一工程哲学的两次独立发明。</span>

## 8 小结

- 有限元 = 伽辽金方法 + 网格剖分 + 分片多项式局部基。
- 帽子函数在节点取值 1/0、只在相邻单元非零，刚度矩阵因此稀疏。
- 组装流程：单元刚度 → 贡献累加 → 求解 $A\boldsymbol{c} = \boldsymbol{b}$。
- 一维线性元算例：节点值精确（超收敛）、单元内线性近似。
- 误差 $\|u-u_h\|_{H^1} \le Ch\|u\|_{H^2}$ 一阶收敛，$L^2$ 二阶收敛；收敛阶 = 多项式次数 + 1。
