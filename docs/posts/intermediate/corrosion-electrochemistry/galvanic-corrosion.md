## 为什么从电偶腐蚀开始

一艘钢壳船，偏偏要用青铜螺旋桨；一根铝质天线的底座，固定螺栓却是碳钢的；教堂铜屋顶上的雨水，把下方的钢构件加速锈穿。这些事故有一个共同凶手：**电偶腐蚀（galvanic corrosion）**——**当两种不同电位的金属在导电介质中电接触时，较活泼（电位较负）的金属成为阳极而加速腐蚀**。<span class="marginnote">人类很早就无意间利用了它：1799 年伏打用锌片与铜片泡在盐水里造出第一只电池，伏打电堆本身就是一场精心布置的电偶腐蚀。反过来，当这场腐蚀发生在你不想要的地方，就成了工程事故。本节把《腐蚀电极过程动力学与极化曲线》的混合电位理论，从「一块金属上两支反应」推广到「两块金属之间电子流动」。</span>电偶腐蚀是工业界最常见的腐蚀形态之一，也是选材、连接、维修时最先要检查的隐患——它告诉你，**「材料本身耐蚀」不等于「装配在一起耐蚀」**。<span class="marginnote">衔接关系：上一课的极化曲线给出单金属的 $i_{\text{corr}}$；本课把它推广为两块金属共享电位、电流在两块之间分配。缓蚀剂与涂层的失效也常以电偶形式局部化，见《缓蚀剂》与《金属涂层与表面处理》。</span>

## 1 电偶序：金属的「电位座次表」

预测电偶腐蚀方向的第一件工具，是把常用金属与合金放进同一环境（通常是海水）里实测它们的开路电位，按电位高低排一张表，称为**电偶序（galvanic series）**。<span class="marginnote">注意：电偶序是「实测开路电位」，包含合金的钝化状态，与《腐蚀热力学与电位-pH 图》里的标准电极电位（纯金属、标准态、热力学值）不是一回事——两者容易混淆，工程判断以电偶序为准。</span>

常见材料在海水中的大致座次（电位从负到正）：

| 座次 | 金属/合金 | 典型电位 vs SCE（约） |
| --- | --- | --- |
| 活泼（阳极） | 镁 | $-1.6\ \text{V}$ |
|  | 锌 | $-1.0\ \text{V}$ |
|  | 铝及其合金 | $-0.8\ \text{V}$ |
|  | 碳钢、铸铁 | $-0.6\ \text{V}$ |
|  | 不锈钢（活化态） | $-0.5\ \text{V}$ |
|  | 锡、铅 | $-0.5\ \text{V}$ |
|  | 铜、黄铜 | $-0.2\ \text{V}$ |
|  | 镍基合金 | $-0.1\ \text{V}$ |
| 惰性（阴极） | 不锈钢（钝化态）、钛 | $+0.1\ \text{V}$ |
|  | 石墨、铂、金 | $+0.3\ \text{V}$ |

读表的要点有二：**表中相距越远、电位差越大，电偶驱动越强**；**同一材料可能两处上榜**——不锈钢活化态偏负、钝化态偏正，差可达半伏，这意味着钝化不锈钢与活化不锈钢接触也会发生电偶腐蚀。

## 2 两块金属的混合电位：把 Evans 图推广

把锌片与铜片在盐水中相连，锌是阳极（溶解）、铜是阴极（析氢或氧还原）。两块金属通过外电路导通后，**电位必然趋于同一个混合电位 $E_g$**，位于两金属各自的腐蚀电位之间。在 Evans 图上，这表现为两条极化曲线求交点——只不过阳极极化曲线来自锌、阴极极化曲线来自铜。

交点对应的总电流 $I_g$ 是耦合系统的净电流，其中锌以 $I_g$ 溶解。关键在于：

$$E_{\text{corr,Zn}} \lt  E_g \lt  E_{\text{corr,Cu}}$$

锌被阳极极化，电位被「拽」向正方向，溶解电流从孤立时的 $i_{\text{corr,Zn}}$ 增大到耦合时的 $I_g$；铜则被阴极极化，电位被拉负，几乎不溶解，只充当阴极。<span class="marginnote">电位差只是「驱动」，真正决定腐蚀量的是极化程度：阴极反应越容易（交换电流密度大、面积大），$I_g$ 越大，锌被加速得越狠。这正是电偶腐蚀「异种金属接触时，越靠近电位正的一端腐蚀越重」的机理。</span>

从 Evans 图上还能看出一个实用推论：<strong>耦合后的 $E_g$ 偏向「极化能力弱」的一方</strong>——阴极很容易极化的一方，$E_g$ 更接近阳极电位；阳极很容易极化的一方，$E_g$ 更接近阴极电位。电位差的大小、双方极化曲线的形状，共同决定了「谁被拉得多、谁被加速得多」。这也是为什么完全相同的两种材料只要表面状态不同（如钝化与活化），也会形成电偶——<strong>电偶腐蚀的本质是电位与极化曲线的差异，不只存在于不同金属之间</strong>。

## 3 公式解析：面积效应——小阳极配大阴极最危险

电偶腐蚀的致命之处常常不是金属种类，而是**面积比**。设耦合总电流 $I_g$，它在阳极与阴极之间分配：

$$i_a = \frac{I_g}{A_a}, \qquad i_c = \frac{I_g}{A_c}$$

$i_a$、$i_c$ 分别是阳极与阴极的电流密度，$A_a$、$A_c$ 是各自面积。

- **第一步，看面积比的杠杆作用**：总电流 $I_g$ 主要受阴极控制（阴极反应通常决定总速率），近似与 $A_c$ 成正比。于是阳极电流密度 $i_a \approx I_g/A_a \propto A_c/A_a$。
- **第二步，代入典型场景**：面积比 $A_c:A_a = 10:1$ 时，阳极电流密度是孤立时的约 10 倍，阳极腐蚀速率同步放大——这就是「**大阴极、小阳极**」组合的危害。
- **第三步，换算失重**：配合法拉第定律 $v = M i_a/(nF)$，面积比每增大一个数量级，阳极失重速率近似放大一个数量级。

**工程铁律：绝不让小面积阳极对接大面积阴极。** 钢螺栓配大面积铜板（阳极小、阴极大）是灾难；反过来，铜螺栓配大面积钢板则风险小得多——所以设计时常用绝缘垫片、涂层过渡来切断或均化这种面积比。<span class="marginnote">经典事故：不锈钢法兰配碳钢小螺栓，不锈钢是大阴极、碳钢螺栓是小阳极，螺栓在几个月内被锈蚀松动。修复方案不是换更耐蚀的螺栓，而是把螺栓换成电位更接近的合金、或加绝缘套筒。</span>

面积效应的另一个推论是「**阳极面积要设计得大**」：牺牲阳极（锌块、镁棒）故意做得比被保护件小很多是不行的——阳极面积过小，自身电流密度过大、寿命骤减。合理的设计是让阳极面积与被保护面积比例合适，这正是《阴极保护与阳极保护》里阳极尺寸计算的内容；而《缓蚀剂》里「阳极型缓蚀剂不足量诱发点蚀」，本质也是「局部小阳极 + 周围大阴极」的同一机理在缓蚀剂场景的重演。

## 4 辨析｜易错点：电偶腐蚀的方向与判据

三个高频误判必须避开：

**「电位差大 = 一定腐蚀得重」是错的**：电位差给驱动，极化曲线给流量。两个高惰性的金属电位差再大，阴极反应慢，实际电流也小；反之电位差适中但阴极反应快的组合反而腐蚀剧烈。<span class="marginnote">海水里碳钢与铜的电位差不算极大，但氧还原在铜上高效进行，碳钢依然被显著加速——「看电位差」只适合快速筛查，定量判断要看极化曲线。</span>

**「阳极被保护、阴极没事」是片面的**：阳极确实被牺牲了，但阴极可能因此吸氢，在高强钢上引发氢脆（见《应力腐蚀开裂与氢脆》），也可能因阴极产物（$\ce{OH^-}$）局部升高而改变周围环境。

**「连接处才有电偶」是错的**：只要两金属同处一个导电介质且电子回路闭合，不直接接触也能构成电偶——甲板上的铝合金件与几米外接地的铜管线，可以通过船体钢板与海水形成完整回路。

## 5 工程对策：防电偶腐蚀清单

电偶腐蚀的预防在设计中就应完成，核心原则是**「要么切断回路，要么拉平电位」**：

- **选材避免大电位差**：异种金属搭配时，尽量选电偶序中相邻者，或用电偶试验数据验证。
- **绝缘隔离**：在异种金属间加绝缘垫片、套管、涂层，切断电子回路——最直接有效。
- **避免小阳极/大阴极**：若必须混用，让更活泼的金属做大面积件、耐蚀金属做小面积件。
- **涂层设计注意「阴阳极规则」**：给阴极（耐蚀方）涂漆，不要只给阳极涂——否则阳极漆膜破损反而把腐蚀集中到小缺口，见《金属涂层与表面处理》。
- **牺牲阳极主动利用**：在船体、管道上刻意安装更活泼的锌/铝块，让电偶腐蚀发生在「可更换的阳极」上——这已是《阴极保护与阳极保护》的序幕。

### 核心概念速查

| 概念 | 一句话定义 | 工程意义 |
| --- | --- | --- |
| 电偶序 | 金属在特定环境中实测开路电位排序 | 判断谁当阳极 |
| 混合电位 $E_g$ | 两金属耦合后共享的电位 | 决定耦合后电流大小 |
| 阳极面积效应 | $i_a \propto A_c/A_a$ | 小阳极 + 大阴极最危险 |
| 阴极控制 | 阴极反应决定总电流 | 按住阴极即按住腐蚀 |
| 绝缘隔离 | 切断电子回路 | 最直接的电偶防治 |

### 一个完整的现场诊断案例

某化工厂输送盐水的不锈钢管线上，一处法兰接头反复在几个月内漏水。检查发现：法兰垫片用的是普通石棉垫，螺栓是碳钢镀锌件，而管道本体是 316L 不锈钢。分析链条如下：

**第一步，定位电偶**：316L 钝化态电位较正、碳钢镀锌件较负，且盐水电导率高，电偶驱动充分——异种金属 + 良好电解质 + 直接电接触，三条件齐备。

**第二步，看面积比**：法兰上一圈碳钢螺栓总面积远小于大面积 316L 管体——正是「小阳极 + 大阴极」的经典构型，螺栓的镀锌层很快被耗尽，随后碳钢基体作为小阳极高速溶解。

**第三步，对症下药**：把螺栓换成与 316L 电位接近的 316 不锈钢螺栓，或在螺栓与法兰之间加绝缘套筒切断回路——两者任选其一，问题即消。

这个案例的启示是：**电偶腐蚀的现场诊断顺序是「找电偶对 → 看面积比 → 定对策」**，每一步都用得上本课的判断工具。

## 6 小结

- **电偶腐蚀**：异种金属在导电介质中电接触，电位较负者作阳极加速溶解。
- **电偶序** 是实测开路电位座次表，工程判断用它而非标准电极电位。
- 耦合后两金属电位趋同于**混合电位 $E_g$**，位于两腐蚀电位之间；阴极控制总电流。
- **面积效应** $i_a \propto A_c/A_a$
