## 为什么从涂层开始

全世界钢结构的防腐，一半以上靠「涂层」完成：镀锌护栏、喷漆桥梁、阳极氧化铝窗、磷化后再喷塑的汽车底盘——它们共同的做法是**在金属表面再造一层「替身」**。**金属涂层与表面处理**：**用物理或化学方法在金属表面形成一层保护层，把金属与环境隔开或转嫁腐蚀**。<span class="marginnote">涂层是「电阻控制」防腐的典型：把电解质与金属的接触切断，电化学回路就无从建立（见《腐蚀电极过程动力学与极化曲线》的电阻控制类型）。但涂层不是一层「静态的壳」——它会老化、破损、剥离，其防护效果取决于涂层类型、厚度与表面处理质量。</span>涂层的智慧在于**分工**：有的靠「牺牲自己」保护基体（镀锌），有的靠「阻隔环境」保护基体（油漆、阳极氧化膜），有的把两者结合（复合涂层体系）。理解涂层，就理解了金属防腐的「最后一公里」——前面的选材、设计、电保护都定好之后，最终在表面落地的往往是涂层。<span class="marginnote">衔接：本课用上《电偶腐蚀》的牺牲阳极逻辑（镀锌）、《钝化与钝化膜》的氧化膜逻辑（阳极氧化、铬化）、《阴极保护与阳极保护》的「涂层+CP」组合，是防护手段的「收官之课」。</span>

## 1 金属涂层：牺牲型与阻隔型

按保护机理，金属涂层分两大阵营：

**牺牲型（阳极性）涂层**：涂层金属比基体金属更活泼，例如**镀锌钢**——锌在电偶序里比铁负（见《电偶腐蚀》），镀层破损露出铁时，**锌继续当阳极保护铁**，直到锌消耗完。牺牲型涂层的最大优点是「破损处仍然安全」。<span class="marginnote">镀锌层破损后的行为是经典的「锈蚀自愈」：破损处露出钢铁，锌先腐蚀生成碱式碳酸锌等致密产物，堵塞破损口——这叫<strong>锌的「自密封」效应</strong>。因此镀锌钢即使划伤，也能带伤运行很多年。</span>

**阻隔型（阴极性）涂层**：涂层金属比基体更惰性，如**镀锡钢（马口铁）**、镀铬、镀镍。这类镀层靠致密把介质挡在外面，但一旦破损，**露出的基体成为小阳极、大面积镀层成为阴极**，反而加速基体穿孔——「阻隔型涂层必须完整」是铁律。

镀锌是最重要的牺牲型涂层，工艺是**热浸镀锌（hot-dip galvanizing）**：把钢件浸入 450 °C 左右的熔融锌中，生成铁锌合金层 + 纯锌层的复合镀层，厚度常为 50–100 μm。它兼有牺牲保护与阻隔保护，是室外钢构、护栏、电力铁塔的首选。热镀锌的细节里有两件事常被忽略：一是**前处理**要酸洗除锈、助镀（氯化锌铵），否则锌层附着不好；二是**镀层与基体之间有冶金结合的合金层**（铁锌金属间化合物），这层让锌「长」在钢上而非「贴」在钢上，是热镀锌寿命长的根本原因——相比电镀锌，热镀锌更厚、更耐磕碰。

**电镀锌**是另一条路：在电镀液中以钢为阴极沉积锌层，厚度通常 5–25 μm，更薄更均匀，适合紧固件、冲压件；缺点是镀层薄、牺牲寿命短，破损后不像热镀锌那样充分「自密封」——**厚度差一个数量级，寿命差一个数量级**，选型先问「要扛几年」。镀层越厚、加工变形（弯折、冲压）时越易开裂，所以薄板件常用电镀锌而非热镀锌，这就是「工艺与厚度由用途反推」的选型逻辑。

**牺牲型涂层「划破不怕」的代价是消耗自身**：锌层在保护破损处时自身被溶解，且溶解速率与暴露面积、环境侵蚀性正相关。设计时必须想清楚：**涂层的「自愈能力」是用寿命换来的**——牺牲型涂层划伤越多、环境越恶劣，锌层耗尽越快。这也是为什么「热镀锌 + 面漆」双保险常见：面漆把大部分环境挡住，锌层只处理漏网破损，两者分摊「寿命预算」。

## 2 公式解析：镀锌层的寿命设计

镀锌层的寿命由两个因素决定：**锌的消耗速率**与**镀层厚度**。简单估算：

$$t_{\text{life}} = \frac{d}{v_{\text{Zn}}}$$

$t_{\text{life}}$ 是镀层寿命，$d$ 是镀层厚度，$v_{\text{Zn}}$ 是锌在给定环境下的腐蚀速率。

- **第一步，查速率**：锌的腐蚀速率随环境差异巨大——乡村大气约 $1\text{–}3\ \mu\text{m/年}$，工业大气含 $\ce{SO2}$ 可达 $5\text{–}10\ \mu\text{m/年}$，海水飞溅区更高。这正是《大气、海水与土壤腐蚀》的腐蚀等级表在镀层设计上的直接应用。
- **第二步，代厚度**：标准热镀锌层厚约 $85\ \mu\text{m}$（镀层等级由镀件厚度定），代入乡村大气 $v_{\text{Zn}}\approx 2\ \mu\text{m/年}$，得 $t_{\text{life}} \approx 40$ 年以上。
- **第三步，看工况修正**：工业大气 $v_{\text{Zn}}\approx 7\ \mu\text{m/年}$ 时寿命降到约 12 年——**同一种镀层，环境不同寿命差三倍**。设计时就该按服役环境选镀层厚度等级，而不是一刀切。<span class="marginnote">同理可估算<strong>油漆体系</strong>的寿命：防腐底漆 + 中间漆 + 面漆的「涂层体系」，按 ISO 12944 分 C1–C5 环境等级与耐久年限，直接指导工程涂装设计——这是《大气、海水与土壤腐蚀》腐蚀等级的另一处工程落地。</span>

工程上镀锌厚度按标准分级（如 ISO 1461 按镀件厚度分档），验收用磁性测厚仪在多个测点取平均，并要求**局部最小值不得低于规定下限**——「平均够、局部不够」会让边角处提前锈蚀。这条「平均 + 最小双控」的验收思路，与涂层体系验收、乃至《腐蚀试验与电化学监测方法》里「平均 + 最大坑深双报告」的逻辑完全一致。

## 3 表面处理：涂层之前的那一半功夫

涂层的命门在**表面处理**——经验说法是「涂层失效，七成死于表面没处理好」。表面处理的目的是：**干净（除油除锈）、粗糙（提供锚固）、活化（利于成膜）**。

**除油除锈**：溶剂/碱液除油，酸洗、喷砂除锈。喷砂把表面打出一定粗糙度（锚纹），让涂层「咬」进金属。

**转化膜**：在金属表面化学反应生成一层非金属膜，既是涂层底，又有缓蚀作用：
**磷化**：磷酸盐在钢表面生成磷酸锌/磷酸铁膜，是油漆与电泳漆的经典底层。
**铬化/钝化**：铬酸盐在铝、锌表面生成钝化膜，增强附着力与耐蚀性（受环保限制，正被无铬工艺替代）。
**阳极氧化**：铝在电解液中作阳极，表面生成多孔 $\ce{Al2O3}$ 膜，**可染色、可封孔**，兼具装饰与防护。<span class="marginnote">阳极氧化与《钝化与钝化膜》的钝化膜同源但不同：钝化膜是「自然长成、极薄」，阳极氧化膜是「电化学加速生长、可到几十微米、多孔可染」。一个靠天然、一个靠人工，道理相通。</span>

阳极氧化的关键一步是**封孔**：刚生成的氧化膜多孔、未封闭，吸附性强但防腐性不足；用沸水/镍盐封孔后，孔内生成水合氧化铝把孔隙堵住，耐蚀性才真正建立。**「不封孔的阳极氧化只是装饰，封孔了才是防护」**——这道工序常被省略或偷工，是铝合金门窗早期腐蚀的常见原因。

**有机涂层（油漆/粉末）**：多层体系——**底漆**（附着力 + 缓蚀颜料，如富锌底漆）、**中间漆**（加厚阻隔）、**面漆**（耐候、装饰）。富锌底漆里的锌粉还能提供牺牲保护，是钢结构重防腐的标配。

涂装质量的三要素是**表面处理等级、涂层厚度、施工环境**。表面处理等级按标准分档：喷砂除锈 Sa2.5 级（近白金属）、Sa3 级（白金属）、手工除锈 St2/St3 级——等级越高，涂层寿命越长。涂层厚度用**湿膜/干膜测厚仪**逐点验收；施工环境要求湿度、温度在涂料允许范围，否则涂层发白、起泡、附着力崩盘。**重防腐涂装的验收不是「刷完了」，而是「测过了」**——这与《腐蚀试验与电化学监测方法》里「测量即管理」的理念一脉相承。

## 4 辨析｜易错点：涂层设计的三条铁律

**「阴极性涂层破损处更安全」是致命的错觉**：镀锡、镀铬、镀镍破损后形成「大阴极小阳极」，基体穿孔速度比裸金属还快。**牺牲型涂层（锌、铝）才不怕破损**——选涂层类型前先想清楚「破了怎么办」。<span class="marginnote">工程铁律叫 <strong>阴极涂层完整律</strong>：凡是比基体惰性的镀层，都必须保持完整；一旦破损，要么及时修补，要么改用牺牲型镀层。马口铁罐头一旦擦伤锈穿，原因正在于此。</span>

**「涂层越厚越好」不成立**：有机涂层过厚会内应力开裂、流挂不均；转化膜过厚则疏松掉粉。每种涂层都有自己的最佳厚度窗口——按标准设计，别「加厚求安心」。阳极氧化膜同理：膜厚增加耐蚀性并非线性提升，过厚反而脆裂、且耗电耗时；**「合适」永远优于「越厚」**。

**「表面处理可以省钱」最危险**：打磨粗糙的钢材上涂再好的漆，漆层也会从锈上整片脱落——**涂层寿命与表面处理等级直接挂钩**。喷砂除锈的 Sa2.5 级与手工除锈 St2 级，涂层寿命可差数倍。这是「看不见的工序决定看得见的寿命」的典型。

**「单层厚漆顶多层体系」是误区**：涂层体系讲究「多层、薄涂、分工」——每层各有职责（底漆附着 + 缓蚀、中间漆加厚、面漆耐候），层间附着力与应力逐层释放。单刷一层厚漆，溶剂难挥发、内应力大、一道破损直达基体，寿命反而短。**「层数 + 干膜厚度」双达标**，才是重防腐的正确验收姿势。

## 5 主要涂层工艺对照

| 工艺 | 典型镀层/膜 | 保护机理 | 适用场景 |
| --- | --- | --- | --- |
| 热浸镀锌 | 锌（铁锌合金+纯锌） | 牺牲型 | 室外钢构、护栏、铁塔 |
| 电镀 | 锌、镍、铬、锡 | 锌为牺牲，镍/铬/锡为阻隔 | 紧固件、装饰件、马口铁 |
| 热喷涂 | 锌、铝 | 牺牲型 | 大型钢结构现场防腐 |
| 阳极氧化 | $\ce{Al2O3}$ | 阻隔型（致密氧化膜） | 铝合金门窗、壳体 |
| 磷化/铬化 | 磷酸盐/铬酸盐膜 | 转化膜底层 | 涂装前处理、汽车 |
| 油漆/粉末涂层 | 多层有机涂层 | 阻隔型 | 全行业钢结构防腐 |
| 渗镀/扩散涂层 | 渗锌、渗铝、渗铬 | 阻隔 + 合金化 | 紧固件、高温件 |
| PVD/CVD | 氮化钛、类金刚石膜 | 阻隔 + 耐磨 | 刀具、模具、装饰 |

表中最后两类值得一句说明：**渗镀**把镀层元素扩散进基体形成合金化表层，结合力最强、不剥落；**PVD/CVD** 是真空镀膜，膜层致密且可做高硬度耐磨镀层。它们造价高、适用于高端或严苛场景——选型表从「便宜大碗」到「精密昂贵」一应俱全，按服役条件对号入座即可。

选择逻辑一句话：**优先牺牲型（锌/铝）应对「会破损」的场景，阻隔型（油漆/氧化膜）依赖「保持完整」的维护**。再补一个成本直觉：**表面处理与涂层的成本占比通常不足构件总价的 5%，却决定了 60% 以上的寿命**——省表面处理的每一分钱，都可能以数倍的维护费还回来。这是防腐领域「小投入大产出」最典型的一课。现实中常用「热镀锌 + 面漆」或「富锌底漆 + 中间漆 + 面漆」的组合，让牺牲保护与阻隔保护互补。<span class="marginnote">海工与油气领域还有「涂层 + 阴极保护」的组合拳：涂层承担 99% 隔绝、CP 处理剩余 1% 破损——前课《阴极保护与阳极保护》已讲过，这里再补一句：涂层的剥离会显著改变 CP 电流需求，两者必须一起监测。</span>

### 一个表面处理选型的决策清单

面对一块待防腐的构件，选型的顺序可以固定成四问：

**问环境**：服役在大气、海水还是土壤？按《大气、海水与土壤腐蚀》定腐蚀等级（C2–C5），直接决定镀层厚度档位与涂层体系等级。

**问形态**：板材还是型材？是否要弯折、冲压、焊接？薄板件变形大，宜电镀锌而非热镀锌；焊接件要先做焊缝打磨与除渣，涂层才能均匀。

**问破损风险**：构件会不会被磕碰、划伤、现场安装刮擦？会破损的位置优先牺牲型镀层（锌/铝），破损后仍安全；只靠阻隔型涂层的地方必须保证「破损即补」。

**问寿命预算**：要求服役 20 年还是 5 年？把镀层厚度、涂层体系等级、维护周期三者折成一张「寿命—成本」表——牺牲型的「自愈」、阻隔型的「完整」，各有各的账要算。

四问走完，选型就落到了具体工艺：室外钢构 → 热镀锌或重防腐油漆；室内冲压件 → 电镀锌；铝合金门窗 → 阳极氧化 + 封孔；高温紧固件 → 渗锌/渗铝。**表面处理不是「选一种涂料」，而是「按环境与寿命反推工艺」**——这正是本课与《腐蚀试验与电化学监测方法》共享的工程思维：先定目标，再定度量，最后定工艺。

### 核心概念速查

| 概念 | 一句话定义 | 保护机理 |
| --- | --- | --- |
| 牺牲型涂层 | 涂层金属比基体活泼（锌、铝） | 破损处仍保护基体 |
| 阻隔型涂层 | 涂层金属比基体惰性（锡、镍、铬） | 必须完整，破损反加速 |
| 热浸镀锌 | 浸入熔融锌，含铁锌合金层 | 牺牲 + 阻隔兼有 |
| 阳极氧化 | 铝阳极电解生成 $\ce{Al2O3}$ 膜 | 阻隔 + 可染色 |
| 磷化/铬化 | 化学反应生成转化膜 | 涂层底层 + 缓蚀 |
| 富锌底漆 | 锌粉底漆 | 牺牲 + 附着力 |

### 一个现场对比：两种护栏，两种命运

同一市政项目的两段钢护栏，一段是热浸镀锌件，另一段为控制成本改用电镀锌件，三年后的现场对比很能说明问题：

**热镀锌段**：表面仍完好，仅有局部锈点。原因：热镀锌层厚约 85 μm，且铁锌合金层与钢结合牢固，磕碰露钢处由锌牺牲保护、「自密封」堵住。

**电镀锌段**：护栏转角与螺栓孔处出现明显红锈。原因：电镀层仅约 10 μm，在安装磕碰与雨雾侵蚀下很快耗尽；更关键的是——**电镀锌件常再涂一层铬酸盐钝化膜（六价铬黄绿钝化）提高耐蚀性，一旦钝化膜划破，薄锌层在含氯雨水中加速消耗**，露出钢基体后就是「小阳极 + 大片锈蚀」。

**结论**：户外长期暴露的构件，镀层厚度与结合力是第一考量，成本让位于寿命——「**省了镀层厚度，就得加倍保养**」。这个案例也说明《大气、海水与土壤腐蚀》里「按环境等级选防护等级」的原则，在涂层厚度上同样成立。

## 6 小结

- **金属涂层**分**牺牲型**（锌/铝，破损安全）与**阻隔型**（锡/镍/铬，破损危险）两类，机理差异决定选型。
- 镀锌层寿命可估算：$t_{\text{life}} = d/v_{\text{Zn}}$，同一种镀层环境不同寿命可差三倍，按腐蚀等级选厚度。
- 表面处理是涂层寿命的命门：**除油除锈（干净）、喷砂锚纹（粗糙）、转化膜（活化）**三步缺一不可。
- 阳极氧化膜要**封孔**才有防护力；磷化/铬化是涂装前的经典底层。
- 三条铁律：阻隔型涂层必须完整、厚度要进「合适窗口」、表面处理省不得。
- 选型四问：**环境、形态、破损风险、寿命预算**——按环境与寿命反推工艺。

在下一节，我们将从「表面再造一层替身」回到「材料自身的特技」——看某些金属如何靠一层自发形成的氧化膜把自己保护起来，这就是《钝化与钝化膜》。
