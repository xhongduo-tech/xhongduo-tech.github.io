## 为什么从应力腐蚀开裂开始

锅炉爆裂、桥梁坍塌、航空紧固件断裂，许多灾难性事故的断口上找不到明显的腐蚀坑，只有一道道「树枝」般的裂纹，从表面悄然伸入金属内部。这类失效叫**应力腐蚀开裂（SCC, stress corrosion cracking）**：**金属在拉应力与特定腐蚀介质的共同作用下，发生脆性开裂**。<span class="marginnote">SCC 的可怕在于它「无预警」：没有明显减薄、没有点蚀坑，裂纹一旦起裂就不断扩展，到临界长度时瞬间失稳。现场常把这种断口比作「陶瓷裂法」——宏观脆断，几乎没有塑性变形。</span>与它常常被混为一谈的是**氢脆（hydrogen embrittlement）**——不是「腐蚀吃掉金属」，而是「氢原子钻进金属把它变脆」。两者的表象相似（脆断）、诱因常重叠（阴极反应产氢）、防护却不同，本节把这对「姊妹病」放在一起辨析。<span class="marginnote">衔接：本课把《腐蚀电极过程动力学与极化曲线》的阴极反应（析氢）与《晶间腐蚀》的裂纹路径结合起来，还牵涉力学中的应力强度因子概念——腐蚀学科里最典型的交叉课题。</span>

## 1 SCC 的三要素：材料、介质、应力

SCC 不是任何组合都发生，它需要**三要素同时满足**：

**敏感材料**：不同材料对特定介质的 SCC 敏感。奥氏体不锈钢对氯离子敏感，碳钢对苛性碱（$\ce{NaOH}$）与硝酸盐敏感，黄铜对氨敏感——「材料—介质」是配对的。

**特定介质**：常常是浓度不高、选择性极强的介质。氯离子浓度哪怕只有几十 ppm，配合高温，就能让 304 不锈钢 SCC。<span class="marginnote">经典配对表是 SCC 研究的入门课：不锈钢–氯化物、不锈钢–高温水、碳钢–$\ce{NaOH}$、黄铜–氨、钛–甲醇。反过来，「万能腐蚀介质」并不引发 SCC——SCC 需要「刚刚好」的选择性攻击。</span>

**拉应力**：包括外加载荷与**残余应力**。焊接残余应力、冷加工残余应力常常就是 SCC 的应力来源——许多 SCC 事故发生在几乎没有外载的部件上，罪魁正是残余应力。

裂纹路径有两种：**穿晶型（transgranular）**裂纹穿过晶粒，如不锈钢的氯化物 SCC；**沿晶型（intergranular）**沿晶界走，如敏化不锈钢在高温水中的 SCC。断口形貌是诊断 SCC 的重要线索。

**残余应力是 SCC 的头号应力来源**：焊接残余应力可达屈服强度量级，冷弯、冷轧、淬火留下的残余拉应力同样可观。许多 SCC 事故发生在几乎无外载的储罐、管件上——残余应力「单独作案」。因此 SCC 防护清单里几乎必有**去应力退火**与**表面压应力处理**（喷丸、滚压）两项：前者消除拉应力，后者把表层应力改成压应力——压应力状态对 SCC 和氢脆都不友好，是「一箭双雕」的表面强化手段。

## 2 公式解析：应力强度因子与 KISCC

SCC 的工程判据建立在断裂力学上。含裂纹构件在拉应力 $\sigma$ 下的裂纹尖端应力场由**应力强度因子 $K$** 描述：

$$K = Y \sigma \sqrt{\pi a}$$

$a$ 是裂纹半长，$Y$ 是几何因子。<span class="marginnote">直觉：裂纹越长、应力越大，尖端应力集中越强，$K$ 越大。当 $K$ 超过材料断裂韧性 $K_{IC}$ 就瞬间断裂——但 SCC 的麻烦在于，腐蚀让裂纹在远低于 $K_{IC}$ 的载荷下慢慢长大。</span>

对每一「材料–介质」体系，存在一个**应力腐蚀开裂门槛值 $K_{ISCC}$**：

**当 $K \lt  K_{ISCC}$**：裂纹不扩展，构件安全——设计准则就是把工作 $K$ 压到 $K_{ISCC}$ 以下。
**当 $K \ge K_{ISCC}$**：裂纹以一定速率（Ⅱ阶段平台）扩展，直至失稳断裂。

**第一步，读门槛**：$K_{ISCC}$ 通常只有 $K_{IC}$ 的 20–50%，说明腐蚀让材料「提前脆断」。
**第二步，反推允许应力**：由 $K_{ISCC} = Y\sigma_{\max}\sqrt{\pi a}$，给定检测出的裂纹尺寸，就能算出许用应力——无损检测（NDT）发现裂纹后「能不能继续用」，就是用这个式子做剩余寿命评估。注意这里的关键不是 $\sigma$ 单独多大，而是 $\sigma\sqrt{a}$ 的组合：**裂纹再小、应力再高也可能危险，应力再低、裂纹够长也危险**——两者按乘积共同决定安全边界，这正解释了「表面小划痕在 SCC 里可能成为致命起裂点」的直觉。
**第三步，工程推论**：**降低应力、减小裂纹尺寸、选高 $K_{ISCC}$ 材料**，三者都能把构件拉回安全区。

## 3 氢脆：氢原子如何把钢变脆

**氢脆（hydrogen embrittlement）** 的链条是：氢原子在金属表面产生（腐蚀阴极析氢、酸洗、电镀、焊接潮湿气氛）→ 吸附 → 渗入晶格并扩散 → 在裂纹尖端、夹杂界面、晶界富集 → 降低原子键合力或产生氢压 → 材料脆断。

氢脆的代表机理有两派（常共存）：

**氢压理论**：氢在缺陷处复合成 $\ce{H2}$ 分子，局部氢压可达数千大气压，把微裂纹撑开——多见于高氢含量场景。

**氢降低原子键合力理论（HEDE）**：富集的氢降低铁原子键的断裂强度，使裂纹尖端在更低应力下开裂。<span class="marginnote">此外还有氢促进局部塑性（HELP）理论：氢促进位错运动、降低局部屈服强度，让裂纹沿氢富集带扩展。三种机理并存，工程上只需记住结论——<strong>氢让钢变脆，且对高强钢最致命</strong>。</span>

最危险的应用场景是**硫化物应力开裂（SSC）**：油气田含 $\ce{H2S}$，$H_2S$ 抑制氢原子复合成分子氢，迫使氢大量进入钢中。高强钢油管在湿硫化氢环境里，无外载都可能沿晶界开裂——因此 API 标准对含硫油气用钢有硬度上限（HRC ≤ 22）的要求，本质就是限制「氢脆敏感度」。

氢的来源不止服役环境，**制造工艺也常引入氢**：酸洗（除锈用酸会产生氢）、电镀（阴极析氢不可避免）、焊接（潮湿焊条分解出水）、甚至潮湿大气中的腐蚀本身。因此对高强钢零件，规范常要求**酸洗/电镀后 150–200 °C 除氢烘烤**数小时，把已进入的氢赶出去——这是制造环节对氢脆的第一道闸门，成本低、收益大，却最容易被省略。

## 4 对照：SCC 与氢脆，一对姊妹病

SCC 与氢脆极易混淆，对照见下：

| 维度 | 应力腐蚀开裂（SCC） | 氢脆（HE） |
| --- | --- | --- |
| 本质 | 阳极溶解型：腐蚀沿裂纹尖端溶解 | 阴极产物型：氢原子进入金属致脆 |
| 需要介质 | 特定的腐蚀介质（氯、碱、氨…） | 只需氢来源（析氢、酸洗、$\ce{H2S}$） |
| 应力条件 | 拉应力（含残余应力），可为静载 | 应力可有可无，无应力也能脆化 |
| 材料敏感性 | 取决于材料–介质配对 | 高强钢、马氏体钢最敏感 |
| 裂纹特征 | 穿晶或沿晶，常带分支 | 无分叉的平直裂纹，断口「发丝」状 |
| 恢复性 | 卸载并去介质后裂纹仍存在（不可逆） | 除氢后部分韧性可能恢复（可逆） |

**判别口诀：SCC 是「腐蚀在应力帮助下走」，氢脆是「氢钻进金属让裂纹自己走」**。两条机理还可能在同一结构里先后登场：SCC 裂纹尖端的阳极溶解会释放氢（局部析氢），这些氢渗入裂纹前方金属，可能叠加诱发氢脆——**工程上把这类「阳极溶解 + 氢致开裂」的耦合称为环境敏感断裂（ESF）**，处理起来比单看其中任一种都要谨慎。阴极保护本是防腐手段，但在高强钢上可能因为加强析氢而诱发氢脆——这是《阴极保护与阳极保护》里要特别小心的副作用。<span class="marginnote">现场区分技巧：SCC 裂纹常沿垂直于主应力方向、有树枝状分支；氢脆断口平齐、无塑性。实验室则用电化学手段区分——SCC 在阳极极化下加速，氢脆在阴极极化（加强析氢）下反而加速。</span>

## 5 辨析｜易错点：四句常被引错的判断

**「不锈钢不会 SCC」**：恰恰相反，奥氏体不锈钢是氯化物 SCC 的重灾区，尤其是含 $\ce{Cl^-}$ 的高温溶液。304 比 316 更敏感，而铁素体不锈钢、双相不锈钢抗 SCC 能力更强——选材要按 SCC 敏感度而非一般耐蚀性。

**「把应力去掉就没事了」**：去应力能预防 SCC，但对已经进入金属的氢，除氢需要加热（如 150–200 °C 烘烤）且并非总能恢复——氢脆有不可逆部分，预防永远优于补救。

**「阴极保护一定安全」**：在敏感材料上，阴极保护的析氢副反应可能诱发氢脆（SSC 就是典型）。含硫油气、超高强钢场景里，保护电位要精确控制，不能一味拉负。<span class="marginnote">电位窗口概念因此重要：既要负到足以免蚀（《腐蚀热力学与电位-pH 图》的免蚀区），又不能负到大量析氢。这个「窗口」是阴极保护设计的关键约束，见《阴极保护与阳极保护》。</span>

**「SCC 只发生在腐蚀环境」**：介质浓度可极低、环境可看似「干净」（如纯水汽、微量氨），SCC 照样发生。判定要用专门的 SCC 试验（如 U 形弯试样、C 形环）而非直觉。

### 核心概念速查

| 概念 | 一句话定义 | 判据/特征 |
| --- | --- | --- |
| SCC 三要素 | 敏感材料 + 特定介质 + 拉应力 | 缺一不可 |
| 应力强度因子 | $K = Y\sigma\sqrt{\pi a}$ | 裂纹尖端应力场强度 |
| $K_{ISCC}$ | SCC 裂纹扩展的门槛应力强度 | 通常为 $K_{IC}$ 的 20–50% |
| 穿晶/沿晶 | 裂纹穿晶粒或沿晶界 | 断口形貌诊断线索 |
| 氢脆 | 氢原子渗入金属致脆 | 高强钢最敏感 |
| SSC | 湿 $\ce{H2S}$ 环境下的氢脆开裂 | 有硬度上限 HRC ≤ 22 |

### 一个现场事故复盘：锅炉水冷壁的苛性 SCC

某燃煤电厂锅炉水冷壁管（碳钢）运行约 6 万小时后发生爆管。切开检查：管壁未见明显减薄，裂纹从内壁沿晶界扩展、呈树枝状分支，断口无塑性变形——典型的沿晶 SCC 形貌。

**环境溯源**：锅炉水质控制波动，局部碱度过高（$p$ 碱度异常升高），在管壁沉积物下形成局部浓缩的 $\ce{NaOH}$ 溶液——碳钢在苛性碱中正是「敏感材料 + 特定介质」的经典配对。拉应力来自水冷壁的膨胀约束与焊接残余应力。

**机理链**：$\ce{NaOH}$ 局部浓缩溶解钝化膜 → 裂纹尖端裸露金属阳极溶解 → 应力使裂纹张开 → 尖端再暴露、再溶解，循环往复。这种「膜破—溶解—再破」的机制属于阳极溶解型 SCC，与氢脆机理不同。

**对策**：严格锅炉水质（控制游离碱）、消除沉积物、焊后去应力退火、改用耐碱钢种。复盘要点：**SCC 事故的共性是「三要素同时在场」，排查顺序先介质、再应力、后材料**。
