# 中学语文课程体系（阅读、写作、古诗文与语言文字运用的教学体系）

中学语文课程是国家规定的母语教育体系，以《义务教育语文课程标准（2022年版）》与《普通高中语文课程标准》为纲，系统培养阅读理解、写作表达、古诗文积累与语言文字运用四大能力。这是国民语文素养的根基，也是高考语文命题与教学设计的直接依据。

## 对标教材

- 中华人民共和国教育部《义务教育语文课程标准（2022年版）》（北京师范大学出版社）
- 中华人民共和国教育部《普通高中语文课程标准（2017年版2020年修订）》（人民教育出版社）
- 叶圣陶、夏丏尊《文心》（生活·读书·新知三联书店）
