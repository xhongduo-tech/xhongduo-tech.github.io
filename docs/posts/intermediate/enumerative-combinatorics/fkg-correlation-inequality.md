## 为什么从 FKG 开始

Lovász 局部引理处理的是「事件彼此纠缠但依赖稀疏」的情形。但有一大类问题恰恰相反：事件**彼此正相关**——一个发生了，另一个也更可能发生。随机图里「含三角形」与「含哈密顿圈」就是这样：图越密，两者都越容易出现。**FKG 不等式（Fortuin–Kasteleyn–Ginibre, 1971）**精确刻画了这种正相关：两个单调事件同时发生的概率，不小于各自概率之积。<span class="marginnote">FKG 的名字来自荷兰数学物理学家 Fortuin、Kasteleyn 与英国统计物理学家 Ginibre。它在统计物理（Ising 模型、渗流）里是标准工具，而乘积测度情形的特例由 Harris 在 1960 年先证得，故常称 <strong>Harris–FKG 不等式</strong>。</span>

FKG 填补了概率方法的另一块拼图：LLL 管「负依赖 / 稀疏依赖」，FKG 管「正依赖」。两者合起来，概率方法对「依赖」的掌握才算完整。

## 1 单调事件：概率论里的「单调函数」

先立一个概念。在**乘积空间** $\{0,1\}^n$ 上（每个坐标独立地取 0 或 1），一个事件 $A$ 称为**单调递增（increasing）**，若把任一结果里的 0 改成 1（「加料」），不会把「属于 $A$」变成「不属于 $A$」。翻译成人话：**$A$ 一旦发生，再多加一点「好东西」也不会让 $A$ 消失**。<span class="marginnote">例如「至少 $k$ 个坐标是 1」「图中含一条哈密顿圈」「图中连通」都是递增事件；「至多 $k$ 个坐标是 1」是递减事件。判断口诀：<strong>把 0 变 1 会不会破坏事件？不破坏 → 递增</strong>。</span>

随机图 $G(n,p)$ 天然是个乘积空间：每条边独立地以概率 $p$ 出现，坐标 = 边。于是「图的性质」都是事件，其中「添加边仍保持」的性质就是递增事件——**连通性、哈密顿性、有三角形、有 $k$-团、无孤立点**，全都是递增事件。<span class="marginnote">「无孤立点」为什么递增？多一条边只会让孤立点更少，不会「制造」孤立点。注意递增性是关于<strong>添加元素</strong>的单调，与事件的具体内容是两回事。</span>

## 2 FKG 不等式：正相关的形式化

**FKG 不等式**：设 $f, g$ 是 $\{0,1\}^n$ 上（关于坐标逐点序）**递增**的非负函数，$\mu$ 为乘积测度，则

$$E_\mu[fg] \ge E_\mu[f]\,E_\mu[g]$$

对**指示函数**版本：若 $A, B$ 都是递增事件，则

$$P(A \cap B) \ge P(A)\,P(B)$$

**两个单调事件同时发生，比它们「各管各」更常见**。这个方向正是「正相关」的定义——知道 $A$ 发生了，$B$ 的条件概率不低于无条件概率：$P(B\mid A) \ge P(B)$。<span class="marginnote">直觉：递增事件都「爱添加」。$A$ 发生说明样本「偏大」，而 $B$ 也偏好大样本，于是「样本既够大又够大」的机会被双重加持。<strong>两个只往上看的性质，总是一起出现得比随机更频繁</strong>。</span>

**辨析｜易错点：** FKG 对「两个都递增」或「两个都递减」成立（正相关）；对「一增一减」成立**反向**不等式 $P(A\cap B) \le P(A)P(B)$（负相关）。用之前先判单调方向，方向判错不等式就反了。

一个最小的数值验证。取 $n=3$ 个独立硬币，$A$ = 「至少 2 个正面」，$B$ = 「第一枚是正面」。两者都递增。$P(A) = \frac{4}{8} = \frac12$（111、110、101、011），$P(B) = \frac12$。而 $A\cap B$ = 「第一枚正面且至少两枚正面」= 111、110、101，$P(A\cap B) = \frac38$。$\frac38 \ge \frac12\cdot\frac12 = \frac14$ ✓——**正相关在最小例子里直接可见**。

## 3 应用：随机图的单调性质

FKG 在随机图里最典型的应用是「**双性质下界**」：想证明「图同时有 $A$ 和 $B$」的概率不低，不用分别估计再相乘，而是直接

$$P(A \cap B) \ge P(A)\,P(B)$$

这看似把目标「拆小了」，实则极有用：**已知 $P(A)$、$P(B)$ 各至少是某个量，立刻得到交事件的同阶下界**，而直接估计交事件往往困难得多。

一个具体例子：在 $G(n,p)$ 中，设 $A$ = 「含至少一个三角形」，$B$ = 「连通」。两者都递增，故

$$P(\text{连通且含三角形}) \ge P(\text{连通}) \cdot P(\text{含三角形})$$

当 $p$ 处于「连通大概率」与「三角形大概率」的交叠区，乘积下界直接给出「连通又有三角形」的正概率——**FKG 用一条不等式省掉了一整场精细估计**。<span class="marginnote">渗流理论里，「左上角到右下角存在通路」是两个递增事件「存在上下通路」「存在左右通路」的交，FKG 常被用来证明渗流阈值处「两条通路同时出现」的正概率。<strong>同一台机器，从随机图开到渗流，再到 Ising 模型</strong>——FKG 是统计物理与组合学的通用桥梁。</span>

## 4 渗流与统计物理：FKG 的家乡

FKG 并非诞生于组合学，而是诞生于**统计物理**。最典型的舞台是**键渗流（bond percolation）**：在平面网格 $\mathbb{Z}^2$ 上，每条边以概率 $p$ 独立地「开通」。考虑两个递增事件——「存在一条从左到右的连通通路」与「存在一条从上到下的连通通路」。FKG 立刻给出

$$P(\text{横贯 } \wedge \text{ 纵贯}) \ge P(\text{横贯})\cdot P(\text{纵贯})$$

在渗流阈值 $p_c$ 附近，两个方向各自「几乎必通」，FKG 的乘积下界直接论证了「同时横贯又纵贯」的正概率——这曾是渗流相变理论的关键一步。<span class="marginnote">Ising 模型中，两个自旋都取「向上」的概率与各自之积相比同样满足 FKG（此时称为 <strong>Griffiths 不等式</strong>）。<strong>FKG 把「正相关」当作普适原理</strong>：凡是在格点模型里「往大里加」不破坏的性质，都被正相关绑在一起。</span>

**FKG 的数学环境**：证明只依赖 $\{0,1\}^n$ 上的逐点序构成一个**分配格（distributive lattice）**——并 $S\cup T$ 与交 $S\cap T$ 满足分配律。凡是有这种结构的概率空间，FKG 都能搬过去；而分配格的概念，正是第二级《格论与序理论》的主角。

## 5 FKG 的边界：正相关的另一面

FKG 说「单调事件都正相关」，但现实里**负相关同样无处不在**，此时 FKG 的方向帮不上忙。典型场景：在随机图里，「两个**不相交**边集上都出现某种结构」的事件之间，往往呈负相关——一个位置占用了「随机性」，另一个位置就被挤占。<span class="marginnote">处理「大量稀有事件、彼此负相关」的工具有：<strong>Janson 不等式</strong>（给「至少一个坏事件发生」的上界）、以及本专题的 LLL（给「一个都不发生」的下界）。<strong>FKG 管正相关，Janson/LLL 管负相关</strong>，概率方法的工具箱由此配齐。</span>

**辨析｜易错点：** 别把 FKG 用在「互斥」事件上。$A$ = 「第一枚硬币正面」，$B$ = 「第一枚硬币反面」：$B$ 是递减事件，FKG 的反向不等式给出 $P(A\cap B) \le P(A)P(B) = \frac14$，而真实值 $P(A\cap B)=0$——**反向不等式成立，但太松**。FKG 是「方向正确的软界」，不是「紧界」；它保证符号方向，不承诺精度。

一个实用的推论常被单独命名：若 $A_1,\dots,A_m$ 全是递增事件，则

$$P(\bigcap_i A_i) \ge \prod_i P(A_i)$$

这比两两版本强得多——**一串单调事件「全都发生」的概率，至少是各自概率的乘积**。这看起来像「独立事件」的公式，但 FKG 告诉你：**正相关事件共享这个下界，哪怕它们远非独立**。

至此，概率方法的主要工具已全部登场，一张对照表收束本节：

| 工具 | 依赖类型 | 结论方向 | 关键条件 |
| --- | --- | --- | --- |
| 第一矩 / 期望 | 任意 | 存在性（有下界/上界） | $E[X]\ge c$ 或 $E[X]\lt 1$ |
| 第二矩 | 弱相关 | 几乎必然（集中） | $\operatorname{Var}/E^2\to0$ |
| LLL | 稀疏依赖 | 全部避开（正概率） | $ep(d+1)\le1$ |
| FKG | 正相关 | 交概率下界 | 事件同向单调 |



## 6 公式解析：由四函数定理证明 FKG

FKG 在乘积测度下的证明，最干净的路由是 **Ahlswede–Daykin 四函数定理（1978）**。先看这个定理：

**四函数定理**：设 $\alpha,\beta,\gamma,\delta$ 是 $\{0,1\}^n$ 上的非负函数，满足对任意 $S, T$：

$$\alpha(S)\,\beta(T) \le \gamma(S \cup T)\,\delta(S \cap T)$$

则 $\left(\sum_S \alpha(S)\right)\left(\sum_T \beta(T)\right) \le \left(\sum_S \gamma(S)\right)\left(\sum_T \delta(T)\right)$。

四步推出 FKG：

- **第一步，选取四函数**：令 $\alpha = f$、$\beta = g$、$\gamma = fg$、$\delta \equiv 1$。
- **第二步，验证条件**：对任意 $S,T$，$\alpha(S)\beta(T) = f(S)g(T)$，而 $\gamma(S\cup T)\delta(S\cap T) = f(S\cup T)\,g(S\cup T)$。因为 $f,g$ 递增且 $S,T \subseteq S\cup T$，有 $f(S)\le f(S\cup T)$、$g(T)\le g(S\cup T)$，故条件成立。
- **第三步，套定理**：$(\sum f)(\sum g) \le (\sum fg)(\sum 1) = (\sum fg)\cdot 2^n$。
- **第四步，归一化**：除以 $2^n\cdot 2^n$，得 $\frac{\sum f}{2^n}\cdot\frac{\sum g}{2^n} \le \frac{\sum fg}{2^n}$，即 $E[f]E[g] \le E[fg]$。∎

**「四函数定理 → FKG」全程只需代入与检查递增性**——一个漂亮的泛化定理，把证明压缩成了两次代数代入。

还有一个更「概率论」的证明路径，直觉上更直接：取两个独立样本 $X, Y$，构造 $X' = X \vee Y$（逐坐标取大）、$Y' = X \wedge Y$（逐坐标取小）。$X'$ 与 $Y'$ 的边缘分布分别同 $X$、$Y$（因为坐标独立且同分布），而 $f,g$ 递增使得「两个都大」的配对比「一大一小」更重——逐坐标展开后得到 $E[f(X)g(Y)] \le E[f(X')g(Y')] = E[f]E[g]$ 的等价形式。**两条证明路，一条靠代数的四函数定理，一条靠概率的耦合**，殊途同归。

## 7 小结

- **单调事件**：把 0 变 1 不破坏的事件；随机图的连通性、三角形、哈密顿圈都是递增事件。
- **FKG**：$f,g$ 递增 ⇒ $E[fg]\ge E[f]E[g]$
