## 为什么从对称函数开始

二次方程的判别式 $b^2 - 4ac$ 关于 $a,b,c$ 的意义，在于「交换根不改变」；任何多项式方程，其系数都是根的对称表达式。这个朴素的观察在 18 世纪经拉格朗日与高斯发酵，最终长成整棵 Galois 理论的参天大树。**对称函数（symmetric function）**研究的就是：交换变量后不变的函数。<span class="marginnote">它也是计数组合学的「大结局」之一：前几节的整数分拆（Young 图）、Pólya 定理（轮换指标）、生成函数，在对称函数里汇聚成一栋统一的建筑——分拆是它的指标，轮换指标是它的一员，而它又通向表示论这一整片大陆。</span>

## 1 什么是对称函数

**对称函数（symmetric function）**：有限变量 $x_1, x_2, \dots, x_n$ 上的多项式，在任意置换变量下保持不变。例如 $n=3$ 时 $x_1^2 + x_2^2 + x_3^2$ 对称，而 $x_1$ 不对称。<span class="marginnote">「函数」其实是「多项式」的宽松叫法。变量个数可以任意大甚至无穷，此时称<strong>对称函数环</strong> $\Lambda$；固定 $n$ 个变量则记 $\Lambda_n$。计数组合学里经常让 $n$「足够大」，让分拆 $\lambda$ 的长度不越界。</span>

为什么要研究它们？因为**对称函数构成了一个丰富的代数结构**：所有对称函数在加法、乘法下封闭，构成一个环。这个环有多套「基底」，每套基底都有清晰的组合意义，而**同一对象在不同基底下的展开**则编码着深刻的计数信息。

## 2 五套经典基底

设 $\lambda = (\lambda_1,\dots,\lambda_k) \vdash m$ 是 $m$ 的一个分拆（衔接《整数分拆》）。五个最重要的对称函数族：

**单项式对称函数** $m_\lambda$：所有「把指数排成分拆 $\lambda$」的单项式之和。例如 $m_{(2,1)} = x_1^2x_2 + x_1^2x_3 + x_2^2x_1 + \cdots$。
**初等对称函数** $e_k = \sum_{i_1 \lt  i_2 \lt  \cdots \lt  i_k} x_{i_1}x_{i_2}\cdots x_{i_k}$，并约定 $e_\lambda = e_{\lambda_1}\cdots e_{\lambda_k}$。<span class="marginnote">$e_k$ 的组合意义是「从 $n$ 个变量里<strong>不重复</strong>地选 $k$ 个相乘」——恰好是《组合数学》的组合数在代数里的化身；下标严格递增，对应「无标签选择」。</span>
**完全齐次对称函数** $h_k = \sum_{i_1 \le i_2 \le \cdots \le i_k} x_{i_1}\cdots x_{i_k}$，$h_\lambda = h_{\lambda_1}\cdots h_{\lambda_k}$。下标**非降**，允许重复——对应「多重集选择」，与 $e_k$ 形成镜像。<span class="marginnote">$e_k$（严格递增）与 $h_k$（非降）的差别，正是《普通生成函数与指数生成函数》里「无标签/有标签」的又一次回响：$e$ 管子集，$h$ 管多重集。</span>
- **幂和对称函数** $p_k = x_1^k + x_2^k + \cdots + x_n^k$，$p_\lambda = p_{\lambda_1}\cdots p_{\lambda_k}$。
- **Schur 函数** $s_\lambda$：最深刻的一套基，可由**半标准 Young 表**的权重求和定义，也等于两个 Vandermonde 行列式的商。它与对称群、一般线性群的不可约表示一一对应。

**基本定理**：$\Lambda_n$ 可以由任意一套基生成——每个 $e_k$、每个 $h_k$、每个 $p_k$（$k=1,\dots,n$）都单独生成整个环：

$$\Lambda_n = \mathbb{Q}[e_1,\dots,e_n] = \mathbb{Q}[h_1,\dots,h_n] = \mathbb{Q}[p_1,\dots,p_n]$$

**基底之间可以互相展开**，而展开系数（如 $h_\lambda$ 用 $p$ 展开）正是数论与组合里的著名函数。这就是对称函数「深不可测」的根源：**一个组合对象同时拥有多个代数身份证**。

变量个数 $n$ 扮演着「天花板」的角色：在 $\Lambda_n$ 中，$e_{n+1} = e_{n+2} = \cdots = 0$，而 $h_k$、$p_k$ 不受此限。做题时先问一句「变量几个？」——它决定哪些恒等式还能用，是防止「套错环」的第一道闸门。

## 3 生成函数对：$E(t)$ 与 $H(t)$

把 $e_k$ 与 $h_k$ 分别装进生成函数，得到一个精妙的对偶：

$$E(t) = \sum_{k\ge0} e_k t^k = \prod_{i=1}^{n}(1 + x_i t), \qquad H(t) = \sum_{k\ge0} h_k t^k = \prod_{i=1}^{n}\frac{1}{1 - x_i t}$$

**$E$ 是「有限个因子的积」，$H$ 是「无限级数的积」**——一个管「每个变量至多选一次」，一个管「每个变量可任选多次」，乘积结构一目了然。两者相乘立刻得到：

$$E(t)\,H(-t) = \prod_{i}(1+x_i t)\cdot\prod_{i}\frac{1}{1 - x_i t} = 1$$

比较 $t^n$ 的系数，得到一组万能恒等式：对任意 $n\ge1$，

$$\sum_{k=0}^{n} (-1)^k e_k\, h_{n-k} = 0$$

这条恒等式是「初等与完全齐次互为镜像」的代数签名，也是后面无数展开的起点。<span class="marginnote">注意它与上一节 Pólya 定理的联系：若把 $x_i$ 看成「颜色权重」，$p_k$ 恰是「把颜色沿 $k$-轮换代入权重」的产物——轮换指标里的 $x_k$，在对称函数里就是幂和 $p_k$。两个主题在此焊接。</span>

$E(t)$ 与 $H(t)$ 还有一层生成函数教科书式的解读：$E(t)$ 是「全部由 $x_i$ 构成的有限子集」的生成函数，$H(t)$ 是「全部多重集」的生成函数。**「子集 vs 多重集」这对老对手，在对称函数里拥有各自的生成函数，并且互为倒数**——这与《普通生成函数》里 $\frac{1}{1-x}$ 与有限和的镜像关系一脉相承。

## 4 Schur 函数：通向表示论的门

$s_\lambda$ 的定义最直观的一条是**表求和**：对分拆 $\lambda$ 画 Young 图（《整数分拆》的 Ferrers 图），往格子里填正整数，要求行不减、列严格增（半标准 Young 表），则

$$s_\lambda = \sum_{\text{半标准表 } T} x^{\operatorname{wt}(T)}$$

其中 $x^{\operatorname{wt}(T)}$ 是各数字出现次数的单项式。例如 $\lambda = (2,1)$，$s_{(2,1)} = x_1^2x_2 + x_1^2x_3 + x_1x_2^2 + x_1x_2x_3 + \cdots$（无穷多个项，若变量无限）。<span class="marginnote">Schur 函数为什么重要？因为<strong>对称群不可约表示的特征标、$GL_n$ 的不可约多项式表示、格拉斯曼流形的上同调环</strong>……全都以 $s_\lambda$ 为坐标。把「数 Young 表」翻译成「数表示维数」，是组合数学 20 世纪最大的跨界之一。</span>

**辨析｜易错点：** 半标准表的规则是**行非降、列严格增**（不是行严格、列非降）。方向反了，$s_\lambda$ 就变成别的对象。另一个常见误解：$s_\lambda$ 是齐次的，次数等于 $|\lambda|$，验证对称性时先检查齐次次数总没错。

$s_\lambda$ 还有一条封闭行列式——**Jacobi–Trudi 恒等式** $s_\lambda = \det\big(h_{\lambda_i - i + j}\big)$——把表求和翻译成行列式。它是连接「计数」与「线性代数」的桥梁：$s_{(1,1)}$ 的行列式展开自动给出 $e_2$，$s_{(2)}$ 给出 $h_2$，一套公式同时承载初等与完全齐次两大基底。**分拆、Young 图、表、行列式，四个面孔指向同一个对象**——这就是对称函数在计数组合学里「大结局」地位的注脚。

## 5 基底互化：牛顿恒等式与轮换指标的会师

既然每套基都能生成整个环，**同一对象在不同基下的展开**就是组合信息最浓缩的地方。最常用的是把 $e_k$、$h_k$ 用幂和 $p_k$ 展开，桥梁是**牛顿恒等式（Newton's identities）**：

$$k\,e_k = \sum_{i=1}^{k}(-1)^{i-1} e_{k-i}\, p_i$$

取 $k=2$ 验算：$2e_2 = e_1 p_1 - p_2$。在 $n=2$ 个变量下，$e_1 = x_1+x_2$，$p_2 = x_1^2+x_2^2$，于是 $e_2 = \frac{(x_1+x_2)^2 - (x_1^2+x_2^2)}{2} = x_1x_2$——正确。**牛顿恒等式把「对称的代数」与「幂和的求和」连成递推**，与《递推关系求解》一节的工具完全同构。

更惊人的是 $h_k$ 的展开。对 $k$ 的所有分拆 $\lambda = (1^{m_1}2^{m_2}\cdots)$ 定义 $z_\lambda = \prod_i i^{m_i} m_i!$，则

$$h_k = \sum_{\lambda \vdash k} \frac{1}{z_\lambda}\, p_\lambda$$

例如 $k=3$：分拆 $1^3, 1^1 2^1, 3^1$ 对应 $z$ 值 $1^3\cdot3! = 6,\ 1\cdot2=2,\ 3$，故 $h_3 = \frac{1}{6}p_1^3 + \frac12 p_1p_2 + \frac13 p_3$。<span class="marginnote">这个系数 $\frac{1}{z_\lambda}$ 眼熟吗？它是<strong>对称群 $S_k$ 的轮换指标的系数</strong>——$Z(S_k) = \sum_{\lambda\vdash k} \frac{1}{z_\lambda} p_\lambda$。上一节 Pólya 定理里的轮换指标，在这里以「幂和对称函数」的身份再度出场：<strong>$h_k$ 恰好等于对称群轮换指标取 $p_i$ 为变量的值</strong>。两条主线正式会师。</span>

**辨析｜易错点：** $z_\lambda$ 的计算「先乘 $i^{m_i}$ 再乘 $m_i!$」，两者缺一不可：$i^{m_i}$ 来自「$m_i$ 个长度 $i$ 的轮换，每个轮换内部有 $i$ 种记法」，$m_i!$ 来自「$m_i$ 个同长轮换的排列」。把 $z_\lambda$ 写成 $1^{m_1}2^{m_2}\cdots m_1!m_2!\cdots$ 是规范记法，别漏了阶乘部分。

| 基底 | 定义 | 组合意义 |
| --- | --- | --- |
| $m_\lambda$ | 单项式对称化 | 按指数分拆分组 |
| $e_k$ | 严格递增下标乘积 | 子集选择 |
| $h_k$ | 非降下标乘积 | 多重集选择 |
| $p_k$ | $\sum x_i^k$ | 轮换指标变量 |
| $s_\lambda$ | 半标准表求和 | 表示论特征标 |

## 6 公式解析：$e_k$ 与 $h_k$ 的镜像恒等式

$$E(t)H(-t) = 1 \quad\Longleftrightarrow\quad \sum_{k=0}^{n}(-1)^k e_k h_{n-k} = 0$$

这条式子逐步拆开看：

- **第一步，$E(t)$ 是什么**：$\prod_{i=1}^n(1+x_i t)$。展开时从每个因子选 $t$ 或 $1$，恰好选 $k$ 个「$x_i t$」时系数是所有「$k$ 个不同变量之积」的和——这就是 $e_k$。
- **第二步，$H(t)$ 是什么**：$\prod_i\frac{1}{1-x_i t} = \prod_i(1 + x_i t + x_i^2 t^2 + \cdots)$。每个变量可以重复选，$t^k$ 的系数是所有「$k$ 个变量的多重集之积」的和——这就是 $h_k$。
- **第三步，相乘为何为 1**：对每个 $i$，$(1+x_it)\cdot\frac{1}{1-x_it}$ 各自相消成 1，整体乘积是 $1$——「有限」与「无限」两个积完美抵消。
- **第四步，读系数**：$E(t)H(-t)$ 中 $t^n$ 的系数是 $\sum_{k=0}^n e_k(-1)^{n-k}h_{n-k}$，恒等于 0。整理符号即得 $\sum_{k=0}^n (-1)^k e_k h_{n-k} = 0$。取 $n=2$ 验算：$e_0h_2 - e_1h_1 + e_2h_0 = h_2 - e_1h_1 + e_2$。而 $h_2 = e_1^2 - e_2$，$e_1 h_1 = e_1^2$，代回得 $0$。✓

**「一个乘积为 1」等价于「一族线性恒等式」**——这是生成函数方法最典型的收益：无穷多个恒等式被压缩成一个乘积。

## 7 小结

- **对称函数**：变量交换不变的函数，构成环 $\Lambda$；分拆是它的指标，衔接《整数分拆》。
- **五套基**：$m_\lambda, e_\lambda, h_\lambda, p_\lambda, s_\lambda$；每套基单独生成整个环，基底互化系数蕴含丰富计数。
- **生成函数对**：$E(t) = \prod(1+x_i t)$，$H(t) = \prod\frac{1}{1-x_i t}$，$E(t)H(-t) = 1$。
- **$e$ vs $h$**：严格递增 vs 非降，对应「子集 vs 多重集」。
- **Schur 函数**：半标准 Young 表求和，通向对称群与 $GL_n$ 的表示论。
- **基底互化**：牛顿恒等式 $ke_k=\sum(-1)^{i-1}e_{k-i}p_i$；$h_k = \sum_{\lambda\vdash k}z_\lambda^{-1}p_\lambda$。
- **通往表示论**：Schur 函数 $s_\lambda$ 是表示论的特征标与 $GL_n$ 表示论的坐标——「数 Young 表」与「数表示维数」在这里同义。

在下一节，我们将离开「精确计数」，转向概率方法的第一课：用期望与删除法证明「满足性质的对象存在」——这就是《概率方法：期望与删除法》。
