## 为什么从概率方法开始

前七节都在问「有多少个」，这一节开始问「**有没有**」。证明某个结构存在，传统做法是显式构造；但很多结构（足够大的 Ramsey 图、大的独立集、好的割）构造起来极其困难。**概率方法（probabilistic method）**另辟蹊径：**随机生成一个对象，若能证明它满足目标性质的概率为正，则满足性质的对象必然存在**——即使没人能亲手造出它。<span class="marginnote">概率方法由保罗 · 埃尔德什（Paul Erdős）在 1947 年对 Ramsey 数下界的证明中系统化，此后成为组合学的常规武器。它最反直觉的地方是：<strong>证明了存在性，却不给出任何构造</strong>——「存在但不具体」，这在数学里是完全合法的推理。</span>

这一节先学两种最基本的战术：**期望论证**（随机量的期望足够大/小，于是有某个取值达到它）与**删除法**（也叫 alteration，随机选一批再删掉坏元素）。它们是后续第二矩、Lovász 局部引理等全部进阶武器的地基。

## 1 概率方法的核心逻辑

概率方法的第一条原则简单到像废话：

$$P(\text{随机对象有性质 } P) > 0 \quad\Longrightarrow\quad \text{存在有性质 } P \text{ 的对象}$$

**区别只在视角**：与其「构造一个满足 $P$ 的对象」，不如「在全体对象上放一个概率分布，算 $P$ 成立的（正）概率」。组合证明关心存在性，概率语言关心度量——同一件事的两副面孔。<span class="marginnote">这个推理的有效性不依赖任何分布选择：只要你能设计一个分布使 $P$ 的概率为正，就赢了。分布选得巧，证明就短；分布选得差，概率算不出来。<strong>「选分布」是概率方法的艺术所在</strong>。</span>

由此派生两条常用推论：

- **期望推存在**：若 $X$ 的期望满足 $E[X] \ge c$，则存在某个对象使 $X \ge c$。
- **正概率推存在**：若 $P(X \ge c) > 0$，则存在对象使 $X \ge c$。

**辨析｜易错点：** $E[X] \ge c$ 只保证「存在 $X \ge c$ 的样本」，不保证「典型样本都 $\ge c$」——分布可能被少数极端值拉高。概率方法要的就是「有一个就行」，别把它误读成「大多数都行」。

由此也能看到概率方法与**随机算法**的分野（第三级《随机算法与概率方法》会系统讲）：概率方法只问「是否存在」，随机算法还要求「能否高效找到」。概率方法常常给出非构造性证明，而把它改造成 Las Vegas / Monte Carlo 算法，往往需要额外的技巧——**存在性易得，可验证性难得**。

## 2 期望论证：最大割

**最大割（Max Cut）**：给定无向图 $G=(V,E)$，把顶点分成两拨，数一数**跨在两拨之间的边**。问：最多能有多少条边跨过去？

随机给每个顶点独立地掷硬币定阵营。对每条边 $e$，它跨阵营当且仅当两端异侧，概率恰为 $\frac12$。定义指示变量 $X_e = 1$ 当且仅当 $e$ 跨割，则跨割边总数 $X = \sum_{e\in E}X_e$，由期望的线性性：

$$E[X] = \sum_{e\in E} E[X_e] = \sum_{e\in E}\frac12 = \frac{m}{2}$$

于是存在一个割，跨过的边数至少 $m/2$。<span class="marginnote"><strong>期望的线性性（linearity of expectation）不需要独立性</strong>——就算 $X_e$ 两两相关，$E[\sum X_e] = \sum E[X_e]$ 照样成立。这正是随机化证明常「白嫖」独立性的地方，也是与《概率论与数理统计》里期望定义直接接轨的点。</span>

**这个证明没有任何构造**——掷完硬币你得检查、修修补补才知道割在哪儿，但证明已经向你保证：那样的割存在。这是「非构造性存在证明」的标准范例。

## 3 删除法：独立集

期望论证直接给出「存在好的东西」；但有时随机选出的对象「基本好，只有少量坏」，这时用**删除法（alteration）**：把坏的删掉，剩下的就是好的。

**定理**：$n$ 个顶点、$m$ 条边的图，必含大小至少 $\frac{n^2}{4m}$ 的独立集。

证明分三步。**第一步，随机采样**：每个顶点以概率 $p$ 独立地入选，得集合 $S$。**第二步，数期望**：$E[|S|] = np$；$S$ 内部出现的边数期望为 $mp^2$（每条边要两端都入选）。**第三步，删除**：把 $S$ 中每条内部边的某一端删掉，剩下的集合独立，其期望大小至少

$$np - mp^2$$

令 $p = \frac{n}{2m}$（要求 $p\le1$，即 $m\ge n/2$；否则图太稀疏，$n/2 \le n^2/(4m)$ 显然成立），得

$$np - mp^2 = \frac{n^2}{2m} - \frac{n^2}{4m} = \frac{n^2}{4m}$$

**期望为正就存在**：有一个独立集大小至少 $\frac{n^2}{4m}$。<span class="marginnote">删除法的通用配方：<strong>随机选（期望好）→ 数坏元素（期望坏）→ 删掉坏元素（期望最终好）</strong>。坏元素的期望必须小于好元素的期望，最终的净期望才为正。这个「坏小于好」的博弈，是删除法每一题的题眼。</span>

**辨析｜易错点：** 删除法得到的独立集大小是「期望下界」，**不是**「总能达到的下界」——同一个随机过程每次结果不同，但期望保证至少存在一次结果达到下界。别把「存在性」写成了「必然性」。

## 4 锦标赛的支配集：一个精致的期望应用

**锦标赛（tournament）**是有向完全图：任意两顶点之间恰有一条定向边。**支配集（dominating set）**是这样一个顶点集 $D$：对每个不在 $D$ 里的顶点 $v$，都存在 $u\in D$ 使边 $u \to v$（$u$ 支配 $v$）。问：$n$ 个顶点的锦标赛，支配集最小可以多小？

随机选 $k$ 个顶点构成 $D$。对固定顶点 $v$，$D$ 中「没有人支配 $v$」当且仅当这 $k$ 个点都不在「指向 $v$」的入邻集里，概率为 $\left(\frac12\right)^k$。于是**未被支配的顶点数**的期望为 $n/2^k$。取 $k = \lceil \log_2 n\rceil$，这个期望小于 1：

$$E[\text{未被支配数}] = \frac{n}{2^k} \le 1$$

期望小于 1 意味着存在一次随机，未被支配的顶点数为 0——把 $D$ 补上这些未支配点，得到支配集大小至多 $k + \frac{n}{2^k} \le \log_2 n + 1$。<span class="marginnote">这个结果至今没有更小的显式构造匹配，而概率证明只花了三行。<strong>「概率告诉你有多好，构造却追不上」</strong>，是概率方法最令构造主义者牙痒、也最令它迷人的特质。</span>

## 5 第一矩方法：马尔可夫不等式与 Ramsey 下界预告

期望论证还有一位「更尖锐的兄弟」——**第一矩方法（first moment method）**，它建立在马尔可夫不等式上：对非负随机变量 $X$ 与 $t>0$，

$$P(X \ge t) \le \frac{E[X]}{t}$$

取 $t=1$ 得到 $P(X\ge1) \le E[X]$。于是若 $E[X] \lt  1$，则 $P(X=0) > 0$——**「坏的期望小于 1」直接推出「存在零坏」**。这比「期望为正就存在」进了一步：它给了存在性一个概率意义上的「几乎」保证。

用它重证 Erdős 的经典下界。把完全图 $K_n$ 的每条边独立地随机染红或蓝。设 $X$ = 单色 $K_k$ 子团的个数。固定一个 $k$ 点子集，它全红或全蓝的概率是 $2\cdot 2^{-\binom{k}{2}}$，故

$$E[X] = \binom{n}{k}\, 2^{1-\binom{k}{2}} \lt  \frac{n^k}{k!}\cdot 2^{1-\binom{k}{2}}$$

取 $n = 2^{k/2}$：$E[X] \lt  \frac{2^{k^2/2}}{k!}\cdot 2^{1-k(k-1)/2} = \frac{2^{(k+2)/2}}{k!} \lt  1 \quad (k \ge 4)$

于是存在一种染色，$K_n$ 中没有单色 $K_k$——这正是 $R(k,k) > 2^{k/2}$ 的证明。<span class="marginnote">这是概率方法史上第一炮（Erdős, 1947）。注意我们只证明了「存在一种好染色」，并不知道它长什么样；而且 $n$ 越大，这种好染色的比例反而越低——<strong>存在性与典型性在这里彻底分道扬镳</strong>。完整的 Ramsey 下界与 Turán 定理将在本专题最后一节展开。</span>

**辨析｜易错点：** 第一矩方法要求 $X$ 非负且 $t>0$。$E[X]\lt 1$ 推出 $P(X=0)>0$，但若 $E[X]$ 略大于 1 就什么也推不出——马尔可夫界在「略大于」时非常松。**第一矩适用于「坏事件期望指数小」，不是「期望略小」**。

## 6 公式解析：最大割的期望论证

$$E[X] = \sum_{e\in E}\frac12 = \frac{m}{2}$$

四步拆解这条「白给」的式子：

- **第一步，设计随机模型**：每个顶点独立等概率分到左右两边，共有 $2^n$ 种等可能割。
- **第二步，写指示变量**：$X_e = 1$ 当且仅当边 $e$ 跨割。则 $X_e$ 只取 $0$ 或 $1$，$E[X_e] = P(X_e=1)$。
- **第三步，算单边概率**：$e = (u,v)$ 两端异侧——$u$ 定了之后 $v$ 有 $\frac12$ 概率在对面，故 $P(X_e=1) = \frac12$。
- **第四步，期望线性**：$X = \sum_e X_e$，$E[X] = \sum_e \frac12 = m/2$。**不要求 $X_e$ 独立**，这正是期望线性的力量。

最后一步再点一句：$E[X] = m/2$ 意味着 $\max_{\text{割}} X \ge m/2$——**随机量的最大值至少不小于期望**，因为若所有割都小于 $m/2$，期望不可能等于 $m/2$。这一句话就是「期望推存在」的全部机理。

## 7 小结

- **概率方法**：$P(\text{性质})>0 \Rightarrow$ 存在性——非构造性证明的典范，由 Erdős 系统化。
- **期望论证**：$E[X]\ge c \Rightarrow$ 存在 $X\ge c$；期望的线性性不要求独立性。
- **删除法**：随机选 → 数坏 → 删坏；坏期望必须小于好期望，净期望为正即存在。
- **经典结果**：任意图有 ≥ $m/2$ 的割；有 ≥ $\frac{n^2}{4m}$ 的独立集；$n$ 顶点锦标赛有 ≤ $\log_2 n + 1$ 的支配集。
- **第一矩方法**：$P(X\ge1)\le E[X]$，$E[X]\lt 1 \Rightarrow$ 存在零坏；Erdős 用它证明 $R(k,k)>2^{k/2}$
