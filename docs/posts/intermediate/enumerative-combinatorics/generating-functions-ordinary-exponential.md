## 为什么从生成函数开始

计数问题的麻烦在于：我们常常要的不是孤零零一个数，而是一整族数——「把 $n$ 个对象按某种规则摆放有几种方法」，$n$ 每变一次就给出一个新答案。与其逐个硬数，不如把这一整族数打包成一个函数，让代数运算替我们做累加。这个打包工具就是**生成函数（generating function）**。<span class="marginnote">生成函数技术贯穿计数组合学的全部主线：递推关系、整数分拆、Catalan 数、对称函数都要借它发力。它把「求和」翻译成「代数」的哲学，也是概率论里矩母函数、乃至大模型注意力里求和结构的同源思想。</span>

## 1 从数列到形式幂级数：普通生成函数

给一个数列 $(a_n)_{n\ge 0} = (a_0, a_1, a_2, \dots)$，构造

$$A(x) = \sum_{n\ge 0} a_n x^n = a_0 + a_1 x + a_2 x^2 + \cdots$$

这个 $A(x)$ 就叫数列 $(a_n)$ 的**普通生成函数（ordinary generating function, OGF）**。关键在「形式」二字：我们把它当幂级数做代数运算，但不关心它在哪个 $x$ 处收敛——$x$ 只是一个占位符，真正的内容全在系数 $a_n$ 里。<span class="marginnote"><strong>形式幂级数</strong>与<strong>收敛幂级数</strong>的区别：前者把级数当作系数序列的代数包装，运算逐项进行，不需要分析学里的极限理论。这让我们能放心地写 $\sum 2^n x^n$，尽管它只在 $|x| \lt  1/2$ 时收敛。</span>

为什么要这样打包？因为**序列的卷积恰好对应函数的乘法**。设 $c_n = \sum_{k=0}^n a_k b_{n-k}$（即 $c = a * b$ 卷积），则 $C(x) = A(x)B(x)$。这一个性质让「求和」变成了「乘法」，是全部生成函数技术的发动机。<span class="marginnote">卷积→乘法，正是概率论里「独立随机变量之和」的分布（卷积）与「矩母函数之积」对应的同一件事。生成函数学到家，等于把概率里的特征函数方法也预习了一遍。</span>

两个立刻能用的例子：

$$\frac{1}{1-x} = \sum_{n\ge0} x^n \quad(\text{常数序列}),\qquad \frac{1}{1-2x} = \sum_{n\ge0} 2^n x^n \quad(\text{公比 }2)$$

**分母里的 $(1-2x)$ 一看就知道序列以 2 为公比增长**——生成函数的「形状」与「数列的成长模式」之间有直观对应。这一眼读出的能力，会反复派上用场。

## 2 指数生成函数：给对象贴上标签

普通生成函数适合「对象彼此相同」的计数（组合：选一个集合，元素无差别）。但当对象**带标签（labeled）**时——比如把 $n$ 个有名字的人排成一列、$n$ 个有编号的顶点连成图——重新分配标签会引入 $n!$ 种重数，普通生成函数就显得别扭。这时改用**指数生成函数（exponential generating function, EGF）**：

$$E(x) = \sum_{n\ge 0} a_n \frac{x^n}{n!}$$

为什么叫「指数」？因为最简单的 EGF 是 $\sum_{n\ge0} \frac{x^n}{n!} = e^x$。**除以 $n!$ 正是为了从「组合」里区分出「排列」**：若 $a_n$ 计的是带标签结构的个数，把标签整体重新洗一遍就得到 $n! \cdot a_n$ 个新对象，EGF 的系数恰好承载这种重数。<span class="marginnote">判断用 OGF 还是 EGF，一句话：<strong>对象是否带标签</strong>。无标签（组合、分拆、多重集）用 OGF；有标签（排列、图、标号树）用 EGF。这是初学最容易混淆的地方，务必用「对象有没有名字」来问自己。</span>

EGF 的乘法对应「标号集合的分拆拼接」：若 $C(x)=A(x)B(x)$，则

$$c_n = \sum_{k=0}^n \binom{n}{k} a_k b_{n-k}$$

先给第一块挑 $k$ 个标签（有 $\binom{n}{k}$ 种挑法），余下 $n-k$ 个给第二块。二项式系数正是「重新分配标签」留下的痕迹——这正是排列问题里处处有 $\binom{n}{k}$ 的根源。

## 3 生成函数的代数运算与封闭形式

会用生成函数，核心就三招：**列方程、解函数、提系数**。

- **列方程**：从递推关系或组合结构，写出 $A(x)$ 满足的方程。
- **解函数**：解出 $A(x)$ 的封闭形式（有理函数、指数、根式……）。
- **提系数**：把 $A(x)$ 展开，读回 $a_n$。

封闭形式是捷径库，三条最常用的要背熟：

$$\sum_{n\ge0}\binom{m}{n}x^n = (1+x)^m, \qquad \sum_{n\ge0}\binom{m+n}{n}x^n = \frac{1}{(1-x)^{m+1}}, \qquad \sum_{n\ge0}\frac{x^n}{n!} = e^x$$

第二条尤其重要：它说 $\frac{1}{(1-x)^{m+1}}$ 的系数是 $\binom{m+n}{n}$。无数计数问题（多重集组合、盒子装球、格路计数）最终都落到这一条上。

**辨析｜易错点：** OGF 与 EGF 的加法、数乘规则相同，但**乘法规则不同**：OGF 乘出的是普通卷积 $\sum a_k b_{n-k}$，EGF 乘出的是带二项式系数的卷积 $\sum \binom{n}{k} a_k b_{n-k}$。同一道题若混用两者，会得到错位的答案——展开后系数对不上，一步错步步错。<span class="marginnote">自检法：把 $e^x$ 当 EGF 用，它的系数序列是 $(1,1,1,\dots)$；把 $\frac{1}{1-x}$ 当 OGF 用，系数序列同样是 $(1,1,1,\dots)$。<strong>同一个序列，两副包装</strong>——选错包装，乘法语义就全变了。</span>

## 4 从结构到函数：乘法原理的生成函数版本

生成函数的乘法不只是一种记号，它背后有一条**组合结构的乘法原理**：若一类计数对象能分解为「先做第一部分，再做第二部分」，两部分的长度相加等于总长度，那么**这类对象的生成函数 = 两部分的生成函数之积**。这条原理把「结构分解」直接翻译成「函数相乘」，是组合枚举里最有力的一把钥匙。

用一个经典例子——**无限供应水果的选法**。假设水果摊有苹果、香蕉、橙子三种水果，每种不限量，要选 $n$ 个（同种水果不区分顺序）。每种水果的贡献是一个因子：

$$1 + x + x^2 + \cdots = \frac{1}{1-x}$$

三种水果彼此独立，总生成函数是三因子的乘积：

$$A(x) = \left(\frac{1}{1-x}\right)^3 = \frac{1}{(1-x)^3} = \sum_{n\ge0}\binom{n+2}{2}x^n$$

于是「选 $n$ 个」的答案立刻读出：$\binom{n+2}{2}$。这与第二级《组合数学》里「多重集组合」的公式 $\binom{n+3-1}{3-1}$ 完全一致——**生成函数把一道公式题变成了一次代数展开**。

再看**限量版**：若橙子最多只能拿 $k$ 个，它的因子就从无限等比级数截成

$$1 + x + \cdots + x^k = \frac{1-x^{k+1}}{1-x}$$

<dl>
<dt>「截断因子」</dt>
<dd>约束某种对象数量上界，就把它的 $\frac{1}{1-x}$ 换成 $\frac{1-x^{k+1}}{1-x}$——这是计数里最常见的操作之一，整数分拆一节还会反复用到它。</dd>
</dl>

常用生成函数速查表，做题时随时回来对照：

| 数列 $a_n$ | OGF $\sum a_n x^n$ | EGF $\sum a_n x^n/n!$ |
| --- | --- | --- |
| $(1,1,1,\dots)$ | $\dfrac{1}{1-x}$ | $e^x$ |
| $\binom{m}{n}$（固定 $m$） | $(1+x)^m$ | — |
| $\binom{m+n}{n}$ | $\dfrac{1}{(1-x)^{m+1}}$ | — |
| $n!$ | — | $\dfrac{1}{1-x}$ |
| $F_n$（斐波那契） | $\dfrac{x}{1-x-x^2}$ | — |
| $1,0,1,0,1,\dots$ | $\dfrac{1}{1-x^2}$ | $\cosh x$ |

这张表是「列方程 → 解函数 → 提系数」的终点站：大部分题目解出来的封闭形式，最终都能落回表里的某一行。

## 5 公式解析：斐波那契数列的生成函数

斐波那契数列 $F_0=0,\ F_1=1,\ F_n=F_{n-1}+F_{n-2}$ 是生成函数最经典的练兵场。设

$$F(x) = \sum_{n\ge0} F_n x^n$$

三步拆解这条链：

- **第一步，用递推关系列方程**：对 $n\ge2$ 有 $F_n = F_{n-1}+F_{n-2}$。两边同乘 $x^n$ 再对 $n\ge2$ 求和，把右边凑回 $F(x)$：

$$\sum_{n\ge2}F_n x^n = x\sum_{n\ge2}F_{n-1}x^{n-1} + x^2\sum_{n\ge2}F_{n-2}x^{n-2} = x\big(F(x)-F_0\big) + x^2F(x)$$

- **第二步，解出函数**：左边等于 $F(x)-F_0-F_1x = F(x)-x$。代入 $F_0=0,\ F_1=1$：

$$F(x) - x = xF(x) + x^2F(x) \quad\Longrightarrow\quad F(x) = \frac{x}{1-x-x^2}$$

- **第三步，展开提系数**：对分母做部分分式，$\frac{x}{1-x-x^2}$ 可展开成 $\sum F_n x^n$，系数恰好回到斐波那契数列（含 $F_2=1,F_3=2,F_4=3,\dots$）。**封闭形式 $x/(1-x-x^2)$ 比列 60 项数列更短、更全**——生成函数的意义正在于此：用几行代数，打包无穷多行数据，还顺手给出了 $F_n \sim \frac{1}{\sqrt5}(\frac{1+\sqrt5}{2})^n$ 的增长率信息。

## 6 小结

- **普通生成函数** $A(x)=\sum a_n x^n$：适合无标签对象，乘法对应普通卷积。
- **指数生成函数** $E(x)=\sum a_n x^n/n!$
