# 正则系综与配分函数

## 为什么从正则系综开始

前面处理的都是**近独立粒子系统**：粒子之间没有相互作用，配分函数可以因子分解。但真实系统——液体、溶液、磁体、聚合物——粒子间有相互作用，不能拆成单粒子。吉布斯 1902 年创立了**系综理论（ensemble theory）**：不追踪单个系统，而是想象**大量的、满足同一宏观约束的副本系统构成的统计全体**，用系综的平均来代表热力学量。正则系综（canonical ensemble）是其中最常用的一个：描述与热库平衡、温度固定（$T, V, N$）的系统。它是统计力学从"理想气体"走向"相互作用系统"的桥梁。<span class="marginnote">系综的哲学：一个真实系统只有一个"样本"，无法做统计。吉布斯的做法是"在想象中复制"——虚构一个由 $M \to \infty$ 个副本组成的集合，让它们按微观力学演化，然后用集合平均替代时间平均。这个"想象中的统计"后来被证明是合理的，并成为整个统计力学最通用的表述。它不再要求粒子独立，只要求宏观约束（$T, V, N$）固定。</span>

## 1 从微正则到正则：把"孤立"换成"接触热库"

微正则系综描述孤立系统（$E, V, N$ 固定）。但真实系统几乎总是与热库（环境）接触，能量可流动。正则系综的做法：

- 系统 $S$ + 热库 $R$ 合起来是孤立系统（微正则适用）；
- 系统与热库弱耦合，能量可交换但粒子数与体积不变；
- 系统的宏观约束是 $(T, V, N)$，其中 $T$ 由热库温度决定。

系统处于微观态 $i$（能量 $E_i$）的概率正比于热库的微观态数 $\Omega_R(E_{\text{tot}} - E_i)$。对热库做大系统展开（$E_i \ll E_{\text{tot}}$）：

$$\ln\Omega_R(E_{\text{tot}} - E_i) \approx \ln\Omega_R(E_{\text{tot}}) - \beta E_i, \qquad \beta = \frac{1}{k_BT}$$

于是得到**正则分布**：

$$P_i = \frac{1}{Z}\,e^{-\beta E_i}, \qquad Z = \sum_i e^{-\beta E_i}$$

**核心概念：正则系综（canonical ensemble）** 温度 $T$、体积 $V$、粒子数 $N$ 固定的系统集合，微观态 $i$ 按玻尔兹曼因子 $e^{-\beta E_i}$ 加权。<span class="marginnote">正则分布与《玻尔兹曼分布》的推导如出一辙，但差别关键：玻尔兹曼分布用于"单粒子能级"（近独立系统），正则分布用于"整个系统的微观态"（任意系统，含相互作用）。两者的数学形式相同，但 $E_i$ 的对象不同——正则系综把玻尔兹曼分布从"单体"升级到"多体"。</span>

## 2 配分函数与热力学量的统一

正则配分函数：

$$Z(T, V, N) = \sum_{\text{微观态 } i} e^{-\beta E_i}$$

它把所有热力学量统一收编：

| 热力学量 | 公式 |
| --- | --- |
| 亥姆霍兹自由能 | $F = -k_BT\ln Z$ |
| 内能 | $U = -\dfrac{\partial\ln Z}{\partial\beta}$ |
| 熵 | $S = k_B(\ln Z + \beta U)$ |
| 压强 | $p = k_BT\dfrac{\partial\ln Z}{\partial V}$ |
| 化学势 | $\mu = -k_BT\dfrac{\partial\ln Z}{\partial N}$ |

**配分函数是整个系综理论的总开关**：算出 $Z$，热力学量全有。对近独立系统，$Z = z_1^N/N!$ 自动回到前面所有结果——正则系综是更一般、更统一的框架。<span class="marginnote">注意这些公式与《配分函数与热力学量》一节的表格几乎一样——区别只在 $Z$ 的定义范围：彼时 $Z = \sum_l \omega_l e^{-\beta\varepsilon_l}$ 对单粒子能级求和，此时 $Z = \sum_i e^{-\beta E_i}$ 对整个系统微观态求和。近独立系统里两者自动一致，这正是"更一般框架包含旧框架"的体现。</span>

## 3 正则系综的推导：从热库计数到变分原理

除了"系统+热库"的推导，正则分布还可以从**最大熵原理**导出：在平均能量固定的约束下，使系统熵最大化的分布就是正则分布。用拉格朗日乘子：

$$\delta\left[-\sum_i P_i\ln P_i - \lambda_1\sum_i P_i - \lambda_2\sum_i P_iE_i\right] = 0$$

对 $P_i$ 变分，得 $P_i \propto e^{-\lambda_2 E_i}$，再定出 $\lambda_2 = \beta$、归一化常数即 $1/Z$。这条路线揭示正则分布的深层含义：**在"能量已知平均"的约束下，它是信息熵最大的分布**——即最不偏不倚、最小假设的分布。<span class="marginnote">最大熵原理由杰恩斯（E. T. Jaynes）1957 年系统提出：统计力学不需要"等几率原理"这样的力学假设，只要把已知信息（能量平均值、粒子数平均值）当约束，最大化信息熵，就得到正则/巨正则分布。这与信息论的连接（对照《信息论》）让统计力学与信息科学共享同一数学。</span>

## 4 公式解析：$F = -k_BT\ln Z$ 与自由能的微观意义

$$

F = -k_BT\ln Z

$$

逐项拆解：

- **第一步，从定义出发**：$F = U - TS$。把 $U$、$S$ 用 $Z$ 表达：$U = -\partial\ln Z/\partial\beta$，$S = k_B(\ln Z + \beta U)$。
- **第二步，代入整理**：$F = U - T\cdot k_B(\ln Z + U/k_BT) = -k_BT\ln Z$。$U$ 项消掉，只剩 $\ln Z$。
- **第三步，物理意义**：$\ln Z$ 越大，自由能越负。$Z$ 大意味着系统微观态多、可访问状态丰富，自由能低、系统更"自由"。
- **第四步，量纲检查**：$\ln Z$ 无量纲，乘以 $k_BT$（能量量纲）得能量量纲的 $F$。
- **直觉**：自由能 = "系统在温度 $T$ 下能释放的最大可做功能量"。$\ln Z$ 计数了所有被热涨落"打开"的微观态，$\ln Z$ 越大，可做功潜力越大（$F$ 越负）。下一节《巨正则系综》里，$F$ 会推广到粒子数可变的情形。

## 5 正则系综的威力：相互作用系统

正则系综的第一个伟大应用是处理**有相互作用的系统**。例子：

- **液体与稠密气体**：分子间有相互作用势 $u(r)$，配分函数含构型积分 $\int e^{-\beta\sum u(r_{ij})}\mathrm{d}^3r_1\cdots$——维里展开、径向分布函数都在这里展开；
- **磁性系统**：伊辛模型（下一节）的配分函数求和是相变理论的主战场；
- **聚合物链**：链段间的约束与相互作用用正则配分函数处理。

正因如此，**正则系综是现代统计计算（蒙特卡洛模拟）的标准框架**：用数值方法估计 $Z$ 的比值，就能算出热力学量。<span class="marginnote">蒙特卡洛模拟（Metropolis 算法）就是给正则系综配分的"数值求解器"：按 $e^{-\beta E}$ 加权随机采样系统的构型，平均出内能、磁化等热力学量。1990 年代以来，计算统计力学（分子动力学、蒙特卡洛）让正则系综成了化学、材料、生物的日常工具——系综理论从纸面走进了模拟器。</span>

**辨析｜易错点：** 正则系综里系统能量**不固定**，服从以 $U = \langle E\rangle$ 为中心的分布。因此"正则系综的温度是确定的、能量是涨落的"，与微正则系综（能量固定）相对。两者的差别在热力学极限下消失（涨落 $\sim 1/\sqrt{N}$），这就是下一节《系综等价性》的内容。初学者常混淆"温度固定"与"能量固定"，它们是两种不同约束。

## 6 例题：两能级系统的正则处理

两能级系统（如自旋 1/2 在磁场中）是正则系综的最小非平凡舞台，全程可解析。

**配分函数**。能级 $\varepsilon_\pm = \mp\mu H$，配分函数只有两项：

$$Z = e^{\beta\mu H} + e^{-\beta\mu H} = 2\cosh(\beta\mu H)$$

**内能**：

$$U = -\frac{\partial\ln Z}{\partial\beta} = -\mu H\tanh(\beta\mu H)$$

**磁化强度**（对外场的响应）：

$$M = \mu\tanh(\beta\mu H)$$

**热容**：

$$C = \frac{\partial U}{\partial T} = k_B(\beta\mu H)^2\,\text{sech}^2(\beta\mu H)$$

**读出物理**：

- 高温极限 $\beta\mu H \ll 1$：$\tanh \to \beta\mu H$，$M \to \mu^2H/k_BT$——居里定律（磁化率 $\propto 1/T$）；
- 低温极限 $\beta\mu H \to \infty$：$M \to \mu$，自旋全部沿场排列（饱和）；
- 热容在 $\beta\mu H \sim 1$ 处出现**薛定谔峰**（两能级差与 $k_BT$ 可比时热容最大），高温与低温都趋于零——「能隙被热涨落完全激发」的唯一窗口。<span class="marginnote">两能级系统的热容峰（薛定谔峰）是量子统计的「签名」：能级间距与 $k_BT$ 相当时，自由度恰好「开始参与」，热容最大。这个峰在《固体热容（爱因斯坦/德拜）》的每个振动自由度上都会出现——爱因斯坦模型本质上就是「两能级/多能级系统的叠加」。认出一个峰，就是认出一次能隙的激活。</span>

**辨析｜易错点：** 两能级系统的正则处理假设自旋之间无相互作用（近独立）。真实磁体里自旋相互作用会改变结果（见《Ising 模型与相变》）。「先无相互作用、再加耦合」是统计力学的标准套路——两能级模型是第一步，Ising 是第二步。

## 7 小结

- **系综**：大量满足同一宏观约束的副本系统构成的统计全体，系综平均替代时间平均。
- **正则系综**：$(T, V, N)$ 固定、与热库平衡的系统；$P_i = e^{-\beta E_i}/Z$。
- **配分函数** $Z = \sum_i e^{-\beta E_i}$：全部热力学量的总开关，$F = -k_BT\ln Z$。
- 正则分布可由热库计数、或最大熵原理导出；对近独立系统自动回到玻尔兹曼分布。
- 正则系综能处理相互作用系统，是蒙特卡洛模拟等数值方法的标准框架。
