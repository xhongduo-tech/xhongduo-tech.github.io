# 朗道相变理论

## 为什么从朗道理论开始

临界现象用临界指数描述"怎么变"，但问"为什么会变"需要一套机制。1937 年，朗道提出一个优雅的框架：**相变是序参量从零到非零的转变，由自由能对序参量的展开控制**。这个**朗道理论（Landau theory of phase transitions）**用一个标量序参量和几个展开系数，统一描述了二级相变（连续）与一级相变（不连续），是凝聚态物理与粒子物理（自发对称性破缺）的共用语言。<span class="marginnote">朗道理论的成功在于它的普适方法：不需要知道微观机制，只要写下一个"序参量 + 按对称性允许的展开"，就能预言相变行为。它后来被扩展到超导（金兹堡-朗道方程，1950）与粒子物理（希格斯机制）——同一套"自由能展开+对称性破缺"的语言贯穿宏观与微观。</span>

## 1 序参量与对称性破缺

**核心概念：序参量（order parameter）** 一个在有序相非零、无序相为零的物理量，标记"有序程度"。铁磁的磁化强度 $m$、超导的凝聚波函数 $\psi$、液-气的密度差 $\Delta\rho$——都是序参量。

朗道理论的出发点：**相变伴随对称性破缺（spontaneous symmetry breaking）**。高温相序参量为零，系统具有完整对称性；温度降低到临界点，序参量自发获得非零值，系统"选择"了某个方向，对称性降低。<span class="marginnote">对称性破缺的直觉：高温时自旋随机取向，系统在自旋反转（$s \to -s$）下不变（对称）；低温时自旋集体朝上，反转对称性被"自发打破"——哈密顿量仍然对称，但系统的状态不再对称。这就像圆桌上的盘子：桌子对称，但盘子必须倒向某个方向。"对称性比系统本身更深刻"是朗道理论的美学核心。</span>

## 2 朗道自由能的展开

设序参量 $\phi$，朗道假设：靠近临界点，自由能密度可以按 $\phi$ 展开（受对称性约束，只保留偶数次幂）：

$$f(\phi, T) = f_0(T) + \frac{1}{2}a(T)\phi^2 + \frac{1}{4}b\,\phi^4 - h\phi$$

其中：

- $a(T) = a_0(T - T_c)$ 在临界点改变符号（$a_0 > 0$）；
- $b > 0$ 保证能量有下界（稳定）；
- $h$ 是外场（如磁场），耦合序参量。

系统的平衡序参量由自由能极小化确定：$\partial f/\partial \phi = 0$。

- $T > T_c$：$a > 0$，$f$ 在 $\phi = 0$ 取极小，无序相稳定，$\phi = 0$；
- $T < T_c$：$a < 0$，$f$ 在 $\phi = \pm\phi_0$ 取极小，有序相稳定，$\phi_0 \neq 0$。

**这正是对称性破缺的图像**：$T < T_c$ 时自由能在两个对称极小之间选一个，序参量获得非零值。<span class="marginnote">$b > 0$ 的必要性：若 $b < 0$，$f$ 在 $|\phi|$ 很大时趋于负无穷，系统无稳定平衡。要构造 $b < 0$、$c > 0$ 的更高次展开，就得到三临界点（tricritical point）等更丰富的相图。朗道展开的"截断阶数"由对称性与稳定性共同决定。</span>

## 3 二级相变的朗道预言

由 $f$ 的极小化可以解出所有临界行为：

- **序参量**：$\phi_0 = \sqrt{a_0(T_c - T)/b}$（$T < T_c$），即 $\phi_0 \propto (T_c - T)^{1/2}$——临界指数 $\beta = 1/2$；
- **比热**：$T > T_c$ 时 $\phi = 0$、$f = f_0$；$T < T_c$ 时代入 $\phi_0$ 得 $f = f_0 - a_0^2(T_c-T)^2/4b$。对 $T$ 求二阶导，比热在 $T_c$ 有**有限跳变**，无发散——指数 $\alpha = 0$；
- **磁化率**：$\chi = \partial^2 f/\partial h^2$ 在 $T_c$ 处发散 $\propto |T - T_c|^{-1}$——指数 $\gamma = 1$。

这些正是《临界现象与标度律》表里的**平均场指数**。朗道理论给出的是"忽略涨落"的经典值，与真实系统的差别在临界点附近最显著（涨落最烈处）。<span class="marginnote">朗道理论的临界指数（$\beta = 1/2$、$\gamma = 1$、$\alpha = 0$）与二维 Ising（$\beta = 1/8$、$\gamma = 7/4$、$\alpha$ 对数）不同，但因为它是"解析可做的"，仍被广泛用作第一近似。朗道理论的适用条件 $d > 4$（上临界维数以上涨落可忽略）由重整化群给出——又一个"平均场何时正确"的判据。</span>

## 4 公式解析：朗道自由能极小化

$$

\phi_0 = \sqrt{\frac{a_0(T_c - T)}{b}} \quad (T < T_c)

$$

逐项拆解：

- **第一步，极小条件**：$\frac{\partial f}{\partial \phi} = a\phi + b\phi^3 - h = 0$。零场（$h = 0$）下 $\phi(a + b\phi^2) = 0$，解为 $\phi = 0$ 或 $\phi^2 = -a/b$。
- **第二步，判据 $a < 0$**：$T < T_c$ 时 $a = a_0(T - T_c) < 0$，$\phi^2 = -a/b = a_0(T_c - T)/b > 0$ 才有实解。
- **第三步，选稳定解**：$\phi^2 = -a/b$ 的两个解 $\pm\phi_0$ 使 $f$ 取极小（二阶导 $a + 3b\phi^2 = -2a > 0$），$\phi = 0$ 是极大（不稳定）。
- **第四步，指数 $1/2$**：$\phi_0 \propto (T_c - T)^{1/2}$——序参量在临界点"以平方根方式"从零长出来，这就是平均场指数 $\beta = 1/2$。
- **直觉**：临界点像分岔点。$T > T_c$ 时势阱中心在 $\phi = 0$（单极小）；$T < T_c$ 时势阱变成"双极小"（墨西哥帽形），序参量随机落入某一侧。"帽子"从单峰变双峰的时刻，就是相变。

## 5 一级相变：朗道展开的推广

朗道框架也能描述**一级相变**。若自由能展开到 $\phi^6$ 且系数 $b < 0$：

$$f = f_0 + \frac{1}{2}a\phi^2 + \frac{1}{4}b\phi^4 + \frac{1}{6}c\phi^6 - h\phi, \qquad b < 0, c > 0$$

这时在某个 $T_1 > T_c$，$\phi = 0$ 与 $\phi = \pm\phi_1 \neq 0$ 两处同时取极小（自由能相等）——**一级相变**：序参量从不连续跳到非零，伴随潜热。温度再降到 $T_c$（亚稳态消失点）以下，$\phi = 0$ 不再是极小。

| 特征 | 二级相变（$b > 0$） | 一级相变（$b < 0$） |
| --- | --- | --- |
| 序参量 | 连续从零增长 | 在 $T_1$ 处不连续跳变 |
| 潜热 | 无 | 有 |
| 亚稳态 | 无 | 有过冷/过热 |
| 对称性破缺点 | $T_c$（连续） | $T_1$（跳变） |

**辨析｜易错点：** 一级相变发生在"两相自由能相等"的温度（$T_1$），不是"$\phi = 0$ 失稳"的温度（$T_c$）。$T_1$ 与 $T_c$ 之间有亚稳态区间，现实里相变实际发生的温度取决于成核动力学。朗道理论的 $T_c$（零场失稳点）常被误当成实际相变温度——要分清"平衡相变点"与"失稳点"。

<span class="marginnote">朗道理论把相变家族统一进一个框架：$b$ 的符号决定一级还是二级，$h \neq 0$ 打开外场，更多系数给出三临界点、临界端点等复杂相图。现代相图研究的"标准作业"仍是：先猜序参量与对称性，写朗道展开，再解自由能极小。</span>

## 6 朗道理论的边界：涨落与金兹堡判据

朗道理论如此优雅，以至于它的适用范围容易被低估——而边界本身又是物理。

**为什么平均场会失效**。朗道理论假设序参量取「平均值」$\phi_0$，忽略了序参量在空间上的涨落。但临界点附近，关联长度 $\xi$ 发散，涨落被放大到宏观尺度——「忽略涨落」从好的近似变成了根本错误。这就是《临界现象与标度律》里平均场指数与实验不符的根源。

**金兹堡判据**。何时平均场成立？金兹堡给出定量判据：当临界点附近的涨落能量远小于序参量平均能量的差距时，平均场可靠。粗略说：

$$\frac{|T - T_c|}{T_c} \gg \left(\frac{a_0^3}{b^2 k_B}\right)^2 \cdot (\text{常数})$$

对大多数三维系统，这个「涨落区间」极小——在远离 $T_c$ 的区域平均场完全够用，只是临界点附近的窄窗口需要更精细的理论。上临界维数 $d_c = 4$：$d > 4$ 时平均场在临界点也正确，$d \le 4$ 时临界区涨落主导。<span class="marginnote">金兹堡判据的实际意义：它不是「理论美学」的讨论，而是工程与模拟的实用指南——什么时候可以放心用平均场、什么时候必须上蒙特卡洛或重整化群。对大多数材料，离开临界点 $T_c$ 百分之几，平均场就已足够精确；这正是朗道理论在材料科学里被广泛使用的原因。</span>

**朗道理论的历史地位**。尽管平均场有局限，朗道理论仍是相变理论的地基：它第一次把「对称性破缺」作为相变的统一图像，第一次用「序参量 + 自由能展开」把一级与二级相变放进同一个框架。金兹堡-朗道方程（含空间梯度项）进而描述了超导涡旋、畴壁等空间非均匀结构。它的「框架」比它的「平均场近似」更长寿——重整化群做的，正是在朗道框架上把涨落系统地加回去。

**辨析｜易错点：** 朗道理论不是「错了」，而是「平均场近似」错了。把「朗道理论」与「平均场」画等号是常见误区——朗道贡献的是「序参量 + 对称性展开」的思想，平均场只是解这个展开的一种（粗糙）方法。高级理论（重整化群）改进的是解法，保留的是朗道的框架。

以超导为例：金兹堡-朗道方程（含梯度项与规范场）成功预言了磁通量子化、涡旋态、相干长度——这些都在「平均场」的范畴内，却与实验定量吻合。这说明朗道框架的生命力远超「平均场失效」的窄窗口：只要不贴着临界点，框架本身就是定量工具。

## 7 小结

- **序参量**：有序相非零、无序相为零；相变 = 对称性自发破缺。
- **朗道自由能** $f = f_0 + \frac12 a\phi^2 + \frac14 b\phi^4 - h\phi$，$a = a_0(T - T_c)$。
- **二级相变**：序参量连续增长 $\phi_0 \propto (T_c - T)^{1/2}$，比热跳变，磁化率发散——平均场指数。
- **一级相变**（$b < 0$ 展开）：序参量跳变、有潜热、有过冷过热亚稳态。
- 朗道理论忽略涨落（平均场），在上临界维数 $d > 4$ 正确；它统一了二级与一级相变，并延伸到超导、粒子物理。
- **金兹堡判据**：涨落能量远小于序参量平均能差时平均场可靠；临界点窄窗口内失效。
- **框架 vs 近似**：朗道贡献「序参量 + 对称性展开」框架，平均场只是解框架的一种近似。
- **超导延伸**：金兹堡-朗道方程预言磁通量子化、涡旋、相干长度，框架在临界区外仍是定量工具。
