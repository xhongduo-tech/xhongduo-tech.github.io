## 为什么从巨正则系综开始

正则系综固定粒子数 $N$，但许多实际问题里粒子数本身在涨落：化学反应中分子数在变、吸附/脱附过程、光子与声子这类准粒子的数目根本不守恒。此时需要**巨正则系综（grand canonical ensemble）**：系统与外界同时交换**能量与粒子**，宏观约束是 $(\mu, V, T)$——温度与化学势固定，能量与粒子数都涨落。它是量子统计里处理"粒子数可变系统"的标准框架，也是从统计力学的 $Z$ 通往化学势 $\mu$ 微观定义的桥梁。<span class="marginnote">巨正则系综的"巨"（grand）指它除了热库还有"粒子库"（particle reservoir）：系统与粒子库交换粒子，粒子库化学势固定。化学势的微观定义——$\mu$ 是"加一个粒子需要付出的自由能变化"——在巨正则框架里获得最清晰的表达。</span>

## 1 巨正则分布与巨配分函数

系统与"热库+粒子库"平衡，处于微观态 $i$（能量 $E_i$、粒子数 $N_i$）的概率：

$$P_i = \frac{1}{\Xi}\,e^{-\beta(E_i - \mu N_i)}$$

其中**巨配分函数（grand partition function）**：

$$\Xi = \sum_{N=0}^{\infty}\sum_i e^{-\beta(E_i - \mu N_i)}$$

**核心概念：巨配分函数 $\Xi$** 对所有粒子数与所有微观态求和。它同时编码了能量与粒子数的统计信息。<span class="marginnote">指数里的 $-\beta\mu N_i$ 是"每个粒子贡献 $\mu$ 的权重"。$\mu$ 为正、粒子数多时权重被压低（费米子系统常如此）；$\mu = 0$ 时粒子数项消失，回到 $\mu=0$ 的玻色分布——光子、声子系统正是这样。看到 $\Xi$ 先问 $\mu$ 是否为零，能立即识别系统的粒子数守恒与否。</span>

## 2 从巨配分函数求热力学量

巨配分函数与热力学量的联系由**巨势（grand potential）**$\Omega_G$ 统摄：

$$\Omega_G(T, V, \mu) = -k_BT\ln\Xi$$

由此导出全部热力学量：

| 热力学量 | 公式 |
| --- | --- |
| 粒子数 | $N = -\left(\dfrac{\partial\Omega_G}{\partial\mu}\right)_{T,V}$ |
| 压强 | $p = -\left(\dfrac{\partial\Omega_G}{\partial V}\right)_{T,\mu}$ |
| 熵 | $S = -\left(\dfrac{\partial\Omega_G}{\partial T}\right)_{V,\mu}$ |
| 内能 | $U = \Omega_G + TS + \mu N$ |
| 自由能 | $F = \Omega_G + \mu N$ |

巨势的另一个性质：$\Omega_G = -pV$（对均匀系统）。于是 $\ln\Xi = pV/k_BT$——**巨配分函数直接给出状态方程**，这是它最大的工程便利。<span class="marginnote">$\ln\Xi = pV/k_BT$ 这条性质极其实用：只要算出巨配分函数，状态方程 $p(T, \mu)$ 直接读出。对理想气体验证：$\ln\Xi = \bar N e^{\beta\mu}$ 之类的结果代入即得 $pV = Nk_BT$。化学势给定时，压强自动出来——这就是为什么做相图、吸附等温线常选巨正则系综。</span>

## 3 公式解析：巨配分函数的求和结构

$$

\Xi = \sum_{N=0}^{\infty}\sum_i e^{-\beta E_i(N)}\,e^{\beta\mu N}

$$

逐项拆解：

- **第一步，两层求和**：外层对粒子数 $N$（从 0 到无穷），内层对 $N$ 个粒子系统的全部微观态 $i$ 求和。$E_i(N)$ 标明能量依赖粒子数。
- **第二步，因子 $e^{\beta\mu N}$**：化学势加权。$\mu$ 大，粒子数多的项权重增大——系统倾向多容纳粒子；$\mu$ 小，粒子数被压低。
- **第三步，与正则配分函数的关系**：对固定 $N$ 的内层求和就是该 $N$ 下的正则配分函数 $Z_N$，于是 $\Xi = \sum_N Z_N e^{\beta\mu N}$——巨配分函数是"各粒子数的正则配分函数的化学势加权和"。
- **第四步，量子统计的统一**：对近独立粒子系统，$\ln\Xi = \mp\sum_l \ln(1 \mp e^{-\beta(\varepsilon_l-\mu)})$（费米取 $-/$上号，玻色取 $+$）。所有量子统计的结果都能从这个统一表达式抽出。
- **直觉**：巨配分函数是"粒子数维度上的配分函数"。正则配分函数处理"几个粒子"，巨配分函数处理"几个粒子的加权叠加"，权重由化学势控制。

## 4 粒子数涨落与化学势

巨正则系综里粒子数本身是随机变量，它的涨落由巨配分函数直接给出：

$$\langle(\Delta N)^2\rangle = k_BT\left(\frac{\partial N}{\partial\mu}\right)_{T,V} = k_BT\left(\frac{\partial^2\ln\Xi}{\partial\mu^2}\right)_{T,V}\cdot(k_BT)^2 \cdot \beta^{-1}$$

整理为标准形式：

$$\frac{\langle(\Delta N)^2\rangle}{\langle N\rangle^2} = \frac{k_BT\kappa_T}{V}$$

其中 $\kappa_T$ 是等温压缩率。**相对粒子数涨落 $\sim 1/\sqrt{\langle N\rangle}$，在热力学极限下趋于零**。<span class="marginnote">粒子数相对涨落 $\sim 1/\sqrt{N}$ 是统计物理"大数定律"的又一次现身（对照《概率论与数理统计》的弱大数定律）。巨正则系综允许涨落，但涨落小到宏观不可见——这就是"系综等价"在粒子数维度上的体现。到《涨落理论》一节，能量涨落与粒子数涨落会被统一处理。</span>

**辨析｜易错点：** 巨正则系综的 $\mu$ 是**外部施加的**（由粒子库决定），不是系统自发确定的。实际计算中常先固定 $\langle N\rangle$（等于实验粒子数），再反解 $\mu$。两种视角（固定 $\mu$ vs 固定 $N$）在热力学极限下给出相同结果——这是《系综等价性》要展开的主题。初学者容易把"巨正则的 $\mu$"与"正则的 $\mu$"混为一谈，其实一个是输入、一个是输出。

## 5 巨正则系综的典型应用

巨正则系综适合一切"粒子数可变"的问题：

- **光子/声子气体**：$\mu = 0$，黑体辐射与德拜理论都在此框架下自然出现；
- **吸附与表面物理**：气体分子在表面上吸附/脱附，Langmuir 吸附等温线由巨配分函数推导；
- **化学反应平衡**：各组分粒子数随反应变化，化学平衡条件 $\sum\nu_i\mu_i = 0$ 在巨正则框架下是自然结论；
- **凝聚体与相变**：玻色-爱因斯坦凝聚、超流的理论处理常以巨正则表述为出发点（化学势锁定在基态能级）。

<span class="marginnote">吸附等温线是一个漂亮的例子：把表面当巨正则系综（与气相交换分子），平衡时表面化学势=气相化学势，Langmuir 等温式 $\theta = p/(p + p_0)$ 从巨配分函数一步导出。从物理化学到生物膜力学，巨正则系综是"开放系统"的通用语言。</span>

## 6 例题：理想气体的巨配分函数

把巨正则方法在理想气体上完整跑一遍，会得到一个漂亮的闭环——状态方程自动出现。

**单粒子巨配分函数**。自由粒子的单粒子态由动量与位置标记，巨配分函数的对数（对玻色-费米统一公式取经典极限 $e^{\beta\mu} \ll 1$）：

$$\ln\Xi = \frac{V}{h^3}e^{\beta\mu}\int e^{-\beta p^2/2m}\,\mathrm{d}^3p = \frac{V}{h^3}e^{\beta\mu}\left(\frac{2\pi m}{\beta}\right)^{3/2}$$

**由 $\ln\Xi$ 求热力学量**。粒子数：

$$N = \frac{1}{\beta}\frac{\partial\ln\Xi}{\partial\mu} = \frac{V}{h^3}e^{\beta\mu}\left(\frac{2\pi m}{\beta}\right)^{3/2}$$

压强由 $\ln\Xi = pV/k_BT$ 直接读出：

$$p = \frac{k_BT}{V}\ln\Xi = \frac{k_BT}{V}N = \frac{Nk_BT}{V}$$

**状态方程自动出现**：$pV = Nk_BT$——理想气体状态方程，这次从巨正则系综「白送」出来，连 $N!$ 修正都不需要（巨配分函数的求和结构天然处理了全同性）。<span class="marginnote">对比《配分函数与热力学量》里正则系综的推导：那里需要引入 $1/N!$ 修正和斯特林公式；巨正则系综里「粒子数求和」的结构自动包含了全同粒子的计数。这不是巧合——巨正则系综的 $\Xi = \sum_N Z_N e^{\beta\mu N}$ 就是把「各种粒子数」的正则系综加权平均，$N!$ 的因子藏在 $Z_N$ 里被求和「洗平」了。</span>

**巨正则的优势在此显现**：对粒子数可变系统（光子、声子、吸附、化学反应），$\ln\Xi$ 常常比 $Z$ 更好算，而状态方程、粒子数、涨落（《涨落理论》）都能从它一步导出。

**辨析｜易错点：** 上面对理想气体取了**经典极限**（$e^{\beta\mu} \ll 1$），得到的是玻尔兹曼统计。若粒子简并（$e^{\beta\mu}$ 不可忽略），要用玻色/费米版的 $\ln\Xi = \mp\sum_l\ln(1\mp e^{-\beta(\varepsilon_l-\mu)})$，结果出现费米简并压或玻色凝聚。判断「用哪个版本」，看占据数是否远小于 1。

## 7 小结

- **巨正则系综**：$(\mu, V, T)$ 固定，能量与粒子数都涨落；分布 $P_i = e^{-\beta(E_i-\mu N_i)}/\Xi$。
- **巨配分函数** $\Xi = \sum_N Z_N e^{\beta\mu N}$；巨势 $\Omega_G = -k_BT\ln\Xi = -pV$，状态方程直接读出。
- $\ln\Xi = \mp\sum_l\ln(1\mp e^{-\beta(\varepsilon_l-\mu)})$ 统一了量子统计。
- **粒子数涨落** $\langle(\Delta N)^2\rangle = k_BT(\partial N/\partial\mu)$，相对涨落 $\sim 1/\sqrt{N}$。
- 应用：光子/声子气体、吸附等温线、化学平衡、BEC——一切粒子数可变系统。
