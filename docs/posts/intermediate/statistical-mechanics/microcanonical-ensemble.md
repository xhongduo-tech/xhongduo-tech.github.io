# 等几率原理与微正则系综

<div class="epigraph">

## 为什么从等几率原理开始

上一节建立了语言：微观态、宏观态、微观状态数 $\Omega$。但要算出概率，还差一条「先验假设」——在众多微观态中，系统更偏爱哪一个？统计物理的第一条公理给出答案：**孤立系统处于任一能量壳内的微观态的概率是相等的**。这就是**等几率原理（principle of equal a priori probabilities）**。它是最小假设、最"省事"的猜测，却撑起了整个统计力学。基于它建立的第一个系综——**微正则系综（microcanonical ensemble）**，是所有其他系综的出发点。<span class="marginnote">等几率原理为什么「合理」？它对应信息论里的最大熵原理：除了「能量固定、孤立、粒子数固定」这些约束外，我们对系统一无所知，于是把不确定度均匀摊到每个微观态上。杰恩斯（E. T. Jaynes）1957 年正是从最大熵原理重新推导出整个统计力学。</span>

## 1 等几率原理的陈述

**等几率原理（equal a priori probabilities）**：对于处于平衡态的孤立系统，能量落在 $[E, E+\Delta E]$ 内的每一个微观态，出现的概率相等。记微观态数为 $\Omega(E)$，则每个微观态的概率为：

$$P_i = \frac{1}{\Omega(E)}, \qquad i = 1, 2, \ldots, \Omega(E)$$

这条原理没有被证明，也不需要被证明——它是统计力学唯一的基本假设。它的正当性最终由后果来检验：**由它推出的全部热力学结论都与实验一致**。<span class="marginnote">「等先验概率」这个词来自拉普拉斯的古典概率论，先验（a priori）指不依赖任何经验信息。统计力学的奠基者玻尔兹曼、吉布斯都把这条假设当作出发点，而它究竟能否从力学+混沌严格推出，至今仍是一个活跃的数学问题（遍历理论）。</span>

## 2 微正则系综

满足等几率原理的统计集合叫**微正则系综**：它描述**孤立系统**——能量、体积、粒子数全部固定（$E, V, N$ 为参量）的系统的统计性质。它是最"原始"的系综，直接对应"能量固定"这一约束。

系统处于宏观态 $(E, V, N)$ 的任一微观态等概率，于是宏观量等于微观态平均：

$$\bar A = \frac{1}{\Omega}\sum_i A_i$$

微正则系综虽然最简单，却很难直接使用——"能量严格固定"在实际计算中极不方便。它的价值在于提供了**熵的定义基点**：

$$S = k_B \ln \Omega(E, V, N)$$

这条**玻尔兹曼公式**是整个统计力学的心脏：它把纯统计量 $\Omega$ 与纯热力学量 $S$ 焊接在一起。<span class="marginnote">$S = k_B \ln\Omega$ 刻在玻尔兹曼的墓碑上（他生前从未以此精确形式写下它，普朗克在 1900 年推导黑体辐射时才写出了这个带 $k_B$ 的完整公式）。从熵还可以反向"定义"温度、压强：$1/T = (\partial S/\partial E)$，$p/T = (\partial S/\partial V)$——热力学的核心概念全部从 $\Omega$ 长出来。</span>

## 3 从微正则系综推出热力学

有了 $S(E,V,N) = k_B\ln\Omega(E,V,N)$，整个热力学都可以被"重写"出来：

**温度**：$\frac{1}{T} = \left(\frac{\partial S}{\partial E}\right)_{V,N}$
**压强**：$p = T\left(\frac{\partial S}{\partial V}\right)_{E,N}$
**化学势**：$\mu = -T\left(\frac{\partial S}{\partial N}\right)_{E,V}$

于是热力学第一定律 $\mathrm{d}E = T\,\mathrm{d}S - p\,\mathrm{d}V + \mu\,\mathrm{d}N$ 不再是公理，而是由 $S$ 的全微分自动得到的一条**定理**。热力学的几条公理浓缩成了一条等几率原理。<span class="marginnote">这是一个漂亮的「公理归并」：热力学需要四条定律，统计力学只需要等几率原理加力学的哈密顿量。温度、熵、压强在统计力学里都有了定义——温度是「能量对熵的响应」，熵是「微观状态数的对数」。</span>

## 4 公式解析：温度的定义式

微正则系综里温度是这样"长出来"的：

$$
\frac{1}{T} = \left(\frac{\partial S}{\partial E}\right)_{V,N} = k_B \frac{\partial \ln\Omega}{\partial E}
$$

拆解：

- **第一步，热力学的温度**：在热力学里 $1/T = (\partial S/\partial E)$ 是**定义式**，温度是"单位熵对应的能量变化率"。
- **第二步，统计力学的温度**：代入 $S = k_B \ln\Omega$，温度变成「$\ln\Omega$ 对能量的斜率乘 $k_B$」。
- **第三步，物理直觉**：$\Omega$ 随能量增长得越陡，同样的能量增加换来更多微观态，系统"容纳能量"的能力越强，表现为温度越低。**温度高 = 微观态数随能量增长平缓 = 能量已经不那么"稀缺"**。
- **第四步，关键推论**：因为 $\Omega$ 随 $E$ 急剧增大，$1/T > 0$，温度为正。要使 $T < 0$，需要 $\partial \ln\Omega/\partial E < 0$，即能量越高微观态越少——这发生在粒子数有上界的系统（如有限格点上的自旋），即**负温度**这一概念只在特殊人造系统里出现。

**辨析｜易错点：** 负温度并非"低于绝对零度"的冷，而是**比无穷温度更热**——能量越高微观态越少，把能量灌进去反而让熵减少。在正负温度接触时，热量会从负温度流向正温度。这个反直觉现象是等几率原理 + 温度定义的直接产物。

## 5 等几率原理与时间平均：遍历性

等几率原理说的是"系综平均"（对大量相同孤立系统构成的集合求平均），而实际测量的是"时间平均"（对单个系统长时间观察）。两者何时一致？回答是**遍历性（ergodicity）**假设：系统长时间演化会均匀地访问能量壳内每一个微观态。若遍历成立，时间平均 = 系综平均，测量才有意义。<span class="marginnote">遍历性是统计力学里一个深刻的数学问题：大多数真实系统并不严格遍历，但只要演化能"足够均匀"地覆盖宏观态对应的微观态，宏观量就仍稳定。这个主题在《非平衡统计初步》会以玻尔兹曼方程和 H 定理的形式重新出现——那里我们问的不是"系统是否遍历"，而是"系统如何接近平衡"。</span>

## 6 例题：$N$ 个自旋的熵与温度

把微正则系综的方法完整跑一遍，最简单而有内容的系统是 $N$ 个独立自旋（每个 $\pm 1$），放在磁场中。系统能量 $E = -\mu H(N_\uparrow - N_\downarrow)$，令 $N = N_\uparrow + N_\downarrow$，则：

$$E = -\mu H(2N_\uparrow - N)$$

**第一步，数微观态**。能量 $E$（即固定 $N_\uparrow$）下的微观态数，是从 $N$ 个自旋里选 $N_\uparrow$ 个向上的组合数：

$$\Omega(N_\uparrow) = \binom{N}{N_\uparrow} = \frac{N!}{N_\uparrow!\,N_\downarrow!}$$

**第二步，算熵**。用斯特林公式取对数：

$$S = k_B\ln\Omega = k_B\left[N\ln N - N_\uparrow\ln N_\uparrow - N_\downarrow\ln N_\downarrow\right]$$

**第三步，算温度**。$1/T = \partial S/\partial E$，把 $E$ 与 $N_\uparrow$ 的关系代入并求导：

$$\frac{1}{T} = \frac{k_B}{2\mu H}\ln\frac{N_\downarrow}{N_\uparrow}$$

**第四步，读出物理**。当 $N_\uparrow > N_\downarrow$（系统能量高、自旋大多朝上）时 $\ln(N_\downarrow/N_\uparrow) < 0$，温度**为负**！这个例子第一次让我们看见「负温度」的真实样貌：自旋系统能量有上界（全朝上），能量越高、微观态越少，熵随能量下降——这正是《等几率原理与微正则系综》里预告过的负温度机制。真实实验（核自旋系统）确实测到过负温度，且负温度比正无穷温度更热。<span class="marginnote">这个二能级模型是理解微正则方法的「最小可行系统」：数态（$\Omega$）→ 熵（$S$）→ 温度（$T$）的链条完整跑通，而且意外地展示了负温度。同样的计算在《玻尔兹曼分布》里用正则系综再做一遍会得到一致结果——两种系综在这里等价，验证了系综理论的自洽性。</span>

**辨析｜易错点：** 自旋系统是「能量有上限」的系统，所以允许负温度；平动自由度能量无上限，永远正温度。判断一个系统能否有负温度，先问「能量是不是有界」。把负温度误解为「比零温更冷」是常见的错误——它其实比无穷高温更热。

## 7 微正则系综的局限与衔接

微正则系综在概念上最「干净」，使用上却最「笨重」，这个反差值得展开。

**为什么难用**：固定能量 $E$ 需要直接数 $\Omega(E)$，而绝大多数系统的态密度计算极其困难。哪怕是最简单的相互作用系统，$\Omega(E)$ 也无法解析。正则系综（$T$ 固定）用玻尔兹曼因子 $e^{-\beta E}$ 替代了「固定 $E$」，把困难从「计数」换成「求和」，配分函数反而更可算。这是历史与实用共同选择正则系综为主角的原因。

**概念的不可替代**：尽管如此，微正则系综仍有其独特地位：

它是**定义熵的锚点**：$S = k_B\ln\Omega$ 的一切概念基础都在这里，正则系综的 $F = -k_BT\ln Z$ 可以从它推导出来；
它是**等几率原理的家**：一切系综的概率分布都以「孤立系统等概率」为出发点；
它是**数值模拟的天然框架**：分子动力学模拟固定能量（微正则），直接演化牛顿方程再统计平均。

**衔接正则系综**：把「能量固定」放松为「能量期望固定」，用拉格朗日乘子最大化 $\ln\Omega$（约束 $\langle E\rangle$ 与 $\langle N\rangle$），得到的正是正则分布与巨正则分布。所以三种系综不是并列的三套理论，而是从「孤立系统等概率」这个唯一假设出发、在不同约束下导出的三个版本。微正则在最上游，正则与巨正则是对它做的「勒让德变换式」推广。<span class="marginnote">这个「放松约束」的推导视角值得记住：正则系综 = 微正则 + 能量约束的拉格朗日乘子；巨正则 = 正则 + 粒子数约束的拉格朗日乘子。每放松一个约束，就多一个乘子（$\beta$、$\mu$），也就多一个「外部施加的势」。统计力学的系综家族，本质是约束的一族。</span>

## 8 小结

- **等几率原理**：孤立系统能量壳内各微观态等概率，是统计力学唯一的基本假设。
- **微正则系综**：$E, V, N$ 固定的孤立系统；每个微观态概率 $1/\Omega$。
- **玻尔兹曼公式** $S = k_B \ln \Omega$：统计量 $\Omega$ 与热力学量 $S$ 的桥梁，整个热力学由此重构。
- 温度、压强、化学势都由 $S$ 的偏导定义；第一定律成为定理而非公理。
- **负温度**是能量上限系统的特殊现象，比无穷高温更热；**遍历性**让时间平均等于系综平均。
- **二能级自旋**是微正则方法的完整演练：数态 → 熵 → 温度，并自然展示负温度机制。
- **三系综衔接**：正则、巨正则都是「放松约束 + 拉格朗日乘子」的版本；微正则居概念上游。

在下一节，我们离开"能量固定"的孤立系统，允许系统与热库交换能量——这将导出统计力学最常用的**玻尔兹曼分布**。
