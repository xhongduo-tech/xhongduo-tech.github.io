## 为什么从金属自由电子气开始

金属导电、导热、有光泽、可延展——这些"金属性"的共同根源是：金属原子的外层电子脱离原子束缚，形成在晶格中自由运动的**电子气**。1900 年德鲁德用经典理想气体处理它，能解释欧姆定律与维德曼-弗兰兹定律，但预言电子比热 $3/2Nk_B$，比实验大了两个数量级——经典模型在此惨败。1927 年索末菲把电子换成**费米气体**，一切豁然开朗：电子的费米温度高达数万开尔文，室温下它们是"强简并"的，热容被泡利原理压到线性项。<span class="marginnote">索末菲模型（1927）把德鲁德模型的经典电子换成费米-狄拉克统计的量子电子，保留"自由电子+碰撞弛豫"的骨架。这看似小改动，却一次性解决了电子比热、磁化率的经典难题。它也是「把经典模型换成量子统计」这个动作的教科书示范——方法不变，统计改对，结论天翻地覆。</span>

## 1 从德鲁德到索末菲：经典电子气的失败

**德鲁德模型**（1900）：把金属电子当经典理想气体。

- 电子密度 $n \sim 10^{28}$–$10^{29}\ \text{m}^{-3}$；
- 经典预言电子比热 $C_e = \frac{3}{2}Nk_B$，与晶格比热 $3Nk_B$ 同量级；
- 实验却显示室温金属热容 ≈ 晶格热容，电子贡献几乎为零。

**经典模型的矛盾**：若每个电子都带 $3k_BT/2$ 的热能，铜的电子比热该是晶格比热的一半，实验否定了它。索末菲指出答案在量子统计：电子的费米温度 $T_F = \varepsilon_F/k_B \sim 10^4$–$10^5$ K，室温 $T \ll T_F$，电子气高度简并——**绝大多数电子被泡利原理"锁死"在费米面以下，根本分不到热能**。<span class="marginnote">经典 vs 量子电子气的核心差别：经典电子像热水分子，每个都分到 $k_BT$；简并电子像"挤满的地铁"，只有费米面附近的乘客能挪动，车厢深处的乘客纹丝不动。能动的电子比例 $\sim T/T_F \sim 0.4\%$，所以电子比热被压到经典值的千分之一量级。</span>

## 2 电子比热：线性 $T$ 定律

索末菲用费米分布计算电子气内能。$T \ll T_F$ 时，只有费米面附近宽度 $\sim k_BT$ 的壳层受温度影响，能量修正量级为：

$$U(T) = U(0) + \frac{\pi^2}{4}Nk_B\frac{(k_BT)^2}{\varepsilon_F}$$

对温度求导，得**电子比热**：

$$C_e = \gamma T, \qquad \gamma = \frac{\pi^2}{2}Nk_B\frac{k_B}{\varepsilon_F} = \frac{\pi^2}{2}Nk_B\frac{1}{T_F}$$

**核心概念：电子比热线性于 $T$**。$C_e = \gamma T$ 与晶格比热 $C_{\text{lat}} \propto T^3$ 在低温下行为完全不同：$T \to 0$ 时电子比热（$\propto T$）胜出，晶格比热（$\propto T^3$）衰减更快。低温总比热：

$$C_V = \gamma T + A T^3$$

实验上做 $C_V/T$ 对 $T^2$ 图，截距给 $\gamma$、斜率给 $A$——这是测量费米能级和德拜温度的经典实验方法。<span class="marginnote">$C_e = \gamma T$ 的推导用索末菲展开（Sommerfeld expansion）：把费米分布的能量积分按 $k_BT/\varepsilon_F$ 做小参数展开。第一项是 $T=0$ 的结果，第二项给出 $\propto T^2$ 的内能修正。这个展开是费米气体理论的"标准操作"，进阶教材会在《退化电子气》的基础上把它系统化。</span>

## 3 公式解析：索末菲展开的首项修正

$$

U(T) - U(0) = \frac{\pi^2}{4}Nk_B\frac{(k_BT)^2}{\varepsilon_F}

$$

逐项拆解：

- **第一步，问题设定**：$U = \int_0^\infty \varepsilon\, g(\varepsilon)\, f(\varepsilon)\,\mathrm{d}\varepsilon$，其中 $f(\varepsilon) = 1/(e^{(\varepsilon-\mu)/k_BT}+1)$ 是费米函数。
- **第二步，小参数**：$T \ll T_F$，即 $k_BT/\varepsilon_F \ll 1$。费米函数只在 $\mu$ 附近 $k_BT$ 宽度内偏离阶梯。
- **第三步，索末菲展开**：对积分做展开，第一项是零温积分 $\frac{3}{5}N\varepsilon_F$，第二项正比于 $(k_BT)^2$，系数含 $\pi^2/6$，乘上态密度相关的因子后得上式。
- **第四步，$T^2$ 而非 $T$**：能动的电子数 $\sim N\cdot T/T_F$，每个多拿 $\sim k_BT$ 的能量，总修正 $\sim N(k_BT)^2/\varepsilon_F$。两个因子相乘，所以是 $T^2$。
- **直觉**：费米海只在"水面"起涟漪。涟漪的宽度 $\propto T$、深度 $\propto T$，涨起来的总"水花能量" $\propto T^2$，对温度求导即得 $\gamma T$。

## 4 金属的费米参数与维德曼-弗兰兹定律

金属自由电子气的特征参数（以铜为例）：

| 量 | 符号 | 数值 |
| --- | --- | --- |
| 电子密度 | $n$ | $8.5\times10^{28}\ \text{m}^{-3}$ |
| 费米波矢 | $k_F$ | $1.36\times10^{10}\ \text{m}^{-1}$ |
| 费米速度 | $v_F = \hbar k_F/m$ | $1.57\times10^6\ \text{m/s}$ |
| 费米温度 | $T_F$ | $8.2\times10^4\ \text{K}$ |
| 电子比热系数 | $\gamma$ | $\sim 0.7\ \text{mJ/(mol·K}^2)$ |

费米速度约 $1.6\times10^6\ \text{m/s}$，是声速的几千倍——电子的"热速度"远大于经典理想气体的预期。<span class="marginnote">费米速度与经典热速度的对比很惊人：经典模型预言室温电子速率约 $10^5\ \text{m/s}$，索末菲的费米速度约 $1.6\times10^6\ \text{m/s}$，但电子比热却小了 100 倍——因为费米海里的电子虽然快，却"动不了"。速度看费米面，热容看费米面附近的壳层，两者完全不同。</span>

**维德曼-弗兰兹定律**：金属热导率 $\kappa$ 与电导率 $\sigma$ 之比正比于温度：

$$\frac{\kappa}{\sigma} = LT, \qquad L = \frac{\pi^2}{3}\left(\frac{k_B}{e}\right)^2 \approx 2.44\times10^{-8}\ \text{W·Ω/K}^2$$

洛伦兹数 $L$ 是普适常数，与金属种类无关。**辨析｜易错点：** 维德曼-弗兰兹定律在德鲁德经典模型里也能"碰巧"推出（用的是 $C_e = \frac32 Nk_B$），但数值差一倍；索末菲的量子版本给出正确的 $\pi^2/3$ 系数。所以"定律成立"本身不证明模型正确——要看系数。高温或低温极端下 $L$ 会偏离，因为散射机制变化。

## 5 超越索末菲模型：周期势与能带

索末菲模型假设电子完全自由，实际金属电子在晶格周期势中运动。布洛赫定理说周期势中的电子态仍是平面波 × 周期函数，但能量色散分裂成**能带**，出现禁带。这带来索末菲模型无法解释的现象：

- 为什么有的固体是导体、半导体、绝缘体（费米能级落在能带还是禁带）；
- 为什么有效质量 $m^*$ 可以偏离裸电子质量；
- 为什么费米面的形状揭示材料的各向异性。

索末菲模型是"零级近似"，能带理论是它的下一级——但量子统计的框架（费米分布、费米能级、$C_e = \gamma T$）原封不动保留。<span class="marginnote">能带理论的统计部分几乎全部继承索末菲模型：把自由电子态密度 $g(\varepsilon)$ 换成能带结构的态密度（含范霍夫奇点），其余推导照搬。半导体里费米能级落在禁带、载流子极稀薄，费米分布退化为玻尔兹曼分布——又是"稀薄极限"的熟悉面孔。统计力学给能带理论提供的，正是这套通用的分布语言。</span>

## 6 应用：热电子发射与功函数

金属电子气的费米统计不仅解释比热，还解释「电子怎么跑出来」——热电子发射是它的经典应用。

**现象**。加热金属丝，电子获得足够能量越过表面势垒逃逸到真空中——白炽灯、电子管、阴极射线管都靠它工作。逃逸电流密度由**理查森-杜什曼方程（Richardson–Dushman equation）**描述：

$$J = A T^2 e^{-W/k_BT}$$

其中 $W$ 是**功函数**（电子逃逸需要越过的最小能量），$A = 4\pi em_e k_B^2/h^3 \approx 1.2\times10^6\ \text{A/(m}^2\text{K}^2)$ 是理查森常数。<span class="marginnote">理查森-杜什曼方程的推导思路：费米分布的「高速尾巴」——电子能量超过真空能级（费米能 + 功函数）的那部分——才能逃逸，比例由玻尔兹曼因子 $e^{-W/k_BT}$ 控制。$T^2$ 因子来自态密度与速度的积分。这个方程把《费米-狄拉克统计》的费米面、高速尾巴与《麦克斯韦速度分布》的玻尔兹曼尾巴揉在一起。</span>

**功函数的物理**。功函数取决于金属种类与表面取向：钨约 4.5 eV，铯约 2.1 eV。功函数低 = 电子容易逃逸 = 光电阴极材料（光电倍增管）、场发射材料（电子显微镜）的选择依据。温度每升一点、电流指数暴涨——正是 $e^{-W/k_BT}$ 的威力。

**辨析｜易错点：** 热电子发射测量的是「费米分布的高速尾巴」，但它发生在「金属内部费米统计 + 表面逃逸玻尔兹曼因子」的组合上——不要误以为这是「经典理想气体的麦克斯韦尾巴」。电子气在金属内是高度简并的费米气体，逃逸过程只是把费米海的「边缘」与真空能级之间的玻尔兹曼尾巴漏出来。两者结合，正是「费米统计 + 玻尔兹曼因子」的分工。

**电子比热的实验确认**。回到本节主线：$C_V = \gamma T + AT^3$ 的分解是索末菲模型的直接检验。低温下测 $C_V/T$ 对 $T^2$ 作图，直线截距给 $\gamma$（电子贡献）、斜率给 $A$（声子贡献）。无数金属的测量都给出与自由电子模型同量级的 $\gamma$——索末菲模型虽然粗糙，方向完全正确。

## 7 小结

- **索末菲模型**：把德鲁德经典电子换成费米气体，$T_F \sim 10^4$–$10^5$ K，室温电子高度简并。
- **电子比热** $C_e = \gamma T$（$\gamma \propto 1/T_F$）：比经典值小两个数量级，低温下 $C_V = \gamma T + AT^3$。
- **索末菲展开**：费米积分的 $k_BT/\varepsilon_F$ 小参数展开，首项修正 $\propto T^2$。
- 费米参数（$k_F$、$v_F$、$T_F$）由电子密度唯一确定；费米速度约 $10^6\ \text{m/s}$。
- **维德曼-弗兰兹定律** $\kappa/\sigma = LT$，洛伦兹数 $L = \pi^2 k_B^2/3e^2$ 普适。
- 能带理论继承量子统计框架，索末菲模型是零级近似。
- **热电子发射**：$J = AT^2e^{-W/k_BT}$，费米统计高速尾巴 + 表面功函数的组合。
- **实验确认**：$C_V/T$ 对 $T^2$ 直线给出 $\gamma$（电子）与 $A$（声子）。
