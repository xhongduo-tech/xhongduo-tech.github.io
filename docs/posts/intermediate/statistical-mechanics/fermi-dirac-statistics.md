## 为什么从费米-狄拉克统计开始

经典统计假设粒子可分辨、每个能级可以容纳任意多粒子。但真实粒子是**全同的**，而且分两类：自旋为半整数的**费米子**（电子、质子、中子）遵守**泡利不相容原理**——每个量子态至多一个粒子；自旋为整数的**玻色子**（光子、声子、$\pi$ 介子）没有这个限制。费米-狄拉克统计（Fermi–Dirac statistics）就是费米子的分布律。它解释金属为什么导电、白矮星为什么不会坍缩、中子星为什么存在——没有它，我们熟悉的物质世界根本无法理解。<span class="marginnote">泡利 1925 年提出不相容原理时还没有量子场论，他从原子光谱的经验规律出发；费米（1926）与狄拉克（1926）同年分别给出费米子的统计分布。费米当时还称它"统计力学的一种新形式"，两年后就解释了金属自由电子气的诸多疑难。</span>

## 1 全同粒子与两类统计

量子力学里，全同粒子不可分辨。$N$ 个粒子分配到单粒子态 $\varepsilon_l$ 的方式计数，在三种情形下不同：

**可分辨粒子（经典）**：$W = \dfrac{N!}{\prod_l n_l!}$，占据数 $n_l$ 无上限 → 玻尔兹曼分布。
**费米子**：每个态至多一个粒子，$n_l \in \{0, 1\}$，$W = \prod_l \dfrac{\omega_l!}{n_l!(\omega_l - n_l)!}$（$\omega_l$ 为能级简并度）→ 费米-狄拉克统计。
**玻色子**：占据数无上限，$W = \prod_l \dfrac{(n_l + \omega_l - 1)!}{n_l!(\omega_l - 1)!}$ → 玻色-爱因斯坦统计（下一节）。

费米子的计数里出现了组合数 $\binom{\omega_l}{n_l}$，正是"从 $\omega_l$ 个态里选 $n_l$ 个填"——不相容原理让它成为组合学问题。<span class="marginnote">三类计数的差别本质上是「粒子是否可分辨 × 占据数是否受限」两个问题的组合。$W$ 的表达式是《组合数学》里排列组合的直接应用：费米子的 $W$ 是选择问题（$C(\omega, n)$），玻色子的是隔板法问题（$C(n+\omega-1, n)$）。统计物理把这些计数公式推到了 $10^{23}$ 量级。</span>

## 2 费米-狄拉克分布

对 $W$ 取对数（斯特林公式），在总粒子数 $\sum n_l = N$ 与总能量 $\sum n_l\varepsilon_l = E$ 约束下最大化，得到**费米-狄拉克分布**：

$$n_l = \frac{\omega_l}{e^{\beta(\varepsilon_l - \mu)} + 1}$$

即每个单粒子态的平均占据数：

$$\bar f(\varepsilon) = \frac{1}{e^{\beta(\varepsilon - \mu)} + 1}$$

**核心概念：费米分布函数** $f(\varepsilon)$ 给出能量为 $\varepsilon$ 的单粒子态被占据的平均概率，其中 $\mu$ 是化学势。<span class="marginnote">费米分布与玻尔兹曼分布的关系：当 $e^{\beta(\varepsilon-\mu)} \gg 1$（即占据数远小于 1），分母的 $+1$ 可忽略，$f(\varepsilon) \to e^{-\beta(\varepsilon-\mu)}$——回到玻尔兹曼分布的指数形式。所以费米-狄拉克统计在"稀薄极限"下自动退化为经典统计。量子统计与经典统计不是对立，而是包含关系。</span>

## 3 费米分布的行为：从零温到高温

费米分布的温度依赖是最重要的物理：

**零温 $T = 0$**：$\beta \to \infty$，费米函数变成阶梯函数——$\varepsilon < \mu$ 时 $f = 1$，$\varepsilon > \mu$ 时 $f = 0$。系统把能级从低到高填满，直到**费米能级** $\varepsilon_F \equiv \mu(T=0)$。最高被占能级以下全部填满，以上全部为空。
**有限低温 $k_BT \ll \varepsilon_F$**：只有费米面附近宽度约 $k_BT$ 的薄壳层里，占据数从 1 平滑过渡到 0。远离费米面的能级要么全满、要么全空，温度对它们毫无影响。
**高温/低密度**：$e^{\beta(\varepsilon-\mu)} \gg 1$，退化为玻尔兹曼分布。

**简并度（degeneracy）**：$k_BT \ll \varepsilon_F$ 的状态叫**强简并（degenerate）**，占据数高度接近阶梯函数。<span class="marginnote">「简并」这个词在这里容易与"能级简并"混淆。统计力学里说"强简并费米气体"指 $k_BT \ll \varepsilon_F$，即量子统计效应显著、经典近似失效。金属自由电子气的费米能约 7 eV，对应温度约 $8\times10^4$ K——室温对它而言是"零温"，这就是为什么金属电子气必须用费米统计而绝不能当理想气体。</span>

**辨析｜易错点：** $\mu$ 与 $\varepsilon_F$ 不严格相等。$\varepsilon_F$ 定义为零温化学势，有限温度下 $\mu(T)$ 随温度略有移动（低温近似 $\mu \approx \varepsilon_F[1 - \frac{\pi^2}{12}(k_BT/\varepsilon_F)^2]$）。许多教材把 $\mu$ 与 $\varepsilon_F$ 混用，在低温金属物理里误差极小，但严格推导时要分清。

## 4 公式解析：费米函数的三个极限

$$

f(\varepsilon) = \frac{1}{e^{(\varepsilon - \mu)/k_BT} + 1}

$$

逐项拆解：

- **第一步，分母的 $+1$**：与玻尔兹曼分布 $e^{-(\varepsilon-\mu)/k_BT}$ 相比，费米分布的分母多了一个 $+1$，这来自不相容原理的计数修正。占据数永远不会超过 1，正是 $+1$ 保证 $f \le 1$。
- **第二步，$\varepsilon = \mu$ 处取值**：$f(\mu) = 1/(1+1) = 1/2$——费米面处的占据概率恒为一半，这是费米分布标志性的"半填充点"。
- **第三步，零温阶梯**：$T\to 0$ 时 $(\varepsilon-\mu)/k_BT \to \pm\infty$，$f$ 骤变为 0 或 1，形成阶梯。
- **第四步，对称性**：$f(\varepsilon)$ 关于 $\mu$ 反对称：$f(\varepsilon) + f(2\mu - \varepsilon) = 1$。这个对称性在低温展开（索末菲展开）里反复使用。
- **直觉**：费米面是"水位线"。$T=0$ 时所有态被填到水位线 $\mu$ 为止；升温只是让水位线附近的"水面"起了一层薄薄的波纹（宽度 $\sim k_BT$），深水与高空完全不受影响。

## 5 费米子世界的应用预览

费米-狄拉克统计直接支撑的物理：

- **金属自由电子气**：电子费米能级、电子比热 $C_e \propto T$、简并压（下一节与《金属自由电子气》详述）。
- **白矮星**：电子气简并压对抗引力坍缩；质量超过钱德拉塞卡极限（约 1.4 倍太阳质量）时简并压撑不住，电子被压进质子形成中子星。
- **半导体**：费米能级决定载流子分布；本征半导体费米能级大致在禁带中央，掺杂移动费米能级——整个现代电子学的根基。

<span class="marginnote">白矮星的故事是费米统计最戏剧性的应用：钱德拉塞卡（Subrahmanyan Chandrasekhar）1930 年在前往英国的轮船上算出了白矮星质量上限，因此获 1983 年诺贝尔奖。比这个极限更重的恒星核心塌缩成中子星甚至黑洞——费米分布函数从"金属导电"一路写到天体物理的死亡线。</span>

## 6 费米分布的推导：从巨正则系综到占据数

费米-狄拉克分布可以从《巨正则系综》的框架干净地推出来，这条路线值得走一遍，因为它同时复习了两个主题。

**第一步，巨配分函数**。对近独立费米子，每个单粒子态 $l$ 的占据数 $n_l \in \{0,1\}$，巨配分函数因子分解：

$$\Xi = \prod_l \left(1 + e^{-\beta(\varepsilon_l - \mu)}\right)$$

**第二步，取对数**。$\ln\Xi = \sum_l \ln\left(1 + e^{-\beta(\varepsilon_l-\mu)}\right)$，这个「$\ln$ 一个因子」的结构是量子统计的标志。

**第三步，平均占据数**。占据数的期望由 $\bar n_l = -\frac{1}{\beta}\frac{\partial\ln\Xi}{\partial\varepsilon_l}$ 求得：

$$\bar n_l = \frac{1}{e^{\beta(\varepsilon_l - \mu)} + 1}$$

这就是费米-狄拉克分布。整个推导只需「巨配分函数 + 求导」两步，比最概然分布的拉格朗日乘子法更系统，也更容易推广。<span class="marginnote">同样的推导对玻色子给出 $\Xi = \prod_l (1 - e^{-\beta(\varepsilon_l-\mu)})^{-1}$ 与 $\bar n_l = 1/(e^{\beta(\varepsilon_l-\mu)}-1)$。两种统计只差巨配分函数里因子「加 1」还是「减 1」——泡利禁令在配分函数语言里就一句话。这个统一视角让《玻色-爱因斯坦统计》与本节可以互相翻译。</span>

**低温展开：索末菲展开**。$T \ll T_F$ 时费米函数的积分可以用索末菲展开系统处理。核心工具是费米函数的「阶梯 + 尾部修正」结构：任意函数 $H(\varepsilon)$ 的费米积分满足

$$\int_0^\infty H(\varepsilon)\,f(\varepsilon)\,\mathrm{d}\varepsilon = \int_0^\mu H(\varepsilon)\,\mathrm{d}\varepsilon + \frac{\pi^2}{6}(k_BT)^2 H'(\mu) + O(T^4)$$

这个展开是《金属自由电子气》与《退化电子气》里一切低温结果（电子比热 $\propto T$、化学势随温度移动）的数学引擎。看懂它，费米气体的低温行为就全在你手里了。

**辨析｜易错点：** 索末菲展开是「$T/\mu$ 小参数展开」，要求费米气体强简并（$T \ll T_F$）。弱简并或经典极限（$T \gg T_F$）下展开失效，要用别的近似。判断「该不该用索末菲展开」，就看 $k_BT/\varepsilon_F$ 是否远小于 1。

费米统计这一节到此收束：它给出的不仅是一条分布公式，更是一套「费米面思维」——看占据数、看费米能级、看泡利封锁。下一节《玻色-爱因斯坦统计》将用同一个数学骨架处理没有泡利禁令的另一类粒子。

**费米子的另一张面孔：泡利封锁**。费米分布直接导致「泡利封锁」效应：费米面以下的态已满，粒子无法散射进这些「已占用」的态，只有费米面附近的空态可供散射。这个效应抑制了费米气体的散射率，解释了金属电子为什么平均自由程可以远大于晶格常数——它们不是不碰撞，而是「无处可去」的碰撞被泡利原理拦截。核物理里的「饱和性」、中子星的刚度，都源于同一种封锁。

## 7 小结

- **费米子**：自旋半整数、遵守泡利不相容原理，每个量子态至多一个粒子。
- **费米-狄拉克分布** $\bar f(\varepsilon) = 1/(e^{\beta(\varepsilon-\mu)}+1)$；零温退化为阶梯函数，费米能级 $\varepsilon_F$ 以下全满、以上全空。
- 低温下只有费米面附近 $k_BT$ 宽度的壳层受温度影响——这是理解电子比热与金属物理的关键。
- **强简并**指 $k_BT \ll \varepsilon_F$；稀薄极限下自动退化为玻尔兹曼分布。
- 应用：金属电子气、白矮星简并压、半导体费米能级。
- **巨正则推导**：$\Xi = \prod_l(1 + e^{-\beta(\varepsilon_l-\mu)})$，占据数 $\bar n = -\partial\ln\Xi/\beta\partial\varepsilon_l$。
- **索末菲展开**：低温费米积分的标准工具，电子比热与化学势温度依赖的引擎。
- **泡利封锁**：费米面下态已满，散射被泡利原理抑制，解释长平均自由程。
- **负温度边界**：平动自由度能量无上界永正温；只有有界谱系统可负温。
