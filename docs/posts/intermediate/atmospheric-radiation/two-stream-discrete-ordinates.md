## 为什么从数值方法开始

上一节的辐射传输方程一旦带上散射项，就成了「带积分算子的微分方程」——除非做极端简化，否则**没有闭式解**。可大气几乎处处有散射：云的可见光、气溶胶、分子瑞利散射，全都让方程无从手解。<span class="marginnote">气候模式每算一步都要对每个网格、每条波段解一遍这个方程，解的「成本」直接决定模式跑多快。于是大气辐射学分化出两条路：追求精度的<strong>逐线/逐方向</strong>解法（离散纵标法），与追求速度的<strong>二流近似</strong>——两条路把「精度—速度」的权衡摆在了台面上。</span>

这一节讲清两个最经典的求解框架：**离散纵标法（discrete ordinates method）**把角度离散成有限个方向、把积分换成求和，逼近到任意精度；**二流近似（two-stream approximation）**只保留上、下两个方向，换来一组可手解的常微分方程。

## 1 为什么散射让方程「难解」

不含散射的史瓦西方程 $dI/d\tau = -I + B$ 是一阶线性 ODE，有闭式解。加上散射后，源函数里出现 $\int_{4\pi} P(\mathbf{\hat{s}},\mathbf{\hat{s}}') I(\mathbf{\hat{s}}')\,d\Omega'$——**未知函数 $I$ 同时出现在微分项和积分项里**，方程变成积分微分方程，且角度是连续变量。

**重点：一切数值方法的共同思路，是把「连续的角度」替换成「离散的方向集合」。** 一旦角度只剩有限个，积分就变成求和，积分微分方程退化成有限个耦合的常微分方程——剩下的只是线性代数。离散纵标法与二流近似的差别，只在「保留多少个方向、如何选取」。

这个权衡在今天格外重要：气象卫星每天要反演上百万像元，每个像元现场跑一次 DISORT 并不现实，业务上普遍用**预计算查找表（LUT）**——把 DISORT 结果离线算好，在线只做插值。理解数值方法的取舍，才能理解 LUT 误差从哪里来。

## 2 离散纵标法（DISORT）

**离散纵标法（discrete ordinates method）**：在 $2N$ 个选定的天顶角方向（纵标）上求解辐射传输方程，方向之间用数值求积（通常是 Gauss–Legendre 求积）连接。

记 $\mu_i$ 为第 $i$ 个方向的 $\cos\theta$（$i = 1, \dots, N$ 对应下行，$i = N+1, \dots, 2N$ 对应上行），方程离散为 $2N$ 个常微分方程：

$$\mu_i \frac{dI_i}{d\tau} = I_i - (1-\tilde\omega)B - \frac{\tilde\omega}{2}\sum_{j=1}^{2N} w_j\, P(\mu_i, \mu_j)\, I_j$$

其中 $w_j$ 是求积权重。$N$ 越大，方向越密，解越接近真实；$N=16$ 的 DISORT 已是行业标准的「精确解」参考。<span class="marginnote">DISORT（DIScrete Ordinate Radiative Transfer，Stamnes 等人 1988 年的开源程序）是目前被引用最多的辐射传输求解器。它的输出常被当作「真值」去检验二流近似、检验卫星反演算法的误差——你会在几乎所有遥感文献里看到「用 DISORT 做基准」这句话。</span>

**相函数的勒让德展开**：相函数只依赖散射角 $\Theta$，按勒让德多项式展开：

$$P(\cos\Theta) = \sum_{l=0}^{L} (2l+1)\, \chi_l\, P_l(\cos\Theta)$$

前三项系数 $\chi_0 = 1$（归一化）、$\chi_1 = g$（非对称因子）、$\chi_2$ 表征前向后向偏好。$L$ 越大越精细，但计算量随之上升——这是离散纵标法的第二个自由度。**补充｜$L$ 的选择有讲究**：工程上常用「截断技巧」——把相函数前向峰用 δ 函数剥掉、只展开剩余部分（即 delta-M 方法），在低 $L$ 下也能保住精度。离散纵标与二流在这里汇合：delta 修正不是二流专享。

## 3 二流近似家族

**二流近似（two-stream approximation）**：只保留两个方向——向上流 $I^+$ 与向下流 $I^-$，把立体角积分约成两个方向间的交换。它不是一个单一公式，而是一个**家族**，按「如何选方向、如何闭合矩」分成若干版本：

| 变体 | 选流方式 | 特点 |
| --- | --- | --- |
| Eddington | 角度分解 $I = I_0 + \mu I_1$ | 经典，解析解干净，适合近各向同性 |
| delta-Eddington | Eddington + δ 函数前向峰修正 | 强前向散射（云、气溶胶）下大幅改善 |
| 求积法（quadrature） | 取 $\mu = \pm 1/\sqrt{3}$ | 与 Eddington 数值等价，实现直观 |
| 半球平均（hemispheric） | 上、下半球各取平均方向 | 简单，常用于快速气候模式 |

其中 **delta 修正（delta-M / delta-Eddington）** 是工程关键：云和大气粒子散射有极强的**前向峰**（大部分光「几乎不偏折」地继续前行），直接二流会严重高估散射带来的削弱。delta-Eddington 把前向峰剥出来当作「透过」，把剩余散射折进标定后的系数，用一次参数重标定换回准确性。<span class="marginnote">delta 修正是「反正则化」的典型：既然无法用少数方向描述尖峰，就先把尖峰解析地拿掉，只对光滑的剩余部分做近似。同样的思想在湍流模式、辐射输运里反复出现——先分离奇性，再离散正则部分。</span>

## 4 公式解析：Eddington 近似的矩方程

**Eddington 近似的核心，是把辐射场按角度展开到一阶，再取「矩」得到一组可解的常微分方程。** 设：

$$I(\tau, \mu) = I_0(\tau) + \mu\, I_1(\tau)$$

并取相函数 $P(\mu,\mu') = 1 + 3g\mu\mu'$（线性各向异性）。代入平面平行辐射传输方程后，对 $\mu$ 取零阶矩（直接平均）与一阶矩（乘 $\mu$ 再平均），得到两个耦合方程：

$$\frac{dI_0}{d\tau} = \frac{1}{2}\,(1 - \tilde\omega g)\, I_1, \qquad \frac{dI_1}{d\tau} = 3\,(1 - \tilde\omega)\,(I_0 - B)$$

三步拆解：

- **第一步，看零阶矩**：第一个方程把「平均辐射强度 $I_0$ 的变化率」与「各向异性强度 $I_1$」联系起来。因子 $(1-\tilde\omega g)$ 合并了吸收（$1-\tilde\omega$）与非对称散射（$g$）的联合作用，纯吸收时 $g=0$、$\tilde\omega=0$，退化为 $dI_0/d\tau = I_1/2$。
- **第二步，看一阶矩**：第二个方程说，各向异性（$I_1$）的变化由「吸收造成的源—汇差」$3(1-\tilde\omega)(I_0 - B)$ 驱动。当辐射场趋近各向同性（$I_1 \to 0$）且 $I_0 \to B$（局地热平衡），两式同时归于零——正是无通量的稳态解。
- **第三步，合成净通量**：净辐照度 $F = 2\pi\int_{-1}^{1}\mu I\,d\mu = 2\pi\int\mu(I_0 + \mu I_1)\,d\mu = \dfrac{4\pi}{3} I_1$。于是两个标量方程闭合成一条关于通量的二阶方程，可解析求解——这就是 Eddington 能给出闭式反射率/透过率的全部秘密。

**算例：均匀云层的反射率。** 取 $\tilde\omega = 0.999$、$g = 0.85$、$\tau = 15$、太阳 $\mu_0 = 0.5$：

- 用 delta-Eddington 解均匀层反射率，约 $R \approx 0.6$，与典型层积云反照率一致。
- 若把 $g$ 错设成 0（忽略前向峰），$R$ 会明显偏低、误差可达百分之十几。
- 以 DISORT($N = 16$) 为基准，delta-Eddington 的相对误差通常在几个百分点内，裸 Eddington 则可能差 10% 以上。

一个 $g$ 的差别就是十分之一的反射率——**这正是相函数近似精度的真实代价**。

## 5 易错辨析：二流近似的适用边界

**辨析｜易错点：** 二流近似不是万能的，三个最常踩的坑：

- **强前向散射必须配 delta 修正**：气溶胶与云的相函数前向峰极陡，裸 Eddington 会显著高估光学厚度效应；**用二流前先问「相函数有没有尖峰」**。太阳天顶角大、光学厚度大时，误差尤其明显。
- **二流只对「通量级」量可靠**：二流输出的是总辐照度、反射率、透过率这类角度积分量；要分辨「哪个方向的辐射」（卫星某个通道的视线亮度），二流的两个方向根本不够，必须上离散纵标。<span class="marginnote">判别一句话就够了：要的是「多少能量」用二流，要的是「哪个方向的光」用 DISORT。卫星反演属于后者，所以业务反演普遍跑 DISORT 或逐线模式；气候模式加热率属于前者，二流是主力。</span>
- **相邻层的参数不能乱取**：二流方程里的 $\tilde\omega$、$g$ 是**层平均**的有效值，需按层加权（常按光学厚度加权）而非简单算术平均；分层太粗时，各层间的耦合（特别是强吸收层附近）会引入系统性偏差。

| 应用场景 | 推荐方法 |
| --- | --- |
| 气候模式加热率、辐射收支 | 二流（delta-Eddington） |
| 卫星单视场反演（云/气溶胶） | DISORT |
| 云与辐射的边界情形 | DISORT 或高阶二流 |
| 精度基准、算法检验 | DISORT（$N \ge 16$） |

选型表再补一句：**气候模式辐射每网格柱只有几毫秒预算**，逐日跑几次二流、配合 k 分布谱带参数化，就是模式辐射的常规配置。

## 6 小结

- 带散射的辐射传输方程是**积分微分方程**，无一般闭式解，必须数值求解。
- **离散纵标法**把角度离散成 $2N$ 个求积方向，$N$ 增大逼近真值，DISORT 是行业基准。
- 相函数用**勒让德多项式**展开，系数 $\chi_0=1$、$\chi_1=g$；$L$ 决定角分辨率。
- **二流近似**只保留上、下两个方向，是一个家族：Eddington、delta-Eddington、求积法、半球平均。
- **delta 修正**剥离前向散射峰，是二流在云/气溶胶条件下可靠的前提。
- 选型口诀：**要能量用二流，要方向用 DISORT**。
- delta 修正（delta-M / delta-Eddington）是二流在云、气溶胶场景可靠的先决条件。
- 业务遥感常用 DISORT 预计算查找表（LUT），在线只做插值。
- **delta-M 与二流共享一把手术刀**：都先把相函数前向峰解析剥离，再离散剩余部分。
- 二流的误差量级（几个百分点）决定了气候模式辐射「骨架」的结实程度。
- **光谱积分**（k 分布）与**角度离散**（二流/DISORT）是辐射方案的两个独立自由度。
- 业务 LUT 把 DISORT 结果离线算好，在线插值——精度与速度的分工由此完成。
- **判断收敛的准则**：加方向数直到解不再变——解的稳定性本身就是误差信号。
- 二流是「一个数的非对称因子」进方程的近似，DISORT 则完整保留相函数展开。
- 云/气溶胶强前向散射下，裸二流必配 delta 修正，否则高估削弱。
- 二流输出通量级量、DISORT 输出方向级量，选型只看要哪个量。
- 数值方法的意义不止于「解方程」：把连续角度离散成有限方向、把积分换成求和，这套「离散化思维」也是从大气辐射走向一切计算物理的通用套路。

在下一节，我们将转向散射的物理来源，回答相函数与系数 $g$ 背后的物理——也就是瑞利散射与米氏散射那一章的起点。我们已经攒齐了数值求解辐射传输的两把钥匙（离散纵标与二流），接下来该问：相函数本身，究竟长什么样、由什么决定？
