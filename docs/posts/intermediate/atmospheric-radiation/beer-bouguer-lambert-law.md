## 为什么从削弱定律开始

上一节我们拿到了光源：黑体辐射给出了「太阳/地表该发多少光」。但这束光从太阳到大气、再穿越大气层到达地面的路上，会被分子吸收、被粒子散射——**光在路上的「损耗」如何定量描述**，就是本节的主题。<span class="marginnote">它的意义远超一条经验公式：气象上用它由地面太阳辐照度反推大气浑浊度，遥感上用它把「测到的光强」换算成「大气的吸收物质总量」，通信上它的思想也出现在无线信号随距离衰减的模型里。一条定律，三个学科共用。</span>

**比尔—布格—朗伯定律（Beer–Bouguer–Lambert law）**：单色平行辐射穿过均匀吸收介质时，透射光的强度随路径长度按指数衰减。它是辐射传输方程的第一块积木——把「吸收」这一个过程先讲清楚，后面再逐步加入发射与散射。

## 1 从一层大气开始

想象一束波长为 $\lambda$ 的单色平行光，垂直穿过厚度为 $ds$ 的一层均匀大气。设入射强度为 $I_\lambda$，穿过这薄层后被吸收掉了多少？实验与理论都给出同一结论：**被吸收的份额与入射强度、吸收物质密度、路径长度三者的乘积成正比**：

$$dI_\lambda = -\,k_\lambda\,\rho\, I_\lambda\, ds$$

负号表示强度在减小。<span class="marginnote">比例系数 $k_\lambda$ 叫作<strong>质量吸收系数（mass absorption coefficient）</strong>，单位 $\mathrm{m^2\,kg^{-1}}$，它刻画「每千克吸收物质对某波长的光有多贪吃」。系数只依赖物质的种类与波长，与密度、路径无关——这正是它作为「物质属性」被写进谱线数据库的原因。</span>

**重点：这条式子是一次齐次的。** 光强 $I_\lambda$ 同时出现在等式两边，意味着「衰减比例」与光强本身无关——光强一倍，衰减掉的也恰好翻倍，比例恒定。这是指数定律的数学根源，也是「线性光学」的体现：光太强、出现非线性效应时，这条定律就会失效。

把这条式子和上一节的普朗克函数放在一起看，就得到辐射传输的最简骨架：**发射由 $B_\nu(T)$ 决定，削弱由 $k_\lambda\rho$ 决定**。两条信息合并，正是卫星反演「先削后补」的全部起点——本专题第 5 篇《辐射传输方程》会把「补」正式请进场。

## 2 把微分积成指数

对上面的微分方程做定积分：光从 $s_0$ 走到 $s_1$，强度从 $I_\lambda(0)$ 衰减到 $I_\lambda(s_1)$，两端都除以 $I_\lambda$ 再积分：

$$\int_{I(0)}^{I(s_1)} \frac{dI_\lambda}{I_\lambda} = -\int_{s_0}^{s_1} k_\lambda\,\rho\, ds$$

左边积出 $\ln\bigl[I(s_1)/I(0)\bigr]$，右边积分结果定义为**光学厚度（optical thickness / optical depth）** $\tau_\lambda$：

$$\tau_\lambda = \int_{s_0}^{s_1} k_\lambda\,\rho\, ds$$

于是得到积分形式的比尔—布格—朗伯定律：

$$I_\lambda(s_1) = I_\lambda(0)\, e^{-\tau_\lambda}$$

**透射率（transmittance）**定义为到达强度与入射强度之比：$T_\lambda = e^{-\tau_\lambda}$；**吸收率（absorptance）**定义为被吸收的份额：$A_\lambda = 1 - T_\lambda = 1 - e^{-\tau_\lambda}$。光学厚度越大，透射越少；光学厚度为 0 时完全透明，趋向无穷时完全吸收。把指数变成「可心算的感觉」，一张数表就够了：

| 光学厚度 $\tau$ | 透射率 $T = e^{-\tau}$ | 吸收率 $A = 1 - e^{-\tau}$ | 直观感受 |
| --- | --- | --- | --- |
| 0.01 | 0.99 | 0.01 | 近乎透明 |
| 0.1 | 0.90 | 0.10 | 轻微雾感 |
| 0.7 | 0.50 | 0.50 | 一半被吸收 |
| 2.3 | 0.10 | 0.90 | 九成被吸收 |
| 4.6 | 0.01 | 0.99 | 几乎全吸收 |

光学厚度每增加 2.3，透过率就掉一个量级。设计遥感通道、估云污染阈值时，这张数表是随手可用的速查尺。

## 3 光学厚度的两种写法

气象与遥感里，光学厚度常换用不同的「配比」书写，这决定了我们用什么单位的数据。两种最常见：

**质量形式**（用质量吸收系数）：

$$\tau_\lambda = \int k_\lambda\,\rho\, ds$$

**数密度形式**（用吸收截面，如分子谱线数据库里的习惯）：

$$\tau_\lambda = \int \sigma_\lambda\, n\, ds$$

其中 $\sigma_\lambda$ 是**吸收截面（absorption cross-section）**，单位 $\mathrm{m^2}$，表示「单个分子挡住光的能力」；$n$ 是数密度（$\mathrm{m^{-3}}$）。两者通过 $k_\lambda \rho = \sigma_\lambda n$ 互换。<span class="marginnote">截面与质量系数的换算关系是 $k = \sigma / m$，其中 $m$ 是单个分子的质量（$\mathrm{kg}$）。谱线数据库 HITRAN 里存的是截面与线强，而气候模式里常用质量系数，记住这个桥就能两边互译。</span>

**斜路径与大气质量因子**：若光线从天顶角 $\theta$ 射入，路径比垂直路径长，几何上有 $ds = dz/\cos\theta = dz/\mu$（$\mu = \cos\theta$）。垂直光学厚度 $\tau_\lambda^\mathrm{v} = \int_0^{\infty} k_\lambda\rho\,dz$ 已知时，斜路径光学厚度近似为：

$$\tau_\lambda(\theta) \approx \frac{\tau_\lambda^\mathrm{v}}{\mu}$$

$\sec\theta = 1/\mu$ 就是常说的**大气质量因子（air mass）**——太阳越低（$\theta$ 越大），光路越长，削弱越强，这也是「日落时太阳又红又暗」的几何根源。

**补充｜斜路径订正的实际应用：** 地基太阳光度计（如 AERONET 全球网）正是利用「同一时刻不同太阳天顶角下的斜路径透过率」反推垂直气溶胶光学厚度——先把每次测量按 $\mu$ 订正到天顶，再对全天结果求平均。这里 $\mu$ 的取值、大气折射对光路的微小弯曲，都是误差的现实来源。

## 4 公式解析：从微分方程到指数定律

**这里真正要掌握的数学，是把「衰减正比于自身」翻译成「指数衰减」。** 微分方程 $dI/ds = -k\rho I$ 是一阶线性齐次方程，解法三步：

- **第一步，分离变量**：把 $I$ 挪到左边、$ds$ 挪到右边，得到 $dI_\lambda/I_\lambda = -k_\lambda\rho\, ds$。左边只含 $I$，右边只含 $s$，两边各自可积。
- **第二步，两边积分**：左边是 $\int dI/I = \ln I$，从 $I(0)$ 积到 $I(s)$；右边是 $-\int k\rho\,ds = -\tau$。于是 $\ln I(s) - \ln I(0) = -\tau$。
- **第三步，取指数**：$\ln\bigl[I(s)/I(0)\bigr] = -\tau$ 两边取 $e$ 的幂，得 $I(s)/I(0) = e^{-\tau}$，即 $I(s) = I(0)e^{-\tau}$。

**直觉**：为什么是 $e$ 而不是别的？因为衰减是「就地发生」的——每一微米路径都按当前光强的固定比例削掉一点。这就像一个本金按固定利率复利缩水，连续复利走到底就是 $e$。$\tau$ 扮演「总利率」，把整段路径的削弱打包成一个无量纲数。

**算例：正午与傍晚的太阳辐射。** 设晴空整层大气垂直光学厚度 $\tau^\mathrm{v} = 0.3$：

- 太阳在天顶（$\theta = 0^\circ$，$\mu = 1$）：$\tau = 0.3$，$T = e^{-0.3} \approx 0.74$，74% 的阳光抵达地面。
- 太阳在 30° 高度（$\theta = 60^\circ$，$\mu = 0.5$）：$\tau = 0.6$，$T \approx 0.55$。
- 太阳贴近地平线（$\theta \approx 88^\circ$，$\mu \approx 0.035$）：$\tau \approx 8.6$，$T \approx 1.8\times10^{-4}$——可见光被削得几乎干净，只剩散射红光与长波到达眼睛。

同一个太阳、同一条垂直路径，只因光路倾斜，到达地面的能量相差近 4000 倍。**日落时太阳又红又暗，不是太阳变了，是光路长了。**

## 5 易错辨析：比尔定律的适用前提

**辨析｜易错点：** 比尔—布格—朗伯定律有三个默认前提，忘记任何一个都会用错：

- **单色**：定律对单一波长成立。若光源是宽谱的，各波长衰减系数不同，总透过率**不是**简单把某一条谱线的 $\tau$ 代进去，而要逐波长积分：$T_{total} = \int S_\lambda e^{-\tau_\lambda}\,d\lambda / \int S_\lambda\,d\lambda$。<span class="marginnote">正因如此，白光过大气后并非整体变暗，而是短波被优先削掉、长波保留——「日落红」与「天空蓝」都是这个道理，散射版在瑞利散射一篇详谈。</span>
- **无散射、无发射**：比尔定律只刻画「吸收削弱」。大气里实际还有散射（把光从原方向弹走，等效于削弱）与自身发射（把光加回来），要同时刻画就必须升级到辐射传输方程——这正是下一篇的主题。
- **单位别混**：$k_\lambda$（$\mathrm{m^2\,kg^{-1}}$）乘质量密度 $\rho$，$\sigma_\lambda$（$\mathrm{m^2}$）乘数密度 $n$，两者等价但换算 $k = \sigma/m$ 里的分子质量 $m$ 常被漏掉——一漏就是几个数量级。HITRAN 给截面、模式给质量系数，换算前先确认分子质量。
- **均匀 / 分层均匀**：$k_\lambda\rho$ 沿路径可以是常数（均匀介质），也可以逐层变（分层大气），但每一层内必须是均匀的；若吸收系数随光强本身变化（非线性吸收），定律即失效。

## 6 小结

- **比尔—布格—朗伯定律**：$I = I_0 e^{-\tau}$，单色平行光透过吸收介质的强度按指数衰减。
- **光学厚度** $\tau_\lambda = \int k_\lambda\rho\, ds$ 是把整段路径的削弱打包成的一个无量纲量；也可用截面×数密度书写。
- **透射率** $T = e^{-\tau}$，**吸收率** $A = 1 - e^{-\tau}$，两者互补。
- **斜路径**用大气质量因子修正：$\tau(\theta) \approx \tau^\mathrm{v}/\mu$。
- 定律前提：**单色、纯吸收、无发射、分层均匀**——前提被破坏就要换更完整的辐射传输方程。
- **经验法则**：$\tau$ 每增加 2.3，透过率掉一个量级；$\tau = 1$ 意味着一束光穿过介质后只剩 37% 幸存——「衰减到 $1/e$」是判断介质开始显著挡光的天然标尺，$\tau > 5$ 基本可以当作全吸收。
- 比尔定律最常用的「反用」是反演：从地基太阳光度计测到的直射光衰减，反推路径上的大气浑浊度与吸收物质总量——测到了光被削多少，就测到了路上有多少东西。
- 从卫星通道设计到无线通信的路径损耗模型，指数衰减的骨架无处不在；但真实大气永远是宽谱的，窄波段假设一破，就必须回到辐射传输方程。

在下一节，我们把「某一波长的 $\tau$」换成「成千上万条波长上的 $\tau$」——分子吸收光谱会铺开「大气在哪段波段透明、在哪段封死」这张最关键的分布图，温室效应与卫星通道都从那里来。
