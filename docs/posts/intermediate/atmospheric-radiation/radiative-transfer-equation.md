## 为什么从辐射传输方程开始

前面的章节把「光被吸收」单独讲透了，但真实大气里，光在路上**同时**经历三件事：被吸收（削弱）、被散射（拐走或拐入）、被发射（补给）。气象卫星测到的每一个辐射量，都是这三者博弈后的净结果。<span class="marginnote">辐射传输方程就是这场博弈的会计账簿：把一束光穿过一层大气的收支，逐项记成微分方程。它是整个大气辐射学的「牛顿第二定律」——几乎所有问题（反演、加热率、辐射收支）最终都落到解这条方程。</span>

**辐射传输方程（equation of radiative transfer）**：单位路程上辐射亮度的变化，等于「发射与散射补给」减去「吸收与散射削弱」。

## 1 一条方程装下四种过程

设单色辐射沿方向 $\mathbf{\hat{s}}$ 穿过密度为 $\rho$ 的大气，吸收系数 $k_a$、散射系数 $k_s$（都是质量系数），辐射传输方程写成：

$$\frac{dI_\nu}{ds} = -\underbrace{(k_a + k_s)\rho\, I_\nu}_{\text{削弱}} + \underbrace{k_a\rho\, B_\nu(T)}_{\text{热发射}} + \underbrace{\frac{k_s\rho}{4\pi}\int_{4\pi} P(\mathbf{\hat{s}}, \mathbf{\hat{s}}')\, I_\nu(\mathbf{\hat{s}}')\, d\Omega'}_{\text{散射补给}}$$

逐项读：<span class="marginnote">第一项是「旧账」——比尔定律的延续：吸收与散射都把光从本方向清走。第二项是「本金」——大气在局地温度 $T$ 下按基尔霍夫定律发射 $k_a B_\nu(T)$。第三项是「外援」——四面八方被散射进来的光，经<strong>相函数（phase function）</strong> $P(\mathbf{\hat{s}}, \mathbf{\hat{s}}')$ 加权后转入本方向。</span>

- **吸收**把辐射能转成内能（加热大气）；
- **散射**只改变光的方向，不改变总量；
- **发射**把内能转回辐射能（冷却大气）。

四种过程的「数学长相」各不相同，收进一张表：

| 过程 | 数学表达 | 对光强的影响 | 对大气的作用 |
| --- | --- | --- | --- |
| 吸收 | $-k_a\rho\, I_\nu$ | 减小 | 加热 |
| 散射出 | $-k_s\rho\, I_\nu$ | 减小 | 中性 |
| 热发射 | $+k_a\rho\, B_\nu(T)$ | 增大 | 冷却 |
| 散射入 | $+\dfrac{k_s\rho}{4\pi}\int P\, I\, d\Omega'$ | 增大 | 中性 |

读表能直接读出「谁是源、谁是汇」：负号项全部带走光强，正号项全部补回；其中只有热发射一项把大气内能转成辐射，是辐射—大气能量耦合的唯一通道。

## 2 光学厚度坐标下的「减一加一」

把路程 $s$ 换成光学厚度 $\tau_\nu$（$d\tau_\nu = (k_a + k_s)\rho\, ds$），再定义**单次散射反照率（single scattering albedo）** $\tilde\omega = k_s/(k_a + k_s)$ 与**源函数（source function）** $J_\nu$，方程化简为：

$$\frac{dI_\nu}{d\tau_\nu} = -I_\nu + J_\nu, \qquad J_\nu = (1-\tilde\omega)\,B_\nu(T) + \frac{\tilde\omega}{4\pi}\int_{4\pi} P(\mathbf{\hat{s}}, \mathbf{\hat{s}}')\, I_\nu(\mathbf{\hat{s}}')\, d\Omega'$$

**重点：这个坐标变换是辐射传输的「第一姿势」。** 光学厚度把「距离」重标成「散射+吸收的总削弱单位」，于是方程左边只剩最干净的「减一加一」结构——每前进一个光学厚度，本方向的光少一份、源函数补一份。几何上的远近、密度的大小全部被吸收进 $\tau$ 里，方程对任何大气剖面同形。

**局部热力学平衡（LTE）**：当碰撞频率远高于辐射过程速率（对流层与平流层大部满足），发射项严格等于 $k_a\rho B_\nu(T)$，温度 $T$ 有明确定义。只有在极高空（约 60–80 km 以上）LTE 才失效，需引入非 LTE 发射率修正。

由辐射传输方程还能直接写出**辐射加热率**——净辐照度随高度的变化除以热容：

$$\left(\frac{\partial T}{\partial t}\right)_{rad} = -\frac{1}{\rho\, c_p}\,\frac{dF}{dz}$$

式中 $F$ 是净辐照度（上行减下行）。温室气体强吸收带附近 $dF/dz$ 的梯度大，加热率也大——温室气体增暖大气，正是通过这行式子在模式网格里逐层记账。

## 3 纯吸收 + 发射：史瓦西方程与其解

若忽略散射（$k_s = 0$，$\tilde\omega = 0$），方程退化为**史瓦西方程（Schwarzschild equation）**，是最重要的一类可解情形：

$$\frac{dI_\nu}{d\tau_\nu} = -I_\nu + B_\nu(T)$$

用积分因子法解（细节见下一节公式解析），得从 $\tau = 0$ 到 $\tau = \tau_1$ 的完整解：

$$I_\nu(\tau_1) = I_\nu(0)\,e^{-\tau_1} + \int_0^{\tau_1} B_\nu\bigl(T(\tau')\bigr)\, e^{-(\tau_1 - \tau')}\, d\tau'$$

**每一项都有名字**：第一项是**地表/背景透过来的光**（比尔定律衰减），第二项是**每一层大气发出的光**、各自再衰减到观测点后的叠加。**算例：等温层的透过与发射。** 设一层等温大气，光学厚度 $\tau_1$、温度 $T$、背景辐射 $I(0)$：

- 解析解化为 $I(\tau_1) = I(0)\,e^{-\tau_1} + B(T)\,(1 - e^{-\tau_1})$。
- 光学薄（$\tau_1 \ll 1$）：$I \approx I(0)(1-\tau_1) + B\,\tau_1$——发射项正比于光学厚度，薄层像「线性掺水」。
- 光学厚（$\tau_1 \gg 1$）：$I \to B(T)$——辐射饱和，只反映最上层大气的温度。<span class="marginnote">这就是卫星热红外遥感的全部骨架：探测器测到的是「地表辐射×透过率 + 沿途大气自发射」。当某条谱线的大气光学厚度极大（如 CO₂ 15 μm 带心），第一项趋零、第二项只剩最上层大气的发射——测这个值就等于在测该层大气的温度，这正是温度反演的基础。</span>

## 4 公式解析：解 $dI/d\tau = -I + B$

**解史瓦西方程是辐射传输的第一个「完整计算」。** 核心是一阶线性常微分方程，积分因子法三步：

**第一步，找积分因子**：把方程写成 $dI/d\tau + I = B$。乘上积分因子 $e^{\tau}$，左边恰好变成全微分：$\dfrac{d}{d\tau}\bigl(I e^{\tau}\bigr) = B e^{\tau}$。
**第二步，两边从 0 积到 $\tau_1$**：$\bigl[I e^{\tau}\bigr]_0^{\tau_1} = \int_0^{\tau_1} B(\tau') e^{\tau'}\, d\tau'$。左边代上下限：$I(\tau_1)e^{\tau_1} - I(0) = \int_0^{\tau_1} B(\tau') e^{\tau'}\,d\tau'$。
**第三步，除以 $e^{\tau_1}$**：$I(\tau_1) = I(0)e^{-\tau_1} + \int_0^{\tau_1} B(\tau') e^{-(\tau_1-\tau')}\,d\tau'$。第一项是背景衰减，第二项是逐层发射的衰减叠加。

**直觉**：把大气切成无数薄层，每层是一个「小史瓦西」——先发出 $B$ 的光，再被上方整段光学厚度衰减。积分就是把无穷多薄层的贡献加起来；指数 $e^{-(\tau_1-\tau')}$ 就是「从这一层到观测点的剩余透过率」。

**换成卫星视角读解：** 对天底观测，$I(0)$ 是地表辐射、$I(\tau_1)$ 是卫星测到的亮度。大气吸收越强（$\tau_1$ 越大），卫星「看」到的地表越少、看到的大气自发射越多。温度反演正是利用不同通道的不同 $\tau_1$，让卫星「看穿」到不同深度——这一层含义在第 11 篇《卫星遥感反演原理》中展开。

**补充｜为什么「史瓦西」总在遥感里出现**：卡尔·史瓦西 1906 年把辐射平衡与局地热平衡联系起来，他的方程是红外遥感的起点。今天每个逐线模式的核心解仍是史瓦西方程的数值化——一百多年过去，骨架未变。

**正演的最小计算流**：输入温度/气体廓线 → 逐层算光学厚度 → 逐层算源函数 → 从底到顶累加史瓦西解 → 输出通道亮度。每一步是一个可单独检验的模块：

| 误差来源 | 主要影响 |
| --- | --- |
| 谱线参数不准 | 吸收强弱整体偏移 |
| 地表发射率假设错 | 低层通道系统性偏 |
| 云参数缺失 | 整柱辐射错位 |

## 5 易错辨析：发射项与散射项不能混为一谈

**辨析｜易错点：** 三个高频混淆：

- **误区一：以为散射也按 $B_\nu$ 发射**。散射是「重定向」，发射是「新生」，二者物理不同。散射源项携带的是**外界射入的光**经相函数加权，而不是局地温度的函数；把散射项误写成 $B_\nu$ 会彻底算错云的辐射。<span class="marginnote">判别法很简单：源函数里出现 $B_\nu(T)$ 的是发射（依赖局地温度），出现 $\int P\,I\,d\Omega$ 的是散射（依赖周围辐射场）。云在热红外发射项强，在可见光则是散射主导——同一朵云，两个波段走两条路。</span>
- **误区二：把 $k_a + k_s$ 都叫「消光」后忘掉单次散射反照率**。消光（extinction）确实是两者之和，但能量如何分配必须看 $\tilde\omega$：$\tilde\omega=0$ 是纯吸收，$\tilde\omega=1$ 是纯散射。分母中消光决定衰减快慢，分子中散射占比决定「丢的光有多少变成源」。
- **误区三：直接拿几何高度当光学厚度用**。辐射传输所有结论都在 $\tau$ 坐标下成立，换算回高度要乘密度剖面；同一个高度，吸收线内外的 $\tau$ 相差几个数量级。
- **误区四：在任何高度都套用 LTE 发射**。60–80 km 以上碰撞频率不足，发射不再等于 $k_a\rho B_\nu(T)$，需非 LTE 修正；把平流层顶附近的卫星通道当 LTE 处理，反演温度会系统性偏低。

## 6 小结

- **辐射传输方程**逐项记录：削弱（吸收+散射）与补给（热发射+散射入），用光学厚度坐标写成 $dI/d\tau = -I + J$。
- **源函数** $J = (1-\tilde\omega)B + \dfrac{\tilde\omega}{4\pi}\int P I\, d\Omega$，发射靠局地温度、散射靠外界辐射场。
- **LTE** 让发射项等于 $k_a\rho B_\nu(T)$，是对流层与平流层大部成立的基石假设。
- **史瓦西方程** $dI/d\tau = -I + B$ 的解 = 背景衰减项 + 逐层发射衰减项，是热红外遥感的骨架。
- 消光、单次散射反照率、源函数三者的分工是读懂一切大气辐射文献的钥匙。
- **辐射加热率** $(\partial T/\partial t)_{rad} = -\dfrac{1}{\rho c_p}\dfrac{dF}{dz}$ 是辐射驱动大气的直接通道。
- 光学薄层发射线性叠加、光学厚层发射饱和（$I \to B(T)$，只反映最上层大气的温度）——卫星选通道的本质，就是选「在哪一层看饱和」。
- 辐射传输方程的三种源对应三种观测解读：地表透过（穿看）、大气发射（发射看）、散射补给（散射看）——一种方程，三种视力。
- 加热率 $(\partial T/\partial t)_{rad}$ 是辐射进入大气动力学的那扇门：温室增暖、平流层加热、夜间降温，全部由这行式子记账。
