## 为什么从伯努利移位开始

上一节末我们预告了「符号化」：把连续系统的轨道翻译成一串符号。现在我们把符号化做到底——**伯努利移位（Bernoulli shift）** 直接从一个字母表出发，不依赖任何几何，用独立同分布的概率掷出无穷长的符号序列。它是最纯粹的「随机」保测系统：没有结构，只有概率。正因为没有结构，它成为遍历理论判断「一个系统到底有多随机」的标尺，也是通向测度熵（第4篇）与 Ornstein 同构定理（第4篇）的必经之路。

## 1 符号空间与移位

设 $S = \{1, 2, \dots, k\}$ 是有限字母表，$\mathbf{p} = (p_1, \dots, p_k)$ 是概率向量（$p_i \ge 0$，$\sum_i p_i = 1$）。**单边符号空间**为

$$\Omega = S^{\mathbb{N}} = \{ \omega = (\omega_0, \omega_1, \omega_2, \dots) \mid \omega_n \in S \}.$$

$\Omega$ 上的**伯努利测度** $\mu_{\mathbf{p}}$ 是无限乘积测度：每个坐标独立地按 $\mathbf{p}$ 取值。<span class="marginnote">乘积测度的严格构造用到了科尔莫戈罗夫扩张定理（见第二级《概率论与数理统计》与《实变函数与测度论》）；直观上，只要规定每个「有限窗口」的概率，就能一致地规定整个序列空间的概率。</span>

**核心概念：** 定义**左移位（left shift）** $\sigma: \Omega \to \Omega$ 为

$$\sigma(\omega_0 \omega_1 \omega_2 \cdots) = \omega_1 \omega_2 \omega_3 \cdots,$$

即丢掉第一个符号，把整个序列左移一位。伯努利移位就是四元组 $(\Omega, \mathcal{B}, \mu_{\mathbf{p}}, \sigma)$。

## 2 圆柱集与保测性的验证

要证明 $\sigma$ 保测，只需在生成元上验证。$\Omega$ 上的基本可测集是**圆柱集（cylinder set）**：固定前 $n$ 个坐标的取值 $a_0, \dots, a_{n-1}$，令

$$[a_0 a_1 \cdots a_{n-1}] = \{ \omega \in \Omega \mid \omega_i = a_i,\ i = 0,\dots,n-1 \}.$$

圆柱集的测度是坐标概率的乘积：

$$\mu_{\mathbf{p}}\big([a_0 \cdots a_{n-1}]\big) = p_{a_0} p_{a_1} \cdots p_{a_{n-1}}.$$

而 $\sigma^{-1}$ 把「要求前 $n$ 位为 $a_0\cdots a_{n-1}$」的集合变成「第 $1$ 到第 $n$ 位为 $a_0\cdots a_{n-1}$」的集合，即 $[?\, a_0 \cdots a_{n-1}]$——第一个坐标被释放，其余 $n$ 个坐标的约束不变。<span class="marginnote">这一步的直觉：先掷一枚硬币再继续，和直接开始掷——前一步的结果已经「进了过去」，不再影响现在的概率分布。这正是独立同分布的本质。</span>

于是

$$\mu_{\mathbf{p}}\big(\sigma^{-1}[a_0 \cdots a_{n-1}]\big) = \mu_{\mathbf{p}}\big([?\, a_0 \cdots a_{n-1}]\big) = \left( \sum_{i=1}^k p_i \right) p_{a_0} \cdots p_{a_{n-1}} = p_{a_0}\cdots p_{a_{n-1}},$$

因为第一坐标的概率之和为 1。圆柱集生成整个 $\sigma$-代数，故 $\sigma$ 保测。**伯努利移位的保测性不是几何的，而是「遗忘」的：移位把最老的信息丢进过去，而独立假设保证丢掉的与剩下的互不影响。**

## 3 从伯努利到有限型子移位

伯努利移位允许任意符号序列。若只允许**满足转移规则**的序列，就得到**有限型子移位（subshift of finite type）**。给定一个 $k\times k$ 的 0-1 矩阵 $A = (A_{ij})$，令

$$\Omega_A = \{ \omega \in S^{\mathbb{Z}} \mid A_{\omega_n \omega_{n+1}} = 1 \ \forall n \},$$

即只保留相邻符号「被允许」的序列。左移位 $\sigma$ 限制在 $\Omega_A$ 上。这类系统对应上一节的马尔可夫链（转移矩阵非零元即 $A_{ij}=1$），并且是符号动力系统里唯一同时具备「简单定义」与「丰富动力学」的一族。

**易错点｜辨析：** 有限型子移位与伯努利移位的关键差别在于**记忆**。伯努利移位中下一符号与之前独立；有限型子移位中下一符号只依赖当前符号——一步记忆。而一般马尔可夫链把「依赖当前符号」推广为「按转移概率随机选择」，仍属一步记忆。更深记忆的移位（higher block）可通过重编码归入有限型，这体现了符号动力学的「重整化」能力。

## 4 公式解析：$p_{a_0} p_{a_1} \cdots p_{a_{n-1}}$

这条乘积公式是整个伯努利理论的核心，拆解如下：

- **第一步，为什么是乘积**：伯努利测度假设各坐标**独立**。独立随机变量的联合概率等于边缘概率之积——这是概率论的基本公理，见第二级《概率论与数理统计》中独立事件的乘法公式。
- **第二步，圆柱集编码了「有限观察」**：$[a_0\cdots a_{n-1}]$ 代表「观察到前 $n$ 个符号恰好是 $a_0,\dots,a_{n-1}$」。概率乘积形式意味着：看到哪一串，完全由各位置的出现概率决定，与排列顺序无关。
- **第三步，乘积与保测性的衔接**：移位后，圆柱集的「首坐标」被释放，乘积公式中多出的因子 $\sum_i p_i = 1$ 恰好抵消，测度不变。若坐标**不独立**，这一步就会失败——这解释了为什么保测性依赖独立性。
- **第四步，均匀情形**：当 $p_1 = \cdots = p_k = 1/k$ 时，每个 $n$ 长的块概率为 $k^{-n}$，所有块等可能。这是「完全随机」的数学表述，也是后续熵取到最大值 $\log k$ 的情形。

## 5 伯努利移位为什么「最随机」

伯努利移位在三个意义上站在随机性的顶端：

**独立同分布**：各坐标独立且同分布——这是概率论中「白噪声」的极限情形（对应第二级《随机过程》里的独立增量过程）。**科尔莫戈罗夫 0-1 律适用**：任何「不依赖前有限个坐标」的尾事件概率只能是 0 或 1，说明系统没有可预测的结构残留。**测度熵达到最大**：对均匀伯努利移位，每步产生 $\log k$ 的信息量——这是同一字母表上任何系统熵的上界，见第4篇 Kolmogorov–Sinai 熵。

**核心结论：** 伯努利移位是「随机性的理想气体」——任何其他系统要证明自己是随机的，都以它为参照；Ornstein 定理（第4篇）则反过来说：熵相同的两个「足够随机」的伯努利移位在度量上同构。

## 6 有限型子移位与拓扑熵

有限型子移位（第3节）不只是马尔可夫链的符号化身，它本身是符号动力学的核心对象，有自己的「复杂度」——**拓扑熵**（第5篇第22节的预告）。

**核心概念：** 设 $\Omega_A$ 是转移矩阵 $A$ 定义的有限型子移位。其**拓扑熵**是每步「可区分轨道」的对数增长率：

$$h_{\mathrm{top}}(\Omega_A, \sigma) = \log \rho(A),$$

其中 $\rho(A)$ 是 $A$ 的**谱半径**（最大特征值绝对值）。**拓扑熵 = 转移矩阵谱半径的对数**——一个纯组合量。

**为什么：** $(\epsilon, n)$-分离集的最大势 $s_n(\epsilon)$ 等于「长度 $n$ 的允许词」的个数，而允许词的个数渐近为 $\rho(A)^n$（由非负矩阵的 Perron–Frobenius 定理，见第二级《线性代数》与《数值线性代数》）。取对数除以 $n$，得 $\log\rho(A)$。<span class="marginnote">Perron–Frobenius 定理保证非负矩阵有非负主特征值，它同时给出马尔可夫链的平稳分布（见第二级《随机过程》）与有限型子移位的拓扑熵——同一套线性代数工具，两处开花。</span>

**与测度熵的连接**：对不可约非周期的 $A$，有限型子移位上存在**最大熵测度**（Parry 测度），使测度熵达到拓扑熵 $\log\rho(A)$——这是变分原理（第5篇第22节）在符号系统上的精确实现。**伯努利移位是 $A$ 全为 1 的特例**，$\rho(A) = k$，最大熵测度是均匀伯努利测度。

**核心结论：** 有限型子移位是「符号复杂度可完全计算」的系统：拓扑熵由矩阵谱半径给出，最大熵测度由特征向量给出。它既是马尔可夫链的模型，也是熵理论的试验田——**从伯努利（全连通）到一般有限型（部分连通），符号动力学展示了复杂度如何从矩阵读出。**

## 7 符号动力学的应用：从编码到生物序列

符号动力学不只是遍历理论的抽象分支——它是「把任意系统数字化」的通用语言，应用横跨信息论、生物与工程。

**编码理论**：有限型子移位（第3节）与纠错码有天然联系：允许词集合 = 合法码字，转移矩阵 = 编码规则。香农容量（每符号可携带的最大信息）正是拓扑熵 $\log \rho(A)$（第6节）——**符号动力学的熵 = 通信信道的容量**（见第二级《信息论》）。设计编码器（如游程受限码 RLL）就是在设计转移矩阵 $A$，使熵接近信道容量。

**生物序列**：DNA、蛋白质序列可建模为符号序列；其「复杂度」可用符号动力学的熵衡量。**语言与文本**：自然语言是符号序列，其熵估计（每字符比特数）是信息论与计算语言学的经典问题——伯努利移位是「零记忆」基线，真实语言的熵远低于它，正反映语言的结构（见第三级《自然语言处理》）。<span class="marginnote">语言熵估计（Shannon 的「字母的熵」实验）是符号动力学最早的工程应用之一：用人类预测实验逼近真实熵。现代语言模型的困惑度（perplexity）正是「每字符交叉熵」的工程化——<strong>从伯努利移位到 LLM，符号动力学的熵思想一脉相承</strong>，这也是「从极限到大模型」主线最直接的连接点之一。</span>

**可计算性与复杂度**：符号序列的「不可压缩性」是 Kolmogorov 复杂度的主题（见第二级《信息论》）；在动力学框架下，轨道的符号编码复杂度（每步新增符号种类）即熵。**动态系统、信息论、计算理论在「复杂度」这一点上完全交汇**。

**核心结论：** 符号动力学是「数字化一切系统」的框架：编码理论、生物序列、自然语言、随机性测试都在这个舞台上展开。**熵（每步信息量）是贯穿这些应用的统一标尺**——从伯努利移位的 $\log k$ 到语言模型的困惑度。

### 延伸：符号系统的维数

符号系统不仅是动力学的模型，也是**维数理论**的试验田。

**核心概念：** 对满足开集条件（open set condition）的有限型子移位，其**豪斯多夫维数**（见第二级《分形几何》）等于由特征方程解出的数。例如，不允许相邻 1 的移位（Fibonacci 移位），其允许词增长率 $p(n) \sim \varphi^n$（$\varphi$ 是黄金比），对应的自相似集的维数为 $\log\varphi/\log 2$。

**熵与维数的连接**：在许多情形，符号系统的维数 = 熵/$\log(\text{符号数})$——**维数把「每步信息」翻译成「几何尺度」**。这是「从极限到大模型」主线里动力系统、分形几何与信息论的交汇点。

**核心结论：** 符号系统把熵与维数统一：**一个系统的信息复杂度（熵）与几何复杂度（维数）由同一套符号结构决定**——符号动力学因此是分形几何最自然的入口。
