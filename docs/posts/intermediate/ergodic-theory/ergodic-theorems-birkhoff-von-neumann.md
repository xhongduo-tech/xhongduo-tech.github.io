## 为什么从遍历定理开始

前两篇建立了对象（例子）与性质（遍历性、不变测度），但遍历理论的核心命题还没兑现：**时间平均 $= \frac1N\sum_{n<N} f(T^n x)$ 到底收敛到哪里？** 这就是遍历定理——它给出收敛、给出极限、给出速度（在可测意义下），是全部学科的心脏。本专题第3篇《von Neumann 平均遍历定理》与《Birkhoff 逐点遍历定理》已给出各自的完整证明与实例，本篇把二者并排，回答三个问题：两个定理各收敛在什么意义下、证明的核心杠杆各是什么、为什么它们各自在分析学里如此重要。<span class="marginnote">对「从极限到大模型」主线，遍历定理就是「用时间平均估计统计量」的合法性证明——强化学习中用一条轨迹估计期望回报、时间序列里用一段样本估计自相关，背后都是 Birkhoff。</span>

## 1 von Neumann 平均遍历定理：Hilbert 空间里的收敛

**定理（von Neumann，1932）**：设 $U$ 是 Hilbert 空间 $H$ 上的酉算子（或等距/压缩算子），$P$ 是到不变子空间 $\mathrm{Fix}(U) = \{g : Ug = g\}$ 上的正交投影。则对任意 $f \in H$，

$$\frac1N \sum_{n=0}^{N-1} U^n f \ \xrightarrow{\ \text{norm}\ } \ P f.$$

这是**均方意义**的收敛：$\|\frac1N\sum_{n<N} U^n f - Pf\|_2 \to 0$。证明走两条路：一是谱定理——酉算子按谱分解为「纯旋转」，而对每个频率 $e^{2\pi i\theta}$ 的贡献，平均 $\frac1N\sum e^{2\pi i n\theta}$ 除 $\theta = 0$ 外都趋于 0；二是初等路线——把 $f$ 拆成 $Pf$（不动部分）与 $(I-P)f$，后者属于 $(I-U)H$ 的闭包，而 $I-U$ 的像被 $U$ 平均消掉。<span class="marginnote">von Neumann 的证明依赖他自己的谱定理——这是遍历定理与泛函分析第一次「联姻」。他用 Koopman 算子 $U_T: f \mapsto f \circ T$ 把动力系统嵌入 Hilbert 空间（Koopman 1931 提出），从此遍历理论有了算子论武器。</span>

**物理意义：** 对遍历系统，$\mathrm{Fix}(U_T)$ 只含常数，故 $Pf = (\int f\,d\mu)\cdot \mathbf{1}$——时间平均在均方意义下收敛到空间平均。**这是「系综平均 = 时间平均」的平方平均版本**，也是统计力学里最常被引用的一条。

**Koopman 算子再深一步：** $U_T$ 把非线性动力学线性化为 $H$ 上的酉算子，而 von Neumann 定理说「长期行为由不动子空间决定」——这恰是谱理论（第4篇）的开场白：动力系统的长期统计 = 算子的谱结构。历史上 Koopman 是 von Neumann 的同事，这一算子观点还直接滋养了量子力学里的酉演化思想（第二级《量子力学》），是「动力系统 ↔ 算子」双向翻译的源头。

## 2 Birkhoff 逐点遍历定理：几乎处处收敛

**定理（Birkhoff，1931）**：设 $(X, \mathcal{B}, \mu)$ 是概率空间，$T$ 保测，$f \in L^1(\mu)$。则几乎处处存在极限

$$\lim_{N \to \infty} \frac1N \sum_{n=0}^{N-1} f(T^n x) \ = \ f^*(x),$$

其中 $f^* = \mathbb{E}(f \mid \mathcal{I})$ 是关于**不变 $\sigma$-代数** $\mathcal{I} = \{A : T^{-1}A = A\}$ 的条件期望。特别地，若 $T$ 遍历，$f^* = \int f \, d\mu$ 常数。

这条定理比 von Neumann 强得多：**收敛发生在每个点（除了零测集），而不是平均意义下**。极限函数 $f^*$ 是最优「不变近似」——用条件期望的语言，它保留 $f$ 里那些「被时间不变的成分」，丢掉「随轨道漂移的部分」。<span class="marginnote">$f^* = \mathbb{E}(f\mid\mathcal{I})$ 这一形式把遍历定理与鞅论（第3篇《逐点遍历定理的推广：上鞅版本与极大函数》）接通：条件期望的鞅收敛定理几乎是逐点遍历定理的「堂兄」。</span>

**推导 $f^*$ 的直觉：** 时间平均沿轨道平均 $f$，而轨道落在某个遍历「房间」里（第6篇第2篇的分解语言），极限正是「在该房间上的平均」——条件期望 $\mathbb{E}(f\mid\mathcal{I})$ 就是「先选房间、再在房间内平均」的算子。遍历性 = 只有一个房间，极限退化为全局平均。

**数值例：** 倍增映射 $x \mapsto 2x \bmod 1$ 配勒贝格测度（遍历），取 $f(x) = x$。Birkhoff 定理说 $\frac1N\sum_{n<N} T^n x \to \int_0^1 t\,dt = \tfrac12$ 几乎处处。用二进制：$T^n x$ 的第 $n$ 位之后的小数，$N$ 项平均逼近「所有二进制数字的平均」——数字 0、1 等频率（正规性），均值趋近 $\tfrac12$。**时间平均收敛的每一步都对应一次「数字平均」，这是遍历定理最可触的实例。**

**非遍历的对比：** 若配 $\delta_0$（$0$ 的周期轨），则 $f^* = f(0) = 0 \ne \tfrac12$——不变 $\sigma$-代数 $\mathcal{I}$ 里「房间」是 $\{0\}$ 的补集与 $\{0\}$，条件期望把 $f$ 投影到房间内，极限随房间而变。**极限不是「跑错」，而是「选对了房间」。**<span class="marginnote">这个例子也示范了遍历分解的实用面向：想知道极限，先问轨道落在哪个遍历分量——分解定理（第6篇第2篇）把「条件期望」换成了「按分量逐点平均」。</span>

## 3 极大遍历定理与 Hopf 论证

Birkhoff 定理的证明核心是一条几乎处处估计——**极大遍历定理（maximal ergodic theorem）**：

**定理（Wiener–Hopf–Hurewicz，1939）**：对 $f \in L^1$，定义极大函数 $M f = \sup_{N \ge 1} \frac1N \big|\sum_{n<N} f \circ T^n\big|$。则对任意 $\alpha > 0$，

$$\mu\big( \{ x : Mf(x) > \alpha \} \big) \ \le \ \frac{1}{\alpha} \|f\|_1.$$

这是**弱 (1,1) 型估计**：极大算子把 $L^1$ 映到「几乎 $L^1$」（测度论意义的 Markov 不等式变体）。证明用 Hopf 的「漂游集」论证：考察 $\{Mf > \alpha\}$ 的轨，把「首次超过阈值」的段剖出来，这些段在 $X$ 里几乎不交，从而它们的长度总和被 $\|f\|_1/\alpha$ 控制。<span class="marginnote">极大函数与弱型估计这套语言，在 Hardy–Littlewood 极大函数、Fourier 分析、奇异积分（第二级《调和分析》）里是同一套工具——遍历定理与实分析共享的基因。</span>

**Hopf 论证的直觉：** 把「$\frac1N\sum f(T^n x) > \alpha$」想象成「沿着轨道累计收入超过支出」。若某点 $x$ 的首段累计就超支，记下这一段；再从段末继续。因为轨道段的首端点互不重叠（漂游），这些「超支段」像不交的砖块铺在 $X$ 上，总测度不得超过可容纳的上界；而每块砖内部累计超支 $\alpha \times$ 段长，总超支又不超过 $\int|f|$——两相对比就得到 $\alpha \cdot \mu\{Mf>\alpha\} \le \|f\|_1$。**「漂游段 + 超支有界」是整条定理的力学。**

**从极大定理到逐点定理（三行）：** 设 $g = \limsup \frac1N\sum f\circ T^n$，$h = \liminf \frac1N\sum f\circ T^n$。极大不等式推出「若 $g - h > \epsilon$ 在一个正测集上，则把 $f$ 换成适当组合后矛盾」——标准做法是取 $f' = f - h - \epsilon$，得到 $g \le h$ 几乎处处，从而极限存在；再用「余界（coboundary）消元」证明极限函数不变、从而等于 $f^*$。**证明的杠杆就是极大不等式，其余是技术细节。**

**辨析｜易错点：** 极大定理的 $\alpha > 0$ 不能取 0——$Mf$ 可能几乎处处等于 0 也可能在零测集上等于无穷。弱 (1,1) 估计只对正阈值给出非平凡界，这正是「几乎处处收敛」而非「处处收敛」的本质原因：$f \in L^1$ 里不可积的野点不会影响几乎处处结论。

## 4 公式解析：均方极限与逐点极限

把两条定理的主公式并排拆解，差别一目了然：

$$\frac1N \sum_{n=0}^{N-1} U^n f \ \xrightarrow{\ \|\cdot\|_2\ } \ P f \qquad\qquad \frac1N \sum_{n=0}^{N-1} f(T^n x) \ \xrightarrow{\ \text{a.e.}\ } \ \mathbb{E}(f \mid \mathcal{I})$$

- **第一项，相同的平均**：两个定理处理同一个对象——沿轨道的时间平均；差只在「在哪个空间里收敛」。
- **第二项，von Neumann 的左端在 $H = L^2$ 里**：$U^n f = f \circ T^n$ 是函数空间里的点，收敛按 $\|\cdot\|_2$ 范数；极限是投影 $Pf$。$L^2$ 的完备性（Hilbert 结构）是证明的温床。
- **第三项，Birkhoff 的左端逐点取值**：固定 $x$，得到一条复数/实数序列；收敛在「几乎每个 $x$」的意义下成立。$L^1$ 里的 $f$ 也能用（条件期望对 $L^1$ 有定义），比 $L^2$ 更宽。
- **第四项，极限对象不同**：$Pf$ 是「$U_T$-不动部分」，$f^*$ 是「条件期望」——遍历时二者都是 $\int f\,d\mu$，此时两条定理殊途同归，共同兑现「时间平均 = 空间平均」。
- **第五项，速度与强度**：von Neumann 保证范数收敛（强），Birkhoff 保证几乎处处（逐点）收敛，二者不可互相推出——著名的例子说明 $L^2$ 收敛不蕴含逐点收敛，反之亦然。**遍历理论里「两条收敛道路」并存，是它与一般遍历过程理论的共同面貌。**
- **第六项，为什么逐点更难**：均方收敛只要求「总误差的平方可积」，逐点收敛却要求「每个点的误差都归零」。极大不等式正是把「逐点的波动」整体捆住——它度量的是「最坏的一刻有多糟」，而均方度量的是「平均的一刻有多糟」。**难度的差异，就是极大函数存在的意义。**

## 5 两个定理：历史与对比

1931–1932 年是遍历理论的「爆点年份」：Koopman 在 1931 年引入算子 $U_T$，von Neumann 随即用谱定理证明平均遍历定理（并于 1932 年正式发表），Birkhoff 在 1931 年末证明逐点遍历定理。围绕**优先权**一度产生龃龉——von Neumann 的证明依赖谱定理，Birkhoff 的证明更初等（只用极大不等式），后者的方法是「仅凭 $L^1$ 假设」的典范。<span class="marginnote">这段公案后来和平收场：Birkhoff 也给出了平均定理的初等证明，von Neumann 亦承认逐点版本的优先。数学史课本（如《数学的里程碑》）把这半年称为「遍历定理的春天」。</span>

**对比表：**

| 维度 | von Neumann 平均定理 | Birkhoff 逐点定理 |
| --- | --- | --- |
| 年份 | 1932 | 1931 |
| 收敛空间 | Hilbert 空间 $L^2$ | 逐点（几乎处处） |
| 前提 | $f \in L^2$（可推广 $L^p$） | $f \in L^1$ |
| 极限 | 投影 $Pf$ | 条件期望 $f^*$ |
| 核心工具 | 谱定理 / $I-U$ 消元 | 极大不等式 + Hopf |
| 物理对应 | 系综平均（均方） | 单次演化（逐点） |

**核心结论：** 两条定理是同一真理的两张脸——**均方脸**靠 Hilbert 空间结构（谱），**逐点脸**靠实分析技术（极大函数）。研究哪个版本更顺手，取决于问题需要「平均意义」还是「单轨道意义」的结论。

**延伸（连续时间）：** 两条定理都自动推广到保测**流**（半群 $\{T_t\}$，如 Hamiltonian 流、KdV 流），只需把平均 $\frac1N\sum_{n<N}$ 换成 $\frac1T\int_0^T$。对 Hamilton 流验证遍历性/回归，正是玻尔兹曼问题在现代数学里的正式形态；本专题的定理语言不变，变的只是求和变成积分——**「时间平均」四个字的粒度从离散步长放宽到连续时刻**。

## 6 应用：大数定律、Shannon–McMillan–Breiman 与等分布

遍历定理的威力在于它把概率论、信息论与数论的经典结论统一成特例：

**大数定律。** 独立同分布随机变量 $(\xi_n)$ 配移位 $\sigma$，取 $f = \xi_0$（首坐标），Birkhoff 定理给出 $\frac1N\sum \xi_n \to \mathbb{E}\xi_0$ 几乎处处——**这就是经典强大数定律**。遍历定理是它的「平稳过程版」：不需要独立，只要过程平稳遍历，大数定律照样成立。<span class="marginnote">这一统一在统计上是根本性的：现实的时间序列（气象、金融、神经信号）几乎从不独立，但若平稳遍历，「样本均值收敛到总体均值」依然合法——这正是第6篇第2篇所说「用一段样本估计统计量」的严格依据。</span>

**Shannon–McMillan–Breiman 定理。** 对遍历平稳过程，逐点遍历定理应用于 $f(x) = -\log \mu[x_0]$（圆柱集测度的对数）给出 $(1/N)\log \mu[x_0 \dots x_{N-1}] \to h$——**测度熵的逐点大数定律**。这把第4篇的 Kolmogorov–Sinai 熵从「定义」变成「可观测量」：熵是「一条典型轨道的信息率」。

**数值例（$(\tfrac12,\tfrac12)$ 移位）：** 圆柱集 $[x_0\dots x_{N-1}]$ 的测度是 $2^{-N}$，故 $-\frac1N \log_2 \mu[x_0\dots x_{N-1}] = \frac1N \log_2 2^N = 1$——常数收敛，熵 $h = 1$（比特/步），与第4篇 $H(\tfrac12,\tfrac12) = \log_2 2 = 1$ 完全吻合。**典型字符串的长度 $N$ 与概率 $2^{-N}$ 的对数关系，被逐点定理逐位兑现。**

**等分布。** 对唯一遍历系统（第7篇），Birkhoff 定理对所有连续 $f$ 同时成立，推出轨道等分布——无理旋转 $\{n\alpha\}$ 的均匀分布、环面平移的等分布，都是遍历定理的特例。**遍历定理是 Weyl 等分布定理的测度论证明。**

**从定理到工具的路线：** 遍历定理在应用时通常不直接出场，而是以「标准引理」的形式被调用——「对几乎每个 $x$，某平均值收敛」这句话在所有证明里反复出现。学会把问题「翻译成」时间平均的形式，是使用遍历定理的第一步；本专题第7篇 Weyl 等分布、第8篇 Furstenberg 定理都会演示这种翻译。

## 7 小结

- **von Neumann 平均定理**：$L^2$ 里时间平均按范数收敛到投影 $Pf$——谱定理 / $I-U$ 消元的产物，统计力学的「系综平均 = 时间平均」版本。
- **Birkhoff 逐点定理**：$L^1$ 里时间平均几乎处处收敛到条件期望 $f^* = \mathbb{E}(f\mid\mathcal{I})$——极大不等式 + Hopf 论证，物理上更常用。
- **极大遍历定理**：$Mf$ 满足弱 (1,1) 估计 $\mu(Mf>\alpha) \le \|f\|_1/\alpha$，是证明逐点收敛的唯一杠杆，也是调和分析同一套工具。
- **遍历情形统一**：两条定理都退化为「时间平均 → $\int f\,d\mu$」，共同兑现遍历性的核心承诺。
- **三大应用**：大数定律（平稳版）、Shannon–McMillan–Breiman（熵的逐点定律）、等分布（Weyl 定理的测度论证明）。
- **历史坐标**：1931–1932 是「遍历定理的春天」——Koopman 算子、谱定理证明、极大不等式三件套在此定型，遍历理论自此与泛函分析、实分析永久合流。
- **一句话记忆**：von Neumann 管「平均收敛」，Birkhoff 管「逐点收敛」，极大不等式管「逐点收敛的杠杆」——三件套记住了，遍历定理的大厦就立住了。
- **遍历情形的落地**：遍历时两条定理都收敛到 $\int f\,d\mu$——统计物理「系综平均代替时间平均」自此有了两套证明、一个结论。
