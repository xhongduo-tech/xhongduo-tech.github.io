# 遍历性与不变测度（Poincaré 回归）

<div class="epigraph">

## 为什么从不变测度开始

第6篇第1篇把例子铺开之后，立刻浮出一个问题：**同一个变换 $T$ 配不同测度，系统的性质完全不同**。$x \mapsto 2x \bmod 1$ 配勒贝格测度遍历又混合，配周期轨上的均匀测度则既非遍历也非混合。所以遍历理论真正的研究对象不是「变换」，而是「变换 + 不变测度」这个二元组。本篇回答三个层层递进的问题：不变测度是否必然存在、遍历测度在不变测度里处于什么位置、以及「有限测度」一条假设能推出怎样惊人的结论——Poincaré 回归。<span class="marginnote">本专题第2篇《遍历性的定义与等价刻画》与《遍历分解》已分别给出遍历性与分解的严格理论；本篇从「不变测度集合」这个更高视角重述它们，并与第1篇第4节的 Poincaré 回复定理接上。</span>

对「从极限到大模型」主线，这一节还有另一层意义：不变测度对应马尔可夫链的**平稳分布**，遍历测度对应**不可约**，Poincaré 回归对应采样算法的**稳态无偏**——把本篇的证明想清楚，MCMC 收敛性背后的原理也就清晰了。

## 1 不变测度的存在性：Krylov–Bogolyubov 定理

一个系统被给定之后，配得上它的不变测度可能没有、可能有多个。**存在性**是第一个问题，答案由 Krylov–Bogolyubov 定理给出：

**定理（Krylov–Bogolyubov，1937）**：设 $T: X \to X$ 是紧度量空间上的连续映射，则存在至少一个 $T$-不变的 Borel 概率测度。

证明思路本身就是一套方法——**轨道平均法**：任取一点 $x$，构造经验测度 $\mu_N = \frac1N\sum_{n=0}^{N-1} \delta_{T^n x}$，即「轨道前 $N$ 步的均匀分布」。概率测度空间按弱-* 拓扑紧（Alaoglu 定理），故 $\{\mu_N\}$ 有聚点 $\mu$；因为 $\mu_N$ 与 $T_*\mu_N$ 只差两端项、差距 $\le \frac2N \to 0$，聚点 $\mu$ 满足 $T_*\mu = \mu$。<span class="marginnote">轨道平均法是遍历理论的「万用手术刀」：它既证明不变测度存在（本定理），又是 Birkhoff 定理里时间平均的载体（第6篇第3篇），还在第7篇 Weyl 等分布中再次出场。一步构造，三处复用。</span>

**易错点｜辨析：** 上述聚点 $\mu$ 不必遍历，也不必是 $x$ 的「正确」分布——不同 $x$ 的聚点可以不同。Krylov–Bogolyubov 只保证「有」，不保证「好」。当系统**唯一遍历**（第7篇）时，聚点对每个 $x$ 都是同一个且遍历，轨道平均的歧义彻底消失。

**例：** 对无理旋转 $R_\alpha$，任取 $x$，经验测度 $\frac1N\sum \delta_{R_\alpha^n x}$ 弱收敛到勒贝格测度——这正是 Weyl 等分布定理（第7篇）的测度论写法，Krylov–Bogolyubov 的聚点在这里是唯一的。对非连续或非紧的情形，存在性不保证：$[0,1)$ 上的无理旋转若在**不是**可数稠密的子集上不连续地定义，可能没有不变概率测度——**紧性与连续性不是装饰，而是存在性的充分条件**。

## 2 遍历测度作为极值点：Choquet 与遍历分解

有了存在性，下一个问题：不变测度们内部的结构。把所有 $T$-不变 Borel 概率测度记作 $\mathcal{M}_T(X)$。

**核心结论（Choquet 观点）**：$\mathcal{M}_T(X)$ 是紧凸集（弱-* 紧 + 凸组合封闭），而**遍历测度恰是它的极值点**——遍历测度无法写成两个不同不变测度的凸组合，反过来，极值点必遍历（第2篇《遍历分解》给出完整证明与 $\sigma$-代数语言）。

凸性与极值点的语言带来一个漂亮的分解定理：**每个不变测度都是遍历分量的「积分平均」**。对一般的 $\mu \in \mathcal{M}_T(X)$，存在遍历测度族 $\{\mu_x\}$ 使 $\mu = \int \mu_x \, d\tilde\mu(x)$——这就是**遍历分解（ergodic decomposition）**，它在测度论层面由「不变 $\sigma$-代数 $\mathcal{I}$ 的条件概率」实现（第2篇《遍历分解》）。

用物理语言说：**一个不遍历的系统，不过是若干个遍历「房间」的概率混合**。粒子呆在哪个房间里，决定它长期统计到哪个分量；而混合系数正是「进入各房间的概率」。遍历性的定义（不变集测度 0 或 1）在这一视角下就是「只有一间房」。

这一视角还给出验证遍历性的实用判据：要证明 $T$ 对 $\mu$ 遍历，只需证明「$T$ 对 $\mu$ 的唯一不变测度就是 $\mu$ 自己」（极值点 + 唯一性）。第2篇《遍历分解》在 $\sigma$-代数语言下把这个图景做得更完整——不变 $\sigma$-代数 $\mathcal{I}$ 的条件期望就是「投影到遍历分量」的算子。

**例：** 有限状态不可约马尔可夫链的平稳分布唯一，对应「$\mathcal{M}_T$ 是单点集」，故链遍历。可约链的平稳分布不唯一，极值点对应各闭类——与第2篇遍历分解逐字对应。**有限情形的 Choquet 图景就是马尔可夫链的经典理论**。

## 3 Poincaré 回归：有限测度下的必然回归

不变测度的存在让「有限测度」成为常设前提，而它立即爆出一条与直觉相悖的定理。

**定理（Poincaré 回归定理，1890）**：设 $T$ 是有限测度空间 $(X, \mathcal{B}, \mu)$ 上的保测变换。则对任意可测集 $A$，$A$ 中几乎每个点 $x$ 都**无限多次**回到 $A$：$\mu\big(A \setminus \bigcup_{n \ge 1} T^{-n} A\big) = 0$。

证明短而有力，用的是**漂游集（wandering set）** 论证：若 $B = A \setminus \bigcup_{n\ge1} T^{-n}A$ 是「从不回归的点集」，则 $T^{-k}B$ 两两不交（若 $T^{-k}B \cap T^{-l}B \ne \emptyset$，点会被拽回 $B$，矛盾）。不交族的测度和 $\sum \mu(T^{-k}B) = \infty \cdot \mu(B)$ 不得超过 $\mu(X) = 1$，故 $\mu(B) = 0$。<span class="marginnote">「有限测度」在这里不可去掉：实数轴上的平移 $x \mapsto x+1$ 配勒贝格（无限）测度，任何紧集都不回归。<strong>有限性让「空间装不下无限多互不相交的漂游副本」这一几何直觉生效</strong>——这是本定理的全部秘密。</span>

**历史：** Poincaré 在 1890 年研究三体问题的周期轨道时写下这一定理，旋即引来 Zermelo（1896）的著名批评：既然回归必然发生，热力学第二定律的「不可逆性」岂不是谎言？Boltzmann 的回应确立了现代理解——**宏观不可逆与微观回归相容**：回归的期望时间随系统规模指数爆炸，物理上永远等不到。本专题第1篇《庞加莱回复定理》有完整的时空尺度数字（如 $2^{10^{23}}$ 量级），此处不重复。

**数值检验：** 对倍增映射与 $A = [0, \tfrac12)$，几乎每个 $x$ 都无限多次进入 $A$——用二进制，$x \in A$ 意味着首位为 0，而二进制小数任意有限前缀之后「下一次出现 0」必然再次发生。对有理数 $x = 0.5$（二进制 $0.1000\dots$），它是周期点、永不离开 $A$；对几乎一切 $x$（无理数），进入 $A$ 无穷多次。**「几乎每个」在这里真的是「去掉一个零测集」**——零测集（有理数）恰好是全部例外。<span class="marginnote">注意 $A$ 本身是闭区间、$T$ 连续，但回归定理不需要任何拓扑假设——它纯粹是测度论的。拓扑与测度的分工，正是第5篇《拓扑动力系统》引入时一再强调的「两个世界」。</span>

## 4 Kac 引理：平均回归时间的精确值

Poincaré 定理保证「几乎必然回归」，Kac 引理给出**回归要等多长时间**。

**引理（Kac，1947）**：设 $T$ 遍历（或更强地满足一定无粘滞条件），$A$ 可测且 $\mu(A) > 0$，定义首次回归时间 $r_A(x) = \min\{n \ge 1 : T^n x \in A\}$。则平均回归时间为

$$\frac{1}{\mu(A)} \int_A r_A(x) \, d\mu = \frac{1}{\mu(A)}.$$

换句话说，**$\mu(A)$ 越大，回归越频繁**——占空间一半的集合平均每两次迭代回归一次。直觉：回归频率与该集合「被访问的概率」成正比，而访问概率就是 $\mu(A)$。

**数值例：** 对倍增映射 $x \mapsto 2x \bmod 1$ 与区间 $A = [0, \tfrac12)$，$\mu(A) = \tfrac12$，Kac 引理说平均首次回归时间为 2。用二进制看：$r_A(x)$ 是 $x$ 的二进制展开中「第一次出现 1」的位置（$x < \tfrac12$ 意味着首位为 0），平均等待两位——与几何分布的期望完全吻合。<span class="marginnote">Kac 引理在遍历定理与动力系统研究里是「估计返回时间」的默认工具：Sinai 的遍历理论教科书、Furstenberg 的多重回复证明都从它出发。它也是「平均返回时间 = 1/概率」这句格言的严格版本。</span>

## 5 公式解析：轨道平均与 Kac 平均

两条公式贯穿本篇，逐项拆开：

$$(1) \quad \mu_N = \frac1N \sum_{n=0}^{N-1} \delta_{T^n x} \ \xrightarrow{\ \mathrm{w}^*\ } \ \mu \in \mathcal{M}_T(X) \qquad (2) \quad \int_A r_A \, d\mu = 1$$

- **公式 (1) 第一项，$\delta_{T^n x}$**：点质量，把「系统在时刻 $n$ 的位置」记录成一个概率分布——位置即分布，动力系统被翻译成测度序列。
- **公式 (1) 第二项，求和与 $\frac1N$**：前 $N$ 个位置的均匀平均。它是「时间平均」的最初形态，也是 Birkhoff 定理（第6篇第3篇）的左端。
- **公式 (1) 第三项，弱-* 收敛**：聚点的存在靠 Alaoglu 紧性；不变性靠「端点项误差 $\le 2/N$」。**存在性的证明 = 取平均 + 取聚点 + 端点误差趋于 0**。
- **公式 (2) 第一项，$r_A$**：首次回归时间，是取值为 $\mathbb{N}$ 的可测函数（有限性由 Poincaré 定理保证）。
- **公式 (2) 第二项，积分等于 1**：这就是「平均回归时间 $= 1/\mu(A)$」，因为左端是 $\int_A r_A/\mu(A)$ 的分子。Kac 引理的证明用「轨道分解」：把 $A$ 中每个点接上它的首返轨道段，这些段的不交性（再次漂游集论证）把回归时间的期望算成几何级数。

两条公式合起来给出遍历理论最实用的图景：**时间平均给出不变测度（存在性），首返时间给出测度与集合大小的关系（Kac），而它们的桥梁正是遍历性**——遍历保证时间平均与空间平均一致，进而保证 Kac 的「访问概率 = 测度」成立。

**从公式到算法：** Krylov–Bogolyubov 的轨道平均正是「用一条长轨道近似不变测度」的算法原型——这就是蒙特卡洛采样与 MCMC 的数学内核（第三级《概率论与随机过程》与第四级《随机算法》都以此为起点）。先取轨道、再取平均、再证聚点不变：三步走通了「理论定理」与「数值模拟」的同一条路。

## 6 遍历性与不变测度的交互：三个具体系统

把抽象放回例子，检验「不变测度集合」的形状如何决定遍历性：

**无理旋转 $R_\alpha$**：勒贝格测度是**唯一**不变测度，故它遍历。**唯一遍历**（第7篇）在这里就是「$\mathcal{M}_T$ 是单点集」——最干净的情形，轨道平均对每个起点收敛到同一个测度。

**有理旋转 $R_{p/q}$**：任意「均匀分布在一条 $q$-周期轨道上」的测度都不变，还有它们的凸组合。$\mathcal{M}_T$ 是 $q$ 维单纯形，极值点对应各条周期轨——**系统在极值点处遍历，在内部点处不遍历**，完美示范第2节的 Choquet 图景。

**倍增映射 $x \mapsto 2x \bmod 1$**：$\mathcal{M}_T$ 既含勒贝格测度（遍历、混合），也含 $0$ 的周期轨点质量 $\delta_0$（不遍历）。**同一个变换的遍历性与否完全由测度决定**——这正是遍历理论不研究「裸变换」的原因。<span class="marginnote">倍增映射的例子说明：一个变换可以同时是「遍历系统」（配勒贝格）与「非遍历系统」（配 $\delta_0$）。文献里说「$T$ 遍历」时都隐含着「对某个（通常勒贝格类）测度」，切记不可望文生义。</span>

**双曲环面自同构 $T_A$**：勒贝格测度是唯一的不变测度，故遍历（第2篇《双曲环面自同构》有完整证明）。这里 Krylov–Bogolyubov 的轨道平均自动收敛——不存在第二个不变测度，轨道平均的歧义彻底消失，这也为第7篇「唯一遍历 ⟹ 等分布」提供了又一实例。

## 7 回归、遍历与统计物理的相容性

把第3、4节拼起来，就得到物理学的完整图景——这也是「遍历」一词（ergodic = 功 + 路径，Boltzmann 1884 年造词）最初要回答的问题。

**三个层次各司其职：** Poincaré 回归保证「微观必然回归」，Kac 引理保证「回归要等指数长的时间」，遍历性保证「时间平均等于空间平均」。热力学第二定律要求的是**宏观量**（温度、压力）单调演化，而宏观量是整个系统的平均量——单个粒子的回归对它毫无影响。<span class="marginnote">关键区分：<strong>回归是单点层面的现象，熵增是集合层面的现象</strong>。Kac 引理的「等待时间指数爆炸」把二者焊在一起——不是回归不会发生，而是它发生在任何实验时间之外。这一分辨在 1900 年代 Boltzmann 与 Zermelo、Loschmidt 的论战中定型。</span>

**回归时间量级：** 对 $N$ 个粒子的硬球气体，从「全挤在左半边」到「回归左半边」的平均时间约为 $2^{N}$ 量级的循环数。$N = 10^{23}$（阿伏伽德罗量级）时，这个数远超宇宙年龄——Kac 引理把「为什么等不到回归」从定性变成了定量。

**对现代科学的辐射：** 同样的图景在三个方向重演——**动力系统**（Aubry–Mather 理论中的回复结构）、**随机算法**（马尔可夫链的稳态分布即不变测度，回归保证「遍历样本的代表性」，见第三级《概率论与随机过程》）、**统计物理的遍历性假设**（系综平均 = 时间平均的严格条件，见第二级《统计力学与热力学》）。**「有限测度 + 保测 + 遍历」三件套，是这三门学科共同的地基。**

**核心结论：** Poincaré 回归不是悖论，而是理解「宏观不可逆来自微观可逆」的关键——回归与不可逆之间隔着一个指数级的等待时间，而遍历性负责把统计平均与时间平均对齐。遍历理论的第一哲学命题由此确立：**长期行为 = 统计行为，靠的正是不变测度与遍历性。**

## 8 小结

- **不变测度存在性**（Krylov–Bogolyubov）：紧度量空间 + 连续映射 ⟹ 至少一个不变概率测度；构造靠**轨道平均 + 弱-* 紧性**。
- **遍历测度 = 极值点**：$\mathcal{M}_T(X)$ 是紧凸集，遍历测度恰为其极值点；每个不变测度是遍历分量的积分（**遍历分解**）。
- **Poincaré 回归**：有限测度下几乎每个点无限多次回归；核心是**漂游集不交论证**，几何直觉是「空间装不下无限多个互不相交的漂游副本」。
- **Kac 引理**：平均首返时间 $= 1/\mu(A)$；倍增映射 + $[0,\tfrac12)$ 给出「平均等 2 步」的显式数值。
- **交互图景**：唯一遍历 ⟺ $\mathcal{M}_T$ 单点；不遍历 ⟺ 多个遍历「房间」的概率混合；同一变换可因测度不同而既遍历又不遍历。
- **统计物理相容性**：回归保证微观必然回归、Kac 保证等待时间指数爆炸、遍历保证时间平均 = 空间平均——三件事合起来解释「宏观不可逆来自微观可逆」。

在下一节，我们将把「时间平均」做成严格定理：**遍历定理**——von Neumann 的平均遍历定理与 Birkhoff 的逐点遍历定理，给出「时间平均 = 空间平均」的 Hilbert 空间与几乎处处两版证明。
