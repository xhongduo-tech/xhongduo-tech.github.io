## 为什么要在基因组里「定位」行为

双生子与收养研究证明了行为有遗传方差，动物模型证明了基因能改变行为，但都还没回答一个更具体的问题：**到底是哪些基因、在染色体上的哪些位置、以多强的效应影响行为？** 这个「定位」问题，是行为遗传学从统计走向分子、从「有多少遗传」走向「遗传在哪」的分水岭。

答案藏在减数分裂的重组里：染色体在形成配子时会交叉互换，**离得越近的基因座越不容易被重组拆散**。于是「共分离程度」成为测量基因之间距离的尺子，而连锁分析与关联分析是这两把尺子的两种读法。<span class="marginnote">上一级《遗传学》里孟德尔遗传学把基因当成抽象单位；这里基因第一次有了「位置」。行为遗传学进入基因组时代后，「一个行为性状的基因在哪」成为可定位的物理问题，也铺平了通往《GWAS 与多基因评分》的道路。</span>

## 1 重组：遗传图谱的尺子

同源染色体在减数分裂前期发生交叉，两条同源染色体交换片段——这就是**重组（recombination）**。两个基因座之间发生重组的概率叫**重组率**，记作 $\theta$，取值 0 到 0.5：

$\theta = 0$：两个基因座从未被拆散，完全连锁。
$\theta = 0.5$：两个基因座独立分配（等同不同染色体），无连锁。
$0 \lt  \theta \lt  0.5$：部分连锁，重组率大致反映物理距离——这就是**遗传作图**的原理：$\theta$ 越大，距离越远。

**辨析｜易错点：** 重组率不是线性地等于物理距离。同一染色体上相距很远的两个位点，重组率接近 0.5，看起来「像不连锁」。所以遗传距离用**厘摩（centiMorgan, cM）**表示，1 cM ≈ 1% 重组率（在较近距离内近似成立），但它与物理距离（碱基对数）只是统计关系而非严格等价。

用三个标记做一个具体的重组定位练习：假设在一条染色体上有标记 A、B、C，两两间实测重组率为 $\theta_{AB} = 0.05$、$\theta_{BC} = 0.04$、$\theta_{AC} = 0.09$。三者几乎满足 $0.05 + 0.04 = 0.09$，说明 A–B–C 顺序成立且重组率近似可加。**当实测的 $\theta_{AC}$ 明显小于 $\theta_{AB} + \theta_{BC}$ 时，说明 B 与 C 之间存在双交换**——两次重组把信号「藏」回去了。这就是为什么做遗传图谱要同时考虑多个标记、并用作图函数（如 Haldane 函数把重组率换算成可加的距离）修正。**单个重组率是「直线距离」，多标记作图才能还原「染色体上的真实顺序」。**

## 2 连锁分析：家系里的共分离

**连锁分析（linkage analysis）**在**家系内部**寻找规律：如果某个标记基因座与某性状在同一个家系里**代代共分离**（一起传递），说明二者在染色体上靠得很近。

工作流程是：收集一个有多个受累成员的大家系 → 对成员做全基因组标记基因分型（过去是微卫星，后来是 SNP）→ 扫描每个标记，看哪个标记的等位基因与患病状态「绑在一起」传下来。

经典的成功案例是亨廷顿舞蹈症：1983 年研究者用一个 DNA 标记在家系中把致病基因定位到 4 号染色体短臂——那时还不知道具体是哪个基因、哪个突变，只知道它**在哪**。这是「先定位、后找基因」范式的第一次胜利，也让连锁分析成为单基因病定位的标准工具。<span class="marginnote">连锁分析对<strong>单基因、高外显率</strong>的性状极其有力：一个大家系就足以锁定染色体区段。但对行为遗传学的主角——多基因、微效、受环境影响大的复杂性状——它的分辨率与功效都捉襟见肘。这正是它后来被关联分析部分取代的原因。</span>

## 3 公式解析：LOD 分数

连锁分析需要一个数字来判断「这个标记算不算与性状连锁」。遗传学家莫顿（Newton Morton）在 1955 年引入**LOD 分数（logarithm of odds）**：

$$
\text{LOD} = \log_{10} \frac{L(\theta = \hat{\theta})}{L(\theta = 0.5)}
$$

逐项拆解：

- **分子 $L(\theta = \hat{\theta})$**：假设真实重组率为 $\hat{\theta}$ 时，观测到的家系数据出现的**似然**（likelihood）。
- **分母 $L(\theta = 0.5)$**：假设「不连锁」（重组率 0.5，基因独立分配）时同一数据的似然。
- **比值**：两个假设下数据出现概率之比——比值越大，越支持「连锁」。
- **取对数**：把比值压到好读的尺度，并便于多个家系的 LOD 相加（对数乘积转和）。

判定标准是经验法则：**LOD ≥ 3 支持连锁**（约等于 1000:1 的赔率），LOD ≤ −2 排除连锁。一次扫描里，候选区段通常以「LOD 峰值」出现——峰的位置就是致病基因最可能所在。<span class="marginnote">LOD ≥ 3 之所以定得这么高，是因为全基因组扫描相当于做了成千上万次统计检验——按 0.05 的常规阈值会有大量假阳性，必须把阈值抬高到「能在多次检验中存活」的水平。这个「多重检验校正」的思路，在《GWAS 与多基因评分》一篇里会以更严格的形式再次出现。</span>

## 4 关联分析：群体里的统计相关

**关联分析（association study）**换了战场：不在单个家系里看共分离，而在**群体**里比较等位基因频率。

最经典的设计是**病例-对照**：精神分裂症患者组与健康对照组各测一组 SNP，看哪个 SNP 的等位基因频率在两组间显著不同。若某等位基因在患者中更常见，就称该 SNP 与疾病**关联（associated）**。

关联能工作，依赖一个现象：**连锁不平衡（linkage disequilibrium, LD）**。群体历史上，相邻的 SNP 往往作为一个整体（单倍型）被一起传下来，不会立刻被重组打散。所以一个致病 SNP 附近的「邻居 SNP」会带上它的统计信号——**我们测到的是邻居，定位的是真凶**。LD 让研究者不必先知道致病变异本身，用一组标签 SNP 就能把染色体扫一遍。<span class="marginnote">候选基因关联研究是早期主力：挑一个生物学上「看起来有关」的基因（比如与多巴胺相关的基因），测它内部的 SNP 与行为是否关联。这类研究的可重复性差到出名——许多「候选基因阳性结果」后来被大样本重复推翻。教训很深刻：统计关联 ≠ 因果机制，可重复性才是证据。这条主线在下一篇继续。</span>

## 5 连锁 vs 关联：分辨率之争

两个方法为何需要并存？因为它们在**分辨率**与**功效**之间做了相反的取舍。

| 维度 | 连锁分析 | 关联分析 |
| --- | --- | --- |
| 分析单元 | 家系 | 群体（病例-对照等） |
| 检测对象 | 基因座-性状共分离 | 等位基因频率差异 |
| 分辨率 | 低（cM 级，数百万碱基） | 高（可到单个 SNP） |
| 对单基因病 | 极有力 | 需要已知候选 |
| 对复杂性状 | 功效低 | 功效高（但需大样本） |

**链条式理解**：连锁分析先把候选区段缩到一个较大的范围（像用粗尺量出城市），关联分析再在范围内精确定位到 SNP（像用细尺找出门牌）。行为遗传学的分子时代是**先连锁粗定位、后关联精定位**的组合拳；而下一个十年，全基因组关联扫描（GWAS）把「精定位」推向全基因组规模，效率与规模都上了新台阶。<span class="marginnote">对多基因行为性状，连锁分析往往只能找到「部分显著的区段」，贡献微弱——这就是为什么行为遗传学在 2000 年代后期逐渐把重心从连锁转向 GWAS。但连锁没有退出历史舞台：罕见大效应突变（如自闭症的某些 de novo 突变）仍然靠家系连锁与家系外显子组测序来找。</span>

## 6 一个行为性状的完整定位工作流

把连锁与关联装进一条流水线，看一个行为性状如何被一步步「逼」到 SNP 上。假设目标是「小鼠的焦虑样行为」：

1. **杂交建系**：用高焦虑与低焦虑两个近交系杂交，得到 F1 再回交或自交，产生重组群体——重组就是天然的打散器。
2. **连锁粗定位**：在重组群体里扫全基因组标记，找到与焦虑分数显著连锁的区段。这一步通常给出一个**几千万碱基**的宽候选区（像用粗尺量出「大致在这个城市」）。
3. **精细作图**：在候选区内增加高密度标记，利用区内历史重组把区段进一步压缩——从「城市」缩到「街区」。
4. **关联精定位**：换成人类群体或更密的标记做关联分析，把信号钉在少数几个 SNP 上——从「街区」锁到「门牌」。
5. **功能验证**：回到动物模型敲除/下调候选基因，看焦虑行为是否改变；再回人类 GWAS 确认该基因与焦虑相关。

**这条流水线的每一站都在做同一件事：借重组这把尺子，把「与行为相关的基因组区域」越缩越小。** 连锁负责「从无到有」的粗定位，关联负责「从粗到精」的精定位，功能验证负责「从相关到因果」。<span class="marginnote">值得注意：步骤 2–3 对效应较大的单基因位点有效，而对精神分裂症这类「数百个微效位点」的性状，单靠连锁根本扫不出显著峰——这正是 GWAS 取代连锁成为主力的原因。连锁退居「罕见大效应变异」的定位工具，两把尺子各管一摊。</span>

**辨析｜易错点：** 工作流里「越缩越小」容易让人误以为「缩到最后一定有一个真凶基因」。现实是：行为性状常常是「每个微效位点周围都有几十个候选基因，谁也分不出谁是主角」。定位工作流的终点往往不是「一个基因」，而是一张「候选基因清单」——它把问题从「在哪」推进到「在谁里面」，但最后的因果判定仍需要功能实验。

## 7 连锁不平衡的度量：D′ 与 r²

第 4 节把 LD 当作一个名词，这一节给它配齐数学。设两个位点各有等位基因 A/a 与 B/b，群体中单倍型 AB 的频率为 $P_{AB}$，两个等位基因各自的频率为 $P_A$、$P_B$：

$$
D = P_{AB} - P_A P_B, \qquad
r^2 = \frac{D^2}{P_A P_a P_B P_b}
$$

- **$D$（连锁不平衡系数）**：观测到的 AB 单倍型频率，与「两个等位基因随机组合」时的期望频率之差。$D = 0$ 表示完全随机（连锁平衡），$D \neq 0$ 表示非随机关联。
- **$D'$**：把 $D$ 标准化到 [−1, 1]，$D' = D / D_{\max}$——它刻画「是否发生了重组」，对等位基因频率不敏感。
- **$r^2$**：把 $D$ 除以四个等位基因频率的乘积再平方，范围 [0, 1]——它直接反映「一个位点能预测另一个位点的程度」，是选择标签 SNP 与评估关联信号的代表性的关键量。

拆成三步理解它们在 GWAS 里的用途：

- **第一步**，估计单倍型频率，算出任意两位点间的 $r^2$。
- **第二步**，选标签 SNP：在 $r^2$ 高的区块里，只需测少数几个「代表」SNP，就能覆盖整个区块的信号——**这是 GWAS 芯片用几十万标签 SNP 覆盖全基因组的原理**。
- **第三步**，精定位：当 GWAS 命中的一个显著 SNP 与附近一群 SNP 高度连锁（$r^2$ 高）时，信号无法区分是哪一个——**LD 既帮助检测，也阻碍定位**。因果变异的判定需要利用不同祖源人群的 LD 结构差异（跨人群精细定位）或功能实验。

**辨析｜易错点：** $D'$ 与 $r^2$ 回答不同问题，不能互换。$D'$ 对「是否有过重组」敏感，$r^2$ 对「统计预测力」敏感——两个位点即使 $D' = 1$（从未重组），若等位基因频率极端，$r^2$ 也可能很低（预测力弱）。**报告 LD 必须说明用的是哪个度量**，这是分子遗传学文献里最容易读串的细节之一。

## 8 小结

- **重组率** $\theta$ 是遗传距离的尺子，$\theta = 0$ 完全连锁，$\theta = 0.5$ 独立分配。
- **连锁分析**在家系内找共分离，**LOD 分数** $\log_{10}[L(\hat\theta)/L(0.5)] \ge 3$
