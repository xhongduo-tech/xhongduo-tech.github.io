# 最小二乘的几何解释与直线拟合

## 为什么从几何解释开始

前面三节的最小二乘是「代数」：正规方程、QR、公式。本节把一切画出来——**最小二乘的几何**。一旦看清「$b$ 投影到列空间、残差垂直」这幅画，最小二乘的全部公式都变成「看图说话」，不再需要死记。<span class="marginnote">最小二乘的几何核心：<strong>$b$ 不在列空间里（数据有噪声），把 $b$ 正交投影到列空间，投影点 $A\hat{x}$ 就是离 $b$ 最近的列组合</strong>。距离（误差）由残差的长度度量，垂直保证距离最小。这幅图是理解回归、PCA、信号逼近的共同入口。</span>

本节配一张投影几何图，并用直线拟合作为完整实例。

## 1 最小二乘的几何图景

![最小二乘的几何：向量 b 在列空间上的正交投影](/images/linear-algebra/least-squares-geometry-1.svg)

上图是直线拟合情形的几何图景：平面（这里是过原点的一条直线）代表列空间 $\operatorname{Col}(A)$；$\mathbf{b}$ 是观测向量；$\hat{\mathbf{b}} = A\hat{\mathbf{x}}$ 是 $\mathbf{b}$ 在列空间上的**正交投影**；残差 $\mathbf{e} = \mathbf{b} - \hat{\mathbf{b}}$ 垂直于列空间。

**重点**：这幅图的三个几何事实，对应最小二乘的全部公式——

1. **投影点在列空间内**：$A\hat{\mathbf{x}} \in \operatorname{Col}(A)$，所以 $Ax = \hat{b}$ 精确可解（把 $b$ 换成投影点）；
2. **残差垂直**：$\mathbf{e} \perp \operatorname{Col}(A)$，即 $A^T\mathbf{e} = \mathbf{0}$，这是正规方程 $A^TA\hat{x} = A^Tb$ 的来源；
3. **投影最近**：$\|\mathbf{e}\|$ 是最短距离——$\hat{b}$ 是列空间中离 $b$ 最近的向量，这正是「误差平方和最小」。

**辨析｜易错点：** 投影点 $\hat{b}$ 在列空间内，但**残差 $e$ 在左零空间**（列空间的正交补）——两者各属一个子空间。图中竖直的那条线段（$e$）横跨「列空间之外」，正是它度量了「$b$ 离可解域有多远」。

## 2 公式解析：$\hat{\mathbf{x}} = (A^TA)^{-1}A^T\mathbf{b}$ 的几何读法

把正规方程的解从几何上重读一遍，拆成四步：

- **第一步，投影是「找到最近点」**：$b$ 投影到 $\operatorname{Col}(A)$ 得 $\hat{b}$。因为 $\hat{b}$ 在列空间，存在 $\hat{x}$ 使 $A\hat{x} = \hat{b}$。
- **第二步，残差垂直锁定位置**：「$\hat{b}$ 是最近点」等价于「$e = b - \hat{b}$ 与每一列垂直」，即 $A^T(b - A\hat{x}) = \mathbf{0}$。
- **第三步，解出 $\hat{x}$**：$A^TA\hat{x} = A^Tb$，列满秩时 $\hat{x} = (A^TA)^{-1}A^Tb$。
- **第四步，合成**：$\hat{b} = A\hat{x} = A(A^TA)^{-1}A^Tb = Pb$，投影矩阵 $P$ 完成「从 $b$ 到最近点」的搬运。**整条链 = 投影 + 垂直 + 解方程**。

<span class="marginnote"><strong>「残差垂直」是整套几何的支点</strong>：任何「最佳逼近」问题（傅里叶级数、PCA、回归）都可以表述成「在子空间里找离目标最近的向量」，而最佳解永远满足「残差垂直于子空间」。这个原理叫<strong>正交投影定理</strong>，是逼近论（第二级《数值分析》）的基石。</span>

## 3 直线拟合：完整实例

拟合数据点 $(0, 1), (1, 2), (2, 3), (3, 5)$ 为直线 $y = c_1 + c_2x$（上节的例，这里做几何对照）。

- 设计矩阵 $A = \begin{pmatrix} 1 & 0 \\ 1 & 1 \\ 1 & 2 \\ 1 & 3 \end{pmatrix}$（列是「常数列」与「x 列」），$\mathbf{b} = (1, 2, 3, 5)^T$；
- 列空间是 $\mathbb{R}^4$ 中的二维子空间，由 $A$ 的两列张成；
- $\mathbf{b}$ 不在这个平面里（数据不在一条直线上），所以 $Ax = b$ 无解；
- 投影得 $\hat{\mathbf{x}} = (1.1, 1.1)^T$，$\hat{b} = A\hat{x} = (1.1, 2.2, 3.3, 4.4)^T$ 是 $\mathbb{R}^4$ 中离 $b$ 最近的「平面点」；
- 拟合直线 $y = 1.1 + 1.1x$，残差 $(-0.1, -0.2, -0.3, 0.6)$ 与两列都垂直（上节已验证）。

**重点**：**「拟合直线」不是几何上的线本身，而是 $b$ 在列空间的投影在「系数空间」里的坐标**。数据点不共线 = $b$ 不在列空间；投影后共线 = 残差最小。这就是「回归线」的代数本质。

## 4 几何解释的推广：多项式与高维

最小二乘的几何不只适用于直线。用 $n$ 个基函数拟合，只需把设计矩阵的列换成对应基函数在数据点的取值：

- 二次拟合：$A$ 的列是 $1, x, x^2$ 在数据点的取值；
- 多元回归：$A$ 的列是各特征在样本上的取值（第十一篇）；
- 傅里叶逼近：$A$ 的列是三角函数在采样点的取值。

**重点**：**无论列是「什么」，几何不变**——$b$ 投影到列空间，残差垂直，正规方程成立。这就是最小二乘的普适性：**一图解万题**。数据科学的线性回归、信号处理的滤波、数值分析的曲线拟合，共用这一幅投影图。

**辨析｜易错点：** 高维情形的「列空间」不可直观画出，但几何结论（垂直、最近、投影）完全不变。学习高阶内容时，**把高维问题「画」成二维投影图的形状再推广**，是行之有效的思维策略。

**补充｜投影的「三种等价表述」**：最小二乘的几何可以用三种语言等价表述——**几何**（$b$ 投影到列空间，残差垂直）、**代数**（正规方程 $A^TA\hat{x} = A^Tb$）、**数值**（QR/SVD 稳定求解）。三者说的都是「在子空间里找最近点」。遇到最小二乘相关的问题，先问自己「用哪种语言想最清楚」：证明存在性用几何、写公式用代数、写代码用数值。**「一题三解」是掌握最小二乘的标志**——任何两种解法得到的 $\hat{x}$ 必须一致。

**辨析｜易错点：** 直线拟合的「投影图」只画得出 $\mathbb{R}^2/\mathbb{R}^3$ 的情形，但高维回归的几何完全平行——只是「列空间」变成高维平面无法画图。**别让「画不出来」误导你「想不明白」**：高维里「投影、垂直、最近」三个性质一字不变，这正是线性代数「从几何直觉到代数严格」的价值所在。

## 5 补充：用公式核对几何

把「投影几何」与「公式」再对齐一遍，用最小二乘的标准记号：

**核心公式**：$\hat{\mathbf{x}} = (A^TA)^{-1}A^T\mathbf{b}$，$\hat{\mathbf{b}} = A\hat{\mathbf{x}} = P\mathbf{b}$，$P = A(A^TA)^{-1}A^T$，$\mathbf{e} = \mathbf{b} - \hat{\mathbf{b}}$。

**公式解析（四步核对）**：

- 第一步，**$\hat{b} \in \operatorname{Col}(A)$**：$P\mathbf{b}$ 是 $A$ 的列的线性组合，几何上就是「落在列空间里的点」；
- 第二步，**$\mathbf{e} \perp \operatorname{Col}(A)$**：$A^T\mathbf{e} = A^T(\mathbf{b} - P\mathbf{b}) = A^T\mathbf{b} - A^TA(A^TA)^{-1}A^T\mathbf{b} = \mathbf{0}$——代数验证了垂直；
- 第三步，**$\hat{b}$ 是最近点**：由正交分解定理（第七篇），$\mathbf{b} = \hat{b} + \mathbf{e}$ 把 $\mathbf{b}$ 唯一拆成「列空间部分 + 垂直部分」，$\|\mathbf{e}\|$ 就是最短距离；
- 第四步，**检验 $R^2$**：$\|\hat{\mathbf{b}}\|^2/\|\mathbf{b}\|^2$ 是「被解释的方差比例」，几何上等于「投影长度平方占总长度平方」。

**辨析｜易错点：** 「投影最近」的严格证明依赖勾股定理：对任意 $\mathbf{u} \in \operatorname{Col}(A)$，$\|\mathbf{b} - \mathbf{u}\|^2 = \|\mathbf{e}\|^2 + \|\hat{b} - \mathbf{u}\|^2 \ge \|\mathbf{e}\|^2$——因为 $\mathbf{e} \perp (\hat{b} - \mathbf{u})$。**「垂直 + 勾股 = 最近」**，这一句话是最小二乘全部几何的证明核心。

## 6 补充：最小二乘几何的三句话总结

最小二乘的全部几何可以压缩成三句话，每一句都对应一组公式：

**第一句（投影）**：$\hat{\mathbf{b}} = P\mathbf{b}$ 是 $\mathbf{b}$ 在列空间上的正交投影，$P = A(A^TA)^{-1}A^T$ 是投影矩阵。

**第二句（垂直）**：残差 $\mathbf{e} = \mathbf{b} - A\hat{\mathbf{x}}$ 垂直于列空间，即 $A^T\mathbf{e} = \mathbf{0}$——这是正规方程 $A^TA\hat{x} = A^Tb$ 的全部来源。

**第三句（最近）**：$\hat{\mathbf{b}}$ 是列空间中离 $\mathbf{b}$ 最近的向量，$\|\mathbf{e}\|$ 是最短距离，误差平方和最小。

**辨析｜易错点：** 这三句话的顺序不要颠倒——先有「投影」，才有「垂直」，再得「最近」。若只记住「正规方程」而忘了背后的投影图，遇到病态、秩亏问题就会迷失方向。**「先画图，再写公式，后选算法」**是最小二乘的完整思维链。

**补充｜学习地图**：最小二乘的几何是整个「正交性」篇的收官——它把投影、正规方程、QR、SVD、四子空间全部串进一个问题，并在第十一篇（回归、PCA）反复使用。**「投影图」是理解一切近似问题的总图景**。

## 7 小结

- **几何核心**：$b$ 投影到列空间，投影点 = 最近点，残差垂直。
- **三大事实**：$\hat{b} \in \operatorname{Col}(A)$；$\mathbf{e} \perp \operatorname{Col}(A)$；$\hat{b}$ 最短距离。
- **公式的几何读法**：$\hat{x} = (A^TA)^{-1}A^Tb$ = 投影 + 垂直 + 解方程。
- **直线拟合**：回归线 = $b$ 在列空间的投影在系数空间的坐标。
- **普适性**：多项式、多元回归、傅里叶逼近共用同一幅投影图。
