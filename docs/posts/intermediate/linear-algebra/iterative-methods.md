## 为什么从迭代解法开始

LU 直接法是稠密矩阵的标准工具，但现实中的大方程组常常是**稀疏的**（每个方程只涉及少量变量，如偏微分方程的差分离散、网络流、图问题）。直接法会破坏稀疏性、代价 $O(n^3)$；**迭代法**每次只做便宜的矩阵乘向量（$O(n)$ 或 $O(n^2)$），从猜测出发逐步逼近真解。<span class="marginnote">迭代法的价值在大规模问题中无可替代：<strong>稀疏矩阵存储 $O(n)$，每次迭代 $O(n)$，几百步就能达到足够精度</strong>——这是求解 10⁶ 变量以上的偏微分方程离散系统的唯一现实路径。共轭梯度、GMRES 是现代迭代法的王牌（本专题点到为止）。</span>

本节介绍两种经典迭代法（Jacobi 与 Gauss-Seidel）及其收敛判据。

## 1 迭代法的思想框架

把方程组 $A\mathbf{x} = \mathbf{b}$ 改写成**不动点形式**：

$$
\mathbf{x} = B\mathbf{x} + \mathbf{c}
$$

给定初始猜测 $\mathbf{x}^{(0)}$，迭代

$$
\mathbf{x}^{(k+1)} = B\mathbf{x}^{(k)} + \mathbf{c}
$$

**重点**：迭代收敛到真解 $\mathbf{x}^*$（满足 $\mathbf{x}^* = B\mathbf{x}^* + \mathbf{c}$）的条件是：**迭代矩阵 $B$ 的谱半径 $\rho(B) < 1$**（谱半径 = 特征值模的最大值）。收敛速率由 $\rho(B)$ 控制：$\rho$ 越接近 0 收敛越快。

**误差演化**：设 $\mathbf{e}^{(k)} = \mathbf{x}^{(k)} - \mathbf{x}^*$，则 $\mathbf{e}^{(k+1)} = B\mathbf{e}^{(k)} = B^k\mathbf{e}^{(0)}$。$\|\mathbf{e}^{(k)}\|$ 约按 $\rho(B)^k$ 衰减——**谱半径是收敛速度的时钟**。

## 2 Jacobi 迭代

把 $A = D + L + U$ 拆成对角 $D$、严格下三角 $L$、严格上三角 $U$。$Ax = b$ 写成分量形式：

$$
\sum_j a_{ij}x_j = b_i \Rightarrow a_{ii}x_i = b_i - \sum_{j \ne i} a_{ij}x_j
$$

**Jacobi 迭代（雅可比迭代）**：用上一步的所有分量来更新第 $i$ 个分量：

$$
x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j \ne i} a_{ij}x_j^{(k)}\right)
$$

矩阵形式：$D\mathbf{x}^{(k+1)} = \mathbf{b} - (L + U)\mathbf{x}^{(k)}$，即 $\mathbf{x}^{(k+1)} = D^{-1}(\mathbf{b} - (L+U)\mathbf{x}^{(k)})$。

**重点**：Jacobi 的迭代矩阵是 $B_J = -D^{-1}(L + U)$。**所有 $i$ 分量的更新同时进行（用 $\mathbf{x}^{(k)}$），天然并行**——这是 Jacobi 在现代并行计算里复兴的原因。

**一个完整例子**：解

$$
\begin{cases}
4x_1 - x_2 = 5 \\
- x_1 + 4x_2 = 3
\end{cases}
$$

从 $\mathbf{x}^{(0)} = (0, 0)$ 出发：$x_1^{(1)} = (5 + x_2^{(0)})/4 = 5/4 = 1.25$，$x_2^{(1)} = (3 + x_1^{(0)})/4 = 0.75$。继续迭代：$x_1^{(2)} = (5 + 0.75)/4 = 1.4375$，$x_2^{(2)} = (3 + 1.25)/4 = 1.0625$。真解 $(4/3, 1/3·... )$：解得 $x_1 = 4/3 \approx 1.333$，$x_2 = 13/12 \approx 1.083$。序列收敛到真解。

## 3 Gauss-Seidel 迭代

Gauss-Seidel 的改进：**更新第 $i$ 个分量时，立刻使用已经更新的 $x_1, \cdots, x_{i-1}$**：

$$
x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j < i} a_{ij}x_j^{(k+1)} - \sum_{j > i} a_{ij}x_j^{(k)}\right)
$$

矩阵形式：$(D + L)\mathbf{x}^{(k+1)} = \mathbf{b} - U\mathbf{x}^{(k)}$，迭代矩阵 $B_{GS} = -(D + L)^{-1}U$。

**重点**：**Gauss-Seidel 通常比 Jacobi 收敛快一倍**（约减半迭代次数），因为它「用上新信息」。代价是**串行**——后一个分量依赖前一个，不容易并行。工程上还有**SOR（逐次超松弛）**：在 Gauss-Seidel 基础上加松弛因子 $\omega$ 加速收敛。

**辨析｜易错点：** Gauss-Seidel 的迭代矩阵 $B_{GS} = -(D+L)^{-1}U$ 更复杂（含求逆），但实际实现不需要显式求逆——直接按分量公式迭代即可。**写实现时用分量公式，分析收敛时用迭代矩阵**。

## 4 公式解析：收敛判据 $\rho(B) < 1$

迭代收敛的核心定理，拆成四步：

- **第一步，谱半径的定义**：$\rho(B) = \max_i |\lambda_i(B)|$——特征值模的最大值。
- **第二步，充分条件**：若 $\rho(B) < 1$，则 $B^k \to O$，对任意初始猜测 $\mathbf{e}^{(k)} = B^k\mathbf{e}^{(0)} \to \mathbf{0}$，迭代收敛到 $\mathbf{x}^*$。
- **第三步，矩阵形式**：若 $\rho(B) \ge 1$，存在特征向量方向不衰减，迭代不收敛（或只在特殊初值收敛）。
- **第四步，实用判据（充分条件）**：若 $\|B\| < 1$（任何范数），则 $\rho(B) < 1$，迭代收敛。特别是**行对角占优**时 Jacobi 与 Gauss-Seidel 都收敛：
  $$
  |a_{ii}| > \sum_{j \ne i} |a_{ij}|
  $$
  ——对角占优是迭代收敛的「免费入场券」。

<span class="marginnote"><strong>对角占优 = 每行主对角元占主导</strong>。物理问题离散化后的矩阵（热传导、扩散）通常对角占优，所以迭代法在这些场景里几乎总是收敛。谱半径不仅判断收敛，还给出收敛速度：$\rho$ 越接近 1，收敛越慢——<strong>病态矩阵的迭代也慢</strong>。</span>

## 5 收敛速度与预条件

- **收敛速率**：误差约按 $\rho^k$ 衰减，达到精度 $\varepsilon$ 需约 $\frac{\ln\varepsilon}{\ln\rho}$ 次迭代。$\rho = 0.9$ 时约需 $66$ 步减半误差，$\rho = 0.5$ 时 $1$ 步就减半。
- **预条件（preconditioning）**：对病态/收敛慢的系统，先乘一个便宜的近似逆 $M^{-1}$，把 $Ax = b$ 变成 $M^{-1}Ax = M^{-1}b$，使新系统的谱半径更小、收敛更快。**预条件是现代迭代法性能的关键**（共轭梯度配合预条件解决大型稀疏系统）。

**重点**：迭代法的完整选择树：稠密小系统用 LU；稀疏大系统用迭代；对称正定用**共轭梯度（CG）**；非对称用 GMRES/BiCGSTAB。CG 每次迭代只需矩阵乘向量与内积，$O(n)$ 每步——**这是大数据线性系统的默认路径**。

**辨析｜易错点：** 迭代法**不精确**（有限步达到给定精度即可），与直接法（精确到舍入误差）哲学不同。「收敛」指误差趋于零，不指某一步恰好到真解。实际停止准则通常是「残差 $\|Ax^{(k)} - b\|$ 小于容差」。

**补充｜残差与停止准则**：迭代法实践中不会迭代到「精确解」，而是在残差足够小时停止：当 $\|A\mathbf{x}^{(k)} - \mathbf{b}\| < \varepsilon$（容差）时认为已收敛。残差是「当前迭代点离真解有多远」的可计算代理。**注意区分「残差」与「误差」**：残差 $r_k = Ax_k - b$ 可以算（不需要真解），误差 $e_k = x_k - x^*$ 算不了（需要真解）；但 $\|e_k\| \le \kappa(A)\|r_k\|$，条件数大的系统里小残差可能对应大误差。

**补充｜残差与停止准则**：迭代法实践中不会迭代到「精确解」，而是在残差足够小时停止：当 $\|A\mathbf{x}^{(k)} - \mathbf{b}\| < \varepsilon$（容差）时认为已收敛。残差是「当前迭代点离真解有多远」的可计算代理。**注意区分「残差」与「误差」**：残差 $r_k = Ax_k - b$ 可以算（不需要真解），误差 $e_k = x_k - x^*$ 算不了（需要真解）；但 $\|e_k\| \le \kappa(A)\|r_k\|$，条件数大的系统里小残差可能对应大误差。

**辨析｜易错点：** Jacobi 与 Gauss-Seidel 的收敛条件：

- **对角占优**（$|a_{ii}| > \sum_{j\ne i}|a_{ij}|$）是两者的充分条件——物理离散矩阵常满足；
- 对称正定时，Gauss-Seidel 必收敛，Jacobi 不一定；
- 谱半径 $\rho(B) < 1$ 是**充要**条件（但计算谱半径本身不便宜）。

**「对角占优给免费入场券，谱半径是精确裁判」**——前者用于快速判断，后者用于理论保证。

## 6 小结

- **思想**：$Ax = b$ 改写成 $\mathbf{x} = B\mathbf{x} + \mathbf{c}$，迭代逼近。
- **收敛**：$\rho(B) < 1$ 收敛；对角占优是充分条件。
- **Jacobi**：所有分量同时更新，天然并行；$B_J = -D^{-1}(L+U)$。
- **Gauss-Seidel**：逐个分量用新值，串行、通常更快；SOR 加松弛加速。
- **现代扩展**：CG/GMRES + 预条件，处理大型稀疏系统。
