# 伪逆（Moore-Penrose 逆）及其性质

## 为什么从伪逆开始

可逆矩阵的 $A^{-1}$ 解决「$Ax = b$ 有唯一解」；但现实里 $A$ 常常是长方形或奇异的。**伪逆（Moore-Penrose 逆）** $A^+$ 把这套理论推广到底：无论 $A$ 是什么形状、什么秩，都能定义一个「最接近逆」的矩阵，给出「最小二乘 + 最小范数」意义下的最佳解。<span class="marginnote">伪逆是数据科学的「万能解算子」：<strong>欠定系统（行少列多）取最小范数解，超定系统（行多列少）取最小二乘解</strong>——两者都是 $x = A^+b$。NumPy 的 `np.linalg.pinv`、MATLAB 的 `pinv` 底层就是 SVD 伪逆。推荐系统、信号重建、机器人逆运动学（第二级《具身智能》）都靠它。</span>

本节用 SVD 构造伪逆，并证明它的四条 Moore-Penrose 公理。

## 1 用 SVD 构造伪逆

设 $A = U\Sigma V^T$ 是 SVD，奇异值 $\sigma_1 \ge \cdots \ge \sigma_r > 0$。定义

$$
A^{+} = V \Sigma^{+} U^T
$$

其中 $\Sigma^{+}$ 是 $n \times m$ 矩阵，把 $\Sigma$ **转置**并把非零对角元**取倒数**：

$$
\Sigma^{+} = \operatorname{diag}\left(\frac{1}{\sigma_1}, \cdots, \frac{1}{\sigma_r}, 0, \cdots, 0\right)
$$

**核心概念**：$A^{+}$ 称为 $A$ 的 **Moore-Penrose 伪逆（pseudoinverse）**。

**重点**：伪逆的构造就是「转置 + 取倒数 + 恢复方向」——对可逆方阵，$A^+ = A^{-1}$（普通逆是伪逆的特例）。$A^{+}$ 的奇异值是 $1/\sigma_i$（对应非零奇异值），零奇异值保持为零。

**辨析｜易错点：** $\Sigma^{+}$ 的尺寸是 $n \times m$（与 $\Sigma$ 转置同型），不是 $m \times n$。$A$ 是 $m \times n$，则 $A^+$ 是 $n \times m$——**伪逆反转形状**。可逆时 $A^{-1}$ 也是 $n \times n$，一致。

## 2 Moore-Penrose 四条公理

$A^+$ 由四条性质**唯一确定**（Moore-Penrose 公理）：

1. $AA^+A = A$（$A^+$ 是 $A$ 的「右逆」意义）；
2. $A^+AA^+ = A^+$（$A$ 是 $A^+$ 的「右逆」意义）；
3. $(AA^+)^T = AA^+$（$AA^+$ 对称，是投影矩阵）；
4. $(A^+A)^T = A^+A$（$A^+A$ 对称，是投影矩阵）。

**重点**：这四条公理把「逆」的全部好性质推广到最弱情形。$AA^+$ 是到 $\operatorname{Col}(A)$ 的正交投影（$m \times m$），$A^+A$ 是到 $\operatorname{Row}(A)$ 的正交投影（$n \times n$）。**伪逆让「投影」有了代数表达**。

**公式解析**（验证公理 3）：$AA^+ = (U\Sigma V^T)(V\Sigma^+ U^T) = U\Sigma\Sigma^+ U^T$。$\Sigma\Sigma^+$ 是对角阵（前 $r$ 个对角元 1、其余 0），对称，故 $AA^+ = U(\Sigma\Sigma^+)U^T$ 对称且幂等——正是列空间投影。**SVD 的正交性让一切验证变成对角阵运算**。

## 3 伪逆的解方程角色：$x = A^+b$

伪逆最重要的应用：$Ax = b$ 的「最佳解」统一为

$$
\hat{\mathbf{x}} = A^{+} \mathbf{b}
$$

分情形拆开：

- **相容且有唯一解**（$A$ 可逆方阵）：$\hat{x} = A^{-1}b$，伪逆退化为普通逆；
- **超定（$m > n$，列满秩）**：$\hat{x} = (A^TA)^{-1}A^Tb$——**最小二乘解**（第八篇正规方程）；
- **欠定（$m < n$，行满秩）**：$\hat{x} = A^T(AA^T)^{-1}b$——**最小范数解**（无穷多解中范数最小者）；
- **一般（秩亏）**：$\hat{x} = V\Sigma^+U^Tb$——**同时最小化 $\|Ax - b\|$ 且 $\|x\|$ 最小**。

**重点**：**$x = A^+b$ 一统天下**：不管 $A$ 什么形状，它都给出「误差最小 + 范数最小」的双重最优解。这解释了为什么现代库的 `pinv` 能处理一切方程组。

<span class="marginnote">伪逆的统一性令人叹服：<strong>最小二乘（投影）与最小范数（选最短）在伪逆里合二为一</strong>。欠定系统（如推荐系统、图像重建）天然有无穷多解，伪逆挑出「最简洁」的那个——这是它在工程里被广泛使用的原因。</span>

## 4 伪逆的性质

- $(A^+)^+ = A$（伪逆的伪逆还原）；
- $(A^T)^+ = (A^+)^T$（转置与伪逆可交换）；
- $(AA^T)^+ = (A^T)^+A^+$ 等代数性质；
- **秩**：$\operatorname{rank} A^+ = \operatorname{rank} A$；
- **可逆特例**：$A$ 可逆时 $A^+ = A^{-1}$；
- **列满秩**：$A^+ = (A^TA)^{-1}A^T$；**行满秩**：$A^+ = A^T(AA^T)^{-1}$。

**辨析｜易错点：** 伪逆**不是**「给零奇异值取倒数」——零奇异值保持为零（不能除以零）。伪逆只对**非零**奇异值取倒数。这正是奇异矩阵「求逆」的出路：不存在的逆方向直接丢弃（映射到零）。

## 5 例子：长方形的伪逆

$A = \begin{pmatrix} 1 & 0 \\ 0 & 1 \\ 0 & 0 \end{pmatrix}$（$3 \times 2$，行满秩）。SVD：$\sigma_1 = \sigma_2 = 1$，$U = I$，$V = I$。伪逆

$$
A^+ = \Sigma^+ U^T = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \end{pmatrix}
$$

验证：$A^+A = I_2$，$AA^+ = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 0 \end{pmatrix}$（到 $\operatorname{Col}(A)$ 的投影）。对 $b = (3, 4, 5)^T$，$A^+b = (3, 4)^T$——**丢弃第三维（左零空间）的信息，取最小二乘解**。

**重点**：伪逆的几何 = 分解到四子空间：$b$ 先投影到列空间（丢弃左零空间部分），在行空间里解出最小范数的 $x$。**「投影 + 解」两步，SVD 伪逆一步完成**。

**补充｜伪逆与「列空间/行空间」的完全分解**：伪逆在四子空间框架下的行为极其干净——$A^+$ 把 $b$ 的**左零空间分量丢弃**（不可解部分），把 $b$ 的**列空间分量**映到行空间中范数最小的原像（最小范数解）。因此 $A^+$ 实际上建立了一个「$\operatorname{Col}(A) \to \operatorname{Row}(A)$」的线性同构，而左零空间与零空间都被置零。**「伪逆 = 在四子空间间建立规范映射」**——这是它几何意义的最深刻表述。

**补充｜伪逆与「列空间/行空间」的完全分解**：伪逆在四子空间框架下的行为极其干净——$A^+$ 把 $b$ 的**左零空间分量丢弃**（不可解部分），把 $b$ 的**列空间分量**映到行空间中范数最小的原像（最小范数解）。因此 $A^+$ 实际上建立了一个「$\operatorname{Col}(A) \to \operatorname{Row}(A)$」的线性同构，而左零空间与零空间都被置零。**「伪逆 = 在四子空间间建立规范映射」**——这是它几何意义的最深刻表述。

**辨析｜易错点：** 伪逆与「左逆/右逆」的关系：

- 列满秩（$m \ge n$）时，$A^+ = (A^TA)^{-1}A^T$ 是**左逆**（$A^+A = I$）；
- 行满秩（$m \le n$）时，$A^+ = A^T(AA^T)^{-1}$ 是**右逆**（$AA^+ = I$）；
- 一般秩亏时，$A^+A$ 与 $AA^+$ 都只是投影矩阵，不再是单位阵。

**「满秩才有单侧逆，秩亏只有投影」**——伪逆统一了三者。

**补充｜伪逆的「一句话」**：**「$A^+$ 是 $A$ 在四子空间间的规范逆」**——列空间分量被解出、左零空间分量被丢弃、零空间方向取最小范数。`np.linalg.pinv` 的一行代码背后，是整个 SVD 理论。

## 6 小结

- **构造**：$A^+ = V\Sigma^+U^T$，非零奇异值取倒数、转置、恢复方向。
- **四条公理**：$AA^+A = A$、$A^+AA^+ = A^+$、$AA^+$ 与 $A^+A$ 对称。
- **投影**：$AA^+$ = 列空间投影，$A^+A$ = 行空间投影。
- **解方程**：$x = A^+b$ 统一最小二乘（超定）与最小范数（欠定）。
- **性质**：$(A^+)^+ = A$、$(A^T)^+ = (A^+)^T$；可逆时 $A^+ = A^{-1}$。
