# 基变换与坐标变换

## 为什么从基变换开始

上一节我们知道了「选基 → 得坐标」。但同一个向量在不同基下有不同的坐标，不同向量在同一基下也可能混淆。当我们需要**从一组基换到另一组基**时，坐标怎么变？答案由一个矩阵——**过渡矩阵**——精确给出。<span class="marginnote">基变换是「相似矩阵」与「线性变换矩阵表示」的地基（第五篇与本节末）：相似矩阵 $P^{-1}AP$ 里的 $P$ 正是过渡矩阵。<strong>换基不改变线性变换本身，只改变它的矩阵表示</strong>——这是「基变换与坐标变换」与「相似」本质相同的两面。</span>

本节给出过渡矩阵的定义、坐标变换公式，并把相似矩阵的「换基」解释讲透。

## 1 过渡矩阵的定义

**核心概念**：设 $\mathbf{a}_1, \cdots, \mathbf{a}_n$ 与 $\mathbf{b}_1, \cdots, \mathbf{b}_n$ 是 $n$ 维线性空间 $V$ 的两组基。若

$$
(\mathbf{b}_1, \cdots, \mathbf{b}_n) = (\mathbf{a}_1, \cdots, \mathbf{a}_n) P
$$

即每个新基向量 $\mathbf{b}_j$ 由旧基线性表示，系数构成矩阵 $P$ 的第 $j$ 列：

$$
\mathbf{b}_j = p_{1j}\mathbf{a}_1 + p_{2j}\mathbf{a}_2 + \cdots + p_{nj}\mathbf{a}_n
$$

则称 $P$ 为**从基 $\{\mathbf{a}_i\}$ 到基 $\{\mathbf{b}_j\}$ 的过渡矩阵（transition matrix）**。

**重点**：$P$ 的第 $j$ 列 = 新基第 $j$ 个向量在旧基下的坐标。$P$ **必可逆**（两组基都能互相表示），且 $P^{-1}$ 是从 $\{\mathbf{b}_j\}$ 到 $\{\mathbf{a}_i\}$ 的过渡矩阵。

**辨析｜易错点：** 过渡矩阵的「列 vs 行」方向最容易混。**第 $j$ 列放 $\mathbf{b}_j$ 在旧基下的坐标**——是「列」不是「行」。检验方法：写出 $(\mathbf{b}_1,\cdots,\mathbf{b}_n) = (\mathbf{a}_1,\cdots,\mathbf{a}_n)P$ 后，$P$ 的第 $j$ 列必与 $\mathbf{b}_j$ 对应。

## 2 坐标变换公式

**定理（坐标变换）**：设 $\mathbf{x} \in V$ 在基 $\{\mathbf{a}_i\}$ 下的坐标为 $\mathbf{x}$，在基 $\{\mathbf{b}_j\}$ 下的坐标为 $\mathbf{x}'$，$P$ 是从 $\{\mathbf{a}_i\}$ 到 $\{\mathbf{b}_j\}$ 的过渡矩阵，则

$$
\mathbf{x} = P \mathbf{x}'
$$

**重点**：这个公式的方向要反复确认：**$\mathbf{x} = P\mathbf{x}'$**——新坐标左乘过渡矩阵得旧坐标；反过来 $\mathbf{x}' = P^{-1}\mathbf{x}$。记忆：**「从旧到新，乘 $P^{-1}$；从新到旧，乘 $P$」**（依 $P$ 的定义方向）。

**为什么**：$\mathbf{x} = (\mathbf{a}_1,\cdots,\mathbf{a}_n)\begin{pmatrix}x_1\\\vdots\\x_n\end{pmatrix} = (\mathbf{b}_1,\cdots,\mathbf{b}_n)\begin{pmatrix}x'_1\\\vdots\\x'_n\end{pmatrix}$。代入 $\mathbf{b}_j$ 的表示，比较系数即得 $\mathbf{x} = P\mathbf{x}'$。

## 3 公式解析：一个具体的基变换

设 $\mathbb{R}^2$ 的旧基是标准基 $\mathbf{a}_1 = (1,0)^T, \mathbf{a}_2 = (0,1)^T$，新基 $\mathbf{b}_1 = (1,1)^T, \mathbf{b}_2 = (1,-1)^T$。

- 过渡矩阵：$\mathbf{b}_1 = 1\cdot\mathbf{a}_1 + 1\cdot\mathbf{a}_2$，$\mathbf{b}_2 = 1\cdot\mathbf{a}_1 + (-1)\cdot\mathbf{a}_2$，故 $P = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}$（第 $j$ 列是 $\mathbf{b}_j$ 的标准坐标）。
- 取向量 $\mathbf{x} = (3, 1)^T$（标准坐标）。它在新基下的坐标 $\mathbf{x}' = P^{-1}\mathbf{x} = \frac12\begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}\begin{pmatrix} 3 \\ 1 \end{pmatrix} = \begin{pmatrix} 2 \\ 1 \end{pmatrix}$。
- 验证：$\mathbf{x} = 2\mathbf{b}_1 + 1\mathbf{b}_2 = 2(1,1) + (1,-1) = (3,1)$ ✓。

**拆成四步理解**：

- **第一步，方向判定**：要「新坐标」，用 $\mathbf{x}' = P^{-1}\mathbf{x}$（新坐标 = 旧坐标经 $P^{-1}$）。
- **第二步，算 $P^{-1}$**：$P = \begin{pmatrix}1&1\\1&-1\end{pmatrix}$，$\det P = -2$，$P^{-1} = \frac12\begin{pmatrix}1&1\\1&-1\end{pmatrix}$。
- **第三步，乘开**：$\mathbf{x}' = \frac12(3+1, 3-1)^T = (2, 1)^T$。
- **第四步，回代验证**：用定义式 $\mathbf{x} = P\mathbf{x}'$ 复核。

<span class="marginnote">注意这个例子中 $P$ 恰好正交（列正交且长度 $\sqrt2$），所以 $P^{-1} = P^T/2$。<strong>正交基之间的过渡矩阵是正交矩阵的倍数</strong>；一般基的过渡矩阵只要求可逆。量子力学里的「表象变换」正是基变换：同一个态在不同表象下的「坐标」用过渡矩阵（酉矩阵）互转。</span>

## 4 基变换与相似矩阵

现在把基变换与第五篇的相似矩阵对接。设线性变换（下节正式定义）$T$ 在基 $\{\mathbf{a}_i\}$ 下的矩阵是 $A$，在基 $\{\mathbf{b}_j\}$ 下的矩阵是 $B$，$P$ 是过渡矩阵，则

$$
B = P^{-1} A P
$$

**重点**：**$A$ 与 $B$ 相似，过渡矩阵 $P$ 就是相似变换矩阵**。相似矩阵的「换基」含义至此完整：同一线性变换，换一组基，矩阵表示变为 $P^{-1}AP$。这就是为什么相似矩阵有相同的特征值、迹、行列式——它们描述的是同一变换，只是坐标不同。

**辨析｜易错点：** $P$ 的方向（从哪到哪）决定公式里 $P^{-1}$ 的位置。若 $P$ 是「从 $\{\mathbf{a}_i\}$ 到 $\{\mathbf{b}_j\}$」，则 $B = P^{-1}AP$。方向写反会得到 $PAP^{-1}$——这是常见错误。**记忆：矩阵表示公式与坐标变换公式方向一致（都乘 $P^{-1}$ 从旧到新）**。

## 5 基变换的实际应用

- **对角化的实现**：$P^{-1}AP = \Lambda$ 就是「把线性变换换到特征向量基下」。特征基下的矩阵最简（对角），这就是特征分解的「换基」视角（第五篇）。
- **简化计算**：选合适的基（如 Fourier 基）能让算子矩阵变稀疏或对角——傅里叶变换本质就是把求导算子对角化（$d/dx$ 在指数基下是对角矩阵）。
- **机器学习特征空间**：PCA 就是在「换基」——把数据从标准基换到协方差矩阵特征向量基下，新基下数据的协方差矩阵对角化（第十一篇）。

**重点**：**换基不改变变换的性质，只改变表示的清晰度**。选对基，复杂的矩阵变成对角阵；选错基，简单的变换变得一塌糊涂。「找最简基」正是对角化、Jordan 标准形、SVD 的共同追求。

**补充｜量子力学里的「表象变换」**：基变换在量子力学中叫**表象变换（change of representation）**——同一个量子态在位置表象下的波函数 $\psi(x)$ 与在动量表象下的波函数 $\tilde{\psi}(p)$ 之间，用傅里叶变换（一个「无穷维基变换」）互转。**「态」是不依赖基的抽象对象，「波函数」是它在特定基下的坐标**——这正是本节「向量 vs 坐标」区分的物理回响。理解基变换，就理解了量子力学的表象语言（第二级《量子力学》）。

**辨析｜易错点：** 求过渡矩阵的标准步骤：

- 把新基每个向量写成旧基的线性组合，系数**按列**排成 $P$；
- 坐标变换：旧坐标 = $P \times$ 新坐标，新坐标 = $P^{-1} \times$ 旧坐标；
- 验证：$P$ 必须可逆，且 $P$ 的第 $j$ 列是「$\mathbf{b}_j$ 在旧基下的坐标」。

**「列放新基坐标、旧坐标乘 $P$」**是过渡矩阵的两条铁律。

**补充｜过渡矩阵的方向记忆法**：

- 定义方向：$(\mathbf{b}_1, \cdots, \mathbf{b}_n) = (\mathbf{a}_1, \cdots, \mathbf{a}_n)P$——$P$ 是「从 $\mathbf{a}$ 基到 $\mathbf{b}$ 基」；
- 坐标方向：$\mathbf{x} = P\mathbf{x}'$（$\mathbf{x}$ 是 $\mathbf{a}$ 基坐标，$\mathbf{x}'$ 是 $\mathbf{b}$ 基坐标）——**「从 $\mathbf{a}$ 到 $\mathbf{b}$，坐标乘 $P$」**；
- 相似方向：$B = P^{-1}AP$（$A$ 是 $\mathbf{a}$ 基的矩阵，$B$ 是 $\mathbf{b}$ 基的矩阵）。

**「三处方向一致：都从 $\mathbf{a}$ 出发乘 $P$」**——记住这一条，三个公式都不容易写反。

## 6 小结

- **过渡矩阵**：$(\mathbf{b}_1,\cdots,\mathbf{b}_n) = (\mathbf{a}_1,\cdots,\mathbf{a}_n)P$，第 $j$ 列是 $\mathbf{b}_j$ 的旧坐标；$P$ 可逆。
- **坐标变换**：$\mathbf{x} = P\mathbf{x}'$（新到旧乘 $P$），$\mathbf{x}' = P^{-1}\mathbf{x}$（旧到新乘 $P^{-1}$）。
- **相似对接**：同一变换换基，$B = P^{-1}AP$，$P$ 即过渡矩阵。
- **应用**：对角化 = 换到特征基；傅里叶 = 换到对角化基。
- **方向口诀**：定义方向 = 新基在旧基下的坐标；公式方向与之一致。

在下一节，我们将正式研究「线性空间内部的子结构」——**线性子空间**，它是零空间、列空间等一切「空间中的空间」的统一语言。
