## 为什么从向量空间开始

前面我们一直在具体的 $\mathbb{R}^n$ 里讨论向量。这一节做一次「去具体化」：把「满足同样运算律的一切对象」抽象成**向量空间**。这是线性代数从「计算方法」走向「结构理论」的转折点——也是通向第六篇《线性空间与线性变换》的桥梁。<span class="marginnote">抽象化的回报是巨大的：一旦证明某组对象构成向量空间，所有线性代数结论（基、维数、秩、线性变换）都自动适用。函数可以构成向量空间，矩阵可以构成向量空间，多项式也可以——<strong>「向量」不是「一列数」，而是「满足八条运算律的任何对象」</strong>。这个思想是量子力学的态空间、信号处理的函数空间的数学根基。</span>

本节在 $\mathbb{R}^n$ 的框架下定义向量空间（第六篇再推广到一般线性空间），建立**基**与**维数**两个终极概念。

## 1 向量空间的定义

**核心概念**：设 $V$ 是非空集合，其元素称为**向量**，定义了加法与数乘两种运算。若对任意 $\mathbf{x}, \mathbf{y}, \mathbf{z} \in V$ 及任意数 $\lambda, \mu$，下列八条运算律全部成立，则称 $V$ 为**向量空间（vector space）**：

1. $\mathbf{x} + \mathbf{y} = \mathbf{y} + \mathbf{x}$（加法交换律）；
2. $(\mathbf{x} + \mathbf{y}) + \mathbf{z} = \mathbf{x} + (\mathbf{y} + \mathbf{z})$（加法结合律）；
3. 存在零向量 $\mathbf{0}$，使 $\mathbf{x} + \mathbf{0} = \mathbf{x}$；
4. 对每个 $\mathbf{x}$ 存在负向量 $-\mathbf{x}$，使 $\mathbf{x} + (-\mathbf{x}) = \mathbf{0}$；
5. $\lambda(\mu\mathbf{x}) = (\lambda\mu)\mathbf{x}$；
6. $(\lambda + \mu)\mathbf{x} = \lambda\mathbf{x} + \mu\mathbf{x}$（数乘分配律 I）；
7. $\lambda(\mathbf{x} + \mathbf{y}) = \lambda\mathbf{x} + \lambda\mathbf{y}$（数乘分配律 II）；
8. $1 \cdot \mathbf{x} = \mathbf{x}$（单位元）。

**重点**：$\mathbb{R}^n$ 是向量空间；全体 $m \times n$ 实矩阵也构成向量空间（第二篇曾提及）；次数不超过 $k$ 的多项式构成向量空间。**只要八条律成立，就是向量空间**，无论元素是数、数组还是函数。

**辨析｜易错点：** 八条律不是空话——数乘分配律 II（$\lambda(\mathbf{x}+\mathbf{y}) = \lambda\mathbf{x} + \lambda\mathbf{y}$）依赖加法与数乘的配合，是「线性」的精髓。若集合不带零元或负元，则不是向量空间。例如「第一分量为 1 的向量」全体不构成向量空间（没有零元，数乘也不封闭）。

## 2 基的定义

**核心概念**：设 $V$ 是向量空间，若 $V$ 中存在一组向量 $\mathbf{a}_1, \cdots, \mathbf{a}_n$ 满足：

- **线性无关**；
- **能表示（张成）$V$**：$V$ 中每个向量都能由它们线性表示；

则称这组向量为 $V$ 的一组**基（basis）**。

**重点**：基 = 极大线性无关组 + 张成整个空间。基的两个条件缺一不可：线性无关保证「不冗余」（表示唯一），张成保证「足够用」（覆盖全部）。上一节的极大线性无关组正是「向量组张成空间的基」。

例：$\mathbb{R}^2$ 的标准基 $\{\mathbf{e}_1, \mathbf{e}_2\}$（即 $(1,0), (0,1)$）线性无关且张成 $\mathbb{R}^2$。但 $\{(1,1), (1,-1)\}$ 也是基——**基不唯一**。

## 3 维数的定义

**核心概念**：向量空间 $V$ 的任意一组基所含向量个数（都相同）称为 $V$ 的**维数（dimension）**，记作 $\dim V$。

- $\dim \mathbb{R}^n = n$；
- 零空间 $\{0\}$ 的维数是 0；
- $\mathbb{R}^{m \times n}$（全体 $m\times n$ 矩阵）的维数是 $mn$；
- 次数 $\le k$ 的多项式空间的维数是 $k+1$（基可取 $1, x, x^2, \cdots, x^k$）。

**定理（维数的交换性质）**：若 $V$ 的维数是 $n$，则：

- $V$ 中任意 $n$ 个**线性无关**的向量必构成基（无关 + 个数够 = 张成）；
- $V$ 中任意 $n$ 个**能张成** $V$ 的向量必线性无关（张成 + 个数够 = 无关）。

<span class="marginnote">这条性质让「验证基」变得便宜：在 $n$ 维空间里，验证 $n$ 个向量只需检查「无关」或「张成」其一即可（加上个数 = 维数）。这是线性代数里少见的「免费午餐」：条件比定义少一半。</span>

## 4 公式解析：向量的坐标

设 $\mathbf{a}_1, \cdots, \mathbf{a}_n$ 是 $V$ 的一组基，则 $V$ 中任意向量 $\mathbf{x}$ 有**唯一**表示：

$$
\mathbf{x} = x_1\mathbf{a}_1 + x_2\mathbf{a}_2 + \cdots + x_n\mathbf{a}_n
$$

数 $x_1, \cdots, x_n$ 称为 $\mathbf{x}$ 在基 $\{\mathbf{a}_i\}$ 下的**坐标（coordinates）**。拆成四步：

- **第一步，存在性**：基张成 $V$，所以 $\mathbf{x}$ 至少有一种表示。
- **第二步，唯一性**：基线性无关，若有两种表示相减得 $\sum (x_i - x'_i)\mathbf{a}_i = \mathbf{0}$，系数全零，表示唯一（上一节定理）。
- **第三步，坐标是有序数组**：$\mathbf{x}$ 对应唯一坐标 $(x_1, \cdots, x_n)^T$，于是「向量」与「坐标数组」建立一一对应——**选定基，抽象向量变回具体数组**。
- **第四步，几何含义**：基是空间的「参考架」，坐标是向量在这个参考架下的「地址」。换一个基，同一向量的坐标会变——这正是第六篇「基变换与坐标变换」的主题。

**辨析｜易错点：** 坐标依赖基的选择。同一个向量 $(1, 1)^T$ 在标准基下坐标是 $(1,1)$，在基 $\{(1,1),(1,-1)\}$ 下坐标变成 $(1, 0)$。**「向量」与「坐标」是两回事**：向量是几何/代数对象，坐标是「换了个参考系后的编号」。混淆二者是后续特征向量、PCA 等概念理解受阻的最常见原因。

## 5 维数守恒：张成空间与秩的汇合

现在把本节的「维数」与前面的「秩」接通：

- 向量组 $\mathbf{a}_1, \cdots, \mathbf{a}_n$ 张成的空间记作 $\operatorname{span}\{\mathbf{a}_1, \cdots, \mathbf{a}_n\}$，它是 $V$ 的**子空间**（第六篇正式定义）。
- $\dim \operatorname{span}\{\mathbf{a}_1, \cdots, \mathbf{a}_n\} = $ 向量组的秩。
- 矩阵 $A$ 的列空间维数 $= \operatorname{rank} A$。

**重点**：**维数、秩、极大线性无关组的大小，说的是同一个数**。三种语言（空间语言、向量组语言、矩阵语言）在「秩」这里完全统一。这一认识让下面几篇（解的结构、四个基本子空间）有了共同的词汇表。

**补充｜坐标变换与「同一向量」**：向量本身不因基而变，变的是坐标——把向量想成「一个点」，基是「坐标系」，坐标是「点在坐标系里的读数」。同一个点 $(1, 1)^T$ 在标准基下读作 $(1,1)$，在旋转后的基下读作别的数，但点没动。**「向量」与「坐标」的分野是线性代数最重要的一次观念升级**——它直接通往量子力学（同一态在不同表象下的波函数）、相对论（同一事件在不同惯性系的坐标）以及下一节的基变换。

**补充｜坐标变换与「同一向量」**：向量本身不因基而变，变的是坐标——把向量想成「一个点」，基是「坐标系」，坐标是「点在坐标系里的读数」。同一个点 $(1, 1)^T$ 在标准基下读作 $(1,1)$，在旋转后的基下读作别的数，但点没动。**「向量」与「坐标」的分野是线性代数最重要的一次观念升级**——它直接通往量子力学（同一态在不同表象下的波函数）、相对论（同一事件在不同惯性系的坐标）以及下一节的基变换。

**辨析｜易错点：** 判断「一组向量是不是基」的三步检查法：

- 先数个数：是否等于 $\dim V$（个数不够必不是基）；
- 再查无关：$\det$（方阵时）或消元查秩；
- 最后看张成：个数够 + 无关 ⇒ 自动张成（维数完备性）。

**「个数够 + 无关 = 基」是免费午餐**——不必验证张成，省一半功夫。

**补充｜维数与「自由度」**：维数 = 独立参数个数 = 自由度。一个三维空间里的点用 3 个坐标描述，一条直线上的点只需 1 个参数——**「维数」回答「需要几个数才能确定一个点」**。统计里的自由度、机械系统的自由度、机器学习的模型参数个数，全是「维数」这个观念的分身。理解维数，就理解了「空间有多大」的精确含义。

**补充｜一句口诀收尾**：**「基 = 无关 + 张成；维数 = 基的个数；坐标 = 基下的唯一表示」**。三个概念环环相扣，是有限维线性空间的完整骨架。

## 6 小结

- **向量空间**：满足八条运算律的集合；「向量」泛指任何满足律的对象。
- **基**：线性无关 + 张成；基不唯一。
- **维数**：基的个数，唯一确定；$\dim \mathbb{R}^n = n$。
- **坐标**：向量在基下的唯一表示；坐标依赖基的选择。
- **统一**：$\dim \operatorname{span} = $ 秩 = 极大无关组大小。

在下一节，我们将用基与维数重写线性方程组的解——**齐次线性方程组解的结构与基础解系**，把「自由变量」翻译成「解空间的基」。
