# 线性变换的矩阵表示

<div class="epigraph">
<p>选定基，任何线性变换都变成一个矩阵；换一组基，矩阵就相似地变化。线性代数的一切，就在这张「变换 ↔ 矩阵」的对照表里。</p>

## 为什么从矩阵表示开始

上一节的线性变换很抽象：$T$ 是一个「保结构的映射」，但没有数字。这一节给出它的**数字面孔**：选定基，$T$ 就变成一个矩阵；作用 $T$ 就是做矩阵乘法。<span class="marginnote">这个「表示定理」是线性代数「抽象与具体」的终极桥梁：<strong>抽象变换可被有限个数完全描述</strong>。求导、积分、傅里叶变换这些「算子」在选定基后都变成矩阵，全部线性代数工具（特征值、分解）随即可用。这就是为什么「函数空间上的微分方程」能变成「矩阵方程」来解。</span>

本节证明「矩阵 ↔ 线性变换」的双向对应，并处理换基时矩阵如何变化。

## 1 线性变换的矩阵

**定理（矩阵表示定理）**：设 $T: V \to W$ 是线性变换，$V$ 有基 $\mathbf{a}_1, \cdots, \mathbf{a}_n$，$W$ 有基 $\mathbf{b}_1, \cdots, \mathbf{b}_m$。则存在唯一的 $m \times n$ 矩阵 $A$，使得对任意 $\mathbf{x} \in V$：

$$
T(\mathbf{x}) \text{ 的坐标} = A \cdot (\mathbf{x} \text{ 的坐标})
$$

$A$ 的第 $j$ 列是 $T(\mathbf{a}_j)$ 在 $\mathbf{b}$ 基下的坐标。$A$ 称为 $T$ 在给定基下的**矩阵（matrix representation）**。

**重点**：**$A$ 的第 $j$ 列 = 第 $j$ 个基向量的像的坐标**。这是构造矩阵的唯一规则——把 $n$ 个基向量分别作用，记录像的坐标，排成 $n$ 列。

## 2 公式解析：$T(\mathbf{x})$ 的矩阵公式

设 $T: V \to W$，基 $\{\mathbf{a}_i\}$、$\{\mathbf{b}_j\}$，$A$ 是 $T$ 的矩阵。对 $\mathbf{x} = \sum x_i \mathbf{a}_i$：

$$
T(\mathbf{x}) = T\left(\sum_i x_i \mathbf{a}_i\right) = \sum_i x_i T(\mathbf{a}_i)
$$

拆成四步：

- **第一步，线性性穿过和号**：$T(\sum x_i\mathbf{a}_i) = \sum x_i T(\mathbf{a}_i)$——线性变换把「$\mathbf{x}$ 在基下的线性组合」搬运到「$T(\mathbf{a}_i)$ 的组合」。
- **第二步，用矩阵列展开**：$T(\mathbf{a}_i)$ 在 $\mathbf{b}$ 基下的坐标是 $A$ 的第 $i$ 列 $\mathbf{c}_i$。于是 $T(\mathbf{x})$ 的坐标 $= \sum x_i \mathbf{c}_i$。
- **第三步，拼成矩阵乘法**：$\sum x_i \mathbf{c}_i = A\mathbf{x}$——这正是「矩阵乘向量 = 列的线性组合」（第二篇）。
- **第四步，结论**：**在线性空间里，线性变换的计算就是矩阵乘法**。基的作用是「坐标化」，$A$ 的作用是「在坐标空间里实现 $T$」。

<span class="marginnote">这个定理的普适性惊人：<strong>求导算子 $\frac{d}{dx}$ 在多项式基 $\{1, x, x^2\}$ 下就是一个 $3\times3$ 矩阵</strong>，特征向量是 $e^{\lambda x}$ 的离散类比。数值分析里微分方程离散化成矩阵方程，正是这一定理的反向应用。</span>

## 3 一个完整的例子

设 $T: \mathbb{P}_2 \to \mathbb{P}_2$ 是求导 $T(p) = p'$，基取 $\{1, x, x^2\}$（都用标准基）。

- $T(1) = 0 = 0\cdot1 + 0\cdot x + 0\cdot x^2$，坐标 $(0,0,0)^T$；
- $T(x) = 1$，坐标 $(1,0,0)^T$；
- $T(x^2) = 2x$，坐标 $(0,2,0)^T$。

矩阵（列排）：

$$
A = \begin{pmatrix} 0 & 1 & 0 \\ 0 & 0 & 2 \\ 0 & 0 & 0 \end{pmatrix}
$$

验证：$p = 1 + 2x - x^2$ 的坐标 $(1,2,-1)^T$，$A\mathbf{x} = (2, -2, 0)^T$ 对应 $2 - 2x = p'$ ✓。

**辨析｜易错点：** 矩阵的第 $j$ 列对应第 $j$ 个**基向量**的像，顺序必须与基的排列一致。换基顺序 = 换列顺序。**先定基的顺序，再写矩阵**——这是所有「表示」类问题的基础纪律。

## 4 换基时矩阵如何变：相似变换

设 $T: V \to V$ 在同一空间上（$V = W$），用基 $\{\mathbf{a}_i\}$ 的矩阵是 $A$，用基 $\{\mathbf{b}_j\}$ 的矩阵是 $B$，$P$ 是从 $\{\mathbf{a}_i\}$ 到 $\{\mathbf{b}_j\}$ 的过渡矩阵，则

$$
B = P^{-1} A P
$$

**重点**：**同一个线性变换，换基后矩阵相似**。这就是第五篇相似矩阵的完整出处：$A$ 与 $B$ 描述同一变换，只是坐标系不同。相似关系「保持特征值、迹、行列式」的原因正在于此——这些是变换的固有属性，不随坐标改变。

**辨析｜易错点：** 公式 $B = P^{-1}AP$ 中 $P$ 的方向：$P$ 是「从 $\{\mathbf{a}_i\}$ 到 $\{\mathbf{b}_j\}$ 的过渡矩阵」。方向写反（用 $PAP^{-1}$）是常见错误。**与坐标变换公式 $\mathbf{x} = P\mathbf{x}'$ 保持一致：从旧到新都用 $P^{-1}$**。

## 5 矩阵表示的统一应用

**例子：特征向量与特征值的变换意义**。$T(\mathbf{v}) = \lambda\mathbf{v}$（$\mathbf{v} \ne \mathbf{0}$）在矩阵语言里是 $A\mathbf{x} = \lambda\mathbf{x}$。特征向量就是「在 $T$ 作用下方向不变、只伸缩」的方向。若把基取成特征向量基，则 $A$ 变成对角矩阵——**特征基 = 让变换矩阵最简的基**。

**例子：线性变换的核与像**。$\ker T$ 对应 $A\mathbf{x} = \mathbf{0}$ 的解空间（零空间），$T(V)$ 对应列空间。秩-零化度定理变为 $\dim V = \dim\operatorname{Nul}(A) + \operatorname{rank} A$——正是第七篇的矩阵形式。

**重点**：**「求线性变换的不变量」=「求矩阵的相似不变量」**。特征值、迹、行列式、秩，全部在「换基」下不变——它们是变换本身的属性，不是坐标的产物。这个认识把第五篇与第六篇焊成一个整体。

**补充｜算子与微分方程的矩阵化**：矩阵表示定理最震撼的应用是把「算子」变成「矩阵」。求导算子 $d/dx$ 在多项式基下是上三角矩阵，二阶微分算子 $d^2/dx^2$ 对应三对角矩阵——于是**微分方程 $Lu = f$ 离散化后就是矩阵方程 $Ax = b$**（有限差分/有限元，第二级《数值分析》、第九级《偏微分方程》）。本专题的 LU、迭代法、条件数全部在这条线上发力。**「算子 → 矩阵 → 解方程」是现代科学计算的万能链路**。

**辨析｜易错点：** 矩阵表示依赖基的选择——同一线性变换在不同基下的矩阵一般不同（差一个相似变换 $P^{-1}AP$）。**问「某线性变换的矩阵」必须同时问「在什么基下」**。不过核与像的维数、特征值、秩等「不变量」不依赖基——它们才是变换的本质属性。做题时「先定基，再写矩阵；验证性质用不变量」。

**补充｜算子与微分方程的矩阵化**：矩阵表示定理最震撼的应用是把「算子」变成「矩阵」。求导算子 $d/dx$ 在多项式基下是上三角矩阵，二阶微分算子 $d^2/dx^2$ 对应三对角矩阵——于是**微分方程 $Lu = f$ 离散化后就是矩阵方程 $Ax = b$**（有限差分/有限元，第二级《数值分析》、第九级《偏微分方程》）。本专题的 LU、迭代法、条件数全部在这条线上发力。**「算子 → 矩阵 → 解方程」是现代科学计算的万能链路**。

**辨析｜易错点：** 矩阵表示依赖基的选择——同一线性变换在不同基下的矩阵一般不同（差一个相似变换 $P^{-1}AP$）。**问「某线性变换的矩阵」必须同时问「在什么基下」**。不过核与像的维数、特征值、秩等「不变量」不依赖基——它们才是变换的本质属性。做题时「先定基，再写矩阵；验证性质用不变量」。

**补充｜相似对角化就是「找好基」**：$P^{-1}AP = \Lambda$ 的含义是「在特征向量基下，线性变换的矩阵是对角阵」——特征基让变换「各方向解耦」。这统一了第五篇与第六篇：**对角化不是「矩阵的技巧」，而是「选基的艺术」**。SVD 更进一步：对任意矩阵选两组不同的正交基（$U$ 与 $V$），让变换成为对角拉伸。

**补充｜矩阵表示的构造三步**：

- 选定 $V$ 的基 $\{\mathbf{a}_i\}$ 与 $W$ 的基 $\{\mathbf{b}_j\}$；
- 对每个基向量 $\mathbf{a}_j$，算出 $T(\mathbf{a}_j)$，写出它在 $\{\mathbf{b}_j\}$ 下的坐标；
- 把这些坐标**按列**排成矩阵 $A$。

**「作用基向量、记录像的坐标、按列排」**是构造矩阵表示的唯一套路，也是求「线性变换矩阵」类题目的标准三步。

**补充｜一句话**：**「选定基，线性变换就是矩阵乘法」**——抽象算子被有限个数完全描述，这是线性代数「抽象与具体」的终极桥梁。

**补充｜学习地图**：矩阵表示打通了「抽象变换」与「具体矩阵」——从此线性代数的一切（特征值、分解、数值方法）都能作用于抽象空间上的算子。

## 6 小结

- **表示定理**：选定基，$T$ 的矩阵 $A$ 第 $j$ 列 = $T(\mathbf{a}_j)$ 的坐标；$T(\mathbf{x})$ 的坐标 $= A\mathbf{x}$。
- **构造**：作用每个基向量，记录像的坐标，排成列。
- **换基**：$B = P^{-1}AP$，同一变换在不同基下的矩阵相似。
- **特征基**：取特征向量作基，矩阵对角化。
- **统一**：线性变换 ↔ 矩阵一一对应，抽象问题全部坐标化。
