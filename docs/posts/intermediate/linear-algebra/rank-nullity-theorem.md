## 为什么从秩-零化度定理开始

我们有两个维数：$\dim \operatorname{Col}(A) = \operatorname{rank} A$ 与 $\dim \operatorname{Nul}(A)$。它们之间有一个极简单的守恒关系——**秩-零化度定理**。这条定理像是线性代数的「能量守恒定律」：列数被矩阵「分配」成两部分，一部分成为输出的自由维数（秩），另一部分被压成输入的冗余（零化度）。<span class="marginnote">秩-零化度定理是抽象维数公式 $\dim V = \dim \ker T + \dim T(V)$（第六篇）的矩阵形式。<strong>它是全课程最强的「免费检验工具」</strong>：算出任意两个量，第三个自动确定——用错了哪里，一核对就露馅。</span>

本节给出定理、证明直觉、以及三大应用。

## 1 定理陈述

**定理（秩-零化度定理，Rank-Nullity Theorem）**：设 $A$ 是 $m \times n$ 矩阵，则

$$
\operatorname{rank}(A) + \dim \operatorname{Nul}(A) = n
$$

即 **列空间维数 + 零空间维数 = 列数**。

**重点**：$n$ 是**列数**（输入维数），不是行数。零空间在 $\mathbb{R}^n$ 里，所以零化度 $\dim \operatorname{Nul}(A)$ 贡献「输入中被压扁的维数」；列空间在 $\mathbb{R}^m$ 里，$\operatorname{rank} A$ 贡献「输出里保留的维数」。两者加起来正好是输入的全部维数。

**立即推论**：$A$ 是 $n$ 阶方阵时，$A$ 可逆 $\Leftrightarrow \operatorname{rank} A = n \Leftrightarrow \dim\operatorname{Nul}(A) = 0 \Leftrightarrow$ 只有零解。

## 2 公式解析：为什么相加等于 $n$

定理的证明本质上是「数自由变量」，拆成四步：

- **第一步，消元计数**：$Ax = 0$ 的零空间维数 = 自由变量个数 $= n - \operatorname{rank} A$（第三篇、第四篇）。这是最关键的一步——零化度就是自由变量的个数。
- **第二步，秩是什么**：$\operatorname{rank} A$ = 主元个数 = 被约束（非自由）的变量个数。
- **第三步，变量被分成两类**：$n$ 个变量中，主元变量 $r$ 个、自由变量 $n - r$ 个，两不相交、合为全部：$r + (n-r) = n$。
- **第四步，翻译成空间语言**：$r = \operatorname{rank} A$，$n - r = \dim \operatorname{Nul}(A)$，故秩 + 零化度 = $n$。**定理不过是「每个变量要么是主元、要么自由」的维数记账**。

<span class="marginnote">自由变量 = 零空间基向量，主元变量 = 列空间的「骨架」。<strong>一个变量对应一个「自由度」</strong>：主元自由度反映到输出（列空间），自由自由度被压进核（零空间）。这个「记账」直觉在数据科学里就是「数据维数 = 信号维数 + 噪声维数」。</span>

## 3 三个推论与反直觉实例

**推论 1（长方形矩阵的必然性）**：若 $m < n$（行少列多），则 $\operatorname{rank} A \le m < n$，故 $\dim\operatorname{Nul}(A) = n - \operatorname{rank} A \ge 1$——**零空间必非零**，$Ax = 0$ 必有非零解。

**推论 2（方阵的满秩等价）**：$A$ 是 $n$ 阶方阵时，$\operatorname{rank} A = n \Leftrightarrow \operatorname{Nul}(A) = \{\mathbf{0}\}$，单射与满射合一。

**推论 3（可逆 = 信息全保留）**：可逆矩阵把每个输入都映到唯一输出，零空间为零，秩满——**不压扁任何方向**。

**反直觉实例**：$A = \begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}$，$n = 2$。列空间由 $(1,1)^T$ 张成，$\operatorname{rank} = 1$；零空间由 $(1,-1)^T$ 张成，$\dim = 1$。$1 + 1 = 2$ ✓。**矩阵把「沿 $(1,1)$ 方向」保留、把「沿 $(1,-1)$ 方向」压扁**——一个方向成为输出，一个方向沉入核。

## 4 应用一：验证计算的正确性

设你算出一个 $5 \times 7$ 矩阵的 $\operatorname{rank} = 3$，则**必有** $\dim \operatorname{Nul}(A) = 7 - 3 = 4$。若你解齐次方程得到的基础解系只有 3 个向量，立即知道算错了。

**重点**：**秩-零化度定理是线性代数手算的「安全检查」**。算出秩，零化度自动确定；反之亦然。凡是「维数对不上」的地方，一定在某一步出了错——这是考试与工程里最有效的自查手段。

## 5 应用二：从零空间判断方程组解的情况

对 $Ax = \mathbf{b}$：

- $\operatorname{rank} A = \operatorname{rank}(A\mid b)$ 时（相容），解为「特解 + 零空间」，**解的自由维数 = $n - \operatorname{rank} A$**；
- $\dim\operatorname{Nul}(A) = 0$ 时解唯一；$\dim\operatorname{Nul}(A) > 0$ 时无穷多解。

**重点**：零空间维数**直接告诉你通解里有多少个自由参数**（基础解系的个数）。这在数据科学的欠定问题里尤其关键：$m < n$ 时解必然不唯一，需借助伪逆取「最小范数解」（第十篇）。

**辨析｜易错点：** 秩-零化度定理对**非方阵**同样成立，但求和的对象是**列数** $n$。若误用「行数 + 零化度」就会出错。零空间在输入空间，所以恒等式里出现的是「输入维数 $n$」。

## 6 应用三：四个基本子空间的序章

秩-零化度定理已经预告了四个基本子空间的维数图景：

| 子空间 | 所在空间 | 维数 |
| --- | --- | --- |
| $\operatorname{Col}(A)$ | $\mathbb{R}^m$ | $r = \operatorname{rank} A$ |
| $\operatorname{Nul}(A)$ | $\mathbb{R}^n$ | $n - r$ |
| $\operatorname{Row}(A)$ | $\mathbb{R}^n$ | $r$ |
| $\operatorname{Nul}(A^T)$ | $\mathbb{R}^m$ | $m - r$ |

**重点**：四子空间成对出现，维数互补——下一节将把这张表填满，并说明它们在 $\mathbb{R}^n$ 与 $\mathbb{R}^m$ 中如何两两正交。

**补充｜秩-零化度定理的「信息论」解读**：把 $Ax = b$ 看成「编码」：$x$ 是 $n$ 维信息，$A$ 把它编码成 $m$ 维输出。秩 = 输出的「有效信息维数」（保留的分量），零化度 = 输入的「不可分辨维数」（多个 $x$ 映射到同一 $b$）。**秩-零化度 = 信息守恒：输入的维数要么变成输出，要么被压缩丢失**——这与香农信息论「无噪声编码定理」有精神上的亲缘（第二级《信息论》）。「丢了多少」与「剩了多少」永远互补。

**辨析｜易错点：** 定理对**任何形状**矩阵成立，但求和对象是「输入维数 $n$」——零空间在输入空间，所以补数来自列数。对 $m \times n$ 矩阵，$\dim\operatorname{Nul}(A) = n - \operatorname{rank}A$；对 $A^T$（$n \times m$），$\dim\operatorname{Nul}(A^T) = m - \operatorname{rank}A$。**两条合起来**就是四个基本子空间维数的完整账本（第七篇）。

**补充｜用秩-零化度定理「猜答案」**：做题时若算出了 $\operatorname{rank}$，零空间维数立即由 $n - \operatorname{rank}$ 给出——可以用来检验基础解系是否找全。若你解齐次方程只找到 $k$ 个独立解而 $k \ne n - \operatorname{rank}$，必然有一步错了。**「维数对不上 = 必有错」**是消元与解空间题目的最有效自查。

**补充｜秩-零化度定理的速记**：**「输入维数 = 幸存维数 + 压扁维数」**——$n = \operatorname{rank} + \operatorname{nullity}$。每次看到秩，立刻能算出零化度；每次看到零化度，立刻能算出秩。

## 7 小结

- **定理**：$\operatorname{rank} A + \dim\operatorname{Nul}(A) = n$（列数）。
- **证明直觉**：变量分成主元与自由两类，记账即可。
- **推论**：$m < n$ 时齐次方程必有非零解；方阵满秩 ⇔ 零空间为零。
- **检验**：秩与零化度互相核对，是手算的免费安全检查。
- **解结构**：通解自由参数个数 = 零空间维数。
