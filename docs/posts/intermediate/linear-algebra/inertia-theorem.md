# 惯性定理与规范形

<div class="epigraph">

## 为什么从惯性定理开始

上两节给了两种化标准形的方法，系数各不相同。这引出一个深刻问题：**有哪些量是「无论怎么化都不变」的？** 惯性定理给出答案：正平方项个数 $p$ 与负平方项个数 $q$（合称**惯性指数**）在一切可逆线性变换下不变。<span class="marginnote">惯性定理的名字来自力学的直觉：<strong>物体运动的「正方向数」与「负方向数」不随坐标系选取而变</strong>，就像质量、动量是物体的固有属性。在数学上，它说明二次型只能被可逆线性变换分成有限个「类型」——$(p, q)$ 就是它的身份证。相对论里的时空度规 $(+---)$ 的惯性指数 $(1,3)$ 正是这种分类的现实例子。</span>

本节建立规范形（把标准形系数归一为 $+1, -1, 0$），并给出二次型的终极分类。

## 1 惯性指数与规范形

**核心概念**：设二次型 $f = \mathbf{x}^TA\mathbf{x}$，经任一可逆线性变换化成的标准形中，**正平方项个数**记作 $p$，**负平方项个数**记作 $q$，则 $(p, q)$ 称为 $f$ 的**惯性指数**。若进一步把每个平方项系数归一成 $1, -1$（非零项）或 $0$（消失项），所得

$$
f = y_1^2 + \cdots + y_p^2 - y_{p+1}^2 - \cdots - y_{p+q}^2
$$

称为二次型的**规范形（normal form）**。

**重点**：$p + q = \operatorname{rank} A$（非零平方项总数 = 秩），$p - q$ 称为**符号差（signature）**。规范形是「最简的标准形」——系数只剩符号，不再有数值。

例：$f = y_1^2 + y_2^2 - 3y_3^2$ 的惯性指数是 $(2, 1)$，规范形为 $z_1^2 + z_2^2 - z_3^2$（$z_3 = \sqrt3\, y_3$）。

## 2 惯性定理

**定理（惯性定理 / Sylvester 惯性定律）**：任一二次型经**任何可逆线性变换**化为标准形，其中**正平方项的个数 $p$ 与负平方项的个数 $q$ 不变**（从而规范形唯一）。

**重点**：配方法得到的系数（$1, 1, -3$）与正交变换得到的特征值（可能不同数值）——但**正负个数永远一致**。惯性定理保证：二次型的「类型」是内在属性，与「怎么化」无关。

**辨析｜易错点：** 惯性指数不变，指的是**可逆线性变换**下。若允许不可逆变换，正负个数可以改变（比如把 $y_1^2$ 通过不可逆代换消掉）。所以惯性定理的适用范围是「可逆（非退化）变换」——正交变换、配方法对应的变换都在这类内。

## 3 公式解析：为什么正负个数不变

惯性定理的证明思路（合同变换 + 秩的论证）：

- **第一步，合同变换视角**：可逆变换 $\mathbf{x} = P\mathbf{y}$ 下，矩阵变为 $B = P^TAP$。问题变成：**合同变换 $A \to P^TAP$ 保持什么？**（$P$ 可逆）
- **第二步，观察秩**：$P$ 可逆，所以 $\operatorname{rank}(P^TAP) = \operatorname{rank} A$——合同变换保持秩，故 $p + q$ 不变。
- **第三步，矛盾论证 $p$ 不变**：假设用两种变换分别得到正项数 $p_1 < p_2$。考虑一种变换下的零空间与另一种的正平方空间——利用维数论证可构造一个非零向量 $\mathbf{z}$，它在第一种表示中只落在非正方向（$f(\mathbf{z}) \le 0$），在第二种表示中又只落在正方向（$f(\mathbf{z}) > 0$），矛盾。
- **第四步，结论**：$p$ 由二次型唯一决定，$q$ 亦然。**「正方向的个数」是二次型的固有几何属性**，如同曲面在坐标旋转下「凸的方向数」不变。

<span class="marginnote">这个证明的难度在于第 3 步的「构造矛盾向量」——它需要同时用两套坐标。直观版本：<strong>一个二次曲面能容纳多少个「正曲率方向」与多少个「负曲率方向」，不因坐标系旋转而变</strong>。这与「曲面形状是几何的、坐标是人为的」哲学一致。</span>

## 4 用惯性指数给二次型分类

二次型按惯性指数可分为五大类，这是全书的分类表：

| 类型 | 条件（惯性指数） | 几何图形（$f = c$） | 判定（特征值） |
| --- | --- | --- | --- |
| 正定 | $q = 0, p = n$ | 椭球 | 全部 $\lambda_i > 0$ |
| 负定 | $p = 0, q = n$ | 虚椭球 | 全部 $\lambda_i < 0$ |
| 半正定 | $q = 0, p < n$ | 退化椭球/柱面 | $\lambda_i \ge 0$ 且含 0 |
| 半负定 | $p = 0, q < n$ | 退化 | $\lambda_i \le 0$ 且含 0 |
| 不定 | $p > 0$ 且 $q > 0$ | 双曲面 | 有正有负 |

**重点**：分类只看**符号**，不看数值。这张表把「二次型的类型」与「特征值符号」「惯性指数」三者完全打通——它们是同一信息的三副面孔。正定与半正定在优化、统计里最重要（下节正定矩阵专门展开）。

**辨析｜易错点：** 判定类型时，**只需要算特征值的符号**（或惯性指数），不必求具体数值。对三阶以上矩阵，特征多项式解不出显式根时，用配方法数正负平方项个数即可——这正是配方法的实用价值。另外，「半正定」要求「全部 $\ge 0$ 且**存在**为 0」，不能只凭「$\det A \ge 0$」判定。

## 5 符号差与不变量汇总

二次型在可逆线性变换下有一组不变量：

- **惯性指数** $(p, q)$：正、负平方项个数；
- **符号差** $p - q$；
- **秩** $p + q = \operatorname{rank} A$；
- **行列式的符号**：$\det A$ 的符号由 $(-1)^q$ 给出（规范形的行列式）。

在**正交变换**（更强的限制）下，还额外保持：特征值本身、迹、行列式的值。

**重点**：惯性与符号差是「合同不变量」，特征值是「正交不变量」——正交变换是合同变换的特例，所以特征值信息比惯性指数更细。SVD 理论里，正奇异值的个数正是 $\operatorname{rank}$，与惯性指数的 $p+q$ 对应（第十篇）。

**补充｜惯性定理与「合同变换」的关系**：惯性定理的精确表述是「**合同变换**（$A \to P^TAP$，$P$ 可逆）保持惯性指数」。合同变换比相似变换更宽（$P$ 不必正交），所以惯性指数比特征值「粗糙」——特征值保持不变的是相似变换（$P^{-1}AP$），惯性指数保持不变的是合同变换。**两个概念容易混**：二次型换元用合同变换（惯性与符号差不变），线性变换换基用相似变换（特征值不变）。「谁不变」取决于「用哪种变换」——这是本专题最容易踩的辨析点之一。

**公式解析（规范形的意义）**：规范形 $f = y_1^2 + \cdots + y_p^2 - y_{p+1}^2 - \cdots - y_{p+q}^2$ 里每个系数只有 $\pm 1$，所以「类型」完全由 $(p, q)$ 决定。相对论的时空度规 $ds^2 = c^2dt^2 - dx^2 - dy^2 - dz^2$ 的惯性指数是 $(1, 3)$——**物理学的时空结构也服从惯性定理的分类**。规范形是二次型的「极简身份证」：剥掉一切数值，只剩符号骨架。

**补充｜惯性定理与「合同变换」的关系**：惯性定理的精确表述是「**合同变换**（$A \to P^TAP$，$P$ 可逆）保持惯性指数」。合同变换比相似变换更宽（$P$ 不必正交），所以惯性指数比特征值「粗糙」——特征值保持不变的是相似变换（$P^{-1}AP$），惯性指数保持不变的是合同变换。**两个概念容易混**：二次型换元用合同变换（惯性与符号差不变），线性变换换基用相似变换（特征值不变）。「谁不变」取决于「用哪种变换」——这是本专题最容易踩的辨析点之一。

**公式解析（规范形的意义）**：规范形 $f = y_1^2 + \cdots + y_p^2 - y_{p+1}^2 - \cdots - y_{p+q}^2$ 里每个系数只有 $\pm 1$，所以「类型」完全由 $(p, q)$ 决定。相对论的时空度规 $ds^2 = c^2dt^2 - dx^2 - dy^2 - dz^2$ 的惯性指数是 $(1, 3)$——**物理学的时空结构也服从惯性定理的分类**。规范形是二次型的「极简身份证」：剥掉一切数值，只剩符号骨架。

**辨析｜易错点：** 求惯性指数的常见错误是把「配方法的系数」直接当特征值来判定正负——其实配方系数与特征值数值不同，**但正负个数相同**（惯性定理保证）。所以判定类型时，可以放心用配方法数「有几个正平方项、几个负平方项」，不必解特征方程。**「数正负」永远比「算数值」便宜**，这正是惯性定理的实用价值。

## 6 例子：用配方法求惯性指数

求 $f = x_1^2 + 2x_2^2 + 3x_3^2 + 4x_1x_2 + 6x_1x_3$ 的惯性指数。

- 配方（关于 $x_1$）：$x_1^2 + 4x_1x_2 + 6x_1x_3 = (x_1 + 2x_2 + 3x_3)^2 - 4x_2^2 - 9x_3^2 - 12x_2x_3$；
- 代入：$f = (x_1 + 2x_2 + 3x_3)^2 - 2x_2^2 - 6x_3^2 - 12x_2x_3$；
- 再配方（关于 $x_2$）：$-2x_2^2 - 12x_2x_3 = -2(x_2 + 3x_3)^2 + 18x_3^2$；
- 得：$f = (x_1+2x_2+3x_3)^2 - 2(x_2+3x_3)^2 + 12x_3^2$。

**惯性指数**：$p = 2$（正平方项 2 个），$q = 1$（负平方项 1 个），秩 $= 3$，符号差 $= 1$。

**辨析｜易错点：** 配方法的结果**不唯一**（配方顺序不同，中间系数不同），但**惯性指数唯一**（惯性定理）。本例用不同配方可能得到不同的「配方系数」，但 $p = 2, q = 1$ 不变。**「系数可变、指数不变」**正是惯性定理的价值——它是验证配方法是否配错的标准。

**补充｜一句话**：**「惯性指数 $(p, q)$ 是二次型的身份，规范形是它的极简证件照」**——$(p, q)$ 在一切可逆变换下不变，这就是惯性定理。

**补充｜惯性指数的学习地图**：惯性定理是「配方法」（下节）与「正定判据」的理论支点——配方系数的正负个数之所以可靠，正是因为惯性指数不随配方方式改变。

## 7 小结

- **惯性指数**：正平方项个数 $p$、负平方项个数 $q$，在可逆变换下不变。
- **规范形**：$\sum_{1}^{p} y_i^2 - \sum_{p+1}^{p+q} y_i^2$，系数归一为 $\pm 1, 0$，唯一。
- **惯性定理**：$p, q$ 是二次型的固有属性，与化法无关。
- **分类表**：正定/负定/半正定/半负定/不定，由惯性指数或特征值符号决定。
- **不变量**：$(p,q)$、$p-q$、$\operatorname{rank}$ 合同不变；特征值正交不变。
