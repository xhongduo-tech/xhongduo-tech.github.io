# 截断 SVD 与最佳低秩近似

<div class="epigraph">

## 为什么从截断 SVD 开始

SVD 把矩阵写成 $\sum \sigma_i \mathbf{u}_i\mathbf{v}_i^T$ 的 $r$ 层叠加。现实中，后面那些层的奇异值往往**极小**——它们代表噪声与冗余。**截断 SVD** 只保留前 $k$ 个最大奇异值对应的层，得到矩阵的最佳 $k$ 秩近似。这是**矩阵压缩、PCA、图像去噪、推荐系统隐语义**的统一数学。<span class="marginnote">截断 SVD 的直觉：<strong>大奇异值 = 结构，小奇异值 = 噪声</strong>。保留前 $k$ 层，用 $k(m + n)$ 个数近似 $mn$ 个元素——压缩率可以极高。谷歌把 PageRank 矩阵、Netflix 把评分矩阵都用低秩模型近似（第十一篇）。</span>

本节给出截断 SVD 的定义、最优性定理（Eckart-Young）与误差公式。

## 1 截断 SVD 的定义

**核心概念**：设 $A$ 的 SVD 为 $A = \sum_{i=1}^r \sigma_i\mathbf{u}_i\mathbf{v}_i^T$。**截断 SVD（truncated SVD）**保留前 $k$ 项（$k < r$）：

$$
A_k = \sum_{i=1}^{k} \sigma_i \mathbf{u}_i \mathbf{v}_i^T = U_k \Sigma_k V_k^T
$$

其中 $U_k$ 取 $U$ 的前 $k$ 列，$\Sigma_k = \operatorname{diag}(\sigma_1, \cdots, \sigma_k)$，$V_k$ 取 $V$ 的前 $k$ 列。

**重点**：$A_k$ 的秩 ≤ $k$，是「用 $k$ 个主要方向近似 $A$」。$A_k$ 需要存储 $k$ 个左奇异向量、$k$ 个右奇异向量、$k$ 个奇异值，共 $k(m + n + 1)$ 个数——远小于 $mn$。

**辨析｜易错点：** 截断 SVD 不是「截断 $\Sigma$ 再把零奇异值去掉」那么简单——它同时截断 $U, V$ 的列。$A_k$ 是「只保留前 $k$ 个秩一层」的近似，不是「把 $A$ 的某个子矩阵保留」。

## 2 Eckart-Young 定理：最佳低秩近似

**定理（Eckart-Young）**：在所有秩 ≤ $k$ 的 $m \times n$ 矩阵 $B$ 中，截断 SVD $A_k$ 是 $A$ 的**最佳近似**，即在 Frobenius 范数与 2-范数下：

$$
\|A - A_k\|_F \le \|A - B\|_F, \qquad \|A - A_k\|_2 \le \|A - B\|_2
$$

对所有 $\operatorname{rank} B \le k$ 成立。

**重点**：**$A_k$ 是「用秩 $k$ 矩阵逼近 $A$」的最优解**。误差公式：

$$
\|A - A_k\|_2 = \sigma_{k+1}, \qquad
\|A - A_k\|_F = \sqrt{\sigma_{k+1}^2 + \cdots + \sigma_r^2}
$$

2-范数误差 = **被丢弃的最大奇异值**；Frobenius 误差 = **被丢弃奇异值的平方和开方**。

<span class="marginnote">Eckart-Young 是「为什么奇异值能排序、能截断」的理论根基：<strong>奇异值递减保证了「丢弃的代价」最小</strong>。如果把奇异值打乱顺序再截断，误差一定更大。这解释了为什么 SVD 排序（奇异值递减）是压缩的前提。</span>

## 3 公式解析：为什么 $A_k$ 是最优

最优性的直觉拆成四步：

- **第一步，$A$ 对单位球的作用**：$A$ 把单位球映成半轴 $\sigma_i$ 的超椭球。秩 $k$ 矩阵最多保留 $k$ 个非零方向——它把椭球「压扁」成 $k$ 维。
- **第二步，丢哪 $r - k$ 个方向最优**：丢掉最短的半轴（$\sigma_{k+1}, \cdots, \sigma_r$），损失的「体积感」最小。若丢掉更长的半轴，损失更大。
- **第三步，$A_k$ 正是「丢最短轴」**：保留最长 $k$ 个奇异值方向，其余置零——几何上就是「椭球投影到前 $k$ 个主轴上」。
- **第四步，误差度量**：2-范数误差 = 被丢半轴中最长的那根（$\sigma_{k+1}$）；Frobenius 误差 = 被丢半轴平方和开方。**排序保证「先丢最小的」永远最优**。

**辨析｜易错点：** Eckart-Young 的「最佳」是对**所有秩 ≤ $k$** 的矩阵而言（不只是 SVD 截断得到的那些）。它排除了一种幻觉：「也许某个非 SVD 的秩 $k$ 矩阵更接近 $A$」——定理证明 SVD 截断已经做到最好。

## 4 例子：图像矩阵的低秩近似

一个 $50 \times 50$ 的图像灰度矩阵 $A$，SVD 奇异值 $\sigma_1 = 2000$，$\sigma_2 = 500$，$\sigma_3 = 50$，$\sigma_4 = 5$，其余 < 1。

- $A_1 = \sigma_1\mathbf{u}_1\mathbf{v}_1^T$：用 1 个奇异值近似，误差 $\|A - A_1\|_2 = \sigma_2 = 500$——只抓住「平均亮度」；
- $A_2$：加 $\sigma_2$ 层，误差 $\sigma_3 = 50$——主要对比度出现；
- $A_3$：误差 $\sigma_4 = 5$——细节浮现；
- 保留前 3 层，存储 $3(50+50+1) = 303$ 个数，对比原 $2500$ 个元素，压缩约 8 倍而视觉几乎无损。

**重点**：**奇异值的「衰减速度」决定可压缩性**。衰减快（前几个奇异值独占大部分能量）→ 低秩近似效果好；衰减慢 → 矩阵本身「很满」，难压缩。数据科学里常用「奇异值能量占比 $\sum_{i\le k}\sigma_i^2/\sum_i\sigma_i^2$」来决定保留多少主成分（PCA，第十一篇）。

## 5 截断 SVD 与 PCA 的衔接

截断 SVD 与主成分分析（PCA）的关系极其密切：

- 数据矩阵 $X$（$m \times n$，$m$ 个样本、$n$ 个特征）的 SVD $X = U\Sigma V^T$；
- $X^TX = V\Sigma^2V^T$——**协方差矩阵的特征分解**（未中心化版本）；
- PCA 的主方向 = $V$ 的列（右奇异向量），主成分得分 = $U\Sigma$（左奇异向量 × 奇异值）；
- **保留前 $k$ 个奇异向量 = PCA 降到 $k$ 维**。

**重点**：**PCA = 截断 SVD 的统计版**。奇异值大小 = 各主方向的方差大小，Eckart-Young 保证「前 $k$ 个方向捕获最大方差」。这一条将在第十一篇完整展开。

**辨析｜易错点：** PCA 通常先对数据**中心化**（减去均值），再做 SVD/特征分解——因为协方差矩阵需要中心化。未中心化的 $X^TX$ 只是「Gram 矩阵」，不是协方差矩阵。**「中心化」是 PCA 与 SVD 之间最常被忽略的细节**。

**补充｜低秩近似的「信息压缩」本质**：$A_k$ 用 $k(m+n)$ 个数近似 $mn$ 个元素，压缩的本质是「假设数据由 $k$ 个潜在因子驱动」——这与推荐系统矩阵分解（隐因子）的思想完全一致。**截断 SVD 与 MF 是同一低秩假设的两个算法**：完整矩阵用 SVD，稀疏矩阵用迭代优化（第十一篇）。Eckart-Young 定理保证：在「平方误差」意义下，SVD 截断是最优的——这给了所有低秩方法一个理论下限。

**补充｜低秩近似的「信息压缩」本质**：$A_k$ 用 $k(m+n)$ 个数近似 $mn$ 个元素，压缩的本质是「假设数据由 $k$ 个潜在因子驱动」——这与推荐系统矩阵分解（隐因子）的思想完全一致。**截断 SVD 与 MF 是同一低秩假设的两个算法**：完整矩阵用 SVD，稀疏矩阵用迭代优化（第十一篇）。Eckart-Young 定理保证：在「平方误差」意义下，SVD 截断是最优的——这给了所有低秩方法一个理论下限。

**辨析｜易错点：** 截断 SVD 的三个易错点：

- $A_k$ 的秩**恰好** ≤ $k$，但不一定等于 $k$（若 $\sigma_k = 0$ 则更低）；
- $A_k$ 的奇异值就是 $A$ 的前 $k$ 个奇异值（不变），但 $A - A_k$ 的奇异值是 $\sigma_{k+1}, \cdots, \sigma_r$；
- 截断不是「把 $A$ 的某 $k \times k$ 子矩阵留下」，而是「用前 $k$ 个秩一层重新合成」。

**「截断在奇异值层、不在元素层」**是理解截断 SVD 的关键。

**补充｜截断 SVD 的「一句话」**：**「保留前 $k$ 个最大奇异值层 = 最佳秩 $k$ 近似」**——Eckart-Young 定理保证它在平方误差意义下最优，压缩、去噪、PCA 全在这一条上。

**补充｜截断 SVD 的应用速览**：

- 图像压缩：保留前 $k$ 层，压缩比 $\frac{mn}{k(m+n)}$；
- 去噪：丢弃小奇异值层（噪声），保结构；
- PCA：中心化数据截断 SVD = 主成分；
- 潜在语义分析：文档词频矩阵的低秩近似 = 语义方向。

**「低秩近似」一个思想，压缩/去噪/降维/语义四场应用**。

## 6 小结

- **截断 SVD**：$A_k = \sum_{i\le k}\sigma_i\mathbf{u}_i\mathbf{v}_i^T$，保留前 $k$ 大奇异值层。
- **Eckart-Young**：$A_k$ 是秩 ≤ $k$ 的最佳近似；误差 $\|A - A_k\|_2 = \sigma_{k+1}$。
- **存储收益**：$k(m+n+1)$ 个数近似 $mn$ 个元素。
- **奇异值衰减**决定可压缩性；能量占比决定保留主成分个数。
- **PCA 衔接**：PCA = 中心化数据后的截断 SVD（$X^TX = V\Sigma^2V^T$）。
