## 为什么从标准形开始

上一节我们把二次型装进了对称矩阵。现在问：怎样去掉所有交叉项，把二次型化成**纯平方和**？答案是**正交变换**（旋转/镜像坐标轴）——它不改变图形的形状与大小，只是把「倾斜的椭圆」转到与坐标轴对齐。<span class="marginnote">正交变换化标准形的几何意义：<strong>二次曲线/曲面的主轴就是对称矩阵的特征向量方向</strong>，主轴的半轴长与特征值相关。理解 $f(\mathbf{x}) = \mathbf{x}^TA\mathbf{x} = c$ 的图形，就是看 $A$ 的特征值——这正是「特征值分解的几何意义」。这个思想直接通到 PCA：找数据椭球的「主轴」。</span>

本节是「实对称矩阵正交对角化」与「二次型」的会师：把 $A = Q\Lambda Q^T$ 代入二次型，交叉项自动消失。

## 1 标准形的定义

**核心概念**：若二次型 $f(x_1, \cdots, x_n)$ 通过可逆线性变换只含**平方项**：

$$
f = \lambda_1 y_1^2 + \lambda_2 y_2^2 + \cdots + \lambda_n y_n^2
$$

则称其为二次型的**标准形（canonical form）**。若再进一步把每个平方项系数化成 $1, -1$ 或 $0$（只留符号），则称为**规范形**（惯性定理一节）。

**重点**：标准形里的系数 $\lambda_i$ 恰好是矩阵 $A$ 的**特征值**（用正交变换时）；用一般可逆变换时系数会变，不再是特征值。所以「用正交变换化标准形」得到的系数具有几何意义——它们就是主轴方向的伸缩率。

## 2 正交变换法：算法与原理

**算法（正交变换化标准形）**：

1. 写出二次型的对称矩阵 $A$。
2. 求 $A$ 的特征值与特征向量，特征向量正交化、单位化得标准正交基 $\mathbf{q}_1, \cdots, \mathbf{q}_n$。
3. 令 $Q = (\mathbf{q}_1, \cdots, \mathbf{q}_n)$，作正交变换 $\mathbf{x} = Q\mathbf{y}$。
4. 代入：$f = \mathbf{x}^TA\mathbf{x} = \mathbf{y}^T(Q^TAQ)\mathbf{y} = \mathbf{y}^T\Lambda\mathbf{y} = \lambda_1 y_1^2 + \cdots + \lambda_n y_n^2$。

**为什么成立**：$Q^TAQ = \Lambda$（实对称矩阵的正交对角化），对角矩阵自动消去交叉项。正交变换不改变长度与角度，所以**图形的形状不变**——只是坐标轴转了。

**一个完整的例子**：化 $f = 3x_1^2 + 2x_1x_2 + 3x_2^2$ 为标准形。

- 矩阵 $A = \begin{pmatrix} 3 & 1 \\ 1 & 3 \end{pmatrix}$，特征值 $\lambda = 2, 4$（前文已求），特征向量单位化 $\mathbf{q}_1 = \frac1{\sqrt2}(1,-1)^T$、$\mathbf{q}_2 = \frac1{\sqrt2}(1,1)^T$。
- 取 $Q = \frac1{\sqrt2}\begin{pmatrix} 1 & 1 \\ -1 & 1 \end{pmatrix}$，$\mathbf{x} = Q\mathbf{y}$。
- 标准形：$f = 2y_1^2 + 4y_2^2$。

几何：原方程 $3x_1^2 + 2x_1x_2 + 3x_2^2 = 1$ 是一个倾斜的椭圆；旋转 $45°$ 后变成 $2y_1^2 + 4y_2^2 = 1$——标准位置的椭圆，半轴长 $1/\sqrt2$ 与 $1/2$。

## 3 公式解析：为什么交叉项会消失

$f = \mathbf{y}^T(Q^TAQ)\mathbf{y}$ 里 $Q^TAQ = \Lambda$ 是对角矩阵，交叉项为何消失？拆开看：

- **第一步，换元后的矩阵**：$\mathbf{x} = Q\mathbf{y}$ 代入得 $f = \mathbf{y}^T(Q^TAQ)\mathbf{y}$，新矩阵是 $B = Q^TAQ$。
- **第二步，$B$ 是什么**：$B$ 的第 $(i,j)$ 元 $= \mathbf{q}_i^T A \mathbf{q}_j = \lambda_j(\mathbf{q}_i^T\mathbf{q}_j) = \lambda_j\delta_{ij}$——特征向量的正交性（$\mathbf{q}_i\cdot\mathbf{q}_j = \delta_{ij}$）把非对角项全部清零。
- **第三步，为什么是特征值**：$A\mathbf{q}_j = \lambda_j\mathbf{q}_j$，所以 $\mathbf{q}_i^TA\mathbf{q}_j = \lambda_j\delta_{ij}$。**正交性筛选 + 特征方程代入**，两步合并得对角元即特征值。
- **第四步，几何意义**：在新坐标（特征向量方向）下，$f$ 变成 $\sum \lambda_i y_i^2$——沿每个主轴方向独立的平方函数。交叉项 $y_iy_j$ 的系数是 $\lambda_j(\mathbf{q}_i\cdot\mathbf{q}_j)$，因垂直而为零。

<span class="marginnote"><strong>「对角化 = 消交叉项」</strong>是双重含义的汇合：从矩阵看，$Q^TAQ$ 对角；从二次函数看，交叉项消失。特征值就是「主轴上的曲率」，特征向量就是「主轴方向」。PCA 正是把这个操作搬到数据协方差矩阵上。</span>

## 4 标准形与几何图形的对应

二次型 $f(\mathbf{x}) = \mathbf{x}^TA\mathbf{x} = c$（常数）的图形由特征值的符号完全决定：

- **全部正**（正定）：椭球（$\mathbb{R}^2$ 中椭圆）；
- **一正一负**（不定）：双曲面（$\mathbb{R}^2$ 中双曲线）；
- **含零**（半正定）：抛物面/柱面退化情形。

例：$2y_1^2 + 4y_2^2 = 1$ 是椭圆；$2y_1^2 - 4y_2^2 = 1$ 是双曲线（一正一负）；$2y_1^2 = 1$ 是两条平行直线（含零）。

**重点**：**特征值的符号**决定二次型的「类型」，特征值的**大小**决定各方向的「胖瘦」。这就是为什么正定二次型（全部特征值 > 0）那么重要——它保证图形是「碗状」的凸函数，最优化问题里保证极小值存在且唯一。

**辨析｜易错点：** 正交变换化标准形得到的系数**必为特征值**；若用非正交的可逆变换（配方法，下节），系数只是「某个非零数」，不一定是特征值。考试题里问「用正交变换化标准形」时，系数必须是特征值——用配方法得到的数不符题意。

## 5 标准形的不变量：迹与行列式

正交变换下（其实任何相似变换下）二次型的两个不变量：

$$
\operatorname{tr} A = \lambda_1 + \cdots + \lambda_n, \qquad \det A = \lambda_1 \cdots \lambda_n
$$

**重点**：这两个量不随坐标系旋转而变——它们是二次曲面的「几何固有量」。椭圆的面积、曲面的曲率积分等都可以用它们表达。在 PCA 中，$\operatorname{tr}(\text{协方差})$ = 总方差（特征值之和），是数据「总散度」的不变量（第十一篇）。

**辨析｜易错点：** 合同变换（$A \to Q^TAQ$，$Q$ 可逆不一定正交）保持的是**惯性指数**（正负平方项个数）而非特征值大小。只有正交合同（$Q$ 正交）才保持特征值本身。这是下一节惯性定理的伏笔。

**补充｜主轴定理与二次曲面的分类**：用正交变换化标准形在几何上就是「旋转坐标轴到主轴方向」——这个结果常被称为**主轴定理（Principal Axis Theorem）**：任何二次曲面的主轴就是对称矩阵特征向量方向。椭圆、双曲线、抛物线的「类型」由特征值符号决定，「大小」由特征值数值决定，「朝向」由特征向量决定。**一条定理同时给出曲线的类型、尺寸与方向**——这就是「正交变换化标准形」的几何回报。

**辨析｜易错点：** 正交变换**不改变图形的形状**（保距），只是转坐标系；配方法对应的可逆变换会**拉伸变形**（把圆变成椭圆但仍保持曲线类型）。若题目要求「图形的几何形状」，用正交变换的结果才是真实的；配方法只保证「代数类型」不变。**「保形状」与「保类型」是正交变换与一般可逆变换的分水岭**。

**补充｜主轴定理与二次曲面的分类**：用正交变换化标准形在几何上就是「旋转坐标轴到主轴方向」——这个结果常被称为**主轴定理（Principal Axis Theorem）**：任何二次曲面的主轴就是对称矩阵特征向量方向。椭圆、双曲线、抛物线的「类型」由特征值符号决定，「大小」由特征值数值决定，「朝向」由特征向量决定。**一条定理同时给出曲线的类型、尺寸与方向**——这就是「正交变换化标准形」的几何回报。

**辨析｜易错点：** 正交变换**不改变图形的形状**（保距），只是转坐标系；配方法对应的可逆变换会**拉伸变形**（把圆变成椭圆但仍保持曲线类型）。若题目要求「图形的几何形状」，用正交变换的结果才是真实的；配方法只保证「代数类型」不变。**「保形状」与「保类型」是正交变换与一般可逆变换的分水岭**。

**补充｜化标准形的完整流程（正交法）**：

- 写出二次型的对称矩阵 $A$；
- 求 $A$ 的特征值与单位特征向量（重特征值组内正交化）；
- 拼正交矩阵 $Q$，作 $\mathbf{x} = Q\mathbf{y}$；
- 标准形 $\sum \lambda_i y_i^2$，系数即特征值。

**「先对角化，再换元」两步走**——对角化给出特征值，换元给出标准形。

**补充｜标准形的判别与应用小结**：

- **类型**：特征值符号决定（正定/不定/半正定）；
- **尺寸**：特征值大小决定（半轴长）；
- **方向**：特征向量决定（主轴方向）。

**「类型、尺寸、方向三件套」**由谱分解一次给出，这就是正交变换化标准形优于配方法的地方。

## 6 小结

- **标准形**：只含平方项 $\sum \lambda_i y_i^2$；用正交变换时系数即特征值。
- **算法**：特征向量单位化拼 $Q$，$\mathbf{x} = Q\mathbf{y}$，$Q^TAQ = \Lambda$。
- **原理**：特征向量正交性把交叉项系数 $\lambda_j(\mathbf{q}_i\cdot\mathbf{q}_j)$ 清零。
- **几何**：二次曲面主轴 = 特征向量方向，半轴由特征值决定。
- **不变量**：$\operatorname{tr} A$、$\det A$ 在旋转下不变。

在下一节，我们将不用矩阵、只用初等代数的手艺把二次型化标准形——**用配方法化二次型为标准形**，并理解它与正交变换法的差别。
