## 为什么从线性子空间开始

线性空间里有一类特殊的子集：它们自己就是线性空间。这些**线性子空间**无处不在——齐次方程组的解空间、矩阵的列空间与行空间、多项式的低次子空间。理解子空间，就是理解「空间内部的结构」：一个 $n$ 维空间里藏着多少个「更低维的世界」。<span class="marginnote">子空间是第七篇「四个基本子空间」的语法：矩阵的列空间、行空间、零空间、左零空间全是 $\mathbb{R}^n$ 或 $\mathbb{R}^m$ 的子空间。判断「某集合是不是子空间」只需验证三件事（含零、加封闭、数乘封闭）——<strong>这是线性代数里最常被问到的「检验题」</strong>。</span>

本节给出子空间的判据、维数公式与交/和运算。

## 1 子空间的定义

**核心概念**：设 $W$ 是线性空间 $V$ 的非空子集。若 $W$ 对 $V$ 的加法和数乘**封闭**（$W$ 中任意两向量相加仍在 $W$，任意向量数乘仍在 $W$），则 $W$ 是 $V$ 的一个**线性子空间（linear subspace）**。

**子空间判据（三个条件）**：$W \subseteq V$ 非空，且满足

1. **含零向量**：$\mathbf{0} \in W$；
2. **加法封闭**：$\mathbf{x}, \mathbf{y} \in W \Rightarrow \mathbf{x} + \mathbf{y} \in W$；
3. **数乘封闭**：$\mathbf{x} \in W, \lambda \in \mathbb{R} \Rightarrow \lambda\mathbf{x} \in W$。

**重点**：验证这三个条件，就验证了 $W$ 自己是线性空间（八条律从 $V$ 继承）。**不需要重验八条律**——封闭性 + 继承 = 子空间。这是子空间判据之所以简洁的原因。

**辨析｜易错点：** 「非空」可由条件 1 保证，所以实际只需验 2、3。**空集不是子空间**（不含零向量）。例：$W = \{(x_1, x_2) \mid x_1 + x_2 = 1\}$ 不是子空间——不含 $(0,0)$（它是「仿射子空间」而非子空间，见第四篇）。$W = \{(x_1, x_2) \mid x_1 + x_2 = 0\}$ 是子空间。

## 2 常见子空间实例

**零空间**：$W = \{\mathbf{0}\}$ 是最小的子空间；$V$ 本身是最大的子空间。
**齐次解空间**：$Ax = 0$ 的解集 $\operatorname{Nul}(A)$ 是 $\mathbb{R}^n$ 的子空间（第四篇）。
**张成空间**：$\operatorname{span}\{\mathbf{v}_1, \cdots, \mathbf{v}_k\}$ 是所有含这些向量的子空间中最小的一个。
**矩阵空间**：$\mathbb{R}^{n\times n}$ 中全体对角矩阵、上三角矩阵、对称矩阵，各构成子空间。
**多项式空间**：$\mathbb{P}_n$ 中偶次多项式、能被 $x^2$ 整除的多项式，都是子空间。

**重点**：**张成空间是「生成子空间」的标准构造**——给任意向量组，它的全部线性组合就是包含它们的最小子空间。反过来，任何子空间都能写成某个向量组的张成空间。子空间 ↔ 张成空间是同一枚硬币的两面。

## 3 公式解析：$\operatorname{span}$ 为什么必是子空间

验证 $\operatorname{span}\{\mathbf{v}_1, \cdots, \mathbf{v}_k\}$ 是子空间，拆成三步：

**第一步，含零**：$\mathbf{0} = 0\cdot\mathbf{v}_1 + \cdots + 0\cdot\mathbf{v}_k$，零向量是「全零系数的组合」，在 $\operatorname{span}$ 内。
**第二步，加法封闭**：$\sum c_i\mathbf{v}_i + \sum d_i\mathbf{v}_i = \sum(c_i + d_i)\mathbf{v}_i$——两个组合相加仍是组合，系数相加即可。
**第三步，数乘封闭**：$\lambda\sum c_i\mathbf{v}_i = \sum(\lambda c_i)\mathbf{v}_i$——组合数乘仍是组合。
**第四步，结论**：**线性组合的线性组合还是线性组合**，这个「封闭性」正是 $\operatorname{span}$ 是子空间的本质原因。所有子空间都能写成这种形式。

<span class="marginnote">「线性组合的封闭性」是子空间理论的核心机制：<strong>子空间 = 对线性组合封闭的非空集合</strong>。因此，给定任意集合 $S$，$S$ 的线性组合全体（$\operatorname{span}S$）就是包含 $S$ 的最小子空间——这个「最小包含」构造在泛函分析、凸分析里反复出现（第二级《泛函分析》）。</span>

## 4 子空间的交与和

两个子空间的交与和仍是子空间：

**定理**：设 $W_1, W_2$ 是 $V$ 的子空间，则

- **交** $W_1 \cap W_2$ 是子空间（满足判据三条件）；
- **和** $W_1 + W_2 = \{\mathbf{w}_1 + \mathbf{w}_2 \mid \mathbf{w}_1 \in W_1, \mathbf{w}_2 \in W_2\}$ 是子空间。

但**并** $W_1 \cup W_2$ 一般不构成子空间（除非一个包含另一个）。

**维数公式（Grassmann 公式）**：

$$
\dim(W_1 + W_2) = \dim W_1 + \dim W_2 - \dim(W_1 \cap W_2)
$$

**重点**：这个公式像容斥原理——「和」的维数 = 两边维数之和 − 交叠部分的维数。例：两个二维子空间在 $\mathbb{R}^3$ 中，交是一维直线，则和是三维全空间。**交小则和大，交大则和小**。

**辨析｜易错点：** 「直和」$W_1 \oplus W_2$ 是和的特殊情形：$W_1 \cap W_2 = \{\mathbf{0}\}$ 时，$W_1 + W_2$ 的表示唯一，记为 $W_1 \oplus W_2$。此时 $\dim(W_1 \oplus W_2) = \dim W_1 + \dim W_2$（容斥里交为零）。直和 = 「各干各的、互不重叠」的分解——谱分解、四个基本子空间的正交分解都追求这种「干净拆分」。

## 5 子空间与维数的应用

**例子**：在 $\mathbb{R}^3$ 中判断两个平面子空间的交。设 $W_1$ 是 $x+y+z=0$（二维），$W_2$ 是 $x-y=0$（二维）。由 Grassmann 公式：$\dim(W_1\cap W_2) = \dim W_1 + \dim W_2 - \dim(W_1+W_2)$。因两者不相等，$W_1 + W_2$ 至少三维（$\mathbb{R}^3$），至多三维，故 $\dim(W_1\cap W_2) = 2 + 2 - 3 = 1$——两个平面交于一条直线。

**重点**：**Grassmann 公式让你「不算坐标」就能推出交/和的维数**，这是子空间理论最具威力的工具之一。它在第七篇四个基本子空间的维数关系、以及线性方程组解的几何中扮演关键角色。

**补充｜子空间与「维数守恒」的应用**：Grassmann 公式 $\dim(W_1+W_2) = \dim W_1 + \dim W_2 - \dim(W_1\cap W_2)$ 还有一个直观版本：**两个子空间「合起来」的维数 = 各自的维数之和，减去它们「重叠」的部分**——与集合容斥原理（并集大小 = 各自大小 − 交集大小）逐字对应。在数据科学里，两个特征子空间的重叠度衡量「信息冗余」，正交（交为零）意味着信息不重叠——这正是「直和」追求的目标。

**辨析｜易错点：** 「并」$W_1 \cup W_2$ 一般不是子空间——取 $\mathbf{w}_1 \in W_1\setminus W_2$ 与 $\mathbf{w}_2 \in W_2\setminus W_1$，它们的和在一般情况下既不在 $W_1$ 也不在 $W_2$。**「和」与「并」是两回事**：和是「所有可能的两元素相加」，并是「两集合直接合并」。只有「和」保证封闭，所以子空间的合并运算是「和」而不是「并」。

**补充｜子空间与「维数守恒」的应用**：Grassmann 公式 $\dim(W_1+W_2) = \dim W_1 + \dim W_2 - \dim(W_1\cap W_2)$ 还有一个直观版本：**两个子空间「合起来」的维数 = 各自的维数之和，减去它们「重叠」的部分**——与集合容斥原理（并集大小 = 各自大小 − 交集大小）逐字对应。在数据科学里，两个特征子空间的重叠度衡量「信息冗余」，正交（交为零）意味着信息不重叠——这正是「直和」追求的目标。

**辨析｜易错点：** 「并」$W_1 \cup W_2$ 一般不是子空间——取 $\mathbf{w}_1 \in W_1\setminus W_2$ 与 $\mathbf{w}_2 \in W_2\setminus W_1$，它们的和在一般情况下既不在 $W_1$ 也不在 $W_2$。**「和」与「并」是两回事**：和是「所有可能的两元素相加」，并是「两集合直接合并」。只有「和」保证封闭，所以子空间的合并运算是「和」而不是「并」。

**补充｜直和与「坐标分解」**：当 $V = W_1 \oplus W_2$ 时，每个向量 $\mathbf{v}$ 有**唯一**的分解 $\mathbf{v} = \mathbf{w}_1 + \mathbf{w}_2$（$\mathbf{w}_i \in W_i$）。这个唯一性让「按子空间分量」可以定义「投影」——$V$ 到 $W_1$ 沿 $W_2$ 的投影算子。**「直和 = 可以无歧义地拆分量」**，这在最小二乘（$\mathbb{R}^m = \operatorname{Col}(A) \oplus \operatorname{Nul}(A^T)$）、信号处理（信号 + 噪声的直和分解）里是基本工具。

## 6 例子：验证子空间 + 求维数

**例 1**：$W = \{(x, y, z) \mid x - y + z = 0\}$ 是 $\mathbb{R}^3$ 的子空间吗？维数？

- 含零：$0 - 0 + 0 = 0$ ✓；
- 加法封闭：$(x - y + z) + (x' - y' + z') = 0$ ✓；
- 数乘封闭：$\lambda(x - y + z) = 0$ ✓；
- 所以 $W$ 是子空间；它由方程约束一个自由度，维数 $= 3 - 1 = 2$（一个平面）。

**例 2**：$W_1 + W_2$ 的维数（Grassmann 公式的应用）。设 $W_1$ 是 $x$-轴（$\operatorname{span}\{(1,0,0)\}$，维数 1），$W_2$ 是 $xy$-平面（维数 2）。$W_1 \subset W_2$，故 $W_1 \cap W_2 = W_1$，$\dim(W_1+W_2) = 1 + 2 - 1 = 2$——和仍是 $xy$-平面。**「子集时和不增维」**是公式的直观特例。

**辨析｜易错点：** 两个二维子空间的和不一定是三维：在 $\mathbb{R}^3$ 中若两个平面重合（交为平面，维数 2），则和维数 $= 2 + 2 - 2 = 2$。**「和」的维数取决于「交」的大小**——交越大，和越小。Grassmann 公式把这种「此消彼长」精确量化。

**补充｜一句话**：**「子空间 = 对线性组合封闭的子集」**——验证三件事（含零、加封闭、数乘封闭），就验证了「自己也是空间」。

**补充｜学习地图**：子空间理论是第七篇「四个基本子空间」与正交补（第七篇）的直接前置——列空间、零空间、行空间、左零空间全都是「矩阵定义的子空间」。

## 7 小结

- **定义**：非空 + 加法封闭 + 数乘封闭；八条律从父空间继承。
- **判据**：验证含零、加法封闭、数乘封闭三件事。
- **实例**：零空间、解空间、张成空间、对称矩阵空间等。
- **运算**：交与和仍是子空间；并一般不构成子空间。
- **Grassmann 公式**：$\dim(W_1+W_2) = \dim W_1 + \dim W_2 - \dim(W_1\cap W_2)$；直和时交为零、维数相加。
