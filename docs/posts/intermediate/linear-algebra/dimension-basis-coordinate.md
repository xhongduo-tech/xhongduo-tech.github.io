## 为什么从维数、基与坐标开始

上一节把「向量」抽象成了任意满足八条律的对象。现在要给抽象空间装上「度量衡」：**基**是坐标系，**维数**是自由度数，**坐标**是向量的「地址」。有了这三样，抽象的线性空间就与具体的 $\mathbb{R}^n$ 完全同构——这是线性代数「化抽象为具体」的经典一步。<span class="marginnote">「有限维线性空间都长成 $\mathbb{R}^n$ 的样子」是本节的核心结论，术语叫<strong>线性同构</strong>：维数相同的线性空间本质是同一个空间，只是元素穿的衣服不同。函数空间 $C[a,b]$ 是无穷维的，不满足有限维，但它仍然有「基」（无穷多个）——傅里叶分析的基就是三角函数系。</span>

本节是第四篇「向量空间、基与维数」的一般化：那里针对 $\mathbb{R}^n$ 内的子集，这里针对任意线性空间。

## 1 基的定义（一般线性空间）

**核心概念**：设 $V$ 是线性空间，若 $V$ 中存在一组向量 $\mathbf{a}_1, \cdots, \mathbf{a}_n$ 满足：

- **线性无关**；
- **张成 $V$**：$V$ 中任一向量都可由它们线性表示；

则称这组向量为 $V$ 的一组**基（basis）**。

**重点**：基的定义在抽象空间与 $\mathbb{R}^n$ 中一字不差——因为「线性无关」与「线性表示」只依赖加法和数乘，而这正是线性空间的公理。**任何线性空间（只要存在有限生成集）都有基**，且任意两组基含相同个数。

例：多项式空间 $\mathbb{P}_2$（次数 ≤ 2）的基可取 $\{1, x, x^2\}$。任意 $p(x) = a_0 + a_1x + a_2x^2$ 都能唯一表示。也可取 $\{1, 1+x, (1+x)^2\}$——基不唯一。

## 2 维数的定义

**核心概念**：线性空间 $V$ 的任意一组基所含向量个数（都相同）称为 $V$ 的**维数（dimension）**，记作 $\dim V$。

- $\dim \mathbb{R}^n = n$；
- $\dim \mathbb{P}_n = n + 1$；
- $\dim \mathbb{R}^{m\times n} = mn$；
- $\dim \{ \mathbf{0} \} = 0$（零空间维数约定为 0）；
- $C[a,b]$ 是**无穷维**线性空间（不存在有限基）。

**定理（维数的完备性）**：若 $\dim V = n$，则：

- $V$ 中任意 $n$ 个线性无关向量必是基；
- $V$ 中任意 $n$ 个张成 $V$ 的向量必线性无关。

**辨析｜易错点：** 「基不唯一、维数唯一」是本节必须建立的区分。$\mathbb{P}_2$ 可以有许多组基，但维数恒为 3。另外注意 $\dim \mathbb{P}_n = n+1$ 而非 $n$——因为多项式 $1, x, \cdots, x^n$ 共有 $n+1$ 个。初学者常在「次数」与「维数」之间差 1。

## 3 坐标的定义

**核心概念**：设 $\mathbf{a}_1, \cdots, \mathbf{a}_n$ 是 $V$ 的一组基，则 $V$ 中任意 $\mathbf{x}$ 有**唯一**表示

$$
\mathbf{x} = x_1\mathbf{a}_1 + x_2\mathbf{a}_2 + \cdots + x_n\mathbf{a}_n
$$

有序数组 $(x_1, \cdots, x_n)^T$ 称为 $\mathbf{x}$ 在基 $\{\mathbf{a}_i\}$ 下的**坐标（coordinates）**。

**定理（坐标的唯一性）**：坐标由向量与基唯一决定——基线性无关保证了表示唯一（若有两种表示相减得 $\sum(x_i - x'_i)\mathbf{a}_i = \mathbf{0}$，系数全零）。

例：$p(x) = 1 + 2x - x^2$ 在基 $\{1, x, x^2\}$ 下的坐标是 $(1, 2, -1)^T$。

**重点**：**选定基，抽象向量 ↔ 坐标数组一一对应**。这个对应 $\mathbf{x} \mapsto (x_1, \cdots, x_n)^T$ 是「从 $V$ 到 $\mathbb{R}^n$」的一个线性同构——它是「抽象空间本质是 $\mathbb{R}^n$」这句话的严格表述。

## 4 公式解析：$\mathbf{x} = \sum x_i\mathbf{a}_i$ 的坐标解读

这条表示式是「向量 = 基的加权和」的抽象版，拆成四步：

- **第一步，向量在基下的「配方」**：基张成 $V$，所以 $\mathbf{x}$ 至少可表示；基无关，所以至多一种。**存在性来自张成，唯一性来自无关**。
- **第二步，坐标作为函数**：把「$\mathbf{x}$ 的第 $i$ 个坐标」看成从 $V$ 到 $\mathbb{R}$ 的函数 $x_i(\cdot)$。它是**线性泛函**：$x_i(\mathbf{x} + \mathbf{y}) = x_i(\mathbf{x}) + x_i(\mathbf{y})$，$x_i(\lambda\mathbf{x}) = \lambda x_i(\mathbf{x})$。坐标是「取分量」的线性算子。
- **第三步，基的「可数性」**：基就是「参考架」，坐标是向量在这架参考下的地址。换一组基，同一向量的坐标改变（下节基变换）。
- **第四步，抽象与具体的桥**：通过坐标，$V$ 上的一切线性运算都能翻译成 $\mathbb{R}^n$ 上的对应运算——这正是「坐标化」的实用价值：把函数、矩阵的问题变成数组的问题。

<span class="marginnote">「坐标是线性泛函」这个视角有深远影响：<strong>对偶空间</strong>——全体线性泛函构成的空间——在微分几何与物理学（协变/逆变向量）中地位重要（第二级《微分几何》）。本节先埋下伏笔。</span>

## 5 维数定理的应用：解空间与矩阵空间

**例子：齐次方程组的解空间**。$Ax = 0$（$A$ 是 $m \times n$）的解集是 $\mathbb{R}^n$ 的子空间，其基就是基础解系（第四篇），所以

$$
\dim(\text{解空间}) = n - \operatorname{rank} A
$$

**例子：矩阵空间**。$\mathbb{R}^{m\times n}$ 的基可取「只在 $(i,j)$ 位置为 1、其余为 0」的矩阵 $E_{ij}$，共 $mn$ 个，故 $\dim \mathbb{R}^{m\times n} = mn$。

**重点**：维数把「自由度数」量化——解空间维数 = 自由变量个数，矩阵空间维数 = 元素个数。**维数 = 独立的自由度**，这条直觉在统计（自由度）、力学（机构自由度）、机器学习（模型参数空间的维数）里通用。

**辨析｜易错点：** 子空间的维数**不超过**原空间维数：若 $W \subseteq V$ 是子空间，则 $\dim W \le \dim V$，等号当且仅当 $W = V$。这与「子集元素数不超过全集的元素数」直觉一致，但需要按基来证明。

**补充｜无穷维空间的一次眺望**：$C[a,b]$（连续函数空间）没有有限基，是**无穷维**的——但这不妨碍它拥有「基」的观念：一组可数基（如三角函数系、多项式基）可以「生成」稠密的子集，任何函数都能被有限线性组合任意逼近。**有限维里「基」精确生成，无穷维里「基」近似生成（在极限意义下）**——这个「有限到无限的过渡」是数学分析（第二级《数学分析》）、泛函分析（第二级《泛函分析》）与信号处理的共同前沿。本专题立足有限维，但「基与坐标」的语言可以平滑地延伸到无穷维。

**补充｜无穷维空间的一次眺望**：$C[a,b]$（连续函数空间）没有有限基，是**无穷维**的——但这不妨碍它拥有「基」的观念：一组可数基（如三角函数系、多项式基）可以「生成」稠密的子集，任何函数都能被有限线性组合任意逼近。**有限维里「基」精确生成，无穷维里「基」近似生成（在极限意义下）**——这个「有限到无限的过渡」是数学分析（第二级《数学分析》）、泛函分析（第二级《泛函分析》）与信号处理的共同前沿。本专题立足有限维，但「基与坐标」的语言可以平滑地延伸到无穷维。

**辨析｜易错点：** 验证「一组向量是基」时容易漏掉的检查：

- **个数**必须等于 $\dim V$——少了不能张成，多了必相关；
- 验证**无关**或**张成**其一即可（维数完备性给出另一半）；
- 标准基、特征向量基、正交基都是基的特例，各有额外性质。

**「个数 + 无关（或张成） = 基」**是最高效的验证路径。

**补充｜坐标在数据科学中的对应**：选定一组基（如 PCA 的主方向），数据点在新基下的坐标就是「降维后的表示」——**「坐标」=「特征变换后的数据」**。基变换（下节）正是「数据在坐标系间迁移」的代数工具。

**补充｜一句话**：**「维数是空间的地基，基是坐标系，坐标是地址」**——三者合起来，把抽象空间变成可计算的具体数组。

**补充｜学习地图**：本节把「基与坐标」建立好，下一节「基变换」将回答「换基后坐标与矩阵怎么变」——坐标是本节的核心产出，变换是下节的主题。

## 6 小结

- **基**：线性无关 + 张成；任何线性空间（有限生成）都有基，基不唯一。
- **维数**：基的个数唯一确定；$\dim \mathbb{P}_n = n+1$，$\dim \mathbb{R}^{m\times n} = mn$。
- **坐标**：向量在基下的唯一有序数组；坐标是线性泛函。
- **同构**：选定基，$V \cong \mathbb{R}^n$，抽象问题坐标化。
- **应用**：解空间维数 $= n - \operatorname{rank} A$；子空间维数不超过原空间。

在下一节，我们将回答「换一组基，坐标怎么变」——**基变换与坐标变换**，这也是相似矩阵 $P^{-1}AP$ 的完整来源。
