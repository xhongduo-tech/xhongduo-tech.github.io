# 奇异值分解的定义与几何意义

## 为什么从 SVD 开始

前面学过的所有分解（LU、QR、特征分解）都有一个共同的局限：**要么要求方阵、要么要求可对角化**。奇异值分解（SVD）打破一切限制——**任何矩阵**（方阵或长方形、可逆或奇异、实或复）都有 SVD。它是「最强」的矩阵分解，也是数据科学里使用频率最高的工具。<span class="marginnote">SVD 的几何：<strong>任何线性变换 = 一次旋转 + 逐轴拉伸 + 再一次旋转</strong>。$V^T$ 旋转输入、$\Sigma$ 沿坐标轴拉伸、$U$ 旋转输出。没有比这更清晰的矩阵形象了。PCA、压缩、伪逆、推荐系统，全都建立在 SVD 之上。</span>

本节给出 SVD 的定义、存在性直觉与几何意义。

## 1 SVD 的定义

**定理（奇异值分解）**：设 $A$ 是 $m \times n$ 实矩阵，则存在正交矩阵 $U$（$m \times m$）、$V$（$n \times n$）与 $m \times n$ 的「对角」矩阵 $\Sigma$，使

$$
A = U \Sigma V^T
$$

其中 $\Sigma$ 的对角元 $\sigma_1 \ge \sigma_2 \ge \cdots \ge \sigma_r > 0$（$r = \operatorname{rank} A$）称为 $A$ 的**奇异值（singular values）**，其余为零。

**核心概念**：$U$ 的列 $\mathbf{u}_1, \cdots, \mathbf{u}_m$ 称为**左奇异向量**（在 $\mathbb{R}^m$），$V$ 的列 $\mathbf{v}_1, \cdots, \mathbf{v}_n$ 称为**右奇异向量**（在 $\mathbb{R}^n$）。

**重点**：奇异值**非负**且**唯一**（按大小排序）；$U, V$ 不唯一（可换符号），但奇异值集合唯一。秩 $r$ = 非零奇异值的个数。

**公式解析（关键推导）**：SVD 与特征分解的联系——拆成四步：

- **第一步，$A^TA$ 是主角**：$A^TA$ 是 $n \times n$ 对称半正定矩阵，由谱定理 $A^TA = V\Lambda V^T$，其特征值 $\lambda_i \ge 0$。
- **第二步，奇异值定义**：$\sigma_i = \sqrt{\lambda_i}$，即 $A^TA$ 特征值的非负平方根。
- **第三步，$V$ 从 $A^TA$ 来**：$A^TA$ 的特征向量即右奇异向量 $\mathbf{v}_i$。
- **第四步，$U$ 从 $AA^T$ 来**：$AA^T$ 的特征向量即左奇异向量；由 $A\mathbf{v}_i = \sigma_i\mathbf{u}_i$ 沟通两边。**SVD 的两个因子空间由 $A^TA$ 与 $AA^T$ 的谱决定**。

## 2 SVD 的存在性直觉

为什么 SVD 对任意矩阵成立？直觉论证：

- 单位球在 $A$ 作用下的像是一个「超椭球」（为什么？因为 $A$ 是线性变换，把球变成椭球；若 $A$ 奇异，椭球退化到低维平面）。
- 椭球的**主半轴方向**就是左奇异向量 $\mathbf{u}_i$，**半轴长度**就是奇异值 $\sigma_i$。
- **原球上的哪些方向被拉伸成这些主轴？** 这些输入方向就是右奇异向量 $\mathbf{v}_i$。
- 于是 $A\mathbf{v}_i = \sigma_i \mathbf{u}_i$——「第 $i$ 个输入方向被拉伸 $\sigma_i$ 倍、转到第 $i$ 个输出方向」。

**重点**：**SVD 把「任意线性变换」拆成「拉伸哪些方向、拉多长、转到哪里」**。$V^T$ 负责选方向（旋转/反射），$\Sigma$ 负责拉伸，$U$ 负责摆放（旋转/反射）。变换的「本质信息」全在奇异值里。

<span class="marginnote"><strong>「$A$ 把单位球变成超椭球」是 SVD 的几何定义</strong>。奇异值 = 半轴长，右奇异向量 = 原球上对应的方向，左奇异向量 = 椭球主轴方向。这个几何图景让 SVD 的每个量都有直观含义——数据科学里「数据椭球的主轴」就是奇异向量。</span>

## 3 一个完整的例子

求 $A = \begin{pmatrix} 3 & 0 \\ 0 & -2 \end{pmatrix}$ 的 SVD。

- $A^TA = \begin{pmatrix} 9 & 0 \\ 0 & 4 \end{pmatrix}$，特征值 $9, 4$，奇异值 $\sigma_1 = 3$，$\sigma_2 = 2$。
- $V = I$（$A^TA$ 的特征向量即标准基），$U$ 由 $A\mathbf{v}_i = \sigma_i\mathbf{u}_i$ 得 $\mathbf{u}_1 = (1, 0)^T$，$\mathbf{u}_2 = (0, -1)^T$。
- $A = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}\begin{pmatrix} 3 & 0 \\ 0 & 2 \end{pmatrix}\begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}^T$。

注意：$A$ 把 $(0,1)$ 映到 $(0,-2)$——**「负号」进到了 $U$ 里**，奇异值本身非负。这是 SVD 的约定：**方向的反转由 $U, V$ 承载，$\Sigma$ 只记录拉伸幅度**。

**辨析｜易错点：** 奇异值**总非负**（$A^TA$ 半正定）。特征值可以有负号，奇异值不可以——**负特征值在 SVD 里变成「奇异值 + $U$ 中对应列的符号」**。这个区别是 SVD 与特征分解最易混淆处。

## 4 方阵、对称矩阵、秩与 SVD 的关系

- **方阵**：$m = n$ 时，$A = U\Sigma V^T$，$U, V$ 都是正交矩阵，奇异值仍非负。
- **对称矩阵**：$A = Q\Lambda Q^T$ 是特征分解；奇异值 = 特征值的绝对值（$|\lambda_i|$），$U$ 与 $V$ 可取成相同（差符号）。
- **奇异值 ≠ 特征值（一般）**：对非对称矩阵，奇异值是 $A^TA$ 的平方根，与特征值无关。
- **条件数**：$\kappa_2(A) = \sigma_{\max}/\sigma_{\min}$（第九篇）——奇异值是条件数的直接来源。
- **2-范数**：$\|A\|_2 = \sigma_{\max}$（第九篇）。

**重点**：奇异值承担了「度量矩阵大小与病态」的全部职责。**特征值管「代数结构」（Jordan 形），奇异值管「几何度量」（长度、范数、条件数）**——两者分工，缺一不可。

## 5 SVD 的几何意义小结

**一次变换 $A$ 的完整几何故事**：

1. 取输入空间中的单位球；
2. $V^T$ 把它旋转到「右奇异向量坐标轴」；
3. $\Sigma$ 沿各轴拉伸 $\sigma_i$ 倍（奇异值小的轴被压缩）；
4. $U$ 把拉伸后的椭球旋转到「左奇异向量方向」；
5. 最终椭球的主轴 = 左奇异向量，半轴长 = 奇异值。

**重点**：SVD 的几何让「秩」也活了——$\operatorname{rank} A = r$ 意味着椭球在 $r$ 个方向有正半轴、其余方向被压扁为零。**零奇异值对应的方向 = 输入被压扁的方向（零空间），正奇异值方向 = 列空间**——这是下一节的内容。

**补充｜SVD 与「特征分解」的完整对照**：两者都是「分解成方向 × 强度」：特征分解 $A = Q\Lambda Q^T$ 要求方阵、可对角化，$Q$ 同时承载左右方向；SVD $A = U\Sigma V^T$ 对任意矩阵成立，$U$ 与 $V$ 可以不同（输入与输出空间不同）。对**对称矩阵**，两者重合：奇异值 = 特征值绝对值，$U = V$（差符号）。**「SVD 是特征分解的推广」**——当矩阵不方、不对称、不可对角化时，SVD 仍然告诉你它「如何拉伸空间」。这是它被称为「最强分解」的原因。

**补充｜用 SVD 理解「矩阵的本质」**：任何一个矩阵，去掉正交旋转（$U, V$）后，剩下的只是「沿坐标轴拉伸 $\sigma_i$ 倍」——**所有矩阵在「旋转视角」下都是对角矩阵**。这个认识把「矩阵的复杂性」归约到「奇异值序列」：矩阵的一切行为（范数、秩、条件数、低秩结构）都编码在奇异值里。数据科学里「看奇异值谱」就是「看矩阵的本质」。

**补充｜SVD 与「特征分解」的完整对照**：两者都是「分解成方向 × 强度」：特征分解 $A = Q\Lambda Q^T$ 要求方阵、可对角化，$Q$ 同时承载左右方向；SVD $A = U\Sigma V^T$ 对任意矩阵成立，$U$ 与 $V$ 可以不同（输入与输出空间不同）。对**对称矩阵**，两者重合：奇异值 = 特征值绝对值，$U = V$（差符号）。**「SVD 是特征分解的推广」**——当矩阵不方、不对称、不可对角化时，SVD 仍然告诉你它「如何拉伸空间」。这是它被称为「最强分解」的原因。

**补充｜用 SVD 理解「矩阵的本质」**：任何一个矩阵，去掉正交旋转（$U, V$）后，剩下的只是「沿坐标轴拉伸 $\sigma_i$ 倍」——**所有矩阵在「旋转视角」下都是对角矩阵**。这个认识把「矩阵的复杂性」归约到「奇异值序列」：矩阵的一切行为（范数、秩、条件数、低秩结构）都编码在奇异值里。数据科学里「看奇异值谱」就是「看矩阵的本质」。

**辨析｜易错点：** 奇异值计算的常规路径是「先算 $A^TA$ 的特征值再开方」——但工程上**不这样算**（会平方条件数）。数值软件用 Golub-Kahan 双对角化等稳定算法直接求奇异值。**「理解用 $A^TA$，计算走稳定算法」**是 SVD 学习与实现的惯例。

**补充｜SVD 的「一句话」**：**「任意矩阵 = 旋转 × 拉伸 × 旋转」**——$A = U\Sigma V^T$ 把任何线性变换分解成两个正交变换夹一个对角拉伸，奇异值就是这个拉伸的幅度。

**补充｜奇异值 vs 特征值对照表**：

| 量 | 特征值 $\lambda$ | 奇异值 $\sigma$ |
| --- | --- | --- |
| 来源 | $\det(A - \lambda I) = 0$ | $\sqrt{\lambda(A^TA)}$ |
| 符号 | 可正可负可复 | 恒非负 |
| 存在条件 | 方阵 | 任意矩阵 |
| 几何 | 轴伸缩（含方向） | 拉伸幅度（纯大小） |

**「特征值管结构，奇异值管度量」**——两个谱各有分工。

## 6 小结

- **SVD**：$A = U\Sigma V^T$，任何矩阵都有；奇异值非负、唯一、递减。
- **推导**：$\sigma_i = \sqrt{\lambda_i(A^TA)}$，$V$ 来自 $A^TA$、$U$ 来自 $AA^T$。
- **几何**：单位球 → 超椭球；奇异值 = 半轴长，$V$ = 输入方向，$U$ = 输出方向。
- **与特征值分工**：特征值管代数结构，奇异值管几何度量。
- **应用预告**：条件数 $\kappa = \sigma_{\max}/\sigma_{\min}$，PCA、伪逆、低秩近似全部基于 SVD。
