## 为什么单独给「外援」一篇

上一篇文章我们讲活性中心的氨基酸如何亲自上阵，但有一大类反应氨基酸的侧链「化学上做不到」：氧化还原要搬运电子、转氨要搬运氨基、羧化要搬运 $\ce{CO2}$——氨基酸里没有能稳定储存和转移这些官能团的工具。于是酶演化出**外援**：金属离子与有机辅酶。它们是最早的「分子化插件」，也解释了为什么**维生素缺乏会致病**——维生素多数是辅酶的前体，缺了它们，整条代谢线就瘫痪。这篇文章把「谁搬什么」理成一张地图：这既是从《酶反应机制》向《酶活性调节》《酶的应用与临床》过渡的桥梁，也是理解代谢网络共享辅因子池（NAD⁺/NADH 等）这一「全局经济」的关键。<span class="marginnote">辅酶池的共享非常有趣：NAD⁺/NADH、FAD/FADH₂ 在数百个氧化还原酶之间流通，ATP 在所有耗能反应间周转。细胞像持有一种「通用货币」，不同酶只是不同商店。这也让「代谢失调」常以辅因子失衡的方式出现——例如对乙酰氨基酚过量耗尽肝内谷胱甘肽与 NADPH。</span>

## 1 结合酶的三件套与两类辅因子

回顾第 1 篇：结合酶 = **脱辅基酶蛋白（apoenzyme）** + **辅因子（cofactor）**，合起来才叫**全酶（holoenzyme）**。辅因子分两类：

**金属离子（metal ions）**：$\ce{Zn^{2+}}$、$\ce{Mg^{2+}}$、$\ce{Fe^{2+}/Fe^{3+}}$、$\ce{Cu^{2+}}$、$\ce{Mn^{2+}}$、$\ce{Co^{2+}}$、$\ce{Mo}$、$\ce{Ni^{2+}}$ 等。可分两类：**金属酶（metalloenzyme）**中金属与酶紧密结合且必需（如碳酸酐酶的 Zn）；**金属激活酶（metal-activated enzyme）**中金属仅松散结合、起辅助作用（如激酶依赖的 $\ce{Mg^{2+}-ATP}$ 复合物）。
- **有机辅因子——辅酶（coenzyme）与辅基（prosthetic group）**：有机分子，常来自维生素。按结合强弱细分：**辅酶**松散结合、可分离（NAD⁺、CoA 随反应进出）；**辅基**共价或紧密结合在酶上（FAD、生物素、血红素）。<span class="marginnote">辅酶与辅基的界限是模糊的——FAD 有时算辅酶有时算辅基，取决于结合强度。核心判断标准是「能否随产物脱离酶」：能脱离是辅酶，钉在酶上是辅基。不要被命名学困住，记住「可搬走 vs 钉住」的物理区别即可。</span>

## 2 维生素 → 辅酶：一张必须背熟的表

水溶性维生素大多不能由人体合成，只能从食物摄取，其功能几乎全在「变身成辅酶」：

| 维生素 | 活性辅酶形式 | 搬运的基团 |
| --- | --- | --- |
| B₁ 硫胺素 | TPP（硫胺素焦磷酸） | 活性醛基（丙酮酸脱氢酶、转酮醇酶） |
| B₂ 核黄素 | FAD、FMN | 氢（电子） |
| B₃ 烟酸 | NAD⁺、NADP⁺ | 氢负离子（$\ce{H^-}$，成 NADH / NADPH） |
| B₅ 泛酸 | CoA | 酰基（乙酰 CoA 等） |
| B₆ 吡哆醇 | PLP（磷酸吡哆醛） | 氨基（转氨） |
| B₇ 生物素 | 生物素（共价结合） | $\ce{CO2}$（羧化） |
| B₉ 叶酸 | THF（四氢叶酸） | 一碳单位 |
| B₁₂ 钴胺素 | 甲钴胺素 / 腺苷钴胺素 | 甲基、重排 |

**核心概念：辅酶的「搬运逻辑」是成对制**——氧化还原辅酶总以氧化 / 还原两态循环（$\ce{NAD^+ \rightleftharpoons NADH}$），因为搬运的本质是「收下一份、转交一份」。这一「成对周转」正是酶循环催化的微观图景。缺乏 B₁ 导致脚气病、缺乏 B₃ 导致糙皮病、缺乏 B₁₂ 导致恶性贫血——每一条都对应一条依赖该辅酶的代谢线断裂。

### 脂溶性维生素：维生素 ≠ 辅酶前体

上面这张表只覆盖水溶性维生素。脂溶性维生素（A、D、E、K）的功能**不是**变成辅酶：维 A 做视觉色素视黄醛、维 D 做钙代谢激素前体、维 E 做脂溶性抗氧化剂、维 K 参与凝血因子羧化。它们溶于脂、随脂转运与储存，过量会蓄积中毒——与水溶性维生素「过量随尿排出」不同。

| 脂溶性维生素 | 活性形式 | 主要功能 | 与辅酶的区别 |
| --- | --- | --- | --- |
| 维 A | 视黄醛 | 视觉、上皮分化 | 激素样 / 结构功能 |
| 维 D | 骨化三醇 | 钙磷代谢 | 类激素 |
| 维 E | 生育酚 | 抗氧化 | 非酶辅因子 |
| 维 K | 甲萘醌 | 凝血因子 γ-羧化 | 参与羧化但非典型辅酶 |

这提醒我们：「维生素」是按「人体必需、不能自足」定义的营养学概念，与「辅酶前体」只是部分重合——**把「维生素」一律理解成「辅酶」是一个常见误区**。

## 3 辅酶怎么干活：四种典型搬运

**氢负离子（hydride）搬运**：乳酸脱氢酶（LDH）催化 $\ce{乳酸 + NAD+ -> 丙酮酸 + NADH + H+}$。NAD⁺ 的烟酰胺环从底物拿走一个氢负离子（两个电子 + 一个质子），自己变成 NADH；酶同时指定了氢的**立体专一性**（A 侧或 B 侧），连「从哪边递氢」都被精确控制。<span class="marginnote">立体专一性在此体现到极致：乙醇脱氢酶只把 NADH 的 pro-R 氢递给乙醛，pro-S 氢从不参与。酶连一个氢原子的「左右手」都分得清——这是第 1 篇「立体专一性」的原子级版本。</span>

### 氧化还原辅酶的电位标尺

「搬运电子」说得抽象，用标准还原电位 $E^{\circ\prime}$（pH 7）就能给辅酶排出先后：

| 辅酶 | 氧化型 / 还原型 | $E^{\circ\prime}$ (V) | 在代谢中的位置 |
| --- | --- | --- | --- |
| $\ce{NAD+}$ / $\ce{NADH}$ | $-0.32$ | 氧化脱氢反应，靠前 |
| $\ce{NADP+}$ / $\ce{NADPH}$ | $-0.32$ | 还原性合成与抗氧化，靠前 |
| $\ce{FAD}$ / $\ce{FADH2}$ | $-0.22$（结合蛋白时约 $-0.06$） | 琥珀酸脱氢等，居中 |
| $\ce{Fe^{3+}}$ / $\ce{Fe^{2+}}$（细胞色素） | 约 $+0.25$ | 电子传递链，靠后 |

电位从负到正的排列，就是电子自发「下坡」的方向：NAD⁺ 比 FAD 更负，所以 FADH₂ 的电子进入电子传递链复合体 II 时落差更小（只泵 2 个质子），而 NADH 从复合体 I 进入时落差更大（泵 4 个质子）。**这柄「电位尺」把氧化还原酶的底物选择、反应方向与能量释放一次讲清**——是理解代谢能量账本（《生物化学》专题）的钥匙。<span class="marginnote">NADPH 与 NADH 电位几乎相同，细胞却严格分池使用：NADPH 专职还原性合成与抗氧化（如谷胱甘肽还原酶），NADH 专职产能。分池而不分「电性」——这与数据库按用途分库、CPU 按功能分总线是同一类隔离思想。</span>

**酰基搬运**：辅酶 A（CoA）的硫醇端（$\ce{-SH}$）以高能硫酯键携带乙酰基成乙酰 CoA，作为「活性乙酸」进入柠檬酸循环与脂肪酸合成。硫酯键的水解 $\Delta G$ 很大，这正是「活化」的能量来源。

**一碳单位搬运**：四氢叶酸（THF）与 S-腺苷甲硫氨酸（SAM）携带甲基等一碳单位，参与核苷酸与氨基酸合成——抗叶酸药（甲氨蝶呤）正是通过卡死 THF 来阻止 DNA 合成、杀伤快速分裂的癌细胞。

**氨基搬运**：PLP 以希夫碱形式与底物氨基结合、兜转氨基，完成转氨（天冬氨酸转氨酶 AST / 丙氨酸转氨酶 ALT——这两项正是临床肝功能检查的常用指标，见本专题末篇）。

### 金属离子：第五类「就地取材」的辅因子

金属离子做辅因子的方式与有机辅酶不同：它们不搬运基团，而是作为路易斯酸、电子中继或结构骨架参与催化：

| 金属离子 | 代表酶 | 在催化中的角色 |
| --- | --- | --- |
| $\ce{Zn^{2+}}$ | 碳酸酐酶、羧肽酶、醇脱氢酶 | 路易斯酸、活化水、稳定过渡态 |
| $\ce{Mg^{2+}}$ | 己糖激酶、DNA 聚合酶 | 桥连 ATP 磷酸基、定位底物 |
| $\ce{Fe^{2+}/Fe^{3+}}$ | 血红素蛋白、铁硫蛋白 | 电子传递、氧结合 |
| $\ce{Cu^{2+}}$ | 细胞色素氧化酶、酪氨酸酶 | 电子中继 |
| $\ce{Mn^{2+}}$ | 精氨酸酶、超氧化物歧化酶 | 氧化还原与酸碱催化 |
| $\ce{Mo}$ | 黄嘌呤氧化酶、固氮酶 | 氧原子转移 |

**关键区分**：金属酶（metalloenzyme）的金属是「零件」——预先组装、洗不掉；金属激活酶（metal-activated enzyme）的金属是「顾客」——松散结合、随时可换。辨别方法很朴素：**透析或螯合剂处理后，活性若仍可恢复，就是金属激活酶；活性随金属一起流失，就是金属酶**。<span class="marginnote">锌是已知酶中用途最广的金属之一：人体内上百种酶含锌，缺锌影响味觉、免疫与生长，部分原因正是含锌酶活性不足。碳酸酐酶把配位水的 pKa 从约 15.7 压到约 7，全靠 $\ce{Zn^{2+}}$ 的静电作用——这是「金属活化水」最纯粹的例证。</span>

## 4 一个多辅酶协奏的例证：丙酮酸脱氢酶复合体

把辅酶串起来看，最壮观的例子是**丙酮酸脱氢酶复合体（PDC）**——它把糖酵解产物丙酮酸送进柠檬酸循环，需要 **5 种辅因子**接力：

$$\ce{丙酮酸 + NAD+ + CoA -> 乙酰CoA + CO2 + NADH}$$

其中 TPP 先收下活性醛，**硫辛酰胺**（共价挂在转乙酰酶上的辅基）把酰基接力传给 CoA，再经 **FAD** 把氢交给 **NAD⁺**，整个体系还有 **Mg²⁺** 稳定结构。**「一个酶复合体像一条装配线，辅因子是各工位的搬运工」**——这与计算机体系结构里「寄存器 + 总线」的分工模式惊人相似，也呼应本博客主线：生物把复杂的多步计算（这里是一次氧化脱羧）拆成流水线。<span class="marginnote">PDC 的运转还受调控：磷酸化使复合体失活（Ca²⁺ 激活磷酸酶去磷酸恢复活性），把辅因子动力学与酶活性调节（本专题第 9 篇）连成一体。硫辛酸缺乏或砷中毒（砷与硫辛酰胺结合）都会让这条装配线停摆。</span>

### 术语速查：这一篇的「部件清单」

| 术语 | 一句话定义 |
| --- | --- |
| 全酶 | 脱辅基酶蛋白 + 辅因子组成的完整活性单位 |
| 辅因子 | 酶活性必需的非蛋白组分（金属离子或有机辅酶 / 辅基） |
| 辅酶 | 与酶松散结合、随反应进出、可被多种酶共享的有机辅因子 |
| 辅基 | 与酶共价或紧密结合、钉在酶上的辅因子 |
| 脱辅基酶蛋白 | 去掉辅因子后仍保持专一性、但丧失催化活性的蛋白部分 |
| 金属酶 | 金属与酶紧密结合且必需的酶 |
| 金属激活酶 | 金属仅松散结合、起辅助作用的酶 |

这一串名字最大的陷阱是「辅酶 vs 辅基」与「金属酶 vs 金属激活酶」两对概念——判定标准分别落在「能否随产物脱离」与「洗掉金属是否失活」上，**记住判据比记住名字更重要**。

## 5 小结

- 结合酶 = **脱辅基酶蛋白 + 辅因子（金属离子 / 辅酶 / 辅基）**；辅酶可随反应脱离，辅基钉在酶上。
- 维生素是辅酶前体：**NAD/NADP（氢）、FAD/FMN（氢）、CoA（酰基）、TPP（醛基）、PLP（氨基）、生物素（CO₂）、THF（一碳）、钴胺素（甲基）**。
- 辅酶以**成对氧化态循环**周转，是「通用货币」；酶规定了搬运的立体专一性。
- 丙酮酸脱氢酶复合体用 5 种辅因子接力完成一次氧化脱羧，是多辅酶流水线的范本。

在下一节，我们把视野从「酶怎么催化」拉回「细胞怎么指挥酶」——**酶活性调节**：别构、共价修饰与酶原激活。
