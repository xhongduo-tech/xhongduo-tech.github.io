# 学校体育与健康课程（体育课程体系、国家学生体质健康标准）

学校体育与健康课程是促进学生身心健康、社会适应与终身体育能力形成的基础性课程，以《义务教育体育与健康课程标准》和国家学生体质健康标准为双重体系依据。从课程理念、教学内容与教学方法，到体质测试、运动干预与课堂实施，系统掌握学校体育从课程标准到教学落地再到体质评价的完整闭环，是体育教师与健康教育工作者必备的专业基础。

## 对标教材

- 中华人民共和国教育部《义务教育体育与健康课程标准（2022年版）》（北京师范大学出版社）
- 中华人民共和国教育部《国家学生体质健康标准（2014年修订）》（教育部制定）
- 毛振明《体育教学论》（高等教育出版社）
