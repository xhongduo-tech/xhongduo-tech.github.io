## 两个形状撞没撞上

**碰撞检测（collision detection）**问：「两个物体是否重叠/接触？」它是物理引擎、电子游戏、机器人、CAD 装配检查、分子模拟的共同底层。本节讲它的核心骨架：**两阶段流水线**（宽相位 + 窄相位）、**包围体**、**分离轴定理（SAT）**与 **GJK 算法**。<span class="marginnote">碰撞检测的工业实践有一条铁律：<strong>先粗后精</strong>。世界里有成百上千物体，直接两两精测是 $O(n^2)$ 灾难；于是先用便宜的「宽相位」筛掉绝大多数「显然不碰」的对，只对幸存者做昂贵的「窄相位」精确判定。这个「粗筛 + 精判」的两层结构，与扫描线求交「只查相邻」、数据库「先索引后过滤」是同一种工程智慧。</span>

## 1 宽相位：先把显然不碰的扔掉

**宽相位（broad phase）**用粗糙但便宜的几何体快速排除不可能碰撞的物体对：

**均匀网格**：把世界切成格子，物体注册到覆盖的格子里；只测「同一格子里」的物体对。
**扫掠剪枝（sweep and prune）**：把物体投影到各轴上，用区间重叠快速排除；最常用 AABB 在 $x$ 轴的区间排序，滑动窗口检查重叠。
**空间索引**：四叉树 / R 树（「空间索引」一讲）把物体按位置组织，查询「我的邻居是谁」$O(\log n + k)$。

宽相位的目的不是「判定碰撞」，而是**把候选对数从 $O(n^2)$ 降到接近线性**。它允许「假阳性」（把不相撞的也放进来），但不能有「假阴性」（绝不能漏掉真正相撞的）。

## 2 窄相位：精确判定

**窄相位（narrow phase）**对宽相位放行的候选对做精确测试。为加速，几乎总是先做**包围体（bounding volume）**测试，再精确到凸包：

**AABB（轴对齐包围盒）**：轴对齐矩形，重叠测试 = 各轴区间相交，$O(1)$、无乘法（仅比较）。
**包围球**：球心距 ≤ 半径和，$O(1)$。
**OBB（有向包围盒）**：跟随物体旋转的盒子，更紧但测试更贵（SAT）。
**凸包**：最紧，测试最贵（GJK）。

层次策略：**先用最便宜的包围体快速拒绝，再用更紧的几何体收窄，最后精确到形状表面**。物理引擎里这个「由粗到精」链条每层都能拒绝一大批。

## 3 分离轴定理：SAT

**分离轴定理（Separating Axis Theorem, SAT）**：两个**凸**形状不相交，当且仅当存在一条轴，使它们在轴上的**投影区间不重叠**。

判定「相交」变成「找一条分离轴」：对所有候选轴检查投影区间是否重叠；都重叠则相交，否则分离。
对两个凸多边形，候选轴只需取**两个多边形的所有边的法向**——有限个，检查完即可。
复杂度：$O(n + m)$ 条候选轴，每条 $O(n+m)$ 投影，总 $O((n+m)^2)$。对少量顶点的凸多边形（三角形、矩形）是 $O(1)$ 级别，极快。<span class="marginnote">SAT 的正确性来自凸集的强分离定理：两个凸集不相交，则存在一条分离线（它们的支撑函数能分开）。「分离轴」就是这条分离线的法向，而它一定平行于某个多边形边的法向——所以有限枚举就够了。这又是「凸性 → 有限验证」的案例，与凸多边形性质一讲的思想一脉相承。</span>

**投影区间重叠的判定**：把每个顶点投影到轴 $\vec{n}$ 上，取最小最大得区间 $[a_{\min}, a_{\max}]$；两区间重叠 ⟺ $a_{\min} \leq b_{\max}$ 且 $b_{\min} \leq a_{\max}$。

## 4 公式解析：投影与区间重叠

SAT 的核心计算是把形状投影到候选轴上：

$$
\text{proj}(P, \vec{n}) = \left[\ \min_{v \in P} (v \cdot \vec{n}),\ \max_{v \in P} (v \cdot \vec{n})\ \right]
$$

拆解四步：

- **第一步，点的投影**：顶点 $v$ 在单位轴 $\vec{n}$ 上的投影是点积 $v \cdot \vec{n}$。投影的几何意义是「沿轴方向的坐标」。
- **第二步，形状的投影**：凸多边形的投影是一个区间 $[a_{\min}, a_{\max}]$，因为凸多边形在任意方向上的投影是连通的（凸集的投影仍是凸集，一维凸集即区间）。
- **第三步，重叠判定**：两形状不相交 ⟺ 存在轴使 $a_{\max} < b_{\min}$ 或 $b_{\max} < a_{\min}$。检查全部候选轴，若某轴满足则「已分离」可提前返回。
- **第四步，候选轴集合**：对凸多边形，只需检查「每条边的法向」——共 $n + m$ 条。非凸形状不适用（投影可能不连通），须先凸分解。

SAT 是一个「找反例」的算法：**只要找到一条分离轴就否定相交，找遍全部轴才确认相交**。这个「反证式」结构让它平均很快、最坏也有界。

## 5 GJK 算法：凸形状的通用检测

**GJK（Gilbert–Johnson–Keerthi, 1988）**是更现代、更适合任意凸形状（多边形、多面体）的窄相位算法。它不直接测形状相交，而是用**闵可夫斯基差**：

$$
A \ominus B = \{\, a - b \mid a \in A,\ b \in B \,\}
$$

**$A$ 与 $B$ 相交 ⟺ 原点 $O$ 属于 $A \ominus B$。** GJK 迭代地在 $A \ominus B$ 里构造一个「越来越靠近原点」的单纯形（点、线段、三角形），若原点被单纯形包含则相交，否则沿「最靠近原点」的方向找支撑点推进。<span class="marginnote">GJK 的精妙在于它从不显式构造闵可夫斯基差——那可能非常复杂。它只通过「支撑函数」查询：给定方向 $\vec{d}$，返回 $A$ 在该方向上最远的点。对凸形状，支撑点用「最大化 $v \cdot \vec{d}$」即可，$O(n)$ 一次。这个「按需查询 + 迭代逼近」让 GJK 同时适用于三角形和光滑凸体（圆、胶囊），是物理引擎（Box2D、Bullet）的默认选择。</span>

GJK 的迭代每一轮都保证进步（原点被单调靠近），最多迭代次数由单纯形维度决定，实际常数小。它返回的距离还能直接用于「穿透深度」计算，是物理响应（推开、反弹）需要的量。

## 6 多层检测的完整流水线

一个工业级碰撞检测系统的完整链条：

```
宽相位（空间划分 / 扫掠剪枝 / R 树）    # 排除明显不相交的对，$O(n^2)$ → 近线性
  → 包围体测试（AABB / 包围球 / OBB）   # $O(1)$ 快速拒绝
    → SAT 分离轴定理（低顶点凸片）       # 投影区间重叠判定
      → GJK 闵可夫斯基差（任意凸形状）  # 支撑函数迭代逼近
        → 精确测试                      # 返回穿透深度 / 接触点
```

每层都只是「筛掉更多」，真正的最终判定在最里层。**优化的核心永远是「让昂贵的检测尽可能少地被调用」**——这与整个计算几何的「剪枝」哲学一致。

### 辨析：凹形状必须先凸分解

**辨析｜易错点：** SAT 与 GJK 都**只对凸形状成立**。对凹多边形直接套用，会得到错误答案——比如两个互相「咬合」的凹多边形，形状确实相交，却可能找不到任何分离轴，误判为不相交。

**为什么 SAT 只对凸成立**：凹形状在某个方向上的投影可能不连通（一个凹口把投影「劈」成两段），「投影区间重叠」与「形状相交」的等价性就被破坏了。

**工业做法是「凸分解（convex decomposition）」**：把凹多边形切成若干凸片（三角形、凸多边形），然后：

1. 对每一对凸片做 SAT / GJK；
2. 任意一对相交则整体相交。

| 方法 | 分解方式 | 凸片数量 |
| --- | --- | --- |
| 三角剖分 | 切成三角形 | $n-2$ 个 |
| 凸分解（Hertel–Mehlhorn） | 合并为尽量大的凸片 | 最多 $3n/2 - 2$ 个 |

**凸分解是碰撞检测的前置工程**：物理引擎（Box2D、Bullet）要求用户把复杂形状手动分解成凸片，正是为了能安全使用 GJK。这也是为什么「多边形三角剖分」一讲是碰撞检测的隐藏前置。

**另一个易错点：穿透深度的方向**。GJK 给出的是「闵可夫斯基差里原点离边界最近的距离」，它是**穿透的度量**，但不是「推开方向」的完备答案——物理引擎还会用「最近点」或「分离向量」进一步计算。别把「检测」当「响应」。

<span class="marginnote"><strong>分层策略回顾</strong>：宽相位（网格/R 树）→ 包围体（AABB 球）→ SAT（低顶点凸片）→ GJK（任意凸片）。每层都拒绝一批，只有最内层做最贵的精确计算——这就是碰撞检测性能的全部秘密。</span>

## 7 小结

- 碰撞检测两阶段：**宽相位**（粗筛，允许假阳性）+ **窄相位**（精确，不许假阴性）。
- **包围体**：AABB、包围球 $O(1)$ 测试，OBB 更紧更贵；由粗到精逐层收窄。
- **SAT**：凸形状不相交 ⟺ 存在分离轴使投影区间不重叠；候选轴取各边法向，$O((n+m)^2)$。
- 投影区间公式 $\text{proj}(P, \vec{n}) = [\min v\!\cdot\!\vec{n},\ \max v\!\cdot\!\vec{n}]$ 是 SAT 的核心。
- **GJK** 用闵可夫斯基差 + 支撑函数迭代判定，兼容任意凸形状，返回穿透深度。
- 工业流水线 = 宽相位 → 包围体 → SAT → GJK → 精确测试，层层剪枝。

在下一节，我们把「空间组织」系统化：**空间索引**——四叉树、R 树与格网，让「谁在我的邻域」变成一次快速查询。
