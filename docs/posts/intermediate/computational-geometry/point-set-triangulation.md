## 点集剖分与多边形剖分的差别

上一节的多边形剖分有个固定边界：先把多边形本身切成三角形，顶点就是多边形的顶点。**点集三角剖分（point-set triangulation）**的问题不同：平面上散布着 $n$ 个点，没有预先给定的边界，问如何用不相交的线段把它们连成一个**三角形网格**。<span class="marginnote">这个问题的应用无处不在：有限元分析的网格剖分、地形模型的 TIN 构建、散点数据的插值基底、无线传感网的三角覆盖。剖分的质量直接影响数值求解的误差，因此「怎么切」比「能不能切」更重要——这正是下一讲 Delaunay 剖分的动机。</span>

## 1 最大平面直线图

**三角剖分（point-set）**：一个平面直线图（planar straight-line graph，顶点集为 $P$，边为不交叉的线段），是**最大的**——无法在不产生交叉的前提下再加入任意一条边。最大性意味着每个有界面都是三角形。

为什么要「最大」？因为我们要的是「铺满」：内部不能有能继续加边的空洞。一个最大平面直线图满足：

凸包边界上的每条边都在图中；
凸包内部被三角形完全覆盖；
没有两条边交叉。

从凸包（$h$ 个顶点）开始，内部任意加一条不交叉的边，就会把某个区域一分为二；最终所有区域都变成三角形时达到最大。<span class="marginnote">最大平面直线图的称呼来自图论：一个连通的平面图若所有面都是三角形，称「三角剖分」。这里的「面」是平面图划分出的区域，包括凸包外部那个无限面——图论与几何术语在这里精确地衔接上了。</span>

## 2 剖分里有多少三角形

点集剖分的三角形数量同样由计数决定。设点数为 $n$，凸包顶点数为 $h$。剖分后记顶点数 $V = n$，边数 $E$，面数 $F$（含外部无限面）。两个守恒：

- **边数按面**：每个三角形面贡献 3 条边，内部边被两个面共享。设 $T$ 为三角形个数，则 $3T = 2E - h$（凸包边只属于一个三角形面）。
- **欧拉公式**：$V - E + F = 2$，而 $F = T + 1$。

联立解出：

$$
T = 2n - h - 2, \qquad E = 3n - h - 3
$$

与多边形剖分的 $n-2$ 不同，点集剖分的三角形数**依赖凸包顶点数 $h$**。直觉：凸包越「鼓」，内部点相对越少，三角形越少；凸包是三角形（$h = 3$）时 $T = 2n - 5$，凸包巨大时 $h$ 接近 $n$，$T$ 接近 $n - 2$。<span class="marginnote">对比上一讲：多边形剖分把「边界已定」的 $n$ 边形切成 $n-2$ 个三角形；点集剖分把「边界自由」的 $n$ 个点铺成 $2n-h-2$ 个三角形。两者同用欧拉公式，却因边界自由度不同而给出不同计数——这是「边界信息 = 信息量」的直观证据。</span>

## 3 边翻转：从一种剖分到另一种

点集剖分不唯一，甚至指数级多。但不同的剖分之间有一条「桥」——**边翻转（edge flip）**。

考虑剖分里的一条内部边 $e = \overline{ab}$，它属于两个相邻三角形 $\triangle abc$ 与 $\triangle abd$。这四个点构成一个四边形 $a c b d$（以 $e$ 为对角线）。若该四边形是**凸的**，我们可以把对角线换成另一条 $\overline{cd}$，得到一个新的合法剖分——这就是一次边翻转。<span class="marginnote">边翻转像是剖分空间里的「一步」：它保持顶点集合、凸包边界不变，只改变内部的连接方式。任意两个点集剖分之间都可以通过有限次边翻转互相到达——这个事实保证了「从任意剖分出发，一路翻到最优」的可行，是下一讲 Lawson 翻转算法的基石。</span>

翻转的合法性判断：$\overline{cd}$ 不能与任何现有边交叉。若四边形 $a c b d$ 非凸（$c$ 或 $d$ 在对方三角形内部），$\overline{cd}$ 会穿出四边形，翻转非法。

## 4 剖分质量的度量：角度向量

既然剖分不唯一，「哪个剖分更好」就需要度量。经典的度量是**角度向量（angle-vector）**：

把剖分中所有 $T$ 个三角形的 $3T$ 个内角从小到大排成一列 $\alpha_1 \leq \alpha_2 \leq \dots \leq \alpha_{3T}$。比较两个剖分 $A, B$：

若存在下标 $i$ 使 $\alpha_j^A = \alpha_j^B$（$j < i$）且 $\alpha_i^A > \alpha_i^B$，则说 $A$ **角优于** $B$。

直觉：**最小的角越大越好**——三角形越「胖」，数值上越稳。瘦长三角形（一个角接近 180°、两个角接近 0°）在有限元里是灾难，插值误差大。这直接引出下一讲的核心结论：**在所有三角剖分中，Delaunay 剖分使最小角最大化**。

## 5 公式解析：一次翻转的角度效应

边翻转为什么会改善角度质量？看公式如何保证。翻转前后，四边形 $a c b d$ 的六个内角（两三角形的内角之和）是**不变的**——两种剖分覆盖同一四边形，内角和恒为 $360^\circ$，四边形的四个「外角」也各是两个相邻三角形角之和。变化的是**分配**：翻转把两个角的组合换成了另一种组合。

设翻转前两三角形在边 $ab$ 处的角为 $x_1, x_2$，翻转后在边 $cd$ 处的角为 $y_1, y_2$。关键是角的大小比较：

由**圆周角定理（Thales 型）**：若 $c, d$ 在直线 $ab$ 同侧，$\angle acb$ 与 $\angle adb$ 满足「谁对应的圆弧更大谁更大」；若 $c, d$ 之一落入过 $a, b, c$ 三点的外接圆内，翻转会增大最小角。
因此判据：**若点 $d$（或 $c$）落在另三点外接圆内，则翻转 $ab \to cd$ 严格改善角度向量**——最小角不减小，且至少一个角变大。

这个「**空圆**」判据是 Delaunay 剖分的灵魂：一条边是「合法」的（不应翻转），当且仅当它的两个相邻三角形的外接圆都不含第四个点。下一讲我们正式命名它。

## 6 约束剖分

很多应用需要剖分**穿过指定线段**——比如地形建模时，河流、道路必须作为剖分边保留。这要求**约束三角剖分（constrained triangulation）**：给定一组不交叉的约束边，构造包含它们的最大平面直线图。

方法通常分两步：

先构造不含约束的剖分；
再逐条把约束边插入——若约束边不在图中，用边翻转「推进」它：反复翻转与其交叉的边，直到约束边成为剖分的一部分。

约束 Delaunay 剖分（CDT）是工程标准，GIS 与有限元里的「带障碍剖分」都建立在它之上。

### 辨析：h 的作用与退化输入

**辨析｜易错点：** 三角形数 $T = 2n - h - 2$ 里那个 $h$（凸包顶点数）常被忽略，但它决定了「边界信息量」对剖分规模的贡献。

$h$ 越大，凸包越「贴」着点集，内部点相对越少，三角形越少；
极端情况：全部点都在凸包上（$h = n$），$T = 2n - n - 2 = n - 2$——退化回多边形剖分的公式；
若误用「$2n - 5$」（凸包是三角形的特例），会高估三角形数，误导存储预算。

| 情形 | $h$ | $T = 2n-h-2$ |
| --- | --- | --- |
| 凸包为三角形 | 3 | $2n - 5$ |
| 一半点在凸包上 | $n/2$ | $\frac{3}{2}n - 2$ |
| 全部在凸包上 | $n$ | $n - 2$ |

**退化输入：四点共圆**。Delaunay 剖分的唯一性在四点共圆时失效（外接圆上四个点，剖分有歧义）。工程处理：用**退化情形**时的符号扰动（数值稳健性一讲）打破平局，得到「某个一般位置输入」的确定剖分。

**边翻转的另一个限制**：翻转只对**凸四边形**有意义。若四点组成非凸四边形（一点在另三点三角形内），对角线换向会穿出——翻转非法，必须跳过。误翻非凸四边形是三角剖分实现里最隐蔽的 bug。

<span class="marginnote"><strong>对账习惯</strong>：写完剖分后数三角形：$T$ 应等于 $2n-h-2$，$E$ 等于 $3n-h-3$。两个不变量同时对不上，几乎必然是「有边交叉没查出来」或「凸包边没闭合」。</span>

**为什么要分「多边形剖分」与「点集剖分」两讲**：两者的计数公式不同（$n-2$ vs $2n-h-2$）、输入不同（边界固定 vs 边界自由）、算法不同（耳切 vs 翻转/增量）。但共享同一个工具——欧拉公式，以及同一个目标——三角形。理解了两者的差异，Delaunay 剖分（点集剖分的最优选择）就顺理成章。

**对账方法**：写完剖分后数三角形数，与 $2n-h-2$ 对照，是最便宜的自测。

## 7 小结

- 点集三角剖分是**最大平面直线图**：内部全部铺成三角形，不能再加边。
- 三角形数 **$T = 2n - h - 2$**、边数 $E = 3n - h - 3$，由欧拉公式给出，依赖凸包顶点数 $h$。
- 不同剖分之间靠**边翻转**互相连通，翻转合法性由「不交叉」判定。
- 剖分质量用**角度向量**度量，最小角越大越好——瘦长三角形是数值灾难。
- 「点落入外接圆」是判断边是否该翻转的**空圆判据**，也是 Delaunay 剖分的前奏。
- **约束剖分**保证指定线段成为剖分边，是 GIS 与有限元的标准配置。

在下一节，我们给「好剖分」一个精确的名字和完整理论：**Delaunay 三角剖分**——最小角最大的那一个。
