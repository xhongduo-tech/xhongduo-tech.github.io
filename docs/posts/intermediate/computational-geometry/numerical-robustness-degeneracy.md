## 从「理论正确」到「代码正确」

全专题 29 讲，所有算法都建立在几个谓词上：`orient`（三点转向）、`incircle`（四点共圆/内外）、`on_segment`（点在线段上）。理论世界假设输入是**一般位置（general position）**——没有三点共线、没有四点共圆、没有三线共点。但真实输入**永远**带退化，浮点计算**永远**有误差。于是最后这一讲回答全专题的元问题：**如何让几何代码在真实机器上不「翻车」？**<span class="marginnote">一个经典事故：扫描线求交算法里，两个交点本该重合，因浮点误差差出 $10^{-16}$，导致状态结构里的顺序错乱、事件重复、甚至死循环。「理论正确、实现崩溃」是几何代码的常态。业界两条路线：<strong>稳健谓词</strong>（让符号判定在浮点上尽量正确）与<strong>精确算术</strong>（用有理数/任意精度彻底消除误差）。两条路线今天都讲。</span>

## 1 浮点几何的问题

IEEE 754 双精度不是实数域。几何代码踩的坑主要有三类：

- **舍入误差**：`0.1 + 0.2` 不等于 `0.3`；叉积中的减法会把相近的大数「消」掉，符号翻转。
- **灾难性消去（catastrophic cancellation）**：$\text{orient}$ 的计算 $x_1 y_2 - x_2 y_1$，若四项量级相近而符号相反，结果的小值完全由舍入决定——**真正的符号被噪声淹没**。
- **不一致性**：同一个点在两个谓词里被算成「略左」和「略右」，导致「点同时在线两侧」的逻辑矛盾，破坏平面图的一致性（DCEL 撕裂）。

核心认识：**几何算法的失败往往不是「数值有点不准」，而是「符号判错导致拓扑错乱」**——谓词输出 0 附近时，任何符号都不该轻信。

## 2 稳健谓词：orient 的误差分析

**稳健谓词（robust predicate）**的目标：**让 `orient`、`incircle` 的符号尽量与真实数学一致**。第一步是误差分析。

`orient(p,q,r)` 计算两个乘积之差：

$$
D = (q_x - p_x)(r_y - p_y) - (q_y - p_y)(r_x - p_x)
$$

浮点下每个乘、减都引入相对误差。设 $\epsilon$ 为机器精度（双精度 $\approx 2.2 \times 10^{-16}$），一次运算的相对误差 $\leq \epsilon$。经过几次运算，$D$ 的误差界约为：

$$
|D_{\text{float}} - D_{\text{exact}}| \leq \gamma_k \cdot |D_{\text{exact}}| \approx k\epsilon \cdot |D_{\text{exact}}|
$$

（$\gamma_k = \frac{k\epsilon}{1 - k\epsilon}$，$k$ 为运算次数）。

于是判据是：**若 $|D_{\text{float}}|$ 远大于误差界，符号可信；若 $D_{\text{float}}$ 落在误差带内，必须用更精确的方法重算**。<span class="marginnote">这个「快路径 + 慢路径」是自适应精度的灵魂：<strong>大多数查询远离退化，双精度直接判；只有接近 0 的极少数情况才动用昂贵的高精度展开</strong>。实测中，几何算法里「接近退化」的谓词调用占比很小（通常个位数百分比），所以自适应版本几乎不慢——却把错误率从「经常」降到「几乎不可能」。</span>

## 3 Shewchuk 的自适应精度谓词

Shewchuk（1997）把上述思想工程化为 `orient2d`、`incircle`、`orient3d`、`insphere` 的经典实现：

1. **快路径**：双精度算 $D$，同时算误差界 $\text{errbound}$。
2. **判定**：若 $D > \text{errbound}$ 或 $D < -\text{errbound}$，直接返回符号——绝大多数情况。
3. **慢路径**：否则用**无误差变换**（Two-Product、Two-Sum）把每个乘积/和拆成「高分量 + 误差分量」，用**扩展精度算术**逐项求和，得到 $D$ 的更高精度表示（甚至精确）。
4. **最终保证**：对 `orient2d`，只要输入是双精度，实现保证**返回的符号与精确结果完全一致**——除非精确结果本身就是 0（此时返回 0，留给上层处理退化）。

关键技术是 **Two-Product / Two-Sum 无误差变换**：用 Dekker 拆分，让浮点乘法的精确误差被单独保存。这些原语把「浮点运算」升级成「几乎精确的运算」，代价只是多几次浮点乘加。

## 4 公式解析：无误差变换与误差带

两个原语撑起整个稳健谓词。**Two-Sum**（把 $a+b$ 拆成精确值 $s$ 与误差 $e$）：

$$
s = a \oplus b, \qquad e = ((a \ominus s) \oplus b) \oplus (a \ominus (s \ominus b))
$$

拆解四步：

- **第一步，目标**：浮点加法 $s = a \oplus b$ 有舍入误差，但我们想要「精确的 $a+b$」。Two-Sum 输出 $(s, e)$，满足 $a + b = s + e$ **精确成立**（$e$ 是被舍掉的部分）。
- **第二步，分解的直觉**：$e$ 是「$a$ 超出 $s$ 的部分」与「$b$ 超出 $s$ 的部分」的补偿。公式里两次「$a \ominus$」是浮点减法，借助 IEEE 舍入性质（Sterbenz 引理附近），误差能被精确捕获。
- **第三步，Two-Product**：把浮点乘法 $p = a \otimes b$ 拆成 $(p, e)$，满足 $ab = p + e$ 精确。用 FMA（fused multiply-add）一次即可：`e = fma(a, b, -p)`——现代 CPU 的 FMA 指令让它几乎免费。
- **第四步，如何用**：`orient` 的四个乘积各自做 Two-Product，再逐层 Two-Sum 求和，得到 $D$ 的高精度表示。误差带 $\text{errbound}$ 则由「各项绝对值的和 × 常数」给出——只要 $|D| > \text{errbound}$，符号就必然正确。

**一句话**：无误差变换把「浮点算术」变成「带误差补偿的算术」，让误差带可以被精确界定，让「符号是否可信」变成一次比较。

## 5 精确算术：另一条彻底的路

稳健谓词解决「符号尽量对」，**精确算术**要求「完全对」。两条实现：

- **任意精度有理数**：所有坐标用有理数（分子分母任意精度整数）表示，`orient` 变成精确整数运算。**符号绝对正确**，但运算慢一个数量级以上（大整数乘法）。
- **扩展精度浮点（如 CGAL 的 `Exact_predicates_exact_constructions`）**：谓词用精确整数、构造用浮点，兼顾「判得准」与「跑得快」。CGAL 全套几何库正是建立在这套「谓词精确 + 构造近似」的策略上。

精确算术的代价是性能，但换来的确定性极其珍贵：**同一输入永远给出同一结果，可复现、可验证**。在 CAD、GIS 这类「错了就要命」的领域，值得。

## 6 退化处理：符号扰动

即使谓词精确，**退化输入本身**（三点共线、四点共圆）也需要策略。经典的统一方案是**符号扰动 / 模拟一般位置（simulation of simplicity）**：

给每个坐标加一个**无穷小扰动**：$p_i = (x_i + i\epsilon, y_i + i\epsilon^2)$（$\epsilon$ 为形式无穷小，按字典序分配）。共线的三点在扰动后「微弯」，四点共圆在扰动后「微偏」——**退化被系统性地打破，且不影响最终组合结果**。

关键性质：

- 扰动是**符号层面的**，无需真的加数——谓词里用「比较坐标的字典序」实现。
- 结果对扰动方式一致：只要所有谓词用同一套扰动规则，得到的拓扑结构就是「某个一般位置输入」的拓扑，合理且可复现。
- 经典实现：**Seidel 的符号扰动**、Edelsbrunner 的 SoS。工程上常在谓词层包装「共线时按字典序处理」的 fallback。

退化处理的另一务实路线是**显式分支**：每个谓词输出 0 时，上层走专门的退化代码路径（如 Graham 扫描里共线去重、三角剖分里重叠边处理）。显式分支直白但易漏，符号扰动自动但需统一——两者常结合使用。

### 辨析：容差 epsilon 的陷阱

**辨析｜易错点：** 很多人处理浮点几何的第一反应是「加个 epsilon 容差」——`if (|D| < eps) 当作 0`。这个思路有两个反直觉的坑：

- **epsilon 是全局的，误差是局部的**：几何的数值误差随坐标量级、运算链长度变化。一个固定 `1e-9` 的容差，对「世界坐标上万」的数据太小、对「单位坐标」的数据又太大，无法一刀切。
- **容差会破坏拓扑一致性**：A 谓词把两个点判为「重合」，B 谓词却因为另一套容差判为「分离」——两个独立判断互相矛盾，平面图照样撕裂。

**比固定容差更可靠的三个替代**：

| 方案 | 思路 | 代价 |
| --- | --- | --- |
| 稳健谓词（Shewchuk） | 精确符号 + 自适应精度 | 快路径几乎免费 |
| 精确算术（有理数 / CGAL） | 彻底无误差 | 慢一个量级 |
| 符号扰动 | 打破退化、统一规则 | 需要全局一致 |

**什么时候可以放心用容差**：纯数值问题（不是拓扑判定）——比如「这个距离是否小于阈值」的物理判断、聚类半径、渲染剔除。**凡是要靠符号决定结构（谁在谁的左侧、是否相交）的地方，别用固定容差**。

**最后一个建议**：把「几何谓词」与「数值容差」**分层隔离**——谓词层只输出 $-1/0/+1$ 的确定性符号，上层才谈容差。这样即使容差策略要改，也只需要改一个薄层，不会污染全库。

<span class="marginnote"><strong>全专题收官心法</strong>：三十讲里反复出现的「谓词优先」「符号比数值重要」「退化要有出口」——这三句话是所有几何代码的共同地基。带着它们进入图形学、优化与算法设计，你会有比别人少踩一半坑的体感。</span>

## 7 小结

- 浮点几何的三类坑：**舍入误差、灾难性消去、不一致性**；失败常表现为拓扑错乱而非数值偏差。
- **稳健谓词**：快路径（双精度 + 误差带）判定符号，接近 0 才走慢路径。
- **自适应精度**：大多数调用双精度直接判，退化附近才用精确展开——几乎不慢、几乎不错。
- **无误差变换**（Two-Sum / Two-Product）是精确展开的原子操作，FMA 让它近乎免费。
- **精确算术**（有理数 / CGAL 策略）完全消除误差，用性能换确定性。
- **退化处理**：符号扰动（模拟一般位置）系统打破共线/共圆，显式分支兜底。
- 全专题的每一条算法，最后都站在这层稳健性地基上——**「谓词优先、符号比数值重要、退化要有出口」**是计算几何代码的三大心法。
