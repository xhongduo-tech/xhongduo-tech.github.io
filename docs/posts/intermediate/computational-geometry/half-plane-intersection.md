## 一撮不等式的几何

一个**半平面（half-plane）**是直线一侧的全部区域：$y \geq mx + c$（或 $\leq$）。**半平面交（half-plane intersection）**问：给定 $n$ 个半平面，求它们的公共区域。它是一组线性不等式 $\mathbf{a}_i \cdot x \geq b_i$ 的几何化身——**每一条线性约束就是一刀，把所有刀切完剩下的区域，就是线性规划的可行域**。<span class="marginnote">半平面交的实用场景极其广泛：多边形裁剪（图形学里的 Sutherland–Hodgman）、线性规划的可视化、可行域的几何构造、甚至「求一片区域同时满足多个方向约束」的几何建模。它与凸包互为对偶（上一讲），与 2 维线性规划是同一枚硬币的两面。</span>

## 1 结构：交出来的一定是凸集

半平面交有几个基本的结构事实：

- **交是凸集**：半平面是凸集，凸集的交是凸集。所以答案是一个**凸多边形**（可能是空的、无界的、甚至退化为点或线段）。
- **边界**：交多边形的每条边来自某个输入半平面的边界直线。
- **空交**：约束互相矛盾时交为空（如 $x \geq 0$ 与 $x \leq -1$）。

「凸」这个事实让半平面交可以用**凸多边形**表示，而两个凸多边形的交可以用线性时间求出（两个多边形求交 $O(n+m)$，见「凸多边形性质」一讲）——这是分治算法的基础。

## 2 分治算法：O(n log n)

**分治**是构造半平面交的经典路线：

1. 把 $n$ 个半平面平均分成两半，递归求各自的交 $H_1, H_2$（都是凸多边形）。
2. **线性合并**：求两个凸多边形的交 $H = H_1 \cap H_2$。

合并两个凸多边形用「平面扫描」：沿着边界走，维护「同时在前一个多边形内部和另一个多边形内部」的边界段。因为凸多边形的边有序，双指针可在 $O(|H_1| + |H_2|)$ 内完成。

递推式 $T(n) = 2T(n/2) + O(n)$，解得 **$O(n\log n)$**。<span class="marginnote">分治合并的两个凸多边形交，本质上就是在解「两个凸多边形是否相交 + 相交区域」——这让我们回到了「凸多边形性质」一讲的双指针扫描。计算几何的知识真的是一层叠一层：每个新问题都在调用前面讲过的原语。</span>

## 3 增量算法：O(n²) 与随机化加速

另一种思路是**增量**：一个半平面一个半平面地加进来，维护当前交 $H$。每加一个半平面 $h$：

- 若 $H$ 完全落在 $h$ 内，不变；
- 否则求 $H$ 与 $h$ 边界直线的两个交点，沿边界裁剪掉 $h$ 外侧的部分。

朴素增量最坏 $O(n^2)$——每次裁剪都可能扫过当前多边形全部边。但**随机化**让期望降到 $O(n\log n)$：若半平面随机排列，当前交的平均大小 $O(\log n)$，总期望 $O(n\log n)$。<span class="marginnote">随机化增量（randomized incremental construction, RIC）是计算几何的通用加速术：把输入打乱顺序逐个插入，让「结构平均很小」的概率性质压低期望复杂度。它同时适用于 Delaunay 剖分、梯形图点定位等一批算法——同样的思想，处处开花。</span>

## 4 公式解析：半平面求交的多边形表示

设第 $i$ 个半平面为 $a_i x + b_i y \geq c_i$。半平面交的多边形表示依赖「哪两条边界线在哪个顶点相交」：

$$
H = \bigcap_{i=1}^{n} \{\, (x,y) \mid a_i x + b_i y \geq c_i \,\}
$$

拆解四步：

- **第一步，边界线**：每条不等式对应一条直线 $a_i x + b_i y = c_i$，法向量 $(a_i, b_i)$ 指向半平面内侧。多边形顶点是两条边界线的交点。
- **第二步，交点参数**：两条线 $L_i, L_j$ 的交点 $(x^*, y^*)$ 由二元一次方程组解得；若法向量平行（$a_i b_j = a_j b_i$），两半平面边界平行——要么一个包含另一个，要么二者矛盾（空交）。
- **第三步，顶点合法性**：交点 $(x^*, y^*)$ 是 $H$ 的顶点当且仅当它满足**所有**其他半平面不等式（落在每个半平面内）。否则该交点被某条约束排除，不是顶点。
- **第四步，有序边界**：顶点按「绕 $H$ 一圈」排列；判断「是否在 $H$ 内」用逐条边叉积符号（凸多边形点包含测试）。当 $n$ 较大时，先排序极角或先求凸包可避免 $O(n^2)$ 的合法性检查。

## 5 半平面交 = 2 维线性规划

2 维线性规划：在线性约束（半平面）下最优化线性目标 $\max c_x x + c_y y$。几何意义是**沿方向 $(c_x, c_y)$ 推一条支撑线，推到可行域的最远顶点**。

- 若可行域（半平面交）非空有界，最优解在某个**顶点**上（线性规划基本定理的几何版）；
- 求最优解 = 在半平面交的顶点里找「方向最远」的。

这给了求解 2 维 LP 的几何算法：增量地求半平面交，同时追踪最优点。**Seidel 的随机化算法**处理 $n$ 个约束只需 $O(n)$ 期望时间——比一般的 $O(n\log n)$ 还快，因为求「方向最远」比求「完整交多边形」更省。

**半平面交与线性规划在 2 维是一回事**：会一个，就会另一个。这对理解线性规划的几何直觉极有帮助——约束是墙，目标方向是力，最优解撞在墙上的某个角。<span class="marginnote">「约束是墙」的直觉可以一直推广到高维线性规划（单纯形法就是沿墙的角走）。而半平面交给我们一个看得见摸得着的 2 维窗口，是学习单纯形、对偶理论之前最直观的入场券。后面学最优化理论时，回来再看这一节会有新的收获。</span>

## 6 应用

- **线性规划可视化**：把约束与目标画出来，直接看可行域。
- **多边形裁剪**：把窗口当成一组半平面，依次裁剪多边形（Sutherland–Hodgman 正是这样）。
- **可见区域**：求「站在某点能看见的区域」时，遮挡关系可以归约为半平面交。
- **最小圆 / 多边形逼近**：约束集合的可行性判定。
- **对偶世界的凸包**：上一讲的「直线集下包络」即对偶半平面交。

### 辨析：空交与无界区域的判定

**辨析｜易错点：** 半平面交有三种结局——**凸多边形、无界区域、空集**，前两种容易被混淆，第三种最容易漏判。

**无界 ≠ 空。** 半平面 $x \geq 0$ 与 $x \leq 10$ 的交是 $[0,10]$ 有界；但 $x \geq 0$ 与 $y \geq 0$ 的交是第一象限，**无界**——它是合法的、非空的可行域。判断有界性：凸多边形的每条边对应的法向必须「各个方向都有」；若所有边界法向落在某个半圆内，区域无界。

**空交的判定**：若某条约束与其余约束矛盾——例如同时要求 $y \geq x$ 与 $y \leq x - 1$——交为空。算法上的早期检测：

| 症状 | 判定方法 |
| --- | --- |
| 两个半平面边界平行且指向相反 | $a_i b_j = a_j b_i$ 且 $c$ 违反，直接空 |
| 分治合并后顶点为空 | 合并凸多边形时 `H = H1 ∩ H2` 为空 |
| 增量插入某条后交为空 | 裁剪后边界段集合为空 |

**一个经典误解**：以为「半平面越多交越小」。实际上增加约束可能让交**更小或变空**，但永远不会变大——这是单调性；若新增约束恰好冗余（被已有约束蕴含），交不变。判定冗余约束在实现里常用来「压缩输入」：先剔除被其他约束包含的半平面，能显著减少后续运算。

<span class="marginnote"><strong>调试建议</strong>：把半平面交的结果画出来看最直观。空交时通常可以靠「找一对矛盾约束」定位——在增量算法里，空交只会在「插入某一条半平面」的瞬间发生，记住那一条是谁，就是矛盾所在。</span>

线性规划的视角下，空交 = **可行域为空 = 原问题无可行解**；无界区域 = 目标函数可能无界。这两个结论对理解单纯形法的「无可行解」与「无界」退出条件极有帮助——回头学最优化理论时，这里是第一手的几何直觉。

**判定空交的代码骨架**（增量算法里最常用）：

```
H = 初始凸多边形（或前两条半平面）
for 每个半平面 h in 剩余输入:
    if H 为空: break            # 已空，不必再试
    if H 完全在 h 内: continue   # 冗余约束
    H = clip(H, h)              # 裁剪 h 外侧的部分
    若裁剪后 H 的边界段为空: H = 空集
```

「裁剪后边界段为空」是空交的**唯一判据**——不要依赖「顶点数变 0」这种近似判断，因为无界区域用「边」表示时顶点可能不为 0 但已经没有可行段。

## 7 小结

- 半平面交是**一组线性不等式的公共凸区域**，可能是空、无界或凸多边形。
- 分治：递归两半 + **两凸多边形线性合并**，$O(n\log n)$。
- 增量：逐个插入裁剪，朴素 $O(n^2)$，**随机化增量期望 $O(n\log n)$**。
- 交点由边界直线方程组给出，顶点合法性 = 满足全部其他不等式。
- **半平面交 = 2 维线性规划**：约束是墙、目标方向是力、最优解撞墙上的角。
- 应用：LP 可视化、多边形裁剪、可见区域、对偶凸包。
