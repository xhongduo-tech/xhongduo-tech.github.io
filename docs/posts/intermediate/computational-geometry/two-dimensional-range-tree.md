# 二维范围树

## 把一维积木叠成二维宫殿

上一讲的 kd 树查询 $O(\sqrt{n} + k)$ 已经不错，但理论天花板是 $O(\log n + k)$。**二维范围树（2D range tree）**把这个天花板真正够到：**$O(\log^2 n + k)$ 查询、$O(n\log n)$ 空间**，再用**分数级联**进一步压到 **$O(\log n + k)$**。它的构造哲学极其优雅：**「主树管 $x$，每个节点挂一棵管 $y$ 的次树」——一维范围树作为积木，叠出二维结构**。<span class="marginnote">二维范围树是「多层数据结构（multi-level data structure）」的原型：把查询条件按维度拆开，每维用一个一维结构，维与维之间通过「节点挂子树」串联。这个模式能推广到任意 $d$ 维：$O(\log^d n + k)$ 查询、$O(n\log^{d-1} n)$ 空间。理解二维，就等于理解了整个家族。</span>

## 1 正交范围查询

**二维正交范围查询**：给定轴对齐矩形 $[x_1, x_2] \times [y_1, y_2]$，报告所有落进矩形的点。

「正交」指矩形的边平行于坐标轴。非正交（旋转矩形、圆、多边形）的范围查询需要别的结构（如 kd 树、BSP），但正交查询是数据库、GIS 里最常见的形态——`WHERE x BETWEEN ... AND y BETWEEN ...`。

朴素解法：全扫 $O(n)$；或用 kd 树 $O(\sqrt{n} + k)$。范围树要做得更好，靠的是**分而治之：先用 $x$ 把候选缩成 $O(\log n)$ 个整块，再对每块用 $y$ 精确过滤**。

## 2 结构：主树 + 每节点挂 y 范围树

**二维范围树**的构造：

- **主树（primary tree）**：所有点按 $x$ 建一棵一维范围树。
- **次树（secondary tree）**：主树的每个节点 $v$ 挂一棵一维范围树 $T_v$，存的是「$v$ 子树里所有点的 $y$ 坐标」的有序集合。

主树有 $O(n)$ 个节点，每个点出现在从它到根的 $O(\log n)$ 个祖先的次树里，所以**总空间 $O(n \log n)$**——这是「节点挂有序列表」的代价，也是它比 kd 树贵的地方。<span class="marginnote">构造次树可以增量完成：叶子节点的次树就是单点；内部节点的次树 = 左右孩子次树的有序合并（类似归并）。这保证每个次树有序，且构建总时间 $O(n\log n)$。<strong>有序合并</strong>这个细节很重要——它让次树无需重新排序。</span>

## 3 查询：先 x 后 y

查询矩形 $[x_1,x_2] \times [y_1,y_2]$：

1. **$x$ 阶段**：在主树上做一维范围查询 $[x_1,x_2]$，得到 $O(\log n)$ 个「规范节点（canonical nodes）」——它们的子树恰好覆盖 $x$ 区间内的全部点，且两两不相交。
2. **$y$ 阶段**：对每个规范节点 $v$，在其次树 $T_v$ 上做一维范围查询 $[y_1,y_2]$，报告命中的点。

每个规范节点的次树查询是 $O(\log n + k_v)$（$k_v$ 为该块内命中的点数）。$O(\log n)$ 个规范节点，总查询时间：

$$
T(n) = O(\log n) \times O(\log n + k) = O(\log^2 n + k)
$$

关键：**$x$ 阶段把「矩形」拆成「$x$ 列块」，$y$ 阶段对每列块精确过滤**——两个一维查询的复合。

## 4 公式解析：规范节点与两阶段过滤

二维查询的核心公式是两阶段复合：

$$
\text{Report}([x_1,x_2] \times [y_1,y_2]) = \bigcup_{v \in \text{Canonical}([x_1,x_2])} \text{Report}_y(T_v, [y_1,y_2])
$$

拆解四步：

- **第一步，规范节点** $\text{Canonical}([x_1,x_2])$：主树一维查询返回的 $O(\log n)$ 个节点，其子树点集**互不相交且并集恰好 = $x \in [x_1,x_2]$ 的全部点**。这由一维范围树的分岔策略保证：报告的是「整棵落入区间的子树」，不重不漏。
- **第二步，逐块 $y$ 过滤**：每个规范节点 $v$ 的子树里，点的 $x$ 全部合法（落在 $[x_1,x_2]$），只需再按 $y$ 过滤。$T_v$ 是 $v$ 子树点的 $y$ 有序结构，一维查询 $[y_1,y_2]$ 精确给出 $x, y$ 都合法的点。
- **第三步，正确性**：矩形内任意点 $p$ 属于**恰好一个**规范节点的子树（不重不漏），且在该子树里被 $y$ 查询命中。故并集恰为全部答案。
- **第四步，复杂度**：$|\text{Canonical}| = O(\log n)$，每个次树查询 $O(\log n + k_v)$，$\sum k_v = k$，合计 $O(\log^2 n + k)$。

$\log^2 n$ 的两层来源清晰可见：**一层 $\log$ 用于 $x$ 定位，一层 $\log$ 用于每块 $y$ 过滤**。

## 5 分数级联：把 log² 压成 log

$O(\log^2 n)$ 虽好，还能更好。**分数级联（fractional cascading）**把每块的 $y$ 二分变成一次二分 + 常数次推进：

- 想法：规范节点在 $x$ 树上是**相邻的**，它们的次树 $y$ 有序列表也**相关**——一个节点的次树 = 两个孩子的次树合并。查询 $y_1$ 在父节点的插入位置，能推出在孩子次树的插入位置附近，不需要重新二分。
- 实现：每个次树的每个元素存一个**指针**，指向它在左右孩子次树中的位置。查询时只在根次树做一次二分，然后沿指针逐层下推，每层 $O(1)$ 定位。

总查询时间降到 **$O(\log n + k)$**，空间仍是 $O(n\log n)$。<span class="marginnote">分数级联是计算几何里少有的「免费午餐」：把一个 $\log$ 因子换成「指针传递」，代价只是每个元素多存几个指针。它的思想后来在数据库（倒排、跳表）、图形学（可见性）里反复出现。若你只记得一个技巧，记住这个：<strong>当多个有序结构互相嵌套时，用指针把它们级联起来，一次二分走遍全局</strong>。</span>

## 6 空间、维数与变体

- **空间 $O(n\log n)$**：每个点出现在 $O(\log n)$ 棵次树里。这是范围树相对 kd 树（$O(n)$ 空间）的主要代价。
- **任意维度**：$d$ 维范围树 = $d$ 层嵌套，查询 $O(\log^d n + k)$、空间 $O(n\log^{d-1}n)$。维度高时空间爆炸，故高维转向 kd 树 / LSH。
- **优先搜索树**：若查询带第三维或需要「按某序取前 $k$ 个」，可用优先搜索树（priority search tree）混合。
- **分层范围树（layered range tree）**：把次树从「完整 BST」换成「有序数组 + 二分」，构造更省，查询不变。

### 辨析：空间 O(n log n) 的直觉与代价

**辨析｜易错点：** 二维范围树的空间 $O(n\log n)$ 常让人不安——它比 kd 树的 $O(n)$ 多一个 $\log$。这笔「空间税」花在哪？直觉是：**每个点出现在它到根路径上的每一棵次树里**。

- 根节点的次树含全部 $n$ 个点；
- 下一层两棵次树各含约 $n/2$；
- 第 $k$ 层共含 $n$ 个点（分摊），但层数是 $\log n$ 层；
- 合计 $n \log n$。

**什么时候值**：查询量巨大、且查询性能是瓶颈时，$O(\log^2 n + k)$（甚至分数级联 $O(\log n + k)$）的查询收益值得多付 $\log$ 的空间。若查询量小、内存紧，kd 树的 $O(n)$ 空间 + $O(\sqrt n)$ 查询更划算。

| 场景 | 推荐 | 理由 |
| --- | --- | --- |
| 查询极多、静态 | 范围树（可级联） | 查询最优 |
| 内存受限、动态 | kd 树 | 空间省、支持插入 |
| 中等规模 | 看常数 | 实测决定 |

**次树的存储细节**：次树不必是完整 BST，可以退化成**有序数组 + 二分**——查询一样 $O(\log n)$，构造更省、常数更小（这是「分层范围树」的做法）。只有需要在线插入时才用平衡树当次树。

<span class="marginnote"><strong>权衡哲学</strong>：范围树与 kd 树是「空间换查询时间」与「简单换通用」的典型对。没有绝对优劣，只有「你的查询频率 vs 你的内存预算」这个工程方程。学会权衡，比记住某个结构更重要。</span>

**分数级联的代价**：级联把查询压到 $O(\log n + k)$，但每个次树元素多存两个指针（指向左右孩子的次树位置），空间常数变大。对超大 $n$，这个常数可能是压垮内存的最后一根稻草——所以级联前先量预算。

**记忆一句话**：二维范围树 = 「用 $x$ 找列，用 $y$ 筛行」——两个一维查询的复合，就是二维查询的全部秘密。

## 7 小结

- 二维范围树 = **主树管 $x$ + 每节点挂 $y$ 次树**，是多层数据结构的原型。
- 查询两阶段：**$x$ 找 $O(\log n)$ 个规范节点 → 每块做 $y$ 一维查询**，$O(\log^2 n + k)$。
- 正确性靠「规范节点不重不漏覆盖 $x$ 区间」；复杂度两层的 $\log$ 各来自 $x$ 定位与 $y$ 过滤。
- **分数级联**用指针串联嵌套有序结构，把查询压到 **$O(\log n + k)$**。
- 空间 $O(n\log n)$；推广到 $d$ 维是 $O(\log^d n + k)$，高维空间爆炸。
- 应用：数据库多维索引、GIS 空间查询、计算机图形学窗口裁剪。

在下一节，我们换一种眼光看同一批点：**几何对偶变换**——把点变成直线、直线变成点，让凸包与下包络在另一个世界里相遇。
