## 为什么从基因树与物种树开始

前面几节的所有建树方法，都在偷偷做一个大胆的假设：**每个基因的树，就是物种的树**。真实世界远比这复杂——同一个物种的基因组里，不同基因座位常常讲出互相矛盾的故事：一部分支持人类与黑猩猩是姐妹，另一部分却支持人类与大猩猩更近。这些**基因树与物种树的不一致（gene tree–species tree discordance）**不是噪声，而是进化过程留下的系统信号。<span class="marginnote">把"单基因树"直接当作"物种树"，在真实数据里可以得出确定性的错误结论。理解不一致的来源，是现代系统发育研究的分水岭：过去三十年，这个主题从"给树加注释的边角料"上升为独立的方法论分支。</span>本节讲四种不一致来源、其中最重要的不完全谱系分选、以及如何用统计模型重建真正的物种树。

## 1 基因树 ≠ 物种树：四种来源

一个基因座位的历史与物种历史分道扬镳，主要有四种机制：

**① 不完全谱系分选（incomplete lineage sorting, ILS）**：祖先多态性在相继的物种形成事件中未能完全分选，导致谱系按与物种关系不同的顺序合并。这是最普遍、也最难绕开的一种，下一节专讲。

**② 基因复制与丢失（duplication and loss）**：基因在演化中被复制成**旁系同源（paralog）**，不同拷贝的树与物种树不同。若把旁系同源误当**直系同源（ortholog）**建树，得到的就是一棵假物种树。<span class="marginnote">直系同源（ortholog）由物种形成事件产生，谱系史 = 物种史；旁系同源（paralog）由基因复制事件产生，谱系史 ≠ 物种史。判断一个位点属于哪类，是基因组时代的家常便饭——误用旁系同源是"无意识建错树"的头号原因。</span>

**③ 水平基因转移（horizontal gene transfer, HGT）**：细菌、古菌之间基因可以直接跨物种转移，被转移区域的历史自然不服从物种树。

**④ 杂交与基因渗入（hybridization and introgression）**：物种间偶发交配使基因流动——这在动物、植物、真菌里都有广泛证据，是"树"这个词本身不够用的地方。

## 2 不完全谱系分选：祖先多态性的遗产

ILS 的机制很直观。想象一个祖先物种含大量中性多态性。它先分裂出 A、B 的共同祖先（与 C 分开），再过一段（相对较短的）时间，A、B 分开。问题来了：**A、B 分开后，两个谱系各自携带的祖先多态性位点，可能迟迟不在各自支系里"固定"成一致状态**——它们要等遗传漂变把多态性消灭，这个过程需要大约 $2N_e$ 个世代（$N_e$ 为有效群体大小）。

若第二次物种形成到第一次物种形成之间的时间 $t$ 小于这个"清理期"，那么某些位点在 A、B 分离时仍保留着祖先多态性——**这时三个谱系（A、B、C）一起等着漂变来决定谁先合并**，A 与 C 先合并的概率并不为零。<span class="marginnote">把 ILS 想成一个"塞车"比喻：物种形成是一个又一个"关卡"，而祖先多态性是塞在关卡之间的旧车队。关卡开得太密（$t$ 短）或车太多（$N_e$ 大）时，总有一些车以错误的顺序通过——这就是不一致的由来。人类、黑猩猩、大猩猩三者的基因组里约有 15–20% 的位点不支持人-黑猩猩姐妹群，正是 ILS 的现场证据。</span>

## 3 公式解析：三物种 ILS 不一致概率

**ILS 有多严重，可以用一个精确的概率公式量化。这是分子进化里少有的"解析解"，务必吃透。**

设物种树为 $((A,B),C)$，两次物种形成事件之间相隔 $t$ 个世代（内部枝长），祖先群体的有效群体大小为 $N_e$。随机取一个中性位点，其**基因树与物种树一致**的概率为：

$$
P(\text{一致}) = 1 - \frac{2}{3}\, e^{-t/(2N_e)}
$$

两个不一致拓扑（$((A,C),B)$ 与 $((B,C),A)$）各占：

$$
P(\text{每个不一致}) = \frac{1}{3}\, e^{-t/(2N_e)}
$$

三步拆解：

- **第一步，看关键比值 $t/(2N_e)$**：分母 $2N_e$ 是漂变"清理"一段祖先多态性所需的世代数尺度。$t$ 与 $2N_e$ 的比值决定了不一致的下限。**$t \gg 2N_e$ 时，$e^{-t/(2N_e)} \to 0$，一致概率 $\to 1$**——物种形成间隔远长于清理期，ILS 几乎不出现。
- **第二步，看最坏情形**：$t \ll 2N_e$ 时，$e^{-t/(2N_e)} \to 1$，一致概率 $\to 1 - 2/3 = 1/3$。**三个拓扑各占约 1/3——基因树与物种树完全不相关**。这是"物种树不可能从单个基因恢复"的极端情形。
- **第三步，看系数 $2/3$ 与 $1/3$**：$2/3$ 来自"若未在内部枝内合并，三个谱系两两合并等概率"的对称性。**中间的推导假设中性位点、恒定的 $N_e$、随机交配**——这些简化让公式可解，也提醒我们真实情况（选择、群体大小变化）会让概率偏离这个解析值。

例如，$t = 2N_e$ 世代时，一致概率 $= 1 - \frac{2}{3}e^{-1} \approx 1 - 0.245 = 0.755$——**即使物种树内部枝长达 $2N_e$ 个世代，仍有约 1/4 的位点与物种树唱反调**。<span class="marginnote">这个数字解释了"为什么简单拼接几十个基因也可能建错树"：每个基因约 1/4 的概率不一致，若这些不一致相互加强而非抵消，拼接法（concatenation）会被"多数基因里恰好都错"的情形欺骗。这正是"拼接 vs 溯祖"之争的数学根源。</span>

## 4 从树到网：渗入、杂交与横向转移

ILS 产生的基因树虽然不同，但仍是**二叉分叉的树**——每个位点的历史仍是一棵树。杂交、渗入与 HGT 则更进一步：**单个位点的某些片段来自"另一个物种"，历史根本不是一个二叉分叉**。

**ABBA-BABA 检验（D 统计量）**是检测渗入的经典工具。对三物种 $(P_1, P_2, P_3)$ 加外群 $O$，统计两种矛盾祖先模式的数量比：大量额外支持"P1 与 P3 共享衍生状态"的位点（ABBA）提示 $P_2$ 与 $P_3$（或 $P_1$）间有渗入。<span class="marginnote">D 统计量之所以流行，是因为它几乎不需要参数：只需要比对好的一组座位，数 ABBA 与 BABA 的差。它揭开了"同域物种间基因组有 10% 的渗入"这类反直觉事实——达尔文雀、熊、蝴蝶、人类古混血（尼安德特人/丹尼索瓦人）都是它的著名应用。</span>

当渗入、杂交普遍到无法忽略时，**系统发育网络（phylogenetic network）**取代树成为更忠实的模型：节点分叉之外还有"网状边"表示基因流动。推断网络的计算比树困难得多，主流软件（如 PhyloNet、SNaQ）在小规模数据上尚可，大规模基因组网络仍是前沿。

## 5 物种树推断：多物种溯祖模型

既然单个基因不可靠，正确的物种树推断就必须显式建模"基因树从物种树抽样"的过程——这就是**多物种溯祖模型（multi-species coalescent, MSC）**。它把物种树与群体遗传参数（$N_e$）作为上层参数，把每个基因座的基因树作为中间层，通过溯祖理论计算整组基因座的数据似然。上一节的 ILS 概率公式，正是 MSC 在三物种时的特例。

两类落地方法：

**① 全模型联合估计**：如 *BEAST——物种树与所有基因树在同一个 MCMC 里联合采样。统计上最优，但计算昂贵，适合中等规模数据。

**② 摘要法（summary methods）**：如 ASTRAL、MP-EST——先独立推断每个基因座的基因树，再把这些基因树作为输入，聚合成最符合溯祖模型的物种树。<span class="marginnote">ASTRAL 快得惊人（数千基因座几分钟），是当前大规模基因组物种树的事实标准。它的代价是把"基因树推断误差"带进了第二步——基因树越不可靠，物种树越受影响。两种路线的取舍 = 统计严格性与可计算性的经典权衡。</span>

关于**拼接法（concatenation）**：把所有基因连成一条超长序列再建树，能提高每个位点的信噪比，却会放大基因树不一致的系统偏差——在 ILS 严重时，拼接法可以高置信地支持一棵错误树，这就是著名的"物种树悖论"。**现代共识：基因座独立、用溯祖法；拼接只适用于 ILS 可忽略（$t \gg 2N_e$）的情形。**

### 识别不一致来源的工作流

拿到一份"基因树打架"的数据，怎么判断是 ILS、渗入还是 HGT？一份实用的决策流程：

**第一步，看冲突分布**：把每个基因座的树都画出来。若每个基因座的树都"干净"（高支撑、无矛盾），只是基因座之间拓扑不同 → 优先怀疑 ILS 或渗入。

**第二步，做 ILS 的溯祖检验**：用 ASTRAL 或 *BEAST 建物种树，再检验单基因座树与物种树的偏离是否落在溯祖模型预期内（如三物种公式给出的 1/3 下界）。**偏离显著超出预期 → ILS 不足以解释，转向渗入/HGT。**

**第三步，做渗入检测**：对候选物种组合跑 ABBA-BABA 检验（D 统计量）与更精细的 f4/f3 统计。D 显著 ≠ 0 → 有基因流证据。

**第四步，做 HGT 检查**：对原核数据用重组/转移检测工具（如 FastTree 的转移同源检测、Guild 分析），看冲突区域是否集中在特定基因或基因簇——HGT 通常只影响少数基因的特定片段，而 ILS 影响所有基因座的统计分布。

**第五步，决定模型**：纯 ILS → 用溯祖法；渗入显著 → 网络模型（SNaQ）；HGT 为主 → 按基因座分别建树 + 转移注释。**用错模型重建出的"物种树"，只是把你对历史的假设画了一遍。**

## 6 小结

- **四种不一致来源**：不完全谱系分选（ILS）、基因复制丢失（ortholog/paralog 混淆）、水平基因转移、杂交渗入。
- **ILS 机制**：祖先多态性在 $t \lt  2N_e$ 时来不及分选，谱系按错误顺序合并。
- **关键公式**：$P(\text{一致}) = 1 - \frac{2}{3}e^{-t/(2N_e)}$；$t \to 0$
