## 为什么从「动态系统」开始

前九篇处理的都是**静态**推断：一个固定目标分布，采一堆样。但现实里大量问题**随时间演化**——GPS 定位要每一秒估计你的位置，自动驾驶要实时追踪周围车辆，气象同化要不断修正大气状态。这些问题的共性：**隐藏状态 $X_t$ 随离散时间演化，只能通过带噪声的观测 $Y_t$ 间接知道**。<span class="marginnote">状态空间模型（state-space model）是这类问题的统一框架：$X_t \sim p(x_t \mid x_{t-1})$ 描述状态演化（动力学），$Y_t \sim p(y_t \mid x_t)$ 描述观测（测量）。目标不是「采一次样」，而是<strong>在线的、逐时刻更新的后验</strong> $p(x_{1:t} \mid y_{1:t})$。</span> 蒙特卡罗的答案是把第 5 篇的重要性抽样**逐时刻递推**，再用**重采样**对抗权重退化——这就是**序贯蒙特卡罗（SMC）/ 粒子滤波**。

## 1 状态空间模型与滤波的目标

设 $t = 1, 2, \dots$ 为时间步，模型由两部分组成：

- **状态方程**：$X_t \mid X_{t-1} \sim f(x_t \mid x_{t-1})$，初始 $X_1 \sim \mu(x_1)$；
- **观测方程**：$Y_t \mid X_t \sim g(y_t \mid x_t)$。

**滤波（filtering）** 指逐时刻更新

$$
p(x_t \mid y_{1:t})
$$

即「用直到 $t$ 时刻的所有观测，估计当前隐藏状态」；**预测**指 $p(x_{t+1} \mid y_{1:t})$，**平滑**指 $p(x_s \mid y_{1:t})$（$s \lt  t$）。<span class="marginnote">经典线性高斯特例是<strong>卡尔曼滤波</strong>，有闭式解；一旦动力学非线性、观测非高斯（机器人定位、金融波动率、流行病传播），闭式解消失，只能靠粒子滤波这类数值方法。粒子滤波可以看作「卡尔曼滤波的非线性推广」。</span>

递推的结构是：给定 $p(x_{t-1} \mid y_{1:t-1})$，先用状态方程预测，再用观测方程校正——但积分通常不可行，于是用样本逼近。

## 2 序贯重要性抽样：权重递推

核心思想是把第 5 篇的 IS 推广到序列。引入**重要性分布** $q(x_{1:t} \mid y_{1:t})$，从它抽样，权重为

$$
w_t = \frac{p(x_{1:t} \mid y_{1:t})}{q(x_{1:t} \mid y_{1:t})}
$$

取 $q$ 具有**序贯因子化**形式 $q(x_{1:t} \mid y_{1:t}) = q(x_1 \mid y_1)\prod_{s=2}^t q(x_s \mid x_{1:s-1}, y_{1:s})$，则权重可以**递推更新**，无需每次重算整个历史。<span class="marginnote">贝叶斯递推写出未归一化后验：$p(x_{1:t} \mid y_{1:t}) \propto g(y_t \mid x_t)\, f(x_t \mid x_{t-1})\, p(x_{1:t-1} \mid y_{1:t-1})$。把分子分母都按这个式子展开，相邻时刻的权重之比就落到「上一步似然 × 状态转移 / 提议分布」上。</span>

## 3 公式解析：重要性权重的递推公式

**粒子滤波的一切都建立在权重递推上。** 设第 $i$ 个粒子在第 $t$ 时刻的权重为 $w_t^{(i)}$，则有

$$
w_t^{(i)} \propto w_{t-1}^{(i)}\;\frac{g\!\big(y_t \mid x_t^{(i)}\big)\; f\!\big(x_t^{(i)} \mid x_{t-1}^{(i)}\big)}{q\!\big(x_t^{(i)} \mid x_{1:t-1}^{(i)}, y_{1:t}\big)}
$$

四步拆解：

- **第一步，比值来源**：$w_t / w_{t-1} = \frac{p(x_{1:t} \mid y_{1:t})}{p(x_{1:t-1} \mid y_{1:t-1})} \cdot \frac{q(x_{1:t-1} \mid y_{1:t-1})}{q(x_{1:t} \mid y_{1:t})}$。
- **第二步，代分子递推**：$p(x_{1:t} \mid y_{1:t}) \propto g(y_t \mid x_t)\, f(x_t \mid x_{t-1})\, p(x_{1:t-1} \mid y_{1:t-1})$，与 $p(x_{1:t-1} \mid y_{1:t-1})$ 相消。
- **第三步，代分母递推**：$q(x_{1:t} \mid y_{1:t}) = q(x_t \mid x_{1:t-1}, y_{1:t})\, q(x_{1:t-1} \mid y_{1:t-1})$，相消。
- **第四步，得到简洁递推**：新权重 = 旧权重 × 观测似然 × 状态转移 / 提议密度。

**最常用的选择**是**先验提议** $q(x_t \mid x_{1:t-1}, y_{1:t}) = f(x_t \mid x_{t-1})$，即直接从状态方程采样。此时递推简化为

$$
w_t^{(i)} \propto w_{t-1}^{(i)}\; g\big(y_t \mid x_t^{(i)}\big)
$$

每个粒子「先跟着动力学走一步，再按观测似然加权」——简单、直观、稳健。<span class="marginnote">先验提议的代价：它没利用当前观测 $y_t$，当观测噪声很小（$g$ 很尖）时，粒子几乎都落在低似然区，权重严重退化。更聪明的选择是「最优提议」$q = p(x_t \mid x_{t-1}, y_t)$，但只在少数模型有闭式；工程上常用局部线性化逼近。</span>

## 4 重采样：对抗权重退化

**权重退化（weight degeneracy）** 是 SMC 的头号敌人：跑几轮后，少数粒子霸占几乎全部权重，其余粒子形同虚设，$n_{\text{eff}}$ 骤降。<span class="marginnote">退化机制：权重是乘积递推的，每步乘一个小因子，指数式地两极分化。第 5 篇的 ESS 公式在这里直接当退化指标：每步算 $n_{\text{eff}}$，低于阈值（如 $n/2$）就触发重采样。</span> **重采样（resampling）**：按权重从当前粒子集合里**有放回地抽样** $n$ 次，权重大的粒子被复制，权重小的被淘汰。重采样后所有权重重置为 $1/n$。

**辨析｜易错点：** 重采样是双刃剑。它治好了退化，却引入了**粒子贫化（particle depletion）**——多样性下降，大量粒子是同一祖先的复制品。处理手段有三：只退化时才重采样（**有效重采样**）；用分层/系统重采样（**systematic resampling**，方差更小、更均匀）；加**马尔可夫移动（jittering / MCMC move）** 让复制品散开。<span class="marginnote">标准算法是<strong>带重采样的 SMC（SIR / 自举滤波）</strong>：预测 → 加权 →（必要时）重采样 → 预测……每时刻输出的加权粒子集合就近似后验 $p(x_t \mid y_{1:t})$。Gordon、Salmond 与 Smith 1993 年的这篇论文是粒子滤波的奠基之作。</span>

## 5 粒子滤波的变体与应用

粒子滤波家族庞大，几条主线：

**SIR / 自举滤波**：先验提议 + 系统重采样，最经典、最易实现。
**辅助粒子滤波（APF）**：重采样提前到预测之前，用「预测后的观测得分」指导重采样，对尖似然更稳。
**SMC² / 粒子 MCMC**：用 MCMC 作重采样后的马尔可夫移动，或把 SMC 与 MCMC 嵌套，处理超稳问题。

应用横跨多个领域：**目标跟踪**（雷达、GPS、机器人 SLAM）、**信号处理**（语音、通信信道估计）、**金融**（随机波动率模型的似然估计）、**流行病学**（SEIR 参数与状态同步估计）、**计量经济学**（状态空间模型的最大似然）。<span class="marginnote">粒子滤波还提供一条优雅的副产品：<strong>平滑</strong>与<strong>边际似然估计</strong>。边际似然（对隐藏状态积分掉）能分解为各步权重平均的乘积，一次粒子滤波运行就顺带给出——这让 SMC 成为贝叶斯模型比较的利器。</span>

## 6 伪代码：带重采样的粒子滤波（SIR）

把整篇算法串成一个最小实现。

```text
输入：粒子数 N，状态方程 f，观测密度 g，观测序列 y₁, y₂, …, y_T
1.  对 i = 1, …, N：x₁⁽ⁱ⁾ ~ μ(·)；w₁⁽ⁱ⁾ ← 1/N          # 初始化
2.  对 t = 1, 2, …, T：
3.    # 预测：从状态方程推进
4.    对 i：xₜ⁽ⁱ⁾ ~ f(· | xₜ₋₁⁽ⁱ⁾)
5.    # 加权：按观测似然更新权重
6.    对 i：wₜ⁽ⁱ⁾ ← wₜ₋₁⁽ⁱ⁾ · g(yₜ | xₜ⁽ⁱ⁾)
7.    归一化：wₜ⁽ⁱ⁾ ← wₜ⁽ⁱ⁾ / Σⱼ wₜ⁽ʲ⁾
8.    # 诊断：若有效样本量过低则重采样
9.    若 n_eff = 1/Σᵢ (wₜ⁽ⁱ⁾)² < N/2：
10.      按权重 wₜ⁽ⁱ⁾ 有放回抽样 N 个粒子
11.      重置 wₜ⁽ⁱ⁾ ← 1/N
12.   输出加权粒子集 { (xₜ⁽ⁱ⁾, wₜ⁽ⁱ⁾) } ≈ p(xₜ | y₁:ₜ)
```

第 8–11 行是关键：**只有在退化明显时才重采样**（有效重采样），并把权重重置为均匀，避免每步都重采样带来的贫化。<span class="marginnote">实现上，第 9 行的判定标准（N/2）是经验阈值，可按问题放宽到 N/10 或收紧到 N；第 10 行的有放回抽样常实现为 <strong>系统重采样</strong>——把 $[0,1)$ 均匀切成 N 段，每段取一个随机点做逆变换，一次遍历完成复制与淘汰，方差比朴素多项式重采样小。</span>

**辨析｜易错点：** 粒子滤波的隐性前提是「状态方程能推进」（第 4 行可抽样）。若状态转移无闭式，就需要内嵌 MH 或别的采样器。另一个易错点：$y_t$ 只在加权阶段（第 6 行）使用，若观测噪声很小、$g$ 很尖，大多数粒子权重趋近 0——此时应改用辅助粒子滤波（APF），把重采样提前到预测之前，用「预测观测得分」引导粒子。

一个典型诊断：画出各时刻的 $n_{\text{eff}}$ 曲线。健康的滤波运行中，$n_{\text{eff}}$ 应周期性「下降—重采样—回满」；若持续低位徘徊，说明粒子数不足或提议分布与观测失配，需要加大 $N$ 或换提议。

## 7 小结

- **状态空间模型**：状态演化 $f(x_t \mid x_{t-1})$ + 观测 $g(y_t \mid x_t)$；目标是逐时刻后验 $p(x_t \mid y_{1:t})$。
- **SMC**：把 IS 序贯化，权重递推 $w_t \propto w_{t-1}\, g(y_t \mid x_t)\, f(x_t \mid x_{t-1})/q$。
- **先验提议** $q = f$：权重递推简化为乘观测似然，简单稳健但观测尖时易退化。
- **重采样**：按权重复制/淘汰粒子，对抗退化，但要提防粒子贫化；退化时触发 + 系统重采样是标配。
- SMC 是「动态版蒙特卡罗」：预测 → 加权 →（重采样）逐时刻滚动，一次运行还顺带给出边际似然。
