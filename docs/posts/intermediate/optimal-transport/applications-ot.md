## 为什么从应用开始

前八篇是"磨刀"，这一篇是"砍柴"。最优传输的迷人之处在于：**同一个数学对象（最优传输映射 / Wasserstein 距离）在不同领域扮演不同角色**——在图像配准里它是位移场，在色彩迁移里它是颜色直方图之间的 Monge 映射，在生成模型里它是损失函数。读完这篇，你会看到一条贯穿始终的主线：**凡是"把一个分布变成另一个分布、并希望代价最小"的问题，都在最优传输的射程之内**。<span class="marginnote">三句话记住三个应用：配准 = "找位移场"；色彩迁移 = "找颜色映射"；WGAN = "找 1-Lipschitz 判别器"。三者共享第 2、3、5 篇的同一套理论，只是把"分布"换成了像素、颜色或样本。</span>

## 1 图像配准：位移场即最优传输映射

**图像配准（image registration）**的目标：给定两幅图像 $I_0$ 与 $I_1$（例如同一器官在不同时刻的 CT 扫描），找一个形变场（warp field）$T$，把 $I_0$ 变形后与 $I_1$ 对齐。经典方法是光流（optical flow）或 Demons 迭代，但它们通常是**局部的**、对初始猜测敏感。

最优传输给出了一个**全局**的视角：把图像看作质量分布（灰度/密度就是"质量"），则最优传输映射 $T = \nabla\varphi$（Brenier 定理）直接就是我们要的形变场。<span class="marginnote">配准与最优传输的亲和力来自 $W_2$ 的几何性：$W_2$ 尊重空间结构，天然惩罚"不连续、撕扯"的形变，这恰好是医学图像配准想要的平滑性。Brenier 映射的凸性还保证形变是"单射、保定向"的——不会出现折叠或自交，这是许多配准方法的硬需求。</span>对"质量守恒"的配准（组织密度不变、只是形变），最优传输给出精确解；对质量不守恒的情形，则用"无界/松弛"变体引入质量生成与湮灭项。这一路线已在肺部呼吸配准、大脑纵向研究中得到验证。

从计算上讲，配准里的最优传输通常走**半离散路线**：把连续图像离散成网格，用第 8 篇的拍卖/Laguerre 方法求精确映射，再用多尺度粗到细初始化保证全局性。$W_2$ 的凸性在这里再次显灵——它把配准从"容易陷入局部极小的非凸优化"变成"有唯一解的结构化问题"，这正是它比传统光流更稳的原因。当然，代价是"质量守恒"的假设：对会生长或萎缩的组织（肿瘤、病灶），需要引入质量源/汇项，这是配准与最优传输结合时最常见的工程细节。

## 2 色彩迁移：用 Monge 映射做直方图匹配

**色彩迁移（color transfer）**：把源图像的色调风格迁移到目标图像上。最朴素的思路是**逐通道直方图匹配**——对 R、G、B 三个通道分别做分位数匹配。但逐通道匹配忽略了颜色通道之间的相关性，常常产生"色偏"或"伪影"。

最优传输的方案更优雅：把源图像的 RGB 三元组看成 $\mathbb{R}^3$ 里的一个点云（分布 $\mu$），目标图像的点云是 $\nu$，**在 $\mu$ 与 $\nu$ 之间求 $W_2$ 最优传输映射 $T$，再把每个像素的颜色经 $T$ 变换**。<span class="marginnote">逐通道直方图匹配 = 假设颜色通道独立；最优传输 = 尊重颜色的联合分布。后者保留了"红苹果配绿叶子"这类通道间的语义相关性。Pitié 等人 2005 年用径向基函数近似 Monge 映射，Rabin 等人 2014 年用 Sinkhorn 把它做成实时工具——这正是第 7 篇算法在图像上最直观的落地。</span>得益于 Sinkhorn 的 GPU 友好性，现代色彩迁移（如 Deep Color Transfer 里的 OT 层）已经把这一步嵌入到深度网络的可微管线里。

## 3 公式解析：Wasserstein GAN

2017 年，**Arjovsky、Chintala 与 Bottou** 发表《Wasserstein Generative Adversarial Networks》，用一个关键观察改变了生成模型的格局：普通 GAN 的 JS 散度在"真实分布与生成分布支撑不重叠"时**梯度消失、训练不稳定**（回忆第 4 篇的对比表：JS 对支撑不重叠恒取最大值）。他们主张用 $W_1$ 代替 JS 散度。

生成器 $G$ 的目标是让生成分布 $g_\#p_z$ 逼近数据分布 $p_{data}$，即最小化 $W_1(p_{data}, g_\#p_z)$。利用第 4 篇的 **Kantorovich–Rubinstein 对偶**：

$$
W_1(p_{data}, g_\# p_z) = \sup_{\|D\|_{\mathrm{Lip}} \le 1} \; \mathbb{E}_{x \sim p_{data}}[D(x)] - \mathbb{E}_{z \sim p_z}[D(G(z))]
$$

于是整个 WGAN 变成两个玩家的博弈：

$$
\min_{G} \; \max_{\|D\|_{\mathrm{Lip}} \le 1} \; \mathbb{E}_{x \sim p_{data}}[D(x)] - \mathbb{E}_{z \sim p_z}[D(G(z))]
$$

拆成三步读：

- **第一步，读懂判别器 $D$**：这里 $D$ 不再是"真/假分类器"，而是"打分器"——它给真实样本打高分、给生成样本打低分。Lipschitz 约束 $\|D\|_{\mathrm{Lip}} \le 1$ 保证打分是"平滑"的，不会疯狂飙分。
- **第二步，读懂为什么工作**：$W_1$ 对参数几乎处处可导且梯度不消失（即使支撑不重叠），所以判别器能给生成器**持续有效的梯度信号**。JS 散度做不到这一点。
- **第三步，读懂工程约束**：Lipschitz 约束的实现是第一工程难点——WGAN 原始版本用**权重裁剪**，后续的 WGAN-GP 用**梯度惩罚**，Spectral Normalization 则从谱范数上保证。三者都是在逼近同一个数学约束。

把训练循环写出来，能看清每个组件在对偶框架里的角色：

```text
for 每轮训练:
    # 判别器 D 更新（找更紧的对偶下界）
    for k 步:
        采样真实批 x ~ p_data，噪声批 z ~ p_z
        # 梯度上升，使 E[D(x)] - E[D(G(z))] 增大
        D ← D + η ∇_D (E[D(x)] - E[D(G(z))])
        施加 Lipschitz 约束（裁剪 / 梯度惩罚 / 谱归一化）
    # 生成器 G 更新（沿 W_1 下降）
    采样噪声批 z ~ p_z
    G ← G - η ∇_G E[D(G(z))]
```

**辨析｜易错点：** 不要把 WGAN 的判别器误认为"判别器逼近 $W_1$ 本身"。判别器 $D$ 只是 $W_1$ 对偶里的一个可行函数，**训练收敛后生成器极小化的是 $W_1$，而判别器是在找最紧的对偶下界**——这与第 3 篇对偶理论中的"势函数"角色完全一致。<span class="marginnote">WGAN 是"对偶理论 + 深度网络"的天作之合：对偶把不可算的 $W_1$ 变成可优化的 Lipschitz 函数族，深度网络恰好擅长参数化光滑函数。整条推理链条只在第 3、4 篇的框架内才说得通。</span>

## 4 更大的应用版图

配准、色彩迁移与 WGAN 只是三个样板。同样由最优传输驱动的还有：

**领域自适应（domain adaptation）**：把源域的表示"搬运"到目标域，使分类器跨域有效；**点云与形状匹配**：用 $W_2$ 或 Gromov–Wasserstein 对齐不同物体的点云（衔接第 10 篇）；**单细胞数据分析**：用最优传输对齐不同实验批次的细胞分布、构建发育轨迹；**经济学与匹配市场**：从 Kantorovich 的苏联物资调度一路到今天的最优匹配机制设计。共同点只有一个：**把"谁到谁"交给最优传输，把"花多少"当作可学习的量**。

若沿"从极限到大模型"的主线再往后看，最优传输还有两张待打的手牌：一是**未匹配最优传输（unbalanced OT）**，允许质量生灭，适合数据量悬殊的真实场景；二是与**对齐/强化学习**的结合——把策略分布与人类偏好分布之间的差异用 OT 度量，比 KL 更尊重几何结构。这提醒我们：十篇只是打开了这扇门。<span class="marginnote">几乎每个"分布对齐"问题都能套进最优传输：你要对齐的是分布（样本、颜色、点云、细胞、词向量），最优传输给出的是"谁到谁、花多少"的完整账本。这也解释了为什么最优传输在 2020 年代成为机器学习工具箱里的常客。</span>

一个值得注意的趋势是**最优传输与大模型的交汇**：扩散模型的去噪过程可以被理解为"高斯分布与数据分布之间的 Wasserstein 路径"；在奖励对齐里，策略分布与参考分布之间的差异也可以用 OT 距离来正则化。最优传输正在从"图像处理的工具箱"变成"分布学习的语言"——这正是本专题放在"从极限到大模型"主线中的原因。

## 5 一个微型端到端：Sinkhorn 色彩迁移

把前几篇的算法串成一个能跑通的小流程。目标是"把源图的色调迁移到目标图"。

**第一步，提取颜色点云**：把源图每个像素的 RGB 三元组收集为点集 $\{x_i\}$，目标图收集为 $\{y_j\}$，每个点赋予均匀质量。于是得到两个 $\mathbb{R}^3$ 里的离散分布 $\mu, \nu$。

**第二步，构造代价矩阵**：$C_{ij} = \|x_i - y_j\|^2$，即 RGB 空间欧氏距离的平方。$C$ 是 $n \times m$ 矩阵，$n,m$ 是两图的像素数（实际用采样降维到几千）。

**第三步，Sinkhorn 求解**：固定 $\varepsilon$（约为 $C$ 标准差的一个比例），交替缩放求熵正则化耦合 $P = \mathrm{diag}(u)K\mathrm{diag}(v)$。这一步直接调用第 7 篇的算法，GPU 上几十轮收敛。

**第四步，映射每个像素**：对源图像素 $x_i$，需要"去往哪里"的颜色。若用确定性映射，取 barycentric 平均 $T(x_i) = \sum_j P_{ij}y_j / \sum_j P_{ij}$；若用随机映射，按 $P_{ij}$ 抽样。<span class="marginnote">barycentric 平均是"软映射"：一个源颜色可以按比例混合多个目标颜色，避免硬映射造成的色带伪影。$\varepsilon$ 大时混合更多、更平滑；$\varepsilon$ 小时更锐利、更保真。</span>

**第五步，重组图像**：把每个像素替换为映射后的颜色，必要时做少量平滑（防止空间上相邻像素的映射跳变）。

整个流程的复杂度由第三步主导（$O(n^2)$ 每轮），在 2020 年代的标准 GPU 上对几千点实时可跑。若把 $C$ 换成图像块之间的相似度、把"颜色点云"换成"图像块"，同样的五步就变成了图像风格迁移的 OT 版本——**换汤不换药，药方就是 Kantorovich + Sinkhorn**。
