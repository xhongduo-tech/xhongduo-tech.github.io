# 古代汉语（文言文阅读与训诂：文字、音韵、训诂、语法、文选）

古代汉语是中文、历史、哲学专业的必修基础课，也是中学文言文教学的学科基础。系统学习汉字构造、古音系统、训诂方法和古汉语语法，是从文字读懂文言文、进行古籍阅读与训诂研究的基石。

## 对标教材

- 王力《古代汉语》（中华书局，四册）
- 郭锡良等《古代汉语》（商务印书馆，上下册）
- 王力《汉语史稿》（中华书局）
