## 为什么从判断句、叙述句与被动句开始

句法分析的核心，是看清一个句子「在做什么」。古汉语的句子可按谓语的性质分为三大类：**判断句**（A 是 B）、**叙述句**（A 干什么）、**被动句**（A 被怎么样）。其中判断句与被动句是古汉语语法最具特色的句式——它们的表达方式与现代汉语截然不同。<span class="marginnote">王力《古代汉语》通论「判断句」「叙述句」「被动句」三节，是句法篇的核心。现代汉语的判断句用「是」，古汉语的判断句却基本不用「是」而用「……者……也」；被动句的「于、见、为、被」四种格式也各有讲究——这一节解决「是什么」与「被怎么样」两大句式。</span>

三句式是阅读与翻译的试金石：判断句被误读为叙述句、被动句被当成主动句，是最常见的语法误判。本节把它们逐一解剖。

## 1 判断句：不用「是」的判断

**判断句**是表示「什么是什么」的句子。现代汉语用判断动词「是」，古汉语判断句却**一般不用「是」**，而用主语、谓语直接组合，或以「者」「也」为标记。<span class="marginnote">「是」在先秦主要是指示代词（「是可忍」= 这），到汉代才逐渐虚化为判断动词。「此是……」的说法始于汉，六朝大盛——所以读先秦文献，判断句须按「者」「也」格式理解。</span>

判断句的四种基本格式：

**「……者，……也」**。「陈胜者，阳城人也」——主语后加「者」提顿，谓语后加「也」煞尾。这是最完整、最标准的判断句式。

**「……，……也」**。「此天子气也」——省主语之「者」，只留谓语之「也」。

**「……者，……」**。「天下者，高祖天下」——省谓语之「也」。

**「……，……」**。全无标记，靠语义判断。「刘备天下枭雄」——「刘备」与「天下枭雄」直接组合，靠谓语名词性判断。

**判断句的变式**：

- 「是」作判断词的萌芽：「问今是何世」——《桃花源记》的「是」已是判断词（东晋时「是」字判断句已通行）。
- 「乃」「即」「则」表判断：「此乃臣效命之秋也」（就是）、「梁父即楚将项燕」（就是）。
- 「非」表否定判断：「此非孟德之困于周郎者乎」（不是）。<span class="marginnote">「乃、即、则」表判断时是副词性质（就是），不是判断动词；「非」是否定副词（不是）。判断句的识别标志：主语与谓语都是名词性成分，两者之间是「等同」或「类属」关系——「陈胜者，阳城人也」是类属，「梁父即楚将项燕」是等同。</span>

## 2 叙述句：谓语的丰富世界

**叙述句**是陈述行为、动作或事件的句子，谓语以动词为中心。叙述句是古汉语的主体句式，其核心是**动词的配置**。<span class="marginnote">叙述句的范围最广：及物动词带宾（「击沛公」）、不及物动词不带宾（「沛公起」）、动词带双宾（「授之书」）、兼语式（「使人闻之」）。读叙述句的关键，是找出谓语动词并判断其与主语、宾语的关系。</span>

叙述句的主要类型：

**动词 + 宾语**。「项伯杀人，臣活之」——动词「杀」「活」各带宾语「人」「之」。宾语与动词的关系（施受、使动、意动）在《词类活用》一节已详论。

**双宾语句**。「公赐之食」——「之」（他）、「食」（食物）双宾语；「授之书而习其句读者」——双宾结构。<span class="marginnote">双宾语是叙述句的难点：「赐之食」= 赐给他食物，间接宾语（人）在前、直接宾语（物）在后。先秦双宾语句数量不少，须按「动词 + 人 + 物」的语序理解。</span>

**兼语式**。「使杞子、逢孙、杨孙戍之」——「使」的宾语又是后一动词的主语（兼语）；「命夸娥氏二子负二山」——兼语式。兼语式在文言中极多，是「使令」类动词（使、令、教、遣）的典型句式。

**主谓谓语句**。「大江东去」——「大江」（主语）、「东去」（谓语）；「吾与徐公孰美」——比较式叙述。

叙述句的翻译要领：先找谓语动词，再理清主语、宾语、状语，最后按现代语序组织——叙述句最考验「六字诀」中的「补」与「调」。

### 判断句的否定与固定格式

判断句除肯定外，还有系统的否定与固定格式：

**「非」字否定判断**。「此非吾所谓传其道解其惑者也」——「非」= 不是；「六国破灭，非兵不利，战不善」——「非」表否定判断。凡「非 + 名词性谓语」，皆是否定判断句。

**「乃、即、则、诚、固」加强判断**。「此乃天子所以兴也」（就是）、「梁父即楚将项燕」（就是）、「此则岳阳楼之大观也」（就是）、「此诚危急存亡之秋也」（确实是）、「固不如也」（本来是）。这些副词不是判断动词，但使判断语气更明确。<span class="marginnote">判断句的识别三招：看谓语是否为名词性成分、看有无「者」「也」、看有无「乃即则诚固非」。三招合用，判断句无所遁形。「乃」「即」表判断时是副词（就是），不可误作「是」——与现代汉语的「是」字判断不同。</span>

**「为」表判断**。「四体不勤，五谷不分，孰为夫子」——「为」= 是；「中峨冠而多髯者为东坡」——「为」表判断。上古「为」多作动词（做、成为），表「是」的判断义在战国渐多——「为」字判断句是判断句由「者也」到「是」的过渡形态。

## 3 被动句：四种标记与识别

**被动句**是主语是动作承受者的句子。现代汉语用「被」字（「被打了」），古汉语的被动句却有四种主要标记：<span class="marginnote">被动句的识别是句法难点：不是所有「被打」式的句子都有标记，古汉语还有一种「无标记被动」（意念被动）。先掌握四种有标记格式，再辨意念被动。</span>

**「于」字被动句**。「此非孟德之困于周郎者乎」（被周郎困）、「受制于人」（被他人制）。格式：**动词 + 于 + 施事者**。<span class="marginnote">「于」字被动句是最早的被动格式：动词后加「于」引出施事。「困于周郎」= 被周郎围困——「于」字使施事者现形。凡「动 + 于 + 名」且「名」是施事而非处所、对象者，多为被动。</span>

**「见」字被动句**。「秦城恐不可得，徒见欺」（被欺）、「见笑于大方之家」。格式：**见 + 动词**，或「见 + 动词 + 于 + 施事」。<span class="marginnote">「见」字被动句中「见」表被动，不能译成「看见」。「徒见欺」= 白白被欺骗。「见 + 动 + 于 + 名」是「见」「于」合用的被动句，「见笑于大方之家」即「被大方之家耻笑」。</span>

**「为」字被动句**。「为天下笑」（被天下人耻笑）、「为秦人积威之所劫」（被秦人的威势所胁迫）。格式：**为 + 施事 + 动词**，或「为 + 施事 + 所 + 动词」。<span class="marginnote">「为……所……」是被动句最完备的格式：「为天下笑」是「为 + 施事 + 动词」，「为秦人积威之所劫」是「为 + 施事 + 所 + 动词」。凡「为」后是施事、其后动词表被动者，即「为」字被动。</span>

**「被」字被动句**。「信而见疑，忠而被谤」（被毁谤）、「被创十余处」（被砍伤）。格式：**被 + 动词**（上古「被」多表「遭受」，句末动词已显被动）。「被」字句在汉以后渐成主流，是现代「被」字句的源头。<span class="marginnote">上古「被」本义是「覆盖」（被衣），引申为「遭受」（「被坚执锐」是被甲），再由「遭受」虚化为被动标记（「被谤」）。「被」字的语法化过程，是「实词虚化为语法词」的典型样本——与《语音演变规律》所讲的词汇化互为表里。</span>

**无标记被动（意念被动）**。无任何标记，靠语义判断。「屈原放逐」（被放逐）、「兵挫地削」（军队受挫、土地被削）、「帝感其诚」（天帝被其诚意感动）。<span class="marginnote">意念被动最难识别：句中无「于见为被」，只能靠「主语是受事」判断。「帝感其诚」——「感」是使动式被动（被感动），须先译「（天帝）被（愚公的）诚意感动」。凡主语为物而谓语为动作而施事另有所指，须考虑意念被动。</span>

### 被动句的辨析与翻译

被动句的识别易混之处，须专门辨析：

**「见」的主动被动之别**。「见」可表被动（「徒见欺」= 被欺），也可作偏指副词（「冀君实或见恕也」= 原谅我）——判断方法：后接动词而施事未明者多为被动，后接动词而语义指向说话人者为偏指。<span class="marginnote">「见恕」是「见 + 动词」的偏指用法：字面「被原谅」，实为「原谅我」——「见」在此相当于「我」。这与被动「见 + 动」形同而实异，是翻译的常见陷阱。凡「见 + 动词」且语义指向主语者，先试被动；指向说话人者，试偏指。</span>

**「于」的处所与被动之别**。「战于长勺」的「于」是处所（在长勺），「困于周郎」的「于」是被动（被周郎困）——判断方法：动词后「于 + 名」若「名」是施事（发出动作的一方），则为被动；若「名」是处所、对象，则为介宾。<span class="marginnote">「困于周郎」——「周郎」是「困」的施事（周瑜围困），故为被动；「战于长勺」——「长勺」是地点，故为处所。辨析「于」字句的关键，是判断「于」后名词的语义角色：施事则被动，处所对象则介宾。</span>

**被动句的翻译**。四种标记被动句，翻译统一还原为「被」字句：「困于周郎」→「被周郎围困」；「徒见欺」→「白白被欺骗」；「为天下笑」→「被天下人耻笑」；「被谤」→「被毁谤」；意念被动「屈原放逐」→「屈原被放逐」。翻译被动句，先识别标记，再补出施事。

## 4 判断、被动与词序的综合运用

三类句式常在同句中出现，须综合判断：

「此非孟德之困于周郎者乎」——《赤壁赋》名句：**判断**（此……乎，反诘判断「这不是……吗」）套**被动**（「困于周郎」= 被周郎困）。一层判断、一层被动，嵌套阅读。

「吾不能举全吴之地，十万之众，受制于人」——《赤壁之战》：「受制于人」是「于」字被动，前有「不能举」的叙述——叙述、被动叠加。

「信而见疑，忠而被谤」——《屈原列传》：两组并列，「见疑」「被谤」各是被动——「见」「被」同义的被动对举，是识别被动的绝佳例证。<span class="marginnote">阅读策略：遇「动 + 于 + 名」先辨「于」的语义（处所、比较、被动）；遇「见」「为」「被」后接动词，先试被动；「为……所……」则必为被动。判断句看「者」「也」与名词谓语，叙述句找谓语动词——三者各有一套识别标志，综合运用方不致误。</span>

## 6 小结

- **判断句**基本不用「是」，用「者」「也」或靠名词谓语判断；「乃、即、则」表「就是」，「非」表「不是」。
- **叙述句**以动词谓语为中心，含动宾、双宾、兼语等结构；翻译重在找动词、理成分。
- **被动句**四种标记：**于、见、为（……所）、被**；另有靠语义判断的**意念被动**。
- 识别被动：「动 + 于 + 施事」「见 + 动」「为……所」「被 + 动」各成格式。
- 三类句式常嵌套出现，须按标志综合判断。
- 「是什么」「干什么」「被怎么样」三大句法框架至此齐备，语法篇收官。
