## 为什么从代词与副词开始

句子的骨架是词类活用与句式，而把这些骨架「铆合」起来的，是虚词。古汉语虚词的核心是**代词、副词、介词、连词、语气词**五大类。本节先处理前两类：**代词**（之、其、孰、斯）与**副词**（甚、殊、颇、皆）。<span class="marginnote">王力《古代汉语》通论以「代词」「副词」等专节系统讲虚词。虚词虽无实义，却是句法关系的最强信号——读懂虚词，等于拿到解开文言句法的密码本。</span>

代词与副词看似是「小词」，实则是阅读的高频难点：几乎每个文言句子里都有它们，而它们的古今对应又极不规则。本节以「分类 + 用例」的方式把它们系统化。

## 1 代词：人称、指示、疑问

**代词**是代替名词、名词性短语的虚词，古汉语代词比现代汉语复杂得多。

**人称代词**：

- **第一人称**（我、吾、余、予）：「吾」「我」最常用，作主语、宾语皆可；「余」「予」多见于先秦。「吾与回言终日」——「吾」作主语。
- **第二人称**（女、汝、尔、若、乃、而）：「女」「汝」「尔」「若」通用，「乃」「而」多作定语。「尔何知」——「尔」作主语；「而翁归」——「而」作定语（你的父亲）。<span class="marginnote">人称代词常省略，是文言的重要特征：「（）相与枕藉乎舟中」——主语「（他们）」省略；「（）曰：'王侯将相宁有种乎'」——主语省略。翻译时须补出。</span>
- **第三人称**：古汉语没有专用的第三人称代词，常以「其」（他的、他们的）、「之」（他、它）兼职。「其」作定语、主语（「其皆出于此乎」），「之」作宾语（「学而时习之」）。<span class="marginnote">「之」的用法定要分清：作宾语是代词（「择其善者而从之」之「之」= 它），作定语标志是助词（「马之千里者」之「之」），作动词是「往」（「吾欲之南海」）。一词多职，凭位置辨职。</span>

**指示代词**：

- **近指**（此、是、斯、兹）：「此」最常用，「是」在古汉语多作指示代词而非判断词。「是可忍，孰不可忍」——「是」指代前面之事。
- **远指**（彼、其、夫）：「彼」指远，「其」兼领属，「夫」作远指带发语色彩。「彼竭我盈」——「彼」指对方。

**疑问代词**：

- **问人**（谁、孰）：「孰」兼表选择，「孰与」表比较。「孰为夫子」——「孰」= 谁；「吾与徐公孰美」——「孰」= 哪一个。
- **问事物**（何、奚、曷、胡）：「何」最常用，「奚」「曷」「胡」多见于上古。「胡为乎来哉」——「胡」= 为何。
- **问处所**（安、焉、恶）：「沛公安在」——「安」= 哪里；「且焉置土石」——「焉」= 在哪里。<span class="marginnote">疑问代词「谁、何、安、焉、奚、曷、胡、孰」作宾语时前置——这是《宾语前置与特殊词序》一节「条件 A」的直接对应。「何以战」「沛公安在」都印证了这条规则。</span>

## 2 副词：范围、程度、时间、否定

**副词**修饰动词、形容词，表范围、程度、时间、否定、情态、语气等。古汉语副词数量庞大，本节抓最常用的几类。

**范围副词**：

- **皆、尽、悉、咸、举**：全部。「百姓皆以王为爱也」——皆 = 都。
- **但、特、徒、直、独**：仅、只。「但闻黄河流水鸣溅溅」——但 = 只；「特以诈佯为予赵城」——特 = 只。

**程度副词**：

- **甚、殊、极、至**：非常。「君美甚」——甚 = 极、很；「老臣今者殊不欲食」——殊 = 很。
- **益、弥、愈**：更加。「故远人不服，则修文德以来之」的「则」另论，「日益骄固」——益 = 更加。<span class="marginnote">「甚」在古汉语多作谓语或补语（「君美甚」= 美得很），与现代汉语「很」作状语的习惯不同——副词的位置差异也是古今语法之别。</span>

**时间副词**：

- **已、既、尝、曾**：已经、曾经。「秦王既丧」——既 = 已经；「尝闻之」——尝 = 曾经。
- **方、正、适**：正在、恰好。「方其破荆州」——方 = 正当。
- **将、且、行将**：将要。「公将战」——将 = 将要。
- **卒、竟、终**：终于。「卒廷见相如」——卒 = 终于。
- **俄、旋、寻、须臾**：不久、随即。「寻病终」——寻 = 不久。

**否定副词**：

- **不、弗、毋、勿、未、莫、无**。「不」表一般否定，「弗」相当于「不之」（「弗胜」= 不胜），「毋」「勿」表禁止（「毋内诸侯」），「未」表「还没有」（「未之有也」），「莫」表「没有人」（「莫能与之争」）。<span class="marginnote">「未」与「不」之别：「未」是「还没有」，暗含「将来可能有」；「不」是「不」，无此含意。「未之有也」= 还没有过这种事。否定副词「不、毋、莫、未、弗、勿」句中代词宾语前置——正是《宾语前置》条件 B 的触发词。</span>

### 代词的省略与活用

代词在古汉语中常省略，这是文言「简洁」的重要来源：

**主语省略**。「（）曰：'王侯将相宁有种乎'」——对话中主语（陈涉）省略；「（）相与枕藉乎舟中」——承前主语省略。

**宾语省略**。「以（）告」——介词宾语省略；「项伯乃夜驰之沛公军，私见张良，具告（）以事」——动词宾语省略。

**兼语省略**。「使（）闻之」——兼语省略。

代词的活用（或曰「虚指」）：

**「其」作语气副词**。「其皆出于此乎」——「其」表推测语气（大概）；「其孰能讥之乎」——「其」表反诘（难道）。<span class="marginnote">「其」兼代词与语气词：「其皆出于此乎」表推测，「其孰能讥之乎」表反诘——读「其」先辨其是代词（他的）还是语气词（大概、难道）。这是高频虚词「其」最易混的两用。</span>

**「莫」作无定代词**。「莫能与之争」——「莫」= 没有人（无定代词）；「莫愁前路无知己」——「莫」= 不要（副词）。「莫」字双义，依语境辨。

代词副词的「省略—活用」机制，让文言句法高度经济——这也解释了为什么文言翻译要「补」：省略处须补出，才能译成通顺的现代汉语。

## 3 副词的辨析：最易混的几组

**「甚」与「很」**。古汉语「甚」常作谓语补语，今「很」只能作状语——「君美甚」译「您美得很」，不能说「您很美国」？可见词序与词性的古今差异。

**「尝」与「曾」**。「尝」表「曾经」（已发生过），「曾」在上古表「竟然、甚至」或「曾经」二义。「何曾食万钱」——「曾」= 曾经。

**「相」与「见」**。二者表「相互」「一方对另一方」。「相」表互相（「父子相保」），或偏指一方（「请奉盆缶，以相娱乐」——相 = 我）；「见」可表被动（「徒见欺」）或偏指（「冀君实或见恕也」——见 = 我）。<span class="marginnote">「见恕」的「见」是偏指代词，代「我」：字面是「被原谅」，实为「原谅我」。这类「虚化副词」是翻译的高频难点——「相」「见」作偏指时须译出具体人称。</span>

**「且」的多职**。「且」可作连词（而且：〈「且壮士不死即已」〉）、副词（将要：〈「存者且偷生」〉；尚且：〈「且焉置土石」〉）。辨「且」之义，看它与前后词语的语法关系。

## 5 小结

- 代词三类：**人称**（我吾余予、汝尔若乃而、其之）、**指示**（此是斯兹、彼其夫）、**疑问**（谁孰何奚曷胡安焉）。
- 疑问代词作宾语前置，否定句代词宾语前置——与《宾语前置》两条件直接对应。
- 副词按**范围、程度、时间、否定**分类；「皆、甚、既、不」等高频词须逐一掌握。
- 最易混副词：「甚」作补语、「尝」表曾经、「相」「见」偏指、「且」兼连副。
- 代词副词是虚词的「地基」：读懂它们，介词、连词、语气词才能接着学。
- 虚词虽无实义，却是句法关系的最强信号——「之乎者也」正是汉语的句法枢纽。

在下一节，我们将继续虚词之旅：**介词、连词与语气词**——「于、以、为、与」的介词用法、「而、则、且、以」的连词用法、「也、矣、乎、哉、焉」的语气功能，把虚词系统补完整。
