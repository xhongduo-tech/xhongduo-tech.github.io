## 为什么从数量性状开始

到此为止，我们研究的都是**离散性状**（有/无、红花/白花、等位基因频率）。
可生物体最引人注目的性状——身高、体重、产奶量、智力、抗病力——都是**连续分布**的，受**许多微效基因**与**环境**共同作用。
这就是**数量性状（quantitative trait）**，而研究它的学科是**数量遗传学（quantitative genetics）**，其核心概念是**遗传力（heritability）**。<span class="marginnote">数量遗传学与前面章节的关系：它把「许多位点各自的小效应」汇总成「一个数字（遗传力）+ 一个方差分解」。孟德尔式的单基因逻辑在这里升级为「多基因 + 环境」的统计逻辑——就像把离散的光谱升级为连续的黑体辐射，信息从「逐个位点」变成「统计参数」。</span>

本篇建立数量性状的模型：从「多基因-环境」分解出发，定义遗传力并讲清它的估计与误读。

## 1 数量性状的方差分解

数量性状表型值 $P$ 由**基因型值（G）**与**环境效应（E）**共同决定，最简单的线性模型：

$$P = G + E$$

于是表型方差可分解为：

$$V_P = V_G + V_E$$

进一步，基因型方差 $V_G$ 还能分解为**加性遗传方差 $V_A$**、**显性方差 $V_D$** 与**上位方差 $V_I$**：

$$V_G = V_A + V_D + V_I$$

**加性方差 $V_A$**是「等位基因效应可加」的部分——它是唯一**可遗传给后代**的部分；显性方差来自同一基因座两等位基因的非加性互作，上位方差来自位点间互作，两者都不稳定地传给后代。<span class="marginnote">为什么只有 $V_A$ 可遗传？后代从父母各取一个等位基因，等位基因的效应是「加减法」；而显性（两位等位基因配对）与上位（位点间组合）在配子形成时被打破，重组使这些非加性组合在子代中不能可靠重现。这个「只有加性可遗传」的结论是数量遗传学的第一课，也是育种选择的基础。</span>

## 2 遗传力的两种定义

**广义遗传力（broad-sense heritability）$H^2$**：

$$H^2 = \frac{V_G}{V_P}$$

度量表型差异中**所有**遗传因素（加性 + 显性 + 上位）所占比例。

**狭义遗传力（narrow-sense heritability）$h^2$**：

$$h^2 = \frac{V_A}{V_P}$$

度量表型差异中**加性遗传效应**所占比例——也是预测「父母-子女相似度」与「选择响应」的关键参数。<span class="marginnote">育种和进化里几乎总是用狭义遗传力 $h^2$，因为只有它能预测选择响应（下节的育种者方程 $R = h^2 S$）。广义遗传力容易高估「可遗传程度」，比如无性系植物 $H^2$ 可以很高，但籽实后代完全不能保持——因为显性与上位不传。看到「遗传力」三个字，先确认是广义还是狭义。</span>

**辨析｜易错点：** 遗传力是**群体、环境特定**的参数，不是性状的固有属性——同一个性状在不同群体、不同环境下 $h^2$ 可以差异巨大。**遗传力高 ≠ 「遗传决定」**：在一个环境完全一致、遗传差异大的实验群体里，$h^2$ 可以很高，但这不意味着个体差异「不可改变」——环境一换，$h^2$ 就变。最著名的误读是把「$h^2 = 0.8$」说成「80% 由基因决定、20% 由环境决定」——它说的其实是「在这个群体、这个环境里，表型方差有多大比例来自加性遗传」，绝不是「个体的成因比例」。

## 3 遗传力的估计方法

**亲缘回归 / 同胞分析**：利用已知亲缘关系个体的表型相似度估计。经典方法是**亲子回归**：$h^2$ 近似等于子女表型对父母均值的回归斜率（中亲回归）：

$$h^2 \approx b_{O,MP}$$

因为子女与中亲（双亲均值）共享一半加性效应。
**双生子法**是人类遗传力估计的经典工具：比较同卵双生（共享 100% 基因）与异卵双生（共享 50%）的表型相似度，$h^2 \approx 2(r_{MZ} - r_{DZ})$。<span class="marginnote">双生子法的逻辑：同卵与异卵的环境相似度假设相同，那么两者表型相关之差就来自「遗传共享程度之差」（100% − 50%）。它估算的是广义遗传力，且依赖「等环境假设」——同卵双生常被更相似地对待，这会让估计偏高。现代方法用「混合模型 + 全基因组亲缘矩阵」（GREML）直接从无关个体估计 $h^2$，绕开了双生子假设。</span>

**选择实验**：从选择响应反推 $h^2$（见下节公式）。

**现代基因组方法**：用 SNP 亲缘关系估计 **SNP 遗传力 $h^2_{SNP}$**——只捕捉「能被常见 SNP 标签的加性变异」，是 $h^2$ 的下界。全基因组关联研究里「缺失遗传力（missing heritability）」的讨论，正是围绕 $h^2$ 与 $h^2_{SNP}$ 的差距展开的。

## 4 数值算例：方差分解与亲子回归

用数字感受方差分解与 $h^2$ 的亲子回归含义。
设某群体身高表型方差 $V_P = 100$（单位 cm²），其中加性方差 $V_A = 40$、显性方差 $V_D = 10$、上位方差 $V_I = 10$、环境方差 $V_E = 40$。

$$h^2 = \frac{V_A}{V_P} = \frac{40}{100} = 0.4, \qquad H^2 = \frac{V_G}{V_P} = \frac{60}{100} = 0.6$$

**亲子回归**：中亲（双亲均值）与子女的回归斜率约等于 $h^2 = 0.4$。若双亲均值比群体均值高 10 cm，子女平均约高出 $0.4 \times 10 = 4$ cm——子女只「继承」了双亲优势的四成，其余六成在配子形成与环境中消散。

**表型预测**：子女表型 = 群体均值 + $h^2 \times$（中亲偏离）——这就是育种者方程（下一节）的亲子版。

**辨析｜易错点：** $H^2 = 0.6$ 与 $h^2 = 0.4$ 的差距（$V_D + V_I$）说明：这 0.6 的「遗传度」里只有 0.4 能在选育中兑现。**只看 $H^2$ 会高估选育潜力**——这正是「遗传力」必须区分广义/狭义的原因。

## 5 数值算例：双生子法

把双生子公式用到具体数字上，并把方差拆成三份。
设同卵双生表型相关 $r_{MZ} = 0.85$、异卵双生相关 $r_{DZ} = 0.55$：

| 分量 | 公式 | 数值 |
| --- | --- | --- |
| 加性遗传（狭义遗传力） | $h^2 \approx 2(r_{MZ} - r_{DZ})$ | $0.60$ |
| 共同环境 | $c^2 \approx 2r_{DZ} - r_{MZ}$ | $0.25$ |
| 个体环境 + 测量误差 | $e^2 = 1 - h^2 - c^2$ | $0.15$ |

**解读**：三份方差加起来恰好为 1——$0.60 + 0.25 + 0.15 = 1$。这个分解说明：身高表型差异约六成来自加性遗传、两成半来自共享家庭环境、一成半来自个体独有环境。**双生子法不只给出一个 $h^2$，还把「家庭共享」与「个体独有」环境剥离开来**——这正是它比简单亲子回归提供更多信息的地方。

**辨析｜易错点：** 双生子法依赖「等环境假设」——如果同卵双生被父母更相似地对待（更常穿同款、更少被区别），$r_{MZ}$ 会被人为抬高，$h^2$ 被高估。此外它估计的是**广义**遗传力（含显性与上位），与育种关心的狭义 $h^2$ 并不严格相等。现代 GREML 方法用无关个体的 SNP 亲缘矩阵估计狭义 $h^2_{SNP}$，但只能捕捉「常见 SNP 标签到」的变异，因此常低于双生子法结果——这正是「缺失遗传力」争论的核心。

## 6 术语速查表

| 术语 | 英文 | 一句话定义 |
| --- | --- | --- |
| 数量性状 | quantitative trait | 连续分布、多基因 + 环境决定 |
| 遗传力 | heritability | 表型方差中遗传方差所占比例 |
| 广义 / 狭义遗传力 | $H^2$ / $h^2$ | $V_G/V_P$ 与 $V_A/V_P$ |
| 加性方差 | additive variance | 唯一可稳定遗传的方差分量 $V_A$ |
| 双生子法 | twin method | $h^2 \approx 2(r_{MZ} - r_{DZ})$ |
| SNP 遗传力 | $h^2_{SNP}$ | 仅由常见 SNP 标签到的加性变异 |

## 7 小结

- **数量性状**由多基因 + 环境决定：$V_P = V_G + V_E$，$V_G = V_A + V_D + V_I$。
- **只有加性方差 $V_A$ 可遗传**——显性与上位在配子形成时被打破。
- 广义遗传力 $H^2 = V_G/V_P$，狭义 $h^2 = V_A/V_P$；进化与育种用狭义。
- 估计方法有亲缘回归、双生子法、选择实验与 GREML；遗传力是群体/环境特定参数，不可解读为「个体成因比例」。
- 数值算例：$r_{MZ}=0.85$、$r_{DZ}=0.55$ → $h^2 \approx 0.60$、$c^2 \approx 0.25$、$e^2 \approx 0.15$。
- 双生子法把「家庭共享」与「个体独有」环境剥离开，但依赖等环境假设。
- 遗传力高 ≠ 「遗传决定」：它是群体与环境的函数，环境改变即失效。
- $h^2$ 预测选择响应的前提是 $h^2$ 相对稳定、无环境趋势、无世代重叠。
