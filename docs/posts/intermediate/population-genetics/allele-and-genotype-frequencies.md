## 为什么从频率开始

上一节我们建立了度量变异的指标，但要描述一个群体「此刻处于什么状态」，需要更精细的语言。
试想：两个群体都有 50% 的个体携带某个稀有等位基因，可一个群体的杂合子特别多、另一个几乎全是携带者纯合——它们在**遗传构成**上其实是两个不同的群体。<span class="marginnote">「状态」一词借用自物理学：群体遗传学把整个群体抽象成一组频率数字，就像热力学把无数分子的运动抽象成温度、压强。频率的演化方程，就相当于群体的「运动方程」。</span>

因此，群体遗传学的第一块基石是把群体**分层**描述：先数基因型的比例（**基因型频率**），再由基因型频率推算出等位基因的比例（**等位基因频率**）。
这两个量之间的换算关系——以及它成立的前提——正是下一节 Hardy-Weinberg 定律的直接入口。

## 1 基因型频率

考虑一个常染色体上的位点，有两个等位基因 $A$ 和 $a$。
一个二倍体个体有三种基因型：$AA$、$Aa$、$aa$。
设群体大小为 $N$（个体数），三种基因型的个体数分别为 $N_{AA}$、$N_{Aa}$、$N_{aa}$，且 $N_{AA} + N_{Aa} + N_{aa} = N$。

**基因型频率（genotype frequency）**定义为各基因型个体数占群体总数的比例：

$$f_{AA} = \frac{N_{AA}}{N}, \qquad f_{Aa} = \frac{N_{Aa}}{N}, \qquad f_{aa} = \frac{N_{aa}}{N}$$

三个频率之和恒为 1：$f_{AA} + f_{Aa} + f_{aa} = 1$。
这是遗传构成的第一层描述——它告诉我们个体层面的组合情况，却还没有告诉我们单个等位基因的「库存量」。

注意基因型频率是**经验可测**的：只要对个体逐个分型（表型、电泳、测序均可），数一数即可。
它是群体遗传学里「直接观测」的层次。

## 2 等位基因频率

**等位基因频率（allele frequency / gene frequency）**指某个等位基因占该位点全部等位基因的比例。每个二倍体个体在该位点有 2 个等位基因，所以群体共有 $2N$ 个等位基因。$A$ 等位基因的总数是 $2 \times N_{AA} + 1 \times N_{Aa}$（$AA$ 个体贡献 2 个，$Aa$ 贡献 1 个），于是：

$$p = f(A) = \frac{2 N_{AA} + N_{Aa}}{2N} = f_{AA} + \tfrac{1}{2} f_{Aa}$$

同理 $q = f(a) = f_{aa} + \tfrac{1}{2} f_{Aa}$，且 $p + q = 1$。
这里 $q$ 的系数是 $\tfrac{1}{2}$，因为**杂合子只贡献一半的等位基因到 $A$ 池、一半到 $a$ 池**——这正是孟德尔分离定律在群体层面的体现。<span class="marginnote">这一步「杂合子对半分」是整个学科最不起眼却最关键的桥梁：它把个体层面的基因型构成，翻译成了基因层面的等位基因库存。后面几乎所有模型的动态方程，都建立在「$p = f_{AA} + \tfrac{1}{2} f_{Aa}$」这条换算之上。</span>

等位基因频率与基因型频率是**两个不同层次的描述**：基因型频率是 3 个数（受 1 个约束，自由度为 2），等位基因频率是 2 个数（受 1 个约束，自由度为 1）。
一般地，一个基因型频率向量可以决定唯一的等位基因频率，但**反过来不成立**——许多不同的基因型频率组合可以给出同一个 $p$。
这中间的「缺失信息」，正是随机配对假设（Hardy-Weinberg）要填补的。

## 3 多等位基因与 X 连锁位点

两个等位基因是最简情形，推广到 $m$ 个等位基因 $A_1, A_2, \ldots, A_m$ 时，纯合基因型 $A_i A_i$ 的频率记 $f_{ii}$，杂合基因型 $A_i A_j$（$i \neq j$）记 $f_{ij}$，则：

$$p_i = f_{ii} + \frac{1}{2} \sum_{j \neq i} f_{ij}, \qquad \sum_{i=1}^{m} p_i = 1$$

X 连锁位点需要特别小心。
雄性（XY 或 ZW 中的异配性别）只有一份 X 连锁基因，因此雄性的基因型频率就是等位基因频率；而雌性有两条 X，仍是二倍体计法。
当两性频率不同时，整个群体的 $p$ 需要按两性加权平均，且两性频率会以「来回振荡」的方式逐步趋同——这一点在随后的演化动态中会看到。

一个 X 连锁的数值例子：设雌性频率 $p_f = 0.7$、雄性频率 $p_m = 0.3$、两性数量相等，则整体频率 $p = (p_f + p_m)/2 = 0.5$。下一代的雄性 X 染色体全部来自母亲，所以子代雄性频率 $p_m' = p_f = 0.7$；子代雌性各取一条 X，来自父亲与母亲各半，故 $p_f' = (p_f + p_m)/2 = 0.5$。于是 $p_m$ 每代跳向 $p_f$、$p_f$ 每代回到两性均值——两性频率以阻尼振荡快速趋同。这就是 X 连锁位点特有的「追赶」动力学，常染色体位点没有这个现象，因为两性都从双方各取一份拷贝。

## 4 公式解析：$p = f_{AA} + \tfrac{1}{2} f_{Aa}$

这条公式是整个学科用得最多的换算，分三步看：

- **第一步，清点库存**：$A$ 等位基因的总数 = 纯合子 $AA$ 个体的 2 份 + 杂合子 $Aa$ 个体的 1 份，即 $2N_{AA} + N_{Aa}$。
- **第二步，除以总池**：总等位基因数是 $2N$，故 $p = (2N_{AA} + N_{Aa}) / (2N)$。
- **第三步，化成频率**：把分子分母同除 $N$，$p = f_{AA} + \tfrac{1}{2} f_{Aa}$。杂合子贡献的 $\tfrac{1}{2}$，就是孟德尔分离定律的代数化身。

**辨析｜易错点：** 初学者常误以为「$Aa$ 的一半给 $A$」意味着 $p$ 永远等于 $f_{AA} + \tfrac{1}{2}f_{Aa}$ 而忽略了这是**定义式**，不是结果式——它不依赖任何假设，只要基因型计数正确就恒成立。真正的假设出现在**由 $p$ 反推基因型频率**那一步：那需要随机配对，正是下一节 Hardy-Weinberg 定律的内容。另外注意，基因型频率总和为 1、等位基因频率总和也为 1，但两者**维度不同**，别把 $p + q = 1$ 误当成基因型频率也满足 $f_{AA} + f_{Aa} = 1$。

## 5 数值算例：从一次分型走到频率

把公式落到实际数字上。设某常染色体位点对 400 个个体分型，结果如下：

| 基因型 | 个体数 | 基因型频率 |
| --- | --- | --- |
| $AA$ | 144 | $144/400 = 0.36$ |
| $Aa$ | 192 | $192/400 = 0.48$ |
| $aa$ | 64 | $64/400 = 0.16$ |
| 合计 | 400 | 1.00 |

**第一步，直接算基因型频率**：$f_{AA} = 0.36$，$f_{Aa} = 0.48$，$f_{aa} = 0.16$，三者相加为 1，检验通过。

**第二步，由基因型频率推等位基因频率**：

$$p = f_{AA} + \tfrac{1}{2} f_{Aa} = 0.36 + 0.24 = 0.60, \qquad q = f_{aa} + \tfrac{1}{2} f_{Aa} = 0.16 + 0.24 = 0.40$$

**第三步，独立核算**：$p = (2 \times 144 + 192)/(2 \times 400) = 480/800 = 0.60$——两条路线结果一致，说明计数没有自相矛盾。

**关键观察**：$f_{Aa} = 0.48 \neq 2pq = 2 \times 0.6 \times 0.4 = 0.48$？这里恰好相等，但这**纯属巧合**——请记住，$2pq$ 是 Hardy-Weinberg 假设下才成立的比例，而 $p = f_{AA} + \tfrac{1}{2}f_{Aa}$ 永远是定义式。若你换一组计数（如 $AA=180, Aa=120, aa=100$，$p = 0.6$），会发现 $f_{Aa}=0.30$ 与 $2pq=0.48$ 明显不符——**基因型频率与等位基因频率各自独立，只在随机配对时才满足 H-W 比例**。

## 6 术语速查表

| 术语 | 英文 | 一句话定义 |
| --- | --- | --- |
| 基因型频率 | genotype frequency | 某基因型个体占群体的比例，经验可测 |
| 等位基因频率 | allele frequency | 某等位基因占该位点全部拷贝的比例 |
| 多态位点 | polymorphic site | 常见等位基因频率不超过 0.95 的位点 |
| 期望杂合度 | expected heterozygosity | $H = 1 - \sum p_i^2$，随机配对下的杂合子比例 |
| X 连锁位点 | X-linked locus | 雄性单拷贝、雌性双拷贝，两性需加权 |
| 显性等位基因 | dominant allele | 杂合子中表现型得以显现的那个等位基因 |
| 分离比 | segregation ratio | 孟德尔式后代基因型的比例，如 1:2:1 |

## 7 小结

- **基因型频率**：$f_{AA}, f_{Aa}, f_{aa}$，是经验可测的个体层次描述，三者之和为 1。
- **等位基因频率**：$p = f_{AA} + \tfrac{1}{2} f_{Aa}$，$q = f_{aa} + \tfrac{1}{2} f_{Aa}$，由基因型频率唯一确定。
- 基因型频率到等位基因频率是**单向换算**；反推需要额外的配对假设。
- 多等位基因与 X 连锁位点需要推广公式，X 连锁要区分两性的频率与加权。
- 数值算例提醒我们：$2pq$ 只在随机配对时成立，而定义式 $p = f_{AA} + \tfrac{1}{2}f_{Aa}$ 永远成立。
- X 连锁位点因雄性单拷贝，两性频率以「追赶」动力学趋同，与常染色体位点不同。
- 从基因型频率推等位基因频率是**单向换算**：信息在换算中损失，反推要靠随机配对假设。
- 频率是群体的「状态变量」：基因型频率与等位基因频率从两个层次描述同一群体，二者的关系是整个学科一切运算的起点。

在下一节，我们将补上「由 $p$ 反推基因型频率」的完整链条——这就是 **Hardy-Weinberg 平衡定律**：在哪些假设下、为什么基因型频率能由等位基因频率唯一确定，以及它如何成为整个学科的第一座零模型。
