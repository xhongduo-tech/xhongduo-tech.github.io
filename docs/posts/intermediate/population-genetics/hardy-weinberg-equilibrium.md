# Hardy-Weinberg 平衡定律

<div class="epigraph">

## 为什么从平衡定律开始

上一节我们学会了描述群体状态的两个层次——基因型频率与等位基因频率，并指出「由 $p$ 反推基因型频率」需要额外的假设。
Hardy-Weinberg 定律（简称 H-W 定律）恰恰补上了这块拼图：它给出一个**零模型（null model）**，描述在没有任何进化力量作用时，群体应该呈现的「默认状态」。<span class="marginnote">零模型是科学中最重要的思维工具之一：先把一切影响清空，得到一个理想基线，再把真实观测与基线比较，差异就是「信号」。Hardy-Weinberg 平衡之于群体遗传学，正如理想气体之于热力学、均匀分布之于统计检验。</span>

1908 年，英国数学家 G. H. Hardy 与德国医生 Wilhelm Weinberg 几乎同时独立发表这条定律，反驳了当时流行的错误观念「显性等位基因会一代代扩散到吞没隐性等位基因」。
他们证明：**在一个满足特定假设的群体里，等位基因频率逐代不变，基因型频率一代之内就稳定在 $p^2 : 2pq : q^2$。** 一个显性等位基因并不会「吞噬」隐性等位基因——这正是本节要推导的结论。

## 1 定律的假设条件

H-W 定律的成立依赖于一组理想化假设，通常列出五条：

**① 大群体（无限大）**：忽略随机漂变的效应，频率波动可忽略。

**② 随机交配（panmixia）**：个体之间的交配不按基因型或表型偏好选择，配子随机结合。

**③ 无突变**：等位基因不会变成另一种。

**④ 无选择**：所有基因型有相同的生存与繁殖能力。

**⑤ 无迁移**：没有个体迁入或迁出改变频率。

在这五条假设下，群体被称为处于 **Hardy-Weinberg 平衡（H-W equilibrium）**。<span class="marginnote">现实群体几乎不可能同时满足全部五条，所以 H-W 定律的价值不在「描述现实」，而在「提供基线」：把现实观测与这条基线对比，就能定位是哪一种进化力量在起作用——杂合子偏少提示近交，频率逐代漂移提示漂变或选择。这个「基线-偏差」框架贯穿整个专题。</span>

## 2 一代到达平衡的推导

设初始群体中 $A$ 的等位基因频率为 $p$、$a$ 的频率为 $q$，$p + q = 1$。
随机交配意味着配子随机结合——雌雄配子各自按频率 $p$、$q$ 携带 $A$、$a$，结合概率为两者乘积：

| 配子结合 | 后代基因型 | 概率 |
| --- | --- | --- |
| $A \times A$ | $AA$ | $p \times p = p^2$ |
| $A \times a$ 或 $a \times A$ | $Aa$ | $2 \times p q = 2pq$ |
| $a \times a$ | $aa$ | $q \times q = q^2$ |

于是子代的基因型频率为 $p^2 : 2pq : q^2$，三者之和 $p^2 + 2pq + q^2 = (p+q)^2 = 1$。
这组频率就是 **H-W 比例（Hardy-Weinberg proportions）**。

关键的一步在下一轮：从这组基因型频率再算等位基因频率，子代中

$$p' = p^2 + \tfrac{1}{2}(2pq) = p^2 + pq = p(p + q) = p$$

**等位基因频率逐代保持不变**，因此基因型频率也永远停在 $p^2 : 2pq : q^2$。这就是 H-W 定律的完整内容：**一代之内基因型频率达到平衡，从此不再改变**——哪怕亲代基因型频率偏离 $p^2 : 2pq : q^2$，只要随机交配，子代就立即校正到 H-W 比例。<span class="marginnote">「一代校正」是 H-W 定律最反直觉也最优雅的性质：假设亲代全是 $AA$（$f_{AA}=1$，$p=1$），这与 $p^2:2pq:q^2$ 当然不符；但亲代只产生 $A$ 配子，随机结合后子代仍是 $AA$——平衡自动成立。更一般地，任何偏离在随机交配一代后即被抹平。</span>

## 3 对「显性扩散谬误」的驳斥

H-W 定律诞生前流传着一个错误直觉：显性等位基因因为「表现型占优」，会逐渐取代隐性等位基因。
用 $p$、$q$ 的语言，这个谬误等价于「$p$ 会逐代增大」。
H-W 定律直接给出反证：

$$p_{t+1} = p_t, \qquad \text{只要五条假设成立}$$

无论 $A$ 是显性还是隐性，等位基因频率都纹丝不动。
显性等位基因的「优势」只是表型层面的现象，在**不施加选择**的群体里，它对等位基因频率毫无影响。
隐性等位基因可以以极低的频率在杂合子中「隐藏」许多代——这是隐性有害等位基因能在群体中长期存在的原因之一，也是近亲繁殖危险的根源（后面近交一节会展开）。

## 4 公式解析：$p^2 + 2pq + q^2 = 1$

这条公式是 H-W 定律的面孔，三项各有意义：

- **$p^2$**：两个 $A$ 配子结合的纯合子 $AA$ 频率。由独立性，概率相乘。
- **$2pq$**：$A$ 配子与 $a$ 配子结合的杂合子频率。因子 2 来自两条路径——父 $A$ 母 $a$、父 $a$ 母 $A$。
- **$q^2$**：纯合隐性 $aa$ 的频率。

三项之和为 1，因为 $(p+q)^2 = 1^2$ 恒成立。
**辨析｜易错点：** 不要只背 $2pq$ 而忘了「为什么是 2」——它是两种受精方向之和，不是多余的外衣。
也不要以为 H-W 比例要求「每代都是 $p^2:2pq:q^2$ 分布」才算平衡：平衡的真正定义是**等位基因频率不变**，基因型频率只是它的推论。
此外，$p^2 + 2pq + q^2 = (p+q)^2$ 这个配方还提醒我们：**只要 $p+q=1$，H-W 比例必然归一**，这是纯代数事实，与生物学假设无关。

## 5 数值算例：一代校正的完整演示

用一个「偏离 H-W 比例」的亲代群体，演示随机交配一代后如何自动校正。

设亲代基因型频率 $f_{AA} = 0.70$、$f_{Aa} = 0.20$、$f_{aa} = 0.10$。先算等位基因频率：

$$p = f_{AA} + \tfrac{1}{2} f_{Aa} = 0.70 + 0.10 = 0.80, \qquad q = 0.20$$

亲代杂合子只有 0.20，而 H-W 期望的 $2pq = 2 \times 0.8 \times 0.2 = 0.32$——**亲代明显偏离平衡**（杂合子偏少）。随机交配一代后：

| 世代 | $f_{AA}$ | $f_{Aa}$ | $f_{aa}$ | $p$ |
| --- | --- | --- | --- | --- |
| 亲代（偏离 H-W） | 0.70 | 0.20 | 0.10 | 0.80 |
| 子代（随机交配一代） | $p^2 = 0.64$ | $2pq = 0.32$ | $q^2 = 0.04$ | 0.80 |

**解读**：子代的基因型频率自动校正为 $0.64/0.32/0.04$，而等位基因频率从亲代到子代保持 0.80 不变。**「基因型频率被重新分配，等位基因频率纹丝不动」**——这正是 H-W 定律「一代校正」最直观的演示，也是后面一切「零模型 + 偏离检验」的起点。

再验证一个极端情形：亲代全部是杂合子（$f_{Aa} = 1$，$p = 0.5$），随机交配一代后子代为 $0.25/0.50/0.25$——即使亲代与 H-W 比例相差最远，一代之内也完全收敛。

## 6 术语速查表

| 术语 | 英文 | 一句话定义 |
| --- | --- | --- |
| 随机交配 | random mating / panmixia | 配子随机结合，无交配偏好 |
| H-W 比例 | Hardy-Weinberg proportions | $p^2 : 2pq : q^2$ 的基因型分布 |
| 零模型 | null model | 无进化力量时的基线状态 |
| 平衡 | equilibrium | 等位基因频率逐代不变的世代状态 |
| 显性扩散谬误 | dominance spread fallacy | 「显性会吞没隐性」的错误直觉 |

## 7 小结

- **Hardy-Weinberg 定律**：在无限大、随机交配、无突变、无选择、无迁移的群体中，等位基因频率逐代不变，基因型频率一代内达到 $p^2 : 2pq : q^2$。
- 五条假设构成**零模型**；现实群体几乎不能满足，其价值在于提供基线。
- **一代校正**：任何偏离 H-W 比例的基因型分布，随机交配一代即被抹平。
- H-W 定律驳斥「显性扩散谬误」：不施加选择时，显性/隐性对等位基因频率毫无影响。
- 数值算例：亲代 $0.70/0.20/0.10$ 一代校正为 $0.64/0.32/0.04$，$p$ 保持 0.80 不变。
- 平衡的定义是「等位基因频率不变」，基因型比例只是它的推论。
