# 群体遗传学

群体遗传学是遗传学与进化生物学的定量核心分支，研究群体内遗传变异及其在世代间的变化规律：以 Hardy-Weinberg 平衡为基石，用概率与统计模型刻画遗传漂变、自然选择、突变、基因流与近交等进化力量如何共同塑造等位基因频率。从经典平衡定律到溯祖理论与分子钟，再到数量遗传与群体基因组学，它为理解进化、育种与人类遗传学提供了可检验的数学框架。

## 对标教材

- Daniel L. Hartl, Andrew G. Clark, *Principles of Population Genetics*（4th ed., Sinauer Associates）
- John H. Gillespie, *Population Genetics: A Concise Guide*（2nd ed., Johns Hopkins University Press）
