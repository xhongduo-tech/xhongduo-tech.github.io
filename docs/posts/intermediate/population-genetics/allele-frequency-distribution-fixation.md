## 为什么从分布与固定概率开始

上一节我们建立了漂变的抽样模型，知道频率每代「期望不变、方差非零」。
但一个随机过程光有前两步还不够：我们要知道长期下来会发生什么——频率最终会变成什么样？
哪个等位基因会赢？
本篇回答这两个问题，它们分别对应**瞬态分布（transient distribution）**与**吸收概率（fixation probability）**。<span class="marginnote">把漂变想象成醉汉在一条从 0 到 1 的走廊里随机走动：0 与 1 是两扇吸人的门，一旦踏进就出不来（等位基因丢失或固定）。醉汉每一步的方向完全随机，但「最终会从哪扇门出去」的概率却可以由起点精确算出——这是马尔可夫链「吸收」性质的标准结论。</span>

## 1 频率的瞬态分布

在 WF 模型中，频率 $p_t$ 是一个马尔可夫链：给定 $p_t$，$p_{t+1}$ 的条件分布由二项分布给出。
经过若干代，$p_t$ 的分布会呈现「双峰堆积」：概率质量逐渐向两端的 0 和 1 聚集，中间频率越来越不可能。<span class="marginnote">直觉：漂变没有「中心引力」，只有边界吸收。所以频率分布不是像正态那样收敛到均值，而是像两堆沙一样分别滚向两头的边界。这正是它与很多随机过程（如中心极限定理场景）不同的地方——状态空间有吸收壁。</span>

精确的瞬态分布需要对 $2N \times 2N$ 转移矩阵反复乘方，计算量大；连续近似用**扩散方程（diffusion equation）**，即 Wright–Fisher 扩散过程。
令 $x = p$，Fokker–Planck（正向 Kolmogorov）方程为：

$$\frac{\partial \phi(x,t)}{\partial t} = -\frac{\partial}{\partial x}\big[M(x)\phi\big] + \frac{1}{2}\frac{\partial^2}{\partial x^2}\big[V(x)\phi\big]$$

对纯漂变，漂移项 $M(x) = 0$，方差项 $V(x) = x(1-x)/(2N)$。
这个方程的稳态解（把 0 与 1 当作反射墙时）是著名的 **平衡分布（stationary distribution）**：

$$\phi(x) \propto \frac{1}{x(1-x)}$$

在 0 与 1 附近 $\phi$ 发散——变异偏向于「极稀有」或「极常见」，中间频率罕见。
这是漂变「双峰化」的连续版。

## 2 固定概率：马尔可夫链方法

考虑一个没有突变的群体，初始 $A$ 频率为 $p$。
因为 0 与 1 是吸收态，$A$ 最终要么固定（达频率 1）要么丢失（达频率 0）。
定义固定概率 $u(p)$。
对 WF 模型，有经典结论：

$$u(p) = p$$

**任何一个等位基因，其固定概率恰好等于它的当前频率。** 一个频率 0.5 的中性等位基因有一半概率固定，一个稀有突变（$p = 1/(2N)$）固定概率为 $1/(2N)$。<span class="marginnote">这是漂变最深刻也最简洁的结果：漂变是「无偏的」，它不偏爱任何一个等位基因，所以每个基因拷贝在未来的「赢面」完全相同。于是固定概率 = 该等位基因占拷贝的比例。反过来读：一个新突变在二倍体群体里固定概率是 $1/(2N)$——它几乎注定丢失，这也解释了为何多数新突变沉默在历史里。</span>

**推导**：对 WF 模型，利用条件期望，$u(p) = \mathbb{E}[u(p')]$。令 $u(p) = \alpha + \beta p$ 猜一个线性解，代入二项抽样后 $u(p') = \alpha + \beta p'$ 且 $\mathbb{E}[p'] = p$，得 $u(p) = \alpha + \beta p$。边界条件 $u(0) = 0$（已丢失则不可能固定）、$u(1) = 1$（已固定则确定固定），解得 $\alpha = 0, \beta = 1$，即 $u(p) = p$。对 Moran 模型做同样的 Markov 链论证，得到**相同的线性结论** $u(p) = p$。

## 3 固定时间与变异耗竭

固定概率只是「能否」，接下来是「多久」。
中性等位基因从频率 $p$ 开始到固定（或丢失）的**平均时间**，对 WF 模型近似为：

$$\bar{t} \approx -4N\left[p \ln p + (1-p)\ln(1-p)\right]$$

这里 $\bar{t}$ 以代为单位的期望固定/丢失时间。
有趣的是，从单个新突变（$p = 1/(2N)$）开始，平均固定时间约为 $4N$ 代——但这只是平均值，实际分布很宽，短则几代，长则成千上万代。<span class="marginnote">$4N$ 代是什么概念？人类有效群体约一万量级，$4N$ 约四万代、近百万年——中性变异从出现到固定，平均要消耗极其漫长的时间。这解释了为什么群体内总有大量中性多态：变异产生很快、固定很慢，两者之间堆起了一座「多态性仓库」。</span>

固定时间的量级还告诉我们：**漂变是慢变量**。
这也为下一节「有效群体大小」埋下伏笔——决定漂变速度的不是表面个体数，而是某个「有效」尺度。

## 4 公式解析：固定概率 $u(p) = p$

这条「固定概率等于频率」的结论是漂变理论的心脏，它的推导依赖马尔可夫链的**鞅性质**：

- **第一步，写条件期望**：$u(p) = \mathbb{E}[u(p')]$——固定概率满足「当前值等于下一步的期望」，因为一旦过程走到吸收态就结束。
- **第二步，猜线性形式**：设 $u(p) = \alpha + \beta p$。因为 WF 抽样下 $\mathbb{E}[p'] = p$（无偏），所以 $\mathbb{E}[u(p')] = \alpha + \beta p = u(p)$，线性形式自洽。
- **第三步，定系数**：边界 $u(0) = 0$（已丢失）、$u(1) = 1$（已固定），得 $\alpha = 0, \beta = 1$。

**为什么「无偏」这么关键？** 漂变不偏向任何等位基因，每个基因拷贝的「赢面」相同，所以一个等位基因的固定概率 = 它占拷贝的比例 $p$。任何有偏的力量（如选择）都会破坏这个线性关系——这正是第 16 篇引入选择后固定概率公式变复杂的根源。

**数值直觉**：一个新突变 $p = 1/(2N)$，固定概率 $1/(2N)$。若 $N = 1000$，概率只有 $0.05\%$——绝大多数新突变注定消失，这解释了为何观察到的固定突变如此之少、而群体内多态如此之多。

## 5 数值算例：把固定概率落到数字上

设一个二倍体群体 $N = 1000$，则该位点共有 $2N = 2000$ 个基因拷贝。一个刚刚出现的新突变只占 1 个拷贝：

$$p = \frac{1}{2N} = \frac{1}{2000} = 0.0005, \qquad u(p) = p = 0.05\%$$

不同初始频率的固定概率一览：

| 初始 $A$ 拷贝数 | 初始频率 $p$ | 固定概率 $u(p) = p$ |
| --- | --- | --- |
| 1（单拷贝新突变） | 0.0005 | 0.05% |
| 2（一个杂合个体） | 0.001 | 0.1% |
| 1000（一半拷贝） | 0.5 | 50% |
| 2000（已全固定） | 1.0 | 100% |

**解读**：固定概率与频率完全成正比——把拷贝数翻倍，固定概率就翻倍。这背后就是「每个基因拷贝的赢面完全相同」的无偏原则。一个中等频率（$p = 0.5$）的等位基因有整整一半的概率固定，而一个新突变几乎注定消失。

**一个反直觉推论**：如果位点上有两个独立的中性等位基因、各自频率 0.5，那么它们中**至少一个**最终固定的概率是 $0.5 + 0.5 - 0.5 \times 0.5 = 0.75$，而不是 1。因为漂变可能让它们各自丢失后再由后来的突变补上，也可能让两者在到达吸收态前共存很久。**固定是一场「谁先到 1」的比赛，而不是「总有一个赢」的保证。**

**扩散近似的适用范围**：固定概率 $u(p) = p$ 对 WF 与 Moran 模型都是**精确**的中性结论，不依赖大群体近似；但固定时间公式 $\bar{t} \approx -4N[p\ln p + (1-p)\ln(1-p)]$ 是扩散近似，在 $N$ 很小时偏差明显。当群体只有 $N = 10$ 量级时，实际固定时间的分布会明显偏离这个期望值——记住「公式给的是量级，不是精确预报」。

## 6 术语速查表

| 术语 | 英文 | 一句话定义 |
| --- | --- | --- |
| 吸收态 | absorbing state | 一旦到达就永不离开的状态（频率 0 或 1） |
| 固定概率 | fixation probability | 从当前频率出发最终达到频率 1 的概率 |
| 瞬态分布 | transient distribution | 到达吸收态之前各频率的概率分布 |
| 扩散方程 | diffusion equation | 漂变的连续时间近似（Fokker–Planck 方程） |
| 鞅 | martingale | 期望值保持不变的随机过程，固定概率推导的数学基础 |

## 7 小结

- 漂变下频率分布随时间**双峰化**，中间频率罕见，稳态分布 $\phi(x) \propto 1/[x(1-x)]$。
- **固定概率** $u(p) = p$：中性等位基因固定概率等于当前频率，漂变无偏。
- 单拷贝新突变固定概率 $1/(2N)$，几乎注定丢失；平均固定时间约 $4N$ 代。
- 数值算例：$N = 1000$ 时单拷贝固定概率 0.05%；两个等频率等位基因「至少一个固定」的概率只有 0.75。
- 扩散方程是漂变的连续时间标准工具，与离散马尔可夫链模型互为补充。
- 固定概率公式精确、固定时间公式是近似：小群体下时间公式只给量级。

在下一节，我们将离开「理想群体」，问一个更现实的问题：现实群体的繁殖差异、性别失衡与大小波动，如何让漂变的实际强度偏离表面个体数——这就是**有效群体大小** $N_e$ 要校准的「群体有多小」的换算尺。
