# 高维与稀疏情形下的多元统计方法

<div class="epigraph">
<p>当变量的个数超过样本量，经典多元统计的每一个公式都会反咬你一口——除非你承认真正重要的变量其实很少。</p>

## 为什么 p > n 是危机

基因组学一次测几千个基因（$p$ 上万）而样本往往只有几十例（$n$ 只有几十）；电商特征工程造出几千个变量、有效样本却有限。**当 $p > n$ 时，前九篇里几乎所有方法都会立刻崩溃**：$\mathbf{S}$ 是奇异的、$\mathbf{S}^{-1}$ 不存在（Hotelling $T^2$、LDA、马氏距离全部失效）；Wishart 分布要求 $n \geq p$；最小二乘回归有无穷多解。这不是「再小心一点」能绕过的，而是维数灾难的结构性结果。<span class="marginnote">几何直觉：$p$ 维球体几乎全部体积挤在表面，$n$ 个样本在高维空间里稀疏得像撒在夜空中的星星——每个点之间都「远」，任何基于近邻或协方差的估计都被稀释。维数灾难（curse of dimensionality）一词由此而来。</span>

高维统计的救赎建立在一条现实假设上：**真正重要的变量其实很少**。数据是「稀疏的」——少数信号 + 大量噪音。本章的方法全部围绕「怎么在 $p \gg n$ 时仍然找到那根针」展开。

更深层的原因来自**集中现象（concentration of measure）**：高维空间中随机向量的长度高度集中在同一个值附近，样本点之间的距离趋于同质——这意味着「靠距离分辨差异」在高维下天然失效，必须依靠结构（稀疏性）而非稠密的几何信息。理解这一点，就理解为什么高维方法几乎都长着「稀疏」的面孔。

## 1 正则化：把约束写进目标函数

一元/多元回归里，经典估计 $\hat{\boldsymbol{\beta}} = (X'X)^{-1}X'y$ 在 $p > n$ 时因为 $X'X$ 不可逆而无解。**正则化（regularization）**在目标函数上追加一项惩罚，把「无唯一解」变成「有偏但稳定」：

以岭回归为第一个例子，它保留全部 $p$ 个变量（收缩系数），Lasso 则直接替你淘汰变量。两者的对比见下表。

**岭回归（Ridge）**——L2 惩罚：

$$
\hat{\boldsymbol{\beta}}^{\text{ridge}} = \arg\min_{\boldsymbol{\beta}} \Bigl\{\|\mathbf{y} - \mathbf{X}\boldsymbol{\beta}\|^2 + \lambda \|\boldsymbol{\beta}\|_2^2\Bigr\}
$$

解是 $(\mathbf{X}'\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}'\mathbf{y}$——$\lambda\mathbf{I}$ 把不可逆矩阵「抬高」成可逆。**岭回归收缩系数但不置零**，适合「变量多、都想保留一点」的场景。<span class="marginnote">几何上 $\lambda$ 控制解的半径：$\lambda=0$ 时回到最小二乘，$\lambda \to \infty$ 时系数全压向 0。选择 $\lambda$ 用交叉验证——见第 4 节。<strong>岭回归的代价是引入偏差，换来方差的大幅下降</strong>，这正是一元统计里「偏差-方差权衡」的高维版。</span>

**Lasso**——L1 惩罚：

$$
\hat{\boldsymbol{\beta}}^{\text{lasso}} = \arg\min_{\boldsymbol{\beta}} \Bigl\{\|\mathbf{y} - \mathbf{X}\boldsymbol{\beta}\|^2 + \lambda \|\boldsymbol{\beta}\|_1\Bigr\}
$$

L1 罚的几何性质（菱形约束的尖角落在坐标轴上）使**大量系数被精确置零**——Lasso 同时做「估计 + 变量选择」。**Lasso 适合稀疏场景：一千个候选变量，它替你挑出真正有用的那几十个**。弹性网（Elastic Net）把 L1 与 L2 混在一起，兼得稀疏与组稳定性。

### 岭回归 vs Lasso

| 对比项 | 岭回归 | Lasso |
| --- | --- | --- |
| 惩罚 | $\lambda\|\boldsymbol{\beta}\|_2^2$ | $\lambda\|\boldsymbol{\beta}\|_1$ |
| 系数行为 | 收缩，不置零 | 收缩且置零 |
| 变量选择 | 否 | 是 |
| 适用 | 变量相关、都要保留 | 稀疏信号、要解释性 |
| 高维可解 | 是 | 是 |

## 2 高维下的多元方法：稀疏 PCA、稀疏判别、稀疏 CCA

正则化的思想不止回归，整个谱方法家族都能被「稀疏化」：

**稀疏 PCA（SPCA）**：经典 PCA 的载荷是全部变量的混叠，高维下无法解释。SPCA 在「最大化方差」的目标上追加 L1 惩罚，逼载荷变成「少数几个非零」的稀疏向量——每个主成分只由少数变量构成，名字一下子好起了。<span class="marginnote">SPCA 与 PCA 的对比如同 Lasso 与岭回归：PCA 保留所有变量的「混合」，SPCA 只挑几个变量的「组合」。代价是解释性好、方差保留略降——高维下「稍微损失方差换取可解释」通常值得。</span>

**稀疏判别分析（sparse LDA）**：LDA 需要 $\mathbf{S}^{-1}$，$p > n$ 时直接失效。稀疏 LDA 在判别方向上加 L1 惩罚，让判别函数只依赖少数变量——**几千个基因里找出十几个真正能区分两类疾病的基因**，这比给几千个基因都配系数可靠得多。

**稀疏 CCA**：上一节 CCA 的系数在高维下同样会爆炸；稀疏 CCA 对 $\mathbf{a}$、$\mathbf{b}$ 加稀疏约束，只让少数变量进入典型变量。**从基因组到表型的两组高维数据里找「少数关键通路」**，是稀疏 CCA 最典型的舞台。

这三者共享同一个配方：**目标函数 + L1/L2 惩罚，把「不可估」变成「可估且可解释」**。

## 3 高维协方差矩阵的估计

很多多元方法的核心原料是 $\boldsymbol{\Sigma}$，而 $p > n$ 时样本协方差 $\mathbf{S}$ 连正定都谈不上。两条出路：

**收缩估计（shrinkage）**：把 $\mathbf{S}$ 朝某个结构目标（如对角矩阵）收缩：

$$
\hat{\boldsymbol{\Sigma}}_{\text{shrink}} = (1-\alpha)\mathbf{S} + \alpha \mathbf{T}
$$

$\mathbf{T}$ 常取对角矩阵（各变量独立时的协方差），$\alpha \in [0,1]$ 由数据自适应选取。收缩在「数据说了什么」与「我们事先相信什么」之间找平衡——**样本量越小，越该信 $\mathbf{T}$**。<span class="marginnote">直觉：$p \gg n$ 时 $\mathbf{S}$ 的极端特征值被严重夸大（样本特征值谱发散）。收缩把特征值往均值方向拉回，是「借用全局信息救局部估计」的经典手法，也直接影响后续 PCA、LDA 的稳定性。$\alpha$ 的选取可用交叉验证或解析公式（如 Ledoit–Wolf），目标都是让估计的均方误差最小。</span>

**图形 Lasso（graphical lasso）**：目标不是整个 $\boldsymbol{\Sigma}$ 而是**精度矩阵（precision matrix）$\boldsymbol{\Theta} = \boldsymbol{\Sigma}^{-1}$**——它的零元恰好对应条件独立关系，刻画变量间的网络结构。用 $\ell_1$ 惩罚极大化高斯似然，逼出稀疏的 $\hat{\boldsymbol{\Theta}}$（目标是凸问题，可用块坐标下降高效求解）：

$$
\max_{\boldsymbol{\Theta} \succ 0}\ \ln\det\boldsymbol{\Theta} - \operatorname{tr}(\mathbf{S}\boldsymbol{\Theta}) - \lambda\|\boldsymbol{\Theta}\|_1
$$

**图形 Lasso 从 $p$ 个变量的数据里「长出」一张相关网络图**，是基因调控网络、脑网络分析等领域的标准工具。<span class="marginnote">稀疏精度矩阵 = 稀疏条件独立图：$\hat{\Theta}_{jk}=0$ 表示「给定其余所有变量后 $j$ 与 $k$ 条件独立」。这比相关矩阵更接近「谁直接影响谁」——相关里混着间接效应，条件独立把间接效应剔除掉了。</span>

## 4 模型选择与交叉验证

高维方法都带着调节参数（$\lambda$、$\alpha$、稀疏度），选不对就白搭。原则是**在独立于训练的数据上验证**：

**交叉验证（cross-validation）**：K 折切分数据，每折用其余数据训练、在当前折上测误差，平均后选使误差最小的 $\lambda$。
**信息准则**：AIC / BIC 给「拟合优度 + 参数个数惩罚」，在低维可计算时快速选模型。
**稳定性选择（stability selection）**：多次重采样，看哪些变量被稳定选中——**「被选中的概率」比「一次选中的名单」可靠得多**。<span class="marginnote">高维推断还有一个重要的「诚实性」问题：用同一份数据既做变量选择又做检验，p 值会系统性偏小。所以高维论文普遍要求「选择样本」与「推断样本」分离，或使用分割样本（data splitting）。这是理解高维文献的关键背景。</span>

在实际操作中，这三个工具常常配合使用：先用交叉验证粗选 $\lambda$ 的量级，再用稳定性选择筛掉「碰巧被选中」的变量，最后在独立验证集上确认——**多一层证据，就少一分把噪音当信号的运气**。

**最后一条纪律**：高维方法给出的是「探索性结论」。它们从成千上万个候选中挑出的变量，需要在独立数据上复现才有说服力——**「找到」一个基因不如「在第二队列里复现」一个基因**。

## 5 公式解析：Lasso 为什么能把系数置零

Lasso 的「稀疏性魔法」来自 L1 惩罚的几何，而不是数学巧合：

- **第一步，改写为约束形式**：$\min \|\mathbf{y}-\mathbf{X}\boldsymbol{\beta}\|^2$ 受 $\|\boldsymbol{\beta}\|_1 \leq t$ 约束。等价的约束版本更容易看几何。
- **第二步，看可行域**：$\|\boldsymbol{\beta}\|_1 \leq t$ 是菱形（$p=2$ 时是旋转 45° 的正方形），$\|\boldsymbol{\beta}\|_2 \leq t$ 是圆。**菱形有尖角，圆没有**。
- **第三步，看最优解位置**：误差的等高线（椭球）与可行域相切。椭球与圆的切点一般落在圆弧上（两坐标都非零）；与菱形的切点**常常正好落在尖角上**（某个坐标恰为零）。
- **第四步，放大到 $p$ 维**：高维时尖角变成「坐标轴上的角」，相切落角上的概率更大——**L1 罚因此系统性地把不重要的系数压到 0**。

**核心结论：Lasso 的稀疏性 = L1 球有尖角**。这条几何直觉不仅解释 Lasso，也解释了为什么稀疏 PCA、稀疏 CCA 全部选用 L1 型惩罚——它们要的正是「把系数钉在 0 上」的尖角。

## 6 小结

- **$p > n$ 危机**：$\mathbf{S}$ 奇异、$\mathbf{S}^{-1}$ 与 Wishart 失效、最小二乘无唯一解；解药是「稀疏性假设 + 正则化」。
- **岭回归**（L2）收缩不置零，**Lasso**（L1）收缩并选择变量，弹性网介于两者之间。
- 谱方法家族全面稀疏化：**稀疏 PCA、稀疏 LDA、稀疏 CCA** 用 L1 惩罚换取可解释性。
- 高维协方差用**收缩估计**救 $\mathbf{S}$，用**图形 Lasso** 估计稀疏精度矩阵、重建条件独立网络。
- 高维结论必须过**交叉验证 / 稳定性选择**，且最好在独立数据上复现——探索不等于确证。
- 高维方法的通用配方：**目标函数 + L1/L2 惩罚 + 交叉验证选 $\lambda$
