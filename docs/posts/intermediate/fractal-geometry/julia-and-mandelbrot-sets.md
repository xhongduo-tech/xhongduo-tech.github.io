## 为什么从 Julia 集与 Mandelbrot 集开始

分形几何最著名的两张「名片」都在复平面上：Julia 集与 Mandelbrot 集。它们源于一个看似天真的问题——**把复函数反复迭代，哪些点会跑远，哪些点会留下？** 答案的边界是一道无穷复杂的曲线：在任何尺度下放大，都能看到新的、与整体相似的旋涡与枝桠。它们不是「造」出来的，而是被迭代**逼**出来的；它们也刷新了我们对「动态系统」的理解——最简单的二次映射 $z \mapsto z^2 + c$ 竟能包含混沌的全部秘密。本专题第 14 篇所依托的复分析（第一级《复数》、第二级《复变函数》）在这里与动力系统、测度论第一次真正相遇。

## 1 复平面上的迭代

对固定参数 $c \in \mathbb{C}$，考虑二次多项式 $f_c(z) = z^2 + c$ 及其迭代 $f_c^{\circ n}(z) = \underbrace{f_c \circ \cdots \circ f_c}_{n \text{ 次}}(z)$。从初始点 $z_0$ 出发，得到轨道（orbit）$z_0, z_1 = f_c(z_0), \dots$

有两个直观的动力学事实：若 $|z_0|$ 很大（比 $|c|$ 和 2 都大得多），轨道必然迅速跑向无穷；若 $z_0$ 靠近 $0$，轨道可能徘徊、可能稳定、也可能逃逸。于是复平面被天然分成两个阵营：**轨道有界的点** 与 **轨道逃逸到无穷的点**。前者的全体称为 **填充 Julia 集（filled Julia set）**：

$$K_c = \{ z \in \mathbb{C} : f_c^{\circ n}(z) \text{ 有界，对所有 } n \ge 0 \}$$

## 2 填充 Julia 集与 Julia 集

**Julia 集（Julia set）** $J_c$ 定义为 $K_c$ 的**边界**：$J_c = \partial K_c$。<span class="marginnote">历史上 Julia 与 Fatou 于 1918—1920 年通过「正则域理论」独立研究迭代，把复平面分成 Fatou 集（轨道行为规则的开集）与 Julia 集（混沌的边界）。$J_c$ 正是 Fatou 集的边界。</span>

为什么边界重要？因为**迭代的混沌全都发生在 $J_c$ 上**：对 $z \in J_c$，微小扰动会让轨道彻底改变走向；而 $J_c$ 之外的点，迭代是「驯良」的。核心性质：

**完全不变性**：$f_c(J_c) = f_c^{-1}(J_c) = J_c$——Julia 集被映射映到自己身上，反向也一样。
- **$J_c$ 是排斥周期点的闭包**：Julia 集上布满周期点，且它们都是排斥的（扰动后逃逸），这给出「$J_c$ 无内点」的直观。
- **自相似性**：$J_c$ 由有限个 $f_c^{-1}$ 的逆像分支拼成，在局部尺度上呈自相似结构。

几个标杆例子：$c = 0$ 时 $f_0(z) = z^2$，$K_0$ 是单位闭圆盘，$J_0$ 是单位圆周；$c$ 在「主心形」内部时，$J_c$ 是一条变形的 Jordan 曲线；$c$ 远离主心形时，$J_c$ 变成一个**康托尔集**（完全不连通）。<span class="marginnote">$J_c$ 的 Hausdorff 维数随 $c$ 变化，介于 0 与 2 之间，几乎处处接近 2。计算它的维数需要第 9 篇的共形 IFS 与热力学形式主义，是当前研究前沿。</span>

## 3 Mandelbrot 集：参数空间的地图

Julia 集是「固定参数 $c$，看动力学」；Mandelbrot 集则是「遍历全部参数 $c$，画地图」：

$$M = \{ c \in \mathbb{C} : K_c \text{ 连通} \} = \{ c \in \mathbb{C} : \text{轨道 } f_c^{\circ n}(0) \text{ 有界} \}$$

关键恒等式是：$K_c$ 连通 $\iff$ 轨道 $f_c^{\circ n}(0)$ 有界。原因在于 Julia 集的连通性与**临界点**（导数零点）的动力学紧密相连：$z = 0$ 是 $f_c$ 唯一的临界点，$K_c$ 是否连通完全由临界轨道的命运决定。于是 Mandelbrot 集只需检查一条轨道——从 $0$ 出发——即可判定。<span class="marginnote">这是「临界点决定全局」的范式：对一般的多项式族，Julia 集的连通性同样由临界轨道的性态决定，称为射影分支结构。Mandelbrot 1980 年用计算机画出 $M$，1991 年 Shishikura 证明 $\dim_H \partial M = 2$。</span>

$M$ 的主心形对应 $f_c$ 有稳定不动点的参数；$c = -3/4$ 处的心形尖端对应周期 2 分岔；沿实轴的细丝是周期 3、4、…… 的分岔链。**在参数空间里逛一圈 $M$，等于看完了二次多项式动力学的一切可能。**

主心形有显式参数方程：$c = \tfrac12 e^{i\theta} - \tfrac14 e^{2i\theta}$（$0 \le \theta < 2\pi$）。它刻画「$f_c$ 有稳定不动点」的参数区域：不动点 $z_*$ 满足 $z_*^2 - z_* + c = 0$ 且 $|2z_*| < 1$。周期 2 灯泡（圆心 $c = -1$、半径 $1/4$）则对应倍周期分岔的边界——从主心形到第一级灯泡，是一条清晰的分岔链。

## 4 公式解析：$M = \{ c \in \mathbb{C} : f_c^{\circ n}(0) \text{ 有界} \}$

$$
M = \{ c \in \mathbb{C} : (f_c^{\circ n}(0))_{n \ge 0} \text{ 是有界序列} \}, \qquad f_c(z) = z^2 + c
$$

三步拆解这条「判据公式」：

- **第一，$f_c(z) = z^2 + c$ 是唯一的规则**：整个分形由这一个二次式迭代产生，没有第二套规则——这正是 $M$ 的惊人之处。
- **第二，初值固定为 $0$（临界点）**：不是任意初值。$0$ 是 $f_c'$ 的零点，迭代从临界点出发，其轨道行为「采样」了系统的全局连通性。
- **第三，有界性判定**：若 $|c| > 2$ 或某个 $|z_n| > 2$，轨道必然逃逸（$|z_{n+1}| \ge |z_n|^2 - |c|$ 立刻放大）。所以「有界」用一条简单的数值规则就可判断——这就是**逃逸时间算法**：迭代到 $|z_n| > 2$ 或迭代步数超限，未逃逸者即属于 $M$。

一句话：**$M$ 是「以 $0$ 为种子、以 $z^2+c$ 为规则、以 2 为界」的生存集。** 每个像素点都对应一个参数 $c$，迭代若干次判定生死，画成图就是那只著名的「蛛形」——整个算法的复杂度低到一台旧电脑都能渲染。

## 5 数值算例：把逃逸时间算法走一遍

判定 $z$ 是否属于 $J_c$ 靠的是第 4 节的界：若某步 $|z_n| > 2$，轨道必然逃逸。于是一台旧电脑就能渲染 Julia 集：对每个像素代表的 $z$，迭代 $z \gets z^2 + c$，记录首次超过 2 的步数 $n(z)$，按 $n$ 上色。

一个具体例子：取 $c = -0.75$（主心形内的参数，$J_c$ 是 Jordan 曲线）。从 $z_0 = 0.5$ 出发：

$$z_1 = 0.5^2 - 0.75 = -0.5, \qquad z_2 = (-0.5)^2 - 0.75 = -0.5, \qquad z_3 = -0.5, \dots$$

$z = -0.5$ 是**不动点**（$(-0.5)^2 - 0.75 = -0.5$），轨道被钉住，永不逃逸——$0.5$ 属于 $K_c$。换 $z_0 = 1.5$：

$$z_1 = 1.5^2 - 0.75 = 1.5, \qquad z_2 = 1.5, \dots$$

$1.5$ 也是不动点——二次方程 $z^2 - z - 0.75 = 0$ 的解正是 $z = -0.5, 1.5$。区别在于稳定性：$|f_c'(-0.5)| = |-1| = 1$（中性），而 $|f_c'(1.5)| = 3 > 1$ 是**排斥**的，数值上轻轻一偏就放大跑远。<span class="marginnote">不动点分吸引与排斥两类，判据是 $|f_c'(z_*)| < 1$ 或 $> 1$。Julia 集恰由排斥周期点构成：$1.5$ 排斥故在 $J_c$ 上，$-0.5$ 的邻域属于 Fatou 集。一个式子同时解释了两件事。</span>

逃逸时间算法的两个工程参数：**迭代上限** $N_{\max}$（决定渲染细节与「未逃逸」判定的可信度）与**逃逸半径** $R$（通常取 2，对 $|c|$ 大的参数可适当放大）。$N_{\max}$ 越大，$J_c$ 的细丝画得越细，但耗时线性增长——这是分形可视化里最经典的「精度–时间」权衡。

复杂度也好估算：$N$ 个像素、每个最多迭代 $N_{\max}$ 步，总代价 $O(N \cdot N_{\max})$。对 Julia 集，$N_{\max} = 100$、$512^2$ 像素约 $2.6\times10^7$ 次复数乘法，现代 CPU 一秒内跑完——这也是 1980 年代个人电脑就能渲染 Mandelbrot 集的原因。

## 6 辨析｜易错点

- **Julia 集在动力学平面，Mandelbrot 集在参数平面**：Julia 集的坐标是初值 $z$（参数 $c$ 固定）；Mandelbrot 集的坐标是参数 $c$。把二者混在一张图里是初学者最常见的错误。
- **$K_c$（填充集）与 $J_c$（边界）之别**：Julia 集只是边界，不含内部；画图时人们常显示填充集（好看），但理论上的对象是边界。
- **「$J_c$ 是排斥周期点的闭包」意味着 $J_c$ 没有内点**：Julia 集要么是光滑曲线（$c=0$），要么是康托尔集，要么是「曲线与康托尔集的混合体」，永远不会是「一大块实心」。
- **$\partial M$ 的维数**：边界 $\partial M$ 的 Hausdorff 维数是 2（Shishikura），而 $M$ 内部的维数当然也是 2——「地图」与「海岸线」的维数之争在这里有了定论。
- **不动点的稳定性是区分 Fatou/Julia 的钥匙**：吸引周期点及其邻域属于 Fatou 集（行为规则），排斥周期点的闭包构成 Julia 集（行为混沌）。判定一个点属于谁，先看它是不是排斥周期点的极限。
- **逃逸半径的微妙**：判据是「$|z_n| > 2$ 必逃逸」——这是一个充分条件。实践中有的点 $|z_n|$ 曾超 2 又缩回，算法会把它错判；渲染时把 $R$ 取大（如 4）能减少这类误判，但要牺牲一点速度。
- **「$c \in M \iff K_c$ 连通」是二次族的特例**：这个等价依赖临界点唯一。对一般多项式族，连通性由「全部临界轨道」决定，判定复杂得多——别把二次的捷径当成一般结论。
- **渲染着色 ≠ 集合成员**：逃逸时间着色的深浅反映「逃逸快慢」，是连续量；「属于 / 不属于 $J_c$」是二值。彩色图里最深的颜色常标出 $J_c$，但那是经验对应，不是定义。
- **$M$ 内部并不空洞**：$M$ 内部对应「$K_c$ 连通且轨道收敛到稳定周期轨道」的参数，动力学是规则的（Fatou 集大）；「复杂」全部集中在边界 $\partial M$ 上。看 $M$ 的图，别只盯着黑色实心区。
- **共轭变换会「并掉」参数**：$f_c$ 与 $f_{c'}$ 若经由共轭（如 $z \mapsto z + 1/z$ 联系 $z^2$ 与 $z^2 - 2$）可互化，则两者的 Julia 集拓扑相同。参数空间里很多「长得一样」的动力学其实是同一个。

## 7 对照表：Julia 集与 Mandelbrot 集

| 维度 | Julia 集 $J_c$ | Mandelbrot 集 $M$ |
| --- | --- | --- |
| 所在平面 | 动力学平面（坐标是初值 $z$） | 参数平面（坐标是参数 $c$） |
| 参数状态 | $c$ 固定 | $c$ 遍历 |
| 定义 | $J_c = \partial K_c$ | $M = \{c : K_c \text{ 连通}\}$ |
| 判定轨道 | 从任意 $z$ 出发 | 从临界点 $0$ 出发 |
| 形态随位置变化 | 光滑曲线 / 康托尔集 / 混合体 | 主心形、分岔丝、Misiurewicz 点 |
| 维数 | $0 < \dim_H J_c < 2$，随 $c$ 变 | $\dim_H \partial M = 2$ |

读这张表的诀窍：**Julia 集是「一个参数下的动力学快照」，Mandelbrot 集是「全部参数的动力学地图」**。看单张 Julia 图问「$c$ 是多少」，看整张 Mandelbrot 图问「$c$ 在哪片区域」。两者的联系正是射影分支结构：$M$ 的每个「孔」对应 $c$ 的某个二次分量，而该分量内的 Julia 集拓扑不变。

若把 $M$ 的边界放大，能看到无数个「迷你 Mandelbrot」——这是二次多项式族在参数空间的普适自相似：周期 $p$ 的「芽」在边界上无穷嵌套，每个芽里又长着一个缩小版的心形。$M$ 因此既是分形对象，又是整个二次族动力学的索引。

## 8 小结

- 填充 Julia 集 $K_c$ 是轨道有界的点集，Julia 集 $J_c = \partial K_c$ 承载全部混沌动力学。
- $J_c$ 完全不变、是排斥周期点的闭包、无内点，随 $c$ 变化可从光滑曲线蜕变为康托尔集。
- Mandelbrot 集 $M = \{c : f_c^{\circ n}(0)\text{ 有界}\}$ 由一条临界轨道判定，是参数空间的地图，边界维数为 2。
- 逃逸时间算法（$|z_n|>2$ 判逃逸）让 Julia 与 Mandelbrot 集都能用最廉价的迭代渲染。

在下一节，我们从确定性的迭代转向随机的行走：布朗运动。它的轨迹以概率 1 是一条维数 3/2 的曲线——随机性本身，就是一种分形。
