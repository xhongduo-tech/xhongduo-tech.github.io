## 为什么从响应面方法开始

此前的设计都在回答「哪些因子显著」「效应多大」，本质是**检验与筛选**。而工程师最终要的往往是**优化**：找到让产率最高、成本最低、杂质最少的**那组工艺参数**。如果因子是连续的（温度、压力、时间），响应就是因子空间里的一张**曲面**——**响应面方法（response surface methodology, RSM）**的任务，就是用一组精心安排的试验把这张曲面拟合出来，然后登山找峰。<span class="marginnote">RSM 由博克斯与威尔逊在 1951 年提出，是「试验设计 + 回归分析」的合体：设计决定数据点摆在哪，回归把数据拟合成曲面。它在化工、制药、食品工艺优化里是标配工具。</span>

RSM 的关键理念是**渐进逼近**：开始时离最优很远，用便宜的一阶模型探方向；走到峰附近，用二阶模型刻画曲率、精确定位。全程不追求「一次到位」，而是「每步都用最省的试验往前走」。

## 1 一阶模型与最速上升

离最优还很远时，响应曲面近似平坦，用**一阶模型**（linear model）足够：

$$
y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_k x_k + \epsilon
$$

这里 $x_i$ 是编码后的因子（$+1/-1$ 或居中）。一阶模型的系数 $\beta_i$ 就是该方向的坡度。要往最优走，就沿**最速上升（steepest ascent）方向**迈步：从当前点出发，沿梯度方向 $\nabla \hat{y} = (\hat\beta_1, \ldots, \hat\beta_k)$ 一步步移动，每一步做完实验看响应，直到响应开始变差——说明走过头了，于是转回二阶模型精修。<span class="marginnote">最速上升的思路朴素得惊人：山脚下你不需要知道山的全貌，只需要知道哪边坡最陡，然后朝那里走。它把「优化」拆成「探测方向 + 迈步 + 再探测」的循环，每一轮成本都极低。</span>

**一阶设计**通常用 2^k 因子设计加中心点重复：中心点（全部因子取中间水平）的重复既给出纯误差估计，又能做**曲率检验**——若中心点响应显著偏离一阶模型的预测，说明曲面已经弯曲，该上二阶模型了。

## 2 曲率检验与二阶模型

若响应面明显弯曲，一阶模型不再够用，升级为**二阶模型（quadratic model）**：

$$
y = \beta_0 + \sum_{i=1}^{k} \beta_i x_i + \sum_{i=1}^{k} \beta_{ii} x_i^2 + \sum_{i<j} \sum \beta_{ij} x_i x_j + \epsilon
$$

比一阶多出**纯二次项** $x_i^2$ 与**交互项** $x_i x_j$。二阶模型的参数个数是 $1 + 2k + \binom{k}{2}$，需要足够多的设计点才能估计。

二阶模型的几何形态多样：椭圆等高线（有唯一最优点）、马鞍形（鞍点）、脊形（最优沿一条线延伸）。判断峰的性质要靠**平稳点分析**——对模型求导令其为零，解出平稳点，再看 Hessian 矩阵的特征值：全负为极大，全正为极小，正负混合为鞍点。<span class="marginnote">平稳点分析把「找最优」变成了线性代数题：求梯度为零的解 + 特征值分解。这正呼应第二级《线性代数》的特征值一节——曲面的凹凸形状全藏在 Hessian 的特征值符号里。</span>

## 3 中心复合设计（CCD）

拟合二阶模型需要一套专用设计，最经典的是**中心复合设计（central composite design, CCD）**。以 $k$ 个因子为例，CCD 由三部分组成：

**一个 2^k 因子设计**（或分辨率 V 的部分因子），提供线性项与交互项的估计，共 $2^k$ 个点；
**$2k$ 个轴向点（axial points）**：每次只把一个因子推到距离中心 $\alpha$ 处，其余因子取中心，共 $2k$ 个点；
**$n_c$ 个中心点**：全部因子取中心，提供纯误差估计与曲率信息。

总试验数 $N = 2^k + 2k + n_c$。<span class="marginnote">以 $k=2$ 为例：4 个因子点 + 4 个轴向点 + 若干中心点，组成一个「星形+方形」的构型——方形决定斜率，星形决定曲率，中心点锚定高程。这套几何构型正是 CCD 高效的来源。</span>

**$\alpha$ 的选择**：轴向距离 $\alpha$ 不是随便定的。取 $\alpha = 2^{k/4}$ 时，设计成为**旋转设计（rotatable design）**——预测方差只取决于到中心的距离、与方向无关。这个性质很实用：无论你沿哪个方向向外预测，精度是均匀的。<span class="marginnote">旋转性是一族设计的共同追求：一阶用 2^k 加中心点即旋转，二阶取 $\alpha = 2^{k/4}$ 即旋转。理解「旋转」只需记住——预测的不确定性只该与远近有关，不该与方向有关。</span>

## 4 公式解析：二阶模型的系数估计

二阶模型的系数用最小二乘估计。写成矩阵形式，$k=2$ 时的模型为：

$$
\hat{y} = \hat\beta_0 + \hat\beta_1 x_1 + \hat\beta_2 x_2 + \hat\beta_{11} x_1^2 + \hat\beta_{22} x_2^2 + \hat\beta_{12} x_1 x_2
$$

估计系数 $\boldsymbol{\hat\beta}$ 的核心公式：

$$
\boldsymbol{\hat\beta} = (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\mathbf{y}
$$

拆解三步：

- **第一步，设计矩阵 $\mathbf{X}$**：每行对应一次试验，列是 $1, x_1, x_2, x_1^2, x_2^2, x_1x_2$——CCD 的 $N$ 次试验构成 $N\times 6$ 的矩阵。
- **第二步，信息矩阵 $\mathbf{X}'\mathbf{X}$**：度量设计点的「信息量」。正交与旋转设计使 $\mathbf{X}'\mathbf{X}$ 呈分块对角甚至对角结构，系数估计互不干扰。
- **第三步，最小二乘解**：$(\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\mathbf{y}$ 是使残差平方和最小的解。$\mathbf{X}'\mathbf{y}$ 是「数据向各列方向投影」，乘以信息矩阵的逆得到系数。

**直觉**：最小二乘的几何意义是把观测向量 $\mathbf{y}$ 投影到设计矩阵的列空间上（见第二级《线性代数》投影一节）。设计选得好（正交、旋转），投影就干净；设计选得差（列近似线性相关），$\mathbf{X}'\mathbf{X}$ 接近奇异，系数估计方差爆表——**这也是为什么「设计先行」在 RSM 里尤其重要**：数据都摆好了，模型再聪明也救不回来。

## 5 辨析：RSM 与一次一因子的本质差别

RSM 常被与「一次一因子试验」对比，差别有三个层次：

**第一，RSM 同时变所有因子**，估计的是多维曲面，能看到交互与弯曲；一次一因子只沿坐标轴来回试，看不到斜向的最优方向——最速上升恰恰是「斜着走」的数学化。

**第二，RSM 有明确的模型**，预测与优化建立在拟合曲面上；一次一因子只有一堆孤立试验点，无法预测未试过的组合。

**第三，RSM 的试验数可控**，从一阶的 $2^k + n_c$ 到二阶的 $2^k + 2k + n_c$，规模随 $k$ 温和增长；而盲目网格搜索或一次一因子法在 $k$ 稍大时成本不可控。

**辨析｜易错点：** 响应面拟合后，**不要只报 $\alpha$ 系数就完事**。标准流程是：先做 ANOVA 检验模型的显著性、缺拟检验（lack of fit）——若模型缺拟，说明曲面形状超出二阶，需要扩域或换模型；再做系数显著性筛选，删掉不显著的项；最后画等高线图/3D 图，做平稳点分析并验证预测。跳过诊断直接报峰位，是 RSM 应用里最常见的坏习惯。

## 6 术语速查

RSM 的词汇与前面各章不同，它从「检验」切换到「拟合与寻优」，先认一张表：

| 术语 | 英文 | 一句话含义 |
| --- | --- | --- |
| 响应面 | response surface | 响应随连续因子变化的曲面 |
| 一阶模型 | first-order model | 只含线性项的模型 |
| 二阶模型 | second-order model | 含线性、二次与交互项的模型 |
| 最速上升 | steepest ascent | 沿梯度方向逐步移向峰点 |
| 中心点 | center point | 全部因子取中间水平的试验 |
| 曲率检验 | test for curvature | 用中心点判断曲面是否弯曲 |
| CCD | central composite design | 因子点+轴向点+中心点的二阶设计 |
| 轴向点 | axial point | 单个因子推到 $\alpha$ 处的试验 |
| 旋转设计 | rotatable design | 预测精度与方向无关的设计 |
| 平稳点 | stationary point | 梯度为零的候选最优点 |
| 缺拟检验 | lack-of-fit test | 判断模型是否够用 |
| Hessian 矩阵 | Hessian matrix | 二阶导数矩阵，决定峰/谷/鞍 |

## 7 小结

- **RSM** = 试验设计 + 回归，目标是拟合连续因子上的响应曲面并寻优；理念是「一阶探方向、二阶定位置」的渐进逼近。
- **一阶模型** + 最速上升：沿梯度方向迈步寻峰，中心点重复做曲率检验。
- **二阶模型**含线性、纯二次、交互项；平稳点分析用 Hessian 特征值判别极大/极小/鞍点。
- **CCD** = 2^k 因子点 + 2k 轴向点 + 中心点；取 $\alpha = 2^{k/4}$ 得旋转设计，预测精度与方向无关。
- 系数估计 $\boldsymbol{\hat\beta} = (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\mathbf{y}$：设计矩阵决定信息结构，正交/旋转设计使估计互不干扰，列近似相关时方差爆表。
- 拟合后必须走完诊断流程：ANOVA 显著性、缺拟检验、系数筛选、平稳点分析与预测验证——跳过诊断直接报峰位是 RSM 最常见的坏习惯。
- RSM 与一次一因子试验的本质差别：同时变因子、有显式模型、试验数可控——「斜着走」的最速上升是一维试探永远给不出的。

在下一节，我们将引入 RSM 在工业界最著名的姊妹方法——**稳健参数设计（田口方法）**：它不再追求「让响应最优」，而是追求「让响应对噪声不敏感」，用信噪比把「最优」与「稳健」合并在同一个目标里。
