## 为什么从部分因子开始

2^k 设计的致命弱点是试验数随 $k$ 爆炸：$k=8$ 时 256 次试验，$k=10$ 时 1024 次——对绝大多数工程试验都不可接受。但仔细想：$k=8$ 的全因子设计给了我们 $2^8-1 = 255$ 个效应，其中**主效应只有 8 个**，二因子交互 28 个，而三因子及更高阶交互有 219 个——高次交互在物理上几乎总是可以忽略的。<span class="marginnote">稀疏效应原则（effect sparsity principle）：在一个因子系统里，真正重要的效应通常很少，绝大多数是高阶交互。部分因子设计正是赌在这条经验法则上。</span>

**部分因子设计（fractional factorial design）**只做全因子设计的 $1/2^p$，即 $2^{k-p}$ 次试验，用「放弃估计高阶交互」换取「保住全部主效应与低阶交互」。代价是效应之间会**混杂（confounding / aliasing）**：两个或多个效应无法由数据区分。本篇的核心任务，就是看清这个代价的结构、学会选择「代价最小」的那一份。

## 1 从 2^{3-1} 看基本思想

设 $k=3$ 个因子，全因子要 8 次试验。做一半，只要 4 次——这就是 **2^{3-1} 设计**。4 次试验怎么安排？取全因子 8 个处理组合里满足「$A \cdot B \cdot C = +$」的 4 个：$(1), ab, ac, bc$（按编码 ±1 理解）。<span class="marginnote">或者等价地取满足「$A\cdot B\cdot C = -$」的另外 4 个——两个都是合法的一半，互为「镜像」。随机选哪个都一样，通常取乘积为正的那一份。</span>

为什么这 4 次试验够用？因为设计矩阵的四列 $A, B, C$ 两两正交，可以各自估计主效应。但代价立刻显现：在 2^3 全因子里独立存在的三因子交互 $ABC$，在 2^{3-1} 里它的对比列与**常数项（全 $+1$ 列）完全相同**——$ABC$ 效应与总均值混杂，完全无法估计。更糟的是，$A$ 列与 $BC$ 列的乘积逐行都是 $+1$，说明 $A$ 与 $BC$ 共享同一条对比：**主效应 A 与交互 BC 互为别名（alias）**。

「3 个主效应 + 3 个二因子交互 + 1 个三因子交互 = 7 个自由度」，4 次试验只有 4 个自由度（含均值）。算术上必然有 $8 - 4 = 4$ 条别名——信息不够，只能靠「高阶交互可忽略」来补。

## 2 定义关系与别名结构

**混杂的数学语言是定义关系（defining relation）**。2^{3-1} 的生成元是 $I = ABC$，读作「$ABC$ 这一列与常数项相同」。任何两个效应，若它们各乘上 $I = ABC$ 后相等，就是别名。例如：

$$
A = A \cdot ABC = A^2BC = BC
$$

（在 ±1 编码下 $A^2 = 1$。）于是 A 与 BC 混杂；同理 $B = AC$、$C = AB$。全部 7 个效应的别名对如下：

| 效应 | 别名 |
| --- | --- |
| $A$ | $BC$ |
| $B$ | $AC$ |
| $C$ | $AB$ |
| $ABC$ | 常数项（均值） |

**别名（alias）**：两个效应在同一列上，数据无法区分它们。要解读「显著」的 $A$，只能说「效应 A 或效应 BC，或二者的混合」。<span class="marginnote">别名不是随机噪声，而是<strong>结构性的不可分辨</strong>。它与误差不同：误差还能靠重复减少，别名是设计本身决定的，换样本也解不开——除非换一个不同的部分设计。</span>

## 3 分辨率：衡量混杂的严重程度

部分设计有优劣之分，**分辨率（resolution）**是度量它好坏的标准。记最小别名效应中「最高阶交互」，用罗马数字表示：

**分辨率 III**：主效应与二因子交互混杂（如 2^{3-1}）。只知道主效应的「大小」，不能确定是否被交互污染。适用于**因子筛选**的极端场合，风险最高。
**分辨率 IV**：主效应与三因子交互混杂，二因子交互之间互相混杂。主效应干净，二因子交互不可分辨。
**分辨率 V**：主效应与四因子交互混杂，二因子交互与三因子交互混杂。主效应与二因子交互都干净——这是多数严肃研究的**推荐起点**。<span class="marginnote">记法：2^{5-1} 有定义关系 $I = ABCDE$，因为别名里最短的词长是 5，所以叫分辨率 V。设计 $2^{k-p}$ 的分辨率 = 定义关系里最短生成词的长度。</span>

**辨析｜易错点：** 分辨率 IV 的 2^{4-1} 设计（定义关系 $I = ABCD$）里，$AB$ 与 $CD$ 混杂——如果你真正关心的恰好是 $AB$，这个设计就救不了你。**选择部分设计前，必须先列出你认为不可忽略的效应清单**，再挑一个不把这些效应配成别名的设计。

## 4 公式解析：用生成元构造部分设计

以常用的 2^{4-1}（分辨率 IV，8 次试验）为例，构造只需两步：

**第一步，选生成元**：让第 4 个因子等于前三个的乘积，$D = ABC$，即 $I = ABCD$。

**第二步，写全部 2^{4-1} 行**：先写前三列 A、B、C 的完整 2^3 表（8 行），第四列 D 由 $D = A\cdot B\cdot C$（逐行乘积）生成。这 8 行就是设计。

设计是否有效，由定义关系 $I = ABCD$ 的**结构**决定：

每个效应在 2^{4-1} 里都有 $2^1 = 2$ 个别名（含自己）。用定义关系乘一遍：$A = A\cdot ABCD = BCD$——主效应与三因子交互混杂；$AB = AB\cdot ABCD = CD$——二因子交互之间混杂。
别名里最短词长为 4，故分辨率为 IV：主效应干净，但 $AB$ 与 $CD$ 不可分。

**核心公式**：在 $2^{k-p}$ 设计中，若定义关系为 $I = W$（$W$ 是某些因子的乘积），则效应 $E$ 的别名是 $E\cdot W$（模去偶次幂）。每一条定义关系产生一组别名，$p$ 条独立定义关系共有 $2^p-1$ 个非平凡别名类，每类含 $2^p$ 个效应。<span class="marginnote">这条公式把「选择设计」变成了「选择定义关系」：你真正要优化的是 $W$ 的最小词长（分辨率）与词内容（哪些效应被配成对）。现代软件能自动枚举并挑出最优，但读懂这条公式是判断软件输出合理性的底线。</span>

## 5 主效应对抗与分析流程

实际使用部分因子设计的标准流程：

**第一轮（筛选）**：因子很多（$k \geq 5$）且缺乏先验信息时，用分辨率 III 或 IV 的设计快速筛出少数重要因子。此时不纠缠个别效应的精确值，只关心「谁显著」。
**第二轮（精修）**：对筛选出的 2–4 个关键因子，补做全因子或分辨率 V 设计，加上中心点，精确估计主效应与二因子交互，必要时升级为响应面设计。<span class="marginnote">「两阶段」是工程试验的黄金节奏：先粗后精、先筛选后建模。一次就想用超大的部分设计把一切估计精确，通常既浪费又不必要。</span>

**辨析｜易错点：** 部分因子的一个常见误用，是把分辨率 III 的结果当精确估计报告。分辨率 III 的主效应可能被二因子交互污染——若某交互真实存在且与主效应同号，你测到的「主效应」会被放大；若反号，甚至会反转符号。**低分辨率设计只配用来「排优先级」，不配用来「定参数」。**

## 6 术语速查

| 术语 | 英文 | 一句话含义 |
| --- | --- | --- |
| 部分因子设计 | fractional factorial | 全因子的一个分数子集 |
| 2^{k-p} 设计 | $2^{k-p}$ design | 全因子的 $1/2^p$ |
| 生成元 | generator | 定义新因子列等于哪些旧列的乘积 |
| 定义关系 | defining relation | 生成元生成的恒等式 $I = W$ |
| 别名 | alias | 共享同一条对比的两个效应 |
| 混杂 | confounding | 两个效应无法由数据区分 |
| 分辨率 | resolution | 别名中最短词的长度，III/IV/V |
| 稀疏效应原则 | effect sparsity | 重要效应通常很少，多为低阶 |
| 效应清单 | effect list | 认为不可忽略的效应集合 |
| 筛选 | screening | 低分辨率快速找出重要因子 |
| 精修 | follow-up | 对关键因子做高分辨率或全因子 |
| 别名类 | alias class | 互为别名的效应组 |

## 7 常见疑问

- 分辨率 III 的结果能当精确估计吗？——不能，只配排优先级。
- 别名与随机误差有何不同？——别名是结构的、换样本解不开；误差可随重复减小。
- 怎么提高分辨率？——少砍一半（加大 $p$ 为 $p-1$）或改用更大设计。
- 选择部分设计前先做什么？——列一张「不可忽略效应」清单。
- 定义关系里的词长怎么看？——最短词长即分辨率。
- 2^{3-1} 为什么主效应与二因子交互混杂？——$I=ABC$ 让 $A$ 与 $BC$ 共享一列。
- 部分设计能估全部效应吗？——不能，信息自由度有限。
- 高次交互真的可忽略吗？——通常是，但需领域知识判断。
- 两阶段是什么？——先低分辨率筛选，再高分辨率精修。
- 软件能帮我选设计吗？——能，但要能读懂定义关系与分辨率。
- 镜像设计有区别吗？——取乘积为正或为负等价，选一个即可。

## 8 小结

- **部分因子设计 $2^{k-p}$**：只做全因子的 $1/2^p$，靠稀疏效应原则（高阶交互可忽略）省成本。
- **混杂（别名）**：两个效应共享同一条对比，数据无法区分；别名是结构性的，重复样本解不开。
- **定义关系** $I = W$ 是混杂的代数表达：效应 $E$ 的别名是 $E\cdot W$；$p$ 条生成元产生 $2^p$ 条独立别名类，每类含 $2^p$ 个效应。
- **分辨率** III/IV/V 衡量混杂严重程度：III 主效应与二因子交互混杂，IV 主效应干净、二因子交互互混，V 主效应与二因子交互都干净——严肃研究从 V 起步。
- **两阶段流程**：先低分辨率筛选（排优先级），再高分辨率精修（定参数）；选择设计前先列「不可忽略效应」清单，别把筛选结果当精确估计。

在下一节，我们将引入另一支对抗「试验数爆炸」的实用武器——**正交表与正交试验设计**：它用更小的拉丁方风格表格把因子配平，并衔接田口方法的信噪比分析，是工业界流传最广的「查表式」设计。
