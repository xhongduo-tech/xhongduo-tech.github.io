# 广义逆与 Moore-Penrose 伪逆

<div class="epigraph">
<p>当逆不存在时，我们仍可追问"最接近解"是什么——伪逆就是那面照出最小二乘解的镜子。</p>

## 为什么从伪逆开始

可逆矩阵处处好办，但现实中的矩阵几乎都不方、或奇异、或病态。线性方程组 $Ax = b$ 可能无解（$b$ 不在列空间里），
也可能有无穷多解（$A$ 有零空间）。**Moore-Penrose 伪逆**用一个统一的公式回答这一切：存在唯一的
$A^{+}$ 使得 $x = A^{+}b$ 给出「最短的最小二乘解」——残差范数最小，且所有最小二乘解中范数最小。
它是回归分析、SVD、推荐系统与深度学习中最小二乘问题的数学底座，也是本专题的收官之笔<span class="marginnote">从极限到大模型的连接：线性回归 $w = X^{+}y$、PCA 的投影、
推荐系统的隐因子分解、以及大模型权重矩阵的秩估计，全都以伪逆为最小二乘的"标准答案"。
伪逆也是理解过参数化系统里"最短范数解"如何挑出来的钥匙。</span>。

## 1 四个 Penrose 条件

**Moore-Penrose 伪逆（Moore-Penrose pseudoinverse）**：矩阵 $A$
的伪逆是唯一的矩阵 $A^{+}$，满足下列四个条件：

1. $A A^{+} A = A$（$A^{+}$ 是 $A$ 的广义逆）；
2. $A^{+} A A^{+} = A^{+}$（反过来，$A^{+}$ 是 $A^{+}$ 的广义逆）；
3. $(A A^{+})^{*} = A A^{+}$（$AA^{+}$ 是 Hermite 矩阵）；
4. $(A^{+} A)^{*} = A^{+} A$（$A^{+}A$ 是 Hermite 矩阵）。<span class="marginnote">前两条保证「广义逆」的基本语义，后两条把解"钉"在正交投影上：$AA^{+}$ 与
$A^{+}A$ 分别是到 $A$ 的列空间、行空间的正交投影。这四条不是独立的简化——Penrose 1955
年证明它们是存在且唯一的完整刻画。</span>

四个条件合起来的效果是：**$AA^{+}$ 是到 $\operatorname{col}(A)$ 的正交投影，
$A^{+}A$ 是到 $\operatorname{row}(A)$ 的正交投影**。正交投影是「尽量不丢失信息」的投影，
这正是伪逆给出的解「最短」的几何原因。

**辨析｜易错点：** 广义逆（满足条件 1 的矩阵，如任意左逆/右逆）**不唯一**，而 Moore-Penrose
伪逆唯一。教材里 `pinv`、`A⁺` 指的都是唯一的那一个。此外 $A^{+}$
不是「逐元素取倒数再转置」——它是**沿奇异值方向**取倒数，零奇异值对应的方向被置零，这与可逆矩阵的逆在 $A$
满秩时一致：若 $A$ 可逆则 $A^{+} = A^{-1}$。

## 2 用 SVD 构造伪逆

设 $A$ 的 SVD 为 $A = U\Sigma V^{*}$，其中 $\Sigma$ 是 $m\times n$
对角阵、奇异值
$\sigma_1 \ge \cdots \ge \sigma_r > 0$（$r = \operatorname{rank} A$），
则

$$A^{+} = V \Sigma^{+} U^{*}$$

其中 $\Sigma^{+}$ 是 $n \times m$ 对角阵，取法为：**把 $\Sigma$ 转置，
把每个非零奇异值换成其倒数，零奇异值保持为零**：

$$\Sigma^{+} = \operatorname{diag}\left(\frac{1}{\sigma_1}, \dots, \frac{1}{\sigma_r}, 0, \dots, 0\right)$$

零奇异值对应的方向（$A$ 的零空间方向）在伪逆中被**丢弃**——因为沿这些方向没有任何可恢复的信息。<span class="marginnote">这个构造揭示伪逆的本质：在 $A$ 的「有效秩」方向上是真正的逆，
在零空间方向上投影为零。$A^{+}$ 不是「想反转一切」，而是「只反转能反转的，其余静默」。</span>

**秩一展开形式**：$A^{+} = \sum_{i=1}^{r} \frac{1}{\sigma_i} v_i u_i^{*}$，
与 $A = \sum_{i=1}^{r}\sigma_i u_i v_i^{*}$ 逐项配对——每一项的奇异值取倒数、
左右奇异向量互换位置。

## 3 伪逆与最小二乘

伪逆是线性最小二乘的**统一解**。对任意 $A$、任意 $b$，令 $x_0 = A^{+}b$，则：

- $x_0$ 是**最小二乘解**：$\|Ax_0 - b\| \le \|Ax - b\|$ 对一切 $x$ 成立；
- 在所有最小二乘解中，$x_0$ 的范数**最小**：$\|x_0\| \le \|x\|$ 对任何最小二乘解 $x$ 成立。

**几何图景**：$b$ 在 $\operatorname{col}(A)$ 上的正交投影是
$\hat b = AA^{+}b = Ax_0$，残差
$b - Ax_0 \perp \operatorname{col}(A)$。<span class="marginnote">列满秩时（$\operatorname{rank} A = n$，$A$
列线性无关），$A^{+} = (A^{*}A)^{-1}A^{*}$，正是正规方程的解；$A^{+}A = I$ 是恒等。
行满秩时 $A^{+} = A^{*}(AA^{*})^{-1}$，是 $Ax = b$ 有无穷多解时的最小范数解。
</span>

**秩亏情形**（$\operatorname{rank} A < n$）：$A^{*}A$ 不可逆，正规方程失效；
伪逆仍给出唯一的最小范数最小二乘解。这正是机器学习里**过参数化回归**的标准答案——当特征数超过样本数，解不唯一，
伪逆挑出范数最小的那个，对应「最小权重」的归纳偏置。

**与 SVD 截断的关系**：若用截断 SVD 计算伪逆（丢去极小的奇异值），得到的 $A^{+}$ 对噪声更稳健，
因为**被丢弃的微小奇异值对应的方向，其倒数会被放大成巨大的噪声放大器**——伪逆对病态矩阵敏感，截断是工程上的常规防护。

## 4 应用：线性回归、伪逆的性质与统计

伪逆是**最小二乘的通用求解器**，这一节把它放到回归、统计与秩亏场景里看。

**线性回归的统一解**：线性回归 $y \approx Xw$（$X$ 为 $n\times p$ 设计矩阵，$y$
为响应）的系数由

$$\hat w = X^{+}y$$

给出。三个情形自动统一：<span class="marginnote">列满秩（$p < n$，
通常情形）：$X^{+} = (X^{T}X)^{-1}X^{T}$，就是正规方程解，最小二乘意义下唯一；
行满秩（$p > n$，过参数化）：解有无穷多个，伪逆挑出<strong>最小范数</strong>的那个，对应"最小权重"的正则化偏置；
秩亏：$X^{T}X$ 不可逆，伪逆仍给出良定义解。</span>

$p < n$：$\hat w = (X^{T}X)^{-1}X^{T}y$，正规方程解，唯一；
- $p > n$：无穷多解，伪逆选**最小范数**解——这是深度学习中"过参数化网络找到最小范数权重"的理论原型；
- $\operatorname{rank} X < p$：设计矩阵奇异，伪逆直接给解，无需额外处理。

**伪逆的代数性质**：伪逆满足一批与普通逆平行的规则，但需小心差异：

- $(A^{+})^{+} = A$，$(\lambda A)^{+} = \lambda^{-1}A^{+}$（$\lambda \neq 0$）；
- $(A^{*})^{+} = (A^{+})^{*}$，$(A^{+})^{T} = (A^{T})^{+}$；
- $(AB)^{+} = B^{+}A^{+}$ **不恒成立**——只有当 $A$ 列满秩、$B$ 行满秩（或 $A, B$ 有更紧的正交条件）时才成立。**反序律对伪逆是条件性的，这是它比普通逆"难缠"的地方**。<span class="marginnote">例：$A = \begin{pmatrix}1\\0\end{pmatrix}$、$B = \begin{pmatrix}1&0\end{pmatrix}$，则 $AB = \begin{pmatrix}1&0\\0&0\end{pmatrix}$，$(AB)^{+} = \begin{pmatrix}1&0\\0&0\end{pmatrix}$；而 $B^{+}A^{+} = \begin{pmatrix}1\\0\end{pmatrix}\begin{pmatrix}1&0\end{pmatrix} = \begin{pmatrix}1&0\\0&0\end{pmatrix}$——这里恰好相等。但一般情形不相等，需逐个验证。伪逆的反序律是"每本矩阵书都强调、每个初学者都踩"的坑。</span>

**与 SVD 截断的统计联系**：当 $A$ 有接近零的奇异值时，$A^{+}$ 中对应项 $1/\sigma_i$
极大，把噪声放大——这就是**岭回归（ridge regression）**的动机：用
$(A^{T}A + \lambda I)^{-1}A^{T}$ 代替 $A^{+}$，
等价于把微小奇异值"垫高"以抑制放大。**伪逆给"精确最小二乘"，岭回归给"稳定化最小二乘"**，两者是同一问题的两极。
<span class="marginnote">从极限到大模型的连接：参数高效微调、
低秩适配（LoRA）中要估计权重增量的最优低秩逼近，用的正是截断 SVD/伪逆框架；
而训练稳定性中的"梯度裁剪""权重衰减"本质上都是把病态最小二乘问题正则化的手段。伪逆与岭回归的选择，就是"过拟合 vs
病态"的经典权衡。</span>

**伪逆与矩阵方程**：矩阵方程 $AXB = C$ 有解当且仅当 $AA^{+}CB^{+}B = C$，此时通解为

$$X = A^{+}CB^{+} + Y - A^{+}AYBB^{+}$$

其中 $Y$ 任意。**伪逆不仅解最小二乘，
也给出一般矩阵方程的有解性判据与通解结构**——它把「逆」的求解能力完整地推广到了长方阵与奇异矩阵。

**辨析｜易错点：** 伪逆不是「元素级倒数」：$A^{+}$ 在 $A$ 的零空间方向投影为零，
而普通逆不存在这种"丢弃"。另一个常见错误：对**行满秩**矩阵误用 $(A^{*}A)^{-1}A^{*}$——此时
$A^{*}A$ 可逆但给出的不是最小范数解，正确应使用 $A^{+} = A^{*}(AA^{*})^{-1}$。
**列满秩用右式、行满秩用左式，方向别记反**。

## 5 公式解析：伪逆构造 $A^{+} = V\Sigma^{+}U^{*}$

把「为什么取倒数、为什么丢零奇异值」拆四步：

- **第一步，验证条件 1**：$AA^{+}A = (U\Sigma V^{*})(V\Sigma^{+}U^{*})(U\Sigma V^{*}) = U\Sigma\Sigma^{+}\Sigma V^{*}$。在 $i \le r$ 处 $\sigma_i \cdot \tfrac1{\sigma_i}\cdot \sigma_i = \sigma_i$，在 $i > r$ 处 $0$——**恰回到 $\Sigma$**，故 $AA^{+}A = A$ 成立。
- **第二步，验证条件 3**：$AA^{+} = U\Sigma\Sigma^{+}U^{*}$，而 $\Sigma\Sigma^{+} = \operatorname{diag}(1, \dots, 1, 0, \dots, 0)$ 是实对角阵，故 $AA^{+}$ 是 $U$ 的「部分酉」构成的 Hermite 矩阵——它是到 $\operatorname{col}(A)$ 的正交投影。
- **第三步，为什么逆要转置**：$A^{+}$ 的维度是 $n \times m$，与 $A$ 的 $m\times n$ 相反，所以 $\Sigma^{+}$ 必须是 $\Sigma$ 的**转置形状**（$n\times m$），否则 $V\Sigma^{+}U^{*}$ 无法相乘。
- **第四步，为什么零奇异值归零**：若把 $1/0$ 强行放进去，$A^{+}$ 无界且不满足 Penrose 条件；归零则使 $A^{+}$ 在 $A$ 的零空间方向恒为零。**伪逆「诚实地承认」秩亏方向没有可逆信息，因此选择不放大噪声**。

## 6 小结

- **Moore-Penrose 伪逆** $A^{+}$：唯一满足四个 Penrose 条件的矩阵；$AA^{+}$、$A^{+}A$ 分别是列空间、行空间的正交投影。
- **SVD 构造**：$A^{+} = V\Sigma^{+}U^{*}$，非零奇异值取倒数、零奇异值保持零。
- **最小二乘统一解**：$x = A^{+}b$ 是残差范数最小、且范数最小的解；列满秩时退化为 $(A^{*}A)^{-1}A^{*}$。
- **秩亏与病态**：伪逆在秩亏时仍良定义；极小奇异值的倒数会放大噪声，工程上用截断 SVD 防护。
- 易错点：广义逆不唯一、伪逆唯一；伪逆不是逐元素倒数；可逆时 $A^{+}=A^{-1}$。
