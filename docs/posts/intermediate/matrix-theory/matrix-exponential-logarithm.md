## 为什么从矩阵指数开始

标量函数的强大之处在于微积分；要把微积分带给向量系统（一阶微分方程组 $\dot{x} = Ax$），就必须把
$\exp$、$\log$、$\cos$ 这些函数「移植」到矩阵上。答案是**矩阵指数**
$e^{A}$——它是线性常微分方程组的通解、李群与李代数的指数映射、也是概率论与随机过程的基石。上一节
Cayley-Hamilton 给了我们「沿谱定义函数」的原理，这一节把它具体化：**先学会用幂级数与 Jordan
块两条路计算矩阵函数，再掌握对数及其存在条件**<span class="marginnote">从极限到大模型的连接：连续时间神经网络（Neural ODE）的解是
$x(t) = e^{tA}x(0)$；扩散模型的概率流 ODE、以及各类动力系统的离散化，处处用到矩阵指数。
它是"连续动力学"和"线性代数"之间的翻译器。</span>。

## 1 矩阵指数：定义与幂级数

**矩阵指数（matrix exponential）**：对任意复方阵 $A$，定义

$$e^{A} = \sum_{k=0}^{\infty} \frac{A^{k}}{k!} = I + A + \frac{A^2}{2!} + \frac{A^3}{3!} + \cdots$$

级数对任意 $A$ 绝对收敛（因为 $\|A^k/k!\| \le \|A\|^k/k!$，与标量指数级数同速收敛）。
这是「把标量指数级数中的 $x$ 换成 $A$」，与 Cayley-Hamilton 的代入思想一脉相承。<span class="marginnote">收敛性论证：任意矩阵范数下
$\|e^{A}\| \le \sum \|A\|^k/k! = e^{\|A\|}$，级数被标量指数控制。
故矩阵指数对一切矩阵良定义，不需要可对角化。</span>

**关键性质**：

- $e^{0} = I$；
- 若 $AB = BA$，则 $e^{A+B} = e^{A}e^{B}$——**可交换性是加法律的前提**；不可交换时一般不成立；
- $e^{A}$ 恒可逆，且 $(e^{A})^{-1} = e^{-A}$；
- 若 $A = PJP^{-1}$，则 $e^{A} = P e^{J} P^{-1}$（相似关系沿函数传递）。

**辨析｜易错点：** $e^{A+B} = e^{A}e^{B}$ 只对可交换矩阵成立，
这是矩阵指数与标量指数最大的分水岭。反例：取
$A = \begin{pmatrix}0&1\\0&0\end{pmatrix}$、$B = A^{T}$，则
$AB \neq BA$，可验算 $e^{A}e^{B} \neq e^{A+B}$。**看到矩阵指数相加，先查交换性**。

## 2 用 Jordan 块计算矩阵指数

对角化情形最简单：$A = S\Lambda S^{-1}$ 时
$e^{A} = S\operatorname{diag}(e^{\lambda_1}, \dots, e^{\lambda_n})S^{-1}$。
亏损情形需要处理 Jordan 块。对 $J_k(\lambda) = \lambda I + N$（$N$ 幂零，
$N^k = 0$）：

$$e^{J_k(\lambda)} = e^{\lambda I} e^{N} = e^{\lambda} \left(I + N + \frac{N^2}{2!} + \cdots + \frac{N^{k-1}}{(k-1)!}\right)$$

**幂零部分让级数自动截断成有限和**（因为 $N^k = 0$），而
$e^{\lambda I} = e^{\lambda}I$ 与 $N$ 可交换，故可拆成乘积。<span class="marginnote">$e^{N}$ 的具体形态是「带移位」的上三角：第 $i$ 条上对角带为
$1/i!$。这使 $e^{J}$ 仍是上三角、仍像指数样地在各链上"扩散"。整个计算只需多项式运算，
不需要特征分解——这是数值库（如 SciPy 的 expm）的基础思路之一。</span>

**对微分方程组的意义**：$\dot{x} = Ax$ 的通解是 $x(t) = e^{tA}x(0)$。若 $A$
可对角化，解是各特征模式 $e^{\lambda_i t}$ 的叠加；若 $A$ 亏损，解中还会出现多项式因子
$t^{i}$（来自 $e^{tN}$ 的截断项）——**这是约当链条在动力系统中"露面"的方式**。

## 3 矩阵对数：指数的逆

**矩阵对数（matrix logarithm）**：若 $X$ 满足 $e^{X} = A$，称 $X$ 是 $A$
的一个对数，记 $X = \log A$。与标量不同，矩阵对数**不一定存在，存在时也不唯一**。

**存在条件**：$A$ 可逆且 $A$ 没有负实数特征值（更精确地说，在某个不穿过 $A$ 谱的割线上取主支），
则存在**主对数**。可逆但特征值含负实数的矩阵可能只有非主对数，甚至没有连续对数。用谱定义：

$$\log A = \frac{1}{2\pi i}\oint_\Gamma \log z\, (zI - A)^{-1}\, dz$$

其中 $\Gamma$ 是环绕 $A$ 全部谱的围道——这是**围道积分定义**，与幂级数定义在谱范围内一致。<span class="marginnote">为什么要围道积分：当 $\log$ 的泰勒级数收敛半径小于 $A$ 的谱半径时，
幂级数定义失效；围道积分只要求 $\log z$ 在 $A$ 的谱附近解析，适用范围更广。主对数 $A = e^{X}$
满足 $X$ 的特征值实部在 $(-\pi, \pi)$ 内。</span>

**对数不唯一的根源**：若 $e^{X} = A$，则 $X + 2\pi i I$ 也满足
$e^{X+2\pi i I} = e^{X}$（因为 $e^{2\pi i I} = I$）。对多 Jordan
块还可按块独立加减 $2\pi i$，得到更多对数。
**对数的不唯一性由谱的"绕数"自由度决定**——这与李群上指数映射的局部同胚性质直接相关。

## 4 应用：线性微分方程组与李群

矩阵指数最直接的应用是解**一阶线性常微分方程组**。设 $\dot{x} = Ax$、$x(0) = x_0$，则唯一解为

$$x(t) = e^{tA}x_0$$

这一句话封装了全部解的结构：$e^{tA}$ 是「时间演化算子」，把初始状态沿系统的流搬运到 $t$ 时刻。
它的性质直接翻译成解的定性行为：$e^{(t+s)A} = e^{tA}e^{sA}$（同一 $A$，可交换，
加法律天然成立）保证流的半群性；$e^{-tA} = (e^{tA})^{-1}$ 保证可逆性与时间反演。<span class="marginnote">从极限到大模型的连接：连续时间神经网络（Neural ODE）用
$dx/dt = f_\theta(x)$ 建模，其线性化增量步正是 $e^{\Delta t A}$；残差网络、
扩散模型的概率流 ODE、以及状态空间模型（SSM/Mamba）的离散化，都是 $e^{tA}$ 的不同离散形式。
矩阵指数是把"连续动力学"写进深度学习的第一语法。</span>

**数值计算矩阵指数的实践**：$e^{A}$ 的朴素幂级数对大范数 $A$ 收敛极慢，工程上使用 **Padé 近似 +
缩放平方（scaling and squaring）** 方法：先对 $A$ 缩放 $A/2^s$（使范数足够小、
幂级数快速收敛），算出近似后再平方 $s$ 次。这是 SciPy 的 `expm`、MATLAB 的 `expm`
的标准算法。<span class="marginnote">为什么不能直接用 Jordan 块算：Jordan
分解对数值不稳定（亏损块对舍入误差极敏感），特征分解同样如此；缩放平方只依赖矩阵乘法，数值稳定且对稀疏结构友好。理论用
Jordan、实践用缩放平方——"分析工具"与"计算工具"在这里分道。</span>

**矩阵对数与李群**：矩阵指数把「矩阵的加法（李代数）」映射到「矩阵的乘法（李群）」。设
$G = \{g : g \text{ 可逆}\} \subseteq \mathrm{GL}_n(\mathbb{C})$
是一个李群，其李代数是
$\mathfrak{g} = \{X : e^{tX} \in G, \ \forall t\}$——**李代数是"群的无穷小生成元"，
指数映射 $X \mapsto e^{X}$ 是连接二者的桥**。<span class="marginnote">例：酉群 $U(n) = \{U : U^{*}U = I\}$ 的李代数是斜
Hermite 矩阵 $\mathfrak{u}(n) = \{X : X^{*} = -X\}$（$e^{X}$
酉当且仅当 $X$ 斜 Hermite）；特殊线性群 $\mathrm{SL}_n$ 的李代数是迹为零的矩阵
$\mathfrak{sl}_n$。这一对应正是前面"迹、交换子、李代数"伏笔的兑现，也是旋转、姿态、
相机位姿估计（$SO(3)$）的数学底座。</span>

**对数在数据科学中的角色**：矩阵对数常用来把「乘法结构的量」线性化——协方差矩阵的对数、以及流形上的对数映射，
把正定矩阵的乘法几何搬到"平直"的切空间里做平均与插值。这在脑电、雷达、医学影像的协方差处理中广泛使用。<span class="marginnote">信息几何视角：正定矩阵构成一个流形，
对数映射把"乘法平均"变成切空间里的向量平均——这就是为什么协方差矩阵做几何平均要先取对数。
矩阵指数与对数是一对往返的"坐标变换"。</span>

**辨析｜易错点：** $e^{A}$ 的**逆**是 $e^{-A}$，但 $e^{A}$ 的**迹**不是
$e^{\operatorname{tr}A}$——正确的关系是
$\det e^{A} = e^{\operatorname{tr}A}$（对可对角化可直接验证，
对一般情形由连续性/三角化推出）。这个「迹在指数里、行列式在指数外」的恒等式是矩阵指数最重要的一条代数恒等式，
也是对数与行列式挂钩的桥梁。

## 5 公式解析：$e^{J_k(\lambda)}$ 的有限截断

把矩阵指数在 Jordan 块上的计算拆四步，这也是「幂零截断」的标准模板：

- **第一步，拆块**：$J = \lambda I + N$，$\lambda I$ 与 $N$ 可交换，$e^{J} = e^{\lambda I}e^{N} = e^{\lambda}\, e^{N}$。**可交换使指数化为两个因子的乘积**。
- **第二步，展开 $e^{N}$**：$e^{N} = \sum_{i\ge0} N^{i}/i!$。$N$ 是移位矩阵，$N^{i}$ 把上对角带整体上移 $i$ 格；但 $N^{k} = 0$，求和到 $i = k-1$ 为止。
- **第三步，读出元素**：$(e^{N})_{p,q} = 1/(q-p)!$ 当 $0 \le q - p \le k-1$，否则为 $0$。于是 $e^{J}$ 的上三角带依次为 $1, 1, \tfrac12, \tfrac16, \dots$。
- **第四步，为什么通用**：$e^{tJ} = e^{t\lambda}e^{tN}$，同法得带 $t^{i}/i!$。解 $x(t) = e^{tA}x(0)$ 中出现的多项式因子 $t^{i}$ 全部来自这一步——**亏损系统的解含有幂多项式尾巴，正是幂零部分 $N$ 的直接指纹**。

## 6 小结

- **矩阵指数** $e^{A} = \sum A^{k}/k!$：对一切矩阵收敛、恒可逆、$(e^{A})^{-1}=e^{-A}$。
- **加法律** $e^{A+B} = e^{A}e^{B}$ 只在 $AB = BA$ 时成立；不可交换时失效。
- **Jordan 块计算**：$e^{\lambda I + N} = e^{\lambda}(I + N + N^2/2! + \cdots)$，幂零 $N$ 使级数截断为有限和。
- **矩阵对数**：$e^{X} = A$；主对数存在需 $A$ 可逆且谱不含负实数；对数一般不唯一（可整体加减 $2\pi i I$）。
- 易错点：加法律需交换性；对数存在需可逆；亏损系统解中出现多项式因子。

在下一节，我们将把「两个矩阵」合并成「一个大矩阵」——Kronecker 积，它是张量积、vec
算子与线性矩阵方程的统一语言。
