# Cayley-Hamilton 定理与最小多项式

<div class="epigraph">
<p>每个矩阵都"忠诚地"满足自己的特征方程——这或许是矩阵代数中最令人惊讶、也最朴素的断言。</p>

## 为什么从 Cayley-Hamilton 开始

特征多项式 $p(\lambda) = \det(\lambda I - A)$ 是用标量 $\lambda$ 写出的，但
Cayley-Hamilton 定理做出了一个大胆的类比断言：**把 $\lambda$ 换成矩阵 $A$ 本身，
特征多项式照样成立**——$p(A) = 0$。这立刻带来一个震撼后果：$A^n$ 及更高次幂都可以被
$I, A, \dots, A^{n-1}$ 线性表出，矩阵的幂「在 $n$ 阶截断」。由此出发，
我们还能找到**最小的**能零化 $A$ 的多项式（最小多项式），它与 Jordan 块结构一一对应。这两件事是矩阵函数、
Jordan 块幂、以及数值方法里「减少矩阵运算」的理论支柱<span class="marginnote">从极限到大模型的连接：任何「矩阵的幂级数」——如矩阵指数、PageRank 迭代、
以及循环神经网络里的状态递推——最终都落到 Cayley-Hamilton 的 $n$ 阶截断上。理解它，就理解了为什么
$A^{n+k}$ 从不引入新的"信息维度"。</span>。

## 1 Cayley-Hamilton 定理

**Cayley-Hamilton 定理**：设 $A$ 是 $n \times n$ 复方阵，
$p(t) = \det(tI - A)$ 是其特征多项式，则

$$p(A) = 0$$

即 $A^n + c_{n-1}A^{n-1} + \cdots + c_1 A + c_0 I = 0$，其中
$c_i$ 是特征多项式的系数。<span class="marginnote">历史上凯莱 1858 年在
$2\times2$ 情形验证、哈密顿在四元数方面独立涉足，一般证明直到弗罗贝尼乌斯才严格给出。
它把「行列式」这一分析工具与「矩阵代数」缝在一起。</span>

**证明的核心直觉（Jordan 视角）**：对每个 Jordan 块 $J_k(\lambda)$，
$p(J_k(\lambda))$ 为零矩阵。因为
$p(t) = (t-\lambda)^{k}(t-\mu_1)\cdots$（含该块的链长因子），而
$(J_k - \lambda I)^{k} = 0$，故 $p(J_k) = 0$。逐块成立 ⇒ 全矩阵成立。<span class="marginnote">最优雅的严格证明用伴随矩阵恒等式：$(tI - A)\operatorname{adj}(tI - A) = \det(tI-A)I = p(t)I$。
两边视为 $t$ 的多项式矩阵，按 $t$ 的次数比较系数后消去，即得 $p(A)=0$。这个证明不需要 Jordan
理论，是教材的经典路线。</span>

**推论：矩阵的幂被 $n$ 阶截断**。由
$A^{n} = -c_{n-1}A^{n-1} - \cdots - c_0I$，任何
$A^{m}$（$m \ge n$）都能反复化简为 $I, A, \dots, A^{n-1}$ 的线性组合。
**$n \times n$ 矩阵生成的代数至多 $n$ 维基座**——这是「矩阵幂的世界并不比 $n$
维更复杂」的定量表述。

## 2 最小多项式：最经济的零化多项式

**最小多项式（minimal polynomial）**：设 $q(t)$ 是**首一**（最高次项系数为 1）多项式，
且满足 $q(A) = 0$，次数最小的那个，记作 $m_A(t)$。最小多项式唯一，且**整除**任何零化 $A$
的多项式——特别是整除特征多项式 $p(t)$：$m_A(t) \mid p(t)$。<span class="marginnote">「整除」的证明：对任意零化多项式 $f$，用带余除法
$f = qm + r$（$\deg r < \deg m$），代入 $A$ 得 $r(A) = 0$；若
$r \neq 0$ 则与最小性矛盾，故 $r = 0$，$m \mid f$。这个"最小 ⇒
整除"的论证在代数里是模板级的。</span>

**如何从 Jordan
块读出最小多项式**：$m_A(t) = \prod_{\lambda} (t - \lambda)^{k_\lambda}$，
其中指数 $k_\lambda$ 是特征值 $\lambda$ 对应 Jordan 块中**最大的链长**（不是代数量、
不是块数）。特征多项式则取**全部**链长之和作指数。两者差异正是「亏缺失去的部分」。

**辨析｜易错点：** 最小多项式与特征多项式在三种情况重合、在一种情况分开：

$A$ 无重特征值 ⇔ $m_A = p$（都是无重根）；
- $A$ 可对角化 ⇔ $m_A$ 无重根（$k_\lambda = 1$ 对所有 $\lambda$）——**即使 $p$ 有重根，只要 $g = m$，最小多项式就没有重根**；
- 亏损矩阵：$m_A \neq p$，最小多项式指数取最大块长，次数严格低于 $n$（或等于 $n$ 但指数更细）。

## 3 用最小多项式判断可对角化

最小多项式给出一个极简的对角化判据：**$A$ 可对角化 ⇔ 最小多项式无重根**。因为可对角化 ⇔ 所有 Jordan
块 $1\times1$ ⇔ 每条链长 $=1$ ⇔ 最小多项式的每个指数 $k_\lambda = 1$。<span class="marginnote">这个判据在计算上很实用：不必求出全部 Jordan 块，只需看 $m_A$
是否无重根。例如幂等矩阵 $A^2 = A$ 满足 $t(t-1)$，最小多项式无重根 ⇒
可对角化——幂等矩阵可对角化的经典结论由此一句话得到。</span>

**应用：矩阵函数的极简定义**。设 $m_A$ 是 $A$ 的最小多项式，$\deg m_A = d$。则对任何多项式
$f$，$f(A)$ 只由 $f$ 在 $A$ 的谱上的取值决定——具体地，$f$ 与它除以 $m_A$ 的余式在 $A$
上相等。这使「定义 $f(A)$」归结为「构造一个 $d-1$ 次插值多项式」，是矩阵指数、矩阵对数的定义基础。

## 4 矩阵幂的递推与伴随展开

Cayley-Hamilton 的「$n$ 阶截断」给出了一个非常实用的副产品：**矩阵幂的线性递推**。

**幂递推**：由 $p(A) = A^{n} + c_{n-1}A^{n-1} + \cdots + c_0I = 0$，
可得

$$A^{n} = -c_{n-1}A^{n-1} - c_{n-2}A^{n-2} - \cdots - c_0 I$$

把两边同乘 $A$ 再代入上式，就能把 $A^{n+1}$ 也化简为 $I, A, \dots, A^{n-1}$
的线性组合；依此类推，**$A^{k}$（任意 $k$）都能化到 $n$ 项之内**。<span class="marginnote">例：$A = \begin{pmatrix}0&1\\1&1\end{pmatrix}$（Fibonacci
矩阵），特征多项式 $t^2 - t - 1$，故 $A^2 = A + I$。于是 $A^{10}$
只需反复代入即可写为 $F_{10}A + F_{9}I$ 这样的组合——矩阵幂与 Fibonacci 数列的对应由此而来。
</span>

**系数与迹、行列式的对应**：特征多项式系数 $c_i$ 是 $A$ 的**初等对称函数**。特别地
$c_{n-1} = -\operatorname{tr}A$、$c_0 = (-1)^n\det A$。把 $A$ 换成
$A^k$ 代入取迹，还能得到著名的 **Newton 恒等式**，把 $\operatorname{tr}(A^k)$
与特征多项式系数互相表出——这是"谱估计"（只需算若干次幂的迹，不必解特征方程）的理论基础。<span class="marginnote">Newton
恒等式：$k\,\mathrm{e}_k = \sum_{i=1}^{k}(-1)^{i-1}\mathrm{e}_{k-i}p_i$，
其中 $p_i = \operatorname{tr}(A^i)$、$\mathrm{e}_i$
是特征多项式的初等对称函数。现代大规模谱估计（如 Lanczos/随机化方法）正是靠少量
$\operatorname{tr}(A^k)$ 反推谱信息。</span>

**伴随矩阵（adjugate）展开**：Cayley-Hamilton 的另一副面孔来自恒等式
$(tI - A)\operatorname{adj}(tI - A) = p(t)I$。把
$\operatorname{adj}(tI-A)$ 按 $t$ 的幂展开并比较系数，可以逐项解出 $A$
的各次幂与伴随矩阵的关系。当 $A$ 可逆时，最干净的形式是

$$A^{-1} = -\frac{1}{c_0}\left(A^{n-1} + c_{n-1}A^{n-2} + \cdots + c_1 I\right)$$

**逆矩阵可以用特征多项式系数直接表出**，完全不经过高斯消元——虽然对大矩阵计算量偏大，但在理论推导（如矩阵方程、
扰动分析）中价值极高。<span class="marginnote">从极限到大模型的连接：矩阵幂的递推是线性循环网络（RNN/LRU）、
以及状态空间模型离散化里"快速幂"的代数内核——预先算好 $A^k$ 的 $n$ 项表达式，就能用 $O(n)$ 而非
$O(n^3)$ 计算任意次幂。这也是"矩阵幂级数求值"（如 Krylov 子空间法）背后的思想。</span>

**辨析｜易错点：** 幂递推中的系数 $c_i$ 来自**特征多项式**（取 $tI - A$ 的展开，首项系数 1）；
若误用 $A - tI$ 的展开，各项符号会整体差 $(-1)^n$。另一个易错点：$A^{-1}$ 的伴随展开要求
$c_0 = (-1)^n\det A \neq 0$，即 $A$ 可逆——奇异矩阵没有此式，这也再次印证"$c_0$
的符号与可逆性挂钩"。

## 5 公式解析：Cayley-Hamilton 的矩阵代入 $p(A) = 0$

「把 $\lambda$ 换成 $A$」看似照抄，实则大有讲究，拆四步：

- **第一步，分清"形式代入"**：特征多项式 $p(\lambda) = \lambda^n + c_{n-1}\lambda^{n-1} + \cdots + c_0$ 中，常数项 $c_0$ 要换成 $c_0 I$——**标量项升级为单位矩阵**，否则常数项无法与矩阵相加。这是代入时的第一处细节。
- **第二步，为什么能对角化情形直接验证**：若 $A = S\Lambda S^{-1}$，则 $p(A) = S p(\Lambda) S^{-1}$，而 $p(\Lambda) = \operatorname{diag}(p(\lambda_1), \dots, p(\lambda_n))$，每个对角元 $p(\lambda_i) = 0$（$\lambda_i$ 是 $p$ 的根），故 $p(\Lambda) = 0$、$p(A) = 0$。**对角阵情形下定理退化为一句话：矩阵对角元逐个满足自己的特征方程**。
- **第三步，亏损情形的桥梁**：不能对角化时，用 Jordan 块逐个验证——每个块内 $(J-\lambda I)^{k}=0$ 恰好命中特征多项式中的链长因子，块被零化。**Cayley-Hamilton 对亏损矩阵依然成立，靠的是 Jordan 链条的幂零结构**。
- **第四步，更高意义**：定理真正说的是「矩阵满足一个 $n$ 次首一多项式」，从而矩阵代数的维度至多为 $n$。这个「有限维约束」是所有矩阵幂级数、矩阵方程解空间维数论断的根源。

## 6 小结

- **Cayley-Hamilton**：$p(A) = 0$；任何矩阵满足自己的特征方程，矩阵幂被 $n$ 阶截断。
- **最小多项式** $m_A$：最小的首一零化多项式，唯一且整除一切零化多项式（含 $p$）。
- **从 Jordan 读 $m_A$**：$m_A = \prod(t-\lambda)^{k_\lambda}$，指数取最大块长；$p$ 的指数取链长之和。
- **对角化判据**：$A$ 可对角化 ⇔ $m_A$ 无重根。
- 易错点：$m_A$ 与 $p$ 指数不同；可对角化时即使 $p$ 有重根 $m_A$ 也无重根。

在下一节，我们将把「沿谱定义函数」的思想推向高潮——矩阵指数与矩阵对数，让 $\exp$ 与 $\log$ 真正作用于矩阵。
