## 为什么从传递函数开始

此前的 ARIMA 模型把序列当作「自洽」的：解释变量只有自己的过去与过去的噪声。但现实中序列常被**外部输入**驱动：广告投放推高销量、利率变化影响房价、工厂停机冲击产量。当外生变量 $Z_t$ 影响目标序列 $X_t$ 时，单变量 ARIMA 就漏掉了最重要的机制。

**传递函数模型（transfer function model）**把「输入如何传导到输出」显式建模：输入冲击不会瞬间完成，而是按一定形状（当期、滞后、渐近、持久）分布到后续各期——这就是**传递函数**。**干预分析（intervention analysis）**是它的一个特殊而重要的情形：输入是「事件哑变量」（政策出台、假期、灾难），估计该事件对序列的持久影响。Box 与 Tiao 在 1975 年用干预分析评估了洛杉矶机场空气质量法令的效果——这是本节最经典的教科书案例。<span class="marginnote">传递函数本质上是对单变量 ARMA 的「外生化」：把「输入 → 输出」的动态关系从噪声里剥离出来。它也可以看作线性系统理论（控制论）在统计时间序列中的映射——我们把 Z 传递到 X 的机制写成有理函数。</span>

## 1 传递函数模型的结构

基本形式是「输入经过延迟与加权进入输出」：

$$
X_t = \frac{\omega(B) B^b}{\delta(B)} Z_t + N_t
$$

其中 $N_t$ 是误差项（常为 ARMA），$b$ 是**延迟阶数**，$\omega(B) = \omega_0 + \omega_1 B + \cdots + \omega_s B^s$ 是输入侧的分子多项式，$\delta(B) = 1 - \delta_1 B - \cdots - \delta_r B^r$ 是输出侧的分母多项式。

**三个要素**各自刻画传导的形状：

- **$b$（延迟）**：输入冲击到输出反应之间的等待时间。广告效果常有 1–2 期延迟。
- **$\omega$ 多项式**：冲击的**直接**强度分布——当期多少、滞后一期多少。
- **$\delta$ 多项式**：冲击的**持久**性——$\delta_1 > 0$ 时冲击的影响渐近累积，形成「渐近到达」或「长期水平位移」。

**静态 vs 动态**：若只有 $\omega_0$（无滞后、无分母），模型退化为普通回归 $X_t = \omega_0 Z_t + N_t$；$\delta$ 的存在才让「动态传导」（乘数效应、衰减路径）出现。<span class="marginnote">从控制论的视角，传递函数 $H(B) = \frac{\omega(B)B^b}{\delta(B)}$ 正是「系统对单位输入的响应」的 Z 变换表达：$\delta(B)$ 根的位置决定响应是振荡、指数衰减还是永久偏移。</span>

## 2 干预变量：哑变量是输入的特例

**干预分析**把 $Z_t$ 换成两类特殊的哑变量：

**阶跃函数（step）**：$S_t^{(T)} = 0 \ (t < T)$，$= 1 \ (t \ge T)$——模拟「政策出台后永久生效」。
- **脉冲函数（pulse）**：$P_t^{(T)} = 1 \ (t = T)$，$= 0$（其余）——模拟「单次事故或节日」。

把这两种哑变量放进传递函数骨架，就能回答「这个事件改变了序列的水平吗？改变了多少？是瞬时还是渐近？」。<span class="marginnote">干预分析的巧妙之处在于：把「事件有没有影响」转化为「传递函数中的参数是否显著非零」——一个统计检验问题。Box-Tiao 的洛杉矶机场研究（1975）正是用阶跃干预估计了空气质量法规的降污效果，成为应用计量的经典。</span>

## 3 传递函数的识别：交叉相关函数

识别 $b$、$r$、$s$ 的关键工具是**交叉相关函数（cross-correlation function，CCF）**：

$$
\rho_{ZX}(k) = \operatorname{Corr}(Z_{t-k}, X_t) / \sigma_{noise}
$$

（严格地，要对预白噪声化的输入与输出计算）。CCF 在哪些滞后上显著，就指示延迟 $b$ 与传导形状。<span class="marginnote">「预白噪声化」是关键一步：若输入 $Z_t$ 本身高度自相关，CCF 会被自身的序列相关污染，必须先把输入「漂白」成白噪声、再用同样的滤波作用于输出，交叉相关才有意义——这又是谱/滤波思想在时域的落地。</span>

**识别步骤**：先对输入建 ARMA（预白噪声化），用同一模型滤波输出，再算 CCF；CCF 显著起始位置定 $b$，随后的衰减形态定 $r$、$s$。

## 4 干预分析的建模流程

**Box-Tiao 干预分析四步**：

1. **建模噪声**：忽略干预，先对 $X_t$ 拟合 ARIMA，得到 $N_t$ 的结构（残差近似白噪声）。
2. **识别干预形式**：观察干预点前后残差，确定用阶跃还是脉冲，确定传递函数形状（瞬时/渐近）。
3. **联合估计**：把干预项与噪声模型一起做 MLE，估计干预参数（水平变化量、衰减率）与噪声参数。
4. **诊断**：检查残差是否白噪声；若有残留，调整干预形式重来。

**一个典型的阶跃干预模型**（瞬时水平位移 + ARMA 噪声）：

$$
X_t = \mu + \omega S_t^{(T)} + N_t, \qquad N_t \text{ 为 ARMA}
$$

$\omega$ 显著则说明事件改变了序列的水平；$\hat\omega$ 就是事件效应的大小估计。

## 5 公式解析：阶跃干预的渐近到达

考虑干预经传递函数 $\frac{\omega_0}{1 - \delta_1 B}$ 作用于输出：

$$
X_t = \frac{\omega_0}{1 - \delta_1 B} S_t^{(T)} + N_t
$$

- **第一步，展开传递函数**：$\frac{1}{1-\delta_1 B} = \sum_{j=0}^\infty \delta_1^j B^j$，于是干预项 $= \omega_0 \sum_{j=0}^\infty \delta_1^j S_{t-j}^{(T)}$。
- **第二步，作用在阶跃上**：$S_{t-j}^{(T)}$ 当 $t-j \ge T$ 时为 1，即 $j \le t-T$。故干预项 $= \omega_0 \sum_{j=0}^{t-T} \delta_1^j = \omega_0 \frac{1 - \delta_1^{t-T+1}}{1 - \delta_1}$。
- **第三步，读形状**：事件发生后，水平从 $\omega_0$ 起步，随 $t$ 增大渐近趋于 $\omega_0/(1-\delta_1)$——**渐近到达**。$\delta_1 \to 0$ 时退化为瞬时到位 $\omega_0$；$\delta_1$ 接近 1 时趋近过程极慢，几乎看不出终点。<span class="marginnote">这个等比求和的形状，与 AR(1) 的脉冲响应 $\phi^j$ 完全同构——干预的渐近到达就是「冲击沿传递函数的记忆扩散」。</span>

**辨析｜易错点**：别把干预效应与趋势变化混淆。若事件前后序列趋势本就改变（如经济拐点），仅加一个阶跃哑变量会把「趋势漂移」误归因于事件。因此干预分析必须与《单位根检验与协整》中的确定性趋势/结构突变判定联合使用——**先分清是水平位移还是趋势变化，再谈效应大小**。

## 6 数值算例：一次阶跃干预的效应

把「渐近到达」落到一组数上。设阶跃干预 $S_t^{(T)}$ 经传递函数 $\frac{\omega_0}{1-\delta_1 B}$ 作用于输出，取 $\omega_0 = 2$、$\delta_1 = 0.8$。事件后第 $j$ 期，累积水平位移为

$$
\text{效应}(j) = \omega_0\, \frac{1 - \delta_1^{j+1}}{1 - \delta_1}
$$

| 事件后第 $j$ 期 | 累积水平位移 |
| --- | --- |
| 0 | 2.00 |
| 1 | 3.60 |
| 2 | 4.88 |
| 3 | 5.90 |
| 4 | 6.72 |
| $\infty$ | 10.00 |

**读表**：事件当天只升 $2$，随后每期补上一部分（$+1.6, +1.28, +1.02, +0.82, \dots$），渐近逼近 $10$——前四期只走了约三分之二，还有三分之一要留给后续。这解释了为什么干预评估要看「长期水平」而非「当期响应」：把第 0 期的 $2$ 当政策效果，会严重低估一个终值 $10$ 的干预。<span class="marginnote">$\delta_1$ 越接近 1，逼近越慢：$\delta_1 = 0.9$ 时同样 $\omega_0 = 2$，终值变成 $20$，且要走约 20 期才到一半。$\delta_1$ 同时决定「多快」与「多远」，是干预形状的枢纽参数。</span>

**顺带核对**：$1 + \delta_1 + \delta_1^2 + \cdots = \frac{1}{1-\delta_1} = 5$，所以终值 $= \omega_0 \times 5 = 10$——与等比求和一致。若 $\delta_1 = 0$，则只升 $\omega_0$ 后立即停住，回到「瞬时到位」的退化情形。

## 7 小结

- **传递函数模型**：$X_t = \frac{\omega(B)B^b}{\delta(B)} Z_t + N_t$，输入经延迟与加权传导到输出。
- **三要素**：延迟 $b$、直接强度 $\omega$、持久性 $\delta$；只有 $\delta$ 才产生动态传导。
- **干预分析**：把事件编码成阶跃/脉冲哑变量，估计事件对水平的（瞬时或渐近）效应。
- **识别工具**：CCF + 预白噪声化，读 $b$、$r$、$s$。
- **Box-Tiao 流程**：先建噪声模型，再定干预形式，联合 MLE，最后诊断。
- **算例直觉**：$\omega_0=2, \delta_1=0.8$ 时终值 $10$，前四期只走三分之二——长期水平才接近政策效应。
- **辨析**：水平位移与趋势变化要区分，避免把拐点误归因于事件。
