## 为什么从凸集开始

这个专题叫「离散与凸几何」，凸性是把它连成一体的脊椎：**离散**的一侧讨论有限点集的排列、格点与计数，**凸**的一侧讨论凸体与支撑函数，而两者交汇于一个朴素的问题——「有限个点生成的凸包长什么样」。凸性又是整个优化理论的地基：线性规划可行的、对偶的、最优的结构全部由凸性保证，第二级《凸分析》与《最优化理论》会把这里的地基盖成高楼。就连大模型的训练表面也处处依赖凸的松弛与近端算子，只不过那里我们常常让凸性「打折扣」。今天这一篇，从凸集的定义一路走到分离定理——后者常被称作「凸性的基本定理」，因为它把几何直观变成了可以证明的分离事实。

## 1 凸集：定义与第一印象

**凸集（convex set）**：集合 $C \subseteq \mathbb{R}^d$ 称为凸集，如果对任意 $x, y \in C$ 与任意 $\lambda \in [0,1]$，线段上的点 $(1-\lambda)x + \lambda y$ 仍属于 $C$。<span class="marginnote">一句话记住它：<strong>凸集对「连接两点的整条线段」封闭</strong>，而不只是对端点封闭。空集、单点集、整条直线都平凡地满足定义，它们都是凸集。</span>

这个定义值得慢读三遍。它要求的不是「两点之间某处」，而是**整条线段**都落在集合里。于是凹多边形不是凸集，挖了洞的圆盘也不是凸集，但实心圆盘、实心多边形、超平面、半空间、整个空间都是凸集。

**辨析｜易错点：** 凸集与凸函数是两个不同的概念。凸函数是「函数图像的上方区域（上境图）为凸集」的函数；判断函数是否凸，用的是 Jensen 不等式 $f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda) f(y)$，这恰好是「图像下方区域是凸集」的翻译。**凸函数的下方区域（下境图）不是凸集，凸集也不是函数**——一个函数、一个集合，别混为一谈。<span class="marginnote">区分它们的口诀：<strong>凸集看线段，凸函数看弦</strong>。图像上任意两点连成的弦（chord）若总在图像上方，函数就是凸的；这与集合里的「线段」严格对应。</span>

凸集的典型例子随手可举：欧氏球 $B(x_0, r) = \{x : \|x - x_0\| \le r\}$，半空间 $\{x : a^\top x \le b\}$，多面体 $\{x : Ax \le b\}$，以及概率单形 $\Delta_d = \{x \ge 0 : \sum_i x_i = 1\}$。概率单形尤其重要——概率分布全体就是一个凸集，混合分布就是凸组合，贝叶斯更新在凸集上移动。这与第一级《集合的概念》里「事件是集合、概率论是集合论加度量」的伏笔接上了。

**凸集的三个「封闭性」操作**是这一概念成为理论的关键：凸集的**交**仍凸（任意多个）、凸集的**Minkowski 和**仍凸、凸集的**仿射像**（线性映射 + 平移的像）仍凸。这三条让「凸」在运算下保持稳定——后两篇的支撑函数、分离定理全靠这些封闭性才成立。而**并集破坏凸性**：两个凸集的并一般不凸（除非粘连成一块），这正是「取凸包」这个操作存在的意义——把被并集破坏的凸性「重新补回来」。

**凸性与大模型的隐秘连接**：机器学习里，参数空间的可行域（例如权重非负、概率单形约束）几乎都是凸集；损失函数若是凸的，局部极小就是全局极小，优化一路绿灯。现代大模型虽是非凸的深渊，但**每一层里的凸子结构（Softmax 的概率单形、ReLU 的分片线性、投影梯度里的凸集投影）仍是稳定性的来源**——「在凸集上做凸运算」这一句，是理解深度学习训练不爆炸的地基。

## 2 凸包：从点集到凸集的最小容器

给定任意集合 $X \subseteq \mathbb{R}^d$，把它装进凸集的最小方式是**凸包（convex hull）**：

$$\mathrm{conv}(X) = \bigcap \{C \supseteq X : C \text{ 是凸集}\}$$

把 $X$ 装进去的所有凸集的交，仍是凸集，且是包含 $X$ 的最小凸集。<span class="marginnote">交仍是凸集这一点很重要：凸集族对任意交封闭（但对并集不封闭）。「先取所有能装下它的凸集，再取交」，这是构造性定义的典型范式，后面还会反复遇到。</span>

凸包还有更实用的生成式描述：$\mathrm{conv}(X)$ 恰是 $X$ 中元素所有凸组合的集合。

$$
\mathrm{conv}(X) = \left\{ \sum_{i=1}^{k} \lambda_i x_i : x_i \in X,\ \lambda_i \ge 0,\ \sum_{i=1}^{k}\lambda_i = 1,\ k \ge 1 \right\}
$$

这个描述让「凸包」从抽象的定义变成可以计算的对象。离散几何里最常见的场景是：$X$ 是一个**有限点集**，它的凸包是一个**凸多面体**，其顶点是 $X$ 的**极点（extreme point）**——不能写成其余点凸组合的点。

对有限点集 $X = \{x_1, \dots, x_n\}$，凸包还有一个「几何视图」：它是 $X$ 的**最小凸壳**，可以想象成「把钉子钉在 $X$ 上、用橡皮筋猛地绷紧」——橡皮筋最终停下的多边形轮廓就是 $\mathrm{conv}(X)$。这个「橡皮筋视图」不是比喻，它就是计算几何里凸包算法（Graham 扫描、单调链）的直接目标：算出轮廓顶点的有序序列。<span class="marginnote">「橡皮筋」对应凸包的唯一性：给定点集，凸包只有一种，轮廓顶点是 $X$ 中不可省去的点。这为后面《与计算几何的联系》里凸包算法的正确性提供了几何保障——算法争的只是「找出这个唯一轮廓」的效率。</span>

**极点（extreme point）**：$p \in C$ 是极点，如果 $p = \lambda x + (1-\lambda)y$（$x,y \in C$，$0 \lt  \lambda \lt  1$）蕴含 $p = x = y$。直观地说，极点就是凸集「伸出去」的角。凸多面体的顶点、概率单形的 $d+1$ 个标准基向量、圆盘的整个边界（无穷多个极点）都是极点。

## 3 支撑超平面：从外面看凸集

凸集最优雅的性质之一是：**它完全由从外面看到的「影子」决定**。对任意方向向量 $a \neq 0$，把 $C$ 沿方向 $a$ 推到最远处，得到支撑函数（support function）：

$$h_C(a) = \sup \{ a^\top x : x \in C \}$$

超平面 $\{x : a^\top x = h_C(a)\}$ 在 $C$ 的「最远端」相切，称为 $C$ 在该方向的**支撑超平面（supporting hyperplane）**，它把 $C$ 留在半空间 $a^\top x \le h_C(a)$ 的一侧。<span class="marginnote">支撑函数是凸集的一种「外表示」：一族方向对应一族支撑超平面，凸集恰好是所有支撑半空间之交。圆盘的支撑函数是半径乘范数，正多边形的支撑函数是分片线性函数——支撑函数的光滑程度，暴露了凸集的光滑程度。</span>

为什么支撑超平面总存在？因为 $C$ 闭且 $a^\top x$ 连续，在有界闭凸集上达到最大值。若 $C$ 无界或开，需要小心处理边界情形——这正是分离定理要精确化的地方。

支撑函数是凸集的一部「雷达」：沿每个方向 $a$ 测一次最远距离，就拼出整个凸集。两个具体例子让「雷达」落地：

**单位圆盘** $B = \{x : \|x\| \le 1\}$：$h_B(a) = \|a\|$，支撑超平面是沿 $a$ 方向切圆的切线；
**单位立方体** $Q = [-1,1]^d$：$h_Q(a) = \|a\|_1 = \sum |a_i|$，支撑超平面在 $a$ 的符号向量决定的顶点处相切。

<strong>支撑函数与范数互为对偶</strong>：$h_K = \|\cdot\|_{K^\circ}$，其中 $K^\circ$ 是极体。圆盘与立方体的支撑函数分别是 $L_2$ 与 $L_1$ 范数，恰好互为对偶——这一层对偶关系在第二级《凸分析》里会展开成支撑函数与范数的完整理论。<span class="marginnote">「凸集的支撑函数 = 一组范数」这条等式，让几何问题可以翻译成范数/对偶范数问题——<strong>几何的凸性，就是范数的凸性</strong>。这也是线性规划对偶、博弈论零和对策里「原始—对偶」轮换的几何源头。</span>

**支撑超平面存在定理**：设 $C$ 是非空闭凸集，$a \neq 0$ 是任意方向，则存在支撑超平面 $H = \{x : a^\top x = h_C(a)\}$ 使 $C \subseteq \{x : a^\top x \le h_C(a)\}$，且 $H$ 与 $C$ 至少有一个公共点（当最大值达到时）。

## 4 公式解析：强分离定理

分离定理是凸性最重要的一条定理，值得逐字拆解。**强分离定理（strong separation theorem）**：设 $C$ 是非空闭凸集，点 $x_0 \notin C$，则存在非零向量 $a$ 与实数 $b$，使得

$$
a^\top x_0 > b, \qquad a^\top y \le b \quad (\forall y \in C)
$$

对这条式子做四步拆解：

- **第一步，读懂 $a^\top y \le b$ 对一切 $y \in C$ 成立**：这说明整个凸集 $C$ 被压在超平面 $H = \{x : a^\top x = b\}$ 的一侧。$b$ 是「门槛」，$a$ 是超平面的法方向。
- **第二步，读懂 $a^\top x_0 > b$**：点 $x_0$ 严格越过门槛，落在 $H$ 的另一侧。于是 $x_0$ 与 $C$ 被 $H$ **严格分开**，中间隔着一条正宽度的缝隙。
- **第三步，为什么需要 $C$ 闭**：若 $C$ 是开集而 $x_0$ 在边界「外侧」，则只能得到弱分离 $a^\top x_0 \ge b \ge a^\top y$，中间的等号可能在边界达到——缝隙消失。闭性保证 $\mathrm{dist}(x_0, C) = \delta > 0$，从而有正缝隙。
- **第四步，证明直觉**：取 $C$ 中离 $x_0$ 最近的点 $p$。因为 $C$ 凸，对任意 $y \in C$，从 $p$ 走向 $y$ 的整条线段都在 $C$ 内，而 $x_0$ 到线段上任一点的距离在 $p$ 处取最小——微积分强迫「$x_0 - p$ 与 $y - p$ 的夹角为钝角」，即 $(x_0-p)^\top (y - p) \le 0$。取 $a = x_0 - p$、$b = a^\top p$，即得结论。

最近点这一论证是凸分析的镇馆之宝：**「到凸集最近的点，其连线垂直于该点的支撑超平面」**，这一几何事实同时给出分离向量 $a$，一个论证同时证明了存在性与构造。第二级《凸分析》里，它会被抽象成「投影算子的刻画」。

## 5 弱分离、严格分离与 Farkas 引理

分离定理有很多强度不一的版本，辨析它们的差别是考试与研究中都爱考的点：

**辨析｜易错点：** 三个版本的区别在于缝隙的大小。**弱分离**只要求 $a^\top x_0 \ge b \ge a^\top y$，允许 $x_0$ 或 $C$ 里的点落在超平面上；**严格分离**要求 $a^\top x_0 > b > a^\top y$，两边都留缝——这要求 $C$ 闭、$x_0 \notin C$；**强分离**只要求一边严格（上面的版本）。**凸集边界上的点与凸集本体不可分离**：如果 $x_0 \in \mathrm{cl}(C)$ 而 $x_0 \notin C$（例如 $C$ 开），则任何超平面都会被 $C$ 逼近到零距离，只能弱分离。<span class="marginnote">一句话：<strong>闭性决定能不能强分离，开性让缝隙消失</strong>。几何直觉——把 $C$ 想成浓汤，$x_0$ 想成汤勺：勺子能挑出汤面，靠的就是 $C$ 闭、$x_0$ 在外面。</span>

分离定理最著名的推论是 **Farkas 引理**，它是线性规划对偶性的发动机：

$$
\exists x \ge 0 \text{ 使 } Ax = b \quad \Longleftrightarrow \quad \forall y,\ (A^\top y \ge 0 \Rightarrow b^\top y \ge 0)
$$

这两个命题恰好一个为真。几何上，它说的是：向量 $b$ 要么落在锥体 $K = \{Ax : x \ge 0\}$ 里，要么存在一个向量 $y$ 把 $b$ 与 $K$ 分离——**「要么在里面，要么被分离」的二选一，正是线性规划原始—对偶互为充要条件的几何根源**。我们把「分离」用到了线性系统上：一个点不在某个凸锥里，就存在超平面把两者隔开，这超平面的法向量 $y$ 反过来正是原系统的「对偶解」。

用一维小例子把 Farkas 摸熟。设 $A = \begin{pmatrix}1\\1\end{pmatrix}$、$b = \begin{pmatrix}1\\-1\end{pmatrix}$，问是否存在 $x \ge 0$ 使 $Ax = b$？即 $\begin{pmatrix}x\\x\end{pmatrix} = \begin{pmatrix}1\\-1\end{pmatrix}$——左边两个分量相同、右边不同，**不可行**。Farkas 的右侧如何察觉？取 $y = \begin{pmatrix}-1\\2\end{pmatrix}$：$A^\top y = 1 \ge 0$，但 $b^\top y = -1 - 2 = -3 \lt  0$——右侧条件被违反，二选一的另一支（不可行）成立。**$y$ 就是这个一维系统的「分离证人」**：它顺着锥的方向非负，却在 $b$ 上给出负值，直接把 $b$ 挡在锥外。<span class="marginnote">「分离证人」$y$ 在优化里的名字是<strong>乘子、影子价格或对偶变量</strong>——约束 $i$ 的影子价格越大，说明这条约束卡得越紧。Farkas 告诉你：不可行的证据，本身就是一份对偶解。</span>

## 6 小结

- **凸集**：对两点间整条线段封闭；凸集族对任意交封闭，对并不封闭。
- **凸包**：包含 $X$ 的最小凸集，等于 $X$ 中元素所有凸组合；极点是不能写成他人凸组合的点。
- **凸集的封闭性**：交、Minkowski 和、仿射像保持凸性；并集破坏凸性，「凸包」负责把凸性补回来。
- **支撑超平面**：沿方向 $a$ 的支撑函数 $h_C(a) = \sup_{x \in C} a^\top x$，凸集是其全部支撑半空间之交；$h_B = \|\cdot\|$ 揭示范数对偶。
- **强分离定理**：闭凸集 $C$ 与外部点 $x_0$ 可被超平面严格分离；证明核心是「最近点—钝角」论证。
- **三个分离版本**：弱、严格、强，差别只在缝隙；边界点与开集只能弱分离。
- **Farkas 引理**：$b$ 在锥内或被分离的二选一，是线性规划对偶性的几何内核；「分离证人」即对偶变量/影子价格。
- **支撑函数 = 范数**：$h_K = \|\cdot\|_{K^\circ}$，几何凸性翻译成范数对偶，通向第二级《凸分析》与《最优化理论》。

在本篇结束前，值得把「分离」这个词再咀嚼一次：它不仅是几何定理，还是一种**论证方式**——「一个点不在凸集里，就找一个超平面把它钉死在外面」。这种「分离式反驳」将贯穿整个专题：Farkas 用它证对偶，Helly 用它查可行性，支持向量机（SVM）用它找最大间隔，而这一切的源头都是今天这篇的分离定理。记住一句话：**凸集之间的战争，靠超平面来裁决。**

在下一节，我们将把「有限点集的凸包」这个话题推到底：一个点若要写成一个集合的凸组合，到底需要多少个点？平面上是 3 个，高维是 $d+1$ 个——而这个「恰好 $d+1$」的事实，正是 **Carathéodory、Helly 与 Radon 三大定理**共同的起点。分离定理说「凸集之间用超平面裁决」，下一节的三兄弟则告诉你「一个点藏进凸包需要几个帮手」——两套语言合在一起，就是离散与凸几何最锋利的组合武器。
