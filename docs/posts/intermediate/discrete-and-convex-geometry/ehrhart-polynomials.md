## 为什么从计数函数开始

上一篇的 Minkowski 定理只回答「有没有非零格点」，是个存在性声明。这一篇要问一个更精细的问题：**多面体边长放大 $n$ 倍后，里面到底有多少个整数点？** 1962 年，法国数学家 Ehrhart 发现了一个近乎奇迹的事实：这个离散的计数函数居然是一个**多项式**——连续的量（体积）与离散的量（格点数）被一条多项式等式缝合。这条多项式叫 **Ehrhart 多项式**，它把上一篇的体积论证、前几篇的多面体几何，以及代数计数（准多项式、生成函数）串成一条线。平面情形它退化为高中竞赛里鼎鼎大名的 **Pick 定理**——很多人第一次意识到「数格点」可以如此精确，就是在 Pick 定理那里。

## 1 计数函数 L_P(n)：把多面体放大

设 $P \subseteq \mathbb{R}^d$ 是一个**格多面体（lattice polytope）**：所有顶点都是整数格点。把 $P$ 沿原点方向放大 $n$ 倍（$n$ 为正整数），记 $nP = \{ n x : x \in P \}$，定义计数函数

$$
L_P(n) = \left| nP \cap \mathbb{Z}^d \right|
$$

即 $nP$ 内整数格点的个数。<span class="marginnote">$nP$ 读作「$n$ 倍 $P$」：放大镜下的多面体。注意 $n$ 必须是整数，$L_P(n)$ 才谈得上格点计数——$n$ 取实数时「格点」概念没有自然意义。</span>

先做小实验，直觉就活了。单位区间 $[0,1]$（$d=1$）：$L(n) = n+1$，放大 $n$ 倍后 $0, 1, \dots, n$ 共 $n+1$ 个点。单位正方形 $[0,1]^2$：$L(n) = (n+1)^2$。标准三角形 $\{x,y \ge 0, x+y \le 1\}$：$L(n) = \frac{(n+1)(n+2)}{2}$。三个例子都指向同一个猜想：$L_P(n)$ 是 $n$ 的多项式，次数等于维数 $d$。

把三个例子并排看，还能读出更多：区间与正方形的 $L(n)$ 是「$(n+1)^d$」型（所有系数都来自「边界加 1」），三角形则不同——$L(n) = \frac{(n+1)(n+2)}{2}$ 是「组合数」型（在 $n+2$ 个位置里取 2 个）。**形状不同，Ehrhart 多项式的「长相」也不同**：方块是乘积型，单形是二项式系数型。这种「形状 → 多项式形态」的对应，正是 Ehrhart 理论最迷人的部分——后面我们还会看到它如何被编码进 $h^*$-向量。

## 2 Ehrhart 定理：离散计数是连续多项式

**定理（Ehrhart, 1962）**：设 $P \subseteq \mathbb{R}^d$ 是 $d$-维格多面体，则 $L_P(n)$ 是 $n$ 的 $d$ 次多项式，且满足结构约束：

$$
L_P(n) = \mathrm{vol}(P)\, n^d + \frac{1}{2}\,\mathrm{vol}(\partial P)\, n^{d-1} + \dots + 1
$$

- **首项系数**是 $P$ 的体积 $\mathrm{vol}(P)$：放大到 $n$ 倍，体积按 $n^d$ 增长，格点密度约等于 $1$，所以最大项是体积乘 $n^d$；
- **次高项系数**是边界（各刻面的 $(d-1)$-维体积之和）的一半；
- **常数项恒为 1**：无论多面体长什么样，$L_P(0) = 1$——只有一个点（原点）在 $0 \cdot P$ 里。<span class="marginnote">常数项 $=1$ 不是平凡的约定，它隐藏着欧拉公式的余韵：$L_P(0)=1$ 对应「空凸体的格点数」，与上一篇 $h_0=1$ 蕴含欧拉公式是同一件事的两种讲法。</span>

**辨析｜易错点：** $L_P(n)$ 是多项式**要求 $P$ 的顶点都是格点**。若 $P$ 是**有理多面体**（顶点坐标有理数），$L_P(n)$ 只是**准多项式（quasi-polynomial）**——按 $n$ 的周期分段的几个多项式。例如三角形 $\{x \ge 0, y \ge 0, 2x + y \le 1\}$ 的计数函数就周期性地在两个多项式间跳变。把「格点」误当「有理点」，多项式就破功。<span class="marginnote">准多项式的周期就是顶点坐标分母的最小公倍数。这个「整数格点 ⟹ 多项式，有理顶点 ⟹ 准多项式」的二分，是 Ehrhart 理论里最容易被忽略却最关键的分界线。</span>

## 3 公式解析：单位方块的 Ehrhart 多项式

用最简单的例子把多项式系数与几何量对号入座。设 $P = [0,1]^2$ 是单位方块（$d=2$）：

$$
L_P(n) = |\{ (i, j) \in \mathbb{Z}^2 : 0 \le i, j \le n \}| = (n+1)^2 = n^2 + 2n + 1
$$

逐项对照：

- **$n^2$ 项**：系数 $1 = \mathrm{vol}(P)$。放大 $n$ 倍面积是 $n^2$，一个单位面积约莫一个格点，首项把「体积」与「格点」粗略对齐。
- **$n$ 项**：系数 $2 = \frac{1}{2}\,\mathrm{vol}(\partial P)$。边界周长是 4，一半是 2。格点计数的次高项被边界「拉长」——放大后，边界上的格点比内部稀疏的位置多出线性量。
- **常数项**：$1$。$n=0$ 时只有原点。

再看标准三角单形 $T = \{x, y \ge 0,\ x+y \le 1\}$：

$$
L_T(n) = \frac{(n+1)(n+2)}{2} = \frac{1}{2}n^2 + \frac{3}{2}n + 1
$$

首项系数 $1/2$ 恰是 $T$ 的面积；$n$ 项系数 $3/2$ 是周长 $\mathrm{vol}(\partial T) = 1 + 1 + \sqrt{2}$ 的……等等，这里是 $3/2$，而边界体积 $2 + \sqrt{2}$ 的一半约 $1.707$，并不相等。**这说明次高项系数 = 边界体积一半只是「多数情况」下的启发，并非对非单纯多面体的精确公式**——精确公式由刻面的相对体积加权给出。初学常被这个近似带偏：记住次高项「与边界有关」，但别把它当恒等式。<span class="marginnote">对单形，次高项系数其实是各刻面的 Ehrhart 常数组合：$T$ 的两个直角边刻面（长度 1）与一个斜边刻面（长度 $\sqrt2$）各有权重，加总得到 $3/2$。系数的精确值是「刻面计数的组合」，这正是 $h^*$-向量登场的地方。</span>

## 4 Ehrhart 互反律：内部与外部的对称

Ehrhart 多项式最漂亮的性质是一条**互反律（reciprocity law）**：把 $n$ 换成 $-n$，得到的不是无意义，而是**内部**格点数。

**Ehrhart 互反律**：设 $P$ 是 $d$-维格多面体，$P^\circ$ 是它的相对内部，则

$$
L_P(-n) = (-1)^d\, L_{P^\circ}(n) = (-1)^d \left| nP^\circ \cap \mathbb{Z}^d \right|
$$

用方块验证：$L_{[0,1]^2}(n) = (n+1)^2$，于是 $L(-n) = (1-n)^2 = (n-1)^2$。而 $n$ 倍开方块的内部格点是 $\{(i,j) : 1 \le i,j \le n-1\}$，共 $(n-1)^2$ 个，$d=2$ 时 $(-1)^2 = 1$，两边吻合。互反律的哲学：**多项式在负整数处的值，读到的是「内部」的计数**——多项式把边界格点与内部格点编码进同一组系数，正负号只在维度奇偶上翻转。<span class="marginnote">互反律在组合学的亲戚是「$P$ 与 $P^\circ$ 的胞腔分解对偶」。它是代数组合里「互反性质」的典型代表：一个看似形式的代换 $n \to -n$，揭开了几何上的内部/边界二分。</span>

## 5 有理多面体：准多项式登场

前面强调过：顶点必须是整数格点，$L_P(n)$ 才是多项式。当顶点是有理点时，出现的是**准多项式（quasi-polynomial）**——按 $n$ 的周期分段的几个多项式。用例子把「准」字看清楚。设

$$
T = \{ x \ge 0,\ y \ge 0,\ 2x + y \le 1 \}
$$

顶点是 $(0,0)$、$(1/2, 0)$、$(0, 1)$，是有理多面体（含半整点）。放大到 $nT = \{2x + y \le n\}$ 数格点：对 $x = 0, 1, \dots, \lfloor n/2 \rfloor$，$y$ 可取 $0$ 到 $n - 2x$，共 $n + 1 - 2x$ 个，于是

$$
L_T(n) = \sum_{x=0}^{\lfloor n/2 \rfloor} (n + 1 - 2x) = \begin{cases} \left(\frac{n}{2} + 1\right)^2, & n \text{ 偶} \\[4pt] \frac{(n+1)(n+3)}{4}, & n \text{ 奇} \end{cases}
$$

- **第一步，看出分段**：$n$ 为偶时 $\lfloor n/2 \rfloor = n/2$，求和得平方；$n$ 为奇时多一项，得不同的二次式。**同一个计数函数，在奇偶两类 $n$ 上由两个多项式轮流描述**。
- **第二步，找周期**：奇偶两种「相」交替出现，周期是 2——恰好是顶点坐标分母（$2$）的最小公倍数。**周期的分母根源在此**：顶点里的 $1/2$ 让格点计数每两步才「回到同一个世界」。
- **第三步，对比整格点情形**：若把 $2x+y \le 1$ 换成 $x+y \le 1$（整顶点），$L(n) = \frac{(n+1)(n+2)}{2}$ 是单多项式。**「顶点是否整」就是「多项式 vs 准多项式」的分水岭**。

准多项式不是特例而是常态：几乎所有「随机」格多边形都是有理的。整数规划、代数组合里处理格点计数时，**先问周期、再写分段多项式**，是标准动作。

## 6 平面特例：Pick 定理

$d=2$ 时，Ehrhart 多项式退化成一条初等而惊艳的公式——**Pick 定理（1899）**：设 $P$ 是平面格多边形，$I$ 是内部格点数，$B$ 是边界格点数，$A$ 是面积，则

$$
A = I + \frac{B}{2} - 1
$$

从 Ehrhart 看它几乎免费。设 $L(n) = a_2 n^2 + a_1 n + 1$，则 $L(1) = I + B$（原多边形内点加边界点）。面积 $A = a_2$；边界格点数 $B = 2a_1$（次高项系数恰为 $B/2$——对二维格多边形，边界体积的一半就是 $B/2$，这一回精确成立）。代入 $L(1) = a_2 + a_1 + 1 = A + B/2 + 1 = I + B$，移项得 $A = I + B/2 - 1$。<span class="marginnote">Pick 定理 1899 年发表，一度被遗忘，1960 年代被 Reeve 的「Reeve 四面体」等反例提醒高维没有简单推广——直到 Ehrhart 多项式给出正确的 d-维版本。它是「竞赛题常客」，也是 Ehrhart 理论在低维的投影。</span>

**应用一览**：Pick 定理本身是格多边形面积计算的利器；高维 Ehrhart 多项式活跃在代数几何（toric varieties 的 Hilbert 函数）、计数组合（格点枚举软件 LattE、Normaliz）与整数优化（整数规划的目标函数计数）中——**一个看似纯数论的计数问题，成了算法与代数的交汇点**。这与第一级《集合的概念》里「描述法把几何翻译成集合」一脉相承：这里，计数把集合翻译成多项式。

**Reeve 四面体的警示**：1957 年 Reeve 发现，存在一族「体积任意大、格点数却恒为 1」的四面体（顶点 $(0,0,0)$、$(1,0,0)$、$(0,1,0)$、$(1,1,r)$，$r$ 为正整数）。这直接戳破了「格点多 ⟹ 体积大」的朴素联想，也说明**高维没有简单的 Pick 型公式**——体积、边界与格点数的线性关系只在一维边界层面成立，高维必须用整条 Ehrhart 多项式才能说清。**这条警示是「高维几何无免费午餐」的又一注脚**。

## 7 小结

- **计数函数**：$L_P(n) = |nP \cap \mathbb{Z}^d|$，放大倍数 $n$ 下的格点数。
- **Ehrhart 定理**：格多面体的 $L_P(n)$ 是 $d$ 次多项式，首项系数 = 体积，常数项 = 1；有理多面体只保证准多项式。
- **系数对照**：方块 $(n+1)^2$、单形 $\frac{(n+1)(n+2)}{2}$，系数与面积、边界、常数一一对应（次高项仅启发式，非恒等式）。
- **互反律**：$L_P(-n) = (-1)^d L_{P^\circ}(n)$，负整数处读到的是内部格点数。
- **Pick 定理**：$A = I + B/2 - 1$，是 $d=2$
