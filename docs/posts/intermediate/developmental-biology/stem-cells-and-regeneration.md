## 为什么从干细胞与再生开始

前十一节讲的全是「胚胎如何把自己建起来」。但成年身体不是一栋盖完就停工的楼——血液要天天换、皮肤要不断补、肠道上皮两三天就翻新一遍。这些「终生施工」由**干细胞（stem cell）**完成。更神奇的是，有些动物（涡虫、蝾螈）能**重新长出一整条被切断的身体**——再生把「发育程序」从胚胎期搬回了成年期。<span class="marginnote">雅各布那句话点破了干细胞的本质：它既要有「变成两个细胞」的冲动，又要有「其中至少一个还是我」的自律——<strong>自我更新</strong>与<strong>分化</strong>是干细胞的一体两面，也是本节的核心概念。</span>

这一节把「干细胞」从定义、分裂策略、栖息地（龛）讲到重编程（iPS）与再生，最后落到一个发育生物学最激动人心的开放问题：**为什么涡虫能，人不能（至少现在还不太能）？**

## 1 干细胞的界定：自我更新 + 多能性

**干细胞（stem cell）**：能够**自我更新**（至少一个子代保持干细胞状态）又能**分化**成一种或多种成熟细胞类型的细胞。两个条件缺一不可——只会自我更新的不是干细胞（是肿瘤），只能分化的只是前体细胞（progenitor）。

按分化潜能从高到低：

**全能性（totipotent）**：能生成整个生物（含胚外组织）——只有**合子与前几次卵裂的分裂球**。
- **多能性（pluripotent）**：能生成三胚层所有细胞类型，但不能生成胚外组织——**胚胎干细胞（ES 细胞）**与 iPS 细胞。
- **多潜能（multipotent）**：能生成一个谱系内的多种细胞——**造血干细胞**（HSC）能生成全部血细胞。
- **单能（unipotent）**：只能生成一种细胞——皮肤表皮干细胞。<span class="marginnote">把「全能/多能/多潜能/单能」当成一张<strong>向下收窄的谱系树</strong>来记：越往下，选项越少、越「专业」。这张树也是干细胞研究里最常用的坐标——几乎所有实验都在问「某个细胞在这棵树上的位置在哪」。</span>

## 2 分裂策略：不对称与对称的平衡

干细胞用三种方式分裂：

**不对称分裂（asymmetric division）**：一个子代保持干细胞、一个子代走向分化——**维持自身，同时供应后代**。
- **对称自我更新分裂**：两个子代都是干细胞——**扩库**。
- **对称分化分裂**：两个子代都分化——**清库**（损伤时或终末时需要）。

三者比例决定干细胞池的大小。稳定状态（如肠道每天更新）要求**自我更新的概率等于分化+死亡的概率**——群体平衡。损伤后则短暂偏向对称自我更新，把库补回来。<span class="marginnote">不对称分裂的经典例子是果蝇生殖干细胞的「固定方向分裂」：干细胞紧贴龛，分裂时一个子代留在龛里（保持干细胞）、另一个被推走（开始分化）。<strong>谁留在龛里谁就是干细胞</strong>——位置决定身份。</span>

分子上，不对称性可以靠**命运决定因子的不对称分配**（如 Numb 抑制 Notch 只进一个子代），也可以靠**与龛的接触不对称**——两条途径殊途同归。

## 3 龛：干细胞的定居地

**干细胞龛（stem cell niche）**：为干细胞提供定居、维持与自我更新信号的特殊微环境。龛不是抽象的——它有实体的解剖位置与分子组成：

**肠道**：隐窝底部的 Lgr5⁺ 细胞，被周围的 Paneth 细胞（分泌 Wnt 等维持因子）包围，Lgr5⁺ 细胞每 24 小时分裂一次，向上供出整个隐窝的上皮。
- **毛囊**：隆突（bulge）区的干细胞，在生长期被激活、休止期休眠。
- **骨髓**：造血干细胞定居在骨内膜与血管周围龛，受多种细胞因子调控。<span class="marginnote">「龛」的概念是 Schofield 1978 年提出的，它解释了为什么同样的 HSC 移植到不同部位命运不同。<strong>干细胞不是「自带永生」，而是「被环境邀请永生」</strong>——龛给了它继续当干细胞的许可。</span>

龛的破坏（如化疗后的骨髓损伤）会导致干细胞耗尽——理解龛，是理解干细胞移植与再生医学的第一步。

## 4 胚胎干细胞与 iPS 重编程

**胚胎干细胞（ES 细胞）**来自囊胚内细胞团，是多能性的金标准：无限自我更新 + 可分化为三胚层全部细胞。但伦理与免疫问题让医学应用受阻，于是有了重编程的梦想：**能不能把成体细胞「倒带」回多能状态？**

2006 年，**山中伸弥（Yamanaka）**用四个转录因子——**Oct4、Sox2、Klf4、c-Myc**（所谓「山中因子」）——把小鼠成纤维细胞重编程为**诱导多能干细胞（iPS 细胞）**。<span class="marginnote">这个实验的思想源头正是《中胚层与内胚层分化》里 MyoD 的故事：既然一个因子能把成纤维细胞变肌肉，那么一组「多能性主控基因」或许能把成纤维细胞变回胚胎态。iPS 打破了「分化不可逆」的神话——<strong>发育的方向可以被重编程逆转</strong>。</span>

iPS 的意义不只是技术：它证明细胞命运的「锁定」是**表观遗传的稳定状态**，而非不可逆转的宿命——这也把《发育的模式与原理》里基因调控网络的「吸引子」概念变成了可操作的工程。

## 5 再生：重新打开发育程序

**再生（regeneration）**是发育程序在成年期的重演。机制分两大类：

**形态变异（morphallaxis）**：身体重排现有细胞重建缺失部分，不依赖大量新增殖——涡虫切断后，躯干细胞重排成完整小涡虫。
- **末端再生（epimorphosis）**：伤口处形成**再生芽（blastema）**——一群去分化的增殖细胞，重新执行肢体的发育程序。蝾螈断腿后，芽基在数周内重新长出一条腿：**受伤组织去分化 → 芽基增殖 → 位置信息重演（AER 样信号、Shh 梯度）→ 长出正确形态**。<span class="marginnote">蝾螈肢体再生几乎完整重演了《器官发生与四肢发育》的全部程序——包括 AER 样的顶端外胚层与 Shh 的 ZPA 信号。<strong>再生不是「愈合」，而是「重放胚胎发育」</strong>。这也是为什么研究再生等于研究发育。</span>

涡虫更有名：把涡虫切两半，前半长尾巴、后半长头，因为它的身体里散布着约 20% 的**成体多能干细胞（neoblast）**，随时可以重建任意组织。<span class="marginnote">涡虫的「头还能记住哪边是头」——再生出来的头保持原有极性，靠的是<strong>Wnt 信号梯度</strong>：把 Wnt 信号扰乱，涡虫会再生出「两头虫」。极性信息在成年身体里仍由梯度维持，再一次呼应了「梯度启动、网络维持」的总纲。</span>

为什么哺乳动物再生能力差？主流解释是：**免疫反应与纤维化（瘢痕）抢在芽基形成之前把伤口「封死」**；加上成年组织的干细胞库有限。但小鼠新生期能再生心尖（在某个时间窗口内），这提示**再生能力不是消失，而是被抑制**——它是再生医学最大的希望所在。

## 6 公式解析：干细胞群体动力学

干细胞池的稳态可以用一个分支过程描述。设每次分裂有概率 $p$ 产生两个干细胞、概率 $q$ 产生两个分化细胞、概率 $1-p-q$ 产生「一个干细胞 + 一个分化细胞」：

$$
S_{n+1} = S_n + (p - q)\, S_n = (1 + p - q)\, S_n
$$

- **第一步，读 $p$ 与 $q$**：$p$ 是「对称自我更新」概率，$q$ 是「对称分化」概率，$1-p-q$ 是不对称分裂。三者的取值把细胞命运的三种选择压成一个数对。<span class="marginnote">这个模型把「自我更新 = 随机决策」数学化：干细胞不是每个都「想好」再分裂，而是<strong>群体层面以固定概率分配三种结局</strong>。单个细胞是随机的，群体是确定的——这是生物学里「随机个体、统计整体」的典型。</span>
**第二步，读稳态条件**：当 $p = q$，有 $S_{n+1} = S_n$——干细胞池**恰好不变**，同时每个周期仍产出一批分化细胞（数量 = 不对称分裂数 + 2q）。这就是「每天更新肠道又不多长」的数学条件：**自我更新与分化达成精确平衡**。
- **第三步，读失控方向**：若 $p > q$，$1+p-q > 1$，干细胞池指数增长——**这就是癌症的萌芽**（肿瘤干细胞自我更新失控）。若 $p < q$，干细胞池指数衰减——**这就是衰老时的干细胞耗竭**。等式两边正是「肿瘤」与「早衰」之间的那条窄路。
- **第四步，读干预思路**：再生医学本质上在操作 $p$ 与 $q$：把 $q$ 压下去（用龛信号维持自我更新）、把 $p$ 提上来（损伤后扩库），然后希望系统能回到 $p=q$ 的稳态。<span class="marginnote">注意这个方程是<strong>期望值</strong>方程，它忽略了随机漂移——真实干细胞群的命运在统计上有方差（克隆丢失），这也是「谱系追踪」实验要处理的核心量。想深入，可看第三级《随机过程与生物建模》。</span>

## 7 辨析：全能≠多能；再生≠愈合

**辨析｜易错点：**

1. **全能性只有合子与早期分裂球有**：ES 细胞和 iPS 细胞只是**多能**（不能生成胚外滋养层）。把「全能」和「多能」混用，是干细胞术语里最常见的错误。
2. **再生 ≠ 伤口愈合**：愈合是纤维化封闭伤口（瘢痕）；再生是**重演发育、重建缺失结构**。哺乳动物皮肤愈合得很好，却不叫再生——因为长回的是疤，不是原组织。
3. **干细胞 ≠ 永生化细胞**：癌细胞「永生化」但不会正常分化；干细胞能分化、受龛约束。**「不死」与「多能」不是一回事**。
4. **iPS 不是 ES 的复制品**：iPS 有自己独特的表观遗传记忆（可能保留原组织的部分沉默印记），且重编程引入了突变风险——「iPS ≈ 患者的私人 ES」只是工程近似，不是完美等价。

## 8 术语速查与再生能力对照

收一张术语表：

| 术语 | 一句话定义 |
| --- | --- |
| 自我更新 | 至少一个子代保持干细胞态 |
| 多能性（pluripotent） | 可分化为三胚层全部细胞 |
| 全能性（totipotent） | 能生成完整生物体 |
| 不对称分裂 | 一子代干细胞、一子代分化 |
| 干细胞龛（niche） | 维持干细胞的微环境 |
| ES 细胞 | 囊胚内细胞团的多能干细胞 |
| iPS 细胞 | 重编程得到的诱导多能干细胞 |
| neoblast | 涡虫的成体多能干细胞 |
| 芽基（blastema） | 再生处去分化的增殖细胞 |

不同动物的再生能力相差悬殊，对照着记最好：

| 动物 | 再生能力 | 机制 |
| --- | --- | --- |
| 涡虫 | 切成多段各可长全 | neoblast 重排（形态变异） |
| 蝾螈 | 断肢长回完整肢体 | 芽基重演肢体程序（末端再生） |
| 斑马鱼 | 心、鳍、脊髓可再 | 芽基 + 部分干细胞 |
| 哺乳动物 | 皮肤可愈合、心尖窗口期可再 | 纤维化抢先，能力被抑制 |

把这张表与第 6 节的方程连起来：再生本质上是把 $p<q$ 的衰减干细胞池**短暂扳回 $p>q$**、扩库重建，再回落 $p=q$ 稳态——「重放发育」的数学形式，就是在一段时间里人为修改 $p$ 与 $q$。

## 9 小结

- 干细胞 = **自我更新 + 多能性**；潜能递减顺序：全能 > 多能 > 多潜能 > 单能。
- 分裂三策略：**不对称 / 对称自我更新 / 对称分化**，其平衡决定干细胞池大小。
- **龛**是干细胞的定居微环境，「谁留在龛里谁就是干细胞」。
- **iPS**（山中因子 Oct4/Sox2/Klf4/c-Myc）证明分化可被重编程逆转——命运锁定是表观遗传的稳定状态。
- 再生分**形态变异**（涡虫重排）与**末端再生**（蝾螈芽基重演肢体程序）；哺乳动物再生差可能是「被抑制」而非「没能力」。
- 群体动力学 $S_{n+1}=(1+p-q)S_n$：$p=q$ 是稳态，$p>q$ 是肿瘤，$p<q$ 是耗竭。
