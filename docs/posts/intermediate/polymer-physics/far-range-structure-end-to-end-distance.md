## 为什么从链的尺寸讲起

上一课我们看清了链的「砖瓦」——重复单元、键接方式、立体构型。但高分子物理真正关心的问题是：**一整条链在空间里到底占多大、蜷成什么样？** 一条聚合度 $10^4$ 的聚乙烯链，完全伸直约有 2.5 微米长，可它在熔体里实际占据的尺寸只有伸直长度的几十分之一——因为单键在不停地**内旋转**，把链卷成一只无规的线团。

这条线团的大小不是某个固定值，而是一个**随机变量**，只能用统计语言描述。<span class="marginnote">把「链的尺寸」当成随机变量来研究，是高分子的第一次「统计革命」。它直接连接到第一级《概率论与数理统计》：一条链 = 一次随机行走（random walk），链的末端距 = 随机行走的终点位移。</span>这就是**远程结构（long-range structure）**——它不再管局部化学，而是把整条链当作一个统计对象，问它的尺寸、形状与分布。

## 1 末端距与均方末端距

设链的一端在原点，另一端的位置向量为 $\mathbf{R}$，称为**末端距向量（end-to-end vector）**。由于链不断蠕动，$\mathbf{R}$ 的方向随机摆动，**平均值 $\langle \mathbf{R} \rangle = \mathbf{0}$**——均值无法描述尺寸，于是改用**均方末端距（mean-square end-to-end distance）**：

$$\langle R^2 \rangle = \langle \mathbf{R} \cdot \mathbf{R} \rangle$$

均方末端距的平方根 $\sqrt{\langle R^2 \rangle}$ 叫**均方根末端距（root-mean-square end-to-end distance）**，是「链的有效尺寸」最常用的标尺。<span class="marginnote">为什么不用均值？因为链取向各向同性，正反两个方向抵消，$\langle R \rangle = 0$。平方后取平均则恒为正，且对链的每个构象都贡献一个正的数——这是随机行走理论的标准处理，也是「用二阶矩描述涨落」的通用思路，后续还会用于回转半径与松弛时间。</span>

## 2 四种理想链模型

「理想链」假设链段之间没有长程相互作用（自身不占体积），是链统计的起点。从粗到细，有四个递进的模型：

| 模型 | 假设 | 均方末端距 |
| --- | --- | --- |
| 自由连接链（freely jointed chain, FJC） | $n$ 段长 $l$，方向完全随机，键角无约束 | $\langle R^2 \rangle = n l^2$ |
| 自由旋转链（freely rotating chain） | 价键角 $\theta$ 固定，绕键自由旋转 | $\langle R^2 \rangle = n l^2 \frac{1-\cos\theta}{1+\cos\theta}$ |
| 受阻旋转链（hindered rotation） | 价键角固定 + 内旋转势垒（位垒角 $\phi$） | $\langle R^2 \rangle = n l^2 \frac{1-\cos\theta}{1+\cos\theta} \cdot \frac{1+\cos\phi}{1-\cos\phi}$ |
| 高斯链（Gaussian chain） | 链段取向相关随距离指数衰减 | $\langle R^2 \rangle = N b^2$ |

表中 $\theta$ 取**价键角**约定（相邻两键在同一个碳上的夹角）。对碳链 $\theta \approx 109.5°$，$\cos\theta = -1/3$，自由旋转链系数 $(1-\cos\theta)/(1+\cos\theta) = 2$，即 $\langle R^2 \rangle = 2 n l^2$——这正是文献里常见的「自由旋转链 $C_\infty = 2$」。<span class="marginnote">一个常被绕晕的约定问题：沿链的<strong>相邻键向量</strong>夹角是价键角的<strong>补角</strong>（$180°-109.5° = 70.5°$，$\cos = +1/3$）。用它写式子则得 $\langle R^2 \rangle = n l^2(1+\cos\alpha)/(1-\cos\alpha) = 2nl^2$——同一结果、两种写法，别被符号吓到。</span>

**共同点是：均方末端距都与链段数的一次方成正比**，写成一个统一的标度形式：$\langle R^2 \rangle \propto N$。<span class="marginnote">「$\langle R^2 \rangle \propto N$」是理想链的签名。这等价于随机行走的扩散定律 $\langle r^2 \rangle = 6Dt$（把链段数当作时间），所以理想链又叫「高斯链」。记住这个标度指数 $1/2$（$\sqrt{\langle R^2 \rangle} \sim N^{1/2}$），后面对比真实链的 $3/5$ 时它就是基准。</span>

**辨析｜易错点：模型间只差一个「链段有效长度」。** 从 FJC 到受阻旋转链，公式形式相同、唯数值系数不同。物理上更聪明的做法是反过来：不管微观细节，直接定义**库恩长度（Kuhn length）$b$**，使 $\langle R^2 \rangle = N_K b^2$ 恒成立。这样 $N_K$（库恩链段数）和 $b$ 就是「等效的自由连接链」，把旋转受阻等细节全部吸收进 $b$ 里。这一「粗粒化」思想将在第 5 课专门展开。

## 3 自由旋转链：从 FJC 出发的推导

为了让「$\langle R^2 \rangle$ 为什么有系数」不流于背诵，这里把自由旋转链推导一遍。链有 $n$ 个键，第 $i$ 个键向量为 $\mathbf{l}_i$，则末端距是各键向量之和：

$$\mathbf{R} = \sum_{i=1}^{n} \mathbf{l}_i$$

对均方末端距展开：

$$\langle R^2 \rangle = \left\langle \sum_i \mathbf{l}_i \cdot \sum_j \mathbf{l}_j \right\rangle = \sum_i \langle l_i^2 \rangle + 2\sum_{i<j} \langle \mathbf{l}_i \cdot \mathbf{l}_j \rangle$$

第一项给出 $n l^2$。第二项是不同键的**取向相关**：键 $j$ 相对键 $i$ 每前进一步，平均方向在夹角 $\alpha$ 下投影为 $\cos\alpha$，所以 $\langle \mathbf{l}_i \cdot \mathbf{l}_{i+k} \rangle = l^2 (\cos\alpha)^k$。对 $k$ 求和得等比级数：

$$\langle R^2 \rangle = n l^2 \left[ 1 + 2\cos\alpha + 2\cos^2\alpha + \cdots \right] = n l^2 \frac{1+\cos\alpha}{1-\cos\alpha}$$

> 注：这里的 $\alpha$ 指**相邻键向量之间的夹角**（对四面体碳链 $\alpha = 180°-109.5° = 70.5°$，$\cos\alpha = +1/3$），故系数 $(1+\cos\alpha)/(1-\cos\alpha) = 2$；与上表用价键角 $\theta=109.5°$ 的写法 $(1-\cos\theta)/(1+\cos\theta) = 2$ 是同一物理结果、两种约定。验证方法：键角越接近 $0°$（直链），系数越大，链越硬；键角越接近 $90°$，系数越接近 $1$，回到 FJC。

这个推导的价值在于：**「均方末端距」不是查表查来的，而是「逐键求和 + 取向相关衰减」的自然结果。** 当 $\cos\theta = 0$（键角 $90°$），系数回到 $1$，退化为自由连接链——FJC 不过是自由旋转链在键角 $90°$ 的特例。

## 4 回转半径：质心视角

末端距需要一个「明确的端点对」，支化链、环状链没有自然端点，于是引入更普适的**均方回转半径（mean-square radius of gyration）**：

$$\langle S^2 \rangle = \frac{1}{N}\sum_{i=1}^{N} \langle (\mathbf{r}_i - \mathbf{r}_{cm})^2 \rangle$$

其中 $\mathbf{r}_i$ 是第 $i$ 个链段的坐标，$\mathbf{r}_{cm}$ 是质心。<span class="marginnote">回转半径把「链尺寸」定义成链段对质心的均方位移——不需要端点，任何拓扑的链都能算。对理想链有 $\langle S^2 \rangle = \langle R^2 \rangle / 6$（线形链）或 $= \langle R^2 \rangle / 12$（环状链）。实验上光散射与中子散射直接给出的是 $S^2$，而非 $R^2$，所以这个量在表征中举足轻重。</span>

末端距与回转半径是「双标尺」：一个从端点看，一个从质心看，两者通过简单的比例互换算。**记住 $\langle R^2 \rangle = 6\langle S^2 \rangle$ 这个理想链关系**，实验与理论对接时它无处不在。

## 5 公式解析：均方末端距的三个层次

把这一课的核心公式汇总，按「微观→有效→测量」三层拆解：

$$
\text{FJC: } \langle R^2 \rangle = n l^2, \qquad
\text{受阻旋转: } \langle R^2 \rangle = n l^2 \frac{1-\cos\theta}{1+\cos\theta}\frac{1+\cos\phi}{1-\cos\phi}, \qquad
\text{Kuhn: } \langle R^2 \rangle = N_K b^2
$$

- **第一层（微观几何）**：$n$ 是真实键数，$l$ 是键长（C—C 键约 0.154 nm），$\theta$ 是键角（C 链约 $109.5°$）。这一层把化学结构翻译成几何参数。
- **第二层（旋转受阻）**：$\phi$ 是内旋转位垒角。取代基越大，$\phi$ 偏离 $180°$ 越远，链越刚硬，系数越大。这一层是「近程结构影响远程尺寸」的定量接口。
- **第三层（等效粗粒化）**：$N_K = n / n_0$、$b = n_0 l \sqrt{\cdots}$，把前两层的全部细节折叠成**一个**有效参数 $b$。这一层是连接理论与实验的关键——任何真实链都能用「库恩链段数 + 库恩长度」表示。

三层是同一个物理对象的三级分辨率：**看得越细，参数越多；看得越粗，参数越少越普适。** 这种「分辨率换普适性」的取舍，就是高分子物理最核心的方法论——标度与粗粒化，下一课我们将正式踏入它。

### 从链尺寸到实验测量

理论给出了 $\langle R^2 \rangle$ 与 $\langle S^2 \rangle$，实验怎么「看见」它们？三条互补的路线：

**光散射**：溶液中链的散射强度在散射角趋于零时给出重均分子量，而散射强度对角度的依赖（Zimm 图的斜率）直接给出**均方回转半径 $\langle S^2 \rangle$**。这是测链尺寸的主力方法，测得的是 $S^2$ 而非 $R^2$——所以理论里必须备好 $R^2 = 6S^2$ 的换算。

**小角中子散射（SANS）**：用氘代标记单条链，在熔体/浓溶液中直接测出单链的 $\langle S^2 \rangle$。正是 SANS 在 1980 年代证实了「熔体里链就是无规线团」——这是《非晶态结构》一课的实验基石。

**黏度法**：特性黏度 $[\eta] = K M^a$ 与链的流体力学体积相关，间接反映链尺寸；Mark–Houwink 指数 $a$ 本身就是溶剂质量的标尺（$\theta$ 溶剂 $a = 0.5$，良溶剂 $a \approx 0.8$）。

三者的尺度视角一致：**散射直接给 $S^2$，黏度间接给流体力学半径，理论则提供两者之间的桥梁**——把「链蜷多大」这个抽象问题变成可测、可对比的物理量。

### 链尺寸与其他尺度的对照

把链尺寸放进「长度标尺图」里，就明白为什么链尺寸是高分子的核心量：

| 尺度 | 典型长度 | 对象 |
| --- | --- | --- |
| 键长 | 0.15 nm | C—C 键 |
| 链段间距离 | 0.5 nm | 非晶态近邻 |
| 库恩段 | 1–2 nm | 等效链段 |
| 线团尺寸 | 10–100 nm | 整条链 |
| 球晶/相区 | 0.1–100 μm | 超结构 |

**链尺寸（10–100 nm）正好落在「原子尺度」与「光学尺度」之间**——这个位置让它成为聚合物物理的枢纽：链比原子大得多（统计有效），又比光波长小（不可见、可穿透）。光散射能测它，是因为散射在 $qR_g \sim 1$ 时对链尺寸敏感——**「恰好落在可测区间」是链尺寸成为表征核心的原因之一**。

**链尺寸决定什么**：线团体积决定溶液黏度与交叠浓度（第 8 课）、缠结密度（第 11 课）、扩散系数（$D \sim 1/R$）——**尺寸是链的「第一性状」**，一切依赖链大小的性质都从这里出发。

**辨析｜易错点：$\sqrt{\langle R^2 \rangle}$ 不是链的「直径」。** 它是均方末端距的平方根，是**统计涨落尺度**，不是链占用的实际空间直径。线团内部链段密度远低于「把链当实心球」的假设——链是「稀疏的线团」，链段体积分数只有几个百分点。**「线团」是统计对象，不是实心球**——这个误读会连锁影响对缠结、交叠的理解。

## 6 小结

- 远程结构把整条链当作统计对象，用**均方末端距 $\langle R^2 \rangle$** 与**均方回转半径 $\langle S^2 \rangle$** 描述链尺寸。
- 末端距向量均值 $\langle \mathbf{R} \rangle = \mathbf{0}$，必须用二阶矩 $\langle R^2 \rangle$ 描述尺寸；理想链满足 $\langle R^2 \rangle \propto N$，标度指数 $1/2$。
- 四种理想链模型（自由连接、自由旋转、受阻旋转、高斯）共享同一结构，差异浓缩为一个有效长度；**库恩长度 $b$ 把一切微观细节粗粒化为一个参数**。
- 回转半径不需要端点，适合任意拓扑；理想线形链满足 $\langle R^2 \rangle = 6 \langle S^2 \rangle$
