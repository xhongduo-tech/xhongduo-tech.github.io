## 为什么从黏弹性讲起

上一课的橡胶是理想弹性体：力一加就变形，力一撤就复原，与时间无关。但真实高分子材料从不这么干脆。**把它拉一下然后固定住，你会发现应力随时间慢慢衰减（应力松弛）；加一个恒力，它会持续慢慢变形（蠕变）。** 这种「既像固体又像液体」的响应，就是**黏弹性（viscoelasticity）**。<span class="marginnote">黏弹性的根源是链的松弛时间谱：链段、整链各有不同的松弛时间，从纳秒到数小时不等。观察时间短，链来不及动，材料像固体；观察时间长，链充分松弛，材料像液体。<strong>同一个材料，快看是固体、慢看是液体</strong>——这是高分子最本质的时间哲学。</span>

这一课建立线性黏弹性的基本语言：松弛模量、蠕变柔量、Maxwell 与 Voigt 模型、玻尔兹曼叠加原理。它们是小应变（线性区）下描述聚合物响应一切的起点。

## 1 两大基本实验：应力松弛与蠕变

线性黏弹性由两个互相对偶的实验定义：

**应力松弛（stress relaxation）**：瞬间给一个固定应变 $\gamma_0$ 并保持，测应力随时间衰减。定义**松弛模量（relaxation modulus）**：

$$G(t) = \frac{\sigma(t)}{\gamma_0}$$

**蠕变（creep）**：瞬间施加恒定应力 $\sigma_0$，测应变随时间增长。定义**蠕变柔量（creep compliance）**：

$$J(t) = \frac{\gamma(t)}{\sigma_0}$$

$G(t)$ 与 $J(t)$ 是同一物理的两个侧面，且满足卷积关系（$G * J = 1$ 在拉普拉斯域意义下）。<span class="marginnote">松弛模量是「应变固定，看应力怎么泄」；蠕变柔量是「应力固定，看应变怎么涨」。两者由 Boltzmann 叠加原理互推。工程上：垫圈用应力松弛（压住不动会不会漏），轴承用蠕变（恒载下会不会越陷越深）。<strong>测哪一个，取决于应用问的是哪一边。</strong></span>

对聚合物熔体/缠结体系，$G(t)$ 的典型形状是：极短时间玻璃平台 → 过渡区 → 缠结平台 → 最终塌向零（流动）。$G(t)$ 曲线是聚合物动力学的「指纹」。

## 2 理想化模型：弹簧与黏壶

线性黏弹性用两个基本元件组合：

**弹簧（Hookean）**：$\sigma = G\gamma$，瞬时响应，无时间依赖。
**黏壶（Newtonian dashpot）**：$\sigma = \eta \dot{\gamma}$，应力正比于应变速率，纯耗散。

两种最基本的组合：

**Maxwell 模型（弹簧+黏壶串联）**：本构方程与松弛模量：

$$\dot{\gamma} = \frac{\dot{\sigma}}{G} + \frac{\sigma}{\eta}, \qquad G(t) = G_0\, e^{-t/\tau}, \qquad \tau = \frac{\eta}{G_0}$$

Maxwell 模型描述**应力松弛**：应变固定后，弹簧的应力逐渐被黏壶「泄掉」，指数衰减，松弛时间 $\tau = \eta/G_0$。它是流体型黏弹性（熔体、溶液）的骨架。<span class="marginnote">Maxwell 模型像「弹簧拉着黏壶」：你拉弹簧，黏壶慢慢跟着走，弹簧的张力被黏壶的位移逐渐卸掉。松弛时间 $\tau = \eta/G_0$ 是「黏性泄掉弹性」的特征时间——黏度越大、弹簧越软，松弛越慢。</span>

**Voigt/Kelvin 模型（弹簧+黏壶并联）**：描述**蠕变**：

$$J(t) = J_0\left(1 - e^{-t/\tau}\right), \qquad \tau = \eta J_0$$

Voigt 模型下应变从零渐近增长到平衡值 $J_0\sigma_0$，描述蠕变回复（撤力后缓慢弹回）。它是固体型黏弹性的骨架。

## 3 标准线性固体与松弛谱

单个 Maxwell 或 Voigt 模型都只有**一个**松弛时间，无法描述真实聚合物横跨十几个数量级的松弛谱。**标准线性固体（standard linear solid）** 用一个弹簧并联一个 Maxwell 单元，能同时给出瞬态弹性、松弛与终态弹性，但它仍只有一个 $\tau$。

真实聚合物需要**连续的松弛时间分布**。把松弛模量写成谱形式：

$$G(t) = G_e + \int_{-\infty}^{\infty} H(\tau)\, e^{-t/\tau}\, d\ln\tau$$

$H(\tau)$ 是**松弛谱（relaxation spectrum）**，$G_e$ 是平衡模量（交联网络不为零，熔体为零）。<span class="marginnote">「用一大排 Maxwell 单元并联」来逼近真实材料，就是松弛谱的物理图像：每个单元有自己的 $\tau$ 和权重 $H(\tau)d\ln\tau$，叠加出总响应。这像把一段音乐分解成不同频率的音符——松弛谱就是聚合物动力学的「频谱」。对数时间的宽峰对应从链段到整链的各级运动模式。</span>

## 4 Boltzmann 叠加原理：线性响应的万能钥匙

线性黏弹性最重要的工具是 **Boltzmann 叠加原理**：**每个应力脉冲独立贡献，总响应是它们的线性叠加。** 对任意应变历史 $\gamma(t)$：

$$\sigma(t) = \int_{-\infty}^{t} G(t - t')\, \frac{d\gamma(t')}{dt'}\, dt'$$

同理，蠕变柔量通过 $J(t)$ 叠加任意应力历史。这条式子的物理含义：**材料在 t 时刻的应力，是过去每一个应变增量乘以「它还记得多少」（松弛模量）的积分**——$G(t-t')$ 就是记忆函数。<span class="marginnote">Boltzmann 叠加把「任意加载历史的响应」全部归结为一个函数 $G(t)$：测出 $G(t)$（一次实验），就能预测任何加载程序下的响应。这正是线性时不变系统的思想——第二级《信号与系统》里的卷积、脉冲响应、叠加原理，在这里原封不动地重现。<strong>物理与工程信号理论共用同一套数学。</strong></span>

**辨析｜易错点：Boltzmann 叠加只在线性区成立。** 它要求响应与应力/应变成正比、且历史效应可加。大应变下（非线性黏弹性，第 23 课）叠加原理失效——不能用 $G(t)$ 的卷积预测剪切变稀等行为。**「先用线性模型，再标注失效边界」是黏弹性学习的基本姿态。**

## 5 公式解析：Maxwell 模型的松弛模量

把 Maxwell 模型推一遍，它是理解一切松弛的起点：

$$
G(t) = G_0\, e^{-t/\tau}, \qquad \tau = \frac{\eta}{G_0}
$$

- **第一步，本构**：$\dot{\gamma} = \dot{\sigma}/G + \sigma/\eta$。应变速率 = 弹簧的（$\dot{\sigma}/G$）+ 黏壶的（$\sigma/\eta$）。
- **第二步，应力松弛**：固定 $\gamma$（$\dot{\gamma} = 0$），方程化为 $\dot{\sigma}/G = -\sigma/\eta$，解出 $\sigma(t) = \sigma_0 e^{-Gt/\eta}$。除以 $\gamma_0$ 即 $G(t) = G_0 e^{-t/\tau}$。
- **第三步，读松弛时间**：$\tau = \eta/G_0$。$t \ll \tau$：$G(t) \approx G_0$，材料像固体；$t \gg \tau$：$G(t) \to 0$，材料像液体。**$\tau$ 就是「固体感」与「液体感」的分界线。**<span class="marginnote">这就引出 <strong>Deborah 数</strong> $De = \tau/t_{\text{obs}}$：松弛时间与观察时间的比值。$De \gg 1$ 是固体（来不及松弛），$De \ll 1$ 是液体（充分松弛）。「快看是固体、慢看是液体」的定量表述就是 $De$。同一条聚合物，$De$ 跨过 1 就从「硬」变「软」——时间尺度是黏弹性的一切。</span>

### 从 G(t) 读出分子结构

松弛模量 $G(t)$ 不只是理论概念——它是聚合物分子结构的「流变指纹」，曲线上的每个区段对应一种运动模式：

| 时间区段 | $G(t)$ 行为 | 对应的分子运动 |
| --- | --- | --- |
| 极短时 | 玻璃平台（约 1 GPa） | 键长键角振动、链段局部运动 |
| 过渡区 | 快速下降 | 链段松弛（$T_g$ 附近的 $\alpha$ 松弛） |
| 缠结平台 | 平台 $G_N^0$ | 缠结约束，整链还没解开 |
| 长时 | 塌向零（熔体）或保留 $G_e$（交联） | 整链蛇行脱出（熔体）或网络限制（交联） |

**读图的实用技巧**：缠结平台的高度给 $M_e$（$G_N^0 = \rho RT/M_e$）；平台的宽度随分子量增加（链越长越晚才整体流动）；交联体系的长时平台 $G_e$ 给交联密度（$G_e = \rho RT/M_c$）。**一张 $G(t)$ 曲线，同时读出缠结与交联**——这就是流变学被称为「聚合物最灵敏的探针」的原因。

**分子量分布的影响**：分布宽时 $G(t)$ 的过渡区变宽、平台区变得不那么平坦——因为不同链长的松弛时间混叠。**$G(t)$ 曲线形状与 MWD 的关系，是「从流变反推分子量分布」这一工业级技术的基础。**

**辨析｜易错点：$G(t)$ 的「平台」不是平衡态。** 缠结平台是**动力学冻结**的临时平台：链还没机会蛇行脱出，所以看起来像固体，时间足够长就塌了。它与交联网络的平衡平台本质不同——**一个会消失（缠结），一个不消失（交联）**。实验中用「平台是否随测量时间消失」区分缠结与交联，是流变学的标准操作。

### 黏弹性的无处不在：日常与工业

黏弹性不是实验室的抽象——它塑造了塑料制品的日常行为：

**蠕变与松驰的日常**：PVC 水管架在支架上久了会弯曲（蠕变）；螺丝拧紧的塑料件过段时间变松（应力松弛）；老化的 O 形圈失去密封力（长期松弛）。**「塑料件松了、弯了、漏了」，大半是黏弹性在作祟**——设计者必须在选材时就计入长期蠕变。

**加工里的黏弹性**：注塑充模靠剪切流动（黏性），脱模后的回弹与翘曲靠弹性记忆（弹性）。**熔体的「黏」决定能不能流动，「弹」决定成型后会不会变形**——流变学是模具设计的科学基础。

**减振与隔音**：高 $\tan\delta$ 的黏弹性材料（橡胶、阻尼胶）把振动能量耗散成热。汽车底盘、桥梁支座、精密仪器底座全靠「损耗」吸振。**「损耗」在结构里是缺点（能量浪费），在减振里是功能（能量吸收）**——同一物理，两副面孔。

**食品与生物**：面团是黏弹性体（拉面靠弹性、成型靠黏性），唾液、黏液是黏弹性液体，血液在微血管里也呈现黏弹性。**从轮胎到面团、从血管到耳机，黏弹性是「介于固液之间」材料的通用语言。**

## 6 小结

- 黏弹性 = 固体弹性 + 液体黏性的融合；**应力松弛**（$G(t)$）与**蠕变**（$J(t)$）是两大基本实验。
- **Maxwell 模型**（弹簧+黏壶串联）：$G(t) = G_0 e^{-t/\tau}$，$\tau = \eta/G_0$，描述流体的应力松弛。
- **Voigt 模型**（并联）：$J(t) = J_0(1-e^{-t/\tau})$，描述固体的蠕变与回复。
- 真实聚合物需要**松弛谱** $H(\tau)$：连续分布的一排 Maxwell 单元叠加。
- **Boltzmann 叠加原理** $\sigma(t) = \int G(t-t')\dot\gamma(t')dt'$：线性响应下，测一个 $G(t)$ 预测一切加载历史；**只在线性区有效**。
- **Deborah 数** $De = \tau/t_{\text{obs}}$
