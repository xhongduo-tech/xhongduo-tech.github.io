# 时温等效与 WLF 方程

<div class="epigraph">

## 为什么从时温等效讲起

上一课的黏弹性告诉我们要看松弛时间谱，但松弛谱横跨十几个数量级——没有任何一台仪器能直接覆盖。聚合物力学最大的工程难题是：**你没法在实验室里等上一万年去测一条室温下的十年蠕变。**<span class="marginnote">时温等效（time-temperature superposition, TTS）解决了这个问题：聚合物在低温下「动得慢」与在高温下「动得快」之间存在精确的对应——<strong>把不同温度下测到的短时数据平移，就能拼出覆盖十几个数量级的主曲线</strong>。这是一条纯经验却威力无穷的规律。</span>

TTS 的理论根基是：**聚合物的全部松弛时间都按同一个因子随温度变化**——温度改变只是把整个松弛谱「整体平移」，不改变它的形状。这一课我们学会怎么平移、为什么能平移、以及 WLF 方程如何定量描述平移量。

## 1 平移因子：时间与温度的兑换率

假设在温度 $T$ 下测得了松弛模量 $G(t, T)$。时温等效假设存在一个**平移因子（shift factor）$a_T$**，使不同温度的数据沿对数时间轴平移后重叠：

$$G(t, T) = G(t/a_T, T_0)$$

$a_T$ 是「以参考温度 $T_0$ 为标准，温度 $T$ 下的时间被拉伸/压缩的倍数」。$a_T > 1$ 表示 $T$ 下的松弛比 $T_0$ 慢（低温），$a_T \lt  1$ 表示更快（高温）。<span class="marginnote">直觉：低温 = 时间轴被拉长。$T_0$ 下 1 秒完成的松弛，在更低温 $T$ 下要 $a_T$ 秒（$a_T>1$）。所以把 $T$ 温度的数据点沿对数时间轴<strong>右移</strong> $\log a_T$，就和 $T_0$ 的数据重合。<strong>测一堆短时曲线 → 各自平移 → 拼成一条超长主曲线</strong>，这就是 TTS 的全部操作。</span>

**物理前提**：所有松弛模式的活化能/温度依赖必须相同（「单一机理」）。对大多数无定形聚合物在 $T_g$ 附近成立；但对含多个独立松弛机理的体系（如某些结晶、多相体系）会失效。

## 2 主曲线：把一万年装进实验室

操作流程：

1. 在多个温度下测短时（或高频）的 $G(t)$ 或 $G'(\omega)$。
2. 选参考温度 $T_0$，把各温度曲线沿对数时间/频率轴平移。
3. 平移到重叠最好的位置，读出各温度的 $\log a_T$。
4. 拼成的完整曲线叫**主曲线（master curve）**，覆盖可能十几个数量级。

主曲线能「看到」什么：从玻璃平台（短时）到过渡区、再到缠结平台、最后到流动区（长时）——如果单点测量，这些区域分散在 $10^{-12}$ 到 $10^8$ 秒，实验根本测不全；TTS 把它们全部拼齐。<span class="marginnote">主曲线的工程意义：<strong>预测长期行为</strong>。室温下要等 10 年的蠕变，等效于在 $T_0 + 50$ °C 下等几分钟。垫片、密封圈、承重塑料件的长期变形，都用 TTS 从加速实验外推。<strong>「用高温换时间」是高分子材料寿命预测的通用手段</strong>——但外推必须落在 WLF 有效区内（见下）。</span>

**辨析｜易错点：TTS 不是「万能外推器」。** TTS 假设形状不变、只是平移。当温度穿越 $T_g$ 或 $T_g+100$ °C 边界、发生结晶/老化/相变时，松弛谱形状改变，TTS 失效。**外推范围必须限制在「无结构变化、单一松弛机理」的温度窗口内。**

## 3 WLF 方程：平移量的定量公式

平移因子 $a_T$ 的温度依赖由 **WLF 方程（Williams–Landel–Ferry）** 描述：

$$\log a_T = -\frac{C_1 (T - T_0)}{C_2 + (T - T_0)}$$

以 $T_g$ 为参考（$T_0 = T_g$），大量无定形聚合物的常数惊人地接近普适值：$C_1 = 17.44$，$C_2 = 51.6$（温度用 K 或 °C，差值不变）。<span class="marginnote">$C_1 = 17.44$、$C_2 = 51.6$ 被称为「准普适常数」：$T_g$ 附近几乎所有无定形聚合物都服从同一组数。这是 WLF 方程最神奇之处——不同化学的聚合物，$T_g$ 归一化后行为几乎相同。<strong>普适性（universality）再次登场</strong>：$T_g$ 标度抹去了化学差异，像前面链统计的普适指数一样。</span>

WLF 方程的应用范围：$T_g \lt  T \lt  T_g + 100$ °C（约）。超出这个区间，$\log a_T$ 对 $1/T$ 的 Arrhenius 行为更适用：

$$\log a_T = \frac{E_a}{2.303 R}\left(\frac{1}{T} - \frac{1}{T_0}\right)$$

**低温侧（$T \lt  T_g$）链段几乎冻结、松弛机理改变；高温侧（$T > T_g + 100$ °C）进入简单激活区。** 两个区间用不同公式，别混用。

## 4 公式解析：从自由体积导出 WLF

WLF 不是纯经验——它可以从自由体积理论严格导出。拆成三步：

$$
\log a_T = -\frac{B}{2.303\, f_0}\,\frac{T - T_0}{f_0/\alpha_f + (T - T_0)} = -\frac{C_1(T-T_0)}{C_2 + (T-T_0)}
$$

- **第一步，黏度与自由体积**：Doolittle 方程 $\eta = A\exp(B/f)$，$f$ 是自由体积分数，$B \approx 1$。自由体积分数随温度线性增加：$f = f_0 + \alpha_f(T - T_0)$，$\alpha_f$ 是自由体积膨胀系数。
- **第二步，平移因子 = 黏度比**：$a_T = \eta(T)/\eta(T_0)$。把 Doolittle 代进去，取对数、相减，整理成 $\log a_T = -(B/2.303)(1/f - 1/f_0)$。
- **第三步，凑成 WLF 形状**：代入 $f = f_0 + \alpha_f\Delta T$，化简得 $C_1 = B/(2.303 f_0)$、$C_2 = f_0/\alpha_f$。用实验值 $f_0 \approx 0.025$（$T_g$ 处自由体积分数）与 $\alpha_f \approx 4.8 \times 10^{-4}$/K 代进去，正好得到 $C_1 \approx 17.4$、$C_2 \approx 52$——**WLF 常数从自由体积理论「算」出来了。**<span class="marginnote">这个推导是高分子物理的杰作之一：一个纯经验方程，被自由体积概念从第一性原理解释，还顺手给出 $T_g$ 处自由体积约 2.5% 的著名数字。它把 $T_g$、自由体积、黏度、时温等效串成一条逻辑链——<strong>第 14 课《玻璃化转变》的自由体积理论在这里开花结果。</strong></span>

### TTS 的操作细节与失效判据

把 TTS 用好，关键在于知道「怎么移」和「何时不能移」：

**水平平移 vs 垂直平移**：主要靠水平平移 $\log a_T$。但模量本身也随温度小幅变化（密度与熵弹性的温度依赖），需要额外的垂直平移因子 $b_T = \rho T/\rho_0 T_0$。**先水平、再垂直修正**，主曲线的质量看重叠是否光滑。

**参考温度的选择**：工程上常取 $T_0 = T_g$（用普适常数 $C_1, C_2$）或取使用温度（直接得到使用温度下的行为）。换参考温度时，WLF 常数要换算——**$C_1, C_2$ 绑定参考温度，不能拿来就用**。

**失效判据：何时不能平移**。TTS 假设「全部松弛时间同因子变化」，下列情况直接失效：

| 失效情形 | 原因 |
| --- | --- |
| 穿越 $T_g$ | 玻璃态与橡胶态机理不同 |
| 结晶/熔融 | 结构随温度改变 |
| 物理老化 | 松弛谱随时间演化 |
| 多相/多机理 | 各组分的温度依赖不同 |
| 增塑剂迁移 | 组成随温度变化 |

<span class="marginnote">判断 TTS 是否有效，最直接的标准是<strong>重合质量</strong>：各温度曲线能否平滑拼成一条主曲线，以及平移因子是否单调光滑地随温度变化。若出现「拼不拢、台阶状」，就是失效信号——<strong>别强行平移，先质疑模型假设</strong>。</span>

**辨析｜易错点：TTS 的外推有「期限」。** 主曲线把室温行为外推到 $10^{10}$ 秒（几百年），但那是「假设材料不变」的数学外推。真实材料会老化、降解，**外推窗口再长，也不等于材料真的能撑那么久**。寿命预测要把 TTS 外推与长期老化实验交叉验证。

### 从 WLF 到活化能：两种语言

TTS 的平移因子可以用两种语言描述——WLF（$T_g$ 附近）与 Arrhenius（高温区），它们对「材料有多怕冷」给出了不同的度量：

**WLF 语言**：$\log a_T = -C_1(T-T_0)/(C_2+T-T_0)$，在 $T_g$ 附近非常准，但**没有单一的活化能**——有效活化能随温度变化（越接近 $T_g$ 越大）。这反映了链段协同运动的本质：接近冻结时，运动越来越「集体」，不是单一能垒能描述的。

**Arrhenius 语言**：$\log a_T = (E_a/2.303R)(1/T - 1/T_0)$，给出恒定活化能 $E_a$。在 $T > T_g + 100$ °C 时适用，此时链段运动已足够快、近似单分子过程。

**「脆与强」玻璃形成体的判据**：D 值（$D = B/T_0$，Angell 图的参数）衡量松弛时间随温度变化的陡峭程度。强玻璃形成体（如 SiO₂）D 大、接近 Arrhenius；脆玻璃形成体（多数聚合物）D 小、强烈偏离 Arrhenius。<span class="marginnote">Angell 图（$\log\tau$ 对 $T_g/T$）把玻璃形成体分成「强」与「脆」两类，是玻璃物理的核心工具。聚合物多为脆玻璃形成体——它们的 $\log\tau$ 在 $T_g/T \to 1$ 时急剧上翘。<strong>「越接近 $T_g$ 越怕冷」是脆玻璃的签名</strong>，也是 WLF 方程存在的理由。</span>

**辨析｜易错点：WLF 的「普适常数」不是物理常数。** $C_1 = 17.44$、$C_2 = 51.6$ 是「大量聚合物在 $T_g$ 参考下的统计平均值」，不是每个材料都精确如此。严格做法是**实测每个材料的 $C_1$、$C_2$**（测多条等温曲线、拟合平移因子）。「普适常数」是方便第一估，不是精确值——工程上用它做初筛，精算要实测。

**从经验到机制**：TTS 与 WLF 最初是纯经验规律，但它能成立的深层原因是**链段运动的协同性**：温度降低，运动区域变大、需要更多链段协同才能移动，于是有效活化能随温度上升——这正是「脆玻璃」的动力学本质，也是 VFT/WLF 非阿伦尼乌斯行为的微观解释。**「经验方程 + 微观机制」的配对**，是高分子物理反复出现的模式：先有数据规律（WLF），后有理论解释（协同运动/自由体积）。理解这一模式，比记住任何一个方程都重要——它告诉你怎么在文献里区分「工程经验」与「第一性原理」。

**这一课在整个黏弹性篇的位置**：线性黏弹性（第 20 课）给「松弛模量」的语言，动态力学（第 22 课）给「频域测量」的工具，而 TTS 与 WLF（本课）给「把时间轴无限延长」的钥匙——三者合起来，才构成「测一小段数据、拼出完整松弛谱、外推任意时间尺度」的完整能力。**学黏弹性，缺了 TTS 就像有相机没有长焦镜头**——只能拍眼前，拍不了远处。下一课把镜头对准「振荡」：在频域里同时读出储能与损耗，那就是动态力学性能。

**一句收束**：时温等效是「用一个维度换另一个维度」的典范——**用温度换时间**。这种「维度兑换」的思维，在物理里反复出现：用压力换体积（状态方程）、用频率换温度（Arrhenius）、用位移换动量（傅里叶）。理解 TTS，不只是记住一条公式，而是学会「当某个维度测不全时，找它的对偶维度」——这是工程与理论共同的方法论财富。

## 5 小结

- **时温等效（TTS）**：温度改变只整体平移松弛谱，不改变形状；$G(t,T) = G(t/a_T, T_0)$。
- **平移因子 $a_T$** 是时间-温度的兑换率；**主曲线**把不同温度的短时数据拼成覆盖十几个数量级的完整曲线。
- **WLF 方程** $\log a_T = -C_1(T-T_0)/(C_2 + T-T_0)$，$T_0 = T_g$ 时 $C_1 = 17.44$、$C_2 = 51.6$（准普适）。
- 适用范围 $T_g \lt  T \lt  T_g + 100$ °C；超出用 **Arrhenius 方程**。
- WLF 可由**自由体积理论**导出：$C_1 = B/(2.303f_0)$、$C_2 = f_0/\alpha_f$，$T_g$ 处 $f_0 \approx 0.025$。
- TTS 失效边界：穿越 $T_g$
