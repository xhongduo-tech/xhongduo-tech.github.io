# 边着色

## 为什么从边着色开始

顶点着色给「点」涂色，边着色给「边」涂色：**共享同一个端点的边必须异色**。
它看起来只是着色的「对偶版本」，却自有截然不同的命运——顶点色数在一般图上无简单公式，
而**边色数**被 Vizing 定理精确锁定在 $\Delta$ 与 $\Delta+1$ 两个值之一。
<span class="marginnote">边着色的现实意义巨大：给每场比赛安排一个时段（同队不能同时赛两场）、给每个数据链路分配一个波长（共享端口的链路不能同波长）、排课表（同一教师同一时间只能上一门课）。
「边着色 = 时分复用」是对偶图着色的工程化。
</span>这一节建立边着色理论，并揭示它与因子分解的深刻联系。

## 1 边着色与边色数

**正常边着色（proper edge coloring）**：
给每条边涂一种颜色，使得**共享端点的边颜色不同**。
<span class="marginnote">与顶点着色不同，
约束对象是「共享端点」而非「相邻」。一个顶点处所有边都必须异色，
所以该顶点需要至少 $\deg(v)$ 种颜色——这正是下界 $\chi'(G) \ge \Delta(G)$ 的来源：
最大度顶点处要用掉 $\Delta$ 种颜色。
</span>

**边色数（edge chromatic number）**：
$\chi'(G)$ 是正常边着色所需的最少颜色数。
基本下界：

$$
\chi'(G) \ge \Delta(G)
$$

因为最大度顶点有 $\Delta$ 条边，它们两两共享端点，
必须全异色。

## 2 Vizing 定理：两难之境

**Vizing 定理（1964）**：对任何简单图 $G$，

$$
\Delta(G) \le \chi'(G) \le \Delta(G) + 1
$$

边色数只能是 $\Delta$ 或 $\Delta+1$，
**没有第三种可能**。
<span class="marginnote">这个「两值定理」在组合优化里极其罕见——大多数问题的最优值范围都宽到无边。
Vizing 定理把搜索范围压缩成两个候选，
但它并没有告诉你每个图是哪个值；
判定「某图边色数是否为 $\Delta$」仍是 NP 完全问题。
</span>

根据落在哪个值，图被分为两类：

- **第一类图（Class 1）**：$\chi'(G) = \Delta$（「正好够用」）。
- **第二类图（Class 2）**：$\chi'(G) = \Delta + 1$（「多一色才够」）。

完全图分类：$K_{2n}$ 是第一类（$\chi' = 2n-1 = \Delta$，
见因子分解一节），$K_{2n+1}$ 是第二类（$\chi' = 2n+1 = \Delta+1$）。

## 3 König 定理：二部图永远是第一类

**König 边着色定理（1916）**：
若 $G$ 是二部图，则

$$
\chi'(G) = \Delta(G)
$$

二部图的边色数**恰好等于最大度**，永远属于第一类。
<span class="marginnote">König 定理是「匹配理论 → 边着色」的直接桥：边着色等价于把边集划分成若干匹配（每种颜色的边构成一个匹配）。
而二部图的 1-因子分解（《因子分解》一节）保证它能被 $\Delta$ 个匹配覆盖——这就是 $\chi' = \Delta$ 的匹配语言。
</span>

证明思想：对二部图用「增广路径」逐步把 $\Delta$-可着色扩展到全部边；
关键在于二部图无奇圈，交替路不会死锁。

**关键联系：边着色 = 匹配划分**。正常边着色的每种颜色类边集是一个匹配（共享端点异色 ⇔ 同一颜色的边不共享端点）。
所以：

$$
\chi'(G) = \text{把 } E(G) \text{ 划分成匹配所需的最少匹配数}
$$

这与《因子分解》里「1-因子分解」视角完全一致：
$\chi' = \Delta$ 意味着边集能拆成 $\Delta$ 个匹配（每个顶点处被 $\Delta$ 个匹配「轮流用一次」）。
<span class="marginnote">于是边着色、匹配、因子分解三者在二部图上完全同义：$K_{2n}$ 的循环赛程表（1-因子分解）就是用 $2n-1$ 种颜色给 $\binom{2n}{2}$ 条边着色的一个具体实例。
</span>

## 4 公式解析：为什么 $\chi' = \Delta$ 是最优中的最优

**边着色下界 $\Delta$ 是「最大度顶点的局部需求」，而二部图恰能全局满足它。** 设二部图最大度为 $\Delta$，
边集 $E$：

$$
\chi'(G) \ge \Delta \quad \text{（局部下界）},\qquad \chi'(G) \le \Delta \quad \text{（König 可构造）}
$$

三步拆解：

- **第一步，下界**：最大度顶点 $v$ 的 $\Delta$ 条边全部共享 $v$，必须 $\Delta$ 种颜色，故 $\chi' \ge \Delta$。
- **第二步，构造上界**：König 定理的证明从 $\Delta$-1 可着色的子图出发，用增广交替路径把颜色缺口的边「补染」进去，始终保持 ≤ $\Delta$ 色。
核心是二部图无奇圈，交替路径永不绕回冲突。
- **第三步，夹逼**：下界 = 上界 = $\Delta$，故 $\chi'(G) = \Delta$。

这个「下界来自局部、上界来自构造」的双夹结构是极值图论的标准姿势：
**找到局部必然需求，再证明全局能恰好供给。**

## 5 辨析｜易错点：边色数 vs 顶点色数的差别

| 维度 | 顶点色数 $\chi$ | 边色数 $\chi'$ |
| --- | --- | --- |
| 约束 | 相邻顶点异色 | 共享端点异色 |
| 上界 | 无统一公式（NP 完全） | Vizing：$\chi' \le \Delta+1$ |
| 二部图 | $\chi = 2$ | $\chi' = \Delta$ |
| 与匹配关系 | 每种颜色是独立集 | 每种颜色是匹配 |
| 计算难度 | NP 完全 | 判定是否 $\Delta$ 是 NP 完全，但区间已知 |

**辨析｜易错点：$\chi'(K_{2n+1}) = \Delta+1$ 需要理由。**
$K_{2n+1}$ 有奇数个顶点，完美匹配不存在（1-因子不存在），
所以边集无法拆成 $2n$ 个完美匹配覆盖全部边；
任何边着色要盖住 $2n+1$ 个顶点上「每点度 $2n$」的需求，
$\Delta$ 种颜色不够，必须 $\Delta+1$。

## 6 小结

- **正常边着色**：共享端点异色；
**边色数** $\chi'(G) \ge \Delta$。
- **Vizing 定理**：$\Delta \le \chi'(G) \le \Delta+1$——只有两种可能，分**第一类 / 第二类**图。
- **König 定理**：二部图 $\chi'(G) = \Delta$，永远第一类。
- **边着色 = 匹配划分**：每种颜色是匹配，与因子分解同源；
$K_{2n}$ 的 1-因子分解就是 $2n-1$ 色边着色。
- 判定「是否为第一类」仍 NP 完全，但候选区间被 Vizing 钉死。

在下一节，我们终于要面对那个「只要四色」的世纪猜想：
四色定理——从 1852 年被提出到 1976 年首次计算机辅助证明，
它如何改写数学证明的定义。
