# 哈密顿图判定条件

<div class="epigraph">
<p>一张图只要足够「密」，就必然走得出环游世界的路线——问题是密到什么程度才够。</p>
<footer>—— 加布里埃尔 · 狄拉克（Gabriel Dirac，1962）</footer>
</div>

<div class="article-byline">
<p>第二级 · 图论 ｜ 邦迪《Graph Theory》第 7 章 §7.2 ｜ 2026-08-07</p>
</div>

## 为什么从判定条件开始

哈密顿问题没有简洁的充要条件，但有**充分条件**：
当图「足够密」「足够均匀」时，哈密顿回路一定存在。
这类定理的回答方式很实用——与其穷举所有回路，
不如检查几个容易计算的度数条件。
1962 年狄拉克给出最著名的一条：最小度 ≥ $n/2$ 就够；
1960 年奥勒（Ore）把它推广到「任何不相邻顶点度数之和 ≥ $n$」。
<span class="marginnote">这类「密度 → 结构」的充分条件是极值图论（本专题第五篇）的前奏：Turán 定理、拉姆齐理论都回答「图要密到什么程度才必然出现某种子结构」。
判定条件本质上是极值思想的先驱。
</span>这一节推导并证明 Ore 定理，再导出 Dirac 定理。

## 1 Dirac 定理

**Dirac 定理（1952）**：设 $G$ 是 $n \ge 3$ 个顶点的简单图。
若

$$
\delta(G) \ge \frac{n}{2}
$$

则 $G$ 是哈密顿图（含有哈密顿回路）。
<span class="marginnote">门槛 $n/2$ 是「恰到好处」的：$K_{n/2-1, n/2+1}$（完全二部图）的最小度只有 $n/2 - 1$，且不是哈密顿图——它左右两组顶点数差 2，回路无法轮流访问。
所以 $n/2$ 是能保证哈密顿回路的最小门限。
</span>

Dirac 定理足够惊人：**不需要检查局部，只要求每个顶点的度都超过顶点数的一半**，全图的连通性与密度就自动撑出一条贯穿全部顶点的回路。

## 2 Ore 定理：更强的充分条件

**Ore 定理（1960）**：设 $G$ 是 $n \ge 3$ 个顶点的简单图。
若对任意两个**不相邻**的顶点 $u, v$ 都有

$$
d(u) + d(v) \ge n
$$

则 $G$ 是哈密顿图。

Ore 条件比 Dirac 条件弱得多——Dirac 条件（每点度 ≥ $n/2$）显然推出 Ore 条件（任意两点的度和 ≥ $n$），
所以 **Dirac 定理是 Ore 定理的推论**。
<span class="marginnote">Ore 条件只说「不相邻」的顶点对度和大，对相邻顶点无要求。
这让 Ore 定理适用范围更宽：很多图不满足 Dirac 却满足 Ore。
</span>它由 Pósa 与 Ore 独立地基于「最长路径 + 闭包」论证给出。

## 3 Ore 定理的证明：最长路径论证

**Ore 定理的证明是一次经典的「最长路径 + 计数」演示。**
假设 $G$ 满足 Ore 条件但没有哈密顿回路。
取一条**最长路径** $P = v_1 v_2 \cdots v_p$（$p < n$，
因为若 $p = n$ 且首尾相邻则成哈密顿回路，
而 Ore 条件在 $n\ge3$ 时保证 $\delta \ge 2$，
首尾必相邻）。

两步论证：

- **第一步，路径端点只能连向路径内部的顶点**：若 $v_1$ 或 $v_p$ 连向路径外的顶点，路径可延长，矛盾于最长。
所以 $N(v_1), N(v_p) \subseteq \{v_2, \dots, v_{p-1}\}$ 附近……准确地说，$v_1$ 的所有邻点、$v_p$ 的所有邻点都落在 $P$ 的顶点里。
- **第二步，把 $P$ 折成一个圈**：若存在下标 $i$ 使得 $v_1 v_{i+1}$ 与 $v_i v_p$ 两条边都在 $G$ 中，则把路径「错位相接」$v_1 \to v_{i+1} \to \cdots \to v_p \to v_i \to \cdots \to v_2$，构成一个覆盖 $P$ 全部顶点的圈——这就能再延出一条更长的路径（任取圈外一点，连通性保证它能接到圈上），矛盾。
<span class="marginnote">所以「不是哈密顿」迫使：对每个 $i \in \{1, \dots, p-1\}$，$v_1 v_{i+1}$ 与 $v_i v_p$ <strong>不能同时</strong>在 $G$ 中。
这给出 $d(v_1) + d(v_p) \le p-1$ 的上界。
</span>
- **第三步，矛盾**：$v_1, v_p$ 不相邻（否则又成圈），由 Ore 条件 $d(v_1) + d(v_p) \ge n > p - 1$，与上一步矛盾。
故最长路径必须达到全部 $n$ 个顶点，$G$ 是哈密顿图。

## 4 公式解析：Ore 条件的界为什么是 $n$

**「度数和 ≥ n」的 $n$ 不是拍脑袋，它来自「错位相接」的计数。** 设最长路径有 $p$ 个顶点，
端点 $v_1$ 与 $v_p$：

$$
d(v_1) + d(v_p) \le p - 1 < n \quad \text{（若 } p < n \text{）}
$$

三步拆解：

- **第一步，数可配对的邻点**：若 $v_1 v_{i+1}$ 且 $v_i v_p$ 同时存在，路径就能折成圈。
为避免成圈，对每个 $i$ 两件事至多发生一件。
- **第二步，$d(v_1)$ 与 $d(v_p)$ 的和被钉住**：$v_1$ 的邻点必须是 $\{v_2,\dots,v_p\}$ 中「可与 $v_p$ 的邻点错位配对」的那些，计数给出 $d(v_1) + d(v_p) \le p-1$。
- **第三步，若 $p<n$ 则矛盾**：Ore 条件给出 $d(v_1)+d(v_p) \ge n$，而 $p-1 < n$，矛盾。

所以「不是哈密顿」与「度和 ≥ n」无法共存：
**$n$ 正是让最长路径被逼到顶点数满员的那个阈值**。
这也是「充分条件门槛」的典型论证结构：先假设最坏情况（最长路径没走满），
再用度数条件推出矛盾。

## 5 进一步的推广：Chvátal 定理与闭包

Ore 定理还能继续推广。
**Chvátal 定理（1972）**：把度序列 $d_1 \le d_2 \le \cdots \le d_n$ 升序排列，
若对每个 $k < n/2$ 都有 $d_k \ge k+1$ 或 $d_{n-k} \ge n-k$，
则 $G$ 是哈密顿图。
它统一了 Dirac 与 Ore 的离散版本。

还有一个关键概念——**闭包（closure）**：
反复把「不相邻且度和 ≥ $n$」的顶点对用边连起来，
直到不能再连，得到的图叫 $G$ 的闭包 $cl(G)$。
Bondy–Chvátal 定理说：**$G$ 是哈密顿图当且仅当 $cl(G)$ 是哈密顿图**。
<span class="marginnote">这个定理把充分条件问题变成「闭包是否够密」的问题：只要闭包有哈密顿回路，原图就有。
闭包是「补边不改变哈密顿性」的极值化工具，与极值图论里「补边看临界」的思路一脉相承。
</span>

## 6 辨析｜易错点：充分条件 ≠ 必要条件

- **Dirac / Ore / Chvátal 都是充分条件**：满足 → 一定是哈密顿图；
不满足 → **什么也推不出**，可能是也可能不是。
- 反例并不罕见：有些图的 $\delta$ 远小于 $n/2$，却仍是哈密顿图（例如 $C_n$ 本身，$\delta = 2$，只要 $n \ge 3$ 且…… $C_n$ 是哈密顿图，但 $\delta = 2$ 通常小于 $n/2$）。
- **判定的正确流程**：先用必要条件（如 $c(G-S) \le |S|$）排除「肯定不是」；
再用充分条件确认「肯定是」；
两都不行时，只能上搜索或启发式（下一篇 TSP）。

**辨析｜易错点：Dirac 的下界要小心取整。**
$\delta(G) \ge n/2$ 当 $n$ 为奇数时实际要求 $\delta \ge \lceil n/2 \rceil$。
$K_{n/2-1, n/2+1}$ 例子说明门槛若松一格，
结论立刻失效——充分条件的界往往「临界精确」。

## 7 小结

- **Dirac 定理**：$n\ge3$ 且 $\delta \ge n/2$ ⇒ 哈密顿图。
- **Ore 定理**：任意不相邻 $u,v$ 有 $d(u)+d(v) \ge n$ ⇒ 哈密顿图；
Dirac 是它的推论。
- **证明核心**：最长路径 + 错位相接计数；
「不是哈密顿 ⇒ $d(v_1)+d(v_p) \le p-1$」是论证引擎。
- **Chvátal 定理**与**闭包**把充分条件推广到「闭包够密即可」。
- 充分条件**不满足时不代表非哈密顿**；
判定需必要条件、充分条件与搜索三者配合。
