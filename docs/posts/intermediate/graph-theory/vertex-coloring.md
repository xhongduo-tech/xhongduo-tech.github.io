## 为什么从顶点着色开始

1852 年格思里注意到：任何一张地图似乎都只要四种颜色就能保证相邻区域异色——这就是著名的四色猜想。
图论把「地图」抽象成**对偶图**：区域是顶点、相邻关系是边，
「地图涂色」变成「给顶点涂色使相邻顶点异色」。
于是诞生了着色理论：**用最少的颜色数**给图涂色。
<span class="marginnote">着色的现实应用远不止地图：考试排程（同时段的考试不能撞学生）、寄存器分配（冲突的变量不能共用寄存器）、无线频道分配（干扰的基站不能用同频），全是对偶图着色的具体化身。
</span>这一节建立顶点着色的基本框架与色数的上下界。

## 1 正常着色与色数

**正常顶点着色（proper vertex coloring）**：
给每个顶点涂一种颜色，使得**相邻顶点颜色不同**。
<span class="marginnote">「正常」两字强调约束：
相邻不同色。允许相邻同色的叫「染色」但通常无意义；
我们的着色一律指正常着色。</span>

**色数（chromatic number）**：
图 $G$ 的色数 $\chi(G)$ 是正常着色所需的最少颜色数。
$G$ 是 $k$-可着色的当且仅当 $\chi(G) \le k$。

色数是图的一个核心不变量，几个基准值：

空图：$\chi(\bar K_n) = 1$（没有边，一种颜色足够）。
完全图：$\chi(K_n) = n$（任意两顶点相邻，必须全不同色）。
**二部图**：$\chi = 2$（左右两组各一色，正是《二部图与匹配》里二染色的意义）。
奇圈：$\chi(C_{2k+1}) = 3$（二色会撞在闭环上）。

**一个重要等价**：$\chi(G) \le 2$ 当且仅当 $G$ 是二部图（或无边）。
所以「二部图 ⇔ 2-可着色」，着色与二部图判定是同一个问题——BFS 二染色就是最朴素的着色算法。
<span class="marginnote">这也是为什么第一篇把「二部图判定 = 无奇圈」讲得那么细：
它本质上是在说「色数 ≤ 2 的特征」。奇圈 $C_3$（三角形）色数 3，
是非二部的最小原因。</span>

## 2 贪心着色与基本上界

**贪心着色算法**：任意给顶点排个序，依次给每个顶点涂「还没被其邻居用掉的最小颜色」。
每一步最多要避开 $\Delta(G)$ 个邻居的颜色，
所以：

$$
\chi(G) \le \Delta(G) + 1
$$

这个上界对任何图都成立，简单但粗糙。
<span class="marginnote">贪心着色的颜色数依赖顶点排序：好的顺序（先涂度数高的）通常用得少，坏的顺序可能正好用满 $\Delta+1$。
不过对最坏情况，$\Delta+1$ 是可靠天花板。
</span>

**Brooks 定理（1941）**把这个上界改进到几乎紧致：

$$
\chi(G) \le \Delta(G), \qquad \text{除非 } G \text{ 是完全图或奇圈}
$$

也就是说：除了 $K_n$ 与奇圈这两个「铁例外」，
任何连通图的色数都不超过最大度——$\Delta$ 比 $\Delta+1$ 少了整整一个颜色。
<span class="marginnote">Brooks 定理是「色数上界」理论的分水岭：之后的研究都围绕「哪些图需要 $\Delta+1$ 色」展开（被称为颜色临界图，color-critical）。
欧拉图、平面图的大量着色结论都从这一定理生长。
</span>

## 3 平面图着色的基本事实

平面图是着色的发源地，最著名的结论是**五色定理**：
**每个平面图都是 5-可着色的。**

证明用「平面图必有低度顶点」：任何平面图都存在度数 ≤ 5 的顶点（否则所有顶点度 ≥ 6，
$2m \ge 6n$，但平面图 $m \le 3n-6$，
矛盾）。
据此归纳：删去低度顶点 $v$，给剩下的图 5-着色；
若 $v$ 的至多 5 个邻居没用满 5 色，
直接补上；
若用满 5 色，用 Kempe 链交换把 $v$ 的一个邻居颜色空出来——这是五色定理的核心论证。
<span class="marginnote">五色定理的 Kempe 链技术后来成为四色定理证明的基石之一，也出现在《四色定理》一节。
平面图从「5 色」到「4 色」之间隔着的，是长达百年的攻坚。
</span>

这个「平面图必有 ≤5 度顶点」的引理本身也是极值思想：
平面性约束直接把「最少度」压到 5。

## 4 公式解析：色数上界的贪心论证

**贪心着色给出 $\chi(G) \le \Delta(G) + 1$，论证只有一行。** 设着色顺序为 $v_1, v_2, \dots, v_n$：

$$
\text{给 } v_i \text{ 选色时} \le \deg(v_i) \le \Delta \text{ 个颜色已被邻居使用} \implies \text{至少 1 色可用}
$$

三步拆解：

- **第一步，数已用色**：轮到 $v_i$ 时，它的邻居至多 $\deg(v_i)$ 个，每个至多用一种颜色，所以被挡掉的颜色数 ≤ $\deg(v_i)$。
- **第二步，上界替换**：$\deg(v_i) \le \Delta$，被挡掉的颜色 ≤ $\Delta$。
- **第三步，颜色总数**：$v_i$ 面前至少有 $\Delta + 1$ 种颜色可选，减去被挡掉的 ≤ $\Delta$ 种，还剩 ≥ 1 种。
全程用 ≤ $\Delta+1$ 种即可。

这个论证的美在于它**不依赖图的具体结构**，
只依赖「每个顶点的邻居数不超过 $\Delta$」这一条局部事实——这就是「局部信息 → 全局上界」的典范。

## 5 辨析｜易错点：色数 ≠ 匹配 / 覆盖，别混在一起

- **色数是「分组不相邻」的最少组数**；
独立集是「最大的一组不相邻」。
两者有关（一种颜色下的顶点集是独立集），但不等价。
- 色数与最大度、平面性、二部性各有独立判据；
**没有统一的简单公式**计算 $\chi(G)$ 是 NP 完全问题（一般图）。
- **$\chi(G) \ge \omega(G)$**（团数下界：一个大团里的顶点全需不同色），但等号不总成立——存在 $\chi > \omega$ 的图（称为非完美图），这是着色理论里「团数 vs 色数」的经典张力。

**辨析｜易错点：贪心着色不保证最少色。** 贪心给出的 ≤ $\Delta+1$ 只是一个**上界**，
实际色数可能远小。求 $\chi(G)$ 的最优值是 NP 完全问题，
工程上用启发式（DSATUR、递归最大独立集）逼近。

## 6 小结

- **正常着色**：相邻顶点异色；
**色数** $\chi(G)$ 是最少颜色数。
- 基准：$\chi(K_n)=n$、$\chi(\text{二部图})=2$、$\chi(C_{2k+1})=3$；
**二部图 ⇔ 2-可着色**。
- **贪心上界** $\chi \le \Delta+1$；
**Brooks 定理**：除 $K_n$、奇圈外 $\chi \le \Delta$。
- **五色定理**：平面图 5-可着色（Kempe 链论证），四色是更深的提升。
- 计算 $\chi(G)$ 是 **NP 完全**；
团数下界 $\chi \ge \omega$ 但常不取等。

在下一节，把颜色涂到边上：边着色。
范登·瓦尔登的边着色定理（Vizing 定理）给出 $\Delta$ 与 $\Delta+1$ 之间的两难，
连接着色与因子分解。
