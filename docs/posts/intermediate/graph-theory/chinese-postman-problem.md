# 中国邮递员问题

<div class="epigraph">

</div>

## 为什么从中国邮递员问题开始

欧拉回路要求「每条边恰好一次」，现实中的投递路线往往更宽松：
**每条边至少要扫一遍**（每户门前的路都要经过），
但可以重复走。
问题是：从邮局出发，走遍全部街道至少一次，最后回到邮局，
怎样让总路程最短？1962 年山东大学管梅谷提出并解决了这个问题，
因提出者国籍得名**中国邮递员问题（Chinese Postman Problem, CPP）**。
<span class="marginnote">CPP 与 TSP 看似一对「边 vs 顶点」的双胞胎，命运却完全不同：CPP 有多项式算法（Edmonds 1973），TSP 是 NP 完全的。
它的解法把欧拉图、最短路径、完美匹配三个模块缝合在一起，
是本章理论的集大成应用。
</span>

## 1 问题定义

**中国邮递员问题（CPP）**：给定带权连通图 $G$（顶点是路口，
边是街道，权是长度），求一条**闭迹**，覆盖 $G$ 的**每条边至少一次**，
使总长度最小。

观察：若 $G$ 已经是欧拉图（度数全偶），
那么欧拉回路本身就是答案——每条边恰好一次，
不可能更短。
困难出在**奇度顶点**上：奇度顶点处的边无法「进出配对」，
必须重复走某些边来把奇度补成偶度。
<span class="marginnote">重复走的边集 $F$ 必须使 $G + F$（在原图上叠加 $F$ 中的边）变成欧拉图：每个奇度顶点在 $F$ 里的度数必须是奇数（奇+奇=偶），每个偶度顶点在 $F$ 里的度数必须是偶数。
所以 $F$ 是「奇度顶点集上的一个边集配对」。
</span>

于是 CPP 变成一个清晰的优化问题：**在奇度顶点之间选择一组路径来重复走，使总重复长度最小。**

## 2 解法总览：三模块缝合

CPP 的多项式算法由 Edmonds（1973）给出，
分三步：

1. **找出奇度顶点集** $O = \{v : d(v) \text{ 为奇数}\}$。
由握手定理 $|O|$ 为偶数。
2. **计算奇度顶点之间的最短路径**：用 Floyd–Warshall 或 Dijkstra，得到 $|O| \times |O|$ 距离矩阵。
3. **在 $O$ 上求最小权完美匹配**：把 $|O|$ 个奇度顶点两两配对，使配对的路径总长最小。

重复走 $F$ = 完美匹配给出的那些最短路径；
最后在 $G+F$（欧拉图）上跑 Hierholzer 得到投递路线。
<span class="marginnote">关键洞察：重复走的边必须能「把奇度补成偶度」，而补偶恰好等价于「在奇度顶点之间两两连一条路」。
每条重复路径贡献它端点在 $F$ 里的奇偶变化。
用最小权完美匹配选配对，就得到最小重复长度。
</span>

## 3 公式解析：奇偶性与重复走的关系

**为什么重复边 $F$ 只在奇度顶点之间配对？** 设 $O$ 为奇度顶点集，
$d_G(v)$ 为原度数，$d_F(v)$ 为重复度数，
要求 $G+F$ 全偶：

$$
d_G(v) + d_F(v) \equiv 0 \pmod 2
\implies d_F(v) \equiv d_G(v) \pmod 2
$$

三步拆解：

- **第一步，全偶条件**：$G + F$ 的每个顶点度数为偶数，即 $d_G(v) + d_F(v)$ 为偶。
- **第二步，奇偶归类**：$v$ 是奇度顶点（$d_G$ 奇）时 $d_F$ 必须为奇；
$v$ 是偶度顶点（$d_G$ 偶）时 $d_F$ 必须为偶。
- **第三步，路径组合**：$d_F(v)$ 统计的是经过 $v$ 的重复路径条数。
若 $v$ 是偶度顶点且 $d_F(v)$ 为偶，多条重复路径可以在 $v$ 处「成对穿过」，等价于只保留路径端点——于是可以假设重复路径的端点全在奇度顶点上。
这归约为**在 $O$ 上做配对**。

最后一步正是「重复走 = 奇度配对」的严格证明：
重复边可以重组为若干条连接奇度顶点的路径，问题规模从「所有边」压缩到「$|O|$ 个奇度顶点」。

## 4 最小权完美匹配的挑选

在奇度顶点 $O$ 上，每个配对方案 $\mathcal{P}$ 对应一个重复长度 $L(\mathcal{P}) = \sum_{(u,v)\in \mathcal{P}} \mathrm{dist}(u,v)$。
CPP 的最优值：

$$
\text{OPT} = |E(G)| \text{ 的总权 } + \min_{\mathcal{P}} \sum_{(u,v)\in \mathcal{P}} \mathrm{dist}(u,v)
$$

其中最小值用**最小权完美匹配算法**计算（$|O|$ 个顶点配成 $|O|/2$ 对，
使配对距离和最小）。
<span class="marginnote">最小权完美匹配是《匹配与最大匹配》《完美匹配与 Tutte 定理》的内容：在完全图上求权最小的完美匹配，Edmonds 的带花算法（Blossom）给出多项式解，复杂度 $O(|O|^3)$。
</span>

为什么路径可交叉也无妨：如果两条重复路径在中间点交叉，
可在交叉点「交换后半段」，总长不变（三角不等式下不增），
所以总能整理成互不干扰的配对——这就是「路径配对等价于匹配」的最后一块拼图。

## 5 特例与变体

**全偶图**：$O$ 为空，直接欧拉回路，答案就是边权总和——不需要匹配。
**恰 2 个奇度顶点**：$O$ 只有两个点，唯一配对就是它们的最短路径，重复走一次该路径即可（这正是《欧拉路径》里「补边变欧拉图」的加权版）。
<span class="marginnote">所以欧拉路径一节里的「加边 $uv$」技巧，在 CPP 里升级成「加最短路径」；
从「恰好一次」到「至少一次」，跨度就这么被匹配理论补齐。
</span>
- **有向版（DCPP）**：街道分单双行，问题变为「有向欧拉图 + 奇偶度差」的配对，同样多项式可解。
- **Capacitated CPP**：车辆有容量限制（每趟最多扫多少条街），难度陡增为 NP 困难——现实的快递分拣问题往往属于这一类。

## 6 辨析｜易错点：CPP 与 TSP 的角色不要混淆

| 维度 | 中国邮递员问题 | 旅行商问题 |
| --- | --- | --- |
| 覆盖对象 | 每条**边**至少一次 | 每个**顶点**恰好一次 |
| 复杂度 | 多项式（Edmonds 1973） | NP 完全 |
| 解法核心 | 欧拉图 + 最短路径 + 完美匹配 | 近似 / 启发式 |
| 提出者 | 管梅谷（1962） | 哈密顿 / 汉密尔顿游戏（1857） |

**辨析｜易错点：CPP 的答案不是「每条街走一次」。**
当存在奇度顶点时，必然要重复走一些街道；
CPP 求的是**重复长度最小的走法**，而不是「尽量少重复」的随意拼凑。
判断方案好坏看重复总长是否等于完美匹配最优值。

## 7 小结

- **CPP**：覆盖每条边至少一次、回到起点的最短闭迹；
奇度顶点必须靠重复走补偶。
- **核心归约**：重复边可重组为「奇度顶点间的路径配对」。
- **多项式算法**：找奇度集 $O$ → 最短路径矩阵 → 最小权完美匹配 → 欧拉回路。
- **最优值公式**：$\text{OPT} = \text{原边权总和} + \text{最小配对距离和}$。
- 全偶（欧拉回路）与恰 2 奇度（欧拉路径补边）是它的特例；
带容量版本 NP 困难。
