# 国际中文教育（对外汉语：汉语作为第二语言教学与水平分级）

国际中文教育（对外汉语）研究汉语作为第二语言教学的学科理论、习得规律与教学实践，并依托国家语言文字标准《国际中文教育中文水平等级标准》与 HSK 汉语水平考试体系实现水平分级与测评。以刘珣《对外汉语教育学引论》、吕必松《对外汉语教学发展概要》和《国际中文教育中文水平等级标准》（GF 0025-2021）为纲，系统重建从学科概说、第二语言习得、教学法流派到语言要素教学与中文水平等级标准的完整知识框架。

## 对标教材

- 《国际中文教育中文水平等级标准》（GF 0025-2021，教育部、国家语言文字工作委员会）
- 刘珣《对外汉语教育学引论》
- 吕必松《对外汉语教学发展概要》
- HSK 汉语水平考试大纲（等级对应参考）
