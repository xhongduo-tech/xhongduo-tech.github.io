## 为什么从 CMOS 工艺开始

器件物理告诉你「MOSFET 是什么」，工艺告诉你「MOSFET 怎么做出来」。**CMOS 工艺**把 NMOS 与 PMOS 集成在同一块衬底上，靠一整套「氧化—光刻—刻蚀—离子注入—淀积」步骤循环，把设计好的版图变成真实的晶体管与互连。理解工艺，才能读懂版图、读懂设计规则、读懂「为什么某些电路结构在硅上不可实现」。<span class="marginnote">CMOS 工艺的核心思想与印刷术同源：<strong>一次次把图形从掩模「印」到硅片上</strong>。掩模是版图的光学副本，光刻把图形转移到光刻胶，刻蚀把图形刻进材料——每一层掩模对应一步图形转移，一颗 7 nm 芯片要印 60 层以上。</span>

## 1 衬底与外延

工艺从一块 **p 型硅衬底**（或 p 型外延层，p-epi on p⁺）开始。外延层的作用：**表面层更纯净、掺杂更可控**，把衬底中的缺陷与杂质「隔」开，同时 p⁺ 重掺底衬给衬底提供低电阻接地点——CMOS 里衬底必须可靠接地以抑制闩锁。<span class="marginnote">为什么常用 p-epi/p⁺？晶体缺陷集中在衬底内部，外延层是「重新长出来的好皮肤」；p⁺ 底衬则让衬底电位稳如泰山。这层「好皮肤 + 稳地基」的结构，是 CMOS 工艺的第一步决策。</span>

## 2 阱与隔离

CMOS 需要 n 阱（容纳 PMOS）与 p 区（容纳 NMOS）：

- **n 阱（n-well）**：离子注入 + 高温推进形成，为 PMOS 提供衬底。
- **浅槽隔离（STI，shallow trench isolation）**：刻出浅沟、填二氧化硅，把相邻器件**电隔离**——取代了老式的局部氧化（LOCOS）。STI 的关键是**密度均匀性**：版图密度差异会导致平坦化（CMP）后厚度不均，直接影响后续光刻。<span class="marginnote">隔离是 CMOS 的隐形骨架：没有 STI，相邻晶体管的源漏会互相「串电」。STI 的「哑铃效应」——设计时要在稀疏区域填充 dummy 结构，让氧化层密度均匀，这解释了版图里那些「无用的方块」的真正用途。</span>

## 3 栅与源漏：自对准的魔法

栅的形成是 CMOS 工艺的**心脏步骤**：

1. 长**栅氧化层**（现在：界面层 + 高 k 介质）。
2. 淀积**多晶硅/金属栅**。
3. **光刻 + 刻蚀**出栅条。
4. 以栅为**自对准掩模**，注入源漏——源漏边缘自动对齐栅的边缘。<span class="marginnote">自对准为何关键：若源漏另用一块掩模对准，错位几纳米都会造成栅-源漏交叠电容剧增、阈值漂移。以栅做掩模注入，几何上<strong>保证</strong>对齐——「用工艺步骤消灭对准误差」，是栅工艺设计的最聪明一笔。</span>

随后做**侧墙（spacer）**（氮化硅侧壁绝缘），再做**轻掺杂漏（LDD）注入**与**源漏重掺杂注入**（LDD 缓释热载流子效应，小尺寸效应一节讲过），最后**快速热退火（RTA）**激活杂质。

## 4 接触、互连与多层金属

晶体管做好后要「接电线」：

- **硅化物（salicide）**：在栅与源漏表面反应生成 TiSi₂/CoSi₂，把接触电阻压低到 $\mu\Omega\cdot\text{cm}^2$ 量级。
- **接触孔（contact）**：刻穿介质层，填钨（W）连接器件与第一层金属。
- **多层互连**：铜大马士革工艺（Damascene）——先刻槽、再电镀铜、CMP 平坦化，层层堆叠（M1, M2, ..., 顶层厚金属）。层间用**低 k 介质**降低互连电容。<span class="marginnote">铝互连时代「先金属、后刻蚀」，铜时代改成「先挖槽、后填铜」——因为铜难刻、易扩散。大马士革工艺把「填平-再叠层」循环到十几层金属，每层 10 万级的过孔——互连才是今天芯片面积与延迟的大头。</span>

## 5 工艺集成与现代流程

一条现代 CMOS 流程（简化）：

| 步骤 | 作用 |
| --- | --- |
| 衬底/外延 | 地基与接地点 |
| 阱注入 | n 阱/p 阱 |
| STI | 器件隔离 |
| 栅堆叠（高 k + 金属栅） | 阈值与栅控 |
| 侧墙 + LDD + 源漏注入 | 沟道保护与重掺 |
| 硅化物 + 接触 | 低阻引出 |
| 多层铜互连 + 低 k | 信号与电源布线 |
| 钝化层 + 焊盘 | 保护与引出 |
| 测试与封装 | 良率判定与成品 |

每一步都有**工艺窗口**（时间、温度、浓度的容差带），窗口越窄良率越难保——CMOS 制造是一门「在容差里跳舞」的工程。<span class="marginnote">「设计规则」（design rule）正是工艺窗口的版图表达：最小线宽、最小间距、覆盖要求——工艺工程师把「物理上能造出来」翻译成「版图上必须满足」的数字。设计规则检查（DRC）没跑过，流片就是烧钱。</span>

## 6 公式解析：MOSIS 缩放与设计规则

设计规则常用**λ 规则**（以特征尺寸 λ 为单位）表示，如「最小线宽 = 2λ」「接触孔 = 2λ × 2λ」。线性缩放下面积 $A \propto \lambda^2$，门延迟 $\tau \propto 1/\lambda$。关键的成本与性能关系：

$$
\text{每颗裸片成本} = \frac{\text{晶圆成本}}{\text{每片晶圆的可用裸片数}} = \frac{C_w}{N_{die}}
$$

而

$$
N_{die} \approx \frac{\pi (D/2)^2}{A} - \frac{\pi D}{\sqrt{2A}}
$$

（$D$ 为晶圆直径，$A$ 为裸片面积）三步拆解：

- **第一步，看面积与数量**：可用裸片数 ≈ 晶圆面积 / 裸片面积，再扣掉边缘的「残片」。
- **第二步，看缺陷与良率**：实际还要乘**良率**（泊松模型 $Y = e^{-D_0A}$，$D_0$ 是缺陷密度）——面积越大，碰到缺陷的概率越高。
- **第三步，看经济含义**：**裸片面积平方增长，良率指数下降**——这就是「die 太大伤成本」的数学根源，也是为什么工艺每代都要把晶体管做小、把设计做紧凑。

## 7 易错辨析

- **辨析｜易错点：** 高 k 介质（HfO₂）不是「取代栅氧化层」，而是「取代 SiO₂ 作为绝缘介质」，且要在界面保留极薄的 SiO₂ 界面层——「高 k = 全换材料」是错的。
- **辨析｜易错点：** STI 的填充氧化物要**平坦化**到与硅表面齐平，不齐平的表面会让后续光刻失焦——CMP 的平整度是先进工艺的命门。
- **辨析｜易错点：** 铜互连不是「直接刻铜」——铜用大马士革工艺填充，且必须用**阻挡层**（Ta/TaN）包住防止扩散进硅，否则铜原子会毒化晶体管。
- **辨析｜易错点：** 设计规则 ≠ 器件物理极限。设计规则是「工艺在良率保障下能稳定制造的最小几何」，比物理极限宽松——它们来自实测与良率统计，不是单纯公式。

## 8 延伸：先进工艺的关键技术里程碑

CMOS 工艺的演进史，是「把晶体管越做越小」的历史，也是新材料、新结构、新设备轮流登场的编年史：

| 节点 | 关键技术突破 | 解决的问题 |
| --- | --- | --- |
| 0.25 μm | 铜互连替代铝 | 互连电阻与电迁移 |
| 90 nm | 应变硅 | 提升迁移率，延续摩尔 |
| 45 nm | 高 k + 金属栅 | 栅氧漏电 |
| 20 nm | FinFET 量产（22 nm 先） | 短沟道静电控制 |
| 5 nm | EUV 光刻量产 | 多重曝光成本与精度 |
| 3 nm | GAA 纳米片 | 更强的栅控 |

**EUV（极紫外光刻）的意义**：波长 13.5 nm 的极紫外光，一次曝光替代多次曝光——**光刻成本与工艺时间大幅下降，是先进节点的「印钞机」级设备**。EUV 的产业化（光源功率、真空、掩模保护膜）前后奋斗了二十年，是「把实验室变成工厂」的极限案例。

**光刻的双重挑战**：分辨率（越刻越细）与成本（越刻越贵）——ASML 一台 EUV 光刻机售价上亿美元，先进节点的「资本门槛」把代工厂数量压缩到个位数。**「造得起光刻机」与「买得起光刻机」成为产业分水岭**。

**工艺与设计的协同**：工艺决定「能造多小」，设计决定「用多小」——设计规则每代更新，设计团队要跟着迁移；同时「工艺-设计协同优化」（DTCO）让器件结构与版图一起设计，从根上减少迭代。**「先有良率、后有设计」倒过来变成「设计也为良率服务」**——这是先进工艺时代的范式转变。

**与「从极限到大模型」的连接**：先进工艺是算力「极限」的物理基础——GPU/NPU 的晶体管密度、能效都来自这条工艺链；没有它，大模型的「极限」无从谈起。半导体工艺是「从极限到大模型」坐标里最底层的「极限」。

## 9 小结

- CMOS 工艺 = 衬底/外延 → 阱 → STI → 栅（自对准）→ 源漏 → 硅化物/接触 → 多层铜互连。
- 自对准栅工艺用「栅做掩模」消灭对准误差，是阈值与电容控制的基石。
- 浅槽隔离 STI 提供器件隔离，CMP 平坦化保证光刻质量。
- 大马士革铜互连 + 低 k 介质统治金属层，接触用硅化物降阻。
- 设计规则是工艺窗口的版图表达；面积越大良率指数下降，成本结构由此决定。
