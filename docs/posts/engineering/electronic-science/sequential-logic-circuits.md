## 为什么从时序逻辑开始

上一节的组合逻辑是无记忆的：输入一变、输出立刻（经传播延迟后）跟着变。但计算机需要「记住」：程序计数器要记住下一条指令在哪、寄存器要记住中间结果、状态机要记住当前进行到哪一步。**时序逻辑（sequential logic）**给数字电路加上记忆，其统一结构是「寄存器 + 组合逻辑」：组合逻辑算下一步状态，寄存器在**时钟边沿**把状态固定下来。<span class="marginnote">「用时钟统一节奏、让全系统同步地『踏步』」是数字设计的核心纪律：无论电路多复杂，只要所有触发器共享同一个时钟，每一步都等所有逻辑稳定后再取数，系统就永远正确。异步世界的混乱，被时钟的纪律驯服了。</span>本节讲锁存器/触发器、计数器/寄存器、以及有限状态机——对应[组合与时序逻辑](./comb-sequential-logic)与[系统芯片（SoC）](./soc)里的流水线与时序。

## 1 从锁存器到触发器：记忆的两种形态

**锁存器（latch）**是电平敏感的：使能信号为高时，输出跟随输入；为低时，输出保持。SR 锁存器用两个交叉耦合的与非门构成，是记忆的最简形态，但有「1、1」输入的非法态。

**触发器（flip-flop）**是边沿敏感的：只在时钟的上升沿（或下降沿）那一瞬间采样输入，其余时间输出保持不变。主流类型：

- **D 触发器**：时钟沿把 D 端的数据锁存到 Q。最常用，一个触发器 = 一位存储；
- **JK 触发器**：J、K 端控制置位/清零/翻转，是通用型；
- **T 触发器**：T=1 时每个时钟沿翻转一次，是计数器的基础。

**核心对比表：锁存器 vs 触发器**

| 特性 | 锁存器（latch） | 触发器（flip-flop） |
| --- | --- | --- |
| 敏感方式 | 电平敏感（使能=高时透明） | 边沿敏感（只在时钟沿采样） |
| 抗毛刺 | 差（使能期间输入毛刺直接通过） | 好（只在边沿采样） |
| 时序可分析性 | 差（透明窗口难建模） | 好（统一按时钟沿分析） |
| 典型应用 | 时钟门控、异步缓冲 | 寄存器、状态机、流水线 |

**重点：集成电路设计普遍「宁用触发器、不用锁存器」**，因为只有边沿触发才能把时序收敛成一套可在工具里验证的建立/保持约束。锁存器的透明窗口让时序不可预测，是设计时序收敛（timing closure）的大敌。

## 2 时序的正确性：建立时间与保持时间

为什么触发器只在边沿采样就保证正确？因为数据必须在采样瞬间保持稳定，这引出两个关键参数：

- **建立时间 $t_{su}$（setup time）**：数据必须在时钟沿**之前**提前稳定，典型几十 ps 到几百 ps；
- **保持时间 $t_h$（hold time）**：数据必须在时钟沿**之后**再保持一小段时间。

**公式解析：最大时钟频率**

两级触发器之间的组合逻辑有传播延迟 $t_{logic}$，触发器本身有钟到 Q 延迟 $t_{clk-q}$，则时钟周期必须满足

$$
T_{clk} \ge t_{clk-q} + t_{logic} + t_{su}
$$

也就是**最大时钟频率 $f_{max} = 1/T_{clk}$**。代入 $t_{clk-q}=200\,\mathrm{ps}$、$t_{su}=100\,\mathrm{ps}$、$t_{logic}=500\,\mathrm{ps}$：$T_{clk} = 800\,\mathrm{ps}$，$f_{max} = 1.25\,\mathrm{GHz}$。<span class="marginnote">这条式子是所有「提频」的指导：超频失败要么是 $t_{logic}$ 太长（关键路径），要么是 $t_{su}$ 不够。CPU 的频率上限 = 关键路径延迟，现代处理器为压关键路径而做指令流水线——把一条长路径切成多段。见[系统芯片（SoC）](./soc)。</span>保持时间约束则是另一个方向：数据变化不能太快传播到下一级，违反保持时间要靠「在寄存器前加延迟」修，这与建立时间约束（减少逻辑延迟）方向相反，是后端实现（见[VLSI设计流程](./vlsi-design-flow)）里常见的修复矛盾。

**辨析｜易错点：亚稳态（metastability）**。当数据在采样边沿附近变化、违反建立/保持时间时，触发器输出既非 0 也非 1，而可能停留在中间电压并长时间不解决——这就是亚稳态。它是「时序不满足」的最坏后果，跨时钟域信号必须用两级触发器同步器（打两拍）来把亚稳态概率压到可忽略。**初学者以为时序约束是「规矩」，其实它是「可靠性」**：亚稳态一旦发生，下一级逻辑读到的值可能完全错误。

## 3 计数器与寄存器：记忆的工程化

**寄存器（register）**是一组共享时钟的 D 触发器，n 位寄存器存 n 位数据；**移位寄存器**让数据在时钟沿逐位移动，可实现串行↔并行转换（SIPO/SISO/PISO/PIPO）、延迟线与伪随机序列发生器。

**计数器（counter）**是时序逻辑最经典的应用：每来一个时钟沿，状态加 1（或按模计数）。

- **异步计数器**：前一级的输出做后一级的时钟，电路简单但各级翻转有先后（波纹延迟），高速下不可靠；
- **同步计数器**：所有触发器共享时钟，各级同时翻转，速度快、无波纹——现代设计几乎只用同步；
- **模 N 计数器**：数到 N-1 就回零，可用作**分频器**：模 2 计数器把时钟频率减半，级联 k 级模 2 得到 $2^k$ 分频。

**数字例**：32.768 kHz 的晶振经 15 级模 2 分频（$2^{15}=32768$）得 1 Hz 秒脉冲，这就是电子表计时原理——手表里那颗晶振与计数器，是时序逻辑最贴近生活的应用。

寄存器家族的另一个成员是**环形计数器**：把 1 在寄存器里循环移位，输出为「独热」序列，用作状态机/时序发生器的简单译码替代——硬件里「数数」与「移位」经常互相转换着用，因为它们本就是同一批触发器的不同接法。

## 4 有限状态机：记忆 + 逻辑 = 程序

把「寄存器（状态）」与「组合逻辑（状态转移）」结合，就得到**有限状态机（FSM）**，它是时序逻辑的最高形态，也是硬件「程序」的原型。FSM 分两类：

- **Mealy 机**：输出 = 状态与输入的函数（输出即时响应输入）；
- **Moore 机**：输出只 = 状态的函数（输出只随状态改变）。

FSM 的设计步骤是流水线式的：**状态图**（画圆圈与箭头）→ **状态表** → 状态编码（二进制/独热）→ 化简 → 由触发器与组合逻辑实现。一个交通灯控制器、一个 UART 接收器、一个 CPU 的取指-译码-执行的循环，全都是 FSM。<span class="marginnote">FSM 与软件的联系：C 语言里的 `switch(state)` 就是 Moore 机的手写版；而「状态机 + 反馈」正是下一层抽象——从 FSM 到 CPU 的指令循环、再到 Transformer 里「位置 + 上下文」的迭代，记忆与规则驱动的模式贯穿计算的所有层级。</span>

**核心对比表：Mealy 与 Moore**

| 特性 | Mealy 机 | Moore 机 |
| --- | --- | --- |
| 输出依据 | 状态 + 当前输入 | 仅当前状态 |
| 速度 | 输出快（响应输入） | 输出慢一拍（等状态变化） |
| 毛刺 | 输入变化可能引起输出毛刺 | 输出稳定（同步于状态） |
| 实现 | 状态数可较少 | 状态数往往更多 |

**工程选择**：组合输入敏感的场合（如握手协议）用 Mealy；输出要求干净、无毛刺的场合（如直接驱动外部设备）用 Moore。

## 5 一个完整的 FSM 例子：序列检测器

把设计流程走一遍。要求：检测输入串行比特流中出现的「101」序列，一旦检测到就输出 1。设计用 Moore 机，四个状态：$S_0$（还没匹配任何前缀）、$S_1$（已匹配「1」）、$S_2$（已匹配「10」）、$S_3$（已匹配「101」，输出 1）。

状态转移规则：

- $S_0$：输入 1 → $S_1$；输入 0 → 留 $S_0$；
- $S_1$：输入 0 → $S_2$；输入 1 → 留 $S_1$（连续 1 仍算「1」前缀）；
- $S_2$：输入 1 → $S_3$（匹配成功）；输入 0 → 回 $S_0$（「100」里没有可用前缀）；
- $S_3$：已输出 1，输入 1 → $S_1$、输入 0 → $S_0$（从下一比特重新开始）。

**这个例子的价值**：它展示了 FSM 设计的精髓——**状态 = 对「已经看过多少历史」的浓缩**。4 个状态就把「任意长度的输入序列里是否出现 101」这个看似无界的问题，变成了有界记忆；而「压缩历史到有限状态」正是从正则表达式到编译器词法分析、再到程序运行的全部计算的共同骨架。<span class="marginnote">软件里的对应：这个检测器就是一个正则表达式 `101` 的硬件实现；`grep`、词法分析器、协议解析器底层全是这类状态机。时序逻辑不是「电路课的知识」，它是计算理论的物理化。</span>

**工程衔接**：上述 FSM 用 D 触发器 + 组合逻辑实现后，还要做**状态编码**（Moore 机的输出 $S_3$ 直接接出）、时序收敛检查（见上节建立/保持公式）与功耗优化（闲置状态低功耗处理，见[低功耗设计](./low-power-design)）。

## 6 小结

- **锁存器电平敏感、触发器边沿敏感**；现代 IC 设计「宁用触发器」，时序才可收敛。
- **建立/保持时间**定义数据采样的稳定窗口，$T_{clk} \ge t_{clk-q}+t_{logic}+t_{su}$ 决定最大时钟频率。
- **计数器**分同步/异步；同步计数无波纹延迟；模 2 计数器即分频器，晶振 32768 分频得秒脉冲。
- **寄存器与移位寄存器**实现数据存储与串并转换，是数据通路的记忆单元。
- **有限状态机**= 状态寄存器 + 转移逻辑；Mealy 输出依赖输入、Moore 输出只依赖状态。
- FSM 设计五步：状态图 → 状态表 → 编码 → 化简 → 实现；它是 CPU 取指循环与一切硬件协议的原型。
- **序列检测器**：4 状态 Moore 机检测「101」，展示「有限状态浓缩无限历史」这一计算根本思想。
- **亚稳态**：违反建立/保持时间的后果，跨时钟域用两级同步器缓解——时序约束是可靠性而非规矩。

在下一节，我们把「记忆」规模化：从单个触发器到百万容量的存储阵列，再到可以现场改写的可编程逻辑——这就是**半导体存储器与可编程器件**。
