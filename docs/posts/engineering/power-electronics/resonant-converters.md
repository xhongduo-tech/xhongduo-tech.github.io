## 为什么从谐振变换器开始

上一节我们说过，开关损耗随频率线性上涨：$P_{sw} \propto f_s$。这给「高频化、小体积」判了死刑——除非，能让开关**在电压为零或电流为零的时刻**开合。<span class="marginnote">回到损耗公式 $E_{sw}=\frac{1}{2}V_{off}I_{on}(t_{on}+t_{off})$：如果关断时电流恰好为零（ZCS），或开通时电压恰好为零（ZVS），电压与电流不再重叠，切换能量直接归零。高频化的天花板，就这样被「挑准时机」绕开了。</span>

**谐振变换器（resonant converter）**在电路里植入 LC 谐振网络，把开关波形从「方波硬切」改造成「正弦软切」。它换来的是：开关频率可以冲上 MHz、开关应力小、电磁干扰低、体积缩到极限。现代手机快充、服务器电源、电动汽车车载充电器，背后都是谐振变换器。

## 1 软开关的两把钥匙：ZVS 与 ZCS

**零电压开关（Zero-Voltage Switching, ZVS）**：开关两端电压先被谐振电容钳到零，再触发开通——开通瞬间电压为 0，没有 $VI$ 重叠。**零电流开关（Zero-Current Switching, ZCS）**：谐振电流先自然过零，再撤去驱动关断——关断瞬间电流为 0。<span class="marginnote">ZVS 和 ZCS 哪个更好？ZVS 对杂散电容天然免疫（开通前已泄放），是 MOSFET/IGBT 的主流；ZCS 对开关管的关断损耗（拖尾电流）特别有效，早年晶闸管时代流行，如今多用于 IGBT 的高压场合。二者常常成对出现在同一变换器里。</span>

两把钥匙各有所长，放一张表对照：

| 特征 | ZVS（零电压开关） | ZCS（零电流开关） |
| --- | --- | --- |
| 关键前提 | 开通前器件两端电压为 0 | 关断前器件电流为 0 |
| 能量依托 | 谐振电容的储能泄放 | 谐振电感电流自然过零 |
| 主要对象 | MOSFET / IGBT | 晶闸管、拖尾电流大的器件 |
| 对杂散电容 | 天然免疫（已泄放） | 敏感（会残留电压） |
| 典型场合 | 移相全桥、LLC、半桥 LLC | 晶闸管谐振、脉冲电源 |

**辨析｜易错点：** 软开关不是免费的午餐。ZVS 的实现条件是「关断期间有足够的谐振能量把开关两端电压荡到零」——负载太轻、能量不足，就会「软不了」，退化成硬开关。谐振变换器通常在额定负载附近最甜，轻载时往往要另辟蹊径（如跳过脉冲、调频上移）。

## 2 串联谐振与并联谐振：一对孪生拓扑

**串联谐振变换器（SRC）**把 LC 与负载串联，**并联谐振变换器（PRC）**把负载接在电容两端。它们的核心是一个**品质因数** Q 和**归一化频率** $\omega_n = \omega_s/\omega_0$：

$$\omega_0 = \frac{1}{\sqrt{LC}}, \qquad Q = \frac{\omega_0 L}{R}$$

串联谐振变换器（负载 R 串联）的电压增益幅值为

$$M = \frac{1}{\sqrt{1 + Q^2\left(\omega_n - \frac{1}{\omega_n}\right)^2}}$$

- **共振点 $\omega_n=1$**：增益 $M=1$，与负载无关——此时变换器像一台「理想变压器」，输出只由输入与匝比决定。
- **$\omega_n > 1$（感性区）**：增益下降；**$\omega_n < 1$（容性区）**：增益上升，但输入阻抗呈容性，开关可能失去 ZVS。
- 轻载时 Q 很小、曲线变平，增益对频率几乎不敏感——这既是优点（负载调整率好）也是麻烦（轻载难调压）。

**核心要点：** 谐振变换器靠**改变开关频率**来调压，而不是像 Buck 那样改变占空比——这就是「调频（PFM）」与「调宽（PWM）」两条控制路线的分野。

ZVS 的充分条件可以从输入阻抗的角度看：谐振变换器在**感性区**（$\omega_n > 1$ 附近）工作时，输入电流滞后于电压，关断瞬间电流为负、能给开关结电容放电，于是电压自然荡到零——这是工作区必须落在感性区的原因。容性区（$\omega_n < 1$）虽然增益更高，代价却是失去 ZVS。

到了 MHz 级，谐振变换器迎来新的敌人——**寄生参数**：PCB 的杂散电感、变压器绕组电容都会改掉谐振频率，让设计点漂移。MHz 谐振电源的布线要像射频电路一样讲究，这解释了为什么 GaN 谐振电源的样板总带「教科书级」的紧致布局。

举一组数值把共振算一遍：取 $L=10\,\mu\text{H}$、$C=100\,\text{nF}$，则 $LC = 10^{-12}$，$\omega_0 = 1/\sqrt{LC} = 10^6\,\text{rad/s}$，即 $f_0 \approx 159\,\text{kHz}$。若负载 $R=10\,\Omega$，则 $Q = \omega_0 L / R = 10^6 \times 10^{-5} / 10 = 1$——Q=1 时增益曲线已经很平坦，Q 再小（更轻的负载）几乎调不动电压。这就是谐振变换器设计里「Q 不能选太小」的直观原因。

谐振变换器的工作区，一张「设计边界」清单讲清：

| 工作区 | $\omega_n$ | 输入阻抗 | 能否 ZVS | 工程态度 |
| --- | --- | --- | --- | --- |
| 容性区 | $<1$ | 容性（电流超前） | 否 | 禁止长期工作 |
| 谐振点 | $=1$ | 纯阻 | 临界 | 设计锚点 |
| 感性区 | $>1$ | 感性（电流滞后） | 是 | 正常工作区 |

「往感性区走」是谐振设计的总口诀：容性区虽然增益更高，代价却是开关在开通瞬间被电流硬顶、失去软开关还平添应力——所以无论 SRC、PRC 还是 LLC，工作点都必须画在感性区，必要时用变频把频率推高去够它。

## 3 公式解析：为什么共振点增益恒为 1

把 M 的公式拆开，就明白了「共振即直通」的道理：

$$M = \frac{1}{\sqrt{1 + Q^2\left(\omega_n - \frac{1}{\omega_n}\right)^2}}$$

- **第一步，看电路**：串联谐振时，电源经过 $L$、$C$、负载 $R$ 分压。阻抗 $Z = R + j\omega L + \frac{1}{j\omega C}$，负载上的增益 $M = R/|Z|$。

谐振变换器的控制芯片早已「专用化」：UCC25600、L6599 这类控制器把 PFM 变频、死区调节、轻载跳频全做成片内功能——设计师的工作从「搭电路」变成「配参数」。这也是谐振变换器能迅速从论文走向量产的原因之一。
- **第二步，凑公式**：$|Z| = R\sqrt{1 + Q^2(\omega_n - 1/\omega_n)^2}$，因为 $Q = \omega_0 L / R$ 且 $\omega L - \frac{1}{\omega C} = Q R (\omega_n - 1/\omega_n)$。分子分母一除，就得到上面的 M。
- **第三步，找共振**：$\omega_n = 1$ 时 $\omega L = 1/(\omega C)$，电抗互相抵消，$Z = R$ 纯阻，$M = 1$——电感和电容在共振时「联手让路」，电路看起来就像直连。
- **第四步，看失谐**：离开共振点，电抗项 $Q(\omega_n - 1/\omega_n)$ 变大，M 减小。Q 越大（负载越轻），曲线越尖，共振峰越峭——所以谐振变换器在共振点附近对负载最宽容。

**LLC 的三个频率区间，一张清单讲清**：
- $f_s < f_r$（低于谐振点）：增益可升，但若深入容性区会失去 ZVS，工程上不让工作点长期待在这里；
- $f_s = f_r$：增益≈1、效率最高，是设计锚点；
- $f_s > f_r$：增益下降，负责轻载调压。

把这条清单记牢，读任何 LLC 增益曲线图都不会迷路。

## 4 LLC：今天的主角

把串联电感和并联电感凑进同一个磁元件，就得到 **LLC 变换器**——近十年开关电源的事实标准。它在**空载到满载的整个区间**都能保持 ZVS，且增益曲线兼具「升压/降压」两段，效率在 95% 以上，广泛用于服务器、快充、车载充电。<span class="marginnote">LLC 的设计核心是选择 $L_n$（励磁电感比）与 $Q$：它们决定了增益曲线的形状——要不要在满载时留出足够增益余量、轻载时能不能调回额定点。工程上通常用「增益曲线族」表格查取设计点，而不是手解方程组。</span>

LLC 的设计流程也值得记一笔：先按输出电压与变压器匝比定出「共振点增益≈1」的位置，再选择 $L_n$（励磁电感与漏感之比，常取 3–7）和满载品质因数 Q（常取 0.3–0.5），最后画出增益曲线族，确认在最低输入电压加满载时增益余量足够、在最高输入电压加轻载时曲线还能降得回来。**整个流程像在地图上给工作点铺路——路的每一段都必须落在 ZVS 区。**

它的兄弟还有：**准谐振变换器（QR）**只在一个开关周期里插一段谐振脉冲，兼得硬开关的简单与软开关的低损耗；**移相全桥**在大功率场合用相位差实现 ZVS。谐振家族枝繁叶茂，但底层逻辑只有一句：**用谐振网络控制开关时刻，让电压电流错峰相遇。**

谐振变压器还有一道「磁学」上的功课：漏感不再是「副作用」而是电路参数本身——LLC 恰恰把变压器漏感当作谐振电感 $L_r$ 用。绕组结构、磁芯气隙、层间分布电容都直接参与 $L_r$、$L_m$、$C_r$ 的取值，所以谐振电源的变压器必须与主电路一起联调，单独「绕一个变压器」的思路在这里不成立。设计表格里标出的 $L_r$、$L_m$ 是「电路值」，工程上还要经过反复试绕与实测才能落实成磁芯与匝数。

**谐振变换器的应用地图**（也是它「值得一学」的明证）：
- 手机快充（20–240 W）：LLC / 准谐振反激，效率做到 93–95%；
- 服务器与数据中心电源（0.5–3 kW）：LLC 稳压 + 高功率密度；
- 电动汽车车载充电机（3–22 kW）：LLC + 移相全桥，兼顾隔离与 ZVS；
- 荧光灯与 LED 电子镇流器：串联谐振点灯，天然软开关；
- 感应加热（kW–MW）：电流型谐振逆变器，输出功率靠频率调节；
- 医疗 X 光机电源：高压准谐振，减小变压器与电容体积。

**什么时候该上谐振**（一句话判断）：
- 要高频小型化 → 谐振几乎是必经之路；
- 要软开关 + 高效 → 谐振的正菜；
- 成本敏感、功率不大 → 硬开关 PWM 仍然够用。

谐振是手段，不是目的——用对了是利器，用错了是负担。

## 5 小结

- 谐振变换器用 **LC 谐振网络**把开关波形「正弦化」，让开关在 ZVS/ZCS 时刻开合，$E_{sw}\to 0$。
- 软开关的两把钥匙：**ZVS**（开通前电压为零，抗杂散电容）与 **ZCS**（关断前电流为零，治拖尾电流）。
- 串联谐振增益 $M = 1/\sqrt{1+Q^2(\omega_n - 1/\omega_n)^2}$：共振点增益恒为 1，失谐后下降，Q 越大曲线越尖。
- 谐振变换器**调频不调宽**（PFM），与 PWM 是两条控制路线。
- LLC 把两个电感合并，全负载区 ZVS、增益两段可调，是开关电源领域当前的主角。
- 软开关不是免费的：轻载时谐振能量不足会「软不了」，需要脉冲跳周期等对策。
