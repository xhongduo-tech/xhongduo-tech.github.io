## 为什么从封装与制造开始

第十篇讲完「光从哪来」，这一篇讲「光怎么进出芯片、芯片怎么造出来」。硅光的**制造**复用 CMOS 工业，这是它的立身之本；但光学又提出了 CMOS 没有的新要求——**怎么把光高效地送进/送出那个 220nm 的波导**。光栅耦合器与边缘耦合器，就是硅光的「门」；晶圆级测试，则是保证量产「门门都好」的手段。<span class="marginnote">这一篇对应 Chrostowski & Hochberg 一书的第5章《Optical I/O》——光输入输出是全书最「工程」的一章。耦合器不是花哨的光学器件，而是决定一颗芯片能否与光纤世界对话的接口，也是第七篇 CPO、第十篇光源落地的物理接缝。</span>

## 1 光栅耦合器：让光垂直进出

**光栅耦合器（grating coupler）**把波导里的光「弯折」到垂直方向，让光可以从芯片表面垂直进出——配合光纤阵列或探针，实现垂直耦合。<span class="marginnote">为什么有人愿意走「弯折」这条路？因为<strong>垂直耦合的位置可以放在芯片任何地方</strong>，测试探针能直接扎在任意端口上，晶圆级测试（本节约后文）也因此成为可能——这是光栅耦合器最大的工程价值。</span>

它的物理是**布拉格衍射**：波导表面的周期性光栅把导模「衍射」出表面。设计光栅的周期、占空比、刻蚀深度，就能让衍射方向对准想要的角度，把光「放」进或「接」出波导。

给一个量级感受：对 1550nm 波长、标准 220nm 硅波导，光栅周期通常在 **600–650nm** 附近，占空比约 0.5，浅刻蚀深度几十到一百多纳米。**这些数字是「波长、波导、出射角」三者共同解出来的**——用第5节的布拉格条件就能算，这也是硅光设计者「手算第一式」的经典练习。

典型性能：耦合效率约 **-1 至 -3 dB**（即 50%–80% 的光能进出），3 dB 带宽数十纳米。够用，但不是无损——这 1–3 dB 就是第十篇说的「外部光源方案多付的过路费」——而且带宽有限，对 WDM 多波长系统可能偏窄。于是有了第二条路线。

光栅设计本身也是门学问：**匀幅光栅**效率高但有旁瓣（背向反射），**切趾光栅（apodized）**通过渐变占空比抑制旁瓣、牺牲一点峰值效率；有的光栅倾斜刻蚀（blazed）以压低二阶衍射。**「效率、带宽、旁瓣、工艺难度」四者在光栅里互相拉扯**——它只是一个小器件，却是硅光「工程即权衡」的浓缩样本。<span class="marginnote">一个值得一提的细节：光栅耦合器常被「复用」为片上光源耦合口（第十篇外部光源）、测试探针口（本节晶圆测试）、以及光纤对接口——<strong>同一个器件，身兼三职</strong>。这也是为什么硅光设计者格外珍视光栅的灵活性。</span>

## 2 边缘耦合器：端面直接对接

**边缘耦合器（edge coupler）**不做「弯折」，而是把波导一直延伸到芯片端面，让光**水平方向**直接耦合进/出——类似「接口对齐」。典型实现是**倒锥（inverse taper）**结构：波导端面逐渐变窄，让光场从束缚态「散开」到更大尺寸，与光纤或片上透镜的模式匹配。<span class="marginnote">倒锥的原理回看第二篇「全内反射关住光」：波导越窄，对光的束缚越弱，光场越向外散——在端面处把模式「撑大」到与光纤相近，耦合损耗就低了。用「越窄越漏」的反直觉设计，换来「模式匹配」的高效率。</span>

边缘耦合的优点是**效率高（-0.5 至 -1 dB）、带宽大**（对波长不敏感，天然支持 WDM），缺点是**必须端面抛光、耦合位置固定在芯片边缘、对准精度要求极高**——它不能像光栅那样「放哪儿都行」。两条路线一对比，就显出工程的味道：**光栅图方便与测试友好，边缘图性能与带宽**。

倒锥之外，边缘耦合还常配**片上透镜**（或锥形模式转换器）把光场进一步整形，再对接光纤；对准精度要到亚微米级，靠**主动对准（active alignment）**——通电发光、实时微调位置到耦合效率最大再固定。**「主动对准」是封装线上最耗时的一步**，也是 CPO（第七篇）把「光电封装」做成产业的核心工艺之一。<span class="marginnote">主动对准的成本，正是光模块贵的隐形原因之一——它要求高精度运动平台与实时监测，一颗一颗地调。这也是「越往芯片里走，封装越贵」的注脚。</span>

## 3 硅光制造：300mm 与 CMOS 兼容

硅光制造的全部叙事，是「复用半导体大工业」。一枚硅光芯片用**300mm SOI 晶圆**生产，工序与 CMOS 高度重合：深紫外（DUV）光刻定义图形，干法/湿法刻蚀做波导与光栅，沉积、注入、金属化做电极与调制器。<span class="marginnote">与逻辑芯片的差别在于「光学对几何极其敏感」：波导宽度差 10nm，折射率、色散、耦合效率都会变。CMOS 的工艺窗口是为电学设定的，硅光要在同一套窗口里守住光学指标——这是制造端最大的摩擦。</span>

代表性量产平台：格芯 **Fotonix**（300mm 硅光 + 晶体管同片，Lightmatter 使用）、台积电路线（与 COUPE 光引擎、3nm 逻辑封装结合）。**「有代工、才能量产」**——这是硅光区别于任何实验室光学的根本，也是第五、七、八篇反复出现的「产业底座」。

材料上还有一位常被忽略的成员：**氮化硅（SiN）**。它的折射率（约 2.0）低于硅，传播损耗更低、非线性更小、可见光波段也能用，适合做低损耗波导、滤波器和无源光路；缺点是难以调制（没有成熟的载流子色散）。于是出现了「硅 + 氮化硅」的**异构无源/有源混合平台**：硅做有源器件，SiN 做低损耗路由，各取所长。<span class="marginnote">SiN 的低损耗（可到 0.1 dB/cm 量级）让超长光延迟线、高 Q 谐振器成为可能——这与第九篇储备池的「延迟线换维度」直接相关。平台选择，又一次是「按器件分工」的问题。</span>

刻蚀工艺是硅光制造的「刀工」：**部分刻蚀（浅刻蚀）**做光栅与弱耦合结构，**全刻蚀（深刻蚀）**做波导侧壁。侧壁粗糙度直接决定波导散射损耗（侧壁越糙、损耗越大）——这是硅光对工艺洁净度与刻蚀平整度提出「超 CMOS 标准」的地方。**「同一条产线，电学放松、光学较真」**，是硅光制造最贴切的写照。<span class="marginnote">散射损耗的机理：波导侧壁的微观粗糙让光发生随机散射，等效于「光漏出波导」。粗糙度从几纳米降到亚纳米，损耗可以差一倍以上——所以硅光工艺对刻蚀条件的控制，比逻辑芯片还要挑剔。</span>

## 4 晶圆级测试与良率

一颗芯片从晶圆到成品，中间最关键的一步是**测试**。电子芯片的晶圆级测试靠电探针；硅光芯片的测试多了一道**光**——探针台上的光学探针要把光打进光栅耦合器（这就是光栅「任意位置可测」价值兑现的地方），同时电探针驱动器件，测出耦合效率、调制响应、探测器灵敏度等全套光学指标。<span class="marginnote">「电测 + 光测」并行是硅光量产测试的常态：一次扎针，电学参数与光学参数一起出来。测试结果直接决定<strong>良率</strong>——光学指标不达标就是废片，而光学对工艺涨落的敏感，让硅光的良率控制比纯电芯片更严苛。</span>

具体测什么？一组硅光测试清单大致包括：**波导传播损耗**（切一列长度渐变的波导，用损耗斜率外推）、**耦合器效率**（标准参考结构对比）、**调制器响应**（眼图与消光比）、**探测器响应度与带宽**、**微环共振波长与 Q 值**。每一项都对应一条「工艺涨落」的探测线——**测试不只是验货，更是反向标定工艺**。<span class="marginnote">这条「测—改」的反馈链，与电子芯片的「设计—制造—测试—改进」迭代是同一套方法论，只是光学多了「波长、相位、效率」这些电学没有的维度。理解硅光的测试，就是理解「光学版的工艺控制」。</span>

**良率是硅光量产的经济学核心。** 一颗光计算芯片动辄几万个相位调谐器、几百个耦合器，任何一个关键器件不达标都可能让整片作废。这也是为什么硅光设计越来越强调**工艺容差（robustness）**：让器件对 ±10nm 的几何涨落不敏感，比追求「极端最优但脆弱」更值钱——**「能稳定量产」与「理论最优」之间，量产永远赢。**

测试的**吞吐**同样决定成本：一次光学扎针通常要几十秒到几分钟，比纯电测试慢一个量级。于是测试工程在「测试内容」与「测试速度」之间做取舍——只测关键参数、用并行探针、把可离线算的留到仿真。**「测什么、怎么快」是硅光测试的一门隐形工程学**，它直接决定每颗芯片的测试成本，进而决定光计算能否规模化。

硅光制造还有一个电子芯片很少碰到的问题：**光学器件无法轻易「修复」**。电芯片有冗余逻辑、可编程修复；光的相位调谐器虽然可以热调校正一部分漂移，但耦合器、波导的几何偏差是「出厂即定」的。于是「设计—制造—测试」必须形成一个闭环：**测试结果反馈回设计，下一版光罩修正工艺敏感点**——硅光的良率提升，靠的是一代代「测—改」迭代，而非一蹴而就。<span class="marginnote">这个「测—改」闭环，正是第九篇「储备池在线训练对齐硬件」思想在制造层面的镜像：无论器件多难复现，只要「测出来、改回去」，系统就能收敛。工程的一切，都是闭环的艺术。</span>

## 5 公式解析：光栅耦合的布拉格条件

光栅耦合器的核心方程是**布拉格条件**，它决定衍射光往哪个方向走：

$$\frac{2\pi}{\Lambda} = \beta - k_0 \sin\theta, \qquad \beta = \frac{2\pi n_{eff}}{\lambda}$$

三步拆解：

- **第一步，读符号**：$\Lambda$ 是光栅周期，$\beta$ 是波导导模的传播常数（由有效折射率 $n_{eff}$ 决定），$k_0 = 2\pi/\lambda$ 是真空波数，$\theta$ 是出射角（相对表面法线）。
- **第二步，看机理**：周期性光栅给波导的传播常数「加上」了一个动量 $2\pi/\Lambda$，把导模「踢」到自由空间——**光栅的本质是动量补偿器**，把波导里「太大」的传播常数，靠光栅动量补足后变成可辐射的自由空间波。
- **第三步，读设计**：给定波长与想要的出射角，就解出需要的周期 $\Lambda$——这是光栅耦合器设计的起点。**改变 $\Lambda$、$n_{eff}$ 或 $\theta$，就能把耦合角「调」到与光纤/探针匹配。**<span class="marginnote">布拉格条件还能解释光栅耦合器的「波长敏感性」：$\beta$ 随波长变化，$\Lambda$ 固定，所以只有特定波长能严格满足条件——这就是光栅带宽有限（数十纳米）的物理根源，也解释了为何边缘耦合（无光栅、无衍射）带宽天然更宽。</span>

布拉格条件是「第一式」，真实的耦合器设计还要靠**数值仿真**：有限时域差分（FDTD）或本征模展开（EME）方法，把光栅的每一小段光场演算出来，迭代优化占空比、刻蚀深度与切趾曲线。**「先手算得方向，再仿真得细节」**——这是硅光器件设计的标准工作流，也与第9章《Photonic Circuit Modelling》把器件级仿真与系统级建模衔接的做法一脉相承。<span class="marginnote">从「手算布拉格条件」到「FDTD 全波仿真」，再到「紧凑模型电路仿真」，是一条「粗到细」的设计链。这篇讲的是制造端，但设计端的这条链，正是第八篇提到的「设计—制造—测试」闭环的起点。</span>

一个工程细节：光纤与芯片表面不是垂直的，通常倾斜 8°–15°（**倾斜角设计**），目的有两个——把背向反射（二阶级联衍射）抑制掉，以及方便光纤夹具的机械布置。**「出射角」看似小，却同时影响效率、反射与封装机械设计**——光栅耦合的每个设计数字，背后都绑着封装层面的现实约束。<span class="marginnote">倾斜角还解释了为什么光栅耦合器对<strong>偏振</strong>敏感：光栅衍射条件通常只对一个偏振（TE）优化，另一个偏振（TM）效率骤降。所以硅光芯片往往要配<strong>偏振分离旋转器（PSR）</strong>，把随机偏振的光「摆正」后再耦合——这又是一层光栅特有的工程成本。</span>

## 6 核心对比表：光栅耦合 vs 边缘耦合

| 维度 | 光栅耦合器 | 边缘耦合器 |
| --- | --- | --- |
| 耦合方向 | 垂直（表面进出） | 水平（端面进出） |
| 耦合效率 | -1 至 -3 dB | -0.5 至 -1 dB |
| 带宽 | 数十纳米（布拉格敏感） | 宽（对波长不敏感） |
| 位置灵活性 | 任意位置 | 必须芯片边缘 |
| 测试友好 | 极好（探针直扎） | 差（端面处理复杂） |
| 端面工艺 | 无需特殊处理 | 需抛光/透镜 |
| 适用 | 晶圆级测试、多端口 | 高性能、WDM、光纤对接 |

这张表的读法：**光栅耦合 = 测试与集成便利优先，边缘耦合 = 性能与带宽优先。** 一颗量产硅光芯片常常两种都用——晶圆级测试用光栅，最终产品用边缘耦合，各取所长。**「一颗芯片两套门」**，就是硅光对「测试 vs 性能」这对矛盾最务实的回答。

多路并行时，光纤不能一根根接——用**光纤阵列（fiber array）**把一排光纤粘到芯片边缘，一次对准、同步耦合几十上百路。阵列的制造与贴装精度（间距、角度、端面）是封装工艺的硬功夫，也决定了 CPO（第七篇）那种「几十路光进出一颗封装」的工程能不能成立。<span class="marginnote">光纤阵列把「一颗一颗对准」变成「一片一起对准」，是封装吞吐的关键一跃。它与第4节「并行光测」的思路完全同构：**能并行就不串行**——这条朴素原则，贯穿硅光制造与封装的每一个环节。</span>

封装层面还有最后一块拼图：**从单芯片到系统**。光引擎要接到光纤（光纤阵列）、接到激光（RLM）、接到电系统（再流焊、引线键合），每一步都在消耗损耗与预算。第七篇 CPO 把光引擎与交换芯片共封，本质就是「把封装层级的每一次耦合都尽量缩短」。**硅光的成本结构里，封装常常比芯片本身还贵**——这颗「能稳定量产」的芯片，最后一段路是封装线走完的。

## 7 小结

- 光栅耦合器用布拉格衍射让光垂直进出：效率 -1 至 -3 dB、带宽数十纳米、位置任意、测试友好。
- 边缘耦合器用倒锥模式匹配水平对接：效率 -0.5 至 -1 dB、带宽大、需端面抛光与精确对准。
- 布拉格条件 $\frac{2\pi}{\Lambda} = \beta - k_0\sin\theta$ 决定衍射方向，也解释光栅的波长敏感性。
- 硅光制造复用 300mm CMOS：格芯 Fotonix、台积电路线，工艺容差决定良率。
- 晶圆级测试 = 电探针 + 光探针并行，良率是量产经济学的核心。
- 量产永远赢过理论最优：**「能稳定量产」比「极端最优但脆弱」更值钱。**
- 光栅耦合器身兼三职（光源口/测试口/光纤口），倾斜角与偏振敏感是它的工程附加成本。
- 硅光成本结构里封装常比芯片还贵：芯片的最后一段路是封装线走完的。
- 1550nm 光栅周期约 600–650nm，是波长、波导、出射角三者的共同解。
- 硅 + 氮化硅异构平台：硅做有源、SiN 做低损耗路由，按器件分工。
- 测试吞吐是隐形成本：光测比电测慢一个量级，「测什么、怎么快」决定规模化。
- 一句话收束：**硅光的制造，是把「光学较真」塞进「CMOS 快产线」的平衡艺术。**
- 记忆锚点：光栅 = 方便与测试，边缘 = 性能与带宽；一颗芯片两套门。
- 光纤阵列让「一颗一颗对准」变成「一片一起对准」，是封装吞吐的关键一跃。
- 联系全站：制造与封装是光计算产业化的最后一道门，也是第八篇「从论文到产品」的物理门槛。
- 一句话：**光栅与边缘是光的「门」，良率与封装是光计算的「命门」。**
