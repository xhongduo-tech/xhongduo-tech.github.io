## 为什么从无人机数据处理流程开始

第8篇让无人机「拍完了」，但几百张照片本身还不是成果。把这些影像变成 DEM、DOM 与三维模型的那条流水线，就是本篇的**无人机数据处理流程**。它的骨架是 SfM（Structure from Motion，运动恢复结构）+ MVS（多视图立体匹配）——一套从计算机视觉「长」出来的算法族，却与第5篇经典空三在数学上同源。<span class="marginnote">理解这条流水线，是理解「为什么无人机航测能对非量测相机也能出精度」的钥匙：SfM 用影像自身完成定向，POS/GCP 负责绝对定位，二者缺一不可。</span>本篇把每个环节拆开讲清，你会获得对「一键出成果」背后机制的第一手认识。

## 1 一条流水线：从影像到产品

无人机数据处理的完整流程，可以浓缩成下面八步：

1. **影像导入与质检**：剔除模糊、过曝、曝光异常影像，记录 POS 数据；
2. **特征提取**：在每张影像上检测特征点（SIFT/ORB），生成描述子；
3. **特征匹配**：跨影像寻找同名特征点，用 RANSAC 剔除误匹配；
4. **初始重建（SfM）**：从匹配关系估计相机位姿与稀疏点云；
5. **光束法平差**：对全体相机位姿与稀疏点做联合精化（第5篇的算法）；
6. **地理配准**：用 GCP 或 RTK/PPK 观测把模型转换到地面坐标系；
7. **密集匹配（MVS）**：为每个像素生成深度，融合成稠密点云；
8. **产品生成**：点云滤波 → DEM/DOM，网格重建 → 三维模型、纹理。

每一步的质量都会向下游传递：特征匹配的误匹配会污染位姿估计，位姿误差会让密集匹配出现空洞，点云滤波的错误会直接反映到 DEM 上。<span class="marginnote">这条「误差向下游放大」的链条，是无人机数据处理与经典摄影测量完全一致的宿命——所以每个环节都有相应的质量检验，而不是「跑完一个软件就行」。</span>

## 2 特征提取与匹配：SfM 的第一站

无人机影像往往同时拍摄几万张、每张数千万像素，靠什么在两两之间找到同名点？答案是**局部特征**——能在光照、尺度、视角变化下保持稳定的显著点（角点、斑点）及其描述子。

**尺度不变特征变换（SIFT）**是 SfM 的黄金标准：它在影像金字塔上检测极值点，为每个点计算 128 维梯度方向直方图描述子，再靠描述子间的最近邻距离匹配。SIFT 对缩放、旋转、光照变化高度鲁棒，但计算量较大；**ORB** 等二进制特征更快，适合实时场景，但鲁棒性略逊。<span class="marginnote">第六级《计算机视觉》会详细讲 SIFT/Harris/ORB 的机理。这里只需记住一句：特征匹配的鲁棒性，决定了 SfM 的成败——而鲁棒性的关键，是描述子的「区分度」与误匹配剔除（RANSAC）的彻底性。</span>

匹配之后，每一对同名点都给出一条**几何约束**：由本质矩阵（或基础矩阵）约束的核线关系。用 RANSAC 从海量候选匹配中稳健估计本质矩阵、同时剔除误匹配（外点），是 SfM 从「噪声海洋」里提纯的第一步。

## 3 SfM 运动恢复结构：从二维到三维

**核心概念——运动恢复结构（Structure from Motion, SfM）**：仅从一组二维影像及其特征匹配，同时恢复每张影像的相机位姿（外方位）与场景的稀疏三维点云。它不需要任何已知的三维点——相机与场景的结构「互为支撑」地被解出来。

主流的**增量式 SfM（incremental SfM）**流程分四步：

1. **选初始像对**：选择匹配最丰富、基线合理的两张影像，用本质矩阵估计相对位姿，三角化出初始稀疏点；
2. **逐张注册**：用 PnP（Perspective-n-Point，n 点透视）估计新影像的位姿，把已有三维点投影到新影像求匹配；
3. **三角化新点**：为新影像中新出现的三维点建立坐标；
4. **光束法精化**：每加入一批影像就做一次全局光束法平差，抑制漂移。

增量式 SfM 是「吃一点、校正一点」的策略——它从一对影像出发不断扩张，靠频繁的全局平差把累积误差压住。<span class="marginnote">增量式 SfM 的经典实现是 Noah Snavely 2006 年的 Photo Tourism 系统（后来成为开源工具 Bundler），它让「互联网照片重建三维场景」成为现实，也为无人机三维重建铺平了算法道路。</span>

## 4 光束法平差与尺度问题

SfM 解出的相机位姿与点云，质量好不好由**光束法平差（bundle adjustment）**说了算。它和第5篇讲的光束法区域网平差是同一个东西——把第3篇的共线方程写成重投影误差的最小化问题，对全部相机位姿与三维点联合优化。SfM 版的差别只是：相机参数（焦距、畸变）也常作为未知数参与自检校。

由此带出 SfM 的两个「先天性格」：

**尺度歧义（scale ambiguity）**：从纯影像出发，SfM 只能确定「形状」，不能确定「大小」——同样的几何，放大两倍或缩小两倍都能满足影像观测。要固定尺度，必须靠外部信息：已知长度的物体、GCP 或 GNSS 提供的绝对位置。

**参考系任意（arbitrary reference）**：SfM 输出的点云悬浮在一个任意坐标系里（常以初始像对为基准），方向与位置都「自由」。把它转到地面坐标系，就是下一步地理配准的任务。<span class="marginnote">这两点再次印证第4篇的结论：相对定向定形状、绝对定向定位置。SfM 的「相对部分」完全自动，而「绝对部分」依赖 GCP/POS——理解了分工，就不会再问「为什么免像控也要 RTK」。</span>

## 5 密集匹配：稀疏点云变稠密

SfM 产出的只是稀疏点云（每张影像几十到几百个特征点），远不够做 DEM 与三维模型。**密集匹配（dense matching / MVS）**为每个像素估计深度，把稀疏点云加密成稠密点云。

**半全局匹配（Semi-Global Matching, SGM）**是当下最流行的立体/密集匹配算法，由 Hirschmüller 在 2008 年提出：它对每个像素在多个方向（上、下、左、右）做路径代价聚合，求使总匹配代价最小的视差。SGM 在精度与效率之间取得了极好的平衡，是无人机摄影测量密集匹配的事实标准。<span class="marginnote">MVS 的另一条主流是「视锥相交 + 灰度一致性」（如 patch-based MVS），对近景与城市场景更稳健；两种路线在工程上常并用、互补。</span>

密集匹配的输出是每张影像的**深度图**，再经多视角深度融合（深度图 → 点云）、点云去噪与滤波，就得到可用于 DEM 与建模的稠密点云。

## 6 地理配准：把模型钉到地面坐标系

SfM 的成果还是一个任意坐标系下的几何体，**地理配准（georeferencing）**把它转成地面坐标。两条路线：

**间接（GCP）路线**：测区布设若干地面控制点，在影像上人工/半自动标出 GCP 的像点，用第4篇的七参数相似变换把点云与位姿转换到控制点所在的坐标系，同时做检校。精度高、可控，但需要外业。

**直接（POS）路线**：利用 RTK/PPK 记录的摄影中心坐标与姿态，直接把 SfM 位姿对齐到地面系。免像控、快，但依赖 POS 精度与相机/IMU 的相对标定（检校杆臂与视准轴）。

**辨析｜易错点：** 免像控不等于「零检核」。无论哪条路线，项目验收都要求布设**检查点**独立核验——免像控作业尤其要抽查，因为 POS 的整体偏移（如高程系统差）只有检查点能暴露。**地理配准的「最后一道关」，永远是独立检查点**。

## 7 公式解析：重投影误差

光束法平差的目标函数，是把所有三维点投影回影像与真实像点的偏差压到最小，即**重投影误差（reprojection error）**最小化：

$$
\min_{\{R_i, t_i, P_j\}} \sum_{i,j} \left\| \pi\left(K_i, R_i, t_i, P_j\right) - p_{ij} \right\|^2
$$

- **第一步，认识符号**：$K_i, R_i, t_i$ 是第 $i$ 张影像的内参、旋转、平移（相机位姿）；$P_j$ 是第 $j$ 个三维点；$p_{ij}$ 是该点在影像 $i$ 上的实际像点；$\pi(\cdot)$ 是投影函数（相当于第3篇共线方程的紧凑写法）。
- **第二步，理解投影**：$\pi(K, R, t, P)$ 把三维点先做刚体变换 $(R P + t)$，再经内参 $K$ 投影到像平面——这就是共线方程的矩阵形式。
- **第三步，理解最小化**：目标是让「预测的像点」与「观测的像点」在所有影像、所有点上尽量重合。残差是**像素单位**的二维距离，通常用鲁棒核（如 Huber）抑制粗差影响。
- **第四步，看规模与解法**：无人机 500 张影像、20 万个三维点，未知数约 60 万、残差数百万——靠稀疏结构、分块消元与迭代（LM 算法）求解，这正是第5篇讲的那套大规模稀疏最小二乘的实战形态。

直觉上：**重投影误差把「所有相机位姿 + 所有三维点」放进一个目标函数里互相校验**，让最终解满足「每个点都能被它的影像以最小误差一致地看到」——这就是 SfM 与经典空三殊途同归的数学核心。

## 8 核心对比表：SfM 流程与经典空三

| 对比项 | 经典解析空三 | SfM 流程 |
| --- | --- | --- |
| 同名点来源 | 人工/半自动立体观测 | 特征匹配全自动 |
| 相机参数 | 已检校 | 自检校（未知数） |
| 初始值 | POS/手工给定 | 从初始像对自动建立 |
| 平差 | 光束法 | 光束法（同源） |
| 尺度与坐标 | 控制点直接定义 | GCP/POS 事后配准 |
| 对相机要求 | 量测相机 | 普通相机即可 |
| 典型软件 | 传统航测工作站 | Metashape、Pix4D、ContextCapture、openMVG |

**辨析｜易错点：** SfM 并不是「取代」了经典空三，而是把经典空三的**同名点获取与定向自动化**了。两套流程共享共线方程、光束法与七参数配准的数学内核，差别在「人做多少、算法做多少」。这正是本专题想传达的：**无人机数据处理没有发明新几何，只是把旧几何「武装」到了自动化**。

## 9 小结

- 无人机数据处理八步流水线：**质检 → 特征 → 匹配 → SfM → 平差 → 配准 → 密集匹配 → 产品**，误差逐级向下游放大。
- SfM 用**特征匹配 + 增量式重建**同时恢复位姿与稀疏点云，靠 RANSAC 剔除误匹配、光束法压漂移。
- SfM 有**尺度歧义与参考系任意**两大性格，必须靠 GCP 或 POS 地理配准补全绝对信息。
- **密集匹配（SGM/MVS）**把稀疏点云加密成稠密点云，是 DEM 与三维模型的原料。
- 地理配准分 **GCP 间接** 与 **POS 直接** 两条路线，独立检查点永远是验收的最后一道关。
- 重投影误差是 SfM 平差的目标函数，与经典空三共线方程完全同源。

在下一节，我们把密集点云继续推进成可看、可用的**实景三维模型**：倾斜摄影测量、三维重建与模型精修——这就是《实景三维建模》。
