## 为什么从油气储运工程开始

这个专题回答一个看似朴素的问题：**地下采出的油气，是怎么到达炼油厂、城市燃气站和千家万户的？** 油气田在西部荒漠，炼化企业在沿海城市，中间隔着数千公里——把「生产」与「消费」连起来的那段产业链，就是**油气储运（oil and gas storage and transportation）**。它与已学的《石油与天然气工程》（钻井、采油）衔接：采出地面只是起点，储运才是让油气真正进入社会流通的通道。在「从极限到大模型」的知识树上，这一专题把流体力学的管流理论、工程热力学的温降计算、材料科学的强度与腐蚀分析，全部落到一套真实的工业系统上。<span class="marginnote">全课程主线的《流体力学》讲动量方程，这里讲它如何变成一条 4000 公里管道的泵站间距；《材料力学》讲应力，这里讲它如何决定 12 毫米厚的管壁。</span>

## 1 储运系统的构成

**油气储运（oil & gas storage & transportation）**：把石油、天然气及其产品从产地输送到加工与消费地，并完成储存、装卸、调配的全部工程活动。一套完整的储运系统由四类设施组成：

- **油气田集输系统**：把井口产物（油、气、水混合）收集、分离、处理，形成合格的原油与天然气——这是储运链的入口。
- **长输管道**：跨省区、跨国界的大动脉。干线管道按输送介质分**原油管道、成品油管道、天然气管道**三类。
- **储库与油库**：储备、调峰、周转的节点。包括油田油库、炼厂油库、销售油库、国家战略储备库、LNG 接收站与地下储气库。
- **分配与销售管网**：城市燃气管网、加油站配送等，把能源送到末端。

**运输方式的比较**是理解管道地位的第一课。对大宗液态烃类，管道、铁路、公路、水路四种方式中：管道建设一次性投资大，但**运营成本最低、损耗最小、受气候影响小、不产生二次污染**，适合连续稳定的大流量运输；铁路与公路灵活但单位能耗高、安全风险大；水路最便宜但受航道限制。<span class="marginnote">美国原油管道干线约 10 万英里，天然气管网约 30 万英里，是世界上规模最大的管道运输网；中国原油管道约 3.5 万公里，天然气管网超 11 万公里，且仍在快速增长。</span>国际经验表明，**当运输距离超过 300–500 公里、年运量足够大时，管道几乎总是最优解**——这就是为什么西气东输、中俄东线这类巨型工程非管道莫属。

## 2 中国储运工业的历史脉络

把真实历史读进工程，比记任何结论都有用：

- **1939 年**，甘肃玉门油矿（老君庙）建成我国第一条原油管道，长 4 公里，把原油从井场送往炼厂，从此中国有了自己的管道工业雏形。
- **1958 年**，新疆克拉玛依—独山子输油管道建成，长 147 公里，是新中国成立后第一条长输原油管道。
- **1970–1975 年「八三工程」**：大庆原油外运需求迫切，国家组织建设大庆—铁岭—秦皇岛等东北输油管网，几年内建成东北原油管网主干，管径 720 mm 级，是我国长输管道工业的一次大跃进。
- **2004 年**，西气东输一线投产，全长约 4000 公里，把塔里木盆地的天然气送到上海，标志着中国天然气管道进入骨干网时代。
- **2019 年**，中俄东线（黑河—上海）投产，管径 1422 mm，压力 12 MPa，是当时世界单管输量最大的天然气管道之一。

这条脉络说明一件事：**管道工业从来与国家能源安全、工业化进程绑定**。理解了历史，才能理解为什么今天要讨论智慧管道与氢能管道——它们都是同一逻辑的延续。<span class="marginnote">1984 年《输油管道设计与管理》作为石油高校统编教材出版，严大凡主编，此后成为我国输油管道工艺设计的标准蓝本——本专题「输油」部分的全部工艺逻辑都以此为准绳。</span>

## 3 油品性质基础：储运设计的输入量

储运设计的每一项计算，都以油品的**物性数据**为输入。核心物性如下：

| 物性 | 定义 | 对储运工艺的影响 |
| --- | --- | --- |
| 密度与相对密度 | 单位体积的质量 | 决定体积计量、泵的吸入能力 |
| 粘度 | 内摩擦阻力的度量 | 决定摩阻、泵站间距 |
| 凝点 | 失去流动性的温度 | 决定是否需加热输送 |
| 含蜡量 | 蜡晶析出的质量分数 | 决定低温流变性与降凝策略 |
| 饱和蒸气压 | 液面上方蒸气的平衡压力 | 决定挥发损耗与密闭输送 |
| 闪点 | 蒸气遇火闪燃的最低温度 | 决定储运安全等级 |

其中**密度**常用 API 重度表示，与相对密度 $d$ 的关系是：

$$
\text{API} = \frac{141.5}{d_{15.6^\circ\text{C}}} - 131.5
$$

**API 重度越大，油越轻**：轻质原油 API 常在 35–45，重质原油可低至 10 以下。<span class="marginnote">「轻」「重」不是物理轻重，而是指组成中轻组分（汽油馏分）多少。API 度每差 10，国际油价基准 Brent 与 WTI 的价差都会波动，因为密度决定了炼厂加工成本。</span>而**含蜡原油**的粘度随温度下降急剧上升，凝点附近出现屈服应力——这正是本专题第 4 篇《热油管道输送工艺》要重点处理的难题。

## 4 公式解析：API 重度与相对密度的换算

这条公式是储运计量的「汇率表」，拆开看三步：

- **第一步，理解相对密度 $d_{15.6}$**：它是 15.6°C（60°F）下油品密度与同温度纯水密度之比，无量纲。原油密度 0.80–0.95 即指 $d$ 在此区间。
- **第二步，看换算系数 141.5 与 131.5**：这两个常数由美国人定义，保证水的 API = 10.0，且 API 与 $d$ 呈反比——油越轻 $d$ 越小，API 越大。Brent 约 38，WTI 约 39.6，重质油（如加拿大油砂稀释沥青）约 20。
- **第三步，反解**：$d = 141.5/(\text{API}+131.5)$。已知 API 可反求密度，工程计量表上常常就靠这一式互查。

**辨析｜易错点：** API 重度是**温度的函数**，标准温度 15.6°C 必须注明；且它只反映密度，不反映粘度——两个 API 相同的油，粘度可能差 10 倍，所以本专题后续所有水力计算都以粘度为第一输入。<span class="marginnote">密度、粘度、凝点、含蜡量构成原油「储运特性四件套」，本专题第 2、3、4 篇将分别把粘度、凝点、流变性变成定量公式。</span>

## 5 储运工程的核心矛盾与设计主线

把整个专题的地图铺开，储运工程围绕三条主线展开：

- **水力主线**：管流摩阻决定泵站/压缩机站布置——对应第 2、3、6 篇。
- **热力主线**：温度决定流变性与能耗——对应第 4 篇热油管道。
- **安全主线**：强度、腐蚀、运行管理决定寿命与可靠性——对应第 7、8、12 篇。

三条主线共同服从一个目标函数：**在保证安全与油品质量的约束下，使单位输送成本最低**。中国成品油长输管道输油成本通常仅铁路的 1/2 到 1/3，靠的就是大规模、低摩阻、密闭连续输送。<span class="marginnote">「密闭输送」是成品油管道的主流：全线泵站与管线连成一体、无中间敞口罐，减少油气挥发损耗，也避免与空气接触——第 3 篇水力计算全部建立在密闭系统假设之上。</span>

本节把储运常用术语速查收尾，供后续各篇直接引用：

| 术语 | 含义 | 首次出处 |
| --- | --- | --- |
| 干线管道 | 连接产地与终端的长距离主管道 | 本篇第 1 节 |
| 泵站/压缩机站 | 为克服摩阻提供压能的站点 | 第 3、6 篇 |
| 密闭输送 | 全线无中间敞口罐的输送方式 | 本篇第 5 节 |
| 翻越点 | 沿程最高点，限制水力工况的咽喉 | 第 3 篇 |
| 混油段 | 顺序输送时两种油品的掺混段 | 第 5 篇 |
| 完整性管理 | 对管道风险的系统化管理 | 第 12 篇 |

## 6 天然气：另一种储运逻辑

天然气与原油的储运逻辑截然不同，值得单独一章来说清：

- **气体必须被压缩或液化才经济**：天然气的临界温度约 −82°C，常温下无法液化，因此陆上长距离输送一律采用**高压气态管道**（干线压力 6–12 MPa），跨海与远洋贸易则采用 **LNG**（−162°C 液化，体积缩小约 600 倍）。
- **输送介质的状态方程不同**：输油算的是不可压缩液体，输气算的是可压缩气体——密度随压力、温度变化，流量公式完全不同（第 6 篇《输气管道工程》专门处理）。
- **储存方式不同**：原油储存用地面常压储罐；天然气的调峰储存用**地下储气库**（枯竭油气藏、盐穴、含水层）和 LNG 储罐，因为高压气罐单位容积成本过高。
- **安全特性不同**：天然气比空气轻、泄漏后向上扩散，爆炸极限 5%–15%；LPG 则比空气重、易在地面积聚——消防与检测策略也因此分野。<span class="marginnote">中国天然气消费量在 2023 年约占一次能源消费的 8%–9%，对外依存度约 40%，其中管道气与 LNG 进口大体各半——这解释了为什么储气库建设与 LNG 接收站是近十年储运投资的重点。</span>

一张表把油与气的储运差异收束起来：

| 对比项 | 原油 | 天然气 |
| --- | --- | --- |
| 相态 | 液态（常温） | 气态或液态（LNG） |
| 长输方式 | 常压加热或等温管道 | 高压管道（6–12 MPa）或 LNG 船 |
| 输送模型 | 不可压缩流体 | 可压缩气体、状态方程 |
| 储存 | 地面常压储罐 | 地下储气库、LNG 储罐 |
| 关键物性 | 粘度、凝点、含蜡量 | 压缩因子、热值、水露点 |

**辨析｜易错点：** 初学者常把输油的水力公式直接套到输气上——但输气管线的压力沿程变化大、气体密度随压力变化，必须用输气专用公式（Weymouth、Panhandle），这一点第 6 篇会反复强调。

## 7 小结

- **油气储运**是连接上游生产与下游消费的产业链环节，由集输、长输管道、储库、分配管网四类设施构成。
- 对大宗烃类运输，**管道在长距离、大流量下综合成本最低**，是陆上运输的首选。
- 中国储运工业从 1939 年玉门 4 公里管道起步，到中俄东线 1422 mm 大管径高压管道，是伴随国家工业化成长的基础设施体系。
- 油品的**密度、粘度、凝点、含蜡量、蒸气压、闪点**六项物性，是全部储运工艺计算的输入量；API 重度是密度的行业表达。
- 储运设计围绕**水力、热力、安全**三条主线展开，统一目标是低输送成本与高可靠性。
