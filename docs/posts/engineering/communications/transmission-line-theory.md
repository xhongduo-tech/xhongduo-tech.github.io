## 为什么低频的"常识"在高频失效

在电路课上，一根导线就是理想导体，电压在整根线上"同时"存在。但频率升高到射频/微波段（数百 MHz 以上），波长缩短到与导线尺寸可比时，**一切常识都要推翻**：电压不再是统一的，而是**沿导线传播的波**；线长是波长的一部分，就处处出现"驻波""反射"。**传输线理论（transmission line theory）** 正是描述高频能量如何沿导线传播的学问——它是射频工程的入门第一课，也是理解 Smith 圆图、阻抗匹配、天线馈电的全部基础。<span class="marginnote">什么时候"电路"开始变成"传输线"？经验判据：线长超过波长的 $1/10$ 时，就必须按分布参数处理。手机频段波长约 30 cm，一根 3 cm 的微带线就不能再当"理想短线"看了——这正是手机射频电路设计处处小心走线的原因。</span>

## 1 分布参数与特征阻抗

传输线不能再看成一个"点"，而是**分布参数网络**：单位长度上有电阻 $R$、电感 $L$、电导 $G$、电容 $C$。一段无限小线元 $\Delta z$ 满足电报方程，解出电压波与电流波：

$$V(z) = V^+ e^{-\gamma z} + V^- e^{\gamma z}, \qquad I(z) = \frac{V^+}{Z_0} e^{-\gamma z} - \frac{V^-}{Z_0} e^{\gamma z}$$

其中 $V^+$ 是前向波、$V^-$ 是反射波。两个关键参数：

- **传播常数** $\gamma = \alpha + j\beta$：$\alpha$ 是衰减常数，$\beta$ 是相位常数。无损耗线 $\alpha = 0$。
- **特征阻抗** $Z_0 = \sqrt{\frac{L}{C}}$（无损耗）：传输线"固有的阻抗"，只由线的几何与介质决定，与长度无关。

**特征阻抗是传输线的"身份"**：50 Ω、75 Ω、300 Ω 这些数字就是不同标准线的 $Z_0$。<span class="marginnote">常见线的 $Z_0$：同轴线 50 Ω（通用射频）、75 Ω（电视接收）、双绞线 100 Ω（以太网）、微带线按尺寸可任意设计。$Z_0$ 决定功率传输与反射特性，是射频工程师开口先问的"你这条线多少欧"。</span>

## 2 反射系数与驻波

当传输线终端接的负载阻抗 $Z_L \neq Z_0$ 时，能量没有被全部吸收，一部分被反射回来。定义**电压反射系数**在负载端：

$$\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$$

前向波与反射波叠加，沿线出现"高低起伏"的**驻波**——波腹与波节交替。驻波的"起伏程度"用**电压驻波比（VSWR）** 度量：

$$\mathrm{VSWR} = \frac{1 + |\Gamma|}{1 - |\Gamma|}$$

- **匹配**（$Z_L = Z_0$）：$\Gamma = 0$，VSWR = 1，能量全部被吸收——**理想状态**；
- **全反射**（开路/短路）：$|\Gamma| = 1$，VSWR = ∞，能量全部弹回——最糟状态。

**反射是射频系统一切麻烦的根源**：反射造成能量浪费、波形畸变、放大器不稳定。射频设计的头号任务，就是"消灭反射"，即**阻抗匹配**。<span class="marginnote">驻波的直观形象：抖绳子时绳端固定，波会反射回来与入射波叠加，出现"不动点"（波节）与"大振幅点"（波腹）——这就是驻波。天线馈线里的 VSWR 太高，功率会反弹回发射机，轻则效率低、重则烧坏功放。功放保护电路常监视 VSWR。</span>

## 3 公式解析：负载反射系数

一段 50 Ω 传输线接 75 Ω 负载，算反射：

- **第一步，写公式**：$\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$。
- **第二步，代入**：$\Gamma = \frac{75 - 50}{75 + 50} = \frac{25}{125} = 0.2$。
- **第三步，解读**：$|\Gamma| = 0.2$ 意味着反射功率占比 $|\Gamma|^2 = 4\%$，96% 的功率送进负载——还算可以。
- **第四步，算 VSWR**：$\mathrm{VSWR} = \frac{1+0.2}{1-0.2} = 1.5$。VSWR = 1.5 是工程上一个常用阈值：**VSWR ≤ 1.5 通常认为"可接受"，≤ 1.2 算良好，≥ 2 就需要处理了**。
- **易错点**：反射系数是**复数**（含相位），模长决定反射量、相位决定驻波位置。**"匹配"是 $Z_L = Z_0$ 而不是"阻抗为零"**——初学者常把"短路"当匹配，恰恰相反，短路是全反射（$\Gamma = -1$）。

## 4 无耗线与阻抗变换

一个反直觉但极其有用的性质：**传输线能变换阻抗**。在距负载 $l$ 处看向线，输入阻抗为

$$Z_{in}(l) = Z_0 \frac{Z_L + j Z_0 \tan(\beta l)}{Z_0 + j Z_L \tan(\beta l)}$$

- 若 $l = \lambda/4$（四分之一波长线），$\tan(\beta l) \to \infty$，得 $Z_{in} = Z_0^2 / Z_L$——**四分之一波长变换器**，把 $Z_L$ 变换成 $Z_0^2/Z_L$。这是最简单的阻抗匹配工具之一。
- 若 $l = \lambda/2$，$Z_{in} = Z_L$——半波长线不改变阻抗，可作"转接线"。

**"一段特定长度的线，可以扮演电阻、电感、电容、甚至谐振器"**——这就是为什么微波电路不用分立元件，而用"一段段线"来构造。这个视角颠覆了低频电路习惯，却是微波设计的日常。<span class="marginnote">四分之一波长变换器是"光学增透膜"的电路版：光学里，薄膜厚度等于光波长的四分之一，反射相消、透射增强；微波里，$\lambda/4$ 线把阻抗从 $Z_0$ 匹配到 $Z_L$。<strong>"四分之一波长"在波的世界里是个神奇的魔术数字</strong>——声学消声器、微波匹配、光学镀膜全用它。</span>

## 5 有损线与常见传输线

**有损线**：$\gamma = \alpha + j\beta$，$\alpha$ 来自导体损耗与介质损耗。长馈线（基站到天线）要算衰减预算——**dB 数直接线性叠加**，是链路预算的语言。
**常见类型**：**同轴线**（屏蔽好、宽带，测试设备标配）、**微带线**（PCB 上印刷，手机/雷达的主流）、**带状线**（夹在介质层中）、**波导**（金属管，高频高功率，损耗低但体积大）。

每种线都有它的 $Z_0$、损耗与功率容量，选线是"带宽、损耗、体积、成本"的权衡。<span class="marginnote">PCB 上走射频信号必须控制特征阻抗（50 Ω 微带），靠的是线宽、介质厚度与介电常数——这属于《射频电路设计》的工艺约束，也与《电子科学与技术》的电磁场知识衔接。高速数字信号（PCIe、USB）同样要控阻抗，原因和射频一模一样：阻抗不连续就反射、就眼图塌陷。</span>

## 6 信号完整性：传输线思想的数字延伸

传输线理论不只属于射频——**高速数字信号（PCIe、USB、DDR、以太网）同样被它统治**。当数字信号上升沿足够陡（如 1 ns），其等效带宽进入百 MHz 以上，PCB 走线就"变成"传输线。

**数字世界的三大传输线问题**：

- **反射**：走线阻抗不连续（过孔、接头、分支）处，信号被反射，波形出现过冲/振铃——**高速数字的"振铃"就是反射波叠加**（见本节反射系数）；
- **串扰**：相邻走线之间的电容/电感耦合，一条线的信号"漏"进另一条——这是"邻近效应"的多导体版；
- **地弹与回流**：电流回流路径不理想，地电位波动——**"地不是零电位，是电感"**。

**工程对策与射频如出一辙**：

- **特性阻抗控制**：高速走线按 50 Ω（单端）或差分 100 Ω（差分对）设计线宽与间距；
- **端接（termination）**：在接收端/源端加匹配电阻（串联端接、并联端接），消灭反射——**"匹配"两个字，射频与数字通用**；
- **长度匹配**：DDR 总线要求等长布线，保证各信号同时到达——**"路径差即相位差"**在数字时序里的体现；
- **仿真验证**：用信号完整性（SI）仿真软件看眼图（见《数字基带传输》的眼图）——**"眼图睁开，信号才健康"**。

**一个观念升级**：学过传输线之后，看 PCB 不再是"画电路"，而是"画波导"——**每一根走线都是传输线，每个不连续都是反射源**。这个视角让射频工程师与高速数字工程师共用一套语言，也让《传输线理论》成为连接"通信/微波"与"计算机体系结构"的桥梁（见第三级《计算机组成原理》的时钟与信号完整性）。

**收尾**：传输线理论是"波在导线上的行为学"——从射频馈线到 CPU 总线，它无处不在。理解它，你就同时理解了微波工程与高速数字设计的一半。

## 7 时域反射：把传输线当"体检仪"

反射不只害人，还能"助人"——**时域反射计（TDR）** 利用反射测量传输线的特性，是网络与互连测试的标准工具。

**TDR 原理**：往传输线打一个阶跃/脉冲，看**反射波什么时候回来、多大**：

- **反射位置 → 距离**：反射波到达时间 × 波速 / 2 = 缺陷位置（"来回一趟"所以要除 2，与雷达测距同源）；
- **反射大小 → 阻抗**：$Z_L$ 越偏离 $Z_0$，$|\Gamma|$ 越大（见反射系数公式）——**"反射波形就是沿线的阻抗画像"**；
- **反射极性 → 阻抗方向**：开路（$Z_L=\infty$）反射同相、短路（$Z_L=0$）反相——**"一个波形的上升/下降就暴露了是断还是短"**。

**TDR 能看到什么**：

- 断点/短路位置（修线缆）；
- 接头与焊点阻抗不连续（连接器质量）；
- 过孔、分支、走线阻抗偏差（PCB 信号完整性，见《信号完整性》一节）；
- 电缆长度与传播速度。

**"反射曲线 = 沿线的阻抗分布图"**——这是 TDR 最有价值的输出：一眼看出哪里阻抗突变、哪里需要整改。

**一句关联**：TDR 的"发脉冲、看回波"与《天线基础》的雷达、与《光纤》的 OTDR（见《光通信系统》）完全同构——**"回波测距"是波的世界里最通用的一把尺子**。

**收尾**：传输线理论给工程师的不只是"匹配与反射"的烦恼，还有"TDR 体检"这个礼物——**"反射既是问题，也是诊断工具"**，这正是工程的辩证：把缺陷变成测量手段。

## 8 小结

- 高频下导线是**分布参数网络**，电压是沿线的波，核心参数 $Z_0 = \sqrt{L/C}$。
- 负载失配产生反射：$\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$，VSWR $= \frac{1+|\Gamma|}{1-|\Gamma|}$。
- **匹配（$Z_L = Z_0$）** 是消灭反射、实现最大功率传输的关键，VSWR ≤ 1.5 是可接受阈值。
- 传输线能变换阻抗：$\lambda/4$ 变换器 $Z_{in} = Z_0^2/Z_L$，是微波匹配的基础件。
- 常见线：同轴、微带、带状线、波导，各有带宽/损耗/体积权衡。
