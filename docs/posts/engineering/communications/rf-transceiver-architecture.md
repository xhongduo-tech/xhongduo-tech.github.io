## 为什么通信原理"落地"要靠收发机

通信原理讲了调制、信道、解调，但现实中这些功能由**射频收发机（RF transceiver）** 实现——一个把"天线上的微波信号"变成"基带数字比特"的完整链路。收发机架构选择是射频系统设计的第一决策：它决定灵敏度、选择性、功耗、成本与集成度。从 1920 年代的超外差收音机到今天手机里一颗指甲大的射频芯片，收发机架构演变了一段"在性能与复杂度之间找平衡"的历史。<span class="marginnote">你手机里那颗射频收发芯片（transceiver IC）连同周围的滤波器、功放、天线开关，就是本节的主角。<strong>它完成《通信系统模型》里"调制/解调+射频搬移"的全部物理层工作</strong>——通信原理是"算法蓝图"，收发机是"工程实现"。一颗 5G 收发芯片内部有十几个混频器、几十个滤波器、上百个放大级。</span>

## 1 接收机：从天线到比特

**接收机（receiver）** 的任务：把天线接收的微弱信号（可能 -100 dBm，即皮瓦级）放大、选频、下变频到基带，再数字化。经典链路：

$$天线 \to 双工器 \to LNA \to 滤波器 \to 混频器 \to IF滤波器/放大 \to 解调/ADC$$

每个模块的职责：

- **LNA（低噪声放大器）**：第一级放大，决定整机噪声系数。它的噪声特性被逐级放大，必须"第一级就要好"。
- **混频器（mixer）**：用本地振荡器（LO）把射频搬到中频/基带——**频率搬移**（乘法，见《傅里叶变换》的频移性质）。
- **滤波器**：选频、抑制镜像与邻道干扰（见《微波滤波器》）。
- **ADC/DAC**：模拟↔数字的接口（见《抽样与量化（PCM）》）。

**级联噪声系数**（Friis 公式）是接收机设计的第一公式：后级噪声被前级增益"压下去"，所以 LNA 的增益与噪声主导整体灵敏度。<span class="marginnote">级联噪声公式 $F_{tot} = F_1 + \frac{F_2-1}{G_1} + \cdots$：第一级的噪声直接计入，第二级以后被前级增益"稀释"。这解释了射频设计铁律——<strong>"LNA 要放在最前面、要好、要高增益"</strong>。与《最佳接收》的匹配滤波思想呼应：接收链路每一步都要为"保住弱信号"服务。</span>

## 2 超外差与镜像干扰

1920 年代发明的**超外差接收机（superheterodyne）** 至今统治射频：先把射频下变频到固定的**中频（IF）**，再在 IF 上做主要放大与滤波。

$$f_{IF} = f_{RF} - f_{LO} \quad \text{（或} f_{LO} - f_{RF}\text{）}$$

为什么要先"降一次"再处理？因为**在固定中频上滤波、放大比在射频上容易**——窄带滤波在较低频率更可实现、放大也更稳定。

超外差的最大敌人是**镜像频率（image frequency）**：$f_{image} = f_{RF} + 2f_{IF}$ 处的干扰，经混频后恰好落在中频带内，与有用信号混在一起。**对付镜像要"镜像抑制滤波器"**——选高 IF（镜像远离有用信号，好滤）或改用镜抑制混频器（Hartley/Weaver 架构）。<span class="marginnote">镜像问题的本质是"混频器分不清 $f_{LO}\pm f_{IF}$ 两个频率"——因为 $\cos(A)\cos(B)$ 同时产生 $\cos(A-B)$ 与 $\cos(A+B)$。<strong>"混频不分辨上下边带"</strong>是理解镜像、零中频、I/Q 架构的总钥匙，根源还是那个频移性质。</span>

## 3 零中频（直接变频）与 I/Q 架构

超外差性能好但器件多（镜像滤波器、两级混频），难以单片集成。于是现代手机广泛采用**零中频（zero-IF / direct conversion）**：

- 射频直接下变频到**基带**（$f_{IF} = 0$），不需要中频滤波器，集成度高、成本低；
- 但带来新问题：**直流偏置**（LO 泄漏自混频）、**闪烁噪声**（低频处噪声大）、**I/Q 失衡**。

零中频必须用**I/Q 正交混频**：本地振荡器分两路（相位差 90°），分别混频出 I、Q 两路基带信号——这样把正负频率都保留下来，信号信息完整进入数字域。

$$s_{BB,I}(t) = \text{LPF}\{s(t)\cos(\omega_{LO}t)\}, \qquad s_{BB,Q}(t) = \text{LPF}\{s(t)\sin(\omega_{LO}t)\}$$

I/Q 架构的代价是**I/Q 失衡**：两路增益不等、相位不垂直，会在频谱上产生镜像干扰（负频率泄漏到正频率）。现代收发机用数字校准（训练序列估计失衡并补偿）。<span class="marginnote">I/Q 失衡的数字补偿，本质是"估计一个 2×2 线性变换并求逆"——线性代数的最小二乘问题。而"用正交两路保信息"正是 QPSK 用 I/Q 支路的思想在接收机层面的延续。<strong>正交永远是射频的免费午餐与纠错对象</strong>。</span>

## 4 公式解析：超外差的本振选择

设计一个 2.4 GHz 接收机，中频 $f_{IF} = 100$ MHz：

- **第一步，定本振**：$f_{LO} = f_{RF} - f_{IF} = 2400 - 100 = 2300$ MHz（低本振选择）。
- **第二步，算镜像**：$f_{image} = f_{RF} + 2f_{IF} = 2400 + 200 = 2600$ MHz。
- **第三步，评估镜像抑制需求**：镜像在 2600 MHz，与有用信号只差 200 MHz——需要镜像抑制滤波器在 2.4 GHz 附近压住 2.6 GHz，滤波器必须非常陡峭。
- **第四步，权衡 IF 高低**：**IF 越高，镜像离得越远越好滤，但中频滤波器越难做**（相对带宽窄）；**IF 越低，中频处理越容易，但镜像越近**。这就是超外差架构的"镜像-选择性"两难，也是双中频、零中频架构的动机。
- **易错点**：本振有高低两种选择（$f_{RF} \pm f_{IF}$），镜像频率公式要随选择改变——**先定"低本振还是高本振"，再算镜像**，顺序反了镜像就错了。

## 5 发射机与全双工

**发射机（transmitter）** 是接收机的逆过程：基带 → 上变频 → 功放 → 天线。

$$基带 \to DAC \to 滤波器 \to 混频器（上变频）\to 驱动放大 \to 功放（PA）\to 天线$$

- **功放（PA）**：最后一级大功率放大，效率与线性度矛盾——线性好效率低（A 类），效率高线性差（开关类）。现代用 DP/DOHERTY 等架构兼顾。
- **双工**：手机收发同时进行（FDD），用**双工器**把收发频段分开（见《多址技术》的 FDD/TDD）；TDD 手机用天线开关在收发间切换。
- **发射机泄漏**：PA 输出泄漏到接收端的强信号，是接收机动态范围的大敌，需要**天线开关/双工器隔离**。

收发链路拼起来，就是一颗完整的射频 SoC。<span class="marginnote">PA 的效率-线性度矛盾，是射频里最经典的能量-保真权衡：效率差浪费电池、线性差污染频谱（邻道泄漏）。5G 的高阶调制（256QAM）对 PA 线性要求极高——<strong>"调得越密，PA 越难做"</strong>是射频链路设计的日常。这与《数字调制》里高阶星座对相位噪声敏感互为因果。</span>

## 6 接收机的动态范围与阻塞

接收机不只面对弱信号，还要在"强干扰旁边听弱信号"——**动态范围（dynamic range）** 是衡量这种能力的核心指标。

**灵敏度 vs 阻塞**：

- **灵敏度**：接收机能解出信号的最弱功率，由噪声底 + 所需 SNR 决定——"能听多轻"；
- **阻塞（blocker）**：一个强邻道信号把 LNA/混频器"顶"到非线性区，有用信号的增益被压缩——"耳朵被强音震聋"；
- **两者共存**：灵敏要求低噪声（LNA 高增益），抗阻塞要求大动态（高线性度）——**矛盾在于"增益越高，越容易被大信号顶爆"**。

**关键指标与对策**：

- **IIP3（三阶互调截点）**：衡量线性度的标准——输入两强信号产生 $2f_1 - f_2$ 等互调产物，落到有用信号带内；IIP3 越高，互调越弱；
- **AGC（自动增益控制）**：信号弱时加大增益、信号强时减小增益，把输出"钳"在 ADC 的动态范围内——**"用可变增益适应宽动态输入"**，是接收机链路的标准件；
- **滤波器分工**：天线后第一级滤波器压带外阻塞，基带滤波器压带内邻道——**"滤波分层负责，动态逐级管理"**。

**级联 IIP3 的直觉**：与噪声级联相反（见《信道与噪声》），**末级对 IIP3 贡献更大**——"噪声看第一级，线性看末级"是接收机设计的一句口诀。

**ADC 的要求**：接收机数字化前，模拟链路的"增益+滤波"必须把信号与干扰"安排"进 ADC 的动态范围——**"模拟链路是 ADC 的保姆"**。ADC 的位数决定动态范围上限（每 bit 约 6 dB，见《抽样与量化（PCM）》），所以"用多少位 ADC"取决于"要抗多强的阻塞"。

**一句话**：接收机设计 = "灵敏度（噪声）与动态范围（线性度）的拔河"——**每一级增益、每一个滤波器、每一位 ADC，都是这场拔河的棋子**。这正是《信道与噪声》的噪声预算与本节动态范围的合流点。

## 7 一张表选架构：超外差 vs 零中频

收发机架构的选择是"性能与可集成性"的取舍，两张主流方案摆在一起看：

| 维度 | 超外差 | 零中频（直接变频） |
| --- | --- | --- |
| 中频 | 固定 IF（如 100 MHz） | IF = 0（直接到基带） |
| 镜像问题 | 严重，需镜像抑制滤波 | 基本消除，换 I/Q 失衡 |
| 直流偏置 | 无 | 有（LO 自混频） |
| 闪烁噪声影响 | 小 | 大（低频处显著） |
| 集成度 | 低（器件多） | 高（省中频滤波器） |
| 代表场景 | 广播收音机、卫星 | 手机、WiFi 芯片 |

**"超外差用复杂度换干净，零中频用校准换集成"**——现代手机普遍选零中频 + 数字校准，广播与高性能测量仪表仍钟爱超外差。

**易错点**：零中频不是"没有频率搬移"，而是"把射频直接搬到了基带（IF = 0）"——它依然要混频，只是跳过了中频这一站。"零中频 = 不混频"是常见误解，根源仍在那条频移性质（见第 2 节）。

## 8 小结

- 接收机链：**LNA → 滤波器 → 混频 → IF/基带 → ADC**，级联噪声系数由第一级主导。
- 超外差架构用固定中频换易实现，代价是**镜像频率干扰**，靠镜像抑制滤波器/镜抑制混频解决。
- 零中频（I/Q 直接变频）集成度高，但受直流偏置、闪烁噪声、I/Q 失衡困扰，需数字校准。
- 本振选择决定镜像位置，IF 高低在"镜像抑制"与"中频可实现性"间两难。
- 发射机 = 基带 → 上变频 → PA → 天线，PA 的效率-线性度矛盾是核心权衡。
