## 为什么"接收"也是一门学问

调制把比特变成波形，但接收端面对的是一个被噪声污染的波形 $r(t) = s(t) + n(t)$。**如何从 $r(t)$ 里以最小错误概率还原比特？** 这就是最佳接收问题。直觉上"积分一下再判决"就行，但噪声的统计特性告诉我们还有更优的做法。最佳接收的理论在 1940 年代由香农、柯捷利尼科夫等人奠定：**把接收问题变成统计判决问题**——给定观测，哪个符号最可能是发送的那个？<span class="marginnote">"最佳接收"是统计决策理论在通信里的化身。它的思想与机器学习里的分类完全同构：特征（接收波形）→ 似然函数 → 后验概率 → 判到后验最大的类。学完这里，你会惊讶地发现大模型的"下一个 token 预测"与 BPSK 判决用的是同一条数学。</span>

## 1 从概率到判决：MAP 与 ML

接收机观测到 $r$ 后要判"发送的是 $s_i$ 吗"。**最大后验概率（MAP）准则**：判给后验概率最大的符号

$$\hat{s} = \arg\max_{s_i} P(s_i | r)$$

由贝叶斯公式 $P(s_i|r) \propto p(r|s_i) P(s_i)$，当各符号**先验等概率**时退化为**最大似然（ML）准则**：

$$\hat{s} = \arg\max_{s_i} p(r | s_i)$$

**等先验时，MAP = ML**——只比较"各符号产生这个观测的可能性"。工程上发送符号通常等概，ML 是默认选择。<span class="marginnote">贝叶斯公式在这里的分工：$p(r|s_i)$ 是"似然"（信道怎么把 $s_i$ 变成 $r$），$P(s_i)$ 是"先验"（各符号发的多不多）。如果某个符号发得更频繁，MAP 会偏向它——这与机器学习里"类别不平衡时调阈值"是同一回事。</span>

## 2 匹配滤波与相关接收

对 AWGN 信道中的已知波形 $s(t)$，ML 判决等价于计算

$$\int_{0}^{T} r(t)\, s(t)\, dt$$

并与各候选符号的门限比较。这个积分的意义：**把接收波形与每个可能的发送波形做"相关"**，选相关最大的——这叫**相关接收**。

与之等价的是**匹配滤波（matched filter）**：滤波器 $h(t) = s(T - t)$（发送波形的时反），在 $t=T$ 时刻采样输出就是上述相关。匹配滤波有两个非凡性质：

1. **在 AWGN 中，匹配滤波使输出信噪比最大**（无需证明的"免费最优"）；
2. 输出在采样时刻的信噪比 $\mathrm{SNR}_{out} = 2E_s/N_0$，只依赖符号能量，与波形形状无关。

**匹配滤波的物理直觉**：它对"像发送信号"的成分给大权值、对噪声（不相关）给零期望——**像一个专门识别 $s(t)$ 的探测器**。<span class="marginnote">匹配滤波的"形状匹配"思想无处不在：雷达脉冲压缩、声呐、图像相关匹配、甚至深度学习里的卷积核。而"与模板做相关"正是傅里叶级数系数投影的翻版——复习《傅里叶级数》那节，$a_n$ 的求法就是一次相关运算。</span>

## 3 最佳判决的几何

把发送波形想成矢量，接收波形 $r$ 是"信号矢量 + 噪声矢量"。判决规则变成**在信号空间里找离 $r$ 最近的星座点**——这就是 ML 判决的几何形式，与《数字调制》里的判决区域一致。

对二进制，判决门限取在两点连线的中点。噪声越大，"点"散布越宽，越容易越界误判。**判决边界是星座点的"势力范围"分界线**，一切噪声容限都可视化为"点到边界的距离"。

**误码率公式（BPSK, 相干接收）**：

$$P_b = Q\left(\sqrt{\frac{2E_b}{N_0}}\right), \qquad Q(x) = \frac{1}{\sqrt{2\pi}}\int_x^\infty e^{-u^2/2}\, du$$

$Q$ 函数是标准正态分布的右尾概率，它的值查表可得：$Q(3.0) \approx 1.3\times 10^{-3}$，$Q(4.0) \approx 3.2\times 10^{-5}$。**误码率随 $E_b/N_0$ 指数改善**——这是"功率换来可靠性"的定量版本。<span class="marginnote">$Q$ 函数就是高斯分布积分，与概率论里正态分布的分位数、机器学习的 ROC 曲线下的 AUC 同源。$Q(x)$ 在 $x$ 稍大时近似 $\frac{1}{x\sqrt{2\pi}}e^{-x^2/2}$——工程师手算误码率全靠它。</span>

## 4 公式解析：BPSK 误码率

**第一步，定问题**：BPSK 发送 $\pm\sqrt{E_b}$ 两个电平，加高斯噪声 $N_0/2$，接收判决门限在 0。
**第二步，写错误条件**：发 $+\sqrt{E_b}$ 时，若 $r < 0$ 就误判。即错误概率 $P(e) = P(+\sqrt{E_b} + n < 0) = P(n < -\sqrt{E_b})$。
**第三步，标准化**：$n \sim \mathcal{N}(0, N_0/2)$，标准差 $\sigma = \sqrt{N_0/2}$。于是 $P(e) = Q\left(\frac{\sqrt{E_b}}{\sqrt{N_0/2}}\right) = Q\left(\sqrt{\frac{2E_b}{N_0}}\right)$。
**第四步，代数字**：要求 $P_b \le 10^{-4}$，查 $Q(3.72)\approx 10^{-4}$，故需 $\sqrt{2E_b/N_0} \ge 3.72$，即 $E_b/N_0 \ge 6.9 \approx 8.4$ dB。
**易错点**：$\sqrt{2E_b/N_0}$ 里的因子 2 来自"两电平差 $2\sqrt{E_b}$"，差越大越容易分清。**"判决门限在两电平中点"是对称噪声下的最优位置**——不对称时门限要向先验大的一侧偏（回到 MAP 的思想）。

## 5 从最佳接收到最佳译码

单个符号的 ML 判决是"逐符号最优"。当信道编码把符号关联起来（卷积码、LDPC），**最优变成对整个码字做 ML/最大似然序列估计**——这时逐符号判决已不最优，需要维特比算法（卷积码）或置信传播（LDPC）在码字级别联合判决。<span class="marginnote">"逐符号最优"与"序列最优"的差别，是通信理论深水区的分界：前者只看一点，后者看全局约束。维特比算法用动态规划做序列最优判决，与《算法设计与分析》里的动态规划、隐马尔可夫模型的 Viterbi 解码完全同源——一个算法，三个学科，见第三级《算法设计与分析》与第二级《随机过程》。</span>这条路径从"最佳接收"通向"最佳译码"，正是差错控制编码的起点。

## 6 软判决：把"不确定"传给下一步

逐符号硬判决会丢掉信息：判决成 0 或 1 之后，"这到底是确定的 0 还是差点判错的 0"就再也无从得知。**软判决（soft decision）** 保留这种不确定性，把**对数似然比（LLR）**传给后续的译码器：

$$\mathrm{LLR}(b) = \ln\frac{P(b=1|r)}{P(b=0|r)}$$

LLR 的符号给出硬判决（正=1，负=0），**绝对值给出"置信度"**——绝对值越大越确定。为什么有用？

- **级联增益**：Turbo/LDPC 的迭代译码（见《信道编码（LDPC/Turbo）》）反复交换的就是 LLR 软信息——**"没有软判决，就没有现代逼近香农极限的译码"**；
- **约 2 dB 收益**：软判决相对硬判决在 AWGN 中带来约 2 dB 的等效增益，相当于发射功率省 40%；
- **软硬结合**：现代接收机"先算软信息、再做迭代译码、最后硬判决"——**把判决推迟到信息最充分的时刻**。

**匹配滤波与相关接收的等价性**：匹配滤波 $h(t) = s(T-t)$ 在 $t=T$ 采样，输出 $\int_0^T r(t)s(t)dt$——这恰是"相关接收"的积分。两者等价，因为匹配滤波的本质就是"与信号模板做相关"。**"匹配滤波 = 相关 = 内积"**三个说法说的是同一件事：衡量接收波形与某个发送波形的"相似度"，这正是最佳判决所需的全部信息。

**一个思想收尾**：最佳接收的整个链条——相关、LLR、软判决、迭代——遵循同一条原则：**别急着做不可逆的决定，把信息留到能最好利用它的地方**。这条原则在《信号与系统》《数字调制》《信道编码》里反复出现，也是现代接收机设计的统一哲学。

## 7 最佳接收的全局图景

最佳接收不是孤立的一章，它是"最优接收机"这条长链的第一环。把它在系统里的位置放正，整个接收机设计就串起来了：

**从"最优"到"可实现"的阶梯**：

- **最优（理论）**：匹配滤波 + ML 判决——AWGN 下逐符号最优，但假设已知信道与定时；
- **准最优（工程）**：实际接收机不知道完美的信道、定时、载波，于是"估计 + 补偿 + 判决"三步走（见《同步原理》的载波/定时恢复）；
- **联合最优（编码系统）**：加了纠错码后，"逐符号最优"不再是全局最优——要用软判决 + 迭代译码（见《信道编码（LDPC/Turbo）》），"全局最优"需要把译码器接进判决链。

**接收机设计的"信息账"**：

- 匹配滤波提取"该提的信息"（相关积分）；
- 判决丢弃信息（硬判决）——**"能晚丢就晚丢"**是软判决哲学（见软判决一节）；
- 译码器用冗余"挽回"被噪声破坏的信息——**"每丢一次信息，系统就损失一点性能"**。

**与统计决策理论的连接**：ML/MAP 判决是贝叶斯决策在通信里的特例；把"误报 vs 漏检"的成本量化，就引出 Neyman-Pearson 准则与 ROC 曲线——**"判决理论"是通信、雷达、医学检测共享的数学**（见《概率论与数理统计》的假设检验）。

**一句话**：最佳接收回答"信息如何被最优地提取"，而整个现代接收机回答"在未知与噪声里如何逼近这个最优"——**理论给上限，工程给逼近**，这是通信工程永远的双轨。

## 8 小结

- 最佳接收 = 统计判决：等先验时 MAP 退化为 ML，判"哪个符号最可能产生这个观测"。
- 匹配滤波 = 相关 = 内积，三句话一件事：衡量接收波形与发送模板的相似度。
- 软判决（LLR）把"置信度"传给译码器，是现代迭代译码的前提，白拿约 2 dB。
- "别急着做不可逆的判决"是接收机设计的统一哲学——能晚丢的信息就晚丢。
- 理论给最优上限，工程给逼近：估计+补偿+判决三步走，是现实接收机的骨架。

- 最佳接收 = 统计判决：**等先验时 MAP 退化为 ML**，判后验/似然最大的符号。
- 相关接收与匹配滤波等价，**匹配滤波在 AWGN 中使输出信噪比最大**。
- 判决边界是星座点的势力范围分界；点到边界的距离决定噪声容限。
- BPSK 误码率 $P_b = Q(\sqrt{2E_b/N_0})$，随 $E_b/N_0$ 指数改善。
- 逐符号最优 → 序列最优（维特比/置信传播），通向最佳译码。
