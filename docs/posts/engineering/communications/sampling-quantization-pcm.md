## 为什么模拟信号要变成 PCM

上一节我们让模拟信号骑上载波，但模拟传输有个绕不开的缺点：**噪声逐级累积**。要彻底摆脱它，只能数字化。**PCM（脉冲编码调制，Pulse Code Modulation）** 就是最经典的数字话音方案：对模拟波形**抽样**（时间上离散）、**量化**（幅度上离散）、**编码**（变成 0/1），三段式把连续世界翻译成比特流。1948 年香农论文发表同年，PCM 已经装在军用电话系统里；今天的电话网、CD、语音编码，全是 PCM 家族的后代。<span class="marginnote">你打电话时说的每个字，经手机和交换机走的就是 PCM：抽样 8000 次/秒、每次 8 bit，一路话音 64 kbps——这个数字写在所有《通信原理》教材里，也写在所有程控交换机的芯片里，至今没变。</span>

## 1 PCM 的三步流水线

**PCM 编码**：$x(t) \xrightarrow{\text{抽样}} x(nT_s) \xrightarrow{\text{量化}} x_q(nT_s) \xrightarrow{\text{编码}} \text{比特流}$。

- **抽样**：按采样定理以 $f_s \ge 2W$ 采样，时间上离散化。这一步只丢"时间信息"，不引入误差。
- **量化**：把连续幅度值归入有限个**量化电平**。这一步**引入不可逆误差**——量化噪声。
- **编码**：每个量化电平用一个 $n$ 比特码字表示。量化电平数 $M = 2^n$。

**抽样只管时间、量化管幅度、编码管表示**：PCM 的性能主要由两个数字决定——采样率（时间分辨率）与量化比特数（幅度分辨率）。CD 的 44.1 kHz × 16 bit 就是这两个数字的经典组合。

## 2 均匀量化与量化信噪比

把幅度范围 $[-V, V]$ 均匀分成 $M$ 个区间，每个区间宽度（量化间隔）

$$\Delta = \frac{2V}{M}$$

量化把真实值 $x$ 换成区间中点 $x_q$，产生量化误差 $e = x - x_q$，均匀分布在 $[-\Delta/2, \Delta/2]$。假设输入均匀分布，量化噪声平均功率

$$N_q = \frac{\Delta^2}{12}$$

信号功率为 $S = V^2/3$ 时，**量化信噪比（SQNR）**：

$$\mathrm{SQNR} = \frac{S}{N_q} = M^2 = 2^{2n}$$

化为分贝，得到工程上背得滚瓜烂熟的公式：

$$\mathrm{SQNR} \text{（dB）} = 6.02 n + 1.76 \ \text{dB}$$

**每增加 1 比特量化，信噪比提升约 6 dB**——这是"16 bit CD ≈ 98 dB 动态范围"的来源。<span class="marginnote">$6.02n+1.76$ dB 里的 $1.76$ dB 来自 $V^2/3$ 与 $\Delta^2/12$ 的比值常数，$6.02$ 来自 $20\lg 2$。把它当成"每比特 6 dB"的记忆锚点，任何量化方案的信噪比估算都从此出发。</span>

## 3 公式解析：16 bit 的量化信噪比

算一下 CD 的 16 bit 均匀量化 SQNR：

**第一步，写公式**：$\mathrm{SQNR} = 6.02 \times 16 + 1.76$ dB。
**第二步，算**：$6.02 \times 16 = 96.32$ dB，加 $1.76$ 得 $98.08$ dB。
**第三步，解读**：约 98 dB 意味着最大信号与量化噪声之比接近 100 万倍——这就是为什么 CD 听起来"干净"。
**第四步，代价账**：每 bit 换来 6 dB 意味着**数据量与音质指数挂钩**：32 bit 浮点录音（192 kHz 采样）数据量是 CD 的 8 倍以上。**量化比特数不是越多越好，而是"够用 + 成本可承受"**——这是所有编码器设计的现实约束。
**易错点**：均匀量化对**小信号**的信噪比很糟——信号小时 $\Delta$ 不变、噪声不变，SQNR 直线下滑。语音的动态范围极大（轻声与大声差 40 dB 以上），均匀量化会让人声"小的太小、噪的噪"，解决之道在下一节压扩。

## 4 非均匀量化：μ律与 A 律

均匀量化对小信号不公平。改进思路：**小信号用细的量化间隔，大信号用粗的间隔**——这叫**非均匀量化**。实现上等价于"先压扩，再均匀量化"：

发送端做**压缩**（compressing）：用小信号放大、大信号压缩的对数曲线变换；
接收端做**扩张**（expanding）：逆变换还原。

两大标准曲线：北美与日本的 **μ 律（μ-law）**，欧洲与中国的 **A 律（A-law）**，都近似对数曲线。A 律 13 折线用 8 bit 达到约 12 bit 均匀量化的主观音质——**用同样的比特数，把小信号信噪比抬高了约 24 dB**。<span class="marginnote">A 律 13 折线的秘密：用 16 段折线逼近对数曲线，前两段共用、共 13 段，是工程对"最优化"的落地——既有对数压扩的优点，又只需比较器与加法器，不真做对数运算。这个"用分段线性逼近光滑曲线"的思路，也是数字信号处理里查表法的通用技巧。</span>

## 5 从 PCM 到差分与自适应编码

PCM 对每个样本独立编码，浪费了一个事实：**相邻样本高度相关**（语音的采样率远高于变化速度）。于是有压缩率更高的家族：

**DPCM（差分 PCM）**：只编码**相邻样本的差值**，差值方差小、可用更少比特。
**ΔM（增量调制）**：每样本只传"上升/下降" 1 位，极简单，但斜率过载时失真。
**ADPCM（自适应差分 PCM）**：预测器与量化步长都自适应，用 4 bit/样本就达到近似 8 bit PCM 音质——32 kbps 数字话音的标准方案。

这些编码都在做同一件事：**利用信源的统计特性，用更少的比特表达同样的信息**——这正是信息论"压缩到熵附近"的工程实现。<span class="marginnote">从 PCM 到 ADPCM 再到现代语音编码（如 Opus、AMR-WB），压缩率不断提升，但"抽样+量化"的内核从未改变。类似地，大模型的 tokenizer 也做"编码"：把可变长度文本变成固定词表索引，本质是信源编码在 NLP 里的亲戚，见第四级《大模型原理》Tokenizer 章节。</span>

## 6 从 PCM 到现代语音编码的压缩阶梯

PCM 是"诚实"的编码——每个样本独立量化，不利用任何统计特性。现代语音编码沿三个方向压数据：

**方向一：利用样本相关性（时域预测）**

- DPCM/ADPCM 只编码"差值"（见本节第五段），32 kbps 达到 64 kbps PCM 的音质——**省一半**。

**方向二：利用语音模型（参数编码 / vocoder）**

- 语音是"声带激励 + 声道滤波"的产物（见本专题第四篇的语音与第五级相关专题），可以只传"基频、清/浊、声道参数"——压到 2.4 kbps（LPC 声码器）；
- 代价是"机器人声"：重建语音保留可懂度，丢掉自然度。

**方向三：混合编码（分析-合成）**

- 现代标准（AMR、G.729、Opus）结合"波形逼近 + 语音模型 + 感知加权"：把残差信号也编码，再用感知模型（掩蔽效应）决定哪些失真"听不见"；
- 典型码率：AMR 4.75–12.2 kbps、Opus 6–510 kbps 自适应——**"用感知模型决定丢什么"**是现代压缩的核心理念。

**一张码率对照表**：

| 编码 | 码率 | 原理 | 用途 |
| --- | --- | --- | --- |
| PCM（G.711） | 64 kbps | 均匀/压扩量化 | 传统电话 |
| ADPCM（G.726） | 32 kbps | 差分预测 | 数字中继 |
| AMR-NB | 12.2 kbps | 混合编码 | 2G/3G 语音 |
| AMR-WB | 23.85 kbps | 宽带语音 | HD 语音 |
| Opus | 6–510 kbps | 感知编码 | 网络通话 |

**压缩的本质回顾**：从 PCM 到 Opus，做的都是同一件事——**"找到信息里的冗余，把它去掉"**。时域相关是冗余、语音模型是冗余、感知不敏感是冗余——信息论的信源编码定理（压缩到熵）在这三个方向上的工程展开。**"编码的每一步压缩，都是对'什么是冗余'认识的加深"**，这条思想也贯穿图像（JPEG）、视频（H.264）与文本（见《信息度量》的霍夫曼/Tokenizer）。

**与大模型语音的连接**：今天大模型的语音输入（Whisper 等，见第四级《语音技术》）直接处理波形或频谱特征，端到端学"声音→文本"——传统编码器的"中间表示"被神经网络取代，但"表示要紧凑、要保留信息"的目标从未改变。

## 7 小结

- 抽样管"快不快"、量化管"细不细"，两者共同决定数字化丢了多少信息。
- 每增加 1 bit 量化 ≈ 6 dB 信噪比，这个"每比特 6 dB"的锚点可估算一切量化方案的性能。

- PCM 三步：**抽样**（时间离散）、**量化**（幅度离散）、**编码**（变 0/1）。
- 均匀量化信噪比 $\mathrm{SQNR} = 6.02n + 1.76$ dB：**每比特 ≈ 6 dB**。
- 均匀量化对小信号不公平，用 μ 律/A 律压扩抬升小信号信噪比。
- DPCM/ΔM/ADPCM 利用样本相关性，用更少比特达到相近音质。

在下一节，我们讨论已经量化好的比特流怎么"在线上跑"：**数字基带传输**将处理 0 和 1 在信道里如何变成波形、又如何被判决。
