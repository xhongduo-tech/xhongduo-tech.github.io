## 为什么 1939 年的图纸还没退休

传输线公式能算反射与匹配，但工程上更常用一种"算图"——**Smith 圆图**。1939 年菲利普·史密斯（Phillip Smith）发明了它：把复反射系数平面经过**共形映射**，变成一张同时刻着阻抗与反射信息的圆图。在计算机普及前，射频工程师靠它在纸上完成所有匹配计算；今天，Smith 圆图依然是射频设计的"共同语言"——EDA 软件里画匹配网络、测试仪器上显示阻抗轨迹，用的都是它。<span class="marginnote">Smith 圆图的"长寿"在于它不只是计算工具，更是一种<strong>直觉</strong>：匹配往哪调、线长往哪变、失配有多严重，看圆图上一眼明了。就像傅里叶变换之于信号、矢量之于电磁，Smith 圆图把阻抗匹配变成"看图说话"。它也是微波网络分析仪屏幕上 S 参数轨迹背后的坐标纸。</span>

## 1 圆图是怎么画出来的

归一化阻抗 $z = Z/Z_0 = r + jx$，反射系数 $\Gamma = |\Gamma|e^{j\theta}$。两者的关系

$$\Gamma = \frac{z - 1}{z + 1}, \qquad z = \frac{1 + \Gamma}{1 - \Gamma}$$

这是一个**分式线性变换（莫比乌斯变换）**，它把 $z$ 平面的直线与圆映成 $\Gamma$ 平面上的圆：

- **等电阻圆（$r$ = 常数）**：一族圆心在实轴上、随 $r$ 增大的圆。$r=0$ 是最外圈（纯电抗边界），$r \to \infty$ 缩成实轴右端点。
- **等电抗圆（$x$ = 常数）**：一族圆心在虚轴两侧的圆弧。上半平面是感抗（$x>0$），下半平面是容抗（$x<0$）。
- **中心点 $z=1$**（即 $Z = Z_0$）：匹配点，$\Gamma = 0$，一切匹配的目标。
- **实轴右端**：开路（$z=\infty$）；**实轴左端**：短路（$z=0$）。

**记住三件事就够了**：中心是匹配点、外圈是纯电抗、上半是电感下半是电容。<span class="marginnote">分式线性变换把"带符号的直线/圆"映成"圆"，这是复变函数里保角映射的标准结论，见第二级《复变函数与积分变换》。Smith 圆图本质上是把一个复杂的复数除法问题变成了"在图上移动点"——几何化消除了大量代数。</span>

## 2 圆图上"走动"的两种基本运动

Smith 圆图的实用价值在于：**每种电路操作对应一种确定的几何运动**。

**沿等反射圆（$|\Gamma|$ 圆）旋转**：**加一段传输线**。线长 $l$ 对应旋转角 $2\beta l = 4\pi l/\lambda$。**顺时针 = 朝源端走**，**逆时针 = 朝负载端走**。旋转一圈 = $\lambda/2$。
**沿等电阻圆或等电抗圆移动**：**串联/并联一个电抗元件**。串联电感向上移（增大 $x$）、串联电容向下移；并联元件用**导纳圆图**（把 $z$ 换成 $y = 1/z$）对应另一族运动。

**匹配的几何目标**：用"加线 + 加元件"的走位，把任意负载点一步步"走"到圆心 $z=1$。<span class="marginnote">圆图上的"旋转=加线长"直接来自 $Z_{in}$ 公式里的 $\tan(\beta l)$ 周期：线长每变化 $\lambda/2$，$Z_{in}$ 绕圆图一圈。所以"加半波长线不改阻抗"在圆图上表现为"转一圈回到原点"——这是《传输线理论》阻抗变换公式的几何翻译。</span>

## 3 公式解析：在圆图上走一步

一个 $Z_L = 100 + j50\ \Omega$ 的负载接在 50 Ω 线上：

**第一步，归一化**：$z_L = (100 + j50)/50 = 2 + j1$。在圆图上找到 $r=2$ 的圆与 $x=+1$ 的圆弧交点，即负载点 $P$。
**第二步，读反射系数**：从原点连到 $P$ 的矢量长度是 $|\Gamma|$，角度是相位。若测得 $|\Gamma| = 0.45$，则 VSWR $= (1+0.45)/(1-0.45) \approx 2.64$。
**第三步，加线**：沿 $|\Gamma|$ 圆顺时针（向源）转 $d = 0.1\lambda$，对应角度 $4\pi \cdot 0.1 = 72°$，到新点 $P'$，读出新阻抗 $z' \approx 0.7 - j0.4$。
**第四步，解读**：圆图把"加一段 0.1 波长的线阻抗变成多少"这个问题，化简成"转 72 度读坐标"——**无需求 $\tan$，看图即得**。
**易错点**：方向。**"向源"是顺时针**，别反了；线长单位是**波长 $\lambda$**，不是长度米——不同频率下同一个物理长度对应不同的旋转角度。

## 4 单枝节匹配：圆图的经典应用

**单枝节匹配（single stub matching）** 是圆图最经典的实战：在距负载某处并联（或串联）一根长度可调的开路/短路枝节，把输入阻抗调到 50 Ω。

**第一步**：归一化负载点 $z_L$，沿等 $|\Gamma|$ 圆向源旋转，直到落在**单位电导圆**（$g=1$）上——此时从主线看进去的电导部分已匹配。
**第二步**：读出旋转距离 $d$（线长），此时主线还剩一个电纳 $jb$ 未匹配。
**第三步**：选一个**电纳为 $-jb$** 的枝节。开路枝节的输入电纳随长度在 $-j\infty$ 到 $+j\infty$ 间扫，在圆图外圈读出需要的长度 $l$。
**第四步**：$d$ 与 $l$ 都确定了，匹配完成。

**单枝节匹配只需"一段线 + 一根枝节"，就能匹配任意负载**——这是圆图把"解方程"变成"两步走位"的典型胜利。<span class="marginnote">单枝节是"可调匹配器"的原理：实验室里常做的"滑块调匹配"、天线匹配盒、微带匹配网络，都基于这个几何。匹配的多样性在于——<strong>同一负载，圆图上有无穷多种"走位"方案</strong>，工程师按带宽、损耗、可实现性挑一种，这就是匹配网络设计，见下一节《阻抗匹配》。</span>

## 5 圆图在现代工具里的角色

今天的射频仿真软件（ADS、HFSS）不再需要手绘圆图，但 Smith 圆图的**概念**仍然统治着设计流程：

**S 参数轨迹**：网络分析仪直接在一张 Smith 圆图上画出 $S_{11}$ 随频率的轨迹——设计师一眼看出"哪个频段接近匹配、哪里失配"；
**匹配网络设计向导**：软件内部仍在解 Smith 圆图的几何问题；
**圆图上的区域直觉**：轨迹落在圆心附近 = 宽带匹配；绕大圈 = 谐振点；螺旋外扩 = 有损耗。

**学会了圆图，就学会了射频工程师的"空间想象"**——它能让你不看屏幕就预测一个匹配网络的行为。<span class="marginnote">圆图的"视觉直觉"与机器学习里的流形学习、PCA 降维精神相通：把高维复杂的阻抗计算压到一张低维图上，保留最重要的结构信息。<strong>"用几何代替代数"是工程直觉的最高形态</strong>，这在《微波网络（S参数）》里还会再遇到。</span>

## 6 读一张 $S_{11}$ 轨迹

圆图在现代最常用的场景，是**看网络分析仪打出的 $S_{11}$ 随频率轨迹**。学会"读轨迹"，圆图就从"计算工具"升级为"诊断语言"。

**一张典型的天线 $S_{11}$ 轨迹会怎么走**：

- 轨迹从 Smith 圆图外圈某处出发，随频率升高向中心"盘旋"；
- **轨迹最靠近中心的频率 = 谐振点**（该频率匹配最好，反射最小）；
- **轨迹离中心越远，VSWR 越大**——落在 VSWR=2 圆之外说明失配超标（见《传输线理论》的 VSWR 阈值）；
- **轨迹绕圆转一圈 = 频率变化半个波长对应**——转得越快说明该结构电长度越敏感。

**从轨迹能读出什么**：

| 观察 | 结论 |
| --- | --- |
| 轨迹在中心附近 | 宽带匹配良好 |
| 轨迹绕大圈 | 存在谐振/高 Q 结构 |
| 轨迹螺旋外扩 | 有损耗（辐射或介质损耗） |
| 轨迹沿实轴 | 纯阻性变化（如渐变线） |
| 高低频两端点 | 匹配网络的带宽边界 |

**一个实战判断**：天线设计者把 $S_{11} < -10$ dB（对应 `VSWR < 2`）作为"可工作"标准，对应 Smith 圆图上就是轨迹**穿过 VSWR=2 圆所覆盖的频率范围**——那段频率就是天线的工作带宽。**"带宽 = 轨迹落在 VSWR=2 圆内的频率区间"**，一句圆图语言，解决了"天线带宽多少"这个问题。

**圆图与系统设计**：匹配网络设计（见《阻抗匹配》）的目标就是把 $S_{11}$ 轨迹"压进" VSWR=2 圆——**"设计匹配 = 把轨迹拽进圈内"**，这个空间直觉比任何公式都直接。

**收尾**：Smith 圆图活了近九十年，因为它把"复数运算"变成"看图"，把"匹配"变成"走位"，把"性能"变成"轨迹"——**它是射频工程师用几何对抗代数的胜利**，也是"一张好图胜过千行公式"的最佳注脚。

## 7 导纳圆图与双枝节匹配

Smith 圆图上同一个点，既可以是归一化阻抗 $z$，也可以是归一化导纳 $y = 1/z$——两者只差 $180°$ 旋转。并联元件的设计，用导纳圆图比阻抗圆图顺手得多。

**导纳的读法**：阻抗圆图上的"等电阻圆"变成导纳圆图上的"等电导圆"，$z=1$ 的圆心仍是匹配点；上半圆的感抗变成"正电纳"，下半圆变成"负电纳"——**"阻抗与导纳是同一张图的两副眼镜"**。<span class="marginnote">$y=1/z$ 在圆图上就是绕圆心转 $180°$：因为 $z$ 与 $1/z$ 互为"复平面单位圆内的反演"。<strong>一张图 + 一次旋转，等于两张图</strong>——这也是共形映射"一图多用"的又一个例子。</span>

**双枝节匹配（double stub）**：单枝节要变枝节位置 $d$，在固定位置的双枝节结构中，靠两个枝节的长度来匹配——牺牲一点"可匹配区域"（有些阻抗够不到），换来"位置固定、只调长度"的工程便利（如波导与同轴里位置难动、长度好调）。

**为什么需要两副图**：串联元件沿阻抗圆图走，并联元件沿导纳圆图走——**混用一张图去画并联元件，等于用错误的坐标纸画图**。实际工程师把"串并混用"的匹配用"阻抗图走串联、导纳图走并联"交替完成，这也是 EDA 软件内部做匹配网络综合的几何语言。

**易错点**：导纳圆图的旋转方向与阻抗圆图一致（向源仍顺时针），但"串电感向上移"在导纳图里变成"并电容向外圈移"——**换了坐标纸，运动规则也要重记**，初学最容易在这里栽跟头。

## 8 小结

- Smith 圆图是复反射平面经**分式线性变换**得到的阻抗地图：中心=匹配点，外圈=纯电抗，上感下容。
- 加传输线 = 沿 $|\Gamma|$ 圆**旋转**（向源顺时针、向负载逆时针），线长 $\lambda/2$ 转一圈。
- 串并联元件 = 沿等电阻/等电抗线移动；匹配 = 把负载点"走"到圆心。
- 单枝节匹配用"旋转到单位电导圆 + 配枝节电纳"，两步走位解任意匹配。
- 现代工具把 S 参数直接画在圆图上，圆图仍是射频设计的共同语言。

在下一节，我们把"点对点的阻抗"升级成"多端口网络"：**微波网络（S 参数）** 将用黑箱方式描述一切微波器件。
