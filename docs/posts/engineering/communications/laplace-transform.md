## 为什么傅里叶变换还不够

傅里叶变换要求信号绝对可积，否则积分发散——可现实中的信号偏偏常常**增长**：不稳定的系统输出、带反馈的放大器、爆炸式的振荡。而且工程师还想顺手把**初始条件**也一起算进去。拉普拉斯变换正是为这两件事而生：把积分核从 $e^{-j\omega t}$ 换成 $e^{-st}$（$s$ 是复数），指数增长的信号也能被"压住"；同时把微分方程变成代数方程，初值自动代入。<span class="marginnote">拉普拉斯变换与自动控制的关系如同钥匙与锁：控制系统的稳定性、暂态响应、根轨迹全部在 $s$ 平面上分析，见第六级《控制科学与工程》胡寿松《自动控制原理》。在通信里，它主要用于电路瞬态分析、系统函数与滤波器综合。</span>

## 1 定义与收敛域

**双边拉普拉斯变换**定义为

$$X(s) = \int_{-\infty}^{+\infty} x(t)\, e^{-st}\, dt, \qquad s = \sigma + j\omega$$

对照傅里叶变换 $X(j\omega) = \int x(t) e^{-j\omega t} dt$：**拉普拉斯变换是"傅里叶变换 + 衰减因子 $e^{-\sigma t}$"**。取 $s = j\omega$（即 $\sigma=0$）就退回傅里叶变换。

不是所有 $s$ 都能让积分收敛。使积分收敛的 $s$ 的集合称为**收敛域（ROC, region of convergence）**。ROC 是拉普拉斯分析的灵魂——**同样的代数表达式，ROC 不同对应不同的时域信号**。

**单边拉普拉斯变换**（通信与控制更常用）从 $0^-$ 起积分：

$$X(s) = \int_{0^-}^{+\infty} x(t)\, e^{-st}\, dt$$

单边变换把"历史"截断在 $t=0$ 之前，因而能自然地携带初始条件。

## 2 常用变换对

| 信号 $x(t)$ | 拉普拉斯变换 $X(s)$ | ROC |
| --- | --- | --- |
| $\delta(t)$ | $1$ | 全平面 |
| $u(t)$ | $\dfrac{1}{s}$ | $\mathrm{Re}(s) > 0$ |
| $e^{-at}u(t)$ | $\dfrac{1}{s+a}$ | $\mathrm{Re}(s) > -a$ |
| $e^{at}u(-t)$ | $-\dfrac{1}{s-a}$ | $\mathrm{Re}(s) < a$ |
| $\cos(\omega_0 t)u(t)$ | $\dfrac{s}{s^2+\omega_0^2}$ | $\mathrm{Re}(s) > 0$ |
| $\sin(\omega_0 t)u(t)$ | $\dfrac{\omega_0}{s^2+\omega_0^2}$ | $\mathrm{Re}(s) > 0$ |

注意表格第三、四行：**同一代数式 $\frac{1}{s+a}$ 在 $a$ 取负时对应两个不同的时域信号，区别全在 ROC**。ROC 在右边对应因果信号（$t \ge 0$），在左边对应反因果信号（$t < 0$）。<span class="marginnote">这种"一个表达式、两个信号"的歧义，正是 ROC 必须同时声明的理由。它和反函数的选取、复变函数里多值分支的选择是同一类"信息藏在定义域里"的现象，见第二级《复变函数与积分变换》。</span>

## 3 主要性质与初值终值定理

拉普拉斯变换让微积分降维成代数，核心性质：

**微分**：$x'(t) \leftrightarrow s X(s) - x(0^-)$——初值自动进入表达式，这是它解微分方程的法宝。
**积分**：$\int_{0^-}^{t} x(\tau)d\tau \leftrightarrow \frac{X(s)}{s}$。
**时移**：$x(t-t_0)u(t-t_0) \leftrightarrow e^{-st_0} X(s)$。
**卷积**：$x(t) * h(t) \leftrightarrow X(s) H(s)$——与傅里叶一致，频域乘法在 $s$ 域同样成立。

两条工程上极常用的定理：

**初值定理**：$x(0^+) = \lim_{s \to \infty} s X(s)$；**终值定理**：$\lim_{t\to\infty} x(t) = \lim_{s \to 0} s X(s)$（须 ROC 含虚轴右半部）。

终值定理让你不反变换就知道稳态值——电路、控制里"系统最后稳定在哪"一问即答。<span class="marginnote">终值定理成立的前提是 $sX(s)$ 的极点都在左半平面（系统稳定）。若系统有振荡极点，直接套终值定理会给出错误"稳定值"——这也是"先判稳定、再读稳态"工程纪律的由来。</span>

## 4 公式解析：用拉普拉斯解电路方程

解 $y''(t) + 3y'(t) + 2y(t) = 2x(t)$，初值 $y(0^-) = 1,\ y'(0^-) = 0$，输入 $x(t) = u(t)$：

- **第一步，两边取单边拉普拉斯变换**：$(s^2 Y - s\cdot 1 - 0) + 3(sY - 1) + 2Y = \frac{2}{s}$。
- **第二步，整理成代数方程**：$(s^2 + 3s + 2) Y(s) = s + 3 + \frac{2}{s}$，得 $Y(s) = \frac{s+3}{s(s^2+3s+2)} + \frac{2}{s(s^2+3s+2)}$。
- **第三步，部分分式展开**：$s^2+3s+2 = (s+1)(s+2)$，设 $Y(s) = \frac{A}{s} + \frac{B}{s+1} + \frac{C}{s+2}$，解出 $A=1,\ B=-1,\ C=0$。
- **第四步，查表反变换**：$y(t) = (1 - e^{-t})u(t)$。
- **关键洞察**：**微分方程 → 代数方程 → 部分分式 → 查表**。整个流程无需猜测通解、无需代入初值求系数——初值在第 2 步就自动安置好了。部分分式展开正是复变函数里"有理函数按极点分解"的应用，见第二级《复变函数与积分变换》留数一章。

## 5 系统函数与极点

把卷积定理搬到系统分析：$Y(s) = H(s) X(s)$，其中

$$H(s) = \frac{\text{输出变换}}{\text{输入变换}} = \frac{b_M s^M + \cdots + b_0}{s^N + a_{N-1}s^{N-1} + \cdots + a_0}$$

**系统函数 $H(s)$** 是冲激响应 $h(t)$ 的拉普拉斯变换，分母的根叫**极点（pole）**，分子的根叫**零点（zero）**。系统的全部行为由零极点图决定：

- **稳定性**：因果系统稳定 ⇔ 全部极点位于 $s$ 平面**左半平面**（实部为负）。
- **自然响应**：每个极点对应一个自然模态 $e^{p_i t}$；极点越靠左，模态衰减越快。
- **频率响应**：沿虚轴 $s=j\omega$ 取值即得频率响应 $H(j\omega)$。

极点在左半平面则模态衰减、系统稳定；在虚轴上则等幅振荡（临界）；在右半平面则发散、不稳定——这一判据是控制理论里"特征根定稳定"的同一句话，见《控制科学与工程》。<span class="marginnote">"极点决定命运"的思想也渗透到深度学习：RNN 的梯度爆炸/消失，根源就是循环权值矩阵的谱半径（类似极点的位置）——把 $s$ 域的稳定性直觉搬到离散的 $z$ 域，就是下一节《Z变换》的内容。</span>

## 6 极点布置：从"分析"到"设计"

拉普拉斯变换不只能分析已有系统，还能**按想要的性能设计极点**——这是它最强大的工程能力。

**极点的"布阵"决定系统性格**：

- **实轴极点**：$p = -\sigma$（$\sigma > 0$），对应指数衰减 $e^{-\sigma t}$——时间常数 $\tau = 1/\sigma$，**极点越靠左，衰减越快**；
- **共轭复极点**：$p = -\sigma \pm j\omega_d$，对应衰减振荡——阻尼比 $\zeta = \sigma/\sqrt{\sigma^2 + \omega_d^2}$，**虚部定振荡频率，实部定衰减快慢**；
- **右半平面极点**：指数增长——不稳定（见本节稳定性判据）。

**设计时的"极点配置"思维**：

- 想要"快"：把极点往左放（$\sigma$ 大）——但实部越大，对噪声越敏感、需要的增益越大；
- 想要"不振荡"：把共轭极点压向实轴（提高阻尼比 $\zeta$）；
- 想要"稳"：全部极点锁在左半平面——**"极点就是设计旋钮"**，这是《控制科学与工程》里根轨迹法的核心：画根轨迹，看极点随增益怎么走，选增益把极点"放"到想要的位置。

**零点的作用**：零点不决定稳定性，但"整形"频率响应——**"极点决定'会不会炸'，零点决定'长得像不像'"**。在某个频率放一个零点，就在那里"挖一个坑"（陷波），这是滤波器与均衡器的基本手法（见《系统函数与频率响应》的零极点几何法）。

**一句话**：拉普拉斯变换把"系统设计"变成"在 $s$ 平面摆棋子"——**摆极点定稳定与快慢，摆零点定频率形状**，这是控制与滤波两条线共同的"布阵法"。

## 7 小结

- 拉普拉斯变换 = 傅里叶 + 收敛因子 $e^{-\sigma t}$，把指数增长信号也纳入分析。
- ROC 决定变换对应哪个时域信号：同表达式、不同 ROC ⇒ 不同信号。
- 微分变代数、初值自动代入，解微分方程四步曲：变换→整理→部分分式→查表。
- 极点布置就是设计：极点定稳定与快慢，零点定频率形状——"在 $s$ 平面摆棋子"。
- 终值定理"先判稳定再读稳态"是工程纪律，乱套会得到错误的"稳定值"。

- 拉普拉斯变换 = 傅里叶 + 收敛因子 $e^{-\sigma t}$；$s = \sigma + j\omega$。
- ROC 决定变换对应哪个时域信号；**同表达式、不同 ROC ⇒ 不同信号**。
- 微分变代数、初值自动代入，解微分方程四步曲：变换→整理→部分分式→查表。
- 系统函数 $H(s)$ 的极点决定稳定性：全在左半平面才稳定。

在下一节，我们把这一整套搬到离散世界：**Z 变换**是离散序列的"拉普拉斯变换"，它统治数字滤波与数字系统的全部分析。
