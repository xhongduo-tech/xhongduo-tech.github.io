## 为什么从系统框架开始

前面十节我们学了信号的数学语言，现在开始真正的"通信工程"。通信要解决的根本问题只有一个：**把信息从一处搬到另一处，搬得准、搬得快、搬得便宜**。为了把这个问题拆成可以独立优化的子问题，香农在 1948 年给出了一个至今沿用的**通信系统模型**——把整个链路分成发端、信道、收端三段的模块链。此后七十多年的通信工程，都是在这个框架里给每个模块做文章。<span class="marginnote">这个模型太重要了：手机、WiFi、卫星、光纤——所有通信系统的教科书开篇都是它。它也是理解"现代通信系统"（第四篇）的地图：每一代移动通信的进步，都可以定位到某个模块的升级。</span>

## 1 模型的分段与每段的职责

**通信系统模型**：信源 → 信源编码 → 信道编码 → 调制 → 信道 → 解调 → 信道译码 → 信源译码 → 信宿。

每一段的职责可以一句话说清：

| 模块 | 干什么 | 用什么对抗 |
| --- | --- | --- |
| 信源 | 产生信息（话音、图像、数据） | — |
| 信源编码 | 压缩冗余，去掉无关信息 | 冗余 |
| 信道编码 | 加入可控冗余，纠错 | 噪声与干扰 |
| 调制 | 把比特搬上高频载波 | 频带匹配、天线尺寸 |
| 信道 | 传播介质（有线/无线/光） | — |
| 解调 | 从载波里恢复比特 | 噪声 |
| 信道译码 | 利用冗余纠错 | 噪声引起的错码 |
| 信源译码 | 还原原始信息 | — |

**关键思想：信源编码和信道编码方向相反**——前者删冗余，后者加冗余。删冗余是为了"搬得少"，加冗余是为了"搬得准"，两者在总比特率上互相拉扯，正是通信设计的核心权衡。<span class="marginnote">香农信源编码定理（可无损压缩到熵）、信道编码定理（存在可达信道容量的编码）分别给这两件事划了理论底线，见第二级《信息论》。"信源压缩与信道纠错分开设计最优"是香农分离定理的结论。</span>

## 2 信道的分类

信道是信息穿越的介质，按特性分成几类：

- **有线信道**：双绞线、同轴电缆、光纤。受干扰小、信道稳定。
- **无线信道**：自由空间传播，受衰落（多径、阴影）、干扰影响大。
- **按统计特性**：**恒参信道**（特性不随时间变，如有线）与**随参信道**（特性随机起伏，如短波、移动信道）。

随参信道的最大敌人是**多径效应**：发射信号经不同路径、不同延迟到达接收机，叠加后产生频率选择性衰落——不同频率分量被不等地衰减，波形畸变。这是移动通信所有复杂技术的动机：均衡、扩频、OFDM、分集，本质上都在对抗多径。<span class="marginnote">多径衰落可以用"冲激响应随时间变化"来建模：信道本身变成了一个时变的 LTI（近似）系统。用第一、二节学的 $h(t)$ 语言，通信系统的信道就是一个"不太友好、还会变的冲激响应"。</span>

## 3 衡量通信质量的两把尺子

**有效性（efficiency）** 与**可靠性（reliability）** 是通信系统的一对基本矛盾：

- **有效性**：传输一定信息所用的资源（带宽、时间、功率）越少越有效。
- **可靠性**：接收端恢复信息的准确程度，用**误码率（BER, bit error rate）**衡量——传错的比特占总数比例。

信息传输速率 $R_b$（比特/秒）与带宽 $B$ 之比，即**频带利用率**

$$\eta = \frac{R_b}{B} \quad \text{（bit/s/Hz）}$$

频带利用率刻画"每赫兹带宽每秒能搬多少比特"。模拟系统的对应指标是信噪比 SNR，数字系统则同时看 BER 与 $\eta$。**提高可靠性（降低 BER）往往需要更多冗余、更大带宽，降低有效性——"快而稳"和"快而省"不可兼得**，这是贯穿全书的权衡主线。<span class="marginnote">这个权衡的精确边界由香农容量公式划出：$C = B\log_2(1 + \mathrm{SNR})$——给定带宽与信噪比，存在最大无差错速率 $C$。接近 $C$ 需要极长的码与复杂的编译码，这就是现代 LDPC/Turbo 码的舞台，见本专题《信道编码》与《信息论与编码》。</span>

## 4 数字通信的优越性与代价

现代通信几乎全部数字化，因为数字传输有一组压倒性优点：

1. **抗噪声能力强**：只需要在噪声中分辨"0/1"两个电平，而非还原模拟波形细节，允许更大的噪声容限；
2. **可再生**：中继站可以"判决后重发"，噪声不会逐级累积——模拟中继则每级都引入不可逆失真；
3. **可灵活处理**：加密、压缩、纠错、存储转发全部可在数字域进行；
4. **多业务统一**：话音、数据、图像都变成比特流，一套网络承载所有业务（全 IP 化）。

代价是：数字化需要**抽样、量化**（引入量化噪声），需要**同步**，且同样信息量的数字信号通常需要更宽带宽。抽样与量化的代价见《抽样与量化（PCM）》，同步见《同步原理》。

## 5 从模型到整本教材的地图

把模型与教材章节对起来，学习就有了路线图：

- 信源编码 ↔ 抽样量化 PCM、信源压缩；
- 信道编码 ↔ 差错控制编码、卷积码、LDPC/Turbo；
- 调制/解调 ↔ 模拟调制、数字调制、最佳接收；
- 信道 ↔ 信道与噪声、多径衰落；
- 同步 ↔ 同步原理；多用户 ↔ 多址技术。

整本《通信原理》就是沿着这条链逐个模块深入。后面的每一节都会回到这张图：**学一个模块时，永远问"它处于模型哪一段，在优化有效性还是可靠性"**。<span class="marginnote">这就像学大模型时先搭起"预训练—指令微调—RLHF—推理—部署"的流水线地图，再逐环节深入——通信系统模型就是通信的"流水线地图"，见第四级《大模型原理》。</span>

## 6 通信系统的性能指标全景

"有效性"与"可靠性"太笼统，工程上要用一套可测的指标把系统管起来：

**物理层指标**：

- **BER（误码率）**：译码前的比特错误比例——调制与信道的"体检报告"（见《最佳接收》）；
- **BLER（误块率）**：编码块（如一个 TB）出错的概率——直接影响重传（HARQ）与吞吐；
- **吞吐率（throughput）**：每秒成功传输的有效比特——**"能用的速率"，不是标称速率**；
- **频谱效率**：吞吐 / 带宽（bit/s/Hz）——"每赫兹赚多少"。

**网络层指标**：

- **时延（latency）**：端到端时延与抖动——语音要求低时延、文件传输容忍高时延；
- **覆盖（coverage）**：链路预算决定的半径——"能通多远"；
- **容量（capacity）**：同时服务的用户数与总吞吐——"能装多少人"。

**关键权衡一张表**：

| 想提升 | 通常牺牲 | 手段 |
| --- | --- | --- |
| 可靠性（BER） | 速率/带宽 | 更强的编码（见《差错控制》） |
| 吞吐 | 时延/覆盖 | 更高阶调制（见《数字调制》） |
| 覆盖 | 吞吐 | 更低速率、更多功率 |
| 容量 | 每用户速率 | 多址与调度（见《多址技术》） |

**"没有免费的提升"是通信系统设计的元原则**：每个指标都对应一种资源（带宽、功率、时延、复杂度），提升一个就要从别处"付账"。**系统工程师的工作，就是在一堆互相拉扯的指标里找到"够用且划算"的平衡点**——这与《最优化理论》的多目标优化、《软件工程》的非功能需求权衡是同一门学问。

**收尾**：带着这套指标全景回头看通信系统模型，每个模块都有明确的"责任指标"——编码管 BER、调制管频谱效率、调度管容量、链路预算管覆盖。**模型是地图，指标是刻度**，两者合起来才能"测量"一个通信系统。

## 7 小结

- 通信系统模型：信源→编码→调制→信道→解调→译码→信宿，七段各司其职。
- **信源编码删冗余（压缩），信道编码加冗余（纠错）**，方向相反、目标互补。
- 信道分恒参/随参；多径衰落是无线信道最核心的敌人。
- 有效性与可靠性是一对矛盾：频带利用率 $\eta = R_b/B$，可靠性用 BER 衡量。
- 数字通信以带宽换抗噪与可处理性，是现代通信的主流。

在下一节，我们给"信息"一个精确的度量：**信息度量**将回答"一条消息到底带多少比特信息"，它是信源编码与信道容量的前提。
