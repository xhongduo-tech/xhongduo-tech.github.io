## 为什么需要傅里叶变换

傅里叶级数只对周期信号有效。但现实中的信号——一段语音、一帧图像、一个突发的脉冲——大多不是周期信号。把周期 $T$ 推向无穷，级数里的离散谱线 $n\omega_0$ 之间的间隔趋于零，谱线连成了连续曲线，**求和变成积分**：这就是**傅里叶变换（Fourier transform）**。它是信号与系统课程的"总枢纽"：采样定理、滤波器、调制解调、频谱分析全部从这里出发。可以说，整本《通信原理》都在反复做傅里叶变换。<span class="marginnote">从离散谱到连续谱的过渡，与级数理论里"从泰勒级数到积分表示"的路径同构：都是把"离散求和"推向"连续积分"。这种"有限到极限"的跳跃，正是本网站标题里"从极限"的精神所在。</span>

## 1 正变换与逆变换

傅里叶变换对（CTFT）定义如下。**正变换**把时域信号变成频域函数：

$$X(j\omega) = \int_{-\infty}^{+\infty} x(t)\, e^{-j\omega t}\, dt$$

**逆变换**把频域还原成时域：

$$x(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} X(j\omega)\, e^{j\omega t}\, d\omega$$

记作 $x(t) \stackrel{\mathcal{F}}{\longleftrightarrow} X(j\omega)$。$X(j\omega)$ 是**频谱密度**：它在频率 $\omega$ 处的值，表示该频率成分的复幅度（含幅度与相位）。<span class="marginnote">$1/2\pi$ 出现在逆变换一侧，是积分测度的归一化；不同教材可能把 $1/\sqrt{2\pi}$ 对称分给两边——那只改变记号，不改变物理。工程教材（奥本海姆）习惯把 $X$ 写成 $j\omega$ 的函数，为的是与拉普拉斯变换的 $s$ 域统一。</span>

**存在条件（狄利克雷条件）**：$x(t)$ 绝对可积，即 $\int |x(t)|dt < \infty$。不过工程上允许通过广义函数把冲激、常数、阶跃也纳入傅里叶变换的疆域。

## 2 常用变换对

几张"面孔"值得背下来，它们是所有分析的积木：

| 信号 $x(t)$ | 傅里叶变换 $X(j\omega)$ | 说明 |
| --- | --- | --- |
| $\delta(t)$ | $1$ | 冲激含所有频率，且等权重 |
| $1$ | $2\pi\delta(\omega)$ | 直流只在 $\omega=0$ |
| $e^{j\omega_0 t}$ | $2\pi\delta(\omega - \omega_0)$ | 复正弦是单根谱线 |
| $\cos(\omega_0 t)$ | $\pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)]$ | 实正弦是两根对称谱线 |
| $\mathrm{rect}(t/T)$ | $T\,\mathrm{sinc}(\omega T/2)$ | 矩形 ↔ 抽样函数 |
| $e^{-at}u(t),\ a>0$ | $\dfrac{1}{a+j\omega}$ | 单边指数 |

**矩形脉冲与 $\mathrm{sinc}$ 的对偶**是通信里最常用的一对：时域越"窄"的脉冲，频域越"宽"；时域越"宽"，频域越"窄"。这正是后面采样定理与带宽概念的直觉来源。<span class="marginnote">"时频互斥"——时间分辨与频率分辨不可兼得，物理根源在这里。它和量子力学里的不确定关系 $\Delta x \cdot \Delta p \ge \hbar/2$ 是同一个数学结构，见第二级《量子力学》。</span>

## 3 重要性质

傅里叶变换的性质把"时域操作"翻译成"频域操作"，其中几条是工程命的：

**线性**：变换是线性映射，叠加原理在频域依旧成立。
**时移**：$x(t-t_0) \leftrightarrow e^{-j\omega t_0} X(j\omega)$——时域平移不改幅度谱，只加线性相位。
**频移（调制）**：$e^{j\omega_0 t}x(t) \leftrightarrow X(j(\omega - \omega_0))$——乘复指数把频谱搬移。**调制解调的全部数学就是这一条**。
**尺度**：$x(at) \leftrightarrow \frac{1}{|a|} X(j\omega/a)$——时域压缩 = 频域扩展。
**卷积定理**：$x(t) * h(t) \leftrightarrow X(j\omega) H(j\omega)$——**时域卷积 = 频域乘法**。
**帕塞瓦尔定理**：$\int |x(t)|^2 dt = \frac{1}{2\pi}\int |X(j\omega)|^2 d\omega$——能量守恒，时域能量 = 频域能量。

## 4 公式解析：卷积定理

卷积定理是整个课程最漂亮的一条性质，值得逐层拆开：

**第一步，写出卷积**：$y(t) = \int x(\tau) h(t-\tau) d\tau$，对它做傅里叶变换 $Y(j\omega) = \int \left[ \int x(\tau) h(t-\tau) d\tau \right] e^{-j\omega t} dt$。
**第二步，交换积分次序**：$Y(j\omega) = \int x(\tau) \left[ \int h(t-\tau) e^{-j\omega t} dt \right] d\tau$。内层对 $t$ 积分，令 $u = t-\tau$，得 $e^{-j\omega\tau} \int h(u)e^{-j\omega u}du = e^{-j\omega\tau} H(j\omega)$。
**第三步，提取**：$Y(j\omega) = \left[ \int x(\tau) e^{-j\omega \tau} d\tau \right] H(j\omega) = X(j\omega) H(j\omega)$。
**结论**：**时域的卷积积分，在频域退化成一次乘法**。这就是"滤波器为什么好算"：设计系统只需乘一个 $H(j\omega)$。

**直觉**：一个 LTI 系统对每个频率分量独立地乘上它的"增益" $H(j\omega)$——系统不混合频率，只改变每个频率的幅度与相位。<span class="marginnote">"系统不混合频率"正是 LTI 的另一种表述，它也是<strong>特征函数</strong>思想的体现：$e^{j\omega t}$ 是 LTI 系统的特征函数，$H(j\omega)$ 是对应特征值。这个看法与线性代数里"对角化矩阵"完全一致——见第二级《线性代数》特征值章节。</span>

## 5 离散与快速算法

实际计算必须数字化，于是有了**离散傅里叶变换（DFT）**与它的快速算法 **FFT**（快速傅里叶变换）。DFT 对有限长序列做周期延拓后求频谱：

$$X[k] = \sum_{n=0}^{N-1} x[n]\, e^{-j 2\pi k n / N}, \qquad k = 0, 1, \ldots, N-1$$

FFT 利用旋转因子的对称性，把 $O(N^2)$ 降到 $O(N \log N)$——这使实时频谱分析、OFDM 调制、图像压缩成为可能。<span class="marginnote">OFDM（正交频分复用）的核心就是 IDFT：发送端把数据比特当作频域系数，用 IFFT 一次性生成时域波形——一个 $N$ 点的 IFFT 就实现了 $N$ 个子载波的并行调制。这是《数字信号处理》与 4G/5G 的关键接口，见本专题《OFDM与MIMO》。</span>JPEG 里用的 DCT 是 DFT 的近亲（取实部、边界延拓更友好），原理同一。

## 6 对偶性：一张表记下半本傅里叶

傅里叶变换最迷人的性质是**对偶性（duality）**：时域里的操作，在频域里有镜像的对应。把常用变换对摆成对偶表，记忆量减半：

| 时域 | 频域 | 对偶说法 |
| --- | --- | --- |
| $\delta(t)$ | $1$ | 冲激 ↔ 直流 |
| $1$ | $2\pi\delta(\omega)$ | 直流 ↔ 冲激 |
| $e^{j\omega_0 t}$ | $2\pi\delta(\omega - \omega_0)$ | 复指数 ↔ 单根谱线 |
| $\delta(t - t_0)$ | $e^{-j\omega t_0}$ | 时移 ↔ 线性相位 |
| $\mathrm{rect}(t/T)$ | $T\,\mathrm{sinc}(\omega T/2)$ | 矩形 ↔ sinc |
| $\mathrm{sinc}(t/\tau)$ | $\tau\,\mathrm{rect}(\omega\tau/2)$ | sinc ↔ 矩形 |
| $x(t)$ | $X(j\omega)$ | 时域 ↔ 频域 |
| $X(jt)$ | $2\pi x(-\omega)$ | **双重对偶** |

**对偶性给我们的三条实用直觉**：

- **"窄 ↔ 宽"互换**：时域窄（脉冲）↔ 频域宽（sinc 展开），时域宽（sinc）↔ 频域窄（矩形）——"矩形与 sinc"互为傅里叶变换，是最经典的对偶对；
- **记忆减半**：记住时域的形态，频域自动得——**"背一张表，得两张表"**；
- **操作镜像**：时域相乘 ↔ 频域卷积、时域卷积 ↔ 频域相乘——**卷积定理与时移定理都是对偶的**。

**对偶性的本质**：傅里叶变换的积分核 $e^{-j\omega t}$ 在"时间"与"频率"两个变量上是对称的，所以"把 $t$ 和 $\omega$ 对调"后定理仍然成立。这是《线性代数》里"对偶空间"概念在函数空间的体现——**"对偶"是数学里"同一结构换个角度"的通用词汇**。

**一个加深理解的做法**：拿着这张对偶表，重看一遍《采样定理》——采样（时域乘冲激串）⇄ 频谱复制（频域卷积冲激串），正是对偶性的直接应用。**对偶性是一条贯穿傅里叶家族的红线**，抓住它，傅里叶分析就从"记忆负担"变成"一张表"。

## 7 小结

- 傅里叶变换把非周期信号分解为连续频率成分；正变换积分、逆变换带 $1/2\pi$。
- 常用变换对：冲激↔常数、矩形↔sinc；**时域窄 ⇔ 频域宽**。
- 性质工具箱：时移加相位、频移即调制、卷积定理、帕塞瓦尔能量守恒。
- 离散世界用 DFT/FFT，$O(N\log N)$ 使一切实时频域处理成为可能。

在下一节，我们把"时域与频域如何离散地互相切换"推到底：**采样定理**会告诉我们，多快的采样才能无失真地保住一个连续信号的全部信息。
