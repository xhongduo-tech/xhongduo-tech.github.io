## 为什么 Turbo 码是 1993 年的"地震"

《差错控制编码》里的汉明码能纠错，但离香农极限（《信道与噪声》的 $C = B\log_2(1+\mathrm{SNR})$）差了十万八千里。长达半个世纪，工程师相信"逼近香农极限需要天文数字的复杂度"。**1993 年 Turbo 码的诞生打破了这个信仰**：两个简单卷积码并行级联 + 迭代译码，在不到 1 dB 的差距内逼近香农极限——这是一场地震。随后被遗忘三十年的 **LDPC 码**（1963 年 Gallager 发明）重新被发现，同样逼近极限。今天，5G 的数据信道用 LDPC、控制信道用 Polar 码，全部工作在香农极限附近。<span class="marginnote">Turbo 码的论文发表时审稿人差点拒稿——因为"不可能接近香农极限"是当时公认的常识。<strong>好编码的秘密不是"更复杂的代数"，而是"让译码器之间互相交换软信息"</strong>——这个"迭代"思想改变了整个编码领域，也深刻影响了现代 AI（见下文与图神经网络的联系）。</span>

## 1 香农极限与"好码"的定义

香农信道编码定理：只要码率 $R < C$，存在码长足够长的编码使误码率任意小。**香农极限**是"给定 SNR 下，达到任意低误码率所需的最小 $E_b/N_0$"。

对 BPSK、码率 1/2，香农极限约为 $E_b/N_0 = 0$ dB（0.187 dB 是精确值附近）；
经典汉明/卷积码需要 5–7 dB 才能达到 $10^{-5}$；
Turbo/LDPC 把差距压到 **0.3–1 dB** 以内——"逼近极限"意味着同样功率下容量提升近一倍。

**"离香农极限多近"成了编码优劣的唯一标尺**——Turbo 与 LDPC 之所以伟大，不是"能纠错"，而是"几乎不浪费功率与带宽"。<span class="marginnote">"逼近香农极限"的工程回报巨大：每 1 dB 的编码增益，等价于发射功率减半、或覆盖半径扩大、或电池寿命延长。<strong>编码增益是"白拿的性能"</strong>——不增加功率、不增加带宽，只改算法。这就是为什么 3G 之后每一代移动通信都把最强编码写进标准。</span>

## 2 Turbo 码：两个译码器互相"商量"

**Turbo 码（并行级联卷积码, PCCC）** 结构：

1. 信息比特经两个卷积编码器（一个直接、一个经**交织器**打乱顺序后编码）；
2. 两个校验序列 + 原始信息，组成码字；
3. 译码端两个译码器**迭代交换"软信息"**：译码器 1 输出每个比特的置信度（LLR），交织后送给译码器 2 作为先验，译码器 2 的输出再送回译码器 1……循环若干次，置信度逐步提高，最终判决。

**交织器是 Turbo 的"魔法配料"**：它让两个码字处理"不同顺序"的比特，使错误在两个译码器之间"不重复"——一个译码器犯的错，另一个能看出来并纠正。<span class="marginnote">Turbo 的迭代译码本质是"两个专家轮流复核"：专家 1 擅长发现一类错误，专家 2 擅长另一类，双方交换"怀疑清单"（软信息）直到达成一致。<strong>这种"交替验证、逐步收敛"的机制，与深度学习里的对抗/协作训练、与《生成模型》的扩散迭代都有神似</strong>——迭代精炼是个通用范式。</span>

## 3 LDPC 码：稀疏矩阵 + 置信传播

**LDPC 码（低密度奇偶校验码）** 由 Gallager 1963 年发明，因当时算力不足被遗忘，1990 年代被重新发现。它的定义极简：一个**稀疏校验矩阵** $H$（每行每列只有少数几个 1），码字满足 $H c^T = 0$。

译码用**置信传播（belief propagation）**，在 **Tanner 图**（变量节点 ↔ 校验节点的二分图）上做消息传递：

1. 每个变量节点从信道拿到初始置信度（该位是 0/1 的似然比）；
2. 沿边向校验节点传递消息："我认为这一位是 1 的可信度是……"；
3. 校验节点做**校验和约束**（该组比特的和必须为 0 的模 2），据此向变量节点回传"修正意见"；
4. 反复迭代，置信度收敛，判决比特。

**LDPC 的性能由 $H$ 的稀疏结构决定**——一个好的 LDPC 码就像一张精心设计的"监督网络"。<span class="marginnote">置信传播是概率图模型（贝叶斯网络、马尔可夫随机场）里的标准推断算法，也是图神经网络信息传递的直系祖先。<strong>LDPC 译码 = 在一个具体图上的置信传播</strong>——1990 年代通信工程师重新发明了图模型推断，而 2010 年代深度学习又在图网络上复用同一思想，见第二级《随机过程》与第四级《图神经网络》。</span>

## 4 公式解析：置信传播的一条边

简化看 Tanner 图里一个校验节点 $c$ 向变量节点 $v$ 回传消息：

- **第一步，写约束**：校验节点连接 $d_c$ 个变量，约束"它们之和为 0（模 2）"。
- **第二步，消息形式**：校验节点回传"我认为 $v$ 应该是 0 的概率"，用 LLR 表示：
$$\mathrm{LLR}(v) = \ln\frac{P(v=0)}{P(v=1)}$$
- **第三步，校验更新（和积算法）**：对 $v$ 来说，其余 $d_c-1$ 个变量的"和"必须等于 $v$ 的取反。LLR 的更新用 $\tanh$ 规则：
$$\tanh\frac{L_{c\to v}}{2} = \prod_{u \neq v} \tanh\frac{L_{u\to c}}{2}$$
- **第四步，解读**：校验节点把邻居们的置信度"相乘"后回传——因为"全为 0 或偶数个 1"的概率是乘积形式。**每条消息都是一次"概率的乘法"**，迭代就是让信息在图上流动收敛。
- **易错点**：置信传播在**有环图**上不保证收敛到精确解——LDPC 的 Tanner 图必须精心设计（大围长，即避免短环），否则性能崩坏。**"图的结构决定译码好坏"**是 LDPC 设计的核心。

## 5 现代标准里的编码版图

迭代码已经全面进入标准：

| 系统 | 信道编码 | 说明 |
| --- | --- | --- |
| 3G（UMTS） | Turbo | 第一个进入标准的主流迭代码 |
| 4G（LTE） | Turbo | 数据信道主力 |
| DVB-S2 / WiFi | LDPC | 广播与短距的高速编码 |
| 5G NR 数据 | **LDPC** | 大数据块，低复杂度高速译码 |
| 5G NR 控制 | **Polar 码** | 小数据块，短码性能极优 |

**Polar 码**（2008 年，E. Arıkan）是另一条路：利用"信道极化"构造出理论上达到香农容量的码——它是第一个**被证明容量可达**的码。5G 的控制信道短码块用 Polar，数据信道长码块用 LDPC——"短码看 Polar，长码看 LDPC"成了工程共识。<span class="marginnote">编码理论的演进像一场接力赛：汉明（代数结构）→ 卷积（有记忆）→ Turbo（级联+迭代）→ LDPC（稀疏图+置信传播）→ Polar（信道极化）。<strong>每一代都在逼近同一个目标：香农极限</strong>——这是通信理论"理论先行、工程追赶"的最佳注脚。</span>

## 6 迭代译码的统一视角：因子图与和积算法

Turbo 与 LDPC 表面不同，骨子里是同一套算法——**在因子图（factor graph）上做和积算法（sum-product / belief propagation）**。这个统一视角是理解现代编码的最高层。

**因子图**：把"变量"（码字比特）与"因子"（校验约束、信道先验）画成二分图——LDPC 的 Tanner 图是它，Turbo 的级联结构也是它。

**和积算法**：消息沿边双向传递——变量节点把"我的当前置信度"传给因子节点，因子节点把"按约束修正后的意见"传回来，迭代直到收敛（见《公式解析》的 tanh 规则）。**Turbo 与 LDPC 的迭代译码，都是和积算法的特例**。

**为什么"迭代交换软信息"能逼近香农极限**：

- 每个约束单独看都很弱（一个校验和只能"感觉"到一位错），但**约束之间通过共享变量耦合**——信息在图上流动，把分散的证据汇成整体判断；
- **"局部推理 + 全局传播"**：像一群目击者互相核对证词，每个人只知道局部，交换后达成一致的全局判断；
- **长码的威力**：码越长、约束越多，因子图越大，"证词"越充分，越逼近香农极限。

**这个思想在 AI 里的回响**：

- 图神经网络（GNN）的消息传递 = 和积算法的可学习版本（见第四级《图神经网络》）；
- 扩散模型的迭代去噪 = "多轮精炼"的另一种形态；
- 大模型的链式推理 = "逐步累积证据"的序列版。

**"局部约束 + 迭代传播"是 20 世纪最深刻的算法思想之一**——它同时统治了纠错编码、概率图模型推断与今天的深度学习。**Turbo/LDPC 不是孤立的技术，而是这条思想长河在通信里的源头**。

**一句话**：现代信道编码 = "把信息编进稀疏约束 + 让约束在图上传话"——**编得越稀疏、图设计得越好，译码越接近最优**。

## 7 小结

- 香农极限是"给定 SNR 的最低 $E_b/N_0$"，Turbo/LDPC 把差距压到 0.3–1 dB。
- **Turbo 码** = 两个卷积码 + 交织器 + 迭代交换软信息；交织让两译码器的错误不重复。
- **LDPC 码** = 稀疏校验矩阵 + Tanner 图上的置信传播，性能由图的围长决定。
- 置信传播是概率图模型推断，也是图神经网络的直系祖先——编码与 AI 在此交汇。
- 现代标准：5G 数据用 LDPC、控制用 Polar，短码看 Polar、长码看 LDPC。
