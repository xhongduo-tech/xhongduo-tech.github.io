## 为什么必须研究 LTI 系统

上一节我们认识了信号，但通信工程真正关心的是**系统**——把输入信号变成输出信号的机器。现实中的系统五花八门：滤波器、放大器、均衡器、信道……如果对每个系统都从头算起，工程将寸步难行。幸运的是，绝大多数系统满足两条朴素性质：**线性（linearity）**与**时不变性（time invariance）**。满足这两条的系统称为 **LTI 系统（Linear Time-Invariant system）**，它们构成信号与系统课程的全部主角。<span class="marginnote">为什么 LTI 如此重要？因为线性给了你叠加原理，时不变给了你平移等价：系统对任意输入的响应，可以由它对单个"基本信号"的响应拼出来。这个思想与线性代数里"用基向量展开向量"是同构的——矩阵就是线性系统，卷积就是矩阵乘法，见第三级《线性代数》。</span>

## 1 线性与时不变

### 线性

若输入 $x_1(t)$ 得输出 $y_1(t)$，输入 $x_2(t)$ 得输出 $y_2(t)$，则对任意常数 $a, b$ 有

$$\mathcal{T}\{a x_1(t) + b x_2(t)\} = a y_1(t) + b y_2(t)$$

这条性质叫**叠加性**。它把"复杂输入"分解成"简单输入的和"，逐项算完再叠加。

### 时不变

若 $x(t) \to y(t)$，则对任意延时 $t_0$ 有

$$x(t - t_0) \to y(t - t_0)$$

**系统的行为不随启动时间改变**：今天测的冲激响应，明天测也一样。它保证了"同样的输入在任何时刻都得到同样的输出形状"，只是平移。

## 2 冲激响应与卷积表示

LTI 系统的全部秘密藏在一个信号里：**冲激响应 $h(t)$**，即输入为单位冲激 $\delta(t)$ 时的输出。

**冲激函数（Dirac delta）**：满足

$$\delta(t) = 0 \ (t \neq 0), \qquad \int_{-\infty}^{+\infty} \delta(t)\, dt = 1$$

它是在 $t=0$ 处"无限高、无限窄、面积为 1"的理想脉冲<span class="marginnote">$\delta(t)$ 不是普通函数，它的严格定义要放到广义函数（分布）理论里，见第二级《泛函分析》的 Sobolev 空间与分布一节。工程上把它当作"瞬间冲击"就好：敲一下铃、发一个脉冲、点一下火，都是 $\delta$ 的物理化身。</span>。

LTI 系统对任意输入 $x(t)$ 的响应，可以写成输入与冲激响应的**卷积**：

$$y(t) = x(t) * h(t) = \int_{-\infty}^{+\infty} x(\tau)\, h(t - \tau)\, d\tau$$

这个式子威力巨大：**只要知道 $h(t)$，任何输入的系统响应都是"一个积分"**，而卷积将在下一节专门展开。

## 3 系统性质的判别

工程上拿到一个系统，先判它是不是 LTI、再判它好不好用。两类重要性质：

**因果性（causality）**：输出只依赖当前及过去的输入，不依赖未来。对 LTI 系统，因果等价于

$$h(t) = 0, \quad t < 0$$

**稳定性（stability）**：有界输入必有有界输出（BIBO 稳定）。对 LTI 系统，等价于冲激响应绝对可积：

$$\int_{-\infty}^{+\infty} |h(t)|\, dt < \infty$$

这两个条件把 $h(t)$ 的"形状"限制住了：因果要求它只活在右半轴，稳定要求它衰减得够快。<span class="marginnote">稳定性的物理解释：过去的一次冲击的"余音"必须随时间消失，否则系统会积累出无穷大的输出。这与随机过程里"平稳序列的系数平方和收敛"是同一类要求，见第二级《随机过程》。</span>

## 4 微分方程与零输入/零状态响应

连续 LTI 系统最常用的数学模型是**常系数线性微分方程**：

$$\sum_{k=0}^{N} a_k \frac{d^k y(t)}{dt^k} = \sum_{k=0}^{M} b_k \frac{d^k x(t)}{dt^k}$$

求它的通解有个工程上极有用的拆分：**全响应 = 零输入响应 + 零状态响应**。

- **零输入响应**：令输入 $x(t)=0$，只由初始储能（电容电压、电感电流的初值）驱动的部分。
- **零状态响应**：令初始条件为 0，只由输入驱动的部分，恰好等于 $x(t) * h(t)$。

这条拆分与线性代数里的**齐次解 + 特解**一脉相承，也与常微分方程课程里"通解 = 齐次通解 + 特解"严格对应，见第二级《常微分方程》。

## 5 公式解析：全响应的三分法

对一个具体方程，比如一阶 RC 电路 $y'(t) + 2y(t) = 3x(t)$，初始条件 $y(0^-) = 1$，输入 $x(t) = e^{-t}u(t)$：

- **第一步，解齐次方程**：$y' + 2y = 0$ 得特征根 $s = -2$，零输入响应形如 $y_{zi}(t) = A e^{-2t}$。代入初值 $y(0^-)=1$ 得 $A=1$，即 $y_{zi}(t) = e^{-2t}u(t)$。
- **第二步，求冲激响应**：对微分方程做单位冲激激励。一阶系统 $h(t) = 3e^{-2t}u(t)$（系数来自方程右端的 3，指数来自特征根 $-2$）。
- **第三步，卷积求零状态响应**：$y_{zs}(t) = x(t) * h(t) = \int_0^t 3 e^{-2(t-\tau)} e^{-\tau} d\tau = 3(e^{-t} - e^{-2t})u(t)$。
- **第四步，相加**：$y(t) = y_{zi}(t) + y_{zs}(t) = e^{-2t}u(t) + 3(e^{-t} - e^{-2t})u(t) = (3e^{-t} - 2e^{-2t})u(t)$。

**易错点**：零输入响应与零状态响应各自独立求解、最后相加；**不能**先求全响应再分解。原因在于线性系统满足叠加原理——初值与输入是两个独立的"激励源"。

## 6 连续与离散 LTI：一对孪生系统

本专题从连续 LTI 讲起，又讲了离散的 Z 变换——这两套理论是"孪生兄弟"，处处平行。列一张对照表，一套理解两处用：

| 概念 | 连续时间 | 离散时间 |
| --- | --- | --- |
| 基本信号 | 冲激 $\delta(t)$ | 单位脉冲 $\delta[n]$ |
| 系统描述 | 微分方程 | 差分方程 |
| 冲激响应 | $h(t)$ | $h[n]$ |
| 卷积 | $\int x(\tau)h(t-\tau)d\tau$ | $\sum_k x[k]h[n-k]$ |
| 变换 | 拉普拉斯（$s$ 域） | Z 变换（$z$ 域） |
| 频率响应 | $H(j\omega)$ | $H(e^{j\omega})$ |
| 因果 | $h(t)=0\ (t<0)$ | $h[n]=0\ (n<0)$ |
| 稳定 | 极点全在左半平面 | 极点全在单位圆内 |

**三组最值得记住的"平行"**：

1. **$s$ 左半平面 ⇄ $z$ 单位圆内**：经 $z = e^{sT_s}$ 映射，稳定性判据从"左半平面"变成"单位圆内"——**同一个判据，两套坐标系**；
2. **积分 ⇄ 求和**：卷积积分与卷积求和的每一项对应，推导和图形法完全同构（见《卷积》）；
3. **微分方程 ⇄ 差分方程**：解方程的方法（零输入+零状态）完全平行——**"一套方法论，两个战场"**。

**为什么学两遍**：现实世界是连续的（物理信号），数字世界是离散的（计算机处理）——**连接它们的正是《采样定理》**。学连续 LTI 是为理解物理，学离散 LTI 是为实现数字，而采样定理是两者之间的桥。**"连续是世界观，离散是方法论"**，本专题第一篇的编排正沿这条线展开。

**一句话**：LTI 理论是人类工程最有"对称美"的一章——**学透一边，另一边只是"翻译"**。

## 7 小结

- **LTI 系统** = 线性 + 时不变；线性给叠加，时不变给平移等价。
- 冲激响应 $h(t)$ 完全刻画 LTI 系统，任意输出 $y(t) = x(t) * h(t)$。
- 因果系统 $h(t)=0\,(t<0)$；BIBO 稳定 $\Leftrightarrow$ $h(t)$ 绝对可积。
- 全响应拆成**零输入响应 + 零状态响应**，前者来自初值，后者来自输入。

在下一节，我们把积分 $\int x(\tau)h(t-\tau)d\tau$ 本身当作主角，研究卷积的几何意义与运算规律——它是连接时域与频域的枢纽。
