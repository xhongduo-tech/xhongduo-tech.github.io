## 为什么从复合控制开始

反馈控制有一个天生的「时间错位」：它**先等误差出现，再动手纠正**。对于已知的、可测的输入或扰动，这显得很被动——明明知道扰动要来，为什么非要等它破坏了输出才反击？**复合控制（composite control）**在反馈环路之外再加一条**前馈（顺馈）通路**，让系统「提前出手」：对可测的输入信号预先施加补偿，对可测的扰动提前抵消。它的杀手锏是：**前馈不影响闭环特征方程，所以能在不牺牲稳定性的前提下，把稳态误差甚至动态误差大幅压缩**。这是精度与抗扰性能的一次质的飞跃，也是现代伺服系统（数控、雷达跟踪、飞行器）的标配结构。<span class="marginnote">复合控制的哲学：反馈负责「兜底」——应对建模误差与不可测扰动；前馈负责「抢跑」——对已知信号提前反应。二者互补，正是工程上「把问题消灭在发生之前」的思路。</span>

## 1 为什么前馈不破坏稳定性

理解复合控制的关键，是弄清前馈通路在结构图中的位置：它**平行于反馈回路**，从输入（或扰动）直连到控制输入端，不经过反馈环。

设系统前向通道为 $G_1(s)G_2(s)$，反馈通道为 $H(s)$，前馈补偿为 $F(s)$。系统的闭环特征方程仍由 $1 + G_1 G_2 H = 0$ 决定——**$F(s)$ 不出现在特征方程里**。

这意味着：**前馈网络 $F(s)$ 的选择只影响响应与误差，不改变系统的极点，也就不会引入新的稳定性问题**。反馈的稳定性代价，前馈一分钱不花就能避开。这正是复合控制最诱人的地方。<span class="marginnote">对比记忆：反馈校正动极点、改稳定性；前馈校正只动零点与增益、不改稳定性。所以复合控制常常是「反馈管稳定，前馈管精度」——各司其职，互不打架。</span>

## 2 按输入补偿（顺馈）：输出完全复现输入

**按输入补偿**是复合控制的第一种形式：把输入信号 $r(t)$ 经前馈装置 $F_r(s)$ 直接叠加到控制输入端，目的是让输出更快、更准地跟上输入。

系统对输入的总传递函数可写为：

$$\Phi(s) = \frac{C(s)}{R(s)} = \frac{[G_1(s) + F_r(s)]G_2(s)}{1 + G_1(s)G_2(s)H(s)}$$

若取前馈装置使分子中的 $F_r$ 满足：

$$F_r(s) = \frac{1}{G_2(s)} - G_1(s)$$

则分子恰好约去分母的 $1 + G_1G_2H$ 的互补结构，使 $\Phi(s)$ 的理想形式接近 1，即 $C(s) \approx R(s)$——**输出完全复现输入，误差恒为零**。这称为**完全不变性（total invariance）**。<span class="marginnote">完全不变性要求前馈装置是对象传递函数的精确逆，这在物理上难以严格实现（微分次数太高、模型不准）。工程上退而求其次，做到「部分不变性」——只对某类典型输入（阶跃/斜坡）实现零误差，即足够实用。别被"完全"二字吓到，它是理想极限。</span>

**辨析｜易错点：** 完全不变性条件的公式形式容易记混。它的逻辑是「让前馈通路 + 原前向通道的组合，在理想情况下等于反馈环的逆」——推导时直接从 $E(s) = R(s) - C(s)$ 出发，令 $E(s)=0$ 反解 $F_r(s)$ 最可靠，别死记公式。<span class="marginnote">实用上，对按输入补偿还有一个直觉版本：如果前馈能精确复现「要达到控制目标所需的那部分控制量」，反馈就只需处理误差的残差。这就是伺服系统里「前馈为主、反馈为辅」的工程配置。</span>

## 3 按扰动补偿：抗扰的不变式

**按扰动补偿**是复合控制的第二种形式：对**可测量的扰动** $n(t)$（如电网电压波动、负载变化），用前馈装置 $F_n(s)$ 在扰动进入对象之前就施加反向补偿。

设扰动 $N(s)$ 作用在被控对象 $G_2(s)$ 的入口，前馈 $F_n(s)$ 从扰动测量点连到同一入口。系统对扰动的传递函数为：

$$\Phi_n(s) = \frac{C(s)}{N(s)} = \frac{G_2(s)[1 - F_n(s)G_1'(s)]}{1 + G_1(s)G_2(s)H(s)}$$

取 $F_n(s) = 1/G_1'(s)$，则 $\Phi_n(s) = 0$——**扰动对输出完全不起作用**，这就是**扰动不变性（invariance with respect to disturbance）**。

**辨析｜易错点：** 按扰动补偿的硬前提是**扰动必须可测**。不可测的扰动无法前馈，只能靠反馈慢慢消除。另一个注意点：前馈补偿 $F_n$ 若实现不准，效果反而恶化——所以工程上只对**主要、可测、模型较准**的扰动做前馈补偿，其余交给反馈。<span class="marginnote">典型工程例：火炮随动系统的负载力矩扰动可测（电机电流反映负载），用电流前馈补偿负载突变；锅炉汽包水位控制里给水流量扰动可测，直接前馈抵消。补偿掉大头，反馈处理残差。</span>

## 4 公式解析：按输入补偿的完全不变性条件

$$F_r(s) = \frac{1}{G_2(s)} - G_1(s)$$

对它做四步拆解：

- **第一步，从误差出发**：单位反馈时 $E(s) = R(s) - C(s)$。要误差恒为零，就要 $C(s) = R(s)$，即闭环传函 $\Phi(s) = 1$。
- **第二步，写出带前馈的闭环传函**：$\Phi(s) = \frac{[G_1(s) + F_r(s)]G_2(s)}{1 + G_1(s)G_2(s)}$（单位反馈 $H=1$）。令它等于 1，解出 $F_r$。
- **第三步，解方程**：$[G_1 + F_r]G_2 = 1 + G_1G_2 \Rightarrow F_r G_2 = 1 \Rightarrow F_r = 1/G_2$。注意 $G_1$ 在两边消掉了——前馈装置只需补偿**前向通道的后半段** $G_2$，这正是「把控制目标要的那部分量直接算出来」的数学体现。
- **第四步，看可实现性**：$F_r = 1/G_2$ 若 $G_2$ 含延时或分子次数高于分母（物理不可实现的微分），严格实现不可能。工程上取近似，或用「按典型输入补偿」的思路，保证阶跃/斜坡/抛物线输入的稳态误差为零。

## 5 复合控制的工程组合

工程上从不只靠一条前馈通路，而是**前馈 + 反馈 + PID 的多层复合**：

- **反馈环（内层）**：保证稳定性，处理不可测扰动与建模误差。
- **输入前馈（中层）**：让输出快速准确地跟踪输入指令，减轻反馈负担。
- **扰动前馈（外层）**：对已知主要扰动提前抵消。

这套结构在数控机床、雷达跟踪、导弹制导、卫星姿态控制中被反复使用。它与《智能控制》里基于模型的前馈思想（如逆模型补偿）一脉相承——**凡是可预测的，就不等它造成误差**。<span class="marginnote">复合控制也是后面《现代控制理论》前馈-反馈结构、以及《最优控制》中「前馈 + 状态反馈」在经典框架里的雏形。把这条「能预测就前馈」的直觉带到现代控制，会顺畅很多。</span>

## 6 复合控制的工程实例

复合控制不是纸上谈兵，三个真实场景能帮你把"前馈管已知、反馈管未知"的分工刻进直觉。

**数控机床的加速度前馈**：机床进给轴跟踪高速曲线时，仅靠反馈会有明显的跟踪滞后（轮廓误差）。工程上按轨迹指令的**加速度**加前馈——提前给电机一个与加速度成正比的电流，抵消惯性滞后。指令已知，前馈"抢跑"；负载波动等未知量，交给反馈兜底。<span class="marginnote">机床行业的"速度前馈 + 加速度前馈"叠加，能让轮廓误差从丝级降到微米级。前馈系数标定得越准，反馈的负担就越轻——"能预测就前馈"在精密运动控制里被用到极致。</span>

**雷达天线伺服**：天线跟踪目标时，目标角速度可测。把目标角速度折算成天线的速度指令前馈，再叠加位置反馈——天线既跟得紧，又不会被目标突然变速带偏。这是随动系统（伺服）里前馈的标准用法。

**锅炉汽包水位三冲量控制**：锅炉汽包水位受"虚假水位"现象困扰——蒸汽负荷突增时水位先上升后下降，纯反馈会被误导。工程方案是**三冲量**：水位（反馈）+ 蒸汽流量（前馈）+ 给水流量（内环）。蒸汽流量变化提前前馈调整给水，避免水位大幅波动。这是过程控制里前馈 + 反馈 + 串级结合的经典案例。

**辨析｜易错点：** 前馈的前提是"**可测**且"**模型够准**"。前馈装置 $F(s)$ 依赖对象模型，模型错、补偿就错，甚至帮倒忙。工程铁律：**前馈只补偿"主要、可测、模型较准"的已知量，其余一律交给反馈**——复合控制的智慧不在"前馈有多强"，而在"知道什么该交给前馈、什么必须留给反馈"。<span class="marginnote">这条铁律其实是一条通用工程原则：把可预测的部分消灭在发生之前，把不可预测的部分交给闭环兜底。从锅炉水位到自动驾驶，从 PID 到 MPC，这条原则无处不在。</span>

**复合控制的性能量化**：前馈对跟踪精度的提升可以用误差的频域分解来理解。设反馈系统的误差传递函数为 $\Phi_e(s)$，加入输入前馈 $F_r(s)$ 后，误差变为：

$$E(s) = \Phi_e(s)\big[1 - F_r(s)G(s)\big]R(s)$$

当 $F_r$ 逼近 $1/G$ 时，误差因子 $1-F_rG \to 0$——这就是"前馈把误差的来源直接消掉"。工程测量上，同一组 PID 参数下，加与不加前馈的轮廓误差可能相差一个数量级。

**复合控制的取舍清单**：

- 前馈只对"可测、可预测"的信号有效——不可测扰动必须靠反馈。
- 前馈装置依赖模型，模型不准则补偿失准，甚至恶化性能。
- 前馈不改闭环极点、不牺牲稳定性——这是它最大的安全优势。
- 综合设计顺序：先调好反馈（保证稳定与基本性能），再加前馈（提升跟踪精度）。

这条"先反馈兜底、再前馈提精"的顺序，是所有复合控制系统共同的施工准则。

**前馈与反馈的哲学收尾**：复合控制把控制工程的两条根本原则统一在一套系统里——**反馈是"等误差出现再纠正"的稳健主义，前馈是"提前算准再行动"的理想主义**。真实的工程总是两者的折中：理想主义者算得准的部分交给前馈，现实主义者兜底的部分留给反馈。学完这一节，你掌握的不仅是一个控制结构，更是一套"如何把已知与未知分开处理"的思维方法，它适用于控制、也适用于一切决策系统。

**复合控制的现代形态**：今天的复合思想早已超出经典前馈——**MPC 的"预测-滚动"本质是时域前馈 + 反馈**，**扰动观测器**把不可测扰动当状态估计出来再前馈补偿，**逆模型控制**（神经网络学逆模型当前馈）是前馈的智能版本。学完本节的"经典前馈"，你会在后续 MPC、滑模、神经网络控制里反复看到它的现代变体——**"能预测就前馈"这条原则贯穿整个智能控制专题**。

**总结一句**：复合控制 = 反馈（兜底未知）+ 前馈（预判已知）——**把"可预测的"消灭在发生之前，把"不可预测的"交给闭环兜底**。这条原则是控制工程最朴素也最深刻的智慧之一。

它贯穿本专题始终：从第一课《控制系统基本概念》的反馈到本节的复合前馈，从 PID 的积分到 MPC 的滚动预测——**所有控制器本质上都在做"预测已知、兜底未知"这一件事**。

## 7 小结

- **复合控制** = 反馈 + 前馈，前馈分**按输入补偿**与**按扰动补偿**两种。
- 前馈通路**不改变闭环特征方程**，因此不影响稳定性——这是它区别于反馈校正的最大优点。
- **完全不变性**：按输入补偿取 $F_r = 1/G_2$ 时输出完全复现输入；按扰动补偿取 $F_n = 1/G_1'$ 时扰动对输出无影响。
- 工程上做**部分不变性**（对典型输入零误差），并对主要可测扰动前馈、其余交给反馈。
- 复合结构是伺服、制导、姿态控制等高性能系统的标配。

至此，经典控制理论（第一篇）从建模、分析到设计的完整闭环已经走通：**微分方程与传递函数 → 时域/根轨迹/频域三副眼镜 → 稳定性与误差 → 校正与复合**。接下来，我们进入现代控制理论，从「系统的外部描述」深入到「系统的内部状态」——第一站是**状态空间描述**。
