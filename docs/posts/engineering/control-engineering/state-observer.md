# 状态观测器

<div class="epigraph">
<p>我们无法直接看见系统的内部状态，但可以让一台计算机模仿系统，再用输出去校准它的误差。</p>
<footer>—— 状态重构思想（D. G. Luenberger, 1964）</footer>
</div>

## 为什么从状态观测器开始

上一节的状态反馈威风凛凛，但它有一个前提：**全部状态可测量**。现实里这几乎从不成立——炉温的内部温度分布、火箭的弹性模态、电机的转子磁链，全都不可直接测量。1964 年，龙伯格（David Luenberger）给出答案：**用一台"影子系统"（观测器）在线重构状态**。思路朴素而漂亮：既然系统模型已知，就让一台计算机按同样的动力学跑起来，再把实际输出与影子输出的差作为修正项反馈进影子系统，使影子状态 $\hat{x}$ 不断逼近真实状态 $x$。观测器设计（选择增益矩阵 $L$）与极点配置完全对偶，并且——关键的一步——**观测器与状态反馈可以分开设计，互不干扰**（分离原理）。状态反馈 + 状态观测器合起来，就是现代控制完整的"输出反馈 → 全状态控制"闭环。<span class="marginnote">观测器在工程上无处不在：传感器太贵、太慢、装不下的地方，都用观测器（软件传感器）。电力驱动的磁链观测、航天器的姿态估计、化工的过程软测量——本质都是同一件事：用模型 + 可测输出重构不可测状态。</span>

## 1 开环重构的问题

最朴素的重构想法：用系统模型 $\dot{\hat{x}} = A\hat{x} + Bu$ 直接仿真。输入 $u$ 已知，只要初始状态对，仿真就是真实状态。

但有两个致命问题：

- **初始状态不知道**：$\hat{x}(0)$ 与 $x(0)$ 不同，误差从第一秒就存在；
- **模型与输入有误差**：$A, B$ 不可能完全准确，扰动也存在，误差会**累积放大**（若 $A$ 有正实部特征值，误差指数增长）。

所以**开环重构不可行**——观测器必须用输出信息把误差"拉回来"。

## 2 全维观测器的结构

**全维观测器（full-order observer）**在模型基础上加一个修正项：输出误差 $\tilde{y} = y - \hat{y}$ 乘增益 $L$ 反馈到状态方程：

$$\dot{\hat{x}} = A\hat{x} + Bu + L\big(y - C\hat{x}\big)$$

其中 $\hat{y} = C\hat{x}$ 是观测器的输出估计，$L$ 是 $n\times p$ 的**观测器增益矩阵**。物理图像：影子系统按模型演化，同时"盯着"真实输出，一旦发现偏差，就施加一股与偏差成正比的修正力，把影子状态拉向真实状态。<span class="marginnote">观测器结构与控制器结构惊人地对称：控制器是"状态偏差 $x$ 乘 $K$ 作用于输入"，观测器是"输出偏差 $y-\hat y$ 乘 $L$ 作用于状态"。一个往前控制，一个往回估计，正是现代控制的对偶美。</span>

## 3 观测器误差的动态

定义观测误差 $\tilde{x} = x - \hat{x}$。用真实系统方程减去观测器方程：

$$\dot{\tilde{x}} = (A - LC)\tilde{x}$$

这个误差方程极其干净：误差的演化只由 $A - LC$ 决定，**与输入 $u$ 和参考 $v$ 无关**！只要 $A - LC$ 的特征值全在左半平面，观测误差指数衰减到零——$\hat{x}$ 渐近收敛到 $x$。

于是观测器设计问题变成：**选择 $L$ 使 $A-LC$ 的特征值（观测器极点）位于指定的左半平面位置**。这与极点配置问题完全对偶：

- 极点配置：选 $K$ 使 $A - BK$ 特征值在指定位置（要求能控）；
- 观测器设计：选 $L$ 使 $A - LC$ 特征值在指定位置（要求能观）。

**能观性是观测器存在的前提**——不能观的状态，从输出里提取不到信息，观测器无能为力。<span class="marginnote">对偶公式：$A-LC$ 的极点配置 ⟺ $A^T - C^T L^T$ 的极点配置（把 $A$ 换成 $A^T$、$B$ 换成 $C^T$）。所以可以直接复用上一节的阿克曼公式，把 $(A^T, C^T)$ 代进去求 $L^T$。</span>

## 4 公式解析：观测器方程

$$\dot{\hat{x}} = A\hat{x} + Bu + L\big(y - C\hat{x}\big)$$

对它做四步拆解：

- **第一步，看前三项**：$A\hat{x} + Bu$ 是影子系统的模型演化——它是观测器的"预测"部分（基于已知输入）。
- **第二步，看修正项**：$L(y - C\hat{x})$ 是观测器的"校正"部分（基于测量输出）。$y - C\hat{x}$ 是**输出预测误差**，$L$ 决定校正确信度。
- **第三步，看 $L$ 的作用**：$L$ 大，修正猛，误差收敛快，但测量噪声被放大；$L$ 小，收敛慢但抗噪好。观测器极点的选取是「快收敛」与「抗噪声」的折中——与控制器设计里"增益大 vs 噪声大"的权衡完全平行。
- **第四步，看整体结构**：观测器本质是一个**由 $u$ 和 $y$ 驱动的线性系统**，它的输出 $\hat{x}$ 就是状态估计。这个结构在后面的卡尔曼滤波中会原样保留，只是 $L$ 不再固定，而是随时间按噪声统计最优地变化。

## 5 分离原理

最精彩的一步在这里：把状态反馈与观测器**组合**起来。

系统方程：$\dot{x} = Ax - BK\hat{x} + Bv$
观测器方程：$\dot{\hat{x}} = (A - LC)\hat{x} + Bu + Ly$
误差方程：$\dot{\tilde{x}} = (A - LC)\tilde{x}$

把 $x = \hat{x} + \tilde{x}$ 代入系统方程，闭环系统的特征多项式为：

$$\det(sI - A + BK)\cdot\det(sI - A + LC)$$

**分离原理（separation principle）**：闭环极点 = 状态反馈极点（来自 $A-BK$）与观测器极点（来自 $A-LC$）的**并集**，两者互相独立。

这意味着：**控制器与观测器可以分开设计**——先按性能要求设计 $K$，再按收敛/抗噪要求设计 $L$，合起来仍是最优组合。这是现代控制工程实践的一根支柱：设计的复杂性被拆成两个可独立处理的问题。<span class="marginnote">分离原理的一个经典直觉：控制器负责"指挥"，观测器负责"侦察"，两者各管各的。这也是为什么 LQG（线性二次高斯）问题能拆成 LQR + 卡尔曼滤波两个独立子问题——分离原理是它的理论基石。</span>

## 6 工程实践：观测器极点的选取

观测器极点该放哪？经验法则：

- **观测器收敛要比控制器快**：观测器极点实部通常取控制器极点的 3~10 倍，让估计值先稳定下来再发挥作用；
- **不能太快**：极点太左，$L$ 过大，测量噪声被严重放大——估计抖得像筛糠；
- **折中**：工程上常取观测器带宽为控制带宽的 5~10 倍，并用仿真验证噪声表现。

**辨析｜易错点：** 观测器与控制器都涉及"极点配置"，但别混：控制器配 $A-BK$、要求**能控**；观测器配 $A-LC$、要求**能观**。四个矩阵（$A,B,C$ 与两个增益 $K,L$）的位置关系是本节最常考也最常错的结构题。<span class="marginnote">现代工程里观测器常升级为卡尔曼滤波器（下一节）：当过程噪声与测量噪声的统计已知时，卡尔曼滤波按"最小方差"原则给出随时间最优变化的 $L(t)$——固定增益的龙伯格观测器是它的确定性特例。学完下一节，这套"影子系统 + 校正增益"的图景会更完整。</span>

## 7 降维观测器

全维观测器估计全部 $n$ 个状态，但其中有些状态其实**直接可测**（由输出 $y=Cx$ 直接给出）。既然可测，就不必"猜"——这启发了**降维观测器（reduced-order observer）**：只估计不可直接测量的那 $n-p$ 个状态，观测器阶数从 $n$ 降到 $n-p$。

设输出已包含 $p$ 个状态（经过坐标变换 $C = [I_p \ 0]$ 后），状态分成可测部分 $x_1$ 与待估部分 $x_2$。对 $x_2$ 构造一个 $n-p$ 阶观测器，其结构与全维观测器同构，只是增益矩阵维数更小。<span class="marginnote">降维观测器的工程意义：传感器能测的量就别让观测器白费功夫。例如电机里电流 $i$ 直接可测（电流传感器），只需降维观测器估计转速与磁链——少估一个量，少一分噪声放大。</span>

**设计要点**：降维观测器的收敛极点仍由"估计误差矩阵 $A_{22} - L A_{12}$"的特征值决定，设计方法与全维观测器完全平行——选 $L$ 使这部分特征值在指定左半平面位置。能观性条件同样必要。

**全维 vs 降维的取舍**：全维观测器结构统一、抗噪性好（对可测状态的估计还能平滑噪声）；降维观测器阶数低、计算省，但可测状态直接用测量值（噪声未滤）。工程上若传感器噪声小，用降维省算力；噪声大，用全维顺便滤波。<span class="marginnote">一个容易忽略的细节：降维观测器输出的估计 $\hat x_2$ 直接由测量驱动，不需要对 $x_1$ 建观测器方程，所以它的收敛速度可以比全维更激进。但"越激进越放大噪声"这条规律依然成立。</span>

**辨析｜易错点：** 降维观测器的设计要**先做坐标变换**把 $C$ 化成 $[I\ 0]$ 形式，变换后增益 $L$ 要变回原坐标系才能用。别在原坐标下直接套公式——这是降维观测器实现里最常见的错误来源。

**观测器的工程应用：故障诊断**：观测器不止服务于状态反馈，它还是**故障检测与诊断**的核心工具。思路很直接：

1. 用健康模型构造观测器，输出估计 $\hat y = C\hat x$；
2. 计算**残差** $r = y - \hat y$（真实输出与估计输出之差）；
3. 健康运行时残差接近零（只有噪声）；发生故障（传感器失效、执行器卡死、部件损坏）时，残差偏离零，据此报警并定位故障。

**为什么观测器适合做这件事**：观测器给出"健康系统本应如何"的参考行为，真实系统一旦偏离，残差立刻暴露异常——"影子系统"变成了"健康基准"。这类技术叫**基于模型的故障诊断**，在航空航天、核电、化工安全里是标准配置。<span class="marginnote">残差设计是一门学问：扰动也会引起残差，所以工程上要做"残差解耦"——让残差只对故障敏感、对扰动不敏感（如未知输入观测器、$H_\infty$ 残差生成）。"把故障从扰动里挑出来"是故障诊断的核心难点。</span>

**辨析｜易错点：** 观测器做故障诊断的前提是**模型可靠**——模型偏差大，健康时残差就很大，误报满天飞。所以故障诊断系统上线前要做"残差基线"标定，把模型误差与故障特征分开。

## 8 小结

- **开环重构不可行**（初值未知、误差累积），观测器用输出修正把误差拉回。
- **全维观测器**：$\dot{\hat{x}} = A\hat{x} + Bu + L(y - C\hat{x})$，误差动态 $\dot{\tilde{x}} = (A-LC)\tilde{x}$。
- 观测器极点由 $A-LC$ 决定，设计即选 $L$；**能观性**是前提，与极点配置对偶。
- **分离原理**：状态反馈 + 观测器的闭环极点 = 两者极点之并，可分开设计。
- 观测器极点选取是「收敛快」与「抗噪」的折中，通常比控制器快 3~10 倍。

在下一节，我们把固定增益的观测器升级为**卡尔曼滤波**：当噪声统计已知时，用概率与最小方差原则给出最优的时变估计。
