# 滑模控制

<div class="epigraph">
<p>滑模控制不试图精确抵消不确定性，而是用一股足够强的力，把状态压到一条轨道上，让不确定性无能为力。</p>

## 为什么从滑模控制开始

鲁棒控制（下一节）用复杂数学对付不确定性；**滑模控制（sliding mode control, SMC）**则用一种更"暴力"也更有趣的思路：**改变控制律的开关结构，把系统状态强行压到一条预先设计的"滑模面"上，然后让状态沿着滑模面滑向目标**。一旦状态进入滑模，系统的行为只由滑模面决定，对参数变化和外部扰动**完全免疫**——这就是滑模控制的招牌特性"强鲁棒性"。它的历史可追溯到 1950 年代的苏联变结构控制学派，如今在电机驱动、电力电子、机器人、飞行器里应用极广。滑模控制也是理解"切换控制"与"抖振"这对矛盾的最佳入口。<span class="marginnote">滑模控制的两阶段画像：第一阶段"趋近"——用开关控制把状态推向滑模面；第二阶段"滑模"——状态沿滑模面滑动，对不确定性免疫。设计者真正要设计的只有滑模面本身。</span>

## 1 滑模面的设计

考虑单输入非线性系统 $\dot{x} = f(x) + b(x)u$，目标是让状态 $x$ 跟踪期望 $x_d$。定义误差 $e = x - x_d$，取**滑模面（sliding surface）**为误差的加权组合：

$$s = \dot{e} + \lambda e, \qquad \lambda > 0$$

这是最常见的一阶滑模面。它的妙处：**当 $s = 0$ 时**，$\dot{e} + \lambda e = 0$ 是一阶线性微分方程，$e \to 0$ **指数收敛**（收敛速率由 $\lambda$ 决定）。于是控制问题被分解成两段：

- 先设计控制律把状态"赶"到 $s=0$ 上；
- 一旦 $s=0$，系统自动沿滑模面收敛，**此时系统动态与 $f(x), b(x)$ 完全无关**——这就是强鲁棒性的来源。

高阶系统用高阶滑模面 $s = e^{(n-1)} + \lambda_{n-2}e^{(n-2)} + \cdots + \lambda_0 e$，思想完全一样：**$s=0$ 定义了希望的误差动态**。<span class="marginnote">滑模面 $s=0$ 是一张"超曲面"，把状态空间分成 $s>0$ 和 $s<0$ 两个区。控制律在这两个区之间切换，就像把球往一个 V 形槽里踢——球进槽后沿槽底滑到底，槽壁挡掉了所有干扰。</span>

## 2 控制律设计：趋近律与等效控制

设计控制律使 $s$ 在有限时间内到达滑模面，且保持 $s=0$。经典方法是**等效控制 + 切换控制**：

$$u = u_{eq} + u_{sw}$$

- **等效控制 $u_{eq}$**：让 $\dot{s} = 0$ 求得的连续控制量，它把系统"维持"在滑模面上。由 $\dot{s} = \frac{\partial s}{\partial x}(f + bu) = 0$ 解出。
- **切换控制 $u_{sw}$**：补偿不确定性、把状态"推"回滑模面的开关项，常用符号函数：

$$u_{sw} = -k\,\text{sgn}(s)$$

取 $k$ 足够大，保证**到达条件**成立：$s\dot{s} < 0$（李雅普诺夫函数 $V = \frac12 s^2$ 沿轨迹下降）。这条条件保证 $s$ 不断减小、状态被压向滑模面。<span class="marginnote">到达条件 $s\dot{s} < 0$ 正是李雅普诺夫第二方法的直接应用：取 $V=s^2/2$，$\dot V = s\dot s < 0$ 即稳定。滑模控制与李雅普诺夫理论的亲缘在这里一目了然——设计控制律使李雅普诺夫导数负定。</span>

## 3 公式解析：滑模控制律

$$u = u_{eq} - k\,\text{sgn}(s), \qquad \text{sgn}(s) = \begin{cases} +1 & s>0 \\ -1 & s<0 \end{cases}$$

对它做四步拆解：

- **第一步，看 $u_{eq}$**：由 $\dot{s}=0$ 解出的连续项，负责"维持滑模"。它依赖标称模型 $f, b$，但滑模的鲁棒性不要求它精确——误差由切换项兜住。
- **第二步，看 $\text{sgn}(s)$**：符号函数输出只有 $\pm1$——控制量在两个极限值之间**跳变**，这就是"变结构"的由来。$s>0$ 时加负力、$s<0$ 时加正力，始终把 $s$ 往 0 推。
- **第三步，看 $k$**：$k$ 必须超过不确定性的上界，才能保证到达条件。$k$ 大则鲁棒强、但抖振大；$k$ 小则抖振小、但可能压不住不确定性。$k$ 是"鲁棒与抖振"的折中。
- **第四步，看抖振（chattering）**：理想滑模是无限快切换，现实中开关频率有限，状态在滑模面两侧**高频抖动**，产生"抖振"。抖振会激励未建模高频动态、加速磨损——**这是滑模控制最著名的缺点**。

## 4 抖振的抑制

抖振是滑模控制工程化的头号敌人，主流对策：

- **边界层方法**：用饱和函数 $\text{sat}(s/\varepsilon)$ 代替 $\text{sgn}(s)$，在 $|s|<\varepsilon$ 的边界层内用连续高增益替代开关。牺牲一点鲁棒性换掉抖振，实现最简单。
- **高阶滑模（HOSM）**：把切换作用在 $s$ 的高阶导数上（如超螺旋算法 Super-Twisting），保持鲁棒性同时抑制抖振，理论更完整、近年应用多。
- **趋近律设计**：改用指数趋近律 $\dot{s} = -k\,\text{sgn}(s) - q s$，让状态快速趋近、到达后沿滑模面平滑滑动。<span class="marginnote">边界层的权衡很直观：$\varepsilon$ 越大，越平滑但鲁棒性越差（等效于把滑模面模糊成一条"软带"）；$\varepsilon$ 越小，越接近理想滑模但抖振越烈。工程上 $\varepsilon$ 通常取测量噪声幅度的量级。</span>

## 5 滑模控制的现代延伸

滑模控制在现代控制里不断进化：

**滑模观测器**：把滑模思想用于状态估计，对测量噪声与模型误差鲁棒，在电机磁链估计、故障检测里很常用。
**终端滑模（terminal SMC）**：用非线性滑模面让误差**有限时间**收敛（而非指数渐近），收敛更快。
**离散滑模**：数字实现下的滑模设计，处理采样带来的抖振。
**与自适应/模糊/神经网络结合**：用智能方法在线估计不确定性的上界，自适应调整切换增益 $k$，缓解"上界保守"问题。<span class="marginnote">滑模的哲学与鲁棒控制互补：鲁棒控制"最坏情况设计"（对全部不确定性保证稳定），滑模"切换压制"（用足够大的开关力把不确定性覆盖掉）。两者都源于对"模型不准"的清醒认识，只是手段不同。</span>

**辨析｜易错点：** 滑模控制的鲁棒性有前提——**匹配条件**：不确定性必须与输入同通道（$f$ 的不确定性被 $b u$ 的通道覆盖）。不匹配的不确定性（直接进状态而不经过输入）滑模压不住，需要额外处理（如积分滑模）。别把"滑模强鲁棒"误当成"无条件鲁棒"。

## 6 趋近律设计与抖振量化

滑模控制律不止"等效 + 符号切换"一种写法。**趋近律（reaching law）**设计直接规定 $s$ 趋向滑模面的方式，是更系统的设计框架。

**等速趋近律**：$\dot s = -k\,\text{sgn}(s)$。$s$ 以恒定速度 $k$ 趋向滑模面，到达时间 $t_r = |s_0|/k$。实现最简单，但到达时速度不减，撞向滑模面时抖振明显。

**指数趋近律**：$\dot s = -k\,\text{sgn}(s) - q s$，$k, q > 0$。第一项 $qs$ 在 $s$ 大时让状态快速逼近滑模面（指数加速），第二项 $k\,\text{sgn}(s)$ 在 $s$ 接近 0 时仍保证到达。到达时间大幅缩短，且到达时速度被 $q$ 项"软着陆"。<span class="marginnote">指数趋近律的直觉：远处使劲赶（$qs$ 项），近处小心贴（$k\,\text{sgn}$ 项）——"前面跑得快、快到站时踩刹车"。这是工程上最常用的趋近律，兼顾速度与抖振。</span>

**幂次趋近律**：$\dot s = -k|s|^\alpha \text{sgn}(s)$，$0<\alpha<1$。$s$ 越大收敛越快、$s\to0$ 时收敛速度趋零，理论上可**有限时间**到达且到达时无抖振。

**抖振的量化**：理想滑模要求开关频率无穷高，实际受采样频率与执行器响应限制。抖振幅度与切换增益 $k$ 成正比、与开关频率成反比。工程上"在采样周期内完成切换"意味着抖振不可避免，只能抑制——边界层、高阶滑模、趋近律优化是三条主流路线。

**辨析｜易错点：** 趋近律里的参数不是越大越好——$k$ 大到达快但抖振大，$q$ 太大会在趋近阶段激起过大控制量。**"快速到达"与"平缓到达"是一对矛盾**，参数要按对象能承受的控制力度来选，而不是一味求快。

**滑模控制的应用领域**：滑模控制的"强鲁棒 + 快响应"让它特别适合几类对象：

- **电机与电力电子**：永磁同步电机的电流环/速度环、Buck/Boost 变换器的电压控制——开关型功率器件天然适合开关型控制律。
- **机器人**：机械臂关节的鲁棒轨迹跟踪，在负载变化、摩擦力不确定时仍保持精度。
- **飞行器与导弹**：姿态控制对抗气动参数的大范围变化。
- **欠驱动与非线性系统**：倒立摆、无人机等，滑模能处理经典线性方法难啃的非线性。

**为什么这些场景选滑模**：它们的共同点是"不确定性大且难以精确建模 + 对鲁棒性要求高"。滑模用"足够的开关增益"直接把不确定性覆盖掉，不需要精确的模型参数——这正好补上经典鲁棒控制（需要不确定集刻画）与自适应控制（需要在线辨识）之间的空缺。

**与智能控制的结合**：滑模与模糊、神经网络、自适应结合是研究热点——用智能方法在线估计不确定性的上界，动态调整切换增益 $k$，既保留滑模的鲁棒性，又缓解"上界保守导致抖振过大"的问题。

**滑模控制的辨识要点**：面对一个实际对象，用不用滑模、怎么用，有三问——**不确定性是否匹配**（不匹配的不确定性滑模压不住）；**执行器能否承受高频切换**（阀门/电机对开关动作的响应快不快）；**抖振能否被接受**（边界层或高阶滑模能否把抖振压到可接受水平）。三问答完，滑模的适用性就清楚了。它不是"所有非线性问题的银弹"，而是"强不确定 + 强鲁棒需求"时的精准工具。

**滑模与李雅普诺夫的最后呼应**：回顾全节，滑模控制的每一步都踩着李雅普诺夫方法的节拍——到达条件 $s\dot s<0$ 就是李雅普诺夫函数 $V=\frac12 s^2$ 的负定性，滑模面的收敛就是误差能量的耗散。**滑模是"设计一个李雅普诺夫函数、再设计控制律让它下降"的典型范例**。若你在非线性控制里继续深造，会发现几乎所有方法（反步法、自适应、$H_\infty$）都在做同一件事：找一个合适 $V$，让 $\dot V$ 负定。这一节的滑模，是理解整个非线性控制家族的最佳入口。

**总结一句**：滑模控制的全部要义可以浓缩成一句话——**"设计一条轨道（滑模面），然后不惜一切代价把状态压上去"**。它把复杂的非线性鲁棒控制问题，化简成了"选轨道 + 定切换增益"两件事。理解了这句话，滑模控制就不再是"一堆公式"，而是一种清晰的设计哲学。

这句总结也适用于本专题更广的图景：**设计目标清晰（稳定、准确、快速），选择工具得当（经典、现代、智能），验证闭环完备（仿真、HIL、现场）**——这就是控制工程师的全部工作内容。

滑模控制的强鲁棒性，正是这套方法论里"用结构换稳定"的典型代表。

## 7 小结

- **滑模控制**：设计滑模面 $s=0$ + 开关控制律，把状态压到滑模面上滑动，对不确定性免疫。
- 滑模面 $s = \dot{e}+\lambda e$：$s=0$ 时误差指数收敛，收敛速率由 $\lambda$ 决定。
- 控制律 = **等效控制**（维持滑模）+ **切换控制** $-k\,\text{sgn}(s)$（压制不确定性）。
- 到达条件 $s\dot{s}<0$ 是李雅普诺夫第二方法的直接应用。
- **抖振**是主要缺点，对策：边界层、高阶滑模、趋近律设计。
- 鲁棒性前提是**匹配条件**；滑模已延伸到观测器、终端滑模、离散滑模。

在下一节，我们从"切换压制"换到"最坏情况设计"：不依赖在线信息，直接用 $H_\infty$ 等工具设计一个对不确定集内一切对象都稳定的**鲁棒控制**。
