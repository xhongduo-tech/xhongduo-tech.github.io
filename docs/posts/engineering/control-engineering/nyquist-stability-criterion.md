# Nyquist 稳定性判据

## 为什么从 Nyquist 判据开始

劳斯判据告诉我们系统稳不稳，根轨迹告诉我们极点往哪走。但它们都有一个隐藏前提：**知道开环传递函数的解析式**。工业上很多系统（尤其是带高频未建模动态的对象）很难写准解析模型，却能通过实验测出频率特性曲线。Nyquist 判据正是为此而生：**只用开环频率响应曲线，就能判断闭环稳定性，而且不用求任何根**。它还能一举给出增益裕度与相位裕度，把「判稳」与「量稳」合并成一步。1932 年奈奎斯特在贝尔实验室发表这篇结果时，为的是解决放大器设计中的稳定性问题——此后它成了频率法最锋利的武器。<span class="marginnote">Nyquist 判据还有一个别人没有的优势：它对开环不稳定的系统（$P>0$）同样适用——只要知道开环右半平面极点数 $P$，照样判定闭环。工程上这叫「利用不稳定对象造稳定系统」，是鲁棒控制的前奏。</span>

## 1 围线映射与幅角原理

Nyquist 判据的数学根基是复变函数里的**幅角原理（argument principle）**，也译作映射定理。

设 $F(s)$ 是复变函数。取一条**闭合围线** $\Gamma$，不经过 $F(s)$ 的零极点，把它映射到 $F$ 平面上的另一条闭合曲线 $F(\Gamma)$。幅角原理说：

- $F(\Gamma)$ **顺时针**绕原点 $F=0$ 的圈数 $N$，等于 $\Gamma$ 内 $F(s)$ 的**零点数 $Z$ 减去极点数 $P$**：
$$N = Z - P$$

为什么？因为当 $s$ 沿 $\Gamma$ 走一圈，每个零点对幅角贡献 $2\pi$，每个极点贡献 $-2\pi$——总幅角变化除以 $2\pi$ 就是圈数。<span class="marginnote">这条定理在《复变函数与积分变换》的留数部分已埋下伏笔：围线积分 ∮$F'/F\,\mathrm{d}s = 2\pi j(N)$，正是幅角原理的积分形式。控制理论把抽象定理变成了工程判据。</span>

## 2 从幅角原理到 Nyquist 判据

现在令 $F(s) = 1 + G(s)H(s)$。注意：

$F(s)$ 的**零点**正是闭环特征方程 $1 + GH = 0$ 的根，即**闭环极点**；
$F(s)$ 的**极点**正是开环传递函数 $G(s)H(s)$ 的极点。

围线 $\Gamma$ 取「D 形围线」：虚轴从 $-j\infty$ 到 $+j\infty$，再沿右半平面的大圆弧回来——这样 $\Gamma$ 恰好**围住整个右半平面**。于是：

$Z$ = 右半平面内闭环极点个数（我们要的就是它 = 0 才稳定）；
$P$ = 右半平面内开环极点个数（已知量）；
$N$ = $1+GH$ 映射曲线绕原点的圈数。

而 $1 + GH$ 绕原点的圈数，等于 $GH$ 绕 $(-1, j0)$ 点的圈数（整体平移）。$GH$ 沿 D 形围线的映射，正是 $\omega$ 从 $-\infty$ 到 $+\infty$ 的**完整 Nyquist 曲线**。

于是得 **Nyquist 稳定性判据**：

> **闭环系统稳定的充要条件是：$\omega$ 从 $-\infty$ 到 $+\infty$ 时，开环 Nyquist 曲线逆时针包围 $(-1, j0)$ 点的圈数 $N$ 等于开环右半平面极点数 $P$。**

用公式记：$Z = P - N$（$N$ 为逆时针圈数），稳定要求 $Z = 0$。<span class="marginnote">对开环稳定（$P=0$）的常见系统，判据退化为「曲线不包围 $(-1,j0)$」。多数入门考题都落在这个特例，但真正的威力在于 $P>0$ 时也能用——记住完整形式才不会被难题卡住。</span>

## 3 公式解析：判据的圈数方程

$$Z = P - N$$

对它做四步拆解：

- **第一步，明确三个量的身份**：$Z$ 是右半平面**闭环**极点数（未知、待判）；$P$ 是右半平面**开环**极点数（已知、从开环传函读）；$N$ 是曲线绕 $(-1,j0)$ 的**逆时针净圈数**（从图上数，可正可负）。
- **第二步，理解逆时针约定**：$N > 0$ 表示逆时针绕、$N < 0$ 表示顺时针绕。开环稳定时 $P=0$，若曲线顺时针绕了一圈（$N=-1$），则 $Z = 0-(-1) = 1$，有一个闭环极点在右半平面——不稳定。
- **第三步，看「恰好穿过」的情形**：Nyquist 曲线**穿过** $(-1,j0)$ 点时，闭环存在纯虚根，系统临界稳定（工程上视为不稳定）。作图时要分辨「绕过去」与「穿过去」。
- **第四步，验证特例**：开环稳定且曲线完全不包围时 $N=0$，$Z=0$ 稳定——这正是我们熟悉的直觉情形，幅角原理在这个特例上退化成「图上一看」。

## 4 开环含积分环节的处理

工程系统开环常含积分环节（如 $K/[s(s+1)]$），此时开环极点落在 $s=0$，而 D 形围线经过原点——幅角原理要求围线不经过零极点，所以要用**修正围线**：以原点为圆心、半径趋于 0 的**小圆弧**从右侧绕过原点。

这个修正的效果在 Nyquist 曲线上表现为：$\omega \to 0^-$ 到 $\omega \to 0^+$ 之间，曲线沿**半径为无穷大的圆弧**从正实轴绕到负实轴方向——对 I 型系统，$\omega=0$ 处相角从 $-90°$ 变到 $+90°$，多出**顺时针 $180°$** 的无穷大半圆。**作图时别忘了补上这半圈**，否则判据会误判。<span class="marginnote">记忆法：系统含 $\nu$ 个积分环节，Nyquist 图就在 $\omega=0$ 处补上 $\nu$ 个顺时针 $180°$ 的无穷大圆弧（从低频段终点开始画）。I 型补半圈、II 型补一圈。这是画图题最常丢分的细节。</span>

## 5 从 Nyquist 图读裕度

Nyquist 判据给了「稳定与否」，而 Nyquist 图还能直接读出「稳定多少」：

**增益裕度 $h$**：曲线与负实轴交点到 $(-1,j0)$ 点的距离，通常折算成 dB；
**相位裕度 $\gamma$**：以原点为圆心、半径 1 的单位圆与曲线的交点到 $(-1,j0)$ 的夹角（沿负实轴度量）。

单位圆对应幅值穿越频率（0 dB），交点相位与 $-180°$ 之差就是 $\gamma$。**一图承载判据 + 裕度**，这正是 Nyquist 方法在频域法中的独特地位。<span class="marginnote">对比三种判据的视角：劳斯用系数、根轨迹用极点移动、Nyquist 用开环频率曲线——它们回答同一问题，但数据来源不同。工程实践中三种方法常交叉验证，结论一致才能放心。</span>

## 6 Nyquist 判据应用示例

把判据走一遍完整流程。设开环传递函数 $G(s)H(s) = \dfrac{K}{s(s+1)(s+2)}$，开环稳定（$P=0$），求闭环稳定的 $K$ 范围。

**第一步，判断 P**：开环极点 $0, -1, -2$ 都在左半平面或原点，右半平面极点数 $P=0$。所以判据退化为"曲线不包围 $(-1,j0)$"。

**第二步，画 Nyquist 曲线关键点**：对象含一个积分环节，$\omega\to0$ 时曲线从 $-90^\circ$ 方向的无穷远点出发；$\omega\to\infty$ 时沿第三象限进入原点。曲线在某个 $\omega$ 处与负实轴相交——**这个交点最关键**。

**第三步，求负实轴交点**：令相角 $\angle G(j\omega) = -180^\circ$。对本题 $\angle G = -90^\circ - \arctan\omega - \arctan(\omega/2) = -180^\circ$，解得 $\omega_g = \sqrt2$。交点处幅值：

$$|G(j\sqrt2)| = \frac{K}{\sqrt2\cdot\sqrt{1+2}\cdot\sqrt{1+2}} = \frac{K}{6}$$

**第四步，应用判据**：曲线要**不包围** $(-1,j0)$，交点必须在 $(-1,j0)$ 右侧，即：

$$\frac{K}{6} < 1 \quad\Longrightarrow\quad K < 6$$

**第五步，交叉验证**：$K=6$ 时曲线恰好穿过 $(-1,j0)$，系统临界稳定——与劳斯判据得出的 $0<K<6$ 完全一致。<span class="marginnote">这就是三种判据"同一件事、三种算法"的最好例证：劳斯判据解不等式、根轨迹看穿越虚轴、Nyquist 看交点位置，殊途同归到 $K=6$。工程上三种方法交叉验证，结论一致才放心。</span>

**辨析｜易错点：** 含积分环节时别忘了 $\omega=0$ 处要补"顺时针无穷大圆弧"（I 型补 $180^\circ$）。本题 $P=0$ 且补弧不影响包围判定，但如果忽略补弧、只画主曲线，判据在开环不稳定时就会误判。补弧不是可有可无的细节。

**Nyquist 判据的工程提醒**：

- **实验数据的使用**：Nyquist 曲线可以来自实验扫频（由 Bode 实测数据合成），不依赖解析模型——这正是它在工业上"模型写不准但能实测"时仍可用的原因。
- **与 Bode 图的换算**：$\omega$ 从 0 到 $\infty$ 的 Nyquist 曲线就是 Bode 图数据的极坐标画法——两者是同一份信息的两种画法，看图习惯不同而已。
- **多变量的推广**：Nyquist 判据的幅角原理思想可以推广到多输入多输出系统（特征轨迹法），但那需要更深的数学，本科阶段以单变量为主。

工程上判稳通常先扫 Bode 图看裕度（快速、直观），有疑问再用 Nyquist 判据严格判定——两招配合，万无一失。

**奈奎斯特其人**：哈里·奈奎斯特（Harry Nyquist, 1889–1976）是贝尔实验室的瑞典裔工程师，他的另一项奠基性成果是**奈奎斯特采样定理**（1928）——"采样频率必须大于信号最高频率的两倍"，这是整个数字信号处理与数字控制的地基。控制理论里他留下 Nyquist 判据，通信理论里他留下采样定理，一个人横跨两大领域，是"控制与通信同一性"（维纳语）的最佳注脚。

**把三判据串成一张心智图**：劳斯看系数、根轨迹看增益、Nyquist 看频率曲线——**同一个"左半平面"标准，三种数据来源**。遇到稳定性问题先想"我手里有什么数据"：只有特征方程系数 → 劳斯；想看参数怎么动 → 根轨迹；有开环频率测量 → Nyquist。数据决定方法，方法服务于结论。

## 7 小结

- **幅角原理**：$N = Z - P$，围线映射绕原点的圈数等于零点数减极点数。
- 取 $F = 1+GH$、D 形围线围住右半平面，得 **Nyquist 判据**：$Z = P - N$，$Z=0$ 即闭环稳定。
- $N$ 是曲线**逆时针**包围 $(-1,j0)$ 的净圈数，$P$ 是开环右半平面极点数。
- 开环含积分环节时用**修正围线**绕过原点，图上要补 $\nu$ 个顺时针无穷大圆弧。
- Nyquist 图同时给出**增益裕度**与**相位裕度**，判稳与量稳合一。
- 三种判据（劳斯/根轨迹/Nyquist）可交叉验证。
