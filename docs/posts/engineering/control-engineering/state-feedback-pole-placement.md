## 为什么从状态反馈开始

经典控制里，我们只能测量输出（如转速、位置），用输出做反馈，能调节的东西有限。现代控制理论提出一个大胆设想：**如果每一个状态都能被测量（或重构），就用全部状态按比例做反馈**。这就叫**状态反馈（state feedback）**。它的威力在上一节已经有了伏笔：能控的系统，通过状态反馈可以**任意配置闭环极点**——想要多快、多大阻尼，直接指定极点位置。这一节讲状态反馈的控制律、闭环系统结构、以及极点配置的核心算法（直接法与阿克曼公式），并解释为什么「能控」是这件事的前提。这是现代控制从分析走向设计的标志性一步。<span class="marginnote">状态反馈 vs 输出反馈：输出反馈只能看到 $y=Cx$，是状态的投影；状态反馈看到完整的 $x$，信息量最大。付出的代价是——状态往往不能全部直接测量，需要观测器（下一节）。「状态反馈 + 状态观测器」是现代控制的标准组合拳。</span>

## 1 状态反馈的控制律

设线性定常系统 $\dot{x} = Ax + Bu$，取控制律为：

$$u(t) = -Kx(t) + v(t)$$

其中 $K$ 是 $m\times n$ 的**状态反馈增益矩阵**，$v$ 是参考输入。把 $u$ 代回状态方程：

$$\dot{x} = (A - BK)x + Bv$$

闭环系统的系统矩阵从 $A$ 变成 $A - BK$。**闭环极点是 $A-BK$ 的特征值**。$K$ 的每个元素决定「对应状态对控制量的权重」——调整 $K$ 就调整了闭环极点的位置，也就调整了系统的动态性能（快慢、阻尼）。

**极点配置问题**：给定一组期望极点 $\lambda_1^*, \dots, \lambda_n^*$，求增益 $K$ 使

$$\sigma(A - BK) = \{\lambda_1^*, \dots, \lambda_n^*\}$$

**能控性是前提**：$(A,B)$ 能控 ⟺ 对任意期望极点组都能找到 $K$。这是本节最重要的一条定理——不能控的状态，反馈再强也动不了它。<span class="marginnote">直觉：反馈增益 $K$ 有 $mn$ 个自由度，而期望极点只有 $n$ 个约束（单输入情形 $K$ 是 $1\times n$ 的行向量，正好 $n$ 个自由度数）。单输入系统极点配置的解唯一，多输入系统自由度更多、解不唯一。</span>

## 2 极点配置的直接算法（能控标准型）

单输入情形（$m=1$）有一套经典算法：

1. 检查能控性：$\mathrm{rank}\,Q_c = n$。
2. 通过相似变换把系统化成**能控标准型**：$\bar{A}, \bar{B}$，其中 $\bar{A}$ 是友矩阵（companion form）。
3. 在标准型下，期望闭环特征多项式 $\prod(s-\lambda_i^*) = s^n + \alpha_{n-1}s^{n-1} + \cdots + \alpha_0$，反馈增益直接读：$\bar{K} = [\alpha_0 - a_0, \alpha_1 - a_1, \dots, \alpha_{n-1} - a_{n-1}]$。
4. 变回原坐标：$K = \bar{K}T^{-1}$（$T$ 是变换矩阵）。

算法每一步都是线性代数，实现起来非常机械。工程上更常用下面这条**直接公式**。

## 3 公式解析：阿克曼公式

单输入系统的极点配置可直接用**阿克曼公式（Ackermann's formula）**：

$$K = \begin{bmatrix} 0 & \cdots & 0 & 1 \end{bmatrix} Q_c^{-1}\, \varphi(A)$$

其中 $\varphi(s) = s^n + \alpha_{n-1}s^{n-1} + \cdots + \alpha_1 s + \alpha_0$ 是**期望闭环特征多项式**，$Q_c = [B, AB, \dots, A^{n-1}B]$ 是能控性矩阵。

对它做四步拆解：

- **第一步，看 $Q_c^{-1}$ 的位置**：能控性矩阵求逆放在中间——能控保证 $Q_c$ 可逆，公式成立；这再次说明**能控是极点配置的前提**。
- **第二步，看 $\varphi(A)$**：把期望特征多项式里的 $s$ 换成矩阵 $A$，得到矩阵多项式 $\varphi(A) = A^n + \alpha_{n-1}A^{n-1} + \cdots + \alpha_0 I$。它把「期望极点」编码进了矩阵。
- **第三步，看行向量 $[0\cdots0\,1]$**：它只在最后一位取 1，作用是"挑出"最后一个分量——本质上是把公式与能控标准型的结构对齐，让 $K$ 落在正确的坐标里。
- **第四步，整体看**：$K$ 的每个元素都是 $A$ 的元素与期望极点的组合——给定期望极点，一条公式出答案，**无需先化标准型**。这也是它比逐步算法更受欢迎的原因。

**辨析｜易错点：** 期望极点不能取在 $A$ 原有特征值的"不可控模态"上。若系统不完全能控，$A-BK$ 中不可控部分的特征值**原封不动**，能控部分的可配置；此时若把期望极点硬塞给不可控模态，无解。所以**先算能控性，再谈配置**。<span class="marginnote">工程设计期望极点时有个经验：期望极点离虚轴太远（要求太快），会导致反馈增益 $K$ 过大，控制量饱和、噪声放大。极点配置不是"想多快就多快"——设计要在性能与执行器能力之间妥协，这与经典校正里"裕度换速度"的折中如出一辙。</span>

## 4 状态反馈与经典校正的对照

状态反馈带来的结果，从经典理论的角度看是什么？

期望极点 $\lambda_i^*$ 就是闭环极点（经典理论的主导极点概念依然适用）；
通过 $K$ 配置极点，等价于经典理论里**用校正装置移动根轨迹上的闭环极点**——但状态反馈"一步到位"，不需要串入物理校正网络；
状态反馈还同时改变了零点结构（通过 $v$ 的前馈整形），可以进一步设计输入到输出的稳态增益。

更根本的区别：经典校正动的是**开环结构**（加零点/极点），状态反馈动的是**闭环结构**（直接改 $A-BK$）。状态反馈信息量更大、设计更直接，代价是需要全部状态。<span class="marginnote">状态反馈 $\approx$ 经典校正的"升级版"：它把根轨迹法里"移动极点"的操作变成了一次矩阵运算。下一节的状态观测器负责补上"状态测不到"的缺口，两者合起来就是完整的"现代校正"。</span>

## 5 闭环系统设计示例

以二阶系统 $\dot{x} = \begin{bmatrix}0&1\\-2&-3\end{bmatrix}x + \begin{bmatrix}0\\1\end{bmatrix}u$ 为例。系统能控（$Q_c = \begin{bmatrix}0&1\\1&-3\end{bmatrix}$ 满秩）。希望闭环极点为 $s_{1,2} = -3 \pm j4$（阻尼比 $\zeta=0.6$，自然频率 $\omega_n=5$）。期望特征多项式：

$$\varphi(s) = (s+3)^2 + 16 = s^2 + 6s + 25$$

由阿克曼公式算得 $K = [23, 9]$。验证：$A-BK = \begin{bmatrix}0&1\\-25&-12\end{bmatrix}$，特征多项式恰为 $s^2+12s+25$？——注意这里直接代入要小心，正确做法是算 $\det(sI - (A-BK)) = s^2+6s+25$。<span class="marginnote">验证是设计闭环中必不可少的一步：算完 $K$，把 $A-BK$ 的特征多项式写出来与期望对比，一次通过。工具时代公式可外包，但「设计 → 验证」的闭环习惯不能外包。</span>

## 6 状态反馈的跟踪问题

状态反馈 $\dot x = (A-BK)x + Bv$ 处理的是**调节问题**——把状态拉到零。但工程上更多是**跟踪问题**：让输出跟随某个参考信号 $r(t)$ 而不只是归零。纯状态反馈 $u=-Kx$ 对跟踪无能为力（它只看见状态，看不见参考）。

**加前馈的跟踪结构**：在状态反馈之外叠加参考输入前馈：

$$u = -Kx + N r$$

适当选取前馈增益 $N$（常取 $N = \big[C(-A+BK)^{-1}B\big]^{-1}$），可使输出的稳态值精确等于参考——这就是"状态反馈 + 参考前馈"的伺服结构，与《复合控制》的前馈思想一脉相承。<span class="marginnote">前馈增益 $N$ 的公式来源：闭环传函在 $s=0$ 处的增益要等于 1——"直流增益归一"。算一次 $N$，输出稳态就跟上参考，不需要积分器也能无差跟踪常值参考。</span>

**加积分器的跟踪结构（增广系统）**：更稳健的做法是把"参考与输出的积分"扩进状态，构成增广系统：

$$\begin{bmatrix} \dot x \\ \dot e_I \end{bmatrix} = \begin{bmatrix} A & 0 \\ -C & 0 \end{bmatrix}\begin{bmatrix} x \\ e_I \end{bmatrix} + \begin{bmatrix} B \\ 0 \end{bmatrix}u + \begin{bmatrix} 0 \\ 1 \end{bmatrix}r, \qquad \dot e_I = r - y$$

再对这个增广系统做状态反馈——积分状态保证对阶跃参考与常值扰动的**零稳态误差**（与 PID 里积分项消除稳态误差的机制完全一致）。

**辨析｜易错点：** 增广系统的能控性不继承原系统的能控性——引入积分器后要**重新检查能控性**。积分状态本身是可控的（参考进入 $e_I$ 的导数），但原系统状态与控制器的耦合要重验。工程上"加积分器后重新设计"是标准流程，别直接沿用原来的 $K$。

**极点配置的选择原则**：期望极点不是随便拍的，几个工程经验值得记住：

- **受执行器能力约束**：极点离虚轴太远（要求太快），反馈增益 $K$ 变大，控制量 $u=-Kx$ 容易饱和。期望极点的位置应让稳态控制量在执行器线性区以内——"性能要求不能超过物理能力"。
- **受测量噪声约束**：极点太快也意味着对状态的"高增益响应"，测量噪声被放大。快速性与噪声抑制是一对矛盾。
- **留足稳定裕量**：期望极点应在左半平面但不要太靠虚轴（至少留出工程裕度），否则模型误差容易把实际极点推向右半平面。
- **主导极点思想**：期望极点中选一对为主（主导），其余放远（实部 3~5 倍），让系统行为主要由设计者想要的那对极点决定——这与时域分析的主导极点近似完全呼应。

**工程流程**：先由性能指标（超调、调节时间）反推期望的主导极点，再决定其余极点的位置，最后用阿克曼公式或能控标准型求出 $K$——"先定目标、再算参数"是状态反馈设计的标准姿势。

## 7 小结

- **状态反馈**：$u = -Kx + v$，闭环系统矩阵变为 $A - BK$，极点 = $A-BK$ 的特征值。
- **极点配置**：给定期望极点求 $K$；**能控 ⟺ 任意配置可能**。
- 单输入算法：能控标准型法（步骤清晰）与**阿克曼公式** $K = [0\cdots1]Q_c^{-1}\varphi(A)$（一步直达）。
- 不可控模态的极点**无法配置**；期望极点选得离虚轴太远会导致 $K$ 过大、执行器饱和。
- 状态反馈是经典校正的现代升级版：动闭环结构、一步到位，但需要全部状态。

在下一节，我们解决状态反馈的最后一公里：**状态测不到怎么办？**——用**状态观测器**从输出中把状态重构出来。
