## 为什么从运动控制开始

如果说过程控制管的是"慢而稳"的温度液位，**运动控制（motion control）**管的则是"快而准"的机械运动——数控机床的刀具轨迹、机器人的关节、打印机喷头、光伏跟踪器。它的核心是**伺服系统（servo system）**：以电机为执行器、以编码器为眼睛、以驱动器为大脑，让运动部件精确跟踪位置/速度指令。伺服系统是工业自动化的"肌肉"，也是控制理论应用最"硬核"的战场：毫秒级带宽、微米级精度、强干扰、强耦合。这一节拆开一台典型伺服系统，看经典与现代控制理论如何在这里协同工作——尤其是**电流-速度-位置三环结构**这个工业标准架构。<span class="marginnote">"伺服"（servo）来自拉丁语 servus（仆人）——伺服系统就是"忠实执行指令的仆人"。1790 年代瓦特调速器是第一个伺服装置，如今伺服电机驱动着从机械臂到光刻机的所有精密运动。</span>

## 1 伺服系统的组成

一个典型的交流伺服系统由四部分组成：

**伺服电机**：执行机构，常为永磁同步电机（PMSM）或无刷直流电机（BLDC），特点是响应快、调速范围宽、体积小。
**编码器**：位置/速度反馈元件，有增量式与绝对式，分辨率决定精度下限。
**伺服驱动器**：内含控制器与功率放大器，把位置/速度指令变成电机电流。
**控制器**：PLC、运动控制卡或独立控制器，生成轨迹指令。

伺服系统按"外环任务"分三类：**位置伺服**（控位置）、**速度伺服**（控转速）、**力矩伺服**（控力矩）。工业机床主轴用速度伺服，进给轴用位置伺服。<span class="marginnote">永磁同步电机的"磁场定向控制（FOC）"是现代伺服驱动的核心技术：把三相交流电流变换成与转子磁场对齐的 d-q 轴分量，让电机像直流电机一样线性可控。这套 d-q 变换本身就是坐标变换 + 反馈控制的杰作——看懂了它，就看见电机控制的半边天。</span>

## 2 电机对象的数学模型

直流电机（或等效的 FOC 电机）的数学模型是典型二阶系统。电枢回路（电气动态）与机械转动（机械动态）：

$$L\frac{\mathrm{d}i}{\mathrm{d}t} + Ri = u - K_e\omega, \qquad J\frac{\mathrm{d}\omega}{\mathrm{d}t} = K_t i - T_L$$

- $u$：电枢电压（输入）；$i$：电枢电流；$\omega$：转速；$R, L$：电枢电阻电感；
- $K_e$：反电动势系数；$K_t$：力矩系数（$K_t \approx K_e$）；$J$：转动惯量；$T_L$：负载力矩。

把两个方程联立，从电压 $u$ 到转速 $\omega$ 的传递函数为（忽略 $L$ 或保留都可）二阶系统。注意两个关键耦合：**反电动势 $K_e\omega$** 把机械量反馈回电气方程，**力矩 $K_t i$** 把电气量送入机械方程——**机电耦合**是伺服建模的核心特征。<span class="marginnote">电流 $i$ 与转速 $\omega$ 正是状态空间里的一对状态（电感储能与转动惯量储能）。伺服系统是"状态空间描述"的天然案例：电流环控 $i$、速度环控 $\omega$、位置环控 $\theta$，每一层都在"控一个状态"。</span>

## 3 三环控制结构

工业伺服的标准结构是**三环嵌套**：

**内环：电流环**——最快，控制电机电流（即力矩）。用电流传感器反馈，PI 控制器，带宽最高（kHz 级）。电流环让电机"瞬间输出指定力矩"。
**中环：速度环**——控制转速。用编码器测速反馈，PI 控制器，带宽居中（百 Hz 级）。速度环让电机"转速跟指令"。
**外环：位置环**——最慢，控制位置。用位置反馈，P 或 PID 控制器，带宽最低（十 Hz 级）。位置环让运动部件"到位"。

**三环的分工逻辑与串级控制完全一致**：内环快、先处理高频扰动（负载突变、反电动势影响），外环慢、只管低频跟踪。每层的时间常数拉开 3~5 倍，保证各环互不干扰、整体稳定。<span class="marginnote">三环结构的"带宽依次降低"是工程铁律：电流环最内、带宽最高，位置环最外、带宽最低。若两环带宽太接近，内环的相位滞后会破坏外环稳定——"带宽拉开"是伺服整定的第一经验。</span>

## 4 公式解析：电流环的简化设计

以内环电流环为例，看工程上如何化简设计。电枢回路方程取拉普拉斯变换：

$$G_i(s) = \frac{I(s)}{U(s)} = \frac{1/R}{1 + (L/R)s} = \frac{1/R}{1 + T_e s}$$

其中 $T_e = L/R$ 是**电气时间常数**（毫秒级）。电流环对象是一阶惯性环节，用 PI 控制器：

$$C_i(s) = K_{pi} + \frac{K_{ii}}{s}$$

对它做四步拆解：

- **第一步，看对象**：电枢回路是"电阻 + 电感"的一阶惯性，时间常数 $T_e$ 很小——所以电流环能做得很快。
- **第二步，看 PI 的角色**：PI 中的积分项消除电流稳态误差（电流要精确等于指令），比例项提供快速响应。**电流环 = 一阶对象 + PI = 经典的最优配置**。
- **第三步，看反电动势的处理**：实际设计会把反电动势 $K_e\omega$ 视为电流环的扰动，靠 PI 的抗扰能力吸收；更精细的驱动还会加"反电动势前馈"补偿——理论与《复合控制》一脉相承。
- **第四步，看带宽的含义**：电流环闭环带宽决定了整个伺服系统的动态上限——电流环够快，速度环与位置环才有"快"的资本。**"内环带宽决定外环可能"**，这是三环设计的总纲。

## 5 运动控制中的现代方法

除了三环 PID，现代运动控制还大量使用：

- **前馈控制**：位置指令的加速度前馈、速度前馈——让系统"提前出力"抵消跟踪滞后。数控机床的高速高精度加工离不开它。
- **陷波滤波器（Notch filter）**：抑制机械谐振——负载与联轴器的弹性产生高频谐振峰，用陷波器"挖掉"谐振频率，避免激励震荡。
- **扰动观测器（DOB）**：估计并补偿负载扰动与模型误差，提高抗扰鲁棒性，是运动控制的核心技术之一。
- **自适应与智能方法**：转动惯量在线辨识、参数自整定；模糊/神经网络整定 PID；RL 做复杂轨迹跟踪优化。
- **同步与协调控制**：多轴运动（龙门双驱、六轴机器人）的同步误差控制。<span class="marginnote">扰动观测器（DOB）值得单独记住：它用"模型逆 + 低通滤波"在线估计扰动并前馈补偿，是"把扰动当状态来估计"的思想——与卡尔曼滤波、状态观测器一脉相承，是运动控制鲁棒性的工程支柱。</span>

## 6 运动控制的应用全景

**数控机床（CNC）**：三轴/五轴联动，微米级轮廓精度——位置环 + 前馈 + 谐振抑制的巅峰应用。
**机器人**：关节伺服 + 运动学/动力学控制（下一节展开）。
**半导体设备**：光刻机工件台，纳米级定位——伺服精度极限。
**3C 制造**：贴片机、焊线机的高速高精点位运动。
**新能源**：光伏跟踪、风机变桨、电动汽车电机驱动。

**辨析｜易错点：** 伺服系统"稳准快"与理论指标完全对应，但工程细节决定成败：编码器分辨率限制位置精度、电流环采样率限制带宽、机械谐振限制增益。**理论给出结构，工程给出边界**——这是运动控制给每个控制工程师的深刻一课。<span class="marginnote">运动控制里"增益调高就抖、调低就软"的拉锯，正是相位裕度与噪声放大矛盾的现场版。伺服整定软件里显示的"带宽""相位裕度"，就是第一篇频率法里学过的概念——理论终于在示波器上显形。</span>

## 7 伺服系统的性能指标与整定

伺服系统的"好"用什么指标衡量、现场怎么调，是运动控制工程师的日常。

**性能指标**：

**定位精度与重复精度**：定位精度是"指令位置与实际位置的偏差"，重复精度是"多次到达同一位置的一致性"。精度由编码器分辨率与机械刚度决定，重复精度还受温度、振动影响。
**跟随误差**：运动过程中的位置滞后，动态指标，由前馈补偿水平决定。
**带宽**：位置环带宽决定系统能跟踪多快的运动指令，是动态性能的总纲。
**刚度**：抗外力干扰的能力，取决于回路增益与机械结构。

**整定流程（现场实用顺序）**：

1. **电流环**：按电机参数设定，通常出厂已标定，现场少动。
2. **速度环**：先给小的速度环增益，逐步加大，观察转速响应——出现明显振荡就回退 20%~30%，留稳定裕量。
3. **位置环**：在速度环稳定后，调位置环增益，兼顾"到位快"与"不超调"。<span class="marginnote">现场整定的经典经验：<strong>每环"先调大看振不振，振了就退三成"</strong>。伺服软件里常直接显示带宽与相位裕度——那些数字就是第一篇频率法里学过的概念。会看频域指标，整定就从"试"变成"算"。</span>

**现代伺服的自整定**：很多驱动器带"一键整定"——注入测试信号、辨识对象（惯量、摩擦）、自动算三环参数。这是"系统辨识 + 控制器设计"在伺服里的自动化，背后的原理正是本专题各章的知识总和。

**辨析｜易错点：** 三环整定顺序**不可颠倒**——外环依赖内环的稳定与带宽，内环没调好就调外环，只会越调越乱。另外，位置环增益过大会把机械谐振激励出来（表现为高频啸叫），此时应**先抑制谐振（陷波器）再加增益**，而不是一味减增益牺牲性能。

## 8 小结

- **伺服系统** = 电机 + 编码器 + 驱动器，实现位置/速度/力矩的精确控制。
- 电机模型：电枢回路（一阶）+ 机械转动（一阶），经反电动势与力矩**机电耦合**成二阶系统。
- **三环结构**：电流环（内、快）→ 速度环（中）→ 位置环（外、慢），带宽依次拉开 3~5 倍。
- 电流环 = 一阶对象 + PI，是伺服动态的上限来源；"**内环带宽决定外环可能**"。
- 现代方法：**前馈、陷波滤波器、扰动观测器**、惯量辨识、多轴同步。
- 应用：数控机床、机器人、光刻机、3C 制造、新能源驱动。

在下一节，我们把伺服装进机器人——**机器人控制**：运动学、动力学与控制的完整配合，让机械臂"想动哪就动哪"。
