## 为什么从非线性系统开始

至此，控制理论的全部经典工具——传递函数、根轨迹、Bode 图、Nyquist 判据、状态空间、LQR——几乎都建立在一个前提上：**系统是线性的，满足叠加原理**。但真实世界没有线性系统：电机有饱和、阀门有死区、继电器有滞环、齿轮有间隙、库仑摩擦根本光滑不了。把继电器控制、电力电子变流器、饱和到顶的执行机构硬塞进线性框架，结论会完全失效——因为它们会表现出线性系统**不可能有**的现象：**极限环（自持振荡）**、跳跃谐振、谐波失真、增益随输入幅值变化的频率响应。<span class="marginnote">线性系统只会有"稳定、不稳定、临界"三种结局；非线性系统多了一种——无外力也能持续振荡下去，比如继电器系统的抖动、飞机的极限环振荡（limit cycle oscillation，LCO）。这是非线性世界最标志性的现象。</span>这一篇把非线性分析的三件工具依次摆开：**描述函数法**（频域、工程近似）、**相平面法**（时域、二阶直观）、**李雅普诺夫方法**（一般情形、严格）。它们与第一篇的频域、第二篇的李雅普诺夫稳定性一脉相承，也解释了 PID 积分饱和为什么难缠——那本质上是执行器饱和这一非线性在作怪。

## 1 非线性系统为什么难：叠加原理失效

**线性系统（linear system）**满足**叠加原理**：输入之和的响应等于各自响应之和，输入的倍数对应响应的倍数。传递函数能一统天下，全靠这条性质。**非线性系统（nonlinear system）**不满足叠加原理，于是频率特性随输入幅值变化，"同一个系统"没有一个固定的传递函数。

工程上最常见的是**本质非线性（inherent nonlinearity）**——它们不光滑、不可线性化，必须当作非线性来处理：

| 特性 | 数学描述 | 物理来源 |
| --- | --- | --- |
| 饱和（saturation） | $y=\operatorname{sat}(x)$ | 运放限幅、阀门开度极限 |
| 死区（dead zone） | 小信号无输出 | 静摩擦、齿轮间隙 |
| 理想继电器 | 输出仅取 $\pm M$ | 开关控制、继电器 |
| 滞环继电器 | 换向存在回差 | 电磁继电器、双金属片 |

非线性带来的现象，线性系统一样都解释不了：**极限环**（无外力自持振荡）、**跳跃谐振**（频率扫过某点输出突然跳变）、**谐波失真**（输出出现输入没有的频率成分）。分析它们，需要专门的工具——描述函数法先登场。<span class="marginnote">前面《PID 控制》讲的<strong>积分饱和</strong>，本质就是"输出限幅"这一饱和非线性：线性设计假设执行器任意出力，饱和却把真实输出钳住，积分项照常累积，于是退饱和时猛烈超调。非线性不是边角料，它藏在每个工程细节里。</span>

## 2 描述函数法：频域的谐波线性化

**描述函数法（describing function method）**的思路是**谐波线性化**：给非线性环节输入一个正弦

$$x(t) = A \sin \omega t$$

输出 $y(t)$ 是周期信号，做傅里叶展开，只保留**基波分量**（频率与输入相同的那一项），其余高次谐波一律忽略。定义**描述函数**

$$N(A) = \frac{Y_1}{A}$$

其中 $Y_1$ 是输出基波分量的复振幅，$A$ 是输入正弦幅值。对静态非线性（输出只依赖当前输入），$N$ 与频率无关，只随幅值 $A$ 变化——**它刻画的是"在不同信号大小下，非线性环节等效成多大的线性增益"**。

方法成立有三个前提，缺一不可：

- **线性部分低通滤波**：非线性环节后面串联的线性部分 $G(s)$ 必须是低通的，把高次谐波滤干净，基波近似才成立。
- **正弦输入**：实际分析中，正弦通常来自极限环的近似——系统临近自持振荡时信号接近正弦。
- **奇对称特性**：非线性特性奇对称，输出无直流分量，基波才能代表主要行为。

<strong>描述函数法不是严格方法，而是工程近似</strong>——它把"非线性环节 + 线性部分"的回路近似成一个"增益随幅值变化"的等效回路，用成熟的一维频域语言说话，代价是放弃严格性。严格性交给第六节的李雅普诺夫方法。

## 3 公式解析：理想继电特性的描述函数

最能说明描述函数思想的是**理想继电器**：输入为正则输出 $+M$，输入为负则输出 $-M$。它的描述函数是

$$N(A) = \frac{4M}{\pi A}$$

分四步拆解：

- **第一步，看输出波形**：输入 $x = A\sin\omega t$ 为正的半周，输出 $+M$；为负的半周，输出 $-M$。输出是一个与输入**同相位**、幅值 $M$ 的方波。
- **第二步，做傅里叶展开**：这个方波的展开式是 $y(t) = \dfrac{4M}{\pi}\left(\sin\omega t + \dfrac{1}{3}\sin 3\omega t + \dfrac{1}{5}\sin 5\omega t + \cdots\right)$，基波幅值 $Y_1 = \dfrac{4M}{\pi}$。
- **第三步，代入定义**：$N(A) = Y_1/A = 4M/(\pi A)$。注意 $M$、$\pi$ 都是常数，**$N$ 与幅值 $A$ 成反比**。
- **第四步，看物理直觉**：$N \propto 1/A$ 意味着输入幅值越大，等效增益越小——这正是"大信号饱和"的频域表达：继电器系统相当于一个增益随信号变强而**自动收缩**的放大器。这个自调节特性，正是继电器系统产生极限环的根源：小扰动时等效增益大，系统趋于发散；幅值增大后增益下降，增长被遏制，最终稳定在一个自持振荡上。

## 4 用描述函数分析稳定性与极限环

把非线性环节替换成等效增益 $N(A)$，闭环特征方程近似为

$$1 + N(A)\,G(j\omega) = 0 \quad\Longrightarrow\quad G(j\omega) = -\frac{1}{N(A)}$$

在 $G(j\omega)$ 的 Nyquist 图上，同时画出曲线 $-1/N(A)$（$A$ 从 0 增到 $\infty$ 时描出的轨迹），两条曲线的相对位置给出结论：

- **$G(j\omega)$ 曲线不包围 $-1/N(A)$ 曲线**：系统稳定，非线性环节不引发振荡。
- **$G(j\omega)$ 曲线包围 $-1/N(A)$ 曲线**：系统不稳定，趋于发散。
- **两曲线相交**：存在**极限环**。交点处对应的 $A$ 是自持振荡幅值，$\omega$ 是振荡频率。

**极限环的稳定性**由交点附近的走向判定：沿 $A$ 增大的方向，若 $G(j\omega)$ 曲线从"包围 $ -1/N(A)$"过渡到"不包围"，则该极限环是稳定的——扰动偏离它之后会被吸回。<span class="marginnote">判极限环就像在两张图上找交点：一张是线性部分固有的 $G(j\omega)$，一张是随幅值漂移的 $-1/N(A)$。交点处"幅值 $A$ 与频率 $\omega$ 同时确定"，这正是自持振荡的两个量——工程上据此设计"抖动小的继电器系统"。</span>

**辨析｜易错点：** 描述函数法的结论依赖"线性部分低通"这一前提，交点判据是近似的。高阶谐波不可忽略时（如线性部分通带很宽），判定可能出错。此时应退回相平面或李雅普诺夫方法核实，不要迷信一条曲线。

## 5 相平面法：时域的几何图画

**相平面法（phase plane method）**把二阶自治系统

$$\ddot{x} = f(x, \dot{x})$$

的状态 $(x, \dot{x})$ 放在平面上，每个初始状态对应一条**相轨迹**——从轨线的几何形态直接读出系统的全部行为。

- **奇点（平衡点）**：$\dot{x}=0,\ \ddot{x}=0$ 处。在其附近线性化，用特征值判定类型：**稳定节点**（两个负实特征值）、**稳定焦点**（负实部复特征值）、**不稳定节点 / 不稳定焦点**、**鞍点**（一正一负）。<span class="marginnote">鞍点是相平面里最"危险"的奇点：它像马鞍，一条特征方向把轨线吸进来，另一条把它推出去。两条稳定流形把相平面分成不同的归宿区域——这就是后面《混沌与分岔》里"分界线"（separatrix）的原型。</span>
- **极限环**：在相平面上表现为一条**闭合轨线**，周围轨线要么卷入、要么甩出——稳定极限环对应实际可观测的自持振荡。
- **绘制方法**：等倾线法（画出斜率相同的点列）或解析法。对线性欠阻尼二阶系统，相轨迹是收向原点的螺旋（稳定焦点）；对范德波尔振荡器等非线性系统，会出现孤立的极限环。

**等倾线法**的具体操作是：令相轨迹斜率 $\mathrm{d}\dot{x}/\mathrm{d}x = m$，从方程 $\ddot{x}=f(x,\dot{x})$ 解出斜率为 $m$ 的曲线（等倾线），在线上画一段斜率 $m$ 的小线段，再换一个 $m$ 值重复——把所有小线段连起来就是相轨迹。对 $\ddot{x} + 2\zeta\omega_n\dot{x} + \omega_n^2 x = 0$ 这类线性二阶系统，等倾线退化为过原点的直线族，绘制格外方便；这也是相平面法用于"带非线性的二阶系统"时最常用的手算手段。

相平面法直观、严谨，但**只适用于二阶系统**——这限制了它的使用范围。要处理一般阶数，需要第六节的李雅普诺夫方法。

## 6 李雅普诺夫方法：一般情形的严格判据

第二篇《李雅普诺夫稳定性》已经铺垫了这套语言，这里把它接到非线性上。考虑平衡点 $x_e = 0$，**李雅普诺夫第二法（直接法）**的核心结论是：

**若存在连续可微、正定的标量函数 $V(x)$，沿系统轨线满足 $\dot{V}(x) \le 0$，则平衡点是稳定的；若 $\dot{V}(x) < 0$（$x \ne 0$），则平衡点是渐近稳定的。**

构造 $V(x)$ 没有通法，常用候选是二次型 $V(x) = x^T P x$（$P$ 正定）或系统的能量函数——对保守系统，机械能天然是李雅普诺夫函数。<span class="marginnote">李雅普诺夫第二法的直觉：把 $V(x)$ 想成"到平衡点的某种距离的平方"，$\dot{V}<0$ 表示这个距离随时间严格缩短。它不需要解微分方程、不限于二阶、甚至可用于时变系统——严谨性换来的是构造 $V$ 的难度。</span>

**李雅普诺夫第一法（间接法）**在平衡点附近线性化，用特征值判定局部稳定性；但特征值实部为零的临界情形必须回看高阶项——这正是线性化失效、非线性真正起作用的场合。

三件工具的分工就此清晰：**描述函数法**回答"有没有极限环、振幅多大"（工程、近似）；**相平面法**给出二阶系统的全局图景（直观、严格）；**李雅普诺夫方法**提供一般情形的严格判据（严密、但 $V$ 难构造）。它们的共同主题是：**不再用线性假设回避非线性，而是直面它、刻画它、驯服它。**

## 7 小结

- **叠加原理失效**是非线性系统的总根源，带来极限环、跳跃谐振、谐波失真等线性系统不可能有的现象。
- **描述函数法**：$N(A)=Y_1/A$，谐波线性化，用 $G(j\omega)$ 与 $-1/N(A)$ 的交点判极限环；前提是线性部分低通，属工程近似。
- **理想继电器** $N(A)=4M/(\pi A)$：增益随幅值增大而收缩，解释了自持振荡的成因。
- **相平面法**：二阶系统的 $(x,\dot{x})$ 轨线图，奇点类型 + 极限环一目了然，但只限二阶。
- **李雅普诺夫第二法**：构造正定 $V(x)$ 并检验 $\dot{V}<0$，是处理一般非线性系统的严格工具，与第二篇《李雅普诺夫稳定性》直接衔接。

在下一节，我们把视角从单点分析拉回系统层面，进入现代控制理论的**状态空间分析**——在能控能观性的严格框架里做极点配置与观测器设计。非线性章留下的"极限环与稳定性"直觉，将在更一般的状态空间语言里获得统一的表述。
