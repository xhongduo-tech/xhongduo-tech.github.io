## 为什么从强化学习控制开始

前几节的智能控制（模糊、神经网络、自适应）都默认"系统模型可知或可学"。但当对象复杂到模型写不出来、环境又充满不确定性时，还有一条更"生物"的路——**强化学习（Reinforcement Learning, RL）**：智能体与环境**反复交互**，通过试错和奖励信号学出最优策略，全程不需要模型。2013 年 DeepMind 用深度 Q 网络（DQN）打游戏、2016 年 AlphaGo 击败李世石、再到机器人控制、自动驾驶、大模型对齐（RLHF）——RL 是当今 AI 最活跃的分支之一。从控制理论的视角看，RL 是《动态规划与变分法》的现代继承者：**贝尔曼方程就是 RL 的理论心脏**。这一节把 RL 放进控制语境，讲清它与经典最优控制的血缘关系，以及它在控制中的用法与难点。<span class="marginnote">RL 与控制论的亲缘：Sutton 与 Barto 的教科书把 RL 的根追溯到最优控制（贝尔曼动态规划）与试错学习心理学两条线。控制理论家看 RL，会觉得它是"无模型、数据驱动、在线学习的动态规划"——新瓶装的不全是新酒，但瓶子实用多了。</span>

## 1 马尔可夫决策过程：RL 的语言

RL 的数学框架是**马尔可夫决策过程（MDP）**，由五元组描述：

$$\big(\mathcal{S}, \mathcal{A}, P, R, \gamma\big)$$

- $\mathcal{S}$：状态集合；$\mathcal{A}$：动作集合；
- $P(s' \mid s, a)$：**状态转移概率**——从状态 $s$ 执行动作 $a$ 到新状态 $s'$ 的概率；
- $R(s, a)$：**奖励函数**——执行动作得到的即时回报；
- $\gamma \in [0,1)$：**折扣因子**——未来奖励的折现率。

智能体的目标是最大化**累积折扣回报**：

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty}\gamma^k R_{t+k+1}$$

$\gamma$ 体现"远见"：$\gamma$ 接近 1，重视远期回报；$\gamma$ 小，只图眼前。这与最优控制里"无限时域折扣指标"完全同构。<span class="marginnote">$\gamma$ 与控制论的联系：折扣因子让无穷和收敛（数学需要），也让"当下偏好"有了解释。在最优控制里对应无限时域指标的折扣版本；$\gamma=1$ 且有限时域则退化为经典 LQR 的指标。</span>

## 2 价值函数与策略

RL 的两个核心对象：

**策略（policy）$\pi(a \mid s)$**：状态到动作的映射——"在状态 $s$ 下该做什么"。控制论里，策略就是控制器。

**状态价值函数（state-value function）**：从状态 $s$ 出发、按策略 $\pi$ 行动的期望回报：

$$V_\pi(s) = \mathbb{E}_\pi\big[ G_t \mid s_t = s \big]$$

**动作价值函数（action-value function，Q 函数）**：状态 $s$ 下先执行动作 $a$、之后按 $\pi$ 行动的期望回报：

$$Q_\pi(s, a) = \mathbb{E}_\pi\big[ G_t \mid s_t = s, a_t = a \big]$$

**最优策略**是使价值函数最大的策略，其价值函数满足**贝尔曼最优方程**：

$$Q^*(s,a) = R(s,a) + \gamma \sum_{s'} P(s'\mid s,a) \max_{a'} Q^*(s', a')$$

这正是《动态规划与变分法》里贝尔曼方程在随机环境的版本——只是多了一个 $\max_{a'}$（选择最优动作）与期望（对随机转移）。**RL 的全部算法，都是在不知道 $P$ 的情况下逼近这个方程的解**。<span class="marginnote">控制论视角：$Q^*$ 等价于最优控制里的"值函数" $V(x)$，贝尔曼最优方程等价于 HJB 方程的离散随机版本。最优控制求解析/数值解，RL 用数据逼近——路线不同，目标同一。</span>

## 3 公式解析：Q-learning 更新

**Q-learning** 是最经典的无模型强化学习算法，其更新规则：

$$Q(s,a) \leftarrow Q(s,a) + \alpha \Big[ R + \gamma \max_{a'} Q(s', a') - Q(s,a) \Big]$$

对它做四步拆解：

- **第一步，看括号里的"时序差分（TD）误差"**：$R + \gamma\max_{a'}Q(s',a')$ 是"这个动作的实际回报 + 下一状态的最优未来价值"——这是对 $Q(s,a)$ 的一个**新估计**。减去当前 $Q(s,a)$ 就是估计的偏差（TD 误差）。
- **第二步，看学习率 $\alpha$**：$\alpha$ 决定朝新估计挪多少。$\alpha\to1$ 全信最新样本，$\alpha\to0$ 几乎不变。工程上用衰减学习率。
- **第三步，看 $\max_{a'}$ 的角色**：用"下一状态的最优动作价值"更新当前——这是**离策略（off-policy）**的关键：Q-learning 学的是最优策略的价值，不管当前在用什么策略采样。这让它可以用任意探索策略收集数据。
- **第四步，看无模型之处**：更新里只有 $R, s', \gamma$，**没有转移概率 $P$**——这就是"无模型"的含义：不需要系统模型，只靠采样交互。

## 4 策略梯度与深度 RL

Q-learning 适合离散动作；连续控制（电机、机器人）需要**策略梯度（policy gradient）**方法。核心思想：把策略参数化 $\pi_\theta$，直接用梯度上升优化期望回报：

$$\nabla_\theta J(\theta) = \mathbb{E}\Big[ \nabla_\theta \log \pi_\theta(a\mid s)\, A(s,a) \Big]$$

其中 $A(s,a)$ 是优势函数（动作好坏的度量）。这条公式神奇地解决了《神经网络控制》里的"误差反传过对象"难题——**用奖励信号和采样估计梯度，完全不碰对象模型**。这就是为什么 RL 能控制模型未知、甚至不可微的系统。

现代深度 RL 的代表算法：

- **DQN**：用深度网络逼近 $Q$ 函数（+经验回放、目标网络）。
- **DDPG / TD3 / SAC**：连续动作的 Actor-Critic 方法，工业机器人控制的主力。
- **PPO**：稳定的策略梯度方法，今天的默认选择。<span class="marginnote">Actor-Critic 的直觉：Actor（演员）是策略 $\pi_\theta$，Critic（评论家）是价值函数 $V$——演员按评论家的评分改进表演，评论家按实际回报改进打分。这个双循环与"控制器 + 观测器"的分离结构有异曲同工之妙。</span>

## 5 RL 在控制中的应用与挑战

RL 在控制领域的应用已经成规模：

- **机器人**：机械臂抓取（手内操作）、四足/双足行走、无人机避障——RL 在仿真里大规模训练、迁移到真机。
- **自动驾驶**：端到端驾驶策略、决策与规划层。
- **过程控制**：化学反应器、能源系统调度——离线仿真训练 + 在线部署。
- **大模型对齐**：RLHF（基于人类反馈的强化学习）把 LLM 的策略对齐到人类偏好——这是 RL 在非物理控制里的最著名应用。

**RL 用于控制的核心挑战**：

- **安全**：试错在真实物理系统上可能造成事故——需要安全约束、仿真先行、离线 RL。
- **奖励设计**：奖励函数难写——"奖励黑客"（agent 找到刷分的漏洞）是 RL 的著名问题。控制指标（ITAE、超调）要小心翻译成奖励。
- **样本效率**：真实系统采样昂贵，RL 往往需要百万级样本——仿真到真实的迁移（sim-to-real）是缓解手段。
- **稳定性保证**：RL 策略多为黑箱，无法直接证明闭环稳定——常与李雅普诺夫、鲁棒控制结合做"安全毯"。<span class="marginnote">RL 与经典控制结合的现代路线：用 MPC 生成安全轨迹作"示范"给 RL 学，或用李雅普诺夫函数约束 RL 的探索范围（如 Lyapunov-based safe RL）。"学习 + 安全保证"是 RL 落地到物理系统的必经之路。</span>

## 6 RL 算法选型指南

强化学习算法很多，按问题特征选型是工程关键：

| 问题特征 | 推荐算法 | 理由 |
| --- | --- | --- |
| 离散动作、表格规模小 | Q-learning | 简单可靠，收敛有保证 |
| 离散动作、状态空间大 | DQN 及其变体 | 深度网络逼近 Q 函数 |
| 连续动作、单智能体 | DDPG / TD3 / SAC | Actor-Critic 处理连续空间 |
| 连续动作、要稳定 | PPO | 裁剪目标保证稳定，默认选择 |
| 真实系统、样本稀缺 | 离线 RL / 基于模型 RL | 复用历史数据、减少试错 |
| 多智能体协同 | MADDPG 等 | 处理智能体间交互 |

**选型三问**：动作是离散还是连续？状态空间多大？能否在仿真里试错（样本贵不贵）？三问一答，算法就收敛到两三个候选。<span class="marginnote">工程铁律：能离线学的就别在线学，能在仿真学的就别在真机学。样本成本从低到高是"表格 → 仿真 → 真机"，RL 的工程艺术很大程度是"把样本需求压到最低档"。</span>

**控制场景的特殊考虑**：物理系统的 RL 还要额外回答——安全怎么保证（约束/安全毯）、奖励怎么设计（防奖励黑客）、仿真与现实差多少（sim-to-real）。**RL 在控制里的真正难点从来不是算法本身，而是"安全地获得足够多的好数据"**。

**辨析｜易错点：** 别一上来就上最复杂的算法。DQN 调不好先试 Q-learning，SAC 调不好先试 PPO——**先让简单基线跑通、建立"任务可达"的信心，再逐步升级**。RL 调参非常依赖实现细节（奖励缩放、网络结构、超参数），从简单开始能少踩一半坑。

## 7 小结

- **RL**：智能体与环境试错交互、最大化累积折扣回报；MDP 是框架，贝尔曼方程是理论心脏。
- **价值函数**：$V_\pi(s)$（状态价值）与 $Q_\pi(s,a)$（动作价值）；最优策略满足**贝尔曼最优方程**。
- **Q-learning** 更新：$Q \leftarrow Q + \alpha[R + \gamma\max_{a'}Q(s',a') - Q]$，无模型、离策略。
- **策略梯度**：$\nabla_\theta J = \mathbb{E}[\nabla_\theta\log\pi_\theta\, A]$，绕开"反传过对象"难题，适合连续控制。
- RL 应用：机器人、自动驾驶、过程控制、RLHF；挑战是**安全、奖励设计、样本效率、稳定性保证**。
