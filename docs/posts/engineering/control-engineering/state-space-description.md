## 为什么从状态空间开始

经典控制理论（第一篇）用**传递函数**描述系统，它回答「输入输出之间的映射」——但有一个根本盲区：**它看不见系统内部**。一个传递函数可能对应多个物理上完全不同的内部结构；初始条件被"清零"后，系统自身的能量状态也被忽略了。1960 年代，以卡尔曼（R. E. Kalman）为代表的现代控制理论引入了**状态空间（state space）**描述：把系统的内部用一组状态变量完整刻画，写成矩阵微分方程。这一转变带来了三样经典理论给不了的东西：**多输入多输出（MIMO）的自然处理**、**初始条件的完整纳入**、以及后续能控性、能观性、状态反馈、最优控制这些现代工具的代数舞台。状态空间也是现代机器学习、强化学习、滤波理论、乃至大模型里「隐状态」概念的数学源头。<span class="marginnote">现代控制理论常以 1960 年为界：卡尔曼在同一年发表了能控性与卡尔曼滤波两大奠基性成果。状态空间法的核心工具是线性代数——所以这门课在第二级《线性代数》之后学才最顺畅。</span>

## 1 状态、状态变量与状态空间

先厘清三个层层递进的定义：

**状态（state）**：系统在某个时刻的全部信息——知道当前状态和未来输入，就能唯一确定系统未来的行为。
**状态变量（state variable）**：足以完整描述系统状态的一组最少的变量 $x_1(t), x_2(t), \dots, x_n(t)$。
**状态向量与状态空间**：把 $n$ 个状态变量排成列向量 $x(t) = [x_1, x_2, \dots, x_n]^T$，所有可能状态向量构成的 $n$ 维空间叫**状态空间**。

「状态」的选择**不唯一**，但有原则：对物理系统，通常选**独立的储能元件的能量变量**——例如电系统的电容电压与电感电流、机械系统的位移与速度。$n$ 个状态变量对应 $n$ 个一阶微分方程，这就是状态方程的维度来源。<span class="marginnote">状态变量的个数 = 系统的<strong>阶数</strong> = 独立储能元件的个数。一个 $n$ 阶微分方程可以拆成 $n$ 个一阶微分方程组——这是「把一个高阶方程降为一阶方程组」的核心手法，也是状态空间描述的最小规模。</span>

## 2 状态空间表达式

线性时不变系统的状态空间描述由两个方程构成：

**状态方程（state equation）**——描述状态的变化：

$$\dot{x}(t) = Ax(t) + Bu(t)$$

**输出方程（output equation）**——描述输出如何从状态与输入读出：

$$y(t) = Cx(t) + Du(t)$$

其中 $x \in \mathbb{R}^n$ 是状态向量，$u \in \mathbb{R}^m$ 是输入向量，$y \in \mathbb{R}^p$ 是输出向量；矩阵 $A$（$n\times n$）叫**系统矩阵**，$B$（$n\times m$）叫**输入矩阵**，$C$（$p\times n$）叫**输出矩阵**，$D$（$p\times m$）叫**直接传递矩阵**（多数系统 $D=0$）。<span class="marginnote">矩阵的每个元素都有物理含义：$A$ 描述状态之间的耦合（例如位移影响速度、速度影响加速度），$B$ 描述输入如何注入各状态，$C$ 描述哪些状态被测量到。看懂这四个矩阵，就"看见"了系统内部结构。</span>

对比传递函数，状态空间表达的优越性立刻显现：

| 特点 | 传递函数 | 状态空间 |
| --- | --- | --- |
| 适用系统 | 线性定常、单入单出 | 线性/非线性、多入多出 |
| 初始条件 | 假定为零 | 完整纳入状态 |
| 内部信息 | 不可见 | 状态全可见 |
| 计算机处理 | 代数 | 矩阵运算，天然适合 |

## 3 从微分方程与传递函数建立状态空间

把高阶微分方程化为状态空间的标准手法是**选状态变量 = 输出及其各阶导数**。

对微分方程 $y^{(n)} + a_{n-1}y^{(n-1)} + \cdots + a_0 y = b u$，令 $x_1 = y, x_2 = \dot{y}, \dots, x_n = y^{(n-1)}$，得到：

$$\dot{x}_1 = x_2, \quad \dot{x}_2 = x_3, \quad \dots, \quad \dot{x}_n = -a_0 x_1 - a_1 x_2 - \cdots - a_{n-1}x_n + b u$$

写成矩阵形式即得**能控标准型（可控标准型）**。若从传递函数出发，可把它化成**能控标准型**、**能观标准型**或**对角型（Jordan 型）**等不同实现——同一传递函数对应**无穷多个状态空间实现**，这正是「状态空间不唯一」的体现。

**最小实现**：传递函数分母分子消去公因子后得到的阶数最低的实现。若出现零极点对消，系统的某些状态既不被输入激发、也不被输出观察——这直接预告下一节的**能控性与能观性**概念。<span class="marginnote">传递函数 vs 状态空间的「一一对应」误区：传递函数 $\to$ 状态空间是多对一。只有加上「能控且能观」的条件，才得到唯一的最小实现。这个细节是现代控制里最容易漏掉的概念连接。</span>

## 4 公式解析：状态方程

$$\dot{x}(t) = Ax(t) + Bu(t)$$

对它做四步拆解：

- **第一步，看 $\dot{x}$**：状态对时间的导数，代表状态的变化率。$n$ 维状态对应 $n$ 个一阶常微分方程——全部是**一阶**的，这正是状态空间的代数魅力：高阶微分方程被降阶成方程组，解法统一为矩阵指数。
- **第二步，看 $Ax$**：状态自身的变化规律，即**系统的固有动力学**。$A$ 的特征值就是系统的**极点**——它决定自由响应的衰减快慢与振荡频率，等价于经典理论里的特征根。$A$ 的特征多项式 $\det(sI-A)$ 正是传递函数的分母（特征方程）。
- **第三步，看 $Bu$**：输入对状态变化率的贡献。$B$ 决定输入能量如何注入各状态通道，对应经典理论里传递函数分子的部分信息。
- **第四步，整体看**：状态方程是「状态在时间上的演化律」，输出方程是「从状态读出观测量的规则」。两个方程合起来，完全刻画了一个线性系统的**外部行为**：从任意初始状态与任意输入出发，都能算出任意时刻的输出。

## 5 状态空间与传递函数的关系

两个描述之间的桥梁是拉普拉斯变换。对状态方程与输出方程取拉普拉斯变换（零初始条件）：

$$sX(s) = AX(s) + BU(s), \qquad Y(s) = CX(s) + DU(s)$$

消去 $X(s)$，得：

$$G(s) = \frac{Y(s)}{U(s)} = C(sI - A)^{-1}B + D$$

这就是从状态空间到传递函数的**标准公式**。其中 $(sI-A)^{-1}$ 的每个元素都是 $s$ 的有理函数，分母 $\det(sI-A)$ 正是特征多项式——**$A$ 的特征值 = 闭环（开环）极点**这条纽带，让现代与经典理论在这里握手。<span class="marginnote">$(sI-A)^{-1}$ 在时域对应的是矩阵指数 $e^{At}$——下一节状态方程求解的主角。学过《线性代数》的矩阵函数与《常微分方程》的一阶方程组，这一节会非常顺。</span>

## 6 相平面：状态的几何

状态空间不只给出一堆矩阵，它还给出系统行为的**几何图景**。对二阶系统，把两个状态 $x_1, x_2$ 作为平面坐标，状态随时间演化画出的轨迹叫**相轨迹（phase trajectory）**，整个平面叫**相平面（phase plane）**。<span class="marginnote">相平面在《常微分方程》里是定性分析的标准工具。对二阶系统，画一条相轨迹，就同时看见了"位置、速度、能量"的全部信息——一条曲线胜过两条时间曲线。</span>

看几个典型系统的相平面形态：

- **稳定节点**：两个负实特征值，相轨迹从四面八方"吸入"原点——对应过阻尼系统，单调收敛。
- **稳定焦点**：共轭复根负实部，相轨迹螺旋收敛到原点——对应欠阻尼系统，衰减振荡。
- **中心**：纯虚特征值，相轨迹是闭合椭圆——无阻尼等幅振荡。
- **鞍点**：一个正实根一个负实根，相轨迹沿一条方向"逃逸"——不稳定平衡。

**相平面把"特征值的位置"翻译成"轨迹的形状"**：特征值实部决定收敛/发散，虚部决定旋转/振荡。这在《现代控制理论》里是理解能控能观、李雅普诺夫稳定性的直观底座——一个系统稳不稳定，看相轨迹往哪走就一目了然。

**辨析｜易错点：** 相平面只适用于**二阶**（或可降阶的二阶）系统；三阶以上需要"相空间"（高维），几何直观大幅减弱。二阶系统的相平面分析是"用眼睛理解动力学"的绝佳训练，但别指望它处理高维系统——那要回到代数方法。

**状态空间的离散化**：计算机只能处理离散时间，所以连续状态空间 $\dot x = Ax + Bu$ 要转成离散形式 $x_{k+1} = A_d x_k + B_d u_k$。精确离散化公式：

$$A_d = e^{AT_s}, \qquad B_d = \int_0^{T_s} e^{A\tau}B\,\mathrm{d}\tau$$

其中 $T_s$ 是采样周期。注意 $A_d$ 正是矩阵指数在采样周期处取值——**离散化又回到了 $e^{At}$**，而 $B_d$ 是输入矩阵在采样周期内的"积分效果"。<span class="marginnote">离散化是联系连续物理世界与数字控制器的桥梁：传感器以 $T_s$ 为间隔采样，控制器在离散时刻运算，控制量保持到下一个采样周期（零阶保持器）。$A_d, B_d$ 把这三件事压缩进两个矩阵。</span>

**辨析｜易错点：** 采样周期 $T_s$ 必须远小于系统最快动态（工程取带宽的 10~20 倍），否则离散模型丢失高频信息、控制器性能退化。离散化的 $A_d$ 特征值与连续 $A$ 特征值满足 $\lambda_{d} = e^{\lambda T_s}$——连续稳定（左半平面）映射到离散稳定（单位圆内），"稳定域从半平面变成单位圆"，这是离散控制与连续控制最本质的记号差异。

## 7 小结

- **状态**是系统的完整内部描述，状态变量取独立储能元件的能量变量，个数等于系统阶数。
- 状态空间表达式：**状态方程** $\dot{x}=Ax+Bu$ 与**输出方程** $y=Cx+Du$。
- 状态空间支持**多入多出、非线性、非零初始条件**，优于传递函数；矩阵 $A,B,C,D$ 各含明确的物理/结构信息。
- 同一传递函数有**无穷多个实现**，最小实现要求能控且能观。
- 桥接公式 $G(s) = C(sI-A)^{-1}B+D$，$A$ 的特征值即系统的极点。

在下一节，我们直面状态方程的第一个计算问题：给定初始状态和输入，状态 $x(t)$ 到底怎么随时间演化？——这就要请出**矩阵指数 $e^{At}$**，也就是**状态方程求解**。
