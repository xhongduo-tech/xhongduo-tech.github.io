## 为什么从频率响应开始

前面几节我们先后用「解微分方程」「看极点移动」来理解系统。这一节换第三副眼镜——**频率域**。思路朴素到惊人：给系统灌进不同频率的正弦输入，观察输出的幅度衰减了多少、相位滞后了多少，把这个「随频率变化的行为」画成图，就得到了系统在频率域的画像。频率法有两大优势：一是**实验上直接可测**（给正弦输入、读输出，不需要推导模型），二是**图为基的设计**（Bode 图上画一画、量一量，就能设计校正器）。它是工业界最常用的分析和设计语言。<span class="marginnote">频率法的先驱是 Bode 与 Nyquist，诞生于 1930 年代贝尔实验室的通信与放大器设计。频率法让工程师脱离繁琐的代数，用「画图+测量」的方式处理高阶系统，至今仍是伺服、电源、航空航天控制的标配语言。</span>

## 1 频率特性的概念

设线性定常系统传递函数为 $G(s)$，输入是正弦信号 $r(t) = A\sin\omega t$。在**稳态**（暂态衰减完毕）后，输出是同频率的正弦，但幅度和相位都变了：

$$c_{ss}(t) = A|G(j\omega)|\sin\big(\omega t + \angle G(j\omega)\big)$$

其中 $s = j\omega$ 代入 $G(s)$ 得到复函数 $G(j\omega)$，它叫**频率特性（frequency response）**：

- **幅频特性** $|G(j\omega)|$：输出幅值 / 输入幅值的比，随 $\omega$ 变化；
- **相频特性** $\angle G(j\omega)$：输出相对输入的相角滞后（一般为负），随 $\omega$ 变化。

**频率特性 $G(j\omega)$ 就是 $s$ 沿虚轴取值时的传递函数**。这是联系时域与频域的关键桥梁——$G(s)$ 是整个复平面上的函数，$G(j\omega)$ 只是它在虚轴上的取值，但足以刻画系统的全部正弦稳态行为。<span class="marginnote">为什么只看虚轴就够了？因为正弦输入 $e^{j\omega t}$ 是系统的"本征信号"——线性系统对它只做幅值缩放与相位搬移，不做频率变换。这正是傅里叶级数思想在系统理论中的体现，与《复变函数》里沿虚轴取值的解析延拓一脉相承。</span>

## 2 Bode 图：对数幅频与相频

**Bode 图（伯德图）**由上下两幅图组成：

- 上幅：**对数幅频特性**，纵轴为 $20\lg|G(j\omega)|$（单位 dB，分贝），横轴为 $\omega$（对数刻度）；
- 下幅：**相频特性**，纵轴为 $\angle G(j\omega)$（单位度），横轴同为对数刻度。

用对数坐标的原因：**乘法变加法**。系统由多个环节串联时，总幅频是各环节幅频之积，取对数后变成各环节对数幅频之和，于是**整条 Bode 图由各基本环节的渐近线叠加而成**——这就是手绘 Bode 图的全部诀窍。

基本环节的对数幅频渐近线：

- **比例环节 $K$**：水平直线 $20\lg K$ dB，相角 0°。
- **积分环节 $1/s$**：斜率 $-20$ dB/dec 的直线，过 $\omega=1$ 处为 0 dB；相角恒为 $-90°$。
- **一阶惯性 $1/(Ts+1)$**：$\omega < 1/T$ 为 0 dB，$\omega > 1/T$ 为 $-20$ dB/dec；转折频率 $\omega_c = 1/T$ 处相位为 $-45°$，低频 0°、高频 $-90°$。
- **二阶振荡 $1/(s^2 + 2\zeta\omega_n s + \omega_n^2)$**：低频 0 dB、高频 $-40$ dB/dec，转折处有谐振峰（$\zeta$ 越小峰越高）；相位从 $0°$ 到 $-180°$。<span class="marginnote">一阶环节的转折频率是带宽感的来源：$\omega_c=1/T$ 处幅值实际为 $-3$ dB（比渐近线低 3 dB），相位 $45°$。工程上常把 $-3$ dB 点定义为带宽——信号频率超过带宽就被明显衰减。</span>

手绘步骤：先把各环节的转折频率标在对数轴上，从低频段按叠加规则画渐近线，每过一个转折频率就改变斜率（惯性减 20、振荡减 40、微分环节反向），最后修正谐振峰。

## 3 Nyquist 图与奈奎斯特判据预告

**Nyquist 图（奈奎斯特图）**是频率特性 $G(j\omega)$ 在复平面上的轨迹：$\omega$ 从 0 到 $\infty$，点 $G(j\omega)$ 走出一条曲线（$\omega$ 从负无穷到正无穷则是完整闭合曲线）。它把幅值、相角压缩进一张平面图，用几何的方式回答稳定性问题。

Nyquist 图的几个特征点：$\omega=0$ 时 $G(j0)$（对 0 型系统是 $K$，在正实轴上）；$\omega\to\infty$ 时趋向原点（方向取决于分母阶次）；与负实轴的交点最关键——这个交点对应的 $\omega$ 称为**穿越频率**，交点与 $(-1, j0)$ 点的相对位置直接决定稳定性。

**稳定性判据（Nyquist）**的基本陈述：若开环在右半平面有 $P$ 个极点，闭环稳定当且仅当 Nyquist 曲线**逆时针包围 $(-1,j0)$ 点 $P$ 次**。对工程上常见的 $P=0$（开环稳定）情形，判据简化为：**曲线不包围 $(-1,j0)$ 点则闭环稳定**。<span class="marginnote">这条判据的深层来源是复变函数里的幅角原理（围线积分）：$1+GH$ 绕原点的圈数 = 右半平面零点数减去极点数。Nyquist 把它变成了一条可以在图纸上直接数圈子的规则。下一节我们会完整展开。</span>

## 4 增益裕度与相位裕度

稳定还不够，工程上要问「有多稳」——这由**稳定裕度（stability margin）**度量，是 Bode 图设计中最常用的两个量：

- **相位裕度（phase margin）$\gamma$**：在幅值穿越频率 $\omega_c$（幅频曲线过 0 dB 的频率）处，相角与 $-180°$ 之差：
$$\gamma = 180° + \angle G(j\omega_c)$$
- **增益裕度（gain margin）$h$**：在相位穿越频率 $\omega_g$（相角等于 $-180°$ 的频率）处，幅值距 0 dB 的距离（负值越大越稳）：
$$h = -20\lg|G(j\omega_g)| \ \text{dB}$$

工程经验：$\gamma$ 在 $30°\sim60°$、$h$ 大于 6 dB 时，系统既稳定又不过分保守。相位裕度还与时域阻尼比有近似关系：对典型二阶系统 $\gamma \approx 100\zeta$（度），因此**相位裕度 ≈ 时域超调的镜像**——它把频域的图与时域的"稳准快"直接接上了。<span class="marginnote">相位裕度的直觉：负反馈系统在相角达到 $-180°$ 时反馈变成正反馈。$\gamma$ 度量的是「距正反馈临界还差多少度」，余量越大越安全。设计校正器时提高 $\gamma$，通常也意味着减小超调。</span>

## 5 公式解析：从 $G(s)$ 到频率特性

$$G(j\omega) = |G(j\omega)|\,e^{j\angle G(j\omega)}$$

以一个典型开环传递函数 $G(s) = \frac{K}{s(Ts+1)}$ 为例，做四步拆解：

- **第一步，代入 $s = j\omega$**：$G(j\omega) = \frac{K}{j\omega(1 + j\omega T)}$。分母是两个因子的乘积，每个因子都是复数。
- **第二步，算幅值**：$|G(j\omega)| = \frac{K}{\omega\sqrt{1+(\omega T)^2}}$。分子是实数 $K$，分母模是 $|j\omega|\cdot|1+j\omega T| = \omega\sqrt{1+\omega^2T^2}$。取对数：$20\lg|G| = 20\lg K - 20\lg\omega - 20\lg\sqrt{1+(\omega T)^2}$——三项分别对应比例、积分、惯性三条渐近线，叠加原理在此显形。
- **第三步，算相角**：$\angle G = 0° - 90° - \arctan(\omega T)$。积分环节贡献 $-90°$，惯性环节贡献 $-\arctan(\omega T)$（从 0° 到 $-90°$ 平滑过渡）。
- **第四步，验证两个关键点**：$\omega T \ll 1$ 时，幅值 $\approx K/\omega$（$-20$ dB/dec 直线），相角 $\approx -90°$；$\omega T \gg 1$ 时，幅值 $\approx K/(\omega^2 T)$（$-40$ dB/dec），相角 $\approx -180°$。这条曲线穿越 0 dB 处读出 $\omega_c$，代回相角公式即得相位裕度 $\gamma$——**整条系统的稳定性，一图可读**。

**辨析｜易错点：** 用 dB 时幅值取 $20\lg$（电压/位移类），而功率类用 $10\lg$，两者差一倍，别混。另外 $\arctan$ 的象限要按 $\omega T$ 为正确认相角在第三、四象限（$-90°\sim-180°$），不能把正切的多值性带进相角。<span class="marginnote">另一个高频坑：转折频率处渐近线误差最大（惯性环节在 $\omega_c$ 处实际幅值比渐近线低 3 dB、相角差 5.7°）。手绘精度够用，但精算校正器时必须用真实曲线而不是渐近线。</span>

## 6 从 Bode 图读系统性能

Bode 图不只是画来好看的，它是工程师的"体检报告"。几个常用读法：

**读带宽（bandwidth）**：幅频曲线从低频基准下降 3 dB 处对应的频率叫**带宽** $\omega_b$。带宽越高，系统能不失真通过的频率范围越宽——**带宽与响应速度成正比**：带宽翻倍，阶跃响应的上升时间大致减半。这是"要快就加带宽"的频域依据。<span class="marginnote">上升时间 $t_r$ 与带宽的工程经验关系：$t_r \approx 0.35/f_b$（单位 GHz 级）。给定带宽要求，直接反推响应速度——航天、通信、伺服设计里这个换算用得极频繁。</span>

**读谐振峰（resonance peak）**：二阶系统在 $\omega_n$ 附近幅频出现峰值，峰值高度 $M_r$ 与阻尼比 $\zeta$ 负相关：$\zeta$ 越小峰越高。$M_r$ 大意味着阶跃响应的超调大——**谐振峰是超调的频域镜像**。

**读稳定裕度**：相位裕度在 Bode 图上就是"相位曲线在幅值穿越频率处距 $-180^\circ$ 的高度"。设计时先看幅频过 0 dB 的位置（穿越频率 $\omega_c$），再读该处相位——一图两读，稳定与否、稳定多少一目了然。

**读系统类型**：低频段幅频斜率直接暴露系统类型数——0 型是水平线，I 型是 $-20$ dB/dec，II 型是 $-40$ dB/dec。**扫一眼低频斜率，就知道系统对阶跃/斜坡有没有稳态误差**——这是 Bode 图最廉价的"体检项目"。

**辨析｜易错点：** 带宽不是越高越好。带宽高 = 响应快 = 对高频噪声敏感 + 对未建模高频动态危险（可能激起谐振）。工程上"带宽是给够就行，不是越大越好"——这与超调、噪声、鲁棒性之间的权衡完全一致。

**频率法与时域指标的对应**：频率域的每个量都能翻译成时域的性能，这是频率法"可以设计时域性能"的依据：

| 频域量 | 时域对应 | 关系 |
| --- | --- | --- |
| 相位裕度 $\gamma$ | 阻尼比 $\zeta$、超调 | $\gamma \approx 100\zeta$（二阶近似） |
| 穿越频率 $\omega_c$ | 调节时间 $t_s$ | 带宽越大响应越快 |
| 谐振峰 $M_r$ | 超调量 | $M_r$ 大则超调大 |
| 低频增益 | 稳态精度 | 增益高则误差小 |
| 高频增益 | 噪声敏感度 | 高频增益高则噪声大 |

这张对应表是频率法设计的"翻译字典"：你在 Bode 图上要调的量，全部对应时域的"稳准快"。反过来，给定时域指标，也能换算成频域目标——这正是校正设计（超前/滞后）的起点。**学会在两张图之间来回翻译，是频率法最值钱的能力**。

**一句话记住频率法**：频率法 = 用"不同频率的正弦输入被放大了多少、移相了多少"来描述系统——**一张 Bode 图，同时给出稳定性（裕度）、动态（带宽）、精度（低频增益）**。它是唯一"从实验数据直接读系统"的方法，也是工程现场最通用的控制语言。

## 7 小结

- **频率特性** $G(j\omega)$ 是传递函数在虚轴上的取值，描述系统对正弦输入的稳态响应（幅值比 + 相位差）。
- **Bode 图**用对数坐标，把乘法变加法，整图由基本环节渐近线**叠加**而成。
- **Nyquist 图**是 $G(j\omega)$ 在复平面上的轨迹，为 Nyquist 稳定性判据提供几何舞台。
- **相位裕度** $\gamma$ 与**增益裕度** $h$ 度量「有多稳」，工程经验值 $\gamma \in 30°\sim60°$、$h>6$ dB。
- 由 $G(j\omega)$ 的幅值、相角公式可读出 $\omega_c$、$\gamma$——**频域的图就是时域性能的镜像**。

在下一节，我们把 Nyquist 判据说完整：什么样的系统曲线要绕 $(-1,j0)$ 几圈才算稳定？——那是频率法对稳定性问题的最终回答。
