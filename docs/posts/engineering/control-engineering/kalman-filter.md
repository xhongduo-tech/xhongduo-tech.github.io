## 为什么从卡尔曼滤波开始

前面观测器的假设是"输出没噪声、模型很精确"。现实正好相反：陀螺仪有漂移、雷达有杂波、GPS 有误差，而模型也不可能精确到分毫不差。1960 年卡尔曼发表的那篇论文，把状态估计放进**随机框架**：模型有过程噪声、测量有量测噪声，问题是——**在噪声统计已知的前提下，怎样给出状态的最小方差估计？** 答案就是**卡尔曼滤波（Kalman filter）**。它没有淘汰观测器，而是把固定增益 $L$ 升级成随时间、按噪声统计最优变化的增益。阿波罗登月舱的导航、GPS、自动驾驶、金融时间序列、乃至大模型训练里的优化器动量——卡尔曼滤波无处不在，是应用数学史上被引用最多的成果之一。<span class="marginnote">名字里的"滤波"来自信号处理的古典含义：从含噪信号里"滤出"真实信号。卡尔曼滤波是时域、递推、适合计算机在线执行的滤波器——相比维纳滤波（频域、需全部历史数据），它一步一递推，天然适合实时系统。</span>

## 1 随机系统模型

把噪声加进状态空间模型，得到离散随机系统：

$$x_{k+1} = A x_k + B u_k + w_k$$
$$y_k = C x_k + v_k$$

- $w_k$：**过程噪声**（过程扰动、模型误差），协方差 $Q_w$；
- $v_k$：**量测噪声**（传感器误差），协方差 $R_v$；
- 通常假设二者为零均值高斯白噪声、互不相关。

问题设定：已知模型 $(A,B,C)$、噪声统计 $(Q_w, R_v)$、一系列测量 $y_1, \dots, y_k$，求状态 $x_k$ 的**最优估计**——在"最小方差"（估计误差协方差最小）意义下。<span class="marginnote">高斯假设不是可有可无：在高斯噪声下，最小方差估计就是条件期望 $\hat{x} = E[x \mid y_1,\dots,y_k]$，且是线性最优的。噪声非高斯时，卡尔曼滤波仍是最小方差线性估计（LMMSE），只是不再全局最优——但工程上足够好。</span>

## 2 预测-更新两步行

卡尔曼滤波是一套**递推两步走**，每来一个测量，先预测、再修正：

**第一步：预测（时间更新）**——用模型往前推一步：

$$\hat{x}_{k|k-1} = A\hat{x}_{k-1|k-1} + B u_{k-1}$$
$$P_{k|k-1} = A P_{k-1|k-1} A^T + Q_w$$

这里 $P$ 是估计误差协方差矩阵。预测把"已知的动力学"与"过程噪声"都折算进不确定性的增长——**模型往前推，不确定性也在长大**。

**第二步：更新（量测更新）**——用新测量修正预测：

$$K_k = P_{k|k-1} C^T \big( C P_{k|k-1} C^T + R_v \big)^{-1}$$
$$\hat{x}_{k|k} = \hat{x}_{k|k-1} + K_k \big( y_k - C\hat{x}_{k|k-1} \big)$$
$$P_{k|k} = \big( I - K_k C \big) P_{k|k-1}$$

其中 $y_k - C\hat{x}_{k|k-1}$ 叫**新息（innovation）**——"测量里模型没预料到的部分"。$K_k$ 是**卡尔曼增益**，决定"信模型还是信测量"的分寸。<span class="marginnote">预测-更新结构与龙伯格观测器同源：观测器也是"模型预测 + 修正项"，只不过卡尔曼滤波把固定的 $L$ 换成了按协方差最优时变的 $K_k$，而且每一步都知道估计的置信度 $P$。从观测器到卡尔曼，只差"让增益最优"这一步，但这一步的工程价值是巨大的。</span>

## 3 公式解析：卡尔曼增益

$$K_k = P_{k|k-1} C^T \big( C P_{k|k-1} C^T + R_v \big)^{-1}$$

对它做四步拆解：

- **第一步，看分子的含义**：$P_{k|k-1}C^T$ 度量"预测不确定性经输出通道后的强度"——预测误差越大的方向，越需要测量来纠正。
- **第二步，看分母的含义**：$C P_{k|k-1}C^T$ 是预测误差映射到测量空间的协方差，加上 $R_v$ 就是"预测测量"与"实际测量"的不确定性之和。分母是"总不确定性"。
- **第三步，看比值**：$K_k$ = 预测不确定性与总不确定性之比，取值在 0 到 1 之间。$R_v$ 大（测量噪声大）→ $K_k$ 小 → 信模型、少信测量；$Q_w$ 大（过程噪声大）→ $P$ 大 → $K_k$ 大 → 信测量、多修正。**$K_k$ 就是"信度配比"的旋钮**。<span class="marginnote">极端情形：$R_v \to 0$ 时 $K_k \to 1$，完全相信测量（测量无噪声）；$Q_w \to 0$ 且初值精确时 $P \to 0$，$K_k \to 0$，几乎不用测量（模型完美）。卡尔曼滤波在这两个极端之间自动滑行。</span>
**第四步，看时变性**：$K_k$ 依赖 $P_{k|k-1}$，而 $P$ 每步都在更新——所以 $K_k$ **随时间变化**。若系统定常且滤波运行足够久，$P$ 收敛到常数，$K$ 也趋于常数——这就是"稳态卡尔曼滤波"，与龙伯格观测器的固定增益对上了。

## 4 卡尔曼滤波与观测器的对照

| 维度 | 龙伯格观测器 | 卡尔曼滤波 |
| --- | --- | --- |
| 噪声假设 | 忽略噪声 | 显式建模 $Q_w, R_v$ |
| 增益 | 常数 $L$（人为选极点） | 时变最优 $K_k$（由协方差算） |
| 最优性 | 无 | 最小方差最优（高斯下） |
| 额外产出 | 状态估计 $\hat{x}$ | 估计 + 置信度 $P$ |
| 使用场景 | 确定性系统 | 随机系统 |

卡尔曼滤波还直接导出**最优控制**的组合结论：若系统是 LQG（线性、二次、高斯），则"卡尔曼滤波 + LQR"按分离原理各自最优——**估计器最优、控制器最优，合起来仍最优**。这是分离原理在随机情形的延续。<span class="marginnote">LQG 分离定理是控制论里最优雅的结果之一：面对随机系统，你不用"边估计边控制"地耦合设计，放心地分别做卡尔曼滤波和 LQR 就行。1960 年代它让无数工程师敢于在实际系统里部署最优控制。</span>

## 5 工程变形与拓展

卡尔曼滤波家族庞大，工程选型要看噪声与模型的性质：

**扩展卡尔曼滤波（EKF）**：对非线性系统在每步做线性化，简单通用，是非线性滤波的工业标准起点。
**无迹卡尔曼滤波（UKF）**：用少量 sigma 点传播非线性，不做线性化，精度更高，适合强非线性。
**粒子滤波（PF）**：非高斯、非线性时用蒙特卡洛采样近似，计算量大但最灵活。<span class="marginnote">从 LQR 到卡尔曼到粒子滤波，是一条"假设越少、计算越贵"的谱线。工程铁律：能在高斯线性下用卡尔曼就别上粒子滤波——复杂度是最后的手段。</span>
**平滑（smoothing）**：用全部历史数据（含未来）估计过去的状态，比滤波更准，离线分析常用。

**辨析｜易错点：** 卡尔曼滤波的**发散问题**——当模型误差（$Q_w$ 给太小）或数值误差累积时，$P$ 变得过度自信，$K_k$ 趋零，估计不再跟随真实状态。对策是适当增大 $Q_w$、加噪声自适应、或周期性重置。**"滤波器过度相信自己"是工程上最常见的失败模式**。<span class="marginnote">数值稳健性也是现实问题：协方差 $P$ 需要保持对称正定，普通实现可能因舍入误差而变负定。工程上常用平方根滤波（Joseph 形式）等数值稳定算法——NASA 的阿波罗导航代码里就藏着这些细节。</span>

## 6 一维卡尔曼滤波数值实例

用最简单的一维问题看卡尔曼滤波如何工作。设匀速直线运动的位置估计：状态 $x = [d, v]^T$（位置、速度），但为看清机制，先看标量版——直接估计位置 $x$。

设对象 $x_{k+1} = x_k + w_k$（位置几乎不变，只有噪声），测量 $y_k = x_k + v_k$，$Q_w = 1$，$R_v = 2$，初值 $\hat x_0 = 0$，$P_0 = 1$。

**第一步，预测**：$\hat x_{1|0} = \hat x_0 = 0$，$P_{1|0} = P_0 + Q_w = 2$。

**第二步，算增益**：$K_1 = \frac{P_{1|0}}{P_{1|0} + R_v} = \frac{2}{2+2} = 0.5$——测量噪声比预测噪声大，增益取一半。

**第三步，更新**：设测得 $y_1 = 3$，则 $\hat x_{1|1} = 0 + 0.5(3 - 0) = 1.5$，$P_{1|1} = (1-0.5)\cdot2 = 1$。**估计值被测量拉向 3，但只拉了一半**。

**第四步，看稳态收敛**：继续递推，$K_k$ 逐渐趋近某个常数，$P_k$ 单调下降趋于稳定值——估计越来越有把握，增益越来越"谨慎"。若过程噪声大（$Q_w$ 大），$P$ 稳定值高、$K$ 保持较大，持续相信测量；若量测噪声大（$R_v$ 大），$K$ 变小，主要靠模型预测。<span class="marginnote">这个一维例子的每一步都能手算——初学者强烈建议亲手递推 5~6 步，你会直观地"看见"$K$ 如何在噪声统计之间自动平衡。理解了标量版，向量版只是把数换成矩阵。</span>

**辨析｜易错点：** 初始协方差 $P_0$ 选得离谱只会让前几步估计差，但卡尔曼滤波会**自动修正**（$P$ 快速收敛）——初值不必精确。真正危险的是 $Q_w$ 给太小：滤波变得过度自信，$K\to0$，之后测量再大也拉不动估计——这就是"滤波发散"的典型成因。

**卡尔曼滤波的信息形式**：工程上有时候关心"估计的精度"而非"估计本身"，此时用**信息滤波（information filter）**更方便——它以"信息矩阵 $P^{-1}$"与"信息向量 $P^{-1}\hat x$"为状态，预测/更新公式变成：

$$P^{-1}_{k|k} = P^{-1}_{k|k-1} + C^T R_v^{-1} C$$

信息滤波的妙处：**融合多个传感器只需把各自的 $C^T R^{-1} C$ 相加**——每来一个测量，就在信息矩阵上加一块。它特别适合"传感器数量可变、按需融合"的场景（如多雷达跟踪、分布式传感器网络）。<span class="marginnote">信息滤波与卡尔曼滤波互为对偶：一个算"估计 + 协方差"，一个算"信息 + 信息矩阵"。数值上信息滤波在"协方差很大/信息很少"时更稳定（不涉及求逆小量），这正是它在 GPS/惯性融合里受欢迎的原因。</span>

**辨析｜易错点：** 两种形式数学等价，但数值特性不同——协方差形式在"测量非常准"（$R_v\to0$）时可能病态，信息形式在"初始无信息"（$P\to\infty$）时更自然。工程选型按数值稳定性来，不必迷信某一种。

## 7 小结

- 随机系统模型：$x_{k+1}=Ax_k+Bu_k+w_k$、$y_k=Cx_k+v_k$，噪声协方差 $Q_w, R_v$。
- 卡尔曼滤波 = **预测（时间更新）+ 更新（量测更新）** 的两步递推。
- **卡尔曼增益** $K_k = P_{k|k-1}C^T(CP_{k|k-1}C^T+R_v)^{-1}$ 是"信模型 vs 信测量"的最优配比，随协方差时变。
- 新息 $y_k - C\hat{x}_{k|k-1}$ 是测量里模型没预料到的部分，驱动修正。
- 高斯下卡尔曼滤波最小方差最优；LQG 下与 LQR 分离成立。
- 拓展家族：EKF（非线性线性化）、UKF、粒子滤波；警惕滤波发散。

在下一节，我们把"随机"彻底纳入控制：当系统既有噪声、又有随机输入，最优控制该怎么做？——这就是**随机控制**。
