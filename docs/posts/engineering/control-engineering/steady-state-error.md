## 为什么从稳态误差开始

「稳、准、快」里，「准」对应的是**稳态精度**：系统稳定下来之后，输出离目标到底差多少。差得太多，系统再稳也没用——数控机床定位偏了 0.1 mm 就是废品，恒温箱温度差 2 ℃ 就酿事故。这一节研究稳态误差，并回答一个工程上极其实用的设计问题：**怎么让系统对某类输入做到零稳态误差？** 答案会落到「系统类型数」与「误差系数」这两个概念上，它们把「准」变成了可以设计的目标。<span class="marginnote">稳态误差与动态指标的分工：动态性能（超调、调节时间）回答「过渡过程好不好看」，稳态误差回答「最终停在哪」。两者互相制约——提高增益能减小稳态误差，却往往加剧振荡，这正是设计的张力所在。</span>

## 1 稳态误差的定义

系统的**偏差信号（误差）**为给定值与被控量之差：

$$e(t) = r(t) - c(t)$$

**稳态误差（steady-state error）**定义为误差信号在时间趋于无穷时的值：

$$e_{ss} = \lim_{t \to \infty} e(t)$$

稳态误差由两部分组成：**跟随稳态误差**（输入引起的）与**扰动稳态误差**（扰动引起的）。经典控制理论先研究前者，后者用叠加原理分别计算后相加。

计算稳态误差最常用的工具是**拉普拉斯变换的终值定理**：

$$e_{ss} = \lim_{t\to\infty} e(t) = \lim_{s \to 0} sE(s)$$

只要误差信号 $E(s)$ 的拉普拉斯变换已知，代 $s \to 0$ 乘 $s$ 就得到稳态误差，完全不用解微分方程。<span class="marginnote">终值定理的条件：$sE(s)$ 在 $s=0$ 处可解析（即系统稳定、且 $E(s)$ 不含有 $\lim$ 后仍振荡的项）。系统不稳定时终值定理会给出荒谬结果——所以<strong>先判稳定，再算误差</strong>，顺序不能乱。</span>

## 2 系统类型数：开环传函里积分器的个数

考虑单位反馈系统，开环传递函数写成标准因子形式：

$$G(s) = \frac{K\prod_{i}(T_i s + 1)}{s^\nu \prod_{j}(T_j s + 1)}$$

其中 $K$ 为**开环增益**，$\nu$ 是**开环传递函数中积分环节 $1/s$ 的个数**。$\nu$ 称为**系统类型数（system type）**：

- $\nu = 0$：**0 型系统**，无积分环节。
- $\nu = 1$：**I 型系统**，含一个积分环节。
- $\nu = 2$：**II 型系统**，含两个积分环节。

**系统类型数是决定稳态精度的关键参数**——它本质上告诉系统「能完全跟踪哪类输入」。$\nu$ 越大，能无差跟踪的输入阶数越高，但积分环节越多，稳定性越差。这是「准」与「稳」之间的又一个矛盾。

## 3 误差系数：静态位置、速度、加速度

定义三个**误差系数**，把稳态误差和输入幅值直接挂钩：

- **静态位置误差系数** $K_p = \lim_{s\to0} G(s)$
- **静态速度误差系数** $K_v = \lim_{s\to0} s\,G(s)$
- **静态加速度误差系数** $K_a = \lim_{s\to0} s^2 G(s)$

注意这里的「速度」「加速度」指**输入信号的类型**，不是系统的运动速度。名称来自所对应的输入：阶跃（位置）、斜坡（速度）、抛物线（加速度）。

三类典型输入下，稳态误差与系统类型、误差系数的关系表是本章的**核心结果**：

| 系统类型 | 阶跃输入 $r(t)=R_0$ | 斜坡输入 $r(t)=R_0 t$ | 抛物线 $r(t)=\frac12 R_0 t^2$ |
| --- | --- | --- | --- |
| 0 型 | $R_0/(1+K_p)$ | $\infty$ | $\infty$ |
| I 型 | $0$ | $R_0/K_v$ | $\infty$ |
| II 型 | $0$ | $0$ | $R_0/K_a$ |

**辨析｜易错点：** 表中规律是「差一个积分环节，就多消除一类输入的稳态误差」，但对应的误差系数是**有限值除以 $K$（而非无穷）**——I 型系统对斜坡输入的稳态误差 $R_0/K_v$ 是有限常数，只有靠提高开环增益 $K$ 才能减小它，而 II 型系统才能做到对斜坡完全无差。别把「类型数足够」误当成「增益无限大」——两者是不同层次的机制。<span class="marginnote">直观理解：积分器像"记忆"。系统含积分环节，才能"记住"并抵消常值输入造成的持续误差，从而对阶跃零误差；对斜坡，一个积分器只能抵消位置、抵消不了速度，所以留下与速度成正比、与增益成反比的残差。</span>

## 4 公式解析：用终值定理算稳态误差

以单位反馈、I 型系统、斜坡输入为例。设 $G(s) = K/[s(Ts+1)]$，$r(t) = R_0 t$，则 $R(s) = R_0/s^2$。单位反馈下：

$$E(s) = \frac{1}{1+G(s)} R(s) = \frac{R_0}{s^2}\cdot\frac{s(Ts+1)}{s(Ts+1)+K}$$

分三步拆解：

- **第一步，写误差传函**：单位反馈下 $E(s) = R(s)/(1+G(s))$。$1/(1+G)$ 是「从输入到误差」的传递函数，叫**误差传递函数**。
- **第二步，代入终值定理**：$e_{ss} = \lim_{s\to0} sE(s) = \lim_{s\to0} \frac{R_0}{s} \cdot \frac{s(Ts+1)}{s(Ts+1)+K} = \frac{R_0}{K}$。
- **第三步，对照误差系数**：$K_v = \lim_{s\to0} sG(s) = K$，于是 $e_{ss} = R_0/K_v$，与表格完全一致。这验证了误差系数方法只是终值定理的**包装**——会用终值定理，就掌握了根本。

**辨析｜易错点：** 若 $sE(s)$ 在 $s \to 0$ 时趋于无穷（如 0 型系统遇斜坡输入），终值定理给出的结果是 $\infty$，对应「误差发散、无法跟踪」。**求极限时不要先约分再代值，要先看有没有极点落在原点或右半平面**——稳定性条件必须先行满足。

## 5 扰动作用下的稳态误差

实际系统里扰动（负载变化、环境干扰）无处不在。用叠加原理：$c(t) = $ 输入单独作用 $+$ 扰动单独作用。扰动引起的稳态误差取决于**扰动作用点之前**的积分环节个数与增益。

结论很重要：**增加扰动作用点之前的积分环节或增大该处增益，能抑制扰动误差**；而在扰动作用点之后加积分环节，对扰动误差无能为力。这给工程师一个明确指引：积分环节要加在"扰动之前"——这也是工业过程控制里常在对象前串积分的原因。<span class="marginnote">这条结论来自误差传函的代数结构：扰动 $N(s)$ 到输出 $c_N(s)$ 的通道中，扰动点之前的环节出现在分母增益里。工程口诀：「抗扰动，把增益与积分加在扰动入口之前」。</span>

## 6 动态误差系数

静态误差系数只回答"稳态误差是多大"，而**动态误差系数（dynamic error coefficients）**能进一步刻画"误差随时间怎么变"。把误差的拉普拉斯变换展开：

$$E(s) = \frac{1}{1+G(s)}R(s)$$

把误差传递函数 $\Phi_e(s) = \frac{1}{1+G(s)}$ 在 $s=0$ 附近展开成泰勒级数：

$$\Phi_e(s) = C_0 + C_1 s + C_2 s^2 + \cdots$$

其中 $C_0, C_1, C_2, \dots$ 就是**动态误差系数**。则稳态误差的级数表示为：

$$e_{ss}(t) = C_0 r(t) + C_1 \dot{r}(t) + \frac{C_2}{2!}\ddot{r}(t) + \cdots$$

**对比静态系数**：静态系数只适用于阶跃/斜坡/抛物线三类典型输入；动态系数对**任意输入**都能给出稳态误差的级数逼近——输入是时间的任意函数时，误差由输入及其各阶导数的加权和表达。<span class="marginnote">直觉：动态误差系数把"稳态误差"从静态的"看输入类型"推广成动态的"看输入轨迹"。$C_0$ 对应位置误差、$C_1$ 对应速度误差、$C_2$ 对应加速度误差——与静态系数的三个名字一一对应，但适用范围更宽。</span>

**辨析｜易错点：** 泰勒展开在 $s=0$ 处要求误差传递函数解析——即系统稳定、且 $s=0$ 不是 $\Phi_e$ 的极点。这与终值定理的前提一致：**先判稳定，再谈任何误差系数**。工程上动态误差系数的价值在于：面对随时间任意变化的输入（如跟踪正弦、多项式组合），不必反复用终值定理，展开一次级数就能读出各阶误差。

**稳态误差与鲁棒性的权衡再强调**：追求零稳态误差的惯用手段是"提高系统类型（加积分）或增大增益"，但这两招都侵蚀稳定性裕度。工程上常见的破解是**折中分层**——反馈环保证稳定与基本精度，前馈或复合控制单独处理"对典型输入的无差跟踪"。这条"反馈管稳定、前馈管精度"的分工，正是《复合控制》一节的核心，也是所有高性能系统（伺服、制导、加工）的共同结构。

## 7 小结

- **稳态误差** $e_{ss} = \lim_{t\to\infty} e(t)$，由跟随与扰动两部分组成，可分别计算叠加。
- 计算工具是**终值定理** $e_{ss} = \lim_{s\to0} sE(s)$；**前提是系统稳定**。
- **系统类型数 $\nu$** 是开环传函中积分环节的个数，决定能无差跟踪哪类输入。
- 三类误差系数 $K_p, K_v, K_a$ 与系统类型、输入类型构成一张**稳态误差表**，是设计的查表工具。
- 抑制扰动误差要把**积分环节与增益加在扰动作用点之前**。

在下一节，我们换一副眼镜看同一个系统：不直接解响应，而是看闭环极点随**根轨迹**如何移动——那将是设计「稳而快」系统的第一把系统化工具。
