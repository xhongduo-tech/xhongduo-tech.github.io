## 为什么从数学模型开始

上一节我们学会了用「环」描述控制系统的结构，但还不会**计算**。工程上真正的问题「这个系统稳不稳？阶跃响应快不快？」必须建立在数量关系上：把物理系统的运动规律写成方程，再研究这个方程。这一节做两件事：一是从物理定律出发建立**微分方程**，二是引入控制理论最重要的工具——**传递函数**，它把复杂的微积分运算变成代数运算，是经典控制论一切分析方法的共同入口。前面在《复变函数与积分变换》里学的拉普拉斯变换，到这里才第一次找到它最重要的工程归宿。

## 1 什么是数学模型

**数学模型（mathematical model）**：描述系统内部各变量之间动态关系的数学表达式。控制系统的数学模型可以是微分方程、传递函数、频率特性、结构图、状态空间表达式等，它们描述同一个系统的不同侧面。

建立模型的两种基本方法：

- **机理分析法（解析法）**：从物理化学定律出发推导，例如牛顿第二定律 $F = ma$、基尔霍夫定律、能量守恒。优点是有物理意义，缺点是对复杂对象难以写出精确方程。
- **实验辨识法**：对系统施加已知测试信号，根据响应数据反推模型。适合机理不清的"黑箱"对象，工业过程常用。这一方法在本专题《控制系统工程实践》与《系统辨识》相关内容中展开。<span class="marginnote">现代工程常用「机理 + 辨识」混合：机理定结构、数据定参数。这在后续《智能控制》的神经网络建模里会更明显。</span>

**线性系统**指满足叠加性与齐次性（合称叠加原理）的系统，其微分方程是常系数线性微分方程。绝大多数控制理论工具（传递函数、频域法）只对线性系统严格适用，所以建模的一个重要环节是——**把非线性方程在小范围内线性化**。

## 2 建模实例：从物理定律到微分方程

看一个贯穿全教材的经典例子——**RC 电路**。电阻 $R$ 与电容 $C$ 串联，输入电压 $u_i(t)$，输出电压 $u_o(t)$（电容两端）。由基尔霍夫定律：

$$u_i(t) = R\,i(t) + u_o(t), \qquad i(t) = C\frac{\mathrm{d}u_o}{\mathrm{d}t}$$

消去中间变量 $i(t)$，得到输出电压与输入电压之间的微分方程：

$$RC\frac{\mathrm{d}u_o(t)}{\mathrm{d}t} + u_o(t) = u_i(t)$$

这是一个**一阶线性定常微分方程**。把它整理成标准形式：

$$T\dot{c}(t) + c(t) = r(t), \qquad T = RC$$

其中 $T$ 称为**时间常数（time constant）**，是刻画一阶系统动态特性的唯一参数，量纲为秒。$r(t)$ 是输入（给定），$c(t)$ 是输出（被控量）。<span class="marginnote">时间常数 $T$ 的物理意义：系统阶跃响应上升到稳态值的 63.2% 所需的时间。$T$ 越小响应越快，这正是下一节时域分析要展开的内容。</span>

再看机械系统。质量—弹簧—阻尼系统，$m$ 为质量，$k$ 为弹簧刚度，$f$ 为阻尼系数，外力 $F(t)$ 为输入，位移 $x(t)$ 为输出。由牛顿第二定律：

$$m\ddot{x}(t) + f\dot{x}(t) + kx(t) = F(t)$$

**电系统与机械系统写出的方程形式完全相同**——都是二阶线性微分方程。这就是控制理论最重要的方法论意义：**物理对象千差万别，数学模型统一处理**。一个方程可以描述电路、机械、热力、流体乃至经济系统，分析结论全部适用。

## 3 非线性系统的线性化

真实系统几乎都含非线性，例如饱和、死区、摩擦。处理思路是**小偏差线性化**：在工作点附近做泰勒展开，只保留一阶项。

设非线性函数 $y = f(x)$ 在平衡点 $x_0$ 附近，令 $\Delta x = x - x_0$：

$$y - y_0 \approx \left.\frac{\mathrm{d}f}{\mathrm{d}x}\right|_{x=x_0} (x - x_0)$$

**辨析｜易错点：** 线性化只在**工作点附近的小范围内**成立。工作点变了，线性化系数（导数）就变，模型也要重新建立。对本质强非线性（如继电特性、齿轮间隙）或者要求大范围工作的系统，不能用线性化，只能走非线性理论或智能控制的路子。<span class="marginnote">这也解释了为什么《智能控制》里的模糊控制、神经网络控制受欢迎：它们能直接处理无法线性化的非线性。经典线性理论管「局部」，智能方法试图管「全局」。</span>

## 4 传递函数

**传递函数（transfer function）**：在**零初始条件**下，线性定常系统输出量的拉普拉斯变换与输入量的拉普拉斯变换之比。

$$G(s) = \frac{C(s)}{R(s)} = \frac{\mathcal{L}[c(t)]}{\mathcal{L}[r(t)]}\bigg|_{\text{零初始条件}}$$

对一般形式的 $n$ 阶线性定常系统：

$$a_n c^{(n)} + a_{n-1} c^{(n-1)} + \cdots + a_0 c = b_m r^{(m)} + b_{m-1} r^{(m-1)} + \cdots + b_0 r$$

在零初始条件下取拉普拉斯变换，得：

$$G(s) = \frac{b_m s^m + b_{m-1} s^{m-1} + \cdots + b_0}{a_n s^n + a_{n-1} s^{n-1} + \cdots + a_0}$$

这就是控制理论的核心对象：**一个有理分式，分子分母都是 $s$ 的多项式**。微分方程里的求导变成乘以 $s$、积分变成除以 $s$，微积分问题转化为代数问题。上一节 RC 电路的传递函数是 $G(s) = 1/(Ts+1)$，典型一阶惯性环节；质量—弹簧—阻尼系统的传递函数是二阶振荡环节 $G(s) = 1/(ms^2 + fs + k)$。

传递函数的**性质**：

- 只由系统**结构与参数**决定，与输入信号无关——同一个系统，输入不同，$G(s)$ 不变。
- 与微分方程描述等价，但更便于级联（串联）、并联、反馈的连接运算。
- 它隐含了系统的全部零初始条件下的动态信息，包括稳定性。

## 5 公式解析：传递函数的定义式

$$G(s) = \frac{C(s)}{R(s)}$$

对它做三步拆解：

- **第一步，理解 $R(s)$ 与 $C(s)$**：它们是输入与输出的拉普拉斯变换，把时间函数映射到复频域。$s = \sigma + j\omega$ 是复变量，实部对应衰减/增长速率，虚部对应振荡频率。
- **第二步，理解「零初始条件」**：要求 $t=0$ 时系统所有状态及其各阶导数为零。这个约定把系统「自身的初始能量」排除在外，使 $G(s)$ 纯粹刻画系统的固有性质。如果初始条件不为零，输出还包含由初始条件引起的**零输入响应**，单独用 $G(s)$ 就不能完整描述。<span class="marginnote">「零初始条件」是经典控制与后续《现代控制理论》的一个重要分野：状态空间法不回避初始条件，直接把它纳入状态向量，从而能处理非零初值问题。</span>
- **第三步，看到 $G(s)$ 的运算意义**：给定输入 $R(s)$，输出 $C(s) = G(s)R(s)$——**输入在复频域被传递函数"整形"**。乘法在这里代替了卷积，这是拉普拉斯变换最漂亮的性质之一。

## 6 四种描述方式的关系

同一系统可以用不同数学对象描述，它们在本质上是等价的，只是"视图"不同：

| 描述方式 | 数学对象 | 优势 | 局限 |
| --- | --- | --- | --- |
| 微分方程 | 时域方程 | 物理意义直接 | 高阶难解 |
| 传递函数 | $G(s)$ 有理分式 | 代数运算、级联方便 | 仅线性定常、零初值 |
| 频率特性 | $G(j\omega)$ | 实验可测、图形设计 | 仅稳态正弦响应 |
| 状态空间 | $(A,B,C,D)$ | 多变量、非线性、可含初值 | 矩阵规模随阶数增长 |

**选择哪种描述，取决于你要回答什么问题**：要算时域响应，用微分方程或状态空间；要判稳定性与设计校正，用传递函数与频率特性；要处理多输入多输出，状态空间是唯一自然的选择。经典控制理论以传递函数为中心，现代控制理论以状态空间为中心——两者由 $G(s)=C(sI-A)^{-1}B+D$ 这座桥相连。<span class="marginnote">一座桥、两种世界观：经典控制看"外部行为"（输入输出），现代控制看"内部结构"（状态演化）。本专题第一篇用经典眼镜，第二篇换现代眼镜，第三篇加智能眼镜——三副眼镜看的是同一个物理世界。</span>

理解"同一系统、多副眼镜"，是控制理论最重要的元认知。后面每一章，你都会看到教科书反复在这几种描述之间切换——那不是混乱，而是"哪个视图最方便就用哪个"的工程智慧。

**建模中的仿真思维**：好的控制工程师建模型时心里始终装着"仿真"——这个模型最终要放进计算机做闭环仿真，所以它的形式要便于数值计算。微分方程要能写成状态空间或差分方程，传递函数要能做离散化，非线性要能选数值求解器。**"模型不是越复杂越好，而是越能用越好"**——能用它完成设计、仿真与验证，这个模型就是好模型。这条标准贯穿本专题从建模到工程实践的全部环节。

## 7 小结

- 数学模型是系统动态关系的数学表达，建立方法有**机理分析法**与**实验辨识法**。
- 典型对象的微分方程：RC 电路 $T\dot{c}+c=r$，质量—弹簧—阻尼 $m\ddot{x}+f\dot{x}+kx=F$——**不同物理本质、相同数学形式**。
- 非线性系统可在工作点附近**小偏差线性化**，但只在小范围成立。
- **传递函数** $G(s)=C(s)/R(s)$ 定义在零初始条件下，是有理分式，把微积分运算化为代数运算。
- 传递函数只取决于系统结构与参数，与输入无关。

在下一节，我们把这些方框与箭头画成图，学会在**结构图与信号流图**上进行化简——那将是一套不用解方程就能求系统闭环传递函数的技巧。
