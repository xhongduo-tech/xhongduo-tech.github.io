## 为什么从独立关节控制开始

上一课的动力学方程 $M(q)\ddot{q} + C\dot{q} + g = \tau$ 是**全耦合**的：一个关节加速，其它关节都会感受到力矩。理论上要把整串方程放在一起解，但工业机械臂却普遍采用一个更朴素的策略——**把每个关节当成独立的单轴伺服系统来调**，这就是独立关节控制（independent joint control）。

它之所以能行，是因为现实里的惯性矩阵 $M(q)$ 通常**对角线占优**：关节间耦合虽存在，却远小于本轴的惯性主导项。先把每个轴各自调稳，再靠重力补偿、前馈把耦合当扰动抵消，工程上即得到 99% 的满意性能。**理解独立关节控制，是理解后面一切高级非线性控制（计算力矩、自适应）的对照系**——那些方法要解决的，正是独立控制忽略掉的耦合问题。<span class="marginnote">控制理论里所谓「模型化误差与扰动」的鲁棒性问题，在机器人这里几乎天然存在：负载变化、摩擦、关节柔性都会让模型失准。独立关节控制就是「不指望精确模型、靠反馈把不确定压下去」的典型代表。</span>

**本课在专题里的位置**：它是从《轨迹规划》的"要动"到《非线性控制》的"如何严格地动"之间的过渡——先用工程最朴素的手段把单轴调稳，再在下一课正面面对"耦合与不确定性"。理解"独立控制为什么不总能行"，比理解"它怎么行"更能照亮后面的路。

## 1 从动力学方程到单关节模型

把耦合项当扰动 $\delta_i$，第 $i$ 个关节的方程简化为

$$J_{\mathrm{eff}} \, \ddot{q}_i + b\,\dot{q}_i + f_c\,\operatorname{sign}(\dot{q}_i) + g_i(q) = \tau_i$$

这里 $J_{\mathrm{eff}}$ 是折算到电机侧的等效惯量（含减速比放大效应），$b\dot{q}$ 是黏性摩擦，$f_c \operatorname{sign}(\dot{q})$ 是库仑摩擦（方向恒与速度相反，是静差的主要来源），$g_i$ 是重力。<span class="marginnote">减速器（如谐波减速器）把电机高速小扭矩变成低速大扭矩，折算到电机侧的等效惯量要乘减速比的平方：$J_{\mathrm{eff}} = J_m + J_L / N^2$。减速比是「惯量匹配」里的主角，选型不当会让动态性能大打折扣。</span>

**单关节模型里的三个"现实"修正**：一是重力项 $g_i(q)$ 随构型变化，低速爬行时尤其显著；二是库仑摩擦在换向瞬间突变，是低速抖动与静差的来源；三是等效惯量随负载变化——抓轻物与抓重物，$J_{\mathrm{eff}}$ 差出数倍，同一套增益的性能随之漂移。**独立控制的全部工程技巧，几乎都是在给这个单关节模型"打补丁"**。

对这样一个二阶系统，经典做法是**逐回路调节**：最内层电流环（力矩）最快，中间速度环，最外层位置环。每层一个 PID，频率依次拉开约 5–10 倍，避免环路间打架——这就是工业伺服「三环结构」的由来。

**补充：为什么要"三环"而不是"一个环"？** 因为物理上"位置→速度→电流"呈积分关系，分层闭环把每个环节的带宽瓶颈单独处理：电流环要快（几百 μs）才能扛住负载突变，速度环居中，位置环最慢（数十 ms）。若只留一个位置环，它同时要完成快（抗扰）与准（定位）两种职责，要么抖、要么慢。**带宽分层是工业伺服三十年的经验结晶**——它与软件分层、网络分层是同一工程哲学在控制领域的再现。

**三环带宽的典型量级**：电流环闭环带宽可达 1–3 kHz（几百 μs 一个周期），速度环 100–500 Hz（几 ms），位置环 10–50 Hz（数十 ms）——每一层比外一层快约一个数量级。这个"内快外慢"的次序不是偏好，而是稳定性要求：外环要把内环的闭环特性当作"被控对象"，内环必须快得让外环感觉不到它的动态。**带宽倒挂是级联设计的大忌**。

## 2 PD 控制与重力补偿

对位置控制，最简单有效的控制器是 **PD（比例–微分）**：

$$\tau = K_p(q_d - q) - K_d \dot{q}$$

其中 $q_d$ 是目标位置，$K_p$ 是比例增益（相当于把关节「拉」向目标的弹簧刚度），$K_d$ 是微分增益（阻尼，防止超调震荡）。把这个 $\tau$ 代入单关节模型，得到误差动力学

$$J_{\mathrm{eff}}\,\ddot{q} + (b + K_d)\dot{q} + K_p(q - q_d) = 0$$

这是一个典型的**弹簧–阻尼系统**：$K_p$ 定刚度、$K_d$ 定阻尼，两者比例决定系统是欠阻尼（震荡）、临界阻尼（最优）还是过阻尼（迟钝）。

但裸 PD 有一个明显缺陷：**重力让关节静止时也持续受力**，纯 PD 靠误差扛重力，会留下稳态静差。解决办法是在控制量里**前馈补偿重力**：

$$\tau = K_p(q_d - q) - K_d\dot{q} + g(q)$$

加一个 $g(q)$ 之后，静止平衡点 $q = q_d$ 处合力为零，静差被彻底消除——**「反馈 + 前馈」是机器人控制里最常用的一对搭配**，本课的重力补偿只是第一次出场。

**一个 PD 数字实例**：设 $J_{\mathrm{eff}} = 0.1$，取 $K_p = 10$、$K_d = 1$，则自然频率 $\omega_n = \sqrt{K_p/J} = 10$ rad/s、阻尼比 $\zeta = K_d/(2\sqrt{K_p J}) = 1/(2\sqrt{10\times0.1}) = 0.5$——轻微欠阻尼，阶跃会带一点超调；把 $K_d$ 提到约 $1.4$，$\zeta$ 升到 $0.7$，超调基本消失。**"先算 $\omega_n$ 与 $\zeta$，再谈手感"**，是整定的第一条纪律。

**重力补偿的代价值得注意**：$g(q)$ 必须随构型实时更新（每控制周期重算），它本身就是一条"模型依赖"的前馈——模型里重力项算错符号或忘了更新，控制器会"越调越歪"。这也埋下了下一课的主题：**前馈的质量取决于模型的准确度，模型不准时就要用自适应或鲁棒来救**。从重力补偿到计算力矩，其实是同一条"前馈"思想在纵深上的不断加码。

**速度前馈让跟踪更准**：位置环跟踪匀速轨迹时，纯 P 控制会留下与速度成正比的位置滞后。加一项**速度前馈** $\tau_{\mathrm{ff}} = K_{ff}\,\dot{q}_d$，让控制器"预判"期望速度，滞后可大幅减小。**前馈只改命令通道、不动反馈环**，稳定性不受影响——这是它比单纯加增益更安全的提速方式。

**前馈与反馈的分工一句话**：反馈负责"纠正已发生的偏差"，前馈负责"预防将要发生的偏差"。重力前馈防静差、速度前馈防滞后、耦合前馈防互扰——**每一个"已知的模型项"都值得尝试前馈**，剩下的交给反馈兜底。这套分工是控制工程里复用率最高的思想之一。

## 3 公式解析：$\tau = K_p(q_d - q) - K_d\dot{q} + g(q)$

把这条控制器拆成三步读：

- **第一步，读懂三项的角色**：$K_p(q_d - q)$ 是「弹性」——把关节当弹簧拉向目标，误差越大拉力越大；$K_d\dot{q}$ 是「阻尼」——速度越快刹车越猛，专治震荡；$g(q)$ 是「托底」——提前算好要扛多少重力，避免反馈硬扛。
- **第二步，读懂闭环方程**：代入 $M\ddot{q} + C\dot{q} + g = \tau$，若忽略 $C$ 并把 $g$ 抵消，得 $M\ddot{q} + K_d\dot{q} + K_p(q - q_d) = 0$——**动力学方程的 $M, C, g$ 三项，控制器每一项都有对应的「反击」**，这正是「前馈抵消 + 反馈镇定」的结构。
- **第三步，读懂稳定性来源**：取能量型函数 $V = \tfrac12 \dot{q}^\top M\dot{q} + \tfrac12 \tilde{q}^\top K_p \tilde{q}$（动能 + 势能），沿闭环求导得 $\dot{V} = -\dot{q}^\top K_d \dot{q} \le 0$——**系统能量只减不增**，这就是李雅普诺夫稳定性的第一次完整亮相。下一课《非线性控制》会把它系统化。

**增益取值的一个安全起点**：对单关节闭环 $\ddot{e} + k_d \dot{e} + k_p e = 0$，取 $k_p = \omega_n^2$、$k_d = 2\zeta\omega_n$，从阻尼比 $\zeta = 0.7$、自然频率取"结构第一谐振频率的 1/3–1/2"起步——**谐振是带宽的真实上限**，这正呼应《机械结构设计》里"结构刚度决定控制带宽"。理论给公式，机械给边界，现场给终值。

**闭环阶数与整定的关系**：二阶闭环只有两个可调参数（$K_p, K_d$），恰好对应"多快"与"多稳"两个目标；加积分项后变三参数。**参数个数 = 你能独立满足的性能指标个数**——想同时控好位置、速度、加速度，就得用更多自由度（下一课的计算力矩正是如此）。这是从"整定"走向"设计"的关键一步。

## 4 PID、饱和与抗饱和

加积分项后成为 **PID**：$\tau = K_p e - K_d\dot{q} + K_i \int e\,\mathrm{d}t$。积分项能消除库仑摩擦造成的静态误差，但引入一个臭名昭著的副作用——**积分饱和（integral windup）**。

**辨析｜易错点：积分饱和让大阶跃变成大超调。** 误差长期存在时，积分项不断累积到超过执行器极限；目标到达后，积分却还「欠着账」，导致大幅超调与来回震荡。工程对策是**抗饱和（anti-windup）**：积分项超过限幅就冻结累积，或把饱和量反馈回积分器。几乎所有工业驱动器的固件里都内嵌了这套逻辑——它太常见，又太容易被自学代码忽略。<span class="marginnote">执行器饱和（力矩上限）是控制里必须正视的约束。上一课动力学公式里的 $\tau$ 在物理上总有界；一旦控制器要求的力矩超出电机能力，系统就不再是线性的，稳定性结论随时失效。</span>

**一个抗饱和数字直觉**：设执行器力矩上限 $u_{\max} = 10$ N·m，位置误差持续 $1$ s 时积分项已累积到 $15$——超出限幅。若不抗饱和，误差回零后积分还要"还账"，超调随之而来。**把积分项限幅在 $[-u_{\max}, u_{\max}]$ 内、或让积分器只在未饱和时累积**，就能避免这笔"糊涂账"。工业驱动器里的 anti-windup 大多就是这两行逻辑的工程封装。

**积分何时该上、何时该撤**：积分项只在"消除静差"上有价值，而静差主要来自库仑摩擦与重力残留。于是有**积分分离（integral separation）**：误差大时禁用积分（避免饱和），误差小到阈值内再启用（消除静差）——"大误差靠 P、小误差靠 I"，是对"积分双刃剑"最直接的回应。

**一个整定数字实例**：设单关节 $J_{\mathrm{eff}} = 0.05\,\mathrm{kg\cdot m^2}$（已含减速比折算），想达到约 $0.7$ 的阻尼比、$10\,\mathrm{rad/s}$ 的自然频率。二阶闭环 $\ddot{q} + \frac{K_d}{J}\dot{q} + \frac{K_p}{J} q = 0$ 给出 $K_p = J\,\omega_n^2 = 0.05 \times 100 = 5$，$K_d = 2\zeta\omega_n J = 2 \times 0.7 \times 10 \times 0.05 = 0.7$。把这两个数代入控制器，系统应无超调地快速到位。现场要做的，就是在这个理论起点上**逐个加增益、观察阶跃响应**，直到性能与噪声的平衡点出现——理论与实验在这一刻握手。

## 5 工程现实：级联回路与摩擦补偿

真正的工业实现是**级联（cascade）三环**：最内层**电流环**（控制力矩/电流，响应最快，几百 μs–1ms），中间**速度环**（PD，几 ms），最外层**位置环**（输出速度指令，10ms 量级）。每层只跟自己的下一层要「指令」，层层跟踪，层层带宽错开。

摩擦则是个难缠的非线性：黏性摩擦相对好补，库仑摩擦的 $\operatorname{sign}(\dot{q})$ 在换向瞬间突变，会引起**爬行（stick-slip）**。工程师常在速度环里加摩擦前馈、在换向时做低速补偿，甚至用扰动观测器在线估计摩擦——这些技巧的共同目标只有一个：**让实际系统尽可能贴近上一课的那个理想二阶模型**。

**摩擦补偿的两个层次**：粗糙层是在控制量里直接加 $\tau_f = \hat{b}\dot{q} + \hat{f}_c\operatorname{sign}(\dot{q})$（用辨识出的摩擦参数前馈）；精细层是在换向瞬间做"爬行检测"——低速时库仑摩擦与静摩擦的切换会让末端一顿一顿，需要更精细的 Stribeck 模型或扰动观测器。**摩擦是独立关节控制里最"非线性"的一块**，也是从"能转"到"不爬行"的分水岭。

**当耦合不再"小"时怎么办**：机械臂负载大、速度快、臂展长时，关节间耦合（惯性矩阵非对角项）会明显削弱独立控制的性能——表现在"一个关节加速、另一关节跟着抖"。此时有三档升级路径：**第一档**，在控制量里加"耦合补偿前馈"（用动力学模型预补偿）；**第二档**，把耦合当扰动，用扰动观测器在线估计并抵消（见本节 DOB 注）；**第三档**，放弃"独立"假设，直接上下一课的计算力矩法。**独立控制不是终点，而是一个"何时该升级"的哨兵**——读懂它的性能边界，就掌握了升级的时机。<span class="marginnote">把摩擦、耦合、负载变化统一当成「未知扰动」来估计与抵消，就是扰动观测器（DOB）与自抗扰控制（ADRC）的思路——它和大模型里「残差学习」的理念同构：模型能预测的交给模型，模型预测不了的交给在线修正。</span>

**耦合补偿前馈的公式形态**：若动力学模型已知，可在独立控制之上叠加一个"期望加速度 → 力矩"的预补偿项：$\tau = \tau_{\text{ind}}(q,\dot{q},q_d) + \hat{C}(q,\dot{q})\dot{q} + \hat{g}(q)$，其中后两项把耦合与重力"提前抵消"。这比纯独立控制多花一次模型计算，却把"一个关节动、另一个抖"的根源压掉大半——**它是计算力矩法在"模型不完全可信"前提下的务实折中**。

## 6 伺服整定：从理论增益到现场调参

控制理论给的是框架，工程现场靠的是**整定（tuning）**——把 $K_p, K_d$ 从"能转"调到"又稳又快"。

**速度估计的取舍**：微分项 $K_d\dot{q}$ 需要的 $\dot{q}$ 通常来自编码器位置差分。差分在低速时放大量化噪声——速度环因此常用专门的**测速编码器或观测器**估计速度，而不是裸差分。<span class="marginnote">"对位置差分求速度"噪声大、"对加速度积分求速度"会漂移——工程里用观测器（如龙伯格观测器）把两者最优融合，这是状态估计里最经典的问题，与《机器人动力学》参数辨识、以及大模型里的 Kalman/滤波类算法一脉相承。</span>
- **逐环整定的顺序**：先电流环（调 PI，带宽最高）→ 再速度环（调 PI，阻尼优先）→ 最后位置环（调 P，增益逐步加直到轻微震荡再回落）。**从内向外，每层先保证自身稳，再放下一层**，这是工业伺服整定三十年不变的铁律。
- **阻尼比的经验锚点**：单关节闭环是二阶系统，理论最优是阻尼比 $\zeta \approx 0.7$（超调小、上升快）；现场常从"无超调"开始往上调增益，直到出现可接受的微小超调为止——**理论给出起点，实验给出终值**。
- **负载观测与在线补偿**：抓取重量变化时，$J_{\mathrm{eff}}$ 与重力项都漂移。渐进做法：先用扰动观测器在线估计"模型外的一切"（负载、摩擦、耦合残留），再当附加前馈加回去——比直接上自适应简单、收敛快。**"把不知道的都当作扰动去估"是从独立控制走向非线性控制的过渡桥梁**，下一课《非线性控制》给出严格版本。
- **负载变化的补偿**：机械臂末端抓的工件重量变了，$J_{\mathrm{eff}}$ 就变了，同一套增益的性能随之漂移。粗调靠**鲁棒性**（把增益选在性能余量内），精调靠**在线辨识/自适应**——这正是下一课《非线性控制》出场的地方。

**辨析｜易错点：增益不是越大越好。** $K_p$ 加大会让系统更快，但也会放大测量噪声、激发结构谐振（还记得《机械结构设计》说的"结构刚度限制带宽"吗？）——增益的上限往往不是稳定性，而是**机械与噪声的忍受极限**。整定到"参数表好看"容易，整定到"产线不抖"才是本事。

**整定的"最后一公里"**：现场调参后还必须验证三类行为——**阶跃响应**（看超调与调节时间）、**斜坡跟踪**（看匀速段误差）、**正弦跟踪**（看带宽与相位滞后）。一台机器人要同时在这三种激励下表现合格，才算整定完成。而真正高产的产线还会监控**跟随误差的统计分布**：误差均值异常 = 重力/摩擦补偿失准，误差方差异常 = 增益过高或传感器噪声。**整定不是一次动作，而是一套"看响应、改增益、再验证"的闭环方法论**——它和本专题其它所有环节一样，本质上是反馈。

**辨析｜易错点：微分项会"踢"系统——derivative kick。** 当目标位置 $q_d$ 阶跃变化时，误差 $e = q_d - q$ 瞬间跳变，微分项 $K_d \dot{e}$ 在这一刻冲到极大，像"踢"了系统一脚。工程对策：只对测量值求导（不取误差的导数）、或用**设定值加权（set-point weighting）** 让目标变化不直接进入微分通道。这类"细节毁掉整套整定"的问题，是 PID 经典文献里最常被重新发现的坑。

**整定结果的三件套文档**：把"增益值、阻尼比目标、实测阶跃指标"记成表格随机器人出厂——产线维护、负载变更、故障诊断都靠这张表说话。**整定结果不落地成文档，等于没整定**；这是工程上最便宜却最常被省略的步骤。

## 7 小结

- 独立关节控制：把耦合当扰动，**每个关节按单轴伺服单独调**；工业实现为「电流–速度–位置」三环级联。
- 单关节模型含等效惯量、黏性摩擦、库仑摩擦与重力，减速比对等效惯量有平方放大。
- PD 控制构成弹簧–阻尼闭环；**加重力前馈 $g(q)$ 可消除静差**。
- 控制器每一项对应动力学方程一项：**前馈抵消 + 反馈镇定**；能量函数沿闭环只减不增 = 李雅普诺夫思想初见。
- PID 的积分项消除静差但会**积分饱和**，必须配抗饱和；误差大时还可**积分分离**。
- 三环带宽按"内快外慢"排列（电流 > 速度 > 位置），**带宽倒挂是级联设计大忌**。
- 前馈（重力、速度、耦合）只改命令通道、不动反馈环，是比加增益更安全的提速手段；微分项要防 **derivative kick**。

在下一节，我们把「当耦合和不确定性不可忽略时」的情况摊开——**非线性控制：计算力矩、李雅普诺夫与自适应**。
