## 为什么从轨迹规划开始

运动学告诉你末端能去哪，动力学告诉你它怎么受力，但工程师真正面对的问题是：**给定起点和终点，末端应该沿什么路径、以什么速度、在什么时刻经过**——这就是轨迹规划（trajectory planning）。它处在「几何」与「控制」之间：规划器输出一条随时间变化的位置曲线，控制器负责把机器人「按上去」。

轨迹规划几乎决定了机器人给人的第一观感：抖不抖、快不快、稳不稳。它还直接与前面各课挂钩——**轨迹必须避开奇异位形（雅可比降秩处）、速度必须被动力学约束（电机力矩上限）**，否则再好的控制器也救不回来。<span class="marginnote">现代机器人学习（如模仿学习、强化学习）常把「规划 + 控制」合并成一个端到端策略，但工业与学术界评测的基线，仍几乎总是「规划出的轨迹 + 跟踪控制器」这套经典分层结构。</span>

## 1 路径与轨迹：两个常被混为一谈的词

**路径（path）**：空间中的一条几何曲线，回答「走哪条线」，没有时间信息。**轨迹（trajectory）**：路径 + 时间标定，回答「每时每刻在哪、速度多少」。一条路径配上不同的时间标定，就是不同的轨迹——同样的「画个圆」，可以 2 秒画完也可以 20 秒画完。

规划的坐标系有两种选择：

**关节空间规划**：对每个关节的 $q_i(t)$ 独立规划。简单、可重复性好、易于满足关节限位；但末端路径不直观（直线运动未必是直线）。
- **笛卡尔空间规划**：直接对末端位姿 $X(t)$ 规划（如直线、圆弧插补）。路径直观，但需逐点求逆解，且可能穿过奇异位形，还要应对多解不连续。

工业机器人常用「笛卡尔规划 + 关节空间平滑过渡」的混合策略。<span class="marginnote">「示教轨迹」本质就是工程师手动把关键点（via point）和运行速度记录下来，再由规划器在点之间插值——示教编程与自动规划共用同一套插值引擎，见本专题《机器人编程与离线编程》一课。</span>

**如何选择规划坐标系？一条经验法则**：任务本身"在空间里是一条直线"（如点胶、焊缝、切割）就选笛卡尔规划——末端走线形漂亮、工艺参数可控；任务只是"从 A 抓到 B"（搬运、码垛）就选关节规划——简单、快、省得在奇异附近冒险。**关键是先问"末端路径是否被工艺约束"，再决定坐标系**，而不是一上来就用"看起来更高级"的笛卡尔。

## 2 三次与五次多项式：用多项式拼出平滑运动

最简单的思路：给定起止角度 $q_0, q_f$ 与起止时间 $0, t_f$，用三次多项式

$$q(t) = a_0 + a_1 t + a_2 t^2 + a_3 t^3$$

满足四个边界条件 $q(0), q(t_f), \dot{q}(0), \dot{q}(t_f)$。四个条件定四个系数，恰好可解。这种轨迹位置与速度连续，但**加速度在端点处跳变**——会让机械臂在起止瞬间受到冲击（jerk 无穷大）。

升级到**五次多项式**，多出两个自由度，可以同时约束加速度边界 $\ddot{q}(0) = \ddot{q}(t_f) = 0$，得到全程 $C^2$ 连续（位置、速度、加速度均连续）的平滑轨迹。**判断轨迹好坏的第一指标就是「加速度是否连续、有无突变」**——冲击是机械磨损与振动的主要来源。

**系数为什么是 6 个**：三次多项式 4 个系数配 4 个边界条件（位置 ×2 + 速度 ×2）；五次多项式 6 个系数配 6 个条件（位置 + 速度 + 加速度各 ×2）。**边界条件数 = 系数个数**，方程才恰好可解——"想约束什么，就要提升多项式阶数"这条配平关系，是轨迹设计里的第一口诀。若还想约束 jerk，就需要七次多项式，依此类推。

**一个五次多项式的直观验证**：设 $q_0 = 0$、$q_f = \pi/2$（约 $1.57\,\mathrm{rad}$）、$t_f = 1\,\mathrm{s}$，起止速度与加速度都为零。解出的系数满足 $a_0 = 0,\ a_1 = 0,\ a_2 = 0,\ a_3 = 10q_f,\ a_4 = -15q_f,\ a_5 = 6q_f$（五段系数的标准解），代入即得一条**速度、加速度两端均为零**的 $S$ 形位置曲线。相比三次多项式在两端"速度从 0 立刻跳成某个值"，五次多项式的每一阶导数都平滑过渡——这正是高精度运动（半导体搬运、精密装配）几乎只用五次以上的原因。

## 3 梯形速度剖面：工程上最常用的时间最优解

如果要求在力矩限制内尽快到达，一个朴素而经典的选择是**梯形速度剖面（trapezoidal velocity profile / LSPB）**：先匀加速到最大速度，匀速保持，再匀减速到零，如图。

![梯形速度轨迹（LSPB）与位置曲线](/images/robotics-engineering/trajectory-planning-1.svg)

三段的时间可由运动学公式直接解出：设加速度上限 $a_{\max}$，位移 $D = q_f - q_0$，则加速段时间 $t_a = v_{\max}/a_{\max}$，匀速段时间 $t_c = D/v_{\max} - t_a$（$t_c$ 需非负，否则 $v_{\max}$ 应下调为 $\sqrt{D a_{\max}}$）。

**辨析｜易错点：梯形剖面的加速度是「分段常数」，端点会跳变。** 当加速度从 $a_{\max}$ 瞬间降到 0（进入匀速段）、再从 0 跳变到 $-a_{\max}$，加速度不连续会带来冲击。工程上常用 **S 形速度剖面（S-curve，jerk 受限）** 把速度剖面「圆角化」，用多一段 jerk 约束换取全程加速度连续——代价是时间略长、规划略复杂。

**为什么"加速度连续"还不够，还要管 jerk？** 加速度 $a(t)$ 连续保证了力不突变，但力的变化率（jerk）过大，同样会激起机械谐振与末端振荡。S 曲线把速度剖面从梯形变成"五次平滑"，正是把 jerk 从无穷大压到有界。**一条严格的好轨迹，位置、速度、加速度、甚至 jerk 都要连续**——这在精密涂胶、光学对准这类"抖一下就废"的工艺里是硬指标，也是本课从三次多项式一路升级到 LSPB、再到 S 曲线的完整动机链。<span class="marginnote">jerk 是加速度对时间的导数。人体在电梯里感到的「顿挫」来自加速度突变；机器人上同样的道理，冲击大则振动、磨损、噪声都上升。S 曲线在半导体搬运等高精度场景是标配。</span>

## 4 公式解析：LSPB 的位置曲线

LSPB 的位置曲线 $q(t)$ 由三段拼接（抛物线—直线—抛物线，parabolic blend），其时间对称的解析式如下：

$$
q(t) = \begin{cases} q_0 + \frac{a_{\max}}{2}t^2, & 0 \le t \le t_a \\[2mm] \dfrac{q_0+q_f}{2} + \dfrac{v_{\max}}{2}(2t - t_f), & t_a < t < t_f - t_a \\[2mm] q_f - \frac{a_{\max}}{2}(t_f - t)^2, & t_f - t_a \le t \le t_f \end{cases}
$$

三步拆解这条分段函数：

- **第一步，看加速段**：$q_0 + \frac{a_{\max}}{2}t^2$ 就是匀加速运动公式 $s = \tfrac12 a t^2$——加速度恒定，位置是时间的抛物线。
- **第二步，看匀速段**：$\frac{q_0+q_f}{2} + \frac{v_{\max}}{2}(2t - t_f)$：中点的 $\tfrac12(q_0+q_f)$ 是整段位移的一半（对称剖面的中点恰在时间中点），第二项以 $v_{\max}$ 线性推进——位置直线上升，斜率即速度。
- **第三步，看出对称性**：减速段是加速段关于中点 $t = t_f/2$ 的镜像，用 $t_f - t$ 代换 $t$ 即可得到。**整条曲线关于「时间中点 + 位移中点」对称**，这是 LSPB 最简单也最优雅的性质。

## 5 经由点与时间标定

真实任务很少是「点到点」，而是「依次经过一串点位」。**经由点（via point）** 之间逐一用多项式/梯形剖面拼接，并在点附近留出过渡带（如圆弧过渡），避免速度降为零的停顿。

时间标定（time scaling）则是「先定路径、再定速度」的两步法：先在笛卡尔空间定出路径弧长参数 $s$，再对 $s$ 做时间规划。这个方法让「避开障碍的路径」与「满足动力学约束的速度」**解耦**，是轨迹规划领域被反复使用的标准技巧。<span class="marginnote">「路径与速度解耦」的思想也体现在大模型机器人的动作生成里：先规划「往哪走」（空间），再决定「多快走」（时间）。两层分离，每一层都能单独评测与改进。</span>

**时间标定的公式形态**：把路径写成弧长参数 $p(s)$，弧长 $s(t)$ 的动力学受"电机力矩折算到切向"的约束，即 $\dot{s}\ddot{s} \le a_{\max}(s)$。在这个约束下求"最短时间"的 $s(t)$，就是**时间最优轨迹规划（time-optimal trajectory planning）**：沿路径加速到边界、贴着边界跑、再减速。它与第 6 节 LSPB 数字例子的关系是"特例与通式"——LSPB 是匀速+匀加减的简化版，时间最优才是这台优化机器的完全体。

## 6 一个数字实例：算一节拍

把公式用具体数字走一遍，LSPB 就不再抽象。设末端要从位移 $D = 0.5\,\mathrm{m}$ 处出发到 $0$（反向亦可，取 $D=0.5$），速度上限 $v_{\max} = 0.4\,\mathrm{m/s}$，加速度上限 $a_{\max} = 2\,\mathrm{m/s^2}$。

加速段时间 $t_a = v_{\max}/a_{\max} = 0.4/2 = 0.2\,\mathrm{s}$。
- 加速段位移 $D_a = \tfrac12 a_{\max} t_a^2 = \tfrac12 \times 2 \times 0.04 = 0.04\,\mathrm{m}$；减速段对称，同样 $0.04\,\mathrm{m}$。
- 匀速段位移 $D_c = D - 2D_a = 0.5 - 0.08 = 0.42\,\mathrm{m}$，耗时 $t_c = D_c / v_{\max} = 0.42/0.4 = 1.05\,\mathrm{s}$。
- 总时间 $t_f = 2 t_a + t_c = 0.4 + 1.05 = 1.45\,\mathrm{s}$。

**辨析｜易错点：先检查匀速段是否非负。** 若位移很小，比如 $D = 0.05\,\mathrm{m}$，则 $D_c = 0.05 - 0.08 < 0$——机器人根本来不及加速到 $v_{\max}$ 就得刹车。此时必须**降速**：令 $t_c = 0$，由 $D = a_{\max} t_a^2$ 反解 $v_{\max}' = \sqrt{D a_{\max}} = \sqrt{0.05 \times 2} = 0.316\,\mathrm{m/s}$。**"最大速度不可达"是轨迹规划里最高频的工程失误**——产线上的节拍估算错，一半源于这里。<span class="marginnote">这个"够不着就降速"的判断，是时间最优轨迹（time-optimal trajectory）的最朴素形态：沿路径扫一遍，看哪些段受加速度限制、哪些段受速度限制，再统一折中。更严格的处理是"时间标定（time scaling）+ 路径参数化"的优化，见第 5 节。</span>

把节拍算准，是规划层对产线最直接的贡献：一个 10s 的循环缩短到 9s，就是 11% 的产能提升。**规划不只是"让机器人动起来"，更是"让它在约束内最快地动"**——本课 LSPB 与 S 曲线，就是这条优化之路的第一步。

## 7 小结

- **路径** = 空间曲线；**轨迹** = 路径 + 时间标定，规划器的输出是后者。
- 关节空间规划简单直观，笛卡尔空间规划路径可控但需处理奇异与多解。
- 三次多项式只有 $C^1$ 连续（加速度跳变）；**五次多项式可同时约束加速度边界**，实现 $C^2$ 连续。
- **LSPB（梯形速度剖面）**：匀加速—匀速—匀减速三段拼接，位置曲线为抛物线—直线—抛物线，关于时间中点对称；加速度在分段点跳变，需 S 曲线改良。
- 经由点之间拼接 + 圆弧过渡，路径与时间标定解耦是通用框架。
