## 为什么从掺杂开始

在《半导体器件物理》里我们反复强调：**PN 结靠掺杂来制造**，晶体管的源、漏、阱、沟道都由掺杂浓度与分布决定。硅片本体是一块浓度均匀的轻掺杂衬底，要让不同区域变成 p 型或 n 型、浓一点或淡一点，就必须把硼、磷、砷等杂质**精确地、按设计的位置与深度**送进硅里——这就是**掺杂（doping）**。<span class="marginnote">掺杂是「在硅里写浓度分布」的艺术：结深、峰值浓度、浓度梯度共同决定器件性能。一个 LDD（轻掺杂漏）结构、一个陡峭的源漏结，全靠掺杂工艺「一笔一画」写出来。可以说，器件物理定义的参数，最终都由掺杂工艺落地。</span>本篇讲掺杂的两大主力——热扩散与离子注入，以及让杂质真正「上岗」的退火。

## 1 热扩散：把杂质「蒸」进硅里

**热扩散（thermal diffusion）** 是最古老的掺杂方式：把晶圆放在含掺杂剂气体的高温炉中，杂质原子从表面向硅内部扩散。过程常分两步：**预淀积（predeposition）** 在恒定表面浓度下让杂质进入表面层，再**推进（drive-in）** 在不含杂质源的高温下让已进入的杂质向深处扩散，形成所需的结深与分布。用气源时（如 $\ce{BCl3}$、$\ce{PH3}$），扩散由表面浓度固定；用预淀积的氧化物薄膜作源（如掺硼的 $\ce{B2O3}$），则浓度可控性更好。<span class="marginnote">扩散掺杂的优势是设备简单、成本低、可同时处理大量晶圆；致命弱点是「只能在高温下进行」，且<strong>各向同性</strong>——杂质向四周均匀扩散，无法形成陡峭的浅结。当器件缩小到亚微米以下，扩散的短板就不可接受了，离子注入取而代之。</span>扩散分布遵循费克定律，常近似为互补误差函数（恒定源）或高斯分布（有限源）。

## 2 离子注入：用加速器「打」进去

**离子注入（ion implantation）** 是当前掺杂的绝对主流。原理是把杂质原子电离成离子，用加速器加到数十至数百 keV 的能量，像炮弹一样射入硅片。两个参数决定结果：

- **能量**决定注入深度（射程）：能量越高，离子射得越深；
- **剂量（dose）** 决定浓度总量：剂量即单位面积注入的离子数，可通过束流电流与时间精确控制。

与热扩散相比，离子注入的优点是革命性的：**低温进行**（不破坏已有结构）、**注入位置与剂量可精确控制**（通过掩模与束流）、**可注入扩散法无法实现的杂质组合**、且能穿过很薄的掩蔽层实现三维分布控制。它的缺点也明显：注入过程会**破坏晶格**、造成大量间隙原子与空位，且离子在晶格中的散射使分布呈高斯状而非理想的陡峭分布。

**核心概念：射程（projected range, $R_p$）**：离子注入后平均到达的深度。实际分布以 $R_p$ 为中心、以射程离散 $\Delta R_p$ 为标准差展开，近似高斯分布。

### 离子注入机的基本结构

| 部件 | 作用 |
| --- | --- |
| 离子源 | 把杂质原子电离成离子 |
| 质量分析磁铁 | 按质荷比挑出目标离子 |
| 加速管 | 设定离子能量 |
| 束流扫描/平行化 | 均匀覆盖晶圆 |
| 剂量控制 | 精确计量注入剂量 |
| 静电吸盘 | 固定晶圆、控制温度 |

## 3 沟道效应与损伤

注入有个著名的「坑」——**沟道效应（channeling）**：离子若恰好沿硅晶格的主轴方向（如 <100> 方向）入射，会在原子列之间的「沟道」里被引导着长距离穿行，实际深度远大于理论射程，浓度分布拖出一条长尾巴。工程对策包括**倾斜注入**（晶圆法向相对束流倾转 7° 左右）与**预非晶化注入**（先用硅或锗离子打乱表面晶格，再注入掺杂离子）。

注入损伤则表现为晶格中的**点缺陷**：间隙原子与空位对。这些缺陷若不清除，杂质原子大多处于间隙位、电学上不激活，器件根本无法工作——于是必须退火。

**辨析｜易错点：** 「剂量」与「浓度」不是一回事。剂量 $Q$ 是**单位面积注入的离子数**（个/cm²），是注入机的设定量；浓度 $N$ 是**单位体积的杂质数**（个/cm³），是剂量在分布曲线上摊开后的结果。同样的剂量，注入得越浅、分布越窄，峰值浓度越高。两者一换就算错，是掺杂领域最常见的概念混淆。

## 4 退火：让杂质「上岗」

**退火（anneal）** 是把注入后的晶圆加热，达到两个目的：**修复晶格损伤**（让间隙原子与空位复合）与**激活杂质**（让杂质从间隙位落入替位位，贡献载流子）。经典方式是在炉管中 900–1000 °C 长时间退火；但长时间高温会**加剧扩散**，把好不容易做陡的结「糊」掉。

于是**快速热退火（RTA）** 成为标准：单片晶圆在数秒内升到 1000 °C 以上、保温数秒即冷却。快升快降让「激活」发生而「扩散」来不及累积，从而获得**高激活率 + 低扩散**的浅结——这正是先进节点维持结陡峭性的关键。<span class="marginnote">RTA 的精髓是「热预算（thermal budget）」管理：器件的每个结构都有各自能承受的累计高温时间，工艺设计必须像预算一样精打细算。退火时间每长一点、温度每高一点，都可能在别处付出代价——这正是《CMOS 工艺集成》里反复权衡的主题。</span>

### 热扩散与离子注入对照

| 维度 | 热扩散 | 离子注入 |
| --- | --- | --- |
| 温度 | 高温（900–1100 °C） | 可低温（室温-低温） |
| 方向性 | 各向同性 | 可编程、受掩模控制 |
| 剂量精度 | 差 | 精确（束流计量） |
| 深度控制 | 浅结难 | 能量控制射程 |
| 晶格损伤 | 无 | 有（需退火） |
| 应用 | 深结、简单结构 | 先进节点主力 |

## 5 公式解析：注入后的高斯分布

离子注入后的纵向浓度分布常用**高斯近似**描述：

$$N(x) = N_p\, e^{-(x - R_p)^2 / 2 \Delta R_p^2}$$

- $N(x)$：深度 $x$ 处的杂质浓度；
- $R_p$：投影射程（峰值浓度所在深度）；
- $\Delta R_p$：射程离散（分布的标准差）；
- $N_p$：峰值浓度，即 $x = R_p$ 处的浓度。

剂量 $Q$（单位面积注入的离子数）与分布的关系是分布曲线下的面积：

$$Q = \int_0^\infty N(x)\, dx = \sqrt{2\pi}\, \Delta R_p\, N_p$$

**第一步，看形状**：注入分布是「以 $R_p$ 为中心的钟形」，$\Delta R_p$ 决定分布的宽窄——能量越高，$R_p$ 越深、$\Delta R_p$ 越宽，分布越「摊开」。
**第二步，看剂量**：$Q$ 是束流电流与时间的乘积，由离子注入机直接设定；而峰值浓度 $N_p = Q/(\sqrt{2\pi}\,\Delta R_p)$——剂量越大、分布越窄，峰值越高。
**第三步，落回器件**：**结深**由 $R_p + \text{若干}\Delta R_p$ 决定，**源漏电阻**由积分剂量决定，**阈值电压**由沟道下方的净掺杂决定——三个器件参数，三条从这条高斯分布「读出」的工程量。这正是离子注入取代热扩散的定量理由：分布的形状与剂量都能被独立、精确地编程。

**算一个数字**：设注入剂量 $Q = 1\times 10^{15}\ \mathrm{cm^{-2}}$、射程离散 $\Delta R_p = 30\ \mathrm{nm} = 3\times 10^{-6}\ \mathrm{cm}$，则峰值浓度 $N_p = Q/(\sqrt{2\pi}\,\Delta R_p) = 10^{15}/(2.51 \times 3\times 10^{-6}) \approx 1.3\times 10^{20}\ \mathrm{cm^{-3}}$——这是典型源漏重掺杂的水平。而若把剂量降到 $10^{12}\ \mathrm{cm^{-2}}$（轻掺杂），峰值浓度降到约 $10^{17}\ \mathrm{cm^{-3}}$，正好是 LDD 或阈值调整注入的量级。一个量级的剂量差，换来三个量级的浓度差——这就是「注入靠剂量编程」的直观写照。

### 5.1 LDD 与源漏工程：掺杂的器件舞台

掺杂在 MOSFET 中最典型的应用是**源漏工程**，它决定器件能否在缩小后仍可靠工作：

**LDD（轻掺杂漏）**：先在栅极侧壁形成前先做一次轻掺杂注入（LDD），再淀积侧壁间隔层、做重掺杂源漏注入。LDD 让沟道边缘的电场梯度变缓，抑制**热载流子效应**——高能载流子不再把电子注入栅氧、不造成阈值漂移。没有 LDD，短沟道器件的可靠性会急剧恶化。
**源漏重掺杂**：透过侧壁间隔层做高剂量注入，形成低电阻的源漏区，与后续的**硅化物（silicide）** 工艺共同把接触电阻压到最低。<span class="marginnote">源漏工程是「掺杂 + 间隔层 + 硅化」的组合拳：LDD 管可靠性、重掺杂管电阻、硅化物管接触。三种手段的剂量、结深、材料在工艺集成里被反复权衡——这也是为什么我们把《CMOS 工艺集成》放在后面：它要把这些细节串成完整流程。</span>

### 5.2 掺杂工艺的失效模式

掺杂出问题，常见有几种：

**剂量漂移**：注入机束流不稳导致剂量偏差，直接改变源漏电阻与阈值——因此注入机要定期做**剂量监控**（四探针测片）。
**结深失控**：退火温度/时间超预算导致结过深、短沟道效应加剧。
**沟道效应残留**：注入角度不准时，掺杂分布拖尾变长，阈值异常。
**污染**：注入机真空与材料引入金属污染，扩散进有源区造成漏电。

这些失效大多能被量测捕捉（四探针测方阻、二次离子质谱测深度分布）——掺杂的可测量性，是它作为「精细工艺」的前提。

## 6 小结

- 掺杂把「p 型 / n 型 / 浓淡」写进硅片，是器件物理落地为工艺的核心步骤。
- **热扩散**高温、各向同性、成本低，靠费克定律描述，适合深结与简单结构；**离子注入**低温、可编程、精确，是先进节点主力。
- 注入面临**沟道效应**（沿晶轴钻得太深）与**晶格损伤**，分别用倾角注入/预非晶化与退火应对。
- **退火**修复损伤并激活杂质；**RTA** 以「快升快降」实现高激活率 + 低扩散的浅结。
- **剂量**（个/cm²）与**浓度**（个/cm³）是两个概念，注入的「剂量编程」决定了分布的「浓度落地」。
- **LDD + 重掺杂 + 硅化**是源漏工程的标准组合；注入机需靠剂量监控与深度量测保证精度。

- 注入分布近似高斯：$N(x) = N_p e^{-(x-R_p)^2/2\Delta R_p^2}$，结深、峰值浓度、剂量都能从这条曲线读出。
