## 为什么从刻蚀开始

光刻只负责「画图」，把图形真正刻进材料里的是**刻蚀（etch）**。光刻胶上那层镂空窗口，如果不被转成氧化硅里的孔、多晶硅上的栅、介质中的槽，就毫无用处。<span class="marginnote">把光刻与刻蚀合起来看：光刻定义「哪里要动」，刻蚀执行「怎么动」。两者精度叠加，共同决定最终图形能否达到器件要求——所以它们总是成对地被讨论、被优化。</span>刻蚀技术的关键词是**选择性与各向异性**：既要只刻目标材料、不伤下层（选择性），又要「直上直下」地刻出垂直侧壁（各向异性），两者同时满足，器件图形才算真正立起来。

## 1 湿法刻蚀：简单但「各向同性」

**湿法刻蚀**用化学溶液溶解目标材料，历史悠久、设备简单、选择性极好。典型配方包括：用**氢氟酸（HF）** 刻蚀 $\ce{SiO2}$，用磷酸刻蚀 $\ce{Si3N4}$，用氢氟酸+硝酸混合液刻蚀多晶硅。湿法刻蚀的化学反应是各向同性的——溶液从各方向同时进攻，导致侧壁被横向掏蚀（undercut），线条比胶上的图形更细。<span class="marginnote">各向同性让湿法无法满足亚微米图形的垂直侧壁要求，但它仍有专属领地：晶圆背面的全片减薄、去离子水可安全冲洗的工艺、以及某些选择性要求极高的去除步骤。湿法不是被淘汰，而是退守到它擅长的战场。</span>湿法刻蚀速率常用「去除速率」与「选择比」表征，受浓度、温度与搅拌强烈影响，重复性一般，因此先进节点以干法为主。

### 常用湿法配方速览

| 目标材料 | 常用配方 | 特点 |
| --- | --- | --- |
| $\ce{SiO2}$ | 稀 HF / BOE | 选择性好、各向同性 |
| $\ce{Si3N4}$ | 热磷酸 | 对氧化硅选择性高 |
| 多晶硅 | HF + 硝酸 | 快、难控 |
| 铝 | 磷酸 + 硝酸 | 早期互连刻蚀 |
| 光刻胶 | 溶剂 / 氧等离子体 | 去胶用 |

## 2 等离子体：干法刻蚀的引擎

**干法刻蚀**用气态反应物在**等离子体**中产生自由基与离子，实现对薄膜的定向刻蚀。等离子体由射频电场电离低压气体（如 $\ce{CF4}$、$\ce{SF6}$、$\ce{Cl2}$）产生：电子在电场中加速，碰撞分子使其**解离**成活性自由基（负责化学反应），也产生**带能离子**（负责轰击）。自由基的化学刻蚀仍偏向各向同性，而离子在电场作用下沿垂直方向加速轰击晶圆，两者的配合正是控制各向异性的关键。

### 干法刻蚀常用气体

| 气体 | 作用 | 典型对象 |
| --- | --- | --- |
| $\ce{CF4}$ | 氟自由基源 | 氧化硅、氮化硅 |
| $\ce{CHF3}$ | 聚合物形成 | 氧化硅（高选择比） |
| $\ce{SF6}$ | 强氟源 | 硅、深孔 |
| $\ce{Cl2}$ / $\ce{BCl3}$ | 氯基刻蚀 | 铝、多晶硅 |
| $\ce{O2}$ | 去胶/灰化 | 光刻胶 |
| $\ce{Ar}$ | 离子轰击/稀释 | 增强各向异性 |

## 3 反应离子刻蚀 RIE：把方向「拧」进刻蚀

**反应离子刻蚀（Reactive Ion Etch, RIE）** 是当前介质与多晶硅刻蚀的绝对主力。RIE 腔体中射频功率同时驱动**等离子体产生**与**自偏压**：射频在电极上建立负直流自偏压，把离子加速砸向晶圆。

RIE 的各向异性来自一个精妙的机制——**离子轰击增强表面反应**：垂直入射的离子不断「擦亮」刻蚀底面，使底面反应物持续更新、副产物及时飞离，而侧壁没有离子轰击，反应慢得多。于是底面被快速刻蚀、侧壁几乎不动，形成垂直的侧壁轮廓。<span class="marginnote">一句话理解 RIE：离子负责「开门」，自由基负责「清扫」。没有离子轰击，自由基在侧壁也能反应，图形就会横向扩张；有了轰击，反应被强行引导到垂直方向，这正是「反应离子刻蚀」这五个字的物理内涵。</span>通过对气压、功率、气体配比（如 $\ce{CF4/CHF3/Ar}$）的调节，RIE 可以在「各向异性」与「选择性」之间取得工程平衡。更进一步的**深反应离子刻蚀（DRIE，博世工艺）** 用「刻蚀/钝化」交替循环，刻出深宽比极高的垂直深孔，是 TSV 与 MEMS 的关键工艺。

## 4 刻蚀的关键性能指标

**选择比（selectivity）**：目标材料刻蚀速率与掩模/下层材料刻蚀速率之比。对栅氧刻蚀，多晶硅与氧化硅的选择比要达到数十，否则会伤到栅氧。
**各向异性度**：横向刻蚀速率与纵向刻蚀速率之比，越接近 0 越好。
**均匀性**：同一晶圆不同位置、不同晶圆之间的刻蚀速率一致性，直接决定整批良率。
**刻蚀终点检测（endpoint）**：用光学发射光谱监测反应副产物的特征谱线强度变化，在目标层刻穿瞬间自动停止，避免过刻。

**辨析｜易错点：** 「各向同性」与「选择性」是**两个正交的维度**。湿法往往各向同性但选择性高；干法可以各向异性但选择性也可能很差。一个刻蚀工艺的好坏，必须同时看「方向性」（各向异性度）与「对象性」（选择比）——只看一个指标选工艺，一定会翻车。

### 干法刻蚀腔体类型对照

| 腔体 | 结构 | 特点 |
| --- | --- | --- |
| 平行板（电容耦合 CCP） | 两平板电极 | 经典 RIE，简单 |
| 电感耦合（ICP） | 线圈 + 平板偏压 | 高密度、独立控离子能 |
| 磁增强（MERIE） | 磁场约束电子 | 高密度、老一代 |
| 原子层刻蚀（ALE） | 自限制循环 | 逐原子层、极限精度 |

## 5 公式解析：各向异性度

把「直上直下」的程度量化，用**各向异性度（anisotropy）** $A$：

$$A = 1 - \frac{R_{lat}}{R_{vert}}$$

- $R_{vert}$：纵向（垂直方向）刻蚀速率；
- $R_{lat}$：横向（侧向）刻蚀速率。

**第一步，看极限**：若 $R_{lat} \to 0$，则 $A \to 1$，得到理想垂直侧壁——纯湿法的极限是 $A = 0$（完全各向同性），RIE 的目标是把 $A$ 推向 1。
**第二步，看代价**：提高 $A$ 往往意味着更强的离子轰击，但轰击会降低选择性、增加对下层和掩模的损伤，于是「各向异性、选择性、刻蚀速率」构成一个互相拉扯的三角，工程上永远在折中。
**第三步，落回器件**：栅极侧壁的垂直度直接决定沟道长度控制；接触孔/通孔的侧壁倾斜则影响填充。用一个 $A$ 值就能量化「这根柱子立得有多直」——它是刻蚀领域最直观的工程语言。

**算一个数字**：若一个 RIE 工艺的纵向刻蚀速率 $R_{vert} = 300\ \mathrm{nm/min}$，横向速率 $R_{lat} = 15\ \mathrm{nm/min}$，则 $A = 1 - 15/300 = 0.95$——接近垂直。若改用某种偏各向同性的条件使 $R_{lat} = 150\ \mathrm{nm/min}$，则 $A = 0.5$，侧壁会明显倾斜，图形宽度在刻深一半处就会明显收窄。用这个数可以直观判断：**哪个工艺适合做垂直孔，哪个只能做浅开窗**。

顺带一提：$A$ 的测量通常用**截面 SEM**——把晶圆切开、放大看侧壁倾斜角，反推横向/纵向速率比。这把「抽象的公式」落到了「可见的图形」上，也是刻蚀工艺与量测（CD-SEM）在《量测与缺陷检测》一节交汇的实例。

### 5.1 刻蚀在器件里的具体应用

每种图形结构都有「对口」的刻蚀：

**栅极刻蚀**：刻多晶硅/金属栅，要求极高的各向异性（垂直栅极侧壁）与对栅氧的高选择比，栅长就是 CD，直接影响沟道长度。
**接触孔/通孔刻蚀**：在介质中刻出垂直深孔，孔深与孔宽的比值（深宽比）可达 10:1 以上，对侧壁垂直度与底部残留控制要求极高。
**浅槽隔离刻蚀（STI）**：在硅中刻出隔离沟槽，要求对硅的稳定刻蚀与光滑侧壁。
**侧壁间隔层刻蚀（spacer）**：回刻（etchback）氮化硅/氧化硅形成侧壁隔墙，几乎完全各向异性——横向不能刻，只能纵向刻。

这些应用共享同一个物理：**用离子轰击的方向性换取图形的方向性**。理解 RIE 的「离子开门、自由基清扫」，就理解了以上全部结构的几何来源。

### 5.2 等离子体损伤：干法刻蚀的副作用

干法刻蚀带来一个特有的麻烦——**等离子体诱导损伤（plasma-induced damage, PID）**：等离子体中的带电粒子会沉积在晶圆表面（尤其是浮置的栅电极上），形成电荷积累；当天线效应（antenna effect）把大面积的导电层与薄栅氧相连时，积累的电荷可能在刻蚀瞬间击穿栅氧。<span class="marginnote">天线效应是「面积」与「电荷」的角力：连接在栅极上的金属/多晶硅面积越大，收集到的等离子体电荷越多，栅氧越容易被打穿。设计规则里会限制「天线比」（导电面积/栅氧面积），这正是刻蚀工艺与版图设计互相约束的又一例证。</span>对策包括：控制偏压与等离子体密度、优化气体化学、以及在版图层面遵守天线比规则。

**补充｜设备视角**：干法刻蚀机除了反应腔，还配有一整套**真空与供气系统**——涡轮泵维持低压、质量流量控制器（MFC）精确配气、尾气处理系统吸收副产物。这些「外围系统」的稳定性，与腔体本身的等离子体条件同等重要：一次供气波动或泵速漂移，就可能让整批晶圆的刻蚀均匀性失守。这也解释了为什么刻蚀机的保养重点是泵与 MFC——它们坏了，腔体再精良也白搭。

回到器件视角：刻蚀的成败最终以**电学结果**为判据——栅极刻蚀偏了就改阈值，接触孔刻浅了就增电阻。所以刻蚀工程师的日常，是与《量测与缺陷检测》《良率工程》两节的 CD 量测与良率数据打交道，用「量测→修正→复测」把刻蚀一步步调到窗口里。

## 6 小结

- 刻蚀把光刻的图形**转成材料结构**，核心指标是选择性与各向异性。
- 湿法刻蚀各向同性、选择性好，退守到去胶、减薄等战场；干法刻蚀以等离子体为引擎。
- **RIE** 用「离子轰击增强表面反应」获得垂直侧壁，是介质/多晶硅刻蚀主力；DRIE 用于深孔。
- 各向异性度 $A = 1 - R_{lat}/R_{vert}$ 把「直上直下」量化，$A\to 1$ 是理想极限。
- 各向异性与选择性是**正交维度**，选工艺必须同时看两者。
- 栅极、接触孔、STI、间隔层各有专属刻蚀要求；干法刻蚀需警惕**等离子体损伤**与天线效应。
- 终点检测用光学发射光谱在刻穿瞬间停机，防止过刻。
