## 为什么从封装开始

前面十四步我们都在「晶圆上造电路」。但芯片终归要装进系统：供电、散热、与主板连通、被机械保护——这就是**封装（packaging）** 的任务。过去封装被当作「装个壳」的配角，如今却是半导体技术最活跃的前沿之一。<span class="marginnote">为什么封装地位陡升？因为晶体管尺寸已逼近物理极限，靠继续缩小节点换取性能越来越贵；而把多个小芯片用先进封装「拼」成一个系统，成本更低、收益更直接。2.5D/3D 集成与 Chiplet 因此成为「后摩尔时代」的主力——封装的接力棒，正从晶圆工艺手里接过来。</span>本篇从传统封装讲到 Chiplet，看封装如何从「外壳」进化为「系统级集成平台」。更系统的 Chiplet 与 2.5D/3D 专题可参见姊妹专题《先进封装与 Chiplet》。

## 1 封装的基本使命

封装同时承担四项功能：

**电气连接**：把芯片的 I/O 引到封装引脚，与电路板互连。
**机械支撑与保护**：保护脆弱的芯片不受物理损伤、潮气与污染侵蚀。
**散热**：把芯片工作产生的热量导到散热器。
**信号与电源分配**：为芯片提供低噪声的供电与高速信号路径。

对封装材料与结构的核心要求是：**电性能好**（低寄生、高带宽）、**热阻低**、**可靠性高**、**成本可控**。封装方案的选择，本质是这四者的权衡。

### 封装的层级结构

| 层级 | 内容 | 说明 |
| --- | --- | --- |
| 芯片级 | die 的钝化、焊盘 | 芯片本身 |
| 封装级 | 引线/焊球 + 载体 | 单芯片封装 |
| 板级 | 焊到 PCB | 系统组装 |
| 系统级 | 多封装/多芯粒集成 | 2.5D/3D、SiP |

## 2 传统封装：从引线键合说起

**引线键合（wire bonding）** 是历史最悠久、至今仍大量使用的连接方式：用金线/铜线/铝线，通过热压或超声把芯片焊盘与封装引脚连起来。**焊线（bonding wire）** 直径通常 20–50 μm，工艺成熟、成本低、可靠性高，在消费级器件中仍占主导。<span class="marginnote">引线键合的软肋是<strong>寄生电感</strong>：每根键合线有几纳亨的电感，高频时造成信号振铃与电源噪声；且键合只能从芯片四周引出，I/O 密度受限。当芯片需要的 I/O 数量超过千级、频率进入 GHz，引线键合就不够用了——倒装焊登场。</span>

**倒装焊（flip-chip）** 把芯片「翻个面」：芯片有源面朝下，通过焊球（bump）阵列直接与基板/封装载体的焊盘焊接。相比引线键合，倒装焊的互连路径短得多、寄生电感低、I/O 密度高、散热路径短，是高性能处理器、GPU 的标配。

## 3 2.5D 与 3D 集成：往「上」堆性能

当单个芯片的集成度不够用，就往「平面之外」要空间：

**2.5D 集成**：把多颗芯片（die）并排安装在**硅中介层（interposer）** 上，中介层内用**硅通孔（TSV, Through-Silicon Via）** 实现垂直互连，芯片之间通过中介层内的微细布线通信。中介层让多颗芯片像「同一颗大芯片」一样高频互联，是高带宽内存（HBM）与 GPU 组合的经典方案。<span class="marginnote">HBM 就是 2.5D 的典型产物：多片 DRAM 堆叠后通过 TSV 垂直串联，再与 GPU 一起放在硅中介层上。相比传统内存走线，HBM 的带宽提升一个量级，而这一切都发生在「封装」里——这就是封装变成前沿技术的原因。</span>
**3D 集成**：把多颗芯片**直接垂直堆叠**（芯片对芯片，die-on-die），层间用 TSV 或混合键合互连。3D 的互连密度与垂直路径最短，但面临**散热**（热量被夹在层间）、**翘曲**（异质材料热失配）与**良率**（一层坏，整堆受损）的严峻挑战。

### 键合与互连技术一览

| 技术 | 互连密度 | 用途 |
| --- | --- | --- |
| 引线键合 | 低（周界） | 消费级 |
| 倒装焊球 | 中 | 高性能单芯片 |
| TSV | 高 | 2.5D/3D 垂直互连 |
| 混合键合 | 极高（μm 级） | 3D 堆叠、Chiplet |

## 4 Chiplet：把大芯片拆成小积木

**Chiplet** 的思想是把一颗大芯片拆成多个功能独立的小芯片（dielet），各自用成熟工艺制造，再通过先进封装拼装成完整系统。相比「一颗大芯片」，Chiplet 带来几大优势：

**良率与成本**：小芯片面积小、良率高，且坏片只需替换对应小片，不必整片报废。
**异构集成**：可以把不同工艺节点、不同工艺类型（逻辑、存储、模拟、射频）的小片「拼」在一起——每个模块用最适合自己的工艺。
**复用与生态**：同一颗小片可用于多种产品，形成「芯片积木」生态；英特尔、AMD、台积电等正在推动统一的 Chiplet 互联标准（如 UCIe）。<span class="marginnote">AMD 的 EPYC/Ryzen 系列是 Chiplet 商业化的代表作：计算芯粒（CCD）与 I/O 芯粒（IOD）分属不同晶圆，再通过 2.5D 互连拼装。这套架构让 AMD 绕开了「一颗大芯片良率低」的陷阱——Chiplet 的本质，是用封装换制造的经济账。</span>Chiplet 的代价是**互连带宽与功耗**——小片之间的通信必须足够快、足够省电，否则拆分的收益会被互连开销吃掉。因此 2.5D 中介层、混合键合等「高密度互连」正是 Chiplet 能否成立的命门。

**辨析｜易错点：** Chiplet 与「多芯片封装（MCM）」不是一回事。MCM 只是把多颗独立芯片装进同一封装，芯片间通信未必高带宽；Chiplet 则强调**把一颗逻辑上完整的芯片拆开设计**、通过**高密度互连**让它们像一颗芯片一样协作。前者是「装在一起」，后者是「设计成一体、制造时分体」——这是架构层面的区别，不是封装形式能定义的。

## 5 核心对比表：传统封装 vs 先进封装

本主题重在「方案权衡」，用对比表把两条技术路线摆清楚。

| 维度 | 传统封装 | 先进封装 |
| --- | --- | --- |
| 代表互连 | 引线键合（wire bond） | 倒装焊、TSV、混合键合 |
| I/O 密度 | 低（芯片四周引出） | 高（面阵列 + 垂直互连） |
| 集成尺度 | 单芯片 + 引脚 | 多芯片 2.5D/3D、Chiplet |
| 带宽 / 寄生 | 带宽有限、寄生电感大 | 高带宽、低寄生 |
| 成本 | 低、成熟、可靠 | 高、技术门槛高 |
| 散热 | 单芯片散热直接 | 3D 堆叠散热困难 |
| 适合场景 | 消费级、中低端 | 高性能计算、AI、HBM |

### 4.1 扇出型封装与 SiP

在 Chiplet 之外，先进封装还有两条重要支线：

**扇出型封装（fan-out）**：把芯片重新「排布」在塑封/树脂载体上，通过再分布层（RDL）把 I/O 扇出到更大面积——无需基板就能实现高密度互连与薄型封装，是移动与高性能应用的宠儿。
**系统级封装（SiP, System-in-Package）**：把多个功能器件（芯片、无源、MEMS、天线）封装进一个模块，实现「一个模块一个系统」。SiP 与 Chiplet 的区别在于：SiP 更偏「异构模块集成」，Chiplet 更偏「逻辑拆分后再拼」。两者互补，共同扩大「封装即系统」的版图。

### 4.2 封装可靠性的硬考验

封装天天面对温变、湿度、机械应力，可靠性测试是出厂前的必修课：

| 测试 | 内容 | 失效模式 |
| --- | --- | --- |
| 温度循环（TCT） | 反复高低温 | 焊点疲劳、开裂 |
| 高温存储（HTS） | 长期高温 | 金属间化合物、氧化 |
| 湿度测试 | 高温高湿 | 电化学迁移、腐蚀 |
| 机械冲击/振动 | 跌落、振动 | 键合线断裂 |
| 热冲击（TST） | 快速温度突变 | 界面分层 |

**辨析｜易错点：** 温度循环（TCT，慢变）与热冲击（TST，快变）都会造成热应力失效，但**失效机制不同**：TCT 主要由热膨胀失配的「累积疲劳」驱动，TST 更接近「瞬间开裂」。别把两者混为一个测试——它们对材料选择（CTE 匹配）与结构设计（应力释放）的指导意义完全不同。<span class="marginnote">封装可靠性的敌人是<strong>热膨胀失配</strong>：硅（CTE 约 3 ppm/K）与基板（如有机材料 CTE 十几 ppm/K）膨胀系数差好几倍，温度一变就互相拉扯。封装材料的选型、底填胶（underfill）的应力缓冲，都是在「给膨胀失配留余地」。</span>

## 6 小结

- 封装承担**电气连接、机械保护、散热、供电与信号分配**四项使命。
- **引线键合**成熟可靠但寄生大、I/O 受限；**倒装焊**以短互连、高密度成为高性能芯片标配。
- **2.5D** 用硅中介层 + TSV 并排互联多芯片（HBM 即典型）；**3D** 直接垂直堆叠，散热与良率是硬约束。
- **Chiplet** 把大芯片拆成小积木、异构拼装，用封装换良率与成本；其命门是互连带宽与功耗。
- **扇出封装**与 **SiP** 是先进封装的两条支线；Chiplet 与 MCM/SiP 的区别在「设计一体 vs 封装一体」。
- 封装可靠性靠**温度循环、湿度、机械冲击**等测试把关，热膨胀失配是头号敌人。

- Chiplet 与 MCM 的区别在「设计一体 vs 封装一体」，别混为一谈。
- 先进封装的本质是**用封装的技术复杂度换取系统级的性能与成本**——后摩尔时代的主战场。
