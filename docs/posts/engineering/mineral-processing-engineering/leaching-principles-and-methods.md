## 为什么从浸出开始

前面所有方法——重选、磁选、电选、浮选——都在「颗粒」尺度上把矿物分开，产物依然是固态的矿物颗粒。可有些矿石偏偏物理性质差异太小、或有用成分太分散（如低品位氧化铜矿、难处理金矿），颗粒层面的分离做不到。这时就轮到**化学选矿**登场：**浸出（leaching）**用化学药剂把有用金属从矿石中选择性地溶解到溶液里，再从溶液回收金属。<span class="marginnote">浸出把选矿的战场从「固—固分离」搬到「固—液分离」：矿石不变，金属变了形态。金矿的氰化浸出、氧化铜矿的酸浸、铀矿的碱浸，都是化学选矿的经典。它让物理方法无能为力的低品位、难处理矿石也具备了经济回收的可能。</span>浸出同时是「选矿」与「冶金」的分界地带——溶解后的净化、电解、沉淀已属湿法冶金，但「浸出」这一步通常仍划在选矿工程里。

## 1 浸出：化学选矿的入口

**浸出（leaching）**：用适当的化学溶剂（浸出剂）选择性地溶解矿石中的有用组分，使其进入溶液，再与不溶残渣分离的作业。

浸出要求「选择性」：理想情况下只溶解目标金属，脉石（石英、硅酸盐）几乎不溶。实际不可能绝对选择，但通过**浸出剂种类、浓度、pH、氧化还原电位**的组合，可以做到「目标金属绝大部分溶解、杂质少量溶解」。

浸出前常需**预处理**：磨细（增大反应面积）、焙烧（把难溶形态转变成易溶形态）、脱除有害杂质。<span class="marginnote">「先焙烧再浸出」是浸出工艺的重要分支：如含砷金矿先氧化焙烧把载金黄铁矿烧成多孔 `Fe2O3`，氰化物才能渗入浸金；含硫铜矿先硫酸化焙烧再水浸，把铜从硫化物转成可溶硫酸铜。焙烧是「改造矿石的化学形态，为浸出开路」。</span>

## 2 浸出方法的分类

按浸出剂与矿物的反应性质分：

**酸浸**：用硫酸、盐酸等溶解金属氧化物与碳酸盐。**氧化铜矿酸浸**是最典型代表：$ \ce{CuO + H2SO4 -> CuSO4 + H2O} $，铜进入溶液后用铁置换或电解回收。
**碱浸**：用苛性碱、碳酸钠、氨等。**氧化铝的拜耳法**（铝土矿碱浸）是最典型的碱浸工业；铀矿也常用碳酸盐碱浸。
- **氰化浸出**：用稀氰化钠（`NaCN`）溶液浸出金、银，是黄金工业的经典方法。金在含氧氰化液中生成可溶的氰金络离子：$ \ce{4Au + 8NaCN + O2 + 2H2O -> 4Na[Au(CN)2] + 4NaOH} $。<span class="marginnote">氰化浸金是浸出技术里产量最大、也最具争议的一个：氰化物剧毒，尾矿库必须严格防渗防泄漏；现代黄金工业大量改用<strong>非氰浸金剂</strong>（硫代硫酸盐、硫脲等）或加强氰化物降解处理，安全与环保已成为金矿浸出的生命线。</span>
**细菌浸出（生物浸出）**：靠微生物把难溶硫化物氧化成可溶硫酸盐，见《生物选矿》一节。
**水浸**：对可溶盐类矿物直接用水溶解。

按作业方式分：**槽浸（搅拌浸出）**、**渗滤浸出**、**堆浸**（见下节）、**原地浸出**（向地下矿体直接注液）。

## 3 浸出过程的物理化学

浸出是**多相反应**：固体矿物与液体浸出剂在固液界面反应。整个过程由一系列步骤串联：

1. 浸出剂扩散到矿物表面（外扩散）。
2. 浸出剂穿过矿物表面的固体产物层（内扩散）。
3. 在表面发生化学反应（表面反应）。
4. 生成的可溶产物从表面扩散回溶液主体（反向扩散）。

其中**最慢的一步决定总浸出速率**（速率控制步骤）。细粒矿石表面反应面积大、浸出快；粗颗粒或表面生成致密产物膜时，扩散成为瓶颈，浸出变慢。<span class="marginnote">金矿氰化浸出的经典经验：磨得越细、金的解离度越高，浸出越快越彻底——因为氰化液必须接触到金粒表面才能溶解。而表面生成的固体产物膜（如氧化膜）会把矿物「包住」，这时要加氧化剂或搅拌强化来突破扩散屏障。</span>

## 4 公式解析：未反应核模型

浸出动力学最经典的模型是**未反应核模型（shrinking core model）**：颗粒外层先被浸出，反应界面逐步向核心收缩。若浸出受**产物层内扩散控制**，球形颗粒的转化率 $X$ 与浸出时间 $t$ 的关系为：

$$
\frac{t}{\tau} = 1 - 3(1-X)^{2/3} + 2(1-X)
$$

$X$ 为已浸出的转化率（0–1），$t$ 为浸出时间，$\tau$ 为完全浸出所需时间（$X \to 1$）。逐步拆解：

- **第一步，看结构的含义**：$1 - 3(1-X)^{2/3} + 2(1-X)$ 随 $X$ 从 0 增到 1 时从 0 增到 1；把 $t/\tau$ 与它相等，就是一条 S 形进度曲线。
- **第二步，解读「先快后慢」**：浸出初期反应界面靠近表面、路程短，浸出快；随着界面内移，产物层越来越厚、扩散路径越来越长，浸出越来越慢。<span class="marginnote">这个「后段拖尾」正是现场浸出时间曲线的典型形状——最后 10% 的转化率要花掉几乎一样多的时间。工业上据此确定「经济浸出时间」：回收率达到 90%–95% 就结束，为追求最后几个百分点无限延长时间得不偿失。</span>
**第三步，参数启示**：$\tau$ 与颗粒半径平方成正比（扩散控制）、与产物层扩散系数成反比——**磨细颗粒、疏松产物层、强化搅拌**都能成倍缩短浸出时间。<span class="marginnote">这就是为什么浸出流程总把「磨矿细度」摆在第一位：颗粒半径减半，扩散控制下的浸出时间减到四分之一。设备上则用搅拌、加温、增氧等手段提高扩散系数与反应速率。</span>

若表面化学反应控制，则 $t/\tau = 1 - (1-X)^{1/3}$（界面收缩型），曲线形态不同——通过拟合浸出数据判断「扩散控制还是反应控制」，是浸出工艺诊断的基本功。

## 5 浸出工艺与设备

**搅拌浸出（agitation leaching）**：矿石磨细后与浸出剂在搅拌槽中混合浸出，反应快、回收率高，是最通用的方式。多段串联（如 6–8 台浸出槽），矿浆连续流动。<span class="marginnote">搅拌浸出的「帕丘卡槽」与机械搅拌槽是黄金氰化浸出的标配。搅拌既保证颗粒悬浮、又强化传质，还帮助氧气溶解进矿浆参与氧化反应——氰化浸金必须有氧，槽内常通空气或富氧。</span>
**渗滤浸出（percolation leaching）**：浸出剂从矿石料层上方喷淋，渗流而下溶解金属，用于粗粒或疏松矿石。设备简单、成本低，但浸出时间长、回收率较低。
**加压浸出（pressure leaching）**：在高压釜中高温高压浸出，用于难处理矿（如高硫砷金矿的氧化预处理），反应温度可达 200°C 以上，可显著提高速率。
- **堆浸与原地浸出**：见下一节《堆浸与化学富集》。

## 6 影响浸出的因素与工业实践

关键因素：

- **粒度**：越细比表面积越大、浸出越快（受扩散控制时尤其显著）。
- **温度**：升高温度加快扩散与反应，但能耗上升、部分反应需控温。
- **浸出剂浓度**：浓度提高速率加快，但过高浪费药剂、选择性变差。
- **搅拌（或渗流）强度**：强化传质，消除浓度梯度。
- **矿浆浓度与 pH、氧化还原电位**：决定反应方向与速率。

工业实践要点：浸出后矿浆要**固液分离**（浓缩、过滤）得到含金属的**浸出液（pregnant solution）**与**浸出渣（tailings / residue）**；浸出液再经净化、沉淀、置换或电解回收金属。<span class="marginnote">从浸出液回收金属的方法：铁置换（`CuSO4` 溶液加废铁：$\ce{Cu^{2+} + Fe -> Cu + Fe^{2+}}$）、锌粉置换（金氰化液加锌粉沉淀金）、电解沉积、溶剂萃取—电积（SX–EW，氧化铜矿与铀矿的现代路线）等。浸出之后的这一段就是湿法冶金的主场。</span>

## 7 拓展：浸出方法的选择对照

不同矿石配不同浸出剂，选择的核心是「目标金属的化学形态」与「脉石对药剂的耐受性」。把常用浸出体系放在一起对照：

| 浸出体系 | 浸出剂 | 典型对象 | 特点 |
| --- | --- | --- | --- |
| 酸浸 | 硫酸、盐酸 | 氧化铜、氧化锌、铀矿 | 便宜、反应快，但脉石耗酸 |
| 碱浸 | 氢氧化钠、氨、碳酸钠 | 铝土矿（拜耳法）、铀矿 | 选择性好，但成本高 |
| 氰化浸出 | 氰化钠 + 氧 | 金银矿 | 对金银特效，剧毒需严管 |
| 硫代硫酸盐浸出 | 硫代硫酸铵/钠 | 金银矿（非氰） | 环保替代，贵液处理复杂 |
| 细菌浸出 | 嗜酸菌 + 硫酸铁 | 低品位硫化铜 | 成本低、周期长 |

选择时三条原则：

1. **看矿物可溶性**：浸出剂必须能溶解目标矿物——氧化矿选酸、碱选型按矿种定，硫化物通常要先氧化（细菌、焙烧、加压）才能浸。
2. **算脉石耗药**：碳酸盐脉石耗酸厉害，酸性浸出前要先看脉石成分；石英脉石对酸稳定，是酸浸的「友好」对象。<span class="marginnote">脉石耗药是浸出经济性的大敌：含碳酸盐高的矿石酸浸时，大量硫酸被方解石「吃掉」，药剂成本飙升。这类矿石要么换碱浸、要么先脱除碳酸盐，要么用细菌浸出（自身产酸、就地取材）。浸出工艺设计的第一步，其实是「化验脉石」。</span>
3. **权衡环保与安全**：氰化剧毒、酸雾腐蚀、碱液强碱，每种浸出剂的环保处置成本都要计入总账——「便宜的药剂 + 昂贵的处理」常常不如「贵一点的药剂 + 简单的处理」。

<strong>浸出方法没有绝对优劣，只有「目标矿物 + 脉石 + 环保」三维约束下的最适解。</strong><span class="marginnote">这也解释了为什么同一种金属会有多条浸出路线并存：氧化铜矿可以酸浸、氨浸、细菌浸出；金矿可以氰化、硫代硫酸盐、硫脲浸出。方法越多，工艺设计的选择空间越大，对工程师「读矿石 + 算成本」的能力要求也越高。</span>

### 浸出的安全与环保

浸出工艺的环保与安全是选型时的「一票否决项」：

**氰化物的管理**：氰化浸金的剧毒性要求配液、浸出、尾渣处置全链条闭环——从「零排放」到「降解处理」（`SO2`/空气氧化、`H2O2` 氧化分解氰化物）都有规范流程。
**酸雾与腐蚀**：酸浸产生酸雾，设备要防腐、作业要通风，含酸尾渣要中和处理。
- **溶液泄漏**：浸出液含有价金属与药剂，任何泄漏都是「经济损失 + 环境风险」双输。<span class="marginnote">「浸出液泄漏」是化选矿厂最怕的事故：高浓度金属溶液一旦进入水体，污染不可逆。防渗、围堰、应急池、在线监测，是浸出车间设计的安全标配——安全投入不是成本，是资格。</span>

<strong>浸出的经济账要把「药剂成本 + 环保成本 + 产品收益」一起算</strong>——便宜的氰化未必最省，贵但环保的非氰浸出可能综合更优。随着环保红线收紧，「绿色浸出」正在成为工艺选择的主导变量。

## 8 小结

- 浸出用化学药剂把有用金属选择性溶入溶液，是**化学选矿**的核心作业。
- 方法分类：酸浸（氧化铜矿）、碱浸（铝土矿拜耳法）、氰化浸金、细菌浸出、水浸。
- 浸出是多相反应，**最慢步骤控制总速率**；扩散控制时后段明显拖尾。
- 未反应核模型 $t/\tau = 1 - 3(1-X)^{2/3} + 2(1-X)$
