# 矿物加工工程（选矿）

矿物加工工程（选矿）研究从矿石中分离、富集有用矿物并获得合格精矿的原理与工艺，涵盖破碎磨矿、选别富集与金属/非金属提取，是连接采矿与冶金的枢纽环节。以王淀佐《选矿学》、孙传尧《选矿工程》与 Wills《Mineral Processing Technology》为纲，每写完一篇勾掉一条。

## 对标教材

- 王淀佐《选矿学》（中南大学出版社）
- 孙传尧《选矿工程》（冶金工业出版社）
- Barry A. Wills《Mineral Processing Technology》(Elsevier)
