## 为什么从油气藏动态分析开始

《油藏描述》给油藏拍了「静态照片」，但油藏是活的——投产以后，压力在降、含水在升、气油比在变。**油气藏动态分析（reservoir performance analysis）**就是利用生产数据，反推油藏的驱动方式、能量消耗程度与剩余油分布，预测未来产量。<span class="marginnote">动态分析被称为油藏工程师的「临床诊断」：静态描述告诉你油藏「长什么样」，动态分析告诉你油藏「现在什么状态、正在发生什么」。两者结合，才能开出开发方案这张「处方」。</span>

从《油水井管理》的单井数据到本节的全油藏视角，动态分析的核心工具是两件：**递减曲线分析**（看产量怎么随时间衰减）与**物质平衡方程**（看油藏能量怎么被消耗）。

## 1 动态分析：从生产数据读油藏

油藏动态分析的输入是每口井日常积累的生产数据——产量、井底压力、含水率、气油比。这些看似琐碎的数字，合起来回答几个关键问题：

**驱动方式判断**：压力下降快 + 气油比先升后降 → 溶解气驱；压力平稳 + 含水上升 → 水驱。驱动方式不同，开发对策截然不同。
**能量评价**：平均地层压力下降多少？还有多少天然能量可用？
**储量核实**：已采出多少？按递减趋势还能采多少？动态储量与《油气藏储量计算》的静态储量互相校验。

动态分析的输出是**油藏动态曲线**——产量、压力、含水、气油比随时间的变化，以及由此外推的**剩余可采储量**。<span class="marginnote">动态数据是油藏工程最诚实的信息源：它来自真实生产，不含预测假设。但它的缺点是「只见结果不见原因」——产量下降可能是油藏问题也可能是设备问题，需要结合《油水井管理》的井况诊断才能分清。</span>

## 2 递减曲线分析：Arps 递减

油田投产后，若不加措施，产量通常按一定规律**递减（decline）**。1945 年 Arps 总结了三种经典的递减规律，统称 **Arps 递减**：

$$q = \frac{q_i}{(1 + b\, D_i\, t)^{1/b}}$$

- $b = 0$ 时退化为**指数递减** $q = q_i e^{-D_i t}$：产量按固定比例下降，常见于溶解气驱后期。
- $0 < b < 1$ 时为**双曲递减**：递减率随产量下降而减小，是最常见的形态。
- $b = 1$ 时为**调和递减**：递减率与产量成正比，递减最慢，常见于重力驱。

<span class="marginnote">三种递减的区别全在「递减率是否变化」：指数递减的递减率恒定（半衰期固定），双曲递减的递减率越来越小，调和递减递减最慢。判断属于哪种，只要把产量-时间数据画在双对数/半对数坐标里看直线——这是递减分析最经典的操作。</span>

递减曲线的用途是**外推预测**：拟合出递减参数后，即可预测未来任意时刻的产量，并积分得到剩余可采储量——这是储量动态核实的主力工具。但外推的前提是**开发条件不变**：一旦加密井网、调整注水或上措施，递减规律就变了，必须重新拟合。

## 3 物质平衡：油藏的收支账簿

**物质平衡方程（material balance equation, MBE）**是油藏工程最根本的守恒定律：**油藏中流体体积的变化 = 采出 + 侵入 + 注入**。它像一本账簿，逐笔记录油藏里每一方流体的来去。

对最简单的**未饱和油藏**（单相、无气顶、无水体），物质平衡简化为：

$$N_p B_o + W_p B_w = N B_{oi}\, c_t\, \Delta p + W_e + W_{inj} B_w$$

- 左端是**地下采出体积**：地面采出的油 $N_p$ 与水 $W_p$ 折算到地下；
- 右端第一项是**油藏岩石与流体膨胀**提供的能量：总压缩系数 $c_t$ 乘初始储量 $N$ 与压降 $\Delta p$——压力每降一点，油藏靠弹性膨胀挤出一点流体；
- 右端第二、三项是**外部补给**：边水侵入 $W_e$ 与注水量 $W_{inj}$。

**公式的用法**：把实测的产量与压力代入，反解未知量——缺水体时求水侵量 $W_e$，或已知水侵时求原始储量 $N$。物质平衡因此既是储量核实工具，也是预测压力衰减的骨架。<span class="marginnote">物质平衡方程的优势是「只依赖累积产量与平均压力」，不需要井筒细节——它把整个油藏当作一个「黑箱」来记账。它的局限也在此：黑箱看不到油藏内部的不均匀流动，那是《油藏数值模拟》才能回答的问题。</span>

## 4 公式解析：指数递减与递减率

以最常用的**指数递减**为例，拆解递减分析的数学：

$$q = q_i e^{-D_i t}, \qquad \ln q = \ln q_i - D_i t$$

逐项拆解：

- $q_i$ 是递减起始时的产量，$D_i$ 是初始递减率（单位 1/时间），$t$ 是时间；
- **取对数后是一条直线**：$\ln q$ 对 $t$ 作图，斜率就是 $-D_i$——这就是为什么指数递减在**半对数坐标**里是直线，看图定参数极其方便；
- $D_i$ 的工程含义：**产量每年下降的比例**。$D_i = 0.1/\text{年}$ 意味着产量每年衰减约 10%，连采七年后产量只剩一半；
- **递减率的把握**决定预测成败：$D_i$ 定得偏大，预测的剩余储量偏小，过早放弃井区；偏小则高估储量、误判开发寿命——递减率是动态分析里最敏感、也最需要谨慎标定的参数。

把 $q(t)$ 对时间积分，就得到从 $t_0$ 到无穷的**可采储量** $N_p = q_i/D_i$（指数递减情形）——一条简单的递减曲线，就足以支撑油田级的经济决策。

## 5 动态分析的现场数据要求

动态分析再精巧，也离不开可靠的基础数据。

「垃圾进、垃圾出」在动态分析里体现得淋漓尽致。

现场数据管理有几条硬要求：

- **计量准确**：油、气、水的计量误差要控制在合理范围；
- **压力可靠**：静压、流压的测点与测法要规范；
- **记录连续**：数据断档比数据偏差更可怕；
- **统一基准**：产量、压力要统一到同一时间基准上。

| 数据 | 常见问题 | 管理要求 |
| --- | --- | --- |
| 产量 | 计量误差 | 定期标定计量设备 |
| 压力 | 测点不规范 | 按标准测压程序 |
| 含水 | 取样代表性差 | 加密取样 |
| 气油比 | 分离条件不同 | 统一折算 |

动态分析的常用数据表，是油田的「病历本」。

它记录每口井、每个层段的产量与压力轨迹。

有了这份病历，工程师才能做：

- 递减曲线拟合；
- 物质平衡计算；
- 储量动态核实。

数据管理是油田的「基础设施工程」。

没有可靠数据，再高级的分析方法都是空中楼阁。

这也是为什么数字化采集被如此重视。

数据从「手写报表」走向「自动采集」。

动态分析的地基，因此越打越牢。

## 6 小结

- **动态分析**用生产数据判断驱动方式、评价能量、核实储量，是油藏的「临床诊断」。
- **Arps 递减**分指数（$b=0$）、双曲（$0<b<1$）、调和（$b=1$）三种，外推预测产量与剩余储量。
- **物质平衡方程**是油藏层面的守恒账簿：地下采出体积 = 弹性膨胀 + 外部补给。
- 未饱和油藏 MBE：$N_p B_o + W_p B_w = N B_{oi} c_t \Delta p + W_e + W_{inj}B_w$。
- 指数递减在半对数坐标是一条直线，递减率 $D_i$ 是最敏感、最需谨慎的标定参数。

在下一节，我们请出动态分析的另一把利器：用井口短暂的开关井，从压力瞬变里读出油藏的渗透率与边界——**试井分析**。
