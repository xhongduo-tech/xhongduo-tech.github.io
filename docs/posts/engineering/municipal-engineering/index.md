# 市政工程（给排水科学与工程）

市政工程（给排水科学与工程）是土木工程一级学科下的二级学科（081403），研究城市给水系统、排水管网与给排水处理技术，是城市基础设施与公共卫生的命脉。它以水为对象，贯通水源取水、水质净化、管网输送、污水处理与资源回用的完整链条，是城市化进程中不可或缺的工程学科。

## 对标教材

- 严煦世、范瑾初《给水工程》（中国建筑工业出版社）
- 张自杰《排水工程》（中国建筑工业出版社）
- Metcalf & Eddy《Wastewater Engineering》(McGraw-Hill)
