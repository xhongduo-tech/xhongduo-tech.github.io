## 为什么从同步电机开始

异步电机是电动机之王，而**同步电机是发电机之王**：全世界 99% 以上的电能都由同步发电机发出。原因在于同步电机的转速与电网频率严格同步（$n = 60f/p$），多台发电机并网时能保持相位一致、稳定地承担功率分配；同时它还能通过调节励磁**主动控制无功功率**——这两条能力，让同步电机成为电网的「心脏」与「稳定器」。<span class="marginnote">同步电机与异步电机的本质差别在转子磁场来源：异步电机转子磁场由感应电流产生（被动），同步电机转子磁场由<strong>直流励磁</strong>产生（主动）。发电机需要「能独立建立磁场、可主动调节」的转子，所以同步电机当仁不让地成为电力系统的主力发电机。</span>

本节按《电机学》同步电机篇的脉络组织：工作原理与结构 → 功角特性 → 并网运行 → 励磁调节。同步电机的知识也是后面《电力系统稳定性》《频率与电压调整》的电机学底座。

**核心对比表：同步电机与异步电机**

| 项目 | 同步电机 | 异步电机 |
| --- | --- | --- |
| 转子磁场来源 | 直流励磁（主动） | 感应电流（被动） |
| 转速与磁场 | 严格同步 $n = n_1$ | 略低于同步（转差率 $s$） |
| 励磁调节 | 可调无功 | 不可调（需无功补偿） |
| 主要角色 | 发电机（99% 电能） | 电动机（工业驱动主力） |
| 启动 | 需异步启动或变频启动 | 直接/降压启动 |
| 优缺点 | 可调无功、结构复杂 | 简单坚固、功率因数低 |

## 1 同步电机的工作原理与结构

**核心概念**：**同步电机**：转子以直流励磁建立磁场，定子通三相交流产生旋转磁场；正常运行时**转子转速与旋转磁场转速严格相等**，即 $n = 60f/p$——转速完全由电网频率决定，这是「同步」的含义。

**结构**：

- **定子**：与异步电机相同的三相对称绕组（电枢）；
- **转子**：凸极式（磁极明显凸出，水轮发电机多用，极数多、转速低）或隐极式（转子呈圆柱，汽轮发电机多用，极数少、转速高 3000 r/min）。

**重点：** 隐极式适合高速（火电、核电汽轮发电机 3000 r/min），凸极式适合低速（水轮发电机 100–600 r/min）——**「转速由原动机决定、结构跟着转速走」**是同步电机设计的第一条规律。汽轮发电机转子细长、水轮发电机转子矮胖，都是转速约束的产物。<span class="marginnote">汽轮发电机转子细长是为了承受 3000 r/min 下的巨大离心应力；水轮发电机转速低、极数多，转子就做成又短又粗的凸极结构。一看转子的「胖瘦」，就能猜出它配的是汽轮机还是水轮机。</span>

## 2 功角特性

**核心概念**：**功角（功率角）$\theta$**：同步电机的空载电动势 $E_0$ 与端电压 $U$ 之间的相位角。功角直接决定电磁功率的大小，是同步电机最重要的状态量。

**核心概念**：**功角特性**：隐极同步电机的电磁功率与功角的关系为：

$$P_{em} = \frac{E_0 U}{X_s} \sin\theta$$

其中 $X_s$ 是同步电抗。这条「正弦功角特性」曲线是理解同步电机的钥匙：

**同步电抗的来源**：$X_s$ 是定子漏抗与电枢反应电抗之和——定子电流建立电枢磁动势，其磁场穿过气隙作用于主磁场（即电枢反应），等效成一个电抗。**同步电抗越大，电枢反应的「软作用」越强**，功角特性越平缓、极限功率越小。这与《直流电机》里的电枢反应同源，只是换成了交流量。

- **功角 $\theta$ 增大，功率增大**，在 $\theta = 90°$ 处达到最大电磁功率（极限功率）；
- 稳态运行时功角 $\theta < 90°$，留有一定裕度（额定运行时 $\theta_N$ 约 30° 左右）。

**重点：** 功角是「电网的粘合剂」——**发电机的输出功率由电网需求决定，而功角自动调整到与之平衡**。功角越大，发电机越「吃力」；一旦超过 90°，发电机失去同步、进入失步状态，这是《电力系统稳定性》里静态稳定分析的起点。

**凸极电机的额外力矩**：凸极同步电机的功角特性除了基本项 $\frac{E_0 U}{X_d}\sin\theta$，还多出一项与励磁无关的**磁阻功率** $\frac{U^2}{2}\left(\frac{1}{X_q}-\frac{1}{X_d}\right)\sin 2\theta$——由直轴与交轴磁阻不同产生。即使不励磁，凸极电机也能发出一点磁阻功率，这是磁阻同步电机、以及凸极发电机「天然稳定余量」的来源。<span class="marginnote">功角像一根「无形的弹簧」：负载突然增加，发电机转子减速、功角拉开、电磁功率增大，直到与机械输入平衡——这台「弹簧」的刚度就是 $E_0U/X_s$ 和功角的组合。理解功角，就理解了电网为何能「自己找到平衡」。</span>

## 3 并网运行

**核心概念**：**并网（parallel operation）**：把同步发电机接入电网，与其他发电机共同运行。并网的**准同期条件**有四条：

- 电压大小相等；
- 电压相位相同；
- 频率相同；
- 相序相同。

**重点：** 四条中任何一条不满足，合闸瞬间都会产生巨大的冲击电流与机械冲击——**实际用「准同期装置」监视并自动合闸**，把误差限制在很小的范围内（电压差 `<1%`，相位差 `<10°`，频差 `<0.5%`）。

**并网的两种方式**：

- **准同期（同步并列）**：先满足四条件再合闸，冲击最小，是主力发电机的标准做法；
- **自同期（非同步并列）**：未励磁的发电机先由原动机拉到接近同步速，直接合闸再投励，冲击电流较大但操作简单——常用于事故后快速并列。

**并网的经济意义**：多台机组并网后，总容量等于各机之和，可以按负荷需求**经济调度**启停机组（见《电力调度与运行》）；单台机组故障也不影响全网供电——**「大电网」的可靠性，建立在并网之上**。<span class="marginnote">老工程师会说「并网四条件」就是「三个相同一个一致」：电压、相位、频率相同，相序一致。其中最玄妙的是<strong>相位</strong>——合闸瞬间电网电压与发电机电压相位若差 180°，等于两电源直接短路，冲击电流可毁坏发电机。这就是并网必须用同期检测的原因。</span>

**并网后的功率调节**：并网后同步电机的转速被电网频率「锁死」——有功功率靠**调节原动机输入**（汽门/水门开度）改变，无功功率靠**调节励磁电流**改变。**「有功靠汽门、无功靠励磁」**是同步电机运行的口诀，对应电网的「有功管频率、无功管电压」（见《频率与电压调整》）。

## 4 励磁调节与 V 形曲线

**核心概念**：**励磁调节**：改变转子励磁电流 $I_f$ 即改变空载电动势 $E_0$，从而改变发电机发出的无功功率。并网运行且有功不变时，调励磁会改变功率因数与无功：

- **欠励**（$I_f$ 小）：发电机吸收感性无功，向电网提供容性无功；
- **正常励磁**：功率因数等于 1，无功为零；
- **过励**（$I_f$ 大）：发电机发出感性无功，向电网提供无功支撑。

**核心概念**：**V 形曲线**：保持有功不变，电枢电流 $I_a$ 随励磁电流 $I_f$ 变化的曲线呈「V」形——V 形最低点对应 $\cos\varphi = 1$，即最小电枢电流。<span class="marginnote">V 形曲线是励磁系统的「仪表盘」：运行人员靠它判断当前是过励还是欠励、电枢电流是否超限。无功补偿、电压调节（见《频率与电压调整》）都是沿着 V 形曲线调励磁的实际操作。</span>

**重点：** **同步电机的「身份双重性」**——既能发有功（发电机），又能当「无功源」：同步调相机就是不带机械负载、专门运行在过励状态提供无功的同步电机。在新能源大量并网后，同步调相机的「无功+惯量」价值被重新认识，成为新型电力系统的重要资源（见《新型电力系统前沿》）。

**同步电动机**：同步电机也能当电动机用——恒转速（不随负载变）、可调功率因数（过励时向电网送无功、改善电网功率因数），用于大型压缩机、轧机、磨机等恒速重载场合。<span class="marginnote">同步电动机曾大量用来「无功补偿」：过励运行向电网提供无功，一机两用。随着电力电子无功补偿装置（SVC、SVG）普及，它的这类用途有所让位，但在大功率恒速驱动的场合仍是主流。</span>不过同步电机自身没有启动转矩，启动需要靠阻尼绕组异步启动或变频启动。

## 5 公式解析：功角特性的三个量

功角特性 $P_{em} = \frac{E_0 U}{X_s}\sin\theta$ 的三个乘数各有其物理含义，逐一拆解：

- **第一步，$E_0$——励磁的贡献**：$E_0$ 由励磁电流决定，是「电机自己发力」的量；励磁越大，能发的功率上限越高。
- **第二步，$U$——电网的约束**：端电压 $U$ 由电网决定，对单台发电机是「外生变量」——它决定了发电机与电网的耦合强度。
- **第三步，$X_s$——内部的阻力**：同步电抗是定子漏抗与电枢反应等效电抗之和，代表「内部压降的代价」；$X_s$ 越小，功角特性越陡、极限功率越大，**所以减少电枢反应（增大气隙）是提高同步电机功角极限的设计手段**。

**数值例**：一台隐极同步发电机 $E_0 = 1.2\, \text{p.u.}$、$U = 1.0\, \text{p.u.}$、$X_s = 1.5\, \text{p.u.}$，则极限功率 $P_{max} = E_0 U/X_s = 0.8\, \text{p.u.}$；额定运行若取 $\theta_N = 30°$，则输出 $P = 0.8\times\sin30° = 0.4\, \text{p.u.}$，过载能力 $P_{max}/P_N = 2.0$——**功角特性一算，过载能力与稳定裕度一目了然**。

**辨析｜易错点：** 功角 $\theta$ 与功率因数角 $\varphi$ 是两个不同的角：$\theta$ 是 $E_0$ 与 $U$ 的夹角（决定有功），$\varphi$ 是电压与电流的夹角（决定功率因数/无功）。**调汽门改 $\theta$、调励磁改 $\varphi$**——把两个角的分工记清楚，同步电机的运行控制就不会乱。

## 6 小结

- 同步电机转速被电网频率**锁死**（$n = 60f/p$），是发电机的绝对主力；转子磁场由直流励磁主动建立。
- **功角特性** $P_{em} = \frac{E_0 U}{X_s}\sin\theta$：功角是功率的「弹簧」，$\theta > 90°$ 即失步。
- 并网四条件：**电压、相位、频率相同、相序一致**；并网后有功靠原动机、无功靠励磁。
- **励磁调节**改变无功：欠励吸收无功、过励发出无功；V 形曲线是最小电流/功率因数为 1 的运行轨迹。
- 同步调相机是「专供无功」的同步电机，新能源时代价值被重新发现。
- **关联预告**：功角特性直接构成《电力系统稳定性》里静态稳定判据（$\mathrm{d}P/\mathrm{d}\theta > 0$）的数学基础。
- 隐极电机功角特性为正弦、凸极电机叠加磁阻功率项；并网后有功靠汽门、无功靠励磁的分工贯穿调度运行。
