## 为什么从正弦稳态分析开始

生活中几乎不存在直流的世界：家里插座是 220 V/50 Hz 的交流电，电网里走的全是正弦波，电机、变压器、输电线路都在正弦激励下运行。上一节的电路基础处理的是电阻网络，但从电感、电容加入的那一刻起，电路的微分方程开始出现——而**正弦稳态分析**给出了一把最优雅的钥匙：**把微积分问题变成代数问题**。这就是相量法的威力，也是本专题一切交流设备（电机、变压器、电力系统）共同的分析语言。<span class="marginnote">为什么交流电统治世界？因为交流电可以用<strong>变压器</strong>轻松升降电压——高压输电损耗小、低压入户安全。这正是《磁路与变压器》那一节里「升压送电降损耗」结论的源头。而正弦波能保证变压器、电机等线性系统里「频率不变、只变幅值相位」，这是相量法成立的前提。</span>

从本节起，你会反复见到三个词：**相量**（把正弦量变复数）、**阻抗**（把元件变复数「电阻」）、**复功率**（把功率算成复数）。掌握它们，后面的每一台电机、每一段输电线路的建模都顺理成章。本节按邱关源《电路》第 8、9、11 章的脉络组织：相量法、阻抗与正弦稳态分析、以及作为频率响应开端的谐振。

## 1 正弦量与相量

**核心概念**：**正弦量**：随时间按正弦（余弦）规律变化的量，写成 $u(t) = U_m \cos(\omega t + \varphi)$。它由三个要素决定：**幅值 $U_m$**、**角频率 $\omega = 2\pi f$**、**初相位 $\varphi$**。

**核心概念**：**相量（phasor）**：利用欧拉公式，把正弦量映射为复数——用一个**幅值等于正弦量幅值、辐角等于初相位**的复数 $\dot{U} = U_m \angle \varphi$ 表示。相量只是正弦量的「复数化身」，它略去了随时间旋转的部分，只保留幅值与相位两个信息。

相量法成立的根本理由：**在线性电路中，各处的稳态响应频率都与激励相同**，于是「频率」这一维在方程两侧自动约掉，剩下幅值与相位两个未知数——正好一个复数能装下。于是，微积分方程变成了复代数方程。

**相量的运算规则**：两个同频正弦量相加，对应的相量按**平行四边形法则**作复数加减——因此「多个同频正弦的合成」退化为复数加法。乘以 $j$ 表示相位超前 90°（旋转因子），乘以 $e^{j\varphi}$ 表示相位平移 $\varphi$。**注意：相量的加减只对同频率正弦成立，不同频率必须分开计算后再相加**（这正是《网络函数》里频率响应逐点计算的原理）。

**电网为什么选 50/60 Hz**：频率影响变压器与电机的体积、损耗与感抗。频率越低，同样容量的变压器铁芯越笨重；频率越高，感抗、涡流与线路损耗越大。1880 年代交直电流之争后，西屋与通用电气分别推广 60 Hz（美洲）与 50 Hz（欧洲、中国）——**这个 120 多年前的工程选择，今天仍是各国电网与电器互不兼容的根源**。对相量法而言，频率是一个固定的已知数，无论 50 还是 60 Hz，方法本身完全一致。<span class="marginnote">欧拉公式 $e^{j\theta} = \cos\theta + j\sin\theta$ 是把正弦量「翻译」成复数的桥梁。相量记号上的那个点 $\dot{U}$ 提醒我们：这是复数，不是时域实数。工科学生第一次见 $j = \sqrt{-1}$（而非数学里的 $i$）就是在相量法里——电力系统习惯用 $j$ 以避开电流 $i$ 的符号冲突。</span>

## 2 阻抗与导纳

**核心概念**：**阻抗（impedance）**：在正弦稳态下，元件端电压相量与电流相量之比，记作 $Z = R + jX$。三个基本元件的阻抗分别是：

$$Z_R = R, \qquad Z_L = j\omega L, \qquad Z_C = \frac{1}{j\omega C} = -j\frac{1}{\omega C}$$

**重点：** 阻抗的实部 $R$ 是**电阻**（消耗有功），虚部 $X$ 是**电抗**（$X_L = \omega L$ 感抗为正、$X_C = -1/(\omega C)$ 容抗为负）——**电感电压超前电流 90°，电容电流超前电压 90°**，这个相位关系是交流世界的常识性结论。导纳 $Y = 1/Z$ 是阻抗的倒数。

**串联与并联**：串联阻抗相加 $Z = Z_1 + Z_2$，并联导纳相加 $Y = Y_1 + Y_2$——与直流电阻的规则完全同构，只是从实数换成了复数。

**相量图**：把各相量按幅值与相位画在复平面上，就得到**相量图（phasor diagram）**。它是一个直观的几何工具：串联电路以电流为基准，各元件电压相量首尾相接；并联电路以电压为基准，各支路电流相量首尾相接。**相量图上各段的方向与长度，直接告诉你谁领先、谁落后、差多少**——分析电机、变压器的电压平衡时，一张相量图胜过十行公式。

**阻抗的串联例**：RLC 串联时 $Z = R + j(\omega L - \frac{1}{\omega C})$。当 $\omega L > \frac{1}{\omega C}$ 时电路显感性（$Z$ 的幅角为正），当 $\omega L < \frac{1}{\omega C}$ 时显容性——**阻抗的「性质」随频率漂移**，这是谐振与频率响应分析（第 4 节）的铺垫。

**频率依赖**：感抗 $X_L = \omega L$ 随频率线性上升，容抗 $X_C = 1/(\omega C)$ 随频率反比下降——**高频信号「走不动」电感、却容易「穿过」电容**。这正是滤波器、旁路电容、电源去耦的物理直觉：大电容滤低频、小电容滤高频，电源板上并一大一小两个电容的原因就在这里。<span class="marginnote">阻抗的幅角就是电压电流的相位差 $\varphi$：$\tan\varphi = X/R$。$\varphi > 0$ 称「感性负载」（电压超前），$\varphi < 0$ 称「容性负载」。电网里绝大多数负载是感性的，所以要在变电站并联电容「补偿」——这正是《频率与电压调整》里无功补偿的电路根源。</span>

## 3 复功率与功率因数

**核心概念**：**复功率（complex power）**：$\tilde{S} = \dot{U}\dot{I}^* = P + jQ$，其中 $\dot{I}^*$ 是电流相量的共轭。它的实部 $P$ 是**有功功率**（W），虚部 $Q$ 是**无功功率**（var），模 $S = |\tilde{S}| = UI$ 是**视在功率**（VA）。

**核心概念**：**功率因数（power factor）**：$\cos\varphi = P/S$——有功与视在之比，衡量电能被「有效利用」的比例。功率因数低意味着线路里流过大量无功电流，白白增加损耗（$P_{loss} = I^2R$），所以电网要求提高功率因数，通常用并联电容进行**无功补偿**。

**重点：** 三个功率构成一个直角三角形：$S^2 = P^2 + Q^2$，$\varphi$ 是功率因数角。**有功功率是「真正做功」的，无功功率是「建立磁场/电场」所需的——电机、变压器都要靠无功建立磁场才能运转**，所以无功不是「没用的功率」，而是「不能缺少但不直接做功」的功率。

**瞬时功率的分解**：瞬时功率 $p(t) = ui$ 可以拆成两部分——恒定分量 $P = UI\cos\varphi$（有功，单位时间真正转化为热/机械功的平均功率）与频率为 $2\omega$ 的振荡分量。振荡分量在一个周期内正负交替，平均为零，对应能量在电源与储能元件之间的往复交换，其幅值就是无功 $Q$。<span class="marginnote">从这个角度看，<strong>无功功率是能量「来回搬运」的速率度量</strong>：电感存了又放、放了又存。虽然它不对外做功，但在线路里一样产生 $I^2R$ 损耗、占用导线截面，所以电网既要有功平衡（频率）、也要无功平衡（电压）——一句话，有功与无功是「一起装车」的。</span>

**提高功率因数的方法**：感性负载并联电容器，电容的容性无功抵消电感的感性无功，使总无功 $Q$ 下降、功率因数 $\cos\varphi$ 提高。**功率因数是电力企业考核用户的经济指标**：过低会被加收电费，因为它浪费了线路与发电设备容量。

**视在功率为什么用 VA**：变压器的容量（如 1000 kVA）、发电机的额定容量都用**视在功率**标注，而不是有功功率——因为铁芯与绕组承载的是电流与电压，与功率因数无关。**同一台变压器，接 $\cos\varphi = 1$ 的负载能输出 1000 kW，接 $\cos\varphi = 0.5$ 的负载只能输出 500 kW**。这正是电力系统逼着用户提高功率因数的经济原因。

**功率的测量**：工程上用**功率表**（瓦特表）直接测有功功率，其读数正比于 $UI\cos\varphi$；无功功率则用无功功率表或由有功表与功率因数换算得到。**三个功率是「一块表测一个维度」**——理解这一点，有助于后面读电力系统的量测数据（见《电力调度与运行》）。

## 4 谐振：RLC 电路的共振

**核心概念**：**谐振（resonance）**：当电感的感抗与电容的容抗恰好相等（$X_L = X_C$）时，电路发生谐振，电压电流同相、功率因数等于 1、阻抗的虚部为零。按谐振元件的连接方式分**串联谐振**与**并联谐振**。

谐振的本质是**能量在电感磁场与电容电场之间往复交换**：谐振时二者储能量互补，电路对外只需补偿电阻损耗。因此谐振回路的「锐度」由储能与耗能之比决定——这个比值就是品质因数 $Q$。<span class="marginnote">把谐振想成秋千：你每次推的时机正好与摆动同步，摆动越来越大——外源只需补充摩擦损耗，这就是<strong>谐振时阻抗最小、电流最大</strong>的直觉。RLC 回路里电容电感轮流「推」对方，电阻负责「摩擦」。</span>

**串联谐振**（RLC 串联，$f_0 = \frac{1}{2\pi\sqrt{LC}}$）：谐振时阻抗最小（$Z = R$）、电流最大；电感与电容上的电压会**互相抵消但各自可能远大于电源电压**（品质因数 $Q$ 倍）——这就是「过电压」现象，谐振时元件可能被高电压击穿。

**谐振过电压在电力系统里是真实的威胁**：当电网中出现由线路电容与变压器电感构成的谐振回路，且参数巧合地满足谐振条件时，系统会产生远超正常运行值的过电压，威胁绝缘——这正是《操作过电压》《绝缘配合》要防范的对象之一。

**并联谐振**（RLC 并联）：谐振时导纳最小、阻抗最大、总电流最小，支路内电流很大。

**核心对比表：串联谐振与并联谐振**

| 项目 | 串联谐振 | 并联谐振 |
| --- | --- | --- |
| 电路结构 | R、L、C 串联 | R、L、C 并联 |
| 谐振频率 | $\omega_0 = 1/\sqrt{LC}$ | 近似 $\omega_0 = 1/\sqrt{LC}$ |
| 谐振时阻抗 | 最小（$=R$） | 最大 |
| 谐振时电流/电压 | 电流最大、元件过电压 $QU$ | 总电流最小、支路过电流 |
| 典型用途 | 选频（收音机）、信号源 | 滤波、阻波、高频电路选频 |
| 主要风险 | 过电压击穿绝缘 | 过电流烧毁元件 |<span class="marginnote">谐振是双刃剑：收音机用<strong>串联谐振选频</strong>——只有频率落在谐振点附近的电台信号才能在回路里产生大电流；电力系统却要<strong>避免谐振</strong>——过电压可能击穿绝缘（见《操作过电压》）。同一现象，用途取决于你站在哪一边。</span>

## 5 公式解析：谐振频率与品质因数

串联 RLC 电路在谐振点附近的行为，由两个量完全刻画：

$$
\omega_0 = \frac{1}{\sqrt{LC}}, \qquad Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 C R}
$$

- **第一步，谐振条件**：令 $X_L = X_C$ 即 $\omega_0 L = 1/(\omega_0 C)$，两边同乘 $\omega_0 C$ 得 $\omega_0^2 LC = 1$，于是 $\omega_0 = 1/\sqrt{LC}$——谐振频率只由 $L$、$C$ 决定，与 $R$ 无关。
- **第二步，品质因数**：$Q$ 定义为谐振时电感（或电容）储能与电阻耗能的比值，等于 $\omega_0 L/R$。它衡量谐振回路的「尖锐程度」。
- **第三步，选频带宽**：通频带宽度 $BW = \omega_0/Q$。$Q$ 越大，回路越「尖锐」，选频能力越强，但对外来频率的抑制也越强——**收音机的选择性由 $Q$ 决定**。
- **第四步，联系网络函数**：谐振曲线其实就是阻抗幅值 $|Z(\omega)|$ 对频率的响应，与《网络函数》里幅频特性 $|H(j\omega)|$ 的概念一脉相承——谐振分析是频率响应分析的第一个实例。从「相量→阻抗→复功率→谐振」这条线走下来，交流电路分析的主干已经齐全。

**辨析｜易错点：** 谐振时电感电压 $U_L = QU$、电容电压 $U_C = QU$（$U$ 为电源电压）——串联谐振的「过电压」是 $Q$ 倍而不是「相等」。这一结论在电力系统的过电压分析里直接相关，千万别把谐振当成都压无害。

**数值算例**：设串联 RLC 电路 $L = 1\,\text{mH}$、$C = 1\,\text{nF}$、$R = 10\,\Omega$，电源电压 $U = 1\,\text{V}$。谐振频率 $f_0 = 1/(2\pi\sqrt{10^{-3}\times 10^{-9}}) \approx 159\,\text{kHz}$；品质因数 $Q = \omega_0 L / R = 2\pi\times159\times10^3\times 10^{-3}/10 \approx 100$。于是谐振时电感电压 $U_L = Q\cdot U = 100\,\text{V}$——**1 V 的电源竟然在元件上激起 100 V 电压**，这就是「过电压」的实感。而在偏离谐振点处，电流迅速衰减，回路表现出极强的选频性。通频带 $BW = f_0/Q \approx 1.6\,\text{kHz}$，说明只有落在 159 kHz 附近约 1 kHz 宽度内的信号才能被显著放大。这个「选频」行为正是调幅收音机中频回路、振荡器选频网络（见第二篇《波形发生与变换》）的物理基础。

## 6 小结

- **相量法把正弦稳态分析从微积分变成复数代数**：频率自动约掉，只剩幅值相位。
- **阻抗** $Z = R + jX$ 是复数化的元件特性：电感正电抗、电容负电抗，90° 相位差是常识。
- **复功率** $\tilde{S} = P + jQ$：有功、无功、视在构成功率三角形；功率因数 $\cos\varphi$ 低则线路损耗高。
- **谐振频率** $\omega_0 = 1/\sqrt{LC}$ 只由 $L$、$C$ 决定；品质因数 $Q$ 决定选频的尖锐程度与过电压倍数。
- 谐振是**选频的工具、也是过电压的风险**——用途与风险取决于应用场景。
- **功率因数低 = 线路损耗高**，电网以并联电容无功补偿来提高功率因数，这是《频率与电压调整》的核心铺垫。
- **相量图**是直观工具，串联以电流为基准、并联以电压为基准，谁领先谁落后一眼可辨。
- 本节与《电路基础》合起来，构成了后面每一台电机、每一段线路交流建模的公共语言。
- **易错提醒**：相量运算只对同频正弦有效；阻抗串联相加、导纳并联相加，方向别搞反。
- **关联预告**：无功补偿、功率因数这些概念在三相系统与电力系统中会以「三相对称」的形式放大出现——本节是它们的单相底座。

在下一节，我们把单相交流推广到工程现实中最普遍的形态——**三相电路**，并引入对称分量法处理不对称问题。
