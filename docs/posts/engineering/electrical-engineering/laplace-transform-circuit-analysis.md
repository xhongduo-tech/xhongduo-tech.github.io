## 为什么从拉普拉斯变换开始

前面的一阶、二阶电路，每换一次电路结构就要重解一次微分方程；正弦稳态虽简单，却只能处理「纯正弦 + 已到稳态」。**能不能有一种方法，既不限制波形、也不限制暂态，还只用代数？** 拉普拉斯变换就是答案。<span class="marginnote">拉普拉斯变换（Laplace transform）得名于数学家皮埃尔-西蒙·拉普拉斯，但把它系统用于求解微分方程的是英国工程师 Oliver Heaviside 的「运算微积分」。Heaviside 先于严格数学用「算子法」解电路，数学家花了二十年才给他补上合法性证明——工程直觉常走在数学严谨前面。</span>

它把时间函数 $f(t)$ 变成复变量 $s$ 的函数 $F(s)$，把求导变成乘以 $s$、积分变成除以 $s$，**把微分方程变成代数方程**。与相量法相比，$s = \sigma + j\omega$ 是复频率：相量法是 $s = j\omega$ 的特例（纯正弦稳态），拉普拉斯变换则通吃暂态与任意波形。第二级《复变函数与积分变换》已讲过它的数学，这一节专注它在电路里的**工程用法**。

## 1 定义与常用变换对

**核心概念**：**拉普拉斯变换**：把时间函数 $f(t)$（$t\ge 0$）映射为复频域函数

$$
F(s) = \mathcal{L}\{f(t)\} = \int_0^{\infty} f(t)\, e^{-st}\, dt
$$

$s = \sigma + j\omega$ 是**复频率**，单位 $\text{s}^{-1}$。变换把「随时间演化的波形」翻译成「在复平面上按频率分布的信息」。

几个必须背下来的常用变换对：

| 时域 $f(t)$ | 复频域 $F(s)$ | 说明 |
| --- | --- | --- |
| $\delta(t)$ 冲激 | $1$ | 最纯的瞬变 |
| $\varepsilon(t)$ 阶跃 | $\frac{1}{s}$ | 开关动作 |
| $t\varepsilon(t)$ 斜坡 | $\frac{1}{s^2}$ | 线性变化 |
| $e^{-\alpha t}\varepsilon(t)$ | $\frac{1}{s+\alpha}$ | 指数衰减 |
| $\cos\omega t\,\varepsilon(t)$ | $\frac{s}{s^2+\omega^2}$ | 正弦 |
| $\sin\omega t\,\varepsilon(t)$ | $\frac{\omega}{s^2+\omega^2}$ | 正弦 |

**两个最重要的性质**（电路分析全靠它们）：

- **线性**：$\mathcal{L}\{af_1 + bf_2\} = aF_1 + bF_2$。
- **微分性质（含初始条件）**：$\mathcal{L}\left\{\frac{df}{dt}\right\} = sF(s) - f(0_-)$。

**重点：** 微分性质里的 $-f(0_-)$ 项，正是初始储能的「报关单」——它让拉普拉斯变换能天然处理暂态，而不像相量法那样假设「早已稳态」。

## 2 复频域的元件模型：运算阻抗与初始折算

在复频域里，每个元件都变成「阻抗 + 附加电源」的组合。

- **电阻** $R$：$U_R(s) = R I_R(s)$，仍是电阻，无附加项。
- **电感** $L$：$U_L(s) = sL\, I_L(s) - Li_L(0_-)$。写成 $Z_L(s) = sL$ 的阻抗，再串联一个附加电压源 $Li_L(0_-)$——初始电流的「遗产」。
- **电容** $C$：$U_C(s) = \frac{1}{sC} I_C(s) + \frac{u_C(0_-)}{s}$。$Z_C(s) = \frac{1}{sC}$，再串联一个附加电压源 $\frac{u_C(0_-)}{s}$——初始电压的「遗产」。

**核心概念**：**运算阻抗（operational impedance）** $Z(s)$：复频域里元件的「阻抗」$R$、$sL$、$\frac{1}{sC}$。它与相量域的 $j\omega L$、$\frac{1}{j\omega C}$ 完全同构，只是 $j\omega$ 换成了 $s$——**把相量法里的所有公式里的 $j\omega$ 换成 $s$，就得到复频域版本**。

**辨析｜易错点：** 初始条件的折算方向：电感的附加电源 $Li_L(0_-)$ 与电流方向一致，电容的附加电源 $\frac{u_C(0_-)}{s}$ 与电压方向一致。折算错了，初始条件符号就反了——复频域法最常出错就在这一处。判断口诀：**附加电源代表「初始储能想把电路推向的方向」**，画图时顺着这个直觉标方向即可。

## 3 复频域分析的完整步骤

把「微分方程 → 代数 → 反变换」的全流程标准化：

1. **换路后的电路**，把各元件换成运算阻抗 $Z(s)$，并串入初始条件对应的附加电源。
2. **写复频域方程**：KCL、KVL 在复频域照常成立，用节点法/回路法列代数方程——**所有直流分析方法原样可用，实数换成 $s$ 的函数**。
3. **解代数方程**，得待求量的象函数 $F(s)$。
4. **部分分式展开 + 查表反变换**，得时域解 $f(t)$。

**重点：** 第四步是唯一需要技巧的环节。$F(s)$ 一般是两个多项式之比，用**部分分式展开**拆成简单项之和，每一项对应一个已知变换对。若分母有单实根 $s_1$，对应项 $\frac{K}{s - s_1}$，反变换是 $Ke^{s_1 t}$；若分母有共轭复根 $-\alpha \pm j\omega_d$，对应项的时域形式是衰减正弦。<span class="marginnote">部分分式展开的系数 $K = \lim_{s\to s_1}(s - s_1)F(s)$ 叫「留数」。第二级《复变函数与积分变换》讲过留数定理，这里用到的只是它在有理分式上的初等形式。拉普拉斯反变换本质是沿复平面垂直直线的围线积分，工程上一般查表，数学上才是留数——两层视角都值得保留。</span>

## 4 公式解析：RLC 电路复频域解

用复频域法重解 RLC 串联电路（电容初始电压 $U_0$，零输入，$t=0$ 换路）。复频域方程是纯代数：

$$
\left(sL + R + \frac{1}{sC}\right) I(s) = \frac{U_0}{s} - Li_L(0_-)
$$

逐项拆解：

- **第一步，写运算阻抗之和**：$sL + R + \frac{1}{sC}$ 是串联总运算阻抗，与 $j\omega L + R + \frac{1}{j\omega C}$ 同构。
- **第二步，写右边附加电源**：$\frac{U_0}{s}$ 是电容初始电压折算的电压源，$Li_L(0_-)$ 是电感初始电流折算的电压源，方向按初始储能推。若 $i_L(0_-) = 0$，该项为零。
- **第三步，解出 $I(s)$**：$I(s) = \frac{U_0/s}{sL + R + 1/(sC)}$，整理成分式。
- **第四步，部分分式展开并反变换**：分母 $s^2 + \frac{R}{L}s + \frac{1}{LC}$ 的根就是特征根 $s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2}$——**与第二章特征方程一模一样**。反变换后自然得到过阻尼/临界/欠阻尼三种时域形态。

**这条链路的精妙之处**：在时域要分三种情形讨论的二阶微分方程，在复频域只是一个代数分式的反变换；三种情形只是分母根的三种分布——**微分方程的分类问题，在复频域变成了多项式求根问题**。

## 5 复频域与相量法、频率响应的关系

三种分析方法的谱系值得理清：

| 方法 | 适用 | 变量 | 本质 |
| --- | --- | --- | --- |
| 直流电路分析 | 恒定激励 | 实数 | 纯代数 |
| 相量法 | 正弦稳态 | $j\omega$ | 代数 + 复阻抗 |
| 拉普拉斯变换 | 任意激励 + 暂态 | $s = \sigma + j\omega$ | 代数 + 运算阻抗 |

**相量法是拉普拉斯变换在 $s = j\omega$ 的特例**：若激励是纯正弦且暂态已消失，令 $s = j\omega$，运算阻抗退化为相量阻抗，复频域解退化为相量解。而把网络函数 $H(s)$ 沿虚轴取值 $H(j\omega)$，就得到**频率响应**——幅频、相频曲线——这正指向下一节《网络函数》。<span class="marginnote">「令 $s = j\omega$」这步把暂态分析与稳态分析、时域与频域缝在了一起：同一个传递函数，在虚轴上读出频率特性，在复平面上读出稳定性与暂态模式。控制理论里「根轨迹」「波特图」正是从这同一个 $H(s)$ 出发的两张不同画像。</span>

**辨析｜易错点：** 不要以为拉普拉斯变换「取代」了相量法。相量法只需正弦稳态、计算量小、物理直观，工程上日常交流分析照用相量；拉普拉斯变换是「重武器」，用于含暂态、含初始储能、任意波形的场合。**方法的选择取决于问题里有没有暂态**。

## 6 拉普拉斯变换的扩展视野

拉普拉斯变换的价值远不止「解电路」，它是整个工程数学的通用工具：

- **控制系统**：传递函数 $G(s)$ 是控制理论的语言——稳定性（极点位置）、响应（阶跃/冲激）、设计（校正网络）全在 $s$ 域进行（见《自动控制原理》）。
- **信号与系统**：LTI 系统的分析统一在 $s$ 域（连续）与 $z$ 域（离散）——**拉普拉斯变换是信号与系统课程的数学主干**。
- **滤波器设计**：从 $H(s)$ 的零极点摆放到模拟滤波器的实现（巴特沃斯、切比雪夫），全在 $s$ 域设计。
- **偏微分方程**：用拉普拉斯变换把 PDE 变成 ODE（对时间变量变换），求解传热、波动问题——**它是数学物理方程的经典工具**（见第二级《偏微分方程》）。

**核心概念**：**s 域的统一视角**：$s = \sigma + j\omega$ 同时携带「衰减（$\sigma$）与振荡（$\omega$）」两个信息——**拉普拉斯变换把「暂态（衰减）与稳态（振荡）」装进了同一个复平面**。相量法只取了虚轴（$j\omega$，纯稳态），拉普拉斯变换取整个复平面（含暂态）——**从相量到拉普拉斯，是「视角从一条线扩展到一个面」**。

**重点：** 学电路时掌握的拉普拉斯变换，会在后续几乎每一门工程课里复用——**它是「一劳永逸」的数学投资**。这一节把「怎么用在电路上」讲透，你就已经拿到了 $s$ 域分析的钥匙；后面的课程只是把这把钥匙用到新门锁上。

## 7 小结

- **拉普拉斯变换**把时间函数变成复频域函数，微分性质把求导变成乘以 $s$ 并「报关」初始条件。
- 元件在复频域变成**运算阻抗** $R$、$sL$、$\frac{1}{sC}$ 加附加电源——初始储能折算其中。
- 分析流程：换路电路 → 运算阻抗网络 → 代数方程 → 部分分式展开 → 查表反变换。
- 二阶微分方程的分类（过阻尼/临界/欠阻尼）在复频域退化为**分母多项式求根**。
- **相量法是 $s = j\omega$ 的特例**；$H(j\omega)$ 沿虚轴取值即频率响应，指向下一节《网络函数》。

在下一节，我们给「电路对信号的加工能力」一个统一的描述——不看具体电路，只看输入输出关系，这就是**网络函数**。
