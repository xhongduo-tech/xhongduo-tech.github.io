## 为什么从等效变换开始

上一节我们用基尔霍夫定律建立了电路方程。但真实电路常常几十个元件连成网状，一上来就列方程并不明智。工程师的第一反应永远是**化简**：能不能把一大片电阻「折叠」成一个，让电路图从密林变成一条小径？**等效变换（equivalent transformation）**就是这种化简的工具。它回答的问题很朴素：**从一对端子看进去，这团电阻到底「相当于」多大的一个电阻？**<span class="marginnote">「从端子看进去」这个视角贯穿整个电路理论：后面戴维南定理、二端口网络、含源网络的化简，全都是同一个动作——站在某个端口处，把背后的一团东西「翻译」成一个更简单的等效物。等效的思想还会蔓延到电机学里的变压器等效电路、控制里的传递函数化简。</span>

本节的另一层意义是训练**代数直觉**：电阻串并联公式看起来只是「加加除除」，但把它写成电导形式、推到极限、推广到 $n$ 个元件，每一步都在打磨你「把一个表达式化简成最优雅形式」的能力——这与第一级《基础数学》里化简代数式、第二级《线性代数》里矩阵消元是同一种素养。

## 1 等效：从「看不清」到「看得清」

先立定义。**核心概念**：**等效（equivalence）**：若两个一端口网络 $N_1$ 与 $N_2$ 的端口电压-电流关系完全相同——即接上任意相同的外部电路，端口电压 $u$ 与电流 $i$ 的关系都一致——则称两者等效。

**重点：等效是对「端口外部」而言的，不是对网络内部而言的。** 两个等效网络内部的功耗、电流分布可以完全不同，外部电路毫不知情——它只感知到「这对端子的 $u$-$i$ 关系」。所以等效不是「长得像」，而是「行为像」。

![串联与并联的等效电阻](/images/electrical-engineering/resistance-equivalent-transformation-1.svg)

上图的两种接法覆盖了绝大多数化简场景：**串联**是「同一个电流流过全部元件」，**并联**是「同一个电压加在全部元件上」。搞清楚「哪一个量相同」，是选择公式的第一步。

对于纯电阻一端口网络，端口处的 $u$-$i$ 关系就是一条过原点的直线 $u = R_{\text{eq}}\,i$，斜率 $R_{\text{eq}}$ 称为**等效电阻（equivalent resistance）**。求等效电阻是本章一切工作的目标：把网络内部的串并联结构逐层折叠，最终得到这一个数。<span class="marginnote">「从外部看是电阻」这句话背后是线性：只要网络全由线性电阻组成，端口特性必然是过原点的直线。若网络里藏了二极管或晶体管，这条线就会弯——那就不是本章的领地，而是后面《非线性电路初步》的内容了。</span>

## 2 串联与分压

**串联（series）**：多个电阻首尾相连，流过同一电流。

**核心概念**：$n$ 个电阻串联的等效电阻等于各电阻之和：

$$
R_{\text{eq}} = R_1 + R_2 + \cdots + R_n
$$

为什么直接相加？因为串联时各电阻电流相同（KCL），端口总电压等于各电压之和（KVL）：$u = u_1 + u_2 + \cdots + u_n = (R_1 + R_2 + \cdots + R_n)\,i$。

**分压公式**：串联电阻两端的电压按电阻大小**正比分配**。设总电压为 $u$，则第 $k$ 个电阻上的电压为：

$$
u_k = \frac{R_k}{R_1 + R_2 + \cdots + R_n}\,u
$$

**直觉**：电阻越大，分到的电压越多——就像越陡的坡，同样流量下需要的水头落差越大。两个电阻串联时的特例 $u_1 = \dfrac{R_1}{R_1+R_2}u$ 是工程师口算的常客。

## 3 并联与分流

**并联（parallel）**：多个电阻两端分别接在一起，承受同一电压。

**核心概念**：$n$ 个电阻并联，等效电阻的倒数等于各电阻倒数之和；换用电导更方便：

$$
\frac{1}{R_{\text{eq}}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n},
\qquad G_{\text{eq}} = G_1 + G_2 + \cdots + G_n
$$

其中 $G_k = 1/R_k$ 为电导（单位西门子 S）。为什么倒数和？因为并联时各电阻电压相同（KVL），端口总电流等于各电流之和（KCL）：$i = i_1 + i_2 + \cdots + i_n = (G_1 + G_2 + \cdots + G_n)\,u$。

**分流公式**：并联电阻中的电流按电导大小**正比分配**。设总电流为 $i$，则第 $k$ 条支路电流为：

$$
i_k = \frac{G_k}{G_1 + G_2 + \cdots + G_n}\,i
$$

**直觉**：电阻越小（电导越大），分到的电流越多——就像排水管越粗、流量越大。两个电阻并联的特例 $i_1 = \dfrac{R_2}{R_1 + R_2}i$ 是分压公式的「镜像」，两者互为对偶。<span class="marginnote">分压公式用「电阻比」，分流公式用「对侧电阻比」——这两条特例是初学者最容易记串的地方：并联分流时，电流大部分走电阻小的支路，所以公式分子是「对侧电阻」。把这个逻辑想通，就不用背公式了。</span>

## 4 公式解析：等效电阻的量纲与极限

把两个特例放在一起看，能读到很多信息。

$$
R_{\text{eq,串}} = R_1 + R_2, \qquad
R_{\text{eq,并}} = \frac{R_1 R_2}{R_1 + R_2}
$$

- **第一步，量纲检查**：串联式是「欧姆 + 欧姆 = 欧姆」；并联式分子是 $\Omega \times \Omega = \Omega^2$，分母是 $\Omega$，相除仍是 $\Omega$。两条公式的量纲都正确，这是它们「长得像可信公式」的第一道保险。
- **第二步，看极限**：并联式中令 $R_2 \to \infty$（开路），得 $R_{\text{eq,并}} \to R_1$——**电阻与开路并联，等于它自己**；令 $R_2 \to 0$（短路），得 $R_{\text{eq,并}} \to 0$——**任何电阻与短路并联都被短路掉**。极限行为与直觉完全吻合。
- **第三步，看嵌套**：并联式可以改写成 $R_{\text{eq,并}} = \dfrac{R_1}{1 + R_1/R_2}$。当 $R_1 \ll R_2$ 时近似等于 $R_1$，这给出工程里常用的估算——**两个电阻并联，等效电阻总小于其中较小的那个**。

**重点：并联等效电阻「永远小于最小的那个电阻」，串联等效电阻「永远大于最大的那个」。** 这两个不等式是口算与验算的利器：算完发现并联结果比任一支路还大，立即知道算错了。

### 两步折叠的完整演示

求 $R_1 = 6\,\Omega$ 与 $R_2 = 3\,\Omega$ 并联、再与 $R_3 = 4\,\Omega$ 串联的等效电阻。

- **第一步，折叠并联**：$R_{12} = \dfrac{6 \times 3}{6 + 3} = 2\,\Omega$。自检：$2 < \min(6, 3) = 3$，✓ 并联结果小于最小支路。
- **第二步，折叠串联**：$R_{\text{eq}} = R_{12} + R_3 = 2 + 4 = 6\,\Omega$。自检：$6 > \max(2, 4) = 4$，✓ 串联结果大于最大元件。

两步做完，整团网络折叠成一个 $6\,\Omega$。这个「折叠-自检-再折叠」的节奏，就是等效变换的标准动作：**每一步都用不等式验一遍，符号错误根本活不到最后。**

## 5 Y-Δ 变换：拆不掉的桥

串并联公式再熟练，也拿「桥式电路」没办法——**四个电阻构成电桥，既不是纯串联也不是纯并联**。这时需要把电阻网络的两种接法互相翻译：**Y 形（星形）接法**与**Δ 形（三角形）接法**。

设 Y 形三电阻为 $R_1, R_2, R_3$（共接于中心点），对应 Δ 形三电阻 $R_{12}, R_{23}, R_{31}$ 接在各节点对之间，等效条件为：

$$
R_{12} = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_3}, \qquad
R_{1} = \frac{R_{12} R_{31}}{R_{12} + R_{23} + R_{31}}
$$

第一条是 Y→Δ（分子为两两乘积之和，除以对侧电阻），第二条是 Δ→Y（相邻两电阻乘积，除以三相之和）。<span class="marginnote">对称特例最好记：若 Y 形三电阻相等都为 $R_Y$，则 Δ 形三电阻相等且 $R_\Delta = 3R_Y$。桥式电路、三相交流负载的星三角变换，全靠这一条。后面《三相电路》里负载的星形-三角形接法换算，就是它的直接应用。</span>

**方法**：遇到被「桥」卡住的电阻网络，把其中一组 Y 或 Δ 用上述公式换成对偶接法，原本纠缠的拓扑立刻被摊平成串并联，再逐层折叠。这是本节唯一需要「背公式」的地方，其余都能靠定义推出来。

## 6 易错辨析

**辨析｜易错点 1：串联看电流相同、并联看电压相同，顺序别记反。** 串联是「同一个电流流过所有元件」，并联是「同一个电压加在所有元件上」。分不清时回到 KCL/KVL：串联断开任何一处整个电路没电，并联各支路独立。

**辨析｜易错点 2：两个电阻并联的快捷公式 $R_1 R_2/(R_1+R_2)$ 只对「两个」成立。** 三个并联没有类似的单项快捷式，必须用倒数和；若强行用两次快捷式会算错——这是高频失分点。

**辨析｜易错点 3：等效是对外部而言的，内部损耗不守恒。** 两个等效网络端口 $u$-$i$ 关系相同，但内部的电流分布、发热可以截然不同。分析「哪个电阻更热」必须回到原网络，不能拿等效网络来算内部量。

## 7 小结

- **等效**：一端口网络的端口 $u$-$i$ 关系相同则等效；纯电阻网络的等效电阻是 $u = R_{\text{eq}} i$ 的斜率。
- **串联**：$R_{\text{eq}} = \sum R_k$，分压正比于电阻。
- **并联**：$G_{\text{eq}} = \sum G_k$，分流正比于电导；$R_{\text{eq,并}} < \min R_k$。
- **Y-Δ 变换**：桥式电路靠它摊平，对称时 $R_\Delta = 3R_Y$。
- **量纲与极限**是检验公式可信度的第一道关卡。

在下一节，我们将离开纯电阻，面对「电路里有多个电源」的普遍情形。届时会发现一个更强大的化简思路：**叠加定理**与**戴维南定理**——把整块含源网络折叠成一个电压源和一个电阻。
