## 为什么从电力调度开始

电网是一台「实时直播的机器」：负荷每秒在变、发电要跟着变、还要保证安全与经济。谁来指挥这一切？**调度中心**。它像交通指挥中心 + 生产调度室 + 应急指挥部的结合体：提前排计划（机组组合）、实时看状态（SCADA）、自动调出力（AGC）、事故时发指令（调度处置）。<span class="marginnote">电力调度是电力系统的「大脑」：中国实行「统一调度、分级管理」，国调—网调—省调—地调—县调五级调度，各管各的电压等级与范围。调度员的每个决定都牵动万家灯火——他们是电力系统里「责任最重、信息量最大」的岗位，培养一个合格调度员需要多年实践。</span>

这一节讲调度体系与负荷预测、经济调度（等耗量微增率）、机组组合、安全约束，以及调度自动化系统 SCADA/EMS。

## 1 调度体系与负荷预测

**核心概念**：**分级调度**：全国电网按「统一调度、分级管理」组织，各级调度中心管理相应电压等级与区域，逐级下达发电计划、执行调度指令。

**核心概念**：**负荷预测**：对未来负荷（次日、次日各时段）的估计。它是调度工作的起点——**先预测负荷，才能排发电计划**。方法：历史数据 + 气象因素 + 统计/智能算法（回归、时间序列、神经网络）。

**负荷曲线**：负荷随时间变化的曲线，有**日负荷曲线、周负荷曲线、年负荷曲线**。日负荷有高峰（白天、晚高峰）与低谷（深夜），调度必须跟着曲线安排出力——**调峰、调频、调压是调度日常的三大任务**。<span class="marginnote">负荷预测的精度直接决定发电成本：预测偏大，多开机组浪费；预测偏小，备用不足、可能拉闸。现代调度用「短期负荷预测（次日 96 点）+ 超短期预测（实时前推几分钟）」双轨——与第四级《大模型部署》里「负载预测 + 弹性伸缩」的思路同构：<strong>预测越准，资源浪费越少</strong>。</span>

## 2 经济调度：等耗量微增率

**核心概念**：**经济调度（economic dispatch）**：在满足负荷与安全约束下，**使全网发电总成本最小**的机组出力分配。

每台发电机的燃料成本 $F_i(P_i)$ 是出力的二次函数（曲线）。经济调度的最优条件是**等耗量微增率准则**：

$$
\frac{dF_1}{dP_1} = \frac{dF_2}{dP_2} = \cdots = \lambda
$$

**核心概念**：**耗量微增率** $\frac{dF_i}{dP_i}$：增加单位出力所增加的成本。**经济调度的核心思想：让所有机组的边际成本相等**——如果一台机组比另一台「便宜」（边际成本低），就多让它发电，直到它们的边际成本拉平。<span class="marginnote">「边际成本相等」是最优化理论里 KKT 条件的经典体现（见第二级《最优化理论》）：约束下求极值，拉格朗日乘子让所有变量的边际代价相等。经济调度是最优化方法在电力系统的第一个、也是最经典的应用——<strong>一台台机组的最优分配，背后是数学最优化与工程成本的最小化统一</strong>。</span>

**网损修正**：考虑线路损耗后，微增率准则要修正（乘网损修正系数），因为远离负荷的机组发电会多耗线损。

## 3 公式解析：等微增率准则

两台机组承担总负荷 $P_L = P_1 + P_2$，成本 $F_1(P_1) + F_2(P_2)$ 最小化：

$$
\min F_1(P_1) + F_2(P_2), \qquad s.t.\ P_1 + P_2 = P_L
$$

逐项拆解：

- **第一步，构造拉格朗日函数**：$\mathcal{L} = F_1 + F_2 + \lambda(P_L - P_1 - P_2)$。
- **第二步，取极值条件**：$\frac{\partial\mathcal{L}}{\partial P_1} = \frac{dF_1}{dP_1} - \lambda = 0$、$\frac{\partial\mathcal{L}}{\partial P_2} = \frac{dF_2}{dP_2} - \lambda = 0$。
- **第三步，联立得等微增率**：$\frac{dF_1}{dP_1} = \frac{dF_2}{dP_2} = \lambda$——**两台机组的边际成本相等**。
- **第四步，读工程含义**：$\lambda$ 就是「系统的边际电价」——**全网统一边际成本**，这正是电力市场现货电价的理论来源（见《电力市场》）！

**这条公式的深远意义**：从调度优化到市场定价，$P_i$ 的分配从「调度员算」变成「市场决定」——但最优点仍是「边际成本相等」。**调度与市场，共用同一个经济最优的数学内核**。

## 4 机组组合与安全约束

**核心概念**：**机组组合（unit commitment）**：决定**哪些机组开、哪些机组停**（经济调度是决定「开着的机组各发多少」）。它比经济调度多一层「开关」决策，是更复杂的**混合整数规划**问题——因为机组有最小出力、启停时间、爬坡速率等约束。

**机组组合的约束**：
- 负荷平衡（各时段总出力 = 负荷）；
- 旋转备用（总出力 + 备用 ≥ 负荷 + 可能事故）；
- 机组最小启停时间、爬坡速率；
- 网络安全（N-1 校核、线路潮流不越限）。

**核心概念**：**安全约束调度**：在满足网络安全（N-1）前提下的经济调度——「经济」必须服从「安全」。调度计划要经过**安全校核**才能执行。

**重点：** 机组组合解决「开哪些」，经济调度解决「开着的发多少」——**先组合、后分配**，层层递进。现代调度用安全约束机组组合（SCUC）+ 安全约束经济调度（SCED）作为日前计划的标配。<span class="marginnote">机组组合的「混合整数 + 大规模约束」在计算上很棘手，是现代电力优化软件的核心难点——与第四级《大模型部署》里「算力调度 + 任务编排」的复杂度同源：既要选哪些机器、又要排怎么分配，还是离散+连续的混合优化。这类问题靠分支定界、启发式、以及近年的大模型辅助求解。</span>

## 5 调度自动化：SCADA 与 EMS

**核心概念**：**SCADA（数据采集与监控）**：实时采集全网的电压、电流、功率、开关状态，远程监控与操作——调度的「眼睛和手」。

**核心概念**：**EMS（能量管理系统）**：在 SCADA 之上的一整套高级应用软件——**状态估计、潮流计算、经济调度、安全分析、负荷预测**——调度的「大脑」。

**核心概念**：**状态估计**：用冗余的 SCADA 量测数据，估计全网最可信的运行状态（修正坏数据、补缺失量测）——它是 EMS 一切高级应用的数据基础。

**AGC（自动发电控制）**：调度自动化自动执行二次调频——监测频率与联络线功率，自动调整指定机组出力。**AGC 是频率调整的自动化实现**（见《频率与电压调整》）。

**重点：** 调度中心的发展脉络：从人工电话调度 → SCADA 监控 → EMS 高级应用 → 调度云/数字电网。**数据是调度的血液，模型是调度的骨架，算法是调度的决策力**。<span class="marginnote">SCADA/EMS 的「数据采集 → 状态估计 → 决策优化 → 下发控制」闭环，与第四级《AI 智能体》的「感知 → 建模 → 规划 → 执行」框架高度同构。调度自动化是「工业级智能体」的先行者——它比大模型 Agent 早几十年实现了「感知-决策-控制」的自动化闭环。</span>

## 6 事故处置与黑启动

**事故处置**：发生事故（跳机、跳线）时，调度按**事故处理预案**指挥：判断故障影响、调整运行方式、恢复供电——优先保人身、保电网、保重要用户。

**核心概念**：**黑启动（black start）**：大停电后，用具备自启动能力的电源（如水电机组、燃气轮机）逐步恢复电网——**从无到有地「点亮」整个系统**。黑启动方案是电网应急预案的核心，要预先演练。

**辨析｜易错点：** 调度「安全」与「经济」的优先级：**安全永远第一，经济其次**。经济调度优化是在「安全约束已满足」的前提下进行——**「经济服从安全」是调度的铁律**。任何以牺牲安全为代价的经济方案都被否决。<span class="marginnote">「安全优先于经济」在调度里的执行，与第四级《AI 安全》里「安全约束必须优先于性能优化」是同一个价值排序。黑启动、备自投、低频减载这些「关键时刻才用的装置」，平时默默无闻，停电时才是主角——<strong>工程系统为极端情况预留的能力，决定它的底线品质</strong>。</span>

## 7 调度员的日常：从计划到执行的闭环

把调度的「一天」走一遍，就理解了调度的全部工作：

- **日前计划**：前一天预测次日负荷 → 机组组合（开哪些机组）→ 安全约束经济调度（各机组发多少）→ 安全校核（N-1）→ 下发计划。
- **实时运行**：当天按计划执行，AGC 自动调频；负荷偏差大时调度手动调整机组出力。
- **监视与预警**：SCADA 实时监视电压、潮流、频率，越限告警；静态安全分析预警「哪些故障会出问题」。
- **事故处置**：故障发生后按预案快速处置——切机、切负荷、转移潮流、恢复供电。
- **复盘与优化**：一天结束后分析运行数据，优化次日计划与预案。

**核心概念**：**调度的时间尺度**：日前计划（天级）、日内滚动修正（小时级）、AGC 自动调频（秒级）、紧急控制（毫秒级）——**「多时间尺度协同」是调度的本质**：每个时间尺度处理自己该处理的扰动，互相衔接。

**重点：** 调度是「**预测 + 优化 + 监控 + 处置**」四件事的循环——**预测靠数据、优化靠算法、监控靠 SCADA、处置靠预案**。理解这个循环，你就理解了「电力系统的大脑怎么工作」，也理解了《电力市场》里「调度与市场如何衔接」。

**一个「调度思维」的升华**：调度看似是「电网的事」，其方法论（预测、优化、监控、处置）却通用——**任何「供不应求、必须实时平衡」的系统**（电力、算力、带宽、库存）都吃这套方法。学调度，学的是一种「实时资源管理」的通用能力。

## 8 小结

- 调度体系：**统一调度、分级管理**；**负荷预测**是排计划的起点。
- **经济调度**：等耗量微增率 $\frac{dF_i}{dP_i} = \lambda$——所有机组边际成本相等，全网成本最小。
- **机组组合**：决定机组开停（混合整数规划），**安全约束**（N-1 校核）优先于经济。
- 调度自动化：**SCADA**（眼睛）、**EMS**（大脑）、**状态估计**（数据基础）、**AGC**（自动调频）。
- 事故处置靠预案，**黑启动**是大停电后的恢复流程；安全永远第一。

在下一节，我们从「调度」走到「市场」——电价由谁定？发电、输电、用电如何交易？这就是**电力市场**。
