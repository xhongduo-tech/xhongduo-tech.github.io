## 为什么从机械安全开始

机器是工业文明的肌肉，也是职业伤害最直观的来源：冲压机一次误动作就能把手指变成残废，旋转轴瞬间把袖口卷成绞索，飞出的切屑如同子弹。机械伤害是制造业「断手断指」事故的主因，也是安全人机工程最古老的课题。<span class="marginnote">机械安全与第六级《机械工程》同源：设计者不懂安全，操作者就要用血肉来还。今天机械安全设计已形成国际标准体系（ISO 12100 安全设计通则、GB/T 15706），核心理念是「设计阶段就把危险设计掉」，而不是等出厂后靠操作者小心。这与第四级《具身智能》里工业机器人的「安全围栏 + 力控 + 急停」设计一脉相承。</span>这一节讲清机械伤害的类型、危险部位，以及从设计到使用层层设防的完整体系。

## 1 机械伤害的类型

机械伤害按作用方式，常见的类型有：

**挤压**：身体部位被两个运动部件或运动件与固定件之间夹住；
**剪切**：像剪刀一样把肢体切断；
**切割与切断**：刀具、锯片直接切伤；
**缠绕**：长发、衣角、手套被旋转部件卷住，把人拉进机器；
**卷入**：身体被吸入两个相对转动的部件之间（如辊筒）；
**碰撞与打击**：运动部件撞人、抛射物（切屑、断裂的砂轮）飞出伤人；
**刺割**：毛刺、刃口划伤。

**重点：缠绕与卷入是后果最惨烈的一类。** 旋转轴转速高、扭矩大，一旦衣角或头发被缠住，人根本没有反应时间就被卷入——这就是为什么机床操作守则严禁戴手套、长发必须盘入帽内。<span class="marginnote">用第一级《物理》的角动量与摩擦语言看：旋转部件把衣物缠入的过程是一个「半径不断减小、线速度却不变」的绞杀过程，人的力量在巨大的机械扭矩面前微不足道。理解「卷入不可抗」，就理解为什么靠「小心」防不住机械伤害。</span>

## 2 机械危险部位与危险因素

机械设备的危险部位按运动形式归纳：

| 运动形式 | 典型危险部位 |
| --- | --- |
| 旋转运动 | 转轴、联轴器、飞轮、传动轴外露段 |
| 旋转 + 往复 | 冲压机滑块、剪切机刀口 |
| 往复直线 | 压力机台面、裁切台 |
| 传动 | 齿轮啮合处、皮带轮与皮带、链轮与链条 |
| 切削 | 车床卡盘、铣刀、锯片 |
| 高压流体 | 高压油管、喷口 |

危险因素分两大类：

**机械性危险**：上述运动的挤压、剪切、缠绕、冲击等；
**非机械性危险**：设备附带的高温表面、噪声、振动、电气、辐射、粉尘——机械伤害分析时必须一并考虑。

**辨析｜易错点：**危险部位并不只在机器「正在运动」时存在。**停机检修、清理、换刀**时的意外启动（如他人误合闸）是机械伤害的高发场景——所以检修必须执行「断电、挂牌、上锁」（LOTO，Lockout/Tagout）程序，这也是机械安全与设备管理（第四篇）的衔接点。

## 3 三道防线：本质安全 → 防护 → 提示

机械安全的设计逻辑，是按「优先级从高到低」的三道防线：

1. **本质安全（设计消除）**：在设计与制造阶段**消除或减小危险**——用无锐角替代有锐角、限制运动能量、把危险部件做成不可及（如封闭齿轮箱）。这是最高级别，也是 ISO 12100 的第一要求。
2. **安全防护（保护装置）**：当危险无法消除时，加**防护装置**与**安全装置**——防护罩、联锁门、光栅、急停。
3. **安全提示与个体防护**：警示标志、操作手册、防护眼镜/手套/鞋——只能作为兜底，**不能替代前两道防线**。

**重点：三道防线的顺序不可颠倒。** 拿「贴个'当心夹手'的牌子」去替代防护罩，是典型的「以提示冒充防护」——警示标志只负责提醒，不负责保命。<span class="marginnote">这道优先级与第一篇《安全科学原理》的「本质安全化三层次」（消除、抑制隔离、防护管理）完全同构：设计阶段能消除的，绝不留到运行阶段靠人来防。可以说，机械安全是本质安全思想最成熟的样板行业。</span>

## 4 防护装置与安全装置

**防护装置（guard）**：用物理屏障隔离危险区，常见类型：

**固定式防护罩**：用工具才能拆卸，始终罩住危险区；
**活动式防护罩（可调式）**：需要接近危险区时局部开合；
**联锁防护装置**：罩子打开时，机器必须停机（或无法启动）——**「罩开即停」是联锁的灵魂**。

**安全装置（safety device）**：主动检测并阻止危险状态的发生，常见类型：

**联锁装置（interlock）**：与防护罩配合，打开即切断动力；
**双手控制装置**：必须双手同时按两个按钮，机器才动作——保证手离开危险区；
**光栅/光幕（light curtain）**：红外光束构成虚拟屏障，手伸入即触发停机；
**急停装置**：醒目红色蘑菇头，按下立即停机；
**限位与超载保护**：行程开关、过载离合，防止越程与过载。

**辨析｜易错点：**防护装置与安全装置的差别在「被动 vs 主动」：防护罩是**死挡板**，挡住人不让进；光栅、双手控制是**活哨兵**，探测到人进入危险区才动作。但两者有个共同前提——**响应要足够快**。机器的停机是需要时间的，安全装置必须在「危险动作完成之前」就刹住机器，这就引出了安全距离的定量计算。<span class="marginnote">冲压机的双手控制按钮还有一个隐藏要求：两个按钮的间距要大于手掌宽度，且松开任一按钮机器立即退回，防止人单手压住两个按钮、另一只手仍在模具里——这类「防作弊」设计是安全装置工程化的细节精华。</span>

## 5 公式解析：安全距离 S = K × T + C

安全光栅与防护装置的安装位置，由一条核心公式决定（ISO 13855 / 国标等效标准）：

$$
S = K \times T + C
$$

其中 $S$ 是**安全距离**（mm），即防护装置离危险区的最小距离；$K$ 是**人体接近危险区的速度**（mm/s，标准取值 1600–2000）；$T$ 是**系统总停机时间**（s），等于检测装置响应时间与机器制动时间之和；$C$ 是**附加余量**（mm），反映手指/手掌侵入防护装置本身的深度。三步拆解：

- **第一步，读懂逻辑**：安全距离 = 机器停下来所需时间内人可能前进的距离（$K \times T$）+ 结构上的额外补偿（$C$）。它保证「手碰到危险区之前，机器已经停稳」。
- **第二步，代入数字**：设光栅响应 0.02 s、机器制动 0.18 s，则 $T = 0.20$ s；取 $K = 2000$ mm/s、$C = 0$，则 $S = 2000 \times 0.20 + 0 = 400$ mm——光栅必须装在离危险区至少 400 mm 的地方。
- **第三步，看工程含义**：若把 $T$ 从 0.20 s 压到 0.10 s，$S$ 从 400 mm 降到 200 mm——**机器停得越快，设备就可以离操作者越近，产线布局越紧凑**。这就是为什么「快速制动」既是安全要求，也是生产效率要求。

**辨析｜易错点：**$K$ 与 $C$ 的取值取决于防护装置类型与人体部位。$K = 2000$ mm/s 只在 $S \leq 500$ mm 时成立；计算结果大于 500 mm 时，标准要求改用 $K = 1600$ mm/s 重算并加 $C$。直接拿一个 K 值套所有场景，会让安全距离算错方向。

### 机械安全标准体系

机械安全不是各厂各一套，而是有完整的国际/国家标准体系支撑。核心标准是 **ISO 12100《机械安全——设计通则》**，它规定了一套从风险辨识到风险减小的设计流程：

1. 确定机械的**边界与寿命周期**；
2. **识别危险**（机械性、电气、热、噪声、辐射等）；
3. **风险估计与评价**：按伤害严重度与发生概率判定风险等级；
4. **风险减小**：按优先级采取本质安全设计、安全防护、使用信息（警示）三层措施。

中国等效采用为 GB/T 15706。此外还有一批专项标准：防护装置（ISO 14120）、安全距离（ISO 13857）、双手控制装置（ISO 13851）、急停（ISO 13850）等，构成一个「通则 + 专项」的标准族。<span class="marginnote">注意标准中「使用信息」被列为风险减小的<strong>最末手段</strong>——警示标志、说明书排在三层措施的最后，正是机械安全「先技术、后管理」优先级原则的制度化。</span>

**重点：标准体系把「机械安全设计」从经验变成流程。** 设计一台新设备，按 ISO 12100 的流程走一遍，等于强制完成一次系统化的风险分析——这与第二篇安全评价的流程同构。对机械设计工程师而言，安全标准不是束缚，而是一张「不会漏项」的设计检查单。

## 6 小结

- 机械伤害主要类型：**挤压、剪切、切割、缠绕、卷入、碰撞、刺割**；缠绕卷入最凶险且不可抗力。
- 危险部位按运动形式分：**旋转、往复、传动、切削、高压流体**；停机检修的意外启动同样危险，须 **LOTO（断电挂牌上锁）**。
- 三道防线：**本质安全 → 防护装置/安全装置 → 提示与个体防护**，顺序不可颠倒。
- 防护装置是「死挡板」，安全装置是「活哨兵」：**联锁、双手控制、光栅、急停**。
- 安全距离公式 $S = K \times T + C$：机器停得越快，设备离人越近；K、C 取值须按标准场景选取。
- 设计标准体系以 **ISO 12100（GB/T 15706）**为核心：辨识危险 → 评价风险 → 三层风险减小（本质安全、防护、使用信息）。
