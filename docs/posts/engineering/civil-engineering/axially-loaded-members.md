## 为什么从轴心受力构件开始

钢结构的桁架杆、网架杆、支撑杆、屋架压杆——绝大多数细长杆件承受的是**轴向力**：要么被拉（轴心受拉），要么被压（轴心受压）。它们是钢结构里最「单纯」的构件，受力模式简单，却藏着钢结构最核心的矛盾——受压时的**稳定**。一根钢柱的抗压强度可能很足，但长细比一大，先「弯」而不是「压碎」。**轴心受力构件**是钢构件设计的入门，也是理解「强度 vs 稳定」这对贯穿钢结构全局矛盾的第一现场。<span class="marginnote">轴心受拉与轴心受压的「待遇」完全不同：受拉构件只验算强度与长细比（怕太柔），受压构件要验算强度 + 整体稳定 + 局部稳定。为什么？拉杆越拉越直、越拉越安全；压杆一压就弯、一弯就失稳——<strong>拉是「自救」，压是「自毁」</strong>，所以压杆的规定多得多。</span>

## 1 轴心受拉构件

**轴心受拉构件**（拉杆）的验算最简单：

- **强度**：截面被螺栓孔等**削弱**处，净截面应力最大：
  $$\sigma = \frac{N}{A_n} \le f$$
  $N$ 是轴力，$A_n$ 是**净截面面积**（扣除孔洞），$f$ 是钢材强度设计值。拉杆的破坏是「净截面拉断」——孔洞处最危险。
- **刚度（长细比）**：拉杆虽然不担心失稳，但太柔会在自重与风下抖动，所以限制长细比：
  $$\lambda = \frac{l_0}{i} \le [\lambda]$$
  $l_0$ 是计算长度，$i$ 是回转半径，$[\lambda]$ 是容许长细比（拉杆约 350，压杆约 150～200）。

**辨析｜易错点：** 拉杆用**净截面**$A_n$ 验强度（孔洞削弱），用**全截面**（毛截面）算长细比。两个面积别混——强度看「最弱的截面」，长细比看「整体的柔度」。

## 2 轴心受压构件的整体稳定

**轴心受压构件**（压杆）的验算分强度与稳定两层：

- **强度**：$\sigma = \frac{N}{A_n} \le f$（与拉杆同式）。
- **整体稳定**：压杆可能**整体失稳**——在轴力未到强度极限时侧向弯屈。这是压杆设计的控制因素：
  $$N \le \varphi A f$$
  $\varphi$ 是**稳定系数**，$A$ 是毛截面面积。**稳定验算用毛截面**（稳定看整体、不受局部孔洞影响）。

**稳定系数 $\varphi$** 是钢结构设计最核心的查表值，与**长细比 $\lambda$** 和**截面分类**有关：$\lambda$ 越大、$\varphi$ 越小，承载力折减越多。规范按截面形状与屈曲方向把截面分 **a、b、c、d 四类**，各类的 $\varphi-\lambda$ 曲线（**柱子曲线**）不同。<span class="marginnote">为什么同一种截面还要分 a、b、c、d 四类？因为不同截面形状的<strong>残余应力分布</strong>与<strong>初始缺陷影响</strong>不同，屈曲性能差异明显。工字形绕强轴（a 类、残余应力影响小）与绕弱轴（b/c 类）的稳定系数就不同。「同一个截面、不同的弯曲方向、不同的稳定系数」——查柱子曲线是钢压杆计算的常事。</span>

## 3 公式解析：压杆的稳定承载力

把 $N \le \varphi A f$ 拆透，理解 $\varphi$ 从哪来：

- **第一步，回到欧拉临界力**：回忆《结构稳定》的欧拉公式 $P_{cr} = \frac{\pi^2 EI}{l_0^2}$。改写成长细比形式：$I = Ai^2$，故
  $$P_{cr} = \frac{\pi^2 E A}{\lambda^2}, \qquad \lambda = \frac{l_0}{i}$$
- **第二步，定义稳定系数**：把临界应力与屈服强度之比作为 $\varphi$：
  $$\varphi = \frac{\sigma_{cr}}{f_y}$$
  理想弹性杆 $\varphi = \pi^2 E/(\lambda^2 f_y)$，随 $\lambda$ 增大而减小。
- **第三步，考虑弹塑性与缺陷**：实际杆件有残余应力与初始弯曲，失稳常发生在弹塑性阶段，$\varphi$ 比弹性理论更低——规范用试验回归的**柱子曲线**给出 $\varphi$。
- **第四步，工程使用**：算 $\lambda = l_0/i$ → 按截面分类查 $\varphi$ → 验算 $N \le \varphi A f$。**稳定承载力的核心是长细比**：$\lambda$ 大则 $\varphi$ 小、材料「发挥不出来」。

## 4 局部稳定：板件不能先皱

压杆除了整体失稳，还可能**局部失稳**：翼缘或腹板板件在压力下先「起皱」屈曲。防止局部失稳靠限制**板件宽厚比**（宽与厚之比）：

- 工字形截面翼缘：$\frac{b}{t} \le 15\sqrt{235/f_y}$（外伸宽度比）。
- 腹板：$\frac{h_0}{t_w} \le 25\sqrt{235/f_y}$ 量级。

**宽厚比限值**保证板件在整体失稳之前不发生局部屈曲——「板先不皱，杆才不失稳」。板太薄（宽厚比过大）则局部先坏，整体承载力打折。<span class="marginnote">宽厚比限值的来源是「局部屈曲临界应力 ≥ 整体屈曲临界应力」的设计原则：让局部不先于整体破坏。$\sqrt{235/f_y}$ 是强度修正因子——钢材强度越高，同样宽厚比的板越容易局部失稳，所以高强钢的宽厚比限值更严。这个「强度越高越要限制板薄」的反直觉，正是高强钢应用的一大门槛。</span>

## 5 实腹柱与格构柱

压杆按截面形式分两类：

- **实腹柱**：工字形、H 型钢、箱形等整体截面——制作简单、应用最广。
- **格构柱**：两个分肢用缀条或缀板连接成「脚手架」式截面——用较少的材料获得大回转半径、大长细比小的截面，适合大跨度、大高度的轴压柱。

格构柱的稳定分**对实轴**与**对虚轴**分别验算：对虚轴的长细比要用**换算长细比**（考虑缀件变形）修正——「虚轴方向的杆件不是连续截面，柔度更大」。

## 6 轴压构件的设计流程

轴压构件设计的完整套路（以实腹工字形柱为例）：

1. **初选截面**：假定长细比 $\lambda$（一般 60～100）→ 反查 $\varphi$ → 由 $N = \varphi A f$ 估所需面积 → 选型钢或组合截面。
2. **验算强度**：$\sigma = N/A_n \le f$。
3. **验算整体稳定**：算两个方向的 $\lambda_x, \lambda_y$ → 查 $\varphi_{\min}$ → $N \le \varphi_{\min} A f$。
4. **验算刚度**：$\lambda_{\max} \le [\lambda]$。
5. **验算局部稳定**：板件宽厚比 ≤ 限值。
6. **不满足则调整截面**，迭代至满足。

**辨析｜易错点：** 整体稳定用**两个方向长细比中较大的那个**（$\lambda_{\max}$ 对应的 $\varphi$ 最小、最不利）——绕弱轴方向通常先失稳。漏算弱轴方向，稳定验算就「名存实亡」。设计时还常让 $\lambda_x \approx \lambda_y$（等稳设计）使两个方向材料都发挥。

## 7 小结

- 轴心受力构件分**拉杆**（强度 + 长细比）与**压杆**（强度 + 整体稳定 + 局部稳定）。
- 拉杆强度 $\sigma = N/A_n \le f$（净截面），长细比 $\lambda = l_0/i \le [\lambda]$。
- 压杆整体稳定 $N \le \varphi A f$：$\varphi$ 由长细比与截面分类（a～d 类）查柱子曲线。
- 局部稳定靠**宽厚比限值**（含 $\sqrt{235/f_y}$ 修正），让板件不先于整体失稳。
- 实腹柱 vs 格构柱；格构柱对虚轴用换算长细比。
- 设计流程：初选截面 → 强度 → 整体稳定 → 刚度 → 局部稳定，迭代至满足。
