## 为什么从力法开始

加了横撑的屋架、连续了几跨的桥梁、带剪力墙的框架——它们比静定结构多出一些「锦上添花」的约束。这些**多余约束**让反力与内力无法只靠平衡方程求出，却也带来了静定结构没有的优点：刚度更大、内力分布更均匀、冗余度更高（一根杆坏了其他杆顶上）。代价是求解变难。**力法（force method）**是征服超静定结构的第一件武器：它把「多了的约束」想象成可以摘除的赘物，先变成熟悉的静定结构，再通过「位移协调」把摘掉的约束请回来。<span class="marginnote">力法也叫<strong>柔度法</strong>（flexibility method）——它的柔度系数 δ 是「单位力引起的位移」。这是结构分析中「先解放、再约束」的思想首次登场，与《矩阵位移法》里「先固定、再释放」恰好相反，两者一阴一阳。</span>

## 1 超静定次数与基本体系

**超静定结构（statically indeterminate structure）**：未知力个数多于独立平衡方程个数的结构。超出的数目称为**超静定次数（degree of indeterminacy）**，等于**多余约束**的个数。

求次数的方法是「拆除计数」：把结构的约束逐一拆掉，直到它变成静定结构，拆掉的就是多余约束。常见拆法：切断一根链杆 = 去掉 1 个约束；撤去一个铰 = 去掉 2 个约束；切断一根梁式杆 = 去掉 3 个约束；把固定端改铰 = 去掉 1 个约束。

拆除多余约束后得到的静定结构，称为**基本体系（basic system）**；被拆掉的约束以**多余未知力** $X_1, X_2, \dots, X_n$ 的形式重新「作用」在基本体系上。<span class="marginnote">基本体系可以任选，但必须几何不变且静定——这是自由度（第 1 章）知识在选基本体系时的实际用途：选错了，体系可变，柔度系数就无意义了。</span>

## 2 力法方程：位移协调是灵魂

设超静定次数为 $n$，多余未知力为 $X_1, X_2, \dots, X_n$。基本体系必须在「多余未知力 + 原荷载」共同作用下，满足原结构在拆除处的**位移条件**（通常为 0），由此得到 $n$ 个方程：

$$
\begin{aligned}
\delta_{11} X_1 + \delta_{12} X_2 + \cdots + \delta_{1n} X_n + \Delta_{1P} &= 0 \\
\delta_{21} X_1 + \delta_{22} X_2 + \cdots + \delta_{2n} X_n + \Delta_{2P} &= 0 \\
&\vdots \\
\delta_{n1} X_1 + \delta_{n2} X_2 + \cdots + \delta_{nn} X_n + \Delta_{nP} &= 0
\end{aligned}
$$

**这就是力法典型方程。** 它的物理含义一句话：**在基本体系上，把荷载与 n 个多余未知力造成的、沿每个多余未知力方向的位移加起来，必须等于原结构的真实位移（一般是零）。** 系数 $\delta_{ij}$ 是 $X_j = 1$ 单独作用时沿 $X_i$ 方向产生的位移，叫**柔度系数**；$\Delta_{iP}$ 是荷载单独作用时沿 $X_i$ 方向的位移，叫**自由项**。<span class="marginnote">力法方程在数学上是一组<strong>线性代数方程</strong>，未知数就是多余力。它对应《线性代数》里「解线性方程组」的全部技巧；到《矩阵位移法》会看到它演变成更系统化的矩阵形式 $[\delta]\{X\} + \{\Delta_P\} = 0$。</span>

由互等定理有 $\delta_{ij} = \delta_{ji}$，系数矩阵对称，可减少一半计算量——这是《线性代数》对称矩阵的性质第一次在结构分析里显形。

## 3 公式解析：柔度系数的计算

柔度系数 $\delta_{ij}$ 与自由项 $\Delta_{iP}$ 都用上一节的**图乘法**计算。以 $\delta_{ij}$ 为例，它是「$X_j = 1$ 的弯矩图 $\bar{M}_j$ 与 $X_i = 1$ 的弯矩图 $\bar{M}_i$」的图乘结果：

$$
\delta_{ij} = \sum \int \frac{\bar{M}_i \bar{M}_j}{EI}\,\mathrm{d}s
= \sum \frac{\omega_j \cdot y_{ic}}{EI}
$$

- **第一步，画单位弯矩图**：分别画出 $X_i = 1$、$X_j = 1$ 单独作用下的弯矩图 $\bar{M}_i$、$\bar{M}_j$（基本体系是静定结构，这步用静力法即可）。
- **第二步，选面积与纵标**：取 $\bar{M}_j$ 图的面积 $\omega_j$，乘以 $\bar{M}_i$ 图在 $\bar{M}_j$ 形心处的纵标 $y_{ic}$。
- **第三步，求和**：把各杆段贡献相加，除以对应的 $EI$。
- **第四步，记忆量纲**：$\delta_{ij}$ 的量纲是「位移 / 力」（柔度），$\Delta_{iP}$ 的量纲是「位移」。把量纲验一遍，是检查力法方程是否写错的第一道防线。

## 4 对称性：让计算减半的免费午餐

超静定结构常有对称性。**对称结构（几何、支座、刚度都对称）在对称荷载下，内力与变形对称；在反对称荷载下，内力与变形反对称。** 利用这一点：

- 对称荷载下，**反对称的多余未知力为零**——可把对称轴上的反对称未知力直接设为 0。
- 反对称荷载下，**对称的多余未知力为零**。

于是超静定次数 $n$ 往往直接砍半，力法方程规模大幅缩减。<span class="marginnote">对称性是结构力学「用代数结构省计算」的经典案例，与《离散数学》里的对称群、《矩阵论》里的特征分解是同一思想——先找结构的不变量，再利用不变量降维。</span>

## 5 力法解题流程与工程意义

力法的完整流程是五步走：

1. **定次数**：拆除多余约束，确定超静定次数 $n$，选基本体系与多余未知力。
2. **列方程**：写出位移协调方程 $\delta_{11}X_1 + \cdots + \Delta_{1P} = 0$。
3. **算系数**：画单位弯矩图与荷载弯矩图，图乘法求 $\delta_{ij}$、$\Delta_{iP}$。
4. **解方程**：解线性方程组得多余未知力。
5. **叠加内力**：$M = \bar{M}_1 X_1 + \bar{M}_2 X_2 + \cdots + M_P$，再算剪力轴力，画内力图。

**辨析｜易错点：** 力法方程右边是**原结构在多余约束处的实际位移**，多数情况是 0，但若该处本身有已知支座位移（如支座沉降 $\Delta$），右边应写 $\Delta$ 而非 0——漏掉支座位移是力法最常见的一类错误。

力法的工程意义不只是「会算超静定」：它揭示了超静定结构的「内力与刚度分布有关」这一深刻事实——同一座连续梁，加大中间支座的刚度，跨中弯矩就会改变。这个「刚度决定内力分配」的规律，是后面《位移法》《矩阵位移法》乃至现代结构设计软件一切计算的底层逻辑。

## 6 小结

- 超静定次数 = 多余约束个数；拆除多余约束得**基本体系**与多余未知力 $X_i$。
- 力法典型方程 $\sum_j \delta_{ij} X_j + \Delta_{iP} = 0$，物理本质是**位移协调**。
- 柔度系数 $\delta_{ij}$ 用图乘法 $\sum \frac{\omega_j y_{ic}}{EI}$ 计算，且 $\delta_{ij} = \delta_{ji}$。
- **对称性利用**：对称结构在对称/反对称荷载下，反对称/对称未知力为零，计算量减半。
- 最终内力由叠加 $M = \sum \bar{M}_i X_i + M_P$ 得到。
- 力法揭示「内力由刚度分配」，是位移法与矩阵位移法的思想前奏。

在下一节，我们把「未知量」从力换成位移——**位移法**以结点位移为基本未知量，天然适合计算机程序化，是通向《矩阵位移法》的最后一站。
