## 为什么从水工模型试验开始

水工建筑物的体型设计，光靠公式和有限元计算不够——水流太复杂，掺气、空蚀、冲刷、水跃的细部流态，计算往往算不准，甚至算不出。
于是工程师在实验室里用**缩小比例的水工模型（hydraulic model）** 预演真实工程：洪水怎么泄、消能池够不够、冲刷坑多深、流态稳不稳，全部「先试后建」。
<span class="marginnote">水工模型试验是《水力学》第十章《模型试验》在建筑物设计中的实战应用。
三峡、溪洛渡、白鹤滩等巨型工程的泄洪消能方案，都在 1:80~1:100 的模型中反复试验验证后才敢上马——因为泄洪流速每秒几十米、冲刷能量巨大，任何设计失误的代价都是灾难性的。
</span>

本章把《模型试验》章的原理与《水工建筑物》的具体对象结合，讲水工模型试验的分类、设计与典型应用。

## 1 水工模型试验的类型

按研究对象分：

**整体模型**：把整个枢纽（坝、溢洪道、厂房、下游河道）按同一比尺做成模型，研究枢纽总体布置、泄洪、流态、下游冲刷——回答「总体行不行」。
**局部模型**：针对单个建筑物或局部流态（消力池、进水口、闸门段）做放大比尺的模型——回答「细节怎么改」。
**断面模型**：取二维断面（如溢流坝剖面）研究表面流态、压强分布。
**专项模型**：掺气、空蚀、温排水、泥沙、冰凌等专门问题的模型。

按相似准则分：**正态模型**（水平与垂直比尺相同，严格几何相似）与**变态模型**（水平/垂直比尺不同，宽浅河道用，见《模型试验》章）。
<span class="marginnote">泄洪消能模型最常用「正态模型 + 弗劳德准则」：水面流动由重力主导，$Fr$ 相等即可保证流态相似。
但高速水流的掺气、空蚀需要更高流速，往往要「大比尺模型」（如 1:30~1:40）才能重现——比尺太小，掺气现象失真。
所以泄洪模型常常「又大又贵」，却是高坝设计的必需品。
</span>

## 2 模型设计与制作

水工模型试验的设计步骤：

1. **确定比尺**：综合原型尺寸、场地、供水能力、测量精度，选几何比尺 $\lambda_l$。
整体模型常 1:50~1:120，局部放大模型可达 1:20。
2. **确定相似准则**：泄洪、消能（自由表面流）用**弗劳德准则**：$\lambda_v = \sqrt{\lambda_l}$，$\lambda_Q = \lambda_l^{5/2}$；
渗流、管流用**雷诺准则**。
<span class="marginnote">$\lambda_Q = \lambda_l^{5/2}$ 意味着：比尺 1:100 的模型，原型泄流 10000 m³/s 对应模型只有 $10000/100^{2.5} = 0.1\,\text{m³/s}$——一座小水泵就能供给。
这正是模型试验「以极小代价预演极大规模」的经济性所在。</span>
3. **制作模型**：按地形等高线做地形模型（水泥砂浆塑形），按图纸做水工模型（有机玻璃、水泥、砖砌）。
闸门、启闭、可调。
4. **量测**：水位用测针，流量用堰槽/流量计，流速用旋桨流速仪、粒子图像测速（PIV），压强用测压管，冲刷地形用断面仪。
<span class="marginnote">现代量测技术让模型试验进入「数字化」：PIV 能测出全场瞬时流速场，激光地形扫描快速捕捉冲刷坑形态，高速摄影记录掺气与空化过程——模型试验从「看水花」变成「数据采集」。
</span>

## 3 泄洪消能试验

泄洪消能是水工模型试验最经典、最核心的用途：

**溢流坝剖面试验**：验证 WES 堰面曲线的压力分布，防止出现过大负压（空蚀风险）。
**消力池试验**：验证水跃位置、跃后水深、消力池尺寸，观察水流是否「跃出」消力池。
**挑流消能试验**：测定挑流水舌的挑距、落点、对下游的冲刷深度与范围——冲刷坑是否会威胁坝脚，直接决定方案取舍。<span class="marginnote">挑流消能的冲刷试验常让工程师「吓一跳」：模型里看似寻常的挑射，在原型尺度放大后冲刷坑可达十几米深。试验的目的就是把这个「吓一跳」提前到图纸阶段——通过调鼻坎角度、加消能墩、调整流方式，把冲刷控制在安全范围。</span>
**空中碰撞消能试验**（拱坝表孔中孔对撞）：验证水舌对撞位置、能量耗散率与雾化范围。

**典型流程**：定方案 → 模型试验 → 发现问题 → 修改体型 → 再试验，循环迭代直至流态与消能均达标。
试验结论直接成为设计图纸的依据。

## 4 流态观测与专项试验

除消能外，模型试验还解决多种专项问题：

**进水口漩涡试验**：验证进水口淹没深度，消除立轴漩涡（防涡梁设计）。
**闸门启闭流态试验**：观察闸下出流、门后掺气、局部开启时的流态。
**通航与过鱼试验**：船闸输水系统、鱼道进口流态。
**泥沙模型试验**：用轻质沙（塑料沙、煤粉）模拟天然沙，研究坝区淤积、取水口防沙、下游河床变形。
**温度模型试验**：温排水扩散、分层取水温差。
**空蚀与掺气试验**：高速水流区掺气坎的掺气效果、空化初生判别。

**辨析｜易错点：** 泥沙模型与清水模型不同：泥沙运动既受重力（弗劳德）又受泥沙沉降特性（颗粒沉速）控制，两个准则难以同时满足，要用**轻质沙 + 变态比尺**折中。
泥沙模型试验是水工试验里最「艺术」的分支，经验性很强。
<span class="marginnote">泥沙模型的「轻质沙」思路很妙：用比重接近 1 的塑料颗粒替代天然沙，在模型里让沉降、起动相似。
但这引入的失真需要用比尺修正与长期率定补偿——泥沙模型往往要反复「验证率定」才可信。
</span>

## 5 数值模型与模型试验的联合

现代水工设计中，实体模型与**数值模型（CFD）** 紧密结合：

**数值先行**：用 CFD 快速筛选方案、参数寻优，缩小试验范围，节省试验周期。
**试验验证**：把数值模拟的最终方案放到实体模型中验证——实体模型仍是「最终裁判」，因为它的边界最真实、无数值离散误差。
**互补短板**：数值模型擅长算全场参数（压力场、流速场）、做方案批量比选；实体模型擅长捕捉真实流态细节（掺气、空化、冲击波）。<span class="marginnote">「数值 + 实体」双轨验证已成为大型工程的标配流程。这与机器学习里的「仿真 + 真机」验证异曲同工：仿真快速迭代，真机最终验收。数字孪生技术（后面《智慧水利》）进一步把模型试验、数值模拟与实时监测打通成一套系统。</span>

## 6 模型试验的相似限制与失真

模型试验不是「万能的照妖镜」，它有自己的相似限制与系统失真：

**比尺效应**：模型过小，水面张力、黏性等次要力的作用被放大，流态失真——所以关键试验要选足够大的比尺。
**掺气与空蚀失真**：模型流速低于原型（弗劳德模型流速比尺 $\lambda_v=\sqrt{\lambda_l}$），高速水流的掺气、空蚀现象难以完全重现，须另做专门试验或经验修正。
**糙率失真**：模型材料的糙率难以按比尺精确缩放，水面坡降与流速分布会有偏差。
**变态模型的几何失真**：水平/垂直比尺不同，流态局部失真，试验成果须经验修正。

**辨析｜易错点：** 模型试验的结论要带着「失真意识」解读——它是定性判断与相对比较的可靠工具，但绝对数值（如冲刷深度）往往偏保守或偏小，须乘经验修正系数并与数值模型互校。
**试验报告必须注明比尺、相似准则与可能的失真来源**，这才是规范的试验成果。

<span class="marginnote">模型试验的科学性在于「知道自己在近似什么」：每一次近似（比尺、糙率、变态）都有明确的适用范围。
这与《数值分析》里「数值解要报告截断误差、收敛性」的自觉完全一致——<strong>工程科学的成熟，体现在对自身近似边界的清醒</strong>。
</span>

## 7 小结

- **类型**：整体、局部、断面、专项模型；正态与变态模型按对象选。
- **设计**：定比尺、定准则（泄洪用弗劳德），量测用 PIV、测针、流速仪。
- **核心应用**：泄洪消能试验（溢流面、消力池、挑流冲刷、空中碰撞）是设计定型的关键依据。
- **专项试验**：漩涡、闸门流态、泥沙、温度、空蚀掺气各有专用模型与方法。
- **趋势**：数值模型与实体模型联合，双轨验证；数字孪生贯通试验、模拟与监测。
