## 为什么从模型试验开始

真实的水利工程太大、太贵、太危险，不能直接试错。三峡大坝的泄洪方案、港口的防波堤布置、南水北调的输水线路——在开工之前，工程师先在实验室里做一个**缩小版的模型**，把真实工程的流动在模型里重现，量出流量、流速、冲刷深度，再换算回原型。
这门技术就是**模型试验（hydraulic model test）**。<span class="marginnote">模型试验是水力学「最后一章」，也是把前面全部公式投入实践的方法论。
历史上水工模型试验对葛洲坝、三峡等巨型枢纽的消能设计功不可没——模型里测出的流态，直接决定了原型的体型。
</span>

但模型试验有个根本难题：模型是原型的 1/50，流速、流量、时间也全都变了，**怎么保证模型里测到的结果能准确换算回原型？
** 答案是「相似三条件」，本章的核心。

## 1 相似的三条件

模型与原型要相似，必须同时满足三方面：

**几何相似（geometric similarity）**：模型与原型所有对应长度成同一比例尺 $\lambda_l = \frac{l_p}{l_m}$（下标 $p$ 原型、$m$ 模型）。角度相同、形状相同，这是基础。
**运动相似（kinematic similarity）**：对应点的流速、加速度方向相同、大小成比例，即速度比尺 $\lambda_v = \frac{v_p}{v_m}$ 处处相同。
**动力相似（dynamic similarity）**：对应点所受的各种力（重力、黏滞力、压力、惯性力）方向相同、大小成比例。

三者的关系：**几何相似是前提，运动相似是表现，动力相似是本质**——只有受力情况相似，流态才会相似。
<span class="marginnote">几何相似是「长得像」，运动相似是「动得像」，动力相似是「受力像」。
三个相似并非独立：只要几何相似且对应点的各种力之比一致，运动就必然相似。
工程上真正要费心的是满足动力相似。</span>

## 2 相似准则：弗劳德与雷诺

动力相似要求**各作用力之比在模型与原型中相同**。但力的种类太多，无法同时满足，只能抓住主要矛盾，取「控制性力」建立相似准则：

### 弗劳德准则（重力主导）

明渠流、堰流、溢流坝等**有自由表面的流动**由重力支配，要求惯性力与重力之比相等，即**弗劳德数相等**：$Fr_m = Fr_p$。

由 $Fr = \frac{v}{\sqrt{gl}}$ 相等可得速度比尺：

$$\lambda_v = \sqrt{\lambda_l}$$

再结合几何相似，推出流量、时间、力等各比尺都是长度比尺 $\lambda_l$ 的简单幂次：$\lambda_Q = \lambda_l^{5/2}$，$\lambda_t = \lambda_l^{1/2}$，$\lambda_F = \lambda_l^3$。
<span class="marginnote">弗劳德模型的一个意外福利：$\lambda_t = \sqrt{\lambda_l}$——若模型比尺 1:100，模型里 1 秒相当于原型 10 秒。
所以实验室里「几秒钟」的一场泄洪，换算回原型是「几十秒」的真实过程，时间也按比尺压缩。
</span>

### 雷诺准则（黏滞力主导）

管流、渗流、水下潜体等**无自由表面、黏性作用重要**的流动，要求雷诺数相等：$Re_m = Re_p$。

由 $Re = \frac{v l}{\nu}$ 相等可得 $\lambda_v = \frac{1}{\lambda_l}$（同种流体）。
这带来一个致命矛盾：模型缩小 50 倍，流速要放大 50 倍，流量比尺 $\lambda_Q = \lambda_l^{1}\cdot\lambda_v\cdot\lambda_l^2 = \lambda_l$，与弗劳德模型完全不同。

**辨析｜易错点：** 同一流动往往同时受重力和黏滞力影响，但**弗劳德准则与雷诺准则不能同时严格满足**（除非更换流体）。
水利工程中水面流动以重力为主，用弗劳德准则；
管流、渗流以黏性为主，用雷诺准则。设计模型前，先问「谁是控制性力」。

## 3 模型设计：选定比尺与流体

模型设计的实际步骤：

**确定几何比尺 $\lambda_l$**：根据场地、原型尺度、可提供的流量选择，通常 1:10~1:100。
**选定相似准则**：有自由表面用弗劳德，管流渗流用雷诺。
**检验次要力**：弗劳德模型中，黏滞力是次要力，$Re_m$ 不一定等于 $Re_p$，但须保证模型流态仍是紊流（否则结果失真）——**模型过小会导致 $Re_m$ 过低**，这是小比尺模型的通病。
**确定各物理量比尺**：由 $\lambda_l$ 与准则推出 $\lambda_v, \lambda_Q, \lambda_F, \lambda_t$ 等，制成比尺表。

**模型变态问题**：当原型河道宽深比过大（如长江），按同一比尺缩小后模型水深只有几厘米，无法反映糙率影响。
工程上常采用**变态模型**——水平比尺与垂直比尺不同（水平 1:100、垂直 1:50），此时流态虽近似，但水面坡降、流速分布均略失真，须凭经验修正。
<span class="marginnote">变态模型是「没有完美相似时的工程妥协」：宽浅河道若用正态模型，水深太浅、表面张力开始作怪；
垂直比尺放大后能保证水深与流速分布合理，但几何相似被破坏。
工程师接受局部失真，换取能解决问题的近似。</span>

## 4 量纲分析：相似理论的数学骨架

模型试验的比尺关系，可以用**量纲分析（dimensional analysis）** 从理论上推出，不必逐一实验。
核心是**白金汉 $\pi$ 定理（Buckingham π theorem）**：

> 若物理过程涉及 $n$ 个物理量、$k$ 个基本量纲，则该过程可由 $n-k$ 个无量纲 $\pi$ 数描述。

对管流阻力问题：$h_f = f(v, d, l, \mu, \rho, \Delta)$，基本量纲 3 个（质量、长度、时间），可得 $\pi_1 = \frac{h_f}{l} \cdot \frac{d}{v^2/2g}$（对应 $\lambda$）、$\pi_2 = Re$、$\pi_3 = \Delta/d$——**达西公式、雷诺数、相对粗糙度全都能由量纲分析「长」出来**。
<span class="marginnote">量纲分析最迷人的地方：它不依赖任何力学方程，只靠「方程两边量纲必须一致」就能预言物理关系的形式。
这在复杂流动（如掺气水流、泥石流）中尤其宝贵——即使写不出方程，也能排出无量纲参数指导实验。
这和机器学习里「无量纲特征缩放」的思想同源。</span>

**公式解析：由 $\pi$ 定理推弗劳德数。** 对明渠流，设 $v = f(h, g)$（忽略黏性），$n = 3$ 个物理量、$k = 2$ 个基本量纲（长度、时间），故 $n - k = 1$ 个无量纲数。
组合得 $\pi = \frac{v}{\sqrt{gh}} = Fr$——**弗劳德数从量纲分析中自动出现**，这正是「$Fr$ 是明渠流唯一决定性参数」的理论根据。

## 5 模型试验的现代形态

传统水工模型是实体模型（缩尺的坝、渠、河床），靠测针、流速仪、粒子图像测速（PIV）量测。
今天出现了新形态：

**数值模型**：用 CFD（计算流体力学）求解纳维—斯托克斯方程，在计算机里「跑模型」，成本低、迭代快。
**模型 + 数值结合**：实体模型验证数值模型，数值模型再优化方案——这是现代水工设计的标准流程。
**人工智能辅助**：用机器学习做流态识别、参数反演，加速模型试验的测量与分析。<span class="marginnote">数值模型与实体模型并非取代关系，而是互补：实体模型解决「方程不敢完全信任」的复杂边界，数值模型解决「试验次数受限」的参数寻优。真正的大枢纽设计，两者并用、互相校核。</span>

## 6 模型试验的典型案例

几组著名试验直观说明模型试验的价值：

**三峡泄洪消能**：1:80 整体模型研究表孔 + 中孔联合泄洪，优化挑流与消力池布置，使下游冲刷控制在允许范围；模型结论直接指导了泄洪布置定型。
**拱坝表孔中孔碰撞消能**：小湾、溪洛渡等拱坝用模型试验反复调整水舌对撞位置，验证「空中消能」效果与下游雾化范围。
**船闸输水系统**：船闸充泄水系统用模型试验优化阀门开度程序，控制输水时系船缆受力。
**鱼道进口流态**：过鱼设施模型试验优化诱鱼水流与进口位置，提高过鱼率。

**辨析｜易错点：** 模型试验的结论有「比尺限制」——模型里最优的体型放大到原型可能流态有变，所以重要结论要做**多比尺试验对比**或与数值模型互校。试验报告的结论必须注明适用比尺与失真修正。

<span class="marginnote">「先试验后定案」是大型水工设计的铁律：三峡、小湾等巨型工程的关键体型，都在模型里反复试错后才最终定型。<strong>模型里花掉的每一分钱，都是为原型省下的安全与返工成本</strong>——这是工程试验经济学最朴素的逻辑。</span>

## 7 小结

- **相似三条件**：几何相似是基础，运动相似是表现，动力相似是本质。
- **弗劳德准则**（重力主导，明渠/堰流）：$Fr_m = Fr_p$，$\lambda_v = \sqrt{\lambda_l}$。
- **雷诺准则**（黏性主导，管流/渗流）：$Re_m = Re_p$，两准则难以同时满足，须选主控力。
- **模型设计**：定比尺、选准则、校验次要力；宽浅河道用变态模型妥协。
- **量纲分析**：$\pi$ 定理给出无量纲参数，弗劳德数、雷诺数等全部由此「长出」。
- **现代形态**：实体模型、数值模型（CFD）与人工智能结合，互相校核。

《水力学》十章的旅程到此结束——从静止的水到运动的场，从能量到阻力，从公式到模型。
