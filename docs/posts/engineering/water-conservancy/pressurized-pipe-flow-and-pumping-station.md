## 为什么从有压管道流动与泵站开始

城市供水、农业提灌、火电站循环冷却、跨流域调水——这些工程里水走的都是**有压管道（pressurized pipe）**：管道被水充满，没有自由水面，压强由泵或高差维持。明渠靠重力自流，有压管道则必须回答两个新问题：**水沿管道流过去要损失多少能量**（管径怎么定），以及**突然关阀停泵时，水流惯性会掀出多大的冲击波**（水击怎么防）。<span class="marginnote">明渠与管道的区别不只是「盖不盖盖子」：明渠的水面高度就是边界条件，管道的压强却是未知量——所以管道问题要把压强、流速两个未知量同时解出来。</span>

有压管道遍及现代生活的每个角落：自来水厂到千家万户的配水管道、南水北调等长距离调水工程的加压管段、石油天然气管道（水力学在这里升级为管流力学）、电厂的冷却水循环管。而**泵站**是这些系统的动力中枢——理解管道，就理解了这些基础设施的「血管」与「心脏」。

泵站是管道系统的「心脏」，它给水流注入能量，把低处的水抬到高处。本篇概述把管道水力计算、泵的基本原理与水击防护三件事串成一条线——这三件事分别对应「管道怎么算、泵怎么选、事故怎么防」，恰好是管道工程从设计到运行的完整链条。

## 1 沿程损失与局部损失：管道里的「油费」

水流在管道里流动，黏性造成摩擦，边界粗糙造成旋涡，机械能不断损失。水头损失分两类：

- **沿程水头损失** $h_f$：直管段因管壁摩擦产生的损失，用**达西—魏斯巴赫公式（Darcy-Weisbach equation）**：

$$h_f = \lambda \frac{L}{d} \frac{v^2}{2g}$$

其中 $\lambda$ 为沿程阻力系数（由雷诺数 $Re$ 与相对粗糙度决定），$L$ 为管长，$d$ 为管径，$v$ 为断面平均流速。

- **局部水头损失** $h_j$：弯头、阀门、变径处因流动方向与断面改变产生的旋涡损失：

$$h_j = \zeta \frac{v^2}{2g}$$

$\zeta$ 为局部阻力系数，由构件形状决定。<span class="marginnote">阻力系数 $\lambda$ 与 $\zeta$ 是水头损失计算的「词典」：前者由莫迪图查，后者查水力手册。工程上宁可多查一次表，也不凭感觉估——损失算错 30%，泵的扬程选择就会出错。</span>

几个常见的局部阻力系数量级值得记住：渐扩管 0.25–0.3、90 度弯头 0.5–1.1、全开闸阀 0.2、全开蝶阀 0.3 左右。一条管线上弯头、阀门动辄数十个，局部损失之和常常与沿程损失相当——**只算沿程不算局部，总损失会低估近一半**。这就是为什么长管道设计要「一笔一笔算局部」，而不是只看直管长度。

**工程直觉**：沿程损失与 $v^2$ 成正比，与管径 $d$ 成反比。管径从 $d$ 加大到 $2d$，过流能力可提高数倍而损失反而下降——所以长距离输水管道「宁粗勿细」，粗管前期投资大，但运行电费省；管径优化的本质，就是在这两者之间找经济平衡点。管道设计、水力计算与经济管径比选，详见详述篇《恒定管流》。

管流的另一个关键概念是**流态判别**。雷诺数 $Re = \frac{vd}{\nu}$（$v$ 为流速、$d$ 为管径、$\nu$ 为水的运动黏度，约 $1.0\times10^{-6}\,\text{m}^2/\text{s}$）小于 2000 左右为**层流**，大于 4000 为**湍流**。工程管道几乎总是湍流，阻力系数 $\lambda$ 由**莫迪图**按 $Re$ 与相对粗糙度查得——层流与湍流的 $\lambda$ 表达式不同，判断错流态，损失就会算错一个量级。

## 2 泵与泵站：给水注入能量的心脏

**水泵（pump）** 把机械能转化为水流的压能与动能，是提水工程的核心设备。工程中最常用的是**离心泵**：叶轮高速旋转，将水从叶轮中心甩向四周，产生压力差把水连续吸上来、压出去。

泵的主要性能参数是**流量 $Q$、扬程 $H$、功率 $N$、效率 $\eta$**，它们由**泵的特性曲线**关联。泵的工作点由两条曲线决定：

- **泵特性曲线**：泵在一定转速下，$H$ 随 $Q$ 的变化关系；
- **管路特性曲线**：管路需要的扬程 = 净扬程 $H_{st}$ + 管路损失 $h_w$，即

$$H_{req} = H_{st} + h_w = H_{st} + \left( \lambda\frac{L}{d} + \sum\zeta \right)\frac{v^2}{2g}$$

两条曲线的交点就是**工作点**。**选泵的要点：让工作点落在泵的高效区**——效率最高的一段曲线内。<span class="marginnote">泵站常配多台泵并联运行，用「开几台、关几台」来调节流量；变频调速则通过改变转速平移泵特性曲线，是现代泵站节电的主要手段。</span>

**辨析｜易错点：** 扬程不是「能把水抽多高」的高度，而是泵对单位重量液体提供的能量所对应的水柱高度，数值上等于「净扬程 + 全部管路损失」。把扬程误当成出水高度，会导致选泵扬程不足、流量达不到设计要求。

机组的组合方式也要会选：**并联**（多台泵同时向一根总管供水）适合流量大、扬程不变的工况；**串联**（前一台出口接后一台入口）适合扬程特别高的工况。变频调速则通过改变转速平移泵特性曲线——转速降低，流量与扬程随之下降，是节能调节的主流手段。设计时还要让各台泵避开「驼峰区」运行，防止流量震荡失稳。

泵还有一个与水力学直接相关的控制指标——**必需汽蚀余量（NPSHr）**。泵吸入口压强过低时，水会汽化形成空泡，空泡在叶轮高压区溃灭即发生**汽蚀**，叶轮被「啃」坏。保证「装置汽蚀余量 > 必需汽蚀余量」靠两件事：泵的安装高度不能太高（吸上高度有限），吸水管尽量短、直、粗以减小损失。汽蚀是水泵运行的头号杀手，也是泵站设计中必须校核的工况。

一座完整的泵站由**进水池（前池）、进水管、泵房、出水管、出水池**等组成：进水池保证水泵有良好的进水条件（防止吸气旋涡），泵房内布置机组与电气设备，出水管把加压后的水送到出水池或压力管线。泵站的总体布置要综合考虑取水、防洪、地质与运行检修——它是水力学、结构与机电三专业的汇合点，详见详述篇《泵站》。

## 3 水击：管道里的冲击波

**水击（water hammer）**：管道中流速突然变化（如快速关阀、突然停泵）时，水流惯性使压强发生剧烈波动的现象。它是最危险的管道瞬态过程——压强骤升可能胀裂管道，骤降则可能压瘪薄壁管。水击属于**管道水力过渡过程**，是水力学里最需要「时间观念」的课题——前面的恒定流问题都是「稳定态」，水击则是一道「波动力学」问题。

它之所以「危险」，是因为涉及的能量极大：一根百米级压力钢管里以数米每秒流动的水，其动能集中释放时足以把管壁顶爆。因此水击防护不是「可选项」，而是长距离输水、泵站、水电站压力管道设计的**必做项**。

水击压强的核心估算式是**儒科夫斯基公式（Joukowsky formula）**（直接关阀、忽略摩阻时）：

$$\Delta p = \rho c \Delta v$$

- **$\Delta p$**：压强突变增量（帕）；
- **$\rho$**：水的密度（约 $1000\,\text{kg/m}^3$）；
- **$c$**：水击波速，钢管中水击波速可达 $800$–$1200\,\text{m/s}$；
- **$\Delta v$**：流速突然变化量。

**公式解析：一次关阀产生的压强增量**

- **第一步，读懂波速**：$c$ 取决于水体与管壁的弹性。钢管的 $c$ 约为 1000 米每秒——远快于水本身，所以关阀瞬间压强变化不是「慢慢传上来」，而是以声速量级的波在管内来回反射；
- **第二步，代入数字**：设 $c = 1000\,\text{m/s}$，流速从 $1\,\text{m/s}$ 突然变为 0，则 $\Delta p = 1000 \times 1000 \times 1 = 10^6\,\text{Pa} \approx 10$ 个大气压——一次普通关阀，管内压强可能瞬间多出十个大气压；
- **第三步，防护措施**：既然「关得越快、波越凶」，防护就围绕**减慢流速变化速率**展开——延长关阀时间、装**调压塔（调压井）**让波动有缓冲空间、装**水击消除器**或安全阀在超压时泄压。

<span class="marginnote">水击波的反射过程：关阀→压强升高→波向上游传→被水池反射为降压波→回传→管端压强骤降。一个周期内压强在「正最大」与「负最小」之间震荡，衰减需要多个周期。泵站突然断电停泵时发生的「停泵水锤」是工程上最常遇到的场景。</span>

**工程实例**：抽水蓄能电站与长距离调水工程都把水击分析列为设计必备环节。南水北调中线输水干渠虽然以明渠为主，但其泵站加压段与分水口都做过完整的水锤模拟，确保事故停泵时管路压强不超过管材承压能力。水击的完整波动过程与数值解法，详见详述篇《水击》。

水击波在一个周期的传播过程可以拆成四阶段：**升压波上行**（关阀端压力骤升，波向上游传）→**降压波下行**（波到上游水库被反射为降压波，回传）→**降压波作用**（管端压力骤降）→**升压波再回**。一个完整周期约 $4L/c$（$L$ 为管长），期间管内压强在正负最大之间震荡，若不衰减足以胀裂或压瘪管道。**理解「波」的往返，是理解水锤防护装置工作原理的前提**——调压塔正是利用其水面自由，把波动压力「消化」掉。

最危险的工况是**停泵水锤**：泵站突然断电，水泵失速，水流惯性使管内出现压强骤降甚至水柱拉断（断流弥合），随后水流回流撞击泵叶，产生第二波高压——这是泵站事故中最常见的爆管原因。防护手段除前述三策外，还常用**缓闭式止回阀**、**水锤消除器**与**两阶段关阀程序**，把水锤压强控制在管材允许范围内。

## 4 管道系统的设计与运行要点

把以上内容串成一条设计主线，一个长距离输水管道系统的设计流程大致是：

1. **确定设计流量与净扬程**：由供水规模与地形高差算出必需扬程；
2. **经济管径比选**：比较不同管径的「年造价 + 年运行电费」，取总费用最小的管径；
3. **选泵与机组配置**：按工作点落在高效区选泵，必要时并联、串联或变频调速；
4. **汽蚀校核**：验算泵的安装高度与吸水管布置，保证不发生汽蚀；
5. **水击分析**：对关阀、停泵工况做水锤模拟，配置调压塔、缓闭阀等防护设备；
6. **运行调度**：按需开停机、多泵组合，兼顾效率与安全。

这六步每一步都用到了本篇的水力学工具——从达西公式到儒科夫斯基公式，一条管道系统就是一部浓缩的水力学教科书。它也再次印证概述系列开篇的判断：**水力学不是一门孤立的课，而是水利工程一切计算的共同语言**——管流如此，明渠、水击、泵站皆是如此。

## 5 小结

- **沿程损失** $h_f = \lambda \frac{L}{d}\frac{v^2}{2g}$ 与**局部损失** $h_j = \zeta\frac{v^2}{2g}$ 是管道水力计算的基础，与 $v^2$ 成正比、与管径成反比。
- **雷诺数**判别层流与湍流，阻力系数 $\lambda$ 由莫迪图按 $Re$ 与相对粗糙度查得。
- **离心泵**通过叶轮把机械能转化为水的压能；**工作点**是泵特性曲线与管路特性曲线的交点，选泵要让工作点落在高效区。
- **扬程** = 净扬程 + 全部管路损失，不是简单的出水高度；**汽蚀余量**校核防叶轮汽蚀。
- **水击**由流速骤变引起，压强增量 $\Delta p = \rho c \Delta v$，一次快关阀可增十多个大气压；水击波一个周期约 $4L/c$。
- 防击三策：**延长关阀时间、设置调压塔缓冲、加装水击消除器**；停泵水锤是泵站最危险工况。
- 泵站由进水池、泵房、出水管等组成，设计六步走：定流量、比管径、选泵、校汽蚀、算水锤、定调度。
- 并联、串联与变频调速是泵的组合与调节手段，选型要让工作点避开驼峰区。
