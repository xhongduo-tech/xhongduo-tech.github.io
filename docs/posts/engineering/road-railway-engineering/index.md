# 道路与铁道工程

对标权威教材体系，按章节逐节写成博文。学完一个学科 = 写完该学科权威教材对应的全部博文。

## 对标教材

- 邓学钧, "路基路面工程" (人民交通出版社经典教材，多版次)
- 黄晓明, "路基路面工程" (公路方向主流教材)
- AASHTO, "A Policy on Geometric Design of Highways and Streets" (公路几何设计权威规范，俗称 Green Book)
- AREMA, "Manual for Railway Engineering" (北美铁路工程权威规范手册)

### 第1篇

- [ ] 道路与铁道工程概论（分级分类、设计速度、通行能力）
- [ ] 道路勘测设计基础（选线定线、平面线形设计要素）
- [ ] 纵断面与横断面设计（纵坡、竖曲线、路幅组成）
- [ ] 道路交叉口设计（平面交叉渠化、立体交叉选型）
- [ ] 路基工程（路基结构、压实、排水与防护）
- [ ] 路基稳定性分析（边坡稳定、软基处理、挡土结构）
- [ ] 路面结构理论（弹性层状体系、沥青路面力学响应）
- [ ] 沥青路面设计（材料特性、配合比设计、结构设计方法）

### 第2篇

- [ ] 水泥混凝土路面设计（板应力分析、接缝与配筋）
- [ ] 铁道轨道结构（钢轨、轨枕、道床与道岔）
- [ ] 轨道几何形位与线路设计（曲线超高、缓和曲线、轨距）

- [ ] 路基路面施工与检测（施工工艺、压实度与平整度检测）
