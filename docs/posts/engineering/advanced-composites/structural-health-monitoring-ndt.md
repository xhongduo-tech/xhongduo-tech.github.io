## 为什么从结构健康监测与无损检测开始

第5篇我们讲过一个「阴险」的事实：复材的冲击损伤常常**表面无痕、内部重伤**。那么问题来了——内部分层到底怎么「看见」？金属可以目视检查裂纹，复合材料靠眼睛远远不够。于是诞生了一门专门的工程技术：**无损检测（Nondestructive Testing, NDT）**与它更进阶的兄弟**结构健康监测（Structural Health Monitoring, SHM）**。

无损检测之于复材，相当于「体检」之于人：结构带着「看不见的伤」服役，检测就是把它揪出来、评估它还能不能扛。它与第5篇的损伤容限设计是一对搭档——**没有可靠的检测，损伤容限只是空谈**。这一篇讲透两大明星手段：**超声 C 扫**（给结构「拍 X 光」）与**声发射**（听结构「喊痛」），并带出热成像、剪切成像等兄弟方法。<span class="marginnote">NDT 与 SHM 的区别：NDT 是「定期体检」——停机、拆开、扫一遍；SHM 是「随身手环」——传感器长期贴在结构上，实时在线监控。飞机机队维保正从「定期 NDT」走向「状态维修（condition-based maintenance）」。</span>

NDT 也常被误解为「生产完成后的事」，其实它贯穿全生命周期：**原材料的出厂检验 → 成型件的出厂 C 扫 → 装机前的复验 → 服役期的定期巡检 → 修理后的复检**。每一件上飞机的复材件，出厂都带一份「体检报告」；而这份报告，正是第3篇工艺质量（孔隙率、分层）在合格证上的最终背书。

这一篇对应 Daniel–Ishai《工程复合材料力学》第10章《实验方法》与 Hull–Clyne 第12章《应用》。它是全专题从「材料与结构」走向「使用与运维」的转折篇。

需要指出，Daniel–Ishai 第10章系统梳理了复材的**标准力学试验**（拉伸、压缩、剪切、弯曲、层间剪切、断裂韧性等，对应 ASTM 系列标准）——这些试验既是材料许用值的来源，也是本专题第4、5篇理论验证的基石。而超声、声发射、热成像等 NDT 手段，则对应检验这些性能在服役中「是否还保得住」。**试验确认「出厂性能」，检测确认「服役状态」**——两者是一枚硬币的两面。

## 1 为什么要给复材做「体检」

金属结构的裂纹在表面，目视就能发现大半；复材则不同，它的典型损伤长在**内部**——层间分层、纤维断裂、芯材脱粘，表面却往往完好。更棘手的是，复材损伤常常「不声不响」地发展：今天一个小分层，明天在载荷下扩展成大片。

因此复材结构的安全理念建立在**「假设有伤」**之上（即第5篇讲的 BVID 与损伤容限）：设计时假定「存在看不见的损伤也能安全」，服役时则靠 NDT 定期确认「损伤没有长到危险尺寸」。**NDT 的核心任务，是回答三个问题：有没有损伤？伤在哪里？伤有多大？**——三问齐备，才能给出「继续飞、限载飞、还是停飞修理」的决策。

NDT 还是**型号取证（certification）**的硬性门槛：B787、A350 这类采用大量复材的机型，取证时民航局要求提交完整的无损检测工艺规范、灵敏度验证与人员资质体系。一张 C 扫图背后，是一整套「检测标准 + 操作规范 + 人员培训 + 数据存档」的体系工程——**NDT 的可靠性，一半靠仪器，一半靠体系**。

## 2 超声 C 扫：给复材「拍 X 光」

**超声检测（ultrasonic testing）**是航空复材 NDT 的绝对主力。原理朴素：换能器发出超声波（常用 1–10 MHz），波在材料里传播，遇到界面（如分层、孔隙、脱粘）会**反射**回来；接收反射波并分析其飞行时间与幅值，就能「看见」内部结构。

**超声 C 扫（ultrasonic C-scan）**是其中最有名的一种：探头发射—接收后，逐点扫过整个部件表面，把每一点的反射幅值（或透射衰减）编码成灰度/颜色，拼成一幅**二维损伤图**——分层在图上呈现为清晰的暗区。<span class="marginnote">C 扫图相当于给零件拍了「B 超」：亮区是健康材料，暗区是缺陷。一块蒙皮扫完，损伤的形状、位置、面积一目了然。配合 A 扫（单点波形）与 B 扫（截面图）可以进一步判断缺陷深度。</span>

超声检测有两类布置：**反射法（pulse-echo）**用单个探头收发，适合单侧可及的部位；**透射法（through-transmission）**用两个探头对置，一发一收，对厚件与大面积蒙皮更灵敏。波在缺陷处的衰减幅度还与缺陷大小相关，可以用**衰减法则**做半定量评估——缺陷越大、衰减越强、C 扫图越暗。

C 扫的工程实施有讲究：探头要**浸水耦合或水柱耦合**（空气会反射超声波，必须在探头与零件间填耦合介质），并按设定的**步进网格（raster）**逐点移动，一个蒙皮件扫完可能需要数小时到数天。为提高效率，现代 C 扫用**相控阵探头（phased array）**——一个阵列探头发射多束波、电子聚焦，一次扫过更大范围，还能现场成像。**仪器进步的本质，是把「扫得准」与「扫得快」同时做到**。

**公式解析：衰减与缺陷的关系。** 超声在材料里传播时强度按指数衰减：

$$
I = I_0 e^{-\alpha x}
$$

- **第一步，认识符号**：$I_0$ 是入射强度，$I$ 是传播距离 $x$ 后的强度，$\alpha$ 是衰减系数（与频率、材料、缺陷密度有关）。
- **第二步，读公式**：缺陷越多、$\alpha$ 越大，同样距离下剩余信号越弱——C 扫正是把这个「弱」翻译成了「暗」。
- **第三步，工程直觉**：孔隙率每上升一点，$\alpha$ 明显增大；一块孔隙率超标的面板，在 C 扫图上就是一片「雾」。这就是为什么第3篇热压罐件要求孔隙率 <1%——**工艺质量与检测结果直接挂钩**。

解读 C 扫图还需要一点「读片」经验：除了分层暗区，还要识别**边界效应**（零件边缘的回波干扰）、**表层波**（表面状况引起的假信号）与**内部结构**（如蜂窝芯的规律花纹）。这正是为什么 NDT 人员要持证上岗、且按严格程序执行——**仪器给出的是数据，判断依赖的是受过训练的「眼睛」**。一块蒙皮要不要放行，最终是持证 NDT 工程师签字的责任。

## 3 声发射：听结构「喊痛」

如果说超声是「主动拍片」，**声发射（Acoustic Emission, AE）**就是「被动听诊」：损伤发生时（纤维断裂、基体开裂、界面脱粘、分层扩展），材料内部会瞬时释放弹性波——像骨头断裂时「咔」的一声。传感器贴在结构表面，捕捉这些**应力波**，从而**实时定位与报警**。

AE 的独特价值在于它是**动态的、在线的**：超声只能在停机时检测既有损伤，AE 却能在一根承力构件**正在加载**时，实时监听损伤事件的发生与增长。常用于：压力容器/气瓶的加载验收、复合材料结构件的载荷试验、疲劳试验中的损伤演化监控。<span class="marginnote">AE 不仅能定位，还能「分类」：不同损伤机制释放的波形特征（幅值、频率、能量）不同——基体开裂的幅值低而密，纤维断裂的幅值高而稀。有经验的工程师能从 AE 信号的「指纹」猜出内部正在发生什么。</span>

AE 也有量化的标尺：每次声发射事件的能量正比于波形包络的平方积分，常以 **MARSE 能量（Measured Area under Rectified Signal Envelope）** 统计；事件**计数率**（单位时间事件数）随载荷上升的曲线形态，被称为 **Kaiser 效应**（重复加载到同一载荷之前，不再产生新的 AE 事件）——利用 Kaiser 效应，可以判断结构是否受过**历史超载**。**AE 把「损伤历史」也一并读了出来**，这是它比静态检测多出来的信息维度。

AE 的局限也要说清：它**不能直接测量既有损伤的静态尺寸**（那是超声的活），且材料背景噪声大、信号易混淆。工程上常「超声定位、AE 报警」组合使用——**AE 管「正在发生」，超声管「已经存在」**。

AE 的定位原理也值得一提：在结构表面布置**多个传感器**，同一损伤事件到达不同传感器的时间不同，利用**时差三角定位法**反推事件源位置——就像地震定位一样。传感器阵列的密度决定了定位精度，也决定了系统成本，这正是 SHM 工程里「精度 vs 预算」的经典权衡。**AE 系统设计，是在「布多密的网」与「花多少钱」之间找平衡**。

## 4 其他手段：热成像、剪切成像、X 射线

复材 NDT 还有一整个家族：

- **红外热成像（thermography）**：给表面快速加热，用红外相机拍温场变化——分层处导热差，会呈现「热斑」。适合大面积快速筛查。
- **剪切成像（shearography）**：用激光干涉测量表面微变形，对近表面分层与脱粘敏感，常用于蜂窝/夹芯结构。<span class="marginnote">剪切成像在飞机客舱、直升机旋翼的蜂窝面板检测里很常见——它能「看出」蒙皮与蜂窝芯的脱粘，而这种脱粘在超声下常常被蜂窝的杂散回波淹没。</span>
- **X 射线/CT**：能看密度差异，适合金属夹杂与厚件，但辐射防护与成本高、对薄层分层的分辨率有限。
- **敲击检测（tap test）**：用锤敲听声——健康区声音清脆、分层区声音发闷。看似原始，却是机务最常用的一线手段。

| 手段 | 原理 | 看什么 | 优势 | 局限 |
| --- | --- | --- | --- | --- |
| 超声 C 扫 | 反射/透射波 | 分层、孔隙、脱粘 | 定量、深部 | 需耦合、停机 |
| 声发射 | 捕获损伤应力波 | 损伤发生与扩展 | 实时在线 | 不测静态尺寸 |
| 热成像 | 温场差异 | 分层、芯材脱粘 | 快速大面积 | 深度分辨率有限 |
| 剪切成像 | 激光干涉变形 | 近表面分层、脱粘 | 蜂窝件强项 | 设备贵 |

这张表也提醒我们：**没有万能检测法**。工程实践是按部件、损伤类型、可达性、成本来「混搭」手段——大蒙皮用超声透射，蜂窝舱板用剪切成像，机翼根部的关键焊缝用相控阵超声。**NDT 工程师的工作，一半是技术，一半是「选对工具」的工程判断**。

X 射线/CT 值得一提：工业 CT 能重建出结构的三维密度体素图，直接「看到」内部的分层曲面、孔隙团与夹杂，是科研与失效分析里的「金标准」。但它设备昂贵、扫描慢、有辐射防护要求，主要用于**失效事故分析**与**工艺研发验证**，而不是日常批量巡检——**越精密的工具，越要花在刀刃上**。

NDT 是「定期体检」，SHM 则是「随身手环」——把传感器**长期埋进或贴上**结构，实时收集数据，在线判断健康状态。常用传感器包括**压电换能器**（可自发超声、也可接收 AE）、**光纤光栅（FBG）**（测应变与温度，抗电磁干扰、可多点复用）、**电阻应变片**、**智能涂层**等。

NDT 标准化程度极高，这是它区别于「实验室检测」的关键：超声、声发射、热成像等都有成套 **ASTM/EN/ISO 标准**（如 ASTM E2580 声发射、ASTM E2662 红外热成像）规定设备、试块、灵敏度与报告格式。标准的存在让「不同厂家、不同人员、不同时间」的检测结果可互比、可复现——**检测的可重复性，是航空安全体系信心的来源**。

FBG 传感器尤其值得一提：一根光纤上可以「写」几十上百个光栅点，每个点反射不同波长的光，测出的应变会使反射波长偏移——**一根光纤就是一根布满测点的「神经」**，且不怕雷击、不干扰电磁环境，非常适合飞机与桥梁的长距离监测。近年来**分布式光纤**（利用瑞利/布里渊散射测全程应变）更进一步，把整根结构都变成了传感网——**结构健康监测正从「布点」走向「布网」**。

SHM 的理想是**按需维修**：不再按固定间隔检修，而是让结构自己「报告」健康状态，坏了才修、快坏了预警。它背后是数据、算法与可靠性的综合工程——第12篇会讲到，SHM 的意义远不止安全，更是**降低全寿命成本**的利器。<span class="marginnote">飞机上 SHM 传感器还能用于「超限记录」：如果某次飞行载荷超限，系统自动提示机务去重点检查特定部位——把「一刀切大检」变成「有的放矢的精准检」。</span>

实现 SHM 离不开数据链路：传感器 → 采集 → 特征提取 → 损伤诊断 → 维修决策。其中**损伤诊断**是难点——要把原始波形/应变数据翻译成「损伤位置与程度」，常用的有基线对比法、机器学习分类法、基于模型的参数辨识法。近年深度学习的兴起，让「从声发射波形直接预测损伤类型」成为现实，SHM 也因此与《代码智能与 AI 辅助编程》《机器学习》等课程直接交汇——**结构监测正在变成一项数据工程**。

**辨析｜易错点：** 不要把「NDT 检出缺陷」等同于「结构要报废」。检出缺陷后要做**损伤评估**：参考设计许用值判断该缺陷是否在容限内、要不要修理、修到什么程度。**检测是手段，决策才是目的**——这与第5篇损伤容限设计的完整链条（检测—评估—决策—修复）完全咬合。

另一处易错：**超声的灵敏度不等于检出率**。检测标准里讲的「能检出 1 mm 缺陷」，指的是在标准试块上的标称灵敏度；真实结构上探头可达性、表面状态、零件几何都会折损实际检出率。工程上常用**概率检测曲线（POD, probability of detection）**描述「缺陷多大时检出概率有多高」——**NDT 不是非黑即白，而是概率性事件**，安全裕度正由此而来。

## 6 小结

- 复材损伤「表面无痕、内部重伤」，NDT 是损伤容限设计的必要搭档，回答「有没有伤、伤在哪、伤多大」。
- **超声 C 扫**是主力：波遇界面反射、按衰减成像，孔隙与分层呈现为暗区，衰减服从 $I = I_0 e^{-\alpha x}$。
- **声发射**是「被动听诊」：实时捕获损伤释放的应力波，管「正在发生」，与超声「管已存在」互补。
- 家族还有**热成像、剪切成像、X 射线、敲击法**，各有擅长场景。
- **SHM** 把传感器长期贴进结构，实现状态维修与超限记录，从「定期体检」走向「随身手环」。
- NDT 检出的缺陷须做损伤评估再决策，检测是手段、决策是目的。
- NDT 是型号取证硬门槛：B787/A350 的完整检测体系 = 标准 + 规范 + 人员 + 存档。
- 混搭选择：超声管蒙皮、剪切管蜂窝、AE 管实时，没有万能检测法。
- AE 的 Kaiser 效应可读「历史超载」，工业 CT 是失效分析的「金标准」。
- SHM 正在变成数据工程：波形/应变 → 特征 → 机器学习诊断 → 按需维修决策。
- NDT 贯穿全生命周期：出厂 C 扫 → 装机复验 → 服役巡检 → 修理复检，每件复材件都带体检报告。
- ASTM/EN/ISO 标准让检测可复现、可互比，是航空安全体系的信心来源。
- NDT 是概率性事件，用 POD（检出概率曲线）描述灵敏度，安全裕度由此而来。
