## 为什么从数字医疗与远程医疗开始

前几节的《医疗监护仪器》《可穿戴健康监测》已经频繁提到「联网」「数据接入电子病历」——这一节把它们放进更大的图景：**整个医疗系统本身的数字化与网络化**。从电子病历、医学影像存档，到远程会诊、互联网医院、医疗物联网，数字技术正在重塑医疗的形态与边界。<span class="marginnote">从「从极限到大模型」的课程线上看，数字医疗是第三级《数据库》《计算机网络》《云计算》与《信息安全》在医疗场景的落地——一张电子病历就是数据库应用，一次远程手术就是低时延网络的考题，而医疗数据的隐私保护则是一场安全的硬仗。</span>这一节讲四层：电子病历与数据标准、医学影像数字化（PACS）、远程医疗的形态与技术、以及医疗数据安全。

## 1 电子病历与医疗数据标准

**电子病历（Electronic Health Record，EHR）** 是数字医疗的地基——把患者的历史病历、检验、影像、用药、医嘱整合成结构化数字记录。

**为什么电子病历难**：医疗数据**异构且分散**——不同科室、不同设备、不同厂商，数据格式五花八门。要让数据「能交换、能理解」，需要**标准**：

| 标准 | 用途 |
| --- | --- |
| HL7（v2/v3） | 医院信息系统间的消息交换（检验结果、医嘱） |
| FHIR | 现代 RESTful 互操作标准，资源化建模 |
| DICOM | 医学影像与元数据（见《医学图像处理》） |
| ICD 编码 | 疾病与操作的标准化分类 |
| SNOMED-CT | 临床术语本体 |

**FHIR（Fast Healthcare Interoperability Resources）** 是当前互操作的主流：把临床数据建模为「资源」（Patient、Observation、Encounter），用 REST API 暴露——医生 App、健康档案、区域平台都基于它交换数据。<span class="marginnote">FHIR 的意义在于把「医院信息孤岛」变成「可编程的医疗数据生态」：<strong>数据不再是躺在系统里的私有资产，而是可通过标准 API 被授权的应用调用</strong>。这也正是《医学人工智能》能拿到大数据训练的前提——没有互操作标准，就没有医疗 AI 的规模数据。</span>

## 2 医学影像数字化：PACS 与影像共享

**PACS（影像归档与通信系统）**：存储、传输、显示医学影像的数字化系统，与 **RIS（放射信息系统）** 配合管理影像检查全流程。

**PACS 的组成**：

**DICOM 存储**：影像服务器按 DICOM 标准归档；
**工作流**：检查申请 → 采集 → 归档 → 阅片 → 报告；
**阅片工作站**：放射科医生在 PACS 工作站读片、测窗宽窗位、三维重建；
**网络与云端**：从院内局域网走向区域影像云、影像共享（检查结果互认）。

**影像的「数据量难题」**：一张 CT 数百张断层（数百 MB）、一次 PET/CT 超 GB——影像数据量每年指数增长，对存储、传输（《计算机网络》的带宽）、压缩算法提出持续挑战。<span class="marginnote">影像数据是医疗大数据的「重矿」：<strong>一张影像包含的信息密度远高于一段文本</strong>。DICOM 影像 + 结构化报告构成「可标注的训练数据」，这是医学影像 AI（肺结节、眼底病筛查）能落地的物质基础。</span>

## 3 远程医疗：跨越地理的诊疗

**远程医疗（telemedicine）**：用通信技术提供远距离的医疗服务。形态分三种：

| 形态 | 场景 | 技术要点 |
| --- | --- | --- |
| 异步（存储转发） | 影像远程会诊、病理远程诊断 | 高质量图像传输 + 专家阅片 |
| 同步（实时） | 视频问诊、远程手术指导 | 低时延音视频 + 数据协同 |
| 远程监护 | 居家慢病管理、术后随访 | 可穿戴/家用设备数据回传（衔接《可穿戴健康监测》） |

**远程医疗的技术支撑**：

**低时延音视频**：视频问诊需要可靠、清晰的音视频通道；
**数据安全传输**：医疗数据经加密通道传输（VPN、HTTPS、专用医疗网络）；
**区域医疗协同**：医联体、远程会诊平台把基层与三甲连接起来——**「优质医疗资源下沉」的工程实现**。

**远程手术**是远程医疗的极限形态：主刀医生在远端操作机器人，本地机械臂执行——对网络时延、可靠性、安全性要求极高（手术级时延需数十毫秒内）。<span class="marginnote">远程手术的工程哲学是「网络即器械的一部分」：<strong>一次网络抖动对视频会议只是卡顿，对远程手术就是安全事件</strong>。因此远程手术系统要有网络质量实时监测、故障预案（医生本地接管）、以及严格的适应症边界。</span>

**互联网医院与在线问诊**：把问诊、开药、随访搬到线上——疫情加速了这一进程。**「数字医疗的普惠价值」**在此显现：让偏远地区、行动不便者获得基础医疗覆盖，是数字医疗最重要的社会意义。

## 4 医疗物联网与医院数字化

**医疗物联网（IoMT，Internet of Medical Things）**：把监护仪、输液泵、呼吸机、可穿戴设备接入网络，实时汇聚数据：

**设备联网**：床旁设备数据自动上传电子病历（消除手工记录）；
**资产追踪**：设备定位、盘点、维护预警（RFID/蓝牙）；
**环境监测**：冷链药品温度、手术室环境监控；
**智能病房**：床旁终端、呼叫系统、患者教育。

**医院信息化的架构**：从「收费/挂号系统」到「临床信息系统（CIS）→ 电子病历 → 大数据平台 → 临床决策支持（CDSS）」——信息化程度决定医院能走多远的数字化与智能化。

**辨析｜易错点：** 「数字化 = 信息化 = 智能化」是常见混淆。**数字化**（把纸面变成电子）→ **信息化**（数据互通、流程线上化）→ **智能化**（AI 辅助决策）是三个不同层次。许多医院停留在信息化阶段，离《医学人工智能》的智能化还有相当距离——**数据质量与流程标准化是智能化的前提**，没有高质量数据就没有可靠 AI。

## 5 医疗数据安全与隐私

医疗数据是最敏感的个人数据之一（健康信息、基因组数据、病历）。**医疗数据安全**涵盖：

**法规合规**：中国《个人信息保护法》《数据安全法》、美国 HIPAA、欧盟 GDPR——医疗数据被列为敏感数据，处理有严格合规要求；
**技术安全**：传输加密（TLS）、存储加密（静态加密）、访问控制（RBAC）、审计日志；
**脱敏与匿名化**：研究用数据需去标识化（移除姓名、身份证号等直接标识）；
**网络安全**：医院系统是勒索软件的高发目标——**一次勒索攻击可以让医院退回「纸笔时代」**，网络弹性和备份恢复是数字医疗的底线。

**辨析｜易错点：** 「数据脱敏后就可以随便用」是危险误解。去标识化不等于匿名化——高维数据（基因组、影像、时间戳组合）可能被「重识别」。**在数据共享与科研需求之间，合规不是「去掉几个字段」这么简单**，需要专门的数据治理框架与伦理审查。

## 6 数字医疗的未来：数据、AI 与普惠

**医疗大数据平台**：临床数据、影像数据、可穿戴数据、基因组数据的整合分析（衔接《医学人工智能》）；
**临床决策支持（CDSS）**：基于指南与数据的诊疗建议、用药提醒、风险预警；
**数字疗法（DTx）**：软件即治疗——基于 App/可穿戴的行为干预（衔接《可穿戴健康监测》）；
**区域医疗互联互通**：检查结果互认、跨院病历调阅、医保数据联动；
**全民健康数字化**：健康档案、疫苗记录、慢病管理全覆盖——**数字医疗的终局是「以人为中心的连续健康数据」**。

<span class="marginnote">数字医疗最深刻的改变不是「多了几个 App」，而是<strong>把医疗从「信息不对称的一次性交易」变成「数据驱动的连续服务」</strong>：医生能看到患者的长期趋势，患者能参与自身健康管理。这个转变的技术基础是数据标准、网络安全与 AI——三者缺一不可。</span>

## 7 数字医疗的关键参数速查

**数字医疗的工程参数速查**：

| 参数 | 典型值 | 含义 |
| --- | --- | --- |
| 单张 CT 图像数据量 | 数百 KB–数 MB | 存储压力 |
| 一次 CT 检查数据量 | 数百 MB | 传输与归档 |
| 一次 PET/CT | 超 1 GB | 大数据量级 |
| 远程会诊分辨率 | 高清（1080p） | 阅片质量要求 |
| 远程手术时延 | < 数十 ms | 网络可靠性命门 |
| 影像保存年限 | 至少 15 年（法规） | 长期存储 |
| 医疗数据加密 | TLS/AES | 传输与存储安全 |

**算例：影像数据量的量级。** 一台 512×512×20 的头部 CT，每像素 16 bit，原始数据约 512×512×20×2 ≈ 10 MB（不含重建与多序列）。一家三甲医院每天数百次 CT/MR/PET，**影像数据以 TB 级/年增长**——这就是 PACS 要分层存储（在线/近线/离线）与云化的原因，也是影像压缩算法的持续需求。

**辨析｜易错点：** 「远程医疗 = 视频问诊」是窄化理解。远程医疗涵盖**异步（存储转发会诊）、同步（实时视频）、远程监护（数据回传）**三种形态——视频问诊只是同步形态的一个子集。**远程医疗的工程核心是「数据/信号的可靠传输 + 安全 + 临床流程适配」**，形式只是外壳。

## 8 小结

- **电子病历**是数字医疗的地基，**FHIR/HL7/DICOM** 等标准让异构数据能交换、能理解。
- **PACS** 实现影像的存储、传输与共享，影像大数据是医学 AI 的物质基础。
- 远程医疗分**异步、同步、远程监护**三形态，远程手术是极限考验（低时延+安全）。
- 医疗物联网把床旁设备接入网络，医院信息化是**数字化→信息化→智能化**的递进。
- 医疗数据是敏感数据，**合规、加密、脱敏、网络弹性**是安全底线；数字医疗的终局是「以人为中心的连续健康数据」。

在下一节，我们把数字医疗积累的数据交给最强大的工具：**医学人工智能**——当机器学习遇到医学，怎样的应用已经落地，怎样的边界仍需守候。
