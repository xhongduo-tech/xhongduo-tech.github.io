## 为什么从 X 射线开始

医学成像的历史起点是 1895 年伦琴发现 X 射线——人类第一次**不切开身体就能看见体内**。从「从极限到大模型」的视角看，X 射线成像是一个完美的工程链条：**辐射物理（第一级《基础物理》）→ 探测器电子学（第六级《电子科学与技术》）→ 图像生成（图像处理）**。<span class="marginnote">而且，X 射线是理解后面所有断层成像的钥匙：CT 不过是「许多张不同角度的 X 射线投影」的数学组合，PET 的伽马探测原理也同源。先吃透它，整个第二篇就通了三分之一。</span>这一节聚焦**投影 X 射线成像**（平片与透视），回答三件事：X 射线怎么产生、怎么与组织作用、怎么被探测成图。

## 1 X 射线的产生：X 射线管

**X 射线（X-ray）**：波长约 0.01–10 nm 的高能电磁辐射，光子能量在 keV–MeV 量级，由高速电子轰击金属靶产生。

X 射线管的核心结构是**两极真空管**：

**阴极**：钨丝加热发射热电子；
**阳极**：钨或钼靶，接高压（诊断用通常 40–150 kV）；
电子被高压加速轰击靶面，与靶原子作用产生 X 射线。

**X 射线的两种产生机制**：

1. **韧致辐射（bremsstrahlung）**：高速电子在靶核库仑场中减速，动能转化为 X 光子，产生**连续谱**。
2. **特征 X 射线**：入射电子击出靶原子内层电子，外层电子跃迁填补，辐射能量等于能级差的光子，产生**线状谱**——能量由靶材料决定，故称特征辐射。

<span class="marginnote">「一个 X 光子携带的能量决定了它能穿透什么」：能量高（短波长）穿透力强，称「硬 X 射线」；能量低（长波长）易被吸收，称「软 X 射线」。临床上用<strong>管电压 kVp</strong> 调节射线硬度——看骨骼用高 kVp，看软组织用低 kVp，这是一条贯穿全部 X 线应用的杠杆。</span>

## 2 X 射线与物质的相互作用

X 射线穿过人体时，光子与原子不断发生相互作用而被**衰减**。诊断 X 射线能量范围内（约 20–150 keV），主导机制有两个：

**光电效应（photoelectric effect）**：光子被原子吸收，能量转移给内层电子使其逸出。光电效应的截面与原子序数关系极大，近似 $\propto Z^3$，且随光子能量升高而下降。**X 射线影像的骨骼-软组织对比，主要来自光电效应**——骨含钙（$Z=20$）、软组织含氢氧碳（$Z\approx 6$–8），吸收差异大。

**康普顿散射（Compton scattering）**：光子与电子碰撞，能量降低、方向改变，产生散射光子。散射贡献了影像上的**噪声性背景**，也带来辐射防护上的散射线问题。

**衰减的数学描述（Beer-Lambert 定律）**：一束强度 $I_0$ 的单能 X 射线穿过厚度 $x$ 的均匀材料，出射强度为

$$I = I_0 e^{-\mu x}$$

其中 $\mu$ 是**线性衰减系数**（cm⁻¹），取决于材料与光子能量。

**公式解析：$I = I_0 e^{-\mu x}$**

- **第一步，符号含义**：$I_0$ 是入射强度，$I$ 是出射强度，$x$ 是穿过的物质厚度，$\mu$ 是线性衰减系数。
- **第二步，指数衰减的直觉**：每穿过一个厚度微元 $dx$，强度损失正比于当前强度 $-\mu I dx$，积分即得指数律。光子「一个接一个被吃掉」，剩余者按比例递减。
- **第三步，多组织路径**：人体是多种组织的串联，指数相乘，等价于把衰减系数沿路径积分：

$$I = I_0 \exp\left(-\int_{\text{路径}} \mu(x)\,dx\right)$$

这就是投影成像的核心方程：**出射强度携带了路径上所有组织的衰减信息**。后面的 CT 重建（《图像重建算法》）正是要反解这个「路径积分」。

**辨析｜易错点：** $\mu$ 与光子能量有关，**单能假设只是近似**。真实 X 射线束是多能谱，低能光子先被滤掉，等效衰减系数随穿透深度漂移，导致「射束硬化」（beam hardening）伪影——CT 里要用滤波补偿，此处先记住「能谱不是单色的」。

## 3 影像的形成：对比度从哪来

X 射线影像的本质是一幅**衰减系数的投影地图**。影像上的「明暗」取决于探测器接收到的光子数差异。

**对比度（contrast）**：相邻区域信号差与背景之比。骨-软组织边界的高对比度，来自二者衰减系数差一个数量级的事实（骨 $\mu \approx 1.5$ cm⁻¹，软组织 $\mu \approx 0.2$ cm⁻¹，量级随能量浮动）。<span class="marginnote">胸部平片能「看见」肺纹理，靠的是空气（几乎不衰减）与肺血管/软组织的巨大密度差；而腹部平片难以区分肝胆胰，因为它们的衰减系数太接近——对比度不足是投影成像的固有局限，也是 CT 与 MRI 存在的原因。</span>

**对比剂（contrast agent）**：当组织间衰减差异太小，就人为引入高 $Z$ 物质扩大差异。硫酸钡（胃肠道）、含碘化合物（血管、泌尿系统）都是高原子序数造影剂——它们把「看不见的腔道」变成高对比结构。

**现代探测器与成像链**：
- **传统**：胶片-增感屏（感光+荧光转换）；
- **数字化平板探测器（DR）**：非晶硅+闪烁体或非晶硒直接转换，把 X 光子变成数字像素；
- **图像链**：探测器阵列 → 数字化 → 对数变换（把指数衰减变回线性路径积分）→ 灰度映射。

## 4 临床应用与局限

**投影 X 射线的主流应用**：

| 检查 | 观察对象 | 关键点 |
| --- | --- | --- |
| 胸部平片 | 肺、心脏轮廓、肋骨 | 肺结节筛查的首选初筛 |
| 骨与关节 | 骨折、脱位、关节炎 | 高对比、低成本 |
| 钡餐/钡灌肠 | 消化道 | 造影剂充盈腔道 |
| 血管造影 | 血管狭窄、动脉瘤 | 碘对比剂+快速序列 |
| 乳腺钼靶 | 乳腺组织 | 低能软 X 线，软组织对比 |

**局限**：
- **重叠结构**：投影成像把三维物体压成二维，前后结构重叠，病灶可能被遮挡。
- **对比度不足**：软组织之间难分辨（这是 CT 的动机）。
- **辐射剂量**：电离辐射有随机性致癌风险（低剂量线性无阈假设），需遵循 ALARA 原则（尽可能低）。

**辨析｜易错点：** 「X 射线检查的剂量都很小，无害」是常见误解。虽然单次胸片剂量很低（约 0.02–0.1 mSv），但 CT 一次可达数 mSv，且儿科与孕期更敏感。**剂量管理是成像工程师的必修课**：在图像质量与辐射剂量之间取平衡。

## 5 小结

- X 射线由**高速电子轰击金属靶**产生，机制为韧致辐射（连续谱）与特征辐射（线状谱）。
- 诊断能量范围内，**光电效应**（$\propto Z^3$）主导骨-软组织对比，**康普顿散射**贡献散射背景。
- 衰减遵循 **Beer-Lambert 定律** $I=I_0e^{-\mu x}$，多组织路径等价于沿路径积分。
- 影像对比度来自**衰减系数差异**，对比剂以高 $Z$ 物质人为扩大差异。
- 投影成像的局限是**结构重叠**与**软组织对比不足**，辐射剂量须按 ALARA 管理。

在下一节，我们解决「重叠」这个投影成像的死穴：**CT 成像**——用几百个角度的投影，把三维人体从数学上「切开」看。
