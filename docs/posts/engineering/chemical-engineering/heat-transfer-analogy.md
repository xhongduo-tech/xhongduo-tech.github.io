## 为什么从热量传递类比开始

上一节建立了湍流下「动量、热量、质量」都由同一批涡携带传递的图像。
本节把它变成**定量工具**——通过类比关系，
用最容易测的量（阻力）去估计最难测的量（传热系数），
或由传热数据推算传质系数。
从雷诺类比、普朗特类比到冯·卡门类比，
再到**奇尔顿–科尔本 j 因子**——工程上应用最广的类比框架。
这些类比是化工原理中对流传热关联式与传质关联式的理论桥：
`Nu` 与 `f`、`Sh` 与 `f` 之间的对应关系由此而来。
<span class="marginnote">「类比省实验」是本节的价值：阻力系数实验最容易做（测压降即可），传热传质实验最难（要测壁温、浓度分布）。<strong>若湍流对三传的强化机制相同，则测出阻力就能换算传热传质系数</strong>——一套阻力数据，三传通用。这正是三传类比工程价值的核心。</span>

## 1 雷诺类比

**雷诺类比（Reynolds analogy）**是最简单的类比：
假设湍流核心内动量、热量、质量由完全相同的涡机制携带，
湍流 Pr、Sc 数均为 1，
则阻力与传热、传质直接对应。

对平板绕流：

$$Nu_x = \frac{1}{2}Re_x C_f, \qquad \frac{Nu_x}{Re_x Pr} = \frac{C_f}{2}$$

即**斯坦顿数 = 摩擦系数的一半**：

$$St = \frac{Nu}{Re\,Pr} = \frac{\alpha}{\rho u c_p} = \frac{C_f}{2}$$

**辨析｜易错点：** 雷诺类比只在 $Pr \approx 1$（气体近似）且无强压力梯度时成立。
水的 $Pr \approx 7$、油的 $Pr \gg 1$，
直接套雷诺类比会高估传热——需要计入 $Pr$ 的修正类比。
<span class="marginnote">斯坦顿数 $St$ 的物理：它把对流传热系数「归一化」成与摩擦系数同量纲——都是「传递速率 / 对流通量」之比。$St = C_f/2$ 的简洁形式让「测压降算传热」在气体场合成为可能，这是早期换热器估算的常用捷径。</span>

## 2 普朗特类比与冯·卡门类比

**普朗特类比（Prandtl analogy）**把近壁分成两层——黏性底层（层流）与湍流核心（涡流），
计入 $Pr$ 的影响：

$$\frac{Nu}{Re\,Pr} = \frac{C_f/2}{1 + \sqrt{C_f/2}(Pr - 1)}$$

$Pr = 1$ 时退化为雷诺类比；
$Pr > 1$ 时分母增大、传热系数降低（底层阻力被放大）。

**冯·卡门类比（von Kármán analogy）**进一步把近壁分成三层（底层、缓冲层、对数律层），精度更高：

$$St = \frac{C_f/2}{1 + 5\sqrt{C_f/2}\left[(Pr - 1) + \ln\frac{1+5Pr}{6}\right]}$$

<strong>类比的共同结构</strong>：$St$（或传热系数）= 摩擦项 × 一个 $Pr$ 修正因子——阻力测量 + $Pr$ 修正即可估计传热系数。<span class="marginnote">从雷诺（一层）到普朗特（两层）到卡门（三层），类比越来越精确：每一层用对应的传递机制（分子扩散 vs 涡流扩散）。三层模型抓住了近壁结构的本质，在 $0.5 < Pr < 10$ 范围内相当准确——这也再次印证「近壁普适剖面」是湍流传热的关键。</span>

## 3 奇尔顿–科尔本 j 因子

**j 因子（j-factor）**是工程上最普适的类比形式。对传热与摩擦：

$$j_H = \frac{Nu}{Re\,Pr^{1/3}} = \frac{St\,Pr^{2/3}}{1}, \qquad j_H = \frac{C_f}{2}$$

对传质（`Sh` 与 `Sc`）：

$$j_D = \frac{Sh}{Re\,Sc^{1/3}}$$

**奇尔顿–科尔本类比（Chilton–Colburn analogy）**的核心陈述：

$$j_H = j_D = \frac{C_f}{2}$$

即**传热 j 因子 = 传质 j 因子 = 摩擦系数的一半**。
$Pr^{2/3}$、$Sc^{1/3}$ 的引入把 $Pr$、$Sc$ 的影响显式扣除，
使类比在 $0.5 < Pr < 100$、$0.5 < Sc < 1000$ 范围内远优于雷诺类比。
<span class="marginnote">j 因子是工程手册的通用货币：换热器管束的 $j_H$ 关联、填料塔的 $j_D$ 关联、管道阻力系数 $f$，都用 j 因子互相换算。<strong>「测 $f$ 得 $j$，由 $j$ 得 $\alpha$ 或 $k$」</strong>成为传递过程的标准化操作。它还打通了传热传质实验数据的互译——冷却塔、干燥器、吸收塔的设计常靠 j 因子借用对方的实验数据。</span>

## 4 公式解析：j 因子与摩阻的关联

管内湍流的经典关联——**迪图斯–贝尔特**（化工原理已见）与 j 因子：

$$
j_H = \frac{Nu}{Re\,Pr^{1/3}} = 0.023\,Re^{-0.2}
$$

而管内湍流摩擦系数 $\lambda = 0.3164\,Re^{-0.25}$。
三步拆解这条「传热与阻力同源」的核心式：

- **第一步，指数对照**：
  $j_H \propto Re^{-0.2}$ 与 $\lambda/2 \propto Re^{-0.25}$——指数接近但不相等。
  奇尔顿–科尔本 $j_H = \lambda/2$ 是近似，
更精确的关系含 $Re$ 的微弱修正。
**相似但不完全相同**是类比的真实面孔。
- **第二步，$Pr^{1/3}$ 的来历**：
  由边界层理论，热边界层厚度 $\delta_t \propto \delta\,Pr^{-1/3}$，
  传热系数 $\alpha \propto 1/\delta_t \propto Pr^{1/3}$——**j 因子的 $Pr^{1/3}$ 来自热边界层与速度边界层的厚度比**，
  有坚实的边界层理论支撑。
- **第三步，工程换算**：
  测得阻力系数 $\lambda$ → $j_H = \lambda/2$ → $\alpha = j_H\,Re\,Pr^{1/3}\,\lambda/(d)$。
  **一套压降实验数据，估计出对流传热系数**——换热器设计初算的标准捷径。

**辨析｜易错点：** 类比成立的前提是「湍流核心控制、无强分离、无强浮力（自然对流）」。
粗糙管、绕流分离区、带翅片等复杂几何下类比误差增大——工程上常给类比式加几何修正或改用直接关联式。
**把类比当普适定律、无视适用边界，是传递计算的高频错误**。

## 5 类比的工程应用

- **换热器估算**：由管束摩擦数据或压降测量估计壳程/管程传热系数——无传热实验也能先算面积。
- **干燥与冷却塔**：气液直接接触中，
  传热与传质同时发生，
j 因子类比把两者联立（Lewis 关系的理论来源——回到《增湿与冷却塔》）。
- **吸收塔设计**：填料塔的传质系数可借用传热 j 因子数据换算，减少实验量。
- **催化剂与反应器**：颗粒床层内传热传质类比估算有效系数与热斑。
- **对流传质系数**：`Sh = j_D Re Sc^{1/3}`，
  由传热数据直接推算——化工原理传质章节的系数大多靠类比获得。
  <span class="marginnote">类比最深的工程影响是「<strong>少做实验、多换算</strong>」：传热数据比传质数据好测得（温度好测、浓度难测），j 因子让传质系数从传热数据「白拿」。现代 CFD 与关联式数据库中，类比仍是最快的初估工具——先类比估算、再精确计算，是传递设计的标准工作流。</span>

## 6 小结

- **雷诺类比** $St = C_f/2$：
  $Pr\approx 1$ 时阻力与传热直接对应。
- **普朗特/卡门类比**按近壁层数（2/3 层）计入 $Pr$ 修正，精度递进。
- **奇尔顿–科尔本 j 因子** $j_H = j_D = C_f/2$，
  $Pr^{1/3}$、$Sc^{1/3}$ 来自边界层厚度比，适用面最广。
- j 因子与 $Re^{-0.2}$ 的指数结构印证「传热与阻力同源」；
  测 $f$ 可估 $\alpha$、$k$。
- 类比前提：湍流核心控制、无强分离；复杂几何需修正或改直接关联。

在下一节，我们把类比扩展到质量传递——**质量传递（分子扩散/对流传质）**，
建立费克定律与传质系数。
