## 为什么从湍流传递开始

化工中的流动绝大多数是**湍流**：
管道内水、气体、换热器管束、塔内气液——$Re > 4000$ 即湍流。
湍流的特征是：速度随机脉动、强烈混合、传递速率比层流高一个数量级以上。
但湍流没有精确解，工程上靠**统计平均 + 湍流模型**处理。
本节建立湍流的描述框架——雷诺分解、雷诺应力、普朗特混合长、涡流扩散系数——并解释为什么湍流「传递快」：
它不是分子扩散，而是**流体微团的大尺度掺混**。
<span class="marginnote">湍流传递的本质是「<strong>涡的搬运</strong>」：流体微团携带动量、热量、质量横穿流场，比分子扩散快几个量级。化工原理里「湍流下对流传热系数远高于层流」，根源就是涡流扩散系数远大于分子扩散系数——湍流是工业传热传质的「免费加速器」，代价是不可精确预测。</span>

## 1 湍流特征与雷诺分解

**湍流（turbulence）**的特征：
随机脉动、涡旋多尺度、强扩散、耗散（把动能逐级传递给小涡最终耗散为热）。
描述湍流的基础是**雷诺分解（Reynolds decomposition）**——把瞬时量分解为时均与脉动：

$$u_x = \bar u_x + u_x', \qquad p = \bar p + p'$$

其中 $\bar u_x$ 是时均速度，
$u_x'$ 是脉动速度（时均值为零）。
**湍流强度** $I = \sqrt{\bar{u'^2}}/\bar u$ 度量脉动相对大小。
<span class="marginnote">雷诺分解是湍流的「统计化」：放弃逐时刻的精确描述，改看时均场 + 脉动统计。工程需要的正是时均量（平均流速、平均温度、平均浓度）——湍流的工程价值在平均，不在一瞬。时均化后，N–S 方程多出一项「雷诺应力」，那是湍流对平均场的额外作用。</span>

## 2 雷诺应力与混合长

对时均后的动量方程，多出的项是**雷诺应力（Reynolds stress）**：

$$\tau_t = -\rho\,\overline{u_x'u_y'}$$

它来自脉动速度的乘积平均——物理上代表「脉动把动量从一层搬运到另一层」产生的表观应力。
总切应力 = 分子黏性应力 + 雷诺应力：

$$\tau = \tau_{\text{lam}} + \tau_t = \mu\frac{\mathrm{d}\bar u}{\mathrm{d}y} - \rho\overline{u'v'}$$

**普朗特混合长理论（Prandtl mixing length）**：
类比分子平均自由程，假设流体微团在混合长 $l$ 内保持动量再掺混，得到：

$$\tau_t = \rho l^2\left|\frac{\mathrm{d}\bar u}{\mathrm{d}y}\right|\frac{\mathrm{d}\bar u}{\mathrm{d}y}$$

于是定义**涡流黏度（eddy viscosity）$\mu_t = \rho l^2|\mathrm{d}\bar u/\mathrm{d}y|$**——它不是物性，
而是流动状态的函数（依赖位置与湍流强度）。
<span class="marginnote">混合长是普朗特的天才类比：把「分子自由程」换成「涡的尺度」——分子碰撞传动量变成涡携带传动量。涡流黏度 $\mu_t$ 比分子黏度大几个量级（中心区可达 $\mu$ 的百倍以上），这就是湍流传速快的数学表述。<strong>$\mu_t$ 是流场性质而非流体性质</strong>——查表查不到，必须靠湍流模型算。</span>

## 3 湍流的近壁结构与通用速度剖面

湍流管流近壁处从壁面到中心分四层：

1. **黏性底层（viscous sublayer）**：
   $y^+ < 5$，分子黏性主导，
   速度线性分布 $u^+ = y^+$；
2. **缓冲层**：$5 < y^+ < 30$，分子与涡流相当；
3. **对数律层（logarithmic layer）**：
   $30 < y^+ < 500$，
   涡流主导，速度对数分布：
$$u^+ = \frac{1}{\kappa}\ln y^+ + B, \qquad \kappa \approx 0.41$$
4. **外区/中心**：速度趋于主流。

其中 $u^+ = \bar u/u^*$、$y^+ = yu^*/\nu$，
$u^* = \sqrt{\tau_w/\rho}$ 是**摩擦速度**。
<span class="marginnote">无量纲化的近壁剖面（$u^+$–$y^+$）是湍流的「普适语言」：不管管径、流速、流体，黏性底层与对数律层的无量纲分布几乎相同。阻力计算、传热传质类比、湍流模型的壁面函数，全部建立在这条普适剖面上。摩擦速度 $u^*$ 是连接壁面切应力与速度剖面的桥梁。</span>

**湍流阻力**：由对数律积分得管内湍流摩擦系数——**布拉修斯式**：

$$\lambda = \frac{0.3164}{Re^{0.25}} \quad (3\times10^3 < Re < 10^5)$$

这正是化工原理里见过的式子——现在我们知道它源自湍流边界层的对数律与普适剖面，而非纯经验。

## 4 公式解析：湍流热量/质量传递

湍流下热流密度与质量通量都写成「分子 + 涡流」两部分：

$$
q_y = -(a + a_t)\rho c_p\frac{\mathrm{d}\bar T}{\mathrm{d}y}, \qquad N_y = -(D + D_t)\frac{\mathrm{d}\bar c}{\mathrm{d}y}
$$

其中 $a_t$、$D_t$ 是**涡流热扩散系数与涡流质扩散系数**。
三步拆解这条「湍流传递强化」核心式：

- **第一步，双扩散**：
  分子扩散项（$a$、$D$）加涡流扩散项（$a_t$、$D_t$）。
  在湍流核心 $a_t$、$D_t$ 远超分子值，
分子项可忽略——**传递几乎全由涡流完成**。
- **第二步，类比假设**：若假设动量、热量、质量的涡流扩散由同一批涡完成，
  则 $\mu_t/(\rho a_t) \approx \mu_t/(\rho D_t) \approx 1$——即**湍流普朗特数/施密特数 ≈ 1**。
  这就是**雷诺类比**的核心：湍流对三传的强化程度相同。
- **第三步，工程后果**：
  由此得类比关系 $Nu \sim (Re)Pr$、$Sh \sim Re\,Sc$ 的湍流形式，
  以及传热传质系数的相互换算——**测传热系数可估传质系数、测阻力可估传热**。
  化工原理里「摩擦因子与 $Nu$ 数的类比式」（下一节《三传类比》展开）都源于此。

**辨析｜易错点：** 涡流扩散系数是**空间位置的函数**（近壁小、中心大），
不是常数——「设 $a_t$ 为常数」只在湍流核心近似成立。
此外 $Pr_t \approx 1$ 是近似，
对液态金属（$Pr$ 极小）与高黏流体偏差明显，需用修正类比。

## 5 湍流的建模与工程

**湍流模型**（把雷诺应力与平均流场联系起来）：
混合长模型（零方程）、$k$–$\varepsilon$ 模型（两方程，
工业最常用）、大涡模拟（LES，
精细但贵）、直接数值模拟（DNS，研究用）。
工程上 $k$–$\varepsilon$ 及其变体是流程与 CFD 软件的主流——它们求解湍动能 $k$ 与耗散率 $\varepsilon$ 的输运方程，给出涡流黏度分布。
<span class="marginnote">湍流模型是「用平均场的方程代替逐涡描述」：$k$–$\varepsilon$ 模型用两个输运方程定涡流黏度，工程精度足够、计算量可控。理解「模型在近似什么」（雷诺应力的本构），才能判断 CFD 结果的可信区间——模型不是真相，是工程化的妥协。</span>

**辨析｜易错点：** 湍流模型都含**经验常数**（$k$–$\varepsilon$ 的 $C_\mu = 0.09$ 等），
由经典湍流实验标定——换流动类型（强旋流、强分离、近壁）需要调参或换模型。
**把 CFD 的湍流模型输出当绝对真值**，
忽略其适用边界，是工程仿真的常见陷阱。

## 6 小结

- 湍流 = 随机脉动 + 涡旋多尺度；
  **雷诺分解** $\bar u + u'$ 把问题统计化。
- **雷诺应力** $-\rho\overline{u'v'}$ 来自脉动搬运动量；
  **普朗特混合长**导出涡流黏度 $\mu_t$。
- 湍流近壁四层：黏性底层（线性）、缓冲层、对数律层（$u^+ = \frac{1}{\kappa}\ln y^+ + B$）、外区。
- **涡流扩散系数** $a_t$、$D_t$ 远超分子值，湍流传递由涡完成；
  $Pr_t \approx 1$ 是雷诺类比基础。
- 工程用湍流模型（$k$–$\varepsilon$ 主流）；
  模型含经验常数、有适用边界，结果须谨慎解读。
