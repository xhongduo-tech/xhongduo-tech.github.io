## 为什么从精馏塔计算开始

上一节立住了精馏的原理，本节把它算成设备尺寸：
**给定分离任务（进料组成、要求的产品纯度），求需要多少块理论板、回流比取多大、塔径多大。** 核心工具是**麦凯布–蒂勒图解法（McCabe–Thiele method）**——在 x–y 图上用操作线、进料线（q 线）与平衡线交替画阶梯，
一块一块数出理论板数。
它是化工原理最经典、最能体现「图解思维」的方法，也是理解后来逐板计算、软件模拟的入口。
<span class="marginnote">McCabe–Thiele 图解法把无穷级联的代数问题变成「画楼梯」：每一条竖线代表一块理论板从液相到气相、每一条横线代表气相到液相。数楼梯的台阶数，就是理论板数——一个抽象优化问题被降维成几何计数。</span>

## 1 操作线与进料线

塔被进料板分成两段，各段有自己的**操作线**（塔内汽液组成关系，由物料衡算得到）。

**精馏段操作线**（过塔顶 $(x_D, y_D)$ 与塔顶回流液组成）：

$$y = \frac{R}{R+1}x + \frac{x_D}{R+1}$$

其中 $R = L/D$ 是**回流比**（回流液量 / 塔顶产品量）。
斜率 $R/(R+1)$ 小于 1，截距 $x_D/(R+1)$。
<span class="marginnote">回流比 $R$ 是精馏塔的「第一设计变量」：$R$ 增大 → 操作线斜率增大、更贴近平衡线 → 推动力变小 → 塔板数变多，但回流多、再沸与冷凝能耗上升。$R$ 减小 → 塔板数变少但操作线可能撞到平衡线。<strong>塔高与能耗围着回流比对赌</strong>，与吸收塔的液气比完全同构。</span>

**提馏段操作线**（过塔釜 $(x_W, y_W)$ 与塔釜汽相组成）：

$$y = \frac{L'}{L'-W}x - \frac{W}{L'-W}x_W$$

其中 $L'$ 是提馏段下降液量，$W$ 是釜残液量。
两段操作线的交点由**进料线（q 线）**控制——进料的热状态用一个参数 $q$ 刻画：

$$q = \frac{\text{把 1 mol 进料变为饱和蒸汽所需热量}}{\text{1 mol 进料的汽化潜热}}$$

进料线方程：

$$y = \frac{q}{q-1}x - \frac{x_F}{q-1}$$

$q$ 的取值决定进料线斜率与两段操作线交点位置：

| 进料热状态 | q 值 | 进料线斜率 |
| --- | --- | --- |
| 冷液体 | $q > 1$ | 正（>1） |
| 饱和液体（泡点） | $q = 1$ | 竖直 |
| 汽液混合 | $0 < q < 1$ | 负 |
| 饱和蒸汽（露点） | $q = 0$ | 水平 |
| 过热蒸汽 | $q < 0$ | 正（<1） |

## 2 最小回流比与回流比选择

当回流比减小到使操作线（或两段操作线的交点）**触到平衡线**时，
该点推动力为零，所需理论板数为无穷——对应的回流比是**最小回流比 $R_{\min}$**。

**芬斯克方程（Fenske equation）**给出全回流（$R \to \infty$，
理论板数最少）时最少理论板数：

$$N_{\min} = \frac{\lg\left[\left(\dfrac{x_D}{1-x_D}\right)\left(\dfrac{1-x_W}{x_W}\right)\right]}{\lg\alpha}$$

其中 $\alpha$ 取塔顶塔釜的平均相对挥发度。
<span class="marginnote">芬斯克方程与「全回流、最少板」是精馏的极值锚点；最小回流比对应「无穷板」。真实的回流比取在两者之间，工程经验是 $R = (1.1\sim2)R_{\min}$——既避免塔过高，又不至于能耗失控。<strong>最优回流比由总费用（设备折旧 + 操作能耗）最小决定</strong>，与管路经济管径是同一类经济权衡。</span>

**辨析｜易错点：** 求 $R_{\min}$ 时，
精馏段操作线与平衡线的交点可能是「操作线相切」而非「与 q 线交点」——当平衡线有下凹（相对挥发度变化大）时，
切点在中间而非 $x_q$ 处。
只算交点不算切线，会高估 $R_{\min}$，实际塔无法操作。

## 3 公式解析：McCabe–Thiele 图解与理论板数

图解法的完整步骤：

1. 画**对角线**（$y = x$）与**平衡曲线** $y = \alpha x/[1+(\alpha-1)x]$；
2. 标出塔顶 $(x_D, x_D)$、塔釜 $(x_W, x_W)$、进料组成 $x_F$；
3. 由 $q$ 画**进料线**，
   由 $R$ 画**精馏段操作线**，
   两者交点与塔釜点连线得**提馏段操作线**；
4. 从 $(x_D, x_D)$ 出发，
   在精馏段操作线与平衡线之间交替画水平线与垂直线——水平线代表汽相到达平衡、垂直线代表液相组成变化——每块理论板对应一个「阶梯」；
5. 跨过进料点后改用提馏段操作线，继续画阶梯直到 $x \le x_W$，数出总阶梯数。
   <span class="marginnote">阶梯的几何含义值得体会：竖线沿平衡线「向上」，代表蒸汽在上方板上达到新平衡、轻组分增加；横线沿操作线「向左」，代表液体下降一级、重组分增加。每一块理论板 = 一次平衡 + 一次回流混合。数「楼梯」就是数「平衡级」。</span>

得到理论板数 $N_T$ 后，
**实际板数** $N = N_T/E$，
其中 $E$ 是**板效率（tray efficiency）**（全塔平均约 50%–80%）。
塔板间距由塔径与操作弹性选定（常压塔取 300–600 mm），
塔高 $H = N\times$ 板间距。

**辨析｜易错点：** 图解法假设**恒摩尔流（constant molal overflow）**——两段内汽、液相摩尔流率恒定。
这对分子汽化潜热相近、热损失可忽略的理想物系近似成立；
若组分潜热差异大或热损失显著，恒摩尔流假设失效，须用逐板热量衡算（回到严格模拟）。
图解前先确认假设的适用性。

## 4 塔径、塔板与效率

塔径由**气速上限**决定：塔内上升蒸汽速度过大，会夹带雾沫（液泛）、塔板效率暴跌。
设计取**最大允许气速**的 60%–80%：

$$u = (0.6\sim0.8)u_{\max}$$

再由汽相体积流量反算塔径。
塔径确定后，需对每块塔板核算：
溢流堰高度、降液管尺寸、板上液层厚度、压降——保证塔板在**稳定操作区**内（不漏液、不液泛、不夹带）。
<span class="marginnote">塔板的操作弹性用「操作上限/下限」描述：上限是液泛与严重夹带，下限是漏液与塔板吹空。正常操作点应落在操作图中央，留足裕度。板式塔设计与填料塔设计共享「通量定径、效率定高」的框架，但塔板多了水力学核算这一大块。</span>

**板效率的构成**：总板效率 E 综合了塔板上的实际传质过程，
与**物系性质**（相对挥发度、黏度）、**气液负荷**、**塔板结构**有关。
经验关联（如奥康奈尔 O'Connell 关联）可用黏度与相对挥发度估算：
$E = 0.49(\alpha\mu)^{-0.245}$。

## 5 设计程序小结

连续精馏塔设计的完整流程：

1. **定任务**：进料组成 $x_F$、流量，
   产品纯度 $x_D$、$x_W$，进料热状态 $q$；
2. **总物料衡算**求 $D$、$W$：
   $F = D + W$，$F x_F = D x_D + W x_W$；
3. 由平衡关系求 $R_{\min}$，选实际回流比 $R$；
4. 用芬斯克方程求 $N_{\min}$ 作为下限参照；
5. **McCabe–Thiele 图解**求理论板数，确定进料板位置；
6. 由板效率求实际板数，由气速定塔径，核算塔板水力学。

**辨析｜易错点：** 进料板位置的选取「每层板都可能成为进料板」，
图解法中跨过 q 线交点处换操作线的那一步，就对应进料板位置。
选错位置（过早换线）会多算板数；
最优进料板是「在该板进料使两段板数总和最小」的位置——图解法里自然给出，
严格设计可用逐板优化。

## 6 小结

- 塔分**精馏段**与**提馏段**，
  各有操作线；**进料线（q 线）**由进料热状态决定，连接两段操作线。
- **回流比 $R$** 是核心设计变量：
  $R$ 大塔矮能耗高、$R$ 小塔高能耗低，
  最优取 $(1.1\sim2)R_{\min}$。
- **最小回流比**对应操作线触平衡线（注意可能是相切），
  **芬斯克方程**给全回流最少板数。
- **McCabe–Thiele 图解法**：
  在平衡线与两段操作线间画阶梯，数出理论板数；
  实际板数 = 理论板数 ÷ 板效率。
- 塔径由气速上限（防液泛夹带）定，塔高由板数 × 板间距定；恒摩尔流假设需先行确认。
