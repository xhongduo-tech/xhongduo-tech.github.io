## 为什么从相平衡开始

相平衡是化工分离的「天花板」：
精馏塔能分多纯、吸收塔能脱多少、闪蒸罐能闪出什么组成，全部由相平衡决定。
本节把上一节的化学位、逸度、活度组装成**相平衡判据与计算方程**——从「逸度相等」这一基本判据出发，
建立汽液平衡（VLE）的各类计算式（泡点、露点、闪蒸），
再延伸到液液平衡（LLE）与恒沸。
学完本节，你在《化工原理》里学的平衡线、精馏曲线，就能从热力学第一性推导出来。
<span class="marginnote">相平衡计算是化工热力学与化工原理的「会师点」：《化工原理》把平衡线当给定的数据用，《化工热力学》则回答「平衡线从哪来、如何精确计算」。两条线在此闭环——分离设计的平衡极限从此有了理论根基。</span>

## 1 相平衡判据

多相体系达到平衡的**基本判据**：温度、压力相等，且**每个组分在各相的化学位相等**：

$$\mu_i^{\alpha} = \mu_i^{\beta} = \cdots \quad (i = 1, 2, \ldots, N)$$

用逸度等价表达（工程计算形式）：

$$f_i^{\alpha} = f_i^{\beta} = \cdots$$

**相律（phase rule）**给出独立变量数：

$$F = C - P + 2$$

其中 $C$ 是组分数、$P$ 是相数。
对二元汽液平衡（$C = 2$、$P = 2$），
$F = 2$——给定温度与一个液相组成，汽相组成即被确定。
<span class="marginnote">相律是相平衡计算的「自由度仪表」：它告诉你「还能自由指定几个变量」。泡点计算「给定 x 和 p 求 T 和 y」用了 2 个自由度，正好把 $F=2$ 用完；饱和区「T、p 互相锁定」也是相律的直接结果。</span>

**辨析｜易错点：** 相平衡判据是**化学位（逸度）相等**，不是压力相等或浓度相等。
汽液平衡时两相压力相同（机械平衡），但组成不同；
「组成相等」只发生在恒沸点。
用「浓度相等」作为平衡判据是初学者常犯的错。

## 2 汽液平衡方程

汽液平衡的计算形式（**VLE 方程**）：液相用活度、气相用逸度系数。
低压时气相可近似理想（$\phi_i \approx 1$），得**修正的拉乌尔定律**：

$$y_i p = x_i \gamma_i p_i^{\text{sat}}$$

其中 $y_i$、$x_i$ 是汽液相摩尔分数，
$p_i^{\text{sat}}$ 是纯组分饱和蒸气压，
$\gamma_i$ 是活度系数。

**K 值**：定义汽液分配比 $K_i = y_i/x_i$，则修正拉乌尔定律给出：

$$K_i = \frac{\gamma_i p_i^{\text{sat}}}{p}$$

$K_i$ 描述组分在两相间的「偏袒程度」——$K_i$ 越大，
组分越倾向汽相。**K 值是闪蒸、精馏逐板计算的核心参数**。
<span class="marginnote">理想溶液（$\gamma_i=1$）时 $K_i = p_i^{\text{sat}}/p$——只由温度压力决定，这就是拉乌尔定律版 VLE。非理想体系靠 $\gamma_i$ 修正。相对挥发度 $\alpha_{ij} = K_i/K_j$ 由 K 值之比给出，精馏的平衡曲线由此而来——化工原理与热力学在此无缝衔接。</span>

**高压 VLE**：压力高时气相不能按理想处理，须用状态方程计算汽相逸度系数：

$$y_i \phi_i p = x_i \gamma_i p_i^{\text{sat}}$$

更高压或近临界时，两相都用工态方程（**EOS 法**），
统一用逸度系数表达汽液两相，
模型选择成为精度关键。

## 3 泡点、露点与闪蒸

VLE 方程的三个基本计算问题：

- **泡点计算**：给定液相组成 $x$ 与压力 $p$，
  求泡点温度 $T_b$ 与汽相组成 $y$。
  由 $\sum y_i = 1$，
即 $\sum x_i\gamma_i p_i^{\text{sat}}(T)/p = 1$，试差求 $T$。
- **露点计算**：给定汽相组成 $y$ 与压力 $p$，
  求露点温度 $T_d$ 与液相组成 $x$。
  由 $\sum x_i = 1$ 试差求 $T$。
- **闪蒸（flash）**：
  给定进料组成 $z$、温度 $T$、压力 $p$，
  求汽化分率 $\psi$ 与两相组成——由物料衡算 + 平衡方程联立：

$$z_i = \psi y_i + (1 - \psi)x_i, \qquad y_i = K_i x_i$$

**辨析｜易错点：** 泡点与露点把「先判断相态」这一前置步骤藏得很深。
给定一个 $T$、$p$、$z$ 的体系，
要先判断它处于过冷液、两相区还是过热汽——判据是 $T < T_b$（泡点温度）为过冷液、$T > T_d$（露点温度）为过热汽、介于两者之间为两相区。
**直接假设两相并解闪蒸方程，却不知体系根本不在两相区，会得出无意义结果**。
工程上先算泡露点定相态，再决定用哪个计算，是相平衡问题第一步的纪律。

## 4 公式解析：修正拉乌尔定律的四个因子

$$
y_i p = x_i \gamma_i p_i^{\text{sat}}
$$

三步拆解这条 VLE 主方程：

- **第一步，平衡条件**：
  它正是「液相逸度 = 汽相逸度」在低压下的展开——液相逸度 $f_i^L = x_i\gamma_i f_i^{\text{pure}} \approx x_i\gamma_i p_i^{\text{sat}}$，
  汽相逸度 $f_i^V = y_i p$（低压理想气相）。
  两边相等即得方程。
- **第二步，四个因子的分工**：
  $x_i$ 是「有多少」、$\gamma_i$ 是「偏离理想多少」（分子作用）、$p_i^{\text{sat}}$ 是「纯组分多爱跑」（蒸气压）、$y_i p$ 是「汽相分压」。
  四者相乘平衡，正好对应「液相想跑出来的趋势 = 汽相已拥有的分压」。
- **第三步，极端情况**：$\gamma_i = 1$ 退化为拉乌尔定律；
  恒沸点时 $y_i = x_i$，
方程给出 $\gamma_i = p/p_i^{\text{sat}}$——**恒沸是活度系数恰好补偿蒸气压差异的结果**。
  理解了这一点，就理解了为什么改变 $\gamma$（特殊精馏）能消除恒沸。

## 5 液液平衡与恒沸

**液液平衡（LLE）**：
部分互溶体系分成两个液相，平衡条件仍为各组分在两液相中逸度相等。
计算用活度系数模型（NRTL/UNIQUAC）：

$$x_i^{\text{I}}\gamma_i^{\text{I}} = x_i^{\text{II}}\gamma_i^{\text{II}}$$

LLE 是**萃取**设计的平衡基础——萃取剂能否分相、分配比多大，都由 LLE 决定。
<span class="marginnote">LLE 与 VLE 的模型要求不同：能算 VLE 的 Wilson 模型不能预测分相，必须用 NRTL/UNIQUAC。萃取流程模拟里「选 NRTL 物性包」几乎是铁律，就是因为萃取本质是 LLE 问题。从 VLE 到 LLE，模型选择跟着问题类型走。</span>

**恒沸物（azeotrope）**：
VLE 曲线与对角线的交点，
$y_i = x_i$、$K_i = 1$，普通精馏无法跨越。
恒沸的类型与位置由活度系数的偏差模式决定：

- **正偏差恒沸（最低恒沸）**：
  $\gamma > 1$ 使组分实际蒸气压升高，
  混合物的泡点低于任一纯组分——乙醇–水（95.6 wt% 乙醇）即此类型。
- **负偏差恒沸（最高恒沸）**：
  $\gamma < 1$ 使泡点升高——硝酸–水、氯仿–丙酮。

**辨析｜易错点：** 恒沸组成随压力变化——改变压力可能移动甚至消除恒沸，
这是**变压精馏（pressure-swing distillation）**的原理。
判断能否用变压精馏，先看恒沸组成随压力的移动量是否足够大；
恒沸对压力不敏感时，只能靠共沸/萃取精馏或膜法。

## 6 小结

- **相平衡判据**：各组分在各相化学位（逸度）相等；
  **相律** $F = C - P + 2$ 决定自由度。
- **VLE 主方程** $y_i p = x_i\gamma_i p_i^{\text{sat}}$：
  $x$ 管多少、$\gamma$ 管偏离、$p^{\text{sat}}$ 管蒸发趋势；
  高压用 EOS 法。
- **K 值** $K_i = \gamma_i p_i^{\text{sat}}/p$ 是闪蒸与精馏逐板计算的核心；
  泡点、露点、闪蒸三类问题各配试差。
- **先判相态**（过冷/两相/过热）再选计算式，是相平衡问题的第一纪律。
- **LLE**（萃取）用活度系数模型，
  Wilson 不能分相、须用 NRTL/UNIQUAC；
  **恒沸**是活度系数补偿蒸气压的结果，变压可移动恒沸。
