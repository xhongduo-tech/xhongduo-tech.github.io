## 为什么从辐射传热开始

传导与对流都需要介质，**热辐射（thermal radiation）**却可以穿越真空把能量送达——它是地球从太阳获得能量的唯一途径。
化工中辐射传热的典型舞台是**高温**：
炉膛内火焰与炉管的换热、高温反应器外壁的散热、管式加热炉的设计。
温度越高，辐射占比急剧增大（与绝对温度的 4 次方成正比），
到 1000 °C 以上辐射成为绝对主角。
<span class="marginnote">辐射传热定律（斯特藩–玻尔兹曼定律）$E \propto T^4$ 与对流、导热的 $T^1$ 形成鲜明对比：温度翻倍，辐射能力变为 16 倍。这也是为什么「高温设备必须保温、炉子必须用耐火材料」——辐射在高温区无法忽视。</span>

## 1 黑体与辐射基本定律

**热辐射**：物体因其温度而发射的电磁辐射。
理想化的基准是**黑体（blackbody）**——能吸收全部外来辐射、且同温度下发射能力最强的物体。

**斯特藩–玻尔兹曼定律（Stefan–Boltzmann law）**：
黑体的辐射能力与其绝对温度的四次方成正比：

$$E_b = \sigma T^4, \qquad \sigma = 5.67\times10^{-8}\ \mathrm{W/(m^2\cdot K^4)}$$

$\sigma$ 是斯特藩–玻尔兹曼常数。
黑体还满足**普朗克定律**（辐射能按波长分布）与**维恩位移定律**（温度越高，
峰值波长越短：$\lambda_{\max} T = 2898\ \mu\mathrm{m\cdot K}$）——后者解释了为什么低温物体发射红外、高温物体发红白炽光。
<span class="marginnote">维恩位移定律可以估算温度：火焰发红约 800–1000 °C、发白约 2000 °C，金属加热「红了又白」正对应峰值波长从红外移向可见光。这也是光学高温计的物理依据——「看颜色估温度」是有定律支撑的。</span>

## 2 实际物体的辐射与吸收

实际物体不是黑体，发射与吸收都打折。定义三个无量纲物性：

- **发射率（emissivity）$\varepsilon$**：
  实际物体辐射能力与同温度黑体之比，
  $\varepsilon = E/E_b$，
  $0 < \varepsilon < 1$。
- **吸收率 $\alpha$、反射率 $\rho$、透射率 $\tau$**：
  入射辐射中分别被吸收、反射、透射的份额，三者之和为 1：
$$\alpha + \rho + \tau = 1$$

**基尔霍夫定律（Kirchhoff's law）**：
在热平衡条件下，物体的发射率等于吸收率：
$\varepsilon = \alpha$。
这条定律把「发射」与「吸收」两个过程统一起来——善于吸收的物体也善于发射。
<span class="marginnote">基尔霍夫定律的直觉：一个物体如果吸收得多却发射得少，它在热平衡中就会持续净获能、温度不断升高，违背热平衡。黑白问题由此得到统一解答——雪的表面看似白（反射可见光），但在红外波段发射率却接近 1。</span>

实际物体的辐射能力写成 $E = \varepsilon \sigma T^4$。
**灰体（gray body）**是工程常用理想化：
假设 $\varepsilon$ 与波长无关（常数），
则基尔霍夫定律严格成立、计算大幅简化。

**辨析｜易错点：** 物体对可见光的颜色不代表其对热辐射（红外）的吸收能力。
白衣服反射可见光、隔热好，但并非所有「白色物体」红外发射率都低。
判断「谁更接近黑体」看的是**红外吸收率/发射率**，不是肉眼颜色。

## 3 两物体间的辐射传热

两块表面之间的净辐射换热量，由「发射 − 吸收」的净差决定。
对**灰体**组成的体系，
引入**角系数（view factor）$F_{12}$**（表面 1 发射的辐射中被表面 2 接收的份额），净换热为：

$$Q_{12} = \varepsilon_{12} C_0 \varphi_{12} A_1 \left[\left(\frac{T_1}{100}\right)^4 - \left(\frac{T_2}{100}\right)^4\right]$$

其中 $C_0 = \sigma\times10^8 = 5.67\ \mathrm{W/(m^2\cdot K^4)}$（工程常数写法），
$\varepsilon_{12}$ 是组合发射率，
$\varphi_{12}$ 是角系数。
**角系数**只取决于几何（形状与相对位置），
与温度无关——这是辐射几何学的一个便利性质。

两个最常用的特例：

- **两无限大平行平板**：$\varphi_{12} = 1$，
  组合发射率 $\varepsilon_{12} = 1/(1/\varepsilon_1 + 1/\varepsilon_2 - 1)$。
  平行平板间辐射与板间距无关——间距变大、角系数仍为 1。
- **被包物体与外壳（如炉膛中加热的小管）**：
  外壳包住内物时，内物发出的辐射几乎全部落在外壳上，角系数接近 1。

**辨析｜易错点：** 角系数有**互易关系** $A_1F_{12} = A_2F_{21}$ 与**完整性** $\sum_j F_{ij} = 1$。
实际计算常要拆多个面之间的辐射网络，
画「辐射网络图」（电阻网络）求解——这与电路类比再次同构，
只是这里的「电阻」是辐射空间热阻与表面热阻。

## 4 公式解析：斯特藩–玻尔兹曼定律与四次方

$$
E_b = \sigma T^4
$$

三步拆解这条辐射第一定律：

- **第一步，绝对温度**：$T$ 必须用开尔文（K），不能用摄氏温度。
  这是辐射计算最常见的单位事故——$t$ 摄氏度与 $T = t + 273.15$ 弄混，
四次方后误差巨大（1000 °C 与 1273 K 差了 2.6 倍辐射能力）。
- **第二步，四次方的来源**：
  普朗克把黑体辐射按波长积分，
  得到与 $T^4$ 成正比的总辐射能——四次方是量子统计（普朗克分布）积分的自然结果，不是经验凑出来的。
  这解释了辐射的「非线性放大」：温差大的高温辐射交换远不能用线性近似。
- **第三步，工程写法**：
  把 $\sigma = 5.67\times10^{-8}$ 写成 $C_0/100^4$，
  即 $E_b = C_0(T/100)^4$，
  $C_0 = 5.67$——为的是把数值调成好算的量级。
  工程手册多用后者，两种写法要能互译。

**辐射 + 对流联合**：高温设备外壁同时以对流与辐射向环境散热，总散热量为两者之和：

$$Q = (\alpha_c + \alpha_r) A (t_w - t_{\infty})$$

其中 $\alpha_r$ 是**辐射传热系数**（把辐射折算成类似对流的线性系数）：

$$\alpha_r = \varepsilon C_0 \frac{(T_w/100)^4 - (T_{\infty}/100)^4}{T_w - T_{\infty}}$$

这种「把非线性辐射线性化」的处理，
使总散热量可以用统一的 $Q = \alpha_{\text{总}}A\Delta t$ 计算，便于工程设计。
<span class="marginnote">保温层外表面散热的计算、高温管道保温厚度的确定，都按「对流 + 辐射」联合散热处理。保温层外壁加铝皮（低 $\varepsilon$）能显著减小辐射散热——发射率低到 0.1 左右，散热可减半，这是保温工程的实际技巧。</span>

## 5 辐射在化工设备中的角色

- **管式加热炉**：燃料在炉膛内燃烧，
  高温烟气与火焰以辐射为主把热传给炉管，
  管内物料被加热到几百摄氏度。
  炉膛辐射传热设计是加热炉的核心计算——炉管排布、火焰位置都要让角系数与温度场配合。
- **高温设备保温**：外壁温度高时辐射散热占大头，
  保温层外表面温度控制在低水平（<60 °C）是为了同时压低对流与辐射散热。
- **温度测量**：热电偶在高温炉内测的是自身辐射平衡温度，
  受炉壁辐射影响会产生误差——「辐射误差」是高温测温的经典问题，需用遮热罩修正。

## 6 小结

- **斯特藩–玻尔兹曼定律** $E_b = \sigma T^4$：
  黑体辐射与绝对温度四次方成正比；
  普朗克、维恩定律刻画辐射谱分布。
- **发射率/吸收率** $\varepsilon = \alpha$（基尔霍夫定律，
  热平衡时成立），灰体假设使计算简化。
- 两灰体间净辐射用角系数 + 组合发射率计算；角系数纯由几何决定，满足互易与完整性关系。
- 辐射必须用**绝对温度**；高温区四次方非线性使辐射主导，不可线性近似。
- 高温设备散热按「对流 + 辐射」联合计算，辐射系数线性化使总式统一。
