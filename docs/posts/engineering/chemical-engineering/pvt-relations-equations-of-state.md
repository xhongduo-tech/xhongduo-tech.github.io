## 为什么从 PVT关系与状态方程开始

化工热力学的一切都建立在「知道流体的**状态**」之上：
给定了温度与压力，气体的体积多大、密度多大、焓熵多大？
这条「$T$、$p$、$V$ 之间的联系」就是**状态方程（equation of state, EOS）**——它是热力学计算的地基，
压缩机功率、闪蒸分离、相平衡、反应平衡全部从这里起步。
<span class="marginnote">从《化工原理》进入《化工热力学》，视角从「设备」转向「状态」：前者算管路、塔、换热器，后者回答「任意状态下流体的性质怎么定」。化工热力学是化工原理的「底层操作系统」——所有单元操作的平衡极限都由热力学给出。</span>

## 1 理想气体与压缩因子

**理想气体状态方程** $pV = nRT$ 是最简单的起点：
分子无体积、分子间无作用力。
它在低压高温下成立，但化工常在高压低温下操作，理想气体严重失真。

衡量偏差的钥匙是**压缩因子（compressibility factor）**：

$$Z = \frac{pV}{nRT}$$

$Z = 1$ 是理想气体；
$Z < 1$ 说明实际体积小于理想值（分子间吸引力占主导，如高压低温）；
$Z > 1$ 说明实际体积更大（分子本身体积不可忽略，如极高压）。
<span class="marginnote">把 $Z$ 想成「理想气体的打折系数」：$Z<1$ 气体比理想「更好压」（分子互相吸引、被拉近），$Z>1$ 比理想「更难压」（分子体积占空间）。判断气体偏理想的程度，就看 $Z$ 离 1 多远——工程上常以 $|Z-1| < 2\%$ 作为可用理想气体近似的判据。</span>

## 2 立方型状态方程

工程热力学的主力是**立方型状态方程**——$V$ 的三次多项式，
可解析求根，同时能描述气液相变。
历史第一式是**范德华方程（van der Waals EOS）**，
在理想气体上做了两处修正：

$$\left(p + \frac{a}{V_m^2}\right)(V_m - b) = RT$$

其中 $a$ 修正分子间引力（内压项 $a/V_m^2$），
$b$ 修正分子本身的体积（$V_m - b$ 是自由空间）。
范德华方程定性正确，定量不足，但它的两个修正项是所有现代立方型方程的共同基因。

现代工业标准是 **SRK 方程** 与 **Peng–Robinson（PR）方程**：

$$p = \frac{RT}{V_m - b} - \frac{a\alpha(T)}{V_m^2 + ubV_m + wb^2}$$

PR 方程取 $u = 2$、$w = -1$，
SRK 取 $u = 1$、$w = 0$。
关键改进在 $\alpha(T)$——一个随温度变化的修正因子，
把温度对分子引力的影响（尤其近临界区）纳入，
使方程能定量预测蒸汽压与相平衡。
<span class="marginnote">PR 与 SRK 是流程模拟软件（Aspen、HYSYS）里最常用的热力学模型。它们的参数 $a$、$b$ 用<strong>临界性质</strong>（临界温度、临界压力、偏心因子）关联——输入临界参数，方程就「自动」复现该物质的临界点与蒸汽压行为。这是「少数输入、全温区预测」的典范。</span>

## 3 对应态原理与通用关联

**对应态原理（principle of corresponding states）**：
把状态方程改写为**对比态**形式——用临界值归一化，
$T_r = T/T_c$、$p_r = p/p_c$、$V_r = V/V_c$。
范德华方程在对比态下写成：

$$\left(p_r + \frac{3}{V_r^2}\right)(3V_r - 1) = 8T_r$$

此式**不含任何物质专属常数**——所有满足范德华方程的物质，
在相同对比态下具有相同的性质。
这是对应态原理的核心陈述：**气体在对比态下行为相同**。
<span class="marginnote">对应态原理是热力学「无量纲化」的胜利：它把「每个物质一条性质曲线」压缩成「所有物质一条通用曲线」。实际应用时引入第三个参数<strong>偏心因子 $\omega$</strong>（刻画分子非球形程度）修正，就得到普适的两参数/三参数压缩因子图——工程上查 $Z$ 图就靠它。</span>

**压缩因子通用图**：以 $p_r$ 为横轴、$Z$ 为纵轴，
以 $T_r$ 为参数绘制的族曲线。
给定物质的 $T_c$、$p_c$，
算 $T_r$、$p_r$，
查图得 $Z$，再由 $Z = pV/(nRT)$ 求体积——**比状态方程手算快得多**，
是手算年代的标准方法。

**辨析｜易错点：** 对比态参数必须用**绝对温度与绝对压力**。
此外 $Z$ 图在近临界区变化剧烈、精度有限，临界点附近优先用状态方程或专用关联。
查图前先确认物质是否有明确的临界点（混合物的 $T_c$、$p_c$ 要用混合规则计算）。

## 4 公式解析：Peng–Robinson 方程的立方结构

$$
p = \frac{RT}{V_m - b} - \frac{a\alpha(T)}{V_m^2 + 2bV_m - b^2}
$$

三步拆解这条现代 EOS 的代表：

- **第一步，两项的物理分工**：
  第一项 $\dfrac{RT}{V_m-b}$ 是「斥力修正项」——体积被 $b$ 缩小后，
  压强按理想气体形式升高；
  第二项是「引力修正项」——引力使内压降低，
从压强里扣掉 $a\alpha/(V_m^2+2bV_m-b^2)$。
  斥力项+引力项，正是范德华修正的现代化身。
- **第二步，为什么是 $V$ 的三次方**：
  乘开分母后，方程变成 $V_m$ 的三次多项式 $V_m^3 - \cdots = 0$。
  三次方程在给定 $p$、$T$ 时最多有三个实根——**最小根是液相摩尔体积、最大根是汽相摩尔体积、中间根无物理意义**。
  一次求解同时得到汽液两相体积，这就是立方型方程能算相平衡的原因。
- **第三步，$\alpha(T)$ 的作用**：
  $\alpha(T)$ 在临界温度时等于 1，
  随温度偏离而调整引力项，使方程精确复现实验蒸汽压曲线。
  参数 $a$、$b$ 由临界条件 $\partial p/\partial V = 0$、$\partial^2 p/\partial V^2 = 0$ 处确定——**方程被「钉」在临界点上**，
从而自动满足临界行为。

**混合规则**：混合物用 EOS 时，
$a$、$b$ 取纯组分的组合——经典 van der Waals 混合规则：

$$a_m = \sum_i\sum_j x_i x_j \sqrt{a_i a_j}(1 - k_{ij}), \qquad b_m = \sum_i x_i b_i$$

$k_{ij}$ 是**二元交互作用参数**，从实验相平衡数据拟合。
<span class="marginnote">混合规则是 EOS 从纯物质走向混合物的桥梁，也是相平衡计算精度的关键。$k_{ij}$ 通常接近零，但能显著影响预测的汽液平衡——化工热力学的「调参」大多发生在这一层。这就是为什么流程模拟里「物性包选什么、交互参数取多少」决定成败。</span>

## 5 小结

- **状态方程**联系 $T$、$p$、$V$，是热力学计算的起点；
  理想气体 $pV=nRT$ 只适合低压高温。
- **压缩因子** $Z = pV/(nRT)$ 度量偏离理想的程度：
  $Z<1$ 引力主导、$Z>1$ 分子体积主导。
- **立方型方程**（van der Waals → SRK → PR）以「斥力项 + 引力项」修正理想气体，
  三次方程同时给汽液两相体积。
- **对应态原理**把物质性质用对比态归一化，
  配偏心因子得通用压缩因子图，
  是手算时代的标准工具。
- 混合物用**混合规则**组合纯组分参数，
  二元交互参数 $k_{ij}$ 是相平衡精度的关键。

在下一节，我们回到热力学的公理体系——**热力学基本定律**，
建立能量衡算与熵增的严格框架。
