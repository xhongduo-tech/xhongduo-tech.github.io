## 为什么从热力学循环开始

化工厂需要动力（蒸汽、电）也需要冷量（冷冻盐水、低温精馏）。
**热力循环**把热量转化为功（动力循环）或把热从低温搬到高温（制冷/热泵循环）。
理解循环的意义在于：它把第二定律从「抽象判据」变成「效率数字」——电厂能效多少、冷冻机能效比多少，
都由循环的类型与改进方向决定。
本节以**朗肯循环**（蒸汽动力）与**蒸气压缩制冷循环**为代表，
分析它们的过程、效率与改进空间。
<span class="marginnote">循环分析是热力学图表（T–S 图、Mollier 图）的最大用武之地：每个过程在图上都是一条线，循环是闭合回路，<strong>回路面积 = 净功，效率一眼可读</strong>。上一节《热力学图表》学的读图本领，本节全数派上用场。</span>

## 1 卡诺循环与效率上限

**卡诺循环（Carnot cycle）**：
两个等温 + 两个绝热过程组成的理想循环，
是所有热机的效率上限：

$$\eta_C = 1 - \frac{T_L}{T_H}$$

任何实际循环效率都低于卡诺效率。
卡诺循环的意义不是直接用它发电（等温过程难实现），
而是给出**参照系**：所有改进方向都是「把循环形状向卡诺循环靠拢」。
<span class="marginnote">卡诺循环是「第二定律的金额化」：它证明效率只取决于高温热源与低温热源的温度。电厂提高锅炉蒸汽温度（$T_H$↑）、降低冷凝器温度（$T_L$↓）都是在往卡诺上限逼近。记住这个上限，就能判断一个循环「还有多少改进空间」。</span>

## 2 朗肯循环

**朗肯循环（Rankine cycle）**是蒸汽动力厂的基本循环，四个过程：

1. **等熵压缩**（水泵）：把冷凝水升压到锅炉压力（功耗很小）；
2. **等压加热**（锅炉）：水加热汽化为过热蒸汽（吸热 $q_H$）；
3. **等熵膨胀**（汽轮机）：高温高压蒸汽膨胀做功（输出功 $W_T$）；
4. **等压冷凝**（冷凝器）：乏汽冷凝回水（放热 $q_L$）。

循环热效率：

$$\eta = \frac{W_{\text{net}}}{q_H} = \frac{(h_3 - h_4) - (h_2 - h_1)}{h_3 - h_2}$$

各焓值在 T–S 图或蒸汽表上读取。**朗肯循环的主要改进方向**（都朝着卡诺上限走）：

- **提高蒸汽初温与初压**：使循环平均吸热温度升高，效率提高（受材料耐温限制）；
- **降低排汽压力**：降低冷凝温度，但受环境温度限制；
- **再热循环**：高压缸膨胀到中间后回到锅炉再热，
  再进低压缸——提高末级干度、减少汽轮机叶片侵蚀、略提效率；
- **回热循环**：从汽轮机抽出部分蒸汽加热给水，
  提高锅炉进水温度——减少锅炉吸热，显著提高效率。

**辨析｜易错点：** 朗肯循环的效率公式要用**焓差**（$W_T = h_3 - h_4$），不是温差。
汽轮机等熵膨胀终态在 Mollier 图上沿等熵线竖直下落，
实际过程按等熵效率打折后终态偏右（焓更高）——**读图取焓值时，别忘了等熵效率修正**，
否则功率会高估 10%–15%。

## 3 公式解析：蒸汽压缩制冷循环

**蒸气压缩制冷（vapor-compression refrigeration）**是最常用的制冷循环，
四过程与朗肯循环方向相反：

1. **等熵压缩**（压缩机）：低压制冷剂蒸汽压缩成高压过热蒸汽（耗功 $W_C$）；
2. **等压冷凝**（冷凝器）：高压蒸汽冷凝为高压液体（放热 $q_H$）；
3. **节流膨胀**（膨胀阀）：高压液体节流降压降温，部分汽化（等焓，$h$ 不变）；
4. **等压蒸发**（蒸发器）：低压液体制冷剂吸热蒸发（制冷 $q_L$）。

**制冷系数（coefficient of performance, COP）**：

$$
\text{COP}_R = \frac{q_L}{W_C} = \frac{h_1 - h_4}{h_2 - h_1}
$$

对**热泵**，制热 COP：

$$\text{COP}_{\text{HP}} = \frac{q_H}{W_C} = \frac{h_2 - h_3}{h_2 - h_1} = \text{COP}_R + 1$$

三步拆解这套循环计算：

- **第一步，节流是等焓的**：
  膨胀阀中流体节流，$h_4 = h_3$——等焓线在 p–h 图上竖直向下。
  节流前后焓相同但压力骤降，
进入两相区、温度降到蒸发温度。
**这是读 p–h 图的第一关键**：
从冷凝后饱和液点竖直向下到蒸发压力等压线，交点即蒸发器入口。
- **第二步，制冷量是焓升**：
  蒸发器中制冷剂从状态 4（低压两相）吸热到状态 1（低压饱和/过热蒸汽），
  制冷量 $q_L = h_1 - h_4$——**单位质量制冷剂在蒸发器里吸收的焓**。
  压缩机耗功 $W_C = h_2 - h_1$ 是压缩过程的焓升。
- **第三步，COP 的经济含义**：COP 是「花一度电得到多少冷/热」。
  理想（卡诺）COP 为 $T_L/(T_H - T_L)$，
实际约为其 60%–80%。
**提高蒸发温度、降低冷凝温度都能提高 COP**——这就是「蒸发温度别设太低、冷凝器要散热好」的操作原则。

**制冷剂选择**：需要合适的沸点（在合适压力下蒸发）、低臭氧破坏潜势（ODP）与低全球变暖潜势（GWP）、无毒不燃、便宜。
从 CFC（氟利昂）到 HCFC、HFC，
再到氨、$\ce{CO2}$ 等自然工质，
制冷剂的变迁是环保法规驱动的技术史。
<span class="marginnote">制冷剂「沸点合适」是核心：氨（沸点 −33 °C）在常压附近就能蒸发，适合大型工业冷冻；$\ce{CO2}$ 作制冷剂在跨临界循环中工作（气体冷却器代替冷凝器），汽车空调与热泵中复兴。制冷剂的选择直接影响循环压力水平与设备结构。</span>

## 4 液化与深冷

**气体液化**与**气体分离**（空分、LNG）需要深冷循环。主要方法：

- **林德循环（Linde cycle）**：
  靠节流制冷（焦耳–汤姆逊效应）逐级降温液化，简单但效率低；
  用于小型液氮机。
- **克劳德循环（Claude cycle）**：
  部分气体在膨胀机中等熵膨胀做功降温，
  比节流效率高——大型空分装置的基础。
- **混合制冷剂循环**：多组分制冷剂在级联中逐级冷凝，效率高，是 LNG 生产的主流。

**辨析｜易错点：** 节流制冷（等焓、靠焦耳–汤姆逊效应降温）与膨胀机制冷（等熵、对外做功降温）是两种机制。
节流降温要求气体处于「转化温度以下」（多数气体常温可以，
氢氦需预冷），膨胀机制冷几乎无条件成立。
把「节流一定降温」当普适结论用，在氢、氦液化中会出错。

## 5 小结

- **卡诺效率** $\eta = 1 - T_L/T_H$ 是热机上限，
  所有循环改进都是向卡诺循环靠拢。
- **朗肯循环**（水泵→锅炉→汽轮机→冷凝器）是蒸汽动力基础，
  改进靠提高初参数、再热与回热。
- **蒸气压缩制冷**（压缩→冷凝→节流→蒸发）：
  **节流等焓**、制冷量 $q_L = h_1 - h_4$、COP $= q_L/W_C$。
- **热泵 COP = COP$_R$ + 1**；
  提高蒸发温度、降低冷凝温度能提升 COP。
- 深冷循环（林德、克劳德、混合制冷剂）用于液化与空分；节流与膨胀机制冷是两种机制。
