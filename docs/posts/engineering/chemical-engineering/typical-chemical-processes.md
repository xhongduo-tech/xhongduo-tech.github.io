## 为什么从典型化工流程开始

前四篇建立了化工的「积木」——流体、传热、分离、反应、传递。
**化工工艺**把这些积木组装成真实的工厂。
合成氨、甲醇、硫酸三大流程是化学工业的「骨架产品」：
合成氨养活了全球人口（氮肥），
硫酸是「化学工业之母」，甲醇是现代碳一化学的枢纽。
解剖这三个流程，等于做一次「全流程的单元操作总复习」——每个流程都把反应、分离、换热、循环组织成一个系统，
处处体现化工原理与反应工程的综合应用。
<span class="marginnote">三个流程的选择有讲究：它们分别代表三类典型——<strong>高压催化气体合成</strong>（氨、甲醇）、<strong>强放热催化氧化</strong>（硫酸 $\ce{SO2}$ 氧化）、以及它们共同的热力学主题（可逆放热反应、循环工艺、能量集成）。读完这三个流程，你对「化工厂长什么样」就有了真实图景。</span>

## 1 合成氨流程

**合成氨（ammonia synthesis）**：
$\ce{N2 + 3H2 <=> 2NH3}$，
哈伯–博施法，20 世纪最重要的化工发明（养活了数十亿人口）。

**原料与制气**：天然气（主要路线）经**蒸汽重整**制氢：
$\ce{CH4 + H2O -> CO + 3H2}$，
再经水煤气变换 $\ce{CO + H2O -> CO2 + H2}$，
脱碳（吸收 $\ce{CO2}$）与甲烷化精制后得纯净的 $\ce{N2:H2 = 1:3}$ 合成气。

**合成工段**：高压（15–30 MPa）、中等温度（400–500 °C）、铁基催化剂，
单程转化率仅 15%–25%——**未反应气体循环**，
产品氨用冷凝或吸收分离，
惰性气体（$\ce{Ar}$、$\ce{CH4}$）需定期排放（弛放气）。
<span class="marginnote">合成氨是「热力学与动力学的世纪博弈」：反应放热、摩尔数减少——热力学要低温高压（平衡有利），动力学要高温（速率快）。哈伯的成就是找到折中——<strong>高压 + 中等温度 + 催化剂</strong>。单程转化率低、循环量大，这是「平衡限制 + 循环工艺」的教科书案例，化学平衡一节的 $K_p$ 计算直接落到这个流程上。</span>

**流程组织**（处处体现单元操作）：

- 原料净化：脱硫（吸附/加氢）、变换、脱碳（吸收）、甲烷化（催化）——**分离 + 催化净化**；
- 合成循环：压缩机加压 → 合成塔 → 冷却 → 氨分离 → 未反应气循环；
- 能量集成：反应放热用于预热原料、副产蒸汽——**过程能量优化**的实例。

## 2 甲醇合成流程

**甲醇合成（methanol synthesis）**：
$\ce{CO + 2H2 -> CH3OH}$，
现代工业以天然气或煤制合成气为原料。

**低压合成工艺**：5–10 MPa、220–280 °C、铜基催化剂，
单程转化率 15%–30%，循环操作。
粗甲醇含水、二甲醚等副产物，经精馏得纯甲醇。
<span class="marginnote">甲醇是「碳一化学的枢纽」：可制甲醛、醋酸、烯烃（MTO）、燃料与氢载体。甲醇合成的动力学是 CO 加氢与 $\ce{CO2}$ 加氢的竞争，催化剂的选择性与组成控制是核心——这是「选择性控制」在工业流程中的典型。相比合成氨，甲醇低压合成是更温和、更现代的工艺路线。</span>

**与合成氨的对照**：

| 项目 | 合成氨 | 甲醇合成 |
| --- | --- | --- |
| 反应 | $\ce{N2 + 3H2 <=> 2NH3}$ | $\ce{CO + 2H2 <=> CH3OH}$ |
| 催化剂 | 铁基 | 铜基 |
| 压力 | 15–30 MPa | 5–10 MPa |
| 温度 | 400–500 °C | 220–280 °C |
| 产品分离 | 冷凝/吸收 | 冷凝 + 精馏 |

**共同特征**：可逆放热、单程转化率低、**循环操作**、反应热利用——三大合成流程（氨、甲醇、费托）共享「合成循环」的工艺骨架。

## 3 硫酸流程

**硫酸（sulfuric acid）**：
接触法（contact process），两步关键反应：

- 焙烧/燃烧：$\ce{S + O2 -> SO2}$（或硫铁矿焙烧）；
- 催化氧化：$\ce{2SO2 + O2 <=> 2SO3}$（$\ce{V2O5}$ 催化剂，
  400–450 °C，强放热、摩尔数减少）；
- 吸收：$\ce{SO3 + H2O -> H2SO4}$（用浓硫酸吸收而非水，避免酸雾）。

**两转两吸（double conversion/double absorption）**：
$\ce{SO2}$ 氧化分两段——第一次转化（~90%）→ 第一次吸收 $\ce{SO3}$ → 未反应气再进第二段转化 → 第二次吸收，
总转化率可达 99.7% 以上。
<span class="marginnote">两转两吸是「<strong>移走产物突破平衡</strong>」的经典工程实现：$\ce{SO2}$ 氧化是可逆放热反应、平衡转化率受限——在中途把 $\ce{SO3}$ 吸收掉，剩下的 $\ce{SO2}$ 继续氧化时平衡右移，总转化率逼近 100%。这与反应精馏「移走产物拉动平衡」是同一个热力学原理（回到《化学平衡》），只是以「分段转化 + 中间吸收」的工艺形式实现。</span>

**硫酸的用途**：「化学工业之母」——磷肥（湿法磷酸）、钛白粉、冶金浸出、石油烷基化、洗涤剂。
硫酸产能常被视为国家化工水平的标尺。
<span class="marginnote">硫酸工艺的温度控制是另一个要点：$\ce{SO2}$ 氧化强放热、催化剂床层分段、段间换热器移热（回到《反应器热稳定性》的多段绝热 + 段间冷却）。催化剂 $\ce{V2O5}$ 的活性窗口、床层温升控制、转化率与尾气排放（环保脱硫）是硫酸厂的设计主线。硫酸生产史也是「尾气治理史」——两转两吸的初衷正是为了达标排放。</span>

## 4 公式解析：全流程的物料衡算

以合成氨为例，全流程设计从**全厂物料衡算**起步：

$$
\ce{N2} + 3\ce{H2} \rightarrow 2\ce{NH3}, \qquad \ce{H2}: \ce{N2} = 3:1
$$

三步拆解这条「流程设计的起点」：

- **第一步，化学计量定原料比**：
  按反应化学计量，$\ce{H2/N2 = 3:1}$。
  过量任何一方都是浪费（惰性组分稀释、增加循环负荷）——进合成塔的气体按化学计量配比。
- **第二步，单程 vs 全流程转化**：单程转化率 15%–25% 决定循环气量；
  全流程总转化率接近 100%（循环把未反应气送回）。
**物料衡算把单程转化率与循环量、产品产量联系起来**——这是全流程模拟的第一层账。
- **第三步，能量与环保联立**：
  物料衡算完成后配热量衡算（反应热、换热网络）与环保约束（驰放气、尾气处理）。
  **流程设计 = 物料衡算 + 热量衡算 + 平衡 + 动力学 + 安全环保**的五重联立——化工工艺把前四篇的所有工具合成了。

## 5 小结

- **合成氨**：蒸汽重整制氢 → 变换/脱碳/精制 → 高压催化合成循环；
  单程转化率低、循环量大。
- **甲醇合成**：低压铜基催化，粗甲醇精馏精制；与合成氨共享「合成循环」工艺骨架。
- **硫酸接触法**：$\ce{SO2}$ 催化氧化 + 浓硫酸吸收；
  **两转两吸**移走产物突破平衡、转化率 99.7%+。
- 三大流程共同主题：可逆放热反应、温度/压力折中、**循环工艺**、反应热利用、环保约束。
- 流程设计 = 物料衡算 + 热量衡算 + 平衡 + 动力学 + 安全环保的综合。
