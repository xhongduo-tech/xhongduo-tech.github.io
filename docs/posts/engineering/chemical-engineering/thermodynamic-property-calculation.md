## 为什么从热力学性质计算开始

工程师需要具体数字：压缩机出口焓、反应器进出口的焓变、流体在任何状态下的熵值。
但这些量**不能直接测量**——温度计量温度、压力表量压力，
焓与熵只能从可测的量**推算**。
热力学性质计算就是这门「推算的艺术」：
以 $T$、$p$、$V$ 数据（来自状态方程）与理想气体热容为输入，
通过热力学关系式求出任意状态的 $H$、$S$、$U$、$G$。
没有这一步，能量衡算、相平衡、反应平衡全是空中楼阁。
<span class="marginnote">本节的钥匙是上一节的<strong>麦克斯韦关系</strong>：它们把「熵对压力的偏导」这类不可测的量，换成「体积对温度的偏导」这类可测的量。热力学性质计算的本质，就是一路把不可测换成可测——这就是「状态方程 → 性质」的桥梁。</span>

## 1 理想气体热容与基准态

**热容（heat capacity）**是性质计算的原料：
定压热容 $c_p$、定容热容 $c_v$，
对理想气体满足 $c_p = c_v + R$。
理想气体热容只是温度的函数，常用多项式关联：

$$c_p^{ig}(T) = a + bT + cT^2 + dT^3$$

工程上用**焓差**而非焓绝对值——一切计算都取**基准态**（通常取 298.15 K、1 atm 的某种参考状态，
令其焓为零或给定标准值），然后积分热容得到任意温度下理想气体的焓：

$$\Delta h^{ig} = \int_{T_0}^{T} c_p^{ig}\,\mathrm{d}T$$

<strong>焓熵没有绝对零点，只有相对基准</strong>——所以化工能量衡算、反应热的计算都以「状态函数之差」为对象，基准态只要前后一致，差值不变。<span class="marginnote">「基准态一致则差值不变」是热力学计算的实用哲学：你可以选任意参考点，只要整个过程都用同一套基准。这也是为什么不同手册的焓值表读出的绝对值不同、但焓差完全一致——用表前先看基准，用表时只取差，是查热力学数据的两条铁律。</span>

## 2 剩余性质：真实流体的修正

真实流体偏离理想气体，用**剩余性质（residual property）**度量：
某状态下实际性质与同温同压下理想气体性质之差：

$$M^R = M(T,p) - M^{ig}(T,p)$$

例如剩余焓 $H^R$、剩余熵 $S^R$。
一旦有了 $H^R$、$S^R$，真实流体的焓熵由理想气体部分 + 修正部分构成：

$$H = H^{ig} + H^R, \qquad S = S^{ig} + S^R$$

**剩余性质可以从状态方程算出来**。
以 $p = p(T,V)$ 型 EOS 为例，剩余焓的通用表达式为：

$$\frac{H^R}{RT} = Z - 1 + \frac{1}{RT}\int_{\infty}^{V}\left[T\left(\frac{\partial p}{\partial T}\right)_V - p\right]\mathrm{d}V$$

积分下限是无穷大体积（对应理想气体极限），上限是实际摩尔体积。
对立方型 EOS，这个积分有解析结果——**给一个状态方程，就有一套对应的剩余焓、剩余熵公式**，
这是流程模拟软件内部在做的计算。
<span class="marginnote">「剩余性质」的分工很清晰：理想气体部分管「温度的影响」（热容积分），剩余部分管「压力的影响」（偏离理想的行为）。两者相加即得真实状态。你可以把剩余焓想成「把它从理想气体'压缩/矫正'到实际状态所需的能量修正」。</span>

**辨析｜易错点：** 剩余性质的定义基准是**同温同压**下的理想气体——注意不是同温同摩尔体积。
许多初学混淆「理想气体状态」与「实际气体状态」的压力基准，导致修正项用错。
判断一个性质是不是剩余性质，先看它是否以「同 T、同 p 的理想气体」为参照。

## 3 公式解析：从状态方程算剩余性质

以 **PR 方程**为例，剩余焓与剩余熵的解析式为：

$$
\frac{H^R}{RT} = Z - 1 + \frac{T\frac{\mathrm{d}a\alpha}{\mathrm{d}T} - a\alpha}{2\sqrt{2}\,bRT}\ln\frac{V + (1+\sqrt{2})b}{V + (1-\sqrt{2})b}
$$

$$
\frac{S^R}{R} = \ln(Z - B) + \frac{\frac{\mathrm{d}a\alpha}{\mathrm{d}T}}{2\sqrt{2}\,bR}\ln\frac{V + (1+\sqrt{2})b}{V + (1-\sqrt{2})b}
$$

三步拆解这套「EOS → 性质」公式：

- **第一步，结构识别**：两项——第一项含压缩因子 $Z$（状态方程本身），
  第二项含 $\ln$ 比值（来自对引力项 $a\alpha$ 的积分）。
  $\mathrm{d}(a\alpha)/\mathrm{d}T$ 是对温度的导数，
体现引力项随温度的变化如何贡献焓与熵。
- **第二步，物理分工**：$H^R$ 中的 $Z - 1$ 反映「分子体积修正」，
  $\ln$ 项反映「分子引力修正」——与状态方程的两项一一对应。
  $S^R$ 中的 $\ln(Z-B)$ 是体积项，
$\ln$ 比值是引力项。
**没有温度导数，熵的引力修正就为零**——因为熵与「吸热随温度的变化」相关。
- **第三步，使用方法**：先解 EOS 求 $V$（或 $Z$），
  再代入上式得 $H^R$、$S^R$；
  配合理想气体的热容积分，
即得任意状态的 $H$、$S$。
**整个过程不需要任何实验焓熵数据**——这正是 EOS 方法的威力：
少数临界参数，推算全部热力学性质。

## 4 相变热与焓熵图的应用

**潜热（latent heat）**是性质计算的重要对象——蒸发、冷凝伴随的焓变。
由克拉佩龙方程：

$$\frac{\mathrm{d}p}{\mathrm{d}T} = \frac{\Delta H_{\text{vap}}}{T\Delta V}$$

对汽液平衡（气相近似理想、液相体积可略），得**克劳修斯–克拉佩龙方程**：

$$\ln p^{\text{sat}} \approx -\frac{\Delta H_{\text{vap}}}{RT} + C$$

以 $\ln p^{\text{sat}}$ 对 $1/T$ 作图得直线，
斜率即 $- \Delta H_{\text{vap}}/R$——**用蒸汽压数据求潜热**的标准方法。
<span class="marginnote">蒸汽压方程（如 Antoine 方程 $\ln p = A - B/(T+C)$）就是克劳修斯–克拉佩龙方程的实用化。查 Antoine 常数得蒸汽压，再由斜率得潜热，这是物性估算的基本功。相变热在《蒸发》《精馏》《干燥》的热量衡算里反复出现，是热量衡算的「潜热项」来源。</span>

**焓熵图（Mollier 图）与温熵图（T–S 图）**：
把焓、熵、温度、压力画成一张图，
工程上直接读图取性质——蒸汽动力循环、制冷循环、透平膨胀都靠它。
**等焓线、等熵线、等压线在图上交织，一次读出四个性质**，比逐项计算快得多。
<span class="marginnote">水蒸气表与焓熵图是热力工程师的「乘法表」。用图要点是识别过程线：等熵（绝热可逆）沿等熵线，节流（绝热不可逆）沿等焓线——两条线画下去，终态一读即得。热力学性质计算的终极目的，就是让工程师能「沿任意过程线读性质」。</span>

## 5 小结

- **热容**是性质计算原料，
  理想气体热容仅为温度函数；**焓熵只有相对基准**，计算一律用差值。
- **剩余性质** = 实际 − 同温同压理想气体；
  真实流体性质 = 理想气体部分 + 剩余修正。
- 剩余焓/熵可从**状态方程**解析求出：
  $Z$ 项对应体积修正、$\ln$ 项对应引力修正。
- **克拉佩龙/克劳修斯–克拉佩龙方程**由蒸汽压数据求潜热；
  Antoine 方程是其实用形式。
- **焓熵图、T–S 图**把性质可视化，过程线（等焓/等熵）一画即读终态。
