## 为什么从最佳接收开始

前几节都在讲「发」：怎么把比特变成波形。这一节站到「收」的一侧，回答一个更尖锐的问题：**给定一段被噪声污染的波形，怎样的处理才是最「优」的判决？** 直觉上的答案——「滤波、放大、判电平」——在数学上会被两个概念彻底改写：**匹配滤波器**在抽样时刻给出最大信噪比，**最大似然判决**在概率意义上给出最小误码率。<span class="marginnote">「最优」在通信理论里是精确的概念：对加性高斯白噪声，使抽样点信噪比最大（匹配滤波）与使误码率最小（最大似然）最终殊途同归——这给了工程师一个坚实的定理，而不是一句口号。</span>这一节的结论将解释为什么上一节的 $P_b = Q(\sqrt{2E_b/N_0})$ 是「最优可达」的。

## 1 检测问题：判决的数学化

数字接收要解决的**检测问题（detection problem）**：收到 $r(t)$，在 $M$ 个可能发送的波形 $s_1(t), \dots, s_M(t)$ 中判决是哪一个。

$$r(t) = s_i(t) + n(t), \quad i \in \{1, \dots, M\}$$

其中 $n(t)$ 是加性高斯白噪声。**判决准则**是统计判决理论里的**最大似然（ML, maximum likelihood）**：在 $M$ 个假设中选择「在已收波形下可能性最大」的那个。对 AWGN 信道，这等价于**最小距离判决**：算 $r(t)$ 与每个候选波形的距离，选距离最近的。<span class="marginnote">为什么「距离最近」是概率最优？因为高斯噪声在信号空间里形成对称的高斯云，真实发送点周围距离越近处概率密度越大——「离谁最近就判给谁」恰好等价于「后验概率最大」。这是信号空间几何与概率最优第一次完美重合。</span>

**信号空间（signal space）**把波形变成点：用一组正交基函数 $\{\phi_j(t)\}$ 展开，每个波形对应一个坐标向量 $\mathbf{s}_i$。判决就变成几何问题——找离接收点 $\mathbf{r}$ 最近的星座点。上一节的星座图，正是信号空间的可视化。

## 2 匹配滤波器：最大输出信噪比

在抽样判决之前，接收端先用一个线性滤波器处理信号。问题：**这个滤波器的冲激响应 $h(t)$ 取什么，能使抽样时刻的输出信噪比最大？**

答案是**匹配滤波器（matched filter）**：

$$h(t) = c \cdot s(T - t)$$

即滤波器的冲激响应是「发送波形的时间反转再平移 $T$」——滤波器与发送波形**匹配**。<span class="marginnote">直觉：滤波器「知道」信号长什么样，于是它像「模板匹配」一样优先放行与信号同形状的频率成分、抑制与信号无关的噪声。噪声在 $T$ 秒内无法与模板对齐，信号却在 $T$ 时刻恰好对齐——信噪比由此被推到最大。</span>

匹配滤波器输出在抽样时刻 $t = T$ 的峰值信噪比为

$$\text{SNR}_{\max} = \frac{2E_s}{N_0}$$

其中 $E_s = \int_0^T s^2(t) dt$ 是符号能量。**匹配滤波器给出的信噪比只由符号能量与噪声密度决定，与发送波形 $s(t)$ 的具体形状无关**——这是「匹配」二字最深刻的含义：波形形状无所谓，关键是让能量全部被利用。

**辨析｜易错点：**匹配滤波器匹配的是**发送波形**，不是**信道**。它假设信道是理想的（只有加性噪声）。信道有衰落、有码间串扰时，需要的是**均衡器**（逆信道），匹配滤波器与均衡器串联使用，各司其职——这在《衰落信道与分集/均衡》一篇展开。

## 3 相关接收：匹配滤波器的等价形式

匹配滤波器输出的计算，可以改写成另一种等价形式。设滤波器输入 $r(t)$，冲激响应 $h(t) = s(T-t)$，输出在 $t=T$ 处为

$$y(T) = \int_0^T r(\tau) s(\tau) d\tau$$

——这正是一个**相关运算**：接收信号与发送波形逐点相乘再积分。<span class="marginnote">匹配滤波器是「卷积」，相关接收是「相关」，二者在抽样时刻给出完全相同的结果。实现上，相关接收需要本地产生 $s(t)$ 并精确对时；匹配滤波器则是一个固定结构的滤波器。工程上两者二选一，数学上它们是一家。</span>

**相关接收机（correlation receiver）**：对每个候选波形 $s_i(t)$ 做一次相关，得到 $M$ 个判决变量，选最大者。<span class="marginnote">把「匹配滤波器 + 抽样」换成「相关器 + 判决」后，整个接收机可以看作「$M$ 个相关器 + 一个比较器」。这架构清晰、易于硬件化，是教科书的标准结构。</span>

## 4 公式解析：匹配滤波器的冲激响应与信噪比

把「为什么要取 $h(t) = s(T-t)$」用三步算明白：

- **第一步，写输出**：滤波输出 $y(t) = \int_0^t r(\tau) h(t-\tau) d\tau$。在抽样时刻 $t=T$，信号分量是 $\int_0^T s(\tau) h(T-\tau) d\tau$。
- **第二步，施耐施瓦茨不等式**：对任意两函数 $a(\tau), b(\tau)$，有 $\left|\int a b\right|^2 \le \left(\int a^2\right)\left(\int b^2\right)$，且**等号当且仅当 $b(\tau) = c \cdot a(\tau)$**。取 $a = s(\tau)$、$b = h(T-\tau)$，则信号分量 $\le \sqrt{E_s \cdot E_h}$。
- **第三步，算噪声功率**：输出噪声功率 $\sigma_y^2 = \frac{N_0}{2}\int_0^T h^2(\tau) d\tau = \frac{N_0}{2} E_h$。
- **第四步，取比值**：$\text{SNR} = \dfrac{(\text{信号分量})^2}{\sigma_y^2} \le \dfrac{E_s E_h}{N_0 E_h / 2} = \dfrac{2E_s}{N_0}$，等号由 $h(T-\tau) = c\, s(\tau)$ 取得——即 $h(t) = c\, s(T-t)$。

**结论：匹配滤波器是最优的，因为施耐施瓦茨不等式的等号条件恰好就是「滤波器与信号共形」。** 这是通信理论里少有的「不等式给出最优设计」的实例。

## 5 最大似然判决与误码率

匹配滤波器 / 相关接收给出的是判决所需的**统计量**，最终判决由最大似然准则完成。对 BPSK，两个候选波形是 $s_1 = +\sqrt{E_b}\cos\omega_c t$ 与 $s_2 = -\sqrt{E_b}\cos\omega_c t$，相关器的输出 $y$ 与两个候选点距离比较，等价于**过零判决**：$y > 0$ 判 1，$y \lt  0$ 判 0。

误码发生在「发送 +1 而噪声把 $y$ 拖过零线」之时，由此得出

$$P_b = Q\left(\sqrt{\frac{2E_b}{N_0}}\right)$$

这正是上一节给出的公式——现在它有了完整的推导链条：匹配滤波给出最大信噪比 $2E_b/N_0$，判决门限由最大似然确定，误码率由高斯右尾概率给出。<span class="marginnote">这条链是通信原理最美的地方之一：<strong>滤波（匹配）、判决（ML）、误码（Q 函数）三件事被同一个 $E_b/N_0$ 串起来</strong>。任何体制的误码分析，都是先把信号放进信号空间、再套这条链。</span>

**辨析｜易错点：**匹配滤波器与相关接收的等价性建立在**精确同步**之上：抽样时刻必须对齐到 $T$，本地模板必须与发送波形同相。定时偏差会直接损失信噪比——这就是《同步原理》一篇存在的理由。此外，匹配滤波器不消除码间串扰，ISI 的消除靠脉冲成形与均衡，两者别混为一谈。

## 6 术语速查表

| 术语 | 含义 | 关联概念 |
| --- | --- | --- |
| 检测问题 | 从 $M$ 个候选波形中判决发送的是哪个 | 统计判决理论 |
| 最大似然（ML） | 选「在已收波形下可能性最大」的假设 | AWGN 下 = 最小距离 |
| 最小距离判决 | 找离接收点最近的星座点 | 信号空间几何 |
| 信号空间 | 波形用正交基展开成的点空间 | 星座图的数学本质 |
| 匹配滤波器 | $h(t) = s(T-t)$ 的线性滤波器 | 抽样点信噪比最大 |
| 相关接收 | 本地模板 × 接收信号再积分 | 匹配滤波的等价形式 |
| 判决门限 | 区分两个候选点的临界值 | BPSK 是零线 |
| $E_b/N_0$ | 每比特能量与噪声谱密度之比 | 一切误码曲线的横轴 |
| $Q(x)$ | 高斯右尾概率函数 | 误码率的标准表达 |
| 相干检测 | 需本地载波同频同相的检测 | 依赖《同步原理》 |
| 抽样时刻 | 匹配滤波输出取样的时刻 $T$ | 定时误差直接损失 SNR |

<span class="marginnote">这张表藏着一条推理链：<strong>检测问题 → 最大似然 → 最小距离 → 信号空间</strong>，四行连起来就是「为什么看图就能定误码」；而 <strong>匹配滤波 → 相关接收</strong> 两行是同一件事的两种实现。剩下的是把这条链「算成数」的工具——$E_b/N_0$ 与 $Q(x)$。</span>

## 7 一步一练：从信噪比算出 BPSK 误码率

设相干 BPSK 工作在 $E_b/N_0 = 9.6$ dB，估算误比特率 $P_b$。

- **第一步，去 dB**：$E_b/N_0 = 10^{9.6/10} = 10^{0.96} \approx 9.12$（功率比）。
- **第二步，算 $Q$ 的自变量**：$\sqrt{2E_b/N_0} = \sqrt{18.24} \approx 4.27$。
- **第三步，查 $Q$ 函数**：$Q(4.27) \approx 9.8 \times 10^{-6}$——即平均每传约 10 万比特错 1 个。
- **第四步，读 $E_b/N_0$ 的杠杆**：若把 $E_b/N_0$ 提高 3 dB 到 12.6 dB，自变量变为 $\sqrt{2 \times 18.24} = 6.04$，$Q(6.04) \approx 10^{-9}$——误码率暴跌三个数量级。**$E_b/N_0$ 每多 3 dB，BPSK 误码率大约降一个数量级以上，这就是「功率换可靠性」的量化手感**。

## 8 小结

- **检测问题**：从 $M$ 个候选波形里判决；AWGN 下最大似然 = 最小距离判决。
- **信号空间**把波形变点，星座图是它的可视化；判决变成「找最近点」。
- **匹配滤波器** $h(t) = s(T-t)$：冲激响应与发送波形共形，抽样点信噪比取到最大 $\text{SNR} = 2E_s/N_0$。
- **相关接收**：匹配滤波在抽样时刻等价于「本地模板 × 接收信号再积分」；$M$ 个相关器 + 比较器构成标准接收机。
- **施耐施瓦茨不等式**给出最优性证明：等号条件就是滤波器与信号共形。
- **误码率** $P_b = Q(\sqrt{2E_b/N_0})$
