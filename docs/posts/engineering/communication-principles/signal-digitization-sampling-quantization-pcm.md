## 为什么从数字化开始

模拟调制把连续消息搬上载波，但模拟信号有个致命弱点：一旦被噪声污染，几乎无法彻底恢复——「失真的消息」与「原消息」没有边界。数字化的思路完全不同：先把连续的消息变成离散的 0/1 序列，再传 0/1。**只要判决没错，接收端拿到的就是一模一样的比特流，噪声被彻底隔离在判决门之外**。<span class="marginnote">这就是数字通信「抗噪」的根本逻辑：模拟系统对抗噪声靠「提高信噪比」，数字系统对抗噪声靠「判决 + 中继再生」。中继器不是把信号放大，而是把信号「重新制造」出来，噪声不再逐级累积。香农公式里 $R<C$ 无差错传输的承诺，在这里以工程形式兑现。</span>而把模拟消息变成比特的工序，就是本节的抽样、量化与 PCM。

## 1 抽样定理：模拟到离散的桥梁

**抽样（sampling）**：每隔 $T_s$ 秒取信号的一个瞬时值，$f_s = 1/T_s$ 称为**抽样频率**。

**抽样定理（sampling theorem）**：一个带宽受限的**低通信号**，若最高频率为 $f_H$，当抽样频率满足

$$f_s \ge 2 f_H$$

时，可以从样值**无失真**地恢复原信号。$2f_H$ 称为**奈奎斯特速率（Nyquist rate）**。<span class="marginnote">直觉版证明：抽样在频域等效于把原频谱以 $f_s$ 为周期「复制」成无数个平移副本。只要副本之间不重叠（$f_s \ge 2f_H$），一个理想低通滤波器就能把原频谱「扣」出来——这就是频域卷积定理的妙用。</span>

恢复靠**内插（interpolation）**：每个样值乘 $\text{sinc}$ 函数再叠加。理想低通滤波器在频域就是矩形窗，时域正是 $\text{sinc}$ 形状——「样值之间补上平滑曲线」这件事，数学上由 $\text{sinc}$ 内插完成。<span class="marginnote">$\text{sinc}(t) = \sin(\pi t)/(\pi t)$ 在 $t=0$ 处取 1、在整数时刻取 0。无数个「在别的样值处恰好为 0」的 $\text{sinc}$ 叠加，正好不干扰彼此的样值——这就是理想重建的几何直觉。</span>

**带通抽样（bandpass sampling）**：若信号带宽为 $B$ 但中心频率很高，不必以 $2f_H$ 抽样，只要 $f_s \ge 2B$（且满足频谱不混叠的条件）即可，这称为**欠抽样**。现实中数字化常常先搬移频谱再以较低的频率抽样。

**辨析｜易错点：**当 $f_s \lt  2f_H$ 时，频谱副本互相重叠，称为**混叠（aliasing）**。混叠是无法通过滤波去除的——被「折回」的高频成分和真实低频成分纠缠在一起，之后的任何处理都救不回来。因此工程上先加**抗混叠滤波器**（低通，截止 $f_H$）再抽样。

## 2 量化：连续到有限的逼近

抽样把连续时间离散化，但样值幅度仍是连续量，无法用有限个比特表示。**量化（quantization）**把连续幅度映射为有限个**量化电平**，这一步是**不可逆的、有损的**。

**均匀量化（uniform quantization）**：把幅度范围等分成 $M$ 个间隔，步长 $\Delta$。每个样值被就近取到最近的电平。量化引入的误差称为**量化噪声（quantization noise）**，均匀量化下其平均功率为

$$N_q = \frac{\Delta^2}{12}$$

「12」来自均匀分布的方差公式：量化误差在一个间隔内近似均匀分布，方差为 $\Delta^2/12$。<span class="marginnote">量化误差是数字化的「原罪」，但它有边界：只要量化级足够密，误差就足够小。与之对照，模拟噪声的污染是无界的——这是「有损数字化」依然远优于「无损模拟」的核心理由。</span>

**量化信噪比（SQNR）**：信号功率与量化噪声功率之比，均匀量化下与比特数 $n$ 直接挂钩（下一节公式解析展开）。

**辨析｜易错点：**抽样是**无损**的（理想条件下），量化是**有损**的。把两者混为一谈、以为数字化就是「取点」，会漏掉量化噪声这个后续所有信噪比分析的来源。

## 3 PCM 系统：抽样-量化-编码

**脉冲编码调制（PCM, Pulse Code Modulation）**是模拟数字化最经典的体制，三步走：

**抽样**：以 $f_s \ge 2f_H$ 取离散样值。**量化**：把每个样值归一到 $M = 2^n$ 个量化电平之一。**编码**：每个量化电平用 $n$ 位二进制码表示，输出比特流。

语音 PCM 的标准参数是：抽样 $f_s = 8$ kHz（语音最高频率按 3.4 kHz，取 $2 \times 3.4 = 6.8$ kHz 再取整留裕量到 8 kHz），量化 $n = 8$ bit，码率

$$R_b = f_s \times n = 8000 \times 8 = 64 \ \text{kbit/s}$$

64 kbit/s 是数字电话的标准速率，也是后续所有数字体制的基准参照。<span class="marginnote">8 kHz × 8 bit = 64 kbit/s，这个数字刻在电信史里：PCM 一次群、ISDN 的 B 通道都是它。记住这个具体数字，比记住抽象公式更有用——它把抽样定理、量化位数和码率三个概念一次性钉在一起。</span>

**辨析｜易错点：**码率 $R_b = f_s n$ 与抽样频率、量化位数是一体三面：想提高话音质量就加 $n$（更细量化）或加 $f_s$（更宽带宽），代价是码率线性上升。**码率一旦定死，话音质量与占用带宽就被共同锁死**——这是 64 kbit/s 时代所有压缩算法的出发点。

## 4 公式解析：量化信噪比 $\mathrm{SQNR} = 6.02n + 1.76 \ \mathrm{dB}$

**这是 PCM 里最实用的公式：每增加 1 位量化，信噪比多 6 dB**。拆解如下：

**第一步，写噪声功率**：均匀量化步长 $\Delta$，噪声平均功率 $N_q = \Delta^2/12$（见第 2 节）。
**第二步，写峰值信号功率**：设满量程峰峰值 $V_{\mathrm{pp}} = M\Delta = 2^n \Delta$，对正弦信号，峰值幅度 $V_{\mathrm{pp}}/2$，信号功率 $P_s = (V_{\mathrm{pp}}/2)^2 / 2 = M^2\Delta^2/8$。
**第三步，做比值**：$\mathrm{SQNR} = \dfrac{P_s}{N_q} = \dfrac{M^2\Delta^2/8}{\Delta^2/12} = 1.5 \times 2^{2n}$。
- **第四步，转成 dB**：$10\log_{10}(1.5 \times 2^{2n}) = 10\log_{10}1.5 + 20n\log_{10}2 \approx 1.76 + 6.02n$。

**辨析｜易错点：**这里用的是**满幅正弦**假设。实际信号若幅度远小于满量程，SQNR 会同步下降——小信号被量化得「很粗糙」。这正是下一节**非均匀量化**要解决的问题：把小信号区间的步长加密，牺牲大信号区间的精度，换取全动态范围的平稳信噪比。

## 5 非均匀量化与压扩

语音信号的幅度呈**小幅度占大多数**的分布。均匀量化对大信号精细、对小信号粗糙，恰好用反了。

**非均匀量化（non-uniform quantization）**：小信号用密电平、大信号用疏电平，等效于先对幅度做**对数压缩**再均匀量化，接收端做逆变换**扩张**，合称**压扩（companding）**。<span class="marginnote">一句话记忆：压缩器「把小信号抬起来」（对数放大），使量化台阶对小信号相对更细；扩张器在接收端把动态范围还原。压缩/扩张互为逆运算，全程无信息损失，只改变量化台阶的分布。</span>

工程上有两套标准曲线。**A 律（A-law）**：中国与欧洲电信使用，取 $A = 87.6$，用 13 折线近似；**μ 律（μ-law）**：北美与日本使用，取 $\mu = 255$，用 15 折线近似。

$$A\text{律：}\quad y = \begin{cases} \dfrac{Ax}{1+\ln A}, & 0 \le x \le \dfrac{1}{A} \\[6pt] \dfrac{1+\ln(Ax)}{1+\ln A}, & \dfrac{1}{A} \lt  x \le 1 \end{cases}$$

**辨析｜易错点：**压扩是**对幅度动态范围**的优化，不是抗信道噪声的编码。它改变的是「量化噪声与信号幅度的相对关系」，让弱信号不被量化噪声淹没——这与《信道编码》纠正信道误码是两回事，不要混淆。

## 6 术语速查表

| 术语 | 含义 | 易混点 |
| --- | --- | --- |
| 抽样 | 每 $T_s$ 秒取一个瞬时值，$f_s = 1/T_s$ | 无损（理想条件下） |
| 奈奎斯特速率 | $2f_H$，低通无失真重建的最小抽样频率 | 带通用 $2B$ 而非 $2f_H$ |
| 混叠 | $f_s \lt  2f_H$ 时频谱副本重叠 | 滤波救不回，只能事前防 |
| 量化 | 连续幅度映射到 $M$ 个电平 | **有损**，误差有界 |
| 量化噪声 | 量化误差功率 $\Delta^2/12$ | 均匀量化下与信号无关 |
| SQNR | 信号功率 / 量化噪声功率 | $\approx 6.02n + 1.76$ dB |
| PCM | 抽样 + 量化 + 编码三步 | 语音标准 64 kbit/s |
| 码率 | $R_b = f_s \times n$ | 与带宽、音质锁死 |
| 非均匀量化 | 小信号密、大信号疏的量化台阶 | 优化动态范围信噪比 |
| A 律 / μ 律 | 两种对数压扩标准 | 中国用 A 律、北美用 μ 律 |
| 压扩 | 压缩 + 扩张的合称 | 是幅度优化，不是信道编码 |

<span class="marginnote">这张表里最该记住的三行：「抽样无损、量化有损」「码率 = 抽样率 × 位数」「SQNR 每 1 位 +6 dB」——三句话就能把数字化一节的全部定量关系串起来，其余都是派生。</span>

## 7 一步一练：CD 音频的码率与信噪比

CD 音频用 $f_s = 44.1$ kHz、$n = 16$ bit 量化，求码率与量化信噪比，并与电话 PCM 对照。

- **第一步，算码率**：$R_b = 44.1 \times 10^3 \times 16 \approx 705.6$ kbit/s（单声道）；立体声加倍为 1.411 Mbit/s。
- **第二步，算 SQNR**：$\text{SQNR} = 6.02 \times 16 + 1.76 \approx 98.1$ dB——远超人耳可分辨的动态范围。
- **第三步，对照电话**：电话 8 kHz × 8 bit = 64 kbit/s、SQNR ≈ 49.8 dB。CD 每秒数据是电话的 22 倍、信噪比是电话的约 48 dB 更高——**这就是「够用即可」与「高保真」在数字化参数上的真实差距**。

**这一步一练的启示**：抽样率与位数不是越大越好，而是按应用定：语音按人耳频带上限取 8 kHz，音乐按 20 kHz 人耳上限取 44.1 kHz——**数字化参数设计的本质，是「感知上限 + 工程裕量」**。

## 8 小结

- **抽样定理**：低通信号 $f_s \ge 2f_H$ 可无失真重建；低于奈奎斯特速率产生**混叠**，无法事后补救。
- **抽样无损、量化有损**：均匀量化噪声功率 $\Delta^2/12$，这是数字化的固有代价。
- **PCM** = 抽样 + 量化 + 编码；语音标准 $f_s = 8$ kHz、$n = 8$ bit，码率 64 kbit/s。
- **SQNR** $\approx 6.02n + 1.76$
