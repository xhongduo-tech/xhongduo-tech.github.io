## 为什么从导行波开始

前几节的平面波在开阔空间里自由奔跑，可现实里能量要**沿一条确定的路径**送到目的地：家里墙里的双绞线、馈给电视天线的同轴电缆、基站到机房的光缆，都是"把波关起来送"的结构。这类结构统称**导行系统（guided-wave structure）**，其中最常见的双导体结构叫**传输线（transmission line）**。<span class="marginnote">当信号频率低到波长远大于电路尺寸时，"电路"足够用；一旦频率升到射频，线长可与波长相比，就必须改用场的语言——海维赛德在 1880 年代为电报线建立的那套方程，今天仍是每一根射频馈线的物理基础。</span>本篇对标 David K. Cheng《Field and Wave Electromagnetics》第 9 章：先建立传输线的分布参数模型，再把场论里的 TEM/TE/TM 模说清。

## 1 从"电路"到"传输线"：分布参数的诞生

集总电路假设元件的尺寸远小于波长，电压电流沿导线"同时到达"任一点。频率一高，这个假设崩塌：导线每一小段都有电阻、电感，段与段之间有电容、漏电导，参数**沿线路分布**而不是集中在某个元件里。<span class="marginnote">把一段 $\Delta z$ 的线看成"微元电路"：串联 $R'\Delta z, L'\Delta z$，并联 $G'\Delta z, C'\Delta z$，让 $\Delta z\to0$ 就得到偏微分方程。$R',L',G',C'$ 是单位长度参数，由几何与材料决定。</span>

对微元列基尔霍夫定律，令 $\Delta z\to0$，得到**电报方程（telegrapher's equations）**

$$-\frac{\partial V}{\partial z} = R'I + L'\frac{\partial I}{\partial t}, \qquad -\frac{\partial I}{\partial z} = G'V + C'\frac{\partial V}{\partial t}$$

**辨析｜易错点：** 电报方程里 $V,I$ 是"传输线横截面上的电压与线电流"，它们只有在横截面尺度远小于波长时才定义良好——这正是 TEM 波才有的性质。到第 8 篇的波导里没有单一"电压"概念，只能谈场，两者的适用范围要分清楚。

## 2 传输线方程与波动解

时谐下，电报方程合并成一个波动方程，定义**传播常数**与**特征阻抗**

$$\gamma = \alpha + j\beta = \sqrt{(R'+j\omega L')(G'+j\omega C')}, \qquad Z_0 = \sqrt{\frac{R'+j\omega L'}{G'+j\omega C'}}$$

无损耗线（$R'=G'=0$）时 $\alpha=0$，$\beta = \omega\sqrt{L'C'}$，$Z_0 = \sqrt{L'/C'}$（纯电阻）。波沿线的解是入射波与反射波的叠加

$$V(z) = V^+e^{-\gamma z} + V^-e^{\gamma z}, \qquad I(z) = \frac{1}{Z_0}\left(V^+e^{-\gamma z} - V^-e^{\gamma z}\right)$$

**特征阻抗（characteristic impedance）** $Z_0$ 是"正向行波电压与电流之比"，只由线的分布参数决定，与终端无关。<span class="marginnote">常见传输线的 $Z_0$：同轴线约 50Ω（75Ω 用于视频）、双绞线约 100Ω、微带线可设计任意值。射频设备都按 50Ω 设计，就是为了与标准线的特征阻抗匹配、减小反射。</span>

线内波的相速度与自由空间不同：$v_p = 1/\sqrt{L'C'} = c/\sqrt{\varepsilon_{re}}$，其中 $\varepsilon_{re}$ 是**等效相对介电常数**（介质基板用 $\varepsilon_r$，但部分场可能在空气中，故取折中值）。于是线上波长 $\lambda_g = v_p/f = \lambda_0/\sqrt{\varepsilon_{re}}$ 比自由空间短——这就是"介质加载缩短波长"现象。PCB 设计里计算一段 $\lambda/4$ 微带线的物理长度，必须先换算成波导波长，否则调出来的匹配段频率全偏。

**辨析｜易错点：** $Z_0$ 不是"你拿万用表量到的电阻"。一段匹配好的传输线，输入端看进去的输入阻抗等于 $Z_0$，但那是因为没有反射；失配时输入阻抗是复数且沿线变化。把特征阻抗当成"线的直流电阻"，是初学最常见的误解。

## 3 终端反射与输入阻抗

传输线终端接负载 $Z_L$。线端处的反射系数

$$\Gamma_L = \frac{V^-}{V^+} = \frac{Z_L - Z_0}{Z_L + Z_0}$$

距终端距离 $l$ 处看进去的**输入阻抗（input impedance）**

$$Z_{in}(l) = Z_0\,\frac{Z_L + jZ_0\tan(\beta l)}{Z_0 + jZ_L\tan(\beta l)}$$

<span class="marginnote">这条式子是传输线的"万能钥匙"：$Z_L=Z_0$ 时 $Z_{in}=Z_0$（匹配，无反射）；$Z_L=0$（短路）时 $Z_{in}=jZ_0\tan\beta l$；$Z_L=\infty$（开路）时 $Z_{in}=-jZ_0\cot\beta l$。一段特定长度的短线可以等效成一个电感或电容——高频电路里的"短线调谐""开路线偏置"全由此而来。</span>

三个工程常用的特例：**匹配负载**（$Z_L=Z_0$，$|\Gamma|=0$，能量全吸收）；**全反射端**（短路或开路，$|\Gamma|=1$，形成纯驻波）；**四分之一波长线**（$l=\lambda/4$ 时 $Z_{in} = Z_0^2/Z_L$，阻抗反演——与第 6 篇的四分之一波长变换器是同一件事）。

**辨析｜易错点：** 输入阻抗随线长周期变化（周期 $\lambda/2$）。于是"测输入阻抗反推负载"必须知道线的长度与电长度；忽略了线长，把失配误判成"负载有问题"，是射频调试里反复出现的坑。

一个立刻能用的推论：把一段长度可变的短路短线（**短路支节**）并联在主线某处，相当于在线上"并联一个可调电抗"。选择合适的接入点与支节长度，就能把失配负载"拉回"匹配——这是射频里最古老的匹配手段之一（单支节匹配），至今仍在天线调试与 Smith 圆图操作里作为基本功出现。它的数学依据，正是 $Z_{in}=jZ_0\tan\beta l$ 这条短路线的输入阻抗公式。

顺带一提，工程上更常用的可视化工具是 **Smith 圆图**：把反射系数（或阻抗）画在归一化复平面上，传输线长度沿圆周转一圈对应 $\lambda/2$，匹配问题变成"转圆、读交点"的几何操作。它本质上是输入阻抗公式的图解版本，所有现代射频仿真软件仍保留它的交互面板。

## 4 TEM/TE/TM 模：导行波按场结构分类

导行波按**纵向场分量是否存在**分为三类，这是场论给导行系统的分类法：

| 模 | 纵向 $\mathbf{E}_z$ | 纵向 $\mathbf{H}_z$ | 典型结构 |
| --- | --- | --- | --- |
| TEM | 无 | 无 | 同轴线、双线、微带（准 TEM） |
| TE | 无 | 有 | 空波导、圆波导 |
| TM | 有 | 无 | 空波导、圆波导 |

**TEM 模（横电磁波）**的电场磁场都垂直于传播方向，与自由空间平面波同构——它**必须**有两根以上导体来约束场，才能存在。**TE 模**只有磁场有纵向分量、**TM 模**只有电场有纵向分量，它们可以在**单根空心金属管（波导）**里存在，因为纵向分量靠金属壁的边界条件"托住"。<span class="marginnote">TEM 波没有截止频率（从直流起就能传）；TE/TM 波存在<strong>截止频率</strong>——频率低于截止值就无法传播。这就是为什么波导只能传高频、而电缆从直流就能用：波导的"高通"特性和 TEM 线的"全通"特性，是两类导行系统最大的工程差别。</span>

## 5 同轴线与微带线：两种最常见的传输线

**同轴线**：内导体半径 $a$、外导体半径 $b$、介质介电常数 $\varepsilon$。单位长度电容（第 2 篇）与电感（第 3 篇）代入，得特征阻抗

$$Z_0 = \frac{1}{2\pi}\sqrt{\frac{\mu}{\varepsilon}}\ln\frac{b}{a} = \frac{60}{\sqrt{\varepsilon_r}}\ln\frac{b}{a}\ \ \Omega$$

同轴线还有一个重要性质：**自屏蔽**。外导体是完整的金属壳，内部场不泄漏、外部场进不来——电磁兼容设计里最优先的传输线选择。它的代价是每单位长度损耗比开放结构稍高，且弯折半径受限。

除同轴线与微带线外，工程上还有**带状线**（介质夹在两层地之间，TEM）、**共面波导**（同层地、无过孔，适合毫米波）、**鳍线**等一大家子。它们的共同点是"用金属边界把场约束在已知介质里"，差别只在损耗、带宽、成本与可制造性之间的权衡——选型没有唯一答案，都是工程折中。

**微带线**：介质基板上一条金属带、背面整片地，是印制电路板（PCB）的"印制传输线"。严格说是准 TEM（部分场在空气中、部分在介质里），其等效介电常数介于空气与介质之间，$Z_0$ 由带线宽高比近似决定。<span class="marginnote">微带线是射频 PCB 的绝对主角：手机射频前端、微波放大器、天线馈电网络几乎全用微带。它把"传输线"印在板子上，代价是比同轴线更容易辐射与损耗——天线设计里微带既是馈线也可能是天线本身（微带天线），本博客《通信原理》《微波》可对照。</span>

**辨析｜易错点：** 同轴线内外导体间的介质会带来损耗，频率越高介质损耗占比越大；微带线还多了辐射损耗。算链路损耗时把"导体损耗 + 介质损耗 + 辐射损耗"分项列清，比笼统说"线有损耗"靠谱得多。

## 6 传输线的功率流与损耗

沿线传输的时间平均功率 $P = \frac{1}{2}\mathrm{Re}[V I^*]$。无反射（匹配）时 $P = |V^+|^2/(2Z_0)$；有反射时功率一部分被负载吸收、一部分反射回源，传输效率下降。透过功率与入射功率之比，正是传输线的**传输效率**——匹配越差，同一段线的"有效长度"越短。工程上把"回波有多强"量化为**回波损耗** $\mathrm{RL} = -20\lg|\Gamma|\ \mathrm{dB}$ 与**插入损耗**，$|\Gamma|=0$ 时回波损耗无限大（dB 为无穷），$|\Gamma|=1$ 时为零。<span class="marginnote">dB 是射频工程师的日常语言：回波损耗 20 dB 对应 $|\Gamma|=0.1$、反射功率 1%，通常已是"匹配良好"的门槛；3 dB 意味着功率对半分，很多分配器、耦合器就以 3 dB 为设计目标。</span>

有损线中传播常数 $\alpha$ 由导体损耗 $\alpha_c$ 与介质损耗 $\alpha_d$ 组成（$\alpha=\alpha_c+\alpha_d$），两者都随频率升高而增大——这解释了为什么高频信号在长线里衰减快，也解释了为什么远距离高速传输要"中继放大"或改用光纤。

## 7 公式解析：输入阻抗公式的来历

终端接 $Z_L$ 的无损线，输入阻抗公式 $Z_{in}=Z_0\frac{Z_L+jZ_0\tan\beta l}{Z_0+jZ_L\tan\beta l}$ 是怎么来的？三步还原：

**第一步，写出沿线电压电流**：$V(z)=V^+e^{-j\beta z}+V^-e^{j\beta z}$，$I(z)=\frac{1}{Z_0}(V^+e^{-j\beta z}-V^-e^{j\beta z})$，坐标 $z$ 从终端算起。
**第二步，代入终端条件**：在 $z=0$ 处 $V(0)/I(0)=Z_L$，解出反射系数 $\Gamma_L=(Z_L-Z_0)/(Z_L+Z_0)$，即 $V^-=\Gamma_L V^+$。
**第三步，求输入阻抗**：在距终端 $l$ 处（$z=-l$），$Z_{in}=V(-l)/I(-l)$，代入 $V^\pm$ 与 $e^{\pm j\beta l}$，整理即得上式。

**三个要点**：第一，$Z_{in}$ 依赖电长度 $\beta l = 2\pi l/\lambda$，所以"线有多长"永远换算成"几个波长"；第二，$\tan\beta l$ 的周期性让 $Z_{in}$ 每 $\lambda/2$ 重复一次；第三，$Z_L=Z_0$ 时 $\Gamma_L=0$、$Z_{in}=Z_0$——匹配是唯一的"沿线处处相同"的输入阻抗。<span class="marginnote">这条式子把第 6 篇的"波撞界面"推广成"波沿线多次反射"：每反射一次就叠一个 $\Gamma$，所有往返波的无穷级数求和，结果就是那个 $\tan$ 形式。传输线理论本质上是"多次反射的稳态合成"。</span>

## 8 小结

- **分布参数** $R',L',G',C'$ 把传输线写成微元电路，电报方程是它的场论形式；集总电路只在波长≫尺寸时成立。
- **特征阻抗** $Z_0=\sqrt{(R'+j\omega L')/(G'+j\omega C')}$，无耗时 $Z_0=\sqrt{L'/C'}$，是线的固有属性、与终端无关。
- **反射系数** $\Gamma_L=(Z_L-Z_0)/(Z_L+Z_0)$，**输入阻抗** $Z_{in}$ 由电长度与终端共同决定；匹配时无反射、全吸收。
- **TEM/TE/TM 分类**看纵向场分量：TEM 需双导体、无截止；TE/TM 可在空波导中传、有截止频率。
- 同轴线 $Z_0=\frac{60}{\sqrt{\varepsilon_r}}\ln\frac{b}{a}$，微带线是射频 PCB 的主角；损耗分导体、介质、辐射三部分。
- 回波损耗与插入损耗用 dB 度量，是射频链路调试的日常指标。
- 短路支节与四分之一波长线是两种最常用的匹配手段，输入阻抗公式是它们共同的数学来源。
- 导行系统的选型是损耗、带宽、成本与可制造性的折中：同轴线自屏蔽、微带可印制、波导高通——没有全能冠军。
- 线上波长比自由空间短（介质加载），电长度换算必须用 $\lambda_g$
