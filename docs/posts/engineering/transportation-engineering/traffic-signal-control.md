## 为什么从信号控制开始

交叉口是路网的冲突点：东西向与南北向的车流、行人、左转车，在同一块地皮上争抢。若任其自流，冲突必然导致事故；若全部立交，造价惊人。**交通信号控制（traffic signal control）** 用时间换空间：让互不兼容的车流分时使用交叉口，把「同时争抢」变成「轮流通过」。它是交通工程中最接近「实时调度」的领域——一个城市成千上万个信号灯，共同决定每天数千万人次的出行节奏。<span class="marginnote">信号控制本质上是一个「调度问题」：在有限的绿灯时间里给竞争性需求分配服务。这与操作系统里的 CPU 时间片调度、网络里的带宽分配同构——都是「多资源竞争共享介质」的排队与优化问题，参见第三级《操作系统》与《计算机网络》。</span>

## 1 信号的基本语言：周期、相位与绿信比

一套信号配时由三个基本量刻画：

- **周期（cycle length）$C$**：信号灯完整循环一遍的时间，一般 60–180 s。
- **相位（phase）**：一组同时获得绿灯的、互不冲突的车流集合。最简单的两相位是「东西直行」与「南北直行」交替放行；左转流量大时加入**专用左转相位**，变成三相位、四相位。
- **绿信比（split / green ratio）$\lambda$**：某相位的有效绿灯时间 $g$ 与周期之比，$\lambda = g / C$。所有相位的绿信比之和加上损失时间比例等于 1。

还有一个隐藏概念：**损失时间（lost time）$L$**——绿灯刚亮时车流启动需要反应时间，绿灯将灭时又要黄灯过渡，这些「花在换相上」的时间不产生通过量。一个周期内总损失时间 $L$ 是各相位启动损失 + 全红时间之和。<span class="marginnote">损失时间是信号配时里的「摩擦力」：相位越多，换相越频繁，损失时间占比越高，通行效率越低——这就是「宁可少设相位」的工程直觉。四相位交叉口比两相位更安全，但效率也必然更差，取舍是常态。</span>

## 2 从流量到配时：Webster 方法

1920 年代以来，工程师一直想知道「周期该设多长」。1958 年，韦伯斯特（F. V. Webster）基于排队论给出了经典答案——**使车辆平均延误最小的最佳周期**：

$$C_{\text{opt}} = \frac{1.5\,L + 5}{1 - \sum_i y_i}$$

其中 $y_i = q_i / s_i$ 是第 $i$ 个相位的**流量比**（到达流量 ÷ 饱和流率），$\sum y_i$ 是所有关键相位的流量比之和。<span class="marginnote">$1 - \sum y_i$ 是「剩余容量」：分母越接近 0，说明交叉口越接近饱和，最佳周期会爆炸式增长——这正是「交叉口快要溢流时，周期必须大幅拉长」的量化表达。Webster 公式是排队论在交通上的第一次经典胜利。</span>

**辨析｜易错点：** $\sum y_i$ 必须小于 1，交叉口才能稳定服务；若某相位 $y_i$ 接近或超过 1，说明该流向需求已超过饱和流率——**任何配时都救不活一个需求超额的交叉口**，此时必须动几何（加车道）或需求（TDM），而不是继续调灯。Webster 公式有一个显式假设：到达服从泊松分布、交叉口未过饱和。在过饱和、随机到达明显的条件下，需要更精细的延误模型（如 HCM 2010 版延误公式）。

## 3 公式解析：黄灯时间为什么不是拍脑袋定的

绿灯结束到红灯亮起之间，需要一段黄灯，让「刹得住的车停下、停不住的车通过」。黄灯时长 $Y$ 由运动学决定：

$$Y = t_r + \frac{v}{2a} + \frac{w + l}{v}$$

分四步拆解：

- **第一步，$t_r$（反应时间）**：驾驶员看到黄灯到开始决策的时间，约 1 s。任何小于反应时间的黄灯都是「陷阱」。
- **第二步，$\frac{v}{2a}$（制动时间）**：以减速度 $a$ 从速度 $v$ 刹停所需的时间 $\frac{v}{a}$，再乘 1/2——因为减速过程的平均速度是 $v/2$，通过的距离对应的时间折算。$a$ 取舒适减速度（约 3–3.7 m/s²），而非极限制动。
- **第三步，$\frac{w + l}{v}$（通过时间）**：若决定不停，车辆要以 $v$ 通过交叉口——$w$ 是交叉口宽度，$l$ 是车身长度，除以速度得到穿越时间。这一项保证「已经在停车线前几米的车」不会被困在交叉口中。
- **第四步，两项取大原则**：黄灯时长必须同时满足「能安全刹停」与「能安全通过」两类驾驶员的决策需求，工程上取两者的协调值，并加上全红时间进一步清空交叉口。

**重点：** 黄灯不是「宽容时间」，而是**决策窗口**。黄灯过短，司机来不及反应只能闯红灯；黄灯过长，司机把黄灯当绿灯抢行。它的长度应当由车速与几何**算出来**，而非随意设定——这是交通工程「用物理定规则」的典型一例。

## 4 从单点配时到协调与感应控制

单点定时信号（fixed-time）只服务一个交叉口，但城市里更常见的是**协调控制**与**感应控制**：

- **绿波带（green wave）**：沿主干道把相邻信号灯的绿灯错开，使车队以设定速度行驶时「一路绿灯」。绿波带的本质是让信号周期对齐、相位差（offset）等于路段行程时间的倍数。合理设计可显著减少停车次数，但只在周期与流量稳定时奏效。<span class="marginnote">绿波带的「相位差」概念，与波传播的相位、网络同步（如电力系统频率同步）异曲同工——都是「让周期性过程在空间上错开排列」，参见第二级《波动光学》与第九级《网络科学》。</span>
- **感应控制（actuated control）**：检测器探测到有车到来才延长或放行绿灯，适合流量波动大的路口。
- **自适应控制（adaptive control）**：实时用检测数据在线重算配时参数（周期、绿信比、相位差），在超大城市已大规模部署——这是《智能交通系统（ITS）》与《控制工程》在路口的落地。

**辨析｜易错点：** 绿波带设计时，周期必须全线统一，否则相位差无法恒定；而相位差的选取要匹配车队实际行驶速度，取错了不但不成绿波，反而成「红波」——每条路都是红灯。调相位差不是调颜色，是调**时间轴上的空间对齐**。

## 5 信号控制的效果评价

配时好不好，最终看**延误（delay）**——车辆在交叉口排队等待的时间。延误小，说明车流被高效放行；延误大，说明配时偏离最优。实测延误常用「停车线前后通过时间差」测量，理论延误可由排队论估算。**评价不仅看平均延误，还看排队长度（是否回溢到上游交叉口）与停车次数**——回溢会引发「绿灯看得到、车流进不去」的连锁拥堵。<span class="marginnote">「排队回溢」是交叉口之间的耦合效应：一个路口处理不过来，排队会蔓延到上一个路口，把上一个路口的出口堵死。这让单点优化失灵，逼出了区域协调控制——复杂系统里「局部最优≠全局最优」的又一例证。</span>

## 6 一个信号配时的完整算例

用一个小算例把 Webster 方法串起来。设某两相位交叉口，东西向关键流量比 $y_1 = 0.35$，南北向 $y_2 = 0.30$，每相位启动损失 3 s，全红共 2 s，总损失时间 $L = 2 \times 3 + 2 = 8$ s。

- **第一步，验算饱和度**：$\sum y_i = 0.35 + 0.30 = 0.65 < 1$，交叉口可稳定服务，Webster 公式可用。
- **第二步，算最佳周期**：$C_{\text{opt}} = (1.5 \times 8 + 5)/(1 - 0.65) = (12+5)/0.35 \approx 48.6$ s，取整为 50 s。<span class="marginnote">注意周期不能无限小——规范通常要求周期 ≥ 某下限（如 40–60 s），否则行人过街时间与黄灯会被挤掉；周期也不能超过 120–180 s，否则红灯过长、排队回溢。Webster 给的是「延误最优」，工程上还要叠加上下限约束。</span>
- **第三步，分配绿灯时间**：有效绿灯总量 $G_e = C - L = 50 - 8 = 42$ s。按流量比比例分配：$g_1 = 42 \times 0.35/0.65 \approx 22.6$ s，$g_2 = 42 \times 0.30/0.65 \approx 19.4$ s。
- **第四步，换算成显示绿灯**：各相位有效绿灯 + 黄灯 - 启动损失 = 显示绿灯时间，据此设定信号机参数。

完成配时后还要**复核**：计算各相位的排队长度是否回溢、行人过街绿灯时间是否够、与相邻交叉口的相位差是否协调。**一次配时不是终点**——随着流量变化，配时需要定期重算（感应/自适应控制则自动完成这件事）。这个算例浓缩了单点信号控制的全部基本动作：算损失、算周期、分绿信比、复核约束。

信号控制的技术前沿，正沿着「感知—决策—执行」三条线同时进化：

- **感知端：全息路口**。在路口部署视频、雷达、激光等多类传感器，实时识别每一辆车的类型、位置、速度、转向意图——信号控制从「靠线圈数流量」升级为「看清每一个交通参与者」。多传感器融合（见《智能交通系统》）让路口的「感知分辨率」达到逐车级别。
- **决策端：自适应与强化学习配时**。传统自适应控制基于实时流量在线重算配时参数；近年强化学习（见第四级《强化学习》）被用于让信号智能体在「与环境的试错交互」中学习最优配时策略——它不再依赖精确建模，而是从历史与实时数据中自己「学会」如何配时。<span class="marginnote">强化学习配时的魅力在于「无需显式建模」：信号智能体把「车流到达」当作环境状态，把「绿灯时间调整」当作动作，把「减少延误」当作奖励，在与真实/仿真交通的反复交互中逼近最优策略。这是《强化学习》在交通领域最耀眼的落地场景之一，也是「AI for City」的代表性应用。</span>
- **执行端：车路协同信号**。通过 V2I 通信（见《智能交通系统》），信号灯向车辆推送「绿灯倒计时」「建议车速」，车辆也把「排队长度、转向意图」回传给信号机——信号控制从「路侧独立决策」变成「路车联合优化」，为未来自动驾驶与信号系统的深度协同铺路。

**辨析｜易错点：** 前沿技术不等于「立刻能上线」：强化学习配时需要大量高质量训练数据与仿真环境（见《交通仿真》），且对安全约束的处理仍需保守兜底——**任何先进配时算法，都必须满足「信号灯的红灯相位绝不可因算法失误而缺失」的安全底线**。工程上常采用「先进算法优化 + 保守逻辑兜底」的双层架构，让创新在安全边界内奔跑。

把信号控制的核心概念与公式做成速查表：

| 概念 | 定义 | 公式/取值 |
| --- | --- | --- |
| 周期 $C$ | 信号循环一遍的时间 | 60–180 s |
| 相位 | 同时获得绿灯的相容车流组 | 两相到多相 |
| 绿信比 $\lambda$ | 有效绿灯/周期 | $\lambda = g/C$ |
| 损失时间 $L$ | 换相不产生通过量的时间 | 启动损失+全红 |
| 流量比 $y$ | 到达流量/饱和流率 | $y = q/s$ |
| 最佳周期 | 延误最小的周期 | $C = (1.5L+5)/(1-\sum y)$ |
| 黄灯时长 | 决策窗口 | $Y = t_r + v/(2a) + (w+l)/v$ |

- **一条主线**：配时 = 算损失 → 算周期 → 分绿信比 → 复核约束（行人、排队、协调）。
- **最易错点**：$\sum y_i$ 必须小于 1，否则交叉口过饱和、任何配时都失效；黄灯是决策窗口不是宽容时间。

信号控制是交通工程里最「日常」也最「精妙」的技艺：日常到每个路口都有，精妙到用几秒的绿灯时间调度成千上万人的出行节奏。从 Webster 公式到强化学习配时，技术一直在变，但本质不变——**在有限的时间资源里，为每一股冲突的车流找到最公平而高效的次序**。读懂信号，就读懂了交通管理的「时间哲学」。

- **一句话记忆**：周期定长短、绿信比分时间、黄灯给决策、协调成绿波、感应应变化。
- **最该记住的数字**：$C_{\text{opt}} = (1.5L+5)/(1-\sum y_i)$；$Y = t_r + v/(2a) + (w+l)/v$。
- **与课程的联系**：Webster 公式是《排队论》的最优化、绿波带是《波动》的相位对齐、强化学习配时是《强化学习》的城市落地——信号控制是排队论与 AI 的共舞。
- **给学习者的建议**：动手算一个 Webster 配时算例（本篇第 6 节），再结合《交通仿真》在软件里验证——「算过一遍 + 仿过一遍」胜过读十遍教材。
- **进阶提示**：当交叉口过饱和（$\sum y_i \ge 1$）时，配时已失效，要转向溢出控制与路网协调——那是《区域信号控制》的战场。

## 7 小结

- 信号三要素：**周期 $C$、相位、绿信比 $\lambda = g/C$**；损失时间 $L$ 是换相成本。
- **Webster 最佳周期** $C_{\text{opt}} = (1.5L + 5)/(1 - \sum y_i)$，流量比 $y_i = q_i/s_i$。
- **黄灯时长由运动学计算**：$Y = t_r + v/(2a) + (w+l)/v$，是决策窗口而非宽容时间。
- 协调控制（**绿波带**）靠相位差对齐，感应与自适应控制靠检测器实时响应。
- 评价看**延误、排队回溢与停车次数**，单点最优不等于全局最优。
