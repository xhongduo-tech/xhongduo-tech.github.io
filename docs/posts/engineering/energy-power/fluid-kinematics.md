## 为什么先描述、后解释

上一节的静止流体没有速度场，问题退化成「压强沿深度怎么变」。一旦流体运动起来，出现的第一个问题是：**怎么描述一个「流场」？** 无数流体微团各有速度，速度又随空间与时间变化——描述本身就是一门学问。**流体运动学（fluid kinematics）**只回答「运动长什么样」，不追问「为什么这样动」（那是下一节动力学的事）。这个分工像解剖学与生理学：先看清结构，再研究机理。<span class="marginnote">流体的描述比刚体难得多：刚体一个速度向量就够，流体需要「每个空间点、每个时刻都定义一个速度」——这是一个<strong>向量场</strong>。学习流体运动学的实质，就是学习「向量场的语言」：流线、迹线、流管、以及速度场的散度与旋度。你在第二级《高等数学》里学过的梯度、散度、旋度，在这里第一次有了流动的物理意义。</span>这一节掌握两种描述方法、三大场线工具，以及「运动的分解」——平动、转动与变形。

## 1 拉格朗日法与欧拉法

描述流体运动有两种方法，是流体力学思维方式的岔路口：

- **拉格朗日法（Lagrangian）**：跟踪每一个流体微团，记录它随时间的轨迹——像给每个运动员别上号码牌跟拍。对流体来说这要跟踪无穷多个微团，方程浩繁。
- **欧拉法（Eulerian）**：不追踪微团，而是站在固定空间点，记录「这个点、这个时刻」流体的速度、压力——像在赛道上安装摄像头，只记录经过该点的选手。

<span class="marginnote">欧拉法为什么统治流体力学？因为工程关心的是「某个位置的状态」——锅炉出口蒸汽的温度、管道某截面流速，而不是「某个水分子去哪了」。欧拉法把注意力从「物质的传记」换成「空间的场」，物理量变成 $p(x,y,z,t)$、$\vec{v}(x,y,z,t)$，与连续介质假设天然契合。</span>

两种方法通过**物质导数（material derivative）**联系：用欧拉场的视角跟踪一个微团，其速度随时间的变化率是：

$$\frac{D\vec{v}}{Dt} = \frac{\partial \vec{v}}{\partial t} + (\vec{v}\cdot\nabla)\vec{v}$$

**重点：物质导数 = 当地导数 + 对流导数。** $\partial \vec{v}/\partial t$ 是「空间点处速度随时间的变化」（当地变化），$(\vec{v}\cdot\nabla)\vec{v}$ 是「微团流到速度不同的地方引起的加速度」（对流变化）。一个粒子在收缩管道里加速，即使流场是定常的（$\partial/\partial t = 0$），它依然有加速度——因为空间梯度。这个分解是流体力学里最容易绕晕、也最核心的一步。

## 2 定常与非定常流动

按流场是否随时间变化分：

- **定常流动（steady flow）**：$\partial/\partial t = 0$，空间各点的速度、压力不随时间变。工程上大量稳定工况（稳定运行的电厂、恒定转速的风机）近似定常。
- **非定常流动（unsteady flow）**：$\partial/\partial t \ne 0$，如汽轮机启动、阀门开关瞬间、水击。

<span class="marginnote">注意定常不等于「微团没有加速度」——定常流场里，微团沿流线加速仍然可能（收敛管道），只是「每个空间点的状态不随时间变」。这是初学者最易混淆的点：<strong>定常是「场的定常」，不是「微团的定常」</strong>。把两个「定常」分清，物质导数的两个项自然就分清了。</span>

## 3 流线、迹线与流管

三个「线」是描述流场的几何工具：

- **迹线（pathline）**：单个流体微团运动的轨迹——拉格朗日视角的产物。烟囱里一缕烟的路径就是迹线。
- **流线（streamline）**：某一瞬间，流场中速度向量与它相切的一系列曲线——欧拉视角的快照。流线上任意一点切线方向就是该点速度方向。
- **流管（streamtube）**：由一束流线围成的管状曲面。流管像「虚拟管道」，流体只能沿流管进出，不能横穿管壁。

<span class="marginnote">定常流动时迹线与流线重合；非定常时二者分离。所以定常流动的图景（风洞实验、稳定水流的染色线）既是迹线也是流线，看一张图就能掌握流场。流管则把「一束流」独立出来分析——连续性方程就要在流管上做积分。</span>

**辨析｜易错点：** 流线在任一瞬时**互不相交**（一个点只有一个速度方向）；迹线可以相交（一个微团不会自己撞自己，但不同时刻的轨迹可能交叉）。流线是「瞬时全场快照」，迹线是「单点全程记录」——时间维度完全不同。

## 4 速度场的散度与旋度：变形与旋转

流场里一个微团在运动中会**变形**，运动学把它分解为四种基本形态：

- **平移**：整体移动，不改变形状。
- **线变形**：沿坐标轴拉伸或压缩——对应散度。
- **旋转**：整体转动——对应旋度（涡量）。
- **角变形**：形状畸变而不旋转——对应剪切变形率。

**散度（divergence）** $\nabla\cdot\vec{v} = \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial w}{\partial z}$ 度量微团的体积膨胀率。**不可压缩流体**的散度为零：$\nabla\cdot\vec{v} = 0$——这是不可压缩条件的微分形式，下一节《连续性方程》会从质量守恒严格推出它。

**旋度（curl）** $\nabla\times\vec{v}$ 度量微团的旋转。涡量 $\vec{\omega} = \nabla\times\vec{v}$ 是旋转速度的二倍。<span class="marginnote">「有旋」与「无旋」是流动分类的又一维度：无旋流（$\nabla\times\vec{v} = 0$）里微团只变形不旋转，可以定义<strong>速度势函数</strong> $\varphi$，使 $\vec{v} = \nabla\varphi$——场论里「无旋场是某标量场的梯度」在此兑现。无旋流动大幅简化方程，是势流理论的基础；有旋流动（尾涡、边界层内）则复杂得多。</span>

**重点：散度管「胀缩」，旋度管「转动」**。一个流场完全由它的散度、旋度与边界条件刻画——这正是流体运动学「分解」的终点，也是《连续性方程与N-S方程》里方程组的几何骨架。

## 5 公式解析：物质导数 $\frac{D\vec{v}}{Dt} = \frac{\partial\vec{v}}{\partial t} + (\vec{v}\cdot\nabla)\vec{v}$

- **第一步，从一维说起**：一维收敛管道里速度 $u(x)$，微团以 $u$ 运动，其加速度 $a = \frac{du}{dt} = \frac{du}{dx}\frac{dx}{dt} = u\frac{du}{dx}$——这就是 $(\vec{v}\cdot\nabla)\vec{v}$ 在一维的化身。
- **第二步，推广到三维**：$\vec{v} = (u,v,w)$，$(\vec{v}\cdot\nabla)\vec{v} = \left(u\frac{\partial}{\partial x}+v\frac{\partial}{\partial y}+w\frac{\partial}{\partial z}\right)\vec{v}$——三个方向的空间对流贡献叠加。若流场还随时间变，加上当地项 $\partial\vec{v}/\partial t$。
- **第三步，读它的物理**：物质导数回答「跟随着一个微团，它的物理量怎么变」。它是拉格朗日视角在欧拉场里的翻译，也是 N-S 方程里惯性项的标准写法——下一节你会在动量方程里和它再次相遇。

**辨析｜易错点：** $(\vec{v}\cdot\nabla)\vec{v}$ 是**非线性项**——速度乘速度的梯度。正是这项让 N-S 方程成为非线性偏微分方程，让湍流难题百年未解。看到 $u\frac{\partial u}{\partial x}$ 这种「自己乘自己的空间导数」，要立刻意识到非线性、意识到难度的来源。

### 用流线图读流动的工程细节

流线图是流场的「X 光片」，工程师读流线图有一套固定套路：

| 流线特征 | 含义 | 工程结论 |
| --- | --- | --- |
| 流线密集 | 流速大 | 高压区可能低（伯努利） |
| 流线稀疏 | 流速小 | 低压区可能高 |
| 流线弯曲 | 有向心加速度 | 有压力梯度维持转弯 |
| 流线分离 | 边界层分离 | 压差阻力、失速 |
| 流线包围的涡 | 有旋流动 | 能量耗散区 |

**重点：读流线图的第一反应是「哪里密、哪里稀、哪里弯、哪里断」**——密度反映速度、弯曲反映压力、断裂（分离）反映损失。机翼设计、风洞显示、CFD 后处理，全都在读这些几何信息。

### 定常流与非定常流的工程判断

判断一个流动「能不能按定常处理」，是建模的第一步：

- **可以按定常**：稳定运行的电厂管道、恒定转速的风机出口、长距离输油管线——状态不随时间变，方程大幅简化。
- **必须按非定常**：阀门开关瞬间（水击）、汽轮机启动过程、泵的启停、蓄水/放水过程——时间项不能丢。

**辨析｜易错点：** 定常假设的代价是「丢掉时间演化」。水击（阀门突然关闭、压力波沿管传播）若按定常算，会漏掉压力骤升——水击压力可高达正常工作压力的数倍，是管道爆裂的常见原因。**「先问定常还是非定常，再选方程」**是流体计算的纪律，与《非稳态导热》里「先问稳态非稳态」完全同构。

### 流函数：无旋与不可压缩的统一工具

二维不可压缩流动除了速度势 $\varphi$，还有**流函数** $\psi$：

- $u = \frac{\partial\psi}{\partial y}$，$v = -\frac{\partial\psi}{\partial x}$。
- 流函数等值线 = 流线（$\psi = \text{const}$ 就是流线方程）。
- 不可压缩（$\nabla\cdot\vec{v} = 0$）自动满足——流函数天然保证连续性方程。

**重点：流函数让「画流线」变成「画等值线」**——给定 $\psi(x,y)$，流线就是它的等高线，一条函数曲线族描述整个流场。势函数 $\varphi$（无旋）与流函数 $\psi$（不可压缩）构成复变函数里的「解析函数」工具，是《复变函数与积分变换》与流体力学交汇的桥梁（保角变换解流动）。

### 涡量与环量的关系（斯托克斯定理）

旋度（涡量）与环量通过**斯托克斯定理**联系：

$$\Gamma = \oint \vec{v}\cdot d\vec{l} = \int_S (\nabla\times\vec{v})\cdot d\vec{S}$$

- 环量 $\Gamma$ = 涡量在面上的通量。
- 无旋流（涡量处处为零）→ 任意闭合回路的环量为零。
- 有旋区（涡量非零）→ 该区域环量不为零——机翼的升力环量、边界层内的涡，全在这条定理的框架下。

**辨析｜易错点：** 「无旋」不等于「不转」——流体微团不旋转，但流线可以弯曲（如势涡、自由涡）。判断有旋无旋要看**涡量（微团自转）**而不是流线形状。把「流线弯」当「有旋」，是运动学里最常见的概念错误。

## 6 小结

- 描述流动有**拉格朗日法**（跟踪微团）与**欧拉法**（固定空间点看场），欧拉法因工程需要而统治流体力学。
- **物质导数** = 当地导数 + 对流导数，是两种视角的翻译桥，也是 N-S 方程惯性项的写法。
- 定常流动的流场不随时间变，但微团仍可有加速度；定常是「场的定常」不是「微团的定常」。
- **流线**（瞬时全场相切）、**迹线**（微团轨迹）、**流管**（一束流线的虚拟管道）；定常时流线与迹线重合。
- 运动分解为**平移、线变形、旋转、角变形**；散度管体积胀缩、旋度管转动。
- 无旋流可定义速度势 $\varphi$，$\vec{v} = \nabla\varphi$——场论工具进入流体力学的入口。

在下一节，我们把运动学升级为动力学——**连续性方程与N-S方程**，从质量守恒与动量守恒推出流体力学的主方程。
