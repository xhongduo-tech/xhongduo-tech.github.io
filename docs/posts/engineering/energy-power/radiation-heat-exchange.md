## 为什么辐射要「成对」地看

上一节的普朗克定律说的是**单面发射**；但工程上真正的辐射问题永远是**两个以上的表面之间互相辐射**：炉膛里火焰照水冷壁、两片平行板互照、热电偶被管道壁面辐射干扰。每一对表面都在「你发射我吸收、我发射你吸收」，最终净换热量是双方你来我往的**差**。<span class="marginnote">辐射换热与导热/对流的本质区别：导热对流是「沿温度梯度的单行道」，辐射是「双向大道」——每个表面既发又收，净流量才是有效换热量。工程上计算辐射换热，第一步永远是把「净」字算对：谁发得多、谁收得多，差值才是真正传出去的热。</span>这一节建立辐射换热的计算体系：角系数、黑体表面间的辐射换热，再到灰体表面的辐射网络法。

## 1 角系数：几何决定「看得到多少」

两个表面之间辐射换热，关键变量是**角系数（view factor / configuration factor）**$X_{1,2}$：表面 1 发射的辐射能中，落到表面 2 上的份额。它是**纯几何参数**，只取决于两表面的形状、尺寸与相对位置，与温度、物性无关。<span class="marginnote">角系数的直觉就是「互相看得见多少」。两个面对面的大平行板，互相「看」得很清楚，$X$ 接近 1；两块相互垂直的窄长条，只看到对方一部分，$X$ 小。计算角系数有代数法（利用相对性、完整性、可加性三条性质）与积分法（对两表面面积元求双重积分），工程上常查图册。</span>

角系数满足三条性质，是求解的钥匙：

- **相对性（互换性）**：$A_1 X_{1,2} = A_2 X_{2,1}$——我发到你面上的能量 = 你发到我面上的能量（按面积加权）。
- **完整性**：对封闭腔，$\sum_j X_{i,j} = 1$——表面 $i$ 发出的辐射总能落到封闭腔某个表面上。
- **可加性**：$X_{1,(2+3)} = X_{1,2} + X_{1,3}$。

**重点：角系数是「纯几何」，靠三条性质就能代数求解。** 很多工程问题不查图、直接列相对性 + 完整性方程组就能解出全部角系数。这是辐射换热里最「优雅」也最常用的技巧。

## 2 黑体表面的辐射换热

对两个黑体表面，辐射换热最简单：发出即吸收（黑体吸收比 = 1），净换热量：

$$\Phi_{1,2} = A_1 X_{1,2}\sigma(T_1^4 - T_2^4)$$

其中 $T_1$、$T_2$ 是两表面热力学温度。<span class="marginnote">注意是 $T^4$ 之差、不是 $(T_1 - T_2)^4$，更不能像对流那样用线性温差。两个表面温度 1000 K 与 900 K，$T_1^4 - T_2^4 = 10^{12} - 6.56\times10^{11}$，净辐射远大于按线性温差猜测的量。温度越高，$T^4$ 差越被高温方主导。</span>

两个无限大平行黑体平板之间，$A_1 X_{1,2} = A_1$（$X_{1,2} = 1$），净辐射 $\Phi = A_1\sigma(T_1^4 - T_2^4)$——这个简例是很多多层保温、航天器热控计算的起点。

**辨析｜易错点：** $T^4$ 差是「绝对温度的差」，不是温度差的四次方。把 $(T_1 - T_2)^4$ 当 $T_1^4 - T_2^4$，是辐射计算最常见、最致命的错误。

## 3 灰体表面的辐射换热网络法

实际表面不是黑体，有反射与吸收损失，辐射能在表面间要「折返多次」——直接积分繁琐。工程上把表面理想化为**灰体**（发射率与吸收比与波长无关、且 $\alpha = \varepsilon$），用**辐射网络法（radiation network method）**求解：把每个表面画成「表面辐射热阻」+「空间辐射热阻」串并联的电路。

- **表面热阻** $\frac{1-\varepsilon_i}{\varepsilon_i A_i}$：代表表面「非黑体」造成的阻碍，黑体（$\varepsilon=1$）此项为零。
- **空间热阻** $\frac{1}{A_i X_{i,j}}$：代表两表面间的几何阻碍，由角系数决定。

两灰体表面（无其它表面）净换热：

$$\Phi_{1,2} = \frac{\sigma(T_1^4 - T_2^4)}{\frac{1-\varepsilon_1}{\varepsilon_1 A_1} + \frac{1}{A_1 X_{1,2}} + \frac{1-\varepsilon_2}{\varepsilon_2 A_2}}$$

<span class="marginnote">网络法的意义在于：它把辐射问题变成了「画电路、串并联、解方程」的例行公事。三个表面就是三个节点，用基尔霍夫节点电流法列方程，多表面封闭腔的辐射换热全部可解。凡是学过电路的人都能快速上手——这是传热学里「电学类比」最成功的一处，与导热里的热阻网络一脉相承。</span>

**重点：发射率低 + 角系数小 = 双重削弱辐射。** 从公式看，降低任一表面发射率（镀银、抛光）或减小角系数（加遮热板、隔挡）都能减少净辐射。**遮热板（radiation shield）**正是这个原理：在两板间插入一块薄板，表面热阻翻倍，净辐射减半——多层遮热板是航天器、液氢储罐保温的利器。

## 4 公式解析：两灰体表面辐射换热公式

**第一步，看清三个热阻串联**：分子是「辐射势差」$\sigma(T_1^4 - T_2^4)$，分母三项分别是表面 1 的表面热阻、空间热阻、表面 2 的表面热阻——与电路里「两个电阻夹一个电阻」完全同构。
**第二步，代入极限验证**：$\varepsilon_1 = \varepsilon_2 = 1$（黑体）时表面热阻为零，公式退回黑体式 $\Phi = A_1 X_{1,2}\sigma(T_1^4 - T_2^4)$——极限自洽，说明公式没错。
**第三步，读工程杠杆**：辐射换热的三根杠杆是温度差（$T^4$ 差）、角系数（几何）、发射率（表面处理）。想减小辐射——降低表面发射率最有效（镀层可把 $\varepsilon$ 从 0.9 压到 0.05，削弱近 20 倍）；想增强辐射——提高发射率并让表面「互相看得见」。

**辨析｜易错点：** 灰体假设要求 $\alpha = \varepsilon$ 且与波长无关。处理太阳辐射这类短波问题时，表面在短波与长波的特性差异巨大，灰体假设失效——必须用「选择性表面」的双波段模型（上一节已埋下伏笔）。

## 5 辐射换热的工程舞台

辐射换热在动力与能源工程里无处不在：

**锅炉炉膛**：高温火焰与烟气对水冷壁的辐射换热是主要传热方式，炉膛布置水冷壁就是为了「张开大网」承接辐射。
**太阳能集热**：集热器表面吸收太阳短波辐射，用选择性涂层抑制自身长波辐射损失。
**航天器热控**：多层遮热板（MLI）让辐射净换热减到极小，维持舱内温度。
**红外测温与热像仪**：通过测量物体辐射反推温度，广泛用于设备巡检、建筑能耗诊断。<span class="marginnote">红外热像仪测到的不是温度而是辐射能，必须知道被测面发射率才能换算温度。金属表面发射率低、反射环境辐射强，直接测温误差巨大——所以工业热像仪要贴高发射率胶带或黑漆做「参考点」，这是辐射工程里一个非常实战的细节。</span>

### 算例：遮热板的效果

两块无限大平行平板，表面温度 $T_1 = 500$ K 与 $T_2 = 300$ K，发射率均为 0.8，间距远小于尺寸（$X_{1,2} = 1$）。直接辐射换热：

$$\Phi_{1,2} = \frac{\sigma(T_1^4 - T_2^4)}{\frac{1-\varepsilon_1}{\varepsilon_1} + 1 + \frac{1-\varepsilon_2}{\varepsilon_2}} = \frac{5.67\times10^{-8}(62500-8100)}{0.25+1+0.25} \approx 1540\ \text{W/m}^2$$

在中间插入一块同样发射率的薄遮热板后，总热阻翻倍（两块板的表面热阻 + 两段空间热阻），净辐射约减半——**一块遮热板把辐射换热降到约一半**。

- **第一步，看表面热阻公式**：$\frac{1-\varepsilon}{\varepsilon A}$ 是表面「非黑体」的阻碍，$\varepsilon = 0.8$ 时每侧约 0.25。
- **第二步，看遮热板的原理**：插板不吸热也不散热（稳态下它达到中间温度），只是让辐射「先到板上、再到目标板」，多绕了两道表面热阻——热阻翻倍，热流减半。
- **第三步，看多层叠加**：N 块遮热板把辐射降到 $1/(N+1)$——航天器多层绝热（MLI，几十层）就是靠这个原理把辐射热流压到极小。

### 角系数三条性质的代数应用

用角系数性质「不用积分、只靠代数」解出复杂几何的角系数。例：两个垂直共边的矩形面 1 与面 2，由相对性 $A_1X_{1,2} = A_2X_{2,1}$；若把面 2 与相邻面 3 合起来构成封闭腔，由完整性 $X_{1,(2+3)} = X_{1,2} + X_{1,3} = 1$，查图或代数得 $X_{1,2}$。

**重点：角系数是纯几何参数，靠「相对性 + 完整性 + 可加性」三条性质就能代数求解**——不必每次做双重积分。工程上把封闭腔画成角系数网络（或查角系数图册），复杂的多面辐射问题就变成解方程组。这是《相似理论》里「用无量纲数压缩参数」思想在辐射换热里的体现。

### 封闭腔的辐射网络法应用

封闭腔（所有辐射都被腔内表面接住）是辐射换热的典型问题。三表面封闭腔：

- 每个表面画一个**节点**（辐射势 $\sigma T^4$）。
- 表面热阻 $\frac{1-\varepsilon}{\varepsilon A}$ 连接「表面节点」与「空间节点」。
- 空间热阻 $\frac{1}{AX}$ 连接两「空间节点」。
- 用节点电流法（基尔霍夫）列方程解各节点辐射势，再算净换热量。

**重点：网络法把「多面辐射」变成「电路问题」**——三表面、四表面乃至更多表面，只要画得出网络、列得出节点方程，就能解。它与《稳态导热》的热阻网络是同一套「电学类比」思想，只是把「导热热阻」换成了「辐射热阻」。

### 辐射换热的常见工程简化

| 情形 | 简化处理 |
| --- | --- |
| 大表面包围小表面 | 角系数 ≈ 1，小表面辐射被大表面全吸收 |
| 两无限大平行板 | $X = 1$，退化成最简单式 |
| 灰体 + 波长无关 | 用发射率折扣 |
| 温度差异巨大 | 必须用 $T^4$ 差，不可线性近似 |

**辨析｜易错点：** 「大表面包围小表面」的简化里，大表面（如房间墙壁）的辐射被小表面吸收的比例是 $\varepsilon_{small}$（发射率折扣），不能把大表面当黑体。辐射换热计算里「先确认几何关系（角系数）、再选简化」是防止算错的顺序。

## 6 小结

- 辐射换热是**双向**的，净换热量才是有效量；角系数 $X_{1,2}$ 度量「看得到多少」，纯几何参数。
- 角系数三性质：**相对性** $A_1X_{1,2}=A_2X_{2,1}$、**完整性** $\sum X_{i,j}=1$、**可加性**。
- 黑体表面净辐射 $\Phi = A_1X_{1,2}\sigma(T_1^4 - T_2^4)$；温度必须用开尔文、不可写成温差四次方。
- 灰体表面用**辐射网络法**：表面热阻 $\frac{1-\varepsilon}{\varepsilon A}$ 与空间热阻 $\frac{1}{AX}$ 串并联。
- 辐射三杠杆：温度差、角系数、发射率；**遮热板**让辐射减半，多层遮热板是航天保温利器。
- 炉膛辐射、太阳能集热、航天热控、红外测温都是辐射换热的工程舞台。
