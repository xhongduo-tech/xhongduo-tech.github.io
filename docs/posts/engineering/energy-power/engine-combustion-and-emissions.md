## 为什么燃烧决定一切

上一节的内燃机还停留在「循环 + 示功图」，这一节钻进气缸内部看**燃烧**——它决定了内燃机的功率、效率、噪声与污染物，是内燃机技术的核心战场。燃烧得好，热效率高、排放干净；燃烧得不好，爆震敲缸、碳烟滚滚。而排放问题早已不是「尾部小事」，它催生了三元催化、柴油颗粒捕集、EGR 等一系列系统技术。<span class="marginnote">燃烧化学是内燃机的底层：汽油是多种烃的混合物，燃烧就是碳氢化合物与氧的氧化反应 $\ce{CxHy + O2 -> CO2 + H2O}$（理想时），而实际永远伴随不完全燃烧产物。你在第一级《化学》里学过的燃烧反应，在这里变成了「反应速率、火焰传播、污染物生成」的工程问题——温度、当量比、停留时间三要素决定了产物的成分。</span>这一节讲汽油机与柴油机的燃烧过程、污染物的生成机理，以及尾气治理的三件套。

## 1 汽油机的正常燃烧与爆震

汽油机正常燃烧是**火焰传播**式：火花塞点火后形成火焰核心，火焰前锋以约 20–50 m/s 的速度在混合气中传播，直到烧完整个燃烧室。燃烧室内的压力平稳上升，做功平滑。

**爆震（knock）**是正常燃烧的破坏：火焰前锋还没到，末端混合气被压缩与辐射加热到自燃温度，**自行爆炸式燃烧**，压力骤升、产生高频冲击波敲击缸壁——声音如金属敲击，故名「敲缸」。<span class="marginnote">爆震的本质是「末端混合气的提前自燃」。它取决于燃料的抗爆性——<strong>辛烷值</strong>：异辛烷辛烷值 100（抗爆好），正庚烷辛烷值 0（易爆）。97 号汽油的「97」就是异辛烷体积分数，抗爆性以此为标尺。提高辛烷值的手段：加抗爆剂（曾经用四乙基铅，因毒性被禁，改用 MTBE、乙醇等）、改进炼油工艺。</span>

**抑制爆震的手段**：提高辛烷值、降低压缩比（牺牲效率）、推迟点火、加浓混合气、缸内直喷（燃油蒸发吸热降低缸温）。爆震与效率的博弈——「想提压缩比就撞上爆震」——是汽油机设计最核心的矛盾。

**重点：爆震是「末端混合气自燃」，不是火花塞的问题。** 火花塞只管点火时刻，爆震发生在远离火花塞的末端。推迟点火能抑制爆震，代价是效率略降——现代 ECU（发动机电控单元）用爆震传感器实时侦测，把点火时刻调到「刚好不爆震」的极限附近，榨取最高效率。

## 2 柴油机的燃烧过程与喷油策略

柴油机靠压燃，燃烧过程分四个阶段：

1. **滞燃期**：喷油后燃油雾化、蒸发、与空气混合，化学反应尚未开始。
2. **急燃期**：滞燃期内积累的可燃混合气同时自燃，压力骤升——这是噪声与振动的来源，也是 NOₓ 生成的高峰。
3. **缓燃期**：随喷随燃，扩散燃烧主导，火焰在空气充足区域传播。
4. **后燃期**：残余燃油继续缓慢氧化。

<span class="marginnote">柴油机的燃烧是「先集中后扩散」：滞燃期积攒的可燃混合气一旦点燃，爆燃式地烧掉，然后靠喷油嘴持续的喷雾维持扩散燃烧。这种燃烧形态决定了柴油机的两大特征：<strong>压力升高率大 → 噪声大；局部缺氧 → 碳烟生成</strong>。现代柴油机的共轨高压喷射（把喷油分成预喷、主喷、后喷多段）就是为了驯服它——预喷先点一小把火升温，主喷再平稳燃烧，后喷烧掉碳烟。</span>

**重点：柴油机排放的两难——NOₓ 与碳烟的此消彼长。** 温度高、氧气多则 NOₓ 生成多；温度低、局部缺氧则碳烟生成多。两种污染物要不同的工况，难以同时压低——这就是「NOₓ–碳烟 trade-off」曲线，也是柴油机排放控制最核心的难题。

## 3 排放物及其生成机理

内燃机的有害排放物主要有五类：

- **CO（一氧化碳）**：局部缺氧、燃烧不完全的产物。混合气越浓越多。
- **HC（碳氢化合物）**：未燃烧的燃油，来自淬熄（火焰碰到冷壁熄灭）与缝隙容积。
- **NOₓ（氮氧化物）**：高温（>1800 K）富氧下氮气被氧化，生成 NO 与 NO₂。
- **颗粒物（PM）**：柴油机碳烟，碳核+可溶有机物，有致癌性。
- **CO₂**：温室气体，燃烧的直接产物——无法用后处理去掉，只能靠提效减排。

<span class="marginnote">生成机理的三要素是<strong>温度、氧气浓度、停留时间</strong>：NOₓ 是「高温 + 富氧 + 长时间」的产物，碳烟是「高温 + 缺氧」的产物，CO/HC 是「低温或局部缺氧」的产物。理解了这三要素，就理解了所有排放控制技术为什么那样设计——把缸内温度、空燃比、混合质量往「低排放窗口」里压。</span>

**排放法规**（国六、欧七）是推动内燃机技术的最大外部力量——每一次法规升级都逼出一代新技术。

## 4 公式解析：三元催化的核心反应

汽油机尾气治理的**三元催化转化器（three-way catalytic converter）**同时处理三种污染物，其「三元」指同时转化 CO、HC、NOₓ：

$$\ce{2CO + O2 -> 2CO2}, \quad \ce{HC + O2 -> CO2 + H2O}, \quad \ce{NO + CO -> N2 + CO2}$$

- **第一步，看三组反应的分工**：前两个是氧化反应（CO 与 HC 被氧化掉），第三个是还原反应（NO 被还原成 N₂）。氧化与还原同时在一个催化剂上发生，这是「三元」的关键。
- **第二步，看工作窗口**：三元催化要求空燃比严格处于**化学计量比（λ = 1）**附近——氧传感器（λ 传感器）反馈控制喷油量，让混合气浓度精确维持在「刚好能把三种污染物都转化」的窗口内。窗口极窄（±0.005），氧传感器闭环控制就是为此而生。
- **第三步，看出它的代价**：三元催化只对汽油机有效（要求 λ ≈ 1）；柴油机富氧燃烧排出的 NOₓ 无法被还原，必须用**SCR（选择性催化还原）**——喷尿素把 NOₓ 还原成 N₂。两条治理路线分属汽油机与柴油机，机理不同。

**辨析｜易错点：** 三元催化需要**贵金属（铂、钯、铑）**做活性组分，且「怕中毒」——铅、硫、机油中的磷都会使催化剂失活。含铅汽油会让三元催化立即报废，这就是「无铅汽油」强制推行的直接原因。

## 5 排放治理的完整系统

现代内燃机的排放控制是「机内净化 + 机外后处理」的组合拳：

- **机内净化**（从源头减少生成）：EGR（废气再循环，把废气引回气缸降温抑 NOₓ）、缸内直喷、高喷射压力、可变气门、稀薄燃烧、增压中冷。
- **机外后处理**（把生成物转化掉）：三元催化（汽油机）、氧化催化 DOC（氧化 CO/HC）、柴油颗粒捕集 DPF（过滤碳烟）、SCR（尿素还原 NOₓ）。

<span class="marginnote">柴油机的后处理链条很长：DOC 先把 CO/HC 氧化、把 NO 氧化成 NO₂，DPF 捕集颗粒并周期性再生烧掉，SCR 再喷尿素还原 NOₓ——一条「先氧化、再过滤、最后还原」的流水线。这也是国六柴油机比国四复杂一大截的原因：法规把 NOₓ 与颗粒限值双双压紧，机内净化已到极限，只能靠后处理堆料。</span>

**重点：机内净化是「堵源头」，后处理是「治末端」，两者缺一不可。** EGR 降 NOₓ 会让碳烟增多，于是配 DPF；SCR 需要还原剂（尿素），于是车要加尿素。整套系统的设计哲学是「用一道道的权衡与补偿，把污染物同时压到法规限值以下」。

### 内燃机排放法规的演进

排放法规是内燃机技术的「指挥棒」，中国标准的演进一目了然：

| 阶段 | 限值重点 | 催生的技术 |
| --- | --- | --- |
| 国二/国三 | CO、HC 基础限值 | 电喷、三元催化普及 |
| 国四/国五 | NOₓ 收紧 | EGR、SCR 上车 |
| 国六 | NOₓ 与颗粒物双紧 | DPF 强制、高压共轨 |
| 欧七（未来） | 全工况低排放 | 混合动力、电气化 |

**重点：每一轮法规升级都「逼」出一代技术**——法规不是单纯「限制」，而是技术路线的推动器。看懂法规时间线，就理解了「为什么现代柴油机加尿素、为什么涡轮增压普及、为什么混动当道」。

### 爆震与辛烷值的定量关系

爆震的抑制与辛烷值直接挂钩：提高压缩比能提效，但压缩比超过燃料辛烷值对应的极限就爆震。换算关系（经验）：

$$\varepsilon_{max} \approx \frac{1}{3}\sqrt{RON - 40}$$

- 92 号汽油（RON 92）：$\varepsilon_{max} \approx \frac{1}{3}\sqrt{52} \approx 2.4$——不对，这是简化经验式的示意，实际要乘系数。真正的经验是：**辛烷值每升 10 个单位，允许的压缩比约提高 1 个单位**。
- 高标号汽油（RON 97）允许更高压缩比 → 更高效率；但高标号更贵，加错标号（低标号车加高标号油）不省油不省功。

**辨析｜易错点：** 辛烷值只代表「抗爆性」，不代表「能量含量」——97 号汽油的热值并不比 92 号高。给低压缩比的车加高标号油，既不提动力也不省油，只是多花钱。**「标号越高越有劲」是误区，标号只决定「你允许把压缩比做多高」**。

### 汽油机与柴油机的排放治理路线对比

| 污染物 | 汽油机（λ≈1） | 柴油机（富氧） |
| --- | --- | --- |
| CO | 三元催化 | DOC 氧化 |
| HC | 三元催化 | DOC 氧化 |
| NOₓ | 三元催化还原 | EGR + SCR |
| 颗粒物 | 少量（直喷车加 GPF） | DPF 捕集 |

**重点：两种发动机的排放治理「路线分明」**——汽油机靠「λ=1 的三元催化一锅端」，柴油机靠「EGR + DOC + DPF + SCR 四件套分头治理」。理解这条分界线，就理解了「为什么柴油车要加尿素、汽油车不用」。

### 燃烧诊断与缸压分析

现代发动机研发的「显微镜」是缸压分析：

- 从缸压曲线反推**放热率**——燃烧的快慢与位置。
- 监测**爆震强度**（缸压高频振荡）——ECU 据此实时调整点火时刻。
- 诊断**失火**（某缸不做功）——排放超标与动力下降的元凶。

**辨析｜易错点：** 缸压传感器测得是「压力随时间」，要换算成「放热率-曲轴转角」才能看燃烧——**传感器采样频率、上止点定位精度都直接影响诊断结论**。缸压分析是「测量 + 热力学反演」的组合，不是读个压力波形就行（这与《内燃机原理》示功图的处理一脉相承）。

## 6 小结

- 汽油机**火焰传播**燃烧，爆震是末端混合气自燃——辛烷值度量抗爆性，压缩比与爆震博弈。
- 柴油机**压燃**四阶段（滞燃/急燃/缓燃/后燃），共轨多段喷射驯服压力升高率与碳烟。
- 污染物五类：CO、HC、NOₓ、颗粒物、CO₂；生成机理由**温度、氧浓度、停留时间**三要素决定。
- **NOₓ–碳烟 trade-off** 是柴油机排放的核心两难，催生 EGR + DPF + SCR 的组合方案。
- **三元催化**在 λ = 1 窗口同时转化 CO/HC/NOₓ，靠氧传感器闭环控制；柴油机用 SCR 处理富氧下的 NOₓ。
- 排放法规是内燃机技术进步的最大推手；治理 = 机内净化堵源头 + 后处理治末端。
