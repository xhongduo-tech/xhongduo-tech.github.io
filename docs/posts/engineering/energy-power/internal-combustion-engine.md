## 为什么从内燃机讲起动力机械

动力机械与系统的家族里，内燃机是**最普及、也最贴近生活**的一员：汽车、摩托车、船舶、发电机组、工程机械，全球的动力半壁江山由它支撑。它也是前三篇理论的总装车间——热力学给出循环效率、传热学处理气缸散热、流体力学安排进排气流动。<span class="marginnote">《热力循环》一节里我们已经建立了奥托循环与狄塞尔循环的效率公式，这里把它们「装进钢铁」：看活塞如何把理论循环变成四冲程、压缩比如何被爆震限制、柴油机为什么更省油。内燃机是理解一切热机的绝佳入口——它最直观、最可触摸，又涵盖了热机设计的全部矛盾。</span>这一节讲四冲程工作原理、两种点火方式的差异、指示功与机械效率。

## 1 四冲程内燃机的工作原理

内燃机把燃料的化学能在**气缸内**燃烧释放，燃气膨胀直接推动活塞做功。四冲程汽油机一个循环经历四个行程（曲轴转两圈）：

1. **进气冲程**：活塞下行，进气门打开，新鲜混合气（空气+汽油）被吸入气缸。
2. **压缩冲程**：两门关闭，活塞上行压缩混合气，压力温度升高（为点火做准备）。
3. **做功冲程**：火花塞点火，混合气爆燃，高温高压燃气膨胀推动活塞下行做功——这是唯一对外做功的冲程。
4. **排气冲程**：活塞上行，排气门打开，废气被推出气缸。

<span class="marginnote">四冲程里只有做功冲程出功，其余三个冲程都要消耗功（靠飞轮惯性与其它缸的做功冲程维持）。所以多缸机（4缸、6缸、V8）的本质是「用相位错开的多个做功冲程抹平扭矩波动」——缸数越多，运转越平顺。这就是为什么三缸机抖、六缸机顺的机理。</span>

**重点：理论循环（奥托/狄塞尔）是「空气标准循环」，真实循环要打折扣。** 真实内燃机有进排气损失、燃烧不完全、传热损失、摩擦——指示效率（缸内做功）只有理论效率的七八成，机械效率（输出到曲轴的净功）再打七八折。理解内燃机，就是理解「理论效率 × 指示效率 × 机械效率」这根乘法链。

## 2 汽油机与柴油机的根本差异

两种内燃机看似都是「活塞+气缸」，机理却完全不同：

| 项目 | 汽油机 | 柴油机 |
| --- | --- | --- |
| 燃料 | 汽油（易挥发） | 柴油（难挥发） |
| 着火方式 | 火花塞点燃（点燃式） | 压缩自燃（压燃式） |
| 压缩比 | 8–11 | 16–22 |
| 混合气形成 | 缸外预混（均匀） | 缸内喷射（不均匀） |
| 负荷调节 | 节气门调进气量 | 直接调喷油量 |
| 热效率 | 较低（约 25%–35%） | 较高（约 35%–45%） |

<span class="marginnote">压缩比是两机差异的根源：柴油机没有爆震之忧，可以做到 20 左右的高压缩比，按奥托/狄塞尔效率公式 $\eta = 1 - 1/\varepsilon^{\gamma-1}$，压缩比翻倍效率显著提升——这就是「柴油机省油」的热力学根源。代价是柴油机转速低、笨重、噪声大，因为压燃的燃烧过程更「粗」。</span>

**重点：汽油机怕爆震、柴油机怕冒烟。** 爆震（敲缸）是末端混合气被火焰前锋压缩自燃产生的压力冲击波，会毁机，所以汽油机压缩比不敢做高；柴油机靠过量空气抑制烟粒，负荷大时容易碳烟超标。两种机器的全部设计权衡，都围绕各自「怕什么」展开。

## 3 指示功、指示功率与机械效率

内燃机的性能用**示功图**（气缸内压力随容积变化图，p–V 图）描述。p–V 图包围的面积就是**指示功** $W_i$——一个循环燃气对活塞做的功。由此定义：

$$P_i = \frac{W_i n}{60\tau} \qquad（指示功率）$$

$$\eta_m = \frac{P_e}{P_i} \qquad（机械效率）$$

其中 $\tau$ 是每循环冲程数（四冲程 $\tau=4$），$n$ 是转速，$P_e$ 是有效功率（输出到曲轴的净功）。<span class="marginnote">p–V 图是内燃机的「心电图」：面积越大做功越多，形状畸变（爆震锯齿、早燃台阶）就是故障信号。现代发动机开发里，测量 p–V 图（缸压示功）是燃烧诊断的核心手段——缸压数据经热力学分析可反推出燃烧放热率、缸内温度，一条缸压曲线浓缩了整个燃烧过程的信息。</span>

**平均有效压力（BMEP）**是衡量强化程度的指标：$p_{me} = \frac{W_e}{V_s}$（有效功 ÷ 排量），它不随排量变化，适合跨机型比较。自然吸气汽油机约 0.8–1.1 MPa，涡轮增压可到 1.6–2.0 MPa 以上。

**辨析｜易错点：** 指示功率 $P_i$ 是「缸内」功率，有效功率 $P_e$ 是「曲轴」功率，两者之差是摩擦与附件损耗。标称的「发动机功率」都是有效功率 $P_e$；机械效率 $\eta_m$ 典型 0.8–0.9。混淆指示与有效，会把油耗算错、把增压机的潜力估计错。

## 4 公式解析：指示功 $W_i = \oint p\,dV$

**第一步，看几何意义**：p–V 图上循环曲线包围的面积就是 $W_i = \oint p\,dV$——这与热力学里「功是曲线下方面积」一脉相承，只是这里是闭合回路。
**第二步，看量纲**：$\text{Pa}\times\text{m}^3 = \text{J}$。示功图测的是缸压随容积的变化，直接积分出每循环指示功。
**第三步，看与实际油耗的联系**：每循环喷入的燃油能量 $Q_{in}$，指示热效率 $\eta_i = W_i/Q_{in}$。测示功图 + 测油耗，就能算出燃烧放了多少热、有多少变成功——这是内燃机燃烧诊断的基本功。
**第四步，推到功率**：指示功率 $P_i = W_i\times(\text{每循环频率})$。转速越高、单位时间循环越多，功率越大——但转速过高时充气不足、摩擦剧增，功率曲线出现峰值，这就是「最大功率转速」的来历。

**重点：p–V 图面积是内燃机一切性能的总源头。** 提高升功率的手段——提高压缩比、增压、优化燃烧、减小摩擦——最终都要反映在「p–V 图面积更大、更饱满」上。

## 5 从奥托循环到真实发动机

把理论循环升级成真实循环，要补四笔「账」：

**工质差异**：真实工质是空气+燃料+残余废气，比热容随温度变化，$\gamma$ 不是常数。
**燃烧时间**：理论定容瞬时加热，实际燃烧要时间，相位滞后损失效率。
**传热损失**：缸壁带走热量，气体多变指数 $n < \gamma$。
**进排气损失**：泵气损失（进排气冲程消耗的功）、残余废气稀释。

<span class="marginnote">真实循环比理论循环效率低 10–20 个百分点，主要来自「燃烧要时间 + 缸壁要散热」两个不可逆项。现代技术（高压缩比、稀薄燃烧、可变气门、增压直喷）的目标，都是让真实循环<strong>更接近</strong>理论循环：燃烧更快、散热更少、泵气损失更小。理解了「接近理想」这条主线，内燃机的技术演进就串成了一条线。</span>

### 四冲程与二冲程的对比

内燃机除主流四冲程外，还有结构更简单的二冲程：

| 维度 | 四冲程 | 二冲程 |
| --- | --- | --- |
| 曲轴转角 | 720°（两圈） | 360°（一圈） |
| 做功频率 | 每 2 圈 1 次 | 每圈 1 次 |
| 功率密度 | 低 | 高（同排量约高 50%–70%） |
| 换气质量 | 好（进排气分开） | 差（扫气与排气重叠） |
| 油耗排放 | 好 | 差（扫气损失大） |
| 应用 | 汽车、发电机组 | 摩托、船用、割草机 |

**重点：二冲程「多一次做功」换「差换气」**——功率密度高但换气时新鲜混合气被扫出（扫气损失），油耗与排放都差。这就是为什么现代汽车全用四冲程，而二冲程只留在摩托车、船用与小型工具上。**「用结构简单换效率损失」还是「用结构复杂换效率」**是内燃机设计的第一类权衡。

### 涡轮增压与机械增压

提高内燃机进气密度、增大每循环进气量的技术叫「增压」：

- **涡轮增压**：废气驱动涡轮、涡轮带动压气机压缩进气——回收废气能量，不消耗曲轴功，但存在「涡轮迟滞」（急加速时废气流量上来需要时间）。
- **机械增压**：曲轴直接驱动压气机——响应快但消耗曲轴功率，高速时反而拖累效率。

**辨析｜易错点：** 涡轮增压「用废气能量」不等于「免费」——压气机压缩空气要耗功，废气涡轮只回收了一部分本来要排掉的能量，增压后进排气压力都要变化，泵气损失与爆震倾向随之改变。**增压是「回收废气能 + 提高进气密度」的组合拳，不是白来的增益**——现代增压发动机还要配合中冷（压缩空气冷却）、直喷（降低爆震）一起设计。

### 内燃机的性能指标速查

| 指标 | 定义 | 意义 |
| --- | --- | --- |
| 升功率 | 功率 / 排量 | 强化程度 |
| 升扭矩 | 扭矩 / 排量 | 低速动力 |
| 燃油消耗率 | g/(kWh) | 经济性（越低越好） |
| 平均有效压力 | 有效功 / 排量 | 强化程度 |
| 机械效率 | 有效 / 指示 | 摩擦损耗 |

**重点：燃油消耗率（BSFC）是内燃机「省不省油」的硬指标**——现代汽油机约 220–260 g/kWh，柴油机约 180–220 g/kWh，最低油耗区在中等负荷。看发动机先进与否，先看 BSFC 最低点与「低油耗区覆盖范围」。

### 内燃机的发展前沿

- **缸内直喷（GDI）**：燃油直喷缸内，蒸发吸热降温、防爆震、提高压缩比。
- **可变压缩比**：按工况改变压缩比，兼顾低速高效与高速防爆震。
- **稀薄燃烧**：过稀混合气，热效率高、NOₓ 低，但燃烧稳定性与后处理是难点。
- **48V 轻混 / 混动**：电机辅助，回收制动能量，避开低效工况。
- **氢内燃机**：直接烧氢，零碳（尾气只排水），难点是回火与 NOₓ 控制。

**辨析｜易错点：** 「涡轮增压=省油」是误区——增压提高功率密度，若按「同功率更小排量」算，油耗降低；若按「同排量更大功率」算，油耗反而升高。**省不省油取决于「增压后如何利用」**——小排量增压 + 混动才是省油的组合，这与《能源系统分析》「系统视角」一致。

## 6 小结

- 四冲程内燃机：**进气、压缩、做功、排气**，只有做功冲程出功，多缸机抹平扭矩波动。
- 汽油机**点燃**（压缩比 8–11，怕爆震）、柴油机**压燃**（压缩比 16–22，效率高、怕冒烟）。
- 性能由**p–V 示功图**刻画，包围面积 = 指示功；平均有效压力 BMEP 衡量强化程度。
- 指示功率（缸内）→ 有效功率（曲轴）要乘机械效率 $\eta_m \approx 0.8–0.9$。
- 真实循环比奥托/狄塞尔理论循环低 10–20 个百分点：燃烧时间、缸壁传热、进排气损失是主因。
- 全部内燃机技术演进 = 让真实循环更接近理论循环。
