## 为什么最后要回到「系统」

前面的章节一台一台地讲设备：锅炉、汽轮机、燃气轮机、热泵、储能。但真实世界没有单台设备——电厂是一个系统，区域供热是一个系统，国家电网是一个系统。**能源系统分析（energy system analysis）**把视角从「设备」拉到「系统」：能量怎么流动、成本怎么核算、不同技术怎么协同、政策怎么评估。它是动力工程的「总装与总调度」环节。<span class="marginnote">系统思维与《能量分析与㶲分析》一脉相承：那里分析单个设备的能量账，这里分析整个能源链的账。一条能源链从「一次能源」（煤、气、太阳）到「二次能源」（电、热、氢）再到「终端用能」（动力、照明、供暖），每一环都有转换效率与成本——能源系统分析就是给整条链做「㶲审计 + 经济审计 + 碳审计」。</span>这一节讲能源平衡、技术经济评价、多能互补与能源规划的思维框架。

## 1 能源链与能源平衡

**能源链（energy chain）**描述能量从源头到终端的流动路径：一次能源 → 转换（电厂、炼厂）→ 输送（电网、管网）→ 储存 → 终端消费。每一环都有损耗：

$$\text{一次能源} \xrightarrow{\eta_1} \text{二次能源} \xrightarrow{\eta_2} \text{终端用能} \xrightarrow{\eta_3} \text{有效服务}$$

**能源平衡（energy balance）**是系统的记账：对某一区域或系统，列出各种能源的输入、转换、损失与输出，确保「输入 = 输出 + 损失 + 库存变化」。国家的能源统计、企业的能耗审计、电厂的厂用电率分析，都是能源平衡的具体形态。<span class="marginnote">一条典型煤电路径的损耗链：燃煤锅炉效率约 92%（排烟、散热损失）→ 朗肯循环效率约 42% → 发电机效率约 98% → 电网输电损失约 5% → 终端设备效率再打折。整条链的「从煤到终端有效功」总效率可能只有 25%–30%。<strong>能源系统分析的第一个价值：看清钱和碳到底丢在链上哪一环</strong>——这与《能量分析与㶲分析》的诊断逻辑完全一致，只是把「设备」换成「环节」。</span>

**重点：系统分析的第一问是「这条能源链的总效率是多少、每一环损失多少」。** 只优化某一环而忽视其它环，可能「局部高效、全局低效」——比如把燃机效率做到极致，若余热全排掉，联合循环的优势就浪费了。

## 2 技术经济评价：效率不是唯一标尺

工程上选择能源方案，不能只看效率，要看**全寿命周期的经济账**。核心指标：

- **年费用法 / 平准化度电成本（LCOE）**：把初投资、燃料费、运行维护费、残值折算到每 kWh 电量的成本。LCOE = $\frac{\text{初投资年化} + \text{年运行费} + \text{年燃料费}}{\text{年发电量}}$。
- **投资回收期**：初投资 ÷ 年净收益，衡量回本快慢。
- **净现值（NPV）**：把全寿命各年现金流折现求和，NPV > 0 才值得投资。

<span class="marginnote">LCOE 是能源项目比较的「通用货币」：光伏、风电、煤电、核电、气电放在同一把尺子下比。近十年光伏与风电的 LCOE 暴跌（光伏组件价格下降 90%+），已低于新建煤电——这就是「平价上网」的由来。注意 LCOE 只算「发电成本」，不含电网调峰成本与环境外部成本，所以系统层面还要叠加「系统成本」。</span>

**辨析｜易错点：** 效率高 ≠ 经济优。高效设备往往初投资高；低效方案可能燃料便宜。决策要用「全寿命经济指标」（LCOE、NPV）而不是单点效率——效率是工程量，LCOE 是决策量。

## 3 公式解析：平准化度电成本 LCOE

$$\text{LCOE} = \frac{\sum_{t=1}^{T}\frac{I_t + M_t + F_t}{(1+r)^t}}{\sum_{t=1}^{T}\frac{E_t}{(1+r)^t}}$$

- **第一步，看分子——全寿命总成本折现**：$I_t$ 是第 $t$ 年的投资（含利息），$M_t$ 是运行维护费，$F_t$ 是燃料费；$(1+r)^t$ 把未来的钱折现到现在（$r$ 是折现率）。资金有时间价值——同样一万块，今天比十年后更值钱。
- **第二步，看分母——全寿命发电量折现**：$E_t$ 是第 $t$ 年发电量。发电量同样折现，因为「早发的电」与「晚发的电」对决策者价值不同。
- **第三步，看三股力量**：初投资占比大的技术（光伏、核电）受折现率与利用小时数影响大；燃料占比大的技术（煤电、气电）受燃料价格影响大。LCOE 对「折现率、利用小时、燃料价」做敏感性分析，是能源项目评估的标配。
- **第四步，读懂它的局限**：LCOE 不含电网调峰成本、不含环境外部性。光伏的 LCOE 低，但光伏出力波动大、需要储能与调峰配套——系统的真实成本要加这一笔。

**重点：LCOE 是「技术比较」的尺子，系统成本才是「系统比较」的尺子。** 评估一项能源技术，先算 LCOE 看「自身成本」，再叠加系统成本看「对电网的负担」。

## 4 多能互补与综合能源系统

单一能源系统的低效在于「各管各」：电是电、热是热、气是气，互不衔接，能量品位错配。**多能互补（multi-energy complementarity）**把电、热、冷、气统筹：电厂的余热给区域供热，热泵消纳波动绿电，储能平移峰谷，氢作为跨季节储能载体。

典型的综合能源系统形态：

- **冷热电三联供（CCHP）**：燃气轮机/内燃机发电，余热驱动吸收式制冷与供暖——能源利用效率从单发电的 40% 提到 70%–80%。
- **电-热耦合**：电热泵、电锅炉消纳弃风弃光（把多余绿电变热储起来），实现「以电代煤」。
- **跨季节储能**：夏季光伏制氢、冬季氢发电/供热，把「丰时不用的能量」搬到「欠时」。

<span class="marginnote">多能互补的本质是「温度对口、品位匹配」：高品位电做高品位的事（驱动、制氢），中品位热做中品位的事（供暖），低品位热做低品位的事（预热、制冷驱动）。这正是《能量分析与㶲分析》「㶲级利用」思想的系统级实现——把一条条孤立的能源链织成一张「能量网」，让每一档温度的能量都找到最合适的用途。</span>

**重点：综合能源系统的价值来自「协同」，不是「堆设备」。** 让电厂余热替代燃气锅炉、让绿电替代煤电、让储能替代备用机组——每一笔替代都赚一份「效率 + 减排 + 经济」的三重收益。系统分析的任务，就是找出这些替代机会并量化收益。

## 5 能源规划与决策方法

区域与国家的能源规划是一套严谨的方法论：

- **情景分析**：设定不同发展路径（基准、积极、激进），比较各情景下的能源结构、碳排放与成本。
- **优化模型**：线性规划/混合整数规划（如 TIMES、MARKAL 模型）在「满足需求 + 约束」下求「总成本最小」的能源结构。
- **敏感性分析**：考察燃料价格、碳价、技术成本变化对最优方案的扰动。
- **政策工具评估**：碳税、补贴、可再生能源配额——经济激励如何改变系统演化。

<span class="marginnote">能源规划已从「算总需求」升级为「算不确定条件下的最优转型」：风电光伏的不确定性、储能成本的快速下降、碳价的波动，让规划变成一个动态优化问题。这与《最优化理论》的线性规划、整数规划方法直接相通——能源系统分析是运筹学最大的应用场之一。</span>

**重点：能源系统分析是「工程 + 经济 + 政策」的三栖学科。** 它不问「单台设备怎么做」，而问「整个系统怎么配」；它不只看效率，更看成本、碳与可靠性。动力工程的工程师在系统层面，是「系统架构师」而非「设备专家」。

### 算例：光伏与煤电的 LCOE 对比

把 LCOE 用到两种电源上，看决策逻辑。设折现率 $r = 5\%$、寿命 25 年：

| 指标 | 光伏 | 煤电 |
| --- | --- | --- |
| 初投资 | 高（组件 + 逆变器） | 高（锅炉 + 汽轮机） |
| 燃料成本 | 0 | 高（煤价主导） |
| 利用小时 | 1200–2000 h/年 | 4500–6000 h/年 |
| LCOE | 0.15–0.35 元/kWh | 0.3–0.5 元/kWh |

- **第一步，看结构差异**：光伏是「高投资 + 零燃料 + 低小时」，煤电是「高投资 + 高燃料 + 高小时」。LCOE 把三股力量折成一个数。
- **第二步，看平价含义**：光伏 LCOE 已低于新建煤电——「平价上网」指的就是这个。但光伏的间歇性带来系统成本（调峰、储能），完整比较还要加这一笔。
- **第三步，看敏感性差异**：光伏对折现率、利用小时敏感；煤电对煤价、碳价敏感。做敏感性分析能看出「哪个变量波动最致命」——这是项目风险管理的核心。

### 能源系统分析的三种「账」

| 账本 | 问的问题 | 工具 |
| --- | --- | --- |
| 能量账 | 能量去哪了？ | 能源平衡、能量分析 |
| 经济账 | 多少钱？ | LCOE、NPV、回收期 |
| 碳账 | 排了多少碳？ | 碳足迹、碳排放核算 |

**重点：三个账本必须一起看，缺一不可**——「能量效率高但贵」的（高效设备初投资高）、「便宜但排碳多」的（煤电）、「清洁但波动」的（光伏），单看任何一本账都会误判。能源系统分析的成熟，体现在三本账的联合权衡。

**辨析｜易错点：** 碳账不是「排放 ÷ 发电量」那么简单——要算**全生命周期**（建设、燃料、运行、退役）的碳足迹。光伏建设期的硅料生产排放不小，但全生命周期仍远低于煤电；忽略生命周期只看运行排放，会高估光伏的清洁度。

### 能源系统分析的常用工具

| 工具 | 用途 | 所属学科 |
| --- | --- | --- |
| 能源平衡表 | 摸清能量流向 | 热力工程 |
| LCOE / NPV | 经济比较 | 工程经济 |
| 敏感性分析 | 风险识别 | 运筹/统计 |
| 优化模型（线性/整数规划） | 求最优能源结构 | 运筹学 |
| 情景分析 | 路径比较 | 战略规划 |

**重点：能源系统分析是「多学科工具箱的组装」**——热力学算能量、经济学算成本、运筹学算优化、统计学算不确定性。它没有自己的「独家公式」，而是把本专题学过的所有方法串成决策链：摸底 → 诊断 → 比较 → 优化。

### 能源转型的系统视角

- **「不可能三角」**：能源系统要在「安全、经济、清洁」三个目标间权衡——顾此失彼是常态。
- **转型不是「一种能源替代另一种」**：而是整个系统（发电、电网、储能、需求侧）的协同重构。
- **路径依赖**：今天的基础设施（电网、燃气管网、煤炭供应链）决定明天能走多快。

**辨析｜易错点：** 「电气化 + 绿电」是主流方向，但「无脑电气化」会踩坑——重工业高温工艺、长距离重载运输、跨季节储能，纯电难以覆盖（《氢能与燃料电池》的「电够不着的地方用氢」）。**能源转型的理性是「因地制宜、场景匹配」**，不是「一种技术包打天下」。

## 6 小结

- **能源链**从一次能源到终端服务，每一环有损耗；系统分析先看清「链上哪一环损失最大」。
- 决策用**全寿命经济指标**：LCOE（平准化度电成本）、NPV、回收期——效率高 ≠ 经济优。
- LCOE = 全寿命成本折现 ÷ 全寿命发电量折现；不含系统成本与环境外部性，要与「系统成本」叠加。
- **多能互补**把电、热、冷、气统筹：三联供、电热耦合、跨季节储能，本质是「温度对口、㶲级利用」。
- 能源规划用**情景分析 + 优化模型 + 敏感性分析**，是运筹学（线性/整数规划）的工程应用场。
- 系统思维 = 不孤立看设备，先看整条链、算全寿命账、找协同机会。
