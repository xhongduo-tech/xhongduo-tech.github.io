## 为什么不能直接「放大」实验结果

飞机不能造一架 1:1 的原型直接试飞，风洞里的模型缩小到几十分之一；汽轮机叶片要做成小比例的试验件；船模要在水池里拖拽。问题来了：**模型实验的结果，凭什么能搬到实机上去？** 直接把模型测的力按比例放大是行不通的——流体的行为不随尺寸线性变化。**相似理论（similarity theory）**回答的就是这个问题：什么条件下两个流动「本质相同」，以及如何把模型数据换算到原型。<span class="marginnote">相似理论是「无量纲化」方法论的正式化。你在《对流传热》里已经用过它——$Nu = f(Re, Pr)$ 就是相似理论的产品：不做上千组全尺寸实验，只要在相似条件下测几组无量纲数，就能覆盖所有尺寸与工况。它也是量纲分析（白金汉 $\pi$ 定理）在流体力学里的完整舞台，把「凭经验凑公式」变成「按定理组公式」。</span>这一节讲相似的条件、量纲分析、以及相似理论在工程实验中的落地。

## 1 几何相似、运动相似与动力相似

两个流动系统要「相似」，需满足三个层次的相似：

**几何相似**：对应长度成同一比例（模型是原型的等比例缩小）。
**运动相似**：对应点速度方向相同、大小成同一比例（流线族相似）。
**动力相似**：对应点所受各类力（惯性、粘性、重力、压力）方向相同、大小成同一比例。

三者层层递进：几何相似是基础，运动相似在几何相似上加上「速度场相似」，动力相似再要求「力的比例相同」。**动力相似是关键**——阻力、升力等一切力的测量结果，只有在动力相似时才可换算。

**重点：动力相似的充分条件是无量纲准则数相等。** 惯性力与粘性力之比是 $Re$，惯性力与重力之比是 $Fr$（弗劳德数），惯性力与压力/弹性力之比是 $Eu$（欧拉数）/ $Ma$（马赫数）。两个流动只要对应的准则数相等，力场就成比例，动力相似就成立。

## 2 量纲分析与白金汉 $\pi$ 定理

怎么知道该组哪些无量纲数？**量纲分析（dimensional analysis）**给出系统方法。**白金汉 $\pi$ 定理（Buckingham π theorem）**：若一个物理问题涉及 $n$ 个物理量、其中含 $k$ 个基本量纲，则问题可化为 $n-k$ 个无量纲 $\pi$ 数的函数关系。<span class="marginnote">对绕球阻力问题：$F_D = f(\rho, v, d, \mu)$，5 个量、3 个基本量纲（质量、长度、时间），于是有 2 个 $\pi$ 数——可取 $\pi_1 = C_D = F_D/(\frac{1}{2}\rho v^2 d^2)$、$\pi_2 = Re = \rho vd/\mu$，即 $C_D = g(Re)$。上一节斯托克斯阻力里那个神秘的 $24/Re$，正是这条函数关系在蠕动流极限下的显式！量纲分析把「猜公式」变成了「定结构」。</span>

量纲分析的价值：不求解方程，只凭「物理量之间的量纲一致性」就能确定问题的无量纲结构，指明实验必须测哪些无量纲数。它是实验设计的地图。

**重点：$\pi$ 定理告诉你有几个数，但不说函数长什么样。** 函数关系要靠理论（层流精确解）、半经验关联或实验标定。量纲分析 + 实验 = 工程关联式的标准生产线。

## 3 常见准则数与相似判据

流体力学与传热学里最重要的无量纲数及其物理意义：

| 准则数 | 定义 | 物理意义 |
| --- | --- | --- |
| $Re$ | $\rho vL/\mu$ | 惯性力 / 粘性力 |
| $Fr$ | $v/\sqrt{gL}$ | 惯性力 / 重力（明渠、船舶） |
| $Ma$ | $v/c$ | 流速 / 声速（可压缩性） |
| $Eu$ | $\Delta p/(\rho v^2)$ | 压力 / 惯性力（压降系数） |
| $We$ | $\rho v^2L/\sigma$ | 惯性力 / 表面张力（喷雾、气泡） |
| $Nu$ | $hL/\lambda$ | 对流传热 / 导热 |
| $Pr$ | $\nu/a$ | 动量扩散 / 热扩散 |
| $Gr$ | $g\beta\Delta tL^3/\nu^2$ | 浮力 / 粘性力 |

<span class="marginnote">工程中「部分相似」是常态：让全部准则数都相等几乎不可能。比如船舶模型既要 $Re$ 相等又要 $Fr$ 相等，所需介质性质互相矛盾——于是按问题主导力选判据：有自由表面重力主导的用 $Fr$ 相似（船模），全浸没粘性主导的用 $Re$ 相似（机翼）。<strong>抓住主导力，牺牲次要相似，是模型实验的现实策略。</strong></span>

**辨析｜易错点：** 相似不是「长得像」。几何相似只是第一步，没有动力相似的几何模型，测出的力毫无意义。反过来，几何不相似但准则数相等也不可能（准则数里含几何量）。判断相似问题先问「主导力是什么」，再选准则数。

## 4 公式解析：白金汉 $\pi$ 定理的应用流程

**第一步，列物理量**：写出问题涉及的全部物理量（含待求量与自变量），如绕球阻力 $F_D$、$\rho$、$v$、$d$、$\mu$——共 5 个。
**第二步，定基本量纲**：质量 $M$、长度 $L$、时间 $T$（力学问题 3 个基本量纲），即 $k = 3$。
**第三步，数 $\pi$ 数**：$n - k = 5 - 3 = 2$ 个无量纲组。选 3 个「重复量」（如 $\rho$、$v$、$d$，互不依赖、覆盖全部量纲），与其余量两两组合成 $\pi$ 数。
**第四步，解指数**：令每个 $\pi$ 数无量纲，解出重复量的指数，得到 $\pi_1 = F_D/(\rho v^2d^2)$、$\pi_2 = \rho vd/\mu$——即 $C_D = f(Re)$。
**第五步，结果落地**：实验只需测 $C_D$ 随 $Re$ 的变化，一条曲线覆盖所有尺寸、流速、介质的组合。

**重点：$\pi$ 定理是「实验设计 + 数据整理」的宪法。** 它决定了实验自变量取什么、结果画在什么坐标上。凡是「画无量纲图」的工程数据（莫迪图、阻力系数曲线、$Nu$ 关联式），都是 $\pi$ 定理的产品。

## 5 相似理论在工程实验中的落地

**风洞实验**：机翼、汽车、建筑模型在风洞里测阻力与压力分布。要求 $Re$ 相似——所以风洞要能变速、增压（高压风洞提高空气密度，凑 $Re$）。测量结果用无量纲系数（$C_D$、$C_L$、$C_p$）输出，直接用于原型设计。
**船模试验**：水池拖拽船模，按 $Fr$ 相似选速度，测剩余阻力，再换算全尺度阻力——造船设计的基本流程。
**水泵与风机试验**：同一族叶轮，用相似换算（比例定律）把模型试验的 $H$–$Q$ 曲线换算到不同转速与叶径：$Q \propto nD^3$、$H \propto n^2D^2$、$P \propto n^3D^5$——这是《泵与风机》选型的核心工具。<span class="marginnote">水泵比例定律是相似理论的工业金矿：一台泵在不同转速下流量与转速一次方、扬程二次方、功率三次方成比例。转速提 10%，流量 +10%、扬程 +21%、功率 +33%——功率涨得最猛，这就是变频调速「低速省电」的流体力学根源。第四篇《泵与风机》会完整展开这条定律。</span>
- **换热器实验**：小尺寸换热件测 $Nu$ 关联式，放大到工业尺寸用同一关联式——传热实验的标准路线。

### 算例：风洞模型实验的相似设计

把一台汽车模型（1:5 缩比）放进风洞，测阻力系数。原型与模型要动力相似：

- 原型：车宽 $L_p = 2$ m，车速 $v_p = 30$ m/s（约 108 km/h），空气 $\nu_p = 1.5\times10^{-5}$ m²/s，$Re_p = \frac{30\times2}{1.5\times10^{-5}} = 4\times10^6$。
- 模型：$L_m = 0.4$ m，风洞需 $Re_m = Re_p$：$v_m = \frac{Re\,\nu_m}{L_m}$。若风洞可增压（$\nu$ 随密度变化），常温常压风洞需 $v_m = 150$ m/s——超音速，不可行！

**重点：完全相似往往不可能，工程做「部分相似」**。汽车风洞的实际做法：模型放大到 1:2 或 1:3、风洞加压提高密度、承认 $Re$ 不完全相等但控制在自模区（$Re$ 超过某临界后 $C_D$ 变化平缓），用修正系数把模型数据外推到原型。**「知道相似，也知道相似做不到，才懂得怎么近似」**——这是相似理论的工程智慧。

### 相似理论在换热的用途

- **模型换热试验**：小尺寸换热件测 $Nu$，关联式放大到工业尺寸（《对流传热》的 $Nu = f(Re, Pr)$ 就是相似理论的产物）。
- **实物测温的反推**：红外测温读到的辐射量通过相似换算成温度。
- **泵与风机的比例定律**：$Q \propto nD^3$、$H \propto n^2D^2$、$P \propto n^3D^5$——同一族叶轮在不同转速与叶径间换算，靠的就是几何相似与动力相似（《泵与风机》）。

**辨析｜易错点：** 相似理论要求「模型与原型几何相似」，但**比尺效应**（scale effect）无处不在：边界层厚度、粗糙度、表面张力等在小模型上的相对作用与原型不同。小模型测到的阻力系数直接当原型用，会因比尺效应失真——所以相似换算总带修正系数，不能「一比一照搬」。

### 无量纲化的力量：一张图覆盖所有工况

相似理论的终极价值：**把「一族问题」压成「一条曲线」**。

- 绕球阻力：$C_D = f(Re)$——一条 $C_D$–$Re$ 曲线，覆盖所有尺寸、流速、介质的球。
- 管内流动：莫迪图——一张图覆盖所有管道（$f$ vs $Re$ vs $\varepsilon/d$）。
- 对流传热：$Nu = f(Re, Pr)$——一个关联式覆盖所有工况。

**重点：无量纲化的本质是「找到问题的标尺」**——把「这个球多大、多快」换成「这个球在哪个 $Re$ 区」，问题就从「无限多个具体参数」变成「一条通用曲线」。工程数据整理成无量纲图，是让「一次实验惠及所有同类问题」的根本手段。

### 量纲分析的局限与注意

量纲分析虽强，但要知道它的边界：

- 它给出**无量纲结构**（有几个数、怎么组合），但**给不出函数关系**——$C_D = f(Re)$ 的具体形式要靠理论或实验。
- 漏掉关键物理量，量纲分析就「漏数」——比如忘了粘度，就组不出 $Re$。
- 常数项（如 $C_D = 24/Re$ 里的 24）无法从量纲分析得出。

**辨析｜易错点：** 量纲分析的前提是「物理量齐全」——**漏掉一个重要的量，无量纲数就少一个，结构就错**。做量纲分析前，先穷举「这个现象涉及哪些量」（黏度、密度、速度、尺寸、重力、表面张力…），再套 $\pi$ 定理。这是「先理解物理、再玩数学」的顺序，颠倒了必错。

## 6 小结

- 相似分**几何、运动、动力**三层，动力相似是关键，其充要条件是准则数相等。
- **白金汉 $\pi$ 定理**：$n$ 个量、$k$ 个基本量纲 $\Rightarrow$ $n-k$ 个无量纲数，决定问题的无量纲结构。
- 常见准则数各有物理意义：$Re$（粘性）、$Fr$（重力）、$Ma$（可压缩）、$We$（表面张力）、$Nu/Pr/Gr$（传热）。
- 模型实验常做**部分相似**：按主导力选判据（船模用 $Fr$、机翼用 $Re$），牺牲次要相似。
- $\pi$ 定理是实验设计与数据整理的宪法：无量纲图（莫迪图、$C_D$ 曲线）都是它的产品。
- **水泵比例定律** $Q\propto nD^3$、$H\propto n^2D^2$、$P\propto n^3D^5$ 是相似理论在叶轮机械里的直接应用。
