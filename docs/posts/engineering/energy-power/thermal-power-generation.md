## 为什么火电仍是电力系统的「压舱石」

尽管可再生能源快速增长，**火力发电（煤电、气电）**仍是全球电力的主力与电网的调峰支撑——尤其煤电，在中国电力结构中长期占半数以上。火电是《蒸汽轮机与锅炉》一节的完整总装：锅炉、汽轮机、发电机、凝汽器、给水泵串联成一条能量链，再把《能源系统分析》的成本与效率方法用上。<span class="marginnote">火电厂是一台「把化学能变电能」的巨型转换器，各环节效率相乘得全厂效率：锅炉（~92%）× 汽轮机循环（~42%）× 机械传动与发电机（~98%）× 厂用电（~93%），亚临界机组全厂净效率约 37%–39%，超超临界可达 45%+。而燃机联合循环（《燃气轮机》一节）可到 62%——这就是燃气发电「碳排放更少」的机理。</span>这一节讲火电厂的完整流程、效率链条、以及煤电的清洁化改造。

## 1 从煤到电：火电厂的完整流程

一座燃煤电厂的主流程是一条清晰的能量链：

1. **输煤与制粉**：原煤经皮带运入，磨煤机磨成煤粉。
2. **锅炉燃烧**：煤粉与热空气在炉膛燃烧，火焰辐射加热水冷壁，烟气加热过热器、再热器、省煤器、空气预热器（四大受热面梯级吸热）。
3. **蒸汽做功**：主蒸汽（超超临界可达 25 MPa、600°C）进汽轮机高压缸做功，经再热器再热后进中低压缸继续做功，带动发电机转子旋转。
4. **排汽凝结**：乏汽进凝汽器被循环水冷却凝结成水，经回热加热器预热后由给水泵送回锅炉——汽水循环闭合。
5. **发电上网**：发电机把转子机械能转成电能，经主变压器升压（如 500 kV）接入电网。
6. **烟气处理**：烟气经除尘（静电除尘器）、脱硫（湿法石灰石）、脱硝（SCR）后排放大气。

<span class="marginnote">火电厂本质上是一个「大锅炉 + 大汽轮机 + 大凝汽器 + 大给水泵」的朗肯循环工程实现，外加燃烧与环保两大系统。它的水汽循环是「闭合的」——水在锅炉里变蒸汽、在汽轮机里做功、在凝汽器里变回水，循环往复。发电功率的调节靠「烧多少煤 + 进多少汽」控制，这就是火电「可调度」的根源，也是它与风电光伏的本质区别。</span>

**重点：火电的三大损失环节——凝汽器、锅炉排烟、汽轮机内损失。** 凝汽器排走的热量最大（约占总能量的 40%+），但那是低温废热、㶲很小（《能量分析与㶲分析》的结论）；真正该治的是锅炉的排烟损失（约 5%–8%）与燃烧㶲损。看懂火电厂的效率，就要用两套账一起看。

## 2 全厂效率的乘法链

全厂净效率由各环节效率相乘：

$$\eta_{net} = \eta_b \times \eta_t \times \eta_g \times \eta_{aux}$$

其中 $\eta_b$ 锅炉效率（排烟、散热、未燃尽损失，约 92%）、$\eta_t$ 汽轮机循环热效率（朗肯循环 + 再热回热，约 40%–48%）、$\eta_g$ 发电机效率（约 98%）、$\eta_{aux}$ 厂用电系数（给水泵、磨煤机、风机等厂用电约占 5%–7%，取 0.93 左右）。<span class="marginnote">这根乘法链暴露了火电的「结构天花板」：锅炉和发电机都接近 95% 以上，瓶颈全在汽轮机循环的 40% 上下——它是卡诺效率的囚徒。所以提升全厂效率只有两条路：<strong>提高蒸汽参数（超临界化）</strong>与<strong>联合循环（气电）</strong>。煤电的「超超临界 + 再热 + 八级回热」就是在这条路上走到极致。</span>

**公式解析：$\eta_{net} = \eta_b\eta_t\eta_g\eta_{aux}$**——每一项都代表一类独立的损失：
- **第一步，认每项的物理**：锅炉效率丢在「烟囱与灰渣」，循环效率丢在「卡诺与设备」，发电机丢在「铜铁损耗」，厂用电丢在「给自己供电的泵与风机」。
- **第二步，看谁是短板**：$\eta_t \approx 0.42$ 是最大短板，其余三项都 ≥ 0.92。改进资源应投向循环效率——这与「先诊断瓶颈、再对症下药」的工程纪律一致。
- **第三步，看提效的杠杆**：蒸汽参数从亚临界升到超超临界，$\eta_t$ 从 0.38 升到 0.48，全厂效率随之从 38% 升到 45%+——每提 1 个百分点，一台 1000 MW 机组年省标煤约 2–3 万吨，减排 CO₂ 约 5–8 万吨。

**辨析｜易错点：** 别把「锅炉效率」当「全厂效率」。锅炉 92% 只是「煤的化学能变成蒸汽热量的比例」，后面还要过汽轮机、发电机、厂用电三关。公众常说的「火电厂效率 40%」指的就是全厂净效率，不是锅炉效率。

## 3 调峰、灵活性改造与深度调峰

火电在新型电力系统里的角色变了：从「基荷主力」转向「调峰支撑」——风电光伏大发时压低出力，缺电时顶上。这就要求煤电**灵活性改造**：

- **深度调峰**：把最小技术出力从额定容量的 50%–60% 压到 30% 甚至 20%——低负荷下锅炉稳燃、汽轮机低负荷效率、环保设备低温运行，全是技术难点。
- **快速变负荷**：AGC（自动发电控制）要求机组快速响应负荷指令，每分钟可变的速率从 1% 提到 2%–3%。
- **热电解耦**：热电联产机组「以热定电」限制了调峰，加装蓄热罐把热和电解耦，让电出力可以独立调节。

<span class="marginnote">深度调峰的技术代价是「低负荷效率下降 + 设备寿命损耗」：锅炉在 30% 负荷下火焰不稳、NOₓ 排放难控，汽轮机末级在低流量下鼓风发热。工程上用等离子点火稳燃、低 NOₓ 燃烧器、以及「转湿态运行」等办法应对。煤电从「全年满发」变成「能上能下」，正是它在新电网里的生存之道。</span>

**重点：火电的价值正在从「发电量」转向「调节能力」。** 当风电光伏占比升高，电网最缺的不是「电」而是「灵活性」——煤电的调峰容量、惯量支撑、备用能力，成了它继续存在的最重要理由。

## 4 煤电的清洁化改造

煤电的环保与减排是三大改造方向：

- **超低排放**：除尘（静电/布袋，颗粒物 <10 mg/m³）、脱硫（石灰石-石膏湿法，SO₂ <35 mg/m³）、脱硝（SCR，NOₓ <50 mg/m³）——煤电排放已达到燃气电厂的限值。
- **节能改造**：汽轮机通流改造、烟气余热回收（低温省煤器）、锅炉优化燃烧——把能效再往上顶。
- **碳减排**：生物质掺烧（把煤粉锅炉烧一部分生物质，降碳）、**碳捕集（CCUS）**——燃烧后捕集 CO₂ 或富氧燃烧，是煤电「保生存」的终极技术（代价是能耗增加 20%–30%）。<span class="marginnote">CCUS 是煤电的「续命稻草」也是「成本噩梦」：每捕集 1 吨 CO₂ 要消耗额外能量、成本约 300–600 元/吨。只有当碳价高到让「捕碳」比「排碳」划算，CCUS 才有经济性——这正是《能源系统分析》里碳定价的逻辑。在「双碳」目标下，煤电的出路是「保供 + 调节 + 低碳」三位一体，而不是简单关停。</span>

**重点：煤电不会「一夜消失」，而是「转型」。** 从基荷到调峰、从高排放到超低排放、从纯煤到掺烧与 CCUS——煤电的角色、排放与成本结构都在重塑。理解这个转型，是理解全球能源转型的一把钥匙。

### 火电厂的能量流向速查

一座典型亚临界 600 MW 机组的能量平衡（以燃料输入 100% 计）：

| 去向 | 占比 | 㶲含义 |
| --- | --- | --- |
| 发电输出 | 约 38% | 有效功 |
| 凝汽器排热 | 约 40% | 低温废热、㶲小 |
| 锅炉排烟与散热 | 约 8% | 中低温损失 |
| 汽轮机内损失 | 约 8% | 㶲损（摩擦、节流） |
| 厂用电与辅机 | 约 6% | 给水泵、风机耗电 |

- **第一步，看能量分析**：凝汽器排热最多（40%），能量分析会说「这是最大损失」。
- **第二步，看㶲分析**：凝汽器排的是 30°C 左右的低温热，㶲近乎为零——真正烧掉做功能力的是锅炉的燃烧不可逆与传热温差（《能量分析与㶲分析》的核心结论）。
- **第三步，看改进方向**：能量分析指向「回收凝汽器余热」（供暖、热泵），㶲分析指向「提高蒸汽参数、减少燃烧损失」——两条路线都对，但对应不同的改造项目与收益量级。

### 火电在新型电力系统中的角色

- **基荷 → 调节**：风电光伏占比升高后，火电从「全年满发」转向「深度调峰」，最小出力压到 20%–30%。
- **惯量支撑**：火电同步发电机提供系统惯量与无功支撑，是电网稳定运行的重要基石——这是新能源（逆变器并网）难以完全替代的。
- **兜底保障**：极端天气、新能源出力骤降时，火电是最后的备用电源。

**重点：火电的「价值标尺」正在从发电量转向「可调度性 + 惯量 + 备用」**——评估火电要看它对电网的系统价值，而不只是度电成本。这呼应《能源系统分析》里「系统成本」的视角。

### 火电厂的水汽循环与热力系统

火电厂的热力系统不只是「锅炉-汽轮机-凝汽器-给水泵」四件套，还包含完整的热力系统设备：

| 设备 | 作用 | 对应章节 |
| --- | --- | --- |
| 回热加热器 | 抽汽预热给水 | 《热力循环》回热 |
| 再热器 | 提高再热蒸汽温度 | 《热力循环》再热 |
| 除氧器 | 除去给水中的氧（防腐蚀） | 热力除氧 |
| 给水泵 | 给水升压 | 《泵与风机》 |
| 凝汽器 | 排汽凝结 | 《传热学》凝结 |

**重点：火电厂的热力系统是「朗肯循环 + 再热回热」的完整展开**——每加一个设备，h–s 图上的循环就「长胖一点」，效率就高一点。看懂 h–s 图与热力系统图的对应，就掌握了火电厂的热力学全貌。

### 烟气处理的环保链条

- **脱硝（SCR）**：喷氨把 NOₓ 还原成 N₂（《内燃机燃烧与排放》的 SCR 同源）。
- **除尘（ESP）**：静电除尘器吸附颗粒物。
- **脱硫（湿法）**：石灰石浆液吸收 SO₂。

**辨析｜易错点：** 烟气处理有「温度窗口」——SCR 要求烟气 300–400°C，脱硫要在低温段。所以烟气处理设备按「高温到低温」的顺序排列：省煤器（高温段回收余热）→ SCR（脱硝）→ 空预器 → 除尘 → 脱硫（低温段）。**顺序排错，环保设备失效或能耗暴增**——这是《传热学》「温度对口」在环保系统的应用。

## 5 小结

- 火电流程 = **输煤制粉 → 锅炉燃烧 → 汽轮机做功 → 凝汽器凝结 → 发电机发电**，水汽循环闭合。
- 全厂净效率 $\eta_{net} = \eta_b\eta_t\eta_g\eta_{aux}$（约 38%–45%+），短板在汽轮机循环效率。
- 提升效率靠**超超临界参数**（25 MPa、600°C）与再热回热；气电联合循环可达 62%。
- 火电角色转向**调峰支撑**：深度调峰、快速变负荷、热电解耦是灵活性改造三件套。
- 清洁化三方向：**超低排放、节能改造、CCUS 碳捕集**；CCUS 的经济性取决于碳价。
- 煤电转型 = 保供 + 调节 + 低碳，从基荷走向「能上能下」的灵活性电源。
