## 为什么制冷与空调独立成篇

《制冷循环与热泵》一节建立了蒸气压缩循环的理论，这里看它的工程形态：从一台家用分体空调到整栋楼宇的中央空调系统，从冷库到冷链。空调不仅「制冷」，还控制**温度、湿度、洁净度、气流组织**——建筑能耗里空调占大头，制冷与空调是动力工程里与日常生活最近的板块。<span class="marginnote">制冷与空调行业是「逆循环工程」的最大应用场：每台空调都是一台蒸气压缩热泵，把室内的热搬到室外。它的经济分量惊人——全球空调保有量数十亿台，建筑能耗中制冷占比三分之一以上。而「制冷剂的选择」让它成了环保议题的中心：从 CFC 到 HFC 再到天然工质，制冷史就是一部环境政策驱动的技术史。</span>这一节讲空调系统的组成、制冷剂与环保、性能评价与节能路径。

## 1 蒸气压缩制冷系统的四大件工程化

《制冷循环与热泵》里的四大件在工程里各有讲究：

- **压缩机**：系统的「心脏」。家用常用**涡旋式**（高效低噪）与**转子式**；商用大机用**螺杆式**与**离心式**。压缩机把低温低压蒸气压成高温高压蒸气。
- **冷凝器**：把高压蒸气冷却凝结成液体，放出热量。家用空调是风冷式（翅片管 + 室外机风扇），大型机组可用水冷式（冷却塔散热）。
- **节流装置**：家用常用**毛细管**（结构简单、靠阻力节流）或**电子膨胀阀**（精确调节、适应变负荷）。电子膨胀阀是现代变频空调的标配。
- **蒸发器**：低温低压液体吸热汽化，把房间的热带走。室内机就是蒸发器 + 风机。

<span class="marginnote">「四大件 + 制冷剂」构成一个封闭回路，制冷剂在里面周而复始地「压缩—冷凝—节流—蒸发」。家用空调和一台几十千瓦的冷水机组，原理完全相同，差别只在压缩机形式、节流方式与制冷剂充注量。<strong>原理不因尺寸而变</strong>——这是学完《制冷循环与热泵》后看任何空调都「一眼看穿」的底气。</span>

**重点：空调的「冷量」与「耗功」之比就是 EER/COP。** 家用空调的能效比 EER（制冷量/输入功率）如今 3.5–5.0；变频空调部分负荷下 COP 更高。能效等级（新国标 1–5 级）就是把 EER 分成档，推动厂商做高效机——能效是空调最重要的性能标尺。

## 2 制冷剂：从 CFC 到天然工质

制冷剂经历了三代变迁，每一步都是环保法规推动：

- **第一代（CFC，如 R12）**：含氯氟烃，破坏臭氧层（ODP 高），已全球禁用（蒙特利尔议定书）。
- **第二代（HCFC，如 R22）**：过渡性工质，仍含氯、ODP 低但非零，正在逐步退出。
- **第三代（HFC，如 R410A、R32、R134a）**：不含氯、不破坏臭氧，但**温室效应强（GWP 高）**——被《基加利修正案》限用。
- **第四代/天然工质**：R290（丙烷）、R600a（异丁烷）、CO₂（R744）、氨（R717）——GWP 低，是未来的方向。

<span class="marginnote">制冷剂选择的关键词是三个：ODP（臭氧破坏潜势）、GWP（全球变暖潜势）、安全等级。R32 的 GWP 是 R410A 的三分之一，已成为中国新空调的主流；R290 的 GWP 接近 0 但易燃（可燃等级 A3），需要防爆设计；CO₂ 不燃但系统压力高、跨临界循环效率略低。<strong>「零臭氧破坏 + 低温室效应 + 安全」三者难兼得</strong>——这是制冷剂选型的永恒权衡。</span>

**重点：制冷剂是「工质 + 环境政策」的双重命题。** 工程上选制冷剂不只是热力学题，更是环保合规题。每轮法规升级，整条产业链（压缩机、换热器、润滑油）都要随之改型。

## 3 空调系统的形式与气流组织

空调系统按规模与形式分：

- **分体式/多联机**：家用与小型商用。一拖一（分体）或一拖多（多联机 VRV，变频压缩机 + 电子膨胀阀按需分配制冷剂）。
- **中央空调（冷水机组）**：大型建筑。冷水机组制出 7°C 冷水，经水泵送到各房间的风机盘管，风机吹过盘管送出冷风。冷源集中、效率高。
- **全空气系统**：组合式空调箱处理空气，通过风管送风——商场、机场常用。

**气流组织**是空调舒适性的工程细节：送风方式（侧送、顶送、地板送风）、送风温差、风速、回风位置，决定了房间的温度均匀度与吹风感。<span class="marginnote">空调解决的不仅是「热」，还有「湿」：湿空气在蒸发器表面冷凝除湿，所以空调房里空气干爽。湿度处理涉及《传热学》的湿空气焓湿图（i–d 图）——焓湿图是空调设计的计算工具，含湿量、相对湿度、焓值都在上面查读，空调箱的加热、加湿、冷却、除湿四个功能对应图上的四条路径。</span>

**重点：空调负荷有两部分——显热（降温）与潜热（除湿）。** 建筑围护传热、太阳辐射、人体、设备散热是显热负荷；人体散湿、新风含湿是潜热负荷。设计空调要先算负荷，再选设备——负荷计算是空调设计的第一步，也是《能源系统分析》里建筑能耗的源头。

## 4 公式解析：制冷量 $Q_0 = \dot{m}(h_1 - h_4)$

- **第一步，认符号**：$\dot{m}$ 是制冷剂质量流量，$h_1$ 是蒸发器出口（压缩机进口）蒸气焓，$h_4$ 是节流后进入蒸发器的湿蒸气焓。
- **第二步，看物理**：$h_1 - h_4$ 是单位质量制冷剂在蒸发器里吸收的热量（潜热 + 少量过热显热）。乘以流量就是制冷量。节流前后焓不变（$h_3 = h_4$），所以 $h_4$ 可用冷凝器出口液体焓代替，查表方便。
- **第三步，看提高制冷量的两条路**：增大流量 $\dot{m}$（换大压缩机）或增大焓差 $h_1 - h_4$（降低冷凝温度、提高蒸发温度、减少过冷损失）。工程上「冷凝器别太热、蒸发器别太冷」的节能直觉，全部来自这条公式。
- **第四步，连到 COP**：$COP = \frac{Q_0}{P_c} = \frac{h_1 - h_4}{h_2 - h_1}$，分子是制冷量、分母是压缩功——两条杠杆同时决定能效。

**辨析｜易错点：** 制冷量 $Q_0$ 不是「空调每小时耗的电」。空调铭牌上的「制冷量 3500 W」是它每小时搬走的热量，而输入电功率可能只有 900 W（能效比约 3.9）。用「制冷量当耗电功率」估电费，会高估三四倍。

## 5 空调节能：从能效到变频

空调节能的三条主线：

- **提高部件效率**：高效压缩机（永磁同步）、高效换热器（亲水翅片、微通道）、电子膨胀阀精确节流。
- **变频调节**：变频压缩机根据负荷连续调速，避免频繁启停损耗，部分负荷 COP 大幅提升——这是新国标推动的普及技术。
- **系统层面**：新风热回收、变风量系统、夜间通风预冷、利用室外免费冷源（Free cooling）、建筑围护保温——从「制冷」扩展到「建筑能源系统」。

<span class="marginnote">变频与定频的差别在部分负荷：空调 90% 时间不在满负荷运行，定频机靠「启停」维持温度，每次启动都耗电且温度波动；变频机低转速连续运行，既省电又恒温。变频空调的能效优势主要来自「匹配负荷」而非「压缩机本身更高效」——这与泵的变速调节是同一个道理，都是《相似理论》里比例定律的工程兑现。</span>

**重点：空调能耗的改善必须放在「全年运行工况」里评价。** 单点 COP 不能代表全年表现——新国标用 **APF（全年性能系数）**，综合制冷与制热、满负荷与部分负荷。评价一台空调看 APF 而不是单点 EER，才能反映真实电费。

### 空调系统的四大件与家用电器的对应

把中央空调与家用空调的四大件对照起来，概念就落地了：

| 部件 | 中央空调 | 家用分体空调 |
| --- | --- | --- |
| 压缩机 | 离心式/螺杆式冷水机组 | 转子式/涡旋式 |
| 冷凝器 | 水冷壳管式 + 冷却塔 | 风冷翅片管（室外机） |
| 节流 | 电子膨胀阀 | 毛细管/电子膨胀阀 |
| 蒸发器 | 壳管式冷水（7°C 水） | 风冷翅片管（室内机） |

**重点：原理完全相同，只是「把热量搬去哪、用什么冷媒搬运」的工程形态不同**。中央空调把冷量做成 7°C 的冷水送到各房间，家用机直接用制冷剂在室内机蒸发——一个「水系统」、一个「直接膨胀系统」。

### 空调负荷的估算与节能关系

空调设计负荷 = 显热负荷（围护传热、太阳辐射、人体、设备）+ 潜热负荷（人体散湿、新风含湿）。估算量级：

- 办公建筑空调冷负荷约 80–120 W/m²。
- 新风负荷可能占总负荷 30%–40%（新风要降温除湿）。

**重点：新风既是健康刚需，又是冷负荷大户**——所以「新风热回收」（排风与新风换热，回收显热与潜热）成为节能标配：把排风的冷/热「还给」新风，省下处理新风的能耗。这与《节能与余热利用》的「余热回收」思想同源，只是回收对象换成了新风。

**辨析｜易错点：** 空调选型按「峰值负荷」还是「平均负荷」？按峰值选型保证极端天气够用，但大部分时间「大马拉小车」、部分负荷效率差（变频机缓解）。**正确做法是按峰值 + 部分负荷性能（APF）综合选型**，而不是只看峰值——这又是《能源系统分析》「系统视角」的体现。

### 空调系统的能效标准与APF

| 能效指标 | 含义 | 说明 |
| --- | --- | --- |
| EER | 制冷量 / 输入功率（单点） | 设计工况能效 |
| COP | 制热量 / 输入功率（单点） | 设计工况能效 |
| SEER | 季节能效比（制冷） | 全年制冷加权 |
| APF | 全年性能系数 | 制冷制热全年加权 |

**重点：APF/SEER 是「全年实际账单」的指标，EER/COP 只是「设计点」的指标**——空调全年大部分时间在部分负荷运行，单点 EER 高的机器，部分负荷未必高效。新国标用 APF 分级，就是逼厂商优化「全年工况」而非「设计工况」。

### 空调制冷剂充注与系统运行

- **充注量**：制冷剂多了少了都伤系统——多了冷凝压力高、少了过热度大、制冷量不足。
- **过冷度/过热度**：运行参数监测的窗口——过冷度不足说明冷凝器换热差，过热度偏大说明制冷剂不足。
- **油管理**：压缩机润滑油需随制冷剂循环，回油不畅会烧压缩机。

**辨析｜易错点：** 空调「不制冷先加氟」是常见误区——多数不制冷是**冷凝器脏堵、滤网堵塞、风机故障**，而非缺氟。**「先查风与滤网、再查氟」**是空调维修的第一判断顺序——这与《换热器设计》「先怀疑结垢」同一运维哲学。

## 6 小结

- 空调系统 = 压缩机 + 冷凝器 + 节流装置 + 蒸发器，制冷剂在封闭回路里周而复始。
- **EER/COP/APF** 是能效标尺，新国标用全年性能系数 APF 综合评价。
- 制冷剂三代变迁：CFC（禁）→ HCFC（退）→ HFC（限），正转向天然工质（R290、CO₂、氨）；ODP、GWP、安全三者难兼得。
- 空调分分体/多联机、中央空调、全空气系统；湿空气处理用**焓湿图（i–d 图）**，负荷分显热与潜热。
- 制冷量 $Q_0 = \dot{m}(h_1 - h_4)$ 是「搬走的热」不是「耗电」，别拿制冷量当电功率。
- 节能三主线：高效部件、变频调节、系统级建筑能源优化。
