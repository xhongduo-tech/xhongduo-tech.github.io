## 为什么从选择性开始

前几篇我们只对付「一种反应」。现实中极少如此幸运：原料除了变成想要的产品，还会顺着别的路径变成废料。**决定一个工艺能不能赚钱的，往往不是转化率，而是「在转化了的那部分里，有多少变成了想要的东西」**——这就是选择性。环氧乙烷的装置、丙烯氧化的装置，研究的核心全是它。

Fogler 第 6 章把多重反应分成两类基本拓扑：**平行反应（parallel）**——同一原料走两条不同的路；**串联反应（series）**——产物还会继续反应掉。你将要学到的核心思想是：**反应器类型不是「越大越好」的尺寸问题，而是「如何用浓度与温度分布操纵各条反应路径相对快慢」的策略问题。**<span class="marginnote">前面《理想反应器设计》里「PFR 总比 CSTR 省体积」的结论在多重反应下必须重写：有时宁可要更大的 CSTR，因为它把副反应压得更低。设计目标从「最小体积」升级为「最优选择性」，这是反应工程思维从算数走向优化的第一次跃迁。</span>

## 1 选择性、收率与瞬时选择性

先立三把尺子。对反应体系 $\ce{A ->[\text{k}_1] D}$（想要）、$\ce{A ->[\text{k}_2] U}$（副产）：

- **收率（yield）$Y$**：进入体系的 A 中，变成 D 的分数

$$
Y = \frac{F_D}{F_{A0}}
$$

- **总选择性（overall selectivity）$\bar{S}$**：生成 D 与生成 U 的摩尔流率之比

$$
\bar{S} = \frac{F_D}{F_U}
$$

- **瞬时选择性（instantaneous selectivity）$S$**：器内某个局部，D 与 U 的生成速率之比

$$
S = \frac{r_D}{r_U}
$$

总选择性与瞬时选择性的关系是积分：$\bar{S} = \frac{\int S\,r_U\,\mathrm{d}t}{\int r_U\,\mathrm{d}t}$。<span class="marginnote">瞬时选择性是「局部的、微观的」判据，决定每一步该不该让反应发生；总选择性是「整台的、宏观的」成绩单，工程考核它。设计任务可以精炼成一句话：<strong>让整个反应器里处处都工作在瞬时选择性最高的地方。</strong></span>收率与选择性还满足恒等式 $Y = \frac{\bar{S}}{1+\bar{S}}X_A$——两者只是同一枚硬币的两面。

## 2 平行反应：级数定生死

对平行反应 $\ce{A ->[\text{k}_1] D}$、$\ce{A ->[\text{k}_2] U}$，速率方程幂律模型 $r_D = k_1C_A^{\alpha_1}$，$r_U = k_2C_A^{\alpha_2}$，瞬时选择性：

$$
S = \frac{r_D}{r_U} = \frac{k_1}{k_2}\,C_A^{\alpha_1-\alpha_2}
$$

**核心结论完全由级数差 $\alpha_1-\alpha_2$ 决定**：

- **$\alpha_1 > \alpha_2$**（想要的反应级数更高）：高浓度利于想要的反应 → **PFR（或高浓度操作）占优**，因为 PFR 保持了长程高浓度。
- **$\alpha_1 < \alpha_2$**：低浓度利于想要的反应 → **CSTR 占优**，因为 CSTR 全场保持低浓度。
- **$\alpha_1 = \alpha_2$**：浓度影响抵消，选择性与浓度无关，只受 $k_1/k_2$ 支配。

温度的影响则看活化能：$k_1/k_2 = (A_1/A_2)\exp(-(E_1-E_2)/RT)$，**若 $E_1 > E_2$，升温和利于想要的反应**；反之降温。级数决定「浓度策略」，活化能决定「温度策略」，两者正交，共同构成全部操作优化空间。<span class="marginnote">化学工程师有一句座右铭式的总结：<strong>平行反应的选择性，由「进料浓度沿器的分布」和「温度水平」两个旋钮控制</strong>。进料策略（纯进料 vs 稀释进料、分段进料）与反应器类型是浓度旋钮的两只手，后文还会再遇见。</span>

## 3 串联反应：中间体的命运

串联反应 $\ce{A ->[\text{k}_1] B ->[\text{k}_2] C}$ 里，若想要的是**中间产物 B**，事情变得微妙：B 太多时它会继续变成 C。B 的浓度必然「先升后降」，存在一个**最优时刻/位置**。对恒容间歇釜（或 PFR），B 浓度极大值出现在：

$$
t_{\max} = \frac{\ln(k_2/k_1)}{k_2 - k_1}, \qquad
\frac{C_{B,\max}}{C_{A0}} = \left(\frac{k_1}{k_2}\right)^{\frac{k_2}{k_2-k_1}}
$$

必须「在 B 达到峰值时停机/出料」。<span class="marginnote">若 $k_2 \ll k_1$，中间体稳定，$C_{B,\max}/C_{A0} \to 1$，几乎全变 B；若 $k_2 \gg k_1$，B 一出现就被吃掉，峰值很低——工业上对这类体系常用「快速移走中间体」的策略（如反应精馏把 B 边生成边蒸出）。</span>串联反应的选择性由「B 的停留时间」决定：B 在器内待得越久，越容易被第二步吃掉。

## 4 反应器选择的策略地图

把平行与串联的结论拼成一张设计地图（对「想要产物、副反应也存在」的情形）：

| 情形 | 选型 | 直觉 |
| --- | --- | --- |
| 平行，想要反应级数更高 | PFR | 保持高浓度 |
| 平行，想要反应级数更低 | CSTR | 保持低浓度 |
| 平行，级数相同 | 体积更小者 | 浓度无关 |
| 串联，想要中间体 | Batch / PFR + 适时出料 | 掐准 B 的峰值 |
| 串联，想要最终产物 | PFR 比 CSTR 好 | B 停留时间越短越好 |

**PFR 与 CSTR 在多重反应下的角色已经反转**：不再是谁体积小谁好，而是谁能把瞬时选择性「加权平均」得更高谁好。CSTR 的特长是「把一切浓度拉平到出口值」，PFR 的特长是「让浓度沿程递减」——利用哪个特长，取决于级数关系。<span class="marginnote">这张地图也是《理想反应器设计》末句「浓度分布决定一切」的直接应用：反应器的流型本质上是一种「浓度—时间经历」的制造机器，选择性工程就是设计这条经历曲线。回到主线：这与《大模型》里的「课程学习」「数据配比」思想同构——如何安排样本（浓度）的出现次序，决定模型（产物）的偏好。</span>

## 5 公式解析：平行反应选择性比

把最核心的平行选择性公式再拆一遍，$S = \frac{k_1}{k_2}C_A^{\alpha_1-\alpha_2}$：

**第一步，写出两路速率**：$r_D = k_1C_A^{\alpha_1}$，$r_U = k_2C_A^{\alpha_2}$。幂律模型来自实验标定，级数已知。
- **第二步，作比消去共同浓度**：$S = r_D/r_U = (k_1/k_2)C_A^{\alpha_1-\alpha_2}$。**共同因子 $C_A$ 并不抵消干净，只剩浓度差次方**——这一步是全部级数论断的来源。
- **第三步，读级数差**：$\alpha_1-\alpha_2 > 0$ 时 $S$ 随 $C_A$ 增大；$<0$ 时随 $C_A$ 减小；$=0$ 时与浓度无关。<span class="marginnote">注意这是「同一温度下」的结论；温度效应藏在 $k_1/k_2$ 里，由活化能差 $E_1-E_2$ 决定。两个维度要分开读、分开设计。</span>
**第四步，翻译成反应器策略**：$S$ 随浓度增大 → 用 PFR 让浓度尽量高 → 全器选择性最大化；$S$ 随浓度减小 → 用 CSTR 让浓度尽量低。

## 6 实战：两个旋钮怎么转

平行反应 $\ce{A -> D}$（$k_1 = 1.0$，$E_1 = 60\ \mathrm{kJ/mol}$，$\alpha_1 = 2$）、$\ce{A -> U}$（$k_2 = 0.5$，$E_2 = 40\ \mathrm{kJ/mol}$，$\alpha_2 = 1$），问操作策略。

**浓度旋钮**：$\alpha_1 - \alpha_2 = 1 > 0$，$S = \frac{k_1}{k_2}C_A$ 随浓度增大 → 用 PFR、保持高浓度。在 $C_A = 2$ 处 $S = 2\times2 = 4$；若稀释到 $C_A = 0.5$，$S = 1$——同一温度下，浓度策略就差了 4 倍选择性。

**温度旋钮**：$E_1 - E_2 = 20\ \mathrm{kJ/mol} > 0$，升温让 $k_1/k_2$ 指数增大 → 尽量高温操作（受热稳定性与副反应约束）。两个旋钮正交叠加：高温 + 高浓度，双管齐下。<span class="marginnote">若 $E_1 < E_2$（副反应对温度更敏感），结论反转：低温虽然总体速率慢，但选择性更高，「慢而精」常常比「快而杂」更划算——这是「转化率 vs 选择性」的核心权衡：宁可牺牲部分转化率，也要保住产品纯度，因为后处理成本通常比多烧一点原料贵得多。</span>

**辨析｜易错点：** 两个最常犯的错。其一，把「总 A 消失速率」错当「D 的生成速率」去算 $S$——$S$ 必须用 $r_D/r_U$，凡涉及总速率都要先扣除副反应路径。其二，级数相同时直接说「浓度无关」就收工——级数相同只意味着浓度旋钮失效，温度旋钮依然由活化能差驱动，不能一并忽视。

把两族拓扑组合起来就是真实工艺：**平行 + 串联的复合网络**。典型例子 $\ce{A -> D -> U}$（想要的 D 还会降解）叠加上 $\ce{A -> W}$（平行副产物）。此时选型要同时回答「浓度高不高」（平行层的级数判断）与「D 别待太久」（串联层的停留时间判断）——PFR 高浓度利于 D 的生成，但 D 沿程待在器内、被降解吃掉；CSTR 低浓度压低平行副产物，却让所有 D 都滞留到出口。两个方向打架，最优常常是「中等返混」或「多段组合」。<span class="marginnote">复合网络的完整解法需要数值求解：把各物种的摩尔衡算与速率方程联立，用《数值分析》的 ODE 求解器在给定流型下扫描操作条件。工程师的功力不在背结论，而在把「结论背后的机制」（级数差、时间尺度、返混度）拼装成正确的方程。</span>

**辨析｜易错点：** 平行反应的「浓度策略」与串联反应的「停留策略」不能分开优化后简单叠加——它们通过浓度共同耦合（D 的浓度同时受生成与降解两路控制）。任何「先定反应器再算选择性」的做法都会漏掉耦合，正确顺序是先写出全部物种的衡算，再在候选流型里求最优。

**辨析｜易错点：** 还有一个藏在温度里的耦合：级数策略与温度策略并非完全独立——改变温度会同时改变 $k_1/k_2$ 与（若反应可逆）平衡位置，浓度策略的选择（PFR/CSTR）在高温下可能反转。完整的优化必须在 $T$ 与 $X$ 的二维平面上扫描，而不是两个旋钮各调各的。

## 7 小结

- **多重反应两拓扑**：平行（同料异路）与串联（产物续变），真实体系常是两者组合。
- **三把尺子**：收率 $Y$、总选择性 $\bar{S}$、瞬时选择性 $S$；$Y = \frac{\bar{S}}{1+\bar{S}}X_A$。
- **平行反应由级数差定策略**：想要反应级数高 → PFR；低 → CSTR；相同 → 浓度无关。温度旋钮由活化能差控制。
- **串联反应要掐峰值**：中间体 B 有最优时刻，Batch/PFR 适可而止。
- **选型逻辑反转**：多重反应下反应器选择服从「瞬时选择性加权平均」而非体积最小。
