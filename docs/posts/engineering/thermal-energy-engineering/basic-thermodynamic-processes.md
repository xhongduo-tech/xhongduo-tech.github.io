## 为什么从基本热力过程开始

能量方程给了我们「账本」，工质性质给了我们「价目表」，这一节则把二者组装成四种最基本的「操作」：定压、定容、定温、绝热。锅炉里的水在定压下吸热汽化，汽轮机里的蒸汽近似绝热膨胀，空压机里的气体被绝热压缩，凝汽器里的排汽在定压下凝结——**整个热力发电厂就是这四种过程按顺序拼接成的循环**。<span class="marginnote">「把复杂系统拆成基本过程」是工程热力学的核心方法论：朗肯循环的每一个环节都能对应到本章某一条过程线，理解它们，下一节蒸汽动力循环将水到渠成。</span>这一章还首次引入**多变过程**这把万能钥匙，把所有特例收进同一个公式。

## 1 四种基本过程的状态关系

对理想气体常比热，四种过程各有一条简洁的关系：

| 过程 | 特征 | 过程方程 | 功与热的关系 |
| --- | --- | --- | --- |
| 定容 | $v$ 不变 | $p/T = \text{const}$ | $w = 0$，$q = \Delta u = c_v\Delta T$ |
| 定压 | $p$ 不变 | $v/T = \text{const}$ | $w = p(v_2 - v_1)$，$q = \Delta h = c_p\Delta T$ |
| 定温 | $T$ 不变 | $pv = \text{const}$ | $w = q = R_gT\ln(v_2/v_1)$ |
| 绝热（等熵） | $q = 0$ | $pv^\kappa = \text{const}$ | $q = 0$，$w = -\Delta u = c_v(T_1 - T_2)$ |

其中 $\kappa = c_p/c_v$ 叫**绝热指数**，空气约 1.4，过热蒸汽约 1.3。<span class="marginnote">绝热可逆过程就是等熵过程：$q=0$ 且无摩擦，熵不增不减。真实汽轮机的膨胀接近但不到等熵，工程上用「等熵效率」去打折——这是后话。</span>

**定压过程的体积功** $w = p(v_2 - v_1)$ 在 $p$-$v$ 图上就是矩形的面积，最直观。而**定温过程的功** $w = R_gT\ln(v_2/v_1)$ 是 $p = R_gT/v$ 这条等边双曲线下的面积——用积分 $\int_{v_1}^{v_2} p\,dv = \int p\,dv$ 即可推出。

**两张图各读什么**：$p$-$v$ 图上曲线下的面积是体积功；$T$-$s$ 图上曲线下的面积是热量，可逆绝热线在 $T$-$s$ 图上是一条竖直线。汽轮机绝热膨胀在 $h$-$s$ 图上是竖向焓降、在 $T$-$s$ 图上是熵不变的水平移动——**同一过程，三张图三种读法，读的却是同一件事**。

## 2 绝热过程的功：从能量方程出发

**辨析｜易错点：** 不要试图用「绝热所以没有热量」去推功。绝热过程的功来自工质自身内能的消耗：

$$
w = -\Delta u = u_1 - u_2 = c_v(T_1 - T_2) = \frac{R_g}{\kappa - 1}(T_1 - T_2)
$$

其中用到了迈耶公式 $c_v = R_g/(\kappa - 1)$。物理图景：气体绝热膨胀，对外做功消耗内能，温度下降——所以汽轮机排汽总是比进汽冷得多。反过来绝热压缩（如空压机）温度升高。**「绝热 ≠ 温度不变」，绝热对温度的影响完全由功的符号决定**，这一点初学极易混淆。

## 3 多变过程：一切过程的统一框架

把四种过程的公式收拢成一条，就是**多变过程（polytropic process）**：

$$
pv^n = \text{const}
$$

$n$ 叫**多变指数**，取特殊值就回到基本过程：$n = 0$ 定压，$n = 1$ 定温，$n = \pm\infty$ 定容，$n = \kappa$ 绝热。<span class="marginnote">真实压缩机的气体既非绝热也非定温，而是 $1 \lt  n \lt  \kappa$ 的多变过程——用 $pv^n=\text{const}$ 拟合实测数据，$n$ 由实验标定。多变过程是工程近似的地基。</span>功与热量在多变过程中各有通式，且绝热可看作 $n = \kappa$ 的特例。掌握「$n$ 决定一切」的视角，记忆负担立刻减半。

## 4 公式解析：绝热过程方程 $p_1 v_1^{\kappa} = p_2 v_2^{\kappa}$

把绝热过程在图上画出来、算出来，靠这条核心方程：

**第一步，看它是什么**：理想气体绝热可逆过程中 $pv^\kappa$ 保持常数。$\kappa = c_p/c_v$ 是物性常数，空气取 1.4。<span class="marginnote">对比定温过程 $pv = \text{const}$：绝热线在 $p$-$v$ 图上比定温线更陡，因为绝热膨胀时温度同时下降，压力跌落更快。两条线谁陡谁缓，是图考题的高频点。</span>
**第二步，导出温度关系**：把 $v = R_gT/p$ 代入消去 $v$，得 $T_1^{\kappa} p_1^{1-\kappa} = T_2^{\kappa} p_2^{1-\kappa}$，即 $T \propto p^{(\kappa-1)/\kappa}$。**绝热膨胀压力降，温度必降**。
**第三步，落到计算**：已知初态 $(p_1, T_1)$ 与终压 $p_2$，先算 $T_2 = T_1 (p_2/p_1)^{(\kappa-1)/\kappa}$，再算功 $w = c_v(T_1 - T_2)$。汽轮机里蒸汽绝热膨胀做功，走的正是这条路。

**辨析｜易错点：** 「绝热」与「等熵」常被混用。绝热只要求 $q=0$；若过程还有摩擦，熵仍会增加——绝热且不可逆 ≠ 等熵。等熵是「绝热 + 可逆」的强条件。汽轮机真实膨胀是绝热但不可逆，所以熵增、做功小于理想等熵值——用相对内效率打折，折的正是这部分「熵增代价」。

**多变指数的一线贯通**：记住了 $pv^n=\text{const}$，四种基本过程只是 $n$ 取值的特例；而真实压缩机介于定温与绝热之间，$1 \lt n \lt \kappa$，由实验标定 $n$。把「$n$ 决定一切」当作世界观，热力过程的记忆负担立刻减半。

## 5 蒸汽的基本热力过程

气体与蒸汽画在 $T$-$s$ 图上的过程形态不同：蒸汽的定压线在湿蒸汽区是水平直线（定压 = 定温），进入过热区才翘起来。对水蒸气的绝热膨胀，工程上不用 $pv^\kappa$，而是**在 $h$-$s$ 图上直接从初态竖着落到终压线**，读出的焓差就是理想做功。

对汽轮机、锅炉等设备的定量计算，统一用「设备效率」把理想过程折算成实际过程：

- **汽轮机相对内效率** $\eta_{ri} = w_{\text{实际}}/w_{\text{理想}}$：真实膨胀有摩擦与散热，做功打八到九折。
- **压气机效率** 反过来定义，$\eta_C = w_{\text{理想}}/w_{\text{实际}}$：实际耗功大于理想耗功。

<span class="marginnote">「先画理想线，再用效率打折」是整门课程的通用套路：理想过程给出理论上限，效率给出工程现实。到第四篇算发电厂热经济性时，这些效率就是煤耗数字背后的每一个百分点。</span>

## 6 小结

- 四种基本过程各有其**过程方程**：定容 $p/T=\text{const}$、定压 $v/T=\text{const}$、定温 $pv=\text{const}$、绝热 $pv^\kappa=\text{const}$。
- 绝热过程做功**消耗内能**：$w = c_v(T_1 - T_2)$，绝热膨胀降温、绝热压缩升温。
- **多变过程 $pv^n = \text{const}$** 统一全部基本过程，$n$ 取特殊值回到各特例。
- 水蒸气过程在 **$h$-$s$ 图上等熵竖落**，用设备效率打折；汽轮机理想膨胀即竖向焓降。

## 7 数值算例：绝热膨胀算一次

汽轮机里的绝热膨胀是本章最重要的应用。设初态 $(p_1=10\ \text{MPa}, T_1=500^\circ\text{C})$ 过热蒸汽（$h_1\approx3374$ kJ/kg），绝热膨胀到 $p_2=5$ kPa：

- 理想（等熵）膨胀：$h$-$s$ 图上竖落，读得 $h_{2s}\approx2160$ kJ/kg，理想做功 $w_s=h_1-h_{2s}\approx1214$ kJ/kg。
- 真实膨胀按相对内效率 $\eta_{ri}=0.88$ 打折：实际做功 $w=0.88\times1214\approx1068$ kJ/kg。

**这 1214 与 1068 的差，就是汽轮机内部的摩擦与散热损失**——「先画理想线、再用效率打折」，是汽轮机功率计算的全部套路。

再感受一下绝热压缩：空压机把空气从 $T_1=293$ K 压缩到 $p_2/p_1=8$，$\kappa=1.4$，则 $T_2=T_1\times8^{(1.4-1)/1.4}\approx293\times1.81\approx531$ K（约 258 ℃）——**绝热压缩让温度暴涨约 238 ℃**，这就是空压机必须冷却、否则机件会烧坏的原因。

## 7.5 基本热力过程术语速查

| 术语 | 含义 | 说明 |
| --- | --- | --- |
| 定容过程 | 比体积不变 | $p/T=\text{const}$，$w=0$ |
| 定压过程 | 压力不变 | $v/T=\text{const}$，$w=p\Delta v$ |
| 定温过程 | 温度不变 | $pv=\text{const}$，$w=R_gT\ln(v_2/v_1)$ |
| 绝热过程 | $q=0$ | $pv^\kappa=\text{const}$，$w=c_v(T_1-T_2)$ |
| 等熵过程 | 绝热且可逆 | 熵 $s$ 不变 |
| 绝热指数 $\kappa$ | $c_p/c_v$ | 空气约 1.4，过热蒸汽约 1.3 |
| 多变过程 | $pv^n=\text{const}$ | $n$ 取 0、1、$\kappa$、$\infty$ 回各特例 |
| 汽轮机相对内效率 $\eta_{ri}$ | 实际功/理想功 | 约 0.85～0.92 |
| 压气机效率 $\eta_C$ | 理想功/实际功 | 反向定义 |

## 8 小结

- 四种基本过程各有其**过程方程**：定容 $p/T=\text{const}$、定压 $v/T=\text{const}$、定温 $pv=\text{const}$、绝热 $pv^\kappa=\text{const}$。
- 绝热过程做功**消耗内能**：$w=c_v(T_1-T_2)$，绝热膨胀降温、绝热压缩升温。
- **多变过程 $pv^n=\text{const}$** 统一全部基本过程，$n$ 取特殊值回到各特例。
- 水蒸气过程在 **$h$-$s$ 图上等熵竖落**，用设备效率（汽轮机 $\eta_{ri}$、压气机 $\eta_C$）打折。
- 理想过程给出理论上限、效率给出工程现实——先画理想线、再用效率打折，是整门课程的通用套路。

把四种过程再串一句：**朗肯循环就是「定压加热 + 绝热膨胀 + 定压凝结 + 绝热压缩」的循环**——锅炉定压、汽轮机绝热、凝汽器定压、给水泵绝热。这一章的四种基本过程，正是下一章蒸汽动力循环的「构件库」。掌握「哪个环节对应哪个过程」，看循环图就不再是看天书。
