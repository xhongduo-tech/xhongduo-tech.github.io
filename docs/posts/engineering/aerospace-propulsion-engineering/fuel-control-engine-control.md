## 为什么从控制系统开始

发动机的物理部件再精妙，没有控制系统也只是「一堆会喘振的旋转件」。飞行员推一下油门杆，发动机要在零点几秒内增加燃油、提高转速、增大推力——但供油太快会超温烧涡轮，供油太慢又跟不上操纵，供油规律与飞行状态失配还会触发喘振。<span class="marginnote">廉小纯教材第9章把控制系统定义为「燃油调节 + 几何调节 + 安全保护」的总和：燃油调节决定功率输出，可调静叶/可调喷管决定工作点位置，超温/超转/喘振保护决定生存底线。控制是发动机「从能转变成好用」的关键一环。</span>

在第六级《控制科学与工程》中你学过 PID 与状态空间控制，这里把它们放到航空发动机这个「强非线性、快时变、多约束」的工业对象上——发动机控制是现代控制理论最有挑战性的应用舞台之一。

## 1 控制目标与控制变量

发动机控制系统要同时满足四个目标：

1. **跟随油门**：飞行员指令（油门杆角度 PLA）→ 发动机推力，响应快、无超调；
2. **安全约束**：涡轮前温度不超过极限、转子转速不超过极限、压气机不喘振、燃烧室不熄火；
3. **稳态精度**：在给定状态点，实际转速/推力与目标一致；
4. **鲁棒性**：大气条件、部件性能衰减、燃油热值变化下仍稳定。

控制变量（执行机构）包括：

**主燃油流量** $\dot{m}_f$：最核心的控制输入，直接决定功率；
**可调静叶角度（VSV）**：调节压气机进气预旋；
- **可调放气活门（VBV）**：级间放气，防喘振；
- **可调喷管喉道面积 $A_8$**：调节涡轮背压与流量匹配；
- **加力燃油流量**：加力状态的控制输入。

其中**主燃油流量是「油门」，其余是「配平」**——发动机控制本质上是一个以燃油为主、几何为辅的多变量调节问题。<span class="marginnote">早期的液压机械控制器只控燃油，几何部件靠机械联动；现代 FADEC 把燃油与几何全部纳入计算机统一调度，能同时优化「推力、喘振裕度、涡轮温度、排放」四个目标。控制变量越多，优化空间越大，但稳定性分析也越难。</span>

## 2 控制规律：从液压机械到 FADEC

**液压机械控制器（HMU）**：用凸轮、杠杆、液压伺服实现控制规律——典型的「模拟计算」。核心规律是**稳态供油规律** $\dot{m}_f = f(n, p_2^*, T_2^*)$：根据进口条件与转速查表给出供油量。

**FADEC（Full Authority Digital Engine Control，全权数字发动机控制）**：现代发动机的标准控制架构，一台嵌入式计算机实时采集转速、温度、压力、油门杆信号，用数字控制律计算所有执行机构的指令。

FADEC 的核心控制律：

**转速闭环控制**：以换算转速 $n_{cor}$ 为被控量，油门杆指令映射为目标转速，用 PID 或更先进的控制律调节供油；
**限制器保护**：在转速环外围叠加温度限制环、转速限制环、喘振裕度限制环——哪个接近极限，就由哪个环「接管」供油指令；
- **加减速计划**：加速/减速时按预设的供油计划供油，防止超温与熄火。<span class="marginnote">FADEC 的「限制器 + 主环」结构是发动机控制的经典范式：正常飞行由转速环决定供油，一旦某个安全量接近极限，限制环通过「取最小值/最大值」的逻辑压住供油。这套「min-max 选择」逻辑把多目标控制简化成一串标量比较，工程上极其稳健。</span>

## 3 防喘振与超温保护

**防喘振**：喘振是压气机的生存威胁。FADEC 防喘振手段：

**工作点监视**：实时估计压气机工作点与喘振边界的距离（喘振裕度），裕度低于阈值时，开大放气活门、前移可调静叶或减少供油；
**喘振恢复**：检测到喘振（压比跌落、转速振荡）后，立即减油、放气，把工作点拉回稳定区，再重新加速。

**超温保护**：涡轮前温度无法直接测量（太热），用**模型估计**——根据转速、压比、进口温度算出涡轮温度的估计值，超过极限就限制供油。<span class="marginnote">「测不到的物理量用模型估计」是发动机控制的一大特色：涡轮前温度 1700°C，传感器没法长期工作，只能用气动热力学模型推算。现代控制还引入<strong>气路健康监测</strong>：比较模型预测与实测的性能参数，诊断叶片磨损、堵塞等部件劣化——这就是第3篇最后一节《发动机性能试验与测试技术》里「健康管理」的雏形。</span>

## 4 公式解析：转速环与限制环

典型 FADEC 控制律可以写成一组「min-max 选择」：

$$\dot{m}_f = \min\Big( \dot{m}_{f,acc}(t),\ \dot{m}_{f,lim}(T_4^*),\ \max\big(\dot{m}_{f,idle},\ \dot{m}_{f,PLA}\big) \Big)$$

其中 $\dot{m}_{f,acc}$ 是加速供油计划，$\dot{m}_{f,lim}(T_4^*)$ 是温度限制供油，$\dot{m}_{f,PLA}$ 是油门指令供油，$\dot{m}_{f,idle}$ 是慢车供油底线。

三步拆解：

- **第一步，看内层 $\max$**：油门指令供油 $\dot{m}_{f,PLA}$ 与慢车供油 $\dot{m}_{f,idle}$ 取大者——保证任何时刻供油不低于慢车底线，防止燃烧室贫油熄火。慢车是发动机能稳定工作的最低转速状态，供油低于底线等于「掐断火苗」。
- **第二步，看外层 $\min$**：加速计划供油与温度限制供油取小者——加速时想多喷油，但温度限制环「踩刹车」，谁小听谁的。这就是限制环接管主环的方式：不是硬切断，而是「压住上限」。
- **第三步，看整体逻辑**：整条公式翻译成一句话——「在满足慢车底线的前提下，按油门计划供油，但绝不超过加速计划与温度极限允许的量」。**发动机控制的一切复杂，都折叠在这一个 min-max 选择里**：正常飞行由油门决定供油，一旦逼近安全极限，限制环立刻接管。

## 5 数值示例：限制环如何「接管」

用一个简化的数字例子感受限制环的作用。设某发动机在 90% 换算转速下：

- 油门指令对应的供油 $\dot{m}_{f,PLA} = 1.8$ kg/s；
- 加速计划允许供油 $\dot{m}_{f,acc} = 2.0$ kg/s；
- 当前涡轮温度估计值对应的限制供油 $\dot{m}_{f,lim} = 1.6$ kg/s；
- 慢车底线 $\dot{m}_{f,idle} = 0.3$ kg/s。

代入 min-max 公式：

$$\dot{m}_f = \min\big(2.0,\ 1.6,\ \max(0.3, 1.8)\big) = \min(2.0, 1.6, 1.8) = 1.6\ \text{kg/s}$$

- **第一步，看内层**：$\max(0.3, 1.8) = 1.8$——油门想让发动机烧 1.8 kg/s，慢车底线不干预。
- **第二步，看外层**：$\min(2.0, 1.6, 1.8) = 1.6$——温度限制环认为 1.6 才是极限，供油被压到 1.6。**油门杆推到再大，供油也上不去**。
- **第三步，看结果**：实际供油 1.6 < 油门需求 1.8——这就是「温度限制环接管」：推力达不到油门杆请求的满值，但涡轮保住了。飞行员会看到转速上不去、推力不足的迹象，FADEC 同时给出告警。

这道算例说明：发动机控制不是「油门杆说了算」，而是「油门与安全极限的 min-max 博弈」——**限制环是发动机安全的最后防线**。它也是理解 FADEC「限功率保护」的钥匙：民航飞行员推大油门但推力上不去，常常不是发动机坏了，而是限制环在起作用。

### 辨析：液压机械控制器与 FADEC 的可靠性之争

一些读者会问：电子控制比机械控制更可靠吗？答案并非那么简单：

| 对比项 | 液压机械控制器 | FADEC |
| --- | --- | --- |
| 计算方式 | 凸轮、杠杆的模拟计算 | 数字计算机 |
| 控制精度 | 低（受加工公差影响） | 高（可到 0.1% 转速量级） |
| 灵活性 | 改控制律要换凸轮 | 改软件即可 |
| 单点失效 | 机械磨损 | 传感器/计算机失效 |
| 冗余策略 | 少 | 双通道冗余 + 余度传感器 |

- **第一步，看时代背景**：液压机械控制器统治了 1950—1990 年代，成熟可靠；FADEC 从 1980 年代起逐步普及，靠「双通道冗余 + 自检测」把失效率压得比机械式还低——现代发动机的 FADEC 失效率远低于单台液压机械控制器。
- **第二步，看不可替代性**：现代发动机的控制规律太复杂（变循环、深度节流、健康管理），机械凸轮根本无法实现——**FADEC 不是「更可靠的机械」，而是「机械做不到的能力」**。
- **第三步，看失效模式**：FADEC 单通道失效会自动切换备份通道，再不行就切到固定供油的失效安全模式；液压机械失效则只能按固定规律「失效安全」。两者的可靠性哲学不同，但都在用「冗余」换「不失控」。

**记忆钩子**：机械控制是「雕刻」，改一刀要重做模具；数字控制是「编程」，改一行代码就行——现代发动机需要的是后者。

### 延伸与交叉引用

控制系统是发动机「性能-控制-结构」链条的指挥中枢，它与全专题的连接十分密集：

- **与整机特性的连接**：控制系统的每个设定值都来自第3篇《发动机稳态与动态特性》的特性曲线——控制不过是在「沿着特性图找最优工作点」。
- **与加力/变循环的连接**：加力燃烧室的燃油、可调喷管的面积、变循环的第三涵道开关，都是控制系统的执行机构——**没有 FADEC，加力与变循环都转不起来**（见第2篇《加力燃烧室与变循环发动机部件》）。
- **与第六级《控制科学与工程》的连接**：min-max 选择、限制器、模型估计，本质是约束优化与状态估计在工业对象上的应用——航空发动机是自动控制理论最严苛的考场之一。

控制系统把「发动机能用」提升到「发动机好用」：性能分析回答「极限在哪」，控制系统回答「如何安全地逼近极限」。理解控制，才算真正读懂了发动机的运行逻辑。

## 6 小结

- 发动机控制同时追求**跟随油门、安全约束、稳态精度与鲁棒性**四个目标，控制变量以主燃油流量为核心，几何调节（VSV、VBV、$A_8$）为辅。
- 控制规律从**液压机械**走向 **FADEC**：数字计算机统一调度燃油与几何，用「转速环 + 限制环」的 min-max 选择结构保证安全。
- 防喘振靠**工作点监视**与**喘振恢复**，超温保护靠**模型估计**涡轮前温度——测不到的物理量用模型推算，是发动机控制的一大特色。
- 控制律 $\dot{m}_f = \min(\dot{m}_{f,acc},\ \dot{m}_{f,lim},\ \max(\dot{m}_{f,idle},\ \dot{m}_{f,PLA}))$ 把多目标控制简化成串标量比较。
