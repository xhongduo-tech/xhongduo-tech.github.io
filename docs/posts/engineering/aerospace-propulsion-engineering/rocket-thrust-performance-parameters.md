## 为什么从火箭发动机开始

前三个部分讲的是**吸气式**发动机：它们靠空气提供氧化剂，所以不能飞出大气层。火箭发动机则完全自带燃料与氧化剂（统称**推进剂**），不依赖外界空气——因此它既能在大气层内工作，也能在真空中工作，是人类进入太空的唯一动力。<span class="marginnote">「吸气式 vs 火箭式」是推进世界的第一分水岭：吸气式发动机的优势是氧化剂免费（空气），劣势是不能高空与入轨；火箭发动机的优势是自带氧化剂、真空可用，劣势是必须把氧化剂也扛上天。两者各守自己的任务域——大气层内飞行用吸气式，入轨与深空用火箭。</span>

本节从《液体火箭发动机原理》第1章出发，建立火箭发动机的性能参数体系。它与你已学的航空发动机性能参数同源（推力、比冲），但有一系列「火箭特有」的新概念。

## 1 火箭发动机的分类与基本构成

按推进剂能量来源与工质形态，火箭发动机主要分三类：

**化学火箭**：燃料与氧化剂发生化学反应放热，工质是燃烧产物。再按推进剂相态分**液体火箭**（液氧/煤油、液氧/液氢等）、**固体火箭**（药柱装填）与**混合火箭**（固液结合）；
**电火箭**（电推进）：用电能把工质加速喷出，推力小但比冲极高，用于在轨机动；
- **核火箭**（概念）：用核反应加热工质，比冲高于化学火箭。

化学液体火箭发动机的核心部件：**推力室**（喷注器 + 燃烧室 + 喷管）、**涡轮泵**（增压输送燃料）、**贮箱**与**阀门**。

火箭与航空发动机的根本区别：**没有旋转的压气机与涡轮的气动耦合**（液体火箭有涡轮泵，但那是给推进剂增压，不是给空气增压）；燃烧室压力直接决定喷管膨胀比；推力靠「自带工质高速喷出」获得。<span class="marginnote">液体火箭发动机的涡轮泵与航空发动机的涡轮是完全不同的角色：航空发动机的涡轮是「从燃气抽功去转压气机」，是热力循环的一部分；火箭的涡轮泵是「用一小股高温燃气（或燃气发生器/预燃室产物）驱动泵，把推进剂打进燃烧室」，它是辅助设备，不参与主推进循环的「做功」。这个区别是理解火箭系统的关键。</span>

## 2 推力与有效排气速度

火箭发动机的推力公式与航空发动机同源，但工质是自带推进剂：

$$F = \dot{m} V_e + A_e (p_e - p_a)$$

其中 $\dot{m}$ 是推进剂质量流量，$V_e$ 是喷管出口速度，$A_e$ 是出口面积，$p_e$ 与 $p_a$ 是出口与环境压力。

**重要区别**：火箭推力与飞行速度无关——它不吞空气，没有冲压效应；推力随高度变化只因为环境压力 $p_a$ 减小（真空时 $p_a=0$，压力项最大，推力最大）。**同一台火箭发动机，真空推力比海平面推力大约大 10%–20%**。<span class="marginnote">火箭「飞行速度不改变推力」是它区别于吸气式发动机的显著标志：涡扇在地面静止时推力最大，飞得越快冲压越强；火箭在真空里推力最大，与速度无关。这使火箭的性能分析比吸气式简单——不需要速度特性与高度特性的复杂耦合，只需按环境压力修正。</span>

**有效排气速度**（characteristic exhaust velocity）$\bar{c} = V_e + \frac{A_e(p_e - p_a)}{\dot{m}}$：把压力项折算成速度，则 $F = \dot{m} \bar{c}$。真空中 $\bar{c} = V_e$。

## 3 比冲：火箭的「油耗率」

**比冲（specific impulse）** $I_{sp}$ 是火箭性能最核心的指标：

$$I_{sp} = \frac{F}{\dot{m} g_0} = \frac{\bar{c}}{g_0}$$

其中 $g_0 = 9.81$ m/s² 是海平面标准重力加速度。<span class="marginnote">比冲的单位是「秒」，物理含义是「1 kg 推进剂能产生多大推力的时间积分」——更直白地说，<strong>比冲就是喷流速度除以 g₀</strong>。为什么除以 g₀？纯粹为了把单位换成「秒」，让数字更直观。比冲越高，同样多的推进剂能给出更多的速度增量，航天任务中比冲直接决定运载效率。</span>

典型比冲（真空）：

| 推进剂组合 | 真空比冲 (s) |
| --- | --- |
| 固液/固体复合推进剂 | 250–300 |
| 液氧/煤油（RP-1） | 310–340 |
| 液氧/甲烷 | 340–370 |
| 液氧/液氢 | 420–460 |
| 电推进（离子） | 2000–8000+ |

**比冲与排气速度的关系**：$I_{sp} = V_e/g_0$（真空、完全膨胀）。比冲越高 = 喷流越快 = 同样推进剂换更多速度增量。

## 4 公式解析：齐奥尔科夫斯基方程

火箭的性能最终由齐奥尔科夫斯基方程（火箭方程）统治：

$$\Delta V = I_{sp} \, g_0 \, \ln\frac{m_0}{m_f} = \bar{c} \, \ln\frac{m_0}{m_f}$$

- **第一步，看变量**：$\Delta V$ 是火箭获得的速度增量，$m_0$ 是起飞质量，$m_f$ 是推进剂烧完后的质量（结构+有效载荷），$m_0/m_f$ 称**质量比**。
- **第二步，看对数**：速度增量与质量比的对数成正比——**想要翻倍 $\Delta V$，质量比要指数级增大**。这是火箭工程的「暴政」：入轨需要 $\Delta V \approx 9.3$ km/s，对应的质量比约 20:1（靠多级火箭分摊）。<span class="marginnote">火箭方程揭示了多级火箭的必要性：单级火箭要把 9.3 km/s 的 ΔV 一次做完，需要质量比 e^(9.3/4.5) ≈ 8，而单级结构加有效载荷往往超过这个承受极限。把火箭分成多级，每级烧完就扔掉死重，等效质量比大幅提高——这就是所有运载火箭都是多级的根本原因。</span>
**第三步，看设计含义**：提高 $\Delta V$ 有两条路——提高比冲 $I_{sp}$（换更好的推进剂）或提高质量比 $m_0/m_f$（减轻结构重量）。**工程上两条路同时走**：液氢比冲最高但密度低（贮箱大而重），煤油密度高但比冲低，所以现实中两级/三级火箭常混用不同推进剂。

## 5 火箭的性能参数族

除比冲外，火箭发动机还有一组常用性能参数：

**推力质量比**（推重比）$T/W$：地面起飞要求推重比 > 1（航天飞机约 1.5）；
- **推进剂质量分数** $\zeta = m_p / m_0$：推进剂占起飞质量的比例，越高越好（典型 0.85–0.93）；
- **特征速度 $c^*$**：衡量燃烧室推进剂能量转化效率，$c^* = p_c A_t / \dot{m}$（$p_c$ 燃烧室压力，$A_t$ 喉道面积），只与燃烧室与推进剂有关，与喷管无关；
- **推力系数 $C_F$**：$C_F = F/(p_c A_t)$，衡量喷管把燃烧室压力转为推力的效率——$C_F$ 只与喷管膨胀比与环境压力有关。

特征速度与推力系数把发动机拆成两个独立环节：**燃烧室产气（$c^*$）× 喷管加速（$C_F$）**，$F = p_c A_t C_F$，$I_{sp} = c^* C_F / g_0$。<span class="marginnote">$F = p_c A_t C_F$ 是火箭发动机设计的「总公式」：燃烧室压力 × 喉道面积 × 推力系数。要提高推力，要么提高燃烧室压力（涡轮泵的功率），要么增大喉道面积（更大的发动机），要么优化喷管（更高的 $C_F$）。这三个旋钮对应三条完全不同的工程路线。</span>

## 6 数值示例：火箭方程的成本

用齐奥尔科夫斯基方程感受「质量比的暴政」。设某上面级发动机真空比冲 $I_{sp} = 450$ s（液氧/液氢），$g_0 = 9.81$ m/s²，有效排气速度 $\bar{c} = 4415$ m/s。

**问题一：要获得 3 km/s 的速度增量，需要多大质量比？**

$$\frac{m_0}{m_f} = e^{\Delta V / \bar{c}} = e^{3000/4415} = e^{0.68} \approx 1.97$$

即起飞质量约是推进剂烧完后质量的 2 倍——**近一半质量是推进剂**，还算温和。

**问题二：要获得入轨速度 7.9 km/s（单级），需要多大质量比？**

$$\frac{m_0}{m_f} = e^{7900/4415} = e^{1.79} \approx 5.99$$

单级入轨需要近 6 倍质量比，即结构+载荷只占 1/6——几乎不可能（单级火箭结构质量通常就占 8%–15%）。

- **第一步，看对数暴政**：$\Delta V$ 从 3 km/s 涨到 7.9 km/s（2.6 倍），质量比从 1.97 涨到 5.99（3 倍）——**速度增量线性增长，质量比指数增长**。
- **第二步，看多级火箭的解**：把 7.9 km/s 拆成两三级，每级质量比只需 2–3，总起飞质量反而远小于单级——**分级是绕过质量比暴政的唯一工程出路**。
- **第三步，看推进剂选择**：若改用比冲 300 s 的固体（$\bar{c}=2943$ m/s），入轨单级质量比要 $e^{2.68} \approx 14.6$——更不可能。**比冲直接决定质量比需求**，这就是火箭界拼命追高比冲的数学根源。

### 辨析：比冲与推力的「鱼与熊掌」

火箭性能参数里，比冲与推力常被误以为越高越好，其实两者方向常相反：

- **第一步，看定义差**：推力是「瞬间力的大小」，比冲是「单位推进剂能换多少速度」——一个看「猛不猛」，一个看「省不省」。
- **第二步，看电推进的反例**：电推进比冲高达数千秒，但推力只有牛顿级——加速极慢，只适合已在轨的卫星做姿态与轨道保持。**高比冲不能替代推力**，两者必须匹配任务。
- **第三步，看设计取舍**：同一发动机里，提高推力（增大流量/压力）往往伴随比冲下降（膨胀不完全）；工程上按任务选——**运载火箭起飞段要推力，上面级与深空要比冲**，这就是为什么第一级与上面级常用不同推进剂。

**记忆钩子**：推力决定「能不能起飞」，比冲决定「能飞多远」——起飞看推力，奔月看比冲。

## 7 小结

- 火箭发动机**自带氧化剂**，不依赖空气，是入轨与深空的唯一动力；分化学、电、核三大类。
- 推力 $F = \dot{m}\bar{c}$，**真空推力比海平面大 10%–20%**，且与飞行速度无关——这是与吸气式发动机的根本区别。
- **比冲** $I_{sp} = \bar{c}/g_0$ 是火箭性能核心指标：液氧/液氢 420–460 s 最高，煤油 310–340 s，固体 250–300 s。
- **齐奥尔科夫斯基方程** $\Delta V = I_{sp}g_0\ln(m_0/m_f)$ 揭示质量比的「对数暴政」，是多级火箭的物理根源。
- 性能参数族：特征速度 $c^*$（燃烧室）× 推力系数 $C_F$（喷管），$F = p_c A_t C_F$
