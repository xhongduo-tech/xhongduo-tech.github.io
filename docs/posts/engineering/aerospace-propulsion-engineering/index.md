# 航空宇航推进理论与工程（航空发动机）

以航空燃气涡轮发动机与液体、固体火箭发动机为主线，系统覆盖从热力循环、部件气动热力设计到发动机控制、结构强度与试验验证的完整推进技术体系，是飞行器动力装置总体设计与发动机研发的核心学科。

## 对标教材

- 廉小纯、吴虎《航空燃气轮机原理》（国防工业出版社）
- Jack D. Mattingly《Aircraft Engine Design》(AIAA Education)
- 《液体火箭发动机原理》（国防工业出版社）
