## 为什么从焊接冶金基础开始

前面几讲把铸造、锻压、轧制、挤压这些「成形」工艺讲完了，这一讲进入焊接分支的起点——**焊接冶金**。焊接与铸造共享同一套凝固物理：熔池是微型的铸件，但它的凝固速度比任何铸件都快、加热冷却都比任何热处理更剧烈。这一讲回答「焊缝为什么会是这个样子」「热影响区为什么是薄弱环节」两个根本问题。<span class="marginnote">焊接冶金的独特性在于「三快」：加热极快（电弧加热升温速率可达每秒上千度）、凝固极快（熔池在几秒内凝固）、冷却极快（热影响区经历快速淬火式冷却）。这三快把普通材料的相变规律全部压缩到极限状态。</span>

在课程体系里，这一讲把《焊接冶金与焊接热过程》的核心收拢成一条主线，为后续《焊接方法与工艺》《焊接结构质量控制》提供冶金依据——为什么高碳钢难焊、为什么热影响区要预热、为什么焊缝会偏析，答案都在这一讲的熔池与热影响区里。<span class="marginnote">焊接冶金的底子正是本专题第一篇《液态金属成形原理》的凝固理论：同样的形核、成分过冷、枝晶生长、偏析，只是尺度缩小到毫米、冷速放大到每秒几百度——把凝固理论「迁移」到焊接，就是焊接冶金。</span>

与铸造、锻压相比，焊接还有一个不可回避的特点——**它永远成对出现**：焊接接头必然由「两件母材 + 熔入的焊材 + 集中的热输入」构成，而这三者在成分、组织、性能上不可能完全一致。所以焊接工程师处理的是「差异与过渡」，而不是「均一的理想材料」——理解这种「差异的必然性」，是理解一切焊接问题的前提。

## 1 焊接热过程与热循环

焊接的本质是**局部加热**：热源（电弧、激光、电子束）集中在接头处，把局部金属加热到熔化，同时把周围金属加热到不同程度。焊接的**热循环**用「加热—峰值温度—冷却」三个参数描述，峰值温度随离焊缝距离的增加而衰减——这就是热影响区组织的分层来源。<span class="marginnote">热循环的定量指标是<strong>焊接热输入</strong> $E = \eta UI/v$（有效功率除以焊接速度），热输入越大，峰值温度越高、冷却越慢。控制热输入是焊接工艺设计的第一旋钮：热输入大，焊缝深、冷却慢（利于淬硬倾向小的钢）；热输入小，冷速快（利于小变形）。</span>

热循环曲线的经典判据是**冷却时间 $t_{8/5}$**：热影响区从 800 ℃ 冷却到 500 ℃ 所用的时间。这一小段正是钢种发生相变（奥氏体分解）的温度区间，$t_{8/5}$ 直接决定冷却后是贝氏体、马氏体还是铁素体珠光体——**$t_{8/5}$ 越长，淬硬越轻、冷裂风险越低，但晶粒越粗、强度越低**。焊接工艺评定（WPS）里，$t_{8/5}$ 就是那个「把冷速钉住」的指标。<span class="marginnote">$t_{8/5}$ 的物理直觉：8→5 是钢在珠光体/贝氏体/马氏体转变区的「十字路口」，在这个温度段停留多久，决定了组织往哪条路走。焊接模拟软件（见《加工过程模拟与智能化》）算温度场，首要输出就是 $t_{8/5}$ 分布——它是冶金与数值模拟之间的桥梁。</span>

热循环的**冷却速度**是焊接冶金的关键变量：对低合金钢，峰值温度后的冷却速度决定能否得到马氏体（淬硬）、会不会冷裂。现场常靠**预热**控制冷却速度——把母材先加热到 100–250 ℃，减少热影响区的温度梯度，让冷却变慢、避免淬硬组织。<span class="marginnote">预热不是「锦上添花」而是「生死攸关」：厚板、高碳当量钢不预热直接焊，热影响区冷速快、生成马氏体、应力集中处立刻开裂——冷裂纹是焊接最危险的缺陷，因为它在焊后数小时甚至数天才出现，可能整条焊缝一夜之间断裂。</span>

焊接的**接头形式**是热过程的前提：**对接接头**（板边对齐、受力最均匀）、**角接/T 形接头**（两板成直角、焊缝在角部）、**搭接接头**（两板重叠、受力偏心但装配容易）、**端接接头**。不同的接头形式，熔池的形状、热影响区的分布、应力的集中程度都不同——其中角接与搭接的**应力集中**明显高于对接，是疲劳失效的高发区。<span class="marginnote">对接接头为什么是首选？因为它受力时载荷沿板平面传递、应力流线最顺畅，应力集中系数接近 1；而角接的应力集中在焊缝根部、搭接在焊缝端部。设计「能对接就不搭接、能全焊透就不角焊」，是焊接结构设计的第一条铁律。</span>

焊接热过程还有一个全局性的后果——**残余应力与变形**。局部加热 → 熔池收缩 → 母材被拉弯：焊缝冷却收缩受母材拘束，焊后结构里留下**焊接残余应力**（受拉），同时整体发生**收缩变形、角变形、翘曲**。残余应力让构件「内伤」，变形让构件「走样」——两者都是《焊接结构质量控制》要专门对付的对象，但它们的根源都在本讲的焊接热过程里。<span class="marginnote">残余应力与变形的取舍很微妙：完全消除变形往往以增大拘束、抬高残余应力为代价，完全消除应力又可能放宽变形。「先控变形、后控应力，或者按结构功能排序」——焊接结构的调校是在两个坏苹果里挑没那么坏的一个。</span>

## 2 熔池凝固与焊缝组织

电弧把母材与焊材熔化成**熔池**，电弧移开后熔池在极短时间内凝固成焊缝。熔池凝固与铸件凝固同源，但有三个不同：

**第一，快速定向凝固**。熔池依附在未熔化的母材晶粒上凝固，母材晶粒直接「外延生长」进熔池——焊缝的柱状晶是从母材继承方向的，没有激冷层。<span class="marginnote">外延凝固是焊缝特有的：母材晶粒成为熔池的「种子」，柱状晶沿着热流方向（从熔池边界向中心）竞争生长。这也意味着——焊缝晶粒粗大、取向单一，是焊接接头力学性能的先天短板。</span>

**第二，快速凝固带来的偏析**。凝固速度快，枝晶间溶质富集严重，焊缝中心形成**中心偏析带**——碳、硫、磷等杂质聚集在焊缝中心，成为裂纹的起点。改善手段靠**焊丝成分**（低杂质、加 Ti、B 细化晶粒）与**工艺参数**（多层多道焊让后一道把前一道的偏析带重熔、打散）。

焊接冶金还有一个铸造没有的环节——**焊材与熔池的化学反应**。焊条药皮、焊剂、保护气在熔池中参与冶金反应：**脱氧**（把熔池中的氧化物还原、生成渣上浮）、**合金过渡**（药皮/焊丝中的合金元素进入熔池、调整焊缝成分）、**脱硫磷**（降低杂质）。所以焊材不只是「提供填充金属」，更是一个移动的「微型冶金炉」——焊材牌号的变化，本质上是在改变焊缝的冶金结果。<span class="marginnote">这也是为什么「选焊材 = 选焊缝冶金」：E50 与 E60 焊条，不只是强度等级不同，药皮成分、脱氧能力、可焊性都不同。焊材的烘烤（焊条使用前 350–400 ℃ 烘干）就是为了除去药皮中的水分——水分是焊缝氢的来源，是冷裂纹的燃料。</span>

**第三，保护**。熔池高温液态金属极易与空气反应——吸氧、吸氮。所以一切电弧焊都必须**保护熔池**：焊条药皮造渣、保护气（CO₂、Ar）隔离空气、埋弧焊的焊剂覆盖。保护失败，焊缝就大量吸气、生成气孔与氧化物夹杂。<span class="marginnote">氮是焊缝的隐性杀手：焊缝吸氮会使强度升高而塑性、韧性骤降，还会导致时效硬化与气孔。所以「焊缝保护不严」不是小瑕疵，而是直接报废级别的质量事故。</span>

焊缝的**成形**也由凝固决定：熔池的宽深比（熔宽与熔深之比）取决于热源能量密度——电弧焊能量密度较低、熔池浅而宽；激光焊能量密度极高、熔池深而窄。熔深不足造成**未熔合**（焊缝与母材没焊在一起）、熔宽不足造成**咬边**（母材边缘被熔出一个缺口）。焊缝成形的理想状态是「熔透均匀、余高适中、无咬边」——它是冶金、参数与操作的共同产物。

## 3 热影响区组织演变：母材的「淬火实验」

紧挨焊缝的母材虽然没有熔化，但经历了剧烈的热循环，组织被重新改变——这片区域叫**热影响区（HAZ，Heat-Affected Zone）**。按峰值温度从高到低，热影响区分成几层：

**熔合区**：焊缝与母材的交界，是「半熔化区」，成分与组织过渡，晶粒粗大，是最薄弱环节——裂纹常在此萌生。

**过热区**：峰值温度在 1100 ℃ 到熔点之间，晶粒严重粗化，冷却后形成粗大的过热组织，塑性韧性显著下降。<span class="marginnote">过热区是热影响区里性能最差的区域——粗晶 + 淬硬组织 + 残余应力三者叠加。对低合金高强度钢，过热区往往是整个接头冲击韧性的下限，也是冷裂纹的优先发源地。</span>

**正火区**：峰值温度在 900–1100 ℃，发生了完全奥氏体化再冷却，晶粒细化，组织较细，性能接近甚至优于母材——这是热影响区里「因祸得福」的一层。

**不完全相变区**：峰值温度在 Ac1–Ac3 之间，部分组织相变，晶粒大小不均，性能不均。

**再结晶区与回火区**：冷变形的母材发生再结晶软化，或已淬火的母材被回火。

把这些区域合起来，就理解了「焊接接头 = 焊缝 + 熔合区 + 热影响区 + 母材」的四元结构，而**热影响区的存在，使焊接接头永远不可能像母材一样均匀**——这是焊接结构设计的根本约束。<span class="marginnote">热影响区宽度一般只有几毫米，却决定了整个接头的性能下限。工程上用「焊接接头性能」而不是「焊缝性能」来验收，就是因为接头是一个不均匀的整体，最弱的一环（熔合区/过热区）决定整体。</span>

对抗热影响区劣化的武器之一是**多层多道焊**：厚板焊缝不用一道焊完，而是一道接一道地填——后一道焊接的热循环对前一道的焊缝及热影响区相当于一次**回火**，粗晶组织被细化、硬度被调低，整个接头的韧性反而提升。这就是为什么同样厚度的板，「一道深熔焊」往往不如「多层多道焊」的接头性能好——**用热循环做热处理，是焊接工艺的一项隐性技能**。<span class="marginnote">但多层多道焊也有代价：道间清理（每道要除渣、清飞溅）、层间温度控制（层间温度过高，回火效果减弱）、以及每道都有的缺陷风险叠加。工程上「几道焊完、层间温度多少」是焊评（焊接工艺评定）里明文规定的参数。</span>

不同材料的热影响区「脾气」各不相同，这构成材料焊接冶金的主要内容：**低碳钢**热影响区问题小、可焊性最好；**低合金高强钢**怕淬硬与冷裂纹，靠预热与控氢；**不锈钢**怕晶间腐蚀（铬在晶界析出、晶界贫铬）与热裂纹，靠低碳/稳定化元素与控热输入；**铝合金**怕氧化膜与气孔，靠惰性气体保护与严格清理。每一种「难焊材料」的难处，都对应一条热影响区或熔池的冶金规律。<span class="marginnote">304 不锈钢的「晶间腐蚀」是经典难题：在 450–850 ℃ 的敏化温度区间停留，碳与铬结合在晶界析出碳化铬、晶界附近贫铬，腐蚀沿晶界发展。对策是降碳（304L）或加稳定化元素钛、铌（321、347）——「把碳管住」是不锈钢焊接冶金的第一课。</span>

## 4 冷裂纹倾向与碳当量

焊接最大的隐患是**冷裂纹（cold cracking）**，也称**氢致延迟裂纹**：焊后冷却到低温时，热影响区在**淬硬组织 + 氢 + 拘束应力**三要素同时满足时开裂。它有三个特征：发生在焊后数小时到数天（延迟性）、沿热影响区扩展（位置性）、与氢含量直接相关（氢致性）。<span class="marginnote">冷裂纹三要素是焊接界的「三条腿」：淬硬（成分与冷速决定）、氢（焊材与潮湿决定）、拘束应力（结构刚度决定）。缺一条腿就不裂，所以防冷裂纹也是三管齐下：预热控冷速、低氢焊材、合理装配顺序。</span>

衡量钢种淬硬倾向（冷裂纹敏感性）的常用指标是**碳当量**（详见公式解析）。碳当量越高，越容易淬硬、越需要预热——这是焊接工艺规程里「要不要预热、预热多少度」的判定依据。低合金高强钢的碳当量一般在 0.35–0.5 之间，碳当量超过 0.4 通常就要求预热了。<span class="marginnote">碳当量的工程用法：碳当量 < 0.35 一般不需预热；0.35–0.5 需酌情预热；> 0.5 必须预热并配合低氢工艺。碳当量还关联到「可焊性」评级——它是把材料成分翻译成焊接工艺参数的第一座桥梁。</span>

焊后还有一道治本的手段——**焊后热处理（PWHT，Post-Weld Heat Treatment）**，典型做法是**焊后消氢**与**焊后消除应力退火**。消氢（150–200 ℃ 保温数小时）让氢从焊缝中扩散逸出，掐断冷裂纹的「氢」这条腿；消应力退火（550–650 ℃，按板厚保温）让残余应力松弛、过热区组织回火——两者都是「焊后补一刀」，专治焊接的先天缺陷。<span class="marginnote">消应力退火对厚板压力容器几乎是强制要求：焊后残余应力与工作应力叠加，可能让应力腐蚀或疲劳提前失效。不过 PWHT 也有代价——成本高、周期长，还可能软化母材的调质组织，所以「该做才做、能不做就不做」靠规范判定，不能凭感觉。</span>

## 5 公式解析：碳当量

冷裂纹敏感性的第一定量工具是**国际焊接学会（IIW）推荐的碳当量公式**：

$$
CE = C + \frac{Mn}{6} + \frac{Cr + Mo + V}{5} + \frac{Ni + Cu}{15}
$$

（各元素均为质量百分数。）拆三步理解：

- **第一步，看各元素的权重**：碳的权重最高（系数 1），因为碳对淬硬性的影响最大；Mn 的系数 1/6，Cr/Mo/V 为 1/5，Ni/Cu 为 1/15——各元素对淬硬倾向的贡献按系数加权，越权重大越敏感。
- **第二步，算一个例子**：Q345（16Mn）钢，成分约为 C 0.16%、Mn 1.4%、Si 0.4%（Si 不计入此式）、少量 Cr/Ni，则 $CE \approx 0.16 + 1.4/6 \approx 0.39$。处于「需考虑预热」区间——所以 16Mn 厚板焊接规程都要求预热或控制热输入。<span class="marginnote">反过来看：为什么低碳钢（C < 0.25%、CE 低）可以直接焊而不预热？因为它的 CE 低，冷却再快也淬不硬、形不成马氏体——「低碳 = 天生抗冷裂」是焊接选材的第一直觉。</span>
- **第三步，与工艺挂钩**：不同标准给出的「临界碳当量」略有差异，但工程逻辑一致——**CE 每升高 0.1，所需的预热温度大约升高 30–50 ℃**。碳当量不是精确预言，而是「要不要小心、小心到什么程度」的快捷指南；精确的冷裂纹判据还有**冷裂纹敏感指数 Pcm**（日本学者提出，更强调碳与氢），用于要求更高的场合。<span class="marginnote">Pcm 公式为 $P_{cm} = C + Si/30 + (Mn+Cu+Cr)/20 + Ni/60 + Mo/15 + V/10 + 5B$，适用于含微量合金的低碳钢。工程上 CE 用于中高碳钢定性分级，Pcm 用于精细判定——两条线配合使用。</span>

## 6 易错辨析

**辨析｜易错点：** 最常见的误区是把**热裂纹**与**冷裂纹**混为一谈。热裂纹发生在**高温下**（凝固末期），机理是凝固收缩应力超过晶间液态膜的强度，沿柱状晶界开裂，多出现在焊缝中心，开裂面呈氧化色；冷裂纹发生在**低温下**（焊后冷却到 200 ℃ 以下乃至室温后），机理是淬硬 + 氢 + 拘束应力，多沿热影响区扩展，开裂面呈金属光泽。**一个「热」在焊缝中心、一个「冷」在热影响区，对策也完全不同**——热裂纹靠控制杂质与焊缝成形，冷裂纹靠预热、低氢与应力释放。<span class="marginnote">还有一个经典区分：热裂纹「边焊边裂」、冷裂纹「焊后延迟裂」。所以焊完验收不能只焊完当时看——冷裂纹要在 24–48 小时后复查，这就是焊接质量检验要「过夜后再探伤」的原因，见《焊接结构质量控制》。</span>

第二个误区是「焊缝比母材强，接头就强」。焊缝金属往往经过合金化与快速凝固，强度可以超过母材；但**接头的薄弱环节是熔合区与热影响区的过热区**——那里晶粒粗大、可能有淬硬组织，冲击韧性显著下降。所以「焊缝强度高于母材」≠「接头强度高于母材」，焊接结构的失效几乎都发生在热影响区或熔合区，而不是焊缝本身。<span class="marginnote">这引出一个设计原则——<strong>等强匹配</strong>：焊材强度不必高于母材太多（否则热影响区应力集中更严重），一般选强度略低、塑性较好的焊材「以柔克刚」，让变形发生在焊缝而非脆化的热影响区。</span>

第三处容易出错的是把「预热」当成只对厚板有用。预热对小板、薄板同样有作用，只是薄板冷速本来就快但散热面积也大、拘束小，风险相对低；而**厚板**拘束大、散热路径长、冷速不均，预热几乎成为必需。判断依据是碳当量与板厚联合决定——「厚板要预热、高碳当量要预热、两者都占更必须预热」。

## 7 小结

- 焊接冶金的独特在「三快」：加热极快、凝固极快、冷却极快，把相变规律压缩到极限状态。
- **焊接热输入 $E = \eta UI/v$** 与预热是控制热循环冷速的两个旋钮，冷速决定淬硬倾向与冷裂纹。
- **冷却时间 $t_{8/5}$** 是焊接热循环的核心判据，钉住 800→500 ℃ 段的停留时间即钉住组织与冷裂风险。
- 熔池凝固是「微缩的快速铸造」：外延凝固、粗大柱状晶、中心偏析带是焊缝的先天短板。
- **热影响区（HAZ）**按峰值温度分层，熔合区与过热区最薄弱，接头性能由最弱一环决定。
- **冷裂纹 = 淬硬组织 + 氢 + 拘束应力**三要素同时满足，延迟出现在焊后数小时到数天。
- **碳当量 CE = C + Mn/6 + (Cr+Mo+V)/5 + (Ni+Cu)/15** 是冷裂纹敏感性的第一判据，CE 高就预热。
- 热裂纹在高温、沿柱状晶界、在焊缝中心；冷裂纹在低温、沿热影响区、焊后延迟——对策完全不同。
- 接头强度由最弱一环（熔合区/过热区）决定，焊材常选「强度略低、塑性较好」以柔克刚。
- 多层多道焊用后道热循环给前道「回火」，是改善接头韧性的隐性技能。
- 材料焊接冶金：低碳钢可焊性最好、高强钢控氢、不锈钢控碳、铝合金控氧化膜。
- 焊后热处理分消氢与消应力退火两档，是「焊后补一刀」的治本手段。
- 焊后热处理（消氢、消应力退火）是治本手段，厚板压力容器几乎强制要求。
- 焊接残余应力与变形同源于焊接热过程，是《焊接结构质量控制》要专门对付的全局性后果。
- 不同材料的热影响区脾气不同：低碳钢最好焊、高强钢怕冷裂、不锈钢怕晶间腐蚀、铝怕气孔。
- 焊材是「移动的微型冶金炉」：药皮的脱氧、合金过渡与除氢决定焊缝的冶金结果。
