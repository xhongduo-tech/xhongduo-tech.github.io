# 材料加工工程（焊接/铸造/锻压/热处理）

材料加工工程是研究材料从坯料到制品的成形、改性与连接全过程的学科，涵盖焊接、铸造、金属塑性成形（锻压）、热处理与粉末冶金五大工艺体系，是连接材料科学设计与工程应用的核心纽带。掌握各工艺的原理、方法与质量控制，才能把材料的性能可靠地转化为工程构件。

## 对标教材

- 《焊接手册》（中国机械工程学会焊接分会，机械工业出版社）
- 《铸造手册》（中国机械工程学会铸造分会，机械工业出版社）
- 吕炎《金属塑性成形原理》（机械工业出版社）
- 《热处理手册》（中国机械工程学会热处理分会，机械工业出版社）
- 黄培云《粉末冶金原理》（冶金工业出版社）
