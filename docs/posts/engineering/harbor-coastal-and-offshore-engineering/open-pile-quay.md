## 为什么从高桩码头开始

如果重力式码头是「坐」在海里，板桩码头是「立」在土里，那么**高桩码头（open-pile / piled quay）**就是「站」在海里：一排排桩从海底立起，把一块码头面高高托起，波浪从桩间自由穿过。<span class="marginnote">「透空」是高桩码头区别于所有实体码头的最本质特征：墙没了，换成腿。波浪与水流从桩间穿过，不形成强反射、不拦阻水流，泊稳与防淤都更有利。代价是结构从「连续墙」变成「框架」，受力体系完全改写。</span>

高桩码头是现代深水港与软基海区的主流选择：水深越大，重力式越贵、板桩越难；而桩总能打到持力层，把荷载交给深处的好土。它也是我国南方海区、长江口、珠江口码头的当家型式。从力学上看，高桩码头是「桩基工程 + 梁板结构」的组合：竖向荷载由桩的轴向承载力扛，水平荷载由直桩抗弯与斜桩轴压分扛——一改前两式的「土压力主导」。

## 1 结构组成：桩、梁、板、靠船件

一座高桩码头从下到上由三部分组成：

**① 桩基（pile foundation）**：把荷载传向深部地层的构件。按材料与工艺分：

**预应力混凝土管桩（PHC 管桩）**：造价低、承载力高、耐久好，是高桩码头的绝对主力；
**钢管桩**：抗弯强、适应深水与硬土穿透，用于大直径、大水平力或嵌岩场合；
- **灌注桩**：现场成孔浇筑，适应复杂地层，但施工慢、质量控制难。

按受力方向分**直桩（vertical pile）**与**斜桩（raker / battered pile）**：直桩以承受竖向荷载为主，斜桩（与竖直方向成 10°–20° 夹角）专门承受水平力。

**② 上部结构（superstructure / deck）**：由**面板**、**纵梁与横梁**（构成梁格）、**桩帽**组成，把桩顶连成整体、形成码头作业面。上部结构可以是现浇、预制拼装或「预制 + 现浇叠合」，是码头「行走、堆货、跑车」的舞台。

**③ 靠船与系船设施**：护舷（fender）、系船柱（bollard）、防冲桩等，安装在码头前沿，承受并传递船舶荷载。

此外还有**接岸结构（shore connection）**：码头面与后方陆域之间的连接，常为挡土墙、引桥或斜坡道，处理「码头高、陆域低」的衔接与岸坡稳定。<span class="marginnote">高桩码头还有一个容易被忽略但致命的构造问题——<strong>码头面与后方回填之间的沉降差</strong>。桩基沉降小、填土沉降大，若两者硬接，接岸处会「拉裂」。所以接岸结构通常做成能适应差异沉降的形式（铰接、设置沉降缝、先填后沉），这是高桩码头设计中「细节决定成败」的一处典型。</span>

## 2 桩基承载力：把荷载交到深部

单根桩的竖向承载力，由**桩侧摩阻力**与**桩端阻力**两部分组成：

$$
Q_u = U \sum_{i} f_i l_i + q_p A_p
$$

- $U$：桩的截面周长；$f_i$：第 $i$ 层土的单位侧摩阻力；$l_i$：第 $i$ 层土中桩段长度；
- $q_p$：桩端单位端阻力；$A_p$：桩端面积。

**摩擦桩**主要靠侧摩阻力（软土层厚、端阻力小），**端承桩**主要靠端阻力（桩端落在坚硬持力层上）。PHC 管桩通常既打穿软土、又把端部打入密实砂层或岩面，两者兼得。单桩承载力按公式估算后，还必须用**静载荷试验（桩基检测）**验证——打试桩、分级加载、测沉降，是港口桩基工程的「终极裁判」。<span class="marginnote">「公式估算 + 静载试验验证」是桩基设计的标准双轨：估算给设计选型，试验给施工验收。静载试验加载量常取设计承载力的 1.5–2 倍，以「沉降与回弹」判定单桩承载力——这和材料试验一样，是「设计有理论、验收靠实测」的工程闭环。</span>

**桩群效应**值得一提：多根桩距离很近时，桩间土相互影响，群桩承载力不等于单桩之和，且受弯时各桩内力不均匀分配。设计中常用「排架（bent）—桩基平台」整体分析，把上部结构梁格与桩基一起算，而非一根根孤立计算。

## 3 水平力：直桩抗弯与斜桩分力

高桩码头要扛的水平力不少：船舶撞击力、系缆力、风浪流力、地震力。这些力传到桩顶，由两类桩分扛：

**直桩**：靠**桩身弯曲刚度**抵抗水平力——桩像一根插在土里的「悬臂弹簧」，水平位移带动桩周土体被动抗力，靠「土弹性抗力 + 桩抗弯」共同工作；
**斜桩**：把水平力转化为**轴向力**——斜桩与竖直方向成夹角，水平力在斜桩轴向上产生分量，由桩的轴压（或轴拉）能力承担，效率远高于直桩抗弯。

因此高桩码头通常布置成**直桩 + 斜桩混合排架**：竖向荷载由直桩挑大梁，水平荷载由斜桩「斜着顶住」——斜桩是码头抗水平力的「主力队员」。<span class="marginnote">斜桩的力学效率是直桩的数倍：直桩抗水平力靠弯曲（材料利用率低、位移大），斜桩抗水平力靠轴压（材料全截面受力、位移小）。所以地震区、强浪区的码头几乎必设斜桩，斜桩的夹角、方向（分叉斜桩/八字桩）是排架设计的核心内容。</span>

直桩的水平承载力计算常用**弹性地基梁法（m 法）**：把桩周土对桩的水平抗力近似为随深度线性增长的弹簧，桩成为一根「竖放的弹性地基梁」，求出桩身弯矩与水平位移。这一方法把「桩—土相互作用」简化成弹簧模型，是桩基水平承载力最常用的实用算法。<span class="marginnote">m 法（弹性抗力系数随深度线性增长）是中国桩基规范的当家方法：它把复杂的桩—土接触用一个随深度增长的弹簧刚度 $m z$ 近似，桩便成了四阶常微分方程 $\frac{d^4y}{dx^4} + \frac{mz}{EI}y = 0$ 的解——从土力学到微分方程，一根桩串起两门课。</span>

## 4 波浪透空与泊稳：高桩码头的水动力性格

高桩码头的「透空」给它带来独特的水动力优势，也带来独特的限制：

**透浪不反射**：波浪从桩间穿过，墙前不形成驻波，泊稳条件好、反射小——这对大浪区码头是显著优势；
**桩间流速**：桩基使过水断面收窄、流速增大，可能引起桩周局部冲刷，需在桩间与桩周铺设护底块石；
- **码头面高程与梁底净空**：大浪时波浪可能顶托码头底板（波浪上托力），码头面下的横梁、管线需高于设计高水位加波高，否则波峰拍打梁底，产生上托冲击力。<span class="marginnote">「梁底净空」是高桩码头的一个隐藏设计点：梁底若浸入波峰以下，每次大浪都是一次「拍打底板」的冲击，长期下来混凝土会疲劳开裂。设计取「设计高水位 + 设计波高 + 富余」作为梁底控制高程——高桩码头看似透空，梁底高程却是与风浪较量的硬指标。</span>

## 5 公式解析：单桩轴向承载力

把高桩码头的「腿力」拆开：

$$
Q_u = U \sum f_i l_i + q_p A_p
$$

- **第一项（桩侧摩阻力）**：$U \sum f_i l_i$，桩身表面与土之间的摩擦力之和。软土层的 $f_i$ 小、密实砂与黏土层的 $f_i$ 大；桩越长、穿过的好土层越多，这项越大。摩擦桩的承载力几乎全部来自这一项。
- **第二项（桩端阻力）**：$q_p A_p$，桩端土体的支承力。端承桩的承载力几乎全部来自这一项；对管桩，$A_p$ 是桩端环形面积（中空），但端部常封口或带桩靴以利用全断面。
- **两个变量的物理**：摩阻力管「侧面包裹」，端阻力管「底部支托」。同一根桩，软土中摩阻力主导（摩擦桩），打到岩面则端阻力主导（端承桩）——**同一根桩，用「摩擦」还是「端承」完全取决于地层**。

设计时用 $Q_u$ 除以安全系数得**单桩容许承载力** $[Q] = Q_u / K$（$K$ 常取 2–3），再分配到每根桩的设计轴力。上部结构的竖向荷载（自重 + 堆货 + 机械）通过梁格传到桩顶，要求每根桩的轴力 $N_i \leq [Q]$。<span class="marginnote">对比三种码头：重力式把荷载「摊」在基床面积上（面承载），板桩把荷载「传」给地基嵌固与锚碇（墙承载），高桩把荷载「点」在桩端与桩侧（点承载）。「面、墙、点」三种传力方式，对应三种截然不同的结构哲学——这是本专题码头部分最好的提纲挈领。</span>

### 高桩码头的耐久性：海洋环境的隐形敌人

高桩码头长期浸泡在海水与潮差环境中，耐久性问题比陆上结构严峻得多。**氯离子侵蚀**是最主要的病害：氯离子随海水渗入混凝土、到达钢筋表面并破坏钝化膜，使钢筋锈蚀膨胀、混凝土顺筋开裂。锈蚀开裂在**浪溅区**（潮位以上被浪花溅湿的区段）最严重——那里干湿交替、供氧充足，是氯离子与氧气的「联合作战区」。

耐久性对策有一套组合拳：

- **混凝土**：提高强度等级与抗渗性、加大保护层厚度、掺入矿物掺合料（粉煤灰、矿粉）、采用环氧涂层钢筋或阻锈剂；
- **钢管桩**：防腐涂层 + **阴极保护**双保险——涂层隔离海水，阴极保护（牺牲阳极或外加电流）使钢管成为阴极、不再锈蚀；
- **监测**：在关键桩位埋设腐蚀传感器，定期检测钢筋电位与氯离子含量，做到「锈蚀未露先处理」。

钢桩的**海生物附着**是一笔长期账：藤壶、牡蛎附着会增加桩径、加大波浪力与水流力，需定期清理；但附着层又为海洋生物提供生境——「清多少、留多少」正成为可持续港口运营的新课题。高桩码头的寿命账，一半在结构计算里，一半在耐久性维护里。

### 高桩码头的施工流程

高桩码头的施工有清晰的先后链条，每一步都决定下一步的质量：

1. **沉桩**：用锤击、静压或振动设备把 PHC 管桩/钢管桩打（压）到设计深度。沉桩的质量控制看三样：桩位偏差（一般控制在数厘米内）、桩身完整性（打桩应力不超限、桩不裂）、贯入度（最后几锤的贯入量达到停锤标准）；
2. **截桩与桩帽**：按设计高程截去多余的桩头，浇筑桩帽把桩顶连成整体，桩帽是「单桩 → 整体」的第一道联结；
3. **上部结构吊装**：预制横梁、纵梁、面板依次吊装就位，现浇接头把它们连成梁格；
4. **面层与附属设施**：现浇码头面层、安装护舷与系船柱、铺设管线与面层附属。

**施工期波浪防护**是高桩码头特有的问题：桩基尚未连成整体时，单根桩抗浪能力弱，常需临时拉缆、限时施工；上部结构吊装也只在风浪窗口期进行。高桩码头的工期，同样是一段「与波浪窗口赛跑」的时间表。

## 6 小结

- **高桩码头**由桩基、上部结构（面板 + 梁格 + 桩帽）、靠船系船设施与接岸结构组成，以「透空」区别于实体码头。
- 桩基分**摩擦桩/端承桩**、**直桩/斜桩**；单桩承载力 $Q_u = U\sum f_i l_i + q_p A_p$
