## 为什么从数控开始

上一课的 PLC 在「开关」的世界里工作：通/断、有/无。但制造的核心动作是**刀具与工件之间的相对运动**——走直线、走圆弧、切多深。把「开关的世界」升级为「坐标的世界」，正是**数控（Numerical Control, NC）**的使命。<span class="marginnote">阿达 · 洛夫莱斯在 19 世纪就预见到：机器能执行的，正是我们写入程序的指令序列。数控机床把这句话变成了每天运转的工业现实。</span> 数控是本专题从「单元控制」跨向「精密制造」的桥，也是后面机器人（同源的运动学）、柔性制造（多台数控联网）的地基。

## 1 什么是数控

**数控（NC）**：用记录在程序中的**数字指令**控制机床运动的自动化技术。1949 年，美国空军与 MIT 合作，用打孔纸带上的数字指令驱动铣床加工直升机叶片，这是世界上第一台数控机床。之后计算机替代纸带，就有了 **CNC（Computer Numerical Control）**——现代数控的代名词。<span class="marginnote">纸带→磁带的进化史，本质是「指令的载体」从物理介质变成内存程序。这个演变与软件行业从打孔卡到文件的演变完全同步。</span>

数控机床由四部分构成：**程序输入装置**（现代是键盘/网络）、**控制器（CNC）**、**伺服驱动与电机**、**机床本体**。控制器读入程序，把每条指令翻译成伺服轴的位移与速度指令，机床就按坐标运动。

## 2 坐标系与两类运动

数控的语言是**坐标系**。以铣床为例，$X$、$Y$ 轴是工作台的平面运动，$Z$ 轴垂直向下进刀。围绕三个轴的旋转自由度记作 $A$、$B$、$C$。<span class="marginnote">坐标轴的定义（右手定则、$Z$ 轴沿主轴方向）有国际标准，是数控与机器人共同的语言。第二级《线性代数》里的坐标变换矩阵，在这里是实打实的工装。</span>

按运动控制方式，数控分两类：

**点位控制（point-to-point）**：只关心终点坐标，中间路径不重要。典型是**数控钻床**——钻头从一点快速移到下一点，途中不切削。
- **轮廓控制（contouring）**：要求刀具沿指定路径连续运动并同时切削。典型是铣削、车削的斜线、圆弧加工。轮廓控制需要**插补器（interpolator）**。

**重点：插补是数控的引擎。** 刀具路径由直线与圆弧组成，而控制只能一步步发脉冲。插补器把一段路径「切」成极短的微段，逐段逼近真实曲线——直线插补在微段间走直线，圆弧插补按圆弧方程算中间点。切得越细，逼近越准。

两类运动的关键差别：

| 维度 | 点位控制 | 轮廓控制 |
| --- | --- | --- |
| 途中是否切削 | 不切削 | 连续切削 |
| 中间路径 | 不重要 | 必须精确 |
| 需不需要插补 | 不需要 | 需要 |
| 典型机床 | 钻床、点焊 | 铣床、车床、磨床 |
| 编程关注点 | 终点坐标 | 完整轨迹 |

这张表的用途是选型：只钻孔、只打点，点位控制足够便宜；要走斜面、走圆弧、车螺纹，就必须上轮廓控制。

## 3 数控编程：写「刀具的路书」

程序是逐条指令序列。以最通用的 **G 代码**为例：

```
N10  G90  G21  G54          ; 绝对坐标，公制，选工件坐标系
N20  G00  X10.0  Y20.0      ; 快速定位到点 (10, 20)
N30  G01  Z-5.0  F150.0     ; 直线进给下刀，进给 150 mm/min
N40  G01  X50.0  Y60.0      ; 直线切削至 (50, 60)
N50  G02  X70.0  Y40.0  R20.0  ; 顺时针圆弧，半径 20
N60  G00  Z50.0             ; 快速抬刀
N70  M05  M30               ; 主轴停，程序结束
```

**G 代码是准备功能，M 代码是辅助功能**：G 管「怎么动」（G01 直线插补、G02/G03 圆弧、G00 快速定位、G90/G91 绝对/增量坐标），M 管「机床的动作」（M03 主轴正转、M05 主轴停、M08 开冷却液、M30 程序结束）。

编程方式三条路：

- **手工编程（manual part programming）**：人逐条写出 G 代码。简单零件够用。
- **计算机辅助编程（APT 语言等）**：用高级语言描述几何，由计算机生成刀轨。APT 是第一代刀具语言。
- **CAM 编程**：在 CAD 图形上直接选面选边，CAM 软件自动算刀轨、自动生成 G 代码——这是现代主流，也是从「人写指令」到「软件写指令」的质变。<span class="marginnote">CAM 背后是几何计算与路径规划算法，这类「自动规划」的思想与机器人路径规划、乃至大模型里的推理规划同源，只是域不同。</span>

## 4 公式解析：主轴转速与加工时间

编程时最常算的两个数：主轴该转多快、这个面要切多久。

**主轴转速**由切削速度换算而来：

$$
N = \frac{1000 \, v}{\pi D}
$$

- **第一步，$v$ 是切削速度**（单位 m/min）：由工件材料与刀具材料查表得出，例如铝合金铣削常用 200–400 m/min，而硬质合金车削钢件约 100–200 m/min。
- **第二步，$D$ 是切削直径**（单位 mm）：铣刀取刀具直径，车削取工件直径。
- **第三步，$N$ 是主轴转速**（单位 r/min）：分子乘 1000 是为了统一 m 与 mm 两个单位。

**加工时间**是进给量的函数：

$$
T_m = \frac{L}{f_r}, \qquad f_r = f_t \cdot z \cdot N
$$

其中 $L$ 是走刀长度，$f_r$ 是进给速度（mm/min），$f_t$ 是每齿进给量，$z$ 是铣刀齿数。<span class="marginnote">转速与进给联立求解：选高转速想快，但要先问刀具耐不耐温、机床刚性够不够。参数选择的本质是「材料去除率」与「刀具寿命」的交换。</span>

**两个数字例子**——先算转速：铣削铝合金，取 $v = 300$ m/min，直径 $D = 20$ mm 的立铣刀：

$$N = \frac{1000 \times 300}{\pi \times 20} = \frac{300000}{62.83} \approx 4775 \text{ r/min}$$

主轴约 4775 r/min。再算加工时间：沿第 3 节 G 代码里的那条直线，$L = 100$ mm，进给 $f_r = 150$ mm/min：

$$T_m = \frac{100}{150} = 0.67 \text{ min} \approx 40 \text{ s}$$

两式联起来读：转速由「材料决定」、时间由「进给决定」，而进给又由「转速 × 每齿进给 × 齿数」决定——三个参数互相咬合，改一个就要重算一串，这正是 CAM 软件替你干的事。

**辨析｜易错点：** 绝对坐标（G90）与增量坐标（G91）是入门第一坑——G90 的每个坐标都是相对工件原点，G91 是相对上一点。混用会直接撞刀。另一个高频误区：**G00 不是切削速度的「快」，而是快速定位**，途中不保证路径，不能用于切削；拿 G00 走刀等于拿快递车送货途中闯工地。还有一处：**插补 ≠ 精加工本身**，插补只是「走」，精度还取决于机床刚性、热变形与刀具磨损——数控给了你精度的可能性，不给保证。

## 5 术语速查：读懂一张数控程序

把数控世界的常用词收进一张表，读程序时随时对照：

| 术语/代码 | 含义 |
| --- | --- |
| G00 | 快速定位（不切削） |
| G01 | 直线插补（切削） |
| G02/G03 | 顺时针/逆时针圆弧插补 |
| G90/G91 | 绝对坐标 / 增量坐标 |
| M03/M05 | 主轴正转 / 主轴停 |
| M08/M09 | 冷却液开 / 关 |
| 插补器 | 把连续路径切成微段的计算单元 |
| 刀补 | 刀具半径补偿，按刀径自动偏移路径 |
| 对刀 | 建立刀具与工件坐标系的相对关系 |

**辨析｜易错点：** 「对刀」与「编程」是两套坐标系的事——程序里的坐标属于**工件坐标系（G54）**，而刀具的实际位置属于**机床坐标系**；对刀就是把两者对齐。初学者常在程序里写「绝对坐标」，却忘了先对刀，结果坐标全部偏移——这也是「G90 混用」之外的第二大撞刀来源。

## 6 小结

- **数控** = 用数字指令控制机床运动；现代形态是 **CNC**，由输入、控制器、伺服、机床本体四部分组成。
- 运动分**点位控制**（只管终点）与**轮廓控制**（连续路径）；轮廓控制靠**插补器**逐段逼近。
- 编程语言分 **G 代码（运动）** 与 **M 代码（机床动作）**；编程演进路线：手工 → APT → CAM。
- 两个必算参数：主轴转速 $N = 1000v/(\pi D)$ 与加工时间 $T_m = L/f_r$；算例：$v=300$、$D=20$ → 4775 r/min。
- 易错三连：**G90/G91 混用、G00 当切削、把插补当精度保证**。

在下一节，我们让数控那套「坐标系 + 插补 + 编程」的思想从机床里跳出来，装进一台有手有腕的机器里——这就是**工业机器人应用**。
