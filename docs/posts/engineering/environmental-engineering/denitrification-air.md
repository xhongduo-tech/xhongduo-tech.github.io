## 为什么从脱硝开始

氮氧化物（$\ce{NO_x}$，主要是 $\ce{NO}$ 与 $\ce{NO2}$）是燃煤电厂、机动车与工业窑炉排放的关键污染物：它是**光化学烟雾**（《环境化学》已述）与**酸雨**的共同前体，还参与生成 PM2.5 中的硝酸盐。与 $\ce{SO2}$ 不同，$\ce{NO}$ 化学性质稳定、难溶于水，脱硝比脱硫更棘手——需要高温催化反应把 $\ce{NO_x}$ 还原成无害的氮气。这一节讲清脱硝的两条路线（还原与氧化）、主流工艺 SCR/SNCR，以及它与《脱硫技术》在治理链中的协同位置。<span class="marginnote">$\ce{NO}$ 的「难」在于它是热力学稳定的自由基分子：常温下既不溶于水、也不易与碱反应——所以脱硝不能像脱硫那样「水洗」，必须靠还原反应把它变回 $\ce{N2}$。这是「脱硫易、脱硝难」的化学根源。</span>

## 1 氮氧化物的生成与危害

**生成机理**（燃烧过程）分三类，理解它才知道怎么从源头控制：

**热力型（thermal NO）**：高温（> 1300°C）下空气中的 $\ce{N2}$ 与 $\ce{O2}$ 直接反应——温度越高、生成越多，**控制手段是降低燃烧温度**（分级燃烧、低氮燃烧器）。
**快速型（prompt NO）**：富燃料火焰中碳氢自由基与 $\ce{N2}$ 快速反应，通常占比小。
**燃料型（fuel NO）**：燃料中的含氮化合物（煤、油中的吡啶、胺类）在燃烧中转化——**燃煤锅炉氮氧化物主要来源（60%～80%）**，控制靠燃料脱氮与低氮燃烧。<span class="marginnote">源头控制是脱硝的「第一道防线」：低氮燃烧器、分级配风、再燃技术可把 $\ce{NO_x}$ 降低 30%～50%——比末端脱硝便宜得多。但源头控制有极限，要达到超低排放仍需末端 SCR——「源头减量 + 末端还原」双管齐下。</span>

**危害**：$\ce{NO_x}$ 参与光化学烟雾（与 VOCs 反应生成臭氧）、酸雨（生成硝酸）、PM2.5 硝酸盐；$\ce{NO2}$ 本身刺激呼吸道。排放标准对 $\ce{NO_x}$ 的限值越来越严（燃煤电厂超低排放 < 50 mg/m³）。

**辨析｜易错点：** 三类 $\ce{NO_x}$ 生成机理的「温度画像」不同——热力型与燃烧温度强相关（温度越高越多），燃料型只与燃料含氮量相关。所以**降低燃烧温度能压热力型、换低氮燃料才能压燃料型**，手段不能混用。燃煤锅炉以燃料型为主（60%～80%），单纯靠「降温」压不下来，必须上燃料脱氮与 SCR——**先认准主要机理，再选控制手段**，这是脱硝的第一判断。

## 2 主流工艺：SCR 选择性催化还原

**SCR（selective catalytic reduction，选择性催化还原）** 是当今最主流的脱硝技术：以氨（$\ce{NH3}$）为还原剂，在催化剂表面把 $\ce{NO_x}$ 选择性地还原为 $\ce{N2}$：

$$\ce{4NO + 4NH3 + O2 -> 4N2 + 6H2O}$$

$$\ce{2NO2 + 4NH3 + O2 -> 3N2 + 6H2O}$$

关键在「**选择性**」：催化剂让 $\ce{NH3}$ 只与 $\ce{NO_x}$ 反应，而不与烟气中的 $\ce{O2}$ 大量反应（$\ce{NH3}$ 若被 $\ce{O2}$ 氧化就浪费了）。催化剂是钒钛系（$\ce{V2O5-WO3/TiO2}$）等，活性温度窗约 300～420°C。<span class="marginnote">SCR 的「催化剂」是核心资产：反应把 $\ce{NO_x}$ 还原需要催化剂把 $\ce{NH3}$ 吸附活化，温度太高催化剂烧结失活、温度太低反应太慢——所以 SCR 反应器要布置在烟气温度合适的省煤器后、除尘脱硫之前，这是「位置决定成败」的经典。</span>

**SCR 系统组成**：氨站（液氨/尿素制氨）→ 喷氨格栅（均匀混合 $\ce{NH3}$ 与烟气）→ 催化反应器（多层催化剂）→ 出口监测。核心运行指标是**脱硝率**与**氨逃逸**。

**还原剂的「氨源」之选**：液氨（便宜、纯度高，但属重大危险源）、尿素（安全、需热解制氨，是新建项目的趋势）、氨水（居中）。**液氨运输与储存的安全风险**是《环境应急管理》的重点监管对象——尿素法用「安全换便利」，是近年替代液氨的主流方向，也体现「安全优先」的工程伦理。

## 3 公式解析：SCR 脱硝率与氨逃逸

SCR 的脱硝率受**氨氮摩尔比（NSR）**控制，把它拆成三步：

- **第一步，化学计量**：按反应式，1 mol $\ce{NO}$ 需 1 mol $\ce{NH3}$——理论氨氮比 NSR = 1。实际运行中因混合不均与副反应，需略过量喷氨。
- **第二步，脱硝率与 NSR**：理想均匀混合下，脱硝率近似等于喷入的氨与 $\ce{NO_x}$ 之比：

$$\eta_{NO_x} = \frac{n_{\ce{NH3}}}{n_{\ce{NO_x}}} \times \text{修正系数}$$

工程上 **NSR 每提高一档，脱硝率上升但氨逃逸也上升**——喷氨过量，多余的 $\ce{NH3}$ 穿过催化剂逸出（氨逃逸），带来新问题。
- **第三步，氨逃逸的连锁反应**：逃逸氨与烟气中的 $\ce{SO3}$、$\ce{H2O}$ 反应生成**硫酸氢铵（ABS）**——一种黏稠物，会堵塞空预器与催化剂孔道，**这是 SCR 运行最头疼的副反应**。所以氨逃逸必须控制在 3 μL/L 以下。

**工程调参**：脱硝率与氨逃逸是「跷跷板」——**喷氨越多，脱硝率越高但氨逃逸越大**。控制目标是「脱硝率达标且氨逃逸最小」，靠喷氨格栅的均匀混合（把氨喷匀是关键）与催化剂的活化管理。<span class="marginnote">SCR 的「喷氨均匀性」是灵魂：同一截面氨浓度分布不均，氨多的地方逃逸、氨少的地方 $\ce{NO_x}$ 穿透——所以喷氨格栅要配流场优化（导流板、静态混合器），运行中用网格监测修正。老运行员常说「SCR 的问题一半在流场」。</span>

**算例：脱硝率与氨逃逸的平衡。** 某电厂 $\ce{NO_x}$ 入口浓度 400 mg/m³，要求出口 ≤ 50 mg/m³（超低排放），则脱硝率需 $\geq (400-50)/400 = 87.5\%$。按 NSR 估算需喷氨略高于理论量（NSR ≈ 0.95～1.0，考虑混合不均）。**关键在平衡**：NSR 提到 1.05，脱硝率冲到 92% 但氨逃逸升到 5 μL/L 以上，超标（限值 3 μL/L），逃逸氨在空预器生成硫酸氢铵堵塞——**「为了多压 4% 的 $\ce{NO_x}$ 而毁掉空预器，得不偿失」**。所以运行优化是在「达标脱硝率」与「氨逃逸红线」之间找那个最优喷氨量，靠出口网格监测实时修正。

## 4 其他脱硝技术

**（1）SNCR 选择性非催化还原**：不装催化剂，直接把尿素/氨喷入炉膛高温区（850～1100°C），靠高温热分解出 $\ce{NH3}$ 自由基还原 $\ce{NO_x}$。**脱硝率低（30%～60%）、对温度窗口敏感**，但投资省、改造方便，常用于中小锅炉或与 SCR 串联（SNCR + SCR 组合：SNCR 粗脱硝 + SCR 精把关）。<span class="marginnote">SNCR 的温度窗口「窄而苛刻」：温度太低（< 800°C）反应太慢，温度太高（> 1100°C）氨被氧化回 $\ce{NO_x}$（反而增排）——窗口中心约 950°C。炉内温度随负荷波动，喷氨位置要跟随调整，这是 SNCR 运行的艺术。</span>

**（2）低氮燃烧**（源头）：低氮燃烧器、空气分级、燃料分级——把 $\ce{NO_x}$ 生成压下去，与末端 SCR 配合实现超低排放。

**（3）氧化法脱硝**：臭氧氧化 $\ce{NO}$ 为易溶的 $\ce{NO2}$、$\ce{N2O5}$，再用碱液吸收——用于湿法脱硫塔的**臭氧协同脱硝**，可同时脱硫脱硝，但臭氧发生能耗高。

**（4）活性焦/催化法**：活性焦吸附 $\ce{SO2}$ 与 $\ce{NO_x}$ 协同脱除，无水、可同时脱硫脱硝除尘，用于缺水或严苛场合。

**脱硝技术的选型框架**：大机组（烟气量大、要求高）选 SCR；中小锅炉（投资敏感）选 SNCR 或 SNCR+SCR；对温度窗口敏感或改造受限的选低氮燃烧 + 尾部补充；缺水或严苛场合选活性焦。**选型的两个硬约束是烟气温度与空间**——SCR 要占高温段位置，改造老机组常因「没有合适位置放反应器」而改选其他路线。

## 5 脱硫脱硝除尘的协同治理

燃煤烟气治理链的完整图景（衔接上一节《脱硫技术》）：

$$\text{锅炉} \to \text{SCR（脱硝，300°C 段）} \to \text{空预器} \to \text{除尘（袋式/电除尘）} \to \text{湿法脱硫} \to \text{湿电（精除尘）} \to \text{烟囱}$$

**协同要点**：
- **位置匹配**：SCR 要高温段（催化剂活性窗），脱硫在尾部（低温段），除尘在中间——**SCR 污染（$\ce{NH3}$ 逃逸、ABS 生成）必须靠脱硫塔吸收尾氨**。
- **粉尘的影响**：烟气含尘会磨蚀催化剂、堵塞孔道——高尘 SCR 要防磨与定期清灰，或采用低尘布置。
- **催化剂寿命**：催化剂中毒（$\ce{As}$、碱金属）与磨损决定更换周期，是 SCR 运行成本的大头。<span class="marginnote">SCR 催化剂的「失活史」：物理堵塞（飞灰）→ 化学中毒（砷、碱金属）→ 热烧结（超温）——催化剂活性逐年下降，到 60% 左右需加装新层或更换。催化剂的再生（清洗、再浸渍）是近年兴起的循环经济业务，一块板再生成本远低于新购。</span>

**脱硫脱硝一体化趋势**：为降本增效，研发方向是**同一装置同时脱硫脱硝**——臭氧氧化 + 湿法吸收（脱硫塔兼脱硝）、活性焦协同、等离子体氧化等，把「三脱」合成一塔，减少占地与投资。

**脱硝的监测与自动控制**：出口设 $\ce{NO_x}$ 与氨在线监测（CEMS），喷氨量由「出口 $\ce{NO_x}$ 反馈 + 入口 $\ce{NO_x}$ 前馈」自动调节——**入口波动大时，前馈让喷氨跟上变化，反馈把氨逃逸压住**。这套「前馈 + 反馈」控制逻辑，与《环境监测方法》的在线监测、《污水处理厂设计》的自动控制一脉相承，是脱硝稳定达标的「软件保障」。<span class="marginnote">「一塔三脱」的诱惑与挑战：把脱硝并入脱硫塔省设备省占地，但 $\ce{NO_x}$ 氧化为硝酸盐后进入脱硫浆液，氯离子与硝酸根富集会腐蚀设备、影响石膏品质——工程权衡至今没有完美答案，这也是烟气治理技术仍在演进的原因。</span>

## 术语速查

| 术语 | 一句话定义 |
| --- | --- |
| NOx | 氮氧化物，主要是 NO 与 NO2 |
| 热力型 / 快速型 / 燃料型 NO | 按生成机理分的三类氮氧化物 |
| SCR | 选择性催化还原，氨在催化剂上还原 NOx |
| SNCR | 选择性非催化还原，炉膛高温区喷氨 |
| NSR | 氨氮摩尔比，理论值为 1 |
| 脱硝率 | 被还原的 NOx 占入口的比例 |
| 氨逃逸 | 未反应的氨穿过催化剂逸出 |
| 硫酸氢铵 ABS | 逃逸氨与 SO3 生成的黏稠堵塞物 |
| 低氮燃烧 | 燃烧段控制 NOx 生成的源头技术 |

**记忆锚点**：把脱硝想成「给 NOx 请个还原者」——氨是还原者，催化剂是「撮合者」（SCR），炉膛高温是「撮合者」（SNCR）。**撮合得好（选择性好），NOx 变 N2；撮合过头（氨过量），多出的氨就变成 ABS 堵路**。一条线串起 SCR、氨逃逸与堵孔道三个概念。

## 6 小结

- $\ce{NO_x}$ 危害：**光化学烟雾、酸雨、PM2.5 硝酸盐**；$\ce{NO}$ 稳定难溶，脱硝靠还原而非水洗。
- 生成三类：**热力型、快速型、燃料型**；源头低氮燃烧是第一道防线。
- **SCR** 是主流：氨在催化剂上选择性还原 $\ce{NO_x}$，脱硝率 80%～95%，活性窗 300～420°C。
- **脱硝率与氨逃逸是跷跷板**：喷氨越多脱硝越高但逃逸越大，逃逸氨生成硫酸氢铵堵孔道。
- **SNCR** 投资省、效率低，常与 SCR 组合；治理链「**SCR → 除尘 → 脱硫 → 湿电**」全链协同。
- 催化剂是 SCR 的核心资产：**堵塞、中毒、烧结**三段失活史决定更换周期，再生业务应运而生。
- 记住总纲：**源头低氮燃烧减量、SCR 末端把关、SNCR 补充、氨逃逸红线**——四条线撑起脱硝全貌。
- **算例启示**：达标脱硝率与氨逃逸红线之间要「够用就好」，为压 4% 而毁空预器得不偿失。
- **一塔三脱**是趋势：臭氧氧化 + 湿法吸收把脱硫脱硝合进一塔，但硝酸根富集腐蚀是待解难题。
- **氨源三选**：液氨便宜但属重大危险源，尿素安全是趋势——「安全换便利」体现工程伦理。
- **前馈 + 反馈**的喷氨自动控制，是脱硝稳定达标的「软件保障」。
