## 为什么从焚烧开始

在土地资源紧张的城市，填埋已难以为继——**焚烧**成了垃圾处理的主攻方向。焚烧的优势是「数量级」的：**减容 80%～90%、减重 70%～80%**，1 吨垃圾变成 0.2 吨灰渣，同时高温彻底消灭病原体与有机毒物，还能**回收余热发电**。但它也是最「双刃剑」的技术：焚烧产生烟气（颗粒物、酸性气体、重金属、二噁英）与飞灰（危废）——**「烧得好是能源厂，烧不好是污染源」**。这一节讲焚烧的化学原理、炉型与烟气净化，与《大气污染控制》的除尘脱硫脱硝、《固废分类》的热值、《温室气体》的低碳转型直接相连。<span class="marginnote">焚烧的地位演变：从「填埋为主」到「焚烧为主」是城市垃圾处理的必然转型——尤其土地紧张、热值提升（分类后厨余减少）之后，焚烧兼具减量与能源化的双重价值，已成为我国大中型城市的主选。</span>

## 1 焚烧的化学原理

焚烧是**高温氧化**：垃圾中的可燃物与氧反应，有机物彻底矿化为 $\ce{CO2}$ 与 $\ce{H2O}$，无机物变成灰渣。核心反应：

$$\ce{C（有机物）+ O2 -> CO2 + 热量}, \qquad \ce{2H + 1/2O2 -> H2O + 热量}$$

**燃烧的「三要素」**：可燃物、助燃物（氧）、着火温度——缺一不可。焚烧工程就是**维持三要素、保证燃烧完全**：

- **温度**：炉膛温度一般 > 850°C（我国标准要求炉膛温度 ≥ 850°C、烟气停留 ≥ 2 秒——**这是分解二噁英等持久性有机物的工程红线**）。
- **过量空气**：提供充足氧气，一般过量空气系数 1.5～2.0，保证完全燃烧。
- **湍流混合**：让垃圾、空气、烟气充分混合，避免局部缺氧产生不完全燃烧产物。<span class="marginnote">「3T+E」是焚烧工程的行话：Temperature（温度）、Time（停留时间）、Turbulence（湍流）加 Excess oxygen（过量氧）——四要素共同保证「燃烧完全、二噁英分解」。任何一项不足，不完全燃烧产物（黑烟、二噁英）就冒出来。850°C/2s 就是对「3T+E」的量化规定。</span>

**燃烧过程分阶段**：干燥（蒸发水分）→ 热解（挥发分析出）→ 燃烧（挥发分与固定碳燃烧）→ 燃尽（灰渣）。垃圾含水率高时干燥耗热大、热值被拉低——所以《固废分类》里厨余多的垃圾焚烧「难烧」。

## 2 焚烧炉的主要类型

**炉排炉（机械炉排炉）**——当今主流，适用于**未经预处理的混合生活垃圾**：
- 垃圾在倾斜炉排上边移动边燃烧，炉排逐段推进（干燥段 → 燃烧段 → 燃尽段）。
- 底部配风、炉膛高温、燃烧稳定，**处理量大、适应我国高水分混合垃圾**——全球生活垃圾焚烧的 80% 用炉排炉。<span class="marginnote">炉排炉的「适应性」是它成为主流的根本：我国垃圾含水率高、成分杂，炉排炉可以「原样吞下」——不像流化床那样要预处理。炉排运动控制燃烧推进速度，是运行调优的核心：太快烧不尽、太慢处理量降。</span>

**流化床焚烧炉**：垃圾在高速气流吹起的沙床上「沸腾」燃烧，燃烧效率高、温度均匀、污染物控制好，但**需对垃圾预处理（破碎、分选）**——适合热值稳定、粒径均匀的垃圾（或 RDF）。

**热解气化炉**：缺氧条件下热解产可燃气，再燃气燃烧——介于焚烧与热解之间（《热解与气化》专节）。

## 3 公式解析：燃烧的空气量与烟气量

焚烧设计的首要计算是**需氧量与烟气量**，以元素组成为基础：

- **第一步，写元素燃烧反应**：垃圾中的碳、氢、硫分别燃烧：$\ce{C + O2 -> CO2}$、$\ce{2H + 1/2O2 -> H2O}$、$\ce{S + O2 -> SO2}$。每千克垃圾的理论需氧量 = 各元素燃烧耗氧之和。
- **第二步，折算空气量**：氧占空气体积 21%，理论空气量 $V_0$（m³/kg 垃圾）：

$$V_0 = \frac{1}{0.21} \times \frac{\text{理论需氧量}}{32} \times 22.4$$

- **第三步，加过量空气**：实际空气量 $V = \alpha V_0$（$\alpha$ 是过量空气系数，1.5～2.0）。**过量空气是双刃剑**：多了燃烧更完全但烟气量增大（热损失与净化负担上升）、少了燃烧不完全。

**烟气量估算**：烟气 = 理论烟气（$\ce{CO2}$、$\ce{H2O}$、$\ce{SO2}$、$\ce{N2}$）+ 过量空气——烟气量决定**余热锅炉、烟气净化系统的规模**，是焚烧厂设计的第一笔大账。<span class="marginnote">过量空气系数选择的工程权衡：$\alpha$ 太低（< 1.4）燃烧不完全、黑烟与二噁英风险；$\alpha$ 太高（> 2.2）烟气量增大、热效率下降（大量热量被空气带走）。现代炉排炉取 1.6～1.8 左右，「够烧又不浪费」。</span>

## 4 烟气净化与二噁英控制

焚烧烟气成分复杂，净化系统是「全套大气治理技术」的组合（呼应第三篇）：

| 污染物 | 来源 | 净化技术 |
| --- | --- | --- |
| 颗粒物 | 灰分飞散 | 袋式除尘器、电除尘 |
| $\ce{HCl}$、$\ce{SO2}$ | 含氯塑料、含硫物 | 半干法/湿法脱酸 |
| $\ce{NO_x}$ | 高温燃烧 | SNCR/SCR |
| 重金属（汞、铅） | 垃圾中金属 | 活性炭吸附 + 袋式除尘 |
| **二噁英（PCDD/Fs）** | 含氯有机物不完全燃烧 | 850°C/2s 分解 + 活性炭吸附 |

**二噁英（dioxins）** 是焚烧污染的头号公众关注点——一类**高毒、持久性有机污染物**。控制「三道防线」：
1. **燃烧控制**：炉温 ≥ 850°C、停留 ≥ 2s，把二噁英在炉内分解（「3T+E」）。
2. **低温再合成抑制**：烟气在 200～400°C 区间二噁英可能**再合成**（铜等金属催化），需**快速冷却**（急冷）缩短危险温区停留。
3. **末端吸附**：活性炭喷射吸附二噁英 + 袋式除尘器截留——**这是最后的把关**。<span class="marginnote">二噁英控制的「全程思维」：它在炉内被高温分解，却可能在余热锅炉里「死灰复燃」——所以「急冷」和「活性炭吸附」两道关缺一不可。飞灰中的二噁英与重金属使其成为危废（《危废管理》），需螯合固化后危废填埋——焚烧的「尾巴」要管到底。</span>

## 5 余热利用与灰渣处理

**余热发电**：焚烧释放的热量经余热锅炉产蒸汽、驱动汽轮发电机——**1 吨生活垃圾约可发电 300～450 kWh**（依热值），这是焚烧「变废为能」的价值兑现。热电联产（供暖 + 发电）进一步提高能效。<span class="marginnote">垃圾焚烧的能源账：热值越高、发电越多；我国分类后热值提升，吨垃圾发电量从早期 200 kWh 升到 350 kWh+。焚烧发电还被纳入可再生能源电价补贴——「垃圾是城市的矿山」在能源意义上成立。</span>

**灰渣**：
- **炉渣（底渣）**：占灰渣的 80%～90%，**可资源化**——分选金属后做建材（砖、路基材料）。
- **飞灰**：烟气净化收集的细灰，**含重金属与二噁英，属危废**——须**螯合固化（水泥 + 螯合剂）后送危废填埋场**。<span class="marginnote">「底渣建材化、飞灰危废化」的分野：炉渣成分接近玻璃质矿料、可安全利用；飞灰富集了挥发性重金属与二噁英、必须特殊处置——「烧完的灰也不是一回事」，这是固废管理的精细处。</span>

## 6 小结

- 焚烧**减容 80%～90%、消灭病原体、回收余热**，是土地紧张城市的垃圾处理主选。
- 焚烧化学 = **高温氧化**；「3T+E」（温度、时间、湍流、过量氧）保证完全燃烧。
- **炉排炉**适应混合垃圾，是主流炉型；流化床需预处理。
- 烟气净化组合：**除尘 + 脱酸 + 脱硝 + 活性炭吸附**；**二噁英靠 850°C/2s 分解 + 急冷 + 活性炭**三道防线。
- 灰渣分流：**炉渣建材化、飞灰危废化**；余热发电 300～450 kWh/吨。
