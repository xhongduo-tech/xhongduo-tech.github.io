## 为什么从环境经济开始

前面各章讨论「技术能不能治」与「法律允不允许」，这一节追问更根本的问题：**为什么会产生污染？为什么治理常觉得「贵」？怎么用经济手段让「治理比排放更划算」？** 环境经济学的回答是：**环境污染的本质是「市场失灵」**——排放污染的人没有为自己的行为付出全部代价（外部性），环境资源没有价格、被当作「免费垃圾场」。环境经济学的任务，就是用**经济分析**（成本效益、价值评估）与**经济政策**（排污收费、碳交易、生态补偿）把「环境代价」摆回经济决策——「让污染者付钱、让保护者获益」。它与《环境规划与管理》的总量与排污权、《温室气体》的碳市场、《循环经济》的资源定价直接相连。<span class="marginnote">环境经济的「第一性」：为什么工厂宁愿排污不愿治理？因为排污的「成本」由全社会承担（别人喝脏水、呼吸脏空气），而治理的成本由工厂自己承担——「<strong>私人成本 < 社会成本</strong>」的差额就是<strong>外部性</strong>。环境经济学的全部工具，都在修补这个「成本错位」。</span>

## 1 外部性与市场失灵

**外部性（externality）**：一个主体的行为对他人福利产生影响，却没有为此支付或获得补偿。环境污染是**负外部性**的典型——排污者污染空气/水，受害者的健康、财产损失没人买单。

**市场失灵**：在存在负外部性时，市场价格不能反映真实社会成本——**企业按「私人成本」决策，会排放过多污染**（因为社会成本被忽略了）。「看不见的手」在环境问题上失灵了。

**破解路径**（外部性内部化）——让私人成本逼近社会成本：
1. **庇古税（Pigovian tax）**：向排污者征收等于「边际外部成本」的税——**排污收费、碳税**就是它的实践。让排污者自己承担污染的代价，排污量自动降到社会最优。<span class="marginnote">庇古税的「精准平衡」：税率 = 边际外部成本（每多排一吨造成的损害），排污者会权衡「减排成本 vs 交税成本」——减排比交税便宜就减排。「把外部性装进价格」是环境经济最经典的药方，碳税、硫税、排污费都是它的后裔。</span>
2. **科斯定理（Coase theorem）**：在产权明晰、交易成本低时，当事人可通过协商解决外部性——**排污权交易**就是科斯思想的实践（产权界定 + 市场交易，见《环境规划与管理》的排污权交易）。
3. **管制（命令控制）**：标准 + 许可（《环境法规与标准》）。

**庇古税 vs 科斯交易**：一个靠「政府定价」、一个靠「市场定价」——**都是把外部性内部化，殊途同归**。

## 2 环境价值评估

环境物品（清洁空气、洁净水、生物多样性）多数**没有市场价格**——要把它纳入经济决策，必须「算出它的价值」。**环境价值评估方法**：

**（1）揭示偏好法（用行为揭示价值）**：
- **旅行费用法（TCM）**：人们愿意花多少钱「去」某个环境景点（旅行费用反映环境价值）——用于评估游憩价值。
- **特征价格法（HPM）**：环境质量如何影响房价（空气好 → 房价高）——「环境价值藏在房价里」。

**（2）陈述偏好法（直接问价值）**：
- **条件价值法（CVM）**：直接调查人们「愿意为改善环境付多少钱」（WTP）或「愿意接受多少补偿放弃环境」（WTA）——**能评估非使用价值（存在价值、遗产价值）**，但依赖问卷设计。
- **选择实验法（CE）**：让受访者在不同环境方案间选择，反推各属性的价值。

**（3）效益转移法**：把已有研究的价值估算「移植」到新案例——**快但粗，用于快速评估**。<span class="marginnote">环境价值评估的「哲学难题」：评估「一条河值多少钱」本质是在给「非市场物品」造价格——旅行费用法只算「去玩的意愿」，条件价值法要问「愿付多少」，但「存在的价值」（这条河存在本身就有价值）最难估。CVM 的价值不在「绝对精确」，而在「把环境效益放进成本效益分析的天平」。</span>

## 3 成本效益分析（CBA）

**成本效益分析（cost-benefit analysis）** 是环境决策的核心工具：把治理方案的成本与效益（包括环境效益）都折算成钱，**「效益 > 成本」的方案才值得做**。

- **成本**：治理设施投资 + 运行维护 + 监管成本。
- **效益**：污染减少带来的健康改善（减少医疗、提高寿命）、生态修复、资源回收价值、减灾——**环境效益用上一节的价值评估方法折算成钱**。

$$\text{净效益} = \sum \frac{B_t - C_t}{(1+r)^t}$$

$B_t$、$C_t$ 是第 $t$ 年的效益与成本，$r$ 是**折现率**——把未来收益折算成现值。**折现率的选择至关重要**：折现率高 → 未来效益被「打折」 → 不利于长期环保项目；折现率低 → 长期效益被重视。<span class="marginnote">折现率的「伦理之争」：环境效益常发生在未来几十年（气候治理、土壤修复），高折现率会让「未来几十年的收益」折算后小得可怜，导致「长期环保项目算不过账」——「该用多低的折现率才不辜负后代」是环境经济学最有争议的问题之一，直接牵动气候政策的成本核算。</span>

**CBA 的局限**：环境价值评估本身有不确定性、跨代公平难处理、不可逆损失（物种灭绝）难以定价——**CBA 是决策的「重要输入」而非「唯一依据」**，还要与风险预防原则（宁可保守）结合。

## 4 公式解析：污染控制的边际分析

环境经济学的「最优污染水平」思想用**边际分析**表达，拆成三步：

- **第一步，两条边际曲线**：
  - **边际治理成本（MAC）**：再多削减一单位污染所需的花费——**削减越多越难，MAC 递增**。
  - **边际损害成本（MDC）**：再多排放一单位污染造成的损害——**污染越多损害越大，MDC 递增**。

- **第二步，最优污染水平的交点**：

$$\text{最优污染量：MAC = MDC}$$

- **第三步，解读含义**：当 MAC < MDC，再多治理一单位「省钱」（治理成本 < 它避免的损害），应继续治理；当 MAC > MDC，再多治理「不划算」。**最优污染水平不是零污染，而是「治理成本 = 损害成本」处**——「**完全零污染在经济学上不是最优**」（边际成本无穷大）。<span class="marginnote">「最优污染不为零」的直觉：把最后一丁点污染也清掉，可能要花天文数字的钱，而它避免的损害很小——「合理的目标是『恰好值得治理』，而不是『绝对零排放』」。这解释了很多排放标准的制定逻辑：不是「越严越好」，而是「边际效益 = 边际成本」处的平衡，当然这个平衡还叠加了健康安全底线。</span>

**环境经济学的政策启示**：**总量控制与排污交易让「达标」变成「以最低成本达标」**——因为不同企业减排成本不同，交易让减排「从成本低的企业做起」（呼应《环境规划与管理》的排污权交易）。

## 5 环境经济政策工具

**环境经济政策工具箱**（从「命令」到「市场」）：

| 工具 | 机制 | 案例 |
| --- | --- | --- |
| 排污收费/环境税 | 按排放量收费 | 排污费、环境保护税 |
| 碳税 | 按碳排放收费 | 多国碳税 |
| 排污权交易 | 总量 + 市场交易 | 碳排放权交易市场 |
| 生态补偿 | 受益方补偿保护方 | 流域生态补偿、森林补偿 |
| 绿色金融 | 资金向绿色倾斜 | 绿色信贷、绿色债券 |
| 环境补贴 | 激励清洁行为 | 新能源补贴、垃圾分类补贴 |
| 押金-返还 | 押金促回收 | 饮料瓶押金制度 |

**「市场工具 vs 命令控制」的比较**：
- 命令控制（标准）**确定性高**（限值明确）但**成本高**（不管企业减排成本差异）。
- 市场工具（交易、税）**总成本最低**但**结果不确定性**（价格波动、监管难度）。
- **现实是两者组合**：标准保底线 + 市场提效率——「**命令控制打底、市场机制优化**」是现代环境政策的主流。

**环境税改**：我国 2018 年开征**环境保护税**（替代排污费），按「多排多征、少排少征」设计——**税收杠杆让减排从「环保义务」变成「省钱选择」**。<span class="marginnote">环保税与排污费的「制度升级」：从「费」变「税」意味着<strong>法律层级更高、征收刚性更强</strong>——环保税按污染物种类与排放量征收，达标排放有减免、超排加倍——「用价格信号引导企业算减排的经济账」，是「经济激励型环境管理」的落地。</span>

## 6 小结

- 环境污染的本质是**负外部性**（私人成本 < 社会成本）导致**市场失灵**——破解靠「外部性内部化」。
- 两条经典路径：**庇古税**（政府定价：排污收费、碳税）与**科斯交易**（市场定价：排污权交易）。
- 环境价值评估：**揭示偏好**（旅行费用、特征价格）与**陈述偏好**（条件价值 CVM）——把无价的空气水「标价」。
- **成本效益分析（CBA）**用净效益现值判断方案；**折现率**决定长期环保项目算不算得过账。
- **最优污染水平在 MAC = MDC**——不是零污染，而是「边际治理成本 = 边际损害」处。
- 政策工具谱系：**收费/税、交易、补偿、金融、补贴**；「命令打底 + 市场优化」是现代主流。
