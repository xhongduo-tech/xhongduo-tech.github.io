## 为什么从气象开始

大气污染控制有一对永远纠缠的主角：**污染源排放**与**大气扩散能力**。同一座工厂，在通风良好的日子排出的烟囱很快被稀释，在静稳天气里却可能让全城空气发臭——**污染浓度 = 排放量 ÷ 扩散能力**。理解大气污染，必须先理解大气的「脾气」：风怎么吹、温度怎么分布、逆温何时形成、扩散能力强弱如何量化。这一节是《大气污染控制工程》的开篇，为后面的除尘、脱硫、扩散模型提供气象学基础，也与《环境化学》的大气二次污染、《大气污染扩散模型》直接衔接。<span class="marginnote">气象对污染的影响经常被低估：同一排放源，扩散条件好时地面浓度可能相差几十倍。所以大气环境管理既要「控排放」，也要「看气象」——重污染天气预警就是「减排 + 错峰」与不利气象赛跑。</span>

## 1 大气组成与主要污染物

地球大气的主要成分稳定（氮 78%、氧 21%、氩 0.9%、二氧化碳约 0.04%），污染问题出在**微量成分的异常增高**。按来源与状态，大气污染物分：

**气态污染物**：二氧化硫（$\ce{SO2}$）、氮氧化物（$\ce{NO_x}$）、一氧化碳（$\ce{CO}$）、臭氧（$\ce{O3}$）、挥发性有机物（VOCs）、氨（$\ce{NH3}$）。

**颗粒物**：总悬浮颗粒物（TSP）、PM10（可吸入）、PM2.5（细颗粒）——PM2.5 因粒径小、可深入肺泡、能长距离传输，成为大气污染治理的头号目标。<span class="marginnote">PM2.5 的「2.5」指空气动力学直径 ≤ 2.5 μm。为什么它最危险：能穿透呼吸道防御直达肺泡，表面还能吸附重金属与多环芳烃等毒物——粒径越小，比表面积越大、毒性越复杂。</span>

**污染源分类**：**固定源**（电厂、工厂烟囱）与**移动源**（汽车、船舶、飞机）；**点源、线源、面源**（按几何形态）。控制策略因源而异：点源上除尘脱硫装置，移动源抓油品与尾气净化。

## 2 大气的温度层结与逆温

对流层内的气温随高度**一般递减**（约每升高 100 m 降 0.65°C，即**气温直减率** $\gamma \approx 0.65°C/100m$）。这个递减是大气垂直对流（混合）的动力——地面受热、热空气上升、冷空气下沉，污染物被不断带到高空稀释。

**逆温（temperature inversion）** 是气温**随高度升高反而增加**的异常层结，它是大气污染的「天敌」：

逆温层像一顶「锅盖」，**抑制垂直对流**，污染物被困在下方累积。
**辐射逆温**：夜间地面辐射冷却，近地面气温低于上层，晴朗无风的夜晚最易形成——**这就是「早晨雾霾重、白天散去」的原因**。<span class="marginnote">辐射逆温的日变化：日落后地面散热、近地空气降温，逆温在黎明前最强，日出后地面升温、逆温自下而上消失。所以早晨上班高峰的污染最重——排放高峰 + 逆温最强同时发生，是城市空气质量的「最黑暗时刻」。</span>
**下沉逆温**：高压系统控制时，气团下沉增温形成逆温，与静稳天气相伴。
**地形逆温**：盆地、山谷夜间冷空气沿坡下沉积聚，谷底被逆温笼罩——**这就是河谷城市冬季雾霾特别重的气象原因**。

## 3 风与湍流

**风**是水平输送污染物的主力：风速大、水平稀释快，风向决定污染羽吹向哪里。烟囱设计、监测布点、扩散计算全都依赖风向风速资料。

**湍流（turbulence）** 是大气中不规则的随机运动，是污染物扩散的真正机制——**分子扩散太慢，污染物主要靠湍流「搅拌」稀释**。大气湍流分两种：

**热力湍流**：由地表受热不均、温度层结不稳定引起——午后太阳晒热地面，热力湍流最强。
**动力湍流**：风遇地面、建筑物摩擦产生的机械扰动——风速大时动力湍流强。<span class="marginnote">风与湍流的区别：风是「平均运动」，湍流是「涨落运动」。烟囱排出的烟在平均风里被吹到下风向，在湍流里被「揉开」——污染羽的扩张（横向散开、纵向展宽）全靠湍流，所以湍流强度决定了「污染羽有多宽多高」。</span>

**大气的扩散能力由「风 + 湍流 + 层结稳定度」共同决定**：风速大、湍流强、层结不稳定 → 扩散能力强 → 地面浓度低；静稳、逆温、微风 → 扩散能力弱 → 污染堆积。

## 4 公式解析：气温直减率与稳定度判据

判断大气「喜不喜欢扩散」，看温度层结的稳定度，核心是比较两个直减率：

- **第一步，认识两个 γ**：大气实际气温直减率 $\gamma = -\mathrm{d}T/\mathrm{d}z$（实测值，随天气变化）；干绝热直减率 $\gamma_d = 0.98\ \mathrm{°C/100m}$（气团绝热上升时的固有冷却率，近常数）。
- **第二步，比较判稳定**：气团上升时按 $\gamma_d$ 自身降温，环境按 $\gamma$ 分布。比较两者的相对温度：
  - $\gamma > \gamma_d$：环境降温比气团快，上升气团始终比周围**暖而轻**，继续上升——**不稳定**，对流强、扩散好。
  - $\gamma = \gamma_d$：中性。
  - $\gamma < \gamma_d$：环境降温比气团慢，上升气团很快比周围**冷而重**，被压回原位——**稳定**，对流受抑、扩散差。
- **第三步，特例即逆温**：$\gamma < 0$（气温随高度升高）是极稳定层结——**逆温层是最稳定的扩散障碍**。

$$\text{稳定度：}\quad \gamma > \gamma_d\ \text{不稳定（扩散强）}\ ;\quad \gamma < \gamma_d\ \text{稳定（扩散弱）}$$

**工程含义**：烟囱高度与排放设计要考虑「污染羽在稳定层结下不下沉、在地面造成高浓度」的风险——**稳定气象下，高烟囱稀排放比低烟囱多排放更能保护地面**，这就是「高烟囱稀释」策略的气象依据。<span class="marginnote">注意一个反直觉：烟羽的「抬升高度」也受层结影响——不稳定时烟羽剧烈翻滚、抬升快，稳定时烟羽水平伸展、很少抬升。所以晴空午后烟囱烟羽「腾云直上」，静稳清晨烟羽「贴着地飘」，都是层结稳定度在说话。</span>

**算例：三种天气的稳定度判断。** 某日实测气温直减率 $\gamma = 0.9$ °C/100m，与 $\gamma_d = 0.98$ °C/100m 相比，$\gamma < \gamma_d$——层结稳定，对流受抑，污染物难以上行稀释，地面浓度容易偏高。若 $\gamma = 1.2$ °C/100m > $\gamma_d$，层结不稳定，午后对流旺盛，污染物被迅速抬升稀释。若清晨出现 $\gamma = -0.5$ °C/100m（逆温），则是最危险的扩散障碍。**把三组数代入判据，就能对「今天适不适合扩散」给出定量回答**——这正是环保部门重污染预警的气象基础，也是《环境应急管理》错峰生产安排的依据之一。

## 5 重要的大气污染气象现象

**（1）混合层高度**：近地面湍流混合能到达的高度。白天混合层高（几百米到一千多米），污染物被稀释到很大空间；夜间混合层矮（几十到几百米），污染物挤在薄薄一层里浓度飙升——**混合层高度是污染预测的核心参数**。

**（5）城市通风廊道**：城市密集建筑会「搓碎」气流、阻碍通风，污染物在街谷里滞留。规划上预留与主导风向一致的**通风廊道**（沿江、沿路、沿河开敞地带），能显著改善城市扩散条件——这是《环境规划与管理》把气象知识落进城市设计的典型案例，也是「从源头为扩散留通道」的预防性思路。

**（2）海陆风与山谷风**：沿海城市白天海风把污染物吹向陆地、夜间陆风吹向海洋，形成污染物的昼夜循环；山谷风使污染物在谷内来回「拉锯」，**谷地城市污染物不易外排**。<span class="marginnote">海陆风的日变化会改变污染输送方向：白天污染向陆输送、夜间向海——这导致沿海监测站在不同时段测到的污染来源不同。理解局地环流，是解读监测数据与预警的关键背景。</span>

**（3）热岛效应**：城市比郊区暖，形成城市上空的上升气流与周围下沉气流——**城市热岛不仅使城市更热，还改变局地风场与污染扩散**，霾与热岛常伴生。

**（4）大气光化学与二次污染**：静稳晴热天气下，$\ce{NO_x}$ 与 VOCs 在阳光中生成臭氧与二次气溶胶（《环境化学》已述）——**气象不仅影响扩散，还影响二次污染的化学反应速率**，晴热 + 静稳是最不利组合。

**重污染天气的气象剧本**：冬季我国中东部重污染往往按同一剧本上演——高压脊控制、下沉逆温、地面静稳微风、混合层被压到几百米以下，污染物在低层「闷」着累积，加上湿度大，PM2.5 吸湿增长，浓度连日攀升。应对靠「减排 + 气象」双轮驱动：不利气象时启动应急减排（错峰生产、限行），把排放压下去，气象稍好污染才不爆表——这就是《环境应急管理》里重污染天气预案的气象逻辑。<span class="marginnote">臭氧污染与 PM2.5 的「天气偏好」不同：PM2.5 重污染多出现在静稳、逆温的冬季早晨；臭氧高值出现在晴热、强光、午后——同一座城市，冬天防霾、夏天防臭氧，是「因时因天气制宜」的分季治理。</span>

## 核心对照：三种逆温

| 类型 | 成因 | 出现时机 | 影响 |
| --- | --- | --- | --- |
| 辐射逆温 | 夜间地面辐射冷却 | 晴朗无风，清晨最强 | 早晨雾霾重 |
| 下沉逆温 | 高压气团下沉增温 | 静稳天气 | 污染物滞留 |
| 地形逆温 | 冷空气沿坡下沉积聚 | 山谷盆地夜间 | 河谷城市冬季污染重 |

**辨析｜易错点：** 「逆温」与「混合层低」是两个相关但不同的概念——逆温是温度层结的异常（$\gamma < 0$），混合层低是湍流混合所能到达的高度。逆温会压扁混合层，但混合层低还可能由其他因素（如清晨弱湍流）造成。把两者分开理解，读气象预报的「逆温层高度」与「混合层高度」时就不会混淆。

| 术语 | 一句话定义 |

| 气温直减率 γ | 气温随高度升高的递减率（°C/100m） |

| 逆温 | 气温随高度升高而升高的异常层结 |
| 湍流 | 大气不规则的随机运动，扩散的真正机制 |
| 混合层高度 | 湍流垂直混合能达到的高度 |
| 热力 / 动力湍流 | 由受热不均 / 机械摩擦引起的湍流 |
| 热岛效应 | 城市比郊区暖、改变局地风场的现象 |

**记忆锚点**：把大气想成一杯「被搅拌的水」——风是杯子的水平位移，湍流是搅拌棒，逆温是杯口的盖子。盖子盖上（逆温），搅拌再弱（低混合层），污染物就沉在杯底浓度飙升。一张图就能记住大气扩散的全部要素。

## 6 小结

- 大气污染浓度 = **排放量 ÷ 扩散能力**；气象是扩散能力的决定者。
- 主要污染物分**气态**（$\ce{SO2}$、$\ce{NO_x}$、$\ce{O3}$、VOCs）与**颗粒物**（PM10、PM2.5），PM2.5 是治理核心。
- **逆温**是扩散的天敌——辐射逆温造成「早晨雾霾重」，盆地地形加剧冬季污染。
- 扩散靠**湍流**（热力 + 动力），**风管水平输送、湍流管垂直混合**。
- 稳定度判据 $\gamma$ vs $\gamma_d$：**$\gamma < \gamma_d$ 稳定扩散差，$\gamma < 0$ 即逆温**；混合层高度决定污染稀释空间。
- 实用口诀：**风管输送、湍流混合、逆温封顶**——三个要素凑齐，就能看懂绝大多数污染天气预报。
- 同一排放源在不同气象下地面浓度可相差几十倍，**控排放与看气象必须两手抓**。
- 从混合层高度到通风廊道，气象知识贯穿**监测、预测、规划、应急**全链条，是大气环境管理的底色。
- 记住一句总纲：**气象决定污染怎么散，减排决定污染有多少**——两者相乘，才是空气质量。

在下一节，我们走进除尘设备的世界——从粉尘性质说起，**粉尘性质与除尘**。气象决定污染「怎么散」，除尘决定污染「从哪截」，两条线将在这里开始汇合。
