## 为什么从反应器开始

环境工程里有大量「容器」：活性污泥曝气池、厌氧消化罐、生物滤塔、石灰中和池、臭氧接触池。它们有的让微生物降解有机污染物，有的让化学药剂与废水反应，但本质上都在做同一件事——**让反应物在有限体积、有限时间里尽可能多地发生反应**。上一节《传质原理》讲了物质怎么跨相迁移，这一节要回答：**物质在容器里怎么流动、反应进行得多快、最终转化到什么程度**。这三个问题拼起来，就是**反应器（reactor）**理论。它与第二级《高等数学》的常微分方程、《基础化学》的化学反应速率直接衔接，也是活性污泥法、厌氧消化、Fenton 氧化等后续所有工艺的共同骨架。<span class="marginnote">反应器理论是「环境工程原理」与「工艺课」之间的桥梁：学完它，你再走进曝气池或消化罐，看到的不再是一潭水，而是一组微分方程的实物投影。</span>

## 1 反应速率与反应级数

反应器分析的第一步，是定量描述「反应快慢」。对单一反应物 $A$，反应速率通常写成幂函数形式：

$$-r_A = k C_A^n$$

$r_A$ 是 $A$ 的消耗速率（$\mathrm{mol/(m^3\cdot s)}$），$k$ 是**反应速率常数**，$C_A$ 是反应物浓度，$n$ 是**反应级数**。环境工程最常用的是零级、一级与二级：

- **零级反应**（$n=0$）：速率与浓度无关，$-r_A = k$。饱和底物下微生物反应常近似零级——酶已被底物「喂饱」，速率不再随底物增加。<span class="marginnote">零级的典型例子是催化剂表面反应和饱和酶促反应（米氏方程高浓度极限）。直觉：反应的「瓶颈」不在底物而在催化剂本身。</span>
- **一级反应**（$n=1$）：速率正比于浓度，$-r_A = k C_A$。放射性衰变、多数有机物的生物降解、消毒剂衰减都近似一级。积分得：

$$C_A = C_{A0} e^{-kt}$$

浓度随时间**指数衰减**，半衰期 $t_{1/2} = \ln 2 / k$ 与初始浓度无关——这是它最容易识别的特征。

- **二级反应**（$n=2$）：速率正比于浓度平方，常见于双分子反应与部分混凝过程。

**辨析｜易错点：** 反应级数**只能由实验测定，不能从化学计量式读出**。化学计量系数是「摩尔比例」，反应级数是「浓度依赖幂次」，两者数值未必相同——例如某些臭氧氧化反应计量式简单，级数却因自由基机理而表现复杂。<span class="marginnote">反应速率常数 $k$ 随温度按阿伦尼乌斯公式 $k = k_0 e^{-E_a/(RT)}$ 变化：温度升高，$k$ 指数上升。这就是为什么污水处理在冬天效率下降、要在夏天达标。</span>

## 2 三种理想反应器

反应器理论的基础是三种**理想模型**，现实装置都是它们的组合：

**（1）间歇反应器（Batch）**：物料一次投入、充分搅拌、无进出流。浓度随时间变化，各点浓度均匀。其设计方程：

$$\frac{\mathrm{d}C_A}{\mathrm{d}t} = r_A \qquad \Rightarrow \qquad t = \int_{C_A}^{C_{A0}} \frac{\mathrm{d}C_A}{-r_A}$$

对一级反应，$t = \dfrac{1}{k}\ln\dfrac{C_{A0}}{C_A}$。实验室小试、化学混凝快速搅拌都是间歇操作。<span class="marginnote">间歇反应器的特点：反应时间越长转化率越高，但无法连续生产。它像一口「闷烧的锅」，是所有反应动力学实验的标准舞台。</span>

**（2）连续搅拌槽反应器（CSTR）**：连续进出流，槽内充分搅拌，**出口浓度 = 槽内浓度**。稳态下物料衡算得：

$$\frac{C_{A0} - C_A}{\tau} = -r_A \qquad \Rightarrow \qquad \tau = \frac{C_{A0} - C_A}{-r_A}$$

$\tau = V/Q$ 是**水力停留时间（HRT）**，$V$ 是有效体积、$Q$ 是流量。对一级反应，$\dfrac{C_A}{C_{A0}} = \dfrac{1}{1 + k\tau}$。**CSTR 的致命缺点是「全槽浓度都低」——反应始终在低浓度、低速率下进行，同等体积下转化率低于活塞流。**

**（3）活塞流反应器（PFR）**：流体像活塞一样平推前进，径向完全混合、轴向无混合，**浓度沿流动方向递减、任一点浓度随时间不变**。稳态下：

$$\frac{\mathrm{d}C_A}{\mathrm{d}z} = \frac{r_A}{u} \qquad \Rightarrow \qquad \tau = \int_{C_A}^{C_{A0}} \frac{\mathrm{d}C_A}{-r_A}$$

对一级反应，$\dfrac{C_A}{C_{A0}} = e^{-k\tau}$。**PFR 里反应物从头到尾保持高浓度，反应速率始终较高，同等体积下转化率最高。** 长管道、推流式曝气池、生物滤塔都接近 PFR。<span class="marginnote">同一反应、同一 $\tau$，PFR 的转化率总高于 CSTR——因为 CSTR 里的浓度被「稀释」成了出口最低值，而 PFR 保留了一路的高浓度梯度。这个差异对反应级数越高越显著。</span>

## 3 公式解析：CSTR 与 PFR 的转化率对比

以一级反应为例，把两种连续反应器的差别用三行公式说清：

**第一步，同写物料衡算**：稳态下「进入 = 流出 + 反应掉」。CSTR 全部在出口浓度 $C_A$ 下反应，PFR 在从 $C_{A0}$ 到 $C_A$ 的渐变浓度下反应。差异全在「用哪个浓度算反应速率」。
**第二步，各自积分**：CSTR 得 $C_A/C_{A0} = 1/(1+k\tau)$；PFR 得 $C_A/C_{A0} = e^{-k\tau}$。
**第三步，数值对比**：取 $k\tau = 1$，CSTR 剩余 $1/2 = 50\%$，PFR 剩余 $e^{-1} \approx 36.8\%$。**达到同样 90% 转化率，CSTR 需要的体积是 PFR 的数倍**（对一级反应约 3.9 倍）。这就是为什么连续流处理工艺总想往「推流」靠。

**工程启示**：活性污泥法中把曝气池做成多格串联的「近似推流」，就是把多个 CSTR 串联逼近 PFR 的性能——**$n$ 个同体积 CSTR 串联，等效转化率随 $n$ 增大而逼近 PFR**。这是「把容器工程化」的典型手法。<span class="marginnote">串联 CSTR 逼近 PFR 的直觉：格子越多，浓度阶梯越细，越来越像连续变化的推流。工程上一般 4～8 格串联即接近 PFR 性能，成本却远低于真正做成长管。</span>

## 4 停留时间分布（RTD）

理想模型是极限，真实反应器里流体有短路、有死区、有返混，出口流体的停留时间有长有短。**停留时间分布（residence time distribution, RTD）** 用示踪实验刻画这种偏离。

实验方法：在入口瞬间注入示踪剂（如食盐、荧光染料），在出口记录浓度随时间的变化，得到 $E(t)$ 曲线——**$E(t)\mathrm{d}t$ 表示停留时间落在 $[t, t+\mathrm{d}t]$ 的流体所占比例**。其数学性质：

$$\int_0^\infty E(t)\,\mathrm{d}t = 1, \qquad \bar{t} = \int_0^\infty t\,E(t)\,\mathrm{d}t$$

$\bar{t}$ 是平均停留时间。**理想 PFR 的 $E(t)$ 是一条窄脉冲（所有流体同时到达），理想 CSTR 的 $E(t)$ 是指数衰减曲线**——越接近这两条标准曲线，越接近相应理想模型。

RTD 曲线的形状直接暴露反应器缺陷：<span class="marginnote">若出口浓度出现「提前的尖峰」，说明存在短路（部分流体抄近道快速流出，停留时间不足）；若平均停留时间明显短于 $\tau = V/Q$，说明存在死区（部分体积不参与流动）。这两条是反应器诊断的入门判读。</span>

**提前尖峰 + 长尾**：短路 + 返混，处理效果打折扣。
**平均停留时间 $< V/Q$**：有效体积缩水，需清淤或改造挡板。

## 5 反应器组合与选择

真实工艺往往组合使用理想反应器模型：

| 工艺 | 主反应器模型 | 设计关键量 |
| --- | --- | --- |
| 活性污泥曝气池 | 串联 CSTR（近似 PFR） | 污泥龄、HRT |
| 厌氧消化罐 | CSTR（全混） | HRT、SRT、产气量 |
| 生物滤塔 | PFR + 传质 | 滤速、高度 |
| 臭氧接触池 | 多室串联 + RTD | CT 值、停留时间 |
| 氧化沟 | 环形推流 | 循环倍率、HRT |

一个重要的区分是**水力停留时间（HRT）**与**污泥龄 / 固体停留时间（SRT）**：HRT 是水流在池里的平均时间，SRT 是固体（微生物）在系统里的平均时间。**活性污泥法能高效处理污水，正是靠 SRT 远大于 HRT**——水几小时就流走，微生物却在系统里待了几天到几十天，得以大量增殖并保持高浓度。<span class="marginnote">SRT > HRT 是生物处理「截留微生物」的数学表达。靠回流污泥把微生物留在系统里，实现「水走了、菌留下」，这是活性污泥工艺全部巧妙之处的起点，下一部分会细讲。</span>

## 6 小结

- 反应速率 $r_A = kC_A^n$，级数由实验确定；环境工程常见**零级、一级、二级**。
- 三种理想反应器：**间歇、CSTR、PFR**；CSTR 浓度最低、PFR 转化率最高。
- 同一级数下 **PFR 转化率总高于 CSTR**，串联 CSTR 逼近 PFR 是工程折中。
- **RTD 曲线**用示踪实验刻画真实流动，判读短路与死区。
- **HRT 管水、SRT 管泥**，活性污泥法靠 SRT ≫ HRT 实现高效生物处理。
