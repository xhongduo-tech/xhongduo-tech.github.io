## 为什么从危废开始

固废里有极小的一支，却占去监管与治理的大半精力——**危险废物（hazardous waste）**。它的量只占固废总量几个百分点，但**毒性、腐蚀性、易燃性、反应性、感染性**让它一旦管理失当，就会造成地下水污染、中毒事件、甚至爆炸火灾。危废管理的独特之处：**它首先是「管理问题」而非「技术问题」**——从产生、分类、贮存、转移到处置，每一环都要依法管住（联单制度、经营许可），技术手段只是管理链条上的一环。它与《固废分类与特性》的危废特性、《焚烧》的危废焚烧、《环境法规与标准》《环境应急管理》直接相连。<span class="marginnote">危废与普通固废的「法律鸿沟」：普通垃圾可以市场化自由处置，危废必须由<strong>持证经营单位</strong>处置、全程联单、跨省转移要审批——「身份」不同，整个管理体系的严格程度完全不同。这是「按风险分级管理」思想的极致体现。</span>

## 1 危险废物的鉴别与名录

危废的「身份认定」靠**双轨**：

**（1）名录制**：《国家危险废物名录》——列出 46 大类、467 种危险废物（如废矿物油、废酸、废碱、含铬废渣、医疗废物等）。**列入名录即危废**，无须再鉴别。

**（2）鉴别制**：未列入名录但有危险特性的废物，按**危险废物鉴别标准**检测——浸出毒性、急性毒性、腐蚀性、易燃性、反应性等。**名录 + 鉴别**双轨，保证「有名单的按名单、没名单的按性质」。

**鉴别标准（危险特性）**，记忆口诀「五性」：
**腐蚀性**：pH ≤ 2 或 ≥ 12.5。
**毒性**：浸出毒性（如重金属、有机毒物浸出浓度超标）、急性毒性（小白鼠口服/吸入试验）。
**易燃性**：闪点 < 60°C 的液体、易自燃固体。
**反应性**：易爆炸、与水或空气剧烈反应。
**感染性**：医疗废物等含病原体废物。<span class="marginnote">「浸出毒性」是危废鉴别最常用的手段：模拟垃圾填埋场渗滤液条件，用酸浸提废物、测浸出液浓度——超标的废物即使形态是固体，也具有「淋溶污染地下水」的风险，故列为危废。这也呼应《土壤污染与修复》里「污染物迁移靠水」的思想。</span>

## 2 危废的收集、贮存与转移

**产生单位的责任**（源头管理）：
**分类收集**：不同危废性质互斥（氧化剂与还原剂、酸与碱）必须分开，防止混合反应。
**识别标识**：危废容器与贮存场所设危险废物标识（骷髅、腐蚀等图标）。
**申报登记**：每年向环保部门申报危废种类、数量、流向。

**贮存要求**：危废贮存场所要**防渗、防雨、防漏、防扬散**（「四防」），容器密闭、分区存放、台账记录。**贮存期限一般不超过一年**，超期需申请延长。<span class="marginnote">危废贮存的「四防」为什么是红线：一场暴雨让含重金属的露天废渣渗入土壤，污染可能持续几十年——「贮存环节的失误，等于把危废提前『释放』到环境里」。所以危废库都建在高出地表的防渗地基上、有围堰与收集沟。</span>

**转移联单制度（电子联单）**——危废管理的「身份证+物流单」：
危废离开产生单位时，填写**危险废物转移联单**，记录种类、数量、起止单位、运输方式。
**每转一程、每换一手都要签收**，全程可追溯——从产生到最终处置形成闭环。
跨省转移需经移出地、移入地环保部门审批——防止「污染转嫁」（发达地区危废偷运到欠发达地区倾倒）。<span class="marginnote">联单制度的「威慑力」：每一桶危废都有「物流轨迹」，倒卖、偷排、混合丢弃都会在联单链条上露出破绽——监管靠「可追溯」而非「碰运气检查」。近年危废倾倒案件频发，追责时联单是定罪的关键证据，这就是「管理留痕」的法律威力。</span>

## 3 危废的处理处置技术

危废的处置路线按「减量、无害、资源化」选择：

**（1）物理化学处理**（预处理/解毒）：
**中和**：废酸废碱中和。
**氧化还原**：氰化物氧化、六价铬还原（与《化学处理》同原理）。
**固化/稳定化**：把危废与水泥、石灰、螯合剂混合，**把污染物「锁」进固体基体**——降低浸出毒性，是飞灰、含重金属残渣填埋前的必要步骤。<span class="marginnote">固化/稳定化的「锁住」逻辑：污染物不是被去除，而是被<strong>物理包裹 + 化学固定</strong>成低浸出毒性的稳定体——像「把毒药封进水泥块」。判断标准是固化体的浸出毒性达标，达标才能进危废填埋场。这是「减毒而非消灭」的典型。</span>

**（2）焚烧**（无害化主力）：
高温（850～1200°C）彻底分解有机物，减容减重显著。
适用：有机危废（废溶剂、废油、医疗废物）、含氯有机物（需高温防二噁英）。
**回转窑焚烧炉**是危废焚烧的主力炉型——适应成分复杂、形态各异的危废，配合急冷 + 烟气净化（《焚烧》技术）。

**（3）填埋**（最终归宿）：
**安全填埋场**：专为危废设计，防渗标准远高于生活垃圾填埋场（双层衬层 + 检漏系统）。
填埋对象：固化/稳定化后的无机残渣、焚烧飞灰与炉渣——**「能烧的烧、烧不了的固化、固化了埋」是危废处置的基本序列**。<span class="marginnote">危废填埋场的「安全冗余」：相比生活垃圾填埋，危废填埋场要求双衬层、双渗滤液收集、检漏系统、更严格的地下水监测——「宁多一道保险，不让一滴渗滤液漏出去」。安全填埋场选址也极苛刻，全国数量有限，因此「危废处置能力紧张」长期是行业痛点。</span>

## 4 医疗废物的特殊管理

**医疗废物**是危废的「特等生」：具有**感染性**，直接关系公共卫生。管理要点：

**分类**：感染性、损伤性、病理性、药物性、化学性五类。
**专门收集**：专用包装袋（黄色）、锐器盒、专用容器，**严禁混入生活垃圾**。
**集中处置**：区域集中焚烧（或高温蒸汽/微波消毒）——**医疗废物必须日产日清、不得贮存过久**。
**全流程监管**：从医院到处置厂的专用运输车、联单、可追溯系统。

**辨析｜易错点：** 医疗废物**不等于**一般生活垃圾，即使经过消毒也不得混入生活垃圾处理。感染性废物（用过的针头、沾血棉球）的**感染风险是即时的**——所以它的管理红线是「日产日清、专车专运、集中焚烧」，与普通危废的「贮存一年内」完全不同。<span class="marginnote">医疗废物的「时限铁律」：普通危废可贮存近一年，医疗废物却要求<strong>日产日清</strong>——因为感染性废物存放越久、暴露风险越大。疫情等特殊时期医疗废物暴增，应急处置（增加处置点、延长工作时间）是《环境应急管理》的实战场景。</span>

## 5 危废管理的政策体系

危废管理是一套完整的**制度体系**：

| 制度 | 内容 |
| --- | --- |
| 名录与鉴别 | 明确「什么是危废」 |
| 申报登记 | 产生单位年报 |
| 转移联单 | 全程可追溯 |
| 经营许可 | 处置单位持证经营 |
| 贮存标准 | 「四防」与时限 |
| 排污许可 | 纳入总量与达标管理 |
| 应急预案 | 泄漏、火灾等应急（《环境应急管理》） |

**危废管理的趋势**：
**全过程信息化**：电子联单、视频监控、GPS 定位——「互联网 + 危废监管」。
**源头减量与资源化**：工艺替代（少产生危废）、危废资源化利用（废溶剂回收、废酸再生、含金属危废提金属）——**危废也是资源**，提纯利用后残渣再处置。<span class="marginnote">危废资源化的「双面性」：废矿物油再生、废酸再生、含钯/铂废催化剂提金属——既减量又回收资源，是循环经济的深度应用。但资源化必须「先无害、后利用」，绝不能借资源化之名行非法处置之实——「利用」要符合标准、产物要有去向，这是监管的红线。</span>

**辨析｜易错点：** **「危废处置率」不等于「危废安全处置率」**。行业常报「处置率 98%」，但要看清是**合法持证处置**还是**长期贮存**或**非法流转**——贮存超期不算真正处置、非法倾倒更不是。**监管的核心是「去向可查」**：每一吨危废最终去了持证设施、被安全处置，才是真达标。这也是为什么电子联单 + 经营许可 + 现场核查要配套使用——单看统计数字会被「数字达标」骗过去。

## 6 术语速查

| 术语 | 含义 | 管理意义 |
| --- | --- | --- |
| 危险废物 | 具五性（腐蚀/毒/易燃/反应/感染） | 名录 + 鉴别双轨确定 |
| 浸出毒性 | 模拟渗滤条件测浸出浓度 | 危废鉴别最常用 |
| 联单制度 | 转移全程签收可追溯 | 防偷排、防转嫁 |
| 四防 | 防渗、防雨、防漏、防扬散 | 贮存场所基本要求 |
| 固化/稳定化 | 药剂把污染物锁进固体基体 | 填埋前必要步骤 |
| 安全填埋场 | 双层衬层 + 检漏的高标准填埋 | 危废最终归宿 |
| 经营许可 | 处置单位持证经营 | 市场准入门槛 |
| 医疗废物 | 具感染性的危废 | 日产日清、专车专运 |

这套术语把危废「鉴别—收集—贮存—转移—处置—监管」的完整链条点清：身份靠名录鉴别、流动靠联单追溯、归宿靠固化填埋焚烧、监管靠制度与信息化。

## 7 小结

- 危废具**腐蚀、毒、易燃、反应、感染**五性；靠**名录 + 鉴别**双轨确定身份。
- 源头管理：**分类收集、标识、申报登记**；贮存要「四防」、期限一般 ≤ 1 年。
- **转移联单**是危废「从摇篮到坟墓」的可追溯凭证，跨省转移需审批防污染转嫁。
- 处置序列：**物理化学处理（中和/还原/固化稳定化）→ 焚烧 → 安全填埋**；「能烧的烧、烧不了的固化、固化了埋」。
- **医疗废物**感染性特殊管理：**日产日清、专车专运、集中焚烧**。
- 制度体系：**名录、申报、联单、许可、贮存、应急**六件套 + 信息化监管 + 资源化减量。
