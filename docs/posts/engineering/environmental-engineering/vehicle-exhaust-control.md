## 为什么从汽车尾气开始

前面几节治理的是「烟囱」（固定源），这一节转向**移动源**——汽车、摩托车、船舶。机动车尾气是城市空气污染的第一大来源：在不少大城市，机动车对 $\ce{NO_x}$ 与 VOCs 排放的贡献超过一半，是**臭氧与 PM2.5 生成的主力燃料**。汽车尾气控制的独特之处：污染源数以千万计、分散流动、每辆车都是一个小反应器——没法给每辆车装「脱硫塔」，只能靠**机内净化 + 机外催化 + 油品管理 + 交通调控**的组合拳。它与《脱硝技术》的催化还原、《VOCs 治理》的臭氧前体、《大气污染与气象》的城市污染紧密相连。<span class="marginnote">移动源治理的逻辑与固定源的根本差异：固定源是「少数大户、集中控制」，移动源是「海量小户、分散流动」——所以移动源靠「标准 + 监督 + 油品」的体系化管控，而不是单点设备。这也是机动车排放法规（国标、欧标）体系特别严密的原因。</span>

## 1 汽车尾气的成分与生成

汽油机与柴油机排气成分不同，但核心污染物一致：

| 污染物 | 生成机理 | 危害 |
| --- | --- | --- |
| 一氧化碳 $\ce{CO}$ | 缺氧燃烧不完全 | 窒息毒物 |
| 碳氢化合物 $\ce{HC}$（VOCs） | 燃料未燃尽、壁面淬熄 | 臭氧前体、致癌 |
| 氮氧化物 $\ce{NO_x}$ | 高温富氧燃烧（热力型） | 臭氧、酸雨、PM |
| 颗粒物（PM，尤其柴油机） | 燃料不完全燃烧成碳核 | PM2.5、致癌 |
| 二氧化碳 $\ce{CO2}$ | 完全燃烧必然产物 | 温室气体 |

**生成机理的「此消彼长」**：$\ce{CO}$ 与 $\ce{HC}$ 在**贫氧**时增加，$\ce{NO_x}$ 在**高温富氧**时增加——**同一缸内想同时压低三种污染物几乎不可能**，这正是排放控制必须靠「机内 + 机外」协同的化学根源。<span class="marginnote">燃烧的「三角矛盾」：富氧低温压 $\ce{CO}$/$\ce{HC}$ 但升高 $\ce{NO_x}$，高温高压提效率但 $\ce{NO_x}$ 暴涨，稀薄燃烧省油却难控 $\ce{NO_x}$——所以现代发动机「先机内尽量优化，再机外催化收尾」，把矛盾交给三元催化器解决。</span>

**柴油机 vs 汽油机**：柴油机压燃、富氧，$\ce{CO}$/$\ce{HC}$ 低但 **PM 与 $\ce{NO_x}$ 高**；汽油机点燃、当量比，三元催化后排放洁净。柴油机「PM 与 $\ce{NO_x}$ 此消彼长」（富氧多 $\ce{NO_x}$、富燃多 PM）是治理的老大难。

## 2 机内净化技术

机内净化是在发动机内部把污染物「压下去」，是成本最低的第一道防线：

**电控燃油喷射（EFI）**：精确控制空燃比，让燃烧更完全——取代化油器后 $\ce{CO}$、$\ce{HC}$ 大幅下降。
**空燃比与三元催化的窗口**：**三元催化器（TWC）要求空燃比严格在化学计量比（λ=1）附近**——在 14.7:1 的窄窗口内，$\ce{CO}$、$\ce{HC}$、$\ce{NO_x}$ 三种污染物的转化效率同时达到最高（> 90%）。氧传感器（λ 传感器）闭环控制把空燃比锁定在窗口内。<span class="marginnote">三元催化的「三元」指同时净化 $\ce{CO}$、$\ce{HC}$、$\ce{NO_x}$ 三种污染物——它靠铂/钯/铑三种贵金属催化：铂钯氧化 $\ce{CO}$/$\ce{HC}$、铑还原 $\ce{NO_x}$。之所以要求 λ=1，是因为「氧化需要氧、还原需要还原剂」必须同时满足，偏离一点就「顾此失彼」。</span>
- **EGR 废气再循环**：把部分废气送回气缸稀释新鲜混合气、降低燃烧温度——**降低热力型 $\ce{NO_x}$**。
- **稀薄燃烧与分层燃烧**：新一代技术，燃油经济性好但 $\ce{NO_x}$ 高，需配 $\ce{NO_x}$ 储存还原催化（NSR）或选择性催化还原（SCR）。

## 3 机外净化：三元催化器与后处理

机外净化是排放达标的主力，核心设备：

**（1）三元催化器（TWC）**——汽油车的标配：
- 结构与原理：陶瓷蜂窝载体上涂覆贵金属催化剂，排气在高温（300°C 以上）下发生氧化还原：

$$\ce{2CO + O2 -> 2CO2}, \qquad \ce{C4H6（HC）+ 5O2 -> 4CO2 + 3H2O}, \qquad \ce{2NO + 2CO -> N2 + 2CO2}$$

- **冷启动问题**：催化剂需到「起燃温度」才工作——冷车启动的前 1～2 分钟是最脏的（催化剂未起燃、喷油加浓），所以「冷启动排放」是法规重点与工程难点（催化剂快速起燃、电加热催化）。

**（2）柴油车后处理系统**：
- **柴油氧化催化器（DOC）**：氧化 $\ce{CO}$、$\ce{HC}$ 与部分可溶有机组分。
- **柴油颗粒捕集器（DPF）**：壁流式陶瓷过滤器捕集 PM——**捕集效率 > 95%**，需定期「再生」（高温烧掉积累的碳）。
- **选择性催化还原（SCR，车用）**：尿素（$\ce{AdBlue}$）喷入排气管分解出氨，在催化剂上把 $\ce{NO_x}$ 还原为 $\ce{N2}$——**车用 SCR 与燃煤 SCR 同原理**，是柴油车控 $\ce{NO_x}$ 的利器。<span class="marginnote">车用 SCR 的「尿素供应链」：尾气 $\ce{NO_x}$ 高 → 喷尿素（$\ce{(NH2)2CO}$）→ 热解出氨 → 还原 $\ce{NO_x}$。所以柴油车「缺尿素就排放超标」——不少车被屏蔽尿素系统以省钱，这是「排放造假」的一个形态，法规专门监管尿素消耗。</span>

**柴油机「PM 与 $\ce{NO_x}$ 的跷跷板」破解**：EGR 降 $\ce{NO_x}$ 但增 PM，DPF 捕 PM、SCR 除 $\ce{NO_x}$——**DOC + DPF + SCR 组合**让两头都达标，这是现代柴油车的「黄金三件套」。

## 4 公式解析：三元催化的转化效率

评价后处理系统的核心指标是**转化效率**，以 $\ce{NO_x}$ 还原为例拆解：

**第一步，定义转化效率**：$\eta = \dfrac{C_{in} - C_{out}}{C_{in}} \times 100\%$，$C_{in}$、$C_{out}$ 是催化器前后污染物浓度。法规考核的是**法规工况下的转化效率与排放总量**（g/km）。
**第二步，空燃比窗口**：三元催化器的转化效率随空燃比变化呈「倒 V」——**λ = 1 附近三种污染物同时达 > 90%**；偏离 ±0.02 就大幅下滑。氧传感器的反馈控制就是把 λ 锁在窗口中心。
**第三步，起燃与失活**：低温下转化效率近零（未起燃），随温度升至起燃温度 $T_{50}$（转化率达 50% 的温度，约 250～350°C）后陡升。**催化剂还会失活**——铅/硫中毒、高温烧结、积碳覆盖——失活后转化效率逐年下降，需要更换。

**排放法规的本质**：用**排放限值（g/km）**倒逼「转化效率 + 起燃速度 + 寿命」全链条达标——国六、欧六标准越来越严，对应的正是三元催化更早起燃、更高转化、更耐老化。<span class="marginnote">排放法规的「尺度演进」：从国一到国六，$\ce{NO_x}$ 限值降了约 90%、PM 降了约 95%——每一次标准升级都逼出一轮技术升级（电喷→三元催化→SCR/DPF→新能源）。「标准拉动技术」是移动源治理的核心机制，这也呼应《环境法规与标准》里「标准是最有力的政策工具」。</span>

## 5 油品、检测与新能源

**（1）油品升级**——治本的基础：燃油含硫是催化剂毒物与 PM 前体。**车用油品从国三到国六（硫含量从 150 ppm 降到 10 ppm）**，让尾气后处理系统「敢用」——高硫燃油会让三元催化与 SCR 快速中毒。**油品先升级、后处理才有效**，是移动源治理的「先决条件」。<span class="marginnote">「油品与后处理」的先后逻辑：硫含量 500 ppm 的油，装 SCR/DPF 几个月就废——所以国五升级国六时「油品 + 排放标准」同步推进，车企才敢装高性能后处理。这也解释了为什么移动源治理一定是「油、机、器、路」四线并进。</span>

**（2）I/M 制度（检查与维护）**：在用车排放定期检测（年检尾气）、超标维修——**新车靠标准、在用车靠 I/M**，堵住「旧车高排放」的漏洞。

**（3）交通调控**：限行、老旧车淘汰、公交优先、智能交通减少怠速——从「车」的维度扩展到「路」的维度。

**（4）新能源替代**：电动车、氢燃料电池——**从源头消灭尾气**，是移动源治理的终极方向。但要看到「全生命周期」：电从哪来（火电也有排放）、电池回收（《电子废弃物》）、稀土开采——「零排放」是使用端还是全链条，是环境评价的辩证话题。<span class="marginnote">电动车的「排放转移」思考：纯电动车使用端零尾气，但发电（尤其火电）与电池制造仍有排放——所以「电动车是否更环保」要看电网清洁度与全生命周期核算（LCA）。这是《环境经济》里外部性内部化的经典案例：污染从「加油站」转移到「电厂与矿场」。</span>

## 6 小结

- 汽车尾气四主污染物：**$\ce{CO}$、$\ce{HC}$、$\ce{NO_x}$、PM**；生成机理相互矛盾，靠机内机外协同解决。
- **机内净化**（电喷、EGR、燃烧优化）是低成本第一道防线；**三元催化器**在 λ=1 窗口同时净化三污染。
- **柴油车后处理**：DOC + **DPF**（捕 PM）+ **SCR**（除 $\ce{NO_x}$）黄金三件套。
- 转化效率受**空燃比窗口、起燃温度、催化剂失活**三因素控制；冷启动排放是难点。
- 移动源治理体系：**油品升级 + 排放标准 + I/M 制度 + 交通调控 + 新能源**，标准拉动技术升级。
