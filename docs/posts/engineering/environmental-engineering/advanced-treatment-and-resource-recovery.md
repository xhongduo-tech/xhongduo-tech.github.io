## 为什么从污水深度处理与资源化开始

前几节讲的是「把水处理到达标排放」，这一节把视角再推进一步：**处理完的水与泥，能不能变成资源？** 当再生水回用于绿化、冲厕、工业冷却甚至直接饮用，当污水里的磷、氮被回收成化肥，当剩余污泥变成能源与建材，污水厂就从「花钱消灾」的末端设施，升级为「城市资源回收中心」。这一节串联《膜分离技术》《中水回用》《污水脱氮除磷》与《固体废物资源化》的公共逻辑：深度处理靠什么技术（膜为主角）、资源回收靠什么抓手（磷回收与能源回收）。<span class="marginnote">一个观念转变：水处理行业的称呼正从「污水处理厂」变成「再生水厂/资源回收设施（Water Resource Recovery Facility）」。这不是改名游戏，而是设计目标的根本转向——从「达标排放」到「物尽其用」。</span>

这一节也是「从极限到大模型」在环境工程里的具象化：深度处理既要用膜通量公式这类「极限式的小模型」，也要面对「水量水质波动」这种必须靠数据与经验共同应对的复杂系统。理解深度处理，就理解了现代水务为什么是「技术 + 数据 + 管理」三位一体的产业。

**一个宏观坐标**：中国城镇污水处理率已超 97%，「建得起厂」的问题基本解决，「把水用好」成为新矛盾——再生水利用率、污泥无害化率、磷回收率成了衡量一座城市水管理水平的三个新指标。深度处理与资源化，正是从「数量覆盖」走向「质量提升」阶段的必然技术选择。

## 1 深度处理的目标与技术路线

常规二级处理（活性污泥）出水只能达到「能排」的水平，要达到「能用」甚至「能喝」，需要**深度处理（tertiary treatment）**。深度处理的目标有三个层次：**脱氮除磷**（防富营养化）、**去除难降解有机物与微量污染物**（抗生素、内分泌干扰物）、**脱盐与微生物安全**（回用与饮用的前提）。

技术路线按「目标—手段」分三档：**第一档**是物理强化——混凝沉淀 + 过滤 + 消毒，把 SS 与浊度再压一个数量级；**第二档**是膜分离——微滤（MF）/超滤（UF）截留颗粒与细菌，反渗透（RO）脱盐，这是再生水的核心技术；**第三档**是高级氧化（AOP）——臭氧、UV/H₂O₂、芬顿，把抗生素等微量有机物「矿化」掉。<span class="marginnote">「颗粒—分子—离子」三档对应的孔径尺度：MF/UF 对付颗粒与细菌（0.01～1 μm），NF 对付二价离子与大分子，RO 对付溶解盐与几乎一切（孔径 < 1 nm）。膜技术是「按尺寸筛分」的极致。</span>

**为什么需要深度处理：二级出水的「死角」。** 活性污泥法对 BOD、SS、氨氮效果好，但对三类东西无能为力——难降解有机物（合成化学品）、溶解性盐（脱盐只能靠膜/蒸发）、病原体（还需消毒）。深度处理就是针对这些「死角」的补刀：混凝沉淀去细颗粒与磷、膜去盐与微生物、高级氧化去微量有机物。<span class="marginnote">一个典型场景：面对「出水总磷要 < 0.05 mg/L」这类超严要求，光靠生物除磷做不到，必须加化学除磷（加铝盐/铁盐混凝沉淀）——深度处理不是「锦上添花」，而是「达标刚需」。</span>

**辨析｜易错点：** 深度处理 ≠ 三级处理。三级处理是「位置概念」（二级之后的处理），深度处理是「目标概念」（为达标回用做的高标准处理）——两者多数时候重合，但严格说，二级出水若直接满足回用标准就不必上深度处理，而某些工业废水可能一进厂就要「深度处理」。分清「位置」与「目标」，才不会被术语绕晕。

## 2 膜技术：深度处理的主角

**膜分离**的本质是一张「筛子」，靠孔径与压差把溶质留下。四大膜按孔径从小到大排列：**微滤 MF**（0.1～1 μm，截留悬浮物与细菌）、**超滤 UF**（0.01～0.1 μm，截留病毒与大分子）、**纳滤 NF**（约 1 nm，截留二价离子与部分有机物）、**反渗透 RO**（< 1 nm，截留几乎一切，包括盐分）。<span class="marginnote">膜的驱动力：MF/UF/NF 主要靠压差，RO 必须克服渗透压——所以 RO 需要高压泵（5～40 bar），能耗远高于 MF/UF。这就是为什么「能 UF 就不 RO」是膜工艺选型的铁律。</span>

膜工艺运行有两个绕不开的敌人：**浓差极化**与**膜污染**。浓差极化是溶质在膜面堆积形成高浓度边界层、抬高局部渗透压；膜污染是污染物吸附堵塞膜孔、通量下降。工程对策是**错流过滤**（让料液切向流过膜面带走堆积物）加**定期反冲洗**。膜通量是设计核心参数：

$$J = \frac{Q}{A} = \frac{\Delta P - \Delta \pi}{\mu R_m}$$

$J$ 为膜通量（L/(m²·h)），$Q$ 为透过流量，$A$ 为膜面积，$\Delta P$ 为跨膜压差，$\Delta \pi$ 为渗透压差（RO 必须扣除），$\mu$ 为粘度，$R_m$ 为膜阻力。<span class="marginnote">通量公式的工程含义：压力越高通量越大，但膜污染也越快；实际运行常把通量压到理论值的 1/3～1/2，换取稳定运行寿命。这就是「运行通量」与「极限通量」的差别。</span>

**膜工艺的家族应用**：MF/UF 用于「前置过滤」与「反渗透预处理」（MBR 膜生物反应器把膜直接放进生化池、取代二沉池）；NF 用于「选择性脱盐」（软水、去除硬度）；RO 用于「脱盐制再生水」（中水回用、海水淡化）。一条产业链上，膜技术从「末端精处理」扩展到了「工艺替代」——**MBR 已经让「膜 + 生物」成为新厂的主流选项之一**。

**膜系统成败的关键在「预处理」**：RO 膜对进水浊度、SDI（污泥密度指数）、余氯极其敏感，进水不合格会让膜在数月内报废。所以 RO 前必配「预处理链」——混凝、MF/UF、阻垢剂、脱氯——工程界有句老话：「膜系统的寿命是预处理设计出来的」。**再好的膜也救不了糟糕的预处理**，这是无数膜项目用教训换来的经验。<span class="marginnote">RO 的浓水（约占 25%）是含高盐高污染物的「苦水」，不能直接排——浓水处理（蒸发、结晶、或回用于冲灰）是 RO 系统设计必须一并考虑的「另一半账」。</span>

## 3 磷回收与氮资源化：从「污染物」到「肥料」

氮磷在传统工艺里是「要除掉的富营养化元凶」，但在资源视角下它们是**不可再生的养分**——磷矿石的全球储量按目前开采速度仅够约 100 年。磷回收因此成了污水资源化的明星方向。主流路线是在生物除磷的污泥上清液中加镁盐（$\ce{MgCl2}$ 或 $\ce{MgO}$），与磷酸根在碱性条件下结晶出**鸟粪石（struvite，$\ce{MgNH4PO4·6H2O}$）**：

$$\ce{Mg^2+ + NH4+ + PO4^3- + 6H2O -> MgNH4PO4·6H2O(s)}$$

鸟粪石是优质的缓释磷肥，一吨可以卖数百元，同时把 N、P 一起从水相搬进固相、缓解了出水磷超标——一举两得。加拿大、荷兰、德国已有规模化工程，中国的磷回收示范项目也在苏州、无锡等地落地。<span class="marginnote">鸟粪石结晶的关键控制参数是 pH 与镁磷比：pH 常调到 8.5～9，镁磷比约 1.1～1.5 时结晶效率最高。回收效率可达进泥磷负荷的 80%～90%。</span>

氮的资源化相对困难：大部分氮在硝化—反硝化中变成了氮气逸入大气，只有少部分进入污泥。工程上氮回收更多转向**厌氧氨氧化（Anammox）**——它把氨氮直接与亚硝酸盐反应生成氮气，比传统硝化-反硝化省 60% 的曝气能耗、且不消耗有机碳源，是当下脱氮技术的前沿。<span class="marginnote">Anammox 菌（浮霉菌门）世代时间长、对环境极敏感，工程化难度大，但一旦稳定运行，侧流（污泥消化液）脱氮成本能大幅下降——这是《脱氮除磷》一章的技术前沿。</span>

**污泥的能源回收：资源化的另一半。** 污水里的有机物一半进了污泥，污泥厌氧消化产沼气（含 50%～60% 甲烷）可热电联产，把污水厂从「耗能大户」变成「能源工厂」。欧洲许多污水厂已实现能源自给率 100%+，中国也在推行「绿色低碳标杆厂」——**污水资源化的真正闭环，是水（再生水）、肥（鸟粪石）、能（沼气）三路并进**。<span class="marginnote">中温厌氧消化的典型参数：35°C 左右、停留 15～20 天，产气率约 0.5～0.8 m³/kg VSS。沼气提纯后可并入天然气管网，或用热电联产机组发电供热。</span>

## 4 核心对比表：再生水回用的三级用途

再生水的「纯度」决定了它能做什么用，也决定了深度处理要上到哪一级：

| 回用等级 | 典型用途 | 关键指标 | 所需处理 |
| --- | --- | --- | --- |
| 一级回用（低质） | 绿化、冲厕、道路洒水 | SS、浊度、色度 | 二级 + 混凝沉淀 + 消毒 |
| 二级回用（中质） | 工业冷却、景观补水 | COD、氨氮、硬度 | 深度处理 + MF/UF |
| 三级回用（高质） | 工艺用水、间接饮用（水库回灌） | 盐、微量有机物、微生物 | RO + 高级氧化 + 消毒 |

城市污水再生利用的核心标准是 **GB/T 18920-2020《城市污水再生利用 城市杂用水水质》** 与 **GB/T 18919 系列**。中国北方缺水城市（北京、天津、石家庄）早已把再生水纳入城市供水计划——北京每年再生水利用量超过 10 亿立方米，约占全市用水总量的四分之一。<span class="marginnote">「间接饮用」路径（污水→RO→地下水回灌→取用）在加州与新加坡 NEWater 已有成熟实践；「直接饮用」目前仅少数国家（如纳米比亚温得和克）实现，属于水处理皇冠上的明珠。</span>

**算一笔经济账**：城市再生水（一级 A + 深度处理）成本约 1.5～3 元/m³，海水淡化约 4～7 元/m³，跨流域调水约 5～10 元/m³——**再生水是缺水城市性价比最高的「新增水源」**。这也是为什么「污水资源化」本质上是「向空间要水」的经济选择，而不是单纯的环保情怀：对缺水城市，每一方再生水都在替代一方高价外调水。

## 5 公式解析：膜面积估算

设计膜系统时，最常见的逆向计算是「已知水量与目标通量，求膜面积」：

$$A = \frac{Q}{J}$$

- **$Q$**：设计产水流量（m³/h）。
- **$J$**：设计通量（L/(m²·h)）——注意单位换算：1 m³/h = 1000 L/h。
- **$A$**：所需膜面积（m²）。

**算例**：某再生水项目要产水 $Q = 200$ m³/h，UF 设计通量取 $J = 50$ L/(m²·h)，则 $A = 200\times1000 / 50 = 4000$ m²。若单支膜面积 50 m²，则需要 80 支膜；再按「实际可用膜率 90%、运行安全系数 1.15」放大，实际要配 80 / 0.9 × 1.15 ≈ 102 支。<span class="marginnote">「设计通量」的选取直接决定膜系统的造价与寿命：通量取得高，膜少、省初投资，但污染快、清洗频繁、膜寿命短；取低则相反。工程上 UF 常取 40～80 L/(m²·h)、RO 常取 15～25 L/(m²·h)。</span>

## 6 术语速查

| 术语 | 一句话定义 |
| --- | --- |
| 深度处理 | 二级处理后为进一步回用/达标所做的三级处理 |
| MF / UF / NF / RO | 微滤 / 超滤 / 纳滤 / 反渗透，按孔径从小到大 |
| 膜通量 J | 单位膜面积单位时间的透过水量 |
| 浓差极化 | 溶质在膜面堆积形成高浓度边界层的现象 |
| 膜污染 | 污染物吸附堵塞膜孔导致通量下降 |
| MBR | 膜生物反应器，膜 + 生化池的组合工艺 |
| 鸟粪石 | $\ce{MgNH4PO4·6H2O}$，磷回收的缓释磷肥 |
| Anammox | 厌氧氨氧化，氨氮直接与亚硝酸盐生成氮气 |
| 再生水 | 达标后回用于杂用/工业/生态的水 |

**记忆锚点**：深度处理「按目标选档」——回用等级越高，膜孔径越小、能耗越大。而磷回收的鸟粪石结晶与 Anammox 脱氮，是把「污染物」当「资源」的两面旗帜。<span class="marginnote">延伸视角：污水资源化的终局是「能源厂 + 肥料厂 + 再生水厂」三合一——新加坡 NEWater 与荷兰的能源中和污水厂已证明这条路在经济上可行。</span>

## 7 小结

- 深度处理三档技术：物理强化（混凝过滤）→ 膜分离（MF/UF/RO）→ 高级氧化（臭氧/H₂O₂/芬顿）。
- 四大膜按孔径：MF > UF > NF > RO；RO 靠高压克服渗透压、能耗最高，能 UF 就不 RO。
- 膜通量 $J = (\Delta P - \Delta \pi)/(\mu R_m)$，浓差极化与膜污染是运行两大敌人，错流+反冲洗应对。
- 膜面积设计 $A = Q/J$，设计通量的选取是「初投资 vs 寿命」的权衡。
- 磷回收靠鸟粪石结晶 $\ce{MgNH4PO4·6H2O}$，缓释磷肥 + 缓解出水磷超标，一举两得。
- 再生水按用途分三级，北京年回用量超 10 亿 m³，缺水城市的再生水已进入市政供水体系。
- 污水厂的未来是「能源厂 + 肥料厂 + 再生水厂」三合一：从末端消纳走向资源回收中心。
- 深度处理是「目标概念」而非「位置概念」：为达标回用做的高标准处理，多数但非必然等于三级处理。
- 污水资源化三路并进：水（再生水）、肥（鸟粪石）、能（沼气热电联产）——污泥厌氧消化让污水厂从耗能走向产能。
- 中国城镇污水处理率已超 97%，从「建厂」转向「用好水」，再生水率、污泥无害化率、磷回收率是新指标。
- 再生水成本（1.5～3 元/m³）远低于海水淡化与跨流域调水，是缺水城市性价比最高的新增水源。
- 膜系统成败在预处理，RO 浓水处理是设计必须一并考虑的「另一半账」。
- 本节要记住「三档技术 × 三级用途」的对应：回用等级越高，膜孔径越小、能耗越大。
- 再生水经济账（1.5～3 vs 4～7 vs 5～10 元/m³）是「污水资源化」的第一说服力——向空间要水而非向外调水。

在下一节，我们将离开水体、把目光投向天空，回答「大气污染是怎么发生、怎么随气象扩散的」——这就是**大气污染气象学**。
