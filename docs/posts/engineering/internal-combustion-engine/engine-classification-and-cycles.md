## 为什么从分类与循环开始

内燃机是全部《内燃机》课程的**入口**：此后的换气、缸内流动、燃烧、排放、传热、摩擦，全部是「在某个确定的循环框架里，把四个冲程里的某一段做得更好」。
开篇不把循环讲透，后面每一章都会悬空。
<span class="marginnote">在第六级《动力工程》里我们已用空气标准循环算过理论效率，这里要把循环「装进钢铁」：看奥托、狄塞尔两位工程师如何把热力学公式变成能转的机器。与博客主线同构的是：热循环是一个「在约束下求能量转换极值」的优化问题，和大模型训练求损失极小值、做超参搜索是同一个方法论骨架。</span>

## 1 内燃机在热机家族中的位置

**热机（heat engine）**：把热能转化为机械功的装置。
整个家族按「燃烧发生在哪里」分成两支：

**外燃机**：燃料在气缸之外燃烧，热先传给工质。蒸汽机、斯特林发动机属于此类——锅炉与做功气缸分离。
- **内燃机（internal combustion engine）**：燃料在气缸**内部**燃烧，高温燃气本身既是工质、又直接推动活塞。

内燃机由此获得三个特征：**工作介质来自燃气本身**（省掉锅炉与换热环节）、**工质即产物**（燃烧后直接膨胀做功）、**间歇工作**（能量以循环为单位断续释放，必须靠飞轮平滑）。

**重点：内燃机与蒸汽机竞争的一百多年，本质是一场「谁能把高温高压制住、而不是被它吓住」的较量。** 蒸汽机把热量交给水管再交给汽缸，每一层传递都损失一次；内燃机让爆炸直接发生在气缸里，省掉的每一层换热，都是白捡的效率。

## 2 分类：一张表看清内燃机的家族树

内燃机的分类维度很多，但真正决定「这台机器怎么烧」的只有两个：

- **按点火方式**：**火花点火（SI，spark ignition）**——汽油机，火花塞强制点燃；**压燃（CI，compression ignition）**——柴油机，靠压缩终了的高温自发着火。
- **按工作循环**：**四冲程**（一个循环四个行程、曲轴两圈）与**二冲程**（一个循环两个行程、曲轴一圈）。

其余维度都是「外围」：按运动方式分**往复式**（活塞上下）与**旋转式**（汪克尔转子机，转子绕偏心轴转）；按冷却方式分**水冷**与**风冷**；按进气方式分**自然吸气**与**增压**；按气缸排列分直列、V 型、水平对置、星形。
<span class="marginnote">旋转式的汪克尔转子机把「往复+气门」简化为「转子+端盖进排气口」，结构零件少、转速高、振动小，但燃烧室形状变化大、密封条磨损快、油耗偏高，最终没能取代往复式——它很好地演示了「结构简化」与「燃烧恶化」之间的此消彼长。</span>

| 分类维度 | 类别 | 代表机型 | 一句话差别 |
| --- | --- | --- | --- |
| 点火方式 | SI / CI | 汽油机 / 柴油机 | 点燃 vs 压燃，根本机理不同 |
| 工作循环 | 四冲程 / 二冲程 | 汽车 / 舷外机、摩托 | 一圈 vs 两圈出一个功 |
| 运动方式 | 往复 / 旋转 | 活塞机 / 转子机 | 直线—旋转转化 vs 直接旋转 |
| 进气方式 | 自然吸气 / 增压 | 家用车 / 高性能、重型机 | 是否有外力压入更多空气 |
| 冷却方式 | 水冷 / 风冷 | 汽车 / 摩托车、小型机 | 冷却介质不同 |
| 气缸排列 | 直列 / V / 对置 | L4 / V6、V8 / 斯巴鲁 | 平衡性与布置取舍 |

**辨析｜易错点：**「SI/CI」与「汽油/柴油」并不完全一一对应。
汽油机也可以压燃（均质压燃 HCCI 就是汽油机的压燃路线），柴油机也可以点火助燃（低排放技术里就有火花辅助柴油机）。
正确的说法是：**SI 与 CI 是燃烧组织方式的区别，汽油与柴油是燃料物性的区别，二者大多数时候重合、但技术上完全可以解耦**。

## 3 四冲程工作循环

以四冲程 SI 机为例，活塞从上止点到下止点再回来，叫做一个**行程（stroke）**。
四个行程构成一个循环，曲轴正好转两圈：

1. **进气冲程**（TDC→BDC）：进气门开，活塞下行，新鲜混合气被吸进气缸。
2. **压缩冲程**（BDC→TDC）：两门关闭，活塞上行压缩混合气，压力和温度急剧升高，为点火做准备。
3. **做功冲程**（TDC→BDC）：点火后燃气爆燃，高温高压燃气膨胀推动活塞下行，**这是唯一对外输出功的冲程**。
4. **排气冲程**（BDC→TDC）：排气门开，活塞上行把废气推出气缸。

**重点：四个冲程里只有一个出功，其余三个都靠飞轮储存的动能「扛过去」。** 因此单缸四冲程机扭矩波动极大，必须用大飞轮；多缸机的本质，就是**用相位错开的多个做功冲程抹平扭矩谷**——这就是三缸机抖、六缸机顺、V8 更平顺的机理。
<span class="marginnote">二冲程机把进气和压缩合并进一个行程、做功与排气合并进另一个行程，曲轴每圈都做功，比功率（功率/排量）高、结构简单，但换气靠扫气口，新鲜工质与废气掺混严重，扫气损失大、碳氢排放高——从《换气过程》一章会看到，四冲程的「四冲程」本身就是为了把换气做干净而付出的代价。</span>

**辨析｜易错点：**三个方向经常被搞反——**压缩冲程和排气冲程都是活塞上行（BDC→TDC），进气冲程和做功冲程都是下行（TDC→BDC）**。
记法：凡是「把东西装进气缸」都是下行（进气靠负压、做功靠膨胀），凡是「把气缸里腾空」都是上行（压缩、排气）。
另外，一个循环曲轴转 **两圈**，其中只有 **一圈** 在对外做功。

## 4 理想循环：奥托与狄塞尔

真实循环太复杂，教科书先做四个**空气标准假设**：工质是空气理想气体；比热容不变；压缩与膨胀都是等熵的（无摩擦、绝热）；燃烧过程用**定容加热**或**定压加热**代替。
<span class="marginnote">「用加热代替燃烧」是循环分析的灵魂：燃烧的本质是释放热量，只要热量和加入的时机对，用等效加热就能算效率的上限。这个「用等效过程代替复杂化学反应」的建模手法，与化学工程里用表观动力学代替基元反应如出一辙。</span>

- **奥托循环（Otto cycle）**：定容加热。过程 1→2 等熵压缩，2→3 **定容加热**，3→4 等熵膨胀，4→1 定容放热。对应**火花点火机**。
- **狄塞尔循环（Diesel cycle）**：定压加热。过程 1→2 等熵压缩，2→3 **定压加热**，3→4 等熵膨胀，4→1 定容放热。对应**压燃机**。

两循环共享同一条等熵压缩线，差别只在加热段——奥托是竖直的定容线，狄塞尔是水平的定压线（见下图）。**奥托的峰值压力高（定容加热下温度直接顶到缸压上限），狄塞尔的峰值温度低但做功线更长。**

![奥托循环与狄塞尔循环的 p-V 图对比，同压缩比下加热方式不同](/images/internal-combustion-engine/engine-classification-and-cycles-1.svg)

**压缩比（compression ratio）** 是循环分析的第一个关键数：**最大容积与最小容积之比**。

$$r = \frac{V_1}{V_2} = \frac{V_c + V_d}{V_c}$$

其中 $V_c$ 是燃烧室容积（上止点容积），$V_d$ 是排量（工作容积）。压缩比把「气缸几何」翻译成「循环上下限温度之比」，是效率公式的唯一输入。

## 5 公式解析：奥托循环热效率

奥托循环热效率是内燃机课程的第一条核心公式：

$$
\eta_{th} = 1 - \frac{1}{r^{\gamma - 1}}
$$

拆成三步理解：

- **第一步，写出热效率定义**：$\eta_{th} = 1 - \dfrac{q_{out}}{q_{in}}$。定容加热 $q_{in} = c_v(T_3 - T_2)$，定容放热 $q_{out} = c_v(T_4 - T_1)$，两者之比化简为温度比。
- **第二步，用等熵关系把温度比翻译成容积比**：对等熵过程 1→2，有 $T_2/T_1 = (V_1/V_2)^{\gamma-1} = r^{\gamma-1}$；同理 $T_3/T_4 = r^{\gamma-1}$。代入后消去所有温度，只留下压缩比。
- **第三步，读出结论**：$\eta_{th}$ 只取决于 $r$ 与 $\gamma$，**压缩比越高、效率越高**，而燃料种类（决定 $\gamma$）只起次要作用。

**重点：这个公式解释了内燃机一百年的两个大方向。** 一是把 $r$ 往高推——柴油机靠压燃躲开爆震，$r$ 高达 16–24，热效率也因此做到 40% 以上；汽油机受爆震（见《汽油机燃烧过程》）限制，$r$ 停在 8–12。二是工质比热：真实气体 $\gamma$ 随温度下降，定容加热终了的高温让 $\gamma$ 变小，效率被压低一截——这就是「理论效率必须打折」的第一个来源。狄塞尔循环的效率公式还要多一项由**截止比** $r_c$（定压加热终点与起点容积之比）决定的修正项，$r_c$ 越大、效率越低。

## 6 实际循环与理想循环的偏差

理想循环给出了上限，真实内燃机离它有多远？主要有六笔「亏损」：

- **泵气损失**：进排气要克服气道阻力，活塞在进、排气两个冲程里做的负功（示功图上「负环」的面积）。
- **传热损失**：高温燃气把热传给缸壁、冷却水，白烧。
- **燃烧不是瞬间完成的**：点火必须**提前**（点火提前角），膨胀后期还在补燃，放热曲线被拉长。
- **排气损失**：做功终了时缸内仍有高温高压，排气门一开，这部分「剩余火用」随废气跑掉——这正是《增压》一章要回收的能量。
- **工质比热随温度变化**：高温下 $\gamma$ 变小，等熵线变「软」，效率打折。
- **工质成分变化**：燃烧后 CO₂、H₂O 混入，不再是纯空气。

把这些损失串起来，就是内燃机的**效率乘法链**：

$$\eta_{brake} = \eta_{th} \times \eta_{indicated} \times \eta_{mech}$$

理论效率（空气标准循环）乘上指示效率（缸内实际做的功）再乘上机械效率（摩擦、附件消耗后的输出），三者连乘才是一台发动机真正送到曲轴端的效率。理解内燃机，就是理解这条乘法链上每一环被什么吃掉。

## 7 小结

- 内燃机是**缸内燃烧、燃气即工质、间歇做功**的热机，与蒸汽机的差别是「燃烧是否在气缸内发生」。
- 分类轴心是**点火方式（SI/CI）**与**工作循环（四/二冲程）**，其余维度都是外围；SI/CI 与汽油/柴油可以解耦。
- 四冲程为**进气—压缩—做功—排气**，曲轴转两圈出一个功，其余三冲程靠飞轮维持；二冲程每圈出功但换气不净。
- 奥托循环**定容加热**、狄塞尔循环**定压加热**，共享等熵压缩与等熵膨胀骨架。
- 奥托效率 $\eta = 1 - 1/r^{\gamma-1}$：**只与压缩比和比热比有关**，这就是发动机不断推高压缩比的根本原因。
- 实际循环有泵气、传热、燃烧时间、排气、比热、成分六笔亏损，最终效率是**理论×指示×机械**的乘法链。

在下一节，我们将把「效率」换成可测量的量——扭矩、功率、平均有效压力、比油耗，并学会从示功图里读出真实的缸内过程，这就是**发动机性能与循环分析**。
