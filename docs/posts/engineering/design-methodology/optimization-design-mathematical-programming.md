## 为什么从数学规划开始

概念阶段我们用形态学矩阵与决策矩阵选出了「用什么原理」，但选好原理不等于做好产品——剩下的问题是如何在给定的原理与约束下，把尺寸、材料、参数调到最优。传统做法是「试错 + 经验」，现代做法是**把设计问题翻译成一个数学规划，交给优化算法求解**。<span class="marginnote">阿基米德名言讲的是「支点」——优化的第一课也正是一个支点问题：<strong>目标函数与约束放在哪，决定了整个求解的成败</strong>。问题形式化（formulation）比算法选择更关键。</span>

在课程体系里，这一节把第一级《微积分》的极值、第二级《线性代数》的向量空间、以及《最优化理论》《数值分析》直接接到机械设计上；它也是第八篇可靠性设计、第九篇田口方法的共同数学底座。<span class="marginnote">第四级《机器学习》里的「梯度下降」在这里以另一种形式出现：机械优化的目标函数常常没有解析表达式，只能靠有限元仿真给出，这就是「黑箱优化」问题的由来。</span>

本篇按「建模 → 求解 → 应对现实」三层展开：先学会把机械问题写成标准形式，再认识主要的问题类型与算法，最后直面全局最优与多目标这两个实战难题。

## 1 把设计问题翻译成数学规划

一个机械优化问题的三要素：

- **设计变量（design variables）** $x = (x_1, x_2, \dots, x_n)$：工程师能自由决定的量，如齿轮模数、壁厚、弹簧钢丝直径、轴承跨距。设计变量要独立、要有界。
- **目标函数（objective function）** $f(x)$：要最小化（或最大化）的量，如质量、成本、应力峰值、能耗。
- **约束（constraints）**：设计要求的形式化，分**不等式约束** $g_i(x) \le 0$（如应力不超过许用值、挠度不超过限值）与**等式约束** $h_j(x) = 0$（如力平衡方程、几何封闭方程）。

**最优解**通常在「约束边界」上：机械优化很少是「无约束地取极值」，而是「在材料不破坏、变形不超限的边界内，把质量压到最低」——所以真正起作用的是约束的交叉点，而不是目标函数的驻点。这是机械优化与纯数学优化的第一差别。

举一个能落地的例子：设计一根圆柱螺旋压缩弹簧，目标是最小质量；设计变量是钢丝直径 $d$、弹簧中径 $D$、有效圈数 $n$；约束包括应力不超过许用、刚度满足要求、不发生失稳、几何尺寸在安装空间内。这样一个问题，用「试算三个方案取好」的传统办法，很容易错过真正的轻量化方案——而数学规划能系统地搜遍可行域。

## 2 公式解析：标准优化模型与拉格朗日乘子

把三要素写成标准形式：

$$\min_{x} \; f(x) \quad \text{s.t.} \quad g_i(x) \le 0 \ (i=1,\dots,m), \quad h_j(x) = 0 \ (j=1,\dots,p)$$

拆开看：

- **$\min_x f(x)$**：在 $n$ 维设计空间里寻找使目标最小的点。等式约束把可行域降为一张曲面，不等式约束把可行域切成一块区域。
- **$g_i(x) \le 0$**：主动约束（active）在最优解处取等号——「材料刚好不屈服」正是经济性的标志；不取等号的约束是「冗余约束」，说明设计还可再挖。
- **拉格朗日乘子（Lagrange multiplier）** $\lambda$：把约束并入目标，$L = f + \sum \lambda_j h_j + \sum \mu_i g_i$。乘子的值等于「放松该约束 1 单位，目标能改善多少」——它是约束的**影子价格**，告诉工程师该把努力花在哪个约束上。

**数字直觉**：设计一根悬臂梁，目标是最小质量，约束是端部挠度 $\delta \le \delta_{\max}$。若最优解处挠度约束恰好取等号（材料应力还远低于许用），影子价格告诉我们「去优化挠度约束最划算」；若应力已取等号而挠度富余，则「换材料提强度」收效甚微——乘子帮我们把调试方向钉死。<span class="marginnote">影子价格的工程读法：乘子大的约束，是当前设计的「瓶颈」；放宽它，目标改善最多。优化报告里列出各约束的乘子，等于给设计团队一张「先改哪、后改哪」的优先级清单——这比单纯看最终数字有用得多。</span>

## 3 机械优化问题的类型与求解策略

按问题结构，机械优化大体分四类：

- **线性规划（LP）**：目标与约束都线性，单纯形法可求全局最优。机械里的排样下料、装配线工位平衡、混合料配比是典型场景。
- **混合整数规划（MILP）**：部分变量只能取整数——选「第几号标准件」、选「多少台设备」。求解更难，常用分支定界。
- **连续非线性规划（NLP）**：应力、挠度、效率几乎都是非线性的。可用梯度类方法（序列二次规划）或**无导数方法**（遗传算法、模拟退火、差分进化）。<span class="marginnote">机械设计目标函数常来自有限元仿真，导数无法解析获得——这时无导数方法与<strong>响应面法（response surface）</strong>（用少量仿真点拟合近似函数再优化）成为主力。响应面本质是「用插值替代仿真」，代价是近似的误差，好处是求解快几个数量级。</span>
- **多目标优化（multi-objective）**：质量、成本、寿命往往要同时最小化。加权和法把多目标压成单目标，但更严谨的是求**帕累托前沿（Pareto front）**：在这条曲线上，任何一个目标都无法在不恶化其他目标的前提下继续改善。工程师最终在帕累托前沿上做人机交互式的取舍，而不是靠一个标量一锤定音。

**约束处理**：惩罚函数把约束压进目标（违反约束即加罚值），这是无导数算法的通行做法；

对机械设计者，NLP 里最常遇到的算法是**序列二次规划（SQP）**：它把非线性问题在每步线性化，用成熟的二次规划子问题求下降方向，对「应力、挠度这类光滑非线性」非常高效；而遗传算法这类进化算法对「不光滑、多峰、离散混合」的问题更稳。选算法不是「哪个最强」，而是「匹配问题的几何」——光滑连续用梯度类，黑箱多峰用进化类。但罚因子设得不好会引入大量局部极小，是实战中最常见的坑。更稳妥的是用「可行域优先」的策略：先找一个可行解，再在可行域内持续改进目标，而不是让算法在可行与不可行之间反复横跳。

## 4 一个完整的算例：弹簧的轻量化设计

把第 1 节的弹簧例子走到底，展示「建模—求解—解读」的闭环。设弹簧的剪切许用应力 $\tau_{max} = 800$ MPa，要求刚度 $k = 20$ N/mm，安装空间限定外径不超过 60 mm、自由高度不超过 150 mm。目标是最小质量，等价于最小化钢丝体积 $V = \pi^2 D d^2 n / 4$。

- **设计变量**：$d \in [1,\ 8]$ mm，$D \in [5,\ 50]$ mm，$n \in [2,\ 20]$ 圈。
- **约束**：应力约束 $\tau(d,D) \le 800$ MPa；刚度约束 $k(d,D,n) = 20$ N/mm；几何约束 $D + d \le 60$ mm、$n d + \delta_{max} \le 150$ mm。
- **求解**：这是非线性约束优化，用序列二次规划或遗传算法迭代求解；最优点通常落在「应力约束 + 刚度约束 + 一个几何约束」的交点上——三个不等式里至少两个取等号。
- **解读**：收敛后看乘子——若应力约束的乘子最大，说明「材料刚好在强度边界」，换更高强度材料收益最大；若几何约束乘子最大，说明「是安装空间卡住了更优解」，改空间比改材料更有效。

这个算例的启示：**优化真正的产出不是那组数字，而是「哪个约束在卡我、改了它收益多大」的洞察**——这正是汉明所说的「计算的目的是洞察」在机械优化里的回响。

一个补充的现实观察：弹簧这类「解析公式可写」的问题，是机械优化里的少数派。更多情况是目标与约束只能靠仿真给出（应力场、模态、疲劳），于是「优化—仿真」之间需要不断往返：优化算法给出新参数，仿真算一次目标，再喂回优化器。这种「黑箱 + 迭代」正是响应面与代理模型（第 3 节）存在的理由——它们把往返次数从上千压到几十。<span class="marginnote">这也是为什么「形式化比算法重要」：约束写漏一条（比如忘了失稳约束），算出的「最优弹簧」在真实里就是一根会失稳的废品。优化的可信度，先取决于模型对现实的忠实度。</span>

## 5 全局最优与局部最优（辨析）

非线性、多峰的机械问题里，「算法给出的答案」常常只是**局部最优（local optimum）**，而不是**全局最优（global optimum）**——算法贪心地爬到了最近的山头，却没发现旁边还有更高的山。识别与规避办法：

- **多起点**：从不同初始点启动优化，观察是否收敛到同一解；不一致说明多峰，需谨慎。
- **全局启发式**：遗传算法、粒子群以群体搜索对抗多峰，能翻越部分峰谷，但不能保证全局最优（这是不可判定层面的现实）。
- **对初值极敏感**：非线性优化的解严重依赖起点，这正是「问题形式化 + 好初值」比「高级算法」更重要的原因。

**辨析｜易错点：** 优化不是「把参数都改到极限」。把尺寸都推到约束边界，产品就站在失效悬崖上——真实设计必须留**安全余量与稳健性**（见第九篇田口方法），并把制造公差、材料波动当作设计变量的一部分，而不是事后的补丁。一个贴着约束边界的「最优」加上一丁点制造误差就可能越界失效，这种最优是纸面的、危险的。

还有一层「数值陷阱」：当设计变量量纲差异悬殊（如壁厚是毫米级、跨距是米级），未经归一化的优化会「偏向」量纲大的变量，收敛很慢甚至停在不合理点。正规做法是对变量做归一化（除以各自的上限），让各变量在同一量级上竞争——这是机械优化里最不起眼却最常踩的坑之一。

## 6 优化软件的工程现实：从公式到产线

理论上的数学规划，到工程里有一层「现实折扣」，值得如实面对：

- **目标函数要能算**：应力、挠度、疲劳寿命都要靠仿真或经验公式给值，仿真的精度就是优化的天花板——「垃圾进、垃圾出」在优化里同样成立。
- **变量有离散与标准件**：齿轮模数要选标准系列、轴承要选货架型号——连续最优解要「取整到标准件」，这一步常让「最优」降档成「次优」，所以要把标准系列当作离散变量纳入模型。
- **鲁棒性 vs 最优性**：第七篇提过，贴边界的「最优」一遇波动就失效；工业实践常退而求其次，选「离边界有安全余量」的次优解——这正是第九篇田口稳健设计与本节的接口。
- **计算成本**：一次有限元仿真可能数分钟，优化要跑成百上千次——所以响应面、代理模型、并行计算是工程优化的家常便饭。

理解了这层现实，就能明白为什么「会用优化软件」不等于「会做优化设计」：真正值钱的是建模（把约束写全、把目标选对）与解读（乘子、瓶颈、稳健性），这些恰是本专题反复强调的元能力。

对学习者来说，优化设计最重要的认知是**位置感**：优化不是设计的起点，而是「原理选定之后」的精细化环节——它把「用什么方案」和「把方案调到多好」分得清清楚楚。前面概念阶段的错误，优化再强也救不回来；而原理选对之后，优化的空间往往比直觉想象的大得多。

另一个值得记住的边界是**优化的结论总要与稳健性对话**：数学上的最优点常常贴着约束边界，而真实世界充满公差与波动。把优化的结果交给第九篇田口方法做稳健性检验，把「最优」修正为「稳健的最优」，才是工程上可交付的答案。这提醒我们：方法学里的每一篇都不是孤岛，而是同一套「把设计做好」的系统里的部件。<span class="marginnote">本专题的阅读方式也正应如此：把十三篇当作一套互相咬合的工具箱，而不是十三件各自孤立的兵器。</span>

优化在工业界的普及还伴随着一句忠告：**别让算法替你承担「该由人承担的价值判断」**——目标函数是「最轻」还是「最便宜」，本质上是对产品定位的表态；帕累托前沿上的取舍更是如此。工具给的是曲线，拍板始终是人。

**动手练习**：拿第七篇的悬臂梁例子，自己写出完整的数学模型——设计变量、目标、所有约束，再手算或用现成工具解一次；解完写一份「约束乘子解读」：哪个约束在卡、改它收益多大。这个「建模—求解—读乘子」的完整闭环，比记住任何一条公式都更能建立优化的手感。

回顾本篇的完整链条：**建模（三要素）→ 求解（四类问题）→ 解读（乘子与瓶颈）→ 稳健化（交给第九篇）**——每一步都和前后的方法咬合，这正是本专题「工具互相咬合」的一个缩影。

对数学规划本身有更深兴趣的读者，可以继续研读《最优化理论》与《数值分析》专题——本篇只取了机械设计最常用的那一面。

## 7 小结

- 机械优化三要素：**设计变量、目标函数、约束**；最优解通常落在约束边界上。
- 标准模型 $\min f(x) \ \text{s.t.}\ g_i \le 0,\ h_j=0$；**拉格朗日乘子**是约束的影子价格，指明改进方向。
- 问题分 LP / MILP / NLP / 多目标四类；响应面与无导数方法应对「黑箱目标」。
- 完整的算例流程：建模 → 求解 → 读乘子 → 找瓶颈；「哪个约束在卡我」比那组数字更重要。
- **多目标**求帕累托前沿再人机取舍；**全局最优**须靠多起点与群体算法对抗局部极小。
- 优化结果要留安全余量并纳入公差与波动，否则是站在失效悬崖上的假最优。

在下一节，我们将从「最优」转向「最可靠」——如何在设计阶段就预见并管理失效，这就是**可靠性设计与失效模式分析（FMEA/FTA）**。
