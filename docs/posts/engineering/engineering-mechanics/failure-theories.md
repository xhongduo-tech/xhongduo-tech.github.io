## 为什么需要「判据」

前面各篇一直在算应力，但一直回避一个问题：**算出来的应力，多大算「不行」？** 单轴拉伸时答案直观——应力超过屈服强度就屈服，超过抗拉强度就断裂。可工程里几乎没有单轴拉伸：传动轴弯扭联合、压力容器双向受拉、车轮接触点三向受压。此时「应力多大算危险」没有现成答案，因为危险不取决于**某一个方向的应力**，而取决于**整个应力状态**。<span class="marginnote">失效理论（theories of failure）要回答的正是这个「判据」问题：把任意三维应力状态压缩成一个「等效单轴应力」，再与材料单轴试验得到的强度比较。它是连接「应力分析」与「强度设计」之间的最后一座桥。</span>

这里的关键在于，**同一种材料在不同受力方式下，破坏机制完全不同**：塑性材料（钢）屈服是「滑移」（剪应力驱动），脆性材料（铸铁）断裂是「拉断」（正应力驱动）。所以失效理论分两大类，先分清「韧」与「脆」，再选判据。

## 1 屈服与断裂：两种失效机制

**塑性材料（延性材料）**：以**屈服**为失效标志。钢、铝受拉先屈服（应变骤增、出现明显变形）再断裂。破坏机制是晶体沿特定滑移面**剪切滑移**，因此是**剪应力主导**的失效。
- **脆性材料**：以**断裂**为失效标志。铸铁、玻璃在极小的塑性变形后突然断裂，断口平齐。破坏机制是最大**拉应力**超过原子间结合力，因此是**正应力主导**的失效。

<span class="marginnote">一条直观记忆：弯折一段铁丝，听到「咔」声前它会先弯——延性；掰断一根粉笔，它直接就断——脆性。强度设计的第一步不是选公式，而是先回答「这材料失效长什么样」。</span>

「屈服还是断裂」决定了整个判据家族的分工：针对延性材料发展出**最大剪应力理论**与**最大畸变能理论**；针对脆性材料发展出**最大正应力理论**与 **Mohr 理论**。

## 2 延性材料：Tresca 与 von Mises

### 最大剪应力理论（Tresca）

**最大剪应力理论（maximum-shear-stress theory）**：当最大剪应力达到材料单轴屈服时的剪应力极限，材料即屈服。

单轴拉伸屈服时 $\tau_{\max} = \sigma_Y/2$，于是判据为

$$\tau_{\max} = \frac{\sigma_1 - \sigma_3}{2} \le \frac{\sigma_Y}{2} \quad \Longrightarrow \quad \sigma_1 - \sigma_3 \le \sigma_Y$$

Tresca 理论简单、偏保守，被压力容器规范等广泛采用。它等价于「用最大与最小主应力之差与屈服强度比较」。<span class="marginnote">注意这里用的是<strong>绝对最大剪应力</strong> $(\sigma_1 - \sigma_3)/2$（三向状态里取最大、最小主应力之差），而非平面状态的 $(\sigma_1 - \sigma_2)/2$——这一步最容易看漏，务必确认用的是哪两个主应力。</span>

### 最大畸变能理论（von Mises）

**最大畸变能理论（maximum-distortion-energy theory）**：应变能可分解为「体积变化能」（球量部分）与「形状畸变能」（偏量部分）。材料屈服由**畸变能**驱动，而非总体积变化能。由此得到 von Mises 判据：

$$\sigma_e = \sqrt{\frac{1}{2}\left[(\sigma_1 - \sigma_2)^2 + (\sigma_2 - \sigma_3)^2 + (\sigma_3 - \sigma_1)^2\right]} \le \sigma_Y$$

$\sigma_e$ 称为**von Mises 等效应力**。对最常用的平面应力状态（$\sigma_3 = 0$），展开得

$$\sigma_e = \sqrt{\sigma_1^2 - \sigma_1\sigma_2 + \sigma_2^2} \qquad \text{或} \qquad \sigma_e = \sqrt{\sigma_x^2 - \sigma_x\sigma_y + \sigma_y^2 + 3\tau_{xy}^2}$$

这一理论由胡贝尔（Huber）、米塞斯（von Mises）、亨基（Hencky）先后独立提出，与延性金属的试验结果吻合最好，是**工程默认**的延性判据。<span class="marginnote">为什么 von Mises 与试验更吻合？因为屈服的本质是晶体滑移，而畸变能恰是「引起滑移的能量」。Tresca 只用了 $\sigma_1$ 与 $\sigma_3$，忽略了中间主应力；von Mises 用到了全部三个主应力，信息更完整。</span>

**解析｜易错点：** 两组公式不要记混。平面状态里若直接用 $\sigma_x,\sigma_y,\tau_{xy}$，是 $\sigma_e = \sqrt{\sigma_x^2 - \sigma_x\sigma_y + \sigma_y^2 + 3\tau_{xy}^2}$；若改用主应力，是 $\sqrt{\sigma_1^2 - \sigma_1\sigma_2 + \sigma_2^2}$。两者完全等价，但把两个混合用（把 $\tau_{xy}$ 之外的项错位）就会出错。还有一个高频坑：**$\sigma_3 = 0$ 只在平面应力时成立**；三向应力时不能省略第三项。

## 3 脆性材料：最大正应力与 Mohr 理论

### 最大正应力理论

**最大正应力理论（maximum-normal-stress theory）**：当最大拉应力达到材料单轴抗拉强度时，材料断裂：

$$\sigma_1 \le \sigma_{ut}$$

脆性材料几乎不看剪应力——即使剪应力很大，只要最大拉应力不大，它仍不坏；反之主应力稍大就断。这个理论对铸铁、玻璃等典型的脆性材料在拉伸主导时表现良好。<span class="marginnote">注意最大正应力理论对<strong>压缩主导</strong>的脆性材料并不好用：铸铁单轴抗压强度远高于抗拉（约 3–4 倍），用单一的 $\sigma_{ut}$ 会过度保守。这正是要引入 Mohr 理论的原因。</span>

### Mohr 理论与 Coulomb-Mohr

**Mohr 失效理论（Mohr's failure theory）**：材料在任意应力状态下，当某一平面上的正应力-剪应力组合（即 Mohr 圆上的点）触及材料在该应力组合下的**包络线（envelope）**时失效。包络线由材料在不同应力组合下的试验确定。工程上常用其简化版：

**Coulomb-Mohr 判据**用两个试验点（单轴拉伸强度 $\sigma_{ut}$、单轴压缩强度 $\sigma_{uc}$）近似包络线：

$$\frac{\sigma_1}{\sigma_{ut}} - \frac{\sigma_3}{\sigma_{uc}} = 1$$

它比最大正应力理论更精确地刻画了「抗压强、抗拉弱」的脆性材料，也解释了「脆性材料压缩时比拉伸时强得多」。<span class="marginnote">混凝土抗压 30 MPa、抗拉仅 3 MPa——用它设计梁时，弯曲会在受拉侧引发开裂，于是必须配钢筋。Coulomb-Mohr 判据（$\sigma_1/\sigma_{ut} - \sigma_3/\sigma_{uc} = 1$）正是这一「强度不对称」的数学表达，也是《梁的弯曲》篇提到「钢筋放受拉侧」的强度理论依据。</span>

## 4 失效理论的横向比较

把四种主流理论放到同一张图（$\sigma_1$–$\sigma_2$ 平面）上比较，会发现它们对「安全区」的划分大致同心、边界不同：

**Tresca**：安全边界是六边形，最保守，落在 von Mises 椭圆之内。
- **von Mises**：安全边界是**椭圆**，介于 Tresca 内外之间，与试验最吻合。
- **最大正应力**：安全边界是正方形，只在一三象限（两个主应力同号）可靠。
- **Mohr/Coulomb-Mohr**：安全边界是不对称的（抗压抗拉不同），用于脆性。

**解析｜易错点：** 选判据不看材料属性、或把脆性判据用在延性材料上，是最常见的「原则性」错误。**口诀：延性材料选剪应力类（von Mises 或 Tresca），脆性材料选正应力类（最大正应力或 Coulomb-Mohr）**。此外，**静水压力（$\sigma_1 = \sigma_2 = \sigma_3 = -p$）不会使延性材料屈服**——它只改变体积不改变形状，不产生畸变能，所以 von Mises 判据里静水压部分被抵消。<span class="marginnote">「静水压不屈服」是 von Mises 理论的隐含结论：深海的潜艇壳承受巨大均匀压力却不屈服，靠的正是这一点。相反，脆性材料在静水压力下也常因三向受压而难以拉断——深部岩石、金刚石压砧都是实例。</span>

## 5 公式解析：von Mises 等效应力

用最简的平面状态公式把 von Mises 判据拆到底：

$$\sigma_e = \sqrt{\sigma_x^2 - \sigma_x\sigma_y + \sigma_y^2 + 3\tau_{xy}^2}$$

- **第一步，取「应力向量」的坐标**：$\sigma_x$、$\sigma_y$、$\sqrt{3}\,\tau_{xy}$ 看成三维空间的三个坐标。为什么 $\tau$ 前有 $\sqrt{3}$？因为畸变能里剪应力的权重与正应力不同——这是由畸变能公式逐项展开、再整理得到的，不是拍脑袋的系数。
- **第二步，算「距离」**：$\sigma_e$ 是这三个坐标的**欧氏范数**（平方和的平方根）。于是「等效应力」这个词有了精确的几何意义：**应力状态到「零应力点」的距离**——距离越大越危险。<span class="marginnote">把这个「范数」视角带回《组合载荷》篇的 $\sqrt{\sigma^2 + 3\tau^2}$：那里是弯曲正应力 + 扭转剪应力的特例（$\sigma_y = 0$）。对照一下两处公式，会得到一个很有用的记忆钩：$\sigma_e$ 永远是「平方和的根」。</span>
- **第三步，与屈服强度比较**：$\sigma_e \le \sigma_Y$。安全时等效应力不超过单轴屈服强度——这正是「等效」的含义：多轴应力状态被翻译成「相当于多大的单轴拉应力」。
- **第四步，回看极限情形**：纯剪切（$\sigma_x = \sigma_y = 0$）时 $\sigma_e = \sqrt{3}\,\tau$，故按 von Mises，纯剪切屈服应力 $\tau_Y = \sigma_Y/\sqrt{3} \approx 0.577\,\sigma_Y$；而 Tresca 给出 $\tau_Y = \sigma_Y/2$。两个理论在纯剪时的分歧（0.5 vs 0.577）是它们安全度差异的最直观体现——试验更靠近后者，这是 von Mises 胜出的证据之一。

## 6 小结

- **失效分两类**：延性材料**屈服**（剪应力主导），脆性材料**断裂**（正应力主导）——先分材料再选判据。
- **Tresca（最大剪应力）**：$\sigma_1 - \sigma_3 \le \sigma_Y$，保守、简单，用于压力容器等规范。
- **von Mises（最大畸变能）**：$\sigma_e \le \sigma_Y$，用全部三个主应力，与试验最吻合，是延性材料的默认判据。
- **最大正应力理论**：$\sigma_1 \le \sigma_{ut}$，用于脆性材料拉伸主导场合。
- **Coulomb-Mohr**：$\sigma_1/\sigma_{ut} - \sigma_3/\sigma_{uc} = 1$，刻画脆性材料「抗压强、抗拉弱」。
- **静水压力不引起屈服**：von Mises 判据中静水压被抵消。

在下一节，我们换一个视角：前面算的都是「载荷一定、应力多大」，现在反过来问——**变形（挠度）有多大**。《梁的挠度与变形》将给出梁弯曲变形的定量描述。
