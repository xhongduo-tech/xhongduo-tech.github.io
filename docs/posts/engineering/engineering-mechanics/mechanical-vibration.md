## 为什么最后讲「振动」

桥在风中微颤、发动机运转时的抖动、地震时高楼的摆动、弦乐器发声——振动是力学世界里最常见的「动」，也是所有工程结构都躲不开的宿敌与伙伴。<span class="marginnote">振动（vibration）是工程力学的收官主题：它把前三篇（静力学、材料力学、动力学）的工具全部征用——动力学的 $F = ma$ 给出方程，能量方法给出更快捷的建模路径，而屈曲篇的「特征值」思想在这里以「固有频率」的形式重新登场。</span>

更重要的是，振动是「从极限到大模型」主线上通向**信号处理、控制系统、乃至大模型里优化动力的数学基地**：二阶线性常微分方程的解、特征值、共振——这些概念在《常微分方程》《信号与系统》《控制论》里将以同一套语言反复出现。学完振动，你等于学会了整条技术主线里「周期世界」的第一课。

## 1 自由振动：弹簧-质量系统

最简单的振动系统是一个**质量-弹簧系统**（无阻尼）。设质量 $m$、弹簧刚度 $k$，取平衡位置为原点，牛顿第二定律给出运动方程：

$$m\ddot{x} + kx = 0$$

即 $\ddot{x} + \omega_n^2 x = 0$，其中

$$\omega_n = \sqrt{\frac{k}{m}}$$

称为系统的**固有角频率（natural angular frequency）**，其单位是 rad/s；对应的**固有频率（natural frequency）** $f_n = \frac{\omega_n}{2\pi}$（Hz）与周期 $T_n = 1/f_n$。

方程的解是简谐振动：

$$x(t) = A\sin(\omega_n t + \phi)$$

振幅 $A$ 与初相 $\phi$ 由**初始条件**（初位移、初速度）决定，而频率由系统参数 $k$、$m$ 决定——**与初始扰动无关**。这是「固有」二字的含义：系统自己「自带」的频率。<span class="marginnote">「固有频率只取决于 $k/m$ 而非扰动大小」是一个深刻事实：钟摆、琴弦、桥梁，各自的「音高」都由系统自身参数决定。这也是《压杆稳定》篇临界载荷「只取决于 $EI/L^2$」的同族思想——特征值由算子决定，不由初始条件决定。</span>

**解析｜易错点：** 固有频率与振动是否发生**无关**——即使没有初始扰动（系统静止），固有频率依然存在；只要给一点扰动，系统就按这个频率振动。另一个易错点是把 $\omega_n$（rad/s）直接当 Hz 用：换算频率时必须除以 $2\pi$。频率、角频率、周期三者混用是振动里最常见的符号事故。

算一个手感：悬挂质量 $m = 100\ \mathrm{kg}$ 的弹簧，静伸长 $\delta_{st} = 25\ \mathrm{mm}$，则 $k = mg/\delta_{st} = 100\times9.81/0.025 \approx 39240\ \mathrm{N/m}$，$\omega_n = \sqrt{k/m} = \sqrt{392.4} \approx 19.8\ \mathrm{rad/s}$，$f_n \approx 3.15\ \mathrm{Hz}$。用静伸长算固有频率的公式 $\omega_n = \sqrt{g/\delta_{st}}$ 非常方便——测出悬挂重物的静伸长，就能立刻估出系统频率，这正是隔振、称重等工程里常用的「静载法」。

## 2 阻尼振动：衰减的节奏

真实系统都有**阻尼（damping）**（摩擦、空气阻力、材料内耗），运动方程变为

$$m\ddot{x} + c\dot{x} + kx = 0$$

令 $c$ 为阻尼系数，定义**阻尼比（damping ratio）**

$$\zeta = \frac{c}{2\sqrt{km}} = \frac{c}{c_{cr}}$$

其中 $c_{cr} = 2\sqrt{km}$ 为**临界阻尼系数**。按 $\zeta$ 的大小，系统分三种情形：

- $\zeta < 1$：**欠阻尼（underdamped）**——振动衰减但仍在振荡，衰减后的频率（有阻尼固有频率）$\omega_d = \omega_n\sqrt{1-\zeta^2}$ 略小于 $\omega_n$。解为 $x(t) = Ae^{-\zeta\omega_n t}\sin(\omega_d t + \phi)$。<span class="marginnote">欠阻尼解里的指数因子 $e^{-\zeta\omega_n t}$ 让振幅按指数衰减，相邻两个峰值之比的自然对数叫<strong>对数衰减率（logarithmic decrement）</strong> $\delta = 2\pi\zeta/\sqrt{1-\zeta^2}$——工程里用「测两次峰值」的办法反推阻尼比，靠的就是这条关系。</span>
- $\zeta = 1$：**临界阻尼（critical damping）**——最快回到平衡且不振荡。
- $\zeta > 1$：**过阻尼（overdamped）**——缓慢回到平衡、不振荡。

三种情形对照起来看：

| 阻尼情形 | $\zeta$ | 运动形态 | 回到平衡 | 工程实例 |
| --- | --- | --- | --- | --- |
| 欠阻尼 | $0<\zeta<1$ | 衰减振荡 $e^{-\zeta\omega_n t}\sin(\omega_d t+\phi)$ | 快、带振荡 | 桥梁、悬架、地震反应 |
| 临界阻尼 | $\zeta=1$ | 无振荡地衰减 | 最快、不振荡 | 仪器指针、门吸 |
| 过阻尼 | $\zeta>1$ | 缓慢衰减 | 慢、不振荡 | 缓冲器、阻尼密封 |

**解析｜易错点：** 阻尼总让有阻尼固有频率 $\omega_d$ **小于**无阻尼 $\omega_n$，但只有当阻尼小（$\zeta \ll 1$）时两者才接近相等。很多人把「固有频率」直接当成「实际振动频率」，忽略阻尼的修正——对桥梁、建筑这类小阻尼结构误差不大，但对悬挂系统这类大阻尼场合会明显错位。

## 3 受迫振动与共振

当系统受到周期外力 $F_0\sin\omega t$ 驱动，方程变为

$$m\ddot{x} + c\dot{x} + kx = F_0\sin\omega t$$

其稳态解是**以驱动频率 $\omega$（而非固有频率）振动**的正弦波，振幅为

$$X = \frac{F_0/k}{\sqrt{(1 - r^2)^2 + (2\zeta r)^2}}, \qquad r = \frac{\omega}{\omega_n}$$

当驱动频率接近固有频率（$r \to 1$），振幅趋于极大——这就是**共振（resonance）**。<span class="marginnote">共振是振动里最戏剧性的现象：1940 年塔科马海峡大桥在风中以固有频率剧烈摆动而坍塌，成为工程史上最著名的共振案例。同一物理规律的另一面是「共振的用处」：收音机选台、MRI 成像、原子吸收光谱，都是「调到固有频率才响应」的技术应用。共振是中性的，危险与否全在工程如何管理它。</span>

振幅-频率关系图（幅频曲线）揭示了受迫振动的全部性格：**低频段**振幅≈静态位移 $F_0/k$；**高频段**振幅→0（质量跟不上驱动）；**共振段**振幅受阻尼比 $\zeta$ 控制。设计原则随之而来：要么让工作频率远离固有频率，要么加大阻尼压低共振峰——**「避开共振或驯服共振」，是振动设计的全部纲领**。

给个数字看共振的威力：$m = 10\ \mathrm{kg}$、$k = 4000\ \mathrm{N/m}$ 的系统，$\omega_n = \sqrt{4000/10} = 20\ \mathrm{rad/s}$（约 3.18 Hz）。若阻尼比 $\zeta = 0.05$、激振力幅 $F_0 = 100\ \mathrm{N}$，则静态位移 $F_0/k = 25\ \mathrm{mm}$；在共振点（$r = 1$）振幅 $X = 25/\sqrt{(1-1)^2 + (2\times0.05\times1)^2} = 25/0.1 = 250\ \mathrm{mm}$——放大整整 10 倍。若阻尼比翻倍到 $0.1$，共振振幅降到 $125\ \mathrm{mm}$，立减一半。「加大阻尼压低共振峰」的定量效果，就在这里。

**解析｜易错点：** 受迫振动的稳态响应频率 = 驱动频率 $\omega$，不是固有频率 $\omega_n$；只有**自由振动**才以固有频率振。工程里常出现的「拍振」（beating）是驱动频率与固有频率**接近但不等**时的叠加现象，也不是共振——共振是驱动频率**等于**固有频率时振幅单调增大（无阻尼）的特殊情形。

## 4 多自由度与模态：从单摆到整桥

单自由度系统（一个 $x$）的方程已能解释许多现象，但真实结构（桥、塔、飞机）有**无穷多**自由度。把系统离散成 $n$ 个质量，方程写成矩阵形式：

$$\mathbf{M}\ddot{\mathbf{x}} + \mathbf{C}\dot{\mathbf{x}} + \mathbf{K}\mathbf{x} = \mathbf{F}(t)$$

$\mathbf{M}$、$\mathbf{C}$、$\mathbf{K}$ 分别为质量、阻尼、刚度矩阵。求解的思路是**模态分解（modal analysis）**：

1. 求解无阻尼自由振动的**特征值问题** $\det(\mathbf{K} - \omega^2\mathbf{M}) = 0$，得到 $n$ 个固有频率与对应的**振型（mode shape）**向量。
2. 把物理坐标变换到模态坐标，$n$ 维耦合方程解耦成 $n$ 个独立的单自由度方程。
3. 分别求解后叠加回物理坐标。

<span class="marginnote">模态分解与《线性代数》里「对角化」是同一件事：取特征向量（振型）为新基底，耦合的方程就变成了坐标独立的一串方程。而模态分析的数值实现——求解大规模特征值问题——正是《压杆稳定》篇提到的「有限元特征值分析」的完整形态。</span>

对于连续体（梁、弦），振动方程升级为**偏微分方程**（如梁的振动方程 $\rho A \frac{\partial^2 v}{\partial t^2} + EI\frac{\partial^4 v}{\partial x^4} = 0$），其解同样是一族模态与固有频率——工程分析中常截取前几阶模态近似整体响应，这就是「**截断**」的思想。

## 5 公式解析：$\omega_n = \sqrt{\frac{k}{m}}$

把固有频率公式拆解到根：

**第一步，它来自方程的系数**：$m\ddot{x} + kx = 0$ 两端除以 $m$，得 $\ddot{x} + \frac{k}{m}x = 0$。让系数与标准简谐方程 $\ddot{x} + \omega_n^2 x = 0$ 对比，$\omega_n^2 = k/m$，于是 $\omega_n = \sqrt{k/m}$。<span class="marginnote">「固有频率 = 刚度的平方根」这个结构处处出现：单摆 $\omega = \sqrt{g/L}$、扭摆 $\omega = \sqrt{k_t/I}$、梁的第一阶频率也正比于 $\sqrt{EI/(\rho A)}$。看到「振动频率」就想到「某个刚度/某个惯量的平方根」，是记住一切频率公式的元方法。</span>
- **第二步，物理意义**：$k$ 大（弹簧硬）则 $\omega_n$ 大、振得快；$m$ 大（惯性大）则 $\omega_n$ 小、振得慢。**刚度与惯性是频率的两极**——频率正是「刚度与惯性的较量」的平方根判据。
- **第三步，无量纲化**：受迫振动里关键的参数 $r = \omega/\omega_n$ 把所有系统「归一化」成同一个幅频曲线——无论 $k$、$m$ 多大，共振都发生在 $r = 1$ 处。这又是「归一化」思想的一次胜利，和《应力与应变》的应变、《压杆稳定》的长细比同族。
- **第四步，延伸到一切周期系统**：$x(t) = A\sin(\omega_n t + \phi)$ 说明位移、速度、加速度都按同一频率变化但相位差 $90^\circ$——速度超前位移、加速度再超前速度。这条相位规律将原封不动地进入《信号与系统》的相频分析。

## 6 小结

- **单自由度自由振动**：$m\ddot{x} + kx = 0$，解为简谐运动，**固有频率** $\omega_n = \sqrt{k/m}$ 只由系统参数决定。
- **阻尼振动**：阻尼比 $\zeta = c/2\sqrt{km}$ 分欠阻尼（$\zeta<1$）、临界（$=1$）、过阻尼（$>1$）；有阻尼频率 $\omega_d = \omega_n\sqrt{1-\zeta^2}$。
- **受迫振动**：稳态以**驱动频率**振动；驱动频率接近固有频率时发生**共振**，振幅由阻尼控制。
- **多自由度系统**：$\mathbf{M}\ddot{\mathbf{x}} + \mathbf{C}\dot{\mathbf{x}} + \mathbf{K}\mathbf{x} = \mathbf{F}$；**模态分解**把耦合方程解耦为独立单自由度方程。
- 频率 = 「刚度/惯量的平方根」；共振设计与阻尼管理是振动工程的纲领。

至此，从静力学的「不动」、材料力学的「微弯」、动力学的「动起来」，再到振动的「周期性动起来」——本专题的力学主线画上了句号。它留下的每一种工具，都将在更宏大的课程里被反复调用：向量的语言进入连续介质力学与有限元，能量的语言进入变分法与优化，振动的语言进入信号处理与控制论。力学没有结束，它只是换了个名字继续生长。
