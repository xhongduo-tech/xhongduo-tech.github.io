## 为什么静力学要「升级」成动力学

前十一篇里，物体要么不动（静力学），要么只做微小变形（材料力学）。但工程世界里满是真正「动起来」的东西：汽车加速、机械臂挥舞、电梯起降、飞船变轨。这些问题的第一问不是「受多少力」，而是——**它动得多快、往哪动**。<span class="marginnote">运动学与动力学（kinematics and kinetics）是理论力学的两大分支：<strong>运动学</strong>只描述运动（位置、速度、加速度的几何关系），不管力；<strong>动力学</strong>把力与运动联系起来（牛顿第二定律 $F = ma$）。先学会「描述」，再学会「解释」，是这一节的总顺序。</span>

这一节的分量在整个《工程力学》里举足轻重：它是连接「静力学」与「机械振动」的中间地带，也是从「力学的静平衡」走向「运动规律」的转折点。数学上，微分与积分的语言第一次全面接管力学的叙述。

## 1 质点的直线运动：微分与积分双通道

**运动学**用位置、速度、加速度三个量描述运动。沿直线运动时：

$$v = \frac{ds}{dt}, \qquad a = \frac{dv}{dt} = \frac{d^2s}{dt^2}$$

反过来，已知加速度求速度、已知速度求位置，就是积分：

$$v = v_0 + \int a\,dt, \qquad s = s_0 + \int v\,dt$$

另外还有一条把「时间」消掉的关系式 $v\,dv = a\,ds$，积分得

$$v^2 = v_0^2 + 2a(s - s_0)$$

这三条微分/积分关系构成了直线运动学的全部骨架：**已知一个量，微分或积分得到另两个量**。<span class="marginnote">把 $a = dv/dt$、$v = ds/dt$ 与《梁的挠度》篇的 $EI v'' = M$ 对照，会发现同一节奏：二阶导数 + 两次积分。微积分在力学里就是「描述量」之间的翻译官——你早在第一级练熟的求导积分，在这里首次全面接管物理。</span>

当加速度恒定（自由落体、匀减速刹车），积分给出中学时代的五个运动学公式（$v = v_0 + at$、$s = v_0t + \frac{1}{2}at^2$ 等），它们是直线运动学里使用频率最高的特例。

**解析｜易错点：** 「匀变速」公式只在 $a$ 为**常数**时成立。若 $a$ 是时间或位置的函数（$a = a(t)$、$a = a(s)$），必须回到微分方程直接积分。另一个高频错误是**换参考系忘加相对速度**——同一物体相对不同参考系的速度不同，相对速度公式 $v_{A/B} = v_A - v_B$ 必须显式写出来。

## 2 曲线运动：切向与法向

物体沿曲线运动时，速度沿轨迹切线方向，而加速度分解为两个分量：

$$a_t = \frac{dv}{dt} \qquad (\text{切向，改变速度大小})$$

$$a_n = \frac{v^2}{\rho} \qquad (\text{法向，改变速度方向})$$

- **切向加速度** $a_t$ 改变速度的大小——「快慢」的变化。
- **法向加速度** $a_n$ 改变速度的方向——「方向」的变化，永远指向曲率中心。<span class="marginnote">法向加速度 $a_n = v^2/\rho$ 与「向心力」是同一个物理事实的两面：转弯越急（$\rho$ 小）、速度越大，向心加速度按平方增长。汽车高速过急弯需要巨大的侧向力——这正是「转弯半径与车速的平方关系」让赛车手谨慎的原因。</span>

对**圆周运动**，用角量描述更自然：角速度 $\omega = d\theta/dt$，切向与法向加速度分别为

$$a_t = \alpha r, \qquad a_n = \omega^2 r$$

其中 $\alpha = d\omega/dt$ 是角加速度。这套「线量-角量」的对照表（$s \leftrightarrow \theta$、$v \leftrightarrow \omega$、$a_t \leftrightarrow \alpha$）让圆周运动成为「直线运动公式的翻译版」。

**抛体运动**是曲线运动最经典的实例：水平方向匀速（$a_x = 0$），竖直方向匀加速（$a_y = -g$）。两个方向完全解耦、分别积分、再合成——**「解耦」是曲线运动的通用策略**：把二维运动拆成两个互相独立的一维运动。

## 3 质点动力学：牛顿第二定律

有了运动学的「描述」，动力学来「解释」。**牛顿第二定律**：

$$\sum \mathbf{F} = m\mathbf{a}$$

质点所受合外力等于质量乘加速度。这是力学的第一条「动态」方程。注意它的两个方向分量独立成立：

$$\sum F_x = ma_x, \qquad \sum F_y = ma_y$$

于是动力学问题的标准解法是：**先画受力图 + 加速度图，沿两个方向分别列方程，解出未知量**。<span class="marginnote">这一套「受力图 + 加速度图」双图法与《质点与刚体静力学》篇的单图法一脉相承：静力学让 $a = 0$，动力学允许 $a \neq 0$。达朗贝尔原理更进一步，把 $ma$ 当成一个「惯性力」写进平衡方程——静力学的工具就原封不动搬进动力学。</span>

工程里最常见的动力学模型是**弹簧-质量**与**阻尼**系统，例如汽车的悬挂、精密仪器的隔振。若只受弹簧力 $F = -kx$，牛顿第二定律给出

$$m\ddot{x} + kx = 0$$

这是**简谐振动方程**——它将在《机械振动》篇被系统展开。这里只需看到：**动力学方程往往是二阶常微分方程**，而解这类方程正是「从极限到大模型」主线里《常微分方程》的看家本领。

## 4 刚体动力学：平动 + 转动

真实构件大多是**刚体**：既有平动又有转动。刚体平面运动可以分解为「随质心的平动」+「绕质心的转动」，对应两组动力学方程：

$$\sum \mathbf{F} = m\mathbf{a}_G \qquad (\text{质心平动})$$

$$\sum M_G = I_G \alpha \qquad (\text{绕质心转动})$$

其中 $I_G$ 是刚体对质心轴的**转动惯量（mass moment of inertia）**，$\alpha$ 是角加速度。第二式与 $F = ma$ 完全同构：**力矩对应力、转动惯量对应质量、角加速度对应加速度**。<span class="marginnote">转动惯量 $I_G = \int r^2 dm$ 与《静力学基础》里截面的惯性矩 $I = \int y^2 dA$ 数学同构——一个对质量、一个对面积。这个「质量版惯性矩」在《机械振动》篇决定系统的转动固有频率，值得与面积版对照记忆。</span>

刚体运动的加速度关系还有个核心几何约束：**刚体上任意两点的速度、加速度满足「相对运动」分解**，如平面运动刚体上 $B$ 点相对 $A$ 点：

$$\mathbf{v}_B = \mathbf{v}_A + \boldsymbol{\omega} \times \mathbf{r}_{B/A}$$

$$\mathbf{a}_B = \mathbf{a}_A + \boldsymbol{\alpha}\times\mathbf{r}_{B/A} + \boldsymbol{\omega}\times(\boldsymbol{\omega}\times\mathbf{r}_{B/A})$$

这条「**瞬时速度三角形/加速度合成**」是连杆机构（四杆机构、曲柄滑块）运动分析的看家工具。<span class="marginnote">曲柄滑块机构——汽车发动机活塞-连杆-曲轴的运动，就是这条相对运动公式的日常应用：活塞的往复运动由曲轴的匀速转动经连杆放大/转换而来。机械设计课的「速度瞬心」「加速度合成」，本质都是这两个叉积式的几何实现。</span>

## 5 公式解析：$a_n = \frac{v^2}{\rho}$ 与 $F = ma$

把这一节最核心的两条公式各拆一遍：

**先看法向加速度 $a_n = v^2/\rho$**：

**第一步，为什么需要它**：速度是矢量。曲线运动中即使速度大小不变（匀速圆周），方向也在变——「方向的变化率」本身就是加速度。
- **第二步，几何推导**：转过小角度 $\Delta\theta$，速度矢量转过相同角度，速度变化量 $|\Delta\mathbf{v}| = v\,\Delta\theta$。除以时间得 $a_n = v\,(d\theta/dt) = v\omega$。
- **第三步，换成曲率半径**：由 $\omega = v/\rho$（角速度 = 线速度 ÷ 半径），得 $a_n = v^2/\rho$。<span class="marginnote">这套推导是「极限」思想的直接演练：小角度近似 $\sin\Delta\theta \approx \Delta\theta$ 正是第一级《微积分》里 $\lim_{\theta\to0}\sin\theta/\theta = 1$。法向加速度的公式本身就是微积分极限定义在物理里的一次成品展示。</span>
- **第四步，直觉落点**：速度翻倍，向心加速度变四倍——所以高速弯道最危险，不是线性增长，而是**平方增长**。

**再看 $F = ma$**：

- **第一步，它是「原因与效果的等式」**：力是原因，$ma$ 是效果。质量是「惯性」的度量——同样大的力，质量大的物体加速度小。
- **第二步，方向性**：$F$ 与 $a$ 同方向。沿轨迹切向的力改变速率（$a_t$），垂直轨迹的力改变方向（$a_n$）——动力学与运动学在此完全对接。
- **第三步，工程步骤**：受力图 → 列 $\sum F_x = ma_x$、$\sum F_y = ma_y$ → 解运动方程。静力学只是它的特例（$a = 0$）。
- **第四步，系统观**：$F = ma$ 给出的是二阶常微分方程，配上初始条件（初位移、初速度）就完整描述了运动——这正是《机械振动》篇打开振动世界的钥匙。

## 6 小结

- **运动学**描述运动：$v = ds/dt$、$a = dv/dt$，微分/积分互相转换；匀加速有五式特例。
- **曲线运动**：$a_t = dv/dt$（改变快慢）、$a_n = v^2/\rho$（改变方向）；圆周运动用角量 $\omega$、$\alpha$ 描述。
- **动力学**：$\sum F = ma$，受力图 + 加速度图双图法；达朗贝尔原理把动力学写成静力学形式。
- **刚体平面运动**：$\sum F = ma_G$ + $\sum M_G = I_G\alpha$；相对运动公式 $\mathbf{v}_B = \mathbf{v}_A + \boldsymbol{\omega}\times\mathbf{r}$ 用于机构分析。
- 弹簧-质量系统的 $m\ddot{x} + kx = 0$ 是通向振动的桥梁。

在下一节，我们把动力学方程「一次积分」——不直接解运动全过程，而是利用**能量守恒**与**动量守恒**这两个全局不变量快速求解：这就是《功-能原理与冲量-动量》。
