## 为什么从「单一载荷」毕业

前三节处理的问题都有一个共同点：构件只受一种载荷——轴力、扭矩、或弯矩之一。但真实构件几乎从不这么听话：烟囱同时被自重压着、被风吹弯；传动轴同时传递扭矩、还承受齿轮啮合力引起的弯曲；吊车臂的受力更是「拉、弯、扭」样样齐全。<span class="marginnote">「组合载荷」（combined loading）不是新物理，而是新组织方式：把已有的每一种简单载荷单独分析，再按<strong>叠加原理</strong>合起来。真正的新问题只剩一个——合起来之后，危险点在哪个位置、该按什么应力来校核强度。</span>

这节是材料力学前半程的「汇总卷」，也是通往下一节《Mohr 应力圆》的桥梁：一旦截面上同时有正应力和剪应力，就必须学会「把任意方向的应力状态翻译成主应力」。

## 1 通用流程：先拆、再算、后合

处理组合载荷的标准流程，恰好是笛卡尔方法论的工程版：

1. **切出危险截面**：先由整体静力学求出构件内力（轴力 $N$、弯矩 $M$、剪力 $V$、扭矩 $T$）沿轴线的分布。
2. **对每种内力，用已知公式算应力分布**：$\sigma = N/A$、$\sigma = My/I$、$\tau = VQ/It$、$\tau = T\rho/J$。
3. **在考察点上叠加**：同类型应力代数相加，不同类型（正/剪）保持分量。
4. **找危险点，按主应力校核**：算出该点应力状态后，用《Mohr 应力圆》方法求主应力并代入失效准则。

<span class="marginnote">注意叠加的前提：线弹性、小变形、应力与载荷线性相关——这三条在《轴向载荷与扭转》篇已经强调过。若载荷大到产生显著变形（如屈曲），叠加失效。工程上先用这条线性路径估算，再对关键构件做非线性校核，是通行做法。</span>

## 2 偏心压缩：$P/A$ 与 $My/I$ 的相遇

最典型的组合载荷是**偏心受压**：力不通过截面形心，而是偏离一段距离 $e$。这是建筑柱、机械夹具里的常态。

处理偏心力的标准技巧是**力的平移**：把偏心力 $P$ 平移到形心，同时附加一个力偶 $M = Pe$。于是构件变成「轴力 $P$ + 弯矩 $M = Pe$」的叠加：

$$\sigma = \frac{P}{A} \pm \frac{M y}{I}$$

- 第一项 $P/A$ 是**均匀的**压缩应力（处处相同）。
- 第二项 $My/I$ 是**线性变化**的弯曲应力（一侧压、一侧拉）。
- 两项叠加后，截面一侧应力**增大**，另一侧**减小**甚至变为拉应力。<span class="marginnote">这个「偏心压缩可能在某侧出现拉应力」的结论，是砖石砌体（几乎不能抗拉）设计的核心约束：砖石柱的载荷必须落在截面核心（core）内，否则一侧受拉、砌体开裂。基础工程里的「合力落在三分点内」要求，正是核心概念的通俗版本。</span>

若再进一步，力在两个方向都偏心（双偏心），应力公式扩展为

$$\sigma = \frac{P}{A} \pm \frac{M_x y}{I_x} \pm \frac{M_y x}{I_y}$$

每个方向的弯矩贡献各自独立、线性叠加。整条式子看起来长，但每一项都是「已知公式」，只需细心选对正负号。

**解析｜易错点：** 叠加前先确认 $P/A$、$My/I$ 各自的**符号**（拉为正、压为负），再判断最不利点在哪一侧。最大压应力在「$P$ 压缩与 $M$ 压缩同侧」的角点，最大拉应力在对面。把「哪个点是哪个应力最不利」先在草图上标出来，比盲目套公式安全得多。

## 3 弯扭组合：传动轴的「双应力场」

传动轴同时受扭矩 $T$ 与由齿轮力引起的弯矩 $M$，是机械设计里出镜率最高的问题。此时截面上任意一点的应力状态是：

$$\sigma = \frac{M y}{I} \quad (\text{由弯曲}) \qquad \tau = \frac{T \rho}{J} \quad (\text{由扭转})$$

二者**互相垂直**：正应力沿轴向，剪应力在截面上。危险点通常在弯矩、扭矩都取极大值处（外表面）。该点的应力状态是「一个正应力 + 一个剪应力」的**平面应力状态**，需要求出**主应力**才能做强度校核。

由后面的《Mohr 应力圆》理论，这两类应力对应的主应力为

$$\sigma_{1,2} = \frac{\sigma}{2} \pm \sqrt{\left(\frac{\sigma}{2}\right)^2 + \tau^2}$$

以及最大剪应力

$$\tau_{\max} = \sqrt{\left(\frac{\sigma}{2}\right)^2 + \tau^2}$$

看这几条式子会发现一个工程上极其好用的判据：**最大剪应力只由「正应力与剪应力的组合」决定，而不单由哪一个决定**。对塑性材料轴类零件，强度校核常用**第四强度理论（von Mises）**：

$$\sigma_e = \sqrt{\sigma^2 + 3\tau^2} \le [\sigma]$$

$\sigma_e$ 称为**等效应力**。它把「弯+扭」两种应力的组合压成「等效的单一拉应力」再与许用应力比较——这正是《失效理论》篇要系统展开的内容。<span class="marginnote">等效应力 $\sigma_e = \sqrt{\sigma^2 + 3\tau^2}$ 与「两点间的欧氏距离」在数学上是同一族：把应力状态看成二维向量，等效应力就是它的「长度」再乘一个材料因子。几何直觉到了《失效理论》篇会彻底展开。</span>

把数字放进去：传动轴直径 $d = 60\ \mathrm{mm}$，$M = 4\ \mathrm{kN\cdot m}$、$T = 3\ \mathrm{kN\cdot m}$。$\sigma = 32M/\pi d^3 = 32 \times 4000 / (\pi \times 0.06^3) \approx 188.6\ \mathrm{MPa}$，$\tau = 16T/\pi d^3 = 16 \times 3000 / (\pi \times 0.06^3) \approx 70.7\ \mathrm{MPa}$；等效应力 $\sigma_e = \sqrt{188.6^2 + 3 \times 70.7^2} \approx 226\ \mathrm{MPa}$。若材料许用 $[\sigma] = 240\ \mathrm{MPa}$，裕量已很小——把直径加大一档到 $65\ \mathrm{mm}$ 再算，裕量立刻回到舒适区。这就是「轴的直径常常由弯扭组合的等效应力决定」的原因。

## 4 一般平面应力状态的叠加

把视野再放大一步。构件截面上某一点可能同时存在：

- **由轴力与弯矩引起的正应力** $\sigma_x$（沿构件轴向）：
$$\sigma_x = \frac{N}{A} \pm \frac{M y}{I}$$
- **由剪力与扭矩引起的剪应力** $\tau_{xy}$：
$$\tau_{xy} = \frac{T \rho}{J} \pm \frac{VQ}{It}$$

（各符号依截面位置与符号约定取值）。于是该点的应力状态完全由 $(\sigma_x, \tau_{xy})$ 两个分量描述。至此，「组合载荷」问题就彻底收敛为一个数学问题：**给定平面应力状态的 $\sigma_x$、$\tau_{xy}$，求任意斜截面上的应力、主应力与最大剪应力**——这正是下一节《Mohr 应力圆与应变转换》的全部内容。

**解析｜易错点：** 同一截面上，不同点的 $\sigma_x$、$\tau_{xy}$ 组合不同——「危险点」不是「应力最大点」的单值概念，而要从整根构件中挑选「组合最不利」的点。初学者常犯的错是只算弯矩最大截面、只算边缘点，忽略了剪切为主的位置（如支座附近腹板）。正确的习惯是：**先画内力图锁定候选截面，再在每个候选截面内按应力分布锁定候选点**，最后用主应力准则逐个比较。

## 5 公式解析：$\sigma = \frac{P}{A} \pm \frac{My}{I}$

这条「偏心压缩公式」是组合载荷的开门钥匙，逐项拆解：

- **第一步，第一项 $P/A$ 是「均布项」**：轴力 $P$ 在截面上产生的应力处处相同，与位置无关。它是叠加的「基线」。
- **第二步，第二项 $\pm My/I$ 是「线性项」**：弯矩 $M = Pe$ 产生线性分布的弯曲应力，在中性轴为零、边缘最大。正负号取决于考察点在受拉侧还是受压侧。
- **第三步，相加**：两式相加即得截面任一点的总正应力。**关键在于 $M$ 是从偏心距来的**——偏心力平移到形心后，多出的力偶矩就是 $M = Pe$，这就是「偏心压缩等价于轴压 + 纯弯」的机制。<span class="marginnote">这再次体现「力的平移 + 力偶」这套《静力学基础》的语言：任何「力不在形心上」的问题，翻译成「力在形心上 + 一个力偶」就变成了两个会解的问题。力学最大的本事就是把不会的问题翻译成会的问题。</span>
- **第四步，推广**：把 $My/I$ 换成 $\pm M_x y/I_x \pm M_y x/I_y$、把 $\sigma$ 换成 $N/A$，同一公式就覆盖双偏心、复合正应力等一切「正应力叠加」情形。至于剪应力，另行用 $\tau = T\rho/J$ 与 $VQ/It$ 相加即可。

## 6 数值算例：偏心受压柱的应力

把偏心压缩算一遍。矩形截面柱宽 $b = 200\ \mathrm{mm}$、高 $h = 300\ \mathrm{mm}$，轴向力 $P = 500\ \mathrm{kN}$ 沿 $h$ 方向偏心 $e = 50\ \mathrm{mm}$。

**第一步，截面几何**：$A = 0.2 \times 0.3 = 0.06\ \mathrm{m^2}$，$I_h = bh^3/12 = 0.2 \times 0.3^3/12 = 4.5\times10^{-4}\ \mathrm{m^4}$。

**第二步，均布项**：$\sigma_c = P/A = 500000/0.06 = 8.33\ \mathrm{MPa}$（压应力，处处相同）。

**第三步，弯曲项**：$M = Pe = 500 \times 0.05 = 25\ \mathrm{kN\cdot m}$，边缘弯曲应力 $\sigma_b = Mc/I_h = 25000 \times 0.15/4.5\times10^{-4} = 8.33\ \mathrm{MPa}$。

**第四步，叠加**：偏心侧最大压应力 $\sigma_{\max} = 8.33 + 8.33 = 16.7\ \mathrm{MPa}$，对侧 $\sigma_{\min} = 8.33 - 8.33 = 0$——恰好到达「全截面受压」的边界。<span class="marginnote">「$\sigma_{\min} = 0$」正是<strong>截面核心</strong>边界的特征：偏心力落在核心边界上时，截面一侧应力恰好为零，再往外偏就出现拉应力。对混凝土柱，出现拉应力即开裂，因此合力必须落进核心内。</span>

这个例子定量展示了砖石砌体「合力必须落在三分点内」的来源：核心半宽 $h/6 = 50\ \mathrm{mm}$，恰与本题的偏心距 $e = 50\ \mathrm{mm}$ 一致——巧合不是偶然，而是这个数字被刻意选在核心边界上。

## 7 小结

- **组合载荷** = 拆成简单载荷 + 分别计算 + **叠加**；前提是线弹性小变形。
- **偏心压缩**：$P$ 平移到形心附加力偶 $M = Pe$，$\sigma = \frac{P}{A} \pm \frac{My}{I}$；砖石结构必须保证合力落在**截面核心**内。
- **弯扭组合**：$\sigma$（弯）与 $\tau$（扭）叠加为平面应力状态；传动轴按 $\sigma_e = \sqrt{\sigma^2 + 3\tau^2}$ 校核（第四强度理论）。
- 危险点的选择：先由**内力图**锁截面，再按**应力分布**锁点位，最后按主应力比较。
- 组合载荷的终点是**一般平面应力状态** $(\sigma_x, \tau_{xy})$——下一节将用**Mohr 应力圆**对它做几何化处理。

在下一节，我们把「一个点上的应力状态」这件事做到底：为什么同一点在不同方向截面上应力不同？如何用一张圆把二维应力状态的所有信息装进去？——这就是《Mohr 应力圆与应变转换》。
