## 为什么必须知道「弯多少」

强度校核保证梁「不坏」，但工程里还有一类更苛刻的要求：**变形不能太大**。机床导轨弯 0.1 mm 就影响加工精度，电梯梁挠度过大会让人心惊，飞机机翼的容许挠度更是气动设计的硬约束。<span class="marginnote">「刚度」与「强度」是梁设计的两条腿：强度管「会不会断」，刚度管「弯多少算超标」。很多构件不是因为强度不足而失败，而是因为挠度太大失去功能——所谓「功能性失效」（serviceability failure）。</span>

上一节的弯曲应力 $\sigma = My/I$ 回答「内部受力多大」，这一节的**挠度（deflection）**回答「变形成什么样」。而桥梁两套问题的核心，是同一个几何量：中性轴的**弹性曲线（elastic curve）**$v(x)$——梁轴线上各点弯曲后的竖直位移。

## 1 弹性曲线的微分方程

由《梁的弯曲》篇的结论，中性轴的曲率与弯矩成正比：

$$\frac{1}{\rho} = \frac{M}{EI}$$

对小挠度（$dv/dx \ll 1$），曲率近似等于 $v''(x)$，于是得到**弹性曲线微分方程**：

$$EI \, v'' = M(x)$$

这是整个挠度理论的总源头：**弯矩分布决定弯曲变形的二阶导数，积分两次即得挠度 $v(x)$**。<span class="marginnote">「曲率 ∝ 弯矩，挠度是曲率的两次积分」——这条链和运动学里「加速度 ∝ 力，位移是加速度的两次积分」惊人地同构。你在《运动学与动力学》篇会看到 $a = dv/dt$、$s = \int v\,dt$，这里则是 $v'' = M/EI$、$v = \iint (M/EI)\,dx^2$。力学到处是「二阶导 + 两次积分」的节奏。</span>

再微分一次，还能得到更完整的链式关系：

$$EI \, v'' = M, \qquad EI \, v''' = V, \qquad EI \, v'''' = -w$$

弯矩、剪力、分布载荷各自对应挠度的二阶、三阶、四阶导数。**知道分布载荷，四次积分出挠度；知道弯矩图，两次积分出挠度**——同一根梁，从哪个入口进都能到挠度，只是要配好边界条件。

## 2 双重积分法：边界条件决定一切

**双重积分法（double integration）**是最基本的解法：

1. 由截面法写出各段的 $M(x)$。
2. 积分一次得转角 $\theta = v' = \int \frac{M}{EI}\,dx + C_1$。
3. 再积分一次得挠度 $v = \int \theta\,dx + C_2$。
4. 用**边界条件（boundary conditions）**定出积分常数。

边界条件的来源有三类：

- **支座条件**：铰支座处挠度为零（$v = 0$）；固定端处挠度与转角都为零（$v = 0$，$v' = 0$）；悬臂梁自由端两者都自由。
- **连续性条件**：相邻两段交界处，挠度与转角必须连续（梁不会断、也不会折角）。
- **对称性条件**：对称梁在对称轴上转角为零（$v' = 0$）。<span class="marginnote">「边界条件定常数」与《线性代数》里「齐次方程的特解 + 边界定系数」是同一句话。积分常数不是随便设的，它们编码的是「这根梁被怎么约束」——同一个 $M(x)$ 配不同支座，挠度曲线完全不同。</span>

**解析｜易错点：** 边界条件必须**逐条列全**。悬臂梁固定端给了两个条件，简支梁两个支座各给一个，跨中载荷的梁在载荷作用点处还要写连续条件。少一条，积分常数就定不出来，或定出一个错误的曲线。写边界条件前，先在梁上画出支座，逐一核对「它约束了什么」。

## 3 奇异函数法：一个方程解决多段问题

梁上有多个集中力、集中力偶或分布载荷分段变化时，$M(x)$ 是分段函数，双重积分法要对每段各积两次、再逐段拼接，繁且易错。**奇异函数法（singularity functions / Macaulay 方法）**用尖括号记号把分段函数压缩进一个表达式：

$$\langle x - a \rangle^n = \begin{cases} 0 & x < a \\ (x - a)^n & x \ge a \end{cases}$$

利用「积分不改变尖括号形式」的性质，$M(x)$ 可以写成**一个式子**，积分两次仍是一个式子，只需在末尾用边界条件定两个常数。对悬臂梁或简支梁的多种载荷，这是手算挠度最快的方法。<span class="marginnote">奇异函数在数学上就是「带开关的幂函数」——$x < a$ 时为零，$x \ge a$ 时才激活。这思想在今天的技术栈里随处可见：ReLU 激活函数、掩码矩阵、分段常数调度……「到某一点才起作用的函数」是工程里最常用的数学工具之一。</span>

工程上更省事的做法是**查表**：教材和手册给出常见「梁型 + 载荷」的挠度、转角公式表。表中悬臂梁自由端集中力 $P$ 的挠度 $\delta = PL^3/3EI$、简支梁跨中集中力的挠度 $\delta = PL^3/48EI$ 等，几乎每条都该混个脸熟。

## 4 叠加法：挠度也能线性加

《轴向载荷》篇确立的**叠加原理**在挠度问题里同样成立：**几个载荷共同引起的挠度，等于各载荷单独引起的挠度之和**。

$$v_{\text{总}} = v_1 + v_2 + \cdots$$

于是复杂受载的梁，只需查表得到每个载荷的挠度、代数和相加。比如简支梁同时受均布载荷与跨中集中力，挠度就是两项之和。**叠加法是工程手算挠度的主力**，因为查表 + 加法比逐段积分快一个数量级。<span class="marginnote">叠加法成立的前提仍是小变形线弹性。若梁已经弯得很厉害（大挠度），载荷会改变挠度、挠度又改变载荷矩——系统非线性化，叠加失效。大挠度梁（如细长拉索）在《压杆稳定》里会成为主角。</span>

**解析｜易错点：** 叠加时每项都要注意「梁型相同」。悬臂梁与简支梁的表格不同，不能用错。其次，叠加的是「同一位置」的挠度——多项的挠度公式代入**同一个 $x$** 再相加，而不是分别求最大值再相加（最大值位置可能不同）。

## 5 弯矩-面积法与挠度限制

另一套经典的几何解法是**弯矩-面积法（moment-area method）**，它绕开积分，直接利用两个几何事实：

- 两点之间转角的差 = 两点间 $M/EI$ 图与 $x$ 轴围成的**面积**；
- 一点相对另一点的挠度 = 该面积对考察点的**面积矩**。

它把「积分」换成「看图算面积」，在分布载荷变化复杂的场合往往比解析积分更直观。虽然数值计算时代解析法地位下降，但弯矩-面积法对理解「挠度曲线的形状由弯矩图决定」仍极有帮助。

最后是**设计层面**：规范通常给出挠度限值，如简支梁容许挠度 $L/360$ 或 $L/480$（$L$ 为跨度）。这给出一个反问题——**刚度校核**：

$$v_{\max} \le [v]$$

强度满足、挠度不满足时，对策不是加粗到「足够强」，而是**提高惯性矩 $I$**（如工字梁、变截面梁）。因为挠度与 $I$ 成反比（$v \propto 1/I$），把材料放远、$I$ 变大，挠度立降——这是《梁的弯曲》篇「材料放远」哲学在刚度问题上的延续。<span class="marginnote">「挠度不达标 → 提高 $I$ 而非提高强度」是新手常踩的坑：加粗可能浪费材料，把截面做成「肚子大」的工字形、箱形，以相同面积换几倍 $I$，才是一本万利的刚度设计。这也是飞机翼梁、轻轨轨道梁设计的核心思路。</span>

## 6 公式解析：$EI \, v'' = M(x)$

这条「总源头」公式值得逐项拆解：

**第一步，左边 $EI\, v''$ 是「内力矩的内禀形式」**：$E$ 是材料刚度、$I$ 是截面刚度，合起来 $EI$ 是抗弯刚度；$v''$ 是挠度的二阶导数，即**曲率近似**。左边整体代表「梁抵抗弯曲变形的能力 × 实际的弯曲程度」。
- **第二步，右边 $M(x)$ 是「外载荷的效果」**：弯矩分布由载荷与支座决定，是已知量。方程说的是：**弯曲程度（曲率）与弯矩成正比，与抗弯刚度成反比**——弯矩大弯得凶，刚度大弯得少。$v'' = M/EI$ 一句话讲完整个刚度概念。
- **第三步，两次积分的物理解释**：$v' = \theta$ 是转角（弹性曲线的斜率），$v$ 是挠度。积分一次从「弯得多快」到「偏了多大角」，再积分一次从角度到位移。每个积分都要用边界条件定常数。
- **第四步，实践形态**：$v_{\max}$ 的常用结果（悬臂端 $\frac{PL^3}{3EI}$、简支跨中 $\frac{PL^3}{48EI}$、均布简支 $\frac{5wL^4}{384EI}$）都是这条方程在具体边界条件下的解。**记住这三个分母 3、48、384，就等于记住了半本挠度表**——它们的共同点是「$EI$ 在分母、载荷与 $L$ 的高次幂在分子」。<span class="marginnote">挠度公式里跨度 $L$ 都是三次或四次方——$L$ 每增大 10%，挠度增大 33% 或 46%。这正是「跨度是刚度最大的敌人」的定量来源，也是大跨度桥梁必须采用桁架、斜拉等结构让「受力路径变短」的原因。</span>

## 7 小结

- **弹性曲线微分方程** $EI\,v'' = M(x)$：弯矩分布决定挠度的二阶导数；再微分可得 $EI\,v''' = V$、$EI\,v'''' = -w$。
- **双重积分法**：积分两次 + **边界条件**（支座、连续、对称）定常数。
- **奇异函数法**：把分段 $M(x)$ 压缩成一个表达式，一个式子解全程。
- **叠加法**：多载荷挠度查表相加，工程手算主力。
- **弯矩-面积法**：$M/EI$ 图的面积与面积矩给出转角差与挠度。
- **刚度校核** $v_{\max} \le [v]$；挠度超标优先**提高 $I$**，$v \propto 1/I$、$v \propto L^3$ 或 $L^4$。

在下一节，我们触碰到材料力学的最后一类危险：当梁变细长、受压力时，即使应力远低于屈服强度，它也可能突然「垮掉」——这不是强度问题，而是**稳定问题**。这就是《压杆稳定》。
