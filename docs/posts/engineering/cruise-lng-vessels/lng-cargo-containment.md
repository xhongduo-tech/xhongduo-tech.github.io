## 为什么从货物围护系统开始

邮轮篇结束，我们转向本专题的另一半——LNG 船。如果说邮轮的灵魂是「重量重心」，那么 LNG 船的灵魂就是**货物围护系统（cargo containment system, CCS）**：它决定了船能装多少货、多安全、多贵。LNG 船的液货舱要把 $\ce{CH4}$ 封存在 $-163\,^\circ\mathrm{C}$，比液氮还冷，任何常规材料在这种低温下都会变脆、开裂——于是出现了「薄膜型」这样近乎魔法的结构：**用一层薄如纸的金属膜当密封壳，用绝缘材料当保温层，让船体钢板永远接触不到低温**。<span class="marginnote">Eyres《Ship Construction》Part Five 专设《Liquified Gas Carriers》一章讲液货船结构；SIGTTO《Liquefied Gas Carriers》则从设计与操作角度讲围护系统。两者互为表里：前者讲「怎么造」，后者讲「怎么安全地造与用」。</span>本节先讲围护系统的两大流派，再深入薄膜型的 Mark III 与 NO96 细节，最后讲那项绝活——殷瓦钢焊接。读完后你会明白：**LNG 船的天价，很大一部分花在了一层「看不见的膜」上**——而这层膜正是低温工程全部智慧的浓缩。

## 1 围护系统的两种流派

LNG 船的液货围护系统分两大流派，分别回答「低温液体怎么装进船里」：

**自持式（self-supporting / Moss type）**：货舱是**独立的大型球罐**（Moss Rosenberg 球罐）或棱柱罐，罐体自带支撑结构、与船体分离，低温液体直接装在厚实的罐体里。球罐方案在 1970–90 年代曾为主流，优点是结构简单、独立于船体，缺点是占据空间大、船体利用效率低。

**薄膜型（membrane type）**：货舱**没有自己的强度**，只靠一层很薄的金属膜密封 + 绝缘层隔热，直接贴合在船体内壁上。船体结构本身承受液货压力。薄膜型的优点是舱容利用率高、重心低、船体紧凑，是当今大型 LNG 船（16 万～17.4 万 m³）的绝对主流。<span class="marginnote">一句话记住两派分野：<strong>自持罐是「把锅端上船」</strong>——罐体自己扛液体；<strong>薄膜舱是「给船体贴膜」</strong>——船体当容器，膜只负责密封，绝缘层负责隔热。</span>

## 2 薄膜型的两种代表：Mark III 与 NO96

薄膜型由法国 GTT 公司主导，旗下两大设计分别继承自 Gaz Transport（GT）与 Technigaz（TG）两家的血统：

**GTT NO96**（Gaz Transport 系）：主膜与次膜都是**殷瓦钢（invar，36% 镍铁合金）**，波纹板厚度仅 0.7 mm，膜内贴合在胶合板（plywood）绝缘箱（insulation box）上，箱内填充珍珠岩（perlite）粉末。殷瓦钢热膨胀系数极低（约 $1.2\times 10^{-6}\,/^\circ\mathrm{C}$），即使从常温冷到 $-163\,^\circ\mathrm{C}$ 也几乎不收缩，因此可以做成**完全平面**的膜，靠「波纹」不是靠「皱褶」吸收残余应力。

**GTT Mark III**（Technigaz 系）：主膜是**带波纹的不锈钢（304L，厚 1.2 mm）**，次膜是一层复合玻璃纤维布（Triplex），绝缘层是聚氨酯泡沫（PUF）+ 玻璃棉的复合结构。不锈钢导热更快，所以 Mark III 的绝缘层要更厚、保温性能更好，但它的装配速度更快、成本相对可控。<span class="marginnote">膜上的「波纹」（corrugations）是薄膜型的关键设计：平面金属在冷缩时会产生应力，波纹像手风琴风箱一样吸收了绝大部分冷缩应变——这样膜才能用这么薄的板材承受数百次的冷热循环而不疲劳开裂。</span>

**辨析｜易错点：** 很多人以为薄膜舱是「一层膜 + 一层保温」，实际上标准构型是**双膜 + 双绝缘**：主膜（primary membrane）、主绝缘层、次膜（secondary membrane）、次绝缘层，一共四层贴向船体。次膜是「第二道防线」——一旦主膜泄漏，次膜接住泄漏的低温液体，防止它直接接触船体钢板。双膜双绝缘是「安全分级」思想的极致体现。

从结构受力看，薄膜舱还有一个隐含要求：船体本身必须是**完整而坚固的容器**。因为薄膜不承担强度，液货压力全部由船体内壁承受——这意味着船体要做成适合贴膜的连续表面，货舱区采用**单壳**、加大型材间距，让绝缘箱有平整的安装面。薄膜舱的舱形设计因此与船体结构「深度绑定」，这正解释了为什么薄膜技术总与船厂的分段建造、精度控制（上一节讲过）咬合得如此之紧。

## 3 公式解析：热泄漏决定蒸发率

围护系统要回答一个关键数字：**每天蒸发掉多少货**？这由热泄漏（heat leak）决定。通过绝缘层的稳态热传导：

$$
Q = \frac{k \, A \, \Delta T}{d}
$$

- **第一步，$k$ 是绝缘材料的导热系数**（W/(m·K)）：珍珠岩、聚氨酯泡沫都是低导热材料，$k$ 越小越好。
- **第二步，$A$ 是舱壁面积、$d$ 是绝缘层厚度**：面积越大热泄漏越多，绝缘越厚热泄漏越少——所以大舱要更厚的绝缘。
- **第三步，$\Delta T$ 是内外温差**：海温约 $25\,^\circ\mathrm{C}$，液货 $-163\,^\circ\mathrm{C}$，温差近 $190\,^\circ\mathrm{C}$——这是热泄漏的「驱动力」。
- **第四步，$Q$ 是每小时漏进的热量**：它转化为蒸发（boil-off），蒸发率以「**每天蒸发占舱容百分比（BOR, boil-off rate）**」表示，现代大型 LNG 船 BOR 约 0.10%～0.15%/天。<span class="marginnote">BOR 是 LNG 船最核心的运营指标：一艘 17.4 万 m³ 的船，0.13%/天的蒸发率意味着每天蒸发约 226 m³ 液态气。这笔「蒸发损失」要么被烧掉供能（见下一节《LNG 蒸发气管理》），要么再液化回收——BOR 的高低直接决定 LNG 船的运营经济性。</span>

## 4 殷瓦钢焊接：毫米级的绝活

薄膜舱的成败最终落在**殷瓦钢焊接**上。殷瓦钢薄板厚仅 0.7 mm，焊缝要求**零缺陷、零渗漏**——任何一毫米的裂纹都会让低温液体漏入绝缘层，酿成灾难。这门手艺有多难：

- **手工焊接**：殷瓦钢焊缝只能由经 GTT 认证的**持证焊工**手工焊接，一人一天通常只能焊数十米，整船殷瓦钢焊缝长达几十公里；
- **低热输入**：殷瓦钢导热慢、热膨胀极低，焊接要控制热输入避免热裂纹与变形，焊后还要打磨平整；
- **检验苛刻**：焊缝要经过 100% 目视 + 荧光渗透 + 氦检漏（helium leak test）等多重检验，主膜与次膜分别试漏，任何一处漏点都要挖掉重焊。

**辨析｜易错点：** 殷瓦钢的「脆性」是个常见误解。殷瓦钢本身在低温下是**稳定的奥氏体**，低温韧性好；它的难点不在「脆」，而在「薄」与「易受污染」——手指油脂、灰尘、铁锈都会污染焊缝导致气孔。所以殷瓦钢焊接要在**专用清洁车间**进行，焊工全身防护、戴专用手套，几乎像手术室一样管理。<span class="marginnote">殷瓦钢的高成本也让「焊接一次合格率」成为船厂竞争力的核心：报废一段焊缝就要重焊，而殷瓦钢价格远高于普通船板。中国船厂（沪东中华等）正是靠攻克殷瓦钢焊接这一关，才挤进了大型 LNG 船的建造俱乐部。</span>

## 5 围护系统的建造与检验

薄膜舱不是「焊完膜就完事」，而是分阶段建造、逐层检验的精密工程：

- **绝缘箱安装**：胶合板绝缘箱按设计顺序铺贴到船体内壁，箱与箱之间的缝隙、平整度都要控制，因为它们是膜的承托基础；
- **主膜焊接与试漏**：殷瓦钢/不锈钢膜焊接完成后，对主膜做**氦检漏**（在膜下充氦气，用质谱仪检测泄漏）；
- **次膜与绝缘封闭**：主膜内侧再装次绝缘层与次膜，次膜同样试漏；
- **整体惰化与预冷**：全部完工后，货舱先充氮气（惰化）排除空气，再逐步预冷到低温，最后才装载 LNG——整个过程要数天到数周。

**辨析｜易错点：** 货舱的「惰化—预冷—装载」是操作层面的安全关键。如果直接向含氧气的货舱装 LNG，甲烷与空气混合遇明火会爆炸；如果预冷太快，热冲击会损伤绝缘与膜。所以这些工序都有严格的**温度梯度与气体浓度控制**，由 SIGTTO 的《Liquefied Gas Carriers》操作规范逐条规定。

建造与检验还牵涉到「在哪个阶段验漏」的细节：主膜试漏必须在次膜封闭之前进行，否则漏点藏在夹层里无法定位。所以薄膜舱的施工顺序是「装一层、验一层、封一层」——每一层都独立验证，绝不让缺陷藏进下一道工序。这种「逐层验证、逐层封闭」的纪律，正是薄膜舱几十年保持高安全记录的施工保障。<span class="marginnote">薄膜舱的寿命期内，主膜与次膜之间的空间会持续充氮并监测气体浓度——按 IGC Code 第 13.6.11 条，隔层间装 0–100% v/v 固定气体探测，报警点设在甲烷爆炸下限（LFL）的 30%。这既是建造检验，也是全寿命监测的延续。</span>

## 6 薄膜舱 vs 球罐：一张对比表

| 维度 | 薄膜型（Mark III / NO96） | 自持球罐（Moss） |
| --- | --- | --- |
| 液货承力结构 | 船体（膜仅密封） | 罐体自身 |
| 舱容利用率 | 高（舱形贴合船体） | 低（球罐浪费舷角空间） |
| 重心高度 | 低 | 较高 |
| 建造难度 | 高（殷瓦钢焊接） | 中 |
| 成本趋势 | 单位舱容成本低（大船） | 单位舱容成本高 |
| 当今地位 | 大型 LNG 船主流 | 中型船/特种船仍有使用 |

**辨析｜易错点：** 球罐「结构独立」听起来更安全，实际上薄膜型经过几十年的验证，其安全性在同等规范约束下并不逊色——因为薄膜型的双膜双绝缘、隔层气体监测提供了**多重冗余**，而球罐的单层罐体一旦破裂反而没有缓冲。**「独立」不等于「安全」，安全来自冗余设计**——这是围护系统给我们的一课。

## 7 围护系统的一段历史

围护系统不是一开始就是今天的样子，它的演化史是「安全验证 + 工程可行」反复博弈的结果：

- **1960 年代**：LNG 运输刚刚起步，早期采用棱柱罐（prismatic）、圆筒罐等多种自持结构，莫斯（Moss）球罐随之兴起。此时薄膜型尚是图纸上的冒险——因为「让船体承受低温压力」在直觉上太危险；
- **1970 年代**：GTT 前身的两家公司（GT 与 TG）先后推出殷瓦钢膜与不锈钢波纹膜，并造出实船验证。薄膜型以**更高的舱容利用率**逐渐占据大型船市场；
- **1990 年代至今**：Q-Max/Q-Flex（卡塔尔订单）把单船舱容推到 21 万～26.6 万 m³，薄膜型几乎垄断了超大型 LNG 船；Moss 球罐退守中型与特种市场。

**辨析｜易错点：** 为什么超大船必须用薄膜？因为球罐的「球形」在船宽有限时无法无限放大——球罐直径增大后，船艏艉的空间浪费也同步放大。而薄膜舱贴合船体轮廓，船越造越大、薄膜型的优势越明显。**「船型大 → 薄膜型胜出」是一条结构逻辑而非偶然**——这解释了为何当今 17 万 m³ 以上几乎全是薄膜船。<span class="marginnote">卡塔尔 Q-Max 级（2008 年起交付）舱容 26.6 万 m³，长 345 米，是当时世界最大的 LNG 船——它采用的正是 GTT 薄膜型，验证了「薄膜型 + 超大型化」的技术路线可以走通。这也是 Eyres《Liquified Gas Carriers》一章的历史背景。</span>

## 8 围护系统的新方向

技术在继续演化，几个方向值得关注：

- **CS1 等新一代薄膜设计**：GTT 把 Mark III 与 NO96 的优点融合，推出 CS1——不锈钢主膜 + 更薄的绝缘结构，兼顾装配速度与保温性能；
- **大型化与压强化**：更高设计压力、更大舱容、更低 BOR 是持续目标，LNG 船正从 17.4 万 m³ 向 20 万 m³ 以上迈进；
- **B 型棱柱舱（SPB）**：日本川崎重工等的 SPB 棱柱自持罐，结合了自持的强度与棱柱的舱容效率，在某些船型上回归；
- **乙烷/氨船的技术迁移**：乙烯、乙烷、氨等新液货的围护需求，正在复用 LNG 薄膜技术并针对新介质调整绝缘与材料。

**辨析｜易错点：** 新货种（如氨作为未来船用燃料）的围护不能照搬甲烷方案——氨的沸点（$-33\,^\circ\mathrm{C}$）比甲烷高得多但**毒性强**，对密封性、材料相容性、泄漏后果评估的要求完全不同。围护系统的每一次「迁移」都要重新走一遍材料选型、安全验证与规范认可，这提醒我们：**工程知识可以迁移，但安全边界必须逐项重证**。<span class="marginnote">氨燃料船是当下的热点——它把「围护 + 燃料舱」一体化，甚至出现「LNG 船 + 氨预留」的混合方案。围护系统不再是 LNG 船的专利，而成为未来清洁能源船舶的基础设施。这与《绿色船舶动力》一节的话题直接相连。</span>

## 9 小结

- LNG 液货围护分**自持式（球罐）**与**薄膜型**两派，薄膜型以高舱容利用率成为大型 LNG 船主流。
- 薄膜型代表是 GTT 的 **Mark III**（不锈钢波纹主膜 + Triplex 次膜）与 **NO96**（殷瓦钢双膜），均为**双膜双绝缘**构型。
- 热泄漏公式 $Q = kA\Delta T/d$ 决定蒸发率（BOR 约 0.10%～0.15%/天），是运营经济性的核心。
- **殷瓦钢焊接**（0.7 mm 薄板、零缺陷、氦检漏）是薄膜舱的工艺皇冠，也是船厂的核心竞争力。
- 围护系统历经**绝缘箱 → 主膜试漏 → 次膜试漏 → 惰化预冷装载**的分阶段精密建造与检验。
- **安全来自冗余**而非结构独立——双膜双绝缘 + 隔层气体监测是薄膜舱的安全底座。
