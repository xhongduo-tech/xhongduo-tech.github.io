## 为什么从傅里叶光学开始

上一节的伏笔是「夫琅禾费衍射 = 波前的傅里叶变换」。本节把它拉满：用**傅里叶变换**重新组织整个光学——把光场当成**信号**、把透镜当成**频谱分析仪**、把成像当成**滤波**。<span class="marginnote">1950 年代杜福特、霍普金斯把通信理论的语言引入光学，「光学传递函数」成为镜头评价的行业标准；1960 年代全息术与光学信息处理盛行，傅里叶光学成为一门完整学科。今天它直接通向你熟悉的世界：图像去模糊、计算成像、甚至大模型里的卷积神经网络——全都在做「频域处理」。</span>本节既是《工程光学》物理光学的集大成，也是通往《光信息处理》《微纳光学》《现代光学前沿》的枢纽。

## 1 空间频率：把光场当作「信号」

时间信号用「时间频率」$f = 1/T$ 描述每秒振荡几次；光场则用**空间频率（spatial frequency）**描述每毫米振荡几次：

$$u = \frac{\sin\theta}{\lambda}$$

其中 $\theta$ 是平面波的传播方向与光轴的夹角。<span class="marginnote">空间频率 $u$ 的单位是「周/毫米」。一个空间频率为 $u$ 的正弦光栅，其实就是一束以 $\sin\theta = u\lambda$ 方向传播的平面波——<strong>方向与频率一一对应</strong>，这是整个傅里叶光学的地基。物平面上每一点的空间结构，都可以用一组平面波（一组空间频率）来展开。</span>

**重点：把「方向」翻译成「频率」，光学的计算语言就从几何变成频谱**。物是各空间频率的叠加，透镜的孔径决定「哪些频率能通过」——这就是成像系统像质评价与滤波操作的共同起点。

一个立刻用得上的例子：一维正弦光栅（空间频率 $u_0$）的频谱是三个尖峰——0 频（直流）加 $\pm u_0$ 两个共轭峰；把多个不同频率的正弦光栅叠加，频谱就是一组分立的尖峰。反过来，**频谱上有几个峰，就说明物里有几套周期结构**——检测晶圆上的重复图形周期、测量光纤光栅的栅距，用的都是这个「数频谱峰」的思路。

## 2 夫琅禾费衍射 = 傅里叶变换

在夫琅禾费条件下，衍射屏后焦平面上的复振幅分布 $U_f$ 与屏上透射函数 $t(x,y)$ 之间正好是傅里叶变换关系：

$$U_f(u,v) \propto \iint t(x,y)\, e^{-i2\pi(ux+vy)}\,\mathrm{d}x\,\mathrm{d}y$$

即**夫琅禾费衍射图样是衍射屏透射函数的傅里叶变换**。这一点把《衍射》一节的结论翻译成了信号处理的语言：单缝的 $\mathrm{sinc}$ 图样、圆孔的艾里斑，都是对应函数的傅里叶变换——数学上早有定论，光学不过是把傅里叶变换「做在屏上」。<span class="marginnote">这就是「光学计算机」的最初形态：一面透镜就能对光场做一次二维傅里叶变换，且天然并行、瞬时完成。傅里叶光学从诞生起就在暗示：<strong>光学可以成为模拟计算机</strong>——这个梦想在《现代光学前沿》的光计算中再次复活。</span>

## 3 透镜的傅里叶变换性质与 4f 系统

透镜不只是成像元件，它还是**傅里叶变换器**：把物放在透镜前焦面，后焦面上恰是物的频谱（傅里叶变换）。两次变换串起来，就是**4f 系统**——物面、频谱面（焦平面）、像面依次排开，相距各为焦距 $f$：

$$\text{物面} \xrightarrow{\text{透镜1}} \text{频谱面} \xrightarrow{\text{透镜2}} \text{像面}$$

在频谱面上放各种**滤波器**（挡掉、通过、衰减某些空间频率），再经第二片透镜成像，就能对图像做「频域手术」。

4f 系统还直接实现**卷积与相关**：两个函数的光学卷积 = 一个函数的频谱被另一个函数（做成滤波器）相乘，再做逆变换。因为「时域卷积 = 频域乘积」（对光场同样成立），一次滤波操作就完成了一次卷积运算。图像平滑、边缘检测、图像复原等经典图像处理，在 4f 系统里都是一片振幅片的事——这也解释了为什么早年有人认真尝试用光学做通用图像计算机。<span class="marginnote">这就是<strong>空间滤波（spatial filtering）</strong>：挡掉高频 = 图像变平滑（低通）；挡掉低频 = 去掉背景与渐晕（高通）；挡掉特定方向的频率 = 去掉条纹噪声（方向滤波）。教材里经典的「阿贝-波特实验」就是用狭缝、小孔在频谱面做手术，直接演示这些效果。</span>

## 4 阿贝成像理论与空间滤波

**阿贝成像理论（Abbe's theory of imaging）**：成像分两步——第一步，物体衍射产生频谱；第二步，频谱被系统孔径**截取**后再次衍射合成像。孔径能通过的空间频率范围，决定像能保留多少细节。

由此得到**相干成像的截止频率**：

$$u_c = \frac{NA}{\lambda}$$

孔径越大、波长越短，截止频率越高，能通过的细节越多。<span class="marginnote">把《典型光学仪器》的瑞利判据 $\sigma = 0.61\lambda/NA$ 与这里的截止频率 $u_c = NA/\lambda$ 对比：一条是空间域表述、一条是频域表述，描述的是同一件事——「有限孔径 = 高频被截」。傅里叶光学的好处是把这条界限写成一次清晰的「频域除法」。</span>

**辨析｜易错点：** 成像不是「物点 → 像点」的几何对应，而是「频谱通过 → 逆变换合成」的信息过程。用傅里叶语言看，**孔径 = 低通滤波器**；「衍射极限」四个字，翻译成频域就是「系统是个低通」——概念上完全不同，结论上完全一致。

阿贝-波特实验（Abbe-Porter experiment）是理解这一切的最佳演示：用一张网格（二维光栅）作物，频谱面上出现整齐的点阵；用狭缝只放行一排点，像就只剩一个方向的条纹；把点阵绕中心遮成十字，像就只剩两个方向的横竖线。**在频谱面动一根手指，像面上整幅图像就变了样**——这个实验第一次直观证明「成像 = 频谱合成」，也宣告了空间滤波作为一种图像处理手段的诞生。

## 5 光学传递函数 OTF 与 MTF

成像系统对空间频率的响应用**光学传递函数（OTF）**描述，其模叫**调制传递函数（MTF）**。MTF 给出「每毫米多少线对的正弦光栅，经系统后衬比度还剩多少」。

**MTF 从 1 单调下降到 0**：零频（均匀背景）完整通过，频率越高衰减越狠，到达截止频率 $u_c$ 归零。<span class="marginnote">现代镜头评测报告满屏的「MTF 曲线」就是这个东西：横轴是空间频率（线对/毫米），纵轴是衬比度保留率。一条好的 MTF 曲线在中等频率还保持高值——它比瑞利判据完整得多，因为它同时包含了衍射与像差的影响，是行业通用的「像质成绩单」。</span>

**重点：MTF 是「成像质量的可测指标」，也是后续一切像质优化（镜头设计、图像复原）的落点**。设计软件里的评价函数、手机摄影的锐化算法、遥感图像的去模糊，优化对象都可以写成「让 MTF 更好」。

OTF 还给出一个漂亮的分解：**系统 OTF = 衍射 OTF × 像差 OTF**——衍射部分是确定的低通，像差部分是随视场、波长变化的相位与振幅损失。这意味着「衍射极限」与「像差」可以分开评测：先用理想系统算衍射 OTF，再实测总 OTF，两者之差就是像差贡献。这种「可分解、可测」的性质，让 MTF 成为镜头质检、天文望远镜验收的硬指标。

## 6 公式解析：透镜的傅里叶变换

把振幅透射函数 $t(x,y)$ 的物体放在透镜前焦面，后焦面（$z = 2f$ 处）的光场为

$$U_f(u,v) = \frac{e^{ikf}}{i\lambda f} \iint t(x,y)\, e^{-i2\pi\left(\frac{x}{\lambda f}u + \frac{y}{\lambda f}v\right)}\,\mathrm{d}x\,\mathrm{d}y$$

- **第一步，认坐标**：频域坐标 $(u,v) = \left(\dfrac{x_f}{\lambda f}, \dfrac{y_f}{\lambda f}\right)$——后焦面上的物理位置除以 $\lambda f$ 就是空间频率，所以「焦面上的光强分布」就是「物的功率谱」。
- **第二步，认积分核**：$e^{-i2\pi(ux+vy)}$ 是二维傅里叶变换核；整个积分就是 $t$ 的傅里叶变换 $\mathcal{F}\{t\}$。
- **第三步，看前置系数**：$1/(i\lambda f)$ 是振幅与相位的标定常数，不影响强度分布，但对相位测量（如全息、干涉）必须带上。<span class="marginnote">一个典型应用：把细丝或狭缝放在焦面前，后焦面上直接显示它的夫琅禾费图样——光谱仪、光束质量分析仪、傅里叶变换光谱仪全是这个「透镜 = 频谱仪」的原理。学完本节，你就能读懂这些仪器内部结构图的第一层含义。</span>

**重点：透镜实现傅里叶变换，是「光学模拟计算」的物理底座**。一次透镜变换 = 一次二维 FFT 运算，且光速完成——这正是光学神经网络、光学计算被寄予厚望的根本原因（见《现代光学前沿》）。

## 7 光信息处理的应用

傅里叶光学的工程出口，集中在「用频域做信息处理」三件事：

**全息术（holography）**：1948 年加博提出，用参考光与物光干涉，把物光的**振幅与相位**一起记录在胶片上；再现时用参考光照明全息图，衍射重建出三维像。普通照片只存强度，全息存「完整的波前」，所以能再现立体景深——三维显示、全息存储、全息干涉计量都由此而来。<span class="marginnote">加博因全息术获 1971 年诺贝尔物理学奖。全息是傅里叶光学的「亲儿子」：记录 = 干涉 + 频谱编码，再现 = 衍射 + 傅里叶逆变换。今天防伪标签上的彩虹全息、扫描仪里的激光干涉，都是它的工业后代。</span>

**匹配滤波与模式识别**：在频谱面放置「与待识别模板共轭」的滤波器，物经过该系统后，相关峰的位置直接指示「物里有没有这个模板、在哪儿」。这就是光学相关器——无需数字运算即可做二维模式识别，曾在雷达图像匹配、指纹比对中风光一时。

**光学神经网络**：4f 系统里，频谱面的振幅/相位调制片就是「可学习权重」；把多个 4f 级联，就构成多层光学神经网络。光的并行性让这类计算有望打破电子芯片的功耗瓶颈——这是《现代光学前沿》里光计算的直接续章。

**重点：傅里叶光学把「计算」请进了光学本身**——透镜做变换、调制片做权重、光做乘法。它不只是解释成像的理论，更是一台「用光做信号处理」的机器图纸。

## 8 小结

- **空间频率** $u = \sin\theta/\lambda$：把传播方向翻译成频率，光场即信号。
- **夫琅禾费衍射 = 傅里叶变换**：衍射屏、透镜、焦面组成一台「频谱仪」。
- **4f 系统** = 物面–频谱面–像面，频谱面上放滤波器做**空间滤波**。
- **阿贝成像理论**：成像 = 衍射产生频谱 + 孔径截取频谱 + 逆变换合成；孔径即低通，截止频率 $u_c = NA/\lambda$。
- **OTF/MTF**：镜头对空间频率的响应曲线，是行业标准的像质评价。
- 傅里叶光学把「光学」与「信号处理」打通，是光计算与计算成像的物理底座。
- 透镜一次变换 = 一次二维 FFT，光速完成，是光计算的硬件直觉。
- 从几何光学到傅里叶光学，「成像」二字完成了从「光线」到「信息」的升级。
- 应用三件套：全息（存完整波前）、匹配滤波（光学相关识别）、光学神经网络（光做乘法）。
- OTF = 衍射 OTF × 像差 OTF，可分解、可实测，是镜头质检的硬指标。
- 频域卷积定理：4f 系统的一次滤波 = 一次卷积，光学天然是图像处理器。
- 透镜即频谱仪：光谱仪、光束质量分析、傅里叶变换光谱仪都以此为本。
- 阿贝-波特实验直观证明「成像 = 频谱合成」，是空间滤波的思想启蒙。
- 相干成像截止频率 $u_c = NA/\lambda$：孔径即低通，频率即细节。
- 正弦光栅频谱 = 0 频 + 双峰，「数频谱峰」可测周期结构。
- 全息 = 干涉记录完整波前 + 衍射重建，三维显示与全息计量都源于此。

- MTF 曲线是镜头评测报告的「成绩单」：中频保真度高，才是一只好镜头。

在下一节，我们转向一种特殊的「频谱分析」：光在各向异性晶体中分裂与转向的**晶体光学**——那里有双折射、电光效应与声光效应，是光学器件的又一大家庭。
