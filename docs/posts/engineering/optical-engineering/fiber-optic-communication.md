## 为什么从光纤通信开始

上一节讲了「光如何在光纤里走」，本节把它接成一个系统：**光纤通信**——把电信号变成光信号、送进光纤、传几千公里、再变回电信号。这是现代信息社会的主动脉。<span class="marginnote">你发送一条微信、看一个视频，数据都要先变成光脉冲、在光纤里狂奔、再变回电信号。全球互联网流量以每秒 Pb（10¹⁵ bit）计，99% 以上走光纤。理解光纤通信，就是理解「数字世界是如何物理相连的」。</span>本节从发射机一路讲到接收机，串起整个链路。

## 1 系统总览：一条光路的四段

光纤通信系统由四段组成：

1. **光发射机**：光源（激光二极管）+ 调制器，把电信号「写」到光上。
2. **光纤链路**：传输介质，加上放大器/再生器中继。
3. **光接收机**：探测器 + 放大电路，把光「读」回电。
4. **辅助系统**：波分复用（WDM）把多路光塞进一根光纤，大幅扩容。<span class="marginnote">光纤通信的压倒性优势：带宽极高（THz 级）、损耗极低（0.2 dB/km）、抗电磁干扰、无串扰、体积重量小。相比铜缆（GHz 级、百 dB/km），光纤是「物理上开挂」的传输介质——这也是为什么骨干网全是光纤。</span>

**重点**：光纤通信的本质是「电 → 光 → 传输 → 光 → 电」的两次转换。系统的全部性能指标——速率、距离、误码率——都由这四段的配合决定。

回望半个世纪：1970 年代单纤速率几十 Mbit/s，2010 年代商用单纤 100 Gbit/s，今天实验室已到单纤 100+ Tbit/s——六十年增长了百万倍。这趟「带宽狂飙」由三个技术里程碑接力：低损耗光纤（1970）、EDFA 光放大（1990）、相干光通信 + 高阶调制 + DSP（2000 后）。每一代都是「物理 + 算法」的双轮驱动。

## 2 光发射机：如何把电信号写到光上

光发射机的核心是**光源**：半导体激光器（激光二极管，LD）或 LED。调制有两种方式：

- **直接调制**：直接改变激光器的注入电流，光强随电流变化——简单便宜，但高速调制时激光器频率会漂移（啁啾），限制传输距离。短距、中速用。
- **外调制**：激光器连续出光，用外部调制器（马赫-曾德尔调制器、电吸收调制器）在光路上「开关」光——无啁啾、速率极高（100 Gbit/s+），长途干线用。<span class="marginnote">直接调制是「拧水龙头」，外调制是「水龙头常开、水闸开关」。外调制器用晶体电光效应或半导体电吸收效应，让光路在皮秒级开合，是 400G/800G 相干光通信的必备。调制的极限速率由电子电路与调制器材料共同决定。</span>

调制格式从最简单的 **OOK**（开/关键控：有光 = 1，无光 = 0）一路演进到 **QPSK、16QAM**（相位/幅度同时编码）——每符号携带的比特数越多，同样带宽下速率越高。<span class="marginnote">OOK 一比特一个「亮/灭」，16QAM 一个符号就能传 4 比特（16 种幅度×相位组合）。从 OOK 到高阶 QAM，是「用信噪比换速率」的经典交易：调制阶数越高，对噪声越敏感、需要越高信噪比。相干光通信用 DSP 补偿色散与相位，让高阶调制成为可能。</span>

**重点**：调制的进化史就是「每个光符号多装几个比特」的历史。从 1 bit/符号到 8 bit/符号，同样光纤、同样带宽，容量翻八倍——这是光通信容量增长的一半来源（另一半是 WDM）。

## 3 光接收机：如何把光读回电

接收机把光信号还原成电信号：**光电探测器（PIN 或 APD）→ 跨阻放大器（TIA）→ 时钟恢复 → 判决**。<span class="marginnote">接收机的第一瓶颈是探测器灵敏度：能测多弱的光，决定中继距离。APD 的内增益让弱光也能读，代价是噪声与高压；PIN 简单可靠，短距为主。接收机灵敏度通常用「接收功率最低值」标定（如 −28 dBm），低于它误码率就爆表。</span>接收端还有一个关键环节：**均衡与色散补偿**——现代相干接收机用 DSP 在数字域把色散、偏振劣化统统补偿回来，让「物理做不到的」由算法做到。

**辨析｜易错点：** 光接收机不是「看到光就输出 1」这么简单。它要解决定时（时钟恢复）、判决阈值（0/1 分界线）、噪声抑制（放大器带宽）三个问题。把接收机理解成「光电转换器」是低估了它——它是「模拟前端 + 数字信号处理」的完整系统。

## 4 掺铒光纤放大器：通信的加油站

长途传输最大的问题是信号衰减。老办法是「光-电-光再生」：每隔几十公里把光变成电、放大、再变回光——复杂、昂贵、速率受限。**掺铒光纤放大器（EDFA）**直接放大光本身：泵浦激光（980/1480 nm）激发铒离子，1550 nm 信号光通过时受激辐射被放大。<span class="marginnote">EDFA 的工程意义怎么强调都不过分：它在光域直接放大，不区分调制格式、不限制速率，增益可达 20–40 dB，一段放大器能抵消 100 km 光纤的损耗。它让跨洋海底光缆成为现实——每隔约 80 km 放一个 EDFA，把信号「续命」上万公里。1990 年代 EDFA 商用，光纤通信进入「全光中继」时代。</span>

**重点**：EDFA 的「不透明」放大是它的魔法——它不在乎光上「写」的是什么信号，只管放大。这使 WDM 的几十路光同时被放大，容量爆炸式增长。

## 5 波分复用：一根光纤当几十根用

单根光纤只传一个波长，容量有限。**波分复用（WDM）**把几十上百个不同波长的光同时送入一根光纤，每路独立调制，接收端再用滤波器分出来。<span class="marginnote">标准 WDM 网格（ITU-T）以 50 GHz 或 100 GHz 间隔把 C 波段切成 40–80 个通道。加上每通道 100 Gbit/s 的相干调制，一根光纤的容量可达 8–16 Tbit/s。这就是「带宽廉价」的秘密：物理上只有一根光纤，逻辑上是几百条「虚拟光纤」。</span>WDM 的关键器件是**合波/分波器**（阵列波导光栅 AWG、薄膜滤波器）——把不同波长精确地合进一根光纤、再精确地拆开。

**重点**：WDM 是「频分复用」在光域的版本。它的价值在于：不换光纤、不换速率，只加波长通道就能扩容——运营商扩容的首选手段。

## 6 链路预算：能传多远的账本

设计一条光纤链路，第一件事是算**链路预算（link budget）**：发射功率一路扣掉光纤损耗、接头损耗、器件损耗，最后剩多少给接收机。接收机要保证误码率，需要最小接收功率 $P_{min}$。最大传输距离：

$$L_{\max} = \frac{P_{tx} - P_{min} - M}{\alpha + \alpha_c/l_c}$$

其中 $P_{tx}$ 是发射功率（dBm），$P_{min}$ 是接收灵敏度，$M$ 是富余量（margin），$\alpha$ 是光纤损耗（dB/km），$\alpha_c$ 是每个接头的损耗，$l_c$ 是接头间距。<span class="marginnote">链路预算的工程意义：它把「能传多远」从感觉变成算术。10 dBm 发射、−28 dBm 灵敏度、0.2 dB/km 损耗，不计接头与富余，理论距离 $(10+28)/0.2 = 190$ km。但实际要扣接头损耗、温漂、老化富余，通常打六折——这就是为什么设计距离总比理论值保守。</span>

**重点**：链路预算是光纤工程的第一算术。所有损耗项都是「减法」，所有增益项都是「加法」，最后必须落在接收机的灵敏度窗口内——**这是光纤通信系统设计的基本功**。

## 7 公式解析：链路预算的三步拆解

以「发射功率 $P_{tx} = +3$ dBm，接收灵敏度 $P_{min} = -25$ dBm，光纤损耗 0.3 dB/km（1310 nm），接头每 2 km 一个、每个 0.1 dB，富余 3 dB」求最大距离：

$$
L_{\max} = \frac{P_{tx} - P_{min} - M}{\alpha + \alpha_c/l_c} = \frac{3 - (-25) - 3}{0.3 + 0.1/2}
$$

- **第一步，算可用功率预算**：$P_{tx} - P_{min} - M = 3 + 25 - 3 = 25$ dB。这是「从发射到接收，可以损耗掉的全部 dB 数」。
- **第二步，算每公里综合损耗**：光纤 0.3 dB/km + 接头 0.1 dB/2km = 0.3 + 0.05 = 0.35 dB/km。
- **第三步，相除得距离**：$L_{\max} = 25 / 0.35 \approx 71$ km。<span class="marginnote">对照：不加富余与接头时理论距离 $28/0.3 = 93$ km，实际 71 km——差了两成多。工程设计的每一分保守，都是给「温度变化、器件老化、光纤弯曲」留的缓冲。链路预算的正确用法是「反着算」：先定目标距离，反推需要多少发射功率、多低损耗的光纤。</span>

**重点**：链路预算的每一步都是 dB 的加减法。dBm 是绝对功率，dB 是相对增益/损耗——**dBm 相减得 dB，dB 与 dB 相加**，别把两者混了。

## 8 误码率：通信质量的总账

光纤通信的最终质量指标是**误码率（bit error rate, BER）**——错误的比特占传输比特的比例。工程标准：数据中心 < $10^{-12}$，长途 < $10^{-15}$（即每万亿比特错不到一个）。<span class="marginnote">误码率换算：BER $10^{-12}$ 意味着每 1000 秒（10 Gbit/s 速率下）才可能错 1 比特——听起来宽松，但正是这个标准保证了你看视频不卡顿。误码的来源是噪声与色散把「1」的幅度压到接近「0」、把「0」抬到接近「1」。</span>误码率与信噪比的关系由高斯噪声近似给出：

$$BER = \frac{1}{2}\,\text{erfc}\!\left(\frac{Q}{\sqrt{2}}\right)$$

$Q$ 因子是接收信号的「1/0 电平差 ÷ 噪声标准差」，工程上 $Q = 6$ 对应 BER ≈ $10^{-9}$，$Q = 7$ 对应 BER ≈ $10^{-12}$。<span class="marginnote">这个 $Q$ 因子是接收机性能的通用语言：眼图的张开高度除以噪声厚度就是 $Q$。工程师在示波器上看「眼图」——1/0 电平的叠加轮廓像一只睁开的眼睛，眼睛张得越大、越清晰，BER 越好。眼图是光通信调测的第一直观工具。</span>

**重点**：误码率是「噪声、色散、串扰」三股破坏力量的总账。设计的目标不是「信号完美」，而是「BER 达标且留有余量」——达标阈值之上，一切优化都服务于「把 BER 压得更低、把距离推得更远」。

## 9 从骨干到数据中心：光纤网络的当代图景

光纤通信已从「电话骨干」演进为全场景覆盖：

- **长途骨干**：跨省跨洋，单纤 16 Tbit/s+，WDM + 相干 + EDFA 全上阵。
- **城域与接入**：PON（无源光网络）把光送到千家万户，一根光纤分给 64 户，FTTH 宽带。
- **数据中心互连（DCI）**：AI 时代数据中心内部与之间用光互连，400G/800G 光模块飞速迭代——**大模型训练的集群通信，底层就是成千上万条高速光纤**。<span class="marginnote">AI 大模型训练时，上万张 GPU 之间要高速交换梯度——这正是光模块的战场。800G 光模块、CPO（共封装光学）把光引擎直接做进交换芯片，是「算力即光」的时代注脚。光纤通信正从「传输管道」变成「计算架构的一部分」。</span>
- **海缆**：跨洋光缆是国际互联的骨干，全球 500+ 条海缆承载几乎全部洲际流量。

**重点**：光纤通信的演进主线是「容量 × 距离 × 成本」三方赛跑。每代技术——更窄激光、更高阶调制、更多波长、更智能 DSP——都在往这三项里推进一格。理解主线，就能预判下一波技术方向。

## 10 小结

- 光纤通信四段：发射机 → 光纤 → 放大器/中继 → 接收机，本质是「电→光→电」两次转换。
- 调制：直接调制 vs 外调制；OOK → QPSK → 16QAM，每符号装更多比特。
- 接收机：探测器 + TIA + 时钟恢复 + DSP 均衡；灵敏度决定中继距离。
- **EDFA** 在光域直接放大，不区分调制格式，让全光中继与跨洋传输成为现实。
- **WDM** 把几十上百个波长塞进一根光纤，容量按通道数倍增。
- 链路预算 $L_{\max} = (P_{tx}-P_{min}-M)/(\alpha+\alpha_c/l_c)$：dBm 与 dB 分清，设计要留富余。
- 误码率 $BER = \frac{1}{2}\text{erfc}(Q/\sqrt{2})$：$Q=7$ 对应 $10^{-12}$，眼图是调测的第一直观工具。
- 当代图景：PON 接入、数据中心光互连（AI 集群）、跨洋海缆——光即算力。

在下一节，我们把光当作「计算媒介」而非「传输媒介」：**光信息处理**——用光直接做傅里叶变换、滤波与全息，让光在数字之外开辟另一条信息通道。
