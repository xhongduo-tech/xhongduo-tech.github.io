## 为什么从射频前端开始

手机每秒钟都在与基站交换无线电波——而把天线收到的 GHz 级微弱信号变成基带数字信号的那套电路，就是**射频前端（RF front-end）**。它是无线通信里「模拟味道」最浓的部分：噪声、线性度、匹配、阻抗——每一个词背后都是毫米级波长的物理。这一篇讲清射频接收链路的经典架构（超外差与零中频）、低噪声放大器与混频器这两块核心积木、以及射频设计最重要的度量——噪声系数与线性度。

## 1 接收链路的两种架构

天线收到的信号极其微弱（µV 级）且频率很高（GHz 级），不能直接 ADC——必须先放大、再降到低频。两大主流架构：

- **超外差（superheterodyne）**：先放大到射频（RF），混频到**中频（IF）**，滤波放大后再二次混频到基带。选择性好、抗镜像干扰强，但需要镜像抑制滤波器，外部元件多、集成度低。<span class="marginnote">超外差是 20 世纪初的发明：把不同载频的信号统一搬到固定中频处理，用一个可调本振就能覆盖整个频段。它的代价是「镜像频率」——本振两侧的信号都会混到同一中频，必须用滤波器干掉一侧。</span>
- **零中频（zero-IF / 直接变频）**：一步混频直接到基带。省去中频滤波器，集成度极高，是现代手机 SoC 的主流——代价是直流失调、I/Q 失配等「自混频」问题需要数字校正。

**重点：零中频用「数字补偿」换「模拟简化」**——把超外差的棘手问题（镜像）换成好补偿的问题（直流失调、失配），这是射频集成化的必然方向。

## 2 低噪声放大器（LNA）：第一级放大器

天线之后第一级是**低噪声放大器（LNA）**，它的使命只有一个：**放大信号，且尽量不引入噪声**。因为整条接收链路的噪声性能几乎由第一级决定——后级的噪声被 LNA 的增益「压制」了。

级联噪声系数（弗里斯公式）：

$$NF_{total} = NF_1 + \frac{NF_2 - 1}{G_1} + \frac{NF_3 - 1}{G_1 G_2} + \cdots$$

**重点：第一级的增益越高、噪声越低，整条链路的噪声越好**——后级再差的噪声也被第一级增益除掉了。这就是为什么 LNA 设计者愿意牺牲线性度去换噪声与增益。<span class="marginnote">弗里斯公式是射频系统设计的「噪声预算」：链路里每一级都贡献噪声，但只有第一级是「全额贡献」，越靠后越被摊薄。于是「噪声优化」永远从 LNA 开始。</span>

LNA 还要做**输入匹配**：天线/滤波器通常以 50 Ω 系统阻抗工作，LNA 输入必须匹配到 50 Ω 才能把功率无反射地收进来。匹配网络常用片上电感（损耗是射频电路的头号敌人）。

## 3 混频器：频率的翻译官

**混频器（mixer）**把高频信号与本振相乘，利用三角恒等式产生和频与差频：

$$\cos(\omega_{RF}t) \cdot \cos(\omega_{LO}t) = \frac{1}{2}[\cos(\omega_{RF}-\omega_{LO})t + \cos(\omega_{RF}+\omega_{LO})t]$$

取差频就是下变频到中频/基带。混频器的核心品质：**转换增益**（RF 到 IF 的电压增益）、**噪声**、以及**线性度**（对强干扰的承受力）。<span class="marginnote">混频器的致命弱点是「干扰信号」：若带外有强信号恰好在 $\omega_{RF}$ 附近，它会与本振的谐波混出假信号——这是线性度指标 IP3 要防的头号事故。手机天线旁若有两个强干扰，三阶互调可能盖住有用信号。</span>

**辨析｜易错点：混频器是「线性时变」电路，不是非线性电路**——它的功能原理是「乘法」（线性），只是本振让时变周期切换。把混频器当非线性电路分析，会得到完全错误的失真结论。

## 4 射频设计的两大指标：NF 与 IP3

**噪声系数（NF）**：输出信噪比 / 输入信噪比，dB 表示。衡量电路「添了多少噪声」。0 dB 是理想（不加噪声）。
**三阶交调点（IIP3）**：两个强干扰造成的三阶互调产物功率曲线外推到与主信号功率曲线相交的点。IIP3 越高，抗强干扰能力越强。<span class="marginnote">IIP3 与 1 dB 压缩点（P1dB）是线性度的两个标签：P1dB 看「信号多大开始压缩」，IIP3 看「干扰多大开始捣乱」。三阶互调的可怕在于：两个靠得很近的强干扰，其三阶产物恰好落在两个干扰之间——正好可能压在有用的弱信号上。</span>

**重点：NF 与 IIP3 是一对死对头**——加大偏置电流、增大晶体管尺寸能改善 IIP3，但往往恶化噪声；而噪声优化（窄带匹配、大源阻抗）又牺牲线性度。射频前端的每一个设计决策都在噪声与线性度之间走钢丝。

## 5 公式解析：弗里斯级联噪声

$$
NF_{total} = NF_1 + \frac{NF_2 - 1}{G_1} + \frac{NF_3 - 1}{G_1 G_2}
$$

- **$NF_1$**：第一级噪声系数——全额计入，无折扣。
- **$(NF_2-1)/G_1$**：第二级噪声被第一级增益压缩——第一级增益 $G_1$ 越大，第二级的影响越小。
- **第三项**：越靠后越被多级增益摊薄，可忽略。
- **设计含义**：LNA 的增益与噪声是系统噪声的「命门」；一旦 LNA 确定，整条链路的噪声天花板基本就定了。

## 6 发射链路与收发信机

接收链路把信号「从天线搬到基带」，发射链路反其道而行——**把基带信号「送上」天线**：

- **发射机结构**：基带 → 上变频混频（本振与基带相乘抬到射频）→ 功率放大器（PA）→ 天线。
- **功率放大器（PA）**：发射链路的「大力士」，也是功耗与线性度的最大矛盾体——要把信号放大到瓦级，但 PA 效率与线性度天然冲突（A 类线性但效率 <50%，开关类效率高但非线性）。
- **功放的线性化**：预失真（数字预失真，DPD）、包络跟踪（ET）——用数字与电源技术把 PA 的线性度「借」回来。
- **收发共存的挑战**：手机同时收发，发射的强信号会漏进接收链路——双工器、频段隔离、收发链路联合设计成为 SoC 的关键难题。

**重点：射频系统的完整视野 = 接收（低噪声）+ 发射（高功率）+ 频率合成（PLL）三线并进**——接收链路求「灵敏」（弱信号也要听清），发射链路求「有力」（强信号要送得远），两者都要「线性」（别失真）。<span class="marginnote">射频与微波工程里有一条贯穿始终的主线：「阻抗匹配」——信号在阻抗不连续处会反射，反射就是损耗与失真。LNA、PA、天线、滤波器之间处处要做 50 Ω 匹配。理解了「不匹配 = 反射 = 损失」，你就掌握了射频设计的通用语言，它与微波工程（见《信息与通信工程》）是一套世界观。</span>

## 7 射频指标的工程直觉

射频系统里四个数字，是工程师的「通用语言」：

**dBm**：绝对功率，0 dBm = 1 mW。手机发射功率约 23 dBm（200 mW），接收灵敏度可达 -100 dBm 以下——动态范围跨越 120 dB，即 10¹² 倍。
**dB**：相对增益/损耗，LNA 增益 20 dB = 100 倍。
**NF（噪声系数）**：0 dB 理想，LNA 做到 1～2 dB 已属优秀。噪声系数每降 1 dB，灵敏度就提升 1 dB——「dB 是射频的货币」。
**IIP3**：线性度标尺，越高越能抗强干扰。手机射频前端要在「-100 dBm 的弱信号」与「-20 dBm 的强干扰」同时存在时工作——动态范围与线性度是射频设计的命门。

**实战直觉**：接收链路噪声预算——LNA NF=2 dB、增益 20 dB，后级混频器 NF=10 dB，则整链 NF ≈ 2 + (10-1)/100 ≈ 2.1 dB。**后级噪声被 LNA 增益压掉了 99%**——这就是「LNA 是第一级的全部意义」。<span class="marginnote">dB 的妙处在于「乘法变加法」：链路各级增益用 dB 相加、噪声系数用级联公式相加，系统预算变成「一张 Excel 表」。射频工程师的日常，就是在这张 dB 的账本上做加减法——理解了 dB 的运算，就掌握了射频设计的算术基础。</span>

## 8 射频前端的设计取舍速览

射频前端的每一个模块，都站在一对矛盾的中间：

| 模块 | 主要矛盾 | 取舍方向 |
| --- | --- | --- |
| LNA | 噪声 vs 线性度 | 保噪声优先（第一级） |
| 混频器 | 增益 vs 线性度 | 折中，靠偏置与拓扑 |
| PA | 效率 vs 线性度 | 线性化技术补效率 |
| PLL/VCO | 相位噪声 vs 调谐范围 | 结构决定（LC vs 环形） |
| 匹配网络 | 增益 vs 带宽 | 带宽匹配理论折中 |

**重点：射频设计的核心功课是「在每个模块的矛盾点找最优解，再在全链路里平衡」**——LNA 可以偏向噪声，因为后级会被它的增益压制；PA 必须兼顾效率，因为它是功耗大户。整条链路的预算分配，比任何单一模块的极致优化都重要。

**实战直觉**：手机射频前端的接收灵敏度大约 -100 dBm（即 $10^{-13}$ W），而旁边基站可能还有 -20 dBm 的强干扰——同时处理「针尖大的信号」与「电饭锅大的干扰」，就是射频工程师的日常。动态范围 80 dB 以上，全靠 NF、IIP3 与滤波器的协同。

## 9 一句话记牢全篇

- **零中频取代超外差**——用数字校正换模拟集成度，手机 SoC 的主流。
- **LNA 决定系统噪声**——第一级增益越高，后级噪声被摊得越薄。
- **混频器是线性时变电路**——它做乘法、不是失真。
- **NF 与 IIP3 是死对头**——噪声优化与线性度优化互相拉扯。
- **弗里斯公式是噪声预算**——第一级是「全额」，越靠后越被摊薄。

**重点：射频设计的全部功夫，浓缩成「在噪声与线性度之间走钢丝」**——LNA 偏噪声、PA 偏效率、混频器折中，整条链路在 dB 的账本上做平衡。

**辨析｜易错点：dB 是「乘法变加法」的语言**——链路各级增益用 dB 相加、噪声用级联公式叠加，系统预算变成一张可追踪的表。读射频文档不会 dB 的换算，就像读账本不会加减法。

## 10 小结

- 射频接收链路从**超外差**走向**零中频**——用数字校正换模拟集成度。
- **LNA** 是第一级放大器，决定整链路噪声；必须做 50 Ω 输入匹配。
- **混频器**用本振「翻译」频率，是线性时变电路，核心指标是转换增益与线性度。
- **NF 与 IIP3** 是射频设计的死对头，所有设计都在噪声与线性度之间权衡。
- 弗里斯公式说明**第一级噪声与增益**决定系统噪声预算。
