## 为什么从路线图结束

前十一节把「先进制程」的过去与现在讲透了：从摩尔定律的缩放史，到 FinFET/GAA/CFET 的架构演进，到 high-k、沟道、源漏、互连、EUV、供电的每一块拼图，再到 DTCO、3D 集成与命名营销。作为收官，本节把目光投向**未来**：IRDS 与 imec 的路线图里，Angstrom 节点（A14/A10）会带来什么？CFET 之后还有什么？2D 材料沟道是不是终极答案？

**IRDS（International Roadmap for Devices and Systems）**：接替 ITRS 的国际半导体路线图组织，每年发布面向未来十年的器件与系统技术目标，是行业「共同的时间表」。**imec**：比利时微电子研究中心，先进制程与 3D 集成的全球顶级研发机构，其 IEDM/SPIE 论文常被视为「未来节点的预告片」。

凯恩斯的这句话精准概括了路线图的本质：**未来并不缺新观念，缺的是挣脱旧观念的勇气**。当我们习惯用「nm 数字」「平面缩放」的旧框架思考，就会低估 A14/A10 时代的彻底性——那里没有「更小的纳米」，只有「全新的结构」。<span class="marginnote">把本专题的坐标放在 IRDS 上：IRDS 用「逻辑器件密度目标」替代「nm 尺寸」，从侧面印证了《制程命名》一节的判断——<strong>密度才是节点，名字只是代号</strong>。本专题的每一节，都能在 IRDS 的章节（器件、互连、光刻、系统集成）里找到对应。</span>

## 1 路线图的机制：一份「行业共同的时间表」

路线图不是预言，而是一份**自我实现的时间表**：设备商、材料商、设计公司都按它安排研发与投资，于是「计划中的节点」真的会落地。理解它的机制，要从三件事说起：<span class="marginnote">IRDS 的运作方式：由全球数百位专家组成各工作小组，每年评估「未来五年器件/互连/光刻等该做到什么」，形成带年份的目标表。它不是某个公司的机密，而是整个行业的「公共规划」——这正是「摩尔定律自我实现」的制度化形态。</span>

- **接替 ITRS**：2016 年，运行多年的 ITRS（国际半导体技术路线图）因「等比例缩放已死」而转型为 IRDS，从「器件缩放路线图」转向「器件 + 系统」的全栈路线图——这本身就是「缩放终结」的制度化承认。
- **节点序列**：IRDS 逻辑路线图列出 N3、N2 之后进入「埃」时代——A14、A10、A7……「A」代表 Ångström（1 Å = 0.1 nm）。命名与物理尺寸无关，纯粹是代际代号。
- **年度滚动**：每年更新、滚动十年，任何技术「掉队」都会被调期或剔除——路线图因此既是「计划」也是「体检」。

把 IRDS 与 imec 的「未来节点叙事」摆出来，能看到一条清晰的演进线：

| 代际 | 器件架构 | 配套技术 |
| --- | --- | --- |
| 当前（N3/N2） | FinFET → GAA 纳米片 | EUV、高 k |
| A14/A10 | GAA + CFET 起步 | BSPDN、先进互连 |
| A7 及以后 | CFET 成熟 + 3D 堆叠 | 背面供电、混合键合 |
| 更远 | 2D 材料、全新器件 | 全新材料体系 |

这张表是「本专题未来篇」的骨架：A14/A10 的主菜是 **CFET 与 BSPDN**（第八、二节的技术进入量产），更远则是 **3D 集成与 2D 材料**（第十节与本节末段的主题）。

需要强调的是，「路线图」一词容易让人误以为未来是被「计划」出来的。实际上，路线图更多是**对已知技术成熟的预估**：每一项技术（CFET、BSPDN、2D 材料）都已有实验室原型，路线图回答的是「它们何时、以什么顺序进入量产」，而非「它们会不会出现」。**未来已经存在于实验室里，路线图只是它的日历**。

## 2 A14/A10：Angstrom 节点会带来什么

A14/A10 不是「N2 再小一号」，而是几个**结构级变革**同时落地的节点：<span class="marginnote">Angstrom 节点的命名逻辑：A14 ≈ 14 Å ≈ 1.4 nm。但它的意义不在「1.4 nm」，而在「这一代由 CFET + BSPDN 定义」——结构创新取代几何缩放，成为每代进步的主角。读懂 Angstrom 节点，等于读懂了后 Dennard 时代的终极形态。</span>

- **CFET 进入量产**：把 NMOS/PMOS 垂直叠起来（第二节的 CFET），标准单元面积近半——这是「水平密度见顶后靠垂直找密度」的决定性一步。
- **BSPDN 成为标配**：第八节的背面供电在 A14/A10 从「可选」变成「标配」——电源走背面、信号走正面，布线资源彻底分层。
- **3D 集成渗透**：顺序式 3D 与 chiplet 3D 开始进入高端产品，memory-on-logic 成为带宽解决方案。
- **互连材料换代**：钴/钌走向成熟，空气隙等超低 k 介质在局部采用。

这四项不是「各干各的」，而是**在 DTCO 的棋盘上咬合在一起**：CFET 让单元更矮、BSPDN 释放轨道、3D 提供垂直自由度——它们共同定义了「Angstrom 时代」的形态。这也呼应了第九节的判断：**先进节点的进步，越来越依赖「多技术协同」而非「单一突破」**。

把 Angstrom 节点的四项变革与「前文的技术」一一对应起来，能看清路线图不过是「本专题各节的未来时态」：

| 路线图变革 | 本专题对应节 |
| --- | --- |
| CFET 量产 | 第2节 架构演进 |
| BSPDN 标配 | 第8节 背面供电 |
| 3D 集成渗透 | 第10节 3D 集成 |
| 互连材料换代 | 第6节 互连演进 |
| EUV 持续演进 | 第7节 EUV 整合 |

这张「对应表」是本节给读者的一个礼物：**读路线图时，不必把它当陌生的未来，它只是本专题已学技术的「排期表」**。

## 3 公式解析：CFET 与 2D 材料背后的物理逻辑

为什么 Angstrom 节点必须靠 CFET 与 2D 材料？两个「物理账」算得清楚。

**CFET 的面积账**：传统 CMOS 里，NMOS 与 PMOS 并排放在水平方向，标准单元宽度至少容纳两者加隔离。CFET 把两者垂直叠放：

$$
W_{cell}^{CFET} \approx \frac{1}{2} W_{cell}^{GAA}
$$

也就是把「两个晶体管并排」变成「两个晶体管叠放」，水平方向的单元宽度几乎减半。**当水平缩放无法再压间距，垂直方向就提供了「免费的密度」**——这是 CFET 的物理动机，也是它成为 A14/A10 主角的根本原因。<span class="marginnote">CFET 的代价在工艺：N/P 垂直堆叠要求上下两层的源漏、栅极、隔离全部重新设计，热预算与良率挑战巨大。imec 已在多个 IEDM 论文中展示 CFET 集成方案，「能造」与「好造」之间还有距离。</span>

**2D 材料的静电账**：当沟道厚度缩到几个原子层（< 1 nm），体硅的「悬挂键」与表面粗糙度散射会让迁移率崩溃。2D 材料（如 MoS₂、WS₂ 等过渡金属硫化物）只有一两个原子层厚、**无悬挂键**、表面天然平整，理论上在超薄沟道下迁移率与静电控制反而更好：

把「硅沟道」与「2D 沟道」在超薄场景下的表现对照一下：

| 维度 | 超薄硅沟道 | 2D 材料沟道 |
| --- | --- | --- |
| 悬挂键 | 大量，表面态密度高 | 无悬挂键，表面天然钝化 |
| 表面粗糙度散射 | 严重 | 极弱 |
| 超薄迁移率 | 随厚度骤降 | 基本保持 |
| 集成难度 | 基准 | 高（生长、接触） |

这张表说明 2D 材料的「优势窗口」在**超薄沟道**——这正是后 Angstrom 节点的沟道厚度区间。它不全面优于硅，但在「目标沟道长度下」，它的综合表现有超越硅的可能。

$$
\lambda_{2D} \propto \sqrt{t_{ox}} \quad \text{（2D 沟道几乎不贡献 $\lambda$）}
$$

即：2D 沟道的本征长度几乎只由栅氧决定，静电控制可以做到体硅无法企及的程度——这是「2D 材料是后硅时代候选」的物理核心。<span class="marginnote">2D 材料的现实挑战：接触电阻难做（与金属的界面态）、与硅工艺的集成困难、大面积生长难均匀——它们的「迁移率不一定更高，但超薄沟道下的综合表现可能更好」是研究者反复强调的判断。与《沟道工程》一节的结论一致：材料竞争看「目标沟道长度下的综合表现」，而非本征迁移率。</span>

## 4 展望与不确定性：哪些会成真

把路线图摊开，需要区分「较确定」与「不确定」：<span class="marginnote">路线的「确定性」来自成本与物理：CFET 与 BSPDN 的结构收益明确、工艺路径已有原型，因此「较确定」；2D 材料与量子器件的收益与工艺都未定型，因此「不确定」。<strong>路线图不是平铺的乐观清单，而是按成熟度分层的赌注</strong>。</span>

还有一个常被忽略的维度：**成本**。先进节点的研发与建厂成本不断攀升，一颗新节点的研发投入以数十亿美元计——成本不再是「做完技术才考虑的问题」，而是「决定技术能否量产的判据」。因此路线图里「较确定」的技术，往往也是「成本可接受」的技术；而「不确定」的 2D 材料，一半卡在物理、一半卡在成本。**技术路线图的背后，是一张成本路线图**。

- **较确定**：GAA → CFET 的架构演进、BSPDN 标配化、3D 集成渗透、互连材料换代——它们都已进入量产路线或原型验证，落地只是时间问题。
- **成本维度**：新节点研发与建厂成本以数十亿美元计，成本决定技术能否量产；路线图背后是成本路线图。
- **不确定**：2D 材料能否真正进入量产、CFET 的良率与成本能否达标、顺序式 3D 能否跨过热预算门槛——这些仍取决于未来几年的工程突破。
- **更深的问题**：Xiao 第4章的标题「摩尔定律的尽头？」依然是悬案。缩放的「密度红利」已显著放缓，行业正在靠「架构 + 系统」续命——**摩尔定律没有死，但它从一个「物理规律」变成了「工程毅力」**。

把本专题十二节串成一句话：**从摩尔定律的缩放史出发，走过 FinFET、GAA、CFET 的架构演进与 high-k、沟道、源漏、互连、EUV、供电的每一块拼图，再经 DTCO、3D 集成与命名营销的视角重审，最终抵达 IRDS 与 imec 的路线图——「先进制程与器件集成」这门学科的全貌，已经尽收眼底。** 当「更小」的旧路走尽，行业正用「结构、系统与材料」的新语言续写摩尔定律的下一章。

## 5 小结

- **路线图机制**：IRDS 接替 ITRS，用「密度目标」替代「nm 尺寸」，是行业共同的自我实现时间表。
- **Angstrom 节点（A14/A10）**：CFET + BSPDN + 3D 集成的结构级变革，取代几何缩放成为进步主角。
- **CFET 面积账**：N/P 垂直叠放，标准单元宽度近半，垂直提供「免费密度」。
- **2D 材料静电账**：无悬挂键、原子级薄，静电控制超越体硅；集成与接触仍是挑战。
- **确定 vs 不确定**：CFET/BSPDN/3D 较确定，2D 材料与良率跨坎不确定；「摩尔定律的尽头」悬而未决。
- **全专题收束**：先进制程正在用「结构、系统、材料」的新语言续写摩尔定律的下一章。

至此，「先进制程与器件集成」专题的十二篇全部完成——从缩放简史到路线图展望，一条从物理到工程、从过去到未来的完整脉络就此贯通。
