## 为什么从农业遥感开始

地面传感器再密集，也只能覆盖「点」；而一片农田是几十上百亩的「面」。**农业遥感（agricultural remote sensing）** 用卫星、无人机等平台从空中对地面「隔空观察」，一次成像就是整片农田——它补上了地面传感「只见树木不见森林」的短板。<span class="marginnote">遥感的字面义是「<strong>遥远的感知</strong>」：不接触目标，通过探测目标反射/发射的电磁波来反推目标性质。农业遥感把「农田的体检」从抽样式（测几个点）变成了<strong>全覆盖式（看整片田）</strong>——这是它相对地面传感的最大优势。</span>本节讲清遥感的基本原理、植被指数的计算、卫星与无人机两类平台，以及农业上的典型应用。

## 1 遥感的基本原理

遥感系统的完整链条是「**电磁波源 → 地物 → 传感器 → 图像 → 反演**」：

**光源**：太阳（被动遥感，接收地物反射的太阳光）或雷达主动发射微波（主动遥感）。
**地物**：不同地物（作物、土壤、水体）对不同波长的电磁波反射率不同，形成各自的**光谱特征**。<span class="marginnote">健康植物叶片富含叶绿素，在红光波段（约 680 nm）强烈吸收、在近红外波段（700–1300 nm）强烈反射——这个「<strong>红吸收、近红外高反射</strong>」的光谱反差，是几乎所有植被遥感指标的基础。作物缺肥、缺水、受病时叶绿素含量下降，红光反射升高、近红外反射降低，光谱特征随之改变。</span>
- **传感器**：装在卫星或无人机上的多光谱相机/高光谱仪，记录地物在各波段的反射率。
- **反演**：从光谱数据反推出植被长势、叶面积、叶绿素含量、土壤水分等农情参数。

## 2 公式解析：归一化植被指数（NDVI）

遥感农业里用得最广的指标是**归一化植被指数（NDVI）**：

$$
NDVI = \frac{NIR - Red}{NIR + Red}
$$

对这条式子做四步拆解：

- **第一步，明确各符号**：$NIR$ 是地物在**近红外波段**的反射率；$Red$ 是地物在**红光波段**的反射率。
- **第二步，为什么这样设计**：健康植被红光反射低（被叶绿素吸收）、近红外反射高，所以 **NIR − Red 大**；而 (NIR + Red) 作为分母做归一化，抵消了光照强度、地形、传感器姿态等整体性影响——**比值式指标天生抗干扰，这是遥感指数的设计哲学**。<span class="marginnote">NDVI 的取值范围在 −1 到 +1 之间：裸土约 0.1–0.2，稀疏植被约 0.2–0.4，茂密健康植被可达 0.6–0.9，水体接近 0 或负值。<strong>NDVI 一张图，就能把整片农田的长势「可视化」</strong>。</span>
**第三步，长势监测的含义**：同一块田在不同时间拍两期 NDVI，差值就是**长势变化**；把 NDVI 与「常年同期正常值」比较，低于阈值的位置就是**长势异常区**，往往对应缺肥、缺水或病虫害。
**第四步，与精准农业的衔接**：NDVI 图直接可做**变量作业的处方图**——长势差的区域多追肥、长势好的少追，这正好回接了《精准农业装备》里「产量图到处方图」的数据链，只是这次的输入换成了遥感长势图。

## 3 卫星遥感与无人机遥感

农业遥感的两类平台各有取舍：

**卫星遥感（satellite remote sensing）**：搭载在轨道卫星上，覆盖范围大、可周期性重访，适合**大尺度、区域性**的农情普查。常见的有 Landsat、Sentinel-2（中分辨率，10–20 m）、以及我国的高分系列。<span class="marginnote">卫星的局限是<strong>分辨率与重访周期的权衡</strong>：中分辨率卫星能看大范围但看不清小田块（10 m 分辨率对 20 m 宽的田块就太粗）；高分辨率商业卫星贵且重访慢；云雨天气还会遮挡观测。</span>

**无人机遥感（UAV remote sensing）**：搭载多光谱相机的无人机低空飞行，分辨率可达**厘米级**，机动灵活、不受云层影响，适合**小地块、精细农情**的监测。<span class="marginnote">无人机遥感把「厘米级分辨率」带进了农业：可以清晰分辨单株作物的长势差异，甚至数清一棵果树上的果实。它的代价是覆盖面积小、作业需要飞手与电池——<strong>卫星管面、无人机管点</strong>，两者互补。</span>

**核心要点**：两类遥感平台的对比——

| 维度 | 卫星遥感 | 无人机遥感 |
| --- | --- | --- |
| 平台高度 | 数百公里 | 数十至数百米 |
| 空间分辨率 | 米级 | 厘米级 |
| 覆盖范围 | 大（整省/国） | 小（单田块） |
| 重访/作业频率 | 固定周期 | 随时 |
| 受云影响 | 大 | 无 |
| 成本 | 数据较便宜 | 设备+人工 |
| 典型用途 | 区域农情普查 | 田块精细诊断 |

## 4 遥感在农业中的典型应用

**作物长势监测**：NDVI/LAI（叶面积指数）时序分析，判断作物生育进程与长势好坏。
**病虫害监测**：病虫害改变叶片光谱，异常光谱区定位受害范围，指导**定点喷药**。
**土壤调查**：土壤反射光谱反演有机质、盐分含量，绘制土壤属性图。
**产量估测**：抽穗灌浆期光谱与最终产量统计相关，建立估产模型，服务粮食安全宏观决策。
**旱情监测**：热红外遥感反演地表温度与蒸散，识别缺水区域。

**辨析｜易错点：**遥感反演的不是「实测值」，而是「**从光谱推断的估算值**」。NDVI 与产量、叶绿素的关系是统计相关，会受品种、生育期、土壤背景、大气影响——**遥感产品必须用地面实测点校验（定标）后才可信**。遥感图是「面上的线索」，地面抽样是「点上的真相」，两者要结合，不能只信一张图。

## 5 遥感的时序分析：看长势「变化」

单张遥感影像只能告诉你「此刻长势如何」，而农业最关心的是「长势在怎么变」——这就需要**时间序列分析**：同一块田在多个时间点拍多期影像，看 NDVI 随时间的变化曲线。

**生育期曲线的形态**：作物的 NDVI 随生育期呈「低—高—低」的钟形曲线——苗期低、旺盛生长期达峰、成熟期回落。<span class="marginnote">把田块的 NDVI 时序曲线与「常年标准曲线」对照：<strong>曲线偏低</strong>说明长势落后（缺肥缺水）、<strong>峰值提前</strong>说明早衰、<strong>曲线整体右移</strong>说明发育延迟。曲线形态的偏差，就是农情的「诊断书」。</span>

**长势异常的定位**：把「当前 NDVI 与常年同期之差」做成差值图，负值集中的区域就是**长势异常区**，据此可以：指导**变量追肥**（异常区多施）、定点**病虫害调查**（异常往往是病虫先兆）、估产（成熟期 NDVI 与产量统计相关）。

**遥感与地面传感的互补**：遥感给「面」，地面给「点」——遥感发现异常区，人带着地面仪器去异常区实测，验证异常原因。<span class="marginnote">「<strong>遥感初筛 + 地面确诊</strong>」是农情监测的标准流程：遥感图便宜快速但只是线索，地面实测准确但费时——两者结合，用最少的实地工作锁定最值得去的地方，这是多源数据融合的经典范例。</span>

**辨析｜易错点：**「NDVI 曲线就是长势」是简化。NDVI 反映的是**植被覆盖与绿度**，不是直接的生物量或产量——同一 NDVI 可能对应不同的叶面积或叶绿素状况；且饱和问题（植被很茂密后 NDVI 不再上升）会掩盖差异。**时序分析要多指数交叉验证（NDVI + EVI + 叶绿素指数），并结合气象与农事记录综合判断**。

**核心要点**：遥感时序分析的应用链条——

| 步骤 | 操作 | 产出 |
| --- | --- | --- |
| 多期影像 | 按旬/月获取 NDVI | 时序曲线 |
| 对比诊断 | 与常年曲线对照 | 长势诊断 |
| 差值定位 | NDVI 差值图 | 异常区分布 |
| 验证处置 | 地面实测 + 农事干预 | 精准农事决策 |

**一组 NDVI 判读参考值**：裸土 0.1–0.2，出苗初期 0.15–0.3，分蘖盛期 0.5–0.7，抽穗灌浆期峰值 0.7–0.85，成熟期回落至 0.4–0.6，水体与建筑近 0 或负值。把这些数值与「常年同期曲线」对照，差值超过 ±0.15 就要实地调查原因——偏低多为缺肥缺水，偏高常是旺长或病害初期的异常表现。

这些阈值本身不是放之四海皆准，但展示了遥感判读的方法：**先有参考基线，再看偏差幅度，最后实地验证**。农业遥感从「看图」到「用图」，中间隔着「标定 + 阈值 + 验证」三步——这正是《农业大数据》里「数据到决策留一块校验缓冲」在遥感环节的具体化。

**延伸衔接**：遥感在智慧农业数据链中的角色——

- 遥感长势图直接生成《精准农业装备》的变量作业处方图。
- 遥感时序数据汇入《农业大数据》，用于估产与农情分析。
- 无人机遥感与《农业机器人》共享低空感知与图像识别技术。
- 遥感的定标-验证方法，与《农业传感与物联网》里传感器校验同源。

遥感还有一个独特的价值在于**时空连续**：同一颗卫星按固定周期重访同一块田，形成长达数年的长势档案——这是地面观测难以企及的「农田历史记忆」，也是《农业大数据》里估产与灾害回溯分析不可缺少的数据源。**一次观测是一张照片，连续观测才是一部农田纪录片**，而后者才是农业管理真正需要的。

正因如此，遥感在农业中的地位可以概括为一句话：**它是农业「看得见、看得全、看得久」的眼睛**——看得见肉眼难辨的光谱差异，看得全整片农田，看得久整个生长季。

## 6 小结

- **遥感**的原理是「地物反射光谱 → 传感器 → 反演参数」，不同地物有自己的光谱特征。
- 健康植被「红吸收、近红外反射」，这是所有植被遥感指标的基础。
- **NDVI = (NIR − Red)/(NIR + Red)**，比值式设计天生抗光照干扰，是长势监测的标配。
- **卫星**管大尺度普查（米级分辨率），**无人机**管田块精细诊断（厘米级）。
- 遥感应用覆盖**长势、病虫害、土壤、估产、旱情**五类场景。
- 遥感产品是估算值，必须**地面实测校验**后才可用于决策。
