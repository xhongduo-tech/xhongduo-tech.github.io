## 为什么从加权残值法开始

上一篇我们看到了变分原理的威力：把偏微分方程变成「找泛函驻点」。但变分原理并非万能的——遇到非保守系统、不可变分的算子，或者更一般的物理问题（如热传导、流体、对流-扩散），「最小势能」这套语言就派不上用场了。**加权残值法（method of weighted residuals）** 提供了一个更通用、更机械的框架：不用找泛函，直接让近似解的「残差」在某种加权意义下为零。Galerkin 方法是其中最著名的一个特例，也是有限元公式的直接源头。如果说变分原理是「从物理直觉出发」，加权残值法就是「从代数构造出发」——后者更笨，却更普适。

## 1 残差：近似解不满足方程的「误差」

设微分方程写作 $Lu = f$（$L$ 是微分算子），我们用一个近似解

$$
\tilde{u} = \sum_{j=1}^{n} a_j \varphi_j(x)
$$

去逼近真解 $u$，其中 $\varphi_j$ 是选定的**基函数（basis / trial functions）**，$a_j$ 是待定系数。<span class="marginnote">基函数的选择是整个方法的灵魂：它决定了近似解空间的维数与质量。有限元里 $\varphi_j$ 取「分片多项式」（只在少数相邻单元内非零），这是 Galerkin 方法能走向工程的关键一步。</span>

把 $\tilde{u}$ 代回方程，一般不会严格满足，剩下的偏差称为**残差（residual）**：

$$
R(x) = L\tilde{u} - f \neq 0
$$

残差是「近似解与真解之间的失配量」，它处处为零当且仅当 $\tilde{u}$ 是精确解。我们无法让 $R$ 处处为零（那是精确解），只能退而求其次：**让残差在某些加权意义下「总体上」为零**。

## 2 加权残值法的通用框架

**加权残值法**：选一组**权函数（weighting functions）** $w_i(x)$（$i = 1, \dots, n$），要求残差与每个权函数的内积为零：

$$
\int_{\Omega} w_i \, R \, d\Omega = 0, \qquad i = 1, 2, \dots, n
$$

这给出 $n$ 个代数方程，正好解出 $n$ 个待定系数 $a_j$。权函数的不同选取，产生不同的方法——这是一棵方法树的公共树干：

| 方法 | 权函数 $w_i$ 的取法 | 特点 |
| --- | --- | --- |
| **配点法（collocation）** | $w_i = \delta(x - x_i)$，Dirac 函数 | 强制残差在 $n$ 个点上为零，实现最简单 |
| **子域法（subdomain）** | $w_i$ 在第 $i$ 个子域内为 1，其余为 0 | 残差在子域上的平均为零 |
| **最小二乘法（least squares）** | $w_i = \partial R / \partial a_i$ | 使 $\int R^2 d\Omega$ 最小，自伴算子下等效于变分 |
| **Galerkin 法** | $w_i = \varphi_i$，权函数取基函数本身 | 对称性最好，有限元的标准选择 |

**辨析｜易错点：** 配点法的 $\delta(x-x_i)$ 看似简单，但会丢失弱形式的「加权平均」性质，稳定性与精度都脆弱；而 Galerkin 法在自伴正定算子下自动退化为最小势能原理，刚度矩阵对称正定，数值行为最好——这正是有限元选择它的深层原因。<span class="marginnote">「Galerkin = 权函数等于基函数」听起来像一句废话，但它带来的自伴性/对称性却是计算成本与稳定性的分水岭。非对称问题（如对流）里有限元会退回到「Petrov-Galerkin」——权函数与基函数分家，那是后话。</span>

## 3 Galerkin 方法：有限元的直接来源

取 $w_i = \varphi_i$，Galerkin 方程写作：

$$
\int_{\Omega} \varphi_i \left( L\tilde{u} - f \right) d\Omega = 0
$$

把 $\tilde{u} = \sum_j a_j \varphi_j$ 代入，得到关于 $a_j$ 的线性代数方程组。以一维杆件 $-(EA u')' = q$ 为例，对左端做分部积分（利用 $\varphi_i$ 在边界为零）：

$$
\int_0^L EA\, \varphi_i' \left( \sum_j a_j \varphi_j' \right) dx = \int_0^L q\, \varphi_i \, dx
$$

写成矩阵形式就是**刚度方程**：

$$
\boldsymbol{K} \boldsymbol{a} = \boldsymbol{F}, \qquad K_{ij} = \int_0^L EA\, \varphi_i' \varphi_j' \, dx, \qquad F_i = \int_0^L q \varphi_i \, dx
$$

这一步极其关键：**Galerkin 方法通过一次分部积分，把「对二阶导的要求」转嫁给了试探函数，只留一阶导**——这正是弱形式的光滑性红利，也是有限元只需要 $C^0$ 连续分片多项式的原因。<span class="marginnote">对比上一篇最小势能：线弹性自伴正定问题里，Galerkin 方程与最小势能的离散形式完全重合。两条路殊途同归，但 Galerkin 不需要存在泛函——这也是为什么流体、传热问题也用同一套有限元技术。</span>

## 4 公式解析：一维两点边值问题的 Galerkin 离散

设问题为

$$
-u'' + u = x, \qquad 0 \lt  x \lt  1, \qquad u(0) = 0, \ u(1) = 0
$$

取基函数 $\varphi_j = \sin(j\pi x)$（满足边界条件），近似解 $\tilde{u} = \sum_{j=1}^n a_j \sin(j\pi x)$。

**三步拆解**：

- **第一步，代残差**：$R = -\tilde{u}'' + \tilde{u} - x = \sum_j a_j (j^2\pi^2 + 1)\sin(j\pi x) - x$。注意特征函数天然满足 $-\varphi_j'' = j^2\pi^2 \varphi_j$。
- **第二步，Galerkin 加权**：对每个 $i$，$\int_0^1 \sin(i\pi x)\, R \, dx = 0$。由正弦函数的正交性 $\int_0^1 \sin(i\pi x)\sin(j\pi x)dx = \delta_{ij}/2$，左侧只剩 $a_i$ 项。
- **第三步，解出系数**：$a_i = \frac{2\int_0^1 x\sin(i\pi x)dx}{i^2\pi^2 + 1} = \frac{2(-1)^{i+1}/(i\pi)}{i^2\pi^2 + 1}$。

$n$ 增大时，$\tilde{u}$ 以谱精度逼近真解——Galerkin 方法在这里表现出「系数解耦」的美好性质。真实有限元没有这种正交好运气，于是 $\boldsymbol{K}$ 不再对角，但整体思路完全一致：**选基函数 → 组装方程 → 解线性系统**。

## 5 方法选型与术语速查

**一个完整的例子**：用配点法与 Galerkin 法分别求解 $u'' + u = 1$（$u(0) = u(1) = 0$），取 $n = 2$、基函数 $\sin(\pi x), \sin(2\pi x)$。配点法在 $x = 1/4, 1/2$ 两点配零，得到的系数与 Galerkin 法的结果略有不同——两者都是近似解，但 Galerkin 在能量意义下最优，整体误差更小。这个例子直观展示「权函数的选择决定误差的分配方式」。

**最小二乘法的独特性**：最小二乘法 $w_i = \partial R / \partial a_i$ 其实来自「让 $\int R^2 d\Omega$ 最小」这个显式目标——它是四种方法里唯一自带「误差最小化」定义的方法。但它对残差的平方做优化，奇异点附近权重过大，工程中使用频率远低于 Galerkin 法。

**术语速查**：

| 术语 | 含义 | 对应有限元概念 |
| --- | --- | --- |
| 残差 $R$ | 近似解代回方程后的偏差 | 节点失衡力 |
| 基函数 $\varphi_j$ | 近似解的展开基底 | 形函数 $N_i$ |
| 权函数 $w_i$ | 残差的加权函数 | 测试函数 |
| Galerkin | $w_i = \varphi_i$ | 标准有限元 |
| 试函数空间 | 基函数张成的函数空间 | 单元多项式空间 |
| Petrov-Galerkin | $w_i \ne \varphi_i$ | 对流问题的稳定化 |

- 配点法的 $\delta$ 权函数实现最省：只求 $R$ 在若干点为零，编程几乎零成本，但误差分布不可控。
- 子域法在子域上求平均，介于配点与 Galerkin 之间，流体力学里与有限体积法有亲缘关系。
- 最小二乘法的残差平方目标让它对强非线性更鲁棒，但二阶导数可能带来额外光滑性要求。
- 有限元里「试函数与测试函数同空间」是 Bubnov-Galerkin 的默认设定，绝大多数商用软件即此。

## 6 小结

- **加权残值法**：让残差在权函数意义下加权为零，配点/子域/最小二乘/Galerkin 是四种主要取法。
- **Galerkin 方法**：权函数取基函数，在自伴正定问题中等价于最小势能原理，刚度矩阵对称。
- **分部积分是关键一步**：把导数阶数从试探函数转移到权函数，从而允许低阶连续的分片多项式逼近。
