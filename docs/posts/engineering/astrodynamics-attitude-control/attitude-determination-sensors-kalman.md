## 为什么从姿态确定开始

第 8 篇建好了姿态的数学（运动学 + 动力学），但有个现实问题悬而未决：**我怎么知道卫星现在朝哪看？** 姿态确定（attitude determination）回答的就是这个问题——用传感器测量 + 估计算法，把「方向」从噪声里拼出来。<span class="marginnote">姿态确定与第 3 篇的轨道确定是「同一思想、两个战场」：都靠「测量 + 模型 + 滤波」三者合璧。轨道确定用测轨数据反推位置，姿态确定用矢量测量反推方向——连数学工具（最小二乘、卡尔曼滤波）都是同源的。</span>从「从极限到大模型」的视角看，姿态确定是**贝叶斯估计与信号处理在工程里的教科书级应用**：陀螺给快速但不稳的预测，星敏感器给慢但精确的观测，卡尔曼滤波把两者融合成最优估计——这正是大模型时代「传感器融合」的最早原型之一。

## 1 姿态确定的原理：一个矢量不够，两个才够

核心思想极简：**已知某参考矢量在惯性系的方向（如太阳方向、某颗星的赤经赤纬），再测量它在本体系的方向，两者的差就包含姿态信息。** 但一个矢量只给两个独立约束（旋转有 3 个自由度），所以至少需要**两个不平行矢量**才能确定完整姿态。

$$\text{本体系测量} = A \times \text{惯性系参考}$$

解 $A$ 的经典算法是 **TRIAD**：用两个测量矢量构造正交基，直接解出姿态矩阵。更稳健的是 **QUEST**（四元数估计器）与 **Wahba 问题**的多种解法——Wahba 把「找 $A$ 使测量残差最小」写成最小二乘优化，是姿态确定理论的核心。<span class="marginnote">Wahba 问题（1965 年提出）至今仍是姿态确定的标准框架：把「多传感器测量 + 权重」统一成一个优化问题，四元数解法（QUEST、q-method）在航天器上跑了半个世纪。它是「最小二乘思想」在姿态领域的化身，与第 3 篇微分校正、第 6 篇轨道拟合同宗。</span>

**重点：姿态确定永远需要「参考信息」——太阳方向、地球方向、恒星位置、磁场方向。** 传感器越多、参考越准，姿态越可靠；单传感器只能给出部分信息，必须融合。

### TRIAD 的三步：把两个矢量变成姿态

TRIAD 是理解「矢量→姿态」的最短路径，共三步：

1. **取测量**：太阳方向在本体系测量 $\hat{\mathbf{s}}_b$，惯性系参考 $\hat{\mathbf{s}}_i$；再取磁场或星矢量的第二对 $\hat{\mathbf{m}}_b, \hat{\mathbf{m}}_i$。
2. **造正交基**：令 $\hat{\mathbf{r}}_1 = \hat{\mathbf{s}}$（第一个矢量），$\hat{\mathbf{r}}_2 = \hat{\mathbf{s}}\times\hat{\mathbf{m}}$（垂直第二分量），$\hat{\mathbf{r}}_3 = \hat{\mathbf{r}}_1 \times \hat{\mathbf{r}}_2$（补全右手系）。
3. **解姿态**：惯性系基阵 $R_i$ 与本体系基阵 $R_b$ 满足 $R_b = A R_i$，于是 $A = R_b R_i^T$。

**重点：TRIAD 把「姿态解算」降维成「两次叉积 + 一次转置」——这就是它便宜而经典的根源。** 但注意它只用了两个矢量、丢了第三个方向的权重信息；矢量更多时要用 QUEST 等优化解法，精度更高。

## 2 传感器家族：各有所长，各有短板

姿态确定的核心传感器各怀绝技，一张表看清取舍：

| 传感器 | 原理 | 精度 | 特点 |
| --- | --- | --- | --- |
| 太阳敏感器 | 太阳方位 | 角分–角秒级 | 便宜、可靠，但地影内失效 |
| 地球敏感器（红外） | 地球边缘红外 | 角分级 | 对地指向常用，依赖地平清晰度 |
| 磁强计 | 地磁场矢量 | 1–5° | 便宜、全天候，但精度低 |
| 星敏感器 | 恒星模式匹配 | 角秒级（0.1″–10″） | 最准，但贵、需黑暗避光 |
| 陀螺仪 | 角速度 | 漂移小则准 | 高频但不给绝对姿态，需标定 |

<span class="marginnote">「精度阶梯」是选型主线：磁强计给度级、太阳/地球敏感器给角分级、星敏感器给角秒级——成本与功耗也按同一阶梯上升。一颗高精度对地观测卫星常配「星敏感器（主）+ 太阳敏感器 + 磁强计 + 陀螺」的组合，冗余互补。</span>

**重点：没有任何单传感器「完美」——姿态确定是组合的艺术。** 星敏感器最准但怕太阳，陀螺最连续但会漂移，磁强计全天候但粗糙；把它们放在一起、用滤波融合，才得到「又准又稳」的姿态。

**补充｜校准与对齐：** 传感器精度的上限往往不是器件本身，而是**安装对齐误差**与**标定残差**——星敏感器的光轴与卫星本体系轴若偏差 1 角分，即使器件精度 1 角秒也没用。工程上用地面标定与在轨自标定（转动对比）把对齐误差压下去，这是姿态确定工程实践中最「琐碎却致命」的一环。

## 3 陀螺与姿态传播：快但会漂

**陀螺仪（gyroscope）**测量本体角速度，配合第 8 篇的四元数运动学方程，可以在测量间隙**外推（propagate）**姿态：

$$\dot{\mathbf{q}} = \frac{1}{2}\,\mathbf{q}\otimes\boldsymbol{\omega}_{\mathrm{meas}}$$

陀螺的「快」无可替代：以数百 Hz 更新姿态，支撑实时控制。但它的「快」用漂移换——**陀螺零偏（bias）**会随温度、时间缓慢变化，积分久了姿态「飘」掉。<span class="marginnote">这就是为什么姿态估计必须「陀螺积分 + 绝对测量校正」双轨并行：星敏感器每隔几秒给一次绝对姿态，滤波器用它来「拉回」陀螺的漂移。陀螺提供高频连续性，星敏感器提供低频准确性——一对完美的互补。</span>

**辨析｜易错点：** 陀螺测量的是**角速度**，不是姿态。把角速度当姿态直接使用是常见误区——必须积分（运动学方程）才能得到姿态，而积分必然引入漂移。所以陀螺的定位永远是「高频外推器」，不是「姿态来源」。

## 4 卡尔曼滤波：姿态确定的引擎

把「快但漂的预测」与「慢但准的测量」融合起来的标准工具是**卡尔曼滤波（Kalman filter）**。它在姿态确定的两种形态：

- **预测（时间更新）**：用陀螺角速度 + 四元数运动学，把姿态状态 $x$ 往前推一步，同时放大协方差 $P$（不确定性增加）。
- **校正（测量更新）**：星敏感器/太阳敏感器给出测量 $z$，用增益 $K$ 加权融合，把状态拉向测量、缩小协方差。

$$x_{k} = x_{k-1} + K_k\,(z_k - h(x_{k-1}))$$

其中 $K_k$ 是卡尔曼增益——它根据「预测不确定性」与「测量噪声」的比值自动决定信谁。<span class="marginnote">卡尔曼滤波的哲学是「两条信息源的最优加权」：预测越不确定、测量越可信，越偏向测量；反之偏向预测。它把『噪声里的测量』变成『可靠的估计』，是第 3 篇轨道确定、本篇姿态确定、乃至自动驾驶/GNSS 融合（大模型时代的智能体感知）共同的理论底座。</span>

## 5 公式解析：互补滤波——卡尔曼的小兄弟

在星上算力有限、只需中低精度时，**互补滤波（complementary filter）**用极简公式达到「陀螺高频 + 绝对测量低频」的融合：

$$\hat{\mathbf{q}} = \text{归一化}\big(\alpha\,\mathbf{q}_{\mathrm{gyro}} \oplus (1-\alpha)\,\mathbf{q}_{\mathrm{meas}}\big)$$

三步拆解：

- **第一步，认权重**：$\alpha$ 接近 1 时偏向陀螺（平滑但会漂），接近 0 时偏向测量（准但噪声大）。
- **第二步，看互补**：陀螺信息**高速滤波**（平滑短时波动），绝对测量**低速滤波**（抑制长时漂移）——两者在频域互补，故得名。
- **第三步，工程取舍**：互补滤波便宜、轻量、无矩阵求逆，是入门卫星与姿控仿真的首选；高精度任务再升级到完整的卡尔曼（含陀螺零偏估计）。

**辨析｜易错点：** 互补滤波不是卡尔曼的「近似」，而是「简化」——它假设权重恒定，而卡尔曼让增益随协方差自适应。选哪个取决于「计算资源 + 精度需求」的权衡，不是「越复杂越好」。

## 6 从确定到控制：姿态估计闭环

姿态确定的输出（姿态估计 $\hat{\mathbf{q}}$、角速度估计 $\hat{\boldsymbol{\omega}}$）直接喂给姿态控制器（第 10 篇）。完整的**姿态估计-控制闭环**是：

1. 传感器原始测量 → 姿态确定算法（TRIAD/QUEST/滤波）→ $\hat{\mathbf{q}}$
2. 陀螺外推 + 测量校正 → 实时 $\hat{\mathbf{q}}, \hat{\boldsymbol{\omega}}$
3. 控制器把 $\hat{\mathbf{q}}$ 与目标姿态 $q_{\mathrm{ref}}$ 之差变成执行指令（反作用轮/推力器）

<span class="marginnote">这条闭环贯穿第 8–10 篇：运动学给模型、确定给状态、控制给动作。姿态确定的精度直接决定控制性能——星敏感器的角秒级误差意味着望远镜能以弧秒级指向，而磁强计只有度级则只能「大致对日」。任务要求与传感器精度是一一对应的。</span>

**重点：姿态确定是「估计算法 + 传感器配置」的系统工程。** 选星敏感器还是太阳敏感器、用卡尔曼还是互补滤波，取决于精度、成本、功耗与失效容忍——与第 6 篇的「轨道选型」同构：都是把需求翻译成选型。

## 7 小结

- **姿态确定 = 参考矢量 + 本体测量 + 估计算法**；至少两个不平行矢量才能确定完整姿态。
- TRIAD/QUEST 是经典静态解算，Wahba 问题把「找姿态使残差最小」统一为优化。
- 传感器按精度阶梯：磁强计（°）→ 太阳/地球（′）→ 星敏感器（″）；无单传感器完美，组合是艺术。
- **陀螺给高频但会漂**：测角速度、需积分、零偏随时间漂移——只当外推器。
- **卡尔曼滤波**融合「预测 + 测量」：$x_k = x_{k-1} + K_k(z_k - h(x_{k-1}))$，增益 $K_k$ 自适应决定信谁。
- **互补滤波**是轻量替代，高频陀螺 + 低频测量在频域互补；按资源与精度取舍。
- 姿态确定与轨道确定（第 3 篇）同源：测量 + 模型 + 滤波，一脉相承。
- 一句话记忆：**磁强计求全天候、星敏感器求精度、陀螺求连续、卡尔曼求融合**——四个各有缺点的工具合起来才可靠。
- 校准与对齐误差常是精度的真正瓶颈：器件精度再高，装歪了照样白搭。
- 卡尔曼与互补滤波的选择是「算力 + 精度」权衡，不是越复杂越好。
- TRIAD 是理解矢量→姿态的最短路径：两次叉积 + 一次转置，即得姿态矩阵。

在下一节，我们有了「知道朝哪看」的姿态确定，还缺「让它朝那看」的执行手段：**姿态控制执行机构**——反作用轮、磁力矩器与推力器，以及驱动它们的控制律。
