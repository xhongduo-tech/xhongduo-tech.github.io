## 为什么从结构开始

第三、四篇我们算出了「该选一台怎样的水轮机」，但水轮机要真正工作，还得把能量方程装进钢铁：蜗壳把水匀进转轮、导叶调节进水量、调速器决定导叶开多大。<span class="marginnote">这一篇把视角从「流体力学」切到「机械结构与自动控制」：前半讲水，后半讲「如何让水听话」。调速系统是水电站区别于火电的又一个显著特征——火电机组靠锅炉燃料量调负荷，水电机组靠导叶开度与水流惯性搏斗。</span>本篇走一遍水轮机的结构骨架，再重点讲导水机构与调速系统这一对「执行器—控制器」，为《水电站电气系统》里的频率与有功调节打底。

## 1 反击式水轮机的过流部件

一台反击式水轮机的过流通道，按水流方向依次是：**蜗壳 → 座环 → 导水机构 → 转轮 → 尾水管**。

**蜗壳（spiral case）**：把水流从压力管道均匀地送进转轮四周。水流沿圆周方向「边走边分」，蜗壳断面越收越窄，保证转轮各入口流量均匀。高水头用**金属蜗壳**（钢板卷焊或铸造），低水头用**钢筋混凝土蜗壳**——材料随压力水平走，是结构选材的第一条规则。

材料选择的规则可以量化：设计水头约 100 m 以下常用钢筋混凝土蜗壳，100 m 以上用金属蜗壳，钢板厚度随水头增加；座环与固定导叶用铸钢或焊接件。转轮材料分不锈钢与碳钢——高含沙河流（如黄河、大渡河）的转轮几乎必须用不锈钢，否则泥沙磨蚀一年内就能让效率明显下降，这正是《水轮发电机组安装与检修》里磨蚀检修频发的根源。

**座环（stay ring）**：固定于机坑内，是导叶与转轮的外支撑骨架，承受来自蜗壳的水压力与整个机组的静荷载，同时把水流过渡到导叶区。座环的上、下环之间的固定导叶既导流又承力。

**导水机构（distributor / guide apparatus）**：由一圈**活动导叶**组成，负责调节进入转轮的流量并形成环量（让水流带初始旋转进入）。导叶的开度变化直接改变出力，是水轮机的「油门」。

**转轮（runner）**：做功的核心部件，水流在此把动量矩交给叶片。混流式转轮由上冠、下环与中间扭曲的叶片构成，叶片数与材质随水头而变：高水头叶片厚而少，低水头叶片薄而多。<span class="marginnote">转轮是整座电站造价最高的单件之一：白鹤滩单只转轮重约 300 吨、由不锈钢铸焊成型。转轮的疲劳与空蚀检修，构成《水轮发电机组安装与检修》里最重的作业内容。</span>

**尾水管（draft tube）**：转轮出口的扩散段，回收出口动能并引导水流安全流入尾水渠。它的形状直接关系到整体效率的几个百分点，设计时用模型试验反复优化。

主轴、轴承与密封构成旋转系统的外围：**主轴**把转轮与发电机转子连成一体；**水导轴承**承受径向力；**推力轴承**承受约千吨级的水推力（白鹤滩机组推力负荷超 2000 吨）；**密封装置**分工作密封与检修密封，防止停机检修时尾水倒灌。

旋转系统有两处「重头戏」决定可靠性。**推力轴承**要托起整个旋转部分的重力与向上水推力，采用分块瓦（可倾瓦）润滑，瓦面比压可达数兆帕；瓦温、油温是运行监视的关键参数，瓦温异常往往是重大事故的前兆信号。**主轴密封**分两道：工作密封在运行时用橡胶或机械密封压住微小漏水，检修密封在停机检修时用围带或阀门把尾水彻底隔断——两道密封各守一个「时刻」，配合默契。

## 2 导水机构：水轮机的「油门」

导水机构由**活动导叶、控制环、连杆与接力器**组成。导叶本身是可以转动的翼型叶片，头部呈「流线+闸门」复合形状；每台机组有十几到二十几个导叶，均匀分布在转轮四周。<span class="marginnote">导叶全关时把流道堵死，是机组的「水闸」；导叶开度从 0 到全开的行程，对应水轮机从空载到满负荷的全部运行区间。</span>

**调节链路**：调速器发出信号 → 油压装置供高压油（常见工作油压 6.3 MPa）→ **接力器（servomotor）**活塞推动**控制环**转动 → 控制环通过连杆带动每个导叶同步转动 → 导叶开度变化、流量变化、出力变化。<span class="marginnote">这条链路里每一环都有行程与时间的约束：接力器行程几十厘米、导叶全关时间按设计可在几秒到十几秒之间整定。整定时间过短会诱发过大的水击（见第七篇），过长则机组转速飞升——调速整定本质上是在「水击压力」与「转速波动」之间走钢丝。</span>

导水机构还承担三个辅助角色：**机组启停**（开机时先开导叶至空载开度，并网后再加大）、**事故停机**（紧急关导叶并联动快速阀门）、**制动**（停机末段用导叶小开度让水流反向制动）。可以说，导水机构是水轮机最忙碌、也最考验可靠性的机械部分。

导叶开度与流量的关系近似线性但并非精确线性：开度小时流量受翼型绕流损失影响、增长偏缓，接近全开时流量趋于饱和。正因为流量—开度的非线性，数字调速器要在不同开度区间采用不同的增益（PID 参数分区整定）——这也是数字调速器相对机械调速器更容易调好的原因之一。

导叶在开启与关闭过程中承受的**水力矩**还会改变方向：开度较小时水力矩趋向于关闭导叶，开度较大时趋向于开启导叶。这个「反向点」是设计控制环与接力器推力、判断导叶能否自锁的关键——接力器推力必须覆盖全行程的水力矩变化，否则某一开度下导叶会失控摆动。

## 3 调速系统：让机组「听话」

调速系统的任务只有一个：**让机组转速稳定在额定值附近，并在负荷变化时迅速恢复**。发电机转速直接决定电网频率（$f = p n / 60$），所以水轮机的调速本质上是**电网频率控制**的一部分。

**调速器（governor）**的典型结构：**测速元件**（机械飞摆或数字测频）感知转速偏差 → 经**放大元件**（主配压阀）放大 → 驱动**执行元件**（接力器）动作 → 改变导叶开度。现代大型机组普遍用**数字式电液调速器**：单片机采集频率与功率，按 PID 规律算出开度指令，再经电液转换器驱动液压执行器。<span class="marginnote">调速器是水电站里最早数字化的控制设备之一：把 PID 控制规律写进软件，改参数只需改设定值，不必拆油管路——这也是自动化专业的第一次「电气化变身」，与《水电站电气系统》的励磁调节互为镜像。</span>

调速器还要按电网需要**分配负荷**。当系统频率下降（负荷增加）时，各机组通过调速器的**调差特性**自动多出力，这就是**一次调频**；调度中心再通过 AGC（自动发电控制）做**二次调频**，把频率精确拉回额定值。调速器上的**调差系数**设定，决定了这台机组在一次调频中分担多少。

调速器还分**单调节**与**双调节**：单调节只控制导叶（混流式、轴流定桨式适用）；双调节同时控制导叶与转轮叶片（轴流转桨式适用），叶片角度随开度联动，让机组在宽负荷范围保持高效率。抽水蓄能机组还有第三层——水泵工况的导叶联动，工况转换的协调逻辑极为复杂，我们留到《抽水蓄能电站》一篇展开。

调速器离不开**油压装置**：压油槽储高压油（常见工作油压 6.3 MPa 或更高），由油泵补压、蓄能器维持压力。整套油压装置必须保证在厂用电全失的最恶劣情况下，仍有足够压力完成一次完整的事故关机——这是水电站最硬的安全底线之一，也是《水电站电气系统》中厂用电设计的输入条件。

## 4 公式解析：调差系数与调速静特性

调速器的静态特性描述「频率偏差 ↔ 出力偏差」的对应关系，用**调差系数（speed droop）**刻画：

$$
e_p = \frac{\Delta P / P_n}{\Delta f / f_n}
$$

逐项拆解：

- **第一步，读懂分子**：$\Delta P / P_n$ 是出力相对偏差——机组多出力了百分之几。
- **第二步，读懂分母**：$\Delta f / f_n$ 是频率相对偏差——电网频率偏移了百分之几。
- **第三步，调差系数的含义**：$e_p$ 是静特性曲线的斜率（单位频率偏差对应的出力变化）。它越小，特性曲线越「平」，同样的频率偏差下机组出力变化越大——也就是**一次调频越积极**。<span class="marginnote">不能把 $e_p$ 设得无限小：如果所有机组都把调差系数设成 0，一次调频就没有「分工」，电网频率会振荡。工程上水电机组 $e_p$ 一般取 2%—6%，留出明确的功率-频率比例关系。</span>
- **第四步，工程直觉**：$e_p = 4\%$ 意味着「频率每偏 1%，机组主动调整 25% 的出力」；调度正是靠各机组的调差系数差异来安排一次调频的出力分担。

**一次调频的动力学背景**：机组转速的动态由转子运动方程支配，$J \frac{d\omega}{dt} = T_t - T_e$（$T_t$ 为水轮机转矩、$T_e$ 为发电机电磁转矩）。甩负荷时 $T_e$ 骤降、转速飞升，调速器必须抢在飞逸转速之前关小导叶——这就是为什么调速器响应速度、导叶关闭时间与转动惯量三者必须统一整定。

调速器的动态品质由几个整定参数决定：**比例系数 $K_p$、积分时间 $T_i$、微分时间 $T_d$**，加上**缓冲时间常数 $T_b$** 与调差系数 $e_p$。整定的目标是「快速但不振荡」：过度求快会让导叶来回摆动、流量波动诱发压力脉动；过度求稳则一次调频反应迟钝。工程上先按机组转动惯量与水流惯性做理论计算，再在试运行中用**甩负荷试验**实测修正——甩负荷试验是水电机组投入商业运行前必做的验收项目之一。

甩负荷试验的做法是：机组带额定负荷稳定运行，突然跳闸甩去全部负荷，记录转速最大飞升、导叶关闭过程与压力上升值，与设计预测对比。试验结果既是调速参数的验收依据，也是**水击计算的实测校验**——它把《水击与调压设施》的理论与现场数据对上了，是理论—试验闭环的典型范例。

## 5 冲击式水轮机的结构与调节

冲击式机组的结构与反击式差异明显：没有蜗壳与座环，代之以**喷嘴、喷针与折向器**。压力钢管的水直接进喷嘴，喷针进退调节射流直径，从而调节流量与出力。<span class="marginnote">冲击式也有「油门」，但它的调节器官在喷嘴而不是导叶——一台多喷嘴水斗机（如双喷嘴、四喷嘴）通过启停不同喷嘴组来分级调节，细调靠喷针微动。</span>

**折向器（deflector）**是冲击式特有的安全装置：紧急事故时，折向器快速插入射流、把水流偏转离开斗叶，即使喷针来不及关闭也能瞬间卸掉大部分水头，防止机组飞逸。折向器响应速度毫秒级，正是高水头机组「以快制快」的保险。<span class="marginnote">对比一下两类机组的停机：反击式靠关导叶、憋住流道；冲击式靠折向器「把水拨开」。高水头水流惯性更大，冲击式用物理上更快的办法处理甩负荷——这个差别在《水击与调压设施》一篇会再次出现。</span>

冲击式机组还讲究**主轴布置**：小型水斗机多为卧轴、主轴水平，喷针与折向器装在侧面；大型水斗机多为竖轴，喷嘴沿转轮圆周分布。水斗转轮由轮盘与一圈斗叶整体铸成，材质为高强度不锈钢——因为斗叶长期承受高速水滴的冲刷磨损，这是冲击式最常见的检修部位。

把两类机组的结构差异收成一张表：

| 部件/功能 | 反击式 | 冲击式 |
| --- | --- | --- |
| 来水引导 | 蜗壳 + 座环 | 压力钢管直进喷嘴 |
| 调节器官 | 活动导叶 | 喷针（+ 折向器） |
| 做功部件 | 叶片转轮 | 水斗转轮 |
| 出流方式 | 尾水管 | 自由落入尾水渠 |
| 停机保险 | 关导叶憋水 | 折向器把水拨开 |
| 空蚀风险 | 高（需吸出高度校核） | 几乎无 |

这张表也是《水轮机原理》《水轮机结构与调速系统》两篇的「合订索引」：原理讲做功方式，结构讲实现方式，两者一一对应。

## 6 小结

- 反击式过流路径「蜗壳—座环—导水机构—转轮—尾水管」各司其职，材料随压力水平选金属或混凝土。
- 导水机构是水轮机的「油门」：接力器—控制环—连杆带动导叶同步转动，兼管启停、事故停机与制动。
- 调速系统由测速、放大、执行三元件构成，现代大型机组用数字式电液调速器，承担电网的一次调频任务。
- 调差系数 $e_p = (\Delta P/P_n)/(\Delta f/f_n)$ 决定一次调频的积极程度，水电机组一般取 2%—6%。
- 冲击式机组用喷嘴—喷针调节、折向器紧急卸荷，两类机组的「油门」与保险机制截然不同。
- 反击式与冲击式在「来水引导、调节器官、出流、停机保险」上的差异可一一对照，原理与结构互相印证。
- 导叶水力矩存在「反向点」，接力器推力必须覆盖全行程，否则导叶会失控摆动；油压装置须保证厂用电全失时仍能完成一次完整的事故关机。
- 调速器 PID 参数、缓冲时间与调差系数靠甩负荷试验整定验收，「快速但不振荡」是永恒目标。
- 过流部件选材随水头与含沙量走：低水头混凝土蜗壳、高水头金属蜗壳；高含沙河流转轮必须用不锈钢抗磨蚀。
- 一次调频靠调速器调差特性自动响应，二次调频靠 AGC 由调度中心集中指挥，两者在《水电站运行与调度》走向联合调度。

在下一节，我们将离开水轮机本身，顺着水流往上走到电站的入口——看进水口与引水道如何把水库的水安全、高效地送到厂房门口。这就是**水电站进水口与引水道**。调速器刚教会机组「听话」，现在该让水在送进机组的路上也不出差错。
