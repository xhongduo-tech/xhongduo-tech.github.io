## 为什么从化学动力学开始

上一篇的热化学回答了「烧得起来吗、能烧多热」；而火焰能不能传播、火焰有多快、可燃极限在哪里、污染物生成多少，全都取决于**速率**——这正是化学动力学的领地。热力学看的是起点与终点，动力学看的是**路线与速度**。一支蜡烛燃烧，热力学上不过是蜡与氧的放热反应；但在微观上，火焰内部每秒发生数以亿计的基元反应，其中绝大多数都围绕一个叫**自由基**的中间体做接力。<span class="marginnote">自由基是带不成对电子的原子或碎片，化学活性极高，寿命极短。燃烧的许多秘密，都藏在自由基「产生—传播—终止」的循环里。</span>理解了动力学，上一篇算出的绝热火焰温度才不是一具静态的骨架，而是一台有血有肉的引擎。

## 1 从热力学到动力学：两个不同的问题

热力学可以判定一个反应在给定条件下**是否可能**，却不能告诉我们**要多快**。氢氧混合气在室温下热力学上极度渴望反应，却能安静地存放数年——直到一粒火星引爆它。这个「能但缓」的落差，就是动力学研究的内容。反过来说，动力学也提醒我们：一个在热力学上「不该自发」的反应，只要中途有一条低活化能的旁路，照样可能以可观速率进行——**热力学可行是必要不充分条件，这条路才是充分条件**。

反应速率最朴素的形式是**幂律**：对基元反应 $\ce{A + B -> 产物}$，速率正比于反应物浓度的乘积：

$$r = k\,[A]\,[B]$$

比例系数 $k$ 叫**速率常数（rate constant）**，它随温度剧烈变化，由阿伦尼乌斯定律描述。浓度项里各指数的和叫**反应级数**，对基元反应，级数就是参与分子数；对总包反应，级数只是拟合数据得到的表观量。

**辨析｜易错点：** 幂律速率不能随便写。对一个复杂的整体反应，直接写「速率 = k[燃料][氧]」往往只是经验近似；只有**基元反应**的级数才严格等于化学计量系数。两者混用是动力学入门最常见的错误。

## 2 基元反应与总包反应

**基元反应（elementary reaction）**：在分子层面上一次性完成的、不可再拆分的反应步骤，如 $\ce{H + O2 -> OH + O}$。它的速率常数可以独立测量，反应级数等于参与反应的分子数。

**总包反应（global / overall reaction）**：把一连串基元反应压缩成一个总方程式，如上一篇的 $\ce{CH4 + 2O2 -> CO2 + 2H2O}$。总包反应便于工程计算，但它**不描述真实路径**。<span class="marginnote">甲烷分子不可能一步与两个氧分子撞成二氧化碳和水——那需要同时打破六个键。真实路径是通过几十个自由基中间体逐级拆解的。</span>把总包反应当真实机理来理解，就会在解释火焰化学时处处碰壁。

甲烷在空气中燃烧的真实机理，如今有公开的高保真版本——**GRI-Mech 3.0**，包含 53 种组分、325 个基元反应。工程计算常常把它进一步压缩成几步的总包链，代价是牺牲对氮氧化物等微量产物的预测精度。

一个经典的工程折中是**两步总包机理**：先 $\ce{CH4 + 3/2 O2 -> CO + 2H2O}$，再 $\ce{CO + 1/2 O2 -> CO2}$。两步都带自己的 Arrhenius 参数，用于预估火焰传播速度相当不错，但**无法预测 NO 与碳烟**——因为那些微量物种依赖几十个竞争性基元反应，压缩到两步后信息全部丢失。选机理的粗与细，本质是在「计算成本」与「需要预报的对象」之间做取舍。<span class="marginnote">判断一个机理够不够用，先问一句：你要算的是火焰速度（粗机理够），还是 NOx 排放（必须上详细机理）？这个问题在第十篇污染物生成与控制中还会反复出现。</span>

## 3 链式反应：燃烧的接力赛

燃烧之所以能「一点就着、一着就旺」，靠的是**链式反应（chain reaction）**。链式反应的四个环节构成一个自我维持的循环：

**链引发（initiation）**：由稳定分子生成自由基。如高温下 $\ce{H2 + M -> H + H + M}$，$M$ 是碰撞第三者。
**链传播（propagation）**：一个自由基反应生成另一个自由基，数目不变。如 $\ce{OH + H2 -> H2O + H}$。
**链支化（branching）**：一个自由基变成两个，数目增加——这是火焰能加速的根源。如 $\ce{H + O2 -> OH + O}$。
**链终止（termination）**：自由基被复合或吸附消灭。如 $\ce{H + H + M -> H2 + M}$。

氢-氧体系是最干净的范例，它撑起了几乎所有碳氢燃料燃烧机理的核心骨架：

$$\ce{H + O2 -> OH + O} \quad (\text{支化})$$

$$\ce{O + H2 -> OH + H} \quad (\text{传播})$$

$$\ce{OH + H2 -> H2O + H} \quad (\text{传播})$$

三个反应连起来看：一个 H 原子进去，产生两个 H 原子出来——**自由基数翻倍，反应自我加速**。这就是为什么氢氧混合物一旦着火，可以在毫秒内完成爆炸。

把四个环节放到一起对照，各自的角色一目了然：

| 环节 | 自由基数目变化 | 典型反应（氢氧体系） | 对反应的影响 |
| --- | --- | --- | --- |
| 链引发 | 0 → 1（或 2） | $\ce{H2 + M -> 2H + M}$ | 点火所需的「第一颗火星」 |
| 链传播 | 1 → 1 | $\ce{O + H2 -> OH + H}$ | 维持反应，数目不变 |
| 链支化 | 1 → 2 | $\ce{H + O2 -> OH + O}$ | 使反应加速、可致爆炸 |
| 链终止 | n → 0 | $\ce{H + H + M -> H2 + M}$ | 使反应减速、抑制爆炸 |

这张表值得背下来：**任何燃烧机理的定性行为，都能还原成「支化对终止」的赛局。** 判断一个混合物是温和燃烧还是猛烈爆轰，先问它的链支化反应活化能高不高、三体终止反应占不占优。<span class="marginnote">链支化与链终止的竞赛，决定了反应是「温和进行」还是「爆轰性进行」。当支化速率压倒终止速率，自由基雪崩式增殖，反应急剧加速。</span>

## 4 公式解析：阿伦尼乌斯定律

温度如何操控反应速率，由**阿伦尼乌斯定律（Arrhenius law）**给出：

$$k = A\, e^{-E_a / (RT)}$$

三步拆解：

- **第一步，看指数项**：$E_a$ 是**活化能（activation energy）**，即反应物要越过能量势垒所需的最低能量；$R$ 是气体常数，$T$ 是绝对温度。$e^{-E_a/(RT)}$ 度量「分子群体中能量够格的份额」。
- **第二步，看指前因子 $A$**：它代表碰撞频率与取向因子的贡献，量纲与 $k$ 相同。对双分子基元反应，$A$ 量级常在 $10^{10}$–$10^{13}\ \mathrm{cm^3/(mol\cdot s)}$ 附近。
- **第三步，感受指数敏感性**：$E_a \approx 70\ \mathrm{kJ/mol}$（氢氧支化反应的典型值）时，温度从 500 K 升到 600 K，$k$ 约放大 $e^{70{,}000/(8.314)}(1/500-1/600) \approx e^{4.6} \approx 100$ 倍。**这就是「火焰温度只差几十 K，燃烧速度却天差地别」的数学根源。**

把两支不同温度下的速率常数相除，可以得到实用的估算式：

$$\ln\frac{k_2}{k_1} = -\frac{E_a}{R}\left(\frac{1}{T_2} - \frac{1}{T_1}\right)$$

用它只需知道 $E_a$ 与一组参考值，就能估算另一温度下的速率——这是工程上做敏感性分析时最常用的快捷工具。

**例：估算「十倍速升温」。** 设支化反应的 $E_a = 70\ \mathrm{kJ/mol}$，$T_1 = 1000\ \mathrm{K}$，问温度升到多少，速率常数 $k$ 恰好翻倍？令 $k_2/k_1 = 2$，代入

$$\ln 2 = -\frac{70{,}000}{8.314}\left(\frac{1}{T_2} - \frac{1}{1000}\right)$$

解得 $T_2 \approx 1010\ \mathrm{K}$。也就是说，在火焰温度附近，**温度每升高约 10 K，这个关键支化反应的速率就翻一倍**。这解释了为什么贫燃极限、熄火距离这些宏观现象，对温度都极度敏感——火焰的「存在与否」往往就悬在几十 K 的余量上。<span class="marginnote">「温度翻倍速率翻倍」是相对规则：低温区需要大温升才能翻倍，高温区只需小温升。活化能越高，速率对温度越敏感——这正是爆震、点火延时等高温问题都要盯住高活化能反应的原因。</span>

## 5 甲烷氧化：从机理到火焰

碳氢燃料的氧化比氢氧体系复杂得多，但骨架仍然清晰。以甲烷为例，真实的氧化路径大致是：

**热解与脱氢**：高温下 $\ce{CH4}$ 先被剥离氢，生成 $\ce{CH3}$、$\ce{CH2}$、$\ce{CH}$ 等碎片；
**核心氧化链**：碎片与氧结合，进入 $\ce{H2/O2}$ 那套支化链，H、O、OH 自由基在此大量增殖；
**深度氧化**：一氧化碳经 $\ce{CO + OH -> CO2 + H}$ 烧成二氧化碳——这一步在总包反应里是一步，在机理里是决定 CO 排放的关键。

**辨析｜易错点：** 许多人以为「火焰里最活跃的是氧分子」，其实火焰高温区的核心自由基是 H、O、OH。氧气分子本身相当惰性，真正负责「撕开」燃料与传播反应的，是这些浓度虽低却极活跃的中间体。<span class="marginnote">OH 自由基的浓度即使在火焰锋面也只有千分之一到万分之一量级，却控制着整个放热速率——用激光诱导荧光（LIF）拍到的火焰照片，很大程度上就是在给 OH 的分布画像，这将在第十二篇燃烧诊断技术中展开。</span>

**支化与爆炸界限**：氢氧混合气存在著名的**爆炸界限（explosion limit）**——在某个温度-压力区间，混合物要么平静反应，要么猛烈爆炸。界限的物理本质就是链支化速率与链终止速率的相对大小：低压下自由基扩散到器壁被消灭，高压下三体复合 $\ce{H + O2 + M -> HO2 + M}$ 成为主导，中间压力区间支化占优，于是出现「爆炸半岛」。<span class="marginnote">同一道理解释了内燃机里的爆震：末端气体在火焰到达前被压缩升温，支化反应加速到临界值，未燃混合气突然自燃。控制爆震，本质上就是控制链支化的条件。</span>

## 6 小结

- **动力学与热力学的分工**：热力学说「能否与多少」，动力学说「多快与哪条路」。
- **基元反应 vs 总包反应**：只有基元反应的级数等于化学计量系数；总包反应是工程简化，不反映真实路径。
- **链式反应四环节**：引发、传播、支化、终止；支化使自由基雪崩，终止压制它。
- **氢氧支化链**：$\ce{H + O2 -> OH + O}$ 是碳氢燃料火焰的共同发动机。
- **Arrhenius 定律**：$k = Ae^{-E_a/(RT)}$，指数敏感性使火焰温度对燃烧速率具有支配性影响。
- **爆炸界限**：支化与终止的竞争，也是内燃机爆震的物理根源。
- **机理的粗与细**：从两步总包到 GRI-Mech 3.0（53 组分 325 步），按预报对象选择，火焰速度可用粗机理，NOx 必须上细机理。
- **量级直觉**：常温气体双分子基元反应的速率常数 $k$ 量级约 $10^{10}$–$10^{13}$ cm³/(mol·s)，活化能越高速率对温度越敏感——这正是火焰对几十 K 温度变化极其敏感的原因。
- **连接主线**：链式机理是第二篇热化学与第三篇传质之间的桥梁——着火极限、火焰传播与污染物生成，最终都由同一套基元反应的「支化对终止」赛局解释。
