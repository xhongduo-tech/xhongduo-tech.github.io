# 过程装备与控制工程（化工机械/压力容器）

过程装备与控制工程是研究石油化工生产中压力容器、塔器、换热器等过程设备的强度设计、结构设计与过程控制技术的工科主干专业，是化工硬件侧从力学分析、规范设计到自动控制的完整技术链条。学完这些章节，就系统写完了过程设备的应力分析基础、压力容器强度设计、典型过程装备结构与过程控制系统的全部内容。

## 对标教材

- 郑津洋、董其伍、桑芝富，《过程设备设计》，化学工业出版社
- 王志文、蔡仁良，《化工容器设计》，化学工业出版社
- 《过程装备控制技术及应用》，化学工业出版社
