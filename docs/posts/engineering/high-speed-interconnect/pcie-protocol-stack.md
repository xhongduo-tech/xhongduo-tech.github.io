## 为什么从 PCIe 协议栈开始

前三篇我们把 SerDes 的物理层讲透了：传输线、S 参数、均衡、抖动。但物理层只解决「比特怎么可靠地飞」，解决不了「比特代表什么含义」——后者是协议栈的领地。PCIe 是这套物理层技术的最大规模落地：从 2003 年 PCIe 1.0 到 2021 年的 PCIe 6.0，每一代都把物理层与协议层同步推进。<span class="marginnote">理解 PCIe 协议栈，等于理解「如何把物理层的比特流组织成一次次有意义的读写事务」——这是从《从极限到大模型》看硬件怎么与软件对话的关键一环：CPU 要读一块内存，最终都要翻译成 PCIe 事务层的一次 TLP。</span>

## 1 三层协议栈：谁管什么

PCIe 沿用 OSI 的分层思想，从下到上分为三层：

**物理层（Physical Layer）**：负责比特的编码、串行化、均衡与链路训练。<span class="marginnote">物理层是前几篇文章全部内容的落脚点：差动信号、8b/10b（1.0/2.0）与 128b/130b（3.0 起）、CTLE/DFE、链路训练状态机（LTSSM）里的复位、配置、恢复各状态。链路训练在这里完成「两端对齐速率、对齐均衡档位」。</span>

**数据链路层（Data Link Layer）**：负责可靠传输。它对上层事务包（TLP）追加序列号与 LCRC 校验，发送数据链路层包（DLLP）用于确认（ACK/NAK）、流控信用与电源管理。<span class="marginnote">数据链路层的可靠性机制是 PCIe 相对早期并行总线的重大升级：发送端缓存未确认的 TLP，收到 NAK 就重发——这让物理层可以放心地「尽力而为」，可靠性由上一层兜底。</span>

**事务层（Transaction Layer）**：最接近软件的一层。它把读/写请求组织成**事务层包（TLP）**，包内含地址、类型、数据、完成（completion）信息，并用流控信用（flow control credits）避免接收端缓冲溢出。

三层之间靠「包」传递：事务层产出的 TLP 交给数据链路层加封装，数据链路层产出的 DLLP 交给物理层编码发送；接收端按相反顺序逐层解包。**每一层只信任下一层的「尽力而为 + 校验」，自己的可靠性自己负责**——这正是分层协议最核心的哲学。

## 2 事务层：读内存的一次完整旅程

以「CPU 读一块 PCIe 设备内存」为例，一次完整事务的包流：

1. CPU 侧软件发起 MMIO 读，主机的根联合体（Root Complex）把请求打包成读请求 TLP。
2. TLP 依次穿过事务层（加包头与校验）、数据链路层（加序列号与 LCRC）、物理层（编码、串行化），沿链路到达设备。
3. 设备端逆向解包，执行实际读，把数据封装成**完成 TLP（Completion）**原路返回。
4. 主机收到完成 TLP，把数据交给软件。

<span class="marginnote">这趟旅程里，TLP 的格式、完成机制的语义（posted vs non-posted）都由 PCI-SIG 规范固定。non-posted 请求（如读）必须有完成，posted 请求（如写）则「烧了就发、无需确认」——理解这个区别，就理解了为什么显卡对显存写操作比读操作快。</span>

流控信用机制值得单独提：每个接收端宣告自己各类缓冲区的可用空间（信用），发送端按信用额度发包，信用耗尽就停止——从协议层面杜绝了丢包与缓冲溢出，这是「用信用换可靠」的典型设计。

PCIe 的拓扑也值得一提：它不再沿用并行总线的共享介质，而是**点对点**——一个设备独占一条链路，通过交换机（switch）扩展出更多端口。这意味着一条链路的带宽不会被其他设备瓜分，也解释了为什么 PCIe 的「带宽承诺」比并行总线实在得多。

## 3 公式解析：PCIe 带宽的算法

**PCIe 的「标称速率」与「真实带宽」之间隔着一个编码效率。** 单通道（x1）的有效数据带宽为：

$$\text{BW}_{\text{per-lane}} = \text{GT/s} \times \eta_{\text{encoding}} \times \frac{8}{8} = \text{GT/s} \times \eta_{\text{encoding}}$$

- **GT/s**：每通道每秒传输的符号数（gigatransfers/s）。PCIe 3.0 是 8 GT/s、5.0 是 32 GT/s、6.0 是 64 GT/s。
- **$\eta_{\text{encoding}}$**：编码效率。8b/10b 时 $\eta = 0.8$，128b/130b 时 $\eta \approx 0.9846$。
- **× lanes**：多通道叠加，如 x16 显卡接口总带宽 = 单通道带宽 × 16。

举例：PCIe 3.0 x16 = 8 GT/s × 0.9846 × 16 ≈ 126 GB/s；而若按 8b/10b 的 2.5 GT/s（PCIe 1.0 x1），则 = 2.5 × 0.8 = 2 Gb/s。这套算法贯穿《标准生态》一节对规范的解读：**规范写 GT/s，厂商宣传写 GB/s，中间差的就是编码效率与通道数。**

## 4 链路训练：两端如何握手

物理层并非上电即通，而是要通过 **LTSSM（链路训练状态机）** 完成一整套握手。典型流程（复位 → 检测 → 配置 → 就绪）：

1. **检测（Detect）**：两端发送检测信号，确认对面有对端。
2. **轮询（Polling）**：交换训练序列，确定链路速率与通道宽度。
3. **配置（Configuration）**：协商通道编号、通道极性，完成链路宽度配置。
4. **空闲（L0 / L0s / L1）**：进入正常工作或低功耗待命。

<span class="marginnote">训练期间，两端还会逐档尝试发送端均衡电平与接收端均衡档位，选出眼图最亮者——这正是《编码与均衡》里自适应训练在标准层面的制度化。PCIe 5.0 起还加入了独立参考时钟的抖动消除训练（对 SRIS 抖动管理的支持）。</span> 训练失败或链路不稳定，LTSSM 会退回到更低的速率或重新训练——这就是为什么 PCIe 链路偶尔「先降速再恢复」。

## 5 代际翻倍史：物理与协议的协同演进

PCIe 每代约每 2–4 年发布，速率基本遵循「每代翻倍」的节奏：

| 代际 | 发布年 | 每通道速率 | 编码 | 每通道有效带宽（x1） |
| --- | --- | --- | --- | --- |
| 1.0 | 2003 | 2.5 GT/s | 8b/10b | 2 Gb/s |
| 2.0 | 2007 | 5 GT/s | 8b/10b | 4 Gb/s |
| 3.0 | 2010 | 8 GT/s | 128b/130b | 7.88 Gb/s |
| 4.0 | 2017 | 16 GT/s | 128b/130b | 15.75 Gb/s |
| 5.0 | 2019 | 32 GT/s | 128b/130b | 31.5 Gb/s |
| 6.0 | 2021 | 64 GT/s | PAM4 + FEC | ~60 Gb/s（含 FEC 开销） |

**代际演进的两条线索**：一是速率翻倍（物理层的均衡、抖动预算被逐代压榨），二是编码与纠错的引入（3.0 换 128b/130b、6.0 上 PAM4 + FEC）。6.0 是转折点——它首次放弃 NRZ，改用 PAM4，把信道的「物理带宽」问题彻底转为「信号处理」问题，这正是《编码与均衡》一节的现实出处。

## 6 核心对比表：PCIe 三层职责

| 层 | 核心对象 | 关键机制 | 对物理层的依赖 |
| --- | --- | --- | --- |
| 事务层 | TLP | 读/写请求、完成、流控信用 | 不关心比特如何编码 |
| 数据链路层 | TLP + DLLP | 序列号、LCRC、ACK/NAK 重发 | 假设物理层尽力而为 |
| 物理层 | 差动符号 | 编码、均衡、LTSSM 训练 | 自身就是信号完整性战场 |

一张表看清分工：**越上层越「懂软件」，越下层越「懂物理」**。分层的好处是让演进解耦——3.0 换编码时上层协议几乎不变，6.0 上 PAM4 时事务层毫无感知。这正是协议栈工程的精髓。

## 7 术语速查表

| 术语 | 含义 |
| --- | --- |
| TLP | 事务层包，携带读/写请求、地址、数据与完成 |
| DLLP | 数据链路层包，负责 ACK/NAK、流控、电源管理 |
| LCRC | 链路层循环冗余校验，检测传输错误 |
| LTSSM | 链路训练状态机，管理速率协商与均衡配置 |
| posted / non-posted | 无需完成 / 需要完成的请求类型 |
| 流控信用 | 接收端宣告缓冲空间，发送端按额度发包 |
| Root Complex | 根联合体，CPU 侧连接 PCIe 的桥接组件 |

## 8 小结

- PCIe 三层：**事务层**（TLP、读/写语义）、**数据链路层**（可靠传输、ACK/NAK）、**物理层**（编码均衡与链路训练）。
- 一次读事务 = 读请求 TLP 下行 + 完成 TLP 上行，posted（写）无需完成、non-posted（读）必须完成。
- 带宽算法 $\text{BW} = \text{GT/s} \times \eta \times \text{lanes}$，8b/10b 的 0.8 与 128b/130b 的 0.9846 是两代的分水岭。
- 代际翻倍史：2.5→5→8→16→32→64 GT/s，3.0 换编码、6.0 上 PAM4 + FEC。
- 分层让演进解耦：换编码、换调制，上层协议不需要跟着改。
- LTSSM 训练完成速率协商、均衡档位选择与低功耗切换，是物理层的「自检程序」。
- 流控信用机制用「额度发包」从协议层杜绝缓冲溢出，是可靠性的另一支柱。
- PCIe 是点对点拓扑（设备独占链路，交换机扩展端口），带宽承诺比共享并行总线实在。
- 理解 TLP 的 posted/non-posted 语义，是判断「读写谁更快」的钥匙。

在下一节，我们将从「外设总线」转向「内存总线」——**DDR 存储接口**：它是并行信号的最后堡垒，用源同步 DQS、拓扑端接与读写训练在时序余量上精打细算。
