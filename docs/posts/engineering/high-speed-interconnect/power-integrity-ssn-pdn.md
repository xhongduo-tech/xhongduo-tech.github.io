# 电源完整性（SSN 同步开关噪声、PDN 设计）

## 为什么从电源完整性开始

前几节处理的是「信号」本身：它的反射、损耗、抖动。但所有信号都有一个共同的下盘——**电源与地**。当几十上百个输出同时翻转时，片内/片外的电源分配网络（PDN）会掀起**同步开关噪声（SSN）**，让芯片内部的逻辑地都跟着抖动。<span class="marginnote">Bogatin 用一个比喻说透 PI 与 SI 的关系：信号完整性是「河面上的波浪」，电源完整性是「河床的地基」——地基不稳，波浪再平也没用。Johnson 在《High-Speed Digital Design》第8章则把 PDN 称为「稳定的电压参考」，强调所有噪声最终都汇到这一处。</span> 这也是本专题把电源完整性放在倒数第二篇的原因：它是前八篇全部信号预算的「共同分母」。

## 1 SSN：同步开关噪声怎么来的

**同步开关噪声（Simultaneous Switching Noise，SSN）** 又叫 **地弹（ground bounce）**：当 N 个输出同时由高到低（或相反）翻转时，瞬态电流 $I = N \cdot dQ/dt$ 要流过封装引脚的寄生电感 $L_{\text{pkg}}$，在电感两端激起电压降。<span class="marginnote">对并行接口（如 DDR 的 DQ 组同时翻转），SSN 直接叠加到输出电平上：地弹让「0」被抬高、「1」被压低，接收端判读出错。SSN 的量级由电感与电流变化率共同决定——这就是为什么引脚电感（见《封装与板级协同》）如此致命。</span>

一个粗略的量级：若 16 个输出同时翻转、每路 20 mA、上升时间 0.5 ns，总 $di/dt$ 约 6.4×10^8 A/s，乘以 1 nH 的封装电感，地弹约 0.64 V——对 1.2 V 的 IO 供电，这几乎吞掉了全部噪声预算。

压制 SSN 的手段与噪声来源一一对应：**减少同时翻转的位数**（差分信号天然低翻转电流）、**降低封装电感**（倒装、多电源/地引脚并联）、**放慢边沿**（可控 slew rate）、**加强去耦**（就近放高频电容）。DDR 的 DQ 组同时翻转场景，就是 SSN 的第一现场。

## 2 PDN 目标阻抗：给噪声设一条红线

电源完整性的设计核心，是保证 PDN 在**关心的频段内**阻抗不超过某个上限，即**目标阻抗（target impedance）**：

$$Z_{\text{target}} = \frac{V_{\text{supply}} \times \text{ripple}_{\%}}{\Delta I_{\text{max}}}$$

## 3 公式解析：目标阻抗的直觉

**目标阻抗把「允许的电压波动」换算成「PDN 允许的最大阻抗」——电压余量与电流变化的比值。** 三步拆解：

- **$V_{\text{supply}} \times \text{ripple}_{\%}$**：允许的电压纹波绝对值。比如 1.8 V 供电、允许 3% 纹波，则纹波预算 = 54 mV。
- **$\Delta I_{\text{max}}$**：负载最大瞬态电流变化。CPU/GPU 的 di/dt 可以到几十 A/ns 量级。
- **比值即阻抗上限**：$Z = \Delta V / \Delta I$，要守住电压纹波，PDN 阻抗就必须低于这个比。

举个真实量级：某 CPU 核心供电 1.0 V、纹波预算 30 mV、瞬态 $\Delta I$ = 100 A，则 $Z_{\text{target}} = 0.3\ \text{m}\Omega$——**毫欧级**！这要求 PDN 在目标频段内由大量并联的去耦电容与平面共同提供超低阻抗，任何单一电容都做不到。这解释了为什么 PDN 设计 = 多层平面 + 多级去耦电容的网络工程。

## 4 去耦层次：谁负责哪个频段

Bogatin 把去耦电容按「有效频率」分层：

| 层次 | 位置 | 容量量级 | 有效频段 |
| --- | --- | --- | --- |
| 片内电容 | Die 内（MIM/MOS） | pF–nF | 数十 MHz–GHz 以上 |
| 基板/封装电容 | 基板埋容、倒装电容 | nF–数十 nF | 数百 MHz–GHz |
| PCB 高频 MLCC | 0402/0201 靠近引脚 | 数十–数百 nF | 数十–数百 MHz |
| 大容量去耦 | 板面 bulk 电容 | µF 级 | kHz–数十 MHz |
| 电源模块 VRM | 板级稳压器 | — | 直流–kHz |

<span class="marginnote">关键教训：电容的<strong>引脚电感</strong>决定了它的有效频率上限——一个 MLCC 的 ESR 很小，但它引脚与焊盘的电感（约 1–2 nH）在几百 MHz 以上就把去耦效果抵消。因此「低阻抗」不是靠加大电容值，而是靠<strong>缩短到负载的电感路径 + 多点并联</strong>。每个电容的串联谐振频率就是它最有效的工作点。</span>

## 5 平面与回流：PDN 的另一半

除了电容，PDN 还依赖**电源/地平面**：一整层铜就是一只巨大的分布式电容与低电感通路。平面电容在高频段（GHz）提供的阻抗低到任何分立电容都追不上——这是多层板相对双面板的决定性优势。<span class="marginnote">平面还有个隐藏职责：作为信号的<strong>回流路径</strong>（return path）。信号完整性教科书反复强调「信号沿最小电感路径回流」，指的就是电流在参考平面上紧贴走线下方返回。平面被切割（槽、孔），回流路径被迫绕行，电感飙升，信号与电源同步恶化——这就是《封装与板级协同》里「回流路径连续」一节的电源完整性根源。</span>

设计上的落地是**保持参考平面完整**：过孔要加回流过孔（via stitching）、跨越分割平面时要有回流桥、电源与地平面尽量相邻成对（叠层里「信号—地—电源—信号」的经典夹心结构）。这些「看不见」的规则，决定了多层板在高频下的真实成色。

## 6 PDN 仿真与测量：把阻抗曲线画出来

PDN 设计不靠猜，靠「画阻抗曲线」。标准流程：

1. **建 PDN 模型**：从 VRM 输出、电容、平面、封装、Die 端到端建模，每段都有 R/L/C。
2. **画阻抗曲线**：仿真得到 $|Z|$ 对频率的曲线，检查是否处处低于 $Z_{\text{target}}$。
3. **找尖峰**：在曲线超出目标阻抗的频段，定位是电容谐振还是平面谐振。
4. **补电容/调布局**：错峰、缩短路径、加阻尼，迭代到曲线全部压线以下。

测量上常用 **VNA 测 PDN 阻抗**（把电源平面当二端口网络），或用**时域的方法**看芯片电源引脚的电压塌陷。<span class="marginnote">与信号域一样，PDN 也有「时域/频域」双视角：频域看阻抗曲线是否低于目标，时域看电源电压在瞬态下的塌陷（droop）幅度。两者是同一物理对象的两面。</span> 现代电源完整性工具还支持把 PDN 阻抗直接转成电源噪声，与信号眼图联合分析——这是「SI 与 PI 协同」的落点。

## 7 谐波与共振：PDN 的隐藏杀手

PDN 阻抗曲线并非平直，而是由电容谐振、平面谐振叠加成的**起伏曲线**。若某个频点的 PDN 阻抗尖峰恰好落在开关噪声频谱上，就会放大噪声——这就是所谓的 **PDN 谐振**。

工程对策：用**多个不同容值的电容**错开谐振点（如 0.1 µF 与 0.01 µF 搭配），让各个串联谐振峰互相填补、整体阻抗被压平；或用**阻尼电阻**压掉平面谐振峰。<span class="marginnote">这也是为什么高速板上去耦电容总是一排排、不同容值交错放置：不是为了「多」，而是为了「错峰」。仿真工具里画出 PDN 阻抗曲线，找尖峰、压尖峰，是电源工程师的日常。</span>

## 8 核心对比表：信号完整性 vs 电源完整性

| 维度 | 信号完整性（SI） | 电源完整性（PI） |
| --- | --- | --- |
| 对象 | 信号波形本身 | 供电压降与参考平面 |
| 关键指标 | 插损、回损、眼图、抖动 | 目标阻抗、纹波、地弹 |
| 频域工具 | S 参数、眼图 | PDN 阻抗曲线 |
| 时域工具 | TDR、眼图 | 电压塌陷、droop 测试 |
| 失效表现 | 误码、眼图闭合 | 逻辑误触发、时序余量丢失 |
| 典型对策 | 端接、均衡、板材 | 去耦电容、平面、错峰 |

**一句话**：SI 管「波形干不干净」，PI 管「让波形立足的地基稳不稳」，两者共用同一块 PCB、同一个封装，必须协同设计——这也是《封装与板级协同》把信号与电源放在同一节的原因。

## 9 术语速查表

| 术语 | 含义 |
| --- | --- |
| SSN | 同步开关噪声，多输出同时翻转激起的地弹 |
| 地弹 | 接地电感上的电压降，抬高「0」压低「1」 |
| PDN | 电源分配网络，从 VRM 到 Die 的整条供电路径 |
| 目标阻抗 | PDN 在关心频段内不得超出的阻抗上限 |
| MLCC | 多层陶瓷电容，去耦的主力器件 |
| 平面电容 | 电源/地平面间的分布电容，高频去耦主力 |
| VRM | 电压调节模块，把电源变换到芯片所需电压 |
| via stitching | 回流过孔，为参考平面之间的电流提供短路径 |
| droop | 瞬态负载下电源电压的塌陷幅度 |

## 10 小结

- **SSN/地弹** = 瞬态电流流过封装电感产生的电压降，同时翻转的位越多越凶。
- **目标阻抗** $Z_{\text{target}} = V \cdot \text{ripple} / \Delta I$ 把电压纹波预算换算成阻抗上限，常低到毫欧级。
- 去耦靠**分层电容**：片内→基板→MLCC→bulk→VRM，每层负责一段频段。
- 电容的有效频率受**引脚电感**限制，低阻抗靠「短路径 + 多并联」而非堆容量。
- 电源/地平面既是高频去耦主力，又是信号回流路径，被切割会让信号与电源同步恶化。
- PDN 阻抗曲线上的谐振尖峰要用错峰电容与阻尼压制——「多」不如「错」。
- 平面既是高频去耦主力又是信号回流路径，参考平面完整性是 PCB 叠层设计的第一原则。
- PDN 仿真流程 = 建模型 → 画阻抗曲线 → 找尖峰 → 补电容，与信号域的仿真工作流同构。
