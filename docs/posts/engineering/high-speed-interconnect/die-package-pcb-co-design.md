## 为什么从封装与板级协同开始

前几篇的传输线、S 参数、均衡，讲的都是一段「干净」的走线。但真实的信号要穿越的是一条**三级接力赛道**：芯片 Die → 封装（substrate、bump、trace、ball）→ PCB 走线。每一级交棒处都有阻抗突变、寄生电容、过孔残桩，都在消耗信号。<span class="marginnote">这正是本博客《先进封装与 Chiplet》专题（第六级）的接口层视角：那边讲封装工艺与 Chiplet 互连，这边讲信号如何在这些封装结构里保持完整——两篇互补，读时可交叉对照。信号完整性在 Die-封装-PCB 三段上必须被当成一个整体来设计，这就是「协同设计（co-design）」。</span>

## 1 三级互连：每一级都在「交棒」

从 Die 上的晶体管到 PCB 走线，信号依次经过：

- **Die 内互连**：晶体管级金属层，纳米尺度，以 RC 为主。
- **封装互连**：微凸点（bump/micro-bump）、再分布层（RDL）、封装基板走线、焊球（ball）。尺度从几十微米到几毫米。
- **PCB 互连**：从 BGA 焊盘经过孔进入内层走线，再到达连接器或下一芯片。尺度是厘米级。

<span class="marginnote">每一级的特征阻抗各不相同：Die 内没有「50 Ω 概念」，封装基板线宽细、靠近参考面，阻抗常在 40–60 Ω 之间，PCB 走线则是标准的 50/100 Ω（差动）。三级之间阻抗不一致，就是反射的来源——协同设计的第一件事，就是让每一级「接口处的等效阻抗」尽量匹配。</span>

以一只 PCIe 5.0 PHY 为例，Die 输出的信号在到达 PCB 之前要经历微凸点（几十 µm）、基板走线（几百 µm–几 mm）、焊球与过孔（约 1 mm）三段——总长也许只有 10 mm，但这一段路的寄生电容可能已有 1–3 pF，等效成一个「低通滤波器」，把上升时间摊平、把高频吃掉。**封装越简单，这段接力越轻松；封装越复杂（大芯片、多 Die、Chiplet），这段接力的设计难度越高。**

## 2 封装的寄生参数：看不见的 RC 税

封装对信号来说是一笔**寄生税**：每个焊球、凸点、过孔都带有寄生电容与寄生电感。工程上常以「每引脚/bump 的寄生值」估算：

| 封装结构 | 典型寄生电容 | 典型寄生电感 |
| --- | --- | --- |
| 引线键合（wire bond） | 0.5–2 pF | 1–3 nH |
| 倒装凸点（flip-chip bump） | 0.05–0.3 pF | 0.05–0.3 nH |
| BGA 焊球 | 0.3–1 pF | 0.5–1.5 nH |
| 过孔（PCB） | 0.2–1 pF | 0.3–1 nH |

<span class="marginnote">引线键合之所以在高速时代被倒装芯片取代，从这张表就能看出来：一根键合线的电感比一个凸点高出一个量级，等效成阻抗不连续也大一个量级。这就是为什么 PCIe 5.0/6.0、DDR5、112G SerDes 一律要求倒装封装。</span> 电感与电容的组合在频率升高时会把「寄生阻抗」放大，于是这些寄生参数成了插损曲线上的波纹来源——与《S 参数与信道表征》里过孔残桩的谐振是同一类现象，只是发生在封装这一级。

对 Chiplet 互连（如 UCIe、BoW），封装的寄生甚至成了**决定性的**因素：Die-to-Die 的链路长度极短，链路预算里几乎没有 PCB 损耗，全部压力都落在封装基板与凸点身上——这正是《先进封装与 Chiplet》专题里「封装即系统」论断的信号完整性注脚。

## 3 公式解析：上升时间的三级预算

**三级互连的「接力」本质是：每经过一段，信号的上升时间都会被摊平一点，总上升时间按平方和叠加。** 这由传播线上「带宽受限元件串联」的著名关系给出：

$$t_{r,\text{out}} = \sqrt{t_{r,\text{in}}^2 + t_{r,\text{die}}^2 + t_{r,\text{pkg}}^2 + t_{r,\text{pcb}}^2}$$

- **$t_{r,\text{in}}$**：驱动器输出的固有上升时间，由工艺与驱动强度决定。
- **$t_{r,\text{die}}$**：Die 内互连 RC 摊平的上升时间。
- **$t_{r,\text{pkg}}$**：封装寄生 RC 摊平的上升时间。
- **$t_{r,\text{pcb}}$**：PCB 走线损耗（趋肤 + 介质）摊平的上升时间。

**平方和叠加的意义**：各项不是相加，而是「平方和开根」。这意味着当某一项很小（如倒装封装把 $t_{r,\text{pkg}}$ 压到很小），它几乎不贡献总预算——**短板决定总上升时间，但长板里的每块短板都可以被「平方」稀释**。这也解释了为什么高速设计宁可花大成本把某一级做好（倒装、低损耗板材），而不是平均用力。

反过来，上升时间越短，边沿的空间长度越短，越需要按《传输线理论》的模型对待——**上升时间预算既是时序指标，也是判断「要不要把这一段当地传输线」的标尺**。

## 4 板级接口：从封装到 PCB 的细节战场

从封装出来的信号进入 PCB，还要面对三个具体的「掉棒点」：

- **过孔（via）**：从表层到内层的通道，残桩（stub）在四分之一波长处谐振。DDR5/PCIe 5.0 时代常用背钻（back-drilling）去掉残桩，或用盲埋孔替代通孔。<span class="marginnote">背钻的成本不低（多一次钻孔工序），但能把过孔残桩从 1 mm 量级砍到 0.2 mm 以下，等效把过孔谐振频率提高数倍——这正是「花钱买频率」的典型例子。</span>
- **连接器**：板对板、卡对卡的机械+电气交接点，寄生电感与差分引脚间的串扰在此集中。差分对在连接器里要「共面铺开」以降低串扰。
- **回流路径**：每一级交棒都要求返回电流有连续的低阻抗路径——参考平面跨不过去（槽），信号完整性就崩。

**协同设计的方法论**：先在系统层定出「每一段的阻抗预算与损耗预算」，再用场求解器逐段建模（封装基板、过孔、连接器各自出 S 参数），最后把三级 S 参数级联成整条信道做眼图仿真——这正是《仿真工作流》一节的主角。**没有协同设计，三级各自「看着不错」的信道级联起来可能一塌糊涂。**

一个经典的失败模式是「封装单独仿真眼图很开，PCB 单独仿真也很开，级联起来却闭成一线」——原因往往出在接口处：封装引脚的阻抗与 PCB 过孔阻抗在高频下并不匹配，反射在级联时叠加。**分段建模的价值，正在于让这些接口处的「暗伤」在仿真阶段就暴露出来。**

## 5 电力侧的接力：封装里的 PDN

协同设计不只管信号，还管**电源**。Die 的开关电流要经过封装焊球、基板平面、再回到片外去耦电容——这条 **PDN（电源分配网络）**路径的电感直接决定电源噪声幅度。<span class="marginnote">Bogatin《Signal and Power Integrity—Simplified》第13章专门讲 PDN：片外 MLCC 去耦电容要「够近」，否则它的引脚电感和封装焊球电感串联起来，就把去耦效果吃掉大半。封装的电感（一般 nH 量级）是 PDN 阻抗曲线在中频段抬升的主因。</span>

典型手段是**分层去耦**：Die 内用高密度 MIM/MOS 电容对付纳秒级瞬态，封装基板里埋入小容量高频电容（与 Die 零距离），PCB 上放 0402/0201 的 MLCC 对付低频，外加 bulk 电容兜底。每一级电容的「有效半径」不同，配合目标阻抗曲线 $Z_{\text{target}} = V_{\text{ripple}}/\Delta I$（见《电源完整性》一节），共同把 PDN 阻抗压到曲线之下。**信号与电源在封装这一级交汇：一个共享的物理结构，承载两种完整性任务。**

## 6 核心对比表：三级互连的信号画像

| 维度 | Die 内 | 封装 | PCB |
| --- | --- | --- | --- |
| 尺度 | 纳米–微米 | 微米–毫米 | 厘米 |
| 阻抗 | 无 50Ω 概念 | 40–60 Ω（近） | 50/100 Ω（标准） |
| 主要损耗 | RC | 寄生 RC + 谐振 | 趋肤 + 介质 |
| 可调手段 | 工艺、布线 | bump/基板材料/布线 | 叠层、板材、背钻 |
| 失效表现 | 延迟 | 插损波纹、串扰 | 眼图闭合、振铃 |

这张表再次印证主线：**每一级都有不同的「物理手感」，但同一套 S 参数语言可以统一描述**——这就是为什么协同设计的第一步永远是「把三级都变成 S 参数」。

## 7 术语速查表

| 术语 | 含义 |
| --- | --- |
| co-design | 协同设计，把 Die-封装-PCB 当整体联合优化 |
| flip-chip | 倒装，裸片翻转贴到基板，凸点互连 |
| RDL | 再分布层，把 Die 的 I/O 扇出到基板 |
| 背钻 back-drill | 钻掉过孔残桩，消除谐振 |
| 残桩 stub | 过孔未用到的多余段，形成谐振腔 |
| 寄生电感/电容 | 封装与互连结构固有的、非设计本意的 RLC |
| MLCC | 片外多层陶瓷去耦电容，PDN 分层的低频主力 |
| 目标阻抗 | PDN 在频率上不得超过的阻抗上限，$Z_{\text{target}} = V_{\text{ripple}}/\Delta I$ |

## 8 小结

- 信号要走完 **Die → 封装 → PCB** 三级接力，每级交棒都有阻抗突变与寄生参数。
- 封装的寄生 RC 是「看不见的税」：引线键合的电感比倒装凸点高一个量级，高速时代因此转向倒装。
- 上升时间预算按**平方和叠加** $t_{r,\text{out}} = \sqrt{\sum t_{r,i}^2}$，短板决定总量、强项可被稀释。
- 过孔残桩、连接器、回流路径是板级三大「掉棒点」，背钻与参考平面连续性是对策。
- 协同设计 = 分段预算 + 逐段 S 参数建模 + 级联眼图仿真。
- 三级互连各自不同，但同一套 S 参数语言能统一描述——这是协同设计的前提。
- 封装是信号与电源两个完整性任务交汇的共享物理结构，PDN 分层去耦（Die 内/基板/MLCC/bulk）缺一不可。
- 背钻、倒装、低损耗板材都是「花钱买频率」的典型决策，上升时间平方和模型为取舍提供依据。
- 三级各自眼图都开、级联却闭，是协同设计失败的标准症状——接口处的阻抗暗伤只能靠分段建模暴露。
- PDN 目标阻抗与去耦分层（Die 内/基板/MLCC/bulk）是封装电力侧接力的核心工具箱。
- Chiplet 互连（UCIe/BoW）让封装寄生成为链路预算的主导项，「封装即系统」在此得到信号完整性层面的印证。

在下一节，我们将跨出铜与硅的世界——**光互连**：当信道损耗逼近极限时，光取代电，信号从「拉一根铜线」变成「点亮一束激光」，AOC、光模块与共封装光学正在改写高速互连的天花板。
