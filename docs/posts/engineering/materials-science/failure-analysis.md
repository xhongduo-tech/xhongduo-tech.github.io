## 为什么失效分析是材料科学的「期末考试」

前面 45 节建立了一整套「结构-性能」的知识，而**失效分析**是它们的总检验：当构件在服役中破坏，失效分析工程师要回答「为什么坏、怎么坏的、怎么防止再坏」。它像法医鉴定，从断裂的残骸里读出材料的全部故事。<span class="marginnote">失效分析的价值远超「追责」：<strong>每一次失效都是一次免费的全尺寸试验</strong>——泰坦尼克号的钢板脆断、彗星客机的疲劳裂纹、航天飞机的密封圈失效，都推动了材料与设计的进步。失效分析把「事故」变成「教科书」。</span>

本章主线：**失效的分类 → 断口分析的读法 → 失效分析的程序 → 典型失效案例 → 预防设计**。

## 1 失效的类型

材料失效分两大类：

### 力学失效

- **断裂失效**：韧性断裂、脆性断裂（见《断裂与疲劳》）。
- **疲劳失效**：交变载荷下的渐进破坏——占工程失效的绝大部分。
- **蠕变失效**：高温下的缓慢变形与断裂。
- **磨损失效**：表面材料逐渐损耗（磨粒磨损、粘着磨损、腐蚀磨损）。

### 环境失效

- **腐蚀失效**：均匀腐蚀、点蚀、应力腐蚀开裂、晶间腐蚀（见《腐蚀与氧化》）。
- **腐蚀疲劳**：腐蚀与疲劳协同，比单一作用更危险。
- **老化失效**：高分子老化（见《高分子老化与改性》）。

**辨析｜易错点：** 失效 ≠ 断裂。**断裂是结果，失效是过程与结果的总和**——失效可能表现为变形（蠕变）、磨损（尺寸减小）、泄漏（密封失效）、腐蚀（穿孔），不只是断成两截。**分析的第一步是「定性」：这属于哪一类失效？**<span class="marginnote">失效分析的「第一现场」是断口与表面：<strong>断口记录裂纹从哪开始、怎么扩展、多快断裂；表面记录腐蚀与磨损的痕迹</strong>。取证越早、越完整，结论越可靠——「分析从现场开始，而不是从实验室开始」。</span>

## 2 断口分析：读断裂的「证词」

断口是失效分析最重要的证据。不同失效类型在断口留下特征形貌：

### 韧性断口

- **宏观**：杯锥状，有明显颈缩，边缘有剪切唇。
- **微观（SEM）**：**韧窝（dimple）**——微孔聚集长大的痕迹。韧窝越大越深，材料韧性越好。
- 说明：**过载或材料韧性不足**。

### 脆性断口

- **宏观**：平齐、无颈缩，有人字纹/放射纹指向起裂点。
- **微观**：**解理台阶、河流花样**——沿解理面撕裂的痕迹。
- 说明：**低温、高应变率、应力集中或回火脆性**。

### 疲劳断口

- **宏观三区**：**疲劳源区（光滑）→ 疲劳扩展区（贝壳纹/海滩纹，每年轮）→ 瞬断区（粗糙）**。<span class="marginnote">疲劳断口的「贝壳纹」是失效分析的时钟：<strong>每一条海滩纹代表一次载荷循环或一个阶段——数一数，就能估算裂纹扩展了多久</strong>。疲劳源多在表面缺陷、缺口、应力集中处——「裂纹从应力最大、缺陷最深处诞生」。</span>
- **微观**：疲劳辉纹（每条纹 = 一次循环）。
- 说明：**交变载荷 + 应力集中**。

### 应力腐蚀断口

- 断口呈脆性特征，表面有腐蚀产物，裂纹多分叉（树枝状）。
- 说明：**腐蚀介质 + 拉应力**（见《腐蚀与氧化》）。

## 3 失效分析的程序

标准失效分析流程（像侦探破案）：

1. **现场调查与取证**：记录断裂位置、残骸、服役环境、载荷历史——「不放过任何异常」。
2. **资料收集**：设计图、材料牌号、工艺记录、检验报告——「材料本该是什么样」。
3. **无损检测**：超声、磁粉、X 射线探伤——找裂纹与缺陷。
4. **断口分析**：宏观观察 → 低倍 → SEM 微观——确定失效类型与起裂点。
5. **成分与组织分析**：XRD、EDS、金相——确认材料是否达标、组织是否异常。
6. **力学与模拟**：硬度、拉伸验证；有限元算应力分布——「应力从哪来」。
7. **综合分析**：还原失效过程，判定失效模式与根本原因。
8. **提出对策**：材料替换、工艺改进、设计修改、检验加强。

**关键原则**：**失效分析要「先定性后定量、先宏观后微观、先无损后破坏」**——破坏性取样留在最后，最大限度保留证据。<span class="marginnote">失效分析的「证据保全」原则：<strong>断口是唯一不可再生的证据——拍照、保护、防锈，任何一个环节污染了断口，结论就可能出错</strong>。合格的失效分析，90% 的功夫在取证与观察，10% 在计算。</span>

## 4 公式解析：疲劳寿命的估算

疲劳失效分析常要反推「裂纹从多大开始、能撑多久」。用**断裂力学**估算剩余寿命：

$$\frac{da}{dN} = C (\Delta K)^m$$

- $a$：裂纹长度；$N$：循环次数；$C$、$m$：材料常数。
- $\Delta K = \Delta\sigma\sqrt{\pi a}$：应力强度因子幅。
- **帕里斯（Paris）公式**：裂纹扩展速率与应力强度因子幅的幂次成正比。

**逐步理解：**
- **第一步**：裂纹不是瞬间贯穿，而是每次循环扩展一小段（$da/dN$）。
- **第二步**：$\Delta K$ 越大（应力越大、裂纹越长），扩展越快。
- **第三步**：从无损检测测得的初始裂纹 $a_0$ 积分到临界裂纹 $a_c$，就能估算**剩余寿命**——「还能用多久，取决于最大缺陷多大」。<span class="marginnote">Paris 公式是「损伤容限设计」的引擎：<strong>知道了初始裂纹尺寸和 Paris 参数，就能算「还能飞多少起落、再开多少公里」</strong>——飞机检修间隔、管道检测周期都由它决定。</span>

## 5 典型失效案例

### 泰坦尼克号（脆性断裂）

1912 年沉没后分析：船体钢含硫磷高、低温韧性差，撞击后**脆性断裂**迅速蔓延——推动「韧脆转变温度」概念与低温用钢标准的确立。

### 彗星客机坠毁（疲劳断裂）

1954 年两起彗星客机事故：方形舷窗角部**应力集中**，增压循环导致**疲劳裂纹**从窗角萌生扩展——推动「疲劳设计」与圆角设计，催生了现代疲劳试验。

### 挑战者号（密封失效）

1986 年：固体助推器**O 形密封圈**在低温下失去弹性（$T_g$ 效应），高温燃气泄漏——推动「低温性能验证」与安全决策文化。<span class="marginnote">三个案例的共同教训：<strong>失效分析不是「找替罪羊」，而是「找系统性漏洞」</strong>——泰坦尼克暴露材料低温脆性，彗星暴露设计应力集中，挑战者暴露密封材料低温失效。每次事故都推动了材料与设计的规范进步。</span>

### 高压蒸汽管道爆裂（蠕变失效）

火电厂管道长期高温服役，**蠕变损伤积累**（晶界孔洞、蠕变裂纹），最终爆裂——推动「蠕变寿命评估」与定期检验。

## 6 失效预防的设计思想

把失效分析的知识前移到设计阶段，就是**失效预防**：

- **选材**：按服役条件（应力、温度、介质）选材，考虑韧脆转变、腐蚀、疲劳。
- **结构设计**：避免尖角应力集中（圆角、过渡）、控制残余应力。
- **表面工程**：涂层、喷丸（表面压应力）、渗碳渗氮。
- **检验与监测**：无损检测定期探伤、在线监测。
- **冗余设计**：关键件留裕度、安全系数、fail-safe 设计。
- **失效模式与影响分析（FMEA）**：系统性地提前识别可能的失效模式。

## 7 小结

- 失效分**力学失效**（断裂、疲劳、蠕变、磨损）与**环境失效**（腐蚀、老化、腐蚀疲劳）。
- **断口是证词**：韧窝（韧断）、解理河流（脆断）、贝壳纹（疲劳）、分叉裂纹（应力腐蚀）。
- 失效分析程序：**现场 → 无损 → 断口 → 成分 → 力学 → 综合 → 对策**，先无损后破坏。
- **Paris 公式** $da/dN = C(\Delta K)^m$ 估算剩余寿命，支撑损伤容限设计。
- 泰坦尼克（脆断）、彗星（疲劳）、挑战者（密封）——事故推动进步。
- 失效预防：**选材、圆角、表面工程、检验、FMEA**。
