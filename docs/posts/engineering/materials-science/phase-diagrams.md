# 相图（二元/三元）

<div class="epigraph">

## 为什么从相图开始

前面几节讨论了单个原子的行为（键合）与单个晶体的几何（结构）。但工程材料几乎都是**多组元、多相**的：钢是铁与碳的合金，黄铜是铜与锌的合金。要回答「这个成分、这个温度下，材料里有几相、各相成分多少、各占多少比例」，就需要**相图（phase diagram）**。<span class="marginnote">「相（phase）」指系统中成分与结构均一、与其他部分有明确界面的部分。一杯盐水是单相（液相），水加冰块是两相（液+固）。材料里铁素体、奥氏体、渗碳体都是不同的相。</span>

相图是**成分—温度—（压强）—相**的平衡关系图。它不回答「要多长时间达到平衡」（那是动力学、是相变章节的事），只回答「平衡时是什么」。但正是这张「静态地图」，为热处理、合金设计提供了全部路线依据——**不懂相图，就无法设计合金成分，也无法选择热处理工艺**。

## 1 相图的基本要素

### 组元、相与自由度

构成合金的独立化学组成物叫**组元（component）**。二元相图有两个组元，以横轴表示成分（质量分数 wt% 或原子分数 at%），纵轴表示温度。

描述系统状态所需的独立可变参数（温度、压强、成分）的数目，叫**自由度**，由**吉布斯相律（Gibbs phase rule）**给出：

$$f = C - P + 2$$

- $C$：组元数；$P$：相数；$2$ 来自温度与压强两个外界变量。
- 对常压下的金属系，压强视为常数，简化为 $f = C - P + 1$。
- 对二元系（$C = 2$）：单相区 $f = 2$（温度、成分都可变，是「面」）；两相区 $f = 1$（温度或成分给定，另一个就定死，是「线」）；三相共存 $f = 0$（温度成分全定，是「点」）。<span class="marginnote">相律是检验一张相图画得对不对的「守恒律」：二元相图的任何位置都不能出现「四条线交于一点」这样的结构，因为那会对应 $f < 0$ 的非法状态。</span>

### 相图的三种基本反应

二元相图由几种基本类型拼接而成：

- **共晶反应（eutectic reaction）**：一个液相同时析出两个固相，$L \rightarrow \alpha + \beta$。发生在共晶温度与共晶成分，如 Pb-Sn、Al-Si。
- **包晶反应（peritectic reaction）**：一个液相与一个固相反应生成另一个固相，$L + \alpha \rightarrow \beta$。发生在包晶温度，如 Cu-Zn、Pt-Ag。
- **共析反应（eutectoid reaction）**：一个固相同时分解为两个固相，$\gamma \rightarrow \alpha + \beta$。它是共晶反应的固态版，钢中的珠光体转变即属此类（详见《铁碳相图》）。

## 2 杠杆定律：定量计算两相区

相图不仅能「读相」，还能**定量计算**两相区中两相的成分与相对含量。在二元相图的两相区，水平线（等温线）与两条相界线相交：

- 两交点在成分轴上的投影，就是两个平衡相的成分。
- 两相的**相对含量**由**杠杆定律（lever rule）**决定。

设合金成分 $C_0$，两相成分分别为 $C_\alpha$ 与 $C_L$，则：

$$f_\alpha = \frac{C_L - C_0}{C_L - C_\alpha}, \qquad f_L = \frac{C_0 - C_\alpha}{C_L - C_\alpha}$$

其中 $f_\alpha + f_L = 1$。

**直觉：** 把整条杠杆看作以合金成分为支点。$C_0$ 越靠近哪一相的成分点，那一相就占得越多。**支点距某相端点越远，该相含量越少**——与力学杠杆完全同构。

**辨析｜易错点：** 杠杆定律**只在两相区适用**。在单相区该相含量恒为 100%，在三相共存点不能直接用二元的杠杆定律（成分不确定）。还要注意横轴若是 wt%，算出的含量就是质量分数；若是 at%，则是原子分数——**比例必须与坐标轴的单位一致**。

## 3 二元相图的实例：Cu-Ni 与 Pb-Sn

### 匀晶相图：Cu-Ni

铜与镍无限互溶，液相与固相都形成连续固溶体，相图只有两个单相区（L 与 α）加一个两相区（L+α），属于**匀晶相图（isomorphous）**。<span class="marginnote">Cu-Ni 相图是入门经典：凝固时先从液相析出富镍的 α 相（因为镍熔点更高），液相应分沿液相线向富铜方向移动——这就是「树枝晶偏析」的成分根源。</span>

对给定成分 $C_0$ 的合金，凝固并非发生在单一温度，而是**从液相线温度 $T_L$ 到固相线温度 $T_S$ 的一个温度区间**。在区间内 L 与 α 共存，两相成分由等温线与液/固相线交点读出，相对含量由杠杆定律求出。

### 共晶相图：Pb-Sn

铅与锡部分互溶，有共晶反应。共晶成分（Sn 61.9 wt%）在共晶温度（183°C）发生 $L \rightarrow \alpha + \beta$，得到两相**交替片层**的共晶组织——这种组织在显微镜下有特征形貌，是识别共晶合金的标志。

**辨析｜易错点：** 不要混淆「共晶成分的合金」与「共晶组织」。**只有成分正好等于共晶成分的合金，凝固时才完全变成共晶组织**；偏离共晶成分的合金，先析出初生相（先共晶相），剩余液相再发生共晶反应——形成「初生相 + 共晶」的混合组织。这一区分在《相变与凝固》与《铁碳相图》中反复出现。

## 4 三元相图入门

三元相图有三个组元，用**等边三角形**表示成分（三顶点各代表一个纯组元），纵轴表示温度，形成三维图形。工程上用三元相图解决「二元不够用」的问题——很多重要合金体系（如 Al-Cu-Mg、Fe-C-Cr）必须用三元来描述。

三元相图的要点：

成分三角形中，一点距某顶点越近，该组元含量越高；**平行于某边的直线代表第三组元含量恒定**。
相图是三维的，常以**等温截面（水平切片）**与**垂直截面（变温截面）**来阅读。
三元系中可能出现**四相共存**（如三元共晶 $L \rightarrow \alpha + \beta + \gamma$），此时 $f = 0$，是相图上的一个固定点。<span class="marginnote">三元相图的三维阅读是材料工程师的实用技能：等温截面告诉我们「某温度下平衡相是什么」，这在合金热处理温度选择中直接使用。可查阅《金属学与热处理》的典型三元系实例。</span>

**辨析｜易错点：** 三元相图里「成分」必须用**三个组元**描述，不能只说两个。合金成分点的判读要会用三角形坐标系：过该点作三条平行于三边的线，与三边的截距分别给出三组元的含量，三者之和为 100%。

## 5 相图与材料设计的桥梁

相图是「平衡的地图」，热处理是「非平衡的旅程」。两者的关系是材料科学的枢纽：

**选成分**：根据目标性能（强度、耐蚀、导电）在相图中选合金系与成分区间。
**定工艺**：由相图确定热处理温度范围（如钢的淬火加热温度取决于 $A_1$、$A_3$ 临界温度）。
**控组织**：平衡相图给出「最终能到达哪里」，而冷却速度决定「实际走到哪里」——这一差距正是《相变与凝固》的核心。

## 6 相图的读图实例：共晶 Pb-Sn 的凝固路径

把前面所有工具串起来的读图练习：分析 **Sn-40 wt% Pb** 合金（亚共晶成分）从液态缓冷到室温的凝固过程。

**第一步，定位**：成分 40% Pb（即 60% Sn）位于共晶点（61.9% Sn）左侧，是**亚共晶合金**——先析出初生相 α（富 Sn 固溶体）。

**第二步，读液相线**：缓冷到液相线温度，开始析出 α；随温度降低，α 不断析出，**剩余液相沿液相线向共晶成分富集**——固相与液相成分分别沿固相线与液相线变化。

**第三步，共晶反应**：温度降到 183°C 时，剩余液相成分恰好到达共晶点，发生 $L \rightarrow \alpha + \beta$——剩余液相全部转变为细密的两相共晶组织。

**第四步，室温组织**：**初生 α + 共晶（α+β）**——显微镜下可看到粗大的初生 α 枝晶散布在细密的共晶基体中。<span class="marginnote">读相图的四个动作是固定的：<strong>①定位（什么成分）→ ②过等温线（读两相成分）→ ③用杠杆定律（算比例）→ ④判断反应（共晶/包晶/共析）</strong>。这套流程对任何二元相图都适用。</span>

**杠杆定律的验证**：在共晶温度以上某温度，两相区中 α 与液相的相对量由杠杆定律计算——**支点越靠近液相线，液相越多**；这正是「初生相析出过程」的定量描述。

再强调一个实用要点：**杠杆定律求出的「含量」是平衡态的比例**。实际凝固中由于冷却偏快、扩散不充分，**初生相的实际量往往偏离杠杆定律**——这正是《相变与凝固》里「非平衡凝固与偏析」要讨论的问题。读相图，既要会算平衡量，也要知道「实际走不到平衡」——**平衡是理想，非平衡才是常态**。

## 7 小结

- 相图是**成分—温度—相**的平衡图；**吉布斯相律** $f = C - P + 2$ 是其结构约束。
- 三类基本反应：**共晶、包晶、共析**。
- **杠杆定律**定量计算两相区各相成分与含量。
- Cu-Ni 是**匀晶相图**典型，Pb-Sn 是**共晶相图**典型。
- **三元相图**用成分三角形 + 温度轴描述三组元体系，靠等温/垂直截面阅读。

在下一节，我们把相图的「平衡世界观」放到凝固的动力学中——**相变与凝固**，看组织如何从液相里长出来。
