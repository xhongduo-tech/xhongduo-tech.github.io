## 为什么炼钢的核心是「脱碳」

高炉铁水含碳约 4%，而钢的碳含量大多在 0.05–1.0% 之间。**炼钢的本质就是把铁水中多余的碳烧掉**，顺便把硅、锰、磷、硫这些杂质降到钢种要求的水平。1950 年代氧气顶吹转炉（BOF/LD）的成熟，让炼一炉钢从平炉的 6 小时缩短到 20 分钟——这一场「氧气革命」彻底改写了钢铁工业的速度。<span class="marginnote">转炉的名字来自炉体可以倾动：装料时倾倒、吹炼时直立、出钢时再倾倒。氧气从顶部氧枪高速喷入熔池，与铁水中的碳、硅、锰等元素剧烈反应——一座 300 t 转炉每分钟要消耗 1000 m³ 以上的工业纯氧。</span>

从知识谱系看，这一篇是《冶金原理》全部火法冶金逻辑的浓缩：脱碳是氧化反应的热力学与动力学问题，造渣脱磷是《熔渣理论》的实战，炉温控制是热平衡的工程形态。读懂转炉，就读懂了「靠氧气把杂质烧掉」这一整类炼钢思想。

## 1 转炉炼钢的原料与物理

转炉原料包括**铁水（约 80–90%）**、**废钢（约 10–20%）**与渣料（石灰、轻烧白云石、萤石等）。铁水兑入前要**脱硫**（KR 搅拌脱硫或喷吹颗粒镁），因为转炉内脱硫能力很弱。

**热平衡是转炉的铁律**：铁水物理热 + 元素氧化放热 = 熔化废钢 + 炉渣显热 + 煤气带走热 + 炉体散热。元素氧化是主要热源——硅氧化放热最猛，碳氧化次之。因此铁水含硅量直接决定废钢配比：硅高则热量富余、可多加废钢；硅低则热量紧张。**「热量不够就加硅铁、热量富余就多装废钢」**，这是转炉操作最经典的调温逻辑。<span class="marginnote">废钢是转炉的「天然冷却剂」：吸收热量熔化而不增加杂质。废钢比每提高 1%，炉温约降 8–10 ℃。转炉热平衡计算（热量收入 = 热量支出）是炉前工每天的基本功。</span>

## 2 吹炼过程中的化学反应

### 2.1 元素的氧化顺序

氧枪吹入的氧气首先与铁反应生成 $\ce{FeO}$，$\ce{FeO}$ 再氧化其他元素。按热力学氧化顺序，**硅最先氧化、锰次之、碳随后、磷在低温段氧化、硫在还原条件下去除**：

$$\ce{[Si] + 2(FeO) -> (SiO2) + 2[Fe]}$$

$$\ce{[C] + (FeO) -> CO\uparrow + [Fe]}$$

方括号表示钢液中组元，圆括号表示渣中组元。碳氧化生成 CO 气泡上浮排出——这就是转炉「火焰」的来源，也是脱碳的驱动力。<span class="marginnote">吹炼前期硅、锰先烧（温度尚低），中期碳开始大量氧化（温度升高），后期进入「脱碳尾声、磷的反扑风险期」。转炉工通过观察炉口火焰（颜色、长度、亮度）判断碳含量——<strong>火焰是转炉的仪表盘</strong>。</span>

### 2.2 脱磷与回磷

磷是高炉铁水带来的主要有害杂质。转炉内脱磷需要**三高**：高碱度渣（$R \approx 3$）、高氧化性（渣中 $\ce{FeO}$ 高）、较低温度：

$$\ce{2[P] + 5(FeO) + 4(CaO) -> (4CaO\cdot P2O5) + 5[Fe]}$$

生成的磷酸钙进入渣中。但**回磷风险**始终存在：后期温度升高、渣中 $\ce{FeO}$ 下降、碱度不足或放渣不净时，渣中 $\ce{P2O5}$ 会被还原回钢液。**转炉出钢前「保碳、压磷、控温」是矛盾的三角**——碳要保、磷要压、温要控，三者互相牵制，是转炉操作艺术的浓缩。

### 2.3 炉渣的泡沫化

吹炼中后期碳大量氧化，CO 气泡在渣层中上浮，渣被吹成泡沫，体积膨胀数倍。**泡沫渣**增大渣钢反应面积、保护炉衬，是脱磷脱碳的好帮手；但泡沫过度则喷溅，甚至「喷炉」造成安全事故。<span class="marginnote">控制泡沫渣靠调节供氧强度与渣中 $\ce{FeO}$：供氧过强、$\ce{FeO}$ 过高都会加剧喷溅。现代转炉用「动态控制」模型实时预测碳温，自动调节氧枪高度与供氧量。</span>

## 3 公式解析：转炉的热平衡方程

转炉操作的核心计算是热平衡——判断一炉铁水能配多少废钢。把热平衡写成简化形式：

$$\sum Q_{\text{收入}} = Q_{\ce{[Si]}} + Q_{\ce{[Mn]}} + Q_{\ce{[C]}} + Q_{\ce{[P]}} + Q_{\text{铁水物理热}} + Q_{\text{渣料}}$$

$$\sum Q_{\text{支出}} = Q_{\text{钢水}} + Q_{\text{炉渣}} + Q_{\text{炉气}} + Q_{\text{炉衬散热}} + Q_{\text{废钢熔化}}$$

对这套方程做三步拆解：

- **第一步，认识收入项**：元素氧化放热是主要热源。Si 氧化 1% 放热约 467 MJ/t 铁水，是「热值之王」；C 氧化到 CO 放热约 114 MJ/t（1%）；Mn、P 各贡献约 80、140 MJ/t。
- **第二步，认识支出项**：钢水升温显热是最大支出（约 0.68 MJ/(t·℃)）；废钢熔化显热 + 潜热约 1.5 MJ/kg；炉渣显热约占 8%。
- **第三步，解废钢比**：令收入 = 支出，未知量废钢量即可解出。**这个方程把「铁水成分 → 废钢配比」变成可算的工程问题**——成分化验单到手，废钢量就有了依据。<span class="marginnote">这套热平衡的思想与《冶金节能》一篇的能量衡算一脉相承：<strong>先把每一笔能量进出列清楚，再谈优化</strong>。转炉热效率约 60–70%，损失的 30% 多在炉气带走的热量——这也是转炉煤气余热回收的出发点。</span>

## 4 转炉冶炼的操作控制

### 4.1 静态控制与动态控制

传统转炉用**静态控制**：按铁水成分、温度、废钢量预先计算供氧量与冷却剂加入量，一炉吹到底。现代大型转炉改用**动态控制**：用副枪（测量钢水温度、碳含量、取样）或炉气分析（CO/$\ce{CO2}$、$\ce{O2}$ 在线）实时反馈，在吹炼后期调整供氧量与冷却剂，把终点碳与终点温度同时打进目标窗口。<span class="marginnote">副枪是现代转炉的「眼睛」：吹炼后期把探头插入熔池，几十秒内返回温度、碳含量与氧活度数据，模型据此预测最佳停吹点。终点命中率从静态控制的 60% 提高到动态控制的 90% 以上。</span>

### 4.2 炉渣操作与炉衬寿命

转炉炉衬用镁碳砖砌筑，寿命以「炉龄」计（现代转炉 5000–20000 炉）。**溅渣护炉**技术：出钢后把含 $\ce{MgO}$ 的高碱度渣用氮气溅到炉衬上，形成保护层，把炉龄从几千炉提到上万炉——这是中国钢厂对世界转炉技术的一大贡献。

### 顶底复合吹炼

现代转炉几乎都采用**顶底复合吹炼**：顶部氧枪主供氧，炉底安装透气砖（或底吹元件）从底部吹入惰性气体（$\ce{N2}$/$\ce{Ar}$）或少量氧。底吹气体的作用远超「搅拌」：

- **强化熔池搅拌**：底吹气泡从炉底上浮，带动整个熔池翻滚，加速渣钢反应与温度均匀。
- **抑制喷溅**：底部气流使熔池运动更平稳，泡沫渣更可控。
- **提高金属收得率与终点命中**：搅拌好，氧的利用率高、渣中 $\ce{FeO}$ 低、脱磷更均匀。

**底吹强度是转炉「细腻程度」的标尺**：老式纯顶吹转炉靠氧枪「硬吹」，终点命中率低；顶底复吹让转炉操作从「大刀阔斧」走向「精雕细琢」。现代复吹转炉的底吹比（底吹氧量/总氧量）约 5–15%，是高品质钢生产的设备前提。

## 5 转炉炼钢的技术经济比较

| 指标 | 转炉 | 电炉 |
| --- | --- | --- |
| 主要原料 | 铁水（80–90%）+ 废钢 | 废钢 + DRI |
| 能源 | 元素氧化化学热 | 电能 + 化学热 |
| 冶炼周期 | 20–40 min | 35–60 min |
| 吨钢能耗（标煤） | 较低（负能炼钢） | 较高（电耗为主） |
| 碳排 | 较高（取决于铁前工序） | 较低（用废钢时） |
| 产品灵活性 | 大批量常规钢种 | 高合金钢、特钢灵活 |

**辨析｜易错点：** 「转炉只能炼普碳钢」是过时印象。现代转炉通过顶底复合吹炼、双渣操作、炉外精炼配合，同样能生产管线钢、汽车板等高品质钢种。转炉与电炉的分工不是「高端/低端」，而是「以铁水为主 vs 以废钢为主」的资源路线选择。

### 转炉的历史与中国的贡献

氧气顶吹转炉（LD 法）1952 年诞生于奥地利林茨（Linz）与多纳维茨（Donawitz）钢厂，以一座旧转炉改造试验成功。它只用 20 分钟就把一炉铁水炼成钢，把平炉的 6 小时节奏压缩到近乎「流水线」——人类第一次把炼钢变成了「连续可调的工业过程」。此后 BOFLD 快速取代平炉与贝塞麦转炉，到 1970 年代成为世界炼钢的绝对主力。

中国对转炉技术的贡献同样值得记一笔：**溅渣护炉**技术把转炉炉龄从几千炉提升到 1–2 万炉，让中国转炉的炉衬寿命长期领先世界；同时转炉煤气回收（OG/LT 系统）、负能炼钢等技术的普及，让中国转炉的能耗指标进入世界先进行列。**技术扩散不是简单的复制，而是被使用者的工况改写了基因**——这是冶金工程史给我们的一个注脚。

### 转炉与「从极限到大模型」的连接

转炉在 20 分钟内把一炉铁水炼成钢，靠的是「把无数个微观反应精确编排」——而精确编排的前提是精确测量与快速决策。这正是《冶金智能化》一篇里副枪、炉气分析与终点动态控制的用武之地。转炉是最典型的「反应速度远快于人工决策速度」的工业对象：一炉吹炼中元素浓度每秒都在变，人工只能看火焰、靠经验，模型却能以秒级频率推算。**转炉从「经验炉」走向「模型炉」，是工业智能最生动的缩影。**

## 6 小结

- 转炉炼钢 = 用氧气把铁水中的 C、Si、Mn、P 氧化掉；脱碳是主反应，CO 气泡是驱动力。
- 脱磷需「高碱度 + 高氧化性 + 较低温」三高；后期回磷风险是操作主线。
- **热平衡方程决定废钢配比**：Si 是热值之王，温度靠元素氧化热维持。
- 动态控制（副枪/炉气分析）把终点命中率提到 90% 以上。
- 转炉与电炉是资源路线分工，不是高低端分工。
- 顶底复吹是现代转炉的标配：底吹搅拌强化反应、抑制喷溅、提高终点命中率。
- 从 LD 法诞生到溅渣护炉，转炉史是「效率革命 + 本土创新」的双重叙事。
