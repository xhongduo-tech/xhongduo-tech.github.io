## 为什么从承载力开始

「万丈高楼平地起」——这里的「地」不是地面，而是**地基**。上部结构的一切荷载，最终都落在基础下那一层土上。**承载力（bearing capacity）** 回答的就是地基的第一问题：**这块土能安全扛住多大的力？** 它把前面所有章节——有效应力、抗剪强度、压缩性——收敛成设计院桌上那一张基础图。<span class="marginnote">古罗马人建斗兽场靠试错，中世纪的桥墩靠「先修了再说」。直到 1943 年太沙基发表《理论上力学》，第一次用强度理论推出地基破坏的定量公式，承载力才从工匠经验变成工程师的计算。本节就以它为起点。</span>更妙的是：承载力公式三项的结构——黏聚力一项、埋深一项、宽度一项——本身就是整个强度理论的「代数缩影」。

## 1 浅基础与破坏模式

**浅基础（shallow foundation）** 是指埋深 $D_f$ 与基础宽度 $B$ 之比很小（通常 $D_f/B \le 1$）的基础：独立基础、条形基础、筏板基础。荷载沿基底直接传给浅层土。而**深基础**（桩、沉井）把荷载传向深处——那是下一节的战场。

地基在极限荷载下的破坏方式有**三种**，取决于土的密实度与基础埋深：

- **整体剪切破坏（general shear failure）**：荷载达到极限时，基础下方形成一个连续的滑动面一直延伸到地表，基础突然下沉——**密实砂与硬黏土**的典型破坏。
- **局部剪切破坏（local shear failure）**：滑动面不完全延伸到地表，基础下沉伴随土体侧向挤动——**中等密实**土的破坏。
- **冲剪破坏（punching shear failure）**：基础「刺入」土中，周围土几乎不动，基础大幅下沉——**松砂、软土**上的破坏，靠「扎进去」而不是「滑出去」承担荷载。

**辨析｜易错点：** 三种破坏的区别在于滑动面「到不到地表」。工程中最危险的是**整体剪切**——它有明确的「失稳」瞬间；松砂的冲剪破坏则更像「沉下去」，强度不亮红灯、但沉降早已超标——这正是「强度校核之外还得校核沉降」的根源。

## 2 太沙基极限承载力公式

太沙基（1943）从塑性理论推出条形基础在**整体剪切破坏**下的极限承载力 $q_u$：

$$q_u = cN_c + qN_q + \frac{1}{2}\gamma B N_\gamma$$

- $c$：地基土的黏聚力；$q = \gamma D_f$：基底处的**上覆有效应力**（埋深项）；
- $B$：基础宽度；$\gamma$：基底以下土的重度；
- $N_c, N_q, N_\gamma$：**承载力系数**，只与内摩擦角 $\phi$ 有关：

$$N_q = \tan^2\left(45^\circ+\frac{\phi}{2}\right)e^{\pi\tan\phi}, \qquad N_c = \frac{N_q - 1}{\tan\phi}, \qquad N_\gamma = 2(N_q+1)\tan\phi$$

对**方形**与**圆形**基础，太沙基给出经验形状修正：方形 $q_u = 1.3cN_c + qN_q + 0.4\gamma B N_\gamma$，圆形把 $0.4$ 换 $0.3$。<span class="marginnote">注意公式里三类的承载机制：$cN_c$ 靠土的「咬合与胶结」、$qN_q$ 靠基础两侧的压重、$\gamma B N_\gamma/2$ 靠基底土的摩擦自持。宽度 $B$ 只出现在最后一项——这是「基础越宽承载力越大」的数学来源，但它增长很慢，所以宽基础主要买的是「沉降表现」而不是「承载力」。</span>

**重点：$\phi = 0$ 的饱和黏土（$c_u$ 不排水强度）下，$N_q = 1, N_c = 5.7, N_\gamma = 0$，条形基础极限承载力退化为 $q_u = c_u N_c = 5.7c_u$。** 常数 $5.7$（按塑性理论应为 $\pi + 2 = 5.14$，太沙基取整并加修正）是每个岩土工程师都该记得的数字——它告诉你「软黏土上基础能扛多少」其实就是黏聚力乘个常数。

## 3 公式解析：三项各代表什么

**第一步，$cN_c$——黏聚力项。** 破坏面上土的黏聚力贡献强度，正比于 $c$ 与「破坏面的几何」——后者被吸进 $N_c$。

**第二步，$qN_q$——埋深项（上覆荷载项）。** 基础埋得越深、两侧压土越重，基底土就越难被「顶开」，像用书压住纸再抽——所以这项目本身与 $B$ 无关，只与埋深 $D_f$ 和重度有关。

**第三步，$\frac{1}{2}\gamma B N_\gamma$——宽度项（土的自重项）。** 基底以下土体剪切时需要克服自身重力与摩擦，基础越宽，参与抵抗的土体越大。$\gamma B/2$ 是「参与土体的等效重量」，$N_\gamma$ 吸收破坏机构的几何。

**三项的物理分工如此清晰，** 这正是太沙基公式成为经典的原因：它不像纯数学推导那样「黑箱」，而是把地基承载分解成「黏聚力 + 压重 + 摩擦自持」三份可理解的力量。<span class="marginnote">这套「分项 + 系数」的思想后来被 Meyerhof、Hansen、Vesic 发扬：他们给每项加上形状系数、深度系数、倾斜系数、偏心系数，公式从三项变成三组乘积——但骨架仍是太沙基的三项。理解骨架，等于理解了整族公式。</span>

## 4 地下水位的影响：用有效应力改写

承载力公式里的 $\gamma$ 与 $q$ 都必须用**有效重度**——因为有效应力才是强度之源。地下水位的位置分三种情况（Das §3.6）：

- **情形一：水位在基底以上（$0 \le d_1 \le D_f$）。** 上覆土部分浮起，$q = \gamma d_1 + \gamma'(D_f - d_1)$；第三项 $\gamma$ 一律换成浮重度 $\gamma'$。
- **情形二：水位在基底以下 $0 \le d_2 \le B$。** 上覆土无水、$q = \gamma D_f$；第三项用平均重度 $\gamma_{avg} = \gamma' + \dfrac{d_2}{B}(\gamma - \gamma')$。
- **情形三：$d_2 \ge B$。** 水位鞭长莫及，公式原样使用。

**辨析｜易错点：** 承载力计算里混用总重度与浮重度，是最高频的失误——而它只差一个「地下水位线画在哪里」。画好水位线、逐项核对 $\gamma$ 用没用水下修正，比任何高阶理论都值钱。

## 5 允许承载力：强度与沉降的合谋

极限承载力 $q_u$ 是「最后的底线」，设计用的是**允许承载力（allowable bearing capacity）**：

$$q_{all} = \frac{q_u}{FS}$$

安全系数 $FS$ 一般取 3。但**重点：很多情况下地基的瓶颈不是强度，而是沉降。** 一栋楼在松砂上可能 $FS$ 足够、却沉降 200 mm——人住不了。于是规范往往另给一套**按沉降控制的允许承载力**（如天然地基允许沉降 25 mm），两本账取小值。<span class="marginnote">于是承载力设计实际是一条链条：算出 $q_u$ → 除安全系数得强度允许值 → 与沉降允许值比大小 → 取小者为设计值。强度「够」不等于「可用」，这个双控思想贯穿基础工程全书，是岩土与结构设计最大的气质差异。</span>

## 6 从公式到设计

**持力层选择**：基础尽量落在密实、均一的土层上；承载力不足就加深、加宽，或改用下节的桩基「绕过」软层。
- **偏心与倾斜荷载**：用 Meyerhof 的**有效面积法**处理——偏心荷载等价成减小了的有效基底面积，再按中心荷载公式算。
- **地基处理 + 基础选型联动**：软弱地基可以先换填、强夯，再上浅基础——第 2 篇压实、第 7 篇地基处理在这里汇合。<span class="marginnote">现代设计早已不用「手算一条公式包打天下」：有限元弹塑性分析能模拟真实破坏面（第八级《数值方法》的内容），而机器学习正被用来标定土性参数（第十级《机器学习》）。但公式给出的量级直觉，永远是「结果离谱不离谱」的第一道校验。</span>

## 7 小结

- 浅基础破坏分**整体剪切、局部剪切、冲剪**三型，滑动面形态各不相同。
- 太沙基承载力公式 $q_u = cN_c + qN_q + \tfrac{1}{2}\gamma BN_\gamma$ 由黏聚力、埋深、宽度三项组成。
- 承载力系数只随 $\phi$ 变；$\phi = 0$ 黏土退化为 $q_u \approx 5.7c_u$。
- 地下水位用**有效重度**修正公式，三种情形分别处理。
- 设计值取「强度允许值」与「沉降允许值」的**较小者**——双控才是设计真身。
