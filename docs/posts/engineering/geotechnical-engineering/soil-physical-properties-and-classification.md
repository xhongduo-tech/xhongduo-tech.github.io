## 为什么从土的性质开始

钢材有牌号，混凝土有标号，工程师拿到手就可以算。但**土**不行：同一块地基里，半米厚的粉砂与黏土层的强度可能相差十倍，而它的出厂证明——一份钻孔记录——只覆盖了千万分之一的空间。<span class="marginnote">这正是太沙基那句名言的残酷内核：岩土工程师算的是「概率」，而钢结构工程师算的是「确定」。本专题的所有篇章，都是在「承认不确定性」的前提下努力把土量化。</span>所以岩土工程的第一课，不是计算，而是**描述**：把一团说不清的土，用几个可测、可复现的指标翻译成数字与类别。这些指标贯穿本专题全部 12 讲——有效应力、固结、抗剪强度、承载力，句句不离它们。把本节读透，等于为整座大厦打了地基。

## 1 三相体系：土的最小写真

取一块湿润的土，掰开看：它有固体的矿物颗粒、孔隙里的水、以及混在其中的空气。于是土被理想化为一个**三相体系（three-phase system）**——**固相（soil solids）、液相（water）、气相（air）**。三相各自占多少、各有多重，决定了土的松紧、软硬、透水与压缩的全部宏观表现。

为了把这个「比例」量化，土力学定义了五个基本指标，全部以三相图为出发点：

**孔隙比 e（void ratio）**：孔隙体积与土粒体积之比，$e = V_v / V_s$。<span class="marginnote">$e$ 是岩土力学里出镜率最高的指标：后面固结、渗透、密实度全用它。它是无量纲比值，跟土粒的绝对大小无关——一勺粉土和一卡车砾石可以有同一个 $e$。</span>
**孔隙率 n（porosity）**：孔隙体积占总体积之比，$n = V_v / V$，常用百分数表示。
- **含水率 w（moisture content）**：水的重量与土粒重量之比，$w = W_w / W_s \times 100\%$。<span class="marginnote">注意分母是「干土重」而不是总重——这有点像统计里的「以某一年为基期」：只有固定在土粒重量上，含水率才具有可比性。这一约定在测定与换算中处处生效。</span>
- **饱和度 S（degree of saturation）**：孔隙中水的体积占孔隙体积之比，$S = V_w / V_v \times 100\%$。
- **土粒比重 G_s（specific gravity of solids）**：土粒重度与 4℃ 纯水重度之比，$G_s = \gamma_s / \gamma_w$，一般矿物在 2.65～2.72 之间。

![土的三相图](/images/geotechnical-engineering/soil-physical-properties-phase-diagram-1.svg)

这五个指标只有四个是独立的（可测三个、推出其余），因为它们同源于三相图，满足一个等式约束——这正是下一节「换算」要展开的内容。**重点是：土力学里一切「多重」的表达，都不过是三相比例的另一种说法。** 干重度、饱和重度、浮重度，本质上是把三相比例折算进单位体积的「重量」。

## 2 三相指标之间的换算

先记住两组最基础的代数关系：

$$n = \frac{e}{1+e}, \qquad e = \frac{n}{1-n}$$

再从定义直接推：$w = \dfrac{S e}{G_s}$，整理成更常用的形式：

$$e = \frac{w G_s}{S}$$

**重点：只要知道 $w$、$G_s$、$S$ 三者，孔隙比 $e$ 就被唯一确定。** 特别地，饱和土 $S = 1$，于是 $e = w G_s$——这解释了为什么饱和黏土越湿，孔隙比越大。

土的**重度**（单位体积的重量）也全部可由三相比例表达：

$$\gamma_d = \frac{G_s \gamma_w}{1+e}, \qquad \gamma = \frac{(G_s + S e)\gamma_w}{1+e}, \qquad \gamma_{sat} = \frac{(G_s + e)\gamma_w}{1+e}$$

其中 $\gamma_d$ 是干重度、$\gamma$ 是天然重度、$\gamma_{sat}$ 是饱和重度。水下土体还要引入**浮重度（submerged unit weight）**：

$$\gamma' = \gamma_{sat} - \gamma_w$$

**辨析｜易错点：** ① 重度 $\gamma$ 是「力 / 体积」（$\mathrm{kN/m^3}$），密度 $\rho$ 是「质量 / 体积」（$\mathrm{kg/m^3}$），两者差一个重力加速度 $g$，混用会直接差出 9.8 倍；② 含水率、饱和度的百分号只是习惯写法，代入公式一律用小数；③ 天然状态下土很少完全饱和或完全干燥，$S$ 介于 0 与 1 之间，两端只是特例。

## 3 粒径分布与级配

把土晒干、过一套标准筛，称出各筛盘上的土重，就能画出**颗粒级配曲线**。曲线越平缓，说明土粒「大中小都有」，工程上称为**级配良好**；曲线陡峭集中，则**级配不良**。

曲线的形状用两个系数刻画——取曲线累计通过率为 60%、30%、10% 时对应的粒径 $D_{60}$、$D_{30}$、$D_{10}$：

$$C_u = \frac{D_{60}}{D_{10}}, \qquad C_c = \frac{D_{30}^2}{D_{60} \cdot D_{10}}$$

$C_u$ 是不均匀系数，越大说明粒径跨度越宽；$C_c$ 是曲率系数，反映曲线中段是否平滑连续。<span class="marginnote">级配良好的土，大小颗粒相互嵌挤、孔隙被小颗粒填实，压实后强度高、渗透性低、压缩性小——这就是为什么「级配良好的砾砂」是极好的路基与地基材料。</span>

按粒径，土被分成四个大类（USCS 粒径界限）：**砾石（gravel）**大于 4.75 mm、**砂（sand）**4.75～0.075 mm、**粉土（silt）**0.075～0.002 mm、**黏土（clay）**小于 0.002 mm。<span class="marginnote">4.75 mm 对应 4 号筛，0.075 mm 对应 200 号筛——筛号与毫米的换算关系本身就是工程史的一部分。更细的粉土黏土筛不动，要用沉降法（水析法）按斯托克斯定律分级，见第四级《流体力学》的相关内容。</span>粒径大小直接决定了土的自重与表面力之比：砂的颗粒行为由重力主导，黏土的行为则由颗粒表面的电化学力主导——这是两条完全不同的物理主线。

## 4 界限含水率：细粒土的语言

对黏性土，光有粒径还不够，因为同样的粒径分布，含水率一变，土可以在「流态」「塑态」「半固态」之间切换。于是有了**阿太堡界限（Atterberg limits）**：

- **液限 LL（liquid limit）**：土由塑性转为流动状态时的含水率。
- **塑限 PL（plastic limit）**：土由半固态转为塑性状态时的含水率。
- **塑性指数 PI**：$PI = LL - PL$，塑性状态的含水率宽度，是细粒土分类的核心参数。

液限用卡萨格兰德杯（Casagrande cup）或落锥仪测定，塑限用「搓条」法（把土搓成 3 mm 直径的细条、恰在断裂处的含水率）。工程中还常用**液性指数**：

$$LI = \frac{w - PL}{PI}$$

$LI < 0$ 说明天然含水率低于塑限，土呈固态或半固态；$LI > 1$ 则土处于流动状态、几乎无强度。**辨析｜易错点：** 阿太堡界限只对粉土、黏土这类细粒土有意义，砂砾根本搓不成条；对细粒土也不能只用 $LL$ 或 $PI$ 之一——分类时两者是搭配使用的（见下节塑性图）。

## 5 公式解析：重度与孔隙比的统一推导

前面罗列了四五个公式，与其背它们，不如推一次。核心是下面这一条：

$$\gamma = \frac{(G_s + S e)\gamma_w}{1+e}$$

**第一步，回到三相图写两个总量方程。** 总体积 $V = V_s + V_v$，总重量 $W = W_s + W_w$。定义 $V_v = e V_s$，于是 $V = V_s (1 + e)$。

**第二步，把重量全部折算到 $V_s$ 与 $\gamma_w$ 上。** 土粒重 $W_s = G_s \gamma_w V_s$；水的重量 $W_w = \gamma_w V_w = \gamma_w \cdot S V_v = \gamma_w S e V_s$。<span class="marginnote">这里唯一的代数技巧是「用 $S$ 把 $V_w$ 换成 $S e V_s$」——把三相图上右栏的重量全部翻译成「$\gamma_w \times$ 系数 $\times V_s$」的形式。</span>

**第三步，作比。** 重度是重量除以体积：

$$\gamma = \frac{W}{V} = \frac{(G_s + S e)\gamma_w V_s}{V_s(1+e)} = \frac{(G_s + S e)\gamma_w}{1+e}$$

取 $S = 0$ 得 $\gamma_d = \dfrac{G_s \gamma_w}{1+e}$，取 $S = 1$ 得 $\gamma_{sat} = \dfrac{(G_s+e)\gamma_w}{1+e}$。**一条式子、三次代入，四个重度全出来了。** 这种「从定义出发、把变量统一到两个基本量上」的推导习惯，正是后续一切土力学公式的共同骨架。

## 6 土的工程分类：USCS 与 AASHTO

土的种类连续变化，工程却需要离散的「类别」，于是出现了两套主流分类体系。

**USCS（统一分类法，Unified Soil Classification System）**：先看 200 号筛（0.075 mm）通过率是否超过 50% 划分粗细。粗粒土按级配与含细量给两个字母，如 GW（级配良好的砾）、SP（级配不良的砂）；细粒土用**塑性图（plasticity chart）**——横轴 $LL$、纵轴 $PI$，用一条 **A 线** $PI = 0.73(LL - 20)$ 把无机黏土（CL、CH，A 线以上）与粉土（ML、MH，A 线以下）分开。有机质土记 OL、OH，泥炭记 PT。

**AASHTO（美国公路与运输官员协会）**：面向路基，按筛分与塑性指标把土分成 A-1 到 A-7，并计算**组指数（group index）**：

$$GI = (F - 35)\big[0.2 + 0.005(LL - 40)\big] + 0.01(F - 15)(PI - 10)$$

其中 $F$ 是 200 号筛通过率（%）。$GI$ 越大，路基质量越差。<span class="marginnote">AASHTO 是「用途导向」的分类——它不关心土在地质上是什么，只关心「垫在公路上行不行」。这提醒我们：分类是为决策服务的工具，没有唯一的「正确分类」，只有「够不够用」。</span>

**辨析｜易错点：** 同一份土样用 USCS 与 AASHTO 分类，结果可以不同——因为两套体系的服务对象不同；引用土的类别时必须注明用了哪套标准，否则工程师之间会「鸡同鸭讲」。

## 7 小结

- 土是**三相体系**，五个基本指标（$e, n, w, S, G_s$）有内在约束，只须测定三个。
- 核心换算：$e = \dfrac{w G_s}{S}$，$\gamma = \dfrac{(G_s + S e)\gamma_w}{1+e}$，一次推导覆盖干、天然、饱和、浮四种重度。
- 粗粒土用**级配**描述（$C_u, C_c$），细粒土用**界限含水率**描述（$LL, PL, PI, LI$）。
- 工程分类（USCS / AASHTO）把连续变化的土离散成类别，须注明所用标准。
