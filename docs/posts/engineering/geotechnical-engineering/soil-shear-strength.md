## 为什么从抗剪强度开始

固结篇回答「沉多少、沉多久」，抗剪强度回答的是另一个生死问题：**土会在什么状态下失去承载力、沿哪个面滑下去。** 注意一个反直觉的事实——土极少被「压坏」，绝大多数破坏是**剪切破坏**：边坡沿滑动面滑落、地基下面的土沿剪切带挤出、挡土墙被墙后土体的剪切滑动推倒。<span class="marginnote">把一块土放在压力机里压，它不会像混凝土那样「炸碎」，而是在内部形成一组剪切裂缝、被「剪」成两半。所以岩土工程的一切「强度」问题，归根结底都是「抗剪强度」问题——地基承载力、边坡稳定、土压力，全是它的应用。</span>这一节是整个专题里最「力学」的一节：它要用到应力圆、主应力这些材料力学的语言，再把它们与有效应力原理熔在一起，形成岩土强度理论的骨架。老子的「柔水攻强」放在这里尤其贴切：土含水则柔，而它恰恰在「水」这个因素上最敏感——这正是本节的核心张力。

## 1 破坏准则：莫尔-库仑准则

库仑（Coulomb）早在 1776 年就提出土的抗剪强度公式，后与有效应力原理结合成今天的形式——**莫尔-库仑破坏准则（Mohr-Coulomb failure criterion）**：

$$\tau_f = c' + \sigma' \tan\phi'$$

- $\tau_f$：破坏面上的抗剪强度；
- $\sigma'$：破坏面上的**有效**正应力；
- $c'$：**有效黏聚力（effective cohesion）**，粒间胶结与吸力贡献的部分；
- $\phi'$：**有效内摩擦角（effective angle of internal friction）**，粒间摩擦与咬合贡献的部分。

**重点：抗剪强度不是一个常数，而是随有效正应力增大而增大的函数。** 压得越紧、剪坏它越费劲——这像一叠扑克牌：压得越紧，横向抽动越难。<span class="marginnote">理解这一点就理解了为何「深处土强度高」：深处有效应力大。同样也理解了为何砂土在松弛状态几乎没有强度（摩擦要靠有效应力撑着），而黏土靠黏聚力还能立起一定的直立边坡。</span>

**辨析｜易错点：** 用总应力写 $\tau_f = c + \sigma\tan\phi$ 在数学上同样成立，但参数 $c, \phi$ 是「表观值」，随排水条件变来变去；只有有效应力参数 $c', \phi'$ 才是土的内在属性。工程计算必须分清用的是哪一套参数。

## 2 莫尔圆：一点应力的完整画像

某一点的应力状态，只用大小主应力 $\sigma_1$、$\sigma_3$ 就能用**莫尔圆（Mohr circle）** 完整表达：横轴为正应力，纵轴为剪应力，圆心 $(\frac{\sigma_1+\sigma_3}{2}, 0)$、半径 $\frac{\sigma_1-\sigma_3}{2}$ 的圆，代表了过该点的所有平面上的应力组合。莫尔圆上任意一点的坐标，就是某一倾角平面上的正应力与剪应力。

判断土会不会破坏，就两步：把莫尔圆画出来，看它**碰没碰到破坏包线 $\tau_f = c' + \sigma'\tan\phi'$**。圆在包线下方——安全；圆恰好相切——临界，切线位置对应**破坏面**；圆穿过包线——早已破坏。

![莫尔圆与破坏包线](/images/geotechnical-engineering/soil-shear-mohr-circle-1.svg)

**莫尔圆随荷载「长大」：** 荷载使 $\sigma_1$ 增大而 $\sigma_3$ 不变，圆的半径不断变大，直到某一点与包线相切——破坏就发生了。相切点的剪应力就是该时刻的抗剪强度。

## 3 公式解析：破坏时的大小主应力关系

把「莫尔圆与包线相切」翻译成代数，就得到三轴试验最常用的破坏公式。设破坏时主应力为 $\sigma_1, \sigma_3$：

$$\sigma_1 = \sigma_3 \tan^2\left(45^\circ + \frac{\phi}{2}\right) + 2c\,\tan\left(45^\circ + \frac{\phi}{2}\right)$$

**第一步，写相切条件。** 圆心到包线的距离等于圆半径。包线 $\tau = c + \sigma\tan\phi$，圆心 $(\frac{\sigma_1+\sigma_3}{2}, 0)$，点到直线距离公式给出：

$$\frac{\sigma_1 - \sigma_3}{2} = \frac{\sigma_1 + \sigma_3}{2}\sin\phi + c\cos\phi$$

**第二步，整理。** 把含 $\sigma_1, \sigma_3$ 的项分到两边，利用三角恒等式 $\dfrac{1+\sin\phi}{1-\sin\phi} = \tan^2(45^\circ+\tfrac{\phi}{2})$、$\dfrac{\cos\phi}{1-\sin\phi} = \tan(45^\circ+\tfrac{\phi}{2})$。

**第三步，代入。** 三行代数后就得上面的公式。<span class="marginnote">这公式的工程含义是「知道了 $\sigma_3$、$c'$、$\phi'$ 就能预言 $\sigma_1$ 多大时破坏」——三轴试验的全部读数都浓缩在这一条式子里。$\tan^2(45^\circ+\phi/2)$ 常记作 $N_\phi$，后面承载力一节还会见到它。</span>

## 4 三轴试验：CD、CU、UU

测定 $c', \phi'$ 的标准仪器是**三轴试验仪**：圆柱试样先受围压 $\sigma_3$ 固结，再轴向加偏应力 $(\sigma_1 - \sigma_3)$ 直到剪坏。三个字母的组合代表两种关键控制——**固结与否（C/U）**与**排水与否（D/U）**：

- **CD（固结排水）**：加载全程允许排水，孔隙水压力始终为零，测得的参数直接是有效应力参数 $\phi'$。过程缓慢（几小时到几天），是最「标准」的试验。
- **CU（固结不排水）**：固结后关闭排水阀、快速剪切，同时量测孔隙水压力——用 $u$ 换算出有效应力，同样得到 $\phi'$。快且实用。
- **UU（不固结不排水）**：加载全程不排水，围压完全由孔隙水承担，有效应力不增加——于是饱和黏土测出的**不排水抗剪强度 $c_u$** 与围压无关，$\phi_u = 0$。

**辨析｜易错点：** UU 试验对饱和黏土给出 $\phi_u = 0$、$\tau_f = c_u$，这不是「土没有摩擦」，而是**有效应力没变**——总应力增加的每一分都被孔隙水压力吃掉。这是初学最容易误解的地方：$c_u$ 是特定排水条件下的「表观」指标，离开工况谈 $c_u$ 毫无意义。

## 5 孔隙水压力系数与有效应力强度参数

CU 试验里那根孔隙水压力计，就是有效应力原理的「活见证」。**斯肯普顿（Skempton）** 给出不排水条件下孔压增量：

$$\Delta u = B\left[\Delta\sigma_3 + A(\Delta\sigma_1 - \Delta\sigma_3)\right]$$

其中 $B$ 与 $A$ 是**孔隙水压力系数**。$B$ 反映土体在围压下的饱和程度——饱和土 $B \approx 1$；$A$ 反映剪切时孔压的响应——正常固结黏土 $A$ 为正（剪切产生正孔压、有效应力下降、强度被削弱），超固结黏土 $A$ 可为零甚至为负。<span class="marginnote">$A$ 的符号就是「土是越剪越软还是越剪越硬」的开关：正常固结土剪着剪着孔隙水压力上升、有效应力下降、越来越软（应变软化）；这直接解释了灵敏黏土和液化砂的失稳根源。</span>

测出孔压、还原有效应力，就能把所有试验统一到**有效应力强度参数 $c', \phi'$** 上——这是强度理论真正的终点：排水也好、不排水也好，破坏只认有效应力。

## 6 无侧限抗压强度与灵敏度

**无侧限压缩试验**是三轴 UU 的一个特例：围压为零，直接轴向压到破坏，测得**无侧限抗压强度 $q_u$**。饱和黏土 $q_u$ 与 $c_u$ 的关系是

$$q_u = 2c_u$$

**重点：这是一条漂亮的几何结论——$\phi_u=0$ 的莫尔圆半径就是 $\sigma_1/2 = q_u/2$，而破坏包线是水平线 $\tau = c_u$，相切即 $c_u = q_u/2$。** 用它测强度又便宜又快速，是工程现场最常用的「土强度体温计」。<span class="marginnote">它的姊妹概念是<strong>灵敏度（sensitivity）</strong> $S_t$：原状土与重塑土无侧限强度之比。$S_t > 4$ 即「灵敏黏土」，一扰动强度骤降——中国东南沿海的软土灵敏度常在 3～8 之间，施工机械一过，原地基强度先塌一半。</span>

## 7 小结

- 土绝大多数破坏是**剪切破坏**；抗剪强度由莫尔-库仑准则描述：$\tau_f = c' + \sigma'\tan\phi'$。
- 破坏判据是**莫尔圆与破坏包线相切**，切线处即破坏面。
- 破坏时主应力关系 $\sigma_1 = \sigma_3\tan^2(45^\circ+\tfrac{\phi}{2}) + 2c\tan(45^\circ+\tfrac{\phi}{2})$ 由相切条件直接推出。
- 三轴试验 CD/CU/UU 对应不同排水条件；UU 对饱和黏土给出 $\phi_u = 0$、$\tau_f = c_u$。
- 有效应力参数 $c', \phi'$ 才是土的固有属性；$q_u = 2c_u$、灵敏度 $S_t$ 是现场快速判据。

在下一节，我们将把「强度」放到动荷载下检验：地震一来，饱和砂土为什么会瞬间「化成水」——这就是**土动力学与地基抗震（液化）**。
