## 为什么从机械零件疲劳设计开始

绝大多数机械零件的失效不是一次过载拉断，而是**在反复交变载荷下慢慢累积损伤、最后猝然断裂**——这就是**疲劳（fatigue）**。轴、齿轮、弹簧、连杆、叶片，凡是承受循环载荷的零件，设计时都要过疲劳这一关。韩非子说「千里之堤溃于蚁穴」，疲劳正是那个「蚁穴」：每次载荷循环留下一点点看不见的损伤，几十年后一次不起眼的过载就把零件送走。<span class="marginnote">1842 年法国凡尔赛铁路一列火车因车轴疲劳断裂而脱轨，震惊欧洲，随后德国工程师沃勒（August Wöhler）在 1850 年代用旋转弯曲试验系统测定钢的疲劳性能，建立了第一条 <strong>S–N 曲线</strong>——疲劳研究由此成为一门定量科学。</span>

疲劳设计在课程里的位置很特别：它把《材料力学》的交变应力、《工程材料力学性能》的疲劳试验数据，与《机械设计》的设计准则缝合在一起。本系列《联接与支承零件》一篇里那些轴的疲劳断裂、齿轮的齿根折断，本质都是同一个问题——**交变应力下的累积损伤**。掌握疲劳设计，就掌握了机器寿命的「算命术」。<span class="marginnote">连接主线：Miner 累积损伤理论把疲劳寿命写成「损伤的线性叠加」，<strong>它在数学上就是第一级概率论里「期望的线性叠加」的工程翻版</strong>——把不可观测的微观损伤，用一个可加和的标量来建模。这种「用一个标量简化复杂过程」的建模思路，在后续所有工程学科里反复出现。</span>

疲劳设计还有一层「看不见」的色彩：疲劳过程在零件外观上毫无预兆——裂纹在内部萌生、缓慢扩展，直到临界尺寸才突然失稳。所以疲劳寿命不是「检查出来的」，而是「设计出来的」：从选材、结构到表面处理，每一步都决定寿命的数量级。这正是把疲劳单列一篇的原因——它的方法论与静强度设计完全不同，值得一套独立的工具。

## 1 交变应力：零件的「呼吸」

零件承受的应力随时间变化，就构成**交变应力**。描述一个循环需要几个量：**最大应力 $\sigma_{\max}$**、**最小应力 $\sigma_{\min}$**、**应力幅 $\sigma_a = (\sigma_{\max}-\sigma_{\min})/2$**、**平均应力 $\sigma_m = (\sigma_{\max}+\sigma_{\min})/2$**，以及**循环特性 $R = \sigma_{\min}/\sigma_{\max}$**。三种典型循环：<span class="marginnote">循环特性 $R$ 是疲劳问题的「身份证」：<strong>$R=-1$ 是对称循环（轴旋转弯曲，应力正负交替），$R=0$ 是脉动循环（从零到最大，如齿轮单向弯曲），$0<R<1$ 是非对称循环</strong>。绝大多数零件的实际载荷都是非对称的。</span>

**对称循环**（$R=-1$，如旋转轴外层纤维每转一圈拉一次压一次）：对疲劳最不利。
**脉动循环**（$R=0$，如齿轮齿根单向受弯）：疲劳极限高于对称循环。
**非对称循环**（$0<R<1$，如弹簧、螺栓）：平均应力越大，允许的应力幅越小。
**平均应力把应力幅「压缩」**，这是疲劳的一个核心规律——相同应力幅下，平均应力越大越早破坏。

**辨析｜易错点：** 疲劳强度不等于静强度。很多初学者拿抗拉强度 $\sigma_b$ 去校核交变载荷，得出「裕量很大」的错误结论——实际上**交变应力下，即使应力远低于 $\sigma_b$ 甚至低于屈服强度，零件也会在千万次循环后断裂**。这就是为什么铁路车轴、飞机起落架这些「明明很粗」的零件，依然会在服役期断裂。

真实零件承受的往往不是单一循环，而是**随机变幅载荷**：汽车跑一趟长途，路况变化让车轴承受的应力幅时大时小。为了设计，工程师用**雨流计数法**把随机载荷统计成一系列「应力循环」，再按 Miner 理论逐档累加——雨流计数是疲劳寿命评估的标准前置工序，也是随机载荷与寿命公式之间的桥梁。

再算一笔「应力幅的账」：旋转轴某点应力从 $+60$ MPa 变到 $-60$ MPa，则 $\sigma_a = 60$ MPa、$\sigma_m = 0$、$R = -1$；而弹簧从 $+20$ MPa 压到 $+80$ MPa，则 $\sigma_a = 30$ MPa、$\sigma_m = 50$ MPa、$R = 0.25$——**同样 60 MPa 的「摆幅」，因为平均应力不同，疲劳危险程度完全不同**。习惯先把载荷拆成 $\sigma_a$ 与 $\sigma_m$，是疲劳分析的第一基本功。

## 2 S–N 曲线与疲劳极限

**S–N 曲线**（应力-寿命曲线）是疲劳设计的基本数据：以应力幅 $S$ 为纵轴、到破坏的循环次数 $N$ 为横轴（对数坐标），曲线在有限寿命区随 $N$ 增大而下降，最后趋于水平渐近线，这条渐近线对应的应力就是**疲劳极限**——低于它，理论上可以无限循环而不破坏。<span class="marginnote">对钢等铁基材料，疲劳极限以 $10^7$ 次循环为测试基准，常写作 $\sigma_{-1}$（对称循环疲劳极限）；<strong>钢的 $\sigma_{-1}$ 大约在抗拉强度的 40%–50%</strong>。有色金属（铝、铜）的 S–N 曲线没有明显水平段——它们原则上没有疲劳极限，只能规定一个「名义寿命下的应力」。</span>

实际零件的疲劳强度还要打**修正系数**：

**应力集中系数** $K_\sigma$（缺口、台阶、键槽放大局部应力）；
**尺寸系数**（大尺寸零件内部缺陷概率高、疲劳强度下降）；
**表面质量系数**（粗糙表面是裂纹策源地）；
**强化系数**（喷丸、渗碳等表面强化提高疲劳强度）。

这四项修正说明：**手册里的材料疲劳极限，和真实零件的疲劳强度，中间隔着一整套工艺细节**——这正是疲劳设计「经验性」的一面。以表面质量系数为例：同一根轴，精磨表面与粗车表面的疲劳极限可相差近一半，而这两者都远低于手册里的「抛光试样」数据。

疲劳极限怎么用？一句话：**工作应力低于疲劳极限，设计就是「无限寿命设计」；高于疲劳极限，就要落到 S–N 曲线下降段上算有限寿命**。工程上常常先按「无限寿命」校核——若工作应力（乘上各类修正系数）低于疲劳极限，万事大吉；若不满足，才进入 Miner 有限寿命计算。这套「先粗后细」的判断顺序，与静强度设计里「先强度校核、不过再加大尺寸」的套路完全一致。

## 3 公式解析：Miner 累积损伤理论

实际零件的载荷不是恒定应力幅，而是大小交替的**变幅载荷**——今天跑一段平稳路，明天过一个大坑。**Miner 线性累积损伤理论**把各次循环的损伤线性相加：

$$
D = \sum_{i=1}^{k} \frac{n_i}{N_i} = 1 \quad \Rightarrow \quad \text{破坏}
$$

**第一步，读懂符号**：$n_i$ 是应力幅为 $S_i$ 的实际循环次数，$N_i$ 是该应力幅下 S–N 曲线给出的「单独作用时能到破坏的次数」，比值 $n_i/N_i$ 就是这一档应力「消耗掉」的寿命比例（损伤分数）。**总损伤 $D$ 达到 1，零件即破坏**。

在进入算例之前，先补一个概念区分：**有限寿命设计与无限寿命设计**。若工作应力高于疲劳极限（落在 S–N 曲线下降段），零件只能在有限循环内安全，就要按 Miner 理论算「还能用多少次」，这叫有限寿命设计；若工作应力低于疲劳极限，理论上无限循环安全，直接按「无限寿命」设计即可。工程上大量承受交变载荷的零件，恰恰是**工作应力略高于疲劳极限、需要精确算寿命**的中间地带——Miner 理论正是为这块地带而生的。

**第二步，直观理解**：把寿命想象成一根「寿命条」，每经历一次应力循环，就按比例划掉一小段。划掉的比例只取决于「当前应力下的寿命」，与之前经历什么无关——这就是「线性、无记忆」假设，也是 Miner 理论简单而实用的根源。

**第三步，做数字算例**：设某零件承受两档载荷，第一档 $S_1$ 对应 $N_1 = 10^5$ 次寿命、实际循环 $n_1 = 2\times10^4$ 次；第二档 $S_2$ 对应 $N_2 = 10^6$ 次寿命、实际循环 $n_2 = 5\times10^5$ 次。则 $D = 20000/100000 + 500000/1000000 = 0.2 + 0.5 = 0.7 < 1$——尚未破坏，还能继续服役约 $0.3$ 的寿命。

**第四步，认识局限**：Miner 理论假设损伤可线性相加、各应力水平互不影响，实际情况往往有偏差（加载顺序影响寿命：先高后低比先低后高更危险）。工程上因此引入**修正的 Miner 理论**：当损伤度接近某阈值（如 0.7）时就判破坏，把计算误差推向安全侧。

**第五步，代入一张两档载荷表**：

| 应力水平 | 单独寿命 $N_i$ | 实际循环 $n_i$ | 损伤 $n_i/N_i$ |
| --- | --- | --- | --- |
| 高载 $S_1$ | $10^5$ | $2\times10^4$ | 0.20 |
| 低载 $S_2$ | $10^6$ | $5\times10^5$ | 0.50 |

累计损伤 $D = 0.20 + 0.50 = 0.70$，尚未达到 1——若这就是「设计寿命内」的载荷谱，说明剩余寿命余量为 30%。把这张表推广到几十个应力水平，就是标准流程里的「谱载荷疲劳计算」。<span class="marginnote">Miner 理论的工程用法是「谱载荷疲劳」：<strong>先把随机载荷用雨流计数法整理成一系列应力循环，再逐档用 Miner 求和</strong>——这是汽车、风电、航空结构疲劳寿命评估的标准流程。雨流计数、损伤求和，就是现代疲劳设计的流水线。</span>

Miner 理论只处理「应力幅的累积」，而平均应力 $\sigma_m$ 的影响要靠**疲劳极限图**来修正：以 $\sigma_a$ 为纵轴、$\sigma_m$ 为横轴，连接对称循环疲劳极限点（$\sigma_m=0,\ \sigma_a=\sigma_{-1}$）与静强度点（$\sigma_a=0,\ \sigma_m=\sigma_b$）的直线，就是常用的简化 Goodman 直线——落在直线内侧的载荷组合安全。**Goodman 直线是「平均应力压缩应力幅」的定量版**，也是疲劳安全校核的第一张图。

## 4 提高疲劳强度的工程手段

疲劳断裂的裂纹「从表面长出来、从缺口萌生」，对策也就围绕这两点：

**降低应力集中**：轴肩加大圆角、键槽改用盘铣刀钝边、避免尖角——应力集中系数 $K_\sigma$ 每降一点，寿命成倍提升。**降低表面粗糙度**：精磨、抛光可让表面不再成为裂纹策源地。**表面强化**：**喷丸**（高压小钢珠轰击表面，留下残余压应力，裂纹在压应力场里难以张开）、**滚压**、**表面淬火**、**渗碳氮化**——其中渗碳硬齿面齿轮的弯曲疲劳强度可比渗碳前提高数倍。

几个提升效果的直观数字值得记住：喷丸可使表面残余压应力达材料屈服强度的 40%–60%，把疲劳寿命提高数倍；一个没有倒圆的尖角，能让疲劳强度骤降一半以上。**这些数字提醒我们：疲劳寿命对细节极度敏感，一个圆角、一道喷丸，可能决定寿命差一个数量级**——所以疲劳设计手册里充满了「经验修正」。<span class="marginnote">残余压应力是表面强化的物理内核：<strong>喷丸、滚压都在表面「塞进」一层残余压应力，抵消了外载引起的拉应力峰值</strong>。裂纹扩展需要拉应力把裂纹面拉开——压应力让它「夹紧」，于是疲劳寿命跃升。这一招从铁路车轴用到汽车连杆、直升机旋翼。</span>

**辨析｜易错点：** 表面强化与「表面越硬越抗疲劳」并不简单等同。硬化的同时若引入磨削裂纹或过大的残余拉应力（磨削烧伤），反而会加速疲劳——**强化工艺的质量控制（磨削烧检查、喷丸强度验证）是疲劳设计落地的一环**。疲劳是统计问题：同一批零件寿命呈对数正态分布，所以设计时要用「可靠寿命」而非「平均寿命」来定许用应力，这与可靠性工程直接相连。

回看 1842 年凡尔赛火车事故与 1998 年德国 ICE 高速列车轮箍疲劳断裂事故，共同的教训是：**疲劳裂纹可以从一个微小的加工缺陷或材料夹杂开始，在一次次循环里悄悄长大**。今天铁路与航空行业普遍采用「损伤容限设计」——允许结构中存在小裂纹，但通过定期探伤确保裂纹在失稳前被发现。疲劳设计由此从「保证不出裂纹」演进为「管理裂纹的成长」。

## 6 疲劳设计的工程落地

疲劳设计在工程里的完整链条是：**载荷谱统计（雨流计数）→ 材料 S–N 数据（查手册或试验）→ 修正系数（应力集中、尺寸、表面、强化）→ Miner 累积损伤计算 → 寿命判定 → 检修周期**。这条链的每一环都有专门的软件与标准，但「该不该修正、修正多少」的工程经验，仍无法被软件替代。

两个真实案例给点体感。**高铁轮对**：车轮与车轴靠过盈压装，压装端部是应力集中源，设计采用「整体锻造 + 表面喷丸 + 定期探伤」的组合，把疲劳风险控制到极低量级，并按走行公里制定检修周期。**风电齿轮箱**：低速重载、变工况，齿面点蚀与齿根弯曲疲劳是寿命瓶颈，设计按 20 年设计寿命用 Miner 理论校核变载谱，并配套油液监测与振动检测。

这些案例的共同点：**疲劳设计从不是「算一个安全系数」了事，而是「数据 + 修正 + 概率 + 检修」的完整体系**。学会用 Miner 理论算一笔账，只是打开了这套体系的门；真正落地，还要靠标准、数据与现场经验的配合。

现代疲劳计算已经软件化：有限元算出的应力结果（如 Ansys、Abaqus 的输出）可以直接输入疲劳后处理软件（如 fe-safe、nCode），自动完成雨流计数、Miner 求和与寿命云图。**软件把重复劳动交给计算机，但材料数据、修正系数的选取仍是工程师的职责**——这又是一次「算法提速、判断留人」的典型分工，与《智能制造与增材制造前沿》一篇的结论一致。

## 7 小结

- **疲劳**是交变应力下的累积损伤失效，断裂前无宏观塑性变形预警；凡尔赛事故与沃勒实验是它的起点。
- 交变应力用 $\sigma_{\max}$、$\sigma_a$、$\sigma_m$、$R$ 描述；**平均应力越大，允许的应力幅越小**。
- **S–N 曲线**给出应力-寿命关系，水平渐近线即疲劳极限（钢约 0.4–0.5 $\sigma_b$）；实际零件强度要乘四类修正系数。
- **Miner 理论**把损伤线性相加，$D=\Sigma(n_i/N_i)=1$ 判破坏；局限是忽略加载顺序，工程上常取更保守的判据。
- 抗疲劳三件套：**降应力集中、降表面粗糙度、表面强化**（喷丸/滚压/渗碳），核心是给表面注入残余压应力。
- 有限寿命设计与无限寿命设计的分界是疲劳极限；多数交变零件落在「略高于疲劳极限」的中间地带。
- 疲劳设计链条：载荷谱统计 → S–N 数据 → 修正系数 → Miner 计算 → 寿命判定 → 检修周期。
- 检修周期表（走行公里/飞行小时/运行小时）本质是疲劳寿命计算的工程化。
- 疲劳对细节极度敏感：一个圆角、一道喷丸，可能决定寿命差一个数量级。
- 疲劳极限图/Goodman 直线是「平均应力压缩应力幅」的定量版，是疲劳安全校核的第一张图。
- 损伤容限设计允许小裂纹存在、靠定期探伤管理裂纹成长，是铁路航空的通行做法。
- 疲劳软件完成雨流计数与 Miner 求和，但材料数据与修正系数仍需工程师判断。
