## 为什么从摩擦开始

前三章我们始终假设接触面是**光滑**的——约束反力只沿法线方向。但真实世界里没有光滑的接触面：螺栓靠摩擦锁紧，制动器靠摩擦停车，皮带靠摩擦传力，而机器的能量损耗也大半来自摩擦。**摩擦（friction）**是工程里又恨又爱的对象：没有它，一切传动与连接都无法工作；有了它，机械效率被大量吞噬。

工程师对摩擦的态度因而总是「双轨」的：在需要传力与锁紧的地方，想办法**增大**摩擦（刹车片用高摩擦材料、轮胎压出花纹、螺栓头打毛）；在需要减少损耗的地方，又拼命**减小**摩擦（加润滑油、用滚动轴承、抛光摩擦副表面）。同一物理定律，被利用与对抗的两面，贯穿了整部机械史——理解摩擦，等于同时理解了传动、制动与润滑三门学问的出发点。

这一章把「理想化假设」请下神坛，讨论一个更真实的模型。它与后续课程的联系极其紧密：《机械设计》里的螺纹自锁、带传动、轴承设计全部以本章的摩擦角与自锁条件为基础；《机械制造工艺学》里刀具与切屑的摩擦直接决定切削力；甚至机器人的机械手能否稳固抓取，本质也是摩擦问题。<span class="marginnote">达·芬奇是最早系统研究摩擦的人，他在手稿中记录了「摩擦力与载荷成正比、与接触面积无关」的规律，比库仑早了约三百年。科学史常把荣誉记在系统发表者名下，但第一手发现者的直觉同样伟大。</span>

## 1 摩擦的两种基本形式

按运动状态，摩擦分为两大类：

**滑动摩擦（sliding friction）**：两物体接触面间存在相对滑动或滑动趋势时产生的切向阻力。
**滚动摩阻（rolling resistance）**：物体沿接触面滚动时受到的阻碍——注意它本质上是**一个力偶矩**，不是单纯的力。

滑动摩擦又按状态分为**静摩擦**与**动摩擦**。静摩擦发生在接触面没有相对滑动、只有相对滑动趋势时；一旦相对滑动发生，就是动摩擦。两者的大小规律不同，是本章的核心区分。

**滚动摩阻**常被初学者误以为「就是摩擦力小一点」，其实它是另一套机制：轮子压地时接触面会因变形形成一个不对称的压力分布，等效成一个阻碍滚动的**力偶矩** $M_f$，与滚动半径无关，量级远小于同载荷下的滑动摩擦。<span class="marginnote">这就是为什么用滚珠轴承代替滑动轴承能大幅降损——轮子在地面上「滚」的阻力（滚动摩阻）远小于「蹭」的阻力（滑动摩擦）。重物下垫圆木搬运，靠的正是把滑动摩擦转成滚动摩阻。</span>

## 2 静摩擦力与库仑摩擦定律

**静摩擦力**的大小不是固定的，而是**自适应**的：它随驱动力同步增大，但存在上限。这个上限叫**最大静摩擦力（maximum static friction）**，与法向反力成正比——这就是**库仑摩擦定律（Coulomb's law of friction）**：

$$
F_{\max} = f_s \, N
$$

其中 $f_s$ 是**静摩擦因数**，只与两接触面的材料与表面状况有关；$N$ 是法向正压力。一旦驱动力超过 $F_{\max}$，物体开始滑动，此时摩擦力由静摩擦切换为**动摩擦力**：

$$
F' = f \, N
$$

动摩擦因数 $f$ 通常略小于静摩擦因数 $f_s$——这正是「推动一个静止物体比维持它滑动更费力」的物理根源。<span class="marginnote">静摩擦因数 $f_s$ 的典型量级：钢对钢 0.1–0.15，橡胶对混凝土约 0.8，冰对冰低至 0.02。工程手册里这些数都是实验测得，无固定值——遇到关键设计，必须查手册或用试验复核。</span>

**辨析｜易错点：静摩擦力不是 $f_s N$。** $f_s N$ 只是它的**上限** $F_{\max}$，真实静摩擦力 $F$ 在 $0 \le F \le F_{\max}$ 之间，取多少由平衡条件决定。把「$F = f_s N$」直接代入平衡方程，等于假设摩擦已经濒临打滑，多数情况下是错的。正确流程是：**先当作未知数用平衡方程解出 $F$，再检验 $F \le F_{\max}$**。

静摩擦因数的量级对工程判断至关重要，摘几组典型值（无润滑、干接触）：

| 接触面 | 静摩擦因数 $f_s$ | 动摩擦因数 $f$ |
| --- | --- | --- |
| 钢—钢 | 0.15 | 0.10 |
| 钢—铸铁 | 0.30 | 0.18 |
| 橡胶—混凝土 | 0.80 | 0.70 |
| 木材—木材 | 0.50 | 0.30 |
| 冰—冰 | 0.10 | 0.03 |

从表中立刻读出两条工程经验：其一，动摩擦因数总小于静摩擦因数，所以「启动比维持难」；其二，橡胶对混凝土的摩擦因数高达 0.8，这正是轮胎和刹车片材料的选择逻辑。

## 3 摩擦角与自锁

把法向反力 $N$ 与摩擦力 $F$ 合成，得到**全反力（total reaction）** $\boldsymbol{R}$。当 $F$ 增大到 $F_{\max}$ 时，全反力与法线的夹角达到最大值，这个角叫**摩擦角**：

$$
\tan\varphi_f = \frac{F_{\max}}{N} = \frac{f_s N}{N} = f_s, \qquad \varphi_f = \arctan f_s
$$

摩擦角有一个极富魅力的推论：**只要主动力的合力作用线落在摩擦锥内，无论力多大，物体都保持静止**——这就是**自锁（self-locking）**现象。

自锁是工程里最常用的开关：螺纹连接靠自锁保证螺母不会自行松脱，螺旋千斤顶靠自锁保证重物不会压着螺杆自己滑下去，楔形夹具靠自锁夹紧工件。反过来，要让锁住的机构解锁，就必须把力改到摩擦锥之外——门锁的舌头、卡销的设计全在这个几何条件里。

**辨析｜易错点：自锁是「力无关」，不是「摩擦力无限大」。** 自锁成立时，静摩擦力会随主动力同步增大、始终「接得住」，但它仍然受 $F_{\max}$ 约束——只要合力方向在锥内，需要的摩擦力就始终小于上限，因此永远平衡。判断自锁的快捷办法是**比较角度**：主动力合力与法线的夹角 $\alpha \le \varphi_f$ 则自锁，否则滑动。

## 4 考虑摩擦的平衡问题

把摩擦加进受力图，解题流程多了一步「**临界状态试算**」。标准步骤：

1. 取分离体，画全主动力、法向反力与**未知的静摩擦力**（方向取相对运动趋势的反方向）。
2. 列出平衡方程，把摩擦力当普通未知量处理，解出 $F$ 与 $N$。
3. 检验条件 $F \le f_s N$：成立，则平衡成立；不成立，则假设滑动，改用动摩擦 $F' = fN$ 重解。

当题目问「能施加的最大力」「刚好不滑」这类**临界问题**时，直接令 $F = F_{\max} = f_s N$，再联立平衡方程求解。<span class="marginnote">临界问题里「恰要滑而未滑」是一个边界条件，它把不等式变成等式，是求解的关键。很多同学失败不是因为不会列方程，而是不知道什么时候该把 $F$ 取成 $f_s N$——记住口诀：问最大最小 → 取临界；问是否平衡 → 先解后验。</span>

一个经典例子：物块重 $W$ 放在倾角为 $\theta$ 的斜面上，静摩擦因数为 $f_s$。沿斜面方向列平衡，得下滑趋势时 $F = W\sin\theta$、$N = W\cos\theta$。平衡条件要求 $W\sin\theta \le f_s W\cos\theta$，即 $\tan\theta \le f_s$——斜面自锁。当 $\theta = \arctan f_s = \varphi_f$，正是「物块刚好不下滑」的临界倾角。

再举一个更「机械」的例子：螺旋千斤顶。螺纹可展开成一个倾角为 $\lambda$（螺纹升角）的斜面，螺母与螺杆之间的摩擦角为 $\varphi_v$（考虑螺纹剖面的当量摩擦角）。重物下压螺杆时，若 $\lambda \le \varphi_v$，则螺杆自锁——无论重物多重，都不会压着螺杆反转坠落。这就是千斤顶「停在哪就锁在哪」的原理：不是因为它有多大的制动器，而是摩擦几何把下坠的路径彻底封死了。<span class="marginnote">这个例子把「斜面」与「螺旋」联系了起来：螺纹不过是缠绕在圆柱面上的斜面。理解了斜面自锁，就理解了螺纹自锁；而螺纹自锁直接决定螺栓连接、千斤顶、丝杠传动三类最常用机械零件的安全性。</span>

## 5 公式解析：摩擦角与自锁条件

把本章最核心的两个条件放在一起拆解：

$$
\tan\varphi_f = f_s, \qquad \alpha \le \varphi_f \iff \text{自锁}
$$

**第一步，看摩擦角从哪来**：全反力 $\boldsymbol{R} = \boldsymbol{N} + \boldsymbol{F}$，当 $F$ 达到 $F_{\max} = f_s N$ 时，$R$ 与法线的夹角为 $\varphi_f$，且 $\tan\varphi_f = F_{\max}/N = f_s$。摩擦角只是摩擦因数的一个**几何化身**——一个无量纲的数被翻译成一个角度。

**第二步，看自锁为什么与力的大小无关**：主动力合力 $P$ 与法线夹角为 $\alpha$ 时，把 $P$ 分解为法向分量 $P\cos\alpha$ 与切向分量 $P\sin\alpha$。平衡需要摩擦力 $F = P\sin\alpha$，而最大静摩擦为 $F_{\max} = f_s P\cos\alpha$。$F \le F_{\max}$ 化为 $P\sin\alpha \le f_s P\cos\alpha$，即 $\tan\alpha \le f_s$——**$P$ 在不等式两边约掉了**。这就是自锁「无论多大力都锁得住」的数学真相。

**第三步，量纲检查**：$\tan\varphi_f$ 与 $\tan\alpha$ 都是无量纲比值（长度除以长度），$f_s$ 是力除以力的无量纲比值，两边量纲完全一致；$\varphi_f$ 本身是角度（弧度），单位 $\mathrm{rad}$。若某处把 $f_s$ 写成了带单位的量，摩擦角公式就会立刻失衡。

**第四步，直觉收尾**：$\alpha \le \varphi_f$ 的几何画面，就是主动力合力被「困」在摩擦锥内部。工程上应用这个条件时，往往不必解方程——画一条摩擦锥的边线，看合力在锥内还是锥外，一眼判断锁与不锁。<span class="marginnote">这个「角度比较」的直觉可以迁移到很多场合：螺纹升角小于当量摩擦角则自锁，齿轮啮合要避免自锁以保证可逆传动，机器人手指的抓取锥（friction cone）也是同一几何——摩擦锥几乎是所有「夹持与锁紧」问题的通用图形。</span>

## 6 小结

- 摩擦分**滑动摩擦**与**滚动摩阻**；滚动摩阻是力偶矩，不是简单的切向力。
- **库仑摩擦定律**：最大静摩擦 $F_{\max} = f_s N$，动摩擦 $F' = fN$，$f < f_s$。
- 静摩擦力是**区间量**（$0 \le F \le F_{\max}$），不是恒等于 $f_s N$；先解方程、再验不等式。
- **摩擦角** $\varphi_f = \arctan f_s$；主动力合力与法线夹角 $\alpha \le \varphi_f$ 时**自锁**，且与力的大小无关。
- 临界问题令 $F = F_{\max}$，把不等式变等式；斜面自锁条件为 $\tan\theta \le f_s$。
- 工程应用双轨并行：传动、制动、锁紧靠**增大**摩擦，润滑、滚动轴承、抛光靠**减小**摩擦；滚动摩阻远小于滑动摩擦，是「轮子省力」的物理根源。
- 螺纹自锁、千斤顶自锁都是「斜面自锁」的变体：把螺纹展开成斜面，用 $\lambda \le \varphi_v$ 判安全。

在下一节，静力学全部收束，我们要让物体真正动起来——从「力如何使物体保持平衡」转向「点的位置随时间如何变化」，这就是**点的运动学**。
