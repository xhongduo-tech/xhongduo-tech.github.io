## 为什么从位流理论开始

上一节的三大守恒方程是「完整的真理」，但也是「难解的方程」——非线性的 N-S 方程到今天也没有通解。空气动力学的智慧在于**分层简化**：先问「黏性可不可以先放一边、压缩性可不可以先放一边」，于是得到**无黏不可压流**。这个模型再叠加「无旋」条件，就进入了**位流理论（potential flow theory）**的殿堂：非线性方程组退化成一条线性方程——拉普拉斯方程。<span class="marginnote">拉普拉斯方程是整个数学物理的常客：静电场、稳态热传导、地下水渗流、位流，全服从 $\nabla^2\phi = 0$。同一条方程服务不同学科，这是「数学是自然的语言」最有力的例证。</span>更妙的是，线性方程允许**叠加**：把几个简单流场加在一起，就是复杂流场。绕机翼、绕圆柱的流场，就这样被分解成几个基本流动的拼图。

## 1 无黏不可压流：最经济的简化

上一节末尾留下的问题是：方程太难。先看两条简化各带走什么。

一句话概括本节的立场：**在「算得出」与「算得对」之间，位流选择先保证前者。** 位流给不了阻力，却在升力、压力分布、流线形态上给出量级正确的第一答案；有了这个基准，再逐层加回黏性与压缩性，才谈得上完整的气动图景。这种「先粗略、后精细」的迭代，是空气动力学一贯的哲学。

**无黏（inviscid）**：忽略黏性，剪应力为零，动量方程回到欧拉方程。代价是算不了阻力、管不了分离——这两件事等后面边界层理论接手。<span class="marginnote">无黏流动仍能给出升力，这几乎是最反直觉的一点。升力的本质是上下表面压力差，而压力差由流场的弯曲程度决定，与黏性无关；黏性只是「帮忙」把后缘的驻点位置钉住（库塔条件）。</span>

**不可压（incompressible）**：密度 $\rho$ 为常数，连续方程退化为

$$\nabla \cdot \mathbf{V} = 0$$

展开成直角坐标就是 $\dfrac{\partial u}{\partial x} + \dfrac{\partial v}{\partial y} + \dfrac{\partial w}{\partial z} = 0$——三个方向的速度梯度必须互相抵消，速度场才能「既不堆积分子的空隙，也不留下真空」。<span class="marginnote">这条方程给了流场很强的约束：一个方向上流速在变，另一个方向上就必须反向变化来补偿。管道变窄处流速增大、边界层内靠近壁面流速趋零、机翼上方气流加速——全都可以从这里读出因果。</span>

代价是放弃激波、膨胀波等一切压缩效应——那是可压流章节的地盘。两条简化叠加，再假设**无旋**（$\nabla\times\mathbf{V} = 0$，来流无旋则全场无旋），位流理论就成立了。<span class="marginnote">无旋不等于无涡：流场可以有<strong>涡量集中区</strong>（如点涡），但每个流体微团本身不发生自旋。形象地讲，微团像一艘不转动的独木舟在环形水流里绕行——它绕圈，但不自转。</span>

## 2 速度势与流函数：两个标量的故事

无旋条件使速度场成为某个标量函数的梯度：

$$\mathbf{V} = \nabla \varphi, \qquad u = \frac{\partial\varphi}{\partial x},\ v = \frac{\partial\varphi}{\partial y}$$

这个 $\varphi$ 叫**速度势（velocity potential）**。把它代进不可压连续方程 $\nabla\cdot\mathbf{V}=0$，立刻得到

$$\nabla^2 \varphi = \frac{\partial^2\varphi}{\partial x^2} + \frac{\partial^2\varphi}{\partial y^2} = 0$$

**拉普拉斯方程（Laplace's equation）**。它的解称为调和函数，满足叠加原理：若 $\varphi_1$、$\varphi_2$ 都是解，则 $\varphi_1 + \varphi_2$ 也是解——这就是位流能「拼积木」的数学根源。

与之并行的还有一个**流函数（stream function）** $\psi$，定义为

$$u = \frac{\partial\psi}{\partial y}, \qquad v = -\frac{\partial\psi}{\partial x}$$

它同样满足拉普拉斯方程。$\psi$ 的等值线恰好就是流线，物理意义极其直观：**$\psi$ 的差给出两流线之间的体积流量**。<span class="marginnote">$\varphi$ 与 $\psi$ 的等值线处处正交，构成流场的两套坐标网。绕障碍物的求解常这样分工：用 $\psi$ 描述形状（固体表面是流线），用 $\varphi$ 给出速度。两者是位流理论的双引擎。</span>

**辨析｜易错点：** 速度势只对**无旋**流存在；流函数对任何二维流都存在（只要满足连续方程）。「有速度势」与「有无旋」互为充要条件，而「有流函数」只需质量守恒。三维流里流函数推广为向量流函数，复杂度骤增，这正是二维位流如此好用的原因。

速度势与流函数之间还藏着一组对称的求导关系：

$$\frac{\partial\varphi}{\partial x} = \frac{\partial\psi}{\partial y}, \qquad \frac{\partial\varphi}{\partial y} = -\frac{\partial\psi}{\partial x}$$

这正是复变函数里**柯西-黎曼方程**的雏形——所以位流可以漂亮地并入复分析：把 $\varphi + i\psi$ 看成一个复势 $F(z)$，流场的一切都浓缩成对单个复函数的处理。<span class="marginnote">复势方法让二维位流成为应用数学里最优雅的一章：保角变换可以把绕圆柱的解「映射」成绕任意翼型的解。茹科夫斯基变换就是这么把圆变出翼型，风洞数据与理论因此有了对照。</span>

## 3 基本流动元件

位流的「积木」有四种，全部用极坐标写出：

**均匀流（uniform flow）**：$\varphi = V_\infty x$，$\psi = V_\infty y$。整片流场速度恒为 $V_\infty$，是最简单的背景流。

**源/汇（source/sink）**：$\varphi = \dfrac{\Lambda}{2\pi}\ln r$，$\psi = \dfrac{\Lambda}{2\pi}\theta$。从一点径向喷出的流体，$\Lambda$ 是源强（体积流量）。源为正、汇为负。

**偶极子（doublet）**：$\varphi = \dfrac{\kappa}{2\pi}\dfrac{\cos\theta}{r}$。一个源与一个等强汇无限靠近的极限，像一个「推一下又拉一下」的扰动。

**点涡（vortex）**：$\psi = -\dfrac{\Gamma}{2\pi}\ln r$，$\varphi = \dfrac{\Gamma}{2\pi}\theta$。流体绕点涡沿圆周运动，环量 $\Gamma$ 度量涡的强度。<span class="marginnote">点涡的流线是一族同心圆，但每个微团自身不旋转（无旋！），只有绕涡心的环量。这是位流里唯一「不满足无旋」却必须存在的角色——真实升力机翼后缘泄出的就是这样的涡。</span>

**叠加原理**说：把均匀流、源、汇、偶极子、涡按需相加，就得到绕各种物体的流场。下一节的绕圆柱流动，就是「均匀流 + 偶极子」两块的产物。

一个更贴近工程的中级示例是**兰金卵形体（Rankine oval）**：均匀流 + 一对源与汇。源在汇的上游，两者之间流线被「撑开」，形成一个封闭的卵形边界——这已能描述一个对称船体、机身或支柱的位流。继续叠加更多奇点，就能逼近任意形状的轮廓，这正是**面元法（panel method）**的思路：把物体表面分成许多小块，每块放一个源，反解源强让表面恰好成为流线。<span class="marginnote">面元法是 1950–1970 年代飞机设计的主力工具，今天的 CFD 教科书仍把二维面元法作为入门案例。它的魅力在于把「解偏微分方程」变成「解一个代数线性方程组」，几十分钟就能算完一架整机的位流。</span>

## 4 公式解析：绕圆柱的无升力流

把均匀流与偶极子叠加，取偶极子强度 $\kappa = 2\pi V_\infty R^2$，得到绕半径为 $R$ 的圆柱的流函数：

$$\psi = V_\infty r \sin\theta\left(1 - \frac{R^2}{r^2}\right)$$

对这条式子做三步拆解：

- **第一步，验证表面是流线**：在 $r = R$ 处括号为零，$\psi = 0$ 恒成立——圆柱表面正是 $\psi = 0$ 这条流线，物面条件天然满足。
- **第二步，求表面速度**：由 $V_r = \dfrac{1}{r}\dfrac{\partial\psi}{\partial\theta}$、$V_\theta = -\dfrac{\partial\psi}{\partial r}$，在 $r=R$ 处得 $V_r = 0$、$V_\theta = -2V_\infty\sin\theta$。
- **第三步，翻译成压力**：用伯努利方程 $p + \tfrac12\rho V^2 = \text{const}$，表面压力系数为

$$C_p = 1 - \left(\frac{V_\theta}{V_\infty}\right)^2 = 1 - 4\sin^2\theta$$

在前驻点 $\theta = 180°$ 处 $C_p = 1$（速度为零、压力最大），在上下两侧 $\theta = 90°$、$270°$ 处 $C_p = -3$（速度最大、压力最低），在后驻点 $\theta = 0°$ 处 $C_p = 1$。压力分布上下完全对称——**没有升力，也没有阻力**。

这张 $C_p$ 曲线是位流的一张「身份证」：它对称、无平台、前后驻点各一个。真实圆柱在同等雷诺数下测得的 $C_p$ 曲线完全不同——前缘附近还算吻合，后缘处出现一个低压平台，那是分离区留下的烙印。<span class="marginnote">把位流 $C_p$ 与实测 $C_p$ 并排比较，是理解「位流在哪一步失效」的直观教材：前半段两者几乎重合，后半段分道扬镳——分离就是那根分界线。</span>

## 5 达朗贝尔佯谬与位流的边界

上述结果干净得反常：绕圆柱的位流竟然既无升力又无阻力。任何翼型、任何对称物体在纯位流里的力都为零——这就是著名的**达朗贝尔佯谬（d'Alembert's paradox）**。

问题出在哪？位流允许流体在圆柱表面光滑滑过，前驻点减速、后驻点重新加速回原速，动能「存进去又取出来」，净效果为零。<span class="marginnote">真实流动里，边界层在逆压梯度下从圆柱后缘<strong>分离</strong>，在物体后面留下一片低压尾迹，阻力就此产生。达朗贝尔佯谬不是位流算错了，而是它把「分离」这个黏性现象排除在前提之外。</span>真实世界的圆柱阻力系数在 $Re \sim 10^5$ 时高达 1.2 左右，而位流算出的零——差了整整一个量级。

但这不意味着位流没用。**升力问题恰好避开了这个死穴**：把点涡加进绕圆柱流场，上下表面速度不等，压力差就产生了升力。这正是下一节库塔-茹科夫斯基定理的入口：位流提供了「绕圆柱 + 环量」的精确解，而升力大小 $L' = \rho_\infty V_\infty \Gamma$ 从此不再神秘。

位流理论在现代工程里仍然活着，只是换了几种形态：低速飞机的**升力面/涡格法**估算气动载荷、水翼与螺旋桨的诱导流场、建筑绕流的初步评估、甚至气象学里对低压气旋的简化描述。它无法给出阻力，但能在几秒内给出升力的可靠近似——这在方案论证阶段极其宝贵。<span class="marginnote">位流的另一个隐藏用途是<strong>校核 CFD 解</strong>：在高雷诺数、小攻角的极限下，CFD 算出的压力分布应当逼近位流解。两个独立方法互相印证，是工程验证的标准动作。</span>

位流也有自己诚实的边界：一旦流动分离、出现激波或强旋涡，它立刻失效。攻角超过失速角、翼型表面出现强逆压梯度、跨声速出现局部超声速区——这些场景必须交给边界层理论与可压缩流理论接力。**位流是「第一近似」，绝不是「最终答案」**，明白它在哪一步该退场，和明白它在哪一步好用，同样重要。

## 6 小结

- **无黏 + 不可压 + 无旋**三个假设把 N-S 方程简化为拉普拉斯方程 $\nabla^2\varphi = 0$。
- **速度势** $\varphi$ 由无旋保证存在，**流函数** $\psi$ 由质量守恒保证存在，二者都满足拉普拉斯方程。
- 四种**基本流动**——均匀流、源/汇、偶极子、点涡——按叠加原理组合，可拼出绕物体的复杂流场。
- 绕圆柱流场由「均匀流 + 偶极子」组成，表面速度 $V_\theta = -2V_\infty\sin\theta$，压力系数 $C_p = 1 - 4\sin^2\theta$。
- 纯位流算出**升力阻力皆为零**（达朗贝尔佯谬），因为分离是黏性现象；但位流加上**环量**就能给出升力。
- 复势 $F(z) = \varphi + i\psi$ 把位流并入复分析，保角变换（茹科夫斯基变换）能绕圆柱解映射出绕翼型的解。
- **量级锚点**：绕圆柱表面速度最大处 $C_p = -3$、前后驻点 $C_p = 1$；真实圆柱在 $Re \sim 10^5$ 时 $C_D \approx 1.2$，与位流的零形成鲜明对照。
- **位流的适用区间**：小攻角、无分离、无激波——失速角以上、跨声速区与强逆压梯度处，位流必须让位给边界层与可压缩流理论。
- **达朗贝尔佯谬的价值**：它精确标出了位流的边界——算不出阻力不是位流错了，而是阻力本质上是黏性现象，必须靠边界层理论补齐。
- **工程遗产**：面元法、升力面与涡格法至今活跃在低速设计第一线，几秒给出升力的可靠近似，是方案论证阶段不可替代的廉价工具。

在下一节，我们将在位流的「绕圆柱 + 环量」基础上，用库塔条件把环量钉定，得到库塔-茹科夫斯基定理。
