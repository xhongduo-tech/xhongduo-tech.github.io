## 为什么从三大守恒方程开始

上一节我们把空气当作连续介质，并建立了标准大气这个「基准坐标系」。但坐标系只是刻度，真正推动整个学科的是**三条守恒律**：质量守恒、动量守恒、能量守恒。<span class="marginnote">物理里的一切场方程——流体力学、电动力学、传热学——都是「某量既不能凭空产生也不能凭空消失」这句话的数学展开；连续/动量/能量正好对应质量、牛顿第二定律与热力学第一定律。</span>空气动力学的全部内容，无论是低速升力线理论、激波关系还是 CFD 的离散方程，都是这三条方程在不同简化条件下的变体。先把它们写对、读对，后面所有章节才有根。

## 1 欧拉观点与流场描述

描述流场有两种观点。**拉格朗日观点（Lagrangian）**盯着单个流体微团，记录它随时间走过的轨迹；**欧拉观点（Eulerian）**则固定空间中的一点，问「经过这一点的流体速度随时间如何变」。空气动力学几乎全用欧拉观点：我们不关心某个空气分子的一生，只关心空间每一点上速度场、压强场、密度场如何分布。

**速度场**记作 $\mathbf{V}(x, y, z, t)$，它同时给出三个分量 $u, v, w$。有了速度场，再叠加压强场 $p(x,y,z,t)$ 与密度场 $\rho(x,y,z,t)$，流场就完全确定。<span class="marginnote">流线（streamline）、迹线（pathline）与脉线（streakline）三种曲线常被混淆：流线是某一瞬间与速度处处相切的曲线，迹线是一个微团实际走过的路，脉线是连续放出的示踪粒子连成的线。定常流里三者重合，非定常流里互不相同。</span>

流线的数学定义是一条空间曲线，它在每一点的切线方向与该点速度方向一致，即

$$\frac{\mathrm{d}x}{u} = \frac{\mathrm{d}y}{v} = \frac{\mathrm{d}z}{w}$$

在风洞试验里，摄影师往气流中放烟雾或丝线，拍下的照片就是流线图谱——流线越密的地方流速越大，这是从图像读流场的第一直觉。两个不同时刻的速度场画出的流线可能完全不同，因此非定常流的流线图每帧都在变。

**物质导数（substantial derivative）** 是欧拉观点的核心工具。它回答：当一个流体微团一边运动一边感受场的变化时，它「跟随着流」看到的速率是多少——

$$\frac{D}{Dt} = \frac{\partial}{\partial t} + \mathbf{V} \cdot \nabla$$

展开写，就是 $\dfrac{D}{Dt} = \dfrac{\partial}{\partial t} + u\dfrac{\partial}{\partial x} + v\dfrac{\partial}{\partial y} + w\dfrac{\partial}{\partial z}$。**第一项是「当地变化率」，后三项是「对流变化率」**：即使空间场不随时间变（$\partial/\partial t = 0$），微团沿流线移动进入新区域，看到的量也在变。

## 2 连续方程：质量守恒

**连续方程（continuity equation）** 是「质量不生不灭」的数学表达。对空间中的控制体写出：单位时间内流入的质量，等于控制体内质量的增加率。微分形式为

$$\frac{\partial \rho}{\partial t} + \nabla \cdot (\rho \mathbf{V}) = 0$$

逐项读：$\partial\rho/\partial t$ 是当地密度的变化率，$\nabla\cdot(\rho\mathbf{V})$ 是质量通量的散度——**散度项度量「单位体积单位时间流出的净质量」**，两项之和为零意味着质量不积累。<span class="marginnote">散度 $\nabla\cdot(\rho\mathbf{V})$ 是「通量密度」的净流出率：正散度对应源（物质向外流），负散度对应汇。这个直觉在电动力学、量子力学里同样成立，是「守恒律＝某量的散度方程」的统一图景。</span>

这里需要区分两种「抓手」：**流体微团**是跟随流场运动的一小团物质，方程描述它随身的守恒；**控制体**是固定在空间中的一个有限区域，方程描述进出边界的通量。二者等价，但适用场景不同——微分方程适合理论推导，积分形式适合处理管道、风洞、发动机这类边界清晰的工程对象。空气动力学里两种表述交替登场，本专题以微分形式为主、积分形式为辅。

对**定常**流动（$\partial\rho/\partial t = 0$），方程退化为 $\nabla\cdot(\rho\mathbf{V}) = 0$；再对一维管道积分，得

$$\rho_1 V_1 A_1 = \rho_2 V_2 A_2$$

这就是工程上最常用的连续方程：**管道变细，流速必须增大**。<span class="marginnote">一个几乎反直觉的推论：低速风洞的<strong>扩压段</strong>必须越走越宽，才能让气流减速——因为质量流量守恒而密度近似不变。文丘里管、飞机进气道、皮托管测速全依赖这条关系。</span>对不可压流（$\rho$ 常数），简化为 $V_1 A_1 = V_2 A_2$。

## 3 动量方程：牛顿第二定律

动量方程是「$F = ma$」作用在流体微团上。对理想（无黏）流体，作用力只有压强与体积力，忽略体积力时得到**欧拉方程（Euler equation）**：

$$\rho \frac{D\mathbf{V}}{Dt} = -\nabla p$$

左边是「质量 × 加速度」，右边是压强梯度力。<span class="marginnote">负号很关键：流体被「推向压强低的地方」。这正是「高速低静压、低速高静压」的物理来源，也是升力产生机制的第一环。</span>真实流体还要加上黏性应力项，得到完整的**纳维-斯托克斯方程（Navier-Stokes equations）**：

$$\rho\frac{D\mathbf{V}}{Dt} = -\nabla p + \mu \nabla^2 \mathbf{V}$$

黏性项 $\mu\nabla^2\mathbf{V}$ 把动量「像热量一样」向四周扩散——这是边界层里剪应力、阻力的数学来源。<span class="marginnote">N-S 方程被誉为「把流场讲完的那句话」，但它在工程雷诺数下没有解析解，直接数值求解代价极高。空气动力学的大量工作，就是找它的简化版本：无黏、不可压、边界层、薄翼型……逐层降维。</span>

**辨析｜易错点：** 欧拉方程是「无黏」的动量方程，但它仍能解释大部分升力现象——因为升力的主体来自压强分布，而不是黏性。黏性真正不可替代的角色是**产生阻力**与**决定分离**。千万别把「无黏 = 没有升力」当成结论，恰恰相反，无黏理论已经能算出升力的大头。

对控制体还可以写出动量方程的**积分形式**：流出控制体的动量通量，等于作用在控制体上的合力。它直接导出**动量定理**在管道、喷管、推进问题里的应用：给喷气发动机估算推力，用的就是「进出控制体的动量差 = 推力」这条关系。<span class="marginnote">涡轮喷气发动机的推力 $T = \dot{m}(V_e - V_\infty)$，本质上就是动量方程的积分形式——控制面取进气道到喷口的整个发动机，动量差加压力差就是净推力。推进、增升、制动等大量工程问题都靠这一式落地。</span>

## 4 公式解析：从欧拉方程到伯努利方程

**伯努利方程**是空气动力学里出现频率最高的一条公式，它正是欧拉方程沿流线积分的结果。对定常、无黏、不可压、无体积力的一维流，沿流线：

$$\rho V \frac{\mathrm{d}V}{\mathrm{d}s} = -\frac{\mathrm{d}p}{\mathrm{d}s}$$

把它改写成 $\dfrac{\mathrm{d}p}{\mathrm{d}s} + \rho V \dfrac{\mathrm{d}V}{\mathrm{d}s} = 0$，这正是 $\dfrac{\mathrm{d}}{\mathrm{d}s}\left(p + \tfrac12\rho V^2\right) = 0$ 的展开——括号里的量沿流线不变：

$$p + \frac{1}{2}\rho V^2 = \text{const}$$

对这条式子做三步拆解：

- **第一步，认清两项的物理身份**：$p$ 是静压，$\tfrac12\rho V^2$ 是动压。动压是「把流体从静止加速到速度 $V$ 所需的压强」，也是后来 $q_\infty = \tfrac12\rho_\infty V_\infty^2$ 的直接来源。
- **第二步，看守恒的代价**：沿同一条流线成立，**不同流线之间并不一定相等**。这是初学者最容易踩的坑——「机翼上表面流线加速，静压降低」，正是伯努利在单条流线上的应用。
- **第三步，体验反直觉结论**：把公式重排为 $p + q = \text{const}$，就得到「**流速越快、静压越低**」。吹两张纸中间，纸不但不分开反而贴拢，就是这个结论的现场演示。

**辨析｜易错点：** 伯努利方程有三个前提缺一不可：定常、无黏、不可压（沿流线）。跨过激波后流动剧烈耗散，伯努利不再适用；压缩性显著时要用可压流版本。把条件忽略掉而到处乱套，是空气动力学里最常见的错误。

伯努利方程最经典的工程应用是**皮托管（Pitot tube）**：正对来流的开口端测得滞止压 $p_0$，侧壁静压孔测得静压 $p$，两者之差就是动压，于是

$$V_\infty = \sqrt{\frac{2(p_0 - p)}{\rho_\infty}}$$

飞机空速表、风洞测速、汽车测速全部基于这一式。<span class="marginnote">空速表上读到的「指示空速」是把这个差压代入标准大气海平面密度算出的等效速度；实际飞行还要按高度与温度修正到真空速。误差来源多为皮托管堵冰、静压孔位置干扰——真实工程里，公式的「理想假设」与传感器的「现实误差」永远同时存在。</span>

## 5 能量方程与环量

第三条守恒律是能量守恒。对定常、绝热（无热量交换）、无轴功的流动，单位质量流体的焓与动能之和沿流线守恒：

$$h + \frac{1}{2}V^2 = \text{const}$$

其中 $h = c_p T$ 是比焓。这条方程在可压缩流里取代伯努利的位置，下一节讲激波时它的功劳会立刻显现：**激波前后总焓不变**，但总压突变——这是超声速流动的标志性事件。

能量方程还有一个常被忽略的推论：它把温度、速度与声速连在一起。对理想气体，$h = c_p T$ 且 $a = \sqrt{\gamma R T}$，于是「滞止温度」$T_0 = T + V^2/(2c_p)$ 直接给出速度对温度的影响。喷管加速气流时温度下降、速度上升，正是这条关系在起作用。<span class="marginnote">高超声速飞行器的气动加热用同一套公式估：来流以 $V_\infty$ 撞击驻点，动能全部转化为热，驻点温度按 $T_0 = T_\infty(1 + \frac{\gamma-1}{2}M_\infty^2)$ 猛升。马赫数 25 再入时驻点温度可达几千摄氏度，这就是航天飞机防热瓦存在的理由。</span>

除了三大守恒方程，还有两个描述「流场旋转与否」的量。**旋度（vorticity）** $\boldsymbol{\omega} = \nabla \times \mathbf{V}$ 度量流体微团的局部旋转；**环量（circulation）** 是速度沿封闭曲线的线积分

$$\Gamma = -\oint_C \mathbf{V} \cdot \mathrm{d}\mathbf{s}$$

环量是升力理论的主角——库塔-茹科夫斯基定理将告诉我们「升力正比于环量」。<span class="marginnote">这里约定取负号是 Anderson 教材的惯例，有的教材不取负。环量的数值与符号约定有关，但「绕翼型存在净环量」这一事实与约定无关——它来自翼型后缘的<strong>库塔条件</strong>，下一节再展开。</span>与之配套的还有**流函数** $\psi$ 与**速度势** $\phi$，它们把「求速度场」转化为「解拉普拉斯方程」，是下一节位流理论的入场券。

## 6 小结

- 空气动力学采用**欧拉观点**，用速度场 $\mathbf{V}$、压强场 $p$、密度场 $\rho$ 描述流场。
- **物质导数** $D/Dt = \partial/\partial t + \mathbf{V}\cdot\nabla$ 是「跟着微团看变化」的算符。
- **连续方程** $\partial\rho/\partial t + \nabla\cdot(\rho\mathbf{V}) = 0$ 表达质量守恒；定常一维形式 $\rho_1V_1A_1 = \rho_2V_2A_2$。
- **动量方程**：无黏为欧拉方程 $\rho D\mathbf{V}/Dt = -\nabla p$，完整形式为 N-S 方程。
- **伯努利方程** $p + \tfrac12\rho V^2 = \text{const}$ 沿流线成立，是欧拉方程积分的产物。
- **能量方程** $h + \tfrac12 V^2 = \text{const}$
