## 为什么总纵强度是第一强度

上一节认识了船体结构组成。真正决定一艘船「会不会从中间断成两截」的，是**总纵强度（longitudinal strength）**：把整艘船看作一根漂浮的空心梁，波浪载荷在其中掀起纵向弯矩与剪力。船的艏艉在波峰、中部在波谷时，梁上凸（中拱）；反之船中部在波峰时，梁下凹（中垂）。这两种状态下，甲板与船底的拉压应力反复交替——**总纵强度是船舶结构安全的第一道底线**。

## 1 船体梁与波浪载荷

船体梁的受力来自重量分布与浮力分布之差。沿船长积分这些分布载荷，得剪力与弯矩曲线：

$$q(x) = w(x) - b(x), \qquad V(x) = \int q\,dx, \qquad M(x) = \iint q\,dx\,dx$$

其中 $w(x)$ 是单位长度的重量分布（船体、货物、油水、设备），$b(x)$ 是单位长度的浮力分布（由邦戎曲线积分）。二者之差 $q(x)$ 是净载荷，二次积分即得**静水弯矩**。

波浪的作用在此基础上叠加：规则波下按波高与波长布置波峰/波谷，用**谱方法**或规范简化公式求**波浪弯矩**。静水弯矩加波浪弯矩，就是船体梁要扛的总弯矩。

**辨析｜易错点：** 中拱（sagging vs hogging 常混淆）——**中拱（hogging）**是艏艉在波谷、中部在波峰，船体上凸，甲板受拉、底部受压；**中垂（sagging）**相反，甲板受压、底部受拉。方向记错，应力符号全反。

## 2 弯矩与剪力的典型分布

典型装载下，船体梁的弯矩沿船长呈「中间大、两端小」的分布：

- **静水弯矩**：与装载状态强相关——均匀装载时小，艏艉重载、中部轻载（或反之）时大。**装载顺序（loading sequence）是营运中控制静水弯矩的关键手段**。
- **波浪弯矩**：主要由波高与波长决定，设计时取设计波（如垂向波浪弯矩按规范波高计算）。
- **剪力**：在中拱/中垂过渡处（约 $1/4$ 与 $3/4$ 船长）最大，船体舷侧板与舱壁要重点校核剪应力。<span class="marginnote">直觉：弯矩是「力偶的累积」，剪力是「载荷的累积」。载荷在中部正负交替最大，所以剪力峰值不在中部而在弯矩快速变化的区间——这正是船艏艉 1/4 处舷侧易出现剪切破坏裂纹的力学背景。</span>

## 3 总纵强度校核：应力与剖面模数

总纵弯曲应力按梁弯曲公式计算：

$$\sigma = \frac{M}{W}, \qquad W = \frac{I}{z}$$

其中 $M$ 是总纵弯矩（静水 + 波浪），$W$ 是剖面模数，$z$ 是距中和轴最远纤维距离。强度要求

$$\sigma_{\max} \le \frac{\sigma_s}{k}$$

$\sigma_s$ 是材料屈服强度，$k$ 是安全系数。**甲板与船底离中和轴最远，应力最大**，因此规范主要校核甲板板与船底板的应力。<span class="marginnote">这和梁理论完全一致：梁的上下翼缘承担弯曲应力，腹板承担剪力。船体梁的「翼缘」就是甲板与船底，「腹板」就是舷侧。所以上甲板与内底板的厚度、纵骨布置，是总纵强度设计的焦点。</span>

还要校核**局部屈曲**：甲板板、船底板在压应力下可能先失稳而非屈服，板格的临界屈曲应力由板的厚度、骨材间距决定——这就是为什么总纵强度与板架局部强度（下一节）要联合设计。

## 4 公式解析：总纵弯曲应力

$$
\sigma = \frac{M_{\text{sw}} + M_w}{I / z_{\max}}
$$

三步拆解：

- **第一步，分子 $M_{\text{sw}} + M_w$**：总弯矩由静水弯矩与波浪弯矩相加。设计波高越大、装载越偏，分子越大。
- **第二步，分母 $I/z_{\max}$**：剖面模数。$I$ 由船体剖面的面积分布决定，甲板底部材料贡献最大；$z_{\max}$ 是中和轴到最远纤维距离。
- **第三步，比较**：$\sigma_{\max}$ 必须小于许用应力（屈服/安全系数）。**应力超限的两种手段**：加大剖面模数（加厚甲板底部、增加型深）或降低设计弯矩（改善装载、限制波高）。注意 $\sigma$ 是拉压交替的循环应力，还要叠加上疲劳校核。

## 5 规范与实测：总纵强度的闭环

总纵强度在设计与营运两个阶段各有一套动作：

- **设计阶段**：规范（如船级社的钢制海船入级规范）给出波浪弯矩公式与最小剖面模数要求 $W_{\min} \ge C \cdot L^2 B (C_b + 0.7)$（$C$ 是系数，$L, B, C_b$ 为船长、宽、方形系数）。设计者按此布置板厚与纵骨。
- **营运阶段**：**装载仪（loading computer）**实时计算各工况的静水弯矩与剪力，提示船长避开超限装载——现代商船强制配备。<span class="marginnote">实船监测则靠<strong>船体应力监测系统</strong>：在甲板、船底贴应变片，实时读取总纵应力，超限报警。它把「按规范设计」变成「按状态营运」，是数字化营运的一部分，与第四篇智能船舶直接相连。</span>

**辨析｜易错点：** 中拱与中垂对船体梁的威胁不对称——中垂工况下甲板受压，受压构件更易屈曲失稳，且中垂时常伴随艏部上浪加重，所以不少规范对中垂工况要求更严。

## 6 装载仪与弯矩控制：一次完整演练

总纵强度的营运控制靠装载仪，把它走一遍完整流程，理解强度管理的日常。

**第一步，输入装载**：船长把各舱货物的重量、重心位置，油水舱的液位输入装载仪。

**第二步，算静水弯矩**：装载仪按「重量分布 − 浮力分布」沿船长积分，得静水剪力与弯矩曲线，与许用包络比对。

**第三步，提示超限**：若某工况的弯矩接近或超过包络，装载仪报警，提示调整：移动货物、调整压载顺序、改变装卸顺序。

**一个数字直觉**：散货船的装卸顺序有严格要求——按「先中部、后艏艉」或反之，分阶段进行，控制每个阶段的弯矩不超限。**顺序错了，同一批货装完，弯矩却超了**——这就是「同样装法、不同顺序、不同安全」的物理根源。

**辨析｜易错点：** 静水弯矩与波浪弯矩的峰值不一定在同一位置——静水弯矩峰值在中部，波浪弯矩峰值也近似中部，但两者叠加的最大值随装载偏移。**只看静水、漏掉波浪，是强度校核最常见的疏漏。**

## 7 关键词对照与自测

把本讲关键术语做一次中英对照：

| 中文 | 英文 |
| --- | --- |
| 总纵强度 | Longitudinal Strength |
| 中拱 | Hogging |
| 中垂 | Sagging |
| 静水弯矩 | Still-water Bending Moment |
| 波浪弯矩 | Wave-induced Bending Moment |
| 装载仪 | Loading Computer |

**要点速览**：一页纸记住本讲核心：

- 总纵弯矩 = 静水弯矩 + 波浪弯矩
- 中拱上凸甲板受拉，中垂下凹甲板受压
- $\sigma = M/W$，甲板底部应力最大
- 设计用规范模数，营运用装载仪实时管控

**自测清单**：合上书试着回答——答不上来的说明还没消化：

- 中拱与中垂分别对应什么波态与受力？
- 静水弯矩来自哪两个分布的差？
- 剖面模数 $W$ 增大如何影响应力？
- 为什么装卸顺序会影响总纵强度？

总纵强度把「船会不会断成两截」变成一条弯矩曲线与一个包络。装载仪的每一次报警，都是这条曲线对装载方案的否决。下一节，我们下探到局部板架。

## 8 小结

- 船体梁的总纵弯矩 = **静水弯矩 + 波浪弯矩**，来自重量与浮力分布之差。
- **中拱（上凸，甲板受拉）** 与 **中垂（下凹，甲板受压）** 是两种相反的受力工况。
- 总纵应力 $\sigma = M/W$，甲板与船底应力最大，是校核焦点。
- 设计用规范最小剖面模数，营运用**装载仪**与应力监测系统实时管控。

在下一节，我们把镜头从整船拉近到局部——甲板板、船底板和它们的骨材组成的板架，如何承受局部压力并保持稳定，这就是**板架强度**。
