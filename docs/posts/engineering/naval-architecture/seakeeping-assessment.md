# 耐波性评价

<div class="epigraph">
<p>一艘船是否「耐波」，不在风平浪静时显露，而在它穿越风暴时还能否执行任务、保住船员——评价耐波性，是在评价船在逆境中的生存与工作能力。</p>
<footer>—— 爱德华·刘易斯（Edward V. Lewis，《Principles of Naval Architecture》主编）</footer>

## 为什么需要一套评价体系

横摇、纵摇、垂荡各有各的物理，但船东与船员问的是更朴素的问题：**这条船在几级海况下还能跑？货物会不会滑动？船员会不会晕到无法工作？甲板会不会上浪？** 耐波性评价（seakeeping assessment）就是把三模态的运动结果，翻译成一套与「能不能用」直接挂钩的指标。它是耐波性从物理走向决策的收口。

## 1 运动统计：从响应谱到有义幅值

承接前两节，船的运动在频域用响应谱 $S_{\text{motion}}(\omega_e) = |RAO|^2 S_{\text{wave}}(\omega_e)$ 描述。从中提取统计特征，最常用的是**有义幅值（significant amplitude）**：近似等于响应谱零阶矩的 4 倍（对应运动的 $1/3$ 大波均值）。

以横摇角为例：

$$\varphi_{1/3} = 4\sqrt{m_{0,\varphi}}, \qquad m_{0,\varphi} = \int_0^\infty S_\varphi(\omega_e)\, d\omega_e$$

这套流程对每一个运动模态都做一遍，得到横摇、纵摇、垂荡、艏艉加速度的统计值——它们是后续所有判据的输入。<span class="marginnote">把波浪当随机过程，船运动当线性滤波器，输出就自动是随机过程——这套「谱方法」让耐波性评价从单次遭遇的运气问题，变成可重复计算的统计科学。它与第二级《随机过程》中平稳过程功率谱一脉相承。</span>

## 2 耐波性判据：一套「能不能」的清单

工程上把耐波性要求整理成一组**运动限值（motion criteria）**，超过限值即认为该工况不可接受：

| 判据 | 典型限值 | 关心对象 |
| --- | --- | --- |
| 横摇有义角 | $4° \sim 6°$（货船） | 货物系固、稳性、舒适 |
| 垂向加速度（艏） | $0.2g \sim 0.4g$ | 抨击、设备、人员 |
| 甲板上浪频率 | 每小时内若干次 | 甲板设备、安全 |
| 晕船率 | 一定海况下船员呕吐比例 | 人员效能 |
| 螺旋桨飞车 | 桨露出水面次数 | 主机与轴系 |

这些数字来自经验与规范，把「耐波性好」从形容词变成可验收的量化指标。<span class="marginnote">不同使命的船判据差异巨大：集装箱船怕横摇（箱子会动），军舰怕加速度（武器与直升机作业），渔船怕横摇与上浪（稳性与劳作安全），豪华邮轮怕晕船率。评价体系必须「一船一表」。</span>

## 3 全生命周期评价：从设计到营运

耐波性评价贯穿船舶全生命周期：

- **设计阶段**：给定设计海况（如北大西洋有义波高 $H_{1/3}=11\ \text{m}$ 的百年一遇环境），计算各模态运动，校核判据；用**耐波性图谱**或现代时域仿真迭代船型与减摇装置。
- **营运阶段**：船长使用**船载耐波性辅助系统**，实时输入海况预报，预测未来几小时的运动与上浪风险，调整航向航速避开共振带——即「**波浪规避（swell avoidance）**」策略：改变航向使遭遇频率偏离固有频率。<span class="marginnote">规避策略常伴「减速」一起用：降速虽延长时间，却同时降低抨击强度与飞车概率——这是船长在安全与准点之间最常做的折中，也是航线气象导航软件的核心算法。</span>
- **事后评估**：实船记录的传感器数据反馈设计，形成「设计预报—实船实测」的闭环修正。

## 4 公式解析：运动有义幅值

$$
\varphi_{1/3} = 4\sqrt{m_0} = 4\sqrt{\int_0^\infty |RAO(\omega_e)|^2\, S(\omega_e)\, d\omega_e}
$$

三步拆解：

- **第一步，谱相乘** $|RAO|^2 \cdot S(\omega_e)$：波浪能量谱经船的幅值响应调制，得到运动能量谱。RAO 在某频率为 2，意味着该频率的波浪运动被放大一倍、能量放大四倍。
- **第二步，积分取零阶矩 $m_0$**：把全部频率的能量加起来，$m_0$ 是运动过程的总方差（能量），对应时域幅值的均方根。
- **第三步，乘 4**：$\varphi_{1/3} = 4\sqrt{m_0}$ 是从瑞利分布导出的统计换算——对窄带平稳过程，有义幅值约等于 $4\sigma$。**看到 $4\sqrt{m_0}$，就应想到「最大有义值 = 4 倍标准差」这条随机过程翻译规则**。

## 5 极限工况：残存性与破舱耐波

常规耐波性评价之外，还有**极限残存性（survivability）**问题：船在破损进水、丧失部分浮力后仍受波浪作用，横摇固有频率改变、静稳性曲线塌缩，可能与波浪共振而倾覆。这类评价引入**概率倾覆判据**：把破损后船的复原力臂曲线与随机波浪激励联合计算，给出**倾覆概率**，要求低于规定阈值。<span class="marginnote">这已从「线性的摇荡」跨入「强非线性的稳性」——倾覆是横摇能量翻过稳性消失角的随机事件，只能按概率评估。它把第一篇的静稳性、本篇的横摇、与随机过程理论三者缝合在一起。</span>

## 6 耐波性在设计与营运中的落地

耐波性评价的最终出口，不是一串统计值，而是两个决策：**设计阶段的船型取舍** 与 **营运阶段的航向航速决策**。

**设计阶段**：设计者把「设计海况」下的运动预报做成一张「耐波性包络图」——横轴航速、纵轴航向角，等高线画出运动限值超标的区域。这张图直接告诉船东：这条船在 6 级海况下、以什么航向航速组合仍能安全作业。若包络太小，就要加大船宽（改善横摇）或优化艏部（减小抨击），把包络撑大。

**营运阶段**：船载系统把实时海况预报代入耐波性模型，给出未来几小时的最优航向航速建议。一个典型策略：**把遭遇周期调到远离横摇固有周期**。例如横摇固有周期 $T_\varphi = 10\ \text{s}$，若波浪自然周期 $T = 8\ \text{s}$、船速 $V$、波向角 $\chi$，遭遇周期

$$T_e = \frac{2\pi}{\omega - kV\cos\chi}$$

调整航向 $\chi$ 使 $T_e$ 避开 $T_\varphi \pm 20\%$ 的禁区，横摇就远离共振。**这不是「躲浪」，而是「错频」**——利用遭遇频率的航向敏感性，用操舵代替硬抗。

**辨析｜易错点：** 优化航向可能牺牲航程与准班——绕路多烧油、多花时间。船长必须在「运动安全」「航程经济」「准点承诺」三者间取平衡，这正是耐波性从工程走向管理的界面：**它给出的不是唯一答案，而是可行域**。

## 7 关键词对照与自测

把本讲关键术语做一次中英对照：

| 中文 | 英文 |
| --- | --- |
| 有义波高 Hs | Significant Wave Height |
| 波能谱 | Wave Spectrum |
| 响应幅值算子 RAO | Response Amplitude Operator |
| 运动限值 | Motion Criteria |
| 遭遇周期 Te | Encounter Period |
| 波浪规避 | Swell Avoidance |

**自测清单**：合上书试着回答——答不上来的说明还没消化：

- $\varphi_{1/3} = 4\sqrt{m_0}$ 中 $m_0$ 的物理含义是什么？
- 耐波性判据为什么因船型使命而异？
- 遭遇频率随航向如何变化？
- 为什么改变航向能避开横摇共振？

耐波性评价把「这船适不适合这片海」变成一个可计算的量。而它真正输出的是可行域——把安全与经济的权衡，交还给船长与设计师的智慧。

**要点速览**：一页纸记住本讲核心：

- $\varphi_{1/3}=4\sqrt{m_0}$ 是谱到统计的翻译规则
- 运动限值按船型使命定制，形成「一船一表」
- 遭遇频率随航向变化，是波浪规避的抓手
- 耐波性输出的是「可行域」而非唯一答案

耐波性评价的最终输出，是「什么海况下能干什么事」的可行域——读懂可行域，就读懂了船的边界。

## 8 小结

- 耐波性评价把运动谱积分成**有义幅值** $\varphi_{1/3} = 4\sqrt{m_0}$，作为统一输入。
- 判据是一套**运动限值**清单，按船型使命定制，把「耐波」变成可验收的指标。
- 设计、营运、事后评估构成全生命周期闭环；**波浪规避**靠改变航向航速避开共振。
- 极限工况用**概率倾覆判据**评估破损船的残存耐波能力。

在下一节，我们从「被波浪推着走」转向「自己决定往哪走」——当船长操舵，船如何响应，又凭什么保持航向，这就是**船舶操纵性方程**。
