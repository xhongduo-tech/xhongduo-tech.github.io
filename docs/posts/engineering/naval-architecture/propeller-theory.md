## 为什么螺旋桨值得一套理论

阻力是「债」，螺旋桨是「赚钱机器」：它把主机转轴的旋转功率转成船的前进推力。一百多年来，人们用两套互补的理论理解它——**动量理论**（把螺旋桨当作一个整体盘，回答「总推力与效率的极限在哪」）与**叶元体理论**（把桨叶切成一片片剖面，回答「每片桨叶怎么受力」）。两者合起来，构成螺旋桨设计与分析的全部起点。

## 1 动量理论：把螺旋桨当成一个「推进盘」

**动量理论（momentum theory）**把螺旋桨理想化为一个直径有限、厚度为零的**致动盘（actuator disk）**，船以速度 $V_A$ 前进，盘后流体被加速。

设盘面处的诱导速度（对水流增量的一半）为 $u$，盘后远方的速度增量为 $2u$。由动量定理，螺旋桨产生的**推力**为

$$T = \rho A (V_A + u) \cdot 2u$$

其中 $A$ 是盘面积，$\rho A(V_A + u)$ 是盘面处流过的质量流量。这个结果给出第一层重要结论：**推力来自把水流加速**，加速量 $2u$ 越大推力越大，但代价是效率下降。

理想效率（无能量损失时）为

$$\eta_i = \frac{V_A}{V_A + u} = \frac{2}{1 + \sqrt{1 + C_T}}$$

其中 $C_T = T / (\tfrac12\rho A V_A^2)$ 是推力负荷系数。<span class="marginnote">理想效率公式告诉我们：推力负荷系数越高（盘面越小、推力越大），效率越低。同一艘船，螺旋桨盘面做大（直径加大），能降低 $C_T$、提升效率——这就是为什么大直径低转速螺旋桨比小直径高转速更省油。</span>

## 2 叶元体理论：把桨叶切成一圈圈「小机翼」

**叶元体理论（blade element theory）**把螺旋桨的每片桨叶沿径向切成许多微段（叶元体），每个叶元体视作一个小翼型，以当地的合速度攻角来流，产生升力与阻力。

设半径 $r$ 处叶元体的弦长为 $c(r)$、螺距角为 $\theta$，该处水流的合速度 $W$ 由进速 $V_A$ 与转动速度 $2\pi n r$ 合成。升力与阻力合力在轴向的投影即叶元体**推力** $dT$，在切向的投影乘以力臂即**转矩** $dQ$：

$$dT = \tfrac12\rho W^2 c\, (C_L\cos\beta - C_D\sin\beta)\, dr$$

$$dQ = \tfrac12\rho W^2 c\, (C_L\sin\beta + C_D\cos\beta)\, r\, dr$$

其中 $\beta$ 是合速度与旋转面的夹角（进角），$C_L, C_D$ 是翼型的升力、阻力系数。<span class="marginnote">注意 $dT$ 与 $dQ$ 的耦合：升力既产生推力也产生转矩，阻力两边都减效率。设计的目标就是让每一段桨叶的攻角都接近最佳，使 $C_L/C_D$ 尽量大。</span>

## 3 两者的合流：叶元体动量理论

纯粹的叶元体理论有一个缺陷：它假设来流速度不因诱导速度而改变，但动量理论说明盘后水流被加速了。现代计算把两者**联立**求解——**叶元体动量理论（BEMT）**：先由动量理论给出当地的诱导速度，再由叶元体理论用修正后的当地合速度算力，迭代到自洽。这一方法至今仍是螺旋桨设计软件（如 OpenProp）的核心引擎。<span class="marginnote">BEMT 的自洽迭代可以理解成「预测—反馈」：先假设诱导速度，算受力，再用力反推诱导速度，往复收敛。它与机器学习里不动点迭代的思想同构——第三级《数值分析》的迭代法在这里有了流体力学的肉身。</span>

## 4 公式解析：理想效率

$$
\eta_i = \frac{2}{1 + \sqrt{1 + C_T}}
$$

三步拆解：

- **第一步，$C_T$ 的定义** $C_T = \dfrac{T}{\tfrac12\rho A V_A^2}$：推力相对来流动压的归一化。$C_T$ 大，说明推力「压得」这面盘很重。
- **第二步，根号项 $\sqrt{1+C_T}$**：来自动量方程 $C_T = 4a(1+a)$（$a$ 是轴向诱导因子）的解，$a = \tfrac12(\sqrt{1+C_T}-1)$。它把推力负荷转成诱导速度大小。
- **第三步，倒数结构**：$\eta_i = \dfrac{1}{1+a}$。诱导速度越大（$a$ 大），理想效率越低。**零负荷（$C_T \to 0$）时 $\eta_i \to 1$**，这是理想极限，实际螺旋桨还要扣除叶型阻力与尾流旋转损失，敞水效率通常 $0.55 \sim 0.75$。

## 5 从理论到设计：桨的宏观特征

理论给出设计指南：**大直径、低转速、适当叶数、最佳螺距分布**能同时降低 $C_T$ 与滑脱损失。于是现代商船螺旋桨直径普遍做到船吃水的 $0.7$ 倍以上、转速降到每分钟百转以内，配合导管、叶梢小翼等改良。但桨不是越大越好——直径受吃水与尾型限制，转速还要与主机匹配。**螺旋桨理论的价值，是让「多大、多快、多斜」这些直觉问题有了可计算的答案**，下一节我们就进入把理论变成实桨的具体流程。

## 6 从理想到实际：效率的层层缩水

把理想效率放回真实世界，看看效率是怎么一步步「缩水」的，能帮你建立对螺旋桨效率的整体直觉。

| 效率层次 | 量级 | 损耗来源 |
| --- | --- | --- |
| 理想效率 $\eta_i$ | $0.75 \sim 0.85$ | 尾流加速、诱导速度（不可避免） |
| 敞水效率 $\eta_0$ | $0.60 \sim 0.72$ | 叶型阻力、梢涡、旋转尾流 |
| 船桨配合 $\eta_H$ | $0.80 \sim 0.95$ | 伴流回收、推力减额 |
| 推进效率 $\eta_D$ | $0.55 \sim 0.70$ | 以上全部累积 |

这张表揭示了一个重要事实：**理想效率已经「扣」掉了诱导速度的损失**——那是动量理论证明的天花板，任何桨都突破不了。真正的设计空间在敞水效率：把叶型阻力做小、梢涡做少，就是在向天花板靠近。

**一个直觉例子**：为什么渔船常用大直径低转速桨？因为渔船要频繁拖网、负荷大，$C_T$ 高。把直径做大、盘面积加大，$C_T$ 降下来，$\eta_i$ 就从 $0.6$ 提到 $0.75$——虽然大桨更贵更重，但每年省下的油钱远超造价。**螺旋桨的每一次选型，都是「多花买效率」与「省钱降效率」的算术题**。

## 7 关键词对照与自测

把本讲关键术语做一次中英对照：

| 中文 | 英文 |
| --- | --- |
| 致动盘 | Actuator Disk |
| 诱导速度 | Induced Velocity |
| 理想效率 | Ideal Efficiency |
| 叶元体理论 | Blade Element Theory |
| 推力负荷系数 CT | Thrust Loading Coefficient |
| 叶元体动量理论 BEMT | Blade Element Momentum Theory |

**自测清单**：合上书试着回答——答不上来的说明还没消化：

- 动量理论中推力为什么等于质量流量乘 $2u$？
- $\eta_i = 2/(1+\sqrt{1+C_T})$ 在什么极限下趋于 1？
- BEMT 为什么需要迭代求解？
- 叶元体理论中升力为何同时产生推力与转矩？

螺旋桨理论的两套工具互补：动量理论告诉你「天花板多高」，叶元体理论告诉你「怎么够到」。把两者的接口——诱导速度——理解透，就抓住了螺旋桨力学的核心。

**要点速览**：一页纸记住本讲核心：

- 动量理论：推力来自把水流加速，理想效率是天花板
- 叶元体理论：每段桨叶按翼型升阻产生推力与转矩
- BEMT 联立两者迭代求解诱导速度
- 大直径低转速低负荷，是提效的三大方向

## 8 小结

- **动量理论**把桨视为致动盘，得推力 $T = \rho A (V_A+u)\cdot 2u$ 与理想效率 $\eta_i = 2/(1+\sqrt{1+C_T})$。
- **叶元体理论**把桨叶切成翼型剖面，逐段计算推力与转矩。
- **BEMT** 联立两理论迭代求解诱导速度，是现代桨设计的引擎。
- 大直径、低转速、低负荷系数，是提升螺旋桨效率的三大方向。
