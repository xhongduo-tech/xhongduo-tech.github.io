## 为什么从车辆工程概论开始

一辆车，从图纸到马路，涉及几万个零件的协调、数十个学科的交叉。学习车辆工程如果一上来就钻进气缸或齿轮，很容易在零件海洋里迷失方向。概论这门课的作用，是先在**坐标系**上把「汽车是什么」讲清楚：按什么标准给汽车分类、发动机与驱动轮如何组合成不同的总体布置、什么样的法规在约束设计。这三件事构成了一张地图，后面每一篇构造、理论、新能源的文章，都是在这张地图上放大某一个区域。

这篇概论还与「从极限到大模型」的主线有一个共鸣点：**分类即建模**。就像集合论先把对象安放进「属于哪个集合」，车辆工程先把车型安放进「属于哪一类别、什么布置、受什么法规约束」。建立了这个框架，后续《汽车动力性》《汽车制动性》里的每一个方程，才知道该套在哪辆车身上。

## 1 汽车的分类：先分清「乘用」与「商用」

汽车是个庞大家族，分类本身是工程常识。国际上最通用的分类框架来自联合国法规与各国标准，中国对应的是 GB/T 3730.1，它把汽车先一刀切为两大类：**乘用车**与**商用车**。

**乘用车（passenger car）**：主要用于载运乘客及其随身物品的汽车，座位数含驾驶员在内不超过 9 个。乘用车之下又按车身形式细分为轿车、SUV、MPV、跑车等。

**商用车（commercial vehicle）**：以载货或运送人员（9 座以上）为主要用途的汽车，细分为客车、货车、半挂牵引车等。

<span class="marginnote">GB/T 3730.1 是《汽车和挂车类型的术语和定义》。「轿车 / SUV / MPV」是乘用车的细分，「客车 / 货车」是商用车的主体——这个两级框架是学分类时的第一张骨架。</span>

除了用途分类，还有两条常用的分类轴：

- **按动力源**分：燃油车、纯电动车、混合动力车、燃料电池车。这是本专题第三篇《新能源汽车与前沿》的编排逻辑。
- **按行驶道路**分：公路车与越野车，两者的通过性设计完全不同（见《汽车通过性》）。

再补充一组按**车身形式**的分类：**三厢轿车**（发动机舱、乘员舱、行李舱分明）、**两厢车**（乘员舱与行李舱合一）、**SUV**（车身高、通过性好）、**MPV**（空间灵活）、**跑车**（低矮、大马力）、**皮卡**（乘员舱加货斗）。车身形式决定造型基因，造型又反过来约束空气阻力系数与空间布置。

**辨析｜易错点：SUV 不是越野车。** 城市 SUV 多为承载式车身、电子四驱，通过性只比轿车略好；硬派越野讲究非承载车身、差速锁与低速四驱。判断能否越野要看底盘与驱动结构（见《驱动桥与差速器》），而不是车身高不高。

## 2 总体布置：发动机与驱动轮的组合

**总体布置**回答的问题是：发动机装在哪、动力传给哪几个轮子。它决定了整车的空间分配、轴荷、操控性格与成本结构。按发动机位置与驱动轮组合，主流布置有以下几种：

**前置前驱（FF）**：发动机在前、驱动前轮。传动系紧凑、空间利用率高、成本低，是当今家用轿车的主流；代价是急加速时前轮易打滑、前轴轴荷大。

**前置后驱（FR）**：发动机在前、驱动后轮。轴荷分配均衡、操纵性好，运动型车与货车常用；传动轴贯穿车身，地板中央有隆起。

**后置后驱（RR）**：发动机放在车尾、驱动后轮。行李箱在前，典型于部分跑车与客车；重心偏后，前轮附着力小、转向易过度。

**中置后驱（MR）**：发动机位于前后轴之间，重心居中，操控极限最高，是超级跑车的主流。

**四轮驱动（4WD/AWD）**：通过分动器或中央差速器把动力分配给前后轴，换取附着与通过性，代价是更重的传动系与更高油耗。

<span class="marginnote">布置形式与转向特性的关系在《汽车操纵稳定性》里会量化：FR 更倾向适度不足转向，FF 更趋中性，RR 容易过度转向——布置直接决定了底盘调校的起点。</span>

总布置工程师的工作，就是在**空间、轴荷、操控、成本**四个目标之间做权衡。轴荷分配尤其关键：它不只在静态决定「前后轮各压多少」，还会影响制动时前轮能获得多大制动力、转向时前轮能提供多大侧向力。定轴荷的那一刻，其实已经为整车的制动性与操稳性打下了基础。

## 3 技术法规：设计的上限与下限

汽车不是随心所欲的产品，它受三层法规约束，构成设计的硬边界。

**安全法规**：碰撞安全（正面、侧面、偏置碰撞）、制动性能、灯光、轮胎、安全带与安全气囊。中国的 C-NCAP 与欧洲的 Euro NCAP 是自愿性星级评价，而强制性国标（如制动、灯具、转向）才是准入门槛。

**排放与油耗法规**：排放方面，中国实行「国六」标准，与欧洲欧六（Euro 6）接轨；美国环保署（EPA）另有体系。油耗方面，中国采用企业平均燃料消耗量（CAFC）管理，测试循环由 NEDC 转向 WLTC（全球轻型车测试循环），测试结果更接近真实路况。

**新能源与智能网联法规**：新能源车有购置税减免、补贴（逐步退坡）、双积分政策；智能网联则有数据安全、准入试点等新规。法规不是静态的，它随技术演进不断加严——这也是为什么「合规」本身就是车辆工程的一个重要研究主题。

法规还有一个容易被忽略的作用：**它催生了新技术**。油耗法规的加严倒逼了涡轮增压、缸内直喷与混动技术的普及；碰撞法规的加严推动了高强度钢与安全气囊的标配化。所以读车辆工程时，不要把法规当成「束缚」，要把它理解成「外部压力」，正是这股压力把很多创新从实验室逼进了量产车。将来读《整车开发与试验》时，你会看到整车开发时间表里永远给「法规符合性验证」留着一整块——这不是行政负担，而是产品定义的一部分。

## 4 整车技术参数：用数字描述一辆车

要比较两辆车、判定它是否符合法规，光看外观不够，需要一组标准化的**整车技术参数**，分为尺寸参数与质量参数两类。

**尺寸参数**：
- **轴距**：前、后轴中心线的距离。轴距长，纵向空间大、行驶更稳，但最小转弯直径也更大。
- **轮距**：同一轴上左右车轮接地中心之间的距离，影响横向稳定性与侧倾倾向。
- **最小离地间隙**：满载时车身最低点（如油底壳、排气管）到地面的距离，是越野通过性的关键指标。
- **接近角 / 离去角**：前、后轮外缘与前、后保险杠最低点连线与地面形成的夹角，决定车辆上坡下坎时会不会「啃头」「托尾」。
- **最小转弯直径**：转向盘转至极限时外转向轮中心平面在地面滚过的圆的直径。

**质量参数**：
- **整备质量**：汽车按规定加满油、冷却液等但无乘员和货物时的质量。整备质量每减小一点，动力性与经济性都直接受益——这正是《汽车设计与轻量化》的主线。
- **总质量**：整备质量 + 额定载质量。轿车习惯用「整备质量 + 人数 × 75 kg」近似。
- **轴荷分配**：各轴承受的质量占整车总质量的百分比，直接决定轮胎磨损、制动稳定性与操纵性。

<span class="marginnote">「75 kg」是 ISO 与各国法规对单个乘员标准质量的近似值（考虑行李取整）。做总布置、算载荷谱时它就是不可省的基本单位，见本专题《汽车总布置设计》。</span>

这套参数是总布置的「计量单位」：工程师在纸上定义轴荷、离地间隙与转弯直径，实车的一切性能都从这些数出发。读后面任何一篇理论文章时，遇到「整车质量」「轴距」「迎风面积」，其实都在读这一节埋下的坐标。

## 5 核心对比表：三类骨架

把本文的核心对象浓缩成一张表，方便日后回查：

| 分类维度 | 主要类别 | 判断要点 |
| --- | --- | --- |
| 用途（GB/T 3730.1） | 乘用车 / 商用车 | 载客 ≤9 座 vs 载货或大客量载客 |
| 动力源 | 燃油 / 纯电 / 混动 / 燃料电池 | 化学能→机械能的转化方式 |
| 车身形式 | 三厢 / 两厢 / SUV / MPV / 跑车 / 皮卡 | 舱体划分与造型基因 |
| 布置形式 | FF / FR / MR / RR / 4WD | 发动机位置与驱动轮组合 |
| 法规约束 | 安全 / 排放 / 油耗 / 新能源 | 强制性国标 + 自愿性评价 + 政策激励 |

这张表也是后面所有文章的前置知识。读《汽车动力性》时要先知道是前置前驱还是前置后驱；读《电动汽车技术》时要先知道「乘用车」与「商用车」在电池装载上的不同；读《智能网联汽车》时要知道数据法规的边界。**概论不是「背分类」，而是为整棵知识树提供坐标。**

**辨析｜易错点：总体布置 ≠ 底盘结构。** 布置描述的是「动力放哪、驱动哪轮」的能量拓扑；底盘结构描述的是「车架、悬架、车桥用什么形式」。同样 FF 的两辆车，底盘可以截然不同——一个是承载式车身配麦弗逊悬架，另一个是独立副车架配多连杆。分类看布置，拆车看底盘。

## 6 小结

- 汽车分类的第一刀是 **GB/T 3730.1**：乘用车（≤9 座）与商用车（客车 / 货车 / 牵引车）。
- 分类轴还有**动力源、行驶道路、车身形式**三种，各自回答不同层面的问题。
- **总体布置** = 发动机位置 × 驱动轮组合，FF / FR / MR / RR / 4WD 各有权衡。
- **轴荷分配**是总布置的灵魂：它同时决定制动性、操稳性与轮胎磨损。
- **技术法规**是设计的硬边界：安全、排放、油耗、新能源四层约束逐级加严。
- 概论提供**坐标系**：后续每一篇构造与理论文章都在此展开。
- 整车技术参数分**尺寸参数**（轴距、轮距、离地间隙、接近/离去角）与**质量参数**（整备质量、总质量、轴荷分配），是总布置的计量单位。
- 法规是设计硬边界也是创新压力源：安全、排放、油耗、新能源四层逐级加严，倒逼技术升级。
- 布置决定性格，法规决定下限，参数决定度量——概论给出的这三把尺子，贯穿整个车辆工程。
