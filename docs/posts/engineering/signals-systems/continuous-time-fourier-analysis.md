## 为什么傅里叶分析是「第二副眼镜」

上一篇的卷积是一个「时域」公式：输出是输入与冲激响应在时间轴上揉合的结果。但工程上真正好用的往往是**频域（frequency domain）**——工程师谈论「这段语音在 3 kHz 以上没什么能量」「Wi-Fi 信号占用了 2.4 GHz 频段」，他们说的都是频率。傅里叶分析做的，就是在这两副眼镜之间架一座**无损的桥**：任何一个信号，都可以被拆成无穷多个纯音（复指数）的叠加；反过来，任意一组复指数按正确的权重叠加，能重建原信号。

为什么拆成复指数而不是别的积木？因为 **$\mathrm{e}^{j\omega t}$ 是 LTI 系统的本征函数**——它穿过任何 LTI 系统后仍然是同一个复指数，只是幅度与相位发生了改变。<span class="marginnote">这与线性代数里「矩阵对本征向量只缩放不旋转」完全同构。傅里叶分解 = 把信号写成 LTI 系统的「本征向量基」展开，系统的作用于是退化成对角阵——这正是本篇末尾卷积定理的深层原因。</span>拆得干净，算起来就干净。大模型里的注意力、图像里的频域增强，乃至几乎一切「先分解再处理」的思路，都长着傅里叶的脸。

## 1 傅里叶级数：周期信号的「乐谱」

**傅里叶级数（Fourier series）**：若 $x(t)$ 是基波周期为 $T_0$ 的周期信号，则可以写成基频 $\omega_0 = 2\pi/T_0$ 的谐波复指数之和：

$$x(t) = \sum_{k=-\infty}^{+\infty} a_k\, \mathrm{e}^{jk\omega_0 t}, \qquad
a_k = \frac{1}{T_0} \int_{T_0} x(t)\, \mathrm{e}^{-jk\omega_0 t}\, dt$$

这里 $a_k$ 称为**傅里叶系数**。$a_0$ 是直流分量（信号在一个周期内的平均值）；$|a_k|$ 表示第 $k$ 次谐波的强度，$\angle a_k$ 表示它的相位。整套记号很像把信号「录音」进频域的乐谱：横轴是频率（$k\omega_0$ 的离散网格），每个「音符」的幅度是 $|a_k|$。

**重点：傅里叶级数告诉我们「纯周期信号的能量集中在离散频率点上」。** 频率网格由基频 $\omega_0$ 决定，周期越大基频越低、谱线越密；周期趋于无穷时，离散谱线将连成连续的频谱——这正是下一节傅里叶变换的诞生过程。

例如周期方波（占空比一半、幅度 ±1）：系数 $a_k = \dfrac{\sin(k\pi/2)}{k\pi}$，即**奇数**次谐波有幅度 $\dfrac{2}{k\pi}$，偶数次谐波为零。方波的「陡峭边缘」需要很多次高次谐波才能逼近——这解释了为什么方波听起来尖锐刺耳，也预示了「信号变化越剧烈，频谱占得越宽」的普遍规律。<span class="marginnote">用前若干项截断级数来逼近方波，会在跳变处出现固定比例（约 9%）的过冲，称为<strong>吉布斯现象（Gibbs phenomenon）</strong>。它不影响收敛性，但提醒我们「用有限项近似不连续信号」在工程上永远是件需要小心的事。</span>

## 2 傅里叶变换：非周期信号的连续频谱

非周期信号可以看成周期 $T_0 \to \infty$ 的极限：基频 $\omega_0 \to 0$，谱线 $\to$ 连续曲线。于是傅里叶级数退化为积分对：

$$X(j\omega) = \int_{-\infty}^{+\infty} x(t)\, \mathrm{e}^{-j\omega t}\, dt \qquad\text{（分析式 / 正变换）}$$

$$x(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} X(j\omega)\, \mathrm{e}^{j\omega t}\, d\omega \qquad\text{（综合式 / 逆变换）}$$

$X(j\omega)$ 称为 $x(t)$ 的**傅里叶变换（Fourier transform）**或频谱，记作 $x(t) \stackrel{\mathcal{F}}{\longleftrightarrow} X(j\omega)$。正变换把时间函数变成频率函数（分析成分），逆变换把频率函数拼回时间函数（合成信号）——两条式子互为「对偶」：除了因子 $1/2\pi$ 与 $j$ 的符号，形状完全一致。<span class="marginnote">对偶性是傅里叶分析的「免费午餐」：知道一个变换对，交换时间/频率角色常能白得另一个。例如 $\delta(t) \leftrightarrow 1$ 对偶出 $1 \leftrightarrow 2\pi\delta(\omega)$——「直流信号只有零频成分」与「冲激包含所有频率」，两个直觉一次性到手。</span>

常用变换对要记成「条件反射」：

| 时域 $x(t)$ | 频域 $X(j\omega)$ |
| --- | --- |
| $\delta(t)$ | $1$ |
| $1$ | $2\pi\,\delta(\omega)$ |
| $\mathrm{e}^{j\omega_0 t}$ | $2\pi\,\delta(\omega - \omega_0)$ |
| 矩形脉冲 | $T\,\mathrm{sinc}(\omega T/2)$ |
| $\mathrm{e}^{-at}u(t)\ (a>0)$ | $\dfrac{1}{a + j\omega}$ |
| $\cos(\omega_0 t)$ | $\pi[\delta(\omega-\omega_0) + \delta(\omega+\omega_0)]$ |

**辨析｜易错点：** 纯正弦的傅里叶变换是两根位于 $\pm\omega_0$ 的冲激，**不是**有限高度的谱峰。周期性 → 频谱离散化 → 表现为冲激，这个对应关系是考点常客：凡是严格的周期信号（理想余弦、周期方波），其频谱都是一串冲激，没有例外。

## 3 傅里叶变换的性质

掌握一批性质，可以避免反复算积分。六个最常用的：

- **线性**：$ax + by \leftrightarrow aX + bY$。
- **时移**：$x(t-t_0) \leftrightarrow \mathrm{e}^{-j\omega t_0} X(j\omega)$。时间平移只改变相位，不改变幅度谱。
- **频移（调制）**：$\mathrm{e}^{j\omega_0 t} x(t) \leftrightarrow X(j(\omega - \omega_0))$。时间域乘复指数，频谱整体搬移——这就是下一篇调制理论的种子。
- **时间尺度**：$x(at) \leftrightarrow \dfrac{1}{|a|} X(j\omega/a)$。信号在时间上压缩，频谱在频率上展宽，且能量守恒。
- **卷积定理**：$x(t) * h(t) \leftrightarrow X(j\omega)\, H(j\omega)$。**时域卷积 ⇔ 频域相乘**。
- **帕塞瓦尔定理（Parseval）**：$\int_{-\infty}^{+\infty} |x(t)|^2 dt = \dfrac{1}{2\pi}\int_{-\infty}^{+\infty} |X(j\omega)|^2\, d\omega$。时域能量等于频域能量。

**核心概念：频率响应（frequency response）** $H(j\omega)$：LTI 系统冲激响应 $h(t)$ 的傅里叶变换。因为卷积定理的存在，$H(j\omega)$ 不只是个记号——它是「系统如何对待每一个频率」的完整档案：$|H|$ 说放行多少，$\angle H$ 说推迟多少。本专题第四篇的全部滤波内容，读的就是这份档案。卷积定理把「时域卷积」等价为「频域相乘」，于是 $Y(j\omega) = H(j\omega)\, X(j\omega)$。**系统的设计从「找 $h$」变成了「挑 $H(j\omega)$」**——滤波（保留哪些频率、滤掉哪些频率）第一次成为一项直接的操作。

**重点：$\mathrm{e}^{j\omega t}$ 是 LTI 系统的本征函数，$H(j\omega)$ 是本征值。** 验证只需一步：$y(t) = \int h(\tau)\mathrm{e}^{j\omega(t-\tau)}d\tau = \mathrm{e}^{j\omega t} H(j\omega)$。这个事实让「系统对每个频率做了什么」一目了然：$|H(j\omega)|$ 是增益，$\angle H(j\omega)$ 是相移。

帕塞瓦尔定理还给了工程师一件趁手工具：**能量守恒的检查**。算完一个信号的频谱后，用 $\int|x|^2$ 与 $\tfrac{1}{2\pi}\int|X|^2$ 对账，两边不等就说明变换算错了、或信号被截断——数值实现里这是最常见的自检手段。更进一步，它把「信号的功率谱」$|X(j\omega)|^2$ 定义为「能量如何随频率分布」——这正是频谱分析仪、音乐均衡器上那些曲线的数学身份。

这套分解还有一层「维度视角」：$x(t)$ 是「一个时间函数」，$X(j\omega)$ 是「它的频率坐标」。两者信息量相同（可逆），但表述方式不同——有些操作在时间坐标下复杂（卷积），在频率坐标下平凡（乘法）；另一些则相反。**傅里叶分析的整个方法论，就是「在两个坐标之间自由切换，永远在更简单的那边干活」。** 后续的滤波、采样、调制，全是这条策略的具体执行。

## 4 收敛与实用视角

并非每个信号都有傅里叶变换——积分必须收敛。工程上实际关心的信号几乎都满足**狄利克雷条件（Dirichlet conditions）**：在任一有限区间内有界、只有有限个间断点与极值点；或如 $1$、$\cos\omega_0 t$ 这类「理想信号」，可通过引入冲激（广义意义下）纳入体系。

**辨析｜易错点：** 把「变换存在」理解成「必须绝对可积」是常见误区。严格说来，绝对可积保证「普通意义」下存在；但 $1$、$\cos$ 这类不绝对可积却工程必备的信号，在**广义函数意义**下依然有变换（含冲激项）。教科书会分别讨论「变换的收敛」与「广义意义的扩展」，考试里见到 $\delta(\omega)$ 不必惊慌——它只是「纯周期信号」这位不速之客的合法身份。实践中绝大多数真实信号都满足工程意义上的可积性，真遇到不收敛的情况，往往是信号里有理想化成分（纯直流、纯周期），换广义视角即迎刃而解。

### 一个完整的小例子：求 $\mathrm{e}^{-at}u(t)$ 的变换

用定义直接算一次，胜过背一百个变换对。对 $x(t) = \mathrm{e}^{-at}u(t)$（$a > 0$）：

$$X(j\omega) = \int_0^{\infty} \mathrm{e}^{-at}\,\mathrm{e}^{-j\omega t}\, dt = \int_0^{\infty} \mathrm{e}^{-(a + j\omega)t}\, dt = \left.\frac{-\mathrm{e}^{-(a+j\omega)t}}{a + j\omega}\right|_0^{\infty} = \frac{1}{a + j\omega}$$

两步读懂：

- **第一步，确定积分下限**：$u(t)$ 把积分下限压到 0，上半限 $\infty$——衰减因子保证收敛，这是 $a > 0$ 的关键；
- **第二步，读出幅度与相位**：$|X(j\omega)| = \dfrac{1}{\sqrt{a^2 + \omega^2}}$，$\angle X = -\arctan(\omega/a)$。$a$ 越大，时域衰减越快，频谱越「矮胖」；$a$ 越小，时域拖得越长，频谱越「高瘦」——**时域越宽、频域越窄**，这是傅里叶分析最朴素的守恒律，也是后面滤波与采样两篇反复出现的「不确定性原理」雏形。

**辨析｜易错点：** 这个例子要求 $a > 0$。若 $a < 0$，$t \to \infty$ 时积分发散，普通意义下变换不存在——这正是下一节拉普拉斯变换要出场接管的场景：把 $j\omega$ 换成 $s$，用实部把「增长信号」也纳进来。

## 5 公式解析：卷积定理

$$y(t) = x(t) * h(t) \quad\Longleftrightarrow\quad Y(j\omega) = X(j\omega)\, H(j\omega)$$

三步拆解：

- **第一步，翻译卷积**：$y(t) = \int x(\tau) h(t-\tau)\, d\tau$，两边同时取傅里叶变换，目标是把 $\int$ 与 $t$ 的耦合解开。
- **第二步，交换积分顺序**：$Y = \int\!\int x(\tau) h(t-\tau) \mathrm{e}^{-j\omega t}\, dt\, d\tau$。令内层作变量替换 $u = t - \tau$，则 $t = u + \tau$，内层化为 $h(u)\mathrm{e}^{-j\omega u}\,du$ 乘上 $\mathrm{e}^{-j\omega \tau}$。
- **第三步，因子分离**：$Y = \underbrace{\int x(\tau)\mathrm{e}^{-j\omega \tau}d\tau}_{X(j\omega)} \cdot \underbrace{\int h(u)\mathrm{e}^{-j\omega u}du}_{H(j\omega)}$。时域的耦合积分，在频域干净地拆成两个独立变换的**乘积**。

直觉：卷积是在时域「揉」两个波形，而每一个纯音 $\mathrm{e}^{j\omega t}$ 穿过系统时只被缩放一次——所以频域里每个频率独立作用、彼此不串扰，总量自然就是「逐频率相乘」。**卷积定理是傅里叶分析献给工程的最贵礼物**：从这篇起，算系统响应不再求积分，查表或乘谱即可。

最后，给本篇一个「位置感」：傅里叶变换并非终点，而是通往拉普拉斯变换的起点——把 $j\omega$ 换成复变量 $s$，一切将自然延展。

## 6 小结

- **傅里叶级数**把周期信号分解为离散谐波 $\sum a_k \mathrm{e}^{jk\omega_0 t}$；周期越大谱线越密，趋于无穷时演化为变换。
- **傅里叶变换对**：分析式 $X(j\omega) = \int x(t)\mathrm{e}^{-j\omega t}dt$ 与综合式 $x(t) = \tfrac{1}{2\pi}\int X(j\omega)\mathrm{e}^{j\omega t}d\omega$。
- 六大性质中，**卷积定理**（时域卷积 ⇔ 频域相乘）与**帕塞瓦尔定理**（时域能量 = 频域能量）最具工程价值。
- **频率响应 $H(j\omega)$** 是系统的频域名片；复指数是其本征函数，$|H|$、$\angle H$ 分别是增益与相移。
- 周期信号的频谱是**冲激**，非周期信号是连续曲线；狄利克雷条件与广义函数共同划定「变换存在」的边界。
- 分解的「坐标」视角：时域与频域互为可逆坐标，永远在更简单的那一边干活。

有了频率这副眼镜，我们终于可以直接「挑选频率」了。傅里叶分析给全专题提供了一套「看频谱」的通用语言：信号有多宽、系统放哪些频率、卷积要花多少力气——都能在这套语言里一次说清。而它的下一站，是把这套语言真正「用起来」：设计一个系统该放行哪些频率、拦下哪些频率。在下一节，我们将把 $H(j\omega)$ 画成图、读出它的性格——**Bode 图、谐振峰与滤波器整形**将把频域分析推向工程实战。
