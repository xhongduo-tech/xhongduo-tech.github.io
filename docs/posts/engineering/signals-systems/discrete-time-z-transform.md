## 为什么数字世界需要自己的变换

前八篇的主战场在连续世界，但真正的数字时代住在**离散世界**：手机里跑的每一个滤波、每一条卷积、每一次降噪，都是对采样得到的序列 $x[n]$ 做的运算。拉普拉斯变换在连续世界的地位，Z 变换在离散世界原样继承——把「差分方程 + 卷积和」的繁重运算变成 z 域里的代数乘法。而它们之间还隔着一座桥：**$z = \mathrm{e}^{sT}$**，把连续世界的左半平面（稳定区）映射成离散世界的单位圆内部。

<span class="marginnote">这篇与第七篇高度平行，学习策略是「对照着读」：$s \leftrightarrow z$，左半平面 $\leftrightarrow$ 单位圆内，微分方程 $\leftrightarrow$ 差分方程，卷积积分 $\leftrightarrow$ 卷积和。抓住这四组对应，离散世界的任何新结果都不会让你觉得陌生。这也是大模型时代你几乎每天要面对的：任何部署在芯片上的信号处理、语音合成里的数字滤波器，都是这套离散理论的产物。</span>

## 1 离散时间信号复习与 Z 变换定义

离散时间信号 $x[n]$ 只在整数时刻取值。它的 Z 变换定义为

$$X(z) = \sum_{n=-\infty}^{+\infty} x[n]\, z^{-n}, \qquad z \text{ 是复变量}$$

把 $z$ 写成极坐标 $z = r\mathrm{e}^{j\omega}$，则 $z^{-n} = r^{-n}\mathrm{e}^{-j\omega n}$——与连续世界的拉普拉斯变换 $\int x(t)\mathrm{e}^{-\sigma t}\mathrm{e}^{-j\omega t}dt$ 逐项对应：$r^{-n}$ 的角色就是那个衰减因子。当 $r = 1$（即 $z$ 在**单位圆**上）时，Z 变换退化为**离散时间傅里叶变换（DTFT）** $X(\mathrm{e}^{j\omega}) = \sum_n x[n]\mathrm{e}^{-j\omega n}$——这是 $s = j\omega$ 在离散世界的同位体。

**收敛域（ROC）**：使级数收敛的 $z$ 的集合，对双边序列是 z 平面上的一个**环带**（$r_1 < |z| < r_2$）。因果序列（$x[n] = 0$ 对 $n < 0$）的 ROC 是最外极点外侧的区域 $|z| > r_{\max}$；反因果序列则反之。**与拉普拉斯域一模一样的告诫：ROC 和代数式合起来才是一个信号。**

**辨析｜易错点：** DTFT 与 Z 变换不是两个独立理论，而是**同一个变换的两个视图**：DTFT 只看单位圆上的取值，Z 变换看整个复平面。因此「DTFT 存在」要求单位圆落在 ROC 内——工程上绝大多数稳定系统都满足，但纯正弦序列（$x[n] = \cos\omega_0 n$）的 Z 变换 ROC 不含单位圆，只能靠冲激（DTFT 广义意义）处理。还有一个和连续世界截然不同的点要警惕：DTFT 是**以 $2\pi$ 为周期**的频率函数（$\mathrm{e}^{-j\omega n}$ 关于 $\omega$ 是 $2\pi$ 周期的），所以离散信号的「频谱」只需在 $(-\pi, \pi)$ 或 $(0, 2\pi)$ 一个周期内给出——第五篇采样定理里「频谱以 $\omega_s$ 复制」的现象，在离散视角下就表现为这条周期性。

## 2 常用变换对与性质

| 时域 $x[n]$ | Z 变换 $X(z)$ | ROC |
| --- | --- | --- |
| $\delta[n]$ | $1$ | 全平面 |
| $u[n]$ | $\dfrac{z}{z-1}$ | $|z| > 1$ |
| $a^n u[n]$ | $\dfrac{z}{z-a}$ | $|z| > |a|$ |
| $a^n \cos(\omega_0 n)\,u[n]$ | $\dfrac{z(z-a\cos\omega_0)}{z^2 - 2az\cos\omega_0 + a^2}$ | $|z| > |a|$ |
| $n a^n u[n]$ | $\dfrac{az}{(z-a)^2}$ | $|z| > |a|$ |
| $a^n \sin(\omega_0 n)\,u[n]$ | $\dfrac{az\sin\omega_0}{z^2 - 2az\cos\omega_0 + a^2}$ | $|z| > |a|$ |

最重要的几条性质与连续域**逐条同构**：

- **时移**：$x[n - n_0] \leftrightarrow z^{-n_0} X(z)$（乘 $z^{-n_0}$，单位延迟是离散系统的「积分」）。
- **卷积定理**：$x[n] * h[n] \leftrightarrow X(z)\, H(z)$。
- **初值定理**：$x[0] = \lim_{z\to\infty} X(z)$（因果序列）。

**核心概念：系统函数 $H(z)$**。离散 LTI 系统冲激响应 $h[n]$ 的 Z 变换；差分方程的两边取 Z 变换后，微分变乘法的对应物是**延迟变乘 $z^{-1}$**，于是常系数线性差分方程变成 z 域的代数方程。数字滤波器的设计——无限冲激响应（IIR）、有限冲激响应（FIR）——全部围绕 $H(z)$ 的极零点布局展开。

## 3 稳定性：单位圆是分界线

**重点：因果离散系统 BIBO 稳定 ⇔ $H(z)$ 的全部极点落在单位圆内。** 这是离散世界最重要的单条判据，与连续世界「极点全在左半平面」严格对应。

![z 平面的极点与单位圆：圆内稳定、圆上临界、圆外不稳定](/images/signals-systems/discrete-time-z-transform-1.svg)

直觉来源：$a^n u[n]$ 是离散的指数信号。$|a| < 1$ 时它逐项衰减、级数收敛；$|a| > 1$ 时逐项爆炸。而 $a$ 正是 $H(z)$ 的极点——**极点的模决定增长还是衰减**，单位圆就是那个「模等于 1」的分界。<span class="marginnote">这个判据和连续世界的对应如此工整，是因为 $z = \mathrm{e}^{sT}$：$s$ 的实部 $\sigma < 0$（左半平面）映射到 $|z| = \mathrm{e}^{\sigma T} < 1$（单位圆内）。写差分方程、布极零点、查稳定——数字滤波器工程师每天在单位圆上工作。</span>

**辨析｜易错点：** 看离散系统的稳定不要类比成「像连续那样看实部正负」。$z$ 平面的极点位置看的是**模长**：$|z| < 1$ 稳定、$|z| > 1$ 不稳定。若把「实部为负」这套连续直觉硬套到 $z$ 平面，连稳定系统都会被误判。

### FIR 与 IIR：极点的两种命运

离散滤波器按冲激响应长短分两大家族。**有限冲激响应（FIR）**：$h[n]$ 只有有限个非零样本，$H(z)$ 是 $z^{-1}$ 的多项式，**只有零点没有（非原点）极点**——永远稳定（全极点都在原点），且可实现严格的线性相位（群延迟为常数，见第四篇）。**无限冲激响应（IIR）**：$h[n]$ 无限延伸，$H(z)$ 是分式，**有非零极点**——同样的截止频率下阶数更低、更省算力，但极点一旦滑出单位圆就爆炸。

这个对照完美呼应第八篇的全部重点：**稳定性判据（单位圆）、群延迟（相位线性）、极点布局（设计自由度）三件事，在 FIR/IIR 之间画出分界。** 工程选型通常一句话：要相位保真选 FIR，要省资源选 IIR。

**辨析｜易错点：** 「FIR 一定稳定」是真的，但别反过来推——IIR 不一定不稳定，只要极点都在单位圆内，IIR 也稳稳当当。稳定性看的是「有没有极点越界」，不是「冲激响应的长短」。

## 4 逆 Z 变换与差分方程求解

逆变换的主流工程做法依旧是**部分分式展开**：把 $X(z)$ 展开为 $\dfrac{A_k z}{z - p_k}$ 形式的项，每项对应 $A_k p_k^{\,n}u[n]$（取因果 ROC）。重根项对应 $n\,p^n$ 之类的形态。

求解差分方程 $y[n] - a y[n-1] = x[n]$（一阶 IIR，即「递归平均器」）的完整流程：

1. **两边取 Z 变换**：$Y(z) - a z^{-1}Y(z) = X(z)$（忽略初值）；
2. **解代数方程**：$Y(z) = \dfrac{X(z)}{1 - az^{-1}} = \dfrac{z}{z-a}\,X(z)$；
3. **代 $X(z) = \dfrac{z}{z-1}$（阶跃输入）**，部分分式展开，查表得 $y[n] = \dfrac{1 - a^{n+1}}{1 - a}\,u[n]$。

若 $|a| < 1$，$n \to \infty$ 时 $y[n] \to \dfrac{1}{1-a}$——输出收敛到稳态，这就是**稳定**；若 $|a| > 1$，输出发散——**不稳定**。同一个差分方程，极点 $z = a$ 的模决定了行为，和第三篇里时域卷积的结论完美闭环。

**公式解析：为什么 $a^n u[n] \leftrightarrow \dfrac{z}{z-a}$，且 ROC 是 $|z| > |a|$**

**第一步，套定义**：$X(z) = \sum_{n=0}^{\infty} a^n z^{-n} = \sum_{n=0}^{\infty} (a z^{-1})^n$。
- **第二步，套等比级数**：$\sum_{n=0}^{\infty} r^n = \dfrac{1}{1-r}$ 当且仅当 $|r| < 1$；这里 $r = a z^{-1}$，收敛条件 $|a z^{-1}| < 1$ 即 $|z| > |a|$。
- **第三步，化简**：$\dfrac{1}{1 - a z^{-1}} = \dfrac{z}{z-a}$。

直觉：**Z 变换把「几何级数求和」变成「有理函数」，把收敛条件变成 ROC。** 离散指数的收敛完全由公比 $a$ 的模决定——这正是一切稳定判据的源头。顺手再记一条连带结论：双边序列的 ROC 若包含单位圆，其 DTFT 就存在——于是「Z 变换的环带」与「DTFT 是否收敛」被同一句话绑定，工程上查 ROC 就能同时回答两个问题。

还有一对「离散专属」的概念值得点破：采样后的序列 $x[n]$，其「时间」本身是离散的，这带来一个与连续世界截然不同的自由——**无需任何物理实现，纯软件就能完成全部信号处理**。数字滤波器的阶数、系数，统统只是内存里的数组。这也是为什么现代信号处理几乎全面数字化：同样的设计，在离散世界可以用算法精确实现、可复现、可微调，而模拟实现总被元件误差拖累。

## 5 从采样到 z 域：与连续世界的完整对账

第五篇讲过采样，本篇讲过 $z = \mathrm{e}^{sT}$，现在把全专题的「两岸」对个总账：

| 连续时间 | 离散时间 |
| --- | --- |
| $x(t)$ | $x[n]$ |
| 拉普拉斯变换 $X(s)$ | Z 变换 $X(z)$，$z = \mathrm{e}^{sT}$ |
| 傅里叶变换 $X(j\omega)$ | DTFT $X(\mathrm{e}^{j\omega})$（单位圆上） |
| 微分方程 | 差分方程（延迟 $z^{-1}$） |
| 稳定 ⇔ 极点实部 $< 0$ | 稳定 ⇔ 极点 $|z| < 1$ |
| 卷积积分 $x * h$ | 卷积和 $x[n] * h[n]$ |

<span class="marginnote">这张表是信号与系统整门课的「地图」：拿着一张 $s$ 域或 $z$ 域的问题，先在表里找到它落在哪个格子，再决定用积分还是求和、用左半平面还是单位圆。学完全专题后回头，你会发现所有「新」工具都是这张表在两种世界里的同一条规律的两次投影。</span>

至此，离散世界的分析工具已经齐备，它与连续世界也完成了对账。

## 6 小结

- **Z 变换** $X(z) = \sum x[n] z^{-n}$ 是离散世界的拉普拉斯变换；单位圆上即 DTFT。
- **ROC** 是环带，与代数式共同确定信号；因果序列 ROC 在最外极点外侧。
- 常用变换对（$u[n]$, $a^n u[n]$）与性质（时移乘 $z^{-1}$、卷积定理）与连续域同构。
- **稳定 ⇔ 全部极点落在单位圆内**，对应连续世界「极点全在左半平面」。
- 逆变换用部分分式展开；差分方程求解 = 取变换 → 代数解 → 反变换三步。
- $z = \mathrm{e}^{sT}$ 把连续与离散两套分析完整接轨，全专题由此闭环。

至此，连续与离散两个世界的工具箱都已齐备。但所有这些系统——滤波器、放大器、控制器——都有一个共通的工程课题还没展开：**怎么让一个系统的行为符合预期？** 离散世界这一整章还可以换个角度收束：无论分析还是设计，数字系统的「地心引力」都是单位圆——极点在圆内才安全，频谱以 $2\pi$ 为周期才自洽。理解了这一点，z 域的一切结论都有了一个共同锚点。而在这一章之后，我们把连续与离散两套分析都握在手里，下一节的课题终于可以登上台面：怎样用闭环让一个系统「听话」。在下一节，**线性反馈系统**将迎来本专题的最后一位主角：用一点点「输出回看输入」的闭环，换取稳定与精确。
