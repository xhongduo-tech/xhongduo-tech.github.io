## 为什么卷积是整门课的支点

上一篇末我们留下了一个承诺：线性时不变（LTI）系统的全部行为由一个函数决定。这一篇兑现它。**卷积（convolution）**是这个专题里出现频率最高的运算，原因只有一条：**只要系统是 LTI，输出就必然是输入与「单位冲激响应」的卷积**——没有例外，没有条件分支。你后面学的傅里叶变换、拉普拉斯变换、Z 变换，本质上都是在问同一个问题：怎样把这条卷积公式变成更方便的乘法？

这个「卷」的思路还远超信号处理。<span class="marginnote">卷积神经网络（CNN）的核心算子也叫卷积：把输入图像块与一个小核逐点相乘求和。数学上那叫互相关（cross-correlation），只差一个「核是否翻转」的记号，思想完全一致。也就是说——你现在学的这条积分，二十年后会在你最常用的大模型视觉骨干里再次登场。</span>先把它学扎实，全专题后面的每一篇都靠它站立。

## 1 从冲激分解到卷积公式

回顾上一篇的「冲激分解」：

$$x(t) = \int_{-\infty}^{+\infty} x(\tau)\, \delta(t - \tau)\, d\tau$$

现在把 $x(t)$ 喂给一个 LTI 系统 $\mathcal{T}$。线性与**时不变**两个性质依次发力：

- 线性告诉我们：输入拆成无穷多个加权冲激，输出就是每个冲激响应的**加权和**，所以 $\mathcal{T}\{\int x(\tau)\delta(t-\tau)\,d\tau\} = \int x(\tau)\, \mathcal{T}\{\delta(t-\tau)\}\, d\tau$。
- 时不变告诉我们：冲激 $\delta(t-\tau)$ 的响应，等于冲激 $\delta(t)$ 的响应平移 $\tau$。

记 $h(t) = \mathcal{T}\{\delta(t)\}$ 为系统的**单位冲激响应（impulse response）**，则：

$$y(t) = \int_{-\infty}^{+\infty} x(\tau)\, h(t - \tau)\, d\tau$$

这就是**卷积积分（convolution integral）**，简记 $y(t) = x(t) * h(t)$。式子里的积分限是全实轴，具体落到哪里，取决于 $x$ 与 $h$ 的支撑范围——实际计算时先画两张图找重叠区，是手工卷积的标准姿势。

**重点：线性 + 时不变 → 卷积。** 缺了任何一个性质，这条公式都不成立。非线性系统的行为必须依赖输入的具体形态，无法用单个 $h(t)$ 概括；时变系统的 $h$ 会随绝对时刻漂移，积分也无法这样简洁地平移。换句话说，**卷积不是「一种系统」，而是「LTI 系统的身份证」**——判断一个系统能不能用卷积描述，先看它是不是 LTI。

离散时间的情形完全平行：$x[n]$ 喂给离散 LTI 系统，输出为**卷积和（convolution sum）**

$$y[n] = \sum_{k=-\infty}^{+\infty} x[k]\, h[n - k]$$

积分换成求和，其余含义一模一样。

## 2 卷积的三步操作

公式里的积分究竟在算什么？把 $h(t-\tau)$ 拆开看，它包含了三个动作：

1. **翻转（flip）**：$h(\tau)$ 关于纵轴翻转为 $h(-\tau)$；
2. **平移（shift）**：把 $h(-\tau)$ 向右平移 $t$，得到 $h(t-\tau)$；
3. **相乘并积分（multiply and integrate）**：对每个固定的 $t$，把 $x(\tau)$ 与 $h(t-\tau)$ 逐点相乘，再对 $\tau$ 积分，得到单个数值 $y(t)$。

让 $t$ 扫过整个实轴，就得到整条 $y(t)$ 曲线。

![卷积的三步操作：翻转、平移、相乘并积分](/images/signals-systems/lti-systems-and-convolution-1.svg)

以两个同宽矩形脉冲的卷积为例（上图）：$x(t)$ 是 $[0,2]$ 上的高度 1 脉冲，$h(t)$ 同样。取 $t=1$ 时，$h(t-\tau)$ 是 $[-1,1]$ 上的脉冲，与 $x$ 的重叠区是 $[0,1]$，面积为 1，故 $y(1) = 1$；$t=0$ 时重叠区缩成一点，$y(0)=0$；$t=2$ 时完全重合，$y(2)=2$。把 $y(t)$ 画出来就是一个从 0 升到 2 再降到 0 的**三角形**——脉冲的宽度相加（2+2=4），峰值是高度的乘积再乘宽度（$1\times1\times2=2$）。**卷积把两个方波「揉」成了一个更平滑的三角波**，这是「信号被系统平滑」的第一印象——越是把 $h$ 拉宽，输出越圆钝、高频细节越少，卷积天然带低通属性。

**辨析｜易错点：** 卷积满足交换律 $x * h = h * x$，但**别忘了中间那步翻转**。两个函数相乘再积分不叫卷积，叫**相关（correlation）**。工程速记：卷积 = 相关 + 把其中一个先翻转。还有一个常见误读：既然 $x * h = h * x$，就误以为「让谁翻转都一样」——是的，数学上任意一方翻转皆可，但**每一步只翻转一方、且只翻一次**，两边同时翻就错了。

## 3 卷积的代数性质

卷积作为一种运算，有三条漂亮的代数规则，它们让复杂系统可以像搭积木一样组合：

- **交换律**：$x(t) * h(t) = h(t) * x(t)$。从哪个信号翻转都一样。
- **结合律**：$(x * h_1) * h_2 = x * (h_1 * h_2)$。级联的 LTI 系统可以合并：系统 1 串联系统 2，等价于一个冲激响应为 $h_1 * h_2$ 的单一系统。
- **分配律**：$x * (h_1 + h_2) = x * h_1 + x * h_2$。并联的 LTI 系统可以叠加。

<span class="marginnote">结合律说明「先滤波再滤波」可以一次算完，这正是通信系统里「信道 + 接收滤波器」合并的数学依据；分配律说明「一条信号分两条路处理再相加」与「先合并再处理」等价，这是工程里并联分路设计的合法性证明。</span>

另外还有三个「常识性」但必须记住的结论：

- **冲激是卷积的单位元**：$x(t) * \delta(t) = x(t)$，$x(t) * \delta(t - t_0) = x(t - t_0)$。与 $\delta$ 卷积等于「把信号搬到冲激所在的位置」。
- **LTI 系统的因果性**：$h(t) = 0$ 对所有 $t < 0$。因为输出不能「预知」未来的输入。
- **LTI 系统的稳定性**：$\int_{-\infty}^{+\infty} |h(t)|\, dt < \infty$（离散时 $\sum_k |h[k]| < \infty$）。这正是 BIBO 稳定的充要条件——有界输入与可积的 $h$ 卷积，结果必有界。

动手算卷积的「找重叠区」习惯，值得在这里郑重强调：教科书上所有卷积例题，第一步都是画 $x(\tau)$ 与 $h(t-\tau)$ 两张草图，按 $t$ 的取值范围把积分限分段。分段点来自两者的端点，段内被积函数不变形。**画图找限，比死记公式可靠得多**——考试里的卷积题失分，九成发生在积分限取错，而非积分本身算错。

## 4 单位阶跃响应与可逆性

冲激响应不是 LTI 系统唯一的「名片」。若输入是单位阶跃 $u(t)$，输出称为**单位阶跃响应（step response）** $s(t)$，且

$$s(t) = u(t) * h(t) = \int_{-\infty}^{t} h(\tau)\, d\tau, \qquad h(t) = \frac{ds(t)}{dt}$$

也就是说，阶跃响应是冲激响应的积分，冲激响应是阶跃响应的导数。实验上往系统里灌一个阶跃比灌一个理想冲激容易得多——所以工程上常先测阶跃响应再微分求得 $h(t)$。

关于**可逆性**：LTI 系统可逆当且仅当存在逆系统的冲激响应 $h_i(t)$ 使 $h * h_i = \delta$。直观上，可逆 = 输出信息无丢失。<span class="marginnote">最经典的反例：理想低通滤波把高频一刀切掉，切掉的信息再也找不回来，故不可逆；而「延迟 $t_0$」的逆就是「提前 $t_0$」。对不可逆系统做反卷积（如把模糊照片复原）必须引入正则化，这是后面数值方法专场的伏笔。</span> 工程上判断可逆有一条实用捷径：在频域看 $H(j\omega)$ 是否有零值点——频域有零点意味着那个频率的信息被彻底滤除，任何逆操作都无从恢复；反之若 $|H(j\omega)|$ 处处非零，理论上存在逆系统（实际还要操心稳定性与噪声放大，但这已经是下一层的问题了）。

## 5 公式解析：用 $RC$ 电路走一遍卷积

一个电压源 $x(t)$ 驱动 $RC$ 低通电路，电容电压为 $y(t)$。它的冲激响应是衰减指数：

$$h(t) = \frac{1}{RC}\, \mathrm{e}^{-t/(RC)}\, u(t)$$

对应微分方程 $RC\,y'(t) + y(t) = x(t)$。若输入是单个矩形脉冲 $x(t) = \begin{cases} 1, & 0 \le t \le 1 \\ 0, & \text{其他} \end{cases}$，则输出

$$y(t) = x(t) * h(t) = \int_{-\infty}^{+\infty} x(\tau)\, h(t-\tau)\, d\tau$$

三步拆解这条积分：

- **第一步，确定积分限**：$x(\tau) = 1$ 仅当 $\tau \in [0,1]$；$h(t-\tau) \neq 0$ 仅当 $t - \tau \ge 0$，即 $\tau \le t$。两者同时成立要求 $\tau \in [0, \min(t, 1)]$ 且 $t \ge 0$。
- **第二步，代入 $h$ 并积分**：$y(t) = \dfrac{1}{RC}\int_0^{\min(t,1)} \mathrm{e}^{-(t-\tau)/(RC)}\, d\tau$。把与 $\tau$ 无关的 $\mathrm{e}^{-t/(RC)}$ 提出，对 $\mathrm{e}^{\tau/(RC)}$ 积分。
- **第三步，分两段读出物理**：$0 \le t \le 1$ 时 $y(t) = 1 - \mathrm{e}^{-t/(RC)}$（电容充电）；$t \ge 1$ 时 $y(t) = \big(1 - \mathrm{e}^{-1/(RC)}\big)\mathrm{e}^{-(t-1)/(RC)}$（脉冲结束后放电）。$RC$ 越大，充放电越慢——这就是时间常数（time constant）的直观含义。

**辨析｜易错点：** 上一步算出的分段点 $t=1$ 来自脉冲宽度，与 $RC$ 无关；而充放电的「快慢」只由 $RC$ 决定。初学者常把两者混为一谈：**分段的位置由输入决定，段内的形状由系统决定。**

## 6 小结

- 卷积的完整心智模型：翻转 → 平移 → 相乘并积分，画图找重叠区是手工计算的可靠起点。

- **卷积公式**：$y(t) = \int_{-\infty}^{+\infty} x(\tau) h(t-\tau)\, d\tau$，它由线性 + 时不变唯一推出，是 LTI 系统的「总纲」。
- 卷积的**三步**：翻转、平移、相乘并积分；记法 $y = x * h$。
- 三条代数律（交换、结合、分配）让 LTI 系统可**级联合并、并联叠加**；$\delta$ 是卷积的单位元。
- **因果** $\Leftrightarrow h(t)=0\ (t<0)$；**BIBO 稳定** $\Leftrightarrow \int|h|\,dt < \infty$。
- 阶跃响应 $s(t)$ 与冲激响应 $h(t)$ 互为积分 / 微分；可逆 $\Leftrightarrow$ 存在 $h_i$ 使 $h*h_i = \delta$。

卷积把时域问题「积」成了一个积分，但计算卷积并不总是轻松。在下一节，我们将用**傅里叶分析**换一副眼镜：把信号分解成复指数，把卷积变成普通的乘法——积分的困难将迎刃而解。
