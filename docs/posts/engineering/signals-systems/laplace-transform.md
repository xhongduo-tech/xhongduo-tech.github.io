## 为什么还要一个「升级版傅里叶」

第三篇的傅里叶变换有个隐蔽的局限：它只对「足够规矩」的信号收敛——很多工程上真正的「问题信号」（增长型指数、不稳定系统的响应）反而不在它的射程内。而工程师真正关心的系统分析，恰恰最怕不稳定。**拉普拉斯变换（Laplace transform）**是傅里叶变换的「放宽版」：把频率从纯虚数 $j\omega$ 推广到复变量 $s = \sigma + j\omega$，多出来的实部 $\sigma$ 相当于给信号乘上一个衰减因子 $\mathrm{e}^{-\sigma t}$，把「爆炸」的信号压成「能积」的信号。于是增长信号、不稳定系统全部纳入统一框架。

更妙的是，微分方程与系统函数在拉普拉斯域变成**纯代数问题**：微分变成乘 $s$，积分变成除 $s$，卷积依旧变成相乘。<span class="marginnote">这个「微分变乘法」的历史可追溯到 18 世纪欧拉与拉普拉斯对幂级数的推广；到了 20 世纪初，电气工程师黑维赛（Heaviside）用「算子法」解电路方程时虽不严格却极好用，后来才被严格化为拉普拉斯变换——教科书上的定义，是先有工程直觉、后有数学兜底的产物。</span>本篇既是分析工具，也是第九篇「反馈系统」的语法准备。

## 1 定义与收敛域

**拉普拉斯变换（Laplace transform）**：双边拉普拉斯变换定义为

$$X(s) = \int_{-\infty}^{+\infty} x(t)\, \mathrm{e}^{-st}\, dt, \qquad s = \sigma + j\omega$$

逆变换 $x(t) = \dfrac{1}{2\pi j}\int_{\sigma-j\infty}^{\sigma+j\infty} X(s)\mathrm{e}^{st}\, ds$ 沿复平面上一条竖直线积分——考试不常直接算它，工程上几乎总用**部分分式展开**替代（见第 4 节）。

与傅里叶的关键差别在于：积分是否收敛，取决于 $\sigma$ 的取值。**收敛域（Region of Convergence，ROC）**：使积分收敛的全体 $s$ 构成的区域——对双边变换，ROC 总是一条竖直带或半个平面。

**重点：ROC 是拉普拉斯变换的「另一半」。** 同一个代数表达式 $X(s)$，配不同 ROC 代表**不同的信号**。例如 $\dfrac{1}{s+1}$ 配 ROC $\{\sigma > -1\}$ 是因果信号 $\mathrm{e}^{-t}u(t)$；配 ROC $\{\sigma < -1\}$ 却是反因果信号 $-\mathrm{e}^{-t}u(-t)$。教材里「一个 $X(s)$ 对应无数信号，ROC 必须同时给出」的告诫，是拉普拉斯变换区别于傅里叶变换的最大陷阱。<span class="marginnote">这个「代数函数 + ROC 才是一个信号」的教训，在离散世界（Z 变换）里会原封不动地再现。数学上，这正是「有理函数的洛朗展开可绕不同中心」的直观版本——只是信号处理把它讲成了工程语言。</span>

**辨析｜易错点：** 不要把「拉普拉斯变换的 $s$」当实数。$s$ 是复变量，实部 $\sigma$ 管收敛、虚部 $\omega$ 管振荡。ROC 的边界必然由**极点**（使 $X(s) \to \infty$ 的点）构成——ROC 内不允许有极点，它总是「最右极点右侧」或「两极点之间」或「最左极点左侧」的某个带。

## 2 极点、零点与系统函数

对 LTI 系统，冲激响应 $h(t)$ 的拉普拉斯变换称为**系统函数（system function）** $H(s)$，输出为 $Y(s) = H(s) X(s)$。绝大多数工程系统是「分式」：

$$H(s) = \frac{N(s)}{D(s)} = \frac{b_m s^m + \cdots + b_0}{s^n + a_{n-1}s^{n-1} + \cdots + a_0}$$

- $N(s)$ 的根叫**零点（zeros）**，$D(s)$ 的根叫**极点（poles）**；
- 若 $n \ge m$，系统**因果**时 ROC 为最右极点右侧的半平面；
- **极点全在左半平面**（实部全部 < 0）⇔ 因果系统 **BIBO 稳定**。

![s 平面的极点与收敛域：ROC 为最右极点右侧的半平面](/images/signals-systems/laplace-transform-1.svg)

上图画了一个典型场景：两个极点在左半平面实轴上（$\sigma = -1, -2$），ROC 是 $\sigma > -1$ 的整个右半区域——这个系统因果且稳定。**判断稳定只需要看极点，不需要知道输入**：任何因果 LTI 系统的稳定性完全由系统函数决定。<span class="marginnote">这与第二篇「BIBO 稳定 ⇔ $\int|h|dt < \infty$」完全一致：$\mathrm{e}^{\alpha t}u(t)$ 的积分收敛当且仅当 $\alpha < 0$，而 $\alpha$ 正是最右极点的实部。两条语言（时域积分 / 频域极点）说的是同一件事。</span>

## 3 性质：微分变乘法

拉普拉斯变换承袭傅里叶的全部性质（线性、时移、卷积定理、帕塞瓦尔等），并多了两条「微分方程专用」性质：

- **时域微分**：$x'(t) \leftrightarrow s X(s) - x(0^-)$（含初值项，需注意单边/双边区别）；
- **时域积分**：$\int_{-\infty}^t x(\tau)\,d\tau \leftrightarrow \dfrac{X(s)}{s}$；
- **$s$ 域位移**：$\mathrm{e}^{s_0 t}x(t) \leftrightarrow X(s - s_0)$——这就是它天然处理**阻尼振荡**的原因：$\mathrm{e}^{-\sigma_0 t}\cos\omega_0 t\, u(t)$ 的变换是 $\cos\omega_0 t$ 的变换左移 $\sigma_0$。

**重点：求解线性常系数微分方程的流程被压缩成三步。** 对微分方程两边取拉普拉斯变换 → 微分变 $s$ 的幂 → 解**代数方程**得 $Y(s)$ → 部分分式展开后查表还原 $y(t)$。初值条件自然出现在变换里，不必再分段求特解通解——这是拉普拉斯变换统治「电路 + 控制系统」课程的原因。

**辨析｜易错点：** 双边变换下「时域微分对应乘 $s$」这句话只对「ROC 内」成立，且初学者常忘掉初值项 $x(0^-)$。用单边变换解初值问题时，$x'(t) \leftrightarrow sX(s) - x(0^-)$ 的初值项**必须带上**，否则微分方程的解会差一个常数——这正是「在零时刻开启系统」的直流响应。

最后补一张「条件反射」级常用变换对，配合部分分式直接查表：

| 时域 $x(t)$ | $X(s)$ | ROC |
| --- | --- | --- |
| $\delta(t)$ | $1$ | 全平面 |
| $u(t)$ | $\dfrac{1}{s}$ | $\sigma > 0$ |
| $\mathrm{e}^{-at}u(t)$ | $\dfrac{1}{s+a}$ | $\sigma > -a$ |
| $t^n u(t)$ | $\dfrac{n!}{s^{n+1}}$ | $\sigma > 0$ |
| $\mathrm{e}^{-at}\cos(\omega_0 t)u(t)$ | $\dfrac{s+a}{(s+a)^2+\omega_0^2}$ | $\sigma > -a$ |
| $\mathrm{e}^{-at}\sin(\omega_0 t)u(t)$ | $\dfrac{\omega_0}{(s+a)^2+\omega_0^2}$ | $\sigma > -a$ |

注意每一行的 ROC 都是「最右极点右侧」——因为教材默认的因果惯例。同一个代数式若配左侧 ROC，就对应反因果信号（第 1 节那句话的复读）。表格背熟后，部分分式展开 + 查表几乎可以无脑完成所有初等逆变换。

## 4 逆变换：部分分式展开

工程上不直接积分求逆，而是把 $X(s)$ 拆成「已知变换对」的叠加。设 $X(s) = \dfrac{N(s)}{D(s)}$ 为真分式，$D(s)$ 有互异实根 $p_1,\dots,p_n$：

$$X(s) = \sum_{k=1}^{n} \frac{A_k}{s - p_k}, \qquad A_k = (s - p_k) X(s)\Big|_{s = p_k}$$

每个 $\dfrac{A_k}{s - p_k}$ 对应时域项 $A_k \mathrm{e}^{p_k t} u(t)$（取 ROC 为右侧半平面时）。重根、复根则分别需要 $(s-p)^{-r}$ 项与「配平方 + 正余弦变换对」。**根决定时域形态**：实根 → 指数，共轭复根 → 衰减/增长振荡，这正是「极点位置 ⇔ 响应波形」这条直觉的代数来源。

### 初值定理与终值定理：不求逆变换读答案

很多时候我们只想知道响应的「起跑」与「终点」，不必把整条曲线算出来。两个定理直接给答案：

- **初值定理**（因果信号）：$x(0^+) = \lim_{s\to\infty} s X(s)$；
- **终值定理**：$\lim_{t\to\infty} x(t) = \lim_{s\to 0} s X(s)$（要求 $sX(s)$ 的极点都在左半平面，即系统确实收敛到稳态）。

例如 $X(s) = \dfrac{1}{s(s+2)}$：初值 $x(0^+) = \lim_{s\to\infty} s \cdot \dfrac{1}{s(s+2)} = 0$；终值 $x(\infty) = \lim_{s\to0} s \cdot \dfrac{1}{s(s+2)} = \dfrac12$。**不展开任何分式、不查任何表**，两条极限就完成「起终点体检」。终值定理是第九篇反馈系统里算稳态误差的利器，那里会再次用它。

### 一个完整的例子：二阶系统怎么解

求解 $y'' + 3y' + 2y = u(t)$，初值 $y(0) = y'(0) = 0$（单位阶跃激励）。

- **第一步，两边取变换**：$s^2 Y + 3s Y + 2Y = \dfrac{1}{s}$（初值为零，无额外项）。
- **第二步，解代数方程**：$Y(s) = \dfrac{1}{s(s^2 + 3s + 2)} = \dfrac{1}{s(s+1)(s+2)}$。
- **第三步，部分分式**：$Y = \dfrac{A}{s} + \dfrac{B}{s+1} + \dfrac{C}{s+2}$，留数法得 $A = \tfrac12, B = -1, C = \tfrac12$。
- **第四步，逐项查表**：$y(t) = \tfrac12 - \mathrm{e}^{-t} + \tfrac12 \mathrm{e}^{-2t}$，$t \ge 0$。

注意终值 $\tfrac12$ 与终值定理算得一致——**代数求解与极限判读互相验证**。而三个极点 $0, -1, -2$ 全部在左半平面，系统稳定、响应收敛，与「极点位置 ⇔ 响应形态」的对应再次闭合。

## 5 公式解析：拉普拉斯变换为什么能驯服增长信号

$$X(s) = \int_{-\infty}^{+\infty} x(t)\,\mathrm{e}^{-st}\,dt = \int_{-\infty}^{+\infty} \left[x(t)\,\mathrm{e}^{-\sigma t}\right]\,\mathrm{e}^{-j\omega t}\,dt$$

三步拆解这条「驯服」的机制：

- **第一步，拆复指数**：$\mathrm{e}^{-st} = \mathrm{e}^{-\sigma t}\,\mathrm{e}^{-j\omega t}$——实部 $\sigma$ 与虚部 $j\omega$ 分家。
- **第二步，识别括号**：方括号里是 $x(t)$ 乘上实衰减因子 $\mathrm{e}^{-\sigma t}$；外层 $\mathrm{e}^{-j\omega t}$ 正是傅里叶变换的核。所以拉普拉斯变换 = **「先乘衰减因子，再做傅里叶变换」**。
- **第三步，读出收敛**：只要选 $\sigma$ 大到让 $|x(t)|\mathrm{e}^{-\sigma t}$ 可积，变换就存在。增长信号 $\mathrm{e}^{3t}u(t)$ 傅里叶发散，但选 $\sigma > 3$ 后 $\mathrm{e}^{(3-\sigma)t}$ 衰减，收敛达成。ROC 于是天然是「$\sigma$ 足够大」的半平面。

一句话直觉：**拉普拉斯用「衰减滤镜」看世界**——滤镜调得够狠，再狂暴的增长信号也能看个通透；而滤镜的调档范围，正是 ROC。

## 6 小结

- **拉普拉斯变换**把傅里叶推广到 $s = \sigma + j\omega$，用实部 $\sigma$ 的衰减因子驯服增长信号。
- **ROC** 与 $X(s)$ 合起来才确定一个信号；ROC 以极点为边界，因果信号的 ROC 是最右极点右侧。
- **系统函数** $H(s) = N(s)/D(s)$；**极点全在左半平面 ⇔ 因果系统稳定**，稳定性只看极点、与输入无关。
- 微分变乘法、积分变除法，常系数微分方程求解压缩为「变换 → 解代数 → 反变换」三步。
- 逆变换主流做法是**部分分式展开**；根的实部 / 共轭虚部直接对应时域的指数与振荡形态。

有了能分析「任何」信号的拉普拉斯域，模拟世界的工具箱已基本齐备。但现代信号处理还有一半在数字世界：在下一节，**离散时间信号与 Z 变换**将把这套分析完整地搬到样本序列上——你会发现，从 $s$ 域到 $z$ 域，故事几乎一模一样，只是那根稳定性分界线换了一个姿态。
