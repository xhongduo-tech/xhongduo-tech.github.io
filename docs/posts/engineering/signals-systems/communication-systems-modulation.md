## 为什么调制是通信的起点

上一篇把连续信号安全地数字化了。但数字信号还**不会飞**：一段 4 kHz 的语音信号直接发射，波长会是惊人的几十公里，天线要做得像山一样高；而且所有电台都挤在同一个低频段，一开声就「撞车」。**调制（modulation）**解决这两个问题——把基带信号（要传的消息）搬到高频载波上：天线尺寸随之缩小到厘米级，不同电台各占一个频段互不干扰。把频谱「扛起来飞」的，正是我们早已熟悉的**频移性质**。

这一篇是傅里叶分析的第一场大型实战。你会在其中反复看到同一张面孔：**时域相乘 $\Leftrightarrow$ 频域搬移**。理解了这个等价，调制、解调、复用、下变频就全都是一件事。<span class="marginnote">Wi-Fi、5G、蓝牙、调频广播，表面千差万别，底层都是「把信息信号乘上一个高频载波再发射」。你看手机信号强度那几格，本质是「调制后的电磁波飞到你身边、被天线收集」的宏观表现。</span>

## 1 幅度调制（AM）：时域乘法、频域搬家

**幅度调制（Amplitude Modulation，AM）**：让载波的幅度随消息 $m(t)$ 变化。最简单的两种形式：

- **双边带抑制载波（DSB-SC）**：$y(t) = m(t)\cos(\omega_c t)$。频谱上，时域相乘等价于频域卷积，余弦的频谱是 ±ωc 两枚冲激，卷积结果就是把 $M(j\omega)$ 复制到 $\pm\omega_c$ 两侧：

$$Y(j\omega) = \frac{1}{2}\left[ M\!\left(j(\omega-\omega_c)\right) + M\!\left(j(\omega+\omega_c)\right) \right]$$

- **标准 AM（带载波）**：$y(t) = A_c[1 + m(t)]\cos(\omega_c t)$。除了两个边带，还在 $\pm\omega_c$ 处保留了一根**载波冲激**（上面公式里来自常数 1 的部分）。

![幅度调制把基带频谱搬到载波两侧](/images/signals-systems/communication-systems-modulation-1.svg)

图中那两份「搬走的频谱」分别称为**上边带（upper sideband）**与**下边带（lower sideband）**。信息 $m(t)$ 完全装在两份边带里——所以理论上载波本身并不携带信息，标准 AM 保留载波，纯粹是为了让接收机**解调简单**。

**重点：带宽翻倍是 AM 的代价。** 基带占 $(-\omega_M, \omega_M)$，调制后占 $(\omega_c-\omega_M, \omega_c+\omega_M)$，总带宽 $2\omega_M$。工程里「带宽是稀缺资源」，于是有了各种省带宽的变体：单边带（SSB，只发一个边带）、残留边带（VSB）——各自在接收复杂度与带宽之间取舍。AM 的带宽还提醒一个常识：收音机 AM 波段只能容纳音质一般的窄带语音/音乐，调频 FM 波段带宽宽得多，音质自然更好——这不是玄学，是频谱搬移的必然结果。

回到频域再看一眼带宽账：把两份边带全保留的 DSB 占 $2\omega_M$；只发一个边带的 SSB 占 $\omega_M$——省一半带宽，却要接收端精确重建缺失的另一半（正交解调、相位估计）。VSB 则折中：留一个边带的大部 + 另一个边带的残余，兼顾带宽与解调复杂度。这条「带宽 ↔ 接收复杂度」的权衡线，贯穿模拟通信的全部设计选择。

## 2 解调：怎么把消息「接回来」

- **同步解调（synchronous / coherent demodulation）**：接收端再乘一次同频同相载波 $\cos(\omega_c t)$，频谱上再搬移一次：$Y(j\omega)$ 的一半回到零频（这就是要的消息），另一半搬到 $\pm 2\omega_c$。用低通滤掉高频，就得到 $\frac{1}{2}m(t)$。代价是**接收端必须精确知道载波的频率与相位**——故称「同步」。

- **包络检波（envelope detection）**：标准 AM 在 $|m(t)| < 1$（不过调）时，载波幅度的**包络**就是 $m(t)$ 的形状，于是用「整流 + 低通」这样的简单电路就能解出消息。这就是**普通广播收音机极便宜**的原因——一台简陋的二极管检波电路就够用。<span class="marginnote">AM 广播电台用「带载波」而不用 DSB-SC，正是工程权衡的典型：多花一点点发射功率，换来接收端省掉昂贵的同步电路。100 年前的无线电能普及到千家万户，靠的就是这个「把复杂度留给发射端」的巧思。</span>

**辨析｜易错点：** 同步解调要求本地载波**同频**；频率不准，消息会被「搬」到某个差频上而非零频。更隐蔽的是**相位**：本地载波与发送载波相位相差 $\theta$，解调结果会乘上 $\cos\theta$——相角差 90° 时消息直接消失（正交不可解）。「失锁」「失步」这些通信术语，本质都是这个 $\cos\theta$ 因子在作怪。工程对策是**锁相环（PLL）**：用本地振荡器与接收信号的相位差驱动一个环路，把频率与相位「锁」到一致——这是反馈思想（第九篇）在通信里的经典应用，也是「相位同步」从理论到硬件的落地。

## 3 频率调制与相位调制

幅度调制让幅度携带消息，**频率调制（FM）**与**相位调制（PM）**则让载波的**瞬时相位**携带消息：

$$y_{\text{FM}}(t) = A_c\cos\!\left(\omega_c t + k_f\!\!\int_{-\infty}^{t} m(\tau)\,d\tau\right)$$

频率调制的第一好性质：**抗噪声**。幅度上的噪声（雷电、发动机火花）对 FM 的影响被天然抑制，因为信息不在幅度里——所以调频广播音质远好于调幅广播，却更费带宽。<span class="marginnote">FM 抗噪的原因可用频域粗略理解：加性噪声主要污染幅度，而 FM 的频谱在噪声背景中保持「瞬时频率」这个维度相对干净。香农告诉我们，换带宽换来的信噪比提升是「对等交易」——FM 正是这条交易在模拟世界的化身。</span>

**辨析｜易错点：** FM 与 PM 的关系不是「两个并列的东西」，而是**一体两面**：对消息先积分再调相得到 FM，先微分再调频得到 PM。考试里「FM 的频谱里 m(t) 如何嵌入」这类问题，关键在于瞬时频率 $\omega_i = \omega_c + k_f m(t)$——信息藏在**频率随时间的变化**里，而不是静态频谱的形状里。

### 调幅指数与包络形状

标准 AM 的时域形态 $y(t) = A_c[1 + m(t)]\cos(\omega_c t)$ 里，$m(t)$ 的幅度有一个安全边界。定义**调幅指数（modulation index）** $\mu = \dfrac{\max|m(t)|}{A_c}$：

- $\mu < 1$：$1 + m(t)$ 恒为正，载波包络完整保留 $m(t)$ 的形状，可用包络检波；
- $\mu = 1$：包络在最小值处碰到零轴，检波仍勉强可行；
- $\mu > 1$：**过调（overmodulation）**，包络出现「翻折」，包络检波解出的波形发生失真——必须改用同步解调才能救回。

**辨析｜易错点：** 「包络 = 消息」只在不过调时成立。同步解调不依赖 $\mu < 1$，却能解出过调信号——两种解调方式的能力边界不同，选哪种取决于发射端是否保证 $\mu < 1$。AM 广播电台保证不发射过调信号，是因为它要照顾千家万户的廉价收音机。

### 超外差接收机：一个频率、通吃所有台

收音机若直接在每个电台频率上做高选择性的带通滤波，需要一台频率连续可调的笨重滤波器。**超外差（superheterodyne）**结构绕开了它：接收端先把任意电台的载频搬到一个固定的**中频（IF，intermediate frequency）**，再用一个固定频率的窄带滤波器选频。搬移靠的正是调制里的「再乘一次本地振荡器」——混频。

$$y(t) = x(t)\cos(\omega_{LO} t) \Rightarrow \text{频谱搬到 } |\omega_c - \omega_{LO}| = \omega_{IF}$$

这个固定中频让高 Q 的选频滤波器可以做到极致，也带来一个副产品——**镜像频率（image frequency）**：若本地振荡频率 $\omega_{LO}$ 选得使 $\omega_c - \omega_{LO} = \omega_{IF}$，则另一个电台频率 $\omega_c + 2\omega_{IF}$ 也会混频到同一个中频，造成串扰。工程上的对策是输入级先用一个粗略的预选滤波器把镜像频段挡住——又是一个「滤波守门员」。

## 4 复用：一条信道，多路消息

调制还有一个隐藏能力：**频分复用（FDM）**。把各路的基带信号分别搬到不同的载频 $\omega_{c1}, \omega_{c2}, \ldots$ 上，让它们的频带互不重叠，就可以**同时**在一个信道上传输，接收端用不同中心频率的带通滤波器逐一取出。<span class="marginnote">老式电话主干网用 FDM 把几十路语音「叠」到一条同轴电缆上；现代数字系统则更常用时分复用（TDM）与正交频分复用（OFDM）——Wi-Fi 与 4G/5G 用的 OFDM，就是把一个宽带信道切成上千个正交窄带子载波，每个子载波各自调制。频谱「分层摆放」的思想一脉相承。</span>

FDM 对滤波器提出硬要求：各路之间必须留**保护间隔（guard band）**，且带通滤波器要有足够陡的边缘。这一脚恰好踩回第四篇的「滤波器整形」——滤波与复用是一对共生概念。

## 5 公式解析：DSB-SC 的频谱搬移

$$y(t) = m(t)\cos(\omega_c t) \quad\Longleftrightarrow\quad Y(j\omega) = \frac{1}{2}\big[M(j(\omega-\omega_c)) + M(j(\omega+\omega_c))\big]$$

三步拆解：

- **第一步，写余弦的变换**：$\cos(\omega_c t) \stackrel{\mathcal{F}}{\longleftrightarrow} \pi\big[\delta(\omega-\omega_c) + \delta(\omega+\omega_c)\big]$（第三篇表格里的变换对）。
- **第二步，用时域相乘定理**：$m(t)\cos(\omega_c t)$ 的变换 = $M(j\omega)$ 与上述冲激对的卷积（乘 $1/2\pi$）。卷积有「采样性」：与 $\delta(\omega-\omega_c)$ 卷积就是把函数平移到 $\omega_c$。
- **第三步，写出结果**：$\frac{1}{2}M(j(\omega-\omega_c)) + \frac{1}{2}M(j(\omega+\omega_c))$。系数 $\tfrac12$ 来自余弦分解为两个复指数时各带 $\tfrac12$ 因子——**频谱减半，两份拷贝**。

直觉一句话：**调制就是让信号的频谱「搬家」，搬家的起点是零频、终点是 $\pm\omega_c$，且每份搬走的频谱能量减半。** 你不需要背任何新定理——第三篇的频移性质 + 卷积的采样性，两步就推导出全部结论。

最后补一个「为什么必须搬到高频」的物理直觉：天线的辐射效率与波长密切相关，只有当天线尺寸与波长同量级时才有效。4 kHz 语音对应的波长是几十公里，天线根本做不出来；搬到 1 MHz 的载频后波长降到 300 米，搬到 100 MHz 后只剩 3 米。**调制把消息「缩」进了可发射的波长范围**——这是调制最古老、也最根本的存在理由。

### 数字调制的先声：从模拟到 IQ

模拟调制讲完后，必须指出它的后继者。现代通信（Wi-Fi、5G）用**数字调制**：把比特流映射到载波的幅度 / 相位 / 频率上。**正交幅度调制（QAM）**把载波看成两路正交（相差 90°）的正弦 $\cos\omega_c t$ 与 $\sin\omega_c t$，分别承载实部 $I$ 与虚部 $Q$：

$$y(t) = I(t)\cos(\omega_c t) - Q(t)\sin(\omega_c t)$$

每个符号 $(I, Q)$ 对应一个点，落在二维平面上形成**星座图（constellation）**——16QAM 有 16 个点，256QAM 有 256 个点。点数越多，每符号携带的比特越多（频谱效率越高），但点间距越近，对噪声越敏感。**频谱效率与抗噪是数字调制里的永恒对赌**，正是「用带宽换信噪比」这条香农主线在数字世界的延续。读完本篇你会发现：调制的基本动作（乘载波、搬频谱）从模拟到数字从未改变，变的只是「消息 $m(t)$」的内容——从连续波形换成了离散的比特符号。

还有一句关于「模拟 vs 数字」的收尾提醒：本篇的通篇工具——搬频谱、选边带、锁相位、抗镜像——在数字域（IQ 采样后的软件处理）里全部依然成立，只是「载波」变成了数字振荡器、「滤波」变成了数字滤波器。**调制背后的频域直觉，模拟与数字是同一套**，这让你未来的数字通信学习拥有一个稳固的出发点。

## 6 小结

- **调制**把基带信号搬到高频载波，时域相乘 ⇔ 频域搬移；代价是带宽翻倍（$2\omega_M$）。
- 载波本身不携带信息，保留它只是为了换取包络检波的低成本——把复杂度留给发射端的经典权衡。
- **DSB-SC** 只发边带；**标准 AM** 额外保留载波，换来接收端可用廉价**包络检波**。
- **同步解调**靠再乘同频载波搬回零频；频率、相位失配分别是「搬错位置」与「乘 $\cos\theta$ 丢消息」两类故障。
- **FM/PM** 让瞬时相位携带消息，FM 抗噪但费带宽；FM 与 PM 通过「积分/微分」互换。
- **FDM** 靠不重叠的频谱实现多路复用，其滤波需求与第四篇的滤波器整形互相咬合。
- 数字调制（QAM 星座图）延续同一套频域直觉，只是消息从波形换成了比特；频谱效率与抗噪永远对赌。
- 天线辐射靠波长，调制把消息「缩」进可发射的波长范围——这是调制最根本的存在理由。

我们已经把信号调制、发射、接收、解调的模拟链路走通了。但模拟手段在复杂性与精度上终有上限——通信的模拟篇章到此收束，但它交给你的不是一堆孤立结论，而是一条贯穿始终的主线：**一切调制，都在搬频谱；一切解调，都在搬回来。** 带着这条主线，你将能看懂任何新一代通信体制的说明书——无论是 OFDM 的千个子载波，还是大规模 MIMO 的天线阵，最终都落到「频谱在哪、怎样搬、如何不串扰」这三个问题上。
