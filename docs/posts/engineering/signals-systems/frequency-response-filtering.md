## 为什么要把频率响应「画出来」

上一篇我们建立了 $Y(j\omega) = H(j\omega)X(j\omega)$ 这条频域乘法。但拿到一个 $H(j\omega)$，工程师的第一动作是**画图**：横轴是频率、纵轴是增益或相位。原因很朴素——在频域设计滤波器，本质上是在做「哪些频率放行、哪些频率拦下」的雕塑，而雕塑离不开看形。<span class="marginnote">这与你学过的对数刻度的动机一脉相承：信号频率跨度动辄 6 个数量级（20 Hz 的人声到 2 GHz 的 Wi-Fi），线性刻度根本放不下；而对数-对数图把「幂律衰减」画成直线，一眼就能读出斜率。</span>

这一篇的内容是「频域工程」的第一次实操：读 Bode 图、理解谐振、设计滤波器。它直接服务后面三篇——采样前的抗混叠滤波、调制里的选频、以及更广义的「对信号整形」，全都是本篇工具的应用。换个角度说，本篇也是从「会算频谱」到「会设计系统」的转折点：前面的篇章告诉我们「系统是什么样」，这一篇开始教「系统该是什么样」。

## 1 增益、相位与 Bode 图

对 LTI 系统，$H(j\omega)$ 是一般复函数，写作

$$H(j\omega) = |H(j\omega)|\, \mathrm{e}^{j\angle H(j\omega)}$$

其中 $|H|$ 是**幅度（增益）**，$\angle H$ 是**相位**。工程上喜欢把增益画成**分贝**：$|H|_{\text{dB}} = 20\log_{10}|H|$。理由是分贝让「相乘」变「相加」，且把宽动态范围压缩到可读区间。

**Bode 图（Bode plot）**：两张图——上图为增益（dB）对频率（对数刻度）的曲线，下图为相位（度）对频率（对数刻度）的曲线。<span class="marginnote">Bode 图是贝尔实验室工程师波德在 1930 年代研究反馈放大器时发明的。它的最大便利是「可以近似到不用算」：用渐近线（直线）手绘折线图，转角处再修正，就得到足够好的草图——做控制系统设计时，这套手绘功夫至今仍是基本功。</span>

读 Bode 图有个基本顺序：**先看增益图（管强度），再看相位图（管时序）**。增益图回答「这个频率还剩多少」——0 dB 是满分，-3 dB 是半功率，-20 dB 是 1/10；相位图回答「这个频率被推迟了多少」——这对音频、通信里「波形是否变形」至关重要。两图共用同一横轴（对数频率），转折频率在两张图上是同一个竖直对齐点，工程师对「转折点对齐」的熟练程度，直接决定读图速度。

对一个**一阶低通** $H(j\omega) = \dfrac{1}{1 + j\omega/\omega_c}$（$\omega_c = 1/(RC)$）：

- $\omega \ll \omega_c$：$|H| \approx 1$（0 dB），信号近乎无损通过；
- $\omega = \omega_c$：$|H| = 1/\sqrt{2} \approx -3\,\text{dB}$，相位 $-45°$。$\omega_c$ 称为**转折频率（break frequency）**，也是常说的**截止频率**；
- $\omega \gg \omega_c$：$|H| \approx \omega_c/\omega$，在 Bode 图上是一条斜率为 **-20 dB/十倍频程（-20 dB/decade）** 的直线，相位趋近 $-90°$。

**重点：Bode 图的斜率就是系统的「阶数名片」。** 一阶系统高频滚降 -20 dB/dec，二阶系统 -40 dB/dec，$n$ 阶系统 -$20n$ dB/dec。读斜率就能快速判断系统「有多快、多狠地滤掉高频」。反过来，若实测一条频响曲线的滚降斜率约为 -40 dB/dec，你基本可以断定被测系统是个二阶系统——**从频响反推系统结构**，是诊断与建模的常用入口。

## 2 二阶系统与谐振

二阶系统（如 RLC 电路、质量-弹簧-阻尼）的频率响应可写成

$$H(j\omega) = \frac{1}{1 - (\omega/\omega_n)^2 + j\,2\zeta\,(\omega/\omega_n)}$$

$\omega_n$ 是**无阻尼自然频率**，$\zeta$ 是**阻尼比（damping ratio）**。$|H(j\omega)|$ 在 $\omega = \omega_n\sqrt{1-2\zeta^2}$ 处出现峰值（当 $\zeta < 1/\sqrt{2}$ 时），峰值高度为 $1/(2\zeta\sqrt{1-\zeta^2})$。

**核心概念：谐振（resonance）**。阻尼越小，峰值越高、峰越尖锐——系统对接近自然频率的成分表现出「放大」而非「衰减」。收音机选台、扬声器箱体设计、桥在风中的涡振，都是同一个二阶系统在作祟：选台靠的是「只放大目标频率」，涡振靠的是「没阻尼、一遇风速就疯狂振荡」。<span class="marginnote">工程上常用<strong>品质因数（Q 值）</strong>量化尖锐程度：$Q = 1/(2\zeta)$（低阻尼时）。Q 越高，3 dB 带宽越窄，选频越锐利。RLC 谐振回路的 Q 可以做到上百，这正是老式收音机一个旋钮就能「扎」进单一电台的原因。</span>

**辨析｜易错点：** 峰值频率 $\omega_r = \omega_n\sqrt{1-2\zeta^2}$ **不等于**自然频率 $\omega_n$。只有 $\zeta \to 0$ 时两者才重合。题目里出现「谐振峰在 $\omega_n$」的说法，前提通常是 $\zeta$ 很小、近似成立——精确计算必须用上面的公式。

## 3 理想滤波器与可实现性

滤波器（filter）是按频率放行/拦截信号的系统。三类基本滤波器：

- **低通（low-pass）**：$\omega < \omega_c$ 放行，$\omega > \omega_c$ 拦截；
- **高通（high-pass）**：$\omega > \omega_c$ 放行，低频拦截；
- **带通（band-pass）**：只在 $\omega_1 < \omega < \omega_2$ 一段放行。

![三类滤波器的幅度响应与通带阻带标注](/images/signals-systems/frequency-response-filtering-1.svg)

**理想低通（ideal low-pass filter）**在频域是一块「门板」：$|H(j\omega)| = 1$（$|\omega| < \omega_c$），其余为 0。它听起来完美，却有一个致命伤：对应的时间域冲激响应是

$$h(t) = \frac{\omega_c}{\pi}\,\mathrm{sinc}\left(\frac{\omega_c t}{\pi}\right)$

这条式子的形状同样值得记牢：主瓣高度正比于 $\omega_c$，第一零点在 $t = \pm \pi/\omega_c$——**截止频率越高，冲激响应越窄**。反过来推：时间上拖得越长的 $h(t)$，对应的频域门板越窄，选频越精细。这正是「时域宽度 ⇔ 频域宽度」守恒定律在滤波设计里的又一次现身。

这个 $\mathrm{sinc}$ 函数在 $t < 0$ 时**不为零**——理想低通**是非因果的，物理上不可实现**。

**重点：不存在物理上完美的滤波器。** 凡能造出来的滤波器，要么是通带/阻带边缘有过渡带（不陡峭），要么通带内有纹波，要么相位不平直。设计哲学因此变为「逼近」而非「实现」：用**巴特沃斯（Butterworth）**换单调性，用**切比雪夫（Chebyshev）**换更陡的边缘，用**椭圆**换最陡但容忍纹波——三种经典的「逼近」路线，各自在通带纹波、阻带衰减、过渡带宽度之间做取舍。<span class="marginnote">这也是现代音频里「等响度曲线」「房间 EQ」这类处理的雏形：EQ 的本质就是一组可调谐的滤波整形器，把频响塑造成你想要的形状——与你此刻读的 Bode 图思路完全一致。</span>

顺带澄清一个选型常识：既然巴特沃斯单调、切比雪夫陡峭，为什么不总是选最陡的那个？因为「陡」通常以「相位畸变更大、群延迟起伏更剧烈」为代价。对音频、视频这类「波形即信息」的场合，宁可过渡带稍宽也要保相位线性；对只需要「知道有没有某个频率」的场合，才优先追过渡带的陡峭。**滤波器的选择，本质是在幅度、相位、阶数（成本）三者间按用途排优先级。**

## 4 群延迟：相位对波形的影响

幅度响应回答「保留多少」，相位响应回答「每根频率被推迟多少」。但真正决定**波形会不会畸变**的是相位关于频率的斜率——**群延迟（group delay）**

$$\tau_g(\omega) = -\frac{d\angle H(j\omega)}{d\omega}$$

若系统对所有频率给出一致的延迟（群延迟为常数），波形整体平移而不变形——这就是「无失真传输」的相位条件。<span class="marginnote">直观：一段音乐里 200 Hz 的低音和 5 kHz 的高音，若相位响应非线性，高音会被推迟不同时间，鼓点与镲声错位，音色「糊」掉。工程上为此设计了 Bessel 滤波器——它的相位响应几乎线性、群延迟近乎常数，专保波形形态。</span>

**辨析｜易错点：** 群延迟 ≠ 相位延迟 $\angle H / \omega$。前者是相位对频率的**斜率**（负数取负），后者是相位**本身**除以频率。对线性相位系统两者恰好相等；一般系统只有群延迟才与「包络是否被拉开」直接相关。考试里「无畸变条件」要答的是群延迟为常数，而不是相位为常数。

### 从规格到元件：一个低通设计实例

把理论落到元件上。需求：设计一个一阶 RC 低通，把 10 kHz 以上的噪声滤掉（即截止频率 $f_c = 10\,\text{kHz}$），并估算它对 100 kHz 信号的衰减。

- **第一步，选转折频率**：$\omega_c = 2\pi f_c \approx 62.8\,\text{krad/s}$，要求 $RC = 1/\omega_c$。
- **第二步，选元件**：取 $R = 1\,\text{k}\Omega$，则 $C = 1/(\omega_c R) \approx 15.9\,\text{nF}$（取标称值 16 nF）。
- **第三步，估算衰减**：100 kHz 是 $f_c$ 的 10 倍，一阶系统高频段每十倍频程衰减 20 dB——所以 100 kHz 处增益约为 $-20\,\text{dB}$（幅度降到 1/10）。若嫌不够狠，改用二阶（加一节 RC 或用电感），每十倍频程 40 dB，100 kHz 处能压到 $-40\,\text{dB}$。

这个例子里「十倍频程 20 dB」的 Bode 斜率估算，正是手算设计不求精确解、快速摸清量级的日常手法——先粗算、再仿真、再微调，是工程师的标准节奏。

**辨析｜易错点：** 串联两节相同 RC 得到的不是「完美二阶」，它传递函数是 $\dfrac{1}{(1 + j\omega RC)^2}$，其阻尼比固定为 $\zeta = 1$——临界阻尼，不会有谐振峰，也不会更尖。想得到可调节的形状（谐振峰、更陡的过渡带），必须按第二篇「级联冲激响应卷积」的正确方式设计真正的二阶网络。

## 5 公式解析：一阶低通的 3 dB 点

$$\omega_c = \frac{1}{RC}, \qquad |H(j\omega_c)| = \frac{1}{\sqrt{2}}$$

拆解这个「转折频率」是如何算出来的：

- **第一步，写出幅度**：对 $H(j\omega) = 1/(1 + j\omega/\omega_c)$，幅度为 $|H(j\omega)| = 1/\sqrt{1 + (\omega/\omega_c)^2}$。
- **第二步，代入** $\omega = \omega_c$：$|H| = 1/\sqrt{1+1} = 1/\sqrt{2}$。
- **第三步，换算分贝**：$20\log_{10}(1/\sqrt{2}) = -10\log_{10}2 \approx -3.01\,\text{dB}$。

所以「3 dB 点」「半功率点」「截止频率」是同一个东西：**增益掉到最大值的 $1/\sqrt{2}$（即功率减半）的那个频率**。工程上定义滤波器的**带宽（bandwidth）**，通常就是指 $-3\,\text{dB}$ 带宽——两个 $-3$ dB 点之间频率区间，带通/谐振选频尤其依赖这个定义。

## 6 小结

- 滤波设计三步走：定规格（截止频率、阻带衰减）→ 选逼近（巴特沃斯 / 切比雪夫等）→ 定阶数；幅度、相位、成本三者按用途权衡。

- **Bode 图**用 dB-对数刻度同时展示增益与相位，渐近线手绘法把频响分析变成「读直线」。
- **转折频率**处增益为 $-3$ dB；高频滚降斜率 = 阶数 $\times (-20\,\text{dB/dec})$。
- 二阶系统的**谐振**由阻尼比 $\zeta$ 控制：$\zeta$ 越小峰越高越尖，$Q = 1/(2\zeta)$。
- 理想滤波器**非因果、不可实现**；现实设计在通带纹波 / 阻带衰减 / 过渡带宽度三者间「逼近」取舍（巴特沃斯、切比雪夫等）。
- **群延迟**是相位对频率的负斜率，常数群延迟 ⇔ 波形无畸变；群延迟 ≠ 相位延迟。

现在我们已经能对信号做频域整形了。但有一个工程前提尚未解决：要让**数字计算机**处理连续信号，必须先把模拟信号变成离散样本——在下一节，我们将回答采样背后那条著名的定理：**奈奎斯特采样定理**，以及它身边那位叫「混叠」的幽灵。
