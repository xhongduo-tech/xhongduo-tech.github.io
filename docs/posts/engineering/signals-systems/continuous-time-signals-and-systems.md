## 为什么从信号与系统开始

「从极限到大模型」这条主线走到工程技术这一级，要面对的第一个对象不再是纯粹的数学结构，而是**真实世界的信息载体——信号（signal）**。你说话时麦克风输出的电压、医生听诊心音时的振动、股票价格的分钟序列、大模型输入的一串 token 的嵌入向量，全都是信号。而任何对信号做的加工——降噪、压缩、识别、合成——都是在与一个**系统（system）**打交道。<span class="marginnote">大模型本身就是一个系统：输入 token 序列（离散信号）进编码器，输出下一个 token 的概率分布。学完本专题你会意识到，Transformer 的「位置编码」本质上是给离散序列附加时间信息——信号处理与深度学习在这里同源。</span>

这一篇是全专题的奠基之作：先讲清**信号**长什么样、怎么分类、怎么测量它的「大小」；再讲清**系统**具有哪些性质、为什么「线性时不变」会成为整个学科的中流砥柱。它与你已学过的微积分、线性代数、微分方程课程直接衔接，又为后续所有工具（卷积、傅里叶、拉普拉斯、Z 变换）备好了词汇表。

## 1 信号：时间的函数

**信号（signal）**：一个携带信息的物理量随独立变量变化的过程。在经典理论中，独立变量通常就是**时间 $t$**。

按时间自变量是否连续取值，信号分为两大类：

**连续时间信号（continuous-time signal）** $x(t)$：对**每一个**实数 $t$ 都有定义，如电压波形、连续语音。
- **离散时间信号（discrete-time signal）** $x[n]$：只在**整数时刻**有定义，如每毫秒采样一次的体温、股票日收盘价。方括号 $[\cdot]$ 是离散时间信号的标准记号，与圆括号区别开。

<span class="marginnote">离散时间信号的「自变量」可以不是时间——它可以是一帧图像的像素序号、一条语句里 token 的位置。方括号记号提醒我们：$x[n]$ 只在整数处取值，谈论「$x[2.5]$」没有意义。</span>

为什么分立成两套理论？因为**处理设备只有两种**：模拟电路天然处理连续时间信号，数字计算机天然处理离散时间信号。现代工程的核心动作是「模数转换（ADC）——数字处理——数模转换（DAC）」这条流水线，而连接两端的桥梁就是本专题第五篇《采样定理》。

**重点：信号理论先分「连续/离散」，再看其他属性。** 分类决定了后面用积分还是用求和、用傅里叶变换还是用 Z 变换。

## 2 信号的三把「尺子」：能量、功率与周期性

如何测量一个信号的「大小」？直觉上是看幅度，但工程上需要一把不依赖具体波形的尺子。

对连续时间信号 $x(t)$，定义其**总能量**为

$$E_\infty = \int_{-\infty}^{+\infty} |x(t)|^2 \, dt$$

定义其**平均功率**为（对一个周期 $T$ 的周期信号）

$$P_\infty = \frac{1}{T} \int_{T} |x(t)|^2 \, dt$$

为什么是「模的平方」？因为 $|x(t)|^2$ 在物理上常对应**瞬时功率**——电压平方除以电阻、力乘速度，平方量总是与「强度」挂钩。取模则是为了容纳复信号。

由此信号分三类：

- **能量信号（energy signal）**：$E_\infty < \infty$，$P_\infty = 0$。脉冲、衰减振荡都属于此类——能量有限但平均功率为零。
- **功率信号（power signal）**：$P_\infty > 0$ 且 $E_\infty = \infty$。周期信号、阶跃信号属于此类——平均功率有限但总能量发散。
- **既非能量也非功率**：如 $x(t) = t$，两把尺子都失效，只能借助「短时能量」这类局部工具。

**辨析｜易错点：** 不要用「信号一直存在就是功率大」的直觉。正弦波看起来柔和，但它持续振荡、能量随时间线性增长，所以 $E_\infty = \infty$，它是**功率信号**；一个衰减的 $\mathrm{e}^{-t}\sin\omega t$ 在 $t \ge 0$ 时能量有限，它是**能量信号**。分类看的是积分收敛性，不是波形「猛不猛」。

另一个重要属性是**周期性**：若存在非零常数 $T$ 使 $x(t) = x(t+T)$ 对一切 $t$ 成立，则 $x(t)$ 是**周期信号（periodic signal）**，最小的正 $T$ 称为**基波周期（fundamental period）**。对复指数 $\mathrm{e}^{j\omega_0 t}$，基波周期为 $T_0 = 2\pi/\omega_0$。<span class="marginnote">复指数 $\mathrm{e}^{j\omega_0 t}$ 是全部后续理论的「积木」：欧拉公式把它拆成 $\cos\omega_0 t + j\sin\omega_0 t$，而傅里叶分析的全部工作就是「把任意信号拆成复指数之和」。这也是为什么本篇要在这里反复强调它。</span>

## 3 自变量变换：移位、反转与尺度

观察信号不只有「原样看」，还有三种改变时间轴的基本操作：

**时移（time shift）**：$x(t - t_0)$ 把波形向右平移 $t_0$（若 $t_0 > 0$）。注意「减去正数 → 向右移」这个反直觉规则：$x(t-3)$ 在 $t=3$ 处取值 $x(0)$，所以波形整体滞后。
- **时间反转（time reversal）**：$x(-t)$ 把波形关于纵轴翻转。
- **时间尺度（time scaling）**：$x(\alpha t)$，$\alpha > 1$ 时波形被**压缩**（单位时间经历了更多波形），$0 < \alpha < 1$ 时被拉伸。注意录音慢放是 $\alpha < 1$，音调变低——这正是改变时标的物理意义。

复合操作按「先替换、再处理」的顺序执行。例如 $x(-2t + 4)$ 应改写为 $x(-2(t-2))$：先做反转 + 压缩（$-2t$ 部分），再做右移 2（从 $-2t$ 提出 +4 得 $-2(t-2)$）。顺序错了，平移量常会算反——这是经典扣分点。

**辨析｜易错点：** $x(-2t+4)$ 的平移量是 $+2$ 还是 $+4$？必须先把 $t$ 的系数提取成 $-2$ 再读括号内常数：$x(-2(t-2))$ 说明时移量是 $2$，不是 $4$。先做尺度/反转，再读平移。

## 4 系统及其六大性质

**系统（system）**：把输入信号 $x(t)$ 映射为输出信号 $y(t)$ 的数学对象，记作 $y(t) = \mathcal{T}\{x(t)\}$。它可以是一个电路、一段算法、一组微分方程，甚至一栋楼的隔音结构。

判断一个系统，工程上最关心六个性质，其中前五个是「入门检查」，第六个是「殿堂级」。

- **记忆性**：输出只依赖当前输入则**无记忆（memoryless）**；否则有记忆（如积分器、电容）。
- **可逆性**：由输出能否唯一反解出输入。微分器不可逆（常数项信息丢失），积分器在去掉直流偏置后可逆。
- **因果性（causality）**：输出 $y(t_0)$ 只依赖 $t \le t_0$ 时刻的输入。所有物理可实现系统都是因果的；但「离线处理」里常见的平滑滤波器（用未来点）是非因果的——离线时没问题，实时系统里却不可实现。
- **稳定性（stability）**：有界输入必有有界输出（**BIBO 稳定**）。即 $|x(t)| \le B_x$ 恒成立时，存在 $B_y$ 使 $|y(t)| \le B_y$。<span class="marginnote">BIBO 稳定性是信号与系统里出现频率最高的一个性质：判断一个算法会不会「爆炸」、一个滤波器是否可用，第一步永远是看它稳不稳定。它会以各种形式贯穿卷积、傅里叶、拉普拉斯全篇。</span>
**时不变性（time invariance）**：输入时移 $t_0$，输出也恰当时移 $t_0$，即 $\mathcal{T}\{x(t - t_0)\} = y(t - t_0)$。电路参数不随时间变化、算法不依赖绝对时刻，就满足时不变。
- **线性（linearity）**：同时满足**叠加性（superposition）** $\mathcal{T}\{x_1 + x_2\} = \mathcal{T}\{x_1\} + \mathcal{T}\{x_2\}$ 与**齐次性（homogeneity）** $\mathcal{T}\{a x\} = a\,\mathcal{T}\{x\}$。

**核心概念：线性时不变（Linear Time-Invariant，LTI）系统**：同时满足线性与时不变性的系统。下一篇会看到，LTI 系统拥有一个「奇迹性质」——它的全部行为由一个函数（单位冲激响应）完全决定，输出就是输入与该函数的卷积。

**辨析｜易错点：** 系统 $y(t) = 2x(t) + 3$ 线性吗？**不线性**——齐次性检查：输入 $x$ 得 $2x+3$，输入 $2x$ 得 $4x+3$，而 $2 \times (2x+3) = 4x+6 \neq 4x+3$。常数项 $+3$ 破坏了齐次性。线性系统的输出必须「过原点」：零输入必得零输出。

## 5 两个基本信号：单位冲激与单位阶跃

整门课有两个「最小的原子」：

- **单位阶跃（unit step）**：$u(t) = \begin{cases} 1, & t > 0 \\ 0, & t < 0 \end{cases}$。它像一扇突然打开的闸门，常用来「从某时刻起开启一个信号」。
- **单位冲激（unit impulse）** $\delta(t)$，狄拉克（Dirac）引入的「无穷高、无穷窄、面积为 1」的极限脉冲：$\delta(t) = 0\ (t \neq 0)$，且 $\int_{-\infty}^{+\infty} \delta(t)\, dt = 1$。

<span class="marginnote">$\delta(t)$ 不是普通函数——没有普通函数在零点取「无穷大」同时面积有限。严格地讲它是个分布（distribution）或广义函数。初学者不必纠结测度论，只需抓住两条运算规则：$\int x(t)\delta(t-t_0)\,dt = x(t_0)$（<strong>筛选性</strong>）与 $x(t)\delta(t-t_0) = x(t_0)\delta(t-t_0)$（<strong>采样性</strong>）。</span>

冲激与阶跃互为微分/积分：$\dfrac{du(t)}{dt} = \delta(t)$，$u(t) = \int_{-\infty}^{t} \delta(\tau)\, d\tau$。**任何信号都可以写成冲激的加权叠加**：

$$x(t) = \int_{-\infty}^{+\infty} x(\tau)\, \delta(t - \tau)\, d\tau$$

这条式子看起来像废话，但它正是下一篇卷积公式的起点——把输入「砸碎」成无穷多个冲激，看每个冲激怎么被系统响应，再拼回去。

## 6 公式解析：奇偶分解公式

任何一个信号都可以唯一地拆成**偶部（even part）**与**奇部（odd part）**之和：

$$
x(t) = x_e(t) + x_o(t), \qquad
x_e(t) = \frac{x(t) + x(-t)}{2}, \qquad
x_o(t) = \frac{x(t) - x(-t)}{2}
$$

三步拆解：

- **第一步，看懂目标**：$x_e(t)$ 是偶函数（满足 $x_e(t) = x_e(-t)$），$x_o(t)$ 是奇函数（满足 $x_o(t) = -x_o(-t)$），两者相加要恰好还原 $x(t)$。
- **第二步，验证偶部**：把 $t$ 换成 $-t$ 得 $x_e(-t) = [x(-t) + x(t)]/2 = x_e(t)$，确为偶函数。
- **第三步，验证还原**：$x_e(t) + x_o(t) = [x(t)+x(-t)]/2 + [x(t)-x(-t)]/2 = x(t)$，精确抵消掉 $x(-t)$ 项。

直觉：把一个波形「对折到左侧」再求平均，得到的对称部分就是偶部；对折后「左减右」得到的反对称部分就是奇部。这条公式的价值在于：**偶部包含全部直流与余弦类成分，奇部包含全部正弦类成分**——傅里叶级数里偶/奇与余弦/正弦的对应，早在这里就埋下了种子。

## 7 小结

- **信号**按自变量分为连续时间 $x(t)$ 与离散时间 $x[n]$；按能量分为**能量信号**（$E_\infty < \infty$）与**功率信号**（$P_\infty > 0, E_\infty = \infty$）。
- 三种基本操作——**时移、反转、时标**——是理解所有波形变换的积木，复合变换要先提取系数再读平移量。
- 系统的六大性质里，**线性**与**时不变**合成 LTI，是后续全部理论的舞台。
- 单位冲激 $\delta(t)$ 与单位阶跃 $u(t)$ 是「原子」；任何信号都能写成冲激的加权积分 $x(t) = \int x(\tau)\delta(t-\tau)\,d\tau$。
- **奇偶分解**公式把信号拆成偶部与奇部，为傅里叶分析里的余弦/正弦分工埋下伏笔。
