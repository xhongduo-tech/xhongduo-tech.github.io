## 为什么从两种微加工开始

上一节我们建立了「缩放律」这个思想工具：微米尺度下表面力称王、结构可以做得很薄很轻。但思想落地要靠工艺。制造一个 MEMS 器件，本质上只有两条路：**从一块完整的硅里「掏」出结构**，或者**在硅表面一层层「搭」出结构**。前者叫**体硅微加工**，后者叫**表面微加工**。本讲把这两条路走通：它们各自用什么化学、什么设备、能做出什么形状，又各自栽在什么坑里。理解了这两条主线，后面讲光刻、刻蚀、沉积乃至传感器执行器，就都有了坐标。

这讲是《半导体物理》中晶向、掺杂、氧化知识的直接应用——上一级我们只关心硅的电学，这一级开始**把硅当作可以切削、可以腐蚀、可以弯曲的结构材料**；它与《晶体学与衍射分析》里晶面指数那套语言也在此汇合。

## 1 体硅微加工：从硅片里掏结构

**体硅微加工（bulk micromachining）**：通过刻蚀直接去除硅片本体的材料，在衬底内部形成悬空结构、腔体或通孔。<span class="marginnote">「体（bulk）」指的是硅片本体。体硅加工的思路很像雕塑——材料减到哪里，结构就剩到哪里；它与《精密与超精密加工》里的减材制造精神相通，只不过切削工具换成了化学药液和高能等离子体。</span>

体硅加工的第一件法宝是**湿法各向异性刻蚀（anisotropic wet etching）**。某些碱性溶液——KOH、TMAH、EDP——对硅不同晶面的刻蚀速率差异巨大：对 $\{100\}$ 面快、对 $\{111\}$ 面慢，速率比可达 100:1 甚至 400:1。<span class="marginnote">以 KOH 为例，室温附近对 $\{100\}$ 面的速率约为每分钟 0.5–1 μm，而对 $\{111\}$ 面几乎不动。正因为 $\{111\}$ 面被刻得极慢，腐蚀会「自动停靠」在 $\{111\}$ 斜面上——这是一个自限效应，无需精确计时。</span>于是刻蚀出的侧壁不是垂直的，而是与表面成固定夹角 54.74° 的斜面，最终形成 V 形槽或倒金字塔腔。

与它相对的是**湿法各向同性刻蚀（isotropic etching）**。经典的 HNA（氢氟酸 + 硝酸 + 乙酸）体系对硅各方向刻蚀速率相同，会向四周均匀「啃」，形成圆滑的弧形腔。它适合快速掏空，但侧壁轮廓难以控制。

进入干法时代后，**深反应离子刻蚀（DRIE）**成了体硅加工的主力。博世工艺（Bosch process）用 SF₆ 刻蚀与 C₄F₈ 钝化交替进行：刻蚀气体咬掉一层硅，钝化气体在侧壁沉积一层类聚合物，下次刻蚀只咬底部、不咬侧壁。<span class="marginnote">博世工艺的典型周期是「刻蚀几秒、钝化几秒」反复循环，侧壁因此呈现微米级的扇形波纹。它是目前唯一能在大深宽比下做出<strong>近垂直侧壁</strong>的通用工艺——深宽比可达 30:1，是制作高深硅通孔（TSV）与微型惯性器件的基石。</span>

掏空结构之后，往往还需要把硅片「焊」起来形成腔体。**阳极键合（anodic bonding）**把硅片与含钠玻璃在高温高压下键合，靠电场驱动离子迁移形成牢固的化学键；**熔融键合（fusion bonding）**则让两片镜面抛光的硅片直接形成共价键，不需要任何中间层。这两个方法决定了 MEMS 封装时「怎么把盖子盖上」，我们在第十讲还会回来。

## 2 表面微加工：用薄膜搭结构

**表面微加工（surface micromachining）**：在衬底表面交替沉积结构层与牺牲层，最后把牺牲层刻蚀掉，释放出可活动的薄膜结构。<span class="marginnote">这里的核心 trick 是「牺牲层（sacrificial layer）」：它只是临时占位，最后注定要被溶解。就像用泡沫搭模型、最后把泡沫冲走留下空腔——制造学里把这种先立模、后移除的思想叫「牺牲技术」。</span>

最经典的组合是**多晶硅作结构层 + 二氧化硅作牺牲层**：

1. 在衬底上沉积磷硅玻璃（PSG）作为牺牲层，并光刻出锚点窗口；
2. 沉积结构层多晶硅，光刻出梁、梳齿、质量块的图形；
3. 用氢氟酸（HF）溶液把二氧化硅牺牲层整体溶掉；
4. 多晶硅结构因没有支撑而悬空，与衬底分离——这一步叫**释放（release）**。

为什么选这对材料？因为**HF 腐蚀二氧化硅很快、腐蚀多晶硅极慢**，选择性高达上千倍，能精确地「只拆脚手架、不伤房屋」。释放之后，残余应力会让悬臂梁翘曲，水的表面张力会让梁粘在衬底上——**粘附（stiction）**正是表面微加工的头号天敌，工艺上常用超临界 CO₂ 干燥或疏水处理来化解。<span class="marginnote">超临界 CO₂ 干燥的原理：把液体直接过渡到超临界态，消除气液界面，从而消灭表面张力——这正是第一讲缩放律里「毛细力 $\propto L$」在工艺上的实战应对。</span>

表面微加工的最大优点是**与集成电路工艺高度兼容**：结构层、牺牲层、互连线可以逐层堆叠，传感器与信号处理电路能做在同一颗芯片上（单片集成）。最大限制是**结构层厚度受薄膜沉积约束**（典型仅 1–10 μm），做不出体硅那样又厚又深的构件。

## 3 两种路线：选型与对比

两种工艺不是竞争关系，而是互补的两条生产线。用一张表定位它们：

| 维度 | 体硅微加工 | 表面微加工 |
| --- | --- | --- |
| 材料来源 | 单晶硅本体 | 沉积薄膜（多晶硅等） |
| 结构厚度 | 可达数百微米 | 通常 1–10 μm |
| 侧壁 | 各向异性 54.74° 斜面或 DRIE 垂直 | 由光刻决定，可垂直 |
| 与 IC 兼容性 | 需前/后工序协调 | 天然兼容，易单片集成 |
| 代表器件 | 压力传感器膜、微喷嘴、TSV | 梳齿驱动、加速度计、微镜 |
| 主要风险 | 深孔刻蚀难、键合对准难 | 内应力、粘附、释放损伤 |

**选型直觉**：要厚、要深、要过通孔的，走体硅；要薄、要柔、要和电路做在一起的，走表面微加工。工程上常把两者**混合**使用——先体硅刻出大质量块，再表面微加工做出精细梳齿，各取所长。<span class="marginnote">这种「体硅 + 表面微加工」的混合路线是现代惯性 MEMS 的主流，比如汽车级加速度计就把大的敏感质量放在体硅层、把灵敏的梳齿电容放在表面层。工艺选择的本质是<strong>用成本换性能</strong>，这条产业逻辑在第十讲还会反复出现。</span>

## 4 公式解析：{111} 晶面夹角与 V 形槽几何

**为什么 KOH 刻出来是 54.74° 的斜面？这是晶面几何的必然。** 在金刚石结构的硅晶体中，晶面夹角由晶面指数唯一确定。设两晶面的法向量分别为 $\vec{n}_1$ 与 $\vec{n}_2$，则夹角 $\theta$ 满足：

$$\cos\theta = \frac{\vec{n}_1 \cdot \vec{n}_2}{|\vec{n}_1|\,|\vec{n}_2|}$$

- **第一步，代 $\{100\}$ 与 $\{111\}$ 的法向量**：$\vec{n}_{100} = (1,0,0)$，$\vec{n}_{111} = (1,1,1)$。
- **第二步，算内积与模长**：$(1,0,0)\cdot(1,1,1) = 1$，$|(1,0,0)| = 1$，$|(1,1,1)| = \sqrt{3}$。
- **第三步，得夹角**：$\cos\theta = 1/\sqrt{3} \approx 0.5774$，故 $\theta \approx 54.74°$。这个角与工艺配方无关，是**晶体结构的固有常数**。

由此可以直接推出**V 形槽的几何关系**。当刻蚀自表面向下推进，最终停靠在两侧的 $\{111\}$ 斜面上时，槽深 $d$ 与槽口宽 $w$ 满足：

$$d = \frac{w}{2}\tan 54.74° = \frac{w}{2}\cdot\sqrt{2}, \qquad w = \sqrt{2}\,d$$

- **$\tan 54.74° = \sqrt{2}$**：因为 $\cos\theta=1/\sqrt{3}$ 时，$\tan\theta = \sqrt{1-\cos^2\theta}/\cos\theta = \sqrt{2/3}/(1/\sqrt{3}) = \sqrt{2}$。
- **$w = \sqrt{2}\,d$**：只要量出槽口宽度，深度立刻算出来——这是光纤对准槽、V 形通道等器件设计的核心换算。

顺带说明各向异性刻蚀的另一个自限行为：当 V 形槽两侧斜面在底部交汇时，暴露的全是 $\{111\}$ 面，腐蚀速率骤降，**再泡再久深度也不变**。这个「自动停靠」让 V 形槽的深度天然地由槽宽决定，制造上极其稳定。<span class="marginnote">V 形槽最著名的应用是把光纤精确卡进槽里实现光路对准——槽深由光刻宽度 $w$ 锁定为 $d=w/\sqrt{2}$，无需逐根测量。这是「工艺自对齐」思想的经典范例，后面微流控、光 MEMS 还会多次用到。</span>

## 5 常见误区辨析

体硅与表面微加工是概念混淆的高发区，四个误区高频出现：

**误区一：以为「湿法刻蚀一定各向同性」。** 事实恰好相反：HNA 体系各向同性，但 KOH、TMAH 等碱性体系对 $\{100\}$ 与 $\{111\}$ 面速率差异巨大，是典型的各向异性刻蚀。「湿法」与「干法」的分野在介质，不在各向异性。

**误区二：以为 DRIE 的侧壁完全光滑。** 博世工艺的钝化-刻蚀交替会在侧壁留下周期性「扇贝纹」，侧壁是「近垂直」而非「绝对垂直」。要更光滑的侧壁需改用低温冷冻刻蚀（cryo-DRIE），用低温让副产物自然钝化，代价是工艺窗口更窄。

**误区三：混淆「结构层」与「牺牲层」的释放关系。** 表面微加工里只有牺牲层被溶解、结构层保留；若选材不当，刻蚀剂会「误伤」结构层。选择性的高低直接决定工艺成败，这是选材的第一原则。

**误区四：以为体硅与表面微加工互斥。** 高端惯性器件恰恰是「体硅做厚质量块 + 表面微加工做细梳齿」的混合体，两种工艺在同一颗芯片上各司其职。

把四种典型工艺排在一起，各自的用途一眼看清：

| 工艺 | 一句话记忆 |
| --- | --- |
| 湿法各向同性（HNA） | 向四周均匀啃，掏空用 |
| 湿法各向异性（KOH） | 停靠在 {111} 面，V 槽用 |
| DRIE（博世工艺） | 钝化交替，垂直深孔用 |
| 表面微加工 | 牺牲层一溶，悬空结构现 |

一条实用的工艺集成顺序也能帮你把两讲串起来：先在体硅上做各向异性刻蚀定出腔体，再在表面做牺牲层与多晶硅结构，最后释放——**先「掏」出大空间，再「搭」出小结构，二者天然互补**。

<span class="marginnote">选型的快捷方式是先问「结构要厚而深，还是薄而柔」：前者往体硅想，后者往表面微加工想；两者都要，就准备混线。这条决策树在第十讲「工艺即器件」的产业观里还会深化。</span>

要把两种微加工接上更大的知识地图，一条线索值得特别提醒：**「工艺自对齐」思想（V 形槽、牺牲层释放）在《精密与超精密加工》里以夹具与对刀的方式重现，在《纳米工程》里以自组装的方式重现**——「让结构自己停在正确位置」是微纳制造贯穿始终的智慧。

## 7 小结

- **体硅微加工**：靠刻蚀掏空硅本体；湿法各向异性刻蚀（KOH 等）依赖 $\{100\}$/$\{111\}$ 速率差，DRIE 提供高深宽比垂直侧壁。
- **表面微加工**：结构层 + 牺牲层逐层沉积，HF 释放牺牲层得到悬空结构；粘附是头号失效模式。
- **晶面几何**：$\{100\}$ 与 $\{111\}$ 面夹角恒为 54.74°，V 形槽满足 $w=\sqrt{2}\,d$
