## 为什么需要倒谱

到目前为止，我们处理的信号混合大多是**加法**性的：$x[n] + v[n]$（信号 + 噪声）。但现实里大量混合是**卷积**性的：语音 = 声道冲激响应 * 激励脉冲串，回声 = 直达声 * 延时冲激，地震记录 = 震源 * 地层响应。<span class="marginnote">卷积混合比加法混合难拆得多：在时域它们是绞在一起的乘积关系，在频域变成相乘关系 $X = S\cdot H$，但两个因子的频域分量彼此纠缠，无法直接分离。倒谱的巧妙之处：<strong>再取一次「对数频谱的傅里叶变换」，让相乘变成相加</strong>——卷积混合就变成了可分离的加法混合。这就是「同态」一词的含义：保持某种代数结构（这里是卷积 $\to$ 加法）的系统。</span>

这一篇讲倒谱的定义、它为什么能解卷积，以及它在语音与回声处理中的应用。

## 1 同态系统与卷积的「对数化」

**同态系统（homomorphic system）** 是把一个空间的代数运算映到另一个空间的代数运算的系统。对卷积而言，目标是把「卷积 $\to$ 加法」：

$$D_{*}\big\{x_1[n] * x_2[n]\big\} = D_{*}\{x_1[n]\} + D_{*}\{x_2[n]\}$$

**只要对频谱取对数，乘积就变成和**：$X(\mathrm{e}^{\,\mathrm{j}\omega}) = S(\mathrm{e}^{\,\mathrm{j}\omega}) H(\mathrm{e}^{\,\mathrm{j}\omega})$ $\Rightarrow$ $\ln X = \ln S + \ln H$。于是三步构成同态解卷积框架：

1. **正变换**：$x[n] \xrightarrow{DFT} X \xrightarrow{\ln} \hat{X} = \ln X$
2. **线性滤波**：在 $\hat{X}$ 域（对数谱域）做线性运算，把两项分离
3. **反变换**：$\hat{Y} \xrightarrow{\exp} Y \xrightarrow{IDFT} y[n]$

其中「对 $\ln X$ 做 IDFT」得到的量，就是**倒谱（cepstrum）**。<span class="marginnote">Bogert 等人 1963 年造词时的俏皮：把「spectrum」的前四个字母倒过来变成「ceps」，于是频谱（spectrum）的傅里叶变换叫「倒谱」（cepstrum），频率（frequency）的倒数叫「倒频率」（quefrency），滤波（filtering）变成「倒滤波」（liftering）。这些颠倒词提醒你：倒谱域是「频域的频域」。</span>

## 2 复倒谱：卷积的加性分离

**复倒谱（complex cepstrum）** 定义为对数频谱的 IDFT：

$$\boxed{\;\hat{x}[n] = \frac{1}{2\pi}\int_{-\pi}^{\pi} \ln\big[X(\mathrm{e}^{\,\mathrm{j}\omega})\big]\, \mathrm{e}^{\,\mathrm{j}\omega n}\,\mathrm{d}\omega\;}$$

其中 $\ln X = \ln|X| + \mathrm{j}\angle X$ 是**复对数**。复倒谱的关键性质：

- **卷积可加性**：$x = x_1 * x_2$ $\Rightarrow$ $\hat{x} = \hat{x}_1 + \hat{x}_2$——**卷积在倒谱域变成加法**，分离问题变成加法问题。
- **实偶/奇分解**：对实信号，$\hat{x}[n]$ 的偶部来自 $\ln|X|$，奇部来自 $\angle X$。
- **因果/反因果分解**：复倒谱的 $n>0$ 部分对应最小相位分量，$n\lt 0$ 部分对应全通分量。

**倒频谱（real cepstrum）** 则只用幅度谱的对数：

$$c[n] = \frac{1}{2\pi}\int_{-\pi}^{\pi} \ln\big|X(\mathrm{e}^{\,\mathrm{j}\omega})\big|\,\mathrm{e}^{\,\mathrm{j}\omega n}\,\mathrm{d}\omega$$

它丢弃了相位，但**对一个周期性/脉冲性混合来说往往已经够用**——回声、语音激励的检测依赖幅度倒谱即可。<span class="marginnote">复倒谱 vs 倒频谱：前者保留全部信息（可逆），后者只留幅度信息（简单、鲁棒）。语音基频检测、回声延迟估计用倒频谱就够了；而完整的「解卷积」——恢复出两个因子——必须用复倒谱。工程上先问「我要恢复全部信息，还是只要一个特征」。</span>

### 为什么倒谱能分开卷积

对回声场景：$y[n] = x[n] + \alpha x[n-n_0]$，其频谱是 $Y = X(1 + \alpha \mathrm{e}^{-\mathrm{j}\omega n_0})$，取对数后

$$\ln Y = \ln X + \ln(1 + \alpha \mathrm{e}^{-\mathrm{j}\omega n_0})$$

第二项展开成级数 $\sum_{k} \tfrac{(-1)^{k+1}\alpha^k}{k}\mathrm{e}^{-\mathrm{j}\omega k n_0}$，它的 IDFT 是一串**位于 $n = k n_0$ 的脉冲**——**回声在倒谱域表现为等间隔的尖峰**。<span class="marginnote">这就是回声检测的全部秘密：倒谱域里，原始信号 $\ln X$ 是「平滑基底」，回声项是一排等距尖峰（间距 $n_0$）。用一个「倒滤波器」把尖峰抠掉，再逆变换回去，就得到去回声的信号——整个过程不需要知道回声系数 $\alpha$ 的任何先验。</span>

## 3 复倒谱的计算：三步流水线

实际计算复倒谱，工程上有标准流水线，要点在**相位展开**：

1. **DFT**：$X[k] = \mathrm{DFT}\{x[n]\}$，$N$ 点。
2. **复对数**：$\hat{X}[k] = \ln|X[k]| + \mathrm{j}\,\angle X[k]$。$\angle X[k]$ 是**多值**的（主值在 $(-\pi,\pi]$），必须做**相位展开（unwrapping）**——相邻频点相位差超过 $\pi$ 就补 $\pm 2\pi$，得到连续相位曲线。
3. **IDFT**：$\hat{x}[n] = \mathrm{IDFT}\{\hat{X}[k]\}$。

**相位展开是复倒谱计算里最容易出错、也最决定成败的一步**。若相位不展开，$\hat{x}[n]$ 会产生「振铃式」的伪分量，倒谱特征全毁。<span class="marginnote">这也是复倒谱在工业上不如倒频谱流行的原因——相位展开的稳健性问题至今没有完美解法，对噪声敏感。需要「可逆解卷积」时，人们常常转而用更现代的方法（稀疏反卷积、盲解卷积），但倒谱作为第一个成功案例，其思想仍是它们的祖师。</span>

**辨析｜易错点：** 对数幅度 $\ln|X|$ 在 $|X|=0$ 处发散——信号频谱过零时，倒谱计算会爆炸。工程处理：加极小正则量（如 $\ln(|X|+\epsilon)$），或避开有零点的信号段。**输入信号的频谱不应有严格零点**，这是复倒谱可计算性的前提之一。

## 4 公式解析：同态解卷积的三个例子

把框架套到三类典型卷积混合上，最能看清它的普适性。

**例一：回声去除**。$y[n] = x[n] * (1 + \alpha\delta[n-n_0])$。

倒谱域：$\hat{y} = \hat{x} + \hat{g}$，其中 $\hat{g}$ 是等距尖峰（上节）。
倒滤波器：把 $n = n_0, 2n_0, \dots$ 处的尖峰置零，得 $\hat{x}$。
- 逆变换：$\exp \to$ IDFT $\to x[n]$。

**例二：语音的声道—激励分解**。语音 $s[n] = v[n] * p[n]$（$v$ 声道响应、$p$ 声门脉冲串）。倒谱域：$\hat{s} = \hat{v} + \hat{p}$。$\hat{v}$ 集中在低倒频率（声道响应平滑、变化慢），$\hat{p}$ 是高倒频率处的等距尖峰（周期 = 基频）。**低通倒滤波取 $\hat{v}$ 得声道谱（共振峰），高通取 $\hat{p}$ 得基频**——这就是语音分析里的**倒谱语音分析（spectral envelope extraction）**。<span class="marginnote">这项技术直接支撑了 20 世纪 70–90 年代的声码器（vocoder）与语音识别的前端：不需要波形，只从倒谱就能分离「说的是什么音素」（声道谱）与「音高多高」（基频）。现代神经网络声码器之前，倒谱就是语音特征的标准形态（MFCC 的雏形）。</span>

**例三：地震反卷积**。地震记录 = 震源子波 * 地层反射序列。倒谱域分离后，反射序列对应尖峰——**地层结构被直接「读出」**。

三个例子的共同结构是：**在倒谱域里，卷积的两个因子落到不同区域（低倒频 vs 高倒频/尖峰），用线性滤波一刀切开**。这正是同态系统的定义性优势：**在变换域里做线性滤波，解决非线性（卷积）混合**。

### 一个最小数值例子：检测回声延迟

设 $y[n] = x[n] + 0.5\,x[n-8]$，即一个回声延迟 8 个样本、衰减一半的混合。三步检验倒谱的能力：

**第一步，算倒频谱**：对 $y[n]$ 做 DFT，取 $\ln|Y[k]|$，再做 IDFT，得到倒频谱 $c[n]$。
**第二步，找峰**：$c[n]$ 在 $n=8$ 处出现一个明显的尖峰（回声的倒频率），其高度近似等于 $0.5$ 的对数幅度。
- **第三步，判决**：尖峰位置就是回声延迟 $n_0 = 8$，尖峰强度对应回声系数——**检测回声不需要知道原始 $x[n]$ 的任何信息**。

这个例子的工程对应物，是声学回声消除器里的「延迟估计」模块：先用倒谱测出回声延迟，再做自适应滤波抵消——**倒谱负责「知道回声在哪」，自适应滤波器负责「把回声抹掉」**，两者分工明确。

## 5 倒谱的局限与现代视角

倒谱方法在上世纪六七十年代是解卷积的主流，但它的局限要正视：

- **相位展开不稳**，对噪声与频谱零点敏感。
- **只适合「卷积性」混合**——加性噪声模型不适用。
- 对长卷积（如长混响）效果差，倒谱尖峰会互相重叠。

这些局限推动了解卷积的现代发展：**盲解卷积（blind deconvolution）、稀疏反卷积、以及深度学习端到端分离**——但倒谱奠定的「变换域去混合」思想，依然是这些方法的共同祖先。<span class="marginnote">放到「从极限到大模型」的主线里看：倒谱是「手工设计特征」时代信号处理的代表——靠数学洞察把物理混合拆开。今天的语音识别用神经网络直接学特征，但 MFCC（倒谱系数的梅尔版本）至今仍是几乎所有语音系统的输入特征——旧思想以新形式活着。</span>

## 6 小结

- **同态系统**把卷积映成加法：$\ln$ 频谱 $\to$ 加性分离 $\to$ $\exp$ 还原。
- **复倒谱** $\hat{x} = \mathrm{IDFT}\{\ln X\}$ 可逆，卷积可加：$\widehat{x_1*x_2} = \hat{x}_1 + \hat{x}_2$。
- **倒频谱**只用 $\ln|X|$
