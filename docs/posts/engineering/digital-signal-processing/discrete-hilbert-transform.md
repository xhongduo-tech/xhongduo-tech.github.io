## 为什么需要希尔伯特变换

真实世界的信号几乎都是实信号——麦克风输出、天线电压、传感器读数。但许多高级处理（包络提取、瞬时频率、单边带调制、雷达测速）需要一个「配套」的虚部信号，与实部构成**解析信号**。<span class="marginnote">希尔伯特变换就是那个「造虚部」的装置：它把每个频率分量相移 $-90°$，从而让实信号 $x[n]$ 配上一个正交的 $\hat{x}[n]$，合成 $x[n] + \mathrm{j}\hat{x}[n]$。有了虚部，包络、瞬时相位、瞬时频率这些概念才有了严格的定义——这是从「处理波形」跃升到「理解信号的物理量」的关键一步。</span>

这一篇讲三件事：希尔伯特变换是什么、为什么它能同时回答「相位约束」的数学问题、以及它在工程里怎么用。

## 1 希尔伯特变换：一个全通但移相 90° 的系统

**连续希尔伯特变换**把实信号 $x(t)$ 映成

$$\hat{x}(t) = \frac{1}{\pi}\int_{-\infty}^{\infty} \frac{x(\tau)}{t - \tau}\,\mathrm{d}\tau$$

这个积分对每个频率分量做 **$-90°$ 相移**、幅度不变。频域描述干净利落：

$$\hat{X}(\mathrm{j}\omega) = -\mathrm{j}\,\mathrm{sgn}(\omega)\, X(\mathrm{j}\omega)$$

即转移函数 $H(\mathrm{j}\omega) = -\mathrm{j}\,\mathrm{sgn}(\omega)$：**正频率相移 $-90°$，负频率相移 $+90°$，幅度恒 1。**<span class="marginnote">「全通、但相位在正负频率各转 90°」——希尔伯特变换是个全通系统，却恰恰在 $\omega=0$ 处有相位跳变。正是这个跳变使它成为「正交变换」：两次希尔伯特变换得回原信号的反号，$\hat{\hat{x}} = -x$。</span>

**离散形式**：离散希尔伯特变换的脉冲响应为

$$h[n] = \begin{cases} \dfrac{2\sin^2(\pi n/2)}{\pi n}, & n \ne 0 \\ 0, & n = 0 \end{cases}$$

$$H(\mathrm{e}^{\,\mathrm{j}\omega}) = -\mathrm{j}\,\mathrm{sgn}(\omega), \qquad |\omega| \lt  \pi$$

与连续版本完全平行。注意 $h[n]$ 是**奇对称**的（$h[n] = -h[-n]$）——这正是上一章 FIR 设计里 III/IV 型奇对称结构的用途所在：**离散希尔伯特变换就是一个理想的 $90°$ 相移器，用奇对称 FIR 实现**。

## 2 解析信号：包络与瞬时频率

**解析信号（analytic signal）** 定义为

$$x_a[n] = x[n] + \mathrm{j}\,\hat{x}[n]$$

其频谱单边：$X_a(\mathrm{e}^{\,\mathrm{j}\omega}) = 2X(\mathrm{e}^{\,\mathrm{j}\omega})$（$0\lt \omega\lt \pi$），$=0$（负频率）。**解析信号把实信号的负频率能量全部折叠到正频率**，信息不丢，但形态大为简化。<span class="marginnote">「负频率」在解析信号里消失了——这正是「解析」一词的由来。工程上构造解析信号，只需做一次 FFT：把负频置零、正频加倍、正变换回来。现代音频软件里的「频带包络」就是这么提取的。</span>

有了虚部，三个物理量有了严格定义：

**包络**：$|x_a[n]| = \sqrt{x^2[n] + \hat{x}^2[n]}$——瞬时幅度。
**瞬时相位**：$\phi[n] = \arg x_a[n]$。
- **瞬时频率**：$\omega_i[n] = \dfrac{\mathrm{d}}{\mathrm{d}n}\phi[n]$。

对窄带信号（如调幅广播、语音的单个共振峰），包络与瞬时频率就是「信号的能量怎么变、频率怎么变」的直接答案。<span class="marginnote">心电图 R 波检测、马达振动分析、语音基频提取——这些任务都用同一招：希尔伯特变换 → 解析信号 → 包络或瞬时频率。所谓「AM 解调」本质就是提取解析信号的包络。</span>

**辨析｜易错点：** 瞬时频率不是「每个时刻的 DFT 峰值」。瞬时频率 $\mathrm{d}\phi/\mathrm{d}n$ 对**宽带多分量信号**没有明确物理意义——两个频率叠加时，瞬时频率会剧烈跳动，不代表任何一个分量。**解析信号法只适合单分量（窄带）信号**；对多分量信号要先滤波分解，再用解析信号。

## 3 因果系统与最小相位：对数谱的希尔伯特关系

希尔伯特变换最深刻的应用不在时域，而在**系统理论**：它编码了「因果性/最小相位」对频域施加的约束。

**关键定理（对数幅度—相位关系）**：对因果稳定的最小相位系统，其相位响应完全由**对数幅度响应**决定：

$$\angle H(\mathrm{e}^{\,\mathrm{j}\omega}) = -\frac{1}{2\pi}\int_{-\pi}^{\pi} \ln\big|H(\mathrm{e}^{\,\mathrm{j}\theta})\big|\,\cot\Big(\frac{\omega - \theta}{2}\Big)\,\mathrm{d}\theta$$

即**相位 = 对数幅度的希尔伯特变换（加常数量纲修正）**。<span class="marginnote">这条关系回答了一个构造性问题：<strong>给定幅度响应，能有多少个因果系统实现它？</strong> 答案是无穷多——它们共享相同的对数幅度，但相位彼此不同；其中唯一的最小相位实现，其相位由上式唯一锁定。这就是「最小相位」为何最小：它的相位是给定幅度下因果系统里最「紧」的那个。</span>

**推论与工程意义**：

**任何因果系统的 $\ln|H|$ 与 $\angle H$ 互相锁定**（对全通部分除外）——所以不能随便独立指定幅度与相位。
**最小相位系统的幅度唯一决定相位**：可以只按幅度设计，相位自动随之而来。
- 对**非最小相位**系统，相位 = 最小相位部分相位 + 全通部分相位（全通承载多余相位）。<span class="marginnote">这条「分解」把相位问题拆成两半：最小相位部分由幅度锁死，全通部分自由选择——你在《LTI 系统的变换域分析》见到的「$H = H_{\min}\cdot H_{\mathrm{ap}}$」，正是这里的希尔伯特约束在系统层面的展开。</span>

## 4 公式解析：希尔伯特变换为什么是「正交」

从解析信号的角度重看希尔伯特变换的「正交性」，三步：

**第一步**：实信号 $x[n]$ 的频谱满足共轭对称 $X(\mathrm{e}^{-\mathrm{j}\omega}) = X^*(\mathrm{e}^{\,\mathrm{j}\omega})$——正负频率各带一半能量。
**第二步**：希尔伯特变换乘以 $-\mathrm{j}\,\mathrm{sgn}(\omega)$：正频乘 $-\mathrm{j}$（相移 $-90°$）、负频乘 $+\mathrm{j}$（相移 $+90°$）。由于 $\mathrm{sgn}$ 的奇对称，$\hat{x}[n]$ 的频谱依然是共轭对称的——**$\hat{x}[n]$ 仍是实信号**。
- **第三步**：$x[n]$ 与 $\hat{x}[n]$ 的互相关在零延迟处为零，$\mathbb{E}\{x[n]\hat{x}[n]\} = 0$——两者**正交**。因为正频处 $X$ 与 $\hat X$ 相差 $90°$，能量互不重叠。

**结论：希尔伯特变换是实信号空间里的「旋转 90°」**：保持能量（帕塞瓦尔）、保持实值、且与原信号正交。这三个性质使 $(x, \hat{x})$ 构成解析信号的正交基底，所有基于解析信号的量（包络、相位、瞬时频率）都建立在它的正交性上。<span class="marginnote">「旋转 90°」的比喻不是修辞：$x[n]$ 与 $\hat{x}[n]$ 恰好构成复数平面上的两个正交轴，解析信号就是它们的矢量合成。任何旋转都保持长度（能量），于是 $|x_a|$ 作为包络才稳定不随相位漂移。</span>

## 5 离散希尔伯特变换器的设计

要用 FIR 实现离散希尔伯特变换，回到上一章的设计工具。理想 $h[n]$ 无限长、非因果，需要近似。两种路线：

**窗函数法**：理想 $h_d[n] = \frac{2\sin^2(\pi n/2)}{\pi n}$ 截断 + 时移。由于奇对称，用 **IV 型** FIR（偶数长、奇对称）：

$$H(\mathrm{e}^{\,\mathrm{j}\omega}) = \mathrm{j}\mathrm{e}^{-\mathrm{j}\omega M/2}\, G(\omega)$$

其中 $G(\omega)$ 实函数，近似 $\mathrm{sgn}$ 形状，幅频近似为常数、相位近似 $90°$。<span class="marginnote">工程实现的细节：奇对称 FIR 在 $\omega=0$ 和 $\omega=\pi$ 处幅度归零，所以希尔伯特变换器只在 $\omega_c \le |\omega| \le \pi-\omega_c$ 的中间频段近似理想——两端不可用。这正是前面 FIR 四种类型能力约束的又一次体现。</span>

**FFT 法**：在频域直接构造——正频乘 $-\mathrm{j}$、负频乘 $+\mathrm{j}$、零频置零，再 IDFT。对整块数据处理最方便。

**应用场景速览**：

- **单边带（SSB）调制**：希尔伯特变换构造解析信号，去掉一个边带，频谱效率翻倍。
- **包络 / 瞬时频率提取**：雷达多普勒、机械振动诊断、语音基频。
- **非最小相位系统的相位重构**：从对数幅度恢复相位（反卷积、地震处理）。

### 一个最小例子：提取调幅信号的包络

设 $x[n] = \big(1 + 0.8\cos(0.1\pi n)\big)\cos(0.9\pi n)$——载波 $0.9\pi$ 被低频 $0.1\pi$ 调幅。做一次离散希尔伯特变换得到 $\hat{x}[n]$，则解析信号的包络

$$|x_a[n]| = \sqrt{x^2[n] + \hat{x}^2[n]} \approx 1 + 0.8\cos(0.1\pi n)$$

精确还原了调制信号。**传统包络检波要二极管整流加低通滤波，而解析信号一步到位**——这就是现代软件无线电里 AM 解调的标准实现。同样的「希尔伯特 → 包络」路径也用于机械振动分析，从轴承振动信号里提取故障特征频率。

## 6 小结

- **离散希尔伯特变换**：全通、相位 $\pm90°$，脉冲响应奇对称 $h[n] = \dfrac{2\sin^2(\pi n/2)}{\pi n}$。
- **解析信号** $x_a = x + \mathrm{j}\hat{x}$：频谱单边，负频率能量折叠到正频率；包络、瞬时相位、瞬时频率都由它严格定义。
- **正交性**：$x$ 与 $\hat{x}$ 保持能量、保持实值、零延迟互相关为零——构成解析信号的正交基底。
- **因果/最小相位**：对数幅度与相位互为希尔伯特变换；最小相位的相位由幅度唯一锁定，$H = H_{\min}\cdot H_{\mathrm{ap}}$ 把相位问题拆成两半。
- **实现**：IV 型奇对称 FIR（中间频段近似）或 FFT 直接构造；$|x_a|$ 一步提取包络，是软件无线电 AM 解调的标准做法。
- **易错点**：瞬时频率只适合单分量窄带信号；多分量信号要先分解再取解析信号。
