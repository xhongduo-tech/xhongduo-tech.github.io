## 为什么从谱估计开始

前面十篇把数字信号处理的工具箱一件件装齐：序列与卷积、z 变换、采样、DFT/FFT、滤波器设计、结构、字长、多速率。这一篇是收官——**把这些工具放回真实信号**，回答三个最实际的问题：一段含噪的信号里有哪些频率成分（**功率谱估计**）？未知的干扰如何在线消除（**自适应滤波**）？非平稳信号如何同时看清时间与频率（**小波变换**）？三者都是「从信号里提取信息」的学问，共同撑起语音、通信、生物医学、地震学等一大片应用。<span class="marginnote">用一句话点题：<strong>前面十篇学的是「怎么把信号搬来搬去」，最后一篇学的是「怎么把信号读出来」</strong>——从变换到解释，是数字信号处理从数学走向科学的临门一脚。</span>

## 1 功率谱估计：从有限数据读出频率成分

对一段有限长信号，最直接的频谱工具是**周期图（periodogram）**：取 $N$ 点 FFT，$\hat P(\omega) = \dfrac{1}{N}\big|X(\mathrm{e}^{\mathrm{j}\omega})\big|^2$。它是功率谱的「直接估计」，但有两大毛病：**偏差**（加窗带来的谱泄漏，见《利用 DFT 的频谱分析与窗函数》）与**方差**（估计值围绕真值剧烈抖动，几乎不随 $N$ 增大而收敛）。<span class="marginnote">周期图的方差为什么大？因为它把整段数据当作「一次随机实验」，功率谱估计的方差 ≈ 真值的平方——<strong>相对标准差 100%</strong>，也就是说单条周期图几乎不可信。工程上绝不直接用它，而是分段平均。</span>

功率谱估计与确定性频谱分析有一个关键区别：**它研究的对象是随机过程**。随机信号没有「确定性频谱」，只有「功率在频率上的分布」——所以估计的是统计量 $P(\omega)$，而不是某个确定的 $X[k]$。这也解释了为什么「取一条 FFT 就算完」的谱线会抖：**你在估计一个平均值，却只做了单次测量**。理解这一层，「为什么要平均」就顺理成章了。

一个身边的例子让谱估计落地：**语音端点检测**与**音乐节拍分析**都靠功率谱的短期变化判断「此刻有没有声音、频率重心在哪」；**故障诊断**用旋转机械的振动谱峰定位不平衡轴承；**雷达**用多普勒谱分辨运动目标的速度。这些系统读的都不是「某一条谱」，而是「平均后稳定、且随时间演化的谱」——**谱估计是它们共同的「听诊器」**。

解决方差的办法是**平均**。**Bartlett 法**把 $N$ 点分成 $K$ 段、各段周期图平均，方差降到 $1/K$；**Welch 法**在 Bartlett 之上加了「分段重叠 + 每段加窗」，进一步抑制谱泄漏并保持统计稳定，是今天最主流的功率谱估计器（MATLAB 的 `pwelch`）。代价是分辨率下降：分段使每段变短、频率分辨率 $\Delta f$ 变粗——**这就是功率谱估计的「方差-偏差-分辨率」三角权衡**。

给「三角权衡」一个具体数字：若想分辨相距 50 Hz 的两根谱线，采样率 10 kHz，则每段长度至少 $L \ge f_s/\Delta f = 10000/50 = 200$ 点。若总数据只有 1000 点，能分 5 段（方差降 1/5）但分辨率恰好贴着 50 Hz；想更稳就减少段数、想更细就增加每段——**三个方向永远互相牵制，选哪个取决于应用**：语音基频检测要分辨率（小段数），地震背景监测要稳定（多段平均）。

## 2 公式解析：Welch 法如何同时压低方差与泄漏

**把 Welch 法「分段 + 加窗 + 重叠 + 平均」四步拆开。** 设总长 $N$ 的数据，分成 $K$ 段、每段长 $L$、重叠 50%，加窗 $w[n]$：

- **第一步，分段加窗**：第 $i$ 段 $x_i[n] = x[n + iD]\, w[n]$，$D$ 是段起点间隔（50% 重叠时 $D = L/2$）。
- **第二步，各段周期图**：$\hat P_i(\omega) = \dfrac{1}{L U}\big|X_i(\mathrm{e}^{\mathrm{j}\omega})\big|^2$，$U = \frac1L\sum w^2[n]$ 是窗能量归一化，保证无偏。
- **第三步，平均**：$\hat P_{welch}(\omega) = \frac{1}{K}\sum_{i=1}^{K} \hat P_i(\omega)$。
- **第四步，读取舍**：$K$ 越大方差越小，但每段 $L$ 越短、分辨率越粗；重叠在不增加分段长度的前提下提高 $K$。**同一份数据，Welch 用「多段短窗」换来平稳的谱线**——方差与分辨率的拔河，是全章最核心的取舍。

用一组具体数字体验取舍：数据总长 $N=4096$，若取 $L=1024$、50% 重叠，约得 $K=7$ 段，方差降到单段的 $1/7$，分辨率 $\Delta f = f_s/L$ 是总长下的 4 倍粗；若取 $L=4096$（不分段），分辨率最细但方差 100%。<span class="marginnote">工程经验：先定可接受的分辨率（决定 $L$），再尽量多分段、多用重叠（50–75%）压低方差——<strong>「分辨率是预算，方差是质量，重叠是免费的方差折扣」</strong>是 Welch 选参的口诀。</span>

**辨析｜易错点：** 周期图的结果**不是**「频谱的真相」，而是「一次带噪声的估计」——把单条周期图的尖峰当成真峰，是最常见的误读。另一个错误是混淆「功率谱」与「幅度谱」：功率谱取模平方，能量集中在少数大峰上，习惯用 dB 显示；幅度谱保留相位信息，两者用途不同，别用错量纲。

## 3 自适应滤波：让滤波器自己学会

**自适应滤波（adaptive filtering）** 处理的是「滤波器该滤什么我不知道」的问题：干扰的统计特性随时间变化、未知，靠人工设计固定滤波器力不从心。它的框架是：滤波器系数 $w[n]$ 由**误差信号**驱动，不断调整以最小化某个代价函数。最经典的算法是 **LMS（最小均方）**：

$$w[n+1] = w[n] + \mu\, e[n]\, x[n]$$

其中 $e[n]$ 是期望输出与实际输出之差，$\mu$ 是步长。LMS 的目标函数是**均方误差** $J = E[e^2[n]]$，它是一个关于 $w$ 的二次型（碗形曲面）；LMS 每步沿梯度下降方向走一小步，最终滑到碗底（维纳解）。**「把统计优化问题变成逐点梯度下降」正是 LMS 的全部智慧**——不求最优，只求每步都在变好。<span class="marginnote">LMS 的三个要点：<strong>步长 $\mu$ 控制收敛速度与稳态失调</strong>（大了快但不稳，小了稳但慢）；复杂度只有 $O(N)$；只需期望信号 $d[n]$ 与输入——不需要知道干扰的统计模型。它是「用简单算法换鲁棒性」的典范。</span>步长的稳定上界约为 $0 < \mu < 2/\lambda_{\max}$（$\lambda_{\max}$ 是输入相关矩阵最大特征值），超出则发散。<span class="marginnote">LMS 的收敛与失调有一个基本权衡：<strong>稳态误差 $\propto \mu$，收敛时间 $\propto 1/\mu$</strong>——想又快又准，只能靠变步长（NLMS、归一化）。工程里 LMS 的实用变体 NLMS 按输入能量归一化步长，几乎人手一份。</span>

自适应滤波的经典应用：**回声消除**（扬声器与麦克风的串扰，用自适应滤波器估计回声路径后减去）、**信道均衡**（通信中抵消多径失真）、**噪声对消**（用参考麦克风估计噪声再减掉）。它们共享同一个模式：**「参考信号 + 误差驱动 + 系数在线更新」**，是数字信号处理里「模型不可知也能工作」的代表。

如果嫌 LMS 收敛慢，工程上还有更强的 **RLS（递推最小二乘）**：它维护输入相关矩阵的递推逆，每步收敛快得多（不依赖特征值分散度），但代价是 $O(N^2)$ 的运算与数值稳定性问题。<span class="marginnote">LMS 与 RLS 的取舍是一对典型矛盾：<strong>LMS 简单快但收敛慢、稳态噪声大；RLS 收敛快但贵、易数值病态</strong>。多数实时系统（电话回声消除）选 LMS/NLMS，因为够用且便宜；需要快速跟踪的雷达、声呐场景才舍得用 RLS。</span>两条路线共享「参考 + 误差 + 更新」的骨架，区别只在「怎么算更新」——这是自适应滤波里最重要的一个观察。

走一个 2 阶 LMS 的具体迭代：设输入 $x[n] = \{2, -1, 0.5\}$、期望 $d[n] = \{1, 0.8, 0.2\}$、初始权重 $w=\{0,0\}$、步长 $\mu=0.05$。$n=0$：输出 $y[0]=0$，误差 $e[0]=1$，$w$ 更新为 $\{0.1, -0.05\}$。$n=1$：$y[1] = 0.1\times(-1) = -0.1$，$e[1] = 0.9$，$w$ 再更新。**每步都在「看误差、调权重」**——迭代几十步后 $w$ 收敛到接近最小二乘解，误差趋近某个稳态值。<span class="marginnote">这正是 LMS「在线学习」的本体：<strong>没有批次、没有矩阵求逆，只有一行更新式</strong>。它牺牲了「一次算最优」换取「随时可用、随时适应」，是嵌入式实时系统的绝配。</span>

## 4 小波变换：同时看时间与频率

FFT 只回答「信号里有哪些频率」，却丢失「这些频率何时出现」——对语音、地震、心电这类**非平稳**信号，这是致命的。**小波变换（wavelet transform）** 用一族「可伸缩、可平移」的小波函数去分解信号，得到**时频联合**描述。<span class="marginnote">连续小波变换 $W(a,b) = \frac{1}{\sqrt a}\int x(t)\,\psi\!\big(\tfrac{t-b}{a}\big)\,\mathrm{d}t$：尺度 $a$ 管频率（大 $a$ 看低频）、平移 $b$ 管时间。离散化后用<strong>多分辨分析（MRA）</strong>与 <strong>Mallat 塔式算法</strong>实现——上一篇《多速率信号处理》的树状滤波器组正是它的骨架。</span>关键性质是**时频分辨率自适应**：高频处时间分辨率高（看突变）、低频处频率分辨率高（看趋势）——这与人类听觉对「短促高频音」与「持续低音」的感知习惯惊人一致。这也解释了它与 STFT 的本质区别：STFT 用固定窗长，时频分辨率处处相同（一旦定了窗，高频看不清突变、低频看不清趋势）；小波让窗长随尺度自动伸缩，**突破了「海森堡测不准」只能在固定格点上分配的局限**。

小波的应用：JPEG 2000 图像压缩（用离散小波分解系数量化编码）、心电/脑电信号去噪与特征提取、地震信号分析、故障诊断。<span class="marginnote">小波去噪的思路简洁优雅：噪声在小波域近似白噪声、系数小；有用信号集中在少数大系数上——<strong>对系数做软阈值（soft threshold）后再重构，噪声就被「筛」掉了</strong>。这一招在生物医学信号里几乎是标配。</span>Mallat 算法把「小波变换」落实成「两通道滤波器组 + 二抽取」的循环，与《小波基》《小波包与局部余弦基》两篇一脉相承。

最简单的 Haar 小波足以演示小波分解的全部思想。把信号 $\{4, 2, 6, 8\}$ 做一层分解：相邻两两求平均得低频系数 $\{3, 7\}$（趋势），求差分得高频系数 $\{1, -1\}$（细节）。低频再做一层得 $\{5\}$ 与 $\{2\}$——**信号被压成「一串趋势 + 一串细节」**，大部分能量集中在低频大系数里，小细节系数多为噪声或可舍成分。JPEG 2000 正是靠这种「能量集中」实现高压缩比，而 Haar 的一层分解与《多速率信号处理》里的两通道滤波器组结构完全同构。

小波族的选型也有一张简表：Haar 最简但光滑性差（方块状）、Daubechies 系（db4、db8）光滑且紧支撑、Symlet 近似对称、Coiflet 更对称。**「越光滑的小波，频域局部化越好，但时域支撑越长」**——又是分辨率与复杂度的权衡。<span class="marginnote">工程上 90% 的场合用 db 系或 Symlet 就够；要边界友好（无镜像扩展）用 CDF（Cohen–Daubechies–Feauveau）双正交小波，JPEG 2000 默认的正是 CDF 9/7。</span>

## 5 三个工具怎么选：一张决策表

| 需求 | 首选工具 | 理由 |
| --- | --- | --- |
| 平稳信号频率成分 | Welch 功率谱 | 方差小、分辨率可调 |
| 未知/时变干扰在线消除 | 自适应滤波（NLMS） | 无需先验模型、实时更新 |
| 非平稳信号的时频联合 | 小波变换 | 时频分辨率自适应 |
| 确定性信号滤波 | FIR/IIR（前几篇） | 指标明确、线性相位可期 |

三个工具并非互相取代，而是各管一段：**功率谱回答「有什么」，自适应回答「怎么去掉」，小波回答「何时何频出现」**。<span class="marginnote">一个真实的复合例子：语音增强——先用小波或谱减法估计噪声，再用自适应滤波跟踪噪声变化，最后用功率谱评估效果。三件工具在同一个系统里协作，正是「从极限到大模型」知识树上数字信号处理与应用分支交汇的缩影。</span>

还有一个容易被低估的工具维度：**参数化谱估计**。当信号确实来自少数几个谐波 + 噪声（如雷达回波、旋转机械振动）时，把信号建模成自回归（AR）过程、用《参数信号建模》里的 Levinson-Durbin 求模型系数，再由模型直接算出谱——这就是 AR 谱估计（如 Burg 法）。它对短数据、窄带信号比 Welch 分辨率高得多，代价是「模型选错了就全错」。<span class="marginnote">选型一句话：<strong>「非参数（Welch）稳健但分辨率受限，参数（AR）分辨率高但依赖模型正确」</strong>——先跑 Welch 看大致形态，再决定要不要上参数化，是工程上的稳妥顺序。</span>

## 6 小结

- **周期图**直接但方差大（相对标准差 ~100%）；**Welch 法**分段 + 加窗 + 重叠 + 平均，方差降、泄漏抑、分辨率让步。
- 功率谱估计是**方差–偏差–分辨率**三角权衡；单条周期图的尖峰不是真相。
- **LMS** 自适应：$w[n+1] = w[n] + \mu e[n]x[n]$，$O(N)$、无需模型；NLMS 归一化更稳。回声消除、信道均衡、噪声对消都是它。
- **小波变换**给出时频联合描述，时频分辨率自适应；Mallat 塔式算法 = 两通道滤波器组 + 二抽取。
- 小波去噪靠软阈值：噪声小系数筛掉、信号大系数保留。
- 三工具协作是语音增强等系统的标准形态——数字信号处理从「变换」走向「解释」。
- Welch 选参口诀：分辨率是预算，方差是质量，重叠是免费的方差折扣。
- 参数化（AR/Burg）谱估计分辨率高但依赖模型正确，先跑 Welch 摸底再上。
- LMS 一行更新式 $w \mathrel{+}= \mu e x$，无矩阵求逆、实时可用，是嵌入式实时系统的绝配。
- 小波去噪 = 软阈值筛小系数 + 重构；Haar 一层分解演示了「趋势 + 细节」的全部思想。
- 频谱分析是确定性视图，谱估计是统计视图，周期图只是单次估计、必须平均。
- 小波族选型：Haar 最简、db 系通用、CDF 9/7 是 JPEG 2000 默认。
- 回声消除、信道均衡、噪声对消共享「参考 + 误差 + 更新」骨架。
- 语音增强是「小波/谱减估计噪声 + 自适应跟踪 + 谱估计评估」的复合系统。
- 谱估计是语音、雷达、故障诊断的「听诊器」：读稳定且随时间演化的谱，而非单条谱线。
- 三条元纪律：域是工具、理论给边界工程给选择、从变换走向解释。
- 功率谱、自适应、小波各管一段：有什么、怎么去掉、何时何频出现。
- 收官工具全部复用前文骨架：卷积、采样、结构、字长、多速率在此汇合。
- 周期图相对标准差 ~100%，单条谱线不可信；平均是谱估计的必修课。
- 收官：数字信号处理 = 变换语言 + 滤波器工坊 + 估计与学习的解读之道。
- 功率谱估计对象是随机过程而非确定性频谱，所以必须平均、不能单次就信。
- 小波时频分辨率自适应，突破 STFT 固定窗长的局限；Mallat 算法与多速率树同构。
- 分辨率三角权衡示例：$\Delta f = f_s/L$ 先定预算，再谈分段数与重叠率。
- LMS 与 RLS 取舍：前者简单快但收敛慢，后者收敛快但贵且易数值病态。

## 7 全专题收束

从序列与卷积出发，我们走过 z 变换与采样、DFT 与 FFT、滤波器设计与实现、字长与多速率，最终在谱估计、自适应与小波里学会「读懂信号」。这条主线就是数字信号处理的全景：**先描述（变换），再塑造（滤波），最后解读（估计与学习）**。回看全专题二十余篇，从「一串数怎么表示」到「一段信号怎么读」，恰如从学会识字到学会品读一篇文章——前者的功夫决定了后者能走多远。站在这座桥上回望，你会看到它如何支撑起语音、音频、图像与通信的各条应用支流——那些支流正是「从极限到大模型」课程体系里与它交汇的下一站：数字语音处理、数字图像处理与模式识别。工具已齐，剩下的是去各自的田野里使用它们。

回望整个专题，还有三条「元纪律」值得带走：

- **域是工具，不是终点**：时域、z 域、频域、小波域只是看同一信号的不同角度，学会「换域」就学会了把难题翻译成易题。
- **理论给边界，工程给选择**：奈奎斯特定理、稳定判据、方差-分辨率权衡划出边界，结构选型、字长分配、窗的选择则是边界内的自由。
- **从变换走向解释**：本专题以「如何算」开场，以「如何读」收场——这是数字信号处理与应用科学的真正分界线，也是你在后续分支课程里继续生长的起点。

这三条纪律不是本专题的「装饰」，而是每一篇反复出现的骨架：第一篇的卷积性质、第三篇的采样定理、第六篇的结构选择、第九篇的字长分配、第十篇的多速率恒等式——它们最终都在「谱估计、自适应、小波」这三件收官工具里汇合。若你日后在任何应用领域遇到「看不懂的信号」，请记得回头从这里找语言。
