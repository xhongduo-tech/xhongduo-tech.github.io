## 为什么从采样定理开始

前两篇都在离散世界内部打转。但现实是模拟的——声音是连续的空气压强，电压是连续变化的曲线。**把连续变成离散，是数字信号处理的第一步，也是一步不可逆的取舍。** 采样定理回答的就是一个生死攸关的问题：每秒取多少个点，才能让离散版本完好无损地还原出连续原件？答案的普适形式是**奈奎斯特采样定理（Nyquist sampling theorem）**：采样率必须大于信号最高频率的两倍。低于这个界限，高频成分会伪装成低频混进来，这就是**混叠（aliasing）**——手机录音里那种「车轮倒转」的错觉，正是它造成的。这一篇，把「取点」这件事从工程习惯升格成严格的数学定理。它与第一级《实数》里「连续与离散的张力」一脉相承，也直接决定了后面 DFT 一族的边界条件。

## 1 理想采样的频域图景

连续信号 $x(t)$ 以间隔 $T$ 采样，得到序列 $x[n] = x(nT)$，采样率 $f_s = 1/T$。<span class="marginnote">采样率单位常用 Hz（每秒样本数）或 rad/sample（数字频率 $\omega = 2\pi f/f_s$）。教材里采样率也常写作每秒样本数 sps，混叠判据看的是「每秒样本数」与「最高频率」的关系。</span>把采样过程写成连续形式：

$$x_s(t) = x(t) \cdot p(t), \qquad p(t) = \sum_{n=-\infty}^{\infty} \delta(t - nT)$$

即连续信号乘以周期脉冲串。**乘法在时域，对应卷积在频域**：采样信号的频谱 $X_s(j\Omega)$ 是原频谱 $X(j\Omega)$ 以 $2\pi/T$ 为间隔的无限重复拷贝：

$$X_s(j\Omega) = \frac{1}{T}\sum_{k=-\infty}^{\infty} X\big(j(\Omega - k\Omega_s)\big), \qquad \Omega_s = \frac{2\pi}{T}$$

这是采样理论的核心图景：**采样把频谱「复印」成了以 $\Omega_s$ 为周期的多个副本。** 若原信号带宽有限（最高频率 $\Omega_N$），且副本之间不重叠，就能用低通滤波器完好地取回其中一个副本。

真实 ADC 里没有一个完美的 $\delta$ 脉冲采样器，取而代之的是**采样保持（sample-and-hold）**：在每个周期把电压短暂「锁住」再量化。它的频域效果相当于把样本通过一个零阶保持器，给频谱乘上一个 $\mathrm{sinc}$ 形状的滚降因子——好消息是它不改变副本的周期结构，坏消息是它在高频端引入幅度损失。**理解理想采样，是为了知道现实装置偏离了哪里、偏差有多大、怎么补偿。**

现实世界的采样率是一个个被奈奎斯特定理约束出的工程选择：

| 场景 | 最高频率 | 采样率 | 过采样倍数 |
| --- | --- | --- | --- |
| 电话语音 | 3.4 kHz | 8 kHz | 2.35 |
| CD 音频 | 20 kHz | 44.1 kHz | 2.2 |
| 数字电视 | 5–8 MHz | 13.5 MHz 采样 | 1.7–2.7 |
| 雷达中频 | 数十 MHz | 数百 MHz | 2–10 |

注意电话语音的 8 kHz 采样几乎贴着奈奎斯特率——所以电话听起来「闷」，因为 3.4 kHz 以上的信息被抗混叠滤波主动切掉了。**采样率的选择永远是一场「保真度」与「数据量/成本」的拔河，奈奎斯特定理给了拔河的下限。**

## 2 奈奎斯特定理与混叠

什么条件下副本不重叠？相邻副本的中心相距 $\Omega_s$，每个副本的半宽是 $\Omega_N$，不重叠需要 $\Omega_s \ge 2\Omega_N$：

$$\boxed{\; f_s \ge 2 f_N \quad \left(f_N = \frac{\Omega_N}{2\pi}\ \text{为信号最高频率}\right)\;}$$

**奈奎斯特定理：采样率必须至少等于信号最高频率的两倍，信号才能由样本无失真重建。** $2f_N$ 称为**奈奎斯特率（Nyquist rate）**，$f_N$ 称为**奈奎斯特频率（Nyquist frequency）**。

把采样结果放进数字域有一个记号转换：连续频率 $\Omega$ 与数字频率 $\omega$ 通过 $\omega = \Omega T = 2\pi f/f_s$ 联系。于是「$f_s/2$ 处折叠」翻译成数字域就是「$\omega = \pi$ 处折叠」——**数字世界的频率轴天然在 $\pi$ 处对折**，这与第一篇《离散时间信号与系统》里「离散频率以 $2\pi$ 为周期」的圆周图景完全自洽：混叠，正是那个圆周上「绕一圈回来撞到自己」的频域版。<span class="marginnote">几个容易记混的名词：<strong>奈奎斯特率 = 不混叠的最低采样率 = $2\times$最高频率</strong>；奈奎斯特频率 = 信号本身最高可分辨的频率成分，也是采样率一半处的「折叠频率」。香农与奈奎斯特同一时期独立给出此结果，工程界通称奈奎斯特定理。</span>

**混叠（aliasing）** 发生在 $f_s \lt 2f_N$ 时：超出 $\pm f_s/2$ 的频率成分，其频谱副本叠进 $\pm f_s/2$ 的区间内，与原有成分相加，再也无法分离。<span class="marginnote">经典例证——<strong>电影里高速旋转的车轮看起来在倒转</strong>：车轮每帧转过超过半圈，帧率（采样率）跟不上转速，高频运动被「混叠」成反向低频运动。数学上，频率 $f$ 与 $f + kf_s$ 在样本序列中完全无法区分。</span>

一个直观的数字例子：设正弦 $x(t) = \cos(2\pi f_0 t)$，$f_0 = 900$ Hz，采样率 $f_s = 1000$ Hz。$f_0$ 超过 $f_s/2 = 500$ Hz，混叠发生后重建出的正弦频率是

$$f_{alias} = |\,f_0 - f_s\,| = |900 - 1000| = 100\ \text{Hz}$$

**900 Hz 的信号被「装扮」成了 100 Hz。** 这正是教科书常说的「欠采样把高频折进低频」——人耳听到的会是那个低频幻影，而它根本不在原信号里。实验室里最常见的混叠陷阱是**频闪灯（stroboscope）**：用频率 $f_s$ 的频闪灯照一个转速 $f_0$ 的旋转轮，人眼看到的是 $|f_0 - k f_s|$ 的「幻觉转速」。当 $f_0$ 接近 $f_s$ 的整数倍时，轮子看起来几乎不动——**采样系统用整数倍频率「骗过了」观察者**，这正是欠采样最经典、也最容易在示波器上踩中的坑（示波器默认采样率不够时，波形会「抖」出完全错误的高频）。

一个实用的防混叠数字例子：若信号最高频率确认为 4 kHz，奈奎斯特率是 8 kHz。取 $f_s = 10$ kHz 时，4 kHz 成分落在 $\pm5$ kHz 带内，安全；但若误判最高频率为 3 kHz、取 $f_s = 8$ kHz，则 3–4 kHz 的真实成分就会混叠进 0–1 kHz 区间——**对最高频率的错估，是混叠的第一来源**，所以工程上宁高勿低。

## 3 公式解析：采样定理为什么是「大于等于」

**把「采样率必须 ≥ 2 倍最高频率」拆开看，它在频率轴上到底意味着什么。**

- **第一步，副本间距**：采样间隔 $T$ 决定副本间距 $\Omega_s = 2\pi/T$。$T$ 越小（采样越密），副本离得越远。
- **第二步，重叠判据**：原频谱占据 $[-\Omega_N, \Omega_N]$，它左边的副本占据 $[\Omega_s - \Omega_N, \Omega_s + \Omega_N]$。两拷贝不重叠，需 $\Omega_s - \Omega_N \ge \Omega_N$，即 $\Omega_s \ge 2\Omega_N$。
- **第三步，边界情形**：$f_s = 2f_N$ 时副本刚好相切，理论可重建但工程上不可行——理想低通需要无限陡的滚降。**所以工程标准永远取「大于」：$f_s > 2f_N$，通常取 3–10 倍留余量。**
- **第四步，重建**：在 $f_s \ge 2f_N$ 时，用理想低通（截止 $\Omega_s/2$）滤掉多余副本，再从频谱回到时域。

**辨析｜易错点：** 「奈奎斯特频率」与「奈奎斯特率」常被互换误用：奈奎斯特频率是**信号**的属性（最高频率），奈奎斯特率是**采样**的最低要求（两倍最高频率）。两者的单位也常被写错：奈奎斯特频率与最高频率同单位（Hz），奈奎斯特率是「每秒样本数」，量纲虽同为 $1/T$，语义却完全不同——把「信号最高 20 kHz、用 40 kHz 采样」读成「用 20 kHz 采样」是课堂上最常见的口误。另一个高频错误是以为「采样率大于信号最高频率即可」——漏掉了「两倍」；也有同学混淆「最高频率」与「带宽」：对带通信号，条件只与最高频率有关。

## 4 重建：从样本回到连续

采样定理的「另一半」是**重建（reconstruction）**。理想重建用理想低通滤波器——时域上就是**理想插值（sinc 插值）**：

$$x(t) = \sum_{n=-\infty}^{\infty} x(nT)\, \frac{\sin\!\big(\pi(t-nT)/T\big)}{\pi(t-nT)/T} = \sum_{n} x(nT)\,\mathrm{sinc}\!\Big(\frac{t-nT}{T}\Big)$$

每个样本 $x(nT)$ 乘一个以 $nT$ 为中心的 $\mathrm{sinc}$ 函数再求和——**sinc 在零点和所有其他采样点上取整数值，恰好「穿过」每个样本**，这正是它成为理想插值基的原因。为什么偏偏是 sinc？因为重建滤波器要在频域「取出一个副本」、滤掉其余副本，而理想低通的冲激响应正是 $\mathrm{sinc}$——**时域的插值基与频域的理想低通，是同一个对象的两个面**。<span class="marginnote">理想插值在数学上完美，但在物理上不可实现：sinc 在时间轴上无限延伸，要求非因果、无限长的滤波器。工程上退而求其次用零阶保持（零阶保持器）或线性插值——DAC 芯片里最常见的正是零阶保持器，代价是在高频端引入 sinc 滚降失真，需要预加重补偿。</span>

用一句工程谚语收束重建这一节：**「采样是站在频域看时域的取舍，重建是站在时域看频域的还原。」** 值得再补一个工程观察：现代音频 DAC 常在输出端做**过采样内插（oversampling interpolation）**——先在数字域把样本插值到 8 倍率，再用一个缓和的模拟低通平滑。这等于把「理想重建」拆成「数字域补样本 + 宽松模拟滤波」两步，是奈奎斯特定理在工程里最常见的正确用法。 采样定理的两个方向——采样与重建——在数学上互为逆过程，只要不混叠，这条环就是闭合的；一旦混叠，信息已经永久丢失，任何插值都救不回来。这也是为什么抗混叠预滤波如此重要：**错误一旦在采样时刻铸成，后端的数字世界无法挽回。**

## 5 实用采样：预滤波与 ADC

现实世界没有理想带宽受限的信号，直接采样必然混叠。工程上的标准做法是**先抗混叠滤波（anti-aliasing filter），后采样**：

- **抗混叠低通**：把高于 $f_s/2$ 的功率先滤掉，让进入采样器的信号近似带限。它是有模拟硬件的，通常放在 ADC 之前。
- **过采样（oversampling）**：用比奈奎斯特率高出数倍的 $f_s$ 采样，让混叠落在远端的过渡带里，再用数字低通在安全区处理——现代音频 ADC 普遍采用，把模拟滤波器的实现难度大幅转移给数字域。
- **ADC 的字长**：采样定时间，量化定幅度。量化误差是下一篇《有限字长效应》的主题，与混叠是两条独立却常被混淆的错误来源。一条实用口诀：**混叠是采样率的错，量化是字长的错**——前者发生在取点之前，后者发生在取点之后，调试时先分清是哪个环节引入的失真，往往能省一半排查时间。以 16 位 CD 为例，量化信噪比约 96 dB，远低于模拟系统的本底噪声，所以听感上量化几乎不可闻；真正听得出区别的，常常是混叠或时钟抖动。

以 CD 音频为例：人耳可听上限约 20 kHz，CD 的采样率取 44.1 kHz，略大于 2 倍上限并留出过渡带——**这不是巧合，而是奈奎斯特定理的一个工程镜像**：数字音频的整个架构，都建立在「采样率必须压过最高频率」这条纪律上。<span class="marginnote">为什么偏偏是 44.1 kHz 而不是 40 kHz？历史的答案是 20 kHz 上限加上对早期 PAL/NTSC 视频时钟的兼容，还留了约 10% 的过渡带余量——奈奎斯特定理给出的是数学下限，工程永远要在它之上再讲裕量。</span>

采样率的「减半」与「加倍」本身也是重要运算——把 44.1 kHz 的信号降采样到 22.05 kHz 就是**抽取（decimation）**，反向则是**内插（interpolation）**。它们合称**多速率信号处理**，靠的是「先滤波再变速率」的纪律：直接跳变采样率就等于欠采样，必然混叠。这一主题要到第 5 篇《多速率信号处理》才展开，但它的全部动机都在本节——**多速率处理的每一步，都是在小心地不违背奈奎斯特定理。**

## 6 一段历史：定理的三个名字

奈奎斯特定理不是一个人的功劳。1915 年惠特克（E. T. Whittaker）从**插值理论**出发，证明带宽受限的函数可以被其均匀采样点唯一决定；1928 年奈奎斯特（Harry Nyquist）在贝尔实验室研究电报信号时提出「采样率需为最高频率两倍」的工程判据；直到 1949 年，香农（Claude Shannon）在《通信的数学理论》里用信息论的框架把它整理成严格的采样定理。<span class="marginnote">这三位分别从插值、通信、信息论三条路走到同一个结论，正是数学定理「殊途同归」的典型。今天中文教材常称「采样定理」或「奈奎斯特—香农采样定理」，英文资料亦常写作 Nyquist–Shannon sampling theorem。</span>

为什么香农的版本成为标准？因为他把问题放进信息论的语言：**一个带宽有限的信号，每秒最多携带 $2f_N$ 个独立自由度**，等间隔采样恰好一个自由度取一个样本——不多不少。这解释了为什么「两倍」如此优雅：**它不是工程上「留点余量」的拍脑袋数字，而是信息自由度的精确计数。** 理解到这一层，采样定理就不再是一条要背的公式，而是一句关于「信息如何被搬进离散世界」的守恒律。

## 7 小结

> 一句话备忘：**采样率不够，高频变低频；字长不够，幅度变噪声。**

- 采样在频域的效果是**以 $\Omega_s=2\pi/T$ 为周期复印频谱**。
- **奈奎斯特定理**：$f_s \ge 2f_N$ 是样本可重建原信号的充要条件（工程上取严格大于）。
- **混叠**：欠采样时高于 $f_s/2$ 的成分折回低频，与原频谱不可分离——车轮倒转、900 Hz 变 100 Hz 都是它的杰作。
- 重建靠**理想低通 / sinc 插值**；工程上用零阶保持器加预加重补偿。
- 工程采样流程 = **抗混叠预滤波 + 过采样 + 合适字长**。
- CD 的 44.1 kHz 采样率是奈奎斯特定理的一个教科书级应用。
- 混叠是采样率的错，量化是字长的错——两条错误链路要分开排查。
- 采样定理 = 惠特克（插值）+ 奈奎斯特（通信）+ 香农（信息论）三路汇流。
- 工程口诀：先抗混叠预滤波，再采样；过采样 + 数字处理是化解模拟滤波器难度的主流路线。
- 数字域频率轴在 $\pi$ 处折叠，混叠正是「圆周频率绕一圈撞自己」的频域表现。

在下一节，我们从时域与连续世界跨回离散频域：**离散傅里叶变换**把有限长的样本序列翻译成有限长的频谱，DFT/DFS 的性质与频域采样将给出离散化在频率一侧的完整图景。
