## 为什么从收敛域与传递函数开始

上一篇把卷积练成了肌肉记忆，但逐点卷积太慢了——一串 1000 点的信号，直接卷积要 $10^6$ 次乘加。z 变换把「卷积」翻译成「乘积」，把「差分方程」翻译成「代数方程」，一下子把问题从时域搬进了复平面。而这一切翻译的关键词有两个：**收敛域（ROC）** 和**传递函数（transfer function）**。收敛域决定一个 z 变换到底「属于」哪条序列，传递函数则把系统的因果性与稳定性浓缩成一张零极点图。这一篇，就是学会在 z 平面这张地图上读信号与系统的全部信息。它承接第一级《复数》与第四级《信号与系统》里拉普拉斯变换的思想，把「域」的思维方式彻底转移到离散世界。

## 1 z 变换：把序列翻译进复平面

**z 变换（z-transform）**：对序列 $x[n]$，定义

$$X(z) = \sum_{n=-\infty}^{\infty} x[n]\, z^{-n}$$

其中 $z$ 是复数。<span class="marginnote">把 $z = \mathrm{e}^{\,\mathrm{j}\omega}$ 代入，$X(\mathrm{e}^{\,\mathrm{j}\omega})$ 就是离散时间傅里叶变换（DTFT）——z 变换是 DTFT 的复化推广，这层关系将在《离散傅里叶变换》一篇被反复引用。</span>这个无穷级数不一定收敛，它收敛的那些 $z$ 构成的区域就是**收敛域（region of convergence）**。**同一个 $X(z)$，配上不同的收敛域，对应完全不同的序列**——这是 z 变换最重要的纪律：给定 $X(z)$ 必须同时给出 ROC，否则没有意义。

常用变换对值得背熟，它们构成反变换查表的底本：

| 序列 $x[n]$ | 变换 $X(z)$ | 收敛域 |
| --- | --- | --- |
| $\delta[n]$ | $1$ | 全平面 |
| $u[n]$ | $\frac{1}{1-z^{-1}}$ | $|z|>1$ |
| $a^{n}u[n]$ | $\frac{1}{1-az^{-1}}$ | $|z|>|a|$ |
| $n\,a^{n}u[n]$ | $\frac{az^{-1}}{(1-az^{-1})^2}$ | $|z|>|a|$ |
| $\cos(\omega_0 n)\,u[n]$ | $\frac{1 - \cos\omega_0\, z^{-1}}{1 - 2\cos\omega_0\,z^{-1}+z^{-2}}$ | $|z|>1$ |

看两个经典例子。有限长序列 $x[n] = \{1, 2, 3\}$ 的变换 $X(z) = 1 + 2z^{-1} + 3z^{-2}$，除 $z=0$ 外处处收敛。而双边指数 $x[n] = a^{n}u[n]$（右边序列）给出

$$X(z) = \sum_{n=0}^{\infty} a^{n} z^{-n} = \frac{1}{1 - a z^{-1}}, \qquad |z| > |a|$$

收敛域是 $z$ 平面上的**圆外区域**。若换成左边序列 $-a^{n}u[-n-1]$，代数式完全相同，但收敛域变成 $|z| \lt |a|$ 的**圆内区域**。<span class="marginnote">$a^{n}u[n]$ 与 $-a^{n}u[-n-1]$ 是「同一代数式、两个 ROC」的经典一对。记忆口诀：<strong>右边序列的 ROC 在圆外，左边序列的 ROC 在圆内</strong>——收敛域的方向，暗示了序列向哪个方向延伸。</span>

## 2 收敛域的四条法则

收敛域的长相有严格的几何约束，记住这四条就能快速判断一个 z 变换是否「合法」：

**法则一（圆环）**：ROC 是 $z$ 平面里的圆环域（含圆外 $|z|>r$、圆内 $|z|\lt r$、圆环 $r_1 \lt |z| \lt r_2$ 三种形态），不可能是条带或扇形。因为 $|z|$ 决定收敛，方向 $\angle z$ 不参与。

**法则二（右边序列在圆外）**：右边序列（$n\ge N_1$ 才有值）的 ROC 形如 $|z| > r_{\max}$（最外极点之外）。

**法则三（左边序列在圆内）**：左边序列（$n \le N_2$ 才有值）的 ROC 形如 $|z| \lt r_{\min}$（最内极点之内）。

**法则四（有限长序列例外）**：有限长序列的 ROC 是全平面（可能去掉 $z=0$ 或 $\infty$），因为它是有限项求和，没有发散问题。<span class="marginnote">这些法则的直接推论：<strong>有理 z 变换的 ROC 边界只可能落在极点圆上</strong>。所以画出零极点图，ROC 的形状就一目了然——这就是下一节「读图」的基础。</span>

把这四条法则应用到具体例子：$X(z) = \dfrac{1}{(1-0.5z^{-1})(1-2z^{-1})}$ 的极点在 $0.5$ 与 $2$ 两处，合法的 ROC 只能是三个——圆外 $|z|>2$（右边、因果）、圆环 $0.5\lt|z|\lt2$（双边，既有右边成分又有左边成分）、圆内 $|z|\lt0.5$（左边、非因果）。**同一个代数式能对应三种性格迥异的序列**，选定哪个 ROC 取决于物理设定：因果系统选圆外，离线分析可以选圆环。

**辨析｜易错点：** 因果序列必是右边序列，但右边序列不一定是因果的（可能 $N_1 \lt 0$）。因果性对应的是「ROC 在某个圆之外且含 $\infty$」，更精确的判据在第五节用初值定理给出。

## 3 传递函数：把差分方程变成代数式

对 LTI 系统做 z 变换，卷积定理 $x[n]*h[n] \xleftrightarrow{z} X(z)H(z)$ 直接给出最核心的对象——**系统函数 / 传递函数（transfer function）**：

$$H(z) = \sum_{n=-\infty}^{\infty} h[n] z^{-n} = \frac{Y(z)}{X(z)}$$

工程上 $H(z)$ 几乎总是从差分方程直接读出。对常系数线性差分方程 $\sum_{k=0}^{N}a_k y[n-k] = \sum_{m=0}^{M} b_m x[n-m]$，两边 z 变换、整理得

$$H(z) = \frac{\sum_{m=0}^{M} b_m z^{-m}}{\sum_{k=0}^{N} a_k z^{-k}} = A\, \frac{\prod_{m}(1 - c_m z^{-1})}{\prod_{k}(1 - d_k z^{-1})}$$

分子根 $c_m$ 叫**零点（zeros）**，分母根 $d_k$ 叫**极点（poles）**。<span class="marginnote">零点是让 $H(z)=0$ 的 $z$，极点是让 $H(z)\to\infty$ 的 $z$。<strong>极点的位置直接决定系统是否稳定</strong>——这是全章最重要的结论，公式解析里详细拆。</span>传递函数的价值在于：**时域里缠绕不清的递推关系，在 z 平面只是一张零极点图。** 级联系统的传递函数是各子系统之积，并联系统是之和——上一章卷积的性质在这里各归其位。

从差分方程读 $H(z)$ 有一处讲究：若 $x[n]$ 与 $y[n]$ 的下标都只有非负延迟，则分子多项式直接对应输入系数 $b_m$、分母对应输出系数 $a_k$，且常可约掉公因子。例如 $y[n]-y[n-2]=x[n]-x[n-2]$，得 $H(z)=\tfrac{1-z^{-2}}{1-z^{-2}}=1$，原来是个纯直通系统——**先化简再分析，能省下大量无用功**。

零极点图能直接读出系统的**频率选择性**：极点在单位圆内靠近 $\omega_0$ 的位置，意味着系统在频率 $\omega_0$ 附近有峰值响应（选频）；零点在单位圆上靠近 $\omega_0$ 的位置，意味着在 $\omega_0$ 附近形成凹陷（陷波）。**设计滤波器，本质就是在单位圆内安排极点、在单位圆上安放零点**——这个直觉贯穿第 5 篇接下来的 IIR 与 FIR 设计两篇。例如一个零点放在 $z = -1$（对应 $\omega=\pi$，即最高频）的系统，就是天然的高通：它把最高频分量完全消掉。

## 4 公式解析：从差分方程到零极点与稳定性

**用一个具体的 IIR 滤波器走通「差分方程 → 传递函数 → 零极点 → 稳定性」全程。** 设系统由差分方程给出：

$$y[n] = x[n] + 0.5\, y[n-1] - 0.6\, y[n-2]$$

- **第一步，写传递函数**：移项得 $y[n] - 0.5y[n-1] + 0.6y[n-2] = x[n]$，z 变换后 $H(z) = \dfrac{1}{1 - 0.5z^{-1} + 0.6z^{-2}}$。
- **第二步，求极点**：令分母为零，$z^2 - 0.5z + 0.6 = 0$，解得 $d_{1,2} = \tfrac{0.5 \pm \sqrt{0.25 - 2.4}}{2} = 0.25 \pm 0.758\,\mathrm{j}$。极点是复共轭对，模 $|d| = \sqrt{0.25^2 + 0.758^2} = 0.798$。
- **第三步，判稳定性**：极点的模 $0.798 \lt 1$，落在单位圆内。若系统因果，则 **系统稳定 $\iff$ 全部极点都在单位圆内**，故本系统稳定。
- **第四步，读出冲激响应的性格**：极点模 $|d| \lt 1$ 意味着 $h[n]$ 按 $|d|^n = 0.798^{n}$ 衰减振荡，极点虚部 $0.758$ 决定了振荡频率——**零极点图不仅告诉你稳不稳，还预告了滤波器是个什么「性格」**。

**辨析｜易错点：** 「极点都在单位圆内」**只对因果系统**才是稳定判据。同一个 $H(z)$，若 ROC 取圆内，对应的是非因果但同样稳定的左边序列系统。判稳定性必须先定 ROC，再谈判据——顺序反了就出错。

## 5 因果性、稳定性与初值定理

把时域判据翻译到 z 域，得到一套完整判据：

- **因果性**：ROC 在某个圆外且包含无穷远点（可展成 $z^{-1}$ 的非负幂级数）；等价地，$H(z)$ 的分子阶数不超过分母阶数（延迟只能延后不能超前）。
- **稳定性（BIBO）**：$h[n]$ 绝对可和 $\iff$ ROC 包含单位圆 $|z|=1$。
- **因果 + 稳定**：ROC 含单位圆且为圆外区域 $\iff$ **全部极点都在单位圆内**。

还有一条被低估的实用工具——**初值定理（initial value theorem）**：

$$x[0] = \lim_{z\to\infty} X(z)$$

它用极限代替级数求和，直接读出序列的第一个样本。例如 $X(z) = \dfrac{2z^{-1} + 1}{1 - 0.5z^{-1}}$，取极限得 $x[0] = 1$。<span class="marginnote">初值定理是数字信号处理里「查错神器」：用差分方程算出 $h[0]$，再与 $\lim_{z\to\infty}H(z)$ 对比，两边不一致就说明哪一步 z 变换算错了。误差定位常常比做完整校验快得多。</span>

反过来，反变换才是真正「回家」的路：部分分式展开把 $X(z)$ 拆成一阶项，每一项目查 ROC 对应右边或左边指数序列。因果系统的 $H(z)$ 配圆外 ROC，所以每一项都对到 $a^{n}u[n]$ 形式——**一个因果稳定系统，它的冲激响应必然是指数衰减序列的加权和**，这正是零极点图「读性格」的数学根源。

走一个短例子收束这一节：设 $X(z) = \dfrac{2}{1 - 0.5z^{-1}} + \dfrac{3}{1 + 0.25z^{-1}}$，配 ROC $|z| > 0.5$。第一项的极点在 $z=0.5$、第二项极点在 $z=-0.25$，圆外 ROC 意味着每一项都是右边序列，查表得 $x[n] = 2(0.5)^{n}u[n] + 3(-0.25)^{n}u[n]$。**部分分式分解把「一个有理函数」拆成「一串指数」**，而指数衰减的快慢由极点的模决定——这再次印证：零极点是系统的身份证。

## 6 小结

- z 变换 $X(z)=\sum x[n]z^{-n}$ 把序列翻译进复平面；**给定 $X(z)$ 必须附 ROC**。
- ROC 的四种几何形态与序列方向对应：右边序列圆外、左边序列圆内、有限长全平面。
- **传递函数** $H(z)=Y(z)/X(z)$ 由差分方程直接读出，零极点图承载全部系统信息。
- 因果稳定系统 $\iff$ **全部极点都在单位圆内**；稳定等价于 ROC 含单位圆。
- **初值定理** $x[0]=\lim_{z\to\infty}X(z)$ 是快速查错的利器。
- 工程上先化简 $H(z)$（约公因子）再分析，零极点图一眼看出滤波性格。
- 部分分式 + ROC 查表 = 反变换的标准化流程。
- 零极点图可直接读出频率选择性：极点在单位圆内选频，零点在单位圆上陷波。
- 常系数差分方程 → 传递函数 → 零极点图 → 稳定性，是本章的标准分析流水线。
