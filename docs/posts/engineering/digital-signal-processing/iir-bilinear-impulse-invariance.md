## 为什么从模拟原型开始

前几篇讨论的都是「给定 $H(z)$ 怎么分析、怎么实现」，这一篇轮到真正的问题：**给定指标，怎么设计出 $H(z)$？** IIR 滤波器继承了模拟滤波器的全部设计积累，因而有一个独特的思路：先设计一个成熟的**模拟原型**（巴特沃斯、切比雪夫、椭圆），再把它「搬」到数字域。搬运的两种主要手段——**冲激不变法（impulse invariance）** 与 **双线性变换（bilinear transform）**——各自把「模拟到数字的映射」讲得清清楚楚，也各有优缺点。这一篇不仅教你调库，更让你明白：为什么双线性变换要预畸变频率、为什么冲激不变法会混叠、为什么椭圆滤波器最省阶数。

## 1 模拟原型：滤波器的「模板库」

IIR 设计的起点是一批经典模拟滤波器，它们按「通带内逼近方式」分成几大家族：

| 原型 | 通带特性 | 特点 | 代价 |
| --- | --- | --- | --- |
| 巴特沃斯 | 最大平坦（单调） | 最平、无波纹 | 过渡带最宽，阶数最高 |
| 切比雪夫 I 型 | 通带等波纹 | 过渡带窄、阶数省 | 通带有波纹 |
| 切比雪夫 II 型 | 阻带等波纹 | 通带平坦 | 阻带有波纹 |
| 椭圆（考尔） | 通阻带都等波纹 | 同样指标阶数最少 | 相位最非线性 |

**巴特沃斯**的幅度平方 $\left|H_a(\mathrm{j}\Omega)\right|^2 = \dfrac{1}{1+(\Omega/\Omega_c)^{2N}}$ 在 $\Omega_c$ 处增益恰为 $-3$ dB，$N$ 阶滚降 $20N$ dB/十倍频。<span class="marginnote">选型口诀：<strong>要「稳」选巴特沃斯，要「窄」选切比雪夫，要「省」选椭圆</strong>。椭圆能以最低阶数满足指标，但相位畸变最大；若后面还要做相位补偿，巴特沃斯往往更省心。</span>这些模拟原型的设计公式、查表、极点在单位圆左半平面的位置，教材都有完整表格，工程上直接调 `butter`、`cheby1`、`ellip` 即可——**理解它们的代价函数，才知道该调谁**。

用一个具体指标感受原型的阶数差异：要求通带内纹波 $\le 1$ dB、阻带衰减 $\ge 60$ dB、过渡带 $\Omega_s/\Omega_p = 1.5$。巴特沃斯要 $N=17$，切比雪夫 I 型要 $N=8$，椭圆只要 $N=4$——**同样是「达标」，原型选得聪明能省四倍阶数**，这直接影响硬件成本与相位复杂度。选择「谁」永远是一次「性能与代价」的权衡，没有免费的午餐。

这些原型也各有来历：巴特沃斯 1930 年提出「最大平坦」准则，切比雪夫借多项式逼近让通带等波纹、过渡带更陡，椭圆原型（考尔）用椭圆函数在通阻带同时等波纹逼近理论极限。**模拟滤波器的整个理论库在 1930–1950 年代已经成熟**，数字时代的双线性变换只是把它平稳地「翻译」进 z 平面——这正是「站在巨人肩膀上」在工程里最实在的一例。

## 2 冲激不变法：把脉冲响应直接采样

**冲激不变法（impulse invariance）** 的想法最直白：数字滤波器的脉冲响应 $h[n]$，就取模拟滤波器脉冲响应 $h_a(t)$ 在 $t = nT$ 处的采样值：

$$h[n] = h_a(nT)$$

这条定义直接复用了《连续时间信号的采样与重建》的框架：把 $h_a(t)$ 当作「被采样的连续信号」，采样定理立刻告诉我们——**只要 $h_a$ 的频谱在 $\pm f_s/2$ 之外足够小，$h[n]$ 就忠实地携带了 $h_a$ 的全部信息**；反之就会混叠。把「采样定理」与「滤波器设计」用一条定义缝合在一起，是冲激不变法最优雅的地方。

模拟传递函数 $H_a(s)$ 的极点 $s_k$ 经此映射变成数字极点 $z_k = \mathrm{e}^{s_k T}$，即 $s_k = \sigma_k + \mathrm{j}\Omega_k \mapsto z_k = \mathrm{e}^{\sigma_k T}\mathrm{e}^{\,\mathrm{j}\Omega_k T}$。<span class="marginnote"><strong>$s \to z$ 的指数映射只把「$s$ 平面」的条带 $-\pi/T\lt \Omega \lt \pi/T$ 卷到单位圆上</strong>；$s$ 平面左半（$\sigma\lt0$）映到单位圆内，虚轴映到单位圆——模拟稳定系统映为数字稳定系统。这个映射是逐极点进行的，所以只在 $H_a(s)$ 可部分分式展开时适用。</span>

冲激不变法的优点：**数字滤波器的时域脉冲响应忠实于模拟原型**，且通带内频率响应近似保持——低频处两系统的幅度谱几乎重合。缺点同样致命：**采样必然混叠**。模拟原型若在高于 $f_s/2$ 处仍有可观频谱，混叠就会污染数字滤波器的阻带。

走一个一阶例子把映射看实。模拟一阶低通 $H_a(s) = \dfrac{1}{s+1}$，部分分式后取 $T=0.1$：$H(z) = \dfrac{T}{1 - \mathrm{e}^{-T} z^{-1}} = \dfrac{0.1}{1 - 0.9048 z^{-1}}$。验证映射方向：模拟极点 $s=-1$（左半平面，稳定）映到 $z = \mathrm{e}^{-0.1} = 0.9048$（单位圆内，稳定）——**稳定保持稳定**。数字直流增益约 $0.1/0.0952 \approx 1.05$，与模拟直流增益 1 有约 0.4 dB 偏差，这正是混叠在低频端的轻微残留。<span class="marginnote">因此冲激不变法<strong>只能用于阻带衰减足够大的低通/带通滤波器</strong>，高通滤波器用它必翻车（高通在无穷频率处仍有增益，混叠不可避免）——这是考试与工程里最常考的适用性判断。</span>此外它无法控制数字频率与模拟频率的比例，设计流程要显式指定采样周期 $T$。

## 3 双线性变换：整体映射，一次到位

**双线性变换（bilinear transform）** 用一次整体代换把整个 $s$ 平面映到 $z$ 平面：

$$s = \frac{2}{T}\,\frac{1 - z^{-1}}{1 + z^{-1}}, \qquad z = \frac{1 + (T/2)s}{1 - (T/2)s}$$

把 $s = \mathrm{j}\Omega$ 代入可证：**$s$ 平面虚轴整体映到单位圆，左半平面映到单位圆内**——稳定系统的映射保持稳定，且是「一次到位」的全局变换，不依赖部分分式展开。<span class="marginnote">双线性变换的关键性质：<strong>它是 $s$ 平面与 $z$ 平面之间的保双线性映射（Möbius 变换）</strong>，把「$s$ 平面整张」而不是「一条条带」卷到单位圆上，因此<strong>没有混叠</strong>——代价是频率轴被非线性压缩。</span>

几何上看，双线性变换是「先把 $s$ 平面按 $\arctan$ 压扁，再指数卷到单位圆」两步的合成：$s \mapsto \frac{2}{T}\arctan\left(\frac{\Omega T}{2}\right)$ 把虚轴压到有限区间，$\mathrm{e}^{\mathrm{j}\omega}$ 再把它卷成圆周。<span class="marginnote">与之对比，冲激不变法是「直接指数映射 $\mathrm{e}^{sT}$」，把无限多条竖直条带都卷到同一个单位圆上——<strong>所以它混叠（条带彼此重叠）、而双线性不混叠（只有一条条带被卷）</strong>。一「压」一「卷」，两种映射的性格差异就在这一步。</span>这也是为什么双线性能处理高通、带阻——冲激不变法对这些「阻带在高频」的滤波器束手无策。

频率压缩由下式描述，称为**频率预畸变（frequency warping）**：

$$\omega = 2\arctan\!\Big(\frac{\Omega T}{2}\Big)$$

模拟频率 $\Omega$ 与数字频率 $\omega$ 不再是线性关系：低频段几乎成正比，高频段被严重压缩——模拟的无穷大频率被压到数字的 $\pi$。**设计时必须先把数字截止频率 $\omega_c$ 反变换成模拟预畸变频率 $\Omega_c = \frac{2}{T}\tan(\omega_c/2)$，再设计模拟原型，最后代回双线性变换。** 这就是「预畸变」三个字的来历。

用具体数字感受畸变的量级：数字截止频率 $\omega_c = 0.5\pi$ 时，$\Omega_c = 2\tan(0.25\pi) = 2$，比「线性估计」的 $\omega_c/T = 1.57$ 大约 27%——**越往高频，偏差越大**。$\omega_c = 0.9\pi$ 时 $\Omega_c = 2\tan(0.45\pi)\approx 12.7$，几乎是线性估计的 4.5 倍。所以「预畸变」不是可选项，而是双线性变换的**必要步骤**：漏掉它，设计的截止频率会整体偏离指标，滤波器性能直接不达标。

## 4 公式解析：一次完整的双线性设计

**设计一个数字低通：通带截止 $f_p = 3$ kHz、阻带截止 $f_s = 5$ kHz、采样率 $f_t = 20$ kHz、阻带衰减至少 40 dB。**

- **第一步，转数字频率**：$\omega_p = 2\pi f_p/f_t = 0.3\pi$，$\omega_s = 2\pi f_s/f_t = 0.5\pi$。
- **第二步，预畸变**：取 $T=1$（归一化），$\Omega_p = 2\tan(\omega_p/2) = 2\tan(0.15\pi) \approx 1.019$，$\Omega_s = 2\tan(0.25\pi) = 2$。
- **第三步，确定阶数**：对巴特沃斯，$N \ge \dfrac{\log\big((10^{4/10}-1)^{1/2}\big)}{\log(\Omega_s/\Omega_p)}$，代入得 $N \ge 3.36$，取 $N=4$。
- **第四步，设计模拟原型、代回双线性**：用 4 阶巴特沃斯极点位置构造 $H_a(s)$，再把 $s = 2(1-z^{-1})/(1+z^{-1})$ 代入、化简，得数字 $H(z)$。
- **第五步，验算**：把 $H(z)$ 在 $z = \mathrm{e}^{\mathrm{j}0.3\pi}$ 处算幅度，应落在通带边沿（约 $-3$ dB 附近）；在 $z = \mathrm{e}^{\mathrm{j}0.5\pi}$ 处应低于 $-40$ dB。**设计完必须验算关键频点**——这是「设计闭环」最重要的一步，所有工具库在返回结果时都应配一张频率响应图，人眼确认过才算数。

**辨析｜易错点：** 全流程有四处高频错误——其一，预畸变方向搞反（必须先反算模拟频率再设计）；其二，忘记 $T$ 的取值约定（教材常取 $T=1$ 归一化，工程上要统一）；其三，把「双线性变换保稳定」误记为「保线性相位」——它**不**保相位线性；其四，阶数计算用错公式（切比雪夫与巴特沃斯的阶数公式不同）。

## 5 设计流程对比与选型

两种方法各有适用域，收成一张对照表：

| 维度 | 冲激不变法 | 双线性变换 |
| --- | --- | --- |
| 映射方式 | 逐极点指数映射 | 全局 Möbius 映射 |
| 混叠 | 有（阻带被污染） | 无 |
| 频率关系 | 近似线性（低频） | 非线性（需预畸变） |
| 适用 | 低通、带通（阻带足够深） | 各种滤波器 |
| 时域保真 | 脉冲响应忠实 | 脉冲响应变形 |
| 实现 | 需部分分式展开 | 直接代换，最常用 |

工程上**双线性变换是默认选择**：MATLAB 的 `bilinear`、`butter` 内部就是它；冲激不变法只在「必须保时域形状」（如某些脉冲整形）时登场。<span class="marginnote">现代工具链里，设计一个 IIR 低通可以一句话：`[b,a] = butter(4, 0.3)`——但这一句背后就是「预畸变 → 原型 → 双线性」三步。<strong>会调库和懂原理的区别，在于指标改变时你知道该改哪个参数、该担心哪个环节</strong>。</span>

IIR 与 FIR 的取舍在选型时绕不开，这里先把账算清：IIR 用低阶数换高效——满足同样阻带指标，IIR 常比 FIR 少 3–5 倍阶数，实时成本低；但 IIR 相位非线性，群延迟随频率剧烈变化，对波形敏感的应用（数据通信、医学波形）会因此失真。**要严格线性相位或任意幅度形状，只能选 FIR**，那是下一篇的主题；而这篇的结论是：IIR 适合「幅度指标为主、相位要求宽松」的场合，如音频均衡、降噪。

从低通原型派生出高通、带通、带阻还有一套**频率变换（frequency transformation）**技巧：对 $H_a(s)$ 做 $s \to f(s)$ 的代换，如低通→高通用 $s \to \omega_c/s$，低通→带通用 $s \to \frac{s^2+\omega_0^2}{Bs}$。配合双线性变换，一条「低通原型 + 代换 + 双线性」的流水线就能设计出任意类型的 IIR 滤波器——**这就是「只设计低通，其他靠变」的设计哲学**，与下一篇 FIR 的「想什么形状就逼近什么形状」形成鲜明对比。

## 6 小结

- IIR 设计主流路线：**先选模拟原型（巴特沃斯/切比雪夫/椭圆），再搬到数字域**。
- **冲激不变法**：$h[n] = h_a(nT)$，逐极点映射 $z = \mathrm{e}^{sT}$；保时域、但有混叠，禁用高通。
- **双线性变换**：$s = \tfrac{2}{T}\tfrac{1-z^{-1}}{1+z^{-1}}$，全局映射、无混叠，需**频率预畸变**。
- 预畸变三步：数字频率 → $\Omega = \tfrac{2}{T}\tan(\omega/2)$ → 设计原型 → 代回变换。
- 预畸变在高频偏差可达数倍（$\omega=0.9\pi$ 时约 4.5 倍），漏掉即指标失效。
- 椭圆阶数最省、相位最差；巴特沃斯最平最稳；双线性是工程默认。
- IIR 相位非线性、结构简单、阶数省；想要严格线性相位要转到 FIR——下一篇主题。
- 设计闭环必须验算关键频点：通带边沿、阻带起点各测一次幅度，人眼确认。
- 冲激不变法「压条带」直接卷圆 → 混叠；双线性「先压扁再卷」→ 不混叠但畸变。
- 高通/带通/带阻可从低通原型经频率变换 $s\to f(s)$ 派生，无需重设计。
- IIR 比 FIR 省 3–5 倍阶数，但相位非线性；幅度优先选 IIR，波形敏感选 FIR。
- 模拟原型库是 1930–1950 年代成熟的；双线性变换只是把它翻译进 z 平面。
- 验证示例：一阶低通经冲激不变得 $H(z)=\frac{T}{1-\mathrm{e}^{-T}z^{-1}}$，极点 $s=-1\to z=0.9048$。
- 双线性设计闭环：指标 → 预畸变 → 原型阶数 → 代换 → 验算关键频点。
- 冲激不变法直接复用采样定理框架，用「$h_a$ 频谱是否带限」预判混叠风险。
- 原型的阶数差可达四倍：同样指标巴特沃斯 17 阶、切比雪夫 8 阶、椭圆 4 阶。

在下一节，我们转向另一大设计流派：**FIR 滤波器设计**。FIR 能给出精确线性相位，窗函数法与等波纹逼近将教会我们如何用有限长的冲激响应逼近理想特性。
