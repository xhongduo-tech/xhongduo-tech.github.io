## 为什么从序列与卷积开始

前面《离散时间信号与系统》一篇已经搭起整套离散语言的地基。这一篇不是重讲一遍，而是把三样最常用的工具打磨成肌肉记忆：**序列（sequence）** 怎么表示与操作、**线性时不变（LTI）系统**凭什么统治数字信号处理的半壁江山、**卷积（convolution）** 到底怎么逐点算出来。语音降噪、图像滤波、通信均衡——几乎所有应用层算法最终都落回「一个 LTI 系统对一串样本做卷积」这句话上。学会亲手算一条卷积，你就真的理解了滤波器内部在发生什么。它与第四级《信号与系统》里的连续卷积遥相呼应，但离散世界自有其周期性与长度法则，这些正是本篇要扎稳的根。

## 1 序列：带序号的数表及其运算

**序列（sequence）** 是定义在整数序号上的函数 $x[n]$，括号里是整数。表示方式三选一：解析式 $x[n] = 0.8^{n}u[n]$、列表式 $x[n] = \{\dots, 2, 4, 6\}$（下划线标 $n=0$ 处）、或图形。<span class="marginnote">列表式里用下划线把 $n=0$ 的位置标出来，否则读者无法判断「6」对应哪个序号——这是数字信号处理教材里的通用约定，考试与论文都遵守。</span>

对序列的运算与对连续函数的运算几乎一一对应，但多了一个**延迟**操作：

**移位（延迟）**：$x[n-k]$ 把整串数向右（$k>0$）移 $k$ 拍。**线性组合**：$a x[n] + b y[n]$ 逐点相加乘。**乘积**：$x[n] y[n]$ 逐点相乘，它不是卷积，别混淆。**翻转**：$x[-n]$ 把序列以 $n=0$ 为轴镜像——这是卷积「翻转」那一步的源头。<span class="marginnote">两个序列相乘与卷积是新手最容易搞混的一对：乘积是「同位相乘」，卷积是「错位加权求和」。在时域里它们的地位天差地别——卷积对应频域的乘法，乘积对应频域的卷积，正好颠倒。</span>

有一类序列在后续章节反复出现，是构建更复杂序列的「积木」：

| 基本序列 | 定义 | 直观角色 |
| --- | --- | --- |
| 单位脉冲 $\delta[n]$ | $n=0$ 时为 1，其余为 0 | 离散世界的「冲激」，卷积的探针 |
| 单位阶跃 $u[n]$ | $n\ge 0$ 时为 1，否则 0 | 离散世界的「开关」 |
| 实指数 $a^{n}u[n]$ | 幂函数乘阶跃 | $|a|\lt 1$ 衰减、$|a|>1$ 增长 |
| 复指数 $\mathrm{e}^{\,\mathrm{j}\omega_0 n}$ | 单位圆上的旋转 | 频域分析的主角 |
| 正弦 $A\cos(\omega_0 n + \phi)$ | 余弦序列 | 最自然的「测试信号」 |

它们之间的递推关系是 $\delta[n] = u[n] - u[n-1]$，而任意序列都能写成

$$x[n] = \sum_{k=-\infty}^{\infty} x[k]\,\delta[n-k]$$

这叫作**移位脉冲分解（sifting property）**。表面上看它只是「把一个序列拆成无穷多个脉冲」，但它的威力在于：**只要知道系统对 $\delta[n]$ 的响应，就能用这条式子推出系统对任意输入的响应**——这就是下一节卷积的直接来源。

## 2 线性时不变系统：为什么它是主角

**离散时间系统**：把输入序列映射为输出序列的变换，记 $y[n] = \mathcal{T}\{x[n]\}$。四条基本性质中，两条定义了 LTI：

**线性（linearity）**：$a x_1[n] + b x_2[n] \mapsto a y_1[n] + b y_2[n]$，即叠加原理。**时不变（time-invariance）**：$x[n-n_0] \mapsto y[n-n_0]$，即系统行为不随时间推移改变。<span class="marginnote">「线性」保证可以把复杂输入拆成简单分量逐个分析再叠加；「时不变」保证昨天测的系统特性今天依然成立——这两条是全部频域分析的前提。若系统是时变的（如自适应滤波器），频域方法就要改头换面，那正是第 5 篇最后一篇《谱估计与应用》的话题。</span>

**同时满足线性与时不变的系统叫 LTI 系统。** 它之所以是主角，是因为下面这条定理：

$$y[n] = \mathcal{T}\{x[n]\} = \sum_{k=-\infty}^{\infty} x[k]\, h[n-k], \qquad h[n] \triangleq \mathcal{T}\{\delta[n]\}$$

即：**LTI 系统对任意输入的响应，等于输入与单位脉冲响应 $h[n]$ 的卷积。** 一个 LTI 系统的全部信息，浓缩在一串 $h[n]$ 里。这解释了为什么数字滤波器的设计最终都归结为「设计一串 $h[n]$ 的系数」——FIR 滤波器设计一章做的工作正是这件事。

反过来说，一个系统若**不**是 LTI，上述定理一概不成立。例如 $y[n] = n\,x[n]$（放大倍数随时间变）是线性的但时变；$y[n] = x^2[n]$ 是时不变的但非线性——它们都不能用单一 $h[n]$ 描述。**判断一个系统是否 LTI，是动手做频域分析前的第一道安检。**

四个性质各自有一眼能识别的典型例子，值得收进一张对照表：

| 系统 | 线性 | 时不变 | 因果 | 稳定 | 备注 |
| --- | --- | --- | --- | --- | --- |
| $y[n] = a x[n] + b$ | 否（偏移破坏叠加） | 是 | 是 | 是 | 常数偏移就不线性 |
| $y[n] = n\,x[n]$ | 是 | 否（放大倍数漂移） | 是 | 否 | 时变典型 |
| $y[n] = x[n+1]$ | 是 | 是 | 否（看未来） | 是 | 非因果典型 |
| $y[n] = 2y[n-1] + x[n]$ | 是 | 是 | 是 | 否（$h[n]=2^n$ 发散） | 不稳定 IIR |
| $y[n] = \frac12\big(x[n]+x[n-1]\big)$ | 是 | 是 | 是 | 是 | 最典型的 LTI：滑动平均 |

这张表最有价值的一行是最后一个——**滑动平均 $y[n] = \tfrac12(x[n]+x[n-1])$**：它兼有全部好性质，是 FIR 低通的雏形，也是后面滤波器设计里「窗函数法」会反复出现的原型。记住它，你就同时记住了一类 LTI 系统的范式。

## 3 卷积的三种算出手法

卷积 $y[n] = x[n] * h[n] = \sum_k x[k] h[n-k]$ 的直观动作是**翻转—平移—相乘—求和**。遇到具体序列时，有三种实用的算法，各有适用场景：

| 手法 | 操作 | 适用 | 缺点 |
| --- | --- | --- | --- |
| 图解法 | 画 $h[-k]$ 平移到 $n$ 逐点相乘累加 | 短序列、看清过程 | 序列一长就繁琐 |
| 表格法 | 两行错位乘加，逐列求和 | 中等长度、考试 | 位置对错易出错 |
| 编程法 | `conv(x, h)` 一条命令 | 工程与仿真 | 看不到过程 |

表格法值得多说一句。设 $x[n]$ 非零区间 $[N_1, N_2]$、$h[n]$ 非零区间 $[M_1, M_2]$，则 $y[n]$ 非零区间是 $[N_1+M_1,\, N_2+M_2]$。把 $x[k]$ 与 $h[n-k]$ 写成两行，按「错位乘加」逐列相加。**输出长度等于两输入长度之和减一**：$L_y = L_x + L_h - 1$——这个结论在做卷积时极其常用。<span class="marginnote">$L_y = L_x + L_h - 1$ 是判断卷积结果长度的黄金公式。例如两个长度都是 4 的序列，卷积结果长度是 7。它也在《DFT 的圆周卷积与线性卷积》一篇里扮演关键角色——圆周卷积要凑成这个长度才能与线性卷积相等。</span>

**辨析｜易错点：** 三种手法其实都在做同一件事，但「乘积 $x[n]y[n]$ 的长度等于两者长度一致时的逐点对应」常被误记成卷积的长度公式。卷积变长、乘积不变长，这一长一短正是两者本质差别的影子。

## 4 公式解析：手工计算一条卷积

**亲手算一遍胜过背十遍公式。** 取 $x[n] = \{2, 1\}$（$n=0,1$），$h[n] = \{1, 3, 2\}$（$n=0,1,2$），两者长度 2 与 3，输出长度 $2+3-1=4$。

- **第一步，列出 $x[k]$ 与 $h[k]$ 的非零值**：$x[0]=2,\ x[1]=1$；$h[0]=1,\ h[1]=3,\ h[2]=2$。
- **第二步，逐个 $n$ 计算**：$y[n] = \sum_k x[k]h[n-k]$。$n=0$：只有 $x[0]h[0]=2$。$n=1$：$x[0]h[1] + x[1]h[0] = 6 + 1 = 7$。$n=2$：$x[0]h[2] + x[1]h[1] = 4 + 3 = 7$。$n=3$：仅 $x[1]h[2] = 2$。
- **第三步，汇总**：$y[n] = \{2, 7, 7, 2\}$。

每个 $n$ 求和的项数是「当前能重叠的移位数」，这正是「翻转—平移」在数字上长什么样。用交换律核对一遍：把 $x$、$h$ 对调再算，$h[n]*x[n]$ 同样得到 $\{2, 7, 7, 2\}$——**结果一致，说明计算无误**，这是最省事的自检法。

**辨析｜易错点：** 计算时常见的两类错——其一，忘了 $n$ 超出 $[N_1+M_1, N_2+M_2]$ 后 $y[n]=0$，把不存在的项写进去；其二，表格法里把「两个序列的相同下标」当成「要相乘的项」，实则相乘项的下标之和恒等于 $n$，这是检验每列是否写对的判据。

## 5 卷积的性质与系统的性质挂钩

卷积的三条性质——**交换律** $x*h = h*x$、**结合律** $x*(h_1*h_2)=(x*h_1)*h_2$、**分配律** $x*(h_1+h_2)=x*h_1+x*h_2$——每一条都对应一个工程事实：级联 LTI 系统的次序可以任意换、级联系统可以折叠成单个系统（$h = h_1 * h_2$）、并联系统可以相加。**设计复杂滤波器网络时，先用这些规律化简，再谈实现。** 一个直观例子：一个「回声器」（$h_1[n]$ 是带延迟的单位脉冲）级联一个「低通」（$h_2[n]$），整体效果等于卷积 $h_1*h_2$，而交换次序听感不变——前提是两个系统都是 LTI。

系统的**因果性**与**稳定性**也能翻译成对 $h[n]$ 的约束：

- **因果性**：$y[n]$ 不依赖未来输入 $\iff h[n]=0\ (n\lt 0)$。
- **稳定性（BIBO）**：有界输入必有有界输出 $\iff \sum_{n=-\infty}^{\infty}|h[n]| \lt \infty$，即脉冲响应绝对可和。

用这两个判据回看上面那张表：滑动平均的 $h[n]=\{\tfrac12,\tfrac12\}$ 因果且绝对可和，当然稳定；而 $y[n]=2y[n-1]+x[n]$ 的 $h[n]=2^n u[n]$ 绝对可和发散，所以不稳定——**稳定性不需要靠「试输入」验证，算一次求和即可**，这正是把性质翻译成 $h[n]$ 约束的价值所在。工程上遇到一个来路不明的滤波器，第一件事就是算 $\sum |h[n]|$，而不是接上信号看它炸不炸。

后一条把「系统会不会爆」化成了一个可以检验的数列求和——在 z 变换一章，它会进一步变成「极点是否在单位圆内」。而因果性则决定了系统「能不能实时实现」：只要 $h[n]$ 在负半轴有值，这个滤波器就偷看了未来，只能做离线处理。<span class="marginnote">一个漂亮的例子：$y[n] = x[n+1]$ 这个「超前一个样本」的系统是 LTI 且因果性不满足（$h[n]=\delta[n+1]$），它无法实时实现，但可在离线批处理里当作「相位补偿」工具使用——非因果系统并非无用，只是不能实时。</span>

## 6 小结

- 序列 $x[n]$ 定义在整数上，运算含**移位、线性组合、乘积、翻转**；任意序列可按移位脉冲分解为 $\sum x[k]\delta[n-k]$。
- **LTI 系统** = 线性 + 时不变；其全部信息由**单位脉冲响应 $h[n]$** 承载。
- 输出是**卷积和** $y[n] = \sum_k x[k]h[n-k]$；卷积可用图解、表格、编程三法计算。
- 输出长度公式：$L_y = L_x + L_h - 1$。
- 卷积满足**交换、结合、分配**律，对应级联/并联系统的化简。
- 因果 $\iff h[n]=0\ (n\lt 0)$；稳定 $\iff \sum|h[n]|\lt\infty$。
- 判定系统是否为 LTI，可对照四条性质的典型例子表逐条检验。

在下一节，我们将把卷积的时域语言升级成代数语言：**z 变换**让「求系统输出」变成「解代数方程」，并给出稳定性的极点判据。
