## 为什么从 DFT 开始

DTFT 给了我们漂亮的频谱理论，但它有两个「不实用」的地方：**求和要对无限长的序列跑遍所有 $n$，积分要在连续的 $\omega$ 上跑**。计算机只能处理有限长的数据、有限多的频点。**离散傅里叶变换（DFT）** 就是为回答「如何在计算机上算频谱」而生：它把长度为 $N$ 的序列，变换成 $N$ 个离散频点上的频谱样本。这一篇是 DSP 从「数学」走向「计算」的分水岭——**DFT 是唯一可以被数字计算机直接执行的傅里叶变换**，它的快速算法就是下一章 FFT，而它的各种截断与周期化副作用，正是再下一章窗函数要处理的题目。你手机里的每一次均衡、每一张 JPEG、每一个语音识别特征，底层都是 DFT 在跑。

## 1 DFT 的定义：有限长序列的离散频谱

**DFT 正变换**：对长度为 $N$ 的有限长序列 $x[n]$（$0\le n \le N-1$），定义

$$\boxed{\;X[k] = \sum_{n=0}^{N-1} x[n]\, \mathrm{e}^{-\mathrm{j}\frac{2\pi}{N}kn}, \qquad k = 0, 1, \dots, N-1\;}$$

**IDFT 反变换**：

$$\boxed{\;x[n] = \frac{1}{N}\sum_{k=0}^{N-1} X[k]\, \mathrm{e}^{\,\mathrm{j}\frac{2\pi}{N}kn}, \qquad n = 0, 1, \dots, N-1\;}$$

其中 $\mathrm{e}^{-\mathrm{j}\frac{2\pi}{N}kn}$ 是 $N$ 个均匀分布在单位圆上的旋转因子。<span class="marginnote">记 $W_N = \mathrm{e}^{-\mathrm{j}2\pi/N}$，则 $X[k] = \sum_{n=0}^{N-1} x[n] W_N^{kn}$。$W_N$ 是 $N$ 次单位根：$W_N^{N} = 1$，把它绕单位圆走一圈正好回到起点。整个 DFT 的对称美都藏在这个 $W_N$ 里。</span>

两个关键理解：

**DFT 是 DTFT 的等间隔采样**。把 DTFT $X(\mathrm{e}^{\,\mathrm{j}\omega}) = \sum_{n} x[n]\mathrm{e}^{-\mathrm{j}\omega n}$ 在 $\omega_k = \frac{2\pi k}{N}$ 处取值，恰好得到 DFT：

$$X[k] = X(\mathrm{e}^{\,\mathrm{j}\omega})\big|_{\omega = \frac{2\pi k}{N}}$$

即**频域被 $N$ 等分，每个 $X[k]$ 是频谱在频点 $\frac{2\pi k}{N}$ 的样本**。<span class="marginnote">所以「做 DFT」就是「在单位圆上均匀布点取频谱」：$k$ 越大，对应频率越高。$k = N/2$ 对应奈奎斯特频率 $\omega = \pi$。这层「频域采样」的视角，是理解频率分辨率的钥匙。</span>

**DFT 隐含周期性**。$X[k]$ 对 $k$ 以 $N$ 为周期（因为 $W_N^{k+N} = W_N^{k}$），于是可把 $X[k]$ 看成周期为 $N$ 的序列；同理，IDFT 恢复出的 $x[n]$ 也应理解为**周期为 $N$ 的周期序列的一个周期**。这正是下一章圆周卷积里「信号在圆周上排列」观念的来源。

### 矩阵形式

DFT 可以写成矩阵乘法：

$$\mathbf{X} = \mathbf{W}\,\mathbf{x}, \qquad \mathbf{W}_{kn} = W_N^{kn}, \quad \mathbf{W}^{-1} = \tfrac{1}{N}\mathbf{W}^{*}$$

$\mathbf{W}$ 是 $N\times N$ 的**DFT 矩阵**，其行向量彼此正交——DFT 本质是一次**酉变换**（差一个归一化因子）。<span class="marginnote">矩阵视角让 DFT 成为线性代数里的一员：它是一次「把信号从时间基换到频率基」的坐标变换。FFT 之所以快，就是因为它利用了 $\mathbf{W}$ 矩阵的结构（可分解性），而不是直接做 $N^2$ 次乘法。</span>

## 2 DFT 的性质

DFT 的性质与 DTFT 大体平行，但多了一条必须时刻记住的差别：**DFT 的一切运算都在「模 $N$」的意义下进行**——移位是圆周移位，卷积是圆周卷积。

**圆周移位（circular shift）**：$x[(n-m))_N]$ 表示把 $x[n]$ 在长度为 $N$ 的圆周上整体旋转 $m$ 步，溢出的一端绕回另一端。

$$x[n-m \bmod N] \quad\Longleftrightarrow\quad W_N^{km} X[k]$$

**圆周卷积（circular convolution）**：两个长度 $N$ 序列的圆周卷积定义为

$$x_1[n] \circledast x_2[n] = \sum_{m=0}^{N-1} x_1[m]\, x_2[(n-m))_N]$$

**圆周卷积定理**：圆周卷积 $\iff$ DFT 逐点相乘。

$$x_1[n] \circledast x_2[n] \quad\Longleftrightarrow\quad X_1[k]\cdot X_2[k]$$

**辨析｜易错点：** 圆周卷积与线性卷积是**两个不同**的运算。普通卷积 $x_1[n] * x_2[n]$ 对应 DTFT 相乘；圆周卷积对应 DFT 相乘。两者只有在序列适当补零后才会相等——**补零正是下一章的主题**。如果不补零直接对两个 $N$ 长序列做「DFT 相乘再 IDFT」，得到的是圆周卷积，两端会「缠绕」污染，这是 DFT 频谱相乘最常见的坑。

其他常用性质：

| 性质 | 时域 | DFT |
| --- | --- | --- |
| 线性 | $ax[n]+by[n]$ | $aX[k]+bY[k]$ |
| 圆周移位 | $x[(n-m))_N]$ | $W_N^{km}X[k]$ |
| 调制 | $W_N^{-ln}x[n]$ | $X[(k-l))_N]$ |
| 圆周卷积 | $x_1[n]\circledast x_2[n]$ | $X_1[k]X_2[k]$ |
| 相乘 | $x_1[n]x_2[n]$ | $\tfrac{1}{N}X_1[k]\circledast X_2[k]$ |
| 帕塞瓦尔 | $\sum_{n}|x[n]|^2$ | $\tfrac{1}{N}\sum_{k}|X[k]|^2$ |
| 共轭对称（实信号） | $x[n]$ 实 | $X[k] = X^{*}[(-k))_N]$ |

**实信号对称性**：对实序列，$X[N-k] = X^{*}[k]$，所以**只需存储/画 $k=0$ 到 $k=N/2$ 的 $N/2+1$ 个频点**，另一半是复共轭镜像。这是所有频谱显示只画一半的根本原因。

## 3 公式解析：频率分辨率与补零

DFT 的一个频点间隔是多少？由 $\omega_k = 2\pi k/N$ 得

$$\Delta\omega = \frac{2\pi}{N} \quad\Longleftrightarrow\quad \Delta f = \frac{f_s}{N}$$

其中 $f_s$ 是采样率。**频率分辨率（frequency resolution）$\Delta f = f_s/N$：相邻两根谱线之间隔着多大的频率。** 三点推论：

- **分辨率只由记录长度 $N$（时长 $NT$）决定，与采样率无关**。想分辨两个靠得很近的频率，必须拉长记录时间 $NT$，而不是提高采样率 $f_s$。
- **补零（zero padding）**：在 $x[n]$ 后面补 $L$ 个零，使长度变为 $M > N$，再做 $M$ 点 DFT。这**不改变分辨率**（频谱本身没变，只是插值得更密了），但让谱线更平滑、峰值定位更准。<span class="marginnote">「补零提高分辨率」是流传最广的误解之一。补零只做插值，两个频率真靠得很近时，补零再多也分不开——必须增加数据时长。这个区分在《利用 DFT 的频谱分析与窗函数》一篇还会用图形重新验证。</span>
- **频谱泄漏**：若序列在窗口内不是周期的整数倍，能量会从一根谱线「漏」到相邻谱线，主瓣变宽。泄漏是截断的固有代价，用窗函数缓解——那也是窗函数一篇的主题。

### 频点与物理频率的换算

$$f_k = \frac{k}{N} f_s, \qquad k = 0, 1, \dots, N-1$$

$k$ 点对应物理频率 $f_k = k f_s / N$。例如 $N=1024$、$f_s = 1024$ Hz，则 $k=256$ 对应 $256$ Hz。<span class="marginnote">这条换算是所有「频谱图横轴」的来源。查谱线时先想清楚 $k$ 与 $f$ 的比例尺，否则极易把第 $k$ 根线当成第 $k$ Hz。</span>

## 4 用 DFT 分析一段有限长的信号

实际分析信号时，手头永远只有一段有限长的数据。假设采样率 $f_s$，取了 $N$ 个样本 $x[0],\dots,x[N-1]$，分析流程是：

1. **直流与去趋势**：减去均值，避免直流分量（$k=0$ 处）淹没低幅信号。
2. **乘窗函数**：如 Hamming 窗，缓解泄漏（详见窗函数一篇）。
3. **做 $N$ 点 DFT**（或补零到 $M$ 点做 $M$ 点 DFT），得到 $X[k]$。
4. **幅度谱**：$|X[k]|$，对实信号取 $k=0..N/2$；工程上常用**幅度平方谱** $|X[k]|^2/N$ 作为功率谱估计。

**辨析｜易错点：** 频谱图的纵轴最常踩坑。$X[k]$ 的模 $|X[k]|$ 比真实正弦幅度大 $N/2$ 倍（能量分摊到正负两根线），除以 $N$ 再乘 2 才能还原正弦幅度；功率谱则要除以 $N$。**画谱前先约定好纵轴的单位（幅度谱还是功率谱，是否归一化）**，否则同一张图可以差出几十倍。

## 5 小结

- **DFT**：$X[k] = \sum_{n=0}^{N-1}x[n]W_N^{kn}$，是 DTFT 在单位圆上 $N$ 个等距频点的采样；IDFT 恢复原序列。
- 矩阵视角：DFT 是一次**酉坐标变换**，$\mathbf{W}$ 矩阵的行向量正交。
- DFT 的运算都在**模 $N$** 下进行：圆周移位、圆周卷积；圆周卷积定理要求 DFT 逐点相乘。
- **频率分辨率 $\Delta f = f_s/N$
