## 为什么讲系统结构

前几篇我们研究的是系统的「外部行为」——$H(z)$、零极点、频率响应。这一篇转向系统的「内部实现」：**同一个差分方程，可以用不同的运算结构来实现**，而结构的选择会实实在在影响三件事——**需要多少乘法器/加法器/延迟单元（成本）**、**对系数量化误差的敏感度（精度）**、以及**中间量的动态范围（噪声）**。<span class="marginnote">这是从「纸上滤波器」到「芯片里的滤波器」的必经之路。你会看到「数学等价」的两种结构，在 16 位定点硬件上跑出天壤之别的性能——结构不是实现细节，它是精度与成本的第一道分水岭。</span>

这一篇讲两种系统：**IIR 结构**（有反馈）与 **FIR 结构**（无反馈），以及它们各自的主流实现形态。

## 1 基本构件与信号流图

任何离散系统都可用三种基本运算搭出来：**加法器、乘法器、延迟单元**（一个单位延迟 $z^{-1}$）。用**信号流图（signal flow graph）** 表示它们，比框图更紧凑：

节点表示信号，支路表示运算，支路增益写在箭头上。
$z^{-1}$ 支路 = 单位延迟；常数支路 = 乘常数；汇聚点 = 求和。

**流图的两条基本操作**——转置与反向——是推导各种等价结构的关键：**把流图所有支路方向反转、交换输入输出，系统函数不变（转置结构）**。<span class="marginnote">转置定理是「免费换结构」的数学依据：转置后的系统 $H'(z) = H(z)$，但数值性质可能完全不同。工程上常取转置结构，因为它有时能改善噪声或延迟。</span>转置还会改变中间节点的延迟分配，因此在并行流水线设计里常常是首选。

三种基本运算的组合自由度，正是「同一系统、无数结构」的根源——$H(z)$ 只约束输入输出关系，不约束内部连法。

## 2 IIR 系统的直接型结构

考虑三阶系统

$$H(z) = \frac{b_0 + b_1 z^{-1} + b_2 z^{-2} + b_3 z^{-3}}{1 + a_1 z^{-1} + a_2 z^{-2} + a_3 z^{-3}}$$

它由「分子多项式（前馈，零点）」与「分母多项式（反馈，极点）」两部分组成。

**直接 I 型（direct form I）**：先把输入过分子（前馈网络），再过分母（反馈网络），是「最忠实于差分方程」的结构。需要 $2N$ 个延迟单元、$2N+1$ 个乘法器。<span class="marginnote">直接 I 型两段串联，直观但「贵」：延迟单元数量翻倍。它还有一个隐患——中间量 $w[n]$ 的幅度可能远大于输入输出，需要更大的动态范围。</span>

**直接 II 型（direct form II）**：利用「两级线性系统可交换」，把反馈网络挪到前头，两段**共享同一串延迟单元**：

先算递归部分：$w[n] = x[n] - a_1 w[n-1] - a_2 w[n-2] - a_3 w[n-3]$
再算前馈部分：$y[n] = b_0 w[n] + b_1 w[n-1] + b_2 w[n-2] + b_3 w[n-3]$

只用一个 $w$ 数组，延迟单元从 $2N$ 减到 $N$。<span class="marginnote">直接 II 型的代价是那个「共享延迟」的巧妙背后，$w[n]$ 的动态范围问题依然存在，且对系数扰动更敏感——它省了硬件，却把精度风险集中起来。</span>

**转置直接 II 型**：对直接 II 型做转置，得到**转置直接 II 型（transposed direct form II）**，信号流方向反转、输入在右输出在左。它在实践中特别常见——每级乘法后立刻累加，舍入误差更分散，常常具有更好的数值行为。

**辨析｜易错点：** 直接型虽然直观，却有致命的数值弱点：**高阶直接型对系数量化误差极其敏感**。一个四阶以上直接型滤波器，系数只要舍入到 16 位，极点位置就可能大幅漂移甚至越过单位圆失稳。这不是「实现得不够小心」，而是结构本身的病——下一节的高阶分解就是为了治这个病。

## 3 级联与并联结构：把大系统拆小

治疗「高阶直接型敏感」的通用药方，是**把高阶系统分解成低阶系统的组合**。二阶是黄金单元，因为二阶极点可写成共轭对，能直接用实系数实现。

### 级联型

把 $H(z)$ 因式分解成二阶子系统之积：

$$H(z) = b_0 \prod_{k=1}^{K} \frac{1 + \beta_{1k} z^{-1} + \beta_{2k} z^{-2}}{1 + \alpha_{1k} z^{-1} + \alpha_{2k} z^{-2}}$$

每级是一个（可直接 II 型实现的）二阶节，级联起来。<span class="marginnote">级联型把「一个大系统」变成「一串小系统」，每个二阶节的极点只依赖 2 个系数，量化误差的影响被局部化——某个节系数偏了，只扰动它自己的那对极点，不会波及其他。这是它敏感度低的原因。</span>

### 并联型

把 $H(z)$ 做部分分式展开，分解成二阶子系统**之和**：

$$H(z) = C + \sum_{k=1}^{K} \frac{e_{0k} + e_{1k} z^{-1}}{1 + \alpha_{1k} z^{-1} + \alpha_{2k} z^{-2}}$$

每级的输出直接相加。<span class="marginnote">级联 vs 并联是「乘法分解 vs 加法分解」：级联里各级依次处理，并联里各级独立处理再求和。级联天然保留零极点成对的几何直觉，并联则把各级贡献孤立开——后者在「并行加速」与「单独观测某对极点」时更有用。</span>

### 为什么二阶节足够

三阶以上的实系数多项式必有实根或复共轭对，任何实数滤波器都能分解成「一阶节 × 二阶节」；而二阶节是复共轭对的最小实系数载体。**所以「级联/并联二阶节」是普适的规范化实现**——几乎所有商用滤波器库都是这么做的。

## 4 FIR 系统的结构

FIR 系统 $H(z) = \sum_{m=0}^{M} b_m z^{-m}$ 无反馈，结构比 IIR 更简单，但仍有讲究。

**直接型**：$y[n] = \sum_{m=0}^{M} b_m x[n-m]$，一串延迟 + 抽头加权 + 累加，就是「横向/抽头延迟线结构」——这是 FIR 的经典形态，也是 FIR 名字「有限脉冲响应」的直观来源。<span class="marginnote">横向结构在 DSP 芯片里有专门的硬件原语（MAC，乘累加单元）：一拍内完成「乘 + 累加」，$M+1$ 个抽头一拍一个。FIR 之所以「便宜」，是因为这种结构高度规整、适合流水线。</span>

**级联型**：把 $H(z)$ 因式分解为二阶节的乘积，适合需要精确零点控制的场合（如陷波器组）。

**线性相位结构**：线性相位 FIR 的脉冲响应关于中心对称 $h[n] = \pm h[M-n]$，可以把对称的抽头先相加再乘一个系数，乘法器数量**减半**：

$$y[n] = \sum_{m=0}^{\lfloor M/2 \rfloor} h[m]\, \big(x[n-m] \pm x[n-M+m]\big)$$

**频率采样型**：利用 $H(z)$ 在 DFT 频点上的值 $H[k]$ 直接构造结构——每根谱线一个谐振器并联，适合频谱直接给定的场合（如声码器）。<span class="marginnote">频率采样结构把「给出 $H[k]$」翻译成「搭一堆谐振器」，但代价是零极点都在单位圆上、数值敏感。它更像概念演示，实际设计常退化为更稳的结构。</span>

## 5 格型结构：从谱估计到语音编码

**格型（lattice）结构**是另一族实现：用递推地「反射系数」而非直接系数描述滤波器。二阶级联的每个反射系数 $\kappa_m$ 对应一个格型节：

$$f_{m}[n] = f_{m-1}[n] + \kappa_m g_{m-1}[n-1], \qquad g_{m}[n] = \kappa_m f_{m-1}[n] + g_{m-1}[n-1]$$

格型结构有三个独到优点：**稳定判定容易**（全部 $|\kappa_m| \lt  1$ 即稳定）、**系数对量化不敏感**、**能同时给出前向与后向预测误差**——最后一个优点让它成为**线性预测（LPC）**与语音编码的核心结构。<span class="marginnote">格型与「反射系数」直接对应声学里的声管反射——这正是语音编码（如 LPC-10、CELP）用它的物理原因：声道被建模成一组声管，反射系数就是格型的 $\kappa_m$。从滤波器结构到语音的生物学，只隔了一层格型。</span>

## 6 公式解析：为什么二阶节级联对量化更稳

用一个数值思想实验说明「结构选择为什么关乎精度」。

- **第一步**：设一个四阶系统，极点为 $p_{1,2} = 0.9\mathrm{e}^{\pm\mathrm{j}\theta_1}$、$p_{3,4} = 0.95\mathrm{e}^{\pm\mathrm{j}\theta_2}$。直接 II 型用一个分母多项式 $A(z) = \prod(1-p_k z^{-1})$，系数是四个极点展开的**四次多项式系数**。
- **第二步**：把系数量化到 $B$ 位。直接型的每个系数都混合了全部四个极点的信息，一个系数的舍入误差会同时扰动全部四个极点——**误差被四倍放大**，高阶系统尤其如此。
- **第三步**：改级联型。每个二阶节只含一对极点，其系数 $(\alpha_{1k}, \alpha_{2k})$
