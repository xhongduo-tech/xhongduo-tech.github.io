## 为什么从离散时间信号开始

数字信号处理（DSP）的全部工作，都建立在一个前提之上：**你手里的数据是「一串数」，而不是「一条连续的曲线」。** 手机里的语音、照片里的像素、传感器里每秒几千次的读数——它们在被计算机处理之前，都已经被一个叫 **ADC（模数转换器）** 的装置切成了离散的点。这一篇回答的就是 DSP 的第一个问题：**给出一串数，我们如何描述它、如何研究一个「系统」对它的作用？** 这套语言与上一级《信号与系统》里的连续时间语言几乎一一对应，但处处藏着离散独有的微妙之处——正是这些微妙之处，构成了后续 DFT、z 变换与滤波器设计全部技术的出发点。

## 1 离散时间信号：一串带序号的数

**离散时间信号（discrete-time signal）**：定义在整数集合上的函数 $x[n]$，其中方括号里的 $n$ 是**时间序号（sample index）**，$x[n]$ 是在该序号处信号的取值。<span class="marginnote">约定俗成：连续时间信号用圆括号 $x(t)$，离散时间信号用方括号 $x[n]$。看见方括号，就知道自变量只能取整数值，这是全书约定。</span>

这一定义有三个要点值得先立住：

**它来源于「采样」**。对连续信号 $x(t)$ 按等间隔 $T$ 取点，就得到 $x[n] = x(nT)$，$T$ 叫**采样间隔**，$f_s = 1/T$ 叫**采样率**。离散信号是真实世界的投影，而「投影丢失了什么、保留了什么」是后面《连续时间信号的采样与重建》一篇的主题。

**它只定义在整数上**。$x[1.5]$ 没有意义；$n$ 从 $-\infty$ 到 $+\infty$，既可以是有限的记录（长度为 $N$ 的序列），也可以是无限长的序列。

**它可以是任意数的序列**。$x[n]$ 的取值不限于实数——复信号在 DSP 中极其常见，例如 $\mathrm{e}^{\,\mathrm{j}\omega n}$ 形式的复指数。<span class="marginnote">为什么研究复信号？因为<strong>一个实正弦可以写成两个复指数的和</strong>：$\cos(\omega n) = \tfrac12(\mathrm{e}^{\,\mathrm{j}\omega n} + \mathrm{e}^{-\mathrm{j}\omega n})$。把实信号拆成复指数来研究，是频域分析一切运算便利的来源。</span>

### 常用基本序列

DSP 的整个工具箱建立在几个基本序列之上，它们等价于连续世界里冲激、阶跃、正弦这些「积木」：

| 名称 | 表达式 | 直观意义 |
| --- | --- | --- |
| 单位脉冲 $\delta[n]$ | $1\ (n=0)$，否则 $0$ | 只在 $n=0$ 处有一个值，是离散世界的「冲激」 |
| 单位阶跃 $u[n]$ | $1\ (n\ge 0)$，否则 $0$ | 从 $n=0$ 起一直是 $1$，是离散世界的「开关」 |
| 实指数 $a^{n}u[n]$ | 幂函数乘阶跃 | 衰减（$|a|\lt 1$）或增长（$|a|>1$） |
| 正弦 $A\cos(\omega_0 n + \phi)$ | 余弦函数 | 数字频率 $\omega_0$ 的单位是 rad/sample |
| 复指数 $\mathrm{e}^{\,\mathrm{j}\omega_0 n}$ | 单位圆上的旋转 | 频域分析的主角 |

一个贯穿全书的关系是 $\delta[n]$ 与 $u[n]$ 互相表达：

$$u[n] = \sum_{k=-\infty}^{n} \delta[k], \qquad \delta[n] = u[n] - u[n-1]$$

**单位脉冲是「把任意序列拆开的工具」**：任意序列都可以写成移位单位脉冲的加权和，

$$x[n] = \sum_{k=-\infty}^{\infty} x[k]\,\delta[n-k]$$

这个式子叫**移位冲激的分解（sifting property）**，它本身极其平凡，却是下一节卷积定义的直接来源——**系统如何作用，完全由它如何响应 $\delta[n]$ 决定**，这就是卷积思想的萌芽。

### 离散频率的周期性

离散正弦有一个与连续正弦本质不同的性质：**离散频率只在 $2\pi$ 内有意义**。观察

$$\cos\big((\omega_0 + 2\pi)n\big) = \cos(\omega_0 n)$$

因为 $n$ 是整数，频率加上 $2\pi$ 后信号完全相同。这意味着**高频 $\omega_0$ 与 $\omega_0 + 2\pi$ 无法区分**，频率轴被「卷」成一个圆周。低频在 $\omega$ 靠近 0 处，高频在 $\omega$ 靠近 $\pi$（即靠近 $\pm\pi$，两者等价）处。<span class="marginnote">「频率是圆周的」是离散世界的第一次世界观冲击。它直接导致采样定理（频率混叠）与 DFT 的圆周移位——后续每一章都会回来重访这个事实。</span>

## 2 离散时间系统

**离散时间系统（discrete-time system）**：把输入序列 $x[n]$ 变换为输出序列 $y[n]$ 的映射，记作 $y[n] = \mathcal{T}\{x[n]\}$。<span class="marginnote">「系统 = 变换」这句话看似平淡，却把数学里的「函数作用于序列」与工程里的「滤波器作用于信号」统一了起来。我们研究的不是某个具体电路，而是任意满足某些性质的变换。</span>

与连续系统一样，离散系统有四条基本性质，考试与工程判断都靠它们：

**线性（linearity）**：若 $x_1[n] \to y_1[n]$、$x_2[n] \to y_2[n]$，则对任意常数 $a, b$ 有 $a x_1[n] + b x_2[n] \to a y_1[n] + b y_2[n]$。即**叠加原理**成立：响应之和等于各自响应的和，缩放可进出系统。

**时不变（time-invariance）**：若 $x[n] \to y[n]$，则对任意整数 $n_0$ 有 $x[n-n_0] \to y[n-n_0]$。即**输入延迟多少，输出就延迟多少**，系统的行为不随时间推移而改变。

**因果性（causality）**：$y[n]$ 只依赖于 $n$ 时刻及以前的输入 $x[n], x[n-1], \dots$。一个因果系统不能「预知未来」——这是所有实时处理系统的硬约束。

**稳定性（stability，BIBO）**：有界输入必有有界输出。即若 $|x[n]| \le B_x$ 恒成立，则存在有限 $B_y$ 使 $|y[n]| \le B_y$。<span class="marginnote">稳定性是最容易被忽略却最致命的性质：一个不稳定的数字滤波器，在工程上等价于「输出在几微秒内爆到无穷大」，直接烧毁下游。稳定性判据在系统响应一节给出，并在 z 变换一章用极点位置重新表述。</span>

## 3 线性时不变系统与卷积

同时满足**线性**与**时不变**的系统叫 **LTI 系统（linear time-invariant system）**。LTI 系统是整个 DSP 的主体研究对象——原因极其简单：**LTI 系统对任意输入的响应，都可以由它对单位脉冲的响应完全决定。**

设 $h[n]$ 是系统对 $\delta[n]$ 的响应，即**单位脉冲响应（impulse response）**。利用移位冲激分解与线性、时不变性：

$$y[n] = \mathcal{T}\Big\{\sum_k x[k]\,\delta[n-k]\Big\} = \sum_k x[k]\,\mathcal{T}\{\delta[n-k]\} = \sum_k x[k]\, h[n-k]$$

这个式子就是**卷积和（convolution sum）**：

$$\boxed{\;y[n] = \sum_{k=-\infty}^{\infty} x[k]\, h[n-k] = x[n] * h[n]\;}$$

卷积的计算可以这样直观理解：**把 $h[k]$ 翻转成 $h[-k]$，再平移 $n$ 得到 $h[n-k]$，与 $x[k]$ 逐点相乘求和，得到 $y[n]$。** 每给定一个输出时刻 $n$，就做一次「翻转—平移—乘—和」的完整操作。

卷积的性质值得记牢：

- **交换律**：$x[n] * h[n] = h[n] * x[n]$
- **结合律**：$x * (h_1 * h_2) = (x * h_1) * h_2$——级联系统的次序无关
- **分配律**：$x * (h_1 + h_2) = x * h_1 + x * h_2$——并联系统可相加

这些性质使「两个 LTI 系统级联」可以合并成一个系统，其脉冲响应为 $h_1[n] * h_2[n]$；并联则可相加。<span class="marginnote">把复杂的滤波器网络折叠成单个脉冲响应，是「系统结构」一章所有化简工作的理论依据——也是你后面学 FIR/IIR 结构时反复使用的规律。</span>

## 4 公式解析：LTI 系统的性质用脉冲响应刻画

**LTI 系统的一切性质，都能翻译成对 $h[n]$ 的约束。** 这是本节最值得沉淀的一句话。展开如下：

- **第一步，因果性**：$y[n]$ 不能用到未来的输入。由于 $y[n] = \sum_k x[k]h[n-k]$，当 $k > n$ 时求和项含 $x[k]$（未来输入），要让这些项消失，必须 $h[n-k] = 0$ 对 $k>n$ 恒成立，等价于 $h[m] = 0$ 对 $m \lt  0$。**因果 $\iff$ $h[n]=0\ (n\lt 0)$**。
- **第二步，稳定性**：对 $|x[n]| \le B_x$，有 $|y[n]| \le B_x \sum_k |h[k]|$。要使 $y[n]$ 恒有界，必须 $h[n]$ **绝对可和**：$\sum_{n=-\infty}^{\infty} |h[n]| \lt  \infty$。
- **第三步，响应分解**：在因果且稳定时，输出可写成

$$y[n] = \sum_{k=-\infty}^{n} x[k]\,h[n-k]$$

求和上限从 $+\infty$ 降到 $n$，因为 $k>n$ 的项全是零——计算量由此省下一半，这也是教材里「可计算卷积」的标准形式。

**辨析｜易错点：** 判定系统性质时，最容易犯两类错。其一，**只看差分方程不看初值**——例如 $y[n] = x[n] + y[n-1]$ 需要指定 $y[-1]$ 才是一个确定的系统，差分方程本身描述的是一族系统。其二，**把「有界输入有界输出」当成「输入衰减输出就衰减」**——稳定性是绝对可和的全局性质，个别输入的衰减说明不了任何问题。

## 5 差分方程：LTI 系统的工程表达

理论上的卷积 $y[n] = x[n] * h[n]$ 是「全知道 $h[n]$ 才能算」，工程上我们更常用**常系数线性差分方程（LCCDE）**描述系统：

$$\sum_{k=0}^{N} a_k\, y[n-k] = \sum_{m=0}^{M} b_m\, x[n-m]$$

其中 $a_0$ 通常归一化为 1。<span class="marginnote">差分方程与微分方程的地位完全平行：微分方程描述连续系统，差分方程描述离散系统。两者的求解框架——通解 + 特解、零输入 + 零状态——也一一对应。</span>

这个方程看起来只是卷积的另一种写法，但有几个重要含义：

- 当 $N=0$（只有 $y[n]$ 自身）时，$y[n] = \sum_m b_m x[n-m]$ 是输入序列的**有限加权滑动平均**，输出只依赖有限个输入——这类系统叫 **FIR（有限脉冲响应）**，$h[n]$ 只有有限个非零值。
- 当 $N \ge 1$ 时，输出依赖过去的输出，脉冲响应一般是无限长的——这类系统叫 **IIR（无限脉冲响应）**。IIR 的反馈结构使它更「高效」，但也带来稳定性问题，这正是第 6 章系统结构要专门处理的。

**差分方程 + 零初始条件**，可以逐点递推求出输出；也可以用 z 变换把差分方程变成代数方程一次解出——那是《z 变换》一篇的入口。这里先立住递推的思想：**把「系统作用」理解成一个可逐拍执行的递归过程**，这是数字滤波器真正在 DSP 芯片里运行的形态。

## 6 小结

- 离散时间信号 $x[n]$ 定义在整数上，来源于对连续信号的**采样**；常用基本序列有 $\delta[n]$、$u[n]$、实指数、正弦与复指数。
- 离散频率**以 $2\pi$ 为周期**，频率轴是圆周——这是离散世界与连续世界的根本差异。
- 系统有**线性、时不变、因果、稳定**四条性质；同时满足前两条即 **LTI 系统**。
- LTI 系统完全由**单位脉冲响应 $h[n]$** 描述，输出是**卷积和** $y[n] = x[n] * h[n]$。
- 因果性 $\iff h[n]=0\ (n\lt 0)$；稳定性 $\iff \sum|h[n]| \lt  \infty$。
- 工程上系统常用**常系数线性差分方程**表达，$N=0$ 为 FIR，$N\ge 1$
