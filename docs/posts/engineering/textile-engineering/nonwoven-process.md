## 为什么非织造布「不讲规矩」

机织物要纱线交织、针织物要线圈串套——都离不开「先纺纱、再成布」的漫长工序。
**非织造布
（nonwoven）**干脆跳过纺纱：**把纤维直接铺成网，
再用机械或化学方法固结成「布
」**。它牺牲了结构的规则性，换来**极短的生产流程、
极高的产量与极低的成本**——口罩
、纸尿裤、过滤材料、土工布、擦布全是它的天下。非织造是纺织「最短路径」的极致，
也是高分子
加工与纺织的交叉前沿。

## 1 非织造的两大工艺：成网 + 固结

非织造布的工艺本质只有两步：**成网（web
formation）**把纤维铺成均匀的纤维网，**固结（bonding）
**把纤维网变
成有强力的布。

### 成网方法

-
  **干法成网**：以短纤维为原料。**梳理成网**（梳理机把纤维梳成平行纤维网，
  再交叉铺网调节各向同性）与**气流成网**（气流把纤维吹散沉降成网，
  纤维取向随机、蓬松）。
-
  **湿法成网**：纤维悬浮于水中，滤网捞取成网——适合短纤维与特种纤维，
  抄纸的亲戚。
-
  **聚合物直接成网**：把聚合物熔体直接纺丝铺网，一步到位——
  **纺粘（spunbond）**与**熔喷（meltblown）**。
  <span class="marginnote">纺粘与熔喷是「从粒子到布」的极致：
  聚合物切片熔融挤出，经喷丝孔喷出，热气流牵伸成极细长丝，铺到成网帘上成网——
  没有传统纺纱的牵伸加捻，全凭「挤出 +
  气流拉伸」。这就是口罩核心滤材熔喷布的来历。</span>

### 固结方法

- **机械固结**：**针刺（needle
  punching）**——带钩刺的针反复穿刺纤维网，把纤维机械缠结；
  **水刺（spunlace）**——高压水针穿刺纤维网，纤维缠绕固结，
  产品柔软（湿巾）。
- **化学粘合**：喷洒或浸渍粘合剂（乳液），烘干后纤维被粘接。
- **热粘合**：混入热熔纤维（如 PE/PP
  双组分纤维），加热使低熔点组分熔融粘接；**热轧**用热压辊点状粘合。

## 2 纺粘与熔喷：口罩滤材的两兄弟

**纺粘法**：聚合物熔体从喷丝孔挤出成丝，热气流牵伸、冷却固化，
铺网后热轧加固。丝较粗（十几微米以上），布强度高、成本低，作骨架层。

**熔喷法**：熔体挤出后，**高速高温气流**把丝急剧牵伸变细（可达 1–5
μm，甚至亚微米），并以极短距离沉降成网，纤维细、比表面积大、蓬松，
靠纤维间的**自身热粘合**固结。熔喷布的过滤、吸附性能极佳，但强度低——
所以口罩用**SMS
复合结构**：纺粘（S）在外提供强度，熔喷（M）在中间提供过滤，热压复合。

<span class="marginnote">SMS 是「骨架 +
滤芯」的分工：两层纺粘像书皮保护脆弱的熔喷芯。口罩过滤靠三层机制——
机械拦截（孔径过滤）
、惯性撞击（纤维弯曲使颗粒撞上纤维）、静电吸附（熔喷驻极处理带电）——
静电吸附是熔喷布效
率远超孔径过滤的关键，N95 的 N 就是指对 0.3 μm 氯化钠颗粒过滤
≥95%。</span>

## 3 非织造布的性能与应用

非织造布的性能由「成网 +
固结」共同决定：纤维细、网蓬松、孔隙多则柔软透气、吸附过滤好；但纤维排列无序、
无规则结构
，强度与保形性一般低于机织/针织。

典型应用谱：

| 领域 | 代表产品 | 关键性能 |
| --- | --- | --- |
| 医疗卫生 | 口罩、手术衣、防护服、敷料 | 过滤、阻隔、透湿、无菌 |
| 卫生用品 | 纸尿裤、卫生巾 | 吸收、柔软、导流 |
| 过滤 | 空气滤芯、水滤袋、油滤 | 过滤效率、容尘量 |
| 土工建筑 | 土工布、防水卷材基材 | 强度、渗透、耐久 |
| 农业园艺 | 育秧布、防草布、保温被 | 透水透气、抗紫外 |
| 汽车 | 顶棚、隔音毡、滤清器 | 隔音、隔热、成型性 |

## 4 公式解析：纤维网孔隙率

过滤、透湿与柔软都与纤网的**孔隙率** $\varepsilon$ 密切相关：

$$
\varepsilon = 1 - \frac{\rho_f}{\rho_p}
$$

其中 $\rho_f$ 是纤网的表观密度，$\rho_p$
是纤维材料本身的密度（如
PP 约 0.91 g/cm³）。纤网表观密度 $\rho_f =
\frac{G}{t}$，$G$ 是克重（g/m²），$t$
是厚度（m）。逐项拆解：

- **第一步，表观密度**：把纤网整体当「多孔体」，其密度 = 克重 ÷
  厚度——远小于纤维本身密度，因为网里全是空气。
- **第二步，孔隙率的定义**：$\varepsilon$ =
  空气体积占总体积的比例 = 1
  −（纤维实体体积占比）。$\rho_f/\rho_p$ 正是纤维实体体积占比。
- **第三步，读工艺含义**：$\varepsilon$ 大（蓬松）→
  透气好、容尘量大、柔软；$\varepsilon$ 小（压实）→
  阻隔性好但透气差。熔喷布要「细纤维 +
  高孔隙率」：纤维细，孔隙虽多但孔道曲折，颗粒难穿透——
  **孔隙率高与过滤效率高并不矛盾**，靠的是细纤维织成的迷宫。

**辨析｜易错点：** 孔隙率高 ≠
过滤效率低。过滤不是简单筛子：细纤维网的孔道细小曲折，
颗粒在穿越中不断撞击纤维被拦截（惯性、扩散、静电共同作用）。熔喷布孔隙率高达
80% 以上，过滤效率却能达到 N95
级——「孔多」与「滤得净」在细纤维结构下可以兼得。

## 5 小结

- 非织造布 = **成网 +
  固结**两步：成网分干法/湿法/聚合物直接成网，固结分机械/化学/热粘合。
- **纺粘**丝粗强度高作骨架，**熔喷**丝极细过滤强作滤芯，**SMS
  复合**是口罩滤材的标准结构。
-
  性能画像：**流程短、成本低、过滤吸附好**，但强度与保形性一般，
  多用于一次性与产业用。
- **孔隙率** $\varepsilon = 1 -
  \rho_f/\rho_p$ 决定透气与过滤的平衡；细纤维 +
  高孔隙率可兼得过滤效率。
- 非织造是「纤维直接成布」的最短路径，也是口罩等医疗防护材料的技术根基。
