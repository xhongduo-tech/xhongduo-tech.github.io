## 为什么染整是纺织环保的主战场

纺织全产业链中，染整是**水耗、能耗与化学品负荷**最集中的环节：
前处理的碱与浆料、染色
的盐与染料、整理的树脂与助剂，最终大量进入废水。
**生态染整（ecological
dyeing and
finishing）**研究两件事：一是**把污染在源头减下来**（清洁生产），
二是**
把废水废气处理达标**（末端治理），
同时用**环保认证**与**有害物质管控**守住消费
者安全的底线。它把前面《浆纱》的
PVA、《整理》的甲醛、《印花》的浆料等所有「环保伏笔」汇成一条主线。

## 1 印染废水：污染的家底

印染废水是工业废水的重点治理对象，特征指标：

-
  **COD（化学需氧量）**：氧化水中还原性污染物（有机物）所需氧量——
  有机物污染的「总量表」。PVA 浆料、染料、助剂都是高 COD 来源。
-
  **BOD（生化需氧量）**：微生物分解有机物耗氧量——反映可生化性。
  BOD/COD 比值低说明废水「难生化」（PVA、染料难降解）。
- **色度**：染料的颜色污染，即使 COD
  不高，色度也超标——色度是印染废水最直观的特征。
- **重金属与
  AOX**：含金属络合染料（铬、铜）、
  含卤素的漂白/整理剂产生的可吸附有机卤化物。
- **pH、SS（悬浮物）、氨氮**等常规指标。

<span class="marginnote">COD 与 BOD
的比值是处理工艺选型的罗盘：BOD/COD > 0.3
左右废水「可生化」，用微生物分解划算；比值低则要先物化预处理（混凝沉淀）再生化。
PVA
浆料、活性染料这类难降解有机物，恰恰把比值拉低——所以《浆纱》一章的无 PVA
浆纱，从源头就在救废水。</span>

## 2 废水处理流程：三级处理

印染废水处理是「物化 + 生化 + 深度」的组合：

- **一级（物化）**：格栅除渣 → 调节池均质 →
  **混凝沉淀/气浮**——加混凝剂（聚合氯化铝等）让悬浮物、胶体、
  部分染料絮凝沉降，脱色去悬浮物。
- **二级（生化）**：**厌氧 + 好氧**生物处理（如 A/O
  工艺）——厌氧水解把难降解大分子「开环断链」提高可生化性，
  好氧微生物把有机物氧化成 CO₂ 和水。这是去除 COD 的主力。
-
  **三级（深度）**：**臭氧氧化、活性炭吸附、膜分离（超滤/反渗透）**——
  进一步脱色、去残余 COD，部分废水回用。

染料脱色是印染废水特有的难题：活性染料、酸性染料水溶性好、色度深且难生化，
常需专门的脱色
环节（混凝、臭氧、吸附）。

## 3 清洁生产：从源头减污

末端治理是「治已病」，清洁生产是「治未病」——在工艺源头少用水、少耗能、
少用化学品：

- **节水**：**低浴比染色**（溢流→气流染色，浴比从 1:10 降到
  1:3 甚至更低，浴比 =
  染液体积/织物质量）、**冷轧堆染色**（室温堆置固色，省蒸汽）、
  数码印花（省浆省水）。
- **节能**：低温染色、湿短蒸（低给液短蒸固色）、热回收。
-
  **少化学品**：**无盐/低盐染色**（活性染料用代用盐或阳离子改性棉，
  省去大量盐）、**无甲醛整理**（《整理》章的无甲醛交联剂）、**无 PVA
  浆纱**（《浆纱》章）、**清洁染料**（高固色率活性染料，减少染料进入废水）。
  <span class="marginnote">「无盐染色」是源头减污的典型案例：
  传统活性染棉每公斤布要用 60–100 g
  盐促染，盐随废水排出提高水体盐度、破坏生态。替代思路一是开发高亲和染料少加盐，
  二是对棉进行阳离子改性（让阴离子染料直接静电吸上去）——从机理上绕过「盐促染」。
  </span>

## 4 公式解析：污染物去除率

评价废水处理（或任一治理环节）效果，用**去除率** $\eta$：

$$
\eta = \frac{C_0 - C_e}{C_0} \times 100\%
$$

其中 $C_0$ 是进水（或处理前）浓度，$C_e$
是出水（或处理后）浓度。逐项拆解：

- **第一步，分子是去除量**：$C_0 - C_e$
  为处理前后浓度差，即被去除的污染物量。
- **第二步，归一化**：除以进水浓度，得到「去除了百分之多少」。COD
  去除率、色度去除率、BOD 去除率各算各的——不同指标要分别考核。
- **第三步，看达标逻辑**：排放标准规定的是**出水浓度**（如 COD
  ≤ 80
  mg/L）而非去除率。同一去除率下，进水浓度高的厂出水未必达标——
  所以既要看去除率（工艺效率），也要看出水浓度（是否合规）。

**辨析｜易错点：** 去除率高 ≠ 一定达标。一个「COD 去除率
95%」很漂亮的工艺，若进水 COD 高达 10000 mg/L，出水仍有
500 mg/L——超标的。评价治理水平必须「**去除率 + 出水浓度 +
排放标准**」三者同看，只看比例是自欺欺人。

## 5 有害物质管控与环保认证

生态染整的另一半是**产品安全**：纺织品中残留的有害物质要控制在限量内。

重点管控对象：

-
  **禁用偶氮染料**：部分偶氮染料在还原条件下会裂解出**致癌芳香胺**——
  欧盟与中国均立法禁用，检测靠「裂解-色谱法」筛查。
- **甲醛**：免烫整理的 2D 树脂残留（《整理》章），按
  OEKO-TEX 四类产品分级限量。
- **重金属、致敏染料、邻苯二甲酸酯、PFOS/PFOA、APEO** 等。

主流认证体系：

| 认证 | 定位 |
| --- | --- |
| OEKO-TEX® Standard 100 | 纺织品有害物质检测认证，最通行 |
| GOTS | 有机棉纺织品全链认证（有机 + 环保 + 社会责任） |
| bluesign® | 供应链化学品管理，从源头管控投入品 |
| 中国环境标志 | 国产生态纺织品认证 |

<span class="marginnote">OEKO-TEX
的四类分级体现「接触风险分级」：I 类婴幼儿（最严）、II
类直接接触皮肤、III
类不直接接触、IV 类装饰材料。同样是甲醛限量，婴幼儿类 16 mg/kg
而装饰类
300
mg/kg——限量随接触风险放松，这是「风险评估」思维在标准中的落地。
</span>

## 6 循环与未来

生态染整的远景是**循环经济**：

-
  **再生纤维**：废旧纺织品回收再生（物理回收开松重纺、化学回收解聚再聚合），
  减少原生纤维需求。
-
  **染液回用与废水回用**：膜处理后的水回用于前处理，染液（如靛蓝）回收再用。
- **可降解染料与生物基助剂**：开发可生物降解的染料助剂，降低末端压力。

循环染整让「纺织-染整-废弃」的线性链，变成「回收-再生-再染」的闭环。

## 7 小结

- 印染废水特征：**高 COD、高色度、难生化**（PVA、染料）；指标看
  COD、BOD、色度、重金属、AOX。
- 治理是三级流程：**物化（混凝脱色）→ 生化（厌氧好氧去 COD）→
  深度（臭氧/膜/吸附）**。
- 清洁生产从源头减污：**低浴比、冷轧堆、无盐染色、无甲醛、无 PVA
  浆纱**。
- **去除率** $\eta = (C_0 - C_e)/C_0$
  与出水浓度、排放标准必须三看。
- 安全靠**有害物质管控 + OEKO-TEX/GOTS/bluesign
  认证**；未来走向**循环染整**。
