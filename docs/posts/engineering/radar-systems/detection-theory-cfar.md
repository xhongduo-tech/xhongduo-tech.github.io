# 检测理论（CFAR 与检测概率）

<div class="epigraph">
<p>检测的本质是一个二选一：**有目标，还是没有目标**。噪声永远在，阈值必须自己站稳——这正是恒虚警（CFAR）要解决的问题。</p>

## 为什么从检测理论讲起

前四篇我们学会了「如何得到回波」（雷达方程）、「如何看穿一个脉冲」（匹配滤波）、「如何分辨动与静」（多普勒）、「如何对付杂波」（杂波模型）。但所有处理最终都要落到一个决定上：**这个幅度到底算不算目标？** 阈值定低了，噪声尖峰满天飞假目标；阈值定高了，真目标被放过。更麻烦的是背景强度会变——雨天杂波大、晴天空旷、敌方干扰一开，固定的阈值立刻失效。这一篇讲的 CFAR（恒虚警）技术，就是雷达界的「自动调阈值」：让虚警率在千变万化的背景中保持恒定，同时尽量不漏真目标。它是第3篇多普勒、第4篇杂波之后，把「检测」做成一门工程学问的关键一环，也是连接探测与跟踪（第8篇）的桥梁。

从「极限到大模型」的主线看，检测理论是「信号与统计」交汇的缩影：第二级《概率论与数理统计》里的假设检验、分布函数，在这里第一次有了硬碰硬的工程对象——一部雷达的检测概率，就是一组统计假设的判决性能。理解了 CFAR，你也同时理解了机器学习的 ROC 曲线、医疗诊断的灵敏度特异度，乃至一切「在噪声里做判断」的系统。

## 1 检测问题的数学骨架：假设检验

雷达检测是一个经典二元假设检验。设接收样本为 $x$，我们面对两个假设：

$$H_0: \text{只有噪声}, \qquad H_1: \text{信号 + 噪声}$$

检测器对每个样本判决「是 $H_1$」（报目标）或「是 $H_0$」（报没有）。两种错误的代价不对等，因此要定义两个量：

**虚警概率 $P_{fa}$**：$H_0$ 成立时误判为 $H_1$ 的概率（噪声过阈值）。预警雷达要求 $P_{fa}$ 低至 $10^{-6}$ 甚至 $10^{-8}$，否则显示器全是假点。
**检测概率 $P_d$**：$H_1$ 成立时正确判为 $H_1$ 的概率（真目标被检出）。作战系统希望 $P_d \ge 0.8\sim0.9$。<span class="marginnote">一句话记忆：$P_d$ 是「不漏真目标」，$P_{fa}$ 是「不认错噪声」。雷达工程师的全部功夫，就是在一个固定的 $P_{fa}$ 约束下把 $P_d$ 推到最高——这就是奈曼-皮尔逊（Neyman-Pearson）准则。</span>

检测器内部还有一个「从检测概率到判决」的工程环节：**门限比较**。匹配滤波 + 包络检波后的每个距离-多普勒单元，与阈值 $V_T$ 比较，过阈记 1、不过记 0，就得到一张「二进制点迹图」。这张图是雷达向跟踪系统交出去的第一份「判决产物」。

对复高斯噪声，匹配滤波输出的幅度服从瑞利分布。设阈值电压为 $V_T$、噪声均方根为 $\psi_0^{1/2}$，则虚警概率有解析式：

$$P_{fa} = e^{-V_T^2 / 2\psi_0}$$

**关键结论：$P_{fa}$ 由「阈值相对噪声的比例」决定**——噪声一变，同样的 $V_T$ 对应完全不同的 $P_{fa}$。这就是为什么固定阈值在实战中行不通。

把 $(P_d, P_{fa})$ 作为阈值从高到低扫一遍，就得到一条**接收机工作特性（receiver operating characteristic, ROC）曲线**：横轴 $P_{fa}$、纵轴 $P_d$。ROC 曲线是检测器性能的「成绩单」——曲线越靠左上（$P_d$ 高、$P_{fa}$ 低），检测器越好；曲线贴着对角线（$P_d = P_{fa}$），检测器等于瞎猜。雷达里 ROC 曲线的用法很直白：给定作战要求的 $P_d$，查曲线得到对应的 $P_{fa}$，再反推出阈值与所需信噪比。<span class="marginnote">ROC 曲线在「从极限到大模型」的知识树上还有一位近亲：机器学习里的「ROC/AUC」就是同一套概念换了名字。二分类模型调阈值、算灵敏度与特异度，本质就是雷达检测概率与虚警概率的翻版——AI 系统评估与雷达检测共享同一份统计遗产。</span>

## 2 检测概率：信噪比与阈值的关系

在固定 $P_{fa}$ 下，检测概率是信噪比的单调函数。对高斯噪声 + 非起伏目标，$P_d$ 与信噪比 $S/N$、阈值的关系由马库姆（Marcum）Q 函数给出。一个便于记忆的近似：对给定 $P_{fa}$，所需的信噪比随 $P_d$ 上升而上升，例如 $P_{fa} = 10^{-6}$ 时，$P_d = 0.5$ 约需 11 dB，$P_d = 0.9$ 约需 13 dB 量级。<span class="marginnote">这是雷达方程里 $(SNR)_{\min}$ 的具体来源：第1篇算探测距离时用的那个 13 dB，背后就是一组具体的 $P_d$ 与 $P_{fa}$ 指标。检测理论把「阈值定多高」变成了「需要多少信噪比」。</span>

**Swerling 起伏模型**把目标 RCS 的随机起伏纳入了统计：Swerling 1/2（慢/快起伏，指数分布）对检测最不利，需要更高的平均信噪比才能达到同样的 $P_d$；Swerling 3/4（一个主散射中心 + 若干小散射中心）介于中间。Skolnik 第5章用一组曲线表给出不同 Swerling 模型下 $P_d$–SNR 的对应，工程上直接查表。

**辨析｜易错点：** 检测概率不是「目标越大越准」。RCS 起伏（Swerling）意味着同一次测量里目标可能「隐身」：在起伏低谷，即使信噪比足够，单脉冲也会漏检。对策是**脉冲积累**（第1篇提过）——把多个独立样本加起来，平均掉起伏低谷。

起伏模型还直接影响波形与扫描策略：Swerling 1（慢起伏）下，相邻脉冲高度相关，必须靠「相隔一个扫描周期」的多次扫描才能获得独立样本；Swerling 2（快起伏）则在脉冲间就独立，单次扫描内积累即可。**选错起伏模型，检测性能的预估会差出好几个 dB**——这是工程里「模型选择」决定成败的典型例子。

一个实用的数量级对照值得背下来（高斯噪声、非起伏目标，$P_{fa} = 10^{-6}$）：

| $P_d$ | 所需单脉冲信噪比（近似） | 直观感受 |
| --- | --- | --- |
| 0.1 | 约 8.5 dB | 勉强露头 |
| 0.5 | 约 11 dB | 半信半疑 |
| 0.9 | 约 13 dB | 工程常用目标 |
| 0.99 | 约 15 dB | 高可靠检测 |

这些数字就是第1篇雷达方程里 $(SNR)_{\min}$ 的「真身」：把要定的 $P_d$、$P_{fa}$ 报给检测理论，它就还你一个需要的信噪比。起伏目标（Swerling）则要在此基础上再加 5–10 dB，取决于模型。

## 3 公式解析：恒虚警（CFAR）怎么自动调阈值

背景强度随时间、距离、方位变化，固定阈值必然失效。**恒虚警（constant false alarm rate, CFAR）**的思路：**用被测单元周围参考单元的幅度，实时估计背景噪声/杂波电平，把阈值设成「估计电平 × 系数」。**

最经典的实现是**单元平均 CFAR（cell-averaging CA-CFAR）**。设被测单元（CUT）两侧各取 $N$ 个参考单元，估计背景电平

$$\hat{P}_n = \frac{1}{2N} \sum_{i=1}^{2N} x_i$$

阈值取 $V_T = \alpha \cdot \hat{P}_n$，其中 $\alpha$ 由目标 $P_{fa}$ 反解。拆解三步：

- **第一步，理解参考窗**：被测单元周围的距离-多普勒单元中，通常只有背景（噪声或均匀杂波）。把这些单元的平均功率当作「当前背景电平」的估计，就自动跟上了背景变化——雨天杂波强，$\hat{P}_n$ 大，阈值跟着抬高。
- **第二步，确定系数 $\alpha$**：对高斯背景，为使虚警概率保持在 $P_{fa}$，$\alpha$ 与参考单元数 $N$ 有关，近似 $\alpha \approx (P_{fa})^{-1/N} - 1$。$N$ 越大，$\alpha$ 估计越稳，代价是参考窗越宽。
- **第三步，判决**：若 $x_{CUT} > \alpha \hat{P}_n$ 则判有目标。**无论背景怎么变，只要它均匀，$P_{fa}$ 就大致恒定——这就是「恒虚警」的含义。**<span class="marginnote">CA-CFAR 的死穴是「掩蔽效应」：当被测单元旁边正好有另一个强目标或强杂波边缘时，参考窗把强回波平均进去，$\hat{P}_n$ 被抬高，把真目标「压」在阈值下漏检。对策有 GO-CFAR（取两侧最大值，保边缘）、OS-CFAR（取排序后第 $k$ 大值，抗多目标）等。</span>

工程实现上，被测单元与参考窗之间还要留出**保护单元（guard cells）**——因为压缩后的目标主瓣会占用几个相邻距离单元，若不跳过，目标自身的能量会污染参考窗估计。这是 CFAR「看起来简单、做起来全是细节」的典型代表。

**四种常见 CFAR 的取舍**：CA-CFAR 在均匀背景最优（损失最小），但抗多目标差；GO-CFAR（greatest-of）保住杂波边缘、牺牲均匀区；OS-CFAR（order statistics）抗多目标强、计算量大；还有 LOG-CFAR 用于对数接收机。工程上根据「背景里有多少别的目标」来选。

一个 CFAR 的数值手感：设参考窗 $2N = 32$ 个单元，目标 $P_{fa} = 10^{-6}$，则 $\alpha \approx (10^{-6})^{-1/32} - 1 = 10^{6/32} - 1 \approx 1.54$。也就是说阈值约为参考单元平均电平的 1.54 倍（约 3.8 dB）。**把阈值订在「平均电平上 4 dB」这个量级，是 CFAR 的直觉锚点**——背景电平一变，阈值跟着变，虚警率才稳得住。<span class="marginnote">再看 CFAR 的代价：参考窗里的样本终究是有限的，估计电平 $\hat{P}_n$ 有起伏，这会造成「CFAR 损失」——达到同样 $P_d$ 所需的信噪比比理想门限多出 1–3 dB（Skolnik 第5章有专门曲线）。参考单元越多，损失越小，但参考窗越宽、越容易把别的目标装进来。</span>

## 4 二进制检测与滑动窗口

雷达界还有一种实用化程度极高的检测器叫**二进制检测器（binary integrator，M-of-N）**：对同一目标在 $N$ 次观察中，若至少 $M$ 次超过阈值就判为目标，否则判为虚警。它等价于在时间维再做一次「参考判决」，用来抑制突发性的噪声尖峰与海杂波尖峰。

若单次 $P_{fa} = p_f$、$P_d = p_d$ 且各次独立，则 $N$ 次中至少 $M$ 次过阈的联合概率由二项分布给出：

$$P_{FA} = \sum_{k=M}^{N} \binom{N}{k} p_f^k (1-p_f)^{N-k}, \qquad P_D = \sum_{k=M}^{N} \binom{N}{k} p_d^k (1-p_d)^{N-k}$$

典型配置是「3-of-8」：8 次观察中至少 3 次过阈。它的好处是**对虚警的压制是组合式的**——单次虚警概率 0.1 时，3-of-8 的联合虚警率可以降到 $10^{-3}$ 量级，而对稳定目标的检测损失很小。

一个数字手感：设单次 $P_{fa} = 0.01$、$P_d = 0.9$，3-of-8 的联合虚警率约 $2\times10^{-5}$、联合检测概率约 0.9996——虚警被压掉近三个数量级，检测却几乎不掉。这就是「数次数」比「算概率」划算的地方：尖峰噪声很少连续 3 次出现，而真目标在 8 帧里通常稳定存在。<span class="marginnote">二进制检测在跟踪雷达里还有一层延伸：跟踪的「航迹起始」本质就是一个 M-of-N 过程——连续 N 帧里目标出现 M 次以上才建立航迹，防止被瞬时尖峰骗出假航迹。检测的统计思想一路延伸到了第8篇《跟踪雷达》。</span><span class="marginnote">二进制检测把「概率」变成了「数数」：与其精确算虚警率，不如数一数 8 次里有几次过阈。它计算量小、抗尖峰，是航管雷达与海面监视雷达最常用的检测器之一。</span>

## 5 CFAR 与现代雷达系统的衔接

CFAR 不是孤立模块，它被嵌在完整的检测链路上：匹配滤波 → 多普勒滤波（MTD）→ 包络检波 → **CFAR** → 二进制积分 → 点迹凝聚。每一步都在为下一步「打扫背景」：

- **多普勒维 CFAR**：在距离-多普勒图上沿多普勒维取参考窗，能同时利用速度信息区分目标与杂波（与第3篇呼应）。
- **点迹凝聚（plot extraction）**：CFAR 后相邻过阈单元合并成一个点迹，避免一个目标报出多个假点。
- **两级检测**：先粗检测（低阈值 CFAR + 二进制积分）再细确认（第二次更严格的 CFAR 或跟踪确认），是现代预警雷达控制虚警的标准做法。<span class="marginnote">注意：CFAR 的「恒虚警」并不等于「恒检测」。它只是保证 $P_{fa}$ 稳定，$P_d$ 仍随信噪比起伏。所以在强杂波或干扰下，CFAR 的阈值会被抬高、检测概率下降——这正是第4篇杂波、第11篇 ECCM 要解决的「检测概率的敌人」。</span>

一个现实数字：现代相控阵雷达在单次扫描里要处理数十万个距离-多普勒单元，每个单元都要过 CFAR。若 CFAR 阈值估计偏差 3 dB，$P_{fa}$ 可能变化一个数量级——所以 CFAR 的参考窗设计、边缘保护、目标污染补偿，都是工程上反复打磨的细节。

还有一个容易混淆的量叫**检测损失（detection loss）**：与「已知背景电平」的理想门限相比，CFAR 因估计背景而多付出的信噪比代价。CA-CFAR 在均匀高斯背景下损失约 $1 + 1/N$ 的因子（$N$ 个参考单元时约 0.2–0.5 dB 量级），但抗干扰与边缘处理会让这个损失涨到 1–3 dB。**设计目标从来不是零损失，而是「在给定威胁下损失最小」**——这是检测理论的全部工程智慧所在。<span class="marginnote">把 CFAR 损失代入雷达方程，你会立刻理解它的重要性：损失 3 dB 意味着功率孔径积要翻一倍才能补回——而代价往往是一台发射机的重量与造价。检测器省下来的每 1 dB，都是系统级的大节省。</span>

## 6 小结

- 检测是二元假设检验：**$P_d$**（不漏真目标）与 **$P_{fa}$**（不认错噪声），奈曼-皮尔逊准则固定 $P_{fa}$ 后最大化 $P_d$。
- 固定阈值随背景漂移而失效：$P_{fa} = e^{-V_T^2/2\psi_0}$ 取决于阈值与噪声的相对比例。
- **Swerling 模型**刻画 RCS 起伏对检测的惩罚，脉冲积累是平均起伏低谷的主要手段。
- **CFAR** 用参考单元估计背景电平、阈值取 $\alpha \hat{P}_n$，让 $P_{fa}$ 在背景变化中保持恒定；CA-CFAR 有掩蔽问题，GO/OS-CFAR 对症下药。
- **二进制检测（M-of-N）** 用「数过阈次数」组合抑制尖峰虚警，3-of-8 是常见配置。
- CFAR 嵌在「匹配滤波 → 多普勒 → 检测 → 凝聚」链路上，与现代雷达点迹处理融为一体。
- 检测的统计语言（假设检验、ROC、二项判决）与机器学习、医学诊断共享同一套数学，是「从极限到大模型」知识树里统计思维的又一次落地。
- 起伏模型（Swerling）决定积累策略与性能预估，选错模型会让检测性能预估偏差数 dB。

在下一节，我们将抬头看天线：当几十万个小发射单元代替一面大天线时，雷达如何靠「相位」让波束在毫秒间无惯性地转向任意方向？这就是**相控阵雷达**——它是把检测、多普勒、CFAR 这几章的全部处理能力，装进一个能随时把波束指向任意方向的「机器」，也是现代雷达由「机械时代」迈向「数字时代」的分水岭。
