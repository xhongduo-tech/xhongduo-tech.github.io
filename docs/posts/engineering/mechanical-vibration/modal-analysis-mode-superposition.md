## 为什么从模态分析开始

上一节得到了系统的模态（固有频率 + 振型），这一节把模态变成**求解工具**。多自由度系统最麻烦的地方是方程互相耦合：动 $x_1$ 会拖拽 $x_2$，解起来牵一发动全身。模态分析的核心思想是**换坐标**：把「谁都在动」的物理坐标换到「各自独立」的模态坐标里，耦合的方程组就变成一堆互不相干的单自由度方程，解完再叠回来。这个「换坐标→解耦→叠加」的过程，就是**振型叠加法（mode superposition method）**，它是结构动力学响应分析的标准方法，也是地震工程、抗风设计、车辆平顺性仿真背后运行的算法。<span class="marginnote">模态分析（modal analysis）这个词有两层含义：理论上是「用模态坐标解耦系统」的数学方法，实验上是「从实测频响提取固有频率、振型、阻尼」的测试技术。这一节讲理论，实验侧在《振动试验与模态测试技术》一节展开——先建立「模态参数」的概念，测试才有目标。</span>

## 1 模态坐标变换

把振型按列排成**振型矩阵** $\Phi = [\boldsymbol{\phi}_1, \boldsymbol{\phi}_2, \dots, \boldsymbol{\phi}_n]$，引入**模态坐标** $\mathbf{q}(t)$，令

$$
\mathbf{x}(t) = \Phi\,\mathbf{q}(t) = \sum_{i=1}^{n} q_i(t)\,\boldsymbol{\phi}_i
$$

**物理坐标是模态坐标的线性叠加**：$q_i(t)$ 表示第 $i$ 阶模态在整体响应里占多大分量。把 $\mathbf{x} = \Phi\mathbf{q}$ 代入无阻尼系统方程 $M\ddot{\mathbf{x}} + K\mathbf{x} = \mathbf{f}(t)$，再用 $\Phi^T$ 左乘全式：

$$
\Phi^T M \Phi\,\ddot{\mathbf{q}} + \Phi^T K \Phi\,\mathbf{q} = \Phi^T \mathbf{f}(t)
$$

**正交性在这里登场**：因为 $\boldsymbol{\phi}_i^T M \boldsymbol{\phi}_j = 0$（$i\neq j$），所以 $\Phi^T M\Phi$ 是对角矩阵，$\Phi^T K\Phi$ 也是对角矩阵。<span class="marginnote">对角化是整件事的高潮：一个原本满秩耦合的方程组，经振型矩阵换坐标后，质量矩阵与刚度矩阵同时变成对角阵。对角线上的元素 $\bar{m}_i = \boldsymbol{\phi}_i^T M\boldsymbol{\phi}_i$、$\bar{k}_i = \boldsymbol{\phi}_i^T K\boldsymbol{\phi}_i$ 分别叫模态质量、模态刚度。</span>

## 2 解耦后的模态方程

对角化之后，矩阵方程拆成了 $n$ 个互不相干的标量方程：

$$
\bar{m}_i \ddot{q}_i + \bar{k}_i q_i = \bar{f}_i(t), \qquad i = 1, 2, \dots, n
$$

其中 $\bar{f}_i(t) = \boldsymbol{\phi}_i^T \mathbf{f}(t)$ 是第 $i$ 阶**模态力**。<span class="marginnote">每个模态方程都是一条独立的单自由度方程！回想第 1 篇学过的 $m\ddot{x}+kx=0$：现在 $n$ 个这样的方程排成一行，每个都能用第一章的现成结论直接求解。这正是「把新问题还原成旧问题」的典型套路。</span>

再除以模态质量，并利用模态刚度的定义 $\bar{k}_i = \omega_i^2 \bar{m}_i$（由模态方程本身可知），得到标准形式

$$
\ddot{q}_i + \omega_i^2 q_i = \frac{\bar{f}_i(t)}{\bar{m}_i}
$$

**第 $i$ 阶模态方程的固有频率就是系统第 $i$ 阶固有频率 $\omega_i$**，但它是独立的一维方程，单自由度的全部结论（杜哈梅积分、频响、共振条件）都能逐条平移过来。

## 3 阻尼的处理：模态阻尼假设

无阻尼系统解耦得天衣无缝，但真实系统有阻尼，而阻尼矩阵 $C$ 一般**不能**被 $\Phi$ 对角化。工程上常用的对策是**比例阻尼假设**：设 $C$ 是 $M$ 与 $K$ 的线性组合

$$
C = \alpha M + \beta K
$$

此时 $\Phi^T C \Phi = \alpha\,\mathrm{diag}(\bar{m}_i) + \beta\,\mathrm{diag}(\bar{k}_i)$ 自动对角化，每个模态方程带一个模态阻尼比 $\zeta_i$：

$$
\ddot{q}_i + 2\zeta_i\omega_i\dot{q}_i + \omega_i^2 q_i = \frac{\bar{f}_i(t)}{\bar{m}_i}
$$

**辨析｜易错点：** 比例阻尼只是工程近似，不是物理定律。实际结构的阻尼分布（连接摩擦、材料滞回、附加阻尼器）大多不满足 $C = \alpha M + \beta K$。因此模态分析时常见两种做法：一是假设比例阻尼直接对角化，二是**从实验逐个测出每阶 $\zeta_i$**，人为把 $\Phi^T C\Phi$ 写成对角阵——后者在模态测试中更常用，但要知道它绕过了「$C$ 能否对角化」的疑问，把阻尼当作每阶独立的经验参数。

### 物理坐标与模态坐标：一张对比表

把「换坐标」前后的差别摆在一张表里，是理解模态分析最快的方式：

| 对比项 | 物理坐标 $\mathbf{x}$ | 模态坐标 $\mathbf{q}$ |
| --- | --- | --- |
| 坐标个数 | $n$（自由度总数） | $n$（模态总数） |
| 方程耦合 | 耦合，$M,K$ 非对角 | 解耦，各方程独立 |
| 物理含义 | 各自由度的真实位移 | 各阶模态的参与程度 |
| 是否可测 | 直接可测（传感器） | 需经 $\Phi$ 变换得到 |
| 求解难度 | 解 $n$ 元方程组 | 解 $n$ 个单自由度方程 |

**模态坐标 $q_i(t)$ 的物理含义是「系统里第 $i$ 阶姿态占了多少分量」**——像乐谱里的声部音量：一段和声可以分解成各声部各自的强弱，叠加起来还原成整体。<span class="marginnote">地震工程与抗风工程是振型叠加法最典型的舞台：高层建筑有几十上百个自由度，但地震响应主要由前几阶弯曲模态主导，于是只保留前 5～10 阶模态就能以极小的代价得到精度足够的时程响应——这正是《结构动力学》《地震工程》里「模态截断」做法的由来。</span>

## 4 公式解析：振型叠加求解的全流程

把「先解耦、再叠加」的完整链条用一组公式走一遍：

$$
\underbrace{\mathbf{x}(t) = \sum_{i=1}^{n} \boldsymbol{\phi}_i\, q_i(t)}_{\text{叠加}} , \qquad
\underbrace{\ddot{q}_i + 2\zeta_i\omega_i\dot{q}_i + \omega_i^2 q_i = \frac{\bar{f}_i(t)}{\bar{m}_i}}_{\text{解耦后的单自由度方程}}
$$

- **第一步，算模态**：求解特征值问题 $(K - \omega^2 M)\mathbf{X} = \mathbf{0}$，得到 $\omega_i$ 与 $\boldsymbol{\phi}_i$，按需归一化（如令最大分量等于 1，或令模态质量 $\bar{m}_i = 1$）。
- **第二步，求模态力**：把外载荷投影到各阶模态上，$\bar{f}_i(t) = \boldsymbol{\phi}_i^T \mathbf{f}(t)$。这一步的物理含义是「外力对第 $i$ 阶模态做了多少功」——外力方向与振型越像，该阶被激发得越强。
- **第三步，解 $n$ 个单自由度方程**：对每个 $i$ 用杜哈梅积分或数值积分求 $q_i(t)$，初始条件也要先投影到模态坐标：$q_i(0) = \boldsymbol{\phi}_i^T M\mathbf{x}(0)/\bar{m}_i$。
- **第四步，叠加还原**：把各阶模态坐标代回 $\mathbf{x} = \Phi\mathbf{q}$ 求和。**实际工程常只取前几阶（如前 5 阶）就能满足精度**，因为高频模态的 $\bar{f}_i$ 小、响应衰减快——这就是「截断叠加」，是振型叠加法相对于直接数值积分最值钱的加速手段。

**辨析｜易错点：** 截断叠加时不能天真地丢掉高阶模态——当激励频率正好落在被丢掉的高阶模态上时，丢掉的恰恰是主要响应。工程惯例是先看激励的频带，**凡是频带内的模态都必须保留**；频带外的高阶模态才允许截断。

### 模态阻尼比的工程量级

模态阻尼比 $\zeta_i$ 是模态分析里最「说不准」的参数——刚度质量能精确建模，阻尼却强烈依赖材料、连接与工艺。工程上不同结构的典型量级值得记住：

| 结构类型 | 模态阻尼比 $\zeta$ 典型范围 |
| --- | --- |
| 焊接钢框架 | 0.5%～2% |
| 预应力混凝土梁 | 2%～4% |
| 螺栓连接机械结构 | 1%～3% |
| 带阻尼处理的汽车车身 | 3%～5% |
| 装有附加阻尼器的建筑 | 5%～10% |

**辨析｜易错点：** 模态叠加时若统一取一个 $\zeta$ 值，会把低阶与高阶的耗能差异抹平。高阶模态的阻尼通常比低阶大（局部变形耗能多），若按低阶的 $\zeta$ 给高阶算响应，会高估高阶振幅、把本该衰减快的分量算「活」了。**工程上宁可每阶单独给阻尼比，也不要图省事用单一平均值。**

## 5 小结

- **振型矩阵** $\Phi$ 把物理坐标换成模态坐标 $\mathbf{x} = \Phi\mathbf{q}$，正交性让 $M$、$K$ 同时对角化。
- 解耦后得到 $n$ 个独立模态方程，每个都是一条单自由度方程，可直接套用第一章结论。
- 阻尼用**比例阻尼**或**实测每阶 $\zeta_i$
