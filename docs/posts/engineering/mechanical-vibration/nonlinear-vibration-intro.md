## 为什么从非线性振动开始

线性理论统治了前面十篇，但它有一个隐性的前提：弹簧力与位移成正比、阻尼力与速度成正比。真实系统常常越界——大振幅下弹簧变硬或变软、摩擦力与速度不成线性、流体力随速度平方变化。一旦非线性出现，叠加原理失效，振动世界立刻变得丰富而危险：**同一激励可能有两个解、频率不再是常数、无外力的系统也会自己动起来**。<span class="marginnote">非线性振动（nonlinear vibration）：恢复力或阻尼力对位移/速度的非线性依赖。它最经典的后果是「频率随振幅漂移」「跳跃现象」「极限环」「次谐波/超谐波共振」——这些在线性框架里统统不存在。数学上与第二级《非线性动力学与混沌》无缝衔接。</span>这一节用 Duffing 方程与 van der Pol 方程两个范式，把非线性振动的标志性现象讲清楚，并给出初步的定量工具。

## 1 Duffing 方程：硬弹簧与软弹簧

**Duffing 方程**是含立方非线性项的单自由度系统范式：

$$
\ddot{x} + 2\zeta\omega_n\dot{x} + \omega_n^2 x + \alpha x^3 = F\cos\omega t
$$

$\alpha > 0$ 时弹簧随振幅变硬（**硬化**），$\alpha \lt  0$ 时变软（**软化**）。<span class="marginnote">立方项 $\alpha x^3$ 的出现让「等效刚度」依赖振幅：振幅越大，硬化弹簧越硬。于是系统没有固定的固有频率，只有随振幅变化的「等效固有频率」——这是非线性振动与线性振动最根本的分水岭。</span>求稳态解时，设 $x = X\cos(\omega t - \phi)$，把 $\cos^3$ 项展开并保留基频分量（谐波平衡），得到振幅与频率的关系：

$$
\left[(\omega_n^2 - \omega^2) + \frac{3}{4}\alpha X^2\right]^2 + (2\zeta\omega_n\omega)^2 = \left(\frac{F}{mX}\right)^2
$$

这个隐式方程给出的 $X$-$\omega$ 关系不再是一条对称的尖峰曲线，而是一根向一侧**弯折**的曲线——弯折的方向由 $\alpha$ 的符号决定。

### 线性系统与非线性系统对比

把前面十篇建立的线性直觉与非线性现实放在一张表里，差异一目了然：

| 对比项 | 线性系统 | 非线性系统 |
| --- | --- | --- |
| 固有频率 | 常数，与振幅无关 | 随振幅漂移（硬化/软化） |
| 叠加原理 | 成立 | **不成立**，解不能线性叠加 |
| 谐波激励响应 | 只有同频分量 | 含谐波、次/超谐波分量 |
| 响应唯一性 | 唯一 | 可能多个稳定解，出现跳跃 |
| 无激励时 | 静止（衰减到零） | 可能自激振荡（极限环） |

**这一表是「非线性振动初步」的提纲**：后面每一节讲的现象（跳跃、骨架曲线、极限环）都能在这一表里找到它的「线性位置」。遇到具体系统时，先问一句「它离线性有多远」——振幅小、非线性弱时按线性处理误差不大；振幅一大，线性结论全部要打问号。

## 2 跳跃现象与骨架曲线

把上面的振幅-频率关系画出来，硬化弹簧（$\alpha>0$）的共振峰向右弯、软化弹簧（$\alpha\lt 0$）向左弯。弯折带来的结果是**跳跃现象（jump phenomenon）**：<span class="marginnote">假设扫频从低往高走：频率升高时振幅沿曲线下支爬升，到弯折点处「啪」地跳到上支；反过来从高往低扫，振幅沿上支走，到另一个弯折点「啪」地跌回下支。同一条曲线、同一个频率，振幅却有两个稳定值——响应由「你从哪边来」决定，这叫滞后（hysteresis）。</span>

**向上扫频**：振幅沿下支缓慢增大，在右弯折点突然跳到上支，跳幅可观。
**向下扫频**：振幅沿上支走，在左弯折点突然跌回下支。

**骨架曲线（backbone curve）**：把无阻尼、无激励（$F=0, \zeta=0$）时的振幅-频率关系 $\omega^2 = \omega_n^2 + \frac{3}{4}\alpha X^2$ 画出来，是共振峰脊背的连线，恰好描述「固有频率随振幅漂移」这条定律：硬化系统振幅越大频率越高，软化系统反之。<span class="marginnote">骨架曲线是判断系统是否非线性、何种非线性的实验依据：实测中不断改变激励幅值、记录共振频率的移动轨迹，若共振峰沿一条弯曲线滑行，就说明系统存在立方非线性。模态测试里常见的「频率随激励级变化」现象，正是这条曲线在作怪。</span>

**辨析｜易错点：** 线性系统只有一个共振峰、一个固有频率；非线性系统的共振峰「长歪了」，且峰的位置随激励幅值移动。若仍用线性方法去读非线性共振峰，读出的「固有频率」会随激励大小漂移——这正是非线性系统无法用单一频响函数描述的原因，也是为什么「大振幅下线性频响失效」。

## 3 自激振动与 van der Pol 振荡

非线性还有一类更本质的现象：**没有周期外力，系统却持续振荡**——因为阻尼项本身随振幅「变号」。**van der Pol 方程**是范式：

$$
\ddot{x} - \epsilon(1 - x^2)\dot{x} + x = 0
$$

注意阻尼系数 $\epsilon(1-x^2)$：**$|x|\lt 1$ 时阻尼为负（能量注入），$|x|>1$ 时阻尼为正（能量耗散）**。系统小振幅时被「加油」、大振幅时被「刹车」，最终稳定在一条固定的闭合轨迹上——**极限环（limit cycle）**。<span class="marginnote">极限环（limit cycle）：相平面里孤立的闭合轨道，附近所有轨迹都被吸引或排斥到它上面。时钟摆、钟表擒纵机构、人的心跳、机翼颤振、管道涡激振动、机床再生颤振，都是自激振荡——它们不需要周期外力，天然自带一个稳定的振动节奏。它与保守系统的等能闭合轨道本质不同：极限环是结构稳定的，扰动之后会自己回来。</span>

自激振荡的三个工程特征值得记住：**振幅由系统内部决定、与初始条件无关；频率由系统决定；一旦停住（阻尼变了）振荡会重新建立。** 机翼颤振、机床切削颤振都是能量从稳态流（气流、切削）注入结构、由结构内部机制调节振幅的自激振动——治理思路也从「避开共振」转为「破坏能量注入机制」。

### 自激振荡的工程案例

自激振荡不是教科书里的摆设，它制造过真实的灾难：

**机床再生颤振**：车削时刀具与工件之间的切削力随切深增加而增大，切削力一旦超过系统阻尼能耗散的极限，刀架就以某一固有频率剧烈振动，工件表面出现波纹。更糟的是，下一次走刀切过上一刀留下的波纹，切深周期性变化，振颤自我维持——这是机加工车间里「怎么调转速都振」的经典难题。治理思路是降低切深、提高系统刚度、或改变转速避开再生周期，**本质都是破坏能量注入的机制，而不是单纯加阻尼**。

**输电线舞动**：冬季覆冰的输电导线在风作用下做低频大幅摆振，振幅可达数米，造成断线倒塔。导线截面覆冰后不再对称，气流产生周期性升力（气动非线性），与导线的几何非线性耦合，形成自激振动。舞动的频率与风速无关、只由导线参数决定——这正是极限环「频率由系统决定」的特征。

**辨析｜易错点：** 自激振荡与共振是两回事：共振需要**外部周期激励**恰好匹配固有频率；自激振荡**不需要任何周期外力**，能量来自稳态流（风、切削、电磁），由系统内部机制自动维持。治理共振靠「错开频率」，治理自激靠「切断能量供给」——两条路混用必然无效。

### 通向混沌

非线性振动的故事并没有止于极限环。Duffing 方程在强非线性与特定激励下会出现**混沌（chaos）**：响应看似杂乱，实则由确定的方程产生，对初值极度敏感——初值差一点，轨迹指数级分道扬镳。<span class="marginnote">混沌的发现重塑了「可预测性」的观念：确定性系统可以产生不可预测的长期行为。洛伦兹的「蝴蝶效应」、弹簧摆的混沌运动都是教科书案例，系统化理论见第二级《非线性动力学与混沌》。振动分析的线性框架在这里彻底失效，留给统计与几何方法（相图、庞加莱截面、李雅普诺夫指数）。</span>这一节只点到为止——知道「非线性振动的终点是混沌」这一句话，就为后续深入学习埋下了坐标。

## 4 公式解析：谐波平衡法的三步

对非线性方程没有精确解，但可以做**近似解析**。以 Duffing 方程为例，谐波平衡法分三步：

- **第一步，假设基频解**：设 $x = X\cos(\omega t - \phi)$，把 $\cos^3\theta = \frac{3}{4}\cos\theta + \frac{1}{4}\cos 3\theta$ 展开。三次谐波项 $\cos 3\omega t$ 的振幅是基频的 1/3，对主共振贡献小，先忽略。
- **第二步，比较基频系数**：把 $x$ 及其导数代入方程，令 $\cos(\omega t - \phi)$ 与 $\sin(\omega t - \phi)$ 前的系数分别平衡，得到两个方程（振幅平衡 + 相位平衡）。
- **第三步，消去相位得振幅方程**：两式平方相加，即得前面的 $X$-$\omega$ 关系；两式相除得相位关系 $\tan\phi = \frac{2\zeta\omega_n\omega}{(\omega_n^2-\omega^2)+\frac{3}{4}\alpha X^2}$。

**辨析｜易错点：** 谐波平衡法只保留基频分量，把 $\cos 3\omega t$ 丢掉，所以它对「主共振」精度良好，但**算不出次谐波共振**——当激励频率接近固有频率的 1/3 时，三倍频分量恰与主频共振，被丢掉的那个谐波恰恰是主角。遇到次谐波、超谐波共振，需要保留更多谐波项（高阶谐波平衡）或改用摄动法，这是非线性振动专门课程的内容。

### 非线性振动术语速查

| 术语 | 一句话定义 |
| --- | --- |
| 硬化/软化弹簧 | 等效刚度随振幅增大而增大/减小的非线性弹簧 |
| 骨架曲线 | 无阻尼自由振动的振幅-频率关系，描述频率随振幅的漂移 |
| 跳跃现象 | 扫频时振幅在两个稳定支之间的突然跳变 |
| 滞后（hysteresis） | 向上与向下扫频走不同路径，响应依赖历史 |
| 极限环 | 相平面中孤立的闭合轨道，自激振荡的稳定形态 |
| 自激振荡 | 无周期外力、靠系统内部机制维持的持续振动 |
| 谐波平衡法 | 假设基频解、比较基频系数的近似解析方法 |
| 次/超谐波共振 | 激励频率为固有频率整数倍/约数时的共振 |
| 混沌 | 确定方程产生的、对初值极端敏感的复杂行为 |

**这张表把本节的散点串成一条线**：Duffing 方程给出前四个术语，van der Pol 方程给出极限环与自激振荡，谐波平衡是工具，次/超谐波与混沌是更深的延伸。记住这张表，就掌握了非线性振动入门的全部关键词。

## 5 小结

- **Duffing 方程**引入立方非线性，系统的等效固有频率随振幅漂移，共振峰向硬化（$\alpha>0$）或软化（$\alpha\lt 0$）方向弯折，扫频时出现**跳跃与滞后**。
- **van der Pol 方程**的阻尼项随振幅变号：小振幅时注入能量、大振幅时耗散能量，系统稳定在**极限环**上——这就是自激振荡的数学形态。
- 自激振荡与共振是两回事：共振靠**外部周期激励**，自激靠**系统内部机制**维持，治理分别走「错开频率」与「切断能量供给」两条路，混用必然无效。
- **谐波平衡法**假设基频解、比较基频系数，对主共振精度良好，却算不出次谐波共振——遇到次/超谐波需保留更高谐波项或改用摄动法。
- 强非线性与特定激励下的 Duffing 系统会走向**混沌**：由确定方程产生、对初值极端敏感的复杂响应，振动分析的线性框架在那里彻底失效。

在下一节，我们将把非线性振动与更一般的动力学联系起来——极限环、分岔与混沌这些概念，正是第二级《非线性动力学与混沌》要系统展开的内容。
