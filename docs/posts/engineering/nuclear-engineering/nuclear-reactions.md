## 为什么从核反应开始

放射性衰变是核的「自发」转变，而**核反应（nuclear reaction）**是核的「受迫」转变——用入射粒子去轰击靶核，制造出自然界不轻易出现的核素与能量。1932 年科克罗夫特与沃尔顿用加速的质子轰击锂，人工实现了第一次核嬗变；1938 年哈恩发现铀核裂变，把核反应推上了世界舞台。今天，从反应堆里的中子诱发裂变，到医院的 PET 同位素生产，再到天文学家眼中恒星内部的核燃烧，全都是核反应的应用。<span class="marginnote">核反应与化学反应的相似之处在于「反应物 → 产物 + 能量」，但能量尺度相差百万倍：化学反应动的是电子壳层（约 eV），核反应动的是核内结构（约 MeV）。记住这个「七个数位」的尺度差，就不会把两类反应混为一谈。</span>

## 1 反应的记号与守恒律

**核反应（nuclear reaction）**：入射粒子 $a$ 轰击靶核 $X$，形成复合系统后放出出射粒子 $b$ 与剩余核 $Y$，记为：

$$X(a,\,b)\,Y \qquad\text{即}\qquad a + X \;\longrightarrow\; Y + b$$

例如卢瑟福 1919 年首次实现的人工核嬗变 $\ce{^{14}N} + \alpha \to \ce{^{17}O} + p$，简写为 $\ce{^{14}N}(\alpha, p)\ce{^{17}O}$。<span class="marginnote">简写记号读作「氮-14 吸收 α 放出质子变成氧-17」。(a,b) 形式在核数据手册与反应堆计算里是标准语言，如 $\ce{^{235}U}(n,f)$ 表示中子诱发裂变。</span>

核反应必须遵守一组守恒律，这是写反应方程的第一道闸门：

- **核子数守恒**：反应前后质量数 $A$ 之和相等。
- **电荷守恒**：反应前后质子数 $Z$ 之和相等。
- **能量与动量守恒**：反应能 $Q$ 由质量亏损决定。
- **角动量、宇称守恒**：约束反应能否发生、如何分配角动量。

## 2 Q 值与反应能学

**反应能（reaction energy）$Q$**：反应释放或吸收的能量，等于反应前后静质量之差乘 $c^2$：

$$Q = \bigl[(m_a + m_X) - (m_Y + m_b)\bigr]\,c^2$$

- $Q > 0$：**放能反应（exothermic）**，反应后粒子动能大于反应前。大多数中子诱发反应都是放能的。
- $Q < 0$：**吸能反应（endothermic）**，入射粒子必须提供额外动能才够「买票进门」。入射粒子在实验室系所需的最低动能叫**阈能（threshold energy）**。

**阈能比 $|Q|$ 大**，因为质心系中有一部分入射动能被「浪费」在整体质心运动上，只有质心系动能可用于引发反应。对入射粒子质量 $m_a$、靶核质量 $m_X$，阈能为：

$$E_{\text{th}} = -Q\,\frac{m_a + m_X}{m_X}$$

**辨析｜易错点：** 不少人把阈能直接当作 $|Q|$。注意 $E_{\text{th}} = |Q|(m_a + m_X)/m_X > |Q|$——只有靶核质量无穷大时（实验室系=质心系）两者才相等。反应堆物理里慢中子引发的 $n + \ce{^{235}U}$ 是 $Q>0$ 的放能反应，不需要阈能，这正是慢中子堆可行的原因之一。

## 3 反应截面：反应发生的「概率门」

束流中单个粒子打在靶上，反应不一定发生。描述发生概率的物理量是**截面（cross section）$\sigma$**：

$$\sigma = \frac{\text{单位时间反应数/单位面积靶核}}{\text{单位时间入射粒子数}}$$

量纲是面积，单位是**靶恩（barn, b）**，$1\,\mathrm{b} = 10^{-28}\,\mathrm{m^2}$。<span class="marginnote">名字源于「像谷仓门一样大」——最初散射实验里很难想象截面会这么大，于是戏称为 barn。$10^{-28}\,\mathrm{m^2}$ 与原子核投影面积同一量级，正是「核大小」的另一种表达。</span>

设靶核密度为 $n$（单位体积核数）、靶厚为 $x$，入射束强度为 $I_0$，则穿透后

$$I(x) = I_0\,e^{-n\sigma x}$$

$n\sigma$ 称为**宏观截面 $\Sigma$**，量纲是长度倒数，$1/\Sigma$ 就是中子在介质中的**平均自由程**。截面越大，束流衰减越快。<span class="marginnote">指数衰减律 $I = I_0 e^{-\Sigma x}$ 与衰变律 $N = N_0 e^{-\lambda t}$ 数学同构：截面之于「穿行距离」正如衰变常数之于「时间」。这层类比在第二篇《中子与物质相互作用》中会进一步展开。</span>

## 4 反应机制：复合核与直接反应

核反应不是简单的「碰撞-弹开」，按相互作用时间可分两类机制：

- **复合核模型（compound nucleus model）**：玻尔提出，入射粒子与靶核先「融合」成一个长寿命的复合核，能量在众多核子间充分分配，复合核「忘记」了入射的历史，再按统计规律衰变放出一个粒子。典型时间 $10^{-16}$ s 量级，比直接穿过的时间长得多。<span class="marginnote">复合核衰变方向与入射方向无关（各向同性），产物分布只取决于复合核的激发能——这就是「遗忘历史」的物理后果。1938 年哈恩发现铀裂变时，实际就是复合核 $\ce{^{236}U^*}$ 的奇特衰变通道。</span>
- **直接反应（direct reaction）**：入射粒子只与靶核表面少数核子交换能量动量，一次性完成，时间约 $10^{-22}$ s，产物有强烈的前冲角分布。常用于单核子转移、拾取等反应。

共振现象强烈支持复合核图像：入射能量恰好使复合核激发到某个量子态时，反应截面出现尖锐峰，称**共振（resonance）**。<span class="marginnote">共振截面峰在慢中子区尤为重要：$\ce{^{235}U}$ 在 0.3 eV 附近的共振峰使热中子裂变截面高达约 586 b。反应堆物理里这些共振吸收峰决定中子能谱与燃耗行为，是《中子与物质相互作用》与《堆物理设计》的核心素材。</span>

## 5 公式解析：复合核的两步图像

复合核反应可写成两个独立的步骤：

$$a + X \;\xrightarrow{\;\sigma_c\;}\; C^* \;\xrightarrow{\; \Gamma_b \;}\; Y + b$$

三步拆解：

- **第一步，形成复合核**：入射粒子被靶核俘获形成激发态复合核 $C^*$，这一步用**形成截面 $\sigma_c$** 描述。入射能量必须超过库仑势垒（带电粒子）或刚好落在共振能级上。
- **第二步，复合核退激**：激发能通过多种通道耗散——发射中子、质子、α、γ，或裂变。每个通道以**宽度（width）$\Gamma_i$** 表征，正比于该通道的衰变概率。
- **第三步，看分支比**：总宽度 $\Gamma = \sum_i \Gamma_i$，第 $b$ 通道的概率是 $\Gamma_b/\Gamma$，反应截面 $\sigma_{ab} = \sigma_c\, \Gamma_b/\Gamma$。**哪个通道的宽度大，反应就更可能走哪条路**。

**复合核公式把「概率」拆成了两个独立乘积**：先看能不能进门（$\sigma_c$），再看进门后往哪条走廊走（$\Gamma_b/\Gamma$）。对反应堆最关键的 $\ce{^{235}U} + n$，复合核 $\ce{^{236}U^*}$ 的裂变宽度远大于辐射俘获宽度，于是裂变成为主通道。

## 6 光核反应与核嬗变的应用

除粒子诱发的反应外，还有**光核反应（photonuclear reaction）**：高能 γ 光子被核吸收后放出中子或质子，记作 $(\gamma,n)$、$(\gamma,p)$。光核反应是放疗加速器与工业探伤中产生中子的副反应，也是屏蔽设计必须考虑的杂散中子源。

核反应最实用的价值是**核嬗变（transmutation）**：制造自然界没有的核素。医学上 $\ce{^{99m}Tc}$ 的母核 $\ce{^{99}Mo}$ 由铀裂变产物或 $\ce{^{98}Mo}(n,\gamma)$ 反应生产；分析化学里的活化分析用中子轰击样品，通过测量感生放射性元素进行定性定量。这一切的入口，都是本章的截面与 Q 值语言。<span class="marginnote">中子活化分析灵敏度可达 ppb 量级，法医鉴定、文物断代、半导体杂质检测都在用。它只需要一台中子源 + 一台 γ 谱仪，是核技术「民用化」的典型。</span>

## 7 小结

- 核反应记作 $X(a,b)Y$，遵守**核子数、电荷、能量、动量、角动量守恒**。
- **Q 值**判放能/吸能；吸能反应有**阈能** $E_{\text{th}} = |Q|(m_a+m_X)/m_X$。
- **截面** $\sigma$（单位 barn）描述反应概率，宏观截面 $\Sigma = n\sigma$ 决定束流衰减 $I = I_0 e^{-\Sigma x}$。
- 反应机制分**复合核**（长寿命、各向同性、有共振）与**直接反应**（快、前冲）；复合核截面 = 形成截面 × 通道分支比。
- 核反应是嬗变与同位素生产的工具，也是中子诱发裂变与反应堆物理的入口。
