## 为什么从拉普拉斯变换开始

回看本专题的来路：电阻电路用代数方程，一阶二阶电路用微分方程，正弦稳态用相量法把微分变 $j\omega$。每种电路都有趁手的工具，但它们各管一段：相量法只应付稳态正弦，时域法解暂态要动微积分。能不能有**一把钥匙开所有锁**——把任意激励下的电路微分方程，统一变成代数方程？<span class="marginnote">答案藏在「把函数映到另一个域」的想法里。相量法把正弦映射到 $j\omega$ 轴，拉普拉斯变换则把一切（因果）函数映射到整个复平面 $s = \sigma + j\omega$。$\sigma = 0$ 时它就是傅里叶变换，$s = j\omega$ 时回到相量法——拉普拉斯变换是相量法的「升级版」，把特例收编为子集。</span>

这一节学完，你会拥有分析电路的**通用方法**：建模（s 域元件模型）→ 求解（代数方程）→ 反变换（部分分式 + 查表）。暂态与稳态、冲激与阶跃、零输入与零状态，全部在同一个框架里自然浮现。

## 1 拉普拉斯变换：把时间函数映到复平面

**核心概念**：**拉普拉斯变换（Laplace transform）**把时间函数 $f(t)$（$t \ge 0$）映射为复变量 $s = \sigma + j\omega$ 的函数：

$$
F(s) = \mathcal{L}\{f(t)\} = \int_{0^-}^{\infty} f(t)\, e^{-st}\,\mathrm{d}t
$$

它把**微分变成乘以 $s$**，把**积分变成除以 $s$**。最关键的性质（微分性质）：

$$
\mathcal{L}\left\{\frac{\mathrm{d}f}{\mathrm{d}t}\right\} = sF(s) - f(0^-)
$$

多出来的 $f(0^-)$ 正是**初始条件**——它被「自动装进」变换式，这就是为什么拉普拉斯法能一并处理暂态与稳态，不需要像三要素法那样分步取初始值。<span class="marginnote">对比三种工具：相量法处理「单频稳态」，傅里叶变换处理「任意频谱但默认零初值」，拉普拉斯变换处理「任意输入 + 任意初值」。$s$ 的实部 $\sigma$ 的存在，让拉普拉斯变换能处理傅里叶不收敛的指数增长信号——这是它作为「更一般工具」的底气。</span>

**辨析｜易错点：**积分下限取 $0^-$ 而非 $0$，是为了把 $t=0$ 时刻可能发生的跳变（换路瞬间）也计入——初始条件用的是**换路前**的值 $f(0^-)$。这正与第 6 篇「换路定则」呼应：$u_C(0^-)$、$i_L(0^-)$ 是换路前的储能状态，拉普拉斯变换自动把它带进方程。

## 2 s 域元件模型

对 R、L、C 分别做拉普拉斯变换，得到**s 域元件模型**：

**电阻**：$U(s) = R\,I(s)$——与直流时形式相同。
**电感**：$U(s) = sL\,I(s) - L\,i(0^-)$——一个阻抗 $sL$ 串联一个电压源 $L i(0^-)$（初始电流的效应）。
**电容**：$U(s) = \dfrac{1}{sC}I(s) + \dfrac{u_C(0^-)}{s}$——阻抗 $1/(sC)$ 串联电压源 $u_C(0^-)/s$。

**核心概念**：在 s 域里，**电容、电感都「变成」阻抗**（$1/sC$、$sL$），初始储能变成附加的源。于是整个电路变成「纯代数」的 s 域电路：KCL、KVL、阻抗串并联、节点法、戴维南全部照搬，解出 $I(s)$ 或 $U(s)$ 后再反变换回时域。<span class="marginnote">s 域元件模型与第 8 篇相量模型几乎一模一样——只是把 $j\omega$ 换成 $s$，并多出初始值源。这正是「相量法是拉普拉斯特例」的又一体现：$s = j\omega$ 且零初值时，模型完全重合。</span>

**重点：电源也要变换。** 阶跃电压源 $U_0 u(t)$ 的变换是 $U_0/s$；冲激 $\delta(t)$ 的变换是 1；正弦 $U_m\cos(\omega t + \varphi)$ 的变换可由欧拉公式查表得到。把激励换成 $F(s)$，问题就变成「解一个含源线性代数网络」。

## 3 公式解析：初值定理与终值定理

$$
f(0^+) = \lim_{s\to\infty} sF(s), \qquad
f(\infty) = \lim_{s\to 0} sF(s)
$$

- **初值定理**：由 $F(s)$ 在 $s \to \infty$ 的行为，直接读出时域响应的**初始值** $f(0^+)$。
- **终值定理**：由 $F(s)$ 在 $s \to 0$ 的行为，直接读出时域响应的**稳态值** $f(\infty)$。
- **前提**：终值定理要求 $sF(s)$ 在虚轴及右半平面无极点（系统稳定），否则 $f(\infty)$ 发散或振荡，定理不适用。

拆解直觉：拉普拉斯变换里，$s \to \infty$ 对应「极短时间尺度」（高频、初始时刻），$s \to 0$ 对应「极长时间尺度」（低频、稳态）。所以初值定理问「$F(s)$ 的高频尾巴长什么样」，终值定理问「$F(s)$ 的直流分量是多少」。**两定理的价值在于：不反变换，就能拿到响应的起止值**——工程上核对仿真结果、验证模型是否正确，这是最快的检查手段。<span class="marginnote">终值定理的应用实例：求阶跃响应稳定后是多少，只需 $\lim_{s\to0} sH(s)\cdot(1/s) = H(0)$，即网络函数在 $s=0$ 的值。这与「直流稳态时电容开路、电感短路」的时域结论一致——两种方法相互印证。</span>

## 4 网络函数与极点

**核心概念**：在**零初始状态**下，输出 $Y(s)$ 与输入 $X(s)$ 之比称为**网络函数（network function）**：

$$
H(s) = \frac{Y(s)}{X(s)}
$$

它是 $s$ 的有理函数，可写成分子多项式比分母多项式。令分母为零的根叫**极点（pole）**，令分子为零的根叫**零点（zero）**。**极点在复平面上的位置，完全决定电路的瞬态特性**：

- 极点实部为负 → 对应模式指数衰减，系统稳定；
- 极点实部为正 → 对应模式指数增长，系统不稳定；
- 极点虚部非零 → 对应模式衰减振荡，虚部即振荡频率。

这正是第 7 篇特征根分析的**统一表达**：二阶电路的特征根就是网络函数的极点。三要素法里的时间常数 $\tau$ 对应最近虚轴的极点，欠阻尼振荡频率 $\omega_d$ 对应共轭极点的虚部。<span class="marginnote">把「网络函数的极点」与「暂态响应模式」对应起来，是线性系统理论的枢纽。第六级《信号与系统》《自动控制原理》里，极点位置与稳定性的关系、极零图、根轨迹，全从这个对应生长出来。第 10 篇的频率响应 $H(j\omega)$ 不过是网络函数在 $s = j\omega$ 轴上的取值。</span>

**重点：网络函数只由网络结构决定，与激励无关。** 同一个电路，接阶跃、接冲激、接正弦，$H(s)$ 都不变；变的是输入 $X(s)$。这正是「系统」与「信号」分离的第一次清晰呈现——一个概念，撑起后面信号与系统、控制论两大领域。

## 5 用拉普拉斯分析电路的步骤

完整流程四步：

1. **变换**：把电路画成 s 域模型（元件换阻抗、初值换源、电源换 $F(s)$）。
2. **求解**：用节点法/网孔法等解出待求量的 $Y(s)$。
3. **反变换**：把 $Y(s)$ 作**部分分式展开**，逐项对照拉普拉斯变换表得时域解。部分分式各项的系数，对应响应中不同模式（指数、振荡、斜坡）的幅度。<span class="marginnote">部分分式展开是线性代数与初等代数的小配合：对不重复的极点，$A_k = (s - s_k)F(s)\big|_{s = s_k}$；有重极点时还需高阶项。这部分在第二级《高等数学》与《复变函数》里都有铺垫，此处只用到最基础的「查表 + 待定系数」。</span>
4. **验证**：用初值、终值定理核对起点与终点是否符合直觉。

**辨析｜易错点：**反变换前**必须**确认 $Y(s)$ 是严格真分式（分子次数低于分母）。若分子次数不低于分母，要先做多项式除法，把整出部分（对应 $\delta$ 及其导数）与真分式部分分开，再对真分式部分展开——漏掉这一手，部分分式会「卡壳」。

**辨析｜易错点：**s 域的「阻抗串并联」公式形式与电阻电路相同，但**运算对象是复数**。合并 $sL$ 与 $1/(sC)$ 时结果是 $sL + 1/(sC)$ 之类的有理式，不是简单实数——把它当实数化简是常见错误。

### 常用拉普拉斯变换对照表

| 时域 $f(t)$（$t \ge 0$） | s 域 $F(s)$ |
| --- | --- |
| $\delta(t)$（冲激） | 1 |
| $u(t)$（阶跃） | $1/s$ |
| $t$（斜坡） | $1/s^2$ |
| $e^{-\alpha t}$（指数） | $1/(s + \alpha)$ |
| $\sin\omega t$ | $\omega/(s^2 + \omega^2)$ |
| $\cos\omega t$ | $s/(s^2 + \omega^2)$ |

反变换的常规做法：把 $F(s)$ 展开成上表形式的线性组合（部分分式），逐项对照即可写出 $f(t)$。这张表值得熟悉到「条件反射」的程度——它是 s 域与时域之间的翻译字典。

一个完整例子：求 $F(s) = \dfrac{3s + 5}{(s+1)(s+2)}$ 的反变换。设 $F(s) = A/(s+1) + B/(s+2)$，待定系数解得 $A = 2$、$B = 1$，于是 $f(t) = 2e^{-t} + e^{-2t}$。两个极点 $-1$、$-2$ 都在左半平面，响应稳定衰减——极点位置判据在此又验证一次。

## 6 小结

- 拉普拉斯变换把微分变 $s$、积分变 $1/s$，**初始条件自动进入方程**。
- s 域元件模型：$R$、$sL$、$1/sC$，初始储能变成附加源——整套代数方法照搬。
- **初值/终值定理**：$\lim_{s\to\infty} sF(s)$ 与 $\lim_{s\to0} sF(s)$，不反变换即得起止值。
- 网络函数 $H(s) = Y/X$ 只由网络结构决定、与激励无关；极点在复平面的位置决定瞬态特性，右半平面有极则不稳定。
- 分析四步：变换 → 求解 → 部分分式反变换 → 初值/终值定理验证；反变换前务必把 $Y(s)$ 化为严格真分式。
- s 域方法的通用性：冲激、阶跃、正弦、任意波形、任意初值都在同一框架内处理，无需按激励类型分而治之。
