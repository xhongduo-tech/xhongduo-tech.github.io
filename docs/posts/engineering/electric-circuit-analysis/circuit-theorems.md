## 为什么从电路定理开始

节点法和网孔法虽然系统，但每次都要解整个网络的方程组。实际工程里，我们常常只关心**某一对端钮**上的行为：电源要给负载供多少功率？信号源带动一块复杂的电路板，等效于带了多大的阻抗？这一节的四条定理，就是为这种「只看局部」的需求准备的**杠杆**——它们把整块网络浓缩成极简单的等效物，让复杂问题瞬间变小。<span class="marginnote">戴维南定理可以看作阿基米德支点的电路版：无论网络内部多复杂，从外部一对端钮看进去，它只是一个电压源串一个电阻。复杂的「内部世界」被降维成两个参数，其余全部藏在黑箱里。</span>

这四条定理也是「从极限到大模型」主线的自然延伸：**线性**是它们的共同前提。叠加定理是「线性映射可分解」的直接推论，而线性正是从函数、到电路、再到神经网络（激活函数之前的仿射变换）里反复出现的主旋律。

## 1 叠加定理

**叠加定理（superposition theorem）**：**在线性电路中，任一电压或电流等于各独立电源单独作用时产生的电压或电流的代数和。**

操作规则：求某个量时，让一个独立源起作用，其余独立源全部「置零」——电压源短路（电压置零）、电流源开路（电流置零），然后求该量的贡献；对每个独立源重复一次，最后代数相加。<span class="marginnote">「电压源置零 = 短路，电流源置零 = 开路」是最容易记反的一点：把电压源换成一根导线，把电流源换成断开的空位。受控源在叠加时<strong>必须保留</strong>——它不独立起作用，是电路结构的一部分。</span>

**核心概念**：**叠加定理**：线性电路的响应（电压或电流）是各独立源单独作用贡献的线性组合。它的成立不依赖电路内部结构，只依赖「电阻是线性的、各支路满足线性 KCL/KVL」这一事实。

**辨析｜易错点：叠加不能用于功率。** 功率是电压电流的乘积，是**二次**量。$p = ui$，而 $u = u_1 + u_2$、$i = i_1 + i_2$ 时，$p \neq u_1 i_1 + u_2 i_2$，因为还有交叉项 $u_1 i_2 + u_2 i_1$。计算功率必须在**叠加完成之后**、用总的电压电流去算。这是叠加定理使用中最常见的误用。

数字例子：设两个独立源分别单独作用在某支路上产生 $i_1 = 2\,\text{A}$、$i_2 = -1\,\text{A}$，则总电流 $i = i_1 + i_2 = 1\,\text{A}$。但两个电源单独作用时的功率之和**绝不等于**总功率——交叉项 $u_1 i_2 + u_2 i_1$ 被丢掉，结论必然出错。

## 2 戴维南定理

**戴维南定理（Thévenin's theorem）**：**任何含独立源的线性二端网络，对外部都等效为一个理想电压源 $u_{Th}$ 与一个电阻 $R_{Th}$ 的串联。**

其中：

**$u_{Th}$：开路电压（open-circuit voltage）**，把外接负载断开，测量端钮间的电压。
**$R_{Th}$：等效电阻（equivalent resistance）**，把所有独立源置零（电压源短路、电流源开路）后，从端钮看进去的电阻。

有了戴维南等效，负载上的电压电流一算即得：负载 $R_L$ 接上去，$i_L = u_{Th}/(R_{Th} + R_L)$。<span class="marginnote">戴维南定理最常用的求法：先断开负载求开路电压 $u_{Th}$；再独立源置零求 $R_{Th}$；也可用「外加测试源法」——保留受控源、置零独立源，在端钮外加电压源 $u_t$ 测流入电流 $i_t$，$R_{Th} = u_t/i_t$。第二条路对含受控源的网络尤其好用。</span>

**核心概念**：**戴维南等效**：把任意线性含源二端网络，用「电压源串联电阻」两步等效，外部行为完全一致。它把「看电路板」变成「看一个电池加一个内阻」——这种抽象能力贯穿整个工程：信号源的输出阻抗、电池的内阻、电源的内阻抗，全是戴维南等效的化身。

## 3 公式解析：开路电压、等效电阻与最大功率传输

$$
i_L = \frac{u_{Th}}{R_{Th} + R_L}, \qquad
p_L = i_L^2 R_L = \frac{u_{Th}^2 R_L}{(R_{Th} + R_L)^2}
$$

- **$u_{Th}$：开路电压**，负载断开时端钮电压，由原网络全部独立源共同决定。
- **$R_{Th}$：戴维南等效电阻**，独立源置零后从端钮看入的电阻。
- **$R_L$：负载电阻**，接在端钮上的外部元件。
- **$i_L$、$p_L$：负载电流与负载吸收的功率**。

**最大功率传输定理**：当负载电阻等于戴维南等效电阻，即 $R_L = R_{Th}$ 时，负载获得最大功率：

$$
p_{L,\max} = \frac{u_{Th}^2}{4 R_{Th}}
$$

推导思路：对 $p_L(R_L)$ 求导令其为零。$\mathrm{d}p_L/\mathrm{d}R_L = 0$ 给出 $R_L = R_{Th}$，且二阶导为负，确为极大。直觉：$R_L$ 太小则分压太少，$R_L$ 太大则电流太小，两者权衡的平衡点恰在阻抗匹配处。<span class="marginnote">「阻抗匹配」四个字是第 9、10 篇的种子：在交流电路里，最大功率传输条件是负载阻抗等于源阻抗的共轭；在通信系统里，匹配还关系到信号反射，这要到《信息与通信工程》的传输线部分才会展开。</span>

注意，最大功率传输**不等于效率最高**：$R_L = R_{Th}$ 时效率只有 50%，另一半功率白白耗在内阻上。电力输电追求高效率，所以负载电阻远大于内阻；信号传输追求最大功率，所以故意让负载匹配内阻。**两个目标，两种取法——工程总是在「要功率」和「要效率」之间权衡。** 最大功率传输定理的前提是 $R_{Th}$ 为正；若电路含受控源出现「负阻」，模型可能给出功率无穷大的病理解，那是线性近似在极端参数下的失效信号。

## 4 诺顿定理

**诺顿定理（Norton's theorem）**：**任何含独立源的线性二端网络，对外部都等效为一个理想电流源 $i_N$ 与一个电阻 $R_N$ 的并联。**

其中 $i_N$ 是**短路电流**（把端钮短接后流过的电流），$R_N$ 与戴维南等效电阻相同：$R_N = R_{Th}$。

诺顿等效与戴维南等效是同一件事的两种面孔，二者通过**电源等效变换**互相转换：电压源 $u_{Th}$ 串电阻 $R_{Th}$ 与电流源 $i_N = u_{Th}/R_{Th}$ 并电阻 $R_N = R_{Th}$，对外部完全等效。这个「电压源串联 ↔ 电流源并联」的互换公式在本专题反复出现。<span class="marginnote">电源等效变换是「黑箱等效」最简单的例子：一个电压源串电阻，如果从外部看电流流向相同，就可以换成电流源并电阻。它只对端钮外部成立，电源自身消耗的功率在两模型中不同——再次说明「等效」只承诺对外行为一致。</span>

**辨析｜易错点：**诺顿等效与戴维南等效的转换方向别记反：戴维南是「电压源**串**电阻」，诺顿是「电流源**并**电阻」。短路电流 $i_N$ 与开路电压 $u_{Th}$ 的关系是 $u_{Th} = i_N R_{Th}$，方向取「电流从 + 端流出」时才成立。

两套等效的选择标准很简单：求短路电流比求开路电压容易就用诺顿，反之用戴维南。实际测量中，短路电流是把端钮直接短接后用电流表测，开路电压是断开负载后测——**哪个量更安全、更容易测，就用哪个等效**。

## 5 定理的适用范围

四条定理各有限制，混用时容易越界：

**叠加**：仅限**线性**电路（线性电阻 + 线性受控源）；非线性元件（二极管、晶体管）不适用。
**戴维南/诺顿**：仅限**线性**电路；但负载本身可以是任何元件，甚至可以是非线性的——定理只管网络内部。<span class="marginnote">这个细节很实用：当负载是二极管这类非线性元件时，用戴维南等效把网络浓缩成「源 + 内阻」，再对非线性负载用图解法（负载线），正是电子学课程里负载线分析的来历。</span>
- **最大功率传输**：需要先求出戴维南等效，且 $R_L$ 为纯电阻时才取 $R_L = R_{Th}$。
- **含受控源**：戴维南/诺顿求等效电阻时**保留受控源**、置零独立源，用外加测试源法。

**重点：线性是所有这些定理的根基。** 什么时候线性不成立？元件值随电压电流变化时（非线性电阻）、信号大到进入有源器件的饱和区时。此时叠加、戴维南全部失效，只能回到逐点分析或仿真。

叠加法的工程意义在于「拆解归因」：当电路性能不达标时，叠加让我们看清是哪个电源、哪条路径贡献最大，从而对症下药——这是调试复杂电路时最常用的「归因」思维。四条定理配合使用时，习惯顺序是：先叠加拆源，再戴维南/诺顿化简端口，最后按最大功率传输选负载——一套「化简工具箱」就此齐备。

还要注意：戴维南/诺顿等效不只对电阻网络成立，对含电容、电感的动态电路在**某一固定频率**下同样成立——只要把电阻换成阻抗、把电压电流换成相量，整套定理原样可用，这正是第 8 篇相量法扩展这套方法的依据。

### 一个完整示例：戴维南定理的实战

用一个具体流程把戴维南定理走一遍，求接在端钮上的负载 $R_L$ 的电流：

- **第一步，求开路电压 $u_{Th}$**：断开 $R_L$，用节点法或叠加求出端钮开路电压。叠加法尤其适合多源电路：让每个独立源单独作用算一次，再把贡献代数相加。
- **第二步，求等效电阻 $R_{Th}$**：把所有独立源置零（电压源短路、电流源开路），从端钮看进去，用串并联化简得 $R_{Th}$。
- **第三步，接回负载**：$i_L = u_{Th}/(R_{Th} + R_L)$，一算即得。

若电路含受控源，第二步改用**外加测试源法**：置零独立源、保留受控源，在端钮外加一个 $1\,\text{V}$ 的测试电压源，测流入电流 $i_t$，则 $R_{Th} = 1/i_t$。加 $1\,\text{V}$ 只是让除法好算，换成任意电压都行——比值 $u_t/i_t$ 与测试源取值无关。

数字例子：设 $u_{Th} = 12\,\text{V}$、$R_{Th} = 4\,\Omega$、$R_L = 8\,\Omega$，则 $i_L = 12/(4+8) = 1\,\text{A}$，$p_L = i_L^2 R_L = 8\,\text{W}$。把 $R_L$ 换成 $4\,\Omega$，$i_L = 1.5\,\text{A}$，$p_L = 9\,\text{W} = u_{Th}^2/(4R_{Th})$——正好落在最大功率点。两相对比可见「最大功率」与「更大电流」并不重合：$R_L = 2\,\Omega$ 时电流更大（$2\,\text{A}$），但功率只有 $8\,\text{W}$，已从峰值回落。

**辨析｜易错点：**开路电压的参考方向必须与最终负载电流的方向协调。若把 $u_{Th}$ 的参考方向画反，代入 $i_L$ 公式时就差一个负号——参考方向不统一，是戴维南应用里最常见的「差一个符号」事故。

若负载本身也是二端网络，戴维南等效对负载侧同样适用——网络与负载互为对方的戴维南对象，谁看谁都是「源 + 内阻」。这种「互相看」的视角，正是二端口网络（第 13 篇）思想的雏形。

## 6 小结

- **叠加定理**：线性电路中，响应 = 各独立源单独作用的代数和；受控源保留；**功率不可叠加**。
- **戴维南定理**：线性含源二端网络 = 开路电压 $u_{Th}$ 串等效电阻 $R_{Th}$。
- **诺顿定理**：同一网络 = 短路电流 $i_N$ 并电阻 $R_N$，与戴维南互相转换。
- **最大功率传输**：$R_L = R_{Th}$ 时 $p_{L,\max} = u_{Th}^2/(4R_{Th})$；但匹配 ≠ 高效率，电力输电追求效率反而不匹配。
- 四条定理都要求**线性**；求含受控源的等效电阻时，受控源**不能置零**，须用外加测试源法。
- 化简工具箱的配合顺序：先叠加拆源归因，再戴维南/诺顿化简端口，最后按最大功率传输选负载。

在下一节，我们将学习运算放大器与含受控源电路——受控源是这些定理的边界：叠加、戴维南都要求线性，而受控源正是线性电路分析里最常遇到的元件，也是最容易用错的那一个。
