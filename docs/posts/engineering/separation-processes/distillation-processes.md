## 为什么从精馏开始

精馏是分离工程当之无愧的「主角」。全世界每天被精馏处理的物料以千万吨计——从炼油厂的常减压塔到石化装置的乙烯塔、从酒精提纯到空气分离深冷精馏，它是工业上应用最广、研究最透的分离过程。本专题的骨架——**逆流级联 + 平衡级**——在精馏里得到了最完整的体现：一块塔板就是一个闪蒸平衡级，全塔就是几十上百级平衡级的逆流叠加，再加上「回流」这个点睛之笔，让分离能力比单级闪蒸高出几个数量级。<span class="marginnote">炼油厂一座常压塔可高达 60 米、内有 40–60 块实际塔板，每天处理十万吨级原油。精馏占化工能耗的比例常被引作「美国化工能耗的一半与精馏有关」。</span>

**精馏（distillation）**：利用组分**相对挥发度**的差异，通过反复部分汽化与部分冷凝，同时靠**回流**提供向下流动的液相，实现多级分离的过程。

## 1 塔的结构与两段划分

精馏塔可分为三段思维模型：

- **精馏段（rectifying section）**：进料位置以上。上升汽与回流液接触，把汽相中的轻组分「洗」得更纯，顶部得到高纯度**馏出液 D（distillate）**。
- **提馏段（stripping section）**：进料位置以下。下降液与再沸产生的汽接触，把液相中的重组分「赶」下去，底部得到**釜液 B（bottoms）**。
- **进料段（feed plate）**：进料在此进入，其热状态决定汽液两股流量的「跃变」。

塔顶冷凝器把全部汽冷凝，一部分作为产品 D 采出，另一部分**回流（reflux）**回塔；塔底再沸器把部分液体汽化，向上提供汽相。**回流比（reflux ratio）$R = L/D$**（$L$ 为回流量）是精馏最重要的操作参数。

**核心概念：全塔物料衡算**。对二元精馏，总衡算与轻组分衡算：

$$F = D + B, \qquad F z_F = D x_D + B x_B$$

其中 $z_F$、$x_D$、$x_B$ 分别为进料、馏出液、釜液中轻组分的摩尔分数。**这两条式子一旦给定 $F, z_F, x_D, x_B$，$D$ 与 $B$ 就完全确定**——分离结果被「产量守恒」锁死。

**塔顶冷凝的两种方式**：**全凝器（total condenser）**把塔顶汽全部冷凝，产品与回流都是液体，操作线方程最简；**分凝器（partial condenser）**只冷凝一部分，汽相产品直接采出，相当于塔顶多了一块平衡级。设计选哪种，取决于产品以汽相还是液相送出——这一点常被初学者忽略，却直接影响回流比与板数。

## 2 操作线与 McCabe-Thiele 图解法

精馏段与提馏段内的组成关系，可以用**操作线（operating line）**描述——它把某一截面处汽相组成 $y_{n+1}$ 与上一级液相组成 $x_n$ 联系起来。精馏段操作线：

$$y_{n+1} = \frac{R}{R+1}\,x_n + \frac{x_D}{R+1}$$

这是一条过点 $(x_D, x_D)$、斜率为 $R/(R+1)$ 的直线。**平衡线 $y = \alpha x/[1+(\alpha-1)x]$（或直接来自 VLE 数据）给「级内」，操作线给「级间」**——两者交替使用，就是图解法：

![McCabe–Thiele 图解法：平衡线与操作线之间的阶梯](/images/separation-processes/distillation-processes-1.svg)

从 $(x_D,x_D)$ 出发，水平走至平衡线得 $y_1$，垂直下落至操作线得 $x_1$，再水平……每一步代表一块理论板。**阶梯数 = 理论塔板数**。进料点的热状态用 **q 线**表示（$q$ 为进料中液相分率），它在两段操作线交点处「拐弯」。<span class="marginnote">McCabe–Thiele 法 (1925) 假设恒摩尔流（等 mol 溢流）：塔内汽液摩尔流量分段恒定，使操作线退化为直线。对大多数体系这一假设相当可靠。</span>

**q 线的五种面孔**（$q$ 是进料中液相分率，$r$ 为摩尔汽化潜热，$\bar h_F$ 为进料焓）：

| $q$ 值 | 进料热状态 | q 线形状 |
| --- | --- | --- |
| $q < 0$ | 过热蒸气 | 向右下斜 |
| $q = 0$ | 饱和蒸气 | 水平 |
| $0 < q < 1$ | 气液混合 | 向右上斜 |
| $q = 1$ | 泡点液体 | 竖直 |
| $q > 1$ | 过冷液体 | 向左上斜 |

**辨析｜易错点：** 阶梯要「水平到平衡线、竖直到操作线」，**顺序不能反**。水平步是「这一级达到平衡」（汽相变浓），竖直步是「下一级前的回流混合」（回到操作线）。反了，塔板数就算错了。

## 3 极限工况：全回流与最小回流比

两块「天花板」决定了塔的可行性边界：

**全回流（total reflux）**：$R\to\infty$，不采出产品，操作线与对角线重合，所需理论板数**最少**，记作 $N_{\min}$。对理想物系，由**芬斯克方程（Fenske equation）**直接给出：

$$N_{\min} = \frac{\ln\left[\left(\dfrac{x_D}{1-x_D}\right)\left(\dfrac{1-x_B}{x_B}\right)\right]}{\ln \alpha_{AB}}$$

**最小回流比（minimum reflux ratio）$R_{\min}$**：操作线与平衡线相切（或相交于 q 线与平衡线交点）时，所需塔板数**无穷多**。实际回流比通常取 $R = 1.1 \sim 1.5\,R_{\min}$。

**辨析｜易错点：** 全回流时塔「不产产品」——它是开车启动、测定塔板数的标准工况，不是运行工况；$N_{\min}$ 与 $R_{\min}$ 一个对应「最少板」，一个对应「最小回流」，**方向相反**，别记反。

**精馏的能耗与节能**：再沸器是塔的能耗中心，回流比越大能耗越高。工业节能三招：**热泵精馏**（把塔顶热量提升温度送回再沸器）、**多效精馏**（多塔串联、一塔塔顶给另一塔供热）、**侧线采出**（避免不必要的过纯分离）。「分离越彻底越贵」与这三招，是精馏经济性的两面。

## 4 算例：先估算，再数板

**问题**：苯-甲苯二元物系，进料 $z_F = 0.45$（苯摩尔分数，泡点进料 $q=1$），要求 $x_D = 0.98$、$x_B = 0.02$，$\alpha = 2.5$，取 $R = 1.2 R_{\min}$。估算最小回流比与理论塔板数。

- **第一步，求 $R_{\min}$**：泡点进料时 q 线竖直于 $x = x_F$。平衡线 $y^* = \dfrac{\alpha x}{1+(\alpha-1)x} = \dfrac{2.5\times0.45}{1+1.5\times0.45} = 0.671$。精馏段操作线过 $(x_D,x_D)$ 与夹紧点 $(x_F,y^*)$，得 $R_{\min} = \dfrac{x_D - y^*}{y^* - x_F} = \dfrac{0.98-0.671}{0.671-0.45} = 1.40$。
- **第二步，取实际回流比**：$R = 1.2 \times 1.40 = 1.68$。
- **第三步，Fenske + Gilliland 估算板数**：全回流下最少板 $N_{\min} = \dfrac{\ln(49\times49)}{\ln 2.5} = \dfrac{\ln 2401}{0.916} \approx 8.5$ 级。由 $X = \dfrac{R-R_{\min}}{R+1} = \dfrac{0.28}{2.68} = 0.104$，查 Gilliland 关联 $Y \approx 0.53$，得 $N \approx \dfrac{Y+N_{\min}}{1-Y} \approx 19.2$，**取 20 块理论板（含再沸器）**。<span class="marginnote">Gilliland 关联把 $N_{\min}$、$R_{\min}$、实际 $R$ 三个量用一张经验图串起来——它不给出精确值，而是给出「合理初值」。严谨设计会把它喂给严格逐板计算器复核，这正是下一篇的主题。</span>

**这个算例的三处意义**：其一，$R_{\min}$ 只由进料与产品组成决定，与塔板数无关；其二，Fenske 给出了「全回流下」这个理论极限，真实塔永远达不到，只能逼近；其三，**先估后精算**是化工设计的通用流程——手算给出数量级正确的初值，软件再精算修正。

## 5 塔板效率与实际塔板数

理论板假设「离开该级的汽液达平衡」，真实塔板达不到。用**默弗里板效率（Murphree efficiency）**修正：

$$E_{MV} = \frac{y_n - y_{n+1}}{y_n^* - y_{n+1}}$$

$y_n^*$ 是与液相组成 $x_n$ 平衡的汽相组成，$y_n$ 是实际离开汽相组成。$E_{MV}$ 通常取 0.6–0.8，**实际塔板数 = 理论塔板数 ÷ 板效率**。<span class="marginnote">板效率由汽液接触时间、传质系数（上一篇的 $k_c$）、流体力学状态决定。填料塔不用板效率，而用「等板高度 HETP」——把填料折算成相当于多高的一块理论板。</span>

## 6 公式解析：精馏段操作线

$$y_{n+1} = \frac{R}{R+1}\,x_n + \frac{x_D}{R+1}$$

三步拆解：

- **第一步，从哪里来**：对精馏段从第 $n$ 块板到塔顶做轻组分物料衡算——上升汽 $V y_{n+1}$ = 回流液 $L x_n$ + 馏出液 $D x_D$。
- **第二步，为什么是这条线**：全凝器下 $V = L + D$，令 $R = L/D$，两边同除以 $V$，斜率与截距自然出现：斜率 $R/(R+1) \in (0,1)$，截距 $x_D/(R+1)$。**回流比越大，操作线越靠近对角线，阶梯越矮、板数越少**——但能耗（再沸器供热）越大。
- **第三步，怎么用**：已知 $R$、$x_D$，操作线即画定；在平衡线与操作线之间走阶梯，数出精馏段理论板数。**「每走一个水平步，汽相就浓一次」——水平步的长度由平衡线决定，竖直步的长度由操作线决定**，两者共同把「一次闪蒸只能分离一点的限制」逐级放大。

## 7 小结

- **精馏 = 逆流级联 + 回流 + 再沸**：精馏段提浓、提馏段提纯、进料热状态决定 q 线。
- 全塔衡算 $F z_F = D x_D + B x_B$ 锁死产量与组成的守恒关系。
- **McCabe–Thiele 图解法**：平衡线管「级内」，操作线管「级间」，阶梯数即理论板数。
- **全回流**给最少板数 $N_{\min}$（芬斯克方程），**最小回流比**给最小回流 $R_{\min}$；实际取 $R=1.1\sim1.5 R_{\min}$。
- 真实塔用**默弗里板效率**修正：实际板数 = 理论板数 ÷ 效率。
- 进料热状态由 **q 值**决定，q 线决定两段操作线交点；塔顶可用**全凝器**或**分凝器**。
- 设计套路「先估后精」：先求 $R_{\min}$ 与 $N_{\min}$，再取实际 $R$ 用 Gilliland 关联估算板数。
- 节能三招：**热泵精馏、多效精馏、侧线采出**；再沸器是塔的能耗中心。
- 板效率与 HETP 是「理论级 → 实际级」的折算尺，$E_{MV}$ 常见取 0.6–0.8。
- 塔顶冷凝可用**全凝器**（产品为液）或**分凝器**（产品为汽，多一级平衡）。

在下一节，二元精馏的整套方法将面对真正的战场：工业塔大多是多组分体系，泡点、露点、夹紧点都不再唯一——这就是**多组分精馏的近似与严格计算**。
