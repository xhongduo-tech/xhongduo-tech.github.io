## 为什么从多组分开始

上一篇的 McCabe–Thiele 图解法优雅而清晰，但它只适用于**二元物系**。真实的工业塔几乎没有二元物系：炼油塔处理的是几十上百种碳氢化合物，石化塔里乙烯、乙烷、丙烯、丙烷挤在一起。二元精馏里「进料只有两个组分、塔顶塔釜各抓住一个」的干净局面消失了——**多组分精馏没有「唯一的产品夹紧点」，必须自己决定哪些组分算产品**。这带来两套并行的思路：**近似法**（几分钟手算给出塔板数与回流比的初值）与**严格法**（计算机逐板求解非线性方程组）。本篇把「先粗后精」的设计逻辑讲透，这也是所有工程软件（Aspen Plus 等）背后的思路。

**关键组分（key components）**：多组分塔中，把**轻关键组分（light key, LK）**定义为「在塔釜中还允许微量存在的最轻组分」，**重关键组分（heavy key, HK）**定义为「在塔顶还允许微量存在的最重组分」。LK 与 HK 之间的组分会被分离；比 HK 更重的组分基本只出现在釜液，比 LK 更轻的基本只出现在馏出液。<span class="marginnote">关键组分的选择是设计者拍板的设计变量——选哪个作 LK/HK，直接决定塔的分离任务与成本，这正是第一篇里「可调设计变量」的活例子。</span>

## 1 从二元到多组分：哪里变了

二元精馏之所以简单，是因为 $x_D$、$x_B$ 把产品组成完全钉死，全塔只有一个「夹紧点」（最小回流比处的 pinch）。多组分体系出现三个本质变化：

- **组成自由度暴增**：$C$ 个组分需要 $C-2$ 个**分配关系**（distribution）来规定各组分在塔顶塔釜的分配——通常由设计者指定 LK、HK 的回收率。
- **夹紧点不再唯一**：塔内可能出现**上夹紧点**（精馏段）与**下夹紧点**（提馏段）两处最小回流比约束，取其中较大者。
- **泡点/露点逐板变**：塔内温度从塔顶到塔釜连续变化，每块板的 K 值都不相同，McCabe–Thiele 的平面图解法彻底失效。

**术语速查**：关键组分（key components）→ 分配关系（distribution）→ 夹紧点（pinch point）→ 上/下夹紧点（upper/lower pinch）→ 全回流（total reflux）。

**塔压怎么定**：塔压决定泡露点温度，也决定每块板的 K 值。工业上常「用冷却水能冷凝的温度反推塔压」——塔顶温度须高于冷却水温以便冷凝，塔底温度不能过高以免热分解。塔压一变，相对挥发度与能耗都变，所以它是精馏设计里最早定下的变量之一，也是流程模拟器里首先要指定的设计变量。

**关键组分的选择为什么重要**：选 A/B 作 LK/HK，塔顶就几乎不可能再控住 C；选 B/C，则 A 几乎全进塔顶。**关键组分直接决定分离任务与塔的规模**——LK 与 HK 之间的相对挥发度越小、夹紧点越紧，塔板数与回流比就越大。工业上常靠「回收率的经济权衡」来定：把高价值组分的回收率拉高，等于同时付更多塔板与能耗，这个取舍是设计者的第一个决策。

## 2 FUG 近似法：半小时算一座塔

多组分精馏的经典近似法叫 **FUG 法**，三段式：

- **F — Fenske 方程**给出**最少理论塔板数 $N_{\min}$**（全回流下），推广到多组分：若已知 LK 与 HK 在塔顶塔釜的分配，则
  $$N_{\min} = \frac{\ln\left(\dfrac{x_{LK,D}}{x_{HK,D}}\cdot\dfrac{x_{HK,B}}{x_{LK,B}}\right)}{\ln \alpha_{LK,HK}}$$
  其中 $\alpha_{LK,HK}$ 取全塔**几何平均**相对挥发度。<span class="marginnote">Fenske 方程还能顺带给出<strong>其他组分在全回流下的分布</strong>——只凭 LK/HK 的分配比，全塔各组分的分布就被几何关系锁定了，这就是化工计算里「一个方程回收一列数字」的典范。</span>
- **U — Underwood 方程**给出**最小回流比 $R_{\min}$**。对多元物系要解一个关于根 $\theta$ 的方程：
  $$\sum_i \frac{\alpha_i z_i}{\alpha_i - \theta} = 1 - q$$
  取根 $\theta$ 介于 $\alpha_{LK}$ 与 $\alpha_{HK}$ 之间，再代入
  $$R_{\min} = \sum_i \frac{\alpha_i x_{i,D}}{\alpha_i - \theta} - 1$$
- **G — Gilliland 关联**把「$N_{\min}$、$R_{\min}$、实际 $R$」联系起来，用一个经验图或关联式给出实际理论板数 $N$：
  $$Y = \frac{N - N_{\min}}{N + 1} = f\left(X = \frac{R - R_{\min}}{R + 1}\right)$$

**辨析｜易错点：** FUG 法是**初值方法**——它假设恒摩尔流、平均挥发度、且未考虑温度逐板变化，只能给出「大概要多少板、多大回流」，**不是最终答案**。把 FUG 的 $N$、$R$ 当作设计终值，是工程新手最常见的偏差；严谨的做法是把它们喂给严格模拟器再精算。

**辨析｜易错点（回收率 vs 纯度）：** **回收率**指某组分在塔顶（或塔釜）被拿回多少，**纯度**指它在产品里占多少，两件事。给 LK 定 98% 回收率，不等于塔顶纯度 98%——纯度还要看比 LK 更轻的组分有没有混进塔顶。FUG 法先按回收率算板数，各组分分布与产品纯度由结果反查，两者不要混为一谈。

## 3 算例：Fenske 方程「一次回收一列数字」

**问题**：三元物系 A（轻）、B、C（重），进料 100 kmol/h，组成 $z_A=0.30,\ z_B=0.40,\ z_C=0.30$。选定 A 为轻关键组分、B 为重关键组分，规定 A 的塔顶回收率 98%、B 的塔底回收率 99%。相对挥发度 $\alpha_{A,B}=2.0$、$\alpha_{C,B}=0.5$。估算 $N_{\min}$ 与 C 在塔顶的分布。

- **第一步，由回收率定分配**：A 在塔顶 $d_A = 0.98 \times 30 = 29.4$ kmol/h；B 在塔釜 $b_B = 0.99 \times 40 = 39.6$，故 B 在塔顶 $d_B = 40-39.6 = 0.4$ kmol/h。
- **第二步，代入 Fenske 方程**：$N_{\min} = \dfrac{\ln[(x_{A,D}/x_{B,D})/(x_{A,B}/x_{B,B})]}{\ln\alpha_{A,B}} = \dfrac{\ln(29.4/0.4)}{\ln 2.0} = \dfrac{\ln 73.5}{0.693} \approx 6.2$ 级。
- **第三步，求 C 的分布**：Fenske 的推广形式 $d_C/d_B = (b_C/b_B)\,\alpha_{C,B}^{N_{\min}}$。C 比 B 重，几乎全部进釜 $b_C \approx 30$，$b_B = 39.6$；代入 $\alpha_{C,B}^{6.2} = 0.5^{6.2} \approx 0.0136$，得 $d_C \approx 0.004$ kmol/h——**塔顶 C 几乎为零**，比 B 重的组分自动「掉」进釜液。<span class="marginnote">这正是一句话：<strong>Fenske 方程不只会算板数，还能预报全塔各组分的分布</strong>。它把「回收率 → 塔板数 → 其他组分去向」一条链全部打通——工程师在拿到严格模拟结果前，靠它就能先在心里把塔的「性格」摸个大概。</span>

**由算例反推的三点直觉**：其一，**回收率是设计的输入，不是输出**——先拍定 LK/HK 的回收率，塔板数随之确定；其二，**$N_{\min}$ 只与相对挥发度和分配比有关**，与进料量无关，所以它是「塔的固有难度」；其三，**比 HK 更重的组分在设计上基本不用管**——它们自动去釜液，正如比 LK 更轻的自动去塔顶，真正要精算的只有 LK 与 HK 之间那部分。

## 4 MESH 方程：严格计算的骨架

严格逐板计算把每一块板写成一组方程。对第 $j$ 块理论板，四类方程合称 **MESH 方程组**：

- **M（Material）— 组分物料衡算**：$L_{j-1}x_{i,j-1} + V_{j+1}y_{i,j+1} + F_j z_{i,j} = V_j y_{i,j} + L_j x_{i,j}$
- **E（Equilibrium）— 相平衡**：$y_{i,j} = K_{i,j} x_{i,j}$
- **S（Summation）— 求和**：$\sum_i x_{i,j} = 1,\quad \sum_i y_{i,j} = 1$
- **H（Heat/enthalpy）— 能量衡算**：$L_{j-1}h_{j-1} + V_{j+1}H_{j+1} + F_j h_{F,j} = V_j H_j + L_j h_j$

对 $N$ 块板、$C$ 个组分的塔，MESH 共约 $N(2C+3)$ 个未知数与方程——高度非线性，必须迭代求解。<span class="marginnote">严格法的求解算法有两条路线：<strong>泡点法（bubble-point method）</strong>逐板修正温度满足 E、S 方程，再解三对角矩阵满足 M 方程，稳定但收敛慢；<strong>同时校正法（Naphtali–Sandholm）</strong>把全部 MESH 方程联立用牛顿法求解，收敛快但对初值敏感。FUG 法恰好为它们提供好初值——两条路线因此串联成一条流水线。</span>

**迭代流程（泡点法）**：先假定温度与汽液流率的初值（可用 FUG 结果）→ 逐板解 M 方程（三对角矩阵）得 $x_{i,j}$ → 由 E、S 方程算泡点温度修正 → 由 H 方程修正汽液流率 → 循环至收敛。**核心是三层循环：组成、温度、流率，层层咬合。**

**K 值的来源与收敛判据**：严格法每一步都要算每块板的 $K_{i,j}$，它来自**状态方程**（如 SRK、Peng-Robinson）或**活度系数模型**（如 NRTL、UNIQUAC）——温度、压力、组成一起决定 K。近似法只用平均挥发度，严格法却要逐板重算 K，这正是两者精度差异的根源。迭代以「物料衡算残差小于容差（如 $10^{-4}$）」为收敛，但工程上更要核**总物料守恒、回收率符合预期、温度剖面单调合理**——数值收敛不等于结果合理，经验检查永远是最后一道闸。

**对照表：近似法 vs 严格法**

| 项目 | FUG 近似法 | MESH 严格法 |
| --- | --- | --- |
| 前提 | 恒摩尔流、平均挥发度 | 真实物性、逐板温度 |
| 未知量 | $N$、$R$ 的初值 | 逐板 $x,y,T,L,V$ |
| 求解方式 | 手算、少量公式 | 迭代非线性方程组 |
| 用途 | 初值、方案快速筛选 | 最终设计、灵敏度分析 |

## 5 公式解析：一个 MESH 之 M

把组分物料衡算单独挑出来看：

$$L_{j-1}x_{i,j-1} + V_{j+1}y_{i,j+1} + F_j z_{i,j} = V_j y_{i,j} + L_j x_{i,j}$$

三步拆解：

- **第一步，读符号**：下标 $j$ 是板号；$L$、$V$ 是液相、汽相摩尔流量；$x$、$y$ 是液相、汽相组成；$F_j$ 与 $z_{i,j}$ 是板上的进料及其组成。
- **第二步，为什么是四项**：左边三项是「进」——上一块板流下的液、下一块板升上的汽、板上进料；右边两项是「出」——离开的汽与液。**「进 = 出」是稳态下组分守恒的唯一形式**。
- **第三步，怎么解**：M 方程里有三个未知量族（$x$、$y$、$L$、$V$），光靠它是闭不了环的——必须由 E 方程把 $y$ 换成 $x$，由 S 方程定温度，由 H 方程定流率。**MESH 四类方程各守一个位置，缺一不可**，这正是「方程组闭环」的思想：每类方程解决一类未知数。

## 6 小结

- 多组分精馏须先指定**关键组分（LK/HK）**，它决定分离任务与塔的规模。
- 多组分的三个新难点：**组成自由度、双夹紧点、逐板温度变化**。
- **FUG 近似法**：Fenske 求 $N_{\min}$，Underwood 求 $R_{\min}$，Gilliland 关联求实际 $N$——半小时的手算初值。
- **MESH 方程组**（物料 M、平衡 E、求和 S、焓衡算 H）是严格逐板计算的骨架。
- 严格法两条路线：**泡点法**（逐板迭代）与**同时校正法**（联立牛顿）；FUG 提供初值。
- FUG 法给出「回收率 → 板数 → 组分分布」的一条链，是拿到严格模拟结果前的标准初值。
- **关键组分（LK/HK）的选择**决定分离任务与塔的规模，是设计者的第一个决策。
- 严格法的 K 值来自**状态方程或活度系数模型**，逐板重算是它比近似法精确的根源。
- 收敛后必须过**工程合理性检查**：总衡算、回收率、温度剖面逐项核对。
- **塔压**由冷凝与再沸温度约束反推，是精馏设计最早定下的变量。
- **回收率 ≠ 纯度**：FUG 先按回收率算板数，产品纯度由分布结果反查。
- 上、下两个**夹紧点**分别给出一份 $R_{\min}$ 约束，取较大者作设计下限。
- 严格法输出要过「总衡算、回收率、温度剖面」三道经验检查才算数。
- 泡点法逐板迭代稳定但收敛慢，同时校正法收敛快但对初值敏感，FUG 恰好喂初值。
- 几何平均相对挥发度 $\alpha_{LK,HK}$ 是 Fenske/Underwood 的共同输入，取法要前后一致。
- 比 HK 更重的组分自动落釜、比 LK 更轻的自动落顶，严格法只需精算 LK 与 HK 之间。

在下一节，我们将从「用热分离」切换到「用质量分离剂分离」——**吸收与汽提**，气体里的组分怎样被液体「洗」走。
