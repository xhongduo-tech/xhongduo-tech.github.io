## 为什么从汽-液平衡开始

上一篇的结尾我们承诺要回答「两相怎样才算谈拢」——答案是**相平衡（phase equilibrium）**：汽液两相充分接触后，各组分在两相中的「逃逸倾向」相等，宏观上净传质停止。精馏塔能一层层把混合物提纯，靠的正是「每块板上汽液达成一次新的平衡」；而整个精馏计算的起点，是**一个阀——单级闪蒸（flash）**：让高压液体突然降压，一部分汽化，汽液分离，计算这「一瞬间」的平衡组成。本篇把「平衡」这件事讲透，下一篇的精馏塔就是无数个「闪蒸级」叠起来。

**汽-液平衡（vapor-liquid equilibrium, VLE）**：给定温度、压力、组成下，汽相与液相共存且无净传质的状态。它是分离工程里最重要的「宪法」——所有汽液分离设备能分到什么程度，都由它说了算。<span class="marginnote">VLE 背后是化学位的平等：$\mu_i^V = \mu_i^L$。化学位的概念与推导在第六级《热力学》中展开，本篇只用它的结果——K 值。</span>

## 1 从拉乌尔定律到 K 值

最朴素的汽液平衡是**理想物系**，由**拉乌尔定律（Raoult's law）**描述：理想溶液中组分 $i$ 的平衡分压正比于其液相摩尔分数：

$$p_i = x_i P_i^{\text{sat}}(T)$$

其中 $P_i^{\text{sat}}(T)$ 是纯组分 $i$ 在温度 $T$ 下的**饱和蒸气压**（安托因方程给出）。汽相分压占总压之比即汽相摩尔分数 $y_i = p_i/P$，于是

$$y_i = \frac{x_i P_i^{\text{sat}}}{P}$$

对稀溶液里的溶质（如空气溶于水、二氧化碳溶于醇），拉乌尔定律失效，改用**亨利定律（Henry's law）**：$p_i = x_i H_i$，$H_i$ 为亨利常数。<span class="marginnote">拉乌尔定律管「自己人」（溶质-溶质-溶剂相似），亨利定律管「外来户」（稀溶质）。两者的适用范围在《物理化学》/《热力学》有严格讨论。</span>

**饱和蒸气压与安托因方程**：纯组分的 $P_i^{\text{sat}}(T)$ 通常由**安托因方程（Antoine equation）**给出：$\log_{10} P^{\text{sat}} = A - \dfrac{B}{T + C}$，其中 $A、B、C$ 为组分常数（可查手册）。它把「温度 → 蒸气压」变成一次查表或一条公式，是汽液平衡计算的第一个数据入口——泡点、露点、K 值全部从它出发。

把汽液组成之比定义为**平衡比（K 值）**：

$$K_i = \frac{y_i}{x_i}$$

对理想物系 $K_i = P_i^{\text{sat}}/P$。$K_i$ 只与温度、压力、物系有关。组分间 K 值之比叫**相对挥发度（relative volatility）**：

$$\alpha_{ij} = \frac{K_i}{K_j}$$

**相对挥发度是判断「能不能用精馏分离」的第一把尺子**：$\alpha_{ij}$ 越远离 1，两组分越容易分开；$\alpha_{ij} = 1$ 时精馏无能为力。

**辨析｜易错点：** $K_i$ 不是常数——它随温度、压力剧烈变化（理想物系 $K_i = P_i^{\text{sat}}/P$，而 $P_i^{\text{sat}}$ 随温度按克劳修斯-克拉佩龙规律指数上升）。同一组分同一「温度压力」下 K 值唯一，**温度一变 K 就变**；相对挥发度 $\alpha_{ij}$ 随温度变化缓慢得多，所以才常被当作「近似常数」用于全程计算——这是精馏手算里最值得记住的一条性质。

## 2 泡点、露点与相图

有了 K 值，可以定义两个关键温度：

- **泡点（bubble point）**：给定液相组成与压力，开始出现第一个气泡的温度，满足 $\sum_i y_i = \sum_i K_i x_i = 1$。
- **露点（dew point）**：给定汽相组成与压力，开始凝出第一滴液体的温度，满足 $\sum_i x_i = \sum_i y_i / K_i = 1$。

温度在泡点与露点之间，体系呈汽液两相共存。<span class="marginnote">对二元理想物系，$\sum_i y_i = 1$ 这个条件可以直接解出泡点温度，再验算组成；对非理想物系则要迭代——这正是流程模拟器里最常见的「泡点迭代」循环。</span>

| 项目 | 泡点（bubble point） | 露点（dew point） |
| --- | --- | --- |
| 含义 | 液体出现第一个气泡 | 汽体凝出第一滴液体 |
| 判据 | $\sum K_i x_i = 1$ | $\sum y_i / K_i = 1$ |
| 温度关系 | 同组成下泡点 ≤ 露点 | 两者之间是两相区 |

二元理想物系的 T-x-y 图是理解一切汽液分离的地图：**汽相线（露点线）总在液相线（泡点线）之上**，水平线（等温线）与两线交出的 $x$ 与 $y$ 即平衡组成。**辨析｜易错点：** 泡点温度**不等于**露点温度——同一组成下泡点低于露点（除纯组分与共沸点外）。「泡点就是液体要沸腾的温度」没错，但「泡点=露点」是错的，两者之间正是两相区。

**非理想体系与共沸**：真实体系常偏离拉乌尔定律——正偏差大时会出现**共沸物（azeotrope）**：在共沸组成处汽液组成相同、$\alpha_{ij} = 1$，单靠普通精馏分不开，必须换分离剂（萃取精馏、共沸精馏）或改压力。闪蒸计算对非理想体系要把 K 换成活度系数修正的形式 $K_i = \gamma_i P_i^{\text{sat}}/P$，计算量陡增，但思路不变。

## 3 单级闪蒸与物料衡算

**闪蒸（flash）**：一股已知组成、温度、压力的进料，经节流阀降压（或加热）后进入闪蒸罐，部分汽化，汽液两相在罐内达到平衡后分开。这是最简单的平衡级，也是石油炼厂里最常见的一级分离（原油的一次闪蒸、脱气罐都是它）。

设进料 $F$ mol，汽化分率 $\psi = V/F$（$V$ 为汽相摩尔流量，$L$ 为液相），对组分 $i$ 做物料衡算：进 = 出，即

$$F z_i = V y_i + L x_i$$

代入 $y_i = K_i x_i$ 与 $V = \psi F,\ L = (1-\psi)F$，消去 $x_i$ 可得：

$$x_i = \frac{z_i}{1 + \psi(K_i - 1)},\qquad y_i = \frac{K_i z_i}{1 + \psi(K_i - 1)}$$

把 $x_i$、$y_i$ 代回归一条件 $\sum x_i = \sum y_i = 1$，得到决定 $\psi$ 的标量方程——**Rachford-Rice 方程**：

$$\sum_i \frac{z_i (K_i - 1)}{1 + \psi(K_i - 1)} = 0$$

只含一个未知数 $\psi$，可用牛顿法快速求解。<span class="marginnote">Rachford & Rice 方程 (1952) 把闪蒸从「三元联立」降维成「单变量寻根」——把方程组压成一维，是工程数学最漂亮的招式之一，牛顿法见第一级《微积分》。</span>解出 $\psi$ 后回代即得 $x_i$、$y_i$，再补一次能量衡算确定温度（绝热闪蒸）或供热量。

## 4 算例：闪蒸罐里的一次「分家」

**问题**：进料 100 mol，苯（1）与甲苯（2）等摩尔 $z_1 = z_2 = 0.5$，在某温度压力下 $K_1 = 2.0$、$K_2 = 0.5$，做一次闪蒸。求汽化分率 $\psi$ 与两相组成。

- **第一步，先判断在不在两相区**：泡点判据 $\sum K_i z_i = 2.0\times0.5 + 0.5\times0.5 = 1.25 > 1$；露点判据 $\sum z_i/K_i = 0.5/2.0 + 0.5/0.5 = 1.25 > 1$。两条都大于 1，处于两相区，可以闪蒸。<span class="marginnote">记忆口诀：<strong>泡点露点两条判据都大于 1，才落在两相区</strong>；只要有一条小于 1，进料在该温度压力下就已是单相（全液或全汽），闪蒸罐只会「原样通过」。</span>
- **第二步，解 Rachford-Rice 方程**：$f(\psi) = \dfrac{0.5(2.0-1)}{1+\psi(2.0-1)} + \dfrac{0.5(0.5-1)}{1+\psi(0.5-1)} = \dfrac{0.5}{1+\psi} - \dfrac{0.25}{1-0.5\psi} = 0$。解得 $\psi = 0.5$——正好一半汽化。
- **第三步，回代求组成**：$x_1 = \dfrac{z_1}{1+\psi(K_1-1)} = \dfrac{0.5}{1+0.5\times1} = 0.333$，$x_2 = 0.667$；$y_1 = K_1 x_1 = 0.667$，$y_2 = K_2 x_2 = 0.333$。

**由算例反推的三点直觉**：其一，**汽相里轻组分被「富集」了一倍**（0.667 vs 进料 0.5），液相里轻组分被「贫化」——一次闪蒸只富集这么多，想把 0.667 再往上推，就必须像精馏那样级联；其二，$\psi$ 直接由 K 值与进料组成决定，**与罐体大小无关**——罐子只负责「让平衡发生」，不负责「决定分多少」；其三，$K$ 值离 1 越远，闪蒸的富集效果越强，这是「相对挥发度决定分离难度」在单级上的直观体现。

## 5 公式解析：闪蒸罐里的总衡算

把闪蒸的骨架浓缩成一条式子：

$$F z_i = \psi F\, y_i + (1-\psi)F\, x_i$$

三步拆解：

- **第一步，读符号**：$F$ 进料摩尔流量，$z_i$ 进料中 $i$ 的摩尔分数；$V=\psi F$ 汽相流量，$L=(1-\psi)F$ 液相流量；$y_i$、$x_i$ 为汽、液相组成。
- **第二步，为什么成立**：稳态下组分 $i$ 进去多少就出来多少（无反应、无累积）——这就是质量守恒，也解释了闪蒸罐为什么必须做两股出口物流的衡算。
- **第三步，怎么用它**：$y_i = K_i x_i$ 给出第二个关系，两式联立解出 $x_i$、$y_i$。若已知 $\psi$，可直接算出组成；若闪蒸温度未定，则与泡点方程 $K_i x_i$ 的求和、能量衡算一起迭代。**闪蒸计算 = 一个衡算 + 一个平衡 + 一个求和的闭环**。

## 6 小结

- **汽-液平衡**是汽液分离的宪法；**拉乌尔定律**描述理想物系，**亨利定律**描述稀溶质。
- **K 值** $K_i = y_i/x_i$，理想物系 $K_i = P_i^{\text{sat}}/P$；**相对挥发度** $\alpha_{ij}$ 决定精馏的可行性。
- **泡点**与**露点**分别是「第一个泡」和「第一滴液」的温度，两者之差即两相区。
- **闪蒸**是最简单的平衡级；**Rachford-Rice 方程**把闪蒸算压缩为单变量寻根。
- 闪蒸计算闭环：**物料衡算 + 相平衡 + 组成求和**；一次闪蒸的富集能力有限，级联才能逼近极限。
- 判断两相区：**泡点判据与露点判据同时大于 1** 才可闪蒸，否则进料是单相。
- Rachford-Rice 方程把闪蒸算压成**单变量寻根**，牛顿法几步即收敛。
- 非理想体系会形成**共沸物**（$\alpha_{ij}=1$），普通精馏分不开，须换分离剂或改压力。
- $K_i$ 随温度压力剧变，而 $\alpha_{ij}$ 变化缓慢——所以相对挥发度常被当作全程常数。

在下一节，我们将把无数个「闪蒸级」逆着摞起来，加上回流，让分离能力指数级放大——这就是**精馏过程**。
