## 为什么从回环检测开始

后端优化再强，也只能摊平「图里已有的边」——而里程计给后端的长程约束是一条**误差单向累积**的链：走一圈回到原点，轨迹却不知道自己回到了原点。**回环检测（loop closure detection）**负责回答那个决定性的问题：**「我来过这里吗？」** 一旦答案是「是」，一条跨越长距离的长程边就被插入位姿图，把累积漂移一次性拉回——这正是后端从「局部一致」升级为「全局一致」的最后一环。

在「从极限到大模型」的体系里，回环检测是**检索（retrieval）与几何验证**的组合拳：词袋模型把「图像相似度」翻译成「词频向量的距离」，是信息检索思想进机器人感知的经典移植；深度学习描述子（NetVLAD 等）则是视觉表示学习与 SLAM 的第一次深度联姻。它也是「鲁棒感知时代」里最容易被低估却最致命的模块——回环出错，地图直接撕裂。

回环检测还与「从极限到大模型」主线里的大模型形成有趣呼应：视觉回环本质上是「在数十万张历史图像里做近实时近似最近邻检索」，与向量数据库（embeddings + ANN）是同一个问题的两种表述——前者用几何验证把关，后者用海量向量与 HNSW/FAISS 加速，思想同源。

## 1 回环要解决的核心矛盾

回环检测看似简单（「两帧像不像？」），实际藏着三个根本矛盾：

- **外观相似 ≠ 同一地点**：两间一模一样的白墙会议室、同一商场里重复的货架，外观几乎相同却不是同一位置——这叫**感知混叠（perceptual aliasing）**，是假回环的主要来源。<span class="marginnote">感知混叠是 Cadena 综述里反复强调的痛点：仅凭外观，回环检测无法区分「我回来了」与「我在另一个长得很像的地方」。对策是把外观相似度当作<strong>候选</strong>，再交给几何验证与后端滤波去判生死。</span>
- **同一地点 ≠ 外观相似**：同一面墙，白天与黑夜、晴天与雨天的外观天差地别——这叫**视角/光照变化（appearance change）**，是假阴性（漏检）的主要来源。
- **实时性 vs 记忆量**：环境越大，已见过的关键帧越多，搜索「我像不像历史中的哪一帧」的成本越高。

**重点：** 回环检测的所有算法，本质都是在「减少假阳性（不能乱认）」与「减少假阴性（不能漏认）」之间找平衡，并且要在**大数据库里做到近实时检索**。

## 2 词袋模型：把图像变成一篇「词汇文档」

**词袋模型（Bag of Words, BoW）**把图像类比成文档，把特征描述子类比成单词。流程四步：

1. **离线建词典**：用大量训练图像的特征描述子做 K 均值聚类，把描述子空间聚成 $V$ 个簇（如 $V=10^5$），每个簇中心就是一个「视觉单词」（visual word）。K 均值聚类的层级版本（k 叉树，如 DBoW 的树）让检索变快。
2. **在线量化**：一张新图像的每个特征描述子，分配到最近的单词，统计每个单词出现的次数——图像就变成一个 $V$ 维词频向量 $\mathbf{v}$。
3. **相似度打分**：两图的相似度用向量距离（如 $L_1$ 距离）衡量：

$$s(\mathbf{v}_1, \mathbf{v}_2) = 1 - \frac{1}{2}\left\| \frac{\mathbf{v}_1}{\|\mathbf{v}_1\|} - \frac{\mathbf{v}_2}{\|\mathbf{v}_2\|} \right\|_1$$

4. **阈值与序列**：相似度超过阈值即认为候选回环；再配合**相邻帧序列投票**（连续多帧都指向同一历史位置才接受），进一步压低假阳性。

层级词典的检索细节也值得交代：DBoW 把词典建成一棵 **k 叉树**（每层把特征空间分 $k$ 簇），查询时从根出发逐层比较、只在少数叶子路径上展开，把「与 $10^5$ 个单词逐一比对」的代价降成「沿树走 log 步」——这是回环检索能实时跑的关键。词典规模本身也可变：$V$ 越大区分度越高、但泛化越差，$10^4$–$10^5$ 是实践中的常见量级。

**重点：** BoW 的致命弱点是**描述子本身的区分度**——ORB 这类手工描述子对光照、视角变化敏感，所以纯 BoW 在剧烈外观变化下表现糟糕。这给深度学习描述子留出了位置。<span class="marginnote">词袋模型的名字来自文本检索的 TF-IDF：视觉单词也按「稀有度」加权——出现得越少的单词（越独特的特征）对相似度贡献越大，这与 TF-IDF 完全同构。DBoW2 是 ORB-SLAM 采用的实现。</span>

## 3 公式解析：词袋相似度的直觉

相似度公式看着只是距离，背后有三层直觉：

- **第一步，归一化**：$\mathbf{v} / \|\mathbf{v}\|$ 把词频向量拉成单位方向——目的是让「图像里特征总数」不干扰相似度（两张图一张有 1000 个特征、另一张 100 个，只要分布相同就算相似）。
- **第二步，$L_1$ 距离**：$\|\mathbf{v}_1 - \mathbf{v}_2\|_1$ 逐维算「词频差的绝对值之和」。两图共享的单词越多、各单词计数越接近，这个数越小。
- **第三步，翻转成相似度**：减去距离并加 1，让「完全一样」时取 1、「完全无关」时趋近 0，便于设阈值。

**辨析｜易错点：** 相似度打分只看「有没有共同单词」与「词频像不像」，**完全无视单词的空间位置**——一幅画里的猫在左边还是右边，词袋不关心。这就是为什么词袋只能当「候选生成器」，必须靠后续的几何验证把关。

举个数值例子：假设词典只有 4 个单词，当前帧的词频向量 $\mathbf{v}_1 = (3, 0, 1, 0)$，某历史帧 $\mathbf{v}_2 = (3, 0, 1, 2)$。归一化后 $L_1$ 距离为 $|\tfrac{3}{4}-\tfrac{3}{6}| + |0| + |\tfrac{1}{4}-\tfrac{1}{6}| + |0-\tfrac{2}{6}|$，相似度明显低于两帧完全一致时的 1——差异主要来自历史帧多出两个「单词 4」。**回环阈值就设在「相似到足以相信，又足够高到不信巧合」的那个点，实践中常结合时序投票来确定。**

## 4 几何验证：用几何给外观「验明正身」

词袋给出的候选回环，要做两层几何验证才敢信：

- **对极约束 / PnP 验证**：在候选帧与当前帧之间匹配特征，用 RANSAC 拟合对极约束（2D–2D）或 PnP（3D–2D），若内点比例足够高，说明这两帧确实**几何一致**，假回环被拒。
- **时序一致性**：当前帧连续 $N$ 帧都命中同一历史位置，才提交回环——因为真回环通常持续数帧，而误报往往是孤立的。
- **共视一致性**：候选帧与当前帧共视的地图点（同一批三维点）应该形成一致的结构，用共视图或遮挡一致性检查，能把「相似但位置错开」的假候选再滤一层。

几何验证把「外观候选」升级为「几何事实」，是回环检测里防假阳性的最后一道闸门。ORB-SLAM 的回环线程正是在词袋候选 + 对极约束验证 + 位姿图优化三步间流转。需要强调的是，几何验证**必须与词袋是两套独立的特征**——否则验证只是「复述了候选的判断」，失去独立纠错的意义。

## 5 概率回环：FAB-MAP 的贝叶斯路线

词袋把回环当成「相似度打分」，FAB-MAP（Cummins & Newman, 2008）则把它当成**贝叶斯推理**：把「当前位置 $L$ 与历史位置 $L_i$ 相同」当作待估的隐藏状态，用贝叶斯公式递归更新每个位置的后验概率，并显式建模「从未见过的新地点」这一可能。它的关键创新是**Chow-Liu 树**——用树结构近似词袋特征之间的条件依赖，在保持可计算的同时纠正「特征独立」这一过强假设。

**重点：** FAB-MAP 与词袋的区别不是「谁更先进」，而是**不确定性意识**——FAB-MAP 会给出「我 87% 确信回到位置 3」这种带置信度的结论，并自然地处理「没见过的新地方」。这在长时自主（同一个环境跑很多天）里价值巨大：系统必须区分「回环」「新地点」「与旧地点相似但不同」三种状态。现代系统（如 DBoW2）往往在词袋快速候选之上，用 FAB-MAP 式的概率与几何验证做二次确认。

## 6 评测：回环的命门是精准率

回环检测的性能用**精准率-召回率（precision-recall）**曲线衡量：精准率 = 「被认可的回环里真回环的比例」，召回率 = 「真回环里被找出来的比例」。SLAM 对回环有一个不成文的铁律：**宁可不回环，不可错回环**——一个假回环会把整张地图撕成两半，且极难自动恢复。<span class="marginnote">这正是为什么回环检测必须「几何验证 + 时序一致」双保险：召回率可以靠阈值放松来提，精准率却要靠机制来守。Cadena 综述里专门强调，鲁棒感知时代对回环的首要要求是极低的假阳性率。</span>

评测的实践标准是公开基准：北大的 **Nordland**（同一路线四季视频）、**Oxford RobotCar**（同一道路多天气多月）等数据集专为「光照/季节变化下的回环」而生，深度学习描述子的论文几乎都要在上面报告 PR 曲线。

## 7 深度学习描述子：让「像不像」由数据说了算

2016 年以来，深度学习描述子大举进入回环检测：

- **NetVLAD（Arandjelović, 2016）**：把 CNN 特征图做成可微的 VLAD 池化，训练目标就是「同一地点图像靠拢、不同地点远离」，在 Place Recognition 基准上大幅刷新词袋。
- **SuperPoint / SuperGlue**：用学习到的关键点与匹配器替代 ORB + 词袋，配合几何验证，回环的鲁棒性在弱纹理与视角变化下显著提升。
- **序列匹配**：SeqSLAM 等用「连续帧序列」而非单帧比对，在剧烈光照变化（同一地点白天黑夜）下仍能回环。

一个值得注意的趋势：2023 年后的视觉语言模型（CLIP 类）也能当回环描述子——把图像与历史图像一起编码到共享语义空间，用文本提示（「这是同一个停车场吗」）辅助判断。这类方法仍处研究前沿，但「用大模型做地点识别」已经不再是论文里的空想，而是回环检测向语义靠近的又一方向，我们将在《语义 SLAM》一篇继续这条线。

**核心对比表：BoW vs 深度学习描述子**：

| 维度 | 词袋（BoW/DBoW2） | 深度描述子（NetVLAD 等） |
| --- | --- | --- |
| 特征 | 手工（ORB） | 数据学得（CNN） |
| 检索速度 | 快（树 + 汉明距离） | 需 GPU/加速 |
| 光照鲁棒 | 弱 | 强 |
| 代表系统 | ORB-SLAM | VPR 评测前沿 |
| 硬件要求 | CPU 可跑 | 常需 GPU/专门加速 |

## 8 回环之后：与后端的接口

回环不是终点，而是**起点**：一条回环边确认后，要估计相对位姿（PnP / 对极）并作为长程因子插入位姿图；后端随即重优化，把漂移摊平；如果尺度漂移大（单目），还要先做 Sim(3) 优化对齐尺度（见后端一篇）。**回环与后端是一对「检测—响应」的握手**：检测决定「何时、哪两帧」，响应决定「把什么边、以什么权重交给优化」。

## 9 小结

- 回环检测回答「我来过这里吗」，是全局一致性的**唯一**来源；Cadena 直言没有回环 SLAM 退化为里程计。
- 核心矛盾：**感知混叠**（假阳性）与**外观变化**（假阴性）要同时对付。
- **词袋模型**把图像变成词频向量，用 $L_1$ 距离打分，配合序列投票做候选生成。
- **几何验证**（对极/PnP + RANSAC）把外观候选升级为几何事实，是防假阳性的闸门。
- **深度描述子**（NetVLAD、SuperGlue）用数据学到的表示，扛住了光照与视角变化。
- 回环确认后通过估计相对位姿、插入位姿图，与后端形成「检测—响应」闭环。
- 评测标准是 PR 曲线与公开数据集（Nordland、Oxford RobotCar）；铁律是「宁可不回环，不可错回环」。
- 回环检索与向量数据库（embedding + ANN）同源，是大模型时代检索思想的前身。

在下一节，我们将离开视觉，转向另一种王者传感器——**激光 SLAM（LOAM 谱系与点云配准 ICP/NDT）**。视觉回环靠「像不像」，激光回环则从几何本身出发，两种思路将在《鲁棒性》一篇汇合。回环是视觉的补完，也是理解「为什么有的 SLAM 系统永远不需要回环也能跑」的对照——而那个问题的答案，恰恰藏在激光的绝对尺度里。
