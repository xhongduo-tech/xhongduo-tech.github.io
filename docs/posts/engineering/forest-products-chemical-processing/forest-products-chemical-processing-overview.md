## 为什么从概论开始

本专题前面四篇，把木材的化学组成（第一篇）、制浆造纸（第二篇）、热解与水解（第三篇）、林产化学品与提取物（第四篇）各讲了一遍。但读到这里，我们手里有二十八章的知识，却还缺一张地图——它们如何连成一个整体？**林产化学加工（chemical processing of forest products）**，正是林业工程一级学科下把这二十八章收拢起来的二级学科：以木材、竹材及其他植物生物质为原料，研究其化学组成、分离转化与产品深加工的工程科学与技术。<span class="marginnote">「林产」二字，把原料限定在<strong>可再生、来自森林的植物生物质</strong>，而非任何生物质——石油是化石，森林是活资产；这正是本学科与石化工业最本质的分野。</span>

老子说「合抱之木，生于毫末」，林产化学加工正是把一棵树的「毫末」——纤维素、半纤维素、木质素、抽提物——各自培育成参天的产业。第五篇从概论开始，是把前面四篇的知识串成一条完整的产业链。<span class="marginnote">这张地图也衔接整个课程体系：上游是《林木遗传育种》《森林培育》等林业基础，下游是《化学工程》《化工原理》与《绿色化学》；本专题处在「森林资源 → 化工产品」的中间枢纽。</span>

## 1 林业生物质资源：原料从哪里来

林产化学加工的原料，通称**林业生物质资源（forest biomass resources）**，可以按来源与形态分层：

**按原料种类分**，主要有五类：

- **针叶材**：马尾松、落叶松、云杉、冷杉。针叶材木素以愈创木基（G 型）为主，含较多树脂，是硫酸盐法制浆与采脂的经典原料。
- **阔叶材**：杨树、桦木、桉树、椴木。阔叶材木素含紫丁香基（S 型），木聚糖含量高，纤维较短但木质部致密，是制浆与板材的常见原料。
- **竹材**：毛竹、慈竹。竹材纤维含量高、生长极快（毛竹 3–5 年即可采伐），是中国南方制浆与竹材加工的特色原料。
- **林区剩余物**：采伐剩余物（枝桠、梢头、伐根）、造材剩余物、加工剩余物（锯末、刨花、边角料）。
- **林特产品与野生植物**：松脂、五倍子、栲胶原料（橡椀、树皮）、野生芳香植物（樟树、肉桂、桉树）。

**按产业地位分**，还要算上**废旧木材**（废旧家具、建筑模板、包装木箱）——它们构成「林产循环利用」的新来源。全球森林面积约 40 亿公顷，中国森林面积约 2.3 亿公顷、森林覆盖率约 24%<span class="marginnote">数字为概数：据 2021 年公布的第九次全国森林资源清查（截至 2018 年底），中国森林面积 2.2 亿公顷、覆盖率 22.96%；林业生物质是唯一既可再生、又可降解、又可固碳的工业原料。</span>，是世界上森林面积最大的国家之一。但可再生不意味着取之不尽——**采伐量必须小于年生长量**，这是林产加工的第一条产业伦理。

## 2 三大组分与化学加工的基本盘

把任何木材烘干称重，化学组成大致是一张稳定的账：

| 组分 | 针叶材（质量分数） | 阔叶材（质量分数） | 化学本质 |
| --- | --- | --- | --- |
| 纤维素 | 40–45% | 40–45% | β-1,4-葡聚糖，结晶微纤丝 |
| 半纤维素 | 20–25% | 25–35% | 木聚糖/葡甘露聚糖等非均聚糖 |
| 木质素 | 25–30% | 20–25% | 苯丙烷单元的芳香族高聚物 |
| 抽提物 | 3–8% | 2–5% | 树脂酸、萜烯、酚类、脂肪酸 |
| 灰分 | 0.2–1% | 0.2–1% | 无机盐、硅酸盐 |

**这五列就是林产化学加工的「基本盘」**：每一类组分对应一类工艺、一类产品。纤维素和半纤维素是碳水化合物，走水解、发酵、造纸；木质素是芳香族高聚物，走碱液溶解、热解、磺化；抽提物含量虽少，却单价高、能直接进化工品。第一篇的六章，就是在为这张表里每一行立传。

## 3 产业链：从森林到货架

林产化学加工的产品链，可以画成一张「原料 → 一级产品 → 深度产品」的网：

- **制浆造纸链**：木材 → 木片 → 纸浆（硫酸盐浆/亚硫酸盐浆/机械浆）→ 漂白浆 → 纸与纸板；副产品黑液 → 碱回收 → 能量与化学品。
- **热解链**：木材 → 干馏 → 木炭、木醋液、木焦油、木煤气；木炭 → 活性炭。
- **水解链**：木材 → 酸水解 → 木糖、葡萄糖 → 糠醛、乙酰丙酸、木糖醇、低聚木糖、乙醇。
- **林产化学品链**：松脂 → 松香、松节油 → 改性松香（酯胶、歧化松香）；栲胶原料 → 单宁提取物；樟树 → 樟脑、樟油。
- **能源与材料链**：生物质 → 气化/热解 → 合成气、生物油；纳米纤维素、木基复合材料。

**辨析｜易错点：** 「林产化学加工」不等于「造纸」。造纸只是它最大的一条产品线，而松香、单宁、精油、活性炭、糠醛、木质素化学品这些**林产化学品**同样居于核心。把本学科窄化为「制浆造纸工程」，是初学者最常见的误解——正确理解是：**制浆造纸是林产化学加工的一个方向，而非全部**。

这条产品链还有一个共性：**组分越少、越「边缘」，单价往往越高**。一吨木材做成纸浆只值几百到上千元，抽提物做成精油或松香却可值数万元——「吃干榨净、梯级利用」是贯穿全专题的经济主线，也是第三篇《生物质精炼》那句话「燃料是下限、化学品是上限」的产业背景。

## 4 公式解析：湿基与全干基含水率

做任何物料衡算，第一步都是把「湿木头」换算成「绝干木头」，这就绕不开含水率的两种约定。设湿木材质量为 $m_w$、绝干质量为 $m_d$，则：

$$
\text{湿基含水率 } W = \frac{m_w - m_d}{m_w} \times 100\%
$$

$$
\text{全干基含水率 } W_d = \frac{m_w - m_d}{m_d} \times 100\%
$$

对这条式子做三步拆解：

- **第一步，两个定义的分母不同**：湿基除以「湿重」（含水的总重），全干基除以「绝干重」。同一个试样，全干基含水率恒大于湿基含水率——因为分母更小。
- **第二步，换算关系**：若已知湿基 $W$，则全干基 $W_d = \frac{W}{1-W}$。例如湿基含水率 50% 的木材，全干基含水率是 100%。
- **第三步，为什么必须统一**：不同国家标准在买卖木材、标定浆料浓度时采用不同约定；化学加工中「每吨绝干木材」是衡算基准，若把湿基当全干基用，一吨木材里的组分质量会被系统性高估。**这是全部物料衡算的起跑线**。

## 5 我国林产化学加工的历史与现状

林产化学加工在中国有深厚的产业根基。**松香**是近代第一个登上世界舞台的产品：马尾松松脂产量长期居世界前列，中国一度是全球最大的松香生产国与出口国，20 世纪 80–90 年代年产量约 30–50 万吨，远销日、欧。<span class="marginnote">松香被称为「工业味精」——量不大、用途极广：造纸施胶、油墨、胶黏剂、肥皂、涂料都要它，一个国家的松香产量常被视为其精细化工水平的标尺。</span>

**栲胶与单宁**：20 世纪 50 年代为配合制革工业，我国在东北、西南建立了一批栲胶厂，原料以落叶松树皮、橡椀、杨梅树皮为主。**樟脑**：江西、福建的樟脑与樟油加工自清末即有规模，樟脑长期是出口创汇的林产化学品。**活性炭**：改革开放后中国成为全球活性炭生产与出口大国，以木质炭与煤质炭两条路线并进，年产能超过 50 万吨。**制浆造纸**：中国纸及纸板产量自 2009 年起居世界第一，年产量超过 1.2 亿吨，其中木浆占比持续提升。

**辨析｜易错点：** 「林产化学加工」与「林产化工产品」的边界——前者是**工程学科**（工艺、设备、流程），后者是**产品集合**（松香、单宁、精油……）。同一门课里「工艺学」讲前者，产品目录讲后者；读教材时不要混淆「松香加工工艺」与「松香产品标准」这两个概念层次。

## 6 学科位置与课程地图

在林业工程一级学科里，林产化学加工工程与木材科学与技术、林业装备、森林工程并列。把它放进「从极限到大模型」的课程体系：上游连接第二级《有机化学》（纤维素、木质素的化学）与《分析化学》（组分定量），横向上与第三级《化工原理》（蒸馏、浸提、干燥）互为工具，下游通向《绿色化学》与《生物化工》。第五篇接下来的八章，就是把这套体系按「原料 → 产品」再走一遍的复习总图。

**本节关键词速查**：

- **林产化学加工**：以森林植物生物质为原料，进行化学分离、转化与产品深加工的工程学科，林业工程一级学科下的二级学科。
- **林业生物质资源**：针叶材、阔叶材、竹材、林区与加工剩余物、林特产品等森林来源的可再生原料。
- **三大组分**：纤维素、半纤维素、木质素——构成细胞壁的主体，占木材干重约 90% 以上。
- **抽提物**：树脂酸、萜烯、酚类、脂肪酸等可被溶剂抽出的少量组分，含量低、单价高。
- **湿基/全干基含水率**：$W=\frac{m_w-m_d}{m_w}$、$W_d=\frac{m_w-m_d}{m_d}$，换算 $W_d=\frac{W}{1-W}$。
- **产业伦理**：采伐量小于年生长量，可再生原料才能持续供给。

**出处与延伸阅读**：

- **本节出处**：《林产化学工艺学》（中国林业出版社）总论部分；《木材化学》（中国林业出版社）第1章「木材的化学成分」。
- **延伸阅读**：关于林业生物质资源量与中国森林资源状况，见国家林草局历次全国森林资源清查公报；关于生物质精炼的整体观，见 E. Sjöström《Wood Chemistry》第11章。
- **相关方法**：木材化学组成分析（抽提、酸水解、Klason 木素测定）、含水率测定（烘箱法）。

## 7 小结

- 林产化学加工 = **以森林植物生物质为原料，进行化学分离、转化与产品深加工**的工程学科，原料可再生、可降解、可固碳。
- 原料分五类：**针叶材、阔叶材、竹材、林区与加工剩余物、林特产品**；利用前提是采伐量小于年生长量。
- 木材化学组成的基本盘：**纤维素、半纤维素、木质素、抽提物、灰分**，每类组分对应一类工艺与产品。
- 产品链五条：**制浆造纸、热解、水解、林产化学品、能源与材料**；制浆造纸只是最大方向而非全部。
- 含水率有**湿基与全干基**两种约定，换算关系 $W_d = \frac{W}{1-W}$，物料衡算必须先统一基准。
- 产业格局：**松香、活性炭、造纸产量中国均居世界前列**；「组分越边缘、单价越高」是梯级利用的经济主线。
- 学科定位：林产化学加工是**林业工程下的二级学科**，介于林业基础与化工原理之间，下游接绿色化学与生物化工。
