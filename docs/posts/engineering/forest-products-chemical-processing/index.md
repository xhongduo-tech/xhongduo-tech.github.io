# 林产化学加工工程

林业工程一级学科下的二级学科，以木材、竹材及其他植物生物质为原料，研究其化学组成、分离转化与产品深加工的工程科学与技术，覆盖制浆造纸、林产化学品、木材热解水解与生物质精炼等方向，是从可再生林业资源通向化工产品产业链的关键学科。

## 对标教材

- 《林产化学工艺学》（中国林业出版社）
- 《木材化学》（中国林业出版社）
- E. Sjöström《Wood Chemistry: Fundamentals and Applications》(Academic Press)
