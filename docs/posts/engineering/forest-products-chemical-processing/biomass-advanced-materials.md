## 为什么以新材料收束整个专题

本专题从一棵树的化学组成讲起，走过制浆、热解、水解、林产化学品、提取物与能源——木材被做成了纸、炭、香、药、燃料。但林产化学加工还有更高的出口：**材料**。荀子说「青出于蓝而青于蓝」，自然界给了纤维素与木质素，人类要做出比原木更强、更轻、更聪明的材料。纳米纤维素、木基复合材料与生物基塑料，正是「以可再生原料支撑先进制造」的绿色答卷。本节是本专题最后一课，纯概念主题，用**核心对比表**替代公式解析，并以全专题收束。

## 1 纳米纤维素：把木头拆到纳米级

**纳米纤维素**是把纤维素纤维拆解到纳米尺度得到的胶体材料，分两大类，制备与形态迥异：

**纤维素纳米晶（CNC）**：用 60–65% 硫酸在 45–60°C 水解，把无定形区溶掉，剩下**棒状结晶**（长约 100–500 nm、宽 5–20 nm）。CNC 结晶度高、刚性大、呈液晶排列，表面带硫酸酯基、在水中稳定分散。<span class="marginnote">CNC 的杨氏模量理论值可达 100–160 GPa，比钢（约 200 GPa）低但密度只有钢的五分之一左右，比强度反而更优——「轻而硬」让它成为增强填料与结构材料的明星。</span>

**纤维素纳米纤丝（CNF）**：通过**机械研磨、高压均质或 TEMPO 氧化+机械解纤**把纤维逐层剥离，得到**长而柔韧的纤丝**（长数微米、宽 5–50 nm）。CNF 长径比大、网络成膜性好，可制透明高强膜、水凝胶、气凝胶。<span class="marginnote">CNC 与 CNF 的制备哲学不同：CNC 是「化学腐蚀掉无定形区」，CNF 是「物理/化学力把纤维劈开」——一个求晶须、一个求纤丝。</span>

纳米纤维素的应用仍在快速扩展：作纸与塑料的**增强填料**（少量即显著提升强度）、作**阻隔涂层的透明包装膜**、作**水凝胶与伤口敷料**的基材、作**电子产品柔性基底**、甚至作**气凝胶**保温材料。它的共同卖点是三条：可再生、可降解、性能不输合成材料。<span class="marginnote">纳米纤维素产业化目前卡在「成本与能耗」——机械解纤耗电大、酸水解耗酸与废液处理，降本是它从实验室走向工厂的最大课题，也是林产化学加工工程可以大展身手的舞台。</span>

## 2 木基复合材料：把原木重组

**木基复合材料**以木材/竹材为原料，经碎化、施胶、热压重组，用途广、原料利用充分：

| 产品 | 原料形态 | 特点与应用 |
| --- | --- | --- |
| 胶合板（plywood） | 旋切单板 | 强度高、幅面大，建筑模板、家具 |
| 刨花板（particleboard） | 刨花 | 成本低、表面平整，家具芯板 |
| 纤维板（MDF/HDF） | 纤维 | 密度可控、加工性好，中/高密度板 |
| 木塑复合材料（WPC） | 木粉+塑料 | 耐水耐腐，户外铺板、护栏 |

**辨析｜易错点：** 木基复合材料不是「把木头压扁」，核心是**胶黏剂**。胶合板、刨花板、纤维板都靠胶黏剂把碎化单元粘成整体，胶的性能与环保性（游离甲醛）决定产品等级——「无醛胶」是木工胶领域的长期命题，单宁-甲醛、大豆蛋白胶等生物质胶黏剂由此登场，与第六篇栲胶单宁的应用呼应。

另外注意：「胶合板与纤维板」不是同一种原料形态的产物——胶合板用**旋切单板**，刨花板用**刨花**，纤维板用**纤维**。原料形态决定产品结构与性能，也决定了能耗与成本层级。

## 3 生物基化学品与绿色化工

**绿色化工**追求用可再生原料、少污染、可降解的工艺替代石化路线，生物质是其中的核心原料来源：

- **生物基塑料**：乳酸发酵聚合得**聚乳酸（PLA）**，可降解、用于餐具与包装；PHA、PBS 等亦在产业化。
- **FDCA 平台**：5-羟甲基糠醛（5-HMF）氧化得 **FDCA**，与乙二醇聚合得 **PEF**——对标石油基 PET 的下一代聚酯。
- **木质素高值化**：木质素制**碳纤维**前驱体、香兰素、分散剂（衔接第二篇木质素化学品一章）。
- **生物基胶黏剂与涂料**：单宁-甲醛、大豆蛋白胶、木质素聚氨酯，逐步替代石化胶黏剂。

<span class="marginnote">绿色化工有一条金线——<strong>原子经济</strong>：产物分子里包含反应物越多的原子越好，副产物越少越好。生物质自带氧、氮官能团，往往比石化中间体更「经济」地合成含氧化学品——这是生物基路线在部分产品上的本质优势。</span>

以**木质素制碳纤维**为例：传统碳纤维用聚丙烯腈（PAN）前驱体，成本高、源自化石；木质素碳含量高（约 60% 以上）、储量巨大，是最受关注的可持续前驱体候选——经熔融纺丝、稳定化、碳化可得碳纤维，缺点是石墨化程度与强度仍低于 PAN 基，正在以共混、改性改善。这类「从废料里长出先进材料」的路线，正是绿色化工对林产化学加工最激动人心的新命题。

## 4 核心对比表：CNC 与 CNF

| 维度 | CNC（纤维素纳米晶） | CNF（纤维素纳米纤丝） |
| --- | --- | --- |
| 制备路线 | 酸水解去无定形区 | 机械/化学解纤 |
| 形态 | 棒状晶须（100–500 nm） | 长纤丝（数微米） |
| 宽度 | 5–20 nm | 5–50 nm |
| 结晶度 | 高（70–90%） | 中（含无定形区） |
| 刚性 | 杨氏模量 100–160 GPa | 略低，但柔韧 |
| 成膜/凝胶性 | 液晶排列、偏脆 | 网络缠结、膜强韧 |
| 典型应用 | 增强填料、手性液晶膜 | 透明膜、水凝胶、气凝胶、包装 |

**一句话对比**：CNC 是「硬而短的晶须」，CNF 是「长而韧的纤丝」；要强度掺 CNC，要成膜与柔性用 CNF——两兄弟分据纳米纤维素应用的两极。

## 5 数值算例：一克纳米纤维素的表面积

纳米效应最直观的指标是比表面积。设 CNF 为直径 20 nm、密度 1.5 $\mathrm{g/cm^3}$ 的圆柱纤丝，忽略端面，比表面积：

$$
S = \frac{4}{\rho d} = \frac{4}{1.5\ \mathrm{g/cm^3} \times 20\times 10^{-7}\ \mathrm{cm}} \approx 1.3\times 10^{7}\ \mathrm{cm^2/g} = 1300\ \mathrm{m^2/g}
$$

**直觉**：1 克 CNF 的表面积约 1300 $\mathrm{m^2/g}$，与优质活性炭同一量级——这就是为什么纳米纤维素能高效吸附、成膜、做传感器基底，也解释了它为何是「纤维素最贵的出口」。

## 6 小结

- **纳米纤维素**分 CNC（酸水解晶须）与 CNF（解纤纤丝）两类，比强度高、比表面积大，是纤维素最高价值的出口。
- **木基复合材料**把碎化木材用胶黏剂重组为胶合板、刨花板、纤维板与木塑，胶黏剂的环保性是等级关键。
- **生物基化学品**以 PLA、PEF（FDCA 路线）、木质素碳纤维、生物基胶黏剂为代表，走原子经济的绿色化工。
- 绿色化工的本质优势：**生物质自带官能团、产物可降解、原子经济高**。
- 本专题全谱：**组成 → 制浆造纸 → 热解水解 → 林产化学品 → 提取物 → 能源 → 新材料**——一棵树从毫末长成参天，又被化学工程拆成纸、炭、香、药、燃料与材料，分毫不浪费。
- 纳米纤维素价值高但**成本与能耗是产业化瓶颈**，正是工程学科发挥的空间。
- 生物基塑料与绿色化工以**原子经济**为尺度，生物质自带官能团是其本质优势。
- 木质素制碳纤维、单宁生物胶黏剂等「废料变材料」路线，是可持续材料的前沿。

## 7 全专题收束

回顾整个「林产化学加工工程」专题：我们从《木材的化学组成与超微结构》认识细胞壁的三组分，用《硫酸盐法制浆》《纸浆漂白》把木材做成纸浆，用《木材干馏》《活性炭》《糠醛》《木糖醇》把它做成化学品，用《松香》《栲胶》《精油》《樟脑》取出它的精华，用《生物质精炼》《生物质能源转化》回收它的能量，最后用《生物质新材料》把它送回先进制造。这条「组分—产品」的完整链条，正是林业工程「把可再生资源吃干榨净」的学科理想。

**本节关键词速查**：

- **纳米纤维素**：CNC（晶须）与 CNF（纤丝），纤维素纳米尺度材料。
- **CNC**：酸水解制得的棒状结晶，模量高、呈液晶排列。
- **CNF**：机械/化学解纤的长纤丝，成膜与凝胶性好。
- **木基复合材料**：胶合板、刨花板、纤维板、木塑等重组木材料。
- **PLA / PEF**：聚乳酸与 FDCA 基聚酯，可降解/生物基塑料代表。
- **绿色化工**：可再生原料、少污染、原子经济的化工路线。
- **胶合板 / 刨花板 / 纤维板 / WPC**：以单板、刨花、纤维、木粉为单元的四种木基复合材料。
- **木质素碳纤维**：以木质素为前驱体经纺丝、稳定化、碳化制得的碳纤维候选路线。
- **5-HMF / FDCA**：由糖脱水得到的平台分子及其氧化产物，PEF 聚酯的单体。
- **气凝胶**：以 CNF 为骨架的超轻多孔材料，保温隔热用途。
- **游离甲醛**：木基复合材料胶黏剂释放的有害物，无醛胶是环保等级关键。
