## 为什么从湿部化学收束第二篇

上一节讲完打浆与抄纸，纸浆似乎已经「自成一体」了。但一张现代纸页里，往往藏着 1%–20% 的**非纤维成分**——填料、施胶剂、助留剂、增强剂、染料。它们的加入量很小，却能彻底改变纸的性能：让纸不洇水、让印刷更鲜艳、让纸杯盛得住热水。这些化学品的舞台，集中在纸机**流浆箱与网部**那一段「含水量极高的纤维悬浮液」里，所以叫**湿部（wet end）**。本节把湿部化学讲清楚——它是「胶体化学 × 纤维工程」的交叉地带，也是第二篇的收官。

<span class="marginnote">「失之毫厘，谬以千里」用在湿部化学再贴切不过：助剂加入量波动 0.1%，就可能让留着率从 85% 掉到 60%，整台纸机的白水系统与纸页质量全面失衡。湿部是典型的「小变量、大后果」体系。</span>

## 1 纤维悬浮液：一个天然胶体体系

湿部浆料在宏观上是「纤维 + 水」，微观上却是一个复杂的**胶体体系**：

**纤维与细料**：纤维素表面在水中电离羧基，使纤维与细料带**负电**（ζ 电位为负）。
**填料粒子**：碳酸钙、高岭土等也带负电，悬浮在水中。
- **溶解与胶体物质（DCS）**：来自木浆的树脂、半纤维素、木素磺酸盐等，是「阴离子垃圾」的源头。

因为所有颗粒都带负电，它们天然**互相排斥、难以聚集**——细料与填料会大量穿透网面流失。湿部化学的全部工作，就是**用阳离子聚合物与微粒把这层负电屏障打破，让细料与填料「抱团」留在纸上**。

## 2 湿部化学品分类

按功能，湿部化学品可分七类：

| 类别 | 代表物 | 功能 |
| --- | --- | --- |
| 填料 | 研磨碳酸钙（GCC）、沉淀碳酸钙（PCC）、高岭土、滑石、$\ce{TiO2}$ | 提白度/不透明度/平滑度，降成本 |
| 施胶剂 | 松香胶（酸法）、AKD、ASA（碱法） | 使纸抗水、抗墨水洇渗 |
| 助留剂 | 阳离子聚丙烯酰胺（CPAM）、聚乙烯亚胺（PEI）、微粒（膨润土/胶体硅） | 让细料、填料留在纸幅上 |
| 干强剂 | 阳离子淀粉、CMC、聚丙烯酰胺 | 提高纸页强度 |
| 湿强剂 | PAE 树脂（聚酰胺多胺环氧氯丙烷）、脲醛、三聚氰胺甲醛 | 纸湿时保持强度（纸巾、纸杯） |
| 增白剂与染料 | 荧光增白剂（OBA）、直接染料 | 提高白度、调色 |
| 助留以外的小料 | 消泡剂、杀菌剂、树脂障碍控制剂 | 维持运行稳定 |

**辨析｜易错点：** 填料不是「加了就白给」——它提高白度与不透明度，却**降低强度**（碳酸钙颗粒不参与纤维间氢键），还会增加磨耗。加多少填料，是「光学性能 vs 强度 vs 成本」的平衡。另外，**施胶剂分内施胶（加入浆料）与外施胶（涂在纸面）**，两者机理与用量完全不同，不可混为一谈。

## 3 留着机理与助留体系

助留剂的作用机理可以概括为四种叠加：

- **电荷中和**：阳离子聚合物吸附在负电颗粒表面，中和电荷、压缩双电层，颗粒间排斥减弱。
- **补丁吸附（patching）**：长链阳离子聚合物在颗粒表面形成正电「补丁」，正负补丁间发生异电吸引。
- **桥联（bridging）**：高分子链同时吸附多个颗粒，把它们「串」起来形成絮团。
- **微粒-聚合物网络**：阳离子聚合物先把颗粒聚成小絮团，再与膨润土等微粒形成更强、更耐剪切的网络。

**留着率（retention）**指细料与填料留在纸幅上的比例，是湿部运行的核心指标。助留剂加多了，留着率高但**纸页匀度变差**（絮团太大）；加少了，细料流失、白水负荷升高。**留着率与匀度是湿部永恒的跷跷板**——现代双元/微粒助留体系（聚合物 + 微粒）就是为了兼得两者。<span class="marginnote">这里的「絮凝-再分散」动态与《胶体与界面化学》里的 DLVO 理论、絮凝动力学完全同源。湿部浆料在流浆箱里的高剪切环境下，絮团不断被打碎又重组——留着率测的就是这场「打碎-重聚」游戏里最终留在网上的那部分。</span>

## 4 公式解析：AKD 的施胶反应

现代纸机多在中性-碱性条件下用 **AKD（烷基烯酮二聚体）** 内施胶。AKD 与纤维素的反应是湿部化学里最经典的共价键施胶机理：

$$
\ce{R-CH=C=O + HO-纤维素 -> R-CH2-C(=O)-O-纤维素}
$$

对这条式子做三步拆解：

- **第一步，AKD 的结构**：AKD 是一个含烯酮环（$\ce{-C=C=O}$）的疏水长链分子。烯酮环张力大、活性高，是它「盯住」纤维素羟基的抓手。
- **第二步，反应的本质**：纤维素羟基（亲核的氧）进攻烯酮环的羰基碳，开环形成**β-酮酯键**，把两条长链烷基「钉」在纤维素表面——AKD 由水中的胶粒变成了纸上的疏水层。**共价键连接，是 AKD 施胶「持久、耐碱」的根本原因**，与松香胶靠铝盐桥接的物理施胶机理完全不同。
- **第三步，为什么是现代主流**：AKD 在中性-碱性抄纸条件下施胶，可直接用碳酸钙填料（碱性湿部、高白度），而松香胶只能在酸性湿部使用。**施胶剂的更替，本质是「碱性抄纸革命」的一部分**——中性施胶让纸的白度、强度与成本同时受益。

**辨析｜易错点：** 不要以为「施胶剂越多越防水」——AKD 是**反应型施胶剂**，加入量超过纤维素表面可反应的羟基容量后，多余的 AKD 不再反应，反而水解失效并造成「假施胶」与滑移问题。另一个误区是把「留着」与「施胶」混为一谈：助留剂管细料填料留不留在纸上，施胶剂管纸抗不抗水，**两套化学品、两个机理、两道工序**。

## 5 阴离子垃圾与树脂障碍控制

湿部运行的头号敌人，是**阴离子垃圾（anionic trash）**——来自木浆的溶解半纤维素、木素磺酸盐、树脂酸与分散松香等负电杂质。它们会：

- **抢占阳离子助剂**：阴离子垃圾先一步消耗 CPAM、PEI，让本该用于细料填料的助剂「被偷走」。
- **干扰留着与施胶**：与阳离子助剂形成不溶性络合物，留着率骤降、施胶失效。
- **污染白水系统**：循环白水中阴离子垃圾不断累积，纸机运行越来越难控。

**对策**：用**固定剂（fixative）**（如聚胺、聚DADMAC）在浆料到达流浆箱前就把阴离子垃圾「固定」在纤维上（垃圾随纸走、不随水循环），或加**定着剂**配合。控制住阴离子垃圾，留着率、施胶、匀度才谈得上稳定——**湿部化学的一半功夫，在「除垃圾」上**。<span class="marginnote">「固定剂」把阴离子垃圾绑在纤维上、随纸幅带走，与《废水处理》里「混凝-沉淀」的思路同源——都是让杂质从液相转入固相。理解了这一点，湿部化学就从不讲道理的「加药」，变成了讲机理的「物料再分配」。</span>

## 6 留着率与白水：湿部运行的现场判读

留着率不是实验室指标，它直接写在**白水（white water）**里——网部滤下的水中带走了多少细料与填料，一测便知。现场常用两个经验判断：

- **首程留着率（first-pass retention）**：单次通过网部留在纸幅上的比例，反映助留体系即时效果。
- **白水浓度**：白水中悬浮固形物越高，留着越差、循环负荷越重。

一个典型场景：不加助留剂时，白水浓度可能高达 1.5%–2%；加入 CPAM + 膨润土微粒后，可降到 0.3% 以下——**留着率每提升 10 个百分点，白水负荷与化学品回收成本就显著下降**。这也是为什么「湿部化学的账」常常是纸厂里回报率最高的技改之一。

**辨析｜易错点：** 「留着率高」不等于「纸好」——高留着常伴随大絮团、匀度差、两面性（纸的正反面填料分布不均）。**留着与匀度的跷跷板，要靠「微粒体系在高剪切下保持小絮团」来同时兼顾**。另外，湿部加药顺序决定效果：固定剂 → 助留剂 → 微粒，顺序错了，药剂互相打架。

## 7 术语速查：湿部化学的一张「单词卡」

| 术语 | 含义 |
| --- | --- |
| 湿部（wet end） | 纸机流浆箱到网部的含水管段，化学品的主舞台 |
| ζ 电位 | 颗粒表面剪切面的电位，负值越大、排斥越强 |
| DCS | 溶解与胶体物质，阴离子垃圾的来源 |
| 留着率（retention） | 细料与填料留在纸幅上的比例 |
| 电荷中和 | 阳离子聚合物压缩双电层、消除斥力 |
| 补丁吸附（patching） | 颗粒表面正电「补丁」间的异电吸引 |
| 桥联（bridging） | 长链聚合物同时吸附多个颗粒 |
| 施胶度（sizing degree） | 纸抵抗液体渗透的能力指标 |
| 阴离子垃圾（anionic trash） | 消耗阳离子助剂的负电杂质 |
| 固定剂（fixative） | 把阴离子垃圾绑在纤维上的助剂 |

这十来个词，几乎就是湿部化学的全部「词汇表」。把它们串成一句话：**湿部化学 = 用阳离子把负电的细料、填料、垃圾都「管住」**——管住细料是留着，管住垃圾是稳定，管住电荷是匀度。

## 8 小结

- 湿部浆料是一个**带负电的胶体体系**（纤维、细料、填料均负电），湿部化学的核心是**用阳离子聚合物与微粒打破电斥力，让细料与填料抱团留在纸上**。
- 湿部化学品七大类：**填料、施胶剂、助留剂、干强剂、湿强剂、增白剂与染料、小料**——各司其职、互相制约。
- 留着靠四种机理叠加：**电荷中和、补丁吸附、桥联、微粒-聚合物网络**；留着率与匀度是湿部永恒的跷跷板。
- AKD 以**烯酮环 + 纤维素羟基的共价酯化**实现抗水，是碱性抄纸的主流施胶；松香胶走酸性湿部，正在被取代。
- **阴离子垃圾**会抢占阳离子助剂、扰乱留着与施胶，需用固定剂「先制服、再分配」。
