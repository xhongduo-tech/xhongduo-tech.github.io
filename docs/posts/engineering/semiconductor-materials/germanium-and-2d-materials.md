## 为什么从锗与 2D 材料开始

硅统治芯片六十年，但它有个物理天花板：**迁移率**。室温下硅的电子迁移率约 1350 cm²/V·s、空穴约 450 cm²/V·s。而锗的电子迁移率约 3900 cm²/V·s、空穴约 1900 cm²/V·s——都是硅的 2–3 倍；更极端的，单层二硫化钼（$\ce{MoS2}$）等 2D 材料把沟道厚度压到原子层。**当摩尔定律在尺寸上减速，人类把目光转向「材料本身跑得更快」**——这就是本节的主题：新型沟道材料的衬底化。<span class="marginnote">本节对标 Holloway &amp; McGuire《Handbook of Compound Semiconductors》第 1 章（体单晶生长与异质集成）的思想框架，并延伸到 2D 材料这一当代前沿——后者仍在快速演进，本专题只讲「材料学瓶颈」这条主线，不追逐最新工艺细节。</span>

但新材料有一条共同的铁律：**好性能 ≠ 好用**。锗在 1950 年代被硅取代，正是因为「性能不够好」的反面——它的缺陷（氧化层不稳定、带隙窄）是材料级的；2D 材料如今卡在「长不大、转不好、摸不得」的衬底化瓶颈上。**理解这些瓶颈，比背下新材料的性能数字更重要**——因为瓶颈揭示了材料工程里那些「性能之外」的决定性因素。<span class="marginnote">这与本专题第 1 篇的立论遥相呼应：材料工程的较量，从来不只是「性能上限」，更是「可制造性」——纯度、界面、缺陷、良率。新材料的性能再诱人，过不了衬底化这一关，就进不了产线。</span>本节的阅读路线是：先看锗如何被取代又如何回归，再看 2D 材料为何「纸面惊艳、量产艰难」，最后收束到「界面」这个终极瓶颈。

## 1 锗：从「被取代」到「被请回」

锗的故事是材料史上最跌宕的回旋。1947 年贝尔实验室的第一只晶体管就是锗做的；1950 年代硅崛起后，锗因三大缺陷淡出主流：**禁带宽度只有 0.66 eV**（器件 100°C 以上就失效）、**锗的氧化层 $\ce{GeO2}$ 溶于水且不稳定**（做不出 MOS 界面）、**资源稀缺**（全球锗储量以千吨计，是硅的百万分之一）。

但「被取代」不等于「被遗忘」。锗的迁移率优势在三个方向被重新请回：

- **硅锗合金（$\ce{SiGe}$）**：本专题第 9 篇的 SiGe HBT 已用它做器件。
- **锗光电探测器**：锗在 1.3–1.55 µm 通信波段有强吸收，直接长在硅上做硅光子的探测器——这是硅基光互连的关键件。
- **锗沟道晶体管**：当硅的短沟道与迁移率双双见顶，锗因**电子与空穴迁移率都高**被视为下一代 p 型沟道的候选。

**锗的回归不是因为它的缺点消失了，而是因为它的优点在特定场景里变得不可替代**——材料没有「过时」，只有「场合」。

历史值得再铺一层：1954 年贝尔实验室的蒂尔做出第一颗硅晶体管时，硅的性能其实**不如**当时的锗——硅的赢点从来不是性能，而是**界面与温度**。这个「性能不如也能赢」的历史，正是理解 2D 材料处境的钥匙：**一种材料能不能统治产业，性能只是必要条件，可制造性才是充分条件。** 锗输给硅、2D 材料至今输给硅，输的都是同一样东西。

## 2 Ge-on-Si：把锗「种」在硅上

锗衬底化的最大障碍是：**锗没有便宜的自身衬底**（锗单晶贵、直径小），所以主流路线是 **Ge-on-Si**——把锗长在现成的硅晶圆上。但这正是材料学瓶颈的标本：

**晶格失配 4.2%**（锗 5.6579 Å vs 硅 5.4310 Å），远高于 SiGe 虚衬底能容忍的阈值。直接外延锗会疯狂生成失配位错，位错穿透到锗膜表面形成**穿透位错（threading dislocation）**，密度高达 $10^9$/cm²。<span class="marginnote">回到第 7 篇的 Mathews-Blakeslee：4% 失配的临界厚度只有十几纳米——锗沟道要几百纳米厚，靠「直接长」根本不可能。于是材料工程祭出第 9 篇的「化整为零」：低温缓冲层 + 循环退火（thermal cycling），让穿透位错密度压到 $10^6$–$10^7$/cm² 级。这是「失配问题」的又一次标准解法。</span>

**热失配**是第二个坎：锗与硅的热膨胀系数不同，高温生长后降温，锗膜会受拉应力甚至开裂。Ge-on-Si 工艺里必须管好「从生长温度到室温」的降温曲线——材料工程的每一个环节，都在与「不同材料的脾气不同」较劲。

锗光电探测器的工作原理值得展开：锗的带隙 0.66 eV，正好能吸收 1.3–1.55 µm 通信波长的光子——在 Ge-on-Si 上做一个 p-i-n 探测器，光从硅波导耦合进锗层，产生光电流。**这可能是「锗衬底化」目前商业化最成功的一幕**：硅光收发模块里的探测器，十有八九是 Ge-on-Si——它把「被取代的材料」变成了「硅光子的心脏」。材料工程里最动人的反转，往往就是这样「从前朝废物变成当朝新宠」。

## 3 2D 材料的承诺：沟道薄到极限

2D 材料把「沟道」概念推向极致——**一层原子就是整个沟道**。2004 年盖姆与诺沃肖洛夫用胶带「撕」出石墨烯，引爆了这个领域；但石墨烯没有带隙（金属性），做不了开关。真正的器件材料是**过渡金属硫族化物（TMD）**：$\ce{MoS2}$、$\ce{WS2}$、$\ce{WSe2}$ 等，单层有 1–2 eV 的带隙，能当晶体管沟道。<span class="marginnote">TMD 单层的结构是「三明治」：一层过渡金属原子夹在两层硫族原子之间，共价键很强、层间是弱范德华力——所以能一层层剥离，也能层层堆叠成范德华异质结。材料工程里的「原子级厚度控制」，在 2D 材料这里是天然属性。</span>

2D 材料的承诺极具诱惑力：**沟道短到原子尺度、无悬挂键表面、可弯曲、可异质堆叠**——理论上绕过硅的迁移率与短沟道极限。但十年研究之后，它仍卡在量产门外，问题全在「衬底化」三个字上。

「可异质堆叠」尤其诱人：因为 2D 材料层间只靠范德华力结合，**可以把不同材料一层层「叠」成范德华异质结**（如 $\ce{MoS2}$/$\ce{WSe2}$ 做 p-n 结）——不需要晶格匹配，避开了第 7 篇的失配问题。这听起来像「打散重建晶格匹配难题」，但代价是：**每一层的转移都引入缺陷，叠得越多、坏得越快**——范德华异质结在实验室是神器，在产线是噩梦。

## 4 2D 材料的四大瓶颈

在进入瓶颈之前，先记住一个时间坐标：2004 年安德烈 · 盖姆与康斯坦丁 · 诺沃肖洛夫用透明胶带反复撕石墨，撕出单层石墨烯——他们因此获得 2010 年诺贝尔物理学奖。**用「胶带」撕出诺贝尔奖**这件事本身就是材料工程的寓言：发现一个新材料可以靠运气与巧劲，但把它变成可量产的衬底，需要的是截然不同的系统工程。这也解释了为什么石墨烯获奖十年后，2D 材料晶体管仍在实验室与中试线之间徘徊。

把 2D 材料「装上晶圆」要闯四关，每一关都是材料工程难题：

**其一，晶圆级生长**。最好的单层 TMD 样品是「撕」出来的微米级小片；要量产必须**CVD 在整片晶圆上长大面积单晶**——目前晶圆级生长普遍是多晶（布满晶界），晶界会散射载流子、破坏性能。**「长大不难，长大成单晶很难」**。

**其二，转移**。在生长衬底（如蓝宝石）上长的 2D 材料，要用聚合物辅助「揭下来、贴上去」转移——转移过程引入褶皱、破损与聚合物残留。**转移是 2D 材料衬底化里最「脏」、最不可控的一步**。<span class="marginnote">转移工艺听起来像「贴膜」，但贴的是原子级厚度的膜：一层气泡、一道褶皱、一点残胶，都会让器件特性崩坏。材料工程在「原子级精度」与「工程级操作」之间，隔着一道巨大的鸿沟。</span>

**其三，界面与介电**。2D 材料表面无悬挂键，本是优点，但也意味着**普通沉积的 $\ce{SiO2}$/$\ce{HfO2}$ 长不牢**、界面态难以控制。研究者转而用**六方氮化硼（h-BN）**作介电与衬底——它同样是 2D 层状材料，无悬挂键、与 TMD 晶格匹配，界面干净得不可思议。

**其四，接触与掺杂**。金属电极与 2D 材料之间是**范德华接触**，功函数与能带对齐难控制，**费米钉扎**让接触电阻居高不下；而 2D 材料的**掺杂手段至今不成熟**——没有可靠的替代离子注入的掺杂工艺。**没有好接触、没有好掺杂，晶体管就「进不来、出不去」电流。**

## 5 公式解析：接触电阻这道「门」

2D 材料晶体管的性能，常常被接触电阻卡死。金属—半导体接触的电流由**热电子发射（Richardson）**控制：

$$J = A^{*} T^{2} \exp\!\left(-\frac{q\phi_B}{kT}\right)$$

- **第一步，认清符号**：$J$ 是接触电流密度，$A^{*}$ 是有效理查德森常数，$T$ 是温度，$q\phi_B$ 是势垒高度，$k$ 是玻尔兹曼常数。
- **第二步，读物理直觉**：势垒 $\phi_B$ 越低、温度越高，越过势垒的电子越多，接触电流越大、接触电阻越小。**接触好坏，本质是「势垒多高」的问题**。
- **第三步，看 2D 的困境**：金属与 2D 材料的界面容易发生**费米钉扎**——金属功函数再怎么调，界面态把费米能级「钉」死，$\phi_B$ 降不下来，$J$ 就上不去。这正是 2D 器件接触电阻大的根源：**不是接触的物理搞不懂，而是界面态这个「捣乱的第三者」在作祟**。

这条公式浓缩了 2D 材料衬底化的一个真谛：**器件性能的敌人往往不在沟道里，而在沟道与外界交接的界面上**——这句结论同样适用于下面要收束的整节。

## 6 材料瓶颈的共性：一切输运都败在界面

把锗与 2D 材料的困境并排看，会惊讶地发现它们共享同一套主题：

| 挑战 | 锗（Ge-on-Si） | 2D 材料 |
| --- | --- | --- |
| 晶格/结构失配 | 4.2% 失配 → 穿透位错 | 多晶晶界、转移褶皱 |
| 界面质量 | $\ce{GeO2}$ 不稳定 | 无悬挂键、介电难长 |
| 接触 | 金属—锗反应 | 费米钉扎、范德华接触 |
| 掺杂 | 激活难（锗能级深） | 无成熟掺杂手段 |
| 规模 | 直径小、贵 | 晶圆级单晶难 |

**重点：这些瓶颈的共同名字是「界面」。** 沟道材料自身的性能是「本征」的，但器件是「界面」的——沟道与衬底、沟道与介电、沟道与电极，每一个交界处都是性能流失的闸口。**新材料衬底化的本质，就是一场「把本征性能安全穿过所有界面」的接力赛**——这也是为什么新材料研究动辄十年，而硅的界面体系（$\ce{SiO2}$/Si）是它难以撼动的护城河。<span class="marginnote">硅最被低估的资产，其实是 $\ce{SiO2}$/Si 界面的完美：热氧化生成、界面态密度低到 $10^{10}$/cm²·eV 级。锗没有它，2D 材料也没有它——所有新材料都在为「重建一个硅级界面」而奋斗。这也是本专题第 12 篇「表征与认证」总要多问一句「界面怎么样」的原因。</span>

**辨析｜易错点：** 「2D 材料迁移率高」这句宣传要打折扣。石墨烯迁移率确实高达数万 cm²/V·s，但它是金属、做不了开关；$\ce{MoS2}$ 有带隙，可实验室测得的高迁移率，在晶圆级多晶、转移污染、接触受限的真实器件里会掉到百分之一量级。**材料手册上的「本征迁移率」与器件里的「有效迁移率」之间，隔着一整套衬底化工艺**——这再次呼应本节标题：瓶颈在衬底化，不在材料本身。

## 6.5 现实中的进度：谁已经上车了

把「瓶颈」讲了半天，也要摆一摆现实进度，免得给人「新材料全是空谈」的印象：

**锗已经上车**：Ge-on-Si 光电探测器在硅光模块里大规模量产，SiGe HBT 是射频前端的成熟主力——锗不是「未来材料」，是「已量产的特殊材料」。

**2D 材料正在上车的路上**：h-BN 已开始作为先进制程里的扩散阻挡与介电候选；TMD 晶体管在实验室做出过接近硅主流节点的演示，但离产线还差「晶圆级单晶 + 无污染转移 + 可靠掺杂」三座大山。<span class="marginnote">可以这样给 2D 材料定位：它目前最现实的商业用途，不是替代硅沟道，而是<strong>硅之后或硅之外的增量</strong>——柔性电子、传感、超低功耗边缘器件。材料工程的历史告诉我们：新材料通常不会取代硅，而是先在硅管不到的地方落地生根。</span>

**判断新材料成熟度的三条铁律**（可作为本节的收束）：一看**晶圆级单晶能不能做**，二看**界面体系成不成熟**，三看**成本能不能打**。三条全过，材料才谈得上「衬底化」——这也是为什么 2D 材料「性能已足够诱人，量产仍需耐心」。

## 7 小结

- 硅的迁移率天花板把目光引向**锗**（迁移率高 2–3 倍）与 **2D 材料**（原子级薄沟道），但两者都卡在衬底化。
- 锗回归靠**特定场景**（SiGe HBT、锗光电探测器、锗沟道），而非全面取代硅。
- **Ge-on-Si** 要过两道坎：4.2% 晶格失配（穿透位错）与热失配（开裂），解法是缓冲层 + 循环退火。
- 2D 材料要闯四关：**晶圆级单晶、转移、介电界面、接触与掺杂**——每一关都是「性能之外的制造力」。
- 接触电阻由势垒 $\phi_B$ 控制，费米钉扎是 2D 接触的隐形杀手。
- 锗光电探测器与 SiGe HBT 已是量产的「锗衬底化」样板，2D 材料仍在实验室与中试线之间。
- 2D 材料最现实的未来是**硅之外的增量**（柔性、传感、超低功耗），而非取代硅沟道。
- 一切新材料的瓶颈可归结为**界面**——硅的护城河是那个近乎完美的 $\ce{SiO2}$/Si 界面。
- 判断新材料成熟度三铁律：**晶圆级单晶、界面体系、成本**；锗已量产上车，2D 材料仍在途中。
- 「本征迁移率」与「有效迁移率」之间隔着一整套衬底化工艺，宣传数字要打折读。

在下一节，我们将离开「沟道」，去看材料工程的后勤战线——**靶材与湿化学品**：那 9N–11N 的纯度承诺，最终要靠一桶桶电子级化学品与一块块高纯靶材兑现。
