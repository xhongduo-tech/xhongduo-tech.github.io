## 为什么从多晶硅提纯开始

上一节我们立住了「9N-11N」这个目标：电子级硅的金属杂质要压到每立方厘米 $10^{13}$ 量级以下。但硅在地壳里并不稀缺——二氧化硅（石英砂）占地壳质量的约 27%——稀缺的是**把二氧化硅变成 11N 硅的能力**。这一节就讲这条化学净化链：从石英砂到冶金级硅、再到电子级多晶硅，最后成为直拉单晶的原料。<span class="marginnote">本节对应 Shimura《Semiconductor Silicon Crystal Technology》第 5.1 节 Starting Materials。上一节我们立住了「为什么必须这么纯」，这一节回答「如何做到这么纯」——纯度目标与提纯手段在此第一次碰面。</span>

多晶硅（polysilicon）是单晶硅生长的原料，也是光伏电池的基础材料。理解提纯，等于理解半导体工业的**上游咽喉**：原料纯度不够，后面直拉、外延、器件做得多好都白搭。<span class="marginnote">这条链与第六级《半导体制造工艺》里「前道工艺」直接衔接：多晶硅是晶圆的第一步。读懂本节，你就拿到了整个硅基工业的第一环。</span>

## 1 从石英砂到冶金级硅：碳热还原

一切从**碳热还原**开始。把高纯石英（$\ce{SiO2}$）与焦炭/木炭在电弧炉里加热到 1900°C 左右，发生：

$$\ce{SiO2 + 2C -> Si + 2CO \uparrow}$$

产物叫**冶金级硅（Metallurgical-grade Silicon，MG-Si）**，纯度只有 98%–99%，余下的杂质主要是铁、铝、钙、钛等金属。电弧炉本身规模巨大、能耗极高，但它是整条链的起点——全世界每年产出的数百万吨冶金级硅，大部分进了铝合金与有机硅行业，只有一小部分继续提纯走向电子工业。<span class="marginnote">冶金级硅提纯是「先粗后细」：粗硅的金属杂质以百万分之一到万分之一计，要在后续多步化学工艺里被搬走。注意，冶金级硅的「杂」主要来自原料与炉体，而不是硅晶格自身的本征缺陷——这是与单晶生长中「缺陷」概念不同的另一类问题。</span>

电弧炉里有意思的是**出料方式**：熔融硅从炉底排出，浇铸成硅块，再破碎成料。破碎过程会引入金属污染，因此冶金级硅从出炉那一刻起就要被「再脏一次」。**这提醒我们一个贯穿全章的原则：提纯不是一次操作，而是一条不断「变纯—再污染—再变纯」的接力链**，每一棒的纯度都被下一棒重新定义。

值得一提的还有**能耗与环境账**：电弧炉出硅本身能耗极高，而后续提纯（无论西门子法还是 FBR）的能耗又比电弧炉高一个量级。因此多晶硅是半导体产业里「碳足迹」最高的环节之一，近年来碳中和压力下，供应商纷纷把产线迁往水电、风电充裕的地区，并研究硅烷回收、氯硅烷闭环等循环方案。**提纯工业的本质是「用电换纯度」**——这一定价规律贯穿本节与下一节。

**重点：碳热还原只能到 98%，剩下 2% 的杂质靠化学方法搬走。** 冶金级硅的杂质太高，无法直接做器件，必须走一条「化学变身—蒸馏—还原回来」的迂回路线——这就是西门子法的思想。

## 2 西门子法：化学变身的净化哲学

直接再结晶不能提纯，因为金属杂质会跟着一起凝固。西门子法的聪明之处在于**先让硅离开固态，变成可蒸馏的化合物，再把它重新变回硅**：

**第一步，合成三氯氢硅。** 冶金级硅与氯化氢气体反应：

$$\ce{Si + 3HCl -> SiHCl3 + H2}$$

这一步在流化床反应器里约 300°C 进行。产物三氯氢硅（$\ce{SiHCl3}$）是沸点 31.8°C 的液体，容易蒸馏。**蒸馏是提纯的核心手段**：杂质的氯化物沸点与 $\ce{SiHCl3}$ 相差较大，多次精馏可以把金属杂质含量压到 ppt 量级。这正是「化学变身」的意义——硅在固态时摆脱不掉的杂质，变成化合物后可以被蒸走。

**第二步，氢还原沉积。** 纯化后的 $\ce{SiHCl3}$ 与高纯氢气混合，通入西门子反应器，在 U 形高纯硅芯棒上加热到约 1100°C：

$$\ce{SiHCl3 + H2 -> Si + 3HCl}$$

硅沉积在发热的硅棒上，芯棒逐渐长粗，直到直径十几厘米，成为一根多晶硅棒。反应副产物氯化氢与未反应的 $\ce{SiHCl3}$ 被回收再利用——提纯工艺同时是回收工艺。

西门子法于 1955 年由西门子公司（Siemens & Halske）开发并申请专利，此后成为电子级多晶硅的绝对主流，一直统治到今天。**它把一个「固态提纯」的难题，变成了「蒸馏提纯+化学还原」两步易行的方案**——这是化工思维对半导体工业最成功的输出。

历史细节值得记住：西门子法的工程成熟并非一蹴而就。早期尝试用 $\ce{SiCl4}$ 氢还原，但四氯化硅的还原效率低、纯度难以控制；**三氯氢硅路线的确立**——先让硅与氯化氢合成 $\ce{SiHCl3}$，精馏后再氢还原——才是西门子法真正量产的转折点。此后数十年，各家厂商的改进都围绕同一个主轴：**如何让沉积更纯、更快、更省电**。反应器从单根棒演进到多对棒、从常压演进到低压操作，沉积速率从每小时零点几毫米提升到 1 毫米以上，但「化学变身—蒸馏—还原」三明治结构始终未变。

## 3 流化床法：节能的另一条路

西门子法有两个缺点：**能耗高**（硅棒要靠电流加热，长时间维持 1100°C）和**间歇式**（一根硅棒长几天才收一次）。流化床法（Fluidized Bed Reactor，FBR）从根上改变了加热方式。

FBR 的思路是：让**硅烷（$\ce{SiH4}$）**在流化床里热解，直接沉积在悬浮的细小硅种子上：

$$\ce{SiH4 -> Si + 2H2}$$

反应温度只有约 600–700°C，远低于西门子法的 1100°C；而且反应是放热的，热源来自气流而非电热棒。产物是流动性好的颗粒状多晶硅（granular polysilicon），可以直接连续进料给直拉炉，还能免去后续破碎工序。<span class="marginnote">FBR 的挑战在工程而不在化学：种子颗粒在床层里运动，硅一旦沉积不均匀、颗粒粘连，床层就会「死掉」；此外硅烷是自燃物，安全与防爆是设备设计的头等大事。2000 年代后期，REC、SunEdison 等公司把 FBR 推向量产，但至今它仍是西门子法的补充而非替代。</span>

硅烷从哪来？工业上主要有两条路：一是**三氯氢硅歧化**——让三氯氢硅在催化下发生歧化反应，最终得到 $\ce{SiH4}$ 与 $\ce{SiCl4}$（这是现代主流的「多晶硅—硅烷」路线，原料与西门子法同源）；二是**硅化镁酸解**——$\ce{Mg2Si}$ 与盐酸反应生成硅烷。无论哪条路，硅烷都是极易自燃、需要严格惰性气氛处理的气体，这也是 FBR 工艺「化学简单、工程危险」的由来。

**对比两者的纯度**：FBR 因床层接触面积大、颗粒表面易残留杂质，历史上一度只能做到太阳能级；西门子法则稳定产出 9N–11N 电子级。**「电子级 vs 太阳能级」的纯度分界，在工艺上就体现在这两条路线的选择上。**

## 4 公式解析：西门子法还原反应的计量

以三氯氢硅氢还原这条主反应为对象，做完整计量分析：

$$\ce{SiHCl3 + H2 -> Si + 3HCl}$$

- **第一步，核对原子守恒**：反应物侧 $\ce{SiHCl3}$ 提供 1 个 Si、1 个 H、3 个 Cl，加上 $\ce{H2}$ 的 2 个 H，共 Si 1、H 3、Cl 3；产物侧 $\ce{Si}$ 1 个 + $\ce{3HCl}$ 提供 3 个 H 与 3 个 Cl。两边原子完全守恒，配平成立。
- **第二步，读出化学本质**：这是**氧化还原**而非简单置换——$\ce{H2}$ 把 $\ce{SiHCl3}$ 里的 $\ce{Si^{2+}}$（实际是 $\ce{Si^{3+}}$ 周围的电负性环境）还原回零价的 $\ce{Si^0}$，自身被氧化成 $\ce{HCl}$ 中的 $\ce{H^{+}}$。反应的化学驱动力来自 $\ce{Si-Si}$ 键的稳定。
- **第三步，看工业意义**：理论上 1 mol $\ce{SiHCl3}$ 只应沉积 1 mol Si，但实际单程转化率只有约 10%–20%——其余 $\ce{SiHCl3}$ 未反应或被回收。因此**反应器的设计目标不是转化率，而是「回收率 × 纯度」的乘积**：宁可单程转化率低，也要保证每层沉积的硅都足够纯。

这一计量关系解释了为什么西门子法能耗高：大量物料在反应器与精馏塔之间循环，维持这个循环本身就是巨大的能量开销。

顺带一提，氯硅烷路线还有一个副产品——**四氯化硅（$\ce{SiCl4}$）**。它每生产一吨多晶硅会伴生数吨，过去难以处置，如今多被氢化回三氯氢硅循环利用。**提纯工业的环保账与成本账，往往指向同一个解：让每一个氯硅烷分子都进入闭环。**

## 5 电子级 vs 太阳能级：纯度需求的双轨

同样是多晶硅，**电子级（EG-Si）与太阳能级（SoG-Si）**走的是不同的需求曲线：

| 指标 | 太阳能级 SoG-Si | 电子级 EG-Si |
| --- | --- | --- |
| 典型纯度 | 6N 左右 | 9N–11N |
| 主要杂质关注 | 铁、铝、碳、氧 | 全部金属、掺杂元素、氧碳 |
| 主流工艺 | 改良西门子法、FBR、冶金法 | 西门子法 |
| 晶圆用途 | 光伏电池片 | IC 衬底、外延片 |

为什么光伏只需要 6N？因为**光生载流子对深能级杂质的敏感度远低于晶体管**：电池的工作电流由光生少子决定，而它的寿命要求、漏电要求、均匀性要求都宽松得多。<span class="marginnote">光伏一度走「冶金法」路线（把 MG-Si 再纯化到 6N 而不走硅烷/三氯氢硅），试图绕过西门子法的能耗——代表是美国的 Elkem 与中国的部分厂商。但多晶硅价格波动剧烈，这条路线时兴时衰，说明纯度的「够用」边界最终由市场成本决定。</span>而 IC 晶体管的漏电、寿命、阈值均匀性对杂质极敏感，必须 9N–11N。

**易错点｜辨析：** 「太阳能级硅不能做 IC」不等于「IC 级硅一定能做电池」。EG-Si 当然也能做电池，只是浪费了纯度、多付了成本。工业分工不是「能/不能」，而是「成本/收益」的最优解。

另一个易错点是**把「纯度」与「掺杂」混谈**：多晶硅阶段几乎没有刻意掺杂——掺杂要到直拉生长时由熔体里的掺杂物一次性决定。多晶硅的纯度要求是「杂质尽量少」的绝对标准，而不是「可控掺杂」的相对标准。这也是为什么多晶硅规格书只谈纯度与寿命，不谈电阻率档位。

## 6 提纯的能耗账与供应链格局

多晶硅提纯是**高能耗工业**。粗略对比：

- **西门子法**：全流程能耗约 60–120 kWh/kg（含还原、精馏、回收），其中氢还原沉积占大头。
- **流化床法**：能耗可低至 25–50 kWh/kg，这是它节能卖点的量化来源。

正因如此，多晶硅产能高度集中于电价低廉的地区，且呈**寡头格局**：电子级多晶硅被全球少数几家厂商（历史上以德国的瓦克、美国的多晶硅巨头、以及后来居上的中国厂商为主）掌控。原料提纯的规模效应极强——先发者靠产能摊薄成本，后来者要越过「纯度稳定 + 成本」双重门槛。<span class="marginnote">多晶硅价格曾在 2008 年前后冲到 400 美元/公斤的历史高位，又随产能扩张跌到过 15 美元/公斤——这种剧烈波动说明：原料环节是半导体与光伏产业的「周期放大器」。</span>理解了这条供应链，就能理解为什么晶圆厂对上游原料极为敏感，也会在下一节直拉生长时发现：炉子的吃料成本，很大程度由这里定下。

## 7 小结

- 多晶硅提纯的起点是**碳热还原**：$\ce{SiO2 + 2C -> Si + 2CO}$，得冶金级硅（98%–99%）。
- **西门子法**通过「三氯氢硅合成—蒸馏—氢还原」把硅化学变身再还原回来，稳定产出 9N–11N 电子级硅。
- **流化床法**用硅烷热解（$\ce{SiH4 -> Si + 2H2}$，约 650°C）连续生产颗粒硅，能耗更低，但历史上纯度偏太阳能级。
- **电子级 9N–11N 与太阳能级 6N 的分界**，本质是「器件需求 vs 提纯成本」的双轨权衡。
- 提纯是**高能耗、寡头化**的上游咽喉，其成本与供应链格局直接决定下游直拉与外延的吃料成本。
- 多晶硅阶段**不做刻意掺杂**，纯度的绝对标准（而不是相对标准）是它与晶圆最本质的区别。

在下一节，我们将拿到 11N 的多晶硅料，把它在 1414°C 的熔体里拉成单晶——这就是**直拉法（CZ）的温场控制与区熔法（FZ）的故事**。届时你会看到：提纯解决「有没有杂质」，而单晶生长解决「杂质与缺陷放在哪里」——两门技术叠加，才构成一块可用衬底的全部材料学。
