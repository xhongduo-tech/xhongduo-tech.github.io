## 为什么从 γ 谱学开始

前五篇把探测器讲透了，但「测到脉冲」只是起点——**真正的目标是读出「这是什么核素、有多少」。** γ 谱学就是连接「脉冲高度分布」与「核素身份」的那座桥。每一种放射性核素在衰变时都会放出特征能量（如铯-137 的 662 keV、钴-60 的 1173/1332 keV、钾-40 的 1461 keV），γ 谱把不同能量的计数画成一张「能量—计数」图，峰的位置告诉你是谁，峰的面积告诉你有多少。这门技术是环境监测、核安保、核医学与材料分析共同的地基。<span class="marginnote">从「从极限到大模型」的视角看，γ 谱学本质是一次「反演」：从观测到的谱（效应）反推核素的成分（原因）——与机器学习里从样本反推分布、从频谱反推信号源同构。探测器是正演，谱分析是反演，两半合起来才构成完整的测量科学。</span>

## 1 从脉冲到能谱：多道分析器

探测器输出的每个脉冲，其高度正比于沉积能量。**多道脉冲幅度分析器（MCA）**把脉冲高度按大小分进几千个「道」（bin），每道记录该高度出现的次数。于是横轴是能量、纵轴是计数，一张能谱就诞生了。现代系统用高速 ADC 数字化脉冲、再用软件做道分配，通量上限大幅提高。<span class="marginnote">「道」的数目决定能量分辨率的上限：1024 道对应 0–10 MeV 时每道约 10 keV。道的概念与直方图、桶排序同源——把连续量离散化，是测量与计算共同的基本动作。</span>

历史上，1948 年霍夫施塔特造出 $\ce{NaI(Tl)}$ 后，第一台 γ 谱仪随之出现，能谱学就此开启；而 1970 年代高纯锗把分辨率提升近三十倍后，核素识别才真正走向「高置信」。**谱学的发展史，就是分辨率不断提高的历史**——今天一支手掌大的 CdZnTe 手持仪，能力已超过当年的实验室整套设备。

能谱的「形状」由物理过程决定，同一个核素的 γ 会产生一张有特定结构的谱，主要成分包括：

- **全能峰（full-energy peak）**：γ 在探测器内把全部能量沉积（光电效应，或多次康普顿后光电吸收），脉冲高度最大，对应 γ 的真实能量——这是核素识别的主要依据。
- **康普顿平台与康普顿边（Compton continuum / edge）**：只沉积部分能量的 γ 形成连续平台，其能量上限对应 180° 反散射，称为康普顿边。
- **反散射峰（backscatter peak）**：在探测器周围物质中散射回探测器、只沉积低能的 γ，在低能处形成小峰。
- **逃逸峰（escape peak）**：电子对产生后，0.511 MeV 湮灭光子逃逸，形成低 511 keV（单逃逸）或 1022 keV（双逃逸）的伴峰。

读懂这些「峰与平台」的搭配，是谱学分析的第一课。

## 2 能量刻度与效率刻度：谱的「尺子」

要读出能量与活度，谱必须先「上尺子」：

**能量刻度**：用已知能量的标准源（如铯-137 的 662 keV、钴-60 的 1173 与 1332 keV、钡-133 的多条线）标定「道号 ↔ 能量」的关系，通常是一条近似的线性或二次曲线。做完能量刻度，任意峰的位置都能换算成能量，进而查表识别核素。标定点越多、覆盖能区越宽，内插越可靠——**刻度的本质是用已知反推未知**。

**效率刻度**：峰的计数率与源的活度成正比，比例因子是**探测效率**（随能量与几何变化）。用已知活度的标准源实测效率曲线 $\varepsilon(E)$，就能把未知峰的计数率换算成活度。效率刻度是「测多少」的关键，也是谱仪计量性能的核心。<span class="marginnote">能量刻度管「是谁」，效率刻度管「有多少」——两把尺子缺一不可。日常把标准源放固定位置、隔段时间重测一次效率，就能监控探测器长期漂移，这也是《剂量测量》里质控思想的雏形。</span>

效率还分两个层次：**几何效率**（源对探测器张开的立体角占比，由距离与源尺寸决定）与**本征效率**（进入灵敏体积的光子被探测到的比例，由材料与能量决定）。距离加倍，几何效率降到四分之一（平方反比）——所以测活度时源的位置必须固定且精确。

## 3 峰分析：从全能峰提取信息

核素识别的核心操作是**峰分析（peak analysis）**：在谱中找到峰、确定峰的位置与净面积。工程上常见步骤：

- **本底扣除**：峰下面垫着康普顿平台等连续本底，先估计本底（如取峰两侧平均），再从总计数中扣除，得到净峰面积。
- **峰形拟合**：全能峰近似为高斯（常带低能拖尾），用高斯 + 线性本底模型拟合，精确定出峰中心与面积。
- **分辨邻近峰**：当两个核素的 γ 能量相近（如小于分辨率的三四倍）时，峰重叠成鼓包，需用多高斯解卷积——分辨率越高越容易分开，这正是前文「高纯锗之王」的价值所在。<span class="marginnote">峰拟合与光谱、色谱、质谱里的峰处理是同一套方法：扣本底、定峰形、解重叠。学过谱学，你就拿到了「一切以峰为语言的分析技术」的通用钥匙。</span>

**辨析｜易错点：** 峰面积与峰高不能混淆。峰高受分辨率影响（分辨率差则峰矮而宽），峰面积才是活度的正比量。初学容易「数峰高」，正确的做法永远是「积峰面积」。

峰分析的统计精度也有一套内在逻辑：**计数服从泊松统计，峰面积的相对不确定度约 $1/\sqrt{N}$**（$N$ 为净峰计数）。要测到 10% 的精度，净计数需约 100 个；要 1% 精度，需约 10,000 个——测量时间与精度由此挂钩。这就是为什么低活度样品往往要「测一整天」：不是仪器慢，而是统计学要求数够多。

## 4 核素识别：指纹库与能谱匹配

识别流程是「找峰 → 定能量 → 查指纹库」。每个核素的 γ 能量与分支比是其特征「指纹」，可查权威核素表（如 IAEA 核数据库）。识别规则包括：

- **能量匹配**：峰能量与库中某核素的特征线在容差内吻合。
- **分支比校验**：同一核素的多条特征线应成比例出现（由分支比决定），若只出现一条则可能误判或存在干扰。
- **半衰期鉴别**：随时间做多幅谱，峰的衰减速率应与该核素半衰期一致——这是甄别短寿命干扰核素的有力手段。
- **干扰核素排查**：能量相近的核素（如铕-152 与铯-137 附近的线）需要更细心地区分。

这套「多证据交叉验证」的逻辑，与法证、诊断学里的「多重独立指标确证」一脉相承——**单一证据可造假，交叉证据才可信。**

谱学还有一个必须交代的量：**最小可探测活度（MDA）**——在给定本底与测量时间下，能「显著」报出的最低活度。它由本底计数、峰位置与置信水平共同决定：本底越高，MDA 越高，小峰越容易被「淹没」。核安保要求「可疑样品必须报得出来」，正是靠压低本底（铅室屏蔽）与延长测量时间来压低 MDA。<span class="marginnote">MDA 是「报告阈值」的科学依据：不是「没测到就是没有」，而是「低于 MDA 就说『不可检出』」。学会区分「未检出」与「零」——这既是统计学纪律，也是辐射报告严谨性的基石。</span>

## 5 公式解析：康普顿边与逃逸峰

先给一张「谱学实战速查」，把前面几节的知识压缩成一张表——这也是环境监测、核安保分析报告里最常见的项目：

| 项目 | 含义 | 判读要点 |
| --- | --- | --- |
| 全能峰能量 | 核素特征 γ 能量 | 与库值匹配即初步识别 |
| 康普顿边位置 | 单次散射最大能量转移 | 校验全能峰是否真实 |
| 逃逸峰 | 511 keV 湮灭光子逃逸 | 高能区避免误判为新核素 |
| 净峰面积 | 扣除本底后的计数 | 活度计算的输入量 |
| 测量不确定度 | 泊松统计 $\approx 1/\sqrt{N}$ | 决定所需测量时间 |



**康普顿散射决定了谱的「平台 + 边」结构。** γ 与电子散射，最大能量转移（180° 反散射）时电子获得动能

$$T_{\max} = E_\gamma - \frac{E_\gamma}{1 + 2E_\gamma/m_ec^2} = \frac{2E_\gamma^2}{m_ec^2 + 2E_\gamma}$$

- **第一步，认识两个能量尺度**：$m_ec^2 = 511$ keV 是电子静能，$E_\gamma$ 是入射 γ 能量。
- **第二步，代入算康普顿边**：对铯-137 的 662 keV，$T_{\max} = 2 \times 662^2/(511 + 2\times 662) \approx 478$ keV——这就是康普顿平台的上限（康普顿边），峰右侧 662 keV 处才是全能峰。
- **第三步，理解伴峰**：对能量超过 1022 keV 的 γ（如钴-60 的 1332 keV），电子对产生后若一个或两个 511 keV 湮灭光子逃逸，谱上会在 1332−511=821 keV（单逃逸）与 1332−1022=310 keV（双逃逸）处出现伴峰。<span class="marginnote">「全能峰 + 康普顿边 + 逃逸峰」是 γ 谱的三件套：能认出它们，就读懂了一张谱的骨架；认不出，就容易被平台误当峰、被伴峰误当新核素。</span>

## 6 谱仪系统的完整链路

把前面的知识串成一条链：**辐射源 → 探测器（半导体/闪烁）→ 前置放大器 → 成形放大器 → 多道分析器 → 能谱 → 峰分析 → 核素识别。** 每一环都影响最终结果：探测器决定分辨率与效率，放大器决定脉冲形状与堆积抑制，MCA 决定道数，软件决定峰拟合精度。<span class="marginnote">这条链路与「从极限到大模型」里的数据处理管线同构：每一级都在「转译 + 放大 + 去噪」，链末的识别精度受链中最弱一环限制。学会「看整条链」而非「盯一个器件」，是系统思维的第一课。</span>

**核心要点表**——谱学四要素：

| 要素 | 回答的问题 | 关键手段 |
| --- | --- | --- |
| 能量刻度 | 峰对应多少能量？ | 标准源标定道—能量关系 |
| 效率刻度 | 峰面积对应多少活度？ | 标准源标定效率曲线 |
| 峰分析 | 峰在哪里、净面积多大？ | 本底扣除 + 高斯拟合 |
| 核素识别 | 是哪种核素？ | 能量匹配 + 分支比 + 半衰期交叉验证 |

这条链路支撑着大量真实场景：福岛事故后空气与食品中碘-131/铯-137 的每日监测、核电站乏燃料与工艺流的核材料衡算、海关截获可疑物品的快速筛查、地质样品的年代测定，乃至医疗核素药物出厂前的纯度检验。**谱学不是实验室的孤岛，而是工业与公众安全体系的神经末梢。**

## 7 小结

- γ 谱学用**多道分析器**把脉冲高度分布变成能谱，峰位定能量、峰面积定活度。
- 一张谱由**全能峰、康普顿平台/边、反散射峰、逃逸峰**构成，认得清才读得懂。
- **能量刻度**管「是谁」，**效率刻度**管「有多少」，两把尺子缺一不可。
- 峰分析 = 扣本底 + 拟合峰形 + 解重叠；峰面积而非峰高才是活度正比量。
- 核素识别靠**能量匹配 + 分支比 + 半衰期**交叉验证，像法证一样讲究多重证据。
- 谱仪是一条完整链路，识别精度受最弱一环限制。
- **最小可探测活度（MDA）**决定报告阈值，「未检出」不等于「零」。
- 峰面积不确定度约 $1/\sqrt{N}$，测量时间与精度直接挂钩。
- 谱学支撑核安保、环境监测、核医学与材料分析，是公众安全体系的神经末梢。
