## 为什么从角系数开始

上一节建立的是「单个黑体」的辐射能力。真实工程问题从来不是孤立的黑体：**锅炉炉膛里火焰辐射给水冷壁，两个物体之间还隔着看得到的其他表面**。辐射能由表面 $A_1$ 出发，并不全部落到 $A_2$ 上——途中可能逃逸到第三面墙、被其他表面截获，还可能被自己再次吸收。于是辐射换热的核心问题变成了：**一个表面发出的辐射，几何上有多大比例落到另一个表面？** 这个比例就是**角系数（view factor / shape factor）**。<span class="marginnote">角系数把「几何」从「物理」里干净地剥离出来：它只依赖表面的形状、大小、相对位置与朝向，与温度、材料、表面性质完全无关。这个分离使辐射换热的分析有了清晰的层次——先算几何（角系数），再算物理（辐射网络）。</span>

这一节的目标：掌握角系数的定义、三条基本性质（相对性、完整性、可加性）、两个重要表面（黑体、灰体大空腔）的简化结论，以及用辐射网络把「两灰体 + 一个绝热面」的换热算成电路题。

## 1 角系数的定义与基本性质

**角系数（view factor）** $X_{1,2}$：表面 $A_1$ 发射的总辐射能中，**直接落到表面 $A_2$ 上的份额**。定义为

$$X_{1,2} = \frac{\text{由 } A_1 \text{ 落到 } A_2 \text{ 的辐射能}}{\text{由 } A_1 \text{ 发出的总辐射能}}$$

由定义立即可得三条性质，它们是辐射网络计算的基石：

- **相对性（reciprocity）**：$A_1 X_{1,2} = A_2 X_{2,1}$。两条表面之间的角系数「乘上各自面积」相等——这使我们可以由易算的一侧推出难算的一侧。
- **完整性（summation rule）**：对封闭空腔内的表面 $i$，其发出的辐射必然全部落在某个表面上：$\sum_j X_{i,j} = 1$。这是「能量守恒」的几何翻译。
- **可加性（superposition）**：若表面 $j$ 由若干子面组成，$X_{i,(j)} = \sum_k X_{i,j_k}$，且 $X_{(i),j} = \dfrac{\sum_k A_k X_{k,j}}{A_{(i)}}$。子面拆分使复杂几何可以分解为查表对象。<span class="marginnote">可加性是「复杂问题拆成简单问题」的钥匙：工程上大量角系数曲线/公式只针对平面对平面、圆对圆等规则组合，任意几何先用可加性拆成这些基本块，再逐块查表累加。</span>

**角系数的积分定义**：两微元面 $dA_1$、$dA_2$，中心连线长 $S$，法线与连线夹角分别为 $\theta_1$、$\theta_2$，则

$$X_{1,2} = \frac{1}{A_1}\int_{A_1}\int_{A_2} \frac{\cos\theta_1\cos\theta_2}{\pi S^2}\,\mathrm{d}A_2\,\mathrm{d}A_1$$

**角系数与距离平方成反比、与两法线夹角的余弦成正比**——辐射「看」得越直、隔得越近，占比越大。这条积分式告诉你角系数为什么难算：二重积分、还要处理遮挡，所以工程多用查表、图线与代数性质。

## 2 黑体表面之间的辐射换热

两个黑体表面温度分别为 $T_1$、$T_2$。黑体不反射（$\rho = 0$），落到表面的辐射全部被吸收，于是从 $A_1$ 发出的 $\sigma T_1^4 A_1 X_{1,2}$ 全部被 $A_2$ 吸收，反过来亦然。净换热量为两者之差：

$$\Phi_{1,2} = A_1 X_{1,2}\,\sigma(T_1^4 - T_2^4) = \sigma(T_1^4 - T_2^4)\,\frac{1}{\dfrac{1}{A_1 X_{1,2}}}$$

定义**空间辐射热阻（space resistance）** $R_s = \dfrac{1}{A_1 X_{1,2}} = \dfrac{1}{A_2 X_{2,1}}$，黑体间的换热就可以写成「辐射势差 ÷ 空间热阻」：$\Phi = \dfrac{\sigma(T_1^4 - T_2^4)}{R_s}$。**黑体间辐射换热只受几何角系数约束**，与表面物性无关。<span class="marginnote">把 $\sigma(T^4)$ 类比为「辐射势」（像电压），$1/(A X)$ 是空间热阻（像电阻），两个黑体之间就是一条单一电阻的电路。接下来引入灰体的表面辐射热阻后，整个网络就完整了。</span>

## 3 灰体表面：表面辐射热阻

真实物体是灰体（$\varepsilon \lt  1$），其表面既不完全吸收也不完全发射，实际离开表面的辐射由**自身发射**与**反射**两部分组成，称为**有效辐射（radiosity）** $J$：

$$J = \varepsilon E_b + \rho\,G = \varepsilon\sigma T^4 + (1-\varepsilon)G$$

其中 $G$ 是投射到表面的辐射（irradiation）。灰体表面净失去的能量等于「发射 + 反射」减「吸收 + 反射」的差额，整理为

$$\Phi = \frac{E_b - J}{\dfrac{1-\varepsilon}{\varepsilon A}}$$

定义**表面辐射热阻（surface resistance）** $R_s = \dfrac{1-\varepsilon}{\varepsilon A}$。于是每个灰体表面在辐射网络里占据一个「节点 $J$」，节点到「黑体势 $E_b$」之间串着一个表面电阻。<span class="marginnote">对比两块：空间热阻 $1/(AX)$ 描述「面与面之间几何上的阻挡」，表面热阻 $(1-\varepsilon)/(\varepsilon A)$ 描述「表面本身不完美（$\varepsilon\lt 1$）带来的阻挡」。前者是几何，后者是物性，两者串联才构成完整的辐射换热路径。</span>

对**黑体**，$\varepsilon = 1$，表面热阻为零，节点 $J$ 直接等于 $E_b = \sigma T^4$；对**大空腔包围的小物体**（如热电偶在管道里、小物体在房间中），空腔内壁近似黑体，$X_{1,2} = 1$，换热简化为

$$\Phi = \varepsilon_1 A_1 \sigma(T_1^4 - T_2^4)$$

**工程上最常见的一类问题**——两个无限大平行灰体平板（隔热屏、夹层）——由两块表面电阻夹一块空间电阻串联，导出

$$q_{1,2} = \frac{\sigma(T_1^4 - T_2^4)}{\dfrac{1}{\varepsilon_1} + \dfrac{1}{\varepsilon_2} - 1}$$

注意分子分母里没有面积——平行大平板单位面积的辐射换热只取决于发射率组合。**这个公式的推广（含隔热屏）是航天器多层隔热、真空绝热的关键**。

## 4 公式解析：两块平行灰体平板的辐射网络

把上式的推导拆成三步，你就掌握了辐射网络法的精髓：

$$q_{1,2} = \frac{E_{b1} - E_{b2}}{\dfrac{1-\varepsilon_1}{\varepsilon_1} + \dfrac{1}{X_{1,2}} + \dfrac{1-\varepsilon_2}{\varepsilon_2}}$$

- **第一步**，画电路：三个电阻串联——表面 $1$ 的表面电阻 $(1-\varepsilon_1)/\varepsilon_1$、空间电阻 $1/X_{1,2}$、表面 $2$ 的表面电阻 $(1-\varepsilon_2)/\varepsilon_2$，两端是辐射势 $E_{b1} = \sigma T_1^4$ 与 $E_{b2} = \sigma T_2^4$。
- **第二步**，对平行大平板 $X_{1,2} = 1$，三个电阻相加：$\dfrac{1}{\varepsilon_1} + 1 + \dfrac{1}{\varepsilon_2} - 2 = \dfrac{1}{\varepsilon_1}+\dfrac{1}{\varepsilon_2}-1$。
- **第三步**，电势差除以总电阻，得到上面的公式。**把「辐射换热」翻译成「电路」，剩下的都是电阻串并联**。

**辐射隔热屏（radiation shield）** 是这个网络法的直接应用：在两板之间插入一块发射率相同的薄金属屏，相当于在原电路里再串两个表面电阻，总热阻大幅增加，辐射热流约**减半**。加 $n$ 块屏，热流降到原来的 $1/(n+1)$。<span class="marginnote">这就是保温瓶内胆镀银、真空镀铝膜包电缆的原理——镀银层发射率极低，表面电阻 $(1-\varepsilon)/\varepsilon$ 极大，热流被「电阻」挡死。隔热屏思想在整个低温工程与航天热控里无处不在。</span>

## 5 三表面网络：绝热表面与重辐射面

真实空腔往往不止两个表面（炉膛火焰 + 水冷壁 + 炉墙、房间四面墙 + 窗 + 人）。三表面及以上时，每个表面是一个 $J$ 节点，节点之间以空间电阻相连，节点与自身黑体势 $E_b$ 之间是表面电阻，构成一个**辐射网络图**。用电路里的基尔霍夫电流定律逐节点列方程，解出各 $J$，再求净换热。

其中有一类特殊表面值得单独理解：**绝热表面（insulated / reradiating surface）**，如炉膛内衬良好的炉墙、抛光隔热屏的边沿。它净换热量为零（$\Phi = 0$），温度自适应于其他表面之间，节点 $J$ 无法预先确定，但在网络里它退化为**一个漂浮节点**：断开与自身 $E_b$ 的连接，只通过空间电阻与各表面相连。<span class="marginnote">绝热表面不是「不参与辐射」，而是「收多少发多少」——它把别的表面发出的辐射原样「转手」到别处，所以又叫重辐射面。辐射温度计的测温误差分析、熔炉内壁设计里，重辐射面都是主角。</span>

**辐射测温的误差辨析**：用光学高温计测炉膛内真实温度时，若忽略炉墙反射，读数是「有效辐射温度」而非真实温度。想准确，必须解出包含重辐射面在内的完整网络——**「一个表面不能脱离环境单独谈温度」是辐射问题最重要的世界观**。

## 6 角系数求法与辐射网络算例

**求角系数的实用路径**（按顺序尝试）：查图表 → 代数性质推导 → 积分计算 → 数值模拟。工程上九成的情况用前两步就够。

**例：同轴平行圆盘。** 两个半径均为 $R$、间距为 $L$ 的同轴平行圆盘，角系数 $X_{1,2}$ 只依赖 $R/L$：$L = R$ 时约 0.414，$L = 2R$ 时约 0.17，$L \to 0$（贴在一起）时趋近 1。**间距越大、角系数越小，辐射交换越弱**——这是「距离平方反比」在有限尺寸表面上的体现，也是为什么高辐射表面要尽量靠近被加热物体。

**例：用完整性求空腔自见角系数。** 对封闭空腔内的表面 1，由完整性 $\sum_j X_{1,j} = 1$。若 1 是凹面能看到自己，则 $X_{1,1} > 0$；若 1 是凸面或平面，则 $X_{1,1} = 0$。**空腔内表面自见角系数 $X_{i,i} = 1 - \sum_{j\ne i}X_{i,j}$**，这条在辐射网络里专门处理「凹表面对自己辐射」的分量，解封闭空腔问题时不能漏。

**辐射网络的完整算例**：两块平行的灰体大平板，$\varepsilon_1 = \varepsilon_2 = 0.8$，$T_1 = 500$ K，$T_2 = 300$ K，求单位面积净辐射换热量。

- 平行大平板公式：$q = \sigma(T_1^4 - T_2^4)/(1/\varepsilon_1 + 1/\varepsilon_2 - 1)$；
- $500^4 = 6.25\times10^{10}$，$300^4 = 8.1\times10^9$，差 $5.44\times10^{10}$，乘 $\sigma = 5.67\times10^{-8}$ 得 $3085\ \mathrm{W/m^2}$；
- 分母 $= 1.25 + 1.25 - 1 = 1.5$，故 $q \approx 2057\ \mathrm{W/m^2}$；
- 对照黑体情形（$\varepsilon = 1$，分母为 1）$q = 3085\ \mathrm{W/m^2}$。**发射率从 1 降到 0.8，辐射换热几乎降到 2/3**——表面热阻 $(1-\varepsilon)/\varepsilon$ 的「减速」作用一目了然。

**工程应用：辐射屏与多层绝热。** 在两板间插入 $n$ 块发射率相同的薄屏，热流降为原来的 $1/(n+1)$。航天器多层隔热（MLI）就是几十层镀铝薄膜叠成的「辐射屏堆」，把日照面与背阴面之间的辐射换热压到极低——在无对流的太空环境里，这是热控的命脉。

**遮挡（blockage）**：若两表面之间存在第三个表面挡住视线，直接辐射被遮挡，角系数变小甚至为零。角系数的积分定义本身不包含遮挡，遮挡必须在建模时显式处理——**工程上「把遮挡面当作第三个节点」是常规做法**。

**气体辐射**：烟气、$\ce{CO2}$、水蒸气等气体也有吸收与发射辐射的能力，且随波长选择性很强（非灰体）。工业炉里的烟气辐射不可忽略，但气体辐射与固体表面辐射机理不同，需要专门的宽带模型——那是进阶内容，这里只需记住「透明介质」假设不是永远成立。

**角系数与距离的关系再强调**：两个互相对正的表面，间距增大一倍，$X$ 大致降为四分之一（远场近似 $X \propto 1/S^2$）；面积增大、朝向变正都会提升 $X$。**设计辐射加热装置时，「把目标放近、放正、放大」是三条基本准则**——这与光学里「对准焦」的直觉完全一致。

## 7 小结

- **角系数** $X_{1,2}$ 只依赖几何，满足**相对性** $A_1X_{1,2}=A_2X_{2,1}$、**完整性** $\sum_jX_{i,j}=1$、**可加性**（可拆分查表）。
- **黑体间换热** $\Phi = \sigma(T_1^4-T_2^4)/(1/(A_1X_{1,2}))$：只有空间热阻。
- **灰体表面**引入有效辐射 $J$ 与表面热阻 $(1-\varepsilon)/(\varepsilon A)$；黑体表面热阻为零。
- **两平行大灰体平板** $q = \sigma(T_1^4-T_2^4)/(\frac{1}{\varepsilon_1}+\frac{1}{\varepsilon_2}-1)$，隔热屏使热流按 $1/(n+1)$
