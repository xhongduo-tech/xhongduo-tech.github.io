## 为什么从数值解法开始

前两节讲的分析解（解析解）很漂亮，但适用范围极其有限：几何要规则（平壁、圆筒、球）、边界要简单（恒温、恒热流、对流）、材料要均匀。真实工程里的换热器管板、电子芯片散热器、带肋片的汽轮机叶片，没有一个是「规则几何 + 简单边界」。<span class="marginnote">上世纪中叶，这个问题只能用实验或大量简化的经验公式对付；计算机出现后，把连续的导热方程「切碎」成离散的代数方程再迭代求解，成了标准做法。今天你在任何 CFD 软件里做的第一件事，本质上都是这里讲的分割网格。</span>

这一节的目标不是写一个工业级求解器，而是让你建立**离散化直觉**：节点如何划分、能量平衡如何写成代数式、显式格式为什么会在某些步长下爆炸、隐式格式为什么稳定但代价更高。这套直觉正是第二级《数值分析》《偏微分方程数值解》与第六级《计算流体力学》的公共地基。

## 1 控制容积与节点能量平衡

数值解法的第一步是把求解区域**离散化**：用一组网格把连续物体切成许多小块，每块的中心取一个**节点（node）**，节点的温度就代表这一小块的平均温度。相邻节点之间的距离叫**步长（step size）**，记为 $\Delta x$。

离散化的灵魂是**节点能量平衡（energy balance on a node）**：**流入节点的净热流量 + 节点内源发热 = 节点热力学能的增加速率**，即

$$\sum_i \Phi_i + \Phi_V = \rho c V \frac{\mathrm{d}t}{\mathrm{d}\tau}$$

其中 $\sum_i \Phi_i$ 是周围各节点通过导热传入的热流量之和，$\Phi_V$ 是内热源（如通电发热）产生的热流量，$V$ 是节点代表的控制容积体积。<span class="marginnote">这一条与集总参数法的能量平衡是同一句话，区别只在于：集总参数法对「整个物体」写平衡，数值法对「每一个小格子」写平衡。把 N 个格子的平衡方程联立，就得到 N 个未知温度、N 个方程的代数系统。</span>

对一维问题，节点 $m$ 与左右相邻节点 $m-1$、$m+1$ 的导热热流量用傅里叶定律离散为

$$\Phi_{m-1 \to m} = \frac{\lambda A}{\Delta x}(t_{m-1} - t_m), \qquad \Phi_{m+1 \to m} = \frac{\lambda A}{\Delta x}(t_{m+1} - t_m)$$

**热流永远写成「导热系数 × 面积 × 相邻温差 ÷ 步长」**，这就是把微分的傅里叶定律替换成了差分的傅里叶定律。

## 2 显式格式与稳定性

对一维非稳态问题，把时间也离散：用 $\Delta\tau$ 表示时间步长，$t_m^n$ 表示 $m$ 节点在 $n$ 时刻的温度。时间导数用向前差分近似，即用上一时刻 $n$ 的节点温度计算当前时刻 $n+1$ 的温度：

$$\rho c \frac{t_m^{n+1} - t_m^n}{\Delta\tau} = \lambda \frac{t_{m+1}^n + t_{m-1}^n - 2 t_m^n}{(\Delta x)^2}$$

整理后得到**显式格式（explicit scheme）**的推进公式：

$$t_m^{n+1} = Fo \cdot (t_{m+1}^n + t_{m-1}^n) + (1 - 2Fo)\, t_m^n$$

其中 $Fo = \dfrac{a\,\Delta\tau}{(\Delta x)^2}$ 是网格 Fourier 数。这个格式的名字来自它的用法：**只用第 $n$ 层已知的温度，一步就能算出第 $n+1$ 层**，无需解方程组。

**显式格式的致命软肋是稳定性。** 注意 $t_m^{n+1}$ 是 $t_m^n$ 的加权平均，只有当权重非负、即 $1 - 2Fo \geq 0$ 时，解才不随推进而振荡发散。于是得到稳定性判据：

$$Fo = \frac{a\,\Delta\tau}{(\Delta x)^2} \leq \frac{1}{2}$$

**当时间步长超过 $\Delta\tau_{max} = \dfrac{(\Delta x)^2}{2a}$ 时，显式格式的温度解会出现非物理的振荡甚至发散**。<span class="marginnote">注意 $\Delta\tau$ 的限值与 $\Delta x$ 的平方成反比——网格加密一倍，时间步长要缩小到四分之一。这就是显式格式「怕小网格」的原因，也是工程上常常被迫用隐式格式的动机。</span>

**辨析｜易错点：这里的 $Fo \le 1/2$ 是稳定性条件，不是精度要求。** 初学者常把两者混为一谈：满足稳定只是「解不爆炸」，若时间步长偏大，即使稳定，解的截断误差也可能不可接受；稳定性只管发散，精度靠收敛性分析保证。

## 3 隐式格式与代数方程

把空间二阶差分改取 $n+1$ 时刻的温度，就得到**隐式格式（implicit scheme）**：

$$t_m^{n+1} = Fo \cdot (t_{m+1}^{n+1} + t_{m-1}^{n+1}) + (1 - 2Fo)\, t_m^{n} \;\Rightarrow\; -Fo\, t_{m+1}^{n+1} + (1+2Fo)\, t_m^{n+1} - Fo\, t_{m-1}^{n+1} = t_m^n$$

未知温度 $t_{m}^{n+1}$ 出现在方程两边，不能逐个推进，必须把整条线上所有节点方程联立起来解一个三对角方程组。**三对角方程组（tridiagonal system）** 可以用追赶法（Thomas algorithm）在 $O(N)$ 时间内求解，这是隐式格式能成为工业标准的工程基础。

隐式格式的最大优点：**无条件稳定**，时间步长不再受 $\Delta\tau \le (\Delta x)^2/(2a)$ 限制，可以大步长推进到稳态。<span class="marginnote">代价是要解方程组，每一步的计算量高于显式格式的一步。工程哲学在这里很鲜明：显式省时但受稳定性钳制，隐式多花点解方程组但随便跨大步——多数非稳态导热仿真选隐式，因为它可以在保证稳定的前提下用尽量大的 $\Delta\tau$ 逼近稳态。</span>

**稳态问题的数值解** 是非稳态取 $\Delta\tau \to \infty$ 的极限：令 $\partial t/\partial\tau = 0$，节点方程退化为

$$t_m = \frac{t_{m-1} + t_{m+1}}{2} \quad (\text{无内热源})$$

即**稳态时每个内部节点的温度等于相邻节点的平均值**——这正是拉普拉斯方程的离散形式。求解方法有两条路：一是写成线性方程组直接解（高斯消元/迭代）；二是用**高斯-赛德尔迭代（Gauss-Seidel）**：反复用「新算出的邻居温度」更新每个节点，直到相邻两次迭代的温差小于容许误差。

## 4 公式解析：一个带对流边界的数值例子

让边界条件进入数值解，是初学者最常卡壳的地方。以一块一维平板、右边界与温度为 $t_\infty$ 的流体对流换热（换热系数 $h$）为例，右端节点 $N$ 的能量平衡中，向右不再有「固体邻居」，而是对流换热量 $hA(t_\infty - t_N)$：

$$\frac{\lambda A}{\Delta x}(t_{N-1} - t_N) + hA\,(t_\infty - t_N) + \Phi_V = 0$$

- **第一步**，写出对 $N$ 节点的所有传热项：左边来自内部节点 $N-1$ 的导热，右边是边界对流，加上可能的内热源；
- **第二步**，令流入总和为零（稳态无储能项），整理出 $N$ 节点的代数方程；
- **第三步**，引入对流换成边界条件系数 $Bi_\Delta = \dfrac{h\,\Delta x}{\lambda}$，方程可化为标准形式，与内点方程一起构成三对角系统。

**对流边界数值化的直觉：把边界对流想象成「一个假想邻居」**——这个邻居温度是 $t_\infty$，它与节点 $N$ 之间的「等效导热系数」为 $h\Delta x$。于是边界节点和内部节点写法统一，一套算法处处通用。<span class="marginnote">这种「把未知边界条件装进虚拟节点、从而统一处理」的思想，在有限元、有限体积里都是基本手法，也与《传热学》第3章把对流问题折算成等效边界的思想一致。</span>

## 5 数值算例：一维稳态导热的逐次迭代

把前三节的知识串成一个最小可手算的例子。**一根长 1 m 的匀质细杆**，两端温度固定 $t_0 = 100$ °C、$t_4 = 0$ °C，无内热源，杆侧面绝热。取 5 个节点（编号 0–4），步长 $\Delta x = 0.25$ m。稳态时内部节点满足「等于相邻节点平均」：

- **方程**：$t_1 = (t_0 + t_2)/2$，$t_2 = (t_1 + t_3)/2$，$t_3 = (t_2 + t_4)/2$，边界 $t_0 = 100$、$t_4 = 0$。
- **高斯-赛德尔迭代**：先猜 $t_1 = t_2 = t_3 = 50$，然后逐节点更新，每次都用「最新算出的邻居」：
  - 第 1 轮：$t_1 = (100+50)/2 = 75$，$t_2 = (75+50)/2 = 62.5$，$t_3 = (62.5+0)/2 = 31.25$；
  - 第 2 轮：$t_1 = (100+62.5)/2 = 81.25$，$t_2 = (81.25+31.25)/2 = 56.25$，$t_3 = (56.25+0)/2 = 28.125$；
  - 继续迭代，若干轮后收敛到精确解 $t_1 = 75$、$t_2 = 50$、$t_3 = 25$——温度沿杆线性分布，与解析解完全一致。
- **收敛判据**：相邻两轮各节点温度差的最大值小于容许误差（如 $10^{-4}$）即停止迭代；迭代次数越多越接近真解，但不会一步到位。

**网格无关性检验**：网格越细，节点越多，每轮迭代计算量越大，但解的空间分辨率越高。**工程纪律是：不断加密网格，直到结果不再明显变化**——如果 5 节点与 10 节点算出的某点温度差了几个百分点，说明网格还不够细，直接拿粗网格的结果去设计是危险的。这个「网格无关性」意识，是数值解法与解析解最重要的区别：解析解给出的是「唯一真值」，数值解必须自证「收敛到了哪里」。

**把非稳态加进去**：若上例变成瞬态问题，显式格式每步推进 $t_m^{n+1} = Fo(t_{m+1}^n+t_{m-1}^n) + (1-2Fo)t_m^n$，时间步长受 $Fo \le 1/2$ 钳制；隐式格式则用追赶法一步解出整条线上所有节点的 $n+1$ 层温度，步长随意取。**同样的物理，两套离散，一套怕步长、一套不怕**——数值稳定性从来都是「格式 + 时间步长 + 空间网格」三方谈判的结果。在第二级《偏微分方程数值解》里，你会看到这套谈判的严格理论（Von Neumann 稳定性分析），这里先建立直觉。

**数值解法的误差来源**：截断误差（离散化把导数换成差分时丢掉的项）与舍入误差（计算机有限精度）是两个来源。加密网格同时减少截断误差，但网格过细会放大舍入误差与计算量。**「网格独立性 + 收敛性检验 + 与解析解/实验对照」三件套，是判定数值解可信度的标准姿势**——任何仿真报告若只给结果、不说明网格与收敛判据，结论都应当存疑。

| 格式 | 时间步长 | 每步成本 | 稳定性 | 适用 |
| --- | --- | --- | --- | --- |
| 显式 | 受 $Fo \le 1/2$ 限制 | 低（无需解方程组） | 有条件稳定 | 网格粗、步长小、教学演示 |
| 隐式 | 不受限 | 中（解三对角方程组） | 无条件稳定 | 工程仿真主流 |
| Crank-Nicolson | 中等 | 中 | 无条件稳定 | 时间精度二阶、初始段可能振荡 |

**Crank-Nicolson 格式**对时间取中心差分，时间方向精度比纯隐式高一阶，但初始几步可能出现振荡。工业软件常以隐式为主、Crank-Nicolson 为可选——**选格式是精度、稳定性、成本三者的权衡，没有「最好」，只有「最适合」**。

## 6 小结

- **离散化**：把连续区域切成节点网格，对每个节点写能量平衡，得到代数方程组。
- **显式格式**：$t_m^{n+1}$ 直接由第 $n$ 层算出，**稳定性条件 $Fo \le 1/2$**，网格加密则时间步长按平方收缩。
- **隐式格式**：未知温度互相耦合，需解三对角方程组（追赶法 $O(N)$
