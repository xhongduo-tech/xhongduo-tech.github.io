## 为什么从宏观核算开始

贸易篇到此为止，接下来进入货币与宏观的世界。
开放经济与封闭经济的第一道分水岭，就是**账本**：国家与外国之间每一笔交易都要被记进一套复式簿记——国际收支平衡表。
不会读这套账，就无法理解汇率、逆差、储备与危机。
而账本的起点，是搞清楚**国民收入到底怎么算**，以及它如何与国际收支咬合。
<span class="marginnote">这章是「从极限到大模型」体系里经济学的承上启下点：宏观篇的 IS-LM、货币篇的需求方程、发展篇的外债危机，全部从本节的几个恒等式出发。
花一节课把恒等式钉死，后面全是应用。</span>

## 1 GDP 与 GNP：属地与属人的区别

**GDP（国内生产总值）**：在一国**境内**生产的最终商品与服务的价值，与生产者国籍无关。
<span class="marginnote">把「属地」记为「谁在我这里干活的增加值」，把「属人」记为「我的人在哪里干活的增加值」——中国苹果手机组装线的增加值记入中国 GDP；若生产的是中国公司海外工厂，则记入中国 GNP 而非 GDP。
</span>**GNP（国民生产总值）**：由**本国要素**（本国人、本国资本）获得的收入，无论要素在哪里工作。关系：

$$GNP = GDP + \text{本国要素从国外的净收入}$$

两者之差衡量要素流动的规模——上一节《国际要素流动》的账本落点就在这里。
<span class="marginnote">现实里跨国公司大国（美国、日本）的海外投资收益可观，GNP 常高于 GDP；吸收大量外资的国家（不少发展中国家）则相反。
这个差值的大小本身就是「要素流动度」的读数。</span>

## 2 开放经济的国民收入恒等式

封闭经济的恒等式是 $Y = C + I + G$（无外部部门）。
开放后加进**净出口**，还有净要素收入与净转移，合称**经常账户（current account, CA）**：

$$Y = C + I + G + CA$$

移项得到 CA 的第一种理解：

$$CA = Y - (C + I + G)$$

**经常账户**：一国对世界其他地区的净贷款（或净借款）。

用一个国家账本的例子走一遍：设某年 $Y = 100$、$C = 60$、$I = 25$、$G = 20$，则 $CA = 100 - 105 = -5$。
该国产出不够花，缺口 5 必须由世界来补——表现为贸易逆差加净要素支出，同时对应的金融账户必然有 5 的净资本流入。
这就是「恒等式不是政策建议」的意思：CA 为负本身无所谓好坏，要看借来的钱是投入了高回报投资（好）还是补贴了消费（糟）。
CA > 0 表示**产出大于国内吸收**（消费+投资+政府），多余部分借给世界；CA < 0 表示本国向世界借钱来补上国内支出的缺口。
<span class="marginnote">「经常账户盈余 = 对外净贷款」这句翻译很重要：它把「贸易」与「金融」连成一体——你出口多、进口少，本质是在给贸易伙伴提供融资。
反过来，美国常年贸易逆差意味着它在向世界借款。</span>

## 3 公式解析：CA 等于储蓄减投资

把 CA 与储蓄联系起来，是本节最重要的恒等式。
令 $S_p = Y - T - C$（私人储蓄），$S_g = T - G$（政府储蓄），则：

$$
CA = Y - C - G - I = (Y - T - C) + (T - G) - I = S_p + S_g - I = S - I
$$

- **第一步，从 $Y - C - I - G$ 出发**：这是第 2 节公式的移项，CA 是产出超出国内吸收的部分。
- **第二步，拆储蓄**：加入税收 $T$ 后，私人储蓄加政府储蓄恰好替换掉 $Y - C - G$。恒等变形不引入任何新假设——**这不是行为方程，是会计恒等式**。
- **第三步，读出政策含义**：$CA = S - I$ 说明贸易逆差 = 储蓄不足（投资大于储蓄）。若政府赤字扩大（$S_g$ 下降）而 $S_p$、$I$ 不变，CA 必然恶化——**这就是「双赤字」现象的代数源头**：财政赤字与经常账户赤字常结伴而行。

把恒等式用到今天的全球经济，能读出不少「意外」：2008 年前美国财政赤字与经常账户赤字并存（双赤字），中国则财政与经常账户双盈余——储蓄过度流向海外。
但恒等式也警告我们别做因果推断：$CA = S - I$ 只是恒等关系，财政赤字并不必然导致 CA 恶化，还要看私人储蓄与投资的反应——有时是 CA 变化带动财政，而非相反。
**恒等式给的是约束，不是因果；政策分析必须在约束之上再谈行为方程**。<span class="marginnote">反过来说，想让 CA 好转的捷径不是关税（关税改变的是相对价格，恒等式仍必须成立），而是提高储蓄或削减投资需求。政策讨论里最常见的错误，就是把贸易逆差当成「外贸部门出了问题」，而恒等式说它其实是「储蓄-投资缺口」的镜像。</span>

## 4 国际收支平衡表：复式簿记

**国际收支平衡表（balance of payments）**记录一国与世界的全部交易，分两大账户：

- **经常账户（CA）**：商品与服务贸易、投资收益、单边转移；
- **金融账户（KA）**：资本流动——本国居民购买外国资产、外国居民购买本国资产、官方储备变动。

每笔交易在簿记上记两次，所以恒有：

$$CA + KA = 0$$

这既是复式簿记的必然结果，也是 CA 定义的另一种体现：**经常账户盈余必须对应等额的资本净流出**。

实操里，国际收支平衡表的恒等式并不「自动」成立——各国的海关、央行、统计局的记录口径不一，**统计误差与遗漏（errors and omissions）**科目常年存在。
中国「热钱之谜」曾让统计误差与遗漏一度巨大：大量资本以虚假贸易面目进出，账面上表现为 CA 与 KA 之和的残差。**所以看到「CA + KA ≠ 0」不要慌，先查统计误差与遗漏**——它是账面之外资本流动的侦探线索。
若一国 CA 为 +1000 亿美元，则它必然向世界贷出 1000 亿美元（购买外国资产或减少外债）。
<span class="marginnote">理解 $CA + KA = 0$ 是读懂「资金回流」新闻的关键：美国巨额经常账户逆差，必然伴随等额的资本净流入（外国人买美国国债、股票、企业）。
所以「美债被外国持有」与「美国逆差」是同一枚硬币的两面。</span>

**辨析｜易错点：** 别把「国际收支平衡表」与「国际收支危机」混为一谈。
平衡表永远「平衡」（复式簿记），危机发生在**资本流动逆转**时：当外国投资者突然不愿再为逆差融资（KA 骤降），CA 被迫急剧收缩，汇率暴跌——这就是第 15、22 节要讲的货币危机机制。

## 5 官方储备与储备货币

金融账户里有一个特殊科目：**官方储备资产**。
中央银行买卖外汇资产（美元国债、黄金、特别提款权）会记入金融账户。
若央行购入美元、积累储备，金融账户的储备科目为正；若消耗储备捍卫汇率，则储备下降。
<span class="marginnote">固定汇率制下，储备是「调节阀」：逆差国用储备填补缺口，顺差国积累储备。
储备的增减反过来成为货币供给的一部分——这是下一节《汇率与开放经济宏观》与固定汇率章的机关所在。</span>

顺差国的储备积累并非只是「数字游戏」：它同时是本国的对外债权与货币投放。
中国 2000 年代的双顺差下，央行买入美元、释放人民币，再通过发行央票、提高准备金率「冲销」，把流动性收回来——**储备的规模，直接决定了货币政策的操作空间**。
一旦储备由增转减，意味着一国开始动用「对外债权」为国内支出融资，这个过程在货币危机章节会变成惊悚片。
一国货币若被别国当作储备资产（美元、欧元），该国获得「过分的特权」——它用几乎零成本的纸币换取真实商品，同时把通胀压力输出给持有国。
<span class="marginnote">特里芬在 1960 年代已警告：储备货币国的逆差是体系必需品（别国需要美元储备）却又是该货币信用的掘墓人——「特里芬难题」是国际货币体系篇的主角。</span>

## 6 小结

- **GDP** 属地、**GNP** 属人，差值是净要素收入；GNP = GDP + 净要素收入。
- 开放恒等式：$Y = C + I + G + CA$，故 $CA = Y - (C+I+G)$，CA 是**对外净贷款**。
- 核心恒等式：$CA = S - I$——贸易逆差即储蓄缺口，「双赤字」由此而来。
- 国际收支：$CA + KA = 0$，经常账户盈余必对应资本净流出；表恒平衡，危机是**资本逆转**。
- 官方储备是固定汇率的调节阀，储备货币地位带来「过分特权」与特里芬难题。
- **统计误差与遗漏**是账面之外的资本流动线索：CA + KA 不恒等于零时，先查这个科目再下结论。
