## 为什么从开放经济宏观开始

上一节我们把账本建好，现在要问：**汇率在宏观经济里到底起什么作用？** 它既受货币政策影响，又反过来决定贸易余额与产出。
开放经济让宏观政策的逻辑发生根本变化：封闭经济里印钞只影响物价，开放经济里它还推动汇率、改变净出口、反过来影响总需求。
本节用**利率平价**把货币市场与外汇市场焊成一个整体，再纳入产出决定，得到 DD-AA 框架——这是后续所有汇率体制分析（固定汇率、货币危机、最优货币区）的公共底座。
<span class="marginnote">DD-AA 是蒙代尔-弗莱明模型（Mundell-Fleming）的现代版本。
蒙代尔为此获得 1999 年诺贝尔奖，他的核心贡献正是「资本自由流动下，货币政策与固定汇率只能二选一」——本节第三节的结论。
</span>

## 1 汇率：名义与真实

**名义汇率（nominal exchange rate, E）**：两种货币的兑换比价，定义为本币兑换单位外币的数量（1 美元 = 7.2 元人民币，则 $E = 7.2$）。
E 上升为**本币贬值（depreciation）**，E 下降为本币升值（appreciation）。
<span class="marginnote">汇率有两种报价习惯（直接/间接标价），本教材统一用「本币/外币」：E 变大 = 本币更不值钱 = 贬值。读数据前先确认标价法，是新手最常见的坑。</span>

**真实汇率（real exchange rate, q）**：用两国商品相对价格衡量的汇率，度量本国商品相对外国商品的竞争力：

$$q = \frac{E \times P^*}{P}$$

$P^*$ 是外国物价，$P$ 是本国物价。q 上升意味着本国商品相对变便宜，出口更有竞争力、进口更贵——**真实汇率才是影响贸易流量的量**，名义汇率只是它的「皮毛」。

数字示例：若美元/人民币名义汇率 $E = 7$，美国物价指数 $P^* = 100$、中国 $P = 120$，则真实汇率 $q = 7 \times 100/120 \approx 5.83$。
若人民币名义升值到 $E = 6.5$ 而物价不变，$q$ 降至 5.42——人民币真实升值，中国商品变贵、竞争力下降。
注意：名义升值未必是真实升值，若同时中国物价上升更快，真实汇率可能反而贬值。**判断竞争力，永远看真实汇率，不看名义汇率**。
<span class="marginnote">注意真实汇率与经常账户并无机械联系：q 上升改善贸易余额需要满足马歇尔-勒纳条件（进出口弹性之和大于 1），否则「本币贬值反而恶化逆差」。
J 曲线效应说的正是这种时滞。</span>

## 2 公式解析：利率平价

外汇市场的均衡由**利率平价**钉住：

$$
R = R^* + \frac{E^e - E}{E}
$$

$R$ 是本币存款利率，$R^*$ 是外币存款利率，$E^e$ 是预期未来汇率。三步拆解：

- **第一步，两侧各是什么**：把 $R$ 元存本币一年得 $1 + R$；换成外币存一年再换回，得 $(1 + R^*) E^e / E$。两种策略的收益要相等，否则资金狂涌向高收益方，价格被拉平。
- **第二步，为什么成立**：资本自由流动 + 完全替代下，收益差瞬间被套利抹平。把两边取近似，得 $R \approx R^* + (E^e - E)/E$——**本币利率 = 外币利率 + 预期贬值率**。
- **第三步，汇率如何被预期主导**：若市场预期本币将贬值（$E^e$ 大），则 $R - R^*$ 必须相应上升以补偿持有者——利率差与预期贬值互为镜像。**汇率今天的水平，一半是资产市场对未来预期的现值**，这解释了下节「汇率为什么大幅波动」：预期一动，汇率即动。<span class="marginnote">由此，外汇市场被归入「资产市场」而非「商品市场」：汇率像股票价格一样，受消息与预期驱动、波动远大于基本面。所有「汇率该值多少钱」的讨论，都要从这条等式出发。</span>

## 3 产出决定与 DD-AA 框架

开放经济的总需求为 $D = C + I + G + \text{净出口}$，其中净出口随真实汇率贬值而增加。
商品市场均衡（产出 = 需求）给出 **DD 曲线**：Y 随 E 上升而上升（贬值 → 出口增 → 产出增）。
<span class="marginnote">与封闭经济的区别：总需求多了一个「受汇率支配」的渠道。贬值相当于对本国商品的全局折扣，把外国需求请进来。
这也是「以邻为壑的贬值」的政策来源——但对方贬值回敬，总效果归零。</span>

资产市场均衡由两部分组成：货币市场 $M^s/P = L(R, Y)$（货币需求随利率降、随产出升）与外汇市场利率平价。
两者合起来给出 **AA 曲线**：E 随 Y 上升而上升（产出升 → 货币需求升 → 利率升 → 为满足平价、本币需预期贬值 → E 上升）。

均衡在 DD 与 AA 的交点。政策影响一目了然：

**货币扩张**：$M^s$ 增 → 利率下降 → 本币贬值（AA 右移）→ 净出口增、产出升。**浮动汇率下货币政策有效，且靠汇率传导**。
- **财政扩张**：$G$ 增 → 产出升、货币需求升、利率升 → 本币升值 → 净出口被挤出（DD 右移）。**浮动汇率下财政政策的扩张效应被升值部分抵消**——「挤出」从利率渠道换成了汇率渠道。<span class="marginnote">这是开放宏观最容易混淆的一对结论：浮动汇率下「货币有用、财政半用」。里根 1980 年代初的减税+紧缩货币组合，正是升值与逆差并存的教科书案例。</span>

## 4 固定汇率下的政策失效

若央行**固定汇率**，情形反转。
央行必须随时在既定汇率上买卖外币，货币供给就不再独立——套利者若预期贬值，会抛售本币，央行必须用储备买入以维持平价，**储备流失即货币收缩**。
于是：

货币扩张被「被迫购汇」抵消，**货币政策在固定汇率下无效**；
- 财政扩张导致利率上升、资本流入，央行被迫**扩张货币**，财政效果被放大。

这个「财政有效、货币无效」的格局，是理解欧洲与东亚政策史的钥匙：欧洲汇率机制时代，各国无法用货币政策应对本国衰退，只能靠财政——而当财政纪律（马斯特里赫特标准）同时收紧，衰退国便陷入「既无货币、又无财政」的双重困境。
固定汇率不是「把货币政策交出去」，而是「把货币政策换成对财政政策的依赖」——前者失效的代价，由后者加倍偿还。

**重点：三元悖论的雏形**——固定汇率、资本自由流动、独立货币政策，三者最多取其二。

三元悖论解释了为什么「浮动 + 自由流动」的国家（美国、欧元区、日本）在危机时不必动用资本管制，而「固定 + 管制」的国家（中国）则可以同时守住汇率与独立货币——代价是牺牲资本自由流动的效率。
每一国都在三角里选边，而**选边的依据是本国冲击的来源**：冲击若来自商品市场，浮动更有利；冲击若来自资本流动，管制或固定更省心。
蒙代尔-弗莱明的这个结论，是整个国际货币体系篇的骨架。
<span class="marginnote">中国长期的选择是「固定（管理浮动）汇率 + 资本管制 + 独立货币」，用牺牲资本自由流动换取政策空间；欧元区则放弃独立货币政策。
哪种组合更优，是最优货币区篇的话题。</span>

## 5 J 曲线与汇率传导

真实世界给教科书加了两条皱纹：

**J 曲线效应**：贬值后贸易余额先恶化后改善——进口价格立即上升（量变慢）、出口量随后才爬升（合同与产能滞后）。
图形上画成字母 J。
<span class="marginnote">典型时滞：本币贬值 20% 后，前半年贸易余额可能继续恶化，一年后才转为改善。所以「贬值改善逆差」不是即时的，政策评估要看两年窗口。</span>

**汇率传导（pass-through）**：贬值在多大程度上转成进口品国内价格上升？
现实中远小于 1——企业通过**定价到市场（pricing to market）**吸收汇率变化。

中国的经验是检验传导理论的天然实验：2005–2015 年人民币对美元累计升值约 25%，但中国出口商品的美元价格仅温和上升、出口量依然增长——企业通过压缩利润率「吃下」了升值。
这既说明定价到市场的普遍性，也说明**汇率政策的效力取决于产业的定价能力**：有定价权的企业能对冲汇率，无定价权的企业只能接受冲击。
对宏观政策的含义是：试图用「一次性贬值」修复竞争力，可能只压缩利润而非刺激出口。
传导低意味着：贬值改善贸易余额靠的是「数量调整」而非「价格竞争」，J 曲线更深、更慢。
<span class="marginnote">若传导率低，本币贬值并不会立即引爆输入性通胀——这给浮动汇率制下的货币政策留了空间，也是新兴市场「怕贬值」心理的一个注脚。</span>

## 6 小结

- 名义汇率 $E$（本币/外币）与真实汇率 $q = EP^*/P$；真实汇率才决定贸易流量。
- **利率平价** $R = R^* + (E^e - E)/E$ 把汇率归入资产市场，汇率受预期驱动、天然波动剧烈。
- **DD-AA 框架**：DD 是商品市场（贬值增产出），AA 是资产市场（产出升则本币贬值）。
- 浮动汇率下**货币政策有效**、财政政策被升值挤出；固定汇率下**货币政策失效**、财政政策被放大。
- 三元悖论：固定汇率、资本自由流动、独立货币政策不可兼得。
- 利率平价让外汇市场归入资产市场，汇率波动因此是常态而非异常——它由预期驱动，而非贸易流驱动。
- **J 曲线**与低传导率让贬值的实际效果滞后且打折。
