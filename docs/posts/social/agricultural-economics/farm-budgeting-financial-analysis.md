## 为什么从预算开始

上一篇我们把农场管理定义为「计划—控制—反馈」的循环。这一篇给它装上数字：**预算是计划的量化形态**。Barnard & Nix 的预算体系像套娃——从最细的**部分预算**（改一个决定，差多少）到**现金预算**（钱够不够花），再到**整体预算**（整个农场合不合算），最后用**盈亏平衡分析**找出「不赔不赚」的门槛。这四件工具在农场管理中几乎每天都被用到。

## 1 部分预算：改一个决定值不值

**部分预算（partial budget）**：只比较某项决策引起的**增减变化**，不重算全部账目。它把变化拆成四类：

- **增加的收益**：改种新品种后增加的产值；
- **减少的成本**：改用机械后省下的人工费；
- **减少的收益**：为上新项目放弃的旧项目收益（机会成本）；
- **增加的成本**：新项目新增的支出。

**净效果 =（增加收益 + 减少成本）−（减少收益 + 增加成本）**。净效果 > 0，这个改变值得做。<span class="marginnote">部分预算的思想与边际分析一脉相承：决策只关心「差分」。这正是第二篇「边际收益 = 边际成本」在生产方案比较上的朴素形态——不重算全局，只算变化量。</span>

**重点：部分预算的威力在于它的「免算」**。不必知道整个农场的总成本，只需估计被改变的几项。对「要不要多种五亩」「要不要租一台收割机」这类高频问题，部分预算几十分钟就能给出答案。

## 2 现金预算：钱会不会断流

**现金预算（cash flow budget）**：按月（或按季）列出预期的现金流入与流出，回答一个尖锐的问题——**在收获变现之前，有没有哪个月付不出工资、还不上贷款？**

农业现金流有强烈的季节性：春播时集中支出（种子、化肥、雇工），秋收后才集中收入。**一个「全年账面盈利」的农场，完全可能在某个月因现金流断裂而被迫贱卖资产**——这就是「盈利但破产」的悖论。<span class="marginnote">现金预算与会计利润是两个口径：利润是权责发生制（收入与费用按归属期计），现金流是收付实现制（只看钱的实际进出）。判断农场能否存活，现金流口径更关键——这也是银行审核农业贷款时第一个看现金预算表的原因。</span>

现金预算表的结构是逐月两列：

| 项目 | 1月 | 2月 | … | 12月 |
| --- | --- | --- | --- | --- |
| 期初现金余额 | | | | |
| ＋现金流入（销售、贷款） | | | | |
| −现金流出（生产、生活、还贷） | | | | |
| ＝期末现金余额 | | | | |

**凡出现负余额的月份，就是需要短期融资或调整生产计划的信号。** 预算是「防断流」的底线工具，不是盈利预测工具。

## 3 整体预算：整个农场合不合算

**整体预算（whole-farm budget）**：把一个农场的全部生产项目、全部成本收入合成一张年度账，检验整体计划的可行性——包括**资源是否够用**（土地、劳动、机器在忙季是否冲突）与**总收益是否合算**。

整体预算的通常步骤：确定生产组合与规模 → 估算各项目产值与可变成本（用第六篇的 GM）→ 汇总固定成本（地租、折旧、保险、管理费）→ 得全农场净收益 → 与「目标收益」对照。

**辨析｜易错点：**整体预算容易出现三类「温柔的错误」——把自家劳动的机会成本漏算（第六篇已强调）、把折旧与还贷混淆（折旧是设备价值损耗，还贷是现金流出，两者口径不同）、忙季劳畜力冲突未校验（两个项目各自划算，但同一周都要用人就爆表）。整体预算的价值一半在于最后这项**资源冲突检查**。<span class="marginnote">整体预算的资源冲突检查，本质上是第八篇线性规划约束条件的雏形：土地、劳动、资金在各生产项目间分配，且不能超总量。预算用手工验算小规模组合，线性规划用算法求解大规模组合——工具在升级，问题没变。</span>

## 4 盈亏平衡分析：不赔不赚的门槛

**盈亏平衡分析（break-even analysis）**：求「总收入恰好等于总成本」时对应的产量或价格，把生产函数、成本与价格压缩成一道算术。

记总固定成本为 $FC$，单位产品可变成本为 $AVC$，单价 $P$，则盈亏平衡产量 $Q^*$ 满足总收入 = 总成本：

$$
TR = TC \quad\Rightarrow\quad P \cdot Q^* = FC + AVC \cdot Q^*
$$

解得：

$$
\boxed{\; Q^* = \frac{FC}{P - AVC} \;}
$$

**分母 $P - AVC$ 是每单位产品对固定成本的贡献**——卖出 1 单位，收入 $P$ 减去可变成本 $AVC$，剩下的钱用来「还」固定成本；把 $FC$ 还清的那个产量就是保本点。高于 $Q^*$ 盈利，低于 $Q^*$ 亏损。同理可解**盈亏平衡价格** $P^* = AVC + FC/Q$：给定产量，单价至少要卖到多少才不亏。<span class="marginnote">盈亏平衡分析把第二篇的固定/可变成本概念变成一把尺子。它在第八篇线性规划、以及工业/金融领域的本量利分析中反复出现——一个公式，多处复用。</span>

**辨析｜易错点：**$P - AVC$ 是**单位贡献毛益（contribution margin）**，不是毛利润率，更不是净利润。盈亏平衡点在短期有效（固定成本不变）；若产量跨过设备容量上限，固定成本会台阶式上升，$Q^*$ 就要分段计算。另外，售价 $P$ 常随产量变化（需求弹性），严格情形需用收入曲线与成本曲线的交点。

## 5 公式解析：一个农场的保本点

设一个蔬菜农场固定成本 $FC = 200{,}000$ 元/年（地租、棚折旧、保险费），每箱菜可变成本 $AVC = 30$ 元，售价 $P = 50$ 元/箱。

**第一步，算单位贡献毛益**：$P - AVC = 50 - 30 = 20$ 元/箱——每卖一箱，有 20 元用来覆盖固定成本。
- **第二步，套保本公式**：$Q^* = FC / (P - AVC) = 200{,}000 / 20 = 10{,}000$ 箱。
- **第三步，读结论**：年产 10,000 箱才不赔不赚；若计划年产量 8,000 箱，预期亏损 $20 \times (10{,}000-8{,}000) = 40{,}000$ 元。反过来也可求保本价：若市场价跌到 40 元，则 $P^* = AVC + FC/Q = 30 + 200{,}000/10{,}000 = 50$，即原产量下单价降到 50 元以下就亏损——价格每跌 10 元，要么产量翻倍，要么亏损 100,000 元。

**直觉：保本点把「产量 × 价格 × 成本」三个量压成一个决策数**。管理者不需要算懂成本会计，只需要盯住「贡献毛益是否为正、产量是否过保本线」——这就是预算工具化管理的意义。

## 6 财务分析：衡量农场的健康度

预算回答「计划合不合算」，财务分析回答「农场财务健不健康」。常用四组指标：

- **流动性（liquidity）**：流动资产 / 流动负债——能否还清一年内到期的债务。
- **偿债能力（solvency）**：净资产 / 总资产（或资产负债率）——总资产对债务的覆盖。
- **盈利能力（profitability）**：净收益 / 投资、净收益 / 产值——资本回报率。
- **效率（efficiency）**：每公顷产值、每工日产值、饲料转化率——投入产出比。

**重点：比率要「跟过去比、跟同类农场比」才有意义。** 单个绝对值没有好坏，趋势与行业对标才说明问题：资产负债率从 40% 爬到 70%，即便盈利，抗风险能力也在恶化——这正是银行评估农业贷款时看的东西，也是第十篇农业金融的前奏。<span class="marginnote">这套「流动—偿债—盈利—效率」四维框架与公司财务的比率分析同构，但在农业上要加一层特殊性：土地往往计入资产但不产生现金，家庭劳动不计工资——口径稍有不同，结论可能翻转。</span>

## 7 小结

- **部分预算**只算决策的差分（增收益＋减成本 − 减收益 − 增成本），适合高频小决策。
- **现金预算**按月盯现金流，防「盈利却断流」；利润看权责发生制，存活看收付实现制。
- **整体预算**汇总全农场账目，重点校验资源冲突与目标收益。
- **盈亏平衡点** $Q^* = FC/(P-AVC)$ 是「不赔不赚」的门槛，分母即单位贡献毛益。
- **财务比率**分流动、偿债、盈利、效率四类，须与历史与同行对标解读。

在下一节，当生产项目很多、资源约束很紧时，手工预算就力不从心了——我们引入**线性规划**：让算法在几百个生产方案里找出最优组合，并顺带算出每份稀缺资源的影子价格。
