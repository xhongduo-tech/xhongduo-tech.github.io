# 中共党史党建学

2022年新设的一级学科，以中国共产党的历史进程与自身建设为研究对象，系统回答党如何领导人民从革命、建设走向改革复兴，以及如何自我革命、长期执政，是贯通政治学与马克思主义理论的交叉基础学科。

## 对标教材

- 中共中央党史和文献研究院.《中国共产党简史》. 人民出版社（2021）
- 中共中央党史研究室.《中国共产党的九十年》. 中共党史出版社（2016）
- 中共中央党史和文献研究院.《中国共产党的一百年》. 中共党史出版社（2022）
