# 农林经济管理

农林经济管理是管理学门类的一级学科（1203），涵盖农业经济管理、林业经济管理与农村发展三大方向，研究农业与林业生产中的资源配置、市场运行、经营管理与政策制度的基本规律。以孔祥智《农业经济学》、高岚《林业经济学》与张培刚《农业与工业化》为纲，系统覆盖从农业要素配置、农产品市场到林业生态经济与农村发展的完整分析框架。

## 对标教材

- 孔祥智《农业经济学》（第三版）中国人民大学出版社
- 张培刚《农业与工业化》华中科技大学出版社
- 高岚《林业经济学》中国林业出版社
