# 社会保障

社会保障是公共管理学的二级学科（代码120404），研究国家和社会依法建立的、保障公民基本生活与抵御生老病死残等社会风险的制度体系，涵盖社会保险、社会救助、社会福利与基金运营四大支柱，是应对人口老龄化、失业与收入分配风险的核心公共制度安排。

## 对标教材

- 郑功成.《社会保障学》. 中国劳动社会保障出版社
- 孙光德、董克用.《社会保障概论》. 中国人民大学出版社（第六版）
