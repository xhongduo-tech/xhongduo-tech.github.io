# 个案工作方法

## 为什么从个案工作开始

上一节我们学了一部五步「操作系统」，现在把它装进最经典的机身——**个案工作**。它是社会工作历史最久、方法论最成熟、也是多数人首先想到的形态：一位社工，一间会谈室，一段关系，一个案主。但「个案工作 = 聊天」是最流行的误解。本节的要害是：个案工作是**有理论、有结构、有技术**的专业过程，它的每一步都可回溯到《理论框架》与《通用实务过程》两节。更重要的是，个案工作方法给出了一套**关于关系本身的技术**——会谈、倾听、记录、契约，这些能力在小组、社区、行政工作中全部复用。<span class="marginnote">王思斌版教材把个案工作定义界定为「以个人或家庭为对象的社会工作方法，通过建立专业关系、运用专业技术，帮助个人与家庭解决问题并增强其社会功能」。注意两个词：专业关系、社会功能——个案工作瞄的不是「心理痊愈」，而是「人在社会中的功能恢复」。</span>

## 1 个案工作的要素与特征

个案工作的构成可拆为四个要素：

**对象**：个人或家庭，重点是「遭遇困境、有改变动机（或需要被激发动机）」者。
- **目标**：恢复与增强社会功能——问题解决、能力提升、资源整合、潜能开发。
- **方法**：建立专业关系，运用会谈、评估、记录、契约等技术。
- **过程**：接案—预估—计划—介入—评估的完整闭环（上一节已学）。

由此可见**个案工作的四个特征**：一是**个别化**——每个案主的处境都是「这一个」，没有两张相同的处方；二是**以关系为媒介**——改变发生在专业关系之中，关系本身就是工具；三是**双向性**——案主不是被动接受者，而是改变的主体；四是**注重社会功能**——不只关注内心，更关注案主与环境的适配。

这四个特征共同指向一个判断：**个案工作的成效，最终取决于案主是否真的「动起来」了**——社工提供的是脚手架，而建筑是案主自己盖的。

**核心要点：** 个案工作与「心理咨询」的边界是经典考题。一张对比表厘清分野：

| 维度 | 个案工作 | 心理咨询 |
| --- | --- | --- |
| 问题域 | 社会功能、生活困境、资源 | 心理障碍、情绪困扰 |
| 视角 | 人在情境中（PIE） | 个人内在心理过程 |
| 介入手段 | 会谈 + 资源整合 + 环境调整 | 以谈话治疗为主 |
| 对象 | 普通困境者到弱势群体 | 以求助心理者为主 |
| 目标 | 恢复社会功能 | 缓解或消除症状 |

**辨析｜易错点：** 两种专业有大量重叠（会谈技术、助人关系），但**它们的终极关切不同**：心理咨询问「你的内心如何」，个案工作问「你与你的处境如何相处」。社工不擅长的精神病理评估，要转介给心理咨询或精神科——转介本身就是个案工作的专业动作，而非失败。

## 2 会谈：个案工作的核心技术

会谈不是聊天，而是**有目的、有结构、有技术的人际互动**。会谈按功能分三类：**收集信息性会谈**（预估阶段）、**诊断性会谈**（评估问题成因）、**治疗性会谈**（介入阶段）。无论哪类，都靠一套可训练的技术支撑：

- **倾听与反应**：不只听内容，也听情绪与潜台词；用「反映」（reflection）复述案主的感受，让案主感到被懂。
- **澄清与聚焦**：把模糊的抱怨（「我什么都完了」）澄清为具体的处境（「失业三个月、被房东催租、孩子学费无着」）。
- **提问技术**：少用「为什么」（容易引发防御），多用开放式提问（「发生了什么？」）与具体化提问（「是哪一天？当时你在哪？」）。
- **摘要**：会谈中段与结束时，用一两句话汇总要点，确认双方理解一致，也把会谈「收进」框架。
- **同理心**：**设身处地理解案主感受并让对方知道被理解**——它是技术，不是同情。罗杰斯把「共情」列为助人关系的核心条件之一。

**核心要点：** 会谈质量的标尺不是「我说了多少」，而是「案主被激发了多少」。**沉默、停顿在会谈中不是故障，而是案主在组织语言——急于填补沉默的社工往往打断了案主最深的表达。**<span class="marginnote">社工的自传性反应（self-disclosure）需克制：偶尔适度分享个人经验可以拉近关系，但过度自述会把焦点从案主移向社工自己。判断标准只有一个——「这个分享对案主有用吗？」</span>

把常用技术按「功能」整理成一张速查表，便于对照使用：

| 技术 | 功能 | 典型话术示范 |
| --- | --- | --- |
| 反映 | 让对方感到被听懂 | 「听起来你为这事感到既愤怒又委屈」 |
| 澄清 | 把模糊还原为具体 | 「你说的『压力很大』，具体指什么？工作还是家里？」 |
| 开放式提问 | 打开话题 | 「能跟我说说那天发生了什么吗？」 |
| 具体化提问 | 锁定细节 | 「那是哪一天？当时你在哪？」 |
| 摘要 | 收束与确认 | 「我们刚才聊到三件事，我复述一遍对吗？」 |
| 重述 | 确认理解 | 「你的意思是，想离开但担心经济，对吗？」 |
| 面质（温和） | 指出矛盾 | 「你一方面说要找工作，一方面又说没有时间——这两者怎么统一？」 |

**辨析｜易错点：** 表里的技术新手容易「背话术」，一开口就僵硬。技术是**为理解服务的手段**，判断标准始终是「这句话是否让案主更愿意表达、更被理解」，而非「我是否用了标准句式」。技巧的最高境界是忘了技巧——只留下真诚的在场。

## 3 个案工作的主要模式

个案工作的模式是在理论之上组合而成的「操作配方」，本节《理论框架》已详解理论，这里只看模式如何选型：

**心理社会模式**：以「人在情境中」为纲，综合心理动力与社会环境分析，通过支持、澄清、领悟与环境改善并举，是「整合取向」的鼻祖。
- **行为治疗模式**：针对具体问题行为，用系统脱敏、行为契约、强化程序干预，见效快、可测量。
- **认知行为模式（CBT）**：修正歪曲信念 + 行为技术，实证支持最强，是当前精神健康领域的主力。
- **人本（案主中心）模式**：以真诚、共情、无条件积极关注提供促进性关系，让案主自我成长。
- **任务中心模式**：问题聚焦、时限明确、任务契约，适合「资源型」困境（经济、就业、搬家）。
- **危机介入模式**：针对突发危机的短促高强度干预，目标是恢复平衡而非人格改造。

**辨析｜易错点：** 模式选择的关键不是「哪个更先进」，而是**案主的问题性质与改变动机**：长期人格议题配心理社会/人本；具体行为问题配行为/CBT；突发危机配危机介入；资源问题配任务中心。**一个成熟的个案工作者是「模式间的翻译者」，而非某一流派的信徒**——这也正是通才实务的要义。

## 4 个案管理：给复杂案主当「总调度」

当案主的问题横跨多个系统（如一名同时失业、患病、无房的中老年人），单打独斗式的个案工作力不从心，需要**个案管理（case management）**。个案管理师的角色不是「直接治疗者」，而是**评估者 + 协调者 + 连接者**：全面评估案主需求，制定整合服务计划，协调民政、医疗、就业、住房各部门，跟踪进度，监督服务衔接。

**核心要点：** 个案管理的核心是**避免案主在系统间「掉缝」**——福利领域的经典困境是：每个部门都在做自己那部分，却没有人对「完整的人」负责。个案管理就是为案主配备的「总体责任」担当者。它的工作对象通常是多重问题的弱势群体，因此在《儿童与家庭》《医务》《老年》等实务章节里，个案管理几乎必然出场。<span class="marginnote">个案管理把「宏观的跨系统协调」压缩成一个个案级动作，可视作微观与宏观实务之间的桥梁——它需要的沟通、谈判、资源评估能力，与《社会工作行政与管理》一节的「跨部门协作」同源。</span>

## 5 个案工作记录与伦理

记录是个案工作的「档案」：接案记录、过程记录、结案记录。记录的功能有三——**评估与计划的基础、专业间沟通的依据、可问责的证据**。同时记录也是伦理的雷区：**保密**要求记录只能为专业目的使用，任何转介、督导讨论都要脱敏处理；记录中不得出现对案主的贬损性评语。

**辨析｜易错点：** 新手常犯两类记录错误：一是「流水账」——只记过程不记分析与判断；二是「贴标签」——把预估写成对案主的定性（「此案主不负责任」）。专业记录应是「**事实 + 专业判断 + 依据**」三层结构：记录行为事实（「连续两次未赴约」），再写判断与理由（「或提示动力不足，需评估支持条件」，而非「案主懒」）。<span class="marginnote">记录还有一层「反身」功能：重读旧记录可以看见自己当初的判断错在哪——案例督导（supervision）正是靠记录展开的「第二只眼睛」，详见《社会工作行政与管理》里的督导制度。</span>

## 6 个案工作的过程：从接案到结案

个案工作不是一堆散点的技术，而是一条有起有终的流程。把《通用实务过程模式》的五步落进个案工作，就有了具体的操作序列：

1. **接案与建立关系**：初次会谈、澄清期待、评估可否提供服务或需转介——本节的核心是「让关系可以谈」。
2. **预估**：用 PIE 视角评估案主的个人、家庭、环境与社会层面，形成「问题 × 资源 × 动力」的初步地图。
3. **制定计划**：与案主共订目标（SMART），选定介入模式（见第三节），明确各自责任与时间表。
4. **实施介入**：按所选模式开展会谈、任务、环境调整；每次介入后监测反应、修正计划。
5. **评估与结案**：评估目标达成度、处理分离情绪、巩固成果、约定跟进或转介。

**核心要点：** 过程中最容易被新手跳过的是**结案**。结案不是「目标达成了就默默结束」，而是一次重要的专业动作：要**提前告知**（给案主消化分离的时间）、**回顾改变**（让案主带走「我靠自己也能做到」的信心）、**处理情绪**（案主可能因失去依靠而退缩甚至愤怒，这是正常反应，要承接而非回避）。**一次草率的结案，可能抵消前面十几次会谈建立的安全感。**

个案工作过程中还要随时准备**转介**：当案主需要精神科诊断、法律帮助或超出本机构能力的服务时，转介是负责任的专业动作，而非「我搞不定」的失败——这与《价值观与伦理》一节的「能力」价值直接呼应。

## 7 小结

- 个案工作是**以个人/家庭为对象、以专业关系为媒介、以恢复社会功能为目标**的方法。
- 个案工作 ≠ 心理咨询：前者**人在情境中**，后者**重内在心理**；转介是专业动作而非失败。
- 会谈技术是核心：**倾听反映、澄清聚焦、开放提问、摘要、共情**；社工克制自传性反应。
- 模式选择依**问题性质 + 改变动机**：危机介入、任务中心、行为/CBT、心理社会、人本各司其职。
- 复杂案主靠**个案管理**当总调度，避免案主在系统间「掉缝」。
- 记录要**事实 + 判断 + 依据**三层结构，并守住保密伦理。
- 个案工作全过程：**接案—预估—计划—介入—评估—结案**；结案要提前告知、巩固成果、处理情绪、约定跟进。
