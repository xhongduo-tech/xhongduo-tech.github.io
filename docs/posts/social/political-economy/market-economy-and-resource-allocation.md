## 为什么从资源配置方式开始

前四节我们建立了「商品—货币—价值规律」的分析框架，那是从**单个商品交换**的微观视角看的。这一节把镜头拉远，问一个宏观问题：一个社会有无限多样的需求，却只有有限的劳动与资源，社会凭什么决定「生产什么、生产多少、为谁生产」？<span class="marginnote">这就是<strong>资源配置</strong>问题。它看上去是个技术问题，但回答它的方式——靠计划、靠市场、还是靠习惯——直接决定了一个经济体制的性质，也是计划与市场之争的根源。</span>
本节承接价值规律（资源配置是价值规律三大作用之一），又为后面讲社会主义市场经济体制（社会主义篇）埋下伏笔：先看清市场经济这个「一般形式」，才能谈它的「社会主义」特殊形态。

## 1 资源配置的基本问题

任何社会都面临资源稀缺，都必须在生产前先回答三个问题：**生产什么、怎样生产、为谁生产**。回答这些问题的机制，就叫**资源配置方式**。

历史上存在三种典型的配置方式：

- **习惯（传统）方式**：由世代相传的习俗决定生产——前商品经济社会主要靠它，简单稳定但僵化；
- **计划（命令）方式**：由中央计划机关统一决定产量与分配——指令性计划经济；
- **市场方式**：由价格信号自发引导生产与消费——商品经济、市场经济。

**重点：** 计划经济与市场经济是两种**资源配置方式**，不是「姓社姓资」的社会制度标签。一种经济体制用哪种方式为主，取决于生产力水平与制度条件——这一点正是我国确立社会主义市场经济体制的理论前提。

## 2 市场配置资源的机制

在市场经济中，资源靠什么流动？靠**价格信号**与**利益驱动**：

- 某种商品**供不应求**，价格上升 → 生产者看到利润空间 → 劳动与资本流入该部门 → 供给增加 → 价格回落；
- 某种商品**供过于求**，价格下跌 → 生产者亏损 → 劳动与资本流出 → 供给减少 → 价格回升。

价格就这样像一只「看不见的手」，引导资源流向最需要的地方。它同时完成两件事：**传递信息**（价格是稀缺程度的信号）与**提供激励**（价格是盈亏的指示器）。

**辨析｜易错点：** 市场配置资源是**事后调节**——先生产出来、卖不掉，才知道生产多了。它与计划的「事前调节」相比更灵活、更灵敏，但以浪费与波动为代价。理解这一点，才不至于把市场神化。

## 3 市场经济的特征与条件

**市场经济（market economy）**：以市场机制为基础来配置社会资源的经济运行方式。它的一般特征有四条：

- **产权清晰**：市场主体拥有明确的财产权利，这是交换的前提；
- **价格由市场决定**：价格由供求形成，又反作用于供求；
- **竞争充分**：市场主体在公平竞争中优胜劣汰；
- **契约与法治**：交换以契约为基础，以法律为保障。

市场经济不是「无政府」的经济。它需要一系列**制度条件**：产权制度、契约制度、竞争规则、货币信用体系。<span class="marginnote">马克思并不否认市场经济的活力，他承认资本主义商品经济空前地解放了生产力；问题在于这种解放以私有制与社会化生产的矛盾为代价——这正是本书第三篇、第四篇要展开的批判线索。</span>

## 4 公式解析：价格机制与市场均衡

把市场配置资源的过程写成公式，就是供求决定价格的机制。设某商品的价格为 $P$，供给量为 $Q_s(P)$，需求量为 $Q_d(P)$：

$$
Q_s(P) = a + bP, \qquad Q_d(P) = c - dP, \qquad Q_s(P^*) = Q_d(P^*)
$$

其中 $a,b,c,d$ 为正的常数；$P^*$ 是均衡价格。对公式做三步拆解：

- **第一步，看供给函数 $Q_s = a + bP$**：价格越高，供给越多（$b > 0$），因为生产者愿意多产；这是「价格上涨 → 资源流入」的数学表达。
- **第二步，看需求函数 $Q_d = c - dP$**：价格越高，需求越少（$d > 0$），因为消费者会减少购买；这是「价格下跌 → 消费增加」的数学表达。
- **第三步，解均衡 $Q_s = Q_d$**：令 $a + bP = c - dP$，得 $P^* = (c - a)/(b + d)$。在 $P^*$ 处供求相等，市场出清。

**重点：** 均衡价格不是「应该有的价格」，而是**供求双方博弈的结果**。当实际价格偏离 $P^*$ 时，市场会自动产生回到 $P^*$ 的力量——价格机制就是靠这套负反馈来配置资源的。但注意：这套分析描述的是「市场做什么」，并没有回答「市场是什么」——这正是政治经济学追问的下一层。

## 5 市场失灵与政府调节

市场机制有强大的配置功能，但它并非万能。存在**市场失灵（market failure）**的领域：

- **公共物品**：国防、灯塔、公共道路——不排他、不竞争，市场不愿提供；
- **外部性**：污染、研发溢出——成本或收益外溢到第三方，价格信号失真；
- **信息不对称**：买方卖方信息不均，可能产生逆向选择与道德风险；
- **垄断**：大企业操纵产量与价格，价格机制失灵；
- **收入分配失衡**：市场按要素贡献分配，可能造成贫富悬殊。

这些失灵为**政府调节**提供了理由。但政府调节也有成本与失误的可能（信息不足、寻租、官僚主义）——因此「政府与市场的关系」不是谁替代谁，而是**在各自有效率的领域各司其职**。这是当代经济学与各国政策争论的永恒主题，也是第 22 篇社会主义市场经济要反复处理的课题。

## 6 核心对比表：计划经济与市场经济

两种配置方式的区别，用一张表收拢：

| 对比维度 | 计划经济 | 市场经济 |
| --- | --- | --- |
| 决策主体 | 中央计划机关 | 千百万市场主体 |
| 信息机制 | 行政命令 | 价格信号 |
| 激励方式 | 计划指标 | 利润盈亏 |
| 调节时点 | 事前（先算后干） | 事后（先干后调） |
| 优点 | 集中力量、避免盲目 | 灵活高效、自动配比 |
| 缺陷 | 信息不全、激励不足 | 盲目波动、分配失衡 |
| 效率前提 | 信息充分、计算可行 | 竞争充分、产权清晰 |

<span class="marginnote">这张表说明：没有一种方式绝对优于另一种。传统计划经济的教训是「信息与激励不足」，市场经济的代价是「波动与失衡」。现代经济普遍实行<strong>以市场为基础、以计划（宏观调控）为补充</strong>的混合配置——我国社会主义市场经济正是这一思路的典型。</span>

## 7 中国资源配置方式的演进

改革开放以来，中国的资源配置方式经历了一个清晰的演进过程：从高度集中的计划经济，到「计划调节为主、市场调节为辅」，再到「市场在资源配置中起基础性作用」，最终确立「使市场在资源配置中起决定性作用」。每一步转变，都是对「计划与市场」关系认识的深化，也是对生产力发展的回应。

**计划体制的教训**：传统计划体制在工业化初期有集中力量办大事的优势，但随着经济规模扩大、需求日益多样，信息与激励不足的弊端越来越突出——生产企业「只管完成指标、不管市场需要」，产品积压与短缺并存。这正是经济学界著名的「计划计算」之争在实践中的回答：中央计划无法及时处理海量信息。

**市场的引入与演进**：价格双轨制、承包经营、现代企业制度、要素市场化——中国的市场化改革是渐进式的，先商品后要素、先沿海后内地、先增量后存量。这种「渐进改革」避免了「休克疗法」式转轨的剧烈震荡，保证了改革中的社会稳定与生产力连续发展。

**政府与市场的再平衡**：中国经验的独特之处在于，它不是「政府退场、市场独大」，而是让市场与政府各归其位：市场解决资源配置的效率问题，政府解决宏观调控、公共服务与收入分配的公平问题。「有效市场 + 有为政府」成为中国特色社会主义市场经济的重要标识。

**理论与实践的相互印证**：这一演进验证了本节开头的基本判断——计划经济与市场经济是配置方式而非制度标签。中国没有放弃公有制与按劳分配，却成功引入了市场机制，这本身就是对「社会主义不能搞市场经济」这一传统教条的最有力反驳。

**面向未来**：要素市场化改革仍在深化，数据要素、碳交易等新型要素市场正在成长。资源配置方式的探索没有终点——它始终在「效率」与「公平」、「市场」与「政府」之间寻找动态平衡，这正是社会主义市场经济的生命力所在。

## 8 小结

- 资源配置要回答**生产什么、怎样生产、为谁生产**；市场与计划是两种基本配置方式，不是社会制度标签。
- 市场配置靠**价格信号与利益驱动**，通过供求的自发调整把资源引向最需要的地方。
- 市场经济的一般特征：**产权清晰、价格由市场决定、竞争充分、契约法治**。
- 均衡价格由供求共同决定：$P^* = (c - a)/(b + d)$，市场以负反馈方式实现配置。
- 市场存在**公共物品、外部性、信息不对称、垄断、分配失衡**等失灵领域，需要政府调节补充。
- 现代经济普遍实行**市场为基础 + 政府调控为补充**的混合配置。

在下一节，我们将结束「商品经济的一般」这一篇，进入资本主义特有的领域：当货币被用来购买一种特殊商品——劳动力，资本增殖的秘密就开始了。这就是**资本总公式与劳动力商品**。
