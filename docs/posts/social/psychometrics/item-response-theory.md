# 项目反应理论（IRT）

<div class="epigraph">
<p>被试答对某题的概率，是他能力与题目参数的函数。</p>

## 为什么从 IRT 开始

经典测量理论简单可靠，但第2篇与第5篇反复暴露它的三个软肋：难度、区分度等**题目参数依赖施测样本**；被试分数**依赖具体题目**——做难卷子得 30 分、做易卷子得 60 分，两个分数不可直接比较；误差被假定为**全能力段同方差**。项目反应理论（Item Response Theory, IRT）换了一个更深的视角：**为「答对概率」与「能力」之间建立一条明确的函数关系**。一旦这条函数成立，题目与被试就被放到了同一条量尺上——参数不再随样本漂移，分数不再依赖碰巧抽到哪些题。<span class="marginnote">IRT 是 20 世纪下半叶测量学最重要的理论突破，也是计算机自适应测验、题库建设、测验等值背后的引擎。</span>

## 1 潜在特质与项目特征曲线

IRT 假设存在一个**潜在特质（latent trait，记作 $\theta$）**——被试身上不可直接观测的「能力水平」或「特质水平」。所有题目都被解释为对 $\theta$ 的测量工具。

核心工具是**项目特征曲线（item characteristic curve, ICC）**：一条刻画「答对概率 $P$ 随能力 $\theta$ 变化」的曲线。$P$ 是条件概率：

$$P(\theta) = P(X_i = 1 \mid \theta)$$

其中 $X_i = 1$ 表示答对第 $i$ 题。<span class="marginnote">第5篇的难度 $p$ 与区分度 $D$ 只是把这条曲线压成两个数字；IRT 则把整条曲线当作模型来估计。</span>

一条理想的 ICC 具有三个特征，恰好对应三个题目参数：

**位置由难度决定**：曲线拐点（$P$ 变化最快处）对应的能力值就是**难度**，记作 $b$。$b$ 越大，题目越难。

**陡峭程度由区分度决定**：曲线越陡，说明能力的一点差异带来答对概率的大变化，区分能力越强，记作 $a$（$\theta$ 的斜率）。

**下渐进线由猜测决定**：多选题即使能力极低，也有纯蒙的猜中率，曲线最低点不落到 0 而是落在**猜测参数** $c$ 上。

## 2 三个基本模型

按引入参数的多少，IRT 有三个层层递进的模型：

**单参数模型（1PL / Rasch 模型）**：只允许难度 $b$ 变化，区分度固定、猜测为零：

$$P(\theta) = \frac{1}{1 + e^{-(\theta - b)}}$$

**双参数模型（2PL）**：难度 $b$ 与区分度 $a$ 都可变：

$$P(\theta) = \frac{1}{1 + e^{-a(\theta - b)}}$$

**三参数模型（3PL）**：再加猜测参数 $c$：

$$P(\theta) = c + (1 - c)\frac{1}{1 + e^{-a(\theta - b)}}$$

<span class="marginnote">Rasch 模型（1PL）在测量界有特殊地位：它假设所有题目区分度相同、无猜测，因此被试的<strong>原始答对数</strong>就足以估计能力——简洁到「分数足够统计量」的程度。主张者认为只有 Rasch 模型才有「客观测量」的地位；反对者认为它过于苛刻、牺牲拟合度。</span>参数越多，模型越灵活、拟合越好，但估计需要的数据量也越大、解释越复杂——**模型选择是在拟合与简约之间的权衡**。

## 3 公式解析：三参数逻辑斯蒂模型

3PL 是实际应用中最常用的完整模型，逐项拆解：

$$P(\theta) = c + (1 - c) \cdot \frac{1}{1 + e^{-a(\theta - b)}}$$

- **第一步，看骨架**：$\frac{1}{1 + e^{-z}}$ 是标准逻辑斯蒂函数，$z$ 是「能力与难度的较量」$z = a(\theta - b)$。
- **第二步，看 $b$（难度）**：当 $\theta = b$ 时 $z = 0$，逻辑斯蒂函数取 $0.5$。**难度 $b$ 是「答对概率恰为 $(1+c)/2$ 的能力点」**——越难，这个拐点越靠右。
- **第三步，看 $a$（区分度）**：$a$ 放大或压缩 $z$。$a$ 大，曲线在拐点处陡峭，能力略变一点、答对概率剧变；$a$ 小，曲线平缓，题目几乎区分不了人。
- **第四步，看 $c$（猜测）**：当 $\theta \to -\infty$，逻辑斯蒂部分趋近 0，$P \to c$。**$c$ 是能力极低时的答对概率下限**，通常接近 $1/k$（$k$ 为选项数）。<span class="marginnote">注意 $c$ 是「下限」而非「四选一就该恰好 0.25」——部分作答、诱答设计都会让实际下限偏离理论值，因此 $c$ 要由数据估计。</span>

**辨析｜易错点：** $b$、$a$、$c$ 都不是「常模里的百分比」，而是**独立于样本的能力量尺上的参数**。这是 IRT 与 CTT 的本质区别：CTT 的难度 $p$ 随样本漂移，IRT 的难度 $b$ 一旦由足够大的样本估计出，就在逻辑上独立于估计样本——此即「参数不变性」。

## 4 信息函数：精确度的逐点地图

CTT 给全测验一个信度数字，假设误差处处相同。IRT 拒绝这个假设，改用**信息函数（information function）**逐点刻画精确度：

$$I(\theta) = \frac{[P'(\theta)]^2}{P(\theta)[1 - P(\theta)]}$$

其中 $P'(\theta)$ 是 ICC 的导数。信息量越大，该能力点的估计误差越小（测量标准误 $SE(\theta) = 1/\sqrt{I(\theta)}$）。<span class="marginnote">直觉：一道题在拐点附近最能「区分人」，所以每道题在难度 $b$ 附近贡献最大信息；把全部题目在各点的信息相加，就得到<strong>测验信息函数</strong>——整份测验的精确度地图。</span>

信息函数带来一个革命性的推论：**不同测验可以在「相同能力点」上比较精确度**。这份测验在低分段信息高（适合测差生）、那份在高分段信息高（适合筛尖子），两个测验可以专门设计、各司其职，而不必追求「一份通吃」。

## 5 IRT 的性质与应用

IRT 的两个核心性质，直接转化为三大应用：

**参数不变性（invariance）**：题目参数不依赖估计样本，被试能力不依赖所测题目。只要模型拟合，用难卷子测出的能力与用易卷子测出的能力可以换算到同一量尺。

**计算机自适应测验（CAT）**：利用「信息最大」原则动态选题——先估一个能力，再挑当前能力点信息最大的题，作答后更新能力估计，重复至精度达标。**一份 CAT 试卷可以因人而异，30 题达到固定 50 题的效果。**<span class="marginnote">CAT 是 IRT 最耀眼的工程应用：它把「对每个人都出同一套题」变成「对每个人出最合适的一套题」，GRE 等大规模考试的机考版就是典型。</span>

**测验等值（equating）**：把不同版本测验的分数换算到同一量尺，使难度不同的两份卷子分数可比——这正是第14篇《测量等值与测验公平性》的主题，IRT 通过共同锚题实现等值。

**题库建设（item banking）**：题目参数存入题库，随时可以按目标信息函数组卷。

**辨析｜易错点：** IRT 的一切美好性质都建立在**模型拟合**之上。数据严重违背模型（如题目具有严重猜测且 $c$ 估计不稳定、局部独立性被破坏）时，参数不变性会失真。**用 IRT 之前必须做模型-数据拟合检验**——这是实践中常被跳过的一步。

## 6 IRT 与 CTT 的核心对比

**核心要点对比表**：

| 维度 | CTT | IRT |
| --- | --- | --- |
| 分析单位 | 整份测验 | 单个题目（项目） |
| 题目参数 | 难度 $p$、区分度 $D$，样本依赖 | $a, b, c$，样本不变 |
| 被试分数 | 原始分/导出分，依赖具体试卷 | 能力 $\theta$，与所测题目无关 |
| 误差 | 全测验一个信度，处处相同 | 信息函数逐点刻画 |
| 等距性 | 原始分不保证等距 | $\theta$ 量尺理论上等距 |
| 数据要求 | 简单、小样本可用 | 复杂、需大样本估计 |
| 主要应用 | 日常测验、教育评分的默认选择 | CAT、等值、题库、跨版本比较 |

**辨析｜易错点：** IRT 并非「全面取代」CTT。对单次测验、小样本、简单评分需求，CTT 简单够用；IRT 的优势在大型题库、跨版本等值、自适应施测这类高要求场景。**工具选择服从任务，而非「越高级越好」。**

## 7 小结

- IRT 为「答对概率」与「潜在特质 $\theta$」建立函数关系，用 **ICC** 刻画每道题。
- 题目参数三个：难度 $b$、区分度 $a$、猜测 $c$；模型按参数分 **1PL（Rasch）/ 2PL / 3PL**。
- 3PL 公式 $P = c + (1-c)/(1+e^{-a(\theta-b)})$：$b$ 定位置、$a$ 定陡峭、$c$ 定下限。
- **信息函数**逐点刻画精确度，$SE(\theta) = 1/\sqrt{I(\theta)}$
