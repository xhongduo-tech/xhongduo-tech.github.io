## 为什么从项目分析开始

前四篇从整份测验的宏观指标（信度、效度）建立了质量框架，但一份测验的好坏最终由**一道道题目**决定。一道错别字连篇、答案歧义、或根本没人能答对的题，只会稀释测验的信度与效度。**项目分析（item analysis）**就是把显微镜对准单个题目：用两个数字刻画每道题——**难度**（这题难不难）与**区分度**（这题能不能把高水平与低水平的被试分开），然后据此增删改题目。<span class="marginnote">项目分析是测验编制的「质量控制车间」：整份测验的信度、效度是车间产品，而难度与区分度是每道工序的质检指标。</span>

## 1 难度：一道题有多难

**难度（difficulty）**：被试答对或通过某题的比例，记作 $p$。对 0/1 计分题：

$$p = \frac{\text{答对人数}}{\text{总人数}}$$

$p$ 值越大题目越容易——注意心理测量学里难度与 $p$ 成反比，$p = 0.9$ 的题很易，$p = 0.1$ 的题很难。这个「反直觉」的记号是初学者最常踩的第一个坑。

对多级计分题（如 1–5 分评分），难度常用该题得分均分占满分的比例表示：$p = \bar{X}_i / X_{i,\max}$。

难度不是越低越好，也不是越高越好，而要看**测验的目的**：

**常模参照测验**（区分个体差异，如选拔考试）希望分数散布开，因此题目难度应**接近 0.50**——此时通过率一半一半，分数变异最大，对区分度的贡献也最大。<span class="marginnote">直觉：一道 0.5 难度的题，一半人会、一半人不会，信息量最大；0.05 难度的题几乎没人会，0.95 难度的题几乎都会，两者都无法区分任何人。</span>

**标准参照测验**（判断达标与否，如资格认证）则按内容要求定难度，不必追求 0.50——有些「应该人人都会」的安全规范题，难度高达 0.95 也合理。

**辨析｜易错点：** 难度受样本水平影响。同一道题在重点班 $p = 0.35$，在普通班 $p = 0.65$——难度不是题目的内在属性，而是「题目 × 样本」的表现。因此 CTT 的难度是样本依赖的，这正是第9篇 IRT 想解决的问题之一。

选择题还有一道「机会水平」的底线要算。一道四选一的选择题，纯靠蒙也有 $1/4 = 25\%$ 的期望通过率。判断这类题的难度时，25% 是下限：一道题 $p = 0.30$，看似适中，其实只比纯蒙高出 5 个百分点，其中几乎不包含区分能力。<span class="marginnote">严格处理猜测可用猜测校正公式 $p_c = (kp - 1)/(k - 1)$，其中 $k$ 是选项数。不过校正后的难度仅在「所有瞎蒙者完全随机」的假定下成立，实践中更常见的做法是直接警惕贴近机会水平的 $p$ 值。</span>把通过率减去机会水平之后的「净增量」，往往比 $p$ 本身更能反映题目真实的难度价值。

## 2 区分度：一道题能把人分开吗

**区分度（discrimination）**：题目区分不同水平被试的能力——答对者整体水平是否显著高于答错者。区分度高的题，高分者大概率答对、低分者大概率答错。

计算区分度最经典的是**极端组法**：把被试按总分排序，取高分组（前 27%）与低分组（后 27%），分别求通过率，其差即为区分度：

$$D = p_H - p_L$$

$D$ 的取值范围为 $[-1, 1]$。$D$ 越大区分越好；$D$ 接近 0 说明题目对总分没有贡献；$D \lt  0$ 说明**高分者反而答错、低分者反而答对**——这道题多半答案标错或题意有歧义，应淘汰或重写。<span class="marginnote">27% 是经验上兼顾「组间差异最大」与「样本量足够」的折中比例；样本很大时也可用 25% 或 33%，结果差别不大。</span>

另一类方法是**相关法**：求每题得分与总分的相关。0/1 计分题用**点二列相关（point-biserial correlation）**，多级计分题用**皮尔逊相关**；总分连续、题目 0/1 而背后假定连续正态时用**二列相关（biserial correlation）**。<span class="marginnote">点二列相关是最常用的「题-总相关」（item–total correlation），它直接回答「这道题跟总分高不高」——一篇《相关与回归》讲相关，这里的用法是它在测验分析中的典型落地。</span>

区分度的经验标尺：$D \ge 0.40$ 优秀，0.30–0.39 良好，0.20–0.29 尚可，低于 0.20 需修改或淘汰。

区分度之外，项目分析还包含一项常被忽略的检查——**选项分析（distractor analysis）**：逐个看干扰项有没有人选、被谁选。理想的干扰项应当被低分组多选、被高分组少选；若某干扰项无人问津，说明它毫无迷惑力；若高分组大量选中某干扰项，该选项很可能表述含糊、甚至是隐性正确答案。**一条题目的质量不只由「正确项」决定，更由「干扰项设计」决定。**

## 3 公式解析：点二列相关

点二列相关度量「二值题目」与「连续总分」的关联，是区分度相关法的主力：

$$r_{pb} = \frac{\bar{X}_1 - \bar{X}_0}{s_X} \sqrt{\frac{n_1 n_0}{n^2}}$$

四步拆解：

- **第一步，$\bar{X}_1$ 与 $\bar{X}_0$**：答对该题（记 1）与答错（记 0）两组被试的总分均值。差越大，说明这题把总分高的人与总分低的人分得越开。
- **第二步，$s_X$**：全体被试总分的标准差，用作标准化尺度，消除总分量纲。
- **第三步，$\sqrt{n_1 n_0/n^2}$**：权重因子。题目答对率越接近 0.5（即 $n_1 \approx n_0$），该因子越大，$r_{pb}$ 越接近它可能的最大值——**这解释了为何中等难度的题更容易获得高区分度**。<span class="marginnote">当通过率极端（几乎全对或全错），$n_1 n_0 \to 0$，即使两组均值有差，$r_{pb}$ 也被压缩——统计上「难到没人会」或「易到人人会」的题都长不出好区分度。</span>
**第四步，读出取值范围**：$r_{pb}$ 在 $[-1, 1]$，绝对值越大关联越强；$r_{pb}$ 为负说明答对者总分反而低，题目有问题。

**辨析｜易错点：** 点二列相关与二列相关不是一回事。前者对「题目只有 0/1 两种取值」不加假设直接计算；后者假设二值背后存在一个连续正态的潜在变量，公式另有一个修正项，数值通常更大。**报告区分度时务必说明用的是哪种相关**，否则数值不可比。

把公式跑一遍数字就直观了。设某题 40 人答对、60 人答错，总分标准差 $s_X = 12$，答对组总分均值 $\bar{X}_1 = 78$，答错组 $\bar{X}_0 = 66$。分子 $78 - 66 = 12$；权重因子 $\sqrt{40 \times 60 / 100^2} = \sqrt{0.24} \approx 0.49$；于是 $r_{pb} = (12/12) \times 0.49 = 0.49$——题-总相关可观，区分度良好。若改设这道题几乎人人答对，$n_1$ 逼近 $n$、$n_0$ 趋近 0，权重因子跟着塌向 0，$r_{pb}$ 即使分子很大也被压得很低——再次印证「中等难度才养得出好区分度」。

## 4 难度与区分度的配合

难度与区分度不是两个孤立的数字，它们之间存在系统关系：

| 难度 $p$ | 区分度 $D$ 的表现 | 对常模参照测验的意义 |
| --- | --- | --- |
| 接近 0.50 | 最可能达到高区分度 | 理想区间 |
| 偏易（0.70 以上） | 通常中等偏低 | 可用于基础题、热身题 |
| 偏难（0.30 以下） | 通常中等偏低 | 可用于拉开尖子差距 |
| 极端（<0.10 或 >0.90） | 趋近 0 | 只对标准参照测验有意义 |

道理在前面的权重因子里已经讲过：**区分度以难度的适度为前提**。一份常模参照测验的理想难度结构，是平均难度接近 0.50、并在 0.30–0.70 之间铺开——既保证整体散布，又留出梯度和层次。<span class="marginnote">难度分布还可以做成「测验信息量的整形术」：想要筛选尖子，就在高分区间多放中难题；想要诊断差生，就在低分区多放中易题——难度安排要服从测验的功能定位。</span>

**辨析｜易错点：** 难度与区分度是「样本—题目」交互的结果，一轮项目分析只能反映**当前样本**下的表现。测验修订后要在新样本上重新分析；换一个人群（如从高中生换成职场成人）更要重做——这与效度需随场景重估的道理一脉相承。

一个常见的编制误区是「把整份测验的题都压到难度 0.5」。实际上，一份理想的常模参照测验，难度应围绕 0.50 呈近似正态铺开：少量 0.30 以下的难题拉开顶尖差距，少量 0.70 以上的易题保住基础区分，中段密集排布 0.40–0.60 的主力题。**全卷难度并非越聚越近越好，合理的散布才同时保证整体信度与各段的区分能力。**

## 5 项目分析在测验编制中的流程

把前三节串起来，一份测验通过项目分析打磨的完整流程是：

1. **试测（pilot）**：编出题量约为正式测验 1.5–2 倍的题目，找有代表性的样本试测。
2. **算难度与区分度**：每题求 $p$ 与 $D$（或 $r_{pb}$），同时检查选项分布——干扰项若无人选，说明没有迷惑力，要改写。
3. **看干扰项**：正确的干扰项应让低分组比高分组选得更多。若高分组大量选中某干扰项，该选项可能其实是对的或含糊。
4. **取舍与改题**：区分度为负、或难度极端且无保留价值的题淘汰；区分度尚可但表述有问题的题重写。
5. **复查整卷指标**：删改后再算整卷信度与效度，观察是否提升。<span class="marginnote">项目分析与信度的关系是双向的：信度低时可借项目分析找「拖后腿」的坏题；删掉坏题后信度又会回升。两者构成测验编制的内循环。</span>

这套流程在今天已由测验分析软件批量完成，但读懂每个数字背后的意义，仍是测验开发者不可外包的能力。

项目分析还有一个通往进阶方向的出口：把每道题的难度与区分度画在同一个坐标系里，就得到**项目特征曲线（item characteristic curve, ICC）**的雏形——横轴是能力水平，纵轴是答对概率。一条理想的 ICC 是单调上升的 S 形曲线：能力越高答对概率越大，曲线在中段的陡峭程度对应区分度，拐点位置对应难度。<span class="marginnote">CTT 的 $p$ 与 $D$ 只是把这条曲线压缩成了两个标量；把它完整地建模出来，正是下一阶段项目反应理论（IRT）的核心工作。</span>从两个数字到一条曲线，测量学对题目的理解从「概要」走向了「函数」。

## 6 小结

- **难度** $p$ 是答对比例，**数值越大越容易**；常模参照测验理想难度在 0.50 附近，标准参照测验按内容要求定。
- **区分度** $D = p_H - p_L$（极端组法）或题-总相关（相关法），衡量题目把人分开的能力，负区分度题必须淘汰。
- 高分组 27% 与低分组 27% 之差是极端组法；相关法里 0/1 题用点二列相关、多级题用皮尔逊相关。
- 点二列相关的权重因子 $\sqrt{n_1 n_0 / n^2}$ 揭示：通过率越极端，区分度上限越低。
- 点二列相关是 0/1 题与总分相关的标准工具，其权重因子解释了「中等难度才易得高区分度」。
- 难度与区分度联动：**区分度以难度适度为前提**，题目安排要服从测验功能。
- 项目分析是「试测 → 算指标 → 查选项 → 取舍 → 复查」的迭代流程，与信度形成编制内循环。
- 一切指标都依赖样本，换人群、换版本必须重做。
- 选项分析看干扰项「有没有人选、被谁选」，干扰项设计决定题目的迷惑力。
- 难度与区分度画成一条 S 形曲线就是 ICC，是通向项目反应理论的桥梁。
- 多选题判断难度要把机会水平（如四选一的 25%）当底线，警惕贴近纯蒙的 $p$ 值。
- 难度与区分度是「题目 × 样本」的表现：同一道题在不同水平班级难度不同，换人群、换版本必须重做项目分析。
- **选项分析**看干扰项「有没有人选、被谁选」——理想的干扰项被低分组多选、被高分组少选，干扰项设计决定题目的迷惑力。
- 难度与区分度画成一条单调上升的 S 形曲线就是**项目特征曲线（ICC）**，是把「两个数字」扩展为「一条函数」、通向项目反应理论的桥梁。
