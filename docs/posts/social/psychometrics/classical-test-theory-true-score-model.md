## 为什么从真分数模型开始

上一篇反复强调了一句话：**测量携带误差**。可「误差」如果只是口头上的提醒，就无法被计算、无法被控制，更无法被改进。经典测量理论（Classical Test Theory，简称 CTT）做的第一件事，就是给这句口头禅一个**精确的数学形式**：把一次测验得到的分数拆成「真实水平」与「误差」两部分。这个模型极简单，却极其耐用——**信度、效度、项目分析，乃至常模分数解释的全部公式，都是从这一个等式里长出来的**。理解了它，你就握住了整个心理测量学的第一性原理。

## 1 可观测分数与真分数

设想某位考生做一份 20 题的测验，得 15 分。这 15 分就是**可观测分数（observed score，记作 $X$）**——它是我们唯一真正看到的东西。

但我们的真实兴趣从来不是这 15 分本身，而是它背后的东西：这位考生的真实能力水平。CTT 把这个「真实水平」定义为**真分数（true score，记作 $T$）**：**若同一考生在无穷多个平行测验上测得分数的期望，就是他的真分数。** 换句话说，真分数不是某个神秘的内在实体，而是「测很多次取平均」的理论极限。<span class="marginnote">注意这一定义的操作性：真分数被定义成「无穷次施测的期望」，而非「本质中的真实智力」。它把形而上的追问翻译成了可计算的平均，这正是科学定义的手法。</span>

一次测量得到的 15 分，与真分数之间一定有差距，这个差距就是**测量误差（measurement error，记作 $E$）**。于是有了真分数模型的基本等式：

$$X = T + E$$

**把一场测验的分数，拆成「稳定的真分数」与「随机的误差」之和**——这是 CTT 的全部出发点。

举一个直观例子。设某考生的阅读理解真分数为 $T = 15.2$（即他若考无穷多次平行试卷的平均分），这一次恰好考了 $X = 15$，则误差 $E = -0.2$：运气略差，比真实水平少了一点点。若下一次考了 $X = 16$，则 $E = +0.8$：手感略好。**真分数是那个看不见的期望，误差是围绕它的随机抖动，观测分是抖动之后落在纸上的那一下。** 单人单次无从分辨误差大小，但把成百上千人的分数放在一起，误差的统计规律就浮现出来了——这正是下一节三条假设要捕捉的东西。

## 2 三大基本假设

模型要可用，误差 $E$ 必须「规矩」。CTT 对误差强加了三条假设：

**假设一：误差的期望为零。** 在无穷多次平行施测中，误差有正有负，平均起来互相抵消：

$$E(E) = 0$$

**假设二：误差与真分数不相关。** 能力高的被试和低的被试，误差的来源与大小并无系统联系：

$$r(T, E) = 0$$

**假设三：不同测验的误差互不相关。** 在同一组被试上，两份平行测验的误差彼此独立：

$$r(E_1, E_2) = 0$$

三条假设合起来说了一件朴素的事：**误差是「随机」的，而不是「系统」的**。<span class="marginnote">如果误差是系统的——比如题目对文科生整体偏难——那它就混进真分数里了，模型就会失真。CTT 把「系统性偏差」赶出误差项，代价是它必须被效度问题另案处理（见第4篇《效度》）。</span>

**辨析｜易错点：** 三条假设都是「理想化条件」，现实中无法严格满足。但假设不是事实描述，而是**建模约定**——只要误差大体随机、不随真分数系统变化，模型给出的结论就足够实用。初学者常误以为「假设不满足模型就废了」，正确的是判断偏差有多大、是否影响你要用的结论。

还需要澄清一个常见混淆：这里说的误差 $E$ 专指**测量误差**（情境、施测、评分等偶然因素），不包括**抽样误差**（样本与总体之间的偏差）。测量误差属于「这一次考了多少分」的抖动，抽样误差属于「这一组人能不能代表总体」的问题——前者由信度刻画，后者由假设检验处理（见第11篇）。两条误差线各管一段，合起来才覆盖了心理研究中「不可信」的全部来源。

## 3 平行测验：让「再测一次」成为可操作概念

真分数的定义依赖「无穷多个平行测验」，可现实中不可能真的做无穷次。于是 CTT 定义了可操作版本：**平行测验（parallel tests）**指两份测验，对同一组被试而言，它们的真分数相等、且误差方差相等：

$$T_1 = T_2, \qquad \sigma_{E_1}^2 = \sigma_{E_2}^2$$

直觉上说，平行测验就是「考同一份知识、难度相当、信度相同」的两个版本——如同同一门考试的两套等价试卷。<span class="marginnote">严格地，还需两份测验误差方差相等且与对方真分数独立。日常说的「复本」近似平行测验，但复本只要求等值而不必同方差，两者的细微差别在信度一章会体现。</span>

平行测验是 CTT 里承上启下的杠杆：真分数期望、误差期望为零、重测信度——全都借它来定义。可以说，**没有平行测验，CTT 的公式就无法落地**。现实中构造严格平行测验极难，于是研究者用「同一测验相隔一段时间重测」「两套等值复本」「内部折半」等近似方案来逼近它——这三种近似，正是下一篇信度的三种估计法。

## 4 公式解析：方差分解与信度的定义

有了 $X = T + E$ 与三条假设，就能推出 CTT 最核心的方差等式。对基本等式两边取方差：

$$\sigma_X^2 = \sigma_T^2 + \sigma_E^2$$

这条式子的来路，值得三步拆解：

- **第一步，展开方差**：两变量之和的方差为 $\sigma_{T+E}^2 = \sigma_T^2 + \sigma_E^2 + 2\sigma_{TE}$，其中 $\sigma_{TE}$ 是 $T$ 与 $E$ 的协方差。
- **第二步，消去交叉项**：由假设二 $r(T, E) = 0$，协方差 $\sigma_{TE} = 0$，交叉项消失，只剩下两项。
- **第三步，读出含义**：**观测分数的方差 = 真分数方差 + 误差方差**。真分数方差是「值得测的东西」，误差方差是「不该测到的噪声」。

由此定义**信度（reliability）**：

$$\rho_{XX} = \frac{\sigma_T^2}{\sigma_X^2} = 1 - \frac{\sigma_E^2}{\sigma_X^2}$$

信度的含义一目了然：**真分数方差在观测分数方差中所占的比例**。若信度 $= 0.9$，意味着 90% 的分数变异来自真实差异，10% 来自误差；若信度趋近 0，说明分数几乎全是噪声。信度也因此天然落在 $[0, 1]$ 区间，越接近 1 越「可信」。<span class="marginnote">注意信度是「对群体的统计量」，不是「对个人的指标」。它描述的是整组被试分数中真实变异的比例，不能直接说「某个人的分数信度是 0.9」。</span>

**辨析｜易错点：** 信度高不等于测量「对」，只表示「稳定」。一把刻度偏了一厘米的尺子，量什么都稳定，但都不准——**稳定（信度）是准确（效度）的必要而非充分条件**。这一句会贯穿信度、效度两章，也是初学者最常踩的坑。

从信度还能立刻导出一个极有用的量——**测量标准误（standard error of measurement，SEM）**，即误差的标准差：

$$\sigma_E = \sigma_X \sqrt{1 - \rho_{XX}}$$

它回答的是「一个人的分数可能偏离真分数多少」。若某测验的观测分数标准差 $\sigma_X = 10$、信度 $0.84$，则 $\sigma_E = 10 \times \sqrt{0.16} = 4$。按正态近似的经验，该被试真分数约有 95% 的可能落在「观测分 $\pm 2 \times 4$」即 $\pm 8$ 分之内。**信度越高，SEM 越小，单个分数越可信**——这是把群体层面的信度翻译回个体层面分数的关键桥梁，在常模解释（第6篇）里会再次登场。

再举一个数值例，把方差分解走一遍：设某测验观测分方差 $\sigma_X^2 = 100$，算得信度 $\rho_{XX} = 0.84$，则真分数方差 $\sigma_T^2 = 84$，误差方差 $\sigma_E^2 = 16$。四舍五入后，**84% 的分数变异来自真实能力差异，16% 是噪声**——这就是信度数字的直接读法。若再提高测验长度或题目质量使信度升到 0.91，误差方差降到 9，SEM 从 4 缩到 3，单个分数的置信区间也随之变窄。

## 5 经典测量理论的边界

真分数模型简单优雅，但也有绕不开的局限，了解它们才能理解后来者为何出现：

**真分数随测验而变**：同一人的真分数被定义为「这一测验的期望」，换一份不同的测验，真分数定义就变了。于是「真分数」不是被试的不变属性，而是「被试—测验」的配对属性。对测验开发者而言，这意味着所有 CTT 指标都要注明「是在哪份测验、哪个样本上算得的」——脱离情境的信度数字是不可比较的。

**样本依赖**：难度、区分度、信度等指标都依赖施测样本。同一条题目，在高手组里难、在低手组里易，参数就漂移。

**等距性存疑**：分数解释以等距近似为前提，但原始分并不保证等距（见第1篇的测量水平讨论）。

这些局限催生了**项目反应理论（IRT）**——它让题目参数不依赖样本、让被试能力不依赖具体题目，这是本专题第9篇的主题。但即便有了 IRT，**CTT 凭借简单、稳健、易推广，至今仍是测验开发的默认起点**，几乎所有测验手册上的信度、效度数字仍来自 CTT。

另外还值得点明一处适用范围：CTT 假设误差是「同方差」的——真分数高的人与低的人，误差大小被假定一样。现实中高分者（接近天花板）与低分者（接近地板）的误差常常不同，这一同方差假设正是后续 IRT 用「信息函数」逐点刻画精确度的动机之一。

## 6 小结

- 真分数模型的基本等式是 $X = T + E$，**观测分数 = 真分数 + 误差**；真分数被定义为无穷次平行施测的期望。
- 三大假设把误差限定为「随机」：误差期望为零、与真分数无关、不同测验误差无关。
- **平行测验**是让「再测一次」可操作的工具，真分数与信度的定义都借它落地。
- 核心方差公式 $\sigma_X^2 = \sigma_T^2 + \sigma_E^2$，由此定义信度 $\rho_{XX} = \sigma_T^2 / \sigma_X^2$。
- **信度是稳定的度量，效度是对准的度量**；高信度是高效度的必要而非充分条件。
- CTT 的局限（样本依赖、真分数随测验变、误差同方差假设）是 IRT 出现的动机。
- 测量误差（信度管）与抽样误差（假设检验管）是两个层面的「不可信」，勿混为一谈。

- 平行测验是让「再测一次」可操作的概念，真分数与信度的定义都依赖它。
