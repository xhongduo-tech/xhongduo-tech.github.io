# 亲属与婚姻

## 为什么从「亲属」开始

在所有人类社会里，最古老、最普遍的组织方式不是国家、不是公司，而是**亲属（kinship）**——以血缘与婚姻结成的网络。
对狩猎采集者，亲属就是全部政治；
对现代都市人，亲属仍是继承、赡养与亲密的核心。
人类学把亲属制度当作「社会如何自我组织」的第一实验室，因为它最清晰地暴露了一条人类学原则：**生物关系是一回事，社会怎么命名、分组、赋予权利义务，是另一回事。**<span class="marginnote">一个反直觉的事实：人类学的「亲属」研究不关心 DNA。一个收养的孩子在亲属制度里就是「亲生的」，一个没有血缘的结拜兄弟可以比亲兄弟更「亲」。亲属是一种<strong>社会事实</strong>，生物学只是它的素材之一。</span>

这一节讲两件事：**亲属如何分类**（称谓与继嗣），**婚姻如何组织**（婚姻形式与规则）。
下一节再看家庭这个最小的单元。

## 1 亲属称谓：一门「切割」的艺术

每个社会都要回答同一个问题：谁算我的亲人？
答案写在**亲属称谓（kinship terminology）**里——即一套语言上如何称呼亲属的分类系统。
人类学发现，全世界的称谓系统虽然千变万化，却可以归入少数几类。
最经典的分类来自摩尔根（他当年想借此证明进化论），后被称作：

- **夏威夷式（Hawaiian）**：只区分**辈分与性别**。父母辈的所有人（生父、叔叔、舅舅、母亲的姐妹的丈夫……）共用一个词，同辈同理。**最简约的系统**，亲属关系薄而广。
- **爱斯基摩式（Eskimo，今称因纽特式）**：**核心家庭突出**——父母、兄弟、姐妹有专门称呼，叔伯姑舅姨都归入笼统的类别。英语与汉语都接近此式（区别在汉语更细分）。**现代工业社会最常采用。**
- **苏丹式（Sudanese）**：每个亲属位置都有独立称呼——叔叔、舅舅、姑父是三个不同的词。**最复杂、区分度最高**，常见于有严格世系与等级的社会。
- **易洛魁式（Iroquois）**：把父方与母方分开——父亲的兄弟也叫「父亲」，母亲的姐妹也叫「母亲」，但母亲的兄弟叫「舅舅」。这与特定的继嗣规则（父系或母系）配套。
- **克劳式（Crow）与奥马哈式（Omaha）**：把**世系**而非辈分当分类主轴——在母系社会（克劳），你母亲的兄弟的子女被归入你母亲的称呼；父系社会（奥马哈）同理反过来。

**重点：称谓不是给亲戚「贴标签」，而是一套关于「谁和谁是一伙、谁可以和谁结婚、财产往哪传」的路线图。**
一个孩子从小叫一个男人「父亲」还是「舅舅」，将决定他对这个人的态度、义务与禁忌。
称谓是凝固的社会结构。<span class="marginnote">摩尔根当年把这六类排成「进化阶梯」，这是错误的——后来的人类学家证明这些系统可以相互转化，与「先进/落后」无关。但它们确实与<strong>继嗣与婚姻的规则</strong>强相关，这是亲属研究的经典问题（列维-斯特劳斯《亲属的基本结构》就是从中生长出来的结构主义大厦）。</span>

## 2 继嗣：我的祖先，我的群体

除了「怎么称呼」，亲属制度还要回答「**我属于哪个群体**」。
这由**继嗣（descent）**规则决定——即如何通过父母把一个人归属到某个世系群体（lineage / clan）：

| 继嗣规则 | 归属方式 | 常见社会 |
| --- | --- | --- |
| 父系继嗣 patrilineal | 从父方追溯，孩子属父亲世系 | 中国汉族传统、许多农耕社会 |
| 母系继嗣 matrilineal | 从母方追溯，孩子属母亲世系 | 米南加保、易洛魁、纳维霍 |
| 双系继嗣 bilateral | 同时承认父母两系 | 现代欧美、因纽特式社会 |
| 双重继嗣 double descent | 不同权利分属父系与母系 | 西非一些社会 |

**辨析｜易错点：** 母系继嗣 ≠ 母权社会。
母系社会里，政治权力往往仍由**母系的男性成员**（如舅舅）行使——权力沿母系传承，但掌权者常常还是男人。
人类学早已放弃「母系 = 女人统治」的浪漫想象，也抛弃了「父系 = 文明、母系 = 原始」的进化偏见。
母系不是父系的镜像反转，而是另一套逻辑。

继嗣群体之所以重要，是因为它承载着实在的功能：**共同财产、共同祭祀、共同防御、集体责任**。
在中国的宗族、非洲的 lineage、太平洋的 clan 里，「我属于哪个世系」直接决定你的土地、身份与责任。**
血缘在这里不是比喻，而是产权与义务的单位。**<span class="marginnote">一条关键区分：<strong>世系群（lineage）</strong>能说出具体的共同祖先并可追踪谱系，<strong>氏族（clan）</strong>则往往把祖先推到神话人物或图腾，无法逐代追溯。氏族常与婚姻规则（外婚）和宗教象征绑定——这通向《社会组织与结构》一篇。</span>

## 3 婚姻的形式与规则

婚姻是人类学里最「任性」的概念之一：它的**文化定义**远远大于「一男一女的法定结合」。
人类学倾向于用功能性的宽定义：**婚姻是一套社会认可的、确立配偶关系及由此产生的权利与义务（对子女、财产、性的权利）的制度**。

婚姻形式五花八门：

- **一夫一妻制（monogamy）**：一对一。在绝大多数社会是规范或至少是理想形式。
- **一夫多妻制（polygyny）**：一男多女。在实行它的社会里，往往是**权力与财富**的象征——多娶妻是多劳力、多后代、多姻亲。
- **一妻多夫制（polyandry）**：一女多夫。极为罕见，经典案例在喜马拉雅山区（如藏族、尼泊尔部分地区），常与**土地不可分割**的经济约束相关——兄弟们共娶一妻以保住田产不被瓜分。<span class="marginnote">一妻多夫是检验「婚姻 = 生育契约」直觉的试金石：在兄弟共妻的藏区，孩子称长兄为「父亲」，其余为「叔叔」，但所有兄弟都承担抚养责任。它说明婚姻首先是一种<strong>经济与社会的安排</strong>，生育只是其中的一环。</span>

婚姻还有**规则**约束，最重要的两条：

- **外婚制（exogamy）**：必须在自己的亲属群体之外寻找配偶。几乎所有社会都有某种程度的外婚——它迫使群体之间建立联盟网络。
- **内婚制（endogamy）**：必须在某个更大群体之内婚配（如种姓、宗教、阶层内部）。种姓制度是内婚的极端形态。

贯穿这一切的是**乱伦禁忌（incest taboo）**——禁止近亲通婚。
它是人类学史上争论最烈的话题：是生物本能？
是家族功能需要？
列维-斯特劳斯把它视为文化的起点——**乱伦禁忌迫使人们「交换女性」，从而建立了最早的群体间联盟**，人类因此从「自然」进入「文化」。<span class="marginnote">乱伦禁忌的内容因社会而异（表亲婚配在某些社会被鼓励、在另一些被禁止），这本身说明它不是纯粹的生物本能，而是被文化塑形的普遍现象。它的普遍性 + 内容可变性，正是人类学「生物×文化」框架的完美样例。</span>

## 4 婚姻的经济：彩礼与嫁妆

婚姻几乎总是伴随**财富流动**，这暴露了婚姻作为「联盟契约」的本质：

- **彩礼（bridewealth / bride-price）**：新郎方付给新娘方的财物。它常被误读为「买媳妇」，但人类学强调它的功能是**补偿**（新娘离开娘家带走劳力与生育力）与**担保**（如果婚姻破裂或女方早亡，财物的返还/保留有严格规则）。在牧区社会（牛、骆驼当彩礼），它还是把两群人的**财产绑定**在一起的手段。
- **嫁妆（dowry）**：新娘带来的财产。在重视「门当户对」与等级的社会（古典欧洲、印度部分地区）中，嫁妆是女方提升女儿地位、与男方缔结平等契约的方式。
- **聘礼/服务婚**：新郎为新娘家劳动若干年以换取妻子，是彩礼的替代形式。

**重点：彩礼与嫁妆的方向，往往镜像着社会的性别分工与财产制度。**
彩礼常见于牧区与稻作父系社会（女性劳力稀缺），嫁妆常见于等级制农区（女性地位靠带资进门维持）。
读一种婚姻经济，就读到了整个社会的性别与财产结构。

## 5 核心要点速查表

| 概念 | 含义 | 一句话考点 |
| --- | --- | --- |
| 亲属称谓 | 称呼亲属的分类系统 | 称谓是「社会结构」的路线图，不是贴标签 |
| 继嗣 descent | 从父母追溯归属世系 | 母系 ≠ 母权 |
| 世系群 / 氏族 | 可追溯祖先 / 神话祖先 | lineage 具体，clan 抽象 |
| 外婚 / 内婚 | 群体外/内择偶 | 外婚造联盟，内婚保等级 |
| 乱伦禁忌 | 禁止近亲通婚 | 普遍但内容可变：文化起点说 |
| 彩礼 / 嫁妆 | 婚姻中的财富流动 | 方向反映性别与财产制度 |

## 6 小结

- 亲属是**社会事实**而非生物事实：称谓系统（夏威夷式→苏丹式等）是切割「谁是谁」的分类逻辑。
- **继嗣**规则（父系/母系/双系）决定群体归属；**母系继嗣不等于母权统治**。
- 婚姻形式多样（一夫一妻、多妻、多夫），受**外婚/内婚**与**乱伦禁忌**约束；列维-斯特劳斯把乱伦禁忌视为文化本身的起点。
- **彩礼与嫁妆**是婚姻的「经济语法」，读它就读懂性别与财产制度。
