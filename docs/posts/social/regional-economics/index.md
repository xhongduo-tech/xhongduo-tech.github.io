# 区域经济学

区域经济学是应用经济学下的二级学科（020202），研究一国范围内经济资源的空间配置、区域经济增长与差异、区域分工与联系以及城市—区域治理的基本规律。它以区位论、区域增长理论和空间经济学为骨架，为理解区域协调发展战略、都市圈与城市群建设、城乡融合发展提供直接的分析工具。

## 对标教材

- 孙久文、叶裕民《区域经济学教程》中国人民大学出版社
- 安虎森等《区域经济学通论》经济科学出版社
- 高洪深《区域经济学》中国人民大学出版社
