## 为什么从遗传与环境开始

上一节我们立住了发展科学的三问之一：**先天还是后天？** 这一节要回答的不是「哪个更重要」——那个问题在今天的知识版图里已经被淘汰了——而是「先天与后天**如何纠缠**」。就像大模型的成功既不是纯算力、也不是纯算法，而是数据、架构、训练三者的协同，一个人的发展同样是基因、环境与个体自身选择三者协同的产物。我们要学的，是一套能说清这种协同的语言：基因型与表现型、可遗传度、基因—环境相关、表观遗传。

## 1 从 DNA 到人：遗传的机械基础

**基因（gene）**：位于染色体上、携带遗传信息的 DNA 片段，是遗传的基本单位。人类体细胞有 **23 对（46 条）染色体**，其中 22 对常染色体，1 对性染色体（XX 或 XY）；每对染色体，一条来自父亲，一条来自母亲。<span class="marginnote">23 这个数字值得记住：它决定了我们继承的每一份遗传物质都有两个「拷贝」（等位基因）。对同一基因，两个等位基因可以相同（纯合）也可以不同（杂合），后者的显隐关系决定性状如何表现。</span>

**基因型（genotype）**：个体从父母获得的整套基因构成，是「遗传蓝图」。**表现型（phenotype）**：基因型与环境共同作用后实际显现的可观察特征——身高、性格、语言能力，都是表现型。<span class="marginnote">把「基因型→表现型」想成「源代码→运行中的程序」：同一份源代码，跑在不同操作系统、不同输入数据下，行为可以很不一样。环境就是那个操作系统与输入。</span>

绝大多数人类特征不是由单个基因决定的，而是**多基因遗传（polygenic）**：由许多基因的效应叠加，再叠加上环境的影响。这正是为什么身高、智力在人群中呈现连续的正态分布，而不是「高/矮」两极。

与之相对，少数**单基因性状**遵循经典的显隐规律，成为遗传咨询的抓手。例如：卷舌、耳垂形态由单基因控制；而一些疾病——镰状细胞贫血（常染色体隐性）、亨廷顿舞蹈症（常染色体显性，发病多在中年后）——则以「一个基因出错」的方式遗传。这里有一个发展心理学特别关心的细节：**同样一个基因型，在生命周期不同阶段的表达不同**。亨廷顿基因在出生时毫无异样，直到四十多岁才「引爆」——遗传不只是出生瞬间的蓝图，而是贯穿一生的、按时间表兑现的程序。

## 2 遗传研究的三种武器：双生子、收养与家庭

行为遗传学要回答「差异里有多少可归因于遗传」，靠的是三种自然实验：

**双生子研究**：比较同卵双生子（MZ，遗传完全一致）与异卵双生子（DZ，平均共享一半基因）在某特征上的一致性。
- **收养研究**：比较收养儿童与其生物学亲属、收养家庭亲属的相关，把共享环境与共享基因分开。
- **家庭研究**：考察亲属关系亲疏与特征相似度的关系。

**可遗传度（heritability, $h^2$）**：群体内某特征的差异中，可归因于遗传差异的比例，取值 0–1。<span class="marginnote">可遗传度是群体的、特定时代的统计量，不是个人属性。某特征的 $h^2$ 在营养充足的社会里可以很高，在环境极端不均的社会里则会很低——环境差异太大时，差异主要是环境造成的。别把「可遗传度」读成「遗传决定的」。</span>

行为遗传学还会把环境的贡献进一步切开：**共享环境（shared environment）**——同一个家庭的兄弟姐妹共同经历的部分（教养方式、家庭收入、居住社区）；**非共享环境（nonshared environment）**——同一屋檐下各自不同的部分（不同的朋友、不同的老师、父母对不同孩子区别对待）。<span class="marginnote">一个反直觉的经典发现：对很多心理特质，兄弟姐妹间的相似更多来自共享基因而非共享环境——同一家庭长大的兄弟姐妹，其差异很大一部分来自非共享环境。它提醒父母：同一套养育方式会被每个孩子「以不同方式接收」，教养是「个体化的」，不是「批量生产的」。</span>

## 3 基因与环境如何协同：三条机制

今天的行为遗传学不再问「各占多少」，而是追问协同机制。核心是三条：

**反应范围（range of reaction）**：基因决定了一个性状可能落人的区间，环境决定个体在这个区间内的具体落点。<span class="marginnote">例：某种基因使「可能的身高」落在 155–175 cm 之间，具体到 160 还是 170，取决于童年营养与运动。基因画框，环境上色。</span>

**环境力（canalization）**：有些特征被基因保护得异常牢固，环境很难撼动——如绝大多数正常发育的胎儿都会长出眼睛和手。这类特征即使在恶劣环境下也能按蓝图长成，即「渠道化」的。

**基因—环境相关（gene–environment correlation）**：携带某种基因的人，更容易遭遇与之相关的环境，形成「基因挑环境、环境喂基因」的循环。斯卡尔（Scarr）与麦卡特尼（McCartney）区分了三种：

| 类型 | 机制 | 典型表现 |
| --- | --- | --- |
| 被动型 | 父母既给基因又给环境 | 爱读书的父母，孩子既继承阅读基因、又生活在书香环境 |
| 唤起型 | 个体特征引来相应的环境反应 | 活泼的孩子更易被同伴邀请、被老师鼓励 |
| 主动型 | 个体主动选择适合自己的环境 | 好动者选择运动社团，回避安静场合 |

**辨析｜易错点：** 基因—环境相关不是「基因直接决定命运」，而恰恰说明**个体在塑造自己的环境**——这是发展心理学里「个体主动性」的分子机制表达。三种相关随年龄而权重转移：婴儿期被动型为主（环境基本由父母给定），童年期唤起型上升（他人对孩子的反应被其气质调制），成年后主动型主导（人主动挑选适合自己的场景）。**看懂这个转移，就理解了「人是环境的产物，也是环境的选择者」的双向性。**

## 4 公式解析：可遗传度从双生子数据里怎么算

可遗传度不是拍脑袋的数字，它的一个经典估计来自双生子一致性（concordance）——同卵与异卵双生子「同病/同特征」的比例之差：

$$h^2 \approx 2\,(r_{MZ} - r_{DZ})$$

其中 $r_{MZ}$ 为同卵双生子在某特征上的一致性（或相关系数），$r_{DZ}$ 为异卵双生子的对应值。三步拆解：

- **第一步，看懂减号的意义**：同卵与异卵双生子共享的环境基本相同（同家庭、同胎龄），唯一的系统性差别是**基因共享程度**——MZ 共享 100%，DZ 平均共享 50%。于是 $r_{MZ} - r_{DZ}$ 度量的是「多共享的一半基因带来多少额外相似」。
- **第二步，看懂系数 2**：因为差值只对应一半基因的贡献，要还原全部基因的贡献就乘以 2。
- **第三步，小心边界**：$h^2$ 只能落在 [0,1]；若算出来超界，往往意味着共享环境、测量误差或模型假设出了问题——这本身就是一个重要的诊断信号。

**辨析｜易错点：** 很多科普把「$h^2=0.5$ 的智力」读成「你的智力一半由基因决定」。错。它的准确读法是：**在特定人群与时代里，智力差异的 50% 可归因于个体间的遗传差异**。它不预言任何一个人的智力，也绝不是说环境无能为力——事实上，高可遗传度的特征恰恰最容易对环境干预做出反应（营养、教育的作用往往很大），因为它的反应范围宽。

## 5 表观遗传：环境刻进基因开关

遗传与环境之争的最后一块拼图是**表观遗传（epigenetics）**：环境事件可以通过改变基因的「开关」（如 DNA 甲基化），调节基因的表达，而不改变 DNA 序列本身。这些修饰可以传给后代。

最著名的研究是加拿大魁北克的「凶残母鼠抚育」实验：母鼠舔舐幼鼠的行为模式会改变幼鼠应激基因的甲基化状态，进而影响其一生面对压力的方式——而且这种模式还会传递给下一代。<span class="marginnote">这给了先天/后天之争一个漂亮的终结答案：后天经验可以改写在「先天」的开关上。类似机制在大模型语境里也可以类比：预训练（基因）定基调，微调与提示（环境）调节输出模式，而 prompt 调出的偏好可以「遗传」给下游任务——表观遗传与「上下文学习」在结构上是同构的。</span>

表观遗传还给出了**跨代效应的机制通道**：上一代的营养、压力、甚至创伤，都可能通过甲基化与组蛋白修饰影响后代的基因表达。这并不意味着「经验写进基因」——DNA 序列没有变，变的是「读不读、怎么读」。**表观遗传把「环境」正式请进了遗传学的大门**：它说明先天/后天的分界，从分子层面就不成立——两者是同一台机器的两面。

由此，第 1 篇的三问在这里得到一个整合的答案：先天与后天不是两条平行线，而是一张**基因—环境交互作用**的网络。发展心理学给这门课的定位非常明确——**不问「先天还是后天」，而问「各自在什么条件下、通过什么机制起作用」**。这正是从「线性决定论」到「系统协同观」的范式跃迁，也是本专题贯穿始终的方法论底色。

**辨析｜易错点：** 表观遗传常被舆论夸大成「上一代的遭遇会遗传给你」。准确的说法是：**表观遗传标记影响的是基因表达的倾向与阈值，不是把「记忆」或「能力」直接拷贝给后代**，且修饰在代际间会逐渐重置，很多并不稳定。区分「遗传给下一代」与「这一代内被环境改写」两个层次，是读懂表观遗传报道的第一课——它与第 1 篇「相关≠因果」的警觉一脉相承：不要因为机制迷人，就跳过证据的严谨。

## 6 数值算例：一个「可遗传度」读法演练

把「群体统计量」落到实处，最好的办法是看一个具体数值怎么算、怎么解读。假设某项行为特征的双生子数据为 $r_{MZ}=0.6$、$r_{DZ}=0.3$：

$$h^2 \approx 2\,(0.6 - 0.3) = 0.6$$

这意味着什么？**在样本所在的人群与时代里，该特征差异的约 60% 可归因于个体间的遗传差异，约 40% 归因于环境与测量误差。** 它完全不能告诉我们「这个人有 60% 由基因决定」——基因是「把差异写在人群里的倾向」，不是一个可以分给单个个体的百分比。<span class="marginnote">再补一句防误读：$h^2$ 高绝不等于环境无效。许多高可遗传度特征（如身高）恰恰对营养等环境变量高度敏感——因为它的反应范围宽。$h^2$ 描述的是「当下这个人群里差异的来源构成」，不是「有没有可干预空间」。</span>

## 7 术语速查表

| 术语 | 一句话定义 |
| --- | --- |
| 基因型 / 表现型 | 遗传蓝图 / 蓝图与环境作用后的可观察特征 |
| 等位基因 | 同一基因的两个拷贝，可纯合或杂合 |
| 多基因遗传 | 多个基因效应叠加，再叠环境影响 |
| 可遗传度 $h^2$ | 群体内差异中归因于遗传的比例（0–1） |
| 反应范围 | 基因划出的性状区间，环境决定落点 |
| 渠道化 | 被基因保护得异常牢固、环境难撼动的特征 |
| 基因—环境相关 | 被动 / 唤起 / 主动三种「基因挑环境」的循环 |
| 表观遗传 | 环境改变基因开关而不改序列，可跨代传递 |
| 双生子 / 收养 / 家庭研究 | 行为遗传学的三种自然实验 |
| 共享环境 / 非共享环境 | 同家庭共有的 / 各自独有的环境部分 |
| 显性 / 隐性 | 单基因性状的显隐规律（如卷舌、亨廷顿症） |

## 8 小结

- 遗传的基础：23 对染色体、等位基因、**基因型→表现型**，多数特征为多基因遗传。
- 行为遗传学三武器：双生子、收养、家庭研究；**可遗传度** $h^2$ 是群体统计量，不是个人属性。
- 基因与环境的协同：**反应范围、渠道化、基因—环境相关**（被动/唤起/主动）。
- **表观遗传**：环境改基因开关而不改序列，可跨代传递——「后天」能刻进「先天」。
- 别把「可遗传」读成「注定」：可遗传度高的特征，反应范围往往更宽，环境干预更有效。
- 读 $h^2$ 数值时要换算成「差异的构成比例」，并牢记它描述的是人群而非个人。
