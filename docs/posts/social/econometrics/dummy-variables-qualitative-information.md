## 为什么从虚拟变量开始

前面的回归里全是数值变量：教育年限、工作经验、面积。但社会科学里最性感的变量往往是**定性的**：性别、种族、婚姻状况、是否参加培训、某个州是否推行新政。要量化这类信息，计量经济学用**虚拟变量（dummy variable）**——只取 0 和 1 的变量。

虚拟变量是实证研究的「开关」：它让回归能比较**组间差异**，还能与数值变量交互，形成**分段回归**——不同群体有不同的截距和斜率。这一套工具在劳动经济学、公共政策评估、因果推断里无处不在，也是后面《面板数据》《工具变量》的前奏。<span class="marginnote">虚拟变量对应的分类思想在计算机科学里是「one-hot 编码」：把一个类别变量拆成一组 0/1 列。你在大模型里看到的「token 被编码成向量」，底层同样依赖这种「离散信息进模型」的思路——见第四级《深度学习》的嵌入层。</span>

## 1 单个虚拟变量：截距移动

最简单的用法：在回归里加入表示「女性」的虚拟变量 $female$（1 表示女性，0 表示男性）：

$$\text{wage} = \beta_0 + \delta_0 \, female + \beta_1 \, educ + u$$

**核心要点**：系数 $\delta_0$ 衡量的是**男性与女性的截距差**——在受教育年限相同的条件下，女性的平均工资比男性高（或低）$\delta_0$。$female = 0$ 时模型退化为 $\beta_0 + \beta_1 educ$（基准组）；$female = 1$ 时为 $(\beta_0 + \delta_0) + \beta_1 educ$。虚拟变量做的是一次**平行的截距移动**。

**辨析｜易错点：** 若类别有 $g$ 个，只能放 $g - 1$ 个虚拟变量。放满 $g$ 个会造成**完全共线性**——因为各组虚拟变量之和恒等于 1，与常数项完全相关。软件会直接报错或自动丢弃一个，这个错误叫「虚拟变量陷阱」（dummy variable trap）。被省去的那一组称为**基准组（base group）**，所有系数都相对于它解读。<span class="marginnote">「虚拟变量陷阱」就是《线性代数》里的线性相关：$\{1, d_1, \dots, d_{g-1}\}$ 这 $g$ 个向量构成一组基，加入第 $g$ 个就线性相关，矩阵不可逆。四个基本子空间的「零空间」在这里直接现身。</span>

虚拟变量设定的四种常见形式可以对照记忆：

| 设定 | 模型 | 系数的经济含义 |
| --- | --- | --- |
| 单个虚拟变量 | $y = \beta_0 + \delta_0 D + \beta_1 x + u$ | $\delta_0$ = 组间截距差 |
| 多类别 | $y = \beta_0 + \delta_1 D_1 + \delta_2 D_2 + u$ | $\delta_j$ = 与基准组之差 |
| 虚拟 × 数值 | $y = \beta_0 + \delta_0 D + \beta_1 x + \delta_1 (D\cdot x) + u$ | $\delta_0$ = 截距差，$\delta_1$ = 斜率差 |
| 虚拟 × 虚拟 | $y = \beta_0 + \delta_1 D_1 + \delta_2 D_2 + \delta_3 D_1 D_2 + u$ | $\delta_3$ = 双重组合的额外效应 |

**辨析｜易错点：** 虚拟变量取值只有 0/1，但「把它当数值变量排序」是常见误解——类别没有天然大小。把「高中/本科/研究生」编码成 1/2/3 暗含「每升一级效应相同」的错误约束；正确做法是拆成两个虚拟变量（相对基准组）。这与数据科学里「把有序类别做成哑变量而非连续数」的规范完全一致。

## 2 多类别虚拟变量：基准组比较

设地区分四类：东北、中西部、南部、西部。取「西部」为基准组，定义三个虚拟变量：

$$\ln(\text{wage}) = \beta_0 + \delta_1 \, ne + \delta_2 \, midwest + \delta_3 \, south + \cdots + u$$

**核心要点**：$\delta_1$ 表示「东北地区相对西部地区的平均工资差异（对数形式）」。所有系数都是与基准组之差。选择基准组会影响**系数数值**，但不影响模型的拟合（$R^2$ 不变）——因为只是重新参数化。

实际研究中常用「整体显著性检验」：检验地区差异是否显著，就是对 $\delta_1, \delta_2, \delta_3$ 做上一节的 $F$ 检验，原假设 $H_0: \delta_1 = \delta_2 = \delta_3 = 0$。拒绝则说明地区确实影响工资。

**示例：教育回报的性别差异。** 设 $\widehat{\ln(\text{wage})} = 0.40 + 0.09 \cdot educ + 0.03 \cdot female + 0.01 \cdot (female \cdot educ)$，$n = 500$，交互项 $t = 2.1$。男性教育回报为 9%，女性为 10%，差 1 个百分点且显著——性别差异「显著但不大」。注意此时主效应 $0.03$ 只是「$educ = 0$ 时的性别工资差」，并无独立经济意义。

## 3 公式解析：虚拟变量与数值变量交互

上面都是「截距不同、斜率相同」。若想允许斜率也不同，就用**交互项**。考虑教育回报是否因性别而异：

$$\ln(\text{wage}) = \beta_0 + \delta_0 \, female + \beta_1 \, educ + \delta_1 \, (female \cdot educ) + u$$

逐项拆解：

- **第一步，写出男、女各自的方程**。$female = 0$（男）：$\ln(\text{wage}) = \beta_0 + \beta_1 \, educ$；$female = 1$（女）：$\ln(\text{wage}) = (\beta_0 + \delta_0) + (\beta_1 + \delta_1) \, educ$。
- **第二步，识别两个差异**。$\delta_0$ 是**截距差异**（$educ = 0$ 时的性别工资差），$\delta_1$ 是**斜率差异**（教育回报率的性别差）。
- **第三步，检验假设**。检验「教育回报无性别差异」就是 $H_0: \delta_1 = 0$——一次 $t$ 检验。检验「工资结构完全无性别差异」则是 $H_0: \delta_0 = \delta_1 = 0$——一次 $F$ 检验。
- **第四步，泛化**。把 $female$ 换成「参加培训」的虚拟变量，$\delta_1$ 就衡量「培训对不同人群的效果差异」——这就是政策评估里「异质性处理效应」的雏形。

**延伸：当 $D$ 有多个水平时**，交互项也随之增多。例如「教育回报是否因地区而异」需要让 $educ$ 与每个地区虚拟变量都交互——这时检验「回报无地区差异」就是对一组交互项做联合 $F$ 检验。交互项的个数 = 数值变量数 × (类别数 − 1)，模型规模会迅速膨胀，这也是「控制变量太多导致方差变大」的又一个实例。

**核心要点**：虚拟变量 × 数值变量 = 允许该变量的效应在不同组之间变化。这一招在实证论文里叫「交互效应」，在机器学习里叫「特征交叉」，在因果推断里叫「异质性分析」——同一个数学，三种叫法。

## 4 分段回归：一个系数的连续替换

另一类交互：**解释变量在不同区间有不同的斜率**。设收入对消费的影响在低收入区和高收入区不同，引入虚拟变量 $hi$（高收入区为 1）：

$$c = \beta_0 + \beta_1 inc + \delta_0 \, hi + \delta_1 \, (hi \cdot inc) + u$$

**示例：收入分段的边际消费倾向。** 设 $\hat c = 500 + 0.8 \cdot inc + 300 \cdot hi - 0.2 \cdot (hi \cdot inc)$，则低收入者每多 1 元收入消费增加 0.8 元；高收入者增加 $0.8 - 0.2 = 0.6$ 元。$\delta_1 = -0.2$ 显著，说明高收入者的边际消费倾向更低，符合凯恩斯消费理论。

**核心要点**：低收入区的边际消费倾向是 $\beta_1$；高收入区是 $\beta_1 + \delta_1$。若 $\delta_1 < 0$，说明高收入者的边际消费倾向更低——与凯恩斯消费函数理论吻合。这种「在断点处改变斜率」的模型，是后面《限值因变量模型》与断点回归（RDD）的亲戚。

**辨析｜易错点：** 分段回归的「段」是研究者主观划分的，段界不同结论可能不同。而且虚拟变量与连续变量的交互，要求我们同时加入**主效应**（$\delta_0$ 和 $\beta_1$）——只放交互项而不放主效应，会让交互项吸收主效应的作用，解释彻底混乱。这条「先主效应，后交互」的纪律同样适用于上节的性别—教育交互。<span class="marginnote">为什么必须加主效应？因为没有主效应的模型假设「$inc = 0$ 时 $hi = 0$ 与 $hi = 1$ 两组消费相同」——这几乎从不是合理的约束。只放交互项 = 强加了不合理的先验。</span>

## 5 虚拟变量与定性信息的扩展

虚拟变量还能做更多：

**组内去均值**：把变量对虚拟变量组回归取残差，等价于「减去组均值」——这是面板数据里固定效应的雏形，见《面板数据方法》。
- **差分中的差分（DiD）**：$after$ 与 $treated$ 两个虚拟变量及其交互项，交互项系数就是「政策处理效应」的经典估计。
- **季节虚拟变量**：在时间序列里控制季度/月份固定效应，剔除季节波动后再看趋势——见《时间序列回归基础》。
- **分组回归**：当交互项对所有数值变量都加入时，模型等价于对每个子样本分别回归。检验「两组回归系数完全相同」就是对所有交互项做联合 $F$ 检验——这是「组间结构比较」的标准做法，用于检验工资决定机制是否因性别或种族而异。<span class="marginnote">虚拟变量方法在机器学习里的对应物是「one-hot 特征」与「条件偏置」。深度学习中「embedding + 偏置项」几乎就是虚拟变量回归的神经网络化——每个类别学到自己的偏移向量。</span>

**核心要点**：虚拟变量是「分类信息进入回归」的统一接口。一条 $0/1$ 列，就能让模型区分「是与否」「组与组」「期与期」，把社会学问题翻译成可估计的系数。

### 常见误区速览

**Q：为什么 $g$ 类只能放 $g-1$ 个虚拟变量？** 因为 $g$ 个虚拟变量之和恒等于 1，与常数项完全共线，$\mathbf{X}'\mathbf{X}$ 不可逆。省掉的那组是基准组，所有系数相对它解读。

**Q：虚拟变量系数显著，就说明「这个组不同」吗？** 只说明「在控制了其它变量后，该组与基准组有显著差异」。它不回答「为什么不同」，也不等于因果——差异可能来自未控制的遗漏变量。

**Q：把有序类别编码成 1/2/3 有何问题？** 隐含「每升一级效应相同」的错误约束。正确做法是拆成哑变量（相对基准组），让每一级的效应自由估计。

**Q：虚拟变量陷阱只会发生在「放满 $g$ 个」时吗？** 是的，一旦放满就与常数项完全共线、模型无法估计。软件通常自动丢弃一个或直接报错——所以「省掉一个做基准组」不是可选项，而是必须。

### 与「从极限到大模型」主线的连接

虚拟变量是「离散信息进入模型」的最早接口，而大模型把这件事做到了极致：token 被 one-hot 编码后经嵌入层变成稠密向量，每个「类别」都学到自己的表示——虚拟变量的系数 $\delta_0$ 就是「该类别相对基准组的偏移」，嵌入向量则是「该 token 在语义空间里的偏移」。

你在这里建立的「分类 = 加哑变量、比较 = 组间差、交互 = 效应异质性」三连，几乎是所有结构化数据机器学习建模的通用骨架。理解「为什么要设基准组、为什么不把类别当数字、为什么交互要配主效应」，等于在正式学机器学习之前，先把「离散世界如何翻译给连续数学」这门课修完——这是从计量经济学走向一切表格数据建模最短的路。

## 6 小结

- **虚拟变量**取 0/1，系数度量与**基准组**的截距差；$g$ 类只能放 $g-1$ 个，避免**虚拟变量陷阱**。
- 虚拟变量 × 数值变量 = **交互项**，允许斜率随组变化；交互时必须同时放**主效应**。
- **分段回归**让解释变量在不同区间有不同的边际效应。
- 多个虚拟变量的整体显著用 **$F$ 检验**；单个差异用 **$t$ 检验**。
- 虚拟变量是**面板固定效应、DiD、季节调整**的共同积木。
