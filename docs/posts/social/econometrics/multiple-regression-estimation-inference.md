## 为什么从多元回归开始

上一节我们用一条直线解释 $y$ 与一个 $x$ 的关系。但真实世界几乎从不由一个变量主宰：工资不止取决于教育年限，还取决于工作经验、行业、城市；房价不止取决于面积，还取决于地段、楼龄、学区。**多元回归（multiple regression）** 把解释变量从一个扩充到 $k$ 个，让每个系数都承载「**保持其他变量不变**」的因果含义。

多元回归是计量经济学的标准工作母机。它需要一点线性代数作为语言——向量、矩阵、正交、投影，这些来自第二级《线性代数》，而在大模型时代，线性代数又正是 Transformer 里注意力矩阵运算的同一套工具。<span class="marginnote">回归的本质是「把 $y$ 投影到解释变量张成的空间上」——这个几何观点在《线性代数》的四个基本子空间里讲过，这里直接复用。理解了「投影」，就理解了 OLS 的一切代数。</span>本篇聚焦**估计与推断**：系数怎么算、方差怎么估、假设怎么检验。下一篇再谈函数形式与模型选择等进一步问题。

## 1 多元模型：偏效应出场

**多元线性回归模型（multiple linear regression model）**写成：

$$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_k x_k + u$$

**核心概念**：系数 $\beta_j$ 称为 $x_j$ 的**偏效应（partial effect）**——它是在**其余解释变量都保持不变**时，$x_j$ 增加一个单位引起的 $y$ 的平均变化。数学上它是条件期望的偏导数：

$$\beta_j = \frac{\partial\, E(y \mid x_1, \dots, x_k)}{\partial x_j}$$

这正是「保持其他条件不变」的精确翻译：偏导只让 $x_j$ 动，其余全部冻结。相比简单回归里 $\beta_1$ 可能混入其他变量的影响，多元回归的 $\beta_j$ 是「净效应」。

多元模型的零条件均值假设升级为：

$$E(u \mid x_1, x_2, \dots, x_k) = 0$$

由此可推出 $E(u) = 0$，以及 $E(x_j u) = 0$ 对每个 $j$ 都成立——每个解释变量都与误差项不相关。<span class="marginnote">多元假设比一元更苛刻：它要求误差项不依赖任何解释变量。若某个重要变量被遗漏（进入 $u$），而它又与某个 $x_j$ 相关，零条件均值就被破坏——这就是下一节「遗漏变量偏误」的由来。</span>

整个模型也可写成矩阵形式。设 $X$ 为 $n \times (k+1)$ 数据矩阵（第一列全为 1），$\beta = (\beta_0, \beta_1, \dots, \beta_k)'$，则 $y = X\beta + u$，OLS 估计量写为 $\hat\beta = (X'X)^{-1}X'y$。<span class="marginnote">矩阵形式是《线性代数》里「最小二乘解」的直接应用：$\hat\beta$ 正是正规方程 $X'X\hat\beta = X'y$ 的解，几何上就是 $y$ 到列空间的投影系数。把这里的 $X$ 换成注意力矩阵的投影矩阵，就是大模型里「把查询投影到键值空间」的同款运算。</span>

## 2 多元 OLS：一阶条件与部分化

设样本为 $\{(x_{i1}, x_{i2}, \dots, x_{ik}, y_i)\}_{i=1}^{n}$。OLS 选择 $\hat\beta_0, \dots, \hat\beta_k$ 最小化：

$$\sum_{i=1}^{n} \left( y_i - \hat\beta_0 - \hat\beta_1 x_{i1} - \cdots - \hat\beta_k x_{ik} \right)^2$$

对每个参数求导并令其为零，得 $k+1$ 个**一阶条件**：

$$\sum_{i=1}^{n} \hat u_i = 0, \qquad \sum_{i=1}^{n} x_{ij} \hat u_i = 0, \quad j = 1, \dots, k$$

**核心要点**：一阶条件要求残差 $\hat u$ 与**每一个**解释变量 $x_j$ 都正交。几何上，拟合值 $\hat y$ 是 $y$ 在由 $\{1, x_1, \dots, x_k\}$ 张成的线性空间上的**正交投影**，而残差 $\hat u = y - \hat y$ 垂直于这个空间。这一句话同时解释了系数公式、平方和分解与自由度。

**辨析｜易错点：** 多元回归里 $\hat\beta_j$ 与「把 $y$ 单独对 $x_j$ 做一元回归」得到的系数**一般不相等**。只有当解释变量两两不相关时二者才相同。多元回归做的事是：先剥离其他变量的影响，再测量 $x_j$ 的净效应——这个「剥离」在下一节用部分化定理精确表达。

## 3 公式解析：部分化定理与偏回归

多元回归系数 $\hat\beta_j$ 有一个极富洞察力的计算方式，叫**部分化（partialling out）**，也叫**Frisch–Waugh–Lovell 定理**：

$$\hat\beta_j = \frac{\sum_{i=1}^{n} \tilde r_{ij} \cdot (y_i - \bar{y})}{\sum_{i=1}^{n} \tilde r_{ij}^2}$$

其中 $\tilde r_{ij}$ 是把 $x_j$ 对**其余所有解释变量**（含常数项）做回归后得到的残差。逐步拆解：

- **第一步，剥离 $x_j$**：把 $x_j$ 对 $x_1, \dots, x_{j-1}, x_{j+1}, \dots, x_k$ 做回归，取残差 $\tilde r_{ij}$。这个残差是 $x_j$ 中**不被其他变量解释**的部分，即「$x_j$ 独有的信息」。
- **第二步，再看 $y$**：把 $y$ 也做同样的剥离，得到 $y$ 中不被其他变量解释的部分 $y - \bar{y}$（在含常数项的回归里，$\tilde y$ 恰是 $y - \bar{y}$）。
- **第三步，回归**：用 $y$ 的残余部分对 $x_j$ 的残余部分做一元回归，斜率就是 $\hat\beta_j$。

**核心要点**：$\hat\beta_j$ 只由「$x_j$ 独有的变化」决定。若 $x_j$ 与其他变量高度共线，$\tilde r_{ij}$ 就非常小，$\hat\beta_j$ 变得不稳定——这正是下一节**多重共线性**问题的根源。部分化定理告诉我们：多元回归不是「黑箱求解」，而是「先净化，再比较」，每一步都有清晰的几何直觉。

## 4 拟合优度与调整 $R^2$

多元模型的平方和分解依旧成立，$R^2$ 同样定义为 $SSE/SST$。但出现一个新问题：**只要往模型里加变量，$R^2$ 就永远不会下降**（残差平方和只会变小）。于是有了**调整 $R^2$**：

$$\bar{R}^2 = 1 - \frac{SSR/(n - k - 1)}{SST/(n - 1)} = 1 - (1 - R^2)\frac{n-1}{n-k-1}$$

**核心要点**：$\bar{R}^2$ 用自由度对加变量施以「惩罚」：分子分母都除以各自的自由度。新增变量若不能带来足够的解释力，$\bar{R}^2$ 可能不升反降。因此 $\bar{R}^2$ 是「在解释力与模型简洁之间找平衡」的第一个工具，下一篇的模型选择会进一步用它。

**辨析｜易错点：** $\bar{R}^2$ 不是「真正的 $R^2$ 修正版」意义上的拟合优度——它可能为负，也不再满足「在 $[0,1]$ 之间」的性质。它本质是一个**模型选择的评分指标**，而非对解释力的估计。用它比较模型时，被比较的模型必须共享同一个被解释变量 $y$。

## 5 统计推断：$t$ 检验

估计出系数还不够，还要问：$\beta_j$ 显著不为零吗？这需要标准误。在**同方差**与**正态误差**假设下，OLS 估计量服从正态分布，于是可构造 $t$ 统计量：

$$t_{\hat\beta_j} = \frac{\hat\beta_j - \beta_j}{\mathrm{se}(\hat\beta_j)} \sim t_{n-k-1}$$

对原假设 $H_0: \beta_j = 0$（$x_j$ 对 $y$ 无偏效应），检验统计量是 $t = \hat\beta_j / \mathrm{se}(\hat\beta_j)$，服从自由度为 $n - k - 1$ 的 $t$ 分布。$\mathrm{se}(\hat\beta_j)$ 由误差方差估计 $\hat\sigma^2 = SSR/(n-k-1)$ 与数据二阶矩共同决定：

$$\mathrm{Var}(\widehat{\beta_j} \mid \mathbf{x}) = \frac{\hat\sigma^2}{SSR_j}, \qquad SSR_j = \sum_{i=1}^{n} \tilde r_{ij}^2$$

实务中更常用 **p 值**：它是在原假设为真时，「看到当前这么极端或更极端统计量」的概率。p 值小于显著性水平 $\alpha$（常取 0.05）即拒绝 $H_0$。**辨析｜易错点：** p 值小不等于效应大——样本量越大，同样大小的效应越容易显著。显著性是「证据强度」，经济重要性是「效应大小」，两者必须分开报告。

**核心要点**：$SSR_j$ 正是部分化里 $x_j$ 对其它变量回归的残差平方和。**$x_j$ 与其它变量越相关，$SSR_j$ 越小，标准误越大，$t$ 值越小**——多重共线性就是这样「吃掉」显著性的。检验逻辑与第二级《概率论与数理统计》的假设检验完全一致：算出 $t$，与临界值比，落在拒绝域则拒绝 $H_0$。

## 6 联合检验：$F$ 检验

有时要同时检验多个系数。例如检验「学历对工资的影响」可能需要教育年限、学历虚拟变量等多个系数一起看；再如检验整组虚拟变量。原假设写为 $H_0: \beta_{q+1} = \cdots = \beta_k = 0$，即最后 $k-q$ 个变量可以剔除。**$F$ 统计量**为：

$$F = \frac{(SSR_r - SSR_{ur})/q}{SSR_{ur}/(n - k - 1)} \sim F_{q,\, n-k-1}$$

其中 $SSR_{ur}$ 是完整（不受限）模型的残差平方和，$SSR_r$ 是剔除 $q$ 个变量后的受限模型残差平方和。**核心要点**：分子衡量「剔除变量后拟合恶化了多少」（按剔除变量数归一化），分母是完整模型的平均残差方差。$F$ 大说明被剔除的变量联合上确实有解释力，应拒绝 $H_0$。

**示例：检验一组地区虚拟变量。** 设完整模型含 3 个地区虚拟变量，$SSR_{ur} = 120$，$n = 200$，$k = 8$；剔除这 3 个变量后受限模型 $SSR_r = 135$。则：

$$F = \frac{(135 - 120)/3}{120/(200 - 8 - 1)} = \frac{5}{0.628} \approx 7.96$$

与 $F_{3, 191}$ 的 5% 临界值（约 2.65）比较，$F$ 落在拒绝域——拒绝「地区对工资无影响」的原假设。

**辨析｜易错点：** $t$ 检验看单个系数，$F$ 检验看一组系数——但**若干各自不显著的系数，联合可能显著**（共线性让单个 $t$ 都小）；反过来，某个系数单独显著，也不保证它所在的整组联合显著。两者回答不同的问题，不能互相替代。<span class="marginnote">$t$ 与 $F$ 的关系：检验单个系数时 $t^2 = F$。所以 $t$ 检验是 $F$ 检验的「单变量特例」——在数理统计里它们同属一般线性假设检验框架。</span>

### 与「从极限到大模型」主线的连接

多元回归的「偏效应」思想，是大模型时代「控制变量」逻辑的统计版本：想判断「一个因素净贡献多少」，就必须把其它因素同时放进模型。Transformer 的多头注意力，本质也是「在高维空间里让每个 token 从其它 token 那里『回归』出自己的表示」——注意力权重就是一场高维回归的系数。

你在这里学会的 $\hat\beta = (X'X)^{-1}X'y$ 与最小二乘几何，将贯穿之后遇到的岭回归、Lasso 乃至神经网络的反向传播：它们都在做同一件事——用数据拟合、用正交化剥离、用方差度量不确定性。学完多元回归，你不仅学会了计量经济学的母机，也拿到了读懂机器学习线性模型家族的第一把钥匙。

## 7 小结

- **多元回归**让每个系数成为**偏效应**：其余变量不变时 $x_j$ 变动的净影响。
- 多元 OLS 的残差与**每个**解释变量正交；拟合值是 $y$ 到解释变量空间的**投影**。
- **部分化定理**：$\hat\beta_j$ 等于「$y$ 的残余」对「$x_j$ 的残余」的回归——系数只由 $x_j$ 独有的信息决定。
- **多重共线性**通过缩小 $SSR_j$ 放大标准误，但不破坏无偏性。
- $t$ 检验单系数、$F$ 检验一组系数；$\bar{R}^2$ 用自由度惩罚加变量。
