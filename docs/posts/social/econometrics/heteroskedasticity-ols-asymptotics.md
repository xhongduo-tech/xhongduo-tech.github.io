## 为什么从异方差开始

OLS 的经典推导里藏着一个安静的假设：误差项 $u$ 的方差**不随解释变量变化**——同方差（homoskedasticity）。但现实中这个假设经常被违反：高收入家庭的花费波动远大于低收入家庭，企业的利润波动随规模增大而变大。这就是**异方差（heteroskedasticity）**。

这一节把「误差方差不恒定」的全部后果讲清楚：它**不破坏无偏性**，但会**破坏标准误、$t$ 检验与置信区间**。好消息是，我们有不需要假设同方差的**稳健标准误**，而且在大样本下 OLS 的渐近性质依然成立。这些内容为后续所有章节打底——面板数据、工具变量、GMM 全都默认要处理异方差。<span class="marginnote">异方差的直觉可以对照大模型训练里的「损失不平滑」：某些样本的误差天然更大。稳健标准误就像「对不同样本的波动给出更诚实的方差估计」，而不是假设所有样本同质。</span>

## 1 异方差的定义与来源

**同方差**：$\mathrm{Var}(u \mid x) = \sigma^2$，误差的方差与解释变量无关。**异方差**：$\mathrm{Var}(u \mid x) = \sigma^2(x)$，误差的方差随 $x$ 变化。

**辨析｜易错点：** 异方差讨论的是**条件方差**的变化，与**误差的均值**无关——零条件均值 $E(u \mid x) = 0$ 依旧成立，所以 **OLS 仍然无偏**。异方差只是说「围绕回归直线的离散程度不均匀」，而不是说「回归直线本身偏了」。把这两件事分开，是理解本节的第一步。

异方差的常见来源：测量误差随规模放大、遗漏了「放大效应」的变量、截面数据里个体异质性大、以及**偏态分布的被解释变量**（如收入、房价、消费）。<span class="marginnote">实用诊断技巧：把 $\hat u^2$ 对 $x$ 或拟合值画散点图，若呈「漏斗形」（拟合值越大、残差越散），多半有异方差。这类图形诊断在《数据科学》的可视化章节有系统讨论。</span>

## 2 异方差的后果

设模型 $y = \beta_0 + \beta_1 x + u$，OLS 估计量仍可写成 $\hat\beta_1 = \beta_1 + \frac{\sum (x_i - \bar{x}) u_i}{\sum (x_i - \bar{x})^2}$。若 $E(u_i \mid x) = 0$ 且 $E(u_i u_j \mid x) = 0$（$i \neq j$），则：

$$E(\hat\beta_1 \mid x) = \beta_1 \quad \text{（仍无偏）}$$

但方差公式变了。在同方差下 $\mathrm{Var}(\hat\beta_1) = \sigma^2 / \sum(x_i-\bar{x})^2$；在异方差下真实方差为：

$$\mathrm{Var}(\hat\beta_1 \mid x) = \frac{\sum (x_i - \bar{x})^2 \sigma_i^2}{\left[\sum (x_i - \bar{x})^2\right]^2}$$

异方差对各环节的影响可以列表对照：

| 项目 | 是否受影响 | 原因 |
| --- | --- | --- |
| 无偏性 / 一致性 | 不受影响 | $E(u \mid x) = 0$ 仍在 |
| $R^2$ | 不受影响 | 只依赖平方和分解 |
| 普通标准误 | 受影响（有偏） | 方差公式假设同方差 |
| $t/F$ 检验、置信区间 | 受影响（失效） | 基于错误的标准误 |
| 稳健标准误 | 正确 | 允许方差随 $x$ 变化 |

**核心要点**：同方差下的方差公式（把 $\sigma_i^2$ 都换成 $\sigma^2$）在异方差下**不再正确**。于是基于它的标准误、$t$ 值、$F$ 值、置信区间**全部失效**——这是异方差最危险的后果：不是系数错了，而是「不知道系数到底有多准」。<span class="marginnote">注意异方差不影响 $R^2$ 的计算（它只依赖平方和分解），所以模型拟合优度的报告照旧，但推断必须修正。</span>

## 3 检验异方差：BP 检验与 White 检验

既然后果严重，先检验有没有异方差。**Breusch–Pagan（BP）检验**的思路：把 OLS 残差平方 $\hat u^2$ 对解释变量做回归：

$$\hat u^2 = \delta_0 + \delta_1 x_1 + \cdots + \delta_k x_k + v$$

原假设 $H_0$：同方差，即 $\delta_1 = \cdots = \delta_k = 0$。检验统计量是 $n R^2_{\hat u^2}$（该辅助回归的 $R^2$ 乘以样本量），在 $H_0$ 下渐近服从 $\chi^2_k$ 分布。**核心要点**：$n R^2$ 大则拒绝同方差。

**White 检验**更一般：辅助回归里除了解释变量，还加入它们的平方与两两交叉项，检验这些项联合是否为零。若不加入交叉项而只加平方项，称「White 检验的简化形式」，参数更少、更常用。无论哪种形式，核心都是「残差平方是否被解释变量系统解释」。它不依赖「异方差的具体函数形式」，能捕捉更多异方差模式，但参数更多、小样本下功效可能下降。<span class="marginnote">BP 与 White 都是「把残差平方当作异方差的探针」。它们与统计里「对辅助回归做 $F$ 或 $\chi^2$ 检验」同出一辙，检验逻辑来自第二级《概率论与数理统计》。</span>

**辨析｜易错点：** 检验不拒绝 $H_0$ 不代表「确定同方差」，只是「没有足够证据反对」。样本小时检验功效低。更稳健的做法是：**别纠结检验，直接一律报告稳健标准误**——现代实证研究的标准实践。

### 加权最小二乘与 FGLS

稳健标准误修正**推断**，但不改变估计效率。若我们愿意对异方差的结构做假设，可以走另一条路：**加权最小二乘（WLS）**。设 $\mathrm{Var}(u_i \mid x_i) = \sigma^2 h(x_i)$，其中 $h(x_i)$ 已知，则把每个观测除以 $\sqrt{h(x_i)}$ 再回归：

$$\frac{y_i}{\sqrt{h_i}} = \beta_0 \frac{1}{\sqrt{h_i}} + \beta_1 \frac{x_i}{\sqrt{h_i}} + \frac{u_i}{\sqrt{h_i}}$$

新误差的方差恒为 $\sigma^2$（同方差了），OLS 在此转换数据上就是 **BLUE**。**核心要点**：WLS 对「方差小（信息准）的观测」给更大权重——这与 GMM 的逆方差加权、机器学习里「按样本权重加权损失」是同一个精度加权原理。当 $h(x_i)$ 未知而需估计时，就叫 **FGLS**；估计 $h$ 的常见方式是把 $\ln \hat u^2$ 对解释变量回归并取指数。

## 4 公式解析：异方差稳健标准误

修正推断的工具是**异方差稳健标准误（heteroskedasticity-robust standard errors）**，也叫 White/Huber–Eicker 标准误。对斜率系数：

$$\mathrm{se}_{\text{robust}}(\hat\beta_1) = \sqrt{\frac{\sum (x_i - \bar{x})^2 \hat u_i^2}{\left[\sum (x_i - \bar{x})^2\right]^2}}$$

逐步拆解：

- **第一步，认出结构**：它与真实方差公式 $\mathrm{Var}(\hat\beta_1 \mid x) = \dfrac{\sum (x_i-\bar{x})^2 \sigma_i^2}{\left[\sum(x_i-\bar{x})^2\right]^2}$ 形状一致——把未知的 $\sigma_i^2$ 换成可得的 $\hat u_i^2$。
- **第二步，为什么有效**：$\hat u_i$ 是 $u_i$ 的一致估计，所以 $\frac{1}{n}\sum (x_i-\bar{x})^2 \hat u_i^2 \xrightarrow{p} \frac{1}{n}\sum (x_i-\bar{x})^2 \sigma_i^2$——大样本下「用残差平方代替误差方差」是对的。
- **第三步，多元推广**：多元模型里稳健协方差矩阵是 $\widehat{\mathrm{Avar}}(\hat\beta) = (\mathbf{X}'\mathbf{X})^{-1} \left(\sum_i \hat u_i^2 \mathbf{x}_i'\mathbf{x}_i\right) (\mathbf{X}'\mathbf{X})^{-1}$——这是「三明治形式」：两片面包是 $(\mathbf{X}'\mathbf{X})^{-1}$，中间的肉是残差平方加权的二阶矩。
- **第四步，作用**：用稳健标准误替换普通标准误，$t$、$F$、置信区间在异方差下依然渐近有效。**系数本身不变，变的只是它的「精度标签」。**

**示例：稳健与普通标准误的差距。** 设一元回归 $n = 100$，普通标准误 $\mathrm{se} = 0.20$，而高收入样本残差大、低收入样本残差小，稳健标准误算得 $0.32$。此时若沿用普通标准误，$t = \hat\beta/0.20$ 会虚高，可能误把不显著当显著。二者差距越大，异方差越严重——这也是「先报告稳健标准误」成为期刊惯例的原因。

**核心要点**：稳健标准误 = 允许每个观测有自己的方差，用残差平方估计之。它不假设异方差的具体形式，故称「稳健」。

## 5 OLS 的渐近性：大样本下的新世界

前几节的无偏性要求严格的假设（如 $E(u\mid x) = 0$）。现实里有些假设很难完全成立，但样本一大，OLS 依然表现出良好性质——这就是**渐近理论（asymptotics）**。

**核心要点**：在相对宽松的假设下（$E(x'u) = 0$、二阶矩有限、无完全共线性），OLS 估计量是**一致的（consistent）**：

$$\hat\beta \xrightarrow{p} \beta$$

且渐近正态：$\sqrt{n}(\hat\beta - \beta) \xrightarrow{d} N(0, \mathbf{A}^{-1}\mathbf{B}\mathbf{A}^{-1})$，其中 $\mathbf{A} = E(\mathbf{x}'\mathbf{x})$，$\mathbf{B} = E(u^2 \mathbf{x}'\mathbf{x})$。**核心要点**：渐近方差正是上面三明治形式的总体系数版本——这说明「稳健标准误」不是锦上添花，而是渐近推断的自然产物。<span class="marginnote">渐近理论让 OLS 从「要求严格假设」升级为「大样本下自然成立」。这把计量经济学带进现代：只要样本够大、矩条件成立，检验就有效。同样的逻辑是 GMM 与机器学习的共同地基。</span>

**核心要点**：渐近理论的价值在于「把困难的分布问题变成简单的大样本近似」。只要样本够大、矩条件成立，就无需逐一验证误差的正态性与同方差——检验在大样本下自动有效。这也是现代应用计量「默认稳健标准误」的底气：即使不知道误差的具体结构，大样本 + 三明治方差也能给出可信推断。

**辨析｜易错点：** 一致性是「样本趋近无穷时逼近真值」，不等于「有限样本无偏」。OLS 可以是「有偏但一致」的（例如存在测量误差时）。渐近正态性也只在大样本下近似成立——小样本时依旧要依赖古典假设或使用 $t$ 分布近似。

### 常见误区速览

**Q：异方差会让 OLS 系数有偏吗？** 不会。只要 $E(u \mid x) = 0$ 仍在，OLS 依旧无偏且一致；异方差只破坏标准误与检验，修正推断用稳健标准误即可。

### 与「从极限到大模型」主线的连接

异方差与稳健标准误揭示了一个普适原则：**误差结构未知时，不要假装它已知**。大模型训练里同样如此——不同样本的损失方差天差地别，于是有了梯度裁剪、损失自适应加权、per-sample 归一化。你在这里学的「用残差平方估计每个观测的方差」，与深度学习里「按梯度方差自适应调整学习率」是同一个精度加权思想。

而渐近理论「大样本下一切自动正确」的乐观，也自带警示：当数据不够大、假设不成立时，一切渐近结论都要打折扣。这提醒大模型研究者，在几十亿参数、海量 token 的尺度上「大样本」总是成立的；但在小样本微调、长尾场景里，异方差式的「不确定性不均」恰恰是必须正视的统计现实。

## 6 小结

- **异方差**是条件方差随 $x$ 变化；它**不破坏 OLS 的无偏性与一致性**。
- 但它使**普通标准误、$t/F$ 检验、置信区间失效**。
- 用 **BP 检验 / White 检验** 侦测；但更稳妥的是**直接使用稳健标准误**。
- **稳健标准误**（三明治形式）用 $\hat u_i^2$ 代替 $\sigma_i^2$，不假设异方差形式，大样本有效。
- **渐近理论**：$E(x'u) = 0$ 下 OLS 一致且渐近正态，稳健推断是渐近框架的自然结论。
