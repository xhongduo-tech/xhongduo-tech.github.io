## 为什么从 ARMA 开始

上一节我们把时间序列当作「带误差项的回归」来处理。但这忽略了一个最自然的事实：**今天往往由昨天塑造**。通货膨胀今天的水平常接近昨天，股价今天的变动常接近昨天的波动。**ARMA/ARIMA 模型**把这种「自己依赖自己」的结构显式建出来，是金融、宏观预测的标准语言。

这一节完成时间序列从「描述」到「建模」的跃迁，并处理最棘手的两个问题：**单位根**（非平稳的根源）与**协整**（非平稳变量间仍存在长期均衡关系）。它们与上节的平稳性直接咬合，也是理解「伪回归为何可怕」的终点。<span class="marginnote">ARMA 的「用过去预测未来」正是序列模型（RNN、Transformer）的核心动机。大模型预测下一个 token，数学上就是一个高阶、非线性的自回归模型——你在这里学的滞后项思想，是它的线性祖辈。</span>

## 1 自回归模型：AR(p)

**自回归（autoregressive, AR）**模型：$y_t$ 用**自己的滞后值**来解释。$AR(p)$：

$$y_t = \phi_1 y_{t-1} + \phi_2 y_{t-2} + \cdots + \phi_p y_{t-p} + e_t$$

其中 $e_t$ 是**白噪声（white noise）**：$E(e_t) = 0$，$\mathrm{Var}(e_t) = \sigma^2$，且不同期不相关。最常用的是 $AR(1)$：

$$y_t = \phi_1 y_{t-1} + e_t$$

**核心要点**：$\phi_1$ 度量「昨天对今天的影响」。$|\phi_1| < 1$ 时冲击会随时间衰减，序列**平稳**；$\phi_1 = 1$ 时冲击永不衰减——这就是**随机游走（random walk）**，非平稳的典型；$|\phi_1| > 1$ 时序列爆炸。**平稳性由系数是否落在单位圆内决定**。<span class="marginnote">为什么叫「单位圆」？AR(p) 的平稳条件是把滞后算子方程 $\phi(L) = 0$ 的根都要求落在单位圆外。对 AR(1)，根是 $1/\phi_1$，故要求 $|\phi_1| < 1$。这套语言在控制理论里叫「系统稳定性」，是同一个数学。</span>

## 2 移动平均模型：MA(q)

**移动平均（moving average, MA）**模型：$y_t$ 用**过去冲击**的线性组合来解释。$MA(q)$：

$$y_t = e_t + \theta_1 e_{t-1} + \cdots + \theta_q e_{t-q}$$

**核心要点**：MA 把 $y_t$ 写成当期与过去白噪声冲击的加权和。MA 模型**无条件平稳**（冲击的权重和有限），其自相关在滞后 $q$ 期后**截断**为零；AR 模型的自相关则**指数衰减**而不截断。这是识别 AR 还是 MA 的经典指纹——看自相关函数（ACF）是否截断。

| 特征 | AR(p) | MA(q) |
| --- | --- | --- |
| 定义 | $y_t$ 用滞后值解释 | $y_t$ 用过去冲击解释 |
| 无条件平稳性 | 需系数在单位圆内 | 无条件平稳 |
| ACF | 指数衰减、不截断 | 滞后 $q$ 后截断 |
| PACF | 滞后 $p$ 后截断 | 指数衰减 |
| 预测 | 直接外推滞后值 | 仅当期冲击可预测 |

**辨析｜易错点：** 识别 AR 与 MA 用 ACF 与 PACF：AR 的 ACF 衰减、PACF 截断；MA 的 ACF 截断、PACF 衰减。注意「衰减」与「截断」在大样本里靠置信带判断——样本相关落在 $\pm 1.96/\sqrt{n}$ 带内即视为 0。

**辨析｜易错点：** AR 与 MA 在理论上可以互相转化（可逆性/平稳性条件下）：一个 $AR(1)$ 可写成一个无穷阶 MA（把 $y_{t-1}$ 继续展开），一个可逆的 $MA(1)$ 也可写成无穷阶 AR。所以「选 AR 还是 MA」不是本质之分，而是「用有限阶近似哪个更经济」——这正是 ACF/PACF 与信息准则存在的意义。

## 3 公式解析：AR(1) 的平稳条件与单位根

把 $AR(1)$：$y_t = \phi y_{t-1} + e_t$ 的平稳性拆透：

- **第一步，求均值**：两边取期望，$E(y_t) = \phi E(y_{t-1})$。平稳时 $E(y_t) = E(y_{t-1}) = \mu$，得 $\mu = \phi \mu$。若 $|\phi| \neq 1$，则 $\mu = 0$——平稳 AR(1) 均值为零。
- **第二步，求方差**：$y_t = \phi y_{t-1} + e_t$，取方差：$\gamma_0 = \phi^2 \gamma_0 + \sigma^2$（$e_t$ 与 $y_{t-1}$ 独立）。解得 $\gamma_0 = \sigma^2 / (1 - \phi^2)$。**方差为正要求 $1 - \phi^2 > 0$，即 $|\phi| < 1$**——平稳条件在此现身。
- **第三步，看 $\phi = 1$**：此时 $y_t = y_{t-1} + e_t$（随机游走）。方差随时间线性增长，均值可能漂移——**单位根（unit root）**，非平稳。
- **第四步，冲击的寿命**：反复代入得 $y_t = \sum_{j=0}^{\infty} \phi^j e_{t-j}$。$|\phi| < 1$ 时早期冲击 $e_{t-j}$ 以 $\phi^j$ 指数衰减；$\phi = 1$ 时所有冲击权重恒为 1，**永不消失**——这就是「单位根 = 冲击持久」的直觉。

**示例：AR(1) 的预测。** 设 $y_t = 0.8 y_{t-1} + e_t$，$e_t$ 标准差为 2，当前 $y_{100} = 5$。一步预测 $E(y_{101}) = 0.8 \times 5 = 4$；两步预测 $0.8^2 \times 5 = 3.2$——预测随 $0.8^j$ 指数收缩向均值 0。对比随机游走（$\phi = 1$）：预测永远等于当前值 $y_{100}$——这就是「单位根 → 最佳预测是现值」的直觉。

**核心要点**：平稳 ↔ $|\phi| < 1$ ↔ 冲击衰减；单位根 ↔ $\phi = 1$ ↔ 冲击永续。这一条线把统计性质与经济含义（冲击的持久性）焊在一起。

## 4 ARIMA 与单位根检验

把三者拼起来：**ARIMA(p, d, q)** 表示对 $y_t$ 做 $d$ 阶差分后是平稳的 ARMA(p, q)：

$$\Delta^d y_t \sim ARMA(p, q)$$

最常见的 **ARIMA(0,1,0)** 就是随机游走 $y_t = y_{t-1} + e_t$（$d=1$）。**核心要点**：差分的目的是「把非平稳变平稳」——趋势型随机游走差分后变成平稳的白噪声或平稳 ARMA。

**单位根检验**：检验「是否需要对序列差分」，即检验 $\rho = 1$（等价于检验 $\phi = 1$）。把 $AR(1)$ 写成差分形式：

$$\Delta y_t = (\phi - 1) y_{t-1} + e_t = \gamma y_{t-1} + e_t$$

原假设 $H_0: \gamma = 0$（单位根），备择 $H_1: \gamma < 0$（平稳）。直接做 $t$ 检验不行——单位根情形下 $t$ 统计量不再服从 $t$ 分布，要用 **Dickey–Fuller（DF）检验**的特殊临界值（其分布非标准，临界值更负）。**Augmented Dickey–Fuller（ADF）检验**在回归里加入滞后差分项以消除自相关，更一般。<span class="marginnote">ADF 检验的「非标准临界值」是一个经典提醒：假设一换，检验分布全变。这与大模型评测里「指标分布随数据分布漂移」同理——统计学的边界意识处处相通。</span>

**补充**：ADF 检验的实际操作还常包含常数项与趋势项（视序列而定），并把滞后差分阶数选到残差无自相关为止。软件默认输出「ADF 统计量 + 对应 p 值」，p 值显著（< 0.05）则拒绝单位根、认为序列平稳。

**辨析｜易错点：** 单位根检验的功效问题很大：当 $\phi$ 接近但不等于 1（如 0.97），有限样本几乎无法区分，检验常错误地「接受单位根」。所以实务上常把单位根检验当作「是否需要差分的参考」，而不是铁律——并应与经济理论（冲击是否应当持久）互相印证，而非机械照单全收。

## 5 协整与误差修正模型

若两个非平稳序列各自有单位根，但它们的**线性组合**却平稳，称它们**协整（cointegrated）**。直觉：两个变量虽然各自乱走，却总被一条「长期均衡关系」拴在一起，偏离了就会拉回来。**核心要点**：协整 = 「共同漂移的非平稳 + 稳定的长期关系」。例子：消费与收入、汇率与相对物价、现货价与期货价。

检验协整用 **Engle–Granger 两步法**：

1. 对 $y_t = \alpha + \beta x_t + u_t$ 做 OLS，得残差 $\hat u_t$；
2. 对 $\hat u_t$ 做单位根检验——若拒绝单位根，则 $y_t, x_t$ 协整，$\beta$ 是长期关系系数。

一旦协整，可估计**误差修正模型（ECM）**：

$$\Delta y_t = \alpha_0 + \alpha_1 \Delta x_t + \lambda \, \hat u_{t-1} + v_t$$

**示例：消费与收入。** 消费 $C_t$ 与可支配收入 $Y_t$ 各自随机游走，但长期看消费约占收入的固定比例——$C_t - \beta Y_t$ 平稳。若某期消费过高（偏离均衡），下一期会被拉回。Engle–Granger 两步法：先回归得 $\hat\beta$，再检验残差是否平稳；ECM 的 $\lambda$ 估计「每月把偏离拉回多少」。

**核心要点**：$\hat u_{t-1}$ 是上一期的「偏离均衡」程度，系数 $\lambda < 0$ 表示偏离会被拉回——$\lambda$ 是**调整速度**。ECM 同时捕捉短期动态（$\alpha_1 \Delta x_t$）与长期均衡（误差修正项），是宏观计量最优雅的模型之一。<span class="marginnote">协整的「长期均衡 + 短期修正」结构，与优化里的「目标函数 + 梯度回拉」、控制论里的「负反馈」是同构的：系统被一条看不见的线拉回。大模型里注意力归一化维持稳定分布，也是同一个「回归均值」原则。</span>

### 常见误区速览

**Q：随机游走与带趋势的平稳序列有何区别？** 随机游走 $y_t = y_{t-1} + e_t$ 的冲击永不衰减、方差随时间发散；带确定性趋势的平稳序列 $y_t = \alpha + \delta t + e_t$ 去掉趋势后平稳。前者须差分，后者加时间项即可。

**Q：ADF 检验不拒绝单位根，就一定非平稳吗？** 未必。$\phi$ 接近 1（如 0.97）时检验功效很低，常误接受单位根。应结合经济理论判断「冲击是否应当持久」。

### 与「从极限到大模型」主线的连接

ARIMA 的「差分变平稳、再自回归」与语言模型的「预测下一个 token」共享同一个骨架：**都是自回归（autoregressive）**。GPT 的架构名里就带着 AR——它用前面的 token 预测后面的 token，与 AR(p) 模型 $y_t = \phi_1 y_{t-1} + \cdots + e_t$ 一脉相承，只是把线性滞后换成了非线性深度网络。

而「单位根 = 冲击永续」提醒我们：一旦系统存在单位根，任何预测都会长期偏离——这与大模型「推理时自回归累积误差」的现象是同一类风险。理解 ACF/PACF 的「截断 vs 衰减」，也让你能看懂大模型里「注意力模式随层数衰减/聚焦」的分析——时间结构的分辨能力，是理解一切序列模型的地基。

## 6 小结

- **AR(p)** 用滞后值解释现在；**MA(q)** 用过去冲击解释现在；**ARMA = AR + MA**，**ARIMA** 先差分再 ARMA。
- **平稳条件**：AR 系数落在单位圆内（$AR(1)$ 即 $|\phi| < 1$）；**$\phi = 1$ 即单位根/随机游走**，冲击永续、方差发散。
- **DF/ADF 检验**判断单位根，但临界值非标准、功效有限。
- **协整**：非平稳序列的平稳线性组合，捕捉长期均衡；用 **Engle–Granger 两步法**检验。
- **误差修正模型（ECM）**把长期均衡与短期动态统一，$\lambda < 0$ 表示向均衡回归。
