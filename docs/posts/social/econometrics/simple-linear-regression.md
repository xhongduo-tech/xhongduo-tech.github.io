## 为什么从简单线性回归开始

计量经济学（econometrics）用数据回答「变量之间是什么关系、关系有多强」这类问题。整个学科的引擎，是从一对变量的关系开始的：**简单线性回归（simple linear regression）**。它把一个被解释变量 $y$ 与一个解释变量 $x$ 之间的关系写成一条直线，再从数据里把这条直线「估」出来。别看它只有一个自变量，OLS 的全部思想——**零条件均值假设、残差正交、平方和分解、统计推断**——都在这个最简单的模型里第一次登场。

学这篇之前，需要两件武器：随机变量、期望与方差的直觉，来自第二级《概率论与数理统计》；把「直线」当作一类函数来理解，来自第一级《集合与函数》。<span class="marginnote">读完本篇你会看到，OLS 估计量 $\hat\beta_1$ 本身就是一个随机变量：换一个样本，就换一套数值。这正是计量经济学「用数据推断总体」的起点。</span>后续的多元回归、面板数据、工具变量，都是在这台小引擎上不断加装部件。先把简单线性回归彻底想明白，等于拿到整门学科的钥匙。

## 1 回归：从「相关」到「条件预期」

**回归分析（regression analysis）**：研究被解释变量 $y$ 如何随解释变量 $x$ 变化的方法。这个词来自高尔顿（Francis Galton）对身高的研究：他发现高个子父母的子女平均身高会「向均值回归」，于是把这类关系命名为 regression。

总体模型写作：

$$y = \beta_0 + \beta_1 x + u$$

其中 $y$ 是**被解释变量（dependent variable）**，$x$ 是**解释变量（explanatory variable）**，$u$ 是**误差项（error term）**——它囊括一切影响 $y$ 却未被 $x$ 捕捉的因素。$\beta_0$ 是**截距（intercept）**，$\beta_1$ 是**斜率（slope）**。

**核心概念**：$\beta_1$ 的严格含义是「**保持其他条件不变**（ceteris paribus）时，$x$ 变动一个单位，$y$ 平均变动 $\beta_1$」。这个「保持其他条件不变」是计量经济学的灵魂——我们想要的是因果效应，而简单相关性混入了混淆因素。<span class="marginnote">「相关不等于因果」是流传最广的统计学警示：冰淇淋销量与溺水人数高度正相关，但多卖冰淇淋并不导致溺水——共同的原因是夏天。回归想逼近因果，靠的是把 $u$ 里的混淆因素「关掉」，这正是下一节零条件均值假设要做的事。</span>

## 2 零条件均值假设：OLS 的基石

要让 $\beta_1$ 能被估计出来，需要给误差项提要求。最核心的一条是**零条件均值假设（zero conditional mean）**：

$$E(u \mid x) = 0$$

**这条假设成立，意味着：给定任意 $x$，误差项 $u$ 的平均值总是 0。** 也就是说，$u$ 里不再藏着与 $x$ 有关、又同时影响 $y$ 的因素——$x$ 的信息无法帮助预测 $u$。由期望的迭代法则（law of iterated expectations）可推出两条伴随结论：

$$E(u) = 0, \qquad E(xu) = 0$$

第一条说误差项无条件均值是零，第二条说 $x$ 与 $u$ 不相关。这两条是后面推导 OLS 公式的出发点。

**辨析｜易错点：** 零条件均值 $E(u \mid x) = 0$ 比「$u$ 与 $x$ 不相关」更强。不相关只要求 $\mathrm{Cov}(x, u) = 0$，而零条件均值要求 $u$ 对 $x$ 的任意函数 $f(x)$ 都有零均值。这个差别会在后面「遗漏变量偏误」里反复出现——遗漏变量恰恰造成 $E(u \mid x) \neq 0$。

## 3 OLS：把直线「画」到数据上

有了总体模型，接下来用样本估计参数。设样本为 $\{(x_i, y_i) : i = 1, \dots, n\}$。**最小二乘估计（Ordinary Least Squares, OLS）** 选择 $\hat\beta_0, \hat\beta_1$，使残差平方和最小：

$$(\hat\beta_0, \hat\beta_1) = \mathop{\arg\min}_{b_0, b_1} \sum_{i=1}^{n} (y_i - b_0 - b_1 x_i)^2$$

其中 $y_i - \hat\beta_0 - \hat\beta_1 x_i = \hat u_i$ 叫**残差（residual）**——它是样本层面 $u_i$ 的估计。最小化的直观含义：画一条直线，让所有数据点到这条直线的**竖直距离**的平方和最小。

![简单线性回归的 OLS 拟合](/images/econometrics/simple-linear-regression-1.svg)

对 $b_0, b_1$ 求偏导并令其为零，得到**一阶条件**：

$$\sum_{i=1}^{n} \hat u_i = 0, \qquad \sum_{i=1}^{n} x_i \hat u_i = 0$$

这两个等式意味着：**残差之和为零，且残差与 $x$ 在样本上正交**——它们正是总体条件 $E(u)=0$ 与 $E(xu)=0$ 的样本版本。这个「正交」结构贯穿整个 OLS 理论，后续所有推导几乎都从这里长出来。<span class="marginnote">为什么用「竖直距离」而不是点到直线的垂直距离？因为我们的目标是预测 $y$，误差只发生在 $y$ 方向；用垂直距离做「正交回归」主要用于两个变量都有测量误差的情形。</span>

## 4 公式解析：OLS 斜率估计量

解一阶条件，得斜率估计量的闭式解：

$$\hat\beta_1 = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2}$$

逐步拆解：

- **第一步，看分子**：$\sum (x_i - \bar{x})(y_i - \bar{y})$ 是 $x$ 与 $y$ 的**样本协方差**（未除以 $n-1$）。它刻画两个变量**一起偏离各自均值**的程度：$x_i$ 高于均值时，$y_i$ 是否也倾向于高于均值。
- **第二步，看分母**：$\sum (x_i - \bar{x})^2$ 是 $x$ 的**样本方差**（未除以 $n-1$）。它刻画 $x$ 自身的分散程度。分母越大，数据在 $x$ 方向铺得越开，斜率越能被精确锁定。
- **第三步，合起来**：$\hat\beta_1 = \text{样本协方差} / \text{样本方差}$。直觉是「$y$ 随 $x$ 变动的单位幅度」——把 $y$ 与 $x$ 共同变化的量，按 $x$ 的变化量归一化。

**核心要点**：$\hat\beta_1$ 衡量「$x$ 变动一个单位，$y$ 平均变动多少」的样本估计。它由数据唯一确定；拟合直线 $\hat y = \hat\beta_0 + \hat\beta_1 x$ 一定穿过样本均值点 $(\bar{x}, \bar{y})$。截距可用 $\hat\beta_0 = \bar{y} - \hat\beta_1 \bar{x}$ 反推——直线过均值点，是 OLS 的一个几何性质。

## 5 OLS 估计量的性质

估计出来的 $\hat\beta_0, \hat\beta_1$ 是随机变量（换一个样本就换一套数值），所以要谈它们的统计性质。在三个经典假设下——**总体线性**（模型形式正确）、**随机抽样**（样本独立同分布）、**零条件均值**——OLS 估计量是**无偏（unbiased）**的：

$$E(\hat\beta_1 \mid x) = \beta_1$$

无偏性意味着「平均来看不偏」。在此基础上，**高斯—马尔可夫定理（Gauss–Markov theorem）** 断言：在所有线性、无偏的估计量中，OLS 的方差最小——即在古典假设下，OLS 是 **BLUE（Best Linear Unbiased Estimator，最优线性无偏估计量）**。

**辨析｜易错点：** 高斯—马尔可夫定理只在线性、无偏的估计量家族里比大小。允许有偏的估计量（如后面的工具变量估计、机器学习里的正则化估计）可以方差更小、或性质更好。所以「BLUE」不等于「所有估计量里最好」，只是「线性无偏这一族里的最优」。

在**同方差（homoskedasticity）**假设 $\mathrm{Var}(u \mid x) = \sigma^2$ 成立时，斜率的条件方差为：

$$\mathrm{Var}(\hat\beta_1 \mid x) = \frac{\sigma^2}{\sum_{i=1}^{n} (x_i - \bar{x})^2}$$

**分母越大方差越小**——$x$ 越分散，斜率估计越精确。这就是做实验时总想拉开 $x$ 取值范围的原因；它也是后面「样本量决定精度」的最初版本。<span class="marginnote">同方差假设如果被违反——$u$ 的方差随 $x$ 变化，就是<strong>异方差（heteroskedasticity）</strong>。OLS 仍无偏，但方差公式与检验失效，这是《异方差性与 OLS 渐近性》一节的主题。</span>

## 6 拟合优度与 $R^2$

估计完直线，自然要问：拟合得好吗？把 $y$ 的离差分解为**已解释部分**与**未解释部分**：

$$y_i - \bar{y} = (\hat y_i - \bar{y}) + \hat u_i$$

两边平方求和，交叉项因残差正交而为零，得到**平方和分解**：

$$\underbrace{\sum (y_i - \bar{y})^2}_{\text{SST}} = \underbrace{\sum (\hat y_i - \bar{y})^2}_{\text{SSE}} + \underbrace{\sum \hat u_i^2}_{\text{SSR}}$$

**判定系数（coefficient of determination）**定义为：

$$R^2 = \frac{SSE}{SST} = 1 - \frac{SSR}{SST}$$

$R^2$ 表示 $x$ 解释 $y$ 总离差的比例，取值总在 $[0, 1]$。$R^2 = 0.6$ 意味着样本中 $y$ 的变动有 60% 被 $x$ 的线性关系解释。在简单回归里，$R^2$ 恰等于样本相关系数的平方。

**辨析｜易错点：** $R^2$ 高不等于模型好，低也不等于模型差。$R^2$ 只衡量「线性关系的解释比例」，不检验因果、不反映系数是否显著、也看不出遗漏变量。横截面研究中 $R^2$ 常常只有 0.2–0.4，却仍是有价值的研究；一味追求 $R^2$ 是初学者最常见的误区，多元回归里我们还会专门讨论「用 $R^2$ 选模型的陷阱」。

## 7 小结

- **简单线性回归**把 $y$ 与一个 $x$ 的关系写成 $y = \beta_0 + \beta_1 x + u$，$\beta_1$ 是「其他条件不变」下 $x$ 的边际效应。
- **零条件均值假设** $E(u \mid x) = 0$ 是 OLS 无偏的基石，它严格强于「$u$ 与 $x$ 不相关」。
- **OLS** 最小化残差平方和，斜率估计量是样本协方差除以样本方差；残差与 $x$ 正交。
- 古典假设下 OLS **无偏且 BLUE**；同方差时 $\mathrm{Var}(\hat\beta_1 \mid x) = \sigma^2 / \sum(x_i - \bar{x})^2$，$x$ 越分散越精确。
- $R^2$ 度量解释比例，但**高 $R^2$ 不等于好模型**。

在下一节，我们将把解释变量从一个扩充到多个——这就是**多元回归分析**，也是整门学科真正的主战场。
