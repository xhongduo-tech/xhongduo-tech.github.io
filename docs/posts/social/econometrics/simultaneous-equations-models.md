## 为什么从联立方程开始

供求分析是经济学的第一课：价格决定需求量，需求量又反过来决定价格。这类「变量相互决定」的现象，在计量上意味着每个方程的解释变量都与别的方程的误差纠缠——**联立性（simultaneity）** 是内生性的又一大来源。

**联立方程模型（simultaneous equations model, SEM）** 把「相互决定」显式写成一族方程。它的核心问题不是「怎么估计」，而是「**能不能识别**」——从观察到的数据里，到底能不能唯一地拆出每条方程的结构系数。这一节将「识别」这个概念推到聚光灯下，它是整个计量经济学最深刻的主题之一，也是工具变量思想的系统化。<span class="marginnote">联立性制造内生性的机制很纯粹：供给冲击同时移动均衡价格与均衡数量，于是价格与供给方程误差相关。反过来，这也解释了为什么「价格对需求量回归」会得到荒谬的斜率——你看到的散点是两条曲线交点的轨迹，不是需求曲线。</span>

## 1 结构式与简化式

以经典**供求模型**为例：

$$\text{需求：} Q^d = \alpha_0 + \alpha_1 P + \alpha_2 Y + u_1, \qquad \text{供给：} Q^s = \beta_0 + \beta_1 P + u_2$$

**结构式（structural form）**：描述经济行为关系的原始方程——需求方程、供给方程。它们含内生变量 $P$ 在等式右边，且误差项之间可能相关。

均衡时 $Q^d = Q^s = Q$，解出 $P$ 与 $Q$ 关于外生变量 $Y$ 的表达式，得**简化式（reduced form）**：

$$P = \pi_{10} + \pi_{11} Y + v_1, \qquad Q = \pi_{20} + \pi_{21} Y + v_2$$

**核心要点**：简化式每个方程右边只有外生变量，可直接用 OLS 估计；它是「把整个系统对外生变量做投影」。结构系数藏在简化式系数 $\pi$ 与误差方差协方差里——能否把它们「反解」出来，就是识别问题。

## 2 公式解析：识别问题的本质

以需求方程 $\alpha_1$（价格弹性）的识别为例，看「能不能唯一确定」：

- **第一步，想清楚数据来源**：观测到的 $(P, Q)$ 是**供给曲线与需求曲线的交点**。每一次外生冲击（如 $Y$ 变化移动需求曲线，或 $u_2$ 变化移动供给曲线）都会扫出一个新交点，形成一条散点带。
- **第二步，问「散点带是什么」**：如果只有需求波动、供给固定，交点沿着**同一条供给曲线**移动——散点带把供给曲线画出来了，需求曲线却无法识别。
- **第三步，对称地看**：如果供给也在动、需求也在动，交点的轨迹是**两条曲线共同作用的结果**——单独一条方程一般无法从混合散点里唯一分离。
- **第四步，结论**：识别需要的是一种「**排他性信息**」——某个外生变量只出现在一条方程里。本例中 $Y$（收入）只出现在需求方程，它就是识别供给方程的工具。**简化式里 $Y$ 能移动需求曲线，从而单独「拨动」供给曲线——这正是识别供给方程所需的杠杆。**

**示例：供求系统的识别。** 设需求含收入 $Y$、供给只含价格。数据显示：$Y$ 上升时 $Q$ 与 $P$ 都上升——交点沿供给曲线移动，供给曲线被「画」出来，于是供给方程 $\beta_1$ 可识别；而需求方程（其移动靠 $Y$）无法从数据中分离，除非另有只影响需求的变量。这就是「$Y$ 是供给方程的工具」的数据直觉。

**延伸**：识别不是「统计检验能确认的」——它由「哪些变量进入哪条方程」的先验结构决定。同一个数据集，不同的排他性假设会给出不同甚至相反的识别结论。这正是「识别靠理论、估计靠数据」的经典分工。

**核心要点**：识别 = 「能否用观察数据唯一确定结构参数」。它本质上是代数问题：结构参数是简化式参数的非线性函数，函数是否可逆，决定可识别性。这与线性代数里「方程组是否有唯一解」是同构的。

## 3 识别的阶条件与秩条件

对含 $G$ 个内生变量、$K$ 个外生变量的**线性联立方程组**，第 $j$ 个方程的识别条件：

**阶条件（order condition）——必要条件**：第 $j$ 个方程里**被排除的外生变量数** ≥ 该方程右边**内生变量数 − 1**。直觉：每个「独有外生变量」就是一个工具；工具数要不少于内生解释变量数，才谈得上识别。

**秩条件（rank condition）——充分条件**：在所有**不含**第 $j$ 个方程被排除变量的其余方程中，这些被排除变量（作为整体）必须与其它方程线性独立，使得「拨动它们」能唯一地移动第 $j$ 条方程。

**辨析｜易错点：** 阶条件只看「数量够不够」，容易满足；秩条件看「独立性够不够」，常被忽略。**阶条件满足但秩条件不满足**的方程仍不可识别——只数工具数、不检查工具是否真的相互独立，是初学者常掉进的坑。<span class="marginnote">阶条件与秩条件的数学背景正是《线性代数》里的秩：识别问题 = 「外生变量在系统里张成的空间是否足以唯一锁定结构向量」。秩是「信息维度」的度量，在这里直接决定了「能否识别」。</span>

**补充**：实践中有个快速检查——数该方程独有的外生变量个数是否 ≥ 该方程内生解释变量个数，满足则阶条件通过；秩条件较难手工验证，通常由软件在估计时报告（如「equation not identified」警告）。

## 4 恰好识别、过度识别与估计

按「被排除外生变量数 $-$ 右边内生变量数 $+ 1$」的差，分三类：

**不可识别**：差 < 0，工具不足，什么方法都救不了（除了加排他性约束）。
- **恰好识别（just identified）**：差 = 0，工具数恰够。可用 **间接最小二乘（ILS）**：估计简化式，再反解结构参数。
- **过度识别（overidentified）**：差 > 0，工具数富余。用 **2SLS**（或更一般的估计），并可用上一节的**过度识别检验**验证多余的排他性约束。

**示例：恰好识别的间接最小二乘。** 设简化式 $P = \pi_{10} + \pi_{11} Y + v_1$、$Q = \pi_{20} + \pi_{21} Y + v_2$，估计得 $\hat\pi_{11} = 0.8$、$\hat\pi_{21} = 0.4$。供给方程的斜率可反解：$\hat\beta_1 = \hat\pi_{21}/\hat\pi_{11} = 0.4/0.8 = 0.5$——这就是 ILS 的「先简化式、再反解」。

| 类型 | 排除外生变量数 − 内生变量数 + 1 | 可识别？ | 估计方法 |
| --- | --- | --- | --- |
| 不可识别 | < 0 | 否 | 加排他性约束 |
| 恰好识别 | = 0 | 是 | ILS / 2SLS |
| 过度识别 | > 0 | 是 | 2SLS + 过度识别检验 |

**核心要点**：联立方程模型对单个方程的估计，其实就是**工具变量回归**——被排除的外生变量就是该方程内生解释变量的工具。因此上一节的 2SLS 在这里直接复用，估计原理完全一致。<span class="marginnote">这一点是理解 SEM 的钥匙：联立方程组「每个方程单独用 2SLS 估计」在大多数情况下就够用了，无需神秘化。真正的系统级工具是 3SLS——它同时利用所有方程的交叉信息，更有效率但更脆弱。</span>

## 5 系统估计与联立方程的价值

**三阶段最小二乘（3SLS）**：对全部方程同时估计，考虑跨方程误差相关，效率高于逐个 2SLS。但 3SLS 对任一方程的错误设定都敏感——一个方程错，整个系统跟着错（错误传播）。因此实践上更偏爱「方程级稳健」的 2SLS。

### 从联立方程到结构性估计

现代应用计量把「联立方程」升级为「结构性估计」：先写下一个经济机制模型（如需求系统、动态厂商模型），把其均衡条件转化为矩条件或似然函数，再估计深层参数，用于反事实模拟。**核心要点**：结构性估计要回答「政策变了会怎样」，这正是大模型时代「世界模型」的目标——不只是拟合观测，而是理解产生观测的机制。

**核心要点**：联立方程模型在现代应用计量中的位置比较微妙——许多研究者已转向「结构式」视角（明确写出行为的潜在方程），用**结构性估计**去回答「反事实」（如果政策变了会怎样）。这与大模型时代的「世界模型」异曲同工：建一个内在机制的模型，而不是只拟合表面相关。

**辨析｜易错点：** 不要以为「方程越多越好」。每个方程都要讲清经济学机制，每个排他性约束都要有正当理由——**多余的、无依据的约束只会污染识别**。经典教科书建议：先用两个方程把逻辑讲透，再谈系统估计。

### 常见误区速览

**Q：联立方程组是不是一定要用 3SLS？** 不一定。对大多数场景，每个方程单独用 2SLS 就够；3SLS 利用跨方程信息更高效，但任一方程设定错误会污染整个系统。

**Q：识别问题能靠「更多数据」解决吗？** 不能。识别是结构问题：数据再多，没有排他性信息（某个外生变量只进一条方程），结构系数依然不可识别。识别靠理论，估计靠数据。

**Q：简化式系数就是结构系数吗？** 不是。简化式系数是外生变量对内生变量的总影响，结构系数藏在其中，需要反解（ILS）或直接用 2SLS 估计。

**Q：联立方程里怎么给方程找工具？** 工具就是「被该方程排除、却出现在系统其它方程里的外生变量」。所以先数清系统的外生变量全集，再看每个方程「独享」了哪些——独享的外生变量就是它的工具。

**核心要点**：联立方程的全部要义浓缩为一句话——「识别靠排他性约束，估计靠工具变量」，其余都是它的展开与细节。

### 与「从极限到大模型」主线的连接

联立方程教给我们的「识别意识」，在科学研究的每个角落都成立：看到「$y$ 对 $x$ 的回归」，先问「$x$ 会不会反过来被 $y$ 决定」。大模型时代这种双向依赖无处不在——推荐算法影响用户行为，用户行为又喂养推荐算法；搜索引擎结果塑造认知，认知又决定搜索。

理解识别，就是理解「相关数据里藏着的双向箭头」。而结构性估计「先写机制、再拟合数据」的方法，正是今天「世界模型」「因果模型」研究者的共同信仰：与其拟合表面相关，不如建立一个能回答反事实问题的内在机制模型——这是联立方程留给 AI 时代最珍贵的遗产。

## 6 小结

- **联立性**是内生性的重要来源：$P$ 决定 $Q$、$Q$ 又决定 $P$，单方程 OLS 有偏。
- **结构式**描述行为机制；**简化式**把内生变量全解成外生变量的函数，可直接 OLS。
- **识别问题** = 能否从简化式唯一反解结构参数；需要「只出现在一条方程里」的排他性信息。
- **阶条件**数工具够不够（必要条件），**秩条件**查工具独立性（充分条件）。
- 对单方程，**2SLS 直接可用**；**3SLS** 系统估计更高效但更脆弱。
- SEM 的思想延伸至**结构性估计**——用机制模型回答反事实问题。
