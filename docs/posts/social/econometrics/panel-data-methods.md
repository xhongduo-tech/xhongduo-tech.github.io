## 为什么从面板数据开始

前几篇的横截面数据只拍「一个时刻的许多人」，时间序列只拍「一个人的很多时刻」。**面板数据（panel data）** 同时拥有两个维度：同一批个体（家庭、企业、州、国家）被**追踪多个时期**。

面板数据的价值在于它能做横截面做不到的事：**控制不可观测的个体异质性**。一个人的能力、一家企业的管理水平、一个州的文化传统，往往看不见、测不到，却又同时影响解释变量与被解释变量——它们是遗漏变量偏误的头号来源。面板数据通过「同一批个体反复出现」这个结构，把这些「不随时间变化的个体特征」直接消掉。<span class="marginnote">面板数据的核心思想与因果推断里的「以己为鉴」一脉相承：拿每个人自己的过去做对照，就能抵消「人与人不同」造成的混淆。这比横截面里「拿别人做对照」干净得多。</span>

## 1 面板数据的结构与模型

设 $i = 1, \dots, n$ 为个体，$t = 1, \dots, T$ 为时期。观测为 $\{y_{it}, x_{it}\}$。**不可观测效应（unobserved effect）**模型：

$$y_{it} = \beta_0 + \beta_1 x_{it} + a_i + u_{it}$$

其中 $a_i$ 是**个体固定特征**（不随时间变化，如能力、基因、企业文化），$u_{it}$ 是**特异误差**（随个体与时间都变）。

**核心要点**：$a_i$ 就是「看不见的个体异质性」。若 $a_i$ 与 $x_{it}$ 相关，把它塞进误差项会导致**遗漏变量偏误**——这正是面板数据要解决的头号问题。$a_i$ 与 $x$ 不相关时，可作随机效应处理；相关时须用固定效应处理（下篇细讲）。

**辨析｜易错点：** 千万别一上来就「混合回归」（把面板当大横截面合并回归）。只要 $a_i$ 与 $x_{it}$ 相关，混合 OLS 就是有偏的。面板方法的第一课是：**先想清楚 $a_i$ 与解释变量是否相关，再选工具**。<span class="marginnote">区分「平衡面板」（每个个体期数相同）与「非平衡面板」（期数不等）。后期进入或流失的个体若与结果相关，会引入选择性——对应医学里的「失访偏倚」。</span>

## 2 一阶差分估计：最朴素的消元法

当 $T = 2$ 时，一个极简单而漂亮的估计是**一阶差分（first difference, FD）**。对同一个体两期相减：

$$y_{i2} - y_{i1} = \beta_1 (x_{i2} - x_{i1}) + (u_{i2} - u_{i1})$$

注意 $a_i$ 在两期相同，**相减后被消掉了**。于是「个体特征」不再出现在方程里——遗漏变量偏误的源头被物理性地移除。

**示例：两期一阶差分。** 设追踪 5 家企业 2 年，$x$ 是培训时长（小时），$y$ 是人均产出。每家企业的 $x$ 平均增加 3 小时、$y$ 平均增加 1.2 单位，则 $\hat\beta_1^{FD} = \overline{\Delta y}/\overline{\Delta x} = 1.2/3 = 0.4$——每多培训 1 小时，人均产出平均增 0.4 单位。注意这里完全绕开了「哪家企业本来就强」：强的企业自始至终强，两期相减后其「水平」被抵消。

**核心要点**：FD 估计用「同一批人的变化」来识别系数。$\hat\beta_1$ 回答的问题是：「**同一家企业**，当 $x$ 增加一个单位时，$y$ 平均增加多少？」——它把「企业之间的差异」全部排除，只留下「企业自身随时间的变化」来估计效应。这比横截面「不同企业之间比较」更接近因果。

## 3 公式解析：一阶差分为何能消掉 $a_i$

把两期方程完整展开，看消元过程：

- **第一步，写两期方程**：
  $$y_{i1} = \beta_0 + \beta_1 x_{i1} + a_i + u_{i1}, \qquad y_{i2} = \beta_0 + \beta_1 x_{i2} + a_i + u_{i2}$$
- **第二步，相减**：第二式减第一式，$\beta_0$ 与 $a_i$ 同时消失（它们不随时间变）：
  $$\Delta y_i = \beta_1 \Delta x_i + \Delta u_i, \qquad \Delta y_i = y_{i2} - y_{i1}, \ \Delta x_i = x_{i2} - x_{i1}$$
- **第三步，看新误差**：新误差 $\Delta u_i = u_{i2} - u_{i1}$ 不再含 $a_i$。只要 $\Delta u_i$ 与 $\Delta x_i$ 不相关，OLS 就无偏。
- **第四步，直觉**：$a_i$ 的消除不是靠「控制变量」，而是靠**数据本身的重复结构**——同一个体被观察两次，它的固定特征在两期中「自我抵消」。这就是面板数据能战胜不可观测异质性的根本机制。
- **延伸**：FD 与 FE 在 $T = 2$ 时给出**完全相同**的估计——两期里「相对均值」与「相邻差分」是同一回事。$T > 2$ 时二者一般不同：FE 利用全部时期信息、通常更有效率；FD 对某些误差结构（如随机游走型误差）更稳健。

**核心要点**：FD 的本质是「用个体的时间变化做识别」，代价是只利用变化信息、损失一期的信息（截距与水平信息）。

## 4 多期面板与扩展

当 $T > 2$ 时，一阶差分变成：

$$\Delta y_{it} = \beta_1 \Delta x_{it} + \Delta u_{it}, \qquad t = 2, \dots, T$$

对每个个体做相邻期差分，再混合估计。**核心要点**：多期 FD 同样消除 $a_i$，且可用上全部相邻变化，效率更高；但相邻差分会引入 $\Delta u_{it}$ 的自相关（$u_{it}$ 与 $u_{i,t-1}$ 出现在相邻差分里），推断时需注意。

**示例：多期 FD。** 设 $T = 5$ 年、$n = 100$ 家企业，$x$ 为研发投入比例。对每家企业计算 4 个相邻差分 $\Delta x_{it}$ 与 $\Delta y_{it}$，合并成 $4 \times 100 = 400$ 个观测做回归。此时 $\hat\beta_1$ 由「研发投入变化与产出变化的关系」识别——比横截面「研发高的企业产出高」更接近因果。

### 面板数据与重复横截面

**重复横截面（repeated cross-section）** 每期换一批人（如每月的消费者调查），**面板数据**追同一批人。区别很关键：重复横截面**无法**消除个体固定效应（没有同一个体被观察两次），只能用时间虚拟变量加组别虚拟变量——这恰恰是 DiD 的用武之地；面板则能靠 FD/FE 直接消掉 $a_i$。**辨析｜易错点：** 把重复横截面当面板用（对不匹配的个体做差分），是数据处理上的严重错误。

面板数据的常见扩展：

- **加入时间虚拟变量**：控制「对所有个体共同作用」的宏观冲击（如某年经济衰退）。
- **加入个体层面的解释变量**：如政策虚拟变量 $policy_{it}$，系数就是「政策实施前后、参与组相对对照组的平均变化」——这已接近**差分中的差分（DiD）** 思想。<span class="marginnote">FD 与 DiD 的关系：$T=2$ 且有一个处理组与对照组时，FD 估计恰等于「处理组变化减去对照组变化」——这就是 DiD 的双重差分公式。你在这里学到的一阶差分，是政策评估主力方法的第一块积木。</span>

## 5 面板数据的优势与局限

**优势**：

**控制不可观测、不随时间变的个体异质性**（消除一类最重要的遗漏变量偏误）。
- 增加样本量与自由度，估计更精确。
- 能刻画**动态调整**（滞后效应、惯性与路径依赖）。
- 提供「个体自身对照」，比横截面更接近因果。

**局限**：

- 只能消除**不随时间变化**的混淆；随时间变化的遗漏变量（如技术冲击）依旧有偏。
- **测量误差**在差分后可能被放大（信噪比恶化）。
- 非平衡面板、缺失与样本损耗（attrition）会引入选择性偏误。
- 短面板（$T$ 小、$n$ 大）与长面板（$T$ 大）的渐近理论不同，需区分对待。<span class="marginnote">「只能消不随时间变的混淆」是面板方法的天花板：如果某项技能在实验期内也在涨，FD 消不掉它。这正是后文工具变量存在的意义——面板 + IV 才能同时对付两类内生性。</span>

**补充**：面板建模还可把滞后因变量放进解释变量（动态面板），这会引入「$y_{i,t-1}$ 与 $a_i$ 相关」的新内生性，需要差分 + 滞后工具（Arellano–Bond），这一话题在《GMM 广义矩估计》里正式展开。**核心要点**：面板方法的力量与边界同在——它把「个体自身的变化」当作对照，是观察数据里最接近因果的设计之一；但「随时间变化的混淆」仍在防线之外。

### 常见误区速览

**Q：面板数据能不能直接当横截面合并回归？** 不能。只要个体效应 $a_i$ 与解释变量相关，混合 OLS 就有偏。必须先做 FD/FE 消掉 $a_i$。

**Q：一阶差分会损失什么信息？** 只利用相邻期的变化，损失了水平信息；且相邻差分会引入 $\Delta u_{it}$ 的自相关。$T = 2$ 时 FD 与 FE 给出相同估计。

**Q：面板必须平衡吗？** 不必，但非平衡面板要小心。个体进入/流失若与结果相关，会引入选择性偏误——对应医学里的「失访偏倚」。处理方式包括检验退出机制、或用更稳健的加权估计。

### 与「从极限到大模型」主线的连接

面板数据的「用个体自身的历史做对照」，与机器学习里的「序列模型用过去预测现在」「差分/去均值做预处理」是同一套思想。你在做时间序列特征时常用的「lag 特征」「变化率特征」，就是 FD 的数据处理版本；「每家企业减去自身均值」的组内变换，与深度学习里的「实例归一化（InstanceNorm）」异曲同工。

而「面板能消除不随时间变的混淆」这一边界，也恰是因果机器学习里「固定效应网络」「时序差分模型」想要推广的对象。理解「为什么重复观测同一个体就能抵消个体差异」，等于理解现代数据科学里「对照设计」与「差分法」的根基——它是从描述相关到逼近因果最重要的一步。

## 6 小结

- **面板数据** = 同一批个体的多期观测，同时拥有个体维度与时间维度。
- 不可观测效应 $a_i$ 是遗漏变量偏误的根源；**与 $x$ 相关时，混合 OLS 有偏**。
- **一阶差分（FD）** 通过「两期相减」物理性消除 $a_i$，用「同一批人的变化」识别效应。
- FD 的本质：**个体的固定特征在两次观测中自我抵消**；代价是只利用变化信息。
- 面板能控「不随时间变的混淆」，但控不了「随时间变的混淆」——后者留给工具变量。
