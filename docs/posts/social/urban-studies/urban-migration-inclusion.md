# 城市移民与包容

## 为什么从城市移民与包容开始

城市化在人口层面的实质，就是**移民进城**——
人是城市化的第一燃料。
但「进城」只是开始，
「被城市接纳」才是更难的部分：移民能否找到稳定工作、落户、享有同等的教育医疗、不被歧视与排斥？
这些问题在中国有一个浓缩的焦点——
**户籍制度**，也有一个全球性的概念——
**包容性城市（inclusive city）**。
理解城市移民，
既要懂人口迁移的「推拉」机理，
也要懂融入过程的三个层次，
还要看到：一座城市对待外来者的态度，
最终决定了它是增长引擎还是排斥机器。

## 1 迁移的推拉理论：人为什么进城

人口迁移的经典解释是 **推拉理论（push-pull theory）**，
可追溯到英国统计学家**拉文斯坦（E. G. Ravenstein）** 1885 年提出的「迁移定律」，
后经李（Everett Lee）1966 年系统化：

**人口迁移 = 迁出地的推力 + 迁入地的拉力 − 两地之间的阻力。**

- **推力**：农业收入低、劳动力过剩、自然灾害、土地不足、公共服务薄弱。
- **拉力**：就业机会多、工资高、教育医疗资源集中、生活方式多元。
- **阻力**：迁移成本、信息不对称、户籍等制度壁垒、文化距离。

**公式解析：迁移的净收益**
$$M_i \sim \frac{P_j - C_{ij}}{R_{ij}}$$

其中 $M_i$ 为从地 $i$ 迁往地 $j$ 的迁移量，$P_j$ 为迁入地的吸引力（机会、收入、服务），$C_{ij}$ 为在原地的损失（机会成本），$R_{ij}$ 为两地阻力。
直觉很直接：**拉力越大、推力越强、阻力越小，迁移越剧烈。**

**辨析｜易错点：** 推拉理论是「个体理性选择」视角，它解释不了所有迁移。
一个重要反例是 **随迁迁移**：农民工进城的决定常是家庭策略（夫妻分工、子女留守），
而不是个人利益最大化。
另一个反例是 **结构性约束**：户籍制度下，进城与「落户」是两回事——
推力拉力只能解释「流动」，不能解释「融入」。
<span class="marginnote">拉文斯坦还总结过一条有趣的规律：迁移以「短距离为主」、呈「阶梯式」递进（乡村→集镇→小城→大城），
女性短途迁移多于男性。
这套 1885 年的「定律」在今天仍大体成立——
中国农民工的「离土不离乡」与「就近城镇化」正是阶梯式迁移的现代表现。
</span>

## 2 中国的城市移民与户籍制度

中国城市移民的最大特色，是**户籍制度（hukou）** 塑造的「半城市化」：

- **农民工规模**：全国农民工总量约 3 亿，其中外出农民工约 1.7 亿——他们常年在城市工作，却未必拥有城市户籍。
- **户籍含金量**：户籍捆绑着教育（学区）、医疗、住房（保障房申请资格）、社保等一揽子公共服务，没有户籍，就是「身在城市、权利在城外」。
- **常住人口城镇化 vs 户籍人口城镇化**：2023 年，中国常住人口城镇化率约 66%，户籍人口城镇化率仅约 48%——两者之间约 18 个百分点的差，就是「进了城但没落户」的群体，规模以亿计。

**重点：户籍制度制造的不是「移民问题」，而是「权利问题」。**
移民不是城市里最穷的人，而是城市里**权利最不完全的人**——
他们贡献了城市的生产与税收，却常在教育、住房、社保上被差别对待。
这正是「半城市化」概念的要害：**人已在城，权利未进城。**
<span class="marginnote">近年来各地推行「落户新政」与居住证制度，
中小城市基本放开落户、大城市逐步放宽，
「租购同权」也被写入政策讨论——
户籍改革的方向是让「居住」而非「出身」决定权利，但公共服务的财政压力让全面同权步履维艰。
</span>

## 3 融入的三层：经济、社会、文化

移民融入（integration）不是一蹴而就，而是分层次的渐进过程。
社会学通常区分三个层面：

**第一层，经济融入。**
找到稳定工作、收入达到一定水平——
这是最基础、最容易实现的一层。
中国的农民工在经济融入上表现突出（他们撑起了制造业与服务业），
但职业分层明显，
多集中于低收入岗位。

**第二层，社会融入。**
建立起跨群体的社交网络、参与社区生活、获得与本地人相当的公共服务。
这比经济融入难——
语言、习俗、居住隔离都会成为障碍。
许多移民的社交圈局限于同乡（「老乡圈」），社会融入停滞。

**第三层，文化认同。**
认同自己是这座城市的一员、被本地人接纳为「自己人」。
这是最难的一层，往往要跨代完成——
**第二代移民（在城市长大的孩子）通常比父辈融入更深，却也因此承受更强烈的身份撕裂感。**
<span class="marginnote">「第二代移民」是全球城市研究的焦点：他们是「心理上的城里人、身份上的外来者」，
其认同困境在纽约（拉美裔二代）、巴黎（北非裔二代）与中国（流动儿童）同样尖锐。
流动儿童的教育与心理支持，因此是包容政策的高杠杆点。
</span>

**辨析｜易错点：** 融入 ≠ 同化（assimilation）。
融入是双向的——
城市也因移民改变（饮食、语言、街景），而移民也保留自身的文化特色。
「沙拉碗」与「大熔炉」是两种不同的理想：同化是「熔炉」（所有人变一个样），
多元文化主义是「沙拉碗」（各成分共存、共享一个容器）。
中国语境下的「包容」，更多指向「服务均等 + 身份尊重」，而非文化同化。

## 4 包容性城市：从口号到指标

**包容性城市（inclusive city）** 是 21 世纪城市治理的核心口号，
联合国《新城市议程》（2016）将其列为目标。
它的内涵可拆为四个维度：

| 维度 | 内容 | 典型指标 |
| --- | --- | --- |
| 空间包容 | 外来者享有平等居住权，不被隔离 | 居住分异指数、保障房覆盖面 |
| 经济包容 | 平等就业、职业上升通道 | 外来人口失业率、职业分层度 |
| 服务包容 | 教育、医疗、社保向所有人开放 | 随迁子女入学率、医保参保率 |
| 制度包容 | 户籍/身份不决定权利 | 落户门槛、居住证含金量 |

**重点：包容不是慈善，而是增长的必要条件。**
城市研究的实证反复证明：**排斥外来者的城市，最终也会失去人才、活力与竞争力。**
硅谷的开放移民政策、深圳的「来了就是深圳人」口号，都是「包容即竞争力」的注脚；
反之，对移民的制度性排斥会催生贫民窟化、黑市与不稳定。
<span class="marginnote">「包容性增长」（inclusive growth）是发展经济学与中国「共同富裕」讨论的公共词汇：增长若只惠及本地户籍者，
就是「排斥性增长」——
它会在城市内部制造出《城中村与贫民窟》一篇要讲的「空间化的不平等」。
</span>

## 5 小结

- **推拉理论**解释迁移的动能：拉力、推力、阻力的净效应决定迁移量，但它是「个体选择」视角，解释不了结构性约束。
- 中国的特色是**户籍制度下的半城市化**：常住城镇化率与户籍城镇化率之间约 18 个百分点的差，是权利未进城的亿级群体。
- 融入分三层：**经济 → 社会 → 文化**，逐层变难，第二代移民是认同困境的焦点。
- **融入 ≠ 同化**：多元共存（沙拉碗）与熔炉是不同理想，包容更接近前者。
- **包容性城市**有空间、经济、服务、制度四个维度，且「包容即竞争力」——排斥外来者最终惩罚的是城市自身。

在下一节，我们转向城市对自身过去的处理：老城如何更新？
大规模推倒重建为何被批评？
绅士化是什么——
这就是**城市更新**。
