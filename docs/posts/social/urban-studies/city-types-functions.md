## 为什么从城市类型与功能开始

上一篇确认了城市「如何诞生」，这一篇回答两个更实用的问题：**城市分几种？
城市有什么用？**
类型学（typology）是城市研究的「分类学」——
没有它，就无法比较开封与匹兹堡、威尼斯与硅谷，更无法设计针对性的政策。
功能分析则触及城市存在的根本理由：**城市之所以是城市，是因为它能做村庄做不了的事——
集聚、分工、交换、创新。**
理解类型与功能，是后面读城市化、城市空间结构与城市治理的公共底座。

## 1 按规模分类：一条最直观的尺子

规模是城市最醒目、也最容易测度的属性。
中国的通行口径按**城区常住人口**划分：

| 类型 | 城区常住人口 | 典型示例 |
| --- | --- | --- |
| 小城市 | 50 万以下 | 县级市、多数县城 |
| 中等城市 | 50–100 万 | 部分地级市 |
| 大城市 | 100–500 万 | 省会、区域中心城市 |
| 特大城市 | 500–1000 万 | 武汉、成都、南京 |
| 超大城市 | 1000 万以上 | 北京、上海、深圳、重庆 |

规模不只是数字，它改变城市的**性质**。
人口达到几百万后，地铁成为刚需、商品住宅高度分层、通勤圈突破行政边界——
这些都不是「小城市放大版」，而是**量变引起质变**。
<span class="marginnote">「规模即逻辑」是城市研究的一条隐性主线：城市经济学里叫「集聚经济」，
社会学里叫「社会密度效应」，
规划学里叫「城市尺度」。
同样的规律在《都市圈与城市群》一篇会再次出现。
</span>这也解释了为什么超大城市普遍面临交通、住房、环境问题——
那是规模红利的另一面。

**辨析｜易错点：** 「人口规模」和「建成区面积」不是一回事。
**常住人口**指居住半年以上的人，**城区人口**还要剔除郊区县；
流动人口（如农民工）常被算进常住却不被算进户籍人口。
同一座城市，用不同口径能差出好几百万，读政府公报时必须先看口径。

## 2 按职能分类：城市靠什么养活自己

比规模更深刻的是**职能（function）**——
这座城市在区域分工中扮演什么角色。
城市职能研究者把职能分为两大类：**基本职能（basic）** 与 **非基本职能（non-basic）**。
<span class="marginnote">「基本/非基本」也叫「对外/对内」职能，
概念出自经济基础理论（economic base theory）。
基本部门向外地输出产品与服务、赚回外部收入；
非基本部门服务本市居民。
城市的兴衰，取决于基本部门是否强劲——
底特律衰落是因为它的基本部门（汽车制造）衰落了。
</span>

按主导职能，城市可粗略分为：

- **政治城市**：首都、省会，靠行政权力聚集资源，如华盛顿、北京、巴西利亚。
- **工业城市**：以制造业为支柱，如曼彻斯特、底特律、东莞。
- **港口与贸易城市**：靠区位与物流起家，如香港、新加坡、鹿特丹。
- **文化教育城市**：以大学、博物馆、旅游为名片，如牛津、海德堡、丽江。
- **金融中心城市**：以资本配置为核心，如纽约、伦敦、法兰克福。
- **交通枢纽城市**：因铁路、机场、高速公路而兴，如郑州（铁路）、亚特兰大（空港）。

**重点：职能决定城市的结构与命运。**
工业城市围绕厂房与工人宿舍组织空间，
金融城市围绕写字楼与信息网络组织空间，
政治城市围绕机关与纪念性建筑组织空间。
职能转型（deindustrialization，
去工业化）是二十世纪西方城市最剧烈的变故——
底特律从 1950 年人口 185 万降到如今不足 70 万，就是职能塌陷的标本。

## 3 城市的功能：为什么城市值得存在

如果只看类型，会以为城市只是「各种东西的堆叠」。
功能分析回答更深的问题：**集聚究竟带来了什么？**
经济学家与社会学家给出三条互补的回答：

**第一，
集聚经济（agglomeration economy）**：企业扎堆能共享劳动力池、供应商与知识溢出，
人扎堆能降低寻找工作与伴侣的「搜索成本」。
同一个行业内，公司密度的提高会显著提升平均生产率——
这就是为什么同样的人在上海比在小县城「更值钱」。

**第二，分工与比较优势**：亚当 · 斯密在《国富论》里用制针厂的例子说明分工提高生产率；
城市是把社会分工**空间化**的装置——
专业化的诊所、律所、会计所，只有在大人口基数上才能被养活。
村庄里一个医生看所有病，城市里有心内科与骨科的分野。

**第三，
知识交换与创新**：城市学家雅各布斯（Jane Jacobs）把城市比作「新工作的孵化器」（incubator）——
不同行业的人在咖啡馆、街区、市场里偶然相遇，产生跨界碰撞。
近年「创新城市」研究进一步证明：**创意人才集聚 + 包容开放的文化 + 密集的面对面交流**，
是现代城市创新区的标准配方（硅谷、波士顿 128 号公路、深圳南山区皆属此类）。
<span class="marginnote">这个「面对面交流催生创新」的论断，
在本博客「大模型」主线里有个镜像：模型靠的是海量参数与算力的「集聚」，
城市靠的是海量人口与空间的「集聚」——
两者共享同一句格言：密度本身就是信息。
</span>

## 4 功能与形态：城市是功能的投影

功能不会漂浮在真空里，它一定会「长」出对应的物质形态：

- 政治城市 → 轴线对称的宫殿/政府区，宽阔的纪念大道（北京中轴线、华盛顿国家广场）。
- 商业城市 → 市场、码头、金融街，地价驱动的高层写字楼群（曼哈顿下城）。
- 工业城市 → 沿铁路与河道的厂房带、工人居住区（曼彻斯特的「棉都」格局）。

这种「功能决定形态」的思路，
是下一节《城市空间结构》三种经典模型的伏笔：**伯吉斯的同心圆、霍伊特的扇形、哈里斯与乌尔曼的多核心，
本质上都在描绘不同功能如何争夺城市空间、又如何各安其位。**
读城市类型与功能，等于先拿到了那三张模型图的「图例」。

**辨析｜易错点：** 一座城市通常**同时拥有多种职能**，分类只是「主导职能」的简化。
上海既是金融中心又是港口又是工业基地，北京既是政治中心又是文化中心——
用单一标签概括大都市必然失真。
真正的分类学应问：**这座城市的「基本职能」有哪些、各占多大份额？**
这需要就业结构的量化数据，而不是贴标签。

## 5 小结

- 城市按规模分为**小、中、大、特大、超大**五档，规模会引发城市性质的变化（量变→质变）。
- 城市按职能分为**政治、工业、港口、文化、金融、枢纽**等类型，**基本职能**决定城市兴衰。
- 城市存在的根本理由：**集聚经济、社会分工、知识交换**三大功能。
- 功能会投射为形态：**政治→轴线、商业→CBD、工业→厂房带**，为空间结构模型埋下伏笔。
- 分类是「主导职能」的简化，真实城市是多重职能的复合体，须用就业结构数据说话。

在下一节，我们转向动态过程：城市从诞生到今天经历了怎样的扩张曲线？
世界与中国的城市化进程有何异同——
这就是**城市化进程**。
