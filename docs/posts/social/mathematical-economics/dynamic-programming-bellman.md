## 为什么从动态规划开始

上一课的最优控制是连续时间的动态优化；但当经济以「期」为单位（每季度决策一次、每次决策影响下一期），更自然的工具是**动态规划（dynamic programming）**。动态规划把「一次选完整个未来」换成「每次只选当前，同时盯着未来」——这种**递归**思维，正是贝尔曼方程的心脏。

从「从极限到大模型」的课程线看，动态规划不仅是宏观经济学（最优增长、资产定价、异质代理人模型）的标配，还直接通向现代机器学习的**强化学习**：Q-learning、Deep Q-Network 背后的贝尔曼方程，与经济学家用的完全是同一个数学对象。<span class="marginnote">贝尔曼（Richard Bellman）1950 年代在兰德公司研究多阶段决策过程时发明了这套方法。据说「dynamic programming」是他为规避军方老板对「research」的敏感而起的低调名字——结果这个低调的名字成了半个世纪的学科基石。</span>

本文按「原理 → 方程 → 解析解 → 数值解」推进：先用最优性原理立住递归的合法性，再写贝尔曼方程并拆解其结构，用吃蛋糕问题演示逆向归纳、用消费-储蓄问题导出欧拉方程，最后落到值函数迭代与强化学习。

## 1 最优性原理：递归思维的起点

设经济从状态 $x_t$ 出发，行为人在每期选择控制 $u_t$，获得即时效用 $f(x_t, u_t)$，状态按 $x_{t+1} = g(x_t, u_t)$ 演化，未来效用按贴现因子 $\beta \in (0,1)$ 折现。定义**价值函数（value function）**：

$$V_t(x_t) = \max_{\{u_s\}_{s \ge t}} \sum_{s=t}^{\infty} \beta^{s-t} f(x_s, u_s)$$

它是「从状态 $x_t$ 出发能获得的最大贴现效用总和」。

**贝尔曼最优性原理**说：从 $(t, x_t)$ 出发的最优策略，其从 $(t+1, x_{t+1})$ 出发的后续部分，也必然是从 $(t+1, x_{t+1})$ 出发的最优策略。<span class="marginnote">这条原理的证明是反证法：若后半段还能改进，就把前半段接上改进的后半段，整条路径的效用更高——与原路径最优矛盾。它听起来像废话，却排除了「跨期后悔」：最优决策在每一步都经得起「重新审视」。</span>

**动态规划与贪心算法（greedy）的根本差别**：贪心每期只最大化当期收益 $f(x_t, u_t)$，不管未来；动态规划最大化「当期 + 未来最优」，通过价值函数把未来纳入今天的账本。经济学的「理性预期」正是这一点的深化——今天的决策内生了明天的最优决策。

## 2 贝尔曼方程：递归的数学形式

最优性原理立刻导出**贝尔曼方程（Bellman equation）**：

$$V(x) = \max_{u} \Big\{ f(x, u) + \beta\, V\big(g(x, u)\big) \Big\}$$

把它拆成三块读：

- **当期收益 $f(x, u)$**：今天这一期实打实拿到的效用。
- **续值 $\beta V(g(x,u))$**：明天从新状态出发的最优价值，贴现到今天。
- **$\max_u$**：在「今天」这个节点上，选择使两者之和最大的控制。

**$V$ 同时出现在方程两边——贝尔曼方程是一个关于价值函数的函数方程，而不是普通的代数方程。** 它的解 $V^*$ 是某个函数空间里的「不动点」，通常需要迭代逼近。<span class="marginnote">可以把贝尔曼方程看作「站在时间轴上回看」的记账：今天的价值 = 今天的收益 + 贴现的明天价值。这正是拉姆齐模型的离散版灵魂，也是资产定价里「无套利 + 递归」定价核的雏形。</span>

### 第一次实战：吃蛋糕问题的逆向归纳

用最干净的例子感受递归：一块蛋糕大小 $W$，效用 $\ln c$，贴现 $\beta = 1$，共 $T$ 期吃完。贝尔曼方程 $V_t(W) = \max_c\{\ln c + V_{t+1}(W - c)\}$，终端条件 $V_T(W) = \ln W$（最后一期全吃掉）。

剩 1 期：$V_1(W) = \ln W$。
剩 2 期：$V_2(W) = \max_c\{\ln c + \ln(W-c)\}$，一阶条件 $\tfrac{1}{c} = \tfrac{1}{W-c}$，得 $c = \tfrac{W}{2}$，$V_2 = 2\ln\tfrac{W}{2}$。
剩 3 期：$V_3(W) = \max_c\{\ln c + 2\ln\tfrac{W-c}{2}\}$，一阶条件 $\tfrac{1}{c} = \tfrac{2}{W-c}$，得 $c = \tfrac{W}{3}$。

**模式跃然纸上：剩 $T$ 期就每期吃 $\tfrac{W}{T}$——把蛋糕均分。** 动态规划不是「走一步看一步」，而是**从最后一步往前倒推**（backward induction），每一期都带着「最优未来」的信息做今天的决定。<span class="marginnote">逆向归纳是动态规划的灵魂算法，也是博弈论里求解子博弈精炼纳什均衡的方法（第五级《博弈论》）。它把「未来」折叠进「今天」的价值函数，正是最优性原理的算法化。</span>

## 3 公式解析：无限期消费-储蓄问题的欧拉方程

用最经典的无限期消费-储蓄问题验证工具。行为人在每期消费 $c$，把剩余产出留作资本，状态演化 $k' = f(k) - c$，问题为

$$V(k) = \max_{c} \Big\{ u(c) + \beta V\big(f(k) - c\big) \Big\}$$

四步拆解：

- **第一步，一阶条件**：对 $c$ 求导，$u'(c) - \beta V'(k') = 0$，即

$$u'(c) = \beta\, V'(k')$$

今天最后一单位消费的边际效用，必须等于把它变成资本后明天价值的贴现。**边际效用跨期相等，是最优储蓄的「不可套利」条件。**
- **第二步，包络条件**：把价值函数对 $k$ 求导（第 6 篇包络定理的动态版），得 $V'(k) = \beta V'(k') f'(k)$。
- **第三步，时间平移**：把一阶条件平移一期得 $u'(c') = \beta V'(k'')$，用它替换第二步里的 $V'(k')$。
- **第四步，联立得欧拉方程**：

$$u'(c) = \beta\, u'(c')\, f'(k')$$

**欧拉方程说：今天的边际效用等于明天边际效用乘上边际产出再乘贴现。** 当 $f'(k)$ 高时，多储蓄（少消费）划算，消费被压到今天之后。<span class="marginnote">对比第 9 篇连续时间的欧拉方程 $\dot{c}/c = (f'(k)-\rho)/\sigma$：离散版用 $u'(c) = \beta u'(c')f'(k')$ 表达同一件事。取对数近似后，$\beta = e^{-\rho}$ 与 $f'(k) = 1+r$ 代入，两式无缝对接——连续与离散，一套经济学。</span>

**辨析｜易错点：** 一阶条件 $u'(c) = \beta V'(k')$ 里出现的是 $V'$，不是 $u'$。$V$ 是「明天一切的最优值」，它的导数来自包络条件——初学者常把 $V'$ 误写成 $u'(c')$ 直接代入，跳过包络步骤，得到的欧拉方程就错了。**必须先走「FOC + 包络 + 平移 + 联立」的完整链条。**

## 4 数值求解：值函数迭代与强化学习

先看清最优控制与动态规划的互补关系：

| 项目 | 最优控制（第 9 篇） | 动态规划 |
| --- | --- | --- |
| 时间 | 连续 | 离散 |
| 核心对象 | 汉密尔顿函数 $H$ | 价值函数 $V$ |
| 一阶条件 | 庞特里亚金三条件 | 贝尔曼方程 + 包络 |
| 边界 | 横截性条件 | 终端条件/压缩映射 |
| 现代后裔 | 变分法 | 强化学习 |

无限期问题的贝尔曼方程没有闭式解（对数效用等特例除外），但可以**迭代求解**。定义贝尔曼算子

$$(TV)(x) = \max_u \Big\{ f(x, u) + \beta\, V(g(x, u)) \Big\}$$

**值函数迭代（value function iteration）**：从任意初始猜测 $V_0$（例如 $V_0 \equiv 0$）出发，反复作用 $T$，序列 $V_{n+1} = TV_n$ 单调收敛到 $V^*$。<span class="marginnote">收敛性的保证来自 $T$ 是一个<strong>压缩映射（contraction）</strong>：贴现因子 $\beta \lt  1$ 让「未来的未来」逐期衰减，两个不同初值被 $T$ 反复作用后彼此靠近。压缩映射原理（巴拿赫不动点定理）在第二级《泛函分析》里是抽象定理，在这里是「迭代一定收敛」的实证保障。</span>

计算上，把状态离散成网格，每轮迭代对每个格点解一次最大化，通常几十轮就能收敛。这个流程的现代化身就是**强化学习**：把「价值函数」换成「动作价值 $Q(s,a)$」，迭代规则变成 Q-learning 更新 $Q(s,a) \leftarrow Q(s,a) + \alpha\big[r + \beta \max_{a'} Q(s', a') - Q(s,a)\big]$——**经济学家与机器学习工程师解的是同一个贝尔曼方程**。<span class="marginnote">顺带一提，第 12 篇的期望效用理论正是这套递归框架的随机版：当状态转移带不确定性，价值函数里的 $V(g(x,u))$ 变成期望 $E[V(x')]$，贝尔曼方程就长出了「期望」的翅膀——那就是理性预期与资产定价的起点。</span>

值函数迭代还有两个实用变体。**策略迭代（policy iteration）**交替做「估值」（给定策略求价值）与「改进」（给定价值求最优策略），在格点问题上通常比纯值函数迭代快一个量级；**拟牛顿加速的 Howard 策略迭代**则是现代求解器的默认引擎。宏观经济学里求解异质代理人模型的现代算法，几乎都是这两者的改良。

**数值示意**：在 Python 里做值函数迭代，只需把状态离散成几百个格点，反复执行「对每个格点解一次最大化」。对数效用的消费-储蓄问题通常几十轮内收敛到机器精度（$\|V_{n+1}-V_n\|_\infty < 10^{-10}$）。迭代快慢由贴现因子 $\beta$ 决定——$\beta$ 越接近 1，压缩比越小、收敛越慢，因为「未来」的价值需要更多轮才能被逐期摊平。**收敛速度本身就是时间偏好的函数**，这条联系在理性预期的数值文献里反复被利用。

## 5 小结

- 动态规划用递归处理离散时间的多期最优：每期选控制，状态按方程演化。
- 动态规划与贪心算法的差别：贪心只看当期，动态规划把未来价值折进今天的决策。
- 贝尔曼方程 $V(x) = \max_u\{f + \beta V(x')\}$ 是价值函数的函数方程，解为不动点。
- 最优性原理：最优策略的任意后继子策略仍然最优，是递归的合法性来源。
- 消费-储蓄问题经 FOC + 包络 + 平移 + 联立导出欧拉方程 $u'(c) = \beta u'(c')f'(k')$。
- 值函数迭代利用压缩映射收敛；Q-learning 是它的随机化与推广。
- 吃蛋糕问题示范逆向归纳：剩 $T$ 期每期吃 $W/T$，未来被折进今天的价值函数。
- 策略迭代是值函数迭代的加速变体，是现代宏观求解器的默认引擎。
- **易错**：$V'$ 来自包络条件而非直接代入；贝尔曼方程两边都有 $V$，解是函数空间里的不动点而非普通代数解。

在下一节，我们把单个行为人的动态优化放大到整个经济——用一般均衡的数学表述回答「是否存在一组价格让所有市场同时出清」。而第 12 篇的期望效用理论，则给动态规划的随机版装上「期望」的翅膀。
