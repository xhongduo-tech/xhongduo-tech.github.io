## 为什么从新公共管理开始

第一篇讲管理途径时说过，它的现代传人叫新公共管理（New Public Management, NPM）。1980 年代起，一场以「市场化」为旗帜的行政改革横扫全球：英国、新西兰、美国、澳大利亚率先试点，随后扩展到整个西欧、拉美与亚洲。NPM 的野心极大——**它试图用企业的语言重写政府**：把公民变成顾客，把拨款变成合同，把垄断变成竞争，把过程问责变成结果问责。它成功了，也失败了；它的遗产（绩效管理、服务外包、客户导向）至今嵌在全世界政府的骨骼里。读懂 NPM，才能读懂当代公共行政的方言。

## 1 NPM 的兴起：政府为什么会失灵

NPM 不是学术空想，而是一连串现实压力的产物：

- **财政危机**：1970 年代的石油危机与福利国家的扩张，让各国政府背上巨额赤字，被迫「省钱」。
- **官僚病**：传统科层制被指责迟钝、僵化、预算最大化（第十一篇会讲尼斯坎南的模型）、只对过程负责不对结果负责。
- **新右派的政治浪潮**：撒切尔（英国）、里根（美国）把「小政府、大市场」变成执政纲领，公共部门成为被审视的对象。

改革的实验场一个接一个：**新西兰**被誉为「最彻底的改革样本」——按公司化逻辑拆分部门、经理与政治领导人签订绩效合同；**英国**1988 年的「下一步行动」（Next Steps）把政策制定与执行分离，成立半自主的「执行局」（agencies）；**美国**1993 年戈尔主持的「国家绩效评估」（NPR）喊出「让政府花更少的钱办更好的事」。

## 2 NPM 的七条信条

伦敦政治经济学院的胡德（Christopher Hood, 1991）把分散的改革实践归纳成 **NPM 的七条信条**，成为后来所有讨论的坐标：

1. **直面管理**：专业化的积极管理——管理者要「管」，而不是「坐等指示」；
2. **明确标准**：设定可测量的绩效目标；
3. **强调产出**：按结果（output）而非按投入（input）来考核与拨款；
4. **机构拆分**：把大一统部门拆成相互独立的执行单位；
5. **引入竞争**：打破公共垄断，让私人部门参与竞标；
6. **私营部门风格**：弹性用工、客户服务、削减层级；
7. **纪律与节俭**：控制资源使用，向「花小钱办大事」看齐。

<span class="marginnote">对照第一篇的三大途径，胡德的七条几乎全部是「管理途径」的当代化：第 2、3 条是效率的测量化，第 4 条是组织设计的拆分，第 5 条是把市场引入行政。NPM 本质上是管理途径在 1980 年代的一次全面反击——政治途径与法律途径则沦为它的批评者。</span>

**核心要点：NPM 与传统行政的对照**

| 维度 | 传统公共行政 | 新公共管理 |
| --- | --- | --- |
| 对人的称呼 | 公民 / 当事人 | 顾客（customer） |
| 责任重心 | 对程序负责 | 对结果负责 |
| 资源分配 | 拨款制、预算切块 | 绩效合同、购买服务 |
| 服务提供 | 政府垄断 | 竞争、外包、公私合作 |
| 管理者角色 | 执行规则 | 掌舵、签约、绩效经理 |

## 3 市场化工具：NPM 的实操箱

NPM 的改革者不满足于口号，他们造了一整套工具箱：

**私有化（privatization）**：出售国有企业或将其上市，让市场直接接管。英国的电信、航空、水务私有化是标志性案例。
- **合同外包（contracting out）**：政府保留出资与监管，把具体服务交给私人或非营利组织生产——垃圾清运、监狱管理、甚至军事后勤。外包的核心是把「生产」与「供给」分离：政府仍是供给者，但不再是生产者。
- **凭证制（vouchers）**：把补贴直接发给使用者（如教育券、住房券），让「顾客」自己选择提供者，倒逼服务提供者竞争。
- **绩效预算与绩效工资**：预算按成果兑现、薪酬与绩效挂钩（见第五篇与第四篇的讨论）。
- **服务宪章与顾客标准**：政府公布服务标准（如「来信三天内回复」），把承诺变成可申诉的权利——英国的《公民宪章》开了先河。

**这些工具的共性：政府从「划桨者」变成「掌舵者」。** 奥斯本与盖布勒那句「掌舵而非划桨」是 NPM 的最佳概括——政府应当决定「往哪开」（政策、监管、出资），而把「怎么划」（生产、执行、操作）交给更灵活的机构。

## 4 成功、失败与反思

NPM 交出的成绩单喜忧参半。

**成功的部分**：绩效导向让许多公共服务变得更透明、更可衡量；外包在部分领域显著降低成本（垃圾清运、后勤服务）；顾客导向改善了政府与公众打交道的方式（一窗办理、服务热线）；行政成本的削减帮助多国走出财政困境。

**失败与代价**：批评者尤其辛辣——

- **空心国家（hollow state）**：米尔沃德（Milward）指出，当政府把大量服务外包后，政府「空心化」了——它不再拥有执行能力，只剩下一纸合同。合同方违约时，政府连补救的手段都没有。
- **问责缺口**：私人承包商不承担政府那样的公开与正当程序义务，公民的权利保障随外包而稀释——这在法律途径（第八篇）看来是严重倒退。
- **指标博弈**：绩效指标被「刷分」。医院为达标延长挂号时间、警察为结案率选择性立案——「照指标办事」取代「照使命办事」，绩效主义自我背叛（呼应第四篇绩效评估的困境）。
- **交易成本**：签订、监督、重谈外包合同的管理成本常常吞噬「市场化省下的钱」。
- **价值观流失**：把公民当顾客，可能把「权利」降格为「消费」——公共行政的政治与法律维度被压缩，回应性与正当程序被效率吞掉。

<span class="marginnote">「空心国家」概念还有一层更深的含义：政府外包的不只是服务，还有责任。当私人承包商出了问题（如监狱虐囚），公众要政府负责，政府却只能「问责合同」。责任的链条一旦断在合同里，问责就成了空转——这是第十篇《行政伦理与问责》的直接入口。</span>

**后 NPM（post-NPM）**：进入 21 世纪，改革者开始收拾 NPM 的残局。新一轮改革强调「**整体政府**」（joined-up government）与「**数字化治理**」（digital-era governance, Dunleavy 等），用信息共享与跨部门协同修复 NPM 拆分造成的碎片化——我们将在第九篇《电子政务》里看到数字化如何接过改革的接力棒。

## 5 NPM 的适用边界：改革不是万能药

NPM 的全球传播留下一个教训：**改革的有效性高度依赖情境**。

- **任务类型**：标准化、可测量、可外包的任务（清运、文书）适合市场化；涉及公权力强制、个人权利或高不确定性的事务（治安、司法、危机应对）外包风险极高。
- **制度土壤**：合同文化成熟、司法可信、资本市场完善的国家，外包才能跑通；在这些条件缺失的地方，NPM 常常只是换了个名字的腐败温床。
- **政府能力**：讽刺的是，「掌舵」比「划桨」更难——监管、签约、绩效评估都需要更强的政府能力，而不是更弱的。

**辨析｜易错点：** NPM 不等于「私有化」。私有化只是工具之一，合同外包、凭证制、绩效管理都是 NPM 的组成部分；而且 NPM 从未主张「政府撤出」，而是主张「政府换姿势」——从生产者变成掌舵者。把 NPM 简化成「砍政府」既误读了理念，也忽略了它留下的绩效管理遗产。

## 6 小结

- NPM 是管理途径在 1980 年代财政危机与新右派浪潮中的全面复兴，核心口号是**「掌舵而非划桨」**。
- 胡德归纳的**七条信条**（直面管理、明确标准、强调产出、机构拆分、引入竞争、私企风格、纪律节俭）是 NPM 的理论坐标。
- 市场化工具箱包括**私有化、外包、凭证制、绩效预算、服务宪章**；其共同逻辑是「供给与生产分离」。
- NPM 的教训包括**空心国家、问责缺口、指标博弈、交易成本**与价值观流失，催生了「整体政府」与「数字化治理」的后 NPM 转向。
- NPM 的适用性取决于任务类型与制度土壤——**市场化不是万能药**。

在下一节，我们将站到 NPM 的对立面去看行政的「刹车系统」：当效率冲撞权利时，法律如何兜底？公共利益如何被程序保护？——这就是**行政法与公共利益**。
