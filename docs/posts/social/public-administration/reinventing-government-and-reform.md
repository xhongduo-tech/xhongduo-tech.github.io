## 为什么从行政改革史开始

这是本专题的收官篇，也是把前面所有线索拧成一股的地方。公共行政这门学科诞生于一场改革（1883 年彭德尔顿法案），此后一百多年里，改革成为它的**常态而非例外**：功绩制、市政改革、罗斯福新政、胡佛委员会、文官改革法、绩效法案、重塑政府、数字政府——一波接一波，永不停歇。更耐人寻味的是：**改革总在成功与失望之间循环**，有些问题被反复「改革」却反复复发。这一篇既是行政改革的历史课，也是一面镜子：透过改革，我们看到制度如何僵化、又如何被唤醒——以及为什么「重塑政府」比「推翻政府」难得多，也重要得多。

## 1 改革的类型与永恒循环

行政改革可以按对象分为三类：

- **结构性改革**：动组织架构——机构合并拆分、权力上收下放、成立或撤销独立机构。
- **过程性改革**：动运作规则——预算方法、人事制度、采购流程、绩效管理。
- **文化性改革**：动价值与行为——顾客导向、廉洁文化、结果文化。

三个层次的改革难度依次递增，效果也依次递减：**改组机构最快，改变规则稍难，改变人的行为与价值观最难。** 这也是为什么很多改革「雷声大、雨点小」——它们只在结构层动刀，而病根在文化层。

改革还有一个耐人寻味的规律：**钟摆式循环。** 当科层制走向僵化，改革就推分权、市场、灵活；当分权造成碎片化与问责缺口，改革又推整合、集权、绩效。第七篇 NPM 的「拆分」与后 NPM 的「整体政府」就是最近一轮钟摆。<span class="marginnote">把钟摆规律与第五篇的渐进主义、第十一篇的制度分析对照：预算与制度都天生护着存量，所以改革往往只能从边缘切入；而每一代改革者都认为自己找到了「最终答案」，下一代却要收拾上一代的副作用。改革史因此是一串「补丁叠加」。</span>

## 2 美国行政改革的百年谱系

把美国百余年改革按年代排开，就是一部浓缩的公共行政史：

| 年代 | 改革 | 要解决的问题 | 遗产 |
| --- | --- | --- | --- |
| 1883 | 彭德尔顿法案 | 分肥制、用人唯亲 | 功绩制、文官考试 |
| 1890s–1920s | 进步时代市政改革 | 市政腐败、城市老板 | 城市经理制、预算制度化 |
| 1930s | 罗斯福新政 | 经济危机、福利国家需求 | 联邦机构大扩张、总统行政办公室 |
| 1937 | 布朗洛委员会 | 总统控制能力不足 | 总统行政办公室重组、机构集中 |
| 1947–1955 | 两次胡佛委员会 | 二战后的机构臃肿 | 部门整合、管理科学化 |
| 1978 | 文官改革法 | 文官制度僵化 | OPM/MSPB/SES、绩效激励 |
| 1993 | GPRA 绩效与结果法案 | 只问投入不问产出 | 战略规划与绩效报告制度 |
| 1993 | 国家绩效评估（NPR） | 官僚病、成本高昂 | 「更小、更好、更便宜」改革 |
| 2000s | PART 项目评估 | 绩效预算落地 | 项目评估分级（后随 GPRA 现代化法案调整） |
| 2010 | GPRA 现代化法案 | 绩效数据利用率低 | 绩效信息驱动决策制度化 |

**每代改革的共同叙事**：先由危机或丑闻点燃政治意愿，再由委员会或专家开出药方，最后立法固化——而改革的后续几乎总伴随「预期落差」与「新一轮修补」。读这张表要抓住的不是每个法案，而是这条主线：**从「怎么选人」（1883）到「怎么花钱」（预算改革）到「怎么管结果」（GPRA 与 PART），问责的重心一路从「投入」移向「产出」。**

## 3 重塑政府运动：奥斯本—盖布勒与戈尔报告

1990 年代的「重塑政府」（reinventing government）是本专题最浓墨重彩的一章。奥斯本与盖布勒 1992 年的《重塑政府》提出「企业家政府」的十个原则，后来被浓缩为几句口号：

**催化式政府**：掌舵而非划桨（第七篇的核心句）；
- **社区拥有的政府**：把服务交付权交给社区；
- **竞争性政府**：把竞争机制引入公共服务；
- **使命驱动的政府**：按使命而非按规章管理；
- **结果导向的政府**：按结果拨款，而非按投入；
- **顾客驱动的政府**：把公民当顾客（第九篇电子政务的直接源头）；
- **有事业心的政府**：学会赚钱而不是只花钱；
- **有预见的政府**：预防优先于治疗；
- **分权的政府**：向一线授权；
- **市场导向的政府**：用市场机制而非行政命令。

1993 年戈尔主持的**国家绩效评估（NPR）**把理念变成行动，打出「让政府花更少的钱办更好的事」（works better, costs less）的旗号：削减文牍、下放人事权、绩效合同、顾客服务标准、裁撤冗余机构。NPR 的直接成果包括政府服务标准承诺、流程简化的试点，以及电子政务的起步（见第九篇）。<span class="marginnote">NPR 有个常被忽略的细节：它刻意用「顾客」一词把公众与政府的关系比喻成市场交易，这既激怒了坚持「公民权利」的人（第八篇），也成功地把「政府服务态度」问题变成可考核的指标——两种解读并存，恰好说明重塑政府运动同时推进与冒犯了三大途径。</span>

**重塑政府的成就与局限**：成就方面，它确实让政府更关注结果与顾客体验，启动了影响至今的绩效管理革命；局限方面，批评者指出：把政府当企业，忽略政府不是追逐利润的组织；绩效指标催生「刷数据」行为（第七篇的指标博弈）；外包与授权扩大问责缺口；一些削减以牺牲公共服务质量为代价。里根那句「政府是问题」的叙事，最终被证明过于简单——**政府既是问题，也是解决问题的唯一场所**。

## 4 全球改革浪潮与反思

重塑政府不是美国专利。1980 年代起，NPM 式改革席卷全球：

**英语世界**：新西兰与澳大利亚的激进市场化改革，英国的「下一步行动」执行局模式；
- **欧洲大陆**：法国、德国的预算与绩效改革、监管改革；
- **发展中国家**：世界银行与 IMF 推行的「新公共管理」处方（绩效预算、私有化、分权），结果褒贬不一——在制度土壤薄弱的国家，市场化处方常与腐败和贫富分化相伴；
- **后 NPM 转向**：21 世纪「整体政府」「合作治理」「数字治理」兴起，修补前一轮改革造成的碎片化（第七、九篇）。

全球经验沉淀出几条共同教训：**改革是「情境依赖」的**——适合北欧的绩效合同未必适合转型国家；**改革成功需要制度配套**——契约文化、法治、职业官僚体系是先决条件；**改革有政治生命周期**——热度随选举周期起伏，需要制度化（立法、独立机构）才能穿越换届。**核心要点：改革三问**

1. 改的是结构、过程，还是文化？（层次决定难度）
2. 改革成果靠什么维持？（靠立法与机构，而不是靠口号与领导人）
3. 改革有没有产生「赢家与输家」？输家的反弹如何化解？（不处理分配后果的改革会自我摧毁）

## 5 改革的逻辑与中国视角

把改革史收拢到理论层面，可以得到一个「改革悖论」：**改革依赖一个高效政府，而改革的对象正是这个政府。** 改革要能推进，需要政治意愿、行政能力与公众支持同时在线——这恰恰是最稀缺的资源。这也是为什么改革总是「危机驱动的」：不撞南墙，不动大手术。

以中国为例，改革开放以来的行政改革走过一条相似又有别的轨迹：从机构精简（多轮「大部制」改革）、转变职能（放管服、行政审批制度改革）、到绩效导向（预算绩效管理）与数字化治理（「数字政府」「一网通办」）。其主线与西方改革高度同构——**从「管得过多」到「管得更准」，从「以部门为中心」到「以群众为中心」**——但节奏与路径受单一制与政党体制的约束，呈现出更强的「顶层设计、试点先行、渐进推进」特征。<span class="marginnote">中国行政改革与西方 NPM 的对照很有意思：西方改革从「小政府」信念出发，中国改革从「效率与秩序并重」出发；西方靠分权与市场化，中国靠职能转变与数字化。但双方都面临同一难题——政府能力的「减法」（精简）与「加法」（数字化、绩效化）如何同步推进。</span>

**辨析｜易错点：** 「改革成功」不等于「改革结束」。行政改革史最大的错觉是「这次终于一劳永逸」。事实是：**每次改革都在为下一次改革制造素材**——GPRA 解决了「没有绩效信息」，PART 暴露了「有信息没人用」，数字政府又带来「有数据没治理」。公共行政的常态不是「改革完成」，而是「改革进行中」。

## 6 小结

- 行政改革分**结构、过程、文化**三个层次，难度递增；改革呈**钟摆式循环**，每代改革都在收拾上一代的副作用。
- 美国改革谱系从 1883 功绩制、1937 布朗洛、1978 文官改革法，到 1993 GPRA/NPR、2000s PART——问责重心一路从「投入」移向「产出」。
- **重塑政府**（奥斯本—盖布勒十原则＋戈尔 NPR）用「掌舵而非划桨」「顾客导向」「结果导向」改写政府，既带来绩效革命，也埋下指标博弈与问责缺口的伏笔。
- 全球 NPM 浪潮证明改革**情境依赖**，需制度配套，且有政治生命周期；后 NPM 转向「整体政府」与「数字治理」。
- **改革悖论**：改革要靠高效政府推进，而改革对象正是政府——所以改革常是危机驱动、且永远进行中。

至此，本专题的十二篇把你从威尔逊的出发点一路带到了改革的当代现场：三大途径（管理、政治、法律）构成观察镜，组织、人事、预算、央地关系构成制度骨架，NPM、行政法、电子政务、伦理、公共选择构成工具箱，而改革史证明这一切永远处在「重塑」之中。如果这段旅程让你想继续深入，下一站可以走向**公共政策**（政策的制定与评估过程）或**经济学**（公共物品、外部性与制度经济学的严格模型）——公共行政是这些学科的交叉路口，而你已经拿到了路口的地图。
