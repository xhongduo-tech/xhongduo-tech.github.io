## 为什么从借贷记账法的应用开始

前几节我们掌握了记账的「语法」：借贷、账户、凭证、账簿。但从没回答过一个更根本的问题——这些语法如何组织起一家企业从生到死、从筹钱到分钱的**完整生命周期**？本节把借贷记账法应用到企业的主要经营环节：**筹资 → 采购 → 生产 → 销售 → 利润形成与分配**。走完这一圈，你就有能力把一家制造企业的整条业务流翻译成分录了。这也是从「会计技术」走向「会计实务」的第一次完整行军。

## 1 资金筹集业务的核算

企业要运转，先要有「钱」。资金筹集的两种来源，正好对应会计等式右边的那两项：

- **所有者投入（权益筹资）**：

```text
借：银行存款
    贷：实收资本
```

<span class="marginnote">「实收资本」记录股东实际投入的资本；股份有限公司发行股票用「股本」。股东投入超过注册资本份额的部分，计入「资本公积——资本溢价」，它同样属于所有者权益，但性质是「溢价的积累」而非「注册的本钱」。</span>

**债权人借入（债务筹资）**：

```text
借：银行存款
    贷：短期借款
```

借款利息的处理值得注意：短期借款利息通常**按月计提**、期末支付，计提时借记「财务费用」、贷记「应付利息」。利息是「用钱的价格」，无论借款用于什么项目，一律进当期费用——这与后面《负债与所有者权益》一篇的利息资本化问题形成对照。

## 2 供应过程：采购业务的核算

采购业务的核心是「存货增加，同时负债或资产减少」。购入原材料：

```text
借：原材料
    应交税费——应交增值税（进项税额）
    贷：应付账款（或银行存款）
```

**辨析｜易错点：** **可抵扣的增值税进项税额不计入原材料成本**——它是将来要抵销销项税的「暂垫款」，属于债权，所以单列在「应交税费」的借方；只有不可抵扣的进项（如用于集体福利、个人消费的购进）才并入存货成本。计入存货成本的，是不含税的买价加上运费、装卸费、入库前的整理费等采购费用。

若材料已到而发票未到，先按暂估价值入账，待发票到达后再调整——这类「暂估」处理是《存货》一篇的细节，此处只需建立「存货的成本 = 买价 + 附带费用」的印象。

## 3 生产过程：费用归集与成本计算

生产过程把「资产」转化为「成本」，最终形成产品。三种成本要素：

**直接材料**：构成产品实体的材料，购入时记「原材料」，领用时直接转入生产成本。
**直接人工**：生产工人的工资，按工时或计件直接计入产品成本。
**制造费用**：车间发生的间接费用（车间水电费、车间设备折旧、车间管理人员工资），先归集到「制造费用」，期末再按工时、产量等标准**分配**转入各产品生产成本。

领料与结算的分录：

```text
(1) 领用材料：
借：生产成本——直接材料
    贷：原材料

(2) 结算直接人工：
借：生产成本——直接人工
    贷：应付职工薪酬
```

产品完工验收入库时：

```text
借：库存商品
    贷：生产成本
```

<span class="marginnote">「生产成本」是成本类账户，期末若有余额，表示<strong>尚未完工的在产品</strong>——它在资产负债表上仍属存货的一部分。注意成本类账户的余额方向与资产一致（借方），这也解释了为什么记账规则把成本类与资产类归入「借增」阵营。</span>

## 4 销售过程：收入与应收的核算

销售实现收入：

```text
借：银行存款 / 应收账款
    贷：主营业务收入
    应交税费——应交增值税（销项税额）
```

与此同时，**必须**结转已售产品的成本：

```text
借：主营业务成本
    贷：库存商品
```

**辨析｜易错点：** 销售业务必须**同时记两笔**——确认收入、结转成本。只记收入不转成本，会高估利润、虚增存货；只转成本不记收入，则漏记利润。**收入与成本的配比**（配比原则）在这里第一次落成具体分录，它是利润表「营业收入 − 营业成本 = 毛利」那一行的会计来源。

此外，销货若有现金折扣或商业折扣，处理不同：**商业折扣**（按折后价开票）直接按折后价确认收入；**现金折扣**（如「2/10，n/30」，10 天内付款打 98 折）按总价法入账，折扣实际发生时计入「财务费用」。这条辨析会在《收入、费用与利润》一篇深入展开。

## 5 利润形成与分配的核算

期末，把所有损益类账户的余额结转到「本年利润」：

收入类结转：

```text
借：主营业务收入
    贷：本年利润
```

费用类结转：

```text
借：本年利润
    贷：主营业务成本
        税金及附加
        销售费用
        管理费用
        财务费用
```

「本年利润」为贷方余额表示**净利润**，借方余额表示**净亏损**。随后进行利润分配：

```text
借：本年利润
    贷：利润分配——未分配利润

借：利润分配——提取盈余公积
    贷：盈余公积

借：利润分配——应付现金股利
    贷：应付股利
```

<span class="marginnote">净利润的三条去向：<strong>提取盈余公积</strong>（留存备用于再投资与弥补亏损）、<strong>向股东分配股利</strong>、<strong>剩下的是未分配利润</strong>。盈余公积与未分配利润合称「留存收益」，是所有者权益里「企业自己挣的」部分，与「实收资本」（股东投入的）在来源上分得清清楚楚。</span>

## 6 公式解析：营业利润的计算链

把第 5 节的结转汇总，就得到利润表的核心公式：

$$
营业利润 = 营业收入 - 营业成本 - 税金及附加 - 销售费用 - 管理费用 - 财务费用 + 投资收益
$$

- **第一步，从营业收入出发**：营业收入 = 主营业务收入 + 其他业务收入，是企业「卖货 + 卖副业服务」挣到的总数。
- **第二步，减营业成本与税金及附加**：营业成本 = 主营业务成本 + 其他业务成本；税金及附加包括消费税、城建税、教育费附加等。减完得到**毛利**。
- **第三步，减三项期间费用**：销售费用（广告、运费、销售佣金）、管理费用（行政、房租、折旧）、财务费用（利息、汇兑损益）。它们不随产品直接归属，而是**按期间列支**。
- **第四步，加投资收益等**：对外投资赚到的钱并入，得到**营业利润**。

再向上收拢两级：

$$
利润总额 = 营业利润 + 营业外收入 - 营业外支出
$$

$$
净利润 = 利润总额 - 所得税费用
$$

这条链条就是《财务报表：利润表》的行次结构，也是《收入、费用与利润》一篇的完整骨架。现在看懂它，等于提前预习了利润表。

## 7 小结

- 资金筹集分**权益筹资**（实收资本 / 股本 / 资本公积）与**债务筹资**（短 / 长期借款）。
- 采购业务把存货记入「原材料」，**可抵扣的进项税额不进成本**。
- 生产成本由**直接材料、直接人工、制造费用**构成；制造费用期末分配转入成本，完工产品转「库存商品」。
- 销售业务必须**同步确认收入与结转成本**，配比原则在此落地。
- 期末损益结转至「本年利润」，再分配为**盈余公积、应付股利、未分配利润**。
- 利润计算链：**营业利润 → 利润总额 → 净利润**，逐层收拢。
