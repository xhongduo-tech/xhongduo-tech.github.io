## 为什么从投资组合理论展开

上一节我们度量了单一资产的风险与收益。
但现实中没人只买一只股票——所有人都「不把鸡蛋放在一个篮子里」。为什么分散化能降低风险？
能降低多少？什么样的组合最优？**现代投资组合理论（Modern Portfolio
Theory，MPT）** 是马科维茨 1952 年的博士论文贡献，他凭此获 1990
年诺贝尔经济学奖。这是金融学第一次用严格的数学回答「组合」问题，也是 CAPM 的直接前奏。
<span class="marginnote">「分散化」人人会说，但马科维茨的洞见在于：<strong>组合的风险不是个股风险的加权平均</strong>——因为股票之间存在相关性。这个「1+1<2」的风险抵消效应，是 MPT 的全部精髓，也是概率论中协方差在金融中的核心应用。</span>

## 1 组合的期望收益与风险

一个投资组合由若干资产按权重构成。若资产 $i$ 的期望收益为 $E(r_i)$、
权重为 $w_i$，则组合的期望收益是**权重加权平均**：

$$E(r_p) = \sum_{i=1}^{n} w_i \, E(r_i)$$

组合的收益好算，但组合的风险（方差）不简单。对两只资产的组合：

$$\sigma_p^2 = w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2 w_1 w_2 \, \sigma_1 \sigma_2 \, \rho_{12}$$

- **$w_1, w_2$：两只资产的权重**（$w_1 + w_2 = 1$）。
- **$\sigma_1, \sigma_2$：各自的标准差**。
- **$\rho_{12}$：两资产的相关系数**，介于 $-1$ 到 $1$ 之间。

拆解三步：

- **第一步，方差为什么有三项**：组合波动不仅来自各自波动（前两项），还来自两者的**同向或反向联动**（第三项）。联动越强，第三项越大。
- **第二步，相关系数 $\rho$ 如何决定分散效果**：$\rho = 1$ 时，$\sigma_p = w_1\sigma_1 + w_2\sigma_2$——风险完全加权平均，分散无效；$\rho < 1$ 时，$\sigma_p$ 小于加权平均——**分散化开始起效**；$\rho = -1$ 时，理论上可构造风险为零的组合（完全对冲）。
- **第三步，为什么「免费午餐」**：期望收益永远是加权平均，而风险在 $\rho < 1$ 时低于加权平均。**收益不减、风险变小——这就是分散化的价值，不需要牺牲任何东西。**<span class="marginnote">$\rho = 1$（完全正相关）时分散无效，$\rho = -1$（完全负相关）时可消除全部风险。现实中多数股票相关系数为 0.3-0.6，所以分散有效但不彻底——这正是「系统性风险」存在的空间，也是下一节 CAPM 的出发点。</span>

## 2 可行集与有效边界

把所有可能权重组合画在「风险—收益」平面上，就得到**可行集（feasible set）
**——一个向左凸出的区域。区域里的大部分组合是「次优」的：同样的风险下，
你能在更高的位置找到收益更好的组合。

**有效边界（efficient frontier）** 是可行集的**左上方边界**：
在给定风险下收益最高、给定收益下风险最低的全部组合的集合。
理性投资者只会在有效边界上选择组合。

**重点：有效边界回答了「哪些组合值得买」——只有落在边界上的组合才是有效的。**
边界下方的组合被支配（总可以改进），边界上方的组合不存在（已到极限）。
<span class="marginnote">有效边界是「可能性前沿」的金融版本：它告诉你物理极限在哪，但选哪一点取决于你的偏好——风险厌恶者靠近最小方差组合，风险偏好者靠近右上方。这与微观经济学里「效用最大化」的框架完全同构。</span>

## 3 引入无风险资产：资本市场线

有效边界考虑的是「全风险资产」的组合。一旦引入**无风险资产** $r_f$（短期国债），
投资者的选择空间就扩展了：可以在无风险资产与某个风险组合 $M$ 之间分配资金。

此时所有可能组合构成一条从 $r_f$ 出发的直线，其斜率 =（组合收益 − $r_f$）
/ 组合风险。最优的是**与有效边界相切的那条直线**——切点组合 $M$
被称为**市场组合（market portfolio）**。
这条切线就是**资本市场线（Capital Market Line，CML）**：

$$E(r_p) = r_f + \frac{E(r_M) - r_f}{\sigma_M} \sigma_p$$

- **$E(r_p)$：组合的期望收益**。
- **$\sigma_p$：组合的标准差**。
- **$E(r_M) - r_f$：市场组合的风险溢价**。
- **$(E(r_M) - r_f)/\sigma_M$：风险的市场价格**——每承担一单位总风险应得的报酬。

拆解三步：

- **第一步，为什么引入无风险资产后图形变直线**：无风险资产与任何风险组合的连线是直线（因为无风险资产与风险资产组合的方差公式中 $\rho$ 项为零）。
- **第二步，为什么选切点**：在所有直线上，切线的斜率最大——同样的风险给最多收益。理性投资者沿着切线选点。
- **第三步，CML 的分离定理**：**所有投资者都持有同一组合 $M$，区别只在于借入或贷出无风险资产的比例**——激进者借钱加杠杆（超出 $M$），保守者持有更多国债。投资决策（选 $M$）与融资决策（配无风险比例）分离。

**辨析｜易错点：** 有效边界与资本市场线不是一回事——**有效边界只有风险资产，CML
是风险资产 + 无风险资产的组合线**。CML 是切线，它的斜率度量「总风险」的价格；
而下一节 CAPM 的证券市场线（SML）度量「系统性风险」的价格。三条线（有效边界、
CML、SML）是投资理论最容易混淆的三个概念。

## 4 分散化的极限：系统性风险

随着组合中股票数量增加，非系统性风险（个别公司的特有风险）不断被稀释，
但组合风险不会降到零——它收敛到一个**不可再分散**的水平。
这就是**系统性风险（systematic risk）**：影响整个市场的风险（利率、衰退、
石油危机），无论持有多少股票都存在。

**重点：分散化只能消除非系统性风险，无法消除系统性风险——因此市场只对系统性风险定价。
** 这正是下一节 CAPM 的核心思想：投资者承担的特有风险得不到补偿（可以被分散掉），
只有承担市场风险才获得风险溢价。
<span class="marginnote">实证上，随机抽取约 30 只股票组成的组合，其标准差已接近市场水平——多持股票几乎不再降低风险。这意味着「买一堆股票」不如「买市场组合」：前者多付交易成本，风险却几乎一样。指数基金的合理性在这里再次得到印证。</span>

## 5 延伸：再平衡与指数基金——理论走向实践

马科维茨理论从 1952 年的论文到今天的千亿美元行业，中间经历了「理论落地」的关键一步：
把有效边界变成可操作的资产配置。

**再平衡（rebalancing）：把组合拉回目标权重。**
市场涨跌会让组合权重偏离最初设定：股票大涨，股票占比就从 60% 涨到 70%。
**再平衡就是定期卖出超配的资产、买入低配的资产，把权重拉回目标。** 它有两个作用：
一是**控制风险**——防止某个资产权重失控；二是**被迫低买高卖**——涨多的卖掉、
跌多的买入，自带「逆向投资」效果。
<span class="marginnote">再平衡是分散化的「执行层面」：马科维茨告诉你该配多少，再平衡保证你始终按这个比例持有。实证研究表明，定期再平衡（如每年一次）能在不牺牲长期收益的前提下显著降低波动——它把「纪律」变成了「收益」的一部分。巴菲特那句「别人恐惧我贪婪」的另一面，就是再平衡的机械化版本。</span>

**指数基金与资产配置：理论的集大成者。** 如果接受「市场难以战胜」与「分散化是免费午餐」
一个自然的推论是：**用低成本的指数基金覆盖各类资产，按风险偏好设定权重，定期再平衡。**
这就是「股债平衡」「全天候组合」等经典配置策略的底层逻辑——它们不是玄学，
而是现代投资组合理论 + 有效市场假说的直接产物。
<span class="marginnote">「三基金组合」（国内股票指数 + 国际股票指数 + 债券指数）被无数理财教科书推荐：只用三类指数基金就能构建一个覆盖全球、分散充分、成本极低的组合。它验证了理论的力量——几个简单原则，胜过复杂的择时与选股。</span>

**辨析｜易错点：** 「分散化 = 买很多基金」是常见误区。持有 50
只股票基金并不比持有 3
只涵盖不同资产类别的基金更分散——**分散的关键是资产类别之间的低相关（股票、债券、黄金、
房产），而不是基金数量**。买一堆同涨同跌的股票基金，只是「把鸡蛋放在更多同一个篮子里」。
<span class="marginnote">用《概率论》的语言：组合风险取决于协方差矩阵，而不取决于资产个数。如果所有资产高度正相关，数量再多也分散不掉系统性风险。真正能分散的，是<strong>相关性低</strong>的资产类别——这正是《风险与收益》与本节「相关系数 $\rho$」知识点的实践落点。</span>

**重点：投资组合理论从「选股票」升级为「配置资产」——它关心的不是哪只股票会涨，
而是各类资产的比例如何平衡风险与收益。** 这套思想的普及，
是过去半个世纪金融学影响普通人生活最深远的方式之一：它让「组合思维」取代「赌博思维」，
成为现代财富管理的默认框架。

## 6 小结

- **组合期望收益** = 加权平均；**组合风险** = 加权项 + 协方差项，$\rho < 1$ 时风险小于加权平均。
- **有效边界** = 给定风险下收益最高（或反之）的组合集合，理性投资者只在边界上选择。
- **资本市场线**：引入无风险资产后的最优直线，切点即市场组合 $M$，分离定理成立。
- **系统性 vs 非系统性风险**：分散化只能消除后者，市场只给前者定价。
- 「分散化的免费午餐」来自资产间的**不完全相关**。

在下一节，我们把「市场只给系统性风险定价」的直觉数学化为
CAPM——**资本资产定价模型**。
