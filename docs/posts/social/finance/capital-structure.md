## 为什么从资本结构进入公司金融

前几节都在讲「市场的价格」，从这一节起进入公司内部：**公司如何融资、如何分配、如何扩张。
** 资本结构（capital structure）
是第一个核心问题——公司的钱来自股权（股东）还是债权（银行、债券）？比例怎么定？1958
年莫迪利亚尼与米勒（MM）用一系列「无关性定理」发问：**馅饼怎么切，
会影响馅饼本身的大小吗？** 这个看似天真的问题，催生了整个公司金融理论。
<span class="marginnote">「从极限到大模型」的读者请留意：MM 定理是经济学里罕见的「负结果」——先告诉你「在理想条件下，资本结构无关紧要」，再逐条放松假设（税收、破产成本、信息不对称），最终得到现实的资本结构理论。先建立理想参照系，再逼近现实，这是最硬核的科学方法。</span>

## 1 MM 定理一：资本结构无关性

莫迪利亚尼—米勒定理一（无税版本）断言：**在无税、无破产成本、无信息不对称的完美市场中，
公司价值与资本结构无关。**

$$V_L = V_U$$

- **$V_L$：有杠杆公司的价值**（部分融资来自债务）。
- **$V_U$：无杠杆公司的价值**（全部股权融资）。

拆解三步：

- **第一步，为什么相等**：公司价值由**资产的现金流**决定，而不是由这些现金如何分配（利息还是股息）决定。股东与债权人加起来拿到的，永远是同一笔经营现金流。
- **第二步，套利证明**：投资者可以**自制杠杆**（home-made leverage）——买无杠杆公司的股票，同时自己借钱，复刻出有杠杆公司的收益结构。既然收益相同，价格必须相同，否则就有套利机会。
- **第三步，结论的震撼性**：负债比例是 0% 还是 90%，公司总价值不变。**财务决策不影响价值，只影响价值的分配。**<span class="marginnote">「自制杠杆」是金融学经典思想实验：如果投资者能自己借钱复制杠杆，公司层面的杠杆就毫无特殊价值。这个逻辑与《资产定价基础》的无套利原理一脉相承——同样现金流必须同样价格。</span>

## 2 公式解析：MM 定理二与权益成本

MM 定理一讲「总价值不变」，定理二则说明**收益率如何随杠杆变化**：

$$r_E = r_A + \frac{D}{E} (r_A - r_D)$$

- **$r_E$：权益（股权）成本**，股东要求的回报率。
- **$r_A$：资产成本**，整个公司（无杠杆）的必要回报率。
- **$D/E$：债务权益比**（杠杆率）。
- **$r_D$：债务成本**，债权人要求的回报率。

拆解三步：

- **第一步，为什么权益成本随杠杆上升**：股东是「剩余索取者」——公司先还债、再分股东。债务越多，股东承担的风险越大，要求的回报率越高。
- **第二步，加权平均不变**：把权益成本与债务成本按权重平均，得到 $WACC = \frac{E}{V}r_E + \frac{D}{V}r_D = r_A$——**恰好回到资产成本**。杠杆升高推高 $r_E$，但同时债务占比 $D/V$ 增大、$r_D < r_E$，加权平均恰巧不变。
- **第三步，深意**：**提高杠杆把风险从债权人转给股东，但不改变公司的总体风险与价值。** 总加权资本成本（WACC）与资本结构无关，这正是定理一的收益率镜像。

**辨析｜易错点：** 很多人误以为「债务便宜（$r_D < r_E$），
所以多借债能降低资本成本」。MM 定理二的回答是：
**债务占比升高会同时推高权益成本 $r_E$，两者抵消，WACC 不变。**
「多借钱摊低成本」在完美市场是个幻觉。
<span class="marginnote">用杠杆前后 WACC 不变来理解：便宜的钱占比多了，但剩余的钱（股权）变贵了，加权后一动不动。这就像往咸水里加糖——盐味淡了，甜味升了，综合味道不变。</span>

## 3 引入税：税盾与杠杆的价值

完美市场的无关性是个参照系。现实最大的偏离是**税收**——债务利息可以在税前扣除（税盾），
股利不能。于是杠杆有了税收好处：

$$V_L = V_U + T_c \times D$$

- **$T_c$：公司所得税率**。
- **$T_c \times D$：税盾的现值**——每年省下的税额 $T_c \times r_D \times D$ 按 $r_D$ 贴现，恰好等于 $T_c D$。

**重点：有税世界里，杠杆提升公司价值——债务越多、税盾越大、价值越高。** 照此推论，
公司应该 100% 负债融资，这与现实矛盾。于是需要引入税盾的对立面：**财务困境成本**。
<span class="marginnote">税盾把 MM 从「无关」推向「杠杆有益」，但极端推论（全负债）显然荒谬。理论的修正方向非常清晰：找到税盾的对冲成本——这就是下一节《权衡理论》的思想。理论的演进路径本身就是最好的教学。</span>

## 4 权衡理论与优序融资

**权衡理论（trade-off theory）** 综合两股力量：
杠杆的**边际税盾收益**与**边际财务困境成本**（破产成本、代理成本）。
最优资本结构出现在两者平衡处——**边际收益 = 边际成本**。

$$V_L = V_U + T_c D - PV(\text{财务困境成本})$$

**优序融资理论（pecking order theory）** 则从信息不对称出发：
内部人比外部人更了解公司价值。融资有**顺序偏好**：先内部留存收益 → 再发债 →
最后发股。为什么股权排在最后？因为**发行股票被市场解读为「内部人认为股价高了」**，
消息一出股价往往下跌——股权融资是「最贵」的信号。

**辨析｜易错点：** 权衡理论说「有最优债务比例」，优序融资说「没有目标比例、
只有顺序偏好」——两者并非矛盾，而是从不同角度回答资本结构问题：权衡从成本收益权衡、
优序从信息信号出发。现实中：成熟稳定行业（现金流可预期）倾向于高杠杆（税盾价值大、
困境成本低），成长行业靠权益融资（信号成本高、需保留财务弹性）。
<span class="marginnote">「增发公告 → 股价下跌」是优序融资最著名的实证：美国数据表明，宣布增发的公司平均股价下跌约 3%。这就是信息不对称的信号成本——公司想说「我需要钱扩张」，市场听到的是「内部人觉得现在股价卖得划算」。</span>

## 5 延伸：杠杆、财务困境与中国的资本结构实践

资本结构的理论在现实中如何落地？几个视角值得展开。

**财务杠杆的「放大镜」效应。** 杠杆不只影响资本成本，更放大股东收益的波动。
用净资产收益率（ROE）看：公司总资产收益率（ROA）高于债务成本时，杠杆提升 ROE；
低于债务成本时，杠杆反而侵蚀 ROE。这就是**财务杠杆的「双刃剑」**——顺风时放大盈利，
逆风时加速亏损，极端情况直接破产。
<span class="marginnote">「杠杆放大 ROE」是为什么企业愿意负债、投资者关注资产负债率的原因。但放大是双向的：当行业景气时，高杠杆公司报表漂亮；行业转冷时，同样这批公司最先暴雷。理解杠杆的放大效应，就理解了为什么《金融危机的机理》把「杠杆」列为危机的第一关键词。</span>

**财务困境成本的现实形态。** 理论里的「破产成本」在实务中有具体表现：
破产清算的直接成本（律师费、资产贱卖）、间接成本（客户流失、供应商要求现款、优秀员工离职、
管理层精力耗散）。这些成本随杠杆上升而加速增长——**杠杆越高，债权人越警惕，
公司的融资与经营处处受制**。这正是权衡理论里「边际困境成本递增」的微观基础。
<span class="marginnote">「财务困境」不等于「破产」——困境是「濒临违约」的灰色地带：公司还能经营，但市场已不信任。处在困境中的公司，新项目融资被拒、供应商要求预付款、优质员工流失……这些「看不见的成本」往往比破产本身更伤人。这也是为什么公司要保留「财务弹性」——手头留有余地，才能在危机时活下来。</span>

**中国实践的独特性。** 中国上市公司整体杠杆（资产负债率）长期偏高，
且呈现「国企杠杆高于民企」「重资产行业高于轻资产」的结构。原因包括：
银行信贷偏好国企（隐性担保预期）、股权融资渠道相对不畅、债券市场发展滞后。
这与《中国金融体系改革》的方向直接相关——**发展直接融资、优化资本结构，
正是中国金融改革要解决的问题**。
<span class="marginnote">把资本结构理论用于中国：中国企业的「融资顺序」更接近「银行信贷 → 股权 → 内部留存」，与优序融资理论的经典顺序不同，根源在制度环境——银行信贷可得性、上市门槛、利率市场化程度都会重塑融资选择。理论是参照系，具体排序要看制度约束。</span>

**重点：资本结构没有「放之四海而皆准」的最优比例——它取决于税收、困境成本、行业波动、
信息不对称与制度环境的综合权衡。** 理论给的是「分析框架」，不是「标准答案」。

## 6 小结

- **MM 定理一**：完美市场下公司价值与资本结构无关，套利与自制杠杆是证明核心。
- **MM 定理二** $r_E = r_A + (D/E)(r_A - r_D)$：杠杆推高权益成本，但 WACC 不变。
- **税盾**：利息税前扣除使杠杆提升价值，$V_L = V_U + T_c D$。
- **权衡理论**：最优资本结构 = 税盾收益与财务困境成本的平衡。
- **优序融资**：留存收益 → 债券 → 股权，股权融资信号成本最高。
