## 为什么从国际收支进入宏观篇

前三篇完成了个体、市场、公司的微观拼图，第四篇把视野拉到**国家与全球**。
起点是**国际收支（balance of payments，BOP）
**——一国居民与外国居民之间全部经济往来的系统性记录。它是国际金融的「总账本」：
贸易顺差还是逆差、资本流入还是流出、外汇储备增减，全部登记在这张表上。读懂国际收支，
是理解汇率、国际货币体系与金融危机的前提。
<span class="marginnote">第一级《经济学》的开放经济章节提到过「净出口」，本篇把那张表完整展开。国际收支的核心是<strong>复式记账</strong>——任何一笔交易都有借方与贷方，总额恒等于零。理解这一点，就抓住了整张表的钥匙。</span>

## 1 国际收支平衡表的三大账户

国际收支采用**复式记账**：每一笔国际经济交易同时记入借方（支付外汇）与贷方（收到外汇），
因此**借贷必相等，国际收支恒等于零**。

平衡表分三大账户：

**经常账户（current account）**：记录**实际资源**的流动，含四部分：
- **货物贸易**：商品的进出口。
- **服务贸易**：运输、旅游、金融、知识产权等服务。
- **初次收入**：工资、利息、股息等要素报酬。
- **二次收入**：无偿转移（援助、侨汇）。

**资本与金融账户（capital and financial account）**：
记录**资本流动**：
- **资本账户**：资本转移、无形资产交易。
- **金融账户**：直接投资（FDI）、证券投资、其他投资、储备资产变动。

**错误与遗漏账户（errors and omissions）**：由于统计误差，
借贷难以完全相等，用该账户轧平。

**重点：经常账户 + 资本与金融账户 + 错误遗漏 = 0。** 这是一个恒等式，
也是理解一切国际收支问题的起点。
<span class="marginnote">这个恒等式有深刻的含义：<strong>经常账户顺差 = 资本账户净流出。</strong> 一个国家出口多于进口（赚了外汇），这些外汇必然以某种形式流向国外——要么购买外国资产，要么增加外汇储备。贸易顺差国在「借钱给」逆差国，这就是全球失衡的结构性来源。</span>

## 2 公式解析：国民收入与国际收支

国际收支与宏观经济的联系通过国民收入恒等式展开：

$$Y = C + I + G + NX$$

- **$Y$：国民收入**，$C$：消费，$I$：投资，$G$：政府购买。
- **$NX = X - M$：净出口**，出口减进口。

由此推出：

$$S - I = NX$$

- **$S$：国民储蓄**（$S = Y - C - G$）。
- **$S - I$：储蓄与投资的差额**（储蓄缺口）。
- **$NX$：净出口**（经常账户余额的近似）。

拆解三步：

- **第一步，从恒等式变形**：$Y - C - G = I + NX$，左边正是储蓄 $S$，移项得 $S - I = NX$。
- **第二步，经济含义**：**国内储蓄多于投资的部分，必然以净出口的形式流向国外。** 储蓄不足（$S < I$）则进口多于出口（$NX < 0$），靠外国资本补足。
- **第三步，全球视角**：把世界当作整体，所有国家的 $NX$ 加总为零——**一国的顺差必然是另一国的逆差**。美国长期逆差（$S < I$，消费过度）对应中国等国的顺差（$S > I$，储蓄过度），这就是「全球失衡」。<span class="marginnote">$S - I = NX$ 是理解贸易摩擦的第一公式：当一个国家储蓄不足又不想压缩消费，就只能靠逆差进口外国储蓄。所谓「贸易逆差是别人的错」，在这个恒等式面前站不住脚——逆差是储蓄—投资结构的内生结果。</span>

## 3 国际收支的失衡与调节

**国际收支失衡**通常指经常账户的持续顺差或逆差。失衡并非天然有害：
发展中国家用逆差引进资本（借外国储蓄搞建设），石油国用顺差积累储备。
真正的危险在于**不可持续的失衡**——持续巨额逆差伴随外汇储备枯竭，
最终引发货币危机（详见《金融危机的机理》）。

**国际收支的调节机制**：

- **自动调节**：汇率浮动下，逆差 → 本币贬值 → 出口变便宜、进口变贵 → 逆差收敛（弹性分析法）。
- **政策调节**：汇率政策（贬值刺激出口）、财政货币政策（压缩内需降进口）、直接管制（关税、配额、外汇管制）。

**辨析｜易错点：** 贬值不一定改善逆差——**J 曲线效应**：本币贬值后，
进口商品以本币计价先变贵（进口额短期反而上升），出口调整有滞后，
逆差可能**先恶化后改善**，轨迹形如字母 J。
<span class="marginnote">J 曲线是国际金融最反直觉的经验规律之一：贬值不是「立竿见影」地改善贸易，而是先恶化数月到一年才好转。因为订单调整需要时间、汇率传导有粘性——政策制定者若只看短期数据，容易误判贬值无效。</span>

## 4 核心对比：经常账户与资本账户

| 维度 | 经常账户 | 资本与金融账户 |
| --- | --- | --- |
| 记录对象 | 实际资源（货物、服务、收入） | 金融资产与负债 |
| 典型项目 | 进出口、旅游、侨汇 | FDI、证券投资、储备 |
| 经济含义 | 储蓄—投资缺口（$S - I$） | 资金的跨国配置 |
| 方向关系 | 顺差 = 资本净流出 | 顺差 = 资本净流入 |
| 调节工具 | 汇率、贸易政策 | 利率、资本管制 |

**重点：国际收支平衡 ≠ 经常账户等于零，而是「经常 + 资本」整体可持续。**
一个健康的开放经济体，可能常年有贸易逆差但靠资本流入（金融中心、投资热土）
维持平衡——美国的美元霸权正是如此。判断失衡是否危险，看的是**融资可持续性**，
而非单个账户的符号。
<span class="marginnote">「贸易逆差 + 资本流入」的组合并不天然是坏事：它说明该国是投资目的地，外国资本愿意为其项目融资。真正危险的是「逆差 + 资本流出」——既入不敷出又无人投资，外汇储备很快耗尽，货币危机随之而来（如 1997 年亚洲金融危机）。</span>

## 5 延伸：中国的国际收支结构与「双顺差」

把国际收支的框架用在中国数据上，能看到教科书概念的鲜活版本。

**中国国际收支的典型特征：长期「双顺差」。** 1990 年代以来，
中国长期同时保持**经常账户顺差**（出口大于进口）
与**资本与金融账户顺差**（资本净流入）——这是非常独特的结构。按恒等式「经常顺差 =
资本净流出」，正常情况下两者应一正一负；「双顺差」
意味着官方储备大量增加来轧平——外汇储备从 2000 年约 1600 亿美元飙升至
2014 年近 4 万亿美元，全球第一。
<span class="marginnote">「双顺差」的成因值得玩味：出口导向政策（经常顺差）+ 招商引资优惠（FDI 流入）叠加，外汇供给大于需求，央行不得不大量购入外汇、投放人民币，导致<strong>外汇占款成为基础货币投放的主要渠道</strong>——这也解释了中国货币政策长期「被动放水」的制度根源。理解双顺差，就理解了中国货币供应量与外汇储备的纠缠关系。</span>

**外汇储备的意义与代价。** 巨额外汇储备带来三重含义：**保障**（抵御货币危机的弹药，
如 1997 年亚洲金融危机中中国因储备充足而幸免）；**成本**（储备以低收益的美债为主，
等于「低息借钱给美国」）；**风险**（美元贬值、美债价格波动侵蚀储备价值）。
<span class="marginnote">「储备的代价」是一个常被忽视的问题：中国把出口赚来的美元换成美国国债，等于把高回报的投资机会让渡给美国，只拿约 4% 的国债利息。这笔「国富外流」的成本，正是《国际货币体系》里「美元霸权」的另一面。2014 年后中国主动调整：藏汇于民、推动人民币跨境使用、降低对美元储备的过度依赖。</span>

**辨析｜易错点：** 「经常账户顺差 = 好事」是常见的直觉误判。
顺差意味着本国储蓄大于投资、净输出资源——既是竞争力强的体现，也可能是**内需不足、
消费疲弱**的信号。中国 2007 年前后顺差占 GDP 超过 8%，恰是「高储蓄、低消费」
失衡的镜像。**判断顺差健不健康，要看它背后的储蓄—消费结构，而非顺差本身。**
<span class="marginnote">回到恒等式 $S - I = NX$：顺差 = 储蓄过剩。中国顺差大的根源是居民储蓄率高、消费占比低，而不是简单的「出口厉害」。这个视角下，扩大内需、降低储蓄、提振消费，才是「从根源调节国际收支」——它与中国经济转型的宏观叙事完全一致。</span>

**重点：国际收支是一国经济结构的「X 光片」——顺差逆差只是症状，背后的储蓄、投资、
产业结构才是病灶。** 读国际收支，最终是读一国经济的健康度与开放度。

## 6 小结

- **国际收支** = 一国与世界的完整账本，复式记账、借贷恒等，三大账户：经常、资本与金融、错误遗漏。
- **核心恒等式**：经常 + 资本 + 遗漏 = 0；经常顺差 = 资本净流出。
- **$S - I = NX$**：储蓄缺口决定净出口，全球失衡源于各国储蓄—投资结构。
- **失衡调节**：汇率自动调节 + 政策调节；贬值改善逆差遵循 J 曲线。
- 失衡是否危险，看**融资可持续性**，而非账户符号。
