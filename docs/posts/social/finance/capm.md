# 资本资产定价模型（CAPM）

<div class="epigraph">

## 为什么从 CAPM 展开

上一节的组合理论解决了「怎么组合最优化」，但留下一个未完成的问题：
**单个资产该要求多高的收益率？** 一只股票的合理回报是 8% 还是 15%？
**资本资产定价模型（CAPM）** 给出了金融学最著名的单资产定价公式。
它是夏普等人在马科维茨组合理论基础上于 1960 年代独立发展的成果，
至今仍是估值的标配工具——从贴现率到资本成本，处处可见它的身影。
<span class="marginnote">CAPM 把上一节的结论压缩成一句话：<strong>市场只奖励系统性风险。</strong> 它用 $\beta$ 精确度量「一项资产承担了多少市场风险」，再用 $\beta$ 乘风险溢价得出应得回报。读者将看到第二级《线性代数》的协方差、回归思想在这里的应用。</span>

## 1 CAPM 的前提与核心思想

CAPM 建立在几个关键假设之上：投资者是**风险厌恶**的、按均值—方差做决策、
**同质预期**（所有人对风险收益的看法相同）、市场无摩擦（无税、无交易成本）、
所有投资者都可以按无风险利率借贷。

在这些假设下，上一节的「分离定理」成立：
**所有投资者持有同一市场组合 $M$（包含所有风险资产，按市值加权），
资本市场线成为均衡定价的基准。**

由此推出 CAPM 的核心思想：既然市场组合已经是最优风险组合，任何单个资产的合理回报，
只取决于它**对市场组合风险的贡献**，而不是它自身的总风险。
这个贡献用**贝塔（beta，$\beta$）** 度量：

$$\beta_i = \frac{\operatorname{Cov}(r_i, r_M)}{\sigma_M^2}$$

- **$\operatorname{Cov}(r_i, r_M)$：资产 $i$ 与市场组合收益的协方差**。
- **$\sigma_M^2$：市场组合的方差**。

拆解三步：

- **第一步，为什么要看协方差**：资产放入市场组合后，真正增加组合风险的不是资产自己的波动，而是它与市场的**联动**。协方差度量这种联动。
- **第二步，为什么除以市场方差**：把协方差「标准化」成相对单位。$\beta = 1$ 表示资产波动与市场同步；$\beta > 1$ 表示比市场更「激进」（放大市场波动）；$\beta < 1$ 表示比市场「温和」（防御型）。
- **第三步，$\beta$ 的直觉**：$\beta = 1.5$ 意味着市场涨 1%，该股票平均涨 1.5%；市场跌 1%，它跌 1.5%。**$\beta$ 就是资产对市场风险的「敞口」倍数**。<span class="marginnote">$\beta$ 从哪来？实务中用历史收益对市场收益做<strong>线性回归</strong>，回归系数就是 $\beta$。这与你学《概率论》的最小二乘回归完全一致——金融学的实证方法，正是统计学教科书的应用。</span>

## 2 公式解析：CAPM 与证券市场线

CAPM 的核心方程：

$$E(r_i) = r_f + \beta_i \left[ E(r_M) - r_f \right]$$

- **$E(r_i)$：资产 $i$ 的期望收益**（应得回报）。
- **$r_f$：无风险利率**。
- **$\beta_i$：资产 $i$ 的贝塔**，市场风险的敞口。
- **$E(r_M) - r_f$：市场风险溢价**，承担一单位市场风险的价格。

拆解三步：

- **第一步，时间价值与风险补偿分开**：$r_f$ 是「钱的时间价值」——不承担任何风险也该拿的回报；$\beta_i[E(r_M) - r_f]$ 是「风险补偿」——因为承担了 $\beta_i$ 倍的市场风险而额外要求的回报。
- **第二步，为什么是乘而不是加**：风险补偿必须**成比例**于敞口。$\beta = 0$（无市场风险，如国债）应得 $r_f$；$\beta = 1$（市场组合）应得 $E(r_M)$；$\beta = 2$ 应得 $r_f + 2$ 倍溢价——线性定价是 CAPM 的灵魂。
- **第三步，证券市场线（SML）**：把 $E(r_i)$ 对 $\beta_i$ 画成图，是一条从 $(0, r_f)$ 出发、斜率为市场风险溢价的直线。**所有资产都应落在 SML 上**——落在线上方说明被低估（应得回报更高，值得买），下方说明被高估。

**辨析｜易错点：** 资本市场线（CML）与证券市场线（SML）极易混淆。**CML
的横轴是总风险 $\sigma$，适用于有效组合；SML 的横轴是 $\beta$，
适用于任何资产（包括单个股票）。** CAPM 给单个资产定价用的是 SML，不是 CML。
<span class="marginnote">记忆法：CML 管「组合怎么配」（有效组合的风险—收益），SML 管「资产怎么定」（任意资产的应得回报）。CML 只有一条，SML 上却可以放所有股票——因为每只股票的 $\beta$ 不同，但面对同一条定价线。</span>

## 3 CAPM 的应用：资本成本的估计

CAPM 最重要的实务用途是估计**股权资本成本**——公司股东要求的回报率，
也是公司投资决策的贴现率。

**重点：一家公司该用什么贴现率评估新项目？** 答案是 CAPM
给出的 $E(r_i)$。公司 $\beta$ 越高（业务越波动、杠杆越高），资本成本越高，
能通过的投资项目越少。这就是为什么科技初创公司（$\beta$ 高）融资「贵」、
公用事业（$\beta$ 低）融资「便宜」——CAPM 把风险偏好翻译成了融资成本。

具体操作三步：估计无风险利率（用长期国债收益率）→ 估计市场风险溢价（历史平均约
5%-7%）→ 估计公司 $\beta$（回归历史数据或参照可比公司）。
三项相乘相加即得资本成本。
<span class="marginnote">CAPM 的「市场组合」理论上应包含<strong>所有</strong>风险资产（股票、债券、房地产、人力资本），实务上只能用宽基指数近似。这个「近似」的偏差是 CAPM 长期被争议的源头之一——但作为工程工具，它简单、透明、可复制，所以至今无可替代。</span>

## 4 CAPM 的局限与多因子扩展

CAPM 问世后被广泛使用，也遭受大量实证挑战：

**$\beta$ 与收益的关系不稳定**：实证中 $\beta$ 对收益的解释力远弱于理论预测。
**规模效应与价值效应**：小市值、低市净率股票跑赢 $\beta$ 预测的水平——这两个「异象」无法用 CAPM 解释。
**假设过强**：同质预期、无摩擦市场、单一风险因子，与现实相去甚远。

**辨析｜易错点：** CAPM 的失败不是「公式错了」，而是「单因子不够」。法玛与弗伦奇
1993 年提出**三因子模型**，在 CAPM 上加入规模因子（SMB）
与价值因子（HML）；之后又发展出四因子（动量）、五因子模型。这些多因子模型的逻辑框架仍是
CAPM——**定价方程 = 无风险利率 + Σ（因子敞口 × 因子溢价）**，
只是把「一个市场风险」扩展为「多个系统性风险因子」。
<span class="marginnote">CAPM 到多因子模型的演化，是「用简单模型建立直觉、再用复杂模型逼近现实」的典型科学路径。正如「从极限到大模型」里，线性模型是深度学习的起点，CAPM 是资产定价的第一性原理——不完美，但一切修正都从它出发。</span>

## 5 延伸：CAPM 的检验与争议

CAPM 问世六十多年，是金融学被检验最多的模型之一。它的「功」与「过」都值得展开。

**实证检验的三个核心发现：**

**市场风险确实被定价**：长期看，$\beta$ 高的股票平均收益确实更高——CAPM 的方向正确。
**但 $\beta$ 的解释力有限**：横截面上，$\beta$ 只能解释股票收益差异的一小部分，远低于理论预期。
**无法解释的「异象」**：小市值股、低市净率股（价值股）、高动量股长期跑赢 $\beta$ 预测的水平——这些「超额收益」是 CAPM 的盲区。<span class="marginnote">法玛与弗伦奇 1992 年的经典论文几乎是「对 CAPM 的审判」：他们发现市值与市净率两个变量就能解释大部分收益差异，$\beta$ 反而无关紧要。这个发现直接催生了三因子模型——不是推翻 CAPM 的框架，而是往框架里加因子。注意这个微妙关系：<strong>CAPM 是「一因子模型」，三因子是它的自然推广，不是替代</strong>。</span>

**为什么模型「不完美」还要学？** 三个理由：

**它是第一性原理**：CAPM 建立了「风险 → 应得收益」的定价逻辑，后续一切模型都是它的扩展。
**它是校准基准**：实务中估计资本成本、判断估值高低，仍普遍以 CAPM 为起点，再按实际情况调整。
**它是思考框架**：任何资产定价问题，先问「它的系统性风险敞口是什么、市场给这个风险多高溢价」——这个问法本身来自 CAPM。<span class="marginnote">类比「从极限到大模型」：线性回归不完美，但它是一切模型的地基——你要先懂线性，才谈得上深度网络。CAPM 在资产定价中的地位正是如此：它的假设可以被放松、因子可以增加，但「风险定价」的思维范式由它奠定。学模型的目的不是背诵公式，而是掌握「怎么想问题」。</span>

**辨析｜易错点：** 「CAPM 被证伪 = CAPM 无用」是常见的极端误读。
**没有模型能完全解释现实，模型的价值在于提供「可修正的近似」**——CAPM
的失败不是「公式算错」，而是「单因子不够」。法玛三因子、五因子，乃至机器学习多因子，都在
CAPM 的骨架上叠加——**不是取代它，而是扩展它**。真正该批判的，是「拿着 CAPM
数值当精确答案」的使用方式，而不是模型本身。
<span class="marginnote">实务中的合理用法：用 CAPM 估算一个「大致合理」的资本成本区间，再结合公司质地、行业景气、市场环境做上下调整。把它当「指南针」而非「GPS」——指南针给方向，GPS 才给精确坐标。这个区分，是理论与应用之间最需要把握的尺度。</span>

## 6 小结

- **CAPM 思想**：市场只给系统性风险定价，资产应得回报与其 $\beta$ 线性相关。
- **贝塔** $\beta_i = \operatorname{Cov}(r_i, r_M)/\sigma_M^2$：资产对市场风险的敞口倍数。
- **核心方程** $E(r_i) = r_f + \beta_i[E(r_M) - r_f]$：时间价值 + 风险补偿。
- **SML vs CML**：SML 横轴是 $\beta$、给单资产定价；CML 横轴是 $\sigma$、给有效组合定价。
- **多因子模型**：在 CAPM 骨架上加入规模、价值、动量等因子，实证解释力更强。
