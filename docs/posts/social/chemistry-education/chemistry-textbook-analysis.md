## 为什么从教材分析开始

上一节我们读了课程标准——那是课程的蓝图。但蓝图不会直接走进教室，它必须先被转译成学生手头的**教材**，再由教师转化为课堂。<span class="marginnote">在「课程—教材—课堂」这条链上，教材是承上启下的枢纽：往上承接课程理念，往下约束课堂形态。教师会不会分析教材，直接决定了他是在「用教材教」还是在「照教材念」——两者有本质差别。</span>

一线教师对教材的态度经常在两个极端间摇摆：要么把教材奉为圣经逐字照搬，要么把教材贬为资料自行其是。本节的目标是建立第三种立场：**把教材当作「课程意图的物化文本」来分析、评价、再创造**。会读教材，是化学教师的基本功，也是后面《化学教学设计与教学模式》的前置能力。

## 1 化学教材：课程标准与课堂之间的桥梁

**化学教材（chemistry textbook）**：依据化学课程标准编写、用于化学教学活动的材料，狭义上指教科书，广义上还包括教师用书、实验册、学案、多媒体资源等。<span class="marginnote">「一标多本」是中国课程改革的一个制度性设计：同一个课程标准，允许多家出版社编写不同版本教材（如人教版、鲁科版、苏教版）。教材因此有了竞争与特色——读懂教材的第一步，是先弄清你手里这本教材的「编写取向」。</span>

教材与课程标准的关系是「转译」而非「复刻」：课标规定目标与内容标准，教材决定这些目标用什么素材、什么顺序、什么语言落地。同一堂「物质的量」，不同教材的引入方式可以完全不同——有的从「生活中的计数单位」切入，有的从「化学反应计量关系」切入。

因此，**教材分析的本质是追问三层问题**：编者为什么这样编排（依据）？这样编排想让学生达成什么（意图）？这样的编排在我的学生身上是否有效（适配）？三层问题逐层深入，构成了教材分析的基本框架。

## 2 化学教材的体系结构分析

教材的**体系（system）**指内容组织的整体框架，它是教材分析的第一个层面。化学教材的体系可以从两个维度审视。

**纵向：章节编排的逻辑线索。** 教材按什么主线组织内容，决定了知识的呈现顺序。<span class="marginnote">化学教材的经典编排主线至少有三条：以「元素周期表」为骨架的周期律主线，以「物质分类」为骨架的物质主线，以「化学反应原理」为骨架的原理主线。人教版高中教材大体走「必修以物质与反应为纲、选择性必修以原理为纲」的路线，正是两条主线的接力。</span>

**横向：单元内部的结构层次。** 一个单元通常由若干节组成，每节内部又有「问题引入—知识呈现—活动探究—总结提升」的推进节奏。分析单元时，要看清节的划分依据：是按知识并列划分，还是按认知递进划分？单元首尾有没有呼应？

体系分析的落点是「为什么先学这个、后学那个」。只有先读懂编排的「为什么」，教师才能判断：这个顺序适合我的学生吗？要不要调整、怎么调整？——这是教材二次开发的第一层空间。

## 3 化学教材栏目的功能分析

现代化学教材的鲜明特征，是设置了丰富的**栏目（column）**——用图标与版式区隔的固定模块。栏目不是装饰，每一个栏目都对应特定的教学功能。<span class="marginnote">栏目设计的背后是学习科学：正文承担「陈述性知识」，实验栏目承担「操作性知识」，思考与讨论承担「建构性任务」，资料卡片与科学视野承担「情境与文化」。教师分析教材时把栏目当成「功能标签」，就能一眼看出编者在这里期望什么样的学习活动。</span>

以人教版高中化学教材为例，典型栏目及其功能如下：

| 栏目 | 功能定位 | 教学用法 |
| --- | --- | --- |
| 正文 | 陈述核心知识 | 精讲、结构化 |
| 实验 | 操作性知识与实证 | 演示或学生实验 |
| 思考与讨论 | 引发认知冲突、建构概念 | 小组讨论、汇报 |
| 资料卡片 | 补充背景、拓展视野 | 自主阅读 |
| 科学视野 | 前沿与 STS 内容 | 课外延伸 |
| 方法引导 | 科学方法显性化 | 迁移训练 |
| 整理与提升 | 单元知识结构化 | 复习课、概念图 |

栏目分析的实用价值在于：**它把「教材编排」翻译成「课堂活动预案」**。一篇「思考与讨论」对应一次讨论活动，一个「科学视野」对应一次拓展任务——教材的栏目结构，就是一份预设的教学活动菜单。

## 4 化学教材的内容分析

内容分析回答「教材教了哪些知识、用多少篇幅、什么深度」。教师通常从三个角度切入。

**知识点的覆盖与衔接**：把教材的知识点与课程标准的内容要求逐一比对，看是否有缺漏或超出，看初高中衔接处（如氧化还原、溶液）是否存在坡度过陡的问题。<span class="marginnote">初高中衔接是教材内容分析的高频痛点：初中把氧化还原定义为「得氧失氧」，高中改成「化合价升降」，再往上是「电子转移」。教材若不在衔接处设置过渡，学生的迷思概念就会在这里固化。分析教材时专门看这类「概念升级点」。</span>

**素材的科学性与时代性**：教材中的数据、情境、图片是否准确，是否体现化学的新进展与社会责任（如新能源汽车电池、碳中和与碳捕集）。科学性是底线，时代性是素养要求。

**例题与习题的层次**：例题示范了什么思维路径，习题覆盖了哪些难度层次，是否体现真实情境与开放性。习题的质量往往比正文更能反映教材的素养取向。

## 5 教材使用的策略：从「教教材」到「用教材教」

分析教材的最终目的是更好地使用教材。成熟教师对教材的使用有一套「三用」策略。

**一用：尊重教材的「底」，不偏离课标。** 教材是课标的权威转译，核心知识、核心活动不要轻易跳过去——尊重教材，就是守住课标的底线。

**二用：超越教材的「面」，做二次开发。** 结合学情对教材增、删、调、换：增加本地化情境，删除过难过偏内容，调整顺序以贴合认知逻辑，替换老旧素材。<span class="marginnote">「用教材教」与「教教材」的分水岭就在这里：教教材把教材当终点，用教材教把教材当起点。同样一节「化学反应速率」，用教材教的人会让学生用生活中观察到的快慢现象（铁生锈与炸药爆炸）激活直觉，再把教材的定量定义接上去。</span>

**三用：跳出教材的「框」，回到真实世界。** 教材是课程意图的物化文本，不是化学世界的全部。把教材内容放回真实的化学问题与真实的社会议题中，学生才能获得迁移能力——这是素养导向教学的最后一公里。

## 6 化学教材分析的实践框架与常见误区

把前面的分析维度收拢成一个可操作的实践框架，一线教师在拿到一本新教材时，可以按「四步走」完成分析。

**第一步：整体浏览，把握编写取向。** 通读目录与前言，判断教材的知识主线、栏目体系与风格取向——是偏学科逻辑还是偏生活情境，是重讲授还是重探究。这一步回答「这本教材是一本什么性格的书」。<span class="marginnote">不同版本的化学教材性格差异很大：有的以「元素周期表」为骨架展开，有的以「身边的化学物质」为线索切入。先把握整体取向，后续的细节分析才有坐标系——否则只见树木不见森林。</span>

**第二步：单元拆解，分析知识结构。** 逐单元列出核心概念、能力目标与活动设计，画出单元概念图，看清知识的递进关系与呈现顺序。

**第三步：对照课标，评估覆盖与深度。** 把教材内容与课程标准的内容要求、学业要求逐条比对，标记缺漏、超纲与深度不当之处。

**第四步：落到学情，判断适配与需要。** 结合所教学生的水平，判断哪些内容要精讲、哪些要简化、哪些要补充本地化素材——这一步为「用教材教」的二次开发提供依据。

围绕教材分析，还有三个常见误区需要提醒。

**误区一：把「分析教材」等同「复述教材」。** 分析是要回答「为什么这样编、该怎么用」，而不是把教材内容重新念一遍。复述是搬运，分析是理解。

**误区二：只分析不批判。** 教材是权威转译，但不是真理本身——对教材中的情境陈旧、数据失真、栏目失效之处，教师要敢于指出并改进。「尊重教材」与「批判教材」不矛盾，批判正是为了更好落实课标。

**误区三：把「用教材教」当成「随意删改」。** 二次开发不是任性取舍，而是有依据的增、删、调、换——依据是课标、学情与教学规律。没有依据的「自由发挥」，往往比循规蹈矩更危险。

## 7 核心术语速查表

| 术语 | 含义 |
| --- | --- |
| 化学教材 | 依据化学课程标准编写、用于化学教学活动的材料 |
| 教科书 | 狭义教材，教材的主要形态 |
| 一标多本 | 一个课标对应多个版本的教材 |
| 教材体系 | 内容组织的整体框架，含章节编排主线 |
| 栏目 | 教材中用图标与版式区隔的固定模块 |
| 先行组织者 | 在正式学习前呈现的引导性材料，帮助新旧知识建立联系 |
| 二次开发 | 教师依据课标与学情对教材的增、删、调、换 |
| 用教材教 | 把教材当起点，依据课标与学情进行再创造 |
| 教教材 | 把教材当终点，逐字照搬 |
| 初高中衔接 | 初中学段与高中学段知识过渡处的教学设计 |
| 迷思概念 | 学生头脑中既有的、与科学概念不符的观念 |

## 8 小结

- **教材**是课程标准与学生之间的桥梁，分析教材的本质是追问「编排依据、编者意图、学生适配」三层问题。
- 教材分析分**体系结构、栏目功能、内容深度**三个层面，逐层深入。
- 现代化学教材的**栏目**是教学功能的标签：正文对应陈述、实验对应操作、思考与讨论对应建构。
- 教材使用的三用策略：**尊重底、超越面、跳出框**，实现从「教教材」到「用教材教」的转变。
- 「一标多本」背景下，读懂教材的编写取向是教师的基本功。

在下一节，我们把视线从「教材」转向「学生」——**化学学习论与学习心理**：学生的大脑是如何理解化学的，教师的教法如何与学习的规律合拍。
