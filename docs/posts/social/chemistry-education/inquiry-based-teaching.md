## 为什么从探究式教学开始

上一节我们讲了实验教学。但实验若只是「照方抓药」，学生的收获就只停留在操作层。素养时代的化学课堂，把实验推向更高形态——**探究**。<span class="marginnote">探究式教学是建构主义学习理论在课堂上的制度化表达，也是化学学科核心素养「科学探究与创新意识」的主要落点。它的基本信念是：<strong>学生应当像科学家那样经历知识形成的过程，而不是只接收知识形成的结果。</strong></span>

科学探究之于化学教育，有着双重身份：它既是化学学习的内容（学生要学科学探究的方法），又是化学学习的方式（用探究的方式学化学）。理解这双重身份，是进入探究式教学的第一把钥匙。

## 1 科学探究：科学家怎么工作，学生就怎么学

**科学探究（scientific inquiry）**：科学家用以研究自然、寻求规律的系统方法。化学课程标准把科学探究的过程要素概括为一套相对完整的流程：**提出问题、猜想与假设、设计方案、进行实验、收集证据、解释与结论、反思与评价**。<span class="marginnote">这七个要素不是必须逐条走完的固定套路，而是科学探究的「家族相似」描述——有的探究突出假设，有的突出证据，有的突出解释。把七要素当清单逐项执行，探究就退化为表演；把七要素当认知支架，探究才有灵魂。</span>

把科学家的探究迁移到课堂，就得到**探究式教学（inquiry-based teaching）**：教师围绕问题组织教学，学生经历类似科学家的过程来获取知识、发展能力。它的本质特征有二：**问题是起点**（学习由真实问题驱动）、**学生是主体**（学生自己设计方案、收集证据、得出结论，而非被动接受）。

## 2 化学探究式教学的基本环节

一节化学探究课，通常经历六个环节，正好对应科学探究的过程要素。

**环节一：创设情境、提出问题。** 探究始于问题，问题源于情境。好的问题应当「真实且有探究空间」——「暖宝宝为什么发热」比「铁生锈的条件是什么」更能驱动探究。教师的作用是把大问题拆解成可操作的小问题。<span class="marginnote">问题设计是探究教学的起点也是难点。好问题的三个标准：有真实情境支撑、有认知冲突驱动、有探究路径可达。若问题太封闭（答案一眼看出），探究失去意义；若问题太开放（无从下手），探究失去方向。</span>

**环节二：猜想与假设。** 学生基于已有知识提出可能的解释——「我认为铁生锈与氧气有关」「我认为还与水有关」。假设要可检验，这是科学与猜想的区别。教师应鼓励多元假设，并把学生的假设显性化。

**环节三：设计方案。** 学生设计实验方案验证假设——选择变量、控制变量、安排步骤。「铁生锈条件的探究」的经典设计，就是通过控制变量，分别检验铁与氧、铁与水的作用。

**环节四：进行实验、收集证据。** 学生动手实验、记录现象与数据。证据是探究的通货——只有证据才能检验假设。

**环节五：解释与结论。** 学生整理证据、分析现象、得出解释，并与假设比对。「铁在潮湿空气中生锈最严重」的证据，支持了「铁生锈是铁与氧气、水共同作用」的结论。

**环节六：反思与交流。** 学生汇报结果、比较不同方案、反思过程、提出新问题。「哪些方案不严谨？误差来自哪里？还有什么值得探究？」——反思让一次探究的收获最大化。

## 3 化学探究式教学的实施策略

环节人人会说，难在实施。三个策略决定探究课能否真正落地。

**策略一：给「支架」不给「答案」。** 探究不等于放任自流。教师通过问题链、任务单、检查点提供支架——「你的假设依据是什么」「你打算怎么控制变量」，让学生在支架内自主探究。支架随探究深入逐步撤除，这就是「脚手架」的教学隐喻。<span class="marginnote">维果茨基的「最近发展区」理论是支架教学的心理学基础：学生在教师帮助下能达到的水平，高于独立能达到的水平。探究课的任务，是把帮助精准地放在「学生够一够能到」的位置，既不大包大揽，也不撒手不管。</span>

**策略二：用真实情境激活动机。** 探究的选题贴近生活与社会，动机自然产生。「测定雨水 pH 判断酸雨」「鉴别食品中的添加剂」——真实问题自带探究意愿，也自带安全与伦理的边界。

**策略三：处理好「预设」与「生成」。** 探究课最大的魅力与风险，都在于学生可能走向教师预设之外。成熟教师会预设「学生可能的错误路径」，并在关键时刻用追问把生成拉回目标——「你的方案能排除水的干扰吗」——既尊重生成，又不失方向。

## 4 核心对比表：接受式教学与探究式教学

| 维度 | 接受式教学 | 探究式教学 |
| --- | --- | --- |
| 知识来源 | 教师讲授、教材呈现 | 学生探究建构 |
| 学生角色 | 接受者、记忆者 | 发现者、建构者 |
| 教师角色 | 讲授者、组织者 | 引导者、支架提供者 |
| 问题地位 | 练习与巩固 | 学习起点与驱动 |
| 认知功能 | 高效传递系统知识 | 深度理解与迁移 |
| 主要局限 | 易被动、迁移弱 | 耗时、对教师要求高 |

两种模式不是对立的两极，而是一条连续谱的两端：**封闭程度越低、学生自主越高，越接近探究；反之越接近接受。** 成熟课堂常在谱系上滑动——知识奠基用接受式，素养突破用探究式。

## 5 探究式教学的评价与困境

探究式教学并非万能，直面它的困境，才能更好地用它。

**时间困境**：完整探究耗时是接受式的数倍，课时紧张时难以逐课开展。缓解之道是「局部探究」——一次课只探究一个环节（如只做方案设计或只做误差分析），把探究的完整历程分散到多节课中完成。

**资源困境**：探究需要实验器材、开放实验室、小班组织，城乡与校际差异巨大。替代方案包括数字化实验（传感器采集数据）、微型实验、虚拟仿真实验等。<span class="marginnote">数字化实验（手持技术）是探究教学的重要增强：pH 传感器可以连续记录中和滴定全程的 pH 变化，画出一条平滑的滴定曲线——这是传统实验「一滴一测」难以企及的。数字化实验把「收集证据」的环节做得更精细，也让探究式教学在资源受限处多了一条出路。</span>

**评价困境**：纸笔考试难以测量「会不会探究」。破解之道是表现性评价与过程性评价：用探究活动表现、实验报告、科学日志来收集素养证据——这与《化学教育测量与评价》一节的理念完全同构。

**教师困境**：探究课对教师的学科功底、课堂调控、追问艺术要求极高。教师自己不经历探究、不理解探究的本质，探究教学就会徒有其形。教师专业发展中「亲历探究」，是破解这一困境的根本路径。

## 6 探究式教学的实施案例：以「影响化学反应速率的因素」为例

把抽象的原则落到一节课上，探究教学的长相就清楚了。以高中化学「影响化学反应速率的因素」为例，走一遍完整设计。

**情境与问题**：展示两张照片——常温下铁钉生锈缓慢，而埋在盐水中、与活泼金属接触的铁锈蚀更快。提问「为什么反应的快慢会不同？哪些因素在起作用？」情境来自真实生活，问题有探究空间。<span class="marginnote">这个情境设计暗含了「提出问题」的素养要求：把现象差异转化为可研究的变量问题——「温度、浓度、接触面积、催化剂，哪个影响速率、怎么影响」。好情境的标准是：现象足够近、问题足够真、路径足够宽。</span>

**猜想与假设**：学生分组讨论，提出假设：温度升高速率加快、浓度越大速率越快、催化剂能改变速率、接触面积越大反应越快。教师把假设写进板书，形成可检验的假设清单。

**设计与实施**：各组认领一个变量设计实验。探究「温度的影响」，可用硫代硫酸钠与稀硫酸反应，比较不同温度下溶液出现浑浊的快慢；探究「浓度的影响」，可用不同浓度盐酸与镁条反应，观察气泡产生的剧烈程度。<span class="marginnote">硫代硫酸钠与稀硫酸反应生成不溶性硫单质，溶液由澄清变浑浊——「浑浊出现的时间」就是这个实验的可观察指标，也是一个把「速率」从抽象变具象的经典载体。</span>

**证据与结论**：各组汇报数据，得出「温度升高、浓度增大、接触面增大、催化剂能加快反应速率」的结论。教师引导反思：哪个实验控制变量最严谨？误差可能来自哪里？

**反思与拓展**：把结论放回生活——为什么食物放冰箱能保鲜？为什么汽车尾气催化转化器用催化剂？探究从课堂延伸到真实世界，素养在迁移中固化。

这个案例示范了探究教学的核心要义：**问题真实、假设多元、证据充分、反思到位**。它不是一次完美的表演，而是一次完整的科学过程体验——学生经历的不只是「知道结论」，更是「得出结论」。

## 7 核心术语速查表

| 术语 | 含义 |
| --- | --- |
| 科学探究 | 科学家研究自然、寻求规律的系统方法 |
| 探究式教学 | 围绕问题组织、学生经历探究过程的教学 |
| 提出问题 | 从情境中提炼出可研究问题的环节 |
| 猜想与假设 | 基于已有知识提出可检验的解释 |
| 控制变量 | 只改变一个变量、保持其他变量不变的实验设计方法 |
| 收集证据 | 通过实验、观察、查阅资料获取证据 |
| 解释与结论 | 依据证据形成解释、得出结论 |
| 反思与评价 | 对探究过程与结论进行批判性审视 |
| 支架 | 教师为支持学生探究提供的适度帮助 |
| 最近发展区 | 学生独立水平与在帮助下可达到水平之间的区域 |
| 局部探究 | 只探究部分环节的探究形式，节约课时的策略 |
| 表现性评价 | 在真实或模拟任务中评价素养表现的方式 |

## 8 小结

- **科学探究**是科学家研究自然的过程，其七要素是探究教学的认知支架，而非必须走完的清单。
- 化学探究课的六环节：**问题→假设→方案→实验→结论→反思**，一一对应科学探究的过程。
- 实施探究的关键策略：**给支架不给答案、用真实情境、处理好预设与生成**。
- 接受式与探究式是连续谱的两端，成熟课堂在谱系上按目标与学情滑动。
- 探究教学直面**时间、资源、评价、教师**四重困境，破局之道在于局部探究、技术赋能、表现性评价与教师亲历。
