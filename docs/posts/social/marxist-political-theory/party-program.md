# 党的纲领与无产阶级运动

## 为什么从纲领开始

上一篇讲了先锋队政党的性质。但一支队伍光有「谁」还不行，还要有「往哪走、怎么走」——这就是**纲领**。

一个没有纲领的政党，就像没有地图的远征军：行动越坚决，迷路越远。

马克思主义政党理论的独特之处在于，它把纲领与运动的关系讲得清清楚楚。

从课程体系看，这篇把第八级《比较政治学》的政党纲领研究、第八级《战略管理》的目标分解逻辑，接到《共产党宣言》第二章的经典文本上。读懂纲领，才能读懂无产阶级运动的「路线图」。

## 1 纲领是什么：党的「一面公开的旗帜」

**党的纲领（party program）**：党公开申明的、关于近期与长远奋斗目标以及实现途径的正式文件。它是党的性质、宗旨、目标的外在表达。

恩格斯有句名言：**一个党的纲领是一面公开树立起来的旗帜，而外界就是根据它来判断这个党。**

这句话有两层含义：对党内，纲领统一思想、凝聚意志；对党外，纲领展示方向、吸引群众、让敌人看清对手。没有纲领或纲领模糊，党就失去了与外界对话、与内部凝聚的共同语言。<span class="marginnote">1847—1848年，共产主义者同盟委托马克思、恩格斯起草纲领，这就是《共产党宣言》——历史上第一个无产阶级政党的「公开旗帜」。它只用了不到一万字，就规定了无产阶级政党的全部基本立场，成为后来一切共产党纲领的母本。</span>

纲领的地位如此之高，正因为**方向错了，一切努力都是南辕北辙**。党的纲领质量，直接决定运动的成败。

## 2 最低纲领与最高纲领：一个硬币的两面

马克思主义政党纲领的核心结构，是**最低纲领**与**最高纲领**的区分：

**最高纲领**——实现共产主义：消灭私有制、消灭阶级、实现人的自由全面发展。这是最终目标，方向恒定不变，是共产党人「旗帜上的大字」。

**最低纲领**——在当前阶段的具体目标：推翻当前阻碍生产力发展的旧制度、建立无产阶级政权（在条件成熟时）、完成当前阶段的革命任务。它是通往最高纲领的「路标」与「台阶」。

两者的关系是辩证的：**最高纲领统率最低纲领**——每一步斗争都指向最终目标，不为眼前的胜利放弃长远方向；**最低纲领支撑最高纲领**——不完成当前阶段的革命任务，最高纲领就是空谈。

列宁把这种关系概括为：**马克思主义者在斗争中「既要有最高纲领，也要有最低纲领」，当前任务服从长远方向，长远方向又须通过当前任务实现。**<span class="marginnote">《共产党宣言》的原话是：共产党人在当前的运动中「始终代表运动的未来」——他们参加当前斗争，但眼光始终盯着最终目标。这就是「既立足当前、又指向未来」的纲领辩证法。</span>

## 3 共产党人的特殊地位：无私又自觉

《共产党宣言》第二章用一段著名的话界定了共产党人与整个无产阶级的关系，这是理解党的纲领的钥匙：

**在理论方面，**共产党人胜过其余无产阶级群众的地方，在于他们了解无产阶级运动的条件、进程和一般结果——别人靠自发经验，共产党靠科学理论。

**在实践方面，**共产党人是各国工人政党中最坚决的、始终起推动作用的部分——冲锋在前、坚守到底。

**在利益关系上，**共产党人没有任何同整个无产阶级利益不同的利益——不谋私利，只代表无产阶级整体。<span class="marginnote">这段论述回答了一个尖锐质疑：共产党是不是「凌驾于无产阶级之上的特权集团」？答案是否定的——党不是无产阶级之外的特殊阶层，而是无产阶级中最自觉、最坚决、最无私的那一部分，它的「特殊」只在觉悟与作用上，不在利益上。</span>

由此可以总结党的纲领的两条原则：**阶级立场上，与无产阶级利益完全一致；理论行动上，比群众更自觉、更坚决。**前者保证党不变质，后者保证党能领导。

## 4 公式解析：纲领—战略—策略的分解链

把「纲领如何指导运动」拆成一条可以操作的链条：

$$
\text{最高纲领(最终目标)} \;\xrightarrow{\text{分解为阶段任务}}\; \text{最低纲领(当前目标)} \;\xrightarrow{\text{化为行动方案}}\; \text{战略与策略}
$$

- **第一段**：最高纲领是方向（消灭阶级、实现共产主义），不可动摇，也不可当作当下立刻执行的要求。
- **第二段**：最低纲领把长远方向分解为当前阶段的具体任务——不同国家、不同时期，最低纲领的具体内容不同。
- **第三段**：战略是全局性的行动路线（谁是主要敌人、联合谁、打击谁），策略是具体环境下的灵活手段（罢工、议会、起义、谈判）。
- **运用要点**：策略可以千变万化，战略保持相对稳定，最高纲领永远不动摇——**「原则的坚定性与策略的灵活性」相统一**，是马克思主义政党行动的经典准则。

这条链解释了党的纲领为什么既不能「过左」（把最高纲领当眼前任务，跳过阶段）也不能「过右」（满足于最低纲领，丢掉最终目标）。**左右摇摆的根源，都在于这一条分解链上的某一段出了问题。**

## 5 核心对比表：两种纲领观

无产阶级政党与其他政党的纲领，立场完全不同。用**核心对比表**对照：

| 维度 | 议会改良型政党 | 无产阶级政党 |
| --- | --- | --- |
| 最终目标 | 执政掌权、维持现行制度 | 消灭私有制、实现共产主义 |
| 当前纲领 | 迎合选民的具体政策包 | 完成当前阶段革命任务 |
| 目标与手段 | 目标可随民意调整 | 原则坚定、策略灵活 |
| 利益立场 | 代表特定选票集团 | 代表无产阶级整体利益 |
| 与运动关系 | 竞选工具 | 运动的旗帜与指南 |

这张表的要害在最后一行：**对议会政党，纲领是拉票的工具，可以随民意摇摆；对无产阶级政党，纲领是运动的旗帜，是「按图行军」的地图。**前者是「纲领服务选举」，后者是「运动服从纲领」——完全相反的两种逻辑。

## 6 案例：历史上有名的党纲之争

党的纲领从来不是纸上谈兵，它是党内路线斗争的焦点。1875年，德国社会民主工党与拉萨尔派合并，制定了《哥达纲领》，其中充斥着拉萨尔主义的错误主张。马克思专门写了《哥达纲领批判》逐条批驳——这就是「按劳分配」「过渡时期」等经典论述的出处。

恩格斯晚年又对《爱尔福特纲领》草案提出批评，坚持党的纲领不能模糊阶级斗争与无产阶级专政的原则。这些争论说明：**纲领的每一句话都可能被机会主义利用，原则的坚持必须体现在纲领的字句里。**

这一历史给今天的启示是：一个政党的成色，首先要看它的纲领——看它最终目标是否坚定、当前任务是否清醒、二者是否在纲领中统一。

## 7 术语速查表

本专题术语较多，下表把本篇出现的核心概念与一句话释义集中列出，供检索与复习：

| 术语 | 一句话释义 |
| --- | --- |
| **党的纲领** | 党公开申明的奋斗目标与实现途径，是「一面公开树立起来的旗帜」 |
| **最高纲领** | 实现共产主义：消灭私有制、消灭阶级、实现人的自由全面发展 |
| **最低纲领** | 当前阶段的具体革命任务，是通往最高纲领的台阶 |
| **战略** | 全局性的行动路线：主要敌人、联合对象、打击方向 |
| **策略** | 具体环境下的灵活手段：罢工、议会、起义、谈判 |
| **共产主义者同盟** | 委托马克思、恩格斯起草《共产党宣言》的第一个无产阶级政党组织 |
| **原则的坚定性** | 最高纲领与基本战略不动摇 |
| **策略的灵活性** | 具体手段随环境而变、千变万化 |

这张速查表与前面的核心对比表配合使用：对比表解决「概念之间如何区分」，速查表解决「每个概念是什么」。

## 8 小结

- **纲领的定义**：党公开申明的奋斗目标与途径，是「一面公开树立起来的旗帜」。
- **双层结构**：最高纲领（共产主义）+ 最低纲领（当前阶段任务），长远方向与当前行动统一。
- **共产党人地位**：理论上有自觉、实践上最坚决、利益上与无产阶级完全一致。
- **分解链条**：最高纲领 → 最低纲领 → 战略与策略；原则坚定性与策略灵活性统一。
- **两种纲领观**：议会政党以纲领服务选举，无产阶级政党使运动服从纲领。
- **两种倾向**：过左（跳过阶段）与过右（丢掉目标），都源于分解链的断裂。
- **纲领之争**：从《哥达纲领批判》到《爱尔福特纲领》，纲领是路线斗争的焦点。

在下一节，我们把「专政」与「民主」这一对范畴放到一起检验：无产阶级国家内部的权力，是如何在民主与专政两端取得平衡的——这就是《民主与专政的辩证统一》。
