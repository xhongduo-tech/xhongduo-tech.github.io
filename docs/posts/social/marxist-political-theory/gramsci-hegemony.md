# 葛兰西：文化领导权与市民社会

<div class="epigraph">
<p>国家 = 政治社会 + 市民社会，也就是说，国家是披上了强制的甲胄的领导权。</p>
<footer>—— 安东尼奥 · 葛兰西（Antonio Gramsci），《狱中札记》</footer>
</div>

## 为什么从葛兰西开始

前面的国家理论都强调暴力——军队、警察、监狱。但一个统治者光靠暴力活不下去：它还需要让大多数人**「心甘情愿」地服从**。

谁把这个问题推进到了理论前沿？——葛兰西，一个在墨索里尼监狱里度过生命最后十年的意大利共产党人。他补上了马克思主义国家理论中最缺的一块：**文化领导权**。

从课程体系看，这篇是第八级《传播学》《社会学理论》与第七级《批判理论》的枢纽，也是理解后两篇（阿尔都塞、普兰查斯）的钥匙。

葛兰西把「国家」从暴力机器扩展为一台「暴力 + 同意」的复合装置。

## 1 葛兰西其人：狱中写成的理论

安东尼奥 · 葛兰西（1891—1937），意大利共产党创始人之一，1921年建党后任总书记。1926年，法西斯头目墨索里尼在意大利建立独裁统治，葛兰西被逮捕，判处20年监禁。

在狱中，葛兰西利用监狱提供的纸笔（经反复斗争争取来的写作权），写下了32本笔记——后人辑为《狱中札记》（Prison Notebooks）。

**这批写于铁窗内的思考，成了20世纪马克思主义最重要的文献之一。**1937年，葛兰西在获释前夕病逝于罗马的医院。<span class="marginnote">葛兰西理论的独特处境值得留意：他面对的不是沙俄式的落后专制，而是意大利这个「先进资本主义」社会——法西斯居然能赢得广泛「同意」。这个问题逼着他思考：西方社会的统治，凭什么如此稳固？答案就是市民社会与文化领导权。</span>

## 2 市民社会：被忽略的统治层

葛兰西对马克思主义国家理论的最大贡献，是重新定义了**市民社会（civil society）**在国家结构中的位置：

在经典马克思主义那里，「经济基础—上层建筑」的两层结构里，国家（政治上层建筑）直接立于经济基础之上。葛兰西则把上层建筑拆成两个层面：**政治社会**（政权、军队、警察、法庭、官僚机构——暴力的领域）与**市民社会**（学校、教会、工会、报刊、文化组织、家庭——观念与舆论的领域）。二者合起来才是完整的国家：**国家 = 政治社会 + 市民社会**。<span class="marginnote">注意葛兰西在东西方之间划的界线：<strong>在俄国等东方落后社会，国家「就是一切」</strong>——政治社会直接支配一切；<strong>在西方先进社会，市民社会非常发达</strong>，像战壕体系一样层层设防，政权即使被攻占，市民社会的观念防线仍能支撑旧秩序。</span>

由此推论：**西方社会的统治，主要不是靠枪炮，而是靠市民社会里持续生产出来的「同意」。**统治者在文化、教育、舆论领域不断再生产自己的世界观，让被统治者把这种世界观当作「常识」接受下来——这就是**文化领导权（cultural hegemony）**。

## 3 文化领导权：靠「同意」而非「强制」的统治

**文化领导权（hegemony）**：统治阶级通过文化和意识形态领域，使自己的世界观成为全社会「自愿接受」的普遍观念，从而实现对被统治阶级的**道德与思想领导**，而不仅仅依靠政治强制。

它的运作特点有三个：**非暴力性**——领导权主要靠教育、传播、日常生活的渗透，而不是直接的强制；**日常性**——它藏在教科书、新闻、流行文化、宗教仪式里，让人习焉不察；**被接受性**——被统治者「同意」这套观念，把它当成理所当然的常识，甚至自愿为其辩护。<span class="marginnote">举一个贴切的例子：现代社会的「消费主义」——人们把「通过消费实现幸福」当作天经地义，这正是资产阶级世界观通过媒体与商业文化成功「领导」了大众思想的典型案例。它不需要警察逼你购物，因为你的欲望本身已经被塑造。</span>

文化领导权的意义在于：**它解释了为什么「被统治的阶级有时反而拥护统治者」**——因为观念层面已被领导。这也回答了上一篇遗留的问题：光靠暴力机器无法长期统治，必须同时赢得「同意」。

## 4 阵地战：革命策略的革命

葛兰西的文化领导权理论，直接引出革命策略的重大转向：

**运动战 vs 阵地战。**列宁主义在东方的策略是「运动战」——集中力量、正面强攻、一举夺取国家政权（十月革命的模式）。葛兰西认为，在市民社会发达的西方，运动战不再适用：**政权只是外围的战壕，真正的战场在市民社会的观念阵地。**革命者必须在市民社会里进行持久的「阵地战」——一个一个文化阵地地争夺：学校、报刊、工会、教会、大众文化——逐步赢得文化领导权，最后才谈得上夺取政治权力。<span class="marginnote">「阵地战」的比喻来自现代堑壕战：强攻敌人坚固的堑壕体系只会白白送命，必须一寸一寸地攻占阵地。西方发达社会的市民社会正是这样一套「堑壕体系」——文化战线的持久争夺，先于、并支撑着政治权力的争夺。</span>

**有机知识分子。**谁来完成阵地战？葛兰西提出：每个阶级都会产生自己的**有机知识分子**——不是脱离群众的「传统文人」，而是扎根于本阶级、在文化阵地上为阶级利益作斗争的组织者、教育者、宣传者。无产阶级要夺取文化领导权，就必须培养自己的有机知识分子，打进市民社会的各个阵地。

## 5 核心对比表：强制与领导权的统治

葛兰西把统治手段一分为二，用**核心对比表**厘清：

| 维度 | 强制（政治社会） | 领导权（市民社会） |
| --- | --- | --- |
| 领域 | 政权、军队、警察、法律 | 学校、教会、报刊、文化 |
| 手段 | 暴力、制裁、镇压 | 教育、传播、舆论、习惯 |
| 对应权力 | 直接政治权力 | 文化、道德、思想权力 |
| 被统治者状态 | 被迫服从 | 自愿同意 |
| 失效标志 | 被暴力推翻 | 意识形态信任瓦解 |
| 典型例证 | 戒严、逮捕、封锁 | 教科书、新闻、流行文化 |

这张表的实践结论：**成熟的统治 = 强制 + 领导权并用**。只靠强制的统治是脆弱的（一压就垮），只靠领导权的统治也不能持久（没枪杆子撑腰）。葛兰西对后世的影响（从阿尔都塞到福柯、从文化研究到传播批判）都从这里展开。

## 6 延伸：葛兰西思想的当代回响

葛兰西的概念几乎遍布当代人文与社会科学的每一个角落：文化研究（伯明翰学派）用它分析大众文化如何被协商与抵抗；传播政治经济学用它解读媒体所有权与意识形态的关系；国际关系学界甚至发展出「霸权稳定论」来讨论世界秩序。

在中国语境里，葛兰西的「领导权」与「阵地战」思想也常被用来理解舆论阵地、意识形态工作的极端重要性——正因为观念能决定「同意」，思想文化战线才需要主动建设。

但也有一句忠告：领导权理论容易被误读成「只要宣传到位就能统治」。葛兰西本人的完整意思是：**领导权必须以物质基础与强制力量为后盾**——没有枪杆子撑腰的同意是脆弱的，没有同意支撑的枪杆子也难长久。

## 7 术语速查表

本专题术语较多，下表把本篇出现的核心概念与一句话释义集中列出，供检索与复习：

| 术语 | 一句话释义 |
| --- | --- |
| **文化领导权** | 统治者通过教育、传播、日常文化使被统治者「自愿同意」其世界观 |
| **市民社会** | 学校、教会、报刊、文化组织等观念与舆论领域 |
| **政治社会** | 政权、军队、警察、法律等暴力领域 |
| **阵地战** | 在市民社会观念阵地的持久争夺，先于政治权力的夺取 |
| **运动战** | 集中力量正面强攻、一举夺取政权的斗争方式 |
| **有机知识分子** | 扎根本阶级、在文化阵地为阶级利益斗争的知识分子 |
| **强制** | 依赖暴力与制裁的统治手段 |
| **同意** | 依赖教育、舆论与日常习惯的统治手段 |

这张速查表与前面的核心对比表配合使用：对比表解决「概念之间如何区分」，速查表解决「每个概念是什么」。

## 8 延伸讨论

把葛兰西放回本专题的国家理论谱系，他补上的正是「暴力之外」的那一半：前文的国家论都强调强制与镇压，葛兰西则证明——统治还有一张「同意」的脸，而这张脸藏在市民社会的日常文化里。

这一补充彻底改变了「革命如何发生」的答案：不只是攻占冬宫，更是先攻占人心。它与下一篇阿尔都塞的「意识形态国家机器」共同构成马克思主义文化政治学的双翼。

## 9 小结

- **葛兰西其人**：意大利共产党创始人，狱中撰成《狱中札记》，1937年病逝。
- **市民社会理论**：国家 = 政治社会 + 市民社会；西方发达社会的统治主要靠市民社会的观念生产。
- **文化领导权**：统治者通过教育、传播、日常文化让被统治者「自愿同意」其世界观，而非仅靠强制。
- **阵地战**：在市民社会发达地区，革命须以文化阵地的持久争夺（阵地战）为先导，而非正面强攻（运动战）。
- **有机知识分子**：扎根本阶级、在文化阵地为阶级利益斗争的知识分子，是争夺领导权的主力。
- **综合统治**：强制与领导权并用，才构成成熟的国家统治。
- **当代回响**：文化研究、传播政治经济学、国际关系「霸权论」均受葛兰西影响。
- **反误读**：领导权不以否定强制为前提——同意与强制互为支撑。
- **一句话总结**：国家 = 政治社会（强制）+ 市民社会（同意），成熟的统治两者并用。
- **延伸线索**：葛兰西的「同意」与列宁的「强制」并不冲突——东方靠强制，西方靠同意，殊途同归。
- **当代应用**：分析媒体、教育、舆论问题时，葛兰西的领导权框架至今是最常用工具。
- **记忆锚点**：文化领导权 = 让被统治者「自愿」接受统治者的世界观。

在下一节，我们顺着葛兰西的思路往前推进：意识形态国家机器到底是怎样「不用暴力地运作暴力」的——这就是《阿尔都塞：意识形态国家机器》。
