# 国家的本质：阶级统治的工具

<div class="epigraph">
<p>国家是经济上占统治地位的阶级的国家，这个阶级借助于国家而在政治上也成为占统治地位的阶级。</p>
<footer>—— 弗里德里希 · 恩格斯（Friedrich Engels），《家庭、私有制和国家的起源》</footer>
</div>

<div class="article-byline">
<p>第八级 · 社会科学 · 马克思主义政治学与国家理论 ｜ 列宁《国家与革命》第一章 ｜ 2026-08-07</p>

## 为什么从国家本质开始

上一篇说清了国家从哪来。但「从哪来」只是入口，真正决定政治判断的是下一个问题：**国家到底为谁服务？**

对这个问题的回答，把政治学分成截然对立的两派——一派把国家打扮成「全民利益的守护者」，另一派（马克思主义）剥掉这层外衣，指出国家是阶级统治的工具。

从课程体系看，这篇为第八级《法理学》《行政管理》提供了国家观的地基，也是本专题「国家篇」的轴心：国家本质定了，职能、革命、专政的讨论才有支点。

## 1 国家的定义：一个冷静的陈述

恩格斯在《家庭、私有制和国家的起源》中给了国家一个著名的描述性定义。它不浪漫，但精确：

**国家是这样一个组织：它是社会在一定发展阶段上的产物，是社会分裂为不可调和的对立面（阶级）时，为把冲突保持在「秩序」范围内而产生的、表面上驾于社会之上的力量；这个力量设立特殊的公共权力（常备军、警察、法庭、监狱），按地区划分国民，靠捐税供养，并日益同社会相异化。**<span class="marginnote">这个定义最锋利的词是「表面上」：国家看起来站在全社会之上、不偏不倚，但「表面上驾于社会之上」恰恰暗示——它的实质立场在某一方。列宁在《国家与革命》中专门强调这层「表面」与「实质」的落差。</span>

把定义拆开，有两个要素缺一不可：**特殊的公共权力**（与氏族社会武装全体成员不同，国家拥有一支脱离生产的职业化暴力）与**按地区划分国民**。这两条加起来，就是国家的形式特征；但形式特征不等于本质。

## 2 本质一：国家是阶级统治的工具

国家的本质是什么？马克思主义的回答只有一句：**国家是经济上占统治地位的阶级在政治上的统治工具。**

为什么「经济上占统治地位的阶级」能独占国家？逻辑不难推：在私有制社会里，谁掌握生产资料，谁就掌握经济命脉；经济上的统治必然要寻求政治上的保障——用军队、警察、法律把既得的经济地位固定下来，把被剥削阶级的挑战压制下去。

恩格斯说得很直白：国家「在本性上是和私有制紧密联系在一起的」，它存在的首要任务就是维护统治阶级赖以生存的经济秩序。

于是国家的面目就清楚了：**它不是超阶级的仲裁者，而是统治阶级的「总委员会」。**它调节统治阶级内部的矛盾，把共同的对立面压制下去，同时用法律把现行秩序宣布为「正当」与「永恒」。<span class="marginnote">这里要纠正一个常见误解：国家有时也会出台「保护工人」「救济穷人」的法律，也会调停劳资纠纷。但这不改变本质——让步是为了维持整个剥削秩序的长治久安，是统治策略而非立场转移。列宁讽刺这种「骑墙」的国家形象不过是阶级统治的遮羞布。</span>

## 3 本质二：国家是阶级矛盾不可调和的产物

与「阶级统治工具」配套的是另一个本质命题：**国家是阶级矛盾不可调和的产物和表现。**这句话要倒过来理解才不漏掉重点：

不是说「调和了矛盾才产生国家」，而是说——**正是矛盾已经尖锐到无法调和，才需要国家这个暴力机关来强制压制。**矛盾越不可调和，统治一方越需要强化暴力；一旦矛盾消失了，国家也就没有存在的理由了。

这个命题同时否定了两类错误国家观。一类是**超阶级论**——把国家看作代表全社会公共利益的中立机构（如福利国家的神话）；另一类是**调和论**——把国家看作社会各集团平衡的仲裁者。

列宁指出，国家恰恰「是在社会分裂为不可调和的对立面时产生的」，它的存在本身就证明矛盾无法靠社会自身解决。<span class="marginnote">一个判断技巧：<strong>看国家是否以「压制被统治阶级」为其存在前提。</strong>只要还需要一支专门对付民众的武装与一套专门维护私有财产的法律，国家的阶级本质就没有消失——无论它挂着什么招牌。</span>

## 4 国家的相对独立性：一个辩证补充

国家由统治阶级支配，但它的运作不是一把直来直去的刀。国家具有**相对独立性**——它一方面忠诚于统治阶级的长远利益，另一方面又必须维持自身的存在（收税、维持秩序、应对危机），因此有时会表现出「超越」某个具体阶级集团的姿态。

这种相对独立性的极端形态，是**国家与社会的分离乃至异化**：官吏成为脱离生产、靠俸禄生活的特殊阶层，军队成为只效忠命令的职业机器。

正因如此，国家既可能被一个阶级集团直接操控，也可能在特殊时刻（如两个敌对阶级势均力敌时）获得短暂的「自主」——后一种情形，正是第二十一篇《普兰查斯与米利班德》争论的核心。

## 5 核心对比表：两种国家本质观

把马克思主义的国家本质观与通行政治学中的主流看法并排，用**核心对比表**呈现：

| 维度 | 超阶级论（公共国家观） | 马克思主义（阶级国家观） |
| --- | --- | --- |
| 国家本质 | 全社会公共利益的中立代表 | 经济上占统治地位的阶级的统治工具 |
| 国家与阶级 | 超越阶级之上 | 阶级矛盾的产物，服务统治阶级 |
| 暴力机关 | 维护公共秩序的必要设施 | 压制被统治阶级的特殊公共权力 |
| 法律 | 公平正义的化身 | 把现行秩序合法化的统治工具 |
| 国家命运 | 人类社会的永恒伴侣 | 随阶级消灭而消亡的历史现象 |
| 代表文本 | 社会契约论、自由主义国家观 | 列宁《国家与革命》第一章 |

这张表的最后一行最要紧：**如果国家是永恒的中立机构，那么革命与打碎国家机器就是无理取闹；如果国家是阶级统治的工具，那么被压迫阶级的目标就不是「改良国家」而是「夺取政权」。**这一分歧贯穿第二篇剩余各篇——从国家职能到革命、从专政到国家消亡。

## 6 延伸：国家本质论的思想史脉络

「国家是什么」是政治学史上最古老的追问之一。柏拉图的「理想国」把国家看作正义的化身，亚里士多德把国家看作「最高的善」的共同体，中世纪神学把国家归于神的安排，近代社会契约论把国家归于人民的约定。

马克思主义的国家本质论正是在这条思想脉络上的一次断裂：它既不把国家神化，也不把国家道德化，而是把国家放回生产与阶级的具体历史条件中，指出国家首先是**一种以暴力为后盾的阶级统治关系**。

理解这个「断裂」的位置，才能理解本篇的价值：它不是在既有国家观里增加一个选项，而是改变了讨论国家问题的整个坐标——从「国家应该是什么」转向「国家在历史中实际是什么」。

## 7 术语速查表

本专题术语较多，下表把本篇出现的核心概念与一句话释义集中列出，供检索与复习：

| 术语 | 一句话释义 |
| --- | --- |
| **国家定义** | 阶级矛盾不可调和时产生的、表面凌驾于社会之上、靠特殊公共权力维持的力量 |
| **阶级统治工具** | 国家是经济上占统治地位的阶级在政治上的统治工具 |
| **不可调和** | 国家正是矛盾尖锐到无法调和时产生的，是阶级矛盾的产物和表现 |
| **相对独立性** | 国家有时表现为超越具体阶级集团，但最终维护统治阶级长远利益 |
| **特殊公共权力** | 脱离生产的职业化暴力：常备军、警察、法庭、监狱 |
| **按地区划分** | 国家按居住地划分国民，不同于氏族的血缘划分 |
| **超阶级论** | 把国家看作全社会公共利益中立代表的观点 |
| **调和论** | 把国家看作各社会集团平衡仲裁者的观点 |

这张速查表与前面的核心对比表配合使用：对比表解决「概念之间如何区分」，速查表解决「每个概念是什么」。

## 8 延伸讨论

把本篇与全专题连起来看，国家本质论是一条贯穿的红线：正因为国家是阶级统治的工具，才谈得上国家职能为谁服务、革命为什么要夺取政权、打碎旧机器、建立无产阶级专政。

一个便于复习的链条：**国家起源（阶级矛盾）→ 国家本质（阶级统治）→ 国家职能（统治 + 管理）→ 国家命运（革命 → 专政 → 消亡）。**抓住这条链，整部马克思主义国家理论就串起来了。

## 9 小结

- **国家定义**：阶级矛盾不可调和时产生的、表面上凌驾于社会之上、靠特殊公共权力维持的力量。
- **本质一**：国家是经济上占统治地位的阶级在政治上的统治工具。
- **本质二**：国家是阶级矛盾不可调和的产物和表现，矛盾消失则国家失去存在理由。
- **相对独立性**：国家有时表现为超越具体阶级集团，但最终维护的是统治阶级的长远利益。
- **判断技巧**：看国家是否以压制被统治阶级为存在前提。
- **理论后果**：国家观的分歧直接决定了对待革命、改良与国家机器的态度。
- **思想史定位**：马克思主义国家本质论是对柏拉图、神学论、契约论的一次坐标转换。
- **核心一句**：国家是经济上占统治地位的阶级在政治上的统治工具。
- **延伸线索**：国家相对独立性是第二十一篇《普兰查斯与米利班德》的直接伏笔。
- **判断口诀**：看国家性质问三句——谁统治、镇压谁、为谁利益。
