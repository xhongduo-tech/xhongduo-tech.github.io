# 无产阶级革命的历史必然性

<div class="epigraph">

## 为什么从「必然性」开始

前一篇对比了两类国家，但有一个问题被悬置了：**凭什么认为资本主义一定会被无产阶级取代？**

这不只是一个价值判断，更是一个历史判断——马克思主义宣称它「必然」发生。理解这个「必然」的推导过程，是进入革命理论的钥匙。

从课程体系看，这篇把唯物史观的社会基本矛盾理论，应用到资本主义这个具体对象上——是第八级《社会学理论》马克思单元与第八级《经济思想史》资本主义批判的汇合点，也为下一篇《革命与打碎旧的国家机器》提供根据。

## 1 两个必然：马克思主义最著名的预言

马克思、恩格斯在《共产党宣言》里给出了最著名的历史判断：**资产阶级的灭亡和无产阶级的胜利是同样不可避免的。**这就是后人概括的「两个必然」——资本主义必然灭亡，社会主义必然胜利。

这个命题不是道德诅咒，而是从唯物史观推导出来的科学结论。

它的推理链条是：**生产力的发展与社会化程度不断提高 → 与生产资料的私人占有产生尖锐矛盾 → 旧生产关系成为生产力发展的桎梏 → 社会变革（革命）成为必然。**

关键在于证明第一环到第二环——资本主义社会里，矛盾为何「必然」尖锐到不可调和。

从课程地图看，这条推理链与第四级《经济学基础》中的「社会化大生产」「资本积累」内容直接衔接，也与第八级《经济思想史》中马克思主义政治经济学的批判互为表里。<span class="marginnote">注意「必然」的确切含义：它指的是历史趋势的必然，而不是具体时点的必然。什么时候、以什么形式爆发革命，取决于多种条件；但「资本主义终将被更高形态的社会制度取代」这一方向，是生产社会化发展的必然结局。</span>

## 2 矛盾的病灶：生产社会化与生产资料私有制

资本主义社会的根本矛盾，用一句话说就是：**生产已经社会化了，占有却仍然是个人的。**

**生产的社会化**体现在三处：生产资料使用的社会化——一台高炉、一条流水线由成千上万工人共同使用；生产过程的社会化——一件产品要经过无数环节、无数人的协作才能完成；产品的社会化——产品不是为个人使用而生产，而是为市场、为全社会生产。

**占有的私人性**却保持不变：生产资料的资本家和产品的分配权仍归个别资本——利润归资本所有者，工人只领工资。

于是，**越社会化的大生产，与越私人的占有之间的反差就越尖锐**，经济危机成为周期性的制度病（1825年第一次全面危机以来，1836、1847、1857……危机的间隔越来越短）。<span class="marginnote">危机的本质不是「东西太少」，而是「东西太多」却无钱购买——生产无限扩张与群众购买力有限之间的断裂。每次危机都证明：私有制的框架已经装不下社会化的生产力，这就是「生产力炸毁生产关系」的直观形态。</span>

## 3 阶级的锻造：资产阶级生产了自己的掘墓人

矛盾要变成革命，还得有一个主体。马克思的论证妙在：**资本主义不仅制造矛盾，还制造了解决矛盾的力量——无产阶级本身。**

资本主义发展的三个副产品，恰恰是无产阶级壮大的条件：

**第一，产业后备军与工人集中**——大工业把劳动者从乡村赶进城市，集中到工厂，使他们形成共同的利益与集体行动的便利。

**第二，组织化条件**——现代交通、通讯与工厂纪律，让工人得以组织工会与政党；资本主义「锻炼」了它自己的对手。

**第三，知识工具**——工人受教育程度随生产力发展而提高，政治觉醒成为可能。

于是《共产党宣言》的结论自然得出：**资产阶级在创造生产力与自身财富的同时，也创造了摧毁自身制度的阶级力量。**历史证明这个判断的深刻性：1848年革命、1871年巴黎公社、1917年十月革命，都发生在工业最发达或矛盾最尖锐的地带。

## 4 公式解析：必然性的推导链条

把「两个必然」的逻辑压成一条链，每个箭头都是一步可检验的推论：

$$
\text{生产社会化} \nearrow \quad \Longrightarrow\quad \text{与私有占有的矛盾} \nearrow \quad \Longrightarrow\quad \text{经济危机与阶级对立} \nearrow \quad \Longrightarrow\quad \text{革命的客观条件成熟}
$$

- **第一段**：生产力不断社会化，是资本积累的必然结果——竞争迫使每个资本扩大规模、深化分工。
- **第二段**：社会化的生产要求全社会共同占有、共同管理，私有制却拒绝这种要求——矛盾以周期性危机「发言」。
- **第三段**：危机中工人失业、中小资本破产，阶级对立简化为资产阶级与无产阶级两大阵营，矛盾集中爆发。
- **第四段**：当「生产力不能再在资本主义外壳下发展」时，外壳就要被炸毁——革命就从可能变为必然。

这条链最关键的一环是第四段：**「必然性」不等于「自动到来」**。客观矛盾成熟了，还需要主观条件——成熟的理论、有组织的政党、革命的大形势——才能把可能变为现实。这就是为什么紧接着要谈革命「如何做」。

## 5 核心对比表：无产阶级革命与以往革命

无产阶级革命不是史上第一次革命，却是性质不同的革命。用**核心对比表**对比它与此前的一切革命：

| 维度 | 以往的革命 | 无产阶级革命 |
| --- | --- | --- |
| 目标 | 一种私有制取代另一种私有制 | 消灭私有制本身 |
| 政权性质 | 新剥削阶级掌权 | 劳动阶级当家作主 |
| 占人口比例 | 少数人（新统治者） | 绝大多数人 |
| 对待旧国家机器 | 完善、接管、加以利用 | 打碎旧机器、另起炉灶 |
| 完成标志 | 夺取政权即告完成 | 夺取政权只是开始，长期改造社会 |
| 最高境界 | 维持新的阶级统治 | 消灭一切阶级，走向无阶级社会 |

这张表揭示了无产阶级革命的独特位置：**它是「最后一次」革命——因为它的目标不是建立新的剥削，而是消灭剥削本身。**正因为如此，它才与「消灭阶级」「国家消亡」内在地连在一起。

## 6 延伸：列宁的「一国首先胜利论」

马克思、恩格斯最初设想社会主义革命将在几个主要资本主义国家同时发生。列宁依据帝国主义时代的不平衡发展规律，提出了**社会主义可以首先在一个或少数几个国家取得胜利**的论断。

理由在于：帝国主义链条的薄弱环节——那些矛盾最尖锐、统治者最脆弱的国家——可能率先爆发革命，而不必等所有发达资本主义国家一起成熟。1917年十月革命在俄国（当时欧洲最落后的帝国主义国家之一）的胜利，正是这一论断的历史验证。

这个延伸与「两个必然」并不矛盾：必然性是长期方向，一国首先胜利是具体路径——**方向上的必然，与路径上的不平衡，统一在唯物史观的框架里。**

本专题术语较多，下表把本篇出现的核心概念与一句话释义集中列出，供检索与复习：

| 术语 | 一句话释义 |
| --- | --- |
| **两个必然** | 资本主义必然灭亡、社会主义必然胜利 |
| **生产社会化** | 生产资料、生产过程与产品都已社会化的趋势 |
| **资本积累** | 竞争迫使资本不断扩大规模、深化分工 |
| **剩余价值** | 工人创造而被资本家无偿占有的价值 |
| **经济危机** | 生产无限扩张与群众购买力有限之间的断裂 |
| **产业后备军** | 失业者构成的劳动后备大军，压低工资、供资本取用 |
| **历史火车头** | 革命对社会形态更替的直接推动作用 |
| **主观条件** | 成熟理论、有组织政党、革命形势等革命的主观准备 |

## 8 小结

- **两个必然**：资本主义必然灭亡、社会主义必然胜利，是从唯物史观推出的科学结论而非道德宣判。
- **根本矛盾**：生产社会化与生产资料私人占有之间的矛盾，以周期性经济危机为症候。
- **阶级锻造**：资本主义在创造财富的同时，也创造了推翻自身的阶级力量——现代无产阶级。
- **推导链条**：社会化 → 矛盾尖锐化 → 危机与对立 → 革命条件成熟。
- **必然 ≠ 自动**：客观矛盾成熟后仍需主观条件（理论、政党、形势）才能变为现实。
- **独特性质**：无产阶级革命以消灭私有制与一切阶级为目标，因此是「最后的革命」。
- **一国首先胜利**：帝国主义时代链条薄弱环节可能率先革命，十月革命即为验证。

在下一节，我们回答「革命如何动手」：为什么夺取政权后还要砸碎旧国家机器，而不是把它接过来接着用——这就是《革命与打碎旧的国家机器》。
