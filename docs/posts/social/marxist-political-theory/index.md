# 马克思主义政治学与国家理论

以唯物史观为基础，系统重建从阶级分析、国家本质到革命与无产阶级专政的马克思主义政治理论体系，并延伸至当代马克思主义对国家与意识形态的最新思考。学完这些章节，就写完了马克思主义政治学与国家理论的核心内容。

- 徐涛《考研政治核心考案》
