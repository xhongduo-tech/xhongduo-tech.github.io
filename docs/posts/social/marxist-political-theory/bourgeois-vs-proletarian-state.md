# 资产阶级国家与无产阶级国家的本质区别

<div class="epigraph">
<p>我们的国家形式是资产阶级民主共和国……工人阶级要打碎的正是这样的国家机器。</p>

## 为什么从两类国家的对比开始

前面说过，国家都是阶级统治的工具——这句话要落地，就必须回答：**资产阶级国家和无产阶级国家，作为两个「工具」，究竟差在哪？**

如果看不出差别，就会得出「一切国家都一样」的虚无结论；如果只看到形式差别，又会错过本质。

从课程体系看，这篇把第八级《比较政治学》的「政体类型学」带进阶级分析的框架：比较政治学比的是制度形态，马克思主义还要追问——这些形态背后站着的究竟是哪个阶级。

它是革命篇与专政篇之间的桥。

## 1 形式与本质：为什么「民主共和国」也是资产阶级国家

先处理最常见的困惑：**现代资本主义国家大多实行普选、议会、多党制，凭什么说它是「资产阶级国家」？**答案在「形式 vs 本质」的区分。

从形式看，资产阶级民主制确实与奴隶制、封建制的公开专断大不相同：公民在形式上平等，享有言论、集会、结社、选举的自由，政权通过定期选举轮换。

但从本质看，**经济权力没有变——生产资料仍归资产阶级独占，国家机器（军队、警察、司法、行政）仍为保障这种占有的秩序服务。**<span class="marginnote">列宁在《国家与革命》中把这种制度称为「最完全、最精巧的资产阶级统治形式」：它在形式上把一切公民拉平，实质上只改变统治手法——从公开暴力转向法治与议会操纵，让被剥削阶级「在资本主义粪堆上每十年选一次粪堆的统治者」。</span>

形式上的民主不改变两个根本事实：**其一，竞选需要金钱与媒体，而金钱与媒体掌握在资产阶级手中；其二，国家的暴力机器——军队、警察、司法——始终由资产阶级掌控，一旦触及其根本利益，民主的外衣随时可以收起。**

于是结论是：民主共和国只是资产阶级统治「最好的政治外壳」，外壳之下是阶级统治。

## 2 无产阶级国家的性质：反过来的国家

无产阶级国家与资产阶级国家的区别，不是「换了一批人」这么简单，而是**国家性质的根本翻转**：

**阶级基础不同。**资产阶级国家是少数剥削者对多数人的统治，依靠的是占有生产资料的少数阶级；无产阶级国家是多数劳动人民对少数旧剥削者的统治，依靠的是劳动者阶级——这正是「多数人的民主」。

**目的不同。**资产阶级国家的目的是维持雇佣剥削秩序；无产阶级国家的目的是消灭阶级——它不仅镇压反抗，更要把产生阶级的生产条件（私有制）逐步消除，为最终消灭一切阶级、从而消灭国家本身创造条件。<span class="marginnote">这是理解无产阶级国家「历史使命」的钥匙：它不是永恒的「千年王国」，而是一个<strong>过渡性的国家形态</strong>——它存在的理由恰恰是为了使自己不再需要存在。列宁说这是「半国家」或「正在消亡的国家」。</span>

**镇压的方向相反。**资产阶级国家镇压多数人；无产阶级国家镇压的只是少数反抗社会主义改造的旧势力，而且镇压的对象随剥削阶级的消灭而不断缩小。

## 3 国家形态：苏维埃与巴黎公社的启示

无产阶级国家采取什么组织形态？马克思主义给出的答案是：不能照抄资产阶级的议会制，而要创造新的形式。列宁在《国家与革命》中详细论述了巴黎公社与苏维埃两种原型：

**巴黎公社式的民主**（1871年）——官员由普选产生、可以随时罢免，所有公职人员领取与工人同等的工资，废除常备军而代之以武装的人民，教会与国家分离。

**苏维埃式民主**（1917年）——由工人、农民、士兵代表组成权力机关，把立法与执行统一起来，抛弃议会制那种「清谈馆」式的分工，让劳动者真正参与管理。<span class="marginnote">对比要点：资产阶级议会制的特征是「议行分立」——议员只管立法、不干实事，行政权独立于议会，实质上让精英操盘；公社与苏维埃的特征是「议行合一」——代表既是立法者又是执行者，且直接向选民负责、随时可被撤换。</span>

两者共同的精髓是**「打碎旧的国家机器、让劳动者直接掌权」**——这与资产阶级国家的代议制形成了鲜明的形态对照。

## 4 核心对比表：两类国家的十个维度

这是本专题最重要的一张对照表，用**核心对比表**完整呈现两类国家的差异：

| 维度 | 资产阶级国家 | 无产阶级国家 |
| --- | --- | --- |
| 阶级基础 | 占少数的资产阶级 | 占多数的劳动阶级 |
| 统治方向 | 少数人统治多数人 | 多数人统治少数旧剥削者 |
| 经济基础 | 生产资料私有制 | 生产资料公有制（过渡） |
| 民主实质 | 形式平等、实质金钱政治 | 劳动者当家作主 |
| 镇压对象 | 广大被剥削群众 | 少数反抗社会主义的旧势力 |
| 国家机器 | 常备军、警察、职业官僚 | 武装的劳动者、可撤换的代表 |
| 政体原型 | 议会制、多党竞争 | 巴黎公社、苏维埃（议行合一） |
| 历史命运 | 随资本主义被取代而消亡 | 过渡性，随阶级消灭而消亡 |
| 政权组织原则 | 代议、职业化、议行分立 | 直接参与、议行合一 |
| 与旧国家的关系 | 继承并完善旧机器 | 打碎旧机器、建立新机器 |

这张表传达的核心判断只有一个：**无产阶级国家不是资产阶级国家的「翻版」或「改良」，而是性质上的对位翻转。**它继承人类政治文明中民主、法治的形式成就，但把民主从形式推进到实质，把政权从少数人手里交到多数人手里。

## 5 误区辨析：三个常见错误理解

**辨析｜易错点：** 学到这里，三个误解需要当场拆掉。

**误解一，「无产阶级国家就是取消一切自由」**——错。它取消的是资产阶级少数人的特权与金钱自由，换来的是劳动者实质的民主权利；它废除的不是民主，而是把民主从议会形式扩展到经济与社会领域。

**误解二，「两类国家只是名称不同、本质都是统治」**——错。区别不在「有没有镇压」，而在「镇压谁、为谁的利益」。「谁统治谁」一旦反转，国家的性质就反转了。

**误解三，「无产阶级国家要立即消灭一切国家形式」**——错。在国家消亡的客观条件具备之前，无产阶级国家必须存在；急于「废除国家」而放弃政权，只会让旧势力复辟。这个「度」的把握，正是《无产阶级专政》篇要展开的。<span class="marginnote">三个误解的共同根源，是把「国家」这个抽象名词当成了超越阶级的中性物。只要记住「谁统治谁、镇压谁、为谁的利益」这组追问，三个误解就都站不住。</span>

## 6 辨析：政体与国家形式

政治学里有一对经典的区分：**国体**（国家的阶级本质，即「谁统治」）与**政体**（政权组织形式，即「怎么统治」）。马克思主义强调：国体决定政体，政体为国体服务。

资产阶级国家可以采用君主制，也可以采用民主共和制——但无论何种政体，其国体都是资产阶级专政。无产阶级国家的政体可以是公社式或苏维埃式——但无论何种政体，其国体都是劳动阶级当家作主。

这个区分提醒我们：**判断一个国家的性质，看国体而不是看政体；政体可以千差万别，国体决定本质。**这也是本篇「形式与本质」区分的政治学通用版。

## 7 术语速查表

本专题术语较多，下表把本篇出现的核心概念与一句话释义集中列出，供检索与复习：

| 术语 | 一句话释义 |
| --- | --- |
| **形式民主** | 公民在形式上平等的选举与权利，但金钱与媒体仍掌握在资产阶级手中 |
| **实质民主** | 劳动者真正参与经济与社会管理，民主扩展到社会领域 |
| **议行合一** | 立法与执行统一，代表既是立法者又是执行者，直接对选民负责 |
| **议行分立** | 议会只管立法、行政独立于议会，实质由职业精英操盘 |
| **半国家** | 列宁对无产阶级国家的称呼：它是过渡性的，为走向消亡而存在 |
| **资产阶级国家** | 少数人对多数人的统治 + 私有制 |
| **无产阶级国家** | 多数人对少数旧势力的统治 + 向公有制过渡 |
| **打碎旧机器** | 不能接管旧国家机器，须另建劳动者掌权的新机器 |

这张速查表与前面的核心对比表配合使用：对比表解决「概念之间如何区分」，速查表解决「每个概念是什么」。

## 8 小结

- **本质对照**：资产阶级国家 = 少数人对多数人的统治 + 私有制；无产阶级国家 = 多数人对少数旧势力的统治 + 向公有制过渡。
- **形式与本质**：民主共和国只是资产阶级统治的「最好外壳」，改变不了经济权力的独占。
- **新形态**：巴黎公社与苏维埃体现「议行合一、随时罢免、劳动者掌权」的无产阶级国家原则。
- **过渡性**：无产阶级国家是「半国家」，存在的目的是使自己成为不再需要的东西。
- **三个误区**：不是取消自由、不是名称游戏、不是立即废除国家。
- **判断追问**：「谁统治谁、镇压谁、为谁的利益」——三问定位国家性质。
- **国体与政体**：国体（谁统治）决定本质，政体（怎么统治）服务国体——判断国家性质看国体。

在下一节，我们进入革命篇的正面论述：为什么无产阶级必须革命、为什么资本主义必然被取代——这就是《无产阶级革命的历史必然性》。
