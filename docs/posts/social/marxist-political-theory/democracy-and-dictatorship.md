# 民主与专政的辩证统一

<div class="epigraph">

## 为什么从「民主」与「专政」这对词开始

在常人的语汇里，「民主」与「专政」是水火不容的：民主意味着人人有权，专政意味着独裁压制。

马克思主义却把它们放在同一台国家机器里，强调二者的**辩证统一**。

这对外行是悖论，对理解无产阶级国家却是要害——不明白这个统一，就既不理解民主的实质，也不理解专政的性质。

从课程体系看，这篇把第八级《比较政治学》的「民主转型」议题、政治学中的「民主—威权」二分，拉到马克思主义的阶级分析高度：**任何民主都是特定阶级的民主，任何国家都在民主与专政两方面同时运作。**

## 1 民主的阶级性：没有抽象的民主

先破一个流行观念：**民主不是超越阶级的「普世价值」，而是有阶级属性的历史范畴。**

民主的原义是「人民主权」——但「人民」从来不是抽象的全部人，而是特定历史条件下的特定阶级联合体。

在奴隶社会，民主是奴隶主的民主，奴隶连「人」的资格都没有；在资本主义社会，民主是资产阶级的民主——公民形式上平等，但金钱、媒体、教育都归资产阶级掌控，平等的选举权无法改变不平等的社会权力；在无产阶级社会，民主是劳动人民的民主——占人口绝大多数的劳动者掌握国家权力。<span class="marginnote">马克思主义的经典表述是：<strong>民主是一种国家形式、一种国家形态</strong>——它是统治阶级实现统治的政治形式。因此不存在「纯粹的、超阶级的民主」，只存在「哪个阶级的民主」。问「谁享受民主、谁被排斥在外」，比空谈「民主」更接近真相。</span>

由此推论：**任何国家，对内民主的范围，恰是对外专政的对象**——对统治阶级讲民主，对被统治阶级就必然是专政。民主与专政从来是一体两面。

## 2 无产阶级国家的民主：多数人的实质民主

无产阶级国家的民主，是民主史上的一次质变：

**从形式民主到实质民主。**资产阶级民主止步于「投票权平等」，无产阶级民主要深入到经济社会领域——劳动者不仅选代表，还参与生产管理、监督公共事务、决定分配。列宁强调，无产阶级民主是「大多数人的、真正的民主」，它的标志不是开几次会，而是劳动者是否真正掌权。

**从少数人的民主到多数人的民主。**民主的「容量」变了：占人口多数的工人、农民及其他劳动群众第一次成为民主的主体。正因为民主扩展到了多数人，专政的对象收缩到了极少数旧剥削势力——**民主范围越大，专政范围越小。**

这揭示了一个不对称：**资产阶级民主是少数人的民主 + 对多数人的专政；无产阶级民主是多数人的民主 + 对少数人的专政。**两端的「量」完全颠倒，这正是《资产阶级国家与无产阶级国家》篇对比表的继续。

## 3 专政的必要性：为什么多数人也要用强制

有人会问：既然无产阶级是多数，为什么还需要专政（强制）？答案在现实的阶级斗争里：

**被推翻的阶级不会自动退出历史舞台。**旧剥削阶级虽然失去了政权，但仍掌握着经济残余、组织残余、观念残余，还可能勾结国际敌对势力，利用一切空隙进行复辟。列宁在十月革命后反复警告：**镇压剥削阶级的反抗，是无产阶级专政「必要的、正当的」职能**——这不是「残暴」，而是多数人保卫革命成果的手段。<span class="marginnote">用一个具体的反例说明：1918—1920年俄国国内战争期间，白军与外国干涉军试图推翻苏维埃政权，正是苏维埃政权的强制机器粉碎了这些复辟尝试。历史证明：对旧势力讲「无条件宽容」，等于把革命果实拱手送回。</span>

**专政针对的是「少数旧势力」，不是「全体人民」。**强制之所以正当，正因为它是多数人授权的、指向极少数人的、服务于全社会解放的。一旦专政的对象不再存在，专政本身也就失去对象——这正是它走向消亡的内在逻辑。

## 4 公式解析：民主与专政的互补关系

把民主与专政的辩证统一写成一个关系式，一眼看清两者如何「互相规定」：

$$
D_{\text{民主}} \;\Longleftrightarrow\; D_{\text{专政}}, \qquad \text{民主对象} \;\cap\; \text{专政对象} = \emptyset, \qquad \text{民主对象} \;\cup\; \text{专政对象} = \text{全体国民}
$$

- **第一式**：民主与专政互为条件——对人民讲民主，就得对破坏人民利益者讲专政；放弃专政，民主就会被内外敌人吞掉。
- **第二式**：两个对象不相交——被民主对待的（人民）与被专政对待的（敌人）不是同一群人，这正是「对谁民主、对谁专政」的分界。
- **第三式**：两者合起来覆盖全体国民——国家的全部对象，要么在民主之内，要么在专政之内，没有真空。
- **趋势**：随着剥削阶级被消灭，专政对象的集合逐渐收缩，民主对象的集合不断扩张，直到前者为空——国家就消亡了。

这套关系式的意义在于：**它把「民主与专政统一」从口号变成结构。**任何人想拆散这对关系——只要民主、不要专政（右的投降主义），或只要专政、不要民主（左的专断主义）——都会破坏国家的平衡，导致变质。

## 5 核心对比表：民主与专政的关系

把「民主」与「专政」放在一起，用**核心对比表**厘清三组关系：

| 维度 | 民主 | 专政 |
| --- | --- | --- |
| 对象 | 人民（多数） | 敌人（少数旧势力） |
| 方式 | 平等权利、参与管理 | 强制、镇压反抗 |
| 性质 | 新型的、实质的民主 | 新型的、过渡性的强制 |
| 目标 | 实现人民当家作主 | 保卫革命成果、扫除复辟 |
| 趋势 | 范围不断扩大 | 范围不断缩小直至消失 |
| 错误倾向 | 只要专政不要民主（专断） | 只要民主不要专政（投降） |

这张表把「统一」落实到操作层面：**无产阶级国家的健康状态，就是民主不断扩展、专政不断收敛的动态过程。**哪一端失衡，都是对无产阶级专政实质的背离。

## 6 延伸：从巴黎公社到人民民主专政

「民主与专政的统一」不是书斋概念，它在中国革命与建设中凝结为**人民民主专政**。毛泽东在《论人民民主专政》中指出：对人民内部的民主与对反动派的专政，互相结合起来，就是人民民主专政。

这一提法把马克思主义的民主专政统一论与中国具体国情结合：在人民内部充分发扬民主、实行群众路线；对敌视和破坏社会主义制度的势力实行专政。二者不是时间的先后，而是同一个政权的一体两面。

理解这一点，就能理解为什么「人民民主」与「对敌专政」在中国语境下从不矛盾——它们各自指向不同的对象，共同维护的是劳动人民的政权。

## 7 术语速查表

本专题术语较多，下表把本篇出现的核心概念与一句话释义集中列出，供检索与复习：

| 术语 | 一句话释义 |
| --- | --- |
| **民主** | 统治阶级实现统治的政治形式，具有鲜明的阶级属性 |
| **专政** | 对敌对阶级的强制与镇压，是民主的另一面 |
| **人民民主专政** | 对人民的民主与对敌人的专政相结合 |
| **新型民主** | 多数劳动人民的实质民主，深入经济与社会领域 |
| **新型专政** | 针对少数旧势力的过渡性强制 |
| **议行合一** | 立法与执行统一，劳动者直接掌权的组织原则 |
| **动态平衡** | 民主扩展、专政收敛、直至专政对象归零的进程 |
| **两种错误** | 只要专政不要民主（专断）或只要民主不要专政（投降） |

这张速查表与前面的核心对比表配合使用：对比表解决「概念之间如何区分」，速查表解决「每个概念是什么」。

## 8 小结

- **民主的阶级性**：没有超阶级的民主，任何民主都是特定阶级的民主；民主与专政是一体两面。
- **实质民主**：无产阶级民主是多数人的实质民主，深入经济与社会管理领域。
- **专政的必要性**：被推翻阶级不会自动退场，多数人必须用强制保卫革命成果。
- **公式结构**：民主对象与专政对象不相交而互补，随阶级消灭，专政对象归零。
- **两种错误**：只要专政不要民主是专断，只要民主不要专政是投降。
- **动态平衡**：健康的无产阶级国家是民主扩展、专政收敛的进程。
- **中国语境**：人民民主专政 = 对人民的民主 + 对敌人的专政，是民主专政统一的制度化表达。

在下一节，我们把「打碎旧机器、建立新民主」第一次变为历史现实：1871年的巴黎公社给了无产阶级什么经验——这就是《巴黎公社经验与无产阶级民主》。
