# 国家与革命的关系

## 为什么从「国家与革命」这对词开始

前面说清了国家是什么、干什么。但政治学里没有比这更紧张的一对词：「国家」代表既有的统治秩序，而「革命」意味着对秩序的推翻。

马克思主义政治理论的全部现实锋芒，都集中在**革命如何对待国家**这个问题上。

从课程体系看，这篇是第八级《比较政治学》中「革命与社会变迁」的马克思主义版本，也是本专题从「国家篇」转向「革命篇」的枢纽。

这里要把前面所有概念——阶级、国家本质、国家职能——拧成一股绳，回答一个行动问题：革命的首要目标是什么？

## 1 革命的定义：不是一切暴力变革

先厘清概念。**革命（revolution）**在马克思主义语境里指一个特定的社会变革类型：**被压迫阶级通过夺取国家政权，改变国家性质，从而推动生产关系的根本变革。**

它与「政变」「改良」「起义」有严格区别：

**政变**（如兵变、宫廷阴谋）只换统治者，不换国家性质——将军推翻总统，帝国仍是帝国。**改良**（如渐进改革）在不触动国家本质的前提下调整政策——提高工资、扩大福利，但雇佣关系原封不动。**起义**是革命的常见武器，但起义不等于革命——没有改变国家性质与生产关系的起义，只是骚乱。<span class="marginnote">判别的尺子只有一把：<strong>政权有没有从一个阶级转到另一个阶级、国家性质有没有根本改变。</strong>因此，同样一场武装行动，可以是革命、也可以是政变——取决于它改变了什么。这是考研政治判断「是否革命」的高频考点。</span>

## 2 革命的首要问题：国家政权问题

既然国家是阶级统治的工具，那么被压迫阶级要改变命运，就不能只在「社会内部」修修补补，而必须夺取国家这个统治机器。

于是马克思主义给出一个斩钉截铁的命题：**革命的首要的基本的标志，就是国家政权从统治阶级手中转到被统治阶级手中；政治革命的根本问题，是国家政权问题。**

一切其他斗争——经济罢工、思想论战——如果不能最终落到政权上，就都停留在改良层面。<span class="marginnote">这正是列宁反复强调的「一切革命的根本问题是国家政权问题」：不抓住政权，工人运动的全部成果都可能被一场镇压或一次退让化为乌有。十九世纪的工联主义——只争工资、不问政权——正是被这个命题否定的路线。</span>

这个命题有一个直接推论：**革命的成败，最终以政权易手为准。**因此革命理论必须把「如何夺取政权、如何建立新政权」作为自己的核心内容——这正是下一篇《革命与打碎旧的国家机器》的主题。

## 3 公式解析：革命的因果链条

革命的发生不是偶然情绪的爆发，而是一条可以解析的因果链。用公式把决定革命的要素压出来：

$$
\text{革命的必然性} = f\left( \frac{\text{生产力与生产关系的矛盾程度}}{\text{统治阶级的镇压能力}} ,\; \text{阶级力量对比},\; \text{革命主观条件} \right)
$$

- **分母的两种理解**：生产力冲破旧生产关系的「压力」越大，革命越迫切；而统治阶级的镇压能力越强，革命代价越大。两者的张力决定了革命的「时机」。
- **阶级力量对比**：被压迫阶级的觉悟、组织程度与团结程度——组织起来的阶级比孤立的群众更有力量，这是《先锋队政党》要展开的变量。
- **主观条件**：革命理论与成熟政党——没有革命的理论，就没有革命的运动（列宁《怎么办？》）。这条链不是「生产力足够就自动革命」，而是结构与主体共同作用的结果。

这条公式的实践含义是双重的：**一方面，革命有客观必然性，不能靠「少数人的密谋」凭空制造；另一方面，革命也需要主观准备，不能坐等「客观条件」自动开花。**成熟的革命理论，正是在这两个极端之间保持张力。

## 4 革命的历史地位：历史的火车头

在唯物史观里，革命不是混乱与倒退，而是社会进步的「火车头」：

**革命是解决社会基本矛盾的根本手段。**当旧生产关系成为生产力发展的桎梏、旧上层建筑死守旧经济基础时，仅靠改良无法完成变革——因为握有暴力的统治阶级不会自愿交出政权。革命以强力搬开这块绊脚石，为生产力发展打开通道。

**革命是阶级力量的大检阅与大洗牌。**革命时期，群众的创造力、组织力、政治觉悟空前爆发，历史舞台上被压抑的阶级力量集中亮相。法国大革命用十年完成了英国用几十年改革才完成的制度转型，正是「革命是历史火车头」的注脚。

**革命推动社会形态的更替。**奴隶制到封建制、封建制到资本主义——每一次更替都有革命（尽管形态各异）作为杠杆。理解了这一点，才能理解《无产阶级革命的历史必然性》：资本主义的被取代，也必然要经历革命这一环节。<span class="marginnote">历史上有一种观点把革命妖魔化为「暴力混乱」。唯物史观的态度是：革命是否发生、以何种形式发生，不取决于人的偏好，而取决于旧秩序是否愿意和平让位。革命是「最后手段」——但它常常是被逼出来的唯一手段。</span>

## 5 核心对比表：革命与改良

「革命 vs 改良」是政治实践中最古老的选择题。用**核心对比表**摆开：

| 维度 | 革命 | 改良 |
| --- | --- | --- |
| 目标 | 改变国家性质、变革生产关系 | 不触动国家本质的政策调整 |
| 手段 | 以夺取政权为核心，常伴随暴力 | 合法、渐进、议会与行政手段 |
| 对国家机器 | 打碎旧机器、建立新机器 | 利用、修补、完善旧机器 |
| 主体 | 被压迫阶级的群众运动 | 议会政党、社会精英 |
| 历史地位 | 社会形态更替的杠杆 | 量变的积累，无法完成质变 |
| 典型 | 1789法国大革命、1917十月革命 | 英国渐进改革、北欧福利改良 |

这张表的要害在「对国家机器」一行：**革命不是改良的「加强版」，而是对待国家机器的两种相反态度。**改良的前提是承认现存国家的合法性，革命的前提是否定它。正因为如此，下一篇要专门回答：革命到底应该「接管」旧国家，还是「打碎」旧国家？

## 6 案例：法国大革命中的国家政权

1789年的法国大革命是检验「政权问题」的经典样本：攻占巴士底狱只是序幕，真正的关键是制宪议会与国民公会反复争夺的国家权力——从君主立宪到共和，从吉伦特派到雅各宾派，每一次政权转移都改写了革命的深度与方向。

拿破仑的雾月政变则从反面说明政变与革命的差别：它推翻了督政府，却没有改变大革命的资本主义性质——政权在资产阶级内部易手，国体未变，因此是政变而非新的革命。

这一对照让「政权问题是革命根本问题」变得可检验：**看一场变革是不是革命，看国家政权是否从一个阶级转到另一个阶级，而不是看它流了多少血、换了多少旗。**

## 7 术语速查表

本专题术语较多，下表把本篇出现的核心概念与一句话释义集中列出，供检索与复习：

| 术语 | 一句话释义 |
| --- | --- |
| **革命** | 被压迫阶级夺取政权、改变国家性质、变革生产关系的社会变革 |
| **政变** | 只换统治者、不换国家性质的暴力更迭 |
| **改良** | 不触动国家本质的政策调整 |
| **起义** | 革命的常见武器，但不等于革命 |
| **政权问题** | 革命的根本问题——国家政权从谁转到谁 |
| **历史火车头** | 革命推动社会形态更替的直接杠杆作用 |
| **客观必然** | 基本矛盾成熟决定的革命必然性 |
| **主观准备** | 理论、政党、形势等把必然变为现实的条件 |

这张速查表与前面的核心对比表配合使用：对比表解决「概念之间如何区分」，速查表解决「每个概念是什么」。

## 8 小结

- **革命的定义**：被压迫阶级夺取政权、改变国家性质、变革生产关系的社会变革，区别于政变、改良与单纯起义。
- **首要问题**：国家政权问题是革命的根本问题，政权易手是革命成败的判据。
- **因果链条**：革命的必然性由基本矛盾、阶级力量对比与主观条件共同决定。
- **历史地位**：革命是历史的火车头，是解决社会基本矛盾的根本手段。
- **革命 vs 改良**：差别在于对待国家机器的态度——接管还是打碎。
- **历史态度**：革命是否发生不取决于偏好，而取决于旧秩序是否愿意和平让位。
- **法国样本**：从攻占巴士底狱到拿破仑政变，政权问题始终是衡量革命深度与性质的标准。
- **判据回顾**：政权是否从一阶级转到另一阶级，是衡量革命与政变、改良的分水岭。

在下一节，我们回答上节留下的问题：革命到底该怎样对待旧国家？——这就是《革命与打碎旧的国家机器》。
