## 为什么从选举制度开始

前面讲政党制度时提到迪韦尔热定律：选举制度塑造政党制度。现在我们把镜头对准这个「塑造者」本身。**选举制度（electoral system）**是「选票如何转化为席位」的规则总和——它是民主政治最精密的齿轮，规则上一个百分点的差异，可能决定哪个党执政、哪种声音被听见。选举制度是政治学中「制度设计」最硬核的分支，也是量化分析最成熟、与数学结合最深的领域之一。这一节我们将拆解主要选举制度的机制、后果与设计权衡。<span class="marginnote">为什么选举规则如此重要？因为它决定「谁当选」——而当选者的政策偏好、代表性与合法性都直接受规则影响。选票如何计，是民主的第一道算法。</span>

## 1 主要选举制度

世界上主流选举制度分两大类，各有许多变种：

- **多数代表制（majoritarian / plurality）**：每个选区产生一名议员，得票最多者当选。
  - **相对多数制（first-past-the-post, FPTP）**：简单得票最多者胜出，不论是否过半。英国下议院、美国国会、印度下院采用。
  - **绝对多数制（majority runoff）**：要求得票过半，不足则两轮决选。法国国民议会、许多国家的总统选举采用。
- **比例代表制（proportional representation, PR）**：按各党得票比例分配席位。
  - **名单比例制（list PR）**：选民投给政党名单，政党按得票比例获得席位，再按名单顺序确定当选者。北欧、以色列、荷兰采用。
  - **单一可转移票制（single transferable vote, STV）**：多议员选区，选民给候选人排序，席位按得票额配额分配。爱尔兰、马耳他采用。<span class="marginnote">混合制是第三条路：德国的「混合成员比例制（MMP）」把一半席位按 FPTP 产生、另一半按比例补偿，让每个党的总席位与得票率一致；日本的「并立制」则是两套平行计票，容易产生「扭曲的比例」。</span>

## 2 两种制度的核心差异

多数制与比例制的差异远不止计票方式，它们代表了两种不同的民主价值观：

| 维度 | 多数代表制 | 比例代表制 |
| --- | --- | --- |
| 选区 | 单议员小选区 | 多议员大选区/全国 |
| 当选门槛 | 得票第一即可 | 按比例分成席位 |
| 代表性 | 胜者全取，输家无席 | 各党按比例进入议会 |
| 政府构成 | 倾向两党、单党政府 | 多党、联合政府 |
| 选民-代表关系 | 直接联系本地代表 | 代表全国性政党纲领 |
| 优点 | 政府稳定、问责清晰 | 结果公平、小党有声音 |
| 弱点 | 浪费选票、忽视少数 | 政府脆弱、极端党可得席 |

**重点：多数制与比例制之争，本质是「有效政府」与「公平代表」之争。** 多数制把议会多数权集中交给一个党，保证执政稳定、责任明确；代价是大量选票「浪费」（落选者的票不影响结果），少数群体的声音被系统性忽略。比例制让每一个百分点都有对应的席位，公平却可能让议会碎片化、政府频繁倒台。<span class="marginnote">美国总统 2016 年、2012 年的「胜者普选票低于对手却当选」现象（因选举人团制度），正是多数制下「选票浪费」与「地理分布」结合的极端案例——制度把全国普选变回了州级赢者通吃。</span>

## 3 选举制度的量化后果：比例性偏差

选举制度的一个重要测量指标是**比例性（proportionality）**——席位比例偏离得票比例的程度。常用**加拉格指数（Gallagher Index）**度量：

$$
LSq = \sqrt{\frac{1}{2} \sum_{i=1}^{n} (v_i - s_i)^2}
$$

其中 $v_i$ 是第 $i$ 党的得票率，$s_i$ 是它的席位率，$n$ 是政党数。三步拆解：

- **第一步，看偏差的度量**：每个党的得票率与席位率之差 $(v_i - s_i)$，反映了该党在议会的「过度代表」或「欠代表」。平方是为了抹掉正负号、并放大大的偏差。
- **第二步，看平均与根号**：所有党偏差平方后相加，乘以 $1/2$ 取平均再开方，得到整体偏离程度。$LSq$ 越小，说明席位越接近得票；理想比例制 $LSq$ 接近 0，英国 2015 年大选 $LSq$ 约为 15——巨大偏差。
- **第三步，读懂量级**：$LSq < 3$ 一般被认为是高比例性，$> 8$ 则视为严重偏差。南非、瑞典等比例制国家常年 $LSq < 2$，而多数制国家普遍在 10 以上。<span class="marginnote">加拉格指数是选举研究最常用的「制度偏差计」，它把「选举制度的公平程度」变成了可跨国家比较的一个数字——这正是比较政治学量化的典型做法。</span>

## 4 选举制度的政治后果

选举制度的具体设计（门槛、选区大小、选票结构）会产生一系列可观察的政治后果：

- **门槛效应**：比例制常设「法定门槛」（德国 5%、土耳其 10%），得票低于门槛的党无席——门槛越高，小党越难进入，越接近两党结构。门槛是比例制用来「换稳定」的折中。
- **选区规模**：一个选区的议席越多（选区规模越大），比例性越高。单席选区天然最多数制化，大选区天然更比例化。<span class="marginnote">这里藏着一条被反复验证的经验规律：选区规模每增加一位议席，有效政党数就上升——选区规模是比「选票结构」更关键的变量。</span>
- **策略性投票**：多数制下选民明知小党无望，会「策略性」投给不太讨厌的大党，以免浪费选票——这进一步巩固两党制（迪韦尔热定律的心理机制）。
- **地理代表与族群政治**：单席选区保证「每个地区都有自己的议员」，有利于地理利益的表达；但若族群在空间上隔离，多数制可能系统性地消灭少数族群的代表性——这是许多多族群国家选举设计的难题。<span class="marginnote">南亚与非洲许多国家为此设计「保留席位」「族群配额」等机制，在比例代表与族群代表之间寻找平衡——详见第三篇《区域比较》。</span>

**辨析｜易错点：** 不要以为「更比例的选举制度 = 更民主」。比例性只是选举公平的一个维度，代表、问责、稳定、族群和解都是重要的民主价值。选选举制度不是选「最好的」，而是选「最适合本国政治条件的」——这是一切制度设计的黄金法则。

## 5 选举改革之争

选举制度不是「定死的」，它在政治争论中被反复设计、修改与推翻。选举改革之争集中体现了「制度设计」的政治性：

- **英国与北美的比例制运动**：英国长期实行 FPTP，绿党、自由民主党等小党屡屡被「浪费选票」压制。改革派主张引入比例代表制以「公平」；保守派主张保留 FPTP 以「稳定与选区联系」。2011 年英国的「选择投票制」公投被否决——现状有「在位者偏好」的保护。
- **新西兰的激进改革**：1993 年新西兰经公投从 FPTP 转为「混合成员比例制（MMP）」——这是少有的「由下而上」成功推翻多数制的案例。改革后小党与毛利族裔代表显著增加，但联合政府也变得更复杂。<span class="marginnote">新西兰改革的启示：选举制度可以「自我修改」，但需要罕见的政治窗口（民众对既有体制强烈不满+公投机制）。大多数国家沿用现状，不是因为现状最优，而是因为「在位者」没有动力改变让自己当选的规则。</span>
- **美国的选举制度争议**：美国长期受困于「杰利蝾螈（gerrymandering，操纵选区）」、「初选极化」与「选举人团」争议——选举制度在美国是高度党派化的战场。2020 年大选后围绕「投票权」的立法攻防，更凸显选举规则的争议性。
- **新制度的探索**：排序选择投票（ranked-choice voting）、全国普选契约（National Popular Vote Interstate Compact）等创新设计，正在部分城市与州落地——选举制度仍在演化。<span class="marginnote">排序选择投票的优点：选民给候选人排序，若无人过半则淘汰最后一名、转移其选票——它能表达「第二选择」，减少「浪费选票」与「策略性投票」，被美国多个城市采用。但它的复杂性也让部分选民困惑。</span>

**辨析｜易错点：** 选举改革不是「技术问题」而是「权力问题」。任何选举规则的改变都会重新分配「谁当选」，因此改革必然引发激烈政治斗争——「制度的公平性」本身就是在位的政治家博弈的对象。以为「找到最优选举制度就能解决政治问题」是技术决定论的天真；现实的规律是：**制度是博弈的规则，而规则本身也是博弈的产物。**

**重点：选举制度研究的终极问题不是「哪种制度最好」，而是「制度如何被选择、如何被改变、又如何塑造政治」。** 从迪韦尔热定律到加拉格指数，我们看到的不仅是「制度→后果」的单向因果，更是「制度⇄政治」的互动循环——这是《比较方法》「制度—行为」分析的典型示范。

## 6 延伸思考与进一步阅读

把选举制度的知识用起来，五个问题值得自己推演：

- **思考一：用「迪韦尔热定律」解释你熟悉的一个国家的政党格局。** 英国、美国用 FPTP → 两党制；荷兰、以色列用比例制 → 多党制；日本用并立制 → 自民党长期主导的「准两党制」。想一想：有没有「违反」迪韦尔热定律的例子（比例制却两党化、多数制却多党化）？为什么会出现例外？（社会分裂、地区主义、法律门槛。）<span class="marginnote">迪韦尔热定律的「定律」之名有争议——它更像「概率倾向」而非「必然规律」。「例外」的例子（印度的 FPTP 却多党林立）恰恰说明：选举制度只是政党格局的一个因素，社会结构（印度的语言与种姓分裂）可以压倒制度效应。</span>

- **思考二：用「加拉格指数」比较两个国家的选举公平性。** 找两个国家最近一次大选的得票率与席位率数据，代入 $LSq = \sqrt{\frac{1}{2}\sum (v_i - s_i)^2}$ 计算偏差。你会发现：比例制国家的 $LSq$ 很小（南非、瑞典常年 < 2），多数制国家很大（英国、加拿大在 10 以上）。想一想：这个「偏差值」揭示了什么？「高偏差」一定「不民主」吗？

- **思考三：如果让你设计一个「理想选举制度」，你选什么？** 要考虑：比例性（公平）、选区联系（本地代表）、政府稳定（有效执政）、少数族裔代表（包容）。完美的制度不存在——每种设计都是权衡。试着为「一个理想的民主国家」设计一套选举制度，并为你的每个选择辩护。

- **思考四：为什么选举制度的改革如此艰难？** 新西兰 1993 年改选制成功了，英国 2011 年失败了——「在位者」没有动力改变让自己当选的规则。想一想：什么条件下改革会成功（民众强烈不满、政治危机、公投机制）？「制度的路径依赖」如何锁定了现状？<span class="marginnote">选举制度改革的「在位者悖论」：现有规则下的赢家（大党）反对改革，输家（小党）想改革却无力推动——改革需要「偶然窗口」（危机、丑闻、弱势政府）+「民众压力」双碰头，罕见却并非不可能（新西兰是证明）。</span>

- **思考五：选举制度如何影响「谁被代表」？** FPTP 下「赢者通吃」，落选党的选民在议会没有声音；比例制下「每票有值」，但可能让小党和极端党得势。想一想：女性和少数族裔的议会代表率，与选举制度有什么关系？（比例制国家女性议员比例普遍更高。）为什么？

**本课核心概念速览**：

| 概念 | 一句话掌握 |
| --- | --- |
| 选举制度 | 选票转化为席位的规则总和 |
| 相对多数制 FPTP | 简单得票最多者胜出的单席选区制度 |
| 绝对多数制 | 要求过半、不足则两轮决选的制度 |
| 名单比例制 | 按政党得票比例分配席位的制度 |
| 单一可转移票制 | 选民排序、按配额分配席位的多席制 |
| 加拉格指数 | $LSq = \sqrt{\frac{1}{2}\sum (v_i - s_i)^2}$ 量化比例偏差 |
| 法定门槛 | 比例制设置的得票下限，低于则无席 |
| 选区规模 | 一个选区的议席数，越大越比例化 |
| 策略性投票 | 预知浪费而战略投给大党的行为 |
| 杰利蝾螈 | 操纵选区边界以利于特定政党的手法 |

**进一步阅读**：想深入选举制度，按顺序读：迪韦尔热《政党政治》、利普哈特《选举制度与政党制度》、塔格佩拉与舒加特《席位与选票：选举制度的数学》。再进阶可以读各国选举制度改革的比较研究。

## 7 小结

- 选举制度是**选票转化为席位的规则**，分多数代表制与比例代表制两大族。
- 多数制（FPTP、决选制）倾向**两党制与单党政府**，比例制（名单制、STV）倾向**多党与联合政府**。
- 多数制与比例制的取舍是**有效政府 vs 公平代表**。
- 加拉格指数 $LSq = \sqrt{\frac{1}{2}\sum (v_i - s_i)^2}$ 量化席位对得票的偏离。
- 法定门槛、选区规模、策略性投票、族群空间分布都会放大或修正制度后果。
- 选举制度设计没有最优解，只有「适合本国条件」的平衡。
