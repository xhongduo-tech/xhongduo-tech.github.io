## 为什么从政治参与开始

上一篇聚焦投票——民主最核心的参与方式。但公民的政治生活远不止四年一次走进投票站：有人写请愿书，有人参加游行，有人联系议员，有人加入政党，也有人（在威权体制下）参加被组织的「群众活动」。这些行为的合集就是**政治参与（political participation）**。它是测量一个政权「谁在发声、谁被听见」的标尺，也是理解民主健康度、威权动员机制与政治不平等的关键窗口。<span class="marginnote">政治参与的经典定义来自维巴与尼（Verba & Nie）：公民「以影响政府人员的选择或其行为为目的而从事的活动」。注意「目的」二字——非政治性的社区活动不在其中。</span>

## 1 政治参与的谱系

政治参与不是一个单点行为，而是一条从**常规**到**非常规**、从**个人**到**集体**的光谱：

**常规参与（conventional participation）**：在既有制度框架内活动——投票、竞选、捐款、联系官员、参加政党、参加社区会议。
**非常规参与（unconventional participation）**：制度外的表达——示威、静坐、抵制、请愿、网络抗议，直至最激烈的暴力抗争。<span class="marginnote">非常规参与不必然「非法」：合法示威是民主的常规选项；但高强度的非常规参与（暴乱、占领）常被视为政治系统功能失调的信号——「街头政治」的兴起往往意味着制度内的渠道堵塞了。</span>

维巴与尼区分了四种参与模式，值得对照：

| 模式 | 主要活动 | 参与者画像 |
| --- | --- | --- |
| 投票者 | 定期投票 | 最广，但投入浅 |
| 竞选活动者 | 助选、捐款、集会 | 投入深，党派性强 |
| 社区活动者 | 参与地方组织与公共事务 | 地方精英，合作导向 |
| 个人联络者 | 为个人问题联系官员 | 资源多、教育高 |

**重点：政治参与的结构是不平等的。** 维巴等人在《声音与平等》（Voice and Equality）中提出核心发现——**政治参与的资源模型**：教育、收入、时间与组织网络决定谁参与。富裕、高教育、有组织联系的人参与更多，于是「谁的声音被听见」系统性地偏向优势群体。这一「参与的不平等」是民主理想与现实之间的永恒张力。

## 2 参与的解释：为什么有人参与有人不参与

政治学综合四种解释变量：

**资源（resources）**：时间、金钱、技能。失业者时间多但金钱少，忙碌白领反之——资源组合决定参与的可能。
**心理倾向（psychological engagement）**：政治兴趣、政治效能感（「我的行动能影响政治吗」）、政治知识。效能感强的人更愿参与。<span class="marginnote">效能感是参与研究的核心心理变量：即使资源充足，若一个人坚信「投了也没用」，也不会参与。威权政权常通过「反正没用」的暗示来抑制参与——降低效能感是一种隐形的压制。</span>
**动员（mobilization）**：被政党、组织、人际网络「拉入」政治。许多人不主动参与，是被熟人拉去参加集会的。动员网络越密，参与率越高。
**结构（institutions）**：制度提供参与渠道的多少——登记程序越简便、投票日是否为假日、结社越自由，参与越多。制度是参与的「高速公路或泥泞小路」。

**辨析｜易错点：** 别把「不参与」一律解读为「冷漠或愚昧」。不参与可能是理性计算的结果（我的一票不重要），可能是效能感低（我的参与没用），也可能是制度把参与成本抬得太高（排长队、程序复杂）。把低参与率诊断为「公民素质问题」而忽略制度障碍，是常见的分析误区。

## 3 参与与民主类型

政治参与在不同政体下呈现出截然相反的形态：

**民主体制下**：参与是**自愿、多元、竞争性**的。公民自由选择参与渠道，参与的结果可能改变政策与统治者。
**威权体制下**：参与常被**组织化、仪式化、控制化**——群众大会、指示性投票、各种「组织动员」的参与。这种「被组织的参与」功能是展示忠诚、生产合法性、监控社会，而非改变政策。<span class="marginnote">亨廷顿（Samuel Huntington）把这种动员型参与称为「参与爆炸」的风险；而研究威权政权韧性的学者则指出，可控的动员参与恰恰是威权政权自我巩固的工具——「高参与率」未必意味着民主，也可能意味着控制。</span>

**重点：参与的形式不能只看数量，还要看性质。** 同样是「90% 的投票率」，在自由选举中是公民热情的证明，在动员型体制中可能是强制与表演。研究政治参与必须同时问「是否自愿」「是否有选择」「是否有效」——这三个问题比参与率数字更能说明民主的真实健康状况。

## 4 参与的新形态：数字参与

互联网与社交媒体改写了政治参与的版图：

**线上请愿与动员**：Change.org、网络签名使请愿成本趋近于零，参与门槛大幅下降。
**社会运动的新组织方式**：网络去中心化动员让「无领袖运动」成为可能——占领华尔街、阿拉伯之春都依赖社交网络快速集结。<span class="marginnote">数字参与的争议：它能快速集结人群，却难以转化为持久的组织与制度力量；「点击主义（clicktivism）」式的轻量参与是否稀释了真正有价值的深度参与，是学界持续争论的问题。</span>
**参与的信息基础被重构**：算法推送既可能激发参与（让更多人看见议题），也可能制造回音壁（让异见者更孤立、更愤怒）。<span class="marginnote">这再次与第二篇《政治沟通》衔接：数字参与不是「参与」的孤立变种，而是整个政治信息生态的产物——它可能放大政治不平等（有数字技能者更强势），也可能让边缘声音首次被听见。</span>

**辨析｜易错点：** 数字参与是「增量」而非「替代」。点击请愿不会取代投票与组织——线上动员的终点往往是线下的集会和投票站。把数字参与浪漫化为「新民主」或贬斥为「懒惰的表演」，都是偏颇的。

## 5 案例研读：政治参与的比较测量

政治参与如何被跨国比较？研究者用「参与指数」把抽象的参与概念变成可比较的数字：

**参与的方式清单**：维巴等人列出「政治参与」的可测量清单——投票、竞选活动、社区参与、与官员联络、捐款、请愿、示威等十余种方式。跨国调查（世界价值观调查、欧洲社会调查）用统一问卷询问「过去一年你是否做过 X」，生成参与率的跨国数据。<span class="marginnote">参与清单的启示：投票只是参与的「冰山一角」——把参与窄化为投票，会系统性低估公民的政治活跃度，也会漏掉威权体制下「无投票却有参与」（动员型参与）的现象。</span>
**参与的国别差异**：北欧的参与率高而均衡（高投票率+高组织参与）；美国呈现出「高竞选参与+低投票率」的悖论（竞选投入大但投票动员不足）；东亚社会则呈现「高政治兴趣+低制度参与」的组合。<span class="marginnote">东亚参与模式的解读：公民对政治有兴趣、信任度高，但不倾向通过制度性参与（投票、游行）表达——这与中国、日本等东亚社会的「秩序取向政治文化」相关，也说明「参与」的形式随政治文化而变。</span>
**参与不平等的跨国证据**：在所有国家，教育与收入都预测参与水平——「参与的不平等」是一个普遍现象。北欧通过福利国家与高密度组织网络部分缓解了这种不平等，美国则加剧了它（金钱政治、动员资源向富人倾斜）。

**辨析｜易错点：** 参与率数据要小心解读。高参与率可能是民主健康（北欧），也可能是动员控制（威权）；低参与率可能是政治冷漠，也可能是制度障碍（投票登记难、参与渠道少）。**离开「是否自愿、是否有选择、是否有效」三个问题，参与率数字没有任何意义**——这是本专题反复强调的「参与性质重于参与数量」。

**重点：跨国比较让「参与」从「道德理想」变成了「可诊断的变量」。** 它揭示的核心规律是：**政治参与的不平等是普遍而顽固的——那些最需要被倾听的群体，恰恰是最少参与的群体。** 民主的质量，某种程度上取决于能否缩小这种「参与鸿沟」。<span class="marginnote">这一发现连接《政治文化》的公民文化研究与《政治决策》的决策科学：参与的质量、平等与制度效果，是民主政治「输入—转换—输出」全链条的关键环节。</span>

## 6 延伸思考与进一步阅读

把政治参与的知识用起来，五个问题值得自己推演：

**思考一：给自己做一份「政治参与体检表」。** 列出维巴等人的参与清单（投票、竞选、社区活动、联络官员、捐款、请愿、示威），逐项问自己「做过吗、为什么做/不做」。你会发现自己的参与模式——是「投票型」（只投票）、「行动型」（深度参与）、还是「疏离型」（什么都不做）？想一想：你的参与结构反映了你哪些资源与心理状态？<span class="marginnote">自我体检的价值：参与研究最容易被当作「研究别人」——但每个人的参与模式都是资源、效能感、动员与制度的产物。理解自己的参与局限，才能理解整个社会的参与不平等。</span>

**思考二：为什么「参与不平等」是民主的顽疾？** 教育高、收入高、有组织联系的人参与更多，于是他们的诉求被更多听见——「谁的声音被听见」系统性地偏向优势群体。想一想：这是否意味着民主「名义上平等、实际上不平等」？有哪些制度设计（强制投票、参与式预算、降低参与门槛）可以缓解参与不平等？

**思考三：威权体制下的「高参与率」是什么？** 动员型参与——群众大会、指示性投票、组织化游行——参与率极高，但性质是完全的「被组织」。想一想：为什么威权政权需要「表演性参与」？「参与的数量」与「参与的自由」，哪个更能说明民主健康状况？

**思考四：数字参与是「参与的民主化」还是「参与的娱乐化」？** 网上请愿、转发、点赞让参与「轻量化」——门槛低了、人数多了，但深度也浅了（「点击主义」）。想一想：如果人们用「点赞」替代「投票」，民主是变好还是变糟？「轻参与」与「深参与」如何共存？

**思考五：政治冷漠是民主的「敌人」还是「安全阀」？** 阿尔蒙德与维巴说健康民主需要「适度疏离」（防止全民狂热）；但也有人说冷漠让少数人垄断政治。想一想：什么程度的政治冷漠是「健康的疏离」、什么程度是「危险的放弃」？你身边的「政治冷漠」属于哪一种？<span class="marginnote">这道思考题回扣《政治文化》的公民文化命题：民主不需要「人人都是积极分子」，但需要「关键时刻有人行动」——政治参与的理想状态，是「平时适度、必要时充分」的弹性公民社会。</span>

**本课核心概念速览**：

| 概念 | 一句话掌握 |
| --- | --- |
| 政治参与 | 以影响政府选择或行为为目的的活动 |
| 常规参与 | 制度框架内的投票、竞选、联络、社区活动 |
| 非常规参与 | 制度外的示威、请愿、抵制等表达 |
| 资源模型 | 教育、收入、时间、网络决定参与能力 |
| 政治效能感 | 「我的行动能影响政治吗」的信念 |
| 动员 | 被政党、组织、熟人拉入政治的过程 |
| 动员型参与 | 威权体制下被组织、仪式化的「高参与率」 |
| 数字参与 | 网上请愿、网络动员、无领袖运动的新形态 |
| 点击主义 | 轻量网络参与对深度参与的稀释 |

**进一步阅读**：想深入政治参与，按顺序读：维巴、尼与金《参与与美国民主》、维巴等《声音与平等》（参与不平等的经典）、帕特南《独自打保龄》（美国参与衰落的诊断）。

## 7 小结

- 政治参与是公民**以影响政治为目的的活动**，从常规到非常规、从个人到集体构成谱系。
- 维巴与尼区分**投票、竞选、社区活动、个人联络**四种参与模式。
- 政治参与存在**系统性的资源不平等**：教育、收入、组织网络决定谁的声音被听见。
- 参与与否由**资源、心理倾向、动员、制度结构**四组变量共同解释。
- 威权体制下的参与常是**组织化、仪式化的动员**，参与率数字需结合性质判断。
- 数字参与降低了门槛、重塑了动员方式，但无法替代深度参与。
