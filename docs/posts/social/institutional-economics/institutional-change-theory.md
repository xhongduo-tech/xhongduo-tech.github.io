# 制度变迁理论

<div class="epigraph">

## 为什么从制度变迁开始

前八节我们解释了制度是什么、为什么重要、为什么顽固。但一个完整的制度理论必须回答最后一个问题：**制度既然这么顽固，它到底是怎么变的？** 历史上既有数百年不变的制度，也有烈火烹油的制度革命；有从无到有的产权体系，也有轰然倒塌的帝国秩序。诺思的制度变迁理论，是经济史领域第一次给出「制度为何变、何时变、怎么变」的系统回答。<span class="marginnote">诺思这一节的理论姿态很特别：他既反对「制度是神圣不可变的」，也反对「制度会自然演化到最优」。他的中间道路是：<strong>制度由人的选择改变，但改变发生在规则的边际，且方向被历史框定</strong>。</span>

## 1 变迁的主体：组织与企业家

谁在推动制度变迁？诺思的回答是：**组织及其中的企业家**。

回顾第一篇的定义：组织是「球员」，制度是「规则」。球员在规则下比赛，但比赛打久了，球员会想「能不能把规则改得对我更有利」。于是：

**经济组织**（企业、行会、合作社）发现现有产权、税收、准入制度阻碍了自己获利，就游说、贿赂、创新合约去改变规则；
- **政治组织**（政党、议会、官僚机构）为了扩大权力或巩固联盟，修改政治规则；
- **教育与社会组织**（学校、教会、媒体）通过塑造意识形态，改变人们对制度正当性的认知。

组织之所以是变迁的发动机，是因为组织是「制度矩阵中机会的最大发现者」——它们在规则下逐利，逐利中不断试探规则的边界，边界一旦松动，就向外扩张。<span class="marginnote">诺思由此把组织定义为「由共同目标约束的个人群体，其成员为实现目标而合作」——目标越明确、利益越集中，组织推动制度变革的动力越强。</span>

这里要特别强调「政治市场的企业家」——与追逐利润的经济企业家不同，政治企业家追求的是权力与支持：他们策划宪法修订、动员联盟、制造意识形态共识。两套市场的企业家都在「规则边际」上作业，区别只在计价的货币是利润还是选票。

## 2 变迁的触发：相对价格与偏好的改变

组织想改规则不假，但什么时候「想」会变成「动」？诺思给出两个触发器：

**相对价格的改变**。制度之所以曾经稳定，是因为当时的收益结构让各方满意；而当相对价格变化——劳动力变贵、资本变便宜、某种资源变得值钱——原来的规则就开始「不合身」了。欧洲黑死病后劳动力稀缺，领主与农民围绕农奴制的重新谈判由此爆发；大西洋贸易兴起后，商人的财富地位上升，旧的政治规则再也装不下新的利益格局。

相对价格的变化还有一层放大效应：它改变的不只是「谁受益」，还有「谁的谈判地位」——劳动力变贵让农民有了离场的选择，谈判杠杆随之倾斜。诺思用「相对价格」这个词，恰恰因为它把「价格」与「权力」两个维度缝在了一起。

**偏好的改变**。人的偏好并非固定：随着教育普及、观念传播、意识形态演化，「什么制度是正当的」会整体位移。当人们不再相信君权神授，旧制度的合法性根基就松动了。<span class="marginnote">诺思把「相对价格」与「偏好」并列，等于承认制度变迁既有经济利益的驱动，也有观念文化的驱动——这正是他在<a href="informal-constraints.md">《非正式约束》</a>里把意识形态列为约束的深意：意识形态既是稳定制度的黏合剂，也是推翻制度的动员令。</span>

两个触发器并非独立运作。相对价格的变化往往先改变利益格局，利益格局的改变又推动观念与偏好的迁移——劳动力变贵让「农奴制度不合理」的看法有了经济基础，大西洋贸易让「商人应参政」的诉求有了实力支撑。**价格与偏好是一前一后的两条腿：价格先动，偏好跟上，制度才真正被改写**。

把两个触发器合起来看，制度变迁就有了「时机」的概念：相对价格与偏好同时指向变革时，变迁的阻力最小、成功的概率最高；两者背离时，即使价格压力巨大，缺乏观念支持也常常久拖不决。**制度变迁的最佳时机，是两个触发器同频的时刻**。

## 3 公式解析：变迁在什么条件下发生

把「变迁何时发生」写成收益-成本比较，诺思的机制就一目了然。对任何一个有影响力的行为主体 $i$（组织、企业家、利益集团），令：

$$
G_i = W_i^{\text{新}} - W_i^{\text{旧}}
$$

其中 $W_i^{\text{新}}$ 是规则改变后 $i$ 的预期收益，$W_i^{\text{旧}}$ 是现状收益，$G_i$ 是变革带来的净收益；再令 $C_i$ 为 $i$ 推动变革必须付出的成本（组织动员、谈判、承受风险的代价）。

**变迁发生的条件是 $G_i - C_i > 0$；制度稳定的条件是全体有影响力主体都满足 $G_i - C_i \le 0$。**

拆解这个条件的含义：

- **第一步，看稳定**：当 $G_i \le C_i$ 对所有人都成立，没有任何一方有动力推翻现状，制度就处于「谈判均衡」——不是因为规则完美，而是因为**改不动**。诺思称之为「制度矩阵的稳定性」。
- **第二步，看触发**：相对价格的改变（比如劳动力价格骤升）会抬高某些主体的 $W_i^{\text{新}}$，使 $G_i$ 越过 $C_i$——于是变革的尝试开始出现。
- **第三步，看边际**：$G_i - C_i > 0$ 的主体通常只想改「对自己有利的那部分规则」——税收调一点、准入松一点、产权清晰一点。**这就是为什么制度变迁多半是边际的、渐进的，而不是整体的、突变的**。<span class="marginnote">「变迁发生于边际」是诺思理论最反直觉、也最深刻的断言：<strong>制度变迁不是宪法级的大改写，而是无数个小边角的不断挪动，最终在长期积累成大变动</strong>——一如演化生物学里基因突变在代际间的累积。</span>

用数字把「边际变迁」具象化。设想一位庄园领主面对黑死病后的劳动力短缺：若维持农奴制（旧制度），庄园净收益 $W^\text{旧} = 100$；若把农奴改为自由佃农、付薪雇工（新制度），预期净收益 $W^\text{新} = 140$——前提是农民愿意留下。变革净收益 $G = 40$，而推动改革的成本 $C$（与农民谈判、承担短期生产混乱）约为 $15$，则 $G - C = 25 > 0$——改革发生了，但只是「把人身依附改成租佃契约」这一小步，农奴制框架并没有一夜消失。<span class="marginnote"><strong>改革的幅度由「边际上最划算的那一步」决定，而不是由理想制度决定</strong>——这就是为什么欧洲从农奴制走向自由劳动走了几百年。</span>

再对照一个反例：若 $W^\text{新} = 110$（改革收益有限）而 $C = 30$（动员成本高企），则 $G - C = -20 < 0$，领主宁可维持旧制——即使从整个社会看自由劳动更优。**制度变迁的刹车，往往不是「不知道该往哪走」，而是「没人愿意承担第一步的代价」**。

## 4 变迁的两种形态：渐进与间断

基于上面的机制，制度变迁呈现两种形态：

**渐进变迁（incremental change）**：常态。无数组织在各自边际上推动微小调整——判例的累积、惯例的迁移、合同的创新。这类变迁难以察觉，但几代人下来可以面目全非。英国普通法就是渐进变迁的样板：没有哪一次改革一夜重写了法律，是几百年的判例在「边际上」把法治精神磨了出来。

渐进与间断之间没有绝对界线：一场看似突变的革命，往往只是把数十年的边际压力集中引爆；而一次彻底的制度重建，落地时依然要靠无数小调整来填充。**两种形态共用同一台发动机——组织在规则边际上的逐利**。读懂这台发动机，制度史就不再是一连串偶然事件，而是一篇可以被解释的因果叙事。

**间断变迁（discontinuous change）**：例外。革命、征服、政权更迭带来的整体性剧变。苏联的建立与解体、日本明治维新、法国大革命。诺思指出：**间断变迁也常常不是「无中生有」，而是把长期积压的边际压力一次性释放**——旧制度的边际再也推不动时，就可能被整体推翻。

明治维新是「间断变迁」的经典注脚：1868 年倒幕运动在数月内推翻了延续两百六十余年的幕府体制，看似一场整体性剧变；但明治政府随后的废藩置县、地税改革、殖产兴业，却是用一连串「边际调整」逐步落实的。**剧变打开窗口，边际变动填充内容**——两者不是替代关系，而是接力关系。

与之配套的还有一对概念：**分配性效率与适应性效率**。前者关心「给定规则下资源如何配置最优」，后者关心「规则本身能不能适应环境变化而改进」。诺思认为：**长期增长的真正源泉是适应性效率**——不是某套规则当下最优，而是制度是否具备自我修正的能力。<span class="marginnote">把这对概念与<a href="path-dependence.md">《路径依赖》</a>连起来看：<strong>好制度不是「一次选对」，而是「选错还能改」</strong>——适应性效率正是对路径依赖的解毒剂。</span>

把「适应性效率」落到现实：它意味着制度的优劣不取决于「当下是否完美」，而取决于「能不能在环境变化后及时修正自己」。苏联的计划经济在重工业化时代曾有效率，却在信息时代僵化——缺的正是适应性效率。**长期繁荣买的是「纠错能力」，不是「一次正确」**。

## 5 核心要点：制度变迁的完整逻辑

| 要素 | 内容 |
| --- | --- |
| 变迁主体 | 组织及其中的企业家（政治与经济市场双线） |
| 变迁触发器 | 相对价格改变、偏好改变 |
| 变迁条件 | $G_i - C_i > 0$，即有主体能从改规则中获利 |
| 变迁形态 | 渐进为主（边际累积），间断为辅（压力释放） |
| 制度优劣标尺 | 适应性效率（能否自我修正）> 分配性效率 |
| 边际变迁 | 组织只在对自己有利的规则边角上推动调整 |
| 制度矩阵 | 正式规则、非正式约束与执行特性共同构成的制度整体 |

本节术语速查：

| 术语 | 含义 |
| --- | --- |
| 组织 | 由共同目标约束的个人群体（企业、政党、行会） |
| 相对价格 | 各要素相对稀缺程度的变化 |
| 渐进变迁 | 无数小边际调整的长期累积 |
| 间断变迁 | 革命、征服等整体性剧变 |
| 分配性效率 | 给定规则下资源的最优配置 |
| 适应性效率 | 规则本身自我修正的能力 |

**辨析｜易错点：渐进变迁 ≠ 没有变迁。** 常见误解是「既然变迁是渐进的，就等于制度停滞」。恰恰相反：单个边际调整难以察觉，但几十年积累起来可以彻底改写制度——英国普通法、现代公司制度都是「小步快跑」的产物。**渐进讲的是速度，不是幅度；幅度可以随时间的累积而巨大。**

## 6 小结

- 制度变迁的主体是**组织与企业家**——规则下的球员推动规则改变。
- 触发器是**相对价格与偏好的改变**，它们抬高某些主体的变革净收益。
- 变迁条件为 $G_i - C_i > 0$；制度稳定 = **没有任何有影响力者能从改规则中获益**。
- 变迁以**渐进**为主、**间断**为辅；长期繁荣靠**适应性效率**而非分配性效率。
- **政治与经济两套市场**都在推动变迁：经济企业家用利润计价，政治企业家用选票与权力计价。

在下一节，我们将进一步追问变迁背后的权力：组织想改规则，凭什么改得动？——**制度变迁的驱动者：组织、企业家与政治权力**。
