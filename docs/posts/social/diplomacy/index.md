# 外交学

外交学是研究国家主权体之间交往方式与规律的政治学二级学科，既追问外交"为何如此"的理论逻辑，也还原外交制度与实务的历史演进，并落实到各国具体的外交实践中。学完这些章节，就写完了从外交理论、外交史到外交实务与国别外交的完整知识框架。

## 对标教材

- 金正昆.《外交学》. 中国人民大学出版社（第三版）
- 杰夫·贝里奇.《外交理论与实践》. 北京大学出版社
- 鲁毅等.《外交学概论》. 世界知识出版社
