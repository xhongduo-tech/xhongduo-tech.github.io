## 为什么从货币供给过程开始

上一节我们看到了央行的权力来源——它能注入货币基础 $MB$。但**货币供给不是央行一个人说了算**：央行发一美元「高能货币」，银行体系按部分准备金制度把它放大成数美元的存款货币；公众持现多少、银行留多少超额准备金，都会改变放大的倍数。理解这套「央行—银行—公众」三方博弈的链条，是全书由「货币是什么」走向「货币如何被创造」的枢纽，也是后面所有货币政策章节（第 9、12—16 篇）的微观地基。<span class="marginnote">货币供给过程是「内生货币 vs 外生货币」争论的战场：教科书先给出教科书式的乘数模型（央行外生主导），再指出现实中乘数随经济行为波动——央行「导演」但银行与公众「即兴发挥」。理解这个张力，就能读懂为什么同一套扩表在不同时期效果迥异。</span>

本章（Mishkin §14）主线：**三个参与者的行为 → 四个决定性变量 → 货币乘数公式 → 货币政策工具如何经此作用于货币供给**。

## 1 存款创造：部分准备金制下的几何级数

设想央行用 1000 美元公开市场购买国债，向银行体系注入 1000 美元准备金，法定准备金率 $r = 10\%$。链条如下（这正是配图所画）：

1. **银行 A** 收到 $1000 准备金，只需保留 $100$（$= 10\%$），把 $900$ 贷出。
2. 借款人把这 $900$ 存入**银行 B**，银行 B 保留 $90$，贷出 $810$。
3. 如此循环：银行 C 存款 $810$，保留 $81$，贷出 $729$……

**总存款是等比级数**：

$$
\text{总存款} = 1000 \times \left(1 + 0.9 + 0.9^2 + 0.9^3 + \cdots\right) = 1000 \times \frac{1}{1 - 0.9} = 10000
$$

一笔 $1000$ 的基础货币，在 $r = 10\%$ 下创造出 $10000$ 的存款货币——**存款创造乘数（deposit multiplier）为 $1/r = 10$**。<span class="marginnote">「一家银行只能贷出准备金的 $1-r$ 倍，整个体系却能创造 $1/r$ 倍的存款」是金融学最著名的反直觉结论：单个银行的稳健（保持准备金）与整个体系的扩张（多次放贷）并不矛盾——因为每次放贷都变成下一家银行的存款。第一级《数学》里的等比级数求和，在这里是货币创造的实际公式。</span>

**辨析｜易错点：** 单个银行「存款 = 准备金」是**会计恒等式**，体系「存款 = 准备金 / r」是**均衡收敛**——两者极易混淆。一家银行无法「多贷一块钱」，因为它贷出去的钱会流走；但整个体系可以，因为流走的钱只是换了一家银行存。把「单个银行」与「整个体系」的层次分开，是读懂货币乘数的第一课。

## 2 公式解析：货币乘数 m

把存款创造推广到包含公众行为，得到完整货币乘数。设：

- $r$：法定准备金率（央行设定）
- $e$：**超额准备金率（excess reserves ratio）**＝超额准备金 / 存款（银行行为）
- $c$：**通货比率（currency ratio）**＝公众持现 / 存款（公众行为）

则货币供给为：

$$
M = m \times MB, \qquad m = \frac{1 + c}{r + e + c}
$$

- **第一步，$MB$ 的分配**：货币基础被分成两部分——公众持有的通货 $C$ 和银行持有的准备金 $R$。准备金里又分法定与超额：$R = rD + eD$。
- **第二步，$MB$ 与 $M$ 的连接**：$M = C + D = cD + D = (1+c)D$；而 $MB = C + R = cD + (r+e)D = (c + r + e)D$。
- **第三步，相除**：$\frac{M}{MB} = \frac{(1+c)D}{(c+r+e)D} = \frac{1+c}{c+r+e}$，即乘数 $m$。
- **第四步，直觉**：分母 $c+r+e$ 表示「每一美元存款要占用的基础货币」；分子 $1+c$ 表示「每一美元基础货币能支撑的总货币」。**任何让分母变大的行为（公众多持现、银行多留超额准备金、央行提法定准备金率）都压低乘数；反之抬升乘数**。<span class="marginnote">当 $c = e = 0$ 时 $m = 1/r$，回到第一节的简单存款乘数——这说明简单乘数是完整乘数在「公众不持现、银行不留超额」下的特例。完整乘数的价值在于：它把货币供给的决定权从央行一家，改写为央行（$r$）、银行（$e$）、公众（$c$）三方的合谋。</span>

## 3 四个变量如何被决定：货币供给的三方博弈

货币供给不是央行单方面拧阀门，而是四个变量被不同主体分别驱动：

| 变量 | 决定主体 | 行为逻辑 |
| --- | --- | --- |
| 货币基础 $MB$ | 央行 | 公开市场操作、贴现贷款、量化宽松 |
| 法定准备金率 $r$ | 央行 | 设定下限，很少动 |
| 超额准备金率 $e$ | 银行 | 权衡「流动性不足成本」与「持金机会成本」 |
| 通货比率 $c$ | 公众 | 支付习惯、对银行的信心、非法交易需求 |

**核心要点**：危机中，$e$ 与 $c$ 会同时飙升——银行害怕挤兑而囤积超额准备金，公众恐慌而提现。分母变大，乘数坍缩，于是出现「央行扩表、$MB$ 猛增、而 $M$ 不动甚至下降」的现象。2008 年后美联储三度量化宽松、货币基础翻了三倍多，但广义货币增长温和——正是乘数坍缩抵消了基础货币扩张。<span class="marginnote">这是理解「2008—2020 年大放水为何没有高通胀」的关键机制，也是「货币数量论（第 11 篇）为何需要乘数修正」的实证背景：MV=PY 里的 V（流速）随 c、e 变化而剧烈波动。</span>

## 4 公式解析：央行三大工具如何撬动 MB

央行直接控制的是 $MB$，三大工具各有不同的作用机制：

**（1）公开市场操作（open market operations）**：央行在二级市场买卖国债。买入 → 支付准备金给卖出方 → $R$↑ → $MB$↑。它是美联储最主要的工具：灵活、精确、可逆、每日执行。**买入国债 $1000$，$MB$ 立即增加 $1000$，而且央行可随时反向卖出回笼。**

**（2）贴现贷款（discount loans）**：央行向银行放款，收取贴现率。银行主动来借，央行被动应对——所以贴现贷款对 $MB$ 的影响是「银行主导、央行定价」，不如公开市场可控。贴现率提高 → 借款减少 → $MB$ 少增。

**（3）法定准备金率（reserve requirements）**：$r$ 提高 → 同样的存款要占用更多准备金 → 乘数缩小 → $M$ 减少。它是**猛药**：一次调整波及全部银行，几乎不再使用（美联储 2020 年已取消法定准备金率要求，转向利息率工具）。

三者分别对应：公开市场操作**直接、精准**；贴现窗口**被动、应急**；准备金率**粗放、罕见**。<span class="marginnote">美联储 2008 年后的新工具是「对准备金付息（IORB）」与「隔夜回购（ON RRP）」——用利率走廊把联邦基金利率钉在目标区间，利率工具取代数量工具成为主流（第 9 篇详述）。理解「数量 vs 价格」两代工具，是货币政策思想史的一条暗线。</span>

**辨析｜易错点：** 公开市场购买增加的是**准备金（基础货币）**，不是直接增加公众的存款。存款要靠银行体系放大——若银行把新增准备金囤起来（$e$ 上升），$M$ 并不增加。所以「央行买债 = 印钱给老百姓」是常见的错误表述：央行买债是**创造银行准备金**，要经过放贷环节才变成公众的货币。

## 5 小结

- 部分准备金制下，一笔基础货币经银行体系逐级放贷，**总存款收敛为 $MB \times (1/r)$**——等比级数求和。
- **货币乘数 $m = \frac{1+c}{r+e+c}$**：央行定 $r$，银行定 $e$，公众定 $c$，货币供给是三方的合谋。
- 危机中 $c$、$e$ 飙升 → 乘数坍缩 → **扩表未必带来货币扩张**。
- 三大工具：**公开市场操作**（主要、精准）、**贴现贷款**（被动、应急）、**法定准备金率**（粗放、罕见）。
- 现代央行转向**利率走廊**（准备金付息）调控利率，数量工具让位于价格工具。
- 货币供给过程是「央行导演、银行与公众即兴」的博弈——不是单向的印钞。
