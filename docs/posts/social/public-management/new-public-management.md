# 新公共管理运动

## 为什么从新公共管理开始

上一节我们看到公共部门与私人部门的边界在移动。
20 世纪 80 年代，
一场把这场移动推向极致的思想运动席卷全球——**新公共管理运动（New Public Management, NPM）**。
它把市场逻辑、竞争机制与绩效意识大规模引入政府，一度成为「政府改革的标准答案」。
<span class="marginnote">NPM 被许多学者称为公共管理学的「范式转换」：
从关注「过程与规则」转向关注「结果与绩效」。
理解这场运动，才能理解当代政府管理几乎所有流行词汇——绩效、外包、
顾客、服务型政府。
</span>这一节承接《公共部门与私人部门》，
并为后面的《政策工具》《政府绩效管理》《政府购买服务》等专题提供思想源头。

## 1 运动的兴起：三条背景线

NPM 的兴起不是偶然，至少有三条历史线索汇合：

- **财政压力**：20 世纪 70 年代石油危机后，
  西方国家福利支出膨胀、财政赤字高企，「大政府」难以为继。
- **意识形态转向**：新自由主义思潮抬头，主张私有化、放松管制，
  撒切尔（英国）与里根（美国）执政是标志性事件。
- **管理理论输入**：企业管理中的目标管理、质量管理、
  流程再造被引入公共部门，
  形成「管理主义」（managerialism）。

1992 年，美国学者戴维 · 奥斯本与特德 · 盖布勒出版《改革政府》，
提出「企业家政府」（entrepreneurial government）十项原则，
「掌舵而非划桨」正是其中最著名的一句。
<span class="marginnote">「掌舵/划桨」的隐喻源于古希腊的航海意象：
舵手决定方向，桨手出力划船。
奥斯本主张政府应把「划桨」（直接生产）交给市场与社会，
自己专注于「掌舵」（决策与监督）——这句话正是第四篇《政府购买服务》的直接纲领。
</span>

## 2 NPM 的核心信条

NPM 不是单一理论，而是一组信条的组合。
通常概括为以下几个方面：

- **市场化**：把竞争机制引入公共物品供给，通过合同外包、民营化、
  公私伙伴关系（PPP）让私人部门参与。
  <span class="marginnote">竞争被视为 NPM 的「第一原则」：
  即使不能民营化，也要在公共部门内部制造竞争，
  比如英国的强制竞争招标（CCT）要求地方政府服务必须公开竞标。
  </span>
- **顾客导向**：把公众当作「顾客」，政府像企业一样提供选择、
  回应需求，推动服务型政府建设。
- **绩效管理**：以「结果」而非「过程」考核，
  强调「3E」——经济（economy）、
  效率（efficiency）、效能（effectiveness）。
  <span class="marginnote">「3E」源自英国审计委员会 20 世纪 80 年代的绩效审计框架，
  是第三篇《政府绩效管理》的核心理念。
  </span>
- **分权与授权**：减少层级，把决策权下放给一线管理者，推行「企业家式」的分权。
- **精简与重构**：缩小政府规模，重组机构，推行大部制与一站式服务。

## 3 批评与反思：新公共管理的遗产

NPM 在 20 世纪 90 年代达到顶峰，随后遭遇系统性批评：

- **「顾客」隐喻失当**：公民不只是顾客，还是主人与股东；
  公共服务不是「卖给顾客」，而是「回应权利」。
- **碎片化**：合同外包与机构分权导致部门割裂，
  公民需要为一项事务跑多个窗口，
  「空心化国家」（hollowing out the state）被广泛讨论。
- **绩效迷思**：
  过度强调可测指标导致「目标置换」——考核什么就做什么，
  指标漂亮而实质受损，如医院排队时间缩短却牺牲了诊疗质量。
- **公平受损**：
  市场化可能把服务引向「有钱的顾客」而非「最需要的公民」，
  与公共服务的公平原则冲突。
  <span class="marginnote">「目标置换」（goal displacement）指组织把「达成目标的手段」错当成「目标本身」。
  这条规律不仅在公共部门，在第八级《管理学》的绩效考核中同样成立，
  甚至在大模型评测里也反复出现——指标与真实能力脱节。
  </span>

## 4 核心对比：传统公共行政与新公共管理

| 维度 | 传统公共行政 | 新公共管理 |
| --- | --- | --- |
| 焦点 | 过程、规则、程序正义 | 结果、绩效、顾客满意 |
| 组织形态 | 科层制、集中统一 | 分权、扁平、弹性 |
| 公民角色 | 管理对象、服务客体 | 顾客、选择者 |
| 供给方式 | 政府直接生产 | 合同外包、民营化、竞争 |
| 考核标准 | 合法合规 | 3E（经济、效率、效能） |
| 对市场的态度 | 警惕、规制 | 信任、引入 |
| 价值取向 | 程序公正优先 | 效率与回应性优先 |

这张表不是「对错清单」，而是两种治理逻辑的对照。
现实中几乎没有国家纯粹采用某一端：英美更偏向 NPM，
北欧在 NPM 与福利国家之间平衡，中国则吸收了绩效管理与服务型政府元素，
同时保留了强政府角色。
<span class="marginnote">进入 21 世纪后，
学者提出「后新公共管理」（post-NPM）：主张重新整合、加强部门协调、
关注整体治理（holistic governance），
以矫正碎片化——第四篇《国家治理现代化》会看到这种整合逻辑的中国版本。
</span>

## 5 中国语境下的新公共管理

新公共管理是西方语境中诞生的运动，但它对中国政府改革产生了深远影响。
理解这种影响的方式，不是寻找中国版的「撒切尔改革」，
而是看中国如何有选择地吸收其理念、
服务于自己的改革议程。

- **绩效意识的引入**：中国吸收 NPM 的绩效理念，
  推行目标责任制、政府绩效评估、生态文明考核、脱贫攻坚考核等，
  把「结果导向」嵌入干部管理——这是 NPM「3E」理念与中国干部考核体制的结合。
  <span class="marginnote">有意思的是，
  中国引入绩效管理的路径与西方不同：西方靠合同与市场化倒逼绩效，
  中国靠「目标责任制 + 考核问责」的体制压力推动绩效。
  同一理念，两种制度载体——这是「本土化吸收」的典型案例。
  </span>
- **服务型政府建设**：2004 年中央提出建设服务型政府，
  「顾客导向」被转化为「以人为本」「执政为民」，政务大厅、一站式服务、
  公共服务热线相继建立——把「以政府为中心」转向「以群众为中心」。
- **市场化工具的有限使用**：中国没有走大规模私有化的路，
  而是选择性地引入市场化工具——政府购买服务、公私合作（PPP）、
  公用事业特许经营，同时牢牢守住核心公共部门。
  <span class="marginnote">这种「选择性吸收」的边界清晰：
  涉及国家安全、民生底线、战略资源的领域坚持国有主导，
  可在市场竞争的领域适度放开。
  它回应了 NPM 批评者的担忧——公平与责任并未被效率逻辑吞没。
  </span>
- **对大部制与整体性的探索**：
  针对西方 NPM 带来的「碎片化」教训，
  中国更强调部门协同与整体政府——大部制改革、党政机构统筹，
  都是对「后新公共管理」整合逻辑的呼应。

总结中国经验：**NPM 对中国而言不是一场运动，
而是一个「工具箱」**——从中挑选适合国情的工具（绩效、服务、市场化），
嵌入自己的制度框架。
这提醒我们，任何理论在跨境传播时都会经历「选择、改造、再语境化」的过程，
公共管理学习最重要的能力，就是识别「什么可以为我所用」。

## 6 小结

- **新公共管理**是 20 世纪 80 年代兴起的、
  把市场逻辑引入政府的一场全球性改革运动。
- 三大信条：**市场化、顾客导向、绩效管理**，辅以分权与机构精简。
- 经典口号「**掌舵而非划桨**」主张政府聚焦决策与监督，生产交给市场与社会。
- 批评集中于：顾客隐喻失当、**碎片化**、**目标置换**与公平受损。
- NPM 之后出现**后新公共管理**，主张重新整合与整体治理，平衡效率与公正。
