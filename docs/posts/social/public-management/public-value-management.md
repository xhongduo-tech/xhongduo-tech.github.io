# 公共价值管理

<div class="epigraph">
<p>公共管理者的根本使命，是创造公共价值。</p>
<footer>—— 马克 · 摩尔（Mark Moore），《创造公共价值》（Creating Public Value）</footer>
</div>

<div class="article-byline">

## 为什么从公共价值开始

上一节我们看到，新公共管理把「效率与顾客满意」推向极致，
但也因此付出了「公平受损、目标置换」的代价。
公共价值管理（Public Value Management）正是站在 NPM 肩膀上的反思：
它不否认效率，却坚持管理的目的必须回到「公共价值」本身。
<span class="marginnote">公共价值理论的标志性文本是 1995 年哈佛学者马克 · 摩尔的《创造公共价值》。
摩尔本人长期执教哈佛肯尼迪政府学院，这套理论后来成为政府战略管理的核心方法。
</span>这一节是公共管理「基础篇」的收官：从公共性出发、历经市场失灵与部门结构、
见识过 NPM 的激进与教训之后，
我们终于问出那个根本问题——公共管理到底为了什么？

## 1 从「顾客」回到「公民」

NPM 把公民当作顾客，公共价值管理认为这个隐喻是错的。
顾客在交易中只关心自己得到的商品，
而公民还关心共同体的整体处境——别人有没有学上、
河流是否干净、制度是否公平。
**公民不是被动的服务接受者，而是公共价值的共同创造者与评判者。
**<span class="marginnote">这一区分呼应了政治学中「citizen vs. consumer」的经典对照：
消费选择是私人性的，公民参与却是公共性的。
第八级《政治学》讲公民身份（citizenship）时会再次相遇。
</span>由此，公共管理者首先要回答的不是「怎么提高效率」，
而是「我们创造的这些结果，是否真的值得」。

## 2 公共价值：超越利润的价值

**公共价值（public value）**：
公民通过集体行动共同界定并期待公共部门创造的价值，包括安全、秩序、
公正、发展机会、
环境品质与公共服务本身。
它有两个不同于私人价值的特征：

**集体性**：由公民集体协商界定，而非由市场价格或股东偏好决定；
**多元性**：价值维度多元，且相互冲突——增长与环保、效率与公平、
  自由与安全，往往是鱼与熊掌。

因此，公共价值无法像企业利润那样被单一指标「衡量」，它需要**协商、
权衡与政治过程**来持续定义。
摩尔由此提出管理公共价值的「战略三角」（strategic triangle），
三个顶点缺一不可：
<span class="marginnote">战略三角的三个顶点是：
①公共价值（这项努力创造了什么公众认可的价值）；
②合法性与支持（政治授权与利益相关者支持）；
③运行能力（组织与伙伴能否把事情做成）。
公共管理者若只顾一头，项目必然失败。
</span>

## 3 公共价值管理的三原则

摩尔的管理观可以凝练为三条操作原则：

**价值为先**：先界定「值得做的事」，再谈「怎么高效地做」；
  价值是目的，效率是手段。
**政治为本**：公共管理者必须善于在政治环境中争取合法性与支持，
  把利益相关者动员起来——管理能力的一半是政治能力。
**合作生产**：公共价值常常无法由政府独自创造，需要公民、企业、
  非营利组织共同参与生产。
  <span class="marginnote">「合作生产」（co-production）在公共价值理论中特指公共服务的价值由供给者与使用者共同创造：
  医疗的效果取决于患者配合，教育的成果取决于学生投入。
  这个思想在第四篇《公共服务供给》中会深化。
  </span>

这三条原则与 NPM 的分权、外包、绩效形成鲜明对照：NPM 关注「怎么生产」，
公共价值管理追问「值不值得、为谁而做」。

## 4 核心对比：三种公共管理范式

| 维度 | 传统公共行政 | 新公共管理 | 公共价值管理 |
| --- | --- | --- | --- |
| 目的 | 执行法律与规则 | 效率与顾客满意 | 创造公共价值 |
| 公民角色 | 客体 | 顾客 | 共同创造者与评判者 |
| 管理者角色 | 执行者 | 企业家 | 战略探索者 |
| 价值来源 | 政治与法律授权 | 市场机制 | 公民协商与民主过程 |
| 绩效标准 | 合规 | 3E | 价值多元、结果权衡 |
| 供给逻辑 | 政府生产 | 外包与竞争 | 多元合作生产 |

这张表把公共管理半个世纪的范式演变压缩在一页。
要点是：**三种范式不是「后浪推前浪」的替代关系，
而是「各管一段」的并存关系**——依法执行是底线，效率是必要手段，
公共价值是最终裁判。
<span class="marginnote">现实的政府管理是三种范式的混合体：
公安执法讲合规，行政审批讲效率，而民生政策的根本标尺是公众是否受益。
学公共管理，训练的就是在三者之间自如切换的判断力。
</span>

## 5 公共价值的测量与争议

公共价值理论最大的魅力，也是它最大的软肋，都指向同一个问题：
**公共价值如何测量？
** 如果无法测量，它会不会只是挂在嘴边的漂亮口号？

**测量的挑战**：企业利润有一个无可争辩的数字，公共价值却没有。
  安全、公平、尊严、社区凝聚这些价值难以量化，
  且不同群体的权重不同——老年人与年轻人的「公共价值」清单不会完全一致。
  学者尝试用**公共价值账户（public value account）**把价值、
  成本与合法性支持放在同一张表上，但始终存在主观判断的空间。
  <span class="marginnote">公共价值测量的困境，
  正是《公共部门绩效》一节「测量困境」的哲学版：凡是被视为重要的，
  往往难以测量；
  凡是可以测量的，往往被过度强调。
  绩效指标与公共价值之间的落差，永远是绩效管理的心病。
  </span>
**对理论的批评**：批评者指出，公共价值概念过于模糊，
  可能被用来为任何政策辩护——「我们创造了公共价值」成为政客与官僚的万能挡箭牌；
  同时，谁有权界定「公共价值」本身就是一个政治问题，若由精英界定，
  可能背离民主本义。
**回应：协商与程序正义**：
  公共价值理论的支持者回应——正因为价值是模糊的，
  才更需要**公开的协商过程**来确定它；
  价值界定的程序正义，比价值内容的精确更重要。
  公共价值的合法性，不来自某个权威的断言，而来自公民参与的质量。
  <span class="marginnote">这条回应把「公共价值」与「民主治理」绑定：
  价值不是被发现的，而是被共同创造的。
  它与第八级《政治学》中的协商民主理论、以及中国「协商于民、
  问计于民」的治理实践高度呼应。
  </span>
- **数字时代的公共价值**：
  公共价值理论正在被应用于数字政府评价——政务 App 的价值不只看点击量，
  更要看它是否提升了公民的可及性、透明性与参与感。
  公共价值正在成为评估「技术治理」的新标尺。

公共价值理论给公共管理留下的最重要遗产，
是它**重新确立了「目的」对「手段」的优先性**：在效率、指标、技术的喧嚣中，
提醒我们不断追问——我们做这些事，到底创造了什么值得的东西？

## 6 小结

- **公共价值**是公民集体界定、期待公共部门创造的价值，具有集体性与多元性。
- 公民是公共价值的**共同创造者**，不是被动的顾客。
- 摩尔的**战略三角**：公共价值、合法性与支持、运行能力，三者缺一不可。
- 公共价值管理三原则：**价值为先、政治为本、合作生产**。
- 三大范式（传统行政、NPM、公共价值管理）是**并存与互补**关系，
  而非简单的线性替代。

到这里，公共管理的基础篇完成：从公共性出发，到公共物品的经济理由、
部门结构与两种现代思潮。

制定、执行与评估，
