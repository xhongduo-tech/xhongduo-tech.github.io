## 为什么从限制与合理使用开始

如果著作权是绝对的，那么引用一句话、拍一张街景、给学生复印讲义、给老师放一段教学视频，全都需要授权——社会将寸步难行。因此著作权法为自己设置了「刹车」：**合理使用**与**法定许可**。这两个制度是著作权人权利与社会公共利益的平衡阀，也是内容创作者必须精准掌握的「安全区」：哪些行为不侵权，边界在哪，稍越线就会从「合理」变成「侵权」。

## 1 合理使用

**合理使用（fair use）**：在法定情形下，**不经著作权人许可、不向其支付报酬**，但应当指明作者姓名或名称、作品名称，且**不得影响作品的正常使用，也不得不合理地损害著作权人的合法利益**而使用作品的行为。<span class="marginnote">合理使用的内在逻辑：某些使用行为对权利人利益损害微小、对公共利益增益巨大，法律直接豁免。但豁免有条件——要署名、要限于法定情形、不得与作品正常利用冲突、不得损害权利人合理利益。这四要素像四个安全气囊。</span>

我国《著作权法》第二十四条列举了 13 种合理使用情形，核心包括：

**个人学习、研究或欣赏**使用他人已发表作品；
**适当引用**他人作品以说明某一问题；
**新闻报道**中不可避免地再现或引用已发表作品；
学校课堂教学或科学研究，**翻译、改编、汇编**少量已发表作品供教学或科研人员使用；
国家机关为执行公务在合理范围内使用；
图书馆、档案馆等为陈列或保存版本的需要**复制**本馆收藏的作品；
免费表演已发表作品，不向公众收费、不向表演者支付报酬；
对室外公共场所的艺术作品进行临摹、绘画、摄影、录像。<span class="marginnote">「适当引用」是最常被引用的抗辩：引用须「适当」——占被引作品比重合理、引用的目的是「说明问题」而非「替代原作」。整篇照搬然后标个出处，绝不构成适当引用。</span>

## 2 三步检验法

合理使用不是「画个圈随便用」，国际通行的判断工具是**三步检验法（three-step test）**：

1. **限于特定情形**：使用行为须属于法律列举的合理使用情形；
2. **不得与作品的正常利用冲突**：使用不得架空作品的市场（如把整本书数字化免费传播）；
3. **不得不合理地损害著作权人的合法利益**：考量对权利人利益的损害是否合理。<span class="marginnote">三步检验法源自《伯尔尼公约》，TRIPS 与 WCT 进一步确认，我国著作权法 2020 年修订时把它写进了「合理使用」的定义条款。它的价值是给「列举式」的合理使用制度装上弹性阀门——列举之外的情形能否豁免，用三步法衡量。</span>

**辨析｜易错点：** 美国法上的 fair use 是「四要素开放式判断」，我国法采用「法定列举 + 三步检验」。两者的差别是：美国法官逐案权衡（使用目的、作品性质、使用比例、市场影响），我国原则上要求落入列举情形。但 2020 年修订后，我国合理使用条款增加了「其他情形」的兜底空间，正逐步向弹性化靠拢。

## 3 法定许可

**法定许可**：在法定情形下，使用他人已发表作品**可以不经过著作权人许可，但应当支付报酬**。它与合理使用的区别在于「是否付费」——合理使用免费，法定许可付费。<span class="marginnote">一句话辨析：合理使用 = 不授权 + 不付费；法定许可 = 不授权 + 付费。法定许可的价值在于降低交易成本——作品使用频繁、逐一授权不现实时，法律直接规定「用可以，但得给钱」，钱交给著作权集体管理组织转付。</span>

我国法定许可的主要情形：

- 为实施义务教育和国家教育规划编写出版教科书，使用已发表作品的**片段或短小作品**；
- 报刊转载或作为文摘、资料刊登（**但作者声明不得转载的除外**）；
- 录音制作者使用他人已经合法录制为录音制品的音乐作品制作录音制品；
- 广播电台、电视台播放他人已发表的作品。

## 4 合理使用 vs 法定许可：核心对比

| 维度 | 合理使用 | 法定许可 |
| --- | --- | --- |
| 是否需许可 | 否 | 否 |
| 是否付费 | 否 | 是（支付报酬） |
| 是否需署名 | 是 | 是 |
| 判断依据 | 法定情形 + 三步检验 | 法定情形 |
| 典型例子 | 适当引用、个人欣赏 | 教科书编写、报刊转载 |

**重点结论：两者共同构成著作权「权利限制」的两级——合理使用是「完全豁免」，法定许可是「有偿使用」。** 站在权利人角度，法定许可保留了报酬请求权；站在使用者角度，两者都省去了逐案谈判的成本。

## 5 合理使用的典型场景辨析

把合理使用放到具体场景里看，边界就清楚了：

- **个人学习欣赏**：下载一篇论文自己读，合理；把整本书做成 PDF 上传网盘分享，不合理——后者超出了「个人」范围，影响作品正常利用。
- **适当引用**：写评论时引用原作的几个关键句并注明出处，合理；把一篇文章几乎全文转载、只加一句评语，不合理——引用必须「为说明问题」且「比例适当」。
- **教学科研**：课堂放映一小段影片、分发少量讲义，合理；把整部电影上传到教学平台供任意下载，不合理。
- **新闻报道**：为报道时事不可避免地再现作品（如报道画展时展示画作），合理；把他人照片当配图大量使用，不合理。

用一张「安全区 / 危险区」表辅助判断：

| 使用行为 | 是否合理 | 关键变量 |
| --- | --- | --- |
| 引用几句写评论 | 通常合理 | 引用比例、署名 |
| 转载整篇加短评 | 通常不合理 | 实质替代原作 |
| 个人下载阅读 | 通常合理 | 不向公众提供 |
| 网盘分享全书 | 不合理 | 影响正常利用 |
| 课堂放映片段 | 通常合理 | 教学目的、非商业 |
| 教学平台挂载全片 | 不合理 | 超出必要范围 |

**重点结论：合理使用的判断不是「行为类型」一刀切，而是「行为 + 比例 + 目的 + 市场影响」的综合衡量。** 记住三步检验法的第三关——「不得不合理地损害权利人的合法利益」——是大多数越界行为的最终绊脚石。

### 实务深探：大模型训练语料的「合理使用」之争

合理使用制度正在经历数字时代最严峻的考验——大模型用海量作品做训练语料，这算不算合理使用？

- **训练语料的性质**：大模型训练要复制、摄录、信息网络传播大量受著作权保护的作品。每一次「喂数据」都是一次复制行为，若不经授权，就进入「合理使用 or 侵权」的争议地带。
- **主张合理使用的理由**：训练是对作品的「转换性使用」（transformative use），不向公众展示作品本身，市场替代效应弱；且逐案授权在技术上行不通。
- **反对的理由**：训练复制了作品的完整表达，若生成内容能「复现」原作（如生成与某小说高度相似的内容），会实质损害权利人利益；权利人并未获得任何补偿。

| 立场 | 核心论据 | 代表方 |
| --- | --- | --- |
| 属于合理使用 | 转换性使用、不展示作品、无市场替代 | 模型公司 |
| 属于侵权 | 完整复制表达、可复现原作、未获补偿 | 权利人、内容产业 |
| 需要法定许可/授权 | 付费使用、平衡各方 | 折中方案 |

**重点结论：这是「从极限到大模型」主线与著作权法最激烈的正面交锋。** 训练数据能否落入合理使用，全世界尚无统一答案——美国有判例倾向放宽，欧盟要求授权，中国正处在个案探索期。这个问题的答案，将决定大模型时代的创作生态走向何方。

### 术语速查

本篇涉及的核心术语汇总如下：

| 术语 | 含义 |
| --- | --- |
| 合理使用 | 法定情形下不经许可、不付费但须署名的使用 |
| 法定许可 | 不经许可但须支付报酬的使用 |
| 三步检验法 | 特定情形、不冲突正常利用、不损害合法利益 |
| 适当引用 | 为说明问题而引用他人作品的部分内容 |
| 个人使用 | 个人学习、研究、欣赏的使用 |
| 新闻报道使用 | 报道时事不可避免的再现 |
| 课堂教学使用 | 为教学科研翻译、改编、汇编少量作品 |
| 免费表演 | 不向公众收费、不向表演者付费的表演 |
| 声明不得转载 | 作者声明保留转载权的意思表示 |
| 转换性使用 | 以新目的、新方式使用作品的美国法概念 |

**一句话记住：** 合理使用 = 不授权 + 不付费；法定许可 = 不授权 + 付费；判断靠三步检验——尤其第三关「是否不合理损害权利人利益」。

## 6 小结

- **合理使用**：法定情形 + 三步检验，不授权不付费，但须署名、不得损害权利人利益。
- **法定许可**：不授权但要付费，适用于教科书编写、报刊转载、录音翻唱、广播播放等。
- 三步检验法：**特定情形 → 不与正常利用冲突 → 不不合理损害权利人利益**。
- 中美国别差异：美国 fair use 四要素开放判断，我国「列举 + 三步检验」。
- 易错点：合理使用 ≠ 随便用，「适当引用」须以说明问题为限；转载他人作品要留意「作者声明不得转载」。
- 交叉引用：大模型训练语料能否落入「合理使用」，是全球版权法与 AI 的主战场，正是「从极限到大模型」与著作权法的直接接驳。
