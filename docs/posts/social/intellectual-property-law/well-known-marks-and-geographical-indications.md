## 为什么从驰名商标与地理标志开始

普通商标的保护以「混淆」为限，但有两类特殊标志享有**更强的保护**：**驰名商标**突破商品类别限制，**地理标志**把「产地」本身变成集体财富。它们分别回应商标法最尖端的两个问题——「知名到极致的商标会不会被淡化」与「具有地域特色的资源如何防止被冒用」。理解它们，才能看懂品牌保护的高级形态与地方特色产业的法治基础。

## 1 驰名商标的认定

**驰名商标（well-known trademark）**：在中国境内为相关公众**广为知晓**的商标。

驰名商标不是「评出来的奖项」，而是**个案认定、按需认定**——在商标注册审查、商标争议处理、商标侵权诉讼等程序中，根据当事人的请求和案件需要，对商标是否驰名进行认定。认定考虑因素包括：

- 相关公众对该商标的**知晓程度**；
- 该商标使用的**持续时间**；
- 该商标的任何宣传工作的**持续时间、程度和地理范围**；
- 该商标作为驰名商标受保护的**记录**；
- 该商标**驰名的其他因素**。<span class="marginnote">「按需认定」是重点：只有在案件确有必要（如需要跨类保护）时才认定驰名，普通案件不主动认定。这与过去「驰名商标＝荣誉称号」的误区截然不同——2013 年修订明确禁止以「驰名商标」字样用于广告宣传。</span>

## 2 驰名商标的特殊保护

普通商标保护靠「混淆」，驰名商标保护**升维**：

**跨类保护**：就**不相同或不相类似**的商品申请注册的商标，是复制、摹仿或翻译他人**已在中国注册的驰名商标**，误导公众，**致使该驰名商标注册人的利益可能受到损害**的，不予注册并禁止使用。<span class="marginnote">跨类保护的逻辑从「消费者会不会认错」升级为「驰名商标会不会被稀释/搭便车」：在汽车上注册「华为」牌矿泉水，虽不至于让人以为华为卖水，但会搭华为品牌声誉的便车、稀释其显著性，因此被禁止。</span>
**防淡化保护**：对驰名商标而言，即使商品类别不同，若使用会**淡化**其显著性或贬损其声誉，也可能构成侵权——这是商标保护从「混淆」到「淡化」的现代演进。
**未注册驰名商标的保护**：未在中国注册的驰名商标，在同一种或类似商品上被复制、摹仿或翻译的，也受保护（但保护范围不及已注册驰名商标的跨类保护）。

**重点结论：驰名商标保护的核心是「跨类 + 防淡化」，把商标保护从「防混淆」推向「防搭便车、防稀释」。**

## 3 地理标志

**地理标志（geographical indication）**：标示某商品来源于某地区，该商品的**特定质量、信誉或其他特征**，主要由该地区的**自然因素或人文因素**所决定。<span class="marginnote">地理标志的三要素：来源地（产地）、特定品质（质量/信誉）、因果联系（品质由当地自然/人文因素决定）。「西湖龙井」的独特品质离不开西湖山水与炒制工艺——地理标志保护的正是一方水土一方物。</span>

地理标志的保护方式在我国呈现**双轨制**：

**集体商标 / 证明商标保护**：作为集体商标或证明商标注册，如「绍兴黄酒」「库尔勒香梨」。
**地理标志保护产品（专门保护）**：市场监管总局依据《地理标志产品保护规定》对地理标志保护产品进行登记保护。<span class="marginnote">中国地理标志保护存在「商标法」与「专门制度」两条轨道：前者走商标注册，后者走行政登记。2020 年前后中央机构改革试图统一管理，但双轨并行的格局仍在，实践中出现「潼关肉夹馍」等集体商标维权争议——权利人把地名注册成商标后向全国商户收费，引发对地理标志公共属性的广泛讨论。</span>

## 4 地理标志与驰名商标、普通商标的对比

| 维度 | 普通商标 | 驰名商标 | 地理标志 |
| --- | --- | --- | --- |
| 保护对象 | 品牌标志 | 高知名度品牌标志 | 产地 + 品质关联 |
| 归属 | 注册人独有 | 注册人独有 | 集体/证明商标或地区共享 |
| 核心保护 | 防混淆 | 跨类 + 防淡化 | 防产地冒用 |
| 显著性来源 | 注册取得 | 知名度 | 自然/人文因素 |
| 典型例子 | 任意品牌 | 华为、茅台 | 西湖龙井、法国香槟 |

**辨析｜易错点：** 地理标志与商标的「显著性」逻辑相反——商标要求标志**区别于产地**（「香槟」在美国被当作通用名称而非产地标志），地理标志恰恰强调**与产地的绑定**。同一标志（如「茅台」）可以同时是普通注册商标与地理标志保护对象，二者不冲突。

## 5 地理标志的运营与国际保护

地理标志不只是「保护」，更是一种产业发展工具：

- **集体/证明商标的运营**：地理标志由协会或管理组织注册为集体商标、证明商标，成员按要求使用、统一标准，实现「抱团发展」。如「安溪铁观音」「金华火腿」的产业化管理。
- **产地质量的守护**：地理标志的价值锚定在品质上，管理者需要监督生产标准、防止以次充好。品质一旦崩坏，地理标志的品牌价值随之瓦解。
- **国际保护**：地理标志的国际保护有两大路径——里斯本体系（专门的地理标志注册）与 TRIPS 框架（各国自行立法保护）。欧盟力推「产品地理标志」强保护，美国更倾向商标途径，两种路径在全球贸易谈判中反复交锋。

| 地理标志 | 保护路径 | 典型案例 |
| --- | --- | --- |
| 葡萄酒 | 里斯本体系/欧盟专门制度 | 波尔多、香槟 |
| 茶叶 | 证明商标/集体商标 | 西湖龙井 |
| 特色农产品 | 地理标志保护产品登记 | 赣南脐橙 |
| 手工艺品 | 证明商标 | 景德镇瓷器 |

**重点结论：地理标志保护的不仅是「名字」，更是一整套「产地 + 标准 + 管理」的价值体系。** 对一个地区而言，地理标志是把自然禀赋转变成法律资产的关键工具——但前提是管理跟得上，否则「原产地」三个字会被滥用殆尽。

### 实务深探：驰名商标的认定与维权

驰名商标的「个案认定、按需认定」原则，在实际维权中如何运作？

- **跨类维权的场景**：你的「ABC」商标在手机类别驰名，另一家公司在餐饮类别注册「ABC」并开店——普通商标管不到跨类，但驰名商标可以主张跨类保护，阻止其在餐饮上使用。
- **认定程序**：可以在商标异议、无效宣告、侵权诉讼中请求认定驰名。法院按需认定，只在有必要跨类保护时才作出驰名认定。
- **举证的要点**：要证明驰名，需提交使用持续时间、宣传投入与范围、销售区域与数额、受保护的记录等证据。证据的「广、深、久」决定认定的成败。

| 证据类型 | 证明什么 |
| --- | --- |
| 销售合同、发票、审计报告 | 市场范围与规模 |
| 广告合同、媒体报道 | 宣传投入与知名度 |
| 商标注册证、维权记录 | 权利基础与受保护史 |
| 消费者调查、行业排名 | 相关公众知晓度 |

**重点结论：驰名商标不是「评来的」，而是「用证据堆出来的」。** 一个品牌想要获得跨类强保护，平时就要系统性地留存经营证据——这些证据既是品牌的成长史，也是法律维权的弹药库。

### 术语速查

本篇涉及的核心术语汇总如下：

| 术语 | 含义 |
| --- | --- |
| 驰名商标 | 为相关公众广为知晓的商标 |
| 个案认定 | 只在具体案件中按需认定驰名 |
| 跨类保护 | 驰名商标跨类别禁止使用 |
| 防淡化 | 防止驰名商标显著性被稀释 |
| 地理标志 | 品质由当地自然/人文因素决定的产地标志 |
| 证明商标 | 证明商品达到某标准的商标 |
| 集体商标 | 表明成员来自某集体的商标 |
| 里斯本体系 | 地理标志专门国际注册体系 |
| 原产地名称 | 直接以产地命名的标志 |
| 商标退化 | 商标沦为通用名称、显著性丧失 |

**一句话记住：** 驰名商标「个案认定、按需认定」，保护升维为「跨类 + 防淡化」；地理标志把「产地 + 品质」变成集体资产，与商标「区别于产地」的逻辑相反。

## 6 小结

- **驰名商标**：为相关公众广为知晓的商标，**个案认定、按需认定**，不再是荣誉称号。
- 特殊保护：**跨类保护 + 防淡化 + 未注册驰名商标保护**。
- **地理标志**：品质由当地自然/人文因素决定的产地标志；保护方式为**集体/证明商标 + 专门制度双轨**。
- 地理标志与商标逻辑相反：商标强调区别于产地，地理标志强调绑定产地。
- 易错点：驰名商标不得用于广告宣传；地理标志属于地区共有资源，抢注地名商标可能引发公共争议。
- 交叉引用：中国地理标志产品的品牌出海，需要把「产地证明」与「国际商标注册」结合，呼应「知识产权的国际保护」。
