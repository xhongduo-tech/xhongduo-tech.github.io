## 为什么从专利侵权与救济开始

前面学的所有制度，最终都要在**侵权诉讼**里接受检验。怎么判断一个产品「抄」了别人的专利？一个加了几个零部件的产品还算不算侵权？被侵权了能要多少钱？「等同原则」「全面覆盖原则」「惩罚性赔偿」这些实务高频词，全部集中在这一节。对工程师与创业者，这是最可能直接遭遇的专利法战场。

## 1 专利侵权判定的核心：全面覆盖原则

**专利侵权判定**：将被诉侵权技术方案与**专利权利要求书记载的技术方案**逐项比对，判断是否落入保护范围。核心原则是**全面覆盖原则**——被诉方案必须包含权利要求记载的**全部技术特征**，才构成侵权。<span class="marginnote">全面覆盖原则来自「权利要求书是保护范围」的逻辑：权利要求把技术方案分解为若干技术特征，像一份「配方清单」。被诉产品必须「配齐」清单上所有特征才算落入，少一项就绕出保护范围。</span>

现实中，专利侵权诉讼还常与标准必要专利、开源合规等问题交织：一套产品里可能同时涉及几件专利、几份开源许可证。学会识别「哪部分技术、落入哪件专利、适用哪条规则」，是这一节真正要训练的能力。

**辨析｜易错点：** 侵权比对不是「整体感觉像不像」，而是**逐特征比对**。判断步骤：

1. 解析权利要求，列出全部技术特征；
2. 解析被诉方案对应的技术特征；
3. 逐一比对，判断被诉方案是否包含权利要求的所有特征（相同或等同）。

## 2 等同原则与禁止反悔

如果只承认字面相同才侵权，侵权人只需做微小改动（把螺丝换成卡扣）就能轻易绕开专利。**等同原则**堵住了这个漏洞：被诉方案的某个技术特征与权利要求记载的技术特征相比，属于**基本相同的手段、实现基本相同的功能、达到基本相同的效果**，且本领域普通技术人员无需创造性劳动即可联想到的，该特征被认定为等同特征，仍落入保护范围。<span class="marginnote">等同原则把专利保护范围从「字面」延伸到「实质」——好比权利要求写着「用钉子固定」，对方改用「用胶水固定」达到同样效果，仍可能构成等同侵权。但等同判断要防止过度扩张，因而有「禁止反悔原则」作为制衡。</span>

**禁止反悔原则**：申请人在审批过程中为获得授权而**放弃、限缩**的内容，不得在侵权诉讼中再纳入保护范围。这是诚实信用原则在专利法中的体现——「申请时为了过审把范围说窄，授权后又说宽，不行」。

## 3 专利侵权的类型

**直接侵权**：未经许可实施专利，如制造、使用、销售、许诺销售、进口侵权产品，或使用专利方法。<span class="marginnote">行为类型决定责任：制造者是侵权的源头，销售者、使用者同样侵权但责任可轻——我国规定「为生产经营目的使用、许诺销售或销售不知道是侵权产品的」，能证明合法来源的，不承担赔偿责任。</span>
**间接侵权**：为他人直接侵权提供帮助，如提供专门用于实施专利的零部件、材料、专用设备。我国现行法通过「共同侵权」规则处理：明知是侵权专用部件仍制造、销售，帮助他人实施侵权，承担连带责任。
**假冒专利**：在非专利产品上标注专利号，误导公众，承担行政责任甚至刑事责任。

## 4 专利侵权的救济

| 救济方式 | 内容 | 特点 |
| --- | --- | --- |
| 停止侵害 | 判令停止制造、销售等侵权行为 | 最直接、最常被请求 |
| 赔偿损失 | 实际损失 → 侵权获利 → 许可费合理倍数 → 法定赔偿 | 四档递进的计算规则 |
| 惩罚性赔偿 | 故意侵权 + 情节严重，1–5 倍赔偿 | 2020 年修订引入 |
| 诉前禁令 | 情况紧急时申请先行停止行为 | 防止损害扩大 |
| 行为保全/证据保全 | 责令提供证据、查封扣押 | 应对举证难 |

**重点结论：损害赔偿按「权利人实际损失 → 侵权人获利 → 专利许可使用费合理倍数 → 法定赔偿」四档依次确定，最高可到 500 万法定赔偿 + 5 倍惩罚性赔偿。** 权利人还可以请求**合理开支**（律师费、公证费等）由侵权人承担。<span class="marginnote">2020 年《专利法》把法定赔偿上限从 100 万提高到 500 万，并首次明确惩罚性赔偿——这被业内称为「严保护」信号：故意侵权、情节严重的，法院可以按基数的 1 到 5 倍判赔，让侵权成本显著高于守法成本。</span>

## 5 侵权判定的典型案例

用一个简化案例走一遍侵权判定流程：某公司拥有一件「智能手环」专利，权利要求包括「计步传感器 + 心率传感器 + 无线传输模块 + 显示屏」四个技术特征。

- **情形一**：竞品手环包含全部四个特征 → 全面覆盖原则成立，直接落入保护范围。
- **情形二**：竞品手环用「光学心率模块」替换「心率传感器」，功能、效果相同 → 可能构成等同侵权（手段基本相同、功能基本相同、效果基本相同、普通技术人员无需创造性劳动即可想到）。
- **情形三**：竞品手环删掉了「显示屏」，改为手机 App 显示 → 缺少「显示屏」这一必要技术特征，不落入保护范围（除非等同认定）。
- **情形四**：竞品手环的传感器是向第三方采购的标准件，但手环整体仍含全部特征 → 竞品制造商直接侵权，传感器供应商一般不构成帮助侵权（除非专用部件）。

| 判断步骤 | 要点 |
| --- | --- |
| 1. 解析权利要求 | 列出全部技术特征 |
| 2. 解析被诉方案 | 对应提取技术特征 |
| 3. 逐项比对 | 相同 or 等同 |
| 4. 得出结论 | 全覆盖 → 侵权 |

**辨析｜易错点：** 等同侵权的适用要从严把握，防止保护范围过度扩张。同时「禁止反悔」会限制等同——申请时主动限缩的特征，不能再通过等同扩张回来。记住：**权利要求书是侵权的尺子，等同原则是尺子上的刻度，禁止反悔是刻度的校零。**

### 实务深探：专利侵权诉讼的举证与程序要点

专利侵权诉讼的难点常在「证据」与「程序」：

- **取证难**：侵权产品多在对方工厂，账目在对方账上。权利人可通过法院的证据保全、行为保全、调查令等手段取证；对新产品制造方法专利，举证责任倒置，由被告证明其方法不同。
- **管辖选择**：专利侵权案件可由侵权行为地或被告住所地法院管辖。侵权行为的实施地、侵权结果发生地都可构成管辖连接点，权利人可选择对自己有利的法院。
- **被告的反制**：被告最常见的反制是提起专利无效宣告请求，法院可能中止诉讼等待无效结果——这既是程序策略，也是拖延战术。

| 环节 | 权利人重点 | 被告重点 |
| --- | --- | --- |
| 起诉 | 选择管辖、固定证据 | 提起无效、抗辩不落入 |
| 审理 | 技术比对、等同论证 | 规避等同、主张现有技术抗辩 |
| 判决 | 赔偿计算、禁令执行 | 上诉、和解谈判 |

**重点结论：专利侵权诉讼是「技术 + 法律 + 程序」的三线作战。** 胜负往往在起诉前就已埋下伏笔——证据是否充分、管辖是否有利、专利是否稳定，这三件事决定了诉讼的走向。对权利人而言，最稳妥的策略是「先评估、后起诉」，把每一个变量都算清楚再出手。

### 术语速查

本篇涉及的核心术语汇总如下：

| 术语 | 含义 |
| --- | --- |
| 全面覆盖原则 | 被诉方案须包含权利要求的全部技术特征 |
| 等同原则 | 基本相同手段/功能/效果且无需创造性劳动的替代仍侵权 |
| 禁止反悔 | 申请时放弃的内容不得在诉讼中再主张 |
| 直接侵权 | 未经许可实施专利的行为 |
| 间接侵权 | 为他人直接侵权提供专用部件等帮助 |
| 假冒专利 | 在非专利产品上标注专利号 |
| 合法来源抗辩 | 不知情且能证明合法来源可免除赔偿责任 |
| 诉前禁令 | 判决前责令先行停止侵权 |
| 证据保全 | 对可能灭失的证据先行固定 |
| 惩罚性赔偿 | 故意侵权情节严重的 1—5 倍赔偿 |

**一句话记住：** 权利要求书是侵权的尺子，等同原则是尺子上的刻度，禁止反悔是刻度的校零；赔偿按实际损失→侵权获利→许可费倍数→法定赔偿四档递进。

## 6 小结

- 侵权判定核心：**全面覆盖原则**——被诉方案须包含权利要求的全部技术特征。
- **等同原则**延伸保护范围；**禁止反悔**防止权利人出尔反尔。
- 侵权类型：**直接侵权、间接侵权（共同侵权）、假冒专利**。
- 救济：停止侵害、赔偿损失、诉前禁令、证据保全；赔偿按四档递进，**最高 500 万法定赔偿 + 5 倍惩罚性赔偿**。
- 易错点：比对是逐特征而非整体相似；不知道侵权且有合法来源的销售者可不承担赔偿责任。

至此，专利从授权、限制到侵权救济的完整链条已经走通——权利人手中的「独占实施权」如何获得、如何受限、如何救济，都有了清晰的答案。掌握这套攻防逻辑，才算真正读懂了专利法。

在下一节，我们从「防御与救济」转向「进攻与变现」——专利如何创造商业价值，这就是**专利运营与转化**。
