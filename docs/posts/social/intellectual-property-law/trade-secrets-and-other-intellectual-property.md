## 为什么从商业秘密与其他知识产权开始

专利、著作权、商标之外，知识产权还有一群「特殊成员」：**商业秘密**不靠公开换保护，而是靠保密维持价值；**集成电路布图设计、植物新品种**各有专门立法。对科技企业而言，商业秘密往往是比专利更核心的资产——大模型的训练数据、算法细节、客户名单，很多就是商业秘密。理解「不公开的知识产权」，才能补全知识产权保护的完整拼图。

## 1 商业秘密的构成要件

**商业秘密（trade secret）**：《反不正当竞争法》第九条定义，商业秘密是指**不为公众所知悉、具有商业价值并经权利人采取相应保密措施**的技术信息、经营信息等商业信息。

三个要件缺一不可：

- **秘密性**：不为公众所知悉，不是相关领域的一般常识或行业惯例。<span class="marginnote">秘密性是商业秘密与专利的分水岭：专利以「公开」换保护，商业秘密以「保密」换保护。一旦技术被公开（如发表论文、开源代码），秘密性即丧失，商业秘密随之灭失——这是「开源与商业秘密不可兼得」的制度根源。</span>
**价值性**：具有现实的或潜在的商业价值，能为权利人带来竞争优势。
**保密性（保密措施）**：权利人采取了相应保密措施，如签订保密协议、设置访问权限、标记密级、物理隔离。<span class="marginnote">「保密措施」是权利人最容易忽视的一环：一个技术再值钱，若公司没有保密制度、代码随便拷走、文件不加权限，法律也难以认定商业秘密。司法实践强调「与其信息性质相适应的合理保密措施」——不要求万无一失，但要有「围墙」的迹象。</span>

**重点结论：秘密性 + 价值性 + 保密性，三要件齐备才构成商业秘密。** 其中保密性是「权利人自救」的要件——法律只保护那些自己努力保护的信息。

## 2 侵犯商业秘密的行为

《反不正当竞争法》规定，经营者不得实施下列侵犯商业秘密的行为：

**不正当获取**：以盗窃、贿赂、欺诈、胁迫、电子侵入或其他不正当手段获取权利人商业秘密。
**披露、使用或允许他人使用**：披露、使用或允许他人使用以不正当手段获取的商业秘密。
**违约披露**：违反保密义务或权利人有关保守商业秘密的要求，披露、使用或允许他人使用其所掌握的商业秘密。
**教唆、引诱、帮助**：教唆、引诱、帮助他人违反保密义务获取、披露、使用商业秘密。
**第三人明知或应知**：第三人明知或应知商业秘密来源违法，仍获取、披露、使用或允许他人使用的，视为侵犯商业秘密。<span class="marginnote">第三人条款是商业秘密保护的「追击线」：从跳槽员工手里买到竞对技术资料的公司，即使没参与最初的盗窃，只要「明知或应知」来源违法，同样构成侵权。这堵住了「我不是偷的，是买来的」这类抗辩。</span>

**辨析｜易错点：** **反向工程**不构成侵犯商业秘密。通过公开渠道获得的产品进行拆卸、分析、还原，独立获得技术信息，属于合法的反向工程；但违反保密约定从事反向工程除外。**商业秘密保护的是「保密的信息」，不保护「通过合法途径可得的信息」。**<span class="marginnote">反向工程与商业秘密的共存逻辑：秘密一旦随产品进入市场，就暴露于被拆解的风险之下。法律允许反向工程，意味着商业秘密的优势是有时限的——这也解释了为什么许多企业选择「专利 + 商业秘密」组合保护：能藏住的用秘密，藏不住的用专利。</span>

## 3 商业秘密保护与竞业限制

商业秘密纠纷最常见于**员工跳槽**场景。企业防范商业秘密流失的两大工具：

**保密协议（NDA）**：约定员工对知悉的商业秘密负保密义务，可设定违约金。<span class="marginnote">保密协议 + 竞业限制是科技公司「护城河」的标配。保密协议针对「在职 + 离职后的保密」；竞业限制针对「离职后一段时间内不得去竞争对手处工作」。</span>
**竞业限制**：对负有保密义务的高级管理人员、高级技术人员和其他知悉商业秘密的人员，可约定离职后一定期限内（**不超过 2 年**）不得到与本单位生产经营同类产品、从事同类业务的有竞争关系的其他单位任职，或自营同类业务。用人单位须**按月支付经济补偿**（实践中常为离职前月平均工资的 30%）。<span class="marginnote">竞业限制的两面性：它是商业秘密保护的利器，也是劳动者择业自由的限制。法律因此设双重约束——期限不超 2 年、必须支付补偿。用人单位三个月未支付经济补偿的，劳动者可解除竞业限制约定。法院近年对竞业限制的适用范围（尤其普通程序员）有收紧趋势。</span>

## 4 其他知识产权：集成电路布图设计与植物新品种

**集成电路布图设计权**：保护集成电路中元件与连线的三维配置（布图设计），经登记取得，保护期 **10 年**。<span class="marginnote">集成电路布图是「专利」与「著作权」之间的过渡形态：它既不是技术方案（难以满足专利的创造性），也不是作品表达（纯功能性的布线）。我国 2001 年制定《集成电路布图设计保护条例》，保护期为自创作完成或首次商业利用起 10 年。</span>
- **植物新品种权**：对具备新颖性、特异性、一致性、稳定性的植物品种，经申请授予品种权，保护期藤本植物、林木等 **20 年**，其他 **15 年**。育种者对其品种的繁殖材料享有排他性权利。

**重点结论：商业秘密与其他知识产权共同构成知识产权的「开放体系」——除三大传统权利外，法律还依技术发展不断创设新客体。** 这体现了知识产权法的动态性：技术走到哪，保护就跟到哪。

## 5 商业秘密的举证与救济

商业秘密案件的「秘密性」决定了它比其他知识产权诉讼更难举证：

- **权利人举证三件事**：① 信息构成商业秘密（秘密性、价值性、保密性）；② 对方实施了获取/披露/使用行为；③ 行为人接触了商业秘密且其信息与秘密实质相同。司法实践中常通过「接触 + 相似 + 排除合法来源」的推定链条完成举证。
- **举证责任转移**：权利人证明对方接触了秘密且信息实质相同后，举证责任转向被告——由被告证明其信息有合法来源（如独立研发、反向工程、公开渠道获得）。
- **刑事保护**：侵犯商业秘密情节严重构成侵犯商业秘密罪，2020 年刑法修正案取消了「给权利人造成重大损失」的入罪门槛，改为「情节严重」，保护力度显著加强。

| 救济途径 | 主要功能 |
| --- | --- |
| 民事诉讼 | 停止侵害、赔偿损失、返还载体 |
| 行为保全 | 防止秘密在诉讼期间进一步泄露 |
| 劳动仲裁 | 针对员工违约（保密/竞业协议） |
| 刑事追诉 | 惩处严重侵犯行为 |
| 行政查处 | 市场监管部门调查不正当竞争 |

**重点结论：商业秘密保护是「事前保密」重于「事后救济」。** 因为秘密一旦公开就永久灭失，最有效的保护永远是在法庭之外的保密制度——权限管理、保密协议、离职审查、物理隔离。法律给的是最后一道防线，而防线之前的工作，全在企业自己手里。

### 实务深探：员工离职与商业秘密风险管控

商业秘密纠纷最常见于「员工跳槽」。对企业的启示是：保密管理要从「入职」管到「离职后」：

- **入职环节**：签订保密协议、明确接触权限、进行保密培训——让员工知道什么是秘密、保密的边界在哪。
- **在职环节**：分级授权访问、代码库权限管理、涉密会议记录、定期审计——保密不是签一份协议，而是「流程上的围墙」。
- **离职环节**：办理保密承诺、进行离职谈话、回收设备与账号、必要时签订竞业限制协议——防止「人走秘密也走」。
- **竞业限制的边界**：期限不超过 2 年、须支付经济补偿、范围限于负有保密义务的人员。过度扩张的竞业限制，法院会调整甚至否定。

| 环节 | 关键动作 | 作用 |
| --- | --- | --- |
| 入职 | 保密协议、培训 | 明确义务 |
| 在职 | 权限分级、审计 | 防内贼 |
| 离职 | 承诺书、回收、竞业限制 | 防泄密 |
| 离职后 | 竞业补偿、定期核查 | 防挖角 |

**重点结论：商业秘密保护是「三分法律、七分管理」。** 法律只保护那些自己采取了合理保密措施的信息——管理上的漏洞，会直接导致法律上的失守。

### 术语速查

本篇涉及的核心术语汇总如下：

| 术语 | 含义 |
| --- | --- |
| 商业秘密 | 不为公众所知悉、有商业价值并经保密的信息 |
| 秘密性 | 不为相关领域的一般常识 |
| 价值性 | 具有现实的或潜在的商业价值 |
| 保密性 | 权利人采取了相应保密措施 |
| 反向工程 | 通过公开产品拆解分析获得技术 |
| 竞业限制 | 离职后一定期限内不得从事竞争业务 |
| 保密协议 | 约定保密义务的合同 |
| 集成电路布图设计权 | 保护集成电路三维配置的权利 |
| 植物新品种权 | 育种者对新品种繁殖材料的排他权 |
| 第三人条款 | 明知来源违法仍获取使用秘密的也侵权 |

**一句话记住：** 商业秘密三要件「秘密 + 价值 + 保密」，公开即灭失；保护是「三分法律、七分管理」——事前保密重于事后救济。

## 6 小结

- **商业秘密三要件**：秘密性 + 价值性 + 保密性；靠保密维持，公开即灭失。
- 侵权形态：不正当获取、披露使用、违约披露、教唆帮助、第三人明知仍用。
- **反向工程合法**，但违反保密约定的反向工程除外。
- 保密协议 + **竞业限制**（≤2 年、须付补偿）双管防跳槽泄密。
- 其他客体：**集成电路布图设计（10 年）、植物新品种（15/20 年）**各有专法。
- 易错点：商业秘密与专利互斥（公开换保护 vs 保密换保护）；员工正常流动与恶意窃密的边界靠保密措施厘清。
- 交叉引用：大模型的训练数据、提示词工程、客户名单等多为商业秘密——「从极限到大模型」与知识产权法在此深度交汇。

在下一节，我们把所有制度收束到现实场景——打官司、举证据、算赔偿，这就是**知识产权司法保护与实践**。
