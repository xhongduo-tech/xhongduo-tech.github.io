## 为什么从客体与主体开始

著作权保护什么？——**作品**。谁享有著作权？——**作者**。这两个概念看起来简单，边界却极其讲究：一张自拍照算作品吗？AI 生成的图片算作品吗？程序员在公司写的代码，著作权归谁？「作品」与「作者」的认定，决定了著作权保护的起点与归属，也是许多纠纷的第一战场。

## 1 著作权客体：作品

**作品**：文学、艺术和科学领域内具有**独创性**并能以某种**有形形式复制**的智力成果。

作品的构成要件有三：

- **独创性**：作品由作者独立完成，并体现作者的智力判断与选择。独创性不要求「全新」，只要求「自己创作、不是抄袭」。<span class="marginnote">独创性（originality）是作品的门槛：同一主题可以写出无数作品，只要各自独立完成并体现个性选择。它比专利的「创造性」低得多——小学生作文也有独创性。</span>
**可复制性**：能够以某种有形形式复制，能被他人感知、传播。
**属于文学、艺术、科学领域**：是「表达」而非「实用功能」。

**辨析｜易错点：** 独创性不要求「艺术高度」。一把以标准方式焊成的金属椅子，可能因缺乏创造性选择而不被认定；但一张精心构图的照片、一段自编代码，即便「很简单」，只要有选择与判断就有独创性。**著作权只问「是不是你写的」，不问「写得多好」。**

## 2 作品的法定类型

我国《著作权法》第三条列举了作品类型（2020 年修订后增列视听作品等）：

| 作品类型 | 例子 |
| --- | --- |
| 文字作品 | 小说、论文、博客、源代码文档 |
| 口述作品 | 演讲、授课、法庭辩论 |
| 音乐、戏剧、曲艺、舞蹈、杂技艺术作品 | 歌曲、剧本、相声 |
| 美术、建筑作品 | 绘画、雕塑、建筑图 |
| 摄影作品 | 照片 |
| **视听作品** | 电影、电视剧、短视频、游戏画面 |
| 工程设计图、产品设计图、地图、示意图 | 图纸、地图 |
| 计算机软件 | 程序及其文档 |
| 民间文学艺术作品 | 传说、歌谣 |

**重点结论：2020 年修订把「电影作品和以类似摄制电影的方法创作的作品」改为「视听作品」，并把「实用艺术作品」纳入美术作品保护。** 这是法律对短视频、网络直播、游戏直播等新形态的直接回应。<span class="marginnote">「视听作品」是 2020 年修订最重要的术语更新：它不再强调「摄制」，从而把没有「拍摄」过程的动画、游戏画面、PPT 动画都纳入保护。条文列举的开放性是关键——第三条以「法律、行政法规规定的其他作品」收尾，为新技术留了口袋。</span>

## 3 著作权主体：作者与特殊作品

**作者**：创作作品的自然人。著作权首先属于作者。

但现实中的作品多是「协作 + 雇佣」的产物，法律设置了特殊规则：

**合作作品**：两人以上合作创作，著作权由合作作者共同享有。<span class="marginnote">合作作品的认定标准是「共同创作」——都付出了独创性劳动。单纯提供素材、提意见、拉资金不构成共同创作。可分割的合作作品（词曲分离）可单独使用。</span>
**职务作品**：自然人为完成**工作任务**所创作的作品。著作权归属分两种情形：一般职务作品归作者，单位有权在业务范围内优先使用；**主要利用单位物质技术条件创作并由单位承担责任的**工程设计图、产品设计图、地图、计算机软件等，作者享有署名权，其他著作权归单位。<span class="marginnote">程序员写的代码、设计师画的图、工程师出的图纸，大概率是「特殊职务作品」——著作权归公司，个人只保留署名权。入职签的劳动合同里「职务成果归属条款」通常就是把这条法定规则再明确一遍。</span>
**委托作品**：受委托创作的作品，著作权归属由合同约定；**合同未约定或约定不明的，著作权归受托人**。<span class="marginnote">委托作品的默认规则与直觉相反：客户出钱委托，但没约定时版权归「受托创作的作者」而非「出钱的委托人」。企业请外包做设计、开发，必须在合同中写明著作权归属——这是最高频的实务陷阱之一。</span>
- **法人作品**：由法人或组织主持，代表其意志创作，并由其承担责任的作品，著作权归法人。

## 4 著作权归属的核心对比

| 作品类型 | 著作权归属（无约定时） | 关键判断 |
| --- | --- | --- |
| 一般职务作品 | 作者 | 与职务有关但不依赖单位物质条件 |
| 特殊职务作品 | 单位（作者保留署名权） | 工程图、软件、地图等 + 单位物质条件 |
| 委托作品 | 受托人 | 合同未约定的默认规则 |
| 合作作品 | 合作作者共有 | 须有共同创作行为 |
| 法人作品 | 法人 | 代表法人意志 + 法人承担责任 |

**辨析｜易错点：** 特殊职务作品与法人作品容易混淆。关键区分：特殊职务作品的作者是「自然人 + 在单位任职」，法人作品的「作者」直接是单位。实务中计算机软件、工程设计图最常见的是**特殊职务作品**。

## 5 作品认定的两个前沿问题

作品与作者的边界正在被新技术撬动：

- **数据库与汇编作品**：对数据、素材进行选择与编排，体现独创性的汇编成果受著作权保护——但保护范围只及于「选择与编排」本身，不及于其中包含的单个数据。这就是数据库的法律处境：投入巨大、保护有限，逼出「数据库特殊权利」的立法探索。
- **人工智能生成内容**：用户输入提示词，模型生成图片、文字、代码——这算不算「作品」？若算，作者是谁？主流立场（含中国司法实践倾向）是：只有体现**人类智力投入**（如对提示词的构思、对结果的筛选修改）的成果才可能受保护，纯机器自动生成的内容难以构成作品。

| 情形 | 是否作品 | 作者 |
| --- | --- | --- |
| 人类独立创作 | 是 | 创作者 |
| 使用 AI 工具辅助、有人类实质性参与 | 视情况 | 人类参与者 |
| 纯 AI 自动生成、无人实质参与 | 主流倾向否 | — |

**重点结论：作品认定的核心始终是「独创性」，而独创性的本质是「人的智力选择」。** 技术可以扩展创作工具，但「作者是人」的底线，至今仍是各国著作权法的共同前提——这与「从极限到大模型」主线直接相连：当模型越来越强，「人的创作」与「机器的输出」的边界，正是著作权法正在划定的新地图。

### 实务深探：一张照片的著作权归属

用最贴近生活的场景——一张照片——串起客体与主体规则：

- **自拍**：自己摆好手机拍的照，是摄影作品，著作权归拍摄者本人。
- **帮拍**：请路人甲用你的手机帮你拍，谁是作者？按「谁按下快门谁创作」的一般规则，创作行为归按快门的人；但实践中若拍摄完全按你的指示进行，著作权归属可能出现争议——最稳妥的是口头约定清楚。
- **工作室约拍**：请摄影工作室拍写真，属于委托作品——没有合同约定的，著作权归受托人（工作室），你只有约定的使用权；要拿到著作权，必须在合同里写明「著作权转让给委托人」。
- **公司活动拍摄**：摄影人员为完成工作任务拍摄，属于职务作品——一般归作者，单位有优先使用权；若主要利用单位设备且由单位承担责任，属特殊职务作品，著作权归单位。

| 场景 | 作品类型 | 著作权归属 |
| --- | --- | --- |
| 自拍 | 摄影作品 | 拍摄者 |
| 帮拍（无约定） | 摄影作品 | 按快门者（有争议） |
| 约拍（无约定） | 委托作品 | 受托人 |
| 约拍（约定转让） | 委托作品 | 委托人 |
| 职务拍摄 | 职务作品 | 作者或单位（视类型） |

**重点结论：同一类作品，因创作情境不同，著作权归属完全不同。** 判断归属时先问三个问题：谁创作的？是职务还是委托？有没有约定？三问过后，答案基本清晰。

### 术语速查

本篇涉及的核心术语汇总如下：

| 术语 | 含义 |
| --- | --- |
| 作品 | 文学、艺术、科学领域有独创性、可复制的智力成果 |
| 独创性 | 独立完成并体现智力判断与选择 |
| 可复制性 | 能够以有形形式复制 |
| 文字作品 | 小说、论文、源代码文档等 |
| 视听作品 | 电影、短视频、游戏画面等 |
| 计算机软件 | 程序及其文档 |
| 合作作品 | 两人以上共同创作的作品 |
| 职务作品 | 为完成工作任务创作的作品 |
| 委托作品 | 受委托创作的作品 |
| 法人作品 | 代表法人意志创作并由法人承担责任的作品 |
| 特殊职务作品 | 主要利用单位物质条件创作、著作权归单位的作品 |

**一句话记住：** 作品认定的核心是「独创性」；归属判断先问三件事——谁创作的、是职务还是委托、有没有约定。

## 6 小结

- **作品**：有独创性、可复制、属文学艺术科学领域的智力成果；门槛是独创性而非「高度」。
- 法定类型开放列举，2020 年引入**视听作品**、纳入实用艺术作品。
- 主体规则：**合作共有、职务归单位/作者（视类型）、委托默认归受托人、法人作品归法人**。
- 易错点：委托作品无约定时归**受托人**；程序员代码多为特殊职务作品归公司。
- 交叉引用：AI 生成内容能否构成作品、作者是谁，是「从极限到大模型」主线与著作权法的前沿接驳点。
