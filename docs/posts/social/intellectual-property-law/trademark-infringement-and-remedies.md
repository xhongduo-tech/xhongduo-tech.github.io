## 为什么从商标侵权与救济开始

商标侵权是市场上最普遍的知识产权纠纷：山寨货、傍名牌、假冒伪劣、蹭流量关键词、把他人商标写进自己商品链接……这一节要建立商标侵权的**完整判断框架**：什么行为构成侵权、如何认定混淆、权利人有哪些救济，以及 2019 年修订后力度空前的惩罚性赔偿。对品牌方与电商经营者，这是最直接的攻防手册。

## 1 商标侵权的行为类型

《商标法》第五十七条列举了商标侵权行为，主要包括：

- **假冒注册商标**：未经许可，在同一种商品上使用与其注册商标**相同**的商标。
- **近似商标侵权**：在同一种商品上使用**近似**商标，或在类似商品上使用相同或近似商标，**容易导致混淆**的。<span class="marginnote">假冒（相同商标 + 相同商品）直接侵权、无需证混淆；近似/类似情形须以「容易导致混淆」为要件。是否混淆是近似商标侵权案件的核心争点，法院会综合商标近似度、商品类似度、商标知名度、相关公众注意程度整体判断。</span>
**销售侵权商品**：销售侵犯注册商标专用权的商品。
**伪造、擅自制造注册商标标识**：制造、销售伪造或擅自制造的注册商标标识。
**反向假冒**：未经同意更换其注册商标并将更换商标的商品投入市场。
**帮助侵权**：故意为侵权行为提供仓储、运输、邮寄、隐匿等便利条件。
**商标侵权延伸行为**：将他人注册商标作为**企业字号**、域名、App 名称等使用，足以造成混淆的，也构成商标侵权或不正当竞争。<span class="marginnote">「傍名牌」的常见形态是把知名商标注册为企业字号：他人用「××华为科技有限公司」做字号，即使商品不完全相同，只要足以造成相关公众混淆，就可能被认定构成侵权或不正当竞争——这是「商标 + 商号」交叉保护的典型场景。</span>

## 2 侵权认定：混淆可能性 + 使用行为

商标侵权的核心是**「商标性使用」+「混淆可能性」**两步判断：

**第一步：是否构成商标性使用**。将标志用于识别商品/服务来源的行为，才是商标性使用；纯描述性、指示性的正当使用（如「本店维修××品牌手机」）不构成商标使用。<span class="marginnote">「描述性正当使用」与「商标性使用」的分界很微妙：卖家在商品标题里写「适用苹果手机壳」，究竟是描述适配性（正当）还是攀附品牌（侵权）？法院要看使用是否超出必要、是否造成混淆。这是电商领域最高频的商标争议。</span>
**第二步：是否可能导致混淆**。综合商标近似度、商品类似度、显著性、知名度等因素判断。

**辨析｜易错点：** 商标侵权不要求「行为人主观故意」。过失侵权同样构成——即使不知情，销售侵权商品也构成侵权（只是若能证明合法来源可免除赔偿责任）。**商标侵权的构成看客观行为，主观状态只影响赔偿责任的轻重。**

## 3 商标侵权的抗辩

**合法来源抗辩**：销售者不知道是侵权商品，能证明该商品是自己合法取得并说明提供者的，不承担赔偿责任。<span class="marginnote">合法来源抗辩保护「善意中间商」：正规进货、有票据、如实披露供货方，就可免赔（但仍须停止销售）。它倒逼渠道商留好进货凭证——这也是跨境电商卖家被商标权利人投诉时最常用的「护身符」。</span>
**先用权抗辩**：在商标注册人申请商标注册前，他人已经在同一种商品或类似商品上先使用相同或近似商标的，有权在**原有范围内**继续使用。
**正当使用抗辩**：对商标中的通用名称、描述性要素的合理使用（如地名、商品原料、功能用途的叙述性使用）。
**未使用抗辩**：注册人连续三年未使用商标的，可申请撤销；侵权赔偿时未实际使用的注册商标，难以获得高额赔偿。

## 4 商标侵权的救济

| 救济方式 | 内容 | 要点 |
| --- | --- | --- |
| 停止侵害 | 停止使用、销售等行为 | 最常用 |
| 赔偿损失 | 实际损失 → 侵权获利 → 商标许可费合理倍数 → 法定赔偿 | 四档递进 |
| 惩罚性赔偿 | 恶意侵权 + 情节严重，1–5 倍 | 2019 年修订引入 |
| 消除影响 | 公开声明、赔礼道歉 | 针对商誉损害 |
| 诉前禁令/保全 | 紧急情况下先行停止 | 防止损害扩大 |
| 行政查处 | 市场监管部门没收、罚款 | 行政保护路径 |
| 刑事追诉 | 假冒注册商标罪等 | 情节严重构成犯罪 |

**重点结论：商标侵权赔偿与专利、著作权一致，采「实际损失 → 侵权获利 → 许可费倍数 → 法定赔偿」四档递进；恶意侵权情节严重的适用 1–5 倍惩罚性赔偿，法定赔偿上限 500 万元。** 假冒注册商标、销售假冒注册商标的商品，情节严重者构成**刑事犯罪**（假冒注册商标罪等），最高可处十年有期徒刑。<span class="marginnote">商标侵权是知识产权中「刑民交叉」最突出的领域：刑事追诉以「情节严重/特别严重」为门槛（非法经营数额、违法所得数额、件数等量化标准），但民事赔偿与刑事追诉可以并行——先刑后民或刑民并行，权利人应结合证据与目标选择路径。</span>

## 5 商标侵权的救济路径选择

商标侵权发生后，权利人的选择不止「打官司」一条：

- **行政投诉**：向市场监管部门投诉，查处假冒伪劣、没收侵权商品、罚款。速度快、成本低，适合打击制假售假。
- **民事起诉**：请求停止侵害、赔偿损失。能拿到真金白银的赔偿，适合追求经济救济。
- **刑事报案**：假冒注册商标罪等，情节严重的可追究刑事责任。威慑力最强。
- **平台投诉**：电商、社交平台的知识产权投诉通道（如「通知—删除」），是数字时代最高频的救济途径。

用一个决策表帮权利人选择：

| 侵权情形 | 首选路径 | 备选 |
| --- | --- | --- |
| 线上售假 | 平台投诉 + 行政查处 | 民事诉讼 |
| 线下制假窝点 | 行政查处 + 刑事报案 | 民事诉讼 |
| 傍名牌（字号/装潢） | 民事诉讼（不正当竞争） | 行政查处 |
| 高额商业损失 | 民事诉讼（惩罚性赔偿） | 刑事报案 |

**重点结论：商标救济是「多线并进」的组合拳。** 成熟的维权策略通常是：先用平台投诉或行政查处快速止损，再用民事诉讼索赔，情节严重的辅以刑事追诉。**止损要快、索赔要准、威慑要狠**——三条线各司其职。

### 实务深探：电商场景的商标侵权高发点

电商是商标侵权最高发的场景，几个高频风险点值得每一个经营者注意：

- **标题关键词侵权**：在商品标题中写入他人注册商标（如「××同款」「适配××」），若构成商标性使用并导致混淆，可能侵权。「描述性正当使用」与「攀附」的边界，是电商审核与诉讼的高频争点。
- **店铺名与装潢**：店铺名称、页面装潢使用他人注册商标或近似标识，造成来源混淆，构成侵权或构成不正当竞争。
- **代购与平行进口**：销售正品但未经授权，一般不构成商标侵权（权利用尽）；但若宣称「官方授权」「专柜正品」失实，可能构成虚假宣传。
- **售假的法律后果**：销售假冒注册商标商品，除民事赔偿外，还要承担行政责任，情节严重的构成犯罪。

| 电商行为 | 是否侵权 | 关键判断 |
| --- | --- | --- |
| 标题写「××同款」 | 视情况 | 是否商标性使用 + 混淆 |
| 正品代购 | 一般不侵权 | 权利用尽 |
| 冒用他人商标 | 侵权 | 假冒/近似 |
| 店铺名傍名牌 | 侵权/不正当竞争 | 来源混淆 |

**重点结论：电商商标合规的底线是「不冒用、不混淆、不虚假宣称」。** 在标题、店铺名、描述这些「寸土寸金」的位置，越是想蹭热度，越容易踩红线。

### 术语速查

本篇涉及的核心术语汇总如下：

| 术语 | 含义 |
| --- | --- |
| 假冒注册商标 | 在相同商品上使用相同商标 |
| 近似商标侵权 | 在相同/类似商品上使用近似商标致混淆 |
| 商标性使用 | 以识别来源为目的的使用 |
| 混淆可能性 | 消费者对来源产生混淆的可能 |
| 合法来源抗辩 | 不知情且能证明合法来源免除赔偿 |
| 先用权抗辩 | 注册前已使用并仅在原范围继续使用 |
| 正当使用抗辩 | 对描述性要素的合理使用 |
| 反向假冒 | 更换他人商标后投入市场 |
| 帮助侵权 | 为侵权提供仓储、运输等便利 |
| 假冒注册商标罪 | 情节严重的刑事犯罪 |

**一句话记住：** 侵权认定两步走——「商标性使用 + 混淆可能性」；过失也构成侵权，主观状态只影响赔偿；救济是行政 + 民事 + 刑事的组合拳。

## 6 小结

- 侵权类型：**假冒、近似混淆、销售侵权品、伪造标识、反向假冒、帮助侵权、傍字号**。
- 认定两步：**商标性使用 + 混淆可能性**；过失也构成侵权，主观状态只影响赔偿。
- 抗辩：**合法来源、先用权、正当使用、未使用**。
- 救济：停止侵害、赔偿（四档递进）、**1–5 倍惩罚性赔偿**、行政查处、刑事追诉。
- 易错点：商标侵权不要求故意；合法来源只免赔不免停；侵权判定看客观行为。
- 交叉引用：电商平台的「通知—删除」责任与商标侵权交织，与「著作权侵权与救济」中的平台责任规则同源。
