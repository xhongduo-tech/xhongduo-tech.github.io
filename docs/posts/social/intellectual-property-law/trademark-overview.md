## 为什么从商标法概述开始

专利保护技术、著作权保护表达，**商标**保护的则是另一类东西——**商业信誉**。一个品牌值多少钱？可口可乐的商标估值数百亿美元，一个「认准这个标志」的信任，能持续为商品创造溢价。商标法研究的就是：标志如何成为受法律保护的权利、如何区分商品来源、如何防止消费者被混淆。对创业者，「商标」是最早该布局的知识产权——因为它是**注册取得**，晚一天申请可能就与品牌失之交臂。

## 1 商标的概念与功能

**商标（trademark）**：商品或服务的提供者使用的，用以**区分**其商品或服务与他人商品或服务的**标志**。

商标的核心功能有四：

- **区别来源功能**：让消费者识别商品/服务来自谁，这是商标最根本的功能。<span class="marginnote">商标的本质是「来源标签」：你买一罐可乐，靠红底白字的「Coca-Cola」知道它来自可口可乐公司。若无商标，市场将陷入「谁是谁的」的混乱，交易成本暴涨。</span>
**品质保证功能**：商标承载商誉，促使经营者维持质量——砸了牌子就是砸了自己的信誉。
**广告宣传功能**：商标是品牌资产的载体，承载营销投入。
**投资载体功能**：商标可转让、许可、质押，本身就是无形资产。

**重点结论：商标保护的不是标志「长得好看」，而是标志承载的「来源指示 + 商誉」。** 这是商标法与著作权（保护表达）、专利法（保护方案）的本质区别。

## 2 商标的种类

按不同标准，商标有多种分类：

| 分类标准 | 类型 | 例子 |
| --- | --- | --- |
| 使用对象 | 商品商标 / 服务商标 | 「华为」商品；「顺丰」服务 |
| 构成要素 | 文字、图形、字母、数字、三维标志、颜色组合、声音，及组合 | 文字商标「小米」；声音商标「英特尔开机音」 |
| 功能 | 集体商标 / 证明商标 | 集体：「沙县小吃」；证明：「西湖龙井」 |
| 注册与否 | 注册商标 / 未注册商标 | 已注册受强保护；未注册受有限保护 |

**辨析｜易错点：** **集体商标**与**证明商标**容易混淆。集体商标归「集体组织」所有、成员使用，表明成员资格（如行业协会商标）；证明商标由「对商品有监督能力的组织」控制、他人申请使用，证明商品达到特定品质（如绿色食品标志、地理标志证明商标）。<span class="marginnote">一句话区分：集体商标证明「来自哪个集体」，证明商标证明「达到什么标准」。2020 年前后我国对「潼关肉夹馍」等地理标志集体商标纠纷的讨论，正是这两类商标制度在现实中的碰撞。</span>

## 3 商标法的演进与立法体系

我国《商标法》于 **1982 年**通过，是改革开放后最早的商事立法之一，历经多次修改：

**1982 年**：首部《商标法》，确立注册原则。
**1993 年**：增加服务商标注册。
**2001 年**：为加入 WTO，增加对**驰名商标**、地理标志的保护，允许自然人和法人申请。
**2013 年**：引入**声音商标**、诚实信用原则、异议程序限缩等。
**2019 年**：强化**打击恶意注册**，明确「不以使用为目的的恶意商标注册申请应当予以驳回」。<span class="marginnote">2019 年修订直指「商标抢注」顽疾：大量职业抢注人以囤积商标、待价而沽为生。修订后，恶意抢注、囤积不以使用为目的的商标将直接面临驳回与无效，诚实信用原则成为贯穿商标注册全流程的准绳。</span>

商标法与专利法、著作权法并称「知识产权三大法」，但它们保护逻辑迥异：**专利靠申请审查、著作权靠自动产生、商标靠注册使用**。<span class="marginnote">三大权利取得方式的对照记忆：专利「申请授权制」（实质审查）、商标「注册取得制」（先注先得）、著作权「自动保护制」（创作即享）。这是知识产权入门最常考、也最常被混淆的一组对比。</span>

## 4 商标权的取得原则

**注册原则**：商标专用权通过注册取得，未注册的商标原则上不受商标法保护（驰名商标与有一定影响的未注册商标例外）。
**申请在先原则**：同一种或类似商品上申请注册相同或近似商标的，**初步审定并公告申请在先的商标**。<span class="marginnote">「申请在先」意味着：你的品牌再有影响力，只要没注册，别人抢先注册就可能反过来告你侵权。这是「防御性注册」「全类别注册」策略的法律根源——宁可多注册，不可少注册。</span>
- **诚实信用原则**：申请注册和使用商标应当遵循诚实信用原则，恶意抢注不受保护。

## 5 商标与品牌的商业逻辑

商标是法律概念，品牌是商业概念，两者的关系值得厘清：

- **商标是品牌的「法律外壳」**：品牌是消费者心中的认知与好感，商标是承载这份认知的可注册标志。品牌可以没有商标（未注册商标也有一定保护），但商标是品牌获得法律强保护的唯一通道。
- **商标布局是品牌战略的前置**：先注册商标再推广品牌，是「先圈地再建设」；先推广品牌后补商标，是「裸奔后补票」。前者成本低、风险小。
- **商标是融资与并购的资产**：商标可作为质押物融资，也是并购估值的重要项。一个知名商标的价值，往往超过公司的有形资产。

用一个时间线看品牌成长中的商标节点：

| 阶段 | 商标动作 |
| --- | --- |
| 品牌命名 | 商标检索，排除在先冲突 |
| 产品上线前 | 核心类别注册 |
| 业务扩展 | 全类别防御注册 |
| 出海前 | 马德里国际注册 |
| 品牌成熟 | 驰名商标保护、维权 |

**重点结论：商标不是「注册完就结束」，而是贯穿品牌全生命周期的持续经营。** 从检索、注册、防御、续展到维权，每一个节点都在为品牌的商业价值添砖加瓦。把商标当「资产」而不是「证书」，是商标法给创业者最重要的一课。

### 实务深探：商标抢注与诚实信用

商标法实务中最常见的乱象是「抢注」——把别人已经使用但尚未注册的商标抢先注册。这类纠纷最能体现诚实信用原则的司法适用：

- **抢注的典型形态**：代理机构抢注被代理人的商标、员工抢注老板的商标、职业抢注人批量注册他人知名未注册商标待价而沽。
- **权利人反制路径**：对抢注商标提出异议或无效宣告，主张其违反诚实信用原则、构成以不正当手段抢先注册；对已经实际使用且有一定影响的商标，可主张「在先使用」抗辩。
- **诚实信用原则的强化**：2019 年修订明确「不以使用为目的的恶意商标注册申请应当予以驳回」，并设置专项规制——抢注的生存空间被大幅压缩。

| 情形 | 是否受保护 |
| --- | --- |
| 已注册 | 强保护 |
| 未注册 + 有一定影响 + 被恶意抢注 | 可对抗抢注 |
| 未注册 + 未使用 | 保护有限 |
| 恶意囤积、不以使用为目的 | 驳回 + 无效 |

**重点结论：商标法越来越强调「注册不是护身符，诚信才是底色」。** 对创业者而言，既要及时注册防被抢，也要保留使用证据防他人反咬——「使用 + 诚信」是商标制度越来越看重的两件事。

### 术语速查

本篇涉及的核心术语汇总如下：

| 术语 | 含义 |
| --- | --- |
| 商标 | 区分商品或服务来源的标志 |
| 显著性 | 标志便于识别、区别于他人商标 |
| 商品商标 | 用于商品的商标 |
| 服务商标 | 用于服务的商标 |
| 集体商标 | 表明成员来自某集体的商标 |
| 证明商标 | 证明商品达到某标准的商标 |
| 声音商标 | 以声音构成的商标 |
| 注册原则 | 商标专用权通过注册取得 |
| 申请在先原则 | 先申请者获得注册 |
| 诚实信用原则 | 申请注册和使用须诚实守信 |
| 未注册商标 | 未经注册但有一定保护的商标 |

**一句话记住：** 商标保护的不是「标志长得好看」，而是标志承载的「来源指示 + 商誉」；注册取得 + 申请在先 + 诚信原则，是商标法的三大支柱。

## 6 小结

- **商标**：区分商品/服务来源的标志，核心功能是**来源指示 + 商誉承载**。
- 种类：商品/服务商标、文字/图形/声音商标、**集体/证明商标**等。
- 我国《商标法》1982 年制定，2019 年修订强化**打击恶意注册**。
- 取得原则：**注册取得 + 申请在先 + 诚实信用**。
- 易错点：集体商标证「来自哪个集体」，证明商标证「达到什么标准」；未注册商标保护有限。
- 交叉引用：大模型的品牌名、开源项目的商标使用，都落在商标法的射程内——商标与代码、开源共存，是技术世界绕不开的合规命题。
