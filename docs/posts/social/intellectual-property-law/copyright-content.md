## 为什么从著作权的内容开始

知道谁拥有著作权之后，下一个问题是：**著作权人到底能做什么？** 著作权的「内容」是一组权利的清单——人身权守护作者的人格，财产权覆盖作品从复制到传播的全部价值链条。这张清单直接决定了：转载一篇公众号文章要不要授权？给一首歌做 remix 要不要许可？把照片放进作品集展览行不行？逐项弄清楚，是内容创作者与平台运营者的基本功。

## 1 著作人身权

**著作人身权（moral rights）**：与作者人身不可分离、原则上不可转让的权利。我国《著作权法》规定四项：

- **发表权**：决定作品是否公之于众的权利。<span class="marginnote">发表权是人身权里最特殊的一项：它只能行使一次——作品一旦被公之于众，发表权即告用尽；且作者死亡后由继承人保护，但发表权常与财产权行使绑定（授权出版即视为行使发表权）。</span>
**署名权**：表明作者身份、在作品上署名的权利。可署真名、笔名、别名或匿名。
**修改权**：修改或授权他人修改作品的权利。
**保护作品完整权**：保护作品不受歪曲、篡改的权利。<span class="marginnote">保护作品完整权与「改编权」构成张力：改编权允许他人合法地改写作品（如小说改剧本），但改编不得「歪曲、篡改」以至于损害作者声誉。判断标准是改动是否损害作者的精神利益与名誉。</span>

**重点结论：人身权四个——发表、署名、修改、保护完整。** 其中署名权与保护作品完整权的保护期不受限制（永久），体现对作者人格的持续守护。

## 2 著作财产权

**著作财产权**：著作权人享有的、以利用作品获得经济利益的权利。我国《著作权法》第十条列举了十多项，按「利用方式」可分为几组：

**复制权**：以印刷、复印、录音、录像、翻录、翻拍等方式制作作品副本的权利——这是著作权的「母权利」。<span class="marginnote">复制权是著作权财产权的基石：一切后续利用（发行、传播、改编）都从「复制」开始。但复制权不保护「思想」——独立重写一段代码实现同样功能，不构成对原代码「表达」的复制。</span>
**发行权**：以出售或赠与方式向公众提供作品**原件或复制件**的权利。
**出租权**：有偿许可他人临时使用视听作品、计算机软件的权利。
**展览权**：公开陈列美术作品、摄影作品的原件或复制件的权利。
**表演权**：公开表演作品，以及用各种手段公开播送作品表演的权利。
**放映权**：通过放映机等技术设备公开再现视听作品的权利。
**广播权**：以无线或有线方式公开传播、转播作品的权利。
**信息网络传播权**：以有线或无线方式**向公众提供作品，使公众在其选定的时间和地点获得**作品的权利。<span class="marginnote">信息网络传播权是互联网时代新增的权利，其定义核心是「交互式传播」——用户主动选择时间和地点获取（点播）。它区别于广播权（单向、定时）。短视频平台的点播、网盘的分享都在此权控制下。</span>
**改编权**：改变作品，创作出具有独创性的新作品的权利。
**翻译权**：将作品从一种语言文字转换成另一种语言文字的权利。
**汇编权**：将作品或片段通过选择或编排汇集成新作品的权利。

## 3 著作财产权逻辑：从复制到传播

著作财产权可以按「复制 → 发行 → 传播 → 演绎」四环记忆：

| 环节 | 权利 | 关键词 |
| --- | --- | --- |
| 复制 | 复制权 | 制作副本 |
| 发行 | 发行权、出租权 | 提供原件/复制件 |
| 传播 | 表演权、放映权、广播权、信息网络传播权 | 让公众感知 |
| 演绎 | 改编权、翻译权、汇编权 | 产生新作品 |

**辨析｜易错点：** 发行权与信息网络传播权最容易混。**发行权针对「有形复制件」**，一份份地转移物理载体；**信息网络传播权针对「无形网络」**，不转移载体、只让公众在线获得。把书挂在电商卖是发行，把电子书放到网盘供下载是信息网络传播。<span class="marginnote">两者的区分在实务上有个著名推论：网络「下载」不适用发行权用尽（exhaustion），因为数字副本的传输必然伴随「再复制」，无法像纸质书转售那样「让渡载体」。欧盟法院在 UsedSoft 案对软件二手交易作了有限度的例外处理，但文字作品的数字转售至今没有通行答案。</span>

## 4 著作权的保护期

| 权利 | 保护期 |
| --- | --- |
| 署名权、修改权、保护作品完整权 | 不受限制（永久） |
| 发表权 + 财产权 | 作者终生及死亡后 **50 年**，截至第 50 年的 12 月 31 日 |
| 法人作品、视听作品、摄影作品（财产权） | 首次发表后 **50 年**（未发表则创作完成后 50 年） |
| 合作作品 | 以最后死亡的作者为准 + 50 年 |

**重点结论：保护期的起点是「发表」或「创作完成」，终点统一算到该年的 12 月 31 日。** 作者死后 50 年，作品进入**公有领域**，任何人都可以自由使用。<span class="marginnote">公有领域（public domain）是著作权制度的「泄洪口」：无数经典作品、算法、民间艺术在保护期后回归自由。大模型的训练语料大量来自公有领域与开放许可作品，这正是「从极限到大模型」与著作权保护期的现实交汇。</span>

## 5 权利行使的实务要点

理解权利清单之后，更要理解权利怎么用：

- **授权方式**：作者可以就一项权利单独授权（如只授权复制发行），也可以打包授权（如图书出版全版权）。授权范围、期限、地域、对价应在合同中写清，否则容易引发「超范围使用」纠纷。
- **平台与作者的权利分配**：互联网平台的用户协议通常要求作者授予平台「信息网络传播权」的许可，并约定分成。2020 年后我国强化「平台滥用优势地位」的规制，作者与平台的权利博弈进入立法视野。
- **孤儿作品与版权清理**：作品作者不明或无法联系（孤儿作品），使用人难以获得授权，各国探索「尽力查找 + 付费托管」的解决路径——这在老照片数字化、历史文献整理中尤为突出。

用一个对比理解「权利清单」与「授权合同」的关系：

| 权利 | 授权场景 | 典型对价 |
| --- | --- | --- |
| 复制权 | 图书出版 | 版税 |
| 信息网络传播权 | 平台上线 | 分成 |
| 改编权 | 影视化、翻译 | 买断/分成 |
| 表演权 | 演唱会、直播 | 许可费 |

**重点结论：著作权法的财产权设计，本质是为「作品交易」提供一套标准化的菜单。** 每一份授权合同，都是在这个菜单上点单。创作者越熟悉菜单，越能在谈判中保护自己的利益。

### 实务深探：信息网络传播权的「交互性」考验

信息网络传播权的定义核心是「使公众在其选定的时间和地点获得」——这一定义在网络直播时代受到了挑战：

- **点播（交互式）**：用户想看的时候点击播放，属于信息网络传播权控制。网盘分享、视频网站点播、音乐平台单曲播放都归它管。
- **直播（非交互式）**：定时直播、广播，用户不能自行选择时间和地点，属于广播权或表演权范畴。一场演唱会直播，用户只能在指定时间收看，就是典型的非交互传播。
- **「随选 + 直播」混合形态**：直播后生成回放，回放是交互式的，又落入信息网络传播权——同一个直播内容，直播与回放由不同权利控制。

| 传播形态 | 用户能否自选时间地点 | 控制的权利 |
| --- | --- | --- |
| 点播/回放 | 能 | 信息网络传播权 |
| 定时直播 | 否 | 广播权/表演权 |
| 线下放映 | 否 | 放映权 |
| 现场表演 | 否 | 表演权 |

**重点结论：判断一种网络传播落入哪项权利，先问「用户能不能自己选时间地点」。** 这个「交互性」测试，是信息网络传播权与广播权、表演权的分界线——直播平台、短视频平台的责任边界，都围绕这条线展开。

### 术语速查

本篇涉及的核心术语汇总如下：

| 术语 | 含义 |
| --- | --- |
| 发表权 | 决定作品是否公之于众的权利 |
| 署名权 | 表明作者身份、在作品上署名的权利 |
| 修改权 | 修改或授权他人修改作品的权利 |
| 保护作品完整权 | 保护作品不受歪曲、篡改的权利 |
| 复制权 | 以印刷、复印等方式制作作品副本的权利 |
| 发行权 | 以出售或赠与方式提供作品原件或复制件 |
| 出租权 | 有偿许可他人临时使用视听作品、软件 |
| 表演权 | 公开表演作品的权利 |
| 广播权 | 以无线或有线方式公开传播作品 |
| 信息网络传播权 | 使公众在其选定的时间和地点获得作品 |
| 改编权 | 改变作品创作出新作品的权利 |
| 公有领域 | 保护期届满、人人可自由使用的作品 |

**一句话记住：** 财产权按「复制→发行→传播→演绎」四环理解；信息网络传播权看「用户能不能自选时间地点」的交互性。

## 6 小结

- 人身权四项：**发表、署名、修改、保护作品完整**；前两项有特殊性（一次性、永久）。
- 财产权按「**复制 → 发行 → 传播 → 演绎**」四环理解，核心是复制权、信息网络传播权。
- **信息网络传播权** = 交互式点播；**发行权** = 有形载体转移；二者不适用权利用尽。
- 保护期：人身权（署名/修改/完整）**永久**；发表权 + 财产权**终生 + 50 年**；期满入公有领域。
- 易错点：改编权允许合法演绎但不得歪曲篡改；网络传播不适用发行权用尽。
