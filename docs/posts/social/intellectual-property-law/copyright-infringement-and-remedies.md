## 为什么从著作权侵权与救济开始

著作权纠纷是三大知识产权中**数量最大、离普通人最近**的一类：公众号洗稿、短视频搬运、盗版影视、代码抄袭。这一节解决两个实务核心问题：**怎么认定侵权**（「接触 + 实质性相似」）与**侵权了怎么办**（停止侵害、赔偿、惩罚性赔偿）。对创作者而言，这既是维权的武器，也是避免踩线的标尺。

## 1 著作权侵权的认定

著作权侵权的一般构成要件与民法侵权一致：**违法行为、损害事实、因果关系、主观过错**。但著作权侵权认定有自己的独特方法论——**「接触 + 实质性相似」**标准：

- **接触**：被告有机会接触原告作品。可以是直接接触（读过、看过），也可以是「高度盖然性接触」（作品广泛传播，处于可及状态）。<span class="marginnote">「接触」常常由作品的公开程度推定：一首全网热歌、一本畅销书，被告几乎不可能没接触过。若原告能证明被告独立创作、纯属巧合雷同，则可推翻接触推定。</span>
**实质性相似**：被告作品与原告作品在**受保护的表达**上构成实质性相似。

**重点结论：著作权侵权 = 接触 + 实质性相似，且相似必须落在「表达」而非「思想」层面。** 两个人都写「失恋主题的散文」，思想相同不侵权；但若句式、结构、意象选择高度雷同，就可能构成表达上的实质性相似。<span class="marginnote">「思想 / 表达二分法」在此是过滤器：法院先剔除思想、事实、通用元素，只比较受保护的独创性表达。计算机软件著作权纠纷中，法院常先做「抽象—过滤—比较」三步骤，把源码里的公共领域元素、行业惯用表达先剔除再比对。</span>

## 2 侵权行为的类型

著作权侵权可分为**直接侵权**与**间接侵权（帮助侵权）**：

**直接侵权**：未经许可实施著作权人的专有权利，如未经许可复制、发行、表演、放映、广播、信息网络传播作品。<span class="marginnote">「未经许可」是关键：授权范围内的使用不侵权，超范围使用仍可能侵权。把「买断公众号图文转载权」当成「可以随意洗稿改编」，就是超范围使用的常见误判。</span>
**间接侵权**：为直接侵权提供帮助或便利，如平台未履行「通知—删除」义务。网络服务提供者在「知道或应当知道」侵权却未及时采取删除、屏蔽、断开链接等必要措施时，承担连带责任——这就是著名的 **「通知—删除」规则**。<span class="marginnote">「通知—删除」（notice-and-takedown）是互联网平台责任的基石：权利人发现侵权，向平台发通知；平台及时删除可免责，怠于删除则担责。2020 年著作权法修订新增「必要措施」与「反通知」机制，与《民法典》网络侵权规则衔接，直播、短视频平台的责任边界因此不断被讨论。</span>

## 3 侵权抗辩事由

被告可以提出的抗辩：

**合理使用**：落入法定合理使用情形（见本专题《著作权的限制与合理使用》）。
**法定许可**：属于法定许可且已支付报酬。
**授权许可**：已取得权利人许可。
**不构成实质性相似 / 无接触**：从正面反驳侵权构成。
**保护期届满**：作品已进入公有领域。
**合法来源**：销售者、出租者不知道是侵权复制品，能证明合法来源，不承担赔偿责任。<span class="marginnote">「合法来源」抗辩只免赔偿责任，不免停止侵害——销售者仍须停止销售侵权商品。它的逻辑是「善意交易者值得保护，但侵权物品不能继续流通」。</span>

## 4 著作权侵权的救济

| 救济方式 | 内容 | 要点 |
| --- | --- | --- |
| 停止侵害 | 停止复制、发行、传播等行为 | 最常用 |
| 消除影响、赔礼道歉 | 针对人身权侵害（署名权、修改权等） | 著作权特有的救济 |
| 赔偿损失 | 实际损失 → 违法所得 → 权利使用费 → 法定赔偿 | 四档递进 |
| 惩罚性赔偿 | 故意侵权 + 情节严重，1–5 倍 | 2020 年引入 |
| 诉前禁令/行为保全 | 紧急情况下先行停止行为 | 防止损害扩大 |
| 证据保全 | 查封、扣押、取证 | 应对举证难 |

**重点结论：著作权损害赔偿按「实际损失 → 违法所得 → 权利使用费合理倍数 → 法定赔偿」依次确定；法定赔偿上限 500 万元，故意侵权情节严重的可适用 1–5 倍惩罚性赔偿。** 权利人还可主张**合理开支**（律师费、公证费、取证费）。<span class="marginnote">2020 年《著作权法》把法定赔偿上限从 50 万提到 500 万、首次引入惩罚性赔偿，与此前 2020 年《专利法》修订同步——三部知识产权法的「严保护」方向完全一致。实践中法院还结合「侵权人拒不提交账簿」作出不利推定，破解赔偿举证难。</span>

## 5 著作权侵权的典型场景

把规则放到场景里检验：

- **文字作品洗稿**：不逐字复制，而是改写句式、替换词汇、重排段落，但保留了原文的结构、逻辑与表达顺序。法院会综合比对「独创性表达」——若核心表达被整体搬运，仍可能构成实质性相似。
- **代码抄袭**：直接复制源代码最明显；改写变量名、重构函数但保留核心逻辑结构，则进入「实质性相似」的比对。软件著作权纠纷中，法院常用「抽象—过滤—比较」方法，先剔除不受保护的通用代码与思想层面的内容。
- **短视频搬运**：未经许可把影视剧剪辑成「三分钟解说」上传平台，是否构成侵权？核心看使用是否构成「适当引用」、是否实质替代原作——大量纯搬运型解说被认定侵权。

| 场景 | 核心争点 |
| --- | --- |
| 洗稿 | 是否复制了独创性表达 |
| 代码抄袭 | 结构相似是否构成表达相似 |
| 短视频解说 | 是否属于适当引用 |
| 图片盗用 | 是否构成复制 + 传播 |
| 背景音乐 | 是否落入表演权/广播权/信息网络传播权 |

**重点结论：著作权侵权认定的落脚点永远是「表达」而非「思想」。** 洗稿洗不掉表达上的相似，搬运搬不掉传播上的越权。对创作者而言，最稳妥的底线是：使用他人作品前，先问一句「这落在合理使用里，还是需要授权？」——犹豫时，去谈授权。

### 实务深探：平台的「通知—删除」责任边界

网络平台是著作权侵权的主要场域，平台责任规则在实践中最为精细：

- **避风港原则**：平台对用户上传的侵权内容，在「不知道也不应知道」且收到通知后及时删除的，不承担赔偿责任——这就是「通知—删除」避风港。
- **红旗原则**：侵权事实像红旗一样明显（如全片盗版电影、热门新剧全集），平台不能装看不见——此时即使没有通知，平台「应知」侵权，须承担责任。
- **转通知与反通知**：平台收到通知后要转通知上传者；上传者可提交反通知主张未侵权；平台据此恢复链接或转入诉讼程序。

| 情形 | 平台责任 |
| --- | --- |
| 不知 + 及时删除 | 免责（避风港） |
| 应知（红旗）未处理 | 担责 |
| 明知仍提供帮助 | 担责（帮助侵权） |
| 通知后未及时删除 | 对扩大部分担责 |

**重点结论：「通知—删除」不是平台责任的「免死金牌」，而是有条件的避风港。** 判断平台担责与否，核心看「是否知道 + 是否及时处理」。对短视频、网盘、直播平台而言，这一规则每天都在被海量投诉检验。

### 术语速查

本篇涉及的核心术语汇总如下：

| 术语 | 含义 |
| --- | --- |
| 接触 + 实质性相似 | 著作权侵权的认定标准 |
| 实质性相似 | 在受保护的表达上构成相似 |
| 直接侵权 | 未经许可实施著作权专有权利 |
| 间接侵权 | 为直接侵权提供帮助 |
| 避风港原则 | 不知情且及时删除可免责 |
| 红旗原则 | 侵权明显时应知并须处理 |
| 通知—删除 | 权利人通知、平台删除的机制 |
| 合法来源 | 不知情且能证明来源合法免除赔偿 |
| 合理使用抗辩 | 落入法定合理使用情形 |
| 惩罚性赔偿 | 故意侵权情节严重的 1—5 倍赔偿 |

**一句话记住：** 著作权侵权 = 接触 + 实质性相似，相似须落在「表达」层；平台责任看「是否知道 + 是否及时处理」，「通知—删除」是有条件的避风港。

## 6 小结

- 侵权认定标准：**接触 + 实质性相似**，且相似须落在「表达」层面。
- 侵权类型：**直接侵权 + 间接侵权**；平台适用「通知—删除」规则担责。
- 抗辩：合理使用、法定许可、授权、不相似、保护期届满、合法来源。
- 救济：停止侵害、赔礼道歉、赔偿（**四档递进**）、**1–5 倍惩罚性赔偿**、诉前禁令、证据保全。
- 易错点：合法来源只免赔不免停；「通知—删除」及时履行可免责。
- 交叉引用：大模型生成内容是否构成对训练语料的「实质性相似」，是全球正在上演的著作权大命题，与「从极限到大模型」主线直接相关。
