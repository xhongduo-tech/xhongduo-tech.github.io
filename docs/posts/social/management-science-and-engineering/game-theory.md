## 为什么「最优」要两个人说了算

前面所有章节都有一个共同假设：**对手是自然**——需求、工期、价格都是给定的或随机的，决策者单方面优化。但当对手是**另一个理性的决策者**时，情形完全变了：你的最优选择取决于对方的选择，对方的最优选择又取决于你的选择。**对策论（game theory）**就是研究这种「互相牵制的理性」的数学。

运筹学视角下的对策论，与第二级《博弈论》理论课略有分工：这里更强调**矩阵博弈（matrix game）**的计算工具——**鞍点、纯策略、混合策略、极小极大定理**，以及它们与**线性规划**的惊人等价。1944 年冯 · 诺依曼与摩根斯坦的《博弈论与经济行为》把这两者缝合在一起：**任何有限零和对策都可以化为一个线性规划**——两个学科在这一刻合流。<span class="marginnote">对策论在现代决策中的分量与日俱增：定价战、投标竞价、进入威慑、供应链谈判都是典型的对策结构。而「混合策略」的思想——必要时用随机化迷惑对手——在对抗性机器学习里也是核心武器。</span>

## 1 对策的三要素与表示

一个对策有三个要素：

**局中人（players）**：理性决策者，记为 $P_1, P_2, \dots$。两人博弈最简单。

**策略（strategies）**：每个局中人的可选行动。有限个策略时可用**支付矩阵（payoff matrix）**表示。

**支付（payoff）**：各局中人策略组合下各自的得益。

**零和对策（zero-sum game）**：一方的所得恰是另一方的所失，支付矩阵只需给 $P_1$ 的支付，$P_2$ 的支付就是它的相反数。这是运筹学经典对象——战争、赌博、市场份额争夺的抽象。

设 $P_1$ 有 $m$ 个策略、$P_2$ 有 $n$ 个策略，支付矩阵 $A = (a_{ij})$ 中 $a_{ij}$ 是 $P_1$ 选第 $i$ 个策略、$P_2$ 选第 $j$ 个策略时 $P_1$ 的所得。$P_1$ 想最大化 $a_{ij}$，$P_2$ 想最小化它。

## 2 纯策略与鞍点

**最大最小准则（maximin）**：$P_1$ 保守地假设「我选什么都可能碰上最坏情况」，于是先算每行的最小值，再取最大值：

$$v_1 = \max_i \min_j a_{ij}$$

**最小最大准则（minimax）**：$P_2$ 对称地先算每列的最大值（最坏被 $P_1$ 拿走多少），再取最小值：

$$v_2 = \min_j \max_i a_{ij}$$

总有 $v_1 \le v_2$。当 $v_1 = v_2 = v$ 时，存在**鞍点（saddle point）**：$a_{i^*j^*}$ 同时是所在行的最小值、所在列的最大值。此时 $(i^*, j^*)$ 是**纯策略均衡**，$v$ 是**对策值（value of the game）**。<span class="marginnote">鞍点就是矩阵里的「马鞍」：在行方向上它是谷底（$P_1$ 至少拿这么多），在列方向上是峰顶（$P_2$ 至多付这么多）。双方都在这一点上「无怨无悔」——任何单方面偏离都对自己不利，这就是纯策略的纳什均衡。</span>

**划去劣势策略（dominance）**可以简化矩阵：若某行的每个元素都不大于另一行（$P_1$ 的劣势），或某列的每个元素都不小于另一列（$P_2$ 的劣势），就把它删掉，不改变对策值。

## 3 混合策略：当没有鞍点

若 $v_1 \lt  v_2$，纯策略找不到均衡——比如「剪刀石头布」，任何确定的选择都会被对手针对性破解。此时局中人必须**随机化**自己的选择，让对手无法预判。

**混合策略**：$P_1$ 按概率 $\mathbf{p} = (p_1, \dots, p_m)$ 选择各策略，$P_2$ 按概率 $\mathbf{q} = (q_1, \dots, q_n)$ 选择。期望支付是：

$$E(p, q) = \sum_i \sum_j p_i\, a_{ij}\, q_j = \mathbf{p}^{\mathsf{T}} A\, \mathbf{q}$$

$P_1$ 要最大化它，$P_2$ 要最小化它。**极小极大定理（minimax theorem）**（冯 · 诺依曼，1928）说：对任何零和对策，

$$\max_{\mathbf{p}} \min_{\mathbf{q}} \mathbf{p}^{\mathsf{T}}A\mathbf{q} = \min_{\mathbf{q}} \max_{\mathbf{p}} \mathbf{p}^{\mathsf{T}}A\mathbf{q} = v$$

**混合策略的意义是：用不确定性换取可保证的下限。** 随机化的价值不在「碰运气」，而在「让对手无法针对你」。

## 4 公式解析：2×2 混合策略的求解

以经典 2×2 对策为例，设 $P_1$ 以概率 $p$ 选策略 1、$(1-p)$ 选策略 2，$P_2$ 以概率 $q$ 选策略 1、$(1-q)$ 选策略 2。

$P_1$ 的期望支付是：

$$E(p,q) = p\,[a_{11}q + a_{12}(1-q)] + (1-p)\,[a_{21}q + a_{22}(1-q)]$$

$P_2$ 的均衡条件是「无论 $q$ 怎么变，$P_1$ 的期望支付都相同」——因为若 $P_1$ 有更优的 $p$，$P_2$ 就会被针对。令 $p$ 的系数为零：

$$(a_{11} - a_{21})q + (a_{12} - a_{22})(1-q) = 0 \quad \Longrightarrow \quad q^* = \frac{a_{22} - a_{12}}{a_{11} - a_{12} - a_{21} + a_{22}}$$

- **第一步，认思路**：混合策略均衡里，每个局中人都在「让对方对任何选择都无差别」——这是**无差别原理（indifference principle）**。
- **第二步，认对称**：$p^*$ 由让 $P_2$ 的期望支付对 $q$ 无差别解出，公式结构完全相同，只是分子换列。
- **第三步，验概率**：$p^*, q^*$ 必须在 $[0,1]$ 内才是真正的混合均衡；越界则说明纯策略均衡已存在。<span class="marginnote">数值例子：「偷懒 vs 检查」博弈——员工可选偷懒/干活，经理可选检查/不查。设计好支付使 $q^* = 0.4$，含义是经理要保证员工偷懒与干活无差别，须以 40% 概率检查。混合策略不是「偶尔为之」，而是<strong>精心校准的频率</strong>。</span>

## 5 对策论与线性规划的握手

**任何矩阵对策都可以化为一个线性规划**——这是对策论与运筹学最深层的连接。对 $P_1$ 求最大化对策值 $v$，等价于：

$$\max\ v \quad \text{s.t.}\ \sum_i p_i a_{ij} \ge v\ (j=1,\dots,n), \qquad \sum_i p_i = 1, \ p_i \ge 0$$

每列约束说「无论 $P_2$ 选哪列，$P_1$ 的期望支付至少是 $v$」。令 $x_i = p_i / v$，可化为标准 LP 求解。<span class="marginnote">这正是对偶理论的用武之地：$P_1$ 的 LP 与 $P_2$ 的 LP 互为对偶，对策值 $v$ 就是两个对偶 LP 共享的最优值。第2章的对偶定理在此获得了一个惊艳的应用——「两军对阵」与「资源定价」是同一个数学对象的两个侧面。</span>

## 6 易错点与辨析

**辨析｜易错点：混合策略最优解不是「按概率随便出」。** $p^*, q^*$ 是让对手无差别的**特定**概率，偏离它反而会被针对。随机化的时机（用什么随机数生成器）与概率（值是多少）是两回事，后者必须精确求解。

**辨析｜易错点：非零和对策没有「极小极大」的干净解。** 零和博弈里双方利益严格对立，有对策值与均衡的统一理论；非零和博弈（双赢可能）需要**纳什均衡**概念，且可能不存在纯策略均衡、也可能多个均衡——计算与解释都复杂得多。运筹学的矩阵博弈工具主要服务于零和结构。

## 7 数值算例：混合策略的完整计算

考虑一个「市场进入博弈」的 2×2 零和简化：挑战者（$P_1$）可选「进入」或「观望」，在位者（$P_2$）可选「降价」或「维持」。支付矩阵给 $P_1$（单位：百万）：

| $P_1 \backslash P_2$ | 降价 | 维持 |
| --- | --- | --- |
| 进入 | −2 | 4 |
| 观望 | 0 | 0 |

**先找鞍点**：$P_1$ 各行最小值：进入 → −2，观望 → 0，maxmin = 0。$P_2$ 各列最大值：降价 → 0，维持 → 4，minimax = 0。**$v_1 = v_2 = 0$，存在鞍点 $(观望, 降价)$**——这就是纯策略均衡，对策值 0。挑战者观望、在位者降价，任何单方偏离都变差。

**再看无鞍点的情形**：把「观望」行换成「反制」行，支付变为：

| $P_1 \backslash P_2$ | 降价 | 维持 |
| --- | --- | --- |
| 进入 | −2 | 4 |
| 反制 | 1 | 1 |

行最小值：进入 −2、反制 1，maxmin = 1；列最大值：降价 1、维持 4，minimax = 1。仍有鞍点 $(反制, 降价)$，对策值 1。

**构造真正无鞍点的 2×2**：把反制行的（1,1）改为（3,−1）：行最小值：进入 −2、反制 −1，maxmin = −1；列最大值：降价 3、维持 4，minimax = 3。$v_1 = -1 \lt  v_2 = 3$，无鞍点，需要混合策略。设 $P_1$ 以概率 $p$ 进入、$1-p$ 反制，$P_2$ 以概率 $q$ 降价、$1-q$ 维持。令 $P_1$ 对 $q$ 无差别：$-2q + 4(1-q) = 3q - (1-q) \Rightarrow -2q + 4 - 4q = 3q - 1 + q \Rightarrow 5 = 10q \Rightarrow q = 0.5$。再令 $P_2$ 对 $p$ 无差别：$-2p + 3(1-p) = 4p - (1-p) \Rightarrow -2p + 3 - 3p = 4p - 1 + p \Rightarrow 4 = 10p \Rightarrow p = 0.4$。混合均衡：$P_1$ 以 40% 概率进入、60% 反制；$P_2$ 以 50% 概率降价、50% 维持。对策值 $v = -2\times0.4\times0.5 + 4\times0.4\times0.5 + 3\times0.6\times0.5 - 1\times0.6\times0.5 = -0.4 + 0.8 + 0.9 - 0.3 = 1$。

这个例子说明两个要点：**有鞍点直接读纯策略；无鞍点才需要解无差别方程**，且解出的概率必须在 [0,1] 内才是真混合均衡。

## 8 小结

- 对策三要素：**局中人、策略、支付**；零和对策用**支付矩阵**表示。
- **鞍点**存在时双方有纯策略均衡：行最小与列最大的交叉；**劣势策略**可划去。
- 无鞍点时用**混合策略**，**极小极大定理**保证 $\max_p \min_q = \min_q \max_p = v$
