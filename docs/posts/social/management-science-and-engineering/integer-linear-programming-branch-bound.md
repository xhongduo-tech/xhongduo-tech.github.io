## 为什么 0.7 台机器不可接受

运筹学的头号谎言是「解完收工」——因为很多决策变量的最优值根本不允许是分数。**买 0.7 台机器、派 1.3 架飞机、雇 2.4 个工人**，在数学上也许可行，在现实中毫无意义。把整数性约束加回线性规划，得到**整数线性规划（Integer Linear Programming, ILP）**：

$$\max\ z = \mathbf{c}^{\mathsf{T}}\mathbf{x}, \qquad \text{s.t.}\ A\mathbf{x} \le \mathbf{b}, \ \mathbf{x} \ge \mathbf{0}, \ \mathbf{x} \in \mathbb{Z}^n$$

按整数变量范围又细分为**纯整数规划**（全部变量取整数）、**混合整数规划（MIP）**（部分变量取整数）与 **0-1 规划**（变量只取 0 或 1，用于「做/不做」「选/不选」）。<span class="marginnote">0-1 变量是建模的瑞士军刀：它能把「二选一」「至多选一个」「依赖关系」「固定成本」全部翻译成线性约束。学会用 0-1 变量建模，是管理运筹从「会算」到「会想」的分水岭。</span>

这里必须泼一盆冷水：**整数约束让问题突然变难**。普通 LP 是多项式时间可解的，而 ILP 在一般情况下是 **NP-hard**——你没法指望存在一个对所有规模都快得多的算法。分支定界、割平面这些方法，都是「在最坏情况与实用效率之间讨价还价」。

## 1 为什么不能直接四舍五入

初学者最自然的想法：先解 LP 松弛，再把分数最优解四舍五入成整数。这个直觉在大多数时候都是**错的**，原因有三：

**第一，四舍五入可能不可行**。四舍五入后的点可能落在可行域之外——它不再是可行解，甚至差得很远。

**第二，四舍五入可能严重次优**。整数最优解与 LP 最优解之间可以隔着很大的「整数间隙」，四舍五入得到的整数点可能差得离谱。

**第三，四舍五入是「方向性」错误的**。往哪个方向舍、舍几位，牵一发动全身，因为约束相互耦合。<span class="marginnote">一个经典反例：$\max z = x_2$，s.t. $-x_1 + x_2 \le 0.5$，$x_1 + x_2 \le 5.5$，$x_1, x_2 \ge 0$ 且整数。LP 最优在 $(2.5, 3)$，四舍五入到 $(3,3)$ 或 $(2,3)$ 都不可行或次优，而整数最优解是 $(0,0)$——目标值从 3 掉到 0。四舍五入连方向都给错了。</span>

**所以整数规划不能靠「解完再舍」**，必须让整数性从一开始就参与求解过程。

## 2 分支定界：把难题切成小份

**分支定界法（branch and bound）**是现代整数规划求解器（CPLEX、Gurobi）的绝对核心。思想朴素到令人惊讶：**把问题递归地分成更小的子问题，剪掉不可能含最优解的枝**。每一步：

**松弛（relax）**：先解当前子问题的 **LP 松弛**（丢掉整数约束）。对最大化问题，LP 松弛的最优值是子问题最优值的一个**上界（upper bound）**。
**分支（branch）**：若松弛解里某个变量 $x_j$ 取分数值 $f$，把它分成两个互斥子问题：$x_j \le \lfloor f \rfloor$ 与 $x_j \ge \lceil f \rceil$。这两个分支覆盖了所有整数可行方案，且排除了不可行的分数点 $f$。<span class="marginnote">分支的正确性来自「整数 $x_j$ 要么 ≤ floor(f)，要么 ≥ ceil(f)」，两个分支合起来就是全部可能性——这是二分的离散版本。把分数解「卡」在两个相邻整数之间，是分支定界最优雅的一步。</span>
- **定界（bound）**：维护一个**当前最优整数解（incumbent）**。任何子问题的上界若不超过 incumbent 的目标值，就**剪枝（fathom）**——这个子问题内部不可能再有更好的解，无需再分。
- **重复**：对最有希望的（上界最大的）子问题继续分支，直到所有子问题都被剪枝或被解出整数解。

$n$ 个 0-1 变量理论上要检查 $2^n$ 个解，但剪枝让实际访问的节点数远少于这个爆炸数。**算法效率几乎全看剪枝的狠不狠**，而剪枝能力又取决于 incumbent 的质量——所以工程上总是先用启发式找一个好整数解当初始 incumbent。

## 3 公式解析：松弛界的意义

设整数问题 $P$ 的 LP 松弛为 $\bar{P}$。对最大化问题：

$$z^*_P \le z^*_{\bar{P}}$$

**LP 松弛的最优值是整数问题最优值的一个上界。**

- **第一步，认方向**：松弛**扩大了可行域**——原来只允许整数点，现在允许分数点。可行域变大，最优值只会更好（对最大化问题更高），所以 $z^*_{\bar{P}} \ge z^*_P$。
- **第二步，认作用**：分支定界里，每个子问题的上界都由它的松弛解提供。上界 ≤ incumbent 就剪枝，等于宣告「这枝里没有惊喜」。
- **第三步，认间隙**：$z^*_{\bar{P}} - z^*_P$ 称为**整数间隙（integrality gap）**。间隙小，说明 LP 松弛已经把问题逼近到位，分支很快收敛；间隙大，说明整数性本身才是难点，分支要深挖很久。<span class="marginnote">「间隙越小越好算」解释了为什么运输问题、指派问题（全幺模矩阵、间隙为 0）能用 LP 直接解，而一般的集合覆盖问题让人抓狂。间隙是问题难度的第一近似。</span>

## 4 割平面：从另一头逼近

**割平面法（cutting plane method）**与分支定界互补：它不切分问题，而是**给 LP 松弛补刀**——找到一条线性不等式，它不砍掉任何整数可行解，却能切掉当前 LP 最优解所在的分数区域。

最经典的**高莫雷割（Gomory cut）**来自最优单纯形表的任意一行。设某基变量行是：

$$x_i + \sum_j \bar{a}_{ij} x_j = \bar{b}_i$$

把 $\bar{b}_i$ 与所有 $\bar{a}_{ij}$ 拆成整数部分与小数部分，令 $\{t\} = t - \lfloor t \rfloor$，则对整数解必须满足：

$$\sum_j \{\bar{a}_{ij}\}\, x_j \ge \{\bar{b}_i\}$$

这条割不会排斥任何整数可行解，却会把当前分数最优解排除在外。反复加割再解松弛，整数可行域被一层层「剥」出来。<span class="marginnote">高莫雷割的妙处在于它不用引入新变量，直接写在现有单纯形表上；它的代价是收敛可能很慢——所以现代求解器通常用更强的一族割（如覆盖割、混合整数舍入割）配合分支定界，构成<strong>分支割平面法（branch-and-cut）</strong>。</span>

## 5 0-1 建模的两个必杀技

0-1 变量的威力在于它能表达「逻辑关系」。这里给两个高频句式：

**二选一约束**：$x_1 + x_2 \le 1$ 表示「$x_1$ 与 $x_2$ 至多选一个」；$x_1 + x_2 = 1$ 表示「恰好选一个」。用一个大 M 把这类逻辑写成线性约束的一般形式是 $f(\mathbf{x}) \le M y$，其中 $y \in \{0,1\}$ 是开关变量。<span class="marginnote">「大 M」里的 $M$ 要取够大但别过大：太小会错误地砍掉可行解，太大则让 LP 松弛几乎无信息、拖慢求解。经验上取「约束左侧在任何可行点上的最大可能值」即可，这是建模里的一个工程细节，却常决定求解器快慢几倍。</span>

**固定成本建模**：产量 $x$ 的固定成本 $F$ 只在 $x > 0$ 时发生。引入 $y \in \{0,1\}$，写 $x \le M y$ 且目标里加 $Fy$。$y=0$ 强制 $x=0$（不生产不付费），$y=1$ 允许生产并计入固定成本。

## 6 易错点与辨析

**辨析｜易错点：LP 松弛解是整数，不等价于原问题已解。** 若松弛解恰好全整数，它确实是原问题最优解；但若只有部分变量是整数，剩余分数变量仍可能通过分支与整数解交叉影响——不能草率收工。

**辨析｜易错点：分支定界的「定界」方向。** 最大化问题用**上界**剪枝，最小化问题用**下界**剪枝。方向搞反，整个剪枝逻辑就塌了：对最小化问题拿上界当剪枝依据，会把最优解无辜剪掉。

## 7 数值算例：分支定界完整走一遍

用一个小例子看分支定界的全貌。$\max z = 3x_1 + 2x_2$，s.t. $2x_1 + 3x_2 \le 14$，$4x_1 + 2x_2 \le 18$，$x_1, x_2 \ge 0$ 且整数。

**根节点（LP 松弛）**：解松弛得 $x_1 = 2.75, x_2 = 2.83$，$z = 13.92$，不是整数解，上界 13.92。取 $x_1 = 2.75$ 分支：$x_1 \le 2$ 与 $x_1 \ge 3$。

**分支一（$x_1 \le 2$）**：LP 最优 $x_1 = 2, x_2 = 3.33$，$z = 12.67$，仍非整数。再对 $x_2$ 分支：$x_2 \le 3$ 与 $x_2 \ge 4$。

**分支 $x_1 \le 2, x_2 \le 3$**：整数解 $x_1 = 2, x_2 = 3$，$z = 12$。这是第一个完整整数解，更新 incumbent = 12，下界 12。

**分支 $x_1 \le 2, x_2 \ge 4$**：LP 无可行解（约束与整数性联合无解），剪枝。

**分支二（$x_1 \ge 3$）**：LP 最优 $x_1 = 3, x_2 = 2.67$，$z = 14.33$。上界 14.33 > incumbent 12，继续分支 $x_2$：$x_2 \le 2$ 与 $x_2 \ge 3$。

**分支 $x_1 \ge 3, x_2 \le 2$**：LP 最优 $x_1 = 3.5, x_2 = 2$，$z = 14.5$，非整数。继续分支 $x_1 \le 3$：得整数解 $x_1 = 3, x_2 = 2$，$z = 13$，更新 incumbent = 13；分支 $x_1 \ge 4$：LP 无可行解，剪枝。

**分支 $x_1 \ge 3, x_2 \ge 3$**：约束 $2x_1 + 3x_2 \le 14$ 在 $x_1 \ge 3, x_2 \ge 3$ 下不成立，剪枝。

**最终**：所有分支处理完毕，最优整数解 $x_1 = 3, x_2 = 2$，$z^* = 13$。整棵搜索树访问了 7 个节点，避免了穷举所有整数点——剪枝把「无穷可能性」压缩成「十几个 LP」。


**补充：整数规划的现代工程面貌。** 分支定界是骨架，但现代求解器（CPLEX、Gurobi、SCIP）在它之上叠加了大量技巧：**预求解（presolve）**先消去冗余约束与固定变量，**割平面**（覆盖割、混合整数舍入割）给松弛补刀，**启发式**先找好 incumbent 加速剪枝，**节点选择与分支变量选择**决定搜索树走向。这些技巧的共同目标是把搜索树「剪小」。对管理者而言，更实用的是**建模技巧**：大 M 要取紧、0-1 变量要会用、对称性要打破（给相同机器编号会导致搜索树爆炸）。整数规划是「难而常用」的问题——NP-hard 的本质决定了没有银弹，但好的建模与求解器配置能把大部分实际问题在可接受时间内解出。理解「为什么有的整数问题秒解、有的却算不动」，往往答案在建模质量而非算法本身。

## 8 小结

- **ILP** 在 LP 上加了整数约束，一般情形是 **NP-hard**；按整数范围分纯整数、MIP、0-1 规划。
- **四舍五入不可靠**：可能不可行、可能严重次优、可能方向都错。
- **分支定界**：松弛（得上界）→ 分支（$\le \lfloor f \rfloor$ / $\ge \lceil f \rceil$
