## 为什么必须学对偶

上一节的单纯形法把 LP 解了出来，但管理者的追问往往不止于「最优方案是什么」：**再多买一吨原料值不值？** **哪个资源是真正的瓶颈？** 涨价 10% 后方案要不要推翻？对偶理论（duality theory）就是为这些问题而生的。它给每个线性规划配了一个「镜像问题」，两者共享同一个最优值，而镜像问题的最优解——**影子价格**——直接回答了资源的边际价值。

对偶理论也是整个优化领域的枢纽：经济学里的**拉格朗日乘子**、博弈论里的**鞍点**、机器学习里的**对偶方法**（SVM 的支持向量就是从对偶问题来的）、大模型里的**RLHF 约束优化**，全都能在对偶框架下找到位置。<span class="marginnote">把对偶想成「议价的另一面」：原问题问「我该生产什么」，对偶问题问「你的资源到底值多少钱」。一个问题的解，恰好是另一个问题的价格——这正是经济学「资源配置」与「价格形成」的数学合一。</span>

## 1 对偶问题的构造规则

设原问题（primal）取我们在第1章见过的形式：

$$\max\ z = c_1 x_1 + \cdots + c_n x_n, \qquad \text{s.t.}\ \sum_{j} a_{ij}x_j \le b_i \ (i=1,\dots,m),\ x_j \ge 0$$

它的**对偶问题（dual）**是：

$$\min\ w = b_1 y_1 + \cdots + b_m y_m, \qquad \text{s.t.}\ \sum_{i} a_{ij}y_i \ge c_j \ (j=1,\dots,n),\ y_i \ge 0$$

构造规则像对联一样整齐，可以总结成一张**对偶对照表**：

| 原问题（max） | 对偶问题（min） |
| --- | --- |
| 目标系数 $c_j$ | 右端项 $b_j$ |
| 约束个数 $m$ | 变量个数 $m$ |
| 变量个数 $n$ | 约束个数 $n$ |
| 第 $i$ 个约束为 $\le$ | 第 $i$ 个对偶变量 $y_i \ge 0$ |
| 第 $i$ 个约束为 $=$ | 第 $i$ 个对偶变量 $y_i$ 无符号限制 |
| 第 $i$ 个约束为 $\ge$ | 第 $i$ 个对偶变量 $y_i \le 0$ |
| 第 $j$ 个变量 $x_j \ge 0$ | 第 $j$ 个对偶约束为 $\ge$ |
| 第 $j$ 个变量 $x_j$ 无符号限制 | 第 $j$ 个对偶约束为 $=$ |
| 第 $j$ 个变量 $x_j \le 0$ | 第 $j$ 个对偶约束为 $\le$ |

口诀是：**约束符号决定对偶变量的符号，变量符号决定对偶约束的符号**——「紧」的一端对应「自由」的一端。<span class="marginnote">这张表不用背，抓住一个原则就能推导：对偶变量是对应<strong>约束</strong>的「价格」，约束是等式时价格完全由市场定（自由），约束是不等式时价格被单边限制（非负或非正）。</span>

## 2 弱对偶与强对偶：两条最优雅的定理

**弱对偶定理（weak duality）**：对任意可行解 $\mathbf{x}$（原问题）与 $\mathbf{y}$（对偶问题），恒有 $z(\mathbf{x}) \le w(\mathbf{y})$。

证明只要一行：$z = \mathbf{c}^{\mathsf{T}}\mathbf{x} \le (\mathbf{A}^{\mathsf{T}}\mathbf{y})^{\mathsf{T}}\mathbf{x} = \mathbf{y}^{\mathsf{T}}\mathbf{A}\mathbf{x} \le \mathbf{y}^{\mathsf{T}}\mathbf{b} = w$。<span class="marginnote">中间的两处不等号分别来自 $\mathbf{A}^{\mathsf{T}}\mathbf{y} \ge \mathbf{c}$ 与 $\mathbf{A}\mathbf{x} \le \mathbf{b}$（注意都用了 $\mathbf{x}, \mathbf{y} \ge \mathbf{0}$）。这行证明是全书最干净的证明之一——弱对偶的一切推论都藏在两处不等号里。</span>

**强对偶定理（strong duality）**：若原问题与对偶问题之一有有限最优解，则另一个也有，且**最优值相等**：$z^* = w^*$。

这两个定理合起来，给出一个实用的**最优性检验**：只要找到一对可行解 $\mathbf{x}, \mathbf{y}$ 满足 $z(\mathbf{x}) = w(\mathbf{y})$，它们就同时都是最优解。管理上的推论同样深刻：**目标值 $z^*$ 只有一个，无论从「方案」还是从「价格」算起。**

## 3 公式解析：影子价格从哪来

**影子价格（shadow price）**是最有管理味道的概念：资源 $i$ 的影子价格 $y_i^*$，是它的可用量 $b_i$ 增加一个单位时，最优目标值的增量。

$$y_i^* = \frac{\partial z^*}{\partial b_i} \approx z^*(b_i + 1) - z^*(b_i)$$

- **第一步，认来源**：$y_i^*$ 不是拍脑袋定的市场价，而是**对偶问题的最优解**。单纯形法最终表里的检验数行，早已把对偶解藏在其中：$\mathbf{y}^* = \mathbf{c}_B^{\mathsf{T}}B^{-1}$。
- **第二步，看量纲**：$y_i^*$ 的单位是「元 / 第 $i$ 种资源单位」，正好是「资源的单价」，所以叫「影子」——它反映了资源在模型内部的真实价格，而非市场牌价。
- **第三步，识边界**：影子价格只在**小范围**内有效。$b_i$ 变动较大时，最优基可能改变，边际价值会跳变；而且**互补松弛**保证，松弛量大于 0 的资源（没用完）影子价格为 0，被用尽的资源才可能有正的影子价格。<span class="marginnote">「没用完的资源不值钱」是影子价格最反直觉也最有用的一条：如果你发现某资源还有富余，它的影子价格必为 0，多买它不会带来任何额外利润——瓶颈之外的资源没有边际价值。</span>

## 4 互补松弛条件：把「紧」翻译成方程

**互补松弛定理（complementary slackness）**把最优解的两边连起来。设 $\mathbf{x}^*, \mathbf{y}^*$ 分别是原问题与对偶问题的最优解，则：

$$y_i^* \left(b_i - \sum_j a_{ij}x_j^*\right) = 0 \quad \forall i, \qquad x_j^* \left(\sum_i a_{ij}y_i^* - c_j\right) = 0 \quad \forall j$$

每一条都读作：**对偶价格与「松弛量」至少有一个是 0**。若第 $i$ 个约束是紧的（资源被用尽），$y_i^*$ 才可能为正；若 $x_j^* > 0$（产品 $j$ 在产），它对应的对偶约束必然取等号，即「生产 $x_j$ 的边际成本恰好等于它的价格」。

互补松弛在算法上极有价值：已知一方的最优解，可以像解方程组一样反解出另一方，而无需重新求解。它是**灵敏度分析**、**分解算法**与**内点法**的共同底色。

## 5 对偶单纯形法

单纯形法一直在「可行解里找最优」；**对偶单纯形法（dual simplex method）**反着来：保持在**对偶可行**（检验数全部满足符号要求）的前提下，不断消去原问题变量中的负值，直到得到原可行解。

它真正的工程价值在于**重新优化**：当原问题右端项 $\mathbf{b}$ 改变导致当前解不可行时（如产能下调），不必从头重解，从对偶单纯形法两步就能回到最优。<span class="marginnote">工业求解器（CPLEX、Gurobi）在管理运筹与整数规划的分支定界里大量使用对偶单纯形法作为子例程，因为砍掉一个分支只改动 $\mathbf{b}$，用它热启动最划算。</span>

## 6 易错点与辨析

**辨析｜易错点：影子价格 ≠ 市场价，也不等于利润分配。** 影子价格是模型内部的边际价值，只在当前约束结构下成立；市场价是外部交易价格。当影子价格大于市场价时，「买入资源」有利可图；小于市场价时「卖出资源」更划算——这直接给出了一个资源买卖的决策规则。

**辨析｜易错点：对偶变量与松弛变量不要混。** 松弛变量衡量的是「资源没用掉多少」，对偶变量衡量的是「资源每多一单位值多少钱」，前者是原问题内部的量，后者是镜像问题的决策量。它们通过互补松弛成对出现，但一个在表左侧、一个在检验数行。

## 7 数值算例：影子价格从对偶解里读出来

沿用本章的工厂模型 $\max z = 3x_1 + 5x_2$，s.t. $x_1 + 2x_2 \le 8$，$x_1 + x_2 \le 6$，$x_1, x_2 \ge 0$。其对偶问题是：

$$\min\ w = 8y_1 + 6y_2, \qquad \text{s.t.}\ y_1 + y_2 \ge 3, \ 2y_1 + y_2 \ge 5, \ y_1, y_2 \ge 0$$

**用互补松弛反解**：原问题最优解 $(x_1, x_2) = (4, 2)$。两个原约束都取等号（$4 + 4 = 8$，$4 + 2 = 6$，都紧）。$x_1, x_2 > 0$，所以两个对偶约束都必须取等号：

$$y_1 + y_2 = 3, \qquad 2y_1 + y_2 = 5 \quad \Longrightarrow \quad y_1 = 2, \ y_2 = 1$$

**验证强对偶**：$w = 8\times2 + 6\times1 = 16 + 6 = 22 = z^*$。对偶可行也满足：$y_1 + y_2 = 3 \ge 3$，$2y_1 + y_2 = 5 \ge 5$，$y \ge 0$。一对可行解达到同一目标值，同时最优。

**读影子价格**：$y_1 = 2$ 元/工时（约束 1 的资源每多 1 小时，利润多 2 元），$y_2 = 1$ 元/单位（约束 2 的资源每多 1 单位，利润多 1 元）。两个资源都被用尽（约束都紧），所以影子价格都为正；若某个约束有松弛量，它的影子价格会归零。

**经济解释**：若市场上能以低于影子价格的价格买到资源，就值得买入扩产——工时影子价格 2 元告诉你，外部产能若每小时低于 2 元，「买了赚」。

## 8 对偶的跨章节应用地图

对偶理论不是孤岛，它在本书多处反复登场，值得画一张地图：

**运输问题的位势法**（第3章）：位势 $u_i, v_j$ 正是对偶变量，检验数 $\sigma_{ij} = c_{ij} - u_i - v_j$ 就是对偶松弛，这解释了为什么位势法「凭空」出来的 $u$、$v$ 能判最优——它们就是资源的价格。

**网络流的对偶**（第8章）：最大流最小割定理是强对偶的一个特例——流的 LP 与割的 LP 互为对偶，最优流值 = 最小割容量，割上的弧就是「值钱的资源」。

**对策论的极小极大**（第12章）：零和对策的两方 LP 互为对偶，对策值即对偶共享最优值，鞍点与影子价格共享同一套数学。

**机器学习与对齐**：SVM 的对偶、RLHF 的 KL 约束，都是「给约束配影子价格」。**读懂影子价格，就读懂了约束的价值**——约束不再只是限制，而是可以定价的资源。

这张地图说明：对偶不是「一个技巧」，而是贯穿优化与决策的通用视角——**每个资源都有价格，每个约束都有分量**。

## 9 小结

- **对偶问题**与原问题共享最优值，构造规则是「约束↔变量、目标↔右端、符号镜像」。
- **弱对偶**给出 $z \le w$ 的边界；**强对偶**保证 $z^* = w^*$。
- **影子价格** $y_i^*$ 是资源边际价值，等于对偶最优解，只有「用尽」的资源才有正影子价格。
- **互补松弛**把「紧约束」翻译成乘积为零的方程，是反解与灵敏度分析的工具。
- **对偶单纯形法**在对偶可行下迭代，擅长处理 $\mathbf{b}$ 变化的重新优化。
