## 为什么「先见之明」可以工业化

上一节的模型描述了系统的**现在**，但系统工程的大多数决策都在为**未来**做准备：明年市场多大、下月库存要备多少、下季度产能够不够。

**系统预测（forecasting）**就是用历史数据、模型与专家判断，对系统未来的状态做出尽可能好的估计。


预测不是算命——它的目标从来不是「精确预知」，而是**把不确定性量化成可决策的形式**。好的预测给出一个带置信区间、带误差口径的估计，让管理者知道「该为多大的偏差留缓冲」。

预测技术因此与前面的库存、决策分析无缝衔接：**再订货点里的安全库存、决策树里的状态概率，背后都是预测**。

<span class="marginnote">预测在「从极限到大模型」主线里的位置很特别：时间序列分析（第二级）给方法，系统工程给「为什么用、怎么用」的问题意识。</span>

大模型里的下一 token 预测，本质也是「时间序列预测」的一个变体——只是把「销量序列」换成了「token 序列」。


## 1 预测方法的两大家族

**定性预测（qualitative）**：数据不足或结构剧变时，依赖专家判断。代表方法是**德尔菲法（Delphi method）**——多轮匿名征询专家意见，统计收敛后取共识；

还有情景分析（scenario analysis）、头脑风暴。<span class="marginnote">德尔菲法的精髓是「匿名 + 收敛」：</span>

匿名避免权威压制（领导先发言，其他人就跟着附和），多轮反馈让专家在见到他人观点后修正。它把「群体智慧」结构化，是定性方法里最严谨的一种。


**定量预测（quantitative）**：基于历史数据推断未来。又分两类——**时间序列法**（只用变量自身的历史，如移动平均、指数平滑、

ARIMA）与**因果法**（用其他解释变量，如回归分析）。选择哪类，取决于「历史是否稳定可重复」与「是否有可靠的解释变量」。


## 2 时间序列的三类基础方法

**移动平均（moving average）**：

用最近 $k$ 期的均值做下期预测，$\hat{y}_{t+1} = (y_t + y_{t-1} + \cdots + y_{t-k+1})/k$。

$k$ 越大越平滑，但对变化的响应越慢——**平滑度与灵敏度的此消彼长**是移动平均的永恒取舍。


**指数平滑（exponential smoothing）**：给历史数据按「越近越重要」加权，权重按几何级数衰减。


**Holt-Winters 方法**：在指数平滑基础上加**趋势项**与**季节项**，能处理带趋势和季节性的数据——这是工程库存预测里最常用的通用模型。


## 3 公式解析：一次指数平滑

**一次指数平滑**是最简单的动态预测模型。设平滑系数 $\alpha \in (0,1)$，递推：


$$\hat{y}_{t+1} = \alpha\, y_t + (1-\alpha)\, \hat{y}_t$$

- **第一步，认结构**：新预测 = 平滑系数 × 最新观测 + (1−平滑系数) × 旧预测。它是「新信息」与「旧信念」的加权折中。
- **第二步，认权重衰减**：展开可得 $\hat{y}_{t+1} = \alpha y_t + \alpha(1-\alpha)y_{t-1} + \alpha(1-\alpha)^2 y_{t-2} + \cdots$——历史越远，权重按 $(1-\alpha)^k$ 指数衰减，**永不归零但迅速遗忘**。<span class="marginnote">权重衰减永不归零，意味着指数平滑「记得所有历史」，只是老的几乎看不见。$\alpha$ 大则反应快（信新数据），$\alpha$ 小则平滑稳（信历史）。$\alpha$ 的选择通常用「最小化历史预测误差」来标定——把参数标定也变成优化问题。</span>
**第三步，认局限**：一次指数平滑**没有趋势**——对持续上升的序列，它永远「跟不上」，产生系统性的滞后偏差。要处理趋势，需要二次指数平滑（加趋势项）或 Holt 线性趋势模型。

## 4 ARIMA 与回归：两个进阶方向

**ARIMA 模型**（差分自回归移动平均，Box-Jenkins 方法）是时间序列的集大成者：先通过**差分**把非平稳序列变平稳，再用**自回归（AR）**项捕捉「过去的观测影响现在」、用**移动平均（MA）**项捕捉「过去的误差影响现在」。记作 ARIMA$(p, d, q)$，$p$、$d$、$q$ 分别是对应阶数。<span class="marginnote">Box-Jenkins 方法的贡献是给了「选阶数」一个方法论：先看自相关函数（ACF）与偏自相关函数（PACF）定候选阶数，再靠信息准则（AIC/BIC）在候选间挑，最后用残差白噪声检验验证。把「挑模型」从玄学变成流程，是它成为工业标准的原因。</span>

**回归预测**（因果法）：$\hat{y} = \beta_0 + \beta_1 x_1 + \cdots + \beta_k x_k$，用解释变量预测目标。它擅长「有明确驱动因素」的预测，但要求解释变量本身也能被预测或已是既知计划值。

## 5 预测的评价与选择

预测好不好，不能凭感觉，要用**历史回测**检验：把序列截成「已发生」与「待预测」两段，在已发生段上拟合模型，再预测待预测段，与真实值对照。三个常用口径：

**偏差（bias）**：$\frac{1}{n}\sum (y_t - \hat{y}_t)$，衡量系统性高估/低估，应接近 0。

**平均绝对误差（MAE）**：$\frac{1}{n}\sum |y_t - \hat{y}_t|$，量纲内误差。

**平均绝对百分比误差（MAPE）**：上节已见，无量纲、跨序列可比。

选择规则：**先看偏差是否为 0**（系统性偏移要先修），再看 MAPE/MAE 大小；多个模型之间用**样本外**误差比较，而不是样本内拟合精度。<span class="marginnote">「样本外验证」是预测里最容易被忽略的纪律：模型在历史上拟合得漂亮，不代表它对未来预测得好——过拟合的模型样本内误差为零、样本外一塌糊涂。这跟机器学习里 train/test 划分是同一个原则：<strong>用没参与拟合的数据来诚实评估</strong>。</span>

## 6 易错点与辨析

**辨析｜易错点：预测越远越不准，但误差不是线性增长。** 短期预测误差大致随预测期线性增大；但长期预测往往出现「结构性突变」（政策、技术、疫情），历史模式不再成立——此时再精密的定量模型也失效，必须回到定性方法与情景分析。

**辨析｜易错点：预测误差要计入决策，不能「预测完就当已知」。** 把点预测当成确定值直接输入库存模型或产能决策，等于无视预测不确定性。正确的做法是把预测误差分布（标准差）传给下游，让安全库存、缓冲产能去吸收——**预测与决策是接力，不是终点**。

## 7 数值算例：一次指数平滑的手算

某产品近 5 个月的销量：$y = (100, 110, 105, 120, 130)$。用一次指数平滑预测下月销量，$\alpha = 0.3$。

**初始值**：取 $\hat{y}_1 = y_1 = 100$（或前几期均值）。

**逐期递推**：
- $\hat{y}_2 = 0.3\times y_1 + 0.7\times \hat{y}_1 = 0.3\times100 + 0.7\times100 = 100$
- $\hat{y}_3 = 0.3\times110 + 0.7\times100 = 103$
- $\hat{y}_4 = 0.3\times105 + 0.7\times103 = 103.6$
- $\hat{y}_5 = 0.3\times120 + 0.7\times103.6 = 108.5$

**预测第 6 期**：$\hat{y}_6 = 0.3\times130 + 0.7\times108.5 = 115$。

**观察滞后**：销量从 100 涨到 130，但预测只跟到 115——**系统性的滞后**。因为一次指数平滑没有趋势项，面对持续上升的序列永远「慢半拍」。

**换成 $\alpha = 0.8$ 对比**：$\hat{y}_2 = 100$，$\hat{y}_3 = 0.8\times110 + 0.2\times100 = 108$，$\hat{y}_4 = 0.8\times105 + 0.2\times108 = 105.6$，$\hat{y}_5 = 0.8\times120 + 0.2\times105.6 = 117.1$，$\hat{y}_6 = 0.8\times130 + 0.2\times117.1 = 127.4$。

$\alpha = 0.8$ 预测 127.4 更贴近实际趋势，但对噪声更敏感（序列若只是随机波动，会被过度反应）。**$\alpha$ 的选择就是「跟踪速度 vs 噪声过滤」的权衡**，常用最小化历史 MSE 来标定。

**样本外验证**：只让模型看到前 4 期，预测第 5 期再对照。$\alpha=0.8$ 预测第 5 期 $= 0.8\times120 + 0.2\times105.6 = 117.1$，误差 $|130 - 117.1| = 12.9$；$\alpha=0.3$ 预测第 5 期 $= 108.5$，误差 21.5——样本外仍是 $\alpha=0.8$ 更好，这才是有说服力的比较。


**补充：预测的三个工程纪律。** 第一，**先定口径再选方法**：预测是「水平」还是「增长率」？是「点值」还是「区间」？口径不同，方法与误差度量完全不同。第二，**组合预测优于单模型**：把指数平滑、回归、专家判断的结果做加权平均（权重由历史回测决定），通常比任何单一模型更稳——因为不同模型犯错的模式不同，组合可以抵消部分误差。第三，**预测要留给执行缓冲**：把点预测当作确定值输入库存或产能决策，等于无视预测误差。正确的做法是把误差分布（标准差）传给下游，让安全库存、缓冲产能去吸收。这三条纪律的本质是同一件事——**预测的价值不在于「准」，而在于「让不确定性可以被管理」**。

**回到全章脉络**：系统预测技术是系统工程「从看清现在到看见未来」的桥梁——预测的每一步（选择方法、标定参数、验证误差、传递不确定性）都在为下游的库存、产能、评价与决策输送「对未来的估计」。记住博克斯的名言：所有预测模型都是错的，但通过回测、组合与误差传递，它们可以有用。预测不是终点，而是决策链上的一环；**预测的价值，最终由它支撑的决策质量来衡量**。

## 8 小结

- 预测两大家族：**定性**（德尔菲、情景）与**定量**（时间序列、因果回归）。
- 时间序列基础：**移动平均、指数平滑、Holt-Winters**（加趋势与季节）。
- 一次指数平滑 $\hat{y}_{t+1} = \alpha y_t + (1-\alpha)\hat{y}_t$ 权重指数衰减，但无趋势项。
- 进阶：**ARIMA$(p,d,q)$
