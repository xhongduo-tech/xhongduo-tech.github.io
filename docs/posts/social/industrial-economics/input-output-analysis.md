## 为什么从投入产出开始

分工把经济切成无数部门：汽车要用钢铁，钢铁要用电，电要用煤，煤要铁路来运。部门之间互相买卖、环环相扣——**一个部门的产量变化，会像涟漪一样扩散到整个经济**。

如何精确描述这种相互依赖？列昂惕夫（Wassily Leontief）在 20 世纪 30 年代给出了答案：**投入产出分析**——用一张表和一个矩阵，把整个经济体的部门间买卖关系装进去。<span class="marginnote">投入产出分析的思想祖先可以追溯到 1758 年魁奈（François Quesnay）的《经济表》（Tableau économique）——人类第一次试图用一张表刻画国民经济的循环。列昂惕夫把它变成可计算的线性代数工具，并凭此获 1973 年诺贝尔经济学奖。</span>

这一节我们学会读这张表、算它的核心矩阵，并理解「完全需求」背后的级数逻辑。

## 1 投入产出表：经济的国民账本

**投入产出表（input-output table）**：把国民经济按部门分行分列，每一格 $x_{ij}$ 表示部门 $j$ 从部门 $i$ 购买的中间产品价值。

![投入产出表的基本结构](/images/industrial-economics/input-output-table-1.svg)

读表要抓住两条主线：

**按行读（产出去向）**：第 $i$ 行的元素是部门 $i$ 的产品卖给了谁——卖给各部门当中间投入，或卖给最终需求（消费、投资、出口）。**行之和 = 部门 $i$ 的总产出 $X_i$**。
**按列读（投入来源）**：第 $j$ 列的元素是部门 $j$ 从各部门买进了什么，加上**增加值**（劳动报酬、折旧、税、利润），构成它的总投入。**列之和 = 部门 $j$ 的总投入**。<span class="marginnote">表的结构有一个漂亮的对称性：每行的总产出等于每列的总投入——对一个封闭的经济循环，一方卖出的正是另一方买入的，全表由此「收支相抵」。这个恒等式是后面一切线性代数推导的出发点。</span>

## 2 直接消耗系数：一张技术配方

要把「买卖关系」变成可运算的数字，列昂惕夫引入**直接消耗系数（technical coefficient）**：

$$a_{ij} = \frac{x_{ij}}{X_j}$$

它回答一个问题：部门 $j$ **每生产 1 元产出**，需要从部门 $i$ 买多少元的中间产品？$a_{ij}$ 就是部门 $j$ 的「技术配方」——钢铁每炼 1 吨要消耗多少度电，正是列 $j$ 里的一个 $a_{ij}$。

直接消耗系数有三个基本性质：

- $0 \le a_{ij} < 1$：生产 1 元产出，不可能买超过 1 元的同一种投入。
- 同一列系数之和 $\sum_i a_{ij} < 1$：所有中间投入加起来必须小于 1，余下的才是增加值——否则部门 $j$ 生产本身就是亏本的。
- 系数相对稳定：技术不变则配方不变，这使 $A$ 矩阵成为可预测的结构参数。<span class="marginnote">$A$ 矩阵可以理解为经济的「输入—输出关系」的机器语言：它把「部门间的技术联系」固化成一张常数表。放在本站主线里，这就像一个全连接层的权重矩阵——输入是各部门产出，权重是消耗系数，输出是中间需求。</span>

## 3 平衡方程与完全需求

把所有部门写在一起，中间需求就是 $A X$（$A$ 乘上总产出向量），于是有国民经济的**行平衡方程**：

$$X = A X + Y$$

意思是：总产出 = 中间需求 + 最终需求。移项整理：

$$X - A X = Y \quad\Longrightarrow\quad (I - A)X = Y \quad\Longrightarrow\quad X = (I-A)^{-1} Y$$

其中 $I$ 是单位矩阵。$(I-A)^{-1}$ 叫**列昂惕夫逆矩阵**，它把「最终需求 $Y$」翻译成「各部门需要的总产出 $X$」——多生产 1 亿元的汽车，钢铁、电力、采煤要各增产多少？答案全在逆矩阵里。<span class="marginnote">$(I-A)^{-1}$ 与 $I+A+A^2+\cdots$ 的等价性（当谱半径小于 1 时）是本节最漂亮的数学——它把「直接 + 间接 + 再间接」的无限链条装进一个有限矩阵里。</span>

## 4 公式解析：列昂惕夫逆矩阵与完全消耗系数

**「乘数效应的根源，在于无限轮次的间接需求。」** 我们拆成四步：

**第一步，把逆矩阵展开成级数**：当矩阵的谱半径小于 1 时，$(I-A)^{-1} = I + A + A^2 + A^3 + \cdots$。这来自几何级数 $1/(1-x)=1+x+x^2+\cdots$ 的矩阵版本。
**第二步，逐轮读含义**：$I$ 是最终需求本身；$A$ 是第一轮——为生产最终产品直接买的中间投入；$A^2$ 是第二轮——为生产这些中间投入又需要的投入；$A^3$ 是第三轮……每一轮都更小，但都真实存在。
**第三步，汇总成「完全需求」**：把 $I + A + A^2 + \cdots$ 加起来，得到「每 1 元最终需求总共拉动的总产出」。矩阵里第 $j$ 列之和就是部门 $j$ 单位最终需求的总拉动效应——**这就是投入产出乘数**，产业政策测算「投 1 元基建带动多少 GDP」用的正是它。
**第四步，定义完全消耗系数**：$B = (I-A)^{-1} - I$，即去掉最终需求本身后的**直接 + 间接全部消耗**。**$B$ 与 $A$ 的差别，正是「看得见的消耗」与「看不见的消耗」的差别**——生产汽车直接耗钢（$A$），但炼钢耗电、发电耗煤，这层层递进的全链条消耗全在 $B$ 里。

**辨析｜易错点：** 初学者容易把「直接消耗系数 $A$」当作分析的全部。只看 $A$ 会严重低估部门间的联动——直接消耗系数矩阵稀疏（每列只有少数非零），但完全消耗系数矩阵往往**处处非零**，因为间接链条把每个部门都牵连进来。分析产业关联、识别「关键部门」，必须用 $B$ 或 $(I-A)^{-1}$。

## 5 延伸：投入产出表的应用与局限

投入产出表不只是教科书工具，它是当代政策分析与供应链研究的日常武器：

**乘数分析**：测算基建投资的拉动效应（带动多少 GDP、多少就业）——投入产出乘数是产业政策评估的标准工具。
**供应链冲击传导**：2021 年全球芯片短缺，经济学家用投入产出表追踪「汽车芯片断供 → 整车减产 → 相关服务萎缩」的涟漪——它把一场局部短缺的全局后果量化了。<span class="marginnote">COVID 供应链危机让投入产出分析迎来「第二春」：识别「哪些环节断不得」（瓶颈部门）、度量「断供的间接损失」，都靠这张表和逆矩阵——产业安全的度量也用同一套工具。</span>
- **环境投入产出分析（EIO）**：给每个部门的单位产出挂上碳排放系数，就能从最终需求反推「谁在为什么买单」的碳足迹——碳核算与「碳关税」测算都以此为基础。
- **编制与更新**：各国统计机构定期编制投入产出表（中国每五年编一次全国表），配合延长表用于当年分析。

但投入产出分析有三个必须承认的局限：

- **固定系数假设**：$a_{ij}$ 被假定不变，即「技术配方」冻结——现实中企业会替代、会改进，系数会变。短期分析尚可，长期外推会失真。
- **静态与线性**：没有规模经济、没有价格反应、没有供给约束——它回答「直接 + 间接需求」很在行，回答「价格与行为反应」不在行。
- **加总误差**：部门必须归并，归并越粗，产品异质性信息丢失越多。

**辨析｜易错点：** 别把投入产出乘数当成「最终效应」的精确预测。它是「在技术不变、价格不变、产能无限」假设下的**结构近似**，适合做「谁拉动谁、量级多大」的排序，不适合做「精确到小数点的预测」。真正的动态效应，需要交给可计算一般均衡（CGE）或结构计量模型。

## 6 延伸思考：投入产出的边界

投入产出分析的力量与局限都来自它的假设——几道题检验你懂不懂它的「甜区」：

1. 直接消耗系数 $a_{ij}$ 是「技术配方」——若钢铁企业改用废钢冶炼，哪几列系数会变？这对用旧表做长期预测意味着什么？
2. 平衡方程 $X=AX+Y$ 里，若某部门出现供给瓶颈（想产也产不出），逆矩阵的预测会如何失真？
3. 完全消耗系数 $B=(I-A)^{-1}-I$ 为什么「处处非零」而直接消耗矩阵稀疏？——请用「汽车耗钢、炼钢耗电、发电耗煤」画出链条。
4. 投入产出乘数适合做「量级排序」而非「精确预测」——那政策报告里的乘数数字该如何谨慎阅读？
5. 环境投入产出（EIO）把碳排放挂到每个部门——若只算直接排放会漏掉什么？「范围三排放」与之何关？
6. 若把「算力」「数据」也当作部门放进投入产出表，会怎样刻画数字经济的产业关联？

投入产出把「分工」变成可计算的矩阵，却也受制于矩阵的假设。理解它的边界，才能用好它的威力——这本身就是一个产业经济学的方法论缩影。

## 8 小结

- **投入产出表**按「行读出向、列读投入」刻画部门间买卖，行合计 = 总产出，列合计 = 总投入。
- **直接消耗系数** $a_{ij}=x_{ij}/X_j$ 是部门 $j$ 的生产配方，满足非负与列和小于 1。
- 平衡方程 $X = AX + Y$ 给出 $(I-A)^{-1}Y$：把最终需求翻译成总产出。
- 列昂惕夫逆矩阵展开为 $I+A+A^2+\cdots$，**完全消耗系数** $B=(I-A)^{-1}-I$ 涵盖全部直接与间接消耗。
- 分析产业联动必须用完全消耗系数，只看直接消耗会严重低估部门间的相互依赖。
