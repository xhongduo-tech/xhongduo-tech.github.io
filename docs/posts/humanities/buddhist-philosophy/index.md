# 佛教哲学

以四谛、缘起、中观空性、唯识、心性论与禅学为核心线索，系统梳理从印度原始佛教到中国佛教宗派哲学的思想谱系。作为与印度哲学、中国哲学并列的东方哲学传统，佛教哲学是理解东方心性智慧、形而上学与解脱论思想的重要门径。

## 对标教材

- 方立天《中国佛教哲学要义》（中国人民大学出版社，上下卷）
- 吕澂《印度佛学源流略讲》（中华书局）
- 印顺《佛法概论》（中华书局）
