## 为什么从原始佛学讲起

第1篇以印顺《佛法概论》建立了佛教哲学的「教科书框架」，第2篇则转入「史学」——从吕澂《印度佛学源流略讲》看这套思想如何在一个真实的历史中诞生、展开与分化。
**原始佛学**即佛陀本人的教说，是全部佛教哲学的「源头活水」。
吕澂把这一讲定位为全书的起点：不弄清原始佛学「讲了什么、为什么这么讲」，后面部派的分裂、大乘的兴起就都没有着落。
<span class="marginnote">吕澂（1896—1989）是中国近现代最重要的佛学研究者之一，以治学谨严著称；《印度佛学源流略讲》是其讲稿结集，以六讲勾勒印度佛学全史。
</span>

## 1 佛学的产生：佛陀与时代背景

佛教由**释迦牟尼（Śākyamuni）**创立，约公元前 5—4 世纪，诞生于古印度北部的迦毗罗卫国（今尼泊尔境内）。
佛陀原名悉达多·乔达摩，本是迦毗罗卫的太子，出家前经历了「四门出游」的触目惊心——见生老病死而深感人生之苦，遂出家求道，最终在菩提伽耶的菩提树下成道，在鹿野苑初转法轮。

**佛陀成道的内容**，据《阿含经》记载，核心就是「四谛」与「缘起」：
当时的印度思想界，「六师外道」各执一端——或断灭（否认因果），或常见（执有灵魂），或苦行（自虐求解脱），或享乐（纵欲求报）。
佛陀的创教，正是对这批思想的系统回应。
<span class="marginnote">「六师外道」指与佛陀同时代的六位沙门思想家，如末伽梨·拘舍罗（宿命论）、尼乾陀·若提子（耆那教祖师，苦行）等。佛陀与他们论辩的记录，保存在《沙门果经》等经典中。
</span>

## 2 原始佛学的基本教义

吕澂把原始佛学的要点概括为几项根本教义，它们构成了后世一切佛学的「公理集」：

**四谛**：苦（人生实相）、集（苦因）、灭（苦可止息）、道（止息之路）——这是佛陀初转法轮的主题，也是全部佛教的纲领。
**缘起**：此有故彼有，此生故彼生——一切法依条件而生起，无独立自存。
- **无常**：一切有为法念念生灭，没有不变的东西。
- **无我**：五蕴和合的生命中，没有常、一、主宰的自我。

**重点：**这四项教义是一个**严密的整体**——**无常、无我**说明「为什么苦」（有情是缘起生灭的，抓不住、靠不住），**四谛**说明「苦的机制与出路」，**缘起**是贯通前后的总法则。
原始佛学不是零散的道德训诫，而是一套「诊断学」：先说病情（苦），再说病因（集），再说预后（灭），最后开药方（道）。

### 十二支缘起：流转与还灭

缘起不是一句空泛的「此有故彼有」，而是展开为「十二支」的具体链条：
无明 → 行 → 识 → 名色 → 六入 → 触 → 受 → 爱 → 取 → 有 → 生 → 老死。

**流转门（顺观）**：从无明到老死，一环扣一环——「无明缘行，行缘识，识缘名色……」——说明苦的由来与轮回的机制。
**还灭门（逆观）**：从老死倒推，「无明灭则行灭，行灭则识灭……」——断无明，则整条苦链随之瓦解，这就是解脱的路径。

**重点：**十二支的「顺观」是「诊断」——指出苦由无明、渴爱所成；「逆观」是「治疗」——指出断无明即断苦。
这与「四谛」的结构完全同构：**顺观对应「集谛」（苦因），逆观对应「灭道二谛」（止苦之路）**。

## 3 核心对比表：原始佛学与婆罗门教

要理解原始佛学的「新」处，最好的办法是与当时主流的婆罗门教对观：

| 议题 | 婆罗门教 | 原始佛学 |
| --- | --- | --- |
| 权威 | 吠陀天启、婆罗门祭司 | 缘起的如实观察，不需祭司 |
| 修行目标 | 与梵合一（梵我一如） | 涅槃（烦恼止息） |
| 轮回主体 | 常住的阿特曼（神我） | 无我而业相续 |
| 苦乐原因 | 祭祀与业（吠陀） | 渴爱与缘起 |
| 社会伦理 | 四姓阶级制度 | 众生平等、业力平等 |

**重点：**最核心的分歧在「我」——**婆罗门教承认有常住的「神我」在轮回，原始佛学则彻底否定任何常住的「我」**。
这一「无我」的翻转，是整个佛教哲学区别于印度其他传统的第一标记，也是后来一切佛教思想（从部派到中观、唯识）都必须回应的问题。

## 4 原始佛学的特点与构成

吕澂特别强调原始佛学的几个特点，帮助理解它的「性格」：

**重实践、轻玄想**：佛陀对「十四无记」（世界有无边、如来死后有无等）一律不答，理由是这些与离苦无关——佛法不是形而上学体系，而是「离苦的实用科学」。
**依现实、立中道**：既反对纵欲，也反对苦行，走「不苦不乐」的中道。
- **对机说法**：对不同的听众说不同的法，故经典中有「了义」与「不了义」之分，给后世留下诠释空间。

**构成上**，原始佛学以「阿含经」为主体（北传四阿含、南传五尼柯耶），以戒律为制度，以僧团为组织，形成了「经、律、论」三藏中「经、律」二藏的最初形态。
<span class="marginnote">「阿含」（āgama）意为「传来的圣教」，是口耳相传的佛陀言教集录；南传巴利文五部《尼柯耶》与北传汉译《四阿含》大体对应，是最可靠的原始佛教史料。
</span>

## 5 从原始佛学到部派的过渡

原始佛学并非静止不动。佛陀灭度后约一百年，僧团因对「戒律细则」「教法理解」的分歧而逐渐分裂，史称「部派分裂」。
这一分裂的种子，其实早已藏在原始佛学内部：

**「无我而轮回」的难题**：原始佛学说无我，又要解释业与轮回，留下了「轮回主体是什么」的悬案——部派围绕它争论不休。
**「法」是否实有**：佛说「一切法无我」，但「法」本身（缘起的成分）是否实有？这成了有部「法体恒有」与后来中观「一切法空」之争的起点。

**重点：**原始佛学的「开放性」——它的概念（如法、无我、缘起）既精要又留有阐释空间——**既是它生命力之所在，也是部派分裂的温床**。
看懂了这一点，下一讲的「部派佛学」就不难理解了：分裂不是佛教的衰落，而是它被「认真对待」的表现。

原始佛学还有一个常被后世概括为总纲的三项教理——**三法印**：「诸行无常、诸法无我、涅槃寂静」。
「诸行无常」是「无常」，「诸法无我」是「无我」，「涅槃寂静」是解脱的归宿；凡符合三法印即佛法，这是原始佛学留给后世的最简「判教标准」。

## 6 小结

- 原始佛学是佛陀本人的教说，核心是四谛、缘起、无常、无我四项根本教义。
- 佛陀创教于公元前 5—4 世纪，是对六师外道与婆罗门教的系统回应。
- 「无我」是佛教区别于印度其他传统的第一标记。
- 原始佛学重实践、轻玄想，立中道、对机说法。
- 「无我而轮回」「法是否实有」两个悬案，为部派分裂埋下种子。

在下一节，我们将看到佛陀灭度后约一百年，僧团如何因这两个悬案而分裂为众多部派——这就是「部派佛学：上座系、说一切有部与大众系」。
