## 为什么从考古现场讲起

前面十篇讲了各类文物的材料学与保护工艺，但所有文物都经历过一个共同的「危险时刻」：**出土的那一瞬间**。<span class="marginnote">孟子说掘井要挖到泉水，否则就是「弃井」——考古发掘同样如此：<strong>挖开、暴露、取出文物而没能护住它，就等于挖了一口废井</strong>。文物的绝大多数损伤，不是发生在博物馆里，而是发生在出土后的最初几个小时。</span>在墓室、遗址里平静躺了千百年的文物，一旦暴露于空气，温度、湿度、氧气、光线全部骤变——饱水木器开始干缩，丝绸开始粉化，青铜开始「发病」，彩绘开始褪色。**考古现场文物保护**，就是给文物「急救」，为后续实验室保护争取时间。这一节讲现场保护为什么特殊、急救怎么做、以及「信息优先」的铁律。

## 1 现场保护：一场没有第二次机会的抢救

现场保护与实验室保护是两套逻辑：

**环境不可控**：实验室能精确控温控湿，考古现场的风、雨、昼夜温差都得硬扛。
**时间紧迫**：文物暴露在空气中的每一分钟都是损伤，必须先「稳定」再「细治」。
**信息优先**：现场的首要任务不是「修得漂亮」，而是**把出土信息完整记录下来**——位置、层位、伴随物、姿势、朝向，这些是文物价值的另一半，一旦破坏就永远丢失。
**不可逆性高**：现场的任何一次错误操作（比如把饱水木器当场晾干）都是不可挽回的。

**重点：现场保护的目标不是「治好」，而是「稳住并安全送到实验室」**——它是一个转运环节，而非治疗环节。<span class="marginnote">现场保护者像急诊科医生，实验室保护者像住院主治：<strong>急诊只做「先保命、再转院」，不做彻底手术</strong>。把「急救」当「治疗」来做，是现场保护最常见的越界。</span>

**现场保护与实验室保护的分工**，用一张表对比：

| 维度 | 现场保护（急救） | 实验室保护（治疗） |
| --- | --- | --- |
| 环境 | 露天、多变、不可控 | 恒温恒湿、可控 |
| 时间 | 以小时计的抢救 | 以周月计的慢工 |
| 目标 | 稳住 + 转运 | 彻底治理 + 长期保存 |
| 操作 | 保湿、隔氧、避光、抑菌 | 脱盐、加固、修复、环境建设 |
| 判断 | 「不做就会坏」才做 | 「能做且该做」就做 |
| 记录 | 现场信息优先 | 全流程档案 |

现场保护的这套理念并非天生——20 世纪中叶以前，考古发掘更多关注「取出」而轻视「保住」。直到 20 世纪 50 年代后，随着马王堆、兵马俑等重大发现的冲击，中国考古界才确立「发掘与保护并重」的共识，现场保护从此成为发掘流程的法定环节。

## 2 出土瞬间：环境突变与「急救四大件」

文物出土时遭遇的环境突变，可以概括为四类，对应四类急救措施：

**失水**（木、漆、丝、纸等有机文物最致命）：出土后水分迅速蒸发。急救：**保湿**——饱水器物立即浸入清水或密封保湿，丝织品用湿棉、塑料膜包裹。
**氧化**（铁器、青铜、壁画彩绘）：暴露于氧气引发快速锈蚀与变色。急救：**隔氧**——尽快密封、用惰性气体（氮气）环境、或保湿隔绝。
**光照**（丝织品、彩绘、颜料）：阳光与紫外使褪色、脆化。急救：**避光**——遮阳棚、暗处操作、拍照用无紫外光源。
**微生物**（有机质）：潮湿闷热中霉菌迅速滋生。急救：**控湿 + 抑菌**——避免高温高湿，必要时低温暂存。<span class="marginnote">这「四大件」——保湿、隔氧、避光、抑菌——是所有现场保护工作的总纲，<strong>相当于给文物先穿四件「防护服」再谈别的</strong>。遇到具体文物时逐件核查，就基本不会出大错。</span>

### 出土瞬间「四大件」速查

把上面的对应关系收成一张速查表：

| 环境突变 | 危害最烈的文物 | 急救动作 |
| --- | --- | --- |
| 失水 | 木、漆、丝、纸、竹简 | 保湿：浸水 / 湿包 / 密封 |
| 氧化 | 铁器、青铜、彩绘 | 隔氧：密封、惰性气体、保湿 |
| 光照 | 丝织品、矿物颜料 | 避光：遮阳、无紫外光源 |
| 微生物 | 有机质 | 抑菌：控湿、低温、通风 |

**现场记录不是拍照就完**：除方位、层位照片外，还要做比例尺标定、颜色校准卡，必要时用三维扫描建档。这些记录与文物一起进实验室，成为保护与研究的「出生档案」。

**一个对照案例：秦始皇陵兵马俑**。陶俑出土时表面常附着彩绘，暴露后短时间内就可能因失水、氧化而起翘脱落。现场保护团队以保湿与临时定影先行稳住彩绘，再整体提取回实验室做仔细清理——这是「急救先行、治疗殿后」的教科书式分工。

## 3 提取与包装：让文物「安全搬家」

稳定之后，最考验手艺的是**提取**与**包装**：

**整体提取**：对脆弱或成组的文物（漆棺、壁画残块、一整件器物的破碎拼体），不逐一取出，而是连同周围土体一起「端走」。常用**套箱法**——在文物四周做箱体框架，底部托板插入，整体吊装运回实验室后再仔细清理，保证文物在搬运中纹丝不动。
**石膏打包**：对易碎小件，用石膏绷带包裹固定（类似骨科打石膏），内衬隔离层，防止石膏与文物粘连。
**托底支撑**：对丝绸、纸张等片状物，用硬质托板从底部插入托起，避免弯折。
**缓冲包装与运输**：装箱时用泡沫、棉花缓冲，标注「易碎、勿倒置」，运输全程防震防潮、避免温度剧变。

### 现场「急救包」：常用应急材料

现场没有实验室的齐全条件，但一套「急救包」是标准配置，按文物类型取用：

| 材料 | 用途 | 要点 |
| --- | --- | --- |
| 聚乙烯薄膜 / 保鲜膜 | 保湿、隔氧、包裹 | 与文物之间垫湿棉或软纸，避免直接粘连 |
| 石膏绷带 / 聚氨酯泡沫 | 临时固定、打包 | 先衬隔离层，防止石膏与文物表面接触 |
| 硬质托板（亚克力、木板） | 托底支撑片状物 | 从底部插入，禁止从上方提拉 |
| 硅胶干燥剂 / 保湿剂 | 调节运输微环境 | 依据文物「怕干还是怕湿」选择 |
| 便携温湿度计 | 全程记录环境 | 每转运节点记录一次，形成「转运档案」 |

**辨析｜易错点：**石膏打包前必须在文物表面先铺一层隔离膜（保鲜膜或无酸纸），否则石膏凝固时放热并与文物表面粘连，等于给文物做了一次「石膏面膜」——拆包时连皮一起揭掉。隔离层是石膏打包的生命线。

**辨析｜易错点：**「提取速度」与「安全」的取舍最容易出错。有人为了抢时间，对饱水木器当场解剖清理——这是把考古现场当成了实验室，导致木器瞬间失水开裂。<span class="marginnote">判断标准很简单：<strong>凡是可以带回实验室再做的操作，一律不做；现场只做「不做就会坏」的操作</strong>。少动手，往往是更专业的现场保护。</span>

## 4 核心要点：现场保护的标准流程

一张表串起现场保护的完整流程：

| 环节 | 关键动作 | 要点 |
| --- | --- | --- |
| 勘察评估 | 判定材质、病害、危险程度 | 先「诊断」再动手 |
| 环境记录 | 温湿度、埋藏介质、周围环境 | 为后续保护提供「原境」参数 |
| 即时稳定 | 保湿、隔氧、避光、抑菌 | 四大件逐项落实 |
| 加固临时 | 对松散物做临时加固（如石膏托） | 只做「应急」，不做「治疗」 |
| 提取 | 套箱、托板、整体提取 | 宁慢勿抢、宁整勿碎 |
| 包装运输 | 缓冲、密封、标注、防震 | 全程可追溯 |
| 登记移交 | 编号、拍照、登记、移交实验室 | 信息链完整闭合 |

**重点：记录是现场保护的一部分，而不是附带工作**——文物的层位、朝向、共存关系，一旦现场丢失，实验室里再也找不回。所以现场保护者要同时具备考古学（读懂现场）与保护学（稳住文物）两种素养，这正是李晓东把「考古现场文物保护」放在《文物学》里的原因：它处于考古学与保护学的交界。<span class="marginnote">这也是本专题与博客《考古学》专题的交叉点：<strong>地层学、类型学解决「怎么认」，现场保护解决「怎么保」——一条探方里，考古学家与保护者并肩作战</strong>。许多重大发现（马王堆、兵马俑）的成果，一半归功于现场保护。</span>

### 现场记录的「最小清单」

保护现场的标准记录至少包含：

- 出土位置与层位（对应考古地层学）
- 文物朝向、姿态、与共存物的关系
- 环境参数：温湿度、埋藏介质（土质、积水、棺液）
- 出土瞬间状态照片（含比例尺与色卡）
- 每一步保护操作的时间、材料、人员

这张清单是「信息优先」原则的落地——记录不全，等于文物「半件出土」。

## 5 数字实例：一片饱水木简的现场抢救

把「四大件」落到具体数字上。以饱水竹木简为例——马王堆汉墓、里耶秦简等出土的竹木简，在地下含水率可高达干重的 200%–400%：一根干重 10 克的木简，出土时可能带着 20–40 克水。

**第一步，判断紧急度**：木简离开地下水环境后，表层水分在几分钟到几十分钟内就开始蒸发；细胞壁一旦塌缩，干缩与开裂不可逆。所以出土瞬间就要湿棉包裹、密封保湿，把「失水」挡在第一步。

**第二步，计算保湿窗口**：保湿的目标是在水分散失前把木简运抵实验室。经验做法是「湿包 + 低温 + 快运」——湿无纺布包裹、密封袋/箱、4 ℃ 左右冷藏运输，把失水速率压到可忽略。

**第三步，留下转运档案**：从出土到入库，每个节点记录温湿度与操作。实验室据此倒推「木简经历了什么」——脱水方法的选择，就取决于它出土后暴露了多久。

马王堆一号汉墓中大量丝织品与竹简出土后，现场考古队以「保湿 + 逐层记录 + 整体提取」流程，把最脆弱的丝织品在几小时内安全转运到库房，为实验室脱水与加固争取了完整时间窗。<span class="marginnote">2002 年湖南里耶古城一口古井出土 3.7 万余枚秦简，大多饱水，<strong>正是靠现场保湿、整体提取与快速转运，这批简牍才得以完好保存</strong>——现场保护做得好坏，直接决定简牍的生死。</span>

## 6 小结

- 现场保护是**急救与转运**，不是治疗：目标是「稳住并安全送抵实验室」。
- 出土环境突变四类：**失水、氧化、光照、微生物**，对应急救四大件：**保湿、隔氧、避光、抑菌**。
- 提取与包装的关键：**整体提取（套箱、石膏包）、托底支撑、缓冲运输**；宁慢勿抢、宁整勿碎。
- 现场保护第一原则是**信息优先**——记录的价值不亚于文物本身。
- 现场保护是**考古学 × 保护学**的交界学科，需要双重素养。
- 现场「急救包」四件套：**保湿 / 隔氧 / 避光 / 抑菌**，按文物「怕干怕湿怕氧怕光」逐项取用。
- 转运全程要有**记录档案**：从出土到入库的每个温湿度节点，都是实验室保护方案的输入。
