## 为什么从类推与借用开始

上一篇我们接受了「音变无例外」的新语法学派纲领。但新语法学派自己也清楚，语言不是一台只会机械音变的机器——还有两种力量不断「打断」音变的规则性，它们正是这一课的主角：**类推（analogy）**来自语言内部，是心理与语法系统的重整；**借用（borrowing）**来自语言外部，是语言与语言接触的产物。两者合起来，构成了历史语言学「例外解释工具箱」里的另外两件工具。

理解类推与借用，也是在理解一个更大的问题：**语言为什么既稳定又善变？** 稳定靠的是代代相传的规则与核心词汇，善变靠的正是类推对规则的重塑、借用对词汇的刷新。上一篇的「音变无例外」是一种理想化；这一篇补上现实——语言里时刻都在发生「有例外」的演变。

从方法论文看，这两者也扮演着「干扰项」与「金矿」的双重角色：对比较法来说，类推与借用是必须排除的噪音；对语言接触研究来说，借用又是最直接的历史证据。**同一件事，在两种研究框架里价值完全不同**——这种视角切换，是历史语言学训练的核心。

## 1 类推变化：语言的心理重整

**核心概念：类推变化（analogical change）**：语言使用者依据语言中已有的、成型的模式，对某个形式进行改造，使其「像」那个模式的过程。它的本质不是「机械的」语音移动，而是「心理的」模式匹配。

最直观的例子是儿童语言：孩子常说「我 buyed 了它」「foots 都脏了」，把不规则动词、名词拉成规则形式——这就是类推在起作用。历史语言学关心的不是儿童错误，而是**这类操作一旦固化进成人语言、代代相传，就成了真正的语言变化**。英语的 *worked* 取代了 *wrought*、*cows* 取代了 *kine*，都是历史上真实发生过的类推。<span class="marginnote">英语 *children* 本身就是类推的产物：古英语复数 *childer* 后来又叠加上 -en，形成双重复数标记 *child-er-en*——类推不是只会「简化」，它也可能给旧形式「加固」一个新标记。</span>

类推有几种典型形态，值得逐一记住：

**水平化（leveling）**：把同一个词形变化表（paradigm）里不一致的形式拉平。古英语 *singan* 各人称词尾不同，现代英语一律用同一个形式，就是词形表的水平化。
**回推构词（backformation）**：从较长的形式反推出一个更短的基式，如英语 *edit* 是从 *editor* 反推出来的，而 *editor* 本身来自拉丁语。
**比例类推（proportional analogy）**：按「a 之于 b，如同 c 之于 x」的比例推出新形式，我们会在第 4 节用公式细讲。

类推并非对所有词一视同仁。有一个著名的规律：**高频的不规则形式更能抵抗类推**。*is / was / were* 这些最常用的词，形态最不规则却千年不变，因为高频词靠整块记忆（rote）储存，不需要也不容易受到「模式套用」的冲击；低频的 *wrought*（work 的过去式）则轻易被 *worked* 取代。频率是类推的「刹车」，这一点在后来的语言使用模型里被反复验证。<span class="marginnote">这条规律解释了上一篇的矛盾：音变「无例外」地作用于所有词，类推却<strong>挑词下手</strong>——高频词免疫，低频词易感。语言变化因此呈现出「音变均匀、类推不均」的双重面貌。</span>

值得强调的是，类推的「规则化」方向常常与音变的「不规则化」方向相互配合，形成一种循环：音变先把 *fōt* 变成 *feet*（元音交替），类推再把整个复数系统朝 -s 拉齐（*foots* 一度出现），但高频的 *feet* 又抵抗住了这轮类推。**音变与类推的拉锯，正是语言在「规律」与「不规则」之间徘徊的常态**。

## 2 核心对比：音变与类推

> 纯概念主题，以核心对比表替代公式解析。

| 维度 | 音变 | 类推 |
| --- | --- | --- |
| 机制 | 发音器官的机械惯性 | 心理的规则匹配 |
| 制约条件 | 语音环境 | 语法/语义模式 |
| 是否关心词义 | 不关心 | 关心 |
| 结果 | 音位系统重组 | 词形/词类系统重整 |
| 方向性 | 无方向，随环境而定 | 趋向规则与能产模式 |
| 可否预测 | 高度可预测 | 只能事后解释 |
| 对「音变无例外」的影响 | 本身是规律 | 制造例外 |

**重点：音变与类推是两种性质相反的力量。** 音变把规则的形式变得不规则（*foot* → *feet* 的元音交替是音变的遗产），类推又把不规则拉回规则（*cows* 取代 *kine*）。语言就是在这两种力量的拉扯中演变的——音变「制造」不规则，类推「修复」不规则，借用则从外部不断「投放」新的材料。

值得注意，这种「制造与修复」的循环不是语言独有的：生物进化的突变（随机制造新性状）与自然选择（定向保留适应性）、技术创新的试错（随机产生新点子）与市场选择（定向淘汰），都与「音变造不规则、类推修规则」共享同一套「随机变异 + 定向选择」结构——历史语言学又一次与演化思想同构。

类推的力量不止于词汇形态，它还推动**语法系统的重组**。英语过去时从强变化（元音交替，如 *sing/sang/sung*）向弱变化（加 -ed）的千年转移，本质就是类推把能产的 -ed 模式扩散到越来越多的动词上。类推因此是连接「词汇层面」与「语法层面」演变的一座桥——这也是本专题末篇《语法化理论与单向性假说》的伏笔。

## 3 词汇借用：语言的横向流动

**核心概念：借用（borrowing）**：一种语言把另一种语言的形式（通常是词，也可以是语音、语法结构）拿过来据为己用。借用不是「缺陷」，而是所有语言都有的常态——世界上不存在「纯洁的、不借词的」语言。<span class="marginnote">「纯洁语言」是常见的误解：连号称最保守的冰岛语也在不断创造仿译词。区别只在于借的「量」与「来源」，不在于借不借。</span>

借用的规模可以衡量语言接触的深度：**只是少量借词，说明浅层接触；大量借词乃至语法结构被借用，说明深度接触甚至双语社会。** 英语的词汇史几乎就是一部借用史——本族词只占现代英语词汇的四分之一左右，其余皆借自他语。这种「借来拼装」的程度，在印欧语系里独一无二。

借用的类型有清晰的梯度，从「整块搬音」到「只借结构」：

- **借词（loanword）**：直接把语音形式搬来，如英语 *sushi* 借自日语，汉语「沙发」借自英语 *sofa*。
- **仿译词（calque）**：把对方的构词方式逐部分翻译过来，如英语 *loanword* 是对德语 *Lehnwort* 的仿译，汉语「超市」是 *supermarket* 的仿译。
- **语义借用（semantic borrowing）**：给本族词添加一个外语里的新义位，如汉语「粉丝」由 *fans* 获得「拥趸」义。
- **结构借用（structural borrowing）**：借用句式或语法手段，如东南亚一些语言对汉语量词结构的借用。

借词的动因通常是**文化威望与概念空缺**：征服者带来餐桌词（诺曼法语 *beef*、*mutton*），科技传播带来术语（英语 *computer* 进入几乎一切语言），避讳也可能促成借词（某些文化里死者名字禁用，改用他语称呼）。

借词一旦进入，就**必须服从借入语言的音系与形态**。英语借来的法语 *garage* 被安上英语的塞音/齿音，日语把英语 *star* 改造成 *sutā*（插入元音、拆分辅音丛），汉语把 *coffee* 变成「咖啡」。借词的语音面貌因此记录了**借入时刻**的音系状态，反过来成为历史语言学的证据——比如芬兰语借自原始印欧语的一批词，保存了 PIE 早已消失的形态特征，为重建提供了宝贵旁证。

借词还常常留下**分层的考古剖面**。英语词汇史清晰地分成三层：诺曼征服前借自古诺尔斯语的日常词（*skirt*、*they*），征服后借自法语的上层词（*beef*、*parliament*），以及文艺复兴后借自拉丁语/希腊语的学术词（*science*、*telephone*）。**每一层借词对应一段文化接触史**——词源的层次，就是历史的层次。

## 4 公式解析：比例类推 a : b = c : x

**比例类推是类推最「公式化」的一种**，索绪尔把它称为「四比例」（*quatrième proportionnelle*）。设已知一对形式 a : b 构成一种语法关系（如单数对复数），要为一个新形式 c 求出对应项 x：

$$
a : b = c : x \quad \Longrightarrow \quad x \text{ 与 } c \text{ 的关系} = b \text{ 与 } a \text{ 的关系}
$$

逐项拆解这条「四比例」：

- **a : b**：一对已知的对应形式。比如 *sing : sang*（现在时 : 过去时），或者 *cat : cats*（单数 : 复数）。a 是源，b 是目标。
- **c**：一个需要变格/变位的「新词」——说话者想要它的对应形式 x。
- **x**：待求的目标形式。比例说：**x 之于 c，应该像 b 之于 a**。孩子听到 *walk* 想要过去时，就按「sing→sang 那样」推出 *walked*。
- **⟹**：结论。x 与 c 的关系 = b 与 a 的关系——**同一语法关系在两组词之间「等比复制」**。

**重点：比例类推的精华在于「关系，而不是形式」**。类推者不是照搬 *sang* 的读音，而是复制「现在时→过去时」这个关系，套用到新词上。这解释了为什么类推能产生**能产（productive）**的变化：只要掌握一个模式，就能推及整类词。也解释了为什么高频词免疫：*is* 的过去时若按比例推，该是 **is→is**，但它不这么变——因为高频词走整块记忆，不走比例运算。<span class="marginnote">这个「复制关系而非形式」的思想，与《机器学习》里的「<strong>学习映射而非记住样本</strong>」完全同构：类推是语言的「少样本学习」，一个样例就能泛化到一类。</span>

比例类推还有个常被忽视的用途：**它是历史语言学的「反推工具」**。当两个词形不一致时，比例可以解释哪一个「更古老」——比如英语 *cow/cows* 与 *ox/oxen*，*oxen* 保留了古老的复数模式，而 *cows* 是类推向 -s 靠拢的结果。**比例类推让研究者能从「哪个形式像类推产物」推断「哪个形式更古早」**——这是《比较法与原始语重建》的重要助手。

## 5 类推与借用：例外工具箱的两件工具

把本课的两种力量放回历史语言学的「例外解释工具箱」，它们的角色一目了然：

**新语法学派的信条是「音变无例外」**——那么「例外」从哪来？答案正是类推与借用：**音变造成「规则的不规则」，类推修复它，借用则从外部投来新材料**。三者构成一个完整的循环：音变磨损规则 → 类推恢复规则 → 借用引入新素材 → 新素材又成为下一轮音变的原料。

| 力量 | 来源 | 作用对象 | 方向 | 对比较法的影响 |
| --- | --- | --- | --- | --- |
| 音变 | 发音器官 | 整个音系 | 机械、无方向 | 建立对应（可用） |
| 类推 | 心理模式 | 词形/词类 | 趋向规则化 | 制造例外（须排除） |
| 借用 | 语言接触 | 词汇为主 | 横向流入 | 制造假同源（须识别） |

**重点：类推与借用是同一枚硬币的两面——一个来自语言内部，一个来自语言外部**。它们都「打断」音变的规则性，却都是语言演变的正常动力。对比较法来说，两者都是「必须排除的噪音」；对语言演变本身来说，两者都是「不可或缺的引擎」。**同一件事，在重建里是障碍，在演变里是动力**——这个视角切换，正是历史语言学训练的核心，也是《语言接触与克里奥尔化》一课的基础。

## 6 小结

- **类推**来自语言内部，是心理的模式匹配：水平化、回推构词、比例类推是三种典型形态。
- **借用**来自语言外部，有借词、仿译词、语义借用、结构借用的梯度；英语词汇史几乎就是一部借用史。
- 比例类推 $a : b = c : x$ 的核心是**复制关系而非形式**，与「少样本学习」同构。
- 高频词抵抗类推（*is/was/were* 千年不变）、低频词易感（*wrought*→*worked*）。
- 类推与借用是「例外解释工具箱」的两件工具，也是比较法必须排除的两类噪音。
- 借词留下**分层剖面**：英语词汇的三层（古诺尔斯/法语/拉丁希腊）就是文化接触的三幕，词源层次即历史层次。
