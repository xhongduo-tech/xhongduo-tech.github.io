## 为什么从语音演变开始

上一篇我们看到了印欧语系的「认亲」过程，其中最关键的一条证据是**语音对应**：英语 *father\* 与拉丁语 *pater\* 反复出现 f~p 的对齐。可是，为什么会有这种对齐？为什么 *p\* 会变成 *f\*？语音演变（sound change）就是回答「对应从何而来」的学科。

在所有语言演变类型里，**语音演变最系统、最可预测**：它不针对个别词，而是把整个音系里的某一类音整体搬移。这也让它成为历史语言学方法论的样板——如果连语音都能发现「规律」，那么其他层面的演变（类推、借用、语法化）就有了可参照的严格标准。<span class="marginnote">这一课的思路与《集合的概念》一课相通：先给出对象的精确分类，再讨论对象之间如何运算、如何守恒。语音演变的分类型学，就是音系的「运算规则」。</span>

## 1 语音演变的分类型学

语音演变形形色色，但大体可以归入几类**基本操作**。理解这些操作，比背一堆例子更有用：

| 操作 | 含义 | 例证 |
| --- | --- | --- |
| **合流（merger）** | 两个音合并成一个 | 拉丁语 *ae\* 与 *e\* 在后期合并 |
| **分裂（split）** | 一个音在特定条件下分成两个 | 英语 /æ/ 在 *bad\* / *bath\* 中分化 |
| **同化（assimilation）** | 一个音变得像邻居 | 拉丁语 *noctem\* → 西语 *noche\*（kt→tʃ） |
| **异化（dissimilation）** | 相同的音变得不同 | 拉丁语 *arbor\*（树）的 r-r 异化 |
| **脱落（deletion）** | 删除一个音 | 英语历史性词首 *k\* 脱落（*knight\*） |
| **插入（epenthesis）** | 加入一个音 | 拉丁语 *humil-* → 西语 *humilde\* |
| **换位（metathesis）** | 两个音互换位置 | 英语 *three\* 的古英语 *thrie\* 与 *thir-* |
| **弱化（lenition）** | 辅音变弱（塞音→擦音） | 西班牙语词间 d→ð |

**核心概念：语音演变（sound change）**：一个语言里，某音位在特定语音环境下、于某一时期发生的形式变化。它有三个特征——**规则性**（系统性作用于一整类音）、**语音制约**（条件来自语音环境，而非词义）、**无意识**（说话者毫不知情）。

为什么音会变？主要动力是**发音省力**：连续语流里，为了把音发得顺畅，嘴会不自觉地简化动作（同化、弱化、脱落都由此而来）。次要动力是**听者的重新分析**：孩子习得母语时，可能把某个音的分布归纳错，代代相传就形成新格局。省力与重新分析共同作用，构成了音变背后「无意识」却方向明确的双引擎。

## 2 格林定律：第一条「语音定律」

格林定律（Grimm's Law）描述的是**原始印欧语（PIE）到原始日耳曼语**的第一次辅音大推移。雅各布·格林把它总结为三组对应：

PIE 清塞音 *p、*t、*k → 日耳曼语清擦音 *f、*þ、*h（*h）
PIE 浊塞音 *b、*d、*g → 日耳曼语清塞音 *p、*t、*k
PIE 送气浊塞音 *bʰ、*dʰ、*gʰ → 日耳曼语浊塞音 *b、*d、*g

三组对应的实例，就是上一篇那批「亲缘证据」：

| 拉丁语（保留 PIE 面貌） | 英语（日耳曼语） | 对应 |
| --- | --- | --- |
| *pater\* 父亲 | *father\* | p→f |
| *trēs\* 三 | *three\* | t→þ |
| *cornū* 角 | *horn\* | k→h |
| *genus\* 种类 | *kin\*（亲属） | g→k |
| *bʰrā́tēr\*（梵语）兄弟 | *brother\* | bʰ→b |

## 3 维尔纳定律：例外如何被「收编」

格林定律刚提出时，有一批扎眼的例外：照理 *t\* 该变 *þ*，可有些词偏偏变成了 *d\*。最著名的就是「父亲」与「兄弟」这对：拉丁语 *pater\* → 英语 *father\*（出现了 d 的痕迹），而 *brāter\* → *brother\*（保持 þ）。

1877 年，丹麦学者**卡尔·维尔纳（Karl Verner）**解开谜团：这些「例外」其实完全规则，只是格林没有找到条件。**维尔纳定律（Verner's Law）**：日耳曼语中，由格林定律产生的清擦音 *f、*þ、*h、*s，若处在**重音不落其前**的位置，就会进一步浊化为 *b、*ð、*g、*z\*。<span class="marginnote">PIE 的重音是自由重音；日耳曼语后来把重音固定到词首音节。维尔纳发现的正是：<strong>格林定律的例外，由 PIE 重音位置预测</strong>——重音位置不同，同一音素走了不同的路。</span>

于是「父亲」与「兄弟」的差别有了解释：PIE *ph₂tḗr 的重音在末音节，*t 前是不重读的元音，满足维尔纳条件，*þ→*ð；而 *bʰréh₂tēr 重音在首音节，*t 前是重读元音，条件不满足，*þ 保留。**「例外」并不是对规律的否定，而是对规律认识的深化**——这正是新语法学派假说最迷人的地方。

值得记住这条科学史节奏：**格林提出规律 → 例外被发现 → 维尔纳发现隐藏条件 → 例外被重新收编**。每转一圈，学界对「规律」的理解就深一层。这种「假设—反常—修正」的循环，与自然科学完全同构——历史语言学在 19 世纪就率先把语言学变成了「可证伪的科学」。

## 4 规则解析：维尔纳定律的触发条件

> 把维尔纳定律读作一条「如果…那么…」规则，逐项拆解它的触发条件。

$$
[\text{清擦音 } f, \theta, x, s] \xrightarrow{\text{① 处于浊音环境} \wedge \text{② 前一音节不重读}} [\text{浊擦音 } \beta, \delta, \gamma, z]
$$
