## 为什么从语音演变开始

上一篇我们看到了印欧语系的「认亲」过程，其中最关键的一条证据是**语音对应**：英语 *father* 与拉丁语 *pater* 反复出现 f~p 的对齐。可是，为什么会有这种对齐？为什么 *p* 会变成 *f*？语音演变（sound change）就是回答「对应从何而来」的学科。

在所有语言演变类型里，**语音演变最系统、最可预测**：它不针对个别词，而是把整个音系里的某一类音整体搬移。这也让它成为历史语言学方法论的样板——如果连语音都能发现「规律」，那么其他层面的演变（类推、借用、语法化）就有了可参照的严格标准。<span class="marginnote">这一课的思路与《集合的概念》一课相通：先给出对象的精确分类，再讨论对象之间如何运算、如何守恒。语音演变的分类型学，就是音系的「运算规则」。</span>

## 1 语音演变的分类型学

语音演变形形色色，但大体可以归入几类**基本操作**。理解这些操作，比背一堆例子更有用：

| 操作 | 含义 | 例证 |
| --- | --- | --- |
| **合流（merger）** | 两个音合并成一个 | 拉丁语 *ae* 与 *e* 在后期合并 |
| **分裂（split）** | 一个音在特定条件下分成两个 | 英语 /æ/ 在 *bad* / *bath* 中分化 |
| **同化（assimilation）** | 一个音变得像邻居 | 拉丁语 *noctem* → 西语 *noche*（kt→tʃ） |
| **异化（dissimilation）** | 相同的音变得不同 | 拉丁语 *arbor*（树）的 r-r 异化 |
| **脱落（deletion）** | 删除一个音 | 英语历史性词首 *k* 脱落（*knight*） |
| **插入（epenthesis）** | 加入一个音 | 拉丁语 *humil-* → 西语 *humilde* |
| **换位（metathesis）** | 两个音互换位置 | 英语 *three* 的古英语 *thrie* 与 *thir-* |
| **弱化（lenition）** | 辅音变弱（塞音→擦音） | 西班牙语词间 d→ð |

**核心概念：语音演变（sound change）**：一个语言里，某音位在特定语音环境下、于某一时期发生的形式变化。它有三个特征——**规则性**（系统性作用于一整类音）、**语音制约**（条件来自语音环境，而非词义）、**无意识**（说话者毫不知情）。

为什么音会变？主要动力是**发音省力**：连续语流里，为了把音发得顺畅，嘴会不自觉地简化动作（同化、弱化、脱落都由此而来）。次要动力是**听者的重新分析**：孩子习得母语时，可能把某个音的分布归纳错，代代相传就形成新格局。省力与重新分析共同作用，构成了音变背后「无意识」却方向明确的双引擎。

## 2 格林定律：第一条「语音定律」

格林定律（Grimm's Law）描述的是**原始印欧语（PIE）到原始日耳曼语**的第一次辅音大推移。雅各布·格林把它总结为三组对应：

PIE 清塞音 *p、*t、*k → 日耳曼语清擦音 *f、*þ、*h（*h）
PIE 浊塞音 *b、*d、*g → 日耳曼语清塞音 *p、*t、*k
PIE 送气浊塞音 *bʰ、*dʰ、*gʰ → 日耳曼语浊塞音 *b、*d、*g

三组对应的实例，就是上一篇那批「亲缘证据」：

| 拉丁语（保留 PIE 面貌） | 英语（日耳曼语） | 对应 |
| --- | --- | --- |
| *pater* 父亲 | *father* | p→f |
| *trēs* 三 | *three* | t→þ |
| *cornū* 角 | *horn* | k→h |
| *genus* 种类 | *kin*（亲属） | g→k |
| *bʰrā́tēr*（梵语）兄弟 | *brother* | bʰ→b |

## 3 维尔纳定律：例外如何被「收编」

格林定律刚提出时，有一批扎眼的例外：照理 *t* 该变 *þ*，可有些词偏偏变成了 *d*。最著名的就是「父亲」与「兄弟」这对：拉丁语 *pater* → 英语 *father*（出现了 d 的痕迹），而 *brāter* → *brother*（保持 þ）。

1877 年，丹麦学者**卡尔·维尔纳（Karl Verner）**解开谜团：这些「例外」其实完全规则，只是格林没有找到条件。**维尔纳定律（Verner's Law）**：日耳曼语中，由格林定律产生的清擦音 *f、*þ、*h、*s，若处在**重音不落其前**的位置，就会进一步浊化为 *b、*ð、*g、*z*。<span class="marginnote">PIE 的重音是自由重音；日耳曼语后来把重音固定到词首音节。维尔纳发现的正是：<strong>格林定律的例外，由 PIE 重音位置预测</strong>——重音位置不同，同一音素走了不同的路。</span>

于是「父亲」与「兄弟」的差别有了解释：PIE *ph₂tḗr 的重音在末音节，*t 前是不重读的元音，满足维尔纳条件，*þ→*ð；而 *bʰréh₂tēr 重音在首音节，*t 前是重读元音，条件不满足，*þ 保留。**「例外」并不是对规律的否定，而是对规律认识的深化**——这正是新语法学派假说最迷人的地方。

值得记住这条科学史节奏：**格林提出规律 → 例外被发现 → 维尔纳发现隐藏条件 → 例外被重新收编**。每转一圈，学界对「规律」的理解就深一层。这种「假设—反常—修正」的循环，与自然科学完全同构——历史语言学在 19 世纪就率先把语言学变成了「可证伪的科学」。

## 4 规则解析：维尔纳定律的触发条件

> 把维尔纳定律读作一条「如果…那么…」规则，逐项拆解它的触发条件。

$$
[\text{清擦音 } f, \theta, x, s] \xrightarrow{\text{① 处于浊音环境} \wedge \text{② 前一音节不重读}} [\text{浊擦音 } \beta, \delta, \gamma, z]
$$

逐项拆解这条规则，它其实是三条独立条件的「与」（合取）：

- **条件①：输出必须是「浊音环境」**。所谓浊音环境，指该擦音**夹在浊音之间**——前后都是元音或浊辅音。*father* 里 *þ* 处于两元音之间（*fa-* 与 *-er* 都是浊音段），满足条件；*brother* 里 *þ* 前面恰是重读元音 *ē*，这个「重读」正是关键。
- **条件②：该擦音的**前一音节**不重读**。维尔纳的精妙之处在于把重音纳入音变条件——这在当时是革命性的。*pater* 的 *t* 处于不重读音节之后，浊化；*brāter* 的 *t* 处于重读音节之后，保持清音。
- **推论：清擦音 f、þ、h、s 各自对应一个浊擦音输出**，f→*β*、þ→*ð*、h→*γ*、s→*z*——四条子规则共享同一触发条件，合并成一条总规则。

**重点：维尔纳定律是「有条件的格林定律」**。它没有推翻格林定律，而是给格林定律的「例外」找到了隐藏的触发条件——这正是科学里「反常 → 新规律」的标准进阶。而重音本身后来也变了（日耳曼语把重音固定在词首），于是现代英语里我们看到的是一条「已经停止运行的化石规则」——**音变是历史快照，条件消失后，规律就冻结在词形里**。

## 5 条件与无条件音变：把「规律」看得更细

格林定律与维尔纳定律揭示了音变的一个共性：**绝大多数音变是有条件的**——只有在特定语音环境里才发生。与无条件音变相对，条件音变是历史语言学里最精细的解剖对象，值得单独拆开：

| 类型 | 含义 | 例证 |
| --- | --- | --- |
| **无条件音变** | 不分环境，音位整体变化 | 上古汉语的入声尾 -p/-t/-k 在多数方言里整体弱化 |
| **条件音变** | 只在特定环境变化 | 维尔纳定律（重音条件）、英语元音大推移（长元音环境） |
| **合并式条件变化** | 不同来源的音在特定环境汇合 | 拉丁语 *ae* 与 *e* 的合流 |

**重点：条件音变是重建的「金矿」**。因为条件音变在词形变化表（paradigm）的不同格位留下不同痕迹，历史语言学家能据此反向锁定音变发生的时间与顺序。比如英语 *was* 与 *were* 的差异，正是维尔纳定律在词形变化表内部留下的化石——**同一个词的两种形式，走过了不同的语音历史**，这为重建提供了「时间锚点」。

用代码语言打比方：无条件音变像是「全局替换」，条件音变像是「正则替换」——后者因为带环境信息，反而更能暴露原始数据的结构。<span class="marginnote">这也是为什么《比较法与原始语重建》里的重建原则强调<strong>先找条件对应，再定原始音</strong>：带条件的对应比无条件的对应信息量更大、更可靠。</span>

## 6 新语法学派与「音变无例外」之争

把格林、维尔纳和 19 世纪语言学串起来的，是 1876 年成立于德国莱比锡的**新语法学派（Neogrammarians）**——布鲁格曼、奥斯特霍夫、莱斯金（August Leskien）等人。他们提出一条近乎信仰的纲领：

**重点：新语法学派假说（Neogrammarian Hypothesis）**：**语音变化毫无例外**——在同一语言、同一时期、同一条件下，某个音变化，就变化该语言里所有符合这一条件的词；所谓的「例外」，都另有原因（类推、借用、条件未辨明）。

这条「无例外」宣言并非空谈，它有极强的操作性：它逼着研究者**为每一个「例外」找解释**——要么是隐藏的语音条件（维尔纳定律正是这样被发现的），要么是类推或借用。正是这种「不许有例外」的纪律，让比较法成为可能：如果音变可以随意发生，那么任何重建都无从谈起。<span class="marginnote">新语法学派的「无例外」与《统计学习方法》里的「<strong>不可约误差</strong>」异曲同工：它承认总有些噪声（类推、借用）无法用语音规则解释，却坚持把可解释的部分解释干净——先榨干规则，再谈残余。</span>

新语法学派并非没有对手。以**于果·舒哈特（Hugo Schuchardt）**为代表的「方言学」阵营批评道：音变不是凭空发生的，而是在语流中、在个人口音里逐步扩散的——这预示了 20 世纪**词汇扩散（lexical diffusion）**理论：音变可能逐个词、逐代地渗透，而非瞬间覆盖全部词汇。

**辨析｜易错点：** 把「音变无例外」误读成「音变瞬间完成」是大忌。**「无例外」说的是「结果上有规律」，不是「过程上瞬间」**。同一时期的语音变化可能慢到需要几代人；但只要它发生了，就按条件作用于所有合格词。规律性与渐进性，是两个可以同时成立的属性。

## 7 小结

- 语音演变分**合流、分裂、同化、异化、脱落、插入、换位、弱化**等基本操作，动力来自发音省力与听者重新分析。
- **格林定律**描述 PIE 到日耳曼语的三组辅音推移；**维尔纳定律**为它的「例外」找到重音条件。
- **新语法学派假说**主张「音变无例外」，把解释「例外」当作学科纪律；**词汇扩散**理论则强调音变在词与词之间渐进渗透。
- 音变研究是历史语言学的样板：**先立规律，再找条件，绝不让「例外」蒙混过关**——这条纪律支撑了比较法的全部可行性。
- 条件音变是重建的「金矿」：它在词形变化表里留下时间锚点，为《比较法与原始语重建》提供最可靠的对应证据。
- 格林定律与维尔纳定律共同说明：**「例外」是未发现的条件，不是规律的失败**——这是新语法学派留给历史语言学最宝贵的遗产。

在下一节，我们将补上「例外」解释工具箱里的另外两件工具。**类推变化与词汇借用**，会让我们看到语言内部的心理重整如何重塑规则、语言之间的接触如何刷新词汇——它们正是新语法学派口中「例外」的两大主要来源。
