# 数学应用与不可或缺性论证

## 为什么从「应用」开始

前面的争论都发生在数学「内部」：对象存在吗？逻辑成立吗？但数学有一个所有流派都无法回避的外部事实——
**它极其好用。**微积分是牛顿力学的语言，群论是粒子物理的词典，微分几何是广义相对论的骨架，
概率论是统计学的底座。如果数学只是柏拉图式理念的静观，为什么理念恰好是世界的语法？
如果数学只是符号游戏，为什么游戏的走法精确到小数点后十位？

维格纳把这个问题命名为「数学不合理的有效性」——不是「合理」，而是「不合理」
地有效。而哲学家里有一派人反手一击：
**正因为数学如此深入地镶嵌在科学里，数学对象才获得了最坚实的实在性证明。**这就是**蒯因（Quine）**与**普特南（Putnam）**提出的**不可或缺性论证（indispensabilityargument）**——
把数学的哲学地位，从「纯理念」挪到了「科学整体的一部分」。这是本节前半段；
后半段讲物理主义者**菲尔德（Hartry Field）**如何用「数学并非不可或缺」
来反击。

## 1 应用之问：从微积分到神经网络

先把这个问题的分量掂量一下。整个「从极限到大模型」的主线，其实都在复演同一种惊讶：

- 牛顿需要「瞬时变化率」，极限与导数被发明出来——此后两个世纪，物理学家用它计算行星轨道，与天文观测一致到角秒级别。
- 黎曼几何在 1854 年只是一个「关于弯曲空间」的纯粹思想构造，半个世纪后成了爱因斯坦引力场方程的语言，并预言了引力波。
- 线性代数与概率论，两个看似「纯粹」的分支，构成了今天神经网络的全部骨架——反向传播是链式法则，损失函数是期望，正则化是范数。<span class="marginnote">站在大模型时代的读者对「应用」应该最有体感：你每天在用的注意力机制、梯度下降、概率采样，每一件都是「先有纯数学，后有用处」。数学不是从应用里归纳出来的，而是先被发明、再被发现恰好适用。</span>

对形式主义者，这是一个死结：一套「没有意义的符号游戏」，凭什么与世界逐条吻合？
对柏拉图主义者，这是一个礼物：抽象对象与世界的深层结构同构，恰恰说明它们都是实在的。
但对两者来说，都先要回答一个更精确的问题——
**数学在科学里的地位，到底是「必需品」还是「方便的记法」？**不可或缺性论证就是冲着「必需品」
这三个字来的。

## 2 不可或缺性论证：三步推理

蒯因的整体主义从两条原则出发，普特南把它们组装成针对数学的明确论证：

1. 
**整体主义 / 自然主义（holism / naturalism）**：科学知识是一个整体，
没有单独的经验陈述能独立于整体被验证或证伪。我们对任何对象（电子、场、星系）
的信念，都来自它在我们最好的科学理论中的位置。
**本体论承诺（ontological commitment）**的标准是蒯因那句著名的口号：
**「存在，就是成为变元的值」（to be is to be the value of avariable）**——
一个理论承诺存在哪些东西，就看它的约束变元必须取哪些值。
2. **数学在科学中不可或缺**：现代物理的定律无法在不使用数学的情况下表述。
抽掉微分方程，就没有牛顿力学；抽掉希尔伯特空间，就没有量子力学。数学不是科学花园里的装饰花，
而是承重墙。
3. **结论**：既然我们接受科学理论，就应接受数学对象的实在性——
**数字、集合、函数，与电子、磁场一样真实。**

这个论证的漂亮之处在于它绕开了本纳塞拉夫两难：数学知识不再是「关于特殊抽象对象的特殊先验知识」
，而是与物理知识同一条经验洪流的一部分。我们「知道」$\pi$ 有超越数性质，
与我们知道「电子有负电荷」，在认识论上是同一件事——都来自整体科学经验。
<span class="marginnote">注意这个论证如何给柏拉图主义「补税」：
它不承诺数学对象住在哪个理念王国，只承诺它们在科学里像电子一样「干活」。柏拉图主义的本体论经验主义的认识论，
被焊在一起。</span>

## 3 公式解析：菲尔德的保守性反击

1990 年之前的争论焦点，集中在**不可缺失性**这个前提：数学真的抽不掉吗？
**菲尔德（Hartry Field）** 在 1980 年的《没有数字的科学》
（_Science Without Numbers_）里给出一个雄心勃勃的回答：
**可以抽掉。**

菲尔德的策略分两步。第一步，**重写物理**：把数学化表述中的「数」，
全部换成对**时空点**之间关系的直接谈论。
牛顿力学说「物体$m$受到$F=ma$」，可以翻译成纯粹关于时空点之间「介于」
「更接近」等几何关系的一阶陈述——不出现任何数字。第二步，
**证明数学只是脚手架**：对任意一个「不用数字的」
物理理论$N$和任意一个这样的物理陈述$\varphi$，都有：

$$
\text{若 } N + \text{数学} \vdash \varphi, \quad \text{则 } N \vdash \varphi
$$

这条式子叫作**保守性（conservativeness）**。三步拆解：

- **第一步，读懂箭头**：左边的「$N + \text{数学}$」是叠加了数学的理论，它推出了 $\varphi$。右边要求：$N$ 自己也能推出 $\varphi$。中间的推论符号 $\vdash$ 是「能证明」。
- **第二步，把握「保守」的语义**：数学对 $N$ 是**保守**的，意思是：**数学加入后能证明的「纯物理」结论，数学加入前也能证明。** 数学没有为物理贡献任何新的事实，只是帮我们把同样的结论算得快一点、写得短一点。
- **第三步，推出反柏拉图主义结论**：如果数学只是「方便的计算工具」，它**没有真理性承诺**——就像计算器的进位器不承诺「存在进位器之神」。于是不可或缺性论证的前提 2（数学不可或缺）不成立，前提 3 的结论（数学对象实在）随之落空：**数学对象可以不存在，科学照样成立。**

保守性定理本身是元数学里被严格证明的结论——这使它比多数哲学论证都「硬」。问题的关键在于：
**菲尔德的几何化翻译真的覆盖了全部物理吗？**它用了「时空点」这个新对象——
这些点若也抽象，不过是把数字换了个名字；此外，量子力学、测度论里对「连续统」
的依赖，能否彻底几何化，至今有争议。
<span class="marginnote">一个更深的检验：现代物理用到的空间（希尔伯特空间、
概率测度空间）不是「物理时空」，而是抽象结构。菲尔德的方法在经典力学上最成功，
在量子理论上面临成倍加大的工程量——这场拉锯到今天仍是开放问题。
</span>

## 4 争论现状：从本体论战场到自然主义

不可或缺性论证与菲尔德反击的拉锯，没有一方彻底获胜，但把问题逼得更清楚了：

**菲尔德证明了**：不可或缺性论证的力量不取决于「科学离了数学没法算」，而取决于「科学离了数学没法表述」
是否成立。这是一个强得多的门槛。
- **蒯因—普特南一方回应**：即便能几何化，那也是用**另一个抽象结构**（时空）替换**一个抽象结构**（数）；「承诺对象」的争论变成了「承诺哪些对象」的争论。

而 1990 年代后，**马迪（Penelope Maddy）**等人提出第三种声音——
**自然主义（naturalism）**：不需要在哲学上裁决数学对象的实在性。
数学家的数学实践（哪些公理可接受、哪些证明算数）由数学自身内部的标准决定，正如科学家的标准由科学内部决定。
**数学不需要哲学的护照，哲学更不该替数学签发本体论签证。**<span class="marginnote">自然主义是本专题最「收手」
的立场：它不回答「数字存在吗」，而说「这个问题不该由哲学定夺」。它的底气来自一个事实——
数学已经独立运行了几千年，从不等待哲学家批准。这个思路到最后一节会彻底展开。
</span>

对「数学应用」本身，争论并未终结：维格纳的「不合理的有效性」在哲学上仍是未解之谜。
一个流行的温和说法是：数学对象（结构）本来就多得无边，科学挑选的只是「真实世界恰好实例化了的那一小批」
——这让「有效性」从奇迹降格为「从无数候选里选中对的」，但「世界恰好实例化了数学结构」
这个事实本身仍是奇迹。它把应用问题引向了一个新的哲学立场——**结构主义**：
数学研究的是结构，而科学恰好用到了真实世界的结构。

## 5 小结

- **应用之问**：微积分、黎曼几何、概率论在发明多年后「恰好」描述了世界——纯数学与应用科学的吻合，是形式主义解释不了的奇迹。
- **不可或缺性论证**（蒯因—普特南）：整体主义 + 数学在科学中不可缺失 ⇒ 数学对象与电子同样真实；「存在，就是成为变元的值」。
- 论证的靶心是**前提 2**：数学是否真的不可缺失。
- **菲尔德的保守性反击**：$N+\text{数学}\vdash\varphi \Rightarrow N\vdash\varphi$ ——数学对物理是保守脚手架；若能几何化全部物理，数学对象就可有可无。
- 争论现状：几何化是否覆盖量子力学有争议；**马迪的自然主义**主张数学的实在性由数学实践内部裁定。
- 应用问题的深层指向：世界恰好实例化了某些数学结构——这正是结构主义的入口。

在下一节，我们将正式接过这个接力棒：如果数学研究的既不是对象王国，也不是无意义符号，
而是**结构**本身，那么「数字是什么」「数学为何适用于世界」这两个老难题，
会不会同时消解？——这就是**数学结构主义**。
