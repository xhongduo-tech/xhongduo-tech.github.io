# 直觉主义与构造主义

## 为什么从「构造」开始

前面两个答案把数学对象要么放得太远（柏拉图式的理念王国），要么放得太近（符号游戏）
。有一个荷兰人提出了第三条路：
**数学既不描述外部世界，也不只是符号——数学就发生在你的心里。**当你做一次数学构造，
你就在实施一次心灵的创造；数学命题为真，不是因为它「符合某个对象」，
而是因为你能**构造**出它的证明。
这个人是**布劳威尔（L. E. J. Brouwer，1881—1966）**，
这个立场叫**直觉主义（intuitionism）**。

直觉主义最惊世骇俗的后果，是它对逻辑本身的动刀：它把「排中律」请出了数学殿堂。
理由朴素而深刻：对有限的事物，排中律是天经地义；对无限的事物，它就是一句空话。
这一刀切开的不只是逻辑，还有「存在」这个词的含义——在直觉主义者看来，
**存在就是可构造**。

## 1 布劳威尔：数学是心灵的构造

布劳威尔早年是顶尖拓扑学家（布劳威尔不动点定理的作者），后半生转入数学基础。
他的哲学起点是一个彻底的倒转：**数学独立于语言和逻辑而存在。**语言只是事后给数学留存的记录，
逻辑只是从成功的构造中抽象出来的描述——先有构造，后有逻辑。

那么，数学最初从哪来？布劳威尔提出「原始直觉」：时间流中，一个生命时刻分裂为「已经过去」
与「即将到来」——这种**二合一（two-oneness）** 的结构。自然数就从这个原始的、
时间性的区分中直接涌现：1，2，3，……是心灵在时间中不断「分离出一个、再分离出一个」
的产物。<span class="marginnote">这个论证听起来玄，
但要点很实际：自然数不是从外部「发现」的，而是心灵活动自身展开的。对布劳威尔而言，
数学是自足的——不需要对象王国，也不需要语言符号，正如意识不需要外物来「担保」
自身存在。</span>

由此，直觉主义与前面两派划清界限：

与**柏拉图主义**对立：不存在先于心灵的对象王国，数字没有独立于心灵的「位置」
。
- 与**形式主义**对立：数学不是无意义的符号游戏，它有真实的内容——就是「心灵中的构造」本身。

## 2 拒斥排中律：存在 = 可构造

直觉主义对古典逻辑的修正集中在**排中律（law of excluded middle）**：
$A \vee \neg A$。直觉主义为什么不承认它？看一个经典例子。

考虑命题「$\pi$ 的十进制展开中出现连续十个 7」。今天我们知道它其实为真，
但站在不知道的时刻思考：古典逻辑说，要么出现要么不出现，二选一，必定成立。直觉主义说：
**这不过是一句空话**——除非你能给我十个连续 7 出现的位置，或者证明它永不出现，
否则「要么……要么……」没有内容。对无穷展开来说，「穷尽检查」是不可能的，所以排中律在无穷对象上失去效力。
<span class="marginnote">注意直觉主义没有说「$A\vee\neg A$为假」
，只说它<strong>不可作为一般原则</strong>使用：它不能当作无需证明的逻辑定律，
只能当作某个具体命题的「有待构造的事实」。
</span>

**存在 = 可构造**是这条线的直接推论：证明「存在 $x$使$A(x)$」
，必须**给出**一个具体的 $x$，并给出「$A(x)$成立」的构造。只看一个经典例子如何被构造主义点破：

> 经典证明「存在无理数 $a,b$ 使 $a^b$ 是有理数」：考虑 $\sqrt{2}^{\sqrt{2}}$。若它是有理数，则取 $a=b=\sqrt{2}$，完成；若它是无理数，则取 $a=\sqrt{2}^{\sqrt{2}},\, b=\sqrt{2}$，于是 $a^b = 2$ 是有理数，也完成。

这个证明两步都「完成了」，却**从头到尾没告诉我们到底是哪种情况**——
它用了排中律「$\sqrt{2}^{\sqrt{2}}$ 要么有理要么无理」
来分叉。构造主义者会拒绝它，转而给出一个明确的构造：
取$a = \sqrt{2}$，$b = 2\log_2 3$（两者皆无理）
，则$a^b = 2^{\log_2 3} = 3$，一步到位。
**同一个定理，经典证明和构造证明给出的是不同强度的知识。**

## 3 公式解析：布劳威尔—海廷—科尔莫戈罗夫解释

直觉主义逻辑不是「少了一条公理的古典逻辑」，而是**用「证明」替换「真」**作为意义的核心。
这个替换被精确化为**布劳威尔—海廷—科尔莫戈罗夫解释（Brouwer–Heyting–Kolmogorov，简称BHK）**——
它逐条给出逻辑联结词的「构造意义」：

$$
\begin{aligned}
\text{证明 } A \wedge B &\text{：一个有序对，由 } A \text{ 的证明与 } B \text{ 的证明组成}\\
\text{证明 } A \vee B &\text{： } A \text{ 的一个证明，或 } B \text{ 的一个证明（并指明是哪一个）}\\
\text{证明 } A \to B &\text{：一个构造，把 } A \text{ 的任一证明变为 } B \text{ 的证明}\\
\text{证明 } \neg A &\text{：一个把 } A \text{ 的证明引向矛盾的构造}\\
\text{证明 } \forall x\,A(x) &\text{：一个构造，对每个 } x \text{ 都给出 } A(x) \text{ 的证明}\\
\text{证明 } \exists x\,A(x) &\text{：一个对象 } x \text{ 加上 } A(x) \text{ 的一个证明}
\end{aligned}
$$

三步拆解这条核心公式：

- **第一步，「析取的定义变了」**：古典语义学里，$A\vee B$ 的真值由 $A$、$B$ 的真值表决定——只要其中一个真，$A\vee B$ 就真。BHK 里，证明 $A\vee B$ 必须**明确指出**是 $A$ 还是 $B$。这正是排中律失灵的根源：你无法「指明」，就无权断言 $A\vee\neg A$。
- **第二步，「否定是构造出来的」**：$\neg A$ 不再是「$A$ 为假」这个静态事实，而是「任何 $A$ 的证明都会产生矛盾」这个动态构造。于是 $\neg\neg A \to A$（双重否定消去）不再是定理——「没被反驳」推不出「被构造」。
- **第三步，「证明即算法」**：$A \to B$ 的证明是「把一个证明变成另一个证明」的**程序**。这条对应关系后来被柯里（Curry）与霍华德（Howard）精确化为 **Curry–Howard 对应**：**证明 = 程序，命题 = 类型。**<span class="marginnote">Curry–Howard 不是数学哲学的花边，而是编程语言理论的基石：函数式编程语言的类型系统、证明助手 Lean/Coq 的形式化验证，都建立在「构造性证明可提取出可执行程序」这个事实上。这是直觉主义给计算科学最大的遗产。</span>

## 4 直觉主义数学：连续统与自由选择序列

直觉主义不是只管逻辑，它改写了分析学本身。最戏剧性的是**布劳威尔定理**：

> 在直觉主义数学中，定义在闭区间上的函数处处连续。

古典分析里的符号函数 $f(x)=\mathrm{sgn}(x)$（在 0处跳变）
在直觉主义里**不「存在」**——因为「构造一个定义在 $[0,1]$上的函数」
意味着你能对每个点给出值，而一个跳变点的存在要求你区分「$x<0$」
与「$x\ge 0$」这两个不可构造的条件。于是直觉主义连续统与康托尔的「点构成的连续统」
分道扬镳：
**连续统不是离散点组成的集合，而是自由选择序列的中介。**<span class="marginnote">直觉主义的连续统更像一条「正在生长的时间流」
：你不断选择下一个数位（自由选择序列），永远没有「完成」的时刻。这与康托尔把实数当作「完成的无穷集合」
形成根本对立——实无穷与潜无穷之争，在这里露出最锋利的獠牙。</span>

## 5 从直觉主义到构造主义与计算

布劳威尔的哲学过于个人化，但它的合理内核被系统化成了两大支流：

**直觉主义逻辑的形式化**：海廷（Arend Heyting）在 1930年给出直觉主义命题逻辑的演算；
克林尼（Stephen Kleene）
在1945年提出**可实现性（realizability）**，把 BHK里的「构造」
明确实现为**递归函数**——一个公式可实现，当且仅当存在一个程序「执行」它的证明。
直觉主义由此与可计算性理论接轨。
- **构造主义数学**：毕肖普（Errett Bishop）在 1967 年的《构造性分析基础》里，用构造性方法重写整个分析学，同时不放弃数学家的日常语言；**马丁-洛夫（Martin-Löf）** 的类型论则给出构造性数学的完整框架，成为证明助手的理论底座。

这条血脉的现代延伸异常醒目：**构造性证明 = 算法 = 可执行程序**。机器学习里「存在一个分类器使误差为零」
这种断言，构造主义者要求你真地给出来；程序验证要求你给出「每个输入都能终止并满足规约」
的构造性证明。直觉主义从1907 年一个荷兰人内心的原始直觉，走到了 21世纪形式化验证的工程前线。
<span class="marginnote">从极限到大模型的视角看：大模型生成的证明若不经过形式化验证，就仍是「可信度的分布」
而非「确定性的构造」；构造性数学要求的是后者。这条线索到最后一节《数学实践与数学哲学》
还会接上。</span>

## 6 小结

- **直觉主义**（布劳威尔）：数学是心灵中的构造，先于语言与逻辑而存在；原始直觉是时间中的「二合一」。
- **存在 = 可构造**：证明「存在」必须给出对象与证明；对无穷对象，**排中律**失去效力，**双重否定消去**不再是定理。
- **BHK 解释**：用「证明」定义逻辑联结词的意义；析取必须指明支路，否定是「引向矛盾」的构造。
- **Curry–Howard 对应**：证明即程序，构造性数学直接通向计算与类型论。
- 直觉主义分析：定义在闭区间上的函数**处处连续**，经典的不连续函数不「存在」；连续统是自由选择序列而非点集。
- 遗产：海廷逻辑、克林尼可实现性、毕肖普构造分析、马丁-洛夫类型论——直觉主义从哲学运动变成计算科学的方法论。

在下一节，我们把镜头拉回到柏拉图主义那个最深的伤口：就算数学对象存在，
**我们究竟如何知道它们？** 本纳塞拉夫把真理语义学与知识论摆在一起，逼出一个著名的两难——
这就是**数学真理与认识论**。
