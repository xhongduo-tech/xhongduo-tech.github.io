## 为什么从符号学开始

前几节争论的是「意义从哪来」——剪辑、作者、类型、权力。
符号学问的是更底层的问题：**意义到底是「什么形态的东西」？** 索绪尔把语言研究改造成一门关于符号的科学——**符号学（semiology / semiotics）**。
而电影——这个既像语言又完全不是语言的媒介——成了符号学最惊心动魄的试验场。

对「从极限到大模型」的读者，符号学可能是本专题最「对味」的一节：大模型的**token 就是符号**——可重复、可组合、携带语义的最小单元；
嵌入空间让「能指」拥有可计算的「所指」。
符号学的「能指／所指」「组合／聚合」「外延／内涵」这套词汇，今天正被嵌入与注意力机制以工程的方式重新发明。
<span class="marginnote">交叉连接：索绪尔把语言看作「能指—所指」的关联系统，这和第三级《深度学习》里「token 化 + 嵌入映射」的思路同构：都先把意义切割成离散单元，再定义单元之间的关联。</span>

## 1 索绪尔的符号：能指、所指与任意性

索绪尔对「符号（sign）」的定义构成全部符号学的地基：

$$\text{符号} = (\text{能指}, \text{所指})$$

- **能指（signifier）**：符号的**可感面**——读音、字形、画面、音符。
- **所指（signified）**：符号的**概念面**——能指所唤起的心理概念。

索绪尔的三个关键命题，每一个都为电影设下陷阱：

**第一，任意性（arbitrariness）**：能指与所指的联结没有内在理据——「狗」这个音与犬科动物没有必然关系，靠约定维持。
<span class="marginnote">注意索绪尔的「任意性」不是「随便」，而是「非动机性」：联结由社会契约而非自然相似确定。这为电影埋了颗炸弹——因为影像与对象之间恰恰有相似关系，影像符号是「动机的」，不是任意的。</span>

**第二，语言符号的双重分节（double articulation）**：话语先切分为有意义的语素（第一分节），再切分为无意义的音素（第二分节）。
这是语言的离散性——几千个音素就能生成无限话语。

**第三，组合（syntagm）与聚合（paradigm）**：语言沿两条轴工作——组合轴是「词按顺序拼成句子」，聚合轴是「一个位置可以替换的不同词」。
一个句子是「从聚合轴各选一词、沿组合轴排成串」的结果。

## 2 皮尔斯的符号三分：图像、指示、象征

与索绪尔的「二元符号」互补，美国的**查尔斯·皮尔斯**给出**三元符号论**——按能指与所指的关系，符号分三类：

| 类型 | 关系基础 | 电影中的例子 |
| --- | --- | --- |
| 图像符号（icon） | 相似性 | 画面与它再现的对象在外观上相似 |
| 指示符号（index） | 因果/邻近 | 烟是火的指示；**摄影影像是指示**——由被摄物的光线直接刻成 |
| 象征符号（symbol） | 约定 | 国旗、十字架、蒙太奇里的红（血/革命） |

皮尔斯三分法对电影理论极有用：**影像同时是图像（相似）与指示（光化学因果）**——这正是巴赞「摄影影像是现实本身」在符号学里的表达。
而**指示符号**的概念让符号学与现实主义在本体层面握手：影像的意义不完全靠约定，而靠「它确实是那个东西的痕迹」。

## 3 梅茨：电影是「没有语言系统的言语」

**克里斯蒂安·梅茨**是电影符号学的奠基人。
他在《电影语言》（1968）中做了电影理论史上最谨慎也最漂亮的一次判断：**电影是一门「没有语言系统的言语」（a language without a langue）**。

索绪尔区分 **langue（语言系统）**——一套抽象的语法与词汇规则——与 **parole（言语）**——具体的话语行为。
梅茨逐一检验电影是否拥有「语言系统」的构件：

**双重分节？没有。** 电影的最小单元（镜头）本身就是「有意义」的——电影无法拆出「无意义的音素」层。
- **任意性？没有。** 影像与对象由相似性绑定（图像符号），不是任意的。
- **离散性？没有。** 影像连续、稠密，不像音素那样可以严格离散化。
- **语法规则？没有。** 镜头拼接没有固定语法，同一组镜头可以有无数种合法连接。

结论：电影**有言语（话语行为），无语言系统（语法）**。
电影不是「语言」，而是**近似语言（language-like）的意指系统**。
因此梅茨拒绝用「电影语法」的说法，转而研究电影独有的**结构单元**——这就是他的**大组合段（grande syntagmatique）**。

## 4 核心要点：大组合段的八种单元

梅茨用组合轴（syntagm）的思路，把电影叙事切分为八种可辨识的单元类型——这是电影符号学最精密、也最常被引用的成果：

| 单元 | 结构特征 | 典型例子 |
| --- | --- | --- |
| 独立镜头（autonomous shot） | 单个镜头自成单元 | 插入的特写镜头 |
| 平行组合段（parallel syntagm） | 两组影像交替，无时间关系 | 「城市白天/乡村夜晚」交替 |
| 括号组合段（bracketing syntagm） | 一组影像以括入方式组织 | 一场宴会的多个瞬间 |
| 描述组合段（descriptive syntagm） | 同时空内的描述性并列 | 一间屋子的陈设镜头 |
| 交替组合段（alternating syntagm） | 两线事件严格同时交替 | 电话通话两端的镜头 |
| 场景（scene） | 连续时空的连续呈现 | 一场完整对话 |
| 段落（sequence） | 连续时空但被省略压缩 | 一段旅程的浓缩 |
| 插曲式段落（episodic sequence） | 时间跳跃的多段事件 | 一个人物的成长蒙太奇 |

这套分类的意义不在「背熟八种」，而在方法论：**它证明了电影拥有「单元 + 组合规则」的符号学结构**，即使这套结构不是索绪尔意义的语法。
<span class="marginnote">后来的学者（包括梅茨自己）批评大组合段是「分类学冲动」——单元之间边界模糊、类型可能遗漏。但它确立的范式仍在：今天的镜头分割（shot boundary detection）与视频语义单元标注，做的就是同一件事。</span>

## 5 公式解析：电影符号不是语言符号

把「电影不是语言」这个判断做成公式，是本节最干净的一步：

$$S_{\text{语言}} = (\text{任意性},\ \text{双重分节},\ \text{离散性}) \qquad S_{\text{电影}} = (\text{动机性},\ \text{无第二分节},\ \text{连续性})$$

- **第一步，读左边**：语言符号的三个「设计特征」——任意（能指所指无内在理据）、双重分节（音素+语素）、离散（单元边界清晰）。
- **第二步，读右边**：电影符号的三个对应特征——动机（影像因相似而意指）、无第二分节（最小单元已经有意义）、连续（画面不是离散单元串）。
- **第三步，结论**：两边没有一项相同，所以**电影不是语言**；但电影仍有单元、有组合、有规则，所以**电影是符号系统**。梅茨的全部工作，就是站在这条「像语言又不是语言」的边界上把它测绘清楚。

**辨析｜易错点：** 「电影语言」是一个**比喻**，不是描述。
说「电影有自己的语言」会误导人以为电影拥有语法规则；
梅茨的工作恰恰是证明这个比喻的限度——**电影更接近「一次性的言语」，每次观看都要重新「说」一遍**。
<span class="marginnote">类比到 NLP：语言模型把「语言」当作「可学习的分布」而不是「语法规则集」，这与梅茨的立场惊人地一致——意义不在规则里，而在「组合的统计模式」里。内涵层（connotation）同理：外延是直接意义，内涵是文化联想，今天的大模型用「相关性」模拟的正是内涵层。</span>

## 6 外延与内涵：巴特与第二符号系统

梅茨的大组合段处理的是电影的**外延层（denotation）**——「这段影像直接表示什么」。
但符号学最锋利的一刀，切在**内涵层（connotation）**。

**罗兰·巴特**在《图像的修辞》（1964）中用一幅意大利通心粉广告做示范：广告画面直接表示「一袋通心粉」（外延），但它同时通过颜色、构图、意大利三色旗的暗示，传达「意大利性」「新鲜感」「家庭温馨」——这些是**内涵**。
巴特的关键论断是：**内涵不是附加的意义，而是一套独立的「第二符号系统」**——第一系统（外延）的符号，整体降级为第二系统（内涵）的能指。
<span class="marginnote">巴特对内涵的政治判断是：内涵是意识形态最隐蔽的栖身之所——广告不直接说「买我的面」，而是让「意大利性」替你说话。外延看起来「自然」，内涵却早已是文化编码——把「自然」看作「自然」，恰恰是意识形态最成功的工作方式。</span>

把「外延/内涵」接回电影：**影像外延（画面直接显示）相对稳定，影像内涵（文化联想）高度可塑且充满政治**——红色在一部影片里是「旗」的外延，在另一部影片里是「血」的内涵；
剪辑让两个镜头并置产出的第三个概念（见《蒙太奇理论与形式主义》篇的 $A \oplus B = C$），本质上就是在**外延之上叠加内涵**。
<span class="marginnote">这为符号学与类型理论（《类型片理论》篇）架起桥梁：类型的影像惯例（iconography）就是「外延恒定、内涵可改写」的符号——荒漠既是荒野（外延），又是「自由与孤独」（内涵）。</span>

**辨析｜易错点：** 符号学常被误读为「解读任意符号的游戏」。
梅茨与巴特的方法论纪律恰恰相反：**先锁定外延（影像直接呈现什么），再谈内涵（它唤起什么）**——把两层混为一谈，符号学就成了猜谜。
这也是它与后面认知理论的分手点：符号学追问「意义如何被系统性地生产」，认知主义追问「意义如何被个别观众建构」——一个偏系统，一个偏过程。

## 7 小结

- 索绪尔：符号 = 能指 + 所指，联结是**任意的**；语言有**双重分节**与**组合/聚合**双轴。
- 皮尔斯：符号分**图像、指示、象征**；摄影影像是图像也是指示。
- 梅茨的核心判断：**电影是「没有语言系统的言语」**——有单元、有组合，无语法、无双重分节。
- **大组合段**的八种单元证明电影拥有可分析的符号结构。
- 电影符号是**动机的、连续的**，与语言符号的**任意、离散**在每一点上都不同。
