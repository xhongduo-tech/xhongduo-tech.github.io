# 工艺美术学

工艺美术学是研究以实用为基础、兼具审美价值的造物——陶瓷、漆器、织绣、金属工艺、家具等——之历史、技艺与美学意蕴的学科。以中国工艺美术史为主干，从原始造物到明清工艺的系统研习，能够理解传统造物中"材美工巧"的理念与中华民族的审美精神。
