# 世界遗产体系与 UNESCO 公约框架

<div class="epigraph">

## 为什么从世界遗产开始

上一节的《威尼斯宪章》把保护原则立到了「古迹」层面，这一节把它推到全球层面：**当一
份遗产被认为「属于全人类」时，谁来判定、用什么标准、走什么程序？**
《保护世界文化和自然遗产公约》（1972）和它名下的《世界遗产名录》就是这套机制。它
是文化遗产制度化的最高平台，也是本专题与联合国教科文组织（UNESCO）体系相接的枢
纽。 <span class="marginnote"> 本节对应
UNESCO《世界遗产公约》的条款与操作指南（Operational
Guidelines）中关于名录、标准与评估程序的部分；它是《物质文化遗产保护原则》
一节的直接延伸。 </span>
理解这套体系的关键词只有一个——**突出普遍价值（OUV）**——它像一把全球尺子，
量出哪些遗产值得被写入全人类的共同清单。

## 1 公约的诞生：阿布辛贝的启示

世界遗产制度诞生于一场抢救。1960
年代，埃及修建阿斯旺大坝，尼罗河沿岸的努比亚古文明遗迹——包括著名的**阿布辛贝神
庙（Abu
Simbel）**——面临被淹没的灭顶之灾。联合国教科文组织发起国际联合行动，把神庙
切割、搬迁到高地重建。这场「抢救阿布辛贝」的跨国工程成为全球合作的教科书，也让世界意
识到：**有些遗产太大、太重要，单个国家无力独守，必须由人类共同体来保护。**
<span class="marginnote">
阿布辛贝的搬迁费用与工程之大在当时史无前例——它证明了「国际合作 + 技术 +
国际舆论」能创造奇迹，也埋下了「遗产的全球责任」这一理念的种子。 </span>

1972 年，《保护世界文化和自然遗产公约》在巴黎通过（1975
年生效），正式建立起一套国际制度。它的机构骨架是三层：

**世界遗产委员会（World Heritage Committee）**：21
  个缔约国代表组成的政府间机构，负责审议与决策。
- **世界遗产中心（World Heritage Centre）**：UNESCO
  的常设秘书处。
- **三个咨询机构**：ICOMOS（文化遗产）、IUCN（自然遗产）、
  ICCROM（保护技术与培训）。

**重点：** 世界遗产制度是「国家申报 +
国际评估」的双层结构——国家主权申报，国际标准把关。没有国家的提名，遗产不会自己进入
名录；没有国际评估，国家也无法单方面把自己的遗产「封圣」。

## 2 突出普遍价值（OUV）：什么是「世界级」

进入名录的资格，叫作**突出普遍价值（Outstanding Universal
Value,
OUV）**——指「罕见的、超越了国家界限、对全人类的现在与未来都具有重大意义的」文
化与自然价值。OUV 的判定不是一句话，而是一个「四支柱」结构：
<span class="marginnote">
「四支柱」并非公约原文的结构词，而是对《操作指南》第 77–92
段的通俗概括——OUV 必须由「标准 + 完整性 + 真实性 +
保护与管理」共同支撑，缺一不可。 </span>

![世界遗产评估的四支柱与申报评审流程](/images/cultural-heritage-museology/world-heritage-unesco-system-1.svg)

**十项标准（10 criteria）**是 OUV
的第一根支柱，前六条属文化、后四条属自然：

| 序号 | 性质 | 价值类型 |
| --- | --- | --- |
| ⅰ–ⅲ | 文化 | 杰作；艺术与建筑的突出价值；文明的独特见证 |
| ⅳ | 文化 | 某种建筑类型、技术或景观的典范 |
| ⅴ–ⅵ | 文化 | 传统聚落/土地利用；与信仰、艺术、事件直接关联 |
| ⅶ–ⅷ | 自然 | 绝美的自然现象；地球演化与生命记录的突出见证 |
| ⅸ–ⅹ | 自然 | 生态系统与生物多样性的突出价值 |

十项标准之外还有三根支柱：**完整性（integrity）**——遗产的各要素是否齐
全、够不够「整」；**真实性（authenticity）**——对文化遗产，其材质、
工艺、设计、传统是否可信，直接承接《威尼斯宪章》与《奈良文件》的争论；**保护与管
理（protection &
management）**——申报国必须证明有长期的法律保护与管理制度。

**辨析｜易错点：** OUV
不是「国家重要」。一个国家觉得很重要的遗产，若只在民族历史里有意义、却谈不上「对全人
类突出」，就没有
OUV。相反，中国长城、埃及金字塔、法国凡尔赛宫之所以入列，是因为它们**超越国
界**地讲述了人类文明的共同故事。OUV 的判定单位是「全人类」，不是「申报国」。

## 3 评审流程：从预备名录到列入

一个遗产地要走完「预备名录 → 申报文件 → 国际评估 →
委员会决议」四步，才谈得上入列：

1. **预备名录（Tentative
   List）**：申报国先提交本国未来拟申报的清单，这是申报的合法前提。
2. **申报文件（Nomination File）**：正式申报材料，含 OUV
   论证、边界、管理规划与法律保护依据。
3. **咨询机构评估**：ICOMOS（文化）或
   IUCN（自然）派专家实地考察，提交技术评估。
4. **委员会决议**：21
   国委员会对评估作出裁决——**列入（inscribe）、退回（refer，需补
   充材料）、缓议（defer，需重大修改）、或不予列入**。
   <span class="marginnote">
   决议的精细程度远超「过/不过」：refer
   意味着「大方向没问题、材料不够」，defer
   意味着「论证或保护措施有硬伤」——每年都有热门遗产因完整性或管理短板被
   defer 的公开案例。 </span>

列入并非终点。世界遗产体系还设了「红绿灯」：遗产状况恶化时，可进入**《濒危世界遗产
名录》（List of World Heritage in
Danger）**，触发国际援助与监督；状况持续恶化且保护失效的极端情况，委员会甚至
可以把遗产**除名（delisting）**——例如阿拉伯野生动物的庇护地（阿拉伯大
羚羊保护区）曾因阿曼单方面削减保护面积而于 2007
年被除名。此外，委员会还设有**世界遗产基金（World Heritage
Fund）**，为欠发达国家提供技术援助。

**重点：**
世界遗产称号是「责任」而非「奖状」——入列意味着接受国际监测、定期提交「保护状况报
告」；挂上「世界遗产」招牌的旅游流量，反过来常常成为保护的最大压力源。这套「荣誉—责
任—压力」的三角关系，正是《遗产地管理与旅游》一节的入口。

## 4 小结

- 世界遗产制度源于 1960 年代**阿布辛贝抢救工程**，1972
  年公约将其制度化，1975 年生效。
- 制度骨架：**委员会（决策）+ 中心（秘书处）+
  ICOMOS/IUCN/ICCROM（咨询）**。
- 入列资格是**突出普遍价值（OUV）**，由「10 项标准 + 完整性 +
  真实性 + 保护与管理」四支柱共同支撑。
- 评审流程：预备名录 → 申报文件 → 国际评估 → 委员会决议（列入 / 退回
  / 缓议 / 不予）。
- 列入后的监测同样重要：**濒危名录**与国际援助应对恶化，极端情况下可**除
  名**。

在下一节，我们将回到新博物馆学埋下的伏笔：社区参与与遗产伦理——当遗产的「意义」属于
社区而非专家，保护与决策的权力该如何交接。
