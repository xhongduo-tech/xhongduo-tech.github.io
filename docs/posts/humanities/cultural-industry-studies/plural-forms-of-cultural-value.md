# 文化价值：审美、社会与经济价值的多元形态

## 为什么从「价值多元」开始

上一节我们建立了文化经济学的两条分析路径：市场路径用价格测度，非市场路径用支付意愿测度。但这两条路径都默认一件事——价值可以被测量。这一章，Throsby 把这个问题拆开：**「文化的价值」到底由哪些成分构成？它能不能被压缩成一个数字？**

答案是否定的。这也是整个文化产业学最需要反复强调的一课：文化产业创造的不只是钱，它同时创造审美体验、社会认同与历史记忆。而这三者恰好是市场最容易看不见、也最容易被破坏的东西。

我们先把这一章放进整条知识链：上一节讲的是「怎么测」，这一节讲的是「测什么」，下一节（文化资本与可持续发展）则回答「怎么把不可测的那部分纳入长期决策」。三层递进，构成 Throsby 一系的核心方法论。

## 1 经济价值：可通约的部分

**经济价值（economic value）**：文化商品与服务在市场中能以货币度量的那部分价值。票房、门票、订阅费、版权费、衍生品收入，全部落在这一轴上。

经济价值的特征是**好用**：它可加总、可比较、可进入成本收益分析。一张电影票 50 元、一场演出票 300 元，加总就是一晚上的娱乐支出。经济价值的测量还延伸到非市场领域——用条件价值评估问人们「愿意为保留某座老宅付多少钱」，得到的仍是经济价值，只是测法不同。

但经济价值的边界同样清晰：它只记录「有人愿意为之付钱」的那部分。一部改变公共议题的纪录片，其社会影响没有直接市场定价；一座博物馆培育的青少年好奇心，也不会出现在任何账本上。**经济价值是文化价值的一个真子集，而不是它的等价物。**

## 2 文化价值：不可压缩的多维结构

**文化价值（cultural value）**：文化对象因审美、精神、社会、历史与象征等属性而承载的非货币价值。Throsby 主张，文化价值不是一个单一量，而是由多个成分构成的**多维结构（multidimensional structure）**。<span class="marginnote">Throsby 强调「多维」是在反对把文化价值硬塞进单一标尺：审美分与历史分无法按同一比例换算，就像质量与温度无法互相折算。承认多维，是方法论上的诚实。</span>

Throsby 列出的成分至少包括六项：

- **审美价值（aesthetic value）**：形式、色彩、构图、声音带来的美与愉悦。
- **精神价值（spiritual value）**：宗教、道德与内在感悟层面的价值。
- **社会价值（social value）**：联结他人、形成认同感与归属感的价值。
- **历史价值（historical value）**：承载过去、连接传统的价值。
- **象征价值（symbolic value）**：作为意义载体、指涉他物的价值。
- **真实性价值（authenticity value）**：作品是真实、原创、唯一而非复制品的价值。

这六项并不互相独立：一幅名画可能同时具有审美、历史与象征价值；一座古城的价值则高度依赖其真实性与完整性。**文化对象的独特性，恰恰在于这些成分以独特的比例组合在一起。**

## 3 公式解析：总经济价值的加总框架

要把「价值」讲清楚，Throsby 借助环境经济学一个成熟框架——**总经济价值（total economic value, TEV）**：

$$
\mathrm{TEV} = \mathrm{UV} + \mathrm{NUV}
$$

其中使用价值（use value, UV）是实际使用带来的价值，非使用价值（non-use value, NUV）又可以拆成三项：

$$
\mathrm{NUV} = \mathrm{OV} + \mathrm{EV} + \mathrm{BV}
$$

拆成三步理解：

- **第一步，读符号**：$\mathrm{UV}$ 是使用价值，$\mathrm{OV}$ 是**期权价值**（保留将来使用的可能，如「我虽没去过敦煌，但希望它一直存在」），$\mathrm{EV}$ 是**存在价值**（单纯因某文化存在而获得的满足），$\mathrm{BV}$ 是**遗赠价值**（希望留给后代的愿望）。
- **第二步，读直觉**：这套框架的贡献，在于把「没用过也有价值」从抽象情感变成可测量的条目。对一座尚未开发的考古遗址，使用价值也许为零，但存在价值与遗赠价值可能极高。
- **第三步，读边界**：TEV 仍然只是「经济价值」的展开。它测量的是以货币表达的意愿，审美与精神的非货币维度仍在框架之外——这正是下一节要处理的张力。

**辨析｜易错点：** 不要把 TEV 误当成「文化价值的全部」。<span class="marginnote">TEV 只是把经济价值的内部结构讲清楚：使用价值、期权价值、存在价值、遗赠价值分门别类。它回答「经济价值有多宽」，不回答「文化价值有多高」。两者是不同维度的问题。</span>

## 4 不可通约性之争

既然文化价值多维、经济价值单维，二者能不能换算？Throsby 的立场是**部分可通约（partial commensurability）**：经济决策必须给文化价值一个权重，但这个权重不必然等于市场价。

支持完全可通约的观点来自成本—收益分析传统：既然要做决策，就得把所有影响折算成钱。反对的声音来自文化研究：把审美折算成价格，等于承认「值多少钱」是衡量艺术的唯一尺度——这正是艺术最不能容忍的简化。<span class="marginnote">这让人想起经济学家对生命定价的争论：交通安全的成本收益分析确实会给一条人命定价，但没有人会因此认为「人命就是那个价格」。定价是决策工具，不是价值主张。</span>

Throsby 的中间路线是：**承认不可完全通约，但不放弃纳入决策**。办法是文化影响评估（cultural impact assessment）——像环境影响评估那样，在项目决策中单独列出文化价值条目，让它与经济条目并列展示，由决策者综合判断，而不是强行换算成一个数字。

## 5 核心对比：经济价值与文化价值

| 维度 | 经济价值 | 文化价值 |
| --- | --- | --- |
| 度量单位 | 货币 | 多维成分，无统一单位 |
| 可加总性 | 可加总、可比较 | 不可简单加总 |
| 来源 | 市场交易与支付意愿 | 审美、精神、社会、历史、象征 |
| 测量工具 | 价格、WTP、TEV | 文化指标、专家评估、影响评估 |
| 进入决策方式 | 成本收益分析 | 文化影响评估、并列展示 |
| 主要风险 | 压扁文化、只看价格 | 难以量化、被决策忽略 |

这张表不是要分出高下，而是要说明：**文化产业学的整个论证，都建立在这两类价值并存的判断之上。** 只承认经济价值，会得出「不好卖的文化就该消失」的结论；只承认文化价值，又会滑向「文化不可定价、不可分析」的神秘主义。Throsby 坚持两者并存、相互对话。

## 6 让双重价值进入真实决策

把抽象的价值理论落到实践，文化经济学给出三个可操作的方向：

- **文化指标（cultural indicators）**：为不可货币化的价值建立可追踪的代理指标，如参观人次、参与率、艺术家就业数、遗产完好率。指标不是价格，但让文化价值变得可观察。
- **文化影响评估**：在公共项目（拆老城、建剧场、规划开发区）中，把文化价值列入与经济效益并列的评估表，防止「只算经济账」。
- **文化核算（cultural accounting）**：把文化资产纳入核算体系，关注存量的维护而不只是流量的产出——这是下一节文化资本理论的直接入口。

一个真实案例：伦敦南岸艺术区（Southbank Centre）的扩建评估中，既算票房与就业，也算公众参与与历史建筑完好度——后者正是文化价值的制度化表达。**价值理论的最终检验，是它能否改变真实决策的账本结构。**

**术语速查：**

| 术语 | 释义 |
| --- | --- |
| 经济价值 | 可用货币度量的价值（票房、版税、支付意愿） |
| 文化价值 | 审美、精神、社会、历史、象征等非货币价值的总和 |
| 使用价值 | 实际使用文化对象带来的价值 |
| 期权价值 | 保留未来使用可能性的价值 |
| 存在价值 | 单纯因某文化存在而获得的满足 |
| 遗赠价值 | 希望将文化留给后代的愿望 |
| 部分可通约 | 承认两类价值可部分换算、但不等于价格 |
| 文化影响评估 | 把文化价值列入决策评估的制度化工具 |

把经济价值与文化价值同时放进决策，靠的不是「找公式」，而是建立**两套并行的评估条目**：一套货币、一套文化指标，决策时并列展示。这正是 Throsby 一系给文化产业学留下的方法论遗产——价值不是被度量出来的，而是被**并置**出来的。

## 7 小结

- 判断文化对象，先分清它是**经济价值**还是**文化价值**，再谈度量。
- 应用层的落脚点是**文化指标、文化影响评估、文化核算**三件工具。
- 记得回到那句话：经济价值是文化价值的**真子集**，而不是它的等价物。

- 经济价值是**可货币化、可加总**的价值；文化价值是**多维、不可压缩**的价值。
- Throsby 把文化价值拆为审美、精神、社会、历史、象征、真实性等成分。
- 总经济价值框架 $\mathrm{TEV} = \mathrm{UV} + \mathrm{OV} + \mathrm{EV} + \mathrm{BV}$ 厘清了经济价值的内部结构。
- 两类价值**部分可通约**：不强行换算，也不放弃纳入决策。
- 落地工具包括**文化指标、文化影响评估、文化核算**。
- 文化产业学的论证根基：文化同时创造货币价值与非货币价值，缺一不可。

在下一节，我们将把「价值」从流量提升到存量——文化的价值会像资本一样积累、折旧与维护，这就是 Throsby 第5章的《文化资本理论与文化可持续发展》。
