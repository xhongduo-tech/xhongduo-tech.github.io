# 句法（短语结构）

<div class="epigraph">
<p>句法是语言组装的核心规则：词不是随意排列的，而是按短语结构一层层组装成句子的。</p>

## 为什么从句法开始

词汇是「积木」，句法是「图纸」。**句法（syntax）** 研究词如何按规则组合成短语、短语如何组成句子。句法最核心的构件是**短语结构（phrase structure）**——它揭示「我读完了这本书」不是五个词平铺，而是一层层「大盒子套小盒子」。<span class="marginnote">短语结构树（constituency tree）是计算机理解句子的第一步：上下文无关文法（CFG）就是为描述短语结构而发明的形式系统，也是编译器解析程序语言的数学工具。乔姆斯基的「短语结构语法」直接催生了编译原理的语法分析（parsing）——这是语言学到计算机科学最直接的血脉。见第三级《编译原理》。</span>这一篇讲短语的种类、结构与组合原则。

## 1 什么是短语结构

**短语（phrase）**：由词按句法规则组合成的、能充当句法成分的单位。短语内部不是平铺的，而是**有中心、有层次**的。

句法分析把句子表示为**树**，例如「那位老师教语文」：

```
         句子(主谓)
       /          \
  名词短语        动词短语
  /    |   \      /    \
那    位   老师   教    语文
```

- 「那位老师」是一个**名词短语（NP）**，内部由「那」+「位」+「老师」组成。
- 「教语文」是一个**动词短语（VP）**。
- 句子 = 主语 NP + 谓语 VP，构成**主谓结构**。

**短语结构 = 一棵树：叶子是词，树枝是结构层次，节点是短语类型。**<span class="marginnote">这棵树就是计算机 parser 的输出。训练一个句法分析器，就是让模型学会「对一句话画出正确的树」。神经网络的「自注意力」之所以能捕捉句法，部分是因为树的层级信息体现在词与词的远程依存上——`那位` 修饰 `老师`，中间隔着任何词都能被注意力捕获。</span>

## 2 短语的类型

短语按**中心词（head）** 的类别命名，中心词决定短语的语法功能：

| 短语类型 | 中心词 | 结构 | 例子 |
| --- | --- | --- | --- |
| 名词短语（NP） | 名词 | 定语+名词 | `美丽的校园` |
| 动词短语（VP） | 动词 | 状语+动词+宾语 | `认真地读书` |
| 形容词短语（AP） | 形容词 | 状语+形容词 | `非常漂亮` |
| 副词短语（AdvP） | 副词 | 状语+副词 | `非常迅速` |
| 介词短语（PP） | 介词 | 介词+名词 | `在教室里` |
| 数量短语 | 数词+量词 | 数+量 | `三个` |

**中心词原则**：短语的整体功能由它的中心词决定——`美丽的校园` 整体是名词性（因为中心词是 `校园`）。这个「中心词决定功能」的原则，是依存句法（dependency grammar）的基础。

## 3 短语结构的组合方式

短语内部的词按**句法关系**结合，主要类型：

- **主谓**：`老师教`——主语+谓语。
- **动宾**：`教语文`——动词+宾语。
- **偏正（定中）**：`美丽的校园`——定语+中心语；**偏正（状中）**：`认真地读`——状语+中心语。
- **补充（中补）**：`读完`、`跑得快`——中心语+补语。
- **联合**：`老师和同学`——并列关系。
- **介宾**：`在教室`——介词+宾语。

**辨析｜易错点：** 汉语「动宾」与「动补」常被混淆：`吃完饭` 是动宾（`饭` 是宾语），`吃饱了` 是动补（`饱` 是补语，补充说明 `吃` 的结果）。判别方法：宾语是动作「涉及的对象」（吃完**什么**），补语是动作的「结果/程度」（吃得**怎样**）。这一区分在层次分析里至关重要。

## 4 短语结构语法：形式化

短语结构可以写成**改写规则（rewrite rules）**，即形式语法：

$$S \to NP \; VP, \qquad VP \to V \; NP, \qquad NP \to \text{Det} \; N$$

- 每条规则表示「左边可以改写成右边」。
- 从 `S`（句子）出发反复改写，最终得到一串词，就是句子的**推导（derivation）**。
- 这样的规则系统叫**短语结构语法（phrase structure grammar）**，对应计算机科学里的**上下文无关文法（CFG）**。<span class="marginnote">这正是「从极限到大模型」里语言学和计算机交汇的枢纽：CFG 的语法分析算法（如 CYK 算法、LR 分析）既是编译器解析程序语言的核心，也是早期句法解析器的数学基础。语言学提出的「短语结构」，成了计算机科学的「形式语言」——见第三级《编译原理》与《形式语言与自动机》。</span>

## 5 汉语短语结构的特色

汉语短语结构有两个显著特点：

- **语序固定但词类灵活**：`名词短语` 的位置可以由多种成分充当——`美丽的校园`（形+名）、`校园的书`（名+名）、`刚到的老师`（动+名）。汉语靠「语序+虚词」而非形态来标记结构。
- **同形歧义**：同一串词可有不同的短语结构。`咬死了猎人的狗` 可分析为「咬死了 / 猎人的狗」（狗被咬）或「咬死了猎人的 / 狗」（狗咬人）——这就是著名的**结构歧义**。<span class="marginnote">结构歧义是句法分析的核心难题：一句话对应多棵树，parser 要选出正确的一棵。中文歧义尤其多，因为无形态、语序信息密度高。语言模型靠上下文语义化解歧义，但「结构性歧义」即使对人也要靠停顿/语境分辨——这既是笑话素材（「叔叔亲了我妈妈也亲了我」），也是 parser 评测的难点。</span>

## 7 中心语与依存语法：另一种句法视角

短语结构树把句子「装箱」，但还有另一种经典句法观——**依存语法（dependency grammar）**：

**核心思想**：句子不是「层层嵌套的盒子」，而是「一个中心词（head）带动所有其他词（依存者，dependents）」的**放射结构**。每个词都依存于另一个词（唯一的根除外），依存关系有类型（主谓、动宾、定中、状中……）。

以「他认真地读书」为例，两种表示对比：

- **短语结构**：`[他] [认真地 [读 书]]`——按层次装箱。
- **依存结构**：`读` 是根，`他` 依存于 `读`（主语）、`书` 依存于 `读`（宾语）、`认真` 依存于 `读`（状语）——按功能放射。

**两种句法观的关系**：每个短语结构树都对应一棵依存树——**短语结构的中心词（head）原则**（`美丽的校园` 的中心是 `校园`）正是依存树的根的选择依据。短语结构强调「层级」，依存语法强调「功能关系」。

**核心对比表：短语结构与依存语法**

| 维度 | 短语结构 | 依存语法 |
| --- | --- | --- |
| 基本单位 | 短语（组块） | 词与词的关系 |
| 结构 | 嵌套树 | 放射树 |
| 强调 | 层级归属 | 功能依赖 |
| 形式化 | 上下文无关文法 | 依存文法 |

<span class="marginnote">依存语法对计算语言学特别友好：依存树不用「发明」短语节点，直接从词建关系——这使依存标注比短语结构标注便宜、跨语言更通用。现代神经 parser 常以依存树为主要输出（Universal Dependencies 项目覆盖上百种语言），是《计算语言学》里句法分析的主流形式。</span>

## 9 一个实操：画出短语结构树

把「短语结构」知识用在「画树」上——这是句法分析的基本功。以「那只小鸟唱着歌」为例：

**第一步：切分最大的两个成分**。`那只小鸟`（主语，名词短语）+ `唱着歌`（谓语，动词短语）——构成主谓结构。

**第二步：切分主语内部**。`那只`（定语，指量短语）+ `小鸟`（中心语，名词）——偏正结构。

**第三步：切分谓语内部**。`唱着`（动词）+ `歌`（宾语，名词）——动宾结构。

**第四步：画出完整的树**：

```
                句子（主谓）
              /              \
          名词短语            动词短语
         /    |   \          /     \
      那    只    小鸟     唱着     歌
     (定语)(定语) (中心语) (动词)  (宾语)
```

**第五步：标注短语类型与成分**。

| 节点 | 短语类型 | 句法成分 |
| --- | --- | --- |
| 那只小鸟 | 名词短语 | 主语 |
| 那只 | 指量短语 | 定语 |
| 唱着歌 | 动词短语 | 谓语 |
| 歌 | 名词 | 宾语 |

**画树的三个口诀**：

1. **层层二分**：每次只切两个直接成分。
2. **中心语定类型**：短语类型由中心词决定。
3. **叶子是词**：切到词为止。

**画树的价值**：它把「句子」从「一串词」变成「一张结构图」——歧义在树上一目了然（见《句法成分与层次分析》），层次在树上一目了然。**画一棵树，胜过读十段语法说明**——这也是句法分析（parsing）训练入门最有效的练习。

**一个自查**：给「我昨天买了两本书」画树，特别注意时间状语「昨天」挂在哪个层级——你会体会到「状语的位置」如何影响结构。

## 10 小结

- **短语结构**把句子表示为有层次、有中心的**树**：叶子是词，节点是短语。
- 短语按**中心词**分类：NP、VP、AP、AdvP、PP、数量短语。
- 短语内部组合关系有**主谓、动宾、偏正、补充、联合、介宾**等。
- 短语结构可用**改写规则（CFG）** 形式化，是编译原理语法分析的数学基础。
- 汉语短语结构**语序固定、词类灵活**，存在结构歧义这一核心难题。
