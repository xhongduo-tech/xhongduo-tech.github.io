# 词汇系统

<div class="epigraph">
<p>词汇不是词的简单总和，而是一个有层次的系统：基本词汇是核心，一般词汇是外围，二者不断交换。</p>

## 为什么从词汇系统开始

一门语言有几十万个词，但它们不是平铺的一堆——词汇内部有**核心与外围**、有**来源分层**、有**新旧交替**。理解词汇系统，就是理解「一个词在语言中的位置」，也才能回答「为什么有些词几千年不变，有些词三年就死」——这个问题对语言建模的「词频分布」与「知识时效」同样关键。<span class="marginnote">Zipf 定律告诉我们：语言中极少数词占了大多数出现次数——「的」「了」「是」几个词就占中文语料近 1/3。这个「核心-长尾」的幂律分布，正是「基本词汇 vs 一般词汇」的统计镜像，也是词表设计与子词切分的出发点。见第二级《概率论与数理统计》与《信息论》。</span>这一篇解剖词汇系统的内部结构。

## 1 基本词汇与一般词汇

**基本词汇（basic vocabulary）**：词汇中最核心、最稳定、使用频率最高的部分，是语言的「骨架」。

基本词汇的三个特征：

- **稳固性**：历经千年基本不变（「人」「山」「水」「大」「小」沿用至今）。
- **能产性**：作为构词部件不断造新词（「人」→ 人民、人类、人才、工人）。
- **全民常用性**：不分阶层、地域、时代，人人常用。

**一般词汇（general vocabulary）**：基本词汇之外的全部词汇，数量庞大、更新快，包括新词、古词、方言词、外来词、行业语、隐语等。<span class="marginnote">基本词汇与一般词汇的界线是「活的」：古汉语的「目」在一般词汇中（成语「一目了然」），而「眼」在基本词汇中；但「目」作为「数据库目录、日程」的词根又在重新活跃——核心与外围不断交换，这就是「词汇系统的动态性」。</span>

## 2 词汇的来源分层

按「出身」分，词汇可分层为：

| 层次 | 说明 | 例子 |
| --- | --- | --- |
| 固有词 | 本族语原有词 | 人、山、水、吃 |
| 古语词 | 来自古代、现多用于书面/成语 | 若干、凯旋、诞辰 |
| 新词 | 近现代新造 | 互联网、芯片、打卡 |
| 方言词 | 进入共同语的方言来源 | 垃圾（吴语）、尴尬（吴语）、搞定 |
| 外来词 | 借自外语 | 咖啡、沙发、逻辑、GDP |

**外来词**尤其值得注意，按吸收方式分：音译（`咖啡`、`沙发`）、意译（`电话`、`电脑`）、音意兼译（`可口可乐`）、借形（`WTO`、`GDP`）、半音半意（`啤酒`、`卡片`）。<span class="marginnote">外来词是语言接触的活化石：汉语从佛教借入「世界、因果、圆满」，从日语借入「社会、经济、电话」（日语用汉字翻译西学），从英语借入「幽默、逻辑」。这些词的年代层叠，像地层一样记录了中外交流史。</span>

## 3 词汇的语体分层：口语与书面语

词汇还按使用场合分**口语词**与**书面语词**：

- **口语词**：日常会话，如「爸爸、唠嗑、特（很）」。
- **书面语词**：正式文牍，如「父亲、交谈、非常」。

口语与书面语的差异在「同义双轨」中清晰可见：「死亡」有口语的「没了、走了」、中性的「去世」、书面的「逝世、殉职、圆寂」。这种**语体风格分层**让语言能应对从闲聊到法律的各类交际场景，也是文本分类与「正式度」建模（formality detection）的语言学基础。

## 4 词汇的义类系统：词汇场

词汇不仅在「层级」上有结构，在「意义」上也有组织——**同义词群、反义词对、上下义词树**把词编织成网。例如「走」的词场包含：`跑、溜达、漫步、散步、踱步、疾走、飞奔`——这些词按「速度、方式、语境」在同一个语义区域里各占一席。<span class="marginnote">把词汇看成「按意义编织的网」而不是「按字母排的清单」，是现代词汇语义学的核心转向。这个观念直接启发了 WordNet——一个按同义集合（synset）与上下位关系组织的英语词网，也是早期 NLP 的核心资源。见《语义场》《语义关系》两篇。</span>

## 5 词汇系统与「从极限到大模型」

词汇系统的结构在统计语言模型中有清晰的对应：

- **基本词汇 ≈ 高频核心 token**：Transformer 注意力中，高频虚词（的、了）承担「句法粘合」功能，低频实词承担「语义载荷」——这正是「基本词汇稳固、一般词汇表义」的分布版。
- **词汇分层 ≈ 语料库构成**：大模型的训练语料按「通用文本 + 专业文本 + 口语转录」分层配比，实际上是在模仿「基本词汇 + 一般词汇」的覆盖。<span class="marginnote">大模型的「知识时效」问题（新词、新闻事件）源于一般词汇更新快而模型训练滞后；「幻觉」部分源于低频词在长尾中缺乏足够约束。理解词汇系统，就能理解为什么模型需要「持续更新词汇」与「检索增强」——词汇的诞生没有停，模型就必须跟上。</span>

## 7 词汇与文化：词汇是社会的一面镜子

词汇系统不只是语言内部的结构，更是**文化的活档案**——每个社会的关注点都会在词汇量上留下印记：

- **亲属词与家庭结构**：汉语区分 `伯父/叔父/舅父/姑父/姨父`，对应宗法社会的亲属网络；英语一个 `uncle`，反映核心家庭为主的社会结构。
- **雪词与生活经验**：关于爱斯基摩语「雪词数量」的传闻虽有夸大，但生活在冰雪环境的人群确实有更细的雪词汇（`新雪`、`陈雪`、`湿雪`），正如海南渔民有更细的鱼词汇。
- **农耕词汇**：汉语丰富的一字农具/作物词（`犁、耙、镰、锄`）记录农业文明的深耕；游牧民族则有丰富的牲畜词汇。
- **避讳词**：`死` 的众多委婉说（`逝世、驾崩、圆寂、走了`）反映对死亡的文化态度。

**词汇与文化的关系是双向的**：文化塑造词汇（哪些概念需要精确区分，就造哪些词），词汇也反过来固化文化观念（词汇的存在让某些区分「可说、易说」）。这就是「词汇反映文化」与「词汇建构文化」的辩证。

<span class="marginnote">「词汇即文化」对跨语言 NLP 的启示：没有对应词的概念（`缘分`、`面子`）在翻译中需要「绕路表达」；而大模型学到的「词义」也带着训练语料文化的烙印——多语言模型是否「偏心」于某些文化的词汇语义，是公平性研究的重要课题，见第九级《计算社会科学》。</span>

## 9 词汇系统的统计面貌：Zipf 定律

词汇系统不只是「质的结构」，还有精确的**量的规律**——**Zipf 定律（齐普夫定律）** 是词汇系统最著名的统计法则：

**Zipf 定律**：把语料中的词按频率降序排列，第 r 名的频率大致与 r 成反比：

$$P(r) \approx \frac{C}{r}$$

即**第二高频词的频率约为最高频词的一半，第三约为三分之一**……这是语言系统惊人的统计规律。

**核心对比表：汉语高频词的实际分布**

| 词 | 排名 | 在语料中的占比 |
| --- | --- | --- |
| 的 | 1 | 约 4% |
| 了 | 2 | 约 2% |
| 是 | 3 | 约 1.6% |
| 我 | 4 | 约 1.3% |

**Zipf 定律揭示了词汇系统的两重性**：

- **核心极小而稳固**：几十个高频虚词占语料的相当比例，构成语法骨架——对应「基本词汇」的统计核心。
- **长尾极长而更新快**：绝大多数词是「只出现几次」的低频词——对应「一般词汇」的长尾，新词、专名都在这里。

**Zipf 定律对语言建模的意义**：

- **子词 token 化**：BPE 把高频词/语素作为 token、把低频词拆开，正是顺着 Zipf 长尾「降维」——避免词表无限膨胀。
- **学习的梯度**：模型先学会高频词（`的`、`了`），再慢慢覆盖长尾——低频词是「知识边界的阴影区」，也是幻觉多发区。
- **评测的偏差**：若评测集偏向高频词，模型成绩虚高——好的评测要按 Zipf 分布抽样，兼顾长尾。

**Zipf 定律的美**：它把「词汇系统的结构」变成「一个公式」——语言学家发现的「基本/一般词汇」之分，在统计上精确地表现为「幂律核心 + 幂律长尾」。**语言的结构与语言的统计，在此统一**。

## 10 小结

- 词汇分为**基本词汇**（稳固、能产、全民常用）与**一般词汇**（量大、更新快、来源杂）。
- 词汇按来源分**固有、古语、新词、方言、外来**等层次，外来词有音译、意译等多种吸收方式。
- 词汇按语体分**口语与书面语**，形成同义双轨。
- 词汇按意义编织成**词汇场**，同义、反义、上下义构成词义网络。
- 词汇系统的「核心-长尾」结构与统计语言模型的词频分布、知识时效问题一一对应。
