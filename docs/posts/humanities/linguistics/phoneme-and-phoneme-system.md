# 音位与音位系统

<div class="epigraph">
<p>音位不是某种个别的音，而是一个语言的音系中能够区别意义的最小对立单位。</p>
<footer>—— 尼古拉 · 特鲁别茨柯伊（Nikolai Trubetzkoy, 《音位学原理》, 1939）</footer>

## 为什么从音位与音位系统开始

同一个「苹果」的「p」，有人发得气声重些、有人轻些，可谁都认为它们「是同一个 p」。但把「p」换成「b」，「苹果」变「苹bo」——意义变了。语言就这样把无穷多的物理声音，压缩成**少数几个能区别意义的单位**。这个单位就是**音位（phoneme）**。<span class="marginnote">音位思想是现代语音工程的基石：ASR 不需要识别「无限的声音」，只需判别「有限的意义单位」。语音识别「音素分类」任务的抽象层级正是音位——把连续声波离散成有限类别，是大模型之前语音系统能工作的关键一步。见第四级《语音技术》。</span>这一篇讲音位是什么、音位系统如何组织、以及汉语普通话的音位表长什么样。

## 1 音素到音位：从「物理音」到「功能音」

回顾上一篇：**音素（phone）** 是语音学概念，指切分到头的物理音段；**音位（phoneme）** 是音系学概念，指**在某一语言中能区别意义的最小语音单位**。

一句话区分：**音素是「发出的音」，音位是「语言认为不同的音」。**

- 普通话里 `pʰ`（送气 p，如「怕」pà）与 `p`（不送气 p，如「爸」bà 的声母，实际记作 `b`）**能区别意义**，所以是**两个音位**：`/pʰ/` 与 `/p/`。
- 英语里 `pʰ`（pin 送气）与 `p`（spin 不送气）**不能区别意义**，只是同一个音位的两个变体，记作一个音位 `/p/`。

**同一个物理差异，在一种语言里是「两个音位」，在另一种语言里只是「一个音位的变体」。** 音位是**语言特有**的范畴。

## 2 对立与互补：确立音位的方法

特鲁别茨柯伊给出判断「两个声音是否同一个音位」的两把尺子：

- **对立（contrast / opposition）**：两个音出现在**相同环境**中且能区别意义，则它们是**不同音位**。检验工具是最小对立对（minimal pair）：`bà`（爸）与 `pà`（怕）只差声母清浊/送气，意义不同 → `/p/` 与 `/pʰ/` 对立，是两个音位。
- **互补分布（complementary distribution）**：两个音出现的环境**互斥**，永不互换，则它们多半是**同一音位**的不同变体。英语 `pʰ` 只出现在音节首重读（`pin`），`p` 只出现在 `s` 后（`spin`），二者环境互补 → 同一个 `/p/`。

**辨析｜易错点：** 互补分布是「同一音位的必要条件，不是充分条件」——两个环境互补的音也可能分属不同音位。真正的判定还要结合「音感相似」与「能否构成对立」。例如普通话 `[ɿ]`（zi 的韵母）与 `[i]`（yi 的韵母）环境互补且都出现于 `z/c/s` 等后，它们被归为同一个音位 `/i/` 的变体还是不同音位，存在分析约定——这正是音位分析「可协商性」的体现。

## 3 音位系统：语言如何组织自己的音位

一门语言的**音位系统（phoneme system / inventory）** 是它全部音位构成的对立网络。音位不是散沙，而是有组织的矩阵：

- **对称性**：有 `p` 的地方常有 `b`，有 `pʰ` 的地方常有 `bʰ`（如果语言有浊音）——音位系统倾向于按「发音部位 × 发音方法 × 清浊/送气」铺成整齐的表格。
- **经济性**：用尽量少的音位、尽量规则的对立，覆盖尽量多的音。

普通话的音位系统（简化归纳）可排成这样的格局：

| 类别 | 音位 |
| --- | --- |
| 声母（22 个） | `b p m f d t n l g k h j q x zh ch sh r z c s` |
| 单元音韵母 | `a o e i u ü` |
| 复元音韵母 | `ai ei ao ou ia ie ua uo üe` 等 |
| 鼻韵尾 | `an en in un ün ang eng ing ong` |
| 声调音位 | 阴平、阳平、上声、去声（4 个） |

<span class="marginnote">注意声调在汉语里也是<strong>音位</strong>：`mā`（妈）与 `mǎ`（马）只是声调不同，意义就不同，所以普通话有 4 个「声调音位」。这让汉语的音位系统在「音段（辅音+元音）」之外多了一个「超音段（声调）」维度——自动语音识别中文时必须同时建模音段与声调。</span>

## 4 音位与「信息的最小差异」

音位的本质是**信息编码的最小对立单位**。可以用信息论的眼光看：一门语言选择哪些对立，就是在决定「用最少的语音差异携带最多的意义区别」。

- 普通话用「送气/不送气」对立（`b/p`、`d/t`、`g/k`），用 6 个清塞音/塞擦音对覆盖 12 个区别。
- 英语用「清/浊」对立（`p/b`、`t/d`、`k/g`），同样 6 个符号。
- 两种语言用**不同的声学线索**做同一件事：区分意义的最小单位。<span class="marginnote">从信息论看，音位系统是一个「源编码」：把连续的语音空间量化成离散符号，再把符号组合成词。这与第二级《信息论》中「离散化携带信息」的思想完全一致——语言的音位表就是人类为语音信道设计的量化器。</span>

## 5 音位系统与语音模型：离散化的两种路线

音位思想深刻影响了语音建模：

- **传统路线**：显式定义音位（或声韵母）单元，ASR 先做音位分类再做词解码——音位表就是分类的标签集。
- **端到端路线**：模型直接学习「声学特征 → 文本」的映射，音位不再显式出现，但模型内部的隐藏单元往往自发学会类似音位的区分——所谓「自监督音位发现」。<span class="marginnote">有趣的是，近年语音大模型的「无监督音位发现」证明：即使不给音位标签，模型也会从数据中重新发明「能区别意义的对立」——这从统计上复现了音位系统的功能本质，堪称特鲁别茨柯伊的当代回响。</span>

## 7 区别特征：音位的最小成分

音位还能再往下分解——**区别特征（distinctive features）**：音位由一组「±特征」定义，如 `/p/` = [−浊、+双唇、+塞音]。区别特征理论由雅柯布森提出、乔姆斯基与哈勒在《英语音系》（SPE）中系统化。

**区别特征的核心主张**：

- **每个音位是一束特征的组合**：`/b/` = [+浊] [+双唇] [−送气]，`/p/` = [−浊] [+双唇] [−送气]，`/pʰ/` = [−浊] [+双唇] [+送气]。
- **对立由特征的差异承担**：`/p/` 与 `/b/` 的差异只在 [±浊] 这一个特征——这个特征就是「区别性」的来源。
- **规则写起来更简洁**：音系规则可以按特征组写——「[+浊] 辅音在词尾清化」比逐个列音位更经济。

**区别特征与义素的平行**：音位由「±特征」定义，词义由「±义素」定义（见《词义与义素》）——**音系学与语义学分享同一个「成分分析」逻辑**，都是把「类」分解为「最小特征」。这种「成分化」思维贯穿语言学的各个层级。

<span class="marginnote">区别特征给语音技术提供了「特征空间」视角：音素的声学建模可以按特征组织（送气、清浊、部位），这也是「发音特征回归」类语音模型的设计思想——把「分类」换成「多标签特征预测」，模型更鲁棒。见第四级《语音技术》。</span>

## 9 音位分析的完整流程：一个实操案例

把「对立、互补分布、音感相似」三把尺子合成一个完整流程，用英语的 `p` 做案例分析：

**第一步：收集材料**。收集包含相关声音的语料——`pin`（送气 `pʰ`）、`spin`（不送气 `p`）、`top`（词尾 `p`）。

**第二步：找最小对立对**。`pin` 与 `bin` 是 `pʰ/b` 的最小对立对——送气清音与浊音对立，所以 `/pʰ/` 与 `/b/` 是不同音位。但 `pin` 与 `spin` 的 `p` 不是最小对立对（环境不同）。

**第三步：检查互补分布**。`pʰ` 出现在重读音节首（`pin`），`p` 出现在 `s` 后（`spin`）与词尾（`top`）——两者环境互补。

**第四步：检验音感相似**。`pʰ` 与 `p` 发音非常接近（同为双唇清塞音，仅差送气）——音感相似。

**第五步：判定**。`pʰ` 与 `p` 互补分布 + 音感相似 → 同一音位 `/p/` 的两个变体；`/p/` 与 `/b/` 对立 → 不同音位。

**核心对比表：`pʰ`、`p`、`b` 三者的音位身份**

| 音 | 环境 | 对立 | 判定 |
| --- | --- | --- | --- |
| `pʰ` | 重读首（`pin`） | 与 `b` 对立 | `/p/` 的变体 |
| `p` | s 后/词尾 | 不构成 | `/p/` 的变体 |
| `b` | 词首（`bin`） | 与 `pʰ` 对立 | `/b/`（独立音位） |

**这个流程就是音位分析的「算法」**：收集 → 对立 → 互补 → 相似 → 判定。每一步都可操作、可复核——这正是结构主义引以为豪的「严格方法」。学会这套流程，你就能分析任何一种语言的声音系统，也是理解「语言学家怎么工作」的入门课。

## 10 小结

- **音位**是某一语言中**能区别意义的最小语音单位**，是「功能音」而非「物理音」。
- 确立音位用两把尺子：**对立**（环境相同、意义不同 → 不同音位）与**互补分布**（环境互斥 → 可能同一音位）。
- 音位系统按**对称、经济**原则组织成矩阵；汉语普通话另有**声调音位**（4 个）。
- 音位是语言为语音信道设计的「最小信息对立」，与信息论思想相通。
- 传统 ASR 显式建模音位，端到端语音模型则从数据中「重新发明」音位。
