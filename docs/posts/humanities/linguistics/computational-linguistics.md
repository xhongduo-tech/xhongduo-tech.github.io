# 计算语言学（与 NLP 衔接）

<div class="epigraph">
<p>计算语言学的目标，是把语言学的知识变成可运行的模型——先让机器能分析句子，再让机器能生成话语。</p>

## 为什么从计算语言学开始

语言学走到现代，与计算机产生了最深刻的交集：**计算语言学（computational linguistics, CL）** 用计算方法建模语言，而 **自然语言处理（NLP）** 是其工程化方向——**CL 问「语言能否被计算」，NLP 问「用计算做什么」**。这一篇是语言学与「从极限到大模型」的直接接口，也是整个系列通往大模型的最短路径。<span class="marginnote">本专题的每一篇都可以在这里找到计算对应：音系→语音识别、形态→分词与词性标注、句法→句法分析、语义→词义消歧、语用→对话系统、词汇→WordNet。计算语言学把前面 42 篇的「语言学」翻译成了「算法」。</span>这一篇梳理 CL 的历史、任务与范式变迁。

## 1 从规则到数据：CL 的三次范式革命

计算语言学经历了三次范式跃迁，正好是「从极限到大模型」的缩影：

| 时代 | 方法 | 代表 | 局限 |
| --- | --- | --- | --- |
| **规则时代**（1950s-80s） | 手写语言规则 | 机器翻译的规则系统、专家语法 | 规则写不完、覆盖不了例外 |
| **统计时代**（1990s-2010s） | 从语料学概率 | n-gram、HMM、统计机器翻译 | 需大量标注、特征工程 |
| **神经时代**（2010s-今） | 端到端深度学习 | word2vec、Transformer、大模型 | 数据饥渴、可解释性差 |

**每次革命都是「规则让步于数据」**：规则系统被统计模型取代，统计模型又被神经模型超越。大模型是这条路的终点（目前）——**语言学的「规则知识」被压缩进了模型的参数分布**。

## 2 CL 的核心任务：语言学的计算化

CL 的任务谱系几乎就是语言学的层级镜像：

| 语言学层级 | 计算任务 | 模型/方法 |
| --- | --- | --- |
| 语音 | 语音识别（ASR）、合成（TTS） | HMM、CTC、Whisper |
| 词法 | 分词、词性标注（POS） | CRF、BiLSTM、BERT |
| 句法 | 句法分析（parsing） | CYK、依存 parser、神经 parser |
| 词汇语义 | 词义消歧（WSD）、词向量 | WordNet、word2vec、ELMo |
| 句子语义 | 语义角色标注、文本蕴含 | FrameNet、NLI 模型 |
| 语篇/语用 | 指代消解、对话系统 | 神经对话模型、LLM |
| 应用 | 机器翻译、问答、摘要 | NMT、RAG、大模型 |

**「每一个语言学概念都有一个计算任务」**——这是 CL 与语言学的血亲关系。

## 3 分布语义学：语言学假设的统计实现

**分布假说（distributional hypothesis）** 是 CL 最关键的桥：**语义相似的词出现在相似的语境中**。它来自哈里斯（1954）——而哈里斯正是乔姆斯基的老师。<span class="marginnote">分布假说把索绪尔的「意义来自差异」变成可计算的「意义来自共现分布」：`word2vec` 的训练目标（预测上下文词）就是分布假说的神经网络实现。从《语言的符号性》到 word2vec，一条「差异→分布→向量」的线索贯穿两千年语言学与三十年 NLP。</span>

- **count 方法**：统计共现矩阵 → 降维（LSA）。
- **predict 方法**：用神经网络预测上下文 → `word2vec`（CBOW、Skip-gram）。
- **语境化嵌入**：`ELMo`、`BERT`——同一个词在不同语境有不同向量，超越静态词向量。

**词向量让「语义」变成「几何」**：`king − man + woman ≈ queen`、同义词余弦相似度高——语义关系全部落在向量空间里。

## 4 大模型：计算语言学的「终极形态」？

从 CL 视角看，大语言模型（LLM）是计算语言学的连续演进，而非断裂：

- **语言模型（LM）**：计算一个词序列的概率——`P(w_1,...,w_n)`，这是 CL 自 n-gram 时代就研究的核心问题。
- **下一个词预测（next-token prediction）**：大模型的训练目标，本质是「语言模型」的神经网络版本。
- **涌现能力**：当参数与数据达到规模，语言模型「涌现」出翻译、推理、对话等能力——这些曾是 CL 的独立任务，如今被一个统一的「预测下一个词」模型覆盖。

**大模型统一了语言学的层级**：不再显式做分词、POS、句法、语义（虽然 pipeline 仍在用），而是端到端地从文本预测文本。**语言学知识没有消失，而是被「内化」进模型的分布**——这既是解放（无需人工标注），也是挑战（难以解释、难以控制）。

## 5 计算语言学与「从极限到大模型」：回望与前瞻

计算语言学是「从极限到大模型」这整条线的**枢纽**：

- **回顾**：本专题的语法、语义、语用知识，构成了 NLP 任务设计的科学基础；编译原理（形式语言）来自生成语法。
- **展望**：大模型仍在与语言学对话——句法可解释性（注意力头是否编码语法）、语义评估（模型是否真懂）、语用能力（模型是否懂言外之意）。
- **回馈**：语言学的「规则知识」在数据稀缺、解释性要求高的场景（法律、医疗文本）依然重要；大模型也反过来成为语言学研究的工具（用模型做语料分析、语言学研究）。<span class="marginnote">「大模型作为语言学家的助手」正在成为现实：用 LLM 标注语料、发现语言模式、翻译调查问卷，甚至生成语言学家的研究假设。计算语言学从「用语言学帮助机器」走向「用机器帮助语言学」——一个完整的双向循环。这也是第九级《数字人文》与《计算社会科学》的起点。</span>

## 7 语言资源与评测：语料库、树库与基准

计算语言学能「跑起来」，靠的不是算法，而是**语言资源（resources）** 与**评测（evaluation）**：

**语料库（corpus）**：

- **平衡语料库**：按文本类型（新闻、口语、学术……）均衡采样，代表「整个语言」——布朗语料库（英语 100 万词）、国家语委现代汉语语料库。
- **标注语料库**：在原始文本上标注词性、句法树、语义角色——**树库（treebank）**（如宾州树库 Penn Treebank）是句法分析的「金标准」。
- **平行语料库**：同一内容的多语言对照——机器翻译的训练与评测基础。

**评测基准（benchmark）**：

- **任务基准**：给固定数据集、固定指标，让系统可比——词性标注的准确率、句法分析的 UAS/LAS、词义消歧的准确率。
- **通用评测集**：GLUE、SuperGLUE 把多个任务打包，测「通用语言理解能力」；中文有 CLUE、CLUEWSC。

**评测的哲学问题**：

- **指标不等于能力**：准确率高不等于「真懂」——`90% 准确率` 可能靠表面线索（词频、共现）而不是深层理解。
- **测试集污染**：如果训练语料包含测试集，成绩虚高——大模型时代「评测泄漏」成了大问题，评测集需不断更新防泄漏。

**核心对比表：语言资源与评测的关系**

| 资源 | 用途 | 对应任务 |
| --- | --- | --- |
| 词性标注语料 | 训练+评测 POS | 词法分析 |
| 树库 | 训练+评测 parser | 句法分析 |
| 平行语料 | 训练+评测 MT | 机器翻译 |
| GLUE/CLUE | 通用评测 | 多任务理解 |

<span class="marginnote">「语料库语言学」把语言学从「直觉」变成「证据」：一个词是否常见、一个结构是否合法，靠语料统计而非语感。大模型是「语料库语言学的终极形态」——但「评测泄漏」问题也提示：当模型见过太多语料，「评测」本身需要像语言一样「动态更新」。</span>

## 9 一个实操：理解一次「分词 + 词性标注 + 句法分析」

把计算语言学的任务用在「跑通一个 NLP 流程」上——以「他正在认真地读书」为例，手动模拟 pipeline：

**第一步：分词（word segmentation）**。

`他 / 正在 / 认真 / 地 / 读书`

依据：`认真` 与 `地` 分开（`地` 是结构助词）、`读书` 是一个词（动宾凝固）。

**第二步：词性标注（POS tagging）**。

| 词 | 词性 | 依据 |
| --- | --- | --- |
| 他 | 代词 | 人称代词 |
| 正在 | 副词 | 时间副词 |
| 认真 | 形容词 | 修饰动词 |
| 地 | 助词 | 状语标记 |
| 读书 | 动词 | 动作 |

**第三步：句法分析（parsing）**。

- 主谓：`他`（主语）+ `正在认真地读书`（谓语）。
- 状中：`正在`、`认真地`（状语）+ `读书`（中心语）。
- 动宾：`读` + `书`（宾语）。

**第四步：还原语言学基础**。每一步都有本专题的对应：分词 ↔ `语素与词`、词性 ↔ `词法`、句法 ↔ `句法成分`。**NLP 的每一步，都是语言学的「算法化」**。

**核心对比表：NLP 任务与语言学概念的对应**

| NLP 任务 | 语言学基础 | 输入/输出 |
| --- | --- | --- |
| 分词 | 语素与词 | 字序列 → 词序列 |
| 词性标注 | 词法 | 词 → 词性 |
| 句法分析 | 句法 | 词序列 → 句法树 |
| 词义消歧 | 词义 | 词+语境 → 义项 |

**这个流程的意义**：传统 pipeline 把「语言理解」拆成「语言学层级」逐步执行——这正是「语言学即计算」的直接实现。而大模型跳过了显式 pipeline，端到端从文本预测文本——但理解 pipeline 仍是理解「模型在隐式做什么」的最好参照。

**一个自查**：给「她把书放在了桌上」做三步 pipeline（分词、词性、句法），特别注意「把」的词性与「放在」的结构——你会体会到「汉语无形态」让每一步都比英语更依赖语境。

## 10 小结

- 计算语言学（CL）建模语言，NLP 是它的工程化；**CL 问「语言能否计算」，NLP 问「计算做什么」**。
- CL 经历**规则→统计→神经**三次范式革命，每次都是「规则让位于数据」。
- CL 任务谱系 = 语言学层级镜像：**语音→ASR、词法→分词/标注、句法→parsing、语义→WSD、语用→对话**。
- **分布假说**把「意义来自差异」变成「意义来自共现」，词向量让语义成为几何。
- 大模型是 CL 的连续演进：**统一「预测下一个词」覆盖了翻译、推理、对话等全部任务**，语言学知识被内化进参数分布。
