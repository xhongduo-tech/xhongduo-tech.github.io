# 词的构造

<div class="epigraph">
<p>语言的词汇不是一堆散沙，而是按固定的构词规则不断生长的活系统——新词从旧材料中组合而来。</p>

## 为什么从词的构造开始

上一节区分了语素与词，这一节回答：**词是怎么「造」出来的？** 一个语言的两万常用词，并非两万个独立记忆单元，而是由几千个语素按有限规则组合而成——这就是**构词法（word formation）**。<span class="marginnote">构词规则让词汇「可预测」：认识「科学」与「家」，就能猜到「科学家」的大意。大模型的词向量也有同样的「组合性」——`queen` 的向量 ≈ `king + woman − man`，词义可以从部件向量合成。见第四级《自然语言处理》与《大模型原理》。</span>这一篇梳理汉语与英语的构词机制。

## 1 词的内部结构：词根、词缀、词干

先给构词的「零件」命名：

- **词根（root）**：词中**最核心、表词汇基本意义**的语素，是构词的基础。如「人民」的「人」、「桌子」的「桌」、「unhappy」的 `happy`。
- **词缀（affix）**：附加在词根上、改变或补充意义的语素，分**前缀**（`un`、`re`）、**后缀**（`-ness`、`-er`）、**中缀**（罕见）与**词尾/屈折后缀**（`-s`、`-ed`）。
- **词干（stem）**：词缀所依附的主体，可以等于词根，也可以是词根+前缀等。

**辨析｜易错点：** 词根 vs 词干的差别：词干是「加词缀前剩下的部分」，词根是「最底层的表义核心」。「unhappiness」去掉后缀 `-ness` 得词干 `unhappy`，再去掉前缀 `un` 得词根 `happy`。词干可以含词根，词根不能更小。

## 2 汉语的构词方式

汉语以**复合法**为主，构词方式主要有：

- **复合**：词根+词根。按两个词根的关系分：
  - 联合式：`人民`、`道路`、`开关`（并列）
  - 偏正式：`火车`、`黑板`、`白菜`（修饰+中心）
  - 动宾式：`开会`、`司机`、`担心`（动作+对象）
  - 主谓式：`地震`、`日食`、`心疼`（主语+谓语）
  - 补充式：`提高`、`说明`、`缩小`（动作+结果）
- **派生（附加）**：词根+词缀，如 `桌子`、`石头`、`老虎`、`阿姨`。<span class="marginnote">汉语词缀不如英语发达，但「子、儿、头、老、阿」是现代汉语最典型的词缀。「子」还有「名物化」功能：动词「盖」→ 名词「盖子」。词缀的「转化词类」功能与英语 `-ness` 如出一辙。</span>
- **重叠**：`妈妈`、`看看`、`高高兴兴`——重叠可表亲近、尝试、状态加深。
- **缩略**：`北京大学 → 北大`、`环境保护 → 环保`、`全国人民代表大会 → 人大`。

## 3 英语的构词方式

英语的构词与汉语形成对照：

| 方式 | 说明 | 例子 |
| --- | --- | --- |
| 派生 | 词根加词缀，常改变词类 | `happy → happiness`、`nation → national` |
| 复合 | 两个自由词根拼合 | `blackboard`、`snowman`、`pickpocket` |
| 转类（零派生） | 词类转换不加词缀 | `email`（名）→ `to email`（动）、`run`（动）→ `a run`（名） |
| 截短 | 词形缩短 | `telephone → phone`、`laboratory → lab` |
| 混成 | 两个词剪接 | `smoke + fog → smog`、`breakfast + lunch → brunch` |
| 首字母缩略 | 取首字母 | `laser`、`radar`、`NATO` |

## 4 构词的经济性：有限规则，无限新词

构词法揭示了语言「经济性」的机制：**用几千个语素 + 有限规则，就能覆盖无限的概念增量。**

- 新词造出的方式高度可预测：AI 浪潮中「人工」加后缀得「人工智能」，「人工智能」加「家」得「人工智能家」。
- 英语中 `-ize`（`computerize`、`tokenize`）一晚上能生成新词——母语者能理解从未见过的派生词，因为规则是活的。<span class="marginnote">这种「组合性」被语言学家称为「词法的生产力（productivity）」：规则越能生成新词，生产力越高。中文复合的「偏正式」生产力极强，所以中文新词多为「修饰语+核心」的名词；而英语靠派生词缀造新词。构词类型差异也影响 tokenizer：中文分词要处理「新造复合词」，英文 BPE 要处理「新造派生词」。</span>

## 5 构词与语言建模

构词的组合性给「从极限到大模型」一个深刻的启示：

- **词汇是组合的，不是查表的**：母语者能理解新词，说明词汇知识是「规则+部件」结构。传统 NLP 的 OOV（未登录词）问题，根源就是「把词汇当枚举清单」；子词 token 化与字符级模型则把「组合性」还给模型。
- **子词 token 化 ≈ 自动构词分析**：BPE 的合并步骤（`un`+`happy`→`unhappy`）与构词法的「词根+词缀」高度同构——tokenizer 在无监督中学会了类似形态组合的结构。<span class="marginnote">有趣的是，神经网络词向量的「组合」与传统构词法并不完全一致：`unhappy` 的向量不是 `un` 向量与 `happy` 向量的简单相加。但「新词可理解」这一语言事实，被大模型的泛化能力以分布方式实现了——数据驱动的组合性，仍是语言学的组合性。</span>

## 7 构词规则与语义透明度

构词法不只管「怎么造词」，还决定「词的语义怎么被理解」——这涉及**语义透明度（semantic transparency）**：

- **透明词**：整体意义可从成分意义直接推得——`黑板`（黑的板）、`下雨`（降下雨）。组合性强，新词多为透明词。
- **半透明词**：成分意义与整体意义部分相关——`马路`（不是「马走的路」，而是「公路」）、`开刀`（动手术）。
- **不透明词（凝固词）**：成分意义与整体意义关系模糊——`东西`（物品）、`眉目`（线索）。这类词语义「冻结」，不能再拆开理解。

**辨析｜易错点：** 透明度的本质是「语义的组成性（compositionality）」程度——整体意义能否由部分意义 + 规则算出。汉语的偏正式复合词多数透明（`火车`、`黑板`），这是汉语「望文生义」的基础；但 `白菜`（不是「白的菜」）、`先生`（不是「先出生的人」）等不透明词必须整体记忆。

**语义透明度与语言学习/建模**：儿童靠透明度「猜词」（`沙发床` 一听就懂）；大模型也依赖组成性——`unhappiness` 的理解建立在 `un`、`happy`、`ness` 的部件语义上。但越不透明的词，越依赖「整体记忆」而非「组合推理」——这正是词向量需要「词条级」而非「部件级」表征的原因。

<span class="marginnote">语义透明度是「组合性 vs 整体性」争论的词汇学版本：乔姆斯基派强调组合（有限规则生成无限意义），认知派强调整体记忆（高频固化表达整存整取）。大模型同时具备两种能力——对透明词组合推理，对不透明词整体记忆——这也许就是它语义能力强的秘诀。</span>

## 9 一个实操：辨认词的内部结构

把构词知识用在「解剖词」上——这是词汇学的基本功。以「科学家」为例，完整解剖：

**第一步：切分语素**。`科学家` → `科学` + `家`（两个语素）。

**第二步：标注语素类型**。

- `科学`：词根（成词、表核心义「系统的知识」）。
- `家`：词缀（后缀，表「从事某类的人」）。

**第三步：判定构词方式**。`科学`（词根）+ `家`（后缀）→ **派生（附加）构词**。

**第四步：检验语义透明度**。`科学家` = 「从事科学研究的人」——语义透明（成分义可推出整体义）。

**再解剖三个词**（对照练习）：

| 词 | 语素切分 | 构词方式 | 透明度 |
| --- | --- | --- | --- |
| 开关 | 开+关 | 复合（联合式） | 半透明 |
| 提高 | 提+高 | 复合（补充式） | 透明 |
| 老鼠 | 老+鼠 | 派生（前缀+词根） | 透明 |
| 葡萄 | 葡萄 | 单纯词（单语素） | — |

**解剖的价值**：会解剖词，才能：

- **猜生词**：遇到 `人工智能体`，拆出 `人工/智能/体`，靠组合规则猜出大意。
- **造新词**：按 `X+家`、`X+化`、`X+主义` 的模板，你能「合法地」造出可理解的新词（`慢生活化`、`内卷家`）。
- **理解多语差异**：汉语靠复合、英语靠派生——这是词汇结构对语言学习与建模的双重影响。

**一个自查**：解剖 `国际化`（国+际+化）、`app`（英语缩略借入）——第一个是复合+派生，第二个是外来词整体借入。同一句话里两种构词机制并存，正是现代汉语词汇的常态。

## 10 小结

- 词的零件：**词根**（表义核心）、**词缀**（前缀/后缀）、**词干**（加缀前的主体）。
- 汉语构词以**复合**为主（联合、偏正、动宾、主谓、补充），另有派生、重叠、缩略。
- 英语构词丰富：**派生、复合、转类、截短、混成、缩略**。
- 构词法体现语言的**经济性**：有限部件 + 规则 → 无限新词，规则具有**生产力**。
- 子词 token 化在无监督中「重新发明」了构词组合，大模型以分布方式实现了新词理解。
