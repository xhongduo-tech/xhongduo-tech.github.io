## 为什么从执笔开始

上一课我们认识了笔、墨、纸、砚——那是书法的「器」。现在轮到「人」：一杆软毫在手，手该怎样握它、腕该怎样运它、笔锋该怎样使唤它？这一课是整个书法技法的地基。<span class="marginnote">地基的意思是：所有书体、所有名帖，最终都建立在「执笔—运笔—笔锋」这套基本动作上。楷书、行书、草书看似千差万别，拆到底，都是同一套用笔原理在不同节奏与变形下的应用。</span>

古人传下一句口诀，叫「**指实掌虚，腕平掌竖**」。八个字，写尽执笔的全部要义。我们这一课就从这个口诀出发，逐层拆解：执笔怎么执、运腕怎么运、笔锋怎么用，最后用「永字八法」把用笔的八种基本笔画收束成一套可练可查的系统。

## 1 执笔法：指实掌虚

**执笔（pen holding）**：握笔的方法。通行至今的是**五指执笔法**，由唐代陆希声总结，五字诀为「**擫、押、钩、格、抵**」，分别对应五指的功能：

**擫（yè）**：大拇指第一节抵住笔管内侧，向右上用力。
**押（yā）**：食指第一节压住笔管外侧，向左下用力——与大指形成对钳。
**钩（gōu）**：中指钩住笔管，加强向左的力量。
**格（gé）**：无名指指甲根部从右向左顶住笔管，抵住中指向内的力。
**抵（dǐ）**：小指贴附无名指之下，辅助用力。

五指向心聚拢，把笔管稳稳「夹」住。关键在两个字：**实**与**虚**。指要实，笔才不会滑脱、不受控制；掌要虚（掌心空，可容一鸡蛋），腕才能自由转动。二者看似矛盾——「实」是稳定，「虚」是灵活——正是书法「稳中求变」的物理形态。

<span class="marginnote">执笔高度随字大小而变：写小楷执低，运笔幅度小、精准；写大草执高，运笔幅度大、气足。元代陈绎曾《翰林要诀》说「唐人多用三指，今人多用五指」——执笔法本身也有时代流变，不必泥古。</span>

**辨析｜易错点：** 初学者最常见的毛病是「**握笔过死**」——五指一齐死扣笔杆，腕部僵硬，写出的笔画呆板。另一个极端是「**悬腕悬肘**」的误解：写小字不必悬肘，枕腕即可；写大字（一拳以上）才需悬腕悬肘。执笔的第一标准不是「像谁」，而是「放松且能发力」。

## 2 运腕与运笔：指主执，腕主运

执笔解决了「怎么握」，运笔解决「怎么动」。核心分工一句话：**指主执笔，腕主运笔。**

**运腕**：以腕关节为轴心转动笔杆。写横画时腕左右摆动，写竖画时腕上下伸缩。腕活则笔画圆活，腕死则笔画僵硬。
**运肘**：写更大的字，腕力不够，需以肘为轴、整条手臂运笔。悬肘最难，也最见功夫——它要求肩、肘、腕三关节通贯，力量从肩直达笔尖。

运笔的动作模式，古人归纳为几种基本类型：**中锋**（笔锋保持在笔画中线，线条圆厚）、**侧锋**（笔锋偏在一侧，线条劲健）、**藏锋**（起收笔时锋尖藏入笔画内，浑厚含蓄）、**露锋**（锋尖外露，精神外耀）、**提按**（笔毫提起变细、按下变粗）、**转折**（转是圆转、折是方折）。

<span class="marginnote">这六种动作并非平级：中锋是「纲」，其余是「目」。历代书家都把中锋视为用笔的第一法则——「常令笔心在点画中行」，是蔡邕《九势》里的话，两千年后依然是书法技法的总纲。</span>

### 从枕腕到悬肘：执笔的三级进阶

执笔运腕的练习，按支撑方式分三级，由易到难：

**枕腕**：手腕贴在桌面上写。最稳，适合写小楷、小行书——字径小，运笔幅度小，枕腕足够。
**悬腕**：手腕离开桌面，以肘为支点。写中楷、中行书时用，腕部获得更大的活动半径。
**悬肘**：腕与肘都离开桌面，整条手臂悬空。写大字、大草时用，力量从肩直达笔尖，运笔最自由，也最难。

初学不必一上来就悬肘——「写多大的字，用多大的支撑」，循序渐进即可。判断的简单标准是：**当字径超过一拳大小时，枕腕就转不动了，必须悬腕悬肘。** 悬腕悬肘的练习没有捷径，只有「每天坚持写大字」一条路——古人说「写字无百日功」，指的不是百日学会，而是百日不间断的功夫。三个月下来，手臂的力量与稳定性自会建立。

值得注意的是，执笔的三级进阶不只对应字的大小，也对应书体：小楷多枕腕，行草大字必悬肘。学会「按需切换」，才是执笔的真正成熟。

**重点：用笔的全部奥义可以压缩成「提按使转」四个字。** 提按管粗细，使转管方向与方圆。一个横画，起笔藏锋，中段中锋运行，收笔回锋——「**欲横先竖，欲竖先横**」「**无垂不缩，无往不收**」，起收之间自带一个回环。这套「逆入平出」的笔法，是毛笔区别于硬笔的根本特征：硬笔直去直回，毛笔则笔笔藏头护尾，像太极，每个动作都留有余地。

### 为什么「欲横先竖」：藏锋的物理与美学

「欲横先竖」是初学者最难过、也最不该跳过的一条笔法。它的字面意思是：写横画，起笔要先有一个向下（竖向）的预备动作。为什么？两层原因：

从**物理层面**看，毛笔是软的——直接向右拖，笔锋会偏滑、起笔处显得单薄。先有一个反向的逆入动作，笔毫被「压开」、笔锋被「稳住」，中锋的运行才有了扎实的开头。这正是「逆锋起笔」的本质：欲左先右、欲右先左、欲上先下、欲下先上。

从**美学层面**看，这个反向动作让线条「藏头护尾」——起笔处圆浑含蓄，不见尖利的锋尖。中国美学推崇「藏」而不露：锋芒外露是少年气，含而不发是成熟味。所以藏锋不只是技术，更是一种审美态度——它让每一笔都「有余地、有回旋」，正是《书法与中国文化》一课讲的「中庸」与「太极」，也与第七级《哲学深化》的[[philosophy-deepening]]专题所论的「阴阳相济」一脉相承。

顺带一提：这个「逆入平出」的逻辑，在篆刻里同样成立——刻印的起刀、收刀也讲究逆与回。可见「逆笔」是中国人用软性工具书写时的通用智慧，书法与篆刻共享着同一套「物理—美学」逻辑。

## 3 永字八法：用笔的基本笔画系统

用笔的种种要领，最终要落实为具体笔画。传王羲之（一说智永）总结的「**永字八法**」，用「永」这一个字，集中了汉字最基本的八种笔画及其写法，是书法入门的经典教材：

| 笔画 | 名称 | 写法要点 |
| --- | --- | --- |
| 点 | 侧 | 侧锋落笔，势如坠石，顾盼生姿 |
| 横 | 勒 | 逆锋起、中锋行、回锋收，如勒马缰 |
| 竖 | 弩 | 直中带曲，不僵不弯，如弓弩之挺 |
| 钩 | 趯（tì） | 蓄势后迅速挑出，如踢脚 |
| 提 | 策 | 仰笔挑上，如策马扬鞭，轻捷有力 |
| 长撇 | 掠 | 起笔重、逐渐提起，如飞燕掠水 |
| 短撇 | 啄 | 短促急出，如鸟之啄食 |
| 捺 | 磔（zhé） | 铺毫渐按、最后捺出，如裂帛 |

这八法表面是笔画，实则是用笔动作的八个范例：**每一法都含「起—行—收」的完整程序，都要求「藏头护尾」「提按相济」。** 练永字，练的从来不是这一个字，而是八种基本运动模式的肌肉记忆。<span class="marginnote">「永」字为什么恰好选得好？因为它横、竖、钩、提、撇、捺、点俱全，唯独没有折。所以永字八法只教基本笔画，转折的规则要到《楷书技法》一课才补全——教材的进阶逻辑与笔画的进阶逻辑在此重叠。</span>

### 一个「永」字的完整写法

把八法连起来，看「永」字如何从「八法」变成「一个字」。「永」字共五笔（按楷书写法实为五笔：点、横折钩、横撇、撇、捺），八法把它们拆成八个动作：

第一笔「点」用「侧」法——落笔即定，势如坠石。第二笔「横折钩」里藏着三个动作：「横」用「勒」，「折」处顿挫，「钩」用「趯」——一笔三法。第三笔「横撇」中，「横」用「策」起，「撇」用「掠」行。第四笔「撇」用「啄」，短促有力。第五笔「捺」用「磔」，铺毫渐按、最后捺出。

所以「永」字虽只五笔，却涵盖了侧、勒、弩、趯、策、掠、啄、磔八种笔势。练永字，练的是「八法在真实书写中的综合运用」——把八个孤立的动作织进一个连贯的字。这就是为什么历代学书者都从「永」入手：它让你在写「第一个完整的字」时，就遇见了「所有的笔法」。

## 4 核心对比：中锋与侧锋

用笔的争议与迷思，一半都集中在「中锋」与「侧锋」上，值得专门辨析。

| 维度 | 中锋（正锋） | 侧锋 |
| --- | --- | --- |
| 笔锋位置 | 笔心沿笔画中线运行 | 笔锋偏靠一侧 |
| 线条质感 | 圆厚、含蓄、立体 | 劲健、锐利、妍美 |
| 技法地位 | 用笔之纲，历代推崇 | 辅助，忌「笔笔侧锋」 |
| 典型用途 | 篆隶楷的骨干笔画 | 行草中的牵丝、呼应 |
| 入门要求 | 先练正，务求纯正 | 后习变，防止浮滑 |

**重点：中锋是基本功，侧锋是调味品。** 初学务必以中锋为主——一个笔画中锋写不圆，线条就「薄」；而「薄」正是书法最忌讳的毛病。但也不必走极端：清代碑学兴起后，书家大量使用侧锋取势，照样写出了雄强一路。正确的心态是：**先立中锋之正，再学侧锋之变**，最终中侧并用、随心所欲。

这一课的所有内容——执笔、运腕、提按、中锋——都是「静态」的规范。把它们放进一个真实的汉字里动起来，就是下一课《楷书技法》的任务：楷书是用笔法则最完整、最严格的检验场，也是最适合用来把「静态规范」练成「动态本能」的书体。

## 5 小结

- **五指执笔法**：擫、押、钩、格、抵；要诀是「指实掌虚」——指实求稳，掌虚求活。
- **运笔分工**：指主执、腕主运；「提按使转」四字概括全部用笔动作。
- 用笔第一法则是**中锋**，「常令笔心在点画中行」；侧锋为辅，先正后变。
- 起收讲究**藏头护尾、逆入平出**，「无垂不缩，无往不收」。
- **永字八法**用一「永」字集中八种基本笔画，是练「起行收」肌肉记忆的经典教材。

在下一节，我们将进入第一种成体系的字体——楷书：它的结构法则、点画规范与临习路径，是通往行、草、隶、篆的桥头堡。
