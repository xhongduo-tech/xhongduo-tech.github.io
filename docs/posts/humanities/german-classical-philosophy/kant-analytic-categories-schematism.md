# 康德先验分析论：范畴与图型

<div class="epigraph">
<p>统觉的先验统一性，是我们在知识中一切必然性的最高根据。</p>
<footer>—— 伊曼努尔 · 康德（Immanuel Kant），《纯粹理性批判》先验分析论（1781/1787）</footer>
</div>

## 为什么从范畴与图型开始

上一篇我们停在「直观无概念则盲」。感性只给了我们杂多的直观——颜色、形状、位置、时间中的先后——但一堆直观还不是知识。要让「这堆感觉」变成「这是苹果」的判断，心灵还必须装备第二套结构：**范畴**。<span class="marginnote">本专题上一篇《康德先验感性论与时空观》处理感性一侧，本篇处理知性一侧。两者合成康德所谓的「先验要素论」完整的两半。</span>

范畴在康德那里不只是「概念的名字」，而是一整套论证的核心：它要回答「为什么我们的概念能适用于世界」——这个问题，哲学史上称为**先验演绎**。<span class="marginnote">先验演绎是整个《纯粹理性批判》公认最难、也最关键的段落，康德自己在第二版里重写了一遍，可见其重要性。读懂它，就读懂了康德认识论的脊梁。</span>而范畴如何「落地」到具体经验上，还要靠**图型**这个时间化的中介。本篇按「判断表 → 范畴表 → 先验演绎 → 图型论」四步走完这条链。

## 1 从感性到知性：判断

康德把知性定义为**判断的能力**——不是「知道事实」，而是「作出判断」的能力。知性自己不能产生内容，它只能把感性的杂多「综合」成判断：把「这是红的」「这是圆的」「这是果子」捏合成一个「这是红苹果」。

一个重要的康德式命题：**知识 = 概念 + 直观**。概念是「对若干对象的共同特征的思维」，直观是「对单一对象的直接给予」。判断就是「用概念去规定直观」——把个别（这个苹果）归到一般（苹果）之下。

那么问题来了：既然概念是后天的、来自经验的（「苹果」概念当然从经验来），为什么康德还要说知性「先天」装备了某些概念？因为——判断本身有其**形式**。无论判断的内容是什么，判断的形式（单称/全称、肯定/否定、直言/假言……）是先天的。而判断形式，正是范畴的居所。

## 2 判断表：逻辑学的十二种判断

康德从传统形式逻辑（亚里士多德以来）提取出判断的十二种形式，按四大类排列。这张表不是他发明的，而是他「借来」并系统化的：

| 类别 | 判断形式 | 例子 |
| --- | --- | --- |
| 量 | 全称判断 | 所有人都要死 |
| 量 | 特称判断 | 有些人是哲学家 |
| 量 | 单称判断 | 苏格拉底是要死的 |
| 质 | 肯定判断 | 灵魂有活动 |
| 质 | 否定判断 | 灵魂没有广延 |
| 质 | 无限判断 | 灵魂是非物质性的 |
| 关系 | 直言判断 | 人是有限的 |
| 关系 | 假言判断 | 如果天晴，我们就出发 |
| 关系 | 选言判断 | 世界要么有开端，要么没有 |
| 模态 | 或然判断 | 可能是下雨 |
| 模态 | 实然判断 | 确实在下雨 |
| 模态 | 必然判断 | 必然下雨 |

关键不在表格本身，而在康德的洞察：**知性每一次作判断，其实都在运用某种范畴**——作全称判断，就是在运用「单一性/复多性/总体性」这类量范畴；作假言判断，就是在运用「原因—结果」范畴。<span class="marginnote">这套「判断形式 → 范畴」的对应关系，就是康德的「形而上学演绎」：范畴不是凭空发明的十二个词，而是判断形式在知性一面的「对偶」。一个判断形式，对应一个范畴。</span>

## 3 范畴表：十二个先天概念

把判断表「翻译」成范畴表，就得到康德著名的十二范畴：

| 类别 | 范畴 |
| --- | --- |
| 量 | 单一性、复多性、总体性 |
| 质 | 实在性、否定性、限制性 |
| 关系 | 实体与偶性、原因与结果、协同性 |
| 模态 | 可能性、现实性、必然性 |

这十二个范畴是知性的**先天概念**：它们不属于经验，却规定着一切经验对象——就像时空是感性的先天形式，范畴是知性的先天概念。<span class="marginnote">为什么要「恰好」十二个？康德认为判断形式穷尽了形式逻辑，因此范畴也就恰好十二个。后人常批评这个论证「太形式化」，但它的结构意义仍在于：认识世界的概念框架是有限的、可枚举的，而非随意的。</span>

其中**关系范畴**是牛顿科学的地基：实体—偶性对应「物质」，原因—结果对应「力」与「定律」，协同性对应「相互作用」。康德要把牛顿物理学的概念骨架，纳入先天的范畴体系。

## 4 公式解析：统觉的先验统一

范畴从判断形式「生出」是一回事，范畴凭什么适用于经验对象是另一回事。后者要靠**先验演绎**。康德用一句话浓缩了演绎的枢纽——**统觉的先验统一**：

$$
\text{「我思」必须能够伴随我的一切表象。}
$$

对这句话做三步拆解：

- **第一步，看清「我思」的地位**：一切表象（红色、声音、位置……）如果要在同一个意识里被我经验到，就必须都归属同一个「我」。康德把这种「自我意识的统一」称为统觉（Apperzeption）。
- **第二步，推出统一的条件**：如果杂多的直观要统一在「一个我」之下，那么统觉的统一就必须是「先于一切经验的」——它规定着经验如何可能。康德称之为统觉的**先验统一**。
- **第三步，让范畴出场**：杂多要统一，就必须由某种「规则」来综合；这些规则，就是范畴。「对象」不是现成的，而是**范畴按规则综合杂多后产生的结果**。

于是结论出现：**范畴是经验对象得以可能的条件——任何对象要成为「被我认识的某物」，都必须已经按照范畴被构造。**<span class="marginnote">这就是先验演绎的结论：不是范畴去符合对象，而是对象符合范畴。它与《先验感性论》的哥白尼式革命同一逻辑，只是从感性推进到了知性。</span>

## 5 图型论：时间如何给概念「配图」

范畴是纯概念，感性提供的是纯直观——两者性质完全不同，怎么接得上？康德的答案是**图型**（Schema）：一个把范畴「翻译」成时间规定的中介。

**图型不是形象（Bild），而是制作形象的程序。** 比如「三角形」的图型，不是某个具体的三角形图片，而是「在空间里画出三角形」的规则。范畴的图型则是时间的规定：

- **实体图型**：时间中的**持存**（那个在变化中不变的东西）。
- **因果图型**：时间中的**相继**（按规则必然前承后继的东西）。
- **量的图型**：时间中的**数目**（把同一单位在时间中反复综合）。

通过图型，纯范畴获得了「时间的图像」，从而能够应用到现象上。<span class="marginnote">图型论是康德体系里最「技术」的段落之一，也最容易被跳过。但它的功能很朴素：没有它，范畴和直观就像两个不相干的齿轮——图型就是那个把两者咬合起来的传动轴。</span>

## 6 范畴图型速查表

把十二范畴各自的图型列成一张表，会清晰地看到「时间」如何贯穿全部：

| 范畴类别 | 范畴 | 图型（时间规定） |
| --- | --- | --- |
| 量 | 单一性/复多性/总体性 | 数（对同一单位的时间综合） |
| 质 | 实在性 | 时间中的充实（实在的存在） |
| 质 | 否定性 | 时间中的空（非存在） |
| 质 | 限制性 | 从有到无的过渡 |
| 关系 | 实体 | 时间中的持存 |
| 关系 | 因果 | 时间中的必然相继 |
| 关系 | 协同性 | 时间中的同时并立 |
| 模态 | 可能性/现实性/必然性 | 存在于某时/特定时/一切时 |

看这张表会有一个惊人的发现：**图型论其实把全部范畴都还原成了时间的各种规定**。时间不但是感性直观的形式，还成了范畴「落地」的唯一通道——这使时间在康德体系中获得了比空间更深的根基地位。

## 7 综合：知识是如何被「做」出来的

康德反对「认识像照镜子」的被动图像。认识是主动的**综合**（Synthesis），大致分三个环节：

- **直观的综合**：把杂多的感觉先统握成一个直观。
- **想象的再生综合**：把过去与现在联系起来（比如认出一个连续移动的点）。
- **概念认定的综合**：用概念把统一的结果固定下来，形成「这是苹果」的判断。

综合的每一环节都受范畴引导。没有综合，杂多只是「轰隆作响的混沌」；有了综合，才有「一个对象」的经验。<span class="marginnote">用今天机器学习的话说：康德式的「对象」不是直接读进来的数据，而是被「感知管线 + 归纳偏置」加工出来的表征。范畴就是认知系统自带的、不可关闭的归纳偏置。</span>这也解释了为什么先验分析论在康德全书中地位如此高——它是「知识生产」的流水线说明。

## 8 小结

- 知性 = **判断的能力**；知识 = **概念 + 直观**。
- **判断表**给出十二种判断形式，**范畴表**由它们推出十二个先天概念。
- **先验演绎**证明：范畴是经验对象可能性的条件——对象符合范畴。
- 统觉的**先验统一**（「我思」伴随一切表象）是知识统一性的最高根据。
- **图型论**用时间规定把纯范畴接到现象上，时间因此成为普遍的通道。
- 认识是**综合**的过程：直观、想象、概念三重综合协同工作。

在下一节，我们将离开分析论，看理性如何不满足于现象界、执意要把握物自体，从而陷入必然的幻相——那就是**康德先验辩证论与理性批判**。
