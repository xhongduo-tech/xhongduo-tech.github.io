# 口述历史与档案

## 为什么从口述历史与档案开始

传统档案是「写下来的记忆」——文件、记录、文书。但历史的大多数参与者并没有留下文件：不识字的农民、沉默的妇女、被主流叙事忽略的普通人，他们的经历只存在于记忆与讲述之中。**口述历史（oral history）**正是要抢救这些「未写入档案的历史」：通过访谈，把亲历者的记忆转化为可保存、可研究的档案。它把档案学的对象从「纸上的记录」扩展到「口中的记忆」，是档案学最具人文温度的分支。<span class="marginnote">口述历史与档案学的关系存在学派之争：正统档案学强调档案的「原始记录性」，主张口述史料是「再造的记录」而非「原生档案」；而现代档案学则认为，记忆本身就是档案的原料——<strong>档案馆不应只收藏既有记录，还应主动生产记忆</strong>。这一争论背后，是档案学「被动收藏」与「主动构建」两种范式之争。</span>它与第七级《考古学》、第九级《数字人文》共享对「历史如何被保存」的追问。

## 1 口述历史的含义与发展

**口述历史（oral history）**：以访谈等口头方式，采集、整理、保存历史亲历者与见证者的回忆，并将其转化为可供研究与利用的历史资料的活动与成果。

口述历史有深远的传统。古代史家已依赖口述——司马迁写《史记》大量依靠游历访求的耳闻；希罗多德《历史》亦以口述为史料基础。但作为**系统化的方法论**，口述历史兴起于 20 世纪中叶：磁带录音机让「采集声音」变得可行，社会史、女性史、底层史研究则让「被忽略的声音」成为研究需求。美国哥伦比亚大学 1948 年建立的口述历史研究机构，被普遍视为现代口述历史运动的起点。<span class="marginnote">口述历史的方法论自觉，与 20 世纪史学范式的转向同步：从「帝王将相的历史」转向「人民的历史」。录音机使历史学第一次可以「保存活人的声音」，这是书写时代不具备的技术条件——口述历史是技术条件与史学观念共同催生的产物。</span>

## 2 口述历史的采集方法

口述历史的核心是**访谈（interview）**，其方法论直接继承社会科学访谈技术，又有独特要求：

1. **前期研究**：访谈前必须做足功课——了解受访者的经历背景、查阅相关文献，带着「有知」的状态进入访谈，才能提出有价值的问题。
2. **访谈设计与问题链**：按时间线或主题组织问题，从开放式问题入手，逐步深入。访谈既要**引导**（保持方向），又要**跟随**（尊重讲述者的叙事节奏）。
3. **记录与现场**：录音、录像、笔记并重，注意访谈环境的安静与氛围营造，签署知情同意书。
4. **访谈后处理**：整理录音转写、核对事实、建立索引，形成可供研究的口述史料。<span class="marginnote">「倾听的艺术」是口述访谈的关键：讲述者常常偏离预设轨道，却可能说出最珍贵的记忆。好的访谈者知道何时追问、何时沉默——追问细节（「那天您穿的什么衣服？」）往往能唤起比抽象叙述更生动的回忆，这是口述方法最微妙的技巧。</span>

**辨析｜易错点：** 口述历史 ≠ 普通访谈，更 ≠ 新闻采访。普通访谈追求「当下的事实」，口述历史追求「记忆中的历史」——它关注的是讲述者如何理解与重构过去，而非简单地获取信息。同样，口述历史不是「随便聊聊」，它有系统的采集流程、学术规范与伦理要求。

## 3 口述历史档案的整理与保存

口述访谈的成果要成为**档案**，须经过规范的整理与保存：

**著录与编目**：为每份口述档案建立元数据——受访者信息、访谈时间地点、主题、时长、开放程度，纳入档案检索体系，见《档案检索与利用》。
**转写与全文整理**：把录音转写成文字稿，并标注时间码、疑问处与背景注释。转写稿与音视频原件互为参照，共同构成完整史料。
**数字保存**：口述档案多为音视频形态，须按数字保存规范长期保存，见《档案保管与保护》与《数字档案》。<span class="marginnote">口述档案的载体风险格外突出：录音带会消磁、光盘会氧化，而老一辈受访者的记忆正随时间流逝——「抢救记忆」是场与时间的赛跑。这也是为什么许多口述历史项目把「尽早采集、尽快数字化」作为第一原则。</span>
**伦理与权限**：口述档案涉及个人隐私与名誉，须明确受访者的授权范围——哪些内容可以公开、哪些须限制、哪些保密。知情同意书是口述档案伦理的法律基础。

## 4 口述历史的利用与争议

口述历史档案的价值在利用中显现：

**补充正史**：为文献记载薄弱的领域（底层生活、女性经验、少数民族历史）提供一手材料，让历史研究更完整。
**服务记忆工程**：重大历史事件的亲历者口述，构成社会记忆工程的核心资源，常与档案馆的专题库建设结合。
**公众历史与教育**：口述史料用于展览、纪录片、博物馆展陈，让历史「可听、可感」。

同时，口述历史有不可回避的争议，核心是**记忆的可靠性**：

**记忆的选择与重构**：人的记忆不是录像带，它会遗忘、美化、重构——几十年后的回忆常与事实有出入。
**叙事的立场**：讲述者会按当下的价值观重新解释过去，口述史提供的是「讲述者认为的历史」，而非「客观的历史」。
**个体记忆与集体记忆**：口述材料是个体视角，如何与文献互证、如何拼出集体图景，需要研究者的批判使用。<span class="marginnote">档案学界对口述历史的经典批评来自强调「原始记录」的学派：口述史料是访谈者与受访者共同「制造」的，不是自然形成的记录，因此不具备档案的「原生性」。回应是：口述历史的价值恰恰在于其「视角性」——它不冒充客观记录，而是如实保存「某个人在某个时刻如何讲述自己的过去」——这本身就是有价值的历史证据。</span>

## 5 核心对比表：口述档案与书面档案

| 维度 | 书面档案 | 口述档案 |
| --- | --- | --- |
| 形成方式 | 活动中自然形成 | 访谈采集、主动生产 |
| 内容形态 | 文字、图表记录 | 声音、影像+转写 |
| 记录视角 | 机构/官方视角为主 | 个人/亲历者视角 |
| 可靠性 | 靠原始性保真 | 靠方法规范与多源互证 |
| 保存难点 | 载体老化 | 载体老化+记忆消逝 |
| 核心价值 | 凭证价值 | 记忆价值与补充价值 |

## 6 案例：抗战口述历史——一场与时间赛跑的抢救

口述历史最典型的实践，是对重大历史事件亲历者的记忆抢救。抗日战争口述史是其中规模最大、也最具紧迫性的工程之一。

**为什么必须抢救**：抗战结束至今已近八十年，亲历者在世的已越来越少，且普遍高龄。每一位老兵的离世，都意味着一段无法复制的亲历记忆的消失——这是「人亡记忆在」的倒计时。史学界与档案馆因此把抗战口述史视为「抢救性工程」：**在记忆消散之前，把它采集、固定、保存下来**。

**实践方法**：抗战口述史项目遵循完整的方法论：

- **对象筛选**：优先访谈年事最高、经历最具代表性（不同战线、不同角色）的亲历者，兼顾老兵、受害者、见证者与后方的普通人。
- **长时访谈**：一次访谈往往持续数小时，从生平入手，聚焦战争经历的关键节点——入伍、战斗、转移、逃难、日常生活，追问具体细节。
- **多轮补访**：一次访谈常有遗漏，研究者随后回访补充；对记忆模糊处，用文献对照核实。
- **完整建档**：访谈的录音录像、转写稿、受访者授权书、访谈背景说明一并归档，形成规范的口述档案。

**采集成果的两重价值**：

- **史料价值**：口述为战争史提供了文献之外的第一手视角——个体如何经历战争、普通人的生存细节、官方档案缺失的层面。研究者需与档案文献**互证**：口述补充文献之缺，文献校正口述之偏。
- **记忆价值**：对受访者而言，讲述是被倾听、被尊重的过程；对公众而言，口述影像让历史「可听、可感」，是抗战记忆传承的载体——许多抗战口述项目同时服务于纪念馆展陈与学校教育。

**这个案例的口述史方法论启示**：

| 环节 | 要点 |
| --- | --- |
| 对象 | 年高者优先，具代表性 |
| 访谈 | 从生平切入、追问细节、容忍偏离 |
| 核实 | 与文献互证，区分「记忆」与「史实」 |
| 建档 | 音像+转写+授权+背景说明一体归档 |
| 利用 | 研究互证、展陈传播、记忆传承 |

**更深的思考**：抗战口述史的价值不只是「多了一些史料」，而是让历史叙事的主体发生了变化——战争不再只是「将军与战役」的叙事，而是亿万普通人的共同经历。这与口述历史「围绕人构建历史」的初衷完全一致：**当记忆被抢救下来，历史才不只是书写者的历史，而是所有人的历史**。这也让口述历史成为档案学与历史学交汇处最动人的实践。

## 7 小结

- 口述历史是通过**访谈采集、整理、保存亲历者记忆**的活动，兴起于 20 世纪中叶，与史学转向同步。
- 采集方法核心是**前期研究、访谈设计、现场记录、访谈后处理**，倾听与追问是其独特技巧。
- 口述档案须经**著录、转写、数字保存、伦理授权**才成为规范史料，是场与时间赛跑的抢救。
- 口述历史以**补充正史、服务记忆工程、公众教育**实现价值，但记忆的选择性使其必须与文献互证使用。
- 口述档案与书面档案在**形成方式、视角、可靠性、保存难点**上根本不同，二者互补构成完整的社会记忆。


### 延伸思考

1. 口述记忆「会选择、会重构」——口述史料的价值既然不等于「客观事实」，它还有什么用？
   （提示：它如实保存「某人如何讲述过去」，是记忆史与心态史的一手材料。）

2. 口述档案与书面档案「多源互证」时，遇到两者矛盾，应如何处理？
   （提示：先核书面档案的权威性，再考口述者的记忆条件，用第三源裁定，不轻信任何一方。）

3. 抗战口述史是「抢救性工程」，为什么说「时间」是口述历史最大的敌人？
   （提示：亲历者高龄离世即记忆消逝，采集必须在人尚在时完成，见案例。）

4. 知情同意书在口述档案中的意义是什么？没有授权，口述材料为什么不能随意公开？
   （提示：口述涉及个人隐私与名誉，授权界定公开范围，是口述档案伦理的法律基础。）
