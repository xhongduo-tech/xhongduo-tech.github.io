# 环境哲学

环境哲学以人与自然的关系及其伦理、美学与价值问题为研究对象，涵盖环境伦理、深层生态学、土地伦理、环境美学、自然哲学与气候伦理等分支。学完这个专题，就系统写完了从自然价值论与各伦理流派，到土地伦理、环境美学，再到气候正义与可持续伦理的完整环境哲学图景。

## 对标教材

- 奥尔多·利奥波德，《沙乡年鉴》，商务印书馆
- Andrew Light & Holmes Rolston III (eds.), "Environmental Ethics: An Anthology", Wiley-Blackwell, 2003
- 王正平，《环境哲学——环境伦理的跨学科研究》，上海人民出版社
