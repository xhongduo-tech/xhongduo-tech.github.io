# 证据、相关与因果

## 为什么从证据讲起

贝叶斯确证理论给出了「证据」的形式定义：$E$ 是 $H$ 的证据，当且仅当 $P(H\mid E) > P(H)$。但这个定义有一个巨大的陷阱——**概率提升只是相关，不是因果**。冰淇淋销量上升的夏天，溺水人数也上升：观察「溺水增多」确实提升了「冰淇淋卖得多」的概率，但没人会认为买冰淇淋导致溺水。<span class="marginnote">概率提升捕捉的是<strong>统计相关性</strong>：两个变量在概率上共变。因果关系则是更强的主张：<strong>干预其中一个会改变另一个</strong>。$P(\text{溺水}\mid\text{冰淇淋})$ 升高是真，但「干预冰淇淋销量」不会改变溺水率——证据与因果在此彻底分家。</span>

对「从极限到大模型」主线，这一篇是**因果推断的哲学前哨**。大模型在海量相关中发现模式，却分不清「症状」与「病因」；推荐系统优化的点击率是相关，用户的真实偏好才是因果。理解相关与因果的缝隙，你就理解了为什么「AI 不能只靠相关性」这句口号是认真的。

## 1 证据作为概率提升

先把「证据」这个正面概念钉牢。在贝叶斯框架里，$E$ 支持 $H$ 意味着**条件化后 $H$ 变可信**：

$$E \text{ 是 } H \text{ 的证据} \iff P(H \mid E) > P(H)$$

这个定义有三个优点：它**分级**（提升越多，证据越强）、**可比较**（两个证据哪个强，看提升幅度）、**可对偶**（$E$ 支持 $H$ 等价于 $E$ 削弱竞争假说）。<span class="marginnote">但这个定义说的是<strong>证据关系</strong>，不是<strong>因果方向</strong>。$E$ 支持 $H$ 只意味着「看见 $E$ 应该提高你对 $H$ 的信念」——至于「是 $H$ 造成 $E$」还是「$E$ 造成 $H$」还是「$Z$ 共同造成两者」，概率关系一概不区分。</span>这正是下一节的伏笔。

## 2 相关不是因果：混淆变量

**混淆变量（confounder）**是相关与因果之间最常见的裂缝：一个变量 $Z$ 同时影响 $E$ 与 $H$，使得 $E$ 与 $H$ 即使完全没有因果关系也高度相关。<span class="marginnote">经典的「伪相关」清单随手拈来：观测到「图书馆藏书量」与「学生成绩」正相关，可干预藏书量并不能提高成绩——真正起作用的是「学校的经费投入」这个共同原因。同理，冰淇淋与溺水共享「夏天」这个共同原因，消防车与火灾共享「火情」。</span>

**辨析｜易错点：** 相关性的形式定义并不犯错，犯错的是**推理**——把「$E$ 与 $H$ 相关」直接推出「$E$ 导致 $H$」。这一步是**非法的因果结论**。莱辛巴赫的**共同原因原则（the principle of the common cause）**给出一个正确的直觉：若 $E$、$H$ 相关且既非 $E$ 致 $H$ 也非 $H$ 致 $E$，则应存在一个共同原因 $Z$，使得在 $Z$ 的条件下 $E$ 与 $H$ 条件独立。这个原则至今仍是因果发现（从数据中挖因果结构）的哲学基石。

## 3 公式解析：辛普森悖论

相关与因果的裂缝，最锋利的表现是**辛普森悖论（Simpson's paradox）**：**总体上的相关方向，在按第三个变量分组的每一组内部，都可能反转。** 看一个真实发生过的药物试验：

| 组别 | 服药组（有效 / 总数） | 对照组（有效 / 总数） |
| --- | --- | --- |
| 男性 | 81 / 87 = 93.1% | 234 / 270 = 86.7% |
| 女性 | 192 / 263 = 73.0% | 55 / 80 = 68.8% |
| **合计** | **273 / 350 = 78.0%** | **289 / 350 = 82.6%** |

男性里服药更好（93.1% > 86.7%），女性里服药也更好（73.0% > 68.8%），但**合并起来对照组反而更好**（82.6% > 78.0%）！拆三步看：

**第一步，看数字**：男性组服药者少（87 人）、对照组多（270 人）；女性组正相反（263 vs 80）。**两组样本量不均衡**是悖论的第一个诱因。
**第二步，看权重**：合计有效率是组内有效率的**加权平均**，权重是各组人数。服药组里高有效率的那组（男性，93.1%）样本太少、权重太低，于是整体被拉低。
**第三步，看因果教训**：性别在这里是**混淆变量**——它同时影响「是否用药」与「是否有效」。辛普森悖论不是算术错误，而是告诉我们：**不对混淆变量分层，合并的相关可能撒谎**。<span class="marginnote">对辛普森悖论的最深刻解读来自因果推断学派（珀尔）：合并不该无条件进行，而要看「性别」在因果图里的位置。若性别是药物有效性的<strong>前因</strong>，就该分层看组内；若性别只是纯统计干扰，才可合并。<strong>「该合并还是该分层」是因果问题，不是纯统计问题</strong>——这正是把因果结构显式化（而不是只盯相关性）的根本动机。</span>

## 4 随机对照试验：打破混淆的黄金标准

既然观察性相关分不清因果，统计学的对策是**随机化（randomization）**。**随机对照试验（randomized controlled trial, RCT）**把受试者随机分到处理组与对照组：随机化保证了两组在**期望意义下**所有混淆变量（已知的与未知的）分布相同，于是两组结果的差异只能归因于处理本身。<span class="marginnote">随机化为什么强？它切断了所有「未知混淆变量 → 是否用药」的箭头。观察性研究里，医生倾向于把病情轻的病人用药、把重的病人不给药，这个选择偏差会污染相关；随机化把「是否用药」从「由病人特征决定」变成「由随机数决定」，混淆链就此断裂。</span>

**辨析｜易错点：** 随机化解决的是**混淆**，不解决**机会**。两组差异即使完全由随机造成，也可能非零——这就是频率派显著性检验存在的意义：RCT 加 p 值，先随机化切断混淆，再统计检验排除机会。把两者混为一谈，是临床试验误读的头号来源。

## 6 延伸思考：四个常见问题

**问 1：为什么相关不蕴含因果，但因果一定蕴含相关？**

如果 $X$ 导致 $Y$，那么 $X$ 的变化通常伴随 $Y$ 的变化，所以因果会表现为相关（除非被恰好抵消）。反过来，相关可能是混淆、巧合或反向因果造成的。所以相关是因果的**必要不充分**信号——这就是「相关是线索，不是证据」的含义。

**问 2：辛普森悖论里的药物到底有没有效？**

看因果结构。如果「性别」是影响用药与疗效的共同前因（男女患病率不同、用药偏好不同），那正确结论是**分层看**：药物在男、女组内都有效。合并的负面结果是被样本量不均衡「伪造」的。因果推断学派会说：把「性别」当作需要控制的变量，而不是当作要合并的噪声。

**问 3：观察性研究能建立因果吗？**

能，但要付出代价。现代观察性因果推断（工具变量、断点回归、倾向得分匹配、孟德尔随机化）都试图在「没有随机化」的情况下重建反事实。它们的前提比 RCT 更脆弱——每个方法都依赖一组可检验但不可证明的假设。哲学上，这正是「相关到因果」的鸿沟有多深的证明。

**问 4：大模型生成的内容是「因果」还是「相关」？**

模型学到的是训练数据里的**统计相关**结构，不是世界里的**因果**结构（除非因果恰好编码在相关里）。这就是为什么模型会给出「冰淇淋导致溺水」式的合理但错误的关联。把模型输出当因果知识，是当前 AI 使用中最危险的错误之一。

## 7 案例一览：相关与因果的四组对照

| 场景 | 相关存在？ | 因果成立？ | 关键机制 |
| --- | --- | --- | --- |
| 冰淇淋销量 × 溺水人数 | 是 | 否 | 共同原因：夏天 |
| 吸烟 × 肺癌 | 是 | 是 | RCT / 队列研究确认 |
| 图书馆藏书量 × 学生成绩 | 是 | 否 | 共同原因：学校经费 |
| 随机试验中药物 × 康复 | 是 | 是 | 随机化切断混淆 |

这组对照是把本章概念一次性落地的速查表：凡是「相关存在但因果不成立」的场景，背后几乎都藏着一个共同原因或反向因果。识别它的第一步，就是问一句：**有没有第三个变量同时解释了两边？**

## 8 延伸：与「从极限到大模型」的连接

从推荐系统到医疗 AI，最大的失败模式都是把相关当因果：推荐系统优化的「点击」不一定是「喜爱」，医疗模型学到的「症状相关」不一定是「病因」。因果推断（第四级《因果推断》）正是在这里补课。

大模型尤其危险：它在语言上会「流利地编造因果」，把纯统计关联叙述成因果故事。读懂这一篇的哲学红线，你就拥有了判断「AI 在讲因果还是讲相关」的基本警觉。

更进一步，因果结构是可以显式画出来的：节点是变量、箭头是因果。现代的因果发现与因果推断把「从相关里识别因果」变成了可计算的程序，但它们的全部合法性都建立在「哪些假设被诚实声明」之上——这正是莱辛巴赫共同原因原则的现代工程化。

## 9 小结

- **证据 = 概率提升**：$P(H\mid E) > P(H)$；但概率提升只捕捉相关，不捕捉因果。
- **相关 ≠ 因果**，最常见的裂缝是**混淆变量** $Z$ 同时影响 $E$ 与 $H$
