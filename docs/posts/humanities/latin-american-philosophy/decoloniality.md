## 为什么从去殖民性思潮开始

这是本专题的收束，也是拉美思想在二十一世纪贡献给全球学术界影响最大的一支：**去殖民性（decoloniality）思潮**。<span class="marginnote">「decoloniality」常被译为「去殖民性」，以区别于针对政治独立的「非殖民化」（decolonization）。它针对的不是已经结束的政治殖民，而是仍然存活于知识、权力与存在结构中的「殖民性」。</span>两位对标教材成书于 2002–2004 年，早于这场思潮的全球爆发，但它们的主题——拉美思想、身份、解放——恰恰是去殖民性的直接母体，故本节为延伸讨论。

整个专题在此汇流：殖民经院的「合法性」问题、正常性之争的「主体性」问题、解放哲学的「他者」、依赖理论的「中心—外围」、马里亚特吉的「本土创造」——这一切最终在去殖民性这里凝聚成一个总命题：**现代性如何与殖民性同构，而边缘又如何从这套结构中「脱离」出来。**

读这一节前，先建立一个清醒的认识：**去殖民性不是「反西方」，而是「反西方中心」**。它的目标不是否定欧洲文明的价值，而是拆解一套让「欧洲 = 唯一标准」的支配结构，让被压制的知识、主体与文明恢复发言权。混淆这两者，就会把一场深刻的批判误读成简单的敌意。

从课程体系看，这一节是本博客「后殖民研究与去殖民性」层级在拉美语境下的主阵地，也与「科学哲学」「认识论」层级直接对话——因为它问的是：**被我们当作「客观知识」的东西，其出生证上是否印着「欧洲」二字？** 这是当代知识论最前沿也最激烈的追问。

## 1 殖民性不是殖民主义的残余

去殖民性的奠基概念来自秘鲁社会学家 **阿尼瓦尔 · 基哈诺（Aníbal Quijano，1928–2018）** 在 1990 年代提出的 **「殖民性权力」（colonialidad del poder）**。

基哈诺的洞见是：殖民主义作为政治制度已经结束，但殖民主义所建立的**支配结构**——按种族划分劳动、知识与文明等级——依然延续到今天。他称之为「殖民性」：**一个持续的、深层的权力矩阵，它把世界组织成「欧洲中心 + 被殖民的外围」的等级秩序**。这套矩阵不仅分配财富，更分配「谁算人、谁算知识」。<span class="marginnote">基哈诺深受马里亚特吉影响（见本专题「Mariátegui 与印第安主义」一节），但把「印第安问题」从经济分析扩展到整个现代权力的认识论结构。「殖民性权力」概念是去殖民性运动的原子核。</span>

**重点**：殖民性 ≠ 殖民主义。殖民主义是历史上的一段时期；殖民性是一种仍在我辈身上运作的结构。这个区分，是整个去殖民性思想的第一块基石。

基哈诺还把「殖民性」具体拆成了几个相互支撑的维度：**权力的殖民性**（按种族分配支配权）、**知识的殖民性**（欧洲知识被设为唯一标准）、**存在的殖民性**（某些人群被剥夺「被视为人」的资格）。这三个维度合起来，就是米尼奥洛后来概括的「殖民性矩阵」——它不是历史遗物，而是当代世界的活结构。

卢贡内斯后来补充了**性别的殖民性**，构成第四个维度。这套「矩阵」思维的价值在于：它说明去殖民性不只是政治口号，而是一套可以分析具体制度（种族、知识、存在、性别）的分析工具——这正是它能在全球学术界迅速扩散的原因。

## 2 现代性/殖民性：一枚硬币的两面

基哈诺与合作者（杜塞尔、米尼奥洛、卡斯特罗-戈麦斯等，合称「现代性/殖民性」研究群体）提出了第二个核心命题：**现代性与殖民性是同一过程的两个面，不可分离。**

「现代性」不是欧洲独立发明后「传播」给世界的；它恰恰是通过殖民美洲才得以成立的。杜塞尔早已指出：没有美洲这个「被遮蔽的他者」，就没有欧洲的自我形象。米尼奥洛进一步说：欧洲的「文艺复兴」「启蒙」「进步」叙事，其另一面正是美洲与非洲的被殖民、被奴役、被命为「野蛮」。<span class="marginnote">米尼奥洛（生于 1941 年，阿根廷）1995 年出版《文艺复兴的阴暗面》，2000 年出版《地方历史/全球设计》，2005 年出版《拉丁美洲的观念》。他提出「认识论的位移」（delinking）：「脱离」不是反对现代性，而是脱离现代性预设的唯一认识论坐标。</span>因此，谈论「现代性」而不谈殖民，等于只看硬币的一面。

**辨析｜易错点**：「现代性/殖民性同构」不是说「现代性 = 坏事」。它说的是：现代性作为历史过程，其进步的一面（科学、人权、启蒙理想）与压迫的一面（殖民、种族主义、奴役）是同一进程的两面，不可割裂地「择其善者」。去殖民性的目标是重新构想一种不再以殖民为前提的现代性——杜塞尔称之为**「跨现代性」（transmodernidad）**，米尼奥洛称之为**「多元宇宙」（pluriversalidad）**。

## 3 核心对比表：去殖民性 vs 后殖民主义

去殖民性常与「后殖民主义」（postcolonialism）混为一谈，实则两者有重要分工：

| 维度 | 后殖民主义 | 去殖民性 |
| --- | --- | --- |
| 地理源头 | 英法殖民世界（南亚、非洲、加勒比） | 拉丁美洲（西班牙/葡萄牙殖民） |
| 代表 | 萨义德、斯皮瓦克、巴巴 | 基哈诺、米尼奥洛、杜塞尔、卢贡内斯 |
| 聚焦 | 文本、话语、文化表征 | 知识结构、权力矩阵、认识论 |
| 关键概念 | 他者、混杂（hybridity）、庶民 | 殖民性、认识论脱离、多元宇宙 |
| 批判对象 | 东方主义话语 | 现代性/殖民性结构 |

**核心要点**：后殖民主义长于「拆解文本中的殖民话语」，去殖民性长于「拆解知识本身的殖民地基」。二者互补而非对立。去殖民性的独特武器是「认识论的南方」——承认被殖民者的知识也是知识，而非等待欧洲认可。

还有一个常被忽视的差异：后殖民主义更多诞生于英法殖民世界（南亚、非洲、加勒比），与「东方学」「庶民研究」联系密切；去殖民性则扎根于西葡殖民世界（拉美），直接继承的是拉美自身的批判传统——解放哲学、依赖理论、马里亚特吉。**去殖民性因此是一种「从拉美内部长出来的」批判，而不是从外部进口的标签。**

## 4 去殖民性的扩展：性别、认识论与全球南方

进入二十一世纪，去殖民性从权力扩展到性别与认识论。

**玛丽亚 · 卢贡内斯（María Lugones，1944–2020）** 提出 **「殖民性性别」（colonialidad de género）**：殖民者把欧洲的性别二元与等级强加给原住民，原住民原有的性别/亲属体系被摧毁。她的「去殖民女性主义」要求同时反抗种族、性别与殖民三重压迫。<span class="marginnote">卢贡内斯生于阿根廷，长期任教于美国宾汉姆顿大学。她的《去殖民女性主义》（2010）把「交叉性」推进到殖民结构的层面。</span>

**认识论南方**：葡萄牙社会学家 **博阿文图拉 · 德 · 苏萨 · 桑托斯（Boaventura de Sousa Santos）** 提出「南方的认识论」与「批判性认识论」，主张收集被现代性压制的知识形式。**拉蒙 · 格罗斯福格尔（Ramón Grosfoguel）** 则把去殖民性接回世界体系分析，强调「知识的地缘政治」——知识不产生于真空中，而是产生于特定的权力位置。

**哥伦比亚学派**也不可忽视：**圣地亚哥 · 卡斯特罗-戈麦斯（Santiago Castro-Gómez）** 在《零点之傲慢》（2005）中分析「零点之点」（hybris del punto cero）——欧洲知识假装自己站在「无立场」的零点俯视世界，而这一姿态本身正是殖民性的标志。他的批判直指「客观性」话语背后的权力。

**争议**：去殖民性也面临批评——有学者指其过度抽象、忽视阶级斗争与国家问题；也有学者批评「学院去殖民性」沦为美国大学里的时髦话语。但这些批评本身，正说明这场思潮的活力。

## 5 去殖民性的谱系：从法农到现代性/殖民性群体

去殖民性并非凭空出现，它有一串明确的思想祖先。**弗朗茨 · 法农（Frantz Fanon，1925–1961）** 的《大地上的受苦者》（1961）与《黑皮肤，白面具》（1952）早已把「殖民造成的心理创伤」与「暴力与解放」放上桌面；**艾梅 · 塞泽尔（Aimé Césaire）** 的《论殖民主义》（1950）则提出「殖民既贬低被殖民者，也贬低殖民者」的著名判断。<span class="marginnote">法农出身马提尼克（加勒比），却长期在阿尔及利亚参与反殖运动，是「第三世界」解放思想的跨洋枢纽。他的「他者」「创伤」「暴力」分析，直接启发了后来所有去殖民理论。</span>

把这些前辈组织成当代「现代性/殖民性」群体的，是 1990 年代末一批拉美学者：基哈诺、杜塞尔、米尼奥洛、卡斯特罗-戈麦斯、卢贡内斯等。他们经常在博尔达（哥伦比亚）的研讨会上聚首，逐渐形成「现代性/殖民性」研究圈。**去殖民性不是一个人的发明，而是一场集体的重新起跑**——它把散落在殖民经院、解放哲学、依赖理论里的问题，统一到一个新概念框架下。

**重点**：去殖民性的谱系提醒我们，它是本专题全部线索的总收束——殖民经院的「合法性」、解放哲学的「他者」、依赖理论的「中心—外围」、马里亚特吉的「本土创造」，在这里第一次被整合成一套完整的理论语言。

## 6 术语速查表

这一节把去殖民性的核心术语集中列出。

| 术语 | 含义 |
| --- | --- |
| 殖民性（colonialidad） | 延续至今的殖民支配结构，区别于历史上的殖民主义 |
| 殖民性权力 | 基哈诺：按种族分配支配权的权力矩阵 |
| 现代性/殖民性 | 现代性与殖民性是一枚硬币的两面 |
| 认识论脱离（delinking） | 米尼奥洛：脱离欧洲唯一认识论坐标 |
| 多元宇宙（pluriversalidad） | 承认多个文明、知识体系并存的世界观 |
| 殖民性性别 | 卢贡内斯：殖民者强加的性别等级与二元 |
| 认识论南方 | 桑托斯：被现代性压制的南方知识体系 |
| 零点之点（hybris del punto cero） | 卡斯特罗-戈麦斯：欧洲知识假装无立场的姿态 |
| 跨现代性（transmodernidad） | 杜塞尔：不再以殖民为前提的现代性构想 |
| 殖民性矩阵 | 米尼奥洛：权力、知识、存在、性别多维的殖民结构 |
| 非殖民化（decolonización） | 政治独立的历史过程，区别于认识论的去殖民性 |
| 全球南方（Global South） | 被边缘化的世界地区，去殖民性研究的关注对象 |

**一句话记忆**：去殖民性 = 基哈诺的「殖民性权力」+ 米尼奥洛的「认识论脱离」+ 杜塞尔的「跨现代性」+ 卢贡内斯的「殖民性性别」，合起来就是「从现代性/殖民性结构中脱离」。

## 7 小结

- 去殖民性以基哈诺的「殖民性权力」为奠基：殖民性 ≠ 殖民主义，而是延续至今的支配结构。
- 「现代性/殖民性」同构命题：现代性借殖民才成立，殖民是现代性的阴暗面。
- 米尼奥洛的「认识论脱离」（delinking）主张脱离欧洲唯一认识论坐标。
- 去殖民性（认识论、知识结构）与后殖民主义（话语、文本）分工互补。
- 卢贡内斯的「殖民性性别」与「认识论南方」把去殖民性扩展到性别与全球知识版图。
- 去殖民性不是「反西方」，而是「反西方中心」——目标是让被压制的知识与文明恢复发言权。
- 基哈诺把殖民性拆成权力、知识、存在三维，米尼奥洛称之为「殖民性矩阵」。
- 去殖民性的谱系从法农、塞泽尔延伸到现代性/殖民性群体，是本专题全部线索的总收束。
- 争议（过度抽象、学院化）恰恰证明这场思潮的活力，而非它的衰落。
- 卡斯特罗-戈麦斯「零点之点」的批判直指「客观性」话语背后的权力，与认识论层级直接对话。
- 去殖民性问的是一个根本问题：被我们当作「客观知识」的东西，其出生证上是否印着「欧洲」二字。
- 「殖民性矩阵」把去殖民性变成可分析具体制度的工具（权力、知识、存在、性别）。
- 去殖民性从拉美内部长出来的批判传统，直接继承了解放哲学、依赖理论与马里亚特吉。

至此，我们从殖民经院一路走到去殖民性，走完了拉丁美洲哲学五百年的自我追问。这条线索的终点也是起点：从「美洲有没有哲学」到「现代性如何被殖民性建构」，拉美哲学反复证明了一件事——**边缘的思想，可以反过来照亮中心**。这正是「从极限到大模型」这座知识之山，为「理解人类如何自我理解」留下的一块不可替代的基石。
