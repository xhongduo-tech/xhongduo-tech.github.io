## 为什么从解放哲学开始

「正常性」之争问的是拉美哲学「够不够格」，存在主义问的是「我们是谁」。到了 **恩里克 · 杜塞尔（Enrique Dussel，1934–2023）**，问题被彻底重写：**哲学不是解释处境的学问，而是参与解放的行动。**<span class="marginnote">杜塞尔生于阿根廷门多萨，1969 年因在墨西哥城主持解放神学与哲学讨论而闻名，1973 年遭阿根廷右翼威胁后流亡墨西哥，任教于墨西哥城自治大学（UAM-Iztapalapa）。Gracia 读本第四部分 B 收有他的《解放哲学》选段。</span>

解放哲学（filosofía de la liberación）诞生于 1970 年代阿根廷一个激进的哲学圈，杜塞尔是灵魂人物。它直接反对西方哲学的「总体性」叙事，也直接回应本专题前几节的积累：实证主义的「向西看」、正常性之争的主体性问题、存在主义的处境反思，都在杜塞尔这里汇聚成一场对「欧洲中心主义」的正面总攻。

杜塞尔本人值得先认识一下。他生于阿根廷门多萨，青年时旅居欧洲，在德国与法国系统学习哲学与神学，1957 年在马德里获得哲学博士学位。他早年的专业是伦理学史与神学，写过关于谢林、阿奎那的著作——这意味着，他的「解放哲学」不是空中楼阁，而是对欧洲哲学（尤其是列维纳斯与马克思）长期研读之后的蓄力爆发。<span class="marginnote">杜塞尔一生著作等身：从《拉丁美洲解放伦理》（1973）、《解放哲学》（1977），到《被遮蔽的他者》（1992）、《全球化与排斥时代的解放伦理》（1998）与晚年《解放政治》（2007–2009），跨度超过五十年。</span>

1973 年，杜塞尔因参与解放神学与哲学的公开讨论而声名鹊起；1975 年，在经历阿根廷右翼的死亡威胁后，他流亡墨西哥，任教于墨西哥城自治大学（UAM-Iztapalapa）。**他的「他者」哲学，是在自己被国家机器视为「他者」之后写出的**——这一点，让他的理论从一开始就带着切身的重量。

**一句话定位**：如果把前面几节比作「给拉美哲学照镜子」，那么解放哲学就是「把这面镜子打碎」——因为它质问的不是「我们照得像不像」，而是「这面镜子本身是谁做的、为谁做的」。从这一节开始，拉美哲学进入了对西方哲学「合法性」本身的全面审查。

## 1 列维纳斯的关键一步：他者的哲学

要理解杜塞尔，必须先理解他的哲学源头：法国哲学家 **埃马纽埃尔 · 列维纳斯（Emmanuel Levinas，1906–1995）**。

列维纳斯在《总体与无限》（1961）中提出一个惊人的命题：**西方哲学从巴门尼德到黑格尔，一直是「总体性」（totalité）的哲学——它把一切差异收编进同一个自我同一的体系。** 但这个体系总有一个残留物：**他者（l'Autre）**。他者是无法被概念收编的「脸」（visage），它向我发出「你不可杀我」的无言命令，把我从自我中心中唤醒。<span class="marginnote">列维纳斯是立陶宛裔犹太人，曾亲历纳粹集中营。他的「他者哲学」是对欧洲总体性思想最深刻的伦理批判。杜塞尔把他从伦理层面接到政治与历史层面：欧洲总体性的「他者」，就是被殖民、被边缘化的拉美与第三世界。</span>

「脸」这个意象值得细想。列维纳斯说的「脸」不是五官，而是「他者的显象」——一种无言的呼求：你不要杀死我、不要把我归入你的计划。它先于一切概念、一切范畴，是伦理的原初事件。对杜塞尔而言，「脸」就是穷人、被征服者、被遗忘者——他们的存在本身，就先于任何「文明—野蛮」的命名。

杜塞尔的解放即从这一步开始：**西方现代性就是一个巨大的「总体」——它以自己的理性、历史、进步叙事吞并一切。而被它遮蔽的「他者」，正是受苦的、贫穷的、被排除的拉美人民。**

为什么列维纳斯对拉美如此有吸引力？因为列维纳斯把「他者」放在一切哲学的第一位，而拉美的整个历史经验——被征服、被命名、被排除出「文明」的叙事——恰好就是「被当作他者」的历史。欧洲哲学家可以把「他者之脸」当作一个伦理概念来思考；拉美哲学家却每一天都生活在这张「脸」被漠视的现实里。这就是为什么列维纳斯在拉美引发的反响远大于在欧美——**他者的哲学，需要一个真正知道自己「被当作他者」的读者群**。

## 2 现代性的神话与「遮蔽他者」

杜塞尔在《被遮蔽的他者》（1992）与《发明美洲》中给出了他的核心历史哲学：**1492 不是现代性的开端，而是「遮蔽他者」的开端。**

西方现代性的自我叙事是：欧洲代表理性与文明，美洲是「待开化的新大陆」。杜塞尔指出这套叙事是**「现代性神话」（el mito de la modernidad）**：它以「文明人」自居，把美洲人民命名为「野蛮人」，从而为征服、奴役与殖民辩护。<span class="marginnote">杜塞尔把这套神话拆成四步：文明自居 → 把对方命名为野蛮 → 以「教化」为名施暴 → 把受害者的反抗称作「野蛮的抵抗」。这套「现代性神话」分析后来成为整个去殖民性运动的奠基石。</span>由此，现代性不是「中性进步」，而是一个把「他者」逐出历史之外的历史过程。

这里要特别注意杜塞尔的一个反直觉主张：**美洲不是「前现代」的，而是「同时代被建构的他者」。** 欧洲的现代性不是先在欧洲成熟、再「传播」给美洲；恰恰相反，没有美洲这个被命名的「野蛮」，欧洲的「文明」自我形象根本无从建立。也就是说，现代性的历史是一枚硬币的两面——一面上写着「启蒙、理性、进步」，另一面写着「征服、奴役、遮蔽」。

**重点**：杜塞尔的转向，是把「发现美洲」重新讲成「遮蔽他者」。现代性的进步叙事每前进一步，都有一个被吞没的他者作代价。这个视角直接否定了拉美哲学「向西看」的全部历史——也为我们本专题末节「去殖民性」的「现代性/殖民性同构」命题，提前埋好了引线。

## 3 核心对比表：辩证法 vs 分析辩证法

杜塞尔认为，要走出总体性，单靠黑格尔式的**辩证法（dialéctica）**不够——因为辩证法最终在「合题」中把差异吸收回同一。他提出 **「分析辩证法」（analéctica）** 作为替代。

| 维度 | 辩证法（dialéctica） | 分析辩证法（analéctica） |
| --- | --- | --- |
| 过程 | 正题 → 反题 → 合题 | 同者面对他者 → 他者炸开总体 |
| 终点 | 合题（吸收差异） | 对他者的倾听与责任 |
| 主体 | 自我意识 | 被遮蔽的受苦者 |
| 哲学姿态 | 解释世界 | 参与解放 |
| 代表 | 黑格尔、马克思（杜塞尔解读） | 杜塞尔、列维纳斯 |

**核心要点**：辩证法的合题总会吞掉他者；分析辩证法则让「他者之脸」成为不可还原的第一义。哲学的任务不再是建立更完备的体系，而是对他者说「我在此，我对你负责」。

**辨析｜易错点**：杜塞尔并不反对辩证法，而是反对把辩证法当「唯一的」与「终点的」方法。马克思的辩证法被他高度尊重，但在他看来，历史唯物主义对阶级的分析仍可能停留在「总体」内部——穷人不只是「无产阶级」这个范畴，更是「他者之脸」。所以分析辩证法不是辩证法的替代，而是辩证法的「外在补充」：提醒它，总有一个无法被合题吸收的剩余。

## 4 解放伦理与「生命优先」

杜塞尔没有停在形而上学，而是把它落实为一套**解放伦理（ética de la liberación）**。1998 年出版的《全球化与排斥时代的解放伦理》是其集大成之作。

解放伦理的出发点不是抽象义务，而是**一个先于一切规范的元规范：生命优先**。当数百万拉美人因贫困、饥饿与结构性排斥而丧失生命时，任何不回应这一现实的伦理学都是空转。<span class="marginnote">杜塞尔晚年还发展了「跨现代性」（transmodernidad）概念：未来的文明不是西方现代性的普世化，而是各文明对自身传统的重新激活与对话——这是他对「现代性之后」的正面构想。</span>据此，杜塞尔晚年转向政治哲学，写了《政治的 20 条论纲》（2006）与《解放政治》（2007–2009），主张把「人民」建构为抵抗主体的政治工程。

**解放伦理的逻辑链条**可以这样压缩：生命优先 → 否定了压迫 → 压迫来自结构 → 结构靠他者维持又排斥他者 → 因此伦理实践 = 对他者的责任行动。这条链条每走一步都指向现实：不是「道德直觉」，而是「对受苦的回应」。这也是杜塞尔与绝大多数欧洲伦理学的分水岭——**他的伦理学不是关于「我应该成为什么」，而是关于「他者正在遭受什么」**。

由此，杜塞尔的伦理带有强烈的「程序性」：它不预设一套具体的规范清单，而是要求每一个处境中的行动者，从「他者的生命」出发去批判与重建规范。这使他既区别于功利主义（不看总量，看具体的他者），也区别于义务论（不看抽象义务，看具体的苦难）。**杜塞尔要的不是「更好的道德体系」，而是一种「让伦理学重新开始的方式」。**

## 5 解放哲学的运动史：一场没有总部的运动

解放哲学不是杜塞尔一个人的书斋事业。1970 年代初，阿根廷布宜诺斯艾利斯一批年轻哲学家——杜塞尔、奥斯卡 · 德尔巴罗（Oscar del Barco）、阿图罗 · 罗伊格（Arturo Roig）等——聚在一起，讨论一套「从第三世界出发」的哲学。这场聚会后来被称为「解放哲学」运动的开端。<span class="marginnote">这场运动与当时的政治背景血肉相连：阿根廷正经历军事独裁与镇压（1976 年后尤烈），「哲学为何而做」这个问题在血与火面前变得不再抽象。多名参与者随后流亡，运动也因路线分歧（对马克思、对革命的看法不同）而分化。</span>

运动内部后来分裂成几条路线：杜塞尔坚持「他者—伦理」的路向；另一些人转向更贴近马克思主义的「人民—实践」路向；还有一些人回归学院的纯学术。**这场分裂说明：解放哲学从一开始就不是一个学派，而是一个问题域**——它共同面对的问题是「哲学与解放的关系」，答案却千差万别。<span class="marginnote">杜塞尔后来回顾这场运动时说，最重要的不是统一答案，而是「把第三世界的哲学问题摆上桌面」。这一自我定位，使解放哲学具有了超乎学派之上的持久影响力。</span>

**重点**：解放哲学的运动史提醒我们，思想的诞生常常是群体的、情境的、有分歧的。读懂杜塞尔，最好同时读懂他身边的争论与分化——正如读懂「正常性」之争，要看塞亚与萨拉萨尔·邦迪的对峙一样。

## 6 术语速查表

这一节把解放哲学的核心术语集中列出。

| 术语 | 含义 |
| --- | --- |
| 总体性（totalidad） | 西方哲学把一切差异收编进同一体系的倾向 |
| 他者（el Otro） | 无法被总体收编的受苦者，杜塞尔的伦理起点 |
| 分析辩证法（analéctica） | 以「倾听他者」取代「吸收合题」的方法 |
| 现代性神话 | 杜塞尔对「文明—野蛮」叙事的结构性批判 |
| 生命优先 | 解放伦理的元规范 |
| 跨现代性（transmodernidad） | 杜塞尔对各文明对话式未来的构想 |
| 解放伦理（ética de la liberación） | 从受苦者出发的伦理学体系 |
| 脸（visage） | 列维纳斯：他者显象发出的「你不可杀我」的无言呼求 |
| 第三世界（Tercer Mundo） | 杜塞尔用来指称被现代性边缘化的世界 |
| 解放（liberación） | 既指政治解放，也指认识论与伦理意义上的从总体中挣脱 |
| 遮蔽（encubrimiento） | 杜塞尔描述现代性把「他者」逐出历史的方式 |

**一句话记忆**：解放哲学 = 列维纳斯的「他者」+ 马克思的「实践」+ 拉美的「受苦现实」，三者合一就是「对他者的责任」。

## 7 小结

- 解放哲学由杜塞尔在 1970 年代阿根廷开创，核心是批判西方现代性的「总体性」。
- 哲学源头是列维纳斯的「他者哲学」：他者是不可被总体收编的脸。
- 杜塞尔把 1492 重述为「遮蔽他者」，以「现代性神话」拆解欧洲进步叙事。
- 「分析辩证法」以「倾听他者」取代辩证法的「吸收合题」。
- 解放伦理以「生命优先」为元规范，晚年发展为跨现代性与解放政治。
- 杜塞尔本人的流亡经历使其「他者」哲学带有切身的重量，而非抽象学理。
- 解放哲学是一场多声部的运动而非单一学派，其内部分歧（伦理路向 vs 实践路向）正是其活力的证明。
- 解放伦理的逻辑链条「生命优先 → 否定压迫 → 回应他者」，是它与欧洲伦理学最清晰的分水岭。
- 「分析辩证法」不是取代辩证法的否定，而是它的「外在补充」——提醒辩证法总有一个吸收不了的剩余。
- 解放哲学的对标落点：Gracia 读本第四部分 B 的杜塞尔选段，正是「历史」主题下解放哲学的代表文本。
- 杜塞尔的伦理是一种「让伦理学重新开始的方式」：不预设规范清单，而从具体他者的生命出发批判与重建规范。
- 列维纳斯「脸」的意象被杜塞尔落实为穷人、被征服者与被遗忘者的存在本身。

在下一节，我们将看到一个与杜塞尔同时兴起的姊妹运动：解放神学——它把「他者」「解放」的词汇放回神学语境，追问信仰与穷人处境的关系。
