# 实用主义

实用主义是与英美分析哲学、欧洲大陆哲学并列的第三大哲学传统，由皮尔士创立、詹姆斯与杜威发扬光大，其核心主张是：信念的意义在于可感觉的行动后果，真理与知识服务于探究、实践与改善经验。按三套权威文献，从奠基性文本到当代复兴，系统梳理这一传统从反笛卡尔主义到新实用主义的完整谱系。

## 对标教材

- 威廉·詹姆斯，《实用主义》，商务印书馆
- Robert B. Talisse & Scott Aikin (eds.), *The Pragmatism Reader*, Princeton University Press, 2011
- 约翰·杜威，《确定性的寻求》，上海人民出版社
