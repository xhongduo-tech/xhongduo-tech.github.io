## 为什么逻辑常项是逻辑哲学的铰链

回顾前几篇，我们发现一个尴尬的循环：逻辑真理用「逻辑常项 vs 非逻辑词项」的分界来定义（第8篇），逻辑后果也用这个分界来定义（第11篇），可**「逻辑常项」本身是谁来定义的？
** 如果它是逻辑的中心概念，就不能再用逻辑来定义——否则就循环了。
<span class="marginnote">这个「循环性指控」不是吹毛求疵：蒯因的逻辑真理定义说「对非逻辑词项代换不变」，可「哪些词是非逻辑的」必须预先给定。
逻辑常项划界问题因此是逻辑哲学真正的铰链——所有其他定义都挂在它上面。
</span>

与此同时，逻辑主义的还原策略（第10篇）也依赖常项概念：逻辑主义说「数学 = 逻辑 + 定义」，可「逻辑」到底是哪几个符号？
若逻辑常项清单无限扩张，逻辑主义就偷懒了。
本篇把常项问题单独拎出来：它凭什么重要、有哪些刻画方案、以及它如何反作用于逻辑主义的成败。

## 1 逻辑常项问题

**逻辑常项（logical constant）**：指逻辑形式中固定不变、不可代换的词汇——经典一阶逻辑里的 `∧`、`∨`、`¬`、`→`、`∀`、`∃`、`=`，以及语法辅助符。
它们是逻辑真理与逻辑后果的「锚点」，而所有描述性词项（`红`、`在…附近`、`苏格拉底`）都是可代换的「变项」。

常项问题问的是：**凭什么这些词是常项？
** 三个候选答案各有不足：

1. **语法标准**：常项是「不变的部分」。
可「不变」取决于我们选择哪种语言——换个语言，常项清单就变了，无法说明常项的特殊地位。
2. **主题中立性（topic neutrality）**：常项对任何主题都适用，`且` 在谈论物理时和谈论美食时一样工作。
但这只是描述了常项的特征，没有解释为什么是它们。
3. **形式标准**：常项是「纯形式的」。
可「形式」与「内容」的分界正是常项问题本身，用「形式」定义常项又在循环。

常项问题之所以难，是因为它要求**在逻辑内部给逻辑的关键词找一个外部立足点**——而所有立足点似乎都已经偷偷用了逻辑。
<span class="marginnote">辨析｜易错点：别把「逻辑常项」与「逻辑连接词」画等号。
连接词（∧、∨、¬）只是常项的一部分；量词、同一性符号也是常项。
「是否把 `=` 算作逻辑常项」直接决定数学结构理论里哪些句子算逻辑真理——同一性问题的哲学分量正在于此，本专题第21篇会展开。
</span>

## 2 两种刻画方案：句法与语义

历史上最有力的两种常项刻画，恰好对应语法与语义两条路线：

**句法刻画（公理化方案）**：逻辑常项就是形式系统里「固定语法地位」的词——它们在公理模式与推理规则中被指名。
例如分离规则（modus ponens）指名了 `→`；全称实例化规则指名了 `∀`。
常项由它们在证明论中的角色界定。
<span class="marginnote">这个方案的优势是显式：打开一本数理逻辑教材，常项就写在语法的开头。
但它是「由惯例指定」而非「由原则导出」——换一套公理就换一套常项，无法解释为什么经典逻辑挑了这六个词。
</span>

**语义刻画（不变性方案）**：逻辑常项是对「底层的置换」保持不变的运算。
塔斯基与林登鲍姆（Lindenbaum）提出，后来又经谢尔（Sher）、麦基（McGee）发展：**逻辑常项是那些在论域的任意置换下保持不变的对象**——`∀` 与 `∃` 在论域置换下不变（「所有」不因元素改名而改变），而「红」就变了（改名后红对象可能全换掉）。

$$
\text{逻辑常项 } C \iff \forall \pi \in \text{Perm}(D):\ \pi(C) = C
$$

这条定义的哲学吸引力在于：**逻辑常项被刻画为对「对象是谁」无动于衷的运算**——它们只看见结构，看不见内容。
这完美匹配逻辑真理的「无信息性」特征。
<span class="marginnote">谢尔的著名推论：按不变性标准，「量词『存在无限多个』」也是逻辑常项——因为它对置换不变。
这意味着逻辑常项清单比经典逻辑宽得多，甚至包含高阶量词。
这个结论挑战了「逻辑就是一阶逻辑」的默认假设，让常项问题直接通向二阶逻辑与逻辑扩张的争论（本专题第16篇）。
</span>

## 3 公式解析：不变性标准的机制

不变性标准看似抽象，机制其实简单。
我们用一个二元关系词举例，看它是否通过「置换不变」测试：

$$
R \text{ 是逻辑的} \iff \text{对任意双射 } \pi: D \to D,\ \ R = \pi(R)
$$

- **第一步，读符号**：`π` 是论域 `D` 到自身的双射（置换）——一个「给对象改名」的操作。`π(R)` 是把关系 R 中所有对象替换为新名字后得到的关系。
- **第二步，看条件**：`R = π(R)` 说「R 在改名后保持不变」。改名不改结构，只改名字——如果 R 对名字无动于衷，它就是逻辑的。
- **第三步，看实例**：`∀`、`∃`、`=` 都满足条件——「所有」「存在」「等于」不因对象改名而改变。而「红」不满足——把论域里的对象改个名，红对象可能全变。**逻辑常项是结构性的，描述词项是内容性的。**
- **第四步，看哲学结论**：不变性标准把「逻辑性」定义为「对对象的同一性无动于衷」——**逻辑常项只见结构，不见内容**。这与第8篇逻辑真理的「无信息性」完美呼应：逻辑常项不承诺任何特定对象，所以由它们构造的逻辑真理不描述世界。

不变性标准的精妙与争议都来自它的广度。谢尔指出：按此标准，**高阶量词「存在无穷多个」也是逻辑常项**——它对置换不变，却在经典一阶逻辑里没有立足之地。若接受这个结论，「逻辑」的范围就比一阶逻辑宽得多；若拒绝，就必须给「不变性」加额外限制。**常项问题因此直接通向第16篇二阶逻辑之争：逻辑的边界，就是常项清单的边界。**

## 4 常项问题与逻辑主义的还原策略

第10篇的逻辑主义主张「数学 = 逻辑 + 定义」。现在看清了：这个口号的成功与否，完全系于**「逻辑」到底是哪几个符号**。

若常项清单是经典一阶逻辑那六个（`∧ ∨ ¬ → ∀ ∃ =`），逻辑主义必败——数学的内容（归纳、选择、连续）远超过这六个符号能表达的范围。若常项清单被扩展（比如把二阶量词、谓词抽象算子算入逻辑），数学的更多部分可以被「逻辑地」表达，但付出的代价是**逻辑不再纯粹**——它偷偷包含了集合论的内容。

于是常项问题反作用于逻辑主义，形成一个深刻的两难：

- **窄清单**：逻辑纯正，但「数学 = 逻辑」明显不够——数学的内容溢出逻辑。
- **宽清单**：逻辑够用，但逻辑被污染——它已经带上了数学的本体论内容。

无论哪种选择，逻辑主义的「纯逻辑基础」梦想都难以成立。<span class="marginnote">辨析｜易错点：常项问题不是「连接词的琐事」，而是「逻辑与数学边界」的仲裁者。
把 `=` 算进常项，数学结构理论里「a=b」类句子就成了逻辑真理；
把二阶量词算进常项，归纳原理就成了逻辑真理。
每扩展一次常项清单，就有一批数学真理「升格」为逻辑真理——这就是常项问题的哲学重量。</span>

## 5 术语速查表：逻辑常项的关键词

| 术语 | 英文 | 含义 |

| 逻辑常项 | logical constant | 逻辑形式中固定不变的词 |
| 连接词 | connective | `∧ ∨ ¬ →` 等 |
| 主题中立性 | topic neutrality | 常项对任何主题都适用 |
| 不变性标准 | invariance criterion | 常项对论域置换不变 |
| 逻辑主义 | logicism | 数学 = 逻辑 + 定义 |
| 还原策略 | reduction | 把数学还原为逻辑 |
| 常项清单 | constant inventory | 哪些词算逻辑常项的名单 |

这张速查表把常项问题的三条线索收齐：**连接词**是常项的核心样本，**主题中立性**与**不变性标准**是两种刻画方案，**逻辑主义**与**还原策略**是常项问题的利害所在——常项清单每扩展一格，就有一批数学真理「升格」为逻辑真理。

一个收束性的观察：**常项问题与逻辑主义互为试金石**。常项清单窄，逻辑主义必败（数学溢出逻辑）；常项清单宽，逻辑被污染（集合论混入）。这个两难不是技术细节，而是「逻辑与数学边界」这一元问题的浓缩。带着这个两难去读第16篇二阶逻辑之争，就能理解为什么「量词算不算逻辑」会牵动整个数学哲学。

## 6 小结

- **逻辑常项**是逻辑真理与逻辑后果的锚点，但它自身的身份悬而未决——**循环性指控**是常项问题的起点。
- 三种刻画方案：**语法**（公理化指名）、**主题中立**（对任何主题适用）、**不变性**（对置换无动于衷）。
- **不变性标准**：逻辑常项 = 在论域任意置换下保持不变的对象——只见结构，不见内容。
- 不变性标准把常项清单推得比一阶逻辑宽，甚至包含高阶量词——通向二阶逻辑之争。
- 常项清单的宽窄，直接决定**逻辑主义的成败**：窄则数学溢出逻辑，宽则逻辑被污染。
