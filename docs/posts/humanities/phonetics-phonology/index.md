# 语音学与音系学

对标权威教材体系，按章节逐节写成博文。学完一个学科 = 写完该学科权威教材对应的全部博文。

## 对标教材

- Peter Ladefoged & Keith Johnson, "A Course in Phonetics" (7th, 2015)
- David Odden, "Introducing Phonology" (2nd, 2013)
- 林焘、王理嘉, 《语音学教程》 (教材经典)

## 主题规划

### 第1篇

- [ ] 语音学导论（发音、声学、感知三分支、国际音标 IPA）
- [ ] 发音语音学（发音器官、元音与辅音的发音描写、协同发音）
- [ ] 声学语音学（声波、频谱、共振峰、Praat 语音分析实验）
- [ ] 感知语音学（听觉机制、范畴感知、语音线索感知实验）
- [ ] 超音段特征（声调、语调、重音、时长与韵律）
- [ ] 音系学基础（音位与音位变体、区别特征、最小对立对）
- [ ] 音系规则与音系过程（同化、异化、增音删音、中和）
- [ ] 音节结构与音系配列（音节理论、响度原则、音位配列学）

### 第2篇

- [ ] 非线性音系学（自主音段音系学、节律与声调几何）

- [ ] 韵律音系学与语调（韵律层级、ToBI 标注、语调模型）
