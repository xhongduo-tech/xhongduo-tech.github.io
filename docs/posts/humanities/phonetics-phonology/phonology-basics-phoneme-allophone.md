## 为什么从「音位」跨进音系学

前五篇是语音学：把音当物理事实来测。这一篇开始换问题：**语言为什么偏偏选用这一小撮音，把它们组织成对立的系统？** 这个问题属于**音系学（phonology）**，而它的最小单位就是**音位（phoneme）**。<span class="marginnote">从「从极限到大模型」的主线看，音位是语音世界里的「第一层离散化」：连续的声学信号被感知范畴化成音类（见《感知语音学》），语言系统再把这些音类组织成最小的对立单位——这正是「把连续切离散」这条主旋律在语言里的第一次正式登场。</span>

音位概念的引入还有一层现代意义：**语音识别与合成最终都要落到离散的单位上**。识别系统把声学帧「解码」成音素序列，TTS 把文本音素序列「编码」成声学帧；大语言模型处理语音时，也常常先经过「离散化 token」这一步（有些模型直接学音频 token，有些则经音素/字符中间层）。**音位学不只是在讲语言学，它讲的是「离散化」本身——而这正是语言技术的地基。**

本专题将从这里开始转入音系学的地盘。建议带着一个「对照轴」读下去：**音系学说的每一个概念，都能在语音技术里找到对应物**——音位对应声学模型要学习的「类」、变体对应「同义不同形」的声学实现、区别特征对应「特征工程」、中和对应「上下文相关的建模」。《音系学基础》是全专题的枢纽：往前接发音、声学、感知（本专题前五篇），往后接规则、音节、非线性与优选论（本专题后六篇）。

## 1 音位：语音的最小辨义单位

**音位（phoneme）**：一种语言中能够区分词义的最小语音单位。判断两个音是不是两个音位，用的是**最小对立对（minimal pair）**：如果两个词只在某个位置有一个音不同、而意义不同，那么这两个音就构成音位对立。

- 英语 /p/ 与 /b/：pit 与 bit 只差首辅音，意义不同 → /p/ 与 /b/ 是两个音位。
- 英语 /s/ 与 /z/：sip 与 zip → 两个音位。
- 普通话 /p/ 与 /pʰ/：爸 bà 与 怕 pà 只差送气 → /p/ 与 /pʰ/ 是两个音位（这正是普通话「送气辨义」的直接证据）。

反过来，如果两个音**永远不在同一个位置出现**，就无法构成对立——它们很可能只是同一个音位的两个**音位变体（allophone）**。英语的 [h] 与 [ŋ] 就是经典例子：/h/ 只出现在音节开头（hat、hot），/ŋ/ 只出现在音节末尾（sing、long），二者互补分布、永不交锋，于是被归为两个音位，而非一对对立。<span class="marginnote">「能不能找到最小对立对」是音位学的第一判别器：能找到→两个音位；找不到且互补分布→一个音位的变体；找不到且随意替换→自由变体。这三个判定条件，本文会逐一用到。</span>

各语言的音位库大小差异悬殊，这也是一份「音系选择」的实据：普通话约 20 来个声母、近 40 个韵母，再加 4 个声调音位；英语约 24 个辅音音位与 20 来个元音音位；而拥有最多辅音音位的语言（如部分高加索语言）可达 60 个以上，最少的（如夏威夷语）只有 8 个辅音、5 个元音。**音位系统不在「多」而在「对立得干净」**——夏威夷语辅音极少，却因元音长短与双元音而照样能表达全部词义。

## 2 音位变体：一个音位的多个「化身」

同一个音位在**不同环境**里发出的具体音（音素，phone）可能明显不同，这些变体就是**音位变体（allophones）**。最典型的例子是英语的清塞音：

- 词首、重读音节前：pit 的 p 是**送气**的 [pʰ]。
- 跟在 s 后：spit 的 p 是**不送气**的 [p]。

英语母语者几乎察觉不到这两个 p 的差别——因为它们从不对立，属于同一个 /p/ 的变体。可普通话恰好相反：送气/不送气是辨义对立（爸/怕）。**同一个发音差异，在英语里只是变体、在普通话里却是音位**——这是「音系是一种语言选择」最直观的证明。

变体按分布分两类：**互补分布（complementary distribution）**指各变体出现在互斥的环境（如 [pʰ] 与 [p]、[h] 与 [ŋ]）；**自由变体（free variation）**指同一环境里可随意互换而不变义（如法语 /r/ 可发成小舌擦音 [ʁ] 或小舌颤音 [ʀ]，粤语/n/与/l/在某些口音里混用）。**判断变体归属性，要看分布，而不是看听感相似与否。**

还有一个容易误判的陷阱：**听感「很不一样」的两个音，可能只是同一音位的变体；听感「差不多」的两个音，反而可能是对立音位。** 英语 [pʰ] 与 [p] 的差异比某些音位对的差异还大，但它们是变体；英语 ʃ 与 ʒ 只差清浊一毫，却是两个音位（ship 对 measure）。**音位的身份不由「物理差距大小」决定，而由「是否承担辨义」决定**——这正是索绪尔「语言是差异系统」思想的音系学版本。

## 3 区别特征：给音位做「档案」

音位之间如何对立？20 世纪的结构主义（雅各布森、特鲁别茨柯依）与乔姆斯基、哈利在《英语音系》(The Sound Pattern of English, 1968) 中系统化的做法是：把每个音位表示成一束**区别特征（distinctive features）**。特征是二元的（+/−），如：

- **[±voice]**：声带振动与否。英语 /b/ 是 [+voice]，/p/ 是 [−voice]。
- **[±nasal]**：软腭是否下垂。英语 /m/ 是 [+nasal]，/p/ 是 [−nasal]。
- **[±continuant]**：气流是否受阻成「持续摩擦」。/s/ 是 [+continuant]，/t/ 是 [−continuant]。
- **[±anterior]**、**[±coronal]**、**[±high]**、**[±back]**、**[±round]**：描述部位与舌位。

一个音位就是一根**特征束（feature bundle）**，例如英语 /b/ 大致是 {[−nasal], [+voice], [−continuant], [+anterior], [−high], [−back]}。特征的价值在于：**它把「这组音为什么总是一起变」解释成「它们共享某条特征」**——凡是 [+voice] 的塞音，在词尾会一起清化（见第 5 节）；凡是 [+high] 的元音，会在某些环境一起高化。**特征束 = 音系规则的「分类标签」**，也是自然类（natural class）的数学基础。

特征的另一大贡献是**压缩描写**：一套十几条特征，就能给全部 24 个英语辅音音位建好档案；而不用特征的纯列举式描写，每个音都要单独记。更关键的是，**规则只对「共享特征的一整类音」起作用**——如「词尾 [+voice] 的塞音清化」，一句话就同时描述了 b、d、g 三个音位。正是这种「以类为单位」的归纳能力，让特征体系成为从结构主义到生成音系学一贯的骨干。

现代音系学还在特征上做了分层：一部分特征（如 [±voice]）挂在喉层，另一部分（如 [±anterior]）挂在口腔层，组成**特征几何（feature geometry）**的树状结构——这属于《非线性音系学》一篇的内容，这里先记住「特征是分层的」这个方向。

做两个小练习就能让特征体系落地。**练习一**：写出英语 /t/ 的特征束，并与 /d/ 比较——两者几乎全同，唯一差别是 [±voice]，这正是「t/d 的最小对立」在特征层的写照。**练习二**：给「英语 /p, t, k/ 是一组」找特征依据——三者同是 [−voice][−continuant][−nasal] 的清塞音，共享三条特征，所以规则可以「一网打尽」它们（如词首送气规则一次给三者都加上 [spread glottis]）。**特征束写得出，音系规则才写得「一针见血」。**

## 4 公式解析：最小对立对判别式与「音位即向量」

音系学的第一个「判别式」是形式化的，值得拆开看。设词由音素序列构成，两个词 $w_1$ 与 $w_2$ 只在第 $i$ 个位置差一个音，且意义不同，则：

$$\forall\, w_1 = \cdots\,X_i\cdots,\;\; w_2 = \cdots\,Y_i\cdots \quad\text{且}\quad \text{意义}(w_1) \neq \text{意义}(w_2) \;\Rightarrow\; X_i, Y_i \text{ 分属两个音位}$$

逐步拆解：

- **第一步，锁定位置**：比较的必须是「除一个音外完全相同」的两个词（pit / bit），位置 i 之外不允许再有差别。
- **第二步，排除干扰**：如果两个词还差别的别的音，就无法把意义差异归因于 X_i 与 Y_i——所以要选最干净的最小对立对。
- **第三步，推结论**：意义不同 → X_i 与 Y_i 承担了「辨义」功能 → 它们是不同音位。找不到这样一对词 → 暂不能判定为两个音位。

再把特征束写成向量形式：**一个音位 = 一个由 ±1 组成的特征向量**（每条特征一维）。英语 /b/ 就是 $[-,+,-,+, \ldots]^T$，/p/ 是 $[-, -, -, +, \ldots]^T$。向量与向量之间的「汉明距离」就是两音位共享特征的数目——**特征向量越接近，音位越容易在规则里一起行动**。这条「把语言单位编码成向量」的思路，正是从音系学的特征矩阵一路通到今天大模型里 embedding 的思想源头：**先有特征向量，后有词向量；离散的对立，总要被放进向量空间才能参与运算。**

## 5 中和：对立在某个环境里「失灵」

音位对立并非在所有环境都成立。**中和（neutralization）**指两个音位在特定位置不再对立、只能以同一种形式出现。最著名的例子是**德语词尾清化（final devoicing / Auslautverhärtung）**：德语的 /b, d, g/ 与 /p, t, k/ 在词中对立（Rad「轮子」与 Rat「建议」词尾都读 [t]，但词干里 d/t 对立），而**在词尾，浊塞音一律变成清塞音**——对立被中和。其他有词尾清化的语言还包括俄语、土耳其语、加泰罗尼亚语。<span class="marginnote">中和的音系学意义：<strong>对立不是音位的固有属性，而是「某语言在某环境下的约定」</strong>。同一个 /d/，词中体现浊音、词尾体现清音，这就是「底层同一、表层不同」的活教材。</span>

英语里也有中和：美式英语的 t 与 d 在非重读元音之间都变成闪音 [ɾ]（butter、rider），清浊对立在「元音—元音」环境被中和；普通话声母「浊塞音」不存在，自然谈不上这种中和，但轻声、儿化里也存在类似的「对立淡化」。**中和是规则作用的结果，它把第 4 节的判别式变成「环境敏感」的版本。**

中和在音系学史上还催生了一个概念：**超音位（archiphoneme）**。当两个音位在某环境中和，可以用一个「不标那条对立」的符号表示它们在那种环境下的共同身份（德语词尾的 /D/ 表示「既是 d 又是 t」）。如今超音位更多被当作历史名词，但它留下的问题依然鲜活：**中性化环境里的音，究竟「是」哪一个音位？**——答案往往要借助语音学实测（VOT、浊音起始）与词干变化（Rad 复数 Rader 露出 d）来反推。

普通话里的「对立淡化」再举一例：轻声不但缩短时长、降低音高，还常常让声母「浊化」或让韵母央化（「哥哥」的第二个「哥」韵母变成近似 ə）。**中立化不只在塞音清浊上出现，元音与声调同样会在弱化环境里「失守」**——这正是超音段特征与音段特征在语流中交汇的地方。

## 6 底层表示与表层表示

音系学由此引入一对关键概念：**底层表示（underlying representation, UR）**与**表层表示（surface representation, SR）**。UR 是「词在词典里的抽象形式」（如德语 Rad 底层含 /d/），SR 是「实际说出来、听得到的形式」（词尾实际是 [t]）。**规则（rule）把 UR 变成 SR**——词尾清化就是一条「/浊塞音/ → /清塞音/ ／ __词尾」的规则。规则的标准写法与详细展开，见下一篇《音系规则与音系过程》。

为什么不肯「SR 是什么就记什么」，非要多设一层 UR？因为 **UR 让音系学拥有了「解释力」**：德语 Rad 的复数 Rader 读 [ˈʁaːdɐ]，词中的 d 清晰可闻——如果词典只记 SR，就得给「轮子」记两套发音（[ʁaːt] 与 [ʁaːdɐ]）且看不出联系；记 UR /rad/，两条规则（复数加 -er、词尾清化）就能统一推导两个形式。**UR 是「把相关形式归并成一个抽象单位」的模型，与机器学习里「共享参数、减少冗余」的思想同源。**

## 7 核心对比表：音素、音位与音位变体

纯概念主题用核心对比表替代公式解析。三个术语读音相近、极易混淆，必须用一张表钉死：

| 术语 | 定义 | 记号 | 例（英语 /p/） | 判据 |
| --- | --- | --- | --- | --- |
| 音素（phone） | 实际发出的具体语音 | [ ] | [pʰ]、[p] | 可测量，听感可辨 |
| 音位（phoneme） | 最小的辨义抽象单位 | / / | /p/ | 存在最小对立对 |
| 音位变体（allophone） | 同一音位的具体实现 | [ ] | [pʰ]、[p] | 互补分布/自由变体 |

读表要点：**方括号 [ ] 装「实际音」，斜杠 / / 装「抽象音位」**。写错括号在音系学里是低级而严重的错误——它混淆了「物理事实」与「语言抽象」两个层面。全篇的判别式、中和与变体规则，都是在给这两个层面搭桥。

## 8 小结

- **音位**是最小辨义单位，由**最小对立对**判定（pit/bit、爸/怕）；找不到对立对且互补分布的音归为**同一音位的变体**。
- **音位变体**分**互补分布**与**自由变体**两类；英语 [pʰ]/[p] 是一音位两变体，普通话里送气/不送气却是两个音位——同一发音差异、不同语言选择。
- **区别特征**把音位编码成 ± 特征束（[±voice]、[±nasal]……），特征束即「音位向量」，是规则分类与后来 embedding 的思想源头。
- **中和**（德语词尾清化、美式闪音）说明对立是「环境敏感」的；**UR→SR** 由规则驱动。
- **UR** 把相关形式归并成抽象单位（Rad/复数/词尾清化一条规则统一推导），是「共享、减少冗余」思想的模型。
- 音位概念在语音技术里的对应物：声学模型学的「类」、同义不同形的变体、「上下文相关」的中和建模。
- 最小对立对判别式是形式化的「音位检定法」：锁定单点差异、排除干扰、据意义差异判定对立。
- 特征束即「音位向量」，共享特征越多越易在规则中集体行动——与 embedding 思想一脉相承。
