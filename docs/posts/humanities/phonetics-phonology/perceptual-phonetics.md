## 为什么从耳朵开始

发音器官造出波形，声学仪器测出频谱——但**语言最终是给人听的**。发音与声学只回答「声音是什么」，感知语音学（auditory / perceptual phonetics）回答最后、也是最关键的一问：**听者的耳朵与大脑如何把这段声波变成「我听见了一个音」？** 这一问把语音学从「物理」推向「认知」，也把「从极限到大模型」的链条补上了最关键的一环——**任何识别系统，无论隐马尔可夫模型还是神经网络，最终都在模仿一个听者**：从连续的声学信号里切出离散的音类。<span class="marginnote">今天的语音识别把「辨音」交给机器，但机器辨音特征的设计（梅尔刻度、临界频带滤波器组）直接抄自人的听觉生理——学感知语音学，等于拿到语音工程的「第二份设计蓝图」。</span>

感知语音学还有一层更深的含义：**它揭示了「音位」这类离散单位的心理真实性**。声学信号明明是连续的（同一元音的 F1 每毫秒都在变），可听者听到的是「这是 a，那是 i」——这道「连续→离散」的转换，正是音系学（本专题后半程）得以成立的心理基础。先看清耳朵，才能看清「音位」这种东西为什么存在于人脑里。

本节会沿着「生理 → 线索 → 范畴 → 学习 → 多模态」的顺序推进：先讲耳朵这台硬件，再讲它提取哪些线索，然后看线索如何被范畴化，接着看范畴如何被语言经验塑造，最后看感知如何与视觉、与产出整合。**每一步都是在「连续」与「离散」之间架一座桥。**

## 1 听觉系统：从外耳到耳蜗的「频谱分析仪」

先走一遍耳朵的解剖，它本身就是一台精密的声学机器：

- **外耳**：耳廓与耳道，起到收集声波、略微放大 2–5 kHz 频段的作用——恰好处在许多辅音信息所在的高频区。
- **中耳**：鼓膜与三块听小骨（锤骨、砧骨、镫骨）把空气的振动转换为内耳淋巴液的振动，并对声压做阻抗匹配。
- **内耳（耳蜗）**：蜗牛状的螺旋腔，内部是**基底膜（basilar membrane）**。声波沿基底膜传播时，不同频率激起不同的最大位移位置：**高频在蜗底、低频在蜗顶**——这叫**耳蜗的音位拓扑（tonotopy）**。

基底膜上分布着约 1.5 万个**毛细胞（hair cells）**，它们按位置各司其职，把机械振动变成神经脉冲。**听觉系统本质上是一台「分频—频谱分析仪」**：每一根毛细胞像一台带通滤波器，只对某个窄频段敏感，整条基底膜等于一排并排的滤波器组。<span class="marginnote">「临界频带（critical band）」由此而来：人耳无法分辨相邻过近的频率，约 1/3 倍频程内的一组频率在听感上合成一个「频带」。梅尔刻度的滤波器组，正是这套生理临界频带的工程近似。</span>

人耳的**可听范围**大约在 20 Hz 到 20 kHz 之间，但灵敏度并不均匀：低频与超高频段需要更大的声压才听得到，这就是**听力图（audibility curve）**。语音信息几乎全部落在 100 Hz 到 8 kHz 之间，其中元音的基频与共振峰集中在低中频，辅音的高频噪声则在 3–8 kHz——**听力损失往往是高频先坏，所以老年人「听得见元音、听不清辅音」**。这一事实直接影响了助听器与语音系统的频段设计，也再次说明：**感知语音学的问题清单，就是工程设计的优先级清单。**

## 2 语音线索：耳朵到底在听什么

声学语音学讲的爆破、摩擦、共振峰过渡、VOT 等「事件」，在感知层就变成**语音线索（phonetic cues）**——听者提取它们来辨别音类。需要先点破一层关系：**线索不是「声学事件」本身，而是「声学事件中被听者使用的那个部分」**。同样一段 VOT，仪器量出来是一串数值，听者只关心它落在边界的哪一侧。感知语音学研究的，正是「信号 → 线索 → 音类」这条从物理到心理的映射。几条最重要的线索及其辨音功能：

- **VOT**：区分清浊与送气（b/p、d/t、g/k）的主要线索。VOT 短→听成浊音，长→清音；普通话里 VOT 的长短还区分 b 与 p。
- **共振峰过渡**：元音前的共振峰滑动方向，是区分「哪个部位的塞音」的主要线索。
- **摩擦噪声的频率分布**：区分 s、sh、f 等擦音的线索——s 的中心频率在 4000 Hz 以上，f 更靠前更低。
- **爆破的频率与强度**：区分 p/t/k 的补充线索。

**一个音往往同时携带多条线索，彼此冗余**——听者不是靠某一条孤立的线索做决定，而是综合多条线索。这种冗余是语音感知稳健性的来源：环境噪声、语速变化、口音差异都会抹掉某几条线索，但只要还有几条幸存，音就能被认出来。**感知语音学的一个核心任务是找出「哪条线索主导、各线索如何相互补位」**，方法正是下一节的操纵实验。

一个著名的实验能让你直观感到这种冗余：**「无声中心」实验（silent-center study）**。把音节中间的几十毫秒完全静音（只留开头与结尾），听者依然能准确辨认这个音节——因为音节首尾包含了共振峰过渡与爆破等足够的线索。反过来，只给音节中间一小段，辨认就大幅下降。这说明**语音线索在时间上也高度分布**：信息不在某一个「点」，而在整个音节的包络里。感知实验常用这类「切一刀再看认不认得出来」的办法来定位线索的位置与权重大小。

## 3 范畴感知：连续信号如何被切碎

感知语音学最著名的发现是**范畴感知（categorical perception）**。1957 年，美国哈斯金斯实验室（Haskins Laboratories）的利伯曼（Alvin Liberman）等人做了经典实验：把一段合成语音的 VOT 从 0 毫秒逐步调到 80 毫秒，得到一连串连续变化的「b→p」刺激；让听者做两种任务：

- **辨认（identification）**：每个刺激是 b 还是 p？结果不是渐变，而是**在某个 VOT 值附近突然「跳变」**——之前几乎全判 b，之后几乎全判 p。
- **分辨（discrimination）**：两两比较刺激是否相同？结果在边界两侧的刺激对最容易分辨，边界内部的刺激对几乎分不出差别。

也就是说，听者把一段物理上连续的 VOT 连续体，感知成**两个离散的类别**，类别内部不再精细分辨。这就是「连续→离散」的实证：**在感知层面，音位对立是「有界」的，边界之内的差异被忽略。**<span class="marginnote">范畴感知对「为什么音位系统能工作」给出了心理答案：语言只需要听者区分「对立」与「不对立」，而不需要分辨一切细微差异——感知把信息压缩成了音系学需要的形状。</span>

有趣的是，并非所有语音对都呈范畴感知。**元音的对立更接近「连续感知」**：改变元音的 F1、F2 做连续体，听者的辨认曲线往往更平缓、分辨也更均匀。塞音 VOT 的范畴性比元音强得多——这与两类音「是否需要快速在线分类」的功能差异有关。范畴感知是「程度」问题，不是「全有或全无」。

实验的具体操作值得了解，它几乎是所有感知实验的模板：先用合成器造一条**连续体（continuum）**，比如 11 个 VOT 从 0 到 80 毫秒、间隔均匀的 b–p 刺激；再随机打乱播放，让被试做辨认（labeling）与分辨（discrimination）；最后把两类结果画成辨认曲线与分辨峰曲线。**「辨认边界陡峭 + 分辨峰出现在边界」两个现象同时出现，才叫范畴感知**——单看辨认曲线会误判，必须双曲线互证。这套「合成连续体 + 双任务」范式后来被反复用于声调、送气、清浊等各种对立的研究，也是今天语音研究的标准工具之一。

## 4 核心对比表：范畴感知与连续感知

纯概念主题用核心对比表替代公式解析。在进入表格之前先记住范畴感知的**功能意义**：语言系统把声学连续体「切成」离散类别，是为了让听者不必对每个音做无穷精细的声学比较，而只需在音系对立的层面做快速分类——**离散化本身就是一种「压缩」，是大脑在信息量与速度之间的最优解**。这与「从极限到大模型」主线里反复出现的主题同构：把连续的东西离散化，才能交给有限的计算资源去处理。范畴感知与连续感知是感知语音学最核心的一组对照：

| 维度 | 范畴感知 | 连续感知 |
| --- | --- | --- |
| 典型对象 | 塞音 VOT（b–p、d–t） | 元音共振峰（i–e、u–o） |
| 辨认曲线 | 陡峭，存在明显边界 | 平缓，渐变过渡 |
| 分辨表现 | 边界内分不出、边界外易分 | 处处可分辨 |
| 心理后果 | 物理连续→知觉离散 | 物理连续→知觉连续 |
| 与音系的关系 | 对应音位「对立/不对立」 | 对应音位的「非对立细微差异」 |
| 例子 | /b/ 与 /p/ 的 VOT 边界约 25–30 毫秒 | i–e 的 F1 连续体无硬边界 |

表中 VOT 的边界值值得记住：英语母语者通常在 VOT 约 25–30 毫秒处划出清浊边界，普通话则是「不送气/送气」的边界（送气清音的 VOT 更长）。**边界位置不是「物理事实」，而是语言习惯的产物**——这正是下一节的主题。

## 5 婴儿与双语：感知是「长出来」的

范畴边界既然是语言习惯，就必然**随着语言经验被塑造**。1970 年代起的一系列实验证明了这一点：

- **婴儿是「世界公民」**：Werker 和 Tees（1984）发现，6–8 个月的婴儿能分辨几乎所有语言的全部音类对立（包括他们母语里没有的），到 10–12 个月，分辨力迅速收窄到母语音系范围内——这就是**感知窄化（perceptual narrowing）**。
- **母语经验塑造边界**：英语母语者听不出印地语的三类清塞音（送气/不送气/浊）差异，而印地语婴儿一开始能分辨，之后才「忘掉」不需要的对立。
- **声调同样可习得**：王士元（William S.-Y. Wang）1976 年的经典实验表明，普通话母语者对四个声调呈明显的范畴感知，且调值边界清晰可测——声调不是「音乐的绝对音高」问题，而是与塞音一样被范畴化的语言信息。值得一提，普通话第二声（35 升调）与第三声（214 降升调）的边界在听感实验中清晰可辨，这与音系学中「上升/降升」的对立描述完全对应（见《超音段特征》）。

这些结果共同指向一个结论：**语音感知不是一套固定程序，而是随着母语经验「被训练」出来的**。出生时的耳朵接近一台「通用分频器」，成年后则变成一部「母语特化」的辨音机。这条「通用→特化」的路径，与机器学习里「预训练→微调」的逻辑惊人地相似。

那么成年之后还能不能「重新学」一门语言的音系对立？实验给出了**有条件地「能」**的答案：给英语母语者做大量针对印地语塞音对立的辨识训练（含反馈、多次重复），他们的分辨力可以显著回升，但往往达不到母语者的自动化水平，且需要刻意维持。这类**感知训练（perceptual training）**研究既回答了「语音可塑性」的理论问题，也直接服务于第二语言教学与语音识别系统的「听者校准」——你教机器听一个新语言的音，本质上就是在做同一件事：**重建一批因母语而失效的边界**。

## 6 麦格克效应：耳朵听，眼睛也在听

感知语音学还发现，**语音感知是「多模态」的**。1976 年麦格克（Harry McGurk）与麦克唐纳（John MacDonald）报告了著名的**麦格克效应（McGurk effect）**：给被试看一段「嘴型发 ga」的视频，同时播放「ba」的配音，大多数人报告自己「听见」了 da——**视觉信息改变了听觉结果**。这个效应在所有年龄、多数语言中都稳定出现，说明语音感知天然是「视听整合」的过程，嘴型的运动信息在时间上与声音高度相关，被大脑当作一条并行的线索一起解码。<span class="marginnote">麦格克效应的工程版是「读唇增强语音识别」：噪声环境下，唇动信息能显著提升识别率，至今仍是多模态语音系统的一个真实组件。</span>

与之呼应的是**左耳优势（right-ear advantage）**：金马拉（Doreen Kimura）1961 年用双耳分听（dichotic listening）实验发现，同时向两耳播送不同音节时，人们更准确报告右耳听到的内容——因为右耳信号优先进入左脑语言区。**耳朵虽是两只，语音却主要「走」一边**，这也是语音加工「侧化」的著名证据。

感知与产出的关系还有一个著名的理论：**马达理论（motor theory of speech perception）**，同样出自哈斯金斯实验室的利伯曼等人。它主张人「听语音」时其实在「模拟发音」——识别一个音靠的是把它与自己的发音动作对应起来，而不是纯粹地匹配声学模板。这个理论有争议（后续研究证明纯声学信息也能驱动感知），但它留下了一个经久不衰的洞察：**感知与产出共用同一套大脑资源，听者在「心里默念」来帮助辨认**。今天神经科学的镜像神经元研究与语音识别的「发音特征」建模，都从这条线索继续深入。

一个更具体的佐证来自**「听觉回输」实验**：当说话者的声音被延迟几十毫秒送回自己耳朵（延迟听觉反馈），他会口吃、变慢——说明听自己在说什么，是产出过程的实时控制回路。反之，语音识别系统遇到「听不清」时，也常借助「发音可能性」先验来猜——马达理论的这个「以发推听」思路，至今仍是鲁棒语音识别的一个组成部分。

## 7 从感知实验到语音识别

感知语音学的每一项发现，几乎都能在语音工程里找到对应物：梅尔滤波器组模拟临界频带、MFCC 用对数压缩模拟响度感知、多模态系统引入视觉线索、端点检测模仿听者的静默处理。更重要的是，**感知实验给出「人如何做」的参考答案，机器识别以此校准**——2010 年代后神经网络不再显式模仿听感，但其学到的特征在可视化时，与耳蜗的临界频带结构依然高度吻合。**感知语音学是「人」与「机」两套语音系统之间最直接的对照系。**

这条对照还在反向生长：**机器也开始反过来给感知理论出题**。端到端模型在干净环境下已接近或超过人类在词级错误率上的表现，但在噪声、口音、语速极端变化的场景仍明显弱于人耳——这提醒我们，人类感知的「冗余线索 + 语言知识反馈」机制，依然是机器没抄全的那一部分。**感知语音学与语音工程的对话，不是「谁服务谁」，而是互相找茬、互相校准。**

## 8 小结

- 听觉系统从外耳到耳蜗是一台**分频的频谱分析仪**，基底膜的音位拓扑决定了「临界频带」等基本听觉性质。
- 听者靠**VOT、共振峰过渡、摩擦噪声分布、爆破**等冗余线索辨音，一条线索受损时其他线索补位。
- **范畴感知**（Liberman 1957）证明塞音 VOT 的连续变化被感知为离散类别；元音则更接近连续感知。
- 感知是**语言经验塑造**的：婴儿 6–8 个月能辨一切对立、10–12 个月收窄到母语音系，普通话声调同样呈范畴感知（王士元 1976）。
- **麦格克效应**表明语音感知是多模态视听整合；**左耳优势**反映语音加工的脑侧化。
- **马达理论**主张感知与产出共用大脑资源；**无声中心实验**说明语音线索在时间上高度分布、彼此冗余。
- 梅尔刻度、临界频带滤波器组等语音识别前端，正是把人的听觉生理「抄」进工程。
- 感知实验的标准范式是「合成连续体 + 辨认/分辨双任务」，辨认边界陡峭与分辨峰重合才算范畴感知。
- 语音线索在时间上高度分布、彼此冗余（无声中心实验），一条受损其余补位，是感知稳健性的来源。
- 感知窄化使成年人的耳朵「母语特化」，但感知训练可部分重建外语对立；机器识别在极端场景仍不及人耳。
- 离散化即压缩：范畴感知把连续信号切成类别，是大脑在信息量与速度之间的最优解，与「从极限到大模型」主线主题同构。

在下一节，我们将离开单个的音，把目光抬到音节与更大的单位：看声调、重音、语调这些「压在音之上」的超音段特征如何在时长、音高与强弱上塑造言语——这就是**超音段特征**。
