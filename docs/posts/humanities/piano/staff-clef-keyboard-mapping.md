## 为什么从读谱开始

上一节我们建立了姿势与手型，手已经「放对位置」；但手要弹什么，需要一份「说明书」——这就是**乐谱**。从「从极限到大模型」的视角看，乐谱就是音乐的**编码**：它把连续流动的声音离散成可见的记号，就像计算机把连续信号采样成离散的数字。<span class="marginnote">乐谱对时间的离散化与对音高的编码，和第四级《大模型原理》里「把文本切成 token」是同一类操作：把无限的信息流压缩成有限的符号序列，再靠规则还原。读谱 = 解码，弹奏 = 解码器。</span>

钢琴是「一纸两谱」的乐器：右手通常读高音谱，左手读低音谱。理解**谱号如何固定音高**、**五线谱如何映射键盘**，你就拿到了整座键盘的地图——后续所有音阶、和弦、练习曲都建立在这张地图上。

## 1 五线谱：五条线与四个间

**五线谱（staff）**由五条平行横线组成，从下到上依次为第一线、第二线……第五线；线与线之间的空隙称为**间**，从下到上为第一间至第四间。音的位置越高，音越高；位置越低，音越低——这是一条贯穿全部读谱的总原则：**位置决定音高**。

五线加四间只能放九个音，不够用，于是引入**加线（ledger lines）**：在五线之上或之下画短横线，音可以继续往上、往下延伸。<span class="marginnote">钢琴音域极宽：88 键、7 个多八度，只靠五线远远不够。加线是把「坐标系」向两端延展的方法——很像数轴上为整数不够用时引入小数、负数，是「数系扩充」在谱面上的对应物（见第一级《集合》）。</span>

## 2 谱号：为五线谱「定音」的钥匙

同样是某条线，在加上**谱号（clef）**之前，它不表示任何具体音名。谱号写在每行开头，作用是**给某一条线「钉死」一个音名，其余各线各间依次推出**。

- **高音谱号（treble clef）**：又称 G 谱号。它起笔盘绕的那条线（从下数第二条线）固定为 G（中央 C 上方的 G）。右手旋律通常写在高音谱上。<span class="marginnote">高音谱号为什么叫 G 谱号？因为它规定了第二线上的音是 G。整个谱号的曲线就是从这条 G 线出发「画」出来的——记住这个事实，看任何 G 谱号都能立刻定位第二线。</span>
- **低音谱号（bass clef）**：又称 F 谱号。它两个圆点夹住的那条线（从下数第四条线）固定为 F（中央 C 下方的 F）。左手伴奏通常写在低音谱上。

**重点：中央 C 是连接两谱的枢纽**。中央 C 在高音谱上记在下方加一线，在低音谱上记在上方加一线——两行谱共享同一个「中轴线」上的音，钢琴的大谱表（grand staff）就是上下两条五线用花括号连起来、以中央 C 为对称中心的结构。

## 3 键盘与谱面的对应：音名与音组

钢琴键盘从左到右是**低音到高音**，对应谱面上从下到上。白键按循环音名排列：C–D–E–F–G–A–B，到 B 之后回到高八度的 C。黑键是白键之间的半音（升 C、降 E 等），键面与谱面一一对应。

- **音名**：C、D、E、F、G、A、B 七个字母循环使用，是「音的名字」。
- **音组**：为区分不同高度的同名音，按音域分组。中央 C 属于**小字一组**（记作 c¹ 或 C4），其下方是小字组、大字组，其上方是小字二组、三组……88 键钢琴从大字二组的 A（A2）到小字五组的 C（C8），共 7 又 1/4 个八度。<span class="marginnote">国际通行用 C4（中央 C）、A4（440 Hz 标准音）等编号法；中国教材多用「小字组」等名称。名称不同，指的都是同一个键——理解「同名不同组」是读懂音域标号的关键。</span>
- **中央 C**：键盘中央附近、离琴锁孔最近的白键，也是大谱表的对称中心。

### 记忆三件套：锚点、相邻与八度

读谱并不需要「每个音都从头数」，靠三件套就能快速定位：

- **锚点音**：中央 C、高音谱第二线 G、低音谱第四线 F——三个锚点钉死后，其余音都以它们为参照。
- **相邻推理**：线上音与相邻间里的音相差二度，隔一线/一间相差三度——用「相邻」推比从头数快得多。
- **八度循环**：同名音每隔八度位置规律相同；记住「中央 C 在高音谱下加一线、低音谱上加一线」，两行谱都通了。

| 锚点 | 位置 | 记忆法 |
| --- | --- | --- |
| 中央 C | 高音谱下加一线 / 低音谱上加一线 | 两谱的正中间 |
| G（高音谱） | 第二线 | 谱号起笔绕的线 |
| F（低音谱） | 第四线 | 两个圆点夹的线 |

把「锚点 + 相邻 + 八度」练成反射，认谱就不再是「数格子」，而是「跳着看」——这正是进阶《视奏》快速读谱的基础，也是从「认识每一个音」走向「一眼看懂一串音」的必经之路。

## 4 核心对比：高音谱与低音谱

（纯概念主题，本节用核心对比表替代公式解析。）

| 维度 | 高音谱（G 谱号） | 低音谱（F 谱号） |
| --- | --- | --- |
| 固定音 | 第二线 = G | 第四线 = F |
| 常用手 | 右手 | 左手 |
| 中央 C 位置 | 下方加一线 | 上方加一线 |
| 音域侧重 | 中高音区 | 中低音区 |
| 谱号形态 | 起笔缠绕 G 线 | 圆点夹住 F 线 |

记忆口诀：高音谱里「下加一线 do、第三间 do」……各家口诀不同，但核心都是**以中央 C 为锚点向上向下数**。先把中央 C 与 G、F 三条「锚线」钉牢，其余各音都是加减法。

## 5 公式解析：音高与频率的对数关系

读谱阶段不必深入声学，但一个公式能让你明白「为什么音高是线性的而频率不是」。钢琴相邻两个键（相差一个半音）的频率比是常数：

$$f_{n+1} = f_n \cdot 2^{1/12}$$

- **第一步，理解底数 2**：高一个八度，频率恰好翻倍（如中央 A4 = 440 Hz，高八度 A5 = 880 Hz）。十二平均律把一个八度均分成 12 个半音，所以每步是 2 的 12 次方根 $2^{1/12} \approx 1.0595$。
- **第二步，看「乘法变加法」**：对等式两边取对数，频率的乘法变成音程的加法——**人耳对音高的感觉是频率的对数**。这就是为什么谱面上「相差一个八度」看起来是同样大小的距离：谱面坐标本质是「对数坐标」。<span class="marginnote">人耳对频率取对数，这个事实在第六级《信号与系统》里会以频谱的形式再次出现：傅里叶分析把「时间上的波形」变成「频率上的分布」，而音乐正是频率分布的艺术。</span>
- **第三步，用它数键盘**：从 A4（440 Hz）开始，每高一个键乘一次 $2^{1/12}$，每 12 步回到同名音且频率翻倍。这条公式把「谱面上的距离」和「耳朵里的音高」精确绑定，是全部乐理可计算化的起点。

## 6 读谱练习方法与常见错误

- **先认锚点再认音**：不要每个音都从头数。把中央 C、两个谱号的锚线（G、F）记死，其余音以它们为参照「相对认谱」。
- **上下对照弹**：双手各弹一个音，同时说出音名，训练「键—谱」双向映射。
- **慢速视奏**：用拜厄前几课的简单曲目，先念谱再弹，把「看谱 → 找键」的路径缩短。<span class="marginnote">初学者最常见的瓶颈不是「不会弹」而是「看不过来」。把认谱做成「反射」，靠的是重复的短距离映射，而不是死记每一条加线。</span>

常见错误速查：

| 现象 | 原因 | 对策 |
| --- | --- | --- |
| 高音谱把中央 C 弹高八度 | 加线位置看反 | 记住中央 C = 下加一线 |
| 左右手谱号看混 | 没先看谱号就弹 | 弹前先念「高音/低音」 |
| 同音名不同组找错 | 音组概念不清 | 以中央 C 为起点逐组数 |

## 7 唱名、音名与临时升降号

读谱阶段还有两件工具需要认识：**唱名**与**临时升降号**。

- **音名与唱名**：音名是 C–D–E–F–G–A–B（固定名），唱名是 do–re–mi–fa–sol–la–si（可唱的称呼）。中国教学里常把两者混用：C 大调里 do 就是 C，但换到 G 大调时唱名需要重新对应。<span class="marginnote">「固定唱名」与「首调唱名」之争持续了一个多世纪：<strong>固定唱名认「音」，首调唱名认「关系」</strong>。钢琴教育偏向固定唱名（因为键位固定），但理解首调思维对学乐理、移调有巨大帮助——就像理解「集合的元素」与「集合的关系」是两回事（见第一级《集合》）。</span>
- **临时升降号（accidental）**：写在音符前面的 ♯、♭、♮（还原号），只对**本小节内、同音高的后续音**生效，小节线后自动失效。它与调号不同：调号是全曲生效的「默认设置」，临时升降号是局部的「临时修改」。<span class="marginnote">临时升降号的有效范围（一小节内）是一条严格的约定——<strong>它把「修改」限定在局部，防止误伤后面的音</strong>。这种「局部优先于全局」的作用域规则，与编程里「局部变量覆盖全局变量」完全同构。</span>
- **黑键的两种写法**：同一个黑键既可以是升号的音（如 C♯），也可以是降号的音（如 D♭）——这取决于乐曲的调。初学不必深究，只要知道「黑键有两个名字」即可。

| 记号 | 名称 | 作用 |
| --- | --- | --- |
| ♯ | 升号 | 升高半音 |
| ♭ | 降号 | 降低半音 |
| ♮ | 还原号 | 取消升/降，回到原位 |

掌握了音名、唱名与临时升降号，五线谱的「读谱系统」就完整了：**位置定音高、谱号定锚点、调号定默认、临时号定修改**——四层叠加，就是全部读谱规则。

## 8 小结

- 五线谱用「位置」编码音高：**线、间、加线**构成一个可上下延伸的坐标系。
- 谱号为谱面定音：**高音谱（G 谱号）定第二线为 G，低音谱（F 谱号）定第四线为 F**；中央 C 是两谱的枢纽。
- 键盘与谱面一一对应：音名 C–D–E–F–G–A–B 循环，音组区分同名不同高，88 键 = 7 又 1/4 个八度。
- 音高与频率成对数关系 $f_{n+1} = f_n \cdot 2^{1/12}$——谱面是「对数坐标」，人耳对音高取对数。

在下一节，我们将把「读到的音」落到手上：**中央 C 五指位弹奏**——连奏与断奏，读谱与手指的第一次合流。
