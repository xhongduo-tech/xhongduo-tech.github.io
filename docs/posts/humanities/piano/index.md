# 钢琴演奏

钢琴演奏是一门以键盘为媒介、融合读谱、指法技术与乐感表达的音乐表演学科，是通向西方音乐经典曲库与即兴创作的最重要入口。对标《拜厄钢琴基础教程》《哈农钢琴练指法》与车尔尼系列练习曲，按「从入门读谱、手指技术到练习曲进阶」的路径逐节写成博文，学完一个学科 = 写完该学科权威教材对应的全部博文。

## 对标教材

- 《拜厄钢琴基础教程》人民音乐出版社
- 《哈农钢琴练指法》（Hanon: The Virtuoso Pianist）人民音乐出版社
- 车尔尼钢琴练习曲系列：Op.599 初级教程、Op.849 流畅练习曲、Op.299 快速练习曲、Op.740 手指灵巧练习曲
