## 为什么从「吃什么」开始

考古遗址里的锅碗瓢盆能告诉研究者「古人用过什么厨具」，却答不出「古人吃了什么」。
而吃什么，直接连着人群的身份、生计、等级与社会分化：农业是种粟还是种稻，狩猎还是放牧，近海还是内陆——这些都写在饭碗里，也**写在骨头里**。
稳定同位素分析让骨骼开口说话：**食物中的碳、氮、氧会以略微不同的同位素比例沉积进人体的骨胶原与牙釉质，死后数千年仍可读出。**<span class="marginnote">同位素是「同一元素、中子数不同」的原子，化学性质几乎相同，但物理性质（如质量）略有差异——正是这点微小的质量差，让它们在不同化学反应中「走得快慢不同」，从而留下可测的痕迹。
这个「几乎相同但略有差别」的思路，贯穿本节全部方法。
</span>

这套方法因此把两个世界连起来：**生态学**（光合作用途径、食物链、水体）与**考古学**（生计方式、社会分层）。
它与前几节的产地溯源同源（大理石也靠同位素定源），
而它背后的「比值测定」「标准化」「混合模型」，
又与「从极限到大模型」的计量方法与统计学直接接轨。

## 1 δ 记法：千分之几的语言

同位素分析不报绝对含量，而报**相对国际标准的千分偏差**——符号 **δ**（delta）。
所有同位素结果（$\delta^{13}C$、$\delta^{15}N$、$\delta^{18}O$）都长这样：

$$
\delta = \left( \frac{R_{\text{sample}}}{R_{\text{standard}}} - 1 \right) \times 1000\,‰
$$

其中 $R = \dfrac{^{13}C}{^{12}C}$ 等轻重同位素之比。
每套元素有自己的国际标尺：碳用 **VPDB**（一种箭石化石标准），氮用大气 **AIR**，氧用水标准 **VSMOW**（海洋水）。
<span class="marginnote">符号 ‰ 读作「permil」——千分之，与百分比 % 是兄弟，只是尺度小十倍。
同位素差异本来就极小（碳在 ‰ 量级、氧的氢同位素甚至在 ppm 量级），
δ 记法把它们放大成好读的数字。
</span>

负号不表示「没有」，只表示「比标准轻」：比如 C3 植物的 $\delta^{13}C$ 约 $-26.5‰$，意思是它的碳十三比例比 VPDB 标准低 26.5‰。
这一记法的精妙在于：**不同实验室、不同仪器的测量可以互相比较**——所有人都在同一把国际标尺上读数。

## 2 碳同位素：C3 与 C4 的餐桌

碳同位素的考古学威力，来自一条生态学分界：**陆生植物按光合作用途径分成 C3 与 C4 两大家族**。

**C3 植物**：大多数植物（稻、麦、豆、树、绝大部分温带草木），光合作用第一步生成三碳化合物，碳同位素分馏大，$\delta^{13}C$ 约 $-26.5‰$。
- **C4 植物**：适应高温干旱环境的植物（粟、黍、玉米、高粱、甘蔗），先固定四碳化合物，分馏小，$\delta^{13}C$ 约 $-12.5‰$。<span class="marginnote">C3 与 C4 相差约 14‰——如此之大的天然「标签」，让考古学家得以分辨史前中国人的主食是稻（C3）还是粟黍（C4）、美洲人的玉米（C4）何时进入食谱。玉米传入、粟黍农业起源的研究都直接建立在这一条分界上。</span>

但骨胶原的 $\delta^{13}C$ 不等于食物的 $\delta^{13}C$：碳在进入骨胶原时还会再富集约 5‰，所以**植物 → 食草动物 → 骨胶原**，C3 食物对应骨胶原约 $-21.5‰$，C4 约 $-7.5‰$。
<span class="marginnote">陆生与海生也有碳差异（海生食物链更长、碳源不同），所以单纯靠碳值可能把「吃海鱼的人」误判成「吃 C4 谷物的农人」——这就是为什么必须碳氮联用，见下节。
</span>

中国考古正是碳同位素的主战场：北方仰韶—龙山时期人群骨胶原 $\delta^{13}C$ 普遍偏正（C4 特征），对应粟黍主食；南方稻作区人群则偏负（C3 特征）。南北之间出现一条「碳同位素过渡带」，与「南稻北粟」的历史图景惊人吻合——同位素数据第一次让「南北生计差异」有了直接的人体证据，而不是只靠陶器与农具猜测。

## 3 氮同位素与营养级：餐桌上的金字塔

$\delta^{15}N$ 回答「你站在食物链的第几级」：氮同位素在**营养级之间逐级富集**，每升一级，$\delta^{15}N$ 大约升高 3–5‰。
素食者骨胶原 $\delta^{15}N$ 约 6–7‰，食肉者约 9–10‰，纯海生食物链顶端可达 14‰ 以上。
据此可以：

判断**肉食程度**：某遗址人群 $\delta^{15}N$ 显著偏高，可能意味着大量肉食或渔猎。
- 识别**哺乳与断奶**：婴儿吃母乳相当于「比母亲高一营养级」，$\delta^{15}N$ 出现特征性尖峰——据此可推断古代断奶年龄与人口结构。<span class="marginnote">断奶研究是同位素考古与社会人口学的交叉点：断奶年龄的早晚，暗含母婴关系、生育间隔与传染病压力的线索，甚至被用来讨论新石器「农业化之后人口爆发」假说。</span>
- 分辨**海陆**：海生食物链长、氮同位素富集多，配合碳值可以区分「沿海渔民」与「内陆 C4 农人」。

**碳氮联用**是标准做法：以 $\delta^{13}C$ 为横轴、$\delta^{15}N$ 为纵轴画双标图（biplot），C3 植物、C4 植物、食草动物、食肉者、海生食物各自占据不同区域，样品落点即其食谱画像。下图就是这张图的骨架。

同位素还能定量估计「食谱中 C3/C4 各占几成」。用最简单的二端元混合模型：若某人群骨胶原 $\delta^{13}C$ 为 $-15‰$，而纯 C3 饮食对应约 $-21.5‰$、纯 C4 饮食对应约 $-7.5‰$，则 C4 占比约为

$$
\frac{-15 - (-21.5)}{-7.5 - (-21.5)} = \frac{6.5}{14} \approx 46\%
$$

也就是说，这个人群的主食里粟黍（C4）与稻麦（C3）大致各半——「吃什么」从定性描述变成了可计算的百分比。真实研究还要考虑淡水、海生食物的干扰，但「线性插值」的骨架不变。

再补充一族方法：**氧同位素（$\delta^{18}O$）**存于牙釉质磷酸盐中，反映饮水与生活地域的降水信号——是「人从哪里迁徙而来」的探针；
氢、锶同位素也在此列，锶同位素（$\ce{^{87}Sr/^{86}Sr}$）尤其擅长追踪出生地与成年地的迁移，是「外来者」研究（如战俘、联姻、贸易移民）的关键工具。

## 4 公式解析：δ 记法是怎么算的

回到那条万法之源的公式，做三步拆解：

$$
\delta^{13}C_{sample} = \left( \frac{(^{13}C/^{12}C)_{sample}}{(^{13}C/^{12}C)_{VPDB}} - 1 \right) \times 1000\,‰
$$

- **第一步，比值先行**：对样品和标准分别测出 $\ce{^{13}C/^{12}C}$ 两个比值。同位素比的测定用质谱仪（IRMS），样品被气化成 $\ce{CO2}$ 后按质量分离计数。
- **第二步，做差、归一**：样品比除以标准比再减 1——得到的是「相对标准偏离了多少」。这个数通常是个极小的负小数（如 $-0.0265$）。
- **第三步，放大 1000 倍**：乘上 1000 变成 $-26.5‰$，一个方便阅读的整数级数字。正因为乘了 1000，δ 值是千分数——别把它当百分比，也别把「‰」写成「%」。

**辨析｜易错点：** 同位素读数是「比例」不是「量」：$\delta^{13}C$ 变正不表示「碳十三绝对变多」，只表示「相对标准变重」。此外，骨胶原是**有机质**，数千年埋藏里可能被微生物降解、被地下水污染——测定前要检验胶原的碳氮比（$\ce{C/N}$ 摩尔比在 2.9–3.6 之间才算「干净」），这正是同位素考古报告里必带的「质量指标」。骨胶原反映的是**死亡前十年左右的饮食**，牙釉质反映**幼年**——同一个人，不同组织对应不同人生阶段，选材即选问题。

## 5 术语速查：同位素考古关键词汇

| 术语 | 含义 |
| --- | --- |
| 稳定同位素 | 不发生放射性衰变的同位素（$\ce{^{13}C}$、$\ce{^{15}N}$、$\ce{^{18}O}$ 等） |
| δ 记法 | 相对国际标准的千分偏差，单位 ‰ |
| VPDB | 碳同位素的国际标尺（一种箭石化石标准） |
| AIR | 氮同位素的国际标尺（大气氮气） |
| VSMOW | 氧同位素标尺（国际标准海洋水） |
| C3 / C4 植物 | 两种光合作用途径，δ¹³C 相差约 14‰ |
| 分馏（fractionation） | 反应中轻重同位素行进速度不同导致的比值变化 |
| 营养级富集 | 氮同位素随食物链逐级升高 3–5‰ 的现象 |
| 骨胶原（collagen） | 骨中有机质，反映死亡前约十年的饮食 |
| 双标图（biplot） | 以 δ¹³C、δ¹⁵N 为轴区分食物类别的散点图 |
| 混合模型 | 用端元值反推食谱各组分占比的定量方法 |

## 6 小结

- **稳定同位素**通过 δ 记法（相对国际标准、单位 ‰）报告样品与标准的千分偏差，碳用 VPDB、氮用 AIR、氧用水标准。
- **碳同位素**分辨 C3/C4 光合途径（差约 14‰），经骨胶原富集约 5‰ 后判读谷类主食；**氮同位素**按营养级每级富集 3–5‰，判读肉食程度、哺乳断奶与海陆来源。
- **碳氮联用双标图**把食物类别画成不同区域，是食谱判读的常规操作；**氧、锶同位素**则追踪饮水与出生地，用于迁移研究。
- 同位素考古的前提是**样品未受成岩污染**（骨胶原 $\ce{C/N}$ 比验证），且**组织对应不同生命阶段**——读数必须与考古语境（墓葬、性别、随葬品）交叉解释。
