# 石器微痕与实验考古：一块石片的「案底」

<div class="epigraph">
<p>要知道一块石器用来干什么，最好的办法是自己去做一块，再用它干活。</p>
<footer>—— 谢苗诺夫（S. A. Semenov），《史前技术》（Prehistoric Technology）</footer>
</div>

## 为什么从一块石片开始

石器是人类制造的第一类工具，在旧石器遗址里动辄数以万计，而且**形态千篇一律**——多数石片长得很像。
最要紧的问题是：它们到底被用来干什么？
传统类型学只能按形状分类，却答不出功能。
答案藏在肉眼看不见的微痕里：**工具在干活时，会把自己的「工作经历」刻在刃口上**——被割过木头、刮过兽皮、剁过骨头，都会留下不同形态的显微磨损。
**微痕分析（use-wear / microwear analysis）**就是读这些「案底」。
<span class="marginnote">苏联学者谢苗诺夫 1964 年出版的《史前技术》是微痕分析的奠基作，但他用的是低倍显微镜、依赖主观经验；
真正的转折是美国人基利（L. Keeley）1980 年那本小书《石器用途的实验测定》——他把抛光形态系统化，
微痕分析才成为可检验的科学。
</span>

支撑微痕分析的，是一种更广的方法论——**实验考古（experimental archaeology）**：不靠想象，靠动手复刻。
它的逻辑朴素得近乎完美：**先做出「已知答案」的参照物，再用未知的考古器物去比对**。
这条「对照实验」思路，
正是「从极限到大模型」里一切科学实验与机器学习评测（训练集 / 测试集、对照组）的考古学同源体。

## 1 三种微痕：损伤、条纹与抛光

考古刃口上的微观证据主要有三类，各自携带不同信息：

**边缘损伤（edge damage）**：使用中刃口崩落形成的微小石片疤。低倍镜下可见。**崩疤的大小、形态与分布**透露运动方式与接触材料——刮削硬物（骨头）产生小而陡的崩疤，砍劈软物（肉）留下大而浅的损伤，受力方向决定崩疤偏向刃口的哪一侧。<span class="marginnote">读崩疤要小心：<strong>埋藏期间地层挤压也会让刃口崩落</strong>，与使用损伤形貌相近。所以边缘损伤必须与抛光、条纹等「使用特征」联看，单看崩疤极易误判——这也是微痕报告永远强调「多指标互证」的原因。</span>

**条纹（striations）**：接触物中的硬颗粒（沙、骨屑）在刃面划出的细线。**条纹的方向记录运动轨迹**（平行于刃＝刮削，垂直于刃＝砍切），条纹的粗细疏密间接反映接触材料。

**抛光（polish）**：这是基利方法的王牌。高倍显微镜（200–400 倍，金相显微镜）下，刃口因摩擦形成一层**均匀光亮、形态可辨识的「磨光」**。关键在于：**不同接触材料产生不同类型的抛光**——磨木头形成不平整、有波纹状轮廓的光亮面；磨兽皮形成暗淡、磨砂状、微滴状的光亮；磨骨角形成非常光亮、平坦但沟槽起伏明显的表面；加工植物茎叶则形成柔和、带编织纹理的光滑面。抛光类型因此成为「这件工具加工过什么」的直接证据。<span class="marginnote">近年 3D 激光共聚焦显微镜把抛光「看得更细」：用表面粗糙度参数（如 Sa、Sq）把「亮不亮」变成可测量的数字，微痕判读正从「目测比较」走向「定量检索」——很像计算机视觉里从人工特征到深度特征的进化。</span>

此外还有**残留物（residue analysis）**：刃口缝隙里残存的血液晶体、淀粉粒、植物纤维。
淀粉粒分析把石器功能与上一节植物考古的牙结石证据直接连通——同一件工具，
一边是使用微痕，
一边是它加工过的植物「细胞身份证」。

## 2 实验考古：制作一份「已知答案」的参照库

微痕最大的问题是：**同一形态可能有多种成因**。
因此必须建立「已知答案」的参照系，方法即实验考古：

1. **复刻**：用燧石、黑曜石按考古器物的打制方法（砸击、锤击、压制）做出同型工具。
2. **使用**：在受控条件下，用复刻工具分别去刮木头、割肉、剥皮、钻骨、收割谷物，每种材料、每种动作重复多件工具，记录使用时长与动作参数。
3. **记录**：观察并摄影每件实验工具的微痕，形成**参照抛光库（reference collection）**——一件工具「刚被刮过木头」的抛光长什么样，是查得到答案的。
4. **盲测（blind test）**：把考古石器（或另一批「隐瞒用途」的实验工具）交给分析者判读，比对真实用途检验判读准确率——这是对整套方法「校准」的独立检验。

这个流程与测年里的校准惊人同构：碳十四需要树轮建参照曲线，微痕需要实验建参照抛光库；
碳十四需要盲测样品验证，微痕需要盲测实验验证。
**科技考古的共同方法论，是把「未知信号」放到「已知参照系」上解读，而参照系必须自带误差检验。**<span class="marginnote">盲测的结果相当稳健：受过训练的微痕分析者对「大分类」（木、骨角、皮、肉、植）的判读准确率常达 70%–90%，但对「小分类」（哪种木材、生皮还是熟皮）仍会混淆——这提醒我们：方法的可信度是「分级的」，报告必须标明证据等级。
</span>

## 3 微痕怎么读：倍率、证据与陷阱

操作层面，微痕分析有两条技术路线：

**低倍法（low-power）**：立体显微镜（10–100 倍）看边缘损伤与粗条纹，快、可看大数量标本，但难分辨抛光类型。
- **高倍法（high-power）**：金相显微镜（200–400 倍）看抛光，是基利路线的核心；慢，但功能分辨率高。

现代微痕报告的趋势是**低倍初筛 + 高倍定功能 + 残留物/3D 量化补充**，多指标互证。

**辨析｜易错点：** 微痕判读有两个系统陷阱。其一是**埋藏学干扰**：砂土里的石器在埋藏中被磨出「土壤光泽（soil sheen）」，与使用抛光形貌相近——判断时必须区分抛光是否与刃口工作区重合、是否有条纹方向逻辑。其二是**「抛光 ≠ 材料」的过度解读**：木材加工抛光可能被骨骼加工覆盖（同一工具干过多样活），观察到的只是**最后一次主要使用的痕迹**；而加工含硅植物（收割谷物）产生的抛光与骨抛光也可能混淆。所以合格报告会写「最可能用途 + 置信度 + 替代解释」，而不是一句斩钉截铁的结论。<span class="marginnote">这与机器学习里的「不确定性校准」是同一种精神：一个负责任的分类器输出的是概率分布而非单点标签。微痕分析的成熟，正在于它学会了把自己的「不确定性」说出来。</span>

## 4 核心要点：抛光类型与工作材料的对应

| 工作材料 | 抛光特征（高倍镜下） | 典型工具动作 |
| --- | --- | --- |
| 木头 | 光亮、不平整、波纹状轮廓，偶见微坑 | 刮削、砍劈、钻孔 |
| 骨 / 角 | 非常光亮、平滑，带沟槽与隆起 | 雕刻、切锯、刮削 |
| 兽皮 | 暗淡磨砂、滴状或微颗粒状，低反射 | 刮皮、鞣革 |
| 肉类 | 弱、稀少、不连续的微亮 | 切割、肢解 |
| 植物茎叶 | 光亮柔和的网状纹理 | 收割、切草 |

这张表是「参照库」的浓缩——它提醒我们：**微痕分析不是看「有没有光」，而是看「光的形态与分布」**。
判别基于组合特征，而非单一指标。

## 5 小结

- **微痕分析**读三类证据：边缘损伤（运动方式）、条纹（运动方向）、抛光（接触材料），辅以残留物分析。
- **实验考古**是微痕的支柱：复刻工具 → 受控使用 → 建参照抛光库 → **盲测**验证判读准确率；这套流程与测年校准共享同一方法论内核。
- 判读分**低倍**（快、看损伤）与**高倍**（细、看抛光）两条路线，现代研究多指标互证并引入 3D 量化。
- 两大陷阱：**埋藏「土壤光泽」冒充使用抛光**、**工具多次使用导致「最后一次使用」偏差**——报告须带置信度与替代解释。
- 微痕分析成熟化的标志，是学会**表达不确定性**，而不是给出虚假的确定性结论。
