# 敦煌学

敦煌学是以敦煌石窟艺术、敦煌文献与河西历史为核心的国际显学，横跨考古学、艺术史、文献学与中古史研究。学完这些章节，就从藏经洞的发现走到敦煌写本学的研究前沿，理解一座沙漠边城如何成为世界学术的焦点。

## 对标教材

- 姜亮夫《敦煌学概论》（中华书局）
- 荣新江《敦煌学十八讲》（北京大学出版社）
