# 马克思主义哲学

以陈先达、杨耕《马克思主义哲学原理》为纲，辅以李秀林等《辩证唯物主义和历史唯物主义原理》与孙正聿《哲学通论》，系统重建从哲学观、唯物辩证法、认识论到历史唯物主义，直至马克思主义哲学史与国外马克思主义的完整理论体系。学完这些章节，就写完了哲学一级学科下首个二级学科（010101）马克思主义哲学的主体内容。

## 对标教材

- 陈先达、杨耕,《马克思主义哲学原理》(第5版),中国人民大学出版社
- 李秀林等,《辩证唯物主义和历史唯物主义原理》(第5版),中国人民大学出版社
- 孙正聿,《哲学通论》,复旦大学出版社
