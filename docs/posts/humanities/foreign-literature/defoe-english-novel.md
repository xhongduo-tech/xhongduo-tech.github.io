# 笛福与英国小说

## 为什么从笛福开始

启蒙文学的「小说崛起」，在**笛福（Daniel Defoe，约 1660—1731）**手里迈出了决定性的一步。
1719 年，年近六十的笛福出版了《鲁滨逊漂流记》（*Robinson Crusoe\*），讲述一个人被冲到荒岛上，靠双手与理性生存二十八年的故事。
这部书一问世就风靡欧洲，被译成几十种语言，成为世界文学史上流传最广的作品之一。
<span class="marginnote">《鲁滨逊漂流记》常被称作「英国第一部长篇小说」或「现代小说的奠基作之一」。
它并不是最早的散文叙事（前面有《十日谈》《堂吉诃德》），但它第一次把「虚构的个人传记」写得如此逼真、如此「现实」——
这就是现代小说的关键一步：让读者相信「这是真的」。
</span>

鲁滨逊之所以不朽，在于他是**「现代人的原型」**：孤身一人、白手起家、用理性与劳动重建文明。
他的荒岛，是整个人类处境的缩影。

## 1 从商人到小说家：笛福其人

笛福的一生充满传奇与波折：他做过商人（经营袜子、砖瓦、烟草），几次破产；
他写政治小册子，为政党论战，因讽刺国教被戴枷示众；
晚年为了还债，才转向写小说——
却在六年间一口气写了近二十部，成为英国小说真正的开创者。
<span class="marginnote">笛福「年近六十才开始写小说」的事实，是文学史上最励志的案例之一：他此前的失败（破产、入狱、遭人耻笑），恰好成了他小说的素材——他比任何书斋作家都更懂商业、债务、流浪与底层生活。
所谓「晚成」，往往是前半生都在为后半生的写作储存经验。
</span>

笛福的写作姿态极其「务实」：他不自命为「诗人」或「文人」，而自称是「讲故事的人」。
他的小说几乎都以**第一人称**写成，追求「像是真人的回忆录」的效果。
这种「伪传记」手法，是现实主义小说的核心技术。

## 2 《鲁滨逊漂流记》：荒岛上的现代人

《鲁滨逊漂流记》的情节家喻户晓：鲁滨逊不满足于安稳的中产生活，执意出海经商，遭遇海难，独自漂到荒岛。
他用破船的木板建屋、种麦、驯羊、做陶器，一步步把荒岛变成「微型文明」，最后救下土人「星期五」，并帮助船长夺回船只，重返英国。

这部小说的深层，是一个**个人主义的寓言**：

**白手起家**：鲁滨逊在荒岛上从零开始重建「文明」——这正是一个中产个人凭理性与劳动创造财富的过程。
**理性与工具**：鲁滨逊的每一件事都讲「计划」与「记账」——他像一个工程师兼会计师，把生存变成一项理性的工程。<span class="marginnote">鲁滨逊最动人的细节是他的「账本式叙事」：今天做了几块木板、收了几斗麦子、存了几只羊——他把生存写成一本收支明细。这种「精确到物件」的现实主义，让读者相信荒岛生活是真的。笛福用「细节」征服了读者，这是小说与传奇的根本区别。</span>
**孤独与自省**：在漫长的孤独中，鲁滨逊开始写「心灵日记」，从抱怨命运转向感谢上帝——荒岛成了他灵魂的修道院。

批评家（如伊恩·瓦特）指出，鲁滨逊是**「经济个人主义」的完美化身**：他代表十八世纪英国上升的中产阶级——
勤勉、务实、虔诚、占有欲强。
<span class="marginnote">伊恩·瓦特在《小说的兴起》（1957）中把鲁滨逊读作「经济个人主义」的典型：他的荒岛劳作，正是资本主义生产逻辑的缩影——把自然变成财产，把劳动变成积累。
这部小说因而既是现代小说的奠基，也是现代「经济人」的画像。
</span>

## 3 星期五与殖民的阴影

鲁滨逊在岛上救下的土人，取名「星期五」（因为救他的那天是星期五）。
从此他有了一个「仆人」——
鲁滨逊教星期五说英语、信基督教、称自己为「主人」。

这个设定在后世引发了巨大的争议：

**启蒙的读法**：鲁滨逊把「野蛮人」提升为「文明人」，是「白人的使命」的正面叙事。
**后殖民的读法**：星期五是**殖民关系的缩影**——白人用武力与宗教驯服「他者」，把他变成顺从的仆人。鲁滨逊对星期五的「恩情」，恰好是殖民权力的话语包装。<span class="marginnote">二十世纪后殖民批评（萨义德《东方学》等）重读《鲁滨逊漂流记》：荒岛是帝国的小型复制品，鲁滨逊是「殖民者原型」，星期五是「被殖民者原型」。这部三百年前的小说，因此成为今天讨论殖民主义与种族关系的重要文本——一部经典的「当代性」，正在于它能被不断重新提问。</span>

**辨析｜易错点：** 不要用今天的道德标准简单「审判」《鲁滨逊漂流记》，也不必否认它的殖民色彩。
正确的读法是**双重眼光**：既承认这部小说作为「现代小说奠基」的艺术贡献，也看见其中殖民主义与种族不平等的结构。
文本不是干净的，但正因不干净，才值得细读。

## 4 核心要点：鲁滨逊的多重读法

| 读法 | 鲁滨逊的形象 |
| --- | --- |
| 启蒙读法 | 理性与劳动战胜自然的现代人 |
| 经济读法 | 中产个人、经济个人主义的化身 |
| 宗教读法 | 孤独中的悔改与对神的感恩 |
| 心理读法 | 孤独、自省与自我认同的建构 |
| 后殖民读法 | 殖民者原型，星期五是被殖民者 |

## 5 延伸：《鲁滨逊漂流记》的「漂流」传统

《鲁滨逊漂流记》开创的不仅是「现代小说」，还有一套历久不衰的叙事类型——
**「荒岛/漂流」叙事**。
一个人在隔绝中重建文明，这个母题此后不断被重写。

- **《珊瑚岛》（1858）**：维多利亚时代的「荒岛小说」，把鲁滨逊的「个人奋斗」改写成「帝国的少年探险」。
- **《蝇王》（1954）**：戈尔丁的「反鲁滨逊」——同样是荒岛上的孩子，却走向野蛮而非文明。
它把笛福的「乐观的个人主义」彻底倒转：人性不是向善，而是向恶。
- **《少年派的奇幻漂流》（2001）**：把「荒岛」换成「救生艇」，把「重建文明」换成「生存与信仰」——漂流成为一个「灵魂的考场」。
- **现实中的「鲁滨逊」**：二战时日本兵横井庄一在关岛丛林独居二十八年，被称「日本的鲁滨逊」——证明「荒岛生存」不只是文学想象。

**辨析｜易错点：** 不要把《鲁滨逊漂流记》只读成「冒险故事」。
它真正的主题是**「一个人如何定义自己」**：在没有任何社会参照的荒岛上，「我是谁」只能由自己的劳动与信仰来定义。
这正是现代个人主义的起点——
而《蝇王》等「反鲁滨逊」作品，恰恰是对这个「个人主义神话」的怀疑。

**补充｜《鲁滨逊漂流记》的「真实感」秘密：** 笛福让小说像「回忆录」——
他声称这是「一个真实人物的真实故事」，并用了大量「账目式细节」（多少天砍木头、多少颗麦子）。
这种「伪真实」的技术，是小说第一次学会「让读者相信」。

**一句话记忆：** 鲁滨逊的荒岛，是现代人「白手起家」的第一张地图。

笛福让小说「像真事」，也让「普通人」第一次成为长篇的主角。

## 5 小结

- 笛福是**英国小说的开创者**，《鲁滨逊漂流记》是现代小说奠基作之一。
- 鲁滨逊是**现代人的原型**：白手起家、理性劳动、精确叙事。
- 小说用「账本式细节」与第一人称伪传记手法，营造出极强的现实感。
- **星期五**的设定让小说成为殖民关系与后殖民批评的重要文本。
- 读《鲁滨逊漂流记》要「双重眼光」：既看艺术贡献，也看见殖民的阴影。

在下一节，小说的幻想外壳将装上最锋利的讽刺——
斯威夫特让主角游历大人国、小人国，用童话的糖衣裹住对人类的冷笑，这就是《斯威夫特〈格列佛游记〉》。
