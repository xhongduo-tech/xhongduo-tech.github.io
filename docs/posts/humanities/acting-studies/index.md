# 表演学（表演理论/方法派/舞台表演/影视表演）

表演学是研究演员如何塑造人物、把生活转化为舞台与银幕艺术实践的系统学问。从斯坦尼斯拉夫斯基的体验派体系到契诃夫的方法派技术，再到舞台与镜头前的专业表演训练，它是演员、导演与所有表演艺术创作者的必修基础。

## 对标教材

- 斯坦尼斯拉夫斯基《演员的自我修养》（体验派表演体系奠基之作）
- 契诃夫《表演的技术》（方法派与技术型表演训练经典）
- 《表演艺术》（表演专业通用教材）
