## 为什么从相对主义开始

上一篇我们画出了元伦理学的立场地图：实在论说道德判断有客观真值，反实在论说不。
而在所有反实在论中，最流行、最像「常识」的一支就是相对主义。
它几乎是每个哲学入门者的第一反应——「道德不都是相对的嘛，各国有各国的规矩」。
但这一篇要告诉你两件事：第一，相对主义远没有看起来那么安全；
第二，**相对主义的大多数日常版本（「我们应该尊重不同文化」）根本不是相对主义，而是它自己极力否认的客观主义。**这一刀切下去，
相对主义就露出它的软肋。
理解它的软肋，是理解整个元伦理学为什么要存在的钥匙。

## 1 先分清三种「相对主义」

「相对主义」这个词被用得极滥。把它拆成三层，各有所指：

**描述性相对主义（descriptive relativism）**：一个经验事实的主张——不同文化确实信奉不同的道德规范。
这是人类学的日常发现，几乎没有争议。
<span class="marginnote">人类学家赫尔斯科维茨（Melville Herskovits）曾据此反对《世界人权宣言》的普世性：「标准与价值，原则上相对于产生它们的文化。」这是描述性相对主义被直接引向规范性结论的著名案例。</span>

**规范性相对主义（normative relativism）**：一个实质道德主张——一个人应当遵守自己社会的道德规范。
注意，这本身就是一个放之四海的主张，说它「相对」，其实非常不相对。

**元伦理相对主义（metaethical relativism）**：一个关于道德判断真值的主张——「X 是对的」为真，
当且仅当 X 被某社会（或某人）的道德规范所认可。
这才是哲学意义上的相对主义，我们这一篇的主角。

三者的关系值得划重点：**描述性相对主义不蕴涵元伦理相对主义。**从「不同文化信奉不同的规范」推不出「对错因文化而异」——就像从「不同社会信奉不同的天文学」推不出「地心说对他们为真」。
这一步推不出来，正是沙弗-兰道用整章篇幅要讲清的事。

## 2 文化相对主义及其论证

**文化相对主义（cultural relativism）**：道德对错是相对于社会的，
一个行为在一个社会是对的，只因为那个社会的规范认可它。
它的核心命题是：

$$\text{「行为 } X \text{ 在 } S \text{ 社会是对的」} \iff S \text{ 的规范认可 } X$$

这个「当且仅当」是它的全部家当。为什么有人相信它？通常通过一个三段论：

- **前提**：不同文化有不同的道德规范。
- **前提**：因此，不存在适用于一切文化的客观道德标准。
- **结论**：所以道德对错是相对于文化的。

这个论证叫**文化差异论证（cultural differences argument）**，
而沙弗-兰道的批驳直接而致命：**前提二不从前提出。**两个社会对「多配偶制」看法不同，
只能推出「至少有一方是错的」或者「双方都错」，推不出「双方都对（相对而言）」。
用科学类比：地心说与日心说对立，不等于没有客观的天文事实，只说明至少一方错了。
分歧的存在本身，恰恰预设了「存在一个唯一正确答案」这件事是有意义的。
<span class="marginnote">我们把这个逻辑写进第一级·基础数学的语言：从「主张 A 与主张 B 互不一致」能推出「A、B 至少有一假」，但推不出「无真值」或「各为真」。这是命题逻辑的基本教训，在这里原样上演。</span>

## 3 相对主义的三个代价

即使文化差异论证成立，文化相对主义也会把自己逼进三个难堪的角落。
这三个「代价论证」是理解相对主义最有效的棱镜。

**代价一：跨文化批评变得不可能。** 假如对错由社会规范决定，
那么「纳粹对犹太人的暴行是错的」这句话，对于纳粹社会而言就是假的（因为纳粹社会的规范认可它）。
相对主义者想谴责纳粹，却发现自己被自己的理论缴了械——**他们只能对纳粹说「我们不赞同你们」，而说不出「你们错了」。**

**代价二：道德进步被定义为不可能。** 废奴主义者认为奴隶制是错的，而当时的美国南方社会认为它是对的。
若「对」等于「社会认可」，那么南方人的判断为真，废奴主义者反社会，当然是错的。
可今天几乎所有人（包括相对主义者）都相信废奴是道德进步。
相对主义把这个「进步」解释没了。<span class="marginnote">沙弗-兰道的措辞很尖：在相对主义框架里，道德改革家永远是错的——他们的主张恰好不获社会认可，于是自动为假。一个把「改善道德」说成不可能的理论，值得怀疑。</span>

**代价三：社会的边界无法说清。** 一个人同时属于无数个「社会」：家庭、公司、民族、国家、宗教团体。
文化相对主义需要回答：**到底以哪个社会的规范为准？**如果以「我的社会」为准，那我的哪个社会？
这个问题至今没有令人满意的答案，而答案的缺失让这个理论在「应用」层面寸步难行。

## 4 个体主观主义：相对主义的个人版

把「社会」缩小成「个人」，就得到相对主义的另一个版本——**伦理主观主义（ethical subjectivism）**：一个行为对某人而言是对的，
当且仅当这个人认可它。

它有一种著名的形式：**简单主观主义（simple subjectivism）**——「X 是对的」意谓「我赞同 X」。
这个版本立刻暴露一个荒谬推论：既然「X 是对的」就是「我赞同 X」，
那么「我赞同 X 但 X 是错的」这句话就变成「我赞同 X 但我不赞同 X」——**自相矛盾，不可能为真。**可我们明明能毫无矛盾地说「我赞同婚前同居，
但婚前同居是错的」——这正是我们讨论道德的方式。
简单主观主义把一个日常的、有意义的疑问变成了逻辑矛盾，说明它把道德语言的语义搞错了。
<span class="marginnote">这个「自反性」检验在本专题反复出现：一个道德理论是否成立，先看它能不能让「我承认 X 而 X 仍是错的」这句话成立。做不到的理论，都没有抓住道德判断的客观维度。</span>

更精致的相对主义会引入「理想化的赞同」——以「我在充分知情、头脑冷静时会赞同的」为真值标准。
但这一步已经是在向客观性撤退了：一旦加入「充分知情、头脑冷静」这些限定词，
真值就不再由「谁赞同」直接决定，而由「理想状态下的判断」决定——那已经半只脚踏回实在论。

## 5 核心要点：三种立场速查表

| 立场 | 「偷窃是错的」是什么意思 | 我能否批评他人的道德？ |
| --- | --- | --- |
| 道德实在论 | 一条客观事实，不取决于态度 | 能——对方的判断可能是错的 |
| 文化相对主义 | 我的社会不认可偷窃（为真或为假取决于社会） | 不能——对方的判断对「他们」为真 |
| 个体主观主义 | 我不认可偷窃（我的态度就是全部） | 不能——对方的判断对「他们」为真 |

这张表最能暴露相对主义的代价：**它用「不能批评他人」换取了「宽容」的美名，却连自己最想谴责的事都谴责不了。**许多人是怀着「宽容」的善意成为相对主义者的，
但宽容本身是客观的善——它恰恰预设了「应当宽容」对所有人都成立。
**辨析｜易错点：**「我们应该尊重不同文化」是一个普世主义的规范性主张，不是相对主义；
把它当成相对主义，是初学者的经典失误。
相对主义说的是「对错因文化而异」，而不是「每种文化都该被尊重」——后者是一个放之四海的道德要求，与相对主义在逻辑上是敌对的。

## 6 小结

- 相对主义有三个层次：**描述性、规范性、元伦理**，三者不能混为一谈，前两者不蕴涵第三者。
- 文化差异论证**推不出**元伦理相对主义：从「分歧存在」只能推出「至少一方错了」。
- 相对主义的三个代价：**跨文化批评不可能、道德进步不可能、社会边界说不清**。
- 个体主观主义使「我赞同 X 而 X 是错的」成为矛盾，暴露了它对道德语义的误解。
- 相对主义与实在论的真正分歧在于：**真值是否由态度决定**——这是整张立场地图上的一条主轴。

在下一节，我们将离开「真值相对不相对」的战场，转向一个更根本的挑战：**表达主义**——它干脆说，道德判断压根没有真值，它只是在表达情绪。
