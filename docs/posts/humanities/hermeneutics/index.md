# 解释学

解释学（诠释学）是大陆哲学传统中关于"理解"与"解释"的哲学学科：从施莱尔马赫、狄尔泰的普遍诠释学，经海德格尔、伽达默尔的存在论诠释学，直至利科的文本解释学，它追问我们如何理解文本、历史与他人，与现象学、存在主义并列而自成一派。学习解释学，是进入当代人文学科方法论与存在论反思的必经之路。

## 对标教材

- 伽达默尔《真理与方法》（洪汉鼎译，商务印书馆）
- 洪汉鼎《诠释学——它的历史和当代发展》（人民出版社）
- 利科《解释学与人文科学》（河北人民出版社）
