## 为什么从「视角」开始

上一篇的思维模式回答「用谁的认知框看世界」，这一篇的**视角（point of view）** 回答一个更基本的问题：**故事从谁的位置、以谁的眼睛看？** 同一个事件，警察、凶手、受害者、旁观者各有版本——小说家对「谁在看」的选择，几乎是叙事权力最重要的分配。<span class="marginnote">本篇主要对标 Simpson《Stylistics》第七章「Style and point of view」，并呼应 Leech & Short《Style in Fiction》第六章。视角是叙述文体学的枢纽：话语呈现（上一篇）、思维模式（上上一篇）都会在视角分析里汇合。</span>

「谁在看」听起来是文学课的老问题，但它有**确定的语言指纹**：人称、指示词、情态、感知动词、话语呈现方式。文体学的任务，就是把「视角」从抽象的叙述学概念还原成一句句可以被指认的文体标记——你不仅能说出「这是第一人称内视角」，还能说出**凭什么语言证据**这么说。

视角分析还牵动着一个更深的问题：**视角不只是「看」，更是「叙述者与读者之间关系的设定」。** 从全知俯瞰到贴身内视，叙述者选择站在多高的位置、多近的距离，读者就被安排在什么位置——视角的每一次调整，都是对读者注意力与判断的一次规划。

## 1 视角的四分格

Simpson 把视角的种种说法整理成一套简洁的四分格，由两个维度交叉而成：

**维度一，人称**：叙述者用**第一人称**（I / we，「我」在故事里）还是**第三人称**（he / she，「他」在故事里）？这决定叙述者是否亲身卷入故事。

**维度二，观察位置**：叙述是**内部的（internal）**——进入人物意识内部，还是**外部的（external）**——只从外面观察人物？<span class="marginnote">这两个维度的经典出处是珀西 · 拉伯克（Percy Lubbock）在《The Craft of Fiction》中提出的「pictorial vs dramatic」、以及更早的「戏剧式 vs 回顾式」。Simpson 把它们收进一个两维矩阵，操作性更强。</span>

两维交叉得到四类视角：**第一人称内部**（自传体、日记体，「我」直接袒露内心）、**第一人称外部**（「我」叙述自己当年的行为，如同旁观过去的自己）、**第三人称内部**（第三人称但镜头探入人物意识——19 世纪小说、意识流的主场）、**第三人称外部**（纯行为报道，叙述者不进入任何人意识）。**先定人称，再定内外，视角就有了坐标。**

四个象限里，**第一人称外部**最容易被人忽视：它看似「我」在讲述，实则以旁观姿态看待过去的自己——回忆录、成长小说常用它制造「当年的我」与「现在的我」之间的张力。读此类文本时，要格外留意叙述者如何评价当年的自己：**那层评价，就是时间距离写在视角上的痕迹。**

## 2 视角的文体标记：指示中心

叙事总有一个**指示中心（deictic centre）**——叙述立足的时空坐标。视角的切换，就是指示中心的移动；而指示中心在语言上由一组**指示语（deictics）** 锚定：

**人称指示**：I / you / he——谁在说话立场上？
**空间指示**：here / there、this / that、来 / 去（come / go）——叙述者站在哪里？
**时间指示**：now / then、今天 / 那天——叙述者站在何时？
**情态与感知**：maybe / perhaps、seemed / looked——叙述者如何限定「知道」？

举一个经典的例子：若叙述者说「the door opened **towards me**」，this 与 me 表明叙述者站在室内；若改为「**he** saw the door open」，指示中心转移到被观察的「他」身上。**视角不是「感觉」，而是指示语在文本里的实际分布。**

再来一个更有欺骗性的例子：第三人称叙述里出现 this、now——「She looked at **this** man before her **now**」——this 与 now 表明指示中心其实移到了人物身上，尽管人称还是第三人称。**人称属于叙述者，指示语属于人物**，这种「混搭」正是内视角最常见的语言信号，也是 FIS 得以运作的机制之一。

把指示语整理成一张对照表，分析时逐项核对：

| 指示类别 | 内视角立足点 | 外视角立足点 |
| --- | --- | --- |
| 人称 | I / he（贴近人物） | he / it（间离） |
| 空间 | here / this | there / that |
| 时间 | now / today | then / that day |
| 感知 | felt / saw / seemed | 少感知动词 |
| 情态 | maybe / perhaps 密集 | 断言为主 |

这张表是视角分析的「工具箱」：**每核对一项，视角就清晰一分。**<span class="marginnote">指示中心还会随叙述层移动：第一人称回顾型叙述里，「我」回忆当年，「现在」的叙述者与「当年」的体验者共享同一个人称，却拥有不同的时间指示——这种分裂正是文学性的重要来源。</span>

## 3 内外视角的切换与前景化

视角分析最关键的动作，是**追踪视角的切换点**。正常叙事会维持一个稳定的指示中心；当中心突然移动——从第三人称外部突然探入某人的内心，或从内视角突然拉远——读者会「咯噔」一下。这个「咯噔」，就是视角在前景化。

Simpson 特别关注一种切换机制：**视角的叙事层与人物层之间反复滑动**。作家用自由间接引语（见第四篇）、用感知动词（felt、saw）把镜头推入人物，又用客观陈述把镜头拉回叙述层。伍尔夫的《到灯塔去》是切换的艺术：叙述平滑地在多个角色的内心之间滑行，指示中心一路漂移，读者跟着「看」而不自知。

**外部视角**常配被动态与概括性叙述（事件被「报告」），**内部视角**常配感知动词、直接思维呈现与 FIS（经验被「体验」）。因此：**内外视角的分界，几乎可以凭句子的文体标记自动判断。**

视角切换还有一个电影式的对应物：**镜头语言。** 外部视角像远景与中景，内部视角像特写；「视角切换」相当于剪辑。黑泽明《罗生门》用四个视角讲同一场凶案——每个视角都自认真实，真相却藏在视角的缝隙里；福克纳《喧哗与骚动》由班吉、昆丁、杰生轮流叙述，正是同一手法的文字版。**多视角叙事把「真相只有一个」改写成了「真相取决于谁在看」。**<span class="marginnote">一个实用的分析口诀：看到「said」「saw」「felt」+ 人物内心内容 → 内部视角；看到概括、被动态、无个人色彩 → 外部视角。先看指示语，再看感知动词，视角就藏不住。</span>

## 4 视角的文体效果：同情与权力

视角不只是一个技术旋钮，它直接生产**伦理与情感效果**——这也是 Simpson 把它与「point of view」并置讨论的原因。

**同情（sympathy）**：内部视角让读者「进入」人物——我们同情那些看到其内心的人。狄更斯笔下的孤儿、托尔斯泰笔下的安娜，一旦镜头探入内心，读者就难以再苛责；相反，只从外部呈现的人物，容易沦为评判的对象。

**距离与喜剧**：外部视角把人物「看扁」——读者只见其行为，不见其动机。喜剧惯用外部视角，把人物框成笑料；侦探小说则借外部视角对所有人保持怀疑，把「内心」当作唯一的悬念来源。

**不可靠叙述（unreliable narration）**：当第一人称内部视角的叙述者自我美饰、隐瞒或说谎（纳博科夫《洛丽塔》中的亨伯特即是经典），读者的认知与叙述者的说法之间出现裂缝——这个裂缝正是布思（Wayne Booth）所谓「不可靠叙述」的文体根源，也是批评文体学（第十一篇）的入口。

于是视角问题的伦理分量浮出水面：**谁被允许拥有「内心」，谁只被从外部「观察」，这本身就是一种立场。** 视角即立场——这句话是通向下两篇的关键。

## 5 视角与叙述层：套娃结构

视角还会发生「套娃」：一个叙述者讲述另一个叙述者。**叙述层（narrative levels）** 理论区分**故事外叙述者（extradiegetic）**与**故事内叙述者（intradiegetic）**——讲故事的「我」与故事里再讲故事的「我」，属于不同的叙述层。

《一千零一夜》是套层结构的教科书：山鲁佐德在皇城讲述故事，故事里的人物又讲起自己的故事——每一层都有独立的指示中心与视角。**跨层（frame break）** 是套层叙事最刺激的时刻：人物突然跳出自己的层，对读者或上一层说话，视角的秩序被打破，前景化随之爆发。<span class="marginnote">叙述层理论与叙事学（humanities 另一个已完成的专题《叙事学》）深度重叠：那里讲「叙述层次」，这里讲「视角随层次而变」。跨专题读者会发现两套术语是一枚硬币的两面。</span>

分析套层叙述，要逐层标明「谁在讲、站在哪一层、用谁的视角」——**把叙述分层，是视角分析在长篇小说里最硬核的体操。** 读完一篇《一千零一夜》式的作品，能分清几层视角，才算真正读懂了它的结构。

## 6 核心要点：内外视角的文体标记对照表

本篇以概念与识别工具为主，用一张对照表把「怎么从文体标记判断视角」落成可操作清单：

| 文体标记 | 内部视角（进入意识） | 外部视角（旁观） |
| --- | --- | --- |
| 人称 | 第一人称或第三人称（贴近人物） | 第三人称居多（间离） |
| 指示语 | this / now / here（人物现场） | that / then / there（叙述者立足点） |
| 感知动词 | felt / saw / seemed（体验） | 少有，多为行为陈述 |
| 话语/思维呈现 | FIS、直接思维呈现密集 | 以概括、NRSA 为主 |
| 情态 | 人物主观情态（maybe、wish） | 叙述者客观断言 |
| 典型效果 | 共鸣、沉浸、暧昧 | 客观、讽刺、掌控 |

判断视角的操作顺序：**先定人称 → 再看指示语与感知动词 → 最后看话语呈现方式**。三步走完，视角就有坐标，切换点也就浮出水面。

这四个维度内部其实互有配合：人称决定「身份」，指示语决定「立足点」，感知动词决定「镜头是否探入」，话语呈现决定「内心如何被转述」。**四者同时校准，视角的判断才靠得住**——只凭人称就下结论，是最常见的偷懒错误。

## 7 小结

- **视角** = 谁在看、从哪看、站得多近；Simpson 用「人称 × 内外」的二分维把视角整理成四分格。
- 视角有**确定的语言指纹**：人称指示、空间/时间指示、情态、感知动词、话语呈现方式。
- **指示中心**是视角的锚：视角切换 = 指示中心的移动；稳定的中心被打破处，就是前景化。
- 外部视角偏爱客观概括与被动态，内部视角偏爱感知动词与自由间接引语——**凭标记可判内外**。
- 视角分析与话语呈现（第四篇）、思维模式（第五篇）汇合：三套工具共同构成叙述文体学的核心。
- 视角的选择是**权力分配**：谁被允许进入内心，谁只被从外部观察，本身就是叙事立场的表态。
- 视角效果可归于三点：**同情**（内部视角）、**距离与喜剧**（外部视角）、**不可靠叙述**（视角与读者的认知裂缝）。
- 叙述可以分层（套娃）：故事外叙述者与故事内叙述者各有独立指示中心；跨层即前景化。
