## 为什么从历史气候变迁开始

「气候」看起来最不可捉摸，
却是历史地理学里证据链最完整、对全局影响最深远的一环。
它的一冷一暖、一干一湿，
能改写农业的收成、牧草的生长、河流的丰枯，
进而撬动人口迁移、都城选址与王朝兴衰。
<span class="marginnote">这不是模糊的因果猜想，
而是被大量实证支撑的机制链：气候 → 农业产量 → 粮价与人口 → 社会秩序与政权更替。
历史气候研究因此被称为历史地理学的「上游学科」。
</span>

这一节我们沿时间轴向下游走，
把「气候」这个要素彻底展开——它是本专题的第一把尺子（时间）与第二把尺子（要素）的第一次交汇。
理解它，后面的河流改道、人口迁移、农牧交错带进退就都有了公共的底层变量。

## 1 如何「读」出千年前的气候

现代气候观测只有一百多年，
要复原千年前的气候，
必须依赖**代用资料（proxy data）**——用可观测的间接证据反推当时的气温与降水。
历史气候学的主要证据有四类，
各有其时间分辨率与局限：

**物候记载**：历史文献中关于桃、杏、梅开花的日期、候鸟来去的日期、霜冻与大雪的记载。<span class="marginnote">物候是「活的温度计」：同一地点杏花初开的日期每提早一天，往往意味着春季气温升高约 0.5–1℃。中国文献从甲骨文起就偶见物候，到《礼记·月令》已系统化。</span>
**雪线、冻土与极端天气事件**：湖心结冰记录（如鄱阳湖、洞庭湖的冰封记载）、极端霜冻、酷暑、大旱、大涝的频次统计。
- **自然代用指标**：树木年轮宽度、湖沼沉积物中的花粉组合、冰芯氧同位素——它们把时间分辨率提高到「年」甚至「季节」。
- **考古与遗迹证据**：古水稻、古麦遗存、干涸湖泊的贝壳层、历史时期的长城与农田遗址，反映的是千年尺度的干湿格局。

**重点：历史气候学是「多源互证」的学科**——单条物候记录可能被讹误或夸大，
但当文献记载、年轮、孢粉三条独立证据链指向同一结论时，
结论就可信。

## 2 万年尺度：冰期结束以来的气候大轮廓

从人类文明诞生到今天的近一万年，
气候在万年尺度上大体经历了**升温期 → 大暖期 → 降温波动期**三个阶段：

**全新世大暖期（约 1.1 万年前至 6000 年前）**：全球气温比现代高约 2–3℃，
中纬度雨带北移。
黄土高原与黄河流域植被比今天繁茂，
华北平原湖沼广布。
<span class="marginnote">大暖期的余晖中，
仰韶文化（约 7000–5000 年前）在黄河中游兴盛——气候宜人是农耕文明在北方兴起的地基。
</span>

**暖期之后的波动**：距今约 5000 年以来，
气温总体缓慢下降，
但叠加了千年尺度的冷暖振荡。
正是这些「小尺度」振荡，
构成了历史时期气候研究的主角。

| 时段 | 冷暖特征 | 温度相对今值（约） |
| --- | --- | --- |
| 仰韶—殷商（约公元前 5000—前 1000） | 偏暖，属大暖期后半段 | +2℃ 左右 |
| 西周至春秋（约公元前 1000—前 500） | 转冷 | 接近今值 |
| 秦汉暖期（约公元前 200—公元 200） | 偏暖 | +0.5℃ 左右 |
| 魏晋南北朝冷期（约公元 200—580） | 偏冷 | −0.5℃ 左右 |
| 隋唐暖期（约公元 580—960） | 偏暖 | +0.5℃ 左右 |
| 两宋冷期（约公元 960—1230） | 转冷 | 接近今值或略低 |
| 元明之间转暖（约公元 1230—1400） | 温和 | +0.3℃ 左右 |
| 明清小冰期（约公元 1400—1900） | 显著偏冷 | −1℃ 至 −0.5℃ |

这一张表，就是中国历史气候的「总谱」——下面的所有讨论，
都在这张谱上找坐标。

## 3 公式解析：把「冷暖序列」写成数据

历史气候研究里最常用的一条「公式」不是数学恒等式，
而是一条**标准化距平（anomaly）**：把某一时段的温度与一个参考时段（通常取现代平均）作差，
得到相对变化的幅度。

$$\Delta T_t = T_t - \bar{T}_\mathrm{ref}$$

- **第一步，读懂符号**：$T_t$ 是第 $t$ 年的代用温度估计，$\bar{T}_\mathrm{ref}$ 是参考期（如 1961—1990）的平均温度，$\Delta T_t$ 就是「距平」。当 $\Delta T_t>0$ 时当年偏暖，反之偏冷。
- **第二步，为什么用距平**：绝对温度受测量口径影响大、可比性差；距平去掉了「平均水平」这个难以统一的常数，让不同地点、不同证据在同一把标尺上比较——这也正是时间序列分析里「去趋势」「标准化」的同一思想。<span class="marginnote">把「距平」换成机器学习术语，就是中心化（centering）：减去均值只改变截距、不改变形状，使序列在 0 上下摆动，便于对比。这是第七级《时间序列分析》的日常操作。</span>
**第三步，对序列做平滑**：单年代用值的噪声很大，研究者常用滑动平均把千年尺度趋势「滤」出来。滑动窗口越长，曲线越平滑、但转折点越迟钝——噪声与分辨率之间永远存在权衡，这与信号处理里的「低通滤波」完全同构。

现代研究把考古、物候、年轮等十几条序列拼合，
用统计方法重建出过去两千年的温度曲线。
这些曲线清楚显示：**过去两千年中国温度的总体趋势是缓慢降温，
其中叠加了若干次百年尺度的冷暖波动**；
而「明清小冰期」正是距今最近、史料记载最详尽的一次寒冷低谷。

## 4 冷暖如何改写历史：三个经典案例

气候曲线本身只是骨架，
它的意义在「落地」。
三个案例足以说明冷暖如何渗透进历史进程：

**暖期北上：汉代与唐代的农牧分界**。
秦汉与隋唐两大暖期，
气温偏高、降水偏多，
半干旱草原的农牧交错带明显北移，
农业垦殖推至长城以北。
<span class="marginnote">以阴山以南地区为例，
唐代的农业边界比明代靠北，
所以李白才写「五月天山雪，
无花只有寒」——那是在讲农牧交错带的真实样貌。
</span>牧场退、农田进，
中原政权得以在北方保持军事与经济优势。

**冷期南下：农牧交错带与民族格局**。
魏晋南北朝冷期，
草原气候恶化、牧草减产，
游牧力量被气候「推」向南方；
而中原农业又因寒害减产。
两种压力合流，构成十六国与南北朝时期大规模民族迁徙与政权重组的环境背景。
侯仁之与谭其骧都强调：**看民族关系史，
不能不看气候曲线**。

**小冰期与明清社会**：明代小冰期（约 15—17 世纪）北方旱涝加剧，
长城沿线饥荒频仍。
气候的干冷直接抬高了北方边防的军事与财政压力——「气候—农业—财政—军事」的链条在明代史中清晰可见。
<span class="marginnote">这不是说气候决定一切。
研究共识是：气候是重要的外部约束与触发条件，
社会制度与政策才是最终决定因素——气候提供「压力」，
社会选择「应对」，
而应对的成败取决于制度。
这就是人地关系里「环境制约」与「人类改造」的辩证。
</span>

## 5 小结

- 历史气候的证据来自**代用资料**：物候、极端天气、年轮孢粉、考古遗迹，须**多源互证**。
- 万年尺度看，全新世大暖期之后**总体降温**，叠加千年与百年的冷暖波动；两千年来的温度可用**距平序列**重建。
- 冷暖通过**农牧交错带**、**农业产量**、**民族格局**三条通道影响历史进程——暖期农牧线北移、冷期南下。
- 气候是**约束而非宿命**：它提供外部压力，社会制度决定应对方式——这正是人地关系的生动注脚。

在下一节，我们把气候的「判决书」应用到地面上：看千年冷暖如何导演了黄河的改道、湖泊的兴衰与沙漠的进退——**历史自然地理**。
