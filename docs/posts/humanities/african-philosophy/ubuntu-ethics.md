## 为什么从「Ubuntu」开始

非洲哲学里没有一个概念比 **Ubuntu** 更出圈。它是南非宪法序言的价值观来源之一，是曼德拉与图图公开宣讲的伦理语汇，也是近年 AI 伦理、全球正义讨论里反复被「出口」的非洲概念。但越流行的概念越容易被稀释成一句口号。本节的目的是把 Ubuntu 从口号还原为哲学：它到底主张什么、在什么传统里、与自由主义伦理的分歧在哪。

Ubuntu 是祖鲁语/科萨语词，字面义「人性」，核心箴言是**「一个人通过他人而成为人」（a person is a person through other persons）**。图图把它阐发为「我的人性与你的人性不可分割地交织在一起」。这套伦理学被当代哲学家（如南非的蒂埃里·梅茨 Thad Metz）系统化，成为「非洲道德理论」的代表。对标教材里，维雷杜《Companion》第 40 章「西方与非洲的社群主义：一个比较」（Western and African Communitarianism）与第 25 章「非洲的人格概念」共同撑起这个话题。<span class="marginnote">Ubuntu 与《从极限到大模型》的对话很直接：AI 对齐的伦理争论里，西方主流框架（功利主义、康德义务论）都是「个体为本」的；Ubuntu 提供一个「关系为本」的替代选项——「一个能促进共同体和谐的 AI」与「一个最大化个体效用的 AI」，评价标准完全不同。</span>

为什么 Ubuntu 值得一篇独立博文？因为它同时是三样东西：**一句箴言**（可被大众传颂）、**一套道德理论**（可被哲学家系统化）、**一个政治原则**（可被写进宪法）。本专题之前的篇章处理「非洲哲学是否存在」「它如何做」，本节开始处理「它主张什么」——从伦理开始，因为伦理是非洲哲学最直接可用的部分。

还有一层现实的原因：**Ubuntu 是非洲哲学对全球问题最成熟的一次输出**。从南非真相与和解委员会（图图任主席）到「非洲人工智能伦理」倡议，Ubuntu 被反复调用为一种「非西方」的治理与伦理资源。这意味着学 Ubuntu 不只是学一个哲学概念，而是在学非洲思想如何参与世界性对话——这也是本专题最后那篇《非洲哲学与西方哲学的对话》的伏笔。

## 1 关系优先：Ubuntu 的元伦理主张

Ubuntu 的第一个哲学主张是**关系本体论**：人不是先孤立存在、再进入关系的原子，而是**在关系中才成为人**。图图的「交织」、姆比提的「我在，因为我们存在」（I am because we are）、奥鲁卡的「无一人孤立地思考」，都在表述同一个直觉：自我的构成是关系性的，而非原子性的。

这在元伦理层面意味着：**脱离关系讨论道德是范畴错误**。功利主义问我「如何最大化总体效用」，康德问我「什么是对一切理性者普遍有效的义务」，两者的出发点是孤立的行动者；Ubuntu 则问「我的行为如何塑造我与他人、与共同体的关系」。道德的单元不是单个行动，而是关系本身。**有 Ubuntu 的人**：慷慨、好客、友善、关怀、有同情心；**没有 Ubuntu 的人**：自私、冷漠、把他人工具化。在这个框架里，「道德失败」被诊断为「关系失败」。<span class="marginnote">注意区别两个层次：作为<strong>描述</strong>，「非洲人重视集体」容易滑向刻板印象；作为<strong>规范</strong>，「关系是道德的载体」是一个可辩护的哲学命题。本节的讨论始终在规范层——不是「非洲人事实上如何」，而是「Ubuntu 主张我们应该如何」。</span>

### 与「个人主义」的对照

Ubuntu 的道德直觉与欧美个人主义的对照，值得用一个生活例子看清。想象两个人在深夜的路边看到一辆抛锚的车。

**个人主义视角**：我该不该帮忙？——取决于我的义务（通常没有法律义务）、成本收益（帮了有什么好处）、以及普遍的「应然」（如果我需要帮助，别人也应该帮我）。**Ubuntu 视角**：我帮不帮忙？——我的人性与那位车主的人性交织在一起；我不帮，受损的不只是他，还有这个共同体、以及我自己作为人的完整性。「我」的利益在此不再与「他」的利益分家——这就是「关系优先」在微观层面的运作。

### 关系本体论的哲学辩护

「关系本体论」不是一句诗，它有一个可以论证的形而上学版本：**如果一个人的身份（我是谁、我追求什么、我珍视什么）在很大程度上由他与重要他人的关系构成，那么「孤立的自我的道德」在概念上就是空的**——因为没有那个可被孤立的自我。这条论证路径与西方哲学里查尔斯·泰勒（Charles Taylor）的「对话式自我」、女性主义伦理学家内尔·诺丁斯（Nel Noddings）的「关怀伦理」高度共鸣：关系优先不是非洲独有的主张，而是反对「原子式个人主义」的哲学家族的一员。Ubuntu 的特殊性在于，它把这条主张更彻底地制度化——从人格概念一路推到政治制度。

## 2 人格作为成就：门基蒂与圭耶克之争

Ubuntu 伦理学的核心构件是**人格（personhood）概念**。这里有一个教科书级的争论：人格是出生即得的，还是后天挣得的？

**伊菲安伊·门基蒂（Ifeanyi Menkiti）**主张：人格不是生物事实，而是**规范成就**。人出生时只有「人」的生物学地位，要成为**完整的人格**，须经过道德成熟的过程——承担责任、履行义务、融入共同体。死亡也并非人格的终结：祖先是「活着的人」的延续（living-dead），随着记忆的消失才逐渐退出人格领域。门基蒂的人格观是**彻底（激进）社群主义**：共同体先于个人，个人靠共同体才得以成为人。批评者指出，这种立场可能意味着：未成熟者（婴幼儿）、被排斥者（某些女性、残障者、性少数）「不成其为人」——这正是《Companion》第 47 章女性主义批判的靶点。

**夸梅·圭耶克（Kwame Gyekye）**主张**温和社群主义**：人格随出生自动获得，共同体与个体相互构成、相互扶持。他承认门基蒂的激进立场有把个体压扁的风险，但也不接受自由主义的原子主义——他坚持个体镶嵌在传统与共同体之中。

**维雷杜**提供了第三种声音：**「把个体利益调整到与共同体利益一致，不是把前者从属于后者——二者的关系是对称的。」** 他坚持个体与共同体的利益可以同时实现，社群主义与个人主义只是「安排个人利益的不同方式」，差别在于：在社群主义社会里，个体对其他人的福祉负有更多义务、也拥有更广的关怀范围。他的立场既拒绝了激进社群主义对个体的吞噬，也拒绝了自由主义对共同体的遗忘。<span class="marginnote">把三位思想家的位置放到一条线上：门基蒂在「共同体优先」的一端，圭耶克在「个体—共同体互成」的中段，维雷杜试图证明「个体利益」与「共同体利益」本可对称——这是一条从激进到温和的连续谱，而不是三个孤立的立场。</span>

### 人格可度量性的一个推论

如果人格是成就，是「多或少」而不是「有或无」，那么它会产生一个有趣的推论：**道德评价的对象从「行为」扩展到「存在方式」**。一个人可以「整体上更有 Ubuntu」或「整体上更少」——评价的不是某一次选择，而是持续的存在状态。这与美德伦理学（德性是品格，不是行为）天然亲近，也是梅茨把 Ubuntu 称为「人格完善论（perfectionist）」理论的原因——它要求人持续地「成为更完整的人」。

### 活着的死人：人格如何延续到死后

门基蒂的人格观还有一个特别的形而上学延伸：**人格在死后依然延续**。去世的祖先被称为「活着的死人」——只要还有人在记忆中供奉他们，他们就还是共同体的一分子，还保有「人格」；直到记忆与祭祀断绝，才逐渐退为无名的集体祖灵。这意味着人格的边界不是「出生—死亡」，而是「被记住—被遗忘」。这条线索我们会在《非洲形而上学》一节展开——现在先记住结论：在 Ubuntu 的框架里，道德共同体不仅包括活人，还包括「活着的死人」。

## 3 Ubuntu 的道德推理：从同情到共识

Ubuntu 落到道德推理上，呈现出两个特点。

**第一，道德动机以「同情—共生」为核心**。西方义务论靠「普遍化」产生动机（我能愿意所有人都这样做吗），功利主义靠「效用计算」产生动机（哪种做法总和最大）；Ubuntu 的动机来自**对他人生存与幸福的切身感知**——我的人性在他人的人性里，损害他人就是损害自己。梅茨把它形式化为一条原则：**道德上正当的行为，是能促进共同体团结与和谐、能促进成员繁荣的行为**。

**第二，决策方法偏好「共识」而非「多数决」**。这与非洲传统的议事制度（见本专题《非洲政治哲学》的 consensus democracy）一脉相承：道德与政治决策都应追求让相关各方都能接受的共识，而不是把少数人的立场压掉。这条偏好后来被引入 AI 伦理的「包容性治理」讨论——让受影响者参与对齐标准的制定，而非由工程师单方面决定。<span class="marginnote">把 Ubuntu 与康德义务论对照：康德说「人是目的，不可只作手段」；Ubuntu 说「人是关系中的存在，其繁荣依赖共同体」。前者保护个体免受工具化，后者要求个体积极承担关系义务——一个防御性的，一个建设性的。</span>

### 一个难题：Ubuntu 如何对待「外人」

Ubuntu 的一个真实难题是边界：**「关系」若以共同体为界，那么共同体之外的陌生人该被如何对待？** 批评者（如奥约维 Oyowe）指出，如果道德价值的根基是「共同体和谐」，那么共同体之外的人（外国人、异族、敌人）就可能被排除在道德关怀之外——这比康德的普遍义务更危险。

Ubuntu 哲学家的回应通常有两路。**一路**是扩大「共同体」的定义：整个非洲、乃至全人类都是一个更大的共同体，共生关系可以扩展。**另一路**是把「关系」本身当作普遍价值：只要对方是有关系潜能的生灵，就进入道德考量。这两路回应至今仍在争论中——对 AI 伦理尤其尖锐：如果「共同体」扩展到机器，机器要不要进入道德共同体？这个问题的答案，将决定 Ubuntu 能否真正成为「全球伦理」的备选方案。

这个难题也让我们看到 Ubuntu 的真实面貌：它不是一套封闭的教条，而是一个**仍在被建构的理论**。它既不是「非洲过去的遗物」，也不是「西方伦理的翻版」，而是当代非洲哲学家们正在与全球问题对话时不断打磨的对象——正如洪通吉所说，非洲哲学存在于未来。

## 4 核心对比表：Ubuntu 与三种主流伦理

这是纯概念主题，用核心对比表把 Ubuntu 放进伦理学的坐标系：

| 维度 | 功利主义 | 康德义务论 | Ubuntu 伦理 |
| --- | --- | --- | --- |
| 道德单元 | 单个行动的结果 | 单个行动者的义务 | 关系与共同体 |
| 人的定位 | 效用的载体 | 理性自主的行动者 | 关系性存在 |
| 道德动机 | 效用最大化 | 普遍化与尊重 | 同情—共生 |
| 核心禁令 | 不减总效用 | 不把人当手段 | 不脱离关系 |
| 决策方法 | 计算 | 律令演绎 | 共识协商 |
| 人格观 | 个体即目的 | 理性者即目的 | 人格是成就（可度量） |

## 5 易错点辨析与延伸阅读

**辨析｜易错点：** 两个常见误读要避开。

其一，**不要把 Ubuntu 等同为「集体主义」**。Ubuntu 不是「个人让位于集体」，而是「个人的善与集体的善在关系里互相成就」——维雷杜的「对称性」论说的正是这一点。把 Ubuntu 讲成「牺牲个体成就集体」，是对它的自由主义式误读。

其二，**不要把 Ubuntu 讲成一句免责口号**。「有 Ubuntu」若只是嘴上说说，道德力量为零；它要求的是持续的存在方式——做人做得「更完整」，这是品格工程，不是社交辞令。

想深入这一节，可以读：

- 维雷杜主编《A Companion to African Philosophy》第 40 章——西方与非洲社群主义的比较。
- 门基蒂《Person and Community in African Traditional Thought》——激进社群主义原典。
- 梅茨《Toward an African Moral Theory》（2007）——Ubuntu 的系统化。
- 图图《没有宽恕就没有未来》（1999）——Ubuntu 在和解政治中的运用。

**进一步追问**：Ubuntu 把「人格」定义为「共同体中的成就」，那么一个主动退出共同体的隐士、一个自愿孤立的思考者，在 Ubuntu 框架里是「更不像人」吗？如果你觉得这里有问题，你正好踩到了「关系本体论」最紧张的那根弦——下一节的非洲人格形而上学，会给你更多弹药。

## 6 小结

- Ubuntu 的核心主张是**关系本体论**：人在关系中成为人，道德单元是关系而非孤立的行动。
- **人格是成就还是赠予**：门基蒂主张激进社群主义（人格是挣得的），圭耶克主张温和社群主义（人格随出生自动获得），维雷杜主张个体与共同体利益的**对称性**。
- Ubuntu 的道德动机是**同情—共生**，决策方法偏好**共识**而非多数决。
- 人格可度量产生推论：道德评价的对象从**行为**扩展到**存在方式**，与美德伦理学亲近。
- Ubuntu 的边界难题：共同体之外的陌生人如何被对待？「扩大共同体」与「关系即普遍价值」是两条回应路线。
- 与西方主流的对照：功利主义算效用、康德讲义务、Ubuntu 修关系。
- 它已从南非宪法进入全球 AI 伦理讨论，成为「关系为本」伦理的代表选项。
- 关系本体论并非非洲独有：它属于泰勒「对话式自我」、关怀伦理同一个反对原子主义的哲学家族。
- 人格在死后延续为「活着的死人」——道德共同体不止包含活人。
- Ubuntu 不是封闭教条，而是当代非洲哲学家与全球问题对话中仍在建构的理论。

在下一节，我们将把 Ubuntu 背后那套「关系性存在」推到形而上学深处：非洲哲学如何理解存在、人格与时间——为什么姆比提说传统时间「几乎只有过去」。
