# 中国少数民族语言文学

中国少数民族语言文学研究中国境内各少数民族的语言与文学，覆盖语言系属、语音词汇语法结构、语言志田野方法，以及从神话传说、民歌到作家文学的完整文学谱系，并深入口头传统与史诗的诗学机制。它处于语言学与文学研究的交叉地带，是理解中华民族多元一体文化格局的关键视角。

## 对标教材

- 马学良、梁庭望主编《中国少数民族文学史》中央民族大学出版社
- 戴庆厦主编《中国少数民族语言研究》民族出版社
- 朝戈金《口传史诗诗学》中国社会科学出版社
