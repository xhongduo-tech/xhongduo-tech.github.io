# 陈望道两大分野：消极修辞与积极修辞

## 为什么从两大分野开始

上一篇我们走完了中国修辞的千年传统，现在抵达现代中国修辞学的枢纽——**陈望道**（1891—1977）的《修辞学发凡》（1932）。这部书里最著名、也最能代表其体系化的贡献，是把一切修辞现象切成一刀两半：**消极修辞**与**积极修辞**。

为什么从两大分野开始？因为它用一根线，把修辞学的全部问题分成了两类。消极修辞问：「怎么说才能把意思说清楚？」积极修辞问：「怎么说才能把话说得动人？」前者是底线，后者是上限。陈望道断言，任何语辞活动都在这两端的拉扯之中——理解这道分野，你就拿到了拆解汉语修辞（以及一切写作）的万能分类器。<span class="marginnote">「消极」「积极」是陈望道的术语，初读容易误会。它不表示好与坏，而是指「防止表达失败」与「追求表达精彩」两种不同的努力方向。用现代说法：消极修辞 ≈ 把话说「对」且「通」，积极修辞 ≈ 把话说「美」且「劲」。</span>

对「从极限到大模型」的读者，这个分野还相当现代：技术文档、法条、论文摘要几乎全是消极修辞的天下，而广告、口号、小说则靠积极修辞撑场。甚至评价大模型的输出，「信息准确、表达通顺」是消极标准，「生动、有感染力」是积极标准——两者缺一不可。

还要先交代陈望道的学术身份：他早年是语言学与传播学者，翻译过《共产党宣言》，参与过白话文运动，深谙语言学理论。这使《发凡》与传统的文话、诗话判然有别——它用**语言学的眼光**看修辞，把修辞现象当作「语辞的调整」来系统研究，而非只作审美品评。这正是「现代修辞学」的标志。

## 1 消极修辞：把意思说清楚

陈望道把消极修辞定义为**「使语辞明白晓畅」**的努力。它的目标是让表达不出岔子：词义不含混、语法不错乱、逻辑不跳跃、让人一看就懂。它对应的是「平实的语言」——科学报告、法律条文、公文、教科书、说明书，全都以消极修辞为纲。

陈望道为消极修辞立下了四条标尺，常常被并提为「四性」：

**明确**：词义确定、不含歧义，能让听话者准确抓住所指。
**通顺**：语序流畅、句读分明，读起来不拗口、不阻滞。
**平匀**：分量匀称、前后一致，不忽高忽低、不东拉西扯。
**稳密**：稳妥而严密，表述周全，不授人以柄。

四条标尺合起来，就是一句话：**消极修辞追求「零事故」**。它不追求惊艳，只追求不出错；而「不出错」在科学、法律、公务这些严肃场合，恰恰是最高的美德。<span class="marginnote">注意一个容易忽略的点：消极修辞不等于「没文采」。陈望道反复强调，消极修辞本身就是一种积极的能力——把复杂的事说简单、把易误解的话说精确，需要极高的功夫。法律里「一字千金」的表述，正是消极修辞的杰作。</span>

举一个对比就清楚了。药品说明书若写成「此药甚妙，服之百病皆消」，虽生动，却既不明「明确」也不合「稳密」；规范写法是「每日三次，每次一片，饭后服用；肝功能不全者慎用」——无一句出彩，却句句站得住。**消极修辞的价值，正在于让最要紧的话经受得起一万遍的推敲。**

## 2 积极修辞：把话说动人

如果说消极修辞是「防败」，积极修辞就是「求胜」。陈望道定义积极修辞为**「使语辞生动形象」**的努力：它不满足于「明白」，还要「传神」；它的目标是激起读者的情感与想象，让语言具有感染力。

积极修辞分两大部类。其一是**辞格**——陈望道系统整理的三十八种修辞格式，如比喻、借代、拟人、夸张、反复、对偶、排比、反问、双关、析字、回文等，每一格都有一套结构规律。其二是**辞趣**——陈望道的独创概念，指词语本身的**情调与意味**：词语的读音、字形、联想会带来超乎字面的趣味，如双声叠韵的声感、谐音双关的机趣。辞格靠「结构」，辞趣靠「风味」。

积极修辞的极端形态是**辞格连用、堆叠**——诗歌、骈文、广告语往往如此。但陈望道同样警告：积极修辞若脱离内容，就成了「虚浮」；它与消极修辞不是对立，而是**在消极的底盘上起高楼**。<span class="marginnote">陈望道对「辞趣」的重视在修辞学史上很有特色：西方传统多关注辞格的结构，陈望道则补上了「词语本身的情味」这一维度——谐音、节奏、字形带来的微妙感受。今天讨论「语感」「文字的温度」，其实都在辞趣的延长线上。</span>

一条现代广告可以当范文：「怕上火，喝王老吉。」八个字里，「怕」起欲、「上火」戳痛点、「喝」给出口——这是积极的辞趣与意境的调度；而它之所以能立住，正因为它先满足「明确」（清楚传达了品类与功效）与「通顺」（朗朗上口）的消极底线。**最好的文案，往往正是「消极打得稳、积极放得开」的产品。**

## 3 三十八种辞格的体系

积极修辞的第一大部类「辞格」，是《发凡》最著名的工程：陈望道系统整理了**三十八种辞格**，并把它们按「着力点」分成四组，这是汉语辞格研究的经典分类：

| 组别 | 着力点 | 代表辞格 |
| --- | --- | --- |
| 材料上的辞格 | 利用词语指称的事物 | 譬喻、借代、映衬、摹状、双关、引用、仿拟 |
| 意境上的辞格 | 利用意念与情感的联想 | 比拟、讽喻、示现、呼告、夸张、婉转、避讳、设问、感叹 |
| 词语上的辞格 | 利用词语的形音义 | 析字、藏词、飞白、镶嵌、复叠、节缩、省略、警策、回文 |
| 章句上的辞格 | 利用句式的组织与变化 | 反复、对偶、排比、层递、错综、顶真、倒装、跳脱 |

这套分类的关键在「着力点」：同样是让语言生动，有的靠**材料**（借彼喻此），有的靠**意境**（造境生情），有的靠**词语**（玩字形音义），有的靠**章句**（变句式节奏）。抓住着力点，就不必死记三十八种，而能「按图索骥」——看到一个辞格，先问它动的是哪一块。<span class="marginnote">这种「先立类别、再列成员」的分类法，与西方把辞格分为转义（tropes）与句式（schemes）的二分有异曲同工之妙，但陈望道的四组更贴合汉语自身的肌理——比如「析字」「回文」这些汉字特有的辞格，西方传统就无从谈起。这正是《发凡》「立足汉语」的体现。</span>

**辨析｜易错点：** 有人以为「辞格 = 修辞的全部」。陈望道明确反对——辞格只是积极修辞的一部分，积极修辞还有辞趣；而积极修辞又只是两大分野之一。把修辞窄化成「背辞格表」，恰恰是把《发凡》读反了。

还要提一句这四组的实践含义：写作者最常用的辞格，往往集中在**材料组与意境组**（譬喻、借代、夸张、拟人等），因为它们直接服务于「生动」；而**章句组**（反复、对偶、排比）则塑造行文的节奏与气势。读文章时用这张表一对照，就能看出作者「在哪里用力」——是更倚重词语的机巧，还是更倚重句式的气势。

## 4 两大分野的关系：底盘与高楼

消极修辞与积极修辞不是两个并列的房间，而是一个**地基与建筑**的关系。陈望道的原话是：消极修辞是「最低限度的努力」，积极修辞是「最高限度的努力」。

**先有消极，后有积极**：一篇文章必须先通顺明白，才谈得上生动感人。若连话都说不清，堆再多辞藻也只是「以辞害意」。**消极管住「底」，积极撑起「顶」**：科学文体几乎只用消极，文学文体消极与积极并用——但即便在最华丽的诗里，句子的「通顺」与「明确」底线也不能破。

**辨析｜易错点：** 不要以为「积极修辞 `>` 消极修辞」。在法庭、医学、工程、财经这些「一句话都可能致命」的领域，消极修辞的权重远高于积极。陈望道的体系之所以高明，正在于它不把「积极」捧为高级，而是把两者放进一个「视情境而定」的坐标——决定用哪一边，看**题旨与情境**。

用工程来打比方：一座桥的**承重结构**必须消极修辞——任何一句表述都要经得起审查，因为它承载的是生命；桥上的**装饰浮雕**则可以积极修辞——花纹、诗句、石刻，为的是动人。桥不能只有装饰没有承重，也不必只有承重毫无装饰。陈望道的两大分野，教的就是这种「哪里该保守、哪里该出彩」的配比艺术。

## 5 题旨情境：修辞的最高统帅

两大分野之上，陈望道还立了一个总纲——**「题旨情境」**。这是《发凡》全书的思想核心：一切修辞活动，最终都要服从「题旨」（说话的目的与主题）与「情境」（说话的场合、对象、上下文）。

「修辞以适应题旨情境为第一义」——陈望道这句纲领，把修辞从「辞藻技术」拉回「语境适配」。同一个人，写法律文书用消极修辞，写情书用积极修辞；对着婴儿讲话用一种语，对着院士答辩用另一种语。**没有放之四海而皆准的修辞**，只有「在这一题旨、这一情境下最合适的修辞」。

这也解释了为什么「同一个意思，换个人说、换个地方说，效果完全不同」：决定表达成败的，常常不是话本身，而是话与情境的适配度。学修辞的进阶，就是从「把话说对」走向「在此时此地，把话说得最对」。<span class="marginnote">「题旨情境」论可与西方传统对照：它几乎就是古希腊「得体」（decorum）与「场合意识」的中国版，但陈望道把它讲得更贴近「目的—对象—场合」三位一体。现代语用学的「语境」「会话含义」，也在同一方向上前进。</span>

这一条对今天的写作意义重大：写报告先问「给谁看、要达成什么」，再决定用消极还是积极——这正是「题旨情境」的现代操作化。

陈望道还强调「情境」包含**对象、目的、场合、上下文**等一切外在条件：对农民讲农业技术，与对农学院士讲，用词、详略、文白都该不同；同一句话在法庭上和在酒桌上，效力天差地别。可以说，「题旨情境」就是陈望道的「得体论」——它要求修辞者时刻把「正在跟谁、为何事、在何地说话」挂在心头。

## 6 核心对比表：消极修辞 vs 积极修辞

纯概念主题，用核心对比表代替公式解析：

| 维度 | 消极修辞 | 积极修辞 |
| --- | --- | --- |
| 目标 | 明白晓畅、不出事故 | 生动形象、富有感染力 |
| 判断标准 | 明确、通顺、平匀、稳密 | 贴切、有力、传神 |
| 主要手段 | 词义精确、语序规范 | 辞格（38 种）+ 辞趣 |
| 适用领域 | 科学、法律、公文、教学 | 文学、广告、演讲、诗歌 |
| 对读者的态度 | 让读者「读懂」 | 让读者「心动」 |
| 失败形态 | 含混、晦涩、歧义 | 虚浮、堆砌、失真 |
| 现代对应 | 技术写作、plain language | 创意写作、广告文案 |

这张表可以当「写作体检表」用：拿到一段文字，先看它是否需要积极修辞（有没有调动情感的需要），再检查它的消极底线（是否明确通顺）。**绝大多数表达问题，都能归入「该积极而消极了」或「该消极而积极了」两类**——这是陈望道两大分野最实用的遗产。

把这张表接到全课程体系上：写作教学的「先求通顺、再求生动」正是两大分野的顺序论；沟通表达课讲的「看场合说话」正是题旨情境的通俗版；甚至连大模型评测里的「可读性」与「感染力」两个维度，也能在此找到理论源头。陈望道的分野论，是中文语境里理解一切表达的第一把尺。

## 7 小结

- 陈望道《修辞学发凡》（1932）把修辞分为**消极修辞与积极修辞**两大分野。
- **消极修辞**求「明白晓畅」，立「明确、通顺、平匀、稳密」四标尺，主用于科学、法律、公文。
- **积极修辞**求「生动形象」，含**三十八种辞格**与**辞趣**两大部分。
- 三十八种辞格按着力点分四组：**材料、意境、词语、章句**。
- 两大分野是「底盘与高楼」的关系：先有消极的底线，才谈得上积极的精彩。
- **题旨情境**是最高统帅：修辞以适应题旨情境为第一义。
- 两大分野不是等级，而是「视情境而定」的两极——决定用哪边，看目的、对象与场合。
- 陈望道用语言学眼光研究修辞，是「现代中国修辞学」的开创者。

在下一节，我们将告别古典与现代中国的修辞学，迎来 20 世纪西方修辞学的复兴。佩雷尔曼（Perelman）重拾论辩，伯克（Burke）提出「认同」——那是「新修辞学」的登场，它要把修辞学从「文体之学」重新抬回「人类行为之学」。
