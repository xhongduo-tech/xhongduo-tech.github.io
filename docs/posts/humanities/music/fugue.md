## 为什么从赋格开始

前几章的和声曲式（奏鸣曲、回旋曲）都是「纵向思维」的产物——和弦作为柱子，旋律作为横线。而**复调（polyphony）**代表的另一种思维：**多条旋律线同时独立歌唱、互相应答**。赋格（fugue）是复调音乐的最高形式——一条主题（subject）像一粒种子，在所有声部中被轮流播种、发芽、变形，织成一张严密的对位之网。理解赋格，等于理解音乐如何「用一条线长出一个世界」——它也是巴赫音乐世界观的浓缩：秩序、对话、无限衍生。

## 1 赋格的基本要素

**赋格（fugue）建立在一条「主题」上，用对位技术让各声部依次进入并持续展开。** 核心要素：

- **主题（subject）**：赋格赖以建立的核心旋律，短而有个性，通常 1–2 小节。
- **答题（answer）**：主题的「回应」，在属调上进入——常为「五度移位」或「守调答题」。
- **对题（countersubject）**：与答题同时奏出的新旋律，与主题形成对比与配合。
- **小结尾（episode）**：主题缺席的过渡段落，由动机碎片模进发展，负责转调与喘息。

**公式解析：赋格 = 主题的函数式展开。** 设主题为 $S$，答题为 $A$（$S$ 的属调移位），对题为 $C$，则赋格的纹理可写作

$$\text{赋格纹理} = \sum_{\text{声部}} \big( S \ \text{或} \ A \big) + \sum_{\text{空隙}} C + \sum_{\text{插部}} E_i$$

**第一步，主题 $S$ 在主调进入；第二步，答题 $A$ 在属调应答，同时对题 $C$ 伴随；第三步，各声部轮流「追跑」，插部 $E_i$ 提供转调过渡。** 赋格的魅力在于：**同一主题，在不同的音高、不同的声部、不同的调上反复出现**——像同一个问题被不同声音从不同角度回答。<span class="marginnote">答题分为「真实答题」（严格的五度移位）与「守调答题」（局部调整，避免转调太远）。守调答题是赋格里最精妙的细节之一：当主题从主音到属音时，答题往往从属音回到主音——像对话中对方「顺着你的话但调转话头」。</span>

## 2 赋格的结构：呈示部与展开

**赋格的结构分为呈示部、中间部与再现部（结尾部）三大板块：**

- **呈示部（exposition）**：所有声部依次以「主调—属调」交替进入，主题首次完整亮相——赋格的「亮相仪式」。
- **中间部（middle section）**：主题在不同调上反复出现（各次进入之间有插部连接），调性游移、动机发展——赋格的「展开旅程」。
- **结尾部（final section）**：主题回到主调，常用紧接段（stretto）把主题叠加，推向终点的强收束。

**公式解析：呈示部的声部进入顺序。** 四声部赋格的呈示部通常为

$$S(\text{主调}) \to A(\text{属调}) \to S(\text{主调}) \to A(\text{属调})$$

**第一步，第一个声部奏主题 $S$；第二步，第二个声部以答题 $A$ 进入，第一个声部转为对题 $C$；第三步，第三、第四声部依次重复「主—属」交替。** 这套「主—属—主—属」的进入序列，像多声部接力——每个新声部接棒，旧声部继续陪伴。**呈示部结束的标志是「所有声部都唱过主题」**，此后进入自由的展开。<span class="marginnote">巴赫《平均律钢琴曲集》（Das Wohltemperierte Klavier）包含 48 首前奏曲与赋格，是赋格艺术的圣经。其中《C 大调赋格》（BWV 846）四声部进入如清泉依次注入，是理解呈示部的完美范本。</span>

## 3 赋格的展开技法

赋格在中间部与结尾部使用一系列变形技法，构成它的「修辞库」：

- **紧接段（stretto）**：主题尚未结束，下一声部就抢入——主题与主题叠加，制造迫近与高潮。
- **增值/减值（augmentation/diminution）**：主题时值加倍或减半，变换其性格。
- **倒影（inversion）**：主题音程方向反转。
- **逆行（retrograde）**：主题从尾到头倒奏。
- **双重/三重赋格**：不止一条主题，第二条主题加入共同展开。<span class="marginnote">这些技法构成了复调的「变换群」——把主题当作可逆、可缩放、可镜像的数学对象。增值使主题「慢下来、变庄严」，紧接段使主题「叠起来、变紧迫」。巴赫《赋格的艺术》就是一部「主题变形大全」，堪称复调的「词典」。</span>

**辨析｜易错点：** 赋格不是「主题+伴奏」，而是**全声部对位**——每个声部都是旋律，都值得单独倾听。初学者常把赋格听成「旋律 + 背景」，但其实没有任何声部是「背景」：对题、插部都是独立线条。**听赋格的正确姿势是「跟线」——每次主题进入时把耳朵转向那个新声部。**

## 4 赋格的历史地位

**赋格在巴洛克时期达到巅峰，巴赫是集大成者**——《平均律》《赋格的艺术》《管风琴赋格》是复调文学的巅峰。赋格不仅是一种曲式，更是一种「思维方式」：它把「一条思想如何被多声部讨论」做到了极致。<span class="marginnote">赋格思维甚至超越了音乐：赋格的「主题—答题—对题—插部」结构，常被用来类比科学对话（一个命题被不同视角检验）、甚至是递归程序（同一过程在不同层级反复调用）。贝多芬晚年奏鸣曲与弦乐四重奏里的「赋格段」（fugato），就是把这种严密思维塞进古典曲式的「智力闪光」。</span>

**公式解析：赋格的「话题延续」判据。** 一段音乐要算赋格，必须满足

$$\exists S: \quad S \ \text{在不少于两个声部以不同调出现} \ \text{且} \ \text{各次进入之间有插部衔接}$$

**第一步，找主题 $S$；第二步，确认它在 ≥2 个声部以主/属调交替出现；第三步，确认插部衔接。** 满足这三条才是严格赋格；只局部使用赋格手法（一段中突然的模仿进入）叫**赋格段（fugato）**——常见于奏鸣曲展开部与歌剧序曲，是赋格思维「低配」的渗透。

## 5 赋格的聆听方法

**赋格是最「复杂」的曲式，聆听需要一套「跟线」策略**——不然会迷失在声部森林里：

1. **等主题**：赋格开头总是「单声部奏主题」——竖起耳朵记住它，这是唯一的「主角」。
2. **跟进入**：主题依次在各声部进入（主—属—主—属），像接力棒传递——每次主题出现，耳朵就「转台」到新声部。
3. **放对题**：主题不在时，听对题与插部如何「填空」——插部是「喘息与转调」，可以放松。
4. **找紧接**：结尾部常出现「紧接段」（主题叠加）——张力最高处，主题层层追跑。

**公式解析：赋格的「进入序列」。** 四声部赋格呈示部的进入顺序为

$$S(T) \to A(D) \to S(T) \to A(D) \quad \text{（主调主题、属调答题交替）}$$

**第一步，记住主题 $S$；第二步，听它何时以答题 $A$ 在属调出现；第三步，数清全部声部进入一遍 = 呈示部结束。** 这套「数进入」法让赋格的结构一目了然——**赋格不是「混沌的多声部」，而是「主题的接力赛」**，每次主题进入都是一次「声部交棒」。<span class="marginnote">听赋格最容易的入门曲：巴赫《平均律》第一卷 C 大调赋格（BWV 846）——四声部依次进入如清泉注入，结构最清晰。<strong>听赋格的「心理准备」：它不是「一条旋律 + 伴奏」，而是「四条旋律轮流当主角」</strong>——心态对了，复杂就变成了丰富。</span>

## 6 练习与自测

1. **听题**：听巴赫《平均律》C 大调赋格（BWV 846），数出呈示部四个声部的进入顺序——主、属、主、属。
2. **辨题**：区分「赋格」与「赋格段」（fugato）——赋格段只在局部使用模仿进入，不是完整赋格。
3. **析题**：听《赋格的艺术》中的增值/减值赋格，感受主题「变慢/变快」——同一主题的时值变形。
4. **唱题**：跟唱主题（可用 do 代替音名），在赋格播放时「唱出每一次主题进入」——训练「跟线耳朵」。
5. **探题**：比较巴赫《平均律》与肖斯塔科维奇《二十四首前奏曲与赋格》——同一赋格体裁，两个时代的对话。

**自测答案要点**：赋格 = 主题（S）在多个声部以主/属调交替进入 + 插部衔接；呈示部 = 所有声部各唱一次主题；紧接段 = 主题尚未结束、下声部抢入。

## 7 延伸聆听与思考

**赋格是「智性的音乐」，聆听推荐从清晰的开始：**

- **巴赫《平均律》第一卷 C 大调赋格（BWV 846）**：四声部进入最清晰，初学者最佳入门。
- **巴赫《平均律》第一卷 c 小调赋格（BWV 847）**：节奏紧凑、紧接段密集，进阶练习。
- **巴赫管风琴赋格（如 g 小调 BWV 578）**：宏大音响中的声部层次。
- **肖斯塔科维奇《二十四首前奏曲与赋格》**：二十世纪的赋格，现代感与巴赫对话。

**思考题：**

1. 赋格的「主题」为什么必须「短而有特点」？太长的主题会带来什么问题？
2. 「守调答题」与「真实答题」的区别是什么？为什么有些主题必须守调？
3. 紧接段（stretto）为什么常在结尾部出现？「主题叠加」如何制造高潮？
4. 赋格的主题变形（增值、倒影、逆行）与变奏曲的「变奏」有何异同？

**赋格的思考题，核心是「一条思想如何被多声部讨论」**——它是复调思维的极致，也是「秩序中生出丰富」的音乐证明。

## 8 小结

- **赋格**以一条主题为核心，各声部依次「主—属」交替进入，构成呈示部。
- 结构为**呈示部—中间部—结尾部**；对题、插部、紧接段是三大辅助部件。
- 展开技法构成复调「变换群」：紧接、增值/减值、倒影、逆行、多主题。
- **赋格是复调的最高形式**：全声部独立歌唱，巴赫《平均律》《赋格的艺术》是巅峰范本。
- 聆听法 = 「跟线」：等主题 → 跟进入 → 放对题 → 找紧接——赋格是「主题的接力赛」。
