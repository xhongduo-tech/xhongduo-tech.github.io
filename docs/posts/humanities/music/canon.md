## 为什么从卡农开始

赋格用「主题多声部轮唱」建立了复调的殿堂，而**卡农（canon）是复调里最纯粹、最严谨的一种**：一个声部奏出完整旋律，另一个声部延迟若干拍后以同样（或变形）的旋律跟入——像回声，像接力。卡农的规则简单到一句话「后者模仿前者」，却能产生惊人的丰富性。帕赫贝尔《卡农》几乎人人耳熟，但它只是卡农家族的冰山一角。理解卡农，等于掌握「**时间错位中的自我对话**」——这也是循环神经网络、回声、迭代算法等一切「反馈结构」在音乐里的原型。

## 1 卡农的定义与基本形态

**卡农（canon）是一种严格的模仿对位：一个声部（导句，leader）奏出完整旋律，其他声部（答句，follower）延迟一定时间后，以相同或变形的形式跟入。** 最基本的卡农形态：

- **同度卡农**：答句与导句音高相同，仅时间错开。
- **八度卡农**：答句在上下八度进入。
- **五度/四度卡农**：答句在五度或四度上进入，常与「循环卡农」（如《轮唱曲》）配合。

**公式解析：卡农 = 导句 + 延迟 + 跟入。** 设导句旋律为 $M(t)$（$t$ 为时间），答句为

$$M'(t) = M(t - \Delta) + \text{移调（可选）}$$

**第一步，确定导句 $M$；第二步，确定延迟量 $\Delta$（通常 1–2 小节）；第三步，答句在 $\Delta$ 后以 $M$ 的移调版本进入。** 关键要求：**导句与答句必须「合得拢」**——两条相隔 $\Delta$ 的旋律在纵向同时发声时，要构成协和的对位。这就是卡农写作的难点：你写的不只是一条旋律，而是「一条旋律 + 它自己的所有延时切片」同时成立。<span class="marginnote">轮唱曲（round）是卡农的通俗形态：《两只老虎》《伦敦桥》都是同度轮唱——大家唱同一条旋律，只是不同声部在不同小节开始。为什么听起来不混乱？因为轮唱曲的旋律被精心设计过：它与「自己延迟一拍」的版本天然协和。<strong>卡农作曲本质上是在「解一个自洽性方程」——让旋律与自身延时后的版本兼容。</strong></span>

## 2 卡农的变形技法

卡农的严谨带来可系统化的变形空间——答句可以不只是「原样跟入」，而是对导句做各种变换：

| 卡农类型 | 变形规则 | 例子 |
| --- | --- | --- |
| 逆行卡农 | 答句从尾到头倒奏 | 巴赫《音乐的奉献》 |
| 倒影卡农 | 答句音程方向反转 | 巴赫《赋格的艺术》 |
| 增值/减值卡农 | 答句时值加倍/减半 | 巴洛克经文歌 |
| 双重/三重卡农 | 两组以上卡农同时进行 | 文艺复兴复调 |
| 无限卡农 | 答句结束时又回到导句开头，循环往复 | 《轮唱曲》 |

**公式解析：倒影卡农的变换。** 设导句音高序列为 $\{p_1, p_2, \dots, p_n\}$，倒影变换为

$$q_i = p_1 + (p_1 - p_i) \quad (\text{以} \ p_1 \ \text{为镜})\ \text{或} \ q_i = \text{转位}(p_i)$$

**第一步，确定镜像轴（通常为调内某音）；第二步，每个音高沿轴翻转**——上行变下行、下行变上行；**第三步，倒影序列与导句形成「对称」的对位。** 倒影卡农的美在于「镜像的严谨」：答句不是随意的变化，而是对导句的精确对称操作。<span class="marginnote">巴赫《音乐的奉献》中有一首传奇的「螃蟹卡农」（crab canon）：答句是导句的逆行——从头唱到尾的旋律，被另一声部从尾唱到头。两条旋律像两只蟹互相钳着对方的尾巴，却是严格的对位。<strong>它把「对称」这个数学概念直接谱成了声音</strong>——巴洛克复调的对位严谨度，已经接近数学证明。</span>

## 3 卡农的历史与巅峰

卡农源远流长：中世纪法国北部的**经文歌**与**猎歌（caccia）**已出现卡农，文艺复兴（若斯坎的「弥撒」、奥克冈）把它发展为精致的复调技巧，巴洛克巴赫在《哥德堡变奏曲》《音乐的奉献》《赋格的艺术》中把卡农推至巅峰。<span class="marginnote">《哥德堡变奏曲》的九段卡农是卡农史的杰作：每一段卡农都换一个音程（同度、二度、三度……直到九度），答句与导句的距离逐段递增，像一套「卡农音程大全」。<strong>把九段卡农连起来听，就是在听「时间差从 0 到最大」的连续光谱。</strong></span>

**最广为人知的卡农是帕赫贝尔的《D 大调卡农》（Pachelbel's Canon）**——三把小提琴以相差两小节的方式演奏同一旋律，低音部以固定低音循环（D–A–B–F♯–G–D–G–A）衬托。它把卡农的「清澈」与固定低音变奏的「循环」结合，成为婚礼与广告的宠儿。<span class="marginnote">帕赫贝尔《卡农》的低音线是著名的「帕赫贝尔进行」（D–A–B–F♯–G–D–G–A）——它后来被无数流行歌曲借用（从《Let It Be》到中文流行），成为和声写作的通用模板。<strong>卡农的结构与流行和声在此交汇：严谨的模仿对位 + 循环的低音，恰好兼得古典的秩序与流行的顺耳。</strong></span>

## 4 卡农与赋格的比较

卡农与赋格同属复调的「模仿」家族，但规则不同：

| 维度 | 卡农 | 赋格 |
| --- | --- | --- |
| 模仿方式 | 全程严格模仿 | 主题出现后有自由段落 |
| 声部角色 | 导句/答句对等 | 主题/对题/插部分工 |
| 主题数量 | 通常一主题 | 一或多主题 |
| 严格程度 | 极高（机械精确） | 较自由（展开多变） |
| 典型时长 | 短小 | 宏大 |<span class="marginnote">一句话区分：`<strong>`卡农是「从头到尾的严格模仿」，赋格是「以主题为中心的自由展开」。赋格里常插入卡农段落（如终曲的紧接段），但整体结构远比卡农松散。可以说：卡农是复调的「数学定理」，赋格是复调的「论说文」。</span>

**辨析｜易错点：** 「卡农」常被当作那首《D 大调卡农》的专名——其实「卡农」是一种**技法/体裁**的名字，帕赫贝尔只是最著名的例子。任何「延迟模仿」的对位都可称为卡农。

## 5 卡农的聆听与创作实验

**卡农的「自洽性」是它最迷人的数学美——听卡农与写卡农，都是对「时间错位中的和谐」的体验。**

**聆听三招：**

1. **跟导句**：先记住导句旋律，它是最先出现的声部。
2. **追答句**：听导句的「回声」何时进入——延迟一拍、一小节，还是更多？
3. **听咬合**：重点听「导句与答句重叠时」——两条旋律同时发声却协和，这是卡农的「魔法时刻」。

**公式解析：卡农的自洽条件 = 「延迟的自我兼容」。** 设导句旋律为 $M$、延迟量为 $\Delta$，则卡农成立的条件是

$$\text{每拍上：} \ M(t) \ \text{与} \ M(t-\Delta) \ \text{的纵向音程协和}$$

**第一步，写一条旋律 $M$；第二步，让它在 $\Delta$ 后自我重复；第三步，逐拍检查「自己与自己」的纵向音程——若有不协和，修改旋律或改变延迟。** 这就是卡农写作的「自洽方程」：**你不是在写一条旋律，而是在解「旋律与自身延时版本的兼容性」**。这也解释了为什么轮唱曲（《两只老虎》）看似简单却经过精心设计——每一句都要「咬」得住自己的回声。<span class="marginnote">卡农的「自洽方程」与反馈系统（回声、延迟、循环神经网络）同构：<strong>一个信号经过延迟回到自身，系统必须「稳定」才不会乱</strong>。卡农作曲本质上是在「设计一个稳定的反馈回路」——这是音乐与工程最迷人的交汇之一。<strong>写一首自己的小卡农</strong>（2 声部、延迟 2 拍），是理解这个「时间错位」概念最直接的方式。</span>

## 6 练习与自测

1. **听题**：听帕赫贝尔《卡农》，数出三把小提琴的进入间隔——相差两小节，听「回声叠层」。
2. **辨题**：听巴赫《音乐的奉献》中的螃蟹卡农（逆行卡农）——答句是导句的倒放，听「对称」。
3. **写题**：写一条 8 小节的旋律，让它延迟 2 拍自我重复成二声部卡农——逐拍检查纵向音程。
4. **改题**：把卡农改成「增值卡农」（答句时值加倍）——听主题「慢下来的自己」。
5. **探题**：听《哥德堡变奏曲》的九段卡农——每段换一个音程间隔（同度到九度），听「间隔的光谱」。

**自测答案要点**：卡农 = 严格延迟模仿；答句可做移调、倒影、逆行、增值等变形；「咬合」即导句与答句重叠时的协和——这是卡农自洽的核心。

## 7 延伸聆听与思考

**卡农的「回声之美」需要专门聆听——推荐：**

- **帕赫贝尔《D 大调卡农》**：三把小提琴依次进入，最著名的卡农。
- **巴赫《哥德堡变奏曲》的九段卡农**：每一段换一个音程间隔——「卡农音程大全」。
- **巴赫《音乐的奉献》的螃蟹卡农**：答句是导句的逆行——「对称」的音乐化身。
- **拉威尔《达夫尼斯与克洛埃》**：配器中的卡农片段——卡农与印象派音色的结合。
- **《两只老虎》**：最简单的轮唱卡农——人人会唱的自洽样本。

**思考题：**

1. 卡农的「延迟量」如何影响听感——延迟 1 拍 vs 延迟 2 小节，效果有何不同？
2. 「逆行卡农」（螃蟹卡农）为什么是「对称」的？它在数学上与「镜像」有何相似？
3. 卡农与赋格都「模仿」，为何一个「全程严格」、一个「自由展开」？二者的美学追求有何不同？
4. 试着设计一个「无限卡农」（轮唱）——它必须满足什么自洽条件？

**卡农的思考题，核心是「时间错位中的自我和谐」**——它把「对称」「反馈」「自洽」这些概念变成了可以听见的声音。

## 8 小结

- **卡农**＝导句 + 延迟跟入的严格模仿，公式 $M'(t) = M(t-\Delta) + \text{移调}$。
- 变形技法构成变换家族：逆行、倒影、增值/减值、双重卡农、无限卡农。
- 巴赫把卡农推向巅峰（《哥德堡变奏曲》《音乐的奉献》），帕赫贝尔《卡农》最脍炙人口。
- **卡农 vs 赋格**：卡农全程严格模仿，赋格围绕主题自由展开——前者像数学定理，后者像论说文。
- 卡农的自洽 = 「延迟的自我兼容」，写卡农即「解自洽方程」——与反馈系统同构。
