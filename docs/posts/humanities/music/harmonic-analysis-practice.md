## 为什么从和声分析实践开始

和声学的知识已铺满四章：三和弦与七和弦、进行与终止、副属与离调、转调。但**知识不转化为分析能力，就像学会所有语法却不会读文章。** 和声分析（harmonic analysis）是把一段实际音乐「翻译」成功能标记的系统方法——标出每个和弦的级数、功能、终止，从而看见音乐的结构骨架。它相当于给音乐做「逆向工程」：从表象（音符）还原底层逻辑（和声语法）。本篇用一个完整的分析流程，把前四章的方法论收束为可操作的工序。

## 1 分析的第一道工序：定调、定拍、定功能

**和声分析的第一步永远不是标和弦，而是建立坐标系：确定调性、拍号与整体结构。** 三道工序：

1. **定调**：看调号 + 乐曲终止处的主和弦，确定大调/小调及主音。小调还要注意三种形态（自然/和声/旋律）。
2. **定拍**：确认拍号与乐句划分，找到小节线的强弱框架。
3. **定段**：先看整体曲式（乐段、乐句），把作品切成句法单元——分析按句进行，不是按音进行。

**辨析｜易错点：** 不先定调就标级数，是新手最常见的错误。同一个和弦（如 A–C–E）在 C 大调是 vi、在 a 小调是 i、在 F 大调是 iii——**脱离调性谈和弦级数毫无意义。** 定调是分析的「坐标系原点」，原点错了，全部标记作废。<span class="marginnote">定调有个实用技巧：先找全曲或乐段的终止式。终止式几乎总是落在主和弦上——正格终止 V–I 的 I 就是主和弦。找到主和弦再倒推调号与调性，比盲目猜调可靠得多。</span>

## 2 分析的记号系统：罗马数字标注

**和声分析用罗马数字标记和弦在调内的级数与性质：大写表示大三和弦、小写表示小三和弦、°表示减、+表示增。** 如 C 大调的 I、ii、iii、IV、V、vi、vii°。转位与七和弦有专门记号：

- 第一转位：I⁶（低音为三音）。
- 第二转位：I⁶₄。
- 七和弦：V⁷、ii⁷、V⁶₅（七和弦第一转位）等。
- 副属/离调：V/V、V⁷/vi。

**公式解析：罗马数字 + 转位 = 根音位置 + 低音位置。** 记号 I⁶₄ 可拆解为「I（根音 = 调内 I 级）+ 6/4（低音到上方根音与三音的音程）」：

$$\text{和弦标记} = \underbrace{\text{罗马数字}}_{\text{根音在调内的级数}} + \underbrace{\text{数字}}_{\text{低音到根音的音程}}$$

**第一步，读罗马数字确定根音**（I → 主音上方的和弦）；**第二步，读数字确定转位**（无数字 = 原位，6 = 第一转位，6/4 = 第二转位）；**第三步，数字的含义是「低音到根音的音程」**——6/4 即低音到根音六度、到三音四度。<span class="marginnote">这套记号的优雅之处在于「信息压缩」：罗马数字管根音身份，数字管低音位置，一个小记号同时编码和声的「谁」与「在哪」。这类似化学式同时编码「元素组成」与「结构位置」——符号设计的目标永远是高效表达关系。</span>

## 3 实战分析：一个典型的 I–vi–IV–V 乐句

取一个最常见的和声进行，用完整工序分析：

**谱面假设**：C 大调，4/4 拍，四小节旋律，和声为 C–Am–F–G。

**第一道工序——定坐标**：调号无升降 → C 大调或 a 小调；终止落在 G（V）上，未闭合，故为半终止，确认 C 大调。

**第二道工序——标和弦**：

| 小节 | 实际和弦 | 级数 | 功能 |
| --- | --- | --- | --- |
| 1 | C–E–G | I | T |
| 2 | A–C–E | vi | T（替代） |
| 3 | F–A–C | IV | S |
| 4 | G–B–D | V | D（半终止） |

**第三道工序——读功能与低音**：I（T）→ vi（T 替身）→ IV（S）→ V（D 半终止）。低音 C–A–F–G 是三度下行 + 上行跳进，构成典型的「级进低音加终止准备」。<span class="marginnote">I–vi–IV–V 被称为「五十度进行」（因为罗马数字转 180° 成 V–IV–vi–I）——它是流行音乐最常用的四大和弦循环，从《青春舞曲》到无数流行金曲都用它。分析它能立刻看到：这个循环其实是在 T 和 S/D 之间反复摆动，永不闭合（半终止），所以可以无限循环。</span>

**第四道工序——整体解读**：这个乐句停在属和弦（半终止），是「问句」，暗示后面会接一个以正格终止闭合的「答句」。**分析的最后一步永远是「这个和声序列想表达什么」**——不只是标号，而是读出叙事的姿态。

## 4 分析中的难点与常见误判

| 难点 | 典型误判 | 对策 |
| --- | --- | --- |
| 装饰音干扰 | 把经过音/倚音当和弦音 | 先过滤非和声音，再认和弦 |
| 转位识别 | 把第一转位当原位 | 低音是锚，先看低音再定转位 |
| 副属识别 | 见临时升降号就当转调 | 先试「是否某和弦的副属」 |
| 调性含混 | 大小调摇摆不定 | 找终止式定调，再回头复核 |
| 织体复杂 | 被琶音/分解和弦淹没 | 压缩织体，找每拍的和声骨架 |<span class="marginnote">「过滤非和声音」是分析的基本功：旋律中的经过音、辅助音、倚音、先现音都不属于和弦。判断口诀是「每个和弦音都要被其他声部支撑」——孤立地悬着的音多半是装饰。这也是计算机和弦识别算法的核心难点：先分离和声音与装饰音。</span>

**公式解析：和弦音的判据 = 纵向支撑。** 设某时刻的音集为 $S$，其中和声音满足

$$\text{音 } x \in \text{和弦} \iff x \ \text{被至少一个其他声部以三度/五度/八度支撑}$$

**第一步，列出该拍的纵向音集；第二步，找到构成三度叠置骨架的音；第三步，不属于骨架的音标记为经过音/辅助音等。** 这一步「去伪存真」决定了和弦标注的正确率，是分析中最需要耐心的工序。

## 5 和声分析的报告写作

**分析的结果要「写出来」才算数——报告写作把直觉变成可辩护的论证。** 一份规范的和声分析报告包含四层：

1. **标记层**：谱面上的罗马数字与功能标注（这是分析的「原始数据」）。
2. **结构层**：乐句/乐段的终止划分——哪里半终止、哪里全终止、哪里有阻碍。
3. **解释层**：为什么这里用副属、为什么转调——把「标记」翻译成「意图」。
4. **评价层**：这段和声的性格与效果——明暗、张弛、时代风格。

**公式解析：分析报告 = 标记 + 结构 + 解释 + 评价。** 设报告质量 $Q$，则

$$Q \propto \underbrace{M}_{\text{标记准确}} + \underbrace{S}_{\text{结构清晰}} + \underbrace{I}_{\text{解释合理}} + \underbrace{E}_{\text{评价有据}}$$

**第一步，保证标记层 $M$ 准确**（这是地基）；**第二步，用终止划分支撑结构层 $S$；第三步，解释层 $I$ 回答「为什么」**——每个异常和弦都要有说法；**第四步，评价层 $E$ 落在「听感效果」上而非空谈。** 这四层就像代码的「注释—结构—文档—评审」——**分析报告是把「听懂」外化为「可说清楚」的过程**，也是音乐专业训练的核心写作能力。

## 6 练习与自测

1. **析题**：选莫扎特奏鸣曲的一段（8–16 小节），按「定调→标和弦→读功能→写报告」四道工序完成一次完整分析。
2. **滤题**：给一段带大量装饰音的旋律，练习「过滤非和声音、只留骨架」——先列和声音，再标装饰音类型。
3. **转位题**：故意把一些和弦写成转位，练习「先看低音再定转位」——低音是锚。
4. **副属题**：在分析中遇到临时升降号，先试「它是不是某和弦的副属」——再决定是离调还是转调。
5. **写作题**：把一次分析写成 150 字的报告，含标记、结构、解释、评价四层——训练「分析的可沟通性」。

**自测答案要点**：完整工序 = 定坐标（谱号/调号/拍号/终止定调）→ 标和弦（罗马数字+转位）→ 读功能与低音 → 整体解读；难点永远在「过滤装饰音」与「识别副属」。

**延伸阅读**：福克斯《艺术津梁》（对位分析范本）、申克《自由作曲》（纵深结构分析）、科普兰《怎样欣赏音乐》（结构聆听入门）——三条分析路线，从「标和弦」到「看结构」再到「听纵深」，是同一能力的三个层次。

**分析与表演的循环**：分析和表演不是「两件事」——**分析给表演提供「依据」，表演给分析提供「验证」**。同一个乐句，分析了它的和声张力后，演奏时就会「知道在哪里呼吸、在哪里推进」。反过来，听一位大师的演奏，也能反过来印证你对和声的理解。**「纸上分析」与「手上演奏」互相滋养，才是和声学习的完整闭环。**

## 7 小结

- 和声分析**先定调、定拍、定段**，再标和弦——坐标系优先于一切。
- **罗马数字标注**编码根音身份（级数）+ 低音位置（转位），是高效的关系符号。
- 完整工序：定坐标 → 标和弦 → 读功能与低音 → 整体解读叙事姿态。
- 难点在**过滤装饰音、识别转位与副属**；每个和弦音都要有纵向支撑。
- 分析报告 = 标记 + 结构 + 解释 + 评价 四层，把「听懂」外化为「可说清楚」。
