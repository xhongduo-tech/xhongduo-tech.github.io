## 为什么从变奏曲式开始

回旋曲式让「主部」反复回归原样，变奏曲式（variation form）则反过来：**主题只出现一次，此后每一段都是它的变形**。如果说回旋曲是「记住一个主题、反复确认」，变奏曲就是「记住一个主题、反复打量它的每一个侧面」。变奏是人类最古老的组织原理之一——从民歌的即兴加花到爵士的标准曲演绎，都是变奏思维。理解变奏曲式，等于掌握「**在变化中保持同一**」的核心美学：这既是作曲的核心技巧，也是「模式识别 + 模式变形」这一认知能力的音乐化表达。

## 1 变奏曲式的基本结构

**变奏曲式（variation form）由主题与其一系列变形构成：主题–变奏1–变奏2–变奏3……** 基本模式：

$$\text{主题} \to V_1 \to V_2 \to V_3 \to \cdots \to V_n$$

- **主题（theme）**：常取自民歌、咏叹调、或自创旋律，结构多为二部曲式或乐段。
- **变奏（variation）**：对主题进行装饰、节奏、和声、调式、织体的变化。
- **变奏群**：每个变奏保留主题的「骨架」（结构长度、和声框架），改变「血肉」（织体、装饰、节奏）。

**公式解析：变奏 = 保留骨架 + 更换血肉。** 设主题的骨架为 $\{H\text{（和声框架）}, L\text{（结构长度）}\}$，则第 $i$ 个变奏为

$$V_i = \text{变形}(H, L; \ \text{织体}_i, \text{装饰}_i, \text{节奏}_i)$$

**第一步，固定主题的和声进行与结构长度**（这是「同一」的保证）；**第二步，每段变奏更换织体与装饰**（这是「变化」的来源）；**第三步，变奏之间形成性格对比**——一段快速华丽、一段安静抒情、一段复调化。**变奏曲的听法不是「认不认得主题」，而是「看这段变奏把主题的哪个侧面照亮了」。**<span class="marginnote">莫扎特《小星星变奏曲》是变奏曲的教科书：主题 8 小节、12 段变奏，每段用不同的音型、节奏、调式（小调变奏）、速度与织体。听它的乐趣在于追踪「同一主题如何穿上 12 套不同的衣服」——这是变奏曲给听众的「寻宝游戏」。</span>

## 2 变奏的手法库

变奏的技术手段可以系统归纳为几大类，作曲家像从工具箱里取用：

| 变奏手法 | 变化对象 | 例子 |
| --- | --- | --- |
| 装饰变奏 | 旋律加花、分解和弦 | 古典时期最常见 |
| 节奏变奏 | 音符时值紧缩/放宽 | 从四分音符到十六分音符群 |
| 织体变奏 | 伴奏型、音区改变 | 分解和弦琶音化 |
| 调式变奏 | 大调/小调转换 | 大调主题用同主音小调变奏 |
| 和声变奏 | 和声重配、转调 | 主题和声替换 |
| 复调变奏 | 卡农、赋格化处理 | 贝多芬《英雄变奏曲》 |
| 性格变奏 | 变为舞曲、进行曲、咏叹调 | 终曲常为壮丽的进行曲 |<span class="marginnote">这套手法库可以理解为「对主题做一组可控的变换」：时间轴（节奏）、空间轴（音区/织体）、色彩轴（调式/和声）、角色轴（性格）。变奏曲的历史演进就是从「装饰变奏」主导到「性格变奏」主导——从「让旋律更好看」到「让主题过不同的人生」。这也呼应了数据增强（data augmentation）的思想：同一个样本，做一组可解释的变换，得到一组保持标签的训练数据。</span>

## 3 变奏曲的类型与体裁

变奏曲在历史上发展出多种形态：

**严格变奏（ornamental/strict variation）**：保留主题的和声与结构，只做装饰变化——巴洛克与古典早期。
**自由变奏（free variation）**：主题只保留局部特征，变奏可以彻底改变性格与和声——浪漫派（舒曼、李斯特）。
**固定低音变奏（ground bass / passacaglia / chaconne）**：主题是一段反复出现的低音旋律，上方声部不断变化——巴洛克（巴赫《恰空舞曲》）。<span class="marginnote">固定低音变奏是变奏曲的「低音流派」：帕萨卡里亚与恰空都以 4–8 小节的低音主题循环为基础，上方和声与旋律每次更换。巴赫 d 小调无伴奏小提琴《恰空》把一段低音主题演绎成一座宏伟的建筑——同一低音细胞上生长出整部史诗，是「变奏曲=变形记」的最极端证明。</span>

**辨析｜易错点：** 变奏曲与回旋曲都「重复」，但方向相反——回旋曲是**主部原样回归**（同一性），变奏曲是**主题从不原样重复、总是变形**（变异性）。一段「A–A'–A''」（同一主题的装饰变奏）是变奏思维；「A–B–A–C–A」是回旋思维。看「A 是否原样回归」即可区分。

## 4 变奏曲的巅峰：贝多芬《迪亚贝利变奏曲》

**变奏曲的巅峰之作是贝多芬《迪亚贝利变奏曲》（Diabelli Variations, Op. 120）**——一个看似平庸的圆舞曲主题被写成 33 段变奏，涵盖赋格、进行曲、谐谑、咏叹调等几乎所有体裁。<span class="marginnote">迪亚贝利当年征集作曲家为他的圆舞曲写变奏，贝多芬把平庸主题「逼」出 33 种性格——有庄严的、滑稽的、暴烈的、冥想的。这 33 段变奏被称作「一个民族的万花筒」：<strong>主题只是种子，变奏是它生长出的整个宇宙</strong>。它证明了变奏曲的最高境界：让微不足道的材料变得无所不能。</span>

**公式解析：贝多芬变奏的「骨架 + 视角」模式。** 每段变奏 $V_i$ 都可看作

$$V_i = \mathcal{P}_i(\text{主题}) \quad \text{其中} \ \mathcal{P}_i \ \text{是第}\ i \ \text{个「视角函数」}$$

**第一步，主题提供基本的节奏细胞与和声轮廓；第二步，每个视角函数 $\mathcal{P}_i$ 提取主题的某一特征（节奏？和声？轮廓？）加以放大；第三步，33 个视角拼成完整的「主题宇宙」。** 变奏曲的终极形态，是把一个有限主题展开成近乎无限的观察角度——这与「一个函数在不同投影下的像」、与「同一个物体在不同光照下的照片」是同一结构的思维。

## 5 变奏曲的「聆听方法」

**变奏曲的聆听乐趣在于「追踪同一与变化」——这是最需要主动听的曲式。** 三招：

1. **先记主题**：听第一遍，记住主题的旋律与和声轮廓——它是后面所有变奏的「参照系」。
2. **再认骨架**：每个变奏里，找到主题的「影子」——旋律轮廓、和声进行、低音线条，至少有一项在。
3. **后品变化**：判断这个变奏「变了什么」——装饰？节奏？调式？织体？性格？

**公式解析：变奏聆听 = 「找不变 + 品变」。** 设主题特征集为 $\{M \text{（旋律）}, H \text{（和声）}, R \text{（节奏）}, T \text{（织体）}\}$，则第 $i$ 个变奏

$$V_i = \text{保留} \ S_i \subseteq \{M,H,R,T\} \ \text{且变化其余}$$

**第一步，锁定保留特征 $S_i$（这是「同一」）；第二步，观察变化特征（这是「变化」）；第三步，用「保留了什么」给变奏归类**——保留和声的是「和声变奏」，保留低音的是「固定低音变奏」，全变化的是「性格变奏」。**变奏曲的听法不是「找主题」，而是「每次判断：它在哪方面忠实、在哪方面自由」**——这套「保同一品变化」的方法，也适用于听一切「改编」「重写」作品。<span class="marginnote">为什么变奏曲是「作曲技术的教科书」？因为作曲家必须在「有限主题」内展示「无限手法」——每个变奏都是一道「约束下的创作题」。<strong>聆听变奏曲 = 观看一场「主题的变形记」</strong>：同一个灵魂，十二种人生。这也是为什么巴赫《哥德堡变奏曲》、贝多芬《迪亚贝利变奏曲》被奉为巅峰——它们在「同一」中开出的「多样」越多，艺术成就越高。</span>

## 6 练习与自测

1. **听题**：听莫扎特《小星星变奏曲》，每段变奏标出「保留了什么、变了什么」——先找主题影子，再品变化。
2. **辨题**：区分严格变奏与自由变奏——看是否「保留主题完整轮廓」。
3. **写题**：给一段 8 小节旋律写两个变奏：一个装饰变奏（加花）、一个节奏变奏（时值减半）——用「保留骨架 + 换血肉」。
4. **探题**：听巴赫《恰空》，追踪 4 小节低音主题如何在整曲循环——固定低音变奏的听觉体验。
5. **评题**：比较两个版本的同一变奏曲（如不同钢琴家弹《哥德堡》），看诠释如何改变「变形」的听感。

**自测答案要点**：变奏 = 保留骨架 + 更换血肉；严格变奏保留和声与结构、只加装饰，自由变奏允许性格剧变；固定低音变奏以循环低音为「同一」。

## 7 延伸聆听与思考

**变奏曲是「聆听的寻宝游戏」——几首必听的经典：**

- **莫扎特《小星星变奏曲》**：12 段变奏的教科书——装饰、节奏、调式（小调变奏）、织体层层变化。
- **巴赫《哥德堡变奏曲》**：30 段变奏——从舞曲到卡农到炫技，一首咏叹调主题的「宇宙」。
- **贝多芬《迪亚贝利变奏曲》**：33 段变奏——一个平庸圆舞曲长成整个风格史。
- **帕赫贝尔《卡农》**：固定低音变奏 + 卡农——循环低音上的「千层蛋糕」。

**思考题：**

1. 变奏曲的「主题」越平庸，变奏反而越精彩——为什么？「迪亚贝利」给出了怎样的答案？
2. 严格变奏与自由变奏的分界在哪？「保留骨架」到什么程度，主题才算是「变了」而不是「没了」？
3. 固定低音变奏（恰空）为什么能「一段低音撑起整曲」？低音在音乐中的「地基」作用如何体现？
4. 如果「变奏」被推向极端——主题完全不可辨认，它还叫变奏吗？试着讨论「变奏的边界」。

**变奏曲的思考题，核心是「同一与变化的哲学」**——它不只是曲式，更是「在约束中创造」的隐喻。

## 8 小结

- **变奏曲式**＝主题 + 系列变形，**保留骨架（和声/结构） + 更换血肉（织体/装饰）**。
- 变奏手法是一个**工具箱**：装饰、节奏、织体、调式、和声、复调、性格七大类。
- **严格变奏**重装饰、**自由变奏**重性格、**固定低音变奏**（恰空/帕萨卡里亚）以低音循环为基。
- 变奏曲的最高境界（贝多芬《迪亚贝利》）：**让平凡主题长成整个宇宙**——同一性中开出的无限多样性。
- 变奏聆听 = 「找不变 + 品变」——每次判断「保留什么、变化什么」，就是变奏曲的听法。
