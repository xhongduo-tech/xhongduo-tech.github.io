## 为什么从和弦开始

上一篇的音程是「两个音的关系」，但当声音从两音扩展到三个、四个甚至更多，音乐就获得了**纵向的厚度**——这就是和弦（chord）。几乎所有西方音乐（以及东亚、拉丁、非洲的现代创作）都在和弦的骨架上前行：旋律是横线，和弦是竖柱，二者织成音乐的经纬。**理解和弦 = 理解音乐如何从单线变成多维**，这与大模型里「把一维序列投影到高维表示空间」的升维直觉相通——和弦正是声音世界里的「高维向量」。

## 1 三和弦：和声的最小完备单元

**三和弦（triad）由三个音按三度关系叠置而成**，自下而上称为**根音（root）、三音（third）、五音（fifth）**。三个音之间形成两个三度音程，根音到五音是一个五度音程。按两个三度的大小组合，三和弦有四种：

| 和弦 | 组成 | 结构式 | 色彩 |
| --- | --- | --- | --- |
| 大三和弦 | 根音+大三度+小三度 | 大3 + 小3 | 明亮、稳定 |
| 小三和弦 | 根音+小三度+大三度 | 小3 + 大3 | 暗淡、柔和 |
| 增三和弦 | 根音+大三度+大三度 | 大3 + 大3 | 紧张、扩张 |
| 减三和弦 | 根音+小三度+小三度 | 小3 + 小3 | 收缩、不安 |

**公式解析：三和弦 = 两个三度音程的「积木拼接」。** 第一步，确立根音 R；第二步，叠一个大三度或小三度得到三音；第三步，再叠一个大/小三度得到五音。大和弦的「大」来自根音到三音的大三度，小和弦的「小」来自根音到三音的小三度。**增三和弦的五音比纯五度多半个音，减三和弦的五音少半个音**，所以一个「扩张」（增）一个「收缩」（减），听感上极不稳定，在传统和声里几乎总要解决。

**辨析｜易错点：** 判断一个三和弦的性质，看的是**根音到三音的音程**（决定大/小）与**三音到五音的音程**（决定增/减），而不是「看有没有黑键」。C–E–G 全白键是大三和弦，但 A–C–E 也全白键却是小三和弦——性质由音程结构决定，与键面黑白无关。

## 2 七和弦：加入第七音的色彩扩展

**七和弦（seventh chord）是在三和弦之上再叠一个三度，构成四个音。** 最常用的五种：<span class="marginnote">七和弦的名称规则是「三和弦的性质 + 根音到七音的音程」。属七和弦（大小七和弦）叫「属七」因为最常建在调式的第五级（属音）上。</span>

**属七和弦（大小七）**：大三和弦 + 小七度，如 G–B–D–F，最常用，倾向解决到主和弦。
**小七和弦**：小三和弦 + 小七度，如 D–F–A–C，柔和，爵士乐基石。
**大七和弦**：大三和弦 + 大七度，如 C–E–G–B，梦幻、漂浮，常出现在 bossa nova。
**半减七和弦**：减三和弦 + 小七度，如 B–D–F–A，紧张但可作过渡。
**减七和弦**：减三和弦 + 减七度，如 B–D–F–♭A，极度紧张，转调利器。

**七和弦让和声从「三度叠置的静物」变成「具有运动倾向的张力结构」**：第七音（尤其是属七的小七度）像弹簧一样迫求解快到下一个和弦，这是下一节「和声进行」的动力来源。

## 3 和弦的原位与转位

**根音在低音部的和弦叫原位（root position）；三音或五音（或七音）在低音部的和弦叫转位（inversion）。** 转位不改变和弦的身份，只改变低音与色彩浓度：

**原位**：低音 = 根音。
**第一转位（六和弦）**：低音 = 三音，记作 6（三音到根音是六度）。
**第二转位（四六和弦）**：低音 = 五音，记作 6/4（五音到三音四度、到根音六度）。

**公式解析：转位标记「6」「6/4」记录的是低音到上方各音的音程。** 以 C 大三和弦为例：原位 C–E–G 记作「5/3」（通常省略）；第一转位 E–G–C，低音 E 到 G 三度、到 C 六度，简记为「6」；第二转位 G–C–E，低音 G 到 C 四度、到 E 六度，简记为「6/4」。**为什么研究转位？** 因为低音线条是音乐的重要声部，转位能让低音平滑连接、避免低音大跳，也能改变和声紧张度——四六和弦尤其不稳定，常作经过、倚音或终止用途。

## 4 和弦与调式：功能和声的雏形

**把和弦放进调式，每个音级上都能构建和弦。** 以自然大调为例，七个音级上的三和弦依次为：I 大、ii 小、iii 小、IV 大、V 大、vi 小、vii° 减。这些和弦被归为三大**功能（function）**：

**主功能（T，tonic）**：I、vi、iii——稳定、安定，是音乐的「家」。
**属功能（D，dominant）**：V、vii°——紧张、倾向解决到主。
**下属功能（S，subdominant）**：IV、ii——介于稳定与紧张之间，常导向属。<span class="marginnote">功能分组的关键是共同音：I 与 vi 共享两个音，所以 vi 是「主功能的替身」；V 与 vii° 共享两个音，都是属功能。这种「按共享音聚类」的思路，很像把数据按特征向量聚类——和声的功能理论本质上是对和弦空间的降维分类。</span>

**辨析｜易错点：** 功能看的是和弦在调内的地位，不是和弦本身的明暗。vi 小三和弦本身暗淡，但在 C 大调里它是主功能，可替代 I 结尾而显得「温柔地结束」；同样一个小三和弦，在别处可能是属功能。**脱离调性谈功能是常见错误。**

## 5 和弦标记：两套符号系统的分工

和弦在乐谱与乐理中有两套标记系统，各有用途——**罗马数字标记**（调内功能）与**和弦符号**（绝对音高）。

**罗马数字标记**（如 I、ii、V⁷、vi）：表示「和弦在调内的位置与性质」，适合**分析功能与转调**——它自带「相对坐标」，一看见 V⁷ 就知道「属功能、倾向主」。

**和弦符号**（如 C、Dm、G⁷、Cmaj⁷、B♭sus4）：用字母根音 + 后缀直接写明「绝对和弦」，适合**演奏与流行记谱**——它是「绝对坐标」，一看见 G⁷ 就知道按什么音。<span class="marginnote">两套系统就是「相对地址 vs 绝对地址」：罗马数字像「当前目录下的相对路径」，和弦符号像「绝对路径」。<strong>分析用罗马数字（因为功能随调而变），演奏用和弦符号（因为音高固定）</strong>——就像同一份数据，在不同场景用不同寻址方式。</span>

**核心要点：两套标记的换算关系。**

| 和弦符号（C 大调） | 罗马数字 | 功能 |
| --- | --- | --- |
| C | I | 主 |
| Dm | ii | 下属 |
| Em | iii | 主/属 |
| F | IV | 下属 |
| G | V | 属 |
| Am | vi | 主 |
| B° | vii° | 属 |

**公式解析：罗马数字 → 和弦符号 = 「级数 → 音名」的一次映射。** 设调的主音为 $T$，则罗马数字 $N$ 对应的根音为

$$\text{根音} = T + (N-1) \ \text{个调内音级}$$

**第一步，确定调（如 C 大调，$T = C$）；第二步，数到第 $N$ 级（如 V → G）；第三步，按大小写/符号确定性质（V 大写 = 大三和弦）。** 这套换算在乐理里反复出现——**它本质上是「级数坐标」与「音名坐标」的坐标系变换**，熟练之后，任何调的和弦都可以秒换算。

## 6 和弦的听感与色彩

**和弦不只是「结构」，更是「色彩」**——每种和弦有独特的听感，训练和声听觉的捷径是「记住和弦的色彩」：

| 和弦 | 色彩关键词 | 听感联想 |
| --- | --- | --- |
| 大三和弦 | 明亮、稳定、阳光 | 进行曲、颂歌 |
| 小三和弦 | 暗淡、柔和、忧郁 | 抒情慢歌 |
| 增三和弦 | 扩张、悬疑、不落定 | 配乐里「未解决」的瞬间 |
| 减三和弦 | 收缩、紧张、痉挛 | 恐怖片配乐常用 |
| 大七和弦 | 梦幻、漂浮、bossa | 爵士与 bossa nova |
| 属七和弦 | 渴望、驱动、待解决 | 蓝调与终止式 |

**辨析｜易错点：** 大三与小三的「明暗」差异只差一个音——根音到三音是大三度还是小三度。**色彩的关键不在「几度」，而在「三音的位置」**：三音是「色彩开关」，所以和声学里才忌讳重复三音（会过度强化色彩，见第二篇《三和弦与七和弦》）。**掌握每种和弦的色彩，是和声听觉训练的起点**——听到一个和弦，先说出「明暗」，再分析「结构」。

## 7 小结

- **三和弦**是根音+三音+五音的三度叠置，四种性质由两个三度音程的组合决定。
- **七和弦**增加第七音，制造运动倾向；属七和弦是功能和声的动力核心。
- **转位**改变低音而不改变身份，转位标记「6」「6/4」是低音到上方音的音程速记。
- 和弦进入调式后按**主—属—下属**三大功能分类，功能决定和声的走向。
- **罗马数字**（分析）与**和弦符号**（演奏）两套标记分工；每种和弦有独特的色彩关键词。
- 记住「**三音是色彩开关**」：大三/小三只差三音位置，转位只变低音不变身份——和弦的「明暗」与「地位」分属两层。
- 从单个和弦到「和弦进行」，是下一节《和声进行与终止式》的入口——和弦的价值不在自身，而在「怎么连接」。
- 三和弦与七和弦也是下一篇《三和弦与七和弦（和声学视角）》的解剖对象——这里看「是什么」，那里看「怎么用」。
