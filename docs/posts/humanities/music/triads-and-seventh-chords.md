## 为什么从三和弦与七和弦开始

《基本乐理》里我们已经认识了和弦的「解剖学」——三度叠置、原位转位、四种性质。进入**和声学（harmony）**，视角要换：和弦不再是静态的物件，而是**在时间中运动的行为体**。和声学回答的是「和弦如何连接、如何解决、如何形成句法」。这一章把三和弦与七和弦重新放回调性系统中，研究它们在旋律与低音之间的**排列、重复、连接规则**——这是从「认识积木」到「学习用积木盖房子」的转折点，也是西方调性音乐五百年的通用语法。

## 1 和弦的排列与重复

**当和弦以四个声部（SATB：女高、女低、男高、男低）写作时，每个音不必都出现——可以省略或重复。** 排列与重复的两条核心规则：

- **三和弦（三音）以四声部呈现时，须重复一个音**——通常重复根音，其次五音，避免重复三音。
- **七和弦（四音）四声部齐备，一般无需重复；若要重复，重复根音。**

为什么避免重复三音？**三音决定和弦的大/小性质（色彩），重复它会过度强化色彩、削弱和声清晰度。** <span class="marginnote">在四声部织体里，三和弦必须「四缺一补」：三个音配四个声部，必然有一音重复。重复根音最稳，重复三音最险——因为三音是「性质担当」，被重复时色彩被放大，容易让耳朵只记得色彩而忘记功能。</span>

**排列方式**还分两种：

- **密集排列（close position）**：四个声部尽量靠拢，相邻声部不超过四度，声音集中、明亮。
- **开放排列（open position）**：声部间距放宽（允许八度以上），声音空旷、柔和。

**辨析｜易错点：** 「重复三音」在教科书里通常被禁止，但在实际创作中（尤其流行音乐）三音常被放在最高声部并重复以强调色彩。**规则是「教科书语法」，实际运用可以偏离——前提是知道自己在偏离什么。**

## 2 和弦连接：和声的语法

**和弦连接（voice leading）研究两个相邻和弦之间各声部如何移动。** 两条基本规则：

- **共同音保持（common tone）**：两和弦若共享一个或多个音，共同音尽量留在同一声部不动。
- **避免平行五度与平行八度**：两个声部若以纯五度或纯八度平行进行，和声会「空洞化」，古典和声学视为大忌。<span class="marginnote">平行五度的「空洞感」来自其泛音的高度重合——两个声部以 3:2 的频率比同向滑行时，几乎融合成「加厚了的单声部」，失去了多声部的独立性。平行八度则更极端，两个声部完全同音。中世纪奥尔加农正是靠平行五度起步，却被后世视为「原始」。</span>

**公式解析：声部进行 = 保持 + 就近。** 设前一和弦声部集合为 $\{s_1,\dots,s_4\}$，后一和弦为 $\{t_1,\dots,t_4\}$。连接规则可写为

$$\forall i: \quad \Delta_i = t_i - s_i \in \{0, \pm 1, \pm 2\} \quad (\text{级进为主})$$

**第一步，找出共同音**，固定不变（$\Delta = 0$）；**第二步，其余声部向目标和弦的音就近移动**，优先级进（大二度、小二度）；**第三步，检查并修正平行五度/八度。** 这条「保持共同音 + 就近解决」的规则，是四部和声写作的核心算法。它的心理学意义是**最小功原理**：音乐要流畅，声部就不该乱跳——就像人体运动倾向于最省力的路径。

## 3 属七和弦：最强倾向与解决

**属七和弦（V⁷）是调性音乐里张力最强的和弦**，它包含两个「不稳定音」：导音（三音）与七音（下属音）。这两个音各自有强烈的解决倾向：

- **导音 → 主音**（半音上行）：由 V⁷ 的三音担当。
- **七音 → 中音**（级进下行）：由 V⁷ 的七音担当，即「七音下行」规则。

**公式解析：属七和弦解决的音向 = 不稳定音的「最小步长投奔」。** V⁷ = G–B–D–F（C 大调）。四个音向主和弦 I = C–E–G 移动：导音 B → C（上行半音），七音 F → E（下行半音），五音 D → C 或 E（就近），根音 G → C（或保持）。**每一个不稳定音都按「最省步数」找到归宿**——半音解决、级进解决，绝不跳进解决。这就是为什么 V⁷→I 听起来「顺理成章」：它是一条完美的「势能释放」路径。<span class="marginnote">V⁷→I 是调性音乐最核心的句型，称为「全终止」。爵士乐手称它为 II–V–I 句型的一环（把 V 前面再接一个 ii⁷），是即兴的语法骨架。理解 V⁷ 的解决 = 理解调性音乐为何「有方向」。</span>

## 4 其他七和弦与功能

除了属七，调内其他七和弦各有权重：

- **ii⁷（小七）**：下属功能，常作为 V⁷ 的准备和弦，构成 ii⁷–V⁷–I 的爵士/流行经典进行。
- **vii°⁷（减七）**：属功能，四个音等距（全小三度），任意转位都可当作多个调的导和弦，是转调与「悬念感」的利器。
- **I 大七、IV 大七**：色彩性和弦，出现在爵士、流行与印象派音乐中。

**公式解析：调内七和弦的音级位置决定其功能。** 大调七个七和弦中，只有 V⁷（大小七）含三全音（导音—下属音），这个三全音是「必须解决」的触发信号；vii°⁷ 也含三全音，故同属属功能。**判断七和弦功能，看它是否含三全音：含则倾向强、需解决，不含则倾向弱、可游移。** <span class="marginnote">三全音在 V⁷ 中由导音与七音构成，在 vii°⁷ 中由根音与五音构成。它就像和声里的「红灯」——一出现就预示「需要转弯解决」。这一洞察让「三全音 = 调性动力源」成为和声分析的核心工具。</span>

## 5 和声织体的「四声部思维」

**四声部和声（SATB）不只是「四个音」，而是四种「声部角色」**——每个声部有自己的音域、运动倾向与功能：

| 声部 | 音域定位 | 功能与倾向 |
| --- | --- | --- |
| 女高（S） | 最高，旋律声部 | 常承担旋律，可适度跳进 |
| 女低（A） | 次高，和声声部 | 平滑级进，连接高低 |
| 男高（T） | 次低，内声部 | 级进为主，避免大跳 |
| 男低（B） | 最低，低音声部 | 根音进行，决定和弦地位 |

**公式解析：声部进行的「总原则」= 独立 + 平滑。** 四声部写作要同时满足两个方向的要求：

$$\text{横向：每声部自身平滑（级进为主、方向自然）} \quad \text{纵向：各声部之间协和（音程受控、无平行五八）}$$

**第一步，先定低音**（决定和弦地位与转位）；**第二步，定女高**（旋律线，允许抒情性大跳）；**第三步，填内声部（女低、男高）**——它们是「和声的填充」，以级进连接两个外声部；**第四步，检查平行五八度与声部交叉。** 这套「先外声部、后内声部」的工序，是四部和声写作的标准流程——**外声部决定「性格」，内声部负责「填充」**，理解了分工，写作就有了秩序。

## 6 属七和弦的「拓展家族」

属七和弦是调性音乐的「动力之源」，围绕它发展出整族「属功能」和弦：

- **属九和弦（V⁹）**：属七再加九音，色彩更丰满（爵士常用）。
- **属十三和弦（V¹³）**：属七再加十三音，爵士与流行的高张力属和弦。
- **导七和弦（vii°⁷）**：减七和弦，可替代属七的「属功能」——比属七更紧张、更自由（任意转位均可作转调枢纽）。
- **增六和弦（Italian/French/German）**：含增六度音程、强烈倾向属和弦的「色彩性属功能」——浪漫派与古典晚期常用的「华丽登属」手段。<span class="marginnote">增六和弦是「属功能的豪华前奏」：它在属和弦前制造最强的「登属感」——尤其德国增六和弦（♭VI 音 + 属音低音）在 19 世纪音乐里几乎成了「浪漫派的签名」。<strong>理解属功能家族，就理解了调性音乐「如何把回家的欲望做到最强烈」</strong>——属七是「敲门」，增六是「砸门」。</span>

**辨析｜易错点：** 属功能家族的和弦虽然都「倾向主和弦」，但**解决规则不同**：属七的七音必须级进下行，导七的根音可以上行或保持，增六的增六音必须向外扩张解决。**「都倾向主」不等于「解决方式相同」**——每个和弦有自己的一套声部进行语法，写作与分析时须分别对待。

**聆听练习：属七解决的「耳朵训练」。** 找一段简单的 V⁷–I 进行（如 G⁷–C），反复听，注意「导音 B 上行到 C、七音 F 下行到 E」两条解决线——**先分别听两条线，再合起来听**，就会「听到」属七为什么「非解决不可」。这个练习是理解整个调性音乐「张力—解决」机制的第一步，也解释了为什么 V⁷–I 被称作「全终止」——它是最小、最完整的「张力释放单元」。

## 7 练习与自测

**四部和声写作与属七解决，是这一章必须落到手的能力：**

1. **写题**：给定低音（如 C–F–G–C），写出对应的 I–IV–V–I 四声部和声——先定女高、再填内声部，检查平行五八度。
2. **排题**：把 C 大三和弦分别写成密集排列与开放排列、原位与两种转位——体会「同一和弦、不同织体」的听感差异。
3. **解题**：写出 G⁷（G–B–D–F）解决到 C 的过程，标出导音 B→C、七音 F→E 两条解决线——理解「为什么非解决不可」。
4. **听题**：听一段属七–主的连接（可找流行歌的结尾），先跟导音、再跟七音、最后整体听——「张力—释放」的耳朵由此建立。
5. **验题**：检查自己写的和声里有没有平行五度/八度、声部交叉、不协和音的强拍直现——把「禁则」变成「自查清单」。

**自测答案要点**：属七解决时导音半音上行、七音级进下行，五音与根音就近处理；平行五八度是「两声部同向滑到纯五/纯八度」，出现即破坏声部独立性。

**延伸聆听**：巴赫众赞歌（和声化对位的极致）、莫扎特四重奏慢乐章（四声部对话的典范）、爵士 ii–V–I（属七解决的现代用法）——同一套和声语法，三种不同的「声部生活」。

## 8 小结

- 四声部和声中，**三和弦须重复一音（通常根音）**，七和弦四音齐备；重复三音会过度强化色彩。
- **和弦连接 = 共同音保持 + 就近级进**，并规避平行五度/平行八度。
- **属七和弦 V⁷** 是张力之王，其导音与七音按最小步长解决到主和弦——V⁷→I 是调性的「全终止」。
- 七和弦功能看是否含**三全音**：含则倾向解决，不含则色彩游移。
- 四声部是「外声部定性格、内声部做填充」的分工；属功能家族（V⁹、导七、增六）各有解决语法。
