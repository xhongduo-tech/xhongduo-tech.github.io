## 为什么从调式与调性开始

音阶不是随意的一串音——它把八度内可用的音组织成一个有主从、有引力、有方向的系统，这就是**调式（mode）**与**调性（tonality）**。有了调性，「回家」（解决到主音）这个音乐里最基本的情感动作才成为可能。理解调性，等于理解音乐的「引力场」：**主音是太阳，其他音按离太阳的远近获得不同的倾向强度**。这套「中心—边缘」的等级结构，恰好也是大模型注意力机制、知识图谱枢纽节点等系统中反复出现的组织原理。

## 1 调式：音的等级秩序

**调式（mode）：以某个音为主音，按一定音程关系组织起来的一群音的体系。** 调式的核心是**主音（tonic）**——最稳定、最具归家感的音；围绕它依次有上主音、中音、下属音、属音、下中音、导音，分别称为第 I–VII 级。

**调（key）＝ 调式 + 主音高度**。C 大调 = 以 C 为主音的大调式；a 小调 = 以 A 为主音的小调式。调号（谱号后的升降记号）正是「把某个音阶的主音与音程结构翻译成升降号」的结果。<span class="marginnote">调号可以反推出调：升号调的最后一个升号上方小二度即主音；降号调中倒数第二个降号即主音。这是读谱的实用技巧，也是「音级结构」与「记谱表示」互相翻译的实例。</span>

## 2 大调式与小调式

**自然大调（major scale）** 的音程结构为「全全半全全全半」（W–W–H–W–W–W–H）。以 C 大调为例：C–D–E–F–G–A–B–C。其色彩明亮，主音上方是大三度。

**小调式**有三种形态：

- **自然小调**：全半全全半全全（W–H–W–W–H–W–W），主音上方是小三度，色彩暗淡。
- **和声小调**：自然小调升高第七级，出现「增二度」音程，阿拉伯/吉普赛色彩，属和弦变成大三和弦从而强力倾向主和弦。
- **旋律小调**：上行升第六、七级（接近大调色彩），下行还原，回自然小调。

**辨析｜易错点：** 大调与小调不是「大小」二字之差的简单变体——它们的**半音位置不同**，导致每个音级的倾向完全不同。C 大调的导音 B 距主音 C 半音（强烈倾向），自然 a 小调的导音 G 距主音 A 是全音（倾向弱），所以和声小调才要把 G 升为 ♯G 让导音半音化。**听感差异的根源是音程结构，不是音高本身。**

### 三种小调对照

| 小调形态 | 第六级 | 第七级 | 特征音程 | 色彩 |
| --- | --- | --- | --- | --- |
| 自然小调 | ♭6 | ♭7 | 无 | 朴素、暗淡 |
| 和声小调 | ♭6 | ♯7 | 增二度 | 异域、强烈 |
| 旋律小调（上） | ♯6 | ♯7 | 大六度 | 明亮、抒情 |

## 3 五声调式与中古调式

**五声调式（pentatonic）** 只用五个音，是东亚、非洲、苏格兰等大量音乐的基础。宫商角徵羽：宫（do）、商（re）、角（mi）、徵（sol）、羽（la），五个音按大二度与小三度交替构成（C–D–E–G–A）。没有半音和导音，五声音阶没有强烈的倾向性，因此安宁、空灵、易于转调。<span class="marginnote">五声音阶「无半音」的特征让它成为最容易即兴的调式：任意两个音组合都不刺耳。钢琴黑键恰好构成一个五声音阶（♭D–♭E–♭G–♭A–♭B），所以即兴时「只弹黑键」永远安全。</span>

**中古调式（church modes）** 是格里高利圣咏使用的七种调式，文艺复兴后复兴于爵士与流行乐：多利亚（Dorian，含升六级的自然小调）、弗里几亚（Phrygian，降二级）、利底亚（Lydian，升四级）、混合利底亚（Mixolydian，降七级）等。<span class="marginnote">中古调式与大小调的差别在于个别音级的升降：Dorian = 小调 + 升六级，Lydian = 大调 + 升四级。它们提供了大小调之外的「灰色地带」，是现代流行与爵士拓展色彩的主要工具。</span>

## 4 公式解析：从主音推导整个调的音阶

给定主音与调式结构，可以像「位置 + 步长」那样逐级推导出全部音：

$$\text{音阶} = \text{主音} \xrightarrow{W,H,\cdots} \text{每一级的音}$$

以 G 大调为例，结构为 W–W–H–W–W–W–H：

- 第一步，从主音 G 出发，按全音走到 A；再全音到 B；再半音到 C；
- 第二步，继续全音 D、全音 E、全音 ♯F、半音回到 G；
- 第三步，得到 G–A–B–C–D–E–♯F，共一个升号。

**为什么必须升 F？** 因为 F 到 G 天然是全音，而大调倒数第二步要求「到主音前最后一个音是全音、主音前是半音」——E–F 天然是半音，若用 F 则 E–F 半音在前，结构就错了。**升号不是约定俗成，而是「结构必须成立」的必然结论。** 同理可推：凡主音在 F、C、G、D、A、E、B 上每升一次，多一个升号；降号系列亦如此。

## 5 关系大小调与平行大小调

**关系大小调（relative keys）**：主音相距小三度、共享同一调号的大小调，如 C 大调与 a 小调，共享全白键。<span class="marginnote">关系小调的主音是大调主音的下方小三度（C 向下大三度即 A）。同一调号下「大调偏亮、小调偏暗」的两副面孔，是作曲家转调的常备武器——相对小调切换就像同一盏灯调了明暗。</span>

**平行大小调（parallel keys）**：主音相同、调号不同，如 C 大调与 c 小调。平行大小调共享主音，但调式色彩剧变，常用来制造「同一个人物换了情绪」的效果。

## 5 调式的识别与调号推算

**拿到一段音乐判断它是什么调，有一套标准工序**——这是调性知识的实际应用。

**判断大调/小调的步骤：**

1. **看调号**：升号/降号的数量确定「调族」——0 个升降是 C/a，1 个升是 G/e，2 个升是 D/b……
2. **找主音**：看结束音与终止式——乐曲通常结束在主音上。
3. **定大小**：结束和弦是大小三和弦定大调/小调——最后的和弦性质是「最后一锤」。
4. **复核中古调式**：若结束和弦不是标准大小调，可能用了中古调式（见下）。

**公式解析：升号调/降号调的「主音口诀」。** 升号调：**最后一个升号向上小二度即主音**——如 2 个升（♯F、♯C），最后一个是 ♯C，向上小二度是 D，即 D 大调；降号调：**倒数第二个降号即主音**——如 3 个降（♭B、♭E、♭A），倒数第二个是 ♭E，即 ♭E 大调。<span class="marginnote">这两条口诀不是魔法，而是「调号排列的必然」：升号按五度链排（F→C→G→D→A→E→B），最后一个升号恰是导音（主音下方小二度）；降号按五度链倒排（B→E→A→D→G→C→F），倒数第二个降号恰是主音。<strong>理解「五度链 + 导音关系」，口诀就不必死记，可以随时推导。</strong></span>

**中古调式的识别**：若旋律结束在 do 但不是大调色彩、结束在 la 但不是小调，就可能用了中古调式——多利亚（小调但六级升高）、弗里几亚（小调但二级降低）、利底亚（大调但四级升高）、混合利底亚（大调但七级降低）。**中古调式 = 大小调基础上的「局部位移」**：记住「大调加升降、小调加升降」的两两对照，识别就快。

## 6 调式思维在创作与即兴中的应用

调式不只是「历史知识」，更是**当代音乐创作与即兴的日常工具**——尤其爵士与流行乐手，几乎每天都在用「调式思维」选音。

**调式即兴的「音色选择」**：同一个 C 和弦，配上 C 大调音阶、C 利底亚音阶（升四级）或 C 多利亚音阶（降三级降七级），会得到完全不同的色彩——**调式即兴的本质是「给同一个和弦换不同的音阶滤镜」**。<span class="marginnote">爵士乐手（如 Miles Davis 的《Kind of Blue》）是调式即兴的奠基人：整曲不频繁换和弦，而是在少量和弦上长时间「驻留」，每个和弦配一个调式音阶，即兴者只在该调式内选音。<strong>这种「少和弦、多调式」的写法，让音乐获得一种「冥想般」的静止感</strong>——与古典的「功能驱动」形成鲜明对比，是现代爵士的重要语法。</span>

**调式的「情绪地图」**（C 大调内）：

| 调式 | 结构 | 情绪色彩 |
| --- | --- | --- |
| 爱奥利亚（自然大调） | 全全半全全全半 | 明亮、中性 |
| 多利亚 | 小调 + 升六级 | 忧郁而温暖（民谣、爵士） |
| 弗里几亚 | 小调 + 降二级 | 西班牙、异域、紧张 |
| 利底亚 | 大调 + 升四级 | 梦幻、漂浮（电影配乐） |
| 混合利底亚 | 大调 + 降七级 | 摇滚、布鲁斯（属和弦上） |

**公式解析：调式 = 大调音阶的「旋转」。** 把 C 大调音阶以不同音为起点，就得到七个中古调式：

$$\text{D 起: D–E–F–G–A–B–C–D = 多利亚} \quad \text{E 起: E–F–G–A–B–C–D–E = 弗里几亚}$$

**第一步，写 C 大调音阶（全白键）；第二步，以第 $i$ 个音为主音重新「转正」；第三步，观察新的全半音结构——每个起点对应一个中古调式。** 这条「旋转」公式说明：**中古调式不是「七个新音阶」，而是「同一个音阶的七个观察角度」**——就像同一组数据从不同维度投影，得到不同视图。理解它，调式就不再神秘。

## 7 小结

- **调式**是音的等级秩序，**调**＝调式+主音高度；主音是调性的引力中心。
- **大调**（全全半全全全半）明亮，**小调**三种形态（自然/和声/旋律）各有色彩。
- **五声调式**无半音、无倾向，安宁而灵活；**中古调式**提供大小调之外的色彩。
- 从主音按结构步长可推出整个调与调号——升降号是结构的必然，不是随意标记。
- 调号口诀（升号看最后、降号看倒数第二）源于五度链；中古调式是大调音阶的「旋转」，是即兴选音的色彩滤镜。
- 调式的识别工序是「看调号 → 找主音 → 定大小 → 复核中古调式」——最后一锤总是落在「终止的和弦性质」上。
