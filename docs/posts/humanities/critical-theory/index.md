# 批判理论（法兰克福学派）

以霍克海默、阿多诺《启蒙辩证法》、哈贝马斯《交往行为理论》与马丁·杰伊《法兰克福学派史》为纲，系统重建从社会研究所的创立、批判理论纲领的确立，到启蒙辩证法与工具理性批判，直至交往行为理论与生活世界殖民化诊断的完整批判理论谱系。学完这些章节，就掌握了20世纪最具影响力的社会批判思想传统。

## 对标教材

- 霍克海默、阿多诺,《启蒙辩证法》,上海人民出版社
- 哈贝马斯,《交往行为理论》,上海人民出版社
- 马丁·杰伊,《法兰克福学派史》,重庆出版社
