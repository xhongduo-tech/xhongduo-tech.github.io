# 翻译的类别

## 为什么先给翻译分类

「翻译」这个词在中文里指称着许多不同的活动：把小说翻成中文是翻译，在会议上传译是翻译，把文言文改写成白话文也算翻译，甚至把一段音乐用舞蹈表现出来在某些理论里也叫翻译。**如果不对「翻译」进行内部切分，任何关于翻译的讨论都会因为所指不明而失焦**。<span class="marginnote">分类是任何学科走向科学的先决条件：生物学先有界门纲目科属种，才有进化论；语言学前有语系划分，才有历史比较法。翻译学同样从分类起步。这与第一级《语言学》里「语系分类」的思路同源。</span>

上一节我们确立了翻译的三维理解（过程、产品、系统），这一节顺着把它切开：按**符号关系**分、按**媒介**分、按**内容**分、按**处理方式**分。四把刀切出四种互不冲突的分类法，它们共同构成翻译研究的坐标系。

## 1 按符号关系：雅各布森的三分法

雅各布森在 1959 年的经典论文《论翻译的语言学问题》中，把翻译分为三类，这个框架至今仍是教科书的第一课：

**语内翻译（intralingual translation）**：在同一语言内部的解释性改写，比如把古汉语翻译成现代汉语、把方言「翻译」成普通话、把专业术语解释成大白话。
**语际翻译（interlingual translation）**：两种不同语言之间的转换，即通常意义上狭义的「翻译」，如英译汉、日译中。
**符际翻译（intersemiotic translation）**：在不同符号系统之间的转换，如把小说改编成电影、把诗歌谱成曲、把文字转成盲文。

雅各布森的意义在于：他让翻译学不再局限于「两种自然语言之间」，而是把**一切「意义在不同符号系统间的转换」都纳入翻译的领地**。<span class="marginnote">符际翻译在今天格外有生命力：短视频的字幕与画面、游戏的本土化配音、数据可视化把数字变成图形——都是符际转换。这个框架与第二级《信息论》里「编码/解码」的模型互为镜像：翻译本质上就是一次有损的再编码。</span>

有意思的是，语内翻译往往被低估，但它的难度毫不亚于语际翻译。「学而时习之，不亦说乎」译成现代汉语，同样要在「时」是「按时」还是「时常」、「说」通「悦」还是本义「说」之间做判断——这不正是译者在两种语言之间做的判断吗？**翻译的本质是「意义的重述」，语言是否不同只是表层差异。**

## 2 按媒介：笔译与口译

按传递的媒介与即时性，翻译首先分为**笔译（written translation）**与**口译（interpreting）**，两者在认知负荷与职业形态上有本质差别。

**笔译**：以书面文本为对象，译者有充足时间反复推敲、查阅资料、修改润色，成品以文本形式交付。它的核心能力是**深度理解 + 精雕细琢**，对准确性、文体感、术语统一的要求极高。<span class="marginnote">笔译可以「延迟决策」：拿不准的词可以查证，整句可以重写，还有审校环节兜底。这让笔译成为绝大多数翻译技巧课的默认对象——第二篇《英汉翻译教程》的全部技巧都针对笔译。</span>

**口译**：以口头话语为对象，译者在极短时间内完成听辨—理解—转换—表达的全链条，几乎没有修改机会。口译又可分为：

**交替传译（consecutive interpreting）**：发言人讲一段，译员记笔记后译出，常用于商务谈判、新闻发布会。
**同声传译（simultaneous interpreting）**：译员在发言人讲话的同时进行翻译，滞后仅数秒，常用于国际会议，是认知负荷最大的翻译形态。
**联络/陪同口译（liaison interpreting）**：在两人或多人的日常交谈中随对话轮流传译。

口译与笔译的差别是**「时间压力」的有无**。这个差别不是程度问题，而是质的问题：笔译可以依赖外部资源，口译只能依赖大脑的即时处理能力，因此口译研究更强调认知负荷、短期记忆与注意力分配。

还要提一种介于两者之间的形态——**字幕翻译（subtitling）**：它按笔译的标准组织文本（有书面稿、可反复润色），却受口译式的时间限制（字幕须与画面同步、受屏内字数约束）。字幕翻译是「带着镣铐的笔译」，既考验文字功力，又考验对时间轴与观众阅读速度的把握，如今已是影视行业的核心工种。

## 3 按内容：文学翻译与实用翻译

按文本内容与功能，翻译分为**文学翻译（literary translation）**与**实用翻译（pragmatic / non-literary translation）**。

**文学翻译**的对象是小说、诗歌、戏剧、散文等文学作品。它的难点在于：文学作品不仅传达信息，更传达**审美效果**——意象、节奏、双关、陌生化手法都参与意义的建构。傅雷译巴尔扎克、朱生豪译莎士比亚、杨宪益与戴乃迭译《红楼梦》，都是文学翻译的典范。文学翻译的评价标准是「再创造」：译文本身是否也是文学作品。

**实用翻译**的对象是科技文献、法律文书、商业合同、新闻、产品说明、医学报告等。它的核心要求是**信息准确、术语规范、格式符合行业惯例**，审美成分让位于信息功能。近年来「专门翻译」（specialized translation）的概念越来越受重视，强调译者不仅要懂语言，还要懂领域的知识体系。

文学与实用的界限近年来进一步模糊：广告文案兼具文学性与呼吁功能，传记文学兼具叙事性与纪实性。实践中的做法是「按主导功能归类」——但更精细的分析会发现，一部作品往往在多个层面同时运作，这正是第三篇文本类型理论要处理的难题。<span class="marginnote">专门翻译与「领域知识」的关系，可以类比第五级《临床医学》里医生与检验报告的关系：术语只是表层，背后的知识结构才是理解的钥匙。这也是为什么医学、法律、金融翻译往往要求译者具备相关专业背景。</span>

两者的差异决定了评价标准的根本不同：**文学翻译以审美等效为鹄的，实用翻译以信息等值为准绳**。把实用文本译得文采飞扬是过度的文学化，把文学文本译得干巴生硬是功能的流失——错位使用标准，是翻译批评里最常见的失误。

## 4 按处理方式：全译与变译

按对原文的保留程度，翻译还有一组容易被忽视的区分：

**全译（full translation）**：把原文完整地翻译出来，忠实度是核心指标，是翻译的「正规军」。
**变译（translation variation）**：根据读者需要与使用目的，对原文进行取舍改写，包括**节译**（节选翻译）、**编译**（编辑加翻译）、**译述**（译出大意）、**综述**（综合多篇原文）等形态。

变译长期以来不被当作「正经翻译」，但在真实世界中，它恰恰是**信息传播的主流形态**：新闻编译、政策文件汇编、产品本地化中的内容改写，几乎都是变译。<span class="marginnote">变译的正当性要到第三篇学完目的论（skopos theory）才能被充分辩护：按弗米尔的说法，翻译行为的目的是决定翻译策略的最高准则，「删减」在特定目的下不是背叛，而是功能实现。这里先埋一个伏笔。</span>

理解变译的关键是：**全译与变译不是「忠实」与「不忠实」的对立，而是「翻译目的」不同的两种选择**。为学术研究翻译文献，必须全译；为大众读者编一本「世界名著精华读本」，变译就是恰当的选择。

变译在中国有深厚的实践传统：古代佛经翻译里的「格义」「译要」，近代严复译《天演论》的「达旨」（译述大意加评述），本质上都是变译。现代翻译产业里的「本地化」（localization）——把软件、网站、游戏按目标市场改写——是变译最发达的当代形态：界面文字、图片、色彩、货币格式都要按文化习惯调整，早已超出逐句翻译的范畴。

## 5 核心对比表：四种分类法的切分维度

纯概念主题，用对比表梳理四条分类轴：

| 分类轴 | 核心区分 | 代表概念 | 典型应用场景 |
| --- | --- | --- | --- |
| 符号关系 | 是否跨越语言 | 语内 / 语际 / 符际 | 古文今译、英译汉、小说改编电影 |
| 媒介与时间 | 书面 / 口头 | 笔译 / 口译 / 交替 / 同传 | 图书出版、国际会议、商务谈判 |
| 内容与功能 | 审美 / 信息 | 文学翻译 / 实用翻译 | 小说、科技文献、法律合同 |
| 处理方式 | 完整 / 取舍 | 全译 / 变译（节编译述） | 学术翻译、新闻编译、产品本地化 |

这四个维度正交组合，构成翻译研究的坐标系。比如「科幻小说的同传」在现实中极少出现，但在分类框架里，它清楚地落在「语际 + 口译 + 文学 + 全译」的交点上——坐标系的价值正是让每个研究对象都有明确的坐标。

## 6 辨析｜易错点：类别边界是「连续谱」而非「铁栅栏」

**辨析｜易错点：** 初学者常把分类当成非此即彼的贴标签，其实多数翻译实践落在边界的模糊地带：

- **文学与实用并非截然两分**：科普作品、纪实文学、企业家自传，既有信息功能又有文学性，套用任何单一标准都会失真。实际操作中常按「主导功能」归类。
- **全译与变译之间存在渐变**：技术文档翻译常被要求「全文翻译」，但译者实际会按目标用户裁剪重复内容——这是「带有变译性质的全译」。
- **口笔译并非永远分立**：会议口译常要求译员在会前笔译发言稿，形成「笔译辅助口译」的工作流；字幕翻译则介于两者之间，既有笔译的文本性，又有口译的时间限制。
- **分类随时代与技术而变**：今天大量出现的「机器翻译 + 译后编辑」（见第三篇《机器翻译与译后编辑》）不纯属笔译也不纯属变译，而是技术催生的新形态——分类框架要容纳新实践，而非让新实践迁就旧分类。

分类的意义不是给翻译钉上标签，而是**给「选择策略」提供坐标系**。知道自己的任务落在哪个象限，才知道该调用哪套标准、哪类技巧。

## 7 术语速查表

| 术语 | 含义 | 关键例证 |
| --- | --- | --- |
| 语内翻译 | 同语言内的改写 | 古文今译、术语白话化 |
| 语际翻译 | 两种语言之间的转换 | 英译汉、日中互译 |
| 符际翻译 | 不同符号系统之间 | 小说改编电影、文字转盲文 |
| 笔译 / 口译 | 按媒介与时间分 | 图书出版 vs 国际会议 |
| 交替传译 | 讲一段译一段 | 商务谈判、新闻发布会 |
| 同声传译 | 边听边说 | 联合国、大型国际会议 |
| 文学 / 实用翻译 | 按内容功能分 | 小说 vs 科技文献 |
| 全译 / 变译 | 按保留程度分 | 学术翻译 vs 新闻编译 |

四把分类刀互不冲突、正交组合：给任何翻译任务贴上「语际 + 口译 + 文学 + 全译」的坐标，你就知道该调用哪套标准。

## 8 小结

- 雅各布森三分法把翻译分为**语内、语际、符际**，让翻译学超越「两种语言之间」的窄视野。
- 按媒介分**笔译与口译**，口译又含交替、同传、联络等形态；核心差别是**时间压力的有无**。
- 按内容分**文学翻译与实用翻译**，分别以审美等效与信息等值为准绳。
- 按处理方式分**全译与变译**，变译是信息传播的常态而非翻译的背叛。
- 四种分类法**正交组合**，为每个翻译任务确定坐标系；类别边界是连续谱，需按主导功能判断。
