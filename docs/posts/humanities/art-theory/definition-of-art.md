## 为什么从定义开始

「什么是艺术」看似一个入门问题，实则是整门艺术哲学的地基。<span class="marginnote">艺术哲学（philosophy of art）与美学（aesthetics）在当代略有分工：美学研究审美经验与美的判断，艺术哲学研究艺术的本质、意义与价值的根本问题，二者多有交叉。Carroll 的书名用 philosophy of art，正是这份当代自觉。</span>先回答「什么东西算艺术」，才谈得上它好不好、有什么意义、该怎样批评。可这个问题偏偏是所有哲学问题里最难缠的一个：两千年讨论下来，居然没有一条被公认的答案。本文梳理这场漫长论争的来龙去脉——模仿说如何统治两千年，现代「艺术」概念如何被发明，二十世纪如何宣布「定义不可得」，以及当代如何给出簇概念这样的新方案。这条线索也贯穿本专题：后面谈本体论、体制论、形式主义时，都在回应这里留下的三个问题——艺术有本质吗？若有，本质在作品里还是在语境里？若无，我们又凭什么还谈论「艺术」？

## 1 模仿说：统治两千年的第一个答案

哲学史上第一个艺术定义来自柏拉图。在他的《理想国》第十卷里，画床的画家被逐出理想国，理由正是模仿（mimesis）：画家模仿的只是个别具体的床，而床的「理念」才是真实存在，所以艺术离真理隔着三层。柏拉图的态度是贬斥，亚里士多德则给模仿翻了案——在《诗学》中，悲剧「通过怜悯与恐惧使这些情感得到净化（catharsis）」，模仿被视为一种认知活动，人天生乐于从模仿中求知。无论褒贬，**模仿说（imitation theory）**都立住了这样一条纲领：**艺术的本质在于对现实的模仿，艺术的价值取决于模仿的逼真程度。**

模仿说的统治从古希腊持续到十八世纪，其间一再被「创新」改写却从未被推翻。<span class="marginnote">中世纪的圣像画、文艺复兴的透视法、十七世纪的荷兰静物画，表面上是「求真」的不同阶段，实则共享同一条教义：好作品等于逼真的作品。维米尔（Vermeer）的《戴珍珠耳环的少女》之所以被当成杰作，很长一段时间正是因为它「画得像照片」。</span>直到摄影术发明，机器在「逼真」上一夜之间超越了所有画家，模仿说的地基才真正松动——这恰好呼应了本专题另一篇《艺术与社会功能》里本雅明的判断：机械复制改变了艺术的存在方式。

摄影反例的意义值得再放大一步。**模仿说输给的不是抽象艺术，而是机器的胜利。**1839 年达盖尔银版法公布时，法国画家德拉罗什（Paul Delaroche）据说喊出「绘画从此死了」。绘画没有死，但它的身份被永久改写：当「把现实留在画面里」不再是画家的独门绝技，「画得逼真」就从最高标准降格为一种可用技术。之后出现的印象派、立体主义，本质上都在回答同一个问题——既然机器已经占领了「像」，画家还能提供什么机器给不了的东西？<span class="marginnote">这个「机器倒逼定义」的机制，与两千年后本雅明论摄影复制艺术、以及当代生成式 AI 倒逼「何为原创」，是同一结构：技术进步总是先把旧定义逼到墙角，再逼出新定义。详见《艺术与社会功能》一篇。</span>

## 2 十八世纪：现代「艺术」概念被发明

「艺术」曾经是广义的「技艺」（拉丁语 ars，希腊语 techne），裁缝、木匠与画家共享这个词。我们今天熟知的「艺术」概念——绘画、雕塑、建筑、音乐、诗——是十八世纪被发明出来的。1746 年，法国美学家夏尔 · 巴托（Charles Batteux）在《归结为单一原则的美的艺术》中第一次把「美的艺术」（les beaux-arts）划为一个独立类别，其统一原则仍是模仿「美的自然」。艺术从工匠技艺中分离出来，获得了自己的等级、学院与价值体系。

**正是在这个分离点上，定义问题变得尖锐起来**：既然艺术成了一个有边界的类别，就必须说清楚边界在哪儿。于是十八世纪到十九世纪出现了一连串定义，它们共享一个**充分必要条件的形式**：

$$x \text{ 是艺术品} \iff x \text{ 具有某种性质 } P$$

- 模仿说：$P$ = 逼真地模仿现实；
- 表现说（托尔斯泰、克罗齐—科林伍德）：$P$ = 传达或表现情感；
- 形式主义（贝尔、格林伯格）：$P$ = 具备有意味的形式或媒介的自我指涉。

注意这三个候选的性质 $P$ 全都落在**作品内部**。无论你是模仿、表现还是讲形式，定义的答案都在作品自身的某个属性上——没有人会说「一件作品是不是艺术，取决于它在什么场合展出、由谁承认」。这个「到作品内部找本质」的共识，正是后来《艺术本体论》与《艺术体制理论与历史》要爆破的东西：前者追问「作品以何种方式存在」，后者干脆把答案移到「艺术世界」的语境里。定义问题的每一次推进，其实都在回答同一个更深的疑问——**艺术的本质到底藏在哪里？**

## 3 维茨的进攻：艺术是开放概念

1956 年，莫里斯 · 维茨发出决定性一击。他借助维特根斯坦（Wittgenstein）的「家族相似」（family resemblance）思想论证：**艺术没有必要条件**。反例随手可举——一件杜尚（Duchamp）的小便池《泉》几乎不满足任何一条传统定义，却已被承认是艺术品；一件先锋作品诞生时，恰恰因为不符合既有定义才显得「新」。如果艺术有固定本质，新艺术就不可能诞生；可艺术史分明是不断突破定义的历史。

维茨的结论是：**「艺术」是一个开放概念（open concept）**，成员之间只有家族相似——像家庭成员一样，脸型、鼻梁、性格各有重叠，却没有任何特征是全体共有的。对维茨而言，「艺术是什么」不是一个可回答的事实问题，而是一个「要不要把这个新对象纳入概念」的**决定问题**。这个论证被称为「反本质主义」（anti-essentialism），它把定义问题的整个框架掀翻了。

<span class="marginnote">家族相似论的洞见可以这样理解：一类东西不是靠共享一条「公理」聚拢，而是靠彼此之间的「重叠相似」连成一张网。维特根斯坦用它消解「游戏」的本质，维茨把它迁移到「艺术」上。注意这里的哲学风险：如果一切概念都是开放的，定义科学（如集合论里的「集合」）岂不也遭殃？维茨只对艺术这类「创造性」概念主张开放，对数学概念依然默认本质存在。</span>

## 4 公式解析：从「必要条件」到「足够相似」

把维茨的进攻与当代回应压缩成一条式子，能看清整场论争的棋眼。古典定义的逻辑形式是：

$$\mathrm{Art}(x) \iff C_1(x) \wedge C_2(x) \wedge \cdots \wedge C_n(x)$$

其中每个 $C_i$ 都是**必要条件**（necessary condition），它们的合取是**充分条件**（sufficient condition）。反本质主义者的论证可以写成：

$$\neg\exists C_i\ \forall x \big(\mathrm{Art}(x) \to C_i(x)\big)$$

即「找不到任何一个条件，是全体艺术品都必须满足的」——于是古典定义崩溃。当代的**簇概念（cluster concept）**回应则是放弃「任一条件必须成立」，改用阈值：

$$\mathrm{Art}(x) \iff \#\{C_i : C_i(x)\} \geq k$$

即「$x$ 满足的候选特征个数达到某个阈值」就足以被认作艺术。三条式子的差别是实质性的：

- **第一步**：看清古典定义的严格性——所有条件缺一不可；
- **第二步**：看清维茨的否定式——没有一条条件能经得起先锋艺术的反例；
- **第三步**：看清卡罗尔的折中——把「全有」降格为「足够多」。

## 5 当代综合：卡罗尔的簇概念

1999 年，诺埃尔 · 卡罗尔（Noël Carroll）在《艺术哲学：当代导论》中给出「第三种立场」。他承认维茨的反例有效，但反对维茨的极端结论——**「艺术」一词并非全无规则可循**。卡罗尔列出一组候选特征（criteria）：对象具有审美性质；是再现或表现；是技艺的产物；隶属于某个公认的艺术门类；是「以成为艺术为意图」的产物；属于某个既定的艺术传统；可以被恰当的历史语境所容纳……<span class="marginnote">卡罗尔是分析美学的中坚人物，他的簇概念主张「多者而非全体」：没有单一特征是必要条件，但满足足够多的特征就足够成为艺术。这既回答了维茨，又守住了「艺术品与普通物确实有差别」的直觉。他这一立场与他在《艺术批评与诠释》一篇中主张的「假设意图论」互为表里——都强调公共可核验的证据，而非不可见的内心。</span>

| 定义理论 | 核心命题 | 代表作 | 阿喀琉斯之踵 |
| --- | --- | --- | --- |
| 模仿说 | 艺术即对现实的逼真模仿 | 柏拉图《理想国》、亚里士多德《诗学》 | 摄影诞生后「逼真」不再是专属本领；抽象艺术无法解释 |
| 表现说 | 艺术即情感的表现或传导 | 托尔斯泰《艺术论》、科林伍德《艺术原理》 | 无法解释纯抽象形式艺术；「情感」概念模糊 |
| 形式主义 | 艺术即「有意味的形式」 | 贝尔《艺术》、格林伯格《艺术与文化》 | 无法解释观念艺术；把内容驱逐出艺术 |
| 反本质主义 | 艺术是开放概念，无本质 | 维茨《美学中的理论角色》 | 使「艺术」失去一切可讨论的确定内容 |
| 体制论 | 艺术即「艺术世界」授予的候选资格 | 丹托《艺术世界》、迪基《艺术与审美》 | 循环定义之嫌，见《艺术体制理论与历史》 |
| 簇概念 | 满足足够多候选特征即艺术 | 卡罗尔《艺术哲学》 | 阈值 $k$ 的选择本身仍含约定成分 |

### 一个算例：把簇概念用在《布里洛盒子》上

把卡罗尔的候选特征逐条套到 1964 年沃霍尔的《布里洛盒子》上，能直观看到「阈值」在起作用：

| 候选特征 | 《布里洛盒子》 | 说明 |
| --- | --- | --- |
| 具有审美性质 | 弱满足 | 红白印刷配色有某种形式外观 |
| 再现或表现某物 | 是 | 它「关于」商品、复制与消费社会 |
| 技艺的产物 | 是 | 是精心制作的木制仿制品 |
| 隶属公认艺术门类 | 是 | 可归入雕塑 / 装置 |
| 以成为艺术为意图 | 是 | 沃霍尔明确以艺术姿态展出 |
| 属于既定艺术传统 | 是 | 波普艺术、现成品传统 |
| 被恰当历史语境容纳 | 是 | 1964 年纽约艺术世界 |

对照之下，超市货架上那个真盒子只满足其中一两条（外观），却因缺乏意图、传统与语境而落选。**簇概念因此不是「数人头」，而是把判定权重从「外观」转到了「语境」**——这恰好预告了《艺术体制理论与历史》里的「艺术世界」概念。

## 7 小结

- **模仿说**统治两千年，其核心是「艺术 = 逼真模仿」；现代「艺术」概念是十八世纪（巴托）从「技艺」中分离出来的。
- 十八至十九世纪的各类定义共享同一逻辑形式：**充分必要条件**。
- **维茨**借助家族相似论证艺术是**开放概念**，没有必要条件——这是对本专题全部定义问题的一次总爆破。
- **卡罗尔**以**簇概念**回应：满足足够多的候选特征即算艺术，同时守住「艺术与普通物有别」的直觉。
- 定义之争留下的三个问题——本质在作品里还是在语境里、艺术有无历史、价值从何而来——将在《艺术本体论》《艺术体制理论与历史》《审美经验与艺术价值》三篇中一一接续。

在下一节，我们把「艺术是什么」暂时搁置，先问一个更基础的问题：一件艺术品究竟以什么方式存在？——那是**艺术本体论**。
