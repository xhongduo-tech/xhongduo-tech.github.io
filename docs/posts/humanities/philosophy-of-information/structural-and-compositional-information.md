# 结构信息与组合信息

<div class="epigraph">
<p>信息不是原子的集合，而是结构的结晶；结构不是信息的装饰，而是信息的血肉。</p>

## 为什么从"结构"开始

上一讲的公式里有一个"显化项 $G$"：信息能从隐变显。但这立刻引出两个问题：**信息以什么形态存在？信息凭什么能"组合"出新的信息**？答案藏在两个词里：**结构信息（structural information）**与**组合信息（compositional information）**。<span class="marginnote">这是信息本体论的"解剖学"一课：把信息切成结构与组合两个维度，
看它如何内在地组织自己。它也是从第2篇本体论走向第3篇语义学的桥——因为"组合"恰恰是意义产生的机制雏形。</span>

本讲的任务：给结构信息与组合信息下定义，揭示二者的关系（组合产生新结构、
结构支撑新组合），并论证为什么"信息的组合性"是理解语义与知识的关键。
这是第2篇信息本体论的收官之作。

## 1 结构信息：信息的内在组织

**结构信息（structural information）**：指一个信息集合内部的组织关系——它的形态、布局、关联，而不只是它的元素个数。用集合论语言说：结构信息 = 元素集合 + 元素间的约束关系。<span class="marginnote">回到第3讲的 LoA 公式：$\text{LoA} = (\mathcal{O}, \mathcal{C})$，其中 $\mathcal{C}$（约束）正是结构信息的载体。
同样的 0 和 1，排成"1010"与"1001"结构不同，
携带的信息不同——这就是结构信息在起作用。</span>

结构信息有三个特征：

**关系性**：它存在于元素之间，而非元素内部。
  孤零零一个比特没有结构信息，两个比特的关系才有。
**可度量性**：结构信息的复杂度可用**柯尔莫哥洛夫复杂度**刻画——最短描述它的程序长度越长，结构越复杂。<span class="marginnote">柯尔莫哥洛夫复杂度是"结构信息"的精确量尺：
一串随机数复杂度高（无法压缩），一串重复数复杂度低（可压缩）。
它把"结构"从定性变成定量。详见第二级《信息论》的算法信息论部分。</span>
**层级性**：结构可以在多个 LoA 上存在——字符级结构、
  词级结构、句级结构、篇章级结构。

结构信息是"信息的骨架"：没有它，信息只是一堆散装记号线（回到第7篇的"数据 vs 信息"区分——正是结构把数据升级为信息的第一个条件）。

## 2 组合信息：结构如何生出结构

**组合信息（compositional information）**：
指信息通过**组合**产生新信息的机制与产物。
组合不是把信息简单相加，而是**在组合中生成新的结构关系**。

三种组合方式（以自然语言为例最直观）：

| 组合方式 | 机制 | 例子 |
| --- | --- | --- |
| 连接（concatenation） | 线性拼接 | "猫" + "吃" + "鱼" → "猫吃鱼" |
| 嵌套（embedding） | 结构套结构 | "我知道[猫吃鱼]" → 新的命题结构 |
| 重组（recomposition） | 打散重排 | "猫吃鱼" → "鱼吃猫"（新语义） |

**组合信息的关键命题：组合产生的信息，大于各部分信息之和**——这就是"整体大于部分之和"的信息学版本。但要注意，"大于"的机制是**新的结构关系**，而不是神秘的整体论：$A$ 与 $B$ 组合后，多出来的是"$A$ 与 $B$ 之间的关系"这一层新结构。<span class="marginnote">形式化：设 $I(A)$ 是 $A$ 的信息，$I(B)$ 是 $B$ 的信息，$I(A \oplus B)$ 是组合体信息，则 $I(A \oplus B) = I(A) + I(B) + I(R(A,B))$，
其中 $I(R(A,B))$ 是新增的关系信息。
这条式子的哲学味道很浓：<strong>关系信息是组合信息超额的来源</strong>——这也呼应了第7篇"数据是关系性实体"。
</span>

## 3 公式解析：组合信息的分解

把第2节的式子正式化，得到组合信息的分解公式（有公式主题，按章程做公式解析）：

$$
I(A \oplus B) = I(A) + I(B) + I(R_{AB})
$$

- **第一步，看 $I(A)$ 与 $I(B)$**：
  两部分各自的结构信息。它们可能来自不同的 LoA、
  不同来源——组合的前提是它们能被"接上"。
- **第二步，看 $R_{AB}$**：组合操作 $\oplus$ 生成的**关系信息**。
  这是新信息量的来源。$R_{AB}$ 可正可负：
  若 $A$ 与 $B$ 冗余（同义反复），$R_{AB} \lt  0$（组合反而减少信息）；
  若互补（"上海"+"是中国城市"），$R_{AB} > 0$。
- **第三步，看整个式子**：它把"组合产生新信息"从神秘命题变成可计算的账本——**新信息 = 各部分信息 + 关系信息**。

这条公式有个直接推论：**信息的"语义"正是通过组合关系涌现的**。
"猫吃鱼"的语义不是"猫"的语义加"吃"的语义，
而是由"主语—谓语—宾语"这个关系结构产生的。
这一观察，直接通向第3篇《信息的意义理论》：
意义的组合性（compositionality）是语义学最古老也最核心的发现，
信息哲学把它翻译成"组合信息"的语言。

## 4 核心对比：结构信息 vs 组合信息

两者是信息本体论的两个互补维度，用对比表把关系讲清（纯概念主题，以对比表标注）：

| 维度 | 结构信息 | 组合信息 |
| --- | --- | --- |
| 关注对象 | 单个信息集合的内部组织 | 多个信息集合如何合出新结构 |
| 时间取向 | 静态（"是什么"） | 动态（"如何生成"） |
| 量度工具 | 柯尔莫哥洛夫复杂度 | 关系信息增量 $I(R_{AB})$ |
| 哲学角色 | 数据的升级条件 | 意义的生成机制 |
| 失败模式 | 结构崩溃 → 数据退化 | 组合不当 → 冗余或矛盾 |

两者不是两个独立实体，而是**同一个信息存在的两个视角**：
结构信息是"横截面"，组合信息是"演化"。没有结构，
组合无从谈起（拿什么组合？）；没有组合，结构无法增长（新结构从哪来？
）。合在一起，它们回答了上一讲的"显化项 $G$"从何而来——**$G$ 来自组合：把已有信息按新方式组合，就显化出新信息**。

## 5 小结

- **结构信息** = 信息集合的内部组织关系，
  用柯尔莫哥洛夫复杂度可量化。
- **组合信息** = 组合生成新结构的机制与产物；
  三种方式：连接、嵌套、重组。
- 组合的关键命题：**整体信息 = 各部分信息 + 关系信息**。
- 分解公式：$I(A \oplus B) = I(A) + I(B) + I(R_{AB})$
