## 为什么从分子生物学开始

实验生物学把「干预」下探到了分子水平，而真正的分子生物学革命，发生在1953年。这一年，沃森（James Watson）与克里克（Francis Crick）在英国剑桥提出 DNA 的双螺旋结构——两个螺旋相互缠绕、碱基精确互补。这一结构不仅解释了「遗传物质如何复制」，还首次让「生命的信息」有了化学的形状。<span class="marginnote">分子生物学革命通常被定义为「以分子（尤其是核酸与蛋白质）解释生命现象」的研究纲领。它把上一篇文章里「一个基因一种酶」的直觉，落实为「基因是一段 DNA、DNA 是双螺旋」的实体知识。第二级《分子生物学》、第四级《基因组学》的全部内容，都在这一结构上展开。</span>理解双螺旋，就理解了「生命 = 信息 + 化学」这个现代生物学的基本等式。

## 1 遗传物质之争：蛋白质还是 DNA？

要问 DNA 为何重要，先要回到一个更基本的问题：**遗传物质到底是什么？** 在二十世纪前半叶，多数生物学家押注蛋白质——它种类繁多、结构复杂，似乎更适合承载「基因」的多样性；而 DNA 被看作「四核苷酸的重复聚合体」，单调乏味，不像能编码信息。<span class="marginnote">「DNA 太简单，不可能承载遗传」——这个判断在当时完全合理：如果 DNA 只是四种核苷酸简单重复，它凭什么编码万物的多样性？<strong>这个「合理怀疑」恰恰是分子生物学要击碎的：DNA 的信息能力不来自单个核苷酸的丰富，而来自它们的排列顺序。</strong></span>

一连串实验逐步把赌注押到 DNA 上。**1928年，格里菲斯（Griffith）**发现肺炎双球菌的「转化」现象：被加热杀死的致病菌（S型）与无毒菌（R型）混合后，R型竟然获得了致病性——某种「转化因子」从死菌进入了活菌。**1944年，艾弗里（Avery）**及其同事用酶分别处理转化因子：蛋白酶不能破坏它，DNA酶却能——证明转化因子是 **DNA**。<span class="marginnote">艾弗里的实验非常干净，却依然没有立刻说服所有人——有人怀疑 DNA 样品里残留的微量蛋白质才是真凶。<strong>「证据再干净，也挡不住理论预期的惯性」</strong>——这正是科学史上「被接受」滞后于「被证明」的典型段落。</span>最后的判决来自**1952年赫尔希与蔡斯（Hershey & Chase）**的噬菌体实验：用放射性同位素分别标记噬菌体的蛋白质（硫）与 DNA（磷），感染细菌后离心，发现进入细菌的是 DNA 而不是蛋白质。**遗传物质是 DNA——这下没有退路了。**

## 2 从化学到结构：查加夫规则与 DNA 的化学构成

确定 DNA 是遗传物质之后，下一个问题是：DNA 长什么样？化学家早已知道 DNA 由三部分组成——**磷酸、脱氧核糖、四种含氮碱基（腺嘌呤 A、胸腺嘧啶 T、鸟嘌呤 G、胞嘧啶 C）**。但它们在三维空间如何组织，无人知晓。

关键线索来自生物化学家**埃尔文·查加夫（Erwin Chargaff）**。他精确测定多种生物的 DNA 碱基组成，发现一条简单的规律：**无论哪种生物，腺嘌呤的量总是约等于胸腺嘧啶（A ≈ T），鸟嘌呤的量总是约等于胞嘧啶（G ≈ C）**——即嘌呤总数等于嘧啶总数。<span class="marginnote">查加夫规则在当时是一个「没有解释的规律」：为什么 A 与 T、G 与 C 总成对出现？它像一把钥匙，等着被放进一把锁里——直到双螺旋模型给出答案：因为 A 与 T 配对、G 与 C 配对，配对的碱基必然等量。<strong>一条先于理论的实验规律，常常是理论的「预告片」。</strong></span>另一条重要线索来自**罗莎琳德·富兰克林（Rosalind Franklin）**与莫里斯·威尔金斯（Maurice Wilkins）的 X 射线衍射照片——特别是著名的「51号照片」，它显示 DNA 呈螺旋结构，且有确定的周期性尺寸。<span class="marginnote">X 射线衍射把 DNA 的「形状」翻译成「数据」：衍射图样的交叉纹样表明双螺旋，周期性表明每一圈的高度与碱基间距。<strong>富兰克林的数据是双螺旋模型不可或缺的证据来源</strong>——但她在 1958 年因癌症去世，未获 1962 年诺贝尔奖的资格，成为科学史上最常被讨论的「缺席者」之一。</span>结构化学家已经把「数据」摆在桌上，只差一个「模型」。

## 3 双螺旋：沃森、克里克与富兰克林

1951—1953年间，沃森与克里克在剑桥卡文迪许实验室反复搭建模型，终于在1953年2月看到了正确的图景：**DNA 是两条反向平行的多核苷酸链，绕同一轴螺旋缠绕；碱基朝向内侧，通过氢键两两配对——A 配 T、G 配 C；糖—磷酸骨架朝向外侧，形成两条「扶手」。**<span class="marginnote">双螺旋的关键洞见是「碱基互补配对」：A 与 T 形成两条氢键、G 与 C 形成三条氢键，几何尺寸刚好一致，所以两条链能稳定地螺旋缠绕。<strong>这个配对同时解释了查加夫规则（A=T、G=C）与 DNA 的复制机制（一条链是另一条链的模板）。</strong> 结构与功能、解释与预言，在这一瞬间合为一体。</span>

1953年4月25日，沃森与克里克在《自然》杂志发表了那篇著名的短文，结尾那句后来被反复引用：「我们注意到，我们提出的这个特殊配对方式，立即暗示了遗传物质可能的复制机制。」<span class="marginnote">双螺旋模型的成功，很大程度上得益于「建模方法」：用已知的化学键长、键角与衍射数据，搭建出唯一自洽的三维结构。<strong>它示范了「数据 + 模型 + 美学直觉」的互补：数据不够时，模型可以引导下一步实验；模型不对时，数据会来纠正它。</strong> 这种「模型驱动的科学」，是二十世纪后半叶科学方法的重要特征。</span>几个月后，沃森与克里克又在《自然》发表论文，提出 DNA 半保留复制机制；1958年，梅塞尔森与斯塔尔用同位素标记实验证明半保留复制成立——双螺旋模型经受住了实验的检验。

## 4 中心法则与遗传密码：从结构到信息

双螺旋只是开端。它点燃的问题比它回答的更多：DNA 如何控制蛋白质的合成？信息如何在细胞里流动？克里克在1957年提出了著名的**中心法则（central dogma）**：遗传信息从 DNA 流向 RNA、再由 RNA 流向蛋白质，方向不可逆。<span class="marginnote">中心法则把「基因型 → 表型」的抽象关系，落实为「DNA → RNA → 蛋白质」的分子流水线。它是分子生物学的地图：转录（DNA→RNA）与翻译（RNA→蛋白质）是地图上的两条大道。<strong>今天我们知道有逆转录等例外，但主干依旧成立——见第二级《分子生物学》与《RNA 生物学》。</strong></span>

那么，RNA 上的信息如何被「翻译」成蛋白质的氨基酸序列？答案同样在六十年代揭晓：**遗传密码（genetic code）**。尼伦伯格（Nirenberg）等人用人工合成的 RNA 模板，逐个破解了三核苷酸密码子与氨基酸的对应关系——**三个碱基一组（密码子），编码一个氨基酸**；四种碱基组成的三联体共有 $4^3 = 64$ 种，其中 61 种编码氨基酸、3 种是终止信号。<span class="marginnote">64 种密码子对应 20 种氨基酸，必然「多对一」——这就是遗传密码的「简并性」（degeneracy）。它让密码子突变时，常常仍编码同一氨基酸，从而缓冲了突变的破坏力。<strong>这套从 DNA 到蛋白质的「信息流」，是分子生物学革命最完整的收官。</strong></span>到1966年，遗传密码表被完整破译，分子生物学的「圣经」从此写定。

## 5 公式解析：查加夫规则与碱基互补配对

**本主题的核心是一条化学计量规律：双链 DNA 中，A 与 T 配对、G 与 C 配对，因此碱基数目严格满足查加夫规则。** 拆成三步：

**第一步，碱基配对的化学依据。** 腺嘌呤与胸腺嘧啶之间形成两条氢键，鸟嘌呤与胞嘧啶之间形成三条氢键：

$$
A \equiv T \ (\text{2 条氢键}), \qquad G \equiv C \ (\text{3 条氢键})
$$

**第二步，数量恒等式。** 由于配对必然等量，任意双链 DNA 都满足：

$$
A = T, \qquad G = C
$$

由此可推出两条推论恒等式：

$$
A + G = T + C \quad (\text{嘌呤总数} = \text{嘧啶总数})
$$

$$
\frac{A + T}{G + C} = \text{随物种而异的比值}
$$

**第三步，理解「等量」不等于「四等分」。** 查加夫规则说的是 A 与 T 等量、G 与 C 等量，**并不意味着 A=T=G=C**。不同物种的 $(A+T)/(G+C)$ 比值不同——这正是 DNA 多样性的化学来源之一：虽然配对固定，但 A/T 与 G/C 的相对比例可以千差万别。<span class="marginnote">一个常见的初学错误是「把 A=T、G=C 误读为四种碱基各占 25%」。<strong>配对的等量性只约束「A 与 T 相等、G 与 C 相等」，并不约束「A 与 G 相等」。</strong> 记住：DNA 的多样性正藏在这个「不相等」里。</span>查加夫规则由此从一条实验规律，升华为双螺旋结构的内在数学——配对是结构的原因，等量是结构的签名。

## 6 核心辨析：蛋白质与 DNA，谁才是遗传物质

本主题已有公式解析，仍用「核心对比表」收束「遗传物质之争」这一历史争论：

| 维度 | 蛋白质假说 | DNA 假说 |
| --- | --- | --- |
| 结构多样性 | 20 种氨基酸，组合极多 | 4 种碱基，曾被误认为太简单 |
| 承载信息 | 看似丰富，实则无复制模板 | 碱基序列可编码，链可作模板 |
| 关键实验 | —— | 格里菲斯转化、艾弗里酶解、赫尔希—蔡斯 |
| 复制机制 | 不明确 | 半保留复制（碱基互补） |
| 最终结论 | 被否决 | 被确认为遗传物质 |

**辨析｜易错点：** 不要以为「蛋白质假说」纯属无知——它在当时有充分的合理性，因为蛋白质种类多样、性质多样，而 DNA 曾被误认为「重复的单调聚合物」。**科学史中最有教育意义的失败，往往是「基于合理理由押错宝」**：它提醒我们，当「直觉合理性」与「实验证据」冲突时，实验才是最后的裁判。同时注意：蛋白质虽非遗传物质，却是基因的产物与功能执行者——「遗传物质」之争不是「蛋白质不重要」，而是「蛋白质不是信息的存储与复制载体」。

## 7 术语速查表

| 术语 | 原文 | 含义 |
| --- | --- | --- |
| 转化因子 | transforming principle | 格里菲斯发现的、能改变菌株性状的物质 |
| 查加夫规则 | Chargaff's rules | 双链 DNA 中 A=T、G=C 的碱基等量规律 |
| 双螺旋 | double helix | DNA 两条反向平行链的螺旋结构 |
| 碱基互补配对 | complementary base pairing | A—T、G—C 的氢键配对 |
| 半保留复制 | semi-conservative replication | 每条新链保留一条旧链的复制方式 |
| 中心法则 | central dogma | DNA → RNA → 蛋白质的信息流 |
| 遗传密码 | genetic code | 三碱基密码子与氨基酸的对应表 |

记忆提示：七个术语可串成一条主线——**格里菲斯发现「转化因子」→ 艾弗里、赫尔希—蔡斯证明它是 DNA → 查加夫规则给出 A=T、G=C 的线索 → 富兰克林提供衍射数据 → 沃森与克里克搭出「双螺旋」、以「碱基互补配对」解释复制 → 梅塞尔森证明「半保留复制」→ 中心法则与「遗传密码」完成从结构到信息的闭环。** 记住这条链，分子生物学革命的完整图景就清晰了。

## 8 易混辨析与答疑

**Q1：富兰克林为什么没拿诺贝尔奖？**
诺贝尔奖不追授给已故者，而富兰克林在1958年因癌症去世，1962年奖项颁发时已不在世。更值得讨论的，是她的贡献是否被充分承认——她拍摄的51号照片是双螺旋模型的关键证据，沃森与克里克也承认看过它。<span class="marginnote"><strong>科学史对「谁先、谁后、谁被看见」的追问，往往比获奖名单更复杂。</strong> 富兰克林的故事是科学史上「贡献与荣誉错位」最常被讨论的案例，也是科学社会学（第九级《科学计量学》）反复研究的对象。</span>

**Q2：中心法则「不可逆」是绝对的吗？**
不是绝对，但主干成立。克里克本人后来补充了「逆转录」等例外：某些病毒（如 HIV）用逆转录酶把 RNA 反转成 DNA。**中心法则不是「铁律」，而是「主干流向」**：绝大多数细胞中的信息流仍遵循 DNA → RNA → 蛋白质，但生命在边角处总能找到特例——这种「主干 + 例外」的结构，正是生物学规律的一般形态。

**Q3：双螺旋是「发现」还是「发明」？**
这是一个哲学味很浓的问题。双螺旋结构是真实存在的物理实体，沃森与克里克是**发现**了它；但他们用的方法是**建模**——像工程师一样用约束搭出唯一自洽的结构。**「发现真实」与「构建模型」在科学中常常是一枚硬币的两面**：模型对了，就撞上了真实。第七级《科学哲学》里关于「科学实在论」的讨论，正从这里出发。

## 9 小结

- **遗传物质之争**：格里菲斯→艾弗里→赫尔希—蔡斯，实验步步紧逼，DNA 胜出。
- **结构线索**：查加夫规则（A=T、G=C）+ 富兰克林的衍射照片，共同指向螺旋结构。
- **双螺旋**：两条反向平行链、碱基朝内配对、糖—磷酸骨架在外，1953 年《自然》发表。
- **功能兑现**：半保留复制、中心法则、遗传密码——结构模型引出一整条信息流。
- **数学内核**：$A=T, G=C$——碱基互补配对是结构、复制与信息流共同的数学签名。
- **方法转折**：建模 + 数据互证，示范「结构生物学」如何引领分子革命。

在下一节，我们将从「读懂」DNA 走向「改写」DNA——看限制酶、质粒与 PCR 如何让人类第一次能够切割、拼接与复制基因，这就是《重组 DNA 与基因组计划》。
