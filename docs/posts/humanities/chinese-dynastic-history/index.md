# 中国断代史系列（先秦/秦汉/魏晋南北朝/隋唐/宋元/明清）

以翦伯赞《中国古代史》、白寿彝《中国通史》和张帆《中国古代简史》为纲，系统梳理从先秦到明清的中国历代王朝更迭、制度变迁与文明演进。学完这一系列，就能贯通中华文明五千年的历史脉络，理解中国何以成为今日之中国。

## 对标教材

- 翦伯赞《中国古代史》
- 白寿彝《中国通史》
- 张帆《中国古代简史》
