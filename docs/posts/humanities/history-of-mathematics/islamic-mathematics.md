## 为什么从一座「智慧宫」讲起

公元 8—15 世纪，当欧洲处于中世纪早期的低谷时，伊斯兰世界却经历了人类历史上最伟大的**翻译与创造时代**。巴格达的**智慧宫（Bayt al-Hikma）**在阿拔斯王朝哈里发马蒙（al-Ma'mun，813—833 年在位）治下成为翻译中心：希腊的欧几里得、阿基米德、托勒密，印度的天文与算术，波斯的古籍，被系统地译成阿拉伯语。<span class="marginnote">这场翻译运动的战略意义无与伦比：古希腊数学在西欧失传的几百年间，正是靠着这些阿拉伯语译本与注释存续，随后又经拉丁文转译「送回」欧洲——文艺复兴的数学复兴，很大程度上是这场翻译运动的接力。</span>但伊斯兰数学家绝不是保管员：他们在翻译之上发明了「代数」之名与完整解法、把三角学建成独立学科、改进了印度数字与十进小数，还在三次方程与无穷级数求和上走到微积分门口。**从「从极限到大模型」的主线看，伊斯兰数学是承接东方计算传统、连接古典几何与现代代数最关键的中间站。**

## 1 翻译运动：把四大源流装进一座城

智慧宫是制度化的「翻译工厂」：学者以研究、校订、再创作为职，而非简单转述。代表人物有翻译并校订托勒密《至大论》的**巴努·穆萨兄弟（Banū Mūsā）**、被称为「阿拉伯哲学家之贤」的**肯迪（al-Kindī，约 801—873）**，以及**撒比特·伊本·库拉（Thābit ibn Qurra，约 826—901）**——后者既精翻译，又是自己的数学家，研究过友数（amicable numbers）与广义勾股定理。<span class="marginnote">友数是这样一对数：一数等于另一数全部真因数之和，如 220 与 284（220 的真因数之和为 284，反之亦然）。欧拉 18 世纪重新研究的这个「友好」概念，其实在巴格达已有人系统探索。</span>翻译不是终点：阿拉伯学者对希腊文本常有独立校订与增补，许多「欧几里得证明」的改进版就出自他们之手。数学在这一时期第一次成为跨文明的「公共知识」。

## 2 花拉子米《代数学》：algebra 一词的诞生

**花拉子米（al-Khwārizmī，约 780—850）**在约 825 年写出《代数学》（全名意为「关于移项与对消的计算方法的简明之书」），书名里的 **al-jabr**（移项，把减去的项搬到等号另一边）与 **al-muqābala**（对消，合并同类项）——前者演化出今天的「algebra」，后者正是「算法（algorithm）」的远亲。<span class="marginnote">词源是理解学科史的一把钥匙：拉丁译者把「al-Khwārizmī」转写为「Algoritmi」，意思是「花拉子米式的计算」，几百后它变成了「algorithm」——一个 9 世纪中亚数学家的名字，成了整个计算机科学的关键词。</span>

《代数学》的结构非常「教材化」：把一次、二次方程按系数符号分成**六种标准型**（平方等于根、平方等于数、根等于数、平方加根等于数、平方加数等于根、根加数等于平方），每种给解法与**几何证明**。以「平方加根等于数」$x^2 + 10x = 39$ 为例（见第 7 节公式解析），他既给出配方法，又用「补成正方形」的图形演示为什么对。<span class="marginnote">注意这套编排的现代性：先分类、再逐类给算法、再用图形说明正确性——这正是后世「定理—证明」的胚芽，只是论证落在几何上而非符号上。</span>花拉子米还写过一部推广**印度-阿拉伯数字**的算术书，欧洲此后几百年学习印度数字，都经由这部书及其拉丁译本的路线。

六种标准型用今天的符号写成一张表，分类逻辑立刻清晰：

| 标准型 | 现代形式 | 典型解法思路 |
| --- | --- | --- |
| 平方等于根 | $x^2 = bx$ | 约去 $x$，得 $x = b$ |
| 平方等于数 | $x^2 = c$ | 直接开方 |
| 根等于数 | $bx = c$ | 一次除法 |
| 平方加根等于数 | $x^2 + bx = c$ | 配方 |
| 平方加数等于根 | $x^2 + c = bx$ | 配方，两解皆可 |
| 根加数等于平方 | $bx + c = x^2$ | 配方 |

注意花拉子米**拒绝负系数**：他把「$x^2 - 10x = 39$」这种方程先移项成 $x^2 = 10x + 39$，于是仍落在六种标准型之内——**分类法强迫代数「先做变换，再进入已有算法」**，这正是「al-jabr」（移项）一词的本义。

「补成正方形」的几何证明也值得亲手画一遍：先画边长为 $x$ 的正方形，在两条邻边外各接一个宽 $5$、长 $x$ 的矩形，再补上角落的 $5\times5 = 25$ 小方块，整块图形就变成边长为 $x+5$ 的大正方形。于是 $x^2 + 10x + 25 = 39 + 25 = 64$，$(x+5)^2 = 64$，$x = 3$。<span class="marginnote">这就是后世「配方法」的全部几何直觉：把二次项与一次项拼成「缺一角的正方形」，补上那一角就能开方——形状即恒等式，几何为代数背书。</span>

## 3 数字的旅行：印度数字与十进小数

现代世界用的「1、2、3…」这套记号，源头在印度，但它的**普及路线**必须经巴格达。花拉子米的算术书系统说明了印度数字的位值用法，随后这套知识随商贸、翻译与天文历法向西传播，经北非与西班牙进入欧洲。<span class="marginnote">欧洲人把这套数字称作「阿拉伯数字」并沿用至今；1202 年斐波那契《算盘书》再把它系统介绍给西欧——「阿拉伯数字取代罗马数字」的过程，本质是位值记数对累积记数的降维打击，直接改变了计算的成本。</span>

十进小数方面，10 世纪的**乌格利迪西（al-Uqlīdisī）**已用小数点处理十进制分数，15 世纪的**卡西（al-Kāshī，1380—1429）**在《算术之钥》里把十进小数发展为一套成熟记法，并写出「把圆周算到 9 个六十进制位」的成果——换算成十进制约 17 位有效数字，比欧洲人重新发明小数早了一百多年。<span class="marginnote">十进小数的价值怎么说都不为过：没有它，「3.1415926…」只能写在六十进制的柱栏里。卡西的工作表明，十进制小数的「正式发明权」虽常记在斯蒂文（16 世纪）名下，其真正技术早在撒马尔罕完成。</span>

十进小数改变的是「计算的成本结构」。在六十进制里，除法要反复「凑 60 的分数」，每一步都依赖查表；而在十进制小数里，$\tfrac{1}{8} = 0.125$ 一眼可读，相乘相乘只需对齐小数点做整数运算。<span class="marginnote">今天的我们早已习以为常，但「把分数写成有限小数」这件事，本身就是位值思想最成熟的产物——它把「数」从「比率」的牢笼里解放出来，让大数计算第一次像整数一样廉价。没有这套记法，天文学表、航海表、复利表都无法大规模生产。</span>卡西的 17 位小数不只是记录，它是「计算工业」的一次装备升级。

## 4 三角学的独立：从弦表到正弦定律

希腊托勒密用「弦」计算角与边；伊斯兰数学家把它发展为独立的**三角学（trigonometry）**。**巴塔尼（al-Battānī，约 858—929）**把天文学计算系统化，使用正切、余切并给出余弦定律；**阿布·瓦法（Abū al-Wafā，940—998）**编制了高精度正弦表，引入正割与余割，还证明了球面三角的若干定理。<span class="marginnote">正弦（sine）一词的词源也在此：印度人用「半弦」jya 表示弦长之半，阿拉伯人音译为 jība，再被拉丁译者误读为「海湾」（sinus），于是有了今天的 sine——一个翻译意外改写了全球符号史。</span>到 13 世纪的**纳西尔丁（Naṣīr al-Dīn al-Ṭūsī，1201—1274）**，三角学彻底独立成科：他的《论完全四边形》系统处理平面与球面三角，给出**正弦定律**

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$$

的平面与球面版本。<span class="marginnote">正弦定律现在出现在几乎所有中学课本——它的成熟形式正是伊斯兰数学的贡献。后来欧洲的三角学（雷格蒙塔努斯、哥白尼）在方法上都建立在这份遗产上。</span>卡西则用高超的三次插值把 $\sin 1°$ 算得空前精确，作为进一步制表的基石。

正弦定律最好用一个能反验的例子来体会。取直角三角形，斜边 $c = 2$，锐角 $A = 30°$，则 $B = 60°$、$C = 90°$，代入

$$\frac{a}{\sin 30°} = \frac{b}{\sin 60°} = \frac{c}{\sin 90°} = 2$$

得 $a = 1$、$b = \sqrt{3}$，与勾股定理 $1^2 + (\sqrt3)^2 = 2^2$ 完全吻合。**正弦定律把「角与边成比例」的比例思想从埃及、巴比伦一路传下，到伊斯兰数学家手里才写成可普遍使用的等式**——这是三角学「从天文工具变成独立学科」的转折点。

## 5 三次方程与数值方法：海亚姆与卡西

**奥马尔·海亚姆（Omar Khayyam，1048—1131）**——今天以诗闻名，当时以数学闻名——完成了古希腊与花拉子米都没做成的事：**用圆锥曲线相交来解三次方程**。他把 $x^3 + bx = c$ 一类方程化为「抛物线交点」，用几何构造给出解。虽然他不接受负根、也不引入符号代数，但这已是「三次方程有一般解法」的第一次严肃尝试。<span class="marginnote">海亚姆把方程按系数与次数分类到 25 种情形，逐一说明用哪些圆锥曲线的相交可以构造解——这是「用几何解代数」的巅峰，也预示了四百多年后欧洲人用「几何证明配方法」时的思想血缘。</span>

海亚姆的几何解法可以落到一个具体方程上。对 $x^3 + 6x = 20$（即 $p=6, q=20$），他把「$x$ 是某条抛物线与某个圆的交点横坐标」——用两种曲线的相交来「读」出三次方程的根。这个方程的真解恰是 $x = 2$（$8 + 12 = 20$），而卡尔达诺公式给出 $\sqrt[3]{10+\sqrt{108}} + \sqrt[3]{10-\sqrt{108}} \approx 2.732 - 0.732 \approx 2$——**六百年后欧洲人用代数得到的数，正是海亚姆用两条圆锥曲线「画」出的那个点**。

**卡西**则把计算推到当时的极限：他用圆周逼近法（结合他精细的插值技巧）算 $\pi$ 到 16—17 位有效数字，并写下《圆周论》专门处理 $\sin 1°$ 的高精度计算——这项纪录到 17 世纪才被欧洲打破。<span class="marginnote">卡西的插值方法相当于「有限差分的三次插值」，今天数值分析课本里的牛顿前向插值公式，与他 1424 年的做法在结构上完全一致——数值分析的另一条东方血脉。</span>

## 6 求和的先声：海赛姆的四次幂和

**伊本·海赛姆（Ibn al-Haytham，965—1040）**——以《光学》闻名——在求旋转体体积时，需要计算

$$1^4 + 2^4 + 3^4 + \cdots + n^4$$

他不仅求出了结果（等价于 $\tfrac{n(n+1)(2n+1)(3n^2+3n-1)}{30}$），还给出了完整的证明，方法与后世「用高次幂和递推低次幂和」完全一致。<span class="marginnote">把曲线下的面积「切成细条求和再取极限」——这正是积分的核心动作。海赛姆的工作被看作「微积分前夜」的重要一幕：欧洲的卡瓦列里、费马、沃利斯在 17 世纪解决同一问题时，用的正是这条「幂和 + 极限」的路线。</span>它再一次显示：积分思想的零部件，在 11 世纪的巴格达已经相当齐全，缺的是把它们焊成统一理论的「极限」语言。

海赛姆的手法可以这样复现：考虑相邻五次幂之差 $(k+1)^5 - k^5 = 5k^4 + 10k^3 + 10k^2 + 5k + 1$，对 $k = 1$ 到 $n$ 求和。左边「裂项相消」只剩 $(n+1)^5 - 1$；右边则把已知的低次幂和 $\sum k$、$\sum k^2$、$\sum k^3$ 代入，就能反解出 $\sum k^4$——**用高次幂差去反推低次幂和**。这条「递推」的骨架，与后世计算积分时「先估计、再校正」的做法完全同构，也预示了伯努利数求和公式的登场（见《18 世纪数学》一节）。

## 7 公式解析：花拉子米如何解 $x^2 + 10x = 39$

配方法是花拉子米《代数学》的招牌，用今天的话写出来是这样的：

$$x^2 + 10x = 39 \;\Longrightarrow\; (x+5)^2 = 39 + 25 = 64 \;\Longrightarrow\; x + 5 = 8 \;\Longrightarrow\; x = 3$$

分四步拆：

- **第一步，配方**：把 $x^2 + 10x$ 看成「边长为 $x+5$ 的正方形」少掉一个 $5\times5 = 25$ 的小方块，即 $x^2 + 10x = (x+5)^2 - 25$。
- **第二步，两边对消**：等式两边都加 25，得 $(x+5)^2 = 64$——**方程从「含二次项」变成「含平方」**，这正是「al-jabr」（移项）与「al-muqābala」（对消）的本义。
- **第三步，开方**：$x+5 = 8$，故 $x = 3$。
- **第四步，验算与边界**：$3^2 + 30 = 39$，成立。花拉子米拒绝负根（$x = -13$ 也是解），因为他的「量」必须为正——这与巴比伦人、希腊人一脉相承，直到印度与近代欧洲才彻底接纳负数解。

把上面算法抽象成现代符号，就是初中课本的求根公式 $x = \tfrac{-b + \sqrt{b^2 - 4c}}{2}$（对 $x^2 + bx = c$）。**花拉子米用「图形 + 文字」完成了「符号公式」的全部逻辑，只差符号本身**——这个「符号化」的最后一跃，要等到文艺复兴的韦达与笛卡尔。

## 8 对照表：伊斯兰数学的枢纽位置

把伊斯兰数学家的工作按「承接—创造—传续」三类归档，枢纽地位一目了然：

| 人物 / 著作 | 承接自 | 创造 | 传续给 |
| --- | --- | --- | --- |
| 智慧宫翻译家 | 希腊、印度、波斯 | 校订与增补 | 拉丁欧洲 |
| 花拉子米《代数学》 | 巴比伦、希腊几何 | 六种标准型、algebra | 欧洲代数 |
| 花拉子米算术书 | 印度数字 | 推广位值记数 | 欧洲「阿拉伯数字」 |
| 巴塔尼、阿布·瓦法 | 托勒密、印度三角 | 正弦定律、正割余割 | 雷格蒙塔努斯 |
| 海亚姆 | 希腊圆锥曲线 | 三次方程的几何解 | 欧洲代数系 |
| 卡西 | 乌格利迪西 | 十进小数、$\pi$ 的 17 位 | 欧洲小数记法 |

这张表透出两条规律：**其一，伊斯兰数学的创造力集中在「把别人的零件改造成通用工具」**——十进制小数、三角学、代数分类皆是如此；**其二，它同时是文明的中转站**——希腊与东方的知识在此汇合并标准化，再被「送回」欧洲。没有这个枢纽，文艺复兴的数学复兴至少要推迟一个世纪。

## 9 小结

- 伊斯兰数学以**翻译运动**为起点，保存并发展了希腊、印度、波斯的数学遗产。
- 花拉子米《代数学》给出二次方程六种标准型的完整解法与几何证明，命名了 **algebra**，也间接命名了 **algorithm**。
- 印度-阿拉伯数字经伊斯兰世界传遍欧亚；卡西把**十进小数**推进到成熟形态。
- 巴塔尼、阿布·瓦法、纳西尔丁把**三角学**建成独立学科，确立正弦定律。
- 海亚姆用圆锥曲线相交解三次方程；海赛姆求四次幂和、卡西把 $\pi$ 算到 17 位——都已站在微积分门口。
- 伊斯兰数学同时是**文明的枢纽**：把东方的计算与希腊的证明汇合、标准化，再转交欧洲——「承接、创造、传续」三件事，它一件没落下。

在下一节，我们将看到这套遗产如何随印刷术与贸易在西欧复活并爆发——**文艺复兴与代数兴起**：三次方程的世纪之争、符号代数的诞生与笛卡尔的解析几何。
