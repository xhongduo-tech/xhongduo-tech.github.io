## 为什么从人像摄影开始

风光教你等光，人像则教你**与人相处**。人像摄影（portrait photography）大概是拍摄量最大、也最容易被误解的题材：器材党以为买支大光圈镜头就能出片，真正的关键在于**「让被摄者放松，并让光线替他说话」**。<span class="marginnote">人像的技术门槛在摄影里并不算最高——大光圈、长焦、对眼睛——难的是「人」的变量：情绪、姿态、信任。技术篇教过你的对焦与景深、构图与光线，在人像里第一次要与「沟通」叠加使用。</span>

本节按「光线 → 镜头 → 沟通」的顺序展开：先讲用光造型的经典模式，再讲镜头与机位如何改变一张脸，最后落到最核心也最常被忽略的环节——引导与情绪。

还有一个值得先建立的认知：**人像是「被允许的凝视」**。你通过取景器端详一个人的脸，这本身是一种权力关系。拍得好的人像，不是摄影师单方面的「索取」，而是被摄者「愿意呈现」的结果。**把尊重放在技术之前，你的照片会先诚实，再好看。**

## 1 用光造型：一张脸的五种讲法

上一节《构图与光线》讲过光位的五种方向，人像把它们发展成了可命名的**布光模式（lighting pattern）**。核心是主光源（key light）与相机/被摄者之间的相对位置：

| 布光模式 | 特征 | 气质 |
| --- | --- | --- |
| 平光（蝴蝶光） | 主光在相机正上方、略高，鼻下形成对称蝶形小影 | 柔美、时尚、影楼风格 |
| 环形光 | 光在 45°，鼻影在脸颊一侧成一个小环形 | 经典耐看，最常用 |
| 伦勃朗光 | 环形光的深化：暗面脸颊留一个三角形光斑 | 戏剧、古典、有深度 |
| 侧光 | 主光 90°，半明半暗 | 刚毅、硬朗、男性化 |
| 剪影/逆光 | 主光在背后，面部隐入暗部或镀上轮廓光 | 神秘、诗意 |

<span class="marginnote">伦勃朗光得名于画家伦勃朗（Rembrandt），他的自画像几乎都用这种布光：<strong>光源位于被摄者前方 45°、上方约 45°</strong>，让鼻影与脸颊影相连，暗面留下一块三角形亮斑。它之所以「经典」，是因为三角光斑让脸部既有立体感又保留了一部分情绪在阴影中。</span>布光不只决定美丑，还决定叙事：平光下的脸阳光、直白，伦勃朗光下的脸沉静、有故事。**用光的选择，本质是情绪的选择。**

### 主光、辅光与轮廓光的分工

单灯无法满足所有需求，完整的人像布光通常是「三光系统」：

**主光（key light）**：决定整体亮部与影调，是整个布光的「基调」。
**辅光（fill light）**：照亮阴影侧、降低光比，控制阴影的深浅。
**轮廓光（rim/hair light）**：从背后勾勒发丝与轮廓，把人物从背景里「剥离」出来。

<span class="marginnote">一个重要的比例概念：<strong>光比（lighting ratio）</strong>——主光与辅光的亮度差。光比 2:1 阴影很浅，适合清新甜美；光比 8:1 阴影浓重，适合戏剧硬朗。<strong>调光比就是调「脸的戏剧性」</strong>：用辅光把阴影「填浅」，或用吸光板把阴影「加深」。记住：不需要昂贵器材，一块反光板就能改变整张脸的明暗叙事。</span>三光的「控制层级」是：先定主光的位置，再用辅光决定光比，最后用轮廓光决定「人物是否从背景中站起来」。

## 2 镜头与机位：焦距如何「塑造」一张脸

人像最常用的焦距是 **85mm 到 135mm**（全画幅），理由有两个：一是中长焦的透视压缩让五官比例自然、背景虚化圆润；二是拍摄距离约 2–4 米，摄影师与被摄者之间保持舒适社交距离，沟通更从容。<span class="marginnote">反例是广角贴脸拍：广角近摄会把鼻子放大、耳朵缩小，产生戏剧性的「透视变形」。这可以是有意的表达（街拍、艺术人像），但绝不该是误操作。记住：<strong>透视变形来自拍摄距离，不来自镜头</strong>——同一颗 50mm 镜头，贴脸与退后三米，脸的形状完全不同。</span>

机位（相机高度）同样在「雕刻」人脸：

**平视**（与眼同高）：平等、亲切，最常用。
**俯拍**（相机略高）：显得脸小、眼神温顺，常见于甜美风格。
**仰拍**（相机略低）：显得高大、下颌线更利落，常见于力量感表达。

**对焦永远在眼睛**：人像的视觉锚点是眼睛，眼睛清晰，整张照片就「有神」。使用单次对焦 + 对焦眼部的快捷键，比自动选择对焦点可靠得多。

### 景深与背景：环境是「第二角色」

人像的背景不是「配角」，而是叙事的一部分：

**虚化的背景（浅景深）**：把背景变成色块与氛围，主体彻底成为主角——大头照、情绪照常用。
**清晰的环境（深景深）**：环境人像，让人物「长」在他的生活里——工匠在作坊、老人在庭院，背景讲述「他是谁」。
**中性背景**：纯色墙、灰卡背景，让人物脱离任何叙事，纯粹呈现「这一张脸」。

<span class="marginnote">光圈的选择因此与「讲什么故事」绑定：f/1.4–f/2.8 把背景融成氛围，f/4–f/5.6 保留环境轮廓，f/8 让环境完全清晰。<strong>没有「人像必须大光圈」的定律——只有「你想让背景承担多少叙事」的选择。</strong> 这个判断，比「全开光圈」专业得多。</span>

## 3 引导：让人放松的那套手艺

人像最难的技术不是相机，而是**引导（directing）**——让一个面对镜头就僵硬的普通人，在你面前露出自然的瞬间。要点拆开：

**先聊天再拍**：拍摄前几分钟不谈拍照，让被摄者适应你的存在。紧张是常态，而镜头前的松弛需要被「允许」。
**给动作，不给表情**：不要命令「笑一个」——那只会得到僵硬的假笑。而是给一个动作（「把手插进头发里」「看着窗外想一件事」），表情会在动作里自然浮现。<span class="marginnote">心理学上这叫「把注意力从自我观察转移到任务上」：当人专注做一件事时，就不再审视自己被拍的脸。专业人像摄影师的大部分工作，是创造让「真实」发生的条件，而不是捕捉「表演」。</span>
**拍前就调好参数，把注意力留给现场**：光圈、ISO、白平衡在拍摄间隙调好，举起相机时只做对焦与构图，少看屏幕、多说话。
**连拍抓自然瞬间**：微小的表情变化稍纵即逝，短连拍能捕捉到「眨眼之间」最真实的那帧。
**尊重与边界**：人像的本质是信任交换。拍摄前说清用途，拍摄中随时确认舒适度，被摄者有权喊停——这是《摄影传播与社会》中图像伦理的起点。

### 一张「引导动作清单」

给「不知道让模特做什么」的新手一张可复制清单：

| 类型 | 指令示例 |
| --- | --- |
| 走动 | 「从那边慢慢走过来，走到我面前停下」 |
| 互动 | 「摸摸头发」「整理一下衣领」「看向窗外」 |
| 静态 | 「双手插兜，肩膀放松」「靠在墙上」 |
| 情绪 | 「想一件让你难过/开心的事」「别看我，看向远处」 |

<span class="marginnote">这套清单的价值在于：<strong>动作是可执行的指令，表情是不可执行的指令</strong>。你让模特「做个表情」，他只会「摆表情」；你让他「走一段路」，路上的真实反应才是你要的。任何一句引导，都应该能「被身体执行」，而不是「被脸表演」。</span>

## 4 环境人像与后期

除了纯肖像，**环境人像（environmental portrait）**把人放进他的生活场景——工匠在作坊里、老人在庭院里——环境成为人物身份的延伸。这类人像常收小光圈（f/5.6–f/8）保留环境细节，让「他是谁」与「他在哪」一起被讲述。<span class="marginnote">环境人像连接着纪实传统：玛格南摄影师的经典人像几乎都是环境人像。它比棚拍肖像多一层「信息量」，也把《人像摄影》与《纪实与新闻摄影》连在了一起。</span>

人像后期有几个专项：**皮肤柔化**要克制（保留毛孔与质感，磨皮过度会「塑料化」）、**眼神光**的保留或补加、**液化**（微调身形线条）要遵循自然比例。核心原则是：**后期服务于「让这个人看起来像他最好看的样子」，而不是「把他变成另一个人」。**

### 人像后期的「四项纪律」

**磨皮不过度**：保留皮肤纹理，观感才真实；「陶瓷肌」是廉价的审美。
**眼睛必须有神**：眼神光（瞳孔里的反光点）让人物「活」起来，后期可适度补加。
**肤色不过艳**：自然饱和度优先，避免把肤色拉成橙红色。
**液化守比例**：微调曲线与线条，不做「换头级」改动——除非你在做艺术创作。

<span class="marginnote">判断后期是否「过了」的黄金标准：<strong>把修完的照片给被摄者本人看，他是否还认得「那是他自己」</strong>。人像后期的底线是「更好的他」，而不是「另一个他」——这条底线，也是商业肖像与艺术肖像的分界。</span>

### 自拍与「被允许的肖像」

最后谈一个时代新现象：**自拍（self-portrait）**。手机前置镜头与社交平台让自拍成为人类历史上数量最大的肖像类型。自拍不是「自恋的注脚」，它延续了摄影史上最长的一支传统——艺术家用自己当模特：从伦勃朗的自画像，到辛迪·舍曼的角色扮演，自拍是「把镜头对准自己」的严肃创作。<span class="marginnote">对普通人而言，自拍是「肖像练习」的最佳起点：没有模特在场的时间压力，你可以反复试光、试角度、试表情，直到理解「光落在自己脸上是什么样」。<strong>能把自己拍好看的人，往往也更懂如何把别人拍好看</strong>——因为自拍逼你把「光、角度、情绪」三者一次性想清楚。</span>

## 5 小结

- **布光模式是情绪的语言**：蝴蝶光柔美、环形光经典、伦勃朗光戏剧、侧光硬朗、逆光诗意；三光系统里先定主光、再用辅光调光比、最后用轮廓光分离背景。
- **85–135mm 是标准人像焦段**，透视变形来自距离而非镜头；机位高低与平/俯/仰都在雕刻脸型与气质。
- **对焦永远在眼睛**；背景的虚化程度与「你想让环境承担多少叙事」绑定，没有「人像必须大光圈」的定律。
- **引导的核心是「给动作不给表情」**：可执行的指令带来真实的反应；尊重与边界先于技术。
- **环境人像把人与场景一起讲述**；后期做到「更好的他」而非「另一个他」。

在下一节，我们把镜头从「个人」转向「社会」——讨论**纪实与新闻摄影**：摄影如何见证历史，以及见证者的底线在哪里。
