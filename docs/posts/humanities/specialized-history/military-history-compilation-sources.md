## 为什么从军事史开始

前三篇讲了经济、社会与思想，军事史要讲第四件事：「如何用暴力保卫与扩张文明」。战争是人类历史最剧烈也最频繁的活动——中国几千年文明史，几乎没有哪一代人完全置身战争之外。而军事史研究的不只是「谁打赢了」，更是战争背后的制度、技术、思想与整个社会的动员能力。军事科学院编纂的《中国军事通史》17 卷是这一领域的集大成之作，本课先解决它的「方法论」：军事史写什么、靠什么材料、按什么分期。<span class="marginnote">军事史与前面四课的联系很深：战争依赖经济（军费、粮草），动员依赖社会（兵役、宗族），战略依赖思想（兵学、谋略），装备依赖科技（兵器、火器）。本专题把军事史放在经济、社会、思想、科技之后讲，正因为军事是它们交汇的「最高压力测试」。</span>

## 1 军事史写什么：四大研究域

《中国军事通史》所代表的军事史学科，研究对象可归纳为四大领域：

**战争史**：战争的过程、战役、战例——为什么发生、如何胜负、后果如何。这是最传统也最直观的部分。

**军制史**：军事制度——兵役制度（征兵、募兵、府兵、卫所）、军队编制（军、师、卫、所）、指挥体系（兵部、枢密院、五军都督府）、军费与后勤。

**军事技术史**：兵器的演进——青铜兵器、铁兵器、弩、火器（火药、火铳、红衣大炮）、战船、城防工事、军事工程。

**军事思想史**：兵学理论——从《孙子兵法》到戚继光《纪效新书》，战争观念、战略战术原则的演变。<span class="marginnote">这四大领域互相支撑：一种新兵器（如火器）会改变战术，战术会改变军制，军制会改变兵学思想——军事史的魅力正在于这种「技术—制度—思想」的连锁反应。</span>

**重点：军事史不是「帝王将相的战争八卦」，而是一门研究「战争作为社会现象」的学问。** 每一次战争背后，都有经济基础（为什么养得起军队）、社会结构（谁去当兵）、制度设计（如何指挥）、技术条件（用什么打）。《中国军事通史》把这四条线编织进按朝代展开的叙事，是理解中国军事的完整坐标系。

## 2 史料文献：五大门类

军事史的资料比其他专门史更零散、更需要辨析，大体分五类：

| 史料类型 | 典型文献 | 特点与局限 |
| --- | --- | --- |
| 兵书 | 《孙子》《武经七书》《纪效新书》 | 理论系统，但多理想化、少战役实录 |
| 正史兵志 | 二十五史中十余部设《兵志》 | 制度记载为主，战争过程简略 |
| 典制与政书 | 《通典·兵》《武备志》 | 制度沿革清晰，跨朝比照便利 |
| 诏令奏议实录 | 《明实录》、平叛方略 | 第一手决策记录，立场偏官方 |
| 考古与实物 | 兵马俑、简牍、长城、兵器 | 直接证据，但多为片段 |

**重点：军事史料必须「互证」。** 正史记「大破之」，细节要从兵书、方略、考古中补全。例如长平之战赵军被坑杀四十余万，仅靠《史记》孤证，须以考古与后世方略参校。军事史研究者的功夫，一半在史料辨析——把宣传性的「捷报」还原为可检验的史实。<span class="marginnote">军事史料的「不可信系数」特别高：战报多夸大己功、讳言己败，「斩首多少」常是浮夸数。汉简中的「守御器簿」（边塞武器清册）之所以珍贵，正因为它是未经修饰的「内部账本」。</span>

## 3 编纂体系：十七卷的结构

《中国军事通史》（军事科学出版社，17 卷）由军事科学院组织编纂，是迄今规模最大的中国军事通史。其结构以「断代纵览＋专题展开」为体例：

- **序卷**：编纂宗旨、史料综述与研究方法（即本课所讲）；
- 先秦各卷：从远古战争、夏商周到春秋战国；
- 秦汉、魏晋南北朝、隋唐五代各卷：军制演变与战争全貌；
- 宋辽夏金元、明清各卷：冷热兵器交替与王朝战争；
- 近代卷：鸦片战争后的军制转型与反侵略战争。

每一卷内部，一般先讲该时代的战争概貌与重大战役，再论军制、兵学与军事技术，最后以「军事与社会」的视角总结该时代军事的特点。**这种「战争—制度—技术—思想」四位一体的编法，正是军事史作为专门史的成熟形态。**<span class="marginnote">《中国军事通史》特别注重「军事与政治、经济的关系」——例如东汉「募兵与豪强部曲」、唐代「府兵与均田」「藩镇与财政」、宋代「守内虚外与冗兵」，都放在制度的因果链里讲，而非孤立叙述战役。这正是本专题把它列为对标教材的原因。</span>

## 4 分期与问题意识

《中国军事通史》的分期大体循王朝，但军事史有自己更内在的线索。若以「兵役制度」为主线，中国军事史可分四期：

- **先秦**：世兵（贵族武士）与国人军赋；
- **秦汉**：征兵制为主，兼以谪戍、募兵；
- **魏晋—唐**：世兵、府兵——兵役与土地、身份制度深度绑定；
- **宋—清**：募兵为主，军制走向职业化、专业化（卫所、八旗、绿营、近代新军）。

若以「兵器技术」为主线，则是冷兵器时代（先秦至宋）→ 冷热兵器并用（宋元明）→ 火器主导（明清）→ 近代化转型（19 世纪中叶以后）。**两条线索交织，构成了中国军事史的「体」与「魂」：制度的演进决定军队怎么组织，技术的演进决定军队怎么作战。** 后面四课将沿着这两条线，从先秦走到近代。

## 5 战例研究：以长平之战为例

看军事史研究如何工作，最好的办法是解剖一个战例——长平之战（前 260 年）：

**问题意识**：长平之战是中国古代最大规模的歼灭战之一，赵军主力被围歼。军事史要回答的不仅是「谁胜谁负」，更是「为什么赵军会全军覆没」「四十余万降卒被坑杀是否属实」「这场战争改变了什么」。

**史料考订**：相关史料有《史记》（战争过程与坑杀记载）、《战国策》（外交背景）、秦简（秦军军功记录）与考古发现（山西高平永禄村出土的尸骨坑）。研究者须辨析：赵军究竟多少（「四十余万」是实数还是约数）？坑杀规模是否被夸大？史料互相矛盾时如何取舍？<span class="marginnote">1995 年山西高平永禄一号尸骨坑的考古发现，为「坑杀」提供了物证——骸骨多为青壮年、多带创伤，印证了《史记》记载的部分事实。考古与文献互证，是战史研究的基本功。</span>

**因果链条**：长平之战的三层解释——战术层（白起诱敌深入、分割包围的谋略）、战略层（秦「远交近攻」的总体布局、赵决策失误）、制度层（秦军功爵制激励下的战斗力、赵国「卒少而廉颇不能用」的用人失误）。三层结合，才是一场完整的战史解释。

**重点：战例研究是军事史方法的浓缩。** 问题意识—史料考订—因果解释三步，与一般史学研究并无二致，只是对象变成了战争。掌握这套方法，你就能把任何一场战争从「故事」读成「研究」。

## 6 军事史与其他史学的关系

军事史不是孤立的「打仗史」，它与本专题其他面向深度互锁：

**军事—经济**：战争是最花钱的事业。军费、军饷、屯田、漕运、战争对财政的拖累（明代辽饷、清代军费），都是经济史与军事史的交汇点。读懂「战争的账单」，就理解了财政危机与王朝兴衰。

**军事—社会**：兵役制度直接塑造社会——府兵制绑定均田、卫所制绑定军户、八旗制绑定旗人。军队是「社会的缩影」，士兵的来源、待遇、地位，反映整个社会的结构。

**军事—思想**：兵学思想（孙子、戚继光）是思想史的一部分；而「尚武」与「重文」的价值取向，更是思想史的经典议题。

**军事—科技**：兵器演进就是科技史——铁器、弩、火药、火器、舰船，都是「技术改变战争」的例证，也正是本专题科技史部分（李约瑟）反复强调的中国贡献。<span class="marginnote">本专题把军事史放在科技史之前，正是因为它牵动经济、社会、思想、科技四个面向——战争是这些线索交汇的「高压测试场」。读军事史时带着「联系」的眼光，会收获数倍于读故事。</span>

**重点：军事史是「五史交汇」的中心。** 经济为它供血，社会为它供人，思想为它供谋，科技为它供器——本专题的五个面向，在军事史上合流。理解这一点，你就理解了为什么军事史是理解中国文明的绝佳窗口。

## 7 军事史关键词速查

军事史有一套常用术语，掌握它们能快速进入文本：

| 术语 | 含义 |
| --- | --- |
| 兵制 | 兵役制度与军队编制 |
| 征兵制 | 农民轮流服役 |
| 募兵制 | 雇佣职业兵 |
| 府兵制 | 兵农合一的军制 |
| 卫所制 | 明代军户屯田制 |
| 军功爵 | 以战功授爵 |
| 火器 | 火药驱动的武器 |
| 大捷/败绩 | 正史中的战果记载（需辨析） |

**重点：这些术语从「兵制」到「火器」，正好覆盖军事史的四大领域。** 读军事史时，遇到不熟的术语就回到这张表；更重要的是——术语背后各有一段制度与技术的演变史，把它展开，就是一部军事史。

## 8 小结

- 军事史研究战争作为社会现象，有战争、军制、军事技术、军事思想四大领域。
- 军事史料分兵书、正史兵志、政书、诏令奏议、考古五类，必须互证辨析。
- 《中国军事通史》17 卷以「战争—制度—技术—思想」四位一体的体例编纂。
- 兵役制度（世兵→征兵→府兵→募兵）与兵器技术（冷→冷热并用→火器→近代化）是两条主线。
- 军事史是经济、社会、思想、科技四大面向在战争中的交汇。

在下一节，我们将回到中国军事史的起点——先秦兵学与战争形态，看车战如何让位于步兵，兵家思想如何在春秋战国达到高峰。
