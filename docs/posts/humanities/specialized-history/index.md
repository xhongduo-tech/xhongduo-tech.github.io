# 专门史：经济史/社会史/思想史/军事史/科技史

专门史以人类历史的某一专门面向为对象，将经济、社会、思想、军事与科技从整体史中剥离出来作纵深考察，是理解中国文明长时段结构与内在动力的关键路径。学完这五个面向，就能在王朝兴替的政治叙事之外，看清更底层的社会骨架、观念气候与技术基础。

## 对标教材

- 傅筑夫《中国封建社会经济史》（人民出版社，5 卷本）
- 冯尔康《中国社会史概论》（高等教育出版社）
- 葛兆光《中国思想史》（复旦大学出版社，2 卷）
- 《中国军事通史》（军事科学出版社，17 卷）
- 李约瑟《中国科学技术史》（Cambridge University Press，多卷本）
