## 为什么从功能问题开始

生物学里最普通的一句话是「心脏的功能是泵血」。它看起来平淡无奇，哲学家却在上面打磨了一个世纪。奥卡沙（Okasha）第 3 章把功能问题当作理解生物学「为什么」之问的总钥匙：**功能语句为什么在生物学中如此常见？它们有没有客观内容？还是只是懒惰的比喻？**

这一节与第7篇（Sober 的目的论自然化）视角互补：那里我们学习了「如何把功能自然化」（随附性 + 选择效果），这里我们后退一步，系统审视功能概念本身——它有哪些理论、它们的分歧在哪、哪种是对的。学完你会拥有一张完整的功能地图，并能判断「这个器官的功能是什么」这类问题的正确问法。

## 1 功能语句的三个奇怪之处

「心脏的功能是泵血」这句话，仔细分析有三个让物理学家皱眉的特点：

- **规范性（normativity）**：它暗含「心脏应该泵血」——不泵血的心脏是「有缺陷的」。物理对象没有「应该」，石头从不「应该」下落。<span class="marginnote">这种规范性也叫「功能性的对错」：一个不能泵血的心脏是「坏」心脏，尽管它跟好心脏一样遵守物理定律。功能语句给世界引入了「标准」，这是纯粹因果描述所没有的。</span>
**目的性（teleology）**：它把心脏的存在解释为「为了泵血」——仿佛泵血是心脏存在的理由。物理学的解释不指向未来，只追溯原因。
**选择性（selectivity）**：心脏同时泵血、发声、占据胸腔空间，但只有「泵血」被算作功能——凭什么是它？<span class="marginnote">这个「选择性问题」是功能理论的分水岭：任何靠谱的功能理论，都必须解释为什么「泵血」是功能而「发声」不是。</span>

## 2 功能的两大理论

当代功能理论分两大阵营，它们对「为什么泵血是功能」给出完全不同的回答。

**目的论理论（etiological / selected-effect theory）**：功能是**被选择的效果**。

「泵血」是功能，因为心脏祖先的泵血给携带者带来了选择优势，泵血正是心脏被保留下来的原因。
「发声」不是功能，因为发声从未给心脏祖先带来选择优势，它只是泵血的结构性副产品。
- 代表：赖特（Wright）、米利肯（Millikan）、尼兰德（Neander）。

**因果角色理论（causal-role theory）**：功能是**在更大系统中所贡献的角色**。

- 「泵血」是功能，因为它在血液循环这个更大的系统中扮演因果角色，维持了有机体的生命。
- 「发声」也可以是功能——如果它在交流系统中扮演角色。
- 代表：卡明斯（Cummins）。<span class="marginnote">卡明斯的功能观来自工程学的「系统分析」：一个零件在整机中的功能 = 它对整机能力的因果贡献。这个视角把「功能」从历史中解放出来——不需要知道演化史，也能说出「这个新器官可能的功能」。</span>

## 3 公式解析：两种理论的逻辑形式

把两种理论写成判定式的逻辑形式，差异一目了然。设「性状 X 的功能是 F」：

**目的论理论**：

$$
F_{\text{etio}}(X) \iff \exists \text{选择历史 } H: \big[\, X \text{ 的祖先因做 } F \text{ 而在 } H \text{ 中获益} \,\big]
$$

**因果角色理论**：

$$
F_{\text{role}}(X) \iff \exists \text{系统 } S: \big[\, X \text{ 是 } S \text{ 的能力 } F \text{ 得以实现的因果组分} \,\big]
$$
