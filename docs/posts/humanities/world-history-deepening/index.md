# 世界史深化（古希腊罗马/中世纪/近现代/冷战）

以斯塔夫里阿诺斯《全球通史》与吴于廑、齐世荣《世界史》为纲，从古希腊罗马的古典文明、中世纪欧洲，到近代资本主义兴起与全球体系形成，直至两次世界大战与冷战两极格局，系统贯通西方文明发展的完整主线。学完这些章节，就写完从古典到冷战的西方文明史主干。

## 对标教材

- 斯塔夫里阿诺斯,《全球通史——从史前史到21世纪》（第7版，北京大学出版社）
- 吴于廑、齐世荣,《世界史》（6卷本，高等教育出版社）
