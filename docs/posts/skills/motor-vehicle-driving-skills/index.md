# 机动车驾驶技术

驾驶是现代生活的基本技能，全国有统一教学大纲与官方教材。以公安部道路交通安全研究中心组织编写的官方教材《安全驾驶从这里开始》为纲，结合公安部令第162号《机动车驾驶证申领和使用规定》与交通运输部《机动车驾驶员培训教学大纲》，系统重建从驾驶人素质、车辆认知、交通法规到场地驾驶、道路驾驶、安全文明驾驶与应急处置的完整驾驶知识与技能体系。

## 对标教材

- 《安全驾驶从这里开始》（公安部道路交通安全研究中心）
- 公安部令第162号《机动车驾驶证申领和使用规定》
- 交通运输部《机动车驾驶员培训教学大纲》
