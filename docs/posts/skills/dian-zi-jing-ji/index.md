# 电子竞技

电子竞技是以电子游戏为载体、以智能设备为器械的竞技对抗运动，核心在于操作技巧、团队战术、赛事规则与产业运营的系统结合。以《电子竞技运动教程》、LPL/英雄联盟赛事规则与电子竞技教练员体系为纲，系统重建从项目概述、产业生态、竞赛规则、操作技术、团队战术到教练员体系的完整知识框架。

## 对标教材
