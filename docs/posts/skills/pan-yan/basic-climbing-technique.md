## 为什么从手点与脚点开始

前面两篇我们解决了「安全」的问题——怎么保护、怎么下降。从这一篇起，进入攀岩的「核心本体」：**怎么爬**。而攀爬的第一课，是重新理解你的四肢。<span class="marginnote">人类的日常动作里，手臂承担「拉、提、撑」，腿负责「走、站」——但在攀岩里，这个分工被彻底改写：<strong>腿才是承重的主力，手臂只是「平衡与定向」的工具</strong>。这一观念转变是新手的第一道坎：总想用手「把自己拉上去」，结果手臂先力竭、腿却在「偷懒」。理解了「手轻脚重」，你就拿到了攀岩技术的总钥匙。</span>

这一节从最基础的「手点（handhold）」与「脚点（foothold）」讲起：它们各自的运用原则，以及「手轻脚重」这条贯穿全部攀岩技术的核心法则。

## 1 手点的种类与抓法

岩点（手点）的形态千变万化，但大致可以按「怎么抓」分成几类：

### 常见手点类型

| 手点类型 | 形态 | 抓法要点 |
| --- | --- | --- |
| 大把手（jug） | 深、好抓的凹槽/把手 | 手指包握，最省力的手点 |
| 侧拉点（sidepull） | 开口朝侧面的点 | 横向拉，不是向下拉 |
| 反提点（undercling） | 开口朝下的点 | 手心向上「托举」 |
| 捏点（pinch） | 两侧平行可捏 | 拇指与四指对捏 |
| 抠点（crimp） | 小、浅的棱边 | 指尖压住边缘，力量集中 |
| 口袋点（pocket） | 单指/双指洞 | 精确插入，避免过度用力 |

### 抓点的通用原则

**用「拉」代替「抓」**：手的核心作用是**对抗重力、保持平衡**，而不是「捏死」岩点。把岩点想象成「你按压的一个表面」，而不是「你要抓住的东西」——放松手指，让手掌与岩点充分接触，比死命攥紧更有效。<span class="marginnote">为什么「放松地抓」比「用力地抓」更好？因为<strong>握得越紧，小臂前群肌（屈指肌）越疲劳</strong>——攀岩的力竭主要来自手臂，而手臂疲劳后会失去握力，直接导致脱落。老手挂在同样的点上，手臂却相对放松——他们把重量交给了脚和骨架，手只负责「维持平衡」。这也是「手轻脚重」的第一层含义。</span>

**用「压」处理抠点（crimp）**：抠点是难度线路的主角。抠点时用**指尖的指腹压住岩点边缘**，而不是用指关节「卡住」——正确的半抠点（half crimp）姿势让手指力量传递更直接，也降低指关节受伤风险（见第5篇《常见损伤与预防》）。

## 2 脚点的运用：攀岩的「隐藏主角」

新手普遍忽视脚点，但**脚点才是承重的主力**。脚点运用的三个层次：

### 第一层：精确踩点

攀岩鞋的鞋尖是踩点的主力。踩脚点时要**用鞋尖（大脚趾区域）最前端**踩住脚点，让身体的重量垂直线落在脚点正上方——这需要**看着脚下踩点**，精确控制脚尖位置。

### 第二层：摩擦与「鞋尖踩法」

在宽大但平缓的脚点（摩擦面）上，靠**鞋底橡胶的摩擦力**支撑，脚跟着略低、鞋底尽量贴合岩面——这叫「**摩擦踩法（smearing）**」，在斜板与花岗岩面上尤其重要。<span class="marginnote">摩擦踩法颠覆「必须有凸起才能踩」的直觉：在光滑斜面上，攀岩鞋的橡胶能产生足够摩擦力，让平脚掌「贴」住岩面。它的关键是「<strong>让鞋底尽量大面积接触岩面 + 身体重心压在脚上</strong>」——越用力往下踩，摩擦力越大，越稳。这是攀岩鞋「软底、黏性橡胶」设计价值的集中体现。</span>

### 第三层：用脚「推」而不是「勾」

**在仰角区（overhang）**，脚点运用变成了「用脚尖把身体**推**向岩壁」——脚用力向下、向后蹬住脚点，把身体「压」向岩壁，从而让手只负责平衡。高手在仰角上「脚比手忙」：每个动作都是「先移动脚、再用手跟」。

**核心要点：** 脚点运用的总原则是「**看脚下、轻踩准、重心压**」。判断标准：爬完一条线，你的脚是否比手更「累」？如果不是，说明你的脚还在「偷懒」。

## 3 手轻脚重：攀岩的第一力学法则

把前两节合起来，就是攀岩技术的第一条总法则——**手轻脚重（hand-light, foot-heavy）**：

**腿的力量远超手臂**：大腿肌群是全身最强壮的肌群之一，而小臂手指的力量有限。把重量交给腿，等于用「大力士」承重、用「细工匠」微调。

### 手轻脚重的三层含义

1. **重量靠脚**：身体的重量主要由双脚承担，手臂不承重或只承担少量重量。
2. **手是平衡器**：手臂的用力方向以「维持平衡、定向」为主，而不是「向上拉」。
3. **脚先手后**：攀爬顺序永远是「先移动脚、再移动手」——脚站稳了，手才有余力去够下一个手点。

**辨析｜易错点：** 新手最常见的错误是「**手臂拉直死撑**」——两臂伸直、像引体一样把自己吊住，结果手臂迅速力竭。**正确的姿态是「手臂微屈、重心放在腿上」**——手臂保持放松微屈，用腿蹬起身体，手只做「扶住」的动作。判断标准：爬完 5 米，你的手臂应该「轻微酸」而非「剧烈酸」；如果你感觉「手指要断了」，多半是手在「替腿干活」。

## 4 公式解析：静态攀爬的重力平衡

基础攀爬的身体状态，可以简化为一个**静力平衡**问题。把身体看作一个刚体，它受到重力 $\vec{G}$、来自手点的力 $\vec{F}_h$ 与脚点的力 $\vec{F}_f$ 三个力作用。静力平衡条件为：

$$
\vec{G} + \vec{F}_h + \vec{F}_f = \vec{0}
$$

分三步拆解：

- **第一步，读懂三个力**：$\vec{G}$ 是重力（竖直向下，大小 $mg$），$\vec{F}_h$ 是手点给手的反力（方向由抓法决定），$\vec{F}_f$ 是脚点给脚的反力。<span class="marginnote">反力的直觉：你「压」岩点，岩点就「推」你——作用力与反作用力。手点能提供的反力方向有限（只能沿抓握的接触方向），所以攀岩动作的本质是「<strong>通过改变身体位置，让手点反力与脚点反力的合力恰好抵消重力</strong>」。</span>
**第二步，看竖直分量的分担**：把平衡方程沿竖直方向投影，得 $F_h\sin\theta_h + F_f\sin\theta_f = mg$——重力的竖直分量由手与脚共同分担。**「手轻脚重」对应的是 $F_f$ 占绝大部分、$F_h$ 很小**；如果 $F_h$ 过大，说明手臂在超负荷承重。
**第三步，落地为动作**：要让 $F_f$ 尽量大，就要**把身体重心尽量贴近岩壁**（减少手臂的水平分力需求）——重心越贴近墙面，重力越能被脚「直接顶住」，手臂越轻松。这也是为什么教练反复喊「**把髋部贴近岩壁**」——它不是美观要求，是力学要求。

**核心要点：** 静力平衡方程 $\vec{G} + \vec{F}_h + \vec{F}_f = \vec{0}$ 是理解一切攀爬姿态的框架：**你的每一个动作，都在重新分配「手与脚各自分担多少重力」。**「手轻脚重」就是在追求「让脚多扛、手少扛」。

## 5 基础攀爬的完整动作链

把上面的一切串成一个基础动作循环：

1. **观察**：看下一个手点与脚点在哪里。
2. **移脚**：先把脚移到目标脚点，看准、轻踩、重心压上。
3. **移手**：脚踩稳后，把手移向下一个手点，保持手臂微屈。
4. **重心跟进**：随着手脚移动，身体重心同步上移、贴近岩壁。

**节奏感**：基础攀爬的节奏是「**慢而稳**」——每一步都先站稳、再动手。新手要克制「急着往上够」的冲动：**够不到往往不是「手短」，而是「脚没站高 / 重心没送上去」**。<span class="marginnote">「够不到就换脚再够」是基础攀爬最实用的一条经验：很多「够不到的手点」，其实只要把脚点高踩一步、重心送上去，手就轻松够到了。攀岩的「高度」不是用手「拉」出来的，而是用脚「撑」出来的——这个观念会贯穿你此后所有的攀爬。</span>

### 基础攀爬的常见错误与纠正

把新手在「手点与脚点」上最常见的错误集中起来，逐一给「纠正口令」：

**错误一：「盯着手，不看脚」**——脚下乱踩，脚点踩不准。**纠正口令：「每一步都先看脚下」**——踩准脚点，比急着够手点更重要。
**错误二：「手臂拉直吊住」**——用引体的方式「挂」在岩壁上，手臂迅速力竭。**纠正口令：「手臂微屈，重量交给腿」**——腿发力蹬起，手只做「扶住」。
**错误三：「用指关节卡抠点」**——抠点姿势错误，指关节受力过大。**纠正口令：「用指腹压住边缘」**——半抠点姿势，指尖发力。
**错误四：「换脚时重心不动」**——换脚后身体重心没跟上，脚「白换」。**纠正口令：「换脚前先移重心」**——重心先倾向新脚点，再换脚。

<span class="marginnote">「纠正口令」的价值在于「可执行」：不说「你要放松」，而是说「手臂微屈、重量交给腿」——给大脑一个「具体的动作指令」，比给一个「抽象的目标」更有效。这也是为什么攀岩教练「现场喊话」时都用短促的具体指令——<strong>「短、具体、可执行」的指令，是纠正动作最有效的方式</strong>。</span>

**核心要点：** 基础攀爬的四类高频错误（不看脚、手臂吊、指关节卡、重心不动）都有对应的「纠正口令」——**用「具体指令」纠正「抽象错误」，进步最快**。

## 6 小结

- 手点分**大把手、侧拉点、反提点、捏点、抠点、口袋点**等类型，抓法各异。
- 抓点原则是「**用拉代替捏**」：放松手指、贴面接触，避免小臂过早力竭。
- 脚点是承重主力：**精确踩尖、摩擦踩法、仰角用脚推**三层次递进。
- **手轻脚重**是第一力学法则：腿承重、手平衡、脚先手后。
- 静力平衡方程说明「**重心贴近岩壁 = 手臂省力**」；基础动作链是「观察 → 移脚 → 移手 → 重心跟进」。

在下一节，我们从「单个动作」上升到「身体整体」：**身体姿态、重心转移与攀爬节奏**——决定你爬得「顺不顺」的三个变量。
