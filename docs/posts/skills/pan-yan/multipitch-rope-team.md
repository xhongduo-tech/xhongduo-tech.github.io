## 为什么从多段攀登开始

当一条线路的高度超过了**一根绳子的长度**（通常 50—70 米），单段攀登就「不够用了」——你需要把它分成若干「段」（pitch），一段一段地爬，这就是**多段攀登（multipitch climbing）**。<span class="marginnote">多段攀登是攀岩「野外形态」的极致：它不再是一个「攀爬者 + 一个保护者」的固定组合，而是<strong>两人不断「角色互换」的协作系统</strong>——这一段的攀爬者，下一段变成保护者；每段之间要在岩壁上建立「保护站（belay station）」，进行交接。多段攀登考验的早已不只是「攀爬」，而是「团队协作、器材管理、系统思维」——它是攀岩技术的「集大成」。</span>

这一节讲多段攀登的核心概念：**绳段、保护站、结组流程**，以及它比单段攀登复杂在哪里。

## 1 多段攀登的基本概念

### 绳段（pitch）

**绳段（pitch）**是多段攀登的基本单位：从**一个保护站到下一个保护站**之间的一段攀爬，长度受绳子长度与线路形态限制（通常 30—50 米）。一条大岩壁线路可能由几十个绳段组成。

### 保护站（belay station）

**保护站**是每个绳段结束处的**中间锚点**：供攀登者停下来、把保护权交给同伴、再继续下一段。保护站要**双点冗余、均衡、独立**（见第2篇《锚点系统》），且要能同时支撑「向上的攀爬者」与「向下的保护者」两个方向的力。

### 结组（rope team）

**结组**指「两个（或更多）攀岩者共享一根绳子、相互保护」的组合——多段攀登的基本单位。结组成员**交替领攀**：一人先锋上一段，另一人在保护站保护；下一段角色互换。

**核心要点：** 多段攀登 = 「**多个单段先锋 + 每个绳段之间的保护站交接**」——它把单段攀登的「一次保护」扩展成「循环往复的保护交接」。

## 2 多段攀登的完整流程

以两人结组为例，走一遍完整流程：

### 第一段：领攀者上

1. **领攀者（leader）**在保护站 A 由**跟攀者（follower）**保护，先锋攀爬第一段，在段顶建立**保护站 B**。
2. 领攀者在 B 站把自己固定好，转为**保护者**，准备保护跟攀者。

### 第二段：跟攀者上

3. **跟攀者**在 A 站**解除保护**，开始攀爬（通常**顶绳式**爬——绳从 B 站垂下），由 B 站的领攀者保护。
4. 跟攀者爬到 B 站，拆除第一段的保护点（如果是传统攀登）。

### 循环往复

5. 两人在 B 站汇合，**交接器材**（把领攀要用的器材交给下一段的领攀者），确认 B 站安全后，**新领攀者**先锋爬第二段……如此循环，直到登顶或目标点。

<span class="marginnote">多段攀登的节奏是「<strong>交替领攀</strong>」：一个绳段一个绳段地推进，两人轮流「当领攀者」。这个「轮流」设计非常关键——领攀既消耗体力又消耗心理，交替领攀让两人都能「间歇性充电」。也是为什么结组伙伴的选择要「水平相近」——如果一人明显弱于另一人，强的人会被「绑定」在领攀位置上，体力与心理都容易透支。</span>

## 3 保护站的交接技术

多段攀登的「系统复杂度」集中在**保护站交接**——这是新手最容易出错、也最需要训练的地方：

### 交接的核心动作

**到达保护站**：领攀者到站后，先用**双套结**把自己固定到保护站主锁上（见第2篇《绳结》），再宣布「保护站建立（off belay / anchored）」。
**保护权转移**：确认领攀者已固定后，下方跟攀者**解除保护**，开始攀爬。
**保护跟攀者**：领攀者用保护器保护跟攀者（跟攀者通常是顶绳式爬）。
**汇合与交接**：跟攀者到站后，两人交换器材、确认保护站、规划下一段。

### 交接的常见错误

**没固定就「解保护」**：领攀者到站后，必须先「固定自己」再让下方解除保护——否则可能出现「两人同时不在保护中」的危险瞬间。
**保护站「单人受力」**：保护站必须能承受「保护者 + 攀爬者」双方的重量——架设时要考虑「双向受力」。
- **器材混乱**：交接时器材归属不清，导致领攀者「该有器材时没器材」——**交接时清点器材是纪律**。

**辨析｜易错点：** 新手最危险的交接错误是「**保护站未建好就开始下一段**」。**保护站是「安全暂停点」——它的可靠性决定整个系统的安全。** 判断标准：**在任何一段开始前，确认「保护站已双点冗余、当前角色已明确、器材已交接」**——「三个确认」缺一不可，就是「系统就绪」的标志。

## 4 多段攀登的风险与应对

多段攀登的风险维度比单段更多：

### 环境风险

**落石**：上方攀登者可能蹬落碎石砸中下方——**头盔必戴**，且下方攀登者应「贴墙避让」。
**天气**：多段线路耗时长，可能遭遇天气变化——出发前看天气窗口，准备防雨衣物。
**迷路/找路**：野外地貌复杂，路书与「找路线」能力至关重要。

### 系统风险

**绳子管理**：两段绳子（或一根长绳）在保护站容易缠绕——**逐段理绳**是纪律。
**沟通风险**：多段攀登中，两人距离远、地形嘈杂——**口令与信号**（如「拉绳」「放绳」的约定）要提前确认。
**设备风险**：保护站、保护器、绳结在反复使用中「出错概率累积」——**每一段都重新检查**（见第2篇《自我保护与绳索管理》）。<span class="marginnote">「多段攀登的错误概率是『乘法』而不是『加法』」——单段攀登犯错的概率若为 1%，多段 20 段累积下来，错误风险会显著放大。这就是为什么多段攀登老手「每段都像第一段一样谨慎」：检查绳结、检查保护站、检查快挂——<strong>重复检查不是「不信任」，而是「对抗概率累积」的纪律</strong>。</span>

### 救援与自救

多段攀登遇险时（有人受伤、被卡），自救能力是关键：**普鲁士结**（挂在绳上移动/固定）、**简易担架**、**下降救援**等技能——这属于进阶救援内容，但每一位多段攀登者都应掌握基本自救。

## 5 核心对比：单段 vs 多段攀登

| 维度 | 单段攀登 | 多段攀登 |
| --- | --- | --- |
| 绳段数 | 1 | 多个 |
| 保护方式 | 固定组合（攀爬者 + 保护者） | 交替领攀、角色互换 |
| 锚点 | 地面/顶部锚点 | 每个绳段有中间保护站 |
| 时间 | 数十分钟 | 数小时—数天 |
| 复杂度 | 低 | 高（系统 + 协作 + 环境） |
| 风险维度 | 攀爬 + 操作 | 攀爬 + 操作 + 环境 + 沟通 |

**核心要点：** 多段攀登是攀岩「复杂度」的最高形态——**它把单段的技术，放进「多段交接 + 角色互换 + 环境变化」的系统里**。会单段不等于会多段，多段需要专门的训练与经验积累。

## 6 多段攀登的训练路径

从单段到多段，训练路径是渐进的：

**先练保护站技术**：在岩馆/低矮墙练习「建立保护站、双套结固定、保护权交接」——把交接动作练成肌肉记忆。
**再练短多段**：在低矮的野外线路上爬「2—3 段」的短多段，体验「交替领攀 + 交接」的完整流程。
**跟老手刷线**：多段攀登的「系统判断力」（找路、评估风险、器材管理）需要实战观摩——**跟随有经验者，是最快的成长路径**。
**逐步升级**：从「螺栓保护的多段运动线路」（安全）到「传统多段」（高要求），逐步增加风险维度。

<span class="marginnote">「多段攀登的成长 = 系统的熟悉度」：每一段交接、每一次角色互换、每一个保护站的评估——重复足够多次，这些「系统动作」会从「想」变成「本能」。这也是为什么多段攀登老手「看着从容」：不是胆子大，而是「系统操作」已经内化，能把注意力留给真正需要判断的地方——找路、读岩、风险管理。</span>

## 7 小结

- **多段攀登** = 多个绳段 + 保护站交接 + 交替领攀；结组是它的基本协作单位。
- 完整流程：**领攀者先上建立保护站 → 跟攀者顶绳上 → 汇合交接 → 新领攀者再上**。
- 保护站交接是「系统复杂度」的核心：**固定 → 转移保护权 → 保护跟攀者 → 清点交接**，三个确认缺一不可。
- 多段攀登的风险是「乘法累积」：**环境风险 + 系统风险 + 沟通风险**，需要逐段重查与自救能力。
- 训练路径：**先练保护站技术 → 短多段 → 跟老手刷线 → 逐步升级**。
