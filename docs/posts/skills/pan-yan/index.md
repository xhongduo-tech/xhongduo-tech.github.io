# 攀岩

攀岩是一项集力量、平衡、柔韧与心理意志于一体的极限运动，研究从装备与保护系统、攀爬技术、训练方法到竞赛规则与岩馆运营的完整体系，是锻炼全身协调性与风险意识的代表性户外运动。以《攀岩运动教程》、IFSC《国际攀岩竞赛规则》与攀岩保护技术培训教材为纲，从基础攀爬与安全保护到岩馆攀爬与自然岩壁攀登，系统重建攀岩的完整知识体系。

## 对标教材

- IFSC《国际攀岩竞赛规则》
