# 金属热处理工

金属热处理工通过加热、保温和冷却的工艺调控改变金属材料的内部组织与性能，是淬火、回火、正火、退火及渗碳渗氮等工序的实操核心工种。以《国家职业技能标准—金属热处理工》、《金属热处理工艺学》与《热处理工实用技术手册》为纲，从热处理基础、炉温控制到缺陷预防，系统写完整套金属热处理操作技能。
