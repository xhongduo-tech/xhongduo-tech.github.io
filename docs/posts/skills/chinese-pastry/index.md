# 中式面点工艺（中式面点师）

中式面点是中餐主食与点心的核心体系，馒头、饺子、面条、点心等品类经发酵、成型、熟制三大技法自成一套完整工艺。以国家职业技能标准《中式面点师》为纲，结合《中式面点制作技术》《中国面点大全》等教材，系统重建从原料认知、面坯调制到制馅、成型、熟制的完整中式面点工艺。学完这些章节，就写完了中式面点工艺的全部内容。

## 对标教材

- 国家职业技能标准《中式面点师》
- 《中式面点制作技术》（中国轻工业出版社）
- 《中国面点大全》
