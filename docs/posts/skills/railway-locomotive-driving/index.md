# 铁路机车车辆驾驶（火车司机）

以《铁路机车车辆驾驶人员资格许可办法》与国铁集团《铁路机车车辆驾驶人员资格考试大纲》为纲，结合《铁路技术管理规程》，系统覆盖从机车车辆构造、制动与信号基础，到列车操纵、行车规章、非正常处置及资格考试法规的完整知识体系。学完这些章节，就掌握了火车司机这一法定资格许可职业从报考、应考到上线值乘的全部核心内容。

## 对标教材

- 《铁路机车车辆驾驶人员资格许可办法》（交通运输部令 2019 年第 31 号）
- 国家铁路局/国铁集团《铁路机车车辆驾驶人员资格考试大纲》
- 《铁路技术管理规程》（普速铁路部分、高速铁路部分）
