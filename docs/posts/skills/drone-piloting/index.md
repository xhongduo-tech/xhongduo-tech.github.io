# 无人机驾驶与操控

无人机驾驶已快速成为大众化、职业化的新技能。本学科以《无人驾驶航空器飞行管理暂行条例》、CCAR-92《民用无人驾驶航空器运行安全管理规则》与民航局《操控员执照考试大纲》为纲，系统掌握从法规执照、系统原理、操控技术到安全运行与行业应用的完整知识链，学完即可覆盖合格操控员应具备的全部理论与实操能力。

## 对标教材

- 《无人驾驶航空器飞行管理暂行条例》（国务院、中央军委令）
- CCAR-92《民用无人驾驶航空器运行安全管理规则》
- 民航局《民用无人驾驶航空器操控员执照考试大纲》
