## 为什么从无线电频率开始

无人机与地面的每一次对话——遥控指令、图传画面、数传数据、GNSS 定位——都发生在**电磁波**里。频谱是无人机的「隐形高速公路」，但这条路**空间有限、易受干扰、人人共享**。<span class="marginnote">一架无人机的正常运行依赖同时工作于多个频段的链路：2.4GHz/5.8GHz 遥控与图传、GNSS 频段的定位信号、可能还有 4G/5G 数传。频谱管理就是把这份「公共资源」的秩序讲清楚——用错频段、功率超标、被干扰而不自知，都可能让飞行瞬间失控。</span>这与「从极限到大模型」里理解「算力、带宽是共享资源，要按约束调度」是同一个资源管理问题。

## 1 无人机的频谱版图

无人机涉及的主要无线电频段与用途：

| 频段 | 主要用途 | 特征 |
| --- | --- | --- |
| 2.4 GHz | 遥控与图传 | 普及但拥挤，公共 WiFi 同频 |
| 5.8 GHz | 图传/数传 | 带宽大、干扰少，距离略短 |
| GNSS（1.1~1.6 GHz 各频点） | 卫星定位 | 信号微弱，极易被干扰压制 |
| 4G/5G 蜂窝 | 超视距数传 | 覆盖广，依赖运营商网络 |

**每条链路都有脆弱点**：2.4GHz 拥挤易碰撞，GNSS 微弱易被压制，蜂窝依赖网络覆盖。理解这张频谱图，才知道「断链」有多少种来源。<span class="marginnote">无人机在 2.4GHz 上与 WiFi、蓝牙、微波炉共用频段——这解释了为什么起飞点选在「无线信号密集区」时容易卡图传。频谱是共享的，没有人拥有它，只有遵守秩序的人能用好它。</span>

## 2 频率使用的合规要求

无人机的无线电使用不是「自由使用」，而受无线电管理法规约束：

- **发射功率与频段**：须符合国家无线电管理规定，使用许可频段，功率不得超标。
- **设备型号核准**：遥控、图传等无线设备须取得**型号核准**，否则不得销售与使用。
- **与航空频段隔离**：严禁占用或干扰民航、空中交通管理等专用频段。<span class="marginnote">擅自改装天线、加大发射功率来「增加图传距离」，是典型的违规操作——它可能压掉别人（包括载人航空器）的合法信号。监管对频谱越界的态度是零容忍，因为频谱冲突直接危及飞行安全。</span>

**频率合规的要义是「功率与频段都要在红线内」**：改功率、占频段，短期看起来「信号更强」，长期是拿公共安全做赌注。

## 3 电磁干扰：看不见的敌人

**电磁干扰（EMI）**指外部电磁信号破坏无人机链路或传感器的现象。常见来源包括：

- **同频干扰**：周边大量 2.4GHz 设备抢占频谱，图传卡顿、遥控延迟。
- **强电磁场**：高压输电线、变电站、雷达站附近的强场环境。
- **GNSS 干扰**：恶意干扰器或无意遮挡（如金属遮蔽、城市峡谷）导致定位失效。<span class="marginnote">高压线与变电站是无人机失联的高发地：强电磁场会让飞控的磁力计失准、让图传出现雪花。作业巡检在输电线路附近飞行时，「靠近即降级」是常态，必须按最小安全距离规划航线。</span>

**干扰的可怕之处在于它「不打招呼」**：没有告警、没有前兆，链路直接消失。所以防干扰的关键是**选址与余量**，而不是事发后补救。

## 4 抗干扰与合规运行实务

把频谱知识落到运行上，是几条可执行的纪律：

- **起飞前扫频**：观察图传与遥控信号质量，信号弱就换频点或换位置。
- **避开强干扰源**：起降点远离高压线、变电站、雷达站与人员密集的 WiFi 区域。
- **留链路余量**：不做「极限距离图传」实验，留出信号衰减的冗余。
- **不改装功率**：坚持原厂天线与功率设置，尊重频谱共享秩序。<span class="marginnote">这条「不改装」原则值得单独强调：图传距离不足时，正确的做法是换更高端合规的设备，而不是把现有设备改装到越界。<strong>合规设备的性能上限，就是你运行的合法边界。</strong></span>

**抗干扰的本质是「给链路留余量、给干扰留距离、给秩序留尊重」**——三者合起来，链路可靠性才有保障。

## 5 易错点辨析

- **距离远 ≠ 画质差**：图传卡顿的本质是**信噪比下降**，数字图传会自动降码率保连接——看链路要看信号强度与码率，不是只看距离。
- **2.4 GHz 与 5.8 GHz 不是「谁更好」**：2.4 GHz 穿障好但拥挤，5.8 GHz 干净但损耗大——选哪个取决于环境，没有绝对最优。
- **加大功率 ≠ 合法增距**：擅自改装天线、加大发射功率会压掉别人信号，属于违规操作——合规设备的性能上限就是运行边界。
- **强磁场区是「无告警陷阱」**：高压线、变电站附近的干扰往往没有前兆，起飞前勘查比事发后补救可靠。
- **罗盘与链路是两回事**：电磁干扰可能同时影响磁力计（航向）与射频链路（失联），排查时两条线都要查。

## 6 术语速查表

| 术语 | 含义 |
| --- | --- |
| ISM 频段 | 2.4 GHz / 5.8 GHz 等免许可民用频段 |
| 遥控链路 | 地面 → 飞机的指令通道 |
| 图传链路 | 飞机 → 地面的画面通道 |
| GNSS 频段 | 卫星定位信号频段 |
| 电磁干扰（EMI） | 外部电磁信号破坏链路或传感器 |
| 同频干扰 | 同频段设备互相挤压 |
| 多径衰落 | 反射波与直射波叠加相消 |
| 信号强度 | 接收端的信号电平 |
| 码率 | 单位时间的视频数据量 |
| 型号核准 | 无线设备合法使用的核准 |

## 7 考点速记

- 无人机涉及频段：**2.4G/5.8G 遥控图传、GNSS 定位、4G/5G 数传**。
- 频率合规：**许可频段、核准设备、功率不超标**。
- 干扰三源：**同频拥挤、强电磁场、GNSS 压制**。
- 图传卡顿看**信噪比与码率**，不是看距离。
- 5.8 GHz 比 2.4 GHz 损耗大约高 **7 dB**。
- 抗干扰纪律：**选址、扫频、留余量**。
- 严禁**擅自改装功率与天线**——合规性能上限就是运行边界。
- 强电磁场干扰**不打招呼**，靠起飞前勘查而非事发补救。
- 一句话记忆：**频谱是共享的，守秩序的人才能用好它**。
- 链路可靠性 = 留余量 + 留距离 + 尊重秩序。

## 8 延伸与动手练习

- 打开遥控器设置，找到自动/手动频点切换，理解「跳频」的机制。
- 在 WiFi 密集区起飞前观察图传信号，练习「换位置、换频点」的排查动作。
- 用测风仪或 App 记录一次「强磁场区附近」飞行的链路表现。
- 阅读机型说明书里关于频率、功率、型号核准的标注。
- 追问：为什么 5.8 GHz 比 2.4 GHz 损耗大约高 7 dB？——回看 FSPL 公式。
- 观察罗盘与图传在同一位置的表现差异，理解干扰的不同作用对象。
- 思考：为什么「加大功率」不是合法增距的正确解法？
- 在规划航拍机位时，把「高压线、变电站、雷达站」标进禁选清单。
- 对比「模拟图传 vs 数字图传」在弱信号下的表现差异。
- 总结一条你自己的「链路自检口诀」，写进起飞前检查单。

## 9 小结

- 无人机运行依赖**2.4G/5.8G/GNSS/蜂窝**等多条链路，各有脆弱点。
- 频率使用须符合**无线电管理规定**：许可频段、核准设备、功率不超标。
- 强电磁场、同频拥挤、GNSS 压制是三大**电磁干扰**来源。
- 防干扰靠**选址、扫频、留余量**，靠起飞前的纪律而非事发后的补救。
- **严禁擅自改装功率与天线**——合规设备的性能上限就是运行合法边界。
