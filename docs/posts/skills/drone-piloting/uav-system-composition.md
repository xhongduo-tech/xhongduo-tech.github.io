## 为什么从系统组成开始

法规篇结束，我们进入「机器怎么工作」。一架无人机不是「一个会飞的东西」，而是一个**由若干子系统组成的闭环系统**——每个子系统单独看都不神奇，组合起来却能悬停、平移、返航、拍摄。<span class="marginnote">理解系统的关键在于「接口」：动力系统出力，飞控系统决策，导航系统定位，通信系统传令。它们之间的接口——总线、串口、协议——决定了整机性能。</span>这与「从极限到大模型」里理解大模型先拆「数据—算力—算法—对齐」一样，任何复杂系统都要先拆后合。

## 1 平台子系统：机体与结构

无人机最基础的子系统是**机体平台**，包括机架、机臂、起落架与各舱位布局。机体决定的是**载荷能力、抗风性与可维护性**：多旋翼的机臂数与布局直接决定推力冗余——四轴失去一桨必须立即降落，六轴、八轴失去一桨仍可安全返航。<span class="marginnote">「旋翼数=冗余度」是选机的第一课：作业型无人机偏爱六轴/八轴，就是因为单点故障时还有继续飞行和降落的余量。</span>

机体还承载着电子设备的布置原则：**重心居中、线缆防震、电磁隔离**——飞控靠近重心，图传天线尽量远离碳纤维结构以获得更好的辐射特性。

## 2 动力子系统：电调、电机与螺旋桨

动力子系统由**电池 → 电调（ESC）→ 电机 → 螺旋桨**的能量链条组成。电调把直流电转换成电机所需的交变电流并调速，电机把电能转成旋转机械能，螺旋桨把旋转转成升力或推力。<span class="marginnote">电调与电机是「油门指令的执行层」：飞控发出 PWM 信号，电调据此换向调速。调速的平顺度直接决定悬停的稳度——这就是为什么飞控和电调的调参要一起做。</span>

在悬停状态下，整个系统的目标是维持一个简单的平衡：**总升力等于重力**。这个平衡方程是我们这一节要做的公式解析。

## 3 飞控子系统：无人机的「大脑」

**飞控（Flight Controller）**：集成惯性测量单元（IMU，含加速度计与陀螺仪）、气压计、磁力计等传感器，并结合导航模块，实时解算姿态并输出电机指令，构成**测量—解算—执行**的闭环。

- **测量**：IMU 给出三轴加速度与角速度，气压计给出高度。
- **解算**：飞控把姿态误差转成各电机的油门修正量，这就是姿态环与位置环的级联。
- **执行**：修正量经电调驱动电机，飞机姿态随之改变，再次被 IMU 测量——闭环由此形成。<span class="marginnote">这个「测量—解算—执行」闭环与「从极限到大模型」里强化学习的「状态—策略—动作」循环同构：都是系统在环境中感知、决策、行动并持续反馈。飞控是整个无人机中最像「人工智能」的部分。</span>

**飞控质量决定了无人机的上限**：同样的机体与动力，飞控算法好的能在大风中稳住，算法差的微风就飘。

## 4 链路子系统：遥控、图传与数传

无人机与地面的连接由三路链路构成：**遥控链路（RC）**传操纵指令，**图传链路（Video/FPV）**传实时画面，**数传链路（Telemetry）**传飞行状态与任务数据。<span class="marginnote">三路链路共享有限的无线频谱，工作频率、功率与抗干扰策略必须统一设计。断链是最危险的失效模式之一，本专题《应急情况处置》与《无线电频率与电磁干扰管理》两篇会重点展开。</span>

任务载荷（云台、相机、喷洒设备、传感器）则负责「干活」：它是无人机与社会需求之间的接口，也是第 5 篇各行业应用的主角。

## 5 公式解析：悬停平衡

**悬停是整个操控训练的地基，它满足一个简单而强大的力平衡方程：**

$$T = m\,g$$

拆解这个式子：

- **第一步，认识变量**：$T$ 是四组旋翼产生的**总升力**（单位牛顿 N），$m$ 是整机**起飞重量**（含载荷，单位千克 kg），$g$ 是重力加速度（取 9.8 m/s²）。
- **第二步，看平衡的实质**：悬停 = 升力恰好抵消重力，即 $T = m\,g$。若 $T > mg$ 则加速上升，$T < mg$ 则加速下降——**升力与重力的差，才是垂直方向的「净力」**。
- **第三步，算一个具体数字**：一架起飞重量 900 克的无人机，$m = 0.9$ kg，则悬停所需总升力为 $0.9 \times 9.8 = 8.82$ N，平均到四只旋翼，每只约需 2.2 N。<span class="marginnote">把 $T=mg$ 推到极限就得到<strong>爬升</strong>：电机转速上升、升力超过重力，多出的部分转化为垂直加速度。操控训练里「轻推油门悬停」的本质，就是让系统保持在 $T=mg$ 的平衡点附近。</span>

**这条式子还解释了「带载荷要付的代价」**：载荷每增加 100 克，悬停所需总升力就要增加约 0.98 N——电池续航、电机发热、抗风余量全都要为此买单。

## 6 易错点辨析

- **四轴 ≠ 四桨同步转**：对角桨同向、相邻桨反向，才能抵消反扭矩——「为什么四轴稳定」的答案在桨序，不在数量。
- **飞控 ≠ GPS**：飞控是姿态与控制核心，GPS 只是导航信息来源之一；GPS 失效飞控仍能靠 IMU 工作。
- **「图传」与「数传」不是一回事**：图传传画面、数传传数据，链路分工不同，别混用术语。
- **电调不是「油门开关」**：电调是调速执行器，接受飞控 PWM 信号换向调速，不是简单的通断。
- **载荷影响悬停平衡**：加装云台、喷药箱会增加起飞重量，悬停升力要随之提高——重载是系统级的重新配平。

## 7 术语速查表

| 术语 | 含义 |
| --- | --- |
| 机体平台 | 机架、机臂、起落架等结构 |
| 电调（ESC） | 驱动电机调速的执行器 |
| 飞控（Flight Controller） | 姿态与控制的决策核心 |
| IMU | 惯性测量单元，含陀螺仪与加速度计 |
| 气压计 | 测高度的传感器 |
| 遥控链路 | 地面 → 飞机的指令通道 |
| 图传链路 | 飞机 → 地面的画面通道 |
| 数传链路 | 飞机 → 地面的遥测通道 |
| 任务载荷 | 云台、相机、喷洒等执行设备 |
| 冗余度 | 部分部件失效后仍能安全运行的能力 |

## 8 考点速记

- 系统四块：**平台、动力、飞控、链路** + 载荷。
- 动力链条：**电池 → 电调 → 电机 → 螺旋桨**。
- 飞控闭环：**测量—解算—执行**，毫秒级循环。
- 悬停平衡：$T = mg$，升力与重力之差决定垂直运动。
- 旋翼数 = 冗余度：六轴、八轴失一桨仍可返航。
- 对角桨同向、相邻桨反向，抵消反扭矩。
- 三路链路分工：**遥控、图传、数传**。
- 载荷每增 100 g，悬停所需升力增约 0.98 N。
- 一句话记忆：**系统靠接口连接，接口靠协议统一**。
- 飞控是「大脑」，链路是「神经」，载荷是「手脚」。

## 9 延伸与动手练习

- 把自己的无人机拆装一次（或看说明书爆炸图），逐一识别平台、动力、飞控、链路模块。
- 用「电池 → 电调 → 电机 → 螺旋桨」的链条，向新手复述动力传递路径。
- 观察飞行日志里的姿态曲线，体会飞控「测量-解算-执行」闭环的痕迹。
- 称重记录加装载荷前后的起飞重量，用 $T = mg$ 算悬停所需升力变化。
- 对比四轴与六轴机型在失一桨时的表现，理解「旋翼数 = 冗余度」。
- 查看遥控器里「遥控/图传/数传」信号指示，逐一对应三条链路。
- 追问：为什么对角桨必须同向旋转？——用反扭矩解释。
- 在模拟器里拆解一台无人机，找出每个子系统与「接口」。
- 思考：飞控与电调之间传的是什么信号？——回顾 PWM。
- 把「系统靠接口连接」的思想，迁移到你对大模型架构的理解上。

## 10 小结

- 无人机是**平台、动力、飞控、链路、载荷**等多个子系统的闭环组合。
- **机体决定载荷与冗余**，旋翼数越多冗余度越高。
- 动力链条为**电池 → 电调 → 电机 → 螺旋桨**，执行飞控的油门指令。
- 飞控构成**测量—解算—执行**闭环，是全机的「大脑」。
- 悬停满足力平衡 $T = mg$，升力与重力之差决定垂直方向的运动。

在下一节，我们将把这套系统真正「开起来」——这就是**飞行原理与空气动力学基础**。
