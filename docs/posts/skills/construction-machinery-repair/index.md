# 工程机械维修与液压系统

面向国家职业资格目录中的法定职业「工程机械维修工」，对标《工程机械维修工国家职业技能标准（2019年版）》与维修教材，系统重建从拆装检修、液压传动、底盘维修、电气诊断到整机综合故障排除的工程机械四大维修技能体系。液压系统是工程机械的核心与维修难点，学完这些章节，就写完了工程机械维修与液压系统的全部内容。
