# 失眠的定义与诊断标准

## 为什么从定义开始

前面所有章节都在讲「怎么睡好」，现在转向「睡不好怎么办」。第一步不是急着找药，而是搞清楚**什么才算真正的失眠**。许多人只是「偶尔没睡好」就给自己贴上了「失眠症」的标签，反而陷入焦虑；也有人长期受困却不自知。临床诊断标准像一把尺子，先量清楚，再谈对策。

## 1 失眠 ≠ 睡得少

**失眠（insomnia）**：在有充足睡眠机会与环境的情况下，仍持续存在入睡困难、维持睡眠困难或早醒，并导致日间功能损害的一组症状。<span class="marginnote">关键词是「有充足的机会却睡不着」：夜班工人白天睡不香、被邻居噪音吵醒、自愿熬夜追剧——这些都不是失眠。失眠是「机会不缺、能力不够」，而非「环境太差或时间太少」。</span>

**关键辨析**：失眠的实质是**睡眠机会与实际睡眠之间的鸿沟**。短睡眠者（如 DEC2 基因携带者）睡 5 小时精神奕奕，不构成失眠；而躺够 8 小时却只睡 5 小时、白天疲惫的人，哪怕「时长」看着正常，也是典型失眠。

## 2 国际通行的诊断标准（ICSD-3 要点）

《睡眠医学》与全球通用的《国际睡眠障碍分类（第3版，ICSD-3）》把失眠障碍的诊断收紧为三条硬性标准：

1. **存在症状**：入睡困难（卧床 30 分钟未入睡）、或维持睡眠困难（夜间醒来 ≥ 2 次、醒后难再入睡）、或早醒（比预期早醒 30 分钟以上且无法再睡）。
2. **有日间损害**：疲劳、注意力/记忆下降、情绪不稳、日间嗜睡、工作学习表现下滑——至少一项。
3. **频率与病程**：每周至少 **3 晚**，且持续 **3 个月**以上，才达到「慢性失眠障碍」的诊断门槛。

**核心认识**：偶尔一晚没睡好只是「急性失眠」，不构成疾病；达到「每周 3 晚、持续 3 月」且影响白天功能，才需要认真对待并考虑专业干预。<span class="marginnote">病程门槛把「失眠」与「失眠障碍」分开，意义重大：多数人一生中都会经历短期失眠，但只有约 10% 会发展为慢性失眠障碍。把普通失眠当绝症会放大焦虑，把慢性失眠当小事则会错过干预窗口。</span>

## 3 失眠的常见分型与排除诊断

临床把失眠按病程与成因分型：

| 分型 | 病程 | 特点 |
| --- | --- | --- |
| 急性失眠 | < 3 个月 | 多由应激事件触发，常自行缓解 |
| 慢性失眠 | ≥ 3 个月 | 常伴心理与行为因素，需系统干预 |
| 继发性失眠 | 伴随他病 | 由疼痛、焦虑抑郁、呼吸暂停等引起 |
| 原发性失眠 | 无明确病因 | 排除其他疾病后仍持续存在 |

本主题为纯概念主题，无公式可解析，用上表替代公式解析。**排除诊断是关键**：诊断失眠前必须先排查「看起来像失眠、实则是别的病」的情况——睡眠呼吸暂停、不宁腿综合征、药物副作用、焦虑抑郁。把睡眠呼吸暂停误当普通失眠治疗，可能延误更严重的健康问题。

## 4 给自己评估的三问自测

在就医之前，可以先做一个三问自测：

- **机会**：我是否给了自己足够的睡眠时间与环境？（没给够 → 是作息问题，不是失眠）
- **症状**：入睡难 / 易醒 / 早醒是否每周 ≥ 3 晚、持续 ≥ 3 个月？
- **代价**：白天是否因此疲劳、分心、情绪差、效率低？

三问都「是」，才建议把「失眠」当问题认真对待——首站是看全科或睡眠专科，而非直接买安眠药。

## 5 常见误区辨析

**误区一：「一晚上没睡好就是失眠症。」** 偶尔一晚没睡好是「急性失眠」，人人都会经历，不构成疾病。达到「每周 ≥ 3 晚、持续 ≥ 3 个月」且影响白天功能，才谈得上慢性失眠障碍——别给普通失眠贴重标签。

**误区二：「睡得少就是失眠。」** 短睡眠者睡 5 小时精神奕奕，不算失眠；躺够 8 小时却只睡 5 小时、白天疲惫，才是失眠。失眠的实质是「睡眠机会与实际睡眠的鸿沟」，不是时长本身。

**误区三：「失眠就是睡不着，早醒不算。」** 早醒是失眠的常见亚型，尤其多见于老年人。比预期早醒 30 分钟以上且无法再入睡，并伴随白天功能下降，同样构成诊断。

**误区四：「失眠靠自己扛一扛就过去了。」** 短期失眠多数自愈，但慢性失眠不会「扛好」——维持因素（焦虑、过度补偿）会让它越拖越顽固。符合诊断标准就该积极干预，而非硬扛。

**误区五：「去医院查失眠就是小题大做。」** 失眠常与焦虑抑郁、睡眠呼吸暂停等共病，早评估能同时发现并处理潜在问题。就医不是「矫情」，而是对自己负责。

五条误区归结为：**用诊断标准的「症状、损害、频率病程」三要素量自己**，既不轻描淡写，也不过度恐慌。

## 6 常见问题速查：失眠的诊断

| 情境 | 快速判断 | 处置要点 |
| --- | --- | --- |
| 昨晚只睡 3 小时 | 急性失眠 | 别慌，今晚规律入睡即可 |
| 每周 3 晚入睡难、持续半年 | 慢性失眠 | 就医评估，启动 CBT-I |
| 凌晨 4 点醒后再睡不着 | 早醒型失眠 | 排查抑郁、就医 |
| 白天不困但躺下清醒 | 睡眠机会充足却睡不着 | 三问自测、必要时就医 |
| 睡前焦虑「今晚又失眠」 | 期待性焦虑 | 认知重构、CBT-I |
| 白天开车犯困 | 可能非失眠 | 排查嗜睡性疾病 |

## 7 实操清单：正确面对失眠

- 用三问自测定位：**有机会吗？症状够频吗？白天受损吗？**
- 短期失眠：不惊慌、不报复性补觉、保持固定起床。
- 符合慢性标准：优先就医 + 睡眠日志，别先买药。
- 排查「冒名者」：打鼾憋气、腿部不适、情绪低落。
- 把「我必须睡」换成「我可以放松」——放下执念是入睡的第一步。

## 8 小结

- **失眠是「有机会却睡不着」**，与「睡得少」「睡不好环境」有本质区别。
- 诊断三要素：**症状 + 日间损害 + 频率病程**（每周 ≥ 3 晚、持续 ≥ 3 月）。
- 慢性失眠影响约一成人群，是真实疾病，需要系统干预而非自责。
- 分型看**病程与成因**；诊断前必须排除呼吸暂停、不宁腿、焦虑抑郁等「冒名者」。
- 三问自测（机会 / 症状 / 代价）帮你在就医前先量清自己的情况。
