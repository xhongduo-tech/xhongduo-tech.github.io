# 睡眠科学与改善

以《睡眠革命》《Why We Sleep：我们为什么要睡觉》与《睡眠医学》为纲，系统学习睡眠分期与昼夜节律的运行规律、睡眠卫生与环境的改善方法、失眠的科学应对以及特殊情境下的睡眠质量提升。睡眠约占人生的三分之一，是记忆、情绪、免疫与代谢健康的地基，学完这些章节就掌握了改善睡眠的完整方法论。

## 对标教材

- 《睡眠革命》（尼克·利特尔黑尔斯）
- 《Why We Sleep：我们为什么要睡觉》（马修·沃克）
- 《睡眠医学》（人民卫生出版社，临床睡眠障碍教材）
