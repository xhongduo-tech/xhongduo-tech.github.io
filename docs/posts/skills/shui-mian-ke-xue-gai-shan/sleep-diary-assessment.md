## 为什么从睡眠日志开始

前几节介绍的睡眠限制、刺激控制都要求「先知道基线」——而基线来自哪里？来自**睡眠日志**。它是最廉价、最客观的自我评估工具：不需要设备，一支笔一张表，连续记录一到两周，就能算出睡眠效率、看清作息规律，也为就医提供医生最需要的数据。本节讲清日志怎么记、怎么算、怎么用。

## 1 睡眠日志：记什么、怎么记

**睡眠日志（sleep diary）**：连续记录每日睡眠关键事件的自评工具，是睡眠医学诊断与评估的基础资料。

每天起床后（而非睡前）回忆并填写，核心字段：

- **上床时间** 与 **实际入睡时间**（估算）
- **夜间醒来次数** 与 **每次醒多久**（估算）
- **最终醒来的时间** 与 **起床时间**
- **白天小睡** 的时长与时段
- **咖啡因/酒精/运动** 的摄入或发生时段
- **主观评价**：睡眠质量（1–10）、白天困倦程度

<span class="marginnote">关键技巧是「早晨填写」：睡前记录容易变成「又没睡着」的自我审查，强化焦虑；早晨填写则是对昨夜的事后复盘，客观得多。记录要诚实，不必追求精确——估算即可，重点是连续与稳定。</span>

## 2 从日志算出三个指标

日志不是拿来「写给自己看」的，而是用来算指标的：

**1. 总睡眠时间（TST）**：入睡到最终醒来的睡眠累计时长。

$$TST = \text{就寝总时长} - \text{入睡潜伏期} - \text{夜间清醒总时长}$$

**2. 入睡潜伏期（SOL）**：躺下到真正入睡的时间，健康人通常 < 30 分钟，失眠者常 > 30 分钟。

**3. 睡眠效率（SE）**：

$$SE = \frac{TST}{\text{卧床时间}} \times 100\%$$

对睡眠效率式子做三步拆解：

- **分子 TST**：实际睡着的时长，是「结果」。
- **分母卧床时间**：从上床到起床的总时长，是「投入」。
- **比值意义**：SE 越低，说明「躺在床上清醒」的时间占比越高——这正是失眠的行为画像。目标：SE > 85%，理想 > 90%。

## 3 量表的补充：不只靠日志

日志之外，还有两个临床常用的标准化工具：

- **匹兹堡睡眠质量指数（PSQI）**：19 题自评量表，从主观质量、潜伏期、时长、效率、障碍、药物、日间功能七个维度打分，是研究中最常用的睡眠质量总评工具。
- **Epworth 嗜睡量表（ESS）**：评估白天嗜睡倾向，8 个场景打分（0–3 分），用于甄别「睡不够」之外的嗜睡性疾病（如睡眠呼吸暂停、发作性睡病）。

**核心认识**：日志回答「我睡得怎么样」，PSQI 把主观感受标准化，ESS 筛查「白天困过头」的病理性问题——三者组合，基本覆盖了睡眠自我评估的主要维度。<span class="marginnote">家用穿戴设备（手表、戒指）测出的「睡眠分期」与实验室多导睡眠图相比误差不小，但它们在「趋势追踪」上仍有价值——记录起床时间、总时长的长期波动，比单夜绝对数值更可靠。详见「多导睡眠图与家用睡眠监测」一节。</span>

## 4 日志的四个用途

1. **找基线**：为睡眠限制疗法提供 TST 与 SE 的起点数据。
2. **抓规律**：连续两周的起床时间曲线，一眼看出「作息是否稳定」。
3. **筛诱因**：咖啡因、运动、饮酒与睡眠质量的对照，帮自己定位真正的破坏项。
4. **就医材料**：医生诊断失眠、评估疗效时，最需要的就是连续睡眠日志——比一句「我睡不好」有说服力得多。

**执行要点**：记录至少 **7–14 天**再下结论；「周末补觉」要在日志上标出，因为周末作息错位正是「社交时差」的证据。

## 5 常见误区辨析

**误区一：「睡眠日志要精确到分钟，记不准就放弃。」** 日志的价值在「连续与稳定」，不在「精确」。估算即可——医生要看的是一周的趋势与规律，而非单夜的准数。别被完美主义劝退。

**误区二：「睡前记录最准确。」** 恰恰相反，睡前记录会变成「又没睡着」的自我审查，强化焦虑。正确做法是**早晨醒来后**复盘昨夜，客观得多。

**误区三：「手表说深睡 2 小时，就相信它。」** 穿戴设备的睡眠分期是模型估算，与 PSG 相比误差不小。它们适合追踪「起床时间、总时长」的趋势，不适合当作诊断依据。

**误区四：「失眠就该先做 PSG 检查。」** 多数慢性失眠靠病史 + 睡眠日志即可诊断，PSG 主要用于排查呼吸暂停、肢体运动、发作性睡病等器质问题。别把昂贵检查当成失眠标配。

**误区五：「自我评估没用，反正要去看医生。」** 睡眠日志正是医生最想要的资料——连续两周的日志比一句「我睡不好」有说服力得多。它是医患沟通的「共同语言」。

五条误区归结为：**评估工具的价值在「用」，不在「准」**——连续记录、趋势判断，才是睡眠自我管理的正确姿势。

## 6 常见问题速查：睡眠日志与评估

| 情境 | 快速判断 | 处置要点 |
| --- | --- | --- |
| 想算睡眠效率 | 需 TST 与卧床时间 | 日志记一周再算 SE |
| 睡前忘了记录 | 记不准 | 改到早晨填写 |
| 手表和感觉不一致 | 穿戴设备有误差 | 以主观感受 + 趋势为准 |
| 白天总想睡 | 疑嗜睡问题 | ESS 量表筛查、就医 |
| 要去看失眠门诊 | 缺数据 | 带两周睡眠日志 |
| 想评估整体睡眠质量 | 需标准化量表 | PSQI 自评 |

## 7 实操清单：建立评估习惯

- 连续记录 7–14 天，标注周末，早晨填写。
- 每周算一次 TST、SOL、SE，观察趋势而非单夜。
- 配合 PSQI 评估主观质量、ESS 筛查白天嗜睡。
- 把穿戴设备当「趋势哨兵」，不当「诊断仪器」。
- 就医时带上日志——这是医生最需要的材料。

## 8 小结

- **睡眠日志**是最廉价客观的自评工具，关键在「早晨填写、连续记录、诚实估算」。
- 从日志可算出三个核心指标：**TST、SOL、SE**；SE > 85% 是行为改善的目标线。
- **PSQI** 标准化主观睡眠质量，**ESS** 筛查白天病理性嗜睡，二者与日志互补。
- 日志四用途：**找基线、抓规律、筛诱因、就医材料**。
- 至少记录 7–14 天，并标注周末，才能看清真实睡眠规律。
