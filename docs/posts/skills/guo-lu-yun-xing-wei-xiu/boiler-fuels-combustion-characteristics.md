## 为什么从燃料开始

上一节学会了读锅炉的型号——DZL4-1.25-AⅡ 里的「AⅡ」告诉你这台炉烧的是Ⅱ类烟煤。可「烟煤」两个字背后是什么？为什么有的煤一点就着，有的煤半天不起火？为什么同一台炉换一种燃料，司炉工就得重调一遍风门？

答案都在**燃烧特性**里。燃料是锅炉的「食物」，司炉工是「喂饭的人」。喂得对，热效率高、排放干净、设备长寿；喂得不对，燃烧不稳、结渣积灰、甚至爆燃。这一节我们把三种燃料家族和它们的「性格」认识一遍，为第2篇的配风调节打下概念基础。

## 1 三大燃料家族：煤、油、气

按形态，锅炉燃料分为三类，它们的燃烧方式截然不同：

| 燃料 | 典型代表 | 燃烧方式 | 低位发热量（约） |
| --- | --- | --- | --- |
| 固体燃料 | 褐煤、烟煤、无烟煤 | 层燃或流化床 | 11.7 ~ 32.6 MJ/kg |
| 液体燃料 | 重油、渣油、柴油 | 雾化后室燃 | 39 ~ 42 MJ/kg |
| 气体燃料 | 天然气、高炉煤气 | 与空气混合室燃 | 34 ~ 36 MJ/m³ |

<span class="marginnote">注意气体燃料的发热量单位是 MJ/m³（按体积），固体、液体燃料是 MJ/kg（按质量）。读燃料资料时单位不同、数值不能直接比较——这是考卷上最廉价的送分陷阱。</span>

三种燃料的「性格」差异可以浓缩成一句话：**煤要「铺开来烧」，油要「喷细了烧」，气要「混匀了烧」**。煤需要炉排或床层提供燃烧空间，油需要雾化喷嘴把油滴变成几十微米的细雾，气则需要与空气预先混合到爆炸极限以上、着火温度以上才敢点。

## 2 煤炭的身份证：工业分析与元素分析

评价一种煤，司炉工看两张表。

**工业分析**直接回答「烧起来怎么样」：

**水分（M）**：水分高，点火难、烟气量增大、有效热下降。
**灰分（A）**：灰分高，发热量低、积灰结渣加剧。
**挥发分（V）**：着火难易的标尺——挥发分离的煤容易着火。
- **固定碳（FC）**：燃烧的主体，发热量的主要来源。

| 煤种 | 干燥无灰基挥发分 Vdaf | 着火难易 | 典型低位发热量 |
| --- | --- | --- | --- |
| 无烟煤 | < 10% | 难着火，需高温引燃 | 25.1 ~ 32.6 MJ/kg |
| 烟煤 | 10% ~ 37% | 着火适中，工业锅炉主力 | 16.7 ~ 29.3 MJ/kg |
| 褐煤 | > 37% | 极易着火，也易自燃 | 11.7 ~ 16.7 MJ/kg |

<span class="marginnote">挥发分是把煤加热到一定温度时析出的可燃气体成分。它高，说明煤里「容易跑出来的燃料」多，点火时先烧它们；它低（如无烟煤），点火全靠把固定碳加热到足够温度，所以难。</span>

**元素分析**则回答「烧完会生成什么」：碳 C、氢 H、氧 O、氮 N、硫 S 是主要可燃与致污元素。其中**硫**最让司炉工头疼——燃烧生成 SO₂，既污染大气，又会在尾部烟道遇水汽凝结成亚硫酸，腐蚀省煤器与空气预热器，这就是**低温硫腐蚀**。灰分的**灰熔点**则决定会不会结渣：灰熔点低，灰粒在高温炉膛里就软化黏结，糊住水冷壁与炉排。

## 3 完全燃烧四要素与过量空气系数

燃料要烧透，必须同时满足四个条件：

1. **足够高的温度**：达到燃料的着火温度以上，并持续供热点火；
2. **足够的空气**：提供充分的氧气；
3. **足够的燃烧时间**：燃料与氧气有充分反应的时间；
4. **良好的混合**：燃料与空气接触均匀。

这四个条件缺一不可，而司炉工每天在操作盘上调的，主要是第二个——**空气量**。空气多了浪费热量，少了烧不透。这个「多还是少」的量化指标，就是**过量空气系数**。

## 4 公式解析：过量空气系数

**过量空气系数（α）**：实际供给的空气量与理论完全燃烧所需空气量之比。

$$\alpha = \frac{V}{V_0}$$

其中 $V$ 是实际空气量，$V_0$ 是理论空气量。但司炉工没法直接量空气体积，工程上改用**烟气中氧含量**来反推：

$$\alpha = \frac{21}{21 - O_2}$$

三步拆解：

- **第一步，记住烟气中氧的来路**：空气中氧的体积分数约为 21%。如果空气刚好够（α = 1），理论上烟气里不应有多余的氧。
- **第二步，看剩了多少氧**：烟气分析仪测出的 $O_2$（%）就是「喂多了」的空气留下的氧。氧气是 21，减去剩下的是被用掉的，用掉的 ÷ 总的 21，就是空气的「富裕程度」反推。<span class="marginnote">直觉校验：O₂ = 0 → α = 1，理论空气、分毫不剩（实际做不到）；O₂ = 5% → α = 21÷16 ≈ 1.31，约多给了三成空气。数值越大，过剩越多。</span>
**第三步，落在合理区间**：层燃炉排烟处 α 一般 1.3 ~ 1.6，燃油燃气炉可低到 1.05 ~ 1.15。α 太大，冷空气带走热量（排烟损失 q₂ 增大）；α 太小，CO 与碳粒带走的化学与机械不完全燃烧损失（q₃、q₄）增大。**最优 α 是两头损失之和最小的那个点**——第4篇《节能减排》会把这笔账算到底。

**辨析｜易错点：** 测氧点的位置影响结果。炉膛出口处的 O₂ 与排烟处的 O₂ 不一样，因为烟道各处可能漏风；调风要以**炉膛出口**的氧量为准，排烟处的氧量还要扣除漏风的影响。

## 5 燃料特性对司炉操作的连锁影响

把前面的特性串起来，你会发现每条燃料「性格」都直接连着操作动作：

**挥发分高（褐煤）**：着火快，点火与压火容易，但煤堆与粉仓易自燃——储存要通风、监测温度。
**水分大**：烟气量增大、排烟损失上升，磨煤或干燥环节负担重——雨天来煤要提前翻晒。
- **灰熔点低**：炉膛结渣，水冷壁挂渣后传热恶化、局部超温——要控制炉膛温度，勤看火、勤清焦。
- **硫分高**：尾部低温腐蚀，排烟温度不能降太低，要守住「露点」这条底线。<span class="marginnote">低温腐蚀的临界点叫「烟气露点」：SO₃ 与水汽凝结的温度，燃油锅炉可达 120–140°C。排烟温度要设计在露点之上留出余量，否则省煤器几年就烂穿。</span>

这些连锁影响告诉我们：**司炉工调的从来不是单一参数，而是一组参数的平衡**。燃料变了，风、煤、火、温度、排污、吹灰几乎都要跟着变。

## 6 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 工业分析 | 水分、灰分、挥发分、固定碳四项分析 |
| 元素分析 | 碳、氢、氧、氮、硫等元素含量 |
| 挥发分 | 加热析出的可燃气体成分 |
| 低位发热量 | 扣除水蒸气潜热后的燃料发热量 |
| 灰熔点 | 灰分开始软化的温度 |
| 着火温度 | 燃料持续燃烧所需的最低温度 |
| 低温硫腐蚀 | 烟气 SO₃ 遇水汽凝结成酸腐蚀尾部 |
| 露点 | 烟气中酸液开始凝结的温度 |
| 完全燃烧 | 温度、空气、时间、混合四条件全满足 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「发热量单位都一样」 | 气体按体积 MJ/m³，固液体按质量 MJ/kg |
| 「挥发分高就一定好」 | 着火容易但易自燃，储存要通风监测 |
| 「无烟煤最好烧」 | 挥发分低难着火，点火全靠高温引燃 |
| 「灰多只是脏」 | 灰分高发热量低、积灰结渣加剧 |
| 「硫高点无所谓」 | 生成 SO₂ 且尾部低温腐蚀，要守露点 |
| 「α 调大点保证烧透」 | α 太大量风热损失 q₂ 增大，落在合理区间 |

### 记忆口诀

- 煤铺开烧、油喷细烧、气混匀烧。
- 挥发分定着火：高易着、低难着。
- 完全燃烧四要素：温度、空气、时间、混合。
- α = 21/(21−O₂)，层燃 1.3–1.6、油气 1.05–1.15。
- 灰熔点低易结渣，硫分高守露点。

## 7 小结

- 燃料三大家族：**煤（铺开来烧）、油（喷细了烧）、气（混匀了烧）**，发热量单位各不相同。
- 工业分析四指标：**水分、灰分、挥发分、固定碳**；挥发分定着火难易。
- 元素分析关注**硫**（生成 SO₂、低温腐蚀）与**灰熔点**（决定结渣）。
- 完全燃烧四要素：**温度、空气、时间、混合**。
- **过量空气系数** $\alpha = \dfrac{21}{21 - O_2}$，层燃炉 1.3~1.6、油气炉 1.05~1.15，是配风的核心目标。

在下一节，我们把「水」请上场——锅炉结垢、腐蚀的元凶，以及水质处理与水质标准，这是保护锅炉本体寿命的第一道防线。
