## 为什么从运行监视开始

点火、升压、并汽、调负荷——这些是「动作」；但锅炉运行绝大部分时间不是在做动作，而是在**盯守**。一台锅炉要在额定工况下连续运行成百上千小时，司炉工的工作重心就从「操作」转为「监视、记录、交接」。

这一节看似平淡，却是事故预防的主战场：大多数锅炉事故都有几小时到几天的「前兆」，而前兆只存在于**连续对比的记录里**。排烟温度连着三天悄悄升高、补水率一周比一周大——这些趋势，只有认真记录、按时巡检的司炉工才看得见。<span class="marginnote">把运行记录比作锅炉的「病历」很贴切：事故发生后的调查，第一件事就是调运行记录。记录上的一行数字，可能就是救下整条证据链的那一行。</span>

## 1 巡回检查：把锅炉「走」一遍

司炉工不能只坐在仪表盘前。每班按规定路线、按固定间隔（一般 **1～2 小时**一次）巡回检查，是规程要求的硬任务。巡检路线通常覆盖：

**锅炉本体**：看火孔观察燃烧、检查人孔/手孔有无渗漏、听锅筒有无异常响声；
**安全附件**：压力表指针是否抖动正常、水位计是否真实、安全阀有无泄漏；
- **辅机**：给水泵振动与发热、风机异响、轴承温度、电机电流；
- **燃料系统**：煤斗煤量、炉排运行、油枪/燃气压力是否正常；
- **烟风系统**：烟道挡板位置、除尘器排灰、烟囱冒烟颜色。

<span class="marginnote">巡检不是「走一圈打个卡」。老师傅教徒弟的第一句话是「眼看、耳听、鼻嗅、手摸」：看渗漏、听异响、嗅焦糊味、摸轴承温度——四样感官全用上，才能揪出仪表上还没来得及反映的隐患。</span>

**辨析｜易错点：** 巡检发现的小异常（一处渗漏、一点异响），随手记在记录本上、并在交班时说明——**宁可多报一句「虚惊」，不可漏报一处真患**。不少大事故，源头就是巡检时「看着没事、没记」。

## 2 运行参数监视：八块表盯什么

正常运行中，司炉工盯着一组参数，它们共同刻画锅炉的「体温与脉搏」：

| 参数 | 正常范围（示例） | 异常含义 |
| --- | --- | --- |
| 汽压 | 额定压力附近 | 波动大 → 负荷或燃烧不稳 |
| 汽温 | 额定汽温 | 过高损设备、过低带水 |
| 水位 | 正常水位 ±50 mm | 超限 → 缺水/满水前兆 |
| 炉膛负压 | 20～30 Pa | 异常 → 燃烧或烟道问题 |
| 排烟温度 | 设计值附近 | 升高 → 积灰、受热面恶化 |
| 给水温度/压力 | 按设计 | 异常 → 给水泵或除氧器问题 |
| 烟气氧量 | 对应合理 α | 偏高费能、偏低冒黑烟 |
| 蒸发量 | 不超额定 | 超负荷 → 带水与超温风险 |

<span class="marginnote">参数之间的<strong>联动</strong>比单个参数更重要：排烟温度升高 + 氧量不变，多半是受热面积灰；氧量升高 + 负压变大，多半是烟道漏风。会读「参数组合」，才算真正会监视。</span>

## 3 运行记录：给锅炉写「病历」

规程要求锅炉运行要有连续、完整的运行记录。记录的基本项目包括：时间、汽压、汽温、水位、蒸发量、燃料量、给水量、排烟温度、炉膛负压、烟气氧量，以及排污、吹灰、加药等操作的时间和备注。

**记录频次**：运行参数一般**每小时记录一次**，排污、吹灰等操作随时记录。
**记录要求**：真实、及时、完整，不补记、不臆造。记录表就是锅炉的法定档案，要留存备查。<span class="marginnote">有的司炉工嫌麻烦，下班前「一次性补记八小时」——这是大忌：补记必然失真，失真就丢掉了事故前兆。真实记录是对自己也是对锅炉的负责。</span>
- **趋势分析**：把逐日记录画成曲线，参数**缓慢漂移**往往预示设备劣化——排烟温度逐日上升是积灰、补水率逐月上升是泄漏，这就是「记录的价值」。

## 4 公式解析：补水率

监视给水系统最有效的综合指标是**补水率**——它把蒸发、排污、泄漏三件事合成一个数：

$$\beta = \frac{G_{\text{补水}}}{D} \times 100\%$$

三步拆解：

- **第一步，认清水量平衡**：锅炉的给水量 = 蒸发量 + 排污量 + 泄漏量。于是补水量 $G_{\text{补水}}$ 中，一部分补排污、一部分补泄漏。
- **第二步，定义补水率**：$\beta$ 是补水量占蒸发量的百分比。系统越严密（泄漏少）、排污率越低，$\beta$ 越小。<span class="marginnote">直觉：补水率是系统的「失血率」。供热凝结水回水系统完善的锅炉房，补水率可以压到 5% 以下；若发现补水率悄悄爬升，先查排污有没有失控，再查管道阀门有没有漏——漏汽漏水是白花花的钱。</span>
**第三步，用趋势判断**：单日数值受工况波动影响，要看**趋势**。连续多日补水率升高而排污率不变，几乎可以断定泄漏在扩大——这时候巡检的重点就明确了。

## 5 交接班制度：责任不断线

锅炉是 24 小时不间断运行的，安全靠每一班司炉工把「接力棒」平稳传下去。交接班的核心是**「四交」**：

1. **交运行状态**：汽压、汽温、水位、负荷、燃烧工况；
2. **交操作情况**：本班做过的排污、吹灰、加药、调负荷；
3. **交检修与遗留问题**：巡检发现的渗漏、异响、仪表异常；
4. **交工具与记录**：工具齐全、记录本填写完毕。

交接时**双方共同巡检一遍**，交班人把注意事项当面讲清，接班人确认无误后签字交接。<span class="marginnote">「口头交代」不如「现场指认」：接班人不只是听你说「没问题」，而是亲眼看到水位、亲耳听到风机、亲手摸过温度——把疑点当场消化，不留到接班后的第一小时。</span>

**辨析｜易错点：** 接班时发现记录与实际不符、或设备状态异常，**有权拒绝接班**，并立即报告——硬着头皮接下一台带病的锅炉，出了事故，责任是算在接班人头上的。

## 6 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 巡回检查 | 按路线、按间隔对锅炉全面检查的制度 |
| 运行记录 | 定时记录锅炉运行参数的法定档案 |
| 补水率 | 补水量占蒸发量的百分比 |
| 交接班 | 班次之间移交运行状态与责任的制度 |
| 排污 | 排出高浓度锅水或底部泥渣的操作 |
| 吹灰 | 清除受热面积灰的操作 |
| 趋势分析 | 对比逐日记录发现参数漂移的方法 |
| 安全技术档案 | 锅炉运行、检验、维修的成套记录 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「巡检走一圈就行」 | 眼看、耳听、鼻嗅、手摸，四感全用 |
| 「记录下班前补」 | 补记必然失真，丢掉事故前兆 |
| 「单点正常就放心」 | 看趋势与参数组合，联动才见真问题 |
| 「口头交代就是交接」 | 双方共同巡检、现场指认、签字确认 |
| 「接班有问题也得接」 | 异常可拒绝接班并报告，硬接出事担责 |
| 「补水多说明锅炉能干」 | 补水率爬升多为泄漏或排污失控，要查 |

### 记忆口诀

- 巡检 1–2 小时一趟，眼看耳听鼻嗅手摸。
- 记录每小时一笔，真实及时不补记。
- 补水率 = 补水量 ÷ 蒸发量，爬升就查漏。
- 交接班四交：状态、操作、问题、工具记录。
- 参数组合读：烟温高+氧量不变 → 积灰；氧量高+负压大 → 漏风。

## 7 小结

- **巡回检查**：每 1～2 小时按路线巡检，眼看、耳听、鼻嗅、手摸。
- **八项参数**：汽压、汽温、水位、炉膛负压、排烟温度、给水、氧量、蒸发量——会读参数组合才叫会监视。
- **运行记录**：每小时记录，真实及时，是事故分析的第一手证据；**趋势比单点更重要**。
- **补水率** $\beta = \dfrac{G_{\text{补水}}}{D}$：综合反映排污与泄漏，爬升即查漏。
- **交接班「四交」**：交状态、交操作、交问题、交工具记录；异常可拒绝接班。
