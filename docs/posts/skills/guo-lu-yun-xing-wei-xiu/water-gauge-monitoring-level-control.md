## 为什么从水位开始

锅炉运行中，司炉工盯得最勤的一块表，不是压力表，而是**水位计**。因为缺水是所有锅炉事故里最凶险的一种——水冷壁一旦露出水面，几分钟内就会过热爆管，甚至引发爆炸。<span class="marginnote">行业统计里，锅炉爆炸事故中相当大比例直接或间接与缺水有关。TSG G0001 对水位计的要求是强制性的：每台蒸汽锅炉至少装两只独立的水位计，且至少一只直读式（玻璃板/玻璃管式）。</span>

这一节我们把水位这件事从原理到操作讲透：水位计靠什么原理显示水位、读数准不准、怎么冲洗校验、运行中怎么调水位，以及最危险的「假水位」怎么识别。

## 1 水位计：司炉工的第一双眼睛

**水位计（water gauge）**：利用**连通器**原理，与汽包汽空间、水空间相连的透明液位指示装置。汽包里的水位，与水位计里的液面在连通器作用下保持同一水平——司炉工透过玻璃看到的水位，就是汽包内的真实水位（近似）。

水位计玻璃上刻着**三条安全水位线**：

**最高安全水位**：运行中水位允许达到的上限；
**正常水位**：运行应维持的基准水位；
**最低安全水位**：运行中水位允许降到的最低点，低于此线即进入危险区。

**重点：正常水位一般定在汽包几何中心线以下。** 水位在最高与最低安全水位之间波动是合法的，但最优运行区间是正常水位上下约 ±50 mm。<span class="marginnote">为什么不把正常水位定在几何中心？水冷壁入口需要足够的静压差维持循环，水位过高会淹没汽水分离器、导致蒸汽带水；过低则水冷壁可能露出水面。中心线略下是两者之间的平衡点。</span>

## 2 水位计的分类与读数

常见水位计有四种，越往现代，读数越「不怕骗」：

| 类型 | 显示方式 | 特点 |
| --- | --- | --- |
| 玻璃管式 | 透明玻璃管直读 | 结构简单，小型锅炉常用 |
| 玻璃板式 | 平板玻璃直读 | 承压能力优于玻璃管 |
| 双色水位计 | 汽红水绿 | 远距离清晰可读 |
| 电接点水位计 | 电极导通点显示 | 远程监控、报警联锁 |

<span class="marginnote">双色水位计的原理很妙：利用汽、水对光的折射率不同，让光通过蒸汽呈红色、通过水呈绿色——隔着好几米也能一眼看清汽水分界。电接点水位计则把水位变成电信号，送去控制室报警。</span>

### 公式解析：玻璃水位计的密度修正

玻璃管里的水温度低、密度大，汽包里的饱和水温度高、密度小，所以**水位计显示的水位，略低于汽包真实水位**：

$$H_{\text{汽包}} = \frac{\rho_{\text{玻璃管水}}}{\rho_{\text{汽包饱和水}}} \times H_{\text{水位计}}$$

三步拆解：

- **第一步，理解连通器平衡**：两边的底部压力相等，即 $\rho_{\text{玻璃}} g H_{\text{玻璃}} = \rho_{\text{汽包}} g H_{\text{汽包}}$，$g$ 消去即得上式。
- **第二步，看密度差的方向**：水位计里的水暴露在大气中（通过放水阀端散热），温度低、密度大；汽包里是饱和水，温度高、密度小。于是 $\rho_{\text{玻璃}} > \rho_{\text{汽包}}$，比值大于 1，$H_{\text{汽包}} > H_{\text{水位计}}$。<span class="marginnote">直觉校验：冷水的密度大，同样的压力只需「更矮的水柱」就能压住，所以冷的一侧水位看起来更低。压力越高，饱和水密度越小，这个修正量越大——1.0 MPa 级锅炉可达 8% 上下。</span>
**第三步，回到操作**：正常运行时这个差值不大，但**绝不能把「水位计满水」当成「汽包满水」**。现代化的双色水位计与电接点水位计已内置密度补偿，直读玻璃管则要心中有数。

## 3 水位调节：给水控制

水位调节的本质是让**给水量 = 蒸发量 + 排污量**。给水多了水位上涨，少了水位下降，司炉工的调节动作分两种：

**间歇给水（手动）**：小型锅炉采用「补水—停泵—补水」的间断方式，每次补到正常水位稍高即停，靠锅水蓄热维持压力。
**连续给水（自动）**：大中型锅炉用给水调节阀连续补水，配合**单冲量/双冲量/三冲量调节**——三冲量同时看水位、蒸汽流量、给水流量，抗干扰能力最强。

<span class="marginnote">三冲量的直觉：只看水位（单冲量）会「反应滞后」——负荷一增，水位先因汽泡膨胀假升，等真降下来再补就晚了。加上蒸汽流量与给水流量两个「预报信号」，调节阀能提前动作。自动调节再好，司炉工仍要每班核对水位计真实性。</span>

排污与水位调节要配合：**定期排污会瞬间拉低水位**，所以排污前要确认水位偏高，排污后立即检查水位并补水——把「排污忘补水」列为交接班的重点核查项。

## 4 假水位：最会骗人的水位

**假水位（false water level）**：水位计显示的水位与汽包实际存水量不一致的现象。它不骗眼睛，骗判断。最典型的场景是**负荷骤增**：

1. 用汽量突然增大 → 汽包压力下降；
2. 压力下降 → 水面下过热水剧烈闪蒸，汽泡大量膨胀；
3. 汽泡撑起水面 → **水位瞬时假升**；
4. 假升误导 → 若司炉工关小给水，等汽泡消失，真实水位暴跌，瞬间缺水。

**处理原则一句话：假水位上升时，非但不能关小给水，反而要加大给水。**<span class="marginnote">判断假水位的辅助信号：假升的同时汽压下降、蒸汽流量上升；真满水则汽压不降反升、蒸汽带水、温度表骤降。把压力、流量、温度三块表与水位计对起来看，就能拆穿假象。</span>

## 5 水位计的冲洗与检查

水位计用久了，汽水通路可能被水垢、油污堵塞，显示失真。所以每班至少冲洗一次，这是考试必考的规定动作：

1. **关水阀**：切断水位计与水空间的通路；
2. **开汽阀、开放水阀**：让蒸汽从汽侧吹扫玻璃管（冲汽路）；
3. **关汽阀、开水阀**：让水从水侧冲洗（冲水路）；
4. **关放水阀**：观察水位恢复情况——先快速上升、再缓慢下降至正常，说明通路畅通、显示真实。

**辨析｜易错点：** 冲洗的顺序与阀门状态错了，会把蒸汽吹进水管、把水挤进汽管，制造新的假水位。冲洗后水位迟迟不恢复，说明通路仍堵，必须处理。若两台水位计的读数长期不一致，也要立即查明——**「两个水位计打架」本身就是重大隐患信号**。

## 6 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 连通器 | 两端液面保持同一水平的容器组合 |
| 正常水位 | 汽包中心线略下、运行应维持的水位 |
| 最高安全水位 | 运行允许达到的水位上限 |
| 最低安全水位 | 运行允许降到的最低点 |
| 假水位 | 显示水位与实际存水量不一致 |
| 叫水法 | 判断锅炉缺水程度的方法 |
| 双色水位计 | 汽红水绿、远距离可读的水位计 |
| 三冲量调节 | 看水位、蒸汽流量、给水流量联合调节 |
| 密度修正 | 因水位计水温低密度大而对读数的校正 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「水位计满水就是汽包满水」 | 玻璃水冷密度大，读数略低于汽包真实水位 |
| 「假水位上升就关小给水」 | 负荷骤增的假升要加大给水，不是关小 |
| 「两个水位计读数不同没关系」 | 读数长期打架是重大隐患信号，必须查明 |
| 「水位计冲洗顺序随便来」 | 关水阀—开汽阀—关汽阀—开水阀，错序出假水位 |
| 「水位越高越好」 | 过高淹没汽水分离器，蒸汽带水 |
| 「排污不用看水位」 | 排污前查水位、排污后补水位，防拉低水位 |

### 记忆口诀

- 水位三线：最高、正常、最低，正常在中心线略下。
- 密度修正：玻璃水冷读数低，H 汽包 = ρ比 × H 水位计。
- 假水位看组合：假升伴汽压降、蒸汽流量升。
- 冲洗水位计：关水—开汽—关汽—开水，一步不差。
- 排污前后盯水位，勤排快排防缺水。

## 7 小结

- 水位计靠**连通器**显示汽包水位，蒸汽锅炉至少装**两只**独立水位计。
- 三条水位线：**最高、正常、最低安全水位**；正常水位在汽包中心线以下，运行区间为正常水位 ±50 mm 上下。
- 水位计读数有**密度修正**：$H_{\text{汽包}} = \dfrac{\rho_{\text{玻璃}}}{\rho_{\text{汽包}}} H_{\text{水位计}}$，高压锅炉修正量更大。
- 水位调节 = 给水量匹配蒸发量 + 排污量；**排污前查水位、排污后补水位**。
- **假水位**：负荷骤增时水位先假升后真降，此时要**加大给水**而非关小。
- 每班**冲洗水位计**一次，按「关水阀—开汽阀—关汽阀—开水阀」顺序执行。
