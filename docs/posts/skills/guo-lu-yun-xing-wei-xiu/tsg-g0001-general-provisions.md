## 为什么从总则开始

上一节讲了司炉工要持证，证照的法律依据之一正是这一节的主角——**TSG G0001《锅炉安全技术监察规程》**。如果说《特种设备安全法》是锅炉安全的「宪法」，那么 TSG G0001 就是它的「实施细则」：它把一台锅炉从图纸到报废的每一个环节都纳入监管轨道。

作为司炉工，你不必背下整部规程，但必须读懂它的**总则**——弄清楚这部规程管什么、不管什么、每个环节谁负责、使用单位扛着哪些义务。<span class="marginnote">TSG 是「特种设备安全技术规范」的拼音缩写（Tezhong Shebei Guifan 之类），G0001 是编号。它是我国特种设备领域特有的技术法规层级，介于法律与技术标准之间，具有强制执行力。</span>

## 1 总则讲什么：一部锅炉的「根本大法」

规程总则（第1章）首先交代了三件事：**立法目的、适用范围、监管体制**。

**目的**：加强锅炉安全监察，防止和减少锅炉事故，保障人身和财产安全。开宗明义一句话——规程不是为了管人，是为了保命。
**依据**：以《特种设备安全法》等法律法规为上位依据，属于强制性的安全技术规范。
- **体制**：国家对锅炉实行安全监察制度，覆盖设计、制造、安装、改造、修理、使用、检验检测全链条。<span class="marginnote">把「全链条」三个字圈出来：锅炉不是「买来就能用」的普通设备，而是从图纸阶段就要接受审查的监管对象。设计不合格的锅炉，根本没机会进锅炉房。</span>

总则还确立了一条总原则：**使用单位是锅炉安全的责任主体**。监管部门的角色是「监察」，真正日复一日对安全负责的，是锅炉所在的单位，以及单位里持证的司炉工本人。

## 2 适用范围：哪些锅炉归它管

规程不是所有「能烧水的东西」都管。划界标准是**承压**与**规模**两个维度：

| 设备类型 | 适用范围（达到以下条件即受监管） |
| --- | --- |
| 承压蒸汽锅炉 | 设计正常水位水容积 ≥ 30 L，且额定蒸汽压力 ≥ 0.1 MPa |
| 承压热水锅炉 | 额定出水压力 ≥ 0.1 MPa，且额定功率 ≥ 0.1 MW |
| 有机热载体锅炉 | 额定功率或工作参数达到规定门槛的液相/气相导热油炉 |

以下情况则**不适用**本规程：设计水容积小于 30 L 的小型蒸汽锅炉、常压热水锅炉，以及军事装备、核设施、铁路机车、船舶等有专门法规管辖的锅炉。<span class="marginnote">30 L 和 0.1 MPa 两道门槛把「玩具」与「设备」分开：家用蒸汽发生器、小型常压开水炉不在此列，但凡是进入工业、商用领域的承压锅炉，几乎都在监管网内。</span>

**重点：判断一台锅炉受不受监管，先看它「承不承压」，再看它「够不够大」。** 常压热水锅炉虽然也叫锅炉，但因不承压、能量低，安全风险模型不同，被划出本规程——这提醒我们，司炉工面对的「承压设备」和家用「热水器」在安全上完全不是一个量级。

## 3 各环节的责任链条

规程把锅炉的「一生」拆成七个监管节点，每个节点都有明确责任主体：

| 环节 | 主要监管要求 | 责任主体 |
| --- | --- | --- |
| **设计** | 设计文件须经鉴定，总图与强度计算符合规范 | 设计单位 |
| **制造** | 制造须取得许可，按鉴定过的图纸生产、监检 | 制造单位 |
| **安装** | 安装前告知，安装过程受监检 | 安装单位 |
| **改造/修理** | 涉及强度、安全附件的改造修理需许可与监检 | 改造/修理单位 |
| **使用** | 使用登记、持证操作、定期检验、日常维护 | 使用单位 |
| **检验** | 制造监检与在用定期检验 | 检验机构 |

<span class="marginnote">司炉工天天打交道的「使用」环节只是链条的一环，但它是时间最长、出事故最多的一环。规程对使用环节的要求最细——从安全管理制度、持证人员配备，到运行记录、应急预案，一条都不能少。</span>

## 4 使用单位的法定义务

对司炉工来说，总则最实用的部分是使用单位的义务清单——因为这些义务最终都会落到你的日常工作里：

1. **办理使用登记**：锅炉投入使用前，向所在地市场监管部门登记，取得使用登记证。
2. **建立安全管理制度**：岗位责任、操作规程、巡检制度、交接班制度等成文上墙。
3. **配备持证人员**：司炉工（G1/G2）、水处理工（G3）按要求持证，且人数与设备匹配。
4. **定期检验**：按检验周期申报外部检验、内部检验、水压试验（详见第4篇《定期检验》一节）。
5. **建立安全技术档案**：登记证、出厂资料、检验报告、运行记录、维修与事故记录，一炉一档。
6. **制定应急预案并演练**：针对缺水、爆管、超压等典型事故有处置预案，司炉工要熟悉。
7. **保障安全附件完好**：压力表、安全阀、水位计、报警联锁随时可用，失效即停用。<span class="marginnote">「安全附件失效即停用」是硬规矩：压力表、安全阀、水位计三者哪怕只有一件失灵，锅炉都不得继续运行——这正是第2篇《压力表、安全阀与温度仪表监控》的操作依据。</span>

**辨析｜易错点：** 使用登记 ≠ 定期检验。登记是「上户口」，一次办理；检验是「体检」，按期反复。很多单位办了登记就以为万事大吉，结果漏检超期，被责令停用——司炉工要盯住本炉的检验有效期。

## 5 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| TSG G0001 | 锅炉安全技术监察规程的编号 |
| 特种设备安全技术规范 | 介于法律与技术标准之间的强制性规范 |
| 水容积 | 锅炉正常水位以下的汽水容积 |
| 承压锅炉 | 承受高于大气压压力的锅炉 |
| 使用登记 | 锅炉投用前向市场监管部门办理的登记 |
| 安全技术档案 | 锅炉登记、检验、运行、维修的成套档案 |
| 监检 | 制造、安装过程中的监督检验 |
| 责任主体 | 对锅炉安全负主要责任的单位或个人 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「规程是给检验机构看的」 | 使用单位与司炉工是主要执行者 |
| 「常压热水锅炉也归 G0001」 | 常压不承压，划出本规程适用范围 |
| 「办了登记就万事大吉」 | 登记一次办理，检验按期反复，两者不同 |
| 「小锅炉随便造随便用」 | 设计、制造、安装全链条都要监管 |
| 「安全附件坏了修好再用」 | 附件失灵即停用，是硬规矩 |
| 「规程数字随便背个大概」 | 以现行 TSG G0001 原文为准，考试查表是基本功 |

### 记忆口诀

- 法规→规程→标准，三层管到底。
- 承压 + 规模两道线：30 L、0.1 MPa 划边界。
- 七环节：设计、制造、安装、改造、修理、使用、检验。
- 使用单位七义务：登记、制度、持证、检验、档案、预案、附件。
- 附件失灵即停用，红线不能碰。
- 使用登记一次办，定期检验反复查。
- 档案一炉一档，运行记录天天留。

## 6 小结

- TSG G0001 是锅炉安全的**技术法规**，依据《特种设备安全法》，覆盖全链条。
- 适用范围看**承压 + 规模**：承压蒸汽锅炉（水容积 ≥ 30 L 且压力 ≥ 0.1 MPa）等三类受监管；常压、小容积锅炉不适用。
- 七个环节：**设计、制造、安装、改造、修理、使用、检验**，各有责任主体。
- **使用单位是安全责任主体**，扛着登记、制度、持证、检验、档案、预案、安全附件七项义务。
- 司炉工的日常操作，本质上是把总则的义务逐条「落成动作」。
