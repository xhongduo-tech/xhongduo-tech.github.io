## 为什么从停炉开始

点火升压是「唤醒」锅炉，停炉则是「让它体面地休息」。很多司炉工把精力放在点火与运行上，对停炉掉以轻心——结果恰恰相反：**停炉操作不当造成的设备损伤，一点不比运行期少。**<span class="marginnote">急停猛放水、熄火后不监护、压火失守——这些「停炉事故」的根源都是同一个：忘了锅炉是厚厚的金属壳，温度骤变会把它撕开。停炉和点火一样，核心纪律是「慢」。</span>

这一节讲两种「停」：**正常停炉**（锅炉要退出运行检修或长期停用）与**压火**（短时休息、保持热备用）。两种场景的操作逻辑完全不同，先分清再用。

## 1 正常停炉：让锅炉「体面谢幕」

**正常停炉（normal shutdown）**：按计划将锅炉从运行状态平稳过渡到停用状态的过程。它适用于计划检修、季节结束或长期停用。核心原则只有一条：**让炉膛和锅筒均匀、缓慢地冷却**——这与点火升压「缓慢升温」是同一个热应力道理的两面。

正常停炉的步骤大致如下：

1. **先减负荷**：通知用汽部门，逐步降低负荷，按「减煤先于减风」的顺序把燃烧减弱。
2. **停止供燃料**：停止给煤（油、气），但保持通风，让炉排上剩余燃料燃尽。<span class="marginnote">链条炉排要等炉排走完、把剩余煤全部烧成灰渣排出；燃气炉要先关燃料阀，再用风机吹扫炉膛。让「肚子里的饭吃完再下桌」，是防止停炉后炉膛存留可燃物自燃、爆燃的关键。</span>
3. **停止送风、关小引风**：燃料燃尽后停送风，关小引风挡板，封住炉门。
4. **关闭主汽阀解列**：锅炉与蒸汽母管解列，汽压开始自然下降。
5. **维持水位**：停炉后锅水仍会缓慢蒸发凝结，要继续维持正常水位，必要时补水——**停炉不等于不用管水**。
6. **自然冷却、缓放水**：停炉后禁止急于放水；待炉水自然冷却到 **70°C 以下**（或规定温度）再排水。

## 2 停炉后的监护与放水

锅炉熄火后，操作并没有结束，而是转入「冷却监护」阶段：

**继续盯压力表**：锅炉虽停火，但压力不会立刻归零。若压力回升（余热加热），还要留意安全阀是否误动。
**防止「真空」**：炉水冷却收缩、蒸汽凝结，锅内可能形成负压，把空气或水从缝隙吸入。检修需要放水时，要打开大气阀或放空阀平衡压力。<span class="marginnote">停炉后锅筒出现「呼噜」声或轻微瘪陷，往往是真空所致。规范的停炉流程要求在适当节点开启放空阀，让内外压力平衡——这个细节最容易在慌乱中被漏掉。</span>
**缓放水**：炉水温度降到 70°C 以下才能放水；放水后如需入炉检修，要通风冷却到人体可进入的温度，并办理检修手续。

**辨析｜易错点：** 「停炉后立刻放水」是禁忌——高温炉水突然放掉，炽热的金属壁瞬间暴露，壁温骤变产生巨大热应力，轻则变形、重则裂纹。停炉冷却宁慢勿快，是写在规程里的硬要求。

## 3 压火：让锅炉「打个盹」

**压火（banking the fire）**：锅炉短时停止供汽、炉内保留余火、处于随时可恢复的热备用状态。它适用于几小时到一两天的临时停炉（如夜间低负荷、短暂检修），既避免频繁启停的损耗，又能在需要时快速恢复供汽。

压火的操作要点因炉型而异：

**链条炉排**：停止炉排与给煤，把火床推至炉排中后部，关闭风室挡板，留少量引风维持阴燃。
- **手烧炉**：把燃煤集中压实，覆盖一层灰渣或湿煤末，封闭炉门，控制空气进入。
- **燃油燃气炉**：直接停燃料停火即可（无法「压火」，只能靠保温），再次启动需重新吹扫点火。

压火期间，司炉工不能走远：**水位照常维持、压力照常监视**，火床的阴燃状态要定期查看。<span class="marginnote">压火的精妙在于「留一口气」：空气给多了，火彻底烧完变冷；给少了，压得过死、重新引燃费劲。火床状态、风门开度都要恰到好处，这是停炉操作里最考手艺的部分。</span>

## 4 正常停炉与压火：一张表分清

这是本节的核心对比表——两种「停」的操作与目的完全不同：

| 对比项 | 正常停炉 | 压火（封火） |
| --- | --- | --- |
| 适用场景 | 长期停用、检修、季节结束 | 短时停炉、热备用 |
| 炉内状态 | 全部熄火、无余火 | 保留余火、阴燃 |
| 主汽阀 | 关闭并解列 | 关闭，但保持随时可恢复 |
| 水位处理 | 维持正常水位，缓冷后放水 | 持续维持，不能断水 |
| 恢复时间 | 需要重新点火升压，以小时计 | 通风加火即可，以分钟计 |
| 主要风险 | 急冷热应力、真空损坏 | 火床失控、压火过死 |

**重点：选哪种「停」，取决于「停多久」与「要不要热备用」。** 超过一两天，压火既费煤又危险，应正常停炉；只停几小时且很快要恢复，压火省时省煤。

## 5 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 正常停炉 | 按计划将锅炉平稳过渡到停用状态 |
| 压火（封火） | 短时停炉保留余火的热备用操作 |
| 解列 | 关闭主汽阀使锅炉与蒸汽母管脱离 |
| 暖管 | 用少量蒸汽缓慢预热蒸汽管道防汽水冲击 |
| 热应力 | 金属受热不均产生的内应力 |
| 真空 | 停炉后锅水冷却收缩形成的负压 |
| 热备用 | 随时可快速恢复供汽的停用状态 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「停炉后立刻放水」 | 高温炉水放掉使金属骤冷，必须冷到 70°C 以下 |
| 「停火就没事了」 | 停炉后仍要监护压力、防真空、维持水位 |
| 「压火就是熄火」 | 压火保留余火，恢复以分钟计；熄火恢复以小时计 |
| 「急停等于正常停炉加快」 | 急停是事故处置，正常停炉是计划操作，目的不同 |
| 「停炉后水位不用管」 | 锅水仍蒸发凝结，需继续维持正常水位 |
| 「随便选停炉方式」 | 看停多久：短时压火、长时正常停炉 |
| 「压火期间可以离岗」 | 火床阴燃要定期查看，水位压力照常监视 |
| 「停炉后汽压马上归零」 | 余热会使压力回升，仍要监护安全阀 |

### 记忆口诀

- 正常停炉六步走：减负荷、停燃料、停风、解列、保水、缓放水。
- 停炉戒急：急冷如急热，都是热应力。
- 炉水 70°C 以下才放水，防真空先开放空阀。
- 压火留一口气：风门开度恰到好处，火床不灭不燥。
- 长短定法：数小时用压火，一两天以上正常停炉。
- 停炉后看压力，回升就留意安全阀。
- 压火像留火种：风门开度定生死。
- 检修要进锅，先通风冷却再办手续。
- 停炉记录别忘写，时间原因都要记。

## 6 小结

- **正常停炉**六步：减负荷 → 停燃料 → 停风封炉 → 关主汽阀解列 → 维持水位 → 缓冷后放水。
- 停炉后仍要**监护压力、防真空**；炉水 **70°C 以下**才可放水，严禁急停猛放。
- **压火**是短时热备用：保留余火、维持水位、监视压力，恢复以分钟计。
- 核心对比：正常停炉全熄火、以小时计恢复；压火留余火、以分钟计恢复。
- 停炉与点火同守一条纪律：**慢**——急冷与急热一样伤人。

在下一节，我们把「慢停」与「急停」对照起来——紧急停炉的条件与操作，看哪些险情出现时必须当机立断、壮士断腕。
