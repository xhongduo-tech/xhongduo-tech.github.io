## 为什么从停炉保养开始

上一节讲三害时提过一句话：**停炉期间的腐蚀，比运行期更凶。** 这不是夸张——运行中的锅炉，水是除过氧的热水、金属温度高、表面干燥；而停炉后的锅炉，水凉了、空气进去了、金属表面又湿又冷，正是氧腐蚀最爱的环境。一台运行十年的锅炉可能完好，若每年停炉几个月不保养，反而先烂穿。<span class="marginnote">停炉腐蚀的原理：潮湿的金属表面 + 空气中的氧 + 残留的水膜，就是一个天然的电解池。锅炉停用越久、密封越差，腐蚀越深——所以「停炉」之后紧跟着的动作必须是「保养」。</span>

**停炉保养（layup preservation）**：在锅炉停用期间采取防腐措施，防止受热面金属腐蚀的方法。选择哪种保养方法，只看一个依据——**停多久**。

## 1 停炉保养的基本思路

无论干法还是湿法，保养的根本思路是**切断腐蚀三要素**：金属、水（湿气）、氧。要么把水抽干让金属保持干燥（干法），要么把水充满让空气进不去（湿法），本质都是「不给氧腐蚀留可乘之机」。

保养前有一个共同的准备动作：**锅炉要先清干净**——放掉炉水、清除水垢与灰渣、擦拭受热面。带着水垢和灰渣保养，等于把腐蚀的「土壤」留在锅里。

## 2 干法保养：长期停炉的「干燥箱」

**干法保养（dry layup）**：把锅炉内部彻底干燥后，用干燥剂吸走残余水分，使金属保持干燥状态的保养方法。适用于**长期停炉**（一般 1 个月以上）。

操作要点：

1. **放水清垢**：停炉冷却后放净炉水，打开人孔、手孔，清除水垢、泥渣与积灰。
2. **烘干**：用微火或热风将锅炉内壁烘干——这一步很关键，残留水膜是干法保养的天敌。
3. **放置干燥剂**：将生石灰（$\ce{CaO}$）或氯化钙（$\ce{CaCl2}$）装入**布袋**，按每立方米容积约 2～3 kg 的用量，分别放入汽包与集箱。<span class="marginnote">干燥剂必须用布袋装好、悬挂或垫高放置，绝不能直接撒在金属表面上——生石灰吸水后发热膨胀，接触金属会造成局部损伤，也污染内壁。放完干燥剂后封紧人孔、手孔。</span>
4. **定期检查**：每 1～2 个月检查一次干燥剂，发现吸潮结块变软即更换；同时检查人孔手孔密封是否良好。

**适用范围**：停炉时间长的设备，以及北方冬季停运的采暖锅炉。

## 3 湿法保养：短期停炉的「密封舱」

**湿法保养（wet layup）**：把锅炉充满加药的水，用碱液保护金属、用满水隔绝空气的保养方法。适用于**短期停炉**（一般 1 个月以内）与热备用锅炉。

操作要点：

1. **加药满水**：停炉后向锅炉内注入加碱的水（常用氢氧化钠、磷酸三钠），使锅水 pH 值保持在 **10 以上**的碱性范围，抑制腐蚀。<span class="marginnote">碱性水会在金属表面形成一层钝化保护膜，把氧腐蚀挡在外面——这就是「加碱」的意义。pH 低于 10，保护膜不稳；pH 过高，又可能引发碱腐蚀，所以定在 10～12 的窗口里。</span>
2. **排尽空气**：注水要**充满到顶**，从高处排气阀把空气彻底赶走——只要留一个气泡，那个位置就是腐蚀的起点。
3. **密封**：关闭所有阀门，保持系统密闭。
4. **定期检查**：每周检查一次水位与碱度，补水补碱；发现水位下降说明有泄漏，要查明。

**冬季特别提醒**：湿法保养的锅炉在严寒地区要**防冻**——水结冰体积膨胀，会把受热面冻裂。无供暖条件的锅炉房，冬季宁可选干法保养。

## 4 干法 vs 湿法：一张表分清

| 对比项 | 干法保养 | 湿法保养 |
| --- | --- | --- |
| 适用时长 | 长期停炉（1 个月以上） | 短期停炉（1 个月以内） |
| 原理 | 干燥 + 干燥剂吸湿 | 满水 + 碱性保护膜 |
| 锅内状态 | 无水、干燥 | 充满加碱水、无空气 |
| 主要操作 | 放水烘干、放干燥剂、密封 | 加碱满水、排空空气、密封 |
| 检查周期 | 1～2 个月查干燥剂 | 每周查水位与碱度 |
| 主要风险 | 密封不严、干燥剂失效 | 泄漏失水、冬季冻裂 |
| 恢复运行 | 取出干燥剂、冲洗、烘干后上水 | 排污冲洗、置换合格后上水 |

**重点：保养方法选错，等于白保养。** 短停用湿法，长期停用还泡着水，就是让锅炉在药水里泡几个月——碱度会流失、水质会恶化；长停却只放水不烘干，锅筒里留着一层潮气，照样锈。**先定停多久，再定用什么法。**

### 记忆口诀

- 停炉三害防腐蚀，切断水汽与氧气。
- 干法：放水烘干放药袋；湿法：加碱满水排空气。
- 长停干、短停湿，冬季湿法要防冻。
- 干燥剂布袋装，查潮勤换记心上。
- 恢复前：干法冲洗、湿法置换，合格再点火。
- 保养前先清垢除灰，带着脏垢保养白搭。
- 干燥剂查潮勤换，人孔手孔密封别漏气。
- 湿法查水位查碱度，补水补碱防泄漏。
- 停炉保养做得好，重启锅炉少烦恼。

## 6 小结

- **停炉腐蚀比运行期更严重**——潮湿金属 + 空气 = 天然电解池，保养就是切断这个组合。
- 保养思路：**切断金属、水、氧三要素**；事前先清垢除灰、放净炉水。
- **干法保养**：放水烘干 + 布袋装干燥剂（生石灰/氯化钙）密封，适用长期停炉，定期换干燥剂。
- **湿法保养**：加碱满水（pH 10～12）+ 排尽空气密封，适用短期停炉，定期查水位碱度，冬季防冻。
- **先定停炉时长，再选保养方法**；恢复运行前按规程冲洗置换。
