## 为什么从辅机开始

前几节把目光全放在锅炉本体上：锅筒、水冷壁、安全附件、事故处理。但一台锅炉真正运转起来，离不开一群「幕后帮手」——**给水泵**送水、**鼓风机引风机**送风抽烟、**除尘器**收灰、**除氧器**除氧、**输煤出渣系统**喂料清渣。它们不直接承压产汽，但任何一台辅机掉链子，锅炉都得跟着停。<span class="marginnote">运行记录里最常见的停机原因，不是本体故障，而是辅机故障：给水泵汽蚀打不上水、引风机轴承烧毁、布袋除尘器堵了——本体完好，辅机先倒。所以司炉工不只烧炉，还得会养辅机。</span>

这一节按「先泵后风再除尘」的顺序，把主要辅机的维护要点过一遍，最后收拢成几条通用纪律。

## 1 锅炉的「帮手们」

| 辅机 | 职责 | 典型失效 | 维护要点 |
| --- | --- | --- | --- |
| 给水泵 | 向锅炉补水 | 汽蚀、轴承磨损 | 查进口水位、盘车、润滑 |
| 鼓风机/引风机 | 送风、抽烟 | 叶轮积灰、振动、烧轴承 | 清灰、润滑、查振动 |
| 除尘器 | 捕集飞灰 | 布袋破损、堵灰 | 定期排灰、查差压 |
| 除氧器 | 除去给水溶解氧 | 除氧效果差 | 控水温、查排汽 |
| 输煤/出渣系统 | 供煤、清渣 | 皮带跑偏、卡渣 | 巡检查偏、清卡 |

<span class="marginnote">记辅机的窍门是「顺流程记」：给水侧（除氧器→给水泵）→ 燃料侧（输煤系统）→ 风烟侧（鼓风机→引风机）→ 环保侧（除尘器）→ 出渣侧。一条流程走下来，谁在哪个位置、干什么、容易坏在哪，一目了然。</span>

## 2 给水泵：锅炉的「心脏泵」

给水泵是辅机里的头号角色——它一停，锅炉立刻面临缺水风险。工业锅炉多用**离心泵**。

维护重点是**防汽蚀**。**汽蚀（cavitation）**：泵进口压力低于水温对应的饱和蒸汽压时，水在泵内汽化形成气泡，气泡随水流到高压区瞬间溃灭，像无数把小锤敲击叶轮，发出噼啪声、引起振动，长期下来叶轮表面被「啃」得坑坑洼洼。<span class="marginnote">汽蚀的声音很有辨识度：像锅里炒豆子，噼里啪啦。听到这种声音，先看进水：进口水位够不够、滤网堵没堵、水温有没有异常升高——汽蚀是「进口条件差」的信号，不是泵本身娇气。</span>

给水泵的日常维护：

- **查进水**：除氧水箱水位充足、进口滤网干净、进水管路无漏气；
- **盘车**：启动前盘车检查是否卡涩，长期停用的泵每周盘动一次；
- **润滑与密封**：轴承按时加注润滑油，填料密封定期检查渗漏；
- **备泵倒换**：有备用泵的，定期轮换运行，避免「备而不用、用时即坏」。

## 3 公式解析：离心泵的轴功率

看给水泵铭牌或算电耗，要会读轴功率：

$$N = \frac{\rho\,g\,Q\,H}{\eta}$$

三步拆解：

- **第一步，认符号**：$N$ 是轴功率（W），$\rho$ 是水的密度（kg/m³），$g$ 是重力加速度，$Q$ 是流量（m³/s），$H$ 是扬程（m），$\eta$ 是泵效率。
- **第二步，代数量感受量级**：一台流量 50 m³/h、扬程 100 m 的给水泵，取 $\eta = 0.7$：$Q = 50/3600 \approx 0.0139\ \text{m}^3/\text{s}$，$N = 1000 \times 9.81 \times 0.0139 \times 100 / 0.7 \approx 19.5\ \text{kW}$。<span class="marginnote">量级感受：泵的耗电跟「流量 × 扬程」成正比。所以用关小阀门来调节流量，是把扬程白白浪费在阀门上——电照花、水没多送。变频调速才是省电的正路，这也是《节能减排》一节要展开的账。</span>
**第三步，看维护含义**：流量或扬程上升、效率下降，都会让轴功率增大。运行中泵电流异常升高，先查是不是出口阀门开过头、或叶轮磨损导致效率下降。

## 4 风机、除尘器与除氧器

**鼓风机与引风机**：鼓风机把空气送进炉膛，引风机把烟气抽出烟囱。维护核心是**叶轮清灰**（烟气含灰会糊叶轮，破坏动平衡引起振动）与**轴承润滑**。风机振动加剧、电流波动，先停机检查叶轮积灰与地脚螺栓。<span class="marginnote">引风机是锅炉房里最「脏」的转动设备——它直接抽带灰的烟气。叶轮积灰不均，一转起来就是一场「抖动舞」，久了连轴都抖弯。定期清灰、测振动，是引风机保养的看家功。</span>
**除尘器**：旋风除尘器看灰斗排灰是否顺畅；布袋除尘器看进出口差压——差压过高说明布袋堵了，需清灰或更换。除尘器失效不仅污染排放，还会让飞灰磨蚀引风机叶轮。
**除氧器**：热力除氧靠把水加热到接近沸点赶走溶解氧。维护重点是控好水温与排汽量——水温不足，除氧不彻底，给水溶解氧超标，氧腐蚀就找上门（呼应第7章三害）。

## 5 通用维护纪律

辅机五花八门，维护纪律却有几条是通用的：

1. **按期润滑**：建立润滑台账，轴承、减速机按周期加换油；
2. **定期倒换**：备用设备轮换运行，保证「备而能用」；
3. **巡检查振查温**：振动、温度、电流、异响，四样巡检必查；
4. **检修留档**：每次检修记录故障现象、处理措施与更换备件，积累设备「病历」；
5. **安全第一**：辅机检修**必须断电、挂牌、上锁**（LOTO），防止误启动伤人。<span class="marginnote">给水泵、风机检修时「挂检修牌、断电源」是保命动作：正在盘车的泵被人启动，手指可能瞬间绞进去。司炉工与检修工的配合，第一规矩就是「谁挂牌、谁摘牌，摘牌前先确认人已撤」。</span>

**辨析｜易错点：** 辅机小毛病要当大问题看。皮带跑偏不及时调，可能断带停产；布袋破损不换，环保数据超标罚款——辅机维护的本质是「把小事做在平时，大事才不会发生」。

## 6 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 辅机 | 给水泵、风机、除尘器等锅炉配套设备 |
| 离心泵 | 靠叶轮离心力输送液体的泵，给水常用 |
| 汽蚀 | 泵内液体汽化、气泡溃灭冲击叶轮 |
| 扬程 | 泵能把水提升的高度（m） |
| 轴功率 | 泵轴上实际消耗的功率 |
| 鼓风机 | 向炉膛输送助燃空气 |
| 引风机 | 从烟囱抽出烟气的风机 |
| 除尘器 | 捕集烟气中飞灰的环保设备 |
| 除氧器 | 加热给水除去溶解氧的设备 |
| 盘车 | 启动前手动转动泵轴检查有无卡涩 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「泵响就是泵坏了」 | 汽蚀响是进口条件差，先查水位滤网水温 |
| 「备用泵放着不用最好」 | 定期倒换，备而不用、用时即坏 |
| 「关小阀门调流量省电」 | 阀门调节浪费扬程，变频调速才省电 |
| 「引风机脏点没事」 | 叶轮积灰不匀破坏动平衡，振动毁轴 |
| 「检修时挂个牌意思一下」 | 断电、挂牌、上锁是保命动作，缺一不可 |
| 「除氧水温差不多就行」 | 水温不足除氧不彻底，溶解氧超标腐蚀 |

### 记忆口诀

- 辅机顺流程记：除氧→泵→输煤→鼓风→引风→除尘→出渣。
- 泵响查进水：水位、滤网、水温三件套。
- 引风机最脏，叶轮清灰测振动。
- 通用五纪律：润滑、倒换、查振温、留档、断电挂牌。
- 变频省电、关阀费电，泵的耗电看流量乘扬程。

## 7 小结

- 辅机按流程记：**给水侧（除氧器→给水泵）→ 燃料侧 → 风烟侧 → 除尘侧 → 出渣侧**。
- **给水泵**防**汽蚀**：查进口水位、滤网、水温，听到「炒豆声」先查进水；备泵定期倒换。
- **离心泵轴功率** $N = \dfrac{\rho g QH}{\eta}$：耗电随「流量 × 扬程」上升，变频调速优于关阀调节。
- **风机**清叶轮积灰、查轴承；**除尘器**看差压排灰；**除氧器**控水温保除氧。
- 通用纪律：**润滑、倒换、查振查温、检修留档、断电挂牌**。
