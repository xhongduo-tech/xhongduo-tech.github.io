# 锅炉定期检验与安全阀校验

<div class="epigraph">
<p>锅炉不是买了就用一辈子的东西——它是要定期「体检」的活设备，体检单上写着的，是每台炉的命。</p>

## 为什么从定期检验开始

《规程总则》一节里，我们提过使用单位要「按检验周期申报检验」。这一节把它落实：锅炉到底多久检一次、每次检什么、水压试验怎么做、安全阀怎么校验。这些不是「上面的事」——**司炉工是检验的第一配合人**：检验要停炉、要清灰、要提供运行记录、要配合试压，检验中发现的问题，往往也先落到司炉工头上。<span class="marginnote">换个角度看，定期检验是司炉工难得的「透视机会」：运行时看不见的水冷壁内壁、测不出真值的壁厚、判断不了的缺陷，停炉检验一次全暴露。懂检验的司炉工，能借着检验报告把锅炉「看懂一半」。</span>

## 1 为什么要定期检验

锅炉在高温、高压、腐蚀、磨损的联合作用下运行，隐患是**动态积累**的：壁厚在减薄、焊缝在老化、结垢在加厚。这些变化运行中很难直接察觉，必须靠定期停炉检验来「摸底」。

**定期检验**：依据规程规定的周期，由检验机构对在用锅炉进行的强制性检查与试验。它的意义有两层——**保安全**（把缺陷消灭在酿成事故之前）与**保寿命**（通过检验及时发现并修复，延长锅炉使用年限）。

## 2 三种检验的周期与内容

在用锅炉的定期检验分三种，周期与内容各有侧重：

| 检验类型 | 周期 | 主要内容 |
| --- | --- | --- |
| **外部检验** | 每年一次 | 运行中检查：安全附件、仪表、管理制度、运行记录、本体外观、泄漏 |
| **内部检验** | 一般每 2 年一次 | 停炉检查：结垢腐蚀、壁厚测量、焊缝与胀口、汽包内部、拉撑与裂纹 |
| **水压试验** | 一般每 6 年一次 | 停炉进行：超压检验强度与严密性（见下节） |

<span class="marginnote">记忆口诀「外一年、内两年、水压六年」：外部检验在运行中就能做、最频繁；内部检验要停炉、查得深；水压试验最重、周期最长。三类检验从外到内、从轻到重，织成一张时间网。</span>

此外还有一些**特殊时点**必须增加检验：新装锅炉投入使用前、移装或大修后、停用 **1 年以上**重新启用时、发生事故后。这些情况按规程做相应检验，不可因「时间还没到」而省略。

## 3 公式解析：水压试验压力

**水压试验（hydrostatic test）**：向锅炉充满水并加压到试验压力，检验受压元件强度与严密性的方法。试验压力按规程规定：

$$p_{\text{试验}} = 1.25\,p_{\text{工作}}$$

三步拆解：

- **第一步，认清基准**：$p_{\text{工作}}$ 是锅炉额定工作压力（表压）。水压试验以它为基础，**超压**到 1.25 倍。
- **第二步，理解为什么是 1.25 倍**：试验压力必须高于工作压力，才能验证「在最高允许压力下仍有余量」；但也不能太高，否则可能把正常完好的元件压坏。1.25 倍是规程在「验得够严」与「别压出病」之间定的系数。<span class="marginnote">举个数：1.25 MPa 的锅炉，水压试验压力约 1.57 MPa。试压时炉膛里没有火、压力却比运行还高——所以水压试验是「停炉清人、慢升慢降、专人监护」的精细活，任何人不得停留在受压元件近旁。</span>
**第三步，掌握试验要求**：升压要**缓慢**，保压期间压力不得下降，期间检查各焊缝、胀口、人孔有无渗漏；合格标准是**无渗漏、无可见残余变形、压力表指针稳定**。试验水温与环境温度一般不低于 5°C，防止钢材低温脆断。

**辨析｜易错点：** 水压试验用**水**不用蒸汽、不用空气——水不可压缩，万一泄漏压力骤降、能量释放温和；气体可压缩，一旦破裂像气球一样爆。这正是「水压」二字的意义。

## 4 安全阀校验

安全阀是超压的最后防线，它的可靠性靠**校验**来保证：

**周期**：**每年至少校验一次**；新装锅炉、安全阀检修或整定调整后也必须校验。
- **内容**：校验**整定压力**（开启压力）是否准确、**回座压力**是否正常（开启排放后能否可靠关闭）、排放是否畅通。
- **方法**：多在锅炉上实压校验——缓慢升压，观察安全阀在整定压力下动作；也可在专用校验台上校验。
- **合格后**：**铅封**，记录校验日期与整定值，任何人不许擅动。<span class="marginnote">安全阀「铅封」是法定痕迹：铅封在，说明这台阀是经校验、被信任的；铅封被破坏，等于自证「动了手脚」，锅炉即失去合格状态。司炉工发现铅封损坏，第一件事是报告，而不是「顺手拧拧」。</span>

**重点：校验不是「走形式」。** 校验后要在锅炉安全技术档案里留记录；校验中发现排放量不足、整定值漂移的安全阀，必须调整或更换，绝不允许「凑合用到下一年」。

## 5 使用单位的配合

检验能不能顺利、真实地进行，取决于使用单位与司炉工的配合：

1. **按时申报**：按检验周期提前安排停炉、联系检验机构，避免「超期未检」。
2. **停炉准备**：按内部检验要求清灰、放水、开启人孔手孔、搭好脚手架，让检验员看得见、够得着。
3. **提供资料**：运行记录、维修记录、上次检验报告、水质化验记录，一应俱全。
4. **配合试压**：水压试验期间安排专人监视压力、配合操作、记录数据。
5. **落实整改**：检验发现的缺陷按结论整改（打磨、补焊、换管、降压运行等），整改后复检确认。

<span class="marginnote">把检验当「找茬」是对自己的不负责。一台检验合格的锅炉，等于有了一张「健康证明」，运行起来司炉工自己心里也踏实——检验暴露的问题，早处理是小修，拖到事故就是大修乃至报废。</span>

## 6 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 外部检验 | 运行中进行的年度检验 |
| 内部检验 | 停炉进行的深度检验，一般每 2 年一次 |
| 水压试验 | 超压检验锅炉强度与严密性的试验 |
| 试验压力 | 水压试验时施加的压力（1.25 倍工作压力） |
| 整定压力 | 安全阀开启排放的压力 |
| 回座压力 | 安全阀排放后重新关闭的压力 |
| 铅封 | 校验合格后加的防篡改封记 |
| 安全技术档案 | 锅炉登记、检验、维修的成套记录 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「检验周期到了再说」 | 要提前安排停炉申报，超期未检会被责令停用 |
| 「水压试验用空气省事」 | 必须用水：水不可压缩、泄漏压力骤降，空气会爆炸 |
| 「水压压力打到 1.25 倍就行」 | 还要保压查漏、无渗漏无变形才算合格 |
| 「安全阀校过就不用管」 | 每年至少校验一次，铅封破损即失效 |
| 「检验是检验机构的事」 | 司炉工要清灰、提供记录、配合试压、落实整改 |
| 「停用 1 年重启不用检」 | 停用超 1 年重新启用必须检验 |

### 记忆口诀

- 外一年、内两年、水压六年一张网。
- 新装大修重启炉，特时点要加检。
- 水压 1.25 倍，慢升慢降保压查漏。
- 安全阀一年一校，校完铅封动不得。
- 配合检验五件事：申报、清灰、给资料、试压、整改。

## 7 小结

- 三种定期检验：**外部检验每年一次、内部检验每 2 年一次、水压试验每 6 年一次**；新装、大修、停用超 1 年重启等要加检。
- **水压试验压力 $p_{\text{试验}} = 1.25\,p_{\text{工作}}$**，用不可压缩的水、缓慢升压、保压查漏、无渗漏无变形为合格。
- **安全阀每年至少校验一次**，校验后铅封、留档，铅封破坏即失效。
- 使用单位配合：按时申报、停炉清灰、提供资料、配合试压、落实整改。
- 定期检验 = 给锅炉做「体检」，司炉工是体检的全程配合者与第一受益人。
