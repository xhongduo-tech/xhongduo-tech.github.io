## 为什么从点火开始

前六节铺垫了构造、分类、燃料、水质、持证与法规，现在正式上手操作。点火升压是司炉工每天最关键的开场动作，也是**考试必考、事故高发**的第一道关。

一台冷锅炉从点火到进入正常运行，少则两三个小时、多则大半天。这段漫长过程的目的只有一个：**让金属均匀、缓慢地热起来**。金属一旦受热不均，就会像冰杯倒开水一样开裂——只不过锅炉裂开的代价，是爆炸。<span class="marginnote">把点火升压理解成「热身」而非「开火」：燃料的火力只是手段，让整个汽水系统按设定速率升温升压才是目的。急性子的司炉工，往往是最早把锅炉「送修」的司炉工。</span>

## 1 点火前的「五查」

锅炉不是随随便便就能点火的。点火前必须完成系统检查，缺一项都可能把隐患带进运行。司炉工把它归纳为「五查」：

1. **查本体检修状态**：确认检修工作票已终结、人孔/手孔已封好、炉内无遗留工具杂物。
2. **查水位**：开启水位计，确认水位在**最低安全水位与正常水位之间（略低于正常水位）**——点火后水受热膨胀，水位会自行上升。<span class="marginnote">为什么点火前水位要偏低？锅水吸热后体积膨胀，若点火前就把水加满到正常水位，升压后可能满水甚至顶开安全阀排汽。留出膨胀余量是点火操作的常识。</span>
3. **查安全附件**：压力表、安全阀、水位计、高低水位报警、联锁保护逐一试验完好。
4. **查燃料与给水**：煤斗有煤、油罐有油或气源正常，给水泵能启动、给水管道阀门开闭正确。
5. **查通风**：打开烟道挡板，启动引风机或自然通风 **5～10 分钟**，把炉膛与烟道里残留的可燃气体彻底吹走。<span class="marginnote">「点火前必须通风」是铁律：上次停炉后，未燃尽的燃气、油气可能积在炉膛里，一遇明火瞬间爆燃，把司炉工炸伤的事故几乎年年都有。通风是花 5 分钟买一条命。</span>

**重点：五查的核心是「防爆燃、防缺水、防附件失灵」。** 任何一查不过，宁可压住火种，绝不带病点火。

## 2 点火：从微火开始

五查通过后，按炉型点火：

**层燃炉（链条炉排）**：先在炉排前部铺一层引火木柴或油棉纱，点燃后形成微火，再缓缓推入少量煤，让火势逐渐铺开。
**燃油燃气炉**：先开启风机吹扫炉膛（吹扫时间按设计，一般不少于 20～30 秒甚至更长，视规程），确认无残余可燃气体后，**先点着火装置，再开燃料阀**——顺序绝不能反。

点火阶段对火力的要求是**「宁小勿大」**：小火维持一段时间，让炉膛、锅筒、水冷壁缓慢受热，然后才逐步加大。<span class="marginnote">先点明火、后开燃料，这一条顺序对燃气炉是保命级的：先开燃料再点火，喷出的燃气聚在炉膛里，遇电火花就是一次微型爆炸。</span>

## 3 升压过程：把温差锁在安全线内

点火后，汽压从零开始缓慢爬升。这个过程的技术核心是**控制升温速率**，而升温速率背后是金属的热应力。

### 公式解析：金属壁的热应力

锅炉金属壁受热不均时，会产生热应力。厚壁汽包上下壁温差越大，应力越大：

$$\sigma = \frac{E\,\alpha\,\Delta t}{1 - \mu}$$

三步拆解：

- **第一步，认识符号**：$\sigma$ 是热应力（MPa），$E$ 是钢材弹性模量（约 $2\times10^5$ MPa），$\alpha$ 是线膨胀系数（约 $12\times10^{-6}/^\circ C$），$\Delta t$ 是两点温差（°C），$\mu$ 是泊松比（约 0.3）。
- **第二步，感受量级**：把常数代进去，$\sigma \approx 3.4 \times \Delta t$（MPa）。汽包上下壁温差 40°C 时，热应力高达约 137 MPa——已经逼近锅炉钢的屈服强度。
- **第三步，推出操作要求**：这就是为什么规程规定汽包壁温差不得超过 40～50°C。升压必须按时间表慢慢来，让热量均匀渗透整个金属断面。<span class="marginnote">快速升压的代价：壁厚处温度滞后，内外温差瞬间拉大，热应力叠加工作应力，轻则变形、泄漏，重则鼓包、裂纹。行业事故档案里「升压过快」是高频死因。</span>

**升压时间**要守规矩：小型快装锅炉从点火到额定压力一般不少于 2～3 小时，中大型锅炉 4～6 小时，具体以锅炉厂说明书为准。升压途中**严禁为了赶时间而猛加燃料**。

## 4 升压途中的规定动作

升压不是干等着压力表爬升，而是按压力节点完成一系列动作：

| 压力节点（约） | 规定动作 | 目的 |
| --- | --- | --- |
| 0.05～0.1 MPa | 冲洗水位计 | 确认水位计畅通、显示真实水位 |
| 0.1～0.3 MPa | 检查并拧紧人孔、法兰螺栓 | 热态下螺栓松动，防泄漏 |
| 0.3～0.5 MPa | 缓慢开启主汽阀暖管 | 预热蒸汽管道，防管道水击 |
| 接近工作压力 | 校验安全阀 | 确认整定压力准确、排放畅通 |

<span class="marginnote"><strong>暖管</strong>最容易出事故：冷的管道一接触蒸汽，蒸汽凝结成水积在管内，被后续蒸汽高速推动，形成「水击」——咚、咚的撞击声能把管道法兰震裂。暖管要「少开阀、慢升温」，先小开度让微量蒸汽缓缓预热，管壁热透后再全开。</span>

**辨析｜易错点：** 拧螺栓要在「带压微热」时进行，用**短把扳手**适度拧紧，严禁用加长力臂狠拧——过热态下猛拧，螺纹可能咬死或拉裂。同理，水位计冲洗要按「关水阀—开汽阀—关汽阀—开水阀」的规范顺序，动作错序会把水冲进汽侧、造成假水位。

## 5 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 五查 | 点火前检修、水位、附件、燃料、通风五项检查 |
| 冷炉点火 | 从常温状态缓慢点火升温 |
| 升压 | 汽压从零缓慢升至工作压力 |
| 热应力 | 金属受热不均产生的内应力 |
| 暖管 | 缓慢预热蒸汽管道防汽水冲击 |
| 冲洗水位计 | 用汽、水吹扫水位计通路的操作 |
| 表压力 | 相对大气压的压力，压力表读数 |
| 汽包壁温差 | 汽包上下金属壁之间的温度差 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「点火越快越省事」 | 快升压拉大壁温差，热应力可超屈服强度 |
| 「点火前不用通风」 | 残留可燃气遇明火爆燃，通风是保命铁律 |
| 「水位加满再点火」 | 点火后水膨胀，水位要略低于正常水位 |
| 「油汽炉先开燃料再点火」 | 必须先点明火后开燃料，顺序不可反 |
| 「升压时干等压力表」 | 按压力节点冲洗水位计、紧螺栓、暖管、校安全阀 |
| 「炉水热就能放水」 | 停炉放水要等冷到规定温度，防骤冷损伤 |

### 记忆口诀

- 点火前五查：检修、水位、附件、燃料、通风。
- 升压看温差：热应力 σ = EαΔt/(1−μ)，壁温差限 40–50°C。
- 升压宁慢勿快：快装炉 2 小时起，大炉 4–6 小时。
- 节点动作：0.1 MPa 冲水位计、0.3 MPa 紧螺栓、0.5 MPa 暖管。
- 油汽炉先火后料，点火前先吹扫。
- 五查不过不点火，宁可压火别带病。

## 6 小结

- 点火前**五查**：检修状态、水位、安全附件、燃料给水、通风。
- 点火前必须**通风 5～10 分钟**，防爆燃是保命铁律。
- 燃油燃气炉**先点明火、后开燃料**，顺序不可反。
- 升压核心是**控温差**：热应力 $\sigma = \dfrac{E\alpha\Delta t}{1-\mu}$，汽包壁温差限 40～50°C，升压宁慢勿快。
- 升压途中按压力节点完成**冲洗水位计、紧螺栓、暖管、校验安全阀**。

在下一节，我们盯住运行中最要紧的仪表——水位计：它怎么读数、怎么冲洗、水位怎么调，以及「假水位」是怎么骗过司炉工眼睛的。
