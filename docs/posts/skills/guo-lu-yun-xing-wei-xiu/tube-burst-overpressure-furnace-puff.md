# 锅炉爆管、超压与灭火事故处理

## 为什么从这三场硬仗开始

上一节的缺水、满水、汽水共腾是「水上的事故」；这一节的三场硬仗更加惨烈——**爆管**是受热面破口喷汽，**超压**是锅筒在强度极限边缘挣扎，**灭火**则可能引出最凶险的炉膛爆炸。它们各自考验司炉工的一项素质：爆管考验「当断则断」，超压考验「冷静降压」，灭火考验「绝不侥幸」。<span class="marginnote">把这三件事放在《停炉保养与故障处理》篇的收尾，是因为它们是前七节全部知识的「总验收」：缺水、结垢、腐蚀、安全阀失灵——所有前文埋下的雷，都会在这里引爆。处置得当与否，看的就是平时功夫。</span>

## 1 爆管事故

**爆管（tube burst）**：受热面管子（水冷壁、对流管束、省煤器、过热器）破裂，高温高压汽水从破口喷出的工况。按破口位置，危险程度与处置略有差别。

**现象与信号**：

炉膛或烟道内有明显爆破声、汽水喷出；
汽压下降、水位迅速下降（水冷壁与对流管束爆管）；
- 炉膛负压变正、从看火孔向外喷烟喷汽；
- 排烟温度异常、引风机电流增大（烟道内汽水涌入）。<span class="marginnote">区分爆管位置：水冷壁爆管破口直对炉膛，现象最猛——炉膛瞬间喷汽；省煤器爆管则更多表现为给水异常、排烟温度骤降；过热器爆管以「炉膛出口冒白汽」为特征。位置不同，停炉的果断程度也不同。</span>

**主要原因**：严重缺水导致金属过热、结垢导致壁温超限、腐蚀减薄、材质缺陷、水循环破坏。归根结底——前几节防的每一件事，都是为防这一声「砰」。

**处理**：

**破口大、危及安全**：立即紧急停炉——停燃料、停送风、保持引风机抽汽排烟、关主汽阀解列，防止汽水喷出伤人、防止事故扩大。
**破口小、尚可维持**：若破口不大、汽压水位尚能维持，可减负荷作短时维持并立即报告，但最终仍需停炉检修——**爆管没有「带病运行」的选项**。
- **省煤器爆管**：若锅炉有省煤器旁路，可切换旁路、减负荷运行；无旁路则停炉。

## 2 超压事故

**超压（overpressure）**：锅内压力超过允许工作压力，安全阀应动作而未能有效降压的工况。超压的危险在于：锅筒、集箱是按工作压力设计的，压力一超，强度裕度被侵蚀，可能变形、泄漏直至爆炸。

**现象与信号**：

- 压力表指示持续高于工作压力（红线之上）；
- 安全阀动作（泄压）或本应动作却未动作（失灵）；
- 锅筒、法兰处出现异响、渗漏。

**主要原因**：安全阀全部失灵（整定过高、阀芯卡死、被压重物）；压力表失灵误读；负荷骤减而燃料未及时减少；蒸汽母管或阀门误关导致憋压。

**处理**：

1. **立即停止供给燃料、停止送风**——釜底抽薪，切断继续升压的热源；
2. **排汽降压**：开启放空阀或旁路排汽阀，把压力降到安全范围；
3. **加强监视**：若安全阀已动作仍降不下压，说明安全阀或压力表有问题，加强排汽并报告；
4. **查明原因**：压力恢复后，检查安全阀整定、压力表校验、负荷突变原因——**超压是严重事故，必须查清并记录**。<span class="marginnote">超压后的安全阀必须重新校验、重新铅封——它已经历过一次强制排放，弹簧特性可能改变。把「超压后校安全阀」写进记忆，是正规锅炉房的规矩。</span>

**辨析｜易错点：** 超压时**严禁**用「压住安全阀、减少排放」的办法维持运行——那是把最后一道保险拆了换侥幸。压力降不下来，正确动作是开阀排汽，而不是堵。

## 3 灭火与炉膛爆炸

**灭火（flameout）**：炉膛火焰突然熄灭的工况。它本身不是最可怕的，最可怕的是**灭火后不吹扫就重新点火**，引燃积存的爆炸性混合气体，造成**炉膛爆炸**——能把整个炉墙掀开。

**现象与信号**：

炉膛火焰瞬间熄灭、炉膛发暗；
炉膛负压突然增大；
- 汽压下降、负荷骤降；
- 灭火保护（MFT）动作，联锁切断燃料。

**主要原因**：燃料中断或压力异常、风量过大把火吹灭、配风严重失调、煤质突变、炉管爆裂喷水浇灭火焰。

**处理——三个「先」**：

1. **先停燃料**：立即关闭燃料阀（燃气、燃油炉尤其关键），切断供料；
2. **先吹扫**：保持引风机运行，按规程充分通风吹扫，把炉膛内积存的可燃气体排净（吹扫时间按设计，燃气炉一般不少于数十秒至数分钟）；
3. **先查因**：查明灭火原因并消除后，才允许重新点火。<span class="marginnote">炉膛爆炸的链条很清晰：灭火 → 燃料继续喷入 → 炉膛积聚燃气 → 未吹扫直接点火 → 火星引爆 → 炉墙崩开。这个链条上任何一环断掉，事故就不会发生——所以「灭火后必须吹扫再点火」是燃气炉的铁律。</span>

## 4 三事故对比：一张表分清

| 对比项 | 爆管 | 超压 | 灭火 |
| --- | --- | --- | --- |
| 核心信号 | 爆破声、汽压水位下降 | 压力超红线 | 火焰熄灭、负压骤增 |
| 直接危险 | 汽水喷出伤人、事故扩大 | 锅筒强度失效 | 炉膛爆炸 |
| 第一动作 | 紧急停炉、抽汽排烟 | 停燃料、开阀排汽 | 停燃料、保持吹扫 |
| 关键红线 | 破口大必须停炉 | 严禁堵阀硬撑 | **吹扫前严禁点火** |
| 事后处理 | 查爆管根因、换管 | 重新校验安全阀 | 查灭火原因后恢复 |

**重点：三件事的第一动作几乎都是「先停燃料」。** 爆管停料停风、超压停料排汽、灭火停料吹扫——把「停料」二字练成条件反射，是这场硬仗的共性基本功。

## 5 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 爆管 | 受热面管子破裂、高温汽水喷出 |
| 超压 | 锅内压力超过允许工作压力 |
| 灭火 | 炉膛火焰突然熄灭 |
| 炉膛爆炸 | 积存可燃气遇火源爆燃损坏炉墙 |
| 灭火保护（MFT） | 检测灭火并自动切断燃料的保护 |
| 吹扫 | 点火前用风机排除炉膛可燃气 |
| 放空阀 | 用于排汽降压的阀门 |
| 解列 | 关闭主汽阀使锅炉与母管脱离 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「爆管口小能凑合继续烧」 | 爆管没有带病运行选项，最终必须停炉 |
| 「超压就压住安全阀」 | 严禁堵阀硬撑，正确是开阀排汽降压 |
| 「灭火后马上重新点火」 | 必须先吹扫排净可燃气，否则炉膛爆炸 |
| 「超压之后校不校安全阀无所谓」 | 强制排放后弹簧特性变了，必须重新校验 |
| 「先关引风再处理」 | 爆管、灭火都要保持引风抽汽排烟 |
| 「三件事处置各管各」 | 第一动作都是先停燃料，共性基本功 |

### 记忆口诀

- 爆管停料停风、保引风、关主汽、防伤人。
- 超压先停料、开阀排汽、事后校安全阀。
- 灭火三先：先停燃料、先吹扫、先查因。
- 灭火不吹扫，点火即爆炸。
- 三事故第一动作都是「先停料」。

## 6 小结

- **爆管**：破口大立即紧急停炉、保持引风抽汽；破口小也只能短时维持、最终停炉；根因多是缺水、结垢、腐蚀。
- **超压**：先停燃料，开阀排汽降压，事后重新校验安全阀；严禁压住安全阀硬撑。
- **灭火**：先停燃料、先吹扫、先查因；**吹扫前严禁重新点火**，防炉膛爆炸。
- 三事故共性：**第一动作先停燃料**；处置看位置、看现象、看表，不凭侥幸。
- 三事故都是前文隐患的「总验收」：防缺水、防结垢、防腐蚀、保附件完好，就是对爆管、超压、灭火最好的准备。
