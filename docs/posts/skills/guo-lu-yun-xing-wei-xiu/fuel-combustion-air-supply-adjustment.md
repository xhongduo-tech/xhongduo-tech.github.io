## 为什么从配风开始

我们在《燃料与燃烧特性》一节认识了**过量空气系数** $\alpha = 21/(21-O_2)$——它是配风的「方向盘」。这一节把方向盘握到手里：司炉工到底怎么调风门、怎么判断燃烧好坏、加负荷减负荷时先动风还是先动煤。

配风是锅炉运行里最考验经验的活。仪表告诉你氧量，但氧量背后是火色、烟色、灰渣、声音的综合信号。老司炉工扫一眼火焰就能说出风大风小，靠的就是把这套「火语」读得滚瓜烂熟。<span class="marginnote">配风调节的上限是仪表，下限是经验：新司炉工盯氧量表，老师傅同时看火看烟——两套信息对上了，配风才算配到点子上。</span>

## 1 燃烧工况三看：看火、看烟、看仪表

判断燃烧好坏，司炉工有一套「三看法」：

**看火**——炉膛里的火焰是燃烧质量的直接窗口：

火焰**明亮橙黄、清晰稳定**：风煤匹配良好，正常。
火焰**白亮刺眼、炉膛发飘**：风量偏大，热量被过量空气带走。
- 火焰**暗红、发软无力、浓烟滚滚**：风量不足，燃烧不完全。<span class="marginnote">把火焰颜色当「体温计」：橙色是燃烧的舒适区，白亮是发烧、暗红是畏寒。调风到火焰「站稳」为止——不飘不沉，就是火候到了。</span>

**看烟**——烟囱冒出的烟色透露尾部工况：

**淡灰或几乎无色**：燃烧完全，正常。
**浓黑**：缺氧，机械不完全燃烧，炭粒被烟带走——浪费加污染。
- **发白且量小**：多为水汽，注意是否给水带水或蒸汽泄漏。

**看仪表**——把主观感受落到客观数据：炉膛出口**氧量表**（对应 α）、**炉膛负压表**、**排烟温度表**三者对照，确认「火看对了」。

## 2 一次风与二次风：分工不同的两路空气

层燃炉的送风分两路，各管各的事：

| 风种 | 送风位置 | 职责 |
| --- | --- | --- |
| **一次风** | 炉排下方穿过煤层 | 提供燃烧所需氧气，决定燃烧强度 |
| **二次风** | 炉膛空间喷入 | 扰动烟气、促进混合，助燃并补氧 |

<span class="marginnote">一次风像「灶下的鼓风」，负责把火烧旺；二次风像「锅里的翻炒」，负责让烧到一半的烟气与可燃气体把氧气用足。层燃炉里挥发分在炉膛空间燃烧，全靠二次风把它「搅和」充分。</span>

链条炉排的燃料沿炉排从前往后移动，各段燃烧阶段不同，对风量的需求也不同：预热段少风、主燃段多风、燃尽段少风。所以运行良好的链条炉采用**分段送风**——各风室独立调节风门，让风跟着燃烧阶段走。

## 3 公式解析：理论空气量与送风量

知道了 α，还要知道「理论空气量是多少」，才能算出风机该送多少风。**理论空气量**可按燃料元素分析估算（固体/液体燃料）：

$$V_0 = 0.0889\,(C_{\text{ar}} + 0.375\,S_{\text{ar}}) + 0.265\,H_{\text{ar}} - 0.0333\,O_{\text{ar}}$$

三步拆解：

- **第一步，认识符号**：$C_{\text{ar}}$、$H_{\text{ar}}$、$O_{\text{ar}}$、$S_{\text{ar}}$ 是燃料收到基（ar）元素分析中碳、氢、氧、硫的质量分数。每一项都是「这一元素烧完需要多少氧，对应多少空气」。
- **第二步，看懂结构**：碳与硫需要氧、按系数 0.0889 折成空气量；氢的发热高、需氧多，系数 0.265；而燃料里自带的氧帮了忙，所以要**减去** 0.0333 倍。<span class="marginnote">直觉：系数其实就是「每 1 kg 该元素完全燃烧所需的空气体积」。燃料自带的氧省了外来的空气，所以要扣——这是唯一带减号的项。</span>
**第三步，落到送风量**：实际送风量 $V = \alpha V_0$。以一台烧烟煤的锅炉为例，若 $V_0 \approx 6.5\ \text{m}^3/\text{kg}$、取 $\alpha = 1.4$，则每烧 1 kg 煤要送约 $9.1\ \text{m}^3$ 空气——再乘上每小时耗煤量，就是引风机、鼓风机的送风基准。

**辨析｜易错点：** 估算公式只用于「心里有数」，实际配风要以烟气分析为准。燃料变化、漏风变化都会让理论值与实际偏离——公式给方向，仪表给答案。

## 4 配风调节的原则与顺序

配风不是「拧大风门」那么简单，它有一套先后顺序的纪律：

**增加负荷**：先加风、后加煤。先让空气富裕起来，再加燃料，可避免瞬间缺氧冒黑烟。
- **降低负荷**：先减煤、后减风。先撤燃料，再收风，防止炉膛过热与熄火。
- **调风门**：一次风和二次风配合，以炉膛出口氧量为基准微调，每次小幅动作、观察稳定后再动下一步。

<span class="marginnote">「先风后煤、先煤后风」八个字是配风的行动纲领。违反顺序的典型事故：加负荷时先猛加煤，煤层瞬间加厚、氧气跟不上，火焰缺氧发暗、一氧化碳猛增——轻则冒黑烟，重则炉膛爆燃。</span>

配套的还有煤层与炉排：煤层厚度按煤种定（烟煤约 100～150 mm，无烟煤略厚，褐煤更厚），炉排速度与负荷匹配；换煤种时，煤层、风量、炉排速度要**一起重调**，只调其中一项必然烧不好。

## 5 炉膛负压与常见燃烧故障

炉膛应该保持**微负压**运行：一般控制在 **20～30 Pa**。负压太大，冷空气从各处缝隙漏入，排烟损失增大；变成正压，火焰从看火孔、炉门喷出，烧伤人员。<span class="marginnote">判断负压是否合适有个土办法：看火孔附近火苗微微内吸、不向外扑，就是负压合适；火苗向外窜就是正压了，立刻开大引风、关小送风。</span>

常见燃烧故障与处置：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 冒黑烟 | 风量不足、煤层太厚 | 加大送风，适当减煤 |
| 火焰白亮、飞灰多 | 风量过大 | 减小送风 |
| 炉排上有「火口」 | 煤层不均、煤块卡滞 | 扒平煤层、消除火口 |
| 结渣严重 | 灰熔点低、炉温过高 | 降负荷、清渣、调风降温 |

## 6 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 一次风 | 从炉排下穿过煤层的风，管燃烧 |
| 二次风 | 向炉膛喷入的风，管混合助燃 |
| 分段送风 | 链条炉按燃烧阶段分室调节送风 |
| 理论空气量 | 完全燃烧所需的最小空气量 |
| 过量空气系数 | 实际空气量与理论空气量之比 |
| 炉膛负压 | 炉膛内低于大气压的压力（20～30 Pa） |
| 火口 | 炉排上因煤层不均形成的火焰空洞 |
| 烟气分析 | 测烟气氧量判断燃烧质量的方法 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「风越大烧得越旺」 | 风太大火焰发白发飘，排烟损失增大 |
| 「增负荷先加煤」 | 先加风后加煤，防瞬间缺氧冒黑烟 |
| 「减负荷先减风」 | 先减煤后减风，防炉膛过热熄火 |
| 「负压越大越安全」 | 负压太大会漏风增排烟损失，正压喷火伤人 |
| 「配风看排烟氧量就行」 | 应以炉膛出口氧量为准，排烟氧量含漏风 |
| 「换煤种只调煤就行」 | 煤层、风量、炉排速度要一起重调 |

### 记忆口诀

- 一次风管烧、二次风管混，链条炉分段送。
- 增负荷先加风后加煤，减负荷先减煤后减风。
- 火焰橙黄为佳：白亮减风、暗红加风。
- 炉膛微负压 20–30 Pa，火苗内吸不上扑。
- α 落在谷底：太大烧热风、太小冒黑烟。

## 7 小结

- 燃烧工况**三看**：看火（橙黄为佳）、看烟（淡灰为佳）、看仪表（氧量、负压、排烟温度）。
- **一次风**管燃烧、从炉排下送；**二次风**管混合、向炉膛喷；链条炉采用**分段送风**。
- 理论空气量 $V_0 = 0.0889(C_{\text{ar}}+0.375S_{\text{ar}}) + 0.265H_{\text{ar}} - 0.0333O_{\text{ar}}$，实际送风量 $V = \alpha V_0$。
- 配风纪律：**增负荷先加风后加煤，减负荷先减煤后减风**。
- 炉膛保持**微负压 20～30 Pa**；冒黑烟加风、火焰发白发飘减风。
