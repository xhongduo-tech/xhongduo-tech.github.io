## 为什么从考核开始

这是本专题的收束篇。前二十一篇把锅炉从构造、操作、保养到事故处理完整过了一遍——而这一切知识，最终要在一个地方接受检验：**职业技能鉴定考核**。司炉工取证、晋级都要过这道关，它是进入锅炉房的「毕业考试」。<span class="marginnote">把考核放在最后讲，是因为它的考点不是「偏题怪题」，而是<strong>前面所有内容的浓缩</strong>：法规数字、操作顺序、事故原则——每一道题都在前文讲过。现在把它们像期末冲刺一样串成清单，正好给整个专题做一次总复习。</span>

这一节讲考核怎么考、考什么、哪些是「一票否决」，以及考前冲刺该抓哪几块。

## 1 考核的两种形式

司炉工职业技能鉴定（及特种设备作业人员考试）通常由**理论知识**与**操作技能**两部分组成：

| 考核类型 | 形式 | 内容侧重 | 合格线 |
| --- | --- | --- | --- |
| **理论知识考核** | 闭卷笔试/机考 | 安全法规、基础知识、原理与原则 | 一般 60 分 |
| **操作技能考核** | 现场实操/情景模拟 | 规定动作、操作顺序、事故处置 | 按评分表 |

**重点：两科都要合格，一科不过即不通过。** 理论背得滚瓜烂熟、动手一塌糊涂不行；实操麻利、法规一问三不知也不行——「懂规矩」与「会干活」缺一不可，这正是司炉工「持证上岗」四个字的完整含义。

## 2 理论考核的考点地图

理论考核的题目，几乎都能在下面这张「考点地图」里找到位置：

| 板块 | 高频考点 |
| --- | --- |
| **安全法规** | 持证要求、检验周期、使用单位义务、TSG G0001 适用范围 |
| **锅炉基础** | 型号编制读法、构造与循环、热效率公式 |
| **燃料燃烧** | 挥发分与着火、过量空气系数、配风顺序 |
| **水质处理** | 指标含义、软化与排污、排污率 |
| **运行操作** | 点火升压、水位调节、并汽条件、安全附件要求 |
| **事故处理** | 缺水/满水/共腾、爆管/超压/灭火的原则 |
| **节能减排** | 五大热损失、反平衡效率、低氮燃烧 |

<span class="marginnote">数字是理论考的「送分题」也是「送命题」：检验周期（外一内二水压六）、安全阀整定（1.04～1.06 倍）、水压试验（1.25 倍）、压力表量程（1.5～3 倍）、证书有效期（4 年）——这些数背熟，等于白捡十几分。</span>

**备考建议**：抓大放小——先记「原则句」（严重缺水严禁进水、灭火后吹扫再点火），再记「数字」，最后才是细节。考卷上原则题占比最高。

## 3 实操考核的规定动作

实操考核考的是**规定动作的标准顺序**。以下是题库里最常见的几个项目，每一步都有扣分点：

**点火前的检查**：五查顺序、水位位置判断、通风时间——漏一项扣一项分。
**水位计冲洗**：关水阀 → 开汽阀 → 关汽阀 → 开水阀，顺序错一步即失分。<span class="marginnote">水位计冲洗是实操的「钉子户」，几乎每场必考。扣分点很细：先关水阀再开汽阀的次序、放水阀的开度、冲洗后水位能否恢复——动作要慢而稳，让考官看清每一步。</span>
**排污操作**：排污前查水位、排污阀「开—关—开—关」脉冲、排污后复查水位补水。
**点火与升压**：引火物处理、通风、升压途中冲洗水位计与暖管的时机。
- **正常停炉**：减负荷 → 停燃料 → 停风 → 解列 → 保水的完整顺序。
- **紧急停炉**：由考官**报一个险情**（如「水位计不见水位」），考生按紧急停炉步骤口述加操作——考的就是条件反射。
- **事故处置（口述）**：缺水、满水、汽水共腾、爆管、灭火等情景，要求说出判断依据与处置步骤。

**实操的诀窍是「先动作、后解释」**：考官看的是你的手有没有按规矩走，嘴巴上的道理是加分项，手上的顺序是必选项。

## 4 一票否决项：高分也可能挂

实操评分表里有一类特殊条目——**一票否决项**，只要踩中，前面分再高也判不合格：

- **严重缺水时向锅炉进水**：违反最致命的安全铁律，直接判负；
- **灭火后未吹扫就重新点火**：燃气炉的爆炸诱因，直接判负；
- **操作顺序严重错误**：如水位计冲洗错序、排污忘补水，视情节判负；
- **危险动作**：正压喷火时探身看火孔、检修未断电就盘车等。

<span class="marginnote">一票否决的逻辑很清晰：<strong>考官不考你的极限，考你的底线</strong>。技术不熟可以学，安全底线破了就是事故苗子——鉴定考试先把「不会闯祸」这件最基本的事卡死，再谈熟练不熟练。</span>

**辨析｜易错点：** 考试紧张时最容易「越熟练越出错」——手比脑子快，把顺序做反了。训练时就要养成「边说边做」的习惯：每个动作前先默念一句依据，让口令带着手走。

## 5 备考冲刺清单

考前冲刺，按优先级抓这几块：

1. **法规数字表**：检验周期、整定压力、试验压力、量程倍数、有效期——做成一张卡天天背；
2. **操作顺序五连**：冲洗水位计、排污、点火升压、正常停炉、紧急停炉——五套顺序闭眼能背；
3. **事故原则句**：严重缺水严禁进水、灭火先吹扫再点火、满水先停水、共腾强排污；
4. **公式三件套**：热效率、过量空气系数、排污率——考卷上出现率最高的三个式；
5. **看几遍规程原文**：TSG G0001 的关键条款，以现行文本为准，别只背培训讲义。

## 6 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 理论知识考核 | 闭卷笔试/机考，考法规原理 |
| 操作技能考核 | 现场实操/情景模拟，考规定动作 |
| 一票否决项 | 触碰即判不合格的关键错误 |
| 规定动作 | 考核中必须按标准顺序完成的操作 |
| 情景模拟 | 考官报险情、考生口述加操作 |
| 数字卡 | 检验周期、整定压力等必背数值汇总 |
| 原则句 | 事故处理的关键规则语句 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「理论考过就行」 | 理论实操双合格，一科不过不通过 |
| 「数字不重要，理解就行」 | 检验周期、整定压力等数字是送分题 |
| 「实操动作快就好」 | 要边说边做，让考官看清每一步顺序 |
| 「考官不抓小错」 | 操作顺序错一步就扣分甚至一票否决 |
| 「技术熟练就不会挂」 | 一票否决项与熟练度无关，碰线即挂 |
| 「背讲义不用看规程」 | 关键条款以现行 TSG G0001 原文为准 |

### 记忆口诀

- 双合格：理论 + 实操，缺一不可。
- 五套顺序背到死：冲洗水位计、排污、点火升压、停炉、紧急停炉。
- 事故三原则：严重缺水禁进水、灭火先吹扫、满水先停水。
- 一票否决别碰线：进水、不吹扫、错序、危险动作。
- 冲刺五件套：数字卡、操作五连、原则句、公式三件套、规程原文。

## 7 小结

- 考核两科：**理论（法规+原理）+ 实操（规定动作）**，双合格才能取证晋级。
- 理论考点七板块：法规、基础、燃烧、水质、运行、事故、节能——**数字与原则句是得分主力**。
- 实操必考五动作：**点火前检查、水位计冲洗、排污、点火升压、停炉**；紧急停炉按情景应对。
- **一票否决**：严重缺水进水、灭火不吹扫就点火、顺序严重错误、危险动作——碰一条即挂。
- 冲刺清单：**数字卡 + 操作五连 + 事故原则 + 公式三件套 + 规程原文**。

至此，从构造原理、运行操作、停炉保养到检验考核，「锅炉运行与维修（司炉工）」的全部知识已经讲完。下一课，带着这张清单走进考场，也带着它走进锅炉房——**证是准入，规矩是保命，功夫在每一天的盯守与调整里。**
