## 为什么从安全附件开始

水位计之外，锅炉还有三件「保命设备」：**压力表、安全阀、温度仪表**。前两节我们学会看水位，这一节学会看压力、管安全阀、读温度——它们共同构成司炉工每时每刻的监控仪表盘。<span class="marginnote">上一节《规程总则》里提过一条硬规矩：「安全附件失灵即停用」。压力表、安全阀、水位计三者哪怕只剩一件失效，锅炉都不得继续运行——本节末尾会把这条红线落到实处。</span>

安全附件的特点是**「平时不显眼，关键时救命」**：压力表每天被扫过无数次，安全阀可能几年不开一次，可一旦超压，只有安全阀能救整座锅炉房。司炉工对它们的态度，决定锅炉的生死。

## 1 安全附件「三件套」各管什么

| 附件 | 功能 | 失效后果 |
| --- | --- | --- |
| **压力表** | 显示锅内蒸汽压力 | 超压无知觉，锅筒强度失效 |
| **安全阀** | 超压自动排汽泄压 | 超压无处释放，锅炉爆炸 |
| **温度仪表** | 显示汽温、水温、烟温 | 过热器超温、尾部再燃烧失控 |

**重点：三件套相互独立、不可互相替代。** 压力表告诉你「压了多少」，安全阀在压力失控时「泄出去」，温度仪表告诉你「热过了头没有」——缺一样，运行就少一只眼睛。

## 2 压力表监控

工业锅炉最常用**弹簧管压力表**：管内压力使弹簧管变形，变形量通过齿轮放大，带动指针指示读数。司炉工要盯住它的三个要素：

**量程**：量程选多大，直接关系读数精度，见下节公式解析。
**精度等级**：低压锅炉压力表精度不低于 **2.5 级**（即示值误差不超过量程的 2.5%），压力越高要求越严。<span class="marginnote">精度等级数字越小越准：1.6 级比 2.5 级误差更小。同一块表，量程选大了误差的绝对值也变大——这就是「量程不能随意放大」的原因。</span>
- **安装**：压力表下必须装**存水弯管**（缓冲蒸汽热量）与**三通旋塞**（便于在线校验、更换），表盘直径不小于 100 mm，并用红线在表盘上标注工作压力位置。

压力表**校验周期**一般不超过半年，校验合格后**铅封**。表盘玻璃破损、指针卡滞、铅封缺失，都要按「失灵」处理。

## 3 公式解析：压力表量程怎么选

量程太小，压力一到头指针打满、读数失真；量程太大，正常压力下指针只动一点点，误差又太大。规程给了一个经验区间：

$$1.5\,p_{\text{工作}} \le \text{量程} \le 3\,p_{\text{工作}}$$

三步拆解：

- **第一步，定下限 1.5 倍**：量程至少是工作压力的 1.5 倍，保证安全阀整定排放时压力表仍有读数余量，指针不会打满损坏。
- **第二步，定上限 3 倍**：量程最大不超过工作压力的 3 倍，否则正常运行时指针只转一小段弧，读数分辨率差，误差相对偏大。
- **第三步，取中间值约 2 倍**：工程上优选「量程 ≈ 2 倍工作压力」。例如 1.25 MPa 的锅炉，配 0～2.5 MPa 量程的压力表最合适。<span class="marginnote">直觉记忆：量程是你给指针留的「活动空间」，留太紧读数到头、留太松读数不准。2 倍是司炉行业公认的甜点——指针平时停在表盘中间 1/2 刻度附近，最好认。</span>

**辨析｜易错点：** 压力表读数的是**表压**（相对大气压），安全阀整定、强度校核都以表压为基准。把绝压当表压、或把表压当绝压，都会让整定值算错——这是考卷上反复出现的陷阱。

## 4 安全阀监控

**安全阀（safety valve）**：当锅内压力超过整定值时自动开启、排放蒸汽降压、压力回落后自动关闭的阀门。它是锅炉在超压事故中**最后一道防线**。

监控要点：

**数量**：蒸发量大于 0.5 t/h 的蒸汽锅炉，至少装 **2 个**安全阀；小于等于 0.5 t/h 可装 1 个。
**整定压力**：一般取工作压力的 **1.04～1.06 倍**。压力达到整定值时安全阀应能灵敏开启。<span class="marginnote">整定压力的直觉：给正常压力留一点「余量」，但又不能留太多。留太少，压力一波动安全阀就误开、白白排汽；留太多，真超压时它反应迟钝——1.04～1.06 倍就是在「不误动」和「不快动」之间找的平衡。</span>
**排放能力**：安全阀的总排放量应不小于锅炉的最大连续蒸发量——否则真超压时「泄不过它产」。
**校验**：**每年至少校验一次**，新装、大修后也必须校验；校验合格后**铅封**，不得擅自调整。
**红线**：严禁在安全阀上加重物压住、用卡具卡死——那等于把最后一道防线拆了。

## 5 温度仪表监控

锅炉上的温度测点各有各的「职责」：

| 测点 | 监控对象 | 异常后果 |
| --- | --- | --- |
| 过热器出口 | 过热蒸汽温度 | 汽温过高损坏用汽设备，过低蒸汽带水 |
| 省煤器出口 | 给水温度 | 影响省煤器换热与防腐蚀 |
| 排烟温度 | 烟气尾部温度 | 过高效率骤降，过低尾部结露腐蚀 |
| 空气预热器出口 | 热风温度 | 影响燃烧稳定性 |

<span class="marginnote">排烟温度是效率的「体温计」：比设计值高出 20°C，锅炉效率可能掉 1 个百分点；但排烟温度也不能降太低，否则烟气中硫酸蒸汽在尾部凝结，把省煤器腐蚀穿孔——「高也不行、低也不行」正是温度监控的难处。</span>

**辨析｜易错点：** 温度仪表读数异常时，先怀疑**测点本身**：热电偶是否松动、热电阻是否断线、套管是否结垢——很多「温度报警」其实是仪表假象。对照相邻测点交叉验证，再判断是设备问题还是仪表问题。

## 6 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 弹簧管压力表 | 靠弹簧管变形指示压力的仪表 |
| 量程 | 压力表的刻度极限值 |
| 精度等级 | 允许误差占量程的百分比 |
| 存水弯管 | 压力表下缓冲蒸汽的弯管 |
| 三通旋塞 | 便于在线校验更换压力表的三通阀 |
| 安全阀 | 超压自动排汽泄压的阀门 |
| 整定压力 | 安全阀开启排放的压力 |
| 铅封 | 校验合格后防篡改的封记 |
| 排烟温度 | 锅炉排出烟气时的温度 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「量程越大越保险」 | 量程太大指针不动，读数误差大，取约 2 倍工作压力 |
| 「压力表读数就是绝压」 | 工程读数表压，热力计算才用绝压 |
| 「安全阀上压个重物防误开」 | 那是拆掉最后防线，严禁压物卡死 |
| 「一个安全阀就够」 | 蒸发量 > 0.5 t/h 至少装 2 个 |
| 「温度报警就是设备坏了」 | 先怀疑测点：热电偶松动、套管结垢 |
| 「排烟温度越低越好」 | 低于露点尾部硫腐蚀，要守设计余量 |

### 记忆口诀

- 三件套：压力表看压、安全阀泄压、温度表管温。
- 量程 1.5–3 倍工作压力，2 倍是甜点。
- 安全阀整定 1.04–1.06 倍，一年一校、校完铅封。
- 附件失灵即停用，压物卡阀是大忌。
- 温度先疑测点，再断设备；排烟守露点。

## 7 小结

- 安全附件三件套：**压力表（看压力）、安全阀（泄超压）、温度仪表（管温度）**，相互独立、缺一不可。
- 压力表**量程取工作压力的 1.5～3 倍，优选约 2 倍**；精度不低于 2.5 级，配存水弯管与三通旋塞。
- 安全阀**至少 2 只**，整定压力为工作压力的 1.04～1.06 倍，**每年校验一次**并铅封，严禁压住卡死。
- 温度测点盯**过热汽温、给水温度、排烟温度**；排烟温度过高损效率、过低致腐蚀。
- **红线：任一安全附件失灵，锅炉立即停用。**
