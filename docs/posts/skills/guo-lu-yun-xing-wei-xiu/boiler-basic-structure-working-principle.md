## 为什么从构造开始

这个网站叫「从极限到大模型」。极限通向微积分，大模型通向当代 AI；而在两者之间的技能层，锅炉是把「燃料的化学能」变成「蒸汽的热能与压力能」的工业心脏。在第六级《热能工程（锅炉与热力发电）》，你会用传热学与工程热力学重新推演锅炉的每一项设计参数；在更上游的第一级《基础物理》里，热力学第一定律与饱和温度的概念已经为今天的讨论铺好了路。

但今天我们要用司炉工的眼光来读锅炉：不画复杂的热力循环图，只看懂构造、分清循环、会算效率。因为**一切运行操作——点火、升压、停炉、事故处理——都建立在「锅炉长什么样、水汽怎么走」之上**。锅炉房的老师傅常把一句话挂在嘴边：你连锅筒在哪都不知道，就敢去开安全阀，那不是勇敢，是玩命。

## 1 「锅」与「炉」：把能量转换拆成两半

**锅炉（boiler）**：利用燃料燃烧释放的热能，将工质（水）加热成具有一定温度和压力蒸汽（或热水）的热力设备。<span class="marginnote">「锅炉」一词即「锅」+「炉」：「锅」负责汽水侧，「炉」负责烟气侧。早期蒸汽机车把这对组合塞进同一金属壳体，近代水管锅炉才把两者分开布置，各得其所。</span>

从功能上拆解，锅炉本体由两大系统构成：

**「锅」——汽水系统**：汽包（锅筒）、下降管、集箱、水冷壁、过热器、省煤器等。工质（水与蒸汽）在其中流动、吸热、汽化，是承压的部分。
**「炉」——燃烧系统**：炉膛、炉排（或燃烧器）、烟道、空气预热器、除尘器等。燃料在其中燃烧，烟气沿烟道流动，把热量交给汽水系统。

**重点：汽水系统与烟气系统通过「受热面」换热，二者互不直接接触。** 水与蒸汽走一条路，烟气走另一条路，热量透过金属管壁传递。这条「不接触」的原则是锅炉安全的底线之一——一旦烟气漏入汽水侧（如爆管），事故随之而来，我们会在第3篇讲透。

## 2 蒸汽是怎么炼成的：一个工质循环

以最常见的**自然循环水管锅炉**为例，工质完整走一圈是这样的：

1. **给水**经省煤器预热后送入**汽包**；
2. 汽包里的水沿**下降管**流向下集箱——这一段是纯水，密度大；
3. 水从下集箱进入包围炉膛的**水冷壁**，被高温火焰与烟气强烈加热，部分汽化，成为汽水混合物，密度显著减小；
4. 汽水混合物密度小，沿水冷壁**向上**流回汽包；
5. 在汽包内经过汽水分离，饱和蒸汽从顶部引出，分离出的水回到下降管，重新开始循环。

<span class="marginnote">驱动这个循环不需要额外泵：水冷壁里汽水混合物密度小、往上升，下降管里纯水密度大、往下沉——密度差就是天然的循环动力，这就是「自然循环」。工业锅炉绝大多数靠它，结构简单、运行可靠。若循环建立不起来（如长期低水位运行），水冷壁就会过热爆管。</span>

蒸汽离开汽包时是**饱和蒸汽**——温度由汽包压力唯一确定。若用户需要更高温度的蒸汽，就把它送进布置在烟气高温区的**过热器**再加热，成为**过热蒸汽**。这也是为什么司炉工要同时看压力表又看温度表：压力定了饱和温度，但过热器出口温度还要靠减温水单独调节。

## 3 主要受压部件认一认

司炉工对锅炉本体的认识，最终要落实到一件件具体部件上。下表列出最容易出镜的七个：

| 部件 | 位置与作用 | 司炉工须知 |
| --- | --- | --- |
| **汽包（锅筒）** | 锅炉最高处的圆筒，汽水分离的场所 | 水位计的零点以汽包中心线为基准 |
| **下降管** | 汽包向下集箱输水的管道 | 不吸热或少吸热，保证水柱密度 |
| **下集箱** | 底部汇水、配水的横管 | 定期排污常在集箱底部进行 |
| **水冷壁** | 炉膛四周的排管，吸收辐射热 | 缺水时最先过热，是爆管高发区 |
| **过热器** | 炉膛出口，加热饱和蒸汽 | 出口温度过高会损坏用汽设备 |
| **省煤器** | 尾部烟道，预热给水 | 给水断水时易汽化，需防干烧 |
| **空气预热器** | 尾部烟道最末端，预热空气 | 降低排烟温度，提高燃烧效率 |

<span class="marginnote">七个部件里，汽包、下降管、集箱、水冷壁构成自然循环的闭环；过热器、省煤器、空气预热器则分别「照顾」蒸汽品质、给水温度和助燃空气——记住这七个名字，你就能听懂锅炉房里 80% 的对话。</span>

这七个部件的记忆诀窍是「先背水汽流程、再背烟气流程」：给水从省煤器进，在汽包里会合，经下降管、水冷壁汽化，回汽包引出，过热器把关；而烟气从炉膛出发，先过热器、再对流管束、后省煤器、末了空气预热器，一路降温排走。

## 4 公式解析：锅炉热效率

司炉工最该先会算的一个数是**锅炉热效率**，它衡量「烧进去的燃料有多少变成了有效蒸汽」。

$$\eta = \frac{Q_{\text{eff}}}{Q_{\text{in}}} \times 100\% = \frac{D\,(h'' - h')}{B\,Q_{\text{net}}} \times 100\%$$

三步拆解：

- **第一步，分子——有效利用热 $Q_{\text{eff}}$**：$D$ 是蒸发量（kg/h），$h''$ 是出口蒸汽焓（kJ/kg），$h'$ 是给水焓，两者之差就是每公斤水从给水变成成品蒸汽净吸收的热量，乘上蒸发量就是锅炉真正「卖出去」的热。
- **第二步，分母——输入热量 $Q_{\text{in}}$**：$B$ 是燃料消耗量（kg/h），$Q_{\text{net}}$ 是燃料低位发热量（kJ/kg），乘积即燃料完全燃烧能放出的总热量。<span class="marginnote">低位发热量指的是扣除水蒸气凝结潜热后剩的热。我国习惯用低位发热量计算锅炉效率，与用高位发热量算出来的数值不一样——同一台锅炉，两种口径能差出 4–6 个百分点。</span>
**第三步，相除**：比值就是效率。工业层燃锅炉热效率通常在 65%–80%，燃气锅炉可到 90% 以上。差值不是燃料的「好坏」，而是燃烧方式与余热回收水平的差距。

**辨析｜易错点：** 热效率不是「烧得越旺效率越高」。过量空气太多，冷空气把热量白白带走（排烟损失 q₂ 增大）；太少则烧不透，灰里带碳、烟气带一氧化碳。司炉工调风调煤，本质上就是在分子分母之间找那个最优比值——这正是第2篇《燃料燃烧与配风调节》的主题。

## 5 受热面与烟气流程：热量如何被「接力」

燃料在炉膛内燃烧，烟气温度可达 1000°C 以上。烟气从炉膛出发，沿烟道依次把热量交给各级受热面，温度逐级下降：

| 受热面 | 布置位置 | 主要换热方式 | 烟气温度段（约） |
| --- | --- | --- | --- |
| 水冷壁 | 炉膛四周 | 辐射换热 | 1300°C → 900°C |
| 过热器 | 炉膛出口烟道 | 对流为主 | 900°C → 600°C |
| 对流管束 | 锅炉本体烟道 | 对流换热 | 600°C → 400°C |
| 省煤器 | 尾部烟道 | 对流换热 | 400°C → 250°C |
| 空气预热器 | 尾部烟道末端 | 对流换热 | 250°C → 150°C |

<span class="marginnote">工程上有个经验数：排烟温度每降低约 15–20°C，锅炉效率约提高 1 个百分点。省煤器和空气预热器就是专门为「压榨」烟气余热而设的——烟气在它们那里降温，水和空气却升温，各得其所。</span>

把这张表读透，你就掌握了锅炉热力的「等高线」：热量从火焰到水，是沿着这条温度梯度一级一级递过去的。谁先吸收、谁后吸收，决定了受热面叫什么名字，也决定了它承受多高的温度——布置在炉膛里的水冷壁承受 1000°C 以上的辐射热，而最末端的空气预热器出口烟温已低到 150°C，两者对材质、对维护的要求完全不同。

## 6 额定参数：锅炉的「身份证号码」

每台锅炉铭牌上印着几个额定参数，司炉工必须能准确读出它们的含义：

**额定蒸发量 $D_e$**：设计工况下每小时产生的蒸汽量，单位 t/h（或 MW，用于热水锅炉）。它是选泵、配管、报负荷的基准。
**额定工作压力 $p_e$**：设计规定的出口蒸汽表压力，单位 MPa。**表压力**是相对大气压的压力——安全阀的整定值、压力表的量程，全都围绕它展开。<span class="marginnote">「表压力」三个字很关键：压力表读数是表压，而热力学公式里常用绝压。工程上说的「1.0 MPa 锅炉」几乎都指表压，对应绝压约 1.1 MPa。忽略这个差值，安全阀整定就会算错。</span>
- **额定蒸汽温度**：过热器出口的设计蒸汽温度；饱和蒸汽锅炉则写「饱和温度」。
- **给水温度**：设计给水温度，决定省煤器的换热负荷。

**辨析｜易错点：** 额定蒸发量是「设计值」，不是「随时都能烧这么多」。实际蒸发量超过额定值时，蒸汽带水加剧、效率下降、受热面超温——司炉工调负荷，第一纪律就是「不超铭牌」。

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 锅炉 | 燃料化学能转蒸汽热能的设备，分「锅」「炉」两系统 |
| 汽包（锅筒） | 汽水分离场所，水位计零点基准 |
| 水冷壁 | 炉膛四周受辐射热的排管，自然循环上升管 |
| 下降管 | 汽包向下集箱输纯水的管道 |
| 省煤器 | 尾部烟道预热给水的受热面 |
| 过热器 | 把饱和蒸汽加热成过热蒸汽 |
| 空气预热器 | 尾部最末端，预热助燃空气 |
| 自然循环 | 靠密度差驱动的汽水循环 |
| 受热面 | 烟气与水汽换热所经的金属壁面 |
| 额定蒸发量 | 设计工况下每小时产汽量（t/h） |
| 额定工作压力 | 设计规定的出口蒸汽表压（MPa） |
| 锅炉热效率 | 有效利用热与输入热量之比 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「锅炉 = 烧水的大壶」 | 锅炉是承压热力设备，水汽与烟气两系统经受热面换热 |
| 「蒸发量想烧多少烧多少」 | 额定蒸发量是设计上限，超负荷带水、超温 |
| 「汽包水位越高越安全」 | 正常水位在中心线略下，过高淹没汽水分离器 |
| 「排烟温度越低越好」 | 过低尾部结露腐蚀，要留设计余量 |
| 「压力表读数是绝压」 | 工程压力表读表压，热力计算才用绝压 |
| 「自然循环也要循环泵」 | 靠密度差驱动，无需额外泵 |

### 记忆口诀

- 锅装水、炉生火，受热面来分家。
- 水循环：给水→省煤器→汽包→下降管→水冷壁→汽包。
- 烟气走：炉膛→过热器→对流管束→省煤器→空预器→排烟。
- 效率 = 有效热 ÷ 输入热，调风就是调效率。
- 铭牌四数：蒸发量、压力、汽温、给水温度。

## 8 小结

- 锅炉 = **「锅」（汽水系统）+「炉」（燃烧系统）**，二者通过受热面换热，水汽与烟气互不接触。
- **自然循环**靠水冷壁与下降管的密度差驱动，不需额外泵。
- 工质流程：给水 → 省煤器 → 汽包 → 下降管 → 水冷壁（汽化）→ 汽包 →（过热器）→ 蒸汽出口。
- 烟气流程：炉膛 → 过热器 → 对流管束 → 省煤器 → 空气预热器 → 排烟，温度逐级下降。
- **锅炉热效率** $\eta = \frac{D(h''-h')}{BQ_{\text{net}}}$，是衡量燃料利用率的总指标，司炉工调风的本质是优化它。
- 铭牌上的**额定蒸发量、额定工作压力、额定蒸汽温度、给水温度**是运行与选型的基准。

在下一节，我们将回答「这台锅炉叫什么」——不同压力、不同结构、不同燃料的锅炉怎么分类、型号怎么读。这是选型、操作与持证上岗的第一个前提。
