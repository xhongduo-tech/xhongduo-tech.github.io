## 为什么从水质开始

构造、分类、燃料都认识了，现在轮到「水」。司炉工有一句老话：**锅炉的事故，一半出在火上，一半出在水上。** 水看起来温和，但在锅炉里它扮演着三个角色：被加热的工质、带走热量的媒介，以及——如果不处理——结垢与腐蚀的原料。

上一节讲燃料时我们提过，水管锅炉对水质要求苛刻。这一节我们把「水质」这件事彻底讲透：水不好会闯什么祸，水里哪些指标要盯，炉外炉内两道处理防线怎么搭，以及排污这笔账怎么算。<span class="marginnote">水质处理不是可有可无的「锦上添花」，而是锅炉受监管的法定项目——TSG G0001 明确要求使用单位按标准进行水处理，配水处理作业人员（G3），水质不合格的锅炉可以责令停用。</span>

## 1 水质不良的三笔账：结垢、腐蚀、汽水共腾

水不处理就进锅炉，至少要付三笔账：

**结垢**：水中钙、镁离子受热浓缩析出，在受热面上结出水垢。水垢的导热系数只有 0.1 ~ 0.5 W/(m·K)，是钢材（约 45 W/(m·K)）的百分之一上下。<span class="marginnote">直观后果：1 mm 厚的水垢，传热热阻相当于 40 mm 左右的钢材。金属壁温被憋高，过热烧损、鼓包、爆管接踵而来。</span>
- **腐蚀**：溶解氧与酸性物质攻击金属壁，造成氧腐蚀、垢下腐蚀与碱腐蚀。腐蚀使壁厚减薄，承压能力下降。
- **汽水共腾**：锅水含盐量过高时，水面起大量泡沫，蒸汽把泡沫与水珠一起带走，蒸汽品质恶化，过热器结盐、用汽设备受损。这是我们在第3篇要专门处理的事故，成因就在水质。

三笔账的共同结局是：**受热面寿命缩短、效率下降、事故风险上升**。而它们全部可以靠合格的水处理避免。

## 2 六个水质指标认识一遍

衡量锅炉水质的核心指标有六个，司炉工不必记下每个数字，但必须知道每个指标管什么：

| 指标 | 含义 | 超标后果 | 常见控制手段 |
| --- | --- | --- | --- |
| **总硬度** | 钙、镁离子总量 | 结垢 | 软化处理 |
| **碱度** | 水中氢氧根、碳酸根等 | 过高加剧碱腐蚀与共腾 | 排污、调整加药 |
| **pH 值** | 酸碱性 | 过低酸腐蚀、过高碱脆 | 加碱调 pH |
| **溶解氧** | 水中溶解的氧 | 氧腐蚀（点蚀） | 除氧 |
| **含盐量** | 溶解固形物总量 | 汽水共腾、蒸汽带盐 | 排污 |
| **悬浮物/浊度** | 泥砂、胶体 | 堵管、结泥垢 | 澄清、过滤 |

其中**硬度**是入门者最先要盯的指标。它的单位是 mmol/L（以 $\ce{1/2Ca^{2+}}$、$\ce{1/2Mg^{2+}}$ 计），对应旧习惯里的「毫克当量/升」——数值不变，只是换了叫法。给水的总硬度若超标，锅炉结垢几乎不可避免。

我国《工业锅炉水质》标准（GB/T 1576）对蒸汽锅炉给水与锅水的各项指标都给出限值，例如给水总硬度一般要求不超过 0.030 mmol/L，锅水 pH 一般控制在 10 ~ 12。**具体数值以现行标准为准**——考司炉工证和日常化验时，对照标准查表是基本功。

## 3 炉外水处理：离子交换软化与除氧

水处理分两道防线。**第一道在锅炉外**，让「进水」先变干净：

**离子交换软化**是工业锅炉最常用的软化手段。钠离子交换器里装填钠型阳离子交换树脂，硬水流过时，钙镁离子被树脂吸附，钠离子被置换出来：

$$\ce{2RNa + Ca^{2+} -> R2Ca + 2Na+}$$

树脂吸饱钙镁后失去软化能力，需要用食盐水**再生**，把吸附的钙镁离子洗下来、换回钠离子，如此循环使用。<span class="marginnote">再生反应是上式的逆过程：$\ce{R2Ca + 2NaCl -> 2RNa + CaCl2}$。所以软化器运行久了要「反洗—再生—正洗」，树脂的交换能力才能恢复——这套工序是水处理工（G3）的日常。</span>

**除氧**针对溶解氧：额定蒸发量较大的锅炉要求给水除氧。常用**热力除氧**（把水加热到接近沸点，赶走溶解氧）或加化学药剂（如亚硫酸钠）消耗残余氧。

## 4 炉内加药与排污：两条防线

即使炉外处理到位，少量残余的钙镁离子与浓缩效应仍会让锅水慢慢「变坏」，所以还要有**第二道防线——炉内**：

**炉内加药处理**：向锅水中加入碳酸钠、磷酸三钠等药剂，让残余的钙镁离子生成松散泥渣（而不是坚硬水垢），随排污排出。注意，加药只是「兜底」，不能替代软化——只加药不软化的锅炉照样结垢。

**排污**是司炉工亲手做的动作，分两种：

**连续排污（表面排污）**：从锅水水面附近连续排走含盐浓度最高的表面水，控制含盐量与碱度，防汽水共腾。<span class="marginnote">锅水在汽包内不断浓缩，水面一层盐分最高。连续排污就从这个「最脏」的地方取水，一般引到排污扩容器回收热量，而不是白白放掉。</span>
- **定期排污（底部排污）**：从下集箱或锅筒底部定期快速排走沉积的泥渣与水垢，间隔几小时一次，动作是「开—关—开—关」的短促脉冲，把沉积物搅起来排走。

## 5 公式解析：排污率

排污要排多少？太少，锅水盐分压不住；太多，热量与水的浪费太大。这个比例用**排污率**量化。

$$\text{排污率 } p = \frac{D_p}{D} \times 100\%$$

其中 $D_p$ 是排污水量，$D$ 是蒸发量。运行中很难直接量排污量，于是用盐量平衡反推：锅水含盐量稳定时，**给水带进的盐 = 排污带走的盐**（合格蒸汽带盐量极小，忽略不计）。

$$p = \frac{S_g}{S_b - S_g} \times 100\%$$

三步拆解：

- **第一步，认清三个量**：$S_g$ 是给水含盐量，$S_b$ 是锅水允许含盐量（即水质标准上限），$p$ 是排污率。
- **第二步，理解平衡式**：锅水浓度稳定 = 进来的盐和出去的盐一样多。给水把 $S_g$ 带进来，排污把高浓度的 $S_b$ 带出去，于是 $S_g(D + D_p) = S_b D_p$，整理即得上式。
- **第三步，代入感受量级**：若给水含盐量 300 mg/L、锅水允许 3000 mg/L，则 $p = 300/(3000-300) \approx 11\%$——也就是说，每蒸发 100 kg 蒸汽，要排掉约 11 kg 锅水。<span class="marginnote">排污率太高是浪费：排污带走的是已经加热到锅水温度的水和热量。工程上会设法提高给水品质（降低 $S_g$）来压低排污率——给水越干净，排污越省，锅炉越经济。</span>

**辨析｜易错点：** 排污阀要「勤排、少排、快排」，严禁长时间小开度慢排——那样排不净底部泥渣，还可能把排污阀磨损关不严。定期排污要在低负荷时进行，且每次只开一个排污点，避免锅水被大量放空导致缺水。

## 6 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 总硬度 | 水中钙、镁离子总量 |
| 碱度 | 水中氢氧根、碳酸根等含量 |
| 溶解氧 | 水中溶解的氧，除氧对象 |
| 含盐量 | 水中溶解固形物总量 |
| 离子交换 | 树脂吸附钙镁、置换钠离子的软化法 |
| 再生 | 用食盐水恢复树脂交换能力 |
| 连续排污 | 从水面排走高浓度锅水 |
| 定期排污 | 从底部排走泥渣沉积物 |
| 排污率 | 排污水量占蒸发量的百分比 |
| GB/T 1576 | 《工业锅炉水质》国家标准 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「加药就能代替软化」 | 加药只是兜底，不软化照样结垢 |
| 「排污阀小开度慢排省水」 | 要开—关—开—关脉冲快排，慢排排不净还磨损 |
| 「水质化验是水处理工的事」 | 司炉工要懂指标含义，配合排污与加药 |
| 「排污越多越干净」 | 排污率太高浪费热量与水，给水越干净排污越省 |
| 「软化器不用再生」 | 树脂吸饱失效，需食盐再生恢复 |
| 「锅水 pH 越高越防腐蚀」 | pH 过高引发碱腐蚀，定在 10～12 窗口 |

### 记忆口诀

- 三害源头在水质：垢、蚀、共腾一锅端。
- 六指标：硬度碱度 pH、溶氧盐量悬浮物。
- 软化是减法（把钙镁换钠），加药是兜底，排污是清账。
- 排污率 p = S_g/(S_b − S_g)，给水净则排污省。
- 连续排表面、定期排底部，勤排少排快排。

## 7 小结

- 水质不良的三笔账：**结垢、腐蚀、汽水共腾**，全都能靠合格水处理避免。
- 六个核心指标：**硬度、碱度、pH、溶解氧、含盐量、悬浮物**；水质标准以 GB/T 1576 为准。
- 炉外防线：**离子交换软化**（$\ce{2RNa + Ca^{2+} -> R2Ca + 2Na+}$）与**除氧**。
- 炉内防线：**加药兜底 + 连续排污（控盐）+ 定期排污（排渣）**。
- **排污率** $p = \dfrac{S_g}{S_b - S_g}$：给水越干净，排污越省。
