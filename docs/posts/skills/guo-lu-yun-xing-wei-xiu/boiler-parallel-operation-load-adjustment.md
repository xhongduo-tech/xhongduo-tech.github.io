## 为什么从并汽开始

上一节学会把一台炉的火烧稳。但锅炉房往往不止一台炉——供暖期两台炉一起烧，检修期一台顶着全厂的用汽。新点火的锅炉要从「孤军奋战」变成「汇入管网」，关键动作就是**并汽**。并汽并不好，轻则蒸汽倒灌、管道水击，重则带水的蒸汽把全厂用汽设备洗一遍。<span class="marginnote">并汽在操作逻辑上很像两辆车并入同一条高速：速度（压力）必须接近、方向（汽质）必须合格、时机（水位）必须恰当——三样不对齐，强行并线必出事故。</span>

这一节我们讲并汽的条件、操作，以及并汽之后最日常的动作——**负荷调整**。

## 1 并汽：让新锅炉「上车」

**并汽（parallel operation）**：把升压完毕的锅炉与运行中的蒸汽母管连通，使多台锅炉并列供汽。它是多炉锅炉房的常规操作，也是单炉系统检修后重新投入的第一步。

并汽的实质是**把两个压力源接到同一根管子上**。如果两边压力相差悬殊，压力高的一侧会向低的一侧倒汽——这正是并汽事故的根源。

## 2 并汽前的四个条件

升压到位的锅炉还不能立刻并汽，必须逐条核对四个条件：

1. **汽压接近母管压力**：锅炉汽压应**略低于母管压力**（一般低 0.05～0.1 MPa）。<span class="marginnote">为什么要「略低」而不是「相等」？开阀瞬间，锅炉侧压力略低，蒸汽只会从母管向锅炉轻微倒流、再被锅炉顶回去，不会猛烈冲击；若锅炉压力高于母管，开阀瞬间大量蒸汽猛灌母管，水击与压力冲击都会找上门。</span>
2. **汽温合格**：过热蒸汽锅炉，过热汽温应接近额定值，防止低温蒸汽进入母管使管壁骤冷。
3. **水位正常且略低**：并汽后负荷上升、汽压上升，水位会相应下降，所以并汽前水位宜在正常水位**稍低处**留出余量。
4. **蒸汽品质合格**：按规程取样化验，含盐量、碱度合格，不带水不带盐——不合格的蒸汽进母管，等于把污染扩散给全厂用汽设备。

**重点：四条件缺一不可。** 尤其是蒸汽品质，肉眼看不见，最容易糊弄过去——可它直接决定母管里所有用户的蒸汽质量。

## 3 并汽操作与暖管

并汽的操作顺序，每一步都踩在前一步的基础上：

1. **暖管**：开启主汽阀的**旁路阀**（或微开主汽阀），让少量蒸汽缓慢预热从锅炉到母管的这一段管道，排净凝结水，防止水击。<span class="marginnote">暖管判据：管道温度均匀上升、疏水阀排出连续蒸汽、没有「咚、咚」的撞击声，说明管子热透了。暖管时间宁长勿短——这是上次升压时强调过的老规矩。</span>
2. **开主汽阀**：暖管完成后，缓慢开启主汽阀，让锅炉与母管逐渐连通。
3. **关旁路阀**：主汽阀全开后关闭旁路阀，完成并汽。
4. **观察稳定**：并汽后 10～15 分钟密切观察汽压、水位、母管压力，确认三表稳定后，方可逐步加负荷。

**辨析｜易错点：** 并汽时不要一次把主汽阀开到最大。阀门开太快，蒸汽涌入母管的瞬间压力波动大；正确做法是「慢开、分级、看表」——开一点、停一停、看压力与水位平稳了，再继续开。

## 4 公式解析：负荷调整的本质

并汽成功后，司炉工每天的主要工作就是**跟着负荷走**。负荷调整的本质，从效率公式可以一眼看穿——蒸发量由燃料量决定：

$$D = \frac{B\,Q_{\text{net}}\,\eta}{h'' - h'}$$

三步拆解：

- **第一步，看分子**：$B$ 是燃料量，$Q_{\text{net}}$ 是燃料低位发热量，$\eta$ 是锅炉热效率——三者相乘，是燃料真正「送进蒸汽里」的热量。
- **第二步，看分母**：$h'' - h'$ 是每公斤蒸汽从给水到成品吸收的热量，即「把水变成汽的单耗」。
- **第三步，看结论**：想多出汽（增大 $D$），要么加燃料（$B$↑），要么提效率（$\eta$↑），要么降单耗（比如用热回收预热给水）。**所以负荷调整的操作对象是燃料量与风量，而不是直接去拧蒸汽阀。**<span class="marginnote">有人误以为「开大主汽阀就能多供汽」——不对。主汽阀只决定「出口流量上限」，真正决定蒸发量的是炉膛里烧了多少燃料。负荷增加时，司炉工的第一动作是加煤加风，而不是动阀。</span>

操作上，负荷调整与配风纪律一致：**增负荷先加风后加煤，减负荷先减煤后减风**；且每次调整幅度小、观察时间长，让汽压、水位、燃烧逐步跟上，避免参数大起大落。

## 5 并列运行的负荷分配

多台锅炉并列运行时，**母管压力**是唯一的「指挥棒」：它由总供汽与总用汽的平衡决定，各台炉只能「跟着走」。

**汽压偏高**（母管压力高于设定值）：总产汽多于用汽，各炉按调度**减负荷**。
**汽压偏低**：总产汽不足，各炉**增负荷**。
**负荷分配原则**：让效率高、状态好的炉多带负荷，效率低或临近检修期的炉少带；避免各炉忽高忽低，尽量稳定在各自的经济负荷区间。<span class="marginnote">并列运行的「经济调度」是个老课题：几台炉以不同的组合分配负荷，总煤耗不一样。效率高的炉多烧一点、效率低的炉少烧一点，整体更省——这是第4篇《节能减排》要细算的账。</span>

**辨析｜易错点：** 并列运行时，别只看自己这台炉的汽压表——你压住自己的汽压没用，母管压力才是全体共用的基准。调负荷要看母管压力 + 自己的负荷指令，两相对照再动手。

## 6 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 并汽 | 把升压完毕的锅炉与运行中蒸汽母管连通 |
| 母管 | 多台锅炉共用、向用户供汽的蒸汽总管 |
| 旁路阀 | 主汽阀旁的小阀，用于并汽前暖管 |
| 蒸汽品质 | 蒸汽的纯净程度，含盐量、带水量的综合 |
| 负荷分配 | 并列运行各炉按调度承担供汽量 |
| 蒸发量 | 每小时产生的蒸汽量（t/h） |
| 倒汽 | 压力高的一侧向压力低的一侧倒灌蒸汽 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「并汽时汽压越高越好」 | 应略低于母管压力，防倒汽与冲击 |
| 「开大主汽阀就多供汽」 | 蒸发量由燃料量决定，主汽阀只定出口上限 |
| 「并汽后马上满负荷」 | 需观察汽压、水位、母管稳定后再逐步加负荷 |
| 「各炉各看各的压力」 | 并列运行以母管压力为指挥棒，统一调度 |
| 「负荷调整看自己汽压表」 | 要对照母管压力与负荷指令，两相对照再动手 |
| 「减负荷先减风」 | 先减煤后减风，防炉膛过热与熄火 |
| 「并汽前不用化验蒸汽」 | 汽质不合格进母管，污染全厂用汽设备 |
| 「并汽一次开到位」 | 慢开分级看表，防母管压力骤变 |

### 记忆口诀

- 并汽四条件：汽压略低、汽温合格、水位略低、汽质合格。
- 并汽操作：暖管→慢开主汽阀→关旁路→观察稳定。
- 蒸发量 = 燃料 × 发热量 × 效率 ÷ 单耗。
- 调负荷：增负荷先加风后加煤，减负荷先减煤后减风。
- 并列运行听母管的「指挥棒」，高效炉多带、临修炉少带。
- 并汽后十分钟盯三表：汽压、水位、母管压力。
- 调负荷小步勤看，别让参数大起大落。

## 7 小结

- **并汽四条件**：汽压略低于母管、汽温合格、水位略低、蒸汽品质合格。
- 并汽操作：**暖管 → 慢开主汽阀 → 关旁路 → 观察稳定**。
- 负荷调整本质：**蒸发量 = 燃料量 × 发热量 × 效率 ÷ 单耗**，所以调负荷 = 调煤调风，而非拧蒸汽阀。
- 增负荷**先加风后加煤**，减负荷**先减煤后减风**，小幅多次、看表稳定。
- 并列运行以**母管压力**为指挥棒，负荷按「高效炉多带、临修炉少带」原则分配。
