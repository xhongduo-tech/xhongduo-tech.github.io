## 为什么从水灾开始

水位计、水位调节、假水位——前几节我们把「水」从原理讲到操作，这一节把这些知识全部用上，应对锅炉运行中最常见的三宗「水灾」：**缺水、满水、汽水共腾**。

这三件事性质完全不同：缺水是「水不够」的致命险情，满水是「水太多」的失稳事故，汽水共腾是「水变脏」的品质事故。但它们的共同点一样吓人——**都以「水位计异常」为第一信号，都要求司炉工在几分钟内做出正确判断与处置。**<span class="marginnote">把这三种事故放在一起学，是因为它们最容易互相混淆：水位计看不清，可能是真缺水、真满水，也可能是汽水共腾的水面沸腾。判断错一步，处置就错一生——本节要练的就是「一看便知、一处置就准」。</span>

## 1 缺水事故：最危险的一种

**缺水（low water）**：锅炉水位低于最低安全水位，甚至从水位计消失的工况。它是锅炉事故中危险程度最高的几种之一——水冷壁一旦露出水面，几分钟内就会过热鼓包、爆管，严重时引发爆炸。

**现象与信号**：

水位计水位低于最低安全水位，或完全不见水位；
汽压可能先升高（受热面露空、传热恶化）再下降；
- 炉膛内壁异常发亮、金属过热变色；
- 严重时听到炉管爆裂声。

**常见原因**：给水泵故障或给水压力不足；排污后忘关排污阀；水位计堵塞造成假显示（实际已缺水却以为有水）；自动给水调节失灵；负荷骤增而补水没跟上。

### 叫水法：分清轻微缺水与严重缺水

水位计不见水位时，第一步不是盲目补水，而是**叫水**——判断水位到底在哪儿：

1. **关闭水位计汽阀**：切断与汽空间的通路；
2. **微开（或开）放水阀**：让水从水侧流入水位计；
3. **观察**：若水位计中有水出现，说明锅筒水位仍在水位计水阀以上，属**轻微缺水**；若叫水后仍不见水，说明水位已低于水阀，属**严重缺水**。<span class="marginnote">叫水法只在水位计「看不见水位」时使用，且前提是水位计的水路没堵。若水阀已堵，叫水叫来的可能是空气，判断就会失真——所以平时冲洗水位计、保持通路畅通，是这一招能救命的前提。</span>

**处置**：

**轻微缺水**：缓慢、少量向锅炉补水，同时加强监视、查明缺水原因（排污阀、给水系统）；严禁猛开给水。
**严重缺水**：**严禁向锅炉进水！** 立即按紧急停炉处理——停料、停风、解列，等炉体自然冷却后查明原因再恢复。<span class="marginnote">这条铁律在《紧急停炉》一节已强调：严重缺水时水冷壁已过热烧红，一进水就是剧烈的骤冷汽化，等于引爆炸弹。宁可让炉子冷却停工，不可一水激起千层「爆」。</span>

## 2 满水事故：水太多的麻烦

**满水（high water）**：水位高于最高安全水位，甚至充满汽空间的工况。满水看着比缺水「温和」，但它让蒸汽大量带水，同样能闯祸——水击、过热器结盐、用汽设备受损。

**现象与信号**：

水位高于最高安全水位，水位计全满；
过热蒸汽温度明显下降；
- 蒸汽管道发出水击声、法兰处冒汽；
- 严重时蒸汽带水，用汽设备出力骤降。

**常见原因**：给水过多或自动给水失灵；水位计显示偏低（假水位），司炉工误判而过度补水。

**处置**：立即**停止给水**，开启排污阀把水位放至正常水位；查明并处理给水系统问题；若蒸汽已严重带水，应将锅炉解列，开启过热器与蒸汽管道疏水，待蒸汽品质合格后再恢复供汽。

**辨析｜易错点：** 满水与缺水的第一反应**截然相反**——缺水（严重）严禁进水，满水则要先停水。判断依据是水位计与叫水法，绝不能凭「感觉水位不对」就乱动给水阀。

## 3 汽水共腾：水变脏的品质事故

**汽水共腾（priming / foaming）**：锅水含盐量或碱度过高，水面产生大量泡沫，蒸汽携泡沫与水珠一起带走的工况。它不像缺水满水那样「水位错了」，而是**水位计剧烈波动、看不清真实水位**，同时蒸汽品质急剧恶化。

**现象与信号**：

- 水位计水面激烈波动，水位模糊难辨；
- 过热蒸汽温度骤降；
- 蒸汽带水带盐，管道水击，用汽设备结盐；
- 化验锅水发现含盐量、碱度严重超标。

**常见原因**：锅水浓缩过度（排污不足）；加药过量；负荷骤增引起水面剧烈汽化；给水含盐量过高。

**处置**：

1. **降低负荷**：减轻水面扰动，给汽水分离创造条件；
2. **加强排污**：连续排污开大，必要时辅以定期排污，同时补充合格给水，把高浓度锅水**置换**出去；<span class="marginnote">置换的思路来自《水质处理》的排污率公式：排污排掉高含盐量锅水、补水补进低含盐量给水，锅水浓度就降下来了。处置汽水共腾，本质就是在现场「跑一遍排污率的生意」。</span>
3. **监视汽质**：过热蒸汽温度回升、水位稳定后，逐步恢复负荷；
4. **严重时解列**：蒸汽品质持续不合格，应解列锅炉，处理锅水合格后再并汽。

**预防**在平时：按时排污、加药适度、控制锅水含盐量与碱度——上一节《水质处理》的全部功夫，就是为此刻少出事。

## 4 三事故对比：一张表分清

| 对比项 | 缺水 | 满水 | 汽水共腾 |
| --- | --- | --- | --- |
| 水位表现 | 低于最低线或不见 | 高于最高线或全满 | 剧烈波动、模糊不清 |
| 蒸汽温度 | 可能升高后降 | 下降 | 骤降 |
| 蒸汽管道 | 无特殊 | 水击、冒汽 | 水击、带盐 |
| 首要原因 | 给水不足、排污忘关 | 给水过多 | 锅水含盐/碱度过高 |
| 第一动作 | 叫水法判断 | 停止给水 | 降低负荷 |
| 关键处置 | 轻微缓慢补水；**严重严禁进水、紧急停炉** | 排污放水至正常 | 加强排污置换 |
| 红线 | 严重缺水进水 = 爆炸 | 停水顺序错误 | 不排污只加负荷 |

**重点：三件事的共同纪律是「先判断、后处置」。** 缺水的进水里、满水的排污里、共腾的置换里，藏着截然相反的操作——误判一次，代价就是整台锅炉。

## 5 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 缺水 | 水位低于最低安全水位的工况 |
| 满水 | 水位高于最高安全水位的工况 |
| 汽水共腾 | 锅水浓度过高、水面起泡、蒸汽带水带盐 |
| 叫水法 | 判断缺水程度的水位计操作方法 |
| 轻微缺水 | 叫水后水位可见，可谨慎补水 |
| 严重缺水 | 叫水后仍不见水位，严禁进水 |
| 蒸汽带水 | 蒸汽携带水珠，品质恶化 |
| 置换 | 排污+补水把高浓度锅水换成合格水 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「水位看不见就是缺水」 | 可能是满水全满或共腾波动，先判断后处置 |
| 「缺水就赶紧加水」 | 严重缺水严禁进水，先叫水判断轻重 |
| 「满水先排污再说」 | 满水第一动作是停给水，再排污放水 |
| 「共腾时加负荷冲冲」 | 共腾要降负荷、加强排污置换 |
| 「共腾排完就恢复」 | 要等蒸汽温度回升、水位稳定再逐步恢复 |
| 「三种事故处置一样」 | 缺水禁水、满水停水、共腾置换，方向相反 |

### 记忆口诀

- 三水灾看水位计：不见（缺水）、全满（满水）、乱跳（共腾）。
- 叫水法：关汽阀、开放水阀，见水轻、不见重。
- 严重缺水禁进水，炉冷查明再恢复。
- 满水停给水、排污放水；共腾降负荷、排污置换。
- 先判断后处置，误判一次毁全炉。

## 6 小结

- **缺水**：最危险，用**叫水法**分清轻重；轻微缺水缓慢补水，**严重缺水严禁进水、紧急停炉**。
- **满水**：停给水、排污放水至正常水位，蒸汽带水时解列疏水。
- **汽水共腾**：锅水浓度过高所致，降负荷、加强排污置换、监视汽质，严重时解列。
- 三种事故都以**水位计异常**为第一信号，处置方向截然相反，**先判断、后处置**。
- 预防根本都在平时：排污到位、水质合格、水位计保持真实畅通。
