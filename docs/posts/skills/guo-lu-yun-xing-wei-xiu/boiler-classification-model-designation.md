## 为什么从分类开始

上一节我们认识了锅炉的构造：锅筒、水冷壁、省煤器……但「锅炉」是一个很大的家族。一台供暖用的 0.7 MW 热水锅炉，与一座电厂 1000 MW 超超临界机组，虽然都叫「锅炉」，构造、操作、安全管理却天差地别。<span class="marginnote">司炉工取证的分级逻辑就藏在分类里：持「工业锅炉司炉（G1）」证的人不能去操作电站锅炉，反过来电站锅炉司炉（G2）操作工业锅炉也有严格限制——先会分类，才知道自己的证管哪台炉。</span>

在第六级《热能工程（锅炉与热力发电）》里，这些类别会升级为严谨的热力系统对比；今天我们要学会的是技师视角的「见名知类」：看一眼铭牌型号，立刻说出它烧什么、多高压力、什么结构。这是选型、配风、报检、取证的前提。

## 1 按压力分类：从低压采暖到超临界

压力是锅炉最重要的分类轴，因为它直接决定蒸汽温度、金属强度与安全监管级别。<span class="marginnote">记忆锚点：水的临界压力是 22.1 MPa（绝压）。压力超过临界点后，水和蒸汽不再有分界线，直接进入超临界状态——这是分类表的「天花板」。</span>

| 类别 | 额定出口压力（表压，MPa） | 主要用途 |
| --- | --- | --- |
| 低压锅炉 | ≤ 2.5 | 工业与民用采暖、生产用汽、热水供应 |
| 中压锅炉 | 2.5 ~ 3.9 | 中型自备电站、区域供热站 |
| 高压锅炉 | 约 9.8 | 火电厂主力机组 |
| 超高压锅炉 | 约 13.7 | 大型火电机组 |
| 亚临界锅炉 | 约 16.7 | 大型火电机组 |
| 超临界锅炉 | ≥ 22.1 | 高效超临界机组 |

**重点：工业锅炉几乎全部落在「低压」一档。** 司炉工日常面对的，是 0.7、1.0、1.25、1.6 MPa 这几个常见压力等级——它们对应着 0.7 t/h 到 35 t/h 不等的蒸发量。理解这一点，你就知道为什么后面讲的安全阀整定、水压试验压力都以「1.0 MPa 级锅炉」为例。

## 2 按结构与水循环分类：火管、水管与水火管

结构决定了一台锅炉「水在哪里走、火在哪里走」，也决定了它的脾气。

**火管锅炉（锅壳式）**：烟气在管内流动，水在管外的大锅壳里。早期蒸汽机车的锅炉就是典型。结构简单、水容积大、对水质要求相对宽松，但受锅壳承压限制，压力一般不超过 2.5 MPa。<span class="marginnote">水容积大 = 蓄热多：负荷骤变时汽压波动小，但点火升压慢、整体笨重。同功率下，火管锅炉往往比水管锅炉大一圈。</span>
**水管锅炉**：水在管内流动，烟气在管外冲刷。承压能力强、受热面布置灵活、热效率高，是中大型锅炉的主流。<span class="marginnote">水管锅炉对水质要求苛刻：管子细、水流快，一旦结垢就局部过热爆管——这就是为什么水质处理在司炉工课程里单独成篇。</span>
**水火管锅炉**：卧式快装水火管锅炉（如 DZL 型）把两者结合起来，锅筒内布置烟管、锅筒外布置水冷壁，结构紧凑、占地小，是中小型快装锅炉的常见形态。

按水循环方式又分两类：

| 循环方式 | 驱动力 | 特点 | 典型型号前缀 |
| --- | --- | --- | --- |
| 自然循环 | 密度差 | 结构简单、运行可靠 | DZ、SH、SZ |
| 强制循环 | 循环泵 | 布置紧凑、不受高度限制 | QX |

## 3 按燃烧方式与用途分类

**燃烧方式是第二把尺子**，它决定司炉工怎么烧：

**层燃炉（炉排炉）**：块状煤铺在炉排上燃烧。固定炉排（手烧）、链条炉排、往复炉排都属于此类，是工业锅炉最常见的烧煤方式。<span class="marginnote">链条炉排像一条慢慢前进的「传送带」：煤从炉前落上炉排，边前进边燃烧，烧完的灰渣在炉尾排掉——司炉工调节煤层厚度与炉排速度，就是在管这条带子的燃烧节奏。</span>
- **室燃炉（悬浮燃烧）**：煤粉、燃油或燃气通过燃烧器喷入炉膛，在空间内悬浮燃烧。燃烧强度大、效率高，但需要精细的风油配比。
- **流化床锅炉（沸腾炉）**：煤粒在向上气流中呈沸腾状态燃烧，燃料适应性极强，可烧劣质煤与煤矸石。

**按用途分类**则是最朴素的一刀切：

| 类型 | 工质与参数 | 典型用途 |
| --- | --- | --- |
| 蒸汽锅炉 | 输出蒸汽，看压力与温度 | 生产用汽、发电、消毒灭菌 |
| 热水锅炉 | 输出热水，看出水/回水温度 | 供暖、生活热水 |
| 有机热载体锅炉 | 输出高温导热油 | 化工、印染等工业加热 |

**辨析｜易错点：** 热水锅炉型号里没有「蒸发量」，而是**热功率（MW）**；它的安全监控重点是出水温度与回水温差，而不是汽包水位——把蒸汽锅炉的操作习惯搬到热水锅炉上，是新手常犯的第一类错误。

## 4 型号编制解析：读锅炉的名字

我国工业锅炉型号按 JB/T 1626《工业锅炉产品型号编制方法》编排，由三部分组成、用短横线相连：

$$\underbrace{\text{型式代号}\text{燃烧设备}\text{蒸发量}}_{\text{第一部分}}-\underbrace{\text{压力}/\text{温度}}_{\text{第二部分}}-\underbrace{\text{燃料代号}\text{设计次序}}_{\text{第三部分}}$$

以最常见的 **DZL4-1.25-AⅡ** 为例，四步拆开读：

- **第一步，DZ——锅筒型式**：单锅筒纵置式。对应代号还有 SH（双锅筒横置）、SZ（双锅筒纵置）、WN（卧式内燃）、LH（立式火管）、QX（强制循环）等。
- **第二步，L——燃烧设备**：链条炉排。其他常见代号：G（固定炉排）、W（往复炉排）、P（抛煤机）、Y（燃油）、Q（燃气）。<span class="marginnote">代号 Q 在这里有歧义风险：它既是燃烧设备「燃气炉」的代号，又在燃料一栏代表「天然气」。读型号要按位置读——第一部分的 Q 是燃烧方式，第三部分的 Q 是燃料种类。</span>
- **第三步，4-1.25——蒸发量与压力**：额定蒸发量 4 t/h，额定蒸汽压力 1.25 MPa。若为过热蒸汽，第二部分的写法是「压力/过热蒸汽温度」，如 2.5/400。
- **第四步，AⅡ——燃料与设计次序**：Ⅱ类烟煤；若是燃油燃气锅炉则写 Y 或 Q。设计次序数字接在燃料代号后，第 1 次设计省略、从第 2 次起写 2、3…

再看一个热水锅炉：**WNS1.4-0.7/95/70-Q**，意为卧式内燃室燃（WNS），热功率 1.4 MW，额定出水压力 0.7 MPa，出水温度 95°C、回水温度 70°C，燃气。这里「95/70」就是热水锅炉特有的出水/回水温度。

## 5 本节速查：术语、误区与口诀

### 术语速查表

| 术语 | 含义 |
| --- | --- |
| 火管锅炉 | 烟气在管内流动、水在管外的锅壳式锅炉 |
| 水管锅炉 | 水在管内流动、烟气在管外冲刷的锅炉 |
| 自然循环 | 靠密度差驱动的水循环 |
| 强制循环 | 靠循环泵驱动的水循环 |
| 层燃炉 | 块煤铺在炉排上燃烧的锅炉 |
| 室燃炉 | 燃料悬浮在炉膛空间燃烧的锅炉 |
| 流化床锅炉 | 煤粒在气流中沸腾燃烧的锅炉 |
| 热水锅炉 | 输出热水的锅炉，看热功率与水温 |
| 有机热载体锅炉 | 输出高温导热油的锅炉 |
| 型号编制 | 用代号表示锅炉型式、参数与燃料的规则 |

### 常见误区辨析

| 误区 | 正解 |
| --- | --- |
| 「型号第一部分都一样」 | 锅筒型式、燃烧设备、蒸发量各不相同 |
| 「热水锅炉也看蒸发量」 | 热水锅炉看热功率 MW 与出水/回水温度 |
| 「G2 能顶 G1 用」 | 电站与工业锅炉操作范围不同，各管各的 |
| 「压力越高越先进」 | 压力等级对应用途，工业锅炉普遍低压 |
| 「火管锅炉比水管差」 | 各有适用：火管蓄热大、水质要求松，但压力受限 |
| 「同一台炉什么燃料都能烧」 | 燃烧方式不同，层燃/室燃/流化床各有燃料适配 |

### 记忆口诀

- 型号三部分：型式燃烧蒸发量 / 压力温度 / 燃料次序。
- DZL4-1.25-AⅡ：单锅筒纵置、链条炉排、4 t/h、1.25 MPa、Ⅱ类烟煤。
- 火管水在管外、水管水在管内，水火管是杂交。
- 层燃铺开烧、室燃喷细烧、流化床腾着烧。
- 先分清蒸汽炉还是热水炉，再读参数。

## 6 小结

- 锅炉按压力分低压、中压、高压、超高压、亚临界与超临界；**工业锅炉几乎都是低压（≤ 2.5 MPa）**。
- 按结构分**火管、水管、水火管**；按水循环分**自然循环与强制循环**。
- 按燃烧方式分**层燃、室燃、流化床**；按用途分**蒸汽锅炉、热水锅炉、有机热载体锅炉**。
- 工业锅炉型号 = 型式代号 + 燃烧设备 + 蒸发量 + 压力/温度 + 燃料代号 + 设计次序。
- **读型号先分清蒸汽锅炉还是热水锅炉**：蒸汽锅炉看蒸发量与压力，热水锅炉看热功率与出水/回水温度。
