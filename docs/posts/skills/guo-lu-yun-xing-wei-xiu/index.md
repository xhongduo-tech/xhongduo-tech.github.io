# 锅炉运行与维修（司炉工）

工业锅炉是供暖、生产与生活用热的核心动力设备，司炉工作为持证上岗的法定特殊工种，需系统掌握锅炉运行操作、水位压力监控、燃料燃烧调节、停炉保养与故障处理等完整技能。以《国家职业技能标准—锅炉操作工》、TSG G0001《锅炉安全技术监察规程》与《锅炉运行与维护》为纲，学完即覆盖司炉工考证上岗所需的全部理论与实操能力。
