# 消防设施操作与维保（消防设施操作员）

以《消防设施操作员国家职业技能标准（2019年版）》《消防设施操作员基础知识》与 GB 25506《消防控制室通用技术要求》为纲，系统重建从职业基础、消防法规、消防控制室值守到火灾自动报警、自动喷水灭火、气体灭火系统操作与维保的完整持证能力链。学完这些章节，就写完了消防设施操作员监控操作与检测维修保养两个方向的全部内容。

## 对标教材

- 《消防设施操作员国家职业技能标准（2019年版）》
- 《消防设施操作员基础知识》（中国劳动社会保障出版社）
- GB 25506《消防控制室通用技术要求》
