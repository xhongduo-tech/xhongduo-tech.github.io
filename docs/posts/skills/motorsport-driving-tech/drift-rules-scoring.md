## 为什么从漂移规则开始

前面几节把漂移的物理、车辆、技术讲了个遍——但漂移首先是一门**竞赛运动**，参赛者要比的从来不是「谁滑得远」，而是「谁滑得对」。漂移比赛的判罚体系与场地赛完全不同：场地赛以「最快冲线」论英雄，漂移赛以**线路、角度、速度、风格**四个维度打分。不懂评分规则，你练再多的定圆也上不了领奖台。

这一节讲漂移赛事的两种形态（单走与追走）、四维评分体系、违规判罚与车辆技术规则。这套规则语言来自 CAMF《汽车比赛规则》漂移篇，其精神与日本 D1、美国 Formula Drift 等国际漂移赛事的评分理念一致——**用规则把「主观的美感」翻译成「可判罚的客观标准」**。

## 1 漂移比赛的形态：单走与追走

### 单走（single run）

车手单独完成规定赛道（通常含多个评分弯），由裁判打分。单走是排位赛与入门组的主要形式，考察车手的基本功。

### 追走（twin run / battle）

两名车手**同场先后出发**，前车（leader）带线、后车（chaser）跟飘。后车要**尽可能贴近前车**，并模仿其走线；前车要**做出足够的线路与角度**，不让后车轻易贴上。两轮交换位置后，裁判判出胜者。

**核心要点：追走是漂移比赛的最高形态**——它同时考验前车的「制造难度」与后车的「贴附能力」，是技术与勇气的直接对抗。

### 比赛组织：资格赛与淘汰赛

正规漂移赛事按「资格赛 → 淘汰赛」组织：

1. **资格赛（qualifying）**：车手依次单走，裁判按四维评分排名——成绩靠前的车手进入正赛，并按名次决定对阵表；
2. **淘汰赛（bracket）**：按对阵表两两进行追走对决，胜者晋级下一轮，直至决出冠军；
3. **种子与对阵**：资格赛名次越高，对阵越有利（先面对较弱对手），所以单走的成绩并非只是「过关」，而是「抢种子」。

**核心要点：单走是「入场券」，追走是「淘汰赛」**——两套评分虽都用四维，但追走多了「贴近」这一维度，比赛风格完全不同。

## 2 评分体系：线路、角度、速度、风格

漂移的分数来自四个维度，缺一不可：

| 维度 | 看什么 | 得高分的关键 |
| --- | --- | --- |
| 线路（Line） | 车辆是否沿理想走线、贴近每个评分弯的弯心 | 贴弯心、不漂偏、不出界 |
| 角度（Angle） | 横摆角是否够大、是否稳定维持 | 大角度 + 稳定，不来回摆动 |
| 速度与流畅（Speed & Flow） | 是否保持速度、动作是否连贯 | 不中途减速、不中断漂移 |
| 风格与秀度（Style） | 烟雾、姿态、追走中的贴近距离 | 烟大、贴得近、姿态干净 |

<span class="marginnote">四维之间要「平衡」而不是「偏科」：<strong>一味追求大角度而丢了线路，或者贴弯心却角度不足，都拿不到高分</strong>。裁判打分的是「综合表现」，这也是为什么漂移高手要在练习中反复权衡「贴多近、斜多狠、跑多快」。</span>

### 单走与追走的对比

两种形态虽共用四维评分，侧重点不同，对照如下：

| 项目 | 单走 | 追走（battle） |
| --- | --- | --- |
| 考察对象 | 车手个人的基本功 | 前车制造难度 + 后车贴近能力 |
| 评分维度 | 线路、角度、速度、风格 | 前车四维 + 后车贴近度 |
| 时间压力 | 中 | 高（要跟上、要贴近） |
| 常见失误 | 漂移中断、出界 | 跟丢、碰撞、贴过头 |
| 对车手的要求 | 稳定、干净 | 稳定 + 侵略性与勇气 |

**核心要点：单走比「谁能滑得最标准」，追走比「谁能让对手更难受、谁更能贴住对方」**——前者是技术，后者是技术 + 心理。

### 追走的评分：前车与后车各考各的

追走中，前车与后车被分开评判：

- **前车**：按线路、角度、速度打分，且要「制造难度」——走线越贴近弯心、角度越大，后车越难贴；
- **后车**：按**贴近度**（与前车的距离）、跟随走线、自身姿态打分；
- **前车失误**：如果前车漂移中断、冲出赛道、打转，会扣前车分（后车可能因此胜出）；
- **后车失误**：如果后车跟不上、撞前车、或「贴过头」，扣后车分。

**易错点｜辨析：** 追走里最常见的误解是「后车贴得越近越好」。贴近确实是得分点，但**后车还要保持自己的走线与姿态**——一味贴太近导致撞车或出界，失分远比「贴得远一点」严重。追走的精髓是「贴近而不碰撞」，像影子一样跟随。

## 3 违规与判罚

漂移比赛对「失控」有明确的判罚标准：

- **打转（spin）**：车辆横摆角超过 360° 或完全失控，该次评分段基本作废；
- **出界（line off）**：车轮完全驶出赛道边界或规定的评分线，扣分或取消该段成绩；
- **碰撞（contact）**：追走中后车顶撞前车、或车手之间发生接触，判罚通常严厉（可能直接判负）；
- **中断漂移**：漂移过程中油门中断、转向回正，漂移状态终止，视为技术失误。

**核心要点：漂移的判罚逻辑是「以失控论英雄」的反面**——你越能接近失控而不失控，分越高；真正失控（打转、出界、碰撞），则分越低甚至出局。

### 追走的判定流程

一场追走对决如何判出胜负，流程大致如下：

1. **第一轮**：前车先发、后车跟飘，完成后两车交换角色，再进行第二轮；
2. **各自打分**：裁判分别对「前车表现」与「后车表现」打分，比较两轮的综合分；
3. **明显失误即判负**：如果后车撞前车、前车打转出界，失误一方通常直接被判负，不再纠结细节；
4. **平分加赛（one more time）**：两轮难分胜负时，可再跑一轮决胜。

**易错点｜辨析：** 追走判定里最容易让新手困惑的是「前车失误，后车也扣分吗？」——答案是不一定。如果前车失误导致后车无法贴近，通常判前车负；但如果后车本身也没有贴上去，则后车同样失分。**胜负看的是「相对表现」，不是「绝对分数」**。

## 4 车辆与技术规则

漂移组别的车辆规则既保证观赏性，也保证安全：

- **后轮驱动**：多数组别要求后驱车（RWD），保证漂移物理的前提；
- **安全改装**：防滚架、桶式座椅、六点式安全带、灭火系统、断电开关（master switch）是硬性要求；
- **轮胎与动力**：轮胎型号受规则限制（决定抓地与烟雾），动力系统须在安全范围内；
- **噪音与排放**：部分赛事对排气噪音有限制，超限可能被取消资格。

### 技术检查的流程

漂移车的技术检查通常在赛前与赛后分两步进行：

- **赛前车检**：确认车辆符合组别规则（驱动形式、轮胎、安全改装），不合格不能上场；
- **赛后复核**：对晋级与获奖车辆重点复查，防止「赛时违规」；
- **裁判的「目检 + 仪测」**：既有目测（防滚架、座椅固定、油管走向），也有仪器测量（重量、胎压、噪音分贝）。

**核心要点：技术检查与评分是两条独立的线**——一辆车可以「滑得漂亮」拿高分，但如果安全改装不过关，照样无法站上领奖台。规则先把「能不能参赛」说清楚，再谈「滑得好不好」。

<span class="marginnote">漂移车的安全改装为什么这么严格？因为<strong>漂移常在接近失控的状态下运行，冲出赛道、接触护栏的风险比场地赛更高</strong>。防滚架与六点安全带不是「竞技逼格」，而是「失控兜底」——先保证人在碰撞中的安全，再谈角度与烟雾。</span>

## 5 小结

- 漂移比赛分**单走**与**追走**：单走考基本功，追走考「制造难度 vs 贴近能力」的对抗。
- 评分四维：**线路、角度、速度、风格**，要平衡不要偏科。
- 追走中**前车制造难度、后车贴近跟随**，前车失误扣前车、后车失误扣后车。
- 判罚以失控为准绳：**打转、出界、碰撞、中断**都扣分甚至出局。
- 车辆规则强调**后驱前提 + 安全改装（防滚架、六点安全带、断电开关）**。
