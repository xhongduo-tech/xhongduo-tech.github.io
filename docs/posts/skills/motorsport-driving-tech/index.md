# 赛车运动与赛车驾驶技术

赛道驾驶、卡丁车与漂移等赛车驾驶技术以完整竞赛规则与系统化训练体系为支撑，是通往赛车运动的专业技术门径。以 CAMF《汽车比赛规则》、FIA《国际运动规则》及《赛车运动》驾驶技术培训教材为纲，从驾驶基本功、赛道走线到卡丁车与漂移专项技术，系统重建赛车驾驶从基础到竞技的完整训练链路。学完这些章节，就掌握了赛车驾驶技术的核心训练体系与参赛能力。

## 对标教材

- 中国汽车摩托车运动联合会《汽车比赛规则》
- 中国汽车摩托车运动联合会赛车执照培训体系
- FIA《国际运动规则》
- 《赛车运动》与驾驶技术培训教材
