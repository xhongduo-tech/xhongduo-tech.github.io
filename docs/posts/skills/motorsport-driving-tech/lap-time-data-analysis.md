## 为什么从圈速分析开始

从坐姿到雨战，前面十篇讲的都是「怎么开」；这一篇讲「怎么知道自己开得对不对」——**数据**。职业车队早已不靠「感觉」判断圈速，而是靠**遥测数据（telemetry）**：车上遍布传感器，把速度、油门、刹车、转向、G 值、转速实时记录下来，练完一圈就能回放分析。

数据驱动的意义在于：**感觉是滞后的、片面的，数据是即时、全面的**。你可能觉得「这一圈出弯开油很顺」，但数据显示你比上一圈晚开了 0.3 秒油门——感觉骗了你，数据不会。圈速分析的完整闭环是：**跑圈 → 采数据 → 对比基准 → 定改进点 → 再跑**，循环往复。

## 1 数据采集：车上的「体检报告」

### 遥测数据通道

现代赛车（从方程式到入门房车赛）普遍配备数据采集系统，常见通道包括：

| 数据通道 | 采集什么 | 告诉你什么 |
| --- | --- | --- |
| 车速（GPS/轮速） | 实时车速 | 每个点的速度曲线 |
| 油门开度 | 0–100% 油门 | 你多早开油、开油是否平滑 |
| 刹车压力 | 制动踏板压力 | 刹车点、刹车力度曲线 |
| 转向角 | 方向盘角度 | 转向是否平滑、是否过多修正 |
| 横向/纵向 G 值 | 加速度 | 载荷转移、抓地利用程度 |
| 发动机转速 | rpm | 换挡时机、转速管理 |

<span class="marginnote">入门级方案也很实用：<strong>手机 GPS 加一个油门/刹车记录 app，就能得到基础的「速度曲线 + 油门/刹车开度」</strong>。数据设备的价值不在贵，而在「有没有形成闭环」——即使只有车速曲线，也能对比发现「这一圈在哪里慢了 0.2 秒」。</span>

### 数据回放的两种视角

**逐圈叠加**：把多圈的速度曲线叠加在同一张图，一眼看出哪一圈在哪一段更快/更慢。
**与基准对比**：把你与队友（或职业车手的公开数据）的曲线叠放，找出差距所在。

## 2 关键数据指标：读图的能力

### 速度曲线与刹车点

**速度曲线**是最基础的数据图：横轴是赛道位置（或距离），纵轴是车速。从曲线上可以直接读出：

- **刹车点的位置**：速度曲线开始下降的点——对比你和基准的「下降起点」，就知道谁刹车晚。
- **弯心的最低速度**：曲线的最低谷——越低说明走线半径越小或入弯速度越保守。
- **出弯的爬升率**：曲线出弯段的斜率——斜率越陡，开油越早越猛。

### 油门与刹车的「叠加分析」

**油门曲线 + 刹车曲线**（0–100% 的开关或连续值）揭示操作习惯：

- **开油是否果断**：出弯点油门从 0 到 100 的过渡是「一段斜坡」还是「一截阶梯」——平滑的斜坡比突兀的阶梯更快。
- **刹车是否线性**：刹车压力的建立与释放是否平滑，有没有「点刹」「抖刹」的痕迹。
- **刹车与油门的重叠**：是否出现「松刹车与踩油门重叠」的瞬间——重叠过多说明过渡仓促。

**核心要点：读数据的目的是找「浪费的时间」，而不是找「最快的瞬间」**。速度曲线里，你领先的段不一定是真正的优势，落后的段才是值得投入的地方。

**易错点｜辨析：** 数据解读的两个陷阱。一是**只看最高速**：直道末端谁的速度高，不一定说明谁快——可能只是他出弯早、直道长，而他的弯道段更慢。二是**过度关注单圈最好成绩**：一个「侥幸快圈」（比如蹭了一次路肩、少堵了一次车）不能代表水平——要对比**多圈的稳定分布**，看平均速度而不是峰值。

## 3 分段对比与理论最快圈

### 把差距定位到弯

整圈慢了 0.8 秒，这 0.8 秒从哪来？答案是**分段**：把赛道按刹车点/弯道切成若干段，逐段对比你与基准的时间差。常见做法：

1. **分段计时**：利用数据系统的分段（sector）功能，或自己按距离切段。
2. **找「负差距」的弯**：列出每一段你比基准慢多少，把改进精力集中在**差距最大的段**。
3. **验证改进**：改完一处再跑，看那个段的时间是否真的下降，以及是否拖累了相邻段。

### 理论最快圈

把每一段你开得最好的成绩拼起来，得到**理论最快圈（theoretical best）**——它通常比你的实际最快圈还快，因为现实中你很难在同一圈里把每一段都开好。理论最快圈的意义在于：**它告诉你这条赛道 + 这辆车 + 你的上限在哪**，剩下的问题是「如何把散落在各圈的最好段，在某一圈里连续地做出来」。

<span class="marginnote">职业车队用数据系统直接计算理论最快圈，并追踪「与理论最佳的时间差」作为稳定性的指标。<strong>一个车手如果实际快圈与理论最快圈差距很小，说明他稳定、可复现；差距很大，说明他「忽快忽慢」，还有把散段拼成一圈的潜力</strong>。</span>

## 4 公式解析：用数据拆解刹车段

圈速分析最常用到的一个拆解，是**刹车段的时间模型**。从刹车点减速到入弯速度所需的时间：

$$
t_{\text{brake}} = \frac{v_0 - v_{\text{in}}}{a_{\text{avg}}}
$$

其中：

- $t_{\text{brake}}$ 是**制动耗时**（s）；
- $v_0$ 是刹车点前的**初速度**（m/s）；
- $v_{\text{in}}$ 是入弯时的**目标速度**（m/s）；
- $a_{\text{avg}}$ 是制动的**平均减速度**（m/s²）。

**直觉**：制动耗时由「要减掉的速度」与「减速度」共同决定。数据分析的用途在于：把实测的刹车压力换算成 $a_{\text{avg}}$，把速度曲线的下降段拟合出 $t_{\text{brake}}$，从而判断——你在这段刹车里，是**刹车点不够晚**（$v_0$ 起点太早），还是**减速度不够大**（$a_{\text{avg}}$ 偏低，即没有把刹车推到极限）。

**算一笔数**：某弯前 $v_0 = 55\ \text{m/s}$（198 km/h），入弯 $v_{\text{in}} = 20\ \text{m/s}$（72 km/h），平均减速度 $a_{\text{avg}} = 9\ \text{m/s}^2$：

$$t_{\text{brake}} = \frac{55 - 20}{9} = \frac{35}{9} \approx 3.9\ \text{s}$$

如果数据对比发现基准车手同样的入弯速度用了 3.5 s——说明他的 $a_{\text{avg}}$ 更高（刹车更狠更晚），你的改进点就是**把刹车点再推迟一点、把减速度再推高一点**。<span class="marginnote">注意 $a_{\text{avg}}$ 的提升有上限：它受 $\mu g$ 限制（约 10 m/s²）。<strong>当你的 $a_{\text{avg}}$ 已经接近 $\mu g$，刹车段的优化就只剩「推迟 $v_0$ 起点」这一条路</strong>——数据会让你看清自己到底卡在哪个环节。</span>

### 数据的「三张图」基本功

初学者从数据入门，先学会读三张图：

1. **车速曲线**：看刹车点位置、弯心最低速、出弯爬升率；
2. **油门开度曲线**：看开油时机与平滑度——理想的油门曲线是「一条平滑的斜坡」；
3. **刹车压力曲线**：看建压与释放的线性度——理想的刹车曲线是「一座平滑的山丘」。

**核心要点：三张图对应三个基本功**——车速看走线、油门看出弯、刹车看入弯。把三张图叠在一起看，就能还原「这一圈到底开得怎么样」。

## 5 小结

- 数据采集把「感觉」变成「可对比的曲线」：**车速、油门、刹车、转向、G 值**是五张基本图表。
- 读图的重点是**找浪费的时间**：刹车点位置、弯心最低速、出弯爬升率、油门过渡是否平滑。
- 分段对比把整圈差距**定位到具体弯道**，优先改进差距最大的段。
- **理论最快圈** = 各段最好的拼合，它指出上限与稳定性的差距。
- 刹车段时间模型 $t = (v_0 - v_{\text{in}})/a_{\text{avg}}$
