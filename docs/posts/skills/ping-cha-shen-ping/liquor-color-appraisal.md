## 为什么从汤色审评开始

茶汤的颜色，是内质最先「显形」的地方。同一泡茶，是绿是黄、是亮是暗、是清是浊，都指向它经历了怎样的工艺、含有怎样的物质。<span class="marginnote">汤色的物理本质，是<strong>内含物质对可见光的吸收与反射</strong>：叶绿素让绿茶汤显绿，茶黄素让红茶汤显金黄，茶褐素让老茶汤显暗褐。看汤色，其实是在「用眼睛读化学成分」。</span>

这一篇拆解汤色审评的三个维度——**色度、明暗、清浊**，并讲清汤色背后的物质成因。

本篇还会回答一个实际问题：为什么审评程序要「先看汤色再看香气」？因为茶汤刚倒入审评碗时状态最新鲜，随后的每一分钟都在氧化、降温、变暗——看汤色是与时间赛跑，时机稍纵即逝。

## 1 汤色的三个维度

**色度（色相）**：茶汤呈现的颜色种类与深浅。审评先看**属于哪类颜色**（绿、黄、红、褐），再看**深浅**（淡、中、浓）。不同茶类各有标准汤色区间，偏离即异常。

**明暗（亮度）**：茶汤的明亮程度。**明亮**的茶汤光泽清透，**暗淡**的茶汤浑闷无光。亮度主要来自茶黄素等色素的呈色与茶汤的澄清度——亮度是汤色里与「品质」关联最紧的一项。<span class="marginnote">为什么亮度如此重要？因为茶黄素（TF）含量高时茶汤金亮，茶红素（TR）适量时红亮，而一旦氧化过度生成茶褐素（TB），茶汤就变暗褐。所以「亮」是发酵恰到好处的信号，「暗」是过度氧化或劣变的信号。</span>

**清浊（清亮度）**：茶汤是清透还是浑浊。清亮为上，浑浊为次。浑浊可能源于原料不净、碎末过多、加工不当或水质问题。

三者的关系可以类比成一支笔：**色度是色相，明暗是明度，清浊是饱和度**——三个维度合起来，才是一杯茶汤完整的颜色画像。

## 2 汤色的物质成因

汤色不是随机的，它由几类核心色素决定：

**叶绿素**：未发酵茶（绿茶、白茶）汤色的主要来源，使茶汤呈绿或黄绿。杀青及时则叶绿素保留多，汤色绿亮。<span class="marginnote">杀青的本质是「用高温灭酶」——叶绿素在鲜叶里若不及时用高温固定，会被叶绿素酶分解而退绿，这也是「绿茶汤发红暗」最常见的技术源头。</span>

**茶黄素（TF）**：发酵茶（红茶、乌龙茶）的产物，呈**金黄明亮**，是「金圈」的来源——茶黄素越多，汤色越亮、滋味越鲜爽。

**茶红素（TR）**：茶多酚进一步氧化的产物，呈**红亮**，是红茶汤色红艳的主体。

**茶褐素（TB）**：过度氧化的产物，呈**暗褐**，含量高则茶汤暗浊——红茶存放过久、发酵过度，茶褐素增多，汤色由红艳转为红暗。<span class="marginnote">三类茶色素的比例，决定了红茶汤色的档位：TF 高则金圈明显、汤色红亮鲜活；TR 高则汤色红艳但略逊鲜活；TB 高则暗褐——「红艳明亮」与「红暗浑浊」的分界，正是 TF、TR、TB 三者比例的直观呈现。这条链条与第二级《生物化学》里酶促氧化的知识直接相连。</span>

理解了这个成因链，汤色审评就不再是「看颜色」，而是「读氧化程度」——这正是评茶从经验走向科学的一步。

不妨用西湖龙井与正山小种对照体会：龙井汤色嫩绿明亮，是因为未经酶促氧化、叶绿素占主导；小种汤色红艳带金圈，是因为茶多酚充分氧化生成茶黄素与茶红素。**同是一片叶子，工艺改变化学，化学显形为汤色**——这条因果链是汤色审评的全部底气。

## 3 汤色审评的操作要领

**趁热看**：茶汤一出审评杯，立即倒入审评碗观察。茶汤放置会因氧化、温度下降而**变暗变浑**——拖延一分钟，误判一分。这是审评程序里「先看汤色」的根本原因。

**白底看**：审评碗必须是纯白瓷，观察时放在白色背景前。白色是中性色，让茶汤的真实色相最大化呈现；有色背景会「染」偏你对汤色的判断。

**分杯看**：同一审评要排开多个茶碗横向比较——单个茶汤看不出「绿得正不正」，几个茶汤并排，色相的差异才一目了然。<span class="marginnote">横向比较是感官审评的通用技法：单看可能被「孤证」骗过，并列对比则让差异显形。这与视觉设计里的「对比检查」、数据可视化的「基准线」是同一原理——人类对差异的敏感度远高于对绝对值的敏感度。</span>

**标准看**：对照该类茶的**标准汤色**判断。绿茶该绿亮、红茶该红亮，若绿茶汤色红褐，直接判为工艺异常。

还有一条容易被忽视的细节：**评汤色要「摇碗」**。轻轻晃动审评碗让茶汤打旋，金圈与悬浮物会随旋涡显形——静止的汤面看不出层次，动态中清澈与浑浊的区别才分明。<span class="marginnote">摇碗的要领是幅度小而匀，让汤面形成稳定的同心旋涡；幅度太大反而把叶底碎末搅起来，混淆清浊判断。</span>

**看金圈**：金圈是红茶汤色审评的特有项目——茶汤与碗壁交界的金色光环，是茶黄素富集的标志。金圈明亮而宽，说明氧化适度；金圈淡、无金圈，说明氧化不足或原料内含物贫乏。

## 4 核心对比表：各茶类的典型汤色

| 茶类 | 标准汤色 | 理想描述 | 异常指向 |
| --- | --- | --- | --- |
| 绿茶 | 绿、黄绿 | 嫩绿明亮、清澈 | 红暗→氧化/劣变 |
| 红茶 | 红 | 红艳明亮、带金圈 | 红暗→过度氧化 |
| 乌龙茶 | 金黄、橙黄 | 金黄明亮 | 浑浊→做青不当 |
| 白茶 | 杏黄、浅黄 | 杏黄清澈 | 暗浊→萎凋不当 |
| 黄茶 | 黄 | 黄亮 | 绿→闷黄不足 |
| 黑茶 | 橙红、红浓 | 红浓明亮 | 暗浊→渥堆过度 |
| 茉莉花茶 | 浅黄、黄绿 | 黄亮清澈 | 浑浊→窨制不当 |
| 普洱生茶 | 黄绿、蜜黄 | 蜜黄明亮 | 红暗→仓储不当 |

表格的「异常指向」一列，是汤色审评最有价值的部分：**每一种异常汤色都对应一种工艺或存放问题**。<span class="marginnote">把这张表记住，你就有了「从汤色反推问题」的起点：看到绿茶汤红，要想到氧化；看到红茶汤暗，要想到过度发酵或陈化；看到乌龙汤浊，要想到做青不足。汤色是工艺的一面镜子。</span>

对照这张表时还要注意「茶类内部也有分档」：同为绿茶，龙井的嫩绿与碧螺春的黄绿、炒青的栗绿各有不同；同为红茶，工夫红茶的艳与红碎茶的浓也不可一刀切。表格给出的是**类别的基准区间**，实际审评要结合具体茶类的品种特征微调。

## 5 辨析｜易错点：汤色的几个误判

**「汤色越深越好」？** 不一定。绿茶以**嫩绿明亮**为佳，深黄反而不优；黑茶以红浓为佳，但「浓」指色度饱满，「浊」是另一回事。深而不亮是「暗」，不是「浓」。<span class="marginnote">「浓」与「浊」一字之差，天壤之别：浓是色度饱满、清亮有光（好）；浊是杂质悬浮、浑暗无光（差）。把「浓」误当「浊」会把好茶评低，把「浊」误当「浓」会把差茶评高——这是汤色审评最常见的失分点。</span>

**「汤色亮就是好茶」？** 亮度是重要指标，但不是唯一。有的茶汤色亮但滋味寡淡，有的茶汤色略暗但香气馥郁。汤色只是五因子之一，不能孤立定级。

**「放凉的茶汤也能评」？** 不能。冷茶汤色变暗、变浑，与热汤完全是两副面孔。审评要求**趁热、及时**——错过窗口，结论即失效。

**「碗壁无金圈就是假红茶」？** 金圈是红茶优质的表现，但并非全部——细嫩的红碎茶金圈通常不如工夫红茶明显，不能凭此一票否决。金圈要结合汤色红亮度、香气滋味综合判断。

**「汤色统一就好」？** 同一批茶汤色应尽量一致，但不同等级、不同山头本就有汤色差异。关键不是「绝对一致」，而是「偏离是否有合理解释」——级别内的微小差异正常，级别的整体漂移才是问题。

## 6 汤色异常对应的常见成因

把「异常汤色 → 可能成因 → 复核手段」的映射收拢起来，是汤色审评从「看」到「断」的关键一跃：

| 异常汤色 | 可能成因 | 复核手段 |
| --- | --- | --- |
| 绿茶汤红暗 | 杀青不足或存放氧化 | 闻香气有无陈味、看叶底是否花青 |
| 红茶汤暗褐 | 发酵过度或陈化 | 看叶底是否乌暗、滋味有无酸馊 |
| 汤色浑浊 | 碎末多、原料不净或水质硬 | 换水重泡、静置看沉淀 |
| 汤色淡薄 | 投茶量不足或内含物贫乏 | 称样复核、对照标准样 |
| 汤色过浓 | 闷泡过度或粗老梗多 | 缩短冲泡时间再比较 |
| 冷汤变暗 | 温度下降致色素聚合 | 坚持趁热观察、不评冷汤 |
| 汤色发灰 | 水质或容器铁离子污染 | 换水换器重泡 |

这张表的第一列是可观察的「果」，第二列是可推断的「因」，第三列是用其他因子「验果」的路径——五因子审评之所以要五因子都评，正因为**单靠汤色永远只能给假设，要靠香气、滋味、叶底交叉验证才能下结论**。

## 7 小结

| 术语 | 含义 | 优 / 劣 |
| --- | --- | --- |
| 色度 | 茶汤的颜色与深浅 | 符类标准 / 色相异常 |
| 明暗 | 茶汤的明亮程度 | 明亮 / 暗淡 |
| 清浊 | 茶汤的清透程度 | 清澈 / 浑浊 |
| 金圈 | 茶汤与碗壁交界处的金色光环 | 金圈明显 / 无金圈 |
| 汤色变暗 | 氧化或降温导致的亮度下降 | 及时观察 / 拖延误判 |

## 7 小结

- 汤色三维度：**色度、明暗、清浊**，合起来是茶汤完整的颜色画像。
- 汤色由**叶绿素、茶黄素、茶红素、茶褐素**的比例决定——读汤色即读氧化程度。
- 审评要领：**趁热看、白底看、分杯看、对照标准看**。
- 「浓」≠「浊」：浓是色度饱满清亮，浊是杂质悬浮浑暗。
- 异常汤色能**反推工艺问题**：但单靠汤色只能给假设，要靠香气、滋味、叶底交叉验证。
