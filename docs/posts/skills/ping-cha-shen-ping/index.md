# 评茶与茶叶审评

评茶是运用感官对茶叶的外形、汤色、香气、滋味、叶底进行系统审评以评定品质等级的科学技能，也是评茶员职业技能鉴定的核心内容。掌握评茶方法，才能客观辨别茶叶品质优劣、把好茶叶质量关。以《评茶员国家职业技能标准》《茶叶审评与检验》《中国名茶评鉴》为纲，从审评基础、五因子方法到分茶类审评与名茶评鉴，系统写完整套评茶技能。
