## 为什么从值班纪律开始

这一节是本专题的收官，也是前面所有技术的「集成环境」。**驾驶不是一个人表演，而是驾驶台团队在持续值班中的协作**——船长、驾驶员、舵工、瞭望人员各守其位，靠纪律保连续性、靠沟通保同步、靠资源管理保不出错。把值班纪律与驾驶台资源管理（BRM）学好，前面学的驾驶、避碰、应急才真正「长在团队身上」<span class="marginnote">驾驶台资源管理的核心，是承认<strong>「人都会犯错」</strong>，然后用团队流程去<strong>兜住个体的失误</strong>：交叉确认、信息共享、互相提醒。这与航空界的 CRM、与软件团队的 code review 同源——<strong>可靠性来自冗余与协作，不来自单点完美</strong>。</span>

## 1 航行值班的基本纪律

航行值班是船舶安全运行的基础，基本纪律包括：

- **正规瞭望**：持续保持视觉、听觉与设备瞭望，全面掌握周围动态。
- **保持船位**：按规定核对航向、船位与航速，防止偏航。
- **如实记录**：按规定记录车钟、航向、气象、交接等信息。
- **禁止脱岗**：值班期间不得擅离职守，离岗须有人接替。
- **禁止疲劳与酒后值班**：保持清醒与良好状态。

**瞭望是值班的第一职责**——设备再多，替代不了人的持续观察。一次瞭望的空档，就可能错过一次险情。

## 2 值班交接：安全的关键节点

交接班是值班链条上最脆弱、也最关键的节点：

- **交接内容**：航行态势、航向航速、周围船舶、设备状态、指令与注意事项。
- **交接方式**：当面交接、书面（记录）交接，确保信息无遗漏。
- **交接原则**：**交接期间不中断瞭望**，接班者确认清楚后方可接班。

**辨析｜易错点：** 交接班最怕「一句『都正常』就走人」——**交接不清，等于把风险藏进缝隙**。交班者要交「状态」，接班者要问「疑点」，两者缺一不可。<span class="marginnote">值班交接本质上是<strong>「状态转移 + 上下文传递」</strong>：把当前的航行态势完整交给下一位值守者。任何系统切换负责人时，都必须做<strong>完整的状态移交</strong>，否则就是「失忆式交接」——这是工程与航行通用的教训。</span>

## 3 驾驶台资源管理（BRM）：让团队高效协同

**驾驶台资源管理（Bridge Resource Management，BRM）** 是把驾驶台的人、设备、信息当作「资源」系统化管理的方法。它的要点包括：

- **信息共享**：所有成员掌握同一份准确信息，不搞「信息孤岛」。
- **明确分工**：谁瞭望、谁操舵、谁联系，分工清晰、责任到人。
- **有效沟通**：指令明确、重复确认、疑问直说，杜绝「我以为」。
- **团队决策**：综合各成员与各设备的信息做决策，充分讨论风险。
- **互相监督**：成员间互相提醒、及时纠错，把错误消灭在萌芽。

| BRM 要素 | 含义 | 落地动作 |
| --- | --- | --- |
| 信息共享 | 人人掌握全局 | 定时通报态势 |
| 明确分工 | 责任到人 | 部署表 + 口头确认 |
| 有效沟通 | 指令无歧义 | 复述确认指令 |
| 团队决策 | 综合判断 | 讨论预案、权衡风险 |
| 互相监督 | 集体兜底 | 发现异常立即提醒 |

**补充｜旁白：** BRM 的核心思想是**「用团队弥补个体」**——船长再强也有限度，但一个互相确认、互相提醒的团队，能挡住绝大多数失误。它把「安全」从一个人的素质，变成一套团队的方法。

## 4 情景意识与疲劳管理

两个决定值班质量的「软因素」，值得专门强调：

**情景意识**：指对「周围正在发生什么、接下来可能发生什么」的持续把握。**情景意识高**，能提前预判险情；**情景意识低**，往往直到碰撞前才「突然发现」。保持情景意识，靠的是**持续瞭望 + 主动预判 + 定期核对**，而不是被动等待。

**疲劳管理**：疲劳是值班安全的最大隐性杀手。管理要点：**合理安排休息、控制连续工作时间、识别疲劳信号（眼皮沉重、注意力漂移、反应变慢）、疲劳时及时报告换班**。<span class="marginnote">疲劳管理是「<strong>人的资源耗尽问题</strong>」：注意力、判断力都是有限资源，连续值班就是在消耗它们。真正的解法不是「硬扛」，而是<strong>按制度休息 + 诚实报告状态</strong>——与任何「资源耗尽」系统的处理逻辑一致。</span>

## 5 核心对比：个人值班与团队资源管理

| 维度 | 个人值班 | 团队资源管理 |
| --- | --- | --- |
| 核心 | 履行职责 | 协同增效 |
| 防什么 | 个人疏忽 | 团队盲区 |
| 靠什么 | 纪律与技能 | 沟通与流程 |
| 关系 | 团队管理的基础单元 | 个人能力的系统放大 |

两者不是二选一，而是**叠加**：个人纪律是地基，团队管理是结构——地基不牢，结构坍塌；结构缺失，地基再牢也孤掌难鸣。

## 6 驾驶台团队的角色示例：各守其位、协同增效

一次典型的靠离泊或复杂航段航行中，驾驶台团队这样分工协作：

| 角色 | 职责 |
| --- | --- |
| 船长 | 总体指挥、关键决策 |
| 值班驾驶员 | 瞭望、操舵指令、执行航行计划 |
| 舵工 | 执行操舵、报告航向 |
| 瞭望人员 | 报告周围船舶与碍航物 |
| 联系人员 | 对外通讯、协调他船 |

**辨析｜易错点：** 团队协作最容易出的问题，是「<strong>各自为战</strong>」——船长看航向、驾驶员看雷达、瞭望看水面，各看各的，却没人把信息汇成整体态势。**BRM 要求「人人共享同一张态势图」**：每一个发现都要及时通报，每一条指令都要确认清楚。<span class="marginnote">驾驶台团队的协作，是「<strong>多模态信息的融合决策</strong>」：每个人的观察都是「一路信号」，BRM 就是把这些信号<strong>汇聚成统一态势</strong>。任何复杂系统的人机协作，都遵循「共享态势 + 明确分工 + 交叉确认」。</span>

## 7 情景意识训练：把「预判」练成习惯

情景意识不是天赋，而是可以训练的能力：

- **持续提问**：不断自问「现在最该警惕什么」「接下来可能发生什么」。
- **主动预判**：看到一艘船转向，就预判它接下来会到哪、会不会与本船相遇。
- **定期核对**：定时把船位、航向、周围动态「对一遍表」。
- **找人验证**：对不确定的判断，向同伴求证、互相提醒。

**补充｜旁白：** 情景意识的本质，是**「在大脑里维护一张实时更新的态势图」**——图更新得越快、越全，决策就越从容。**它是瞭望、经验与思考三者的合成**，也是值班质量的分水岭。

**辨析｜易错点：** 值班协作中还有一个高频误区——**「权威盲从」**：下级发现异常，却因为「船长在，不用我操心」而选择不说。BRM 恰恰要求**任何成员发现任何疑点都要直说**——船长也会有盲区，团队的价值正在于互相补位。**敢说、会说、及时说**，才是团队值班的正确姿态。

**补充｜旁白：** 最后，把整个专题的收官主题落在一句话上——**「安全，是一群人在一起，把每一件小事都做对」**。值班、交接、协作、预判，每一件都是小事，但连起来，就是一条船、一个团队、一次航程的平安。

**补充｜旁白：** 愿每一次开航，都是平安的往返。

## 8 小结

- 航行值班纪律以**正规瞭望**为核心，防疲劳、防脱岗、如实记录。
- 值班交接是**状态转移的关键节点**，交接期间不中断瞭望。
- **驾驶台资源管理（BRM）**通过信息共享、分工、沟通、决策、监督，让团队协同兜底。
- **情景意识**与**疲劳管理**决定值班质量，靠持续瞭望与合理休息维持。
- 个人纪律与团队管理**叠加互补**，构成内河船舶安全运行的最终保障。
