## 为什么从助航设备开始

前面学的航道、航标、避碰，最终都要落到一个具体场景：**人在驾驶台，借助设备，持续值班**。雷达看远、测深仪看底、罗经定方向、AIS 认身份，设备把「看不见的水面」变成驾驶台前的「可见信息」；而航行值班则是把这些信息持续整合、保持警惕的制度化动作。会看设备、会值好班，是驾驶员的日常功课。<span class="marginnote">助航设备与值班的关系，很像<strong>「传感器 + 操作员」</strong>：传感器采集数据，人做判断与决策。设备再多，也替代不了人的持续瞭望——这就是「设备辅助、人负总责」的航行理念。</span>

## 1 助航设备全景：驾驶台有哪些「眼睛」

内河船舶驾驶台的助航设备，通常包括：

| 设备 | 作用 | 典型输出 |
| --- | --- | --- |
| 罗经 | 指示航向 | 航向角 |
| 雷达 | 探测他船、岸线与物标 | 相对位置、距离、方位 |
| 测深仪 | 测量水深 | 实时水深 |
| AIS（自动识别系统） | 交换船舶身份与动态 | 船名、位置、航向、航速 |
| 电子航道图 | 显示航道与船位 | 航行态势图 |
| GPS / 卫星定位 | 提供绝对位置 | 经纬度 |

设备各有专长，**没有一台设备是万能的**——雷达看不到船底下，测深仪看不到远处，GPS 需要别的参照校验。驾驶员的功夫，在于**综合各设备的信息形成统一态势判断**。

## 2 罗经与航向：方向感的基础

**罗经**是船舶方向感的基础，分**磁罗经**与**陀螺罗经**：

- **磁罗经**：利用地磁场指示磁北，结构简单、不依赖电源，但受船体磁场与铁磁物干扰，存在误差。
- **陀螺罗经**：利用高速回转体的定轴性指示地理真北，精度高，但依赖电源与维护。

**航向**是船首所指的方向，以罗经为基准读取。**罗经误差要定期校正、航行中要心中有数**——方向错了，一切都错。

## 3 公式解析：测深仪的测距公式

测深仪（回声测深仪）向水底发射声波，接收回波，按**声速与往返时间**算出水深：

$$
D = \frac{c \cdot t}{2}
$$

- **第一步，看 $c$**：$c$ 是水中声速，约 **1500 米/秒**（随水温、盐度、压力略有变化）。
- **第二步，看 $t$**：$t$ 是声波从发射到收到回波的总**往返时间**。
- **第三步，理解除以 2**：$t$ 是「下去 + 上来」的时间，单程时间只有 $t/2$，所以距离要除以 2。

这条公式是「**回声测距**」的通用原理——不止测深，雷达测距、声呐探鱼也同出一理。<span class="marginnote">测深仪、雷达都是「<strong>发出脉冲 → 接收回波 → 按时间差算距离</strong>」的测距仪。它们共享同一个物理模型，只是介质（水 / 电磁波）与用途不同。理解一个，就理解了一类。</span>

## 4 雷达、AIS 与电子航道图

三件现代设备把航行带进了「信息化驾驶」：

**雷达**：主动发射电磁波，探测他船与岸线，能显示相对位置并测定**距离与方位**。雨雪雾中尤其重要——它是「看不见时也能看」的眼睛。

**AIS**：自动广播本船身份与动态（船名、呼号、位置、航向航速），同时接收附近船舶的信息。**AIS 让每艘船都「有名有姓、有轨迹」**，是避碰与交通管理的重要工具。<span class="marginnote">AIS 本质上是一个<strong>「广播协议」</strong>：每船周期广播自身状态，其余船监听并共享态势。这与分布式系统里节点交换心跳、区块链广播交易是同一类「公开信息同步」机制——<strong>透明度带来安全</strong>。</span>

**电子航道图**：把航道图数字化，叠加本船实时位置，形成**航行态势图**。配合 AIS 与雷达，驾驶台上就能「看着图开船」。

**辨析｜易错点：** 设备显示的是「数据」，不是「真相」。**雷达会受雨雪杂波影响、AIS 信息可能缺失或错误、电子航道图可能有更新滞后**——设备只是辅助，最终判断仍靠瞭望与经验，**「设备可信但不可全信」**。

## 5 航行值班制度：持续保持警惕

设备再好，也要有人持续值守。航行值班的基本要求：

| 要素 | 要求 |
| --- | --- |
| 瞭望 | 持续保持正规瞭望，眼耳并用 |
| 定位 | 定时核对船位与航向 |
| 记录 | 按规定记录车钟、航向、气象与设备数据 |
| 交接 | 交接班交接清楚，交接时不中断瞭望 |
| 纪律 | 值班人员不得擅离职守、不得疲劳驾驶 |

**补充｜旁白：** 值班的核心是「**持续**」二字——瞭望不能断、定位不能停、记录不能漏。一次松懈的瞬间，可能就是事故的起点。**把值班纪律当成系统的高可用要求**：任何一个环节的「失守」，都是整个安全链的隐患。<span class="marginnote">航行值班的本质是<strong>「人在环上的持续监控」</strong>：人在，警惕就在；人倦、人走、人散，系统就裸奔。这也是为什么值班纪律、休息制度要写在规则里——<strong>防的不是机器，是人的疲劳与疏忽</strong>。</span>

## 6 设备自检与故障应急

设备不是「通电就能用」，值班时要会**自检**、会应对**故障**：

| 设备 | 自检要点 | 故障应对 |
| --- | --- | --- |
| 雷达 | 量程、增益、杂波抑制 | 改用目测与瞭望，报告 |
| 测深仪 | 读数稳定、探头正常 | 换备用手段核深 |
| AIS | 本船信息正确、在播 | 用无线电补报船位 |
| GPS | 定位更新正常 | 用雷达/陆标定位替代 |

**辨析｜易错点：** 设备故障最常见的错误是「<strong>死等设备恢复</strong>」——雷达坏了就一直盯着黑屏，忘了还有眼睛。**设备是辅助，瞭望是本**；设备失灵时，立即切换到人工手段并加强瞭望，才是正确应对。<span class="marginnote">设备故障应对，是「<strong>单点失效的降级路径</strong>」：每个关键设备都要有<strong>备用手段</strong>（雷达→目测、GPS→陆标）。高可用系统的核心思想——<strong>消除单点、预设降级</strong>——在驾驶台上同样成立。</span>

## 7 航行值班的记录：把「发生过的事」留住

值班记录是航行安全的「黑匣子」：

- **车钟记录**：每次用车、用舵的时间与指令。
- **航向航速记录**：定时记录航向、航速变化。
- **气象与水位记录**：风、雾、水位等环境信息。
- **交接记录**：交接班的书面留痕。

**补充｜旁白：** 记录的意义不在「应付检查」，而在「**事后可回溯**」——出了情况，记录是还原经过、分清责任的依据。**如实记录，是值班人员对自己也是对全船负责**。

**辨析｜易错点：** 还要记住——**设备是「辅助」，瞭望是「主体」**。再先进的电子设备，也不能取代眼睛看、耳朵听。能见度好时也要坚持瞭望，设备只用于补充与校验，而非替代。把这句话刻进值班习惯，设备才不会成为「分心的来源」而始终是「助航的工具」。

**补充｜旁白：** 设备再全，也替代不了一双持续瞭望的眼睛——这句话值得再强调一次。**把「设备辅助、人负总责」刻进值班习惯**，设备就永远是助手，而不是替身。

## 8 小结

- 助航设备包括**罗经、雷达、测深仪、AIS、电子航道图、GPS**，各有所长、须综合使用。
- 罗经分**磁罗经与陀螺罗经**，航向以罗经为基准，误差要定期校正。
- 测深仪公式 $D = ct/2$ 是「回声测距」的通用原理，雷达、声呐同出一理。
- 雷达看远、AIS 认身份、电子航道图叠加态势，但**设备可信不可全信**，最终靠瞭望。
- 航行值班要**持续瞭望、定时定位、如实记录、规范交接**，纪律是安全链的关键。
