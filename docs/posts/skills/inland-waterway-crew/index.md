# 内河船舶驾驶与船员适任

中国内河航运规模居世界前列，内河船舶船员适任考试与发证是船员依法上岗的法定准入门槛。以《内河船舶船员适任考试和发证规则》《内河交通安全管理条例》《内河船舶船员培训大纲》为纲，学完这些章节，就掌握了从内河船舶驾驶、航行技术到船员适任考试发证的完整基础。
