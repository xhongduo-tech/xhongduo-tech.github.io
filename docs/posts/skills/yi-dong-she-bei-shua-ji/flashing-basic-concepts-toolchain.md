## 为什么先把概念与工具链讲清楚

上一节我们画出了启动流程与分区结构这两张地图。这一节要回答一个更实操的问题：**刷机到底是个什么动作，需要哪些工具？** 很多新手失败，不是操作错，而是被术语搞晕——ROM、固件、卡刷、线刷、解锁、Root 混在一起，不知道哪一步对应哪个工具。这一节先把词汇对齐、把工具链画全，之后每一篇的「怎么操作」才有了坐标系。

## 1 一套词先对齐：刷机、ROM、固件到底指什么

**刷机（flashing）**：把一份预先做好的系统镜像（或镜像集合）写入设备分区的过程。它区别于「恢复出厂设置」——后者只是清空 `data` 分区，而刷机可以改写 `system`、`boot`、`recovery` 等任何分区。<span class="marginnote">一句话区分：<strong>恢复出厂 = 只动 data；刷机 = 动 system/boot/recovery 等系统分区</strong>。所以「刷机会变砖、恢复出厂不会」的根本原因就在分区操作范围的差别上。</span>

**ROM（Read-Only Memory 的借用词）**：在刷机语境里指**整套系统镜像**，包括系统、内核、界面、预装应用。它借用「只读存储器」的名字，是因为系统分区传统上以只读方式挂载。一个 ROM 通常就是一套「可刷进去的完整系统」。

**固件（firmware）**：比 ROM 更底层的软件，指设备上「固化」的程序——Bootloader、基带、TEE、内核都算固件。**刷固件**与**刷 ROM** 常被混用，但严格说固件偏底层（modem、bootloader），ROM 偏系统层（system、界面）。

**解锁（unlock bootloader）**：关闭 Bootloader 对镜像的验签，使未签名的系统可以被刷入。这是刷第三方系统的**前置条件**。

**Root**：获得系统内最高权限（相当于 Linux 的 root 用户），从而可以读写系统分区、运行特权程序。Root 不等同于刷机——刷机是换系统，Root 是在系统里开权限。

这几个词的关系可以这样记：**先解锁（打开门），再刷机（换系统），刷机后可 Root（在系统里当管理员），最后还能定制 ROM（自己造系统）**。

## 2 刷机的三种路径：卡刷、线刷与 OTA

刷机的执行路径有三条，按「谁来刷、走什么通道」区分：

**卡刷（sideload / flash from recovery）**：手机进入 Recovery 模式后，从存储卡或通过 adb sideload 把系统包刷入。它依赖 Recovery 程序，适合升级、装第三方 ROM，操作在手机端完成。

**线刷（flash via PC）**：手机进入 Fastboot（或厂商下载模式），由电脑端工具通过数据线把镜像写入分区。线刷可以刷最底层的东西（Bootloader、基带），是**救砖的主力路径**，操作在电脑端完成。<span class="marginnote">为什么救砖必须线刷？<strong>卡刷依赖 Recovery 还能启动，而变砖往往 Recovery 也起不来</strong>；线刷走的是 Fastboot/深刷通道，只要底层引导还在就能刷。</span>

**OTA（Over-The-Air）**：厂商推送的空中升级。它本质是系统自己更新，由系统升级服务执行增量包。OTA 不是「刷机」，但原理相通——所以刷机者常借助「卡刷官方 OTA 包」的方式重装系统。

三条路径的分工可以概括为：**日常升级走 OTA，换系统走卡刷，救砖和刷底层走线刷**。不同的 ROM 包也对应不同路径：卡刷包（zip）要在 Recovery 里刷，线刷包（含多个镜像）要解压后用工具刷。

## 3 完整工具链：从电脑到手机的每一环

一次完整的刷机，需要电脑端、手机端、连接层三部分协同：

**电脑端工具**：
- **ADB（Android Debug Bridge）**：电脑与手机的调试桥梁，负责传文件、执行 shell 命令、进入 Fastboot/Recovery。是刷机最通用的入口。
- **Fastboot**：电脑与 Bootloader 通信的命令行工具，负责线刷分区。几乎所有刷机都绕不开它。
- **厂商专用工具**：小米的 **MiFlash**、三星的 **Odin**、高通机型的 **QFIL/MSM 工具**、联发科的 **SP Flash Tool**。它们封装了 Fastboot 或走底层深刷通道，是官方线刷的推荐工具。

**手机端工具**：
- **Bootloader / Fastboot 模式**：接受电脑线刷命令的「底层环境」。
- **官方 Recovery**：执行恢复出厂、卡刷官方包。
- **第三方 Recovery（TWRP）**：功能更强的恢复环境，能刷任意卡刷包、备份分区。后文专门有篇讲它。

**连接层**：
- **USB 驱动**：手机进入 Fastboot/深刷模式后，Windows 需要装对驱动（如高通 9008 驱动、厂商 USB 驱动）才能被电脑识别——**「电脑不认设备」是刷机第一大卡点**。
- **数据线**：尽量用原装或短线，避免劣质线导致刷写中断。

工具链的典型运转方式：用 ADB 让手机进入 Fastboot 模式 → 用 Fastboot/厂商工具把镜像写入分区 → 重启进入系统或 Recovery 继续操作。

## 4 公式解析：一次线刷的「命令 + 分区」对应链

线刷的本质是一条条「往分区写镜像」的命令。以 Fastboot 为例，一次刷写可以被抽象为：

$$
\text{fastboot flash} \quad \underbrace{\text{<partition>}}_{\text{目标分区}} \quad \underbrace{\text{<image>}}_{\text{镜像文件}}
$$

逐步拆解：

- **`flash`**：告诉 Bootloader 执行「写分区」操作。
- **`<partition>`**：上一节的分区名，如 `boot`、`recovery`、`system`、`vendor`。写错分区名要么报错、要么写错位置。
- **`<image>`**：要写入的镜像文件，如 `boot.img`、`twrp.img`。镜像必须与该分区匹配——**把 recovery 镜像刷进 boot 分区，手机就无法正常开机**。

完整的线刷流程是多条这样的命令串起来：先刷 `boot`，再刷 `system`、`vendor`，最后刷 `vbmeta`、重设槽位。理解了这条「命令 + 分区」的对应关系，任何机型的线刷脚本在你眼里都会变成「若干条已知命令的排列组合」。

## 5 核心要点：刷机路径与工具选择对照表

| 场景 | 推荐路径 | 核心工具 | 备注 |
| --- | --- | --- | --- |
| 日常升级 | OTA | 系统更新 | 最安全 |
| 重装官方系统 | 线刷 | MiFlash / Odin / Fastboot | 可救大部分软变砖 |
| 刷第三方 ROM | 卡刷 | TWRP + 卡刷包 | 需先解锁 |
| 救砖（Bootloader 损坏） | 深刷 | QFIL / MSM / SP Flash | 走 9008 等底层通道 |
| 刷底层固件 | 线刷 | Fastboot / 厂商工具 | 基带、Bootloader |
| 只清资料 | 恢复出厂 | 官方 Recovery | 不刷分区 |

## 6 术语速查表

| 术语 | 含义 | 关键点 |
| --- | --- | --- |
| 刷机 | 写入系统镜像到分区 | 可改系统分区 |
| ROM | 整套系统镜像 | 卡刷/线刷的对象 |
| 固件 | 底层固化程序 | 偏 bootloader/modem |
| 解锁 | 关闭 Bootloader 验签 | 刷第三方的门槛 |
| Root | 系统内最高权限 | 刷机后可做 |
| 卡刷 | Recovery 内刷包 | 依赖 Recovery |
| 线刷 | 电脑端写分区 | 救砖主力 |
| OTA | 厂商空中升级 | 增量包 |
| ADB | 调试桥梁 | 万能入口 |
| Fastboot | 线刷命令行 | 直接写分区 |

## 7 快速自查清单

开始任何刷机前，对照清单确认：

- 我这次操作走的是**卡刷、线刷还是 OTA**？对应工具准备好没有？
- 电脑是否**装好了 USB 驱动**？数据线是否可靠？
- 目标 ROM/固件包是否**与机型、系统版本匹配**？
- 是否清楚这次刷写涉及**哪些分区**，会不会清空 `data`？
- 是否需要**先解锁**？解锁前置条件是否满足？

## 8 小结

- 刷机是把系统镜像写入分区，区别于只清数据的**恢复出厂**。
- ROM 是整套系统镜像，固件偏底层，**先解锁 → 刷机 → 可 Root → 定制 ROM** 是完整进阶路径。
- 三条路径：**OTA**（升级）、**卡刷**（换系统）、**线刷**（救砖/刷底层）。
- 工具链由**电脑端**（ADB/Fastboot/厂商工具）、**手机端**（Bootloader/Recovery）、**连接层**（驱动/数据线）三部分组成。
- 线刷的本质是「**命令 + 分区 + 镜像**」的对应，读懂它就能读懂任何刷机脚本。
