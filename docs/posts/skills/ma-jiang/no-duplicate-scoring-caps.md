## 为什么从不重复计番开始

前几节认识了 81 个番种，这一节回答一个更棘手的问题：**一副牌同时满足好几个番种，到底算几个？** 如果一股脑全加，一副字一色会同时算上碰碰和、字一色、还有各种小番，分数立刻爆表。**不重复计番**就是给这种「叠罗汉」设的规则。

这个问题在现实里每天都会发生：几乎每一副够格和牌的牌，都会同时命中多个番种。会不会「去重」，直接决定了报出的分数是 24 番还是 48 番。<span class="marginnote">算番不是「数番种个数」，而是「数有效番种」。不重复计番规则规定：反映同一事实的番种只计一次，必然成立的番种被大番种「吞噬」。理解这条规则，才算真正学会了算番。</span>

与不重复计番并行的，还有**封顶规则**——当番值叠加到天文数字时，用一条上限把分差拉回可控范围。一防虚高、一防失控，两道防火墙共同守护计分的公平。

这一节也是第3篇「算番与计分体系」的收官。从番种体系概述、到 88 番塔尖、到 64/48 番、32/16 番、8 番及以下、再到今天的不重复与封顶——国标算番的完整逻辑链已经闭合。

## 1 不重复计番的四条原则

不重复计番不是一条孤零零的规则，而是一套由四条原则组成的系统：

**原则一：同番种不重复计。** 同样的番种在一副牌里只计一次。四个暗杠的牌，四暗刻只计一次 64 番，不会因为四个刻子各算一遍而变成 256 番。

**原则二：必然成立的不计。** 大番种自动「吞噬」它必然包含的小番种。字一色必然构成碰碰和结构，所以字一色不计碰碰和；大三元由三副箭刻组成，所以大三元不计箭刻。<span class="marginnote">「必然成立的不计」是理解整个「不计」清单的钥匙：清一色不计无字（它必然无字）、平和不计无字、连七对不计清一色——凡是「没有这个成分，大番种就不成立」的小番种，统统被吞噬。</span>

**原则三：互斥反映的不重算。** 两个番种描述的是同一组牌、同一个事实时，只计较高者。例如清龙与连六——清龙的顺子里已经包含了连六的结构，连六不再单独计。

**原则四：不冲突即可叠加。** 只要没有上述三种关系，番种全部可以叠加。清一色（24）+ 清龙（16）+ 门前清（2）+ 自摸（1），四者互不冲突，全部成立。

四条原则的本质是一句话：**番种按「独立事实」计数，不按「名称个数」计数**。

## 2 常见的不计组合清单

把国标规则里最常见的「不计」组合收集成清单，实战时逐条对照：

| 主番种 | 不计 |
| --- | --- |
| 清一色 | 无字 |
| 混一色 | 无字 |
| 平和 | 无字 |
| 字一色 | 碰碰和 |
| 清幺九 | 碰碰和、同刻、无字 |
| 混幺九 | 碰碰和 |
| 大三元 | 箭刻 |
| 小三元 | 箭刻 |
| 大四喜 | 圈风刻、门风刻、三风刻、碰碰和 |
| 小四喜 | 三风刻 |
| 四暗刻 | 门前清、碰碰和 |
| 七对 | 不求人、单钓 |
| 连七对 | 清一色、不求人、单钓 |
| 十三幺 | 五门齐、不求人、单钓 |
| 全不靠 | 五门齐、不求人、单钓 |
| 一色四同顺 | 一色三节高、一般高、四归一 |
| 一色双龙会 | 平和、七对、清一色 |

这张清单看着长，规律却很统一：**「不计」的几乎都是「主番种必然包含」的番种**。抓住「必然成立就不计」这一条，清单可以推导出来，不必死背。<span class="marginnote">清单里有一对特别容易记反：七对「不计单钓」——七对听牌本来就是单钓成对，单钓这个 1 番被 24 番的七对吞噬了。而普通的单钓将（非七对）仍计 1 番。判断「不计」要结合主番种看，不能一概而论。</span>

## 3 封顶规则：给大牌设上限

不重复计番管住了「虚高」，但即便不重复，一副天牌仍可能叠出天文数字：大四喜（88）+ 字一色（64）+ 四暗刻（64）+ 杠上开花（8），单是这四项就有 224 番。若不加限制，一局就能决定整场比赛的胜负，竞技就失去了悬念。

**封顶规则（cap）**：对单局得分设定上限。具体形式因规则版本而异：

**按分值封顶**：规定单局最高得分不超过某一数值（如 300 分或 500 分）。超过部分截断，按上限计。<span class="marginnote">封顶规则是「保护弱者」的设计：它防止一次极端好运彻底摧毁比分结构，让比赛始终留有翻盘空间。竞技体育里类似的「分差上限」逻辑，在麻将桌上以封顶的形式出现。</span>

**按倍数封顶**：规定最高番数或倍数（如「最高 88×4」），超过的叠加不再计入。

**花分是否封顶**：花牌附加分通常不参与封顶，单独累加——这是「附加分」与「番种分」分野的又一体现。

封顶的数值没有统一标准，各赛事各有规定。打比赛前问清「封顶多少、怎么封」，比研究任何战术都重要。

封顶还有一个常见的**辨析点**：封顶限制的是「单局得分」，不是「单番分值」。88 番的大四喜永远计 88 番，不会因为封顶而被压成 64 番——封顶只作用于「多个番种叠加后的总和」。分清「番种分」与「封顶线」，就不会在报分时把两者搞混。

## 4 公式解析：计番的完整流程

把不重复计番与封顶规则整合起来，一副和牌的计分可以写成一条完整流水线：

$$\text{总分} = \min\left( \sum_{\text{互不冲突的番种}} \text{番种分值} + \text{附加分},\ \text{封顶值} \right)$$

逐项拆解：

- **第一步，列出全部番种**：把和牌可能命中的番种全部找出来，写在纸上。
- **第二步，剔除重复**：按四条原则，删掉「同番种重复」「必然成立」「互斥反映」的项，只留互不冲突的。
- **第三步，求和**：留下的番种分值全部相加，加上花牌附加分。
- **第四步，封顶**：若总和超过封顶值，按封顶值计；未超过，按实际值计。<span class="marginnote">前三步是「技术活」，第四步是「规则活」。多数和牌走不到第四步——只有天牌才需要封顶。但「知道自己大概多少分、有没有触顶」，是决定要不要自摸硬顶、要不要抢杠的关键决策依据。</span>

例：一副「大四喜 + 字一色 + 四暗刻 + 自摸」。列出全部：大四喜 88、字一色 64、四暗刻 64、碰碰和（被字一色吞噬）、自摸 1、三风刻（被大四喜吞噬）、圈风刻/门风刻（被大四喜吞噬）。剔除后只剩四项：88 + 64 + 64 + 1 = 217 番。若赛事封顶 200 番，则按 200 计；未设封顶则按 217 计。

## 5 核心要点表：四条原则速查

不重复计番与封顶规则的核心，浓缩为一张表：

| 规则 | 作用 | 判定要点 |
| --- | --- | --- |
| 同番种不重复 | 防叠罗汉 | 同一番种只计一次 |
| 必然成立不计 | 防虚高 | 大番种吞噬其必然包含的小番种 |
| 互斥反映不重算 | 防双计 | 同一事实只计较高者 |
| 不冲突可叠加 | 促多样 | 独立事实全部相加 |
| 封顶 | 防失控 | 超过上限按上限计 |

四条原则 + 一道封顶，构成了国标算番的完整闭环。**算番的技术，九成在「剔除重复」这一步**；熟练之后，看到一副牌先想「它能命中哪些番种、哪些会被吞噬」，比逐条翻规则快得多。<span class="marginnote">把这一节与前面的番种表合起来看，你就拥有了完整的「算番工具箱」：番种表告诉你「有什么」，不重复原则告诉你「算什么」，封顶告诉你「最多算多少」。三件套齐备，任何一副和牌都能快速、准确地报出分数。</span>

## 6 小结

- **四条原则**：同番种不重复、必然成立不计、互斥反映不重算、不冲突可叠加。
- **吞噬规律**：「不计」的几乎都是主番种必然包含的番种，可推导不必死背。
- **封顶规则**：给单局得分设上限，按分值或按倍数封顶，花分通常不参与封顶。
- **计分流程**：列出 → 剔除 → 求和 → 封顶。
- **算番三件套**：番种表 + 不重复原则 + 封顶规则。
- **封顶辨析**：封顶限制「单局得分总和」，不改变单个番种的分值。
