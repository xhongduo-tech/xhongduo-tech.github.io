# 麻将

以《麻将入门与技巧》、国标麻将规则与麻将竞技规范为纲，系统学习麻将牌具规则、和牌牌型、算番计分与竞技攻防技巧。从基础规则到高阶战术逐层递进，帮助读者掌握牌型判断、番种计算与实战博弈，既可用于日常娱乐，也可用于规范化的竞技比赛。

## 对标教材

- 《麻将入门与技巧》
- 国标麻将规则
- 麻将竞技规范
