## 为什么从舍牌与防守开始

上一节讲了起手判断——方向定好了，接下来每一手都要「出牌」。**舍牌（出牌）是麻将里出现频率最高的动作，也是攻防转换的枢纽**：打出安全牌，你在防守；打出进攻牌，你在推进自己的牌型；而每一次出牌，都会在牌河上留下一张「明牌」，供所有对手研读。<span class="marginnote">麻将的信息不对称就藏在这里：你的手牌是「暗」的，但你的舍牌是「明」的。高手与新手的分水岭，往往不在「摸到什么好牌」，而在「打出去的每一张牌都经过了攻防两方面的考量」。</span>

《麻将入门与技巧》第8章把这一块拆成两个互相咬合的能力：**舍牌技巧**（怎么打牌，既推进自己的牌型、又不给对手喂牌）与**防守猜牌**（怎么读牌河、读副露，判断别人的手牌、避开危险牌）。这一节先讲舍牌，再讲防守，最后用一个「筋」的数学把两者接起来。

## 1 舍牌：每一次出牌都是信息发布

舍牌的第一原则是**次序**——先打什么、后打什么，几乎决定了你整手牌的「信息公开度」。

**标准的舍牌次序**：孤张字牌 → 边张孤张（`1`、`9` 之类的孤张）→ 中张孤张 → 再按需拆搭子。这个次序的道理在于：孤张字牌进张能力最差、对牌型最没用，越早打出，越不心疼；而它的「信号价值」也最低——打一张 `北`，对手只知道「他没有在留北风」，学不到你牌型的实质信息。<span class="marginnote">反过来说，一张牌在牌河里的位置也透露你的「舍得爽不爽」：开局不久就打出的字牌，多半是「本来就没打算留」；中盘才打出的字牌，则可能是「为了做某门花色而忍痛放弃」——两者对读牌者是完全不同的信息。</span>

**舍牌的第二原则是「留有余地」**。能打成顺子的牌、能跟其他搭子呼应的牌，尽量后打；暂时用不上但进张潜力大的牌，宁可晚打一两轮。舍牌不是「淘汰废牌」，而是「在废牌里挑损失最小的先打」。

**舍牌的第三原则是「不给对手喂牌」**。这一点在防守时最关键：如果某张牌打出去几乎必然被下家吃碰、或正中别家听牌，就要警惕。判断「喂不喂」的依据，正是后面的猜牌技术。

**舍牌也要「自我复盘」**。每打完一手，回头看自己先打了什么、后打了什么——「这张字牌是不是打早了？那张边张是不是该留着挡一轮？」复盘舍牌次序，是提升舍牌水平最快的路径，也是第4篇心态一节讲过的复盘训练在技术层面的落地。

## 2 防守的核心：安全牌判断

当局面进入「别人可能要听牌了」的阶段，舍牌就从「怎么推进」切换到「怎么不点炮」。这时候第一要务是打**安全牌**。

**安全牌**：打出去几乎不可能让别家和牌的牌。安全度从高到低可以排一个序列：

**现物最安全**。别人已经打出的牌（牌河里的牌），你再打一张相同的，他当然不能和——这是铁的安全牌。防守时最先找的就是「现物」。

**字牌次之**。没有副露的字牌，别人除非在单钓字牌，否则难以和它——除非对手已经亮出字牌副露，否则字牌是仅次于现物的安全选择。<span class="marginnote">注意「单钓」例外：对手做七对或单钓雀头时，什么牌都可能和，现物也不安全。判断对手是不是单钓，要看他的副露与舍牌节奏——这也是猜牌的一部分。</span>

**筋牌再次**。下一节的「筋」理论会给出安全度判断的数学；这里先记住结论：与危险牌隔两张的「筋牌」，是防守的第三梯队。

**生张最危险**。从未出现过的牌、恰好是常见搭子的进张、又是多家的焦点，这种「生张」是点炮高发区。牌局越到后期，生张越危险。

举个例子说明「现物最安全」。中盘你手里有 `4筒` 与 `8万` 两张犹豫牌。牌河里已经有两张 `4筒`、且下家刚刚打过 `4筒`——这张 `4筒` 就是现物，打出去几乎零风险；`8万` 则从未露面，还是两条花色的中张，谁都在等。不用犹豫，先打 `4筒`。这就是安全度分级的现场应用：**判断一张牌安不安全，先问「它是不是现物」，再问「它是不是生张」**。

**防守的启动时机**也要拿捏：不是等别人亮出副露才防守。判断标准是「副露数量 + 舍牌速度」——一家碰出两组以上副露，或开始连续摸打（摸一张、打刚摸的那张），就应视为「可能听牌」，提前进入防守警戒。宁可早防一轮，不可晚防一手。

## 3 猜牌：从对手的动作反推手牌

猜牌不是「猜」，而是「推理」。推理的素材主要有三类：

**读副露**。对手碰出一组 `3万`，说明他手里大概率不再需要 `3万` 相邻的搭子？恰恰相反——他碰了 3 万，接下来可能就是在等 `2万`、`4万` 这类「靠边」的牌，或者在做碰碰和。副露是麻将里最「话多」的动作：吃说明牌型偏顺子、碰说明偏刻子、杠则基本宣告「我在做大牌」。

**读舍牌次序**。前文讲过，舍牌次序携带信息：先打字牌、后打中张，说明在做清一色；先打某门的边张，说明这门花色大概率放弃；中盘开始打「刚摸进来的牌」（摸打），往往说明手牌已定、在防守或听牌。

**读节奏**。犹豫时间、碰牌与否的选择、吃牌后的微表情——这些「节奏信息」在竞技麻将里有规范约束（不允许拖沓），但在日常对局中仍是重要线索。<span class="marginnote">需要提醒的是，竞技规范明令禁止通过表情、语言传递信息（见第4篇《运动员行为规范与礼仪》）。猜牌应建立在「牌面证据」上，而不是「察言观色」——后者的不可靠性，恰恰是业余牌局最多的误判来源。</span>

三路信息汇合，就能大致拼出对手的牌型轮廓：他在做哪门花色、差几张听牌、大概听在什么区间。猜牌的精度不需要 100%——只要能把「危险牌集合」缩小一半，防守就成功了。

举一个综合的例子。中盘时，上家碰出 `东` 与 `5筒` 两组副露，牌河前几轮依次打出 `9万`、`7万`、`6万`、`白`。三路信息合起来推理：打出 `9万 7万 6万`，说明万子这门的顺子潜力已被他主动放弃，他不太可能听万子；碰出 `东` 与 `5筒`，剩下的手牌大概率围绕筒子或条子组织。于是防守时，万子牌对上家相对安全，筒子与条子的生张则要格外警惕——这就是「读副露 + 读舍牌次序」合成一张防守地图的过程。

猜牌还要「动态更新」：牌局每一轮都在变化——一张新副露、一张新舍牌，都可能推翻之前的判断。高手会在一局里反复修正对每家手牌的「模型」，而不是「猜一次管到底」。

## 4 公式解析：「筋」的推理链

「筋」（スジ）是防守猜牌里最有用的工具，它背后是一条干净的推理链。先看命题：

**命题：对手舍出 `5万`，则 `2万` 与 `8万` 相对安全。**

先把这个关系写成一条「筋函数」。对中张 $x$（$3 \le x \le 7$）：

$$
\text{筋}(x) = \{x - 3, \, x + 3\}
$$

即中张 $x$ 的筋牌是 $x-3$ 与 $x+3$：舍 `5` 得筋 `2`、`8`；舍 `4` 得筋 `1`、`7`；舍 `6` 得筋 `3`、`9`。这就是「147、258、369」三组筋的来历。当 $x$ 取边张 `1`、`2`、`8`、`9` 时，公式退化为单边（只有 $x+3$ 或 $x-3$），对应着边张的「半筋」——`1` 的筋只有 `4`，`9` 的筋只有 `6`。

拆开推理链：

- **第一步，列出 `5万` 的「邻居搭子」**：能和 `5万` 组成两面搭子的，只有 `3万 4万`（听 `2万 5万`）与 `6万 7万`（听 `5万 8万`）两组。
- **第二步，排除矛盾**：若对手手里有 `3万 4万` 或 `6万 7万`，他正等着 `5万` 和牌，绝不可能主动把 `5万` 打出来。因此「舍出 `5万`」这一事实，同时排除了这两组搭子。
- **第三步，追出筋牌**：排除了 `3万 4万`，意味着对手不再可能通过这组搭子听 `2万`；排除了 `6万 7万`，意味着不可能通过它听 `8万`。于是 `2万`、`8万` 的危险来源被砍掉两条，安全度显著上升。

`2` 与 `8` 就是 `5` 的**筋牌**。同理，`4` 的筋是 `1` 与 `7`，`6` 的筋是 `3` 与 `9`——这就是「147、258、369」三组筋的来历。<span class="marginnote">把三组筋背下来：`1-4-7`、`2-5-8`、`3-6-9`。防守时见到对手舍出 `4`，就优先考虑打 `1` 或 `7`；见到舍 `6`，考虑打 `3` 或 `9`。这是麻将防守里性价比最高的一条经验法则。</span>

需要精确化的是「相对安全」：筋牌不是现物那样的绝对安全牌。它只是「危险来源被砍掉」的牌——如果对手还在单钓、或他的搭子是 `2万 3万`（听 `1万 4万`，与 `5万` 无关），筋牌的判断就失效。所以筋牌的正确用法是「作为防守的候选集」，而不是「无脑打出的免死金牌」。

实战中筋牌与现物要「组合使用」：先打现物（铁安全），现物打完了，再按筋牌顺序取——对手舍过 `4筒`，你手里的 `1筒`、`7筒` 就都是筋牌候选；两张安全度相近时，再比「哪张对自己的牌型用处更小」，用处小的优先打。**把「安全度排序」与「自我牌型损失最小化」结合起来，才是完整的防守出牌逻辑**——只讲安全不顾牌型，会把自己打成一手废牌。

还要记住筋的「双向性」：对手舍 `5`，他不仅难和 `2`、`8`，而且大概率也没有 `3-4`、`6-7` 这类搭子——这意味着如果你手里恰好有这类搭子，反而是相对安全的进张方向。读筋不止能防守，还能反过来判断「什么牌对手没有」。

## 5 核心要点表：安全度分级速查

防守时手里一堆牌，先打哪张？按安全度排一张速查表：

| 安全度 | 牌的类型 | 说明 |
| --- | --- | --- |
| 最高 | 现物 | 牌河里已有的牌，铁安全（除非单钓） |
| 高 | 无副露字牌 | 难以被顺子利用，仅次于现物 |
| 中 | 筋牌 | 危险来源被对手舍牌排除 |
| 低 | 熟张 | 曾出现但间隔久，仍可能被等 |
| 最低 | 生张 | 从未出现，点炮高发区 |

打牌顺序就是按这张表从「最高」往「最低」取。**记住口诀：先现物、再字牌、其次筋、最后才碰生张**。<span class="marginnote">口诀的价值在于「免思考」：牌局后期时间紧、压力大，把安全度次序练成直觉，就不用在每一手都重新推算一遍。高手的「快」，一半是算得快，一半是把常用的计算练成了肌肉记忆。</span>

## 6 辨析｜舍牌与防守的常见错误

**辨析｜易错点：** 新手防守时最常犯的三个错误：

**误区一：贪进攻，舍不得打安全牌**。牌还没完全成形，就觉得「打安全牌太亏」，于是生张照打。结果往往是牌没和成，先把大牌点给对手。正确的姿势是：**一旦判断某家接近听牌，进攻的优先级立刻让位给防守**——宁可这一手不和，也不能点炮。

**误区二：把「现物」当万能安全牌**。现物对大多数牌型安全，但对手若在单钓、或他在做七对，现物照样能点炮。安全牌永远是「概率判断」，不是「绝对保证」。判断对手牌型（是不是单钓），还是要回到猜牌。

**误区三：过度防守**。防守的代价是「放弃进攻」，一局里防守过多，等于把和牌机会拱手让人。**防守的度**：只在自己牌差、或对手明显听牌时才转防守；牌好、机会大时，该进攻就进攻。麻将的精髓是「攻防转换」，不是「一路防守」。

**误区四：把下家当唯一防守对象**。麻将的防守对象是「所有可能和牌的人」，不只是下家。下家会吃你的牌，对家、上家同样可能和你的牌。真正要防的，是「最接近听牌的那一家」——哪家副露多、舍牌急，就先防谁。

**误区五：猜牌只在防守时用**。猜牌是攻防共用的工具：进攻时猜别人的牌，能帮你判断「这张牌打出去会不会喂人、这副大牌会不会被人截胡」；防守时猜牌，是为了找到安全牌。把猜牌限定在防守阶段，等于丢掉了一半的信息优势。

## 7 小结

- **舍牌三原则**：按次序打（字牌→边张→中张）、留有余地、不给对手喂牌。
- **安全度分级**：现物 ＞ 字牌 ＞ 筋牌 ＞ 熟张 ＞ 生张；口诀「先现物、再字牌、其次筋」。
- **猜牌三素材**：读副露、读舍牌次序、读节奏——从牌面证据推理，不靠察言观色。
- **筋的推理链**：舍 `5` 排除 `3-4` 与 `6-7` 两组搭子，故 `2`、`8` 相对安全；筋牌是候选集，不是免死金牌。
- **攻防转换**：防守要果断，但别过度防守；麻将的精髓是判断「何时该攻、何时该守」。
- **动态猜牌**：每轮都在更新对对手手牌的「模型」，不猜一次管到底。

舍牌与防守解决了「怎么打才安全」，下一节把镜头转向进攻的另一半——**听牌选择与效率提升**：在众多听牌可能里，选哪张听、听几张，才能把和牌概率提到最高。
