## 为什么从两大基础蛋糕开始

上一节讲了蛋糕的比例原理，这一节把原理变成两只手的动作。**黄油蛋糕（butter cake）**与**海绵蛋糕（sponge cake）**是蛋糕世界的两大基柱：前者代表「油脂打发」路线，成品香润厚重；后者代表「蛋液打发」路线，成品轻盈绵细。绝大多数家庭蛋糕——纸杯蛋糕、磅蛋糕、瑞士卷、蛋糕卷——都是这两条路线的产物。学会这两款，等于把蛋糕的「两条腿」都站稳了。

## 1 黄油蛋糕：油脂打发的完整流程

**黄油蛋糕（butter cake）**：以黄油为主要油脂，通过打发黄油包入空气而膨发的蛋糕。代表：磅蛋糕、纸杯蛋糕、玛芬（油蛋糕系）。

**完整流程（6 寸或纸杯蛋糕 8 个量）**：

**原料**：无盐黄油 100g、细砂糖 100g、蛋 100g（约 2 个）、低筋面粉 120g、泡打粉 2g、牛奶 30g、香草精少许。

**第一步：黄油软化与打发**。黄油室温软化到指压出坑，加入糖，中高速打发 3–5 分钟，至颜色发白、体积明显膨胀、质地如羽毛。

**第二步：分次加蛋**。蛋液打散后**分 3–4 次**加入，每次充分打发吸收再加下一次。一次性倒入容易「油水分离」——蛋液来不及乳化，黄油糊瞬间变渣。

**第三步：拌入粉类**。面粉与泡打粉过筛，分两次加入，用刮刀**翻拌至无干粉即可**，不要过度搅拌。最后拌入牛奶与香草精，面糊呈顺滑流动状。

**第四步：装模烤制**。面糊装到模具七分满，175°C 烤 25–30 分钟（纸杯蛋糕）或 40–45 分钟（磅蛋糕），探针插入中心无湿糊带出即熟。

<span class="marginnote"><strong>分次加蛋是黄油蛋糕的「安全带」</strong>：乳化需要时间，一次加太多蛋液，体系瞬间过载就会油水分离。分离的黄油糊烤出来组织粗糙、口感发渣——加蛋「少量多次、每次都打匀」，是这道工序的全部秘密。</span>

**辨析｜易错点**：黄油打发到「羽毛状」是成功标志，但别打过头——打发过度，气泡过大过薄，烤时破裂，蛋糕塌陷。打到颜色发白、提起打蛋头糊体缓慢落下即可。

**泡打粉要「测」不要「猜」**：放久受潮的泡打粉会失效——取一勺放温水里，冒泡说明有效，不冒泡就换新。**黄油蛋糕的膨发来自「空气 + 泡打粉」双保险**，泡打粉失效时，再好的打发也撑不起组织。

**黄油蛋糕的冷藏与回温**：做好的黄油蛋糕可冷藏保存，吃前回温到室温口感最佳；想长期保存就冷冻，切片后冷冻、吃前复烤。**「冷藏」和「冷冻」是两种状态**：冷藏 3–5 天内吃完，冷冻可放一个月——别把两件事混为一谈。

## 2 海绵蛋糕：全蛋打发的轻盈路线

**海绵蛋糕（sponge cake）**：以打发蛋液为主要膨发来源的蛋糕，油脂含量低甚至为零。代表：瑞士卷、慕斯底、手指饼（ladyfinger）。

**两种打发方式**：

**全蛋海绵**：全蛋 + 糖一起坐在温水盆上隔水加热至约 40°C，再高速打发至颜色发白、体积膨胀 3–4 倍、提起打蛋头画「8」字不易消失。**隔水加热让蛋的乳化与发泡能力增强**（蛋黄中的脂肪在温热下更易展开包裹气泡；卵磷脂这类天然乳化剂的亲水亲油机制，在第二级《生物化学》与《表面与界面化学》中有系统讲解）。

**分蛋海绵**：蛋白与蛋黄分开，蛋白加糖打至干性发泡，蛋黄打发后两者混合。分蛋法膨发更稳定、成品更轻，是戚风的近亲。

**拌粉与入模**：低筋面粉过筛分次撒入打发蛋液中，用刮刀**从底部翻拌**，动作轻快——既要拌匀，又不能把气泡压碎。倒入模具抹平，180°C 烤 25–30 分钟。

**辨析｜易错点**：海绵蛋糕**最怕消泡**。消泡的元凶有二：一是拌粉时画圈搅拌（应该切拌/翻拌），二是粉一次性倒太多压塌气泡。**翻拌口诀：刮底、翻起、转盆**，三拍循环直到无干粉。<span class="marginnote"><strong>隔水加热到 40°C 的作用是「给蛋黄化冻」</strong>：蛋黄中的脂肪在低温下呈固态、不易展开包住气泡，温热后脂肪液化、乳化与起泡能力大增。用手背试温，微微温热（约体温偏上）即是最佳状态，过热会把蛋烫熟。</span>

**全蛋海绵的「粉糖比」**：面粉量约为蛋重的 60%–80%，糖约为 60%–70%。**糖太少则泡沫不稳，太多则甜腻发粘**——经典全蛋海绵「蛋 : 糖 : 粉 ≈ 1 : 0.7 : 0.7」，记住这个比例，随便改分量都不会跑偏。

**拌粉的手感**：面粉过筛后**分两次**撒入，第一次拌匀到「看不见白粉」再撒第二次。刮刀从盆底中央切入、翻起、同时转盆，**像在写「J」字**——动作快而轻，拌匀即停。拌好的面糊应当「勉强能流动」，没有面粉颗粒，也没有明显的气泡破裂声。

## 3 核心对比表：黄油蛋糕 vs 海绵蛋糕

| 对比项 | 黄油蛋糕 | 海绵蛋糕 |
| --- | --- | --- |
| 膨发来源 | 打发黄油包入空气 | 打发蛋液包入空气 |
| 油脂 | 多（黄油为主） | 少或无 |
| 质地 | 润实、香浓 | 轻细、干爽 |
| 口感 | 厚实有满足感 | 轻盈易消化 |
| 典型 | 磅蛋糕、纸杯蛋糕 | 瑞士卷、慕斯底 |
| 打发关键 | 黄油软而不融、分次加蛋 | 隔水加温、防消泡 |
| 常用场景 | 抹奶油霜当主体 | 作卷、作底、作夹层 |

**怎么选**：要「扎实香甜、能撑住厚奶油霜」选黄油蛋糕；要「轻盈卷得动、清爽不腻」选海绵蛋糕。同一块蛋糕体的选择，其实决定了后面抹面与搭配的方向。

**两种蛋糕的「液体油」变体**：把海绵蛋糕里的融化黄油换成植物油，成品更湿润、组织更细腻（这是「戚风」的关键一步）；把黄油蛋糕里的部分黄油换成酸奶或果泥，则更低脂、口感更清新——**配方是一条连续的光谱，黄油蛋糕与海绵蛋糕只是两个端点**。

## 4 失败诊断：两大蛋糕的常见坑

| 症状 | 黄油蛋糕的可能原因 | 海绵蛋糕的可能原因 |
| --- | --- | --- |
| 不膨发 | 黄油没打发到位、泡打粉失效 | 蛋液没打够、拌粉消泡 |
| 组织粗糙 | 蛋加太快导致油水分离 | 拌粉画圈、气泡破碎 |
| 中心塌陷 | 没烤熟、出炉震模太猛 | 蛋白霜打过头、没烤熟 |
| 口感干硬 | 烤过头、面粉过多 | 无油少水、烤温过高 |

**共性排查第一招：先测熟度**。探针无湿糊、中心温度 ≥95°C，再谈其他。蛋糕最常见的失败原因永远是「没烤熟」与「消泡」，其余都是配角。

**出炉的「震模」有讲究**：出炉后立即在台面轻震两下、让热气散出，再倒扣或放凉。**震模的目的是「排气防回缩」，不是「摔蛋糕」**——用力过猛会把刚定形的组织震塌。轻震两下即可，尤其戚风与海绵类要格外温柔。

## 5 手法要点速记

把本节手法浓缩成四条「肌肉记忆」：

1. **黄油蛋糕**：黄油「软而不融」，糖油打发到羽毛状，蛋分次加。
2. **海绵蛋糕**：全蛋隔水加温到 40°C，打至画「8」字不消。
3. **拌粉**：过筛分次、切拌翻拌、刮底转盆，三拍循环。
4. **熟度**：探针 + 中心温度，比看颜色可靠得多。

**这四条是所有蛋糕的公共底盘**：掌握了它们，后面戚风、玛芬、蛋糕卷都只是在这四条上换配方、换手法。

**把「底盘」变成一张检查清单**：开工前问自己——黄油软化到位了吗？蛋液分次加了吗？面粉过筛了吗？拌到无干粉就停吗？炉温实测了吗？**五问对答，失败率立刻减半**。

### 术语速查表

| 术语 | 含义 | 一句话记忆 |
| --- | --- | --- |
| 油水分离 | 蛋加太快导致黄油糊变渣 | 分次加蛋的「安全带」 |
| 羽毛状 | 黄油打发到蓬松发白的状态 | 成功打发的标志 |
| 全蛋海绵 | 全蛋一起打发 | 隔水加温更易起泡 |
| 分蛋海绵 | 蛋白蛋黄分开打发再混合 | 更稳定、更轻 |
| 消泡 | 气泡破裂导致组织塌实 | 翻拌时最大的敌人 |
| 水浴 | 隔热水加热 | 给蛋黄「化冻」的一招 |

**全蛋 vs 分蛋，一张表看清**：

| 对比项 | 全蛋海绵 | 分蛋海绵 |
| --- | --- | --- |
| 打发对象 | 全蛋 + 糖 | 蛋白（干性）+ 蛋黄 |
| 膨发主力 | 全蛋泡沫 | 蛋白霜 |
| 操作难度 | 较低（隔水加温） | 较高（两个体系混合） |
| 口感 | 蓬松偏干 | 更轻、更细腻 |
| 用途 | 蛋糕卷、慕斯底 | 戚风、瑞士卷 |

**两种做法没有高低之分，只有「适配场景」之分**：全蛋省事、出得快，分蛋更稳、更轻。理解了这张表，你就能根据「要什么口感、有多少时间」自由选择——这也是本专题一贯的思路：先懂原理，再谈手法。

## 6 小结

- **黄油蛋糕**靠打发黄油进气，香润厚实；**分次加蛋 + 软而不融**是两条铁律。
- **海绵蛋糕**靠打发蛋液进气，轻盈干爽；**隔水加温 + 防消泡翻拌**是核心。
- 选材看用途：撑奶油用黄油蛋糕，作卷作底用海绵蛋糕。
- 失败诊断先查熟度与消泡，再查其余。
- 四条公共底盘手法，是所有蛋糕的通用基础。
