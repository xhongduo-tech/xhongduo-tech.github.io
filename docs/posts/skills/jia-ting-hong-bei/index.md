# 家庭烘焙与西点

家庭烘焙与西点是利用家用烤箱与日常厨房，自制面包、蛋糕、饼干与甜点并加以基础装饰的实用技艺。学完这些章节，就掌握了从原料称量、发酵面团、蛋糕饼干烤制到抹面裱花出品的完整家庭烘焙基础，在家也能做出媲美烘焙店的安心美味。

## 对标教材

- 《Professional Baking》（Wayne Gisslen）
- 《The Bread Baker's Apprentice》（Peter Reinhart）
- 烘焙爱好者社区资料（君之《从零开始学烘焙》等）
