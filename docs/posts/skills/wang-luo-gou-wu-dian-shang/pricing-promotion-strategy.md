## 为什么从定价讲起

买家视角的「到手价」公式，翻到卖家这面就是**定价公式**：一件商品定多少钱，决定你赚多少、卖多快、在哪个价格带竞争。定价不是拍脑袋，而是一道**成本、竞争、心理**三者的平衡题。<span class="marginnote">定价是电商运营里「一发动全身」的杠杆：价格影响排序权重（商业信号）、影响点击率、影响转化、影响利润。定错价，流量与利润双输。</span>

## 1 定价的底线：成本核算

定价的第一块基石是**搞清楚你的成本**，否则卖得越多亏得越多：

$$\text{定价下限} = \text{商品成本} + \text{物流成本} + \text{平台佣金} + \text{包装与杂费}$$

逐项拆解：

- **商品成本**：拿货价或生产成本。
- **物流成本**：快递费（含偏远地区差价）。
- **平台佣金**：按成交额的比例抽成，不同类目不同。
- **包装与杂费**：包装材料、退换损耗、售后成本。

**净利公式**：$\text{净利} = \text{售价} - \text{定价下限} - \text{营销推广费}$。<span class="marginnote">新手最容易漏算「营销推广费」与「退货损耗」：做推广要花钱，退货要承担运费与损耗。定价时把它们算进去，才能避免「账面赚钱、实际亏钱」。</span>

## 2 定价策略：三种常见打法

定价策略与店铺定位一一对应：

**成本加成法**：在成本基础上加固定利润率。简单稳健，适合标准品与低竞争类目，但可能定价过高或过低。

**价值定价法**：按「买家愿意为价值付多少」定价——品牌、设计、服务带来的溢价。适合差异化精品型店铺。

**竞争定价法**：对标竞品价格带，锚定在「比头部低一点」或「比尾部高一点」。适合低价跑量与红海类目。<span class="marginnote">价格带思维在第2篇《价格构成分析》里讲过买家版：卖家版同样适用——<strong>先用竞品搜索确定价格带，再把自己的定价落进合理区间</strong>，避免「高不成低不就」。</span>

> **辨析｜易错点：** **定价 ≠ 低价。** 低价能带来初期销量，但会锁死利润空间、吸引价格敏感型买家（忠诚度低），且难以再提价。**「低价引流 + 高价利润款」的组合结构**，比单一低价更健康。

## 3 价格的心理技巧

电商定价有一批经过验证的心理技巧，合理使用能显著提升转化：

| 技巧 | 做法 | 原理 |
| --- | --- | --- |
| 尾数定价 | ¥99 而非 ¥100 | 锚点左移，感知更低 |
| 锚点定价 | 划线价高、成交价低 | 衬托优惠力度 |
| 套餐定价 | 单件 + 两件套餐 | 拉高客单价 |
| 阶梯定价 | 低配引流、高配利润 | 覆盖多人群 |
| 限时优惠 | 倒计时 + 折扣 | 制造紧迫感 |

<span class="marginnote">这些技巧有伦理边界：<strong>锚点不能虚构</strong>——划线价如果从未真实销售过，构成虚假宣传，第4篇讲的「退一赔三」就是它的代价。心理技巧服务转化，但必须以真实价格为基础。</span>

## 4 促销组合：把价格变成活动

定价是静态的，促销是动态的。常见促销组合：

**店铺券 + 满减**：门槛设置要「够得着」——满减门槛比客单价略高，诱导凑单。

**限时限量**：秒杀、闪购，制造稀缺，适合引流款。

**赠品与套餐**：买赠、加价购，比直接降价更保护价格体系。

**会员/复购**：会员价、老客券，拉复购。

**促销设计的一条原则：促销要服务定位，别把价格体系打烂。** 频繁打折会让买家「等折扣」，原价卖不动——定价与促销组合，要维护「价格锚点」的稳定。<span class="marginnote">「先涨后降」式虚假促销是平台严查的违规行为（虚假优惠），会带来处罚与信誉损失。真正的促销是<strong>让利</strong>，而不是数字游戏。</span>

## 6 常见误区与对策

| 误区 | 正解 |
| --- | --- |
| 「低价 = 好卖」 | 低价锁死利润，还吸引低忠诚度客户 |
| 「划线价可以虚构」 | 虚构锚点构成虚假宣传，涉退一赔三 |
| 「促销 = 天天打折」 | 频繁打折会让买家等折扣，破坏价格体系 |
| 「定价凭感觉」 | 定价 = 成本 + 竞争 + 心理三者的计算 |

## 7 实战要点清单

- 定价先算成本下限：商品 + 物流 + 佣金 + 包装 + 退货损耗。
- 用「低价引流款 + 高价利润款」结构代替单一低价。
- 促销设计守住真实让利，别玩先涨后降的数字游戏。

## 8 实战案例推演：一件 T 恤的定价测算

进价 20 元的 T 恤，算一算该卖多少钱：

| 成本项 | 金额（元） |
| --- | --- |
| 商品成本 | 20 |
| 快递 | 5 |
| 平台佣金（5%） | 按售价另算 |
| 包装 | 1 |
| 退货损耗分摊 | 2 |

先算定价下限：$20 + 5 + 1 + 2 = 28$ 元（不含佣金）。若定 39 元，佣金约 2 元，净利约 $39 - 28 - 2 = 9$ 元；若做推广，还需再扣推广费。若定位低价跑量，39 元在同类中是否还有竞争力，要放到价格带里看。**这条推演的关键是：所有成本都要进公式，包括最容易漏算的退货损耗与推广费**——否则会出现「账面赚钱、实际亏钱」。

## 9 小结

- 定价下限公式：**成本 + 物流 + 佣金 + 包装杂费**；净利要扣除营销与退货损耗。
- 三种策略：**成本加成、价值定价、竞争定价**，与店铺打法一一对应。
- 定价 ≠ 低价：**低价引流 + 高价利润款**的结构优于单一低价。
- 心理技巧：**尾数、锚点、套餐、阶梯、限时**；锚点必须真实，虚构即违法。
- 促销组合服务定位：**优惠券、满减、限时、赠品、复购**，别打烂价格体系、别玩虚假让利。

在下一节，我们把「卖出去」落到「服务好」：客服怎么管、评价怎么经营、差评怎么应对——这就是**客户服务与评价管理**。
