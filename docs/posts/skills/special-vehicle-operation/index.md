# 工程机械与特种车辆操作（叉车/挖掘机/起重机）

叉车、挖掘机、起重机等工程机械与特种车辆多属法定特种设备/特种作业范畴，作业人员必须持证上岗、按章作业，安全要求高于一般工种。以《特种设备安全法》、特种作业人员考核规定及 GB 6067《起重机械安全规程》为纲，系统建立从法规持证、结构原理到分机型实操与安全应急的完整知识体系，是叉车司机、起重机械司机等职业取证实操的核心课程。

## 对标教材

- 《中华人民共和国特种设备安全法》及市场监管总局《特种设备使用管理规则》（TSG 08-2017）
- 应急管理部《特种作业人员安全技术培训考核管理规定》及特种设备作业人员考核大纲
- GB 6067《起重机械安全规程》系列强制性国家标准
- GB/T 10827《工业车辆 安全要求和验证》与 TSG N0001《场(厂)内专用机动车辆安全技术监察规程》
