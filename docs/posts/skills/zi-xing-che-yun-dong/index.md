# 自行车运动

骑行集大众健身与竞技于一体，从基础技术与安全骑行，到功率训练、体能周期化，再到 UCI 竞赛规则，是普通人强身健体、骑行爱好者科学训练与运动员参赛竞技的完整知识体系。

## 对标教材

- 《公路自行车训练圣经》（Joe Friel）
- 中国自行车运动协会《训练指南》
- UCI《自行车竞赛规则》
