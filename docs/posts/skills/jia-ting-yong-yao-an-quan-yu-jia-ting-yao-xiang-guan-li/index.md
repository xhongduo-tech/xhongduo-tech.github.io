# 家庭用药安全与家庭药箱管理

非处方药安全使用、药品储存与常见病自我用药是家庭健康的基础技能。掌握这些知识，能在常见小病面前减少用药错误、避免药品失效浪费，更安全地守护全家的健康。

## 对标教材

- 国家药监局《药品说明书和标签管理规定》
- 卫健委《国家基本药物临床应用指南》
- 中国药学会《家庭安全用药》
