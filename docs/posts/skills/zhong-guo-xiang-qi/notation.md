## 为什么从记谱法开始

一局棋从开枰到终局，少则十几着、多则上百着。没有记谱法，这些着法就像口耳相传的歌谣，容易走样、无法复现；有了记谱法，一盘棋就能被**完整存档**，供自己复盘、供他人研究、供后人传承。<span class="marginnote">记谱法本质是「把局面状态序列编码成文本」——这正是一切复盘、拆棋、教学的基础设施。类比计算机科学：棋谱相当于「对局日志（game log）」，而读谱复盘就是「回放日志定位问题」，见第三级《软件工程》中日志驱动调试的思想。</span>中国象棋通行两套记谱体系：**传统记谱法**（比赛与棋书通用）与**坐标记谱法**（软件与数据库常用）。本篇把两套体系分别讲透，并给出互译实例——读懂棋谱，是象棋学习的「阅读能力」，之后所有布局与残局知识都要靠它输入。

## 1 记谱的五个基本符号

无论哪套记谱法，都建立在五个基本要素之上，先记熟它们：

**棋子名**：七类棋子的名称简写——帅（将）、仕（士）、相（象）、马、车、炮、兵（卒），记谱时用「車」「馬」「炮」「兵」等汉字（或对应字母）。

**竖线编号**：从己方右侧起，把竖线编号为 1 至 9。红方从红方右侧编号，黑方从黑方右侧编号，因此**同一竖线在红黑两边的编号方向相反**。<span class="marginnote">这是传统记谱最容易绕晕的地方：红方的「二路」与黑方的「二路」不是同一条竖线。判断方法很简单——记谱永远站在「走子方」自己的角度：红方走子用红方的编号，黑方走子用黑方的编号。</span>

**进（jin）**：棋子向对方阵地方向移动。

**退（tui）**：棋子向己方阵地方向移动。

**平（ping）**：棋子沿横线平行移动。

进、退、平是传统记谱的三种「运动动词」，配合竖线编号与步数（或落点），就能完整描述任何一着棋。

## 2 传统记谱法：平进退的完整规则

传统记谱的格式是 **「棋子名 + 起点竖线 + 运动动词 + 终点信息」**，其中终点信息的写法分两类：

**第一类：车、炮、兵（卒）、帅（将）—— 终点写「步数」或「落点竖线」**。这类子沿直线走，所以：
**平**：写落点所在竖线，如「炮二平五」= 二路炮平移到五路。
**进 / 退**：写移动的步数，如「车一进一」= 一路车前进 1 步；「炮五退二」= 五路炮后退 2 步。

**第二类：马、相（象）、仕（士）—— 进 / 退只写「落点竖线」**。这类子走斜线，步数不直观（马走日、相走田），所以进、退后面直接写**落点所在竖线**，如「马八进七」= 八路马进到七路。<span class="marginnote">注意马、相、仕<strong>没有「平」</strong>——它们从不走直线，所以传统记谱中只有进、退两种动词。这也是为什么「马二进三」后面跟的是竖线数字 3，而不是步数 3：落点竖线是 3 路。</span>

当同一方有两枚同种棋子落在同一竖线上时，用 **前（前车）** 与 **后（后车）** 区分：离对方阵地近的为「前」，远的为「后」，如「前车进一」「后炮平五」。

**完整实例：中炮对屏风马开局前三步**

红方（从下往上）：`炮二平五`（二路炮平到中路，架中炮）→ `马二进三`（二路马进到三路，跳正马）→ `车一平二`（一路车平到二路，出直车）。

黑方（从上往下）：`马8进7`（八路马进到七路，跳屏风马右马）→ `马2进3`（二路马进到三路，跳左马）→ `车9平8`（九路车平到八路，出直车）。

这六着合起来就是最经典的中炮对屏风马开局骨架。读出这六步，你已经能看懂任意一部象棋棋谱的前三回合了。

## 3 坐标记谱法：把着点编码成坐标

传统记谱直观、棋手通用，但它有一个弱点：**它描述的是「相对运动」，需要配合棋局上下文才能定位着点**。计算机与数据库更喜欢绝对定位——于是有了**坐标记谱法**。

坐标记谱的规则是：

**给每个着点一个「（竖线, 横线）」坐标**。竖线从己方右侧起编 1–9（与红方视角一致），横线从己方底线起编 1–10（或 0–9，具体软件略有差异）。于是：

红方帅位于 `(5, 1)`，红方双炮位于 `(2, 3)` 与 `(8, 3)`，红方双车位于 `(1, 1)` 与 `(9, 1)`。
黑方将位于 `(5, 10)`，黑方双炮位于 `(2, 8)` 与 `(8, 8)`。

**一着棋记作「起点坐标 → 终点坐标」**：例如「炮二平五」记为 `(2,3) → (5,3)`，「马八进七」记为 `(8,1) → (7,3)`。<span class="marginnote">坐标记谱与面向对象的坐标思维同构：每个着点是一个「对象」，一着棋是一条「从 from 到 to 的记录」。象棋软件（如象棋巫师、天象棋谱）的内部存储正是这种格式，玩家用鼠标点哪走哪，程序在后台记录的就是坐标对。</span>坐标记谱的好处是**自包含**——不依赖上下文，任何局面都能无歧义地还原；坏处是**不直观**——棋手读起来不如「炮二平五」有画面感。

## 4 核心对比表：两套记谱体系对照

| 维度 | 传统记谱法 | 坐标记谱法 |
| --- | --- | --- |
| 运动描述 | 平 / 进 / 退 + 步数或落点 | 起点坐标 → 终点坐标 |
| 参考系 | 走子方视角（红黑编号相反） | 红方视角为主（竖线 1–9 固定） |
| 歧义处理 | 前车 / 后车区分 | 坐标天然无歧义 |
| 可读性 | 高，棋手习惯 | 低，但精确 |
| 适用场景 | 比赛记录、棋书讲解 | 软件存储、数据库、教学课件 |
| 实例 | 炮二平五 | `(2,3) → (5,3)` |

**核心要点：** 两套记谱不是竞争关系，而是**互补**——棋手用传统记谱交流，软件用坐标记谱存储。会读传统记谱、能理解坐标记谱的「从→到」逻辑，就打通了「人类棋谱」与「机器棋谱」的接口，这也是后续拆解布局定式（棋谱密集区）的基本功。

## 5 读懂一盘完整棋谱：一次实战演练

把记谱知识落到实践——用传统记谱读一盘短小精悍的实战对局，感受「从记谱到还原」的完整流程。以中炮对屏风马的一盘短对局为例：

```
1. 炮二平五  马8进7
2. 马二进三  马2进3
3. 车一平二  车9平8
4. 兵七进一  卒7进1
5. 马八进七  炮8进2
```

第五着黑方「炮8进2」是经典的**巡河炮**——8 路炮前进 2 步，巡守河口。读谱时注意它的动作类型：炮是直行子，进 2 指「前进 2 步」，与马的「马八进七」（进到七路）写法不同——这正是传统记谱「车炮兵走步数、马相仕走落点」规则的实战再现。<span class="marginnote">这盘谱里藏着传统记谱的三个典型场景：<strong>同线双子</strong>（车一平二，一路车平移）、<strong>落点竖线</strong>（马八进七，进到七路）、<strong>步数</strong>（炮8进2，前进两步）。读懂这三类写法，就掌握了传统记谱的 90%。</span>

接着读中局的几个关键着：

```
6. 车九平八  炮2平4
7. 车八进六  车8进4
```

「炮2平4」是黑方的**士角炮**——2 路炮平到 4 路（士角），这步棋给黑方中卒加了保护；红方「车八进六」则是直车过河，压住黑方阵地。到这里，局面已经从「背定式」过渡到「凭棋理」——**记谱法读到这里，你已经能复现整盘棋的每一个局面，这就是记谱的全部价值**：它让任何一盘棋都可以被「存档—读取—研究」。

**读谱练习建议**：找一本棋谱（或网上的对局记录），每周读 1–2 盘——先只读记谱、不摆棋盘，在脑中「盲读」还原局面，再摆盘验证。这个「盲读」训练能把记谱法从「看得懂」练成「读得快」，是棋谱阅读能力的关键一步。<span class="marginnote">「盲读棋谱」训练对应「心算模拟」的能力：在脑中维护一个局面状态，逐着更新——这就像程序里「状态机的心智模拟」，见第三级《计算机组成原理》中程序执行的心智模型。练熟了，读谱速度会成倍提升。</span>

## 6 记谱的易错点辨析

记谱看似简单，实际应用中有几个高频易错点，专门辨析：

**易错点一：马、相、仕的「进」后面写的是「落点竖线」，不是步数**。`马八进七` 是「八路马进到七路」，不是「前进七步」。很多初学者把马当成直行子，误读步数——判断方法是：**斜行子（马相仕）写落点，直行子（车炮兵帅）写步数或平线**。<span class="marginnote">「斜行子写落点、直行子写步数」是传统记谱最容易混淆的规则。记住一个检验技巧：马走「日」、相走「田」、仕走「士角」，它们每一步的落点都在一条竖线上——写落点竖线，才能唯一确定这枚子走到了哪里。</span>

**易错点二：红黑两边的「二路」不是同一条线**。红方的二路（从红方右侧数）与黑方的二路（从黑方右侧数）方向相反。读谱时务必站在「走子方」的视角看编号——记谱的坐标系永远以「当前走子方」为准。<span class="marginnote">「记谱视角随走子方切换」是传统记谱的设计核心：红方记红方编号、黑方记黑方编号。这也是它比坐标记谱「人性化」的地方——每个棋手都用自己的右起编号，不用换算；代价是读谱时必须不断切换视角。</span>

**易错点三：前/后子的写法**。同一竖线有两枚同种棋子时，靠近对方阵地的是「前」、靠近己方阵地的是「后」，写作「前车进一」「后炮平五」等。注意「前后」是相对方位，不固定指某一枚——随棋子移动会变化。

**实战建议**：记谱的错误多数出在「急」——走完棋不记录，等局面复杂了凭记忆补记，必然出错。**养成「落子即记」的习惯**，让记谱成为与走棋同步的动作，是避免记谱错误的根本办法。

## 7 小结

- 记谱五要素：**棋子名、竖线编号（己方右侧起 1–9）、进、退、平**。
- 传统记谱：车炮兵帅进退化写**步数**、平写**落点竖线**；马相仕进退化写**落点竖线**、无「平」；同线双子用**前 / 后**区分。
- 坐标记谱：每个着点编码为 **（竖线, 横线）**，走子记作 **起点 → 终点**，无歧义、适合软件。
- 两套体系互补：**传统记谱给人看，坐标记谱给机器看**。
