# 中国象棋

中国象棋是融策略、计算与实战智慧于一体的传统棋类项目，以车马炮兵卒在九宫河界间的攻杀为核心，是训练逻辑思维与决策能力的经典智力运动。以《中国象棋入门》、中国象棋协会等级体系与《象棋布局与残局》为纲，系统重建从入门棋规、基本杀法与战术到布局体系、中局攻防与残局定式的完整知识体系。
