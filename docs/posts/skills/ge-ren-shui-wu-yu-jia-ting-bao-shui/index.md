# 个人税务与家庭报税

个人税务与家庭报税以《中华人民共和国个人所得税法》《个人所得税专项附加扣除暂行办法》和税务总局《个税综合所得年度汇算办税指引》为纲，系统掌握从收入分类、税率计税、专项附加扣除到年度汇算清缴与家庭统筹申报的完整实操链条。学完这些章节，就写完了个人税务与家庭报税的全部内容。

## 对标教材

- 《中华人民共和国个人所得税法》
- 《个人所得税专项附加扣除暂行办法》
- 国家税务总局《个税综合所得年度汇算办税指引》
