## 为什么从压缩机开始

上一节我们把制冷原理与冰箱系统组成讲透了：制冷剂在蒸发器里吸热、在冷凝器里放热，但谁让制冷剂流动起来？答案是**压缩机**——它是蒸气压缩制冷循环的「心脏」与「动力源」：把低压低温的制冷剂蒸气压缩成高压高温蒸气，维持整个循环的压差。<span class="marginnote">制冷循环里只有压缩机是「做功者」，其余部件（冷凝器、节流、蒸发器）都在「耗用」它建立的压力差。没有压缩机，制冷剂静止不动，制冷量为零——所以「压缩机坏」几乎等于「冰箱报废」级别的故障。</span>本节把压缩机的结构原理、启动方式、保护装置讲透，这是后面冰箱空调检修中最常接触的三大部件之一。

家用压缩机的两个技术要点值得先立住：**它是单相电机**（家用是单相 220 V 电），而单相电机的启动需要专门手段；**它是全封闭式**（电机与压缩机构封装在一个钢壳里），出了问题只能整体更换。理解「单相电机怎么启动」与「过载怎么保护」，就是本节的核心。

掌握压缩机，还意味着掌握一套「先数据后结论」的检修习惯：绕组阻值、对地绝缘、运行电流、吸排压力——压缩机的一切状态都能用这四组数据表达。**别凭「感觉」换压缩机，那是本专题最贵的配件**。

这四组数据之间还有关联：绕组阻值看「线圈断没断」，绝缘看「漏不漏电」，电流看「转得累不累」，压力看「压得动压不动」。**四者结合，压缩机「电、磁、机、热」四方面的状态都能说清**——这正是后文整机诊断反复用到的判断工具。

**全封闭压缩机的「听诊」**：耳朵贴着壳体听运行声——正常是低沉平稳的运转声；「嗡嗡」不转是堵转/启动失败；内部「嗒嗒」是阀片松动或异物；尖锐啸叫是内部机械异常。**听声是数据之前的第一判断，但要靠数据确认**。

## 1 压缩机的类型与工作过程

家用冰箱空调压缩机主要有三类：

**往复活塞式压缩机**：活塞在气缸里往复运动，压缩制冷剂。结构成熟、应用广泛，家用冰箱与早期空调多用此型。

**旋转式（滚动转子式）压缩机**：一个偏心滚子在气缸内滚动，把制冷剂从吸气口推到排气口。结构紧凑、振动小、效率高，是现代家用空调主力。<span class="marginnote">旋转式压缩机没有往复式那种「连杆-活塞」机构，滚子每转一圈完成一次压缩，运转平稳、噪音低——这也是分体空调外机可以挂在墙外、日夜运转的底气。</span>

**涡旋式压缩机**：两个螺旋涡盘啮合，一个固定、一个偏心平动，形成多个月牙形压缩腔连续压缩。效率高、静音，用于中高档空调与多联机。

无论哪种，工作过程都遵循同一条**四步循环**：吸气（低压蒸气进气缸）→ 压缩（压力温度升高）→ 排气（高压蒸气进冷凝器）→ 膨胀（气缸内残留高压气体回压）。四步不断重复，维持系统高压侧与低压侧的稳定压差。

**全封闭压缩机**：家用冰箱空调压缩机是**全封闭式**——电机与压缩机构封在一个焊接密封的钢壳内，壳体既是电机定子的一部分、也是散热表面。优点：密封性好、制冷剂不外漏、噪声小；代价：**内部故障无法修理，只能整体更换**。所以压缩机检修的重心，是「判断要不要换」而不是「修」——用绕组、绝缘、电流、压力数据把故障定性清楚，再决定更换。

**压缩机启动瞬间的电流**：启动时转子还没转起来、反电动势为零，启动电流可达运行电流的 5–8 倍——这正是「启动继电器 + 过载保护器」存在的意义：启动瞬时大电流由它们承受与保护，启动后电流回落。**量电流要等启动完成后再读运行值**，别把启动电流误判为过载。

## 2 单相压缩机：主副绕组与启动

冰箱空调压缩机内部是**单相异步电动机**，定子上有两套绕组：**主绕组（运行绕组，M）** 与 **副绕组（启动绕组，S）**，再加上公共端（C）。单相交流电产生的磁场不是旋转磁场，电机无法自行启动——必须靠副绕组创造启动转矩。<span class="marginnote">单相电机为什么转不起来？因为单相绕组通电后只产生「脉振磁场」，它不旋转。要让它转，必须把副绕组的电流与主绕组错开相位（移相），合成一个旋转磁场——这就是「启动电容移相」的原理。</span>

按启动方式，家用压缩机分三类：

| 启动方式 | 核心元件 | 启动后元件状态 | 典型应用 |
| --- | --- | --- | --- |
| 电阻分相（RSIR） | 启动继电器（PTC/重锤） | 启动绕组断电 | 老式冰箱、小功率 |
| 电容启动（CSIR） | 启动电容 + 启动继电器 | 电容与启动绕组断电 | 中大型冰箱 |
| 电容运转/双电容（PSC/CSR） | 运转电容（+启动电容） | 电容持续参与 | 空调压缩机 |

**启动继电器**的作用是「启动时接通副绕组，转起来后断开它」：**重锤式**靠启动电流吸合、运行后电流减小而释放；**PTC 热敏式**靠元件自身发热变高阻来切断。启动继电器开路或短路，压缩机就「只嗡嗡不转」或「转一下就停」。

## 3 公式解析：启动电容与移相

启动电容的核心作用，是把副绕组的电流相位**前移**，与主绕组电流形成相位差，从而产生旋转磁场：

$$\varphi = \arctan \frac{X_C}{R_S} = \arctan \frac{1}{2\pi f C R_S}$$

- **第一步，读符号**：$X_C = 1/(2\pi f C)$ 是电容的容抗，$C$ 是电容量，$f$ 是电源频率（50 Hz），$R_S$ 是副绕组电阻，$\varphi$ 是副绕组电流的相位超前角。
- **第二步，看相位关系**：电容使副绕组电流**超前**于电压，而主绕组电流滞后于电压——两路电流错开相位，合成磁场从超前相转向滞后相，旋转磁场由此产生。
- **第三步，连到故障**：**电容失容（容量下降）→ $X_C$ 变大 → 相位差缩小 → 启动转矩不足 → 压缩机「嗡嗡」不启动或启动困难**。所以量启动电容的容量（把电容挡读数与标称值对照，允许 ±10%）是「不启动」故障的首查项之一。<span class="marginnote">电容失容的典型特征是「启动慢、启动无力、负荷重时起不来」，但运转后看似正常。旧电容几乎都会容量衰减，换新电容前先放电——电解电容两极能存很久的电荷。</span>

## 4 保护装置：过载保护器与热保护

压缩机是制冷系统里最贵、最不可修的部件，因此每一台压缩机都配有**过载保护**，防止绕组过热烧毁：

**碟形过载保护器**：紧贴在压缩机壳体上的金属碟片 + 双金属片 + 加热丝，串在运行回路里。当电流过大（堵转、过载）或壳体温度过高时，双金属片受热变形跳开，切断压缩机电源；冷却后自动复位。<span class="marginnote">「外机转一会儿就停、凉了又能转」的周期现象，常是过载保护器在动作：电流大或散热差 → 壳体升温 → 保护跳开；冷却后复位又转。查清「为什么热」比换保护器重要得多。</span>

**绕组内置热保护器**：埋设在电机绕组内的 PTC/双金属元件，直接感知绕组温度，保护更精准，广泛用于旋转式压缩机。

**启动继电器的双重身份**：它既是启动元件，也承担部分保护——PTC 元件在启动电流下迅速升温变高阻，若压缩机堵转、启动电流持续，PTC 长时间处于高阻态可防止绕组长时间大电流。

**辨析｜易错点：** 过载保护器动作后不能「反复试机」——每试一次，压缩机绕组就多受一次大电流冲击。正确的做法是：先断电降温，查明过载的**原因**（电压、散热、电容、绕组、卡缸），排除后再通电。**保护器是症状的报警器，不是故障本身**。

## 5 压缩机常见故障与检修要点

**不启动**：先查供电 → 温控 → 过载保护器 → 启动继电器 → 电容 → 绕组。用万用表量绕组阻值：主、副绕组及公共端之间应有几十欧（制冷量越小阻值越大），**对地绝缘应 ≥ 1 MΩ**。

**启动频繁 / 过载保护跳闸**：量运行电流，对照铭牌。电流大 → 电压偏低、散热差、负载重（冰堵/脏堵使系统高压偏高）；电流正常却保护 → 保护器本身失灵或壳体温度过高。

**运转但制冷差**：压缩机排气能力不足——阀片磨损、内部泄漏。量吸气压力与排气压力可判（需压力表，见检漏篇）。

**运行电流的三类读法**：电流偏大 → 负载重（高压偏高、堵转、电压低）；电流偏小 → 负荷轻（缺氟、吸气压力低、排气能力差）；电流波动大 → 液击（回液）、系统不稳定。**电流表 + 压力表 + 温感是判断压缩机「干得怎么样」的三件套**，单靠听声往往误判。

**压缩机排气温度**：正常排气温度较高（壳体热但可手摸），但「烫得摸不得」多指系统异常——回气过热、制冷剂不足或堵。摸壳体温度、量电流、看压力，三者对照，压缩机状态八九不离十。

**卡缸（抱轴）**：压缩机内部机械卡死，通电后只有「嗡嗡」声且电流极大。轻度的可用「电容启动法」或敲击法尝试，重度只能换压缩机。<span class="marginnote">换压缩机不是「拆下旧的装上新」这么简单：要回收制冷剂、抽真空、换干燥过滤器、焊接、再充注——这是一整套系统性工序，也是「钎焊」与「检漏充注」两篇的基础。压缩机是冰箱空调维修的「总指挥」，换它就等于重建整个制冷系统。</span>

## 6 核心要点：压缩机检修术语与数据速查

把本节出现的术语与关键数据汇总成一张速查表，检修时随手可查：

| 术语/数据 | 含义 | 检修要点 |
| --- | --- | --- |
| 主绕组（M）/副绕组（S）/公共端（C） | 单相电机三端子 | 量端子间阻值定公共端 |
| 启动继电器 | 启动时接通副绕组 | PTC 开路/重锤触点坏则不启动 |
| 启动电容/运转电容 | 移相产生旋转磁场 | 失容则启动无力 |
| 过载保护器 | 电流大/过热跳开 | 保护跳闸先查「为什么热」 |
| 绕组对地绝缘 | 绕组与壳体间电阻 | ≥ 1 MΩ，低则漏电 |
| 卡缸（抱轴） | 机械卡死 | 嗡嗡声+电流大，重则换压缩机 |

**绕组识别的记忆法**：同一型号压缩机，**阻值最小的一组端子是主绕组、最大的是副绕组**（公共端与绕组另一端之间）；三端子两两间阻值满足「最大 = 两小之和」的关系——利用这个关系，即使没有接线图也能识别出 C/M/S 三端。

**换压缩机的完整工序**（回顾连接各篇）：回收制冷剂 → 拆旧机 → 新机到位 → 钎焊管路 → 更换干燥过滤器 → 检漏 → 抽真空 → 定量充注 → 通电试机。**任何一步省略，都可能让新压缩机「短命」**——这也是本章五至七节要一步步展开的原因。

## 7 小结

- 压缩机是制冷循环的**动力源**，分往复、旋转、涡旋三类；工作都走「吸→压→排→回」四步。
- 家用压缩机是**单相电机**，靠**主副绕组 + 启动继电器/电容**解决启动；启动元件坏则「嗡嗡不转」。
- 启动电容通过移相产生旋转磁场，**容量衰减是「启动无力」的高频病因**，量容量看是否失容。
- **过载保护器**串在回路里，电流过大或壳体过热即跳开；保护跳闸要查「为什么热」，而不是反复试机。
- 绕组阻值、对地绝缘、运行电流是压缩机检修的三组关键数据，先量后换。
