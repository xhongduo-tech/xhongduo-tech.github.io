## 为什么从波轮洗衣机结构开始

从本篇起，我们离开制冷系统，进入「电机 + 传动 + 程序控制」的世界——洗衣机。波轮洗衣机是结构最典型、维修最入门的机型：一台电机、一只波轮、一根传动轴，加上进水排水与程序控制，就构成完整的洗涤逻辑。<span class="marginnote">波轮与滚筒是洗衣机的两大流派：波轮靠「波轮搅水、衣物在桶内翻滚」洗涤，用水省、洗净比高、结构简单；滚筒靠「摔打」洗涤，护衣、省水但结构复杂（见滚筒篇）。先学会波轮，等于先掌握了洗衣机最基本的「电机→减速→搅水」传动链条。</span>本节把波轮的整机结构、洗涤与脱水两种传动路线、以及离合器等核心传动件讲透，为后面的电机检修、程序控制、故障诊断打好「机体」基础。

波轮洗衣机的传动是理解它的钥匙：**洗涤要慢速大扭矩正反转，脱水要高速单转**——两种截然不同的运动由同一台电机驱动，中间靠**离合器**切换。理解「一个电机怎么同时干两种活」，就理解了波轮洗衣机的核心。

## 1 波轮洗衣机整机结构

波轮洗衣机的整机由五大系统构成：

**洗涤系统**：洗涤桶（内桶）+ 波轮 + 传动系统。波轮装在桶底，转动时带动水流与衣物翻滚。

**传动系统**：电动机 + 减速机构 + 离合器 + 波轮轴/脱水轴。把电机的高速旋转变成波轮所需的慢速搅动（洗涤）或内桶的高速旋转（脱水）。

**进水排水系统**：进水电磁阀（控制进水）、水位开关（感知水位）、排水阀/排水电磁铁、排水管。<span class="marginnote">波轮机的进水排水是一条「阀」链：进水电磁阀得电进水、失电停止；水位开关感知到设定水位后主控停止进水；洗涤结束后排水电磁阀/牵引器打开排水阀排水。进水不止、不排水，八成在这条阀链上（详见水位控制篇）。</span>

**电气控制系统**：定时器/程序控制器（机械式）或电脑板（电子式）+ 电机电容 + 各种保护。

**箱体与悬挂系统**：外壳 + 吊簧/减震装置 + 底座。

## 2 洗涤传动：低速大扭矩的正反转

洗涤时，波轮需要**低速（约 150–200 r/min）大扭矩、周期性正反转**——这样衣物才能被充分搅动。传动路线是：

**电机 → 离合器减速 → 波轮轴 → 波轮**

**电机的选择**：传统波轮机用**PSC 单相电容运转电机**（正反转靠换向电路对调副绕组极性，见电机篇）。高档机型用**变频电机**（更静音、可调速）。

**减速方式**：多数波轮机靠**减速齿轮组**（在离合器/减速器内）把电机高速降为波轮低速。皮带传动（电机→离合器皮带轮）也是常见形式。<span class="marginnote">为什么洗涤要减速？波轮转速太高，衣物会贴桶壁甩不开、洗净效果差，且磨损大。低速大扭矩的波轮「揉搓」是洗涤质量的保障——这也是波轮洗衣机与滚筒「摔打」的差别所在。</span>

**正反转的实现**：洗涤程序让电机周期性换向（正转→停→反转→停）。机械定时器用触点组切换，电脑板用双向可控硅/继电器切换。**正反转能否顺畅，是波轮机「只朝一个方向转」故障的排查点**（见电机篇）。

## 3 脱水传动：高速单转的切换

脱水时，需要**内桶高速旋转（约 800–1000 r/min）**，利用离心力把衣物水分甩出。传动路线是：

**电机 → 离合器（脱开洗涤、锁止波轮）→ 脱水轴 → 内桶**

这里的关键是**离合器**——它负责在洗涤与脱水两种模式间切换：

**洗涤状态**：离合器让电机动力传给波轮轴（波轮转、内桶不转），脱水轴被制动。
**脱水状态**：离合器松开制动、锁止波轮，让电机动力传给脱水轴，带动内桶（波轮不转）高速旋转。<span class="marginnote">离合器是波轮机的「变速箱 + 刹车」：里面装着减速齿轮、离合弹簧、抱簧（制动带）、排水电磁铁/牵引器联动机构。洗涤→脱水切换时，抱簧抱住脱水轴制动内桶、排水阀同步打开排水。离合器磨损、抱簧失效，就会「只能洗不能脱」或「脱水不转」。</span>

**脱水前排水**：脱水必须先排空桶内水——所以脱水程序先开排水阀，水排尽后内桶才提速。**水位未降、衣物不平衡，主控会保护停机**。

## 4 公式解析：波轮转速与脱水离心力

脱水靠离心力甩水，离心力与转速的平方成正比：

$$F_c = m \omega^2 r = m r \left(\frac{2\pi n}{60}\right)^2$$

- **第一步，读符号**：$m$ 是衣物的质量，$r$ 是衣物距转动轴的距离（近似内桶半径），$n$ 是内桶转速（r/min），$\omega = 2\pi n/60$ 是角速度。
- **第二步，看转速的角色**：$F_c$ 与 $n$ 的**平方**成正比——转速从 500 提到 1000 r/min，离心力变成 4 倍。这正是脱水桶要高速的原因：低速甩不动水。
- **第三步，连到故障**：**脱水转速不足 → 甩不干**。原因可能是电压偏低、电机电容失容（启动无力）、皮带打滑、离合器拖滞。量转速/听声可初步判断，量电容与皮带状态再定位。<span class="marginnote">转速与离心力的平方关系，也解释了「衣物不平衡」为什么危险：偏心质量在高转速下产生巨大振动，严重时「跳舞」移位、撞箱。所以脱水前主控要「均布衣物」试转，检测偏心过大就保护停机。</span>

## 5 波轮洗衣机常见结构与传动故障

**波轮不转 / 洗涤无力**：

**皮带问题**：皮带松弛、打滑 → 波轮转得慢或不动。压紧皮带或更换。
**电容失容**：PSC 电机启动无力，正转无力甚至不转。量电容容量。
**离合器损坏**：离合器内部齿轮打滑、抱簧失效。洗涤时听不到「咔嗒」切换声、波轮空转，疑离合器。
**波轮卡滞**：波轮下卡入硬币、异物，或波轮轴磨损打滑。拆波轮检查。

**能洗不能脱 / 脱水不转**：

**门开关/盖开关**：脱水需盖好机盖，盖开关未闭合则拒绝脱水。
**离合器抱簧/制动**：制动未松开、抱簧失效，内桶带不动。检查抱簧、排水牵引联动。
**排水不畅**：水没排空，主控保护不进入脱水。查排水阀、排水管是否堵。

**洗涤噪声大**：波轮下异物、轴承磨损、皮带老化、减速机构缺油。拆机逐项排查。<span class="marginnote">「波轮下有异物」是波轮机噪声与波轮卡滞的头号外部原因：硬币、纽扣、发卡掉进波轮底部，摩擦桶壁发出刺耳声甚至卡死波轮。拆下波轮清理，十有八九立竿见影。</span>

**波轮轴密封漏水**：波轮轴处渗水，多为轴密封圈磨损、老化——水从波轮轴与桶底之间渗出。检修：拆波轮查密封圈，更换后装回并试水。**波轮下的水渍常被误认为「洗涤时溅水」，实际是密封圈漏**——检查时留意桶底有无持续渗水。

**波轮机的排水路径**：洗涤后污水经排水阀从桶底排出，经排水管流入地漏。**排水管不能过高或压扁**——排水管被压扁是「排水缓慢、不排水」的隐蔽原因，检查时顺着排水路径逐段摸。

**小结前的自查**：本节的整机结构、洗涤/脱水传动、离合器与常见故障，构成了波轮洗衣机检修的完整底座——**下节滚筒洗衣机的「摔打」与直驱，就是在这一底座上换一种传动方式**。

## 6 核心要点：波轮洗衣机传动检修速查

把波轮机的传动故障浓缩成一张速查表：

| 症状 | 首查 | 关键点 |
| --- | --- | --- |
| 波轮不转 | 皮带、电容、波轮异物 | 空转试验、量电容 |
| 洗涤无力 | 皮带松、电容失容 | 张紧/换皮带、换电容 |
| 不能脱水 | 盖开关、抱簧、排水 | 盖开关通断、抱簧 |
| 脱水不干 | 电容、皮带、离合器 | 量电容、查打滑 |
| 洗涤异响 | 波轮下异物、轴承 | 拆波轮、查轴承 |
| 波轮空转不搅水 | 波轮轴打滑 | 拆波轮查轴 |

**「空转试验」的操作细节**：断电后拆下皮带，手拨/通电让电机单独转——能转说明电机好、问题在负载侧（波轮卡、离合器抱死）；不转再量电机绕组与电容。**这一招把「电机问题」与「传动问题」一刀切开**，是所有电机驱动设备的通用排障法。

**波轮机的日常保养建议**：洗衣前掏净口袋（硬币、钥匙、发卡）、定期清理波轮底部与过滤器、脱水衣物尽量放匀。**很多波轮机故障不是坏，是「被喂进去的东西」弄坏的**——清洁习惯能省下大半报修。

## 7 小结

- 波轮洗衣机由**洗涤、传动、进水排水、电气控制、箱体悬挂**五大系统构成，传动是核心。
- 洗涤靠**低速大扭矩正反转**，脱水靠**高速单转**，两种运动由同一电机 + **离合器**切换。
- 传动路线两分：洗涤「电机→离合器→波轮轴→波轮」，脱水「电机→离合器→脱水轴→内桶」。
- 脱水靠离心力甩水，**力与转速平方成正比**；转速不足甩不干，偏心大则跳舞保护。
- 波轮不转查皮带/电容/离合器/波轮异物；不能脱水查盖开关/抱簧/排水；噪声先查波轮下异物。
