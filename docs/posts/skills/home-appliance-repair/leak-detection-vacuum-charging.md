## 为什么从检漏、抽真空、充注开始

上一节我们学会了钎焊，但焊口到底密封不密封？修过的系统里还有没有水分？该加多少制冷剂？这三问，分别由本节的三道工序回答：**检漏**验证系统密封，**抽真空**去除系统内的空气与水分，**充注**让系统重新达到正确的制冷剂量。<span class="marginnote">这三道工序是一套完整闭环：检漏不过 → 真空白抽；真空不净 → 冰堵脏堵；充注不准 → 制冷差或高压报警。少做任何一道，前面换的压缩机、补的焊口都可能白费——「开系统 = 检漏 + 抽空 + 充注」是维修工脑中的固定套餐。</span>「制冷剂少了（缺氟）」是冰箱空调最高频的诊断，而真正的修法不是「再加一点」，而是**找到漏点补好、重新抽真空、按量充注**——这才是根治。

本节把三种检漏方法、抽真空的原理与标准、充注量的计算与判断讲透，最后给一张「充注后验收」清单。掌握这套流程，才算真正「开过系统」。

## 1 检漏：找到那个让氟跑光的洞

系统漏制冷剂有三个典型症状：**制冷量下降、运行电流偏小、压缩机运转时间长**。检漏方法从粗到精有三种：

**肥皂水检漏**：在疑似泄漏点（焊口、接头、阀芯）涂肥皂水，有泄漏处会冒泡。直观、便宜、适合**已无压或低压**系统先做粗查。要点：调成较浓的皂液、静置观察、从高压侧开始逐点排查。<span class="marginnote">肥皂水检漏是最「土」也最可靠的方法之一：焊口、螺纹接头、气门芯是三大高频漏点。它不需要专用设备，适合维修点现场先做一轮粗查，再用专业仪器精确定位。</span>

**压力检漏**：向系统充入干燥氮气（或制冷剂+氮气），打到规定压力（冰箱约 1.0–1.5 MPa），保压一段时间看压力是否下降。**保压时间越长越可靠**——微漏往往需要数小时才暴露。若压力明显下降，说明有漏点，配合肥皂水定位。

**电子检漏仪（卤素检漏仪）**：探头靠近可疑点，检测空气中制冷剂浓度，灵敏、快速、能定位微漏。R600a 系统还应配用可燃气体检测仪（防爆考虑）。<span class="marginnote">电子检漏仪的工作原理：探头的卤素感应/半导体传感器对含卤或碳氢制冷剂敏感，靠近漏点浓度升高即报警。它能把肥皂水查不出的微漏找出来，是「查了半天找不到漏」时的最后手段。</span>

## 2 抽真空：去除空气与水分

**抽真空（vacuum）** 用真空泵把系统内抽成负压，目的是排出两样东西：**空气**（不凝性气体，会推高冷凝压力）与**水分**（会在毛细管结冰形成冰堵）。标准做法：

**连接真空泵**：从维修口（工艺管/低压接口）接真空泵，先打开系统所有阀件。

**抽真空**：家用冰箱抽真空一般 **15–30 分钟**（或用双级泵达到规定真空度），真空度应达到 **-0.1 MPa（100 Pa 级）** 以下。<span class="marginnote">真空度是「抽没抽干净」的判据：单级泵抽到 -0.09 MPa 往往不够，残留水分仍会作怪；双级泵能抽到 100 Pa 以下，更适合严格维修。抽完观察真空表是否回升——回升说明有漏，先补漏再抽。</span>

**静置确认**：停泵后保真空一段时间，若真空度保持不回升，说明系统密封良好，可以充注。

**换干燥过滤器**：凡开系统（换压缩机、焊管、检漏修补），都应**同步更换干燥过滤器**——它负责吸附残余水分，是防冰堵的最后防线。

## 3 充注：加多少制冷剂才算对

制冷剂充注量必须**准确**：少了，蒸发器制冷不足；多了，冷凝压力升高、高压保护、效率下降。家用机通常**按铭牌标称重量定量充注**（以克为单位），是精度最高的方式。没有定量条件的，用**观察法**：

**观察法判断**：边充边看。以冰箱为例，正常时**回气管（低压管）用手摸应发凉、结露而不结厚霜**；蒸发器均匀结霜；压缩机运行电流接近铭牌；吸排气温差明显。<span class="marginnote">观察法的几组手感信号：回气管「凉而不厚霜」说明蒸发完全、充注适量；回气管过热是缺氟（过热度大）；回气管结厚霜是过量（液击回液）。这些「手感」需要积累，但方向是确定的——充注以蒸发器吸热充分、回气不结厚霜为佳。</span>

充注操作要点：

**排空充注**：先打开钢瓶阀排出充注管内的空气（避免空气进系统），再接维修口充注。

**边充边测**：充到接近标称量时改用观察法，微调至合适。**切勿一次性过量**——多充比少充更难处理（需要回收）。

**封口**：充注完成后，用钳口/封口钳封死工艺管，再检漏确认无泄漏。

**操作安全**：制冷剂钢瓶属**压力容器**，存放远离热源与明火，搬运防止碰撞；R600a 钢瓶作业区严禁烟火、保持通风。充注时戴**护目镜与防护手套**——制冷剂接触皮肤会冻伤。**「先看安全、再谈工艺」在制冷剂操作上体现得最直接**。

## 4 公式解析：制冷剂流量与制冷量的关系

充注量直接影响制冷量，背后的物理是：制冷量等于制冷剂质量流量乘单位质量吸热量：

$$Q_e = \dot{m} \cdot (h_1 - h_4)$$

- **第一步，读符号**：$\dot{m}$ 是制冷剂质量流量（kg/s），$h_1$ 是蒸发器出口制冷剂蒸气的比焓，$h_4$ 是节流后进入蒸发器的液态制冷剂比焓，$h_1 - h_4$ 是每千克制冷剂在蒸发器里吸收的热量。
- **第二步，看充注量的影响**：充注不足 → 进入蒸发器的液量少 → $\dot{m}$ 小 → $Q_e$ 下降，制冷差。充注过量 → 冷凝器积液、高压升高、$\dot{m}$ 未必增加但耗功增大，效率下降。
- **第三步，连到维修**：**流量是「量」的问题，温差焓差是「质」的问题**。缺氟（量不足）与换热差（质不足，见换热篇）都表现为制冷差，但要区分——量压力、量管温、看回气，正是为分辨这两类病因。

## 5 充注后验收清单

一套完整的开系统维修，交付前按这个清单过一遍：

| 检查项 | 合格判据 |
| --- | --- |
| 焊口/接头 | 检漏仪无报警、肥皂水无泡 |
| 真空度 | 抽空达标、停泵后不回升 |
| 充注量 | 按铭牌定量或观察法合适 |
| 回气管 | 发凉、结露、不结厚霜 |
| 运行电流 | 接近铭牌、平稳 |
| 蒸发器 | 均匀结霜、制冷量恢复 |
| 高低压 | 压力符合该机型正常值 |

**辨析｜易错点：**「缺氟就加点」是维修最常见的错误姿势。不查漏点直接加氟，制冷剂很快又漏光——**加氟不是修，补漏抽空再定量充注才是修**。另一个错误是「凭手感加氟不加量」：家用机铭牌都标了充注量，能定量就定量。

## 6 核心要点：检漏抽空充注流程速查

把「开系统」的完整工序浓缩成一张流程表：

| 工序 | 目的 | 合格判据 |
| --- | --- | --- |
| 检漏（肥皂水） | 粗查漏点 | 无气泡 |
| 检漏（压力保压） | 验证密封 | 保压压力不降 |
| 检漏（电子仪） | 精定位微漏 | 无报警 |
| 抽真空 | 排空气与水分 | 真空度 -0.1 MPa 级、静置不回升 |
| 换干燥过滤器 | 吸附残余水分 | 同步更换 |
| 定量充注 | 恢复制冷剂量 | 按铭牌克数 |
| 封口复检 | 确认无泄漏 | 检漏仪无报警 |

**「缺氟」诊断的完整链条**：制冷差 → 摸回气管过热（疑缺氟）→ 检漏找漏点 → 补漏 → 抽真空 → 换干燥过滤器 → 定量充注。**只走「制冷差→加氟」两步，等于没修**——漏点还在，氟还会漏光。

**R600a 与 R134a 的工序差异**：R134a 系统检漏可用卤素检漏仪；R600a 系统必须用**可燃气体检测仪**确认无残留，且回收、抽空要求更高。**同一套工序，两种制冷剂的安全等级不同**——这正体现了「先认制冷剂、再定工序」的职业素养。

**制冷剂钢瓶的保存**：钢瓶直立存放、远离热源与明火、避免暴晒；R600a 钢瓶存放处严禁烟火。**制冷剂也是「危险化学品」，保存规范与操作规范同样重要**——钢瓶倒置可能让液态制冷剂进入管路造成液击。

**「开系统」前的一次清单确认**：检漏仪/肥皂水备好？真空泵油位正常？干燥过滤器已备？充注秤/量杯在校准？**把这四样过一遍再动手，比焊到一半才发现缺工具划算得多**——「开系统」是整套工序，一次准备、一次做完，系统才少一次进气的机会。

## 7 小结

- 检漏三法：**肥皂水**（粗查）、**压力保压**（验证）、**电子检漏仪**（精确定位微漏）。
- 抽真空排出**空气与水分**，真空度 -0.1 MPa 级、静置不回升才合格；开系统必换**干燥过滤器**。
- 充注按**铭牌定量**最准，无条件时用**观察法**（回气发凉不结厚霜、电流接近铭牌）。
- 制冷量 = 流量 × 单位吸热量：缺氟是「量不足」，换热差是「质不足」，要分开诊断。
- **补漏 + 抽空 + 定量充注**是一套完整流程，缺氟直接加氟不治本。

**本节要点回顾**：检漏找漏点、抽空除水气、充注定量——「开系统」是一次性完整流程，少了任何一步都会让前面的修复白费。

**一句话总结**：检漏靠耐心、抽空靠真空度、充注靠定量——「开系统」三步走完，制冷系统才算真正修好。
