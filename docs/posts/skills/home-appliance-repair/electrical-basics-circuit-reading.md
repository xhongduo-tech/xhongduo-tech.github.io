## 为什么从电工基础开始

上一节立住了「安全是手艺的公理」，而安全规则背后的物理，正是本节的三块基石：**电压、电流、电阻**。冰箱压缩机为什么 220 V 能转？洗衣机脱水桶为何要并一个大电容？电路图上那个弯折的符号代表什么？不把「电流怎么流动、电器为什么耗电」想清楚，后面的每个故障判断都只是背口诀。反过来，一旦掌握电路语言，**任何一台家电的说明书电路图，都变成了可以逐点追问的对象**——这正是「从极限到大模型」式的学习法：先建立最小公理集，再在之上推导一切。<span class="marginnote">这一节也是与知识树其他分支的连接点：欧姆定律在第二级《电路》与《物理》中都有严格展开，这里只取维修够用的版本；而「读图即建模」的思维，与第三级《数字逻辑》的时序图、第四级《计算机组成原理》的数据通路一脉相承。</span>

读图能力的养成，靠的是「从最小的机器开始练」。家用电路千变万化，但都是由「串联管通断、并联管独立」两种接法组合而成；本章第五节用欧姆定律算电热水器加热管，第六节用一盏电热水壶完整演示「沿回路逐点量」的方法——小机器练会了，冰箱、空调的大回路只是更多元件的串联并联。**读图不是背图，而是会拆图**。

## 1 电压、电流与电阻：电路的三要素

**电流（current）**：电荷的定向移动形成电流，单位安培（A）。习惯规定正电荷移动的方向为电流方向。**电压（voltage）**：推动电荷移动的「势」，单位伏特（V），是两点之间的电位差。**电阻（resistance）**：导体对电流的阻碍作用，单位欧姆（Ω）。

三者被**欧姆定律（Ohm's law）** 绑成一条直线关系：

$$I = \frac{U}{R}$$

电流等于电压除以电阻。直觉上：电压是「推手」，电阻是「阻力」，推手越大电流越大，阻力越大电流越小。这台冰箱启动瞬间电流为什么比正常运行时大好几倍？因为启动时电机绕组近似纯电阻、阻抗小，转起来后产生了反电动势、等效阻抗变大——这些都是欧姆定律在不同时刻的应用。<span class="marginnote">欧姆定律是维修工脑中时刻运行的一条默认公式：测到一个 2 kΩ 的加热管，接上 220 V，心算电流约 0.11 A，再乘电压得功率约 24 W——先有数量级感，再上仪器。</span>

**电功率（electric power）**：单位时间消耗的电能，单位瓦特（W）：

$$P = U \times I$$

功率等于电压乘电流。一台标注 220 V、10 A 的电器，最大功率约 2200 W，与插头、电线、断路器的规格必须匹配——**功率超限是电线过热起火的主要诱因**。

## 2 交流电与家用电网

家用电器用的是**交流电（alternating current, AC）**：电压大小和方向随时间周期性变化。中国家庭供电标准是**单相 220 V、频率 50 Hz**——电压有效值 220 V，每秒完成 50 个周期。交流电的「220 V」是**有效值**，其峰值电压约 220 × √2 ≈ 311 V。<span class="marginnote">有效值是把交流电与直流电「发热效果」等同的等效值，$U_{rms} = U_{peak}/\sqrt{2}$。修电机、选电容耐压时，必须按峰值而非有效值考量绝缘与耐压。</span>

家庭配电经电表、总断路器（空气开关）引入，再分路到各个房间。对维修工最重要的是识别**三根线**：<span class="marginnote">新国标用颜色区分：火线（L）棕色/红色，零线（N）蓝色，地线（PE）黄绿双色。家电维修中颜色是线索但不是保证——老电器改过线后颜色可能失效，必须用仪表实测确认。</span>

**火线（L, live）**：对地电压约 220 V，是危险源。
**零线（N, neutral）**：正常工作时对地电压接近 0 V。
- **地线（PE, protective earth）**：接大地的保护线，正常时不带电，用于把外壳故障电位引走。

**辨析｜易错点：** 不少初学者以为零线就是「没电的线」。实际上零线在负载回路中同样承载电流，且若零线断开，火线会经负载串到断点之后，使原本「不带电」的部分带电。**永远把零线当作可能带电来对待**，按上一节流程先断电验电。

## 3 串联、并联与混合电路

两个元件只有一种接法两种：**串联**——电流依次流过，一处断开全路不通；**并联**——两端分别相连，电压相同，各支路独立。

| 比较维度 | 串联 | 并联 |
| --- | --- | --- |
| 电流 | 处处相等 $I = I_1 = I_2$ | 各支路按电阻分配，$I = I_1 + I_2$ |
| 电压 | 按电阻分压，$U = U_1 + U_2$ | 各支路电压相等 |
| 总电阻 | $R = R_1 + R_2$ | $1/R = 1/R_1 + 1/R_2$ |
| 家电实例 | 温控器串在压缩机回路里 | 照明灯、插座并联在电网上 |

家电电路中，**开关、温控器、保护器必须串联**在负载回路中（它们要「通断」整条路）；而**各用电部件并联**在电源两端（它们要独立工作）。读懂一个家电电路，第一步就是**沿电流路径分清串并联**：从火线出发，经过哪些元件，回到零线，中间有没有分支——这条路径就是整机的「主回路」。

## 4 电路图符号与识读方法

维修工面对的是两类图：**电气原理图**（用符号表达逻辑连接）与**接线图**（表达实际物理接线）。先会读原理图，再对照接线图找实物。

常用符号要形成肌肉记忆：<span class="marginnote">电路符号在 GB/T 4728《电气简图用图形符号》中有标准规定，但各家电厂家的图纸常有自己的习惯画法——原理一致、画法略有出入，不必因符号差异慌张。</span>电阻画作锯齿线或矩形、电容画作两平行线、电感/线圈画作螺旋或圆弧、熔断器画作方框带 X、电动机画作圆圈带 M、开关画作闸刀形、温控器在开关符号上标「TC」字样。

识读一张家电原理图，按三步走：

**第一步，找电源**：找到 L、N 端子，确认供电从哪进。**第二步，追主回路**：从 L 出发，把串联在路上的元件逐个点名——开关、温控器、保护器、负载（压缩机/加热管/电机）。**第三步，看支路**：主回路之外的并联支路，往往是启动电容、指示灯、控制板供电等，它们各自完成辅助功能。

以一台最简单的直冷冰箱电路为例：电源 → 温控器 → 过载保护器 → 压缩机绕组 → 电源，另有启动器与启动电容并在压缩机启动绕组上。读懂这条链，就为第六节以后「不制冷先查哪几个点」埋下了伏笔。

## 5 公式解析：用欧姆定律给故障定位

维修中大量判断建立在两个公式的快速心算上，我们把它们拆开看：

$$P = UI = I^2 R = \frac{U^2}{R}$$

- **第一步，三个等价式**：由 $U = IR$ 代入 $P = UI$，得 $P = I^2 R$；再由 $I = U/R$ 得 $P = U^2 / R$。三个形式在三种场景下各有方便处。
- **第二步，测电热器具**：一台标注 220 V、1500 W 的电热水器加热管，正常电阻应为 $R = U^2 / P = 220^2 / 1500 ≈ 32.3\ \Omega$。实测若为无穷大 → 加热管断路；若明显偏小 → 绝缘可能击穿。**用铭牌功率反推电阻，再与实测对照**，是最常用的一招。
- **第三步，估电流**：同一台加热管工作电流 $I = P/U ≈ 6.8\ \text{A}$，据此判断该回路断路器容量（应 ≥ 1.25 倍工作电流）是否够。

## 6 实战案例：读懂一台电热水壶的电路

把前三节的方法落到一台最简单的家电上。电热水壶结构极简，却浓缩了电路识读的全部要点：

**部件清单**：电源线（三脚插头）、底座耦合器、加热盘（电热丝）、蒸汽开关（双金属片/感温）、过热熔断器、指示灯。<span class="marginnote">电热水壶是「串联链」的教科书：电源 → 底座触点 → 蒸汽开关 → 过热熔断器 → 加热盘 → 电源。链上任意一环断开，整壶「不通电」。指示灯经电阻并联在加热盘上，是唯一的并联支路——所以读它的电路，就是读一条链加一个旁路。</span>

**电路主回路**：火线 → 底座火触点 → 蒸汽开关 → 过热熔断器 → 加热盘 → 底座零触点 → 零线。**蒸汽开关**是壶的「大脑」：水烧开时蒸汽推动双金属片动作、断开电路；**过热熔断器**是兜底：水烧干、温度异常时熔断，防止干烧起火。

**故障排查实战**：「水烧不开 / 不加热」时，沿链逐点量：
测底座有无 220 V → 无电查电源线与耦合器接触。
测蒸汽开关通断 → 常开不通，开关坏或已跳开未复位。
- 测过热熔断器通断 → 不通则已熔断（要查烧干原因）。
- 测加热盘阻值 → 正常约 30–50 Ω（由 $R=U^2/P$，1500–2200 W），无穷大即烧断。

按这条链逐点量，10 分钟定位。<span class="marginnote">维修的「以小见大」：电热水壶练会「沿回路逐点量」，冰箱的「温控→保护→压缩机」也是同一条链的放大版。会读小机器，才能读大机器——这一招放到后面每一篇整机维修里。</span>

## 7 小结

- 电路三要素**电压、电流、电阻**由欧姆定律 $I=U/R$ 统一；功率 $P=UI$
