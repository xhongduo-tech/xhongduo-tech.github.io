## 为什么从燃气热水器开始

电热水器把电变成热，燃气热水器把**燃气的化学能**变成热——同样的目的，完全不同的能量来源，也带来完全不同的结构与安全逻辑。燃气热水器是四大家电里**唯一涉及燃烧**的：有燃气、有火焰、有废气（一氧化碳），安全保护必须三重冗余。<span class="marginnote">燃气热水器的维修是「气、水、电、风」四路系统的协同：气路供燃气、水路供冷水、电路控制与点火、风路排废气。任何一路异常，热水器都可能「不点火」「忽冷忽热」或「报警停机」。读懂这四路，就掌握了燃气热水器。</span>本节讲结构与燃烧系统，重点是「怎么安全地点火、燃烧、排烟」。

燃气热水器是「气、水、电、风」四路协同的机器，也是四大家电里唯一涉及燃烧的：有燃气、有火焰、有废气。本章第三节把「水气联动—点火—火焰检测」的安全链讲透，第四节用甲烷燃烧方程点明一氧化碳的来路——**读懂四路协同，是安全维修燃气热水器的前提**。

## 1 燃气热水器类型与总体结构

按排烟方式，家用燃气热水器分四代：

**直排式**：燃烧废气直接排入室内，已因一氧化碳中毒风险被国家禁止生产销售。
**烟道式**：靠自然抽力排烟，抗风差，也在淘汰中。
**强排式（强制排气）**：内置**排烟风机**强制把废气排出室外，是当前主流。<span class="marginnote">强排式靠风机把燃烧废气「吹」出室外，比自然抽力可靠得多。判断标准是「有没有排烟风机」——强排机开机时风机先转、再点火，这是它的安全时序。</span>
**平衡式（强制给排气）**：燃烧所需的空气也从室外引入，全密闭燃烧，可用于浴室内，是安全等级最高的家用型。

**总体结构**：外壳内包含**水路系统**（进水管、水气联动/水流量传感器、热交换器、出水管）、**燃气系统**（燃气阀、燃烧器、点火器、火焰检测）、**排烟系统**（风机、烟道）、**电控系统**（主控板、温度控制、各种保护开关）。

## 2 水路系统与水量控制

燃气热水器是**即热式**：冷水通过热交换器，被火焰加热后立即出水，没有储水。它的水路核心是**水气联动**——有水流动才允许通气点火，无水则切断燃气。

**水气联动阀（水动阀）**：老式用机械膜片——水流推动膜片，膜片带动顶杆打开燃气阀；水停则膜片复位、燃气切断。<span class="marginnote">机械水气联动阀的逻辑是「水推气」：水不流，燃气门就打不开。它的典型故障是膜片破损（水渗进燃气侧或联动失灵）、顶杆卡滞——表现为「有水不开气、点不着火」或「水小不点火」。</span>

**水流量传感器（霍尔式）**：现代机型用涡轮 + 霍尔传感器检测水流量，把流量变成脉冲频率送给主控板，主控再决定是否点火、火力多大。<span class="marginnote">霍尔传感器靠「涡轮转、磁铁转、霍尔测转速」把水流变成电脉冲：水流越大，脉冲频率越高。它比机械联动更精确，但怕磁铁退磁、涡轮卡异物。检修「不出热水」时，可拆下传感器看涡轮是否卡滞。</span>

**热交换器**：燃气燃烧的火焰加热铜质热交换器，水流经其内吸热升温。热交换器**翅片积碳、内部结垢**会使换热效率下降——「水温不高、火力已最大」时优先查它。

## 3 燃气与燃烧系统

燃气系统是一条「阀门—燃烧—检测」的安全链：

**燃气阀（电磁阀）**：主控板控制的通断阀门，常见有主燃气阀与分段阀。断电即关——**电磁阀必须在得电时才能保持打开**，这是「意外停电自动断气」的安全设计。

**点火器**：点火时先由点火器产生高压火花，点燃燃烧器喷出的燃气-空气混合气。**点火失败**是燃气热水器最高频故障之一：不放电（点火器坏）、不打火（主板没指令）、有火不燃（燃气没到/风压保护）。

**火焰检测（熄火保护）**：用**火焰离子检测**——火焰中有离子，探针在火焰中能检测到微弱电流。若燃烧中途熄火，检测信号消失，主控立即切断燃气阀。<span class="marginnote">「离子火焰检测」是燃气具的标准安全机制：燃烧时火焰把探针与燃烧器之间的空气电离，形成微弱电流；火焰熄灭，电流消失，控制器在数秒内切断燃气，防止燃气泄漏。检修「点着火又马上灭」要查探针位置、绝缘与信号线。</span>

**燃烧化学反应**：家用天然气主要成分是甲烷：

$$\ce{CH4 + 2O2 -> CO2 + 2H2O}$$

甲烷完全燃烧生成二氧化碳与水。若氧气不足，会生成一氧化碳（CO）：

$$\ce{2CH4 + 3O2 -> 2CO + 4H2O}$$
**燃烧的工程参数**：家用燃气热水器标注「热负荷」（kW），表示单位时间燃烧放热的能力——热负荷越大，可加热的水量越多。检修中常关注两个参数：**燃气压力**（过低则火力不足、水温上不来）与**进水量**（过大则温升不足）。**「水温不够热」先看这两个量的匹配**。

## 3 燃烧器与换热器结构

**燃烧器（火排）**：燃气从喷嘴喷出，与空气混合后经火排（多孔燃烧器）喷出燃烧。火排是「燃烧面」，孔径堵塞、变形会影响燃烧均匀性。

**换热器（水箱/热交换器）**：燃烧热量传给流经的水。家用机多为**铜制翅片式换热器**，水流在铜管内、高温烟气掠过翅片。换热器**积垢**（水垢）会降低换热效率——「用久了热得慢」的一大原因。

**排烟系统**：燃烧废气经排烟管排出室外。**排烟不畅、倒灌**是重大安全隐患（一氧化碳中毒），检修时务必检查排烟管通畅与室外出口。<span class="marginnote">燃气热水器的「三分靠机器、七分靠排烟」：排烟管弯曲过多、出口被堵、装在密闭空间，都会让一氧化碳回灌室内。<strong>检修燃气热水器，先查排烟，再查燃烧</strong>——安全永远在前。</span>

## 4 点火与火焰检测的故障排查

**点火失败**是燃气热水器最高频故障，按三步查：

**不放电**：点火器不产生高压火花——查点火器供电、点火器本身、放电针间隙（过大或过小都难放电）。

**有火不燃**：点火器放电了但燃气没点着——查燃气阀（没得电/没打开）、燃气压力、风压保护（排烟不畅时风压开关动作，禁止点火）。

**点着又灭**：燃烧中途熄火——火焰检测探针位置不对、氧化、信号线断，主控误判熄火而切断燃气。<span class="marginnote">「点着又马上灭」的排查顺序：先看火焰探针与燃烧器是否接触良好、探针有无氧化，再量探针信号线，最后疑主控。<strong>熄火保护是「防漏气」的底线，探针脏了它就会「误杀」</strong>。</span>

## 5 核心要点：燃气系统故障速查

| 现象 | 首查 | 关键点 |
| --- | --- | --- |
| 点火不放电 | 点火器、放电针 | 供电、间隙 |
| 有火不燃 | 燃气阀、风压保护 | 得电、压力、风压 |
| 点着又灭 | 火焰探针 | 位置、氧化、信号线 |
| 水温不够热 | 燃气压力、进水量 | 热负荷匹配 |
| 排烟异常 | 排烟管、风机 | 通畅、室外出口 |

**燃气检修的安全纪律**：检修前**先关气、再通风**；检修时用肥皂水查漏气；检修后确认无泄漏再点火试机。**燃气热水器检修「安全永远第一」**——漏气的代价不是钱，是命。

## 6 小结

- 燃气热水器靠**燃烧放热**加热水，核心反应是甲烷完全燃烧 $\ce{CH4 + 2O2 -> CO2 + 2H2O}$；缺氧则生成有毒的 CO。
- 安全链是「**燃气阀 + 点火器 + 火焰检测（熄火保护）**」：断电断气、点火确认、熄火立即关气。
- 燃烧器（火排）与换热器（水箱）是两大核心部件；水垢降低换热、排烟不畅危及生命。
- 「点火不放电、有火不燃、点着又灭」是三大高频故障，分别查点火器、燃气/风压、火焰探针。
- **检修先关气通风、后点火试机**——燃气安全是热水器维修的最高优先级。

**燃气热水器的类型**：按排气方式分**强排式**（风机强制排烟，主流）与**平衡式**（可装在浴室内，更安全）；按点火分**脉冲点火**与**水气联动点火**。**检修先认机型**——强排式多一个排烟风机与风压开关，故障也多在排气链上。

**燃烧的「空气-燃气比」**：燃烧需要合适比例的空气。空气不足 → 燃烧不完全 → 产生 CO 且火焰发黄；空气过多 → 火焰发蓝但热效率下降。**火焰发黄、熏黑换热器，是「空气不足/燃烧不完全」的直观信号**——查风量、查火排堵塞。

**燃气压力与喷嘴**：喷嘴孔径决定燃气流量，堵塞则火力不足；燃气压力波动则水温不稳。**检修「火力小、水温低」先查喷嘴与燃气压力**。

**小结前的自查**：本节把燃烧反应、安全链、燃烧器、点火检测讲透——**下一节的温控与安全装置，将给热水器的「火」配上「闸」**。

**燃烧安全的三道闸**：燃气阀（断电断气）、风压开关（排烟不畅禁点火）、熄火保护（燃烧中断立即关气）——**三道闸层层设防，任何一道失效都意味着「燃气安全少一分」**。检修时三道闸逐一确认，再谈燃烧效果。

**一句话收尾**：燃气热水器的核心是「烧得稳、排得畅、灭得快」——燃烧稳定、排烟通畅、熄火保护灵敏，热水器才安全又舒适。

**燃气检修的三件套**：肥皂水（查漏气）、可燃气体检测仪（查残留）、压力表（查燃气压力）——**三件套备齐，燃气系统的故障排查才完整**。

**燃烧检修的「三看三查」**：看火焰（蓝火正常、黄火异常）、看排烟（顺畅无倒灌）、看换热器（积垢少）；查燃气压力、查风压开关、查熄火保护——**三看三查走完，燃烧系统的状态就清楚了**。

**一句话收尾**：燃气热水器「烧得稳、排得畅、灭得快」——把燃烧与安全链吃透，燃气系统检修就稳了。

安全第一、燃烧第二——燃气热水器检修，永远是这句话。
