## 为什么从洗衣机故障诊断开始

前四节我们把洗衣机拆成了结构（波轮/滚筒）、电机（含离合器）、程序控制、水位温控四大块，现在把它们装回一台整机，从一个「用户报修」的完整症状出发做综合诊断。<span class="marginnote">洗衣机诊断与冰箱空调不同的地方在于：它的故障大多「看得见、摸得着」——不进水位看阀、不排水看泵、不转看电机、不脱水看盖开关与离合器。按「进水→洗涤→排水→脱水」的程序链，卡在哪一步就查哪一步，是洗衣机诊断的基本框架。</span>本节按「不进水/进水不止、不排水、不转/洗涤无力、不脱水/脱水异常、漏水、噪声」六个高频症状，各给一条从现象到原因的排查路线，最后配一张速查表。

洗衣机诊断的一条总纲先立住：**把症状挂到程序链上**。洗衣机的工作是一条固定流水线——进水、洗涤、排水、脱水、漂洗、再排水、再脱水。报修时先问「卡在哪一步」：没到那一步就停，是前一步的条件没满足（水没进够、盖没合上）；到了那一步不动，是那一步的执行件或控制出了问题。

## 1 不进水 / 进水不止

**不进水**（通电后水不进桶）：

**进水阀**：量进水阀线圈（220 V 机型线圈阻值常见几百欧至几千欧）。线圈开路则不动作；阀芯卡滞则得电不进水。<span class="marginnote">进水阀是「电控水」的执行件：线圈得电吸起阀芯、水压推开阀门进水。查它分两步——先量线圈通断（电有没有、线圈坏没坏），再听阀体有无「咔嗒」吸合声（机械动没动）。</span>
**供电**：进水阀得不得电——查程序是否推进到进水段、电脑板驱动输出。
**水压**：水龙头没开、水压过低，阀门打不开。

**进水不止**（水一直进、漫出来）：

**水位开关/传感器**：水位开关读不到水位（气管漏气、压扁、开关坏），主控「以为没水」→ 一直进水。**查气管是进水不止的头号物理病因**。
**进水阀卡滞**：断电还进水 → 阀芯卡在开位或异物顶住。
**电脑板驱动**：进水阀驱动可控硅击穿常通 → 断电才停。断电试阀，一步分清是执行件还是控制件。

## 2 不排水 / 排水缓慢

**不排水**：

**排水泵/排水阀**：量排水泵（滚筒）线圈、排水电磁铁（波轮）通断；泵叶轮被硬币、纽扣卡死——「嗡嗡不转」是卡堵的典型。<span class="marginnote">排水泵/阀卡堵是「不排水」头号原因：硬币、纽扣、发卡、碎布卡住叶轮，泵转不动（嗡鸣）或排水极慢。先断电清理排水过滤器/泵体，再量线圈——很多时候清完就好了。</span>
**排水过滤器/管路堵**：滚筒机排水过滤器（右下角小门）被絮状物堵死——清理过滤器是「不排水」第一动作。
**驱动/控制**：排水阀得不得电、可控硅好坏。先查执行件再查驱动。

**排水缓慢**：排水管压扁、弯折、过滤器半堵、排水高度过高。逐段检查管路。

## 3 不转 / 洗涤无力

**波轮/滚筒不转**：

**先断电空转**：拆下皮带（波轮）让电机空转试——能空转 → 负载卡死或传动问题；不空转 → 电机或启动问题。<span class="marginnote">「空转试机」是电机类故障的第一刀：把负载与电机分离，电机能转说明电机好、卡的是负载；电机不转才是电机或电容、供电的问题。这一步 5 分钟，能把故障范围缩小一半。</span>

**电机**：量主副绕组、电容。电容失容 → 启动无力甚至不转。
**皮带（波轮）**：皮带松、打滑、断裂 → 洗涤无力。
**离合器（波轮）**：齿轮打滑 → 波轮空转、洗涤无力。
**电脑板/定时器**：驱动信号有无输出——先量负载再疑板子。

**只朝一个方向转**（不换向）：换向触点/可控硅烧蚀粘连，或换向信号缺失（详见电机篇）。

## 4 不脱水 / 脱水异常

**不脱水**（程序到脱水段但不转）：

**盖开关/门开关**：脱水必须盖（门）合好。盖开关未闭合、接触不良 → 拒绝脱水。量盖开关通断。<span class="marginnote">脱水保护是洗衣机的「安全闸」：桶高速旋转，盖没合好或衣物偏心，都会触发保护停机。所以「不脱水」先查盖开关、看桶内衣物是否堆在一侧——往往不是机器坏，是使用或安全逻辑在起作用。</span>
**排水不净**：水没排空，主控不进入脱水。查排水。
**离合器（波轮）**：抱簧失效、制动未松开 → 内桶带不动。检查离合器联动。
**电机/电容**：脱水转速不足甩不干——量电容、皮带。

**脱水异常**：

**震动大 / 「跳舞」**：衣物不平衡（偏心）、减震失效（吊簧/减震器）、机器不平。先均布衣物试机，再查减震。
**反复进水不脱水**：偏心保护自动加水再平衡——属正常保护逻辑，衣物均布后恢复。

## 5 漏水与噪声

**漏水**：

**门封圈（滚筒）**：门封圈老化开裂、卡异物 → 门边渗水。检查门封。
**洗涤剂盒**：泡沫外溢、盒子未推到位 → 盒下滴水。减量、清理。
**排水管/接头**：排水管接头松脱、排水泵密封圈老化 → 底部渗水。重新密封。
**波轮轴封**：波轮轴密封圈磨损 → 波轮下渗水。更换密封圈。

**噪声**：

**波轮下异物**：硬币、发卡摩擦桶壁 → 刺耳声。拆波轮清理。
**轴承磨损**：轴承间隙增大 → 运转时「咯噔」声、脱水尤其明显。更换轴承。
**皮带打滑**：尖啸声。张紧/更换皮带。
**减震失效**：脱水时撞击箱体。更换减震器。

## 6 核心要点：洗衣机故障速查表

| 症状 | 首查 | 关键检查点 |
| --- | --- | --- |
| 不进水 | 进水阀、供电 | 阀线圈、驱动、水压 |
| 进水不止 | 水位开关、气管 | 气管、开关、驱动 |
| 不排水 | 排水泵/过滤器 | 过滤器、泵线圈、卡堵 |
| 不转 | 电机、电容、皮带 | 空转试验、绕组、电容 |
| 只单向转 | 换向触点/可控硅 | 换向信号、粘连 |
| 不脱水 | 盖开关、排水、离合器 | 盖开关、抱簧、制动 |
| 脱水跳舞 | 偏心、减震 | 均布、减震器 |
| 漏水 | 门封/轴封/接头 | 门封圈、轴封、接头 |
| 噪声 | 异物/轴承/皮带 | 波轮下、轴承、皮带 |

**诊断纪律**：**卡在哪一步查哪一步**，先执行件再控制件，先外部（过滤器、异物、门封）再内部（电机、离合器、电脑板）。

## 7 核心要点：洗衣机故障诊断五问

把洗衣机诊断浓缩成「五问」，从症状到结论顺次回答：

**一问卡在哪一步**：进水、洗涤、排水、脱水——程序链上的哪一环停住了？
**二问执行件坏没坏**：该步的阀/泵/电机/离合器，量线圈、做空转，先排外围。
**三问控制给不给**：执行件好的话，电脑板/定时器有没有输出信号。
**四问外部条件够不够**：水压、门盖开关、衣物平衡、排水通畅——使用与环境因素。
**五问是不是安全保护**：盖没盖好、衣物偏心、水没排空——很多「故障」其实是保护逻辑在拦截。

**「五问」的价值**：它把「洗衣机坏了」这样模糊的报修，翻译成可执行的排查顺序——**先回答「卡在哪一步」，后面四问就有了方向**。这也正是本专题综合诊断方法论在洗衣机上的具体化。

**洗衣机保养三件事**：定期清理排水过滤器、掏净口袋再洗衣、洗衣粉按量投放（过量泡沫会从洗涤剂盒溢出）。三件事做到，一大半进水、排水、溢流类报修都不会发生。

## 8 小结

- 洗衣机诊断的总纲：**把症状挂到「进水→洗涤→排水→脱水」程序链上**，卡在哪步查哪步。
- 进水问题分「不进」（进水阀/供电/水压）与「不止」（水位开关/气管/阀卡滞），断电试阀先分执行与控制。
- 不排水先清**排水过滤器/泵卡堵**，再量泵线圈与驱动——卡堵是头号原因。
- 不转先做**空转试验**区分负载与电机，再量电容、绕组、皮带；不脱水查盖开关、排水、离合器。
- 漏水查门封/轴封/接头，噪声查波轮下异物/轴承/皮带；**先外部后内部**是通用纪律。
