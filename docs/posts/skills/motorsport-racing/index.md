# 赛车运动与竞技驾驶

赛车运动与竞技驾驶是以执照分级、赛事安全与国际竞赛规则为核心的标准化竞技驾驶体系，也是竞技赛道的入门门槛。从中国汽摩联的执照培训到 FIA 的国际规则，掌握这套体系既能系统读懂全球各大赛事，也是规范参与赛车运动的必修课。

## 对标教材

- 中国汽车摩托车运动联合会《汽车运动管理条例》
