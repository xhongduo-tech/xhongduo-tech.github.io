# 摄影构图与后期

摄影构图与后期是让照片从"拍下来"走向"看得懂、有味道"的核心能力，涵盖构图法则、用光技巧、色彩表达与 Lightroom/Photoshop 数码后期修图的全流程。以《摄影构图学》《光影之美》《数码摄影后期》为纲，系统建立从取景构图、光影控制到后期调色精修与作品输出的完整知识链，学完这些章节就掌握了从相机取景到成片发布的完整创作基础。

## 对标教材

- 《摄影构图学》
- 《光影之美》
