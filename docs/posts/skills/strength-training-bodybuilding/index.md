# 力量训练与健身健美

力量训练与健身健美是以抗阻训练为核心、以塑造体形与提升运动表现为目标的实践学科，涵盖动作技术、训练计划设计、体适能评估与营养恢复配合。以NSCA《力量与体能训练》、《健身教练》国家职业资格培训教材与《社会体育指导员国家职业技能标准》（健身教练）为纲，系统重建从运动科学基础、评估测试、动作技术到计划设计、营养与恢复的完整知识体系。

## 对标教材

- NSCA《力量与体能训练》（美国国家体能协会）
- 《健身教练》国家职业资格培训教材
- 《社会体育指导员国家职业技能标准》（健身教练）
