## 为什么从日常检查开始

构造篇的四篇（总体构造、操纵装置、发动机传动、制动轮胎）把「车是什么」讲完了，这一篇回答「车怎么保持健康」。

摩托车没有车身保护、没有四轮冗余，任何一个系统带病上路，代价都是直接的：轮胎慢漏气在弯道爆胎、链条松垮在骑行中断裂、制动液含水在长下坡失灵——每一类事故都能在事发前的检查里找到预兆。

《摩托车驾驶培训教材》第5章把日常检查与维护放在构造之后、驾驶技术之前，逻辑很清楚：**只有一辆健康的车，才配得上后面全部驾驶技术。**<span class="marginnote">本节对标<strong>人民交通出版社《摩托车驾驶培训教材》第5章「日常检查与维护保养」</strong>：出车检查、周期保养、常见故障的框架都以该章为准。</span>

## 1 出车前检查：两分钟绕车一圈

把检查养成「上车前的肌肉记忆」，核心是**绕车一圈 + 两处低头**。绕车一圈看灯光、轮胎、链条；两处低头看油量、机油。

**轮胎**：目视胎面有无扎钉、鼓包、裂纹；快速捏一下确认胎压不瘪。胎压正常与否，直接决定弯道抓地与制动距离（见《制动系统与轮胎》的 μ 分析）。

<span class="marginnote">早上冷态检查胎压最准：<strong>热胎测压会偏高 0.2—0.3 bar</strong>，容易让人误判。备一只随身胎压计，是几十元买回的安全底线。</span>

**灯光**：转向灯左右打一次、近远光切换、刹车灯捏前刹/踩后刹各看一次。刹车灯不亮是事故隐患，也常被检查站抓罚。

**制动**：捏前刹、踩后刹，确认行程正常、不空、有力。制动行程突然变长，往往预示制动液不足或系统漏油。

**链条/皮带**：目视链条松紧（上下摆幅约 20—30 mm）、有无锈蚀、是否缺油；皮带车检查有无裂纹。

**油量与机油**：目测油表；冷车看机油尺或观察窗，油位应在上限与下限之间。

<span class="marginnote">机油是发动机的命脉：<strong>缺机油拉缸的维修成本，足以买好几桶最好的机油</strong>。长途骑行前检查机油，比检查任何装饰件都重要。</span>

## 2 周期性保养：按时按里程的「体检表」

除了每次出车前检查，还要按里程周期做保养。把常见项目排成一张表：

| 项目 | 周期（参考） | 不保养的后果 |
| --- | --- | --- |
| 更换机油 | 矿物油 1000—2000 km，合成油更长 | 磨损加剧、拉缸 |
| 清洁/更换空气滤芯 | 约 3000—5000 km | 进气不畅、油耗上升 |
| 链条润滑与调整 | 每 500 km 左右检查 | 掉链、异响、磨损 |
| 检查制动片 | 随检查，看磨损标记 | 制动力下降、碟盘损伤 |
| 电瓶维护 | 冬季每月补电 | 亏电、打不着火 |
| 检查制动液 | 每 2 年更换 | 吸水生锈、刹车发软 |

<span class="marginnote">保养周期的「参考值」以随车说明书为准——不同车型、不同机油差异很大。把说明书放在随车储物里，是比任何「经验值」更可靠的依据。</span>

## 3 核心对比：自己动手 vs 送店保养

保养不必全部 DIY，但分清「该自己盯的」与「该送店的」很重要：

| 项目 | 适合自己动手 | 建议送店 |
| --- | --- | --- |
| 检查胎压、灯光 | 是 | — |
| 链条润滑调整 | 是 | — |
| 更换机油 | 视熟练度 | 是 |
| 更换刹车片 | 否 | 是 |
| 制动液更换 | 否 | 是（涉及排气） |
| 电气故障检修 | 否 | 是 |

**核心结论：日常检查与基础保养自己动手，机械与安全关键项交给专业店。**

判定的标准是「失效风险」——链条松了最多掉链，刹车片装错却是救命零件的失误，后者不值得省几十元工时费。

<span class="marginnote">这也是《摩托车驾驶培训教材》把「维护保养」单列一章的原因：<strong>摩托车的保养不是「锦上添花」，而是「安全系统的日常备份」</strong>——你不维护它，它就在关键时候不维护你。</span>

## 4 常见故障识别：先会「听诊」，再谈维修

养护的进阶，是能根据症状判断大致方向：

**打不着火**：优先排查三件套——电瓶电量（喇叭是否响亮）、火花塞（拆下看是否潮湿积碳）、油路（化油器/电喷是否供油）。多数「打不着火」是电瓶亏电或火花塞老化。

**行驶中异响**：链条松响、轴承嗡嗡、刹车片摩擦声，各有特征音。学会分辨「金属摩擦」「周期敲击」「尖锐啸叫」三类异响，能大幅缩小故障范围。

**抖动**：高速车把抖动查轮胎动平衡与龙头轴承；怠速抖动多与发动机机脚、火花塞有关。

**辨析｜易错点：**「发动机声音变大 = 该换机油」是片面的。机油变质会影响怠速平稳与动力，但金属敲击声（嗒嗒响）往往指向气门间隙、链条张紧器或更深的问题——**听到敲击声先送检，别只靠换机油拖延**。

## 5 三个高频问题速答

- **Q：多久换一次机油？** A：矿物油约 1000—2000 公里，合成油可到 5000 公里以上；以说明书为准，宁可略早不拖晚。
- **Q：链条什么时候该紧？** A：上下摆幅超出约 20—30 mm（视车型）就该调整；过松易掉链、过紧加速磨损。
- **Q：轮胎能用几年？** A：即使未磨到磨损标记，出厂 5 年以上也会老化开裂，应更换；看侧壁 DOT 编号的周/年。

## 6 养护周期速查表

把出车检查与周期保养浓缩成一张「养护日历」：

| 频率 | 项目 | 关键提示 |
| --- | --- | --- |
| 每次出车 | 轮胎、灯光、制动、链条、油量、机油 | 两分钟绕车一圈 |
| 每 500 km | 链条润滑与调整 | 上下摆幅 20—30 mm |
| 每 1000—2000 km | 换机油（矿物） | 合成油可更长 |
| 每 3000—5000 km | 清洁/更换空滤 | 进气不畅油耗升 |
| 每 2 年 | 更换制动液 | 吸水生锈刹车软 |
| 冬季每月 | 电瓶补电 | 防亏电打不着火 |

<span class="marginnote">养护日历的「锚点」是随车说明书：<strong>不同车型、不同机油的周期差异很大，说明书比任何「经验值」都可靠</strong>——把说明书放随车储物里，随时可查。</span>

- **出车两分钟**：绕车一圈 + 两处低头（油量、机油），养成肌肉记忆。
- **关键安全件**：轮胎（胎压/磨损）、制动（行程/刹车片）、链条（松紧）优先盯。
- **记录习惯**：记下换油里程与日期，避免「凭感觉保养」。
- **听诊故障**：打不着火查电瓶/火花塞/油路，异响辨类别，抖动查动平衡。

把这张日历贴进手机提醒，养护就从「想起来才做」变成了「到点就做」。

## 7 小结

- 出车前**绕车一圈 + 两处低头**：轮胎、灯光、制动、链条、油量、机油六项两分钟完成。
- 周期性保养按**里程表**执行：机油、空滤、链条、制动片、电瓶、制动液各有周期，以说明书为准。
- 保养分工原则：**日常检查自己盯，安全关键项送店**——以「失效风险」为判据。
- 常见故障按**症状听诊**：打不着火查电瓶/火花塞/油路，异响辨类别，抖动查动平衡与轴承。
- 养护的本质：**在关键零件失效之前发现它**——这是摩托车安全链上被低估的一环。
