# 烘焙与西式面点制作

以《西式面点师国家职业技能标准》与中国焙烤食品糖制品工业协会培训体系为纲，系统重建从原料认识、面团发酵、整形烘烤到蛋糕裱花装饰的完整烘焙技艺链。学完这些章节，就写完了从家常面包、戚风蛋糕到精致酥点与裱花工艺所需的全部内容。
