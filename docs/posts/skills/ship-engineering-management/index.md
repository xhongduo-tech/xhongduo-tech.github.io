# 船舶轮机与机电管理

船舶轮机工程是研究船舶动力装置、机电设备运行管理与维修保养的应用学科，STCW 公约为轮机部海员规定了独立的适任标准。全球船舶的推进、发电、舱室环境与货物装卸都依赖机舱机电系统，学完这些章节，就掌握了从柴油机原理、辅机操作到轮机值班管理的完整适任基础。

## 对标教材

- STCW 公约——国际海员培训、发证和值班标准公约（含轮机部适任标准，第III章）
- 交通运输部《海船船员培训大纲（2021 版）》（轮机职能模块）
- 《船舶柴油机》（高等航海院校统编教材）
- 《船舶轮机管理》（高等航海院校统编教材）
