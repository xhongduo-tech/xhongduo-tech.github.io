# 电动自行车与骑行安全

以 GB 17761-2018《电动自行车安全技术规范》、《道路交通安全法》非机动车通行规定与各地《电动自行车管理条例》为纲，系统学习电动自行车车辆标准、通行法规、骑行防护与停放充电安全。电动自行车保有量超 3 亿辆、新国标强制实施，是覆盖面最广的日常出行安全知识。

## 对标教材

- GB 17761-2018《电动自行车安全技术规范》
- 《道路交通安全法》及其实施条例（非机动车通行规定）
- 各地《电动自行车管理条例》
