# 家庭园艺与阳台种植

阳台种菜、庭院养花与盆栽是融入日常的绿色生活技能，系统涵盖从土壤基质、播种育苗到蔬菜种植、盆花养护与病虫害防治的完整流程。学完这些章节，就能在阳台和庭院里亲手种出新鲜蔬菜与繁茂花卉。

## 对标教材

- FAO《A Vegetable Garden for All》
- 《家庭园艺与阳台栽培》丛书
- 《室内观赏植物养护》
