# 宠物美容与造型

宠物美容与造型是以宠物的洗护、修剪造型与造型设计为核心的一门职业技能学科，涉及宠物生理健康、工具技法与造型美学的系统结合。以《宠物美容师国家职业技能标准》、宠物美容师职业能力评价体系与《宠物造型设计与美容》为纲，从基础规范、洗护技术到修剪造型与整体造型设计，逐步重建完整的宠物美容知识框架。
