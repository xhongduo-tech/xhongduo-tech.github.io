## 为什么从标记标签开始

包装把危险货物「关进了笼子」，但笼子里装的到底是什么、有多危险，外界必须看得懂——这就是**标记、标签与运输标牌**的职责。它们是危险货物运输的「公共语言」：装卸工靠它判断怎么搬，司机靠它知道拉了什么，消防员到场后第一件事就是读车身上的标牌决定怎么处置。<span class="marginnote">把标记标签想成「危险信息的盲文」——不看它的人也能通过图案与颜色读懂风险。应急救援的黄金时间往往就花在「读信息」上，信息印得对，处置就快一步。</span>

本篇承接《包装》《罐式》两篇：容器解决了「怎么装」，本篇解决「怎么让所有人知道装的是什么」。它把 JT/T 617 第5部分与联合国规章范本第5部分的托运程序要求落到了「包件与车辆的脸面」上。

## 1 三种信息载体：先分清再使用

危险信息在运输中分三个层次出现，名称相近、作用不同：

**标记（marking）**：印在包件上的**文字信息**——UN 编号、正确运输名称、包装等级标记等，以文字为主。

**标签（label）**：贴在**包件**上的**图形标志**——菱形图案 + 危险类别符号 + 颜色，以图形为主，一眼识别危险类别。

**标牌（placard）**：挂在**运输单元（车辆/集装箱）**上的**放大版标签**——让远距离与应急人员识别整车危险。

**重点：** 一句话记忆——标记是「写文字」，标签是「贴图形」，标牌是「把图形放大挂上整车」。三者配合，才能让「包件级」与「整车级」的信息都完整。

## 2 包件标记：文字信息要齐全

每个包件表面必须印有规定文字，包括：

- **UN 编号**与**正确运输名称（PSN）**：如「UN 1203，汽油」；
- **包装标记**：如 1A1 / X / 100 / 94 / CN / XXX（见《包装要求》一篇）；
- **托运人 / 收货人信息**：按需标注，便于追溯；
- **方向标记**：对液态包件，标「向上」箭头指示安放方向。

**易错点：** 标记要**耐久、清晰、抗运输磨损**——用纸贴、易褪色的墨水都不合格；标记不得与包装上的其他印刷信息混淆，字号与位置有规定。

## 3 危险标签：图形语言一眼识险

危险标签是菱形的图形标志，左上角（或规定位置）为危险符号，右下角为类别/项号，底色按类别统一。九大类各有固定图形与配色：

| 类别 | 标签图形 | 底色 |
| --- | --- | --- |
| 第1类 爆炸品 | 爆炸的火球 | 橙 |
| 第2类 气体 | 火焰（2.1）/ 气瓶（2.2）/ 骷髅（2.3） | 红 / 绿 / 白 |
| 第3类 易燃液体 | 火焰 | 红 |
| 第4类 | 火焰（4.1）/ 自燃（4.2）/ 水滴（4.3） | 红白条纹 / 上白下红 / 蓝 |
| 第5类 | 火焰圈（5.1）/ 火焰与爆炸（5.2） | 黄 |
| 第6.1/6.2 | 骷髅 / 生物危害 | 白 / 白 |
| 第7类 | 三叶扇形 | 白 + 黄 |
| 第8类 | 腐蚀滴落 | 上白下黑 |
| 第9类 | 黑白竖条纹 | 白 |

**重点：** 标签贴错是**重大违规**——不仅检查通不过，应急时还会误导救援。贴标签的唯一依据是**一览表中该 UN 编号的标签列**，不是「看起来像易燃物就贴火焰」。

## 4 核心对比：标记、标签与标牌

把三者再钉一次：

| 对比项 | 标记 | 标签 | 标牌 |
| --- | --- | --- | --- |
| 载体 | 包件表面 | 包件表面 | 车辆 / 集装箱 |
| 内容 | 文字（UN 编号、名称） | 图形（类别符号 + 颜色） | 放大的标签图形 |
| 作用 | 精确指认货物 | 快速识别危险类别 | 远距离 / 应急识别整车 |
| 依据 | 一览表 + 托运程序 | 一览表标签列 | 车辆标志牌规定 |

**辨析｜易错点：** 「有标签就不用写标记」是误读。标签告诉你「是哪一类」，标记告诉你「具体是哪个号」，两类信息各司其职、缺一不可——单证与包件上的 UN 编号、名称对不上，就是最典型的信息链断裂。

## 5 从包件到整车：信息如何衔接

包件贴好标签、印好标记之后，还有一个「上行」环节：**整车必须挂与包件标签对应的标牌**。比如整车装的是第3类易燃液体，车身两侧与尾部就挂红色火焰菱形标牌；若混装多种类别，则分别挂对应标牌（见《车辆标志牌》一篇）。

这一层层上行的信息，最终汇成**随车文件**里的危险货物运输单据——包件级、整车级、文件级三层信息一致，才是完整的托运程序。

## 6 实务：一桶汽油的标记与标签

以「一个 1A1 闭口钢桶，装 UN 1203 汽油，Ⅱ 类包装」为例，把标记与标签逐项落到位：

| 要素 | 内容 | 位置与要求 |
| --- | --- | --- |
| UN 编号 + PSN | UN 1203，汽油 | 桶身，字迹清晰、耐久 |
| 包装标记 | 1A1 / X / 100 / CN / XXX | 桶身，含等级、最大毛重、年份 |
| 危险标签 | 第3类红色火焰标签 | 桶身两侧各一，对称可见 |
| 方向标记 | 向上箭头 | 液态货物，桶身明显处 |
| 托运人信息 | 托运人、收货人、应急电话 | 桶身或随附单据 |

**重点：** 贴标的关键是「先查一览表再动手」——UN 1203 的标签列明确「第3类」，标签就选第3类红色火焰；**不看表凭「它是液体应该易燃」猜标签，是最容易犯的错**。标签尺寸、位置、数量按托运程序规定执行，不是「贴一张意思一下」。

**辨析｜易错点：** 「多贴一张标签更保险」是反向错误。**贴错类别（如把第3类贴成第2类）比不贴更危险**——它会让应急人员按错误类别处置。一张包件只能贴与一览表标签列一致的标签，附加的危险性（次要危险性）另按特殊规定标注，不能自由发挥。

### 本节自查清单

用一组问题检验对标记标签的掌握：

1. 标记、标签、标牌三者的本质区别？——标记写文字、标签贴图形、标牌挂整车。
2. 包件标记至少包含哪些文字？——UN 编号、正确运输名称、包装标记、方向标记。
3. 贴标签的依据是什么？——一览表中该 UN 编号的标签列，不是凭感觉。
4. 第3类易燃液体的标签底色是什么？——红色，火焰图形。
5. 贴错类别标签比不贴更危险吗？——是，会误导应急按错误类别处置。
6. 包件级、整车级、文件级三层信息要满足什么？——必须一致，信息链不能断。

### 延伸与衔接

标记标签体系是「把危险变成信息，把信息变成行动」的枢纽。它的设计哲学与本博客《信息可视化》专题高度一致：**同一份信息，面向不同场景做不同层次的呈现**——装卸工读文字标记、司机看图形标签、消防读整车标牌。危险货物规则的每一个信息载体，背后都是「谁在什么场景下需要什么信息」的周密设计。

**重点：** 一句口诀——**先查表、再贴标、三层一致才算好**。标记标签不是「印刷装饰」，而是应急响应的第一信息来源，错一处在检查中是一处违规，在事故中可能就是一处误判。

## 7 小结

- 标记是文字、标签是图形、标牌是整车级放大的图形，三者作用与载体不同。
- 包件标记含 UN 编号、PSN、包装标记、方向标记，须耐久清晰。
- 标签按一览表标签列选用，九大类有固定图形与配色，贴错即违规。
- 包件级、整车级、文件级三层信息必须一致，信息链断裂是常见违规。
- 标记标签是应急响应的第一手信息来源，印错、贴错都可能误导救援。
