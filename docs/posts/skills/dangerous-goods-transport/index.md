# 危险货物道路运输安全

以 JT/T 617《危险货物道路运输规则》为纲，结合《危险化学品安全管理条例》与联合国《关于危险货物运输的建议书·规章范本》及 ADR，系统覆盖危险货物从分类、包装到装卸、运输、应急与监管的全链条安全规则体系。学完这些章节，就掌握了危化品道路运输的强制性部颁规则与国际法规的完整体系。

## 对标教材

- 交通运输部《危险货物道路运输规则》（JT/T 617，1-6 部分）
- 《危险化学品安全管理条例》（国务院令第 591 号）
- 联合国《关于危险货物运输的建议书·规章范本》（UN Model Regulations）与《危险货物国际道路运输欧洲协议》（ADR）
