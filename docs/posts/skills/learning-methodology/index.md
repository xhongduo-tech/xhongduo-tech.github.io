# 高效学习方法论（费曼/刻意练习/间隔重复）

以《学习之道》《刻意练习》与《费曼学习法》为纲，系统建立从大脑学习机制、高效记忆与复习技巧、用输出倒逼输入的费曼学习法，到刻意练习与专家成长路线的完整高效学习方法体系。学完这些章节，就掌握了让学习事半功倍的底层方法论。

## 对标教材

- 《学习之道》（芭芭拉·奥克利）
- 《刻意练习》（安德斯·艾利克森）
- 《费曼学习法》（尹红心、李伟）
