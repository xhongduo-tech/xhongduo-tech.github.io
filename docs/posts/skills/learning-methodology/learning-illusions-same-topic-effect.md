# 克服学习错觉与同题效应

<div class="epigraph">
<p>最危险的学习错觉，是「我练习了很多，所以我应该已经学会了」。</p>
<footer>—— 芭芭拉 · 奥克利（Barbara Oakley），《学习之道》（A Mind for Numbers）</footer>

## 为什么「练得多」反而会翻车

前面讲了主动回忆、间隔重复——全是「做对」的方法。这一节要正面拆一个「看起来完全正确、实则暗藏陷阱」的做法：**连续做同一类题**。

你大概经历过：考前猛刷同类题，越刷越顺、正确率飙升，信心满满上考场。结果卷子一翻，第一题就变了点花样，你突然不会了。这不是偶然，而是一个有名字的效应——**同题效应（Einstellung effect，又译「思维定势」）**。它和上一节讲的学习错觉是近亲，都是「感觉会了、其实不会」的变种。

## 1 什么是同题效应：大脑的「惯性车道」

**Einstellung** 是德语，本意「定势」「已确立的态度」。心理学家用它描述一种现象：**人一旦形成了一种解法或思路，就倾向于用它去套一切问题，即使换一条路更简单，甚至原路根本走不通。**

奥克利在《学习之道》第8章用一个水壶实验讲透了它：

- 实验里，被试被反复训练用「先装满、再倒掉一部分」的复杂方法解一类倒水题；
- 后面的题其实有更简单的解法，甚至有些题只有简单解法；
- 结果：受过复杂训练的被试，**继续用复杂方法**，甚至对只能用简单方法的题束手无策。

<span class="marginnote">这个实验揭示的机制是：大脑喜欢「已烧录」的路径——用过的路径最省力。一旦某条路被反复走熟，它就变成了默认路线；新题来了，大脑先走默认路线，而不是先「看题」。这就是「熟练的反噬」：会得越熟，越容易被自己的熟困住。</span>

## 2 同题效应怎么在学习里出现

同题效应不是实验室里的怪现象，它每天都在你的练习里发生：

- **刷同类题**：连做二十道同类题，前几道训练了方法，后十几道只是在重复——大脑把「这个方法」烧成了默认路线；
- **依赖题型标志**：题号顺序、章节位置成了「提示」——「这章学了积分，这道肯定用积分」，离开章节背景就不会判断；
- **记住答案而非方法**：练的题越熟，越容易「背题」而不是「做题」——考试换个数字、换个条件就露馅。

<span class="marginnote">最容易骗人的是「正确率的攀升」：同类题连做，正确率一路涨，于是你确信「我学会了」。但奥克利提醒：这正确率里有一大半是「惯性」贡献的——题目之间太像，你其实是在「认套路」，不是在「做判断」。这正是上一节学习错觉在「练习量」上的投影。</span>

## 3 为什么考试就考「判断力」

理解同题效应，要先想清楚考试到底在考什么。

考卷上的题目是**混合的、变形的**：不会告诉你「这题用哪一章的方法」，甚至同一考点会换装、换情境。所以考试真正在测的不是「你熟不熟某类题」，而是**「拿到一道题，你能不能判断出它该用什么方法」**——这个能力叫「迁移」（transfer），也叫「判断力」。

而连做同类题，恰恰练不到判断力：它练的是「认出套路后的执行」，把「判断」这一步完全跳过了。于是——

- 平时：同样的题，你做得飞快，因为套路已经走熟；
- 考时：套路不见了（题变形了），你失去判断依据，全线崩溃。

<span class="marginnote">「熟练的笨拙」这个词是奥克利描述这类情况的：<strong>熟练地执行 + 笨拙地判断</strong>。运动员里也有同样的现象——定点投篮练得再准，比赛里没有定点让你投；只有「跑动中接球投篮」这种混着练，才练得到判断力。</span>

## 4 破解同题效应：交替练习

正解在前面已经预告过：**交替练习（interleaving）**——把不同类型、不同章节的题混着练，而不是按类型连练。下一节《交替练习与多样化训练》会详细展开，这里先给三条立刻能用的措施：

- **打乱题序**：做完一套题，打乱顺序重做一遍——让大脑必须「判断」每道题，而不是「顺着套」；
- **跨章节混练**：复习时把不同章节的题混在一起做，逼自己在「积分题 / 代数题 / 几何题」之间来回切换判断；
- **换变式**：同一考点，换数字、换情境、换问法——每换一次，判断力就多练一分。

<span class="marginnote">「打乱重做」是抵抗同题效应最便宜的招式：第一遍你是「按顺序做」，第二遍打乱后，「上一题的解法」就不再能提示当前题——你被迫回到「看题判断」。就这一个动作，练习的含金量立刻不同。</span>

## 5 核心对比：连做同类题 vs 交替练习

| 维度 | 连做同类题 | 交替练习 |
| --- | --- | --- |
| 题目安排 | 同类型连续做 | 不同类型混着做 |
| 训练的能力 | 套路执行 | 套路判断 + 迁移 |
| 即时正确率 | 高（有惯性加成） | 较低（每题要判断） |
| 考试迁移 | 差 | 好 |
| 典型幻觉 | 同题效应 | 必要难度 |
| 适用阶段 | 刚学完、建立熟练 | 巩固提升、考前冲刺 |

## 6 用「怀疑」保护自己

同题效应和学习错觉的终极防线，是一种习惯：**对自己「会了」的判断保持怀疑**。具体操作三条：

- **变换再测**：觉得会了，就「换个数 / 换个情境」再测一次——能过才算会；
- **合书重做**：不看答案、不翻笔记，从头独立做一遍——能独立做才算会；
- **讲给他人**：把一个知识点讲给别人听，讲得清、讲得顺，才说明没被「熟悉感」骗了——这是费曼学习法的预告。

<span class="marginnote">这三条里「变换再测」是最轻量的自检：同一道题换个数字，正确率立刻暴露「你是真懂还是认套路」。它和本专题《理解与记忆的关系》里的「不同场景的会用才算会」完全同源——怀疑自己的熟悉感，是学习的最高美德之一。</span>

**同题效应的「正例」：为什么高手反而更容易「被套住」**

研究发现，同题效应在「经验丰富」的人身上有时更顽固——因为他们脑子里的「默认解法」更多、更熟。一个练了十年的棋手，面对新规则时，往往比新手更难适应——因为他的每一条旧路径都太顺畅。**这提醒我们：熟练是资产，也是负债；越是高手，越要主动「怀疑自己的第一反应」。**

**三个「反定势」的日常练习**

- **给自己出变式题**：把做过的题换个数字、换个条件、换个问法再做一遍；
- **故意换一种解法**：同一道题，逼自己用「第二种方法」解——打破「只会一种」的路径；
- **离开「套路提示」做题**：不看章节标题、不按顺序做题，让大脑必须自己判断。

**当「怀疑」遇到「考试」**

考前最容易「感觉全会」，考后最容易「发现全不会」。把「怀疑自己」写进复习流程：每复习完一章，先自测（合书回忆 + 换情境重做），再决定「是继续还是返回」。**自测没过，就是「没会」——感觉再顺也不算数。**

**「同题效应」与「学习错觉」的关系**

两者是近亲：学习错觉是「以为懂了其实没懂」，同题效应是「会了一种解法就套用一切」。它们共同的根源是**「熟练产生的信任」**——越熟，越不怀疑。所以破解的方法也相通：主动怀疑、换变式、合书重做。

**一个「换变式」的例子**

你刚学会「用配方法解 $x^2+4x+3=0$」。变式一：把系数换成 $x^2+4x+5=0$（判别式变了，无实根）；变式二：换成 $2x^2+4x+3=0$（先除 2 再配方）；变式三：换成「用配方法求抛物线 $y=x^2+4x+3$ 的顶点」。

**做完这三个变式**，你才算「真的会配方」——只做一个，你会的只是「这道题」。判断力不是练出来的题量，而是「同一知识点能应付的变式数」。

## 7 小结

- **同题效应（Einstellung）**：解法一旦走熟就变成默认路线，新题来了先套旧路，被自己的熟练困住。
- 学习里的典型表现：**刷同类题、依赖题型标志、记住答案而非方法**。
- 考试考的是**判断力（迁移）**，连做同类题练不到判断力，只在「认套路」。
- 破解三招：**打乱题序、跨章节混练、换变式重做**。
- 交替练习的正确率「看起来更低」，但它是必要难度，长远效果更好。
- 终极防线是**怀疑自己的熟悉感**：变换再测、合书重做、讲给他人。

到这里，「高效记忆与复习技巧」这一篇就讲完了：间隔重复定节奏、主动回忆换方式、记忆宫殿补容量、番茄钟保专注、交替练习练判断——五件武器配齐了。在下一节，我们将进入本专题最著名的方法——它把所有「输出倒逼输入」的思想浓缩成四步，这就是**费曼学习法的本质与四步流程**。
