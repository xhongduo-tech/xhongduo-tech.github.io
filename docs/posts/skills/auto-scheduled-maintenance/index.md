# 汽车保养与定期维护

日常保养（油液、滤芯、周期维护）是车主与技师共享的常识性技能，覆盖从维护制度、定期保养项目到检测诊断的完整作业链条。以 GB/T 18344-2016《汽车维护、检测、诊断技术规范》为纲，配合《汽车保养与维护》培训教材与《汽车维修工国家职业技能标准》，学完这些章节，就写完了汽车日常保养与定期维护从规范到实操的全部内容。
