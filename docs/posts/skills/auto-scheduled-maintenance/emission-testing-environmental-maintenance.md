## 为什么从排放检测开始

上一节讲了 OBD——车辆实时自检排放系统。这一节看**排放检测**：把尾气采样到分析仪里，量化读出污染物浓度。排放检测既是年检的法定项目，也是判断发动机燃烧状况的「照妖镜」——**尾气成分直接反映混合气浓度、点火质量、燃烧效率，是诊断发动机健康状态最客观的信号之一。**

对车主而言，排放检测的现实意义很直接：**年检排放不合格就过不了关**。而对维护而言，排放超标不是「调一下就行」的表面问题，它背后往往站着空滤堵塞、氧传感器老化、火花塞失火、三元催化器失效等真实故障。<span class="marginnote">排放检测与 OBD 是一对互补的诊断手段：OBD 看「电控系统的自我判断」，排放检测看「燃烧的物理结果」。一个查系统、一个查结果，交叉验证才能定位问题。这也是 GB/T 18344-2016 把二者都纳入二级维护的原因。</span>

## 1 尾气里的四种主角

汽油机尾气中与排放法规直接相关的四种污染物，各有来源与含义：

**一氧化碳（CO）**：氧气不足时碳不完全燃烧的产物。**CO 高 = 混合气过浓**（进气不足或喷油过多）。
**碳氢化合物（HC）**：未燃烧的燃油分子。**HC 高 = 有燃油没烧掉**——失火、点火弱、混合气过稀或过浓都可能导致。
**氮氧化物（NOx）**：高温高压下空气中氮与氧反应的产物。**NOx 高 = 燃烧温度过高**（混合气过稀、点火提前角过大、EGR 失效）。
**颗粒物（PM）**：未完全燃烧的碳粒。汽油直喷与柴油机常见。

**读出这三个指标，就能交叉判断燃烧状态**：CO 与 HC 同时高 → 混合气过浓；HC 高但 CO 正常 → 多为失火；NOx 高 → 燃烧温度过高。这正是「尾气诊断」的入门功夫。<span class="marginnote">把尾气当「化验单」来读，是维修诊断的高级技能：CO 与 HC 的关系（浓/稀）、NOx 与温度的关系，背后是发动机燃烧化学——到第六级《热能工程》的内燃机原理章节，这些燃烧反应式（$\ce{2CO + O2 -> 2CO2}$）会得到严格的化学平衡描述。这里你只需记住一个框架：<strong>浓度异常 = 燃烧过程某个环节出了问题</strong>。</span>

## 2 排放检测的方式与标准

排放检测按车辆的负载与工况，分为几种方式：

- **怠速法**：车辆怠速运转时采样，测 CO、HC。简单快速，多用于早期年检与简易抽查；但只能反映怠速工况的排放。
- **双怠速法**：在低怠速与高怠速（约 2500 r/min）两个工况分别采样，能反映中低负荷的排放，是多数在用汽油车年检的常用方法。
- **简易工况法（稳态工况/瞬态工况）**：在底盘测功机上让车辆按设定工况行驶，同时采样——模拟真实行驶负荷，测量更全面（含 NOx），对排放控制的检验更严格，大城市年检逐步采用。
- **柴油车**：用**不透光度计**测排气烟度（自由加速烟度），配合加载减速法检测颗粒物。

**重点：怠速法测不到 NOx，而 NOx 恰恰是排放控制的重点污染物之一。** 因此检测方式越「工况化」，对车辆排放控制系统的检验越真实——这也是简易工况法逐步推广的原因。排放限值执行国家标准（如 GB 18285 汽油车、GB 3847 柴油车）规定，不同排放阶段（国三/国四/国五/国六）限值不同，**越新的车标准越严**。<span class="marginnote">为什么排放限值不断加严？因为机动车是城市大气污染的重要来源——CO、HC、NOx、PM 都会影响空气质量与人体健康。从国一到国六，排放标准对污染物的限值降了一个数量级以上，倒逼车企采用三元催化、EGR、颗粒捕集等净化技术。年检的排放检测，就是「用标准守住每一辆在用车的环保底线」。</span>

## 3 排放超标的原因与环保维护

排放检测不合格，往往指向以下真实故障（而不是「车老了就该不合格」）：

- **空滤堵塞** → 进气不足 → 混合气过浓 → CO、HC 超标。
- **火花塞老化/失火** → 燃烧不完全 → HC 超标。
- **氧传感器老化** → 空燃比闭环失效 → CO、HC 超标。
- **三元催化器失效** → 尾气净化能力下降 → 各项污染物超标。
- **喷油嘴堵塞/雾化不良** → 燃烧恶化 → HC、CO 超标。
- **机油燃烧（烧机油）** → 尾气冒蓝烟 → HC、PM 超标。

**环保维护的思路**：排放检测不只是「过关考试」，它把发动机的保养状态「照」了出来。排放超标时，按「空气供给 → 点火 → 喷油 → 后处理」的顺序排查——**先做基础保养（清洁空滤、换火花塞、检查氧传感器），再判断三元催化器等后处理部件**。很多排放超标通过基础保养就能解决，不必一上来就换贵重的催化器。<span class="marginnote">排放维护与常规保养的联动：按时换空滤、火花塞、机油，本身就是最好的「环保维护」——因为这些部件直接决定燃烧质量与排放水平。GB/T 18344-2016 把排放检测纳入二级维护，正是把「环保」落进「维护」——保养到位，排放自然达标。这也是为什么国标把排放检测与维护制度绑在一起：维护是减排的第一道手段。</span>

## 4 排放控制系统：让尾气变干净的技术

排放超标指向的「后处理系统」，是一套让尾气变干净的净化装置，理解它们才懂环保维护：

- **三元催化转化器（TWC）**：把 CO、HC 氧化成 $\ce{CO2}$ 和 $\ce{H2O}$，把 NOx 还原成 $\ce{N2}$——**同时处理三种污染物**的「化学工厂」。它靠铂、铑、钯等贵金属催化，必须「达到工作温度」才高效，所以冷起动时排放最差。
- **氧传感器**：装在排气管上，检测排气中氧含量，反馈给 ECU 调整喷油量——**空燃比闭环控制的核心**，也是排放超标的常见元凶。
- **EGR（废气再循环）**：把部分废气送回气缸，降低燃烧温度，从而**抑制 NOx 生成**。
- **颗粒捕集器（GPF/DPF）**：拦截汽油直喷与柴油机的碳颗粒，是国六标准后的重要装置。

**重点：排放超标往往不是「净化器坏了」，而是「燃烧没做好」或「反馈失灵」。** 排放控制的链条是「燃烧生成 → 催化净化 → 传感器反馈」，任何一环出问题，尾气都会超标——这也解释了为什么排放检测能「照出」发动机的健康状态。<span class="marginnote">三元催化器为什么「要先热才有效」？催化反应需要温度激活——冷车时催化器温度低（几百摄氏度以下），催化效率极低，所以冷起动那一两分钟的排放是最差的。工程师用「排气管前移、快速加热」等方式缩短这个「起燃时间」。这也解释了为什么短途频繁冷启动的车，排放控制部件更容易劣化——它老在「不工作状态」下接受尾气冲击。</span>

## 5 排放法规与环保维护的关系

排放法规是排放检测的「指挥棒」，理解法规演进，就理解了维护的方向：

- **从国一到国六**：污染物限值不断加严（CO、HC、NOx、PM 各限值大幅下调），强制车企装三元催化、EGR、颗粒捕集等净化技术——**排放法规是环保技术的推动力**。
- **对在用车的意义**：法规不仅约束新车，也通过年检约束在用车的排放状态——**排放检测守住的是每一辆上路车的环保底线**。
- **环保维护的核心理念**：**「保养好，就减排」**——空滤干净、火花塞正常、氧传感器灵敏、催化器健康，尾气自然达标。环保不是单独的一项作业，而是**维护到位的自然结果**。

**辨析｜易错点：** 年检前「临时猛跑高速」不能真正改善排放——热车与轻微清积碳只能短期改善怠速工况读数，**根本的排放改善来自长期按时保养**。把排放检测当「考试冲刺」是本末倒置，把保养当「日常功课」才是正解。<span class="marginnote">为什么「临时高速」治标不治本？高速工况确实能烧掉一部分积碳、让催化器热起来，使排放读数短暂变好——但氧传感器老化、催化器硫中毒、空滤堵塞这些「结构性病因」并不会因此消失，重新回到市区工况后排放很快反弹。真正的环保维护是「预防性」的：在污染累积之前，就通过按时保养让燃烧与净化系统保持健康。</span>

## 7 排放检测与 OBD 的配合使用

排放检测与 OBD 诊断是一对互补手段，配合使用才能高效定位：

- **先读码、再测尾气**：维护时先读 OBD 故障码，如有排放相关码（氧传感器、失火、催化器），直接按码排查——比盲目测尾气高效。
- **尾气结果反推系统**：排放读数异常（如 CO 高），结合 OBD 数据流（氧传感器电压、空燃比），快速锁定「混合气过浓」的具体原因。
- **年检前的自检**：年检前先读 OBD、自查排放相关系统，把「临检不合格」变成「主动整改」。
- **区别与联系**：OBD 查「电控系统的自我判断」，排放检测查「燃烧的物理结果」——一个查系统、一个查结果，交叉验证。

**重点：读码 + 测尾气 + 看数据流，三件套是排放诊断的标准动作。** 只测尾气不读码，是「只看结果不查原因」。

## 9 排放小结补充

- **排放标准演进**：从国一到国六，CO、HC、NOx、PM 限值大幅收紧，环保技术要求不断提高。
- **维护即减排**：按时保养（空滤、火花塞、氧传感器、催化器）是最有效的日常减排手段。
- **年检提示**：排放检测是年检法定项，提前自检（读码、看数据流）可避免临检不合格。

## 9 小结

- 排放检测把尾气变成「化验单」：**CO 高 = 混合气浓，HC 高 = 燃烧恶化，NOx 高 = 温度过高**。
- 检测方式：**怠速法 → 双怠速法 → 简易工况法**，越工况化越真实；柴油车测烟度。
- 排放限值执行国标，**越新的车标准越严**（国三→国六）。
- 排放超标多指向**空滤、火花塞、氧传感器、三元催化器**等真实故障。
- 环保维护 = 按时做基础保养（清洁、换件），让燃烧与后处理保持良好。
- 排放检测是年检法定项，也是发动机健康状态最客观的信号之一。
