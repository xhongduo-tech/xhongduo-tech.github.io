## 为什么从排放检测开始

上一节讲了 OBD——车辆实时自检排放系统。这一节看**排放检测**：把尾气采样到分析仪里，量化读出污染物浓度。排放检测既是年检的法定项目，也是判断发动机燃烧状况的「照妖镜」——**尾气成分直接反映混合气浓度、点火质量、燃烧效率，是诊断发动机健康状态最客观的信号之一。**

对车主而言，排放检测的现实意义很直接：**年检排放不合格就过不了关**。而对维护而言，排放超标不是「调一下就行」的表面问题，它背后往往站着空滤堵塞、氧传感器老化、火花塞失火、三元催化器失效等真实故障。<span class="marginnote">排放检测与 OBD 是一对互补的诊断手段：OBD 看「电控系统的自我判断」，排放检测看「燃烧的物理结果」。一个查系统、一个查结果，交叉验证才能定位问题。这也是 GB/T 18344-2016 把二者都纳入二级维护的原因。</span>

## 1 尾气里的四种主角

汽油机尾气中与排放法规直接相关的四种污染物，各有来源与含义：

**一氧化碳（CO）**：氧气不足时碳不完全燃烧的产物。**CO 高 = 混合气过浓**（进气不足或喷油过多）。
**碳氢化合物（HC）**：未燃烧的燃油分子。**HC 高 = 有燃油没烧掉**——失火、点火弱、混合气过稀或过浓都可能导致。
**氮氧化物（NOx）**：高温高压下空气中氮与氧反应的产物。**NOx 高 = 燃烧温度过高**（混合气过稀、点火提前角过大、EGR 失效）。
**颗粒物（PM）**：未完全燃烧的碳粒。汽油直喷与柴油机常见。

**读出这三个指标，就能交叉判断燃烧状态**：CO 与 HC 同时高 → 混合气过浓；HC 高但 CO 正常 → 多为失火；NOx 高 → 燃烧温度过高。这正是「尾气诊断」的入门功夫。<span class="marginnote">把尾气当「化验单」来读，是维修诊断的高级技能：CO 与 HC 的关系（浓/稀）、NOx 与温度的关系，背后是发动机燃烧化学。到第六级《热能工程》的内燃机原理章节，这些反应式（$\ce{2CO + O2 -> 2CO2}$</span>
