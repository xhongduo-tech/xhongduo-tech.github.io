# 网球

网球是一项以发球、正反手击球与网前截击为核心技术的隔网对抗性球类项目，胜负取决于技术动作的稳定、对竞赛规则的理解与单双打战术的灵活运用。以 ITF《网球规则》、《网球运动教程》与 USPTA 教练认证体系为纲，系统重建从规则认知、基本技术、发球截击到单双打战术、体能训练与教练认证的完整知识体系。

## 对标教材

- ITF《网球规则》（国际网球联合会）
- 《网球运动教程》
- USPTA 教练认证体系
