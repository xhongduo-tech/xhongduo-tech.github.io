## 为什么灸法要懂经络理论

操作篇里你会学「灸哪里」，但「为什么灸那里」的答案全在这一节。灸法不像吃药——药物入胃后经吸收散布全身，灸法只作用于体表一点，却能影响远端脏腑。**中间那座「桥」，就是经络系统**。不理解经络、腧穴、气血这三块基石，灸法在你眼里就只是一团火在皮肤上烤；理解了，你就知道为什么足三里能调脾胃、关元能温下焦。<span class="marginnote">经络学说与西医解剖学的关系一直是热点：<strong>现代研究用循经感传、红外热像、结缔组织筋膜网络等假说解释经络，但迄今无定论</strong>——本专题按中医理论体系讲述，同时提示这仍是开放的学术问题，与《针灸推拿学》专题一脉相承。</span>

## 1 经络：灸火的传导网络

**经络（meridian / channel）**：人体内运行气血、联络脏腑肢节、沟通上下内外的通路系统，由**经脉**与**络脉**两大部分组成。经脉是主干（十二正经 + 奇经八脉），络脉是经脉分出的细小分支（十五别络及孙络、浮络），两者共同构成网状结构——「经如江河，络如沟渠」。

灸法依赖经络的核心机制是**传导**：灸火在腧穴处产生的温热刺激，沿经络向远端传导，这就是临床上的「循经感传」现象——患者灸足三里时，热感可沿足阳明胃经向腹部传导。**灸法作用的关键不在于皮表温度有多高，而在于刺激能否「得气传经」**。

十二正经是经络系统的骨架，按手足、阴阳分为三阴三阳，与五脏六腑一一对应：

| 经名 | 属络脏腑 | 走向特点 |
| --- | --- | --- |
| 手太阴肺经 | 属肺络大肠 | 胸 → 手 |
| 手阳明大肠经 | 属大肠络肺 | 手 → 头 |
| 足阳明胃经 | 属胃络脾 | 头 → 足 |
| 足太阴脾经 | 属脾络胃 | 足 → 胸 |
| 手少阴心经 | 属心络小肠 | 胸 → 手 |
| 手太阳小肠经 | 属小肠络心 | 手 → 头 |
| 足太阳膀胱经 | 属膀胱络肾 | 头 → 足 |
| 足少阴肾经 | 属肾络膀胱 | 足 → 胸 |
| 手厥阴心包经 | 属心包络三焦 | 胸 → 手 |
| 手少阳三焦经 | 属三焦络心包 | 手 → 头 |
| 足少阳胆经 | 属胆络肝 | 头 → 足 |
| 足厥阴肝经 | 属肝络胆 | 足 → 胸 |

这张表的规律不难记：**阴经属脏络腑、行于内侧，阳经属腑络脏、行于外侧；同名阴阳经互为表里**（如肺与大肠、脾与胃）。灸法选穴时「循经取穴」——在病变脏腑的相应经脉上取穴——就是建立在这张表之上的。

## 2 腧穴：灸火的落点

**腧穴（acupoint）**：人体脏腑经络之气输注于体表的部位，是灸法、针刺等刺激的落点。「腧」通「输」，意为输注；古时也写作「输穴」「俞穴」。腧穴不是孤立的一个点，而是**「经络之气」在体表的门户**——刺激腧穴，意在通过它影响整条经络及所联系的脏腑。

腧穴按其归属可大致分三类：**十四经穴**（归属十二正经与任督二脉，有固定名称与位置，是灸法取穴的主体）、**奇穴**（有固定位置但未归入十四经，如太阳、华佗夹脊）、**阿是穴**（以痛为腧，哪里痛灸哪里，无固定位置）。<span class="marginnote">「阿是穴」之名始于唐代孙思邈：患者被按到痛处时发出「啊—是」的叫声，故而得名。<strong>它没有固定坐标，却是灸法止痛时最常用的落点</strong>——家庭保健里「哪疼灸哪」正是阿是穴的思路。</span>

取穴是否准确，直接影响灸效。临床上用**骨度分寸法**（以体表骨节为标志折算等分）与**体表标志法**（如两乳头连线中点取膻中）定位。这里有个关键认知：**灸法对穴位定位的要求比针刺宽松**——因为灸的热力辐射范围比针尖大，落在穴区即可起效，这给了家庭艾灸一定的容错空间，但「大致位置」仍需掌握，本专题第 4 篇会给出常用穴位的定位口诀。

## 3 气血：灸火要温的东西

**气与血**是构成人体和维持生命活动的基本物质，也是灸法作用的对象。**气**（qi）是不断运动的精微物质，有推动、温煦、防御、固摄、气化五大功能；**血**（blood）是循行于脉中的液态物质，有濡养与化神的功能。气为血之帅（气能生血、行血、摄血），血为气之母（血能载气、养气）——两者相互依存。

灸法与气血的关系可概括为**温气行血**：气虚则温煦无力、血虚则脉络失养、寒凝则血行不畅，灸火的温热恰好能**补气温阳、散寒活血**。这正是灸法对「虚、寒、瘀」三大类病证有效的根本原因。<span class="marginnote">把气血理论翻译成现代语言：<strong>灸法的温热刺激扩张局部血管、改善微循环、调节免疫与神经内分泌，这些可测量的效应，可以看作「温气行血」的现代注脚</strong>——理论语言不同，观察到的现象却是同一条。</span>

**辨析｜易错点：** 初学者常把「气」想成一种神秘实体。中医的气是**功能性概念**——它描述的是人体各组织器官的功能活动及其物质基础，不是解剖可见的某种「气」。同理，**经络不是一根解剖管道**，而是一组功能联系的综合表述。把这两个概念当成「功能性描述」而非「实物结构」，是读懂一切中医理论的前提，也是与《中医学》专题其他部分保持一致的立场。

## 4 核心要点：灸法如何「借力」理论三基石

灸法的完整作用链，是把三块理论基石串成一条流水线：

1. **腧穴是入口**：灸火落在腧穴，等于找到了经络之气在体表的门户。
2. **经络是通道**：温热刺激沿经络传导，把局部信号带到远端脏腑。
3. **气血是对象**：灸火温热之气进入经络，温煦气血、驱散寒凝，实现「温通温补」。

三者缺一不可：只懂腧穴不懂经络，取穴就是死记坐标；只懂经络不懂气血，就解释不了为什么「寒证用灸、热证忌灸」。**一句话记住：灸法 = 在腧穴点火，借经络运热，让气血温通。**

## 5 经络学说的现代研究视角

经络学说常被问「解剖学上找不到，凭什么可信」。诚实的回答是：**经络是功能性概念，不是解剖结构**——它的证据来自临床现象与功能联系，现代研究从多个角度尝试解释，迄今没有定论，但有几个方向值得了解：

**循经感传现象**：刺激穴位时，部分受试者能报告沿古典经络路线走向的感觉传导线。这一现象可重复、可记录，感传路线与经络走向高度吻合，是经络学说最直接的现象学证据。

**筋膜结缔组织网络假说**：解剖发现人体的结缔组织筋膜网络与经络走行存在重合，针灸刺激可能通过牵拉筋膜、激活间质细胞产生信号传导——这为「经络」提供了一种结构学猜想。

**红外热像与阻抗测量**：部分研究报道穴位区的红外辐射与皮肤阻抗与非穴位区不同，但结论尚不稳定，属探索性研究。

**关键立场**：本专题按中医理论体系讲授经络学说，同时明确它仍是开放的科学问题。**实践上，经络学说提供了一套经过千年临床检验的「取穴地图」——疗效可以验证，机制可以存疑**，这与《中医学》《针灸推拿学》专题的立场完全一致。

## 6 取穴基本功：同身寸与骨度分寸

无论灸还是针，取穴准确都是前提。家庭最实用的两套定位法是：

**同身寸法**：以**被灸者本人**的手指宽度为寸——拇指横宽为 1 寸，食中指并拢为 1.5 寸，四指并拢为 3 寸。注意「同身寸」三字的含义：**用自己的手量自己**，替别人量时要用对方的手，不可用自己的手替代。

**体表标志法**：利用体表的固定标志定位——两乳头连线中点取膻中，肚脐取神阙，第 7 颈椎棘突下取大椎，两眉头中点取印堂。骨性标志最可靠，是「不依赖尺寸」的定位法。

**取穴的一个实用原则**：灸法对取穴精度的要求宽于针刺——灸的热力辐射范围比针尖大，落在穴区即可起效。但「穴区」仍然有界，**宁可先量后灸，不可随手一放**；量错一寸，可能灸到旁经上去。

## 7 三条经络线：灸法最常用的「主干道」

十二正经不必一次记全，灸法家庭应用的高频经络其实集中在三条「主干道」上：

**任脉（腹中线）**：从会阴沿腹胸正中线上行。**神阙、气海、关元、中脘、膻中**都在此线——灸任脉是「温补下元、调理脾胃」的主干线，虚寒证的腹灸几乎都在此线取穴。

**督脉（背正中线）**：从尾骨沿脊柱上行。**命门、大椎**是灸法高频穴——督脉总督一身之阳，灸督脉之穴是「壮阳」的主力。

**足阳明胃经（下肢前外侧）**：**足三里、天枢**所在——足三里是「补后天」第一穴，灸胃经下肢段是保健灸的日常操作。

**记忆口诀**：「**腹灸任、背灸督、下肢灸胃经**」——先记这三条主干道，再逐步扩展到其他经，经络地图就从「十二正经」简化成了「三横三纵」。理解主干道，本专题第 4 篇的保健配穴（足三里、关元、命门为何高频出现）也就有了依据。

## 8 气血理论的「一句话把握」

气血是灸法作用的对象，也是中医理论里最容易被误解的部分。给一个「一句话把握」：

**气是「功能」，血是「物质」；气推动、温煦、防御，血濡养、化神；气行则血行，气滞则血瘀。**

把握这句话，就能理解灸法的作用链条：**灸火温气（补气、温阳）→ 气行（推动）→ 血行（活血）→ 濡养修复**——一条「温→行→通→养」的链。气虚则温煦无力、血瘀则痛有定处，灸法恰好从「温气」这一端入手，撬动整条链。

**与现代语言的对应**：气≈功能状态与代谢动力，血≈血液循环与营养物质——「温气行血」≈改善循环、促进代谢。两套语言描述的是同一个生理过程，只是术语体系不同。**把握住「功能与物质、推动与濡养」这两对关系，气血就不再是玄学，而是一套可理解的功能描述。**

## 9 小结

- **经络**是运行气血、联络脏腑的通路，经脉为干、络脉为支；灸火靠经络传导起效，临床可见「循经感传」。
- 十二正经按**三阴三阳 + 手足**分类，与脏腑一一对应，同名阴阳经互为表里——这是循经取穴的依据。
- **腧穴**是经气输注体表的落点，分十四经穴、奇穴、阿是穴三类；灸法对取穴精度的要求宽于针刺。
- **气血**是灸法作用的对象，「气为血之帅、血为气之母」；灸法通过**温气行血**对虚、寒、瘀证有效。
- 气与经络是**功能性概念**而非解剖结构，这是理解中医理论的世界观前提。
