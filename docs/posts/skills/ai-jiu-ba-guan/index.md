# 艾灸与拔罐

艾灸与拔罐是中医外治体系中最常用的两大自然疗法，以经络腧穴学说为基础，分别通过温热刺激与罐内负压温通气血、祛湿散寒、扶正祛邪。以《灸法学》《拔罐疗法》与《中医外治技术》为纲，系统重建从灸法、拔罐的理论基础、操作技术到临床常见病应用与家庭保健的完整知识体系。
