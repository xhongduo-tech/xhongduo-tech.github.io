## 为什么从机床原理开始

上一课我们认识了「车工」这个职业，这一课认识它手里的家伙——**数控机床**。普通车工与数控车工的分水岭，不是力气大小，而是「谁来指挥刀具」：普通车床靠人手摇，数控车床靠一串数字指挥。这串数字是怎么变成刀具精确移动的？中间那条看不见的链条，就是本章要讲的核心。理解这条链条，你写程序时才知道「G 代码只是冰山水面以上的那一角，水面以下是插补、伺服、检测整台机器在替你工作」。<span class="marginnote">这条链条的每一环在后续博文里都有专章展开：插补思想在第 10 篇《G/M 代码基础》会用到，伺服与检测则是第 14、20 篇机床结构的底子。</span>

## 1 从普通机床到数控机床

**普通机床（conventional machine tool）**：由人手动操作手柄、手轮，通过齿轮箱与丝杠把人的动作传给刀具。加工精度取决于人的手感与熟练度。

**数控机床（NC / CNC machine tool）**：**用数字化的程序控制刀具与工件相对运动的机床。** NC 是早期「数字控制」（Numerical Control）的缩写，用穿孔纸带输入；现代机床普遍采用 CNC（Computer Numerical Control，计算机数字控制），用微型计算机处理程序。<span class="marginnote">「CNC」中的 Computer 是 1970 年代后加上的——用一台专用/通用计算机取代了硬接线的逻辑电路，从此程序可以存在内存里反复调用，这也是后来「子程序」「固定循环」这类功能得以实现的硬件前提。</span>

两者最本质的差别一句话可概括：**普通机床的加工轨迹是"人手画的"，数控机床的加工轨迹是"计算出来的"。** 正因为是算出来的，它才能重复一万次都丝毫不差——这正是批产、精密加工选择数控的原因。

## 2 数控机床的组成

一台数控机床由**程序载体与输入输出装置、数控装置、伺服系统、位置检测装置、辅助装置、机床本体**六大部分组成，可以形象地分成「大脑、神经、肌肉、感官」四层：

**数控装置（CNC）——大脑**：接收程序，完成译码、插补运算、位置控制。它告诉你「下一步该到哪、走多快」。
**伺服系统——肌肉**：由伺服单元与伺服电机组成，把 CNC 的速度/位置指令放大成电机转动，再经滚珠丝杠驱动工作台或刀架移动。
- **位置检测装置——感官**：光栅尺、编码器等，实时测量工作台实际位置并反馈给 CNC，构成闭环。
- **可编程控制器（PLC）——调度员**：处理开关量信号，管理刀库、自动换刀、冷却泵、润滑、急停等「要么开要么关」的动作。<span class="marginnote">一个常见的理解误区是「PLC 也是数控的一部分」。严格说，CNC 管坐标轴的连续运动，PLC 管开关量逻辑；两者通过接口协同。加工中心的换刀动作通常就是 CNC 与 PLC 联手完成的。</span>
- **机床本体——骨架**：床身、主轴、导轨、刀架/工作台，保证运动精度与刚性。

把六部分连起来，就得到数控机床的工作流程：

$$ \text{程序} \xrightarrow{\text{输入}} \text{译码} \xrightarrow{\text{指令}} \text{插补运算} \xrightarrow{\text{位置指令}} \text{伺服驱动} \longrightarrow \text{机床运动} \xrightarrow{\text{反馈}} \text{位置检测} $$

## 3 加工原理：插补——把"直线"翻译成步进

机床的伺服电机本质上是一步步转动的，那它是怎么走出光滑的斜线、圆弧的？答案在**插补（interpolation）**。

**插补**：根据起点与终点之间的几何信息，在两点之间实时计算出一系列中间点的坐标，并把这些中间点逐一作为运动指令送给伺服系统。CNC 不是「直接走一条斜线」，而是**用无数小直线段（或一步一格的阶梯）逼近那条斜线**。<span class="marginnote">把连续轨迹离散成有限步，正是计算机处理连续问题的通用手法——与微积分里「以直代曲」、图形学里「用像素逼近直线」是同一个思想。你在第一级《基础数学》里学的斜率概念，在这里以最务实的方式复活了。</span>

常用的插补算法有**逐点比较法、数字积分法（DDA）、时间分割法**等。数控车铣最常用的是逐点比较法与时间分割法。本节先掌握逐点比较法的核心思想，具体计算放到下面的公式解析。

## 4 数控机床的分类

数控机床从不同角度分类，看的角度不同、叫法就不同。初学者最需要分清的是以下三把尺子：

### 按加工工艺分

| 类型 | 主要加工对象 | 备注 |
| --- | --- | --- |
| 数控车床 | 回转体（轴、盘、套） | 工件旋转，刀具直线移动 |
| 数控铣床 | 平面、沟槽、轮廓、型腔 | 刀具旋转，工件移动 |
| 数控钻/镗床 | 孔系加工 | 点位控制典型应用 |
| 数控磨床 | 淬硬表面的精加工 | 砂轮旋转 |
| 加工中心 | 铣、钻、镗、攻丝等复合加工 | 带刀库与自动换刀装置 |
| 特种加工机床 | 电火花、线切割、激光 | 非传统切削 |

### 按控制轨迹分

**点位控制**：只要求刀具从一点精确移动到另一点，移动路径不加工（如钻床定位、冲床）。**直线控制**：两点间沿平行坐标轴的方向进行切削。**轮廓控制**：同时控制两个及以上坐标轴，实现连续轨迹切削——数控车、铣都属于轮廓控制，这是它们能加工圆弧、斜线、曲面的根本原因。

### 按伺服系统分

- **开环控制**：没有位置反馈，用步进电机驱动，结构简单、成本低、精度低。
- **闭环控制**：工作台上装光栅尺直接检测实际位置并反馈，精度高但调试复杂、易振荡。
- **半闭环控制**：在伺服电机轴上装编码器检测转角，间接推算工作台位置。**现代数控机床以半闭环与闭环为主流。**

### 按联动轴数分

**联动轴**指同时参与插补运算、协同走出轨迹的坐标轴数量。两轴联动可加工平面曲线，三轴联动可加工立体曲面，五轴联动可一次装夹加工复杂空间曲面。2.5 轴则指三根轴中只有两根联动、第三根作点位移动。

## 5 公式解析：逐点比较法直线插补

逐点比较法是理解「插补」最直观的算法，它的流程是四步循环：**偏差判别 → 坐标进给 → 新偏差计算 → 终点判别**。这里解析第一步与第三步用的核心公式。

设第一象限直线起点在坐标原点 $O$，终点为 $(x_e, y_e)$，刀具当前位置为 $(x_i, y_i)$，定义**偏差函数**：

$$
F_i = x_e y_i - x_i y_e
$$

逐项拆解这条式子：

- **第一步，理解 $F_i$ 的几何含义**：直线 $OA$ 的斜率为 $y_e/x_e$，动点 $P(x_i, y_i)$ 到原点的连线斜率为 $y_i/x_i$。$F_i = x_e y_i - x_i y_e$ 的符号恰好比较出两者大小：$F_i = 0$ 时两点共线（$y_i/x_i = y_e/x_e$），$F_i > 0$ 时动点在直线上方，$F_i \lt  0$ 时在下方。
- **第二步，偏差判别**：$F_i \ge 0$ 时，向 $+X$ 进给一步（追直线）；$F_i \lt  0$ 时，向 $+Y$ 进给一步。
- **第三步，递推计算新偏差**。沿 $+X$ 走一步后 $x_{i+1} = x_i + 1$，代入 $F_{i+1} = x_e y_i - x_{i+1} y_e$，得：

$$
F_{i+1} = F_i - y_e \quad (\text{向 } +X \text{ 进给})
$$

沿 $+Y$ 走一步后 $y_{i+1} = y_i + 1$，同理得：

$$
F_{i+1} = F_i + x_e \quad (\text{向 } +Y \text{ 进给})
$$

- **第四步，终点判别**：统计已进给步数，或检查 $x_i, y_i$ 是否到达 $x_e, y_e$，未到则回到第一步循环。

这条公式链展示了插补的本质：**CNC 不用一次算出整条直线，只需记住一个偏差值 $F_i$，每走一步做一次加减法更新它，就能让刀具沿直线逼近终点。** 圆弧插补的偏差函数 $F_i = x_i^2 + y_i^2 - R^2$ 也是同一个思想——用「点到圆心距离与半径之差」代替「点到直线偏离」。<span class="marginnote">为什么只做加减法？因为 1970 年代的数控硬件没有乘除电路，递推公式把乘除化为加减，让高速插补成为可能。今天的高速加工中心改用时间分割法直接算坐标增量，但逐点比较法的四步循环思想仍是理解一切插补的钥匙。</span>

## 6 小结

- 数控机床用**程序控制运动**，其组成可记为「大脑（CNC）+ 肌肉（伺服）+ 感官（检测）+ 调度（PLC）+ 骨架（机床本体）」。
- 工作流程是**程序 → 译码 → 插补 → 伺服 → 运动 → 反馈**的闭环。
- **插补**是用有限步进逼近连续轨迹；逐点比较法四步循环：判别、进给、算新偏差、判终点。
- 分类三把尺子：按工艺、按控制轨迹（点位/直线/轮廓）、按伺服（开环/闭环/半闭环）；还有联动轴数。
