## 为什么从坐标系开始

程序里的每一个坐标数字，都必须有个「从哪量起」的原点，否则毫无意义。数控加工里有两套坐标系叠加在一起：**机床坐标系**是机器自己的「家」，由制造厂定死、靠回参考点建立；**工件坐标系**是零件的「工作台」，由操作者在对刀时设定，程序里的数字全部以它为基准。**两套坐标系之间的桥梁，就是对刀**——第 16、22 篇会专门讲。<span class="marginnote">坐标系是「从极限到大模型」里数学与工程的第一次正面握手：你在第一级《基础数学》里学的笛卡尔坐标、原点、坐标变换，在这里变成机床回零、对刀、G54 偏置这些看得见摸得着的动作。理解了「坐标系是相对的」，数控编程就入门了一半。</span>这一课先把方向规则讲透，再讲两套坐标系如何分工。

## 1 机床坐标系的轴与方向规定

数控机床的坐标轴采用**右手笛卡尔直角坐标系**：三根互相垂直的轴 $X$、$Y$、$Z$，加上绕它们的旋转轴 $A$（绕 $X$）、$B$（绕 $Y$）、$C$（绕 $Z$）。方向规定的三条硬规则：

1. **Z 轴**：平行于机床主轴轴线，**刀具远离工件（增大工件与刀具距离）的方向为正**。
2. **X 轴**：水平、垂直于 Z 轴。车床上 X 轴沿工件径向，**刀架远离工件旋转轴线的方向为正**；铣床上 X 轴沿工作台纵向，**面向主轴（立柱）时向右为正**。
3. **Y 轴**：由右手定则确定——右手拇指指向 +X、食指指向 +Z（或按笛卡尔右手定则），中指方向即 +Y。

落实到两类机床上，方向感是这样的：

**数控车床**：Z 轴与主轴同轴，正方向是刀架**远离卡盘**的方向；X 轴与工件轴线垂直，正方向是刀具**离开工件中心**的方向。
**数控铣床 / 加工中心**：Z 轴垂直工作台，**向上为正**；X、Y 在水平面内。

判断方向的正负，永远问一句话：**这个轴的正向，是不是「让刀与工件分开」的方向？** 答案是则正，反之则负。<span class="marginnote">正方向规则的统一约定（ISO 841）让全世界机床的程序风格一致：无论什么品牌，Z 正方向都是"退刀"。这也是为什么程序里退刀常用 `G00 Z100` 这种"越退越大"的坐标——数字越大离工件越远。</span>

## 2 机床原点与参考点

**机床原点（machine zero point）**：机床坐标系的原点，由机床制造厂在设计时设定，一般位于主轴端面中心（车床）或工作台一角（铣床）附近，是机床上**固定不变**的基准点。

**机床参考点（reference point）**：机床各坐标轴上靠近正向极限的一个固定点。数控机床开机后并不知道自己的坐标——它需要一个「校准动作」：**回参考点（回零）**。各轴移动到参考点后，系统就把该点登记为机床坐标系的已知位置，机床坐标系由此建立。<span class="marginnote">为什么开机要回零？因为 CNC 用的是增量式编码器，只能感知"走了多少"，不能感知"在哪里"。回参考点相当于给编码器做一次"清零"——类似尺子找不到零刻度时，先对个齐。也正因如此，机床断电后坐标系会丢失，重新开机必须再次回零。</span>

**回参考点**是每天的开工动作，操作顺序：开机 → 回参考点（一般先回 Z，再回 X）→ 建立机床坐标系 → 才能对刀与加工。

## 3 工件坐标系与编程原点

**工件坐标系（workpiece coordinate system）**：编程人员以工件为参照设定的坐标系，其原点称为**工件原点 / 编程原点**。

编程原点的选择原则：**尽量选在零件的设计基准或工艺基准上**，让程序里的尺寸与图纸尺寸一致，便于编程与检查。车床零件常把编程原点设在**工件右端面与轴线的交点**；铣床零件常设在**工件上表面中心**。<span class="marginnote">「编程原点定在哪」直接影响程序的可读性：原点定在右端面，则外圆长度方向坐标直接按图纸标注；原点定在左端面，则所有坐标都要先减一个总长。规范编程的第一课就是「把原点对准图纸基准」。</span>

工件坐标系在机床坐标系中的位置，通过**对刀**确定后，用两种方式告诉系统：

**G54—G59（工件坐标系偏置）**：在系统里预先输入工件原点相对机床原点的偏置值，程序用 `G54` 调用。这是现代数控的主流方式。
**G92 / G50（坐标系设定）**：程序运行到该指令时，以当前位置为工件原点重新定义坐标系。因为依赖「当前刀尖位置」，操作要格外小心。

## 4 绝对编程与增量编程

同一个点的坐标，可以有两种表示法：

**绝对编程（G90）**：每个坐标值都是**相对工件原点的绝对尺寸**，只与原点有关，与刀具前一位置无关。
**增量编程（G91）**：每个坐标值都是**相对刀具前一位置的增量**，只与「上一刀在哪」有关。

车床系统常用**直径编程**：X 坐标直接写直径值。因为零件图上的尺寸大多是直径，直径编程让程序与图纸一一对应，避免换算出错。<span class="marginnote">直径编程是车床新手最容易混淆的点：图上写「外圆 φ50」，程序里 X 就写 50，而不是 25（半径）。但增量编程中 X 的增量通常也按直径差写，而系统内部处理半径坐标——各厂家细节略有差异，编程前务必确认机床是直径编程还是半径编程。</span>

## 5 公式解析：绝对坐标与增量坐标的换算

绝对与增量之间只是一次减法。设前一点在工件坐标系中的绝对坐标为 $(X_1, Z_1)$，目标点的绝对坐标为 $(X_2, Z_2)$，则目标点的**增量坐标**：

$$
\Delta X = X_2 - X_1, \qquad \Delta Z = Z_2 - Z_1
$$

逐项拆解：

- **第一步，理解增量是「差」**：增量坐标描述的是「从当前位置走到目标位置，沿各轴要移动多少」，所以就是两点绝对坐标之差。正号表示沿正方向走，负号表示反向。
- **第二步，看绝对编程的写法**：`G90 X40 Z-30` 表示刀具走到工件坐标系里 $X=40, Z=-30$ 那个点，无论之前在哪。
- **第三步，看增量编程的写法**：`G91 X-10 Z-15` 表示从当前位置向 $X$ 负方向走 10、向 $Z$ 负方向走 15。
- **第四步，一个换算实例**：刀具当前在 $X=50, Z=-5$，要走到 $X=40, Z=-30$。增量方式应写 `G91 X-10 Z-25`，因为 $\Delta X = 40 - 50 = -10$，$\Delta Z = -30 - (-5) = -25$。<span class="marginnote">实际编程中，车削粗加工循环（G71 等）系统内部就是用增量方式逐层进刀的——你对循环里 `X` 增量的理解，直接决定循环轨迹是否走对。铣削中镜像、平移、旋转等功能也是对坐标做类似变换，公式形式一模一样。</span>

再补一条车床特有的换算。直径编程时，程序中的 $X$ 坐标值是直径值；若系统内部以半径计算，则两者关系：

$$
X_{\text{直径}} = 2 X_{\text{半径}}
$$

这条式子提醒你：**对刀时输入的 X 偏置、刀补里的 X 数值，都要跟编程方式保持一致**，混用直径与半径是车床事故的高发原因。

## 6 车床与铣床的坐标系对照

车床与铣床的坐标系规则同源，但落实到具体轴向上差异明显，对照着记比单独记牢靠：

| 对比项 | 数控车床 | 数控铣床/加工中心 |
| --- | --- | --- |
| 主运动 | 工件旋转 | 刀具旋转 |
| Z 轴 | 与主轴同轴（工件轴线） | 垂直工作台，向上为正 |
| X 轴 | 沿工件径向，离开轴心为正 | 工作台纵向，面向立柱向右为正 |
| Y 轴 | 一般不编程（车削为两轴） | 工作台横向 |
| 常用编程原点 | 工件右端面中心 | 工件上表面中心 |
| 编程平面 | X-Z 平面 | 默认 X-Y 平面（G17） |

对照表里藏着两个最该记住的差异：**车床是「工件转、刀走两轴」，铣床是「刀转、工件走三轴」**；车床程序几乎都在 X-Z 平面里写，铣床默认在 X-Y 平面里写圆弧与刀补，用到 `G17/G18/G19` 选择平面。<span class="marginnote">正因为铣床默认在 X-Y 平面编程，圆弧插补的 `I J` 对应 X/Y 方向、`K` 对应 Z 方向；而车床圆弧用 `I K` 对应 X/Z 方向。同一套 `G02/G03`，在不同机床上地址字含义不同——读程序前先看是车是铣，是第 10 篇强调的「一机一说明书」的又一次体现。</span>

除了三根直线轴，多轴机床还有**旋转轴**：绕 X 轴转的 A 轴、绕 Y 轴转的 B 轴、绕 Z 轴转的 C 轴。四轴加工中心通常是「XYZ + 一个旋转轴」（如绕 Y 的 B 轴回转工作台），五轴则再加一个刀轴摆动。旋转轴的正方向同样遵守「右手螺旋定则」——右手拇指指向某直线轴正方向，四指弯曲方向即对应旋转轴正方向。<span class="marginnote">旋转轴的正方向判断是五轴编程的入门门槛，但本专题以三轴车铣为主，先记住「旋转轴用右手定则，拇指指轴、四指绕向」即可。等学到智能制造、五轴加工时再展开。</span>

一个把两套坐标系串起来的完整场景：在立式加工中心加工板件，编程原点设在上表面中心。开机回参考点建立机床坐标系 → 对刀把工件原点位置存入 `G54` → 程序开头 `G54` 调用 → 此后所有坐标都以工件上表面中心计算。若还要加工工件的背面，就再设一个 `G55` 坐标系，程序里切到 `G55` 即可。整个过程机床坐标系始终不变，变的只是「工件坐标系相对机床坐标系的偏置」——这正是第 16、22 篇对刀操作反复在做的事，也是「坐标系是相对的」在工程里最标准的用法。

再补一句多轴的直觉：四轴加工中心在 XYZ 之外加一个旋转轴（如绕 Y 的 B 轴），程序写 `B45.0`，工作台就带工件绕 Y 轴转 45°；若旋转轴与 XYZ 同时插补，就是四轴联动加工空间曲面。旋转轴正方向同样由右手定则确定——拇指指直线轴正方向，四指弯曲方向即对应旋转轴正方向。

把本课要点压缩成四句速记：
- 坐标正方向 = **刀具远离工件的方向**。
- 开机必做回参考点，机床坐标系才建立。
- 程序坐标都以工件原点为基准，对刀就是求这个偏置。
- `G90` 绝对、`G91` 增量，增量 = 两点绝对坐标之差。

## 7 小结

- 坐标系采用**右手笛卡尔直角坐标系**；三根轴的正方向都满足「**刀具远离工件为正**」。
- **机床原点**是固定基准，开机后须**回参考点**才能建立机床坐标系。
- **工件坐标系**由对刀设定，程序坐标全部以编程原点为基准；设定位移用 `G54-G59` 或 `G92`。
- `G90` 绝对编程以原点为基准，`G91` 增量编程以前一点为基准，增量 = 两点绝对坐标之差。
- 车床常用**直径编程**，$X_{\text{直径}} = 2X_{\text{半径}}$；对刀与刀补数值要与编程方式保持一致。
