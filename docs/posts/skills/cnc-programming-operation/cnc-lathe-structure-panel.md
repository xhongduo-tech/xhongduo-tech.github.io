## 为什么从车床结构开始

前面讲完了理论层（切削、工艺、代码），从这一课起进入数控车床的实体世界。**操作一台车床，首先要懂它的「骨头」：主轴在哪里、刀架怎么动、尾座管什么、面板上每个键干什么。** 结构与操作面板是「对刀、编程、加工」三大实操的前提——你连手轮在哪、急停在哪都不知道，谈何加工？<span class="marginnote">数控车床与普通车床的结构同源：都是主轴带工件转、刀架带刀走。区别在于普通车床的进给靠手柄丝杠，数控车床靠伺服电机加滚珠丝杠；普通车床变速靠齿轮箱，数控车床靠主轴电机无级调速。理解了「同源」，学数控结构就有了一张旧地图。</span>这一课先立结构总图，再讲面板操作。

## 1 数控车床的组成

一台数控车床由以下主要部分构成：

**床身（床座）**：整台机床的基础，承受全部重量与切削力，导轨精度决定运动精度。
**主轴箱（床头箱）**：装夹工件并使其旋转。主轴由伺服主轴电机驱动，实现**无级变速**，是主运动的执行部件。
**进给传动系统**：伺服电机通过滚珠丝杠驱动刀架沿 Z（纵向）与 X（横向）运动，实现进给运动。<span class="marginnote">滚珠丝杠是数控机床「精度的心脏」：它把电机的旋转变成刀架的直线移动，丝杠的导程精度直接决定定位精度。滚珠在螺母与丝杠之间滚动代替滑动摩擦，所以能长期保持高精度、低磨损——这也是数控机床区别于普通机床的关键传动件。</span>
**刀架**：安装刀具并按指令换刀，常见四工位、六工位、八工位电动刀架或排刀架。
**尾座**：支承长工件的另一端，可装顶尖、钻头；加工细长轴时必不可少。
**冷却润滑系统**：供给切削液冷却刀具与工件，润滑导轨与丝杠。
**数控系统与操作面板**：车床的「大脑」与「操作台」。

## 2 布局形式：平床身与斜床身

按床身导轨的布置，数控车床分**水平床身**与**倾斜床身**两大类：

| 特征 | 水平床身 | 倾斜床身 |
| --- | --- | --- |
| 导轨倾角 | 0°（水平） | 通常 30°—60° |
| 排屑 | 铁屑易堆积在导轨区 | 切屑借重力滑落，排屑流畅 |
| 刚性 | 结构简单、占地小 | 刚性好，适合重切削与高速 |
| 刀具布置 | 刀架在工件上方 | 刀架倾斜布置，观察方便 |
| 典型应用 | 经济型数控车床 | 中高档数控车床、车削中心 |

**倾斜床身是当今中高档数控车床的主流**，核心优势是「排屑顺畅 + 刚性高」——铁屑不堆在导轨上，就不会挤进导轨间隙磨损精度。<span class="marginnote">床身倾斜的另一个隐藏好处是热对称：切屑和切削液从低处流走，床身左右受热更均匀，热变形对精度的影响更小。这在高速、长时间加工时优势明显。</span>

## 3 主传动与进给传动

**主传动**：主轴电机（变频或伺服）直接或经皮带驱动主轴。特点是无级变速，转速范围宽，能在加工中自动变速——这正是数控车床实现「恒线速切削」（G96）的硬件基础。<span class="marginnote">恒线速切削是数控车床的独门优势：车端面时工件直径从大到小，普通车床要手动不断升转速才能保持表面质量一致，数控车床用 G96 指令让系统自动随直径变化调整转速，保持切削速度恒定。这背后还是第 6 篇那条公式 $v_c = \pi D n / 1000$——直径变小、转速自动升高。</span>

**进给传动**：伺服电机通过滚珠丝杠把旋转变成刀架直线运动。X 轴（横向）带动刀架沿工件径向进退，Z 轴（纵向）带动刀架沿工件轴向移动。**X 轴是数控车床精度要求最高的轴**：车外圆的直径公差全靠 X 轴定位，而 X 向移动量与直径变化是 1:2 的关系（直径减小 0.1 mm，X 只移动 0.05 mm 半径量）——所以 X 轴常采用高精度丝杠与预紧结构。

**刀架**按换刀方式分**电动刀架**（转位选刀，四/六/八工位）与**排刀架**（刀具固定排列，靠 X/Z 移动换刀，常用于车削中心与小型车床）。电动刀架的换刀动作是「抬起 → 转位 → 锁紧」，转位到位后靠齿盘或端齿盘精确定位锁紧。

## 4 数控系统与操作面板

数控车床的「大脑」是**数控系统**，操作者与它打交道的窗口是**操作面板**。面板分两大区：

**CRT/LCD 显示屏区**：显示坐标、程序、报警、参数。屏幕上一行行坐标值是操作者的「眼睛」——加工时实时看刀具位置，对刀时读机械坐标，报警时看报警号。<span class="marginnote">屏幕上的坐标显示有三个窗口：机床坐标（机械坐标）、相对坐标、绝对坐标。对刀时看机械坐标，编程验证看绝对坐标，手轮移动看相对坐标——三种坐标窗口各管一摊，理解它们的区别才能读懂屏幕（第 9 篇《坐标系》讲过三者的关系）。</span>
**MDI/编辑键盘区**：输入程序、修改刀补、执行 MDI 指令。字母数字键 + 功能键（编辑、输入、删除、插入、翻页、光标）。

**机床操作面板区**：这是「开机床」的实体按钮区，几个关键件：

**急停按钮**：红色大按钮，紧急时按下，切断主轴与进给（第 3 篇详述）。
**方式选择开关**：编辑 / 自动 / MDI / 手动(JOG) / 手轮 / 回零，切换操作模式。
**循环启动与进给保持**：自动加工时「开始」与「暂停」。
**倍率旋钮**：主轴转速倍率、进给倍率、快速倍率（0—120% 或 0—100%）。
**单段运行开关**：逐段执行程序。
**手轮（电子手轮/摇手轮）**：手动精确移动刀架，对刀找正的主力工具——一格最小可移动 0.001 mm。

## 5 机床操作面板的关键按键与用法

新手最容易「认得清字、用不对键」，几个关键件的用法单独说：

**手轮（手摇脉冲发生器）**：选择手轮方式 → 选轴（X 或 Z）→ 选倍率（×1=0.001mm、×10=0.01mm、×100=0.1mm）→ 转动手轮。**对刀、找正、首件慢移全靠它**；倍率越低越精细，接近工件时务必切到 ×1 或 ×10。<span class="marginnote">手轮的三个倍率档（×1/×10/×100）对应「一格走多少」：×1 每格 0.001 mm（微调）、×10 每格 0.01 mm（对刀）、×100 每格 0.1 mm（快速找位）。接近工件一定要用低倍率——「最后 1 mm 用 ×1 慢慢蹭」是车床操作的基本功。</span>
**进给保持（Feed Hold）**：自动加工时按下，进给暂停、主轴继续转——「先停一下看看切屑和尺寸」的安全操作。
**单段运行（Single Block）**：开一次执行一个程序段，首件试切的标配。
**MDI 方式**：手动输入单条指令（如 `T0101`、`M03 S500`、`G00 X100 Z100`）立即执行，对刀、验证刀具、试主轴都靠它。

操作面板的所有按键里，**「急停」的位置必须闭着眼都能摸到**——这不是要求，而是事故换来的共识。

## 6 数控车床的基本操作流程

把面板各键串起来，就是数控车床的基本操作：

1. **开机**：合上电源，系统自检，解除急停、复位报警。
2. **回参考点**：方式开关切到「回零」，按 Z+、X+，让各轴回到参考点，建立机床坐标系。
3. **装夹工件**：装好毛坯（三爪卡盘夹紧，取下扳手）。
4. **装刀对刀**：装好刀具，用手轮慢移接近工件，按第 16 篇方法试切对刀，输入刀补。
5. **编辑/调用程序**：输入或调用程序，核对程序号与刀号。
6. **试运行与首件**：图形模拟 → 空运行 → **单段 + 低倍率**试切首件 → 检验。
7. **自动加工**：首件合格后，方式切「自动」，按循环启动，进入批量循环。
8. **收工**：清屑、润滑保养、记录交接。

其中第 2 步「回零」与第 6 步「单段试切」是最容易出问题的环节——**回零建立坐标系、单段防撞刀**，是数控车床两条生命线。

## 7 核心对比表：数控车床与普通车床

把数控车床与普通车床放一起对比，看清「升级」在哪里：

| 对比项 | 普通车床 | 数控车床 |
| --- | --- | --- |
| 进给驱动 | 人手摇手柄/丝杠 | 伺服电机 + 滚珠丝杠 |
| 主轴变速 | 齿轮箱手动变速 | 无级变速（G96 恒线速） |
| 刀具换位 | 手动松刀换刀 | 电动刀架自动转位 |
| 运动控制 | 人手控制轨迹 | 程序控制轨迹（插补） |
| 重复精度 | 依赖熟练度 | 程序保证，批量一致 |
| 操作面板 | 手柄、手轮、扳手 | 数控系统 + 操作面板 |

**这张表的本质：普通车床是「人的手」，数控车床是「程序 + 机器的手」。** 普通车床的每项操作在数控车床上都变成了「程序指令 + 面板按钮」——理解这一点，你操作数控车床时就知道「我按的这个键，对应普通车床的哪个动作」。

## 8 小结

- 数控车床组成：**床身、主轴箱、进给传动、刀架、尾座、冷却润滑、数控系统**。
- 布局两大类：**水平床身**（简单经济）与**倾斜床身**（排屑好、刚性高，中高档主流）。
- 主传动**无级变速**是恒线速 G96 的硬件基础；**X 轴精度要求最高**（直径 1:2 关系）。
- 操作面板分**显示屏区 + MDI 键盘区 + 机床操作面板**；手轮、急停、倍率、单段、循环启动/进给保持是关键件。
- 手轮倍率 ×1/×10/×100 对应 0.001/0.01/0.1 mm，接近工件用低倍率。
- 基本流程：开机 → **回零** → 装夹 → 对刀 → 调程序 → **单段试切** → 自动加工 → 收工。
