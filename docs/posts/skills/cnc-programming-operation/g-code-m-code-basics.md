## 为什么从 G/M 代码开始

前面的课程都在「想」，这一课开始「说」——用数控机床听得懂的语言把工艺写出来。这套语言由 **G 代码**（准备功能，管「怎么运动」）与 **M 代码**（辅助功能，管「开什么、停什么」）组成。<span class="marginnote">G/M 代码的历史可以追溯到 1950 年代 MIT 的伺服机构实验室：最初用穿孔纸带上的数字与字母控制机床，后来固化成 EIA RS-274 标准，今天几乎所有数控系统都沿用这套"G 字 + M 字"的语法。学它就是在学一门全球通用的机器语言。</span>这一课建立两个最重要的概念——**模态**与**代码分组**，再给你一张常用的 G/M 速查表。

## 1 指令字的构成与模态

一个程序段（一行程序）由若干**指令字**组成，每个指令字 = 地址符 + 数字，如 `G01`、`X40.0`、`F0.2`、`S1200`。地址符决定字的类别：`N` 段号、`G` 准备功能、`X/Y/Z` 坐标、`F` 进给、`S` 主轴转速、`T` 刀具、`M` 辅助功能。

其中最关键的概念是**模态指令（modal）**：**模态指令一旦指定，就一直有效，直到被同组的另一个指令取代。** 例如 `G01` 是模态的，写一次之后，后面所有只给坐标、不给 G 字的程序段都默认走直线切削。与之相对的是**非模态指令**：只在它所在的那一行有效，如 `G04` 暂停。<span class="marginnote">模态设计让程序大幅缩短，也埋下了隐患：你在程序开头写了 `G01`，跑到中间想快速定位却忘了写 `G00`——机床会继续按 G01 直线切削的速度跑过去，可能直接撞刀。所以编程高手都习惯在每个关键位置显式写清 G 代码，不依赖"上一行还记着"。</span>

## 2 运动类 G 代码

**`G00` 快速定位**：以机床最大速度空行程移动，**不切削**。格式 `G00 X… Z…`。只保证点对点到位，不保证轨迹是直线。
**`G01` 直线插补**：以指定进给速度沿直线切削。格式 `G01 X… Z… F…`。
- **`G02` 顺时针圆弧插补 / `G03` 逆时针圆弧插补**：以指定进给速度沿圆弧切削。判断顺逆时针的方向以「从 Z 轴正方向看」或按平面选择为准。
- **`G04` 暂停（延时）**：让程序在当前位置停留一段时间，用于光整、让刀让削。格式 `G04 X2.0`（秒）或 `G04 P2000`（毫秒，取决于系统）。

## 3 坐标系与补偿类 G 代码

- **`G90` 绝对编程 / `G91` 增量编程**：上一课讲过，模态指令。
- **`G92`（车床为螺纹循环；铣床为坐标系设定）**、**`G50`（车床坐标系设定）**：设定工件坐标系的另一类方式。
- **`G54`—`G59` 工件坐标系偏置**：调用预存的对刀偏置值，一台机床可预存六个工件坐标系，多工位加工非常有用。
- **`G40`/`G41`/`G42` 刀具半径补偿取消/左补/右补**：铣削轮廓加工的灵魂指令，第 12 篇专门讲。
- **`G98`/`G99`**：车床中常指「每分钟进给 / 每转进给」；孔加工固定循环中指「返回初始平面 / 返回 R 平面」，第 23 篇展开。
- **`G28` 返回参考点**：先经过中间点再回参考点，用于换刀或安全退刀。

**辨析｜易错点：同一个 G 代码，在不同机床、不同系统里含义可能不同。** 最典型的是 `G90`：在大多数数控铣床/加工中心上它是「绝对编程」，但在部分车床系统里它被用作「外圆切削循环」。`G92` 在车床上是螺纹循环、在铣床上是坐标系设定。**写程序前，第一件事永远是翻该机床的操作说明书确认代码含义，绝不能凭记忆跨机型套用。**<span class="marginnote">国际标准 ISO 6983 规定了 G 代码的基本功能，但各数控系统（FANUC、SIEMENS、MITSUBISHI、华中、广数等）在标准之外扩展了大量代码，甚至对同一编号有不同解释。这也是为什么正规数控车间要求「一机一工艺文件」——程序和代码约定都要绑定具体机床。</span>

## 4 M 代码：辅助功能

M 代码控制机床的「开关类」动作，多为非模态或按功能分组：

| M 代码 | 功能 | 典型用途 |
| --- | --- | --- |
| M00 | 程序暂停 | 人工测量、检查后按启动继续 |
| M01 | 选择停止 | 与面板「选择停止」开关配合，抽检时用 |
| M02 | 程序结束 | 停在程序末尾 |
| M30 | 程序结束并返回开头 | 批量生产的标准结束指令 |
| M03 | 主轴正转 | 车床/铣床开转 |
| M04 | 主轴反转 | 反向旋转 |
| M05 | 主轴停止 | 停转 |
| M06 | 自动换刀 | 加工中心换刀 |
| M07/M08 | 切削液开（雾/液） | 冷却润滑 |
| M09 | 切削液关 | 停冷却 |
| M98 | 调用子程序 | 第 13 篇展开 |
| M99 | 子程序返回 | 返回主程序 |

## 5 核心对比表：G 代码分组速查

G 代码按功能分组，**同一组的代码互为模态互斥**——写了一个，同组其他自动失效。这是全章最重要的结构图：

| 组 | G 代码 | 功能 | 说明 |
| --- | --- | --- | --- |
| 运动 | G00 / G01 / G02 / G03 | 快速/直线/圆弧 | 同一行只能有一个 |
| 坐标系 | G90 / G91 | 绝对/增量 | 模态互斥 |
| 工件坐标系 | G54—G59 / G92 | 偏置/设定 | 选一种方式 |
| 平面 | G17 / G18 / G19 | X-Y / X-Z / Y-Z 平面 | 圆弧与刀补的基准面 |
| 单位 | G20 / G21 | 英制/公制 | 常开机设定 |
| 刀补 | G40 / G41 / G42 | 取消/左/右 | 轮廓加工 |
| 车削循环 | G71/G72/G73/G74/G75/G76 | 复合固定循环 | 第 17 篇 |

## 6 圆弧插补：R 法与 IJK 法

圆弧除了用终点坐标，还必须指明圆心或半径，两种指定方法：

**R 法**：`G02 X… Y… R…`，直接给圆弧半径。系统自动选圆。**但 R 法有两个缺陷：无法编程整圆（R 无法区分 0° 与 360° 的同圆），且一个 R 对应两段弧（优弧/劣弧）时要用 R 正负来区分**——`R` 为负表示优弧（大于 180°）。<span class="marginnote">R 正负的约定：小于等于 180° 的圆弧用正 R，大于 180° 的圆弧用负 R。这个细节极易踩坑——少写一个负号，刀具会沿另一侧圆弧走过去，可能在工件内部走一条完全不同的轨迹。</span>
- **IJK 法**：`G02 X… Y… I… J…`，用圆心相对起点的增量坐标定位圆心：

$$
I = X_C - X_S, \qquad J = Y_C - Y_S
$$

其中 $(X_C, Y_C)$ 为圆心坐标，$(X_S, Y_S)$ 为圆弧起点坐标。车床的 X-Z 平面里相应为 `I K`。IJK 法能编程整圆（起点终点重合时，I J 给出圆心即得整圆），是轮廓编程的推荐写法。

## 7 常见 G/M 代码使用误区

编程老手与新手的差距，往往不在会不会写，而在**会不会踩坑**。以下是数控车间最典型的 G/M 代码误区清单：

- **误区一：G90/G91 混淆**。绝对/增量切换后忘了改回来，后续坐标全错。对策：程序开头显式写 `G90`，切换处加注释。
- **误区二：依赖模态、忘写关键指令**。前面是 `G01`，想快速定位却忘写 `G00`——机床按切削速度跑过去，直接撞刀。对策：快速移动段显式写 `G00`。
- **误区三：进给 F 的单位不分**。车床常用每转进给 mm/r，铣床常用每分钟进给 mm/min，混用会让进给量差一个数量级。对策：按机床与系统确认 F 单位。
- **误区四：T 指令的刀补号混乱**。`T0303` 前两位刀号、后两位刀补号，只写 `T03` 可能没有刀补，加工尺寸全偏。对策：按机床要求写全 `T××××`。
- **误区五：M03 忘写或主轴未转就切削**。对策：程序里每个加工段之前确认主轴状态。
- **误区六：圆弧 R 正负不分**。优弧忘写负 R，刀具沿另一侧圆弧走。对策：>180° 的圆弧用负 R，或用 IJK 法。

这六条误区的共同根源是**「想当然」**——拿一台机床的习惯去套另一台机床，或默认系统记得上一段的指令。<span class="marginnote">消除误区的系统性办法，是给每台机床建立一份「编程规范」：规定程序开头必须有哪些初始化指令、F/S/T 的写法、注释规范。车间里的编程规范相当于「代码风格指南」——它不能替代对系统的理解，但能挡住大量低级错误。这和软件工程的代码规范是同一件事。</span>

最后补一条 M 代码的注意事项：`M00`（程序暂停）在批产中常用于中间测量，但若忘了重新按启动，机床就一直停着，影响节拍；`M01`（选择停止）则要靠面板开关激活，适合抽检场景。暂停类指令用在哪、怎么用，写进编程规范，避免批产时手忙脚乱。

把本课要点压缩成两句速记：**运动靠 G、开关靠 M，模态写一次全程有效；查代码先查说明书，绝不跨机型套用。**

## 8 小结

- 程序段由**指令字**构成，地址符决定类别；**模态指令**一旦指定一直有效，直到同组指令取代。
- 运动类：`G00` 快速、`G01` 直线、`G02/G03` 圆弧、`G04` 暂停。
- 坐标类：`G90/G91` 绝对/增量，`G54-G59` 工件坐标系偏置，`G40-G42` 刀补。
- M 代码管开关：`M03` 主轴正转、`M05` 停、`M06` 换刀、`M08/M09` 切削液、`M30` 结束。
- **辨析**：同一 G 代码在不同系统含义可能不同，编程前必须查说明书。
- 圆弧两种写法：**R 法**（正负区分优弧劣弧，不能整圆）与 **IJK 法**（$I=X_C-X_S$
