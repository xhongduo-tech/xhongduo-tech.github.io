## 为什么从子程序与固定循环开始

一个零件上常有四个相同的孔、三条相同的键槽；粗加工时，同一轮廓要一层层地切七八刀。如果每一刀、每一个孔都老老实实写进程序，程序会又长又难改。**子程序**把重复的「程序段组」打包复用，**固定循环**更进一步，把「进刀—切削—退刀—返回」整套动作浓缩成一条指令。<span class="marginnote">这两种机制分别对应编程思想的「函数抽象」与「高阶指令」：子程序就是没有参数的子函数，固定循环则把常见操作封装成库函数。你在第三级《数据结构与算法》里学的「复用」与「抽象」，在数控编程里以最直白的形式出现。</span>这一课先讲子程序的调用规则，再讲两类固定循环的全貌。

## 1 子程序：把重复代码打包

**子程序（subprogram）**：被主程序调用的、独立编号的一段程序。主程序遇到 `M98` 就跳进子程序执行，子程序以 `M99` 结束并**返回主程序中调用点的下一段**继续执行。<span class="marginnote">`M99` 返回的位置不是程序开头，而是「调用它的 M98 的下一个程序段」——这就是「调用返回」语义，与高级语言里的函数返回一模一样。正因为要回到调用点，子程序里通常用相对坐标或由主程序设定好状态，避免「返程后坐标乱了」。</span>

调用格式（以 FANUC 为例）：

$$M98\ P\underline{OOOO}\ \underline{LLLL}$$

- `P` 后跟 8 位数字：前 4 位是**子程序号**（`O` 号，如 `O1234` 写为 `P1234`），后 4 位是**调用次数**（如 `L2` 表示调用 2 次）。
- 省略 `L` 时默认调用 1 次。子程序内部可以嵌套调用另一个子程序（嵌套级数有限制，一般为 2—3 层）。

一个典型的调用片段：

```
O1000;            主程序
N10 G90 G54;
N20 M98 P2000;    调用 O2000 一次
N30 G00 X100 Z100;
N40 M30;

O2000;            子程序
N10 G00 X20 Z0;
N20 G01 Z-30 F0.1;
N30 G00 X30;
N40 M99;          返回主程序
```

**子程序最适合的场景**：批量件中每个零件形状相同（调用子程序加工一个，主程序用循环控制多个工位）；同一轮廓在不同位置重复出现（用相对坐标的子程序配合平移）；粗加工分层（子程序配合坐标偏移逐层下刀）。

## 2 子程序的编程注意事项

用子程序有四个易错点，写之前先看：

- **坐标系状态**：子程序里用的坐标系（G54/G90/G91）要与主程序协调。若子程序内用增量编程（G91），调用点在什么位置、子程序就相对那里移动——**用增量子程序可以复用到任意位置**，这是最灵活的用法。
- **模态指令残留**：子程序里设置的模态（如 G01 的 F 值）会「带回去」影响主程序，返回后要检查。
- **调用次数上限**：调用次数不能超过系统限制（一般 9999 次），嵌套层数不能超过系统规定。
- **程序号不能重复**：子程序号与主程序号、其他子程序号都不得重复，否则系统会调错程序。

<span class="marginnote">把「子程序的模态残留」想清楚，你就抓住了数控程序的一个核心特性：<strong>程序段不是独立的，状态在段与段之间流动</strong>。这跟函数式编程里「纯函数」的思维正好相反——数控程序是「有状态」的，每个子程序都可能在「污染」或「恢复」状态。老手写子程序会刻意在开头设定好所需状态、结尾恢复主程序需要的状态。</span>

## 3 固定循环：把整套动作浓缩成一条指令

**固定循环（fixed cycle / canned cycle）**：把某一类加工中反复出现的「进刀 → 切削 → 退刀 → 返回」动作序列，用一条指令代替。固定循环减少程序段数、避免手工算重复坐标，是数控编程里「一条指令干一套活」的代表。

固定循环分两大类：

**车床复合固定循环（G70—G76）**：面向车削的粗精加工，自动分层切削。
**铣床孔加工固定循环（G80—G89）**：面向钻孔、镗孔、攻丝，自动完成快速定位、工进、退刀、返回。

两者思路一致：**你只给出「目标位置 + 加工参数」，系统自动补全整套动作轨迹**。<span class="marginnote">固定循环是数控系统「内置子程序」的体现：系统固化了这些动作序列，你调用 G71 就相当于调用了一个藏在系统里的子程序。这正是「子程序」思想向「系统级封装」的升级——如果说子程序是「自己写的函数」，固定循环就是「系统自带的库函数」。</span>

## 4 车床复合固定循环：G71—G76

车削复合固定循环主要处理「分层粗车」这一最麻烦的重复动作。核心指令：

**G71 外圆/内孔粗车复合循环**：一条指令完成「按给定轮廓多层粗车」。只需给出轮廓的起点、终点、每次切深、精车余量，系统自动沿轮廓分层进刀。这是轴类零件粗加工的主力指令。<span class="marginnote">G71 的威力在「自动分层」：你只需指定「毛坯从哪切到哪、每层吃多深」，剩下的每刀起点、退刀、返回全由系统算——这正是固定循环「一条指令干一套活」的典范。注意 G71 对轮廓的走刀方向有要求（从右往左还是从左往右），编程前先确认。</span>
**G72 端面粗车循环**：适合端面、盘类零件，沿 X 向分层。
**G73 固定形状粗车循环**：适合毛坯形状接近成品的锻造/铸造件，按形状平行偏移分层。
**G70 精车循环**：配合 G71/G72/G73，调用其精车余量，精车一刀成形。
**G74 端面钻孔循环 / G75 切槽循环**：分别处理端面钻孔与切槽的往复动作。
**G76 螺纹切削复合循环**：螺纹分层车削（第 17 篇《车削螺纹循环编程》专门展开）。

一个 G71 就能顶替几十段手工分层程序——把粗加工从「十几行重复」压缩成「一条指令 + 轮廓描述」。

## 5 铣床孔加工固定循环：G80—G89

铣床/加工中心的孔加工固定循环，是「钻孔、镗孔、攻丝」的标准封装。统一格式：

$$G\text{（循环码）}\ X\_\ Y\_\ Z\_\ R\_\ Q\_\ F\_$$

- `X Y`：孔位（坐标系里的孔中心）。
- `Z`：孔底深度（Z 坐标）。
- `R`：**R 平面（参考平面）**——刀具快速下降到 R 平面，再转为工进（切削速度）进到孔底。
- `Q`：每次进给量（啄钻用）。
- `F`：进给速度。

常用循环：

| 指令 | 功能 | 特点 |
| --- | --- | --- |
| G81 | 钻孔循环 | 快进到 R 面 → 工进到孔底 → 快退 |
| G82 | 钻孔循环（带暂停） | 孔底暂停光整 |
| G83 | 深孔啄钻循环 | 分段进给 + 退屑，防钻头折断 |
| G84 | 攻丝循环 | 主轴正转进、反转退 |
| G85 | 镗孔循环 | 工进进、工进退（不抬刀刮花孔壁） |
| G86 | 镗孔循环（主轴停） | 孔底主轴停、快退 |
| G80 | 取消固定循环 | 回到普通运动 |

**R 平面是孔加工循环里最容易出错的概念**：刀具先快进到 R 平面，然后才以切削速度进给。R 平面要设在工件表面上方（如工件上表面 +5 mm），既保证安全又节省快速行程。<span class="marginnote">G83 啄钻循环的关键参数是「每次啄进量 Q」与「退屑量」：每啄一段就快速退到 R 面排屑，再快速回到孔底继续啄。深孔不啄钻，切屑排不出来，钻头会「憋死」烧毁。啄钻的代价是时间，但换来的是钻头寿命——「用时间换安全」在孔加工里是必然选择。</span>

## 6 核心对比表：子程序与固定循环

把两种复用机制放一起对比，看清分工：

| 对比项 | 子程序（M98/M99） | 固定循环（G71/G76/G81 等） |
| --- | --- | --- |
| 本质 | 自己编写的代码块 | 系统内置的动作序列 |
| 调用方式 | `M98 P___ L___` | 一条 G 指令 + 参数 |
| 灵活度 | 高（可任意编排） | 低（固定动作模式） |
| 适用 | 重复出现的轮廓/工位 | 重复的标准动作（粗车、钻孔） |
| 参数化 | 靠状态/坐标 | 靠指令后的地址字 |

**分工原则：标准动作（钻孔、粗车分层）用固定循环；非标准重复（同一轮廓多工位、批量件单件循环）用子程序。** 两者常常配合：子程序里调用固定循环（子程序负责「位置循环」，固定循环负责「单孔/单层动作」），是加工中心批量加工的经典组合。

## 7 使用注意事项与常见错误

固定循环的使用有几个高频错误：

**忘记取消固定循环**：用了 G81 后忘了 G80，后续所有运动都被当成钻孔循环执行，坐标全乱。**规则：孔加工完成后立即 G80。**
**R 平面设太低**：R 平面低于工件表面，刀具会直接撞上去。R 面要高于最高工件表面。
**模态循环码残留**：G81 是模态的，写了一次后面每段都执行钻孔动作，直到 G80 或同组指令取代。
**循环参数遗忘**：换循环前没写 Z、R、Q，系统沿用上一次循环的参数，孔深错误。
**子程序嵌套过深**：超过系统嵌套限制，程序报警。

**辨析｜易错点：G80 取消的不仅是「这一个孔」，而是「这一整组循环模态」。** 很多新手以为写了一个孔就自动结束了，其实循环会一直延续到 G80。所以把「G80 取消」当成「写完孔加工段组后的强制收尾动作」——和程序结束用 M30 一样，是固定循环的规范收尾。

## 8 小结

- **子程序**用 `M98 P____ L____` 调用、`M99` 返回；可嵌套，适合重复轮廓与批量单件。
- 子程序注意**坐标系状态、模态残留、程序号不重复**；增量子程序可复用到任意位置。
- **固定循环**是系统内置的「进刀—切削—退刀—返回」封装，分**车床复合循环（G70—G76）**与**铣床孔加工循环（G80—G89）**两大类。
- 车床 G71 自动分层粗车、G76 螺纹循环；铣床 G81 钻孔、G83 啄钻、G84 攻丝、G80 取消。
- 孔加工固定循环三要素：**Z 孔底、R 平面、Q 啄进量**；R 面设太高浪费行程、设太低撞工件。
- 固定循环是**模态指令**，用完**必须 G80 取消**；子程序与固定循环可叠加使用。
