# 数控加工（数控车/铣编程与操作）

数控加工是以 G/M 代码为核心、通过数控车床与数控铣床实现零件自动切削的现代制造核心工种，涵盖编程、对刀、装夹找正与机床操作四大技能。以《国家职业技能标准—车工（2018年版）》数控车床工种、《数控加工工艺与编程》和《数控机床编程与操作》教材为纲，从安全基础、加工工艺、编程指令到车铣两类机床的实操，系统写完整门数控加工操作技能。

## 对标教材

- 《国家职业技能标准—车工（2018年版）》（数控车床工种）
- 《数控加工工艺与编程》（高职高专机械类教材）
- 《数控机床编程与操作》（高职高专机械类教材）
