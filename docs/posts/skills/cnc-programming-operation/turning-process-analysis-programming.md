## 为什么从车削工艺分析开始

从这一课开始，前面积累的所有知识开始「合流」：读零件图 → 定工艺 → 选刀 → 定用量 → 写程序。这一课以最常见的**轴类、盘类零件**为例，走一遍车削工艺分析与编程的完整流程。**车削是所有数控加工里程序最简单、工艺也最直白的一类**——工件只绕一根轴转，刀具只走 X/Z 两轴，是学习数控编程的最佳入门战场。<span class="marginnote">车削的程序简单，不代表工艺简单：轴的长径比、装夹方式、圆锥与圆弧的衔接、粗精分工，每个决定都影响最终精度。把车削这套「从图到程序」的流程走熟，后面学铣削就是沿着同一条路换一套动作。</span>这一课重点讲三件事：工艺分析看什么、圆锥圆弧怎么算、完整程序怎么写。

## 1 车削加工类型与装夹方案

车削能加工的回转表面类型：**外圆、端面、内孔、台阶、切槽与切断、螺纹、圆锥、圆弧成形面**。每种表面对应不同的刀具与工艺安排。

装夹方案按零件特点选择：

| 零件特点 | 装夹方案 | 说明 |
| --- | --- | --- |
| 短轴、盘类 | 三爪自定心卡盘 | 自动对中，装夹快 |
| 不规则件、偏心件 | 四爪单动卡盘 | 逐爪找正 |
| 细长轴 | 一夹一顶 / 两顶尖 | 增加支承，减少让刀 |
| 盘套类（以孔定位） | 心轴 | 保证内外圆同轴 |

**细长轴是最考验车削工艺的典型**：长径比大、刚性差，车削时径向力把它顶弯，产生「让刀 + 振动」。对策是用**一夹一顶**（卡盘夹一端、尾座顶尖顶另一端），必要时加**中心架/跟刀架**，并适当减小背吃刀量、提高切削速度。<span class="marginnote">车细长轴的经典困局：径向切削力 $F_p$ 把轴顶弯，弯了再切就更弯。跟刀架的作用就是「在刀尖附近给轴一个反向支承」，让轴顶着刀走而不弯。理解这一点，你就明白为什么细长轴要「顶着车」而不是「夹着车」。</span>

## 2 车削工艺分析的要点

拿到一张车削零件图，工艺分析按顺序做四件事：

1. **读结构与精度**：找出最重要的尺寸公差、同轴度、圆柱度要求，这些表面是工艺重点。
2. **选毛坯与装夹**：根据批量与形状定毛坯（棒料/锻件），按上表定装夹。
3. **排工序路线**：按「先基准后其他、先粗后精、先端面后外圆」原则。典型轴类路线：**粗车各外圆 → 精车各外圆 → 切槽 → 车螺纹 → 倒角**。
4. **定刀具与用量**：每道工序选刀（外圆刀/切槽刀/螺纹刀），按第 7 篇原则定 $a_p$、$f$、$v_c$。

车削加工路线的设计有一条重要原则——**进给路线尽量短、尽量不空行程**：先车离卡盘远的一端，再车近端，避免刀具频繁往返。

## 3 车削编程常用指令

车削程序在两轴（X-Z）平面内书写，常用指令：

**`G00` 快速定位**、**`G01` 直线插补**：运动主力。
**`G02` / `G03` 圆弧插补**：X-Z 平面内车圆弧，圆心用 `I K` 给出（`I` 为圆心相对起点的 X 向增量，`K` 为 Z 向增量）。
**`G90` 外圆切削循环**：一条指令完成「进刀—车外圆—退刀—返回」的单一固定循环，适合台阶轴粗车。
**`G94` 端面切削循环**：车端面用。
- **`G71`—`G76` 复合循环**：自动分层粗车与精车，是批产主力的编程方式（第 13 篇已见全貌，细节在螺纹循环一课展开）。

车床编程默认**直径编程**：X 坐标写直径值。<span class="marginnote">直径编程再次强调：图纸标注外圆 φ50，程序 X 就写 50.0，不要写成 25.0。很多第一次上车床的人在这里栽跟头——写半径值会把零件车成一半大小，而且因为系统以为是直径，实际刀尖只走了半径距离，零件尺寸直接翻倍错误。</span>

## 4 公式解析：圆锥尺寸的锥度计算

车圆锥（锥度表面）是车削编程里最常见的几何计算。设圆锥**大端直径 $D$**、**小端直径 $d$**、**圆锥长度 $L$**，定义**锥度**：

$$
C = \frac{D - d}{L}
$$

圆锥半角 $\alpha/2$ 满足：

$$
\tan\frac{\alpha}{2} = \frac{D - d}{2L}
$$

逐项拆解：

- **第一步，锥度的含义**：锥度是「每单位长度直径的变化量」。例如锥度 $1:5$ 表示每 5 mm 长度直径减小 1 mm，即 $C = 1/5 = 0.2$。
- **第二步，半角公式的几何来源**：把圆锥沿轴线剖开，剖面是一个梯形，其两腰延长交于一点成三角形。半角 $\alpha/2$ 是「直径差的一半」与「圆锥长度」构成的直角三角形的对边/邻边，故用 $\tan$。
- **第三步，一个具体例**：车一圆锥，$D = 40$ mm、$d = 36$ mm、$L = 40$ mm，则 $C = (40-36)/40 = 1/10$，半角 $\alpha/2 = \arctan(0.05) \approx 2.86°$。<span class="marginnote">圆锥编程有两种思路：知道大端、小端、长度时，算出半角后，可用「每移动 Z 方向 L，X 方向变化 (D-d)」在 G01 里直接写两个端点坐标——程序里只要把锥面起终点坐标算准，系统自动插补出锥面。半角主要用于选择锥度规、检验锥面角度。</span>
**第四步，编程中的换算**：若锥面起点在 $Z=0$、小端 $d$，终点在 $Z=-L$、大端 $D$，则终点 X 坐标写 $D$（直径编程），程序段 `G01 X40.0 Z-40.0 F...` 即车出该锥面。

## 5 一个完整实例：台阶轴编程

以一根典型台阶轴为例走完整流程。毛坯 $\phi 40 \times 100$ 棒料，要求：车端面、粗精车 $\phi 36$ 外圆长 50、车 $\phi 28$ 外圆长 25、倒角 $1 \times 45°$、切断。编程原点设在**右端面中心**。

```
O1000
N10 G90 G21 G50 S2000;      (绝对、公制，限定最高转速)
N20 G00 X42.0 Z2.0;         (快速定位到起刀点)
N30 M03 S800;               (主轴正转)
N40 G01 X40.0 Z0 F0.3;      (平端面)
N50 G01 X36.0 Z-1.5 F0.15;  (倒角 1×45°)
N60 G01 X36.0 Z-50.0 F0.2;  (粗精车 φ36 外圆)
N70 G01 X28.0;              (退至 φ28)
N80 G01 X28.0 Z-25.0 F0.15; (车 φ28 外圆)
N90 G00 X42.0 Z2.0;         (快速退刀)
N100 M05;                   (主轴停)
N110 M30;                   (程序结束)
```

逐段读一遍：**先平端面给长度定基准，再倒角避免尖角应力，然后从右到左车外圆，最后退刀结束。** 这版程序用的是最直白的逐段方式；批产时通常改用 `G71` 粗车循环 + `G70` 精车循环，程序更短、更可靠。

**本节为工艺分析类内容，以锥度计算作为公式解析，辅以完整编程实例。**

## 6 车削常见质量缺陷与对策

车削加工的常见缺陷大多有迹可循，按「现象 → 原因 → 对策」排查，比盲目调整参数高效得多：

| 缺陷 | 常见原因 | 对策 |
| --- | --- | --- |
| 外圆出现锥度 | 导轨磨损、让刀、尾座偏移 | 检查机床精度、减小径向力、调整尾座 |
| 圆度超差（椭圆） | 卡盘夹紧变形、主轴轴承间隙 | 控制夹紧力、用软爪、检修主轴 |
| 端面凹凸不平 | 刀具角度不当、刚性不足 | 换端面车刀、减小悬伸 |
| 表面粗糙度差 | 进给过大、刀尖圆弧小、振刀 | 减小进给、换大圆弧刀片、消振 |
| 台阶不垂直 | 刀具主偏角/副偏角不当 | 调整刀具角度、精车最后光一刀 |
| 倒角不匀 | 对刀不准、刀具磨损 | 重新对刀、换刀片 |

排查的顺序遵循第 18 篇的方法论：**先看装夹、再看刀具、后调参数**。车削中「锥度」与「让刀」经常相伴出现——细长轴径向力大，刀尖被推离工件，车出的外圆呈「喇叭口」。对策是先减小背吃刀量、加中心架/跟刀架，再谈调整机床。<span class="marginnote">车削缺陷排查里有个经验：<strong>表面出现规律性振纹，先查工件刚性（是否细长、夹持是否牢固），再查刀具悬伸，最后才查转速</strong>。很多人一上来就调转速，往往绕了远路——振动的根源大多是「哪里刚度不够」，而不是「转速不对」。</span>

把这张表存进记忆，等于给自己配了一张「车削故障速查卡」。实践中最快的进步方式，就是带着这张卡去机床上「对症下药」。

## 7 小结

- 车削可加工**外圆、端面、内孔、台阶、切槽、螺纹、圆锥、圆弧**等回转表面。
- 装夹四方案：**三爪/四爪/一夹一顶/心轴**；细长轴要一夹一顶加跟刀架。
- 工艺四步：**读图 → 选毛坯装夹 → 排路线（先基准、先粗后精）→ 定刀定量**。
- 常用指令：`G00/G01/G02/G03` + `G90/G94` 单一循环 + `G71-G76` 复合循环；**直径编程**。
- 锥度公式 $C = (D-d)/L$，半角 $\tan(\alpha/2) = (D-d)/(2L)$
