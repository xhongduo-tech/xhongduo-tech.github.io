# 私人飞行驾驶执照（PPL/运动照）

私照培训是系统化的航空驾驶教育体系，覆盖从执照申请资格、飞机结构与飞行原理、航空气象与导航到飞行运行、应急处置与安全决策的完整知识链。以 CCAR-61、民航局理论考试大纲与 FAA 飞行员航空知识手册为纲，学完这些章节，就写完了私用驾驶员执照（PPL）理论考试与飞行训练要求的全部内容。

## 对标教材

- CCAR-61《民用航空器驾驶员合格审定规则》
- 民航局《私用驾驶员执照理论考试大纲》
- FAA《飞行员航空知识手册》（Pilot's Handbook of Aeronautical Knowledge）
