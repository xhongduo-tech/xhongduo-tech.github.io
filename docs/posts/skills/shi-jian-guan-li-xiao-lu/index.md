# 时间管理与效率提升

以《番茄工作法图解》《高效能人士的七个习惯》与《深度工作》为纲，系统建立从时间管理观念与要事优先、番茄工作法的专注节奏、深度工作法对注意力的训练，到摒弃浮浅与效率系统整合的完整方法论体系。学完这些章节，就掌握了让单位时间产出更高、专注状态可持续的时间管理底层能力。

## 对标教材

- 《番茄工作法图解》（史蒂夫·诺特伯格）
- 《高效能人士的七个习惯》（史蒂芬·柯维）
- 《深度工作》（卡尔·纽波特）
