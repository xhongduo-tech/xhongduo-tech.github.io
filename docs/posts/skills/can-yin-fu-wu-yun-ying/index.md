# 餐饮服务与门店运营管理

餐饮服务与门店运营管理是餐饮从业者从服务员、领班到店长、运营经理的完整职业能力链，涵盖餐厅服务礼仪、点单上菜、收银结账、门店排班、成本控制与运营管理。以《餐厅服务与管理》《餐饮企业运营管理》《餐饮门店经营管理》三本教材为纲，学完这些章节，就系统掌握了从餐前准备、席间服务、收银结账到门店经营与成本控制的餐饮运营全流程技能。

## 对标教材

- 《餐饮企业运营管理》
