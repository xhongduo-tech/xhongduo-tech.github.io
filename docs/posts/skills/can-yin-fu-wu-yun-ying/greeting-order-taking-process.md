## 为什么从迎宾与点单开始

前面学的托盘、摆台、礼仪，都是「准备」；从顾客进门这一刻起，服务进入「实战」。**迎宾**是服务的起点，**点单**是服务链条的第一个关键决策点——顾客在这一刻决定「点什么、花多少、坐多久」，餐厅在这一刻决定「推什么、备什么、怎么排后厨」。<span class="marginnote">迎宾与点单看似是服务员的两件小事，其实是餐厅经营的「漏斗入口」：进门人数 × 客单价 = 营业额，而点单直接决定客单价。会点单的服务员，一桌能比普通服务员多卖 20%—30%——这是「推销能力」与「服务能力」的交汇点。</span>

本课把这两个动作连成一条完整流程：**迎客 → 引领 → 递菜单 → 点单 → 复述确认 → 下单**，并讲清每个环节的标准动作与常见错误。

## 1 迎宾引领：第一印象与动线安排

**迎宾（greeting）**：顾客到店，迎宾员或值台服务员应**主动迎上前去**——不是等顾客走到跟前，而是看到顾客进门的瞬间就起身、微笑、问候。

**引领（seating）**：引领顾客到合适座位的过程。**「合适」按三条标准判断**：

**按人数**：两位顾客不坐八人台，大桌散开不紧凑——台型与人数匹配，避免浪费台面，也让顾客不觉得空旷或被挤。
**按需求**：带小孩的家庭靠窗或靠游乐区；情侣偏好安静角落；商务宴请选包间或安静区；行动不便者选离门口近的座位。<span class="marginnote">「按需求分座」是迎宾的进阶能力——它要求迎宾员在十几秒内观察出顾客的类型与偏好。观察力是迎宾的核心技能：着装、人数、行李、是否带孩子，都是分座的线索。</span>
**按动线**：引领时避开传菜动线、上菜频繁的区域；空位不足时礼貌说明并请顾客稍候，**绝不能说「没有位子了」就结束对话**。

**易错点｜辨析：** 迎宾常见的错误是「只顾引路、不问需求」——机械地把顾客带到最近的空桌，既不问「几位」，也不看顾客类型。**迎宾不是「带路」，是「第一次为顾客做安排」**——多问一句「您几位」「需要安静一点的位置吗」，第一印象立刻不同。<span class="marginnote">迎宾问的「几位、有什么需求」，与第5课礼仪讲的「主动问候」是一体的：礼仪给的是形式，这里给的是内容。形式 + 内容，才构成一次完整的迎宾。</span>

## 2 点单：从递菜单到推荐

**点单（order taking）**是服务员最重要的「产出动作」之一。完整点单分四步：

**第一步，递菜单**：顾客落座后 1—2 分钟内递上菜单，**双手奉上、翻开正面**；同时可简单介绍「我们店的招牌菜是××，您可以先看看」。**递菜单的时间点很讲究**——太早显得催促，太晚显得怠慢，以顾客刚坐稳、水已上桌为佳。

**第二步，观察与等待**：递菜单后**给顾客留出阅读时间**，不要立刻问「您吃什么」。经验做法是：趁这个间隙为顾客斟茶、介绍当日特色，既缓解沉默，又为推荐铺垫。<span class="marginnote">「留白」是点单的节奏感：顾客需要时间看菜单，服务员也需要时间判断顾客类型——是熟客（直接推荐新品）、是请客（推荐有面子的硬菜）、是家庭（推荐实惠分量足的菜）。判断对了，推荐才有用。</span>

**第三步，推荐与推销**：在顾客犹豫时给出**针对性建议**。推荐的三条原则：

**推招牌**：推荐本店特色、点击率高的菜品——招牌菜是餐厅的「记忆点」，顾客最容易接受。
**推搭配**：按「一荤一素一汤一主食」的结构补全点单，让一桌菜更均衡，也抬高客单价。
**推季节与限量**：「这个季节的河蟹最肥」「今天的例汤是××」——**稀缺性与时效性是最有力的推销话术**。<span class="marginnote">「结构式推销」比「硬推销」有效得多：硬推销是「您要不要来份龙虾」，顾客本能拒绝；结构式推销是「您点了两个荤菜，要不要配个清爽的素菜」，看起来是为顾客着想，实际上是在补全点单、提升客单价——这是服务与销售的双赢。</span>

**第四步，复述确认**：点单完成后，**把所点菜品逐一向顾客复述一遍**——「您点的是：宫保鸡丁、清蒸鲈鱼、蒜蓉西兰花、例汤和米饭，对吗？」。复述是点单流程的**防错关键**：名字相近的菜（如「鱼香肉丝」与「宫保肉丝」）、忌口（免辣、去香菜）、数量，都在复述环节得到最终确认。<span class="marginnote">复述确认与第1篇讲的服务礼仪一脉相承——它看似多花十秒钟，却能避免一整桌「上错菜」的连锁事故。错单的成本远超复述的成本，这是服务业「预防优于补救」的典型例子。</span>

## 3 下单与特殊要求处理

点单确认后，**下单**进入后厨：

**下单方式**：手写点菜单（传统）或 POS 机录入（现代）。**无论哪种，台号、菜名、数量、规格、备注必须完整**——台号写错，菜送到邻桌；备注漏写（免辣、少油），出锅才发现。手写点菜单要字迹清楚，一式三联（前台、后厨、收银各一联）或电子同步。<span class="marginnote">「台号 + 菜名 + 数量 + 备注」四要素是点单信息的完整性标准，与数据库里的「字段完整性」同理——任何一个字段缺失或写错，整条记录就不可用。把点单当「填表」做，出错率自然下降。</span>

**特殊要求处理**：顾客提出忌口（对某原料过敏、不吃葱姜蒜、宗教饮食禁忌）、做法调整（少油、微辣、走葱）时，**必须记录在备注中并口头知会后厨**——只记在单上怕后厨忙乱中漏看，口头交代是最保险的双保险。

**易错点｜辨析：** 点单最怕「不懂菜」。顾客问「你们这个西湖醋鱼酸不酸」「龙井虾仁用什么茶」，答不上来或答错，点单就卡住了。**点单能力的一半是菜品知识**——服务员要对本店菜单的原料、口味、分量、出菜时间了如指掌，这是点单培训的隐藏课程。<span class="marginnote">「点单能力 = 菜品知识 + 推销技巧 + 沟通节奏」三件套：菜品知识让你答得上，推销技巧让你卖得多，沟通节奏让你让顾客觉得舒服。三者缺一不可——这也是服务员晋升领班的考核重点。</span>

## 4 核心要点：迎宾点单流程对照表

迎宾与点单是流程性技能，不涉及公式，用一张流程对照表固定每个环节的标准动作与关键细节：

| 环节 | 标准动作 | 关键细节 | 常见错误 |
| --- | --- | --- | --- |
| 迎客 | 主动上前、微笑问候 | 顾客进门瞬间起身 | 埋头干活不抬头 |
| 引领 | 问人数需求、分配合适座位 | 动线避让、拉椅让座 | 不问需求、就近乱塞 |
| 递菜单 | 双手奉上、翻开正面 | 落座 1—2 分钟内、先上水 | 久等不递、随手一放 |
| 推荐 | 推招牌、推搭配、推限量 | 观察顾客类型再推荐 | 不看人就硬推销 |
| 复述 | 逐项复述所点菜品 | 确认忌口、数量、规格 | 点完就下单不确认 |
| 下单 | 台号菜名数量备注齐全 | 特殊要求口头知会后厨 | 漏备注、写错台号 |

**读表要点**：整个流程的节奏是「**快而不急、稳而不拖**」——迎客要快（不冷落）、点单要稳（不催逼）、下单要准（不出错）。节奏感是流程性服务的灵魂，而节奏来自对每个环节标准动作的熟练掌握。<span class="marginnote">这张流程表是第2篇整篇的「骨架」：本课讲的是入口（迎宾点单），后续课程是身体的展开（上菜分菜、西餐服务、酒水、宴会、结账）。把这张表刻进习惯里，后续每一课都是它的延伸。</span>

## 5 常见问题速查与实操要点

迎宾与点单是「出错率最高」的服务环节——信息密集、沟通多、时间紧。把高频问题列成速查表：

| 问题场景 | 快速判断 | 处置要点 |
| --- | --- | --- |
| 顾客进门没空台 | 台位已满 | 登记候位、预估时间、安抚等候 |
| 顾客问「有什么推荐」 | 推荐时机到了 | 推招牌 + 搭配，报 2—3 道并说理由 |
| 两桌同时催点单 | 人手紧张 | 先回应「马上来」，逐一处理不慌乱 |
| 菜名相近点错 | 复述环节没做 | 逐项复述，特别确认易混菜名 |
| 顾客忌口没说清 | 备注漏记 | 记备注 + 口头知会后厨，双保险 |
| 顾客对推荐不耐烦 | 推销过度 | 立即收住，回归「您想吃点什么」 |

这张表覆盖了迎宾点单的高频场景。**读表要点：** 点单问题的共同根源是「信息」——**点单环节的一切风险，都靠「复述确认 + 记录完整」来防**。把复述养成习惯，错单率会断崖式下降。

**实操要点（本课动作清单）**：

**迎宾先问三件事**：几位、有预订吗、有没有偏好位置——三问把需求问清。
**递菜单后留白**：先上水、简单介绍特色，再给顾客看菜单的时间。
**推荐用「理由」不用「命令」**：报招牌菜时带一句「这道是我们点击率最高的」。
- **复述必做**：点完单逐项复述，让顾客说「对」再下单。
- **忌口双保险**：备注写一遍、口头说一遍，后厨两处都到。

**点单是「服务的咽喉」**：点对了，后面上菜、结账都顺；点错了，整桌服务被拖累。把点单做成「零差错」的流程，服务就稳了一半。

## 6 进阶：点单推销的「看人下菜」

点单推销不是「对谁都推同一句」，而是**看顾客类型、选推荐策略**。把常见顾客类型与推销策略列成对照表：

| 顾客类型 | 消费特征 | 推荐策略 | 话术示例 |
| --- | --- | --- | --- |
| 家庭聚餐 | 注重实惠与分量 | 推性价比套餐、儿童菜 | 「家庭套餐更划算，含汤和主食」 |
| 商务宴请 | 注重面子与档次 | 推招牌硬菜、有排场 | 「这道是我们店招，宴请很有面子」 |
| 情侣约会 | 注重氛围与精致 | 推精致小份、搭配酒水 | 「配一杯红酒，气氛更好」 |
| 老顾客 | 熟悉菜单、有偏好 | 推新品、问口味变化 | 「这季上了新菜，您尝尝？」 |
| 赶时间的顾客 | 要快、要饱 | 推现成套餐、出菜快的菜 | 「这套餐出菜快，不耽误您时间」 |

**读表要点：** 推销的根基是**「读懂顾客要什么」**——家庭要实惠、商务要面子、情侣要氛围、老客要新鲜、赶时间要速度。**推荐不是「卖你贵的」，而是「给你合适的」**——合适的推荐，顾客接受度高，客单价自然上去。<span class="marginnote">「看人下菜」的推销，与第6课「观察顾客类型再推荐」一脉相承——它是点单从「会点」到「会卖」的进阶。<strong>推销的本质是「帮顾客做选择」</strong>：顾客面对菜单常常「选择困难」，服务员的价值就是「给出合适的建议」——前提是读懂他。</span>

**推销的边界**：推荐可以积极，但**尊重顾客的最终选择**——顾客明确不要，立即收住不纠缠。**「推荐」与「强迫」只差一条线：顾客说不要，就停止**。

## 7 小结

- 迎宾引领的三条分座标准：**按人数、按需求、按动线**；迎宾不是带路，是第一次为顾客做安排。
- 点单四步：**递菜单 → 观察等待 → 推荐推销 → 复述确认**；复述是防错关键。
- 推荐三原则：**推招牌、推搭配、推限量**；「结构式推销」是服务与销售的双赢。
- 下单信息四要素：**台号、菜名、数量、备注**；特殊要求要记录并口头知会后厨。
- 点单能力 = **菜品知识 + 推销技巧 + 沟通节奏**三件套。

在下一课，点单之后是重头戏——**中餐上菜、分菜与派菜服务**。菜从后厨出来了，怎么把它端上桌、分到位、派得体，是中餐服务的核心手艺。
