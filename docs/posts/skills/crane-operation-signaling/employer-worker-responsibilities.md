# 用人单位与作业人员的职责义务

## 为什么从职责义务开始

前几课都在讲「证」，这一课把镜头从证拉回人——**持证的人到了单位，单位和你之间，法律各自分配了哪些责任？** 特种设备安全从来不是作业人员一个人的事：单位出制度、出条件、出培训，作业人员出技能、出操守、出执行。两边各尽其责，安全才立得住。<span class="marginnote">职责划分的实质是「谁对什么负责」：出了事故，调查首先问的就是「单位做到了没有、个人做到了没有」。所以这一课不是抽象的法条罗列，而是<strong>给自己和单位各画一张责任清单</strong>——事故追责时，清单就是答案。</span>

## 1 用人单位的职责义务

《特种设备作业人员监督管理办法》对用人单位（使用单位）规定了明确的义务，可归纳为「聘、培、管、保」四件事：

**聘用持证人员**：用人单位应聘用持有有效《特种设备作业人员证》的作业人员，不得安排无证人员从事特种设备作业。<span class="marginnote">「聘用持证人员」是单位的第一义务：单位在招聘、排班时就要核验证件。若单位明知无证还安排上岗，出了事故，单位的责任往往重于作业人员本人——<strong>无证作业是「单位的失职 + 个人的违法」双重问题</strong>。</span>

**组织培训与安全教育**：单位应组织作业人员进行安全教育和培训，保证其具备必要的安全知识与技能；建立培训档案，记录培训情况。特种设备作业的培训不能「入职一次就完」，要随法规更新、设备更换持续进行。

**建立健全管理制度**：单位应建立特种设备安全管理制度与操作规程，明确岗位职责、交接班制度、检查制度，并把制度落实到每一班、每一岗。

**保障作业安全条件**：单位应为作业人员提供符合安全要求的作业环境与防护条件——设备检验合格、安全装置有效、作业现场安全；对作业人员的违章行为，单位有纠正与处理的责任。

## 2 作业人员的职责义务

持证上岗的作业人员，同样有一份法定的责任清单：

**持证作业、对证上岗**：在自己证书载明的项目与机型范围内作业，证件随身备查，不无证作业、不跨项作业。

**遵守规程与信号**：严格执行操作规程与安全管理制度，服从持证指挥人员的正确指挥；对违反安全规定的指挥，有权拒绝执行——**「不安全的活，可以（应当）不干」**。<span class="marginnote">「拒绝权」是作业人员的法定权利，也是本专题反复强调的底线：<strong>信号不明不吊、超载不吊、下方有人不吊</strong>。司机对违章指挥说「不」，不是顶撞，是尽责——这条在 GB 5082 与操作规范的执行中，始终优先于「听指挥」。</span>

**正确使用与维护设备**：按规程操作设备，做好交接班检查与日常维护，发现隐患及时报告；不擅自拆除、短接、调整安全保护装置。

**参加培训与复审**：参加单位组织的安全教育与培训，按规定申请证书复审，保持证书有效与自身技能更新。

## 3 作业人员的权利：不只是义务

职责的另一面是权利。法律在给作业人员设定义务的同时，也给了保护：

**获得安全培训与劳动保护的权利**：作业人员有权获得岗位必需的培训、合格的设备、必要的劳动防护用品。

**拒绝违章指挥、违章作业的权利**：对违章指挥与强令冒险作业，作业人员有权拒绝；对危害生命安全的行为，有权提出批评、检举和控告。

**紧急避险权**：作业现场出现直接危及人身安全的紧急情况时，作业人员有权停止作业或者在采取可能的应急措施后撤离作业场所。

**重点：权利与义务是一体两面。** 拒绝违章指挥，既是权利也是责任——因为「明知危险还硬上」，作业人员自己也要对后果负责。会拒绝，是特种设备作业人员成熟的重要标志。

## 4 持证人员的日常管理

证书之外，作业人员与单位之间还有一套日常管理动作：

**持证台账**：单位建立作业人员台账，登记证件、项目、有效期、复审情况，到期前提醒复审。台账是单位「把证管起来」的直接体现。

**定期体检与状态管理**：单位应关注作业人员的健康状况与精神状态，身体不适、疲劳、酒后等状态下不得安排作业。起重作业是「人的状态直接决定安全」的工作。

**违章记录与考核**：单位对作业人员的违章行为记录在案，纳入考核；屡次违章的，可调离岗位或按规定处理。<span class="marginnote">日常管理的关键词是「留痕」：培训有记录、检查有记录、违章有记录。<strong>记录既是管理的工具，也是事故调查时的证据</strong>——单位有没有尽到义务，记录会说话。</span>

## 5 核心要点对比：单位与作业人员的责任清单

| 事项 | 用人单位的责任 | 作业人员的责任 |
| --- | --- | --- |
| 持证 | 聘用持证人员、建立台账 | 持证上岗、对证作业 |
| 培训 | 组织培训、建档案 | 参加培训、按期复审 |
| 规程 | 制定制度与规程 | 遵守规程与信号 |
| 安全条件 | 提供合格设备与条件 | 正确使用、及时报告隐患 |
| 违章指挥 | 纠正与处理违章 | 有权拒绝并报告 |

这张表的两列是一一对应的：**单位给条件，个人守规矩**。任何一边缺位，安全链条就断了一环。

## 6 术语速查：职责义务的常用术语

| 术语 | 含义 | 关键要点 |
| --- | --- | --- |
| 用人单位 | 聘用作业人员的单位 | 特种设备使用单位 |
| 持证聘用 | 聘用持有效证件的作业人员 | 不得安排无证上岗 |
| 安全培训 | 单位组织的安全知识与技能培训 | 建档案、留记录 |
| 操作规程 | 规定作业动作的制度文件 | 作业的基本依据 |
| 交接班制度 | 班次间的设备与责任交接 | 记录、签字 |
| 拒绝权 | 拒绝违章指挥与强令冒险作业 | 既是权利也是责任 |
| 紧急避险权 | 紧急情况下停止作业、撤离 | 直接危及人身时行使 |
| 持证台账 | 单位登记的作业人员证件信息 | 到期前提醒复审 |
| 劳动防护 | 单位提供的个人防护用品 | 作业人员有权获得 |
| 违章记录 | 对违章行为的登记 | 纳入考核 |
| 培训档案 | 培训情况的记录材料 | 管理留痕的体现 |

### 现场口诀速记：单位与个人各司其职

- 单位四责：聘培训管保，一样不能少；
- 个人四责：持证按规护设备，培训复审记得牢；
- 违章指挥敢拒绝，紧急避险不犹豫；
- 台账体检加记录，责任清单两栏明。

这张表是「谁对什么负责」的速查卡：单位一栏、个人一栏，两栏对照、各司其职——责任清单时刻在案，安全链条环环相扣。

## 7 小结

- 单位四责：**聘（聘用持证人员）、培（组织培训）、管（建章立制）、保（保障安全条件）**。
- 作业人员四责：**持证作业、遵守规程、正确使用设备、参加培训复审**。
- 作业人员的权利：**获得培训与保护、拒绝违章指挥、紧急避险**——拒绝违章既是权利也是责任。
- 日常管理：**持证台账、定期体检、违章记录**，管理靠「留痕」。
- 责任对应：**单位给条件、个人守规矩**，任何一边缺位，安全链条就断。
- 事故追责先看责任清单：**单位做到了没有、个人做到了没有**，答案都在清单里。
- 职责清楚，责任才分得清；责任分清，安全才立得住。
- 单位与个人不是「对立」，而是「同一根绳上的两端」——**单位尽到义务，个人守住规矩，安全才能共同托底**。
- 把这份责任清单带在身上，出任何问题先对照清单——**答案都在清单里**。
- 单位与个人共同守住各自的「四责」，起重作业的责任体系才算完整。
- 责任越清楚，执行越自觉——**把责任写进制度、记在心里、落到动作**。
- 职责义务讲完，下一节我们把视野拉到整个监督体系，看监管与责任。
- 单位的「聘培管保」与个人的「持证守规」，是起重安全这枚硬币的两面。
