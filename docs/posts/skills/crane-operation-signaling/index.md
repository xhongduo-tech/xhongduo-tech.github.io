# 起重机械作业与指挥（特种设备作业）

起重机司机(Q2)与起重指挥(Q1)是法定持证的特种设备作业岗位，本专题以《特种设备作业人员监督管理办法》、TSG Z6001《特种设备作业人员考核规则》与 GB 5082《起重吊运指挥信号》为纲，系统建立从法规持证、机械原理到指挥信号、吊运实务的完整作业知识体系，是考取证书与安全上岗的必修内容。

## 对标教材

- 《特种设备作业人员监督管理办法》
- TSG Z6001《特种设备作业人员考核规则》
- GB 5082《起重吊运指挥信号》
