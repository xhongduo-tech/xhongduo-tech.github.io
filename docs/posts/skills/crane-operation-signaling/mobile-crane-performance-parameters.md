## 为什么从流动式起重机的性能参数开始

塔吊「长在」工地上，流动式起重机则「跟着工程走」：汽车吊一天之内可能从市政抢修转场到设备安装，履带吊则常驻大型吊装现场。它的核心特征是一个词——**机动**。机动带来了灵活性，也带来了独有的风险：支腿伸不伸、地基硬不硬、特性曲线怎么读，每一样都直接决定这台机器今天能不能安全地把活干完。<span class="marginnote">流动式起重机是起重事故中「整机倾覆」概率最高的机型——因为它没有塔吊那样的固定基础，整机的稳定全靠支腿与地基临时构建。读懂性能参数，就是读懂这台机器的安全边界。</span>这一课讲清结构与那本最重要的「说明书」——起重特性表。

## 1 流动式起重机的结构组成

**流动式起重机（mobile crane）**：可整体转场、自带动力行驶的臂架型起重机。典型机型有**汽车起重机**（汽车吊）、**全地面起重机**、**履带起重机**、**随车起重机**（随车吊）。结构上分三大部分：

**底盘**：承载与行走部分。汽车吊用汽车底盘，行驶与吊装共用一套动力；履带吊用履带底盘，接地比压小、可带载行走但转场需板车。<span class="marginnote">底盘是「行驶系统」与「吊装系统」的分界：行驶状态由底盘司机驾驶（一般需驾驶证），吊装状态由上车操作。汽车吊行驶时吊臂必须收拢、吊钩固定，超限行驶或吊臂未收是常见违章。</span>

**上车（回转部分）**：安装在底盘转台之上的部分，包括发动机、起升机构、变幅机构、回转机构、伸缩臂与司机室。上车可绕转台 360° 回转。

**吊臂**：流动式起重机多用**箱形伸缩臂**——多节臂套叠，靠伸缩机构逐节伸出，长度与幅度可调。吊臂材料为高强度结构钢，是整机最贵的部件之一。

**支腿系统**：作业前伸出、把整机从车轮/履带上撑起的支承装置，常见**H 型支腿**（水平外伸 + 垂直油缸）与**X 型支腿**。支腿伸出后，支腿盘（垫板）与地面接触，整机重量经支腿传到地基。<span class="marginnote">支腿是流动式起重机的「第二条命」：作业时四个支腿必须完全伸出并可靠支承，垫板面积要足够大、地面要平整坚实。支腿未全伸、垫板下陷、地基松软，是流动式起重机倾覆的三大土壤。</span>

## 2 起重特性表：流动式起重机的「安全圣经」

固定式起重机起重量相对固定，流动式起重机则不同——同一台 50 t 汽车吊，在幅度 3 m 时可能能吊 50 t，在幅度 14 m 时也许只能吊 5 t。**额定起重量随工况变化**，这个变化关系记录在厂家的**起重特性表（load chart）**中。

**起重特性表**：以表格或曲线的形式，列出在不同**臂长、幅度、支腿状态、回转方位、有无配重**组合下的额定起重量。<span class="marginnote">特性表常贴在司机室或随车手册中，形式有两种：表格（按臂长×幅度交叉查值）与曲线图（如前图）。侧方与后方作业的额定起重量通常高于前方（司机室方向），吊重行走一般另有独立表格。</span>读表要抓四个要素：

- **臂长**：吊臂伸出的长度，臂越长、自重越大、剩余起吊能力越小；
- **幅度**：吊物到回转中心的水平距离，幅度越大越危险；
- **支腿状态**：全伸 / 半伸 / 不打支腿，三种状态对应三套不同的额定值；
- **回转方位**：侧方、后方、前方各方位额定值不同，表中常分栏列出。

![流动式起重机起重特性曲线示意图](/images/crane-operation-signaling/mobile-crane-performance-parameters-1.svg)

**重点：司机必须按实际工况查表取值，而不是凭「这台车吊多少吨」的印象。** 指挥报出吊物重量与就位半径后，司机的第一件事就是翻特性表核对——查表是流动式起重机司机实操考核的必考动作。

## 3 公式解析：支腿反力与地基承载力

流动式起重机的整机载荷最终压到四个支腿上，再传给地基。判断「这里能不能立车」要算两笔账，用一个简单模型理解：

$$
\sigma = \frac{N}{A} \le [\sigma]
$$

其中 $\sigma$ 为地基实际接触压力（kPa），$N$ 为单支腿的最大压力（kN），$A$ 为支腿垫板的有效支承面积（m²），$[\sigma]$ 为地基容许承载力（kPa）。

三步拆解：

- **第一步，读符号**：$N$ 由整机自重、配重与吊载共同分配产生，最不利支腿（通常是吊载方向对角线的后支腿）承担最大压力；$A$ 是垫板与地面的接触面积——这就是为什么支腿下要垫**钢板或路基箱**，为的是增大 $A$。
- **第二步，看机理**：同样的 $N$，$A$ 越大则 $\sigma$ 越小。垫板从 $0.25\ \text{m}^2$ 换成 $1\ \text{m}^2$，接触压力降到四分之一，地基不易下陷。
- **第三步，得工程结论**：作业前要确认「支腿垫板面积 × 地基承载力 ≥ 支腿压力」。工地上常见的地基隐患是**雨天软化**与**回填土不实**——昨天能立车的硬地，下过一场雨就可能承载不足。雨天、回填区作业，必须重新验算或加铺路基箱。<span class="marginnote">履带起重机因为履带接地面积大、接地比压小，对地基的要求比汽车吊宽松，但也正因接地面积大，「地基下沉」往往整机缓慢倾斜，司机与指挥不易察觉——所以履带吊作业同样要盯地基沉降。</span>

## 4 核心要点对比：汽车吊与履带吊

| 对比维度 | 汽车起重机 | 履带起重机 |
| --- | --- | --- |
| 行走方式 | 汽车底盘行驶 | 履带行走 |
| 转场机动性 | 自行转场，速度快 | 短距自行，远距需板车 |
| 带载行走 | 一般不允许 | 允许（按特性表降额） |
| 接地比压 | 大（支腿集中） | 小（履带分散） |
| 地基要求 | 高，需垫板 | 相对低，但怕沉降 |
| 典型场景 | 市政、抢修、快速转场 | 大型设备、石化、风电吊装 |

这张表是选型的起点：**追求快速机动选汽车吊，追求重载稳定选履带吊**。但无论哪一型，「支腿/履带 + 地基 + 特性表」三角永远是安全的三条腿。

## 5 辨析｜易错点：流动式起重机作业的四个误区

**易错点一：把铭牌上的「最大起重量」当普遍值。** 铭牌标注的往往是「最小幅度、支腿全伸、理想配重」下的极限值。实际作业中绝大多数工况的允许起重量远低于铭牌最大值——特性表才是唯一准绳。

**易错点二：忽视「不打支腿」的降额。** 有些工况（如快速吊小件）不打支腿，仅靠轮胎/悬挂承载，额定起重量通常只有支腿全伸的几分之一。把支腿工况的数值套用到不打支腿作业，是典型的超载。

**易错点三：忘记风与惯性。** 特性表的额定值基于静载假定；吊物摆动、急起急停产生的动载荷与惯性力会瞬间增大支腿压力。「擦着额定值吊」在静态是对的，在动态里就是超载。<span class="marginnote">所以正规吊装作业要求「稳起稳落、斜拉斜吊绝对禁止」——斜拉不仅增大水平分力、让吊物摆荡，还直接破坏支腿反力的分配，是流动式起重机操作的大忌，也是本专题第 4 篇操作要领要展开的内容。</span>

**易错点四：忽略支腿垫板的检查。** 垫板下陷、垫板面积不足、支腿盘未压紧，都要在起吊前处理完。起吊过程中一旦发现支腿下陷或整机倾斜，立即停止起吊、放下吊物。

## 6 术语速查：流动式起重机的性能术语

| 术语 | 含义 | 关键要点 |
| --- | --- | --- |
| 流动式起重机 | 可整体转场的臂架型起重机 | 机动是灵魂 |
| 底盘 | 承载与行走部分 | 行驶与吊装动力 |
| 上车 | 转台之上的回转部分 | 发动机、机构、司机室 |
| 伸缩吊臂 | 多节套叠的箱形臂 | 最贵部件之一 |
| 支腿系统 | 作业前撑起整机的支承 | H 型、X 型 |
| 垫板 | 支腿下的支承垫 | 增大接地面积 |
| 额定起重量 | 规定工况下的允许质量 | 随工况变化 |
| 起重特性表 | 工况→额定值的表格 | 司机查表的准绳 |
| 臂长 | 吊臂伸出长度 | 臂越长能力越小 |
| 幅度 | 吊物到回转中心距离 | 幅度越大越危险 |
| 支腿状态 | 全伸/半伸/不打支腿 | 三套不同额定值 |
| 回转方位 | 侧方/后方/前方 | 各方位额定不同 |
| 接地比压 | 压力/接地面积 | 履带小、支腿大 |
| 带载行走 | 吊着载荷行走 | 按特性表降额 |
| 地基承载力 | [σ] 容许值 | 决定能否立车 |

### 现场口诀速记：流动式操作口诀

- 先查特性表，后算实际重；
- 支腿全伸垫板实，地基不硬不立车；
- 侧方后方能多吊，司机室前方要减载；
- 吊重行走大降额，不看表就超载。

## 7 流动式起重机的作业流程

从立车到收车，流动式起重机司机有一套固定的流程，顺序错了就是风险：

**立车准备**：选择平整坚实的场地，四个支腿完全伸出，垫板（钢板或路基箱）面积足够、支腿盘压紧；测量支腿对角线水平，确认整机水平。地形复杂时先勘察地基，雨天、回填区重新验算承载力。<span class="marginnote">「支腿水平」不是细节：整机倾斜会让吊载的重力产生水平分量，吊物一离地就朝低侧滑移。正规车上有水平仪，立车时看它调到居中，是司机的基本功。</span>

**工况确认**：根据吊装任务查特性表，确认该臂长、幅度、支腿状态下的额定起重量；指挥报出吊物重量与就位半径后，司机复核是否在曲线下方。查表-复核-起吊，一步都不能省。

**试吊与作业**：先试吊离地 100—200 mm，确认吊物水平、支腿无下陷、整机稳定，再正式起吊；作业中匀速、平稳，禁止斜拉斜吊与急起急停。

**收车归位**：吊臂缩回、吊钩固定、支腿收起，检查有无漏油、异常磨损。收车不是结束，是为下一班把状态归零。

这套流程的每一环，最终都指向两个数字——**特性表里的额定值**与**地基的承载力**。记住它们，就记住了流动式起重机安全的一半。

## 8 小结

- 流动式起重机结构 = **底盘 + 上车（回转部分）+ 伸缩吊臂 + 支腿系统**，机动是它的灵魂。
- 额定起重量**随臂长、幅度、支腿状态、回转方位变化**，唯一准绳是厂家的**起重特性表**。
- 读表四要素：**臂长、幅度、支腿状态、回转方位**；司机查表是实操考核必考动作。
- 核心公式 **$\sigma = N/A \le [\sigma]$**：地基接触压力 = 支腿压力/垫板面积，须不大于地基容许承载力。
- 作业流程四步：**立车准备、工况确认、试吊作业、收车归位**，顺序错了就是风险。
- 危险之源两处：**特性表额定值**与**地基承载力**；斜拉斜吊、支腿未全伸、垫板下陷，是倾覆的三大土壤。
