## 为什么从分类清点开始

上一节立住了全屋整理的总纲：按类别整理，顺序是衣物、书籍、文件、小物、纪念品。这一节要回答总纲里的第一个实操问题：**每一类物品，具体怎么清、怎么点？**

分类清点是整个整理流程的「数据采集阶段」。它不解决去留——那是下一步的事。它只做两件事：**把同类物品找全，把总量点清楚**。

这个阶段之所以值得单独一章，是因为它决定了后续所有判断的质量：数据不全，判断必偏；数据清晰，判断自然顺畅。<span class="marginnote">在「从极限到大模型」的语境里，分类清点就是<strong>建立物品的「全量索引」</strong>——没有索引的检索是灾难，没有清点的整理同样是灾难。</span>

## 1 清点的核心：让总量可见

清点的意义用一个例子就能讲透。

假设你要处理「袜子」这个子类。如果只在抽屉里看到十来双，你会觉得「袜子不多，都留下吧」。但当你把玄关、床底、旅行袋、洗衣机旁的袜子全部搜出来摊开，才发现一共 43 双——其中 20 双不成对、15 双有破洞。

**清点改变了判断的前提。** 面对「10 双」你无从取舍，面对「43 双」你自然知道该清理一半。这就是「总量可见」的力量：决策的前提是完整的数据，而不是模糊的印象。

清点还带来一个副产品——**建立物品清单**。整理一次之后，你对「家里有多少东西、分别在哪」有了全局认识，这种认识本身就是极简生活最珍贵的资产：它让你对「再买一件」的边际成本格外敏感。

## 2 衣物的清点

衣物是数量最大、最需要细分的一类。按近藤的方法，先分成几个子类，再逐一清点：

| 子类 | 清点要点 |
| --- | --- |
| 上衣 | 短袖、长袖、外套、卫衣分开数 |
| 下装 | 裤、裙分别数，注意季节 |
| 内衣袜子 | 容易藏在角落，重点搜索床头、旅行包 |
| 鞋 | 鞋柜、玄关、阳台都要算 |
| 包袋 | 通勤包、双肩包、购物袋都算 |
| 配饰 | 围巾、帽子、腰带、首饰 |

清点衣物的关键动作是**全部摊开**：把衣橱、抽屉、收纳箱、衣架上的所有衣物集中到床上或地面。<span class="marginnote">近藤要求「让衣服堆成一座小山」——<strong>看到小山，你才会被总量的体积震撼，判断才会从「都挺好」转向「太多了」</strong>。视觉冲击是整理的心理催化剂。</span>

衣物的细分还有一个目的：为后续「竖式收纳」做准备——同一子类的衣物折叠后放在同一个抽屉或区域，竖放才能实现「一目了然、随取随归」。

## 3 书籍的清点

书籍是第二类，判断标准比衣物更理性：书的价值在于「内容是否还会被需要」，而不在「装帧好不好看」。

清点时按用途分四堆：

1. **常读**：最近一年翻过、正在读、计划再读的。
2. **工具参考**：字典、手册、专业资料——即使不常读，也有「查阅价值」。
3. **待读**：买来未读、想读但一直没读的——这一堆最危险，是「收藏而未读」的重灾区。
4. **已读完不再需要**：读过、不会再读、也不打算引用的一—这一堆可以直接流转。

判断「待读」堆的关键问题是：**「如果明天搬家，你会把这本书一起搬走吗？」** 不会搬走的书，就是不会读的书——诚实面对这一点，能省下大量「藏书量」。<span class="marginnote">很多人把「拥有书」当作「读过书」的替代品——心理学里叫<strong>「收藏幻觉」</strong>：收藏行为本身提供了「我正在成长」的虚假满足。书的价值在使用，不在拥有。</span>

## 4 文件的清点

文件的判断规则最简单，也最容易拖沓——因为「万一以后要用」的恐惧在文件上最强。

清点前先明确一个事实：**90% 的文件，丢掉后永远不会再找它。** 真正需要长期保存的，只有极少数契约、证件与凭证。

文件分成三堆处理：

**需要长期保存**：合同、房产证件、保险单、学历证书——数量极少，放进固定的「文件保险夹」。
**需要处理**：待缴账单、待办表格、待回复函件——设一个「待办托盘」，处理完即归档或丢弃。
- **可以丢弃**：过期说明书、贺卡、旧杂志、广告单——直接进回收。

文件处理有一句口诀：**「存不存，看凭证价值；留不留，看是否有原件。」** 很多文件（说明书、票据）在数字时代都有电子版，确认可在线获取后，纸版就可以安心放手。

## 5 小物的清点

小物是五大类中最庞杂的一类——它其实是「除前四类之外所有物品」的总和。清点的诀窍是**继续按功能细分**：

| 功能子类 | 典型物品 |
| --- | --- |
| 电器数码 | 充电线、耳机、旧手机、电池 |
| 工具 | 螺丝刀、锤子、胶带、备用零件 |
| 文具 | 笔、本子、便签、订书机 |
| 日用品 | 雨伞、保温杯、旅行洗漱包 |
| 药品 | 常备药、保健品、过期药 |
| 化妆品护肤 | 口红、面霜、囤货、小样 |
| 季节用品 | 风扇、暖炉、节日装饰 |

每个子类清点完，都会发现惊人的冗余：八根充电线、十二支笔、五把雨伞、三瓶只用了十分之一的沐浴露。

小物的去留判断要双轨并用：工具电器走「实用主义」（最近用不用），化妆品走「保质期 + 心动的叠加」。特别注意**过期药品与过期化妆品**——它们不只是「该扔」，而是「必须扔」，留着有害健康。

## 6 纪念品的清点

纪念品是压轴的类别，也是情感浓度最高的一类。照片、礼物、旅行纪念品、孩子的画——每一件都连着一段回忆，清点起来最费力。

近藤的处理原则是：**纪念品不是「要不要扔」，而是「怎么留存最有价值」。**

- 实体的礼物与摆设：只留「看到它会心生温暖」的，数量控制在一处展示。
- 孩子的手工作品：拍照数字化，实体只保留最有代表性的一两件。
- 旅行纪念品：优先留「能融入生活」的（一件实用的当地器具），而非「只能积灰」的（冰箱贴、纪念币）。
- 照片与书信：整理成册或数字化，让回忆有归处，而不是散落各处。

纪念品清点的关键心理建设是：**回忆存在于你心里，不依附于物件。** 扔掉一张船票，并没有扔掉那次旅行——你记得它，它就是你的一部分。<span class="marginnote">这正是「离」的功课：<strong>放手物品，不等于放手回忆</strong>。想通了这一点，纪念品的清点就不再是「割舍」，而是「重新安放」。</span>

## 7 核心对比表：五大类的清点要点

无公式主题，用一张表汇总五大类的清点策略：

| 类别 | 细分方式 | 清点关键动作 | 主要风险 |
| --- | --- | --- | --- |
| 衣物 | 按穿着部位 | 全部摊开成山 | 数量冲击大，容易累 |
| 书籍 | 按用途 | 问「搬家会带走吗」 | 收藏幻觉 |
| 文件 | 按保存价值 | 三堆分类 | 「万一有用」恐惧 |
| 小物 | 按功能 | 逐子类清点 | 数量庞大、耗时 |
| 纪念品 | 按情感价值 | 问「看到会温暖吗」 | 什么都舍不得 |

五大类的清点顺序与难度，和上一节的整理顺序完全一致：从最客观到最主观。清点到纪念品时，你的判断力已经被前四类训练成熟——这就是顺序设计的意义。

## 8 小结

- 分类清点的作用是**让总量可见**：决策的前提是完整数据，而非模糊印象。
- 清点建立**物品清单**：对家的全局认识，是极简生活最珍贵的资产。
- 衣物按部位细分、书籍按用途分四堆、文件按保存价值分三堆、小物按功能继续细分、纪念品按情感价值处理。
- 文件的口诀：**「存不存，看凭证价值；留不留，看是否有原件。」**
- 纪念品的心理建设：**回忆存在于心里，不依附于物件。**
- 清点顺序从最客观到最主观，判断力在过程中逐步成长。
