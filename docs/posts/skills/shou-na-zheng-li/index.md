# 家庭收纳整理与极简生活

家庭收纳整理与极简生活是让居家空间回归清爽、让生活减负增效的实用学问，系统覆盖断舍离理念、怦然心动整理法、空间规划与分品类收纳实践，并延伸至极简主义生活方式的养成。学完这些章节，就掌握了从整理心法、收纳方法到习惯维持的完整体系，能让家的每个角落有序、舒适且可持续。
