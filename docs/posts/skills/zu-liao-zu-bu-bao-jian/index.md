# 足疗与足部保健

足疗与足部保健是以足部反射区刺激和足部按摩手法为核心的保健养生技艺，融合中医经络学说与现代反射区理论，系统覆盖足部解剖、反射区定位、按摩手法与常见病症调理。学完这些章节，就掌握了从足部结构认知、反射区找位到手法操作与日常保健护理的完整足疗知识体系。
