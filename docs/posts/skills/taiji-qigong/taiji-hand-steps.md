## 为什么从手型与步型开始

上一节我们立住了太极拳的「世界观」——阴阳虚实。但要真正动起来，身体得先有最基本的零件。手型与步型就是太极拳的**字母表**：全部套路都只是这些字母按不同顺序拼成的句子。<span class="marginnote">就像大模型里的 token 是模型的最小处理单元，手型与步型是拳架的最小单元——先把它们练标准，后面几十个式子才不会走样。</span>这一节我们把最常见的三种手型、五种步型和四种步法逐一拆开。

手型与步型看似只是几个「零件」，却是判断一个人会不会太极拳的第一道门槛。动作做没做对，第一眼往往就看手脚——架子散不散、重心稳不稳，全都写在手脚上。

把一套拳比作一门语言：手型步型是「词法」，身法是「句法」，套路是「篇章」。词法都含混，后面读什么都会出歧义。这也是为什么段位制教程把基本技术放在所有套路之前。

所以这一节虽然「零件」多、略显枯燥，却务必耐下心，一个零件一个零件地校。你现在的每一个弓步、每一个虚步，都会在后面的 24 式里被反复调用。

## 1 手型：掌、拳、勾

太极拳的手型以**掌**为最多，另有**拳**与**勾**两种辅助手型。

**太极掌**：五指自然舒展分开，虎口撑圆，掌心微含呈凹形，腕部自然下坐，称为「坐腕」。杨式掌形舒展，陈式掌形则四指微拢、掌根突出，称为「瓦棱掌」。掌是太极拳运用最广的手型，掤、捋、挤、按、推、采都由掌变化而来。<span class="marginnote">「坐腕」不是僵硬的折腕，而是让腕、掌、指之间保持松而通的弧度，劲才能从肘贯到指尖——这与「松而不懈」的总原则一致。</span>

**太极拳**：四指并拢卷曲，拇指扣压在食指与中指的中节上，拳面要平整，拳心要虚握如握鸡蛋，称「空心拳」或「虚拳」。太极拳的拳不追求死握，讲究「拳宜松不宜紧」，发劲时才在接触瞬间一紧即松。

**勾手**：五指撮拢，屈腕下垂，勾尖朝下，状如鸟喙。勾手常用于「单鞭」「斜飞势」等动作，配合另一手的推掌形成「一收一放」的对比。

| 手型 | 要点 | 常见动作 |
| --- | --- | --- |
| 掌 | 五指舒展、坐腕、虎口撑圆 | 掤、捋、挤、按、推 |
| 拳 | 虚握、拳面平整、拇指扣压 | 搬拦捶、掩手肱捶 |
| 勾 | 五指撮拢、屈腕下垂 | 单鞭、斜飞势 |

## 2 步型：弓、虚、马、仆、独立

步型决定重心与身体框架。太极拳五大基本步型各有分工。

**弓步**：前腿屈膝成弓、后腿自然伸直成箭，故又称「弓步」或「弓箭步」。前脚脚尖朝前，后脚脚尖外展约 45 度，两脚横向相距一脚宽。重心约七分在前脚、三分在后脚——这是「虚中有实」的基础。野马分鬃、搂膝拗步、揽雀尾等多数动作都以弓步成形。

**虚步**：一脚全脚着地支撑，另一脚脚尖点地、脚跟虚提，身体重心大部分在支撑腿。白鹤亮翅、手挥琵琶、高探马都以虚步收势。<span class="marginnote">「虚步」之「虚」，正是太极拳「虚实分明」最直白的体现：点地的脚可随时提起进招，是进退转换的蓄势状态。</span>

**马步**：两脚左右开立，间距约为本人脚长的三倍，屈膝半蹲，重心落于两腿之间，膝盖不越过脚尖。马步是陈式太极拳的常见步型，也是站桩的基本架子。

**仆步**：一腿全蹲，另一腿向侧方伸直平铺，脚尖内扣。常用于「下势」「蛇身下势」等低位动作，是太极拳少有的低架。

**独立步**：一腿支撑微屈，另一腿屈膝提起，膝高于胯。用于「蹬脚」「金鸡独立」等，考验单腿平衡能力。

| 步型 | 重心分配 | 代表动作 |
| --- | --- | --- |
| 弓步 | 前实后虚，约七三 | 野马分鬃、揽雀尾 |
| 虚步 | 前虚后实 | 白鹤亮翅、高探马 |
| 马步 | 居中，五五 | 陈式金刚捣碓 |
| 仆步 | 全蹲腿为实 | 下势 |
| 独立步 | 单腿全实 | 右蹬脚 |

## 3 步法：进步、退步、跟步、摆扣步

**步型**是静止的架子，**步法**是移动的方式。太极拳强调「迈步如猫行」——落步轻灵、如猫蹑足，不许砸脚出响。

**进步**：以野马分鬃为例，前脚先轻轻迈出，脚跟先着地，随重心前移过渡到全脚掌，后脚顺势蹬地。落脚要「由脚跟到脚尖」地滚动，才能保持中正。

**退步**：倒卷肱是退步的典型。后脚先向后撤、脚尖先着地，再落实全脚掌。退步时视线不丢，身体仍保持朝前，重心缓缓后移。

**跟步**：前脚进步后，后脚紧随前脚靠拢或跟进半步。揽雀尾「挤」之前、穿梭之前都有跟步，作用是「借地发力」。

**摆步与扣步**：转身动作靠脚的碾转完成。脚尖向外摆称「摆步」，脚尖向内扣称「扣步」，如「转身搬拦捶」「十字手」的转身。<span class="marginnote">碾步时脚掌微微旋转、脚跟或脚尖为轴，膝盖必须随之转向同一方向，否则容易扭伤膝关节——这是初学最易出错、也最该慢练的一环。</span>

## 4 劲力解析：形于手指的那条链

《太极拳论》说「其根在脚，发于腿，主宰于腰，形于手指」，这不是比喻，而是劲力传导的真实路径。把它写成一条链：

$$\text{脚底} \xrightarrow{\text{蹬地}} \text{踝、膝} \xrightarrow{\text{伸蹬}} \text{胯} \xrightarrow{\text{松转}} \text{腰脊} \xrightarrow{\text{主宰}} \text{肩} \xrightarrow{\text{沉坠}} \text{肘} \xrightarrow{\text{垂} \rightarrow \text{松}} \text{腕、掌、指}$$

**第一步，脚底为根**：劲从后脚蹬地开始，脚掌与地面接触的支撑力，是一切动作的能量来源。弓步中后腿蹬地，就是这条链的起点。

**第二步，腰为主宰**：蹬地的反作用力经胯传入腰脊，靠腰的旋转把力「拧」向躯干。腰不松、不转，力就会在胯部断掉，变成只有手臂在动。

**第三步，形于手指**：力经肩（沉）、肘（坠）到达腕、掌、指。肩不沉则力浮于上，肘不坠则力散于旁。整条链每一环都「松而通」，劲才完整。

**核心要点**：这条链告诉我们，太极拳的「手劲」其实来自脚与腰。练手型练的只是「形」，真正的力要由步型（脚）与身法（腰）提供——这也是为什么下一节必须讲身法。

## 5 手型步型常见错误与速查

**错误一：弓步两脚前后成一条直线**。正确做法是两脚保持约一脚宽的横向距离，前后脚错开，支撑面才宽，重心才稳。两脚一条线练久了，不仅不稳，还容易在转体时扭伤踝膝。

**错误二：虚步重心前移**。虚步的精髓是「前虚后实」——前脚只点地、不承重，重心牢牢坐在后腿上。很多人把虚步站成了「半弓步」，前脚偷偷吃了力，虚实就没分清。

**错误三：勾手撮指过紧**。勾手要「虚撮」，五指撮拢但不僵，手腕下垂而松。把它撮成拳头，单鞭的味道就全没了。

**错误四：退步时脚跟先着地**。倒卷肱等退步式子要求脚尖先着地，随重心后移再落全脚掌。脚跟先着地会重心跟不上、容易后仰，也是退步最常见的伤膝动作。

除了纠错，还要明白手型与步型的「用意」：坐腕立掌是为了劲达指尖，弓步后蹬是为了力从脚起。形是意的载体，把意想清楚，形自然就正了。

手型步型还与身高、体型有关：个子高、步子可以略大，个子矮则步幅收小；不必强求与教程里的示范架式一模一样，重要的是「三线」——膝尖与脚尖同向、两脚横向有距、重心落在支撑面内。

左右差异也值得注意：多数人习惯右手右脚发力，左式往往比右式差一截。练手型步型时要有意多练弱侧，把左右练平衡，后面套路才不会「偏科」。

步型之间还有一个隐藏的功课——**转换**。弓步转虚步、虚步转弓步，靠的是后腿的屈伸与前脚掌的碾转，转换练顺了，整套拳才连贯。初学者可单练「弓虚转换」各二十次。

最后说一句：手型步型与健身气功的站姿道理相通——都要求立身中正、重心稳定。学完太极拳再学健身气功时，你会发现自己已经在用同一套「形体语言」。

段位制一段的考核里，手型步型占了很大比重——方向、角度、重心分配都要经得起检查。把这一节的表格当自查清单，练一个查一个，是最实在的进阶路径。

| 术语 | 含义 |
| --- | --- |
| 弓步 | 前腿弓、后腿蹬，前实后虚约七三开 |
| 虚步 | 前脚点地不承重，重心在后腿 |
| 马步 | 两脚开立屈膝，重心居中 |
| 仆步 | 一腿全蹲一腿伸直铺地 |
| 独立步 | 单腿支撑、一腿提起 |
| 坐腕 | 腕部下坐、掌根微沉 |
| 拗步 | 手脚异侧配合的步法 |
| 顺步 | 同侧手脚配合的步法 |

进阶练习可以这样做：每天站桩前，先做一组「定式检查」——把弓步、虚步、马步、仆步、独立步五种步型各站十秒，用上面表格逐项核对；再做一组「步法转换」，弓虚转换、进步退步各十次。每次五分钟，坚持一个月，下盘会有明显变化。

下一节的身法、桩功与松静，正是在这些手型步型之上展开的。手脚的架子立住了，躯干才有立足之地。

## 6 小结

- **手型**以掌为主，拳要虚握、勾要撮拢，核心是「松而不懈」。
- **步型**五种：弓、虚、马、仆、独立，各有重心分配与代表动作。
- **步法**讲究「迈步如猫行」，进步脚跟先着地、退步脚尖先着地。
- **劲力**由脚起、经腰、达手指，手型只是这条链的最后一环。
