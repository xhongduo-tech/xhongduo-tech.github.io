# 太极拳与健身气功

以国家体育总局武术研究院《中国武术段位制教程》（杨式/陈式太极拳）为纲，结合《简化太极拳24式》与健身气功功法（八段锦、五禽戏、易筋经、六字诀），系统重建从太极拳源流、基本功、套路演练到健身气功养生实践的中式身心锻炼体系，兼具体育健身与中医养生双重价值。学完这些章节，就写完了太极拳与健身气功的全部内容。

## 对标教材

- 《中国武术段位制教程·杨式太极拳》（国家体育总局武术研究院）
- 《中国武术段位制教程·陈式太极拳》（国家体育总局武术研究院）
- 《简化太极拳24式》（人民体育出版社）
- 《健身气功·八段锦》《健身气功·五禽戏》（国家体育总局健身气功管理中心）
