## 为什么从咨询开始

从这一节起，我们真正进入操作。但第一课不是拿镊子，而是**开口说话**。美睫师与顾客之间的第一道工序是**嫁接前咨询**：搞清楚顾客想要什么、她的眼睛适合什么、她的原生睫毛能承载什么。咨询做得好的美睫师，能一次成交、长期复购；咨询潦草的美睫师，即使手法娴熟，也会频繁踩中「做完才发现不是想要的效果」的售后雷区。<span class="marginnote">美睫是「结果不可逆预览」的服务：嫁接后 3–4 周才能改款。因此咨询不是走流程，而是用一次对话，把「顾客脑中的想象」翻译成「睫毛上的现实」——翻译错了，后面所有手法都白做。</span>

## 1 咨询的目标：四个「对齐」

一次合格的嫁接前咨询，要完成四个对齐：

**需求对齐**：顾客想要什么效果？「自然」「浓密」「上镜」「放大眼睛」这些词，在美睫师耳中必须翻译成具体的长度、卷翘与密度。方法是拿图片说话——让顾客在款式图中指认，比听形容词可靠得多。<span class="marginnote">「我想要的自然」在不同顾客心里是完全不同的东西：有人指 8 号长度的素颜感，有人指 11 号长度但排列稀疏的自然。最有效的对齐工具是<strong>款式参考图</strong>，让顾客指图，而不是让顾客描述。</span>

**眼型对齐**：顾客想要的效果，与她的眼型是否兼容？垂眼配 C 卷可提神，垂眼配平直 J 卷可能更显疲惫。美睫师要能预判「顾客想要的」与「顾客适合的」之间的落差，并用专业语言说明取舍。

**睫毛条件对齐**：原生睫毛的状态决定承载上限。太稀疏、太细弱、处于休止期比例高的睫毛，撑不起浓密款——如实告知，是上一节职业道德「不夸大原则」的落地。

**卫生安全对齐**：禁忌排查、过敏史、近期眼部手术、眼部疾病，在咨询阶段一次问清，并记录存档。

## 2 眼型分析：读懂眼睛的「骨架」

**眼型（eye shape）**：由眼眶骨、眼睑皮肤、脂肪与内眦赘皮的形态共同决定的眼部轮廓特征。常见眼型及分析如下：

**杏仁眼（almond eye）**：眼裂适中，内外眼角圆润，上下眼睑弧线匀称。**万能眼型**，多数款式都适配，可大胆发挥。
**圆眼（round eye）**：眼裂偏圆，上下眼睑暴露度大。适合拉长眼尾的款式，视觉上把圆眼「压」成杏仁。
- **丹凤眼（almond upturned）**：眼尾略上扬、内眼角略低，带古典气质。适合眼尾加长的猫眼式排布，强化上扬感。
- **下垂眼（downturned eye）**：眼尾低于眼头，眼神显无辜也易显疲惫。适合眼头短、眼中起、眼尾略抬的「提拉式」排布，用眼尾的卷翘向上「提」。
- **上扬眼 / 吊眼（upturned eye）**：眼尾上扬明显。适合弱化眼尾、均衡处理，避免过度拉长让眼神显凌厉。
- **肿泡眼（puffy eye）**：上睑脂肪厚，睫毛被「压」得下垂。适合用 D 型或 L 型卷翘度，从根部把睫毛「撑」起来。
- **单眼皮 / 内双（monolid / hooded eye）**：睑缘褶皱覆盖睫毛根部。适合卷翘度高、根部直立的款式，避开过长的睫毛以免被眼皮「吃掉」。<span class="marginnote">眼型分析的目的不是给顾客贴标签，而是找「提神的关键点」：下垂眼的关键在眼尾上提，肿泡眼的关键在根部卷翘，内双的关键在避开褶皱遮挡。每一类眼型，都有一个最划算的着力点。</span>

## 3 原生睫毛评估：承载力的体检

眼型决定「往哪做」，原生睫毛决定「能做多重」。评估分四步：

**数量与密度**：估算单眼可用睫毛根数。稀疏（&lt;60 根）宜自然款，中等（60–90 根）宜标准款，浓密（&gt;90 根）可做浓密或开花款。
**长度与粗细**：原生睫毛越粗越长，承载力越强，可选更长的假睫毛与更粗的规格；反之宜选细而短的规格。
- **卷翘方向**：原生睫毛向下垂、平直还是上翘？下垂的睫毛需用更卷的假睫毛「借力」。
- **健康状态**：观察是否有分叉、稀疏、炎症、缺睫斑。发现炎症或异常脱落，建议先就医，不急于嫁接。<span class="marginnote">「拨动测试」在咨询时即可顺手完成：轻拨一根睫毛，根部发白、一拨就掉的多为休止期睫毛，这类睫毛应避开不接；需用力才动、根部色深的处于生长期，是理想的嫁接对象。</span>

## 4 核心要点对比表：眼型 × 推荐设计

| 眼型 | 推荐卷翘度 | 推荐排布 | 设计要点 |
| --- | --- | --- | --- |
| 杏仁眼 | C 型 | 扇形（眼头短→眼中长→眼尾过渡） | 万能，按需求选密度 |
| 圆眼 | C/D 型 | 眼尾加长拉长 | 视觉拉长眼裂 |
| 丹凤眼 | C 型 | 眼尾加强猫眼式 | 强化上扬古典感 |
| 下垂眼 | C/D 型 | 眼头短、眼尾上提 | 用卷翘「提拉」眼尾 |
| 上扬眼 | B/C 型 | 整体均衡、弱化眼尾 | 收敛凌厉感 |
| 肿泡眼 | D/L 型 | 根部直立、全长均匀 | 从根部撑起眼皮 |
| 单眼皮/内双 | D/L 型 | 卷翘优先、长度保守 | 避开褶皱遮挡 |

**辨析｜易错点：** 新手容易把「顾客想要的」直接当方案，忽略眼型适配。例如肿泡眼顾客坚持要「超自然 J 卷」，结果睫毛被眼皮压得完全看不见——这不是顾客错了，而是美睫师没有完成眼型对齐。正确做法是**先满足需求、再优化适配**：保留顾客想要的效果方向，同时给出能达成的卷翘与长度，并说明取舍原因。<span class="marginnote">这句话是咨询的万能句式：「你想要的自然效果，我们可以这样实现——长度选到 10，但卷翘用 D 型把眼皮撑开，视觉上会更清透，而且不会塌。」既尊重需求，又用专业补上盲区。</span>

## 5 咨询到方案的落地流程

把咨询收束成一份可执行的方案，标准流程是五步：

1. **倾听记录**：记录顾客关键词与参考图偏好。
2. **眼型与睫毛评估**：完成第 2、3 节的检查，记下眼型结论与原生睫毛状态。
3. **方案提案**：给出「卷翘度 + 长度范围 + 密度 + 款型」的组合，附一句设计理由。
4. **确认与告知**：确认款式，同时告知固位时长（约 3–4 周）、自然脱落规律、护理要点与安全风险。
5. **存档预约**：记录本次方案与顾客反应，作为下次补睫与改款的基线。

方案一旦确认，就进入下一节要学的「建材」选择——**假睫毛材质与卷翘度选择**。

### 咨询实战：一份「万能咨询脚本」的拆解

新手不知道咨询从何问起时，可以套用下面这份脚本骨架，再根据现场微调：

- **开场（建立信任）**：「您好，今天想做什么感觉的？先别急，我先看看你的眼型和睫毛条件，再给你建议。」——先看再建议，体现专业，而不是一上来就推销。
- **需求探询（用图对焦）**：「你平时是通勤多还是拍照多？我给你看几个款式图，你指一下比较接近你想要的感觉。」——把「自然/浓密」这类词换成「指图」，一句话压缩歧义。
- **条件评估（专业诊断）**：「你的眼型偏圆，眼尾可以稍微拉长一点；睫毛条件不错，够密，做中间款效果会很好。」——先给一句诊断结论，再给方案方向，顾客会觉得「你懂她」。
- **方案提案（给出参数）**：「我建议 10 号长度、C 卷、单眼 80 根，扇形排布，眼睛会放大但不会太夸张。你看可以吗？」——具体到数字，让顾客有「被定制」的感觉。
- **边界告知（管理预期）**：「嫁接能放大和加密，但不能让单眼皮变双眼皮；效果一般维持 3～4 周，2～3 周来补一次最佳。」——诚实设边界，减少售后。
- **收尾闭环（复述 + 预约）**：「所以今天是自然偏浓的中间款，10 号 C 卷 80 根，全程约 90 分钟。我们 2 周后提醒你来补，那时候效果最好。」——复述确认 + 预约埋点。

**脚本的价值**：它不限制你的发挥，而是给新手一根「不会漏项」的拐杖。熟练之后，你会发现咨询其实是一个「倾听 → 诊断 → 提案 → 确认」的循环，脚本只是把这个循环的骨架固定下来，让每一次咨询都稳定地高质量。

### 补充：眼型分析中容易混淆的「两组概念」

眼型分析有几个概念容易混淆，理清它们能避免方案偏差：

- **「圆眼」与「杏仁眼」不能只靠「圆不圆」判断**。圆眼的特征是眼裂高度与宽度接近、上下眼睑暴露度大；杏仁眼是外眼角略高、内眼角略低、眼裂呈杏仁形。判断方法：从正面看眼裂整体轮廓的「长宽比」——接近 1:1 偏圆，大于 1:1 偏杏仁。误判会导致拉长或收尾方向的方案错误。
- **「下垂眼」与「肿泡眼」不是一回事**。下垂眼是「眼尾位置低于眼头」，是轮廓形态问题；肿泡眼是「上睑脂肪厚、压住睫毛」，是容积与支撑问题。前者靠「眼尾上提」的排布解决，后者靠「根部卷翘」的选材解决。把两者混为一谈，方案会「提错了地方」。

**概念辨析的实用价值**：眼型判断错了，方案跟着错——给肿泡眼下「眼尾加长」的处方，解决不了「根部被压」的问题；给下垂眼下「整体加卷」的处方，也提不起眼尾。美睫师对眼型的判断力，直接决定方案的针对性。**多花一分钟把眼型看准，能省下后面几十分钟的返工**。

### 补充：眼型评估的「四步观察法」

眼型分析不必复杂，按四步观察，就能快速建立对顾客眼型的判断：

- **第一步 · 看轮廓**：从正面看眼裂整体形状——长宽比接近 1:1 偏圆，大于 1:1 偏杏仁；眼头眼尾的高低关系判断上扬或下垂。轮廓决定排布的「大方向」。
- **第二步 · 看褶皱**：观察双眼皮/单眼皮/内双的褶皱形态，判断睫毛根部是否被褶皱遮挡——被遮挡则需要更高卷翘度「撑开」。褶皱决定卷翘度的「下限」。
- **第三步 · 看脂肪**：观察上睑是否有浮肿感、脂肪厚度——肿泡眼需要根部直立（D/L 卷）撑开眼皮。脂肪决定「要不要用卷翘破局」。
- **第四步 · 看睫毛**：最后看原生睫毛本身——数量、粗细、卷向、健康。条件决定「承载上限」，也是选材的直接依据。

**四步观察的顺序逻辑**：先看「型」（轮廓），再看「盖」（褶皱），再看「压」（脂肪），最后看「根」（睫毛）——从宏观到微观，一步不漏。练成这套顺序，面对任何顾客都能快速、系统地完成眼型评估。

## 6 小结

- 咨询的本质是**四个对齐**：需求、眼型、睫毛条件、卫生安全。
- 眼型分析找「提神关键点」：下垂眼提眼尾、肿泡眼提根部、内双避褶皱。
- 原生睫毛评估看**数量、粗细、卷向、健康**四要素，决定承载上限。
- 用款式参考图替代形容词沟通，用「尊重需求 + 专业取舍」化解落差。
- 咨询落地为五步流程，并**存档作为补睫基线**。
