# 演讲与口才

演讲与口才是职场汇报、学术展示与人际沟通中的核心软技能。以《演讲的艺术》《金字塔原理》与《影响力》为纲，系统重建从演讲准备、内容组织、舞台表达到说服影响与即兴发言的完整能力体系。学完这些章节，就写完了从克服怯场、搭建清晰结构到掌控舞台、随机应变的全部内容。

## 对标教材

- 《演讲的艺术》（史蒂芬·E. 卢卡斯）
- 《金字塔原理》（芭芭拉·明托）
- 《影响力》（罗伯特·西奥迪尼）
