# 选题与演讲目标设定

## 为什么从选题开始

上一篇走完了第一次演讲的全流程，其中第一步「选话题」被我们轻轻带过。这一篇停下来把它做扎实：**你讲什么，决定了后面一切环节的天花板。** 卢卡斯在《演讲的艺术》第5章里说，选对题目，演讲成功一半；题目没选对，再好的结构、再稳的表达都是在给一座歪楼装修。<span class="marginnote">卢卡斯总结新手选题的三大通病：<strong>题目太大</strong>（「我想讲中国历史」）、<strong>题目太空</strong>（「我想讲环保」）、<strong>题目太自私</strong>（「我想讲我为什么喜欢这个专业」）。三者本质相同——选题时心里只有「我想讲」，没有「听众能带走什么」。</span>

选题的表面问题是「讲什么」，底层问题是「**这次演讲要完成什么改变**」。所以这一篇其实在讲两件事：**怎么选题目**，以及**怎么把题目翻译成一个清晰的目标**——具体目的与中心思想。

## 1 选题的来源：你熟悉的，才讲得动

卢卡斯给出的选题原则朴素而有力：**选择一个你熟悉且感兴趣的话题，再把它缩小到与时间、听众匹配的规模。**

怎么找到这样的题目？用「双盘点」头脑风暴：

**盘点一：个人盘点（personal inventory）**。把自己拆成清单逐项扫描——专业、爱好、经历、观点、难忘的事、熟悉的人。每个清单项都是一个潜在题目：「我做 IT 运维」「我跑马拉松」「我在三线城市创业」……题目就藏在你自己的库存里。

**盘点二：资讯盘点（clustering）**。从一个词出发，往外联想三层，把联想词画成一棵树：写「AI」→ 联想到「大模型」「GPU」「算力」→ 再联想到「国产芯片」「功耗」「训练成本」。树上的每个节点，都可能是一个好题目。<span class="marginnote">聚类法（clustering）本质是一种发散→聚焦的结构化过程：先不加评判地联想，把可能的题目铺开；再按「我熟不熟、听众要不要」两个筛子过滤。这与后面第 10 篇《金字塔的三种子结构》里的「MECE 分解」思路同源——发散要全，收敛要准。</span>

**筛选标准只有两条：我熟不熟（讲得动），听众要不要（值得听）。** 两个都满足 → 好题目；只满足一个 → 换一个或改造它。

## 2 缩小题目：把「想讲」压成「讲得完」

新手最常犯的错是题目过大：「我要讲人工智能。」——3 分钟、10 分钟、甚至 1 小时都讲不完「人工智能」。卢卡斯的方法是把大题目**向下缩小**，直到它匹配你的时间预算：

> 人工智能 → 大模型 → 大模型为什么需要那么多显卡 → **「训练一次大模型要烧掉多少电」**

三条缩小路径，可以组合使用：

**限定范围**：把「人工智能」限定到「大模型」，再限定到「训练成本」。
**限定角度**：不讲「是什么」，讲「一个被忽略的侧面」（成本、伦理、就业）。
- **限定听众**：同一个题目，给程序员讲与给中学生讲，是两篇不同的演讲。

**一个实用的标尺：题目里能放下一句话观点，才够小。** 如果题目大到你找不到一句话能概括的观点，它就没缩到位。<span class="marginnote">「一句话观点」标尺在后面的《金字塔原理》里会升级成「中心思想必须是能用一句话说清楚的命题」。题目是容器，观点是内容——容器必须小到装得下、端得起。</span>

## 3 一般目的 → 具体目的 → 中心思想

选好题目后，卢卡斯给出一条层层收紧的「目标链」，这是第5章的核心骨架：

**第一层，一般目的（general purpose）**：这场演讲要「信息、说服、还是娱乐」？三选一。第一篇已经讲过——一次演讲只有一个主目的。

**第二层，具体目的（specific purpose）**：把一般目的翻译成一句完整的陈述句，说明「讲完听众会怎样」。格式是「**让听众** + 动词 + 内容」：

> 一般目的：告知
> 具体目的：**让听众知道，训练一个大模型需要付出多少电力成本。**

**第三层，中心思想（central idea / thesis）**：整场演讲的一句话说辞，是「我要让听众带走的那句话」：

> 中心思想：**「大模型的智能，是以巨大的能源为代价换来的。」**

具体目的与中心思想的差别很微妙但关键：**具体目的是给你的（指引你组织内容），中心思想是给听众的（他们带走的话）。**<span class="marginnote">打个比方：具体目的是「我要把这桌菜端上桌」（厨师的目标），中心思想是「这桌菜是川菜——麻辣鲜香」（客人的记忆点）。目标句约束你的工作，中心句定义听众的收获。</span>

## 4 核心对比表：好目标句与坏目标句

本专题纯技能主题，用核心对比表替代公式解析。卢卡斯给具体目的句定了五条准则，整理成对照表：

| 准则 | 坏例子 | 好例子 |
| --- | --- | --- |
| 用完整陈述句 | 「大模型耗电」 | 「让听众知道大模型训练的成本构成」 |
| 不用疑问句 | 「大模型到底耗多少电？」 | 同上（疑问句不指导内容组织） |
| 避免模糊抽象 | 「谈谈能源问题」 | 「让听众比较训练与推理的耗电差异」 |
| 只讲一个思想 | 「讲大模型耗电和未来趋势」 | 「只讲训练阶段的耗电」 |
| 别与中心思想混淆 | 目标是观点而非任务 | 目标是「让听众知道……」而非「大模型耗电……」 |

**辨析｜易错点：** 最容易混的是**「只讲一个思想」**。一次演讲的**目的**只能有一个（一件事），但支撑它的**论点**可以有三四个（多件事）。「目的是让听众理解 A、B、C 三个概念」——这其实是三个目的，等于没有目的。正确写法：**目的是一个动词短语，论点是它的展开。** 「让听众理解『大模型为什么耗电』」是一个目的；「耗电来自数据、算力、电费」是支撑它的三个论点。

## 5 从题目到一句话：选题的检验清单

最后把选题阶段可交付的成果定成四件，写清楚即选题完成：

**话题（topic）**：缩小后的题目——「大模型训练的成本」。
**一般目的**：信息 / 说服 / 娱乐——「告知」。
- **具体目的**：给「让听众……」句——「让听众知道训练大模型的真实电力成本」。
- **中心思想**：给「听众带走的一句话」——「大模型的智能，以巨大的能源为代价」。

这四件写下来，选题阶段才算完成。**没有把题目翻译成「让听众……」句之前，不要开始组织材料**——因为材料组织必须服务于目标，目标模糊，材料必然散乱。<span class="marginnote">这条「先定目标再选材」的顺序，也贯穿写作领域：第 5 篇《选题与目标》讲的是「任务定义」，后面《资料收集与支持材料》讲的是「按任务取料」。先有订单，再进货——顺序反了，货就白进。</span>

这一篇的收获：**题目来自你的库存，缩小到装得下一句话观点；目标链层层收紧——一般目的三选一、具体目的一句话、中心思想另一句话；四件套写齐，选题才算完。** 下一篇，把视角从「我讲什么」转向「讲给谁听」——**听众分析，是所有演讲准备的起点与终点。**

## 6 术语速查表

把选题阶段的四件套与目标链术语收进速查表：

| 术语 | 含义 | 使用要点 |
| --- | --- | --- |
| 话题（topic） | 缩小后、具体可讲的题目 | 小到放得下一句话观点 |
| 一般目的（general purpose） | 信息 / 说服 / 娱乐，三选一 | 一场演讲只有一个主目的 |
| 具体目的（specific purpose） | 「让听众……（动词+内容）」句 | 是给你的，指引内容组织 |
| 中心思想（central idea） | 听众带走的那句话 | 是给听众的，定义收获 |
| 目标链 | 一般目的→具体目的→中心思想 | 层层收紧，先定目标再选材 |
| 个人盘点 | 扫描自己的专业、经历、兴趣 | 题目藏在你的库存里 |
| 资讯聚类（clustering） | 从一个词向外联想成树 | 发散要全，收敛要准 |
| 限定范围 | 把大题目往下缩小 | 人工智能→大模型→训练成本 |
| 限定角度 | 只讲一个侧面 | 不讲「是什么」，讲「被忽略的」 |
| 限定听众 | 按听众层次换讲法 | 给程序员与给中学生是两篇演讲 |
| 一句话观点标尺 | 题目里能否放下一个观点 | 放不下就是没缩到位 |
| 目标句五准则 | 完整句、非问句、不模糊、单目的、非中心句 | 写完全部目标句再核对一遍 |

## 7 小结

- 选题原则：**选你熟悉且感兴趣的题目，再缩小到与时间、听众匹配**。
- 双盘点：**个人盘点 + 资讯聚类**，从自己的库存里长题目。
- 缩小三路径：**限定范围、限定角度、限定听众**；题目要小到放得下一句话观点。
- 目标链三层：**一般目的（三选一）→ 具体目的（让听众……句）→ 中心思想（听众带走的话）**。
- 目标句五准则：完整陈述、不用疑问、避免模糊、只讲一个思想、不与中心思想混淆。

下一篇进入听众的视角：**听众分析**——他们的兴趣、态度、知识水平如何决定你选题、取材与表达的全部策略。
