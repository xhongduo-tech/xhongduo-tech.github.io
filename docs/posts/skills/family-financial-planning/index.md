# 家庭理财规划与资产配置

以 AFP《金融理财原理》、中国银行业协会《个人理财》与证监会《证券期货投资者适当性管理办法》为纲，系统重建从家庭记账预算、财务比率分析、投资工具与资产配置，到风险管理保险、退休税务规划与适当性合规的完整家庭理财体系。学完这些章节，就掌握了从家庭财务诊断到综合理财规划落地的全过程。

## 对标教材

- AFP《金融理财原理》
- 中国银行业协会《个人理财》
- 证监会《证券期货投资者适当性管理办法》
