## 为什么从静水竞赛规则开始

上一节的总则讲的是「通用的法律」，这一节落到静水竞速（canoe sprint）的**具体程序**：比什么项目、怎么晋级、怎么起航、什么算犯规、终点怎么判。静水比赛的规则精度以「零点几秒、半个船头」为刻度——一次抢航、一次越道、一次触碰，都可能改写名次。读懂这些细节，你既能看懂直播里的每一次判罚，也能在自己参赛时「不踩雷」。

## 1 竞赛项目：船型、距离与分组

静水竞速的比赛项目由**船型 × 距离 × 组别**三维组合决定：

- **船型**：皮艇 **K1、K2、K4**（单人、双人、四人皮艇），划艇 **C1、C2**（单人、双人划艇）；男女项目基本对称。
- **距离**：**200 米、500 米、1000 米**为奥运与世锦赛常用距离，另有 **5000 米**长距离（世锦赛项目）。
- **组别**：成年、U23、青少年，男女分开。

<span class="marginnote">船型代号的快速记忆：<strong>K = kayak（皮艇），C = canoe（划艇），数字 = 人数</strong>。K4 是四人皮艇、C2 是双人划艇——看字母与数字，一眼就知道是哪个项目。艇型与距离的组合决定了战术，例如 200 米 K1 拼起航爆发，1000 米 K2 更看重配速配合。</span>

**换项限制**：一名运动员在同一赛事中**可兼报多个项目**，但受赛事日程与体力限制，实际报名以组委会公布的限项为准；兼项选手需注意项目之间间隔，避免体力透支。

## 2 赛制与晋级：预赛、半决赛、决赛

静水比赛的赛制是**多轮淘汰制**：报名艇数多时，先打**预赛（heats）**，再经**半决赛（semifinals）**，最后进入**决赛（finals）**。

**预赛**：按报名数分组进行，小组**前几名直接晋级半决赛或决赛**，其余进入**复赛（repechage）**争取递补。
**复赛（repechage）**：给预赛失利的艇一次「复活」机会，复赛前几名晋级半决赛——这是静水赛制的特点，避免「预赛分到死亡之组就出局」。
**半决赛/决赛**：最终决出决赛 A 组（1–9 名）与 B 组（10–18 名）等，A 组决出奖牌。<span class="marginnote">理解赛制的钥匙：<strong>预赛只是「初筛」，复赛是「保底」</strong>。预赛不必全力，保住晋级名额即可；真正要拼的是半决赛与决赛。很多老将预赛「收着划」，到决赛才亮真章——赛制给了战术留力的空间。</span>

**航道分配**：各轮次的航道由抽签或按前一轮成绩确定——通常成绩好的艇分在**中央航道**（中间航道风浪小、视野好），成绩靠后的艇分在两侧。中央航道在静水比赛中常被视为「优势道」。

## 3 起航程序：从点名到出发

静水起航有一套严格的程序，核心是**公平**与**同步**：

1. **点名**：各艇在出发浮台就位，裁判点名确认。
2. **预备**：发令员确认所有艇对齐后，给出预备信号（如举旗/语音「Attention」）。
3. **出发**：发令枪响（或电子出发信号），所有艇同时离台。<span class="marginnote">起航的判罚关键在<strong>「静止」</strong>：规则要求出发信号前艇必须是静止的（由浮台固定或运动员稳住）。如果在信号前就开始移动或脱手，即构成<strong>抢航（false start）</strong>——抢航者被召回重赛，严重者二次抢航直接取消资格。</span>

**召回（recall）**：发令员若判断出发不齐（抢航、系统故障），会立即**召回**所有艇回到起点重新出发。运动员听到召回信号应立即减速回台，不得「将错就错」划完。

## 4 途中与冲刺的犯规判罚

静水途中与冲刺的判罚，主要集中在**航道纪律**：

**越道（crossing lanes）**：运动员须**在自己的航道内**划行。艇的任何部分越过航道分界线、且**干扰了邻道选手**，即构成犯规；若越道但未干扰他人，通常判警告。
**故意干扰（interference）**：故意挤靠、阻挡、别住邻道艇，属严重犯规，可判**取消资格**。
**触碰浮标**：触碰航道浮标一般判警告（浮标是分界标志，碰浮标往往意味着越道倾向）；故意踢浮标借力则判犯规。
- **终点冲刺干扰**：冲刺阶段撞向邻道艇、或冲线后急转影响他人，同样受罚。<span class="marginnote">判罚的「干扰判定」核心：<strong>是否影响了对手的成绩</strong>。规则不罚「碰」本身，罚的是「碰带来的影响」——所以无干扰越道是警告，有干扰越道是犯规。这个「影响论」贯穿所有水上项目，是读判罚的通用逻辑。</span>

## 5 终点判定与并列

静水比赛的终点以**艇头（船头球/艇首）越过终点线**为判定依据：

**判定设备**：现代赛事用**终点摄影（photo finish）**捕捉艇头过线的瞬间，精确到千分之一秒。
**过线次序**：按艇头过线顺序排列名次；艇身是否完全过线不影响判定，**只看艇头**。
**并列（dead heat）**：两艇艇头几乎同时过线、摄影无法分辨先后时，判**并列**——并列的艇共享该名次（如并列第一则并列金牌）。
- **成绩修正**：比赛中因被干扰而影响成绩的选手，可依申诉程序申请**重赛或成绩修正**（见第19节总则）。

## 6 核心要点：静水判罚速查

| 情形 | 判罚 | 备注 |
| --- | --- | --- |
| 出发信号前移动 | 抢航，召回重赛 | 二次抢航取消资格 |
| 越道且干扰邻道 | 犯规，可能取消资格 | 看「是否影响对手」 |
| 越道但未干扰 | 警告 | 判罚较轻 |
| 故意挤靠/阻挡 | 取消资格 | 严重犯规 |
| 触碰航道浮标 | 警告 | 通常伴随越道倾向 |
| 冲刺撞向邻道 | 犯规 | 按干扰论处 |
| 艇头并列过线 | 判并列 | 共享名次 |
| 赛后艇重不达标 | 成绩无效 | 复检环节 |

## 7 典型判例解读

规则条文是抽象的，判例才是「活的规则」。读懂几个典型判例，就能把握判罚的「手感」。

**判例一：终点前的越道**。两艇在冲刺阶段靠得太近，A 艇艇头压过 B 艇航道分界线、但立即回到本道，未发生碰撞。判罚：**警告**——因为「越道但未干扰」，裁判按「影响论」判定未影响 B 艇成绩。若 A 艇的越道让 B 艇被迫减速或改变线路，则判**犯规**。

**判例二：起航抢航后的争议**。发令枪响瞬间，A 艇艇头轻微前移，发令员判定抢航召回全部艇；A 艇辩称是「浪动非人为」。判罚：**以发令员的电子记录为准**——现代发令系统有起航监控，人为主观判断让位于客观记录，这是规则演进的方向。

**判例三：赛道被邻艇浪涌影响**。C 艇沿边道划行，被邻道 D 艇的尾浪掀乱节奏，C 艇赛后申诉。判罚：**依据干扰程度裁决**——若 D 艇的浪涌构成明显干扰且影响 C 艇成绩，可能判 C 艇重赛或成绩修正；若属正常航道范围内的浪涌，则申诉不成立。

**判例四：赛后器材复检不合格**。某艇以第二名完赛，赛后称重发现艇重低于最低标准。判罚：**成绩取消**，名次顺延——器材合规是「全程义务」，赛前合格不代表赛后豁免。

<span class="marginnote">四个判例的共同逻辑：<strong>判罚永远看「是否影响了对手或比赛公平」</strong>——抢航破坏起航公平、越道干扰破坏航道公平、器材不达标破坏竞赛公平。理解了这把「公平之尺」，任何判例你都能自己先判断一遍，再看裁判怎么判。</span>

## 8 本节自测

**自测一：项目三维度**。静水比赛项目由哪三个维度组合而成？答案：**船型（K/C + 人数）× 距离 × 组别**——例如「女子 K1 500 米」就是一组完整定义；K 是皮艇、C 是划艇，数字是人数。

**自测二：赛制结构**。静水多轮淘汰制的晋级路径是什么？复赛（repechage）的作用是什么？答案：**预赛 → 复赛（repechage）→ 半决赛 → 决赛**；复赛给预赛失利的艇一次「复活」机会，避免「分到死亡之组就出局」。

**自测三：起航判罚**。出发信号前艇就移动，怎么判？答案：**抢航（false start）**——召回全部艇重新出发；同一艇**二次抢航取消资格**。

**自测四：越道与干扰**。越道但未干扰邻道选手怎么判？越道且干扰呢？答案：**越道未干扰 → 警告**；**越道且干扰邻道 → 犯规，可能取消资格**——判罚核心是「是否影响了对手成绩」，这叫「干扰影响论」。

<span class="marginnote">静水规则自测的观赛应用：看比赛时<strong>边看边自己判</strong>——「这一桨越道了，判警告还是犯规？」「这个起航算不算抢航？」——自己先判，再看裁判怎么判，规则敏感度提升最快。</span>


**延伸思考：**规则书会更新，但「干扰影响论」这条主线不会变——**判断一次碰撞、越道、抢航，先问「它影响了谁的公平」**。带着这条主线读任何判罚，你都能先于裁判预判结果。

## 9 小结

- 静水项目 = **船型（K/C + 人数）× 距离（200/500/1000/5000m）× 组别**。
- 赛制为多轮淘汰：**预赛 → 复赛（repechage）→ 半决赛 → 决赛**；预赛留力、决赛亮剑。
- 起航程序：**点名 → 预备 → 出发**；信号前移动即抢航，召回重赛。
- 途中判罚核心是**航道纪律与「干扰影响」论**：越道未必犯规，干扰邻道才犯规。
- 终点只看**艇头过线**；终点摄影判定，并列共享名次。
- 赛后复检：艇重不达标，成绩无效。
