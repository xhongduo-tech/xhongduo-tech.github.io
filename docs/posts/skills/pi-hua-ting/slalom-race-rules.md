## 为什么从激流规则开始

如果说静水规则考的是「直线上的公平」，那么激流回旋（canoe slalom）规则考的是**「白水里的精确」**：一道门怎么算「通过」、碰杆算几分、漏门算几分、方向错怎么判——每一个细节都以「厘米」与「零点几秒」为刻度。激流比赛的成绩是「用时 + 罚分」的复合结果，看懂罚分体系，才能真正看懂比分牌。这一节把激流回旋的规则与裁判执法讲透。

## 1 赛道与门：规格与通过定义

**赛道（course）**：200–400 米的白水段，设 **18–25 道门**。每道门由两根悬垂的门杆组成，杆色标示通过方向：

- **顺流门（绿杆）**：必须**顺着水流方向**穿过。
- **逆流门（红杆）**：必须**逆着水流方向**穿过。

**「通过」的精确定义**是激流规则的核心：**艇首、艇尾与运动员的头部必须完整通过两根门杆之间的门线**，且穿过方向符合杆色规定。<span class="marginnote">「通过」的三个要件：<strong>艇首、艇尾、头</strong>，缺一不可——只过了一半、或人过了而艇尾留在门外，都不算通过。裁判盯的就是这三个点在门线上「完整出现」的瞬间。这就是为什么激流运动员过门要「整船钻过去」，而不是「擦着杆把身子送过去」。</span>

**门的顺序**：门有编号，运动员须**按顺序**通过；跳号（漏过前一道门）即使后来补过，也按漏门处理。

## 2 比赛流程：试划、出发与两轮赛制

激流回旋的比赛流程有它自己的节奏：

**赛前试划（course familiarization / inspection）**：比赛前运动员可**步行沿赛道熟悉**，记住每道门的颜色、顺序与水流结构；正式比赛前通常还有一次**试划（practice run）**机会，但不计入成绩。
**出发方式**：激流是**逐一计时出发**（interval start）——运动员按顺序逐个出发，间隔约数十秒，不争抢同一赛道，因此没有静水那种「抢航」问题，重点是**准点出发**（错过出发时间按弃权）。
**两轮赛制**：正式比赛通常进行**两轮**，**取两轮中的最好成绩**作为最终成绩；若两轮均完成，取快的一轮排名。罚分加在对应轮次的用时上。<span class="marginnote">「取最好一轮」是激流赛制的关键：第一轮可以<strong>保守求稳</strong>（确保有个保底成绩），第二轮再<strong>放手一搏</strong>（冲更快、赌更少的罚分）。这个「一轮保底、一轮冲刺」的策略，是看懂激流比赛排名的钥匙。</span>

## 3 罚分体系：触门、漏门与方向错误

激流回旋的罚分只有三种额度，简单而残酷：

**触门罚 2 秒**：船体、桨、人或身体任何部位**碰到门杆**，罚 2 秒。
**漏门罚 50 秒**：未按定义「通过」一道门（未完整穿过、跳过门、方向错误），罚 50 秒。
**方向错误按漏门计**：穿过方向与杆色要求相反（顺流门逆穿、逆流门顺穿），按漏门罚 50 秒。

<span class="marginnote">为什么漏门罚 50 秒？因为「漏门」意味着赛道设计被破坏——50 秒远大于任何一次失误的用时，等于「这一轮出局」。所以激流运动员宁可<strong>擦杆而过</strong>（2 秒）也绝不<strong>绕门</strong>（50 秒）——擦杆是「战术代价」，漏门是「战略灾难」。</span>

**罚分的判定**：碰杆与否由**门裁判（gate judge）**在门边观察判定；现代赛事普遍辅以**视频回放**，碰杆瞬间帧帧可查，争议判罚可提交仲裁复核。

## 4 裁判执法：门裁判、视频与申诉

激流回旋的裁判体系层级分明：

**门裁判（gate judge）**：每道门（或每几道门）设一名门裁判，负责记录本门的**触门与通过**情况，当场上报主裁判。
**主裁判/总裁判（chief judge）**：汇总各门记录、核对出发与计时，裁定最终罚分。
**计时**：电子计时系统记录起终点时间，罚分直接累加到用时上。
- **视频回放**：终点区设摄影点，对争议判罚（尤其是**是否漏门、是否反向穿门**）进行回放复核；仲裁委员会（jury）依据视频作出终局裁决。<span class="marginnote">裁判执法的现代趋势：<strong>「人眼判定 + 视频复核」双保险</strong>——门裁判第一时间报判，仲裁用视频复核争议。运动员若对判罚不服，按总则申诉程序（限时书面申诉 + 保证金）提交仲裁，仲裁决定即为终局。</span>

**器材与安全**：激流回旋强制佩戴**头盔**，船体须符合最低重量与尺寸规定；激流艇的浮力（艇内浮力装置）须保证翻船后仍能浮起，这是安全底线条款。

## 5 核心要点：激流罚分速查

| 情形 | 罚分 | 判定依据 |
| --- | --- | --- |
| 触门（碰杆） | 罚 2 秒 | 门裁判目测 + 视频 |
| 漏门（未完整通过） | 罚 50 秒 | 艇首/艇尾/头三要件 |
| 方向错误（逆穿/顺穿颠倒） | 罚 50 秒 | 按漏门计 |
| 跳号（不按顺序） | 罚 50 秒 | 按漏门计 |
| 未佩戴头盔 | 取消资格/禁止出发 | 安全条款 |
| 抢时出发 | 按弃权处理 | 点名未到 |

## 6 激流竞赛装备与参赛实务

看懂规则之后，还要解决「怎么在激流赛场上合规参赛」。激流竞赛装备与参赛实务有几条与静水明显不同的点：

**装备合规**：激流回旋对器材有专属规定——**头盔强制佩戴**（并须通过赛事安检）、**船体符合最低重量与尺寸**、**救生衣（PFD）为强制装备**（激流赛中不可脱下）。此外，**桨叶尺寸**受项目规定约束——激流桨比静水桨更短更宽，便于在湍流中快速翻转；用错桨型会被判器材不合规。

**参赛流程**：激流运动员的参赛流程比静水更「个人化」——**赛前试划（inspection）**是关键环节：步行沿赛道记门、选线；出发前按序号到检录区报到，**逐一计时出发**，错过出发时间即弃权。

**罚分策略**：理解「触门 2 秒、漏门 50 秒」后，还要会算**战术账**——比赛中若因体力不支可能漏门，宁可**放慢速度、稳住穿门**（多花 2–3 秒）也不冒险绕门；但若已确定漏了一道门（50 秒），剩下的比赛重点是**保住其他门不碰杆**，避免「漏门 + 触门」双重损失。

**成绩构成**：最终成绩 = **用时 + 罚分**。看懂比分牌：两名选手用时相近时，**罚分更少者胜**——所以激流比赛「求稳」常常比「求快」更重要，这是它区别于静水竞速的核心观赛点。

<span class="marginnote">激流参赛的「三提前」：<strong>提前试划、提前检录、提前算账</strong>——试划选线、检录保资格、算账定策略。激流比赛容错率低，这三件「提前」能帮你把不确定性降到最低——剩下的，就交给技术。</span>

## 7 本节自测

**自测一：「通过」三要件**。激流比赛中，一道门怎么才算「通过」？答案：**艇首、艇尾、运动员头部**三者必须完整穿过两根门杆之间的门线，且方向符合杆色规定——三者缺一，即按漏门处理。

**自测二：罚分体系**。触门、漏门、方向错误各罚多少？答案：**触门 2 秒、漏门 50 秒、方向错误按漏门（50 秒）**——所以「宁可擦杆而过、绝不绕门」。

**自测三：两轮赛制**。激流回旋通常比两轮，最终成绩怎么算？答案：**取两轮中的最好成绩**——第一轮可保守求稳保底，第二轮放手一搏冲更快。

**自测四：强制装备**。激流回旋竞赛强制佩戴的两件装备是什么？答案：**头盔**与**救生衣（PFD）**——头盔防撞、PFD 保浮，是白水赛道的安全底线，缺失即禁止出发。

<span class="marginnote">激流规则自测的观赛应用：看一场激流回旋直播，<strong>每道门自行判断「过 or 漏」并估算罚分</strong>，再对照官方成绩——几场比赛下来，你对罚分体系的敏感度会远超普通观众。</span>


**延伸思考：**激流规则的判罚争议，近年来越来越多靠**视频回放**解决——碰杆的瞬间、艇尾是否过线、穿门方向，都能逐帧判定。对运动员来说，这意味着「争议空间」变小了：与其抱怨判罚，不如把每次触杆当作技术信号——**触杆的位置（上杆/下杆）能告诉你入水角度偏在哪**。另一个趋势是**极限激流（extreme slalom）**的兴起——多艇同场对抗、红绿门混合，判罚与对抗规则更复杂，但观赏性极强。规则在变，但「艇首、艇尾、头过门线」这条铁律不变。

| 触门 | 罚 2 秒 | 门裁判 + 视频 |
| 漏门 | 罚 50 秒 | 三要件缺一 |

## 8 小结

- 激流赛道 200–400 米、18–25 道门；**绿杆顺流、红杆逆流**。
- 「通过」= **艇首、艇尾、头**完整穿过门线且方向正确。
- 罚分三档：**触门 2 秒、漏门 50 秒、方向错误按漏门**；擦杆是战术、漏门是灾难。
- 赛制：**逐一计时出发、两轮取最好成绩**；一轮保底、一轮冲刺。
- 裁判体系：**门裁判 + 主裁判 + 视频回放 + 仲裁**；申诉按总则程序终局裁决。
- 安全底线：**强制头盔**、艇体浮力合规。
