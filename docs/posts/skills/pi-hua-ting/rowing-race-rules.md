## 为什么从赛艇规则开始

赛艇的规则体系由**世界赛艇联合会（World Rowing，原 FISA）**制定，管辖 2000 米航道上的全部程序。与皮划艇静水相比，赛艇规则有几个独特之处：**起航桩静止出发、裁判乘摩托艇全程跟随、对「碰撞」的判罚极其细化**。读懂赛艇规则，是看懂一场 8+ 比赛的必备能力——尤其是起航的「抢航」判定与途中的「干扰」处理，这两处是赛艇判罚争议的高发区。

## 1 竞赛项目与航道

**竞赛项目**：赛艇奥运项目以**单桨（2-、4-、8+）与双桨（1x、2x、4x）**船型为主，另有轻量级（lightweight）项目（近年逐步退出奥运）。比赛距离**标准为 2000 米**。

**航道**：国际赛道通常 **6–8 条航道**，每条宽约 12.5–13.5 米，以浮球串分隔；航道按 1–8 编号，**1 号道通常靠裁判塔一侧**。<span class="marginnote">与皮划艇不同，赛艇的航道并非「哪条都一样」——受风向与水流影响，<strong>不同航道在顶风/侧风下有微小差异</strong>；中央航道一般被视为较优道。分组时种子艇通常分在中央，这是「种子制度」的规则化体现。</span>

## 2 起航规则：静止出发与抢航

赛艇采用**静止出发（standing start）**，起航程序比皮划艇更严苛：

1. **排齐**：各艇船尾由起航桩的绳索固定，**对准各自航道**；**排齐裁判（aligner）**在塔上确认所有艇船头在一条线上。
2. **预备**：排齐后发令员给出语音「**Attention**」（各艇预备）。
3. **出发**：确认静止后，发令员按发令系统给出出发信号（扬声器/灯光），缆绳同步松开。

**抢航（false start）**：出发信号前**任何部分越出起航线**（艇头提前过线）即构成抢航。处理规则：

**第一次抢航**：召回全部艇，重新排齐出发；
**同一艇第二次抢航**：**取消该艇资格**（皮划艇静水同样适用，但赛艇执行更严格）；<span class="marginnote">赛艇起航还有两个细节规则：一是<strong>「后溜」（roll-back）</strong>——预备时船尾向后倒退，若影响排齐会被判警告；二是<strong>起航后</strong>若发令员认定出发不齐（系统故障、风浪所致），会在数桨内<strong>召回</strong>重赛。记住：起航判罚问的是「艇头是否提前越线」，与运动员的主观意图无关。</span>
**故障召回**：起航装置故障或比赛被干扰时，裁判可召回重赛。

## 3 途中规则：航道纪律与干扰

赛艇途中规则的**核心词是「干扰（interference）」**：

**航道纪律**：各艇须在自己的航道内划行；**船体任何部分不得进入邻道**。
- **干扰判罚**：若一艇**越入邻道并干扰了对手**（碰撞、阻挡、浪涌冲击），裁判（乘艇跟随的**裁判员/umpire**）可判：
  - **警告（warning）**：对轻微、非故意的越道；
  - **取消资格（exclusion）**：对故意干扰或严重犯规；
  - **补偿判罚（compensation）**：若干扰明显影响了被干扰艇的成绩，裁判可判**被干扰艇晋级或重赛（re-row）**——这是赛艇规则的独特之处：**受害方获得救济，而非只惩罚加害方**。<span class="marginnote">「补偿判罚」是赛艇规则最有人情味的一笔：它不问「谁撞了谁」，而问「被撞的人是否因此输了比赛」。如果一艇因干扰掉速却未获补偿，规则就失去了「公平」的意义。读赛艇判罚，永远先找「受害方是否得到救济」。</span>
**浪涌（wash）**：赛艇高速划过会在两侧产生**尾浪**；跟在侧后方的艇若被浪掀乱节奏，可向裁判申诉——「被洗浪」也是干扰的一种形态。

## 4 终点判定与成绩

**终点判定**：以**艇头（船头球位置）越过终点线**为判定依据，与皮划艇相同；终点摄影用于精确判读并列。
- **成绩记录**：比赛成绩以电子计时为准，**风况（风速/风向）会被记录**——顺风超强时的成绩可能不被认可为纪录（认证纪录对风速有上限要求）。
- **并列与重赛**：并列名次共享；因干扰导致成绩异常时，可经仲裁判**重赛**（在指定时间重划一次）。

## 5 裁判执法体系

赛艇比赛的裁判分工细密，各有专属职责：

| 裁判角色 | 职责 |
| --- | --- |
| 发令员 Starter | 排齐确认、发出起航信号 |
| 排齐裁判 Aligner | 在塔上确认各艇船头对齐 |
| 航道裁判 Umpire | 乘艇跟随比赛，判罚途中犯规 |
| 终点裁判 Finish judge | 判定艇头过线次序 |
| 主裁判 Chief umpire | 总览全场、裁决争议 |
| 仲裁委员会 Jury | 处理申诉、终局裁决 |

<span class="marginnote">赛艇执法的「移动性」是它区别于皮划艇的特点：<strong>裁判不是坐在岸边，而是乘裁判艇跟在比赛船队侧后方</strong>，贴近观察每一桨的航道位置。所以赛艇比赛结束后常常看到裁判艇与运动员「并驾齐驱」——那是 umpire 在记录全程。</span>

**申诉**：对判罚不服按规则程序提交书面申诉（限时 + 保证金），由仲裁委员会依据裁判报告与视频回放作出终局裁决。

## 6 核心要点：赛艇判罚速查

| 情形 | 判罚 | 备注 |
| --- | --- | --- |
| 出发信号前艇头越线 | 抢航，召回重赛 | 同艇两次抢航取消资格 |
| 预备时船尾后溜 | 警告 | 影响排齐时判罚 |
| 越道且干扰对手 | 取消资格/补偿判罚 | 看是否影响成绩 |
| 故意碰撞/阻挡 | 取消资格 | 严重犯规 |
| 浪涌干扰他艇 | 可判补偿 | 受害方获救济 |
| 艇头并列过线 | 判并列 | 共享名次 |
| 风速超标 | 成绩不认证纪录 | 纪录条款 |
| 赛后艇重/船头球不达标 | 取消成绩 | 技术检查 |

## 7 规则实战解读

把规则条文放进真实比赛场景，能更清楚地把握判罚逻辑。三个高频场景值得提前「预习」：

**场景一：起航的「抢航」争议**。发令前 A 艇船头微微前移、又迅速收回，B 艇认为应判抢航。解读：抢航以**艇头越过起航线**为客观标准，不以「收回」论——只要信号前越线即判抢航；争议由**起航监控系统**记录，主观争论无效。所以起航口令响起前，桨手唯一要做的是**把船彻底稳住**。

**场景二：途中航道偏移**。8+ 比赛中，C 艇在顶风下向邻道偏移半个船身、未碰邻艇，邻艇未受影响。解读：**越道但未干扰**通常只判警告——但注意，赛艇的「干扰」定义很宽，浪涌（wash）冲击邻艇也算干扰，所以「没碰到」不等于「没干扰」。

**场景三：被干扰后的申诉**。D 艇被 E 艇撞到桨、掉速 2 秒，D 艇申诉要求重赛。解读：仲裁会评估——干扰是否真实发生、是否影响了 D 艇成绩；若成立，**可判 D 艇晋级或重赛**（补偿判罚），这正是赛艇「受害方获救济」原则的体现。

<span class="marginnote">三个场景的共同启示：<strong>赛艇判罚看「客观事实 + 成绩影响」，不靠「谁嗓门大」</strong>——起航看监控、航道看裁判记录、干扰看成绩影响。参赛者最聪明的做法是「<strong>用事实说话</strong>」：申诉要提交客观证据（视频、裁判记录），而不是主观描述。</span>

## 8 本节自测

**自测一：起航判定标准**。赛艇的抢航以什么为客观标准？答案：**艇头是否在出发信号前越过起航线**——与主观意图无关；由起航监控系统记录，争议时以客观记录为准。

**自测二：干扰的宽定义**。赛艇的「干扰」为什么不能只理解为「碰撞」？答案：**浪涌（wash）冲击邻艇也算干扰**——高速划行的尾浪可能掀乱邻艇节奏，所以「没碰到」不等于「没干扰」。

**自测三：补偿判罚**。赛艇独有的「补偿判罚」是什么意思？答案：若干扰**明显影响了被干扰艇的成绩**，仲裁可判**被干扰艇晋级或重赛（re-row）**——规则问「受害方是否得到救济」，而非只惩罚加害方。

**自测四：裁判体系**。赛艇的航道裁判（umpire）与皮划艇裁判在执法方式上有什么不同？答案：赛艇 umpire **乘艇跟随比赛**、贴近观察每桨航道位置；皮划艇裁判多在岸边/门边执法——「移动执法」是赛艇执法的特点。

<span class="marginnote">规则自测的观赛应用：看赛艇直播时<strong>数一数赛道边的裁判艇</strong>——它们跟着哪条船、在判什么——把「裁判体系」从书本对应到真实画面，规则就不再是抽象条文。</span>

## 9 小结

- 赛艇规则由 **World Rowing** 制定，2000 米、6–8 航道、静止出发。
- **起航**：排齐 → Attention → 出发；艇头提前越线即抢航，两次抢航取消资格。
- 途中核心是**干扰判罚**：越道未必犯规，干扰影响成绩才犯规；**补偿判罚**让受害方获救济。
- 终点只看**艇头过线**；风速超标不认证纪录。
- 裁判体系分工：**发令员、排齐裁判、航道裁判（乘艇跟随）、终点裁判、主裁判、仲裁**。
- 申诉程序限时提交、仲裁终局。
