# 工程机械操作（挖掘机/装载机等土方机械）

工程机械操作是建筑、矿山、道路等行业的通用核心技能工种，涵盖挖掘机、装载机等土方机械的驾驶、作业与维护保养，是操作工职业技能等级认定的实操型职业通道。以 GB 25684《土方机械 安全》强制性国家标准、挖掘机/装载机驾驶员职业技能等级认定标准和《挖掘机操作与维护》教材为纲，从安全法规、结构原理到分机型操作与维护，系统写完整门操作技能。

## 对标教材

- GB 25684《土方机械 安全》系列强制性国家标准（GB 25684.1 通用要求 等 13 部分）
- 挖掘机/装载机驾驶员职业技能等级认定（土方机械操作工国家职业技能标准）
- 《挖掘机操作与维护》（高职高专机械类教材）
