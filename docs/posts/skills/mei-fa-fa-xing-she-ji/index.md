# 美发与发型设计

美发与发型设计是以剪发、烫染、吹风造型与发型整体设计为核心的一门职业技能学科，涉及毛发生理、工具技法与造型美学的系统结合。以《美发技术》、美发师职业技能标准与《发型设计》为纲，从基础规范、洗发护发、修剪烫染到吹风造型与发型设计，逐步重建完整的美发知识框架。
