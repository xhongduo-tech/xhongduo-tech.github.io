# 汽车维修与故障诊断

面向保有量最大、从业人员最多的汽车服务职业，以《国家职业技能标准—汽车维修工（2018年版）》为纲，对标《汽车故障诊断技术》与《汽车发动机构造与维修》，系统重建从维修基础、发动机底盘检修维护到电气系统与整车综合故障诊断的完整技能体系。学完这些章节，就写完了汽车维修与故障诊断的全部内容。
