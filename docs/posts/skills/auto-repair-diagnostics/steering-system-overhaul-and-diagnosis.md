## 为什么从转向系统开始

底盘「传行转制」的第三项是**转向系统**。它把方向盘的运动转化为车轮的转角，让车辆按驾驶者意图改变方向。转向系统的故障往往有清晰的「手感」——转向沉重、方向盘抖动、异响、跑偏、不回正——每一种手感都指向一类具体病因。<span class="marginnote">《汽车故障诊断技术》第 8 章把转向系统分为「机械转向系统」与「动力转向系统」两大部分。诊断顺序则是先排除轮胎与定位等「非转向」因素，再查转向器、拉杆与助力系统——转向手感的变化常常只是悬架或轮胎问题的投影。</span>

这一篇讲转向系统的组成与类型、转向传动比的计算、液压助力与电动助力的区别，以及常见转向故障的诊断。

## 1 转向系统的组成与类型

转向系统的基本链路是：

**方向盘 → 转向柱 → 转向器 → 转向横拉杆 → 转向节 → 车轮**

**转向器**：把方向盘的旋转运动转换成拉杆的直线（或近似直线）运动，是转向系统的核心减速放大机构。常见形式有齿轮齿条式（乘用车主流，结构简单、路感直接）与循环球式（货车与大车，操纵省力）。
**转向拉杆与转向节**：把转向器的运动传给车轮，包含可调长度的横拉杆（用于调整前束）。<span class="marginnote">转向横拉杆两端各有一个球头（球节），球头磨损是转向「咯噔」异响的常见来源——旷量大了，方向盘会有明显的「自由旷动」间隙。</span>
- **助力系统**：减轻转向力，分液压助力（HPS）与电动助力（EPS）。

## 2 公式解析：转向角传动比

转向器的核心参数是**角传动比 $i$**——方向盘转角 $\theta_{sw}$ 与车轮转角 $\theta_w$ 之比：

$$
i = \frac{\theta_{sw}}{\theta_w}
$$

做三步拆解：

- **第一步，比值含义**：乘用车转向角传动比约 15–20，即方向盘转 15–20°，车轮才转 1°。
- **第二步，为什么需要大传动比**：大传动比让转向「省力且可控」——方向盘小幅转动对应车轮小幅转向，高速行驶时更稳。代价是打满方向盘的圈数多（约 2.5–3.5 圈）。
- **第三步，与助力的关系**：液压/电动助力的本质是「帮你转方向盘」，但**角传动比仍然由转向器机械结构决定**——助力解决的是力，不是角度。

**重点：方向盘「转几圈打满」是固定的机械属性。** 如果方向盘总圈数突然变化、或方向盘不正（车轮直行时方向盘歪），往往指向转向器装配、拉杆长度调整或定位参数变化，而不是助力系统。

## 3 动力转向：液压助力与电动助力

两种主流助力方式，检修思路完全不同：

| 项目 | 液压助力（HPS） | 电动助力（EPS） |
| --- | --- | --- |
| 动力来源 | 发动机带动液压泵 | 电机直接驱动 |
| 转向手感 | 低速轻、高速略沉 | 低速轻、高速沉（程序控制） |
| 液压油 | 需要定期检查更换 | 无 |
| 典型故障 | 助力油泄漏、皮带打滑、泵异响 | 故障码、扭矩传感器、电机 |
| 诊断入口 | 看油位、听泵响 | 读数据流、查故障码 |

**辨析｜易错点：** 液压助力转向沉重，先查**助力油油位与皮带**——油少了或皮带打滑，泵吸不到油或转不动，助力直接消失，转向瞬间变沉。而电动助力转向沉重，先读故障码与数据流（EPS 扭矩请求、电机电流），再考虑扭矩传感器或电机本身——两者表面症状相同，内部逻辑完全不同。<span class="marginnote">EPS 是现代乘用车绝对主流，它还承担两个附加功能：低速轻高速沉的可变助力，以及与车道保持系统联动的主动转向力矩。EPS 转向柱内集成了扭矩传感器，这个传感器的信号错误会直接让助力「时有时无」——偶发转向发沉，优先怀疑它。</span>

## 4 常见转向故障诊断

转向故障按「手感」分类定位：

**转向沉重**：先查轮胎气压与前轮定位（外倾、前束异常会增加回正阻力），再查助力系统（油位、皮带、EPS 数据流），最后查转向器内部。
**转向异响**：原地或低速打方向「咯噔」响 → 转向拉杆球头、下摆臂球头松旷；打方向「吱吱」响 → 助力泵皮带或助力系统；方向盘内「咔咔」响 → 螺旋电缆（气囊游丝）或转向柱。
**方向盘不回正**：四轮定位后倾角不足、转向器内部发卡、转向柱阻力大。<span class="marginnote">「跑偏」与「不回正」常被混淆：跑偏是直线行驶时车自动偏，不回正是打方向后松手方向盘不自动回中。跑偏优先查胎压与定位，不回正优先查后倾角与转向器阻力——先分清症状，再动手。</span>
- **方向盘抖动**：低速打满方向抖动 → 转向泵/助力系统或球头；高速方向盘抖动 → 动平衡或转向节，与转向系统本身关系不大。

**重点：转向故障诊断有一个前置动作——先把「转向本身」与「悬架轮胎」分开。** 同样的「跑偏」，可能是转向拉杆球头松旷，也可能是左右轮胎气压不一致或定位失准。按先轮胎、后定位、再转向器的顺序排查，能避免误拆转向器。

## 5 转向系统的维护要点

转向系统是「手感」系统，维护的重点在于**保持间隙与油液状态**：

**定期检查项目**：
- **转向拉杆球头**：举升后双手上下摇动车轮，检查球头是否松旷；松旷则「咯噔」响、方向盘旷动。
- **防尘套**：球头、转向器防尘套破裂会让灰尘进入、润滑流失，加速磨损——发现破损及时更换。
- **转向油液（HPS）**：检查油位与油质（发黑、发臭、有泡沫即需更换），助力油有更换周期。
- **转向柱与气囊游丝**：方向盘按键失灵、气囊灯亮、打方向「咔咔」响，多指向螺旋电缆（游丝）磨损。

**四轮定位联动**：前束调整就是通过转向拉杆长度实现的——调整前束后，必须确认方向盘**摆正**，否则会出现「车轮直行方向盘歪」。转向件更换（球头、拉杆、转向器）后也要重新定位，因为间隙与长度的微小变化都会改变前束。<span class="marginnote">「换完拉杆方向盘歪」是常见返工：换拉杆改变了前束，没做定位、没调正方向盘就交车。凡是动过转向拉杆的维修，都要把「定位 + 方向盘对正」写进收尾清单。</span>

**重点：转向系统维护的核心是「间隙」。** 球头、拉杆、转向器内部的间隙一旦变大，方向盘就会出现旷动、异响、跑偏。定期检查间隙并保持防尘套完好，转向系统能用很久。

## 6 转向梯形与前束调整

转向系统还有一个常被忽略的几何概念——**转向梯形与阿克曼原理**：

**转向梯形**：转向节与横拉杆组成的梯形机构，让内外侧车轮在转弯时**转角不同**——内侧轮转角大于外侧轮，各轮围绕同一瞬时转向中心转动，轮胎才不拖滑。这是四轮定位里「前束差」的理论基础。

**阿克曼角**：理想转向几何要求内侧轮转角按阿克曼比例大于外侧轮，以减少转弯时轮胎侧滑与磨损。实际车辆按工况取近似值，前束调整不当会破坏这一几何，造成转弯响胎、轮胎偏磨。<span class="marginnote">转弯时「前轮响胎」常被当成轮胎问题，实则可能是前束调整不当导致转向几何破坏。<strong>做完前束调整后路试急弯，听有无响胎</strong>——这是检验转向梯形是否正确的快捷方法。</span>

**前束调整实战**：前束通过改变左右横拉杆长度调整，两侧要**等量对称**调整，否则方向盘会偏。步骤是：定位仪测量 → 调整拉杆 → 锁紧锁母 → 复查前束 → 路试确认方向盘对正、不跑偏、急弯不响胎。

**重点：转向几何是「手感」与「轮胎寿命」的共同决定者。** 前束、外倾、后倾与转向梯形协同工作，任何一个失准都会在方向盘手感与轮胎磨损上暴露。做转向件更换或定位时，把转向梯形与前束放在一起检查。

## 7 小结

- 转向链路为**方向盘→转向柱→转向器→横拉杆→转向节→车轮**，乘用车主流是齿轮齿条式。
- 角传动比 $i = \theta_{sw}/\theta_w$：15–20 的比值让转向省力可控，圈数由机械结构决定。
- HPS 查油位与皮带、EPS 查数据流与扭矩传感器，表面同症状、内里不同逻辑。
- 转向故障按「手感」定位：沉重查胎压定位与助力、咯噔查球头、不回正查后倾角与转向器。
- 维护核心是**间隙**：球头、拉杆、转向器防尘套定期检查，动过拉杆必须定位并对正方向盘。
- 「跑偏」与「不回正」要分清：跑偏查胎压定位、不回正查后倾与转向器阻力。
- 转向梯形与阿克曼角决定转弯几何：前束调不当会转弯响胎、轮胎偏磨。
- 转向件更换（球头、拉杆、转向器）后必须**重新定位并对正方向盘**。
- 转向系统维护核心是**间隙 + 油液**：球头防尘套、助力油、螺旋电缆定期检查。
- 转向是「手感」系统，先分清转向本身与悬架轮胎，再动手拆转向器。
- 转向沉重先查胎压与定位，再查助力，最后才怀疑转向器内部。
- 打方向「咯噔」响查拉杆球头、下摆臂球头；「咔咔」响查螺旋电缆与转向柱。
- 方向盘总圈数突变或方向盘不正，指向转向器装配、拉杆长度或定位参数。
- EPS 助力「时有时无」，优先怀疑转向柱内的扭矩传感器信号。
- HPS 助力油发黑发臭有泡沫即应更换，助力油有更换周期。

**辨析｜易错点：** 转向系统最怕「小病大修」——方向盘发沉，先查胎压、定位与助力油，都是廉价项目；直接拆转向器往往既费工又解决不了问题。按「从廉到贵、从外到内」排查，才能既快又省。
- 方向盘「转几圈打满」是固定机械属性，圈数突变指向装配或定位而非助力。
