# 空中交通管制与飞行签派

空中交通管制与飞行签派是民航运行安全的核心法定岗位体系，研究从空域划设、管制指挥、飞行签派放行到运行监控的完整链条。空管员与飞行签派员是 CCAR-65《空中交通管制员执照管理规则》规定的法定持证岗位，学完这些章节，就掌握了从执照资格、管制程序到运行控制的完整专业基础。

## 对标教材

- 《空中交通管制员执照管理规则》（CCAR-65）
- 国际民航组织《空中交通管理》（ICAO Doc 4444，PANS-ATM）
- 《空中交通管制基础》教材（民航院校管制专业核心课程教材）
