## 为什么从空域分类讲起

前两节讲了服务与体系，这一节要回答一个更基础的问题：**管制员在哪儿管、飞机在哪儿飞？** 答案是空域——一片被规则切分、被责任界定的三维空间。空域怎么划、划成几类，直接决定了一架飞机在某个位置要受哪套管制规则、承担哪种间隔责任。<span class="marginnote">把空域想成「海洋的分区」：近岸港口（机场塔台区）规则最密，公海（无管制空域）规则最松。空域分类就是给天空画「航道图」，每一格都写着：谁在管、怎么间隔、目视飞行怎么飞。这跟本站第一级《集合》里「用规则刻画集合」的思路一样——空域就是「满足某类服务规则的空间点的集合」。</span>

这一节讲空域的基本划设、ICAO 空域分类 A—G、以及中国空域的实际结构。读完你会理解：飞行员报「我在 C 类空域」，管制员就知道该按哪套程序来管。

## 1 空域划设的基本概念

**空域（Airspace）**：地球表面上空可供航空器飞行的空间，按国家主权划分。空域划设的几类基本单位：

**飞行情报区（FIR，Flight Information Region）**：提供飞行情报与告警服务的空域范围，是空域管理的基础单位。中国设立多个飞行情报区（如北京飞行情报区、上海飞行情报区）。

**管制区（CTA，Control Area）**：提供管制服务的空域，通常从某一高度以上起算（如 600 米以上为管制区，以下为非管制区）。

**管制地带（CTR，Control Zone）**：机场周围为保护起降而划设的管制空域，通常从地面到某一高度。<span class="marginnote">管制地带是「贴地」的管制空域：它把机场周围一小片空间全部划为管制，无论高度多低都归塔台管——因为起降阶段的飞机最脆弱、最需要保护。中国许多机场的 CTR 划成不规则多边形，正是为贴合起降航迹。</span>

**航路与航线**：连接重要点的空中通道，划设高度层后构成航路网络（第 24 篇《导航设施与航路结构》详解）。

## 2 ICAO 空域分类 A—G

**ICAO 空域分类**：按「提供何种 ATS 服务、是否要求 IFR、是否提供间隔」把空域分为 A—G 七类，核心维度有三个：**是否接受 IFR（仪表飞行规则）**、**是否提供管制服务**、**各类航空器之间是否提供间隔**。

关键几类：

**A 类**：只允许 IFR，管制服务对所有航空器提供，所有航空器之间均提供间隔。间隔责任最满，一般用于高空繁忙航路。

**C 类**：IFR 与 VFR 均可，IFR 之间、IFR 与 VFR 之间提供间隔，VFR 与 VFR 之间不提供间隔只提供交通情报。<span class="marginnote">C 类是中国终端区的主流：进近管制区多属 C 类。它的逻辑是「IFR 被全力保护，VFR 自己看着办」——因为 VFR 靠目视飞行，自己就「看得见」对方，不必全靠管制员。这个「看得见就少管一点」的思想，是理解整张空域分类表的一把钥匙。</span>

**D 类**：IFR 与 VFR 均可，IFR 之间提供间隔，VFR 获得全部交通情报并自行保持间隔。

**G 类**：非管制空域，不提供管制服务，只提供飞行情报；所有飞行自行保持间隔。

**分类不是越高越好**：分类越高（A 最高），管制负担与流量限制越大；分类越低，越自由但越要自己负责。设计者要做的是「在安全与效率之间选最合适的类」。

## 3 中国空域的实际结构

中国空域以 ICAO 分类为框架，结合国情落地：

**高空空域**：主要实行雷达管制，按航路划设管制扇区，采用与 ICAO 接轨的间隔标准（详见雷达管制篇）。

**中低空空域与终端区**：进近管制区通常为 C 类；机场管制地带（CTR）为塔台管辖。

**通用航空空域**：低空目视飞行多运行于非管制空域（近 G 类），如跳伞、航拍、农用航空作业。

**军民航协调**：中国实行军民航空域共用，通过空域管理（ASM）机制临时释放军用空域、调整民航班机流，这是中国空域运行的重要特色。<span class="marginnote">中国空域还有一个特殊性：绝大多数民用飞行需要「预先申请、审批放行」，通用航空空域资源长期偏紧。近几年低空经济政策推动空域管理改革——「动态空域管理」「灵活使用空域（FUA）」正是把 ICAO 的空域分类思想在中国落地的尝试，这在本站第十级《家庭组网与路由器配置》聊的「资源如何划分与共享」是同一类问题。</span>

## 4 空域分类与管制责任的关系

空域分类决定了**责任归属**：分类越高，管制单位承担的间隔责任越大，机长自主权越小。

| 空域类 | 是否管制 | IFR 间隔 | VFR 间隔 | 中国典型应用 |
| --- | --- | --- | --- | --- |
| A | 是 | 全部间隔 | 不允许 VFR | 高空繁忙航路（部分） |
| C | 是 | IFR—IFR、IFR—VFR | 不提供，给交通情报 | 终端进近管制区 |
| D | 是 | IFR—IFR | 不提供，给情报 | 部分中小机场塔台区 |
| G | 否 | 不提供 | 不提供 | 低空通用航空空域 |

**辨析｜易错点：** 空域分类 ≠ 管制方法。分类回答「这片空域归谁管、管到什么程度」，管制方法回答「怎么管（程序还是雷达）」。同一个 C 类空域可以既用雷达管制（有雷达覆盖）也用程序管制（雷达失效时）。考试常考：某空域属 C 类，问 IFR 与 VFR 之间是否提供间隔——答案提供，VFR 与 VFR 之间才不提供。

## 5 空域分类的实用意义

对签派员与管制员而言，空域分类是日常决策的「规则库」：签派员看航路上经过哪些空域类，判断是否允许 VFR、是否需要优先保障；管制员看空域类，决定间隔与放行策略。<span class="marginnote">一条跨国航路可能依次穿过多个国家的不同空域类——每过一条 FIR 边界，就要换一套规则、换一个管制单位。这正是「移交」之所以频繁的原因：空域边界就是责任边界，责任边界就是移交点。</span>

把空域想成「给飞行定规则的地图」，一切管制程序就都有了落点——下一节起，我们从法规的层面看看约束空管员本身的执照制度。

**空域分类的现实应用**：签派员排时刻要避开 C 类终端区的高峰、管制员开扇区要核对本扇区空域类与间隔标准、通用航空要查「这片低空是 G 类还是管制空域」——空域分类不是书本知识，而是每天被三方面使用的「运行规则」。它决定了「谁在管、管多严、能飞多自由」。

**一个记忆锚点**：把空域类与「管制责任」绑定记忆——分类越靠前（A→G），管制责任越大、飞行自由度越小；A 类「全管制、全间隔、仅 IFR」，G 类「无管制、各管各」。**顺着 A 到 G 的字母序，就是管制责任递减、飞行自由递增的顺序**，一张表就记住了。

## 6 空域分类的演进与改革

空域分类不是一成不变的静态规则，而是一套随技术与社会需求演进的动态体系：

**从固定到灵活**：传统空域分类是「划死」的——A 类一直 A 类、G 类一直 G 类。现代空域管理（ASM）引入「灵活使用空域」（FUA）：白天商业高峰用民航、夜间/空闲时段释放给军事或通用，空域类可以按时段动态切换——空域的「类」从静态标签变成动态状态。

**从划分到整合**：低空经济、无人机兴起后，传统「民航 + 通用 + 军事」的切分方式不够用了——新的空域管理在探索「按用途与风险分层」，为无人机、低空物流让出空间，同时保持有人机安全。中国低空经济改革正是这一方向的实践。

**对学习者的启示**：理解空域分类的「当前规则」是基础，理解它「为何这样演化」才是进阶——规则背后是技术（雷达、导航、数据链）与需求（容量、低空、无人机）的博弈。本站第七级《大历史》里「制度随技术演进」的视角，在空域分类上得到最直观的印证。

## 7 空域术语速查表

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| FIR | Flight Information Region | 飞行情报区，提供 FIS 与告警服务 |
| CTA | Control Area | 管制区，提供管制服务的空域 |
| CTR | Control Zone | 管制地带，机场周围贴地的管制空域 |
| TMA | Terminal Control Area | 终端管制区，枢纽机场周围的进近空域 |
| ATS 航路 | ATS Route | 划设的空中通道，含高度层 |
| Waypoint | Waypoint | 航路点，RNAV 定位点 |
| FUA | Flexible Use of Airspace | 灵活使用空域，动态调配 |
| IFR/VFR | Instrument/Visual Flight Rules | 仪表/目视飞行规则 |

**辨析｜易错点：** TMA（终端管制区）与 CTA（管制区）容易混淆——TMA 是机场周围进近管制服务的空域，通常只到终端区边界；CTA 范围更大、按高度起算。记住「TMA 在机场门口、CTA 覆盖航路」即可。另一个易错点：FIR 不一定提供管制服务——它主要是「情报与告警」的边界，管制区是「管制」的边界。

## 8 小结

- **空域单位**：FIR（飞行情报区）、CTA（管制区）、CTR（管制地带）、航路。
- **A—G 七类**：按是否管制、是否要求 IFR、是否提供间隔划分；核心是「谁负间隔责任」。
- **C 类逻辑**：IFR 被全力保护，VFR 之间靠目视自行保持间隔。
- **中国落地**：C 类终端区、G 类通用航空、军民航空域动态调配。
- **责任归属**：分类越高，管制责任越大、机长自主权越小。
- **分类 ≠ 方法**：空域类管「管到什么程度」，管制方法管「怎么管」。
