# 西式面点与烘焙（西式面点师）

以Gisslen《Professional Baking》、国家职业技能标准《西式面点师》与Reinhart《The Bread Bakers Apprentice》为纲，系统覆盖从面粉糖蛋原料、发酵面团、蛋糕曲奇酥皮到裱花装饰与职业等级考核的完整烘焙技能体系。学完这些章节，就写完了西式面点师从称量原料、和面烤制到裱花出品的全部内容。

## 对标教材

- 《Professional Baking》（Wayne Gisslen）
- 《西式面点师》国家职业技能标准
- 《The Bread Bakers Apprentice》（Peter Reinhart）
