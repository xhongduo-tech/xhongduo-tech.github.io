# 进攻站位体系：stack 与 handler 站位

## 为什么从进攻站位体系开始

切盘教会你「一个人怎么跑」，但比赛是七个人的游戏——如果七个人都在跑、都在抢同一个空间，那叫混乱，不叫进攻。进攻站位体系（stack）要解决的正是这个问题：**把七个人安排进合理的空间结构，让每次切盘都有干净的跑道，让每次传盘都有明确的目标。**<span class="marginnote">站位是「空间的组织学」：同一块 100 米场地，乱站是一锅粥，站好了就是一套运转的机器。这也是为什么教练在战术板上画的第一样东西，永远是那根表示 stack 的线。</span>

## 1 stack：排队，是为了清空空间

**核心概念（stack）：** stack（直译「堆叠」）是进攻方在无盘状态下，把部分队员沿场地某一方向排成队列的阵型。排队的直接目的是**集中自己人、清空一片空间**，让单个切盘手能在这片空地里跑出干净的路线。

为什么要「排成一队」而不是「散开站位」？两个原因：

**清空切盘区**：把队员集中到场地一侧/一侧纵深，另一侧就成了无人区——切盘手从队列里出发，可以迎着空当跑，而不会被队友堵住路线。
**拉开防守**：进攻方排队，防守方也必须排队跟防。stack 越集中，防守阵型被压缩得越紧，切盘手一旦甩开防守，面前就是大片空白。<span class="marginnote">stack 的逻辑与篮球的「拉开空间」完全同构：大个子挤在禁区，突破就难；拉到三分线外，突破路线就打开了。飞盘用「排队」完成同样的清场，只是把「人」换成「盘权」。</span>

## 2 handler：传盘手的站位与职责

**核心概念（handler）：** handler 是进攻方中负责持盘组织、传盘推进的队员。他们通常站在盘的后方或侧后方，承担「发起进攻」的职责。

handler 的站位有讲究：

**盘后站位**：在持盘人后方 3–10 米处，为持盘人提供「回传（dump/reset）」的安全选项——当持盘人被逼到死角，盘后总有一个 handler 可以回传。
**盘侧站位**：在盘的两侧偏后位置，形成「三角出球结构」，保证盘有多个可传方向。<span class="marginnote">handler 站位的核心是「永远给持盘人留一条后路」：好的 handler 不会让持盘人只剩往前一条路，而是让传盘永远有「向前 + 回传」两个选项，逼抢就失效了一半。</span>
**轮转换位**：盘传到哪，handler 就移动到盘的后方，保持「盘后有人」的结构始终成立。

**handler 与 cutter 的分工：** handler 是「组织者」，cutter 是「执行者」。handler 用站位和传盘决定进攻的节奏与方向，cutter 用跑动撕开防线。一支队伍通常有 2–3 名 handler 与 4–5 名 cutter，比例视战术而定。

## 3 对比表：handler 与 cutter 的角色分工

把两类角色并排看，职责边界立刻清晰：

| 维度 | handler（传盘手） | cutter（切盘手） |
| --- | --- | --- |
| 主要任务 | 持盘、组织、传盘 | 跑位、摆脱、接盘 |
| 站位 | 盘后/盘侧 | 站在 stack 队列中 |
| 移动方式 | 小范围跟随盘的位置 | 大范围切盘跑动 |
| 技能侧重 | 传盘准、视野广、节奏感 | 速度、变向、空间感 |
| 核心价值 | 决定盘往哪去 | 决定盘能不能到 |

**核心要点：** 边界不是死的——handler 也会切盘，cutter 也会传盘，但**站位与思维的重心不同**。handler 的思维重心是「下一盘传哪」，cutter 的思维重心是「下一段往哪跑」。理解分工，才能理解为什么站位体系要求「该谁站哪、就站哪」。

## 4 站位体系的两大母版：竖排与横排

stack 家族有两位最重要的成员，几乎所有进攻体系都从它们派生：

**垂直 stack（vertical stack）**：cutter 沿场地**纵深方向**排成一列，站位在场地一侧。竖排清出的是**横向空间**——切盘手从队列里横向切出，接球后通常已面向得分区方向。

**水平 stack（horizontal stack）**：cutter 沿场地**宽度方向**排成一排，横在中场。横排清出的是**纵深空间**——切盘手从队列里纵向切出，靠连续的内切/外切推进。

**这一节先立住概念：竖排管「横向」，横排管「纵向」。** 两种母版的优劣、适用时机、转换策略，是第4篇《进攻体系》整节的展开内容——这里只需记住它们各自打开的空间方向，为下一阶段做好准备。<span class="marginnote">用几何语言记：竖排把「前后」留给自己、把「左右」让给切盘；横排则反过来。空间方向的选择，决定了整套战术的性格。</span>

## 5 站位体系的黄金法则：空间卫生

堆叠站位不是为了「好看」，而是为了维持一片**干净的空间**。几条黄金法则保证空间不被自己人污染：

**保持间距**：站位之间留出合理距离（通常 3–5 米），避免队友互相挤占。两个人站在同一个点，等于一个位置空了。
**一次一个 cutter**：竖排里同一时刻通常只让一名 cutter 切盘，其余人保持队列。两个 cutter 同时切，会互相堵路、也让防守者一防二。
**切完回队列**：切盘没接到盘，要立即回到队列，为下一次切盘重新蓄力——滞留切盘区会把空间堵死。
- **盘动我动**：handler 要随盘移动保持「盘后有人」，cutter 的位置也要随盘的位置重新组织。<span class="marginnote">「一次一个 cutter」是竖排体系的核心纪律，也是新手最容易犯的错：人人都想切，结果人人都切不出来。空间卫生的本质是<strong>自律</strong>——懂得「此刻该我保持不动」，比「此刻冲上去」更需要球商。</span>

**空间卫生的意义**在于：它把「七个人的进攻」组织成「一个人切、六个人等」的循环。看起来简单，执行起来极难——因为每个人都要同时克制自己「去切」的冲动，信任队友的节奏。这一课，是个人技术向团队战术过渡的必经门槛。

## 6 小结

- **stack** 是进攻方集中排队、清空空间的阵型，让切盘手有干净的跑道。
- **handler** 是传盘组织者，站位在盘后/盘侧，永远给持盘人留「回传」后路。
- **cutter** 是切盘执行者，站在 stack 队列中，用跑动撕开防线。
- handler 与 cutter 分工：一个管「传哪」，一个管「往哪跑」；边界可流动，思维重心不同。
- stack 两大母版：**垂直 stack 清横向空间，水平 stack 清纵向空间**，细节留待第4篇展开。
