## 为什么从水平 stack 与垂直 stack 开始

第13篇我们立住了「stack 是清空空间的排队」，现在要把这句话落到两种具体的队形上——**垂直 stack** 与 **水平 stack**。它们是极限飞盘进攻体系的两大母版，绝大多数球队的进攻战术都从二者之一派生。选竖排还是横排，不是「喜欢哪个」，而是**「你想清空哪个方向的空间、激活哪种切盘路线」**。<span class="marginnote">记住几何关键词：竖排清「横向」，横排清「纵向」。方向的选择决定切盘手往哪跑、handler 往哪传，一整套进攻性格都由此展开。</span>

## 1 垂直 stack：把切盘手排成一列

**核心概念（vertical stack）：** 垂直 stack 是切盘手沿场地**纵深方向**（端区到端区）排成一列的阵型，列的位置通常在场地一侧，2–3 名 handler 在盘后组织。

![垂直 stack 与水平 stack 站位对比](/images/fei-pan/horizontal-and-vertical-stack-1.svg)

竖排的空间逻辑：

**清出横向空间**：切盘手全部集中在一条纵线上，两侧就空了——切盘手从队列里**横向切出**（in/out cut），沿场地宽度方向跑向盘或甩开防守。
**进攻方向天然向前**：横向切出后接盘，身体往往已朝向对方端区，接球后可以直接向前传，推进效率高。
- **适合有速度的队伍**：竖排的核心武器是「横向变向 + 纵向推进」，对切盘手的爆发力与变向能力要求高。<span class="marginnote">竖排里最经典的画面是：队列里的 cutter 猛地横向切出，在防守者追上来之前接到盘，转身面向端区——一次横向切盘就完成了「摆脱 + 转向 + 推进」三个动作。</span>

## 2 水平 stack：把切盘手排成一行

**核心概念（horizontal stack）：** 水平 stack 是切盘手沿场地**宽度方向**排成一行的阵型，通常 3–4 名 handler 在后、4 名 cutter 横跨场地中前场。

横排的空间逻辑：

**清出纵深空间**：切盘手横成一排，场地前后就空了——切盘手从队列里**纵向切出**，或内切到盘前、或纵深冲向端区。
**多点进攻**：横排让四名 cutter 同时拥有向前的角度，进攻不依赖单一强点，配合「连续传切」可以快速撕裂防线。
- **适合传接流畅的队伍**：横排的武器是「多点短传 + 连续轮转」，对全队的传接准度与无球跑动要求高。<span class="marginnote">横排常被形容为「流动的进攻」：四名 cutter 像波浪一样依次向前，盘在 handler 间快速转移。它的节奏比竖排更「绵密」，但一旦传接断了，空当也暴露得更明显。</span>

## 3 对比表：竖排 vs 横排

两种体系并排看，各自的性格一目了然：

| 维度 | 垂直 stack（竖排） | 水平 stack（横排） |
| --- | --- | --- |
| 排队方向 | 纵深（前后）一列 | 宽度（左右）一行 |
| 清出的空间 | 横向空间 | 纵深空间 |
| 主要切盘路线 | 横向切出 | 纵向切出 |
| 核心武器 | 速度、变向、单点突破 | 短传、轮转、多点进攻 |
| 对个人能力依赖 | 较高（强点带动） | 较低（整体配合） |
| 对传接稳定要求 | 中 | 高 |

**核心要点：** 竖排是「一把尖刀」——用强点撕开防线；横排是「一张网」——用整体流动覆盖全场。**没有绝对优劣，只有是否匹配队伍资源**：队伍里有一两个速度爆点，竖排能放大他们；队伍传接细腻、配合默契，横排能释放整体。

## 4 如何选择：体系与队伍的匹配

选择竖排还是横排，实战教练看的是三件事：

**队员构成**：有绝对速度强点，优先竖排；整体技术均衡，优先横排。
**对手防守**：对手人盯人强、区域弱，竖排的横向切出好打；对手区域联防强，横排的多点短传更能瓦解。
- **比赛情境**：比分落后需要快速追分，竖排的推进效率高；比分领先需要稳控节奏，横排的短传更安全。<span class="marginnote">顶级队伍不会死守一种体系——他们会根据对手与比分在两套 stack 间切换，甚至在同一分里混合使用。体系是工具箱，不是信仰；能灵活换挡的队伍，才最难被针对。</span>

**学习建议：** 初学队伍先选一种练透，通常推荐**竖排**——它对传接稳定的要求略低、概念更直观，适合作为团队战术的起点。练熟一套再学另一套，两套都会用时，才谈得上「因敌变化」。

## 5 术语速查：读懂进攻体系的黑话

观看比赛或阅读战术时，下面这些词会反复出现。提前记熟，就能跟着解说「看懂场面」：

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 内切 | in-cut | 切向持盘人方向的跑位 |
| 外切 | out-cut | 切离持盘人方向的跑位 |
| 纵深切 | deep cut | 朝对方端区的纵深跑位 |
| 回传 | dump | 传回盘后的 handler，缓解逼抢 |
| 重置 | reset | 回传后再重新组织进攻 |
| 破防传 | break throw | 打破 force 方向的传盘 |
| 轮转 | flow | 盘在队员间流动的节奏 |

**核心要点：** 这七组词是「读懂进攻」的最小词汇量——**in/out/deep 是切盘的三种方向，dump/reset 是 handler 的保底手段，break throw 是破防的钥匙，flow 是整套体系的节奏描述**。第4篇接下来的几节（give-and-go、force、队伍分工）都会在这套词汇上继续搭建。<span class="marginnote">把这些词放到「为什么」层面记：in-cut 是为了快速出盘，dump 是为了活命，break throw 是为了打开死局——每个词背后都是一个战术动机。记住动机，词汇自然不忘。</span>到这一步，你已经拥有读懂进攻体系全部核心术语的词汇量了。

## 6 小结

- **垂直 stack**：切盘手沿纵深排成一列，清出**横向空间**，靠速度与变向单点突破。
- **水平 stack**：切盘手沿宽度排成一行，清出**纵深空间**，靠短传与轮转多点进攻。
- 竖排是「尖刀」、横排是「网」：**竖排放大强点，横排释放整体**。
- 选择依据：**队伍构成、对手防守、比赛情境**三因素综合判断。
- 体系是工具箱不是信仰；初学者先练透竖排，再学横排，最终能灵活切换。
