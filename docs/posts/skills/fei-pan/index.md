# 飞盘

极限飞盘是一项融合传接盘技术、跑位意识、团队战术与精神规则的无接触竞技运动，以自我裁判和「精神规则」著称。以 WFDF《极限飞盘规则》、《极限飞盘运动》与飞盘教学资料为纲，系统重建从场地器材、传接盘技术、跑位与个人攻防到团队战术、规则深化与体能训练的完整知识体系。

## 对标教材

- WFDF《极限飞盘规则》（世界飞盘联合会）
- 《极限飞盘运动》
- 飞盘教学资料（中国飞盘协会 / 高校飞盘教材）
