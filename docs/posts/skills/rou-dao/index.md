# 柔道

柔道是由嘉纳治五郎创立的现代武道，以投技、固技与寝技为核心技术，奉行「精力善用、自他共荣」的宗旨。以《柔道运动教程》、国际柔联（IJF）竞赛规则与柔道段位体系为纲，系统重建从礼仪受身、投技寝技技术到竞赛规则、段位考核的完整进阶路径。学完这些章节，就写完了柔道运动体系的主体内容。
