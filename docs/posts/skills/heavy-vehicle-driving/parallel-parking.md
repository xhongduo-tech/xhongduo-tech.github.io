## 为什么从侧方停车开始

侧方停车是科目二的必考项目，也是大型车真实作业中天天用的技能——货场靠台、路边停靠、卸货点对位，本质上都是「侧方入库」。

大型车侧方停车与小型车原理相同，但**车身长、轴距长、转弯半径大、盲区大**，让「进库—修正—出库」每一步都更考验对轨迹的预判。

理解侧方停车的运动学，比死记点位更重要：**车尾先进、车头出库要防内轮差**，这两条主线想通了，点位才有意义。
<span class="marginnote">大型车侧方停车比倒车入库「好进」：库位横向余量相对宽松、且入库方向与行驶方向一致，更接近「倒着拐个弯」。但它考的是另一种能力——<strong>在有限空间里把车身姿态摆正</strong>，出库时还要防车头扫到前车或障碍。</span>

## 1 侧方停车的场地与考试要求

侧方停车场地为道路一侧划出的**平行库位**，通常由前后边界线、边线与库底界定：

- **场地布局**：库位长约 1.5 倍车长、宽约车身宽 + 0.8 米左右，车位与车道平行。
- **考试流程**：从车位前驶过 → 倒车入位 → 车身完全入位、不压线 → 前进出库驶离，全程不能中途停车（大车要求严）。
- **评判要点**：车身出线不合格；入库后车身触碰库边线不合格；倒库不入不合格；中途停车每次扣分。<span class="marginnote">相比 C1 侧方停车，大型车的库位更长更宽，但车身也更长——「库位比车长一点、车宽多一点」的相对余量同样紧张。大型车侧方停车的「看点」普遍以右后视镜、右后轮与库角的关系为基准，且因车身长，修正时机要更提前。</span>

**重点：侧方停车的难点不在「进得去」，而在「摆得正、出得来」。**
车身入位后若歪斜或未完全平行，会影响出库；
出库时车头外摆，还要防车头扫到库位前方的障碍或来车。

## 2 侧方停车的运动学：车尾先进，车身摆正

侧方停车（右侧入库）的核心是**车尾先进入库位、车身逐渐摆正**：

1. 车辆与库位平行、保持约 30–50 厘米横向距离，**车尾越过库位起点后**停车；
2. 挂倒挡，右打方向，**车尾向右画弧进库**；
3. 车尾进入库位后，**回正方向**，让车身沿库位方向直线倒车；
4. 车身与库边平行、前轮完全入位后停车。

**关键在「回正方向」的时机**：方向回得早，车尾偏向库外、右后轮压库边；
回得晚，车尾偏向库内、左后轮压库边。
判断回正时机的经典参照是**后视镜中库角的位置**——看到库角在镜中移动到位，就该回正。
<span class="marginnote">侧方停车「看点」的核心循环：<strong>看右后视镜——盯库角——到点回正——看车身平行——停稳</strong>。车速越慢，每个点位越可复现；车速忽快忽慢，点位必然乱。这也是所有科目二项目的共同纪律。</span>

## 3 公式解析：为什么车尾先进、车头后出

侧方停车的轨迹可以用「转弯半径」的几何解释。
设轴距 $L$、前轮转角 $\delta$，后轴中心的转弯半径仍是自行车模型的经典结果（第 3 篇《倒车入库》已推导）：

$$
R = \frac{L}{\tan \delta}
$$

- **$R$**：后轴中心的转弯半径。倒车时**后轴画弧**、车尾沿着这条弧进库，所以车尾是「主角」。
- **$L$**：轴距。大型车轴距 4–6 米，$R$ 比小汽车大得多，车尾画出的弧「平」且「大」，入位要更早打方向。
- **$\delta$**：前轮转角。倒车入位的转向幅度比想象中更大，因为要靠这个转角把长长的车身「拐」进平行库位。

**推导直觉**：侧方停车本质是「用圆弧把车身的纵向轴线从与车道平行转到与库位平行」。
车尾先进，是因为**后轴画出的圆弧决定了车身能否进得去**；
进库后回正方向，是把「转弯弧」切换成「直线倒车」，让车身沿库位方向摆正。
<span class="marginnote">对大型车，这个公式还有一个实际含义：<strong>轴距越长，越不能指望「一把进库」</strong>——转弯半径大，车尾扫过的空间大，所以大车侧方停车普遍采用「倒车进库 + 小幅修正」的两段式，而不是小车那种一把方向甩进去。</span>

## 4 大型车侧方停车的操作要领

以右侧库位为例，一套完整流程：

1. **起始对位**：车与库平行，横向距离约 30–50 厘米，车尾越过库位前边界后停车，挂倒挡。
2. **第一把方向（右打）**：倒车时观察右后视镜，当**库位右前角（或参照物）**移动到镜中合适位置时，**向右打方向**，车尾向右画弧进库。
3. **回正方向**：车尾进入库位、车身接近与库边平行时，**快速回正方向**，保持直线倒车。
4. **修正入库**：通过后视镜观察车身与库边距离，**哪边宽往哪边打**微调，保持车身正直。
5. **停车**：前轮完全入位、车头与库底平齐时，踩离合制动停车，拉手刹、回空挡。
6. **出库**：打左转向灯，观察左侧后视镜与盲区，起步出库；**车头出库时防内轮差**——车尾会向库边方向甩，注意别刮蹭库位边缘或旁边障碍。<span class="marginnote">侧方停车易错点集中在「<strong>回正过早/过晚</strong>」：回正早 → 车尾压右侧库边；回正晚 → 车尾压左侧库边。判断口诀是「<strong>压哪边，方向就往反方向修</strong>」——右后轮压右库边，说明回正早了，下次晚点回正。</span>

## 5 易错点与实战答疑

**「为什么我的车总是斜着进库？」**
进库时车身与库边不平行，通常是回正时机不准或回正后没有继续微调。
对策：回正后不要立刻停车，继续缓慢倒车，用「哪边宽往哪边打」把车身摆正再停。

**「车头出库时总怕蹭到前车，怎么办？」**
出库是侧方停车的第二道坎：车身越长，车头外摆越多。
对策：出库前先回正方向让车直行一段，再打方向出库，给车头留出外摆空间；
观察右后视镜确认车尾与库边距离足够。

**「侧方停车和倒车入库的看点有什么区别？」**
倒车入库是「先打满方向、后回正」，侧方停车是「先右打进库、再回正直线倒车」。
前者靠打满方向让车尾甩进库位，后者靠「画弧 + 摆正」两段完成——侧方停车对「回正时机」的依赖更重。
<span class="marginnote">真实作业与考试的差异：考试库位有标线、有固定的「看点」，真实路边停车没有标线，只能靠<strong>前后车距离、路缘线、后视镜</strong>综合判断。把考试练成的「回正—摆正」程序带到真实场景，比考场点位置信得多——这也是为什么教练常说「科目二练的是手感，不是点位」。</span>

## 6 实操要点复盘

**侧方停车「六步口诀」**：

1. 对位——车身与库平行，横向 30–50 厘米；
2. 右打——车尾越过库前角后，右打方向画弧进库；
3. 回正——车尾进库、车身接近平行时快速回正；
4. 微调——哪边宽往哪边打，把车身摆正；
5. 停车——前轮完全入位、车头与库底平齐时停稳；
6. 出库——回正直行一段再打方向，防车头外摆蹭前车。

**侧方停车「三忌」**：

- 忌车速忽快忽慢——点位全乱；
- 忌一把方向甩进库——大车转弯半径大，甩进去必压线；
- 忌出库不看右后轮——内轮差会让车尾蹭库边。

**考场与实战的衔接**：把「对位—进库—摆正—出库」练成程序，考场上按程序走，实战里靠后视镜与路缘综合判断——程序是考试的定心丸，判断是实战的真功夫。


## 7 小结

- 侧方停车是科目二必考项，也是货场靠台、路边停靠的日常技能；大型车难点在**车身长、轨迹大、盲区大**。
- 运动学主线：**车尾先进（后轴画弧）、回正后摆正、出库防内轮差**。
- 转弯半径公式 $R = L/\tan\delta$ 解释了为什么大型车「不能一把进库」，而要多段修正。
- 关键点位循环：看右后视镜 → 盯库角 → 到点回正 → 看平行 → 停稳；车速慢、点位才可复现。
- 易错点：回正过早压右库边、过晚压左库边；出库防车头外摆蹭前车。
