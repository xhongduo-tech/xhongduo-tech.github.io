## 为什么从考试流程与评判开始

前面几节把科目二的每个项目拆开讲了，这一节把它们装回「考试」这个容器里：**考几项、按什么顺序、多少分合格、哪些动作直接不合格**。

理解评判标准，不是教你钻空子，而是帮你把训练精力投在最容易丢分的地方——评判规则本质上就是「安全驾驶的最低清单」。

对大型车而言，科目二项目比小型车多、合格线比小型车高、评判也从严，这一节把这些差异讲清楚，让你知道「这 100 分到底是怎么构成的」。
<span class="marginnote">大型车科目二的满分与合格线是区分度最大的地方：<strong>满分 100 分、90 分合格</strong>，而小型汽车是 80 分合格。同样压一次线，大车只剩 10 分的容错——所以大车科目二对每个项目都要「奔着满分练」。</span>

## 1 大型车科目二的考试项目

按公安部令第 162 号附件，大型客车（A1）、牵引车（A2）、中型客车（B1）、大型货车（B2）等大型车型的科目二考试内容，比小型汽车多了多项专门针对大型车的项目：

| 项目 | 说明 |
| --- | --- |
| 倒车入库（桩考） | 车身入位、不压线、不碰桩，A1/A2/A3/B1/B2 必考 |
| 坡道定点停车和起步 | 定点停车 + 坡道起步，考「油离刹」配合 |
| 侧方停车 | 平行库位入位、出库 |
| 通过单边桥 | 左右轮依次通过窄桥，考车轮轨迹 |
| 曲线行驶 | 沿 S 形弯道贴线行驶 |
| 直角转弯 | 直角路口打满方向通过 |
| 通过连续障碍 | 按轮迹依次绕圆饼 |
| 窄路掉头 | 窄路上「前进—后退」多次掉头 |
| 模拟高速公路 | 模拟匝道、车道、驶入驶出规则 |
| 连续急弯山区路 | 模拟山区连续弯道 |
| 模拟隧道 | 隧道内灯光、限速、禁停 |
| 模拟湿滑路 | 低附着路面起步与制动 |
| 紧急情况处置 | 模拟突发状况的应急处置 |

**重点：大型车科目二是「全地形考场」。**
从城市道路到高速公路、从山区弯道到隧道、从湿滑路面到紧急情况，这些项目模拟的就是大型车真实运营中会遇到的每一种危险场景——这也是它比小型车科目二项目多出一倍的原因。
<span class="marginnote">不同车型的项目略有差异：牵引车（A2）与大型货车（B2）都要考<strong>窄路掉头</strong>（详见《大型车辆掉头与转弯半径控制》），客车类还重<strong>模拟隧道</strong>与<strong>紧急情况处置</strong>。各车型的具体项目与顺序以当地车管所考试大纲为准，报名时先确认，训练时对表练。</span>

## 2 考试流程：从候考到出考场

科目二考试的全流程，大致分五个环节：

1. **身份核验与候考**：凭身份证与考试预约凭证进入考场，候考区等待，按批次进入待考区。
2. **上车准备**：调整座椅与后视镜、系安全带、确认挡位与手刹、点火启动；确认车辆状态后示意考官（或系统）开始。
3. **按序考试**：按考试系统分配的车辆与路线，依次完成全部考试项目。大型车项目多，全程由车载电脑/考试系统评判并记录。
4. **当场补考**：一次考试未合格（或中途不合格），按系统提示进行**当场补考一次**；补考不合格的，本次考试结束，须重新预约。
5. **签字确认**：考试结束后签字确认成绩；不合格的，当场可了解扣分原因，下次预约前针对性补练。

**易错点 | 辨析：科目二中途熄火要立即重新启动。**
考试中发动机熄火后，**只要及时重新启动、在限定时间内继续完成项目**，通常只扣分而非直接不合格；
但熄火后若未及时处理、或长时间滞留，就会叠加扣分直至不合格。
所以「熄火不慌、立刻重启动、继续考试」是科目二的保命心态。

## 3 评判要点：哪些动作直接不合格

科目二评判分「直接不合格」与「扣分项」两类。
**直接不合格**的动作（大型车从严）主要包括：

- 不按规定使用安全带；
- 不按考试员指令或规定路线行驶；
- 不按规定速度行驶（超速）；
- 车辆行驶中骑轧车道实线、道路边缘实线或触碰桩杆；
- 倒车入库不入、车身出线、中途停车（部分项目规定）；
- 发动机熄火且未在规定时间内重新启动（视项目规定）；
- 起步时车辆后溜距离过大。

**扣分项**（每次扣 10 分或 5 分不等）主要包括：停车后未拉紧驻车制动、起步时未打转向灯或转向灯使用错误、通过项目时车速不稳、停车距离超出规定范围等。
<span class="marginnote">评判从严的底层逻辑：科目二的项目都是「<strong>有限空间里的精准操控</strong>」，压线、出线、碰桩对应的正是真实驾驶中「越线、越位、碰撞」的风险。考试系统按厘米级精度评判，是模拟真实场景里「厘米级差就是事故级差」的代价。</span>

## 4 大型车与小型车科目二的差异对照

把大型车科目二与小型车（C1）对比，差异一目了然：

| 对比维度 | 大型车（A1/A2/B1/B2） | 小型汽车（C1） |
| --- | --- | --- |
| 项目数量 | 多（含单边桥、连续障碍、窄路掉头、模拟隧道等） | 少（倒库、侧方、坡道、曲线、直角等） |
| 合格线 | **90 分合格** | 80 分合格 |
| 评判精度 | 厘米级从严 | 相对宽松 |
| 场地尺度 | 库位更大但余量同样紧张 | 库位较小 |

**重点：合格线 90 分意味着「一次失误就危险」。**
满分 100 分，一个 10 分扣分项就逼近底线，两个 10 分项或一个直接不合格项直接出局。
所以大型车学员的科目二策略不是「求 90」，而是「每一个项目都按满分练、把直接不合格动作从习惯里根除」——这正是前面各节反复强调「程序化」的原因。
<span class="marginnote">训练策略建议：先按<strong>「不扣直接不合格分」</strong>为目标练（压线、出线、碰桩一个都不能有），再抠扣分项（转向灯、驻车制动、车速稳定）。把 90 分线当作「不允许任何大失误」的心理锚点，考试才稳。</span>

## 5 实战提示：考前一周怎么练

- **锁定弱点项目**：回顾平时训练记录，找出扣分最多的 1–2 个项目，考前集中突破，其余项目保持手感即可。
- **还原考试节奏**：把「倒库 → 坡道 → 侧方 → …」按考试顺序完整串练几遍，让身体记住「项目切换」的节奏，而不是单项目突击。
- **固定看点与参照**：考前确认自己车辆的看点参照（左后视镜下沿、雨刮器节点、引擎盖参照点）是固定的，考试时只信自己的点位。
- **心态预案**：把「当场补考」当作一次免费纠错机会——第一把求稳、补考放轻松；熄火、压线都是正常波动，不要因为一次失误崩盘。<span class="marginnote">科目二的心理战术：<strong>第一把当「模拟」、补考当「正式」</strong>。很多学员第一把紧张失误后，补考反而更放松、动作更干净——把这种经验前置，第一把就按「求稳」打，补考再谈「求满」。</span>

## 6 常见疑问与答疑

**「科目二考试车和训练车不一样，看点会变吗？」**
会。不同车辆的座椅高度、后视镜视野有差异，看点参照（后视镜下沿、雨刮器节点）位置可能偏移。
上车准备时把座椅与后视镜调到自己习惯的位置，再按「先小角度试、后按点位走」的节奏适应考试车。

**「考试中压了一次线，是不是就完了？」**
不一定。压线是否不合格看具体项目与位置——有些是扣分项，有些是直接不合格项。
关键是「压线后不慌」，继续完成后续项目，把分数损失控制到最小。

**「第一把挂了，补考怎么调整心态？」**
把补考当作「第二次机会」而不是「最后一次机会」——深呼吸，把车速放慢，只盯「下一个动作」。
很多学员第一把挂后，补考反而动作更干净，因为紧张已被「已经挂过一次」释放。


## 7 小结

- 大型车科目二项目多（含单边桥、连续障碍、窄路掉头、模拟高速公路/隧道/湿滑路等），**满分 100、90 分合格**。
- 考试流程：**身份核验 → 上车准备 → 按序考试 → 当场补考一次 → 签字确认**。
- 直接不合格动作：不系安全带、不按规定路线行驶、压线碰桩、入库不入、后溜过大等；熄火后须及时重启。
- 大型车与小车的核心差异：**项目多、合格线高（90 vs 80）、评判严（厘米级）**。
- 考前策略：锁定弱点、还原节奏、固定看点、心态预案（第一把求稳、补考放松）。

在下一节，我们离开封闭场地，走上真实道路：直线行驶怎么把稳方向盘、加减挡怎么匹配车速——这就是**直线行驶与加减挡车速控制**。
