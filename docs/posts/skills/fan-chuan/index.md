# 帆船与帆板

帆船与帆板是以自然风为动力的水上运动，融合空气动力学、流体力学与操舵调帆技术，既可休闲航行又可竞赛竞技。以《帆船运动教程》、World Sailing《帆船竞赛规则》与《帆板运动》为纲，系统重建从航行原理、操舵调帆到竞赛规则的完整实操与理论体系。学完这些章节，就写完了帆船与帆板运动的全部内容。

## 对标教材

- 《帆船运动教程》
- World Sailing《帆船竞赛规则》（Racing Rules of Sailing）
- 《帆板运动》
