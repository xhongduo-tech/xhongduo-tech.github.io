# 美甲

美甲是以手部护理与甲面造型为核心的美学手工技能，涵盖基础护理、彩绘艺术与延长建构技术，既有审美价值，也是可职业化的服务型技能。学完这些章节，就写完了美甲基础、彩绘、延长与美甲师职业的全部内容。
