## 为什么从品势段位考核讲起

上一课我们走完了「彩带世界」——级位晋升考核。现在要跨过那道门槛，进入**黑带段位（Dan）** 的考核世界。段位考核与级位考核最大的不同在于：**级位是「道馆内」的标准，段位是「国技院背书」的认证**——它有更正式的考官、更统一的评分、更高的技术要求。<span class="marginnote">国技院（Kukkiwon）是跆拳道段位认证的权威机构——黑带段位证书（Dan certificate）由国技院颁发，全球通用。段位考核通常由「国技院认证考官」参与，比级位考核更正式、更严格。</span>

在段位考核中，**品势**是重中之重——黑带品势（高丽、金刚、太白等）代替了级位的太极系列，成为段位考核的核心内容。本课聚焦「品势段位考核」：考什么、怎么评分、以及段位品势的体系。

## 1 段位品势的世界：从太极到高丽金刚

级位阶段学的品势是「太极八章」——它们是「基础品势」。而黑带段位学的品势，是「**段位品势（Yudanja Poomsae）**」——一系列以传统命名、难度更高的品势。

国技院体系下的段位品势（通行）包括：

**高丽（Koryo）**：象征「高句丽民族精神」，是 1 段（晋黑带）考核的经典品势。
**金刚（Keumgang）**：象征「刚强与坚固」，与「金刚山」的意象相连，常与 2 段考核关联。
**太白（Taebaek）**：象征「明亮的山峰」（太白山），常与 3 段考核关联。
**平原（Pyongwon）**、**十进（Sipjin）**、**地跆（Jitae）**、**天拳（Cheonkwon）**、**汉水（Hansoo）**、**一如（Ilyeo）**：更高段位（4 段以后）的品势系列。

<span class="marginnote">段位品势的命名多与韩国传统意象相连：高丽（古代王朝名）、金刚（金刚山）、太白（太白山）、汉水（汉江）、一如（佛教「万法一如」之意）。命名背后是「用传统文化承载武学精神」的设计——品势不仅是技术，也是文化载体。</span>

**重点：段位品势与太极系列的区别，不只是「更难」，而是「技术语汇的升级」——段位品势加入了更多高级技术（转身、腾空、复杂步法）、更深的技术组合、更强的节奏与劲力要求。** 如果说太极系列是「基础词汇」，段位品势就是「高级写作」——同一套基本功，用更高难度、更深内涵的方式重新组织。

**辨析｜易错点：** 很多人以为「晋黑带 = 学会太极八章 + 会踢几个腿法」。**实际上晋黑带（1 段）的核心品势考核是高丽（Koryo）——不是太极八章**。太极八章是「级位的终点」，高丽是「段位的起点」。理解这个「衔接」，你才知道晋黑带前真正该练的是什么。

## 2 品势段位考核的「考什么」：多维度的「修为检验」

品势段位考核比级位考核更严格，它的考核内容与评分维度可以归纳为：

**指定品势演练**：考生演练对应段位的指定品势（如 1 段考高丽）。这是考核的「主项」。

**技术与理论问答**：考官可能提问品势技术要点、跆拳道精神、品势的攻防含义等——检验「理解深度」而非「只会做」。

**品势的攻防解析**：考生可能被要求「讲解某段品势的攻防含义」——这一段是防、那一段是攻、为什么这样编排。这检验的是「对品势的理解」——不只是「会打」，而是「懂为什么这样打」。

**体能与其他**：部分段位考核包含体能测试与基本技术抽测（如随机抽考几种腿法）。

**重点：品势段位考核检验的是「对品势的深度理解」——从「会打」上升到「懂打」。** 这就是为什么段位考核会有「攻防解析」「理论问答」这些环节：级位考核看「动作对不对」，段位考核看「动作懂不懂」。一个能讲解「高丽里这段转身为什么这样设计」的考生，与一个「只会照葫芦画瓢」的考生，在段位考核中的表现天差地别。

<span class="marginnote">「从会打到懂打」的跨越，正是《品势的呼吸、节奏与劲力表现》一课强调的「从形到神」：段位考核的评分者看的不是你「动作多标准」，而是你「能不能让动作有灵魂」——呼吸、节奏、劲力、攻防意识，全部要到位。段位品势的「高丽」尤其强调「刚健沉稳」的气势，这正是「神」的部分。</span>

## 3 品势段位考核的「怎么评分」：评分体系

品势段位考核的评分，通行做法是「分项评分 + 减分制（或加分制）」的混合体系：

**评分维度（打分项）**：

| 评分维度 | 观察重点 |
| --- | --- |
| 准确性 | 方向、线路、站架、手位是否正确 |
| 节奏 | 快慢对比、停顿定格、段落起伏 |
| 劲力 | 整劲、爆发、贯透、发力是否到位 |
| 呼吸 | 发力呼、蓄势吸，是否自然配合 |
| 表现力 | 气势、眼神、攻防意识、整体观感 |

**评分方式**：通行做法是「基础分 + 加减分」——从满分基准开始，按「错误程度」减分（方向错、动作忘、站架不稳各减多少），再按「表现加分项」（劲力出色、气势到位）加分。

**重点：品势段位评分的核心逻辑是「减分为主、加分为辅」——先保证「不扣分」（准确），再争取「加分」（表现）。** 这与《品势的呼吸、节奏与劲力表现》一课讲的「先保底再提优」完全一致：准确性是「扣分底线」，表现力是「加分上限」。段位考核中，一个「动作全对但平淡」的考生，与一个「动作略瑕疵但气势惊人」的考生，分数可能不相上下——因为评分体系既惩罚「错误」，也奖励「表现」。

**公式解析：品势段位评分的「构成模型」**

$$
\text{品势得分} \approx \text{基准分} - \sum \text{扣分项} + \sum \text{加分项}
$$

逐项拆解：

- **基准分**：每个品势的「满分基准」——通常是 10 分或百分制，代表「完美演练」。
- **$\sum \text{扣分项}$**：所有扣分的总和——方向错、动作忘、站架不稳、节奏乱、呼吸断，每一项按程度减分。扣分项是「错误的账本」，越多的错误，基准分被扣得越多。
