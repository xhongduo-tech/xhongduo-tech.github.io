# 跆拳道

跆拳道是起源于韩国的现代武道，以腿法为核心技术、以品势与竞技对抗为两大主线。以世界跆拳道（WT）竞技规则、国技院品势与段位体系为纲，结合《跆拳道运动教程》，系统重建从礼仪武德、腿法基本功到品势套路、竞技实战、段位考核与少儿培训的完整进阶路径。学完这些章节，就写完了跆拳道运动体系的主体内容。

## 对标教材

- World Taekwondo《竞技跆拳道竞赛规则》
