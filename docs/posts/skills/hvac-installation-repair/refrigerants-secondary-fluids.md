## 为什么从制冷剂开始

上一篇我们认识了四大部件，这一篇认识在它们之间循环的**工质**。制冷剂在蒸发器里吸热、在冷凝器里放热，是热量的「搬运工」；载冷剂则是中间人——在一些大型系统里，冷媒先冷却水或盐水，再由它们把冷送到远处。安装维修工每天都与它们打交道：充注、回收、更换、辨识。**认错制冷剂，轻则压力表读数全盘作废，重则混用后压缩机烧毁、甚至发生爆炸。**

这篇的另一层意义是理解行业的「变局」：老空调用的 R22 正被淘汰，新一代 R32、R410A 与天然工质正在接管。修一台旧机器，先要能说出「它现在跑的是什么血」。

读这一篇时请带着两个问题：这台机器的工质属于哪一代、该用哪一套表？如果我要换一种工质，整套系统里有哪些部件要跟着换？

## 1 制冷剂：循环的「血液」与它的身份证

**制冷剂（refrigerant）**：在制冷循环中不断进行相变（蒸发吸热、冷凝放热），把热量从低温处搬运到高温处的工质。<span class="marginnote">制冷剂靠「潜热」干活，不靠「显热」：液体沸腾吸收大量汽化潜热，气体凝结放出等量潜热。所以好的制冷剂必须「容易沸腾、容易凝结」——沸点落在使用温度区间附近。</span>

每一类制冷剂都有一个标准编号，由 ASHRAE 规定，工程上以字母 R（Refrigerant）加数字称呼：

| 编号 | 制冷剂 | 化学组成 | 大致用途 |
| --- | --- | --- | --- |
| R22 | 二氟一氯甲烷 | $\ce{CHClF2}$ | 老式家用/商用空调（逐步淘汰中） |
| R134a | 四氟乙烷 | $\ce{C2H2F4}$ | 汽车空调、中温冷库 |
| R410A | 混配制冷剂 | $\ce{CH2F2 + C2HF5}$（近共沸） | 现役主流家用/商用空调 |
| R32 | 二氟甲烷 | $\ce{CH2F2}$ | 新一代家用空调（微可燃） |
| R290 | 丙烷 | $\ce{C3H8}$ | 可燃天然工质，小型系统 |
| R717 | 氨 | $\ce{NH3}$ | 大型冷库、工业制冷 |
| R744 | 二氧化碳 | $\ce{CO2}$ | 跨临界循环，车用/热泵 |

**辨析｜易错点：** R410A 与 R22 都是常用空调制冷剂，但**绝对不能混用、也不能用同一套表**。R410A 压力明显高于 R22（同温度下高约 60%），充注工具、压力表、安全阀必须专用，否则表炸管裂。维修前先看铭牌，是这一行的铁律。<span class="marginnote">混用制冷剂的后果比想象严重：不同制冷剂沸点、压力不同，混在一起会改变共沸点，使系统压力异常、效率下降，还可能把压缩机油膜冲刷掉导致烧机。发现混用，只能回收全部、重抽真空、重新充注。</span>

## 2 制冷剂家族：从氟利昂到天然工质

按化学性质与环保指标，制冷剂分几个家族：

**CFC（氟氯烃）**：如 R12，含氯，对臭氧层破坏最大（ODP 高），已被《蒙特利尔议定书》全球淘汰。<span class="marginnote">ODP（臭氧消耗潜能）以 R11 为 1 的相对值；GWP（全球变暖潜能）以 CO₂ 为 1 的相对值。维修工记两个数就够：R22 的 ODP 约 0.055、GWP 约 1810；R32 的 ODP 为 0、GWP 约 675。</span>

**HCFC（含氢氯氟烃）**：如 R22，含氯但分子里含氢，在大气中寿命较短，属「过渡工质」，发达地区已停止新装，维修量正逐年减少。

**HFC（氢氟烃）**：如 R134a、R410A、R32，不含氯、ODP 为 0，但 GWP 仍高。其中 R32 可燃性低（A2L 级别），正成为家用空调主流。

**HFO（氢氟烯烃）**：如 R1234yf，含双键、在大气中很快分解，GWP 极低，用于新一代汽车空调。

**天然工质**：R290（丙烷）、R717（氨）、R744（CO₂），GWP 低或为零，但各有脾气——丙烷可燃、氨有毒、CO₂ 压力极高。<span class="marginnote">氨（R717）是可燃的误解要纠正：氨本身不燃烧，但在空气中浓度 16%～25% 时遇明火会爆炸；它的「毒性」才是主要约束。氨系统要用专用无缝钢管与氨阀，绝不能与铜直接接触。</span>

把家族沿革串起来，是一条清晰的环保线索：**ODP 管臭氧层，GWP 管气候，新一代工质两样都要低**。维修工不必背全套数据，但要知道手里这台机器的工质处在哪一代，因为它决定能用的表、能换的件、能充的氟。

## 3 制冷剂的关键特性：怎么判断它好不好

挑选与使用制冷剂，看四个维度：

**沸点与潜热**：标准沸点落在使用温度附近；单位质量汽化潜热越大，同样流量搬的热越多。R22 汽化潜热大，所以老系统「一次充注管很久」。
**临界温度**：必须远高于冷凝温度，否则无法靠冷凝液化。CO₂ 的临界温度只有 31 ℃，所以空调工况必须走「跨临界循环」——这是 R744 系统设计特殊的根源。<span class="marginnote">临界点之上没有「汽液之分」，只有超临界流体。维修 CO₂ 系统时，高压侧压力动辄 8～12 MPa，必须用专用耐高压设备和管件，普通 R22 工具不能碰。</span>
- **安全性**：分毒性（A 无毒 / B 有毒）与可燃性（1 不燃 / 2 可燃 / 3 易燃易爆）两轴。R22、R134a、R410A 都是 A1（无毒不燃）；R32 是 A2L（低可燃）；R290 是 A3（易燃）。可燃工质充注、检漏、通风都有额外要求。
- **与润滑油、材料的相容性**：制冷剂不能与压缩机润滑油、橡胶密封件、干燥剂起反应。R134a 与矿物油不相溶，必须用酯类油（POE）——这就是「换 R12 为 R134a 必须彻底换油」的原因。

**辨析｜易错点：** 「R32 微可燃，是不是不安全？」恰恰相反，在规范作业下 R32 是安全的——它火焰传播慢、所需引燃能量高。真正的危险来自**违规动火**：在充注 R32 的现场使用明火或电焊而未排空系统。安全的核心是「通风 + 排空 + 远离火源」，而不是因噎废食。

**选用总原则**：实际选工质，四件事一起权衡——**环保法规**（ODP、GWP 是否被限）、**能效**（同工况下 COP 高低）、**成本与可得性**、**与现有设备匹配**（压力等级、润滑油、密封材料）。没有「最好的制冷剂」，只有「这台设备最适合的制冷剂」；维修工更常面对的是「这台设备**原来用什么，就还用什么**」——代换必须做全套评估，而不是看压力差不多就充。

## 4 公式解析：制冷剂编号 R-number 的读法

**制冷剂的编号不是随机数字，而是一串编码的化学式——会读编号，就能反推出分子结构。**

对一碳、二碳类氢卤烃，编号规则是：**R-(a)(b)(c)**，其中：

$$
a = C - 1, \qquad b = H + 1, \qquad c = F
$$

- **第一步，读懂三个数字的含义**：$a$ 是碳原子数减 1，$b$ 是氢原子数加 1，$c$ 是氟原子数；其余价键由氯补齐。以 R22 为例：$a = 1$ → 碳数 $C = 2$？不对，这里要小心：当数字只有两位（R-22），默认碳数为 1，即 $a = 0$。<span class="marginnote">细节：R-22 实为「0-2-2」：碳数 = a+1 = 1，氢数 = b−1 = 1，氟数 c = 2，氯数 = 4 − 1 − 1 − 2 = 0？也不对——甲烷 CH₄ 只有 4 个键，这里氯数应为 4 − 1(碳) − 1(氢) − 2(氟) = 1，恰好是 $\ce{CHClF2}$。数字与分子式严格对得上。</span>
**第二步，反推分子式**：R-134a：碳数 = a+1 = 2，氢数 = b−1 = 2，氟数 = c = 4，氯数 = 0，分子式 $\ce{C2H2F4}$——与乙烷 C₂H₆ 相比，两个氢被氟顶替、另两个氢被氯顶替，正是一氟二氯乙烷家族的正确成员。<span class="marginnote">「碳数 = a+1、氢数 = b−1」这两个 +1/−1 是为了让甲烷（C1）编号从 R-10 起跳、让乙烷（C2）从 R-110 起跳，从而把卤代烃统一进一套编号里。记住这条规则，看铭牌上的 R 号就能估出工质的分子骨架。</span>

**第三步，读懂字母后缀与混配记号**：编号末尾的小写字母表示同分异构体——R-134a 与 R-134 化学式相同但结构不同，制冷工业只用 134a 这一种；R-404A、R-410A 等大写 A 表示由多种纯制冷剂**混配**而成的共沸/近共沸混合工质（R-410A 即 R32/R125 按 50/50 混配）。维修时看到「A」字样，就要意识到「这是一瓶混合工质」，充注必须按液态称重、整瓶使用，不能随意只补加其中一种组分。

## 5 载冷剂：把冷再搬一次的「二传手」

在一些大型系统里，制冷剂并不直接进用户空间，而是先在蒸发器里冷却一种中间介质，再由这种介质把冷送到远处——这个中间介质就是**载冷剂（secondary refrigerant / brine）**。<span class="marginnote">区分两个角色：<strong>制冷剂</strong>在系统内相变、是热量搬运的「主力」；<strong>载冷剂</strong>只做液体温度变化、不参与相变，是冷量输送的「二传手」。氟系统（分体空调、冷柜）没有载冷剂，水系统（中央空调冷冻水、冷库盐水）才有。</span>

**为什么需要载冷剂**：把冷量集中产生、再分头输送，好处是——制冷机组可以集中布置、远离用冷现场；制冷剂管路大幅缩短、充注量减小、泄漏风险降低；用户空间里只有水或盐水、没有制冷剂，卫生又安全。代价是多了一个「中间环节」，换热温差损失使系统效率略降。

按使用温度，常见载冷剂分三档：

| 载冷剂 | 适用温度范围 | 特点 |
| --- | --- | --- |
| 水 | 0 ℃ 以上 | 比热大、无毒、最便宜；只能用于冷冻水系统 |
| 氯化钠 / 氯化钙盐水 | 0 ℃ 以下（约 −20 ℃ 上下） | 冰点随浓度升高而降低，对金属腐蚀强，需加缓蚀剂 |
| 乙二醇 / 丙二醇水溶液 | −10～−40 ℃ | 防腐、不冻，黏度随低温增大、换热略差；丙二醇无毒，用于食品冷库 |

**载冷剂的选型与保养**：第一看凝固点——**凝固点必须比最低使用温度低 5～10 ℃**，否则在低温端结冰堵管；第二看腐蚀性——盐水系统要定期检查 pH 值、补加缓蚀剂，乙二醇系统要防止氧化变酸；第三看粘度——温度越低粘度越大、泵耗越高，浓度不是越高越好，够用即可。<span class="marginnote">「浓度越高越保险」是常见误区：乙二醇浓度过高，过了共晶点后冰点反而回升、黏度剧增、换热恶化。按设计浓度配、用冰点仪抽查，才是正路。</span>

**辨析｜易错点：** 有人把「载冷剂」与「制冷剂」混为一谈，问「冷库用氟还是用盐水」——两者不是替代关系，而是同一套系统里的两个环节：氟利昂在机组内循环制冷，盐水或乙二醇在冷库内循环送冷。判断一套水系统「要不要加防冻液」，看的是**最低环境温度 vs 水的冰点**，而不是看制冷剂型号。

**一台中央空调水系统的实例**：主机在机房用氟利昂制冷，蒸发器把 7 ℃ 的冷冻水送进大楼各层风机盘管；盘管风机把室内空气吹过冷冻水盘管，风就变冷。这里的载冷剂是水，只在 7～12 ℃ 之间变化，不结冰、无腐蚀，是水系统里最省心的方案。而冷库的盐水系统则相反——盐水要承受 −18 ℃ 甚至更低的库温，必须用凝固点足够低的盐水或乙二醇，且随库温变化定期复测浓度。**同是「水系统」，冷冻水与盐水是两种完全不同的维护对象**：前者防的是管道结垢与微生物滋生，后者防的是腐蚀与结冰。

## 6 小结

- **制冷剂**是系统的血液，编号即化学式；家族沿环保线索演进：CFC → HCFC → HFC → HFO/天然工质，ODP 管臭氧、GWP 管气候。
- **四大判据**选制冷剂：沸点与潜热、临界温度、安全性（毒性与可燃两轴）、与润滑油及材料的相容性。
- **R 编号可反推分子式**：碳数 = a+1、氢数 = b−1、氟数 = c、氯补齐；末尾大写 A 表示混合工质，必须按液态称重整瓶充注。
- **载冷剂**是水系统的二传手：水、盐水、乙二醇三档按温度选；凝固点留 5～10 ℃ 余量，防腐蚀、控浓度。
- **不能混用的铁律**：R410A 与 R22 不同表、不同工具；换工质必须评估润滑油、干燥剂与全部密封件。
- **混合工质充注纪律**：带 A 字尾的共沸/近共沸工质必须整瓶、按液态称重充注，绝不允许只补加其中一种组分。
- **载冷剂与制冷剂分工**：一个相变搬热、一个显热送冷；冷冻水防结垢，盐水防腐蚀与结冰，乙二醇防氧化，维护对象各不相同。
- **要背的三组数字**：R22 常温吸气侧约 0.4～0.6 MPa、排气侧约 1.5～1.8 MPa；R410A 约高 60%；R134a 介于两者之间——第一眼就能判断「这台机器跑的是什么血」。
- **环保责任**：维修放空要用回收机把冷媒抽回钢瓶，而不是直接排空——既守法规，又省钱。

**冷媒回收与环保**：维修排放制冷剂会直接贡献温室效应，R22 还破坏臭氧层。规范操作是**回收再充注**：换机、维修放掉系统时，用回收机把制冷剂抽回钢瓶，而不是直接排空。这既是环保责任，也省钱——一瓶新冷媒的价格，往往比回收设备的一次折旧还贵。
