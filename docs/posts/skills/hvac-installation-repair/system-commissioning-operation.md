## 为什么从调试开始

系统充好氟，第一次通电运行，这是安装工程的「大考」。调试（运行调试与工况调整）就是这场考试：不仅要让系统「转起来」，还要让它**在最合理的工况下转**——蒸发温度、冷凝温度、过冷度、过热度、风量水量都落在设计区间。调试质量直接决定系统效率、寿命与舒适度。

这一篇的线索是「**测量 → 判断 → 调整 → 复测**」的闭环：先量一组运行参数，对照正常范围找偏差，再针对偏差调整（膨胀阀、风量、水量），调整后复测确认。调试不是「碰运气调」，而是一套可复盘的诊断方法。

## 1 试机启动：从盘车到稳定运行

首次通电启动，按节奏来，别一上来就全速：

1. **启动前复查**：确认检修阀开闭正确、排水畅通、滤网装好、风机与压缩机接线无松动；用手盘动风机与压缩机，确认无卡阻（小型机盘风机即可，压缩机由电气保护把关）。
2. **点动**：压缩机通电 1～2 秒立即断电，听声音、看转向——反转（三相）或异常声响立即排查。<span class="marginnote">三相压缩机反转不会立即烧毁，但反转时无吸排气、电流异常、噪声大。点动确认转向正确，是保护压缩机免遭「假启动」磨损的第一道防线。</span>
3. **启动运行**：确认正常后通电运行，观察启动电流是否瞬间过大、有无异响、有无漏氟气味。启动电流通常为额定电流的数倍，几秒内回落——若持续高电流不下，说明启动困难或负荷异常，先查电气再查机械。
4. **稳定观察**：让系统运行 15～30 分钟，等参数稳定（压力、温度趋于平稳）后再开始测量记录。刚启动时参数波动大，测早了会误判。<span class="marginnote">「运行 20 分钟后再读数」是调试的时间纪律：制冷剂在系统内要循环若干圈才能建立稳定工况，过早读的压力温度只是过渡值。等压缩机启停一两次循环后再测，才有代表性。</span>
5. **整机检查**：运行稳定后，绕机组走一圈：听有无异常噪声（气流声、机械声、电磁声）、摸压缩机与排气管温度是否正常、看有无结霜异常（正常是蒸发器均匀薄霜，压缩机壳不应大范围结霜）。

**易错点：** 启动时发现压缩机「嗡嗡响但不转」，立即断电！这是启动不良（电容坏、绕组问题、抱轴）的信号，长时间通电会烧启动绕组。先查启动电容、再查机械卡阻，而不是反复通电试。

## 2 运行参数的测量与读盘

稳定运行后，采集一组「运行参数全家福」：

| 参数 | 测量工具 | 关注点 |
| --- | --- | --- |
| 吸气压力 / 蒸发温度 | 低压表 | 过低→欠充/堵/蒸发器结霜；过高→过充/负荷大 |
| 排气压力 / 冷凝温度 | 高压表 | 过高→散热差/过充/不凝气；过低→欠充/冷凝温度低 |
| 吸排气温度 | 热电偶/红外 | 过热度、排气温度是否超限 |
| 运行电流 | 钳形表 | 与铭牌额定电流对比 |
| 进出风温度 | 温度计 | 空调判温差，一般 ≥8 ℃（制冷） |
| 冷库库温 | 温度计 | 降温速度是否符合设计 |

读数要「同时记」——压力、温度、电流、进出风温在同一时刻采一组，才有诊断价值。孤立读一个数（比如只看吸气压力）很难定位问题。<span class="marginnote">「同时读一组」与第 14 篇充注判断的「证据链」是一套方法论：单参数会骗人，多参数互相印证才可信。这份「运行参数记录」也是第 16 篇竣工验收的数据基础。</span>

**读盘心法**：把测得的蒸发温度、冷凝温度代入压焓图的逻辑（第 1 篇），判断循环走得好不好；再结合过冷过热（下一节），就能定位问题在「充注量、节流、换热、风量」中的哪一个环节。

测量技巧：吸气管温度用热电偶贴在管壁并包保温棉，读数才接近管内气体温度；红外测温枪测的是表面温度，用于快速粗查、不用于精确判断。压力表读数要等表针稳定后再读，防止刚开阀的冲击值误导。风量用风速仪在出风口多点测量取平均，或用风量罩直接读。<span class="marginnote">「测点选得对不对」决定「读数可信不可信」：吸气管温度要测压缩机吸气口附近（远离分液头与蒸发器出口，那里还带着低温液体）；冷凝温度用排气压力反查饱和表，比直接测管温更准。</span>

## 3 公式解析：过热度与过冷度

**过热度与过冷度是调试手里最灵敏的两把尺子——它们把「系统状态」翻译成两个可测的温度差。**

$$
SH = T_{\mathrm{suction\ line}} - T_{\mathrm{evap\ sat}}, \qquad SC = T_{\mathrm{cond\ sat}} - T_{\mathrm{liquid\ line}}
$$

- **第一步，读符号**：$SH$（superheat）是过热度：吸气管温度 $T_{\mathrm{suction\ line}}$ 减去蒸发饱和温度 $T_{\mathrm{evap\ sat}}$（由吸气压力查饱和表得）。$SC$（subcooling）是过冷度：冷凝饱和温度 $T_{\mathrm{cond\ sat}}$（由排气压力查饱和表得）减去液管温度 $T_{\mathrm{liquid\ line}}$
