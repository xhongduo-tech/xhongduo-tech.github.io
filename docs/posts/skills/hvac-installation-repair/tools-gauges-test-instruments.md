## 为什么从工具开始

前四篇立住了「机器怎么转、人怎么规范」，这一篇认识**干活的手**。制冷空调安装维修的工具分两拨：一拨是「把系统装起来」的管路与焊接工具，一拨是「看清系统状态」的检测仪器。前者的功夫在手上，后者的功夫在读数。很多维修新手的问题不是不懂原理，而是**拿错工具、用错量程、读错单位**——明明压力正常，却因表压/绝对压力没换算而误判系统缺氟。

这篇把常用工具按「干什么活」分类梳理，并给出每样工具的使用要点与禁忌。工具不值钱，**会用工具的判断值钱**——这也是初级工考核的核心内容。

## 1 工具的分类：四套工具包

按作业内容，工具可分成四组，各自服务于制冷循环的一段：<span class="marginnote">这四组划分与《国家职业技能标准》初级的「工具设备使用」考核模块对应：管路工具、焊接工具、电气工具、检测仪器，逐项考核。</span>

| 工具包 | 主要工具 | 对应作业 |
| --- | --- | --- |
| 通用工具 | 开口/梅花扳手、内六角、螺丝刀、钳类 | 拆装紧固、面板开合 |
| 管路工具 | 割管器、扩口器、胀管器、弯管器 | 铜管切割、喇叭口制作、弯管 |
| 焊接工具 | 焊炬（氧气+燃气）、钎料、焊膏 | 铜管钎焊连接 |
| 检测仪器 | 歧管压力表、温度计、万用表、钳形表、检漏仪、真空计 | 测压测温、测电检漏 |

原则：**用对工具、不凑合**。用活动扳手拧六角阀、用锤子敲扩口、用普通钳子代替割管器——这些「图省事」的做法是漏氟、裂管、划伤喇叭口的根源。

工具与仪器还有个共同点：**它们是耗材，也是资产**。刀刃会钝、表会失准、软管会老化，定期检查与更换不是浪费，而是对施工质量的投资。一台用了十年的割管器切出的口，跟新刀的差别肉眼可见——而这份差别最终会反映在喇叭口和气密性上。

## 2 管路加工工具：三分技术，七分工具

管路作业的质量决定系统气密性，而气密性又决定系统寿命。三样工具是管路工的「三件套」：

**割管器（切管器）**：旋转割刀沿铜管外圆周进刀切割。使用要点：割刀与管轴垂直、每次进刀量小、边割边转；割完用**倒角器**去除管内毛刺。<span class="marginnote">用钢锯切铜管是禁忌：锯口不平、毛刺易脱落进入系统，成为堵塞膨胀阀、划伤压缩机阀片的异物。割管器切完必须倒角，否则毛刺就是隐患。</span>

**扩口器（喇叭口工具）**：把铜管端部扩成喇叭形，用于喇叭口连接（螺纹锁紧）。要点：管子露出夹模的高度要严格按扩口器刻度，露多了扩出的大口易压裂，露少了喇叭口太小密封不足。**喇叭口是制冷系统的第一泄漏点**——扩口质量不过关，检漏永远查不完。<span class="marginnote">判断喇叭口好坏的标准：锥面光滑无裂纹、无褶皱、无偏心，锥角与接头锥面贴合。扩口前先在管口套上锁紧螺母——忘了套，扩完口就装不回去。</span>

**弯管器**：把铜管弯成所需角度而不塌瘪。要点：弯曲半径不小于管径的 3～5 倍，弯管器型号与管径匹配。铜管弯扁后截面变小、流动阻力骤增，等于给系统加了「隐性过滤器」。

**胀管器**：把管口胀大以便套接（管对管套焊、套管口）。用于焊接收口时，胀口深度与过盈量要合适，胀裂或过松都会影响焊接质量。胀管时先退火软化铜管、再分次胀到目标尺寸，一次胀到位容易裂口。

## 3 检测仪器：系统的「眼睛」

检测仪器把看不见的状态变成看得见的读数，是故障诊断的前提：

| 仪器 | 测什么 | 使用要点 |
| --- | --- | --- |
| 歧管压力表（复合表） | 吸排气压力 | 三阀两表，先对表、再接高压侧 |
| 温度计（红外/热电偶） | 进出风温、管壁温度 | 测管温用热电偶贴紧，红外测表面 |
| 万用表 | 电压、电流、电阻、通断 | 先选对档位与量程，表笔插对孔 |
| 钳形电流表 | 运行电流 | 卡单根导线，不能卡两根 |
| 电子检漏仪 | 制冷剂泄漏 | 预热、调灵敏度、探头慢速移动 |
| 真空计 / 真空泵 | 系统真空度 | 抽真空时测绝压，单位 mbar/Pa |

**辨析｜易错点：** 万用表测电流必须**串联**在回路里，而钳形表是**卡钳**在单根导线上，不需要断开电路。新手用万用表电流档去「卡」导线，等于短路烧表。记住分工：**测电流用钳形表，测电压电阻通断用万用表。**

检测仪器的共同准则是**先校准、再读数**：压力表要回零检查，温度计要与标准温度核对，检漏仪要在新鲜空气中调零。仪器读数不可靠，后面的诊断全部建立在沙滩上。<span class="marginnote">这个「先校准再读数」的习惯，与第六级《工程技术》里仪表仪控专题强调的「计量溯源性」是一回事——现场快速判断可以不精密，但方向不能错。</span>

**量具**另成一族：游标卡尺量管径壁厚、千分尺量配合间隙、水平尺校正机组水平、塞尺量间隙。它们虽然不直接读数「状态」，却决定了装配质量——压缩机找正（第 2 篇）、阀组装配（第 4 篇）都要靠量具把关。量具用前要校零，卡尺测外径用外爪、测内径用内爪、深度用深度尺，读数要估读一位。

## 4 公式解析：表压与绝对压力的换算

**制冷压力表读的是「表压」，而热力学公式用的是「绝对压力」——这一换算没搞清，读数就会误导整个判断。**

$$
p_{\mathrm{abs}} = p_{\mathrm{gauge}} + p_{\mathrm{atm}}
$$

- **第一步，分清两种压力**：表压 $p_{\mathrm{gauge}}$ 是压力表读数，它以大气压为基准（大气压时读 0）；绝对压力 $p_{\mathrm{abs}}$ 以绝对真空为基准，热力学计算、饱和温度查表都用它。标准大气压 $p_{\mathrm{atm}} \approx 0.1013\ \mathrm{MPa}$。<span class="marginnote">R22 在 0 ℃ 的饱和绝对压力约 0.498 MPa，换算成表压约 0.397 MPa。歧管表上标的就是表压，查温度对应关系时心里要加回一个大气压。</span>
**第二步，算一遍**：某空调 R22 系统吸气表压 0.4 MPa，则绝对压力 $p_{\mathrm{abs}} = 0.4 + 0.1013 \approx 0.501\ \mathrm{MPa}$，查 R22 饱和表对应约 0 ℃ 蒸发温度。若有人直接拿 0.4 MPa 去查表，查到的蒸发温度约 −2 ℃，判断就会偏冷，导致误加制冷剂。
**第三步，记住负压区**：抽真空时表压为负（如 −0.1 MPa 即接近绝对真空），此时 $p_{\mathrm{abs}}$ 接近 0。真空度的工程表达常用**真空计读数**（绝对压力）而非表压，单位为 mbar、Pa 或 mmHg（Torr）——单位换算见真空计铭牌，不要混用。<span class="marginnote">系统正常运行时，吸气侧表压为正；只有抽真空或运行在极低蒸发温度时才会出现负压。看到吸气表负压长期存在，多半是管路堵、制冷剂严重不足或蒸发器结霜，不是「真空度好」。</span>

## 5 仪器的量程选择与读数纪律

再好的仪器，量程用错也是灾难：

**万用表**：测电压先估电压范围，选 AC/DC 正确档位；测电阻必须断电；测通断在断电下进行。表笔插孔要插对（COM 与 V/Ω 孔），插错电流孔去测电压会烧表。
**钳形表**：选量程大于运行电流 1.5 倍的档位，钳口完全闭合、不夹两根线、不夹带电裸线过近。<span class="marginnote">钳形表只卡一根相线才测得准：同时卡住火线与零线，两电流大小相等方向相反，磁场抵消，读数会「看起来没有电流」——这是测错电流最经典的乌龙。</span>
**电子检漏仪**：在通风处开机预热并调零，探头距疑似泄漏点 3～5 mm、移动速度约每秒 2～3 cm；检测 R410A 等高压制冷剂要选对应频率的检漏仪，普通卤素检漏仪可能误报。
**压力表**：歧管表高压侧接液管/排气侧，低压侧接吸气管。**接错高低压侧会瞬间打表**，损坏表头甚至炸表。<span class="marginnote">分体空调维修的歧管表有颜色区分：蓝色低压、红色高压、黄色中间接真空泵/充注瓶。接表前先确认系统压力不高、表阀关闭，再接软管，逐根排空软管内空气。</span>

对压力表的量程选择，一个实用经验：**表的最大量程约为正常读数的 2 倍**。R22 系统低压表常用 −0.1～1.8 MPa，高压表 0～3.8 MPa；R410A 压力更高，要用专用高压表。用 R22 表测 R410A，读数可能直接顶表，既测不准又不安全——这又回到了第 3 篇的「认工质、选对表」。

读数纪律只有一条：**同一组判断用同一组校准过的仪器、同一套单位**。混用两把表、混用 psi 与 MPa、混用 ℃ 与 ℉，都会让「对比读数」失去意义。维修单上记录压力时，要同时记下压力值、单位与对应的制冷剂型号——这样回头翻记录，任何一行数据都自洽可读。

最后提一个易被忽略的细节：**软管与接头的密封**。充注软管接头处的橡胶密封圈会老化，接表后应用肥皂水检漏；软管内部若残留制冷剂或水分，会污染系统。规范做法是软管接歧管表后先排空，再连接系统——这一小步，能省下后面「系统进水」的大麻烦。

## 6 工具保养与安全

工具与仪器的寿命，取决于保养习惯：

割管器、扩口器用后擦净、上油防锈；刀具钝了及时换片。
压力表、真空计属于精密仪器，严禁摔打，软管用后盘好、阀口加盖防尘。
万用表长期不用要取出电池，防漏液腐蚀。
焊炬与气瓶要定期检漏：气瓶直立固定、远离热源，氧气瓶与燃气瓶间距保持安全距离，用后关闭总阀。<span class="marginnote">焊炬回火（火焰缩回软管）是危险事故，预防靠「先开燃气点火、再开氧气调节」的操作顺序，以及用后先关氧气阀、再关燃气阀。回火时先关氧气阀切断回燃。</span>
- 检漏仪、电子秤等电子设备防潮防尘，按说明书校准周期送检。

**安全底线：工具不代用、气瓶不歪放、仪表不超量程、现场不留火种。** 这几条与上一篇的职业安全规范互为表里——工具安全就是作业安全的一半。工具上的一点锈蚀、一点油污、一点失灵，都可能在一个最不合适的瞬间变成事故导火索。

## 7 小结

- 工具按作业分四组：**通用、管路、焊接、检测**，用对工具、不凑合是第一条纪律。
- 管路「三件套」**割管器、扩口器、弯管器**决定系统气密性；喇叭口是头号泄漏点。
- 检测仪器是系统的眼睛：**钳形表测电流、万用表测电压电阻、歧管表测压力**，分工不可混。
- 表压与绝对压力换算 $p_{\mathrm{abs}} = p_{\mathrm{gauge}} + p_{\mathrm{atm}}$：表压以大气为基准，抽真空与饱和表读的是绝对压力，别混。
- 量程选择纪律：**测什么选什么量程，读数落在满量程的 1/3～2/3**——量程选错，读数白测。
- 工具保养：**表阀不紧拧、刀具不落地、仪器防潮防摔**，工具是你的另一双手。
- 一表一笔一记录：**读数当时记、当场记**，别靠「回去再记」——现场数据过了就回不来了。

- 钳形表测电流的注意：**卡口完全闭合、导线居中、先选大量程再降档**——开口测、偏心测都偏低。
- 歧管表的「高/低/中」三口：**高压表接排气、低压表接吸气、中间口接泵/瓶**——接错口，读数全错。
- 电子秤在充注中的角色：**精确充注以称重为准，表压只作参考**——这是定量的底气。
- 工具的「归位」文化：**用一件还一件、下班前清点**——工具不丢，是老师傅的基本功。
