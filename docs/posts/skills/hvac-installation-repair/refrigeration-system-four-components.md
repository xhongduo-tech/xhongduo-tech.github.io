## 为什么从四大部件开始

上一篇我们把制冷循环画成压焓图上的封闭折线，这一篇给折线的四条边装上实体零件：**压缩机、冷凝器、节流装置、蒸发器**。它们是制冷系统的一切——所谓安装，就是把这四样东西用管路连成回路；所谓维修，就是判断「哪个零件没干好它的活」。修理空调不修这四样，等于没修。

学这一篇的重点不是背零件名称，而是建立**「部件＝一段循环过程」**的对应：每个部件只负责压焓图上一段线的变化，现场看一眼某个部件的进出口温度，就能说出这一段线走得对不对。<span class="marginnote">这套「部件与循环过程一一对应」的思维，和上一篇「压力是温度的影子」共同构成维修判断的两把尺子。</span>

本文的叙述顺序刻意与制冷剂的流动方向一致：从压缩机出发，沿排气管到冷凝器、经液管到节流装置、再经蒸发器回到压缩机。跟着工质走一遍，四大部件的边界就自然记牢了——这也是安装时布管、检修时查表的工作路径。

## 1 压缩机：系统的「心脏」

**压缩机（compressor）**：把来自蒸发器的低温低压制冷剂气体吸入、压缩成高温高压气体，为整个循环提供动力与压差。它消耗的电能，正是上一篇公式里分母上的那份功 $W$。

按压缩原理分，现场最常见的有三类：

| 类型 | 结构要点 | 常见场合 |
| --- | --- | --- |
| 活塞式 | 曲柄连杆推动活塞往复压缩 | 冰箱、中小型冷库、车用空调 |
| 涡旋式 | 一动一静两个涡旋盘相互啮合 | 家用/轻商空调、热泵热水器 |
| 螺杆式 / 离心式 | 螺杆啮合或叶轮离心 | 大型中央空调、工业冷源 |

**辨析｜易错点：** 新手常以为「压缩机越贵越好」。压缩机选型匹配的是**制冷量与冷凝温度区间**——涡旋机在高压缩比下效率骤降，活塞机在低转速下振动大，离心机在小负荷下会喘振。安装时乱换大一号的压缩机，往往不是「更有劲」，而是排气温度过高、润滑油结焦、很快烧机。**选型看设计工况，不看出力。**

压缩机的两个「进出口身份」务必记牢：吸气口接蒸发器出口（低压制冷剂气体），排气口接冷凝器进口（高压气体）。装反了，压缩机立刻液击或超压损坏。

## 2 冷凝器：把热交给环境的「散热器」

**冷凝器（condenser）**：高温高压的制冷剂气体在此向环境放热，凝结为液体。它对应压焓图上的 2→3 水平左段，放出的热量记作 $Q_k$。<span class="marginnote">冷凝热量不是制冷量！热力学第一定律要求 $Q_k = Q_0 + W$：冷凝器放出的热 = 从被冷却对象吸的热 + 压缩机消耗的功。所以室外机吹出的风比环境热，是双重贡献。</span>

按冷却介质分：

**风冷式**：靠风机吹翅片散热。家用空调、小型冷库多用。维修要点：翅片结灰、风机停转是它效率下降的头号原因。
**水冷式**：靠冷却水在管壳间带走热量。中央空调、中大型机组多用。维修要点：冷却塔结垢、水质差会让换热面结水垢，冷凝压力随之升高。<span class="marginnote">水冷系统的结垢用「温差判断」：冷却水进出温差过大或冷凝压力异常升高，都指向水侧结垢——这是第 6 篇冷凝器安装与日常保养的重点。</span>
**蒸发式 / 淋激式**：水蒸发吸热辅助散热，节水但维护复杂，多用于缺水地区的大型装置。

**过冷段**：冷凝器下部常保留一段液体，让饱和液体再降温几度（过冷），保证节流装置前是纯液相。维修中看到液管烫手或过冷度不足，第一嫌疑是制冷剂充注量偏少。

## 3 节流装置：压焓图上的「减压阀」

**节流装置（throttling device）**：把来自冷凝器的高压液体降压降温，变成低温低压的湿蒸气送入蒸发器。它对应压焓图上的 3→4 竖直向下段，**节流前后比焓不变**（等焓过程 $h_3 = h_4$）——它只降压、不换热、不做功。<span class="marginnote">节流是「等焓降压」而非「等熵膨胀」：理想等熵膨胀本可回收一部分功，但等焓节流简单可靠、无运动件，工程上几乎都用它。代价是损失一点理论效率——维修工知道这一点即可，不必在原理上纠结。</span>

三种常见形式：

**毛细管（capillary tube）**：细长铜管，靠管内流动阻力降压。冰箱、小型空调用，结构最简单，但不能调节，工况变化时适应性差。
**热力膨胀阀（TXV）**：靠感温包检测蒸发器出口过热度，自动调节开度。中小型制冷装置最常用，是维修训练的核心对象。<span class="marginnote">热力膨胀阀的感温包必须紧贴蒸发器出口管、并包裹保温，否则测不准过热度，阀会「乱开」——这是安装时的经典细节，也是后期蒸发器供液不正常的常见根源。</span>
**电子膨胀阀（EEV）**：步进电机驱动，由控制器按目标过热度精确调节。变频空调、大型机组多用，响应快、可调范围大。

节流装置选型与维修的核心是**过热度（superheat）**：阀开得过大，过热度过小甚至回液（液击危险）；开得过小，过热度过大，蒸发器用不满、制冷量不足。调阀本质上就是调过热度。

## 4 蒸发器：把冷交给对象的「吸热器」

**蒸发器（evaporator）**：低温低压的制冷剂液体在此吸收被冷却对象的热量，沸腾为气体。它对应压焓图上的 4→1 水平右段，吸热量即制冷量 $Q_0$。

按结构分：

**直接蒸发式（干式）**：制冷剂在管内蒸发，空气/水在管外被冷却。空调室内机、风机盘管的翅片盘管都是这种，维修重点是翅片清洁与气流组织。
**满液式 / 沉浸式**：管束浸在待冷却液体（如水、盐水、冷水箱）中，液体沸腾充分，换热效率高，但回油与液位控制较复杂，多用于中大型机组。<span class="marginnote">满液式蒸发器有一个液位问题：液位过高会带液到压缩机，液位过低换热面积浪费。这也是为什么满液式系统要有专门的液位计与回油装置。</span>

蒸发器最重要的运行指标是**蒸发温度与过热度**。蒸发温度由吸气压力决定（饱和对应关系），过热度由膨胀阀控制。现场看蒸发器「结霜均匀程度」：霜层均匀而薄，说明供液与换热带匹配良好；结霜只在一端、另一端干，说明供液分配不均或制冷剂不足。<span class="marginnote">注意：蒸发温度低于 0 ℃ 时结霜是正常的（这是「把霜去掉才能吸热」的反直觉之处）；真正要警惕的是蒸发器结冰成坨——那是除霜系统失效，见第 5 篇化霜章节。</span>

对空调类设备，蒸发器还多一个身份：它同时是**空气处理器**。冷媒在管内蒸发，风机把室内空气抽过翅片、被冷却后送回房间。于是蒸发器有两套「脏」：管内是油垢与水分的化学脏，管外是灰尘与纤维的物理脏——前者靠系统清洗（第 4 篇），后者靠拆洗滤网与翅片（日常保养）。判断蒸发器该清哪边，先看是制冷变差还是风量变小。

## 5 公式解析：压缩机理论输气量与系统热平衡

**压缩机的「个头」决定系统能搬运多少热量，输气量是选型与判断缺氟的出发点。**

对活塞式压缩机，理论输气量（单位时间扫过的气缸容积）为：

$$
V_h = \frac{\pi}{4} D^2 \, S \, z \, n
$$

- **第一步，读符号**：$D$ 是气缸直径（m），$S$ 是活塞行程（m），$z$ 是气缸数，$n$ 是转速（r/s）。直径平方乘以行程，就是单缸单次扫过的圆柱体积；再乘气缸数与转速，就是一秒的总扫过容积。<span class="marginnote">这台压缩机铭牌上的「排量」往往就是这个 $V_h$ 的工程简化（以 mL/r 或 cm³/rev 表示）。排量越大，能撬动的制冷量越大——但前提是吸气密度不变，密度又与蒸发温度挂钩。</span>
- **第二步，理解实际与理论的差**：实际输气量总小于 $V_h$，因为有余隙容积、吸排气阀阻力、泄漏与吸气预热。两者之比叫**容积效率** $\eta_v$，一般 0.6～0.9。维修现场常听到「这台机子吸气不足」，多半是阀片漏气或余隙增大导致 $\eta_v$ 塌方，而不是电机没劲。
- **第三步，套上系统热平衡**：把循环整体看成黑箱，热力学第一定律给出：

$$
Q_k = Q_0 + W
$$

冷凝器放热 = 蒸发器吸热 + 压缩功。这条式子装维修工身上是一句口诀：**「室外机吹出的热，等于室内搬走的冷加上电费」**。它还能用来反推——若室外机排风很烫但制冷很差，说明 $Q_k$ 主要来自 $W$ 而不是 $Q_0$，即压缩机在「空转做功」，大概率是制冷剂泄漏或蒸发器堵塞。

## 6 四大部件的一体化思维

四个部件不是孤立的零件，而是同一回路上的四个边界条件——**任何一个的工况改变，都会顺着管路传导到其他三个**：

- 冷凝器散热变差 → 冷凝压力升高 → 压比增大 → 压缩机负荷与排气温度升高 → 制冷量下降。
- 蒸发器结霜 → 蒸发温度下降 → 吸气压力降低 → 单位制冷量下降 → 压缩机输气不足 → 冷凝器负荷也变小。
- 节流阀堵塞 → 蒸发器供液不足 → 过热度猛增 → 吸气温度升高 → 压缩机排气温度过高 → 润滑油结焦。

这就是为什么维修要先「看整体、后拆零件」：先量吸排气压力、过冷过热、电流，判断故障落点在哪个环节，再动手拆。**故障不会只坏一个部件——它总是从某个边界条件开始，沿着回路扩散。**

举一个最常见的连锁：某冷库「不制冷」，新手拆下膨胀阀清洗，装上依旧。老手先量吸气压力——发现只有 0.1 MPa（正常 0.25 MPa 左右），再看蒸发器结霜——只结半排，推断供液不足。检查发现干燥过滤器前后温差大、表面发凉，拆下一看滤网堵死。**故障源头在过滤器，受害者却是膨胀阀与蒸发器**——这就是「边界条件传导」的现场教材。

## 7 小结

- 制冷系统由**压缩机、冷凝器、节流装置、蒸发器**四大部件构成，分别对应压焓图上的一段过程。
- **压缩机**做功抬压（活塞/涡旋/螺杆/离心），选型匹配设计工况，不能乱换大排量。
- **冷凝器**放热（$Q_k = Q_0 + W$），风冷看翅片与风机，水冷看结垢，过冷不足先怀疑充注量。
- **节流装置**等焓降压（$h_3 = h_4$），毛细管/热力膨胀阀/电子膨胀阀，核心是过热度调节。
- **蒸发器**吸热（$Q_0$）：翅片、风道、分液要均匀，蒸发不足会让过热度偏高、制冷量打折。
- 四大部件一体思维：**任一部件工况异常都会牵连全局**，诊断时把四大部件放回循环里一起看。
- 从「认识部件」到「会用系统」：**每一件都对应压焓图上的一段**，部件是零件、循环才是系统。

- 学习检查法：**对着压焓图默画循环、讲清每段对应哪个部件**——能讲清，才算真会了。

在下一节，四大部件认识完了，该认识在它们之间循环的「血液」了——这就是**制冷剂与载冷剂的种类与特性**。
