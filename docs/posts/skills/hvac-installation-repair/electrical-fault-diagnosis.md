## 为什么从电气故障诊断开始

制冷系统「不工作」的现场故障里，电气原因占了大半。上一节学了温控与化霜，这一节把电气故障的诊断方法系统化：**跳闸、烧保险、风机不转、温控失灵、接触器不吸合**——这些高频故障怎么查、怎么测、怎么安全地修。电气维修的最大特点：**看不见摸不着，全靠测量推理**。而测量推理的前提是安全——断电、验电、放电，一步不能省。

这一篇从「故障分类」出发，建立「**现象 → 怀疑 → 测量 → 定位 → 处理**」的通用排查路径。

## 1 电气故障的四大类

电气故障归根结底是四类：

| 类型 | 本质 | 典型表现 | 危险度 |
| --- | --- | --- | --- |
| 短路 | 不该通的导体相通 | 跳闸、烧保险、冒烟 | 高，先断电 |
| 断路 | 该通的导体断了 | 设备不转、无电 | 低 |
| 漏电 | 电流漏向机壳/地 | 麻手、漏保动作 | 高，危及人身 |
| 过载 | 电流超过额定 | 保护动作、发热 | 中 |

**短路**：相线与零线（或相间）直接相碰，电流骤增，断路器/熔断器动作。短路点常出现在：接线端子松动碰触、线皮破损、电机绕组击穿、电容击穿。<span class="marginnote">短路排查的安全前提：先断开电源，用万用表电阻档分段量「相间/相对地是否导通」。带电查短路是极其危险的——短路瞬间的电流和电弧足以致命，务必先断电。</span>

**断路**：导线断裂、端子松脱、触点不闭合、保险熔断。断路排查用「电压法」或「通断法」逐段找「电断了在哪」。

**漏电**：绝缘破损使电流漏向机壳或大地。漏电保护器（漏保）动作、触摸机壳有麻电感。用兆欧表测绝缘电阻定位漏电点。

**过载**：电流超过额定（机械卡滞、电压过低、负荷过大、绕组匝间短路）。过载保护动作跳闸。

**易错点：** 短路与过载都让保护动作，但性质不同：短路是「瞬间大电流」，过载是「持续过流」。断路器跳闸后的复位尝试要区别对待——短路跳闸往往一合闸又跳（或冒火花），过载跳闸是运行一段时间后跳。**先分清是「一合就跳」还是「跑一会跳」，排查方向完全不同。**

## 2 保护跳闸与烧保险的排查

「一通电就跳闸 / 烧保险」，按以下路径查：

1. **分断排查**：把负载逐段断开（先断开压缩机、风机等），一段一段试——跳闸的段就是故障段。这是「分段隔离法」在电气上的应用。<span class="marginnote">分段隔离是短路排查的利器：断开所有负载，逐段合闸，哪一段「一合就跳」就锁定在哪一段。把故障从「整机」缩小到「一个段」，再在那一段里找具体短路点。</span>
2. **测量确认**：锁定的段内，断电用万用表电阻档量「相间、相对地」，看是否有低阻导通。
3. **常见短路点**：电机绕组（击穿短路）、启动电容（击穿）、接线端子（碰触）、线缆（破损）。

**过载跳闸（运行后跳）**：查运行电流是否超过整定（第 21 节）、电压是否偏低、机械是否卡滞、负荷是否过大（过充、压比高）。

**漏保动作（漏电跳闸）**：查绝缘——用兆欧表测各回路对地绝缘，找到绝缘破损处；同时查是否误接（零线地线接错）。<span class="marginnote">漏保动作有两类：真漏电（绝缘破损）与误动作（接错线、漏保本身坏）。判断方法：拔掉所有负载，若漏保仍跳，是线路或漏保本身问题；不跳，再逐个接回负载找漏电的那一台。</span>

**易错点：** 烧保险后「换根保险就完事」——保险是保护元件，烧断说明背后有异常（短路或过载）。不查原因直接换，新保险立刻再烧，还可能扩大故障。**换保险前必须找到并排除「为什么会烧」**。

## 3 风机不转与温控失灵的排查

**风机不转**（室内风机或冷凝风机）：

1. 查供电：风机端子有无电压（有电压不转 → 电机/电容问题；无电压 → 控制/供电问题）。
2. 查电容：风机多为单相，电容坏 → 不转或嗡嗡响，测电容容值。
3. 查电机：绕组电阻与绝缘（第 22 节）。
4. 查控制：温控/控制板是否给出风机启动指令，继电器是否吸合。<span class="marginnote">「有电压不转」和「没电压不转」是风机排查的第一分岔：有电不转，问题在风机本体（电容、绕组、轴承）；没电不转，问题在控制侧（温控、继电器、线路）。先测这一点，方向就对了。</span>

**温控失灵**（不启停、温度失控）：

1. 先看显示/设定：设定与显示是否正常（电子温控）。
2. 查传感器：NTC 阻值与温度对应（第 23 节），传感器线是否断。
3. 查执行：温控输出到压缩机/风机的信号是否到达。
4. 查控制板：供电、输出继电器、程序（最后才怀疑）。

**易错点：** 风机不转时，手摸电机发烫——先怀疑「电机烧了」，但发烫可能只是过载保护在保护（绕组没烧，保护器跳了）。等电机冷却、量绕组电阻与绝缘，才判断是真烧还是保护跳。**「烫」不等于「烧」，测量说了算。**

## 4 公式解析：接触不良与电压降

**很多「设备没劲、转速慢、启动难」的怪故障，根子是接触不良——接触电阻让电压降在了接头上。这条式子解释「为什么接触不良如此阴险」。**

$$
U_{\mathrm{drop}} = I \cdot R_{\mathrm{contact}}
$$

- **第一步，读符号**：$U_{\mathrm{drop}}$ 是接触点上的电压降（V），$I$ 是流过电流（A），$R_{\mathrm{contact}}$ 是接触电阻（Ω）。接触不良（螺丝松动、触点氧化、端子锈蚀）时，$R_{\mathrm{contact}}$ 变大，在接触点上吃掉一部分电压。<span class="marginnote">正常接线端子接触电阻极小（毫欧级），压降可以忽略；但松动、氧化后接触电阻可涨到几欧姆。电流越大，压降越明显——所以大电流的压缩机主电路，接触不良的危害远大于小电流的控制电路。</span>
**第二步，看后果链**：接触不良 → 接触点压降大 → 电机端电压不足 → 欠压运行 → 电流增大、转矩下降、发热。这就是「接线端子松了，压缩机启动困难、电流偏大、接线端子处发烫」的完整链条。**摸到接线端子发烫，就是接触不良的直观信号。**<span class="marginnote">排查方法：带电测「电源端电压」与「负载端电压」，两者之差就是 $U_{\mathrm{drop}}$——差值明显（如 >5 V）说明中间有接触不良。断电后再用电阻档量怀疑的端子，确认接触电阻偏大。</span>
**第三步，把式子用回维修**：遇到「设备启动无力、电流异常、端子发烫」，先查所有接线端子的紧固与氧化，再怀疑电机本身。**紧一遍螺丝、打磨一下端子，常常就修好了一台「以为要换电机」的机子**——这是成本最低、被忽略最多的维修。

## 5 测量方法与安全

电气测量的规范动作：

**测电压**：万用表电压档并联测量，先选大量程再逐步减小；带电测电压是电气测量最常见操作，注意表笔绝缘与手的位置。
- **测通断/电阻**：断电测量，用蜂鸣档测通断、电阻档测阻值。
- **测电流**：钳形表卡单根线（第 5 篇）。
- **测绝缘**：兆欧表，断电且设备已放电后测。

**安全纪律**（与第 4 篇呼应）：

1. **断电挂牌验电**：维修前断开电源、挂「有人作业禁止合闸」牌、验电确认无电。
2. **放电**：电容器、变频器母线必须先放电。
3. **单手操作**：带电测量时单手操作、另一只手不碰导体，穿绝缘鞋。
4. **一人操作一人监护**：高压/大设备维修要有人监护，紧急时能断电。<span class="marginnote">「单手测量、脚下绝缘、身旁有人」是带电作业的三条保命原则。低压（220 V）触电一样致命，不要因为「电压不高」就放松。</span>

**易错点：** 测绝缘电阻必须在断电状态——兆欧表自身输出高压，带电测绝缘会电击操作者、损坏仪表。

## 6 电气故障排查流程总结

把本篇内容收成一张排查流程图（记忆用）：

- **整机不工作** → 查电源进线 → 查保险/断路器 → 查控制电路供电。
- **一合就跳** → 短路：分段隔离 → 测相间/对地 → 找短路点。
- **跑一会跳** → 过载：测电流 → 查电压 → 查机械 → 查整定。
- **漏保动作** → 漏电：断负载 → 逐段测绝缘 → 找漏电点。
- **不转** → 先分「有电没电」：有电查电机/电容，没电查控制。
- **启动无力** → 查端子压降（U=I·R）→ 紧固端子 → 查电容。
- **温度失控** → 传感器 → 执行器 → 控制板。

这套流程的核心就一句话：**先测量、后判断；先排除最便宜的可能，再动最贵的部件。**

## 7 小结

- 电气故障四类：**短路、断路、漏电、过载**；短路危险、漏电危及人身，一律先断电。
- 跳闸排查用**分段隔离**；烧保险先查「为什么会烧」，换保险不查根因等于白换。
- 风机不转先分「有电没电」；电机发烫不等于烧毁，量过电阻绝缘再下结论。
- 接触不良公式 $U_{\mathrm{drop}} = I R_{\mathrm{contact}}$
