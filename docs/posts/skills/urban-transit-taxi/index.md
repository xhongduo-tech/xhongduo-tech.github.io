# 城市公共交通与出租汽车运营（公交/出租/网约车）

以《城市公共汽电车客运管理办法》《巡游出租汽车经营服务管理规定》和《网络预约出租汽车经营服务管理暂行办法》为纲，系统梳理从经营许可、车辆与驾驶员资格、运营服务规范到监督检查与法律责任的完整公共交通与出租汽车运营制度。学完这些章节，就写完了公交、巡游出租车与网约车运营管理的全部规范内容。
