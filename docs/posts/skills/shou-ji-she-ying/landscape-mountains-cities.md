## 为什么从风光摄影开始

人像篇解决了「怎么拍人」，风光篇回答「怎么拍世界」。**风光是手机摄影最公平的题材**——它不考验沟通、不挑剔设备，只考验三件事：**看得准、站得对、等得住**。<span class="marginnote">安塞尔·亚当斯把风光摄影称作「在正确的时间出现在正确的地点，然后耐心等待」。手机让「地点」的容错率变高了——随身带着、随手能拍——但「时间」与「耐心」依然不可替代：光线的黄金时刻、云海的出现、水面平静的瞬间，都是等出来的。</span>本节把风光拆成两类：**山水（自然风光）**与**城市建筑（人造风光）**。它们的底层原理相同——用广角收进空间、用层次建立纵深、用光线定调情绪——但技法各有侧重。学完本节，你会用同一套「风光心法」，同时驾驭山川与街巷。

## 1 风光的底层参数：广角、小光圈与低感光度

拍风光先定三件参数，它们与人像几乎是反着来的：

**广角**：风光要「装得下」，主摄的 1×（等效约 24–26mm 广角）是风光的默认镜头；0.5× 超广角用于「震撼场面」（大场景、建筑仰拍），2×–3× 长焦用于「局部提炼」（山体纹理、远处楼群）。**焦段的选择决定叙事**：超广角强调「空间」，长焦强调「秩序」。
**小光圈（大 f 值）**：专业模式下把光圈收到 f/4–f/8（或启用「景深」相关的清晰度档），保证**全景清晰**——风光要的是大景深，近处的石头和远处的山都清楚。
- **低感光度（低 ISO）**：白天用 ISO 50–100，让画面最干净、色彩最饱和。风光讲究画质优先，宁可稍降快门，也不提 ISO。

**曝光基准**：风光拍摄常用「宁欠勿过」原则——亮部（天空、云彩）一旦过曝就永远找不回来，而暗部（山体阴影）还能靠后期拉回一点。所以对天空测光、让地面略欠曝，是风光曝光的默认姿势，具体见《对焦、测光与曝光补偿》。<span class="marginnote">「宁欠勿过」与手机 HDR 是绝配：开启 HDR 后，手机会自动拍多帧合成，把欠曝的地面与正确的天空「缝合」起来——这是风光新手最容易忽略的一步。<strong>广角 + 小光圈 + 低 ISO + HDR</strong>，就是手机风光的「四件套」。</span>

## 2 层次与前景：一张风光照的「三段式」

风光照最容易拍成「一张平面」——远山是远山、天空是天空，各管各的，画面没有纵深感。破解的关键是**层次**：让画面里有**前景、中景、远景**三层的递进，眼睛就有了「走入画面」的路径。

**三段式构图**：前景（近处的一枝花、一块石、一艘船）→ 中景（水面、山腰、街道）→ 远景（远山、天际线、楼群）。三层缺一不可，尤其**前景是风光片的灵魂**——没有前景，照片就是一张「明信片」；有了前景，照片才「有得看」。<span class="marginnote">前景还承担着「尺度参照」的作用：一块近处的礁石，能让观者估算出远处悬崖有多高；一个走过的人影，能让摩天楼显得更庞大。摄影里这叫<strong>比例参照物</strong>——风光照里的人不是主角，却是最好的「尺子」。</span>

**层次的技术保障**是三段式景深：前景贴得够近、中景在清晰带内、远景无限远——只要光圈够小（大景深），三层都能锐利；若想让前景「带一点点虚」的梦幻感，也可用 1× 广角凑近前景，靠最近对焦距离制造微景深，这属于高级玩法。

**辨析｜易错点：前景不是「随便放个东西」** 前景要**与主题相关、有形状、有位置感**。一棵伸进画面的树枝、一片前景的麦浪、一段伸向远方的栈桥，都能引导视线；但一个「为了有前景而有」的杂物，反而干扰画面。判断标准是：**前景能否把视线「递」给中景和远景**。能递，是引导线；不能递，是挡镜头。<span class="marginnote">「引导线」是前景的高级形态：栈桥的栏杆、河岸的曲线、街道的透视，它们不只是前景，还承担着<strong>把眼睛从画面底部一路引向主体</strong>的功能。引导线 + 三段式，是风光构图的两大支柱，详见《对称、引导线与框架构图》。</span>

## 3 山水：水、山与天空的拍法

自然风光的三件主角——水、山、天空，各有脾气：

**拍水**：水的表情随曝光时间而变。静水面用低机位平拍，能拍出「天空之境」的倒影；流动的水（瀑布、溪流）用专业模式的**长曝光**（1/4s 到数秒），水会变成绸缎般的丝滑质感，需要三脚架或固定支撑。拍倒影的秘诀是**机位贴近水面**，离水越近，倒影越完整。

**拍山**：山的拍法看「线」——山脊的轮廓线是画面的大骨架。顺光下山体有细节、有纹理；侧光下山体一半亮一半暗，立体感最强；**剪影**则干脆放弃山体细节，用逆光把山脊线画成纯黑的轮廓，配上一轮日出日落，情绪最浓。拍群山时用 2×–3× 长焦「压缩」远山，让山与山的间距显得更近，层次更密。

**拍天空**：天空是风光的「情绪开关」。蓝天白云适合顺光、干净明快；日出日落的**黄金时刻**（日出后/日落前约 1 小时）和**蓝调时刻**（太阳刚落、天色深蓝的约 20 分钟）是天空最出片的时段。<span class="marginnote">黄金时刻的光线是「暖 + 低角度 + 柔和」三合一：低角度的光拉长了山影树影，让画面有立体感；暖色调让一切镀上金色；光线经过大气层路径更长，被散射的蓝光更多，剩下的红橙光更浓——所以黄金时刻的天空是暖的。</span>阴天不是不能拍：云层是天然的「柔光箱」，阴天的森林、山涧反而细腻耐看。

**辨析｜易错点：山水照的「白平衡陷阱」** 日出日落时画面极暖，手机自动白平衡常常「纠正」掉这份暖色，把金色天空拍成灰白。对策：专业模式手动把白平衡调到偏暖（约 6000–7000K），或干脆用「保留暖调」的拍摄模式（见《白平衡与色温控制》）。**风光里的「偏色」往往是情绪，不是错误**——别让相机把你的「氛围」纠正掉。

## 4 城市建筑：仰拍、对称与秩序

城市建筑的魅力在**人造的秩序**：直线、重复、几何、透视。拍建筑抓住四种语言：

1. **仰拍的力量感**：站在楼底，广角仰拍，建筑向画面顶端收拢，形成强烈的透视汇聚——「向上延伸」的张力扑面而来。仰拍时手机要端平（或后期校正透视），否则柱子会「歪得失控」。
2. **对称的仪式感**：建筑天生对称，正面平拍、让画面左右对称，就是建筑最「整」的拍法——穹顶、门廊、隧道、走廊，都是对称构图的好素材。
3. **线条的节奏感**：把镜头转向建筑表面的重复元素——一排窗、一层层阳台、一格格的幕墙玻璃——用长焦截取「局部」，抽象出线条与图案，建筑就成了几何作品。
4. **剪影与灯火**：日落后的蓝调时刻，建筑的轮廓配着亮起的窗灯，冷暖对比最出片；天桥、高架、车轨配合长曝光（见《夜景摄影》），城市就「流动」起来。

**辨析｜易错点：建筑「歪楼」是手机摄影的头号事故** 手机广角镜头的透视畸变会让竖直线条向外「倒」，尤其仰拍时楼顶明显后仰。三条对策：其一，**站远一点 + 用 2× 长焦**，透视畸变随距离增大而减弱；其二，**端起手机、保持竖直**，让中线与地面垂直；其三，**后期透视校正**（裁剪篇会讲），把「歪楼」拉正。拍建筑的正确姿势是「先端平，再构图」，而不是「先构图，再歪着拍」。<span class="marginnote">一个职业技巧：手机取景框里往往有「水平仪」或「网格线」，开启它，让地平线/建筑线对齐网格，是拍建筑最省力的「防歪」手段。专业模式下还能看到「水平指示」，歪一度都会显示——<strong>建筑摄影的第一课，是学会端平</strong>。</span>

## 5 核心对比表：自然风光与城市建筑

纯概念主题用「核心对比表」替代公式解析——山水与建筑没有统一公式，但有清晰的技法对照：

| 维度 | 自然风光（山水） | 城市建筑 |
| --- | --- | --- |
| 核心美感 | 层次、光影、氛围 | 秩序、几何、透视 |
| 主镜头 | 超广角/广角收空间 | 广角仰拍 + 长焦截局部 |
| 构图语言 | 三段式、引导线、前景 | 对称、线条、重复 |
| 光线偏好 | 黄金时刻、蓝调时刻 | 顺光细节 + 蓝调灯火 |
| 常见失误 | 前景抢戏、天空过曝 | 歪楼、透视畸变 |
| 白平衡 | 保留暖调情绪 | 还原中性灰调 |
| 后期重点 | 提暗部、增层次、微调色彩 | 透视校正、拉直竖线、压高光 |

这张表的启示是：**同一个「风光心法」——广角、层次、秩序、光线——在山水里表现为「借自然」，在城市里表现为「借人造」**。两者都要求你「看得准、站得对、等得住」，只是站的位置不同。<span class="marginnote">跨类型练习的效果最好：同一个傍晚，先拍一条山脊线，再拍一排建筑天际线，比较两次构图的取舍。你会发现自己对「线」和「秩序」的敏感度在两类题材间互相增强——<strong>风光摄影的进步，恰恰发生在题材的交叉处</strong>。</span>

## 6 实操：一张完整风光的拍摄流程

1. **定时间**：优先黄金时刻/蓝调时刻，避开正午平光（正午顶光下风光「平」且「硬」）。
2. **找机位**：先站高/站低/走近，再谈构图；「换一个地方」永远比「换一个参数」管用。
3. **定焦段**：大场景用超广角/广角，局部提炼用长焦；心里先问「我要空间还是秩序」。
4. **搭层次**：找前景 → 摆中景 → 等远景，让画面有「走进来」的路径。
5. **设参数**：专业模式小光圈 + 低 ISO，对天空测光，HDR 常开。
6. **控白平衡**：日出日落手动加暖，白天还原中性。
7. **拍多张**：同一机位至少拍 3 张（不同曝光/不同等待瞬间），回去选最好的。

这套流程把本节的「参数、层次、题材」全部串成一条线。**风光的宽容度远比人像大**——同一个地方，不同时间、不同光线、不同焦段能拍出完全不同的照片，所以风光进步最快的方式是「反复去同一个地方」：把它当成一个系列来拍，你会看到自己眼光的成长。<span class="marginnote">给自己定一个「重返计划」：选定一个离家最近的景（一座桥、一个公园、一条街），一年四季各拍一次。四张照片放在一起，就是一组最好的「光线与季节」教材——<strong>风光摄影的本质，是练习「看见」</strong>，而练习「看见」最好的场地，就在身边。</span>

## 7 风光摄影的常见失误清单

风光片的「事故」，集中在六类，每类都能在前文找到原理：

1. **画面「平」**：没有层次——前景缺位，只有「中景 + 远景」。对策：找一块近处的石头、一枝花作前景，让视线有「走进来」的路径。
2. **天空过曝**：对地面测光导致天空一片死白。对策：对天空测光、开 HDR、压高光（见《对焦、测光与曝光补偿》）。
3. **建筑歪楼**：竖直线条向外倒。对策：站远 + 长焦、端平手机、后期透视校正。
4. **色彩「脏」**：白平衡被自动纠正掉氛围（日出日落拍成灰白）。对策：手动白平衡加暖。
5. **前景抢戏**：为了前景而前景，干扰主体。对策：让前景「递」视线，递不了就撤。
6. **锐化过度**：后期拉过清晰度，山体边缘出现白边（光晕）。对策：清晰度克制，或导出前降一点。

**对照自查**：这六条与《人像》篇的事故清单异曲同工——**风光与人像的失误，本质上都是「构图、曝光、色彩、后期」四件事的失控**。每拍一次风光，对照清单自查一遍，翻车的概率会逐次下降。

## 8 小结

- 风光三参数与人像相反：**广角装空间、小光圈保全景清晰、低 ISO 保画质**；「广角 + 小光圈 + 低 ISO + HDR」是手机风光四件套。
- 曝光基准「**宁欠勿过**」：亮部过曝找不回，暗部能靠后期拉回——对天空测光，地面略欠。
- 三段式层次：**前景 → 中景 → 远景**；前景是风光片的灵魂，且承担「比例参照物」职责。
- 前景不是「随便放」：它是**引导线**，能把视线「递」给中景与远景，递不了就是挡镜头。
- 拍水看曝光时间：静水低机位拍倒影，流水长曝光拍丝绢；拍山看轮廓线，顺光细节、侧光立体、逆光剪影。
- 拍天空看时刻：黄金时刻（暖+低角度）与蓝调时刻（深蓝 20 分钟）最出片；阴天的云是天然柔光箱。
- 拍建筑四种语言：**仰拍的力量感、对称的仪式感、线条的节奏感、蓝调的灯火**。
- 「歪楼」是建筑头号事故：站远 + 长焦、端平手机、后期透视校正——建筑摄影第一课是学会端平。
- 山水借自然、城市借人造，共用同一套「风光心法」：看得准、站得对、等得住。
- 风光进步最快的办法是「反复去同一个地方」：当成系列拍，练的是「看见」的能力。
- 风光三件套之外别忘了「耐心」：云、光、水面平静都要等——「等得住」是风光的基本功。
- 山水与城市共用同一套心法：借自然或借人造，都在练「看得准、站得对、等得住」。

在下一节，当光线亮不起来、环境暗下来时怎么办：**夜景摄影：长曝光与手持夜景**——黑暗不是风光的终点，而是另一种开始。
