## 为什么从夜景摄影开始

夜景是手机摄影的**分水岭**。白天，任何一台手机都能拍出差不多的照片；到了夜晚，光量骤降到白天的万分之一以下，拼的才是真正的技术。夜景的难度来自三件事——**暗（光不够）、抖（手不稳）、噪（画质劣化）**，这三件事互相纠缠：光不够，就要加长曝光；曝光一长，手抖就糊；不想糊，就提 ISO；ISO 一提，噪点就多。<span class="marginnote">这个「三角死循环」正是曝光三要素（光圈、快门、ISO）在极端条件下的逼真演练：<strong>光不够 → 快门慢 → 手抖糊；或光不够 → 提 ISO → 噪点多</strong>。手机厂商的夜景模式，本质是用「多帧合成」把这个死循环破解掉——一次快门，其实是几十次短曝光的数学平均。</span>本节给你两套破解方案：**长曝光**（借三脚架与时间，把光「攒」起来）与**手持夜景**（借算法与多帧，把光「算」出来）。学会夜景，等于把前六篇的曝光、对焦、白平衡全部推到了极限。

## 1 夜景的三重挑战：暗、抖、噪

先看清敌人，再谈破解。夜景的三个敌人：

**暗**：夜晚的光量只有白天的约十万分之一。手机为了保证不糊，默认会「拉长快门 + 提 ISO」——但每一样都有代价。快门一长，任何手持的微抖都会被放大成「拖影」；ISO 一提，传感器每个像素的放大增益变高，噪点（随机出现的彩色/灰度颗粒）随之而来。<span class="marginnote">噪点的来源值得一说：传感器读出信号时自带热噪声与读出噪声，提 ISO 等于把信号和噪声<strong>一起</strong>放大。现代手机用「多帧降噪」应对——拍 N 张，每张的噪点是随机的，而真实景物是固定的，把 N 张叠加平均，固定信号累加成 N 倍，随机噪声只增加为 √N 倍，信噪比就提高了。<strong>多帧合成，就是「量变引起质变」的噪点对策</strong>。</span>

**抖**：手持的安全快门约是「1/焦段」秒——用 1×（约 24mm）手持，快门别低于约 1/25s，再慢就容易糊。夜晚往往需要 1/10s 甚至更慢，所以「抖」与「暗」天然冲突。

**噪**：噪点不只是「丑」，它还会抹掉细节——暗部的树叶、夜空里的星星，都可能被噪点「吃掉」。噪点还与**色彩**相关：高 ISO 下的阴影区域容易出彩色噪点（色度噪声），比灰度噪点更难去除。

**辨析｜易错点：夜景的失败模式不止「糊」一种** 新手以为夜景最大的敌人是「糊」，其实还有三种常见失败：**过曝**（路灯、霓虹灯被拍成一片死白，高光全毁）、**偏色**（混合光源下白平衡错乱，暖的路灯 + 冷的路牌灯互相打架）、**噪点抹掉暗部细节**（看似「干净」的夜景，其实暗部全糊成一片）。夜景的合格标准不是「亮」，而是**「亮部不过曝、暗部有细节、色彩不打架」**三件事同时成立。

## 2 长曝光：把时间变成画笔

长曝光（慢门）是夜景最具表现力的技法：**让运动的物体在画面里留下轨迹**。车流变成光轨、流水变成丝绢、人潮变成虚影——时间是长曝光的画笔。

**长曝光的应用场景**：车流光轨（车灯划出的红白线条）、流水拉丝（瀑布、海浪的雾化）、星轨（星星绕北极星画弧）、人流虚化（行人淡成影、静止的建筑清晰）。每一样都需要**相机不动**，所以长曝光的第一条件是**三脚架或稳固支撑**（栏杆、台阶、背包都行）。

**手机长曝光的实现**：大多数手机的专业模式提供**手动快门**（S 档，快门速度可设 1s、4s、10s 等），部分手机还有专门的「长曝光模式」。没有三脚架时，把手机靠在稳定物体上、用「延时自拍/声控快门」触发（避免手按屏幕瞬间的震动），是等效方案。<span class="marginnote">一个容易忽略的细节：长曝光时手机本身发热、或风吹晃动，都会让画面「糊而不自知」。稳妥做法是<strong>开启 2–3 秒的延时自拍触发快门</strong>，等手机「站稳」了再拍；拍摄多张时，间隔留几秒，让前一张的机内处理完全结束，避免帧间错位。</span>

**参数设定**：长曝光用**低 ISO（50–100）**保画质，快门速度按「想留多长的轨迹」来定——车流要 2–4s、流水要 1–2s、星轨要数分钟（用「星轨模式」或堆栈合成）。光圈收到中档。测光要格外注意**高光保护**：车灯、路灯最容易过曝，宁可整体略欠。

**辨析｜易错点：长曝光 ≠ 「曝光时间越长越好」** 时间太长，光轨会「糊成一团」而失去线条感；车流的「红白间隔」之美，恰恰来自**适中的曝光让车灯成线而非成片**。经验值：单辆车流 2–4s 足够；想拍「多车交错」的复杂轨迹，才用更长。长曝光的艺术在于「控制轨迹的长度」，而不是「无脑拉长」——**时间长短，取决于你想让画面里的运动「走多远」**。

## 3 手持夜景：多帧合成的魔法

不是每次夜景都有三脚架。**手持夜景**，是手机算法给出的答案——**一次快门，多帧合成**。按下快门时，手机在零点几秒内连拍十几张到几十张（有的机种达 50 帧），然后：**对齐**（消除手持微抖造成的帧间位移）→ **堆叠平均**（提升信噪比、压噪点）→ **高光/暗部融合**（HDR 式地保亮部、提暗部），最终合成一张「干净且亮」的照片。

**手持夜景的适用边界**：它擅长**静态场景**——城市街道、夜景建筑、星空下的静物。它不擅长**强运动**——行驶的车、走动的人，在多帧合成里会留下「重影」或「拖影」，因为各帧里物体的位置不同，对齐算法只能顾上静止部分。所以：**拍静止的夜景，交给手持夜景模式；拍运动的夜景（车轨、人流），交给长曝光**。

**辨析｜易错点：夜景模式「糊了」不一定是手抖** 夜景模式合成的失败，常常是**主体在拍摄期间动了**——哪怕动了 1 厘米，合成后也会出现「边缘虚、脸糊」的怪相。对策：开启夜景模式后，**保持手持稳定直到拍完**（取景框通常显示剩余秒数），并尽量选择「正在休息」的主体——等行人走过去再拍、等车停下来再按。夜景模式的「稳定要求」比普通模式严格得多，因为它本质是在拍一段 1–3 秒的「极短视频」再平均。<span class="marginnote">进阶技巧：<strong>夜景模式 + 依托支撑</strong>是「双重保险」。把手机靠在栏杆、车窗或同伴肩上，手持夜景模式的合成质量会明显上升——因为每一帧都更「稳」，对齐算法留出的余量就更多，暗部能拉到更多细节。稳定，是夜景一切技法的前提。</span>

## 4 夜景参数与拍摄设置

不同场景选对模式，比「参数」更重要。夜景拍摄的模式决策表：

| 场景 | 推荐模式 | 关键设置 |
| --- | --- | --- |
| 城市街景（静止） | 夜景模式 | 依托支撑，等行人走过再拍 |
| 车流光轨 | 专业模式/长曝光 | 快门 2–4s、ISO 50–100、三脚架 |
| 夜景人像 | 夜景模式 + 人像模式 | 让人物尽量静止，闪光灯慎开 |
| 星空 | 专业模式/星空模式 | 快门 15–30s、ISO 800–3200、三脚架 |
| 夜景剪影 | 专业模式 | 对着天空测光、对焦在轮廓上 |

**三个通用设置**：其一，**ISO 能低则低**——能依托支撑就把 ISO 压到 100–400，画面最干净；纯手持才用「自动」。其二，**对焦手动锁远处**——夜空的自动对焦容易「拉风箱」，点一下远处的灯光锁定焦点。其三，**白平衡按光源选**——路灯多的街道选「日光」或「荧光灯」预设的修正版，混合光源下手动定一个中间值（见《白平衡与色温控制》）。<span class="marginnote">一个反直觉的经验：<strong>夜景不怕暗，怕「脏」</strong>。与其把 ISO 拉满让整张图噪点遍布，不如接受「偏暗但干净」的画面，回去用后期「提阴影 + 降噪」——后期的降噪比机内高 ISO 的硬提，能保留更多色彩与细节。夜景的后期空间，往往比拍摄瞬间更大。</span>

## 5 核心对比表：长曝光与手持夜景

纯概念主题用「核心对比表」替代公式解析——两种夜景技法没有公式，只有适用边界的清晰对照：

| 维度 | 长曝光 | 手持夜景 |
| --- | --- | --- |
| 核心原理 | 延长快门，让时间「累积」光 | 多帧短曝，让算法「平均」光 |
| 必备条件 | 三脚架/稳固支撑 | 手持稳定即可，依托支撑更佳 |
| 适合对象 | 运动的轨迹（车轨、流水、星轨） | 静止的场景（街景、建筑、夜景人像） |
| 画面气质 | 流动、轨迹、时间感 | 干净、明亮、平衡 |
| 关键技术 | 快门速度控制 | 多帧对齐与堆叠 |
| 常见失败 | 时间过长轨迹糊成团 | 主体微动产生重影 |
| 画质策略 | 低 ISO + 长快门 | 多帧降噪 + HDR 融合 |

这张表的核心启示：**长曝光是「用硬件条件换时间」，手持夜景是「用算法算力换稳定」**——两者的目标都是「在暗光下拿到干净的画面」，只是把「光」的来源，分别交给了物理时间与数字计算。真正的夜景高手，会在同一个场景里「两种都拍」：先手持拍一张「干净基线」，再上三脚架拍一张「轨迹作品」，互为备份。<span class="marginnote">把两种技法想成同一枚硬币的两面，就能理解手机夜景菜单的布局：<strong>「夜景模式」是面向大众的自动多帧，「专业模式/长曝光」是面向创作者的手动时间</strong>。从自动走向手动，正是手机摄影从「拍得到」走向「拍得妙」的必经之路。</span>

## 6 实操：两种夜景的完整流程

**手持夜景流程**（无三脚架）：
1. 找依托：栏杆、墙、背包，让手机「靠」上去。
2. 开夜景模式，画面显示剩余曝光秒数。
3. 对焦锁定远处灯光，白平衡按光源预设。
4. 等运动体离开画面（行人走完、车停），再按快门。
5. 保持稳定直到取景提示结束，检查「亮部不过曝、暗部有细节」。

**长曝光流程**（有三脚架）：
1. 架稳三脚架，手机装正，开启网格线与水平仪。
2. 专业模式：ISO 50–100，快门先试 2s，光圈中档。
3. 测光偏重高光（路灯/车灯不能过曝）。
4. 用 2–3s 延时自拍触发，避免按键震动。
5. 连拍 3 张不同快门（如 2s / 3s / 5s），回去选轨迹最「妙」的一张。

两条流程的结尾都是同一件事——**回看检查**。夜景的失败信息都在屏幕里：糊了看「是否依托稳定」，噪了看「是否 ISO 过高」，过曝看「测光是否偏了高光」。**把每一次翻车读成一次参数反馈，夜景技术就会在一夜之间进步**。<span class="marginnote">给自己一次「夜景拉练」：一个雨后的夜晚（地面反光会放大灯光，夜景质感加倍），带上手机去最近的街口，手持与长曝光各拍 10 张。你会在对比中同时学会两件事：<strong>手持的「稳」与长曝光的「等」</strong>——前者是手的修为，后者是心的修为。</span>

## 7 夜景摄影的三个进阶技巧

**技巧一：找「二次光源」** 夜景不是「只有灯」——月光、水面反光、雨后地面积水的倒影，都是被忽视的光源。雨后夜晚是夜景的「黄金时间」：地面的反光让灯光「翻倍」，画面层次瞬间丰富。

**技巧二：点测光保高光** 夜景测光要「点」在亮部（路灯、霓虹灯）上，让高光准确、整体略欠——暗部靠后期拉，高光过曝则无法挽回（「宁欠勿过」的夜景版）。

**技巧三：后期「先提后降」** 夜景 Raw 的暗部往往有噪点。后期先「提阴影」再「降噪」——先让暗部细节出来，再整体降噪，比「边提边降」效果好；彩色噪点用「去彩色噪点」滑杆单独处理。

三条技巧对应夜景的三个环节：**找光在前期、测光在曝光、降噪在后期**——把「暗、抖、噪」三个敌人分别在前、中、后期各个击破，夜景就不再是「碰运气」。

## 8 小结

- 夜景三大挑战：**暗、抖、噪**，三者互相纠缠；破解靠「多帧合成」或「延长曝光」两条路。
- 夜景合格标准是三项同时成立：**亮部不过曝、暗部有细节、色彩不打架**。
- 多帧合成的原理：N 张叠加平均，固定信号 ×N、随机噪声 ×√N——「量变引起质变」的噪点对策。
- 长曝光 = 用时间当画笔：车轨、流水、星轨、人流虚影；第一条件是**三脚架或稳固支撑**。
- 长曝光不是越长越好：时间长短取决于想让运动「走多远」，车流 2–4s 最出线条。
- 手持夜景 = 多帧对齐 + 堆叠降噪 + HDR 融合；擅长静止场景，怕运动主体（重影）。
- 夜景模式开启期间**保持主体静止**：动的物体在多帧合成里会「糊而不自知」。
- ISO 能低则低：夜景不怕暗，怕「脏」；「偏暗但干净」比「过亮但噪」更有后期空间。
- 长曝光换「时间」，手持夜景换「算力」——同一场景两种都拍，互为备份。
- 夜景拉练是进阶捷径：雨后夜晚，手持 + 长曝光各拍 10 张，学会「稳」与「等」。

在下一节，我们把镜头对准城市里流动的人：**街头与人文摄影**——不打扰、不摆拍，用快门凝固生活的瞬间。
