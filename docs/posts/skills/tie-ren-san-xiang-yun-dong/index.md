# 铁人三项运动

铁人三项运动是由游泳、骑行与跑步三项耐力运动按序衔接而成的复合竞赛项目，涵盖从短距离到大铁全程的多种赛制，考验三项单项技术、换项衔接与整体体能分配。以 World Triathlon《铁人三项竞赛规则》、《铁人三项训练圣经》与中国铁人三项运动协会规范为纲，系统建立从三项技术训练、衔接转换、营养补给到装备与赛事准备的完整能力体系。

## 对标教材

- World Triathlon《铁人三项竞赛规则》
- 《铁人三项训练圣经》（乔·弗里尔 著）
- 《中国铁人三项运动协会竞赛与训练规范》
