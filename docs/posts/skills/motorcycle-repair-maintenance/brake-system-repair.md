## 为什么制动是「保命系统」

摩托车的加速是享受，制动是底线——刹不住，一切性能都失去意义。<span class="marginnote">制动系统是整车唯一「直接关系到生命安全」的系统：<strong>它的故障没有「先凑合一段」的余地</strong>。职业标准把制动检修列为摩托车维修工的高风险项目，要求检查、调整、试车层层把关。</span>这一节讲清鼓式与盘式两种制动的结构与原理、制动液的更换、以及检修中必须盯住的安全细节。

## 1 鼓式制动：机械时代的经典

**鼓式制动（drum brake）**：制动蹄从内部向外张开、压紧随车轮转动的制动鼓内壁，靠摩擦力制动。结构核心是**制动蹄、制动鼓、凸轮与回位弹簧**。

工作方式：捏（踩）下制动杆 → 拉索或推杆带动**凸轮**转动 → 凸轮把两片制动蹄向外撑开 → 蹄片压紧制动鼓 → 摩擦力产生制动力矩。松开后回位弹簧把蹄片拉回。

| 结构件 | 磨损/故障表现 | 处理 |
| --- | --- | --- |
| 制动蹄摩擦片 | 厚度磨薄、刹不住 | 成组更换蹄片 |
| 制动鼓 | 内壁起槽、失圆 | 轻度可继续，严重镗鼓/更换 |
| 凸轮轴 | 磨损、卡滞 | 润滑或更换 |
| 回位弹簧 | 弹力衰减 | 更换（防止拖滞） |

<span class="marginnote">鼓式制动的优点是「制动平稳、成本低」，缺点是「散热差、热衰退明显」——连续重刹后，摩擦片表面温度升高、摩擦系数下降，制动力衰减。这就是「下长坡别一直带着刹」的原因。</span>

**调节机构**：鼓式制动都有**制动蹄间隙调节器**，随着蹄片磨损，间隙变大、制动手柄行程变长。调整方法一般是旋转调节螺母或调节螺栓，使「转动车轮时有轻微摩擦、手柄行程合适」。调整是鼓式制动保养最频繁的操作。

## 2 盘式制动：液压时代的精准

**盘式制动（disc brake）**：制动钳夹紧随车轮转动的制动盘，靠摩擦片与盘面的摩擦力制动。结构核心是**制动盘、制动钳、摩擦片、液压系统（主缸、油管、分泵）**。

工作方式：捏制动手柄 → 主缸活塞推动**制动液** → 液压力经油管传到卡钳分泵 → 分泵活塞推动摩擦片夹紧制动盘。<span class="marginnote">盘式制动的优势是散热好、热衰退小、制动力线性可控——现代摩托车前轮几乎全用盘式。它的代价是「娇贵」：<strong>制动液会吸水、液压系统不能有气泡、制动盘不能变形</strong>，保养要求更高。</span>

**盘式制动的关键部件检查**：

**制动盘**：用百分表测端面跳动（超过极限值会造成制动抖动）、用卡尺测厚度（磨到极限标记必须更换）。
**摩擦片**：目测摩擦材料厚度，接近极限（通常剩 1–2 mm）即换；摩擦片磨损到铁背板会刮伤制动盘。
**制动液**：液位在储油罐上下限之间，颜色变深（吸水老化）需更换。

## 3 公式解析：液压制动的力量放大

盘式制动靠**帕斯卡原理**放大制动力——液体在密闭容器中传递压强，大小不变、方向改变：

$$
F_{夹} = p \times A_{分泵} = \frac{F_{主}}{A_{主}} \times A_{分泵}
$$

- **第一步，认识符号**：$F_{夹}$ 是**卡钳施加的夹紧力**；$p$ 是制动液**压强**；$A_{分泵}$ 是卡钳分泵活塞面积；$F_{主}$ 是手指施加在主缸活塞上的力；$A_{主}$ 是主缸活塞面积。
- **第二步，直觉理解**：压强处处相等，但面积不同就放大力量。主缸活塞小、分泵活塞大，手指的一点力就被放大成几倍甚至十几倍的夹紧力。这就是「轻轻一捏就能刹住高速行驶的车」的物理基础。
- **第三步，维修含义**：这套放大系统**最怕气泡**——气体可压缩，捏下制动手柄时气泡先被压缩，力量传不到卡钳，制动手柄「发软」、刹不住。**制动系统排气**就是把液压管路里的气泡排净，是换制动液后的必做动作。<span class="marginnote">制动液为什么会吸水：它的主要成分是聚乙二醇醚，<strong>吸湿性强，会从储油罐呼吸孔与油管接头吸入水分</strong>。含水后沸点大幅下降，激烈制动时制动液在分泵处沸腾产生气泡——这就是「热衰退」在液压制动里的另一种表现，也是制动液需定期更换的原因。</span>

## 4 制动液的选用与更换

**制动液（brake fluid）**：液压制动系统的传力介质，常见规格为 DOT 3、DOT 4、DOT 5.1（干沸点逐级升高）。选用以手册为准，DOT 等级可高不可低。

**更换周期**：一般每 1–2 年或按手册里程更换；制动液吸水老化后沸点下降，是安全隐患。

**更换操作要点**：从储油罐排旧油 → 从卡钳放气螺钉处放出旧油并排气 → 加注新液至标准液位。**排气顺序**按「离主缸最远的卡钳先排」的原则（通常先右后左、先远后近），直到放气口流出连续无气泡的液柱。<span class="marginnote">制动液对漆面有腐蚀性，溅到车身要立即擦拭；更换时用专用抽液工具可避免滴漏。<strong>废制动液按有害废液处理，不能倒入下水道</strong>。</span>

**辨析｜易错点：** 制动液**不能混加不同 DOT 等级**——不同等级添加剂不同，混用可能产生沉淀或沸点下降。加注时务必确认储油罐盖上的规格标注；不确定时整系统更换。另一个易错点是「油位低就补」——油位下降往往意味着摩擦片磨损（分泵活塞外伸、液面下降），**应先检查摩擦片厚度而不是单纯补液**。

## 5 制动系统的安全检修要点

制动系统检修有一套「保命流程」，缺一不可：

**检查调整**：鼓式调蹄片间隙、盘式查摩擦片与制动盘；制动手柄/踏板行程在标准内。
**液压系统**：检查油管有无裂纹鼓包（橡胶管老化鼓包是爆管前兆）、接头有无渗漏、制动液液位与颜色。
**制动测试**：静态试刹（原地捏紧，手柄应硬实不软）→ 低速路试（轻刹→重刹，检查制动力、有无跑偏、异响、抖动）→ 检查制动灯（第4篇照明信号系统）。

**核心要点：** 制动检修完成后，**试车验证是强制步骤**，不是可选。制动力不均（跑偏）、制动手柄发软（气泡）、制动抖动（制动盘跳动）这三类问题，都只有在实际制动中才能最终确认。试车路段要开阔、限速内完成，这也呼应了第1篇《安全操作规程》里的「试车场地开阔、佩戴头盔、确认制动」。

### 术语速查

| 术语 | 含义 |
| --- | --- |
| 鼓式制动 | 制动蹄从内部张开压紧制动鼓的制动 |
| 盘式制动 | 卡钳夹紧制动盘的液压制动 |
| 制动蹄 | 鼓式制动中带摩擦片的撑开件 |
| 制动鼓 | 随车轮转动、被蹄片压紧的鼓 |
| 凸轮 | 撑开制动蹄的机构 |
| 制动盘 | 被卡钳夹紧的圆盘 |
| 制动钳 | 容纳分泵与摩擦片的夹紧装置 |
| 摩擦片 | 与制动盘/鼓接触产生摩擦力的片 |
| 主缸 | 把制动手柄力转成液压的部件 |
| 分泵 | 把液压转成夹紧力的卡钳活塞 |
| 制动液 | 液压制动系统的传力介质 |
| DOT 等级 | 制动液的沸点规格等级 |
| 排气 | 排出液压管路中气泡的工序 |
| 热衰退 | 制动件高温后制动力下降的现象 |

### 制动「五查五防」

- **查液位**：储油罐在上下限，下降先查摩擦片。
- **查油管**：橡胶管裂纹鼓包是爆管前兆。
- **查摩擦片**：厚度接近极限即换，防刮盘。
- **查制动盘**：端面跳动与厚度极限。
- **查行程**：手柄硬实不发软，自由行程标准。

- **防混液**：DOT 等级不可混加。
- **防气泡**：换液必排气，远缸先排。
- **防腐蚀**：制动液溅漆面立即擦拭。
- **防过热**：下长坡用发动机制动辅助。
- **防拖刹**：鼓式回位弹簧衰减即换。

**制动排气顺序**：从离主缸最远的卡钳开始排（先右后左、先远后近），直到放气口流出连续无气泡的液柱。排气不净，制动手柄发软、刹不住——这是盘式制动「修完必须试刹」的原因。

## 6 小结

- **鼓式制动**靠凸轮撑开蹄片压紧制动鼓，调节蹄片间隙是保养重点，热衰退明显。
- **盘式制动**靠液压夹紧制动盘，散热好、制动力线性，是现代前轮主流。
- 液压制动的力量放大来自**帕斯卡原理**：$F_{夹} = (F_{主}/A_{主}) \times A_{分泵}$
