## 为什么先学配气机构

上一节讲了四冲程循环，而「进气门什么时候开、排气门什么时候关」这件时序的事，正是**配气机构**的职责。<span class="marginnote">配气机构相当于发动机的「门卫」：<strong>开早了漏压、关晚了窜气、开少了进气不足、关不严直接烧气门</strong>。它的故障常常不声不响——车还能跑，只是「没劲、费油、气门响」。</span>这一节讲清配气机构的结构、正时的概念，以及维修中最高频的操作——气门间隙的检查与调整。

## 1 配气机构的结构与传动形式

**配气机构（valve train）**：按发动机工作循环的要求，定时开启和关闭进、排气门，保证混合气及时进入气缸、废气及时排出的机构。它由**气门组**与**气门传动组**两部分组成：

**气门组**：气门（阀片）、气门座、气门导管、气门弹簧、油封、锁夹。气门靠弹簧复位，靠油封防止机油窜入燃烧室。

**气门传动组**：凸轮轴、挺柱/摇臂、正时链（或正时带、齿轮）、张紧器。凸轮轴的凸轮轮廓决定气门开启的时机与升程，通过正时机构与曲轴保持严格同步。

按凸轮轴位置分两种常见形式：

| 形式 | 特点 | 典型应用 |
| --- | --- | --- |
| 顶置气门（OHV） | 凸轮轴在曲轴箱内，推杆传动 | 老式单缸车 |
| 顶置凸轮轴（OHC） | 凸轮轴在缸头内，正时链/带传动 | 现代绝大多数车型 |

<span class="marginnote">现代摩托车几乎都是 OHC 结构，正时链（cam chain）把曲轴与凸轮轴连起来。链传动会有磨损拉长，所以都配有<strong>张紧器</strong>——链松了会「哗啦哗啦」响，这也是正时链磨损的典型症状，后面第3节会讲。</span>

## 2 气门间隙：为什么要留、为什么不能乱

**气门间隙（valve clearance）**：在冷态下，气门处于完全关闭时，气门杆端与传动件（摇臂或挺柱）之间的间隙。发动机工作时气门及缸头受热膨胀，如果冷态不留间隙，热态下气门会被顶开、关闭不严，导致漏气、烧气门。

间隙的典型值很小：进气门约 0.05–0.08 mm，排气门约 0.08–0.12 mm（具体以手册为准）。排气门间隙通常比进气门大，因为排气门工作温度更高、热膨胀更多。

**辨析｜易错点：** 间隙有两个方向性的错误：

**间隙过大**：气门开启变晚、关闭变早、升程减小，进排气效率下降——症状是「怠速不稳、气门嗒嗒响、功率下降」。响声来自摇臂与气门杆端的敲击。
**间隙过小**：热态下气门被顶住关不严——症状是「气门烧蚀、压缩压力下降、启动困难、回火放炮」。**间隙过小比过大更危险**，因为它直接导致气门与座圈烧损。<span class="marginnote">判断气门响还是敲缸响，有经验的维修工会「冷车听、热车听」对比：<strong>气门响冷热车都有但热车略小，敲缸响冷车明显、热车减弱</strong>。拿不准就拆开量间隙，用数据说话。</span>

## 3 正时：曲轴与凸轮轴的同步

**正时（timing）**：指曲轴转角与气门开启时刻之间的对应关系。装配时如果正时错齿，气门会在错误时刻开闭，轻则「没劲、放炮」，重则活塞顶气门、顶弯气门杆。

装配 OHC 发动机的要点：转动曲轴使活塞处于**压缩上止点**（此时进排气门均关闭、可自由摇动），将凸轮轴上的正时标记对准缸头上的标记，再装正时链。判断压缩上止点的方法是：同时观察两个气门——在排气行程末，进排气门有一瞬间「同开」的**气门重叠**，此时过后很快就是压缩上止点。<span class="marginnote">压缩上止点的判断是配气维修的「第一关」：<strong>上止点有压缩与排气两个，对准压缩上止点才能调气门间隙、对正时</strong>。记口诀：排气门刚关、进气门将开（重叠），下一个上止点就是压缩上止点。</span>

## 4 公式解析：气门间隙的调整计算

气门间隙调整的本质是「量出当前值，算出调整量，再锁紧」。以最常见的垫片/螺钉调节为例：

$$
\Delta = L_{\text{标准}} - L_{\text{实测}}
$$

- **第一步，认识符号**：$\Delta$ 是**需调整量**（单位 $\mathrm{mm}$）；$L_{\text{标准}}$ 是手册规定的**标准间隙**；$L_{\text{实测}}$ 是塞尺量出的**当前间隙**。
- **第二步，操作含义**：$\Delta > 0$ 说明间隙偏小，需调大（换更厚的垫片或拧松调节螺钉）；$\Delta \lt  0$ 说明间隙偏大，需调小。
- **第三步，热态与冷态**：手册给出的间隙标准都是**冷态值**（发动机完全冷却）。热车时气门及缸头膨胀、间隙变小，此时测量会偏小——所以「热车调气门」是新手常犯的错误，得到的间隙在冷车后必然偏大。

**核心要点：** 气门间隙调整看似是个「塞尺+扳手」的机械活，实质是一道「量—算—调—复核」的闭环：量当前值、算调整量、调整到位、再用塞尺复核一遍。**复核**这步最容易被跳过，而它恰恰是防止「调完还是不对」的关键。

## 5 配气机构的检修要点

配气机构的日常检修集中在三处：

**正时链张紧度**：链条过松会发出「哗啦」声，且可能跳齿错位。检查张紧器是否正常伸出、链是否磨损拉长；链条磨损到规定极限应更换。<span class="marginnote">正时链的「哗啦声」与气门「嗒嗒声」要分清楚：<strong>哗啦声来自链侧敲击、嗒嗒声来自气门杆端敲击</strong>。前者怠速明显、转速升高后减弱；后者随转速升高变快。听声辨位是配气诊断的基本功。</span>

**气门与气门座的密封**：气门关闭不严会漏气，表现为缸压下降。检查方法：缸压测试、或拆下缸头灌煤油/倒置看气门口是否渗漏。气门烧蚀、座圈磨损的要研磨或更换。

**气门弹簧**：弹簧弹力衰减会导致高速时气门浮起（valve float）、失控。检查自由长度与弹力是否在标准内，异常则更换。

### 术语速查

| 术语 | 含义 |
| --- | --- |
| 配气机构 | 按时开闭进排气门的机构 |
| 气门组 | 气门、气门座、导管、弹簧、油封 |
| 气门传动组 | 凸轮轴、挺柱、摇臂、正时链 |
| 凸轮轴 | 控制气门开启时机与升程的轴 |
| 正时链 | 连接曲轴与凸轮轴、保证同步的链条 |
| 张紧器 | 自动张紧正时链、消除松弛的装置 |
| 气门间隙 | 冷态下气门杆端与传动件之间的间隙 |
| 进气门间隙 | 进气门标准间隙，通常小于排气门 |
| 排气门间隙 | 排气门标准间隙，因温度高而偏大 |
| 压缩上止点 | 压缩冲程末活塞的最高位置 |
| 气门重叠 | 排气末进排气门短暂同时开启的相位 |
| 缸压 | 气缸压缩压力，判断密封的指标 |
| 气门烧蚀 | 气门与座圈因关不严过热烧损 |
| 塞尺 | 测量气门间隙的精密薄钢片 |

### 气门间隙故障方向速查

| 间隙状态 | 症状 | 危害 |
| --- | --- | --- |
| 间隙过大 | 气门嗒嗒响、没劲 | 进排气效率下降 |
| 间隙过小 | 热态关不严、启动难 | 气门烧蚀（更危险） |

### 配气检修「四查」

- **查张紧度**：正时链「哗啦」声，张紧器与链磨损检查。
- **查密封**：缸压下降，气门口灌煤油或倒置查漏。
- **查弹簧**：自由长度与弹力衰减，高速气门浮起。
- **查正时**：装配对准压缩上止点，防错齿顶气门。

**听声辨位**：正时链「哗啦」与气门「嗒嗒」要分清——哗啦声来自链侧敲击、怠速明显；嗒嗒声来自气门杆端、随转速变快。用长螺丝刀抵住可疑部位「探听」，把声源缩小到几厘米范围。

## 6 小结

- **配气机构** = 气门组 + 传动组，负责按时开闭气门；现代车型多为 OHC 正时链传动。
- **气门间隙**是冷态预留的热膨胀余量，间隙过大「嗒嗒响、没劲」，间隙过小「关不严、烧气门」。
- **正时**是曲轴与凸轮轴的同步，装配对准压缩上止点是第一关。
- 间隙调整是「量—算—调—复核」闭环，公式 $\Delta = L_{\text{标准}} - L_{\text{实测}}$：$\Delta>0$ 间隙偏小需调大、$\Delta<0$ 需调小；标准都是冷态值，「热车调气门」是新手常犯错误。
- 正时装配对准**压缩上止点**是「第一关」：排气门刚关、进气门将开（气门重叠），下一个上止点就是压缩上止点。
- 听声辨位：正时链「哗啦」声来自链侧敲击、怠速明显；气门「嗒嗒」声来自气门杆端、随转速变快——用长螺丝刀抵住探听缩小声源。
