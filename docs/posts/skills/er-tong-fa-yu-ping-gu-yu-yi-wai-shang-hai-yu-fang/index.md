# 儿童发育评估与意外伤害预防

以 WHO《世界儿童意外伤害预防报告》《养育照护促进儿童早期发展框架》与卫健委《儿童心理行为发育预警征象筛查表》为纲，系统构建从儿童发育里程碑监测、发育异常预警识别到各类意外伤害预防与应急处置的完整知识体系。学完这些章节，就掌握了儿童发育评估与意外伤害预防的核心内容。

## 对标教材

- 《世界儿童意外伤害预防报告》（WHO）
- 《养育照护促进儿童早期发展框架》（WHO，2018）
- 《儿童心理行为发育预警征象筛查表》（卫健委）
