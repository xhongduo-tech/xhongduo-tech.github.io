## 为什么要把电路「按功能块」看

前几篇学会了认单个元件，但真实电路板上是几十上百个元件连在一起——**逐元件读必然迷失，按功能块读才能看清全局**。康华光《电子技术基础·模拟部分》第4章进入「集成运算放大器」与功能电路，正是从「元件」升维到「模块」的一章。<span class="marginnote">读电路图的「模块思维」：<strong>把一片电路看成「放大的、滤波的、稳压的、振荡的」功能块</strong>，每个块有输入、输出、核心结构。维修时先在模块层面定位「哪个功能坏了」，再进模块内部查元件——从战略到战术。</span>

这一篇覆盖五个最常遇到的模拟功能模块：**放大、滤波、稳压、振荡、比较**，并给识别与维修定位的方法。

## 1 从元件到模块：模拟电路的功能块思维

模拟电路虽然千变万化，但翻来覆去就是几种**基本功能**：

| 功能模块 | 做什么 | 核心结构 | 家电里的例子 |
| --- | --- | --- | --- |
| 放大 | 把弱信号变大 | 三极管 + 偏置电阻，或运放 + 反馈电阻 | 音频放大、传感信号调理 |
| 滤波 | 让有用频率过、无用频率挡 | 阻容（RC）网络、有源滤波 | 电源滤波、抗干扰 |
| 稳压 | 把波动的电压稳住 | 线性稳压管/LDO、开关电源 | 5 V/12 V 供电 |
| 振荡 | 产生周期性信号 | 晶振 + 放大电路、RC 振荡 | 时钟、遥控载波 |
| 比较 | 判断电压大小 | 比较器、运放开环 | 过压保护、限位检测 |

<span class="marginnote">识别功能块的方法：<strong>先看输入输出，再看核心元件</strong>——输入端接传感器/信号源、输出端接负载/后级，中间是三极管还是运放还是阻容网络，功能基本就定了。每个模块都有一条「信号流」，顺着流走就能画出整机的功能骨架。</span>

## 2 放大模块：三极管放大与运算放大器

**三极管放大电路**：核心是「一个三极管 + 偏置电阻 + 输入输出耦合电容」。共射极放大把电压放大，是模拟放大最经典的形态。识别要点：信号从基极进、从集电极出，发射极接地或有反馈电阻。

**运算放大器（运放）**：集成化的高增益放大器，是现代模拟电路的「万能积木」。运放符号是一个三角（或矩形）：「+」输入（同相）、「−」输入（反相）、输出。**闭环用法（带反馈电阻）**使其增益精确可控——这是第 4 章的核心内容，下一节给出公式。<span class="marginnote">识别电路里是不是运放：<strong>找到「一个多脚 IC + 周围一圈精密电阻」</strong>，几乎就是运放。运放的输入阻抗极高，不会「拉低」被测信号——这正是万用表测不准、运放却能量准的原因。</span>

## 3 滤波模块：RC 低通与高通

滤波模块把信号按频率分流：**低通**（低频过、高频挡）与**高通**（高频过、低频挡）。最简单的就是 **RC 滤波**：

**RC 低通**：一个电阻串联 + 一个电容对地。信号经电阻进电容端，高频被电容「短路到地」衰减，低频顺利通过。**识别**：输入端一串电阻、输出端一个电容接地。<span class="marginnote">电源滤波就是低通：整流后的脉动直流，经过大电解电容「把纹波短路到地」，剩下平滑直流。所以电源输出端<strong>「一个电解电容 + 一个高频小瓷片电容并联接地」</strong>是标准配置——电解管低频、瓷片管高频。</span>

**RC 高通**：一个电容串联 + 一个电阻对地。低频被串联电容挡住，高频通过。**识别**：输入端一个电容、输出端电阻接地——音频放大器的耦合电容就是高通，隔直流通交流。

## 4 稳压模块：线性与开关

把不稳定的电压变成稳定的输出，两种主流方案：

**线性稳压（LDO）**：核心是「调整管 + 基准 + 反馈」。简单、噪声低，但效率低（压差大的时候发热严重）。三端稳压 IC（7805/7812/LM317）是最常见形态——「三只脚：输入、地、输出」一眼可认。<span class="marginnote">三端稳压 IC 是家电维修的「熟面孔」：<strong>7805 出 5 V、7812 出 12 V、LM317 可调</strong>。测它只需量三只脚——输入该有未稳压直流、输出该有稳定电压、外壳（地）为 0。输出不对先查输入与负载，再怀疑 IC。</span>

**开关电源**：核心是「开关管 + 变压器 + 反馈」。效率高（85%+）、体积小，是现代设备绝对主流（手机充电器、家电电源全是）。但它结构复杂、故障点多——这也是本专题最后一篇要专门讲的。识别：变压器 + 大电解 + 开关管（MOSFET）+ 光耦反馈，就是开关电源。

## 5 公式解析：运放反相放大 $A = -\frac{R_f}{R_1}$

运算放大器的闭环增益由**外部电阻决定**，与运放自身参数几乎无关——这是它成为万能积木的根本。反相放大器：

$$A = -\frac{R_f}{R_1}$$

拆解三步：

- **第一步，看结构**：信号经 $R_1$ 接运放「−」输入（反相端），反馈电阻 $R_f$ 从输出接回「−」输入，「+」输入接地。这是**反相放大器**——输出与输入**相位相反**（负号的意义）。
- **第二步，看增益**：增益 $A = -R_f/R_1$，**只由两个电阻之比决定**。$R_f = 100\ \text{kΩ}$、$R_1 = 10\ \text{kΩ}$，则 $A = -10$，输入 0.1 V 输出 −1 V。想改增益？改电阻比值即可——不用换运放。
- **第三步，对应到维修**：读到「运放 + 两个精密电阻」的结构，立刻能算增益、能心算「该点输出应该多少伏」。实测输出偏离心算值太多，问题就在运放本身或反馈回路——**反馈电阻开路（虚焊/变质）会让增益失控，输出直接撞到电源轨**，这是维修中「运放输出异常高」的常见原因。

## 6 模块识别与维修定位

把模块思维落到维修流程：

**第一步，画出整机功能链**：从信号源/输入到输出，标出「放大 → 滤波 → 稳压 → 控制 → 驱动」各模块。

**第二步，按故障现象缩小范围**：没声音 → 查音频放大链；电压不稳 → 查稳压模块；无时钟 → 查振荡模块。<span class="marginnote">故障定位的两条路径：<strong>「信号寻迹」（信号在哪一级消失/失真）与「电源追查」（电源在哪一级异常）</strong>。前者用信号发生器 + 示波器逐级看波形，后者用万用表沿电源轨逐点量电压。两条路都走，多数模拟故障无处遁形。</span>

**第三步，进模块内部查元件**：锁定模块后，用万用表/示波器查该模块的核心元件——放大管是否饱和、反馈电阻是否变质、滤波电容是否失效。

## 7 用信号寻迹法检查模拟模块

模拟电路检修的「标准动作」是把**信号寻迹法**应用到功能模块链上——第 25 篇的正式方法，这里提前上手。

**准备**：信号发生器设 1 kHz 正弦波、幅度按输入级要求（如 100 mV Vpp）；示波器探头接好；电源给板子供电。

**逐级追踪**：从输入端开始，信号发生器注入信号，示波器依次测「每一级的输出」。正常链路上，每一级的输出都应比输入更大（放大级）或保持形状（缓冲级）；**信号在某一级「消失、削顶、失真」——故障锁定在这一级**。

**常见异常波形与模块诊断**：

| 波形异常 | 可能的模块问题 |
| --- | --- |
| 输出信号消失 | 该级供电缺失、放大管/运放失效 |
| 波形削顶（顶部平） | 放大级饱和、偏置点偏移 |
| 波形失真（不对称） | 工作点偏置错误、元件变质 |
| 输出带纹波/噪声 | 滤波电容失效、电源耦合不良 |
| 低频嗡嗡声 | 地线回路、滤波不足 |

**二分定位提速**：信号链较长时，**先在中间级测**——正常则前半段没问题、故障在后半段；异常则在前半段。每次对半，几次就能把故障范围缩到一两级之间，比逐级扫描快一倍。

**验证修复**：换件/重焊后，重新从输入端注入信号，确认**整条链的每一级输出都恢复正常**——不是「某一级不叫了」就收工，而是整链复验。**信号寻迹法的终点是「从头到尾的波形都对了」**。

**模块检修的「三板斧」**：不管什么模块，检查都有三件套：

**第一板斧，量供电**：模块的电源脚/供电点电压对不对——**供电不对，模块直接不工作**。量电压是最快的「模块活着吗」测试。

**第二板斧，查输入**：模块的输入端有没有正常的信号/电压——输入不对，输出当然不对。**别一上来就怀疑模块坏了，先确认喂进去的是不是对的**。

**第三板斧，比输出**：输入正常、供电正常，输出却不对——才轮到「模块本身有问题」。此时按模块内部结构（放大→反馈→元件）逐点查。

**案例**：一台功放无声。先量功放模块供电（±12 V 正常）→ 信号发生器注入 1 kHz 信号到输入端 → 示波器看输出端（没有放大信号）→ 输入正常、供电正常、输出异常 → 锁定功放模块，进一步查内部功率管与偏置。

| 检查顺序 | 验证什么 | 异常含义 |
| --- | --- | --- |
| 供电 | 模块电源电压 | 供电故障 |
| 输入 | 输入信号正常 | 前级故障 |
| 输出 | 输出响应正确 | 模块内部故障 |

**三板斧的逻辑**：**「先外后内」**——先排除外部条件（供电、输入），再怀疑内部故障。遵循这个顺序，能把「模块检修」从碰运气变成有章法。

## 8 小结

- **模块思维**：把电路看成「放大、滤波、稳压、振荡、比较」功能块，先看输入输出、再看核心结构。
- **放大模块**：三极管共射放大 + 运放闭环放大；运放识别看「IC + 精密电阻圈」。
- **滤波模块**：RC 低通（串阻并容）与 RC 高通（串容并阻）；电源滤波=低通，耦合电容=高通。
- **稳压模块**：线性 LDO（7805 三端，一眼可认）与开关电源（变压器+开关管+光耦）。
- 运放增益 $A = -R_f/R_1$
