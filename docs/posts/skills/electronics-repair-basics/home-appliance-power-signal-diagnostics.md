## 为什么这是全专题的「毕业考」

前 24 篇把安全、焊接、仪表、识读全部学完了，这一篇把它们**组装成一套完整的故障排除方法**。家电维修的终极目标不是「会焊会测」，而是「能修好一台真机器」——而这需要一条清晰的诊断路径：**从故障现象出发，锁定故障模块，定位故障元件，动手修复**。<span class="marginnote">《国家职业技能标准·家用电子产品维修工》把「故障排除」列为职业核心能力：<strong>维修的价值不在动作，在判断</strong>。焊得再好，判断错了方向也是白焊。这一篇教你一套「先想后拆、先测后换」的检修思维。</span>

以最常见的两类故障——**电源电路不工作**与**信号通路异常**——为主线，给出完整的检修方法论。

## 1 故障排除的总流程：观察 → 拆测 → 定位 → 修复

任何维修都走四步，缺一不可：

**第一步，观察**：先通电试机看现象（能试才试，注意安全）。故障现象是**最重要的线索**——「完全没电」与「有电但声音沙哑」是两个完全不同的排查方向。同时闻气味（烧焦）、看外观（鼓包、烧黑、爆裂）。<span class="marginnote">「<strong>先看后测</strong>」是维修铁律：很多故障一眼就能看出——保险丝烧黑、电容鼓包、IC 炸裂、电阻烧焦。外观检查零成本、零风险，先做，往往直接命中。</span>

**第二步，拆测**：断电、放电、拆开，用万用表/示波器测量。测量前先想「这一步要验证什么」，不盲目乱测。

**第三步，定位**：把故障从「整机」缩小到「模块」，再缩小到「元件」。定位靠的是排除法 + 信号追踪。

**第四步，修复**：换件/重焊/补焊，修完**通电验证**，确认故障消失且无新问题，再装机。

**易错点｜辨析：** 新手最常见的错误是「**跳步**」——不观察就拆、不定位就换。换件不是维修，只是「碰运气」；没有定位就换元件，可能把好的元件也换坏。

## 2 电源电路检修：从保险丝到稳压输出

家电电源电路（线性或开关）的故障检修，按「从前往后」的顺序排查：

**第一步，查保险丝**：保险丝熔断说明**后面有短路**。换上同规格保险丝前，**必须查出短路点**——直接换新保险丝，会再烧一次（或更糟）。先测整流桥、开关管、大电容是否击穿。<span class="marginnote">保险丝不是「反复烧、反复换」的消耗品，而是<strong>短路的报警器</strong>。判断短路方向：用万用表电阻档测电源输入两端，阻值接近 0 → 整流桥或其后有短路；阻值正常 → 短路在更下游或偶发。</span>

**第二步，查整流滤波**：整流桥四臂用二极管档测（正接压降、反接 OL）；滤波大电容先看外观（鼓包是铁证），再放电、测容值。**整流桥击穿或电容失效是「没电压」的头号原因**。

**第三步，查稳压环节**：线性电源测三端稳压 IC 输入/输出（输入该有未稳压直流、输出该有稳定值）；开关电源查开关管、启动电阻、反馈光耦——开关电源的排查需要示波器看启动波形，故障点多、难度高。

**第四步，查负载**：输出对地短路（滤波电容击穿、后级 IC 击穿）会拉低电源输出。**断开负载测空载电压**——空载正常、带载下跌，多半是负载短路而非电源故障。

## 3 常见电源故障模式速查

| 故障现象 | 常见原因 | 排查要点 |
| --- | --- | --- |
| 完全没电、保险丝断 | 整流桥/开关管击穿、大电容短路 | 先查短路点再换保险 |
| 完全没电、保险丝完好 | 电源输入断线、开关管开路、启动电阻坏 | 从输入逐点量电压 |
| 输出电压为 0 | 稳压 IC 坏、输出短路 | 断开负载测空载 |
| 输出电压偏低 | 滤波电容失效、稳压反馈异常 | 看输出纹波、查电容 |
| 输出电压偏高 | 稳压反馈开路、基准漂移 | 查反馈电阻/基准 |
| 通电爆保险或冒烟 | 电容极性接反、元件短路 | 先外观后测量 |

<span class="marginnote">记住检修的「<strong>剥洋葱</strong>」结构：输入 → 整流 → 滤波 → 稳压 → 输出，一层层往里查，每层量「该有的电压有没有」。大多数电源故障，用万用表沿这条链逐点量一遍，就能圈定在某一层。</span>

## 4 信号通路检修：信号寻迹法

电源没问题、机器却功能异常（没声音、没图像、控制失灵），故障在**信号通路**。检修用「信号寻迹法」：

**第一步，确认信号链**：从输入端到输出端画出信号路径——传感器/输入 → 放大 → 处理 → 驱动 → 输出。

**第二步，分段注入与追踪**：用信号发生器在输入端注入测试信号，用示波器**从前往后逐级看波形**。信号在某一级「消失、严重失真、幅度异常」——故障就锁在这级与上一级之间。<span class="marginnote">信号寻迹的核心动作是「<strong>二分定位</strong>」：先在信号链中间点测——正常则故障在后半段、异常则在前半段，然后对半继续缩小。比逐级从头扫到尾快一倍，是检修效率的关键。</span>

**第三步，级内查因**：锁定故障级后，查该级的供电、偏置、耦合元件——三极管/运放工作点对不对、耦合电容是否失效、反馈电阻是否变质。

**第四步，模拟故障复现**：无法直接测出时，用「替换法」——把可疑元件换新件试。**替换要有依据**，不是盲换；换一个、测一次，确认恢复。

## 5 公式解析：滤波电容与纹波 $V_{ripple} \approx \frac{I_{load}}{2 f C}$

「输出电压偏低 + 有嗡声」是家电维修的经典故障，多半是滤波电容失效导致**纹波过大**。纹波大小由下式估算：

$$V_{ripple} \approx \frac{I_{load}}{2 f C}$$

拆解三步：

- **第一步，看 $I_{load}$（负载电流）**：负载越大，电容放电越快、纹波越大。大功率设备对滤波电容要求更高。
- **第二步，看 $f$（电源频率）**：全波整流后，电容以**两倍市电频率**（$2 \times 50\ \text{Hz} = 100\ \text{Hz}$）放电——这就是公式里 $2f$ 的由来。
- **第三步，看 $C$（滤波电容）**：容量越大、纹波越小——**电容是纹波的「蓄水池」**。代入估算：$I_{load} = 0.5\ \text{A}$、$C = 1000\ \mu\text{F}$，$V_{ripple} \approx 0.5 / (2 \times 100 \times 1000\times10^{-6}) \approx 2.5\ \text{V}$——这么大的纹波足以让设备「哼声」、工作异常。**检修判断：实测纹波远超估算值 → 滤波电容容量衰减或 ESR 增大，更换即可恢复**。<span class="marginnote">这也是「电容老化 → 设备慢慢变坏」的量化解释：<strong>电解电容用久了容量衰减、ESR 升高，纹波随之变大</strong>，设备开始出现「时好时坏、带载变差、有哼声」等软故障。用示波器 AC 耦合看电源纹波，是判断「该换滤波电容了」的最直接方法。</span>

## 6 维修记录与经验沉淀

维修能力的成长，一半在手上，一半在**记录**。一台修完就忘，修十台还是新手；一台一记，修十台就摸出规律。

**维修记录该记什么**：

- **故障现象**：用户怎么描述的、通电后的实际表现——现象是定位的起点。
- **排查路径**：先查了什么、排除了什么、最后锁定在哪——记录「弯路」比记录「直路」更有价值。
- **根因与修复**：坏的是什么、为什么坏、怎么换的——**根因**是经验的核心。
- **代换与参数**：换了什么型号、参数如何——下次同类维修直接查记录。
- **耗时与成本**：修这台花了多久、成本多少——帮自己判断「值不值得修」。

**经验沉淀的进阶**：

- **故障模式归类**：修过十台「电源没输出」，总结出「保险丝→整流→滤波→稳压」的检查顺序——你的检修流程就开始「固化成套路」。
- **失败案例本**：记录「修坏/返工」的教训——**失败的记录比成功的记录更能防止重蹈覆辙**。
- **元件参数库**：常见元件（稳压 IC、功率管、整流桥）的参数与代换型号建个小表，代换时直接查。

| 记录项 | 价值 | 示例 |
| --- | --- | --- |
| 故障现象 | 定位起点 | 「无输出 + 保险断」 |
| 排查路径 | 少走弯路 | 「先查桥堆 → 击穿」 |
| 根因修复 | 经验核心 | 「电解电容鼓包」 |
| 代换参数 | 直接复用 | 「用 2A/600V 换 1A」 |
| 教训 | 防止重蹈 | 「忘了放电烧表」 |

**记录的心态**：维修记录不是「作业」，是**给未来的自己留的路标**。刚开始简单记几行就行，坚持下来，三个月后你会有一本「自己的维修手册」——这比任何教科书都贴近你的实战。

## 7 小结

- 检修四步：**观察（现象是线索）→ 拆测（先想后测）→ 定位（模块→元件）→ 修复（验证后装机）**；**跳步 = 碰运气**。
- 电源检修沿「**输入 → 整流 → 滤波 → 稳压 → 输出**」逐层量电压；保险丝是短路的报警器，**先查短路再换保险**。
- 信号通路用**信号寻迹法**：注入测试信号、逐级看波形、**二分定位**锁定故障级。
- 纹波公式 $V_{ripple} \approx I_{load}/(2fC)$：**实测纹波远超估算 = 滤波电容容量衰减或 ESR 增大**，换电容即恢复。
- 维修记录让经验沉淀：**记现象、记路径、记根因、记代换、记教训**，三个月攒成自己的维修手册。
