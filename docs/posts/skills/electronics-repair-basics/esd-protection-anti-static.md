## 为什么静电值得单开一篇

上一节我们处理的是「看得见的危险」——市电、大电容、明火般的电流。而静电是另一种更阴险的杀手：**你感觉不到它，它却能无声无息地毁掉一整块板**。<span class="marginnote">干燥冬天脱毛衣时「啪」地一响，那是几千伏的静电在空气里放电——放电视象你看见了，但手上那颗 MOS 管可能已经被同样的放电悄悄打穿。</span>

现代电子元件越做越小，栅氧化层越来越薄，对静电越来越敏感。一颗普通的 CMOS 芯片，几十伏的静电就能把栅极绝缘层击穿；而人体在干燥环境下随便活动就能积累数千伏静电。**维修工常常是那个亲手毁掉芯片的人**：你拿着防静电的意愿，却没有防静电的方法。iFixit 的焊接指南把 ESD 防护列为拆修任何精密电子设备的第一步，理由正在于此。这篇讲清楚静电的物理、它怎么破坏元件，以及三道防线的完整操作。

## 1 静电从哪来：摩擦起电与人体电容

静电的本质是**电荷的不平衡**。两种不同材料摩擦、分离时，电子会从一种材料转移到另一种——这就是**摩擦起电（triboelectric effect）**。尼龙与塑料摩擦、走路时鞋底与地板摩擦、脱衣服时化纤与身体摩擦，都会在人体表面积累正电荷或负电荷。

人体是一只天然的「电容器」：皮肤与衣物相当于绝缘介质，身体对大地存在一个约 **100–250 pF** 的杂散电容。电荷积累得越多，人体电位就越高。干燥环境下（相对湿度低于 30%），人体静电电压轻松可达 **3 kV–15 kV**，冬天甚至更高。<span class="marginnote">相对湿度是关键变量：湿度高时，空气中的水分子在物体表面形成导电薄膜，把电荷悄悄泄放掉；湿度低时静电无处可去，只能越积越高。这也是为什么北方干燥的冬天静电事故特别多。</span>

最讽刺的是：人体能**感觉到**的静电放电，阈值大约在 3 kV 以上；而多数精密元件在**几十到几百伏**就会受损。也就是说，**当你「啪」地感觉到被电了一下时，手上的芯片多半已经坏了**——静电的伤害永远跑在感知之前。

## 2 静电如何毁掉元器件：三种失效模式

静电对元器件的破坏不是「烧出一个洞」这么简单，它有三种典型路径：

**过压击穿**：ESD 放电瞬间产生高压，直接击穿 MOS 管的**栅氧化层**或 IC 的绝缘层。氧化层一旦被击穿，元件要么当场失效，要么参数劣化、寿命骤减。<span class="marginnote">栅氧化层的厚度在先进工艺下只有几个纳米，对应的击穿电压只有十几伏到几十伏——比一块锂电池的电压还低。这是 MOSFET、CMOS IC、运算放大器等元件「怕静电」的根本原因。</span>

**闩锁效应（latch-up）**：CMOS 芯片内部存在寄生晶闸管结构。ESD 注入的大电流一旦触发它导通，电源到地之间就形成短路，芯片持续发热直至烧毁。

**潜在性损伤**：最麻烦的一种——元件当场测起来还是好的，但内部已经形成微裂纹或局部缺陷，在后续使用中随机失效。这种「幽灵故障」让维修和返修都极难定位，也是许多电子产品「用一阵就坏」的幕后黑手。

## 3 公式解析：一次放电携带的能量 $W = \frac{1}{2} C V^2$

用静电能量公式来理解「为什么电压高不等于能量大」：

$$W = \frac{1}{2} C V^2$$

拆解三步：

- **第一步，看 $C$（电容）**：人体对地的杂散电容约 150 pF。这个值很小，但它决定了一旦放电、能释放多少电荷量。
- **第二步，看 $V$（电压）**：人体静电电压可达 3–15 kV。注意公式里电压是**平方**项，电压翻倍，能量翻四倍——这就是为什么「高压静电」如此可怕。
- **第三步，算 $W$（能量）**：代入 $C = 150\ \text{pF}$、$V = 5\ \text{kV}$，得 $W = 0.5 \times 150\times 10^{-12} \times (5\times10^3)^2 \approx 1.9\ \text{mJ}$。1.9 mJ 的宏观能量微不足道（约等于一枚灰尘落下的能量），却足以在几十纳秒内灌入一个微米级的结区——**能量密度极高**，恰好在氧化层上打出足以失效的孔洞。反过来说，这也是为什么静电放电看起来「没威力」，却能毁掉芯片。

## 4 防静电的三道防线：接地、等电位、屏蔽

防静电的思路不是「消灭静电」（在干燥环境里几乎做不到），而是**让静电以无害的方式泄放，或让它根本不形成电压差**。三个关键词：

**第一道防线，接地泄放**：把人体与工作台的电位稳定在「地」。**防静电腕带**（腕带 + 1 MΩ 电阻 + 接地线）把操作者与大地连接，人体积累的电荷经电阻缓慢泄放，避免瞬间放电。1 MΩ 电阻是安全冗余——万一操作者接触带电体，电阻限制流经人体的电流。<span class="marginnote">腕带接地要接「防静电地」（单独埋设的接地体），不能直接夹在市电插座的地线上凑数，也不能接到水管上——那可能反而把杂散电位引入工作区。正规维修台都会配一个带接地插孔的防静电垫。</span>

**第二道防线，等电位**：所有与元件接触的表面——防静电垫、防静电腕带、操作者、被修设备——通过同一接地母线连成**等电位**。等电位意味着「没有电位差，就没有放电」。防静电工作台表面铺的导电胶垫，就是把台面上所有物体拉到同一个电位。

**第三道防线，屏蔽与包装**：**防静电屏蔽袋**（银灰色带金属层的袋子）既泄放表面电荷，又屏蔽外部电场。运输、存放敏感元件时，必须使用屏蔽袋；普通塑料袋和泡沫是静电的重灾区——它们摩擦起电，等于给元件裹了一层「静电发生源」。

## 5 防静电操作规范

把三道防线落到动作上，维修时的完整流程是：

**操作前**：戴上防静电腕带并检查接地是否可靠；工作台铺防静电垫；用**防静电喷雾或加湿器**把环境湿度维持在 40%–60%。<span class="marginnote">快速自检腕带的方法：戴着腕带触摸金属水龙头或地线排，若没有任何感觉，多半接触良好；若「啪」地有放电感，说明腕带没接地——你刚刚把静电放给了手边的电路板。</span>
- **拿元件**：只捏元件本体，不碰引脚；拿 PCB 时捏板边，不碰金手指与焊盘。
- **摆放**：散落元件放在防静电垫或导电海绵上，不堆在普通塑料盒、毛绒布、干燥的化纤桌布上。
- **工具**：烙铁必须使用**防静电型**（三线接地，烙铁头通过地线泄放静电）并确认接地良好；吸锡器、镊子、刷子尽量选防静电款。
- **运输**：敏感元件（MOS 管、CMOS IC、激光二极管、精密运放）一律装进防静电屏蔽袋，贴 ESD 标识。
- **特别警惕**：手机屏幕、CMOS 摄像头模组、CPU、存储芯片是 ESD 敏感度最高的器件，操作前务必先接触工作台放电或戴腕带。

## 6 ESD 敏感度分级与高危器件

静电对不同器件的杀伤力差异巨大。工业界用**人体模型（HBM，Human Body Model）**给器件打 ESD 敏感度等级：等级越低，能承受的静电电压越低，越需要防护。

| ESD 敏感度等级 | 承受电压（HBM） | 典型器件 |
| --- | --- | --- |
| Class 0 | < 250 V | 部分射频器件、精密运放 |
| Class 1A | 250–500 V | 大部分 CMOS IC、MOSFET |
| Class 1B | 500–1000 V | 通用逻辑芯片、存储器 |
| Class 2 | 1000–2000 V | 多数分立半导体 |
| Class 3A | 2000–4000 V | 普通二极管、电阻 |
| Class 3B | 4000–8000 V | 大部分无源元件 |

对照这张表，再看人体日常活动积累的静电（干燥环境下 3–15 kV），你就明白为什么「感觉不到的静电也能打坏芯片」——**绝大多数芯片的承受能力远低于人体静电的常规量级**。

维修中尤其要当心的高危器件：

- **MOSFET 与 CMOS IC**：栅氧化层薄，几十伏即可击穿，是静电损伤的第一受害者。
- **精密运算放大器**：输入级对静电敏感，损坏后表现为输入偏置异常、输出漂移。
- **存储器与 EEPROM**：静电可能改写存储内容或损坏存储单元——「数据突然丢失」有时是静电干的。
- **激光二极管（DVD 光头等）**：对静电极度敏感，碰一下就可能永久损坏。
- **射频器件与微波元件**：微小结电容承受能力差，静电损伤后性能劣化。

**防护动作**：接触上述器件前，先触摸工作台接地金属或戴腕带泄放自身静电；器件从防静电袋取出后**立即使用、不裸放**；拿器件只捏本体不碰引脚。把这五类器件当成「碰不得的贵客」，ESD 风险就降了大半。

**防静电用品清单与自检**：把常用防静电用品列一张表，逐项对照自己缺什么、该不该补：

| 用品 | 用途 | 常见误区 |
| --- | --- | --- |
| 防静电腕带 | 人体静电泄放 | 腕带不接地=摆设 |
| 防静电垫 | 台面等电位 | 垫不接地=白铺 |
| 防静电袋 | 元件屏蔽包装 | 普通塑料袋更危险 |
| 防静电镊子/刷子 | 工具泄放 | 金属镊子蓄静电 |
| 离子风机 | 中和台面静电场 | 干燥环境才有明显效果 |

**自检流程**：戴上腕带 → 触摸台面防静电垫 → 摸金属水管（应无放电感）→ 确认腕带与垫都接地。**「无感」才是正常**——有「啪」的一声，说明静电没泄放，接地有问题。

**易错点｜辨析：** 很多人以为「戴了腕带就万事大吉」，却把腕带的鳄鱼夹夹在桌腿、塑料壳上——**夹在非接地体上，腕带只是装饰**。腕带必须通过接地线连接到真正的防静电地（专用接地端子或大地），否则静电照样积累。

## 7 小结

- 静电来自**摩擦起电**，人体是 100–250 pF 的「电容器」，干燥环境可积累 **3–15 kV** 静电；感知阈值（约 3 kV）远高于元件损伤阈值（几十伏）。
- 破坏路径有三：**过压击穿**、**闩锁效应**、**潜在性损伤**（幽灵故障）。
- ESD 能量 $W = \frac{1}{2} C V^2$
