# 电子维修基础（焊接/仪表/电路识读）

以《电子技术基础》（康华光）、《国家职业技能标准·家用电子产品维修工》与 iFixit 电子焊接指南为纲，从安全规范、电烙铁焊接、万用表示波器使用到电路与元器件识读，系统建立家用电子产品维修所需的基础技能体系。学完这些章节，就掌握了电子维修入门的全部核心操作与识读能力。

## 对标教材

- 《电子技术基础》（康华光，高等教育出版社）
- 《国家职业技能标准·家用电子产品维修工》
- iFixit 电子焊接指南
