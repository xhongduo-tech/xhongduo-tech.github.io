## 为什么万用表能「体检」元件

上一节学会了测电压、电流、电阻，这一节把万用表变成一台**元件体检仪**：测二极管好坏、给三极管认脚、判断电容是否失效。维修中大量故障的根源是「某个元件坏了」，而元件坏不坏，万用表多半能直接判出。<span class="marginnote">元件检测的本质是「<strong>拿万用表当照妖镜</strong>」：给被测元件施加已知的电信号（注入电流、充电电压），观察它的响应是否符合该元件的特性曲线——符合则大概率是好的，偏离则基本可以判定坏。</span>

这一篇按二极管 → 三极管 → 电容三类元件，讲清检测原理、接线方法与判定标准。

## 1 二极管检测：单向导电性的验证

二极管（diode）的核心特性是**单向导电**：正向导通、反向截止。万用表检测二极管正是验证这一特性：

**用二极管档（→|）测**：红表笔接阳极（A）、黑表笔接阴极（K），正向导通，表显示**正向压降**——硅二极管约 **0.6–0.7 V**、锗管约 0.2–0.3 V、肖特基管约 0.2–0.4 V、LED 约 1.8–3 V（与颜色相关）。反向（红笔接 K、黑笔接 A）应显示 **OL（超量程/不导通）**。<span class="marginnote">记忆锚点：<strong>「红进黑出」</strong>——二极管档时，表内会输出一个小测试电流，红表笔是电流「流出」端，接阳极时正好让二极管正向偏置，于是读出导通压降。把「红笔=正极」记牢，测二极管、三极管、LED 的方向判断全靠它。</span>

**判定标准**：

| 测量 | 正常 | 击穿/损坏 |
| --- | --- | --- |
| 正向 | 显示压降（0.2–0.7 V，LED 更高） | 显示 0（短路）或 OL（开路） |
| 反向 | 显示 OL（不导通） | 显示 0 或小阻值（击穿） |

**易错点｜辨析：** 一个「正反向都不导通（都 OL）」的二极管，可能是**真开路**，也可能是**测错方向**——有些二极管（如稳压二极管）反向也有特性。判好坏前先确认正负方向，再对比正向压降是否在正常范围。

## 2 三极管检测：识别基极与判断好坏

三极管（BJT）本质是**两个背靠背的 PN 结**：NPN 管内部是 N-P-N 结构，P-N 结在基极两侧各一个。所以三极管可以当成「两个二极管」来测。

**识别基极（B）**：三极管三个脚（B 基极、C 集电极、E 发射极）。用二极管档，红表笔固定接一个脚、黑表笔分别接另外两脚——若**两次都导通**（都显示压降），则红表笔接的就是**基极**，且该管是 **NPN**（因为基极为 P 型，正向偏置时电流从 B 流出到 N 区）。反过来，若黑表笔固定、红表笔分别接两脚两次都导通，则黑表笔所接为基极，管型为 **PNP**。<span class="marginnote">这个方法就是「<strong>找公共脚</strong>」：三个脚里，必然有一个脚对另外两脚的「导电方向」是一致的。找到它，B 脚确定，管型也确定（NPN 红笔为 B、PNP 黑笔为 B）。</span>

**判断好坏**：确认 B 脚后，测 C-E 间（两个结串起来）正反都不应导通；再结合 hFE 档（部分表有）插进对应管座读放大倍数。正常的三极管：B-C、B-E 单向导通，C-E 反向不导通；任一结正反都通（击穿）或都不通（开路），即为坏管。

**功率管与达林顿管**：内部带保护二极管，C-E 正向可能显示压降——这是正常的，测法略有差异，需查手册。

## 3 电容检测：充放电与故障识别

电容（capacitor）的万用表检测分两层：

**电容档（→| 或 nF/μF 档）**：把电容放电后，表笔接两端直接读容值，与标称值对比。读数明显偏小或为 0，说明电容**失效（容量衰减或开路）**；读数正常则基本可用。大容量电解电容用 μF 档，小容量贴片用 nF/pF 档。

**电阻档看充放电**：没有电容档的表（或测大电解时），用**电阻档**观察指针/数字变化——接入瞬间，表显示一个较小的阻值（电容充电电流大），随后阻值**逐渐增大到 OL**（电容充满、电流趋零）。这个「从有到无」的过程证明电容能充放电。<span class="marginnote">电阻档测电容的关键是「<strong>看趋势不看终值</strong>」：电容越大，充到 OL 越慢；阻值始终为 0 说明短路击穿，始终为 OL 说明开路失效。<strong>测前必须先放电</strong>——带电电容的残压会打表甚至烧表。</span>

**电解电容特别提醒**：电解电容有**极性**，反向接入会损坏；鼓包、漏液、顶部变形是**外观先判**的失效信号，无需上表。在线测电容受周边元件影响，精确判定要拆下来测。

## 4 公式解析：电容充放电的时间常数 $\tau = RC$

电容「充多久算充满」由时间常数决定，这也是测电容时观察「阻值变化快慢」的理论依据：

$$\tau = R \cdot C$$

拆解三步：

- **第一步，看 $R$（充电回路电阻）**：用万用表电阻档测电容时，$R$ 是表内测试源的内阻（加上表笔接触电阻）。$R$ 越大，充电越慢。
- **第二步，看 $C$（电容容量）**：$\tau$ 与 $C$ 成正比——**电容越大，充到同样电压需要的时间越长**。一个 4700 μF 的大电解，比 0.1 μF 的小电容慢了几万倍。
- **第三步，合成 $\tau$（时间常数）**：$\tau = RC$ 是「充到 63.2% 满」所需的时间，约 5 个 $\tau$ 电容「基本充满」。它把电容的「快慢」量化了：测电容时，看到阻值爬升的速度，就能反推电容容量量级——**大电解爬升缓慢、小电容瞬间到顶**，这正是「看趋势」判容量的数学基础。维修中判断「电容容量是否衰减」，除了直接读电容档，也可以靠这个充放电时间的对比经验。

## 5 在线 vs 离线检测

元件检测分两种场景，策略不同：

**在线检测（in-circuit）**：元件焊在板上直接测。速度快、不动烙铁，但读数**受周边元件并联影响**——二极管可能被旁路、电容被其他充放电通路干扰、电阻被并成偏小值。在线检测的价值是**对比**：测可疑元件与测同型号好元件对比，异常明显才拆下来复核。<span class="marginnote">在线检测的经典误区：<strong>在板上测出一个「坏的」二极管，拆下来一测却是好的</strong>——因为板上并联的元件干扰了读数。原则是：<strong>在线测异常 ≠ 元件坏，先复核再拆</strong>；在线测正常则元件大概率没事。</span>

**离线检测（out-of-circuit）**：元件拆下、单测。读数准、判定可靠，但费时费焊。**判定「元件坏」最终都要以离线检测为准**，拆下来的元件顺手测一遍，还能回收复用。

## 6 元件检测实战案例

把前面的检测方法放进真实维修场景，看三个典型病例：

**病例一：电视「有声音没图像」**。排查电源与信号通路后，怀疑高压部分。用二极管档测行输出管（大功率三极管）——B-E 结正反都通，击穿！拆下离线复测确认，更换同型号行管，图像恢复。**要点**：功率管击穿是电源/高压电路的常见病，二极管档一测即中。

**病例二：功放「一边声道无声」**。用信号寻迹法锁定到输出级，怀疑功率管。用二极管档测两个功率管的 C-E 结——一个正常、一个开路（正反都 OL）。更换后声音恢复。**要点**：三极管开路（内部断极）测「正反都 OL」，与击穿（都通）是两种相反坏法，判定都要以离线为准。

**病例三：电源「输出电压偏低、有哼声」**。先看滤波电容——顶部微微鼓起。放电后拆下，电容档测容值：标称 1000 μF 实测只有 300 μF，容量衰减严重。更换后输出恢复、哼声消失。**要点**：**鼓包 + 容量衰减**是电解电容失效的「双保险」判据，外观先判、上表复验。

| 病例 | 症状 | 检测动作 | 结论 |
| --- | --- | --- | --- |
| 电视无图 | 无高压 | 二极管档测行管 | B-E 击穿 → 换管 |
| 功放单边无声 | 输出级异常 | 测功率管 C-E | 开路 → 换管 |
| 电源哼声 | 电压偏低 | 看外观 + 电容档 | 鼓包衰减 → 换电容 |

**案例启示**：元件检测的价值不在「会操作」，而在「知道何时测、测什么、如何判」——三个病例都遵循「**外观先看 → 档位选对 → 离线确认 → 更换复验**」的完整闭环。

**检测操作小抄**：把三大元件的检测浓缩成一张「开机就能看」的速查卡，贴在维修台旁：

- **二极管**：二极管档，红笔接 A、黑笔接 K → 硅管 0.6–0.7 V、肖特基 0.2–0.4 V、LED 1.8–3 V；反接 OL。正反都通=击穿、都不通=开路。
- **三极管**：先找公共脚定基极（红笔为 B 是 NPN、黑笔为 B 是 PNP）；两结单向导通、C-E 反向不通。
- **电解电容**：先看外观（鼓包=坏）→ 放电 → 电容档读容值对比标称；无电容档则电阻档看充放电趋势。
- **小电容**：pF/nF 级用电容档直接读；在线测受并联影响，精确判定拆下复测。

**易错点｜辨析：** 测出「异常」先别急着判坏——**先确认档位、表笔、方向都对**，再确认是否在线受并联影响，最后才下「元件坏」的结论。一次误判，可能让你白换一个好元件。

**给新手的一张「检测决策表」**：不确定「该不该测、测了怎么判」时，对照下表快速决策：

| 场景 | 测什么 | 怎么判 |
| --- | --- | --- |
| 怀疑二极管坏 | 二极管档正反测 | 正出压降、反 OL 为好 |
| 怀疑三极管坏 | 找基极 + 两结 | 结单向导通、C-E 不通 |
| 怀疑电容失效 | 外观 + 电容档 | 鼓包或容值衰减即换 |
| 怀疑元件虚焊 | 蜂鸣档测通断 | 接触不良则补焊 |
| 整板没电压 | 电源端测电压 | 沿电源链逐点量 |

**一句忠告**：检测是为了**定位**，不是为了「证明元件坏」。**先问「我要排除什么」，再动手测**——带着问题的测量，才叫检修；没有目标的测量，只是按表按灯。

## 7 小结

- 二极管检测：**二极管档正接出压降、反接 OL**；硅管 0.6–0.7 V、肖特基 0.2–0.4 V；正反都不通为开路、都通为击穿。
- 三极管检测：**找公共脚定基极**——红笔为 B 是 NPN、黑笔为 B 是 PNP；结击穿/开路即坏管。
- 电容检测：**电容档读容值** + **电阻档看充放电趋势**；电解电容先看鼓包漏液、测前必放电。
- 充放电时间 $\tau = RC$
