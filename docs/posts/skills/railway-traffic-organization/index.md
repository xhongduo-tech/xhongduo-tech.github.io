# 铁路行车组织与调度

铁路行车组织与调度是铁路运输运营管理的核心专业体系，研究从车站作业、调车组织、列车运行图编制到通过能力计算与调度指挥的完整链条，是保障铁路行车安全、提高运输效率与运输能力的核心支撑学科。以《铁路行车组织》教材、《铁路技术管理规程》和国家铁路局《铁路运输调度规则》为纲，从车站工作基础到调度指挥实践，系统写完整门运营组织专业知识。

## 对标教材

- 《铁路行车组织》（中国铁道出版社，交通运输/铁道运输专业核心课程教材）
- 《铁路技术管理规程》（普速铁路部分 / 高速铁路部分）
- 国家铁路局《铁路运输调度规则》
