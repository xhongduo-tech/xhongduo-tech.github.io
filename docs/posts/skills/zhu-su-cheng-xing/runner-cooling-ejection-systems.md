## 为什么从三大系统入手

上一篇介绍了模具的整体构成，这篇深入模具里与操作工关系最直接的三个系统：**浇注系统**（料怎么进来）、**冷却系统**（热怎么带走）、**脱模系统**（件怎么出来）。三大系统是缺陷的高发地——充模不足、缩水、翘曲、顶白，几乎都能在这三个系统里找到根源。<span class="marginnote">把三大系统想成一条生产线：<strong>浇注系统是「入口」，冷却系统是「降温」，脱模系统是「出口」</strong>——任何一环不畅，制品就出问题。排缺陷时先问「这是入口、降温还是出口的问题」，思路就清晰了。</span>本篇把三大系统的结构、动作与操作要点讲透，为第 4 篇的缺陷排除铺路。

## 1 浇注系统：熔料进来的通道

浇注系统把熔料从喷嘴引向型腔，由四部分组成：

**主流道（浇道）**：与喷嘴直接对接的锥形通道，熔料最先进入的地方。主流道底部常有**冷料穴**，用来捕捉最先进入的低温料头（防止冷料进入型腔造成缺陷）。<span class="marginnote">冷料穴是浇注系统里最容易被忽略却最重要的细节：<strong>最先进入的熔料温度低、可能夹带杂物，若不截留直接进型腔，会在制品上形成冷料斑、流痕</strong>。凡制品靠近浇口处有「冷料痕」，先查冷料穴是否有效。</span>

**分流道**：把熔料从主流道分配到各型腔的通道。分流道的截面形状与尺寸影响流动阻力与凝料重量——圆形截面流动阻力最小、比表面积小、热量损失少。<span class="marginnote">分流道也有「经济账」：<strong>截面过小则阻力大、充模慢；截面过大则凝料多、浪费料</strong>。多腔模里各分流道到型腔的距离应尽量相等，否则后到的型腔「吃不饱」。</span>

**浇口**：分流道末端进入型腔前的「咽喉」，是浇注系统最细、最关键的部位。浇口的类型与尺寸决定熔料进入型腔的方式，直接关系制品质量。

**冷料穴**：位于主流道末端，储存冷料，兼有滞留料流、防止拉丝的作用。

浇注系统的设计原则是「**短、直、粗、匀**」：流程尽量短、通道尽量直、截面尽量足够大、各腔尽量均匀——这些原则都是为了**减少流动阻力、保证充填均衡**。操作工读模具时，看浇口在哪、多大，就能预判许多充模问题的方向。

## 2 浇口的类型与选择直觉

浇口是操作工看得见、摸得着的「模具变量」之一，认识常见浇口类型很有用：

| 浇口类型 | 特点 | 典型用途 |
| --- | --- | --- |
| 侧浇口 | 最常见，开在分型面侧边 | 绝大多数中小件 |
| 点浇口 | 痕迹小，开在制品顶面 | 外观要求高的件 |
| 潜伏浇口 | 隐蔽，浇口痕迹藏在内侧 | 外观件、自动切水口 |
| 直接浇口 | 无分流道，熔料直入 | 大型单腔件、厚壁件 |
| 扇形浇口 | 宽度大、分散充填 | 薄壁大面积件、防流痕 |

<span class="marginnote">浇口尺寸与制品壁厚、熔体流动性直接相关：<strong>浇口太小→充模阻力大、压力损失大、易充模不足；浇口太大→凝料粗、切除难、浇口附近应力集中</strong>。凡「怎么加压都打不饱」的件，要怀疑浇口是否偏小。</span>操作工虽不改浇口尺寸，但要能「看出浇口大小与制品壁厚的匹配度」——这决定了调机时对「充模不足」的判断方向。浇口位置还决定**熔接线**落在哪里：熔料分两路汇合处会形成熔接线，位置不佳会影响强度与外观。

## 3 冷却系统：热量带走的通道

冷却系统由模具内的**冷却水道（水路）**与外部**模温机**组成。冷却水道贴近型腔分布，通入冷却水（或导热油，用于高温模温）带走熔料的热量。

**冷却水道的布局**：水道尽量贴近型腔表面、均匀环绕制品轮廓。多腔或多区域模具的水道可**串联**（一条水走到底）或**并联**（多路并进）——并联流量分配更均匀，适合大面积件。<span class="marginnote">冷却均匀性的现场验证：<strong>摸模温——制品脱模后立即用手背快速探一遍模具表面各区域温度，温差大说明冷却不均</strong>，制品容易翘曲或局部缩水。模温机显示的温度是「进水温度」，不等于「模面温度」。</span>

**冷却水道清洁**：水道内结垢、堵塞会严重降低冷却效率。冷却水常用软水或加防垢处理，定期清洗水道——结垢一毫米，冷却能力可能下降三成以上。

**冷却水道连接**：每条水道有进/出水接头，要保证**水流方向正确、流量足够、无泄漏**。水道接错或堵住，该区域冷却失效、制品局部过热。<span class="marginnote">一个常见的低级错误：<strong>进水和出水接反，或把两条水道串成「一进一出却都接在同一端」，冷却水只在局部打转</strong>。换模后先通水看各水道是否都出水、水流是否顺畅，是必做检查。</span>

**冷却时间的判断**：冷却时间以「制品充分定型」为准。实际操作中常用**模面温度**或**制品脱模温度**来判断冷却是否到位——顶出后捏一下厚壁处，还软还烫说明冷却不足，需要加冷却时间；已硬挺、不发烫则冷却足够。<span class="marginnote">冷却不足的制品取出后会继续收缩、变形，所以「省冷却时间」往往得不偿失。<strong>冷却时间占整个注塑周期的 60%–80%</strong>，是周期优化的主战场，但缩短的前提是制品已定型。</span>

## 4 脱模系统：制品出来的通道

脱模系统负责把冷却定型的制品从型腔中推出。核心零件是**顶针（顶杆）**、**顶针板**与**回程机构**。

**顶出方式**：**推杆顶出**（顶针顶制品，最常用）、**推板顶出**（推板沿制品周边推出，适合薄壁深腔件、不留顶痕）、**推管顶出**（推管套在型芯上推出，适合圆筒件）、**气动顶出**（压缩空气吹出，适合浅腔软性件）。<span class="marginnote">顶出方式的选择看三件事：<strong>制品形状（有无深腔、圆筒）、外观要求（能否留顶痕）、脱模阻力（软性件易粘模）</strong>。推板与推管顶出顶痕小，但模具结构更复杂。</span>

**顶出机构动作**：开模到位后，机器顶杆推动模具顶针板 → 顶针板带动顶针 → 顶针把制品从型芯上推出 → 回程杆（复位杆）在下次合模前把顶针板带回原位。<span class="marginnote">顶出机构里有一个关键配合：<strong>机器顶杆与模具顶针板的「对位」</strong>——机器顶杆必须顶在模具顶针板的中心或指定位置，顶偏会造成顶针板歪斜、顶出卡滞。换模时核对这个对位，是装模流程的必做项（第 3 篇《模具安装与紧固操作》会实操）。</span>

**脱模斜度与脱模阻力**：制品冷却收缩后抱紧型芯，需要顶针施加足够的力才能脱出。若脱模斜度不足、制品有倒扣（侧凹），脱模会卡滞甚至顶裂制品。<span class="marginnote">「倒扣」是脱模的天敌：<strong>制品内侧有向里勾的结构，脱模方向被卡死，轻则顶裂制品，重则损坏模具</strong>。调机时遇到「顶不出、硬顶裂」，先问模具设计有没有侧向抽芯或更大的斜度。</span>

**顶出速度与顶出平衡**：顶出速度要「先慢后快」——慢速顶出让制品先脱离型芯，再快速推出；顶出位置要对称，避免制品单侧受力而变形。

## 5 核心对比表：三大系统一张图

三大系统是缺陷分析的「责任地图」，用一张核心对比表做速查：

| 系统 | 关键零件 | 失效表现 | 典型缺陷 | 排查方向 |
| --- | --- | --- | --- | --- |
| 浇注系统 | 主流道、分流道、浇口、冷料穴 | 流动受阻、冷料未截留 | 充模不足、流痕、冷料斑、熔接线位置 | 浇口尺寸/位置、冷料穴、分流道平衡 |
| 冷却系统 | 冷却水道、模温机 | 冷却不均、热量散不走 | 缩水、翘曲、局部发亮、变形 | 冷却均匀性、水道堵塞、模温设定 |
| 脱模系统 | 顶针、顶针板、回程机构 | 脱模卡滞、顶出力不均 | 顶白、顶裂、脱模困难、变形 | 顶针位置/面积、脱模斜度、顶出速度 |

<span class="marginnote">用这张表建立「缺陷→系统」的第一反应：<strong>表面有冷料斑找浇注，厚壁处凹陷找冷却+保压，脱模发白找脱模</strong>。先定位到系统，再在系统内查具体零件，排查就从「大海捞针」变成了「分诊看病」。</span>这张表也是第 4 篇四篇缺陷排除的「模具侧」预演——同一缺陷往往横跨工艺与模具两侧，工艺侧先调，模具侧后修。

## 6 易错辨析：三大系统中最容易混淆的三件事

**辨析｜易错点一：把「冷料穴」当成「浇口」。** 冷料穴在主流道末端、专收低温料头；浇口是分流道末端进型腔的咽喉。两者位置不同、职责不同——冷料穴防冷料斑，浇口控充模。<span class="marginnote">判断口诀：<strong>「收料」的是冷料穴，「进料」的是浇口</strong>。一条流道里先收后放，顺序别记反。</span>

**辨析｜易错点二：把「冷却时间」当成「冷却温度」。** 冷却时间是**时间参数**（秒），指保压结束后到开模前让制品定型的时间；模温是**温度参数**（℃），指模具表面维持的温度。两者共同决定冷却效果，但调法不同——厚壁件要多给冷却时间，薄壁件更依赖模温与水道。<span class="marginnote">调机现场：<strong>缩水先想「冷却时间够不够」，翘曲先想「模温均不均」</strong>——一个管时长，一个管分布。</span>

**辨析｜易错点三：把「顶白」当成「应力开裂」。** 顶白是顶针顶着制品局部发白，是脱模系统的局部受力痕迹；应力开裂是制品在应力集中处开裂，往往与浇口附近残余应力、材料脆性有关。前者在脱模系统找，后者在浇口与工艺（保压、模温）找。

## 7 术语速查表

这一章出现了大量模具零件名词，操作工在车间沟通、读工艺卡、填交接记录时都要用准确的名字。整理成速查表：

| 术语 | 英文常用名 | 一句话作用 |
| --- | --- | --- |
| 主流道 | sprue | 喷嘴对接的进料锥道 |
| 分流道 | runner | 向各型腔分配熔料 |
| 浇口 | gate | 进型腔前的咽喉，最细处 |
| 冷料穴 | cold slug well | 截留低温料头 |
| 冷却水道 | cooling channel | 带走模具热量的水路 |
| 模温机 | mold temperature controller | 控模具温度的辅机 |
| 顶针 | ejector pin | 顶出制品的小杆 |
| 顶针板 | ejector plate | 承载顶针、被机器顶杆推动 |
| 回程杆 | return pin | 合模前把顶针板带回原位 |
| 脱模斜度 | draft angle | 型芯/型腔侧壁的拔模斜度 |
| 倒扣 | undercut | 卡住脱模方向的侧凹结构 |
| 熔接线 | weld line | 两股熔料汇合形成的线 |

<span class="marginnote">记术语的窍门是「对位记」：<strong>进料段（主流道/分流道/浇口/冷料穴）是一条料路的四个环节，出件段（顶针/顶针板/回程杆）是一条动作链的三个零件</strong>——成串记，比孤立背要牢。考核笔试里「指出浇注系统各部位名称」这类题，靠的就是这串名字。</span>第十二篇《职业技能等级认定考核要点与应试》里，术语辨识是稳定拿分的题源。

## 8 小结

- 浇注系统=**主流道+分流道+浇口+冷料穴**，原则「短、直、粗、匀」；冷料穴截留冷料防缺陷。
- 浇口是「咽喉」：类型决定进料方式，尺寸过小致充模不足，过大致凝料粗、应力集中。
- 冷却系统=**水道+模温机**；**冷却均匀性 > 冷却速度**，水道要清洁、连接要正确。
- 脱模系统=**顶针+顶针板+回程机构**；顶出方式各有适用，机器顶杆与顶针板要对位。
- 核心对比表：**浇注→充模/流痕、冷却→缩水/翘曲、脱模→顶白/变形**。
- 易错三件事：冷料穴≠浇口、冷却时间≠冷却温度、顶白≠应力开裂。
