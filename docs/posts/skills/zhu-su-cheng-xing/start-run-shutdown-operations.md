## 为什么「开停机」是操作工的基本功

前面几篇讲的都是「机器会动之后怎么调」，这一篇讲的是「机器怎么开起来、怎么盯住、怎么停下去」——**开机、运行、停机**三个环节，是操作工每天重复最多、也最容易麻痹的流程。<span class="marginnote">开停机的最大风险是「<strong>以为按了几个按钮就算会了</strong>」：开机少查一项油位，停机少清一次料筒，隐患就埋下了。规范的开停机不是「走流程」，是给机器做「日保」的窗口。</span>本篇按标准作业顺序展开，这也是职业考核实操项目的基本盘。

## 1 开机前的检查：启动前的「五查」

开机前不能直接按启动，先做一遍**开机前检查**——通常归纳为「五查」：

**查油位与油温**：液压油油位在油标刻度内，油温正常（过低要先预热）。油位不足会造成液压泵吸空、异响、损坏。<span class="marginnote">液压油是机器的「血液」：<strong>油位太低液压泵会「吸空」打不到油，发出尖锐异响，长时间会烧泵</strong>。开机前看一眼油标，是最便宜的保险。</span>

**查气压**：气动系统（取件机械手、气动顶出、吹气）的气压调到规定值，气路无泄漏。

**查加热与温度**：料筒各区温度显示正常，与设定一致；升温到设定值后**保温足够时间**再开始塑化。<span class="marginnote">料筒升温后要「保温」：<strong>料筒是厚壁钢件，外壁到内壁温度传导需要时间，表面温度到了不代表芯部到了</strong>——保温时间不够就上料，冷芯会把料「憋」住，螺杆过载。保温时长看料筒大小，一般 15—30 分钟。</span>

**查安全装置**：安全门、紧急停止按钮、低压保护、光栅等**全部试一遍**，确认有效。安全装置失灵时**严禁生产**。

**查料与辅机**：料斗内物料牌号与工艺卡一致、已按规定**干燥**；模温机、冷水机、机械手等辅机状态正常。

## 2 开机流程：按顺序「热、动、清、产」

检查通过后，按顺序启动：

**上电与加热**：合上主电源，启动加热，让料筒各区温度到设定值并保温到位。<span class="marginnote">加热的坑：<strong>先上电后升温，升温期间别急着动螺杆</strong>。料筒未到温就塑化，冷料会把螺杆「咬死」，严重时扭断螺杆。</span>

**润滑与手动动作**：给导轨、肘杆等润滑点加油；在手动模式做**空循环**——合模、开模、顶出各动作走一遍，听声音、看动作是否顺畅。

**塑化清料**：把料筒内原有余料（可能是上一班残留或上次换料残留）**塑化排出**，直到新料颜色、状态稳定。<span class="marginnote">清料看状态：<strong>排出的熔料颜色均匀、无黑点、无焦料，说明料筒干净了</strong>。换色时「排到颜色纯正」就是清料合格的标准。</span>

**转入生产**：清料合格后，按工艺卡确认参数，先手动打一两模确认正常，再转半自动、全自动。

## 3 运行中的监控：盯周期、盯质量、盯异常

机器转起来后，操作工的工作是**监控**，而不是「看着它转」：

**周期监控**：注意每模周期是否稳定——周期变长说明某段动作变慢（如顶出卡滞、冷却不够），周期突然变化往往预示异常。<span class="marginnote">周期是机器的「脉搏」：<strong>自动机周期突然变长，多半是动作在「等」什么——等模温、等顶出回位、等机械手</strong>。学会看周期曲线，能提前发现故障苗头。</span>

**质量抽检**：按抽检频次取样，检查外观、重量，与首件比对。质量有波动要立刻查工艺与模具。

**异常处理**：机器报警时，**先看清报警代码与提示，再处理**——常见的报警如「安全门未关」「低压保护」「料筒温度未到」。<span class="marginnote">处理报警的纪律：<strong>先停机、后判断、再复位</strong>。盲目按复位键「消音」继续跑，是把问题压下去而不是解决掉——反复报警同一代码，一定要查根因。</span>

**记录**：运行中按班次填写**运行记录**（产量、异常、换料、停机原因），交接班时口头+书面交代清楚。

## 4 停机流程：别让「收工」变成「埋雷」

停机分**临时停机**（短时、如吃饭/换班）与**长期停机**（换模/换料/过夜/大修），要点不同：

**临时停机**：料筒保温状态（降到保温温度维持），不必清料；关掉不必要的辅机，安全门关闭。

**长期停机**：先**清料**——把料筒内余料排空（换料停机更要清干净，防止残留料碳化）；然后**降温**——关闭加热，让料筒自然冷却到安全温度；再按顺序**断动力**：停液压泵 → 停主电源 → 关冷却水 → 关压缩空气。<span class="marginnote">长期停机的顺序铁律：<strong>先清料、再降温、后断电、最后关水</strong>。料没清就断电，余料在料筒里冷却碳化，下次开机全是黑点；水没关就下班，可能漏水泡坏设备。</span>

**停机后状态**：模具涂防锈（长期停机）、设备表面清洁、工作区整理、记录填写完毕、挂牌（检修时挂检修牌）。

## 5 核心对比表：开机—运行—停机三段速查

把三个环节的核心动作压缩成一张对比表：

| 环节 | 核心动作 | 必做检查 | 常见失误 |
| --- | --- | --- | --- |
| 开机 | 五查、加热保温、清料、手动试动 | 油位/气压/安全装置/温度 | 不保温就塑化、安全装置失灵仍生产 |
| 运行 | 盯周期、抽检、处理报警、记录 | 周期稳定、重量一致 | 盲按复位键、记录不填 |
| 停机 | 清料、降温、断动力、关水 | 料筒清空、电源水气全断 | 留余料碳化、忘关冷却水 |

<span class="marginnote">三段口诀：<strong>「开：查清保试；运：盯检处记；停：清降断关」</strong>——九字诀把三段流程压缩成可背的动作序列。考核实操评分表基本就按这三段打分。</span>把九字诀记熟，开停机的每一步该干什么就不会乱。

## 6 易错辨析：开停机现场最常见的三个错

**辨析｜易错点一：料筒没保温就上料塑化。** 表面温度到了、芯部还凉，冷料把螺杆憋住，严重时扭断螺杆。<span class="marginnote">判断保温是否到位的土办法：<strong>看料筒温度显示稳定不再波动，再等 10 分钟</strong>——宁可多等，不要赶。</span>

**辨析｜易错点二：安全装置失灵还继续生产。** 安全门限位坏了、低压保护不动作，有人图省事「先干着」。安全装置是保护人的最后一道闸，**失灵必须停、修好才能开**。

**辨析｜易错点三：停机只断电不清料。** 长期停机不清料，余料碳化，下次开机打黑点，还要花时间清料——**清料省不了，越省越费**。<span class="marginnote">把「清料」看成对机器的「存钱」：<strong>停机时清干净，开机时少返工——这笔账永远是划算的</strong>。</span>

## 7 术语速查表

开停机与交接班涉及一批车间黑话，说错一个词可能误操作，务必记准。

这一串词里，有「动作」（五查、清料、空循环），有「状态」（保温、临时停机），有「管理」（运行记录、交接班）——按类别记，遇到时才能对号入座：

| 术语 | 英文常用名 | 一句话作用 |
| --- | --- | --- |
| 五查 | pre-start checks | 开机前的油位/气压/加热/安全/料检查 |
| 液压泵吸空 | pump cavitation | 油位低时泵吸入空气的异常状态 |
| 保温 | soak time | 料筒到温后维持的时间，让芯部热透 |
| 清料 | purging | 排出料筒余料直到状态合格 |
| 空循环 | dry cycle | 不注射的合模开模试动作 |
| 报警代码 | alarm code | 机器故障的数字标识 |
| 复位 | reset | 报警后恢复运行的操作 |
| 临时停机 | short stop | 短时停机的保温状态 |
| 长期停机 | long stop | 需清料降温断电的停机 |
| 运行记录 | shift log | 班次产量与异常的书面记录 |
| 交接班 | shift handover | 班次间的口头+书面交接 |
| 安全门 | safety gate | 防护门，打开即禁止合模 |

<span class="marginnote">「报警代码」是现代机的「病历本」：<strong>记熟本车间常见的几个报警代码（安全门未关、低压保护、温度未到），处理速度能快一大截</strong>。每次处理完报警，把代码和根因记在运行记录里，就是自己的排障手册。</span>这一章的术语多数与「动作/状态」相关——五查是动作、保温是状态、清料是动作、交接班是管理——分门别类记，遇到时才能对号入座。

## 8 小结

- 开机前**五查**：油位、气压、加热、安全装置、料与辅机；安全失灵严禁生产。
- 开机流程：**上电加热→保温→润滑试动→清料→转生产**，先手动后自动。
- 运行监控：**盯周期、抽检质量、按代码处理报警、如实记录**；盲按复位键是大忌。
- 停机分临时/长期：长期停机**先清料、再降温、后断电、最后关水**。
- 三段口诀：**「开：查清保试；运：盯检处记；停：清降断关」**。
- 交接班是开停机流程的收尾：**口头+书面双交代，异常不隔班**。
