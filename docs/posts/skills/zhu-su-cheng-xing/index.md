# 注塑成型操作（塑料制品成型制作工）

注塑成型是将塑料颗粒熔融后注入模具冷却定型的热塑性加工方法，是塑料制品产量占比最高的成型工艺。以《国家职业技能标准—塑料制品成型制作工》为职业导向，系统学习注塑机操作、模具装拆、工艺参数调试与常见缺陷（缩水/飞边/气痕）排除，是从操作工到技师的核心技能通道。
