## 为什么这四种要放一起排

前几篇的缺陷都很「专一」——缩水是补缩、飞边是缝隙、气痕是排气。这一篇的四种缺陷是**「杂症」**：**银纹**在表面、**黑点**是污染、**翘曲**是变形、**烧焦**是过热，它们互不相同，但常常结伴出现、共享同一批成因（干燥、料筒卫生、冷却均匀性）。<span class="marginnote">把这四种放一起学的价值在于「找共性」：<strong>银纹与黑点都指向「材料与料筒」的污染源，翘曲指向「冷却与内应力」，烧焦指向「过热」</strong>——排到后来，你练的不是四个缺陷，而是「从表象反推成因」的本事。</span>本篇把四种缺陷的成因、排查与关系讲透。

## 1 银纹与黑点：两种「表面污染」

**银纹（silver streak / splay）**：制品表面沿熔料流动方向分布的**银白色细条纹**，像水迹。

**银纹成因链**：熔料里的**挥发性气体**（水分汽化、料温过高分解气、剪切过热产生的气体）在充模时被压扁拉长，冷却后留在表面成为银白色条纹。<span class="marginnote">银纹的头号嫌疑是<strong>水分</strong>：原料干燥不足，水汽化成气被「摊」在表面——所以吸湿料的银纹，先查烘料（与上一章气泡同源）。其次是料温过高与剪切过热。</span>

**排查方向**：**干燥→料温→剪切（射速/背压）→回料纯度**。银纹多时，先查烘料记录；料温超窗口则降温；射速过快则降速。

**黑点（black spec / contamination）**：制品表面或内部的黑色小点或小块。

**黑点成因链**：**碳化物**混进熔料——料筒内残留料长期高温碳化、原料或回料中夹带杂质、料筒/螺杆死角积料、回料不干净。<span class="marginnote">黑点的排查主线：<strong>「脏从哪来」——先查料筒（残留料碳化、死角积料），再查原料与回料（杂质、混料）</strong>。换色/换料后黑点突然增多，多半是料筒没清干净。</span>

**排查方向**：**清料筒（空转塑化/清料剂）→ 查回料纯度 → 查原料批次 → 检修料筒死角**。<span class="marginnote">黑点常被忽略的根因：<strong>料筒前段温度过高，熔料在螺杆前端的「死区」滞留碳化</strong>——所以降料温、定期清料筒，比单纯「换料」更治本。</span>

## 2 翘曲：整体变形的收缩逻辑

**翘曲（warpage / deformation）**：制品整体或局部**变形**，平面度、垂直度、装配尺寸超差，是「形状」级别的缺陷。

**翘曲成因链**：本质是**收缩不均匀**——不同部位收缩量不同，产生内应力，制品为了平衡应力而变形。收缩不均的来源：**壁厚不均**（厚处收缩大）、**冷却不均**（模温不均、冷却水道布局）、**料流方向性**（沿流动方向与垂直方向收缩不同，取向应力）、**顶出不均**（脱模时受力变形）。<span class="marginnote">翘曲的物理本质：<strong>塑料收缩率在不同方向、不同部位不一样，收缩差异越大、内应力越大、翘得越厉害</strong>。所以治翘曲的核心不是「压」它，而是「让收缩均匀」。</span>

**排查方向（按优先级）**：
**冷却均匀性**：查模温分布、冷却水道，让制品各部位冷却速度一致。
**壁厚均匀性**：厚薄悬殊是翘曲温床 → 属模具设计问题，反馈模具。
- **模温**：整体模温调整影响收缩大小；模温不均导致局部收缩差异。
- **保压**：保压适当可补偿收缩、减少内应力。
- **顶出**：顶出平衡，防止顶歪顶变形。

## 3 烧焦：两种来源要分清

「烧焦」这个词在车间里对应两种不同的情况，务必分清：

**困气烧焦**：上一章的**气痕**——型腔气体被压缩升温烧焦，位置固定、靠近困气点，治法是排气/降速/降温。

**料筒焦料**：熔料在料筒内**长时间高温滞留**，碳化产生焦料，随后被新料带出，在制品上形成黑点或焦块，位置不固定、时有时无。<span class="marginnote">区分两种烧焦的抓手：<strong>固定位置→困气烧焦（模具/射速问题）；时有时无、带黑点→料筒焦料（温度/滞留时间问题）</strong>。判断对了，方向就对了。</span>治料筒焦料：降料温、减少熔料滞留（缩短循环、避免停机后高温久置）、定期清料筒。

## 4 核心对比表：四种缺陷一张图

四种杂症的成因与排查，用一张表总览：

| 缺陷 | 表象 | 主要成因 | 排查主线 |
| --- | --- | --- | --- |
| 银纹 | 表面银白细条纹 | 水分汽化、分解气、剪切热 | 干燥→料温→射速 |
| 黑点 | 表面/内部黑点 | 碳化物、杂质、死角积料 | 清料筒→查回料→降料温 |
| 翘曲 | 整体变形超差 | 收缩不均、内应力 | 冷却均匀→壁厚→保压→顶出 |
| 烧焦（困气） | 固定位置焦斑 | 气体压缩升温 | 排气→降速→降温 |
| 烧焦（焦料） | 时有时无黑焦 | 料筒高温滞留碳化 | 降料温→清料筒→减滞留 |

<span class="marginnote">这张表的读法是「一横一纵」：<strong>横向看每个缺陷的「表象→成因→排查」链；纵向对比会发现银纹与黑点共用一个「料筒卫生」检查、翘曲独属「冷却应力」、烧焦要分「模具/料筒」两账</strong>。排缺陷到这一步，你已经能「分类归档」了。</span>这五种表象（银纹/黑点/翘曲/两种烧焦）正是职业考核里「缺陷识别与处理」的核心题库。

## 5 案例示范：一个「银纹+黑点」同现的排查

设某 ABS 外观件同时出现银纹与少量黑点。新手各查各的：银纹查干燥、黑点查回料——都查了，银纹减轻但黑点仍在。

**分析**：银纹与黑点同现，往往指向一个共同根因——**料筒温度过高**：料温过高，水分与分解气更多（银纹），同时高温碳化加剧（黑点）。按材料窗口把料温降到中低位、缩短停机滞留，两种缺陷一起改善。<span class="marginnote">案例的启示：<strong>缺陷同现时，先找「公共变量」——料温同时影响银纹（分解气）与黑点（碳化）</strong>。排缺陷别孤立看，找多个缺陷的交集，往往一击即中。</span>结论：缺陷排查的进阶是「从单一缺陷到组合缺陷」，找公共根因。

## 6 易错辨析：这组缺陷最常见的三个错

**辨析｜易错点一：银纹一律加料温。** 银纹若因干燥不足，加料温只会让水分汽化更猛、银纹更多。<span class="marginnote">银纹的方向判断：<strong>干燥不足→先烘料；料温过高→降温；两者都指向「先把水分与分解气减下来」</strong>——方向几乎都是「减」，不是「加」。</span>

**辨析｜易错点二：翘曲当「顶出问题」只调顶出。** 翘曲根因多是收缩不均，顶出只是「压垮骆驼的最后一根稻草」。只调顶出不解决收缩不均，翘曲反复出现。**先查冷却均匀与壁厚，再谈顶出**。

**辨析｜易错点三：黑点全靠「清料筒」扛。** 料筒清干净了黑点还来，要查**回料纯度、料筒死角、料温**——黑点是「污染源」问题，清一次料筒只是「扫一次地」，根治要找「垃圾从哪来」。

## 7 术语速查表

这组缺陷的术语跨材料、模具、质量三个领域，记录与反馈都要用准：

| 术语 | 英文常用名 | 一句话作用 |
| --- | --- | --- |
| 银纹 | silver streak / splay | 表面银白色细条纹 |
| 黑点 | black spec | 表面/内部黑色污染点 |
| 翘曲 | warpage | 制品整体变形超差 |
| 烧焦 | burn mark | 过热形成的焦痕 |
| 碳化 | carbonization | 塑料高温降解变黑 |
| 死角 | dead spot | 料筒内滞留料的位置 |
| 回料 | regrind | 粉碎回收的浇口/废件 |
| 取向 | orientation | 分子沿流动方向排列 |
| 内应力 | internal stress | 制品内部残余应力 |
| 剪切热 | shear heating | 高速流动摩擦生热 |
| 挥发物 | volatiles | 熔料中的可汽化成分 |
| 平面度 | flatness | 表面平整程度的公差 |

<span class="marginnote">「取向」与「内应力」是翘曲的幕后黑手：<strong>分子沿流动方向取向，冷却后取向部分与未取向部分收缩不同，内应力就来了</strong>——所以薄壁高取向件更容易翘曲。理解这两个词，就理解翘曲为什么「压不住」。</span>术语是缺陷报告的语言，说得出术语，才能把现象准确描述给工艺与模具。

**记录缺陷的四个字段**：排缺陷要留痕，每起缺陷记四样——**位置**（哪一处）、**形态**（长什么样）、**频次**（稳定还是时有时无）、**已调参数**（改了什么、效果如何）。四个字段填全，换人也能接着排。

这套记录法在职业考核「缺陷处理」实操里同样适用：评分员看的就是「能不能说清位置形态、能不能按步排查、有没有留记录」。

## 8 小结

- 银纹=**水分/分解气被摊平在表面**，排查：干燥→料温→射速。
- 黑点=**碳化物/杂质混入**，排查：清料筒→查回料→降料温→检修死角。
- 翘曲=**收缩不均的内应力变形**，核心是「让收缩均匀」：冷却均匀→壁厚→保压→顶出。
- 烧焦分两种：**固定位置找困气（排气/降速）、时有时无找料筒焦料（降料温/清料筒）**。
- 组合缺陷找**公共变量**（如料温同时治银纹与黑点），别孤立排。
- 排缺陷的最高境界：**从「认缺陷」到「找根因」，从「单发」到「组合」**。
- 缺陷记录四字段：**位置、形态、频次、已调参数**——填全才能接力排查。
- 吸湿料银纹与气泡同源：**先烘料再谈工艺**，方向都是「减水分、减分解」。
- 银纹与黑点共查料筒卫生：**料筒清、料温稳、滞留少**，污染类缺陷就少一半。
