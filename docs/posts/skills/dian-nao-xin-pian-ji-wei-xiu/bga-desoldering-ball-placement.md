## 为什么拆与植是 BGA 维修的两道关卡

BGA 芯片更换的完整链条是「拆下来 → 处理焊盘 → 重新植球 → 装回去」。「拆」考验热管理与力度的把握，「植」考验对位与清洁度——两道关卡任何一道失手，芯片或主板就会二次损伤。芯片级维修的价值，正在于把「拆装芯片」这件高风险操作做成可控工艺。<span class="marginnote">拆焊最怕的不是温度不够，而是温度到了之后「硬撬」——焊球还没完全熔化就用力，会把焊盘连根拔起，导致主板永久损坏。判断「焊球熔没熔」是拆焊的核心经验，本章会给出可操作的判据。</span>

本章逐步拆解拆焊与植球的工艺动作，给出每一步的要点与判据。

## 1 BGA 拆焊工艺

**拆焊（desoldering）**的目标：在最小损伤前提下，把芯片从 PCB 上完整取下。标准流程如下：

**第一步，预热**：用下加热区把 PCB 预热到 120–150 ℃，让 PCB 整体「热透」，减小后续加热的热应力。
**第二步，上加热**：上加热头按曲线升温，将芯片加热到焊球熔化温度以上（无铅约 220–240 ℃，比熔点高 20 ℃ 左右以确保完全熔化）。
**第三步，判断熔化**：焊球完全熔化时，芯片会有「自动归位」感——轻轻触碰芯片，它有轻微浮动感；或观察到芯片与 PCB 之间缝隙处的助焊剂沸腾均匀。<span class="marginnote">判断焊球熔化的实用技巧：用镊子轻推芯片侧面，若芯片能轻微滑动后自动回位（表面张力把芯片拉回对位），说明焊球已完全熔化——此时可以取芯片。若推不动，再等片刻，切忌硬撬。</span>
**第四步，取下芯片**：确认熔化后，用真空吸笔或镊子将芯片轻轻提起，保持水平，避免拖带焊盘。
**第五步，检查焊盘**：检查 PCB 焊盘是否平整、有无掉盘，芯片底面焊球是否完整。<span class="marginnote">拆下后的检查决定下一步：PCB 焊盘完好 → 清理残锡即可重新装；焊盘被拔起（掉盘）→ 需要飞线或放弃该点；芯片焊球不全 → 需要重新植球。拆完先「验收」再「重建」，是 BGA 维修的纪律。</span>

**要点：拆焊的成功标志是「零掉盘」。** 温度曲线合理、力度轻柔、熔化判断准确，三者缺一不可。

## 2 植球工艺：钢网植球法

**植球（ball placement / reballing）**是为芯片重新制作焊球。钢网植球是最主流的方法：

**第一步，清洁芯片**：把芯片底面的残锡清理干净。用吸锡带+助焊剂+烙铁，把焊盘上的旧焊锡吸走，露出平整的焊盘。
**第二步，清洁焊盘**：用洗板水或酒精清洗焊盘，去除助焊剂残留与氧化物，保证植球时焊盘洁净。
**第三步，对位钢网**：把钢网对准芯片焊盘，使钢网开孔与焊盘一一对应，用夹具固定。
**第四步，刮涂焊膏**：把焊膏（或直接放锡球）刮入钢网开孔，使每个孔位均匀充满焊膏/锡球。<span class="marginnote">刮涂焊膏的要点是「一次刮平、力度均匀」：刮刀倾斜约 45°，从一端匀速刮到另一端，让焊膏填满每个开孔。刮太快或角度不对，会出现「有的孔满、有的孔空」，植出的球大小不一。</span>
**第五步，取下钢网**：轻轻垂直提起钢网，焊膏/锡球留在芯片焊盘上，形成整齐的球阵。
**第六步，加热成型**：用返修台或热风枪加热芯片，让焊膏中的锡粉熔融聚合成球，冷却后焊球成型。

**辨析｜易错点：** 钢网对位是植球失败的高发环节——钢网偏移哪怕半个孔距，植出的球就会整体错位，装回主板后与 PCB 焊盘对不上。对位时用放大镜/显微镜确认**钢网开孔与芯片焊盘的角点对齐**，再固定刮涂。

## 3 植球质量检查

植球完成后的检查直接决定芯片能不能装回：

**观察球阵**：用放大镜/显微镜观察焊球是否整齐、大小是否均匀、有无连球、有无缺球。合格的球阵应「排列整齐、大小一致、无连无缺」。
**测量球高**：焊球高度应均匀一致，可用卡尺或对比标准件判断。球高不均会导致装回后部分焊点接触不良。
**检查清洁度**：焊球之间与芯片边缘不应有焊膏/助焊剂残留，否则装回后可能短路或绝缘不良。<span class="marginnote">连球（两个球连成一体）是植球最常被忽略的缺陷：它会在装回后把相邻两个焊盘短路。发现连球，用烙铁加热连球处、配合吸锡带把多余焊锡吸走，重新成型。缺球则需补球——在缺球处涂助焊剂、放一颗锡球再加热。</span>

## 4 拆焊与植球的工艺要点对照表

把两道工序的要点整理成表：

| 工序 | 关键动作 | 判据/要点 | 常见失败 |
| --- | --- | --- | --- |
| 拆焊预热 | 下加热 120–150 ℃ | PCB 整体热透 | 预热不足热应力大 |
| 拆焊熔化 | 加热到熔点 +20 ℃ | 芯片可轻推回位 | 没熔就硬撬掉盘 |
| 拆焊取下 | 水平提起 | 保持水平 | 倾斜拖带焊盘 |
| 植球清洁 | 去残锡、清洗 | 焊盘平整洁净 | 残锡未清球不牢 |
| 植球对位 | 钢网精确对位 | 角点对齐 | 错位整阵偏斜 |
| 植球刮涂 | 45° 一次刮平 | 孔孔填满 | 孔空球缺 |
| 植球成型 | 加热熔融聚合 | 球径均匀 | 过烧球塌 |

**要点：工艺是「检查-动作-再检查」的循环。** 每一步做完都先检查（焊盘是否平整、球阵是否整齐），确认合格再进下一步——带着隐患往下走，最后的成品必然不合格。

## 5 拆焊与植球的常见失误

识别常见失误，比重复成功经验更能提升工艺水平。拆焊与植球的高频失误如下：

| 失误 | 后果 | 预防 |
| --- | --- | --- |
| 未熔就撬 | 掉盘、焊盘拔起 | 轻推确认熔化再取 |
| 预热不足 | 翘板、焊点开裂 | 下加热预热到位 |
| 残锡未清 | 植球不牢 | 吸锡带清理干净 |
| 钢网错位 | 球阵整体偏斜 | 角点对位确认 |
| 刮涂不均 | 球大小不一 | 45° 匀速一次刮平 |
| 过烧 | 球塌、焊盘损伤 | 控温、缩短焊接时间 |
| 焊盘污染 | 润湿不良 | 清洗焊盘后操作 |

**失误一：未熔就撬**。这是最严重的失误——焊球没熔化就硬撬，焊盘被连根拔起，PCB 永久损伤。预防的铁律：**先轻推确认芯片能回位，再取芯片**。

**失误二：预热不足**。PCB 没热透就加热芯片，上下温差大，PCB 翘曲变形、焊点开裂。预防：下加热预热到 120–150 ℃ 并保持足够时间。

**失误三：残锡未清**。芯片焊盘上的旧锡没清理干净就植球，新旧焊锡混合，植出的球不牢、大小不匀。预防：吸锡带配合助焊剂彻底清锡，露出平整焊盘。

**失误四：钢网错位**。钢网对位偏差半个孔距，植出的球整体偏斜，装回后对不上焊盘。预防：放大镜确认角点对齐再固定刮涂。<span class="marginnote"><strong>「对齐角点」是钢网对位的金标准</strong>：芯片焊盘阵列有方向性（一角缺球或标 1 脚），钢网开孔也带同样的方向标记。对位时先找两角对齐，再整体核对——只靠「看着差不多」就刮涂，是错位的温床。</span>

**要点：失误多发生在「着急」与「自信」两处**——着急跳过检查，自信省略对位。把每道工序的检查点当成「刹车」，工艺质量才有保障。

## 6 植球的替代方法

钢网植球是主流，但并非唯一。了解替代方法，能在没有合适钢网时救急：

**直接植球法（手工植球）**：不用钢网，在芯片焊盘上涂助焊剂，用镊子或吸球笔逐颗摆放锡球，再加热成型。适合球数少的芯片或应急处理——速度慢，但不需要专用钢网。

**焊膏点涂法**：不用锡球，直接在焊盘上点涂焊膏，加热后焊膏聚合成球。球的尺寸由焊膏量控制，适合少量植球。

**混用法**：钢网植球为主，个别缺球用手工补球——兼具效率与灵活。

<span class="marginnote"><strong>替代方法的适用边界</strong>：手工植球与点涂法适合球数少（几十颗以内）的芯片；球数数百上千的 BGA，手工植球效率低、精度难保证，还是钢网植球可靠。方法选择以「球数 × 精度要求」为准，不为省事牺牲质量。</span>

**要点：钢网植球是「主力」，替代方法是「备用」**。主力保证质量与效率，备用解决应急——两手都会，遇到没有钢网的芯片也能从容应对。

## 7 拆焊植球的精进方向

拆焊与植球工艺精进的方向，是「稳、准、匀」三字诀：**稳**——动作稳定不抖动，拆取不伤焊盘；**准**——对位精准不偏移，植球位置精确；**匀**——温度均匀、锡量均匀，球径一致。

每个字诀都是刻意练习的目标：拆焊练「稳」——用报废板反复拆装，直到动作如行云流水；植球练「准」——用放大镜核对每次对位，直到一次到位；成型练「匀」——观察每次球径一致性，直到整齐划一。**工艺的精进没有捷径，只有大量正确练习的累积**。

<span class="marginnote"><strong>「稳准匀」三字诀，是拆焊植球工艺的自我检查表</strong>：每次操作后用三字诀复盘——动作稳不稳、对位准不准、结果匀不匀——把每次练习都变成一次有反馈的精进。</span>

**要点：以「稳准匀」为纲，用刻意练习打磨手艺**。拆焊植球是「手上功夫」，功夫靠练、靠复盘，不靠天赋。

## 8 小结

- 拆焊四步：**预热 → 加热熔化 → 判断熔化 → 水平取下**，核心是零掉盘。
- 熔化判据：**轻推芯片可回位**，证明焊球已完全熔融，切忌硬撬。
- 钢网植球六步：**清洁 → 对位 → 刮涂 → 脱网 → 加热成型**，对位是关键。
- 植球后检查：**球阵整齐、无连无缺、球高均匀、无残留**。
