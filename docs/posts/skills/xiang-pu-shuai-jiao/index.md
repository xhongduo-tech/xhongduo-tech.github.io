# 相扑与摔跤

相扑与摔跤是融合力量、技巧与智慧的世界级古老格斗运动，涵盖古典式摔跤、自由式摔跤、中国式摔跤与相扑四大体系。以《国际摔跤》教材、UWW 竞赛规则及中国式摔跤、相扑运动资料为纲，系统学习从历史源流、基本技术、实战战术到竞赛规则与科学训练的完整内容，为业余训练与观赛鉴赏建立扎实基础。

## 对标教材

- 《国际摔跤》（体育院校通用教材）
- 世界摔跤联合会（UWW）《国际式摔跤竞赛规则》
- 中国式摔跤教学与训练资料
- 日本相扑协会《相扑竞赛规则》及相扑运动资料
