# 汽车驾驶技能（C1/C2 小型汽车）

中国机动车驾驶人超 3 亿，汽车驾驶是现代人最普遍的实用技能。以公安部令第162号《机动车驾驶证申领和使用规定》、交通运输部《机动车驾驶员培训教学大纲》为纲，结合人民交通出版社《机动车驾驶员培训教材》，系统重建从车辆认知、法律法规到场地驾驶、道路驾驶、安全文明驾驶的完整实操与考试训练体系。学完这些章节，就写完了 C1/C2 小型汽车驾驶的全部内容。
