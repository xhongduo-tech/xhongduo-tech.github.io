## 为什么从科目三的起步开始

科目二在封闭场地里练「停」，科目三在真实道路上练「行」。**科目三的第一组项目——上车准备、起步、直线行驶——是「从静态到动态」的过渡**：上车准备考规范、起步考「把车安全地开进车流」、直线行驶考「让车笔直地跟着你的视线走」。这三个项目是所有道路驾驶的入口，也是考官最先观察你的部分。这一节把它们逐一拆开，重点讲清与科目二的差别：路是活的，车是动的，风险是真实的。

**为什么这三个项目放在最前面**：上车准备是「安全习惯的起点」，起步是「第一次进入车流的动作」，直线行驶是「把车开稳的基本功」。科目三把它们放在最前面，是因为它们构成了整个道路驾驶的基础循环——每一次变道、超车、靠边，都要先回到「观察—打灯—起步/变道」这套动作上来。把这三个项目练成条件反射，后面的综合项目就都「有地基可依」。

## 1 科目三的上车准备：更严格的流程

科目三的上车准备在科目二的基础上更严格，因为它发生在真实道路环境：

**上车前（绕车一周）**：从驾驶位一侧开始，**逆时针**绕车一周，检查车辆周边与车底。科目三考试中，这一步还常常要求「**观察车后与周围交通情况**」并确认安全，才开门上车。<span class="marginnote">科目三的绕车一周，观察的对象从「车本身」扩展到了「车与道路的关系」：车后是否有来车、行人；开门前是否会影响后方车辆。<strong>开门杀</strong>（随意开门撞到后方来车）是真实道路的高危事故，科目三把它放进了「上车准备」的考核点。</span>

**上车后**：调整座椅、后视镜、系安全带、检查仪表与挡位、确认手刹状态——与科目二流程一致，但多一项「**确认安全后起步**」。

**核心要点：** 科目三的上车准备，核心是「**把安全确认前置**」：上车前确认车周、上车后确认车况、起步前确认路况。三道确认，一道都不能省。

**观察的三次确认**：上车准备里的「观察」实际要做三次——绕车时看一次（车周环境）、开门前看一次（后方来车）、起步前再看一次（盲区）。三次确认都做到，起步才谈得上安全。

## 2 起步：把车安全地开进车流

科目三的起步与科目二最大的不同，是**起步的「周围环境是活的」**——旁边可能有车、有行人、有非机动车。规范的起步流程：

1. **观察**：通过后视镜与转头确认左侧后方安全（无来车、行人）。
2. **打灯**：开启**左转向灯**（起步驶入行车道需向左并线），保持至少 3 秒。
3. **鸣喇叭**（可鸣喇叭的路段）：提醒周围车辆与行人。
4. **挂挡松手刹**：挂 1 挡（C1）/D 挡（C2），确认安全后**松开手刹**。
5. **平稳起步**：缓抬离合（C1 半联动）/缓松制动（C2），轻加油，车辆平稳驶入行车道。
6. **回灯**：车身进入车道后，关闭转向灯，正常行驶。

**易错点｜辨析：** 起步的高频失误：**忘打转向灯**、**打灯不足 3 秒就起步**、**不看左后方盲区直接起步**（最危险）、**起步熄火**（C1 离合抬太快）、**起步后忘记回转向灯**。科目三电子评判对「起步前未观察、未开转向灯」有明确扣分，且这些也是真实事故的直接成因。<span class="marginnote">起步的安全顺序是「<strong>先观察、再打灯、后动车</strong>」——观察确认了「能不能走」，打灯告知了「我要走」，动车才执行「走」。顺序乱了（先动车再看），危险就已经发生。</span>

**平地与坡道的起步衔接**：科目三起步多发生在平直路段，但若起步点正处坡道，应按《坡道定点停车与起步》的方法处理——半联动给足动力再松手刹，防止后溜。掌握了坡起的「驱动力 > 重力分力」的力平衡，平地上的起步就只是它的「简化版」，心态与技术都更从容。

**核心要点：** 起步的本质是「**一次安全的变道**」——从静止进入车道，与「变更车道」共享同一套逻辑：观察 → 打灯 → 确认 → 行动 → 回灯。

## 3 直线行驶：让车笔直地「跟着视线走」

直线行驶看似简单，却是新手最容易「跑偏」的项目。它的核心不是「方向盘不动」，而是「**看得远 + 微调勤**」：

**视线放远**：把视线放到前方 **100–150 米**的道路尽头，用「余光」兼顾车头附近。看远处，才能感知到车辆在车道内的整体位置；只看车头前两三米，车已经歪了你才发现。

**微调方向**：直线行驶不等于「方向盘锁死不动」——道路有起伏、路面有倾斜，车辆会自然跑偏。正确做法是**小幅、高频修正**：发现车身偏离，轻打 1–2 厘米的方向修正，回正后稳住。让方向盘在「似动非动」之间保持车辆笔直。<span class="marginnote">直线行驶的判断标准是「<strong>车身与车道边线平行、左右两侧距离均匀</strong>」。看远处 + 用两侧边线做参照，比「盯着车头」更可靠。科目三直线行驶项目还要求车速与挡位匹配，且一般不要求刻意高速，重在「走得直」。</span>

**挡速匹配**：直线行驶时保持挡位与车速匹配（如 3 挡行驶），避免低速高档的拖挡或高速低挡的轰油门。

**易错点｜辨析：** 直线行驶最典型的错误是「**握死方向盘**」——双手紧绷、越怕跑偏越乱动，结果越修越歪。正确的手感是「**轻握、随车微调**」：方向盘是「顺着路面」的，不是「对抗路面」的。另一个错误是「视线盯着车头」——越看近处越看不出偏斜，一定要放远视线。

**参照方法**：直线行驶的「直」要有一个可比的参照——视线放远看道路尽头的消失点，同时用余光让车身与两侧车道线保持平行、左右距离均匀。还可以用「雨刮器节点 / 车头 1/3 处」与车道线的相对位置做辅助参照。参照越多，越能在车身刚有偏离苗头时及时发现并修正。

**车速与直线的关系**：直线行驶并不要求「慢」，而是要求「稳」——在道路允许的速度下保持匀速、方向稳定。速度过低（拖挡）或忽快忽慢，都会让车辆更难保持直线。科目三直线行驶一般要求 3 挡左右、以道路正常速度通过，重在「走直」而非「走慢」。

## 4 核心对比表：科目二起步与科目三起步

本节以「核心对比表」替代公式解析——两类起步的对照，看清科目三「严在哪」。

| 对比项 | 科目二起步 | 科目三起步 |
| --- | --- | --- |
| 环境 | 封闭场地 | 真实道路 |
| 观察 | 看场地参考点 | 看后视镜 + 转头确认盲区 |
| 转向灯 | 部分项目要求 | 必须打、且至少 3 秒 |
| 风险 | 压线扣分 | 可能撞车撞人 |
| 核心 | 起步动作熟练 | 起步动作 + 安全确认 |

**核心要点：** 科目二练的是「动作」，科目三考的是「动作 + 判断」。同一个起步，科目二比「快不快、稳不稳」，科目三比「有没有观察、有没有打灯、有没有确认安全」。动作早已会了，科目三练的是**把安全习惯刻进流程**。

## 5 起步与直线行驶的综合：驶入车道后的第一次「走」

起步完成后，紧接着往往就是直线行驶或驶入规定车道。这一段「从静止到笔直行驶」的衔接，把本节内容串成一条线：

- **起步**把车从路边带进行车道；
- **加速加挡**把车速提到道路要求；
- **直线行驶**让车稳定在车道中央笔直前进。

**核心要点：** 这一段「上路初体验」决定了考官对你的第一印象，也决定了你在真实道路上的起点能力。把「观察—打灯—起步—加速—走直」练成一条流畅的链，科目三就成功了一大半。<span class="marginnote">从「从极限到大模型」的主线看，科目三是对科目二所有单项的「<strong>集成测试</strong>」——就像把数学公式放进真实问题里求解。每个单项都熟，集成才不会崩；集成稳了，才算真正「会开」。</span>

## 5 起步与直线行驶的高频失误速查

起步与直线行驶是科目三「开篇三项目」之二，也是新手最早暴露问题的地方。把高频失误整理成速查表：

| 环节 | 高频失误 | 对策 |
| --- | --- | --- |
| 绕车 | 漏查车后、未观察交通 | 逆时针绕车一周 + 观察 |
| 上车 | 忘系安全带 | 固定顺序：座椅→镜子→安全带 |
| 起步 | 不打灯 / 灯不足 3 秒 | 打左灯、数三秒再动 |
| 起步 | 不观察直接走 | 看镜 + 转头确认盲区 |
| 起步 | 熄火、溜车 | 缓抬离合至半联动再加油 |
| 直线 | 握死方向盘 | 轻握、小幅高频修正 |
| 直线 | 盯着车头看 | 视线放远 100–150 米 |
| 直线 | 挡速不匹配 | 听声 / 看转速换挡 |

**核心要点：** 这张表的前半段是「流程问题」，后半段是「手感问题」——流程问题靠「按清单走」解决，手感问题靠「放远视线 + 轻握微调」解决。两类问题都解决，起步与直线行驶就稳了。<span class="marginnote">一个提升起步平稳度的小技巧：起步时<strong>离合抬到半联动、车刚动起来的那一刻稳住 2–3 秒</strong>，再继续加油——这 2–3 秒的「稳住」，让车辆从静止到移动的过渡最平顺，也是 C1 起步不熄火的关键。</span>

**把它连成一条链**：上车准备 → 起步 → 直线行驶，本质是「安全确认 → 进入车流 → 稳定行驶」三步。练的时候把三者当作一个整体反复走，让「先确认、再操作」成为自动反应——后面的变道、超车、会车，都建立在这条链的地基上。

## 6 小结

- **上车准备**：逆时针绕车一周 + 观察车周，上车后按清单调座椅、镜子、安全带、仪表。
- **起步流程**：观察 → 打左灯（≥3 秒）→ 鸣喇叭 → 挂挡松手刹 → 平稳驶入 → 回灯。
- **直线行驶**：视线放远 100–150 米、小幅高频微调、挡速匹配。
- 起步本质是一次「安全变道」；直线行驶的敌人是「握死方向 + 盯着车头」。
- 平地起步与坡道起步同源：坡起按「半联动 + 手刹」处理，力平衡是底层逻辑。
- 科目三 = 科目二动作 + 真实环境判断，安全习惯是最大的加分项。

在下一节，我们将学习道路上最频繁也最考验判断的操作——**加减挡与车速控制**，让车跟着道路节奏走。
