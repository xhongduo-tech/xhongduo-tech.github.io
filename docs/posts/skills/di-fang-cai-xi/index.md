# 地方菜系与地域饮食文化

以《中国饮食文化》《中华饮食文化史》为理论纲、以《八大菜系》系列菜谱为实操纲，系统梳理八大菜系与各地域饮食风味、代表菜品与地方饮食文化。一餐一饭里藏着地理与历史，学会它就能读懂中国每个地方的味觉密码。
