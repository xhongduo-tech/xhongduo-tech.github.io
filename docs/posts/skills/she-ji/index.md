# 射击

射击是一项以精确、稳定与心理控制为核心的奥运竞技运动，涵盖手枪、步枪与飞碟等多个项目，其核心在于射击姿势的稳固、瞄准与扳机控制的精准以及竞赛规则的规范约束。
以《射击运动教程》、ISSF《国际射击运动联合会竞赛规则》与国家体育总局《射击训练大纲》为纲，系统重建从项目概览、枪支装备、基本技术到专项训练、竞赛规则与比赛实践的完整知识体系。
