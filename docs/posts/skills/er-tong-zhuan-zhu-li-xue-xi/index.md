# 儿童专注力与学习习惯培养

儿童专注力与学习习惯培养是关乎儿童认知发展与自主成长的能力训练学科，聚焦专注力训练、学习习惯养成与自主学习能力的系统构建。以《儿童专注力训练》、《孩子是如何学习的》、《正面管教》为纲，从专注力基础评估、训练方法、习惯养成到自主学习与积极管教层层递进。

## 对标教材

- 《儿童专注力训练》
- 《孩子是如何学习的》（约翰·霍尔特）
- 《正面管教》（简·尼尔森）
