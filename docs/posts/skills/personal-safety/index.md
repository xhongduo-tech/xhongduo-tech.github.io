# 个人安全与应急防护

以《公共安全应急指南》与公安部《安全防范手册》为纲，系统构建从安全意识养成、防诈骗防盗窃、人身暴力防范到突发灾害避险与应急自救互救的完整个人安全与应急防护能力体系。学完这些章节，就写完了个人安全防范与突发事件应对的全部内容。

## 对标教材
