# 速度滑冰与花样滑冰

速度滑冰与花样滑冰是冬季奥林匹克运动的代表性冰上项目，短道速滑与花样滑冰更是中国冬奥的夺金优势项目。以 ISU 国际滑联《速度滑冰与短道速滑规则》《花样滑冰规则》及其评分系统、《冰上运动教程》与中国滑冰协会训练大纲为纲，系统构建从冰上基础、竞赛规则、裁判体系到专项技术、战术配合与训练方法的完整知识框架。
