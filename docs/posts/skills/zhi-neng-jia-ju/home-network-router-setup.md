## 为什么先修路再通车

智能家居的每一条指令，本质都是一段网络数据：你点「关灯」，数据从手机 → 路由器 → 网关 → 灯。这条路只要有一环堵了、断了，灯就「没反应」。所以老练的安装师傅到客户家，**第一件事不是装设备，而是先看网络**——路由器放哪、是什么型号、信号覆盖到不到每个房间。本篇讲透家庭网络的地基：拓扑、IP、路由器配置与覆盖方案。

## 1 家庭网络三件套

**光猫（ONT）**：运营商入户的光纤信号在这里转成电信号，是整个家庭网络的「入口」。光猫通常兼做路由器，但性能孱弱、功能简陋，智能家居设备一多就顶不住。<span class="marginnote">安装师傅的常见操作是「桥接」：把光猫改成桥接模式，只做信号转换，把拨号与路由交给后面性能更强的路由器。改桥接需要运营商超级密码，家庭改造单经常要跟客户确认这一步。</span>

**路由器**：家庭网络的「大脑」——负责拨号上网、NAT 地址转换、DHCP 地址分配、无线信号发射。智能家居对路由器的核心要求不是网速，而是**带机量与稳定性**：同时挂 30–50 台设备不掉线、不重启。

**交换机/AP（接入点）**：房间多、弱电箱到各房间有预埋网线时，用交换机扩展有线口，用 AP 扩展无线覆盖。**能用有线，不靠无线**是施工铁律——摄像头、中枢网关这类关键设备优先插网线。

**重点：智能家居网络的关键指标是「带机量」与「稳定性」，不是「千兆还是万兆」。** 给客户选路由器，优先看「支持多少台设备同时在线」，其次才是带宽。

## 2 IP 与地址分配

每台联网设备需要一个**IP 地址**才能被找到。家用路由器默认通过 **DHCP** 自动给设备发地址，地址形如 `192.168.1.x`。设备重新上线，地址可能变化——这会给某些依赖固定 IP 的功能（如摄像头端口转发）带来麻烦。

三个配置动作值得掌握：

**① 开 DHCP，别手动填**：绝大多数智能设备用 DHCP 就够，手动填 IP 反而容易冲突。

**② 静态 IP/地址绑定**：对摄像头、NAS、中枢网关这类「我要主动连它」的设备，在路由器里做 **DHCP 地址绑定**，让它们每次拿到同一个 IP，方便后续配置与排障。<span class="marginnote">在路由器后台「DHCP 静态分配」里，把摄像头、网关的 MAC 与固定 IP 绑死，是排查「App 连不上设备」的最省力手段之一——地址不再飘，端口映射才有效。</span>

**③ 设备命名**：把路由器里的设备名改成「客厅灯」「书房网关」而不是一串乱码 MAC，排障时一眼能认出谁掉线了。

## 3 路由器配置要点

**双频合一与分离**：现代路由器同时广播 2.4 GHz 与 5 GHz 两个频段。5 GHz 快但穿墙弱，2.4 GHz 慢但覆盖远。多数智能设备只支持 2.4 GHz。<span class="marginnote">配网失败的头号原因：<strong>手机连着 5 GHz，智能设备只认 2.4 GHz，两者不在同一个频段自然搜不到</strong>。所以配网前先把手机切到 2.4 GHz 的 SSID，配完再切回来。</span>「双频合一」模式（一个 SSID 自动选频）对手机方便，但会误导配网，老练师傅常建议分开广播。

**信道选择**：2.4 GHz 用 1、6、11 三个不重叠信道。路由器默认自动选信道，但邻居多时频繁跳信道反而引发掉线，可固定到相对空闲的信道。

**QoS（流量整形）**：给摄像头、中枢网关设高优先级，防止下载占满带宽导致智能设备「卡」。

**连接数上限**：家用路由器带机量通常 30–50 台。设备超过 50 台的豪宅，需要企业级路由器或把部分设备挪到 Zigbee 网关下（Zigbee 设备不占路由器连接数）。<span class="marginnote">这是协议选择反哺网络设计的关键：<strong>传感走 Zigbee/Thread 挂在网关上，一个网关只占路由器 1 个连接，却管着 30 多台设备</strong>——路由器压力骤减。全屋百台设备靠这个才能跑起来。</span>

## 4 覆盖方案：三种组网

设备掉线的另一个高频原因是**信号到不了**。三种覆盖方案：

**单路由器**：小户型（<90㎡）、隔墙少时够用。路由器要放全屋几何中心、开阔高处，避开弱电箱（金属箱体屏蔽信号）与墙角。

**Mesh 组网**：两个以上节点组成一个统一 Wi-Fi，全屋一个 SSID，漫游无缝切换。适合中大户型、复式。部署要点：节点之间尽量**无线直通**或网线回程，避免「接力掉速」。

**AP 组网（AC + AP）**：每个房间预埋网线接一个 AP，由 AC 控制器统一管理。覆盖最稳、支持设备最多，但需要施工时布网线，属于**装修阶段就规划**的方案。<span class="marginnote">「Mesh」与「AP」是经常被混淆的两个词：<strong>Mesh 是无线自组网，AP 组网是靠网线</strong>。Mesh 施工轻，AP 覆盖稳；精装房后改造选 Mesh，装修规划选 AP。</span>

## 5 核心对比表：三种覆盖方案

纯技能主题，用对比表替代公式解析：

| 对比维度 | 单路由器 | Mesh 组网 | AC + AP |
| --- | --- | --- | --- |
| 适用户型 | 小户型 | 中大户型/复式 | 大平层/别墅 |
| 是否需要布网线 | 否 | 否（可加网线回程） | **是** |
| 统一 SSID | 是 | 是 | 是 |
| 漫游体验 | — | 较好 | 最好 |
| 带机量 | 30–50 | 50–100 | 100+ |
| 施工复杂度 | 最低 | 低 | 高（需电工配合） |
| 适合阶段 | 任意 | 后装改造 | 装修规划 |

**选型结论**：后装改造、户型不大，优先 Mesh；设备上百、要求极致稳定，或正在装修，直接用 AC + AP；小户型单路由足矣，把预算省给网关与传感器。

## 6 术语速查表

网络是智能家居的「地基」，把路由器相关术语一次归档：

| 术语 | 含义 |
| --- | --- |
| 光猫（ONT） | 运营商光纤入户的信号转换设备，家庭网络入口 |
| 路由器 | 家庭网络大脑，负责拨号、NAT、DHCP 与无线发射 |
| AP（接入点） | 扩展无线覆盖的设备，有线接入交换机 |
| 交换机 | 扩展有线口的设备，把网线分给多台设备 |
| DHCP | 自动分配 IP 地址的协议，设备入网默认走它 |
| NAT | 网络地址转换，让多台设备共享一个公网 IP |
| SSID | Wi-Fi 网络名称，设备配网时选择的就是它 |
| 带机量 | 路由器能稳定同时接入的设备数量 |
| 桥接 | 光猫只做信号转换、由路由器拨号上网的模式 |
| 静态分配 | 把设备的 MAC 与固定 IP 绑定，地址不再漂移 |
| QoS | 流量整形，给关键设备分配高优先级带宽 |
| AP 隔离 | 客户端互相隔离的设置，会阻断设备间通信 |

## 7 常见网络误区

网络配置的误区往往要等到「设备掉线」才暴露，提前规避：

| 误区 | 正解 |
| --- | --- |
| 路由器越贵网速越快 | 智能家居看带机量与稳定性，不是带宽 |
| 5 GHz 快就全用 5 GHz | 智能设备多数只支持 2.4 GHz，需双频分开 |
| 双频合一最省事 | 合一模式会误导配网，老练师傅建议分开广播 |
| 弱电箱里放路由器就行 | 金属箱体屏蔽信号，路由器要放开阔高处 |
| 设备多就换更贵的路由器 | 先把传感类设备挪到 Zigbee 网关，减负比换机有效 |
| 网线随便接 | 关键设备（摄像头、网关）优先有线，稳定远胜无线 |
| 光猫就是路由器 | 光猫性能孱弱，建议桥接后由路由器负责拨号 |

## 8 小结

- 网络三件套：**光猫、路由器、交换机/AP**；关键指标是带机量与稳定性。
- 用 **DHCP 地址绑定**给摄像头/网关固定 IP，用**设备命名**方便排障。
- 配网前把手机切到 **2.4 GHz**，是「搜不到设备」的头号解药。
- 传感类设备挂 Zigbee 网关，**为路由器省连接数**，是全屋百台的架构前提。
- 覆盖三方案：小户型单路由、后装 Mesh、装修 AP 组网。

在下一节，我们从网络层下到电气层——讲智能家居用电安全与布线规范，这是安装工作的安全红线，也是新手最容易栽跟头的地方。
