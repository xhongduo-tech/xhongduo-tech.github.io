## 为什么传感器的「位置」比「品牌」更重要

自动化场景的触发器几乎全部来自传感器：人进客厅灯亮、门开警报响、湿度低于 40% 加湿器启动。但传感器有一个反直觉的特点——**它不是「越灵敏越好」，而是「装得对才灵」**。装错位置，昂贵的传感器要么误报不停，要么该触发时不触发。传感器安装是整个智能家居里最考验「空间感」的环节。

## 1 传感器类型

**人体传感器（PIR）**：被动红外，检测人体红外热辐射的变化。分**广角型**（大范围、看动静）与**幕帘型**（一道直线、看通过）。幕帘型适合门口、阳台门——人经过即触发，而不是待在沙发上就一直触发。这是人体传感器最常见的选型分叉。<span class="marginnote">PIR 的原理是「热变化」：<strong>人静止不动时，PIR 不一定持续输出</strong>，所以「人坐沙发上一小时」的场景（判断是否有人在屋）要用带存在检测的毫米波/双鉴传感器，而不是普通 PIR。</span>

**门窗磁（门磁）**：由磁簧开关与磁铁两部分组成，两者分离时状态翻转。装在门框与门扇、窗框与窗扇上，用于判断门窗开合。常见用途：开门亮灯、开门报警、开窗关空调。

**温湿度传感器**：检测温度与相对湿度，用 DHT/SHT 类温湿度芯片。用于联动空调、加湿器、除湿机。**注意温湿度传感器的位置会「说谎」**：装在空调直吹处、窗边、阳光直射处，读数都失真。

**烟雾/燃气报警器**：火灾与燃气泄漏的安全类传感器。安装位置最讲究：烟雾报警器装天花板（烟雾向上聚集），燃气报警器装在燃气具附近**离地 0.3–0.5 米**（天然气比空气轻，往上飘；液化气比空气重，往下沉，要按气种定高度）。<span class="marginnote">燃气报警高度是安全常识也是考点：<strong>天然气（甲烷）向上飘，报警器宜装在燃气具上方 0.3–0.5 米；液化气（丙烷）下沉，报警器要装在低处</strong>。装反了，泄漏了也未必报警。</span>

**水浸传感器**：检测地面积水，装在厨房水槽下、卫生间、洗衣机旁等漏水高风险点，两触点接触水即触发。

## 2 安装位置三原则

**① 对着「必经路径」，不对着「静止区域」**。人体传感器装门口、走廊转角，捕捉走动的人；不要正对窗户（窗帘飘动能误触发）、不要正对空调出风口（气流温度变化被误判为「人」）。<span class="marginnote">「空调误触发」是 PIR 头号误报源：<strong>PIR 把冷暖气流当成热源变化，人没进门灯却亮了</strong>。装人体传感器时避开空调出风直吹方向，是防误报的第一招。</span>

**② 高度决定探测范围**。广角人体传感器一般装 **1.2–2.2 米**，越高覆盖越大但灵敏度下降；安装角度稍微下压，避免探测到窗外的行人。门窗磁要保证磁铁与主体**平行对齐、间距 1–2cm**——距离太远磁簧吸不动，状态永远显示「开」。

**③ 一个场景配两种触发源**。单一传感器判断容易误判，重要场景用「双重确认」：例如「回家模式」用门锁状态 + 门磁/人体双触发，避免快递员经过门口就触发全屋回家场景。

## 3 调试与常见误区

安装完要做的调试，比安装本身更花功夫：

**误报排查三步**：先看朝向（是否对着窗/风口）→ 再看高度（是否过高/过低）→ 最后调灵敏度。多数误报不用换设备，调位置就能解决。

**漏报排查**：传感器装了却不触发，优先查**电池**（低电量灵敏度骤降）与**离线**（Zigbee 传感器掉线）。Zigbee 传感器是休眠设备，重新上线有延迟，测试时按一下设备按键唤醒再试。<span class="marginnote">传感器「测不到」时的检查顺序：<strong>电量 → 信号（App 看在线状态）→ 位置朝向 → 遮挡物</strong>。别一上来就判定传感器坏了——十个「坏」里九个是位置或电量问题。</span>

**温湿度校准**：把温湿度传感器与可靠温湿度计放一起比对，读数偏差较大时（超过 ±1℃ / ±5%）在 App 里做偏移校准。

**电池与维护**：传感器多为纽扣电池（CR2032 等），寿命几个月到两年。交付时告诉客户**换电池周期**与低电量提醒设置，并把低电量告警接进自动化（如小爱播报）。

纯技能主题，用对比表替代公式解析：

| 传感器 | 检测原理 | 最佳安装位置 | 高度参考 | 常见坑 |
| --- | --- | --- | --- | --- |
| 人体 PIR | 红外热变化 | 门口/走廊/客厅 | 1.2–2.2m | 对空调风口误报 |
| 门窗磁 | 磁簧通断 | 门框/窗框 | — | 磁铁未对齐 |

| 水浸 | 触点导电 | 水槽下/卫生间 | 地面 | 触点氧化 |

## 5 术语速查表

传感器是自动化链条的「眼睛」，术语先归档：

| 术语 | 含义 |
| --- | --- |
| PIR | 被动红外传感器，检测人体红外热辐射变化 |
| 存在检测 | 判断「是否有人在」的持续状态检测，常用毫米波 |
| 门磁 | 磁簧开关与磁铁组成的门窗开合检测器 |
| 幕帘型 PIR | 探测一道直线的传感器，适合门口、阳台门 |
| 广角型 PIR | 大范围探测动静的传感器，适合客厅 |
| 温湿度芯片 | 测量温度与相对湿度的传感器核心，如 DHT/SHT 系列 |
| 气敏半导体 | 检测燃气浓度的传感器原理 |
| 纽扣电池 | 传感器常用的供电电池，如 CR2032 |
| 误报 | 未发生真实事件却被触发的报警 |
| 漏报 | 真实事件发生却没有触发 |
| 探测角度 | 传感器能感知的水平/垂直范围 |
| 探测距离 | 传感器有效感知的最远距离 |
| 冷却时间 | 两次触发之间的最短间隔 |
| 触发事件 | 传感器输出的一次动作信号 |
| 持续状态 | 传感器输出的有人/无人持续信号 |
| 场景联动 | 传感器触发后执行的设备动作 |
| 报警阈值 | 触发报警的数值界限，如燃气浓度 |
| 校准偏移 | 修正传感器读数偏差的补偿值 |
| 双鉴 | 两种技术共同判断，减少误报 |
| 吸顶安装 | 安装在天花板的传感器安装方式 |

## 6 传感器安装常见误区

传感器的问题几乎都是「装错了」，而不是「坏了」：

| 误区 | 正解 |
| --- | --- |
| 传感器越灵敏越好 | 过灵敏会被气流、宠物误触发，灵敏度要按场景调 |
| 人体传感器能检测「有人坐着」 | 普通 PIR 只测动作，静止时需存在检测传感器 |
| 门磁随便贴 | 磁铁需与主体对齐、间距 1–2cm，否则永远报「开」 |
| 温湿度计随便放 | 出风口、窗边、阳光直射处读数失真 |
| 燃气报警器统一装高处 | 天然气装高处、液化气装低处，按气种定高度 |
| 传感器没反应就是坏了 | 先查电量与信号，再查位置，十个「坏」九个是位置问题 |
| 传感器装得越高越好 | 过高会降低灵敏度，按类型定高度 |
| 传感器越多越安全 | 装错位置的多不如装对位置的少 |
| 门磁不需要对齐 | 磁铁错位或间距过大，永远报「开」 |
| 温湿度计不需要校准 | 偏差超 ±1℃/±5% 应做偏移校准 |
| 烟雾报警器随便装 | 应装天花板，避开油烟与蒸汽直冲 |
| 水浸传感器只装卫生间 | 厨房水槽下、洗衣机旁同样是高风险点 |
| 传感器不需要维护 | 定期换电池、清洁探头，保灵敏度 |

## 7 小结

- 传感器类型各司其职：**PIR 看动静、门磁看开合、温湿度看环境、燃气水浸保安全**。
- 装位三原则：**对必经路径、高度定范围、重要场景双触发源**。
- 误报先查**朝向与风口**，漏报先查**电量与离线**——十个「坏」里九个是位置或电量问题。
- 燃气报警器高度**按气种定**：天然气向上装高处，液化气向下装低处。
- 交付时交代**换电池周期**，把低电量告警接进自动化。
