## 为什么选生态比选设备更优先

新手最容易犯的错，是先把喜欢的功能设备买回家，再考虑「怎么把它们凑到一起」；结果经常是三个牌子的灯、两家的网关、五个 App，手机通知栏一屏图标，开关灯要打开不同的 App。老手选型的第一步永远是反问一句：**你要站在哪条生态上？**

生态（Ecosystem）决定了三件大事：设备之间能不能互联、场景怎么触发、以及**谁来当「大脑」**。生态一旦定错，返工成本极高——换生态几乎等于全部设备重买。所以这一篇把三条主流生态路线讲透，再给出从需求到设备清单的完整选型流程。

## 1 三条生态路线

**米家（Mi Home）生态**：以小米/米家 App 为中枢，云平台在小米，设备覆盖面极广、价格亲民，是国内家庭改造的性价比之王。它的典型链路是：Zigbee 传感器 → 米家多功能网关 → 小米云 → 米家 App/小爱音箱。优点：**开箱即用、联动丰富、成本低**；代价：设备状态与场景运行在云端，外网断了本地场景可能失灵（部分场景已支持本地执行）。<span class="marginnote">米家的「本地自动化」近年逐步开放，但大量场景仍依赖云端。断网时「能手动开关、自动场景失灵」是米家系统的典型表现，选型时要向客户说清这条边界。</span>

**HomeKit 生态**：苹果的家庭平台，核心卖点是**隐私与本地优先**——场景在家庭中枢（HomePod/Apple TV/iPad）本地运行，不经过苹果云；Siri 语音、HomeKit 安全视频是加分项。代价：认证设备贵、数量相对少，且要求家里有**常驻的家庭中枢**。

**Home Assistant（HA）生态**：开源本地智能家居平台，跑在自己家里的设备（树莓派、NAS、迷你主机）上。它的哲学是「**万物皆可接入**」——米家设备、HomeKit 设备、任意 Zigbee 设备都能通过集成拉进来，用一套界面、一套自动化统一管理。代价：**有技术门槛**，需要懂一点 Linux、YAML、网络；没有官方客服，靠社区。

## 2 选型的四个硬指标

生态定了，具体选哪台设备，用四个指标筛：

**① 通信协议**：回顾第 2 篇——传感器、开关面板这类低功耗设备优先选 **Zigbee/Thread**；摄像头、音箱这类大流量设备选 **Wi-Fi**。同一个生态里，协议决定要不要额外网关，直接关系安装复杂度与总价。

**② 供电方式**：灯具、插座、空调面板通常是**强电直供**；门锁、窗帘电机、传感器则有**电池、USB、强电**三种。供电方式决定布线预留，选型阶段就要对着图纸标注「这里要留零火线」「那里要留插座」。<span class="marginnote">最贵的返工是布线返工：<strong>墙内线走完再发现要加零线，代价是凿墙</strong>。所以选型清单必须和电工布线图一起出，一次对齐。</span>

**③ 兼容性（认证/接入方式）**：米家生态里要区分「米家 App 直连」还是「仅支持小爱」还是「要额外网关」；HomeKit 要认准包装上的 Works with Apple HomeKit 标识；HA 生态要查该设备有没有官方或社区集成。

**④ 关键规格**：摄像头看分辨率与夜视；门锁看锁体类型与天地钩；传感器看探测角度、探测距离与电池寿命。规格不过关，安装再完美体验也差。

**重点：先用四个指标筛出一张短名单，再谈品牌与价格。** 反过来先看品牌，很容易被营销术语带走，买回协议不搭、供电不符的设备。

## 3 核心对比表：三条生态怎么选

纯技能主题，用对比表替代公式解析：

| 对比维度 | 米家 | HomeKit | Home Assistant |
| --- | --- | --- | --- |
| 中枢位置 | 小米云（部分本地） | 家庭中枢本地 | 自家设备本地 |
| 断网可用性 | 部分场景失灵 | 本地场景可用 | 全部本地可用 |
| 上手门槛 | 低 | 低 | 高 |
| 设备广度 | 极广、性价比高 | 认证设备少而贵 | 万物皆可接入 |
| 语音助手 | 小爱同学 | Siri | 兼容多助手 |
| 适合人群 | 追求性价比的多数家庭 | 苹果全家桶用户 | 爱折腾的玩家/极客 |
| 安装调试定位 | 主推路线、跑量 | 高端单子、苹果用户 | 复杂集成、跨品牌单 |

**选型铁律**：给客户做方案时，**默认从米家入手**（易上手、生态全）；客户是苹果用户且预算充足，升级 HomeKit；客户明确要「不依赖云、跨品牌一统」，才上 Home Assistant。<span class="marginnote">三条生态并不互斥：<strong>HA 可以同时把米家与 HomeKit 设备拉进同一个系统</strong>，实现「米家买设备、HA 当大脑」。第 15、16 篇专门讲这种跨生态集成。</span>

## 4 选型流程：从需求到清单

把选型做成流水线，避免遗漏：

**第 1 步：需求访谈**。问客户三个问题：最想自动化的是哪三个场景（照明、安防、舒适）？家里是谁在用（老人小孩要语音，极客要 DIY）？预算与改造程度（全屋还是局部、要不要布线）？

**第 2 步：定生态与架构**。按第 1 节的路线选择定中枢：米家网关几个、要不要 HA 盒子、HomePod 放哪个房间。

**第 3 步：逐房画设备点位**。客厅：灯/开关、空调面板、电视、窗帘、人体传感；玄关：门锁、门磁、灯；卧室：睡眠场景设备；厨房卫生间：燃气/水浸报警。每个点位标注：协议、供电、安装位置。

**第 4 步：四指标筛选与出清单**。生成设备型号清单，标注是否需要额外网关、是否需电工配合、哪些地方要补插座。清单交付给客户与电工，就是安装施工的依据。

## 5 术语速查表

选型沟通中的高频词，统一口径避免理解偏差：

| 术语 | 含义 |
| --- | --- |
| 生态 | 设备所属平台体系，决定互联方式与控制入口 |
| 中枢 | 家庭自动化的大脑，保存场景规则并本地执行 |
| 网关 | 协议转换设备，私域协议与 IP 之间的翻译官 |
| 认证设备 | 通过官方认证、可原生接入生态的设备 |
| 桥接 | 通过中间设备把一种生态的设备接入另一生态 |
| 本地优先 | 场景与数据优先在本地运行，不依赖云 |
| 配网 | 设备首次接入家庭网络的过程 |
| 点位 | 施工图上标注的设备安装位置与供电要求 |
| 布线预留 | 装修阶段为智能设备预埋的线管与插座 |

## 6 常见选型误区

选型阶段踩坑的代价是返工，提前规避这几个高频误区：

| 误区 | 正解 |
| --- | --- |
| 先买设备再定生态 | 先定生态再选设备，换生态等于设备重买 |
| 只看品牌不看协议 | 协议决定要不要网关、功耗与带宽，比品牌更影响安装 |
| 忽略供电方式 | 供电决定布线预留，装修后补插座代价高昂 |
| 以为 HA 什么都能接就无脑上 | HA 需要技术门槛与持续维护，普通家庭米家更合适 |
| 摄像头只看分辨率 | 存储方案、夜视、隐私边界同样决定体验 |
| 预算全砸在单件设备上 | 网关、网络、布线这些「看不见的地基」更值得投入 |
| 只看单价不看总价 | 网关、安装、调试、售后都要计入总成本 |
| 大品牌一定兼容 | 同一品牌不同系列也可能不互通，查协议与认证 |
| 传感设备随便买 | 探测角度、距离、电池寿命都是选型硬指标 |
| 只装设备不做规划 | 先画点位图再施工，避免返工 |
| 忽视售后与扩展 | 选型要留扩展余地，为后续加设备留口子 |
| 把路由器当赠品 | 网络是地基，路由器值得单独预算 |
| 抄邻居配置 | 户型、家庭成员、习惯不同，配置不能照搬 |
| 一次买齐所有设备 | 分阶段实施，边用边调整更稳 |
| 忽略家人使用习惯 | 设备要家人愿意用，先培训再验收 |
| 只选最贵生态 | 生态匹配家庭需求即可，不是越贵越好 |

## 7 小结

- 选型**先定生态**，再选设备；生态决定互联方式与「大脑」位置。
- 三条路线：**米家**（性价比主流）、**HomeKit**（苹果本地优先）、**Home Assistant**（开源万物皆可接入）。
- 四个硬指标：**通信协议、供电方式、兼容性、关键规格**，先筛短名单再看品牌。
- 选型流程：需求访谈 → 定生态架构 → 逐房画点位 → 四指标出清单。
- 三条生态可叠加：HA 能把米家与 HomeKit 设备统一管理。
