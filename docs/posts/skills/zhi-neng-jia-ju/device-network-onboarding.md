## 为什么「配不上网」占了一半的售后电话

设备安装好、通上电，接下来就是配网——让设备连上家里的 Wi-Fi 或网关。这一步看似简单，却是售后率最高的环节：「设备搜不到」「一直转圈」「配上了又离线」。原因在于配网涉及**手机、路由器、设备**三方协同，任何一环不对就失败。这一篇把配网原理、通用流程与排查方法讲透，让配网从「玄学」变成「流程」。

## 1 配网的四种方式

设备第一次怎么知道家里的 Wi-Fi 密码？答案是通过配网方式「告诉」它。四种主流方式：

**AP 配网（软热点）**：设备自己发出一个临时热点（Soft-AP），手机连上这个热点，把家里 Wi-Fi 的 SSID 与密码写进设备，设备再断开热点、连上家中 Wi-Fi。这是**最常见、兼容性最好**的方式，几乎各品牌都有。配网时手机要**切到 2.4 GHz**（设备大多不支持 5 GHz）。

**蓝牙配网**：手机通过蓝牙把 Wi-Fi 信息发给设备，设备自动连接。体验最顺滑——不用手动切热点、不用找 SSID。Zigbee 网关、部分音箱与灯常用蓝牙配网。

**声波配网**：手机播放一段特定音频，设备用麦克风「听」到 Wi-Fi 信息。老式智能音箱常见，速度慢、怕噪音干扰，已渐被淘汰。

**扫码/配网码**：设备上印二维码，App 扫描后自动识别型号并引导配网；部分设备支持「配网码」（NFC/二维码），扫码即连。<span class="marginnote">配网的本质就一句话：<strong>把「家里 Wi-Fi 的名字和密码」安全地告诉一个还不认识路由器的设备</strong>。AP 是「设备发热点你来连」，蓝牙是「手机蓝牙直接喂」，扫码只是「先认型号再走前两种」。</span>

## 2 配网通用流程与失败排查

以米家 App 为例，标准流程是：设备通电 → App 添加设备 → 选择配网方式 → 手机切 2.4 GHz → 输入 Wi-Fi 密码 → 等待设备上线。

**配网失败，按顺序查这六项**：

**① 手机频段**：手机连的是不是 2.4 GHz？设备不支持 5 GHz，频段不一致必然搜不到。**这是第一排查项。**<span class="marginnote">双频合一（一个 SSID 自动选频）的路由器配网也容易翻车：<strong>手机可能被路由器「派」到 5 GHz 上，而设备只认 2.4 GHz</strong>。排查时手动关掉手机 5 GHz 或用「仅 2.4G」访客网络配网。</span>

**② 密码正确性**：Wi-Fi 密码含特殊字符（`$`、`&`、空格）时，设备端解析可能出错，重输或换简单密码测试。

**③ 设备距离**：配网时设备离路由器太远、信号弱，超时失败。把设备拿到路由器旁配好，再移回原位。

**④ 路由器限制**：路由器开了 MAC 过滤、AP 隔离（客户端隔离），设备配上了网但互相不通。检查路由器设置，AP 隔离要关。

**⑤ 设备状态**：设备处于异常状态（如上次配网残留配置）无法进入配网模式。多数设备**长按复位键 5–10 秒**可恢复出厂，重新配网。

**⑥ 网关/协议**：Zigbee 设备不是连路由器，是连**网关**。配网前先确认网关在线、处于配对模式，且设备与网关同品牌同生态。

## 3 局域网接入：设备怎么「住进」网络

配网成功只是开始，设备要稳定住在局域网里，还需要理解它的「住址」：

**DHCP 分配**：路由器自动给设备分配 IP 地址（如 `192.168.1.23`）。多数设备用 DHCP 即可，但**地址会变动**——依赖固定地址的功能（摄像头访问、端口转发、HA 集成）要给它固定 IP。

**设备命名与识别**：在路由器后台或 App 里把设备改名为「客厅灯」「门锁」，排障时一眼认出。米家 App 里设备会显示在线状态，离线时红灯提示。

**离线判断**：设备「离线」有三种情况——**断电**（物理掉电）、**断网**（Wi-Fi 信号问题）、**云端失联**（设备在线但连不上厂商云，App 显示离线）。三者处理方式完全不同：断电查电源，断网查信号，云端失联重启设备或等云恢复。<span class="marginnote">「App 显示离线」不等于「设备坏了」：<strong>先看设备指示灯</strong>——灯亮是云端失联，灯灭是断电或断网。指示灯是排障的第一口信息。</span>

**静态 IP 与地址绑定**：对网关、摄像头、NAS 这类关键设备，在路由器做 **DHCP 静态分配**（绑定 MAC 与 IP），让它们每次拿到同一地址。这样端口转发、HA 集成、摄像头访问地址都稳定。

## 4 核心对比表：不同协议设备的配网方式

纯技能主题，用对比表替代公式解析：

| 设备类型 | 配网方式 | 接入对象 | 常见失败点 |
| --- | --- | --- | --- |
| Wi-Fi 设备 | AP 配网 | 路由器 | 手机频段不对、密码含特殊字符 |
| 蓝牙设备 | 蓝牙配网 | 手机（直连） | 蓝牙未开、距离过远 |
| Zigbee 设备 | 网关配对 | Zigbee 网关 | 网关不在配对模式、生态不匹配 |
| Thread 设备 | 边界路由器配对 | Thread 边界路由器 | 无边界路由器、未启用 Thread |
| 有线设备（POE） | 无需配网 | 交换机/路由器 | 网线/供电问题 |

**结论**：先把设备「归好类」再配网——Wi-Fi 设备关注手机频段，Zigbee/Thread 设备先确认网关，有线设备直接看物理连接。配网前问一句「这设备连谁」，一半的失败已经避免了。

## 5 术语速查表

配网相关词汇，排障时能准确描述问题：

| 术语 | 含义 |
| --- | --- |
| 配网 | 设备首次接入家庭网络的过程 |
| AP 配网 | 设备发出临时热点，手机连上后写入 Wi-Fi 密码 |
| 软热点（Soft-AP） | 设备自身发出的小范围临时热点 |
| 蓝牙配网 | 手机通过蓝牙把 Wi-Fi 信息传给设备 |
| 声波配网 | 手机播放音频传递 Wi-Fi 信息，已渐淘汰 |
| 配网码 | 设备上的二维码/NFC，扫码引导配网 |
| 复位键 | 长按恢复出厂设置，重新进入配网模式 |
| DHCP | 自动分配 IP 的协议，设备入网默认走它 |
| 静态分配 | 绑定 MAC 与固定 IP，地址不漂移 |
| 云端失联 | 设备在线但连不上厂商云，App 显示离线 |
| 在线状态 | App 中设备的联网指示，用于判断离线原因 |
| 指示灯 | 设备自带的状态灯，颜色/闪烁含义见说明书 |
| 访客网络 | 路由器提供的隔离 SSID，配网时可用它隔离干扰 |
| MAC 地址 | 设备唯一的物理地址，静态绑定时要用 |
| 重启 | 给设备断电再上电，刷新网络与握手状态 |

## 6 配网失败排查口诀

配网失败按这套口诀逐步排查，避免瞎试：

| 步骤 | 检查内容 |
| --- | --- |
| ① 频段 | 手机是否切到 2.4 GHz |
| ② 密码 | Wi-Fi 密码是否含特殊字符导致解析出错 |
| ③ 距离 | 设备是否离路由器太远 |
| ④ 路由器 | 是否开了 MAC 过滤或 AP 隔离 |
| ⑤ 设备 | 是否需要长按复位重新进入配网模式 |
| ⑥ 网关 | Zigbee/Thread 设备是否先确认网关在配对模式 |

## 7 小结

- 配网四方式：**AP 配网最通用、蓝牙配网最顺滑、声波与扫码是补充**；本质是告诉设备 Wi-Fi 密码。
- 配网失败排查六步：**手机频段 → 密码 → 距离 → 路由器限制 → 设备复位 → 网关状态**。
- Zigbee/Thread 设备不连路由器，**先确认网关/边界路由器**在配对模式。
- 局域网接入三件事：**DHCP 地址、设备命名、关键设备静态绑定**。
- 「App 离线」先看指示灯：**灯亮查云，灯灭查电与信号**。
