## 为什么窗帘是「量错就废」的定制件

智能窗帘和灯泡不一样，它几乎都是**按窗定制的**：轨道要按窗户宽度截取，电机要按窗帘重量匹配，行程要按实际开合范围校准。量错一个尺寸，轨道装不下、电机带不动、窗帘合不拢——而且没有「万能标准件」可换。这篇把智能窗帘的选型、安装、校准讲成一条可复制的流程。

## 1 轨道类型与开合方式

**开合帘（左右拉开）**：最常见的智能窗帘，电机带动轨道上的挂轮，窗帘左右开合。分**单开**（从一侧开向另一侧）与**双开**（从中缝向两侧开）。

**卷帘/百叶**：上下卷动，常用直流电机，对限位精度要求更高。

**轨道安装方式**：

- **顶装**：轨道固定在窗框顶部或窗帘盒内，最隐形、最整洁。需要在窗顶有承重位置（实木、混凝土、石膏板要用膨胀栓/飞机胀塞）。
- **侧装**：轨道固定在窗户两侧墙面，适合窗顶无承重位的场景。<span class="marginnote">顶装 vs 侧装的关键是<strong>窗顶承重</strong>：吊顶石膏板承重差，顶装必须打胀塞到上层楼板；石膏板内没有握钉点，硬装轨道会连板一起坠下来。</span>

**轨道弯直**：普通平窗用直轨；飘窗、弧形窗用**弯轨**，弯轨需按窗户弧度现场弯制，安装难度高一档。

## 2 电机选型

电机是窗帘系统的「心脏」，三个参数必须匹配：

**① 牵引力（扭矩）**：决定能拉动多重的窗帘。家用开合帘电机牵引力常见 40–60N（牛顿）级别。窗帘越厚（遮光布、绒布）、轨道越长、褶皱越密，需要的牵引力越大。**量窗帘重量再选电机**：超过电机额定牵引力，帘布拉到一半就停，是安装后最常见的「罢工」原因。<span class="marginnote">选电机的黄金法则：<strong>电机额定牵引力 ≥ 窗帘总重的 1.5 倍</strong>。厚重的遮光帘+长轨道，宁大勿小——带不动不是故障，是选型错误。</span>

**② 协议与供电**：Wi-Fi 电机直连路由器（安装最省事，但要留插座）；Zigbee 电机要网关（米家生态常见）；锂电池电机免布线、定期充电（适合没有插座的老窗）。**电源位置**是安装前就要定的：电动窗帘电机通常在轨道一侧，必须在该侧预留插座（或锂电池）。<span class="marginnote">窗帘电机是「留插座」的重灾区：<strong>窗帘装好才发现窗边没插座</strong>，只能走明线或换锂电池版。规划阶段就要在每扇要装电动窗帘的窗边标注电源位。</span>

**③ 离合与手拉**：选带**手动离合**的电机——断电或故障时能手动拉窗帘，不至于全屋窗帘卡死在关闭状态。这是居家安全的底线功能。

## 3 安装流程

以开合帘顶装为例，标准五步：

**第 1 步：量尺**。量窗户净宽，轨道长度取「窗户宽度 + 两端各 10–15cm」（留出帘布堆叠与遮挡余量）；量窗帘盒深度，确认轨道与电机放得下。

**第 2 步：固定轨道**。顶装时先打孔装胀塞，再固定轨道托架；轨道水平度用水平尺校准——**轨道不水平，窗帘会自己往低处滑**。弯轨先按弧度预弯再固定。

**第 3 步：装电机与传动**。电机按方向（左装/右装）接入轨道传动端，装好皮带或联轴器，确认电机与轨道连接无卡滞。<span class="marginnote">电机装在轨道哪一端，决定窗帘的收纳方向：<strong>电机端是「死端」，帘布向另一侧收拢</strong>。要窗帘向左侧收，电机就装在轨道右侧，反之亦然。</span>

**第 4 步：挂帘布**。帘布挂钩均匀挂上挂轮，拉动测试：手动轻轻一拉，帘布应顺畅滑动到底，无明显顿挫与偏斜。

**第 5 步：接线送电**。插电（或装电池），电机通电自检，转入行程校准。

## 4 行程校准与限位

行程校准是电动窗帘安装的「灵魂步骤」——电机必须知道「开到哪里停、关到哪里停」：

**机械限位**：老式电机靠轨道两端限位挡块，安装时滑动挡块到正确位置。

**电子行程（遥控/App 校准）**：现代电机通电后，先按遥控或 App 使帘布运行到**全开位置**，设定「开限位」；再运行到**全关位置**，设定「关限位」。操作要点：

校准前先确认帘布**两侧余量对称**，否则全开后帘布会偏向一侧。
全关位置留 2–3cm 微缝，避免帘布过度挤压电机导致堵转报警。
校准完成后**反复试开合 3–5 次**，确认每次停位一致、无爬行（缓慢位移）。<span class="marginnote">「行程漂移」是电子限位的典型故障：<strong>用久了开合停位慢慢偏移，多半是轨道有阻力或帘布变重</strong>，电机每次都在硬转，计数失准。先清轨道灰尘与卡涩，再重新校准行程。</span>

## 5 核心对比表：不同窗户怎么配

纯技能主题，用对比表替代公式解析：

| 窗户类型 | 轨道 | 电机 | 安装要点 |
| --- | --- | --- | --- |
| 平窗/落地窗 | 直轨顶装/侧装 | 开合帘电机 | 量净宽+两端余量，窗顶需承重 |
| 飘窗（三面） | 弯轨 | 开合帘电机 | 弯轨现场弯制，弧度处挂轮易卡 |
| 卷帘窗 | 卷帘专用 | 卷帘电机 | 限位精度要求高，多次校准 |
| 老窗无插座 | 直轨 | 锂电池电机 | 免布线，注意充电周期 |
| 重型遮光帘 | 加强直轨 | 大牵引力电机 | 牵引力≥1.5 倍帘重 |

## 6 术语速查表

窗帘安装的尺寸与机械词汇，量尺前先对齐：

| 术语 | 含义 |
| --- | --- |
| 开合帘 | 左右拉开式窗帘，智能窗帘的主流形态 |
| 卷帘 | 上下卷动式窗帘，对限位精度要求高 |
| 顶装 | 轨道固定在窗框顶部或窗帘盒内，最隐形 |
| 侧装 | 轨道固定在窗户两侧墙面，窗顶无承重位时用 |
| 牵引力 | 电机能拉动的力，单位牛顿（N） |
| 行程 | 帘布从全开到全关的运行范围 |
| 限位 | 电机停车的开/关位置设定 |
| 离合 | 电机的手动释放机构，断电时能手动拉帘 |
| 弯轨 | 按窗户弧度弯制的轨道，飘窗专用 |
| 窗帘盒 | 隐藏轨道与帘头的吊顶凹槽 |

## 7 窗帘安装检查清单

装完窗帘按清单验收，重点在「行程与受力」：

| 检查项 | 标准 |
| --- | --- |
| 轨道水平 | 水平尺校准，避免帘布自行滑动 |
| 牵引力匹配 | 电机牵引力 ≥ 帘重 1.5 倍 |
| 开合顺畅 | 手动拉动无顿挫、无偏斜 |
| 行程校准 | 全开全关停位一致，留 2–3cm 微缝 |
| 离合测试 | 断电时能手动拉帘 |
| 电源预留 | 电机侧有插座或锂电池可充电 |
| 反复测试 | 自动开合 5 次无漂移、无卡滞 |

## 8 小结

- 窗帘是**定制件**：量窗净宽 + 两端余量，轨道水平、窗顶承重，装前定电源位。
- 电机三匹配：**牵引力 ≥ 1.5 倍帘重、协议对生态、带手动离合**。
- 电机端是「死端」，决定帘布收纳方向，装反了方向就反了。
- 行程校准是灵魂步骤：**开合限位校准 + 反复试开合**，留微缝防堵转。
- 「带不动、停位漂移」先查选型与轨道阻力，再查电机。
