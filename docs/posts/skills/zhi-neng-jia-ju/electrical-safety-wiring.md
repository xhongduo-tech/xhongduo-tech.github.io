## 为什么先谈电，再谈智能

智能设备装在墙里、接在电上，而市电 **220V 交流电**可以轻易致命。这一篇是所有安装工作之前的「安全课」：不懂强电常识，不知道什么是零线火线，不知道线径怎么选，安装智能开关、插座、窗帘电机时轻则烧设备、跳闸，重则触电。**安装调试的第一条职业底线，就是安全作业。**

需要先声明边界：**本篇讲的是安装师傅需要掌握的用电常识与规范，不是怂恿任何人无证作业。** 涉及配电箱改造、大功率回路施工，必须由持证电工执行——智能家居安装人员的职责，是「接线正确、配合规范」，而不是越俎代庖。

## 1 强电基础：火线、零线、地线

中国家庭用电是 **220V / 50Hz 单相交流电**，入户三根线：

**火线（L，Live）**：带电相线，对地电压约 220V。它是电流的「来路」，开关必须串在火线上——这样关断开关才真正切断设备供电。
**零线（N，Neutral）**：回路返回线，正常时对地电压接近 0V。电流经负载后从零线流回电源。
**地线（PE，Earth）**：保护接地线，平时不带电，把设备金属外壳的漏电导向大地。**地线是保命线**，金属外壳的设备（冰箱、智能开关面板、摄像头）必须有。

**重点：开关必须断火线，不能断零线。** 这是强电接线最核心的一条。如果开关断的是零线，灯具虽然「不亮」了，但灯座仍带 220V，换灯泡时伸手碰到就是触电。<span class="marginnote">判断零火线的方法：用<strong>验电笔</strong>（试电笔）测，亮的是火线；或者用<strong>万用表</strong>量对地电压。老电工的习惯是<strong>断电操作、带电复核</strong>——接线时拉闸，接完送电前用万用表确认无短路再合闸。</span>

## 2 安全装置：断路器与漏电保护

配电箱里的每个「开关」不是普通开关，而是保护装置：

**断路器（空开）**：过载与短路保护。电流超过额定值（如 16A、20A）就跳闸，防止电线过热起火。空调、热水器这类大功率回路要单独一路、单独空开。

**漏电保护开关（漏保/RCD）**：检测火线与零线电流是否相等。正常时两者相等；一旦有人触电或设备漏电，火线电流的一部分从地线或人体流走，漏保检测到差值立即跳闸（动作电流通常 30mA，动作时间小于 0.1s）。**凡是有插座的回路，国标要求装漏保。**

**接地**：地线把设备外壳的异常电压导入大地，配合漏保形成完整保护链。老房常见的坑是「有插座没地线」——三孔插座只接了两根线，摄像头外壳一漏电就危险。<span class="marginnote">智能家居安装排查时若发现「一摸金属外壳发麻」，几乎可以锁定<strong>没接地或地线虚接</strong>。宁可停装，也不要绕过接地继续干活。</span>

## 3 布线规范：线径、走线、接头

布线决定安全上限，三条规范必须刻进习惯：

**① 线径与负载匹配**。电线越粗，允许电流越大。家用常见线径对应关系：

| 铜芯线径 | 常用回路 | 参考载流量 |
| --- | --- | --- |
| 1.5 mm² | 照明回路 | ~8–10A |
| 2.5 mm² | 普通插座回路 | ~16A |
| 4 mm² | 空调、厨房大功率 | ~25A |
| 6 mm² | 入户主线/电热水器 | ~32A |

智能开关面板、智能插座通常走照明或插座回路，按原回路线径即可；新增的大功率设备必须**单独回路**，不能往照明回路上硬挂。<span class="marginnote">判断「这路能不能加设备」：算回路总功率，<strong>功率 = 电压 × 电流</strong>（220V × 16A ≈ 3.5kW），所有设备功率加起来不超过回路容量的 80%，才谈得上安全余量。</span>

**② 走线规范**。电线穿管（PVC 阻燃管）保护，管内导线总截面积不超过管内截面的 40%（防散热不良）；一根管内不同回路、强弱电要分开——**强电与弱电（网线、信号线）平行距离不小于 30cm**，交叉时垂直 90° 穿过，避免 220V 干扰弱电信号。

**③ 接头处理**。导线连接不能简单缠绕，要用**接线端子（如 Wago 端子）**或涮锡，接头处绝缘胶带缠牢并放入接线盒，**不允许裸接头埋在墙里**。接线盒盖板必须装回，这是后期检修的唯一入口。

## 4 智能设备的接线场景

智能开关、智能插座是强电接线最多的两类设备，两个关键概念：

**单火线（单火）开关**：老房灯位只有一根火线进开关、一根控制线到灯，没有零线。单火智能开关靠「关灯时从灯具取微弱电流维持供电」，对 LED 灯具负载有要求（负载过低会闪烁或失联）。<span class="marginnote">单火开关的典型坑：<strong>LED 灯功率太小（几瓦），单火开关取不到维持电流，灯会「鬼火」闪烁</strong>。解决办法是并联电容，或优先用零火方案。</span>

**零火线（零火）开关**：开关盒里同时有火线、零线。零火智能开关供电稳定、负载兼容性好，**是现在的主推方案**。但很多老房开关盒里只有火线没有零线——这正是第 3 篇选型时反复强调「布线预留」的原因。

**接线步骤模板**（以零火智能开关为例）：拉闸断电 → 验电确认无电 → 拆旧开关 → 核对线色（火线 L、零线 N、控制线 L1）→ 接入新开关对应端子 → 螺丝锁紧、轻拉确认不脱 → 装回面板 → 送电测试。**全程遵循「断电操作、送电复核」。**<span class="marginnote">送电测试的正确姿势：先合总闸，再逐个合回路空开，<strong>合一个回路空开就试一路设备</strong>——万一接线有误，故障范围被限制在一个回路内，好定位也好抢救。</span>

## 5 核心对比表：单火与零火智能开关

纯技能主题，用对比表替代公式解析，这也是选型时客户问得最多的一组对比：

| 对比维度 | 单火智能开关 | 零火智能开关 |
| --- | --- | --- |
| 开关盒内需要的线 | 火线 + 控制线 | 火线 + 零线 + 控制线 |
| 老房适用性 | 高（老房无零线也能装） | 需开关盒有零线 |
| 供电稳定性 | 依赖负载，LED 低载易闪 | 稳定 |
| 负载兼容性 | 对灯具功率有下限要求 | 好 |
| 新增成本 | 无额外布线 | 可能需补零线（施工成本高） |

**结论**：新装或装修阶段，**一律按零火方案预留**；老房改造、确实无零线，才用单火开关，并确认灯具功率满足要求。给客户报价前先看开关盒照片，判断属于哪种，避免到现场才发现线不对。

## 6 术语速查表

电工话题有一套自己的行话，装智能设备前先对齐口径：

| 术语 | 含义 |
| --- | --- |
| 火线（L） | 带电相线，对地约 220V，开关必须串在火线上 |
| 零线（N） | 回路返回线，正常时对地接近 0V |
| 地线（PE） | 保护接地线，把设备外壳漏电导向大地 |
| 断路器 | 过载与短路保护，电流超额定值跳闸 |
| 漏电保护（漏保） | 检测火零线电流差，人体触电或漏电时跳闸 |
| 单火线 | 开关盒只有火线与控制线，无零线，老房常见 |
| 零火线 | 开关盒同时有火线与零线，供电稳定 |
| 控制线（L1） | 从开关到灯具的线，开关通过它通断灯具 |
| 接线端子 | 导线连接的规范连接件，如 Wago 端子 |
| 回路 | 一组由同一空开保护的电线系统 |

## 7 用电安全检查清单

智能设备接线完成后，按这份清单过一遍再送电：

| 检查项 | 要求 |
| --- | --- |
| 开关断火线 | 通断的必须是火线，不能断零线 |
| 接线端子 | 接头用端子连接，不允许裸绞埋墙 |
| 回路负载 | 回路总功率不超过容量 80% |
| 强弱电分离 | 强电与网线平行距离 ≥ 30cm |
| 地线 | 金属外壳设备必须有可靠接地 |
| 送电方式 | 先合总闸，再逐个合回路空开，逐路试 |
| 防水 | 室外接线做好防水胶带与线管保护 |

## 8 小结

- 三根线各司其职：**火线供电、零线回流、地线保命**；开关必须断火线。
- 保护装置两件套：**断路器防过载短路，漏保防触电漏电**；插座回路必须装漏保。
- 布线三规范：**线径配负载、强电弱电分开走、接头进盒不裸埋**。
- 智能开关两方案：**零火稳定为主推，单火救老房但挑负载**。
- 作业铁律：**断电操作、送电复核、回路逐个送**。
