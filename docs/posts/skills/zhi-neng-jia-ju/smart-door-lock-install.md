## 为什么门锁安装要以「零返工」为目标

智能门锁和智能灯泡不一样：灯泡装砸了换一个就好，门锁装砸了——门关不上、锁舌卡住、反锁后打不开——是直接把人关在门外或门内的安全事故。门锁安装的核心要求是**一次装对**，而这要求装锁前把锁体类型、门的结构、导向片规格全部核对清楚。本篇从选型讲到调试与排障，把「装锁」做成一条不出错的流水线。

## 1 门锁的三种类型

**执手式（把手式）智能锁**：外观与传统机械锁最接近，带下压把手，开锁后下压开门，动作自然。优点：符合全家（尤其老人）的操作习惯，价格亲民。缺点：全自动程度低，部分型号关门后需手动上提反锁。

**推拉式智能锁**：无把手，开锁后直接推/拉门扇。外观现代、科技感强，是近年主流。注意区分**真推拉**（开锁后推门）与**假推拉**（仍需按压执手），选型时别被外观误导。

**全自动智能锁**：开锁后锁舌自动收回，关门自动上锁，无需任何手动动作。体验最顺滑，但结构更复杂、功耗更高、价格更贵，对门缝精度要求更高。<span class="marginnote">全自动锁最怕「门缝过大或门下垂」：<strong>门缝变了，自动锁舌对准不了导向片，就会反复报「锁舌卡阻」</strong>。装全自动锁前，先检查门扇是否下垂、门缝是否均匀。</span>

**重点：类型决定「开锁动作」与「对门况的要求」**——执手式容错最高，全自动要求门况最好。老房旧门，优先执手式；新装标准门，可选全自动。

## 2 开锁方式与通信

智能门锁的开锁方式决定了日常体验与安全性：

**指纹识别**：主流是**半导体指纹**（电容式），活体识别、防假指纹；老式光学指纹模块对干手指、脏手指识别率差，已逐渐淘汰。安装调试时务必**录入多个手指**并测试干手、湿手场景。

**密码/临时密码**：虚位密码（前后可加任意数字防偷窥）；临时密码用于访客，可设有效时长，是出租房与保姆场景的刚需。

**NFC/刷卡**：门禁卡、手机 NFC 模拟，适合老人小孩（指纹浅、记不住密码）。

**蓝牙/远程**：手机蓝牙靠近开锁；Wi-Fi/Zigbee 联网后 App 远程下发临时密码、查看开关记录。**联网方式决定是否需要网关**：Wi-Fi 直连最省事，Zigbee 版需要 Zigbee 网关（米家生态常见）。<span class="marginnote">安全提醒：<strong>远程开锁功能要慎重——它把「家门钥匙」暴露在网络上</strong>。给客户配置时，默认关闭「远程一键开锁」，只开「远程发临时密码」；并开启开锁通知与异常报警。</span>

## 3 安装：锁体、导向片与天地钩

安装前先核对三个硬件要素，这是「装不装得上」的关键：

**① 锁体（Lock Body）**：智能锁锁体分**标准锁体**（6068 锁体、欧标锁体等）与**电子锁体**。选购时根据门原有开孔尺寸匹配，多数智能锁兼容常见锁体，但**通配型锁体**对异形门更友好。锁体装歪会导致锁舌与导向片错位。

**② 导向片（Strike Plate）**：门框上的金属片，锁舌伸入的地方。它的**长、宽、边距**决定智能锁能否装上。老房门的导向片千奇百怪，厂商会附带**通用导向片**或提供定制——安装前必须量好尺寸与照片发给厂家确认。<span class="marginnote">导向片是门锁安装「返工重灾区」：<strong>厂家默认导向片与原门不匹配，装不上</strong>。正确流程是下单前把导向片尺寸（长/宽/固定螺丝孔距）拍照报给客服，而不是到货后才发现。</span>

**③ 天地钩（Anti-theft Hooks）**：老式防盗门侧面连出的上下锁钩。智能锁支持与否差别很大：**带天地钩的门装智能锁，要么选支持天地钩的锁，要么拆掉天地钩**——很多智能锁的电机拉不动天地钩，强行连接会卡死。安装前先确认门的天地钩情况，并跟客户讲清拆装利弊。

## 4 安装调试流程

把安装做成固定七步，每步都有验收标准：

**第 1 步：验货核对**。开箱核对锁体、导向片、面板、把手是否与订单一致，确认门的开向（左开/右开）与面板方向。

**第 2 步：拆旧锁**。拆下旧锁体与面板，清理门体开孔，检查孔位是否偏斜。

**第 3 步：装锁体**。锁体放入门槽，用螺丝固定；转动锁芯传动件，确认锁舌伸缩顺畅、无异响。

**第 4 步：装导向片**。将导向片固定在门框，锁舌试插，**间隙以 2–3mm 为宜**——太紧关门费劲，太松门会晃动。

**第 5 步：装内外面板**。连接方轴与连接线，穿线孔要预留足够线长（防止开关门时拉断排线），固定面板，调整把手方向。

**第 6 步：上电与初始设置**。装电池（注意正负极）、激活锁具，按 App 引导添加设备、录入管理员指纹与密码。<span class="marginnote">电池安装的一个细节：<strong>装电池前确认锁体已正确复位，且面板排线已接好</strong>——否则一通电锁体就自检报错，容易误判为「锁坏了」。</span>

**第 7 步：整锁联调**。反复测试：门外指纹开锁、密码开锁、门内快开、反锁、低电量报警；再测试**关门自动上锁/自动反锁**，确认锁舌在门缝正常时能顺畅进出。

## 5 核心对比表：三类锁怎么选

纯技能主题，用对比表替代公式解析：

| 对比维度 | 执手式 | 推拉式 | 全自动 |
| --- | --- | --- | --- |
| 开锁后动作 | 下压把手 | 推/拉门扇 | 锁舌自动收回 |
| 操作习惯 | 最接近传统锁 | 现代直观 | 最省事 |
| 对门况要求 | 低 | 中 | 高 |
| 老人小孩友好度 | 高 | 中 | 高 |
| 功耗 | 低 | 中 | 较高（需大容量电池） |
| 价格区间 | 入门 | 主流 | 高端 |

**结论**：老人家庭、老房旧门选**执手式**；追求现代感、标准门选**推拉式**；新装高配、门况良好选**全自动**。无论哪种，联网优先选支持本地网关的型号，把「门锁状态」接进全屋场景（开门亮灯、离家布防）。

## 6 常见故障排查

| 故障现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 指纹识别不了 | 手指干/脏、指纹浅 | 重录指纹、换手指、清洁传感器 |
| 关门后不上锁 | 门缝过大、锁舌未对准 | 调导向片位置或门吸 |
| 锁舌卡阻报警 | 门下垂、锁体装歪 | 校正锁体、微调导向片 |
| 无法远程控制 | 网络离线、网关掉线 | 查 Wi-Fi/网关，重启锁具 |
| 电池很快没电 | 全自动锁频繁动作、低温 | 换大容量电池、查是否有频繁自检 |

## 7 术语速查表

门锁安装的硬件词汇，装锁前先对号：

| 术语 | 含义 |
| --- | --- |
| 锁体 | 门内的机械部分，决定锁舌伸缩与锁的类型 |
| 导向片 | 门框上的金属片，锁舌伸入的位置，规格影响安装 |
| 天地钩 | 老式防盗门上下连出的锁钩，与智能锁兼容性需确认 |
| 执手式 | 带下压把手的智能锁，开锁后下压开门 |
| 推拉式 | 无把手智能锁，开锁后推/拉门扇 |
| 全自动 | 开锁后锁舌自动收回、关门自动上锁 |
| 虚位密码 | 真实密码前后可加任意数字，防偷窥 |
| 半导体指纹 | 电容式活体指纹识别，优于老式光学指纹 |
| 方轴 | 连接内外把手的传动轴，驱动锁舌 |
| 防猫眼 | 室内把手防猫眼开启功能，防技术开锁 |

## 8 门锁安装验收单

装完锁按这份清单逐项验收，避免「人走了才出问题」：

| 验收项 | 标准 |
| --- | --- |
| 锁舌顺畅 | 转动传动件无卡阻、无异响 |
| 门缝间隙 | 锁舌与导向片间隙 2–3mm |
| 排线余量 | 内外面板连接线留足长度，开关门不拉拽 |
| 指纹录入 | 至少 3 个手指，干手湿手各测一次 |
| 反锁测试 | 内外反锁、自动上锁各测 5 次 |
| 低电量报警 | 触发一次低电量提醒，确认能感知 |
| 备用钥匙 | 机械钥匙移交客户并叮嘱保管 |

## 9 小结

- 三类锁：**执手式**容错高、**推拉式**主流、**全自动**体验最好但挑门况。
- 开锁方式按人群配置：**指纹为主、密码访客、NFC 给老人小孩**；远程开锁默认关闭。
- 安装三要素：**锁体、导向片、天地钩**，下单前先量导向片尺寸。
- 七步安装法，每步有验收标准；**门缝 2–3mm** 是锁舌顺畅的关键。
- 常见故障多为**门况与锁体错位**，不是锁本身坏，先校门再换锁。
