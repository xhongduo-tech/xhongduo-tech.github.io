## 为什么从酱油开始

如果说酿造调味品是中餐味觉的基石，酱油就是基石的中央。它同时贡献咸、鲜、香、色四重功能，一道菜里哪怕只放酱油一味，也能撑起大半的味觉骨架。<span class="marginnote">从第一级《基础数学》的集合，走到生活技能树的这口酱缸，这条博客路线一直在做同一件事：把最熟悉的东西拆出最精确的结构。酱油正是「最熟悉的陌生工艺」。</span>《酱油酿造工艺》是调味品酿造最完整的一本教材，学好酱油，等于拿到了酱类、食醋之外的整把钥匙。这一章先把酱油的身世与分类讲清。

## 1 酱油的定义与身世

**酱油（soy sauce）**：以大豆（或脱脂大豆）、小麦（或面粉）为主要原料，经微生物发酵制成的、具有特殊色香味的咸鲜调味液。

酱油的身世有一条清晰的演化链：先秦的肉酱「醢」→ 汉代的豆酱 → 酱汁被单独沥出成为「清酱」→ 宋代市井出现「酱油」之名，到明清成为厨房必备。<span class="marginnote">「酱油」是「酱之油」：古代酱缸上层澄出的清液，被单独收集——酱与酱油本是同源产物，分开只是「取汁」与「留体」的差别，这条线在《豆酱酿造工艺》还会再续。</span>

酱油传入日本后演变为「醤油（shoyu）」，成为东亚共同的风味密码。而欧洲的「soy sauce」之名，正源于日语读音的转写——一物一名，串起整个东亚。

## 2 酱油的呈味密码

理解酱油，先理解它的四重功能是怎么来的：

**咸。** 来自食盐，是酱油的骨架；没有盐，一切鲜香都悬空。

**鲜。** 来自蛋白质水解出的**氨基酸**（谷氨酸、天门冬氨酸）与**核苷酸**（呈味核苷酸与氨基酸的鲜味有协同增效）。这是酱油最核心的味觉贡献。<span class="marginnote">谷氨酸的鲜与肌苷酸、鸟苷酸的鲜相乘（味觉协同），而非简单相加——这一原理在《食品化学》鲜味一章有精确定量，也是「生抽 + 蚝油 + 味精」复合提鲜的化学依据。</span>

**香。** 来自焙炒小麦的焦香前体、酵母与乳酸菌代谢的醇酯、发酵褐变生成的吡嗪与呋喃酮。香气是酱油的「层次」。

**色。** 来自美拉德反应的类黑精与焦糖色，红褐油亮是优质酱油的观感标志。

## 3 酱油的产品分类

酱油按工艺与形态有多个分类维度，初学者先抓住两条主线：

**按酿造工艺分（最重要）：**

| 类别 | 工艺要点 | 特点 |
| --- | --- | --- |
| 高盐稀态酿造酱油 | 盐水 18–20%，低温长时发酵 3–6 月 | 醇厚、酱香浓、氨基酸态氮高 |
| 低盐固态酿造酱油 | 盐水 12–14%，固态短时发酵 15–30 天 | 鲜咸直接、周期短、成本低 |
| 配制酱油 | 酿造酱油 + 酸水解植物蛋白液勾兑 | 成本低，须明示「配制」 |

**按食用功能分：** 生抽（色浅味鲜，用于提鲜）、老抽（色深味浓，用于上色）、佐餐酱油（直接蘸食，卫生要求更高）、烹调酱油（加热使用）。<span class="marginnote">「生抽」与「老抽」本是粤语俗称：生抽「抽」取自酱醅「抽」出的头道汁，老抽则是在生抽基础上再加焦糖色与酱汁复晒——一个为鲜、一个为色。</span>

## 4 酱油的主要成分

把一瓶酱油倒进量杯，它的大致构成是：

| 成分 | 大致含量 | 作用 |
| --- | --- | --- |
| 水 | 60–70% | 溶剂与载体 |
| 氯化钠 | 15–20% | 咸味、防腐 |
| 氨基酸态氮 | 0.4–1.2 g/100mL | 鲜味与品质分级 |
| 总糖（还原糖） | 2–5% | 回甘、色泽前体 |
| 有机酸 | 1–3% | 酸香、口感 |
| 乙醇 | 微量–2% | 酯香前体 |

**氨基酸态氮（amino nitrogen）**是酱油分级的最核心指标：每 100 mL 中 ≥ 0.80 g 为特级，≥ 0.70 g 一级，≥ 0.55 g 二级，≥ 0.40 g 三级。这一数字直接反映蛋白质被酶解成氨基酸的程度——也就是鲜味的储量。

**一个量化的例子：从指标看懂一瓶酱油。** 拿起货架上一瓶酱油，看两行字就能判断大半：**执行标准号**（GB/T 18186 是酿造酱油）与**氨基酸态氮**（0.4 起分三级、0.8 以上特级）。再配一个「全氮」指标——酿造酱油的氨基酸态氮约占全氮的一半以上，比例失衡说明可能掺了水解液。指标不是数字游戏，是工艺诚实的记录。

**酱油的保存与使用要点。**

| 要点 | 做法 | 原因 |
| --- | --- | --- |
| 避光保存 | 阴凉处、用后盖紧 | 光照加速褐变、香气挥发 |
| 尽量冷藏 | 开封后冷藏更稳 | 低温抑制微生物继续发酵 |
| 先尝后放 | 咸鲜作基准、少量多次 | 酱油含盐高，过量则味死 |
| 区分用途 | 生抽提鲜、老抽上色 | 两类产品配比不同 |

**辨析｜易错点：** 「酱油越鲜越好」要辨证。氨基酸态氮高代表鲜味足，但酱油是「咸鲜平衡」的整体——只有鲜没有咸撑不住，只有咸没有鲜则发死。等级只说明鲜味储量，好不好吃还要看香气与咸淡是否协调。

**术语速查**

| 术语 | 含义 |
| --- | --- |
| 氨基酸态氮 | 游离氨基酸折算含氮量，酱油分级的核心指标 |
| 全氮 | 酱油中所有含氮物质的总量，可识破水解液掺假 |
| 高盐稀态 | 盐水 18–20%、低温长时的慢酿工艺 |
| 低盐固态 | 盐水 12–14%、高温短时的快酿工艺 |
| 焦糖色 | 老抽上色的天然着色剂，与生抽的核心分野 |

## 5 酱油与「从极限到大模型」的对照

这一章给全篇立个框架，值得用一句话总结：**酱油是「时间的函数」**。把品质指标看成发酵时间与温度的因变量，控制变量（盐度、温度、酶活）就决定了函数曲线——高盐稀态正是把时间轴拉长、把速率压慢，让风味积分面积最大。这套「控制变量、调控速率、以时间换品质」的思路，与《发酵基本原理与工艺调控》一脉相承，也是理解后续每一道酱油工序的总纲。<span class="marginnote">把「品质 = f(盐度, 温度, 时间, 酶活)」这种函数视角带进工艺学习，后面每看一道工序都在问同一句：它动了哪个自变量、改变了哪条曲线？</span>

**一句补充。** 酱油与食醋、豆酱的关系，是「同源分家」：都从「大豆 + 米曲霉」或「糖化—酒化—醋化」的发酵原理出发，只因目标味与取汁方式不同而各成一派。带着这套框架走进后面各章，会处处遇到「老朋友」。

**酱油术语速查**

| 术语 | 含义 |
| --- | --- |
| 氨基酸态氮 | 游离氨基酸折算含氮量，鲜味与分级核心 |
| 生抽 | 色浅味鲜，用于提鲜 |
| 老抽 | 色深味浓，加焦糖色复配，用于上色 |
| 高盐稀态 | 盐水 18–20%、低温长时慢酿 |
| 低盐固态 | 盐水 12–14%、高温短时快酿 |

**酱油的四大名产区与风味。** 中国酱油素有地域流派：广东的晒制酱油鲜甜突出、以生抽见长；上海的本帮酱油色泽浓、酱香厚；北方酱油偏咸鲜直率；湖南、四川则喜复配辣与香料。同一套「大豆 + 小麦 + 米曲霉」，只因盐水浓度、发酵温度与晒酱时长的不同，就长出了各地风格——风土与工艺，共同写就了酱油的地域性格。

**一张图看全章。** 酱油这一章立了三条线：**身世线**（醢 → 豆酱 → 清酱 → 酱油）、**分类线**（工艺：高盐稀态/低盐固态/配制；功能：生抽/老抽）、**指标线**（氨基酸态氮分级、全氮验真）。三条线交汇处，就是「看懂一瓶酱油」的能力。

## 6 小结

- **酱油**以大豆小麦为原料、经微生物发酵制成，集**咸、鲜、香、色**于一身。
- 鲜味来自氨基酸与核苷酸，二者有**味觉协同增效**。
- 分类两大主线：**高盐稀态 vs 低盐固态**（工艺）、**生抽 vs 老抽**（功能）。
- **氨基酸态氮**是品质分级的硬指标：特级 ≥ 0.80 g/100 mL。
- 把酱油看成**时间的函数**，全篇工艺都可归结为对温度、盐度、酶活等自变量的调控。
