# 中国传统调味品酿造工艺

中国传统调味品酿造工艺是以酱油、食醋、酱类、腐乳为代表的传统发酵调味品酿造技术体系，涵盖制曲、发酵、浸出、陈酿等核心工序，是酿造工、酱油酱类制作工等职业技能鉴定的实操型职业通道。以《调味品酿造工艺》《酱油酿造工艺》《醋与酱类酿造技术》三本教材为纲，从酿造微生物与原料基础，到酱油、食醋、酱类、腐乳的完整酿造流程，系统写完整门工艺。

## 对标教材

- 《调味品酿造工艺》
- 《酱油酿造工艺》
- 《醋与酱类酿造技术》
