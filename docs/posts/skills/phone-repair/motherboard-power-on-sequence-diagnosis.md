## 为什么从开机时序讲起

「手机不开机」是维修中最高频也最棘手的问题。棘手之处在于：**不开机的原因横跨软件与硬件、贯穿整块主板**——可能是电池没电、开机键损坏、电源 IC 故障、SoC 虚焊、或系统崩溃。高级维修员与新手的分水岭，就在于是否掌握「开机时序」这一分析框架。

**开机时序（power-on sequence）**：手机从按下电源键到系统启动，必须按**严格顺序**完成一系列上电与使能动作。<span class="marginnote">开机时序是主板设计的「仪式流程」：电池电压 → 电源键触发 → PMIC 各路电压依次输出 → 时钟电路启动 → SoC 复位 → 引导加载 → 系统启动。每一步都是下一步的前提——诊断「不开机」，就是沿着这个时序检查「卡在哪一步」。</span>

这一篇建立主板供电电路与开机时序的诊断方法。

## 1 主板供电网络：从电池到各路电压

主板供电的核心是 **PMIC（电源管理 IC）**，它把电池电压转换成系统需要的各路电压。手机主板上常见的电压轨：

| 电压轨 | 用途 |
| --- | --- |
| 0.8~1.0 V（核心电压） | SoC 内核供电 |
| 1.2~1.8 V | 内存、IO、时钟 |
| 3.0~3.3 V | 外设、传感器、SD 卡 |
| 背光升压 | 屏幕背光（LCD） |

每路电压由 PMIC 的对应输出 + 外围电感、电容滤波构成，电感负责储能、电容负责平滑。<span class="marginnote">主板上的电感（大块黑色方块元件）与电容（小颗粒）是 PMIC 输出的「滤波组」：电感储能、电容稳压。某路电压异常时，常先检查该路对应电感是否虚焊、电容是否短路。</span>

**重点**：**每一路电压都是独立的「电路子域」**——测某路电压缺失，就顺着该路输出（电感、电容、负载）追查，而不必「全板找短路」。

### 电压轨测量的三个判断层次

面对「某路电压异常」，测量不能停在「有没有电压」这一层，要分三个层次判断：

| 测量层次 | 方法 | 判断 |
| --- | --- | --- |
| 有没有电压 | 测该路输出端 | 无电压 → 供电链路断 |
| 电压对不对 | 对照设计值 | 偏低 → 负载过重或短路 |
| 纹波稳不稳 | 示波器看波形 | 波动大 → 滤波电容失效 |

**辨析｜易错点**：**「电压偏低」与「电压没有」是两个不同诊断方向**——「没有」指向供电链路（PMIC 没输出、电感开路），「偏低」指向负载侧（某元件短路拉低电压）。只看「有没有」容易漏掉「偏低但存在」的短路故障。所以电压轨的测量要从「有无」深化到「数值对照」——**把读到的电压与设计值对比，偏差本身就是线索**，这正是「用电压反推电路健康度」的具体落地。

## 2 开机时序：电源键按下之后

一次完整的开机，由一系列「按序事件」构成。以典型设计为例：

1. **触发**：按下电源键，开机键线路产生触发信号（拉低 PMIC 的开机引脚）。
2. **PMIC 启动**：PMIC 检测到触发，开始逐路输出系统电压。
3. **时钟与复位**：主时钟（晶振）起振；SoC 复位信号释放，SoC 开始执行引导程序。
4. **引导**：SoC 从存储读取引导加载程序，初始化内存与系统。
5. **系统启动**：操作系统加载，屏幕亮起，进入桌面。

**辨析｜易错点**：**「不开机」要先分「完全无反应」与「有反应不亮屏」**。完全无反应（按电源键电流无变化）→ 供电/开机触发链路问题；有电流反应但不亮屏 → 引导/显示链路问题。两种「不开机」的诊断方向完全不同。

## 3 用电流判断开机进度

主板维修中最强大的工具不是万用表，而是**稳压电源的电流表**——通过观察开机电流曲线，可以「看」到开机进行到哪一步：

| 电流表现 | 判断 |
| --- | --- |
| 按下无电流 | 开机触发链路断（开机键、排线） |
| 电流小且不动 | 供电未完全建立（PMIC 未启动） |
| 电流跳动（如 0~100~200mA） | 正在启动，时钟/引导工作 |
| 电流到一定值回落 | 引导失败（软件或存储问题） |
| 电流异常大（短路） | 供电短路（某路电压对地短路） |

**重点**：**电流曲线是「不开机」诊断的望远镜**。维修高级工「看电流判断故障」，本质是把不可见的主板状态，用电流的变化轨迹可视化——这正是「测量让故障现形」思想的极致体现。

## 4 公式解析：用欧姆定律定位短路

「不开机 + 电流异常大」往往意味着供电短路。定位短路的方法，用欧姆定律的变形：

$$
R = \frac{U}{I}
$$

- 某路电压正常输出时，若负载短路，电流会异常增大，电压被拉低。
- 反推：测该路对地阻值，阻值接近 0 Ω 即短路；阻值明显偏小，存在漏电。

**实操步骤**：

1. 用稳压电源给主板供电（限流保护，如限 200mA）。
2. 观察电流：异常大 → 有短路。
3. 用「烧机法」（低电压、限流）让故障元件发热。
4. 用热成像或手指感知发热点，定位短路元件。

**辨析｜易错点**：**「烧机法」必须在限流、低压下进行**。直接给短路主板加正常电压，可能烧毁线路与更多元件。正确做法是「低电压（如 3V 以内）+ 限流（如 200mA）」逐步排查——用最小的能量找到故障点。

## 5 开机时序诊断的流程

把以上知识收束成「不开机」的诊断流程：

1. **外因排除**：确认电池有电、充电能充、开机键完好。
2. **电流初判**：接稳压电源观察按下开机键的电流反应，判断「哪一步没走」。
3. **供电检查**：测 PMIC 各路关键电压，定位「哪路电压缺失」。
4. **时钟复位检查**：查晶振起振、复位信号，判断 SoC 是否「醒」过来。
5. **引导与存储**：查引导加载、存储通信，判断是软件层还是存储硬件故障。

**重点**：**开机时序诊断的价值在于「把大问题拆成小环节」**——每一次测量都在回答「时序走到哪一步、这一步的条件是否满足」。这正是「从极限到大模型」主线的分治思维在主板维修中的完整体现。诊断「不开机」永远不是一次测量解决，而是沿着时序「一环一环」地推进——每排除一步，离故障点就近一步。

## 6 小结

- **供电网络**：PMIC 输出各路电压，电感电容滤波；每路电压是独立子域。
- **开机时序**：触发 → PMIC 上电 → 时钟复位 → 引导 → 系统启动，环环相扣。
- **电流判读**：稳压电源电流曲线「看」开机进度；短路表现为电流异常大。
- **环环相扣**：时序每一步是下一步前提，逐环推进直到定位故障点。
- **短路定位**：$R = U/I$
