# 棒球与垒球

以 WBSC《棒球/垒球竞赛规则》、《棒垒球运动教程》与中国棒球协会培训体系为纲，系统建立从竞赛规则、投打跑垒技术、攻守战术到教练员培训与球队管理的完整棒垒球能力链，学完即可覆盖从看懂比赛到执教一支球队应具备的核心理论与实践技能。

## 对标教材

- WBSC《棒球/垒球竞赛规则》
- 《棒垒球运动教程》
- 中国棒球协会培训体系
