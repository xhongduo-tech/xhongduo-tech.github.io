## 为什么从 IPC 关键指标开始

前几篇分别讲了参数、镜头、形态、场景能力，现在要把它们合成**一张采购清单**。网络摄像机（IPC）是家用监控的主角，但商家参数表动辄几十行，多数人只会看「像素」。这一篇把 IPC 的关键指标压缩成**选型时必看的几项**，并给出品牌选择的判断框架，让你拿到任何一台 IPC 都能在两分钟内判断「值不值得买、适不适合我家」。<span class="marginnote">这一篇是第1篇的「收银台」：前面所有概念在此汇集成一份可执行的选型清单，后续施工、布线、NVR 配置都以这份清单为依据。</span>

## 1 IPC 关键指标：一张表看懂

IPC 的指标可以归为四组：**成像、编码、网络、环境**。家用选型时逐组核对，抓大放小：

| 指标组 | 核心指标 | 家用判断要点 |
| --- | --- | --- |
| 成像 | 有效像素、传感器尺寸、最低照度、宽动态 | 像素 ≥ 200 万；传感器越大越好；门口逆光位看 WDR |
| 编码 | 编码标准、主码流/子码流 | 必须支持 H.265；子码流用于远程流畅预览 |
| 网络 | 网口、PoE、Wi-Fi、ONVIF 协议 | 有线优先选 PoE；跨品牌兼容看 ONVIF |
| 环境 | 防护等级、夜视距离、工作温度 | 室外 IP66+；夜视距离留 1.5 倍余量 |

**核心概念**：**主码流（main stream）与子码流（sub stream）** 是 IPC 最重要的设计之一——摄像机同时输出两路码流：主码流画质高、供本地存储与回放；子码流画质低、码率小，供手机远程实时预览。<span class="marginnote">子码流是「远程看流畅」的关键：手机通过 4G 看 4K 主码流必卡，看子码流（如 704×576）则流畅得多。这是「NVR 配置」与「远程监控」两篇反复出现的概念。</span>

**辨析｜易错点：** 「支持 800 万像素」不等于「你的 NVR 能接收」。**NVR 的通道能力**（如 8 路 200 万）限制了它能同时接入的码流规格。买 4K 摄像机却配了只支持 200 万通道的 NVR，画面会被强制降级——选 IPC 和 NVR 必须**成对核对**，不能只看单端。

## 2 协议兼容性：ONVIF 与生态绑定

**ONVIF（Open Network Video Interface Forum，开放网络视频接口论坛）** 是一个让不同品牌的 IPC 与 NVR/软件互相通信的**标准协议**。

为什么它重要：家用系统常有「摄像机是 A 牌、录像机是 B 牌」的混搭需求。支持 ONVIF 的设备可以跨品牌接入——A 牌 IPC 能被 B 牌 NVR 或通用监控软件（如 iVMS、各类开源 NVR）发现和取流。<span class="marginnote">ONVIF 相当于监控界的「USB 标准」：有了它，你的设备不被单一厂商锁死。选购时认准参数表里的「支持 ONVIF 协议」字样。</span>

与 ONVIF 相对的是**厂商私有协议**：海康威视的私有协议、大华的私有协议等。同品牌内功能最全、联动最顺，但**跨品牌时私有功能会失效**。

**辨析｜易错点：** 支持 ONVIF ≠ 所有功能都能跨品牌用。ONVIF 只保证基础的发现、取流、云台控制；**移动侦测回传、智能分析（人脸/车辆）、报警联动等高级功能**往往只有同品牌私有协议下才完整。混搭前要有「基础可用、高级功能可能缺失」的心理准备。

## 3 品牌选型框架：从预算与生态出发

家用 IPC 品牌选择，不必迷信「最贵」，而要匹配自己的**安装能力与生态需求**：

**一线品牌（海康威视、大华、宇视等）**：产品线全、固件稳定、App 生态成熟、售后与文档齐全，是「不想折腾」的首选。缺点是同规格价格偏高，且较依赖自家生态。<span class="marginnote">一线品牌的「生态闭环」意味着：手机 App、NVR、IPC 同品牌时体验最顺；混搭时仍可靠 ONVIF 兜底，但高级联动会打折扣。</span>

**二线品牌与互联网品牌（小米、TP-LINK、360 等）**：性价比高、App 易用、与智能家居生态（语音助手、传感器）联动好，适合「家用简单场景」。部分型号支持 ONVIF，可接入通用 NVR。

**无品牌白牌/杂牌**：价格极低但**固件安全性、隐私保护、售后**风险大，监控设备直接暴露在公网，**强烈不建议**用于家庭。

**核心选型框架**——三个问题：

1. **要不要与智能家居联动？** 要 → 优先互联网生态品牌；不要 → 一线品牌稳定优先。
2. **系统是否混搭？** 是 → 核对 ONVIF；全同品牌 → 生态体验最佳。
3. **预算多少？** 按「设备单价 × 通道数 + NVR + 硬盘」算总账，别只看摄像机单价。<span class="marginnote">很多人忽略总账：4 台 200 万 IPC + NVR + 2TB 硬盘的完整系统预算，往往接近单台摄像机标价的 10 倍——先算总账再决定砍哪项。</span>

## 4 核心对比表：三类品牌定位（纯概念主题）

本主题是纯概念性内容，用核心对比表代替公式解析：

| 维度 | 一线安防品牌 | 互联网/性价比品牌 | 白牌 |
| --- | --- | --- | --- |
| 代表 | 海康威视、大华、宇视 | 小米、TP-LINK、360 | 无明确品牌 |
| 稳定性与固件 | 高 | 中高 | 低 |
| App 与生态 | 自家生态、功能全 | 智能家居联动好 | 参差不齐 |
| 隐私与安全 | 强 | 中 | 风险大 |
| 家用推荐度 | ★★★★★ | ★★★★ | ★ |

## 5 完整选型清单：一张采购单

把第1篇所有选型知识收拢成一张可执行的采购单：

| 检查项 | 判定标准 |
| --- | --- |
| 分辨率 | ≥ 200 万（1080P），门口要车牌选 4K |
| 编码 | 必须支持 H.265 |
| 镜头焦距 | 按「场景→焦距」表对照 |
| 形态 | 室外枪机、室内半球、大范围球机 |
| 夜视距离 | ≥ 监控距离 1.5 倍 |
| 防护等级 | 室外 IP66+ |
| PoE | 支持 PoE（配 PoE 交换机/一体 NVR） |
| ONVIF | 支持（混搭时兜底） |
| 品牌 | 按「联动/混搭/预算」三问定 |

**核心概念**：这张表的逻辑是「**从需求反推参数**」——先想清楚每个点位要看什么（白天/夜间/车牌/人脸），再对照表逐项打勾。全部打勾的机型才进入比价环节。

**辨析｜易错点：** 采购单漏掉「NVR 通道与像素」核对是最常见的返工源头——4K 摄像机配了只支持 200 万通道的 NVR，画面被降级。**采购单要把 NVR 与 IPC 成对核对**，不能只看摄像机端。

## 6 本节自测：检验选型

**问题一：主码流和子码流分别用于什么？**
主码流画质高、供本地存储与回放；子码流画质低、码率小，供手机远程实时预览。两者独立设置、互不拖累。

**问题二：ONVIF 协议解决什么问题？**
让不同品牌的 IPC 与 NVR/软件互相通信——A 牌 IPC 可被 B 牌 NVR 发现与取流。但高级功能（智能分析、报警联动）常需同品牌私有协议。

**问题三：品牌选型三问是什么？**
联动需求（要智能家居联动？）→ 混搭与否（跨品牌看 ONVIF？）→ 总账多少（设备+NVR+硬盘算总价？）。

**问题四：为什么白牌监控设备不建议家用？**
固件安全性、隐私保护、售后风险大，且监控设备直接暴露在公网，弱固件极易被扫描利用。

**问题五：为什么「支持 800 万像素」不等于「你的 NVR 能接收」？**
NVR 的通道能力（如 8 路 200 万）限制接入码流规格。买 4K 摄像机配低规格 NVR，画面会被强制降级。

### 本节实践建议

拿一张纸写下你的点位清单，逐点对照「分辨率、编码、焦距、形态、夜视、防水」六项打勾，全部满足才进入比价——这张表就是你的采购单。

## 7 小结

- IPC 关键指标分**成像、编码、网络、环境**四组；必看：H.265、PoE、ONVIF、防护等级与夜视距离。
- **主码流供存储回放、子码流供远程预览**，是 IPC 最实用的设计。
- **IPC 与 NVR 要成对核对通道能力**，避免 4K 摄像机被低规格 NVR 降级。
- **ONVIF 是跨品牌互通的底座**，但高级联动（智能分析、报警）常需同品牌私有协议。
- 品牌选型三问：**联动需求？混搭与否？总账多少？** ——用三个问题收敛到具体品牌。
