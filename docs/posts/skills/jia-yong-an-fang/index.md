# 家用安防监控系统安装与调试

家用安防监控是居家安全防护的基础设施，涵盖摄像头选型、安装布线、NVR 配置到远程监控与录像回放的全流程。以《安防监控系统安装与调试》《视频监控系统技术》与海康威视、大华官方文档为纲，系统覆盖从监控系统认知、设备选型、施工布线到设备调试与日常运维的完整知识体系。学完这些章节，就能独立完成一套家用监控系统的选型、安装、调试与运维。
