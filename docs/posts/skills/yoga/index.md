# 瑜伽运动

以《中国健身瑜伽段位制》与《健身瑜伽体位标准》为纲，结合艾扬格《瑜伽之光》与《帕坦伽利瑜伽经》，系统重建从瑜伽源流、呼吸法、体位法、段位体式到冥想放松与体式教学的完整瑜伽运动体系，并对照中国官方段位考评标准。

## 对标教材

- 《中国健身瑜伽段位制》（国家体育总局社体中心）
- 《健身瑜伽体位标准》（国家体育总局社体中心）
- 艾扬格《瑜伽之光》（Light on Yoga）
- 《帕坦伽利瑜伽经》（Patanjali Yoga Sutras）
