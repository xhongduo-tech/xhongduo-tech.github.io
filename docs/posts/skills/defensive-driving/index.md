# 防御性驾驶与道路安全驾驶

防御性驾驶是以预见风险、提前决策为核心的主动安全驾驶理念，已被交通运输部纳入营运驾驶员强制培训内容，掌握它既能守护自身与他人的生命安全，也是系统化提升道路安全素养的必修课。
