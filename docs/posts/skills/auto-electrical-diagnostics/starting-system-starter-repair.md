## 为什么从起动系统继续

如果说发电机是汽车的「发电厂」，那么起动机就是全车**消耗电流最猛、机械冲击最大**的执行部件。发动机不能自己从静止转起来，必须靠起动机先撬动它：这短短一两秒内，电流可达 150–300A，相当于同时点亮几十只大灯。<span class="marginnote">正因为起动电流如此之大，起动回路必须用粗导线（蓄电池正极到起动机的电缆），且每处连接都必须压紧、无氧化。起动故障里有相当一部分根本不是起动机坏了，而是这条大电流回路上某一处接触电阻过大——这也解释了为什么第一课讲的「电压降诊断法」在起动系统上格外好用。</span>从职业技能的角度看，起动系统连接蓄电池（第2课）、电压测量（第1课）与电机原理（第3课的电磁感应逆用），是前三课知识的第一次综合运用。

## 1 起动系统的组成与工作过程

起动系统由**蓄电池、点火开关（或起动按钮）、起动继电器、起动机**四大部分组成，工作过程是一条接力链：

点火钥匙拧到 START 位 → 控制电流经起动继电器线圈 → 继电器触点闭合 → 大电流进入起动机电磁开关线圈 → 电磁开关吸合，一方面推出小齿轮与飞轮齿圈啮合，另一方面接通主电路 → 直流电机高速旋转 → 带动曲轴起动。

**重点：起动机的「啮合」与「通电」是同一个电磁开关完成的，且必须「先啮合、后通电」。** 若通电瞬间小齿轮还没完全啮合，齿轮会高速空转打齿，发出尖锐的「嘎嘎」声。电磁开关在结构上保证了这点——衔铁先推齿轮，行程末端才闭合主触点，这正是它被称为「电磁开关」而非简单继电器的原因。<span class="marginnote">单向离合器是起动机的保险：发动机起动后曲轴转速会反超起动机，离合器立即打滑，防止起动机被拖到超速损坏。听到起动后电机「嗡嗡」空转的短促声音，其实是单向离合器在正常打滑。</span>

## 2 起动机的结构与串励特性

起动机本质上是一台**直流串励电动机**——励磁绕组与电枢绕组串联。串励结构带来两个关键特性：

**起动转矩大**：串励电机的转矩近似与电流的平方成正比，起动瞬间电流最大，转矩也最大，正好满足「从静止撬动发动机」的需求；
**空载转速高、负载转速骤降**：带载后转速急剧下降，转矩急剧上升，这种「软特性」天然适合起动这种短时大负荷工况。

结构上，起动机由**直流电机（转子+定子励磁绕组+碳刷）**、**传动机构（单向离合器+拨叉）**与**电磁开关**三部分组成。碳刷是易损件——它把电流从静止的机壳引入旋转的换向器，磨损到极限后触点接触不良，起动机就表现为「转无力」甚至「时转时不转」。<span class="marginnote">串励电机与第3课发电机的永磁/并励结构形成对照：发电机要的是「转速越高电压越稳」，起动机要的是「低速大转矩」。理解「电机按励磁方式分特性」这一思想，与第六级《电机学》中直流电机的章节完全对应。</span>
