# 汽车电器与电控系统维修（含OBD故障诊断）

以《汽车维修工国家职业技能标准》（汽车电器维修工工种）与《汽车电子控制技术与故障诊断》培训教材为纲，结合国六OBD要求（GB 18352.6-2016）与ISO 15031标准，系统覆盖从汽车电路识图、电源起动照明检修、电控传感器执行器维护到OBD故障码读取与诊断实操的完整维修技能体系。学完这些章节，就写完了汽车电器维修工从量电测信号到读码定故障所需的全部内容。

## 对标教材

- 《汽车维修工国家职业技能标准》汽车电器维修工工种
- 《汽车电子控制技术与故障诊断》培训教材
- 国六OBD要求（GB 18352.6-2016）及ISO 15031标准
