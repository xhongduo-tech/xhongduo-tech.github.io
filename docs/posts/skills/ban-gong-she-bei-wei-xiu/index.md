# 办公设备维修（打印机/复印机/扫描仪）

打印机、复印机、扫描仪是办公场所最常见的机电一体化设备，其检修涉及机械传动、光学成像、硒鼓显影与定影加热等多类系统。以《打印机维修技术》《复印机维修》及办公设备维修行业培训教材为纲，学完这些章节，就掌握了从办公设备工作原理、故障诊断到机械光学与成像系统检修的完整技能。

- 《复印机维修》
