## 为什么从重装开始

这是本专题的收官篇。前面 27 节把「从准备介质到故障排除」走了一遍，现在把最后一块拼图放上：**决定重装时，怎么做到「系统推倒重来、数据一个不丢」**。重装不是终点，而是「旧系统 → 新系统」的完整迁移，涉及三个环节：**决定何时重装、迁移前准备、数据与环境的恢复**。

把三平台的重装与迁移方案（Windows 的备份还原、Linux 的 tar/rsync、macOS 的迁移助理）串在一起，你就拥有了「从头到尾自己搞定一台电脑」的完整能力。

## 1 什么时候该重装：判断的智慧

重装不是越多越好，但有些情况确实「重装是正道」：

| 该重装 | 不该重装 |
| --- | --- |
| 系统被严重感染（勒索/木马） | 小毛病（先试修复工具） |
| 系统文件损坏无法修复 | 硬件问题（重装也白搭） |
| 常年累积越来越慢 | 只是磁盘满（清理即可） |
| 换更大/新的硬盘 | 单纯想换口味（考虑虚拟机） |

<span class="marginnote">判断口诀：「软件问题重装能解决，硬件问题重装也白搭。」重装前先确认不是硬件故障（硬盘 SMART、内存测试），否则重装完照样蓝屏。参考本专题《硬盘健康检测与坏道排查》《无法开机与蓝屏错误排查》。</span>

**重点：重装是一场「结构化搬家」，顺序是「备份 → 重装 → 恢复」。** 三分之二的功夫在备份与恢复，重装本身只占三分之一。

## 2 重装前的准备清单

无论哪平台，重装前做齐四件事：

1. **备份数据**：按《系统备份与还原》的 3-2-1 原则，个人文件 + 系统级备份各一份。
2. **导出凭证**：浏览器密码、SSH 私钥、2FA 恢复码、BitLocker/FileVault 恢复密钥。
3. **记录环境**：装了哪些重要软件、用了哪些设置，方便重装后补装。
4. **准备介质**：启动 U 盘（三平台介质制作见第1篇）。

**辨析｜易错点：** 「重装前备份」最常见的坑是**只备份了个人文件，没备份环境**。系统重装后，开发者会发现自己少装了 30 个软件、丢了 SSH 配置。把「记录环境」这一步认真做，重装后的恢复能省 80% 的时间。

## 3 核心对比表：三平台的数据迁移方案

| 迁移对象 | Windows | Linux | macOS |
| --- | --- | --- | --- |
| 个人文件 | 文件历史 / 手动拷贝 | rsync / tar | Time Machine / 迁移助理 |
| 系统设置 | 微软账号同步 | dotfiles（配置文件） | iCloud + 迁移助理 |
| 应用 | 重装 + 账号恢复 | 包管理器批量安装 | App Store + 下载 |
| 完整还原 | 系统映像恢复 | tar 解包 | Time Machine 全量恢复 |

三平台思路不同：Windows 靠「账号 + 云」，Linux 靠「配置文件（dotfiles）+ 包管理器」，macOS 靠「迁移助理 + Time Machine」。各有各的哲学，但目标一致——**重装后尽量「回到原来的样子」**。

## 4 动手：Linux 重装的数据迁移

Linux 用户重装最依赖「dotfiles + 包管理器」这套极客工作流：

**第一步：备份 dotfiles。** 把 `~/.bashrc`、`~/.zshrc`、`~/.config/`、`~/.ssh/`、`.gitconfig` 同步到 Git 仓库或备份盘。

**第二步：记录软件清单。** 导出已安装软件列表：

```
dpkg --get-selections > packages.txt     # Debian/Ubuntu 系
dnf list installed > packages.txt        # Red Hat 系
```

**第三步：重装系统。** 用启动 U 盘重装，注意 `/home` 独立分区的话个人数据原样保留（见《Linux 自定义分区与挂载点规划》）。

**第四步：恢复软件。** 新系统里用清单批量重装：

```
sudo apt install $(cat packages.txt)     # 或按需
```

**第五步：恢复配置。** 把 dotfiles 拉回来，`~/.ssh` 权限设为 600，SSH 私钥重新可用。<span class="marginnote">dotfiles 是 Linux 迁移的灵魂：配置文件才是「我的环境」，重装系统只是换个「装着它们的壳」。把 dotfiles 放进 Git 仓库管理，任何机器都能一键还原到自己的开发环境——这是从「会重装」到「会迁移」的分水岭。</span>

## 5 动手：Windows 与 macOS 的数据迁移

**Windows：** 微软账号登录后，壁纸、部分设置、密码（凭据管理器）能自动同步；个人文件从文件历史/备份盘拷回；软件从官网或商店重装。想「整机还原到某个时刻」，用「系统映像恢复」（对应《系统备份与还原》的系统映像）。

**macOS：** 新 Mac 或重装后用**迁移助理（Migration Assistant）**：可从 Time Machine 备份或另一台 Mac 迁移「用户、应用、设置、文件」一步到位。<span class="marginnote">macOS 的迁移助理是最「无痛」的方案：接上 Time Machine 硬盘，启动后按提示选「从 Mac、Time Machine 备份或启动磁盘传输」，它会把用户数据、应用、设置整体搬过去。相比 Windows 的手动恢复，macOS 更接近「整机克隆」。</span>

## 6 动手：一次完整的重装迁移

把三平台流程统一成一套节奏：

**第一步：定方案。** 按第3节选好本平台迁移路径。

**第二步：备份 + 导出。** 数据、凭证、环境清单三件套做齐。

**第三步：重装系统。** 启动 U 盘全新安装（或重置此电脑 / 恢复模式重装）。

**第四步：迁移数据。** Windows 拷回文件 + 账号登录；Linux 恢复 dotfiles + 批量装软件；macOS 迁移助理全量搬。

**第五步：验证。** 逐项检查：文件在、账号通、软件能开、密钥能用。

**第六步：收尾。** 装好防病毒（保持更新）、设好自动备份，把「下一次重装」的代价降到最低。

## 8 小结

- 重装是「**备份 → 重装 → 恢复**」的三段式搬家，功夫在备份与恢复。
- 判断口诀：**软件问题重装能解决，硬件问题重装也白搭**。
- 重装前四件事：**备份数据、导出凭证、记录环境、准备介质**。
- Linux 迁移靠 **dotfiles + 包管理器清单**；macOS 靠**迁移助理**；Windows 靠**账号 + 文件历史/系统映像**。
- 重装后验证：**文件、账号、软件、密钥**逐项检查，确认「新家」真的住得进去。
