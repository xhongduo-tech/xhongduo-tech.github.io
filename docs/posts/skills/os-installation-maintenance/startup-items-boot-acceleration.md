## 为什么从启动项开始

「开机怎么这么慢？」——大多数人第一反应是「换个固态硬盘」或「重装系统」，但其实 90% 的开机慢是**启动项（startup items）**太多导致的：每次开机，系统要一个个把后台软件拉起来，软件越多，开机越慢。而管理启动项是**零成本**的加速手段。

本节讲清启动项的机制（Windows、Linux、macOS 三平台），以及怎么判断哪些该留、哪些该关。它承接上一节的「磁盘清理」，也呼应本专题「日常维护」的总目标——让电脑恢复出厂般流畅。

## 1 开机慢的真相：启动项是元凶

开机流程本质是「加载系统 → 加载驱动 → 启动后台服务与程序」。前两部分由系统与硬件决定，你能掌控的主要是第三部分——**启动项**。很多软件安装时默认「开机自启」（QQ、微信、各类云盘、软件管家、游戏平台），数量一多，开机就是「全家福点名」。<span class="marginnote">判断「启动项是不是罪魁祸首」有个简单方法：进安全模式或干净启动（msconfig 关闭所有启动项）对比开机时间。若干净启动明显变快，问题就在启动项。</span>

**重点：启动项管理的目标是「保留必要的，关掉冗余的」。** 系统必要的服务、输入法、安全软件要留；聊天工具、云盘、播放器这些「要用时再开」的可以关。

## 2 Windows：任务管理器管理启动项

Windows 的启动项管理入口在**任务管理器**：`Ctrl+Shift+Esc` →「启动」标签。<span class="marginnote">老教程会说「注册表 `HKLM\...\Run` 或 `msconfig`」，但现代 Windows 管理启动项的标准入口就是任务管理器——它把每个启动项标了「状态」和「启动影响」（无/低/中/高），一目了然。</span>

操作要点：

| 操作 | 说明 |
| --- | --- |
| 查看启动影响 | 任务管理器 → 启动，看「启动影响」列 |
| 禁用 | 右键 →「禁用」，开机不再自动启动 |
| 启用 | 右键 →「启用」，恢复自动启动 |
| 深层服务 | 任务管理器 →「服务」标签，或 `services.msc` |

**判断要点：** 「启动影响」标「高」且你不需要它常驻的（如某些游戏平台），优先禁用。但**别动**安全软件（杀毒、防火墙）与输入法——它们开机即需要。

## 3 Linux：systemd 与开机服务

Linux 的开机自启由 **systemd** 管理，服务通过「单元（unit）」定义。常用命令：

```
systemctl list-unit-files --type=service    # 列出所有服务
systemctl is-enabled 服务名                 # 查看某服务是否开机自启
sudo systemctl disable 服务名               # 关闭开机自启
sudo systemctl enable 服务名                # 开启开机自启
```

<span class="marginnote">鸟哥在《基础学习篇》系统服务章节讲的正是这套 `systemctl` 命令族：`enable` 相当于「加入开机启动清单」，`disable` 是移除。桌面 Linux 用户遇到「某个服务拖慢开机」，用 `systemd-analyze blame` 能直接列出各服务耗时，精准定位。</span>

`systemd-analyze` 是加速开机的利器：

```
systemd-analyze              # 显示总开机时间
systemd-analyze blame        # 各服务启动耗时排序
```

耗时最高的服务如果不是必要项，`disable` 它，开机立刻变快。

## 4 macOS：登录项

macOS 的启动项叫**登录项（Login Items）**：系统设置 →「通用」→「登录项与扩展」。里面分「登录时打开」和「在后台允许」。<span class="marginnote">macOS 新版把登录项与「后台项目」（旧版叫「登录项与扩展」）合并管理，还能查看「最近因后台项目占用的资源」。对「开机转菊花」的 Mac，清点登录项是第一步。</span>

操作：选中不需要的项目 → 点减号「−」移除。保留：输入法（如搜狗、微信输入法）、安全类工具；可关：云盘、消息类、下载工具。

## 5 核心对比表：三平台启动项管理

| 对比项 | Windows | Linux | macOS |
| --- | --- | --- | --- |
| 管理入口 | 任务管理器 → 启动 | `systemctl enable/disable` | 系统设置 → 登录项 |
| 查看影响 | 启动影响（高/中/低） | `systemd-analyze blame` | 后台项目占用 |
| 必要保留 | 安全软件、输入法 | 系统服务、硬件相关 | 输入法、安全工具 |
| 可关闭 | 聊天、云盘、游戏平台 | 非必要用户服务 | 云盘、下载工具 |

## 6 动手：把开机时间压下去

**第一步：观察现状。** Windows 任务管理器看启动项与影响；Linux 跑 `systemd-analyze`。

**第二步：列出「高影响 + 非必需」清单。** 通常包括：各类云盘、游戏平台、软件管家、迅雷等下载工具。

**第三步：逐个禁用。** Windows 任务管理器右键禁用；Linux `systemctl disable`；macOS 登录项移除。

**第四步：保留底线。** 安全软件、输入法、系统服务一律不动。

**第五步：验证。** 重启一次，对比开机时间；出问题（某个功能没了）就把对应项启用回来。

## 7 速查表：启动项管理命令

| 平台 | 命令/路径 |
| --- | --- |
| Windows 任务管理器 | `Ctrl+Shift+Esc` → 启动 |
| Windows 服务 | `services.msc` |
| Linux 列服务 | `systemctl list-unit-files --type=service` |
| Linux 禁用 | `sudo systemctl disable 服务名` |
| Linux 查看耗时 | `systemd-analyze blame` |
| Linux 总耗时 | `systemd-analyze` |
| macOS 登录项 | 系统设置 → 通用 → 登录项与扩展 |

## 8 补充速查：启动项留弃判断表

把「哪些启动项该留、哪些该关」做成一张判断表：

| 启动项 | 判断 | 建议 |
| --- | --- | --- |
| 安全软件 | 开机即需要 | 保留 |
| 输入法 | 常用 | 保留 |
| 系统更新服务 | 系统必须 | 保留 |
| 聊天工具 | 用时不迟 | 可关 |
| 云盘同步 | 可手动开 | 可关 |
| 游戏平台 | 玩游戏才用 | 可关 |
| 软件管家 | 常驻无用 | 建议关 |
| 下载工具 | 用时不迟 | 可关 |

## 9 小结

- 开机慢的头号元凶是**启动项太多**，管理启动项是零成本加速。
- 判断标准：**必要留（安全软件、输入法、系统服务），冗余关（聊天、云盘、游戏平台）**。
- Windows：任务管理器「启动」标签，看「启动影响」禁用高影响非必需项。
- Linux：`systemctl disable` 关服务，`systemd-analyze blame` 定位耗时大户。
- macOS：系统设置「登录项」，移除不需要的登录项与后台项目。
- 改造后重启验证，出问题就启用回来——启动项管理可随时回退。
