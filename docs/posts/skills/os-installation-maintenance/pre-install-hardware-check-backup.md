## 为什么从安装前准备开始

这一节是整个专题的「起跑线」。大多数人装系统失败，不是败在安装过程中，而是败在**没有核对硬件、没有备份数据**就仓促动手。一台机器能不能装某个系统、装完能不能驱动、装坏了有没有退路，答案在按下电源键之前就已经注定了。把「装前检查」练成肌肉记忆，后面的每一节（分区、引导、驱动、恢复）都会少踩一半的坑。

本专题以《鸟哥的Linux私房菜：基础学习篇》为 Linux 主线，鸟哥在第2章「主机规划与磁盘分区」里反复强调：安装前的硬件规划决定了系统未来的稳定与安全。本节与其说在教你操作，不如说在教你「安装前问自己四个问题」——能装吗、能跑吗、能驱动吗、数据安全吗。

## 1 三个「能」：核对硬件的三层目标

安装前核对硬件，其实是在回答三个层层递进的问题，任何一个不满足都要提前做决定：

**能装吗——满足最低要求。** 每个系统都有最低配置门槛。以 Windows 11 为例，微软官方要求：1 GHz 及以上、2 核及以上的 64 位处理器，4 GB 内存，64 GB 存储，支持 UEFI 安全启动（Secure Boot）的固件，以及 TPM 2.0 模块。<span class="marginnote">TPM（可信平台模块）2.0 是 Windows 11 的硬性要求，也是很多老机器「升不了级」的直接原因。微软官方提供 PC Health Check 工具，装前先跑一遍最省事。</span>而主流的 Linux 桌面（如 Ubuntu 24.04）官方最低要求通常低得多——2 GB 内存、25 GB 磁盘即可起步，这也是老机器装 Linux 重获新生的原因。

**能跑吗——够不够流畅。** 最低配置只是「能开机」，离「好用」还很远。桌面系统建议至少 8 GB 内存，固态硬盘（SSD）几乎是必须的——机械硬盘上装 Windows 11，开机动辄两三分钟，体验是灾难级的。<span class="marginnote">安装系统前顺手看看内存插槽和硬盘接口：DDR4/DDR5、SATA/NVMe，这些决定了「能不能升级」，属于成本最低的硬件核对。</span>

**能驱动吗——硬件有没有系统支持。** 网卡、显卡、声卡、无线网卡（Wi-Fi）是驱动重灾区。Linux 尤其要留意：太新的无线网卡、独显，可能在发行版默认内核里没有现成驱动（鸟哥在《基础学习篇》第9章讲内核模块时专门谈过这个）。核对方式很简单——装之前用搜索引擎查「你的硬件型号 + 系统名」，看别人的成功经验。

还有一层容易被忽略的「能跑吗」变体：**架构问题**。现代电脑分 x86_64 与 arm64（Apple Silicon、部分新轻薄本）两大阵营，镜像必须对应架构——拿 x86 的 Windows 镜像装 arm64 机器是装不进去的，Linux 要下载 `amd64` 还是 `arm64` 版也全看 CPU。

## 2 一张可执行的硬件核对表

把核对做成表格，照着打勾就不会漏：

| 核对项 | 怎么查 | 装系统时的影响 |
| --- | --- | --- |
| CPU 架构（x86_64 / arm64） | 系统信息 | 决定下载哪个版本镜像 |
| 内存容量与插槽 | BIOS/任务管理器 | 决定选 32/64 位、桌面体验 |
| 磁盘容量与接口 | 磁盘管理 / `lsblk` | 决定分区方案与安装位置 |
| 固件模式（UEFI/Legacy） | BIOS 设置 | 决定 GPT 还是 MBR |
| 是否有 TPM 2.0 | BIOS 设置 / tpm.msc | Windows 11 硬性要求 |
| 网卡型号 | 设备管理器 / `lspci` | 预判驱动是否好找 |
| 显卡型号 | 设备管理器 / `lspci` | 预判是否需要闭源驱动 |

其中「固件模式」与「磁盘格式」必须配对：**UEFI 配 GPT，Legacy 配 MBR**，混搭是装完无法引导的头号原因，详见本专题《BIOS/UEFI 引导模式与启动介质制作》。核对完这张表，你手里就握着一份「这台机器能装什么」的说明书。

## 3 数据备份：重装前的「后悔药」

系统装坏可以重来，数据丢了就真没了。备份不是可选项，是**安装前唯一的后悔药**。这里引入运维界最著名的 **3-2-1 备份原则**：**至少 3 份数据、2 种不同介质、1 份在异地（离机）**。<span class="marginnote">3-2-1 原则出自摄影师 Peter Krogh 在《The DAM Book》中总结的经验，如今是数据保护的通用准绳。对普通用户而言：电脑一份 + 移动硬盘一份 + 云盘一份，就达标了。</span>

备份清单要覆盖「数据」而非「系统」——系统装完是全新的，但下面的东西一旦丢了很难找回来：

- **个人文档**：桌面、文档、图片、视频、音乐文件夹。
- **浏览器资产**：书签、保存的密码、Cookie（建议用浏览器自带同步或导出）。
- **密钥与凭证**：SSH 私钥（`~/.ssh/`）、GPG 密钥、二次验证器的恢复码——丢了等于丢账号。
- **开发环境**：`.gitconfig`、`~/.zshrc`/`~/.bashrc`、IDE 设置、依赖锁文件（`package-lock.json`、`requirements.txt`）。
- **聊天与邮件**：微信/QQ 聊天记录（客户端内可导出）、邮件本地归档。
- **系统级凭证**：路由器管理员密码、BitLocker 恢复密钥（务必导出到微软账户或打印保存）。

**辨析｜易错点：** 备份不是「全盘复制」。微信几百 GB 的缓存、游戏本体、临时文件，重装后都能重新下载，不需要占备份空间；真正稀缺的是**那些「世界上只有这一份」的东西**——照片原图、手头未同步的文档、私钥与恢复码。想清楚「哪些丢了要哭」，就备份哪些。

## 4 核心对比表：三个平台的「装前功课」

不同平台装前要准备的侧重点不同，用一张表对照记忆：

| 对比项 | Windows | Linux | macOS |
| --- | --- | --- | --- |
| 典型硬件门槛 | Windows 11 要求 TPM 2.0 | 配置宽松，老机器友好 | 仅限 Apple 硬件 |
| 介质来源 | 微软媒体创建工具 | 发行版官网镜像 | App Store / 恢复模式 |
| 架构限制 | 基本只有 x86_64 | x86_64 / arm64 都常见 | Apple Silicon 专用镜像 |
| 数据迁移工具 | 文件历史 / 备份还原 | rsync / tar 手动 | 迁移助理（Migration Assistant） |
| 重装后可恢复性 | 微软账号登录找回大部分设置 | 靠 dotfiles 与备份 | iCloud 同步 + Time Machine |

这张表也预告了后面五篇的结构：第1篇讲介质制作，第2篇讲安装实战，最后两篇讲故障恢复——但无论走到哪一步，「备份先做」的规矩都不变。

## 5 动手：五步完成装前准备

把抽象原则落成一条可执行路径：

**第一步：决定要装的系统。** 是 Windows 11、Ubuntu 双系统，还是重装 macOS？系统决定后面所有步骤。

**第二步：跑硬件体检。** Windows 下用官方「PC Health Check」；Linux 下用 `lspci`、`free -h`、`df -h` 快速确认硬件与磁盘空间。<span class="marginnote">`free -h` 看内存，`df -h` 看磁盘剩余，`lspci` 看硬件型号——这是 Linux 下最常用的三条体检命令，后面《Linux 自定义分区与挂载点规划》还会频繁用到 `df`。</span>

**第三步：执行 3-2-1 备份。** 把第3节的清单逐项导出到移动硬盘和云盘，各存一份。

**第四步：记录关键凭证。** 把 TPM 恢复密钥、BitLocker 密钥、账号信息抄到离线安全的地方。

**第五步：准备启动介质。** 下载安装镜像并写入 U 盘，这一步的细节在《Windows 安装介质（U盘）制作》与《Linux 发行版镜像下载与启动盘制作》中展开。

## 6 易错点：装前最常见的三个坑

三个坑几乎每年都在新手身上重演，提前说破：

- **「我装个系统而已，为什么要备份？」** 最贵的一课。装机过程删分区、格式化是常态，一次误操作就是照片和论文全部清零。
- **「官网下载太慢，我从 XX 系统之家下。」** 第三方镜像站常被植入广告、捆绑软件甚至后门，装完系统就「中招」。镜像只认官网。
- **「这台老电脑直接上 Windows 11 吧。」** 没有 TPM 2.0、不支持 Secure Boot 的老机器装 Windows 11 会被安装器直接拒绝；与其硬装，不如换 Linux 桌面，反而流畅得多。

## 7 补充速查：装前检查与备份清单

把本节的检查与备份动作收敛成一张可打勾的清单：

| 事项 | 完成动作 | 打勾 |
| --- | --- | --- |
| 确定要装的系统 | 选好 Windows/Linux/macOS 版本 | ☐ |
| 硬件体检 | PC Health Check / `lspci`+`free -h` | ☐ |
| 固件模式 | 确认 UEFI/Legacy | ☐ |
| 架构确认 | x86_64 / arm64 | ☐ |
| 个人文档备份 | 桌面、文档、照片拷出 | ☐ |
| 密钥导出 | SSH、GPG、2FA 恢复码 | ☐ |
| 浏览器导出 | 书签、密码 | ☐ |
| 磁盘密钥 | BitLocker/FileVault 恢复密钥 | ☐ |
| 3-2-1 落点 | 移动硬盘 + 云盘各一份 | ☐ |
| 制作介质 | 启动 U 盘备好 | ☐ |

## 8 小结

- 安装前核对硬件，本质是回答三个问题：**能装吗、能跑吗、能驱动吗**。
- Windows 11 的硬门槛是 **TPM 2.0 + UEFI 安全启动 + 4 GB 内存 + 64 GB 磁盘**；Linux 门槛低得多。
- **UEFI 配 GPT、Legacy 配 MBR**，固件与磁盘格式必须配对。
- 备份遵循 **3-2-1 原则**：3 份、2 种介质、1 份异地。
- 数据备份清单优先级：个人文档、浏览器资产、**密钥与凭证**、开发环境、聊天记录。
- 镜像只从官网下载；老机器装 Windows 11 前先确认 TPM。

在下一节，我们将进入硬件之下的地基——弄明白磁盘上**分区**是怎么组织的，这就是**磁盘分区基础：MBR、GPT 与文件系统**。
