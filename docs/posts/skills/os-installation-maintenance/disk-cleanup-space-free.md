## 为什么从磁盘清理开始

「C 盘满了」大概是电脑日常维护里被吐槽最多的一句话。磁盘空间耗尽不只是「装不了新东西」——它会让系统变慢、更新失败、软件崩溃，甚至无法开机。而磁盘清理恰恰是**回报率最高的维护动作**：不需要买新硬盘，几下就能腾出几十 GB。

本节按「先看清占在哪 → 再针对性清理」的思路，把三平台的清理工具与命令一次讲清。它承接《系统更新与补丁管理》里提到的「更新占磁盘」问题，也呼应鸟哥第7章的磁盘管理。

## 1 清理前先看清：占用分布图

别盲目删文件，先看清空间都去哪了。Windows 用「设置 → 系统 → 存储」看各类占用，Linux 用命令，macOS 用「关于本机 → 储存空间」：

| 常见空间大户 | 说明 |
| --- | --- |
| 系统更新缓存 | Windows 更新残留、旧版本文件 |
| 临时文件 | 系统与软件产生的临时缓存 |
| 浏览器缓存 | 图片、JS、视频缓存 |
| 微信/QQ 缓存 | 聊天图片视频，动辄几十 GB |
| 回收站/垃圾桶 | 删除的文件并未真正释放 |
| 休眠文件（hiberfil.sys） | 占内存等量的磁盘空间 |
| 软件安装残留 | 卸载不干净的组件 |

**重点：清理的第一原则是「先定位，后动手」。** 用工具看清哪个目录占用最大，再针对性清理；盲目「全部删除」可能删掉有用的东西。

## 2 Windows：磁盘清理全家桶

Windows 提供了层层递进的清理工具：

**第一层：存储感知（Storage Sense）。** 设置 → 系统 → 存储 → 打开「存储感知」，系统会自动清理临时文件与回收站，可设定期运行。

**第二层：磁盘清理（Disk Cleanup）。** 对 C 盘右键 → 属性 → 磁盘清理，勾选「Windows 更新清理」「临时文件」「回收站」等。点「清理系统文件」能拿到更多选项（含旧的 Windows 安装文件）。<span class="marginnote">「磁盘清理 → 清理系统文件 → Windows 更新清理」常能一次释放 5–20 GB——那是系统更新留下的旧版本文件。这也是上一节「更新占磁盘」的收尾解法。</span>

**第三层：手动清理大户。** 微信/QQ 的「设置 → 文件管理 → 打开文件夹」，把缓存聊天图片清掉；浏览器的「清除浏览数据」。

## 3 Linux：命令行清理

Linux 用户用命令查看与清理，核心三件套：

| 命令 | 作用 |
| --- | --- |
| `df -h` | 看各挂载点使用量 |
| `du -sh *` | 看当前目录下各项目占用 |
| `ncdu` | 交互式磁盘占用分析（更好用） |

清理动作：

```
sudo apt autoremove          # 清理无用的依赖包
sudo apt clean               # 清理下载的 .deb 缓存
journalctl --disk-usage      # 看系统日志占用
sudo journalctl --vacuum-size=200M   # 压缩日志到 200M
```

<span class="marginnote">Linux 的日志（journal）常被忽略：长期运行的机器 `/var/log/journal` 可能累积到几 GB。`journalctl --vacuum-size` 一行命令就能压缩。配合 `du -sh /var/*` 找出大户目录，清理就有的放矢。</span>

## 4 macOS：优化储存空间

macOS 的清理入口很集中：「系统设置 → 通用 → 储存空间」。它会自动列出「系统数据」「文稿」「App」等占用，并给出「优化储存空间」建议：<span class="marginnote">macOS 的「系统数据」常含大量缓存与 Time Machine 本地快照，占几十 GB。存储设置里的「优化」会建议清空废纸篓、卸载未用 App、清理 iMessage 附件等，一键式完成大部分清理。</span>

| macOS 优化项 | 作用 |
| --- | --- |
| 清空废纸篓 | 30 天未清空时自动清 |
| 存储到 iCloud | 把文件上云，本地留占位 |
| 卸载未使用的 App | 识别长时间未用的应用 |
| 清理 iMessage 附件 | 删除大于指定年龄的附件 |

## 5 核心对比表：三平台清理工具

| 对比项 | Windows | Linux | macOS |
| --- | --- | --- | --- |
| 自动化 | 存储感知 | 手动 + cron | 优化储存空间 |
| 查看占用 | 设置→存储 | `df`/`du`/`ncdu` | 储存空间面板 |
| 更新缓存清理 | 磁盘清理 | `apt clean` | 系统自带 |
| 日志清理 | 磁盘清理（事件日志） | `journalctl --vacuum` | 系统管理 |
| 第三方工具 | CCleaner（慎用） | BleachBit | 第三方（一般不必要） |

**判断要点：** 优先用系统自带工具，第三方清理软件（如 CCleaner）容易误删、捆绑广告，能不用就不用。

## 6 动手：一次完整的磁盘清理

**第一步：定位大户。** Windows 打开「设置 → 系统 → 存储」看分类；Linux 跑 `df -h` + `ncdu`。

**第二步：清更新缓存。** Windows 磁盘清理勾「Windows 更新清理」；Linux `sudo apt clean`。

**第三步：清用户缓存。** 微信/QQ、浏览器、回收站。

**第四步：清日志（Linux）。** `journalctl --vacuum-size=200M`。

**第五步：验证。** 再看一次占用，确认释放了多少空间。

## 7 速查表：空间占用排查命令

| 场景 | 命令/路径 |
| --- | --- |
| Windows 看占用 | 设置 → 系统 → 存储 |
| Windows 磁盘清理 | C 盘右键 → 属性 → 磁盘清理 |
| Linux 看挂载使用 | `df -h` |
| Linux 看目录占用 | `du -sh *` |
| Linux 交互式分析 | `ncdu` |
| Linux 清依赖 | `sudo apt autoremove` |
| Linux 清包缓存 | `sudo apt clean` |
| Linux 清日志 | `journalctl --vacuum-size=200M` |
| macOS 看占用 | 系统设置 → 通用 → 储存空间 |

## 8 小结

- 清理第一原则：**先定位占用地，再动手删除**，别盲目全删。
- 空间大户：**更新缓存、临时文件、浏览器缓存、聊天缓存、回收站、休眠文件**。
- Windows 三件套：**存储感知 → 磁盘清理 → 手动清大户**，「清理系统文件」能释放更新残留。
- Linux 命令：`df -h`、`du -sh *`、`ncdu` 定位，`apt clean` + `journalctl --vacuum-size` 清理。
- macOS 走**「优化储存空间」**，一键处理废纸篓、卸载未用 App 等。
- 优先系统自带工具，第三方清理软件能不用就不用。
