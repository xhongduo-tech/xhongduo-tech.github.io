## 为什么从安全模式开始

上一节讲「无法开机」时反复提到「进安全模式」「进恢复环境」——它们是故障排除的**最后阵地**：系统正常时它们用不上，系统坏了它们是你唯一能动手的地方。**安全模式（Safe Mode）** 以最精简的驱动和服务启动系统，让你在「干净环境」里卸载问题驱动、查杀病毒、修复配置。

本节把三平台的「安全启动」体系一次讲清：安全模式能干什么、怎么进、和「高级启动（WinRE）」有什么关系，以及 Linux/macOS 各自的对应方案。它是「系统还能救吗」的答案之书。

## 1 安全模式是什么

**安全模式**是操作系统的一种**最小化启动模式**：只加载基本驱动（显示、键盘、鼠标、磁盘），不加载第三方驱动、不启动多余服务、不加载启动项。用最干净的环境启动，从而：

- 判断问题是否由驱动/软件引起（安全模式正常 = 问题在第三方软件）。
- 卸载无法正常卸载的问题驱动、软件。
- 运行杀毒、修复工具、`chkdsk`、系统还原。
- 找回被勒索软件加密前的工作状态（进安全模式往往禁用网络，阻止传播）。

<span class="marginnote">安全模式的「干净」体现在一个细节：进去后分辨率变低、壁纸消失、部分功能不可用——这不是「坏了」，而是「只带了最低配置出门」。看到低分辨率桌面，说明你已经安全着陆在排除区。</span>

**重点：安全模式是一把「照妖镜」——能判断问题是不是第三方驱动/软件引起的。** 普通模式蓝屏、安全模式正常，结论基本就是「某个驱动或启动项有问题」。

## 2 进入安全模式的三种方式

| 方式 | 步骤 | 适用 |
| --- | --- | --- |
| 设置里重启 | 设置 → 系统 → 恢复 → 高级启动 → 立即重新启动 | 系统还能进桌面 |
| Shift+重启 | 按住 Shift 点「重新启动」 | 系统还能进锁屏 |
| 连续失败 3 次 | 开机失败自动进 WinRE | 进不了系统 |

进入 WinRE 后：疑难解答 → 高级选项 → 启动设置 → 重启，重启后按数字键选「启用安全模式」（4）或「带网络的安全模式」（5）。<span class="marginnote">「带网络的安全模式」比「安全模式」多加载网卡驱动，用于「需要联网下载驱动/杀毒」的场景。排障第一遍用普通安全模式即可，需要联网再换带网络的。</span>

## 3 高级启动（WinRE）：排障工具箱

**WinRE（Windows 恢复环境）** 是一整套恢复工具，比安全模式功能更全，入口就是「高级启动」。常用工具：

| 工具 | 作用 |
| --- | --- |
| 启动修复 | 自动修复引导问题 |
| 启动设置 | 进入安全模式等启动选项 |
| 命令提示符 | 手动执行 `chkdsk`、`bcdboot` 等 |
| 卸载更新 | 卸载最近装的更新（更新导致问题时用） |
| 系统还原 | 回到之前的还原点 |
| 系统映像恢复 | 从完整系统镜像恢复 |

**判断要点：** 排障的阶梯是「启动修复 → 安全模式 → 命令提示符 → 系统还原 → 重置」，从最轻到最重逐级尝试，别一步跳到重装。

## 4 核心对比表：三平台的「安全启动」

| 对比项 | Windows | Linux | macOS |
| --- | --- | --- | --- |
| 名称 | 安全模式 | 单用户模式/救援模式 | 安全模式 |
| 进入方式 | WinRE → 启动设置 | GRUB 编辑 `single` | 开机按 Shift |
| 主要用途 | 卸载驱动、查毒 | 修配置、救引导 | 排障、修磁盘 |
| 恢复工具 | WinRE 全家桶 | Live CD + chroot | 恢复模式 + 磁盘工具 |

Linux 与 macOS 的对应方案分别在第3节和第5节讲，三者的共同点是：**都在「最小环境」里排除第三方因素**。

## 5 动手：在安全模式下卸载问题驱动

**第一步：进安全模式。** 按第2节的任一种方式进入。

**第二步：确认「照妖镜」结果。** 安全模式能正常进 → 问题在第三方驱动/软件。

**第三步：卸载最近装的驱动。** 设备管理器 → 右键可疑设备 → 卸载设备（勾选删除驱动软件）。

**第四步：跑修复工具。** 安全模式下运行 `chkdsk /r`（磁盘检查）、Windows 安全中心全盘扫描。

**第五步：重启验证。** 正常模式重启，问题消失即成功；没消失则继续排查（内存、硬盘）。

## 6 速查表：安全模式与恢复工具

| 场景 | 路径/命令 |
| --- | --- |
| 进高级启动 | 设置 → 系统 → 恢复 → 高级启动 |
| 强制进 WinRE | 开机连续失败 3 次 |
| 进安全模式 | 启动设置 → 数字键 4 |
| 带网络安全模式 | 启动设置 → 数字键 5 |
| 启动修复 | 高级选项 → 启动修复 |
| 磁盘检查 | 命令提示符 → `chkdsk /r` |
| 系统还原 | 高级选项 → 系统还原 |

## 7 补充速查：进入安全模式的完整路径

把「怎么进安全模式」的每一步列成可照做的路径表：

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| 方式一 | 设置 → 系统 → 恢复 → 高级启动 | 系统还能进桌面时 |
| 方式二 | 按住 Shift 点「重新启动」 | 锁屏界面也可以 |
| 方式三 | 开机连续失败 3 次 | 自动进 WinRE |
| 进入 WinRE | 疑难解答 → 高级选项 | 恢复环境主菜单 |
| 启动设置 | 高级选项 → 启动设置 → 重启 | 重启进入选择界面 |
| 普通安全模式 | 按数字键 4 | 最精简启动 |
| 带网络安全模式 | 按数字键 5 | 需联网时用 |
| 退出安全模式 | 正常重启即可 | 无需额外设置 |

## 8 小结

- 安全模式是**最小化启动**，只加载基本驱动，是排障的「照妖镜」。
- 普通模式蓝屏、安全模式正常 → 问题在第三方驱动/软件。
- 进安全模式三招：**设置重启、Shift+重启、连续失败 3 次进 WinRE**。
- **WinRE** 是排障工具箱：启动修复、安全模式、命令提示符、系统还原都在里面。
- 排障阶梯：**启动修复 → 安全模式 → 命令提示符 → 系统还原 → 重置**。
- Linux/macOS 各有对应方案（单用户模式/安全模式），见后续两节。
