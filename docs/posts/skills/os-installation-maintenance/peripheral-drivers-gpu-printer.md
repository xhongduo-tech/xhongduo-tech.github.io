## 为什么从外设驱动开始

前面几节讲了驱动的一般原理和 Windows 设备管理器，本节把它们用到最常出问题的两类外设上：**显卡**与**打印机**。它们恰恰是驱动管理两个极端的代表——显卡驱动「复杂、关键、影响性能」，打印机驱动「琐碎、多样、厂商各自为政」。把这两类搞定，其他外设（声卡、蓝牙、摄像头）就是降维打击。

三平台在「外设驱动」上的哲学差异也最明显：Windows 靠设备管理器 + 厂商安装包，Linux 靠内核模块 + 包管理器，macOS 靠系统内置 + 系统更新。本节分别给出可执行的安装路径。

## 1 显卡驱动：性能与折腾并存的巨头

显卡驱动是三平台中最「重」的驱动，因为现代 GPU 承担游戏渲染、视频编解码、AI 加速（CUDA）等重任，驱动直接决定性能与稳定性。三家的处理方式：

| 厂商/平台 | 安装方式 | 说明 |
| --- | --- | --- |
| NVIDIA（Windows） | GeForce Experience / 官网 .exe | 闭源驱动，需登录/选 Game Ready 或 Studio 版 |
| AMD（Windows） | Adrenalin 软件 | 闭源，官网下载 |
| Intel（Windows） | 官网 / Windows 更新 | 核显驱动，较省心 |
| NVIDIA（Linux） | 发行版包管理器 / DKMS | 闭源，见《Linux 内核模块与驱动管理》 |
| macOS | 系统更新 | Apple 把驱动收进系统，用户几乎无感 |

<span class="marginnote">Windows 下 NVIDIA 驱动分两版：<strong>Game Ready（游戏就绪）</strong> 针对新游戏优化、更新频繁；<strong>Studio（创作者）</strong> 更稳、面向设计渲染。按用途选，别默认只追「最新」。装错版本导致的显卡崩溃（代码 43）很常见。</span>

**重点：显卡驱动更新的黄金顺序是「干净安装」。** 跨大版本升级显卡驱动前，建议用 DDU（Display Driver Uninstaller）这类工具在安全模式下彻底清除旧驱动，再装新版——直接覆盖安装容易残留冲突，是花屏、黑屏的常见诱因。

## 2 动手：Windows 下给 NVIDIA 显卡装驱动

**第一步：确认显卡型号。** 设备管理器「显示适配器」看型号，或 `Win+R` → `dxdiag`。

**第二步：下载官方驱动。** 去 NVIDIA 官网按「型号 + 系统版本 + 架构」选择下载；或用 GeForce Experience 一键安装。

**第三步：选版本。** 游戏党选 Game Ready，创作者选 Studio。

**第四步：安装。** 运行安装包，选「自定义（高级）」→ 勾选「执行清洁安装」，然后等待完成并重启。

**第五步：验证。** 桌面右键 →「NVIDIA 控制面板」出现即成功；或任务栏通知区出现 NVIDIA 图标。

**Linux 侧补充：** 发行版用户直接用包管理器（`sudo apt install nvidia-driver-535` 或 `sudo dnf install akmod-nvidia`），DKMS 会在内核升级后自动重编模块，别用官网 `.run` 手动装——那是冲突重灾区（详见《Linux 内核模块与驱动管理》）。

## 3 打印机驱动：通用先上，专用后补

打印机是「琐碎外设之王」：品牌型号上千，驱动各自为政，端口（USB/网络/IPP）五花八门。好在现代操作系统都内置了「通用驱动」，让打印机也能「先能用」。<span class="marginnote">Windows 10/11 内置的 <strong>IPP 类驱动程序</strong>能驱动大多数支持网络打印的现代打印机；macOS 的 AirPrint 让同一 Wi-Fi 下的打印机几乎「插电即用」。通用驱动是打印机排障的第一站。</span>

打印机驱动的完整路径：

1. **物理连接**：USB 连接或接同一局域网（Wi-Fi/网线）。
2. **让系统发现**：Windows「设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 添加设备」；macOS「系统设置 → 打印机与扫描仪」。
3. **先用通用驱动**：系统自动安装或选择「通用驱动」，先让打印机能出纸。
4. **再装厂商专用**：需要双面打印、扫描功能时，去打印机官网下载对应型号驱动或官方套件。
5. **测试**：打印测试页确认。

## 4 动手：给一台网络打印机装驱动

**第一步：开打印机。** 确保打印机开机并连入同一网络，记住它的 IP（打印机面板上能查到，或路由器后台）。

**第二步：添加打印机。** Windows「添加设备」搜索，或手动输入打印机 IP 添加。

**第三步：选驱动。** 系统提示选择驱动时，优先选「厂商型号」；列表里没有就选「通用 / IPP」。

**第四步：装专用驱动。** 打印测试成功后再去官网装完整驱动包，解锁双面、扫描。

**第五步：设为默认。** 「设为默认打印机」，完成。

**判断要点：** 打印机「打不出来」先查三件事——电源、网络/连接、默认打印机。八成是物理层问题，不是驱动问题。

## 5 核心对比表：显卡 vs 打印机 vs 其他外设

| 对比项 | 显卡 | 打印机 | 键鼠/摄像头 |
| --- | --- | --- | --- |
| 驱动复杂度 | 高（性能关键） | 中（厂商多样） | 低（通用驱动够） |
| 更新频率 | 高（月更） | 低 | 极低 |
| 通用驱动可用性 | 低（只有基础显示） | 高（IPP/AirPrint） | 极高（即插即用） |
| 排障重点 | 干净安装、版本匹配 | 连接、端口、默认设备 | 供电、接口 |

## 6 速查表：外设驱动的常见坑

| 场景 | 解法 |
| --- | --- |
| 显卡花屏黑屏 | 安全模式 + DDU 干净卸载，重装稳定版 |
| 游戏帧数异常低 | 确认用了独显而非核显，更新 Game Ready 驱动 |
| 打印机离线 | 检查电源、网络、默认端口，重启打印服务 |
| 打印机双面不可用 | 装厂商专用驱动，通用驱动只支持基础打印 |
| 蓝牙设备连不上 | 卸载蓝牙驱动重启，检查蓝牙服务 |
| Linux 下显卡不加速 | `lspci -k` 看驱动是否加载，装厂商 DKMS 驱动 |

## 7 补充速查：外设驱动安装速记表

把三类外设的安装要点收敛成一张速查表：

| 外设 | 通用驱动 | 专用驱动 | 排障要点 |
| --- | --- | --- | --- |
| NVIDIA 显卡 | 基本显示 | Game Ready/Studio | DDU 干净安装 |
| AMD 显卡 | 基本显示 | Adrenalin | 官网下载 |
| Intel 核显 | 系统自带 | 官网/更新 | 装错版本会黑屏 |
| Linux 显卡 | 内核模块 | 包管理器/DKMS | `lspci -k` 查驱动 |
| USB 打印机 | IPP 通用 | 厂商驱动包 | 查端口与默认设备 |
| 网络打印机 | AirPrint/IPP | 官网套件 | 先查网络连通 |
| 蓝牙设备 | 系统驱动 | 厂商工具 | 卸载重装、查服务 |
| 摄像头 | 系统驱动 | 厂商驱动 | 查隐私权限 |

## 8 小结

- 显卡驱动是驱动「重灾区」：**复杂、关键、性能相关**，三平台方式各异。
- NVIDIA 驱动分 **Game Ready / Studio** 两版，按用途选；大版本升级前用 **DDU 干净安装**。
- Linux 装显卡驱动走**包管理器 + DKMS**，别用官网 `.run` 手动装。
- 打印机驱动策略：**通用驱动先能用（IPP/AirPrint），厂商专用后补全功能**。
- 打印机打不出先查**电源、网络、默认设备**，八成不是驱动问题。
- 其他外设（键鼠、摄像头）通用驱动足够，别过度折腾。
