## 为什么从设备管理器开始

Windows 里所有「硬件不工作」的抱怨，最终都会汇聚到同一个窗口——**设备管理器（Device Manager）**。它是 Windows 的「硬件户口本 + 病历本」：列出每一件被系统认识的硬件、它的驱动状态、以及出错时的错误代码。学会读设备管理器，你就掌握了 Windows 驱动排查的入口语言。

本节把它拆开讲：界面怎么看、黄色感叹号代表什么、错误代码怎么翻译、驱动怎么更新/回滚/卸载。它是上一节《驱动程序的类型、来源与安装方式》在 Windows 侧的实战落地。

## 1 认识设备管理器

打开方式：`Win+X` →「设备管理器」，或 `Win+R` 输入 `devmgmt.msc`。窗口按设备类别分组，点开「显示适配器」「网络适配器」等就能看到具体设备。<span class="marginnote">设备管理器里有个隐藏技巧：「查看 → 显示隐藏的设备」能显示已安装但当前未连接的设备（如打印机）。排查「设备去哪了」时先开这个。</span>

每个设备旁可能带有状态图标，含义如下：

| 图标 | 含义 |
| --- | --- |
| 正常图标（设备型号） | 驱动正常，设备工作 |
| 黄色感叹号 ⚠️ | 设备有问题：缺驱动、驱动冲突、被禁用 |
| 向下箭头 ↓ | 设备被手动禁用 |
| 红叉 ✖ | 设备已断开或严重故障 |

**重点：黄色感叹号 = 设备「在户口本上但没办好入职」**——要么没驱动（代码 28），要么驱动异常（代码 43），要么被禁用。它是驱动问题的第一信号灯。

## 2 错误代码速查：Windows 的「诊断黑话」

双击出问题的设备 →「属性」→「常规」标签，能看到一串「错误代码」。这是微软官方的诊断语言，常见的几个：

| 错误代码 | 含义 | 通常解法 |
| --- | --- | --- |
| 代码 28 | 未安装此设备的驱动程序 | 更新驱动 / 官网下载 |
| 代码 43 | 设备已报告问题（常见于显卡） | 回滚驱动、换接口、查硬件 |
| 代码 10 | 设备无法启动 | 重装驱动、检查设备属性 |
| 代码 31 | 设备工作不正常 | 更新驱动或卸载重装 |
| 代码 12 | 无法找到足够可用资源 | 换 PCIe 插槽、检查资源冲突 |
| 代码 22 | 设备已禁用 | 右键「启用设备」 |

<span class="marginnote">代码 43 是最「玄学」的一个：它可能是驱动版本问题，也可能是显卡硬件真的坏了。标准排查顺序：回滚驱动 → 换显示器接口 → 重装系统驱动 → 插拔显卡（断电后）→ 送修。一步步排除，别急着下「硬件坏了」的结论。</span>

## 3 更新、回滚与卸载：驱动管理的三个动作

设备管理器对驱动的核心操作有三个：

- **更新驱动程序**：右键设备 →「更新驱动程序」→「自动搜索驱动程序」，系统联网找并安装更合适的驱动；也可「浏览我的电脑」手动指定驱动文件（INF）。<span class="marginnote">更新驱动「新」不一定「好」。Windows 更新推送的驱动通常经过测试，比官网最新版更稳。跑专业软件（图形设计、建模）时才值得去官网追最新版。稳定优先，是驱动更新的第一原则。</span>
- **回滚驱动程序**：设备 →「属性」→「驱动程序」→「回退驱动程序」。驱动更新后出问题，回滚是最快的后悔药——前提是 Windows 保留了旧版本驱动。
- **卸载设备**：右键「卸载设备」，可勾选「删除此设备的驱动程序软件」。卸载后重启，系统会重新扫描并尝试重装。

**判断要点：** 三动作的先后顺序是「更新 → 回滚 → 卸载」。先给一次更新机会，更新完坏了立刻回滚，卸载是最后手段（卸载后设备会从列表消失，重启后回来）。

## 4 动手：给一台「没网卡」的电脑装驱动

网卡驱动缺失是最常见、也最死循环的场景（没网卡 → 没法联网下驱动）。解法路径：

**第一步：确认问题。** 设备管理器「网络适配器」里看是否有黄色感叹号，或干脆「其他设备」里出现一个未识别的「以太网控制器」。

**第二步：用通用驱动顶上。** 右键 →「更新驱动」→「自动搜索」；不行就「浏览我的电脑 → 让我从计算机上的可用驱动程序列表中选择」，选「Microsoft」下的通用网络驱动——先让网卡「能用」。<span class="marginnote">这一步是破局关键：Windows 自带的通用网卡驱动能驱动绝大多数有线网卡，先联网，再更新厂商专用驱动获得完整功能。</span>

**第三步：联网补专用驱动。** 联网后去「可选更新」或厂商官网下载对应网卡驱动。

**第四步：验证。** 设备管理器无感叹号，「网络适配器」显示正常型号，任务栏网络图标恢复。

## 5 核心对比表：常见驱动故障场景

| 场景 | 错误表现 | 排查优先级 |
| --- | --- | --- |
| 新装系统没网卡 | 代码 28 / 未识别设备 | 通用驱动顶上 → 厂商驱动 |
| 显卡黑屏花屏 | 代码 43 | 回滚 → 换接口 → 重装 |
| 声卡无声 | 感叹号/无输出设备 | 更新驱动 → 检查默认设备 |
| 蓝牙连不上 | 蓝牙适配器感叹号 | 卸载重装 → 检查服务 |
| 打印机不认 | 代码 28 / 无端口 | 官网下载 → 检查端口 |

## 6 速查表：设备管理器常用入口

| 操作 | 路径/命令 |
| --- | --- |
| 打开设备管理器 | `Win+X` → 设备管理器，或 `devmgmt.msc` |
| 查看隐藏设备 | 查看 → 显示隐藏的设备 |
| 更新驱动 | 右键设备 → 更新驱动程序 → 自动搜索 |
| 回滚驱动 | 属性 → 驱动程序 → 回退驱动程序 |
| 卸载驱动 | 右键设备 → 卸载设备（可勾选删除驱动软件） |
| 查看硬件 ID | 属性 → 详细信息 → 硬件 ID |
| 强制重装驱动 | 卸载设备 → 重启 → 自动重装 |

**补充：** 「硬件 ID」是找驱动的终极线索——把 `VEN_8086&DEV_153B` 这类字符串复制到搜索引擎，能直接定位到设备型号与驱动。

| 代码 | 含义 | 首选解法 |

| 代码 10 | 设备无法启动 | 更新驱动、查资源 |

| 代码 22 | 设备已禁用 | 右键「启用设备」 |
| 代码 28 | 未安装驱动 | 更新驱动 / 官网下载 |
| 代码 31 | 驱动工作不正常 | 卸载重装 |

| 代码 56 | 设备未被授权 | 检查组策略/BIOS |

## 8 小结

- 设备管理器是 Windows 的**硬件户口本 + 病历本**，黄色感叹号 = 驱动有问题。
- **错误代码**是官方诊断语言：代码 28 没驱动、代码 43 设备报告问题、代码 10 无法启动。
- 驱动三动作：**更新 → 回滚 → 卸载**，先给更新机会，坏了回滚，卸载最后。
- 「没网卡」破局：先用 Windows 通用网卡驱动联网，再补厂商专用驱动。
- **硬件 ID**（如 `VEN_8086&DEV_153B`）是找驱动的终极线索。
- 稳定优先于「最新」，Windows 更新推送的驱动通常够用且更稳。
