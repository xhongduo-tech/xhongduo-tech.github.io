## 为什么从 Windows 介质开始

上一节讲清了引导模式的原理：UEFI 需要「FAT32 + 引导文件」的启动盘。现在把它落到 Windows 上。绝大多数 Windows 用户的第一场「装机实战」，就是从做启动 U 盘开始的——重装、刷机、给新电脑装系统，都绕不开「一个能启动的 U 盘」。

微软官方把这件工具叫**媒体创建工具（Media Creation Tool）**，它支持一条龙完成「下载最新版 Windows + 写入 U 盘」。本节围绕它展开，同时介绍常用的第三方工具（Rufus、Ventoy），让你既能用官方方案「稳」，也能用第三方方案「快」。

## 1 微软官方媒体创建工具：最省心的选择

微软官方支持文档提供的标准做法：从微软官网下载「媒体创建工具」，运行后选「为另一台电脑创建安装介质」，再选语言、版本和架构（x64），最后选「U 盘」作为介质，工具就会自动完成下载与写入。<span class="marginnote">官方工具的优点是版本永远最新、自带微软数字签名，不会被安全软件误报；缺点是下载速度受微软服务器影响，且「只能写最新版 Windows」，无法指定历史版本（如 Windows 10 22H2）。</span>

使用时的两个要点：

- **U 盘容量 ≥ 8 GB**，数据会被清空——插入前先确认里面没有重要文件。
- 若只是给**当前这台电脑**装系统，也可以选「保存到 ISO 文件」，得到 `Win11_..._x64.iso`，之后挂载或写盘都行。

## 2 三种工具该怎么选

第三方工具里，**Rufus** 与 **Ventoy** 是最常见的两个。Rufus 轻量、免费、开源，写盘速度快，还能额外设置分区类型（GPT/UEFI 或 MBR/Legacy）；Ventoy 则是「一次制作、终身拷贝 ISO」的启动盘。<span class="marginnote">Rufus 的「分区类型」下拉框对应上一节的配对关系：新电脑选 GPT，老电脑（纯 Legacy BIOS）选 MBR。选错最容易表现为「U 盘启动不了」或「安装时报引导模式错误」。</span>

三种方案对照：

| 方案 | 优点 | 缺点 | 适用 |
| --- | --- | --- | --- |
| 微软媒体创建工具 | 官方、最新版、免设置 | 只能最新版、下载较慢 | 新手首选 |
| Rufus | 快、可选 GPT/MBR、开源 | 需自行下载 ISO | 需要指定版本/模式 |
| Ventoy | 一 U 盘多系统 | 首次制作略繁琐 | 常装系统的人 |

## 3 动手：用媒体创建工具做 U 盘启动盘

官方流程大约五步，全图形界面：

**第一步：准备。** 一台联网 Windows 电脑 + 一只 ≥8 GB 的 U 盘（建议 USB 3.0，快很多）。

**第二步：下载运行工具。** 打开微软官网「下载 Windows」页面，下载「媒体创建工具」并运行，接受许可条款。

**第三步：选「为另一台电脑创建安装介质」。** 默认会自动匹配「语言 + 版本 + 架构」；想要 x86 版或指定语言，取消勾选「使用推荐的选项」手动选。

**第四步：选择 U 盘。** 插入 U 盘 → 选「U 盘」→ 在下拉框里选到它（注意别选错盘，工具会清空）→ 开始下载写入。此步骤通常耗时 15–40 分钟，取决于网速与 U 盘速度。<span class="marginnote">「下一步」之后工具会提示「此 U 盘上的文件将被删除」。这是 U 盘启动盘唯一不可逆的环节——写之前务必把 U 盘里想留的东西拷走。</span>

**第五步：完成并验证。** 完成后安全弹出 U 盘。验证方法：重启进 BIOS 启动菜单（Del/F2/F10/F12 视主板而定），把 U 盘设为第一启动项，能看到 Windows 的蓝色徽标即成功。

## 4 扩展：用 Rufus 把已有 ISO 写进 U 盘

当你手头已经有一个 `.iso` 镜像（比如从官方渠道下载的旧版本），用 Rufus 更直接：

1. 打开 Rufus，选 U 盘设备。
2. 「引导类型选择」里点「选择」，指定 `.iso` 文件。
3. 「分区类型」按目标电脑选 GPT（UEFI）或 MBR（Legacy）。
4. 点「开始」，等进度走完。

Rufus 还能处理「U 盘容量不足 4 GB 镜像放不下 FAT32」的问题——它会智能地把镜像分成 FAT32 可容纳的结构，无需你操心 4 GiB 单文件上限。<span class="marginnote">Windows 官方 ISO 里的 `install.wim`/`install.esd` 常常超过 4 GiB，直接拷进 FAT32 会失败。Rufus 默认会把它拆成 `install.swm` 分段存放，安装器仍能正常读取——这是「整盘写入」优于「文件复制」的又一个证据。</span>

## 5 易错点：写盘后的排查清单

U 盘做完却不启动，按下面顺序排查：

- **引导模式不匹配**：U 盘是 GPT（UEFI）做的，电脑却是 Legacy BIOS，或反之 → 重做 U 盘或改固件设置。
- **没进启动菜单**：开机时按的键不对。常见的是 F12（戴尔、联想）、F10（惠普）、F2/Delete（进 BIOS 后改启动顺序）。
- **U 盘没被识别**：插到主板后置 USB 接口试试，前置口供电/兼容性问题常见。
- **Secure Boot 拦住了 U 盘**：个别主板默认开启 Secure Boot 且无签名白名单外的项，可临时在 BIOS 里关掉，装完再开。

**判断要点：** 排查顺序永远是「介质 → 引导模式 → 固件设置」，不要一上来就怀疑 U 盘坏了。Windows 官方 ISO 的 SHA-256 校验值在微软官网公布，怀疑下载损坏时可以先 `certutil -hashfile xxx.iso SHA256` 对比一下。

## 6 补充速查：Windows 安装介质全流程

把本节要点收敛成一张可照做的流程表，从准备到验证一次通关：

| 环节 | 操作 | 要点 |
| --- | --- | --- |
| 准备 U 盘 | ≥8 GB，建议 USB 3.0 | 数据会被清空，先拷走 |
| 获取工具 | 微软官网「媒体创建工具」 | 认准官方，别下第三方 |
| 选版本 | 默认推荐或手动选 | 语言 + x64 + 版本 |
| 选介质 | U 盘 / ISO 文件 | 只为本机可选 ISO |
| 写入 | 工具自动下载写入 | 耗时 15–40 分钟 |
| 验证 | 启动菜单选 U 盘 | 看到蓝色徽标即成功 |
| 分区类型 | 新机 GPT / 老机 MBR | 与固件模式匹配 |
| Secure Boot | 装不了就临时关闭 | 装完记得开回来 |
| 指定旧版本 | 用 Rufus + 已有 ISO | 官方工具只写最新版 |
| 一 U 盘多系统 | 用 Ventoy | 之后拷 ISO 即可 |
| 大文件超限 | 工具自动分段 | FAT32 单文件上限 4 GiB |
| 下载太慢 | 换时段或镜像源 | 别用破解版工具 |
| 校验完整性 | `certutil -hashfile` 比对 SHA-256 | 微软官网公布哈希值 |
| 启动失败排查 | 介质 → 引导模式 → 固件设置 | 别急着怪 U 盘 |

## 7 补充速查：U 盘启动失败排查

U 盘做好了却启动不了，按这张表逐项排除：

| 检查项 | 说明 |
| --- | --- |
| 引导模式 | U 盘分区类型与电脑固件是否匹配 |
| 启动按键 | 是否按对 F12/F10/F2 |
| 接口 | 换后置 USB 口试试 |
| Secure Boot | 是否拦截了 U 盘引导器 |
| 文件系统 | 是否为 FAT32 |
| 镜像完整性 | SHA-256 是否匹配官网 |
| 写入方式 | 是否整盘写入而非解压复制 |

## 8 小结

- 微软官方**媒体创建工具**负责「下载最新版 + 写盘」一条龙，是新手首选。
- U 盘要求：**≥8 GB、数据会清空、建议 USB 3.0**。
- **Rufus** 适合指定 ISO/分区模式；**Ventoy** 适合一 U 盘多系统。
- 分区类型选择与目标电脑匹配：**新机 GPT/UEFI，老机 MBR/Legacy**。
- Windows ISO 内大文件超过 FAT32 的 4 GiB 上限，需工具分段处理，不能直接复制。
- 启动失败按「介质 → 引导模式 → 固件设置」顺序排查。
