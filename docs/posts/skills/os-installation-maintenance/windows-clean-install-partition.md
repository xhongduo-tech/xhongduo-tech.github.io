## 为什么从「全新安装」开始

上一节做出了启动 U 盘，这一节把它用起来。**全新安装（clean install）**指把磁盘上原有系统连同分区一起清掉，装一个崭新的 Windows——它是三平台安装中最「暴力」也最「彻底」的方式：没有旧系统残留、没有驱动冲突、没有注册表垃圾，是解决「电脑越用越慢」「中毒后系统千疮百孔」这类问题的终极大招。

代价也明确：磁盘上的一切都会被清除。所以本节开头必须重申上一节的规矩——**数据先备份**。本节以「自定义（高级）安装」为主线，把 Windows 安装器自己会创建哪些分区讲清楚，并给出分区选择的原则。

## 1 从 U 盘启动：走进安装界面

插上启动 U 盘，重启进入固件启动菜单（F12/F10/F2/Delete 视主板而定），选 U 盘启动。随后屏幕出现 Windows 蓝色徽标，进入安装程序的第一屏：**语言、时间和键盘**选择。完成基础选择后点「下一步」→「现在安装」，输入产品密钥（可以后跳过），接受许可条款，来到最关键的一屏。

这一屏有两个按钮：

- **升级安装（Upgrade）**：保留文件、设置和应用程序，在原系统之上更新——它不是本节要讲的。
- **自定义安装（Custom / Advanced）**：仅安装 Windows，可让你选择把系统装到哪个分区——**全新安装走这里**。<span class="marginnote">选择「自定义」之前，安装程序会再次弹窗警告「磁盘上的所有文件将被删除」。这是全新安装最后的确认关口，只有当你已做好备份时才点继续。</span>

## 2 安装类型对比：两种选择一次看清

| 对比项 | 升级安装 | 自定义（全新）安装 |
| --- | --- | --- |
| 保留个人文件 | 保留 | 不保留（除非手动选对分区） |
| 保留应用程序 | 保留 | 不保留 |
| 保留设置 | 保留 | 不保留 |
| 适用场景 | 大版本更新、修复异常 | 换盘、清病毒、系统重获新生 |
| 风险 | 旧问题可能残留 | 误删数据的风险最高 |

**判断要点：** 想「保留个人文件的重装」其实有更好的路径（见下一节《Windows 重装与保留个人文件》），真正的全新安装就把「清空重来」贯彻到底，不要中途犹豫。

## 3 Windows 自动生成的系统分区

进入「自定义」界面后，你会看到磁盘的现有分区，也可能是一片「未分配空间」。安装器在全新磁盘上会自动创建一组分区，这是理解 Windows 引导的关键：

| 分区 | 类型 | 大小（典型） | 作用 |
| --- | --- | --- | --- |
| EFI 系统分区（ESP） | FAT32 | 100 MB | 存放 UEFI 引导文件 |
| MSR（Microsoft Reserved） | 无文件系统 | 16 MB | 微软保留，供系统内部使用 |
| 主分区（C:） | NTFS | 剩余容量 | 系统与数据 |
| 恢复分区（Windows RE） | NTFS | 500–750 MB | 存放恢复环境 WinRE |

<span class="marginnote">这组分区对应本专题《磁盘分区基础》讲过的结构：ESP 是 UEFI 引导的「入口」，恢复分区是「重置此电脑」与「高级启动」的根基。它们共同的特点是——<strong>不要手动删除</strong>，删除任意一个都可能让 Windows 无法启动或无法恢复。</span>

如果你选择的是 Legacy/MBR 模式，安装器会创建「系统保留（System Reserved）」分区替代 ESP+MSR，大小约 500 MB，作用相同。

## 4 全新安装时的分区选择原则

在「自定义」界面里，你的操作对象是**磁盘上的分区**，常用的三个动作：

- **新建（New）**：在未分配空间上创建分区。先在「大小」里填你想分给系统的容量（如 120 GB），点「应用」。
- **格式化（Format）**：把已有分区格式化为 NTFS，清空内容。
- **删除（Delete）**：删除分区回到未分配空间。删除前 Windows 会反复确认——因为删除即释放，恢复极难。

**重点：Windows 全新安装的标准做法是「删干净再装」。** 把旧系统的所有分区全部删除，得到一整块「未分配空间」，再点「新建」让它自己重新生成那组系统分区，最后把主分区选中，点「下一步」。这样装出来的系统最干净，也不会有「ESP 在另一块盘上」这类历史遗留问题。<span class="marginnote">如果电脑里有两块硬盘，安装器会让你选择「把 Windows 安装到哪块磁盘」。原则是：<strong>系统装在哪块盘，引导分区就跟着在哪块盘</strong>，别让系统和 ESP 分居两块盘，否则拔掉某块盘就可能无法开机。</span>

## 5 动手：一次完整的全新安装

把上面的原则走成一条可执行路径：

**第一步：备份。** 磁盘上的照片、文档、密钥全部按 3-2-1 原则备份好。

**第二步：启动 U 盘。** 进固件启动菜单，选 U 盘，进入安装程序。

**第三步：选「自定义」。** 在「你想进行哪种类型的安装」一屏选「自定义（高级）」。

**第四步：清理分区。** 选中系统盘上所有旧分区，逐个「删除」，直到变成一整块「未分配空间」。

**第五步：新建分区。** 点「新建」，输入系统分区大小（建议 ≥120 GB），「应用」；安装器自动补建 ESP、MSR、恢复分区。

**第六步：安装。** 选中刚建好的主分区，点「下一步」，开始复制文件并自动重启。重启后进入「开箱（OOBE）」设置：微软账号登录、个性化、隐私选项。

**第七步：取走 U 盘。** 全程完成后，Windows 会显示登录界面即成功。

## 6 易错点：全新安装的三个坑

- **把 U 盘当成目标盘**：安装器列表里出现多个磁盘时，先核对「型号 + 容量」再动手，别把启动 U 盘当成系统盘「删除」了。
- **只删 C 盘不删其他分区**：老系统盘里常有「系统保留」「恢复分区」散落各处，只删主分区会导致引导结构混乱，要整盘删干净。
- **装完进不了系统**：多半是引导模式与磁盘格式不匹配（UEFI 装了 MBR），回到《BIOS/UEFI 引导模式与启动介质制作》检查配对关系。

## 7 补充速查：Windows 全新安装要点表

把「全新安装」的每个动作与要点列成一张执行表：

| 动作 | 操作 | 要点 |
| --- | --- | --- |
| 备份 | 3-2-1 原则 | 先备份再动手 |
| 启动 U 盘 | 进固件启动菜单 | F12/F10/F2 看主板 |
| 语言选择 | 中文/键盘布局 | 装后可改 |
| 产品密钥 | 可跳过 | 装完再激活 |
| 安装类型 | 选「自定义（高级）」 | 全新安装走这里 |
| 删除旧分区 | 逐个删除 | 别误删其他磁盘 |
| 新建分区 | 输入系统盘大小 | 建议 ≥120 GB |
| 确认目标盘 | 核对型号+容量 | 别选成 U 盘 |
| 系统分区 | 安装器自动建 | ESP/MSR/恢复分区别删 |
| 安装过程 | 多次重启 | 别拔 U 盘 |
| OOBE 设置 | 账号、隐私 | 微软账号登录 |
| 收尾 | 弹出 U 盘 | 改回硬盘启动 |

## 8 小结

- **全新安装** = 清掉所有分区装新系统，解决「越用越慢」「系统中毒」最彻底。
- 安装器会自动创建 **ESP + MSR + 主分区 + 恢复分区** 四个分区，一律不要手动删。
- 标准流程：**备份 → 启动 U 盘 → 自定义 → 删分区 → 新建 → 下一步**。
- 系统与 ESP 引导分区必须在**同一块盘**。
- 多盘环境下先核对「型号 + 容量」再选择目标盘。
- 引导模式（UEFI/Legacy）必须与磁盘格式（GPT/MBR）匹配。
