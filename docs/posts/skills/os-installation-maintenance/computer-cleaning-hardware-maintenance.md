## 为什么从除尘开始

前面几节都是「软件层」的维护，这一节回到**物理世界**。电脑性能再好，散热不行也白搭——灰尘堆积会让风扇转速飙升、温度居高不下，触发降频、死机、甚至烧毁硬件。**除尘**是成本最低、回报最直接的硬件保养：一把螺丝刀 + 一台鼓风机，就能让「风扇狂转的老电脑」恢复安静凉爽。

《国家职业技能标准·计算机维修工》把「整机清洁与维护」列为基本技能。本节从「灰尘为什么有害」讲起，到「温度的科学」、再到「一次标准除尘实操」，把硬件保养的里子讲透。

## 1 灰尘是电脑的慢性杀手

灰尘为什么致命？它不直接「堵死」电脑，而是通过两个机制慢性伤害：

- **隔热**：灰尘附着在散热鳍片、风扇叶片上，等于给散热器穿了件棉袄，热量散不出去。
- **积热**：温度升高 → 风扇加速 → 吸入更多灰尘 → 温度更高，形成恶性循环。

典型后果：开机风扇狂转、游戏帧数骤降（降频保护）、频繁蓝屏重启、硬件提前老化。<span class="marginnote">温度每升高约 10°C，电子元件老化速度大致翻倍（阿伦尼乌斯定律的经验直觉）。所以「电脑热一点没事」是错的——长期高温是硬件寿命的头号杀手。这也是为什么服务器机房必须常年空调恒温。</span>

## 2 温度与散热的科学

先理解散热系统的构成：CPU/GPU 发热 → 导热硅脂把热量传给散热器底座 → 热管/鳍片把热量分散 → 风扇把热风吹出机箱。任何一个环节被灰尘/老化破坏，整条链路就失效。

| 部件 | 常见健康温度范围 | 高温后果 |
| --- | --- | --- |
| CPU | 待机 35–50°C，满载 <90°C | 降频、重启、烧毁 |
| GPU | 待机 35–55°C，满载 <85°C | 花屏、驱动崩溃、烧毁 |
| 硬盘（HDD） | 30–45°C | 加速坏道 |
| SSD | 30–65°C | 过热降速 |

**重点：温度监控是硬件保养的眼睛。** Windows 用 HWMonitor、Linux 用 `sensors` 命令看 CPU/GPU 温度，macOS 用第三方工具或直接摸机壳。发现「待机就 70°C」，就该除尘换硅脂了。<span class="marginnote">Linux 查看温度：`sudo apt install lm-sensors && sensors`，能列出 CPU 与主板温度。Windows 的 HWMonitor 能同时看 CPU、GPU、硬盘温度与风扇转速，是除尘前后的「前后对比仪」。</span>

## 3 除尘实操：安全第一，工具第二

除尘前先立规矩——**断电、防静电、温柔**：

| 工具 | 作用 |
| --- | --- |
| 十字螺丝刀 | 开侧板、拆散热器 |
| 鼓风机/皮老虎 | 吹走灰尘（**别用吸尘器，静电可能击穿芯片**） |
| 软毛刷 | 刷掉顽固积灰 |
| 防静电手环（可选） | 释放静电，保护芯片 |
| 硅脂 + 酒精棉片 | 换导热硅脂 |

安全要点三条：

- **完全断电**：拔电源线，并长按电源键几秒放掉主板残余电荷。
- **别用吸尘器**：吸尘器会产生静电与吸力，可能损坏芯片或吸掉细小元件。
- **温柔操作**：风扇、主板、显卡别用力扳，卡扣要对位。

## 4 硅脂：导热的关键

**导热硅脂（thermal paste）** 是 CPU/GPU 与散热器之间的导热介质，填补两者接触面的微小缝隙。用久后会干裂、变硬，导热能力大幅下降——所以「散热变差」时，除了除尘还要换硅脂。<span class="marginnote">涂硅脂的经典方法：「绿豆大小」挤在 CPU 中心，散热器压上去后自然摊平，无需手工抹平。硅脂涂太多反而会溢到基板、影响导电（要选非导电型）。拆散热器后记得清洁干净再涂新硅脂。</span>

判断「该换硅脂了吗」：温度长期偏高、散热器拆下来硅脂已干裂发白，就换。

## 5 日常保养清单

把保养变成习惯，按周期执行：

| 周期 | 保养动作 |
| --- | --- |
| 每周 | 清理桌面灰尘、保持通风 |
| 每月 | 系统清理 + 检查温度 |
| 每 3–6 个月 | 拆机除尘 |
| 每 1–2 年 | 换硅脂 |
| 长期 | 环境湿度控制、防尘罩、注意雷雨天 |

## 6 动手：一次完整的台式机除尘

**第一步：断电开箱。** 关机、拔电源线、长按电源键放电，用螺丝刀开侧板。

**第二步：粗除尘。** 用鼓风机从机箱内向外吹，重点吹电源风扇、CPU 散热器、显卡风扇。

**第三步：细清理。** 软毛刷清理鳍片缝隙与风扇叶片上的顽固积灰。

**第四步：换硅脂（可选）。** 拆下 CPU 散热器，酒精棉片清掉旧硅脂，涂绿豆大的新硅脂，装回散热器。

**第五步：装回通电。** 盖侧板、接电源、开机，用 `sensors`/HWMonitor 对比除尘前后的温度。

**第六步：观察。** 风扇转速下降、温度降低 10–20°C 即成功。

## 9 小结

- 灰尘通过**隔热 + 积热**两机制伤害硬件，导致降频、蓝屏、老化加速。
- 散热链路：**硅脂 → 散热器 → 风扇**，任一环节失效整条就瘫。
- 温度监控是保养的眼睛：待机温度异常偏高就该除尘换硅脂。
- 除尘三原则：**断电、别用吸尘器、温柔操作**。
- **硅脂**干裂是散热变差的主因，绿豆大小涂法 + 每 1–2 年更换。
- 保养节奏：**每 3–6 个月除尘、每 1–2 年换硅脂**，除尘后温度应降 10–20°C。
