## 为什么从「保留文件的重装」开始

上一节的「全新安装」是伤筋动骨——删光一切从头再来。但现实中更多人的诉求是：**系统坏了想重装，又不想丢照片、文档和软件设置**。微软为此准备了一套「有层次的解决方案」：从「重置此电脑」到「保留我的文件」再到「升级安装」，疼痛程度和保留程度各不相同。

本节把这套方案讲透：什么时候用「保留我的文件」，什么时候「删除所有内容」，云端下载和本地重装怎么选。理解这些选项，你就能在「重装系统」和「数据安全」之间找到最省心的平衡点。

## 1 重置此电脑：微软的「傻瓜重装」

**重置此电脑（Reset this PC）** 是微软在 Windows 10/11 里内置的重装工具，相当于「系统内自带的恢复出厂」。入口：设置 → 系统 → 恢复 → 「重置此电脑」→「开始」。

它的原理不是清盘重装，而是**基于系统自带或下载的镜像重新安装 Windows**，并在安装过程中决定保留或删除你的个人文件。它的最大价值是：不需要启动 U 盘、不需要 BIOS 操作，在系统还能进桌面时点几下就能「重装」一遍。<span class="marginnote">重置此电脑的恢复分区是「系统保留区（WinRE）」提供的，这就是上一节说「恢复分区不能删」的原因——删了它，重置此电脑和高级启动就都失灵了。</span>

## 2 三种重置选项对比

点「开始」后会遇到第一个选择，它决定了你的数据去留：

| 选项 | 保留个人文件 | 保留应用 | 适用场景 |
| --- | --- | --- | --- |
| 保留我的文件 | 保留 | 不保留 | 系统异常但文件要留 |
| 删除所有内容 | 不保留 | 不保留 | 送修、出售、彻底清盘 |
| 还原设置 | 保留 | 视选项而定 | 只恢复系统设置 |

**重点：选「保留我的文件」≠ 万事大吉。** 它保留的是「个人文件」，但**你安装的桌面软件全部会被移除**，软件设置也会被重置。所以即使是这条「温和」路径，重装前也值得把浏览器书签、密钥、重要文档再做一次备份——多留一手总没错。<span class="marginnote">「保留我的文件」其实还会把部分东西移到 `Windows.old` 目录，方便你事后找回。但 `Windows.old` 会在 10 天后自动清理，需要的东西务必尽早抢救。</span>

## 3 云端下载 vs 本地重新安装

选完文件去留，还会遇到第二个选择：**如何获取 Windows**。

- **云下载（Cloud download）**：从微软服务器下载最新版 Windows 再安装。需要联网，但能顺便把系统更新到最新，也能绕开本机镜像损坏的问题。
- **本地重新安装（Local reinstall）**：使用本机现有恢复镜像重新安装，不消耗流量、更快，但如果本机镜像本身有问题，装完可能还是带病。

| 对比项 | 云下载 | 本地重新安装 |
| --- | --- | --- |
| 网络 | 需要（数 GB 流量） | 不需要 |
| 版本 | 最新 | 本机镜像版本 |
| 耗时 | 较长 | 较快 |
| 适用 | 镜像损坏、想升最新 | 网速慢、只想重置 |

**判断要点：** 电脑能正常上网且不心疼流量，选云下载通常更省心；离线环境或网速很慢，选本地重装。

## 4 升级安装：保留应用与文件的第三条路

当你想保留**软件**而不只是文件时，「重置此电脑」就不够用了。此时可以走**升级安装（Repair install / In-place upgrade）**：用 Windows 安装介质（ISO 或 U 盘）在现有系统上「再安装一遍」，系统会检测到已有 Windows，默认保留文件、应用和设置，修复系统组件。它常被用来「不动应用救系统」。<span class="marginnote">升级安装的典型用法：把 `Win11.iso` 挂载后运行 `setup.exe`，选「保留个人文件和应用」。它对「系统文件损坏但不想重装软件」的场景几乎是唯一不折腾的办法。</span>

## 5 动手：用「保留我的文件」重装

**第一步：备份关键数据。** 文档、照片、书签、密钥各备份一份，别全押在「保留我的文件」上。

**第二步：打开重置。** 设置 → 系统 → 恢复 → 「重置此电脑」→「开始」。

**第三步：选「保留我的文件」。**

**第四步：选安装方式。** 按第3节判断选「云下载」或「本地重新安装」。

**第五步：确认并等待。** 系统会给出将删除应用的清单，确认后进入「正在重置」流程，期间电脑会多次重启，耗时约 30–60 分钟。

**第六步：重装后收拾。** 登录后用 Windows 更新补驱动，重新安装需要的软件，从备份恢复书签与密钥。

## 6 易错点：保留文件的三个误区

- **以为「保留我的文件」= 保留一切**：应用、系统设置都会被清，只有个人文件保留。
- **以为重置后不需要备份**：重置过程本身有风险（断电、镜像损坏），且软件全部消失，备份是双保险。
- **恢复分区被删导致无路可退**：没有 WinRE 时「重置此电脑」按钮会变灰，只能借助 U 盘进入安装器修复。

## 7 补充速查：重置此电脑选项全对照

把「重置此电脑」的每个选择点列成表，到界面时不慌：

| 选择点 | 选项 | 保留什么 | 适合谁 |
| --- | --- | --- | --- |
| 文件去留 | 保留我的文件 | 个人文件 | 系统异常但文件要留 |
| 文件去留 | 删除所有内容 | 什么都不留 | 送修、出售、彻底清盘 |
| 文件去留 | 还原设置 | 个人文件 | 只想重置系统设置 |
| 获取方式 | 云下载 | 最新版 Windows | 网速快、想升最新 |
| 获取方式 | 本地重新安装 | 本机镜像版本 | 离线、网速慢 |
| 额外选项 | 更改设置 | 可关闭数据擦除 | 隐私需求高 |
| 预判结果 | 显示待删应用清单 | 应用会被清 | 确认后再继续 |
| 替代方案 | 升级安装（setup.exe） | 应用 + 文件 + 设置 | 想保留软件 |
| 前置条件 | WinRE 恢复分区完好 | — | 没有就无法重置 |

## 8 补充速查：重装前备份清单

不管选哪种重装方式，重装前把下面几项备份做齐，心里才有底：

| 备份项 | 怎么备 | 常见遗漏 |
| --- | --- | --- |
| 个人文档 | 拷到移动硬盘/云盘 | 桌面堆的文件 |
| 浏览器书签密码 | 浏览器同步或导出 | 收藏的网址 |
| 微信聊天记录 | 客户端内备份/迁移 | 本地记录 |
| 密钥与凭证 | 导出到离线安全处 | 2FA 恢复码 |
| 开发配置 | dotfiles 入库 | `.ssh`、`.gitconfig` |
| 磁盘恢复密钥 | 抄写或导出 | BitLocker 密钥 |
| 邮件归档 | 客户端导出 | 本地邮箱 |

## 9 小结

- **重置此电脑**是系统内自带的重装工具，无需 U 盘即可「重装」。
- 三种选项：**保留我的文件 / 删除所有内容 / 还原设置**，保留程度逐级递减。
- 「保留我的文件」只保文件，**应用和设置会被清**，备份不能省。
- **云下载**取最新版但费流量；**本地重新安装**快但受本机镜像质量影响。
- **升级安装**（运行 `setup.exe` 保留应用和文件）是「不动软件救系统」的第三条路。
- 恢复分区（WinRE）是重置此电脑的地基，删了它就没有「傻瓜重装」。
