## 为什么从启动故障开始

Mac 一向以稳定著称，但「启动故障」仍然会发生：转菊花卡住、启动到一半重启、出现「问号文件夹」图标、或直接黑屏。好在 macOS 的排障体系非常「Apple 化」——它把大部分修复都收进**恢复模式 + 磁盘工具**，普通用户按提示点几下就能解决大部分问题。

本节把 macOS 启动故障的诊断路径讲清：先看故障图标（问号文件夹、禁止符号、转菊花），再讲磁盘工具急救（First Aid）、安全模式、启动磁盘与重置 NVRAM/SMC，最后给出一条完整的排障流程。

## 1 读懂启动故障的「图标语言」

macOS 开机出问题时会显示特定图标，每种图标都「说了话」：

| 图标 | 含义 | 处理方向 |
| --- | --- | --- |
| 问号文件夹 ❓ | 找不到启动磁盘/系统 | 选启动磁盘、检查系统宗卷 |
| 禁止符号 🚫 | 系统版本与硬件不兼容 | 换兼容版本或检查硬件 |
| 转菊花无限转 | 系统或磁盘异常 | 磁盘工具急救、安全模式 |
| 黑屏/无画面 | 硬件或显示器问题 | 重置 NVRAM、检查外接屏 |
| 启动到一半重启 | 系统或内核异常 | 安全模式、磁盘急救、重装 |

<span class="marginnote">「问号文件夹」最常见：它表示「找不到可启动的系统」。多在「重装时误抹掉系统宗卷」「换了系统盘没装系统」时出现。解法是按住 `Option` 手动选启动磁盘，或在恢复模式里重装系统。</span>

## 2 磁盘工具急救：First Aid

**磁盘工具急救（First Aid）** 是 macOS 的「磁盘体检 + 修复」，对应 Windows 的 `chkdsk`。它检查磁盘结构、修复损坏的目录/宗卷元数据。操作路径：恢复模式 → 磁盘工具 → 选中宗卷/容器 → 点「急救」→「运行」。<span class="marginnote">急救可以「在线跑」（系统里打开磁盘工具对非系统宗卷急救），但系统盘（Macintosh HD）在正常系统运行时无法急救，必须进恢复模式。转菊花卡死、文件突然丢失、系统越来越怪，先跑一遍急救准没错。</span>

**重点：急救的定位是「修复元数据，不是修硬件」。** 它解决「磁盘结构逻辑损坏」；若是物理坏道或硬件故障，急救会报错，此时需要检查硬件（对应《硬盘健康检测与坏道排查》）。

## 3 安全模式与启动组合键

macOS 的**安全模式**（对应 Windows 安全模式）：开机按住 **Shift**，进入后系统只加载最小内核扩展、不加载登录项，还能自动运行「启动磁盘检查」。进安全模式能修复「启动异常」并在重启后恢复正常启动。

常用启动组合键汇总：

| 组合键 | 作用 |
| --- | --- |
| `Command-R` | 进入恢复模式 |
| `Option-Command-R` | 网络恢复 |
| `Option` | 启动管理器（选启动磁盘） |
| `Shift` | 安全模式 |
| `Command-Option-P-R` | 重置 NVRAM（Intel Mac） |

<span class="marginnote"><strong>重置 NVRAM/PRAM</strong>（`Command-Option-P-R`）能解决一类「启动怪症」：音量/分辨率异常、启动磁盘设置错乱、开机会卡在某一步。Apple Silicon 的 Mac 没有这个组合键，但重置方式不同——关机后长按电源键进入启动选项，再用「选项」进恢复模式。NVRAM 相当于 Mac 的「小 BIOS 设置」。</span>

## 4 启动磁盘：让 Mac 找到正确的「家」

macOS 支持多系统/多磁盘，若启动磁盘指向了错误的对象，就会「找不到系统」。修复方式：

- **系统设置 → 通用 → 启动磁盘**：选中正确的系统宗卷，点「重新启动」。
- **按住 `Option` 开机**：进入启动管理器，手动选启动磁盘（临时生效，重启后恢复默认）。

**判断要点：** 「问号文件夹」出现时，先按住 `Option` 看能否手动选到系统宗卷；能选到 → 设置启动磁盘；选不到 → 系统宗卷可能损坏，进恢复模式跑急救或重装。

## 5 动手：一次完整的 macOS 排障

**第一步：识别图标。** 按第1节判断问题类型。

**第二步：进恢复模式。** `Command-R`（或 Apple Silicon 按住电源键）进入。

**第三步：跑急救。** 磁盘工具 → 选系统宗卷 → 急救。修复失败会提示原因。

**第四步：安全模式验证。** 重启按住 Shift，若能进系统 → 问题在第三方扩展/登录项，排查并清理。

**第五步：重装系统（最后手段）。** 恢复模式 → 重新安装 macOS，一般不会动个人文件（系统宗卷重装，数据宗卷保留）。

## 6 速查表：macOS 排障速记

| 场景 | 动作 |
| --- | --- |
| 问号文件夹 | 恢复模式重装 / 选启动磁盘 |
| 转菊花卡住 | 磁盘工具急救 → 安全模式 |
| 进安全模式 | 开机按住 Shift |
| 进恢复模式 | 开机按住 `Command-R` |
| 选启动磁盘 | 开机按住 Option |
| 重置 NVRAM | 开机按住 `Command-Option-P-R`（Intel） |
| 检查系统健康 | 系统信息 → 存储 |

## 7 补充速查：macOS 排障动作清单

把故障表现与对应动作汇总成一张执行表：

| 故障表现 | 第一步 | 第二步 | 最后手段 |
| --- | --- | --- | --- |
| 问号文件夹 | `Option` 选启动盘 | 设置启动磁盘 | 恢复模式重装 |
| 转菊花卡住 | 磁盘工具急救 | 安全模式 | 重装系统 |
| 启动到一半重启 | 安全模式（Shift） | 磁盘急救 | 重装系统 |
| 黑屏无画面 | 重置 NVRAM | 检查外接屏/线 | 硬件检测 |
| 禁止符号 | 确认系统版本 | 查硬件兼容 | 换兼容版本 |
| 系统越来越怪 | 磁盘工具急救 | 安全模式排查 | 重装 |
| 找不到系统宗卷 | `Option` 查看 | 恢复模式急救 | 重装 |
| 风扇狂转/温度高 | 检查硬件散热 | — | 除尘换硅脂 |

## 8 补充速查：恢复模式里能做什么

进恢复模式后，你能获得的工具一览：

| 工具 | 作用 |
| --- | --- |
| 磁盘工具 | 急救、抹掉、分区 |
| 重新安装 macOS | 重装系统 |
| 从时间机器恢复 | 还原备份 |
| 系统迁移助理 | 迁移数据 |
| 终端 | 手动命令操作 |
| 启动安全性实用工具 | 管理外部启动策略 |

## 9 小结

- 启动故障先看**图标语言**：问号文件夹（找不到系统）、禁止符号（不兼容）、转菊花（系统/磁盘异常）。
- **磁盘工具急救（First Aid）** 是 macOS 的 `chkdsk`，修复元数据、结构损坏。
- **安全模式**（开机按 Shift）排第三方扩展/登录项问题，并自动跑启动检查。
- 启动组合键：`Option` 选启动磁盘、`Command-R` 进恢复、`Command-Option-P-R` 重置 NVRAM（Intel）。
- 排障阶梯：**急救 → 安全模式 → 重装系统**，系统宗卷重装通常不动个人文件。
- Apple Silicon 组合键略不同：按住电源键进启动选项。
