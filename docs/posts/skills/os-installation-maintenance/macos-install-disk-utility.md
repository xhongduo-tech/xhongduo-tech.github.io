## 为什么从「磁盘工具」开始

macOS 安装走的是「恢复模式 + 磁盘工具 + 重装」三步曲，而其中最容易被忽略、也最决定成败的是中间那步——**磁盘工具**。它负责抹盘、分区、修盘，是 Mac 上唯一能「对磁盘动刀」的官方工具。理解它，你就理解了 macOS 的分区哲学：Apple 2017 年引入 **APFS** 后，「分区」不再是切硬块，而变成了「容器（Container）+ 宗卷（Volume）」的弹性结构。

本节讲清磁盘工具的界面逻辑、APFS 容器与宗卷的区别、抹盘与分区的正确姿势，然后给出一条「从抹盘到装系统」的完整路径。它承接上一节的安装介质，也呼应本专题《磁盘分区基础》里的 APFS 概念。

## 1 磁盘工具的两种视图：物理层与逻辑层

打开「应用程序 → 实用工具 → 磁盘工具」，左侧栏会列出两块区域，这是最容易迷惑人的地方：

- **物理磁盘**（如 `APPLE SSD` 或「磁盘图标」）：对应真实的硬盘，名称通常是型号。
- **宗卷/容器**（缩进的条目）：逻辑层，是物理磁盘之上划分出来的存储区。

Mac 的左侧栏默认显示「仅显示宗卷」，所以新手常看到的是一堆「Macintosh HD」「Macintosh HD - Data」这样的逻辑条目。点击左上角「显示」→「显示所有设备」，才能看到底层物理磁盘。<span class="marginnote">「Macintosh HD」和「Macintosh HD - Data」是 APFS 容器里的两个宗卷：前者是只读的系统快照，后者是可写的用户数据区。它们共用同一个容器，不是两块独立空间——这也是「APFS 不用手动分大量分区」的原因。</span>

## 2 APFS：容器与宗卷的弹性结构

**APFS（Apple File System，苹果文件系统）** 从 macOS High Sierra（2017）起成为默认文件系统，它带来的核心变化是**把「分区」换成了「容器 + 宗卷」**：

- **容器（Container）**：一段物理空间，相当于传统意义上的「大分区」。
- **宗卷（Volume）**：容器内的逻辑存储区，相当于「小分区」，但**共享容器的总容量**——没有固定上限，谁需要谁多用。

这意味着：传统「分区」是「画好格子各用各的」，APFS 是「一个大水池，大家按需取水」。所以 Mac 装系统通常不需要手动分很多区，一个容器 + 系统/数据两个宗卷就是标准形态。<span class="marginnote">APFS 容器还能随时「添加宗卷」（加号按钮），相当于「在同一个池子里再开一个逻辑分区」，比传统分区灵活得多。想要「重装系统不丢数据」，本质是「只抹系统宗卷、保留数据宗卷」——这是 Mac 版「系统数据分离」。</span>

## 3 核心对比表：APFS 与「Mac OS 扩展（日志式）」

老 Mac 用户会记得另一种格式——**Mac OS 扩展（HFS+）**。两者对比：

| 对比项 | APFS | Mac OS 扩展（HFS+） |
| --- | --- | --- |
| 默认起始 | macOS 10.13（2017）起 | 更早的 macOS |
| 分区模型 | 容器 + 宗卷 | 传统分区 |
| 空间管理 | 宗卷共享容量 | 分区固定大小 |
| 快照 | 支持 | 不支持 |
| 加密 | 原生支持 | 需额外配置 |
| 兼容 | 仅较新 macOS | 老系统/Windows 只读兼容 |

**判断要点：** 装新版 macOS（Big Sur 及以上）就用 APFS，不需要为兼容旧系统选 HFS+。只有「要跟老设备交换数据」时才考虑 HFS+ 或 exFAT。

## 4 抹盘 vs 分区：两种操作不能混

磁盘工具里两个按钮「抹掉」与「分区」，看起来像，用起来完全不同：

- **抹掉（Erase）**：清空某个宗卷或磁盘上的所有数据，重新格式化。**不能改变容量大小**，只是「清空重来」。格式可选 APFS / Mac OS 扩展 / exFAT / MS-DOS（FAT）。
- **分区（Partition）**：改变物理磁盘的分区结构——可以增加、删除分区，或调整大小。APFS 下多数场景用「抹掉」就够，物理分区很少需要动。

| 操作 | 改变容量 | 改变数量 | 清空数据 |
| --- | --- | --- | --- |
| 抹掉（Erase） | 否 | 否 | 是 |
| 分区（Partition） | 是 | 是 | 是（被操作部分） |

<span class="marginnote">对全新 Mac 重装，标准动作是「抹掉」而不是「分区」：选中物理磁盘或系统宗卷 → 抹掉 → 格式 APFS → 名称随意 → 抹掉。分区通常只在「我要手动切一块装 Windows/做 Time Machine 盘」时才需要。</span>

## 5 动手：从抹盘到安装 macOS

把整个流程走一遍：

**第一步：进恢复模式。** 开机按住 `Command-R`，或 Apple Silicon 按住电源键进入启动选项，再选「选项」。

**第二步：打开磁盘工具。** 恢复模式菜单 →「磁盘工具」→「继续」。

**第三步：抹掉目标盘。** 左侧选中物理磁盘（点「显示所有设备」后），点「抹掉」，名称随便填，格式选 **APFS**，方案选 **GUID 分区图**，点「抹掉」。<span class="marginnote">「方案」选 GUID 分区图是 UEFI/GPT 的 Mac 标准配置，相当于「GPT 分区表 + ESP」。抹掉后磁盘就是一张干净的 APFS 白纸。</span>

**第四步：退出磁盘工具。** 完成抹掉后，点左上角关闭磁盘工具，回到恢复模式主菜单。

**第五步：重新安装 macOS。** 点「重新安装 macOS」，选择刚抹掉的磁盘，开始安装。系统会自动创建容器与系统/数据宗卷。

**第六步：等待完成。** 安装过程会多次重启，最后进入「你好」设置向导，用 Apple ID 登录或新建本地账号即完成。

## 6 易错点：磁盘工具的三个坑

- **抹错盘**：左侧有多个磁盘时，确认选的是「物理磁盘」而非某个宗卷，更别选成外接 U 盘。
- **格式选错**：目标是装 macOS 却选成 exFAT/FAT，装系统时找不到可用宗卷。装系统一律 APFS。
- **误以为抹掉能改大小**：抹掉不改容量，想调整空间要用「分区」。把「抹掉」当「分区」用，是新手常见的认知错位。

## 7 补充速查：磁盘工具操作要点

把磁盘工具的使用要点收敛成速查表：

| 场景 | 操作 | 注意 |
| --- | --- | --- |
| 看物理磁盘 | 「显示」→「显示所有设备」 | 默认只看宗卷 |
| 全新安装前 | 抹掉 → APFS + GUID | 别选 exFAT |
| 只想重装系统 | 抹掉系统宗卷 | 保留数据宗卷 |
| 调整空间大小 | 用「分区」 | 抹掉不能改容量 |
| 修复磁盘 | 急救（First Aid） | 恢复模式里跑系统盘 |
| 加一块存储 | 添加宗卷 | APFS 容器内加 |
| 换数据盘 | 抹成 exFAT | 兼容 Win/mac |
| 老设备兼容 | 抹成 macOS 扩展 | 仅老系统需要 |

## 8 补充速查：APFS 与 HFS+ 选择判断

| 场景 | 用哪种 |
| --- | --- |
| 装新版 macOS | APFS |
| 老系统兼容 | Mac OS 扩展 |
| 跨 Win/mac 交换 | exFAT |
| 启动 U 盘 | APFS 或 macOS 扩展 |
| 需要快照 | APFS |

判断要点：装系统一律 APFS，跨平台才用 exFAT。

## 9 小结

- 磁盘工具是 macOS 唯一的官方磁盘管理工具，左侧「宗卷/容器」是逻辑层，物理磁盘要「显示所有设备」才看得到。
- **APFS** 用「容器 + 宗卷」模型，宗卷共享容量、按需取用，无需手动大量分区。
- **抹掉 ≠ 分区**：抹掉清空重格式，分区改变容量与数量。
- 全新安装标准动作：**恢复模式 → 磁盘工具 → 抹掉（APFS + GUID）→ 重新安装**。
- 「Macintosh HD」与「- Data」是 APFS 容器里的系统与数据宗卷，不是两块空间。
- 装系统格式一律 APFS；HFS+/exFAT 只在跨设备交换数据时考虑。
