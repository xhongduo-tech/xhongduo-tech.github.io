## 为什么从故障排查开始

第5篇的主题是「故障排除与系统恢复」，而所有故障里最让人慌的是这句——**「电脑开不了机」**。黑屏、转圈、反复重启、蓝屏……很多人一慌就送去维修店，其实绝大多数「无法开机」都有清晰的排查路径，自己动手十几分钟就能定位。**故障排查的核心不是「会修」，而是「会分类」**：先把问题归到「硬件 / 引导 / 系统 / 驱动」哪一类，再对症下药。

本节以 Windows 为主讲「无法开机」与**蓝屏（BSOD）**的排查，它对应鸟哥在《基础学习篇》里讲的「开机流程」概念——问题出在哪一步，就修哪一步。

## 1 无法开机：先给问题分类

开机失败按「卡在哪一步」分三类，各自的排查方向完全不同：

| 现象 | 问题层 | 首查方向 |
| --- | --- | --- |
| 完全没电/风扇不转 | 供电层 | 电源线、电源、主板 |
| 有电但黑屏无提示 | 硬件自检层 | 内存、显卡、显示器接口 |
| 厂商 LOGO 后转圈/蓝屏/反复重启 | 引导与系统层 | 引导、驱动、系统文件 |
| 能进系统但缓慢 | 系统层 | 磁盘健康、启动项 |

<span class="marginnote">一个实用分界：<strong>看 LOGO 之后发生什么</strong>。LOGO 是固件自检（POST）结束的标志，LOGO 前出问题偏硬件，LOGO 后出问题偏引导/系统。这个分界能瞬间把排查范围缩小一半。</span>

**重点：排查顺序永远是「硬件 → 引导 → 系统 → 驱动」从底层往上层走。** 先排除「没通电」「内存没插好」这些最便宜的假设，再动系统。

## 2 蓝屏：它在说什么

**蓝屏（Blue Screen of Death，BSOD）** 是 Windows 遇到「无法继续运行」的致命错误时显示的诊断画面。它不是「随机抽风」，而是在告诉你一个具体原因——**错误码 + 出错文件**。现代蓝屏还会显示一个「二维码」，用手机扫一下直接跳到微软官方的排障页。<span class="marginnote">蓝屏错误码有固定格式：`0x0000007B` 这类十六进制码，或 `CRITICAL_PROCESS_DIED` 这种「友好名」。微信/手机上照一张蓝屏照片，把错误码记下来——这是排障的第一手情报。</span>

要拿到蓝屏细节，最可靠的是**蓝屏转储（dump）文件**：Windows 会在 `C:\Windows\Minidump` 下生成 `.dmp` 文件，可用蓝屏分析工具（如 BlueScreenView）读出是哪个驱动/文件导致崩溃。

## 3 核心对比表：常见蓝屏错误码

| 错误码 | 含义 | 常见原因 | 排查方向 |
| --- | --- | --- | --- |
| `INACCESSIBLE_BOOT_DEVICE` | 无法访问启动设备 | 磁盘故障、引导配置损坏 | 进恢复环境修复引导 |
| `CRITICAL_PROCESS_DIED` | 关键进程崩溃 | 系统文件损坏、驱动冲突 | 重置/修复安装 |
| `DRIVER_IRQL_NOT_LESS_OR_EQUAL` | 驱动内存访问错误 | 驱动版本冲突 | 回滚/重装驱动 |
| `MEMORY_MANAGEMENT` | 内存管理异常 | **内存条故障** | 内存检测（MemTest） |
| `KERNEL_SECURITY_CHECK_FAILURE` | 内核安全检查失败 | 系统损坏、内存不稳定 | 更新系统、测内存 |
| `SYSTEM_THREAD_EXCEPTION_NOT_HANDLED` | 系统线程异常 | 驱动问题 | 更新驱动 |

**判断要点：** 蓝屏排查的最高频三原因依次是**驱动、内存、系统文件**。内存故障最隐蔽——建议备一条 `MemTest86` 启动盘，蓝屏反复且怀疑内存时跑一遍。

## 4 排查流程：一次蓝屏的标准动作

**第一步：记下错误码。** 拍照蓝屏画面，记下 `0x...` 码或友好名。

**第二步：判断频率。** 只蓝屏一次（偶发）→ 观察；反复蓝屏 → 进入正式排查。

**第三步：重启试安全模式。** 能进安全模式 → 问题多半是驱动或软件，在安全模式下卸载最近安装的驱动/软件；安全模式也蓝屏 → 偏硬件或系统文件。

**第四步：测硬件。** 内存用 MemTest86，硬盘用 CrystalDiskInfo 看 SMART。

**第五步：修系统。** 用「启动修复」「系统还原」「重置此电脑」逐级恢复（详见《安全模式与高级启动选项》《系统备份与还原》）。

## 5 动手：处理「无法开机」

**第一步：分类。** 按第1节表格判断问题层。

**第二步：查供电与接线。** 无电 → 查电源线、插座、电源开关；有电黑屏 → 检查内存条是否松动（拔下重新插紧），显卡接口。

**第三步：进恢复环境。** 连续三次开机失败，Windows 会自动进入「高级启动」（WinRE），或按住 Shift 点重启。<span class="marginnote">「连续开机失败 3 次自动进 WinRE」是 Windows 的自动修复机制，相当于「系统自带的急救室」。从这里能进「启动修复」「安全模式」「命令提示符」「卸载更新」等工具，是后续《安全模式与高级启动选项》的主战场。</span>

**第四步：启动修复。** 高级启动 → 疑难解答 → 高级选项 → 启动修复。

**第五步：逐级恢复。** 启动修复无效 → 系统还原 → 重置此电脑。

## 6 速查表：开机排障速记

| 场景 | 动作 |
| --- | --- |
| 完全没电 | 查电源线、电源、主板 |
| 有电黑屏 | 重插内存、检查显卡/显示器 |
| 反复重启 | 进 WinRE → 启动修复 |
| 蓝屏 | 记错误码 → 查驱动/内存/系统 |
| 安全模式 | 进 WinRE → 高级选项 → 启动设置 |
| 读蓝屏转储 | BlueScreenView 读 `C:\Windows\Minidump` |

## 7 补充速查：蓝屏与开机故障排查表

把「症状 → 首查 → 解法」收敛成一张速查表：

| 症状 | 问题层 | 首查 | 常用解法 |
| --- | --- | --- | --- |
| 完全没电 | 供电 | 电源线/插座 | 换线、查电源 |
| 有电黑屏 | 自检 | 内存、显卡 | 重插内存条 |
| LOGO 后转圈卡住 | 引导/系统 | 引导配置 | 启动修复 |
| 反复自动重启 | 引导/系统 | WinRE | 启动修复→还原 |
| 蓝屏 `INACCESSIBLE_BOOT_DEVICE` | 引导/磁盘 | 磁盘、引导 | 修复引导 |
| 蓝屏 `DRIVER_IRQL_NOT_LESS_OR_EQUAL` | 驱动 | 最近装的驱动 | 回滚/卸载驱动 |
| 蓝屏 `MEMORY_MANAGEMENT` | 硬件 | 内存 | MemTest86 检测 |
| 蓝屏 `CRITICAL_PROCESS_DIED` | 系统 | 系统文件 | 重置/修复安装 |
| 偶发蓝屏一次 | 未知 | 观察 | 记录错误码备用 |
| 需要蓝屏细节 | 系统 | 转储文件 | BlueScreenView 读 Minidump |

## 8 补充速查：开机排障优先级

排障时按这个顺序走，避免做无用功：

| 顺序 | 排查 | 说明 |
| --- | --- | --- |
| 1 | 供电与接线 | 最便宜、最常见 |
| 2 | 内存/显卡 | 重插可解决大半 |
| 3 | 引导 | WinRE 启动修复 |
| 4 | 驱动 | 安全模式卸载 |
| 5 | 系统文件 | 还原/重置 |

## 9 小结

- 无法开机先**分类**：供电层 / 自检层 / 引导系统层，按「硬件 → 引导 → 系统 → 驱动」排查。
- 看 **LOGO** 分界：LOGO 前偏硬件，LOGO 后偏引导/系统。
- 蓝屏在告诉你原因：**错误码 + 出错文件**，拍照记录 + 读转储文件。
- 蓝屏三大元凶：**驱动、内存、系统文件**；内存用 MemTest86 排查。
- 连续开机失败 3 次会**自动进 WinRE**，从这里逐级「启动修复 → 还原 → 重置」。
- 排障不是「会修」，而是**会分类、会按顺序排除**。
