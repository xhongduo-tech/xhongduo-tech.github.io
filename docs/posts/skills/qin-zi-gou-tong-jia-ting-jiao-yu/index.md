# 亲子沟通与家庭教育

以《非暴力沟通》的四要素方法、《如何说孩子才会听》的亲子对话技巧与《全国家庭教育指导大纲》的分龄教养指引为纲，系统重建从沟通理念与表达基础、倾听与对话技巧，到情绪管理与冲突化解、习惯养成与行为管教、分龄教养与家庭协同的完整亲子沟通与家庭教育体系。学完这些章节，就掌握了让孩子愿意听、愿意说的沟通心法，以及科学育儿的落地方法。

## 对标教材

- 《非暴力沟通》
- 《全国家庭教育指导大纲》
- 《如何说孩子才会听》
