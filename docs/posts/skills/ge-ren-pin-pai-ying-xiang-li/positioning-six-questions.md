## 为什么从定位六问开始

第 1 篇走到最后一章，前面七章给了你一套完整的定位工具箱：认知、阶梯、空位、攻守、改写、命名、自我认知。工具很多，但现实里人最缺的不是工具，而是**一套用得上手的检查流程**。

《定位》第 26 章给出全书最实操的部分：**定位六问**——六个问题，把定位从理论压缩成一张可以反复填写的自检表。<span class="marginnote">这六问是整本《定位》的「落地接口」：前面所有概念，最终都要能回答这六个问题才算数。对个人来说，它既是入职、转行、做 IP 前的体检，也是每年复盘的固定动作。</span>

这一章同时宣告第 1 篇的收束：从「什么是定位」的抽象，一路走到「怎么检验我的定位」的落地。

## 1 第一问：你现在拥有什么位置

六问的第一问，指向现状：**在你想要影响的那群人里，你已经占据了一个什么位置？**

这一问要求你停止「我觉得我是什么」，转而问「别人觉得我是什么」。回答的依据不是愿望，而是第 7 章讲过的**行为证据与外部评价**。

里斯与特劳特强调，大多数人对自己现状位置的判断是失真的——要么高估（以为别人很看重自己），要么低估（不知道自己已经被某部分人依赖）。

一个有效的回答方式：**问五个熟悉你的人——「如果让你用一个词向别人介绍我，你会用哪个词？」** 五个答案的交集，往往就是你现在真正占据的位置。

如果答案是「没人介绍得出」，那么诚实的结论是：**你目前没有位置，或位置模糊**。这不是坏消息，而是起点——知道自己没有位置，才知道该从第 3 章的空位策略开始。

## 2 第二问：你想拥有什么位置

第二问指向目标：**你希望长期占据的位置是什么？**

这一问逼你做出选择。定位的本质是取舍，**「想要的位置」必须是一个，而不是一串**。

里斯与特劳特特别提醒一个陷阱：**「什么都想要」是最常见的回答**。想被看成专家，又想被看成全能；想显得资深，又想显得年轻有活力——愿望一多，心智无法安放，等于没有愿望。

给这一问一个好答案，要满足两个条件：

**第一，具体到可以被验证。** 「成为受人尊敬的专业人士」太模糊；「成为中小企业主咨询数据问题的第一人选」才具体。

**第二，与你现在的位置有路径可连。** 目标位置如果与现状完全脱节，就成了空想。更好的写法是「从我现在的位置，向上移一级」——比如从「会写报告的人」到「帮团队把数据讲清楚的人」。

一个检验目标位置是否够具体的方法是「电梯测试」：**如果电梯里遇到一个陌生人，你能否在三十秒内说清自己想占据的位置？** 三十秒里说不清的目标，多半不是目标，只是一个方向性的好感。第二问要的不是「好感」，是能被别人复述的坐标。

## 3 第三问：你必须超越谁

第三问指向竞争：**在你想要的位置上，谁已经站着？**

这不是要你列出一堆敌人，而是要你**指出具体的占位对手**。如果你说不出「在我要占据的位置上，目前谁最强」，那说明你要么看错了位置，要么这个位置根本不存在。

里斯与特劳特给竞争问题的态度很冷静：**不要回避竞争，也不要恐惧竞争**。竞争的存在恰恰证明位置有价值——无人争抢的位置，通常也没人需要。

面对占位对手，回到第 4、5、8 章的策略池：你是领导者就去守位，是追随者就找空位或对立面，位置被占就重新定位。**第三问的功能，是把前几章的策略对号入座到你的具体处境。**

## 4 第四问与第五问：资源与坚持

第四问：**你愿意投入多少资源？** 位置不会因为「想要」就自动归属。里斯与特劳特的原话毫不客气——问自己有没有足够的钱、时间、人力去到达那个位置。

对个人，资源不只是钱，更是**注意力预算**：你能为这个定位持续投入多少时间与精力，去换取认知的建立？没有资源支撑的定位，只是愿望。

第五问：**你能坚持到底吗？** 这是六问里最容易被跳过、却最致命的一问。

定位的建立是「钉子钉进心智」的过程，而钉钉子需要的是**时间上的持续**，不是一次性的用力。<span class="marginnote">前几章反复强调「重复」「持续输出」，第五问把它变成决策标准：如果你没有把握坚持三年以上，这个位置就不是你的位置——因为心智不会为一个短暂出现又消失的人保留格子。</span>

## 5 第六问：你与自己的定位相符吗

第六问指向一致性：**你的日常言行、形象、媒介选择，是否与你的定位一致？**

里斯与特劳特用了一个词：**match（匹配）**。定位不是一句对外宣布的话，而是你整个人与这句话的匹配度。你在公开场合的样子、你发布的内容、你合作的对象，每一项都在替你的定位打分。

这一问揭露许多个人品牌失败的真相：**定位语说得很好，行为却处处偏离**。声称专业，却分享大量娱乐段子；声称严谨，却频繁犯错不修正——心智会按行为更新印象，而行为与宣言打架时，输的永远是宣言。

「是否相符」不是一个零一判断，而是一份可以逐项打分的清单：你的社交头像与定位匹配吗？你转发的内容与定位一致吗？你的穿着、谈吐、合作伙伴，会加强还是稀释你的定位？每一项打分的结果，就是你实际在公众面前呈现的「行为定位」——它才是心智真正记住的那个位置。

用一句话收束第六问：**你不需要完美地活出定位，但至少不能活成它的反面。** 偶尔的偏离可以理解，持续的偏离则会在心智里留下「此人言行不一」的印记——这个印记一旦形成，比没有定位更伤，因为它同时摧毁了信任。

第六问也是「内外一致」的落地版：**你要成为你想占的位置那样的人，而不只是声称自己站在那里。**

## 6 六问的组合用法：一张反复填写的表格

六问不是答一次就结束，而是**一套循环自检**。把它们做成一张表，定期重填：

| 问题 | 一年前的答案 | 现在的答案 | 变化说明 |
| --- | --- | --- | --- |
| 现在拥有什么位置 | | | |
| 想要什么位置 | | | |
| 必须超越谁 | | | |
| 愿意投入多少资源 | | | |
| 能坚持多久 | | | |
| 与定位是否相符 | | | |

重填的规律：**前两问的答案差距在缩小，说明你在朝目标移动；第三问的答案在变，说明战场在变化；第四、五问的答案动摇，说明该重新评估要不要继续；第六问长期答「否」，说明你的言行与定位脱节，定位迟早会塌。**

## 7 辨析｜易错点：六问不是问卷，是行动

把六问当成「填完就完了」的问卷调查，是最常见的误用。

**六问的价值不在答案，而在答案引发的行动。** 第二问逼你选择，就真的去砍掉多余的愿望；第四问逼你盘点资源，就真的为定位排注意力预算；第六问发现言行不符，就真的去调整行为。

另一个误读是把六问当成一次性测试，答完即抛。**定位是动态的：位置会变、对手会变、资源会变，六问必须定期重答**——这正是它作为「循环自检表」的意义。答一次的正确率不重要，持续重答带来的校准才重要。

## 8 小结

- 定位六问：**拥有什么位置、想要什么位置、超越谁、投入多少、坚持多久、是否相符**。
- 第一、二问管**现状与目标**，第三问管**战场**，第四、五问管**资源与时间**，第六问管**一致性**。
- 「什么都想要」是第二问最常见的错误答案，**想要的位置必须只有一个**。
- 第五问是六问的命门：**没有长期坚持的把握，就别选择那个位置**。
- 第六问决定定位的存亡：**行为与宣言打架时，输的永远是宣言**。
- 六问是一套**循环自检表**，定期重填，行动比答案重要。
- 第二问的好答案要能通过「电梯测试」：**三十秒内说清自己占据的位置**。
