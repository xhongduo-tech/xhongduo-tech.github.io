## 为什么从比赛流程讲起

一场射箭比赛能在几十名选手、数百支箭、多个靶位之间有序运转，靠的是**一套严格的流程与判罚体系**。学比赛流程，不只是为了「不犯规」，更是为了理解射箭赛事的「操作系统」——何时能射、何时能拔箭、器材什么能带什么不能带，都在这个系统里被规定死。<span class="marginnote">世界箭联规则的判罚哲学很明确：<strong>违规分「器材违规」与「行为违规」两类</strong>，前者先检查后处理，后者当场裁决。理解这套二分法，遇到任何赛场状况都不会慌乱。</span>这一篇讲比赛从报到到结束的完整流程，以及判罚的「红黄牌」体系。

比赛流程是「竞赛项目」这一篇的「动态版」：竞赛项目讲「比赛怎么比」的静态规则，比赛流程讲「比赛从开始到结束每一步怎么走」的动态过程。两者合起来，才构成「一场比赛的完整画面」。**读懂流程，你才能「对号入座」**：什么时候该报到、什么时候能试射、什么时候能上前拔箭——每一句都对应一个具体的动作指令。

## 1 比赛流程：五步走完一场比赛

一场标准赛事从选手视角看，大致经历五个环节：

**报到与检录（registration）**：选手按指定时间报到，确认身份、核对参赛项目与射位。迟到的后果按规程处理——多数赛事有「迟到截止时间」，超过即视为弃权。

**器材检查（equipment inspection）**：开赛前，裁判按规则检查选手器材合规性（详见下一节）。检查不合格的器材需更换或调整后才能参赛。

**试射（sighters）**：正式计分前通常有试射轮——让选手在正式环境里「热身 + 校准」瞄准器。试射不计入成绩，但时间有限（常见为若干箭、几分钟），要抓紧校准。

**正式发射（official ends）**：按排位/淘汰赛规程发射，每轮时间到即停，未射出的箭按脱靶或该轮作废处理。

**计分与拔箭（scoring & retrieval）**：停射哨响后，射手到靶前按《计分规则》互记环值、确认后拔箭、返回。<span class="marginnote">整个流程的「哨声语言」是射箭场的基本法：一声短哨 = 准备/上起射线；三声短哨或长哨 = 开始发射；三声长哨 = 停止发射/可上前。新手上场第一课，就是把这套哨声背熟——它比任何规则都更直接地决定你「何时能动手」。</span>

五步流程里，「试射」是最容易被新手忽略价值的环节：它不是「走过场」，而是「唯一一次合法的实战校准」——在这几分钟里，你要完成「确认器材状态、校准瞄准器、找回手感」三件事。**真正的高手把试射当「比赛的第一局」来对待**：不浪费一箭、不仓促了事。而新手常在试射时「舍不得用箭」或「随便射几箭」，结果正式发射时才发现「瞄具没校准好」——试射的每一箭，都是在为正式发射「排雷」。

## 2 器材检查：什么能带、什么不能带

器材检查是「公平」的守门员。世界箭联规则对各类器材有明确清单：

**允许的器材**：符合弓种规定的弓、箭、箭台、瞄准器（反曲弓）、护指/护臂/护胸、箭壶、护弓绳等。各弓种的「允许清单」不同——比如反曲弓允许稳定器与响片，复合弓允许窥孔与机械撒放器，传统弓则禁止瞄准器与稳定器。

**禁止的器材**：任何**辅助瞄准的电子装置**（激光瞄、测距仪——测距仪在部分野外赛事允许、靶场赛禁用）、**放大倍率超标的瞄准镜**、**不合规的箭头**（靶场禁猎箭头）等。<span class="marginnote">判罚的关键在「辅助瞄准」四个字：凡是对「瞄准」提供机器辅助的装置，竞技靶场基本禁用——因为它的本质是「把人的能力外包给设备」。测距仪在靶场赛禁用、野外赛可用的差异，恰是「规则随项目目的而变」的例子。</span>

**检查时机**：开赛前全面检查，比赛期间裁判可随时抽查。赛后夺冠的器材也常被复检——「赛后检查」防的是「赛时偷偷改装」。

器材检查的「允许/禁止」清单，背后有一条统一的判断逻辑：**「这个装置是否替射手完成了本该由人完成的工作」**。瞄准器、稳定器是「辅助人的既有能力」，允许；激光瞄、测距仪是「代替人去瞄准/测距」，禁止。用这条逻辑判断，遇到清单没列的新装置，也能自己「对号入座」。**规则不是死记的清单，而是一套「能力边界」的哲学**——这条边界划在「人的能力」与「机器的能力」之间。

## 3 违例与判罚：从警告到取消资格

世界箭联的判罚分档（类似足球的红黄牌逻辑）：

**警告（warning）**：首次、非故意的轻微违规（如轻微越线、未及时回位）。裁判出示警告并记录，不影响成绩。

**扣分或罚箭（penalty）**：情节较重或屡教不改的违规（如再次越线、干扰他人发射）。处罚可能是扣除若干环数，或取消某箭/某轮成绩。

**取消资格（disqualification）**：严重违规——**作弊**（篡改器材、冒充身份）、**危险行为**（朝人放箭、进入安全区）、**不服从裁判**等。取消资格意味着整场比赛成绩作废。<span class="marginnote">「朝人放箭」在射箭判罚里是零容忍的重罪——因为它威胁生命安全。射箭场所有安全设计（哨声协议、禁行区、挡网）最终都指向一件事：<strong>箭只能在裁判许可的方向与时机离弦</strong>。这条红线没有任何「酌情」空间。</span>

判罚的三档「警告 → 扣分 → 取消资格」是一条「升级路径」：**从「提醒」到「罚分」到「出局」**，越往上越严重。这条路径的设计逻辑，是「先给改过的机会，再逐步加重」——轻微的首次违规用警告「提醒」，屡教不改才加重到罚分，只有威胁公平或安全的严重行为才直接取消资格。理解这条「升级路径」，犯规时就不会「一上来就慌」：多数轻微违规，警告后改过即可；真正不可触碰的，只有「作弊、危险、不服从」三条红线。

## 4 核心对照表：常见违规与判罚

| 违规情形 | 性质 | 典型判罚 |
| --- | --- | --- |
| 越线发射（首次） | 行为违规 | 警告 |
| 越线发射（再次） | 行为违规 | 扣环或罚箭 |
| 使用禁带器材 | 器材违规 | 责令更换/禁赛该项 |
| 干扰他人发射 | 行为违规 | 扣分/取消该轮 |
| 朝人放箭/危险行为 | 安全重罪 | 取消资格 |
| 赛时私自改装器材 | 器材违规 | 取消资格 |

这张表读一遍，会得出一个「判罚对称」的启示：**行为违规与器材违规的处理路径不同**——行为违规「当场裁决」（警告/扣分/取消），器材违规「先检查后处理」（责令更换/复检/取消）。因为行为是「临时的」，当场裁决即可；器材是「状态性的」，需要「检查—确认—处理」的流程。读懂这张表，「被检查时不慌、被判罚时明白」——知道自己的行为属于哪一类、会有什么后果。

## 5 术语速查表：流程与判罚的词汇

| 术语 | 定义 | 关键点 |
| --- | --- | --- |
| 报到检录 | 确认身份与射位 | 迟到超时视为弃权 |
| 器材检查 | 开赛前检查器材合规性 | 允许/禁止清单 + 能力边界 |
| 试射 | 正式计分前的校准轮 | 唯一合法的实战校准 |
| 哨声协议 | 上射线/发射/停射的信号 | 新手上场第一课 |
| 同靶互记 | 同靶选手互相计分 | 先确认后拔箭 |
| 警告/扣分/取消 | 判罚的三级升级路径 | 三条红线不可触碰 |
| 辅助瞄准装置 | 替射手瞄准的电子装置 | 靶场赛基本禁用 |

七个词构成流程与判罚的「词汇表」。其中「哨声协议」是「何时能动手」的第一纪律，而「警告/扣分/取消」是「犯规有什么后果」的判罚地图。把这两组词记熟，上场时就能「听哨行事、按规行事」，不再因为「不懂流程」而紧张或犯规。

## 6 赛场应对：不同状况的处置速查

赛场上状况繁多，用一张「状况—应对」表把高频场景一次理清：

| 赛场状况 | 正确应对 | 常见失误 |
| --- | --- | --- |
| 器材检查 | 如实申报、配合检查 | 紧张对抗、隐瞒 |
| 试射阶段 | 抓紧校准瞄准器与手感 | 随便射几箭浪费机会 |
| 听哨上射线 | 短哨上、发射哨开始 | 抢跑、越线 |
| 计分异议 | 当场提出、请裁判复核 | 事后申诉、私下争执 |
| 停射后拔箭 | 停射哨响后再上前 | 提前上前（违规） |
| 超时未射 | 接受按脱靶处理 | 慌乱抢放 |
| 判罚后 | 服从裁判、继续比赛 | 情绪失控影响后续 |

这张表的逻辑是「**每种状况都有唯一正确的动作**」——赛场上的不确定感，大多来自「不知道此刻该做什么」。把这张表记熟，等于把「赛场的应急手册」装进脑子：器材检查配合就好、试射抓紧校准、计分异议当场提、停射后再拔箭。**赛场上的从容，来自「预演过所有状况」**——这正是《赛前心理调节》篇「意象演练」在流程层面的具体化。

## 7 辨析｜易错点：「被检查」不等于「被罚」

许多新选手一听「器材检查」就紧张，其实**检查是例行程序，不是处罚**——被抽查器材合规且如实配合，没有任何后果。真正会被罚的是「**违规还隐瞒**」：如实申报、现场整改，通常只是警告；试图蒙混过关、抗拒检查，才会升级为取消资格。<span class="marginnote">另一个易错点是<strong>把「试射」当「正式计分」</strong>：试射轮射完的箭不记录，但试射「超时未射完」照样算违规。分清「哪些箭算分、哪些不算」，是赛前流程里最容易手忙脚乱的细节——训练时就养成「听哨—发射—停哨」的反应，赛时才不慌。</span>最后提醒：比赛中的**计时**是硬约束——每轮发射有时间上限（如个人对抗赛每轮 120 秒），超时未射的箭按脱靶处理。平时的《呼吸控制与动作节奏》训练，就是在为「时间压力下不抢放」做准备。

「被检查 ≠ 被罚」的背后，还有一个「心态」提醒：**把器材检查当成「免费体检」而非「找茬」**。检查是裁判在帮你确认「器材状态是否合规、是否安全」——一次合规的检查通过，等于给「器材状态」上了一道保险；而若真被查出问题，也是「赛前发现、当场整改」，好过「赛中被判罚」。所以面对检查，态度是「配合 + 感谢」，而不是「紧张 + 对抗」。**把裁判当成「规则的守护者」而非「你的敌人」**，是赛场心态成熟的第一步。

## 8 小结

- 比赛流程五步：**报到检录 → 器材检查 → 试射 → 正式发射 → 计分拔箭**。
- 哨声语言是全场秩序核心：上射线、发射、停射各有明确信号。
- 器材检查分「允许/禁止」清单，**电子辅助瞄准装置**是靶场赛的禁区。
- 判罚分**警告、扣分罚箭、取消资格**三档；朝人放箭是零容忍重罪。
- 被检查≠被罚，如实配合即可；计时是硬约束，超时未射按脱靶处理。
- 试射是「唯一合法的实战校准」，高手把试射当「比赛的第一局」。
- 判罚路径是「提醒 → 罚分 → 出局」，只有作弊、危险、不服从三条红线不可触碰。
- 把器材检查当「免费体检」，把裁判当「规则守护者」，赛场心态更成熟。
- 用「状况—应对」速查表预演所有赛场场景，从容来自「预演过」。
- 赛场的从容不是天赋，而是「把应急手册装进脑子」的结果。
