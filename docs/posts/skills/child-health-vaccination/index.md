# 儿童保健与预防接种

以《中华人民共和国疫苗管理法》《预防接种工作规范（2023年版）》与《国家免疫规划疫苗儿童免疫程序》为纲，结合儿童保健查体与生长发育监测，系统构建从疫苗管理法规、国家免疫规划程序、预防接种操作规范到儿童保健随访的完整知识体系。学完这些章节，就掌握了儿童疫苗接种与保健管理工作的核心内容。

## 对标教材

- 《中华人民共和国疫苗管理法》
