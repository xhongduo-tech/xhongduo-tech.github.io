# 围棋

围棋是起源于中国的黑白对弈智力运动，以 19 路棋盘上围地多少判定胜负，规则简洁而变化无穷，被誉为"人类智慧的体操"。以《围棋入门》、中国围棋协会段位体系与《围棋布局与中盘》为纲，系统重建从规则基础、基本定式、布局原则到中盘战斗与收官技巧的完整知识结构。
