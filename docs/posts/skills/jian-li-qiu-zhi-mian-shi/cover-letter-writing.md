## 为什么还需要一封「信」

有了简历为什么还要求职信？因为两者分工不同：**简历是「事实清单」，求职信是「叙述与动机」。** 简历回答「你做过什么」，求职信回答「你为什么想做这个、你为什么来这家公司、你能带来什么特别的价值」——这三个问题简历都答不了，因为它们需要「叙事」而非「列举」。<span class="marginnote">一个容易被忽略的事实：很多人把求职信写成简历的文字版，开头「本人毕业于 XX 大学，有 X 年经验……」然后逐条复述经历。这样的求职信 HR 看完等于没看——它没有提供任何简历之外的新信息。一封合格的求职信的价值，恰恰在于「简历放不下的那部分」：动机、故事、与这家公司的独特连接。</span>《简历写作指南》第6章的核心结论是：**求职信不是简历的附件，而是简历的「应用层」——它决定 HR 是否愿意点开简历。**

## 1 求职信的结构：三段式 + 一段钩子

一封高效的求职信，长度控制在一页以内、400–600 字，结构是「钩子 + 动机 + 匹配 + 行动」：

**第一段：钩子与开场。** 前两句话必须抓住 HR——直接说明「我应聘什么岗位 + 为什么是此刻 + 我与这家公司的独特连接」。避免「您好，我从网上看到贵司的招聘信息」这类无效开场。<span class="marginnote">钩子的写法差异很大，但共同点是「具体」：具体到这家公司（「我注意到贵司上月发布的海外市场扩展计划」）、具体到这个人（「我上一份工作服务的客户里就有贵司的产品」）。具体的钩子说明你真做了功课，泛泛的开场说明你群发了同一封信。</span>

**第二段：动机陈述。** 为什么想加入这家公司、为什么想做这个岗位。动机要「具体 + 真诚」——具体到公司的产品、业务、团队或价值观，而不是「贵司是行业龙头」这种套话。

**第三段：价值匹配。** 把简历里最相关的 1–2 个成果拎出来，说明「我能带来什么」。这一段不是复述简历，而是**挑重点 + 加解读**——告诉 HR 这个成果为什么对你的岗位有价值。

**第四段：行动召唤（CTA）。** 结尾明确「期待面试机会」，并留下联系方式。一个得体的行动召唤：表明主动跟进的态度，但不纠缠。

**示例骨架：**

> 尊敬的 XX 女士/先生：
> 我应聘贵司的「用户运营」岗位。我持续关注贵司在本地生活赛道的增长策略，上一份工作中，我用数据驱动的活动方法服务过 3 家同类平台……
> 我过去 3 年专注于用户增长，其中最相关的一段是：通过渠道分层与 A/B 测试，将新用户次日留存提升 18%……
> 期待有机会进一步交流。随信附上简历，我的联系方式是……

## 2 自荐信：没有在招岗位时，如何「创造机会」

自荐信（speculative application）是另一种武器：**不是投给一个在招岗位，而是主动写给一家你心仪的公司，表达「即使现在没岗位，我也想让你知道我的价值」。** 它与求职信的区别在「时机」——求职信对应用人需求，自荐信创造用人需求。

**核心概念：自荐信**——向目标公司主动投递、以建立联系与未来机会为目的的求职文书，常见于「这家公司我非去不可、但此刻没有岗位」的情形。

自荐信的写法与求职信基本同构，但有两个关键差异：

**差异一：更强调「我能为你解决什么」，而非「我想做什么」。** 因为没有在招岗位，你必须先给出价值：指出公司可能面临的一个问题或机会，并说明「如果是这样，我可以帮你做 X」。<span class="marginnote">写自荐信前做足公司调研（第1篇《行业与公司调研方法》），找出一个具体的业务切入口。比如「我注意到贵司的出海业务刚起步，我在东南亚市场有 2 年本地化运营经验」——把一个「未来的需求」摆上台面，比笼统的「我热爱贵司」有力得多。</span>

**差异二：语气更「低压力」。** 自荐信是「敲门」不是「叫门」——结尾给足台阶：「如果近期没有合适机会，也欢迎保持联系」，让收信人没有「不回应就是失礼」的压力。低压力反而更容易得到回应。

## 3 核心辨析：求职信的四个高频错误

**辨析｜易错点：** 求职信是「低字数、高错误密度」的区域，四个最常见的坑：

**「复述简历。」** 求职信里出现「详见简历」式的逐条搬运，是最大的浪费。信里只挑最相关的 1–2 个成果 + 解读，其余留给简历。
**「称呼与格式草率。」** 「尊敬的领导」不如「尊敬的 HR 老师」，能查到具体收件人（如用人部门负责人）就写具体人。「邮件标题用'求职'」不如「应聘用户运营 - 张伟 - 3年经验」。称呼和标题是专业度的第一信号。<span class="marginnote">邮件标题其实是一条「微型求职信」——在 HR 打开邮件之前，它已经决定了邮件是否会被点开。公式：<strong>应聘岗位 + 姓名 + 核心卖点</strong>（如「应聘用户运营·张伟·3年增长经验·附作品集」），信息完整又有一眼亮点。</span>
**「通篇套话。」** 「本人勤奋刻苦、乐于学习、服从安排」——这类自我评价没有任何信息量，还暴露「你没有具体可写的东西」。把每一句套话替换成一个具体事实，是求职信优化的通用改法。
**「语法与错别字。」** 求职信篇幅短，一个错别字的「伤害密度」远高于长文档。写完通读两遍，或让朋友过目——错别字在求职信里几乎等于「粗心」的实锤证据。

## 4 什么情况该写、什么情况不必写

求职信不是「每投必写」的强制项，写不写要看渠道与公司的信号：

| 场景 | 建议 |
| --- | --- |
| 官网 / 邮件投递，要求附求职信 | 必须写，且按岗位定制 |
| 邮件直联目标公司 | 邮件正文本身就是求职信，精简到 200–300 字 |
| 招聘网站一键投递，无附加栏 | 可不写，把省下的精力用于定制简历 |
| 内推 | 不必长篇求职信，但可给内推人一段 100 字简介供其转发 |
| 自荐（无在招岗位） | 必须写，且按「公司调研 + 价值切入」定制 |

**重点：求职信是「锦上添花」，不是「雪中送炭」。** 它无法拯救一份不匹配的简历，但能把一份匹配的简历从「合格」推向「优先」——尤其当竞争者有相同资历、而你的信里写出了对这家公司的独特理解时。<span class="marginnote">判断要不要花时间写求职信，可以用第1篇的「机会成本」框架：当目标岗位竞争激烈、或者这封信用得上公司调研成果时，写它的预期收益最高；当渠道只是海投、对方根本不看附加材料时，把时间投给简历定制更划算。</span>

## 5 求职信的「改写升级」：从套话到钩子的三次迭代

写求职信最有效的练习方式，是拿自己的一封「初稿」做三次迭代改写，每次只解决一个毛病：

**第一次迭代：删掉所有套话。** 把「本人勤奋刻苦、乐于学习、希望加入贵司这个优秀的平台」这类句子全部划掉。判断标准：**「这句话能不能被任何其他求职者原样使用？」** 能，就删——套话的共同特征就是「放之四海而皆准」，也因此毫无信息量。<span class="marginnote">「能否被他人复用」是识别套话的黄金标准：一句「贵司是行业领军企业」可以被一千个人写在同一封求职信里，而一句「我注意到贵司刚发布了 XX 产品，这与我上一份工作的 XX 项目高度相关」只能由你写出来。信里「只能由你写出」的句子越多，信就越有效。</span>

**第二次迭代：把「我」的视角换成「你（公司）」的视角。** 初稿通常通篇「我怎么样」——我的经历、我的期望、我的优势。改写时把每一句「我想……」翻译成「我能为贵司……」。同样的信息，叙述主语从「我」换成「你」，立意立刻不同：前者是「索取者」，后者是「贡献者」。

**第三次迭代：给「动机」补一个「具体依据」。** 把「我很喜欢贵司」升级为「我喜欢贵司，因为 XX」——因为具体的产品、因为某篇报道里的观点、因为朋友的从业体验。**动机有没有依据，是「真诚」和「客套」的分界线**，也是面试官判断「你是不是真心想来」的最重要信号。

**三次迭代的示例（浓缩版）：**

> 初稿：本人学习能力强，希望加入贵司。
> 一改：希望用我的用户增长经验，为贵司的出海业务贡献力量。
> 二改：贵司正在拓展出海业务，我在东南亚市场有 2 年本地化运营经验，能帮你快速建立增长基线。
> 终稿：注意到贵司上月宣布进军东南亚，我上一份工作正是负责该区域的新用户增长（12 个月做到月活 10 万）。如果能在出海初期加入，我想用这套打法帮贵司把「从 0 到 1」的阶段走得更稳。

三次迭代后，同一封求职信的信息量与说服力判若两信。**把「初稿 → 终稿」的过程走一遍，胜过读十篇求职信写作指南。**

| 迭代 | 动作 | 效果 |
| --- | --- | --- |
| 一改 | 删套话 | 信息密度提升 |
| 二改 | 我→你（公司）视角 | 从索取到贡献 |
| 三改 | 动机补依据 | 从客套到真诚 |

## 6 求职信的「核心句式库」：拆解一封好信的句子

与其抽象地讲「怎么写」，不如把一封好求职信里的「核心句式」拆出来，供你直接套用。每个句式都有「作用说明」，你按需取用、组合成自己的信：

**开场钩子句：**
「我注意到贵司 [具体业务/动态]，这正是我 [相关经验] 最擅长的方向。」（具体 + 连接）
「我持续关注贵司在 [领域] 的 [具体动作]，并希望成为其中一员。」（表达关注 + 动机）

**动机陈述句：**
- 「之所以选择贵司，是因为 [具体原因]，而不仅是 [行业/规模]。」（区分「真诚」与「套话」）
- 「我希望能在一个 [特征] 的平台上深耕 [方向]，贵司的 [特征] 恰好契合。」（自我规划 × 公司匹配）

**价值匹配句：**
- 「我过去最相关的一段经历是 [成果]，这直接对应贵司这个岗位的 [核心要求]。」（成果 → 岗位映射）
- 「如果加入贵司，我希望用 [能力] 帮你 [解决什么问题]。」（贡献视角）

**行动召唤句：**
- 「期待有机会进一步交流，随信附上简历与作品集。」（明确的下一步）
- 「如有任何需要补充的信息，随时联系我。」（主动但留余地）

<span class="marginnote">句式库的使用方法：<strong>先用「填空」组装一版，再逐句换成「你自己的话」</strong>——句式库给的是「骨架」，你自己的经历与措辞是「血肉」。直接用别人的句子写完整封信（而不换措辞），容易显得「模板味」太重；先套骨架、再个性化，是平衡「结构」与「真诚」的正确路径。</span>

**一封求职信的「自查清单」：**

| 检查项 | 标准 |
| --- | --- |
| 有没有具体钩子？ | 提到公司具体业务/动态 |
| 动机真诚吗？ | 有具体原因，不是「贵司很好」 |
| 价值匹配了吗？ | 挑出最相关的 1–2 个成果并解读 |
| 结尾有行动召唤吗？ | 明确下一步 |
| 全文是否「只能由你写出」？ | 换个人就不能原样使用 |

**最后的提醒：** 求职信是「锦上添花」，但「添花」也有「添得好不好」之分——一封「只能由你写出」的信，是简历之外最有力的「差异化武器」；一封「人人可用」的信，则是纯属多余的负担。**把每一次写求职信，都当成「只写给这家公司」来写**——写得越「专属」，价值越大。

## 7 小结

- 求职信与简历**分工不同**：简历列事实，求职信讲动机与价值；它决定 HR 是否点开简历。
- 求职信结构：**钩子 + 动机 + 价值匹配 + 行动召唤**，一页以内，避免复述简历。
- 自荐信用于「**没岗位也想去**」：更强调「我能为你解决什么」，语气低压力、留台阶。
- 排雷：不复述简历、称呼标题要具体、套话全换事实、错别字零容忍。
- 写不写看场景：官网/邮件/自荐必写，海投与内推可从简；求职信是锦上添花，不能拯救不匹配的简历。

在下一节，我们来做一次「逆向工程」——把简历写作中所有高频的坑集中盘点，形成一份可对照自查的避坑清单。《简历写作指南》第7章就是这份清单的集大成，写完简历后照单核查一遍，能挡住绝大多数低级失误。
