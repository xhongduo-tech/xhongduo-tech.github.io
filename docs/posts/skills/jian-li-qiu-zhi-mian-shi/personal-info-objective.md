## 为什么开头最容易被忽视

上一节搭好了简历的骨架，现在填第一格。奇怪的是，求职者对「个人基本信息」的态度两极分化：要么随手一写（姓名、电话、邮箱、没了），要么塞满无关信息（年龄、籍贯、政治面貌、婚姻状况、一张精心挑选的照片）。<span class="marginnote">随手写，HR 找不到关键联系方式；塞满无关信息，则是主动提供被歧视的把柄。个人信息区的原则只有一句：<strong>给 HR 提供「验证你身份 + 联系你」所必需的最小信息集</strong>。这不是保守，而是专业——简历的每一行都要回答「这与岗位有什么关系」，顶部也不例外。</span>《简历写作指南》第2章花一章讲这块「头部区域」，因为它是 HR 扫描的第一站，也是 ATS 解析简历的入口。

## 1 个人信息：最小必要信息集

一份专业的个人信息区，只包含五类信息：

**姓名**：真实姓名，字号可略大于正文。若你的名字有生僻字，可在括号里注拼音，避免 HR 念不出、沟通尴尬。

**联系电话**：一个当前在用、保持畅通的手机号。**重点：面试期间保持电话畅通、注意接听陌生号码，并留好语音信箱**——错过 HR 电话是最高频的「低级失误」。

**电子邮箱**：优先使用常用邮箱，格式建议「姓名拼音 + 数字」的组合。避免使用「可爱」「中二」风格的昵称邮箱（如 `badboy666@`），它会显著拉低专业感。<span class="marginnote">邮箱命名看似小事，却是 HR 形成第一印象的隐性信号。`zhangwei2020@` 和 `xiao_ke_ai_0909@` 放在一起，前者天然显得更职业。邮箱是求职者的「数字名片」，值得花 5 分钟注册一个干净的。</span>

**所在地 / 到岗状态**：如果跨城市求职，建议写明「现居城市 + 是否可到岗」，避免 HR 因「人在外地」的顾虑直接过滤你。

**可选信息**：个人网站 / 作品集链接、LinkedIn 或脉脉主页、GitHub 等。**判据是：放了是否加分？** 与岗位相关就放，不相关或质量一般就不放——一个空壳作品集是减分项。

**辨析｜易错点：** 以下信息**不建议**出现在简历上：年龄与出生年月（无必要且可能引发歧视联想）、籍贯、政治面貌、婚姻状况、宗教信仰、体重身高。判断标准很简单：**与「能否胜任岗位」无关的信息，一律不放。**

## 2 求职意向：从「一句空话」到「精准匹配」

求职意向是简历里信息密度最高、也最常被写废的一行。常见废写法：「寻求一份有发展前景、能发挥个人能力的工作」——这句话毫无信息量，等于没写。

**核心概念：求职意向（objective）**——一句话说明「你要应聘什么岗位、在什么行业、期望什么层级」，它直接告诉 HR「这份简历是冲着哪个坑来的」。

一个好的求职意向，由三个元素构成：

**岗位名称**：写「用户运营」而不是「运营」，写「Java 后端开发」而不是「程序员」。岗位名要与 JD 完全一致，这既是让 HR 秒懂，也是让 ATS 匹配到关键词。

**行业 / 业务方向**：写「互联网内容行业」或「消费品牌电商」，让 HR 知道你对行业有认知、不是乱投。

**可选的附加价值**：一句你相对同岗位候选人的差异化优势，如「擅长数据驱动的用户增长」。

合起来，一个可用的求职意向是：

> 求职意向：互联网内容行业 · 用户运营，3 年经验，擅长数据驱动的用户增长与活动策划。

<span class="marginnote">注意「求职意向」与第1篇的「定位陈述」的区别与联系：定位陈述是给「你自己」看的方向校准，求职意向是给「HR」看的岗位标签。两者同源，但求职意向要更短、更贴近 JD 语言——把定位陈述翻译成招聘方能秒懂的话，就是这一行的写法。</span>

## 3 针对不同岗位，怎么写不同的意向

求职意向最大的陷阱是「一份简历走天下」。既然意向是第一眼的关键词，它就必须跟随目标岗位变化：

| 目标岗位 JD 关键词 | 求职意向写法示例 |
| --- | --- |
| 用户增长 / 拉新 / 活动 | 用户增长运营，擅长拉新活动设计与转化漏斗优化 |
| 内容运营 / 图文 / 公众号 | 内容运营，3 年公众号经验，专注选题策划与数据复盘 |
| 数据分析 / SQL / 报表 | 数据分析师，熟练 SQL 与可视化，服务业务决策 |

**重点：投递前把求职意向与 JD 对齐**——JD 里出现的核心名词（岗位名、业务方向、技术栈）应该在求职意向里原样出现。这不是造假，而是「用对方听得懂的语言介绍自己」，与第2篇《简历的针对性定制与关键词优化》是同一逻辑的顶部版本。

## 4 核心辨析：个人信息区的三个高频错误

**辨析｜易错点：** 头部区域虽小，错误却最密集：

**「照片：放不放？」** 国内职场对照片的期待因行业而异——国企、银行、传统行业普遍放，互联网、外企多不放。<span class="marginnote">一个稳妥的折中：放一张<strong>职业照</strong>（正装、正面、背景简洁），不放生活照、旅行照、过度修图的自拍。照片若放，就要像证件照一样正式；拿不准时，可参考目标公司的在职员工风格。</span>
**「邮箱/电话写错，检查不仔细。」** 联系方式是唯一「错了就没下文」的信息。提交前逐字核对电话位数、邮箱拼写，这是零成本但一票否决的检查项。
**「求职意向频繁变化，自己也没定位。」** 如果你今天写用户运营、明天写产品助理、后天写行政，简历在 HR 眼里就是「没想清楚的人」。意向可以随岗位微调，但大方向要保持稳定——这是第1篇定位工作的延续，定位没做好的人，意向区会反复动摇。

## 5 常见「个人信息区」的正误对照

把头部区域最容易写错的几处，用「正误对照」的方式直接呈现，比抽象原则更直观：

| 项目 | ✗ 错误写法 | ✓ 正确写法 | 说明 |
| --- | --- | --- | --- |
| 邮箱 | `xiao_ke_ai_0909@qq.com` | `zhangwei2020@qq.com` | 姓名 + 数字，干净专业 |
| 求职意向 | 寻求一份有发展前景的工作 | 互联网内容行业 · 用户运营（3 年） | 岗位 + 行业 + 经验 |
| 所在地 | （不写） | 现居上海，可到岗 | 跨城市求职必写 |
| 照片 | 旅行自拍 | 职业照或不放 | 放则正式，拿不准不放 |
| 电话 | 座机号（打不通） | 常用手机号 | 保持畅通、留语音信箱 |
| 无关信息 | 年龄 / 籍贯 / 婚姻 | 一律不写 | 与胜任无关即不放 |

<span class="marginnote">正误对照的核心逻辑：<strong>简历头部不是「证明你是谁」的地方，而是「让 HR 最快确认你就是他要找的人」的地方</strong>。每个信息都要回答「这对我拿到这个岗位有帮助吗」——有帮助才放，没帮助就是干扰。这张表也可以当成「投递前最后一眼」的检查单：扫一眼正误，就知道头部是否达标。</span>

**关于「姓名」的一个细节：** 如果你的名字有生僻字或多音字，可以在姓名后用括号注拼音——「张茜（qiàn）」。这个小动作看似多余，却能避免两种尴尬：HR 念不出你的名字不敢喊你、或把「茜」误读成「xī」导致叫错人。**降低对方「识别你」的成本，是个人信息区的隐藏功能。**

**关于「作品集链接」的一个提醒：** 放链接的收益取决于「点开后的质量」。一个精心打磨的作品集是强力加分项，一个半年没更新、打开是空壳的链接是减分项。**链接的判据：点开后 10 秒内，对方能看出「这个人会什么」**——看不出来，就不如不放。<span class="marginnote">作品集链接还涉及一个「访问成本」问题：需要登录才能看、需要翻好几层才能找到代表作、手机打不开的链接，都会让 HR 直接放弃。把作品集做成「无需登录、一页直达代表作」的形式，是尊重对方时间、也最大化展示效果的做法。</span>

## 6 求职意向的「对齐机制」：意向与岗位的匹配检查

求职意向写得再好，如果与目标岗位不对齐，也等于白写。把「意向对齐」做成一个可检查的机制，防止「意向与内容错位」这类问题（第2篇《简历常见错误》里的减分项）：

**对齐检查的三问：**

| 检查问 | 说明 |
| --- | --- |
| 意向里的岗位名，与 JD 一致吗？ | 一字不差最好——系统匹配靠它 |
| 意向里的行业方向，与公司匹配吗？ | 体现你对行业有认知、不是乱投 |
| 意向里的「附加价值」，与岗位核心要求相关吗？ | 差异化优势要对着岗位痛点说 |

**重点：意向的「三个一」原则。** 每次投递前，把求职意向「对齐三件事」——**岗位名对齐（和 JD 一致）、方向对齐（和公司业务一致）、卖点对齐（和岗位核心要求一致）**。三个都对上，意向就是「精准标签」；任何一个没对上，HR 就会怀疑这份简历是群发的。

**意向与自我介绍的衔接：** 求职意向是简历里的「一句话定位」，自我介绍是面试里的「一句话定位」——两者应该同源（第2篇《自我介绍与开场表达》）。**简历意向怎么写，面试自我介绍就怎么讲**，前后一致，面试官会感到「这个人的自我认知是稳定的」。

**辨析｜易错点：** 意向对齐过程中最容易犯的错——**「为了对齐而过度修饰」**。比如你不是「3 年经验」却为了对齐 JD 写「3 年经验」；你不是「专注增长」却把意向写成「专注增长」。**对齐的是「表达方式」，不是「事实本身」**——你的经验年限、能力方向是事实，对齐只能调整「怎么说」，不能篡改「是什么」。<span class="marginnote">这条「对齐表达、不篡改事实」的边界，和第2篇《简历的针对性定制与关键词优化》里「定制与造假的界限」完全一致——同一个原则在不同环节的重复出现，说明它是简历写作的底层红线：<strong>所有优化都发生在「表达层」，事实层不可触碰</strong>。守住这条线，简历怎么优化都安全。</span>

**一个「意向维护」的提醒：** 求职意向不是写一次就完的——**每隔一段时间（或岗位方向调整时）回看一次**，确认它仍然准确表达「你现在的定位」。定位在成长（第1篇《目标岗位与职业方向定位》的「动态校准」），意向也要跟着更新——一份 2023 年写的意向，到 2025 年还在用，说明你的自我认知已经落后于你的成长了。

## 7 小结

- 个人信息区只放**最小必要信息集**：姓名、电话、邮箱、所在地/到岗状态、可选的作品集链接。
- 与「能否胜任」无关的信息（年龄、籍贯、婚姻等）**一律不放**。
- 求职意向 = **岗位名 + 行业方向 + 可选差异化优势**，要贴近 JD 语言，拒绝「寻求有发展前景的工作」式空话。
- 意向随岗位**定向调整**但方向稳定；联系方式逐字核对，照片放不放看行业惯例。
