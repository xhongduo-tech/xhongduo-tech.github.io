## 为什么从「职业定义」开始

上一节我们看清了城轨系统与司机岗位的位置，这一节要回答一个更直接的问题：**这个岗位到底做什么、不做什么**。职业定义看起来只是一句话，却决定了后面全部内容的边界——哪些技能该学、哪些责任该担、哪些情形该由谁处置，都以「职业定义与工作任务」为起点展开。<span class="marginnote">职业定义是把岗位「框」出来的第一刀：它划清司机与调度、车站、检修的分工边界，避免「该管的不管、不该管的瞎管」。许多作业分歧，归根到底是职责边界没厘清。</span>

《城市轨道交通列车司机》职业技能标准对本职业给出了权威定义，并据此拆出**职业功能**——每个职业功能下再列具体工作内容与技能要求。学习本篇，就是先拿到这张「岗位说明书」，再逐条去把它变成真本事。

## 1 职业定义：司机的「一句话身份」

依据《城市轨道交通列车司机》职业技能标准，列车司机是**操作城市轨道交通列车，按规定组织行车，安全、正点地运送乘客，并对列车运行安全承担直接责任**的从业人员。

把这句话拆开，有三个关键词：**操作**（动手，驾驶操纵）、**组织行车**（按规章与运行图运行，与调度、车站联控）、**直接责任**（安全责任落到个人，不是「系统负责」）。<span class="marginnote">「直接责任」四个字分量很重：信号系统可以辅助防护，但司机对瞭望、判断、操作负有不可推卸的责任。理解这一点，就理解了为什么司机要反复练、年年考。</span>

这个定义还隐含一个属性：**司机是「人机结合」岗位**——既要操纵物理的列车，又要与庞大的运营系统协同。它不同于普通驾驶员，因为司机的一切动作都嵌在「统一指挥、按图运行」的网络里。

## 2 工作任务：从出勤到退勤的作业链条

司机的日常工作可以组织成一条完整的**作业链条**，每个环节都有明确的作业标准：

**出勤**：按乘务计划到点报到，接受酒精检测，领取值乘任务、运行揭示与调度命令，了解当日线路、天气与注意事项。

**接车与整备**：到司机室接车，按规定检查车辆与设备状态，完成制动试验、车门试验、信号（ATP）测试，确认具备出库条件。

**正线驾驶**：按运行图与信号显示操纵列车，执行「调速—对标—开关门—确认发车」的循环，全程瞭望线路与站台。

**折返与换端**：到终点站完成折返作业（换端、动车司机室），再投入下一程运行。

**交接班**：在规定的换班点向接班司机交接列车状态、运行情况与注意事项，办理交接手续。

**退勤**：回段/回场交车，报告运行情况与设备异常，办理退勤。

每一个环节都在《职业技能标准》里对应着具体的**作业项目、技能要求与知识要求**，也是职业技能鉴定的考核点。<span class="marginnote">这套链条最重要的特征是「闭环」：出勤有登记、交接有记录、退勤有汇报，任何一环的信息缺失都可能成为安全隐患。司机要养成的第一个习惯，就是「事事留痕、件件确认」。</span>

## 3 知识要求：司机「脑中的四块地图」

职业能力不仅靠手，更靠脑。职业技能标准对司机的**知识要求**可以归纳为四块，缺一不可：

**行车规章知识**：运行图、行车闭塞、信号显示、联控用语、限速规定——这是「按章行车」的依据。

**车辆与信号知识**：车辆结构、牵引制动原理、信号与 ATP 原理、车门系统——这是「看得懂现象」的基础，例如制动力不足时能推断是风压、制动系统还是黏着问题。

**安全与应急处置知识**：危险源辨识、应急程序、消防、疏散、救援配合——这是「出事不乱」的前提。

**服务与职业道德知识**：服务规范、乘客心理、职业守则——这是「当好服务者」的素养。<span class="marginnote">把知识分四块，是为了看清「司机不是只会开车的工人」：行车规章让动作合法，车辆知识让判断有据，应急知识让处置不乱，服务知识让乘客安心。四块地图合起来，才构成「能值乘」的完整能力。</span>

## 4 工作环境与联控对象

司机的主要工作环境是**司机室**与**正线线路**，二者性质截然不同：司机室里要同时观察仪表、信号、线路与站台，是典型的**多任务并行**作业；正线上则要面对隧道、桥梁、曲线、道岔、站台等复杂环境。

司机的联控对象主要有三方：

**行车调度（调度中心）**：通过无线电台保持联系，接收调度命令、报告运行异常、请求处置支援。

**车站值班员/站务员**：确认发车条件、协同处理站台侧情况、组织乘客乘降。

**沿线作业人员**：施工、检修、清障人员，司机须按章与之联系，确认作业区域与防护状态。

**理解联控对象，就是理解「司机不是一个人在战斗」**：他的每一个决定，都要与这三方互通信息、相互确认，这正是城轨「统一指挥、逐级负责」的具体落地。

## 5 核心对比表：司机、调度、车站的职责边界

| 角色 | 主要职责 | 直接对象 | 权力边界 |
| --- | --- | --- | --- |
| 列车司机 | 驾驶操纵、安全正点、应急处置 | 本列车 | 在信号与命令框架内操纵列车 |
| 行车调度 | 运行图组织、命令下达、全局指挥 | 全线列车 | 统筹全线，不直接操纵单列车 |
| 车站值班员 | 接发车、乘降组织、站台安全 | 本站站台与列车 | 负责站务与发车条件确认 |

**横向读表**：三者职责互补、相互制约——调度管「全局怎么跑」，司机管「这一列车怎么开」，车站管「站台上和车门边怎么安全」。任何一环缺位，另外两环都要兜住，这就是联控的意义。

## 6 辨析｜易错点：司机「会开车」不等于「能值乘」

最常见的误解是：会操纵列车，就等于能干司机。

**辨析｜易错点：** 驾驶操纵只是司机工作任务的一环。一个合格的司机还要会**整备检查**（接车时发现设备隐患）、**联控交流**（与调度、车站规范沟通）、**应急处置**（故障、火灾、疏散时按程序处置）、**记录交接**（交接班信息完整闭环）。职业技能鉴定的实操考核，正是按「整备—驾驶—处置—交班」的全链条出题，而不只是考「开得稳」。<span class="marginnote">把「会开车」误当「能值乘」，是很多新司机轻视整备、轻视交接的根源。作业链条上任何一环松了，都会在正线上以别的形式找回来。</span>

**正确理解**：司机的职业能力 = 操纵技能 + 行车组织知识 + 应急处置能力 + 职业纪律，四者缺一不可。

## 7 术语速查表

| 术语 | 含义 |
| --- | --- |
| 职业定义 | 对职业性质与职责的权威界定 |
| 职业功能 | 职业技能标准中按功能划分的工作模块 |
| 出勤 | 按乘务计划到值乘点报到并接受检查 |
| 运行揭示 | 当日运行的临时限速、施工等注意事项 |
| 换端 | 折返时从一端司机室转移到另一端司机室 |
| 交接班 | 司机之间交接列车状态与运行信息的制度 |
| 联控 | 调度、车站、司机之间的行车联系与确认 |
| 知识要求 | 职业技能标准中对应职业功能的知识条目 |
| 闭环 | 作业信息有登记、有交接、有汇报的完整回路 |

**一句话记忆**：司机是「操作列车、组织行车、直接负责安全」的人，作业链条「出勤—整备—驾驶—折返—交接—退勤」闭环，知识地图「规章、车辆、应急、服务」四块。

**延伸**：把职业定义反复读，就读出了司机岗位的底层逻辑——人机结合、统一指挥、直接责任，这三条是理解本专题全部内容的钥匙。

**收束**：职业定义是司机一切知识的原点——回到定义，就回到「为什么做司机」的根本。

## 8 小结

- 列车司机是**操作城轨列车、按规定组织行车、安全正点运送乘客并承担直接责任**的职业。
- 工作任务是一条**从出勤到退勤的闭环链条**：出勤—整备—驾驶—折返—交接—退勤。
- 知识要求分**行车规章、车辆信号、应急安全、服务道德**四块地图。
- 司机与**调度、车站**三方联控、职责互补，共同构成行车组织网络。
- 「会开车」≠「能值乘」：整备、联控、处置、交接都是职业能力的一部分。
