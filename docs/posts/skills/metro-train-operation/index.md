# 城市轨道交通列车司机与运营

城市轨道交通是城市公共交通的骨干，列车司机是保障数百万乘客安全出行的关键岗位。以《城市轨道交通列车司机》职业技能标准为纲，结合交通运输部《城市轨道交通运营管理规定》与《城轨运营安全管理办法》，系统重建从职业准入、车辆设备认知、驾驶操作到行车组织、应急处置的完整能力体系。学完这些章节，就写完了城轨列车司机职业能力与安全运营的全部内容。

## 对标教材

- 交通运输部《城市轨道交通运营管理规定》
- 《城轨运营安全管理办法》
