## 为什么从「车门」讲起

对乘客而言，车门是每天接触最多的列车部件；对司机而言，车门则是**乘降安全的第一道闸门**。夹人夹物、门故障隔离、带门动车——车门相关的事故与险情，在城轨安全事件里占有相当大的比例。<span class="marginnote">把车门系统单独成篇，是因为它处在「人（乘客）—机（列车）—站（站台门）」三者交汇的最危险界面：开关门的顺序、确认、联锁任何一个环节出问题，都可能伤到乘客或引发行车事件。</span>

本节讲清车门系统的结构与联锁逻辑，为第3篇「车门开关与乘客上下车操作」打下系统基础。

## 1 车门类型：塞拉、内藏与外挂

城轨客室车门按开闭方式主要有三类：

**塞拉门**：关门时门扇向车体内侧收拢并压紧，密封性好、外观平整，是当前城轨主流。开门时先外移再侧滑，占用门楣空间小。

**内藏门**：门扇关闭后收纳在车体侧墙内，结构简单，多用于部分早期与轻轨车辆。

**外挂门**：门扇挂在车体外侧，不占用车内空间，但密封与外观略逊，多用于部分市域与低地板车辆。

**无论哪种类型，车门都具备防夹功能**：关门过程中若检测到夹人夹物（阻力异常、防夹开关触发），车门会自动退回重开，多次夹阻后停止动作并报警。<span class="marginnote">防夹不是「万能保险」：它靠检测关门阻力或胶条开关触发，细小物品、衣角、书包带有时检测不到，或触发后仍有夹住风险。所以司机不能把安全完全托付给防夹——开关门时的瞭望与确认，永远是最后一道防线。</span>

## 2 车门控制：集中、本地与隔离

车门控制围绕「谁来决定开、谁来决定关」组织：

**司机室集中控制**：正常运营时，司机在司机室通过车门控制按钮**集中开关全列客室门**，与站台门联动。这是日常运营的主要控制方式。

**本地控制（站台侧）**：司机或站务在站台侧操作，用于协助处理个别车门问题、救援或特殊作业。

**单门隔离**：某扇门故障时，可在司机室显示屏或本地把该门**切除（隔离）**，使其不参与开关动作并保持锁闭，同时做好警示，防止乘客误用。<span class="marginnote">「隔离」是车门故障处置的常用手段，但有代价：被隔离的车门位置乘客无法正常上下，须在站台侧安排引导、必要时广播提示。隔离不是「修好」，而是「让坏门不添乱」——后续仍要报修。</span>

## 3 站台门（屏蔽门/安全门）与联动

沿站台边缘设置的门统称**站台门**：与线路完全封闭隔离的叫**屏蔽门**，半封闭的叫**安全门**。站台门把乘客与轨道隔开，防坠落、防异物、改善环控。<span class="marginnote">屏蔽门（全封闭）常见于地下线，兼有环控节能作用；安全门（半封闭）常见于高架与地面线。无论哪种，站台门与客室门的<strong>联动</strong>都是安全核心：通常「先开站台门，再开客室门；先关客室门，再关站台门」。</span>

**联动逻辑**：正常流程下，列车到站对标停稳、ATP 确认停稳后，司机操作开关门；站台门与客室门按顺序联动开关，司机通过站台/司机室显示屏确认两侧门都开关到位。

**门联锁（发车条件）**是核心安全机制：**必须客室门关好、站台门关好、站台紧急按钮未按、ATP 给出允许**，列车才具备发车条件。任一条件不满足，系统禁止动车或立即制动——这就是「门关好之前列车一步也不能动」的系统实现。

## 4 核心对比表：屏蔽门与安全门

| 维度 | 屏蔽门（全封闭） | 安全门（半封闭） |
| --- | --- | --- |
| 封闭程度 | 与轨道完全隔离 | 半封闭，留有缝隙 |
| 主要作用 | 安全 + 环控节能 | 安全（防坠落、防异物） |
| 常见场景 | 地下站 | 高架、地面站 |
| 对司机瞭望的影响 | 司机室可看站台监控 | 可直接瞭望站台 |

**横向读表**：两种站台门的安全逻辑一致——都是「乘客与轨道之间的物理屏障」，司机作业时都要**确认站台门与客室门联动状态**，区别只在瞭望方式与环控作用。

## 5 司机室界面：门操作与状态监视

司机室的「列车界面」围绕车门操作布置：

**门控按钮**：开关门按钮、门模式选择（集中/切除）、紧急制动相关操作。

**门状态显示**：司机室显示屏逐扇显示每节车每侧门的开关状态，夹阻、故障、隔离都有报警提示。

**站台监控**：配合站台摄像头，司机在司机室即可确认站台侧门状态与站台秩序，弥补「直接瞭望不到」的盲区。<span class="marginnote">司机室界面设计的逻辑是「一屏看全车」：把全列车的门状态、制动状态、故障信息集中呈现，让司机用最短时间掌握全局。学会「扫屏」——快速定位异常条目——是司机的日常基本功，比盯着单块表更实用。</span>

**开关门作业要点**：先确认站台与门状态，再操作开门；关门时确认无夹人夹物、门关闭到位、站台门关闭、发车条件具备后再动车。

## 6 车门常见故障与现场处置

司机在值乘中最常遇到的门相关故障与处置：

**单门无法关闭**：反复关门不落锁或报警，先确认有无夹物、是否异物卡阻；排除后仍关不上，按程序**隔离**该门并通报站务与检修，确认其他门正常后继续运行。

**门无法打开**：到站门打不开，确认停稳与解锁条件，检查门控制与联锁状态；按程序处理，必要时报修。

**防夹反复触发**：反复夹阻报警，先查找原因（乘客、物品、设备），确认安全后重新关门；多次无效要隔离并处理。

**门状态误报**：显示与实际不符（如显示关好实际未关），属于高危险信号——**严禁动车**，立即报告调度处理。<span class="marginnote">门故障处置有一条底线：<strong>门状态不明，就绝不动车</strong>。显示与实际不一致时，司机宁可信「没关好」也不信「应该关好了」——带门动车是城轨最严重的事故类型之一，任何门状态的不确定，都要以停车核实为准。</span>

## 7 辨析｜易错点：防夹功能 ≠ 绝对安全

「门有防夹，夹一下会自动弹开，没事」——这是对车门安全最危险的误读。

**辨析｜易错点：** 防夹功能依赖**阻力或胶条检测**触发，存在检测盲区：细小的衣角、书包带、儿童手指等可能检测不到，或检测滞后；防夹触发后的重开、再关过程本身也有风险。**司机必须把防夹当成「辅助保险」，而不是「安全依据」**——真正的安全，来自关门前的瞭望确认与关门中的状态确认。<span class="marginnote">行业事故复盘常指向同一个根子：把安全托付给单一设备。防夹、门联锁、站台监控都是保险，但最后一道保险永远是司机的确认动作——设备会失效，确认不能失效。</span>

**正确理解**：防夹是「兜底」，确认是「根本」；两者都要，但不能用前者替代后者。

## 8 术语速查表

| 术语 | 含义 |
| --- | --- |
| 塞拉门 | 关门收拢压紧、密封性好的客室门 |
| 内藏门 | 门扇收纳于车体侧墙的门 |
| 外挂门 | 门扇挂于车体外侧的门 |
| 防夹功能 | 关门遇阻自动重开的功能 |
| 集中控制 | 司机室集中开关全列客室门 |
| 单门隔离 | 切除故障门使其退出开关动作 |
| 屏蔽门 | 全封闭的站台门 |
| 安全门 | 半封闭的站台门 |
| 门联锁 | 门未关好禁止动车的安全逻辑 |

**收束**：车门系统的全部知识，最终都汇成一句话——**门，是乘客安全的最后一道物理屏障，也是司机责任最密集的地方**。

## 9 小结

- 客室门主要有**塞拉门、内藏门、外挂门**三类，均具防夹功能，但司机不能全托付给防夹。
- 车门控制分**集中控制、本地控制、单门隔离**三种方式，隔离是故障处置的常用手段。
- 站台门分**屏蔽门与安全门**，与客室门联动，「先开站台门再开客室门、先关客室门再关站台门」。
- **门联锁是发车条件**：门未关好、站台紧急按钮未复位，系统禁止动车。
- 司机室通过**门状态显示与站台监控**实现「一屏看全车」。
- 门故障处置底线：**门状态不明，绝不动车**。
