## 为什么从味觉开始

嗅觉是「主通道」，味觉却是「审判庭」——最终的品质判断、配餐决策、适饮期评估，几乎全部落在口腔里。**味觉采集的不是一种感觉，而是一组并行的测量**：甜度（糖）、酸度（酸）、单宁（涩）、酒体（重量感）、酒精（灼热感）、余味（持续时间）。这六项就是葡萄酒的「结构参数」，就像音色、音高、音量对音乐的意义。

这一节的关键是学会「把口腔感受翻译成可比较的刻度」。单宁的多寡、酸度的高低、酒体的轻重，都能在 1–5 的刻度上描述——**品鉴的标准化，本质上是把这些主观感受锚定到相对刻度上**。<span class="marginnote">「相对刻度」比「绝对刻度」可靠：没有绝对标准告诉你「酸度 3 分是多少」，但同一场里「这款比上一款更酸」是可复现的判断。这就是为什么品鉴强调「对比品」——参照系让主观变客观。</span>

## 1 六大结构参数：一次量一遍

喝一小口，让酒液覆盖舌面与口腔，按顺序「测量」六项：

**甜度（Sweetness）**：舌尖最先感知。注意是「残糖」带来的实际甜，而不是果味带来的「甜感」。区分「含糖」与「果味甜」是初学者第一道坎——干型酒也可能「喝着甜」，那是成熟果香的错觉。

**酸度（Acidity）**：口腔两侧与下方，刺激流口水的程度就是酸度。**酸度越高，分泌唾液越多**。高酸让酒「清新、有活力」；酸度不足则「平板、松弛」。

**单宁（Tannin）**：口腔的「收敛感/涩感」——像喝浓茶后的干涩，来自葡萄皮与橡木。单宁的质量比数量更重要：**细腻的单宁（天鹅绒）vs 粗糙的单宁（刮舌）**。<span class="marginnote">单宁是红葡萄酒的「骨架」：它提供结构、支撑陈年，也负责与食物中的蛋白质「握手」（配餐篇会讲）。判断单宁记住「数量 + 质感」两个维度，而不是只说「涩不涩」。</span>

**酒体（Body）**：酒在口中的「重量感」——像水（轻盈）、像脱脂奶（中等）、像全脂奶（饱满）。酒体由酒精、甘油、糖、单宁共同决定，酒精是最大变量。

**酒精感（Alcohol）**：喉部的灼热与暖意。高酒精（>14%）带来「热感」；低酒精（<12%）更显清爽。酒精还「放大甜感、压住酸感」——所以高酒精酒常显得更「圆」。

**余味（Finish）**：咽下/吐出后风味持续的时间与质感。**余味长（>15 秒）且干净 = 好酒的重要标志**；余味短促或发苦发涩则扣分。

## 2 平衡与结构：把参数合成「判断」

六项参数单独看只是数据，合起来才是「品质」。核心概念是**平衡（Balance）**：

**平衡**指各要素「谁也不压过谁」的和谐状态。红葡萄酒的理想平衡是：**果味能撑住单宁，酸度能托起甜度，酒精不突兀**。失衡的典型例子：单宁太重而果味不足（「空架子」）、酸度过高而果味寡淡（「尖酸」）、酒精过高而酸度不够（「烫嘴的肥硕」）。

**结构（Structure）**则是平衡的「骨架版本」——单宁与酸度是红酒的「梁柱」，果味与酒精是「墙体」。**结构强的酒「站得住」，能承受陈年；结构弱的酒「软塌」，只能早饮。**<span class="marginnote">「平衡 vs 结构」的区分常被混淆：平衡是当下的和谐，结构是耐受时间的骨架。一支年轻的波尔多可能「紧」而「不平衡」，但它结构强、值得等待；一支便宜的果味酒当下很平衡，却没有结构、放两年就散架。</span>

**核心要点：品质判断的第一原则 = 先看平衡，再看结构，最后才谈偏好。** 平衡是客观的和谐，偏好是主观的取向——专业品鉴把两者分开，才不会「因为我不喜欢就判它不好」。

## 3 甜度、酸度、单宁的相互作用

三大「味觉化学」要素不是独立工作的，它们互相调制：

**甜 × 酸**：甜能掩盖酸，酸能削减甜。所以甜酒的「甜而不腻」全靠高酸支撑——托卡伊、苏玳的高残糖必须配高酸，否则只剩甜腻。这也是为什么「酸度是甜酒的生命」。

**单宁 × 果味**：果味（尤其甜果味）能「软化」单宁的涩感。成熟年份的葡萄果味浓，单宁就显得更「融」；生青年份果味不足，同样的单宁就「刮舌」——**单宁的感知硬度，一半来自单宁本身，一半来自果味的掩护**。

**酒精 × 酸度**：酒精放大甜感、压住酸感。因此高酒精低酸酒显得「肥」，低酒精高酸酒显得「瘦」。判断酒体时，这组关系是核心线索。<span class="marginnote">这三组「相互作用」是配餐学的地基：餐酒搭配的本质就是「用食物的某种属性去调制酒的多余参数」——第5篇《餐酒搭配基本原理》将把这套化学关系系统展开。</span>

### 口腔「六项测量」的实操诀窍

把六项结构参数「测量准」，需要几个关键技巧：

**测酸度的诀窍**：咽下后感受「流口水的程度」——口水越多，酸度越高。不要凭「喝起来酸不酸」判断，要凭「身体反应」判断。

**测单宁的诀窍**：用舌尖与上颚「摩擦」感受收敛感——细腻还是粗糙？在口腔前部「刮不刮」是单宁质感的关键。

**测酒体的诀窍**：感受酒的「重量与黏稠度」——像水、像脱脂奶还是像全脂奶？咽下的「滑腻感」是酒体的信号。

**测酒精的诀窍**：注意喉部的「温热感」与鼻腔的「酒精刺激」——高酒精酒的「热感」在吞咽后最明显。

**测甜度的诀窍**：舌尖最先感知甜——注意区分「残糖的甜」与「果味的甜感」。干型酒也可能「喝着甜」，那是成熟果香。

**测余味的诀窍**：咽下后计时——风味持续 5 秒是短、15 秒是长；同时注意余味是「干净」还是「发苦发涩」。

**「六项测量」速查卡**：

| 参数 | 感知位置 | 测量信号 |
| --- | --- | --- |
| 甜度 | 舌尖 | 糖的甜 vs 果味甜感 |
| 酸度 | 两侧+下方 | 流口水的程度 |
| 单宁 | 全口腔 | 收敛感、刮不刮 |
| 酒体 | 口腔整体 | 重量与黏稠度 |
| 酒精 | 喉部+鼻腔 | 温热感与刺激 |
| 余味 | 咽后 | 时长与干净度 |

把这张速查卡贴在脑海里，每次品鉴「按表逐项过」——六项全量一遍，你的「口感数据」就完整了。这也是「先采集、后决策」在味觉环节的落地。

### 从「口感数据」到「风格画像」

六项参数不是孤立的，把它们组合起来，就是一杯酒的「风格画像」：

- **高酸 + 轻酒体 + 低单宁** → 清爽派（雷司令、长相思）。
- **高单宁 + 高酸 + 饱满酒体** → 结构派（赤霞珠、内比奥罗）。
- **低酸 + 高酒精 + 饱满** → 浓郁圆润派（巴罗萨西拉、某些加州酒）。
- **中酸 + 中单宁 + 中酒体** → 均衡派（梅洛、多数混酿）。

**核心要点：风格画像 = 六项参数的「组合指纹」。** 单独一个参数没有意义，组合才定义风格——这就是为什么品鉴要先「逐项采集」再「整体合成」。下次盲品时，先在心里画出这杯酒的「参数雷达图」，再与记忆中的「风格模板」比对，准确率会大幅提升。

## 4 公式解析：单宁涩感的分子机制

「单宁为什么涩」可以精确到分子层面——它是单宁与唾液蛋白「握手」的化学计量：

$$
\ce{Tannin + Protein_{唾液} -> Tannin{-}Protein_{沉淀}}
$$

- **第一步，理解反应物**：单宁（黄烷-3-醇聚合物）带多个酚羟基，唾液中的富脯氨酸蛋白（PRP）提供疏水表面与氢键位点。
- **第二步，理解反应**：两者通过疏水作用与氢键结合，形成不溶性复合物沉淀。**沉淀越多，口腔黏膜上的蛋白质被「抽走」越多，涩感越强。**
- **第三步，理解「质感的差异」**：聚合度高的单宁（老酒、陈年单宁）结合方式更「圆钝」、沉淀更缓慢，涩感细腻；聚合度低的小分子单宁结合快而粗暴，涩感尖锐。
- **第四步，落到品鉴**：这就是为什么「老酒单宁更顺滑」——陈年让单宁聚合变大，反应的「粗暴程度」下降。也是为什么「吃牛排配红酒更顺」——肉中蛋白质与单宁结合，抢走了本该涩你口腔的份额。

这条公式把「涩」从口感变成化学反应，也预告了配餐学的核心机制：**单宁与蛋白质的「抢亲」，是红肉配红酒的化学本质**。<span class="marginnote">这套「分子机制还原」与《食品化学》专题的收敛性成分章节一脉相承——把感官现象还原到分子层面，是「理解式学习」与「死记式学习」的分水岭。</span>

## 5 小结

- 口腔里要「测量」六项：**甜度、酸度、单宁、酒体、酒精感、余味**，各用相对刻度记录。
- 平衡 = 当下的和谐；结构 = 耐受时间的骨架。**先看平衡，再看结构，最后谈偏好**。
- 三组相互作用：甜×酸、单宁×果味、酒精×酸度，构成配餐学的化学地基。
- 单宁涩感 = 单宁与唾液蛋白的结合沉淀；老酒顺滑 = 单宁聚合后反应变钝。
- 味觉是「审判庭」：把主观感受锚定到相对刻度，主观才能变客观。
