## 为什么从酿造开始

我们已走完「土地—品种—农时」，现在走进酒窖。**酿造工艺是风土与品种的「翻译官」**：同样的赤霞珠，过不过橡木桶、浸渍几天、是否苹果酸-乳酸发酵，会酿出风格迥异的酒。对侍酒师而言，理解酿造不止是考 WSET 的需要——它是你向客人解释「这瓶酒为什么是这个味道」的唯一科学依据。

更重要的是，酿造决定了一支酒的**技术身份**：是单一品种还是混酿？是过桶还是不锈钢罐？是早饮还是陈年？这些信息藏在酒标背面，却都源于酿造环节的每一个选择。这一节把静止酒（不含气泡的餐酒）的酿造链路走一遍：**破碎 → 浸渍 → 发酵 → 熟化 → 澄清装瓶**。<span class="marginnote">「静止葡萄酒」的定义是「不含明显气泡的葡萄酒」，与起泡酒相对。香槟是起泡酒，而它的基酒酿造流程几乎与本节完全一致——理解了静止酒，起泡酒只需在最后加一步「二次发酵」。</span>

## 1 从破碎到发酵：浸渍与酵母的主场

**第一步，破碎（crushing）**：把葡萄压破，让果汁（must，葡萄醪）与果皮、果肉、种子接触。白葡萄通常立即压榨分离，红葡萄则带着果皮一起发酵——**这「带不带皮」的差异，是红白葡萄酒分野的第一道分水岭**。

**第二步，浸渍（maceration）**：红葡萄在发酵期间或发酵前，让果皮与果汁长时间接触，萃取颜色、单宁与风味物质。浸渍时间越长、温度越高，萃取越充分。这就是为什么赤霞珠颜色深邃、黑皮诺却浅淡——除了皮厚差异，浸渍策略也参与塑造。

**第三步，发酵（fermentation）**：酵母把糖转化为酒精与二氧化碳。关键变量有两个：

**发酵温度**：白葡萄酒多在 12–18 ℃ 低温发酵，保住花香与果香；红葡萄酒常在 25–30 ℃ 高温发酵，萃取充分、结构更强。
**酵母选择**：野生酵母（native yeast）风味复杂但风险高；商业酵母（cultured yeast）稳定可控。是否用野生酵母，是「自然酒」与主流酒庄的分野之一。<span class="marginnote">发酵是「糖→酒精+CO₂」的化学转化，与上一节「约 17 g/L 糖产 1% 酒精」的换算直接对接。发酵停止时剩多少糖，就决定了酒是干型还是甜型。</span>

## 2 苹果酸-乳酸发酵与熟化：从锐利到圆润

红葡萄酒以及多数优质白葡萄酒，会经历第二道关键工序——**苹果酸-乳酸发酵（Malolactic Fermentation, MLF）**。

**MLF 的本质**：由乳酸菌把尖锐的**苹果酸**（malic acid）转化为柔和的**乳酸**（lactic acid），同时释放出黄油般的双乙酰。**结果是酸度下降、口感变圆润、带奶油与榛子气息**。

**核心要点：MLF 是「口感软化器」，但代价是酸度。** 霞多丽过桶风格那标志性的黄油香，一半来自 MLF；而夏布利、雷司令强调清爽高酸，就会刻意阻止 MLF——同样是白葡萄酒，是否做 MLF 往往是「圆润派」与「清爽派」的技术分界。<span class="marginnote">对侍酒师的启示：点酒时「这酒喝起来带黄油味」不等于「加过奶油」，而是 MLF 的化学结果。向客人科普这点，专业感立刻拉满。</span>

**熟化（maturation / aging）**：发酵结束后，酒进入熟化期，接触的容器决定风格：

| 容器 | 作用 | 典型使用者 |
| --- | --- | --- |
| 新橡木桶 | 强桶味（香草、烘烤、烟熏），微氧化 | 纳帕赤霞珠、波尔多列级庄 |
| 旧橡木桶 | 几乎无桶味，只提供微氧化 | 勃艮第多数酒庄 |
| 不锈钢罐 | 无木味，保留清新果味 | 夏布利、新世界入门款 |
| 水泥罐/陶罐 | 无木味、微氧化，保留矿物感 | 自然酒庄、格鲁吉亚传统 |

熟化时间从几个月（多数亲民白）到数年（顶级红）不等。**时间不是越长越好**：单宁与酸度不足的酒，陈酿过久会「散架」；结构足够强的酒，才能越陈越醇。

## 3 混酿、澄清与装瓶：把决定权交给最后一步

**混酿（blending）**：多数名庄酒不是单一品种，而是把不同地块、不同品种、甚至不同年份（无年份酒）的基酒调配。混酿的目的有三：**补足缺陷（结构、酸度）、增加复杂度、保持风格一致性**。波尔多的赤霞珠-梅洛混酿是补结构的经典；香槟的无年份调配则是「保持一致风格」的极致。

**澄清（fining）与过滤（filtration）**：装瓶前去除酒中悬浮颗粒。传统上会用蛋清、鱼胶、膨润土等澄清剂；有些酒庄选择「不过滤」以保留更多风味与质感——但代价是酒中可能出现沉淀，需要侍酒师滗酒处理（见第4篇《开瓶、倒酒与醒酒》）。<span class="marginnote">「不过滤」是自然酒运动的标志之一，但它与「酒质差」不能画等号。一瓶有沉淀的酒，可能只是「未经澄清」，风味未必受损——反而是耐陈年的证据。</span>

**装瓶（bottling）**：装瓶方式（真空、惰性气体保护）与瓶塞（软木塞、螺旋盖、合成塞）影响酒与氧气的接触。螺旋盖并非廉价标志——澳洲与新西兰相当多的顶级雷司令、长相思用螺旋盖，恰恰是为了保住新鲜果味。

### 酿造工艺的「看酒标读法」

酿造信息藏在酒标与背标里，会读的人能「隔瓶看工艺」：

**看「品种与混酿」**：单一品种酒 = 品种表达；混酿酒 = 互补逻辑（波尔多式混酿、GSM 混酿各有配方逻辑）。

**看「产区与法规」**：法定产区（AOC/DOC）对酿造有约束——香槟必须传统法、卡瓦可以罐式法；产区法规本身就透露了工艺。

**看「背标关键词」**：

- **「橡木桶陈酿」（Barrel Aged / Élevage en fût）**：提示有桶味——再细看「新桶比例」，新桶越多桶味越重。
- **「苹果酸-乳酸发酵」（Malolactic）**：提示黄油/奶香与圆润口感。
- **「自然酒 / 低干预」（Natural / Low Intervention）**：提示野生酵母、不过滤、可能有沉淀。
- **「有机 / 生物动力」（Organic / Biodynamic）**：提示葡萄园管理方式，影响风格方向。
- **「不澄清不过滤」（Unfined / Unfiltered）**：提示保留更多质感，可能有沉淀。

**「酿造—风格」对照速查表**：

| 酿造决策 | 结果风格 | 典型酒 |
| --- | --- | --- |
| 长时间浸渍 | 颜色深、单宁强 | 纳帕赤霞珠 |
| 短浸渍/整串发酵 | 颜色浅、细腻 | 部分黑皮诺 |
| 新橡木桶陈酿 | 香草、烘烤、桶味重 | 波尔多列级庄 |
| 旧桶/不锈钢 | 果味纯净、无木味 | 夏布利、雷司令 |
| 做 MLF | 圆润、黄油香 | 过桶霞多丽 |
| 不做 MLF | 高酸、清爽 | 夏布利、多数雷司令 |

**核心心法：酿造是「翻译」，不是「创作」**——它把风土与品种「翻译」成杯中风格，但翻译有「意译」与「直译」之分：意译（重工艺）让酒更「像酿酒师」，直译（轻干预）让酒更「像土地」。读懂酒标上的工艺线索，你就能判断面前这瓶酒是「翻译派」还是「直译派」。

### 从工艺到品鉴：两个「可反推」的例子

**例一**：一杯颜色深紫、单宁紧致、带明显香草烘烤味的赤霞珠——反推工艺：长时间浸渍 + 新橡木桶。你不需要看酒标就能说出它的大致酿造。

**例二**：一杯颜色浅、香气清新、带青苹果与矿物感的白葡萄酒——反推工艺：低温不锈钢罐 + 不做 MLF。它几乎可以锁定为「清爽派」白葡萄酒（夏布利或新世界雷司令）。

这两个例子说明：**工艺知识不是「死记」，而是「反推」的工具**——把品鉴观察到的手段译回工艺，你的盲品与推荐能力会上一个台阶。这与品鉴篇「先采集、后决策」的原则一脉相承。

## 4 公式解析：单宁萃取的浓度方程

浸渍与发酵是把「果皮里的东西搬进酒里」，可以用一个萃取浓度模型理解：

$$
C(t) = C_{\max}\left(1 - e^{-k t}\right)
$$

- **第一步，理解 $C_{\max}$**：果皮中可萃取的色素与单宁的「总量上限」——由品种（皮厚）与年份（成熟度）决定。
- **第二步，理解 $k$**：萃取速率常数，与温度、搅动（pumping over，压帽）强度正相关。温度越高、翻搅越勤，$k$ 越大，萃取越快。
- **第三步，理解 $e^{-kt}$**：它让浓度随时间**先快后慢**地逼近上限——萃取前期效率高，后期逐渐饱和。这就是为什么「浸渍两三天」与「浸渍三周」的差距，远大于「三周」与「六周」的差距。
- **第四步，理解选择**：酿酒师想「快萃」就高温多翻（新世界浓郁派），想「慢萃」就低温少动（旧世界优雅派）；想「极轻」就整串发酵减少皮汁接触（部分黑皮诺）。**公式里的 $k$，正是酿酒师的风格旋钮**。

这条公式把「浸渍时间—温度—萃取量」三者的关系量化，也解释了陈年酒为什么单宁更「融」——瓶中岁月让单宁聚合，有效单宁浓度随陈年下降。<span class="marginnote">陈年让单宁从「涩」变「柔」，本质是单宁分子聚合变大、失去与唾液蛋白结合的粗糙表面。这就是「老酒单宁更顺滑」的化学机制，也是第3篇《味觉与口感》的预告。</span>

## 5 小结

- 酿造链路：**破碎 → 浸渍 → 发酵 → MLF → 熟化 → 澄清装瓶**；红白分野的起点在「带不带皮」。
- 浸渍时间与温度决定颜色、单宁与风味的萃取量，是酿酒师的第一风格旋钮。
- **MLF 把苹果酸变乳酸**，口感从锐利变圆润、并带来黄油香；追求清爽的酒会刻意不做。
- 熟化容器（新橡木桶/旧桶/不锈钢/陶罐）决定「桶味」与「氧化程度」两条风格轴。
- 混酿、澄清、瓶塞都是「最后一步的决择」，每一处都藏着风格与商业的双重考量。
