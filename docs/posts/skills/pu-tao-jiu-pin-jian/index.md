# 葡萄酒品鉴与侍酒

以《侍酒师专业手册》、WSET 葡萄酒认证体系与《葡萄酒品鉴》为纲，系统建立从葡萄品种、世界产区、酿造工艺到品鉴步骤、侍酒服务与餐酒搭配的完整能力链。学完这些章节，就写完了从入门到专业侍酒师应掌握的核心理论、品鉴方法与服务技能。
