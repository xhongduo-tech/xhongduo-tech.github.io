## 为什么先要一张「锻造家族谱」

上一课认识了锻造工这个职业，这一课要给**锻造本身**画一张分类地图：锻造不是一种方法，而是一个「家族」——自由锻、模锻、胎膜锻各有各的本领，热锻、温锻、冷锻各有各的适用场景。<span class="marginnote">分类学的价值在于「按需取用」：拿到一张零件图，先判断它适合自由锻还是模锻、该热锻还是冷锻——这一步选错，后面全盘皆输。本专题后续每一课，都是这张分类地图上某一支的展开。</span>

本课先把锻造放进金属成形加工的坐标系，再按两条轴线给锻造方法分类。

## 1 锻造在金属成形中的位置

金属零件成形，主要有**四大基本工艺**：铸造、塑性加工（锻造与轧制）、焊接、粉末冶金。锻造属于**塑性加工（plastic working）**一支——靠金属在固态下的塑性流动成形。

与其他成形方式相比，锻造的独特性在于：

**组织致密**：锻造压力压实内部疏松、气孔，消除铸态缺陷。<span class="marginnote">所以飞机机身框梁、汽车曲轴连杆、火电转子等承受交变载荷的关键件几乎全部用锻件。锻造的代价是材料利用率低（有余量、有飞边）、模具投入大——这正是「自由锻 vs 模锻」要权衡的问题。</span>
**流线合理**：金属流线沿锻件轮廓分布，受力方向与流线一致时强度最高。
**综合力学性能好**：锻造件的强度、韧性、疲劳性能普遍优于铸造件与焊接件。

锻造与轧制、挤压的区别在设备与变形方式，但同属塑性加工——理解了锻造，就理解了整个塑性加工的半壁江山。

## 2 按成形方式分类

这是锻造最核心的分类，直接对应本专题第 2、3 篇的内容安排。

**自由锻（free forging）**：不用专用模具，坯料在砧面（平砧、型砧）之间自由变形，形状靠操作者的技艺控制。它灵活、通用、投入小，适合单件小批与大型锻件，但精度低、生产效率低、依赖工人技艺。<span class="marginnote">自由锻是「铁匠的艺术」：锻锤的力量 + 工人的手法 = 锻件形状。钢锭开坯、大型轴类、法兰、环件都靠自由锻，是重型机械制造的看家本领。</span>

**模锻（die forging）**：坯料在专用锻模的模膛内成形，上下模对合，金属被强迫挤入模膛。精度高、效率高、适合大批量，但模具设计与制造投入大，改型就要改模。<span class="marginnote">模锻是「模具的艺术」：把形状刻进模具，成千上万件锻件复制同一个形状。汽车曲轴、连杆、转向节都是模锻的典型产品。</span>

**胎膜锻（loose tool forging）**：介于自由锻与模锻之间——用简单的活动胎膜（不固定在设备上）约束坯料成形，胎膜随用随换。投入比模锻小，精度比自由锻高，适合中批量复杂件。

## 3 按加热温度分类

另一条重要分类轴是**变形温度**，按再结晶温度区分：

**热锻（hot forging）**：在再结晶温度以上锻造，变形与再结晶同时进行，金属抗力低、塑性好，能锻大变形量与复杂形状，是锻造的主力。碳钢始锻温度通常 1150～1250 ℃，终锻温度 750～850 ℃。

**温锻（warm forging）**：在室温与再结晶温度之间锻造，兼有冷锻的精度与热锻的塑性，氧化少、精度高，但变形抗力仍较大。

**冷锻（cold forging）**：在室温下锻造，精度最高、表面质量最好、材料利用率高，但变形抗力大、只能锻小型简单件，且存在加工硬化。<span class="marginnote">温度是锻造分类的分水岭：热锻成形能力强但精度低，冷锻精度高但变形受限，温锻是两者的折中。本专题以热锻为主线，冷锻与温锻的知识在《精密模锻与特种锻造方法》一课再展开。</span>

## 4 锻造工艺的典型流程

无论哪种锻造方法，生产流程都遵循同一骨架：

**下料 → 加热 → 成形（锻打/模锻） → 切边（模锻） → 热处理 → 清理 → 检验**

其中**加热**与**成形**是锻造的「灵魂」工序，本专题用大量篇幅展开；**热处理**与**检验**则与《锻件质量检验方法与无损检测》一课呼应。<span class="marginnote">记住这条流程，就记住了锻造车间的布局逻辑：加热炉在锻锤旁边，切边机紧随其后，热处理炉在末端——物料沿流程单向流动，省力又安全。</span>

## 5 核心对比表：三种主要锻造方法

| 项目 | 自由锻 | 模锻 | 胎膜锻 |
| --- | --- | --- | --- |
| 模具 | 无（平砧/型砧） | 专用锻模 | 简单活动胎膜 |
| 成形控制 | 靠操作技艺 | 靠模膛 | 靠胎膜+操作 |
| 尺寸精度 | 低 | 高 | 中 |
| 生产率 | 低 | 高 | 中 |
| 模具投入 | 几乎为零 | 大 | 小 |
| 适用批量 | 单件/小批 | 大批量 | 小批/中批 |
| 典型产品 | 大轴、法兰、开坯 | 曲轴、连杆、齿轮 | 中批量复杂件 |

三者的关系不是「谁取代谁」，而是**按批量、精度、尺寸三把尺子选型**：大件单件选自由锻，中批选胎膜锻，大批量选模锻。

## 6 现场操作要点

把本课知识压缩成几条可带上车间的操作要点，读一遍、记一遍：

- 锻造三大法：自由锻靠技艺、模锻靠模具、胎膜锻是折中。
- 温度三分类：热锻成形强、冷锻精度高、温锻是折中。
- 选方法三问：批量大不大？精度要求高不高？锻件大不大？
- 记住流程骨架：下料→加热→成形→切边→热处理→清理→检验。

## 7 术语速查表

本课核心术语一览：

| 术语 | 释义 | 本课要点 |
| --- | --- | --- |
| 塑性加工 | 固态塑性流动成形 | 锻造、轧制、挤压同属 |
| 自由锻 | 不用专用模具的锻造 | 靠操作技艺、单件小批 |
| 模锻 | 模膛内成形的锻造 | 精度高、大批量、模具贵 |
| 胎膜锻 | 用活动胎膜约束的锻造 | 介于自由锻与模锻之间 |
| 热锻 | 再结晶温度以上锻造 | 主力工艺、抗力低塑性好 |
| 温锻 | 室温与再结晶温度之间 | 精度与塑性的折中 |
| 冷锻 | 室温锻造 | 精度高、只适合小型件 |
| 再结晶温度 | 畸变晶粒被新晶粒取代的温度 | 热锻冷锻的分界线 |

## 8 辨析｜易错点

本课最容易混淆的地方，集中辨析：

- 自由锻 ≠ 没有约束：自由锻也有型砧、剁刀、摔子等工具，只是没有固定在设备上的专用模膛，别把「自由」理解成「乱打」。
- 胎膜锻不是模锻：胎膜不固定在设备上、随用随换，是自由锻的「升级工具」，不是完整的专用锻模——成本和精度都介于两者之间。
- 热锻冷锻的界限是再结晶温度：不是「烧红了的都是热锻」，温锻也是加热的但温度低于再结晶温度——区分要看再结晶线，不是看「热不热」。
- 锻造与铸造不冲突：锻造是固态成形、铸造是液态浇注，同一零件毛坯可能两种工艺都行，但组织与性能完全不同，关键受力件优先选锻件。

## M 小结

- 锻造是**塑性加工**的核心工艺，靠固态塑性流动成形，组织致密、流线合理、综合性能好。
- 按成形方式分**自由锻、模锻、胎膜锻**三种，按温度分**热锻、温锻、冷锻**三类。
- 三种成形方法按**批量、精度、尺寸**选型：大件单件自由锻，中批胎膜锻，大批量模锻。
- 锻造生产流程骨架：**下料 → 加热 → 成形 → 切边 → 热处理 → 清理 → 检验**。
- 本专题主线是热锻：先自由锻后模锻，胎膜锻是承上启下的折中。
- 分类不是死板标签：同一锻件常要「自由锻制坯 + 模锻成形」组合使用，方法之间可衔接、可嵌套。
- 锻造方法的选择权在工艺员手里，锻造工的职责是吃透每种方法的「脾气」，按图施工。
