# 锻造工（锻造操作技能）

锻造工是以自由锻、模锻、胎膜锻等方式对金属坯料加热并锻压成型的机械制造核心技能，广泛服务于汽车、航空航天、重机与模具等行业，是成形加工中不可替代的基础工种。以《锻造工艺学》为纲，配合《锻工手册》与《国家职业技能标准—锻造工》，学完这些章节，就写完了从金属加热、锻造成型到锻件质量检验的完整锻造操作链条。
