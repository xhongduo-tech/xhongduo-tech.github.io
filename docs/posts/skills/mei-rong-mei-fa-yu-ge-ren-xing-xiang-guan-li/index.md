# 美容美发与个人形象管理

美容美发与个人形象管理是覆盖皮肤护理、日常化妆、发型打理与整体形象塑造的实用生活技能学科，直接关系到个人外在气质与职业形象。以《美容师国家职业技能标准》《美发师国家职业技能标准》与《美容师国家职业资格培训教程》为纲，系统重建从皮肤护理、化妆造型、美发技艺到整体形象管理的完整知识体系。

## 对标教材

- 《美容师国家职业技能标准》
- 《美发师国家职业技能标准》
- 《美容师国家职业资格培训教程》
