# 家用 NAS 与私有云搭建

从选购硬件到落地私有云，系统掌握 NAS 机型的选型逻辑、硬盘阵列与存储规划、系统部署与基础服务、远程访问与网络安全，最终建立一套可靠的数据备份与灾难恢复方案。学完这些章节，就能独立搭建并长期运维自己的家用数据中心。
