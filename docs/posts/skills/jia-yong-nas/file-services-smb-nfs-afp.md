## 为什么从文件协议开始

共享文件夹建好了，下一步是让手机、Windows 电脑、Mac、Linux 机器都能访问它。NAS 通过**文件服务协议**把共享暴露给网络——而不同系统「说」的协议不一样。搞懂 SMB、NFS、AFP 是什么、各自服务谁，是「让全家人顺利连上 NAS」的最后一公里。<span class="marginnote">文件协议是《计算机网络》应用层的经典案例：协议 = 网络上双方交换数据的「语法 + 语义约定」。理解了 SMB 这类协议的设计动机（让一个程序在异构系统间透明地读写文件），也就理解了应用层协议的一般形态。</span>

## 1 SMB：Windows 世界的通用语言

**SMB（Server Message Block，服务器消息块协议）**：最早由微软主导、用于在局域网内共享文件与打印机的协议，现代版本是 **SMB3**（Windows 10/11、macOS、Linux 均已原生支持）。<span class="marginnote">SMB 的发展史是一部「协议兼容」的教科书：从 IBM 提出、微软发扬光大，到 CIFS（Common Internet File System）作为 SMB1 的通俗名称，再到 SMB2/3 的重写与安全加固。今天家用 NAS 用 SMB3，安全性与性能都已成熟。</span>

SMB 的特点：

**平台覆盖最广**：Windows 原生支持，macOS、Linux、Android/iOS 也都能连，是家用 NAS 的「默认协议」。
**挂载即用**：在 Windows 里「映射网络驱动器」、Mac 里「连接服务器」输入 `smb://NAS地址/共享名` 即可访问。
- **功能完整**：支持权限（复用共享文件夹权限）、文件锁定、缓存等。

家用几乎可以只开 SMB——它解决了 90% 的访问需求。

## 2 NFS 与 AFP：其他世界的方言

**NFS（Network File System，网络文件系统）**：由 Sun 开发、Unix/Linux 世界的经典协议，用于 Unix 主机之间共享文件。

- 优势：在 Linux/Unix 生态里性能好、成熟稳定；服务器与 Linux 客户端之间无许可证成本。
- 家用场景：适合「Linux 机器 → NAS」的挂载，或 TrueNAS/DIY 用户之间的文件共享；Windows 对 NFS 支持较弱。

**AFP（Apple Filing Protocol，苹果归档协议）**：苹果的专有文件共享协议，macOS 的「老本行」。

- 历史地位：当年 Mac 访问文件服务器的主力协议。
- 现状：现代 macOS 已原生支持 SMB，且苹果官方**推荐优先使用 SMB**；AFP 逐渐退居幕后，新款 NAS 系统仍保留兼容但已非首选。

**辨析｜易错点：不要「什么协议都开、开到最大」。** 每个开启的服务都是暴露在网络上的一个攻击面（见第 4 篇网络安全基线）。家用建议只开 **SMB（默认）+ 按需开 NFS**，用不到的协议（如 AFP、FTP）一律关闭，从源头减少风险面。<span class="marginnote">「默认最小化」是系统安全的第一习惯：不开的服务不存在漏洞。NAS 厂商默认会开启一串协议，装完系统后花五分钟关掉不用的，是成本最低的安全升级。</span>

## 3 挂载与访问：把共享接进系统

「挂载（Mount）」就是把远端共享接进本地文件系统，让本地程序像访问本地磁盘一样访问 NAS。三大平台的典型操作：

- **Windows**：「此电脑 → 映射网络驱动器」→ 输入 `\\NAS地址\共享名`，输入 NAS 账号密码，重启后仍可自动重连。
- **macOS**：Finder →「前往 → 连接服务器」→ 输入 `smb://NAS地址/共享名`，可加入「登录项」实现开机自动挂载。
- **Linux**：命令行挂载 `mount -t cifs //NAS地址/共享名 /mnt/nas -o username=xxx`，或写入 `/etc/fstab` 实现开机自动挂载。

挂载后的三个实用技巧：

1. **用 IP 还是主机名**：局域网建议用主机名/固定 IP（在路由器里给 NAS 绑定固定 IP，避免 DHCP 变更导致连接中断）。
2. **速度验证**：挂载后复制一个大文件测速，千兆网络应达到 100 MB/s 上下——明显偏低则排查网线与协议版本。
3. **凭据安全**：Windows 记住的 NAS 密码以凭据形式保存，公共电脑上不要勾选「记住凭据」。

## 4 核心对比表：三大协议

本篇的核心对比表如下（纯概念主题，以表格替代公式解析）：

| 协议 | 出身 | 最佳客户端 | 家用定位 |
| --- | --- | --- | --- |
| SMB | 微软 | Windows/macOS/Linux/手机 | 默认主力 |
| NFS | Sun/Unix | Linux/Unix | Linux 生态按需开 |
| AFP | 苹果 | 老 Mac | 已退役，默认关 |
| FTP/SFTP | 通用 | 浏览器/下载工具 | 不推荐（明文/冗余） |

从表里能读出结论：**家用只需 SMB 打底，NFS 留给 Linux，AFP 与 FTP 一律关闭**——协议越少，攻击面越小。

## 5 小结

- **SMB** 是平台覆盖最广的协议，家用 NAS 的默认选择，Windows/macOS/手机都能连。
- **NFS** 服务 Linux/Unix 生态，按需开启；**AFP** 已让位给 SMB，默认关闭。
- 挂载三平台各有入口：Windows 映射驱动器、macOS 连接服务器、Linux 用 `mount`/`fstab`。
- 主机名 + 固定 IP 让连接稳定；挂载后测速验证链路健康。
- **只开用得着的协议**，是成本最低的安全基线。
