# 家政保洁与收纳整理服务

家庭深度保洁、收纳整理与熨烫养护是家政服务业的核心技能，也是现代家庭高品质生活的刚需。以《家政服务员国家职业技能标准》《保洁服务规范》与《收纳整理师职业技能》为纲，系统覆盖从职业规范、深度保洁、空间收纳整理到专项服务与经营管理的完整技能体系。
