# 编织工艺（棒针/钩针/中国结）

编织工艺是以线材为载体、以针法与结法为核心的手工造型技艺，涵盖棒针编织、钩针编织与中国结艺三大体系，部分项目（如中国结、传统竹编草编）属非物质文化遗产。以《棒针编织基础》《钩针编织基础》与《中国结艺》丛书为纲，系统重建从工具线材、基础针法、花样编织到非遗传统技艺与作品应用的完整知识框架。

## 对标教材

- 《棒针编织基础》
- 《钩针编织基础》
- 《中国结艺》丛书（含基础结法、盘长结、组合造型等分册）
- 非遗传统编织技艺项目（中国结、竹编、草编、绳结技艺等）
