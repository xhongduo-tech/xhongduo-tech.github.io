## 为什么排泄照护最见功力

排泄是老人最私密、最羞耻、也最容易被粗暴对待的领域。一句「又尿了，真麻烦」能击碎老人最后的自尊；而一次不规范的便盆使用或长期不更换失禁垫，则是皮肤浸渍、压疮、尿路感染的温床。**排泄照护做得好不好，直接衡量一个照护者的专业与人格**。本节讲清排便、排尿两大类照护，以及失禁这一最常见问题的系统管理。<span class="marginnote">老年失禁非常普遍——社区老人尿失禁患病率可达 20%–40%，<strong>失禁不是「懒」也不是「退行没救」，而是可以评估、可以管理、可以部分改善的健康问题</strong>。</span>

## 1 排便照护：从便盆到协助如厕

**能下床者**：鼓励坐马桶或床旁便椅排便——坐位利用重力，比卧位更符合生理、更省力。房间保持私密，门关好，尽量不催促。

**卧床者**：使用便盆。操作要领：
- 先向老人说明，拉好屏风/关门，保护隐私。
- 协助侧卧，将便盆开口朝臀部方向放置，再协助翻回仰卧；或抬高臀部垫入便盆。
- 排空后，及时撤走便盆并盖上，避免气味与暴露；用温水清洗肛周并擦干。
- 便盆每日清洗消毒；观察大便性状（次数、颜色、软硬、有无血），异常记录并报告。

**便秘护理**：老年人肠蠕动减慢，加之活动少、饮水不足、药物影响，便秘高发。日常预防：晨起一杯温水、规律进食粗纤维（蔬菜、水果）、定时如厕训练（每天固定时间坐便，即使无便意）、腹部顺时针按摩、必要时遵医嘱用药——**切忌长期自行使用刺激性泻药**。

## 2 排尿照护与尿失禁管理

**排尿观察**：记录排尿次数、量、颜色、有无尿痛尿急。尿色深、尿量骤减、发热，警惕尿路感染或脱水。

**尿失禁分类**（护理意义在于区分类型）：<span class="marginnote">分型是照护的起点：<strong>先判断「漏尿是哪种」，再决定「练盆底肌还是练膀胱」</strong>——用错方法，越练越糟。</span>
- **压力性尿失禁**：咳嗽、打喷嚏、大笑时漏尿——多见于女性盆底肌松弛。
- **急迫性尿失禁**：尿意一来就憋不住——与膀胱过度活动相关。
- **充盈性/溢出性**：膀胱排空不全，少量尿液持续渗出——警惕前列腺增生或神经病变。

**护理要点**：定时提醒如厕（白天每 2–3 小时主动询问一次）、睡前减少饮水、膀胱训练（憋尿到固定间隔）、盆底肌锻炼（凯格尔运动）。对卧床者，使用合适的失禁垫与隔尿垫并**勤更换、勤清洗、勤检查皮肤**。

## 3 公式解析：液体出入量的记录

失禁与脱水管理的共同基础，是**记录出入量（Input/Output, I/O）**：

$$V_{in} = V_{out} + \Delta V_{body}$$

- **$V_{in}$**：24 小时总入量（饮水量 + 食物含水 + 静脉输液量）。
- **$V_{out}$**：24 小时总出量（尿量 + 大便水分 + 汗液 + 呼吸蒸发等隐性失水）。
- **$\Delta V_{body}$**：体内水分的净变化——正值代表储水（水肿），负值代表失水。

**实践简化**：家庭中主要记录「饮水毫升数」与「排尿毫升数/次数」。正常成人每日尿量约 1000–2000 mL；**24 小时尿量 < 400 mL 或 > 2500 mL 属异常**，应及时就医。对失禁老人，可用成人尿不湿称重粗略估算：湿尿布称重减去干尿布重量，1 克 ≈ 1 mL 尿量。**出入量连续记录能最早发现脱水与肾损伤信号**——这是医生最看重的家庭数据之一。

## 4 核心对比表：两种尿失禁的照护策略

| 项目 | 压力性尿失禁 | 急迫性尿失禁 |
| --- | --- | --- |
| 诱因 | 咳嗽、提重、大笑 | 尿意急促、不受控 |
| 常见人群 | 女性、盆底肌松弛 | 老人、膀胱过度活动 |
| 首要训练 | 盆底肌锻炼（凯格尔） | 膀胱训练、定时排尿 |
| 饮水策略 | 正常饮水 | 睡前减少、少量多次 |
| 必要时 | 盆底康复、专科就诊 | 药物、行为治疗 |
| 皮肤护理 | 保持干爽 | 保持干爽、防浸渍 |

## 5 便秘的家庭管理与用药原则

老年便秘要「先生活，后药物」——顺序错了，越治越依赖。

**生活干预先行**：
- **晨起一杯温水**：空腹温水刺激肠蠕动，是最便宜的「通便剂」。
- **足量纤维与饮水**：蔬菜水果粗粮，饮水 1500 mL 以上；纤维与水分必须同补，只补纤维不补水反而加重便秘。
- **定时如厕**：每天固定时间坐便 5–10 分钟，即使无便意也试——建立「排便生物钟」。
- **腹部按摩**：顺时针（升结肠→横结肠→降结肠）轻揉，饭后进行。
- **适量活动**：能走则走，卧床者做下肢被动运动，促进肠蠕动。

**用药原则**：
- 首选温和的**容积性/渗透性**通便药（如乳果糖），遵医嘱。
- **避免长期依赖刺激性泻药**（番泻叶、酚酞类）——越用越不蠕动，形成「泻药依赖」。
- 连续 3 天未排便伴腹胀腹痛，或大便带血，及时就医，排查梗阻。

## 6 失禁的皮肤保护与卫生管理

失禁老人的第一大并发症不是失禁本身，而是**皮肤浸渍导致的破损与压疮**。

- **及时更换**：失禁后尽快清洁更换，不「攒到点」再处理；夜间可用高吸收性失禁垫。
- **清洁手法**：温水（37–40℃）蘸洗，由前向后，不用刺激性肥皂；洗后轻按吸干，不来回搓。
- **隔离保护**：皮肤干后涂**护臀霜/皮肤保护霜**形成隔离膜；潮湿处保持干燥，必要时用氧化锌软膏。
- **观察皮肤**：每次更换查看臀沟、会阴、大腿内侧有无发红破溃——发红不消退即预警压疮。
- **气味管理**：及时处理 + 开窗通风，保持房间无异味，护住老人尊严。

**一句话**：失禁照护的目标不是「不让漏」，而是「漏了也干净、皮肤不受伤」。

## 7 排泄护理的记录与沟通

排泄记录是评估老人状态的重要窗口，别嫌麻烦：

- **记什么**：排便（次数、性状、颜色、有无血）、排尿（次数、量、失禁次数）、食欲与饮水。
- **记多久**：至少连续记 1–2 周，形成基线；异常时加密。
- **看什么**：突然的便秘/腹泻、大便变黑（警惕消化道出血）、尿痛尿频（尿路感染）、尿量骤减。
- **沟通什么**：就医时把记录带给医生，比「大概挺好」有用得多。

**一句话**：排泄记录是「身体的下水管道图」——按时记录，异常一目了然。

## 8 失禁照护的心理支持

失禁对老人是「尊严重创」——从「体面的人」变成「尿裤子的人」，羞耻感比身体不适更伤：

- **不羞辱、不调侃**：一次「怎么又尿了」的抱怨，足以让老人从此拒绝喝水、拒绝起身——照护者的态度就是失禁的「第一剂药」。
- **正常化处理**：用「这是常见的老化问题，我们一起管好它」的坦然，帮老人卸下羞耻。
- **保护自主**：让老人参与决策（选失禁垫、定如厕提醒时间），重建掌控感。
- **创造安全**：白天主动提醒如厕、夜间床边备便盆，减少「来不及」的挫败。
- **鼓励就医**：失禁有时可改善（盆底训练、膀胱训练、对症治疗），鼓励老人就医评估，不要「认命」。

**一句话**：失禁照护护的是「皮肤」也是「心」——态度对了，失禁就少了一半的心理负担。

## 9 小结

- 排泄照护以**隐私、从容、清洁**为三原则，便盆使用要规范、不催促。
- 便秘预防靠**饮水、纤维、定时如厕、腹部按摩**，勿滥用刺激性泻药。
- 尿失禁先分型：压力性练盆底肌，急迫性练膀胱，充盈性查原因。
- 出入量记录 $V_{in} = V_{out} + \Delta V_{body}$，尿量异常（<400 mL 或 >2500 mL/24h）及时就医。
- 失禁垫勤换勤洗，皮肤保持干爽是防压疮的底线。
- 便秘「先生活后药物」：晨起温水、纤维补水同补、定时如厕、避免泻药依赖。
- 失禁皮肤保护「及时换、温水洗、护臀霜隔离、勤观察」。
- 排泄记录至少连记 1–2 周，异常如黑便、尿痛尿量变化及时就医。
