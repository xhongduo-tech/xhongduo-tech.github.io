## 为什么从排水安装开始

给水是「把水请进来」，排水是「把水送出去」。排水系统靠**重力与坡度**工作，没有压力帮忙，所以它的每一分合格都来自**坡度、管径、连接方式**三者的精确配合。排水管安装看着比给水粗放，实则容错率更低：坡度不够，水流不动；连接太急，水流翻涌；立管不畅，全楼返味。这一节以 PVC-U 排水管为主线，讲清室内排水管道的安装逻辑与验收要点。<span class="marginnote">排水系统的检验靠两道「水」的考试：灌水试验考接口不漏，通球试验考管路畅通。两道都过了，排水才算合格——这两道考试在后面试压篇会系统展开。</span>

## 1 排水系统的组成与管材

室内排水系统收集三类水：**生活污水**（马桶）、**生活废水**（洗涤）、**雨水**（屋面）。它们各自成系统或合并排放，由四部分构成：

**卫生器具排水管**：器具底部到横支管的短管，带存水弯。
**横支管**：汇集同一楼层器具排水，沿坡度流向立管。
**排水立管**：垂直输送各层污水的主干。
**排出管（出户管）**：立管底部到室外检查井的管段。

管材以 **PVC-U 硬聚氯乙烯管**为主力，胶粘连接；高层建筑与对隔声要求高的场所用**柔性接口铸铁管**。<span class="marginnote">PVC-U 排水管耐腐蚀、价廉、内壁光滑，但隔声差——楼上冲水楼下听得见。铸铁管隔声好但贵且重，所以高层常做「塑料管+隔声包扎」或「铸铁立管」的组合。</span>选管材的同时要定**管径**：器具排水管按器具类型定，立管与横支管按排水量算，马桶排水管通径一般不小于 $100\text{ mm}$。

## 2 坡度：排水管的第一生命线

排水管不靠压力，靠**坡度**让水自流。坡度用 $i$ 表示，即单位管长的高差：

$$
i = \frac{h}{L}
$$

其中 $h$ 是管道两端的高差（m），$L$ 是管长（m）。$i = 0.02$ 表示每 $1\text{ m}$ 管长下降 $20\text{ mm}$。<span class="marginnote">坡度不是越大越好：坡度过大，水流太快，会把固体杂物冲走但水会先跑，导致固体滞留管底；坡度过小，水流太慢，杂物沉淀堵塞。规范给出「标准坡度」与「最小坡度」，施工时按标准坡度做，受限处不小于最小坡度。</span>

PVC-U 排水横管常用坡度参考：$d50$ 标准坡度 $0.035$、最小 $0.025$；$d75$ 标准 $0.025$、最小 $0.015$；$d110$ 标准 $0.020$、最小 $0.012$。施工时用**坡度尺或水准仪**校核，横管吊装前先定坡，吊架间距再按管径确定。

**易错点：** 排水横管**不能有「倒坡」**——哪怕一小段反坡，也会成为杂物沉积点。吊顶内排水管被其他管线顶住时，宁可绕行，不可抬坡。验收时拿水平尺沿管长一量，倒坡立即现形。

## 3 横管连接与立管安装

**横管连接**讲究「顺水」二字：

支管与横管、横管与立管的连接要用**顺水三通、斜三通、45°弯头**，让水流沿切线汇入，避免直角冲击产生翻涌与气阻。<span class="marginnote">「斜进不直插」是排水连接的口诀：所有支流都顺着主流方向斜向汇入，而不是垂直砸进去。直角连接会让污水在交汇处飞溅、堵塞，也更容易让臭气在系统内串动。</span>
横管坡度方向统一指向立管，管件接口胶粘前清洁承口，插入到位并保持一段时间固化。

**立管安装**的要点：

立管每层或每隔几层设**检查口**，方便日后疏通；检查口朝向便于操作，盖板朝外。
立管穿越楼板处设**伸缩节**，PVC 管热胀冷缩系数大，无伸缩节会在接口处被拉裂或顶裂。<span class="marginnote">伸缩节的插入方向要顺水流方向（承口朝上），且预留的伸缩余量要在安装时算好——插得太深失去伸缩作用，插得太浅会脱出。这是排水立管安装最容易被新手忽略的细节。</span>
立管穿越楼板要配合土建做**防水套管或阻火圈**，高层建筑防火规范要求在塑料立管穿越楼板处设阻火圈，防止火灾沿管道蔓延。

## 4 排出管与出户连接

立管底部的处理是排水安装的「重灾区」：

立管底部到排出管要用**两个 45° 弯头**（或大半径弯头）过渡，而不是单个 90° 弯头——高速下落的污水在直角处会剧烈冲击、产生反压，造成上层排水不畅。
排出管穿外墙处设**防水套管**，室外侧接入检查井，井内管口要**伸入井内并留出跌落高度**，让水流自由跌落，防止井内液面倒灌。
排出管同样要有坡度，且埋地部分在回填前必须做**灌水试验**。

**易错点：** 立管底部用 90° 弯头是排水系统最常见的「先天缺陷」，它不一定会立即堵，但会在多年后成为反复堵塞的节点。改两个 45° 弯头，成本不高，一劳永逸。

## 5 核心要点：排水安装的质量检查清单

把室内排水安装的质量要求收拢成一张自检表：

| 检查项 | 合格标准 | 常见缺陷 |
| --- | --- | --- |
| 横管坡度 | 标准坡度，不小于最小坡度 | 倒坡、坡度过大过小 |
| 支管汇入 | 斜三通/顺水三通 | 直角连接 |
| 立管伸缩节 | 承口朝上，余量合适 | 漏装、插深 |
| 立管检查口 | 每层或隔层，便于操作 | 位置别扭、漏设 |
| 立管底部 | 两个 45° 弯头过渡 | 单 90° 弯头 |
| 穿越楼板 | 套管/阻火圈 | 漏设、不封堵 |
| 灌水试验 | 接口不渗漏 | 漏水未发现即覆盖 |

这张表既是安装时的作业指引，也是验收时的对照单：每一条都是规范条文的工程化翻译。排水安装做得好不好，拿这张表逐项打勾即可。

## 6 易错辨析：排水安装的常见通病

**辨析｜易错点：** 排水系统「装好容易、用好难」，大量通病都源于几个反复出现的老问题：

**「倒坡」**：横管被其他管线顶住时抬坡，形成反坡。这是排水系统的「慢性病」——不立即堵，但日积月累沉积杂物。验收时用水平尺逐段校坡，倒坡必须纠正。
- **「直角汇入」**：支管用正三通垂直接入横管或立管，水流对撞、翻涌、憋气。正确做法是用顺水三通、斜三通，让水流沿切向汇入。
- **「立管底部单弯」**：立管底部用单个 90° 弯头，高速水流冲击产生反压，上层排水不畅。用两个 45° 弯头过渡，是规范的做法。
- **「伸缩节方向装反」**：PVC 伸缩节承口要朝上（顺水流方向），装反了伸缩失效，管道热胀时接口拉裂。<span class="marginnote">排水立管「底部双 45°」常被新手认为是「多此一举」：单弯省一个弯头，但多年后反复堵塞、返味，才明白这个弯头省不得——排水系统的容错率，全靠这些「看着多余」的细节撑起来。</span>

**排水通病排查顺序**：先查坡（倒坡是万恶之源）、再查弯（直角与单弯）、后查节（伸缩节与检查口）。按这个顺序排查，绝大多数排水顽疾都能找到病根。

### 常见问题速查：排水安装与验收

| 问题 | 快速判断 | 处置要点 |
| --- | --- | --- |
| 排水慢 | 坡度不足或倒坡 | 校坡，纠正反坡 |
| 冲水咕噜响 | 立管通气不畅 | 检查伸顶通气管 |
| 接口渗水 | 胶粘未固化或承口脏 | 清洁重胶、保持固化 |
| 立管底部反水 | 底部用单 90° 弯 | 改两个 45° 弯过渡 |
| 立管伸缩节拉裂 | 伸缩节漏装或方向反 | 按顺水流方向装伸缩节 |
| 检查口位置别扭 | 朝向不便操作 | 转向便于开启一侧 |
| 穿越楼板渗漏 | 套管未封堵防水 | 套管填实、做防水封堵 |
| 楼上冲水楼下响 | 塑料管隔声差 | 加隔声包扎或换铸铁管 |

这八条覆盖了排水安装从施工到验收的高频问题。**排水系统的「顺」字诀**——顺坡、顺水、顺气流——是贯穿始终的主线：横管顺坡而下、支管顺向汇入、通气管顺气上行，三处都「顺」，系统才顺。

排水施工的返工往往要「动楼板、拆吊顶」，代价极大。所以规范把灌水试验、通球试验放在覆盖之前——**让问题在「还便宜的时候」暴露**，是排水安装最大的智慧。

## 7 小结

- 排水系统由**器具管、横支管、立管、排出管**四部分构成，管材以 PVC-U 与柔性铸铁管为主。
- 坡度是排水第一生命线：$i = h/L$
