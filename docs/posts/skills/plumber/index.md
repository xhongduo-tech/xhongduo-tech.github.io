# 水暖工（建筑给水排水与采暖安装维修）

水暖工负责建筑给水、排水与采暖系统的安装、连接、试压与维修，是建筑安装工程中不可或缺的基础工种。以 GB 50242、GB 50268 与《国家职业技能标准—管工》为纲，系统掌握从识图备料、管道安装、卫生器具与采暖连接，到试压验收与堵漏疏通的完整技能，学完这些章节就能独立完成建筑给排水与采暖系统的施工与维护。

## 对标教材

- GB 50242《建筑给水排水及采暖工程施工质量验收规范》
- GB 50268《给水排水管道工程施工及验收规范》
- 《国家职业技能标准—管工》
