# 排球运动

排球运动是以垫、传、扣、拦、发五大基本技术为核心，集力量、速度、技巧与团队配合于一体的隔网对抗性球类运动，是世界三大球之一。以 FIVB《排球竞赛规则》、《排球运动教程》与《排球裁判员手册》为纲，从基本技术、战术体系到规则裁判与教练员体系，系统写完整门运动的完整知识框架。

## 对标教材

- FIVB《排球竞赛规则》
- 《排球运动教程》（体育院校通用教材）
