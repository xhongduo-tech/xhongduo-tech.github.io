# 农机维修与保养（农机修理工）

以《农机修理工国家职业技能标准（2020年版）》与《农机修理工职业技能鉴定培训教材》为纲，结合《农业机械产品修理、更换、退货责任规定》，系统覆盖从维修安全、田间保养到发动机液压电气检修、故障诊断与三包服务的完整农机维修体系。农机维修是涉及三包服务的法定职业，学完这些章节，就写完了田间实用维修所需的全部内容。
