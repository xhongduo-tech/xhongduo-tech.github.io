# 中华烹饪技艺（中式烹调与中式面点）

中华烹饪技艺是中式烹调与中式面点两大技艺体系的完整技术栈，涵盖刀工、火候、味型调配与面点成型等核心技能，是中式烹调师、中式面点师职业技能等级认定的实操型职业通道。以《中式烹调师国家职业技能标准》《中式面点师国家职业技能标准》和《中国烹饪百科全书》为纲，从原料初加工、刀工火候、烹调方法到菜系流派与面点工艺，系统写完整门技艺。

## 对标教材

- 《中式烹调师国家职业技能标准》
- 《中式面点师国家职业技能标准》
- 《中国烹饪百科全书》
