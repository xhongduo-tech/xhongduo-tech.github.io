## 为什么从调味品开始

原料决定一道菜的下限，调味决定一道菜的上限。同样一盘肉，放盐还是放糖、放酱油还是放醋，完全是两个世界。中餐调味的独特之处在于：**味道不是单一存在的，而是由一个「味型」统领的**——咸鲜、糖醋、鱼香、麻辣，每一种都是一个被反复验证的组合方案。这一节先认识「调味品」这个工具箱，再认识由它们组合出的「基本味型」，为下一篇的复合味型调配打地基。

## 1 调味品按味的分类

调味品按所提供的基本味，可分为六大类：

**咸味**：食盐、酱油、酱（黄酱、甜面酱）、豆豉。咸味是「百味之王」，是多数菜肴的骨架。<span class="marginnote">为什么咸味是百味之王？因为人体生理需要钠盐，而咸味能提鲜、衬甜、压腥——几乎每个复合味型都以咸打底，没有咸味的菜会显得「没味」。</span>

**甜味**：白糖、红糖、冰糖、蜂蜜、饴糖（麦芽糖）。甜味缓和咸与酸，增添回甘。

**酸味**：食醋（米醋、陈醋、香醋、白醋）、番茄酱、柠檬汁。酸味开胃去腥，与糖配对构成糖醋。

**鲜味**：味精（谷氨酸钠）、鸡精、高汤、蚝油、鱼露、虾酱。鲜味是味觉的「放大器」，本身弱但能衬托主味。

**辣味**：鲜辣椒、干辣椒、辣椒粉、花椒、胡椒、姜、蒜、葱。辣味刺激味蕾，带来「热感」，是川湘风味的核心。

**香味与苦味**：八角、桂皮、香叶、小茴香、孜然、丁香；苦味少量来自陈皮、苦瓜、咖啡豆。<span class="marginnote">「香」与「味」在中文里常连用，但感官上不同：香走嗅觉（鼻子），味走味觉（舌头）。炒香香料其实是在「煎出香气」——油脂是香气最好的溶剂。</span>

## 2 常用调味品的品质与用法

**食盐**：分加碘盐与无碘盐。盐是渗透压的主要来源，腌制、焯水、调味都靠它；用量以「先少后补」为原则，宁淡勿咸。

**酱油**：生抽色淡味咸鲜，多用于炒菜提鲜；老抽色深味淡，多用于红烧上色；两者配合是「生抽调味、老抽上色」的黄金组合。

**食醋**：陈醋酸味醇厚、适合红烧炖菜；香醋柔和带香、适合凉拌蘸食；米醋色浅、适合炒菜；白醋酸味冲、适合做泡菜与糖醋的浅色菜。

**料酒（黄酒）**：去腥增香。酒精挥发带走腥味物质，同时为菜肴注入酒香。<span class="marginnote">料酒去腥的机制是「酒精溶解并随蒸汽带走异味物质」——所以要在<strong>锅热时沿锅边淋入</strong>，让酒精瞬间挥发，才能起效；冷锅加料酒效果大打折扣。</span>

**味精与鸡精**：味精主成分谷氨酸钠，遇热遇酸稳定；鸡精是在味精基础上加鸡肉香精与核苷酸，鲜味更复合。两者都应在**出锅前**放，且用量克制。

**蚝油**：牡蛎浓缩而成，自带鲜甜咸，适合炒菜、焖菜收汁。

## 3 基本味型及其构成

把上述调味品按一定比例组合，就得到**基本味型**。中餐常说的基本味型主要有七种：

**咸鲜味**：盐 + 味精（+ 高汤），最简单也最见功夫，体现原料本味。如清蒸鱼、白灼虾。

**咸甜味**：盐 + 糖 + 酱油，甜咸互衬，如无锡酱排骨、蜜汁叉烧。

**酸甜味（糖醋）**：糖 + 醋，比例约 2：1，是酸甜的骨架，如糖醋里脊、咕噜肉。

**香辣味**：辣椒 + 盐 + 味精，如辣子鸡、香辣虾。

**麻辣味**：花椒 + 辣椒 + 盐，麻与辣叠加，如麻婆豆腐、水煮鱼。<span class="marginnote">麻辣与香辣的区别在花椒：麻辣是「花椒的麻 + 辣椒的辣」双通道刺激，麻感其实是一种轻微的触觉震动，来自花椒中的山椒素。</span>

**酸辣味**：醋 + 辣椒 + 盐，如酸辣汤、酸菜鱼。

**椒麻味**：花椒 + 葱 + 油，麻香清冽，如椒麻鸡。

**重点：** 基本味型是**配方的骨架**，每个味型背后都有可量化的比例，学复合味型之前先把这七种骨架记牢。

## 4 味觉原理与公式解析

咸、甜、酸、苦、鲜五种基本味觉，对应味蕾上的不同感受器。中餐调味的核心逻辑可以概括成一条**味觉叠加公式**：

$$
\text{最终味感} = \sum_{i} c_i \cdot w_i
$$

把它拆开看：

- **$c_i$（第 i 种味剂的浓度）**：某一种味觉物质（盐、糖、酸）在菜里的浓度。味觉强度随浓度**对数增长**——这就是著名的韦伯-费希纳定律：浓度翻倍，感觉到的强度只增加一小段。
- **$w_i$（第 i 种味剂的权重）**：每种味觉在整体中的「戏份」。咸味权重最高（骨架），鲜味权重低但能放大其他味。
- **$\sum$（求和）**：味道是**叠加**的，但叠加不是简单相加——盐会「压甜、提鲜」，糖会「缓和酸与咸」，酸能「去腥解腻」。调料互相影响，所以中餐讲「味道要平衡」。

**重点：** 把公式翻译成厨房语言：**调味不是「加得多就够味」，而是「配比恰当才平衡」**。盐 1 份配糖 1 份是咸甜，配糖 2 份就成了糖醋底子；同样的调料，比例一变，味型就变。这正是下一节复合味型的预备。

## 5 调味的基本原则

**有味使之出，无味使之入**：有本味的原料（海鲜）保持本味，少调或清调；本身清淡的原料（豆腐、粉丝）借助高汤与复合味「入味」。<span class="marginnote">「有味使之出，无味使之入」是中餐调味的八字总纲。有味之物（鱼、虾）宜轻调味以显鲜；无味之物（豆腐、萝卜）宜重汤味以补味——两道菜放同一勺盐，用法完全不同。</span>

**因料调味、因菜调味、因时调味**：嫩料轻调味，老料重调味；同一原料冷菜与热菜的咸度不同（冷菜略咸，因低温钝化味觉）；春夏清淡、秋冬浓郁。

**投放时机**：爆炒调味在锅中一次完成（「一烹成味」）；炖焖调味分次加入（先淡后浓、收汁补味）；凉拌调味最后拌入（先加盐会出水）。

**先少后多、宁淡勿咸**：咸了难救，淡了可补。

## 6 核心对比表：同源调味品

本篇纯概念梳理，用核心对比表替代公式解析，把最容易混用的同源调味品对照清楚：

| 调味品 | 来源/特点 | 典型用途 | 替代关系 |
| --- | --- | --- | --- |
| 生抽 / 老抽 | 生抽咸鲜、老抽色重 | 提鲜 / 上色 | 不能互换，配合使用 |
| 陈醋 / 香醋 / 米醋 | 醇厚 / 柔和 / 色浅 | 红烧 / 凉拌 / 炒菜 | 风味各有侧重 |
| 白糖 / 冰糖 / 饴糖 | 纯甜 / 清甜 / 黏稠带麦香 | 日常 / 炖糖色 / 烧腊 | 甜度递增、色重递增 |
| 味精 / 鸡精 | 单一鲜 / 复合鲜 | 提鲜 / 增鲜 | 鸡精可替代味精 |
| 鲜辣椒 / 干辣椒 | 鲜辣 / 干香辣 | 鲜食爆炒 / 炝锅炖卤 | 用量换算约 3：1 |

**重点：** 表格的要点是**「同源不同用」**——酱油、醋、糖都分多种，选对品种比多放一味更关键。记住每类的「默认用法」，再做变通。

## 7 小结

- 调味品按味分**咸、甜、酸、鲜、辣、香苦**六大类，咸味是百味之王。
- 七大基本味型：**咸鲜、咸甜、糖醋、香辣、麻辣、酸辣、椒麻**，各有骨架比例。
- 味觉随浓度**对数增长**（韦伯-费希纳），调味讲平衡而非堆量。
- 调味总纲八字：**有味使之出，无味使之入**。
- 投放时机讲究「爆炒一烹、炖焖分次、凉拌后拌」。
- 同源调味品（生抽/老抽、各类醋、各类糖）要按用途选对品种。

在下一节，七种基本味型只是零件，把它们组装成复杂又协调的整体，就是复合味型调配与应用。
