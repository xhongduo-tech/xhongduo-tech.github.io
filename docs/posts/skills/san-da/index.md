# 散打

散打是中国武术徒手格斗的现代竞技形式，以拳法、腿法、摔法相结合，集实战对抗、攻防转换与规则竞技于一体。以《散打运动教程》《中国武术散打规则》与散打训练体系为纲，系统重建从基本技术、实战战术到竞赛规则与训练进阶的完整习武路径。
