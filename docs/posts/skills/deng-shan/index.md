# 登山

登山是一项集体能、技术、判断力与风险管理于一体的户外运动，涵盖装备使用、路线规划、高海拔适应与安全救援等核心能力。以《登山圣经》、中国登山协会培训教材与《户外运动安全》为纲，系统重建从运动认知、装备器材、攀登技术到高海拔生存与应急救援的完整知识体系。

## 对标教材

- 《登山圣经》（Mountaineering: Freedom of the Hills，美国登山协会）
- 中国登山协会培训教材
- 《户外运动安全》
