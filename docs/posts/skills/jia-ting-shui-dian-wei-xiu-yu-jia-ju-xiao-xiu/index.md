# 家庭水电维修与家居小修

家庭水管、电路、龙头、灯具等日常小修关系居住安全与生活品质，掌握基础检修与安全操作即可应对绝大多数居家小故障。以《电工国家职业技能标准》《水电工技能手册》与《家庭水电维修实用技术》为纲，系统建立从安全规范、工具仪表、电路检修到水管龙头维修与家居小修的完整技能体系，学完这些章节就能独立完成家庭常见水电故障的处理与家居小修。
