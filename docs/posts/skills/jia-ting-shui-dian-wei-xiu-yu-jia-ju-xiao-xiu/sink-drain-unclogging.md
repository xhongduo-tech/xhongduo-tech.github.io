## 为什么从疏通开始

上一节我们管好了「进水」的接口，这一节转向「出水」的世界——水槽堵了、地漏返味、排水缓慢，是家庭里最磨人的「慢性病」。与漏水相比，堵塞不紧急却反复，而**「返味」看似小事，其实是排水系统「水封失效」的警报**。<span class="marginnote">疏通不是「把堵住的捅开」这么简单，它考验的是对排水系统结构的理解：<strong>水槽下有 S 弯（存水弯）、地漏里有水封、主管靠坡度</strong>。堵在哪一段、为什么堵，决定了用什么工具、从哪下手。疏通是「看懂排水系统」的实战课。</span>本节讲清水槽、地漏与排水管堵塞的成因与疏通方法，从「先懂结构」到「分级处理」，让疏通不再靠蛮力。

## 1 排水系统先看懂：水槽、地漏与主管

疏通之前，先明白水往哪里流。家庭排水是一条「接力链」：

**水槽排水**：水槽下水口 → 存水弯（S 弯）→ 支管 → 竖管（主管）→ 楼下主管。**存水弯是「第一道闸」**——它存水封气，也是堵塞最先「卡」住的地方（弯道最窄、转角最急）。

**地漏排水**：地漏面板 → 地漏芯（内置水封或存水盒）→ 支管 → 主管。地漏的**水封**是隔臭关键，水封干涸就返味。<span class="marginnote">「地漏返味」九成是<strong>水封干涸</strong>：水封里的水蒸发了，下水道的气体就顺着干涸的水封窜上来。<strong>每月往不常用的地漏补一次水</strong>（尤其是阳台、卫生间角落的地漏），是最便宜的隔臭方法——这也是《给排水系统》一篇「每月补水保持水封」的落点。</span>

**主管与通气管**：竖管收集各支管的污水，通气管平衡管内气压、防止虹吸破坏水封。主管堵塞影响全楼，通常超出家庭维修范围。

**核心认知**：堵塞的「卡点」有规律——**水槽多堵在存水弯（油垢+食物残渣）、地漏多堵在存水盒（头发+皂垢）、主管多堵在竖管弯头（大块物+长期淤积）**。知道堵在哪，疏通就成功了一半。

## 2 堵塞的成因与分级处理思路

堵塞不是「突然发生的」，而是「逐渐淤积的」。看清水槽、地漏各自的主要「罪魁」：

- **水槽堵塞**：油脂冷却凝固 + 食物残渣 + 洗洁精泡沫，在存水弯结成黏腻的「油垢堵」。
- **地漏堵塞**：头发缠绕 + 皂垢 + 皮屑，在存水盒/水封处结成「毛发堵」。
- **主管堵塞**：不溶性垃圾（湿巾、卫生巾、猫砂）+ 长期油垢，在竖管弯头结成「硬堵」。

**分级处理思路**：从「最温和」到「最强力」逐级升级——**热水冲 → 皮搋子 → 疏通器/疏通剂 → 拆存水弯 → 主管（请人）**。每一步都「先温和后强力」，避免一上来就拆管道或倒强酸。

## 3 疏通方法一：物理疏通（皮搋子与疏通器）

**皮搋子（搋子）**：对付浅层堵塞最有效。用法关键在「**密封 + 按压**」：水槽放少量水（让橡胶碗边缘没入水中），扣住下水口垂直按压——压下去形成水压冲击堵塞物，弹起形成负压把它「往回拉」，反复几十次，多数油垢堵、毛发包就能松动。

**弹簧疏通器（手摇疏通器/管道疏通器）**：对付皮搋子捅不动的深层堵塞。把弹簧头伸进排水管，边转边进，利用螺旋弹簧的旋转把毛发、杂物缠绕带出，或把堵塞物顶开。<span class="marginnote">弹簧疏通器是「手劲 + 手感」的活：<strong>感觉到「卡住」就回退一点再进，感觉到「转不动」就顺时针紧一紧再退</strong>。家用选 3–5 m 的短款即可；水管弯道多时，弹簧可能「卡在弯里出不来」，此时别硬顶，退出来换个角度再试。</span>

**核心对比表：疏通工具怎么选**

| 工具 | 对付的堵塞 | 用法要点 | 局限 |
| --- | --- | --- | --- |
| 热水 + 洗洁精 | 浅层油垢 | 沸水冲入、油脂软化 | 毛发包、硬堵无效 |
| 皮搋子 | 存水弯/地漏口附近堵塞 | 密封碗口、垂直按压 | 深层、弯道多时无力 |
| 弹簧疏通器 | 深层毛发包、软堵 | 旋转进管、遇阻回退 | 弯道多可能卡管 |
| 疏通剂（温和型） | 油脂、皂垢 | 按说明用量、勿过量 | 硬堵、管道有腐蚀风险 |
| 拆存水弯 | 存水弯内的顽固硬堵 | 拆下清理、彻底 | 需工具、可能漏污水 |

## 4 疏通方法二：拆存水弯与清洁地漏芯

**拆存水弯**是处理水槽顽固堵塞的「终极家庭手段」——存水弯是可以拆开的：

**第一步，关水放水**。水槽下接好水盆，关掉水龙头，把水槽里剩水放掉。
**第二步，拆下存水弯**。存水弯两端（上接水槽下水口、下接墙内管）通常有活接头（螺纹卡扣），徒手或管钳拧松拆下——**拆之前先拍照记住安装方向**。
**第三步，清理**。把存水弯里的油垢、残渣、毛发倒出冲洗干净；弯管内的硬结垢用长柄刷或铁丝清理。<span class="marginnote">拆存水弯有两个「坑」要提前避：<strong>一是拆之前一定在下方放好接水盆</strong>（弯里存着半弯水，一拆就洒）；<strong>二是装回时别装反</strong>——存水弯是有方向的，装反了水封存不住水、照样返味。拆前拍照，是治「装不回去」的良药。</span>
**第四步，装回试水**。按拍照方向装回，活接头拧紧（别过紧），开水龙头试水——**排水顺畅、弯里存水、不渗漏**，即成功。

**清洁地漏芯**：地漏的面板与内芯（存水盒）可取出。取出后清理盒内毛发皂垢，用牙刷+清洁剂刷净，装回后**倒一杯水确认水封重新建立**。若是「无水封的直通地漏」，返味是结构问题，需换带水封的地漏芯。

## 5 防堵胜于通堵：日常习惯与定期养护

疏通是「治已病」，防堵才是「治未病」。排水系统的健康，靠的是习惯：

**厨房习惯**：① **油脂不往水槽倒**——剩油倒进废油瓶，或先用纸吸干再冲；② **残渣进垃圾桶**，别靠水冲；③ 每周用**热水 + 洗洁精**冲一次存水弯，软化油垢。<span class="marginnote">「热水冲管」是成本最低的排水保养：<strong>每月烧一壶热水（或倒热水管的水）冲下水口，能把存水弯里初步凝结的油脂冲软化</strong>，防止它结成年深日久的硬垢。油脂的熔点低，热水一到就变软，顺着水流走——防堵的关键是把油垢「扼杀在液态」。</span>

**卫生间习惯**：① 头发掉进地漏前**先收进垃圾桶**（洗澡前顺手捡）；② 地漏口加**滤网/防发网**（几块钱，拦截九成毛发）；③ 每月给不常用的地漏补水，保持水封。

**定期养护**：每月热水冲管一次、每季检查一次存水弯与地漏芯、每半年清一次地漏毛发——把「疏通」变成「体检」，堵塞就很少发生了。

## 6 常见问题答疑与疏通边界

**问：倒疏通剂就能一劳永逸吗？**

**不能，且要慎用**。强力疏通剂（强酸强碱）对油脂有一定溶解力，但**对硬堵（毛发缠绕、大块物）基本无效，还会腐蚀管道与存水弯**，特别是老旧的铸铁管与塑料管。家庭疏通的原则是「物理优先、化学辅助」——先热水、皮搋子、弹簧疏通器，化学疏通剂只作浅层油垢的辅助，且**严格按用量、不与皮搋子联用**（疏通剂遇到高压按压可能喷溅伤人）。

**问：地漏返味，倒清水管水有用吗？**

**有用，但要看「为什么返味」**。若是水封干涸，补水量新建立水封就解决；若返味仍反复，可能原因有二：**一是水封太浅**（新型地漏或安装不当），气味从浅水封穿透；**二是通气管堵塞/密封不严**，主管异味从不密封处逸出。先补水观察，仍返味再检查地漏芯结构与接口密封，必要时更换带深水封的地漏芯。

**问：主管堵了，自己能用弹簧疏通器处理吗？**

**浅层可以试，深层不建议**。家庭弹簧疏通器只有几米长，只能处理到自己这一段支管与最近的弯头；主管堵塞（影响多户、楼下返水）需要专业疏通设备与经验，**且主管疏通涉及公共设施，擅自操作可能把堵塞推向更深处或损坏管壁**。主管反复堵塞，请物业或专业管道疏通公司——这不是「不会修」，而是「边界正确」。

**问：水槽排水慢，但没堵死，是为什么？**

**多数是存水弯内壁的「软垢」让过水截面变窄了**——油垢附着在弯道内壁，水流变缓但不完全堵死。处理：热水 + 洗洁精冲几次（软化油垢）；无效就拆存水弯彻底清洗。**「慢而不堵」是堵塞的前奏**，趁还通着处理好，比彻底堵了再疏通省事得多。

**问：高层的厨房下水，为什么「上面堵、下面返水」？**

**高层住宅的排水竖管是「共管」**——楼上各户的水都汇入同一根竖管，堵塞时水会在竖管里「倒灌」，你家水槽刚排完水，楼下堵了，水又返上来。**「返水」不是你家堵了，而是竖管或楼下堵了**：先确认自家支管通不通（水槽放水看流速），自家通、却返水，多半是公共竖管问题，联系物业处理。别在「返水」时反复冲水——水越积越多，殃及自家与楼上。

**水槽地漏防堵清单**

- 剩油进废油瓶，不往水槽倒。
- 残渣进垃圾桶，地漏口加防发网。
- 每月热水冲管、不常用地漏补水。
- 每季拆洗一次存水弯与地漏芯。
- 疏通用「物理优先、化学辅助」原则。

## 7 小结

- 排水是「接力链」：**水槽（存水弯）→ 支管 → 竖管 → 主管**；存水弯与水封是隔臭关键，也是堵塞高发点。
- 堵塞有规律：**水槽多堵油垢（存水弯）、地漏多堵毛发（存水盒）、主管多堵硬物（弯头）**——先判断卡点再动手。
- 分级疏通：**热水 → 皮搋子 → 弹簧疏通器 → 温和疏通剂 → 拆存水弯 → 主管请人**，物理优先、化学辅助。
- 拆存水弯四步：**放水 → 拆下（先拍照）→ 清理 → 装回试水**；拆前备接水盆、装回防装反。
- 防堵胜于通堵：**剩油不倒槽、毛发先收走、每月热水冲管、地漏常补水**——把疏通变成体检，堵塞自然少。
- 高层「返水」未必是自家堵：**自家支管通、却返水，多是公共竖管问题**，联系物业处理，别反复冲水。
- 疏通工具备齐三件：**皮搋子、弹簧疏通器、温和疏通剂**——从「最温和」到「最强力」逐级升级，不一开始就拆管倒酸。
