## 为什么从应急救助开始

这是本专题的最后一章，也是「安全篇」的收尾——前几章教了「怎么防」，这一章教「**万一没防住，怎么办**」。雪场上事故不可避免（别人可能撞到你、你可能目睹他人受伤），而**事故后的「现场处置」直接影响伤者的预后**：处置得当，为救援赢得时间；处置不当，可能造成二次伤害、甚至加重伤情。**滑雪者（尤其未来的指导员）掌握「现场应急与救助」的基本能力，是「持证上岗」的硬要求，也是雪道公民的基本素养**。<span class="marginnote">本章与上一章的分工：<strong>上一章是「预防」——把损伤挡在发生之前；这一章是「应急」——损伤发生后，第一时间把伤害降到最低</strong>。记住急救的根本原则：<strong>「先保护现场、再评估伤情、再施救，绝不造成二次伤害」</strong>——这一句，贯穿本章全部内容。</span>

## 1 现场评估：先「保护现场」，再「靠近伤者」

遇到雪场事故，**第一反应不是「冲过去救人」，而是「先看现场」**：

**第一步，确保自身安全**：站在事故点**坡上方**的位置（面向坡下）充当「警戒」，让后来的滑行者能看见并绕行——**防止「二次碰撞」**（后来者撞上伤者或救援者，是雪场救援最常见的「二次事故」）。**先设警戒，再靠近伤者**——这是现场处置的第一原则。

**第二步，呼叫救援**：**第一时间呼叫雪场救援**——雪场有统一的救援电话（写在门票、雪道边标识上），说明**具体位置（哪条道、哪个坐标/参照物）、伤者情况（人数、意识、出血情况）**。**「先呼叫救援」比「自己动手」更重要**——专业救援到场前的「黄金时间」，靠的是「准确的信息」。

**第三步，接近与初步评估**：在确保现场安全后，靠近伤者，**评估意识与呼吸**——「能说话吗？哪儿疼？」**如果伤者清醒且无明显大出血，不要移动他**；**如果无意识、无呼吸，立即开始心肺复苏（CPR）并持续到救援到场**。<span class="marginnote">雪场救援的「分工思维」很重要：<strong>你（现场滑雪者）不是「医生」，而是「现场协调者」</strong>——你的任务是「设警戒、呼叫救援、初步评估、安抚伤者」，而不是「凭印象搬动伤者」。<strong>「专业救援 + 现场保护 + 信息传递」三者配合，才是雪场救助的正确模式</strong>——别把自己当成「孤胆英雄」。</span>

## 2 常见伤情的现场处置

在现场等待救援期间，对常见伤情做「正确的初步处置」：

**软组织挫伤 / 扭伤（无骨折迹象）**：让伤者**停止活动、就地休息**；用雪或冰**冷敷**患处（隔着布，防冻伤）；**抬高患肢**减轻肿胀。**「RICE 原则」**：Rest（休息）、Ice（冷敷）、Compression（加压）、Elevation（抬高）——但**加压包扎需谨慎，肿胀明显时不强求**。

**疑似骨折**：**不要移动、不要试图「复位」**——用雪杖、滑雪板、背包等**就地固定**患肢，等待救援；**有明显畸形、骨擦感、无法承重**都按骨折处理。**「宁可不做，不可做错」**——疑似骨折时，错误的搬动可能加重伤情。

**头部损伤（疑似脑震荡）**：伤者可能有意识模糊、恶心、头晕、记忆力问题——**即使「觉得没事」也要送医评估**（脑震荡症状可能延迟出现）。**不要让伤者「睡过去」**，保持观察；**有呕吐、意识丧失、瞳孔异常，立即呼叫并优先转运**。<span class="marginnote">头部损伤的判断有一条「硬规则」：<strong>「摔倒撞头后，即使马上站起来说没事，也应停止滑雪、观察 24 小时」</strong>——脑震荡的延迟症状（头痛、呕吐、嗜睡）可能数小时后才出现。<strong>「滑雪撞头」永远值得「停下来看」</strong>，这是对自己负责，也是给别人示范「安全第一」。</span>

**冻伤与低体温**：冻伤部位**变白、麻木、发硬**——**不要搓揉**（会加重组织损伤），用**温水（37—40°C）缓慢复温**，保持伤者整体温暖；低体温（发抖、意识变差）时，**保暖、给温饮、避免剧烈活动**，尽快转移到温暖环境。

**止血**：有出血时，用**干净的布料直接按压**出血点（直接压迫止血），持续按压直到救援到场；**不要用止血带**（除非专业人员指导，非专业人士用止血带风险很大）。

## 3 心肺复苏（CPR）与救援协作

**心肺复苏（CPR）** 是「呼吸心跳骤停」时的救命技术——滑雪现场可能因心脏骤停、严重撞击等原因需要它。滑雪者（尤其指导员）**建议掌握 CPR 与 AED（自动体外除颤器）的使用**——它可能在某次救援中救回一条生命：

**CPR 的要点**：① **确认环境安全 + 伤者无意识、无呼吸/异常呼吸**；② **立即呼叫救援 + 让人取 AED**；③ **胸外按压**：双掌重叠、置于**胸骨下半部**，以约 **100—120 次/分**的频率、**5—6 cm** 的深度垂直按压，**按压中断越短越好**；④ **AED 到位后按提示使用**（AED 会分析心律并给出语音指导）。

**CPR 需要「正规培训」**：本章只能给出「要点」，**真正的 CPR 操作必须通过正规急救培训（如红十字会急救课程）学习并演练**——滑雪指导员持证考核，通常要求急救认证（如红十字急救证）。**「看过不等于会做」，实操演练是 CPR 的必修课**。<span class="marginnote">为什么滑雪特别强调 CPR/AED？因为<strong>滑雪人群年龄跨度大、运动强度高、低温环境增加心脏负担</strong>——心源性猝死在雪场上并不罕见。<strong>「雪场是否配备 AED、你懂不懂用 AED」，可能在关键时刻决定生死</strong>。作为未来的指导员，<strong>急救认证不是「加分项」，是「职业底线」</strong>。</span>

**救援协作：把「现场」交给专业团队**：专业救援（雪场巡逻队 Ski Patrol）到场后，**听从指挥、提供你掌握的信息（发生了什么、伤者现状、已做的处置）**，然后**配合疏散围观者**——**你的角色从「施救者」转为「信息提供者 + 现场协助者」**。急救的「交接」是专业流程，配合得当，才能让救援高效。

## 4 核心对比：不同情况的「该做 / 不该做」

| 情况 | 该做 | 不该做 |
| --- | --- | --- |
| 事故现场 | 设警戒、呼叫救援 | 直接冲过去、移动伤者 |
| 疑似骨折 | 就地固定、等待救援 | 复位、搬动、让伤者站立 |
| 头部撞击 | 停止滑雪、观察 24 小时、送医 | 说「没事」继续滑、让伤者睡 |
| 冻伤 | 温水复温、保暖 | 搓揉、用热水烫 |
| 出血 | 直接压迫止血 | 用止血带、频繁松手看 |
| 呼吸心跳骤停 | CPR + AED + 呼叫救援 | 等待、放弃按压 |

**这张表的「底层逻辑」**：现场处置的「该做 / 不该做」背后只有一句话——**「不造成二次伤害，为专业救援争取时间」**。**该做的是「保护 + 评估 + 信息 + 基础急救」，不该做的是「逞强 + 想当然 + 乱搬动」**。记住这张表，你在雪场上就能「做对的事」。

## 5 雪场救援与「现场信息」的价值

现场应急里，有一个常被低估、却能救命的环节——**信息**。专业救援到场前，你掌握的「现场信息」决定了救援的效率：

**信息一，精确位置**：雪道名称 + 相对参照物（「中级道第三个转弯下方」「缆车塔架下 50 米」）——位置越精确，救援越快到。**呼叫救援时先说位置**，是现场协调的第一优先级。

**信息二，伤情概要**：几人受伤、有无意识、有无出血、疑似部位——**让救援人员提前准备担架、夹板、药品**，而不是到场后「现场评估」。

**信息三，伤情变化**：等待期间持续观察——**意识是否变差、呼吸是否异常、是否开始发抖（低体温）**——伤情变化要及时向救援报告，因为它决定处置优先级。

**信息的「交接」价值**：专业救援到场后，把你掌握的信息「完整交接」——「他撞到了树、当时清醒、说左膝很疼、没出血、我给他垫了外套保温」——**一段完整的信息，等于帮救援人员提前「诊断」了一半**。

**信息的「记录」价值**：事故相关的**时间、过程、对方信息**要有意识记录——**为后续的责任认定、医疗跟进、保险理赔提供依据**。FIS 第十条守则（身份确认）要求交换联系方式，这里落实到「记录」：不慌不忙地记下关键信息，是事故后的「冷静作业」。

**为什么这一节单独讲**：因为「现场应急」最容易被忽略的，不是「做什么」，而是「传递什么」。**「做对现场处置」是保护伤者的身体，「传递准信息」是保护伤者的「救援通道」**——两者配合，才能让专业救援发挥最大价值。这也是「现场滑雪者」与「专业救援」协作的核心：**你的信息，是救援的「起点数据」**。

## 6 应急救助的「场景演练」与「职业要求」

现场救助是「关键时候不能慌」的技能——而「不慌」只能靠「练」。把救助从「看过」变成「会做」，靠的是场景演练：

**场景一，模拟「发现事故」**：练习「站在坡上方警戒 → 呼叫救援 → 评估伤者」的完整流程——**计时练习**「先警戒、再呼叫、再靠近」的顺序，让「第一反应」变成「正确反应」。很多人在现场「慌了去扶伤者」，忘了先警戒——演练能纠正这种本能。

**场景二，模拟「疑似骨折」**：练习「不搬动、就地固定、等待救援」——**用滑雪板、雪杖做临时夹板的实操演练**，练的是「知道什么能当夹板、怎么固定、怎么防止移动」。

**场景三，模拟「头部撞击」**：练习「停止滑雪、观察、送医评估」的判断——**掌握「何时必须送医」的硬指标**（意识变化、呕吐、瞳孔异常），避免「觉得没事」的侥幸。

**场景四，CPR/AED 演练**：通过正规急救课程**实操练习 CPR 按压、AED 使用**——「看视频会」与「上手会」是两回事，**按压深度、频率、节奏只能靠实操建立肌肉记忆**。

**「职业要求」**：对滑雪社会体育指导员，急救能力是**硬性要求**——持证考核通常要求**红十字急救认证**（覆盖 CPR、AED、常见外伤处置）。**「会急救」不是「加分项」，是「上岗底线」**——因为你在雪场上面对学员，最坏的情况是「学员在你面前受伤」。

**「应急演练」的态度**：急救演练「用不上是最好的，用上时救命」——**「宁可永远用不上，不可用上时不会」**。把应急演练当成「职业训练的一部分」，而不是「多余的事」，是滑雪指导员的成熟心态。

**再点一次「现场应急」的核心**：本章讲了「保护现场、呼叫救援、评估伤情、基础急救、CPR/AED、信息交接」——把它收拢成一句「现场口诀」：**「先警戒、再呼叫、后靠近；能不动、就不动；伤情变化要报告」**——这句口诀，就是你在雪场上「不慌」的支点。急救知识平时用不上，但一旦用上，你「会」与「不会」，可能是两种结局。**「宁可永远用不上，不可用上时不会」**——这句重复的话，值得用一生去践行。

最后补一个「容易被忽视」的环节——**事后复盘**：一次应急处置结束后，**回顾整个过程**（我哪一步做得对、哪一步可以更快、信息传递是否完整）——**把每一次「用到急救」都当作一次「演练」**，让下一次更从容。真正的专业，来自「每一次经历之后的复盘」。

最后，把「应急」与「预防」连成一句话收束：**最好的急救，是「不发生」；发生了，最好的处置是「不慌乱」**——预防（上一章）让你的急救「用不上」，而本章的应急能力，让你在「万一」到来时「用得上、用得对」。**「会预防 + 会应急」，才是完整的「滑雪安全」**——这两章合起来，是本专题「安全篇」的完整拼图。

## 7 小结

- **现场应急的第一原则**：先保护现场（设警戒防二次碰撞）、再呼叫救援、再靠近伤者评估——**不造成二次伤害**。
- 呼叫救援要说清：**具体位置、伤者人数、意识与出血情况**——准确的信息是「黄金时间」的前提。
- 常见伤情处置：扭伤（RICE）、疑似骨折（就地固定不搬动）、头部损伤（停滑观察送医）、冻伤（温水复温不搓揉）、出血（直接压迫）。
- **CPR 与 AED** 是呼吸心跳骤停时的救命技术，**必须通过正规急救培训实操学习**——急救认证是滑雪指导员的「职业底线」。
- 救援到场后，你的角色转为「信息提供者 + 现场协助者」，听从指挥、配合疏散。
- 现场处置的底线：**「该做的是保护与基础急救，不该做的是逞强与乱搬动」**。


至此，本专题的五篇知识全部完成——从第一篇的装备调校，到第二、三篇的双板与单板技术，到第四篇的分级教学，再到第五篇的雪道安全与应急救助，我们走完了「从第一次上雪到持证上岗教滑雪」的完整路径。雪道的安全，靠的是每一位滑雪者把守则、评估、预防、救助都变成「习惯」；滑雪的乐趣，也正建立在这份「安全的底气」之上。愿你在雪道上，滑得畅快，也滑得安心。

愿你永远用不上本章的技能，也永远不怕用上它——这就是滑雪者的底气。
