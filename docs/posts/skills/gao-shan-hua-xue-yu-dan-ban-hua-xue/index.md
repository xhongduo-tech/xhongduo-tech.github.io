# 高山滑雪与单板滑雪

高山滑雪与单板滑雪是大众冰雪运动的标志性项目，掌握分级教学体系、雪道安全规范与装备调校技术，既能安全尽享滑雪乐趣，也是成为滑雪社会体育指导员的起点。以美国滑雪教练协会 PSIA/AASI 分级教学体系、国家体育总局《滑雪社会体育指导员国家职业技能标准》和《高山滑雪》教材为纲，系统重建从装备调校、基础滑行技术到分级教学指导与雪道安全应急的完整知识技能体系。学完这些章节，就写完了从第一次上雪到持证上岗教滑雪的全部内容。

## 对标教材

- PSIA/AASI《高山滑雪与单板滑雪教学技术体系》（美国滑雪教练协会）
- 国家体育总局《滑雪社会体育指导员国家职业技能标准》
- 《高山滑雪》教材
