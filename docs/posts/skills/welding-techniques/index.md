# 焊工（焊接操作技能与工艺）

以《国家职业技能标准—焊工（2018年版）》、《焊接手册》与 GB 50236《现场设备、工业管道焊接工程施工规范》为纲，系统掌握从手工电弧焊到氩弧焊、CO₂气体保护焊的持证操作技能、工艺控制与安全考核知识，学完即覆盖焊工职业技能鉴定所要求的全部理论与实操能力。

## 对标教材

- 《国家职业技能标准—焊工（2018年版）》
- 《焊接手册》（中国机械工程学会焊接学会编）
- GB 50236《现场设备、工业管道焊接工程施工规范》
