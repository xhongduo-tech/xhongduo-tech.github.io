## 为什么从不锈钢与铝镁合金氩弧焊开始

氩弧焊之所以被称为「质量天花板」，很大程度是因为它把两种焊条电弧焊几乎碰不得的材料——**不锈钢**与**铝镁合金**——变成了日常可焊。这两种材料各有各的「脾气」：不锈钢怕「热」（热输入一大就敏化、晶间腐蚀、热裂），铝镁合金怕「氧化膜」（表面的氧化铝熔点 2050 ℃，不清理就焊不上）。<span class="marginnote">不锈钢与铝是「氩弧焊的名片材料」：焊条电弧焊焊不锈钢容易增碳敏化、焊铝根本焊不上（氧化膜清不掉），而氩弧焊的惰性气体保护 + 交流阴极破碎，恰好把这两道难关一一化解。<strong>会焊不锈钢与铝，是氩弧焊「高端」二字最实在的注脚。</strong></span>这一篇把这两种材料的氩弧焊工艺拆开讲——材料为什么要这样焊、参数怎么定、常见缺陷怎么防。它是《手工钨极氩弧焊操作技术》的应用延伸，也是氩弧焊组走向「能焊特殊材料」的一步。

## 1 不锈钢的氩弧焊：怕热与防敏化

**不锈钢（不锈钢与耐酸钢的统称）**按组织分奥氏体（304/316）、铁素体、马氏体等，工业焊接接触最多的是**奥氏体不锈钢**。它的氩弧焊，全部围绕「怕热」这一件事展开：

**奥氏体不锈钢怕三样东西**：**晶间腐蚀**（在 450–850 ℃ 温度区间停留时，晶界析出碳化铬、晶界贫铬，焊缝在腐蚀介质中沿晶界开裂——这叫「敏化」）、**热裂纹**（热导率低、线膨胀系数大，凝固时收缩应力大，易沿晶界开裂）、**变形**（线膨胀系数比碳钢大近一半，焊后变形明显）。<span class="marginnote">「敏化」是奥氏体不锈钢焊接最需要提防的冶金现象：450–850 ℃ 被称为「敏化温度区间」，焊件在这个区间停留越久，晶间贫铬越严重。所以不锈钢焊接的总原则是「<strong>压热输入、快冷却、快离开敏化区</strong>」——小电流、快焊速、尽量不摆动。</span>

这三种「怕」里，**变形**是最容易被新手低估的：不锈钢的线膨胀系数约为碳钢的 1.5 倍，同样的热输入，变形明显更大——所以不锈钢薄板拼焊常用「小电流多层快焊 + 夹具固定 + 对称施焊」来压变形。**「焊钢怕裂、焊不锈钢怕变形怕敏化」，材料的怕点不同，对策就不同。**

**不锈钢氩弧焊的工艺要点**：**小电流、快焊速**（压热输入，缩短高温停留时间）、**尽量不摆动或少摆动**（摆动加大热输入与敏化风险）、**多层多道且控制层间温度**（不锈钢层间一般 ≤ 150 ℃，等冷却再焊下一层）、**背面保护**（不锈钢管对接时背面也要通氩气保护，防止背面氧化形成「焊渣」与变色）。**焊丝选择**：304 用 308L、316 用 316L（含低碳、抗晶间腐蚀好），这是「焊丝选成分不选牌号」的典型例子（回顾《钨极、焊丝与保护气体选用》）。

把「怕热」落到具体数字上，可以给出几个参考值：**不锈钢薄板（1–3 mm）打底电流约 50–90 A，填充 90–120 A**；焊接速度比同厚度碳钢快（压热输入）；层间温度 ≤ 150 ℃。**「小电流快焊 + 层温压住」是不锈钢氩弧焊的三句口诀**——记住这三点，不锈钢的「怕热」就有了解药。

## 2 不锈钢氩弧焊的操作细节

**不锈钢焊缝的颜色是质量的风向标**：银白色 → 保护最好、质量最优；淡黄色 → 轻微氧化、尚可；蓝色 → 氧化明显；灰黑色 → 保护失效、必须返工。<span class="marginnote">不锈钢焊缝的颜色直接反映保护效果，是氩弧焊「看颜色判质量」的最佳样本：<strong>银白是满分，越往灰黑越糟</strong>。焊工焊完一掀面罩先看颜色，心里就有数了——这就是「焊缝颜色会说话」。</span>所以不锈钢氩弧焊的每一条操作细节（枪距、流量、防风、延时）都在为「保住银白色」服务。

**背面保护**：不锈钢管道对接、薄板焊接时，背面（看不见的一面）也要防止氧化。常用**背面充氩**（管内通氩气）或用**背面保护剂**（涂敷在焊缝背面，焊接时形成保护膜）。背面氧化不仅难看，还会形成「焊渣」影响根部质量，重要焊缝的背面保护是硬性要求。

不锈钢氩弧焊还有一个「清洁纪律」：母材与焊丝表面的油、锈、指纹都要除净——不锈钢表面的污染在焊接时会碳化、敏化，成为耐蚀性的薄弱点。**焊前用丙酮等脱脂、用不锈钢专用钢丝刷清理**，是奥氏体不锈钢焊接的「卫生标准」。

**热裂纹的防治**：奥氏体不锈钢的热裂纹倾向比碳钢大，除了压热输入，还要**控制焊缝成形**（避免深而窄的焊缝把杂质挤到中心线，回顾《焊接冶金过程与热循环》的深宽比）与**选用含钼、含铌的焊丝**（改善凝固组织）。

## 3 铝及铝合金的氩弧焊：交流与阴极破碎

**铝及铝合金**的焊接难度来自它的「双重性格」：**导热快**（导热系数约为钢的 2–3 倍，热量很快散失，需要大电流）与**氧化膜**（表面致密的氧化铝熔点 2050 ℃、远高于铝的 660 ℃，不清除就焊不上）。氩弧焊对付它们，靠的是**交流 + 阴极破碎**（回顾《钨极氩弧焊原理与设备组成》）：

**交流焊接**：正半周给工件加热（熔深），负半周靠正离子轰击工件表面、把氧化膜打碎清除（阴极破碎/阴极雾化）。**交流是铝镁合金氩弧焊的标配**——直流正接清不掉氧化膜，直流反接钨极过热严重，只有交流能「一边清理、一边加热」。

交流焊接还有一个「平衡」旋钮：正负半周的时间比例可以调整——负半周（清理）占比大，清理强但钨极热；正半周占比大，加热多但清理弱。**焊铝时调平衡，就是调「清理力度 vs 钨极热度」的平衡**，一般从 50/50 起步按熔池状态微调。<span class="marginnote">阴极破碎的「清理」是铝焊的关键：氧化铝膜一旦不清除，熔池与母材之间隔着一层膜，焊上去的金属「浮」在表面、根本没有冶金结合——这就是「焊上了却一碰就掉」的原因。<strong>交流的正负半周，一半时间清理、一半时间加热，把这对矛盾一次解决。</strong></span>

**铝氩弧焊的工艺要点**：**电流大**（导热快，需要足够热量）、**焊速快**（铝熔池流动性好、容易下塌，要快焊）、**氧化膜清理**（焊前用钢丝刷把坡口两侧的氧化膜刷净，且焊前要尽快焊，铝在空气中很快又生成氧化膜）、**焊丝选同系**（纯铝用纯铝焊丝，铝镁合金用 5183 等镁含量略高的焊丝，补偿镁的烧损）。

把「铝的性格」落到数字上：**铝的导热系数约为碳钢的 2–3 倍**，所以同样厚度铝件的焊接电流要明显大于钢；**氧化铝熔点 2050 ℃ vs 铝熔点 660 ℃**——这个巨大的温差，正是交流阴极破碎存在的根本原因。**记住「铝导热快、氧化膜难熔」，铝焊的一切工艺（大电流、快焊、交流、清膜）都能推导出来**。

## 4 铝氩弧焊的操作细节

**铝氩弧焊的特殊难点——熔池状态的判断**：铝熔化时没有明显的颜色变化（不像钢那样变红），熔池状态难判断，新手常把「已熔化」看成「还没化」，或反之。<span class="marginnote">铝熔池的「看不见」是新手最大的障碍：铝在熔化瞬间表面张力骤变，熔池会出现一个「亮斑」或「洼陷」——老焊工靠观察这个「化开的信号」判断什么时候该送丝、该推进。练铝焊，先练「看熔化」。</span>

铝氩弧焊还有一个「声音信号」：铝熔池化开时电弧声音会变「润」（连续柔和），未化开时声音发「尖」。**把声音也用作判断信号，铝焊的「看不见」就多了一双耳朵**——这是老焊工焊铝的独门经验。对策是**依赖熔化信号的观察**（熔池表面出现亮斑、边缘变圆润）而非颜色，并配合**合适的交流平衡**（正负半周比例可调，清理不足就增大负半周比例）。

**铝氩弧焊的缺陷**：**气孔**（铝对氢极敏感，焊丝与母材的油、水分都是氢源，焊前清理是防气孔的关键）、**烧穿**（薄铝导热快又易塌，电流控制要精细，可用脉冲）、**变形**（铝线膨胀系数大，薄板拼焊要控制热输入与顺序）。**厚铝件的深熔焊**可考虑氩氦混合气（氦导热高、电弧集中）。

铝氩弧焊还有一个「焊后处理」的提醒：焊完的铝焊缝表面有氧化膜与焊渣，要用不锈钢丝刷轻轻刷净，检查成形与气孔；重要铝构件焊后常做**渗透检测（PT）**查表面缺陷。**「焊完刷净再看」，是铝焊质量检查的常规动作**。

## 5 不锈钢与铝氩弧焊的核心对比表

把两种材料的氩弧焊要点收成一张对比表，突出「材料性格决定工艺动作」（本主题以材料工艺为主，故以对比表呈现核心信息）：

| 对比维度 | 奥氏体不锈钢 | 铝及铝合金 |
| --- | --- | --- |
| 主要难点 | 敏化、热裂纹、变形 | 氧化膜、导热快、熔池难判断 |
| 电流种类 | 直流正接（DCEN） | 交流（AC，阴极破碎） |
| 热输入策略 | 小电流快焊压热输入 | 大电流补散热，快焊 |
| 焊前清理 | 脱脂去油、防污染 | 钢丝刷除氧化膜、防再氧化 |
| 焊丝选择 | 308L/316L（低碳抗敏化） | 同系焊丝，镁含量略高 |
| 层间温度 | ≤ 150 ℃ 控制 | 控制过热防变形 |
| 特色操作 | 背面充氩保护 | 看「熔化信号」而非颜色 |

**读表的方法是把每一行翻译成「材料怕什么」**：不锈钢怕热 → 小电流快焊压热输入；铝怕氧化膜与导热 → 交流清理 + 大电流补热。**材料的「性格」直接决定工艺的「动作」**——这条主线从《金属材料与焊接性基础》贯穿到这一篇，是焊接工艺学的灵魂。

## 6 不锈钢氩弧焊的常见缺陷与防治

不锈钢氩弧焊的缺陷，多数能从前面的「怕热」主线推出根因：

**焊缝变色（氧化）**：银白 → 淡黄 → 蓝 → 灰黑，颜色直接反映保护效果。对策：防风、调流量、缩短枪距、检查气体纯度。<span class="marginnote">不锈钢焊缝变色的机理是高温氧化：保护一旦失效，空气中的氧与铬反应、生成氧化铬，焊缝失铬又变色——<strong>颜色不只是「难看」，还意味着铬被烧掉、耐蚀性下降</strong>。所以「颜色不合格」在重要结构里是实打实的质量问题，不是美观问题。</span>

**热裂纹（凝固裂纹）**：奥氏体不锈钢的热裂纹倾向比碳钢大，根因是低熔点共晶与收缩应力。对策：压热输入、控制焊缝成形（避免深而窄）、选用含钼含铌焊丝。**晶间腐蚀**：焊后在敏化温度区停留过久，晶界贫铬。对策：压热输入、控层温、选低碳或稳定化焊丝。

**变形**：不锈钢线膨胀系数大，焊后变形明显。对策：压热输入、对称施焊、反变形、合理顺序。**夹钨**：钨极碰熔池或收弧不当，对策是保持枪距、正确收弧。

## 7 铝镁合金氩弧焊的常见缺陷与防治

铝镁合金氩弧焊的缺陷，几乎都与「铝的性格」相关：

**气孔**：铝对氢极其敏感——铝液对氢的溶解度远高于固态铝，冷却时氢析出形成气孔。氢的来源是焊丝与母材表面的油、水分、氧化膜。对策：**焊前清理**（除油、除氧化膜、尽快施焊）、选用干燥的焊丝、控制环境湿度。<span class="marginnote">铝的气孔是「氢」的气孔：焊接烟尘、空气中的水汽都是氢源，母材与焊丝表面的油膜更是「氢的仓库」。<strong>铝焊防气孔的第一招，永远是「焊前清理」</strong>——清理不彻底，参数再好也白搭。</span>

**烧穿（薄板）**：铝导热快又易塌，薄板极易烧穿。对策：小电流、快焊速、脉冲电流。**变形**：铝线膨胀系数大，薄板拼焊变形严重。对策：控制热输入、对称焊、夹具固定。

**未熔合与氧化物夹杂**：氧化膜没清干净时，熔池与母材之间隔着膜，焊不上或焊不牢。对策：焊前彻底除膜、交流阴极破碎清理、焊丝选同系含镁焊丝补偿烧损。

## 8 不锈钢与铝氩弧焊的实操要点

两种材料的氩弧焊，落到实操上有几条「共同+分异」的要点：

**共同点**：都要焊前清理、都要控制热输入、都要防风保护、都要选与母材匹配的焊丝。**分异点**：不锈钢直流正接、压热输入防敏化；铝交流焊接、大电流补散热——「材料性格决定工艺动作」这条主线，在两个材料上体现得淋漓尽致。<span class="marginnote">把两种材料放在一起学，最大的收获是「<strong>学会读材料的性格</strong>」：不锈钢怕热，铝怕氧化膜与氢——读懂了「怕什么」，工艺动作（电流、极性、热输入、清理）就都能推导出来。材料变了，推导方法不变，这就是「举一反三」。</span>

**实操顺序建议**：先练不锈钢（直流、看颜色判质量，直观易上手），再练铝（交流、看熔化信号，难判断）——由易到难，两个材料的氩弧焊就都掌握了。**练到「不锈钢看颜色、铝看信号」，两种材料的手感就都建立了。**

## 9 小结

- 不锈钢氩弧焊的钥匙是**「怕热防敏化」**：小电流、快焊速、控层温、背保护、选低碳焊丝。
- 不锈钢焊缝颜色是质量风向标：**银白最好、灰黑返工**。
- 铝氩弧焊的钥匙是**「交流清膜 + 大电流补热」**：交流的阴极破碎清除氧化铝膜。
- 铝熔池难判断，要靠**观察「熔化信号」**而非颜色变化。
- 铝的缺陷以气孔、烧穿、变形为主，焊前清理是防气孔的关键。
- 两种材料的全部工艺差异，都源自「**材料性格决定工艺动作**」。
- 铝焊靠「看熔化信号 + 听电弧声音」双信号判断熔池，补上「看不见」的短板。
- 交流平衡旋钮调「清理力度 vs 钨极热度」，焊铝的进阶手感。
