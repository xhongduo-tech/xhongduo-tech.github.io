## 为什么从信号系统开始

上一节讲了电气控制系统的「大脑」，这一节讲它的「五官」——**信号系统**。乘客在层站按下召唤按钮，电梯怎么知道有人要梯？轿厢在几楼、往哪个方向走，又是怎么显示出来的？这些全靠信号系统：**召唤、选层、位置检测、楼层显示与方向指示**。对安装维修工来说，信号系统是**与乘客体验最直接相关**的电气部分——召唤不灵、显示不准，乘客第一反应就是「这台电梯坏了」。<span class="marginnote">信号系统的每个故障几乎都会「脸朝乘客」：召唤按钮失灵、楼层显示乱跳、方向箭头错乱，都是乘客能直接感知的故障。正因如此，信号系统在维保投诉里占比很高，安装时把信号接线做扎实，能省掉大量后期投诉。</span>

这一节沿「信号系统构成 → 召唤与选层 → 位置检测 → 显示与指示 → 安装调试」展开。

## 1 信号系统的构成

电梯信号系统由**信号输入、信号处理、信号输出**三部分组成：

**信号输入**：层站召唤按钮（上、下召唤）、轿内选层按钮、开关门按钮、检修按钮等。

**信号处理**：控制系统的程序对召唤与选层进行登记、排队、定向与分配（哪台梯响应哪个召唤）。

**信号输出**：轿内楼层显示、方向指示、层站呼梯显示、运行状态指示（满载、消防、检修等）。

**重点**：信号系统是「乘客能摸到、能看到」的部分，而它背后连着控制系统的调度逻辑。安装信号系统，既要接好每一条信号线，也要理解每条信号在控制逻辑里起什么作用。

## 2 召唤与选层系统

**召唤（call）**：乘客在层站发出的呼梯信号，分**上召唤**与**下召唤**——按「上」按钮表示想去上方楼层，按「下」表示想下到下方楼层。层站召唤按钮装在召唤盒上，并有指示灯显示「呼梯已登记」。

**选层（car call）**：乘客在轿内按下的目标楼层按钮。轿内操纵箱上每个楼层一个按钮，选中后点亮，到达后熄灭。

**信号登记与清除**：召唤与选层信号被「登记」后，控制系统在调度中响应；轿厢到达并开门后，对应信号被「清除」。<span class="marginnote">「登记—响应—清除」是信号系统的基本循环：按钮按下即登记，电梯响应到达即清除。按钮按下灯不亮，说明信号没登记上（按钮或接线问题）；灯亮了电梯不来，则是调度或运行问题——从「灯亮不亮」就能把故障定位到子系统。</span>

**重点**：方向性是召唤系统的核心——同一楼层可以既有上召唤又有下召唤，控制系统按电梯当前运行方向选择响应「顺向召唤」还是「反向召唤」，这是群控与单梯调度的基础逻辑。

## 3 位置检测与平层信号

电梯要知道自己在几楼、该不该停，靠**位置检测系统**：

**井道位置检测**：在井道内按楼层设置**感应开关（如平层开关、隔磁板）**或采用**井道位置编码系统**（光电、磁栅、激光），检测轿厢的绝对位置。

**平层信号**：轿厢接近楼层时，平层感应器感应井道内的平层板（隔磁板），产生平层信号，控制系统据此减速、爬行、停靠，实现准确平层。<span class="marginnote">平层板的安装位置直接决定平层精度：板装得准，电梯每层都停得齐；板装得歪，就会「有的层平、有的层差」。调试平层，本质是校平层板与平层感应器的相对位置——这也是《电梯变频调速与控制系统调试》里平层调整的物理基础。</span>

**位置丢失与自学习**：现代电梯在安装调试时做**井道自学习（自学习运行）**——轿厢以检修速度走一遍全程，系统记录各楼层、减速点、端站的位置信号，生成位置表。自学习不完整，电梯就会出现「不知道自己在几楼」的乱层故障。

**重点**：位置系统是电梯「认路」的基础。自学习完成后的位置数据是调试与平层的依据，换编码器、改隔磁板后都要重新自学习。

## 4 显示与指示系统

**楼层显示**：轿内与层站显示轿厢当前所在楼层，常用数码管或液晶屏。显示数值与实际楼层的关系在调试中设定（可定义显示 1 楼为「1」或「G」「B1」等）。

**方向指示**：显示轿厢运行方向（上行/下行箭头），运行中点亮、停站熄灭。

**状态指示**：满载（不响应顺向召唤）、超载（报警）、消防状态、检修状态、到站钟等，向乘客传达电梯的当前状态。

**召唤显示**：层站召唤盒上「电梯正在赶来」的指示灯，减少乘客等待焦虑。

**辨析｜易错点：** **「显示楼层」≠「实际楼层」**。显示的数字是控制系统设定的映射值，与井道位置信号对应；显示乱跳通常是位置信号或显示设置错误，而不是「电梯真的乱跑」。判断显示故障时，先查位置信号源，再查显示设置。

## 5 信号系统的安装与调试

信号系统的安装围绕「**接线正确、信号可靠、显示准确**」展开：

**按钮与开关安装**：召唤盒、操纵箱按图纸接线，按钮动作可靠、指示灯正常；按钮接线用编号与图纸对应，防止「接串线」。

**传感器安装**：平层感应器与隔磁板（平层板）的相对位置按调试要求安装；井道位置编码装置的固定与接线防护到位。

**显示单元安装**：轿内与层站显示面板安装牢固、视角良好，线束整理规范。

**调试步骤**：通电后先校验各信号输入（按按钮看登记灯），再校验位置信号（走检修全程看楼层显示），最后校验调度输出（自动运行看响应与显示）。

**重点**：信号系统调试的常见故障是「信号接串」——按钮按下，登记的却是另一个楼层的信号。逐点核对编号与图纸，比通电后猜故障高效得多。**先查线、后猜逻辑**是信号调试的纪律。

### 常见信号故障速查

| 现象 | 优先排查 | 常见根因 |
| --- | --- | --- |
| 按钮按下灯不亮 | 按钮、接线、控制板输入 | 按钮坏、线断、端子松 |
| 楼层显示乱跳 | 位置信号、显示设置 | 平层板错位、自学习缺失 |
| 召唤登记了不来 | 调度、运行状态 | 满载不停、方向逻辑错 |
| 方向箭头不亮 | 方向继电器、显示驱动 | 接线错、显示单元故障 |
| 到站钟不响 | 到站钟接线、蜂鸣器 | 线断、蜂鸣器损坏 |

### 群控与多台电梯的信号协同

现代建筑常有多台电梯并列运行，信号系统还要承担**群控协同**：

- **群控调度**：多台电梯由群控系统统一调度，把召唤信号分配给最合适的电梯（最近、同向、闲置优先）；
- **信号共享**：各梯的召唤、位置、状态信号汇总到群控，统一决策；
- **分区运行**：早晚高峰按区间分区服务，减少无效停靠；
- **故障转移**：某台梯故障时，群控把其信号转移给其它梯，维持服务。

**重点**：群控让信号系统从「单梯应答」升级为「多梯协同」——安装时不仅接好每台梯的信号线，还要调试好梯与梯之间的通讯与调度参数。群控的调试比单梯复杂得多，是高级工与技师等级的能力要求。

### 信号系统的安装质量要点

信号系统「脸朝乘客」，安装质量直接决定使用体验：

- **接线可靠**：按钮、显示、传感器的接线端子压接牢靠、编号清晰，杜绝「接串线」；
- **防干扰**：信号线远离动力线、屏蔽层可靠接地，防止干扰误动作；
- **插接件防护**：随行电缆、插接件固定可靠、留足运动余量；
- **功能逐项验证**：安装后逐层验证召唤、选层、平层、显示功能；
- **自学习完成**：井道自学习完整，位置数据与实物一致。

**重点**：信号系统的隐蔽质量在于**「防干扰」与「防松动」**——干扰与松动的故障往往随机出现、难以复现，安装时做扎实，能省掉维保期大量「说不清」的投诉。

## 6 小结

- **信号系统**：输入（召唤/选层）→ 处理（登记调度）→ 输出（显示指示）三段式。
- **召唤与选层**：上/下召唤带方向性，「登记—响应—清除」是基本循环。
- **位置检测**：平层板与感应器、井道编码、自学习，是电梯「认路」的基础。
- **显示≠实际**：显示是映射值，乱跳先查位置信号源。
- **调试纪律**：先查线、后猜逻辑；逐点核对编号与图纸。
