## 为什么从困人应急救援开始

电梯故障里，最牵动人心的是**困人**——乘客被关在轿厢里，既出不来、又不知道发生了什么。对维保单位来说，困人救援是**法定义务与职业责任**：接到困人报警必须尽快到场，按规范流程把人安全救出。救援做得好，一次「惊魂」变成「有惊无险」；救援乱来，小故障可能酿成大事故。<span class="marginnote">被困乘客最大的恐惧来自<strong>缺氧想象</strong>——以为轿厢是密闭的、空气会耗尽。实际上轿厢有通风孔，断电也不至于窒息。救援的第一步不是动手，而是<strong>安抚</strong>：让乘客知道「一切可控、救援在路上」，恐慌本身比困梯更危险。</span>

这一节沿「困人救援的原则 → 救援前的准备 → 解救操作流程 → 特殊工况 → 救援后的处理」展开。

## 1 困人救援的基本原则

困人救援有几条**铁律**：

**先安抚、后操作**：与被困乘客保持联络，安抚情绪、告知救援进程，防止乘客盲目扒门自救。

**先判断、后动作**：判断轿厢位置、故障状态、救援环境，再决定救援方式。

**先断电、后作业**：救援操作涉及停电与手动松闸，必须先断电挂牌，防止误动作。

**专业操作**：救援由持证人员执行，严禁使用单位、无关人员擅自「撬门自救」。<span class="marginnote">「盲目扒门自救」是困人事故的大忌：轿厢不在平层时扒开门，下面是井道深坑；轿厢在两层之间，乘客跳出轿厢可能坠落。规范救援的核心，就是<strong>让乘客留在轿厢内、由专业人员解救</strong>——轿厢是相对安全的空间。</span>

**重点**：困人救援的优先级是**先保人、再救出**。乘客在轿厢内是安全的，救援的目标是「安全地救出」，而不是「尽快地拉出」——欲速则不达。

## 2 救援前的准备

接报困人后，**先做救援准备**，再前往现场：

**联络确认**：与乘客通话，确认被困人数、身体状况、有无儿童老人孕妇，安抚情绪。

**信息判断**：通过监控或现场了解轿厢位置、门是否夹人、有无停电，判断故障类型。

**人员与工具**：安排持证救援人员，携带机房钥匙、三角钥匙、松闸工具、对讲机、照明与警示用品。

**到达确认**：到场后确认电梯状态（是否检修、是否有人作业），再按流程解救。

**重点**：救援准备的关键是**「先问清、再行动」**——不了解轿厢位置与乘客状况就动手，可能适得其反。通讯是救援的第一工具。

## 3 解救操作的基本流程

电梯困人救援的典型流程（以轿厢停在两层之间为例）：

**第一步，确认状态**：到达现场，确认电梯处于停止状态，通知乘客「救援开始」。

**第二步，断电挂牌**：断开主开关并挂牌，使电梯处于安全状态，防止救援中误送电。

**第三步，手动松闸盘车**：到机房（或无机房电梯的松闸装置处），用**松闸扳手**打开制动器，配合**盘车手轮**（或专用装置）缓慢移动轿厢，使轿厢平层。<span class="marginnote">手动松闸是救援的核心操作：松闸扳手撬开抱闸，轿厢在重力作用下缓慢移动，靠盘车控制速度与方向。这里最危险的是「<strong>松闸过快</strong>」——轿厢失去制动力后加速下滑，必须「一松一停」分段控制，并对对重侧、轿厢侧的轻重方向有预判。</span>

**第四步，确认平层**：通过观察平层标志或听门刀位置，确认轿厢到达平层区。

**第五步，开门放人**：到轿厢所在层站，用三角钥匙打开层门（必要时打开轿门），引导乘客有序撤离。

**重点**：松闸盘车的方向与力度，取决于轿厢与对重的重量关系——轿厢轻时松闸轿厢上溜、重时下溜。**有经验的救援人员会在松闸前判断轿厢载重与位置，用「点动松闸」控制速度**。

## 4 特殊工况的救援

不同工况的救援方法不同，**核心对比表**如下：

| 工况 | 救援要点 |
| --- | --- |
| 轿厢平层 | 直接开门放人，最简单 |
| 轿厢两层之间 | 机房松闸盘车至平层，再开门放人 |
| 停电困人 | 按停电预案，松闸盘车或通知供电恢复 |
| 轿厢在顶层/底层端站 | 确认缓冲器位置与安全，再开门 |
| 无机房电梯 | 通过控制柜旁的松闸/盘车装置操作 |
| 门被外力撬开 | 先评估井道坠落风险，按程序复位 |

**辨析｜易错点：** 常见误区是「救援时让乘客在轿厢里配合跳一下」（增加配重方便平层）。**绝对禁止**——乘客在轿厢内蹦跳会改变轿厢重心与载荷，松闸盘车时可能失控。救援全程应要求乘客**站好扶稳、不要动作**。

## 5 救援后的处理

人救出来了，救援还没结束：

**现场检查**：检查轿厢位置、门系统、制动器状态，确认无损伤。

**原因排查**：分析困人原因（停电、故障、误动作），安排后续维修。

**恢复运行**：确认故障排除、电梯正常后，恢复送电并试运行。

**记录报告**：记录困人时间、原因、救援过程与处理结果，按要求上报。<span class="marginnote">困人事件是电梯维保质量的「报警器」：同一台梯频繁困人，说明存在未根治的隐患（制动器漂移、变频器故障、安全回路不稳定）。把每次困人的原因追查到底、消除根因，比「救一次算一次」重要得多——这是《电梯维保记录、档案与检验申报管理》里把困人记录归档的意义。</span>

**重点**：救援的终点不是「人出来了」，而是**「把根因修好、避免再次困人」**。一次救援 + 一次根因排查，才是完整的闭环。

### 困人事件的应急处置预案

维保单位与使用单位都应建立**困人应急处置预案**：

- **报警受理**：24 小时应急电话，接报即记录被困信息、通知救援人员；
- **人员调度**：救援人员就近出动，明确到场时限；
- **现场分工**：一人负责安抚乘客、一人负责机房操作、一人负责层站接应；
- **升级上报**：超过规定时间未解决、或有人员受伤时，升级上报并配合消防、医疗；
- **复盘总结**：救援完成后复盘，分析困人原因与处置过程，改进预案。

**重点**：预案的价值在于**把应急动作提前想好**——困人现场分秒必争，临时临场最容易出错。预案 + 演练，是让救援「紧张而有序」的保证。

### 被困乘客的安抚技巧

安抚被困乘客，是救援里最容易忽视、却至关重要的一环：

- **保持通话**：让乘客知道「有人来救」，消除「没人管」的恐惧；
- **告知进度**：如实告知救援进展，不夸大也不隐瞒；
- **劝阻自救**：明确告知「不要扒门、不要撬门」，说明危险；
- **关注特殊人群**：老人、儿童、孕妇、病患重点关注，必要时协调急救；
- **稳定情绪**：语言平和，避免在乘客面前暴露慌乱或争议。

**重点**：大部分困人事故中，乘客本身是安全的，风险往往来自**恐慌后的盲目自救**。安抚到位，乘客配合，救援就成功了一半——这也是为什么规范把「先安抚」放在救援流程的第一步。

## 6 小结

- **救援原则**：先安抚、先判断、先断电、专业操作，让乘客留在轿厢内由专业人员解救。
- **救援准备**：联络确认、信息判断、人员工具、到达确认，通讯是第一步。
- **解救流程**：确认状态 → 断电挂牌 → 松闸盘车 → 确认平层 → 开门放人。
- **特殊工况**：平层直接开、两层之间盘车、停电按预案、无机房用专用装置。
- **禁止蹦跳**：乘客蹦跳改变载荷重心，救援中全程要求站好扶稳。
- **救援闭环**：人救出 + 根因排查 + 记录报告，避免再次困人。
