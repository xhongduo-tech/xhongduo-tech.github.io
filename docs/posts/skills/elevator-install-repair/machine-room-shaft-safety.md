## 为什么从机房与井道安全开始

电梯安装的主战场有两个：**机房**（放置曳引机与控制系统）和**井道**（轿厢与对重运行的竖井）。这两个地方集中了电梯作业的几乎所有高风险因素：高处、受限、带电、旋转机械、悬空吊装。上一节讲了个人防护，这一节把安全放到**作业环境**的尺度上：机房有什么危险、井道怎么进出、高处与受限空间怎么防护。<span class="marginnote">机房与井道是电梯事故的高发区，也是安全监管的检查重点。TSG T7001 对机房通道、照明、井道防护、底坑设施都有明确要求——安全要求不仅写在作业规程里，也写在检验项目里，双重约束。</span>

这一节沿「机房安全 → 井道作业 → 高处作业 → 受限空间 → 现场管理」展开。

## 1 机房作业安全

机房是电梯的「心脏室」，作业安全围绕**设备危险源**展开：

**旋转部件防护**：曳引轮、导向轮、飞轮等旋转部件运转时不得触碰，防护罩完整；检查或调整时先停机、确认锁死。

**电气危险**：控制柜内带电作业按规程执行，验电、挂牌、绝缘工具；母线、端子排裸露处设绝缘防护。

**设备坠落与滑移**：曳引机吊装就位后及时紧固地脚螺栓，避免半吊状态；机房地面油污及时清理，防滑倒。

**散热与通风**：机房作业注意设备发热，避免在散热通道堆物；通风不良时加强通风后再作业。<span class="marginnote">机房常被当「杂物间」使用——堆放纸箱、工具、易燃物。这不仅堵塞散热与检修通道，火灾时还会把唯一逃生路线堵死。保持机房整洁，既是安全要求，也是检验项目。</span>

**通道与逃生**：机房通道畅通、照明充足、有应急照明；机房门向外开启或可双向开启，保证紧急情况能撤出。

## 2 井道作业安全

井道作业是电梯安装的高频风险环节，核心原则是**「人机分离」**：

**进入井道的准备**：把电梯置于检修状态，断开主开关并挂牌；确认井道内无遗落人员工具；从层门口或机房进入时，先观察轿厢位置。

**轿顶作业**：轿顶作业时按下轿顶检修盒的急停，使用轿顶照明；作业者站立于轿顶有效区域，系挂安全带，防止轿厢意外启动或坠落物伤人。<span class="marginnote">轿顶作业的经典陷阱：只按了轿内操纵箱的急停，而没有让轿厢处于<strong>检修状态</strong>——一旦有人误按正常运行的召唤，轿厢可能直接启动。正确做法是检修状态 + 轿顶急停 + 断电挂牌三重确认。</span>

**底坑作业**：进入底坑前确认轿厢停在安全位置或完全上提到位；注意缓冲器、张紧装置、限速器绳的位置，防止挤压与绊倒；底坑照明与急停开关正常。

**井道内垂直运输**：工具与材料用工具袋、绳索传递，禁止上下抛掷；作业平台或脚手架搭设牢固、有护栏。

## 3 高处作业防护

电梯安装大量涉及**高处作业**（距坠落基准面 2 米及以上），防护要求：

**作业平台**：优先采用脚手板、平台、护栏构成的工作面，避免「踩钢管、扶电线」式的临时作业。

**安全带的挂点**：安全带挂点必须**牢固、能承受坠落冲击**，高挂低用。井道内可在导轨支架、专用挂点上系挂，禁止挂在移动部件上。

**梯子使用**：直梯与伸缩梯使用前检查，底部防滑、上部固定或有人扶，作业时身体重心不超出梯侧。

**坠落防护系统**：高处作业还可采用**安全网、水平生命线、防坠器**等系统防护，与安全带形成冗余。<span class="marginnote">「安全带 + 独立生命线」是高坠防护的黄金组合：安全带保护人的坠落，独立生命线保证即使安全带挂点失效，人也不会坠落到底。井道多台电梯同时施工时，生命线还能防止作业人员互相干扰。</span>

**辨析｜易错点：** 「井道矮、高度小就不用系安全带」是常见错误认识。坠落伤害与高度不是线性关系——1 米的高处摔落也可能造成重伤。规范以坠落基准面 2 米为界，但安全习惯应不分高低一律系挂。

## 4 受限空间作业防护

井道、底坑、机房地坑等**通风不良、出入口受限**的空间，具有**受限空间**作业特征，防护要点：

**先通风、再检测、后作业**：进入前检测氧气浓度与有害气体（井道底部易积聚较重的有害气体），通风后再进入。

**设监护**：受限空间作业必须设专人监护，监护人能看清作业人员并能随时联络。

**应急装备**：配备救援绳索、三脚架、通讯设备，制定撤离预案。

**时间与轮换**：长时间在底坑、井道作业注意休息与轮换，防止疲劳引发失误。

**重点**：受限空间最大的危险是**盲目施救**——作业人员缺氧晕倒，施救者贸然进入，造成连锁伤亡。正确流程是「检测 → 通风 → 设防 → 监护进入 → 异常立即撤离并呼叫专业救援」。

## 5 现场安全管理

安全最终要落到**现场管理**，几条基础做法：

**安全交底与班前会**：作业前交代任务、危险点、防护措施，作业人员签字确认。

**警示与隔离**：井道口、机房口、吊装区设警戒线、警示牌，无关人员禁入。

**工具与材料管理**：工具随手归位、材料定点堆放，杜绝「满天飞」的现场。

**班后检查**：收工前清点人员、工具，关灯断电、锁闭井道门，确认现场无遗留。

**重点**：现场管理的本质是**把不确定性变成确定性**——每个开关、每扇门、每件工具都处在「已知状态」，事故就没有可乘之机。

### 井道作业的典型事故场景

理解井道作业的高风险，先看清几类**典型事故场景**：

- **轿厢意外启动**：未置检修状态、未断电挂牌，电梯被召唤启动，轿顶作业者被挤压；
- **坠落井道**：层门误开、井道口无防护，人员踏空坠落；
- **高处坠物**：工具、材料从轿顶或井道口坠落，砸伤下方人员；
- **受限空间缺氧**：底坑通风不良，人员晕倒；
- **触电**：井道内电缆破损、带电作业未验电。

**重点**：每一类事故场景，都对应一条安全规程——检修状态 + 断电挂牌对应「轿厢意外启动」，层门管理与防护对应「坠落井道」，工具袋与隔离区对应「高处坠物」，通风检测对应「缺氧」。**规程不是凭空规定的，每条都是事故的反面教材**。

### 井道施工的防护设施

井道施工的安全，离不开**防护设施**的支撑：

- **层门口防护**：施工期间每层层门位置设临时防护门或护栏，防止坠井；
- **井道口警示**：机房、井道口设警示标志与警戒线；
- **作业平台**：轿顶、脚手架作业面铺满脚手板、设踢脚板与护栏；
- **照明**：井道全程设检修照明，底坑与轿顶单独照明；
- **通讯**：轿顶、底坑、机房之间保持可靠通讯。

**重点**：防护设施是「把危险挡在外面」的工程措施，与个人防护（把人在危险中保护起来）互为补充。**工程防护优先、个人防护兜底**，是安全防护的原则顺序。

## 6 小结

- **机房安全**：旋转部件防护、电气验电挂牌、通道畅通、不堆杂物。
- **井道作业**：人机分离，检修状态 + 轿顶急停 + 断电挂牌三重确认。
- **高处防护**：作业平台优先，安全带高挂低用，挂点牢固。
- **受限空间**：先通风、再检测、后作业，设监护、防盲目施救。
- **现场管理**：交底、警示、隔离、班后检查，把不确定性变成确定性。
