# 电梯定期检验周期、项目与自检要求

## 为什么从定期检验开始

监督检验管的是「电梯出生」，**定期检验**管的是「电梯一生」。电梯投入使用后，随运行年限增长，部件会磨损、参数会漂移、保护会失效——定期检验就是定期把这些「悄悄变差」抓出来。对维保单位与使用单位来说，定期检验是**每年一次必须面对的大考**，而它与日常维保的衔接，直接决定这台电梯能不能「一年又一年地平安」。<span class="marginnote">定期检验的周期通常为<strong>一年</strong>（按规定项目周期执行）。逾期未检继续使用的电梯属于违法使用——使用单位与维保单位都有责任盯住检验周期，这也正是《电梯维保记录、档案与检验申报管理》要把「检验到期」列为台账重点的原因。</span>

这一节沿「定期检验的周期与定位 → 检验项目 → 自检要求 → 检验与维保的衔接 → 常见不合格项」展开。

## 1 定期检验的周期与定位

**定期检验（periodic inspection）**：对在用电梯按规定的周期实施的法定检验，验证电梯在持续使用中仍符合安全要求。

**核心对比表**（与监督检验对照）：

| 项目 | 定期检验 | 监督检验 |
| --- | --- | --- |
| 对象 | 在用电梯 | 新装、改造、重大修理电梯 |
| 周期 | 每年（按规定周期） | 一次性 |
| 关注点 | 磨损、漂移、持续合格 | 施工质量 |
| 主体配合 | 使用单位 + 维保单位 | 安装/改造/修理单位 |

**重点**：定期检验与监督检验在项目上有重合，但视角不同——定期检验尤其关注**「用久了会退化」**的项目：磨损、疲劳、间隙漂移、保护参数变化。

## 2 定期检验的项目

定期检验的项目覆盖机械、电气与安全装置，**重点核查「会随使用劣化」的环节**：

**机械项目**：导轨磨损与接头、导靴间隙、曳引绳断丝与直径减小、绳头连接、制动器间隙与磨损、门系统间隙与门锁、安全钳与导轨间隙。

**电气项目**：绝缘电阻、接地连续性、安全回路完整性、漏电保护动作、照明与应急照明。<span class="marginnote">定期检验与安装检验的差异在「看趋势」：安装检验看「当时合不合格」，定期检验看「这一年退化到什么程度」——曳引绳断丝数、导轨磨损量、制动器摩擦片剩余量，都是「退化指标」。维保记录里留存的历次数据，正是判断退化的参照。</span>

**试验项目**：平衡系数复核、制停试验、限速器—安全钳联动试验、超载保护、缓冲器复位检查等。

**重点**：定期检验不是「每项都重测一遍」，而是**有侧重地复核**——凡是被使用影响的项目都要查，凡是被安全机制强制要求的试验都要做。

## 3 自检与报检要求

定期检验前，**维保单位先自检**，再报检：

**自检依据**：对照 TSG T7001 定期检验项目与要求，由维保单位（或使用单位组织）对电梯进行自行检查。

**自检内容**：覆盖检验项目，重点验证安全装置与保护功能，发现隐患先整改。

**自检记录**：形成自检记录，作为报检资料与整改依据。

**报检**：使用单位在检验到期前向检验机构申报定期检验，提交自检记录、维保记录、上次检验报告等。

**辨析｜易错点：** 常见误区是「自检就是做做样子，反正检验员会再查」。实际上**自检不合格项越多，检验现场整改越多、电梯停用越久**。自检的意义是「把问题消化在检验之前」——认真自检，报检一次通过率高，电梯停机时间最短。

## 4 定期检验与维保的衔接

定期检验与日常维保**相辅相成**：

**维保为检验打底**：按《电梯维护保养制度与保养周期》与《电梯日常保养项目与工艺规程》做好日常保养，检验时自然问题少。

**检验为维保反馈**：检验发现的不合格项，往往暴露维保的薄弱环节——某部件频繁不合格，说明该部位的保养频次或方法需要加强。

**数据为下轮参照**：历次检验数据与维保记录互相印证，构成电梯的健康档案。<span class="marginnote">「检验数据 + 维保记录」是电梯最宝贵的健康档案：曳引绳断丝从 0 到 2 再到 5，导轨磨损逐年增大，制动器声音渐响——这些趋势比任何单次数据都说明问题。维保单位把这些数据积累下来，就能预判电梯何时需要大修或改造，见《电梯改造、加装与能效提升实务》。</span>

**重点**：检验不是维保的「外挂」，而是维保质量的「体检报告」。把检验发现的问题当作维保改进的线索，电梯的可靠性才会逐年提升。

## 5 常见不合格项与整改

定期检验常见的不合格项，值得提前预防：

**安全装置失效**：安全钳间隙漂移、限速器动作速度偏差、缓冲器不回位——及时调整与试验。
**曳引绳超限**：断丝数、直径减小超限——按《曳引系统结构与曳引机、钢丝绳安装》的判定标准更换。
**门系统隐患**：门锁啮合不足、门间隙超差、门保护不灵——逐层排查整改。
**电气问题**：绝缘电阻下降、接地连续性差、漏电保护不动作——测量并修复。
**资料缺失**：维保记录不全、检验标志缺失——补齐台账。

**重点**：不合格项整改的优先级先 A 类（安全直接相关，立即整改）再 B/C 类；整改后复检合格，电梯方可继续使用。**「发现问题不可怕，发现后不管才可怕」**——检验制度的全部意义，就在推动问题闭环。

### 检验标志与使用登记

定期检验通过后，还有两项管理动作：

**检验标志（合格标志）**：检验合格后，检验机构或使用单位在电梯轿厢内张贴检验合格标志，标明下次检验日期。乘客看到标志，就知道这台电梯「在有效期内」——这是电梯向社会展示「我合格」的窗口。<span class="marginnote">轿厢内的检验合格标志常被忽视，但它有实际意义：标志过期（超期未检）的电梯，乘客有权质疑其安全；使用单位把它贴在醒目的地方，既是合规要求，也是给乘客的安全承诺。</span>

**使用登记证**：电梯投入使用时办理使用登记，登记证与检验报告配套管理，构成电梯的「身份证」。检验合格、登记有效、标志在期，三者齐备，电梯才处于「完全合法」的受控状态。

**重点**：检验合格只是「技术合格」，加上登记与标志，才是「管理合格」。三项配套，电梯的整个合规闭环才算完整——这也与《电梯维保记录、档案与检验申报管理》里的档案管理一脉相承。

### 检验中的安全配合

定期检验是检验人员在现场动真格，配合单位要注意安全：

- 检验涉及的轿顶、底坑、井道作业，配合人员遵守高处与受限空间安全规程；
- 试验（制停、安全钳联动、超载）前清空井道与轿厢人员，设好监护；
- 检验现场有明确分工，听从检验负责人指挥，不擅自操作；
- 发现问题当场记录，整改过程规范作业，复检时提供整改佐证。

**重点**：检验现场是「多个工种 + 动真格试验」的叠加环境，安全配合与检验结果同样重要——配合得好，检验快、结论准；配合乱，既拖时间又添隐患。

## 6 小结

- **周期定位**：在用电梯每年一检，逾期未检不得使用。
- **项目侧重**：机械磨损、电气绝缘、安全装置试验，重点看「会退化的环节」。
- **自检报检**：先自检、再报检，把问题消化在检验之前。
- **维保衔接**：维保为检验打底，检验为维保反馈，数据积累成健康档案。
- **整改闭环**：先 A 后 B/C，整改复检合格方可继续使用。
- **合规三件套**：检验合格 + 使用登记 + 标志在期，电梯才算完全受控。
- **检验安全**：轿顶底坑井道作业守规程，试验前清场设监护，配合好才检得快、测得准。
- **检验标志**：合格标志标明下次检验日期，与使用登记、检验报告配套构成合规闭环。
