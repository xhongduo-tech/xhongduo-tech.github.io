## 为什么从监督检验程序开始

上一节讲了安装工程的组织与验收，这一节深入验收的核心环节——**监督检验**。电梯新装、改造、重大修理后，必须经过监督检验合格才能投入使用。对安装单位来说，监督检验是「**考试**」；对检验机构来说，监督检验是「**把关**」。搞清楚监督检验的程序、申报方式与资料审查要求，安装单位才能把「考」做得顺、把「关」把得好。<span class="marginnote">监督检验由<strong>特种设备检验机构</strong>依法实施。它检验的不只是电梯本身，还包括安装过程的质量——施工告知、过程记录、检验资料，一起构成监督检验的依据。</span>

这一节沿「监督检验的定位 → 申报与程序 → 资料审查 → 现场检验衔接 → 结论与整改」展开。

## 1 监督检验是什么

**监督检验（supervision inspection）**：依据安全技术规范，在电梯安装、改造、重大修理过程中及完工后，由检验机构对施工质量进行的法定检验确认。

**与定期检验的区别**（核心对比表）：

| 项目 | 监督检验 | 定期检验 |
| --- | --- | --- |
| 对象 | 新装、改造、重大修理的电梯 | 在用电梯 |
| 时机 | 施工中 + 完工后 | 按周期（通常每年） |
| 目的 | 确认施工质量合格 | 确认持续符合使用安全要求 |
| 不合格后果 | 不得投入使用 | 停止使用、整改复检 |

**重点**：监督检验的「法定性」体现在——未监督检验合格，电梯**不得投入使用**。这与安装单位自检性质完全不同：自检是自我把关，监督检验是国家强制确认。

## 2 监督检验的申报与程序

监督检验有一套标准程序，安装单位按流程走：

**施工告知**：安装、改造、修理单位在施工前向所在地特种设备安全监督管理部门办理**施工告知**，告知施工项目与单位信息。

**报检申请**：施工过程中（或完工后按约定节点）向检验机构提出监督检验申请，提交报检材料。

**资料审查**：检验机构对提交的随机资料、资质证明、告知文件进行审查，审查通过才进入现场检验。

**现场检验**：检验人员按 TSG T7001 到现场实施检验与试验，安装单位配合。

**出具结论**：检验机构根据检验结果出具监督检验报告，合格后方可投入使用。<span class="marginnote">「施工告知 → 报检 → 资料审查 → 现场检验 → 出具报告」这条链路，把安装工程纳入了全过程监管。中间任何一环缺失，电梯都上不了路——报检前逐项核对流程清单，是安装单位的基本功。</span>

**重点**：报检时机的把握很重要——有的检验项目（如导轨、安全装置）在施工过程中就要检验，不能等全部装完才报检。安装单位应了解哪些项目在什么节点被检验，避免「装完才想起来」的返工。

## 3 资料审查：第一道关卡

**资料审查**是监督检验的第一关，审查的主要内容：

**制造资料**：电梯制造许可证明、出厂合格证、型式试验证书（安全部件：限速器、安全钳、缓冲器等）、产品说明书。

**安装资料**：安装单位资质与许可、施工告知文件、安装施工记录、自检记录。

**设计与参数**：井道布置图、电气原理图、整机参数（额定载重、额定速度、层站数）与实物铭牌一致性。

**辨析｜易错点：** 最常见的报检打回原因是**「资料与实物不一致」**——铭牌额定载重与图纸不符、型式试验证书编号对不上、自检记录缺失。资料审查不看「资料多不多」，而看「资料真不真、齐不齐、对得上对不上」。报检前把资料逐项核对，能省一次打回重报。

## 4 现场检验与施工的配合

现场检验阶段，安装单位要做好配合：

**人员配合**：安排熟悉施工情况的负责人与技术员配合检验，提供必要的工具与安全条件。

**试验配合**：平衡系数测定、制停试验、安全钳联动、超载试验等需要安装单位操作或配合，提前做好试验准备（载荷、工具、现场安全）。

**整改配合**：检验发现问题后，按整改通知书逐项整改，整改完成后申请复检。<span class="marginnote">现场检验最耗时的往往是「等」：等安装单位找资料、等载荷搬运、等整改人员到场。把检验涉及的资料、工具、人员提前准备好，检验过程可以压缩到很短——准备，是现场检验效率的隐藏变量。</span>

**重点**：现场检验不是「检验员自己玩」，而是**安装单位与检验机构协同**的确认过程。配合到位，检验顺利；配合混乱，检验拖长、问题暴露更多。

## 5 检验结论与整改闭环

监督检验的结论与整改，形成完整的闭环：

**结论分类**：全部合格 → 出具合格结论；存在不合格 → 出具整改通知书，按 A/B/C 类别提出整改要求。

**整改流程**：A 类项目（直接涉及安全）立即整改并复检；B/C 类项目限期整改；整改完成后重新检验相关项目。

**报告出具**：复检合格后，检验机构出具监督检验报告，作为电梯投入使用与登记的依据。

**重点**：整改的优先级是**先 A 类、后 B/C 类**——A 类不合格是安全底线，一天都不能拖；B/C 类在期限内完成。整改不是「改一处算一处」，而是「改完一处、验证一处、记录一处」，确保闭环。

### 监督检验与安装过程的节点

监督检验不是只在完工后「考一次」，而是**跟随施工过程**分节点把关：

- **井道与土建节点**：井道尺寸、预留孔洞、机房位置是否符合图纸——这是最早被检验的环节；
- **导轨与安全装置节点**：导轨垂直度、限速器、安全钳等关键部位在施工中接受检查，而非装完再查；
- **整机与试验节点**：完工后整机检验与试验（平衡系数、制停、安全钳联动、超载）集中实施。

**重点**：理解「过程分节点检验」后，报检时机的把握就清楚了——不是全部装完才报，而是**按节点配合检验**。把每个节点该准备的资料与现场条件提前备好，检验就顺；等装完再补，往往要返工或拆改。

### 资料审查的清单化管理

报检资料多而杂，用**清单化管理**最稳妥：

- 建立报检资料清单，逐项核对打勾：制造许可、合格证、型式试验证书、告知文件、资质证明、施工记录、自检记录；
- 资料编号与电梯实物对应，杜绝「张冠李戴」；
- 提交前由负责人复核一遍，重点核对参数与铭牌一致性；
- 电子与纸质各留一份，便于补正与归档。

**重点**：资料审查的「一次通过」，靠的是报检前的清单化核对，而不是检验现场的手忙脚乱。把清单当成工具，资料审查这道关卡就稳了。

## 6 小结

- **监督检验定位**：新装、改造、重大修理后法定的质量确认，不合格不得投入使用。
- **申报程序**：施工告知 → 报检 → 资料审查 → 现场检验 → 出具结论。
- **资料审查**：制造资料、安装资料、设计参数与实物一致性，是第一道关卡。
- **现场配合**：人员、试验、整改三方面配合，准备充分是检验效率的关键。
- **整改闭环**：先 A 后 B/C，改完一处、验证一处、记录一处。
- **过程分节点**：监督检验跟随施工过程分节点把关，报检时机按节点配合而非装完再报。
