# 电梯安装与维修保养

电梯安装、调试、维保与检验属特种设备强制管理职业，涉及机械结构、电气控制与安全检验多学科交叉。以《电梯安装维修工国家职业技能标准》、TSG T7001《电梯监督检验和定期检验规则》与《电梯安装与维修》为纲，系统建立从电梯结构认知、机械电气安装、调试检验到维护保养与故障排除的完整职业技能体系。学完这些章节，就写完了电梯安装与维修保养的全部内容。

## 对标教材

- 《电梯安装维修工国家职业技能标准》
- TSG T7001《电梯监督检验和定期检验规则》
