## 为什么从工程组织与验收开始

前面所有章节教的都是「怎么把一台电梯装好」，这一节教「**怎么把一台电梯的安装工程组织起来并交付**」。电梯安装是一项**多工种、多专业、多环节**协同的工程：土建配合、设备进场、机械安装、电气安装、调试、自检、报检、验收交付。单个工序做得再好，若组织混乱、验收缺项，工程照样交付不了。<span class="marginnote">电梯安装工程是典型的「<strong>交钥匙工程</strong>」：从井道交付到电梯交付，安装单位要对全过程负责。组织能力——排计划、管进度、控质量、保安全——是中级工走向技师的关键能力，职业标准里把它列为技师等级的核心技能。</span>

这一节沿「工程准备 → 施工组织 → 自检 → 报检与验收 → 交付资料」展开。

## 1 安装工程的准备阶段

电梯安装从**施工准备**开始，准备充分与否直接决定施工能否顺利：

**图纸与技术资料**：电梯井道布置图、电气原理图、随机文件（说明书、合格证），与土建图纸核对井道尺寸、预留孔洞、机房位置。

**现场勘察**：核实井道净尺寸、层站数、提升高度、底坑深度、顶层高度与设计参数是否一致；发现偏差及时与设计、土建沟通。

**人员与资质**：作业人员持证、技术交底、分工明确；安装单位具备相应许可。

**机具与材料**：吊装设备、电动工具、量具、耗材备齐并检验合格；材料（导轨、钢丝绳、电缆）按清单清点验收。<span class="marginnote">「机具先于施工」看似常识，实则是进度失控的第一诱因：导轨吊到井道口才发现没有合格吊装索具，全班组停下来等工具——现场经验老到的班长，准备工作往往占掉整个工期近三分之一。</span>

**安全方案**：编制施工安全方案，明确高处、井道、带电作业的安全措施与应急流程。

## 2 施工的组织与进度管理

电梯安装施工有固定的**工艺顺序**，组织时按此安排工序衔接：

**井道准备 → 导轨安装 → 曳引机就位 → 轿厢与对重安装 → 门系统安装 → 电气接线 → 安全装置联动 → 调试 → 自检 → 报检**。

**进度安排**：按总工期倒排各工序节点，预留调试与整改时间；工序之间明确交接标准——「上道工序不合格，下道工序不接手」。

**质量管理**：关键工序（导轨垂直度、安全钳间隙、平层精度）设置**质量停检点**，检查合格再进入下道工序。

**协调配合**：与土建（孔洞、封堵、地坪）、供电（电源到位）、其它工种（吊装、动火）协调界面，避免交叉干扰。

**重点**：电梯安装是「**强依赖顺序**」的工程——曳引机没就位就挂不了绳，导轨没直就装不了轿厢。进度管理做得好，就是把顺序依赖排顺、把关键资源（吊装、电力）调度到位。

## 3 自检：交付前的自己把关

安装与调试完成后，安装单位须先**自检**，把问题消化在报检之前：

**自检依据**：对照 TSG T7001 的检验项目与技术要求，逐项自查。

**自检内容**：机械项目（导轨、轿厢、对重、门、安全装置）、电气项目（接地、绝缘、回路）、试验项目（平衡系数、制停、安全钳联动、超载）全覆盖。

**自检记录**：每项自检形成记录，不合格项整改后复检，形成「问题—整改—复检」闭环。<span class="marginnote">「先自检、再报检」是安装单位的职业修养：把问题消化在自己手里，报检时一次通过率高，还能避免检验现场反复整改的尴尬。自检记录本身就是监督检验的资料附件。</span>

**重点**：自检不是「走过场」，而是**用检验的标准要求自己**。自检合格的电梯，报检才有效率；自检敷衍的工程，往往在检验现场被逐项打回。

## 4 报检与监督检验

自检合格后，进入**报检与监督检验**环节：

**报检**：安装单位向检验机构申报监督检验，提交施工告知证明、自检记录、随机资料（合格证、型式试验证书）、安装单位资质等材料。

**监督检验实施**：检验机构按 TSG T7001 对电梯实施监督检验，包括资料审查、现场检验与试验（详见《电梯监督检验程序、申报与资料审查》与《曳引式电梯检验项目与技术要求》）。

**整改与复检**：检验发现问题，按类别整改；A 类项目不合格立即整改复检，B/C 类按限期整改。

**检验结论**：全部项目合格后，检验机构出具监督检验报告，电梯方可投入使用。

**重点**：报检的成功率，取决于**资料完整 + 自检扎实**。资料不全先打回补件，现场问题多则整改反复——把「准备工作」做到位，报检就顺。

## 5 交付与资料归档

验收通过后，进入**交付**环节：

**交接**：向使用单位交付电梯、钥匙、随机资料与质保说明，培训使用单位操作与应急流程。

**竣工资料**：整理竣工资料（图纸、说明书、合格证、自检记录、检验报告、施工记录），按档案要求归档。

**质保期服务**：质保期内跟踪运行状况，处理使用单位反馈的问题，配合首次定期检验。

**辨析｜易错点：** 常见问题是「验收合格就撒手」——随机资料没移交、使用单位没培训、档案没归档。资料与培训是交付的一部分，缺了它们，电梯后续的维保、检验、管理都会遇到麻烦。**交付不仅是交钥匙，也是交资料、交责任边界**。

### 安装单位与使用单位的交接清单

为了让「交钥匙」落地，一份交接清单能避免遗漏：

| 交接内容 | 说明 |
| --- | --- |
| 钥匙与操作权 | 机房钥匙、三角钥匙、操纵权移交使用单位 |
| 随机文件 | 合格证、说明书、图纸、质保卡 |
| 检验报告 | 监督检验报告、自检记录 |
| 使用培训 | 日常操作、召唤使用、应急呼救方法 |
| 质保与维保 | 质保条款、推荐维保单位与联系 |

**重点**：交接清单的意义是把「交付」从一句话变成一张表——逐项打勾、双方签字，责任边界清晰，后续扯皮大幅减少。

### 安装工程的常见质量通病

长期安装实践里，有几类反复出现的通病，值得在施工与自检时重点盯防：

- **导轨垂直度靠「目测」**：不按要求测量，运行后晃动难根治；
- **安全钳间隙凭手感**：过大咬不住、过小误动作，必须用塞尺量化；
- **门锁触点不调**：门看似关好但触点不通，电梯报门锁故障；
- **接地「看着接」**：螺栓锈蚀、跨接松动，接地形同虚设；
- **记录事后补**：自检记录与实物脱节，报检被退回。

**重点**：质量通病的共性，是**「差不多思维」**——用感觉代替测量、用形式代替实质。验收与检验的意义，正是用「数据」和「标准」把这个「差不多」纠正成「准确」。施工时按标准量、按图纸做，通病自然远离。

## 6 小结

- **工程准备**：图纸核对、现场勘察、资质机具、安全方案，准备充分是成功的一半。
- **施工组织**：按「井道→导轨→曳引→轿厢对重→门→电气→安全→调试」顺序衔接，设质量停检点。
- **自检先行**：对照 TSG T7001 逐项自查，问题—整改—复检闭环。
- **报检验收**：资料完整 + 自检扎实是报检顺畅的前提，A 类不合格一票否决。
- **交付归档**：交钥匙、交资料、交培训、交责任边界，质保期内跟踪服务。
