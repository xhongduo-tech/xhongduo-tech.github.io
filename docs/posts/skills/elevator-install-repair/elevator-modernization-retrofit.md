## 为什么从改造与加装开始

本专题走到这里，电梯的一生我们已经走完一遍：装好、验好、保养好、修好。但电梯的寿命远长于技术的寿命——一台用了 15 年的电梯，曳引机还能转，可它的控制方式、能耗水平、安全性能，已经被新一代技术甩开很远。**改造**，就是让老电梯「重获新生」；**加装**，是让没有电梯的老楼「第一次拥有电梯」。这两项是电梯技师等级的核心技能，也是本专题的收官之篇。<span class="marginnote">老楼加装电梯是近年来城市更新的热点：老旧小区居民楼普遍无电梯，加装需求巨大。它牵涉土建（井道、基坑）、设备、审批、居民协商等多方，是「<strong>特种设备 + 民生工程 + 建筑改造</strong>」的复合工程——对从业者而言，既是技术活，也是协调活。</span>

这一节沿「改造的类型与意义 → 加装电梯实务 → 能效提升 → 改造的报批与检验 → 改造决策」展开。

## 1 电梯改造：给老电梯换「心脏」

**电梯改造（modernization / retrofit）**：在不更换整机的前提下，对电梯的部分系统进行升级改造，提升性能、安全与能效。

电梯改造的典型内容：

**控制系统改造**：把老旧的继电器控制或模拟控制换成微机/变频控制，提升可靠性、舒适度与可维护性。

**拖动系统改造**：把交流双速、直流拖动换成变频调速（VVVF），改善启停舒适度、降低能耗。<span class="marginnote">「电控 + 拖动」往往是改造的第一组合拳：变频调速带来的舒适度与节电收益立竿见影，改造周期短、对井道结构影响小。许多老梯改造的第一步，就是换上变频器与新型控制柜——这也是《电梯变频调速与控制系统调试》技能在改造场景的直接应用。</span>

**安全装置更新**：更换老化限速器、安全钳、缓冲器，升级门保护（光幕）与超载保护，补齐安全性能。

**部件升级**：更换曳引绳、导轨、门机、召唤显示等磨损老化部件。

**重点**：改造的核心是**「选对升级对象」**——不是把能动的都换掉，而是针对电梯的薄弱环节（控制系统老旧、能耗高、安全装置过期）做精准升级，用有限的投入获得最大的性能与安全提升。

## 2 老楼加装电梯实务

老楼加装电梯是近年高频需求，工程实务要点：

**可行性评估**：勘察楼体结构、场地条件、供电与管线，评估加装的技术可行性。

**方案与报批**：编制加装方案（井道型式、电梯选型、连接方式），办理规划、建设与特种设备相关审批。

**土建施工**：施工井道（钢结构、混凝土或玻璃幕墙井道）、基坑与连廊，涉及结构加固与防水。

**设备安装**：按常规流程安装电梯机械与电气系统，并与原建筑做好连接与防水。

**检验与交付**：加装电梯同样须经监督检验合格后投入使用，并纳入使用登记与维保管理。<span class="marginnote">加装电梯的难点常在「<strong>协调</strong>」而非技术：居民对出资比例、采光遮挡、噪音影响的协商，审批环节的多方沟通，往往比安装本身耗时更长。从业者要清楚，加装工程的成功 = 技术可行 + 手续合规 + 邻里和谐。</span>

**重点**：加装电梯是「**土建 + 电梯**」的复合工程，土建接口（井道垂直度、基坑、预留孔洞）直接决定电梯能否顺利安装。电梯安装单位进场前，先复核土建质量，是避免返工的关键。

## 3 能效提升：电梯的绿色升级

电梯是建筑里的耗能大户，能效提升是改造的重要方向：

**变频调速**：取代传统的电阻调速、交流双速，节电效果显著（可达 30% 以上），同时改善舒适度。

**能量回馈**：加装回馈装置，把重载下行、轻载上行时电机的发电能量送回电网，减少能量损耗与机房发热。<span class="marginnote">能量回馈是「把浪费变成回收」的技术：电梯发电状态的能量以往靠制动电阻发热耗掉，回馈装置把它逆变成交流电送回电网。节能效果随电梯使用频率与工况而定，且回馈装置要与电网参数匹配、控制谐波——加装前做谐波与电磁兼容评估是必要环节。</span>

**照明与待机节能**：轿厢照明采用 LED、无人待机时自动熄灭或休眠，降低待机能耗。

**电机与传动效率**：更换高效永磁同步电机与曳引机，提升传动效率。

**能效评估**：改造前后对比电能消耗，量化节能效果，作为改造效益的依据。

**重点**：能效提升的收益要「**算得清**」——改造投入与节电收益、舒适度提升、减碳效果综合权衡。节能改造不是越贵越好，而是「投入产出合理、技术可靠可维护」。

## 4 改造的报批与检验

电梯改造不同于日常维修，须遵循**法定程序**：

**界定改造/重大修理**：更换曳引机、控制系统、安全装置等关键部件，通常构成改造或重大修理，需按 TSG T7001 实施监督检验；一般修理按合同与规范进行。

**施工告知与报检**：改造单位办理施工告知，改造完工后报请监督检验，合格后方可恢复使用。

**随机文件更新**：改造后的电梯参数、图纸、合格证等随机文件应更新归档。

**档案衔接**：改造资料追加到电梯档案，与历史记录衔接，保证全生命周期可追溯。<span class="marginnote">改造后的电梯，其检验基准以「改造后的状态」为准：改造涉及的关键参数（额定载重、速度、控制系统）要与改造文件一致。改造资料不更新，等于档案与实物脱节——这也是《电梯维保记录、档案与检验申报管理》里「档案持续更新」原则在改造场景的应用。</span>

**辨析｜易错点：** 常见误区是把「改造当维修」——换了一套控制系统，却只按一般维修处理、不办施工告知、不报监督检验。**改造（含重大修理）必须走特种设备法定程序**，否则改造后的电梯未经检验确认，属于违法使用。

## 5 改造决策：换新还是改造

面对一台老旧电梯，业主常纠结「**改造还是整梯更换**」，核心对比表如下：

| 项目 | 改造 | 整梯更换 |
| --- | --- | --- |
| 投入 | 相对较低 | 较高 |
| 周期 | 短（不停梯或短暂停梯） | 长（拆旧装新） |
| 保留 | 保留曳引机、导轨、轿厢等可用部件 | 全部换新 |
| 提升 | 针对薄弱系统精准升级 | 整机性能全面更新 |
| 适用 | 结构良好、仅部分系统老旧 | 结构老化、全系统落后 |

**重点**：改造与更换的取舍，取决于**结构状态 + 技术差距 + 预算周期**。结构良好、改造可覆盖升级需求的，改造性价比高；结构老化、全系统落后的，更换更彻底。决策前做一次全面的电梯评估（机械状态、电气状态、安全性能、能耗），用数据说话。

### 改造施工的组织与衔接

改造工程同样需要规范的施工组织：

- **方案交底**：改造范围、工序、安全措施向施工人员交底；
- **分阶段实施**：拆旧、装新、调试分段进行，关键节点设停检；
- **土建配合**：涉及井道、机房的改造，与土建单位衔接界面；
- **旧件处置**：拆除部件清点、报废或回收，避免遗留隐患；
- **临时运行管理**：改造期间电梯的停用、启用与警示管理到位。

**重点**：改造施工与新建安装的最大差异，是**在旧设备上动刀**——旧件状态、历史问题、现场条件都要先摸清。改造的返工成本更高，前期准备与方案比新建更重要。

### 物联网与电梯的智能化升级

近年电梯改造常纳入**智能化**内容：

- **远程监控**：运行数据、故障代码实时上传，远程诊断；
- **困人告警**：困人自动检测并联网报警，缩短救援响应；
- **预诊断**：通过运行数据分析磨损趋势，提前预警；
- **智能调度**：群控算法优化派梯，缩短等候时间。

**重点**：智能化是电梯改造的新方向，但它建立在**可靠的设备与数据**之上——先把机械、电气、安全基础改造好，智能化才有意义。对从业者而言，物联网既是新技术，也是新技能，技师等级的能力要求正在向这个方向扩展。

## 6 小结

- **改造类型**：控制系统、拖动系统、安全装置、部件升级四类，核心是「选对升级对象」。
- **加装实务**：可行性评估 → 报批 → 土建 → 设备安装 → 检验交付，协调常比技术更难。
- **能效提升**：变频调速、能量回馈、LED 照明与待机节能，收益要算得清。
- **法定程序**：改造/重大修理须施工告知、监督检验、文件更新、档案衔接。
- **决策取舍**：改造与更换取决于结构、技术差距与预算，用全面评估的数据说话。

到此，我们从电梯的概述分类出发，走完了参数术语、法规职业、安全防护、机房井道，再到曳引、轿厢对重、门、导轨、安全装置等机械安装，电气控制、供电接地、信号、变频调试、工程验收、试运行，监督检验、曳引电梯检验、扶梯检验、定期检验、联动试验，最后到维保制度、日常保养、故障排除、应急救援、记录档案与改造加装——**「从极限到大模型」的电梯安装与维修保养专题全部内容就到这里**。电梯这门手艺，从「装得上」到「保得好」再到「改得新」，靠的始终是安全敬畏、规范作业与持续学习。
