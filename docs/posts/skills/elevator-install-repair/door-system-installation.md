## 为什么从门系统开始

电梯每天接触乘客最多的部件，不是曳引机也不是导轨，而是**门**。乘客每次乘梯都要经过两次门：层门（楼层的门）与轿门（轿厢的门）。门系统承担着三重职能：**让乘客安全进出、把井道与层站隔离、与控制系统联动保证「门不开梯不动」**。对安装维修工而言，门系统是**工作量最大、检验最密集、故障最高发**的子系统之一。<span class="marginnote">门系统的安全地位从 TSG T7001 的项目分类就能看出：层门锁紧按 A 类项目对待——它是防坠落的最后一道物理屏障。门没关好电梯就不能走，这条逻辑由门锁回路强制实现。</span>

这一节沿「门系统构成 → 层门安装 → 轿门安装 → 门锁与门保护 → 联动调整」展开。

## 1 门系统的构成与分类

**门系统**：由**层门、轿门、开门机（门机）、门锁装置、门保护装置**组成。

**层门（landing door / hall door）**：安装在每个层站井道口，把层站与井道隔开，防止乘客坠入井道。层门由门扇、门框、门锁装置与门导靴构成。

**轿门（car door）**：安装在轿厢入口，随轿厢一起运动，通过门刀与层门门锁啮合，带动层门开闭。

**开门机（door operator）**：装在轿顶或轿门上方，驱动轿门开闭，并通过门刀带动层门同步开闭。

**门保护装置**：检测关门过程中有无夹人夹物，常见有**光幕、安全触板**（见第3节）。

**重点**：层门与轿门**不是一个门**。轿门跟轿厢走、可自动开关；层门停在楼层面、靠轿门带动。理解「轿门带层门」的传动关系，是读门系统图纸的起点。

### 门的开关方式

按开门方式，电梯门分为**中分式**与**旁开式**两类：

- **中分式**：两扇门向两侧平分开启，开门宽度大、通行效率高，是乘客电梯主流；
- **旁开式**：单扇或双扇向一侧推开，结构简单，多用于货梯与医用梯。

开门方式影响层站预留与门机选型，安装前须与建筑图纸核对开门方向与净尺寸。

## 2 层门的安装

层门安装在每个层站，工序围绕「**门框就位 → 门扇挂装 → 门锁安装 → 地坎配合**」展开：

**门框安装**：层门门框固定在井道口预留的门洞上，**垂直度与平面度**要合格——门框歪斜，门扇就关不严、门锁就啮合不上。门框与墙体间缝隙按防火要求封堵。

**地坎安装**：层站地坎与轿厢地坎配合构成进出通道，二者间距与标高差是平层精度的直接体现。<span class="marginnote">地坎是门系统里最容易「差几毫米」的部位：地坎不水平，门扇运行就发涩；地坎与轿厢地坎间距超标，推车进轿厢就会卡。检验项目里专门查地坎间距，安装时按基准放线一次到位。</span>

**门扇挂装**：门扇通过吊门轮挂在门导轨上，底部由门导靴（防脱靴）约束在门槛槽内。门扇安装后检查**垂直度、门缝均匀度与开关顺畅度**。

**门锁装置安装**：每层层门必须有门锁装置，由**锁钩与锁座**组成。关门后锁钩挂住锁座，门锁电气触点接通，电梯才能运行；开门或锁钩未到位时，门锁回路断开，电梯不能运行。<span class="marginnote">门锁是「机械联锁 + 电气监控」的组合：锁钩是机械锁（防止外力推开门），触点回路是电气锁（防止门开着电梯走）。两层都合格，防坠落的门这道屏障才成立——这也是它被列为 A 类检验项目的原因。</span>

### 层门安装的检验要点

层门装完后逐项自查：

- 门扇与门框、门扇之间的间隙均匀，符合规定（防止夹手与剪切）；
- 门锁啮合深度足够，锁钩与锁座啮合量、触点接通可靠；
- 层门在轿厢不在本层时**应能锁紧且不能从层站侧打开**（紧急开锁装置除外）；
- 门扇运行无卡阻、无噪声，关门力符合要求（过大夹人、过小关不严）。

**重点**：层门「从层站侧打不开」是一条硬安全要求——它保证乘客在等梯时不会被坠入井道。紧急开锁装置（三角钥匙孔）仅供救援使用，钥匙必须由持证人员保管。

## 3 轿门与门保护装置

**轿门安装**：轿门随轿厢运行，由开门机驱动。轿门结构类似层门，但更强调**轻量与联动**：

- 门扇与吊门轮、防脱靴的配合；
- 门刀（装在轿门上）与层门门锁滚轮（装在层门上）的啮合调整；
- 门机行程与开关门速度的调整。

**门保护装置**：关门过程中检测夹人夹物，**核心对比表**如下：

| 装置 | 原理 | 特点 |
| --- | --- | --- |
| 安全触板 | 门边缘触板碰到物体即反转开门 | 接触式，简单可靠 |
| 光幕（光栅） | 门两侧发射多束红外光，光束被挡即反转 | 非接触，覆盖整个门宽 |
| 超声波 / 电磁式 | 检测门区障碍物 | 特殊场合补充 |

**重点**：门保护是防夹人、防剪切的关键，其动作灵敏性要定期试验。光幕光束被遮挡但电梯仍关门，说明光幕失效或接线松动——必须立即整改，这直接关系到儿童与老人的安全。

## 4 门锁回路与门系统的安全逻辑

门系统与电气控制通过**门锁回路**（安全回路的一部分）相连，实现一条铁律：**「门不开梯不动，门不关梯不走」**。

**门锁回路**：所有层门门锁触点与轿门门锁（关门到位）触点**串联**在一条回路里。任何一扇门未锁紧，回路断开，电梯不能启动运行。<span class="marginnote">把门锁触点「串联」不是偶然：串联意味着<strong>一票否决</strong>——任何一层门没关好，整条回路都不通。这也是门锁回路严禁被短接的原因：短接等于让电梯「不知道门没关」地运行，是事故导火索。</span>

**门的联动逻辑**：

- 开门：轿厢平层停稳后，开门机驱动轿门，门刀带动层门同步开启；
- 关门：关门过程门保护装置全程监测，遇阻即反转重新开门；
- 运行条件：门完全关闭且门锁触点全部接通，电梯才能启动。

**辨析｜易错点：** 常见误区是「门关上了就能走」。实际上**「门关好」与「门锁好」是两个状态**——门扇合拢不等于锁钩啮合到位、触点接通。门系统调试时最常见的故障，就是「门看似关好但门锁触点没通」，电梯报门锁故障。判断门锁是否到位，要看触点而非只看门缝。

## 5 门系统的联动调整与验收

门系统安装后的联动调整，是「让门听话」的最后一关：

**门机参数调整**：开门保持时间、关门速度、缓冲减速位置，按乘客舒适与安全要求整定。

**门刀与门锁啮合调整**：轿厢平层时门刀插入层门门锁滚轮的深度要适中——过深啮合困难、过浅容易脱开，且每层都要复核。

**关门力调整**：关门力以不夹伤人为准，规范对关门力上限有要求，必要时测力。

**门保护试验**：用测试棒插入门缝试验光幕/触板是否反转开门，逐层试验并记录。

**联动验收**：以「轿厢不在本层时层门锁紧打不开」「轿厢在本层时能正常开关门」「关门遇阻自动反转」三项为验收底线。

**重点**：门系统调试的功夫在「**逐层**」——门刀啮合、门锁触点、地坎配合每一层都可能不同，电梯运行后才发现某层门有问题，返工成本高得多。安装阶段逐层走一遍，是门系统验收的纪律。

## 6 小结

- **门系统构成**：层门、轿门、开门机、门锁、门保护，各司其职。
- **层门安装**：门框垂直、地坎水平、门扇顺畅、门锁啮合，缺一不可。
- **门锁地位**：门锁回路串联所有门锁触点，门不开梯不动，A 类检验项目。
- **门保护**：触板与光幕防夹人，灵敏性要定期试验。
- **「关好」≠「锁好」**：判断门锁靠触点而非门缝，是调试高频坑。
