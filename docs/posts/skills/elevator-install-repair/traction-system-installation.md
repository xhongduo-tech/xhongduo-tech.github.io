## 为什么从曳引系统开始

八大系统里，曳引系统是电梯的**心脏与动力源**。它把电机的旋转运动，通过绳轮摩擦转变成轿厢的垂直运动；这套系统一旦出问题，电梯连「正常动」都谈不上，更遑论安全。对安装工来说，曳引系统的安装是整个机械施工的**第一条主线**：曳引机就位、曳引钢丝绳挂设与张力调整、导向轮定位，每一道工序都直接决定电梯能否平稳、安全地运行。<span class="marginnote">《电梯安装与维修》第2章以曳引系统开篇，符合施工逻辑：先立动力系统，再装轿厢、对重、门与导轨，最后做安全装置——机械施工的顺序本身就在回答「谁先谁后」。</span>

这一节先认清曳引系统的组成，再看曳引机结构，然后进入钢丝绳安装的核心工艺，最后用曳引条件公式把「为什么摩擦能当动力」讲透。

## 1 曳引系统的组成

**曳引系统**：由**曳引机、曳引钢丝绳、导向轮（反绳轮）**三大部分组成，其职能是把电机的旋转运动转换为轿厢的直线运动并传递全部载荷。

**曳引机**：电梯的动力装置，由电动机、制动器、减速装置（无齿轮曳引机则无）与曳引轮组成。它是整个系统中工作最繁重、故障影响最大的部件。

**曳引钢丝绳**：连接轿厢与对重的柔性传力件，一般 3–8 根并设，承担全部悬吊载荷。它既是传力件，也是安全件——断丝、磨损、锈蚀的判定直接关系生命安全。

**导向轮 / 反绳轮**：改变钢丝绳绕行方向的绳轮。轿厢侧导向轮改变绳的方向，反绳轮配合曳引比实现减速或增力。

三者的安装顺序遵循「**先主机、后挂绳、再张紧调整**」：曳引机就位并找正后，才具备挂绳的条件；绳挂好后才能做张力均衡与曳引能力验证。

## 2 曳引机结构与选型

按减速方式，曳引机分**有齿轮曳引机**与**无齿轮曳引机**两大类，**核心对比表**如下：

| 项目 | 有齿轮曳引机 | 无齿轮曳引机 |
| --- | --- | --- |
| 传动方式 | 蜗轮蜗杆或行星齿轮减速 | 电机直接驱动曳引轮 |
| 传动比 | 数十比一，转速降低、扭矩放大 | 1:1，曳引轮与电机同速 |
| 噪声与效率 | 有啮合噪声、效率略低 | 更安静、效率更高 |
| 适用速度 | 中低速（一般 ≤ 2 m/s） | 高速、超高速梯 |
| 维护重点 | 齿轮箱润滑、蜗轮磨损 | 制动器与轴承、电机散热 |

**重点**：曳引机安装的核心是**水平度与同心度**。曳引机底座须找水平，曳引轮槽中心线应与导向轮、轿厢中心在铅垂面内对正；偏差过大时，钢丝绳会偏磨轮槽、造成张力不均与异常磨损。<span class="marginnote">「找水平」在安装现场通常用框式水平仪完成，允差以设备说明书为准；无齿轮曳引机对水平度要求更高，因为电机与曳引轮同轴，任何偏斜都会直接放大为绳轮偏磨。</span>

### 曳引机的就位与找正工艺

曳引机就位是「一锤定音」的工序，找正做得不好，后期极难返工：

**基础复核**：确认机房基础承载与地脚螺栓孔位符合图纸，混凝土强度达到要求；
**吊装就位**：用倒链或吊车将曳引机吊至基础上，就位过程避免碰撞绳轮与制动器；
**初找水平**：用框式水平仪在曳引机底座加工面找水平，允许偏差按说明书；
- **精找同心**：以曳引轮槽为基准，用线坠或激光把轮槽中心线与导向轮、轿厢中心对正；
- **紧固防松**：地脚螺栓分次对角紧固，紧固后复测水平度——紧固会改变就位状态，必须复测。

**「紧固后复测」是找正的收尾动作**：地脚螺栓拧紧时产生的位移，可能把刚找好的水平度破坏掉。所以规范的找正流程，最后一步永远是复测确认。

### 曳引绳挂设的工序要点

挂绳是曳引系统施工的「最后一步大动作」，工序要点：

- **绳长确认**：按曳引比与提升高度计算绳长，预留绳头余量；长度不足则整组返工。
- **放绳防扭**：钢丝绳从绳盘上放卷时应保持原捻向，避免扭转与打折；放绳过程严禁在地面拖拽。
- **挂设顺序**：先挂轿厢侧、再绕曳引轮、后挂对重侧；各绳依次挂设，保持间距。
- **预紧与复测**：挂完后对每根绳施加预紧力，再统一调整张力，用弹簧秤复测各绳张力差。

**挂绳的质量，直接决定曳引轮的磨损寿命与运行平顺**。绳挂得歪、张力不均，曳引轮槽会偏磨出「台阶」，后期换绳都难以根治——挂绳时的一次到位，胜过维保期的十次调整。

## 3 曳引钢丝绳的安装

钢丝绳安装是曳引系统施工中**最讲究细节**的工序，分挂设、绳头制作、张力调整三步。

**挂设**：按 1:1 或 2:1 曳引比把钢丝绳从曳引轮一侧绕过，两端分别连接轿厢与对重。挂设时严禁钢丝绳在地面拖拽摩擦、严禁打折弯折，防止绳芯受损。

**绳头制作**：常用巴氏合金浇铸或绳夹固定。巴氏合金绳头把绳头散开、锥套浇注合金，连接可靠、承受疲劳好；绳夹固定则要遵守「夹座间距、夹数、防脱」的规范，绳夹鞍座必须压在受力绳段一侧。<span class="marginnote">绳夹方向是新手最易错的地方：绳夹的鞍座（有圆弧凹槽的一侧）必须贴合受力绳段，U 形螺栓压在短头（非受力）侧；装反会使受力绳段被 U 形螺栓勒伤，是严重的隐蔽缺陷。</span>

**张力调整**：各根钢丝绳的张力应基本一致，偏差一般控制在规定范围内。张力不均会导致偏磨、曳引轮槽磨损不均与轿厢晃动。

**辨析｜易错点：** 判断绳的张力，新手常用手去「捏」，这是错误且危险的做法。规范方法是用**弹簧秤**测量各绳的挠度（或测力计直接测张力），让各绳挠度一致或张力偏差在允差内。手感判断在高速梯上几乎必然出错。

## 4 公式解析：曳引条件

**曳引系统为什么靠摩擦就能吊起一吨多的轿厢？答案写在欧拉公式里。**

曳引绳在曳引轮上包绕角度为 $\theta$，紧边（轿厢侧）张力 $T_1$、松边（对重侧）张力 $T_2$，绳与轮槽摩擦系数为 $f$。曳引能够成立的条件是：

$$
\frac{T_1}{T_2} \le e^{f\theta}
$$

对这条式子做三步拆解：

- **第一步，认识符号**：$T_1$ 为紧边张力（轿厢侧总张力），$T_2$ 为松边张力（对重侧总张力），$f$ 为当量摩擦系数（取决于槽型与材料，V 形槽大于半圆槽），$\theta$ 为绳在轮上的包角（弧度），$e \approx 2.718$ 为自然常数。
- **第二步，读出边界**：$e^{f\theta}$ 是这根绳轮副所能提供的**最大摩擦传力比**。当载荷波动使 $T_1/T_2$ 超过它时，绳就打滑——打滑意味着曳引失效。
- **第三步，落到设计**：正常工况下设计者要让 $T_1/T_2$ 明显小于 $e^{f\theta}$，保证电梯有足够曳引能力；但又要留一个「**打滑阈值**」——当轿厢被卡死、对重落地等极端工况时，绳要能打滑以避免把曳引机或结构硬拖坏。<span class="marginnote">注意这里藏着曳引电梯「既要抓得住、又要放得开」的双重性格：抓得住，保证正常载重不打滑；放得开，保证极端工况绳先滑、结构不坏。这正对应检验规范里「曳引能力试验」与「制停试验」分居两端的检验项目。</span>

因此，摩擦系数、包角、张力是曳引系统的三个可调变量：增大包角（加导向轮）、增大摩擦系数（选槽型）、控制张力比，都能提升曳引能力；而这一切调整都必须在安装阶段完成。

## 5 安装后的检查要点

曳引系统安装完成，须逐项检查后才能进入后续工序：

- **水平与对正**：曳引机水平度、曳引轮与导向轮的对正符合要求。
- **绳的排列与张力**：各绳在轮槽中不跳槽、不偏磨，张力均衡。
- **绳头连接**：巴氏合金无裂纹，绳夹数量与方向正确，防脱措施到位。
- **制动器**：制动器抱闸与松闸间隙均匀，动作灵活，弹簧压力可调。
- **安全间距**：曳引轮、导向轮防护罩完好，旋转部件与固定件无干涉。

## 6 小结

- **曳引系统三要素**：曳引机（动力）、曳引钢丝绳（传力）、导向轮/反绳轮（改向）。
- **两类曳引机**：有齿轮（中低速）与无齿轮（高速），安装核心是水平度与对正。
- **钢丝绳工艺**：挂设防弯折、绳头按规范（绳夹鞍座压受力段）、张力用弹簧秤调匀。
- **曳引条件公式**：$T_1/T_2 \le e^{f\theta}$，摩擦系数、包角、张力比是三个可调变量。
- **双重性格**：抓得住（正常载重不打滑）+ 放得开（极端工况绳先滑、结构不坏）。
- **安装顺序**：先主机找正、再挂绳、后张紧调整；紧固后必复测水平度。
- **绳头工艺**：巴氏合金浇铸或绳夹固定，绳夹鞍座压在受力段、U 形螺栓压短头。
- **检查要点**：水平对正、绳排列张力、绳头连接、制动器间隙、防护罩完好。
