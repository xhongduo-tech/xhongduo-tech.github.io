## 为什么从法律法规开始

前两节讲了电梯「是什么、有什么参数」，这一节讲电梯「**归谁管、凭什么管**」。电梯不是普通的机电产品，它属于**特种设备**，从制造、安装、改造、修理到检验、使用、报废，全部处于国家强制监管之下。对安装维修工来说，法律不只是「别人罚你」的条文，更是**职业行为的边界**：哪些操作合法、哪些操作是红线，全写在法条里。<span class="marginnote">电梯安装维修工是<strong>特种设备作业人员</strong>，需要考取相应作业项目证书后持证上岗。无证作业不仅违法，事故发生后还可能构成刑事追责——这是这门职业与普通工种最本质的区别。</span>

这一节沿「法律体系 → 监管制度 → 安全技术规范 → 责任边界」的脉络展开，最后用核心对比表收拢各类主体的责任。

## 1 电梯安全的法律体系

我国电梯安全监管的法律体系呈**「法律—行政法规—部门规章—安全技术规范」**金字塔结构：

**法律层**：《中华人民共和国特种设备安全法》（2013 年颁布，2014 年起施行），是特种设备安全的基本法，确立了「预防为主、安全第一、节能环保、综合治理」的方针。

**行政法规层**：《特种设备安全监察条例》（国务院令第 549 号）在基本法之前先行建立监管框架，至今仍是重要依据。

**部门规章与规范性文件**：市场监管总局发布的《特种设备作业人员监督管理办法》等，规范作业人员考试、发证与复审。

**安全技术规范层**：TSG 系列规则（如 TSG T7001《电梯监督检验和定期检验规则》），是技术层面的强制性要求，直接指导检验与使用管理。

**重点**：法律管「责任」，技术规范管「怎么做」。安装维修工日常打交道最多的，是**安全技术规范**——它把法律的抽象要求翻译成可执行的技术条款。

## 2 电梯的全生命周期监管

电梯的监管覆盖从「出生」到「退役」的每个环节，安装维修处于其中的关键节点：

**设计制造环节**：电梯制造单位须取得**制造许可**，产品出厂附合格证与随机文件；型式试验覆盖重要安全部件（如限速器、安全钳、缓冲器）。

**安装改造修理环节**：由取得相应许可的单位施工，**施工前告知**特种设备安全监督管理部门，施工过程受**监督检验**。<span class="marginnote">「施工告知」是安装单位必须履行的前置程序：在施工前向所在地市场监管部门告知施工单位与项目信息。未告知即施工属于违法行为，也意味着后续监督检验失去依据。</span>

**使用环节**：使用单位登记、建立档案、委托维保、申报定期检验、制定应急预案。

**检验环节**：监督检验（新装/改造/重大修理后）与定期检验（在用电梯周期检验）都由法定检验机构实施。

**退役环节**：达到设计使用年限或检验不合格且无法整改的电梯，按规定停用、改造或报废。

## 3 电梯安全技术规范：TSG T7001

**TSG T7001《电梯监督检验和定期检验规则》**是电梯检验的核心安全技术规范，它把「监督检验」与「定期检验」两种检验方式统一纳入一部规则。

**监督检验**：在电梯安装、改造、重大修理过程中及完工后实施，是对施工质量的确认——前面《电梯安装工程组织与验收流程》里「报检」的动作，报的就是监督检验。

**定期检验**：对在用电梯按周期实施，验证电梯在后续使用中持续符合安全要求，周期通常为一年一次（部分项目周期不同）。

**核心对比表**如下：

| 检验类型 | 实施时机 | 检验对象 | 判定不合格的后果 |
| --- | --- | --- | --- |
| 监督检验 | 施工中 + 完工后 | 新装/改造/重大修理电梯 | 不得投入使用 |
| 定期检验 | 每年一次（按规定周期） | 在用电梯 | 停止使用、整改后复检 |
| 自行检测 | 使用单位/维保单位自查 | 日常运行状态 | 发现问题及时整改 |

**重点**：检验不是「走形式」，而是**法定确认**。电梯未监督检验合格就投入使用、或逾期未定期检验仍继续使用，都属于违法使用——安装工把检验流程记牢，也是在保护使用单位不违法。

## 4 各方责任与作业人员的法定义务

电梯安全是多方共治，各方责任不同，**核心对比表**如下：

| 主体 | 核心责任 |
| --- | --- |
| 制造单位 | 质量与安全性能、出厂资料、跟踪服务 |
| 安装/改造/修理单位 | 施工质量、施工告知、监督检验配合 |
| 使用单位 | 登记建档、委托维保、申报检验、日常管理 |
| 维保单位 | 按规范保养、故障维修、应急响应 |
| 检验机构 | 依法实施检验、出具检验报告 |
| 作业人员 | 持证上岗、按章作业、拒绝违章指挥 |

**辨析｜易错点：** 常见误解是「安装维修工只对安装维修负责」。实际上作业人员还有两项法定义务：**一是持证上岗，证书按期复审**；**二是拒绝违章指挥**——即使安装单位要求，也不能进行明知违章的操作（如短接安全回路）。这两条写在法条里，是保护作业者自己的最后防线。

### 电梯事故的法律责任

理解法律责任，能帮从业者看清「规章为什么是铁律」。电梯事故中的责任追究，遵循「**谁有过错、谁担责任，按过错程度分担**」的原则：

**行政处罚**：使用未登记、超期未检、无证作业、短接安全回路等违法行为，由市场监管部门责令改正并处罚款；情节严重的，责令停用、停产停业整顿。

**民事责任**：电梯故障造成乘客人身或财产损害的，按过错责任承担民事赔偿——维保不到位、救援不及时、记录造假，都可能被认定为过错。

**刑事责任**：发生重大事故并构成犯罪的，依法追究刑事责任。特种设备领域已有因「明知隐患仍放任运行」「伪造维保记录导致事故」而入刑的判例。<span class="marginnote">对从业者最有警示意义的，是<strong>「记录造假」的责任</strong>：没做保养却填写「正常」，一旦电梯出事，这份假记录会成为过错认定的直接证据。与其事后追悔，不如如实记录——记录诚实，是保护自己最便宜的方式。</span>

**重点**：法律责任的逻辑，是把「安全」从道德要求变成「利益约束」——不守规章，损失的不只是良心，还有执照、罚款甚至自由。理解了这一点，规章就不再是「别人的要求」，而是「自己的保护」。

### 从业者如何与监管体系打交道

电梯从业者日常与监管体系的接触，集中在几个节点：

- **持证**：考取特种设备作业人员证书，按规定复审；
- **施工告知**：安装、改造、重大修理前办理告知；
- **配合检验**：监督检验与定期检验中如实提供资料、配合现场检验；
- **记录真实**：维保记录、自检记录如实填写；
- **应急上报**：发生故障、事故按规定报告与处置。

**重点**：与监管打交道的关键词是「**合规 + 配合**」——手续齐全、行为规范、主动配合，监管对正常经营是「服务」而非「麻烦」。

## 5 小结

- **法律体系**：法律—行政法规—部门规章—安全技术规范四层金字塔，TSG 系列是技术强制性要求。
- **全生命周期**：设计制造、安装改造修理、使用、检验、退役五个环节都有监管节点。
- **TSG T7001**：统一监督检验与定期检验，是检验工作的直接依据。
- **责任矩阵**：制造、安装、使用、维保、检验、作业人员各司其职，共治电梯安全。
- **作业人员义务**：持证上岗、按章作业、拒绝违章指挥，是保护自己的最后防线。
- **法律责任**：行政、民事、刑事三层责任并存，「记录造假」是事故中最容易被定罪的过错。
- **监管接触点**：持证、施工告知、配合检验、记录真实、应急上报，合规 + 配合是关键词。
- **法规体系**：法律—行政法规—部门规章—安全技术规范四层，TSG 系列把法律翻译成可执行条款。
- **全生命周期**：设计制造、安装改造修理、使用、检验、退役五个环节都有监管节点。
