## 为什么从变频调速开始

现代电梯的核心体验——**起步柔、运行稳、停车准、电费省**——几乎全部来自变频调速技术（VVVF）。曳引电机不再简单「通电转、断电停」，而是由变频器控制电压与频率，让电机按设计的速度曲线平滑加减速。<span class="marginnote">VVVF 是 Variable Voltage and Variable Frequency（变压变频）的缩写，是当今电梯拖动的主流方案。它取代了早期的交流双速与直流调速，把电梯的乘坐体验与能耗水平整体抬升了一个台阶。</span>

这一节先讲变频调速的原理，再讲变频器与电机的配合，然后进入这一节的主角——**公式解析**，最后落到控制系统的整定步骤。

## 1 VVVF 变频调速原理

异步电机（或永磁同步电机）的转速由电源频率决定，变频调速的出发点正是**通过改变频率来改变转速**。但只变频不变压会出问题：电机绕组是感性负载，频率降低时感抗下降，电流会异常增大、磁路饱和，电机发热甚至烧毁。

解决办法是**恒压频比（U/f 恒定）**：变频的同时按比例变压，保持电机磁通基本恒定，使电机在调速范围内既不过磁、也不欠磁，输出转矩稳定。<span class="marginnote">「U/f 恒定」是 VVVF 的第一原则：变频低压，频率降一半、电压也降一半左右。高速与低速都维持良好的转矩特性，电梯才能在全速度范围内平稳驱动。</span>

**重点**：电梯用的变频器常配**速度反馈（编码器 / PG）**构成闭环，或采用高性能开环矢量控制，以获得从零速到额定速的稳定转矩——电梯要频繁起停，零速附近的转矩控制是硬要求。

## 2 变频器与曳引电机

**变频器**：把固定频率的交流电变换为电压、频率可调的交流电供给曳引电机。电梯变频器除逆变主电路外，还内置**制动单元**（能耗制动电阻）或**回馈单元**，处理电梯重载下行或轻载上行时电机的发电状态。<span class="marginnote">电梯的「发电状态」值得专门理解：重载下行时，负载带着电机转，电机变成发电机，能量反灌变频器直流母线——此时要么用制动电阻把能量耗掉，要么用回馈装置送回电网。这部分能量管理直接关系电费与机房发热。</span>

**曳引电机**：现代电梯多用**永磁同步电机（PMSM）**或异步电机。永磁同步电机体积小、效率高、可低速大转矩，与无齿轮曳引机配合成为高速梯主流；异步电机则常见于有齿轮曳引机。

**编码器 / 旋转编码器（PG）**：装在电机轴上，把转子位置与转速反馈给变频器，是闭环矢量控制的「眼睛」。编码器信号异常，电梯会表现为启动抖动、运行噪声或保护停机。

### 变频调速的舒适度指标

变频调速不仅解决「能不能动」，更解决「动得舒不舒服」。电梯舒适度用两个指标衡量：

- **加速度 $a$**：速度变化的快慢。加速度过大，启动与停车时乘客明显「前倾后仰」；过小则启停拖沓。
- **加加速度（急动度）$j$**：加速度的变化率。即使加速度不大，加加速度过大也会让乘客感到「顿挫」——所以现代电梯的速度曲线在起停段采用 S 形（加加速—匀速加—减加速），让加速度平滑过渡，而不是矩形突变。

调试时通过变频器参数设置速度曲线的斜率与圆角：斜率决定加速度，圆角决定加加速度。**「加速度不大但感觉顿挫」的故障，十有八九是加加速度设置过陡**——这是从「能跑」走向「跑得舒服」的关键一步。

### 制动与能量管理

电梯制动与能量管理是变频调速的另一个核心议题：

- **能耗制动**：电机发电状态的能量通过制动单元泄放到制动电阻，转化为热量。适用于小功率与不频繁制动的场合，电阻发热需要机房散热。
- **能量回馈**：通过回馈单元把发电能量逆变成交流电送回电网，节能且减少机房发热，是能效改造的热门方向。回馈装置须与电网参数匹配，加装后需验证谐波与电磁兼容。
- **机械制动器**：变频器负责电气减速，制动器负责「停住」与「保持」。电梯到站后变频器先降速至零，制动器才抱闸——两者配合不当（如制动器提前抱闸）会带来明显的顿挫与平层误差。

对调试者而言，**「电气制动 + 机械抱闸」的分工必须清晰**：电气制动负责把速度降到零附近，机械抱闸负责锁住静止状态。混用或分工错乱，是启动溜车与停车顿挫的常见根因。

### 调试工具与记录

变频调速调试离不开工具：万用表测电压电流、示波器看波形（如编码器信号、母线电压）、变频器面板读参数与故障代码、电脑软件联机做参数备份与监控。

调试过程应形成记录：参数表（辨识值、曲线参数、保护阈值）、试运行数据（各工况电流、平层精度、舒适度评价）、故障代码与处理。**参数表随设备存档，是后期维保「参数漂移对比」的基准**——没有初始参数，就无法判断变频器参数是否被误改、需要恢复出厂还是重新辨识。

### 常见调试问题速查

调试阶段的高频问题与排查方向，可以整理成一张速查表：

| 现象 | 优先排查方向 | 常见根因 |
| --- | --- | --- |
| 启动即过流保护 | 参数辨识是否完成、编码器接线 | 电机参数不符、编码器信号错 |
| 运行抖动 | 编码器信号、速度反馈滤波 | 编码器线接触不良、屏蔽受损 |
| 减速时顿挫 | 减速曲线斜率、加加速度 | 曲线圆角过小 |
| 平层总差几毫米 | 爬行速度、平层开关位置 | 爬行距离不足、开关移位 |
| 变频器报过压 | 制动单元、回馈装置、母线 | 发电能量无处泄放 |

速查表的价值在于**缩短「从现象到根因」的路径**：老练的调试者脑子里都有一张这样的表，遇到现象先查表定位方向，再实测确认。新手把它抄下来，能少走很多弯路——但它永远替代不了对原理的理解，查表定位后，还要回到《电梯常见故障分析与排除方法》的排查逻辑里去做验证。

## 3 公式解析：同步转速

**变频调速的物理基础，是电机转速与电源频率的线性关系。**

对交流电机，旋转磁场的同步转速 $n$（转/分）为：

$$
n = \frac{60 f}{p}
$$

对这条式子做三步拆解：

- **第一步，认识符号**：$n$ 为旋转磁场同步转速（r/min），$f$ 为电源频率（Hz），$p$ 为电机磁极对数。
- **第二步，读出直觉**：一个电流周期，磁场转过一对磁极对应的空间角度；每秒 $f$ 个周期，每分钟转过 $60f$ 个电角度周期，再除以极对数 $p$ 换算成机械转数。所以频率每升高 1 Hz，同步转速升高 $60/p$ 转/分。
- **第三步，落到电梯**：设 4 极电机 $p = 2$，额定频率 $f = 50\,\mathrm{Hz}$，则 $n = 60 \times 50 / 2 = 1500\,\mathrm{r/min}$。变频器把频率从 0 平滑升到 50 Hz，电机转速就随之从 0 平滑升到 1500 r/min——**电梯的加减速曲线，本质就是变频器的频率曲线**。<span class="marginnote">对异步电机，实际转速略低于同步转速（存在转差率）；对永磁同步电机，转速与频率严格同步。调试时「给定频率—实际转速」的对应关系是否准确，直接决定平层精度与乘坐舒适度，这也是自学习（参数辨识）要做的事。</span>

## 4 控制系统调试的步骤

变频调速电梯的调试，通常沿固定次序展开：

**参数辨识（自学习）**：变频器对电机做参数辨识，记录定子电阻、电感、磁通等参数。辨识不准，矢量控制就「看不见」电机，启动即抖动或过流。
**速度曲线整定**：设置启动曲线、运行速度、减速曲线与爬行距离。曲线过陡则顿挫，过缓则浪费时间——调出一条「快而平」的曲线是调试师傅的看家本领。
- **平层调整**：通过减速点、爬行速度与平层开关位置，把平层精度调到规定范围。现代电梯靠井道位置与速度闭环自动平层，人工调整主要是确认参数与开关位置匹配。<span class="marginnote">平层精度是调试成果的「可感知指标」：地坎差一厘米，轮椅推车就卡。TSG T7001 对平层精度有数值要求，试运行与检验时逐层抽查——调试时宁可慢工，也要让每层都落在允差内。</span>
**舒适度验证**：满载、空载、急停等工况下感受加速度变化率（加加速度），消除冲击与「点头」现象。
**保护参数设置**：过流、过压、欠压、过热、超速等保护阈值按说明书整定，既不能太灵敏误停，也不能太迟钝失护。

**辨析｜易错点：** 调试中最常见的误区是**「参数照抄手册就行」**。变频器参数必须与实际电机、曳引比、编码器线数匹配——换过电机或编码器后参数不更新，电梯会以「看似正常、实则带病」的状态运行，故障常在几个月后以随机停梯的形式暴露。<span class="marginnote">「参数随设备走」是调试的一条铁律：曳引机、编码器、变频器任一更换，都要重新做参数辨识与曲线验证，并更新记录——这条在《电梯维保记录、档案与检验申报管理》里会被强调为档案管理的核心内容。</span>

## 5 小结

- **VVVF 原理**：变频变压调速，U/f 恒定保证磁通与转矩稳定。
- **系统构成**：变频器 + 曳引电机 + 编码器反馈，制动单元处理发电状态。
- **同步转速公式**：$n = 60f/p$
