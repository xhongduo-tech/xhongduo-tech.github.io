## 为什么从电气控制开始

机械系统给了电梯「身体」，**电气控制系统**给了电梯「大脑」。没有电气控制，曳引机不会自己启动，门不会自己开关，电梯甚至不知道自己在几楼。对安装维修工来说，电气控制是**从「装得动」走向「调得懂」的分水岭**——机械故障肉眼能看，电气故障要靠读图、测量与逻辑推理。而这一切的起点，是**电路图识读**。<span class="marginnote">电梯电气控制从继电器控制走向 PLC（可编程控制器）与微机控制，但读图能力是恒定的基本功——即使现代电梯大量用电脑板，维修时仍要对照原理图定位信号从哪里来、到哪里去。</span>

这一节沿「控制系统的组成 → 电路图识读方法 → 控制方式演进 → 安全回路 → 安装调试要点」展开，最后用公式解析讲透「电路识读」这一步最核心的功夫。

## 1 电气控制系统的组成

电梯电气控制系统按功能可分为几个部分：

**主拖动控制系统**：控制曳引电机的启动、调速与制动（现代多为变频器），是系统的「动力指挥」。

**信号控制系统**：处理召唤、选层、方向、位置信号，决定电梯「往哪走、停不停」（见《电梯召唤指示与信号系统安装》）。

**操纵系统**：轿内操纵箱（楼层按钮、开关门按钮）、层站召唤盒，是人与电梯的接口。

**平层与门控制**：平层开关与门机控制，实现准确的停站与门联动。

**安全保护系统**：安全回路、门锁回路、超载、急停等，是电气控制的「刹车」。

**重点**：电气控制系统的核心思想是**「信号 → 逻辑 → 动作」**——传感器与开关产生信号，控制系统按逻辑判断，再输出动作指令。理解这条链，读电路图就有了主线。

## 2 电路图识读：从元件到逻辑

**电路图识读**是电气安装维修的基本功。一张电梯电路图由元件符号、导线连接与逻辑关系构成，读图按「**先整体、后局部；先电源、后负载；先回路、后器件**」的顺序：

**读图第一步，找电源与回路**：看图先找电源线（通常标注相线、零线、保护线），沿着电源走，凡是「从电源出去、经元件又回到电源」的闭合路径，就是一条回路。电梯控制的核心回路都围绕「电源—触点—负载—电源」展开。<span class="marginnote">「找回路」是读图的钥匙：一个按钮按下去，电流从哪里来、经过哪些触点、驱动哪个继电器或接触器，最后回到哪里——把这条闭合路径走通，这段电路就「读懂了」。读不懂的图，通常是回路没走通。</span>

**读图第二步，识别元件与触点**：按钮、继电器、接触器、限位开关、门锁触点等各有符号；同一继电器在不同位置有多个触点，靠**相同的元件标号**（如 KM1、KA2）互相呼应。

**读图第三步，理解逻辑**：触点分**常开（动合）**与**常闭（动断）**——常开触点断电时断开、通电时闭合；常闭相反。控制逻辑就是「哪些触点闭合、哪些断开」的组合。

### 自锁与互锁：两个最重要的逻辑

电梯控制里最常用的两个逻辑单元，是**自锁**与**互锁**：

**自锁（自保持）**：启动按钮松开后，靠自身的辅助触点保持回路通电。例如按启动按钮，接触器吸合，其常开辅助触点闭合「代替」按钮保持通电——电梯就这样「记得」自己要运行。

**互锁**：两个不能同时动作的回路互相闭锁。例如上行与下行接触器**互锁**——上行吸合时，其常闭触点串在下行回路里使其无法吸合，防止上下接触器同时得电造成短路。<span class="marginnote">互锁是电梯控制的安全惯例：上、下行主接触器必须互锁，这是「电气互锁」；有的还用机械联锁做双保险。互锁失效（上下同时吸合）是严重的电气事故——这正是安装与检验必查的项。</span>

**重点**：自锁解决「保持」，互锁解决「防冲突」。读懂这两个逻辑，电梯控制图的一半就通了。

## 3 控制方式的演进

电梯电气控制经历了几个阶段，**核心对比表**如下：

| 阶段 | 控制方式 | 特点 |
| --- | --- | --- |
| 继电器控制 | 继电器、接触器逻辑 | 触点多、体积大、故障率高，早期主流 |
| PLC 控制 | 可编程控制器 + 程序 | 灵活、可靠、易修改，维修靠程序判断 |
| 微机 / 智能控制 | 单片机、变频器一体化 | 集成度高、群控调度、物联网远程监控 |

**重点**：无论控制方式怎么演进，**输入信号、输出动作、安全回路**这三块是永远存在的。继电器时代的「读图」，到了 PLC 时代变成「读程序 + 读 I/O 表」，但底层逻辑同源——这也是为什么要先学继电器控制：它是理解一切控制的基础。

## 4 安全回路：电梯电气控制的生命线

**安全回路（safety circuit）**：由全部安全装置的开关串联而成的一条回路——**任何一环断开，电梯都不能运行**。它把限速器开关、安全钳开关、门锁触点、急停、缓冲器开关、断绳开关等串在一起，实现「一票否决」。

**安全回路的特性**：

- **串联**：所有安全开关串接，任一个动作（断开）即整条回路不通；
- **独立**：独立于运行控制，即使控制程序出错，安全回路仍能强制停机；
- **可检查**：回路中每环节点可测量，检修时通过分段测量定位断开点。

**辨析｜易错点：** 最常见的红线操作是**短接安全回路**——把断开的环节短接让电梯「先跑起来」。这是绝对禁止的：短接等于让电梯在失去保护的情况下运行，一旦发生事故，后果由操作者承担。安全回路断开，正确的做法是**查出并修复那个环节**，而不是绕过它。

### 安全回路的检修方法

安全回路断开了，怎么找到断点？常用**分段法**：

- 从主控制柜接线端开始，用万用表沿线测量各开关两端的电压或通断；
- 把回路分成几段（门锁段、急停段、限速器段），逐段测量，缩小范围；
- 定位到某开关不导通时，检查该开关本身与接线。

**重点**：分段测量把「几十个开关找断点」变成「几段找断点」，是检修安全回路的标准思路——这也是《电梯常见故障分析与排除方法》里「先安全回路、后运行控制」排查逻辑的体现。

## 5 电气安装与调试要点

电气系统的安装与调试，是让「大脑」与「身体」对接的工序：

**接线规范**：导线按图纸编号、颜色分区（动力、控制、保护），接线端子压接可靠、标识清楚；随行电缆、井道布线留有运动余量。

**绝缘与接地**：接线完成后测量绝缘电阻，确认接地系统可靠（见《电梯供电、照明、通风与接地保护》）。

**通电调试**：先低压、后通电；先手动、后自动；先点动、后连续——逐级验证输入信号、逻辑输出与执行动作。

**信号校验**：逐层校验召唤、选层、平层、位置信号，与运行实际对照。

**重点**：电气调试遵循「**先空载、后带载，先低速、后高速**」的渐进原则。每一步确认无误再进入下一步，是避免「一通电烧一片」的安全节奏。

## 6 小结

- **系统组成**：主拖动、信号、操纵、平层门控、安全保护五块，核心是「信号—逻辑—动作」。
- **读图方法**：先电源后负载、先回路后器件，走通回路就读懂电路。
- **两大逻辑**：自锁管保持、互锁管防冲突，是控制图的一半。
- **控制演进**：继电器 → PLC → 微机，底层逻辑同源。
- **安全回路**：串联一票否决、独立于控制、严禁短接；检修用分段法定位断点。
- **两大逻辑**：自锁管保持、互锁管防冲突，读图时先找回路、再辨触点、后读逻辑。
- **调试节奏**：先低压后通电、先手动后自动、先点动后连续，逐级验证不冒进。
- **电气安装**：接线编号、颜色分区、端子压接可靠；随行电缆留运动余量。
- **控制演进**：继电器 → PLC → 微机/智能，底层「信号—逻辑—动作」逻辑同源。
- **读图纪律**：先整体后局部、先电源后负载、先回路后器件，走通回路就读懂电路。
