## 为什么从电梯概述开始

知识树走到第十级「技能」分支，我们第一次面对一台要**对公众安全持续负责**的设备。电梯每天运送无数人，但它不是一件可以「凑合着用」的机械——它是**特种设备**，受《中华人民共和国特种设备安全法》与 TSG 系列安全技术规范强制管理。要理解后来所有的安装、调试、检验与维保，第一步是把这个庞然大物拆开看：它由哪些系统组成、各自承担什么职能、又按什么维度分类。<span class="marginnote">本专题对标《电梯安装维修工国家职业技能标准》、TSG T7001《电梯监督检验和定期检验规则》与《电梯安装与维修》三份文本，全部术语以它们为基准。</span>

电梯这个行业最迷人的地方在于：**它把「曳引摩擦」「导向」「平衡」这些上百年的机械原理，与变频调速、微机控制这些当代电气技术压缩在同一台设备里**。搞懂它，等于同时上手了一门机械课与一门电气课。我们从全局出发，先建立「电梯是什么、由什么构成、怎么分类」的骨架。

## 1 电梯的定义与曳引工作原理

**电梯（elevator / lift）**：服务于建筑物内若干特定楼层、其轿厢运行在至少两列垂直于水平面的刚性导轨之间的运输设备。

现代电梯绝大多数采用**曳引式（traction）**结构。它的核心动作可以概括为：**电机带动曳引轮，曳引轮依靠与钢丝绳之间的摩擦力，拖动轿厢与对重作相反方向的运动**。

曳引式电梯的关键是「摩擦传动」而非「卷绕传动」：钢丝绳两端分别悬挂轿厢与对重，绳与轮槽之间的摩擦力提供了全部驱动力。<span class="marginnote">这正是曳引电梯与早期卷筒电梯的本质差别：卷筒电梯把绳卷在筒上，绳与筒是刚性牵连；曳引电梯里绳与轮只靠摩擦耦合，一旦对重或轿厢撞到缓冲器，绳可以在轮槽上打滑，避免把轿厢强行拖过行程——这是电梯最重要的安全冗余之一。</span>

**曳引电梯的平衡思想**：轿厢与对重通过曳引轮形成杠杆式的平衡。当轿厢侧载荷接近对重侧重量时，曳引电机只需提供很小的驱动力矩；载荷偏离平衡点时，电机才输出相应的驱动力。这一「以平衡换节能、以摩擦换传动」的思路，是后续理解平衡系数、曳引能力的钥匙。

## 2 电梯的分类

电梯可以按用途、速度、拖动方式等多个维度分类，一张核心对比表把它们一次说清。

> **纯概念主题说明**：本节属于概念辨识内容，无核心公式，用**核心对比表**替代公式解析。

| 分类维度 | 类别 | 典型特征 / 用途 |
| --- | --- | --- |
| 按用途 | 乘客电梯 | 运送乘客，要求平稳舒适，载人为主 |
| 按用途 | 载货电梯 | 运送货物，可有人伴随，结构更结实 |
| 按用途 | 客货两用电梯 | 以载客为主，兼运货物 |
| 按用途 | 医用电梯 | 运送病床与病人，轿厢深长、平层精确 |
| 按用途 | 杂物电梯 | 仅运物不运人，轿厢狭小，载重通常 ≤ 500 kg |
| 按用途 | 观光电梯 | 轿厢壁透明，供观景，多在观光塔与商场 |
| 按速度 | 低速电梯 | 额定速度 ≤ 1.0 m/s，常见于住宅 |
| 按速度 | 快速电梯 | 1.0 < v ≤ 2.0 m/s，一般办公楼 |
| 按速度 | 高速电梯 | 2.0 < v ≤ 4.0 m/s，高层写字楼 |
| 按速度 | 超高速电梯 | v > 4.0 m/s，超高层建筑 |
| 按拖动方式 | 交流双速 | 变极调速，起制动冲击大，正被淘汰 |
| 按拖动方式 | 交流变频调速（VVVF） | 变频变压调速，平层准、能耗低，当今主流 |
| 按驱动方式 | 曳引式 | 摩擦传动，钢丝绳悬挂，最常见 |
| 按驱动方式 | 液压式 | 液压缸顶升，适合低层、大载重 |
| 按驱动方式 | 强制式 / 卷筒式 | 绳与卷筒刚性连接，曳引高度受限，已少用 |

三组维度放在一起看：**用途决定功能设计，速度决定曳引与导轨的选型，驱动方式决定整个传动链条**。一台住宅用的低速曳引客梯与一台超高速曳引客梯，原理相同，但曳引机、导轨、安全装置的等级天差地别。<span class="marginnote">对安装维修工而言，先确认「这是什么类别、什么速度等级的电梯」再动手，是最基本的前置判断——错误地把低速梯的验收标准套在高速梯上，会在检验环节直接碰壁。</span>

## 3 电梯的基本结构：八大系统

把一台曳引电梯自上而下、从机到电拆开，通常归纳为**八大系统**。这是本专题后续所有章节的地图，务必一次记牢。

**曳引系统**：由曳引机、曳引钢丝绳、导向轮（反绳轮）等组成，职能是**输出并传递动力**，是电梯的心脏。

**导向系统**：由导轨、导靴与导轨架组成，约束轿厢与对重只能沿垂直方向运动，职能是**保证运行轨迹**。

**轿厢**：由轿厢架与轿厢体组成，是**承载乘客与货物的容器**。

**门系统**：由轿门、层门、开门机与门锁装置组成，职能是**封闭层站与轿厢出入口**，防止坠落与剪切。

**重量平衡系统**：由对重与补偿装置组成，职能是**平衡轿厢自重与部分载荷**，减小曳引机负担。

**电力拖动系统**：由曳引电机、供电装置与调速装置组成，职能是**提供动力并控制速度**。

**电气控制系统**：由操纵装置、位置显示装置、控制柜等组成，职能是**协调各部件按指令动作**，是电梯的大脑。

**安全保护系统**：由限速器、安全钳、缓冲器、端站保护等组成，职能是**在异常时使电梯停止或减缓冲击**，是电梯的最后防线。

八大系统各司其职，又相互咬合：曳引系统拖得动轿厢，导向系统管得住方向，门系统守得住出入口，电气系统调度全局，安全系统在每一环失效时兜底。

## 4 一个核心辨析：曳引电梯为什么「不会断绳坠落」

初学电梯，最常被问的问题是：**钢丝绳会不会突然断掉？断掉是不是直接坠落？**

把这个问题拆成三层回答：

- **第一层，断绳概率被工程手段压到极低**：曳引钢丝绳通常由多股钢丝捻制，且有安全系数要求（乘客电梯曳引绳安全系数一般 ≥ 12），并在定期检验中逐根检查断丝与磨损。
- **第二层，即使绳出问题，安全钳兜底**：限速器在超速到设定值时动作，触发安全钳夹紧导轨，把轿厢刚性制停在导轨上——这是「最后防线」。
- **第三层，曳引打滑反而是保护**：正常运行时，若轿厢被卡住而曳引机仍施力，绳在轮槽上打滑而不是硬拉，从机械上避免了「把结构拉坏」。

**辨析｜易错点：** 很多人把「曳引摩擦」误以为「越粗糙越好」。实际上轮槽与绳的摩擦系数必须与曳引能力匹配：摩擦太小则打滑无力，摩擦太大则**磨损钢丝绳并可能在超载时无法打滑保护**。设计上正是利用「打滑阈值」做安全冗余——这不是设计缺陷，而是刻意的安全边界。<span class="marginnote">这一点在后续《曳引系统结构与曳引机、钢丝绳安装》与《限速器、安全钳、缓冲器安装与联动调整》两篇里会反复出现：安全钳动作的触发条件，正是「曳引摩擦无法继续约束的超速状态」。</span>

## 5 与整条知识树的位置

电梯不是孤立学科。它的**电气控制**部分，直接继承第三级《电工》的电路识读与低压电器知识；它的**机械结构**，与第六级《机械设计》的摩擦传动、轴承与联轴器知识呼应；它的**安全检验**逻辑，则与特种设备监管、职业安全体系同源。<span class="marginnote">本站知识树的设计里，技能级条目负责「把原理落到可操作的动作上」——读这篇时，不妨把前面学过的电路、机械常识带进来，效果远好于死记硬背部件名称。</span>本专题其余 29 篇都建立在这幅「八大系统」地图上。

## 6 小结

- **电梯定义**：沿刚性导轨垂直运行的运输设备，属特种设备，受法律法规强制管理。
- **曳引原理**：电机经曳引轮，靠绳轮摩擦拖动轿厢与对重反向运动；摩擦既是传力手段，也是打滑保护。
- **分类维度**：按用途、速度、拖动方式、驱动方式等分类，不同类别对应不同的设计与验收标准。
- **八大系统**：曳引、导向、轿厢、门、重量平衡、电力拖动、电气控制、安全保护，各司其职、相互咬合。
- **防坠落逻辑**：安全系数 + 限速器安全钳 + 曳引打滑三层冗余，构成了「不会自由坠落」的工程回答。

在下一节，我们进入电梯的**参数与术语**：额定速度、额定载重、平衡系数这些数字，才是把「结构」翻译成「设计规格」的语言。
