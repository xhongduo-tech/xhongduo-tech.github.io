## 为什么从电梯概述开始

本专题讲电梯的**安装与维修保养**。但动手之前，必须先回答三个问题：电梯是什么、电梯分几类、电梯由什么构成。这三问就是这一节的全部内容——它们是整个职业技能体系的**入口**，后面的参数、机械安装、电气调试、检验与维保，全部挂在「电梯的结构骨架」上展开。<span class="marginnote">电梯属于<strong>特种设备</strong>，受《中华人民共和国特种设备安全法》约束，由市场监管部门实行目录管理。把电梯当普通机电产品对待，是职业生涯的第一个认知错误。</span>

对初学者，这一节的价值在于**建立地图**：先看清电梯的八个子系统各管什么、彼此如何连接，再钻进每一个子系统的细节。读完全专题再回头，你会发现这一节的每一句话，都被后面的章节一句句展开了。

## 1 电梯是什么

**电梯（elevator / lift）**：服务于规定楼层的固定式升降设备，具有一个轿厢，运行于至少两列垂直的或倾斜角小于 15° 的刚性导轨之间，轿厢尺寸与结构型式便于乘客出入或装卸货物。<span class="marginnote">这是《电梯、自动扶梯、自动人行道术语》GB/T 7024 意义上的「电梯」。注意它的两个限定：一是「固定式」，区别于施工升降机、物料提升机等其它升降设备；二是「轿厢 + 导轨」，这正是曳引式电梯的基本运动学构型。</span>

电梯的安全意义远超一台机器：它一次运送几十人，一旦失控，后果是群体的。所以电梯被纳入**特种设备目录**，实行设计、制造、安装、改造、修理、检验的全链条许可管理——安装维修工持证上岗，正是这套制度的末梢。

### 一部简史

电梯的历史，是一条「先有安全，后有速度」的曲线：

**蒸汽时代**：1853 年奥的斯（Elisha Otis）在纽约水晶宫博览会上当众展示「安全钳」——他让人砍断吊绳，电梯平台被两枚弹簧卡爪咬住，没有坠落。**安全的演示先于动力的普及**，这个演示奠定了电梯进入商用的前提。

**电力时代**：19 世纪末电动机成熟，1889 年奥的斯公司制造出电力驱动电梯，电梯由「液压/蒸汽的玩具」变为「电力的交通」。

**高层时代**：20 世纪高层建筑兴起，电梯成为楼宇的垂直动脉；1950 年代起自动平层、群控调度、变频调速（VVVF）相继落地，电梯从「有人开」走向「无人智能开」。

记住这条曲线，后面讲安全装置（限速器、安全钳、缓冲器）时会反复看到「安全先于速度」的设计哲学——正是奥的斯 1853 年那个动作的现代回声。

## 2 电梯的分类

电梯按不同维度有多种分类，**核心对比表**如下：

| 分类维度 | 类别 | 主要用途 / 特征 |
| --- | --- | --- |
| 用途 | 乘客电梯、载货电梯、病床电梯、杂物电梯、观光电梯 | 载客、载货、医用、小型杂物、观景 |
| 拖动方式 | 曳引式、液压式、强制（卷筒）式 | 曳引靠摩擦传力，液压靠油缸顶升 |
| 速度 | 低速（≤ 1 m/s）、中速（1–2 m/s）、高速（2–6 m/s）、超高速（> 6 m/s） | 与建筑高度匹配 |
| 曳引机结构 | 有齿轮（蜗轮蜗杆）、无齿轮（永磁同步） | 无齿轮适用高速、更安静 |
| 有无机房 | 有机房、无机房、无底坑（小机房） | 影响安装与维保作业面 |

**重点**：分类不是「背名词」，而是**决定工艺的开关**。曳引式与液压式的安装工序完全不同；有齿轮与无齿轮曳引机的调试参数不同；高速梯对限速器、安全钳、缓冲器的要求远高于低速梯。看到一台电梯，先判类，再谈工艺，是安装工的职业本能。<span class="marginnote">本专题以<strong>曳引式乘客电梯</strong>为主线展开——它是市场保有量最大的类型，也几乎覆盖了全部典型工艺；液压电梯、杂物电梯只在相关章节顺带辨析。</span>

## 3 电梯的基本结构：八大系统

现代曳引式电梯从功能上可划分为**八大系统**，这是理解整机的骨架：

**曳引系统**：曳引机、曳引钢丝绳、导向轮/反绳轮。把旋转运动变为垂直运动，传递全部载荷——电梯的「心脏」。

**导向系统**：导轨、导靴、导轨支架。约束轿厢与对重的运行轨迹，保证垂直运行——电梯的「轨道」。

**轿厢**：轿厢架 + 轿厢体，直接承载乘客与货物。

**门系统**：层门、轿门、开门机、门锁装置。负责进出与安全隔离。

**重量平衡系统**：对重 + 重量补偿装置。平衡轿厢自重与部分载重，减轻曳引机负担。

**电力拖动系统**：曳引电机 + 供电装置。提供动力，现代多采用变频调速。

**电气控制系统**：控制柜、操纵装置、平层装置、位置显示。指挥电梯「怎么走、停在哪」。

**安全保护系统**：限速器、安全钳、缓冲器、超载保护、急停开关等。防坠落、防超速、防超载——电梯的「生命线」。

**辨析｜易错点：** 初学者常把「电力拖动系统」与「电气控制系统」混为一谈。分清二者的速记法：**拖动系统负责「给力」（把电能变成轿厢的运动），控制系统负责「指挥」（决定什么时候给力、给多大力）**。一个管力气，一个管脑子，二者在物理上由变频器与控制柜分界。

### 八大系统的协同：从按钮到平层

八大系统不是八台独立的机器，而是一条**接力链**。乘客按下召唤按钮的短短几秒，各系统完成一次协同：

**信号系统**登记召唤，把「有人要梯」送给控制系统；**控制系统**定向、调度并发出运行指令；**电力拖动系统**按指令驱动曳引电机；**曳引系统**通过钢丝绳与曳引轮把旋转变成轿厢的垂直运动；**导向系统**约束轿厢沿导轨运行；**门系统**在到站后开门放人；**安全保护系统**全程监控速度、超速与异常。

这条接力链的任何一环失效，电梯都会停下来——这就是「系统」二字的含义：**没有哪个部件是孤立工作的**。理解这条链，后面的安装与维修章节就有了统一的观察框架：装曳引机是装「链条的一环」，接控制柜是接「链条的一环」，调平层也是在调「链条的一环」。

**重点**：把八大系统记成一张「接力图」而非「零件清单」，是理解电梯整机的关键一步。后面的章节，我们正是沿着这条接力链，一环一环地把电梯装起来、调起来、保起来。

## 4 安全保护系统：电梯的立身之本

八大系统里，最值得单独展开的是**安全保护系统**——它是电梯区别于普通机电设备的关键，也是检验与维保投入最大的部分。

防坠落的三道防线层层接力：**限速器感知超速 → 安全钳把轿厢夹在导轨上 → 缓冲器吸收最后的冲击**。此外还有防超载的超载保护、防剪切的门锁与门保护、防触电的接地与漏电保护、紧急情况下的急停与应急救援装置。

**重点**：安全装置遵循「**独立于控制系统**」的设计原则——它们靠机械动作直接作用，不依赖控制电路。控制电路全瘫，安全链仍能机械制停。这个原则后面检验、故障分析时反复用到。<span class="marginnote">「独立于控制系统」还有一个推论：安全回路的每一环都<strong>串在一条电气安全回路上</strong>，任何一环断开，电梯都不能运行。维修时「把安全回路短接」是红线操作，禁止在任何工况下进行——这在《电梯作业安全防护》里会再强调。</span>

### 安全装置的组成与分工

安全保护系统内部还有细致的分工，**核心对比表**如下：

| 安全装置 | 保护对象 | 触发条件 |
| --- | --- | --- |
| 限速器 | 超速与坠落 | 运行速度超设定值 |
| 安全钳 | 坠落 | 限速器触发后夹轨 |
| 缓冲器 | 蹲底/冲顶 | 轿厢超过端站撞底 |
| 门锁与门保护 | 坠落、剪切、夹人 | 门未锁紧、门区有障碍 |
| 超载保护 | 超载 | 载重超过额定载重 |
| 急停与端站保护 | 运行异常 | 按下急停、越程 |

**重点**：每一类安全装置保护的「事故模式」不同，它们的设置位置、整定值与试验方法也因此不同——后面的《限速器、安全钳、缓冲器安装与联动调整》《电梯电气控制系统与电路图识读》《曳引式电梯检验项目与技术要求》会逐类展开。先记住一句总纲：**安全装置的使命，是把「可能的事故」在发生前变成「不可能的事故」**。

## 5 小结

- **电梯定义**：固定式、轿厢沿导轨运行的服务楼层升降设备，属于特种设备，全链条许可管理。
- **历史主线**：安全先于速度——奥的斯 1853 年安全钳演示是电梯商用化的起点。
- **分类开关**：用途、拖动、速度、曳引机结构、有无机房五种维度，判定后工艺随之不同。
- **八大系统**：曳引、导向、轿厢、门、重量平衡、电力拖动、电气控制、安全保护，是整机地图。
- **安全立身**：限速器—安全钳—缓冲器三道防线，独立于控制系统机械动作。
- **系统协同**：八大系统是一条接力链，从召唤登记到平层开门，任何一环失效整机停下。
- **安全分工**：每一类安全装置保护一种事故模式，整定值、试验方法各不相同。
