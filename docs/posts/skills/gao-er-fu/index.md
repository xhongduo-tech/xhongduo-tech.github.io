# 高尔夫

高尔夫是一项在广阔球场上以球杆将球依次击入各洞、总杆数少者为胜的运动，其核心在于挥杆、短杆与推杆技术的精准稳定，以及规则运用与球场策略的智慧博弈。以R&A《高尔夫规则》、《高尔夫挥杆技术》与PGA教学体系为纲，系统重建从场地规则、挥杆技术、短杆与推杆到球场策略、体能训练与比赛心理的完整知识体系。

## 对标教材

- R&A《高尔夫规则》
- 《高尔夫挥杆技术》
