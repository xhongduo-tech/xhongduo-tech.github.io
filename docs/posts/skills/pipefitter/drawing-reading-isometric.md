## 为什么从识图开始

管道安装的第一道工序不是拿扳手，而是**读图**。工业管网是三维的——一段管线要在平面上拐弯、爬高、穿设备，靠眼睛想象不出全貌；而图纸把它翻译成两种语言：**平面图**回答「往哪走」，**轴测图（单线图）**回答「怎么拐、怎么爬、多高」。<span class="marginnote">轴测图是管工最亲密的伙伴：它把空间管道画成一根连续的折线，X 方向画水平线、Y 方向画斜线、Z 方向画垂直线，一看就知道管子往哪边拐、往上升还是往下落。施工现场经常没有完整的平立面图，却永远有一张轴测图——因为下料、组对、安装全都靠它。</span>

这一节掌握三件事：看懂管道图的**基本要素**（线型、符号、标注）、读懂**三视图与投影**（管道在平面图上如何表示空间走向），以及独立画出**管道轴测图**（把平面图转成施工用的单线图）。识图能力决定了后面所有章节——下料、弯管、敷设——的准确率。

## 1 管道图的线型与符号

管道工程图用不同的线型与符号表达不同对象。**线型**是图面的「语法」：

| 线型 | 用途 |
| --- | --- |
| 粗实线 | 可见管道轮廓、主要管线 |
| 细实线 | 尺寸线、标注线、图例 |
| 虚线 | 被遮挡的管道、预留管线 |
| 点划线 | 中心线、轴线 |
| 双点划线 | 原有管道、假想位置 |
| 波浪线 | 管道断开处、折断线 |

**管道符号**则是图面的「词汇」。常见的有：管段（直线加箭头的流向标记）、阀门（按类型用标准图例）、法兰、弯头、三通、异径管、补偿器等。<span class="marginnote">阀门图例是最容易记混的部分：截止阀是「一横一竖中间连弧线」，闸阀是「两条平行竖线」，蝶阀是「中间一道斜杠加扇形」。判断阀门图例的原则是看它的<strong>关闭件形状</strong>——这是后面讲阀门安装时「阀杆方向、安装朝向」判断的先导。</span>

管道标注里藏着安装的关键数据：**管径（DN）、压力等级（PN）、介质代号、流向箭头、标高（EL）**。一根标注为 $\text{DN150 PN16} \ \ce{->}$ 的管线，读作「公称直径 150 毫米、公称压力 1.6 兆帕、介质沿箭头方向流动」——这就是下料与选阀门的全部前提。

## 2 管道三视图：平面、立面与投影规则

工业管道图以**正投影**原理绘制。把一根「L 形」空间管道放在三投影面之间，正对着它看，就得到**平面图（俯视）**、**正立面图**与**侧立面图**三张图。<span class="marginnote">投影规则的一句话口诀是「长对正、高平齐、宽相等」：平面图与立面图在长度方向对齐，立面图与侧面图在高度方向平齐。管道图常用的是<strong>平面图 + 单线轴测图</strong>组合，而不是机械制图的三视图全套——因为管线走向比零件形状更重要。</span>

三视图最关键的用处是**读标高**：平面图上看不出管子在半空还是贴地，必须配合立面图或标注的标高。标高的记法是 $\nabla 12.50$ 或 $\text{EL}+12.500$，单位米，通常以室内地面为 $\pm 0.000$。<span class="marginnote">管道的标高分「管中心标高」「管底标高」两种，安装时一定要看清图纸标注的是哪一种——用错一个，整段管子的净空就错了。这也是后续讲支吊架高度计算时的关键依据。</span>

## 3 管道轴测图（单线图）的画法

**管道轴测图（isometric drawing）**：把空间管道用三条坐标轴投影到一张图上的立体示意图。它遵循一个简单而严格的约定：

- **东西方向（X）**：画成水平线；
- **南北方向（Y）**：画成与水平线成 $45°$ 的斜线；
- **铅垂方向（Z）**：画成垂直线。

这三条线组成的坐标系，就是轴测图的空间语言。任意一段管道，都可以分解成「先沿 X 走多远、再沿 Y 拐、同时沿 Z 升降」的矢量叠加。于是，一段实际长度 $L$、方向余弦为 $(\cos\alpha, \cos\beta, \cos\gamma)$ 的管道，在轴测图上沿各轴画出的长度是它在各方向上的**投影分量**：

$$
L_x = L \cos\alpha, \qquad L_y = L \cos\beta, \qquad L_z = L \cos\gamma
$$

其中：

- $L_x, L_y, L_z$：管段在轴测图三轴方向上的**投影长度**，也是下料时的水平/垂直分段尺寸；
- $\alpha, \beta, \gamma$：管段空间方向与三坐标轴的夹角；
- $L$：管段的空间实际长度，满足 $L = \sqrt{L_x^2 + L_y^2 + L_z^2}$。

## 4 公式解析：从平面图读出空间长度

轴测图最有用的一个能力，是**从平面图反算空间实际长度**。平面图上量出的 $L_{XY}$ 是水平投影，而管子还有标高差 $\Delta z$，于是空间实际长度要用勾股定理合成：

$$
L = \sqrt{L_{XY}^2 + \Delta z^2}
$$

逐步拆解：

- **第一步，量水平投影 $L_{XY}$**：在平面图上量出两控制点间的水平距离（含 X、Y 两个方向的合成），它就是轴测图中斜线段的长度。
- **第二步，读标高差 $\Delta z$**：从两端的标高标注读出高差。若两端标高相同，$\Delta z = 0$，空间长度就等于水平长度。
- **第三步，合成**：$L = \sqrt{L_{XY}^2 + \Delta z^2}$。这一步回答了下料的核心问题——**「图纸上这根管子到底要下多长」**，它也是下一节讲弯管展开长度的预备知识。<span class="marginnote">这条式子看着简单，却管住了一个高频错误：在平面图上直接量直线长度就下料。图纸上标注的长度通常已经是展开或投影后的净尺寸，但两管件之间的<strong>净管段</strong>必须考虑弯头、法兰的占据长度，否则装上就短一截。这个「扣除管件长度」的修正，正是第2篇《管道下料》要讲的实用技能。</span>

## 5 识图实例：读一张给水泵出口管线

把零散知识串成一个实例。一张给水泵出口管线轴测图，通常包含：泵出口法兰 → 短管 → 止回阀 → 闸阀 → 异径管（$DN100 \to DN150$）→ 埋地或架空管线。<span class="marginnote">读懂一张轴测图按三步走：一看<strong>流向</strong>（箭头从泵出口向外），二看<strong>高程</strong>（先升后降、越管廊），三看<strong>管件清单</strong>（阀门前后的短管长度、法兰数量）。管件清单直接决定材料表——这也是识图与备料环节的天然衔接。</span>

读图时逐项核对：管径是否与泵口匹配、阀门的压力等级是否 ≥ 系统 PN 值、止回阀的安装方向是否与流向一致、标高是否满足泵的汽蚀余量要求。**读图不是「看懂了」，而是「核对过了」**——每一根管、每一个阀都要在图纸与现场之间来回对一遍，这正是后面所有安装章节的开工动作。

## 6 读图常见错误辨析

**辨析｜易错点：** 识图阶段的错误会一路传染到下料与安装，最典型的有四类：

**把投影长度当实际长度**：平面图上量出的距离是水平投影，遇到有标高差的斜管、弯管，实际长度必须按勾股定理合成。直接拿投影长度下料，装出来短一截。<span class="marginnote">这是「量图下料」的头号错误。正确做法是：先看两端标高，有高差就按 $L = \sqrt{L_{XY}^2 + \Delta z^2}$ 反算，再扣管件占据长度。图纸上标注的「图面距离」与「安装净距」是两个概念，下料前要分清。</span>

**忽略流向与坡度**：看图只关注管径和位置，忽略箭头流向与坡度标注。流向决定止回阀、疏水阀的安装方向，坡度决定排水排气，漏看任何一个都会在安装或运行时出问题。

**标高基准混淆**：图上有相对标高（以室内地面为 $\pm 0.000$）与绝对标高（以海拔为基准），混用两种基准会让整段管线标高错乱。开工前确认图纸采用的标高体系。

**管件符号读错**：三通与弯头符号相似，异径管的方向（大端小端）容易看反。读图时把每个管件的符号、方向、规格逐一核对，尤其是异径管「大端朝哪、小端朝哪」——装反了流向就对不上。

## 7 识图速记

把识图要领压成「一读、二查、三算」：

**一读**：读流向、读高程、读管件清单——按「流向 → 高程 → 管件」三步读图，脉络清晰。
**二查**：查管径与压力等级、查阀门方向、查标高基准——每根管、每个阀在图纸与现场间对一遍。
- **三算**：算空间实际长度（$L = \sqrt{L_{XY}^2 + \Delta z^2}$）、算坡度、算弯管展开——把图纸尺寸翻译成下料尺寸。

<span class="marginnote">「一读二查三算」是识图的三层功夫：读是理解、查是核对、算是转化。读懂了结构、核对对了标注、计算出了尺寸，图纸才真正变成了施工的依据——这也正是下料篇、弯管篇反复用到识图成果的原因。</span>

## 8 小结

- 管道图用**线型**（粗实线、虚线、点划线）与**符号**（阀门、管件图例）构成语法与词汇。
- 三视图遵循正投影的「长对正、高平齐、宽相等」，管道图以**平面图 + 标高**为主，轴测图为施工核心。
- 轴测图约定：X 水平、Y 成 $45°$ 斜线、Z 垂直，空间管道分解为三轴方向的投影分量。
- 空间实际长度由水平投影与标高差合成：$L = \sqrt{L_{XY}^2 + \Delta z^2}$
