## 为什么从基本规定开始

前面的章节把材料、工具、连接都备齐了，现在要回答一个问题：**一条工业管道到底按什么顺序装起来？** 工业管道安装不是「哪根方便装哪根」，而是一套有严格次序与检验节点的施工程序——每个节点都是一道质量门，过了这道门才能进入下一道工序。<span class="marginnote">GB 50236 第 3 章的基本规定，本质上是一张「质量关卡图」：从技术交底、材料验收，到预制、组对、焊接、无损检测、试压、防腐保温、交工，每一站都有记录、有签字、有标准。管工眼里的一条管线，其实是几十个质量节点的链条。</span>

这一节建立管道安装的**总程序框架**、**开工条件**与**中间检验**制度，为第3篇后面各节提供「工序地图」。

## 1 安装的总施工程序

工业管道安装的典型程序可以画成一条流水线：

**技术准备** → **材料验收** → **管道预制** → **支架安装** → **管道安装（组对焊接/连接）** → **无损检测** → **强度与严密性试验** → **防腐保温** → **系统吹洗** → **交工验收**。

每一步之间不是「做完就完」，而是「做完并检验合格再进入下一步」：<span class="marginnote">程序里最容易走样的地方是「跳序」：为了赶工期，先装管再补支架、先保温再试压、先试压再补无损检测。规范之所以强调顺序，是因为<strong>每一步的检验结果会掩盖或暴露上一步的缺陷</strong>——支架没装就试压，管子因自重下垂，试压结果失真；保温先做了，焊缝缺陷被盖住看不见。</span>

| 工序 | 主要检验 / 记录 | 把关重点 |
| --- | --- | --- |
| 技术准备 | 图纸会审、技术交底 | 图纸疑问闭环 |
| 材料验收 | 材质证明、复验 | 管材、阀门的 PN/DN/材质 |
| 管道预制 | 预制件尺寸、坡口检查 | 下料、坡口、组对 |
| 管道安装 | 安装记录、隐蔽记录 | 标高、坡度、连接质量 |
| 无损检测 | RT/UT 报告 | 焊缝合格率 |
| 试压 | 试验记录 | 强度、严密性 |
| 防腐保温 | 施工记录 | 除锈等级、保温厚度 |
| 交工 | 交工资料汇编 | 全套记录齐全 |

## 2 开工条件：五不装

管道安装开工前，先要核对**开工条件**，规范与实践把它概括为「五不装」：

**图纸没交底不装**：施工图、技术交底未完成，不清楚就动手，必然返工。
**材料没验收不装**：管材、管件、阀门的材质证明与复验不合格，不得使用。
**工序没衔接不装**：土建（基础、预埋件）未验收、设备就位未完成，管道没有可依附的基准。
- **焊接工艺没确认不装**：焊接工艺评定、焊工资格未确认，焊缝质量没有制度保障。
- **安全措施没落实不装**：动火、吊装、脚手架等作业的安全条件不具备，禁止开工。<span class="marginnote">「五不装」不是教条，而是每一条背后都有事故教训：图纸未交底装上反了要拆；材料未复验用错材质要换；基础未验收装完支架就歪；焊工资格未确认，焊口全部返工。管工拿到任务单后，第一件事是对照「五不装」自查。</span>

## 3 中间检验与工序交接

管道安装实行**工序交接检验**制度：上一道工序完成后，由质检人员检查，合格后**办理工序交接记录**，才能进入下一道工序。关键的中间检验节点：

**隐蔽工程检验**：埋地管道、管沟内管道、墙内管道安装后、回填或封闭前，必须检验并做隐蔽记录——因为一旦封闭就看不见了。<span class="marginnote">隐蔽工程是质量记录的「重灾区」：埋地管的防腐、接口、坡向，回填土一盖全部看不见。所以隐蔽验收的时间点是「回填之前」，验收内容写进隐蔽记录，附照片与签字。漏做隐蔽记录，交工资料就缺一大块。</span>

**无损检测节点**：焊缝焊接后、试压前，按规范比例进行射线（RT）或超声（UT）检测。检测不合格的焊口，返修后重新检测——**检测在试压之前**，因为试压压力可能把有缺陷的焊口直接暴露，代价更大。

**强度试验节点**：管道系统安装完毕、无损检测合格、防腐保温之前（或之后按规范），进行强度与严密性试验。试验合格是进入吹洗与保温的前提。

## 4 公式解析：安装坡度的确定

管道安装里最常被「基本规定」约束的量，是**管道坡度**——让介质按设计方向流动、让水或气顺利排出。坡度的定义式：

$$
i = \frac{h_1 - h_2}{L} \times 100\%
$$

其中：

- $i$：管道坡度（%），如 $i = 0.3\%$ 表示每 100 m 水平长度高差 0.3 m；
- $h_1$：管道起点标高（m）；
- $h_2$：管道终点标高（m）；
- $L$：管道水平投影长度（m）。

公式解析分三步：

- **第一步，看坡度的含义**：坡度是「沿流向单位水平长度的高度变化」。$h_1 > h_2$ 表示顺流向下坡，排水顺畅。
- **第二步，看设计规定**：坡度方向与数值由设计给定——蒸汽管一般顺流坡（利于疏水），水管道坡向泄水点，气体管道坡向排水器。**安装时必须按设计放坡，不反坡**。
- **第三步，看实测方法**：用水平尺或水准仪测两端标高，算出实际 $i$，与设计值核对。坡度错误在试压与运行时才暴露——水排不出去、气体积在管内。<span class="marginnote">反坡（倒坡）是最隐蔽的安装错误：图纸要求 0.3% 顺流坡，装成逆流坡 0.3%，运行时管底积水、汽液两相流喘振，管道振动甚至水击。坡向与坡度要在<strong>支架安装时</strong>就控制住——支架标高差定了，管子坡度就定了，这正是下一节《支吊架制作与安装》的衔接点。</span>

## 5 施工组织与进度管理

程序之外，一条工业管道的安装还要靠**施工组织**把它管起来：

**施工方案**：按程序编制施工方案，明确工序、人员、机械、检验节点。方案是程序的「落地文件」——每一道工序配什么工种、用什么机械、卡哪个检验点，都写进方案。

**技术交底**：开工前向班组做技术交底，把图纸要求、工艺要求、安全措施讲清楚。交底不是「念一遍图纸」，而是**把关键尺寸、关键工艺、易错点讲到每个人**。<span class="marginnote">技术交底是质量的第一道「教育关」：图纸上的一句话要求，交底时要翻译成现场的具体动作——「这道坡口 60°、间隙 2~3 mm、错边不超过 1.5 mm」。交底到人，返工率下降一大半；交底走过场，问题就留在后面。</span>

**进度与工序平衡**：管道安装与土建、设备、电气等多专业交叉，进度要按工序衔接安排——支架基础未做完不能装管道，设备未就位不能配管。抢工序是质量的大敌，进度管理的第一原则是「**工序不抢、检验不跳**」。

**记录同步**：施工记录随工序同步填写，不补记、不后记。记录同步是交工资料真实性的保证——这与最后一篇《验收与交工资料》的「隐蔽记录当场签」是同一逻辑。

## 6 施工程序速记

把安装程序的精髓压成「三不、一同步」：

**不跳序**：按「技术准备 → 材料验收 → 预制 → 支架 → 安装 → 检测 → 试压 → 防腐保温 → 交工」顺序走，禁止为赶工跳序。
**不虚检**：中间检验不是走过场，隐蔽工程、无损检测、强度试验节点一关不落。
**不抢工**：工序未衔接不装（五不装），土建基础、设备就位不完成，管道不抢装。
- **记录同步**：施工记录随工序当场签，不补记不后记。

<span class="marginnote">「三不一同步」是安装程序的负向清单：不跳序守住顺序、不虚检守住质量、不抢工守住条件、记录同步守住真实。四个「不」挡住的是安装阶段最常见的四种违规——它们背后，就是 GB 50236 第 3 章基本规定的全部精神。</span>

## 7 小结

- 管道安装是一条「**技术准备 → 材料验收 → 预制 → 支架 → 安装 → 检测 → 试压 → 防腐保温 → 交工**」的质量链条。
- 每道工序「做完并检验合格」才能进入下一道，禁止跳序抢工。
- 开工查「五不装」：图纸、材料、工序、焊接工艺、安全措施逐项确认。
- 中间检验的关键节点是**隐蔽工程、无损检测、强度试验**，三者都有记录与签字。
- 管道坡度 $i = (h_1-h_2)/L$
