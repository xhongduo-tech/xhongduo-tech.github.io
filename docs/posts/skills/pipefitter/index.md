# 管道工（工业管道与长输管网施工）

管道工负责工业管道与压力管道系统的管件加工、焊接连接、安装敷设、试压吹扫及防腐保温。以《国家职业技能标准—管工》、GB 50268 与 GB 50236 为纲，系统掌握从识图备料、管件加工预制、工业与长输管网安装，到试压吹扫、防腐保温与验收交工的全流程技能，学完即具备独立完成工业管道与长输管网施工的能力。

## 对标教材

- 《国家职业技能标准—管工》
- GB 50268《给水排水管道工程施工及验收规范》
- GB 50236《现场设备、工业管道焊接工程施工规范》
