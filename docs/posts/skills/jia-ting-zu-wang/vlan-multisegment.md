## 为什么从 VLAN 开始

上一节的「双路由器多网段」是一个思路：用多台设备把网络切开。但还有另一个更精妙的思路——**一台设备，也能切出多个互不干扰的网络**。这就是 **VLAN（虚拟局域网，Virtual Local Area Network）**。

家庭场景里，VLAN 最典型的化身你早就见过：路由器后台的「**访客网络**」。它让客人的手机连上 WiFi，却访问不了你家 NAS、打印机、智能家居——这正是 VLAN 的隔离能力。这篇讲清楚 VLAN 的原理、家用怎么用、以及它和「网段/子网」的关系。

## 1 VLAN 是什么

**VLAN（虚拟局域网）**：在一台（或多台）物理交换机上，通过逻辑配置把端口划分成若干独立的**广播域**。不同 VLAN 里的设备，虽然插在同一台交换机上，但彼此「看不见」——二层广播不能跨 VLAN，就像物理上接在不同的交换机上一样。

VLAN 靠**802.1Q 标签**实现：交换机在以太网帧里插入一个 4 字节的 VLAN 标签，标明这帧属于哪个 VLAN。

$$
\text{以太网帧} \xrightarrow{\text{插入 4 字节 802.1Q 头}} \text{带 VLAN 标签的帧}
$$

**重点：VLAN 的核心价值是「隔离」**——隔离广播域（避免广播风暴扩散）、隔离访问（访客不能碰内网）、隔离安全风险（被攻破的 IoT 设备够不到核心设备）。<span class="marginnote">回顾《以太网与局域网基础》一篇：交换机不隔离广播域，广播会传遍全网；VLAN 就是「让交换机也能切广播域」的技术，一台交换机被切成 N 个 VLAN，就等于 N 台互不相通的交换机。</span>

## 2 家用场景的 VLAN 划分

家庭网络里，VLAN 最实用的划分是按「信任级别」分三四个网段：

| VLAN | 设备 | 信任级别 | 需要访问外网 | 需要访问主网 |
| --- | --- | --- | --- | --- |
| **主网络** | 电脑、手机、NAS | 高 | 是 | — |
| **访客网络** | 客人手机 | 低 | 是 | **否** |
| **IoT/智能家居** | 摄像头、智能音箱 | 低 | 是 | 看需求 |

**重点：访客网络与 IoT 隔离，是家庭网络安全性价比最高的两个动作。** 客人连「访客 WiFi」，能上网但够不到你的 NAS；智能家居设备即使被入侵，也摸不到你的电脑与手机。<span class="marginnote">很多家用路由器自带的「访客网络」开关，本质就是一个预设好的简易 VLAN：默认禁止访客访问内网，但可以上网。真正要自己动手配 VLAN 的场景，通常是「智能家居隔离」——需要路由器支持多 SSID 与 VLAN 绑定。</span>

**辨析｜易错点：**「访客网络 = 第二个 WiFi 密码」是常见误解。访客网络的核心不是「多个密码」，而是**网络隔离**——它和主网络在二层上是不通的。如果只把访客网络当成「第二个 SSID」而没启用隔离，客人照样能扫描到你家设备。

## 3 802.1Q 标签与 VLAN ID

VLAN 要能工作，每个 VLAN 必须有一个**唯一编号 VLAN ID**。802.1Q 用帧里的 **12 位字段**存储 VLAN ID：

$$
2^{12} = 4096 \quad \Rightarrow \quad \text{VLAN ID 范围 } 1 \sim 4094
$$

分三步拆解：

- **第一步，看 12 位能编多少**：12 位二进制能表示 $2^{12} = 4096$ 个值（0–4095）。
- **第二步，排除保留值**：VLAN 0 与 VLAN 4095 被协议保留（0 表示「不带标签」，4095 保留），所以**可用范围是 1–4094**。
- **第三步，家用取小值**：家用网络用到 1、2、3 个 VLAN 就绰绰有余，常用约定是 VLAN 1 主网、VLAN 2 访客、VLAN 3 IoT。

**直觉：VLAN ID 就像「楼层号」**——同一栋楼（一台交换机），按楼层（VLAN）把人隔开；电梯（路由器）负责让不同楼层之间的人按规则走动。

## 4 端口模式：Access 与 Trunk

VLAN 配置落地到交换机端口，分两种角色：

**Access 端口（接入端口）**：属于**一个固定 VLAN**，连接终端设备（电脑、AP）。帧进出这个口时，交换机会剥掉或打上对应的 VLAN 标签，终端感知不到 VLAN 的存在。

**Trunk 端口（干道端口）**：同时承载**多个 VLAN** 的流量，连接交换机与交换机、交换机与路由器。帧带着 VLAN 标签原样通过，靠标签区分各自属于哪个 VLAN。<span class="marginnote">Trunk 口是「多 VLAN 共享一根线」的通道：两栋楼之间只拉一根线，却能传所有 VLAN 的流量，就是靠 Trunk + 标签。家庭组网里，路由器与交换机之间若要跑多个 VLAN，就该用 Trunk。</span>

**核心对比：Access 与 Trunk**

| 对比维度 | Access 端口 | Trunk 端口 |
| --- | --- | --- |
| 承载 VLAN 数 | 1 个 | 多个 |
| 是否打标签 | 终端侧不打 | 打标签 |
| 连接对象 | 终端设备 | 交换机/路由器 |
| 家用场景 | 接电脑/AP | 交换机级联、VLAN 到路由器 |

## 5 VLAN 之间靠什么互通

VLAN 是二层隔离，但**不同 VLAN 的设备和智能家居要上网，最终还是要跨 VLAN 通信**——这必须靠三层（IP 路由）来完成。

- 每个 VLAN 通常配一个**独立子网**（如 VLAN 1 是 `192.168.1.0/24`，VLAN 2 是 `192.168.2.0/24`）。
- VLAN 之间的流量要经过路由器（或三层交换机）转发，同时受**访问控制**约束——主网允许主动访问 IoT，IoT 不允许访问主网。
- 家用路由器如果支持「VLAN 间访问控制」，就能写出「允许谁到谁」的策略。

**辨析｜易错点：**「VLAN = 子网」是常见混淆。两者不同维度：**VLAN 是二层广播域隔离，子网是三层 IP 划分**。常规做法是「一个 VLAN 配一个子网」，但 VLAN 的隔离能力来自二层，子网只是配套的三层地址规划。判断两台设备能不能二层互通，看 VLAN；能不能三层互通，看路由与访问控制。

**再辨析一个高频坑：**「我把 IoT 设备放进访客网络，为什么它反而连不上网了？」因为部分智能家居设备**只支持 2.4 GHz、且需要和手机同一网段才能配网**。把 IoT 单独隔离成 VLAN 的代价，是配网时手机要先临时切到那个网段——这是「安全隔离」与「易用性」之间的取舍，后面《智能家居设备联网》一篇会给出完整方案。

### 单臂路由：一台设备管多个 VLAN 的互通

不同 VLAN 之间要通信，必须经过三层设备（路由器）。但家庭或小型网络里，「每个 VLAN 都配一台路由器」太奢侈，于是有了**单臂路由（router-on-a-stick）**：

1. 交换机把多个 VLAN 的流量通过**一条 Trunk 链路**送到路由器。
2. 路由器的物理接口上划出**多个逻辑子接口**（如 `eth0.10`、`eth0.20`），每个子接口对应一个 VLAN、配一个网关 IP。
3. 数据包带着 VLAN 标签到达路由器，路由器按子接口路由转发。

**重点：单臂路由是「一根线、多个 VLAN、一个路由器」的标准解法。** 家用路由器如果支持 VLAN 与子接口，就能用一台设备管「主网 + 访客 + IoT」三个网段的互通与隔离——这正是企业三层交换思想在家用设备上的浓缩版。

### 家用路由器怎么知道支不支持 VLAN

不是所有家用路由器都开放 VLAN 功能。判断方法：

- **后台搜索「VLAN」**：路由器的网络设置里有没有 VLAN/IPTV 绑定选项（很多带 IPTV 功能的路由器有隐藏的 VLAN 设置）。
- **查看型号参数**：官方规格里是否标注「支持 802.1Q VLAN」「支持多 SSID + VLAN 绑定」。
- **刷第三方固件**（OpenWrt）**几乎必然支持**——但代价是放弃官方固件（《固件升级与路由器日常维护》一篇讲过第三方固件的权衡）。

**易错点：**「路由器有访客网络 = 支持 VLAN」不完全成立。访客网络是「做好的 VLAN 隔离」，但通常**不允许自定义 VLAN ID 与更多网段**；要真正自由划分多网段，还是得确认设备支持 802.1Q。

## 6 小结

- **VLAN** 是「一台设备切出多个独立广播域」的技术，靠 **802.1Q 标签**标识帧属于哪个 VLAN。
- 家用 VLAN 按信任划分：**主网、访客、IoT** 三段，访客与 IoT 隔离性价比最高。
- VLAN ID 是 12 位字段，**可用 1–4094**（0 与 4095 保留）。
- 端口分 **Access（单 VLAN、接终端）** 与 **Trunk（多 VLAN、级联）** 两种角色。
- VLAN 是二层隔离，跨 VLAN 通信靠**三层路由 + 访问控制**；VLAN 与子网是不同维度，通常一配一。
