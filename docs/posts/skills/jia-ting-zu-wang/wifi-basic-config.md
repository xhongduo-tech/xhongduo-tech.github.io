## 为什么从 WiFi 基本配置开始

家庭网络里，用户感知最强的永远是 WiFi：连得快不快、信号稳不稳、密码对不对。它也是配置项最多、最容易出错的一环——频段、频宽、信道、加密、功率，每一项都影响体验，但每一项的默认值未必适合你家。

这一篇把 WiFi 基本配置讲透：先理解无线接入的本质，再逐一拆解后台里的每个配置项，最后落到「双频怎么选、速率怎么算、常见坑怎么避」。它是第3篇《WiFi 频段与信道选择优化》的基石——先会配，再谈优化。

## 1 WiFi 的工作原理

**WiFi（Wireless Fidelity）**：基于 IEEE 802.11 系列标准的无线局域网技术。它的基本工作模型是「**AP + 终端**」：

**无线接入点（AP）**：持续在指定信道上广播**信标帧（beacon）**，通告「我的 SSID 在这里」。
**终端（station）**：手机/电脑扫描信道，发现 SSID，输入密码完成**认证与关联（association）**，此后与 AP 建立无线链路。
**关联之后**：终端通过 AP 接入背后的有线网络，AP 充当无线设备与有线网络的「桥」。

**重点：WiFi 是半双工共享介质。** 同一时刻，一个信道上一台设备发送、其余设备接收（除非是 Wi-Fi 7 的 MLO 等多链路技术）。这意味着无线速率是「所有连上这台 AP 的设备共享的」，设备越多，单台能分到的越少——这与有线交换机每个端口独享带宽完全不同。<span class="marginnote">「为什么家里 5 台设备同时刷视频就卡」的根本原因就在这：无线是共享信道，单台路由器的总吞吐就那么多。这也解释了为什么 Mesh 组网要用多节点分担负载。</span>

## 2 基本配置项逐一拆解

路由器后台「无线设置」页的每一项，都对应一个可以优化的参数：

| 配置项 | 它是什么 | 配置建议 |
| --- | --- | --- |
| **SSID** | 无线网络名称 | 改成易识别、不含中文特殊字符的名字 |
| **加密方式** | 无线数据加密协议 | 用 WPA3 或 WPA2/WPA3 混合 |
| **无线密码** | 接入密钥 | ≥10 位，大小写+数字 |
| **频段** | 2.4 GHz / 5 GHz | 双频同时开，各司其职 |
| **频宽** | 信道占用的频率宽度 | 2.4 GHz 用 20 MHz，5 GHz 用 80/160 MHz |
| **信道** | 具体使用的频段通道 | 自动即可，手动时避开邻居干扰 |
| **发射功率** | 信号强度 | 默认或调低节能，不必拉满 |
| **WPS** | 一键配网 | **关闭**（安全风险） |

**辨析｜易错点：**「发射功率拉满信号就最好」是常见误解。功率只是发射端的事，**决定连接质量的是接收端收到的信噪比**——你把 AP 功率调满，邻居家的干扰也一起放大，信噪比未必提升；而且国内法规对 EIRP 有 20 dBm 左右的上限，路由器出厂就压线了。真正提升覆盖靠的是**摆放位置与节点数量**，不是把功率旋钮拧到底。

### 无线加密方式怎么选

后台「加密方式」下拉框里有 WEP、WPA/WPA2、WPA2/WPA3 混合等选项，家用怎么选？

**看设备新旧**：家里全是近年设备（2019 年后），直接选 **WPA3（WPA3-Personal）**；还有老设备（老智能家居、旧笔记本），选 **WPA2/WPA3 混合模式**——它让新设备用 WPA3、老设备降级到 WPA2，两者都能连。

**避开两个坑**：一是别选 WEP（已全面淘汰，形同虚设）；二是别选「仅 WPA2」而关掉 WPA3 兼容，除非所有设备确认不支持 WPA3。加密方式的完整原理见第3篇《无线加密与接入安全》，这里只需要记住：**默认选 WPA2/WPA3 混合，最省心最安全。**

### 多 SSID：一个路由器开几个网络

现代路由器支持**多 SSID**：同一台路由器同时广播两三个 WiFi 名称，每个名称对应一套独立配置：

**主网络**：主人设备用，全功能。
**访客网络**：客人用，开启「访客隔离」（只能上网、不能访问内网）。
**智能家居网络**（部分路由器支持）：专门给 IoT 设备，配合 VLAN 隔离（见第2篇《VLAN 划分与多网段管理》）。

**重点：多 SSID 让「一台路由器物理上分出多个逻辑网络」**，是家庭网络里「安全隔离」最便宜的实现——不用买新设备，只需在后台多开几个 WiFi。

## 3 双频 WiFi：2.4 GHz 与 5 GHz

现代家用路由器默认开启**双频**：一个 2.4 GHz 频段、一个 5 GHz 频段，SSID 常带 `_2.4G` / `_5G` 后缀。两者是「覆盖」与「速度」的取舍：

| 对比维度 | 2.4 GHz | 5 GHz |
| --- | --- | --- |
| 覆盖范围 | 大，穿墙能力强 | 小，穿墙衰减明显 |
| 干扰程度 | 高（蓝牙、微波炉、邻居都用） | 低（信道干净） |
| 最高速率 | 低（约 300–600 Mbps） | 高（约 800 Mbps–数 Gbps） |
| 适用设备 | 远距离、老设备、智能家居 | 近场高速设备 |

**重点：正确用法是「按设备分工」而不是「全挤在 5 GHz」。** 手机、笔记本、电视盒子这类追求速度的设备连 5 GHz；智能灯泡、插座、扫地机器人这类「隔墙、低频、不在乎速度」的设备连 2.4 GHz。<span class="marginnote">很多智能家居设备只支持 2.4 GHz 频段——这是《智能家居设备联网》一篇里反复出现的一个约束：配网时若手机连的是 5 GHz，设备反而搜不到网络。</span>

### 一个实用开关：独立控制频段

后台里常有「关闭 2.4 GHz / 关闭 5 GHz」的开关，偶尔非常有用：某些老智能家居设备配网时，临时**关掉 5 GHz**，让手机和配网设备都留在 2.4 GHz 上，配网成功率会大增——配完再开回来。平时两个频段都开着，按第3篇《WiFi 频段与信道选择优化》的分工使用即可。

## 4 公式解析：香农公式决定无线速率上限

无线链路的速率上限不是路由器标出来的，而是**物理定律**决定的。香农公式给出了信道容量的天花板：

$$
C = B \log_2(1 + \text{SNR})
$$

其中 $C$ 是信道容量（bit/s），$B$ 是信道带宽（Hz），$\text{SNR}$ 是信噪比（信号功率/噪声功率）。

分三步拆解：

- **第一步，看带宽 $B$**：信道越宽，容量越大。这就是为什么 5 GHz 频段能用 80/160 MHz 频宽、速率远高于 2.4 GHz 的 20 MHz——**频宽直接进公式线性放大容量**。
- **第二步，看信噪比 SNR**：信号越强、噪声越低，$\log_2(1+\text{SNR})$ 越大。这就是为什么离路由器越近速度越快、隔墙（信号衰减）速度骤降。
- **第三步，组合直觉**：想提速，要么拓宽频段（用 5/6 GHz），要么提升信噪比（靠近 AP、减少干扰）——**路由器标称的「AX3000」是理论极限，香农公式告诉我们实际远低于它**，因为 SNR 永远不可能是无穷大。

<span class="marginnote">香农公式是全站反复出现的一条主线：它在第二级《信息论》是核心定理，在这里是无线速率的物理天花板，到大模型时代则是「数据带宽决定训练吞吐」的底层逻辑——同一个公式，三个尺度。</span>

## 5 常见困惑与易错辨析

**「WiFi 显示已连接，但就是上不了网」**：这是最经典的 WiFi 故障。WiFi「连接成功」只说明**链路层通了**，上网还需要 DHCP 拿到 IP、网关能出网、DNS 能解析。排查顺序：先看能否 `ping` 网关（链路通）、再看能否 `ping` 公网 IP（出网通）、最后看能否 `ping` 域名（DNS 通）——卡在哪一步，问题就在哪一层。

**「隐藏 SSID 是不是更安全？」**：隐藏 SSID 只是不让网络名在广播里出现，**数据包里的 SSID 字段依然存在**，用工具一抓就能发现。它挡得住「图省事蹭网」的路人，挡不住任何稍有手段的攻击者。<strong>安全靠的是强密码与加密方式，不是靠「看不见」。</strong>

**「5 GHz 信号为什么总是断？」**：5 GHz 穿墙衰减远大于 2.4 GHz，隔一两堵承重墙后信号掉得很快。解决靠调整位置、Mesh 节点或让设备自动切换频段，而不是把 5 GHz 关掉。

## 6 小结

- WiFi 是「**AP + 终端**」模型，无线是**共享信道、半双工**，总吞吐由所有连接设备分摊。
- 基本配置项里，**加密（WPA3/WPA2）、密码强度、频段分工**是核心，WPS 应关闭。
- 双频分工：**5 GHz 给高速近场设备，2.4 GHz 给远距离与智能家居**。
- 无线速率上限由**香农公式 $C = B \log_2(1+\text{SNR})$** 决定：带宽与信噪比是两大杠杆。
- 排查「连上却上不了网」按三层走：**网关 → 公网 → DNS**。
- **隐藏 SSID 不等于安全**，安全靠强密码与加密。
