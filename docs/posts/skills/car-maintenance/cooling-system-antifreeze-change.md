## 为什么从冷却开始

上一节机油管住了「摩擦生热」的一半，这一节处理另一半：燃烧产生的巨大热量。汽油燃烧温度可达 2000 ℃ 以上，而发动机金属部件必须在约 90–110 ℃ 的工作温度下运行——温度过高会烧毁机油、拉缸、爆震，温度过低则燃烧不完全、油耗上升。<span class="marginnote">发动机「过热」（开锅）是仅次于缺机油的第二大致命故障：缸垫烧穿、缸盖变形、活塞卡死，一次过热就可能让发动机报废。</span> 冷却系统就是在这条温度红线上走钢丝的「体温调节系统」，而它的工作介质——防冻液——绝非普通的水。

## 1 冷却系统的组成与循环

**冷却系统（cooling system）**：通过冷却液在发动机水套与散热器之间的循环，把多余热量排到大气的系统。其主要部件：

| 部件 | 作用 |
| --- | --- |
| 水套 | 缸体与缸盖内的空腔，冷却液在其中流过吸热 |
| 水泵 | 驱动冷却液循环，通常由皮带带动 |
| 散热器（水箱） | 把冷却液的热量散到空气 |
| 节温器 | 根据水温自动切换循环路径 |
| 电动风扇 | 低速/怠速时强制通风散热 |
| 膨胀水壶（储液罐） | 容纳冷却液热胀冷缩与排气 |
| 冷却液温度传感器 | 监测水温，供仪表与 ECU 使用 |

<span class="marginnote">冷却系统有「小循环」与「大循环」两个回路，切换开关就是节温器：冷车时节温器关闭，冷却液只在发动机内部小循环，快速暖机；水温达到约 82–90 ℃ 时节温器打开，冷却液流经散热器大循环散热。节温器卡死是大循环不工作、水温过高的常见原因。</span>

**循环的直觉**：水泵把冷却液压入水套 → 冷却液吸收缸壁热量 → 流过节温器进入散热器 → 风扇与迎面风把热量带走 → 冷却液降温后回到水泵。这个回路在发动机运转期间持续工作，把「热」从发动机搬到散热器，再搬到空气里。

## 2 防冻液：不只是「水」

**防冻液（antifreeze/coolant）**：以乙二醇或丙二醇为防冻组分、加水与添加剂调配而成的冷却介质。它比水强在四个方面：

**防冻**：纯水在 0 ℃ 结冰，体积膨胀会撑裂缸体与散热器；乙二醇水溶液把冰点压低到 -35 ℃ 甚至更低。
**防沸**：水的沸点在常压下只有 100 ℃，冷却系统加压后防冻液沸点可达 120 ℃ 以上，避免「开锅」。
**防腐防垢**：添加剂保护铝制缸体、散热器与橡胶密封，防止水垢堵塞水套。
**润滑水泵**：防冻液对水泵轴承与密封件提供润滑保护。

<span class="marginnote">「加水就行」是冷却系统最大的误区。自来水含有矿物质，长期使用会在水套内结水垢，降低换热效率，还会腐蚀铝制缸体。应急缺水可以临时加蒸馏水，但事后应尽快更换为合规防冻液。</span>

**防冻液类型**：按防冻组分，主流是**乙二醇型**（绿色、红色、蓝色）与**丙二醇型**（环保型）。不同颜色通常代表不同配方，混用可能引起添加剂沉淀——更换时最好使用与原车相同的型号，或彻底冲洗后换新。

### 公式解析：冷却液带走多少热量

冷却系统能带走的热量，由热力学的基本公式决定：

$$
Q = c \cdot m \cdot \Delta T
$$

- **第一步，认识符号**：$Q$ 是冷却液吸收的**热量**（单位 $\mathrm{J}$）；$c$ 是冷却液的**比热容**（单位 $\mathrm{J/(kg\cdot^{\circ}C)}$）；$m$ 是参与循环的冷却液**质量**（单位 $\mathrm{kg}$）；$\Delta T$ 是冷却液进、出发动机的**温差**（单位 $^{\circ}\mathrm{C}$）。
- **第二步，直觉理解**：热量 = 比热容 × 质量 × 温差。比热容越大、循环量越大、进出温差越大，散热能力越强。水的比热容很大，这正是它适合做冷却介质的原因；乙二醇虽比热略低，但换来了防冻与防腐性能。
- **第三步，工程含义**：发动机散热量基本由工况决定，所以冷却系统要靠**温差**来调节——节温器维持最佳水温、风扇根据温度开停，本质上都是控制 $\Delta T$。冷却液不足时 $m$ 变小，带走的热量随之下降，水温就会攀升——这就是「缺冷却液导致过热」的定量解释。

## 3 冷却系统的日常与定期检查

冷却系统保养分三个层次：

**日常检查（驾驶员）**：冷车状态下观察膨胀水壶的液位，应在「MIN」与「MAX」刻度之间；注意仪表水温是否异常偏高；闻车头有无甜味的冷却液气味、看地面有无有色水渍——这些都提示渗漏。<span class="marginnote">防冻液大多有甜味与鲜艳颜色（绿/红/蓝），这既是添加剂染色便于识漏，也是提醒：发现地面有色水渍就要排查渗漏点。猫咪喜欢舔甜味冷却液，所以开车前看看车底有没有小动物也是养车常识。</span>

**定期检查（维护作业）**：检查散热器与各软管接头有无渗漏、老化鼓包；检查风扇能否正常运转；必要时用**冰点仪/折射仪**测防冻液冰点，判断是否需要更换——防冻液的有效期一般 2 年或 40000 km。

**更换时机**：按手册周期更换，或出现以下情况时更换——冰点不达标、颜色变淡变浑、pH 值异常、长期只加过水。

## 4 防冻液浓度与冰点

防冻液的防冻能力取决于乙二醇浓度，浓度与冰点并非线性关系，而是有一条经典的对照曲线。维修中常查的几档：

| 乙二醇体积浓度 | 约对应冰点 | 适用地区 |
| --- | --- | --- |
| 30% | -14 ℃ | 南方冬季 |
| 50% | -37 ℃ | 长江流域及以北 |
| 60% | -52 ℃ | 严寒地区 |
| 70% 以上 | 冰点回升 | 不推荐 |

<span class="marginnote">注意冰点在浓度约 60–65% 处出现极小值，超过这个浓度冰点反而<strong>回升</strong>——纯乙二醇的冰点只有 -13 ℃。所以「防冻液越浓越好」是错误的，市售防冻液通常要求兑水使用，浓度过高反而降低防冻能力并影响散热。</span>

**如何测浓度？** 用**折射仪（冰点仪）** 滴一滴冷却液在棱镜上，透过目镜读取刻度，即可换算冰点。这是定期维护中「测冰点」的标准操作，比「凭颜色判断」可靠得多。

## 5 冷却异常信号的排查思路

水温异常是冷却系统故障的通用信号，但「亮红灯」背后的原因差别很大，需要按信号分层判断：

| 信号 | 常见原因 | 排查方向 |
| --- | --- | --- |
| 水温持续偏高 | 缺液、节温器卡死、水泵皮带松 | 查液位、节温器开度、皮带张力 |
| 高速正常、低速开锅 | 风扇不转、散热器堵塞 | 查风扇电机/温控开关 |
| 开锅但液位正常 | 节温器卡在关闭位、水套气阻 | 查节温器、排空气 |
| 水温忽高忽低 | 节温器开闭异常、水泵叶轮腐蚀 | 换节温器、查水泵 |
| 车内暖风不热 | 暖风水箱堵塞、节温器常开 | 查暖风水箱、节温器 |

**辨析｜易错点：** 水温报警灯一亮，很多人第一反应是「停车立即熄火」。正确的做法是**靠边停车、保持发动机怠速运转片刻再熄火**——立即熄火会让水泵停转，局部热量积聚反而加剧热害；怠速运转能让冷却液继续循环降温。当然，若出现蒸汽喷出等危险信号，安全撤离为先。<span class="marginnote">水温报警后的处置顺序：安全靠边 → 开暖风辅助散热 → 怠速运转片刻 → 熄火 → 等冷却后检查液位。这套顺序在《发动机常见故障诊断与排除》中还会作为典型案例细讲。</span>

## 6 防冻液更换流程

更换防冻液是二级维护中的常见项目，核心要点如下：

**冷车操作**：发动机完全冷却后再拆散热器盖，避免高温带压喷出烫伤（呼应安全篇「热车不拧散热器盖」）。
**排旧液**：打开散热器底部放液阀，放净旧液；部分车型还需拆下水套放液螺栓。
**清洗（视情况）**：若旧液浑浊或有水垢，用清水或专用清洗剂冲洗冷却系统。
**加新液**：从膨胀水壶或散热器加注口加入新防冻液，加至规定刻度。
**排气**：启动发动机运转至节温器打开，让空气从系统中排出，再补充液位至规定范围——冷却系统内不能有气阻，否则会局部过热。

**辨析｜易错点：** 防冻液常见的三个错误是「混加不同颜色」「只补不换」「加太满」。防冻液有热胀冷缩，膨胀水壶必须留出膨胀空间，加太满反而会在高温时溢出、造成浪费与污染。<span class="marginnote">散热器盖不是一个普通盖子，它是带压力阀的「压力帽」：加压提高沸点，又通过阀在过压时泄放。所以拧盖时听到「嘶」的放气声是正常的，先慢慢松到第一道卡扣放压，再完全取下。</span>

## 7 小结

- **冷却系统构成**：水套、水泵、散热器、节温器、风扇、膨胀壶，节温器控制小循环/大循环切换。
- **防冻液四重功能**：防冻、防沸、防腐防垢、润滑水泵，不能用水替代。
- **散热能力**由 $Q = cm\Delta T$ 决定，冷却液不足使 $m$ 减小、散热能力下降——保持液位与浓度正常，是防过热的第一道防线。
- **节温器与大小循环**：冷车小循环、热车大循环；节温器常开会水温偏低、暖风不热，常闭则水温偏高甚至开锅。
- **更换流程**：冷车操作 → 排旧液 → 视情清洗 → 加新液 → 排气补充；水温报警先靠边、怠速片刻再熄火，切忌立即熄火加剧热害。
