## 为什么从润滑开始

在维护制度这张「日历」里，换机油是出现频率最高的定期作业——它也是新手最容易上手、却又最容易做错的保养项目。说它是发动机的血液并不夸张：发动机内部曲轴、连杆、活塞与气缸壁之间在高速相对运动，如果失去机油膜，金属与金属直接摩擦会在数分钟内烧毁发动机。<span class="marginnote">「抱瓦」「拉缸」这两个维修术语描述的就是润滑失效的灾难性后果：轴瓦熔化、气缸壁划伤，维修成本接近换一台发动机。而这一切的起点，常常只是「该换机油没换」。</span> 这一节讲清机油如何工作、标号怎么看、更换怎么操作，是从维护制度落地到发动机的第一个系统。

## 1 润滑系统的组成：机油的旅程

**润滑系统（lubrication system）**：以机油为介质，在发动机各运动件之间建立油膜以减小摩擦、带走热量的系统。它的组成是一条完整的循环回路：

| 部件 | 作用 |
| --- | --- |
| 油底壳（油盘） | 储存机油，位于发动机最底部 |
| 机油泵 | 把机油加压泵入油道，提供循环动力 |
| 机油滤清器 | 过滤金属屑与杂质，防止磨粒进入轴承 |
| 油道 | 在缸体、缸盖内钻孔形成的输油通路 |
| 机油压力开关 / 传感器 | 监测油压，油压过低时点亮仪表警告灯 |
| 机油尺 | 检查油位高低的量具 |

<span class="marginnote">机油泵由曲轴驱动，转速随发动机转速变化——所以怠速时油压较低、高速时油压较高是正常现象。真正危险的信号是「怠速亮灯、加速灯灭」这种压力波动，它往往提示机油量不足或油道堵塞。</span>

机油的旅程大致是：机油泵从油底壳吸油 → 加压送入机油滤清器 → 过滤后进入主油道 → 分配到曲轴主轴承、连杆轴承、凸轮轴等摩擦副 → 靠飞溅与油雾润滑气缸壁 → 落回油底壳。这个循环在发动机运转时一刻不停，机油既是润滑剂，也是把摩擦热带走的冷却介质。

## 2 机油的五大功能与劣化

**机油（engine oil）** 在发动机里承担五重角色：

**润滑**：在摩擦面之间建立油膜，把金属接触转化为油膜剪切，减小摩擦与磨损。
**冷却**：把活塞、轴承处的热量带走，辅助冷却系统散热。
**清洁**：把积碳、油泥、金属屑悬浮在油中，带到滤清器过滤掉。
**密封**：在活塞环与气缸壁之间填充间隙，减少燃气下窜。
- **防锈防腐**：在金属表面形成保护膜，抵御燃烧产物的腐蚀。

<span class="marginnote">「清洁」功能是机油变黑的原因之一——机油变黑恰恰说明它在正常工作，把积碳洗下来了。单凭颜色判断机油该不该换是不准的，应以里程/时间周期为准。</span>

**机油为什么会劣化？** 高温使基础油氧化、粘度改变；积碳与磨损颗粒不断混入使油变脏；燃料与水分渗入稀释机油、降低油膜强度；酸性燃烧产物使酸值升高、腐蚀金属。这些因素叠加，机油最终失去润滑能力——所以「定期换油」的本质，是**在机油劣化到危险线之前把它换掉**。

## 3 机油标号解读：5W-30 是什么意思

机油瓶身上的标号遵循**美国汽车工程师学会（SAE）** 的粘度分类。以常见的 `5W-30` 为例：

字母 **W** 代表冬季（Winter），前面的数字 `5` 是**低温粘度等级**——数字越小，低温流动性越好，冷启动越顺畅。
后面的数字 `30` 是**高温粘度等级**——数字越大，高温下油膜强度越高，但流动阻力也越大。

<span class="marginnote">一个常见误区是「W 前面的数字是温度」。严格说它是按低温泵送能力划分的等级，不是摄氏温度本身；但粗记忆可以用「0W 约适合 -35 ℃ 以上、5W 约 -30 ℃ 以上」来把握，具体看厂家的倾点数据。</span>

**怎么选标号？** 原则是「优先按车辆使用手册」——厂家在发动机设计时已标定了最适合的粘度。在严寒地区或高里程老车上，可以按手册允许的范围微调：严寒选更小的 W 数字，老车烧机油时可适当提高高温粘度等级。

### 公式解析：机油油膜与粘度

机油能否护住发动机，取决于油膜的**承载能力**，其核心物理量是动力粘度 $\eta$。牛顿流体在平行板间的剪切应力满足：

$$
\tau = \eta \cdot \frac{du}{dy}
$$

- **第一步，认识符号**：$\tau$ 是油膜内的**剪切应力**（单位 $\mathrm{Pa}$）；$\eta$ 是机油的**动力粘度**（单位 $\mathrm{Pa\cdot s}$）；$\frac{du}{dy}$ 是沿油膜厚度方向的速度**梯度**——上下摩擦面速度差除以油膜厚度。
- **第二步，直觉理解**：粘度 $\eta$ 越大，同样速度梯度下油膜抵抗变形的力越大——油膜越「黏」，越不容易被挤压出去。但粘度也不是越大越好：粘度过大，冷启动时机油泵送困难、流动阻力大，反而加剧磨损与油耗。
- **第三步，工程含义**：这正是「粘度要匹配工况」的理论根源。发动机启动瞬间转速低、温度低，需要低粘度机油快速到达摩擦面；高转速高负荷时需要足够粘度维持油膜不破裂。SAE 多级油（如 5W-30）通过添加剂让机油「低温稀、高温稠」，就是为了兼顾这两个矛盾的需求。

## 4 机油的类型与更换周期

按基础油不同，机油分三大类：

| 类型 | 基础油 | 特点 | 典型更换周期 |
| --- | --- | --- | --- |
| 矿物油 | 天然原油提炼 | 价格低，性能一般，氧化较快 | 3000–5000 km |
| 半合成油 | 矿物油 + 合成油 | 性价比均衡，性能优于矿物油 | 5000–7500 km |
| 全合成油 | 化学合成基础油 | 高温稳定性、低温流动性最佳 | 7500–15000 km |

<span class="marginnote">周期数值是经验参考，务必以车辆手册为准。涡轮增压发动机、高温高负荷工况会加速机油劣化，应适当缩短周期。API 标号（如 SN、SP）表示质量等级，字母越靠后等级越高；ACEA 标号是欧洲标准，两者互有对应。</span>

**更换操作要点**（换油是二级维护的常设项目，需在车辆水平、发动机达到工作温度后操作）：

**放油**：拧松油底壳放油螺栓，让旧油自然流出；热车放油流动性好，能带走更多杂质。
**换滤芯**：用机油滤清器扳手拆下旧滤芯，在新滤芯密封圈上涂少量新机油，再按力矩装回。
**加油**：从加注口注入新油，加到规定容量后，启动发动机运转片刻，熄火静置几分钟。
**查油位**：拔出机油尺擦拭后插回再拔出，油位应在上下刻度线之间；不足则补充，严禁超过上限。
- **查泄漏**：检查放油螺栓与滤清器处有无渗漏；旧油装入容器交危废处理。

**换油时的安全提醒**：换油时机油温度很高，接触皮肤可能烫伤，操作时佩戴耐油手套；放油螺栓在油底壳最底部，车辆必须可靠举升并加安全支架，绝不能在仅靠千斤顶支撑的状态下钻入车底。

## 5 核心对比：机油标号速查

把常见场景收拢成速查表，选油时对号入座：

| 场景 | 推荐思路 |
| --- | --- |
| 家用自然吸气车 | 手册标号全合成或半合成，5W-30 / 0W-20 常见 |
| 涡轮增压车 | 倾向全合成，按手册选更高等级（SN/SP） |
| 严寒地区冬季 | 选更小 W 数字，如 0W-20 |
| 高里程老车轻微烧机油 | 手册允许时可提高高温粘度等级一档 |
| 激烈驾驶 / 长期拥堵 | 缩短更换周期，勤检查油位 |

**辨析｜易错点：** 机油保养有三个高频错误。其一，**机油加多**——油位超过上限会导致曲轴搅油、油耗上升、甚至油封渗漏；其二，**冷车看油位**——机油尺读数应以发动机熄火静置数分钟后为准，冷车热车读法不同；其三，**只换油不换滤芯**——旧滤芯里沉积的杂质会立即污染新机油，换油必换滤，这个组合项目就叫「三滤」中的机滤。<span class="marginnote">「三滤」指机油滤清器、空气滤清器、燃油滤清器（汽油滤芯），其中机滤随每次换油更换，空滤与汽滤周期更长，下一节《空气滤清器与燃油系统保养》接着讲。</span>

## 6 小结

- **润滑系统循环**：油底壳 → 机油泵 → 滤清器 → 主油道 → 摩擦副 → 回油，机油同时承担润滑、冷却、清洁、密封、防锈五大功能。
- **机油标号**：`5W-30` 中 W 前数字是低温粘度（小则冷启动好），W 后数字是高温粘度（大则高温油膜强），选型以手册为准。
- **油膜承载**由牛顿剪切公式 $\tau = \eta\frac{du}{dy}$
