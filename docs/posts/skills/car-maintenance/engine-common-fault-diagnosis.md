## 为什么从发动机故障开始

第3篇学完了诊断方法与检测武器，第4篇把它们全部派上用场，而发动机是故障率最高、也最能检验诊断功力的系统。发动机故障的规律性很强：同样的症状背后是有限的几类原因，只要按故障树逐层排查，大多数都能定位。<span class="marginnote">发动机维修是职业技能标准的核心模块，也是等级考核的必考项目。本专题第2篇保养篇已建立了「健康」的标准，这一篇反过来说「生病」——两相对照，才是完整的知识闭环。</span> 这一节把发动机常见故障按「现象 → 可能原因 → 诊断方向」整理成可操作的排查框架。

## 1 发动机故障的分类框架

发动机故障林林总总，先按「故障发生在哪个环节」分类，排查就有章法：

| 分类 | 典型现象 | 核心排查方向 |
| --- | --- | --- |
| 起动类 | 无法启动、启动困难 | 起动系、点火、供油 |
| 运行类 | 怠速不稳、抖动、熄火 | 混合气、点火、漏气 |
| 动力类 | 加速无力、顿挫、异响 | 油压、点火、机械 |
| 消耗类 | 烧机油、油耗高、过热 | 密封、冷却、活塞环 |

<span class="marginnote">分类的意义在于「先定大类、再进小类」：怠速不稳属于运行类，先查混合气与点火；加速无力属于动力类，先测油压与缸压。大类定了，故障树就自然长出来了。</span>

## 2 无法启动与启动困难

**现象一：起动机不转**。先看电瓶——测电压、查桩头（呼应蓄电池篇）；再查起动继电器、起动机本体与搭铁。故障树顶层：供电有没有？搭铁好不好？起动机转不转？

**现象二：起动机转，但发动机不着火**。这是最经典的排查场景，按「气、火、油、电」四路推进：

**气**：进气是否通畅（空滤、节气门）、有没有明显漏气。
**火**：有没有高压火——拔出火花塞试火或看点火波形；无火查曲轴位置传感器、点火线圈。
- **油**：有没有油压——测油轨压力；无压查燃油泵、继电器、滤芯。
- **电控**：读故障码，曲轴/凸轮轴位置信号异常会直接禁止喷油点火。

<span class="marginnote">「不着火先看曲轴位置信号」是电喷车的第一排查项：CKP 无信号时 ECU 无法判断正时，会切断喷油与点火。所以启动困难时，先读故障码确认有没有转速信号，比盲目查火查油更高效。</span>

**启动困难的细分**：冷车困难（查电瓶 CCA、火花塞、节气门）、热车困难（查喷油器滴漏、碳罐电磁阀）、偶尔困难（查插接器、搭铁）。

## 3 怠速不稳与动力不足

**怠速不稳**是运行类的代表，先看数据流（呼应电控篇）：氧传感器是否摆动、节气门开度、喷油脉宽、短期燃油修正。常见原因排序：进气漏气 → 节气门/怠速阀积碳 → 火花塞老化 → 喷油器堵塞 → 真空管路脱落。

**加速无力 / 顿挫**是动力类的代表，排查顺序：

- 先读故障码，看有没有失火码（P030x）或混合气码（P017x）。
- 测油压——油压低查燃油泵与滤芯（诊断篇的「加速无力」案例就是这条线）。
- 查点火——火花塞、点火线圈在负荷下失火（热态性能下降）。
- 查进气——空滤堵塞、三元催化器堵塞（排气背压高）。
- 查机械——缸压是否均匀（活塞环、气门密封）。

### 公式解析：功率与扭矩

「动力不足」的本质是发动机输出功率下降。功率、扭矩与转速的关系是：

$$
P = T \times \omega = T \times \frac{2\pi n}{60}
$$

- **第一步，认识符号**：$P$ 是发动机**有效功率**（单位 $\mathrm{W}$）；$T$ 是**扭矩**（单位 $\mathrm{N\cdot m}$）；$\omega$ 是曲轴**角速度**（单位 $\mathrm{rad/s}$）；$n$ 是**转速**（单位 $\mathrm{r/min}$）。
- **第二步，直觉理解**：功率 = 扭矩 × 转速。同一转速下扭矩下降，功率就下降——这就是「没劲」的定量来源。
- **第三步，维修含义**：加速无力的诊断可以拆成两问——「扭矩够不够」（油压、燃烧、机械）与「转速上不上去」（变速器打滑、排气堵塞）。功率上不去的根因，要么是「每转输出的力变小」（扭矩），要么是「转不快」（转速）。顺着这两问排查，思路就清晰了。

## 4 烧机油与机油消耗异常

**烧机油**指机油进入燃烧室被烧掉，表现为排气管冒蓝烟、机油消耗快、火花塞积碳发黑。三类典型成因：

| 成因 | 机理 | 诊断线索 |
| --- | --- | --- |
| 活塞环磨损/卡滞 | 机油经活塞环上窜 | 急加速冒蓝烟，缸压偏低 |
| 气门油封老化 | 机油沿气门杆下漏 | 松油门滑行/长时间怠速冒蓝烟 |
| PCV 系统堵塞 | 曲轴箱压力高，机油窜出 | 曲轴箱压力异常，机油口冒烟 |

<span class="marginnote">一个实用的区分技巧：<strong>急加速时冒蓝烟</strong>多提示活塞环问题（高转速时上窜量增大），<strong>松油门或怠速时冒蓝烟</strong>多提示气门油封问题（进气真空把机油吸入气缸）。用「什么工况冒烟」来分方向，比拆开看更省事。</span>

**机油消耗标准**：发动机存在正常的机油消耗，一般每 1000 km 消耗不超过约 0.3 L 属正常范围（因车型而异）。明显超标才叫「烧机油」，别把正常消耗误判为故障，也别把真烧机油拖成大修。

## 5 发动机异响与过热

**异响速查**（发动机舱）：

| 异响 | 特征 | 常见原因 |
| --- | --- | --- |
| 气门「哒哒」声 | 怠速清晰、随转速加快 | 气门间隙大、液压挺柱失效 |
| 正时链条「哗啦」声 | 冷车明显 | 正时链条/张紧器磨损 |
| 爆震「金属敲击」声 | 加速时出现 | 用错汽油标号、点火提前角过大 |
| 皮带「吱吱」声 | 冷启动、潮湿天 | 附件皮带松弛打滑 |
| 敲缸「沉闷」声 | 负荷时明显 | 活塞-缸壁间隙大（严重） |

<span class="marginnote">异响的「听诊」要配合转速与负荷：加速响多为负荷相关（爆震、敲缸），怠速响多为配气相关（气门、链条）。用「什么工况响」配合听诊器或加长螺丝刀抵住部件听声，能快速定位发声部位。</span>

**发动机过热**（呼应冷却篇）：水温高 → 查液位、节温器、风扇、水泵、散热器；特别警惕「假性高温」——水温表高但数据流正常，可能是仪表或传感器线路问题。过热后必须排查二次损伤：缸垫是否烧穿（冷却液进机油、机油乳化、水箱翻油花）。

**尾气颜色是发动机的「三色信号灯」**：

| 排烟颜色 | 含义 | 排查方向 |
| --- | --- | --- |
| 蓝烟 | 机油进入燃烧室 | 活塞环 / 气门油封 / PCV |
| 白烟（持续） | 冷却液进入燃烧室 | 缸垫烧穿 / 缸体裂纹 |
| 黑烟 | 混合气过浓 | 空滤堵 / 油压高 / 喷油器故障 |
| 白烟（冷天少量） | 水蒸气，正常 | 无需处理 |

<span class="marginnote">冬天冷启动排出少量白烟是水蒸气冷凝，属正常；但持续大量白烟且防冻液减少，就要高度怀疑缸垫烧穿。尾气颜色 + 液位变化 + 机油乳化三个线索互相印证，缸垫问题基本可以坐实。</span>

## 6 小结

- **故障分类四类**：起动、运行、动力、消耗，先定大类再进小类。
- **无法启动**：起动机转不转 → 气、火、油、电控四路排查；电喷车先看曲轴位置信号。
- **怠速不稳**：先看数据流（氧传感器、节气门、燃油修正），从漏气与积碳排起。
- **功率公式** $P = T\cdot\frac{2\pi n}{60}$
