## 为什么从工具开始

安全规程讲完，接下来认识「手」。修车是用工具与测量说话的职业：一颗螺栓该用多大套筒、拧多大力矩，一个间隙该是多少毫米，都由工具来保证。可以说，**工具是技师手的延长，测量仪器是技师眼睛的延长**。<span class="marginnote">阿基米德的「支点」名言放在这里非常贴切：扭矩扳手、套筒加力杆、举升机，本质都是杠杆原理在汽车维修中的应用——用更小的力控制更大的力。</span> 这一节不求把每个工具的每个型号讲尽，而是建立一张「工具地图」：什么活用什么东西、怎么选型、怎么保养，为后面每一篇保养与检修文章提供公共工具箱。

## 1 手动工具：扳手家族

**手动工具**：靠人力操作、用于拧紧或松开紧固件的工具，是维修作业的基座。按结构与用途，扳手可分成几大家族：

| 扳手类型 | 特征 | 适用场景 |
| --- | --- | --- |
| 开口扳手 | 端部 U 形开口 | 普通六角螺栓，快速拧紧 |
| 梅花扳手 | 端部封闭环状，12 角 | 高扭矩、不易滑脱 |
| 两用扳手 | 一端开口、一端梅花 | 通用首选 |
| 活动扳手 | 开口可调 | 非标尺寸，应急使用 |
| 内六角扳手 | L 形，六角断面 | 内六角螺栓（如盘头） |
| 套筒扳手 | 筒状 + 棘轮手柄 | 狭窄空间、批量拆装 |

<span class="marginnote">活动扳手虽然方便，却是技师眼里的「危险品」：它容易打滑、磨圆螺栓头，正规作业优先用固定尺寸扳手。判断一把好扳手，看它的材质（铬钒钢）与开口是否与螺栓头精密贴合。</span>

**拧螺栓的方向记忆**：顺时针拧紧、逆时针松开，是右旋螺纹的通用规则。但要注意部分特殊部位（如某些风扇、车轮左侧螺栓）使用左旋螺纹，作业前先看螺纹方向，避免越拧越紧。

## 2 套筒与力矩工具：力的控制

**套筒（socket）**：与螺栓头配合的筒状套件，按**六角 / 十二角**、**公制 / 英制**、**浅套筒 / 深套筒**分类。深套筒用于螺栓杆较长的场合，十二角套筒便于快速对位但传递扭矩略弱。

**力矩工具（torque tool）**：包括**扭力扳手**与**预置式扭力扳手**。扭力扳手能显示拧紧力矩，用于对扭矩有严格要求的部位——缸盖螺栓、轮毂螺栓、油底壳螺栓等。按结构分，常见三种：

**机械刻度式（表盘式）**：指针读数，直观但精度一般，适合通用场合。
**预置式（click type）**：预设扭矩值，到达时发出「咔哒」声与手感振动，防超扭，最常用。
**数显式**：电子读数，精度最高、带蜂鸣提示，用于对扭矩有严格公差的关键部位。

使用后必须把刻度退回零位存放，否则内部弹簧会疲劳失效，下次拧出的力矩就不再可信。<span class="marginnote">轮毂螺栓（俗称轮胎螺丝）的紧固扭矩通常在 100–140 N·m 左右，具体看车型手册；用加力杆「死命拧」反而可能把螺栓拧断或使轮毂变形。</span>

### 公式解析：拧紧力矩 T = F × L

**力矩（moment of force）** 是力与力臂的乘积，它决定了螺栓被拧得多紧：

$$
T = F \times L
$$

对这条式子做三步拆解：

- **第一步，认识符号**：$T$ 是**力矩（torque）**，单位牛顿·米（$\mathrm{N\cdot m}$）；$F$ 是施加在扳手上的**力**，单位牛顿（$\mathrm{N}$）；$L$ 是**力臂**——从旋转中心到施力点的垂直距离，单位米（$\mathrm{m}$）。
- **第二步，直觉理解**：同样一把扳手，手越靠近旋转中心（$L$ 小）就越费力；把套筒加长杆接上，$L$ 变大，同样的手劲就能产生更大的拧紧力矩。这正是「给我一个支点」的杠杆原理。
- **第三步，工程含义**：力矩决定了螺栓的**预紧力**——过小，螺栓在振动中松动；过大，螺栓拉伸甚至断裂、螺纹滑牙。所以维修工艺卡才会规定「缸盖螺栓分两次、按 40 N·m + 90° 顺序拧紧」，扭矩值不是随便写的，而是按螺栓材质与受力计算的。

## 3 检测仪器：技师的眼睛

修车不仅要「换」，更要「量」。**检测仪器**把看不见的状态变成读数：

- **游标卡尺（caliper）**：测量外径、内径、深度，精度 0.02 mm；用于测制动盘厚度、活塞直径。
- **千分尺（micrometer）**：测量更精密的厚度，精度 0.01 mm；用于测曲轴轴颈磨损。
- **塞尺（feeler gauge）**：一组已知厚度的薄片，测量间隙，如气门间隙、火花塞间隙。
- **万用表（multimeter）**：测量电压、电流、电阻；电控系统检测的入门仪器，测传感器供电、搭铁、信号电压。
- **缸压表（compression gauge）**：旋入火花塞孔测气缸压缩压力，判断活塞环、气门密封是否良好。
- **蓄电池检测仪**：测冷启动电流（CCA）与电池健康状态。
- **汽车故障诊断仪（解码器）**：连接 OBD 接口读取故障码与数据流，是现代维修的「主力仪器」，将在本专题第3篇《车载诊断系统（OBD）读取与解读》中展开。

<span class="marginnote">万用表是电气诊断的起点，但很多人只会「测通断」。更常用的是电压测量：传感器信号线对搭铁的电压、供电线对搭铁的电压，配合数据流对比，才能定位「是传感器坏了，还是线路坏了」。</span>

**量具保养铁律**：量具是精密仪器，严禁敲击、摔落；使用后擦净并涂防锈油；不测量旋转中的工件；游标卡尺不测粗糙表面。

## 4 举升与支撑设备

前面安全篇讲过举升安全，这里从「工具」角度补充它的选型：

| 设备 | 额定载荷典型值 | 用途 |
| --- | --- | --- |
| 剪式举升机 | 3–4 t | 整车举升，底盘作业 |
| 双柱举升机 | 3–5 t | 整车举升，通用 |
| 四柱举升机 | 3–5 t | 整车举升，定位稳定 |
| 卧式千斤顶 | 1.5–3 t | 局部举升（换胎） |
| 安全支架 | 2–6 t | 车下作业支撑 |
| 变速箱托架 | 0.5–1 t | 拆装变速器支撑 |

<span class="marginnote">所有举升设备的铭牌上都有额定载荷，超载使用是绝对红线。选型原则是「设备额定载荷 ≥ 1.5 倍实际载荷」，留足安全余量。</span>

**设备日常检查**：每月检查举升机液压油位、钢丝绳/链条磨损、保险棘爪动作；千斤顶检查活塞是否渗漏、密封圈是否老化。带病设备比没有设备更危险。

## 5 工具选型速查

把零散知识收拢成一张速查表，实操时「对号入座」：

普通螺栓拆装 → 梅花扳手 / 套筒 + 棘轮；空间狭窄 → 套筒 + 加力杆。
螺栓锈死拧不动 → 松动剂渗透 + 小角度反复松紧，或加力杆增大力臂，杜绝硬拧。
扭矩敏感部位 → 扭力扳手，按手册规定值分次拧紧。
测间隙 → 塞尺；测厚度 → 卡尺 / 千分尺；测压力 → 压力表。
电气检测 → 万用表 + 电路图；电控诊断 → 故障诊断仪 + 数据流。
- 整车举升 → 举升机 + 安全支架；换轮胎 → 千斤顶 + 备胎垫护。

**辨析｜易错点：** 「大力出奇迹」是修车新人最常见的误区。螺栓拧不动时，正确做法是使用加力杆增大力臂、用 WD-40 类松动剂渗透、或加热螺栓头（对非塑料件），而不是一味加力——硬拧的结果往往是断螺栓、滑牙，把小修变大修。<span class="marginnote">断螺栓取出是维修工的基本功，但最好的「取出」是别让它断。遇到锈死螺栓，先喷松动剂、等 10 分钟，再小角度反复松紧，比一次猛用力有效得多。</span>

## 6 小结

- **扳手家族**：开口、梅花、两用、活动、内六角、套筒各有适用场景；活动扳手仅作应急。
- **力矩控制**：扭矩 $T = F \times L$
