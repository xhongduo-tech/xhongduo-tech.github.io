## 为什么从底盘传动开始

发动机的故障「会亮灯、会冒烟」，而底盘与传动系统的故障「不说话、只发声」——抖动、异响、顿挫、跑偏，全靠技师去听、去感受、去排查。<span class="marginnote">底盘是「隐藏系统」：发动机故障有故障码可读，底盘故障大多要靠机械检查与路试判断。这也是为什么底盘维修特别考验诊断思路的「问诊 + 验证」能力。</span> 这一节把传动、行驶、转向三个系统的常见故障整理成排查框架，承接保养篇的底盘知识，进入故障检修层面。

## 1 传动系统的常见故障

**传动系统（drivetrain）** 负责把发动机动力送到驱动轮，常见故障集中在离合器、变速器、传动轴/半轴三处。

**离合器故障（手动挡）**：

**打滑**：加速时发动机转速上升但车速不涨、有烧焦味——摩擦片磨损到极限或压盘压力不足。
**分离不彻底**：挂挡困难、踩离合有「沙沙」声——分离轴承磨损、离合器踏板自由行程过大。
**发抖**：起步时车身抖动——摩擦片表面油污、压盘翘曲、飞轮不平。

<span class="marginnote">区分「离合器打滑」与「变速器故障」的简易方法：拉紧驻车制动挂高挡，缓抬离合试起步——发动机被憋熄火说明离合器正常，发动机转速上升车不动则打滑。这个「憋车测试」是离合器诊断的经典操作。</span>

**变速器故障**：手动挡挂挡不入（同步器磨损、离合分离不彻底）、自动挡换挡顿挫/冲击（油液老化、阀体故障、传感器信号）、变速器异响（轴承磨损、齿轮打齿）。自动变速器维修要先读故障码与油温数据流，再判断机械故障。

**自动变速器诊断的层次**：先读故障码与油温，再查油质油位（油液发黑有焦味提示内部磨损），然后用主动测试/换挡测试判断是电控问题还是机械问题，最后才考虑解体——**能不动变速箱就不动**，是自动变速器维修的第一原则。CVT 无级变速器还多一个特殊故障模式：钢带打滑（加速时转速突升、车速不升），多与油液劣化或钢带磨损有关，属严重故障需总成处理。

**传动轴/半轴故障**：半轴万向节磨损在转弯时发出「咔咔」声（防尘套破裂导致缺油进水），传动轴动平衡失效在高速时整车抖动，差速器异响多为齿轮间隙过大或油量不足。

## 2 公式解析：变速器传动比

变速器为什么能「变扭」？核心是齿轮传动比。一对啮合齿轮的传动比为：

$$
i = \frac{n_1}{n_2} = \frac{T_2}{T_1} = \frac{z_2}{z_1}
$$

- **第一步，认识符号**：$n_1$、$n_2$ 是主动轮与从动轮的**转速**；$T_1$、$T_2$ 是相应的**扭矩**；$z_1$、$z_2$ 是两轮的**齿数**。
- **第二步，直觉理解**：传动比 $i > 1$ 时（如 $i = 3$），主动轮转 3 圈从动轮转 1 圈——转速降低、扭矩放大 3 倍。一挡的大传动比用于「起步放大扭矩」，超速挡的小传动比用于「高速省油」。
- **第三步，维修含义**：理解传动比，就能看懂「为什么低挡有力、高挡省油」，也能理解变速器故障的后果——打滑（液力变矩器/离合）会让扭矩传递不上来，等于实际传动比「失效」。测传动比是否正常，是自动变速器诊断的重要环节。

## 3 行驶系统的常见故障

**行驶系统**的故障集中在悬架与车轮：

**减振器失效**：车身过减速带后余振多、高速发飘、制动时「点头」明显——检查筒体漏油，按压车身测试回弹（呼应悬架保养篇）。

**车轮轴承磨损**：行驶中「嗡嗡」声随车速变化、转弯时更明显——轴承磨损导致。判断方法：举起车辆转动车轮，听有无「沙沙」异响、晃感；或路试时左右转向听声音变化，确认是哪一侧轴承。

**轮胎偏磨与抖动**：单侧偏磨查四轮定位，锯齿状磨损查前束，高速方向盘抖动查车轮动平衡。偏磨、定位、球头松旷常常互相纠缠，要按「先机械、后定位」顺序排查（呼应转向悬架保养篇的辨析）。

**悬架异响**：过坎「咯噔」声查稳定杆吊杆、减振器顶胶；低速转向「咯噔」查半轴万向节与球头——异响排查用「什么工况响」定位，具体判断表在保养篇已有，此处不再赘述。

## 4 转向系统的常见故障

**转向跑偏**：行驶中车辆自动偏向一侧。先区分是「制动跑偏」（制动时偏，查制动系统）还是「行驶跑偏」（始终偏，查四轮定位、轮胎气压、悬挂部件）。**左右胎压不一致是跑偏最常见的低成本原因**，先测胎压再谈定位。

**方向盘抖动**：高速抖动查轮胎动平衡与轮辋变形；制动时抖动查制动盘变形；低速打方向抖动查转向助力或转向机。

**转向助力异常**：EPS 方向盘突然变重 → 读故障码、查助力电机与扭矩传感器；液压助力变重 → 查助力油液位、皮带、助力泵压力。**方向盘重不等于转向机坏**——先查助力源，再查机械件。<span class="marginnote">转向故障最危险的是「间隙过大」：方向盘虚位明显，可能是指向转向拉杆球头、转向机内部磨损，甚至是转向柱万向节松动——任何转向间隙都要按安全件处理，绝不能「再开开看」。</span>

## 5 差速器与四驱系统

**差速器（differential）** 让左右驱动轮在转弯时能以不同转速转动——内侧轮走短弧、外侧轮走长弧，若强行等速，轮胎会拖滑。理解差速器，就能看懂两类典型故障：

**差速器异响**：行驶时「嗡嗡」或转弯时「呜呜」声，多为齿轮间隙过大、油量不足或轴承磨损——差速器油（齿轮油）按周期更换是预防关键。

**差速器故障的特殊性**：普通差速器在单侧车轮打滑时会「把动力全给打滑轮」，导致陷车。限滑差速器（LSD）与电子差速锁通过限制打滑轮的转速来分配动力——这类系统的维修对油液与标定有特殊要求，需按厂家规范操作。

**四驱系统（AWD/4WD）** 故障的典型表现是**四驱指示灯异常、转弯时车轮「发响」或「别劲」**——常见原因为前后轮胎规格/磨损不一致（前后轴转速差超出耦合器容忍范围）、分动箱油液不足、耦合器（多片离合器）故障。<span class="marginnote">四驱车换胎有一条硬规则：<strong>四个轮胎尽量同规格、同磨损程度</strong>。因为四驱系统靠前后轴转速差判断是否打滑，若前后轮直径差异过大，系统会误判「打滑」而频繁介入，造成耦合器过热甚至损坏。</span>

**传动系统的周期维护**：手动挡变速器油、自动变速器油、差速器齿轮油、四驱分动箱油各有更换周期（多随二级维护或厂家手册），这些油液老化后润滑与散热能力下降，是许多「慢性异响」的根源。

## 6 底盘传动故障速查表

把底盘传动常见故障浓缩成速查表，路试与举升检查时对号入座：

| 故障现象 | 排查重点 | 常见根因 |
| --- | --- | --- |
| 高速方向盘抖动 | 轮胎动平衡 | 平衡块脱落、轮辋变形 |
| 制动时抖动 | 制动盘 | 制动盘端面跳动变形 |
| 转弯「咔咔」声 | 半轴万向节 | 防尘套破裂、万向节磨损 |
| 起步「咯噔」 | 球头 / 支架 | 球头松旷、下摆臂衬套 |
| 车身余振多 | 减振器 | 减振器漏油失效 |
| 「嗡嗡」随车速 | 车轮轴承 | 轴承磨损 |
| 挂挡困难 | 离合器 / 同步器 | 分离不彻底、同步器磨损 |
| 行驶跑偏 | 胎压、定位、悬架 | 胎压差、前束外倾不当 |

**辨析｜易错点：** 底盘传动维修最忌讳「头痛医头」。方向盘抖动既可能来自轮胎动平衡，也可能来自轮毂变形、传动轴不平衡、甚至悬架球头松旷——**先做「症状复现 + 逐项排除」，别一上来就拆传动轴**。动平衡机 10 分钟能判断的事，拆半轴可能要半天。<span class="marginnote">路试是底盘诊断不可或缺的环节：抖动发生的车速、转向时的声音变化、制动时的方向偏移，都是定位的关键信息。规范的底盘检修流程是「路试记录症状 → 举升静态检查 → 逐项验证排除 → 维修 → 复路试确认」。</span>

## 7 小结

- **传动故障三分**：离合器（打滑/分离不彻底/发抖）、变速器（挂挡难/顿挫/异响）、半轴（转弯咔咔声）。
- **传动比公式** $i = \frac{n_1}{n_2} = \frac{T_2}{T_1} = \frac{z_2}{z_1}$
