# 汽车维护保养与检修

以人民交通出版社《汽车维护与保养》为纲，结合《汽车维修工国家职业技能标准（2018年版）》与 GB/T 18344《汽车维护、检测、诊断技术规范》，系统覆盖从维修安全、定期保养到检测诊断、故障排除与竣工检验的完整汽车维修技能体系。汽车维修是千万级就业职业，学完这些章节，就写完了从日常保养到故障检修所需的全部内容。

## 对标教材

- 《汽车维修工国家职业技能标准（2018年版）》
- GB/T 18344《汽车维护、检测、诊断技术规范》
- 人民交通出版社《汽车维护与保养》
