## 为什么从电气故障开始

随着车辆电控化程度提高，电气故障在维修中的占比越来越大——现代车的故障里，相当一部分是「电的问题」而不是「机械的问题」。而电是看不见摸不着的，排查电气故障靠的不是力气，而是**电路逻辑 + 测量工具**。<span class="marginnote">电气维修是职业技能标准中难度较高的模块：它要求技师会读电路图、会用万用表、会分析电压降。好消息是，电气故障的规律性很强——翻来覆去就是短路、断路、搭铁、高电阻这几种基本类型。</span> 这一节从电气故障的基本类型讲起，建立「先测量、后判断」的电气诊断能力。

## 1 电气故障的四种基本类型

几乎所有电气故障都可归结为四种基本类型：

| 类型 | 本质 | 典型表现 |
| --- | --- | --- |
| 断路 | 回路断开，电流为 0 | 电器完全不工作 |
| 短路 | 不该连接的导体相接 | 保险丝熔断、冒烟、电器常转 |
| 搭铁不良 | 回路接地电阻大 | 灯光变暗、电器工作异常 |
| 高电阻 | 接触电阻过大 | 电器时好时坏、发热 |

<span class="marginnote">四类故障里「高电阻」最阴险：它不彻底断路，电器还能工作但功率不足、发热——比如大灯发暗、起动机转得慢。高电阻常见于插接器氧化、端子松动、搭铁点锈蚀，是「间歇性故障」的头号元凶。</span>

**短路之所以危险**：电流不走设计的负载，直接经低电阻路径回流，电流瞬间剧增、发热，烧毁保险丝甚至线束起火。所以保险丝熔断不是「换个保险丝」了事，而是**必须先查明短路点**。

## 2 排查工具与电路图

电气维修的工具箱与机械维修不同：

**数字万用表**：测电压、电阻、通断、电流——电气排查的主力。
**试灯（测试灯）**：快速判断供电有无，比万用表更直观。
- **电路图**：车辆电气系统的「地图」，标注每个电器的供电、搭铁、信号走向——**不会读电路图，就谈不上电气诊断**。
- **示波器**：看信号波形，诊断传感器与总线。

**读电路图的三个要点**：认图例符号、找供电与搭铁、追踪信号路径。排查一个电器不工作时，标准动作是「沿电路图从保险丝到负载逐点测电压」——**用测电压代替换件**，一步定位断点。

<span class="marginnote">排查的黄金顺序（呼应蓄电池篇）：先确认保险丝（有没有供电）、再查搭铁（回路通不通）、然后测负载两端电压差（接触电阻大不大）、最后才判断负载本体。90% 的「电器坏了」其实是前三个环节的问题。</span>

## 3 公式解析：欧姆定律与电压降

电气诊断的一切测量，根基是欧姆定律：

$$
V = I \times R
$$

- **第一步，认识符号**：$V$ 是**电压**（单位 $\mathrm{V}$）；$I$ 是**电流**（单位 $\mathrm{A}$）；$R$ 是**电阻**（单位 $\mathrm{\Omega}$）。
- **第二步，直觉理解**：电压 = 电流 × 电阻。回路中任何一处的电阻异常，都会在该处产生电压降，表现为「该处之前电压正常、该处之后电压不足」。
- **第三步，维修含义**：**电压降测量**是电气诊断的核心手段——正常回路中，导线与接头处的电压降应极小（通常低于 0.1–0.5 V）。若某段导线/接头两端电压降明显偏大，说明该处存在高电阻（氧化、松动），即使万用表「通断测试」显示导通，实际承载大电流时也会掉压。**用电压降测高电阻，比用通断挡测更真实**——这是电气技师的进阶技能。

## 4 起动系统与充电系统故障

**起动系统故障**的表现是「打不着火」：

- **起动机不转**：先测电瓶电压（> 12 V 才够），再测起动机电源端有无 12 V、搭铁是否良好；都正常则查起动继电器与起动机本体。
- **起动机转得慢**：多为电瓶亏电、桩头氧化（高电阻）、起动机本身磨损——用电压降测桩头与搭铁线，定位高电阻点。
- **起动机空转 / 异响**：起动机电磁开关故障、飞轮齿圈磨损——机械问题。

**充电系统故障**的表现是「充电灯亮、电瓶反复亏电」：

- 怠速测电瓶电压：13.5–14.5 V 正常，只有 12 V 则发电机不充电。
- 查发电机皮带（打滑？）、发电机输出线、励磁电路、电压调节器。
- 用示波器看发电机波形可判断整流二极管是否损坏（波形出现异常脉动）。<span class="marginnote">「电瓶新换还是亏电」的经典场景：问题常在充电系统而不在电瓶。判断口诀——<strong>能起动、充电灯不亮、电瓶还是亏</strong>，重点转向发电机与线路；<strong>起动无力</strong>，重点转向电瓶与桩头。</span>

## 5 灯光、仪表与舒适系统故障

**灯光故障**：单个灯不亮查灯泡与对应保险丝；多个灯异常查搭铁与继电器。制动灯不亮是重大安全隐患（后车看不到刹车），修好后必须两人配合验证。

**仪表故障**：仪表不亮查仪表保险丝与供电；个别指示异常查对应传感器与线路；仪表「乱码」多个指示灯齐亮，多为**通信问题或搭铁不良**，不是仪表本身坏了。

**舒适系统故障**：电动车窗、中控锁、电动座椅等——先查保险丝与继电器，再查门内线束（开关门弯折处易断线），最后查电机/执行器。<span class="marginnote">门内线束是「高发断线点」：车门开合百万次，线束在铰链附近反复弯折，容易内部断裂。车窗时好时坏，先晃一晃门内线束看现象是否变化——这是排查这类故障的经典手法。</span>

## 6 车载网络与疑难电气故障

当单点排查都正常却故障依旧，就要考虑**车载网络（CAN 总线）** 层面（呼应蓄电池篇的车载网络）：

**多系统同时异常**：仪表乱码、多个模块通信中断、车窗与灯光同时失灵——高度提示总线问题。
**排查方法**：读通信类故障码（U 字头），用示波器测总线波形（正常应为规整差分波形），检查总线终端电阻（CAN 总线两端各约 120 Ω，并联后约 60 Ω）。
- **常见原因**：线束磨损短路、插接器进水、模块内部损坏拉低总线。

**辨析｜易错点：** 电气维修的两大常见错误——其一，**不测就换件**，把「换件」当诊断；其二，**只测通断不测电压降**，把高电阻当正常。正确的方法是：先读电路图确定测试点，用万用表测「该有电的地方有没有电、该搭铁的地方搭铁好不好」，用电压降定位高电阻，最后才考虑换件。<span class="marginnote">疑难电气故障有个「笨但有效」的底线方法：对照电路图逐段测量 + 记录，绝不凭感觉跳段。很多「电老虎」最后都是被耐心和逻辑降服的，而不是被运气。</span>

## 7 常见电气故障速查

把高频电气故障收拢成速查表，实测时对号入座：

| 故障现象 | 排查顺序 |
| --- | --- |
| 大灯不亮 | 灯泡 → 保险丝 → 继电器 → 开关 → 搭铁 |
| 大灯发暗 | 发电机电压 → 搭铁点 → 插接器氧化（电压降） |
| 起动机不转 | 电瓶电压 → 桩头 → 起动继电器 → 起动机 |
| 起动机转得慢 | 电瓶 CCA → 桩头高电阻 → 搭铁线 → 起动机磨损 |
| 车窗时好时坏 | 门内线束 → 升降开关 → 电机 |
| 仪表乱码 | 搭铁 → 通信线 → 仪表模块 |
| 反复烧同一保险丝 | 该回路短路（重点查线束磨破处） |
| 电器间歇失灵 | 插接器松动 → 线束磨损 → 搭铁锈蚀 |

<span class="marginnote">这张表的共同规律是「从供电到负载、从便宜到贵、从简单到复杂」——先确认最基础的电压与搭铁，再往深处走。把这张表吃透，电气维修的基本盘就稳了。</span>

## 8 小结

- **四类基本故障**：断路、短路、搭铁不良、高电阻；高电阻最阴险，是间歇性故障的头号元凶。
- **排查工具**：万用表、试灯、电路图、示波器；**读图 → 测电压 → 定位断点**，用测代替猜。
- **欧姆定律** $V = I \times R$
