## 为什么先准备急救箱

前面两节讲了原则与流程，但原则最终要靠**工具**落地。没有纱布，大出血时你只能用衣物替代；没有创可贴，小伤口只能裸露。急救的「黄金时间」往往短于找到工具的时间——**提前把工具备好、放在固定位置、让全家人知道在哪里**，是成本最低、收益最确定的急救准备。<span class="marginnote">急救箱不是「买了就完事」，而是一个<strong>动态维护的系统</strong>：药品会过期、敷料会耗尽、季节会换需求（夏天要防中暑用品、冬天要加保温用品）。半年清理一次，是急救箱的基本纪律。</span>

这一节我们回答三个问题：家庭急救箱里到底该装什么、药品与耗材怎么分类管理、以及除了急救箱之外，家庭还需要准备哪些应急物资。目标是把「急救箱」从一件买回来的商品，变成一套全家参与、随时可用的家庭系统。

## 1 急救箱的分区：先想「什么伤用什么东西」

合格的急救箱不是杂货铺，而是**按处理流程分区**的。红会《救护员》建议家庭急救箱按功能分四个区：

**清洁消毒区**：碘伏棉签、75% 医用酒精棉片、生理盐水（冲洗用）、无菌纱布块、医用胶带、一次性手套。<span class="marginnote">这里的顺序是「清洁在前、覆盖在后」：碘伏/酒精负责消毒，纱布负责覆盖，胶带负责固定。三个动作对应三种耗材，分区能让你在慌乱中不拿错。</span>

**止血包扎区**：不同规格的纱布、绷带（卷轴绷带与三角巾）、创可贴、止血带（作为大出血的最后手段）。止血带使用有严格前提（详见出血止血一节），所以它单独放置、单独说明。

**工具辅助区**：圆头剪刀（剪绷带、剪衣物）、镊子（取小异物）、体温计、手电筒、口哨（求救用）。<span class="marginnote">圆头剪刀是急救专用设计——普通剪刀容易刺破皮肤或剪伤伤病员。同理，镊子要选防滑尖头的，处理木刺、小玻璃片更可靠。</span>

**常备药品区**：退热药（对乙酰氨基酚、布洛芬）、止泻药、抗过敏药（氯雷他定等）、外用药（烫伤膏、碘伏软膏）、口服补液盐。处方药不进急救箱，单独存放（用药安全一节详述）。

## 2 药品与耗材的分类管理原则

分好区只是第一步，急救箱的长期价值靠**管理**维持。四条原则：

**标签清晰。** 每个瓶子保留原包装与说明书；过期日期用记号笔写在醒目的位置。药品绝不能「倒进小瓶不贴标签」——这是家庭用药事故的头号隐患。<span class="marginnote">原包装还保留着剂量说明、禁忌症与批号。<strong>没有标签的药品，等于没有身份的危险品</strong>——误服后连是什么药都说不清，医生无从处置。</span>

**位置固定、全家知晓。** 急救箱放在**成人够得着、儿童够不着**的地方，比如高处的储物柜；箱内附一张「家庭急救箱物品清单」，列出所有物品与位置。全家人（包括老人、青少年）都要知道急救箱在哪、怎么打开。

**定期检查、更新补充。** 至少每半年（或换季时）检查一次：清点过期药品、补充用尽的敷料、更换损坏的工具。夏季加入防暑与驱蚊用品，冬季加入保温毯与暖宝宝，有婴幼儿的家庭备好儿童专用退热药。

**只放你用得上的。** 急救箱不是「药品收藏馆」。囤积大量自己不会用、没有针对性的药品，只会增加误拿误用的风险。<span class="marginnote">红会教材反复强调「<strong>质量大于数量</strong>」：十种你认识且会用、且针对家庭实际情况的药品，远好过四十种不认识不用的药。开箱一看全是陌生药，等于没准备。</span>

## 3 家庭应急物资：急救箱之外的另一张清单

急救箱解决「伤病」问题，家庭应急物资解决「生存」问题。两者互补，共同构成家庭应急准备。

红会与应急管理部门推荐的「家庭应急包」一般包括：

| 类别 | 物品 | 用途 |
| --- | --- | --- |
| 生存保障 | 瓶装水、压缩饼干、应急食品 | 断电停水时维持体力 |
| 照明通讯 | 手电筒、备用电池、充电宝、口哨 | 停电与被困时求救 |
| 保暖防护 | 保温毯、一次性雨衣、手套 | 寒冷与恶劣天气 |
| 医疗急救 | 便携急救包、常用药、口罩 | 应急医疗处置 |
| 证件备份 | 身份证、户口本复印件、现金 | 疏散与身份识别 |
| 联络信息 | 家庭联络卡、急救电话表 | 失散后联络 |

应急物资与急救箱一样要**定期更换**——瓶装水、应急食品、药品都有保质期。建议每半年检查一次，与急救箱同步。

## 4 核心对比表：急救箱 vs 应急包

| 维度 | 家庭急救箱 | 家庭应急包 |
| --- | --- | --- |
| 应对场景 | 日常伤病（外伤、急症、用药） | 灾害（地震、火灾、断电、疏散） |
| 核心物品 | 敷料、绷带、消毒剂、常备药 | 水、食品、照明、保暖、证件 |
| 使用频率 | 较高，常被使用 | 低，但关键时刻保命 |
| 放置位置 | 家中固定高处 | 门口玄关、逃生通道附近 |
| 维护周期 | 每半年清点 | 每半年更换易耗品 |

**辨析｜易错点：** 一个常见误区是「把急救箱当成应急包」。地震来了，急救箱里的纱布救不了断电缺水的困境；反之，日常擦伤，应急包里的压缩饼干也派不上用场。**两者是并列关系，不是替代关系。**

## 5 自制急救箱：一张可对照的清单

急救箱既可以买成品，也可以自己配。自己配的核心价值是**「每样东西你都认识、都会用」**——这比成品箱的「样样俱全」更重要。按四区配齐后，建议附一张「物品清单 + 用途速记」：

| 物品 | 用途 | 放置区 |
| --- | --- | --- |
| 碘伏棉签/碘伏液 | 伤口消毒 | 清洁消毒区 |
| 生理盐水 | 冲洗伤口、洗眼 | 清洁消毒区 |
| 无菌纱布块/纱布卷 | 覆盖、包扎 | 止血包扎区 |
| 绷带/三角巾 | 加压包扎、悬吊 | 止血包扎区 |
| 创可贴 | 小伤口 | 止血包扎区 |
| 圆头剪刀/镊子 | 剪绷带、取异物 | 工具辅助区 |
| 体温计 | 测体温 | 工具辅助区 |
| 退热药/止泻药/抗过敏药 | 常备用药 | 常备药品区 |
| 一次性手套/口罩 | 个人防护 | 防护角 |
| 手电筒/口哨 | 照明求救 | 工具辅助区 |

清单做成塑封卡贴在箱盖内侧，每半年对照清点一次；**用掉的物品用后即补**，并标记购买日期。<span class="marginnote">急救箱的维护要「<strong>用后即补</strong>」而不是「月底一起补」：用完一卷纱布就立刻放回一卷，否则下次打开又是一个空半的箱子。把「补充」写进每个月的家庭检查里，急救箱才能常备常新。</span>

**辨析｜易错点：** 买成品急救箱最容易踩的坑是「箱内物品没人会用」——拆箱后逐样过一遍，把不会用的替换掉；其次是「急救箱放太深」——放在储物柜底层等于没有。急救箱就该放在**最容易拿到的地方**（如玄关、客厅显眼柜），并让全家人知道位置。

| 术语 | 含义 |

| 生理盐水 | 0.9% 氯化钠溶液，用于冲洗 |
| 三角巾 | 直角三角形布巾，多用途包扎 |

## 7 小结

- 急救箱按**清洁消毒、止血包扎、工具辅助、常备药品**四区布置，按处理流程取用。
- 管理四原则：**标签清晰、位置固定全家知晓、定期检查、只放用得上的**。
- 药品保留原包装、儿童够不着、过期即清；处方药单独存放。
- 急救箱之外还要备**家庭应急包**，覆盖水、食品、照明、保暖、证件，与急救箱同步维护。

在下一节，我们将从「工具」转向「判断」——学习急救最关键的一步：**意识、呼吸与循环的快速评估**，这是决定要不要启动心肺复苏的分水岭。
