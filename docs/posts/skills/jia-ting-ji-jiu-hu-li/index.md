# 家庭急救与日常医疗护理

家庭急救与日常医疗护理是守护家人健康的生活必备技能，系统覆盖常见伤病的现场急救、心肺复苏与气道急救、常见急症与意外伤害处理，以及家庭药箱、用药管理与基础护理。学完这些章节，就能够在突发伤病的第一时间实施正确处置，并做好家庭日常健康管理与基础照护。
