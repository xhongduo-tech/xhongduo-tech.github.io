## 为什么从中高级动作开始

垫上基础篇建立了核心耐力、脊柱逐节活动、骨盆控制与背部伸展的基本功。本节进入**中高级动作**，但「高级」的含义值得先澄清：**它不是因为「强度更大」而高级，而是因为「整合度更高」而高级**——每个中高级动作都要求你把前面学过的多个技能，在同一个动作里同时用出来。<span class="marginnote">以「海豹」为例：它同时需要脊柱卷曲（滚动如球）、双腿控制（腿部伸展）与平衡（核心稳定）——任何一个基础技能有缺口，这个动作就会「卡壳」。</span>本节拆解三个标志性的中高级动作：天鹅、游泳完整版与海豹。

## 1 从中级到高级的跨越

在动手练之前，先建立一个判断「你准备好了没有」的框架。普拉提进阶通常遵循三关：

**第一关：控制关**。基础动作是否能在慢速下保持质量？腰椎是否不代偿、呼吸是否不乱？
**第二关：整合关**。能否把两个以上技能在同一个动作里同时执行？（如「卷曲 + 伸展」「稳定 + 协调」）
- **第三关：节奏关**。动作是否流畅连贯，而非「分解动作的拼接」？

<span class="marginnote">中高级动作的「门槛」，主要是第二关与第三关。若基础动作还没过「控制关」，贸然上中高级动作，只会把错误模式「练得更熟」。<strong>进阶的正确顺序永远是：基础 → 整合 → 高级。</strong></span>

## 2 天鹅（Swan）：完整版伸展

**天鹅（Swan）**是天鹅预备式的完整版：从俯卧开始，双臂向前伸展，上身整体抬起后，手臂向后画弧、回到身体两侧，再回俯卧——动作像天鹅「划水」般流畅。

**动作步骤**：

1. **起始**：俯卧，双腿并拢，双臂向前伸直，前额贴垫。
2. **呼气抬起**：呼气，上身抬起，胸椎伸展，下巴微收，视线看前下方。
3. **画弧**：吸气，双臂向两侧画弧、向后收回体侧，同时上身继续维持伸展。
4. **回俯卧**：呼气，上身缓缓落回，双臂回到向前伸直位。
5. **重复**：完成 4—6 次。

**训练要点**：天鹅的「画弧」是点睛之笔——它把「胸椎伸展」与「肩胛活动」结合，练的是「伸展中的流畅」。<span class="marginnote">常见误区是把天鹅做成「俯卧撑」：手臂发力把上身「推」起来。正确的发力来自背伸肌群与核心，手臂只是「跟随画弧」。</span>若腰椎代偿，退回天鹅预备式。

## 3 游泳（Swimming）完整版

游泳在基础篇已介绍过「预备版」，完整版的要求更高：**抬起幅度更大、交替速度更快、躯干稳定要求更严**，可加上「双手双脚同时抬起、只以腹部为支点」的静态版本。

**完整版要点**：

**幅度**：四肢抬起离垫更高，但躯干始终稳定，像「浮在水面」。
**速度**：交替加快，如「自由泳打腿」，但呼吸保持节律，不因加快而屏息。
- **稳定**：骨盆与肩胛保持相对固定，只有四肢在「划水」。

**训练要点**：游泳练的是「动态中的核心稳定」——四肢越动，躯干越要「定」住。若躯干随四肢左右摇摆，说明核心的「抗旋转」能力不足，应退回预备版、放慢速度。

## 4 海豹（Seal）：滚动家族的进阶

**海豹（Seal）**：坐姿，双腿向前伸直，双手从内侧握住脚踝（或抓脚），身体后滚至肩颈、再回滚，滚动时双手拍脚 3 次、再拍垫 3 次——像「海豹鼓掌」。

**动作步骤**：

1. **起始**：坐于垫上，双腿向前伸直微屈，双手抓脚踝内侧。
2. **卷曲平衡**：收腹、卷背，身体后仰至「平衡点」，脚离地。
3. **后滚**：呼气，身体向后滚，滚至肩胛着垫即止（不到头部）。
4. **拍脚 3 次**：滚动到后方时，双手拍脚 3 次。
5. **回滚拍垫 3 次**：吸气回滚，回至平衡点后，双手拍垫 3 次。
6. **重复**：完成 6—8 次。

**训练要点**：海豹的难度在于「伸腿滚动」——腿伸直使力臂变长，平衡更难维持。<span class="marginnote">如果海豹「滚不动」或「砸背」，通常不是力量问题，而是「平衡点没找到」——先回到滚动如球，把「找平衡点」练熟，再挑战伸腿版本。</span>后滚始终止于肩胛，后脑勺不触垫。

## 5 机制解析：为什么中高级动作更「费脑」

中高级动作的「难」，本质是**注意力的资源被分光**了。普拉提动作的执行，消耗一种有限的认知资源——**动作注意力**。

$$注意力池 = 核心控制 + 呼吸 + 四肢协调 + 平衡，总量有限$$
