# 普拉提

普拉提是由约瑟夫·普拉提（Joseph Pilates）创立的身心整合训练体系，以垫上与各类小器械练习为形式，通过呼吸、核心控制与精准动作重塑深层肌群，兼具核心训练与体态矫正的功能。以《普拉提基础教程》、约瑟夫·普拉提原著与普拉提教练培训体系为纲，系统重建从普拉提原理、垫上基础与进阶、小器械练习到核心训练、体态矫正与教学实践的完整知识体系。
