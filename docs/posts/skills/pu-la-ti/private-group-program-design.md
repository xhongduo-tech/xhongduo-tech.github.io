## 为什么从私教与小班编排开始

上一节建立了课程结构，本节回答「结构如何适配场景」：**私教（一对一）与小班（一对多）是两种截然不同的教学场景**——私教为「一个人」定制，小班为「一群人」兼容。<span class="marginnote">许多教练的困惑在于「同一套动作怎么教给不同的人」：私教可以逐项定制，小班必须「一套动作、各自进阶」。理解两种场景的差异，是课程编排的进阶能力。</span>本节讲透私教与小班的编排逻辑、动作选择与进退阶策略。

## 1 私教 vs 小班：两种场景的分工

私教与小班不是「谁更好」的关系，而是「服务不同需求」的关系：

| 维度 | 私教（1 对 1） | 小班（1 对多） |
| --- | --- | --- |
| 核心目标 | 个性化定制、精准矫正 | 大众化训练、氛围带动 |
| 评估深度 | 深入（逐项评估、跟踪复评） | 浅层（统一评估、粗略分组） |
| 动作调整 | 每个动作单独进退阶 | 同一动作给多档选择 |
| 纠错频率 | 高（每动作都盯） | 低（巡视 + 重点纠错） |
| 课程成本 | 高 | 低 |

<span class="marginnote">判断建议：<strong>有明确体态问题、伤病史、特定目标的学员适合私教；追求氛围、规律训练、预算有限的选择小班。</strong> 许多学员的组合是「私教打基础 + 小班保频率」。</span>

## 2 私教课程编排：个性化定制

私教的价值在于「为一个人设计」，编排遵循「评估 → 定目标 → 选动作 → 复评」的闭环：

**第一步：深入评估。** 参考第3章的身体评估框架，做静态观察、动态评估、呼吸评估与核心检测，找到「最需要先解决」的 1—3 个问题。

**第二步：定制目标。** 与学员共同确定阶段目标，如「8 周内改善骨盆前倾」「4 周建立核心激活」。

**第三步：选动作。** 围绕目标选 4—6 个动作，遵循「松 → 练 → 整 → 管」的干预逻辑，并明确每个动作「对应解决哪个问题」。<span class="marginnote">私教编排的核心心法：<strong>每个动作都要「答得上一个问题」——教练必须能说出「这个动作解决什么、为什么选它」。</strong> 说不出的动作，就不该出现在私教方案里。</span>

**第四步：复评调整。** 每 4—8 周复评一次（用同一套评估方法），对比进步、调整方案——该进阶的进阶，该换的换。

## 3 小班课程编排：多水平兼容

小班的难点是「一套课教给不同水平的人」。编排策略是「同一动作、多档选择」：

**策略一：动作给「基础档」与「进阶档」。** 每个主体动作提供两个版本：基础版（退阶）与进阶版（加难度）。如平板支撑——基础版跪姿平板、进阶版直腿平板。学员按自己的水平选档。

**策略二：统一口令 + 个性化提示。** 课程用统一的动作口令（保证课堂节奏），但教练巡视时给个别学员「个性化提示」（「你的腰拱起来了，试试跪姿平板」）。

**策略三：按「难度」而非「水平」分组。** 小班内不用「初学者/进阶者」贴标签，而是「这一轮用 A 档、那一轮用 B 档」——同一学员也可能不同动作用不同档。<span class="marginnote">这样既避免了「贴标签」的心理负担，也让每个学员都能「各自进阶」。<strong>小班编排的实质，是把「个性化」藏在「多档选择」里。</strong></span>

**小班课的节奏管理**：动作之间的过渡要快而有序（提前摆好器械、口令简洁），避免「等动作」造成的时间浪费。

## 4 动作选择与进退阶

无论私教还是小班，动作选择都遵循「进退阶的杠杆」——用「变量」调节同一动作的难度：

**支撑面**：稳定面（垫）→ 不稳定面（小球、泡沫轴）。
**力臂**：短力臂（屈膝、腿高）→ 长力臂（伸腿、腿低）。
**幅度**：小幅度 → 大幅度。
- **速度**：慢速（易控）→ 流畅快速（难控）。
- **对称性**：双腿/双臂 → 单腿/单臂。

<span class="marginnote">这张「进退阶杠杆表」是教练最常用的工具：<strong>遇到「做不了」的学员，往「退阶方向」调一个变量；遇到「太轻松」的学员，往「进阶方向」调一个变量。</strong> 一次只调一个，方便归因。</span>

**动作选择的原则**：先选「基础且安全」的动作，再按目标叠加「针对性」动作；宁选「能正确完成」的简单动作，不选「勉强完成」的复杂动作。

## 5 机制解析：教学中的「注意力分配」

私教与小班编排的本质差异，可以归结为教练的「注意力分配」问题。

$$注意力预算 = 示范（如何做） + 讲解（为什么做） + 巡视（看谁做错） + 反馈（纠错）$$

把教练的「注意力预算」拆开：

- **示范（如何做）**：展示动作——注意力放在「自己的动作」上。
- **讲解（为什么做）**：解释要点——注意力放在「教学语言」上。
- **巡视（看谁做错）**：观察学员——注意力放在「课堂全景」上。
- **反馈（纠错）**：给出纠正——注意力放在「个别学员」上。

**注意力预算的总量有限**：私教可以把几乎全部注意力给「一个人」的反馈；小班则必须「分」给示范、讲解、巡视、反馈四件事——这就是两种场景「难度不同」的本质。小班教练的「进阶能力」，就是学会「分配注意力」：示范少而精、讲解一次到位、巡视有重点、反馈按优先级。

## 6 常见错误与辨析

**辨析｜易错点：** 私教与小班编排的常见错误：

**错误一：私教做成「小班范儿」。** 一对一的课也按「统一模板」走，没有「针对个人定制」。修正：私教每个动作都要「答得上这个问题」，围绕「评估 → 目标 → 选动作 → 复评」闭环。

**错误二：小班「只讲基础档」。** 为了「照顾最弱的学员」，整节课都做基础版，进阶学员「吃不饱」。修正：每个动作给「基础档 + 进阶档」，多水平兼容。

**错误三：小班「贴标签」。** 把学员分成「初学/进阶」并固定下来，挫伤学习动机。修正：按「难度」分组、按「动作」选档，同一学员不同动作可不同档。

**错误四：私教不复评。** 课程设计了，但从不复评调整，方案「万年不变」。修正：每 4—8 周复评一次，对比进步、调整方案。

## 7 从「编排」到「教学」：一个动作的教法

无论私教还是小班，一个动作的完整教法都遵循「四步」：

**第一步：示范完整动作。** 让学员看到「目标全貌」——先示范，再讲解。
**第二步：拆解要点。** 讲 1—2 个关键要点（如「呼气时卷起」），不一次讲太多。
**第三步：让学员练习。** 观察、纠正，只纠「最影响质量」的一个错误。
**第四步：进退阶。** 做不了的往「退阶方向」调一个变量，太轻松的往「进阶方向」调。

<span class="marginnote">教法的原则：<strong>「一次只教一个要点、一次只纠一个错误」——讲太多、纠太多，学员记不住，注意力反而被稀释。</strong> 会做「减法」的教练，才是好教练。</span>

## 8 小结

- 私教与小班：**私教定制、小班兼容**，是「服务不同需求」而非「谁更好」。
- 私教编排四步：**深入评估 → 定制目标 → 选动作 → 复评调整**，每个动作都要「答得上一个问题」。
- 小班编排三策略：**基础/进阶双档、统一口令 + 个性化提示、按难度而非水平分组**。
- 进退阶杠杆：**支撑面、力臂、幅度、速度、对称性**——一次只调一个变量。
- 机制解析：注意力预算 = 示范 + 讲解 + 巡视 + 反馈，小班难在「分配注意力」。
- 教学四步：**示范 → 拆解 → 练习 → 进退阶**，一次只教一个要点。
- 私教与组合：许多学员「私教打基础 + 小班保频率」，两种场景可互补衔接。
