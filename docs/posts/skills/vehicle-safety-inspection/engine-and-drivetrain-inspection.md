# 发动机与动力传动装置检查

## 为什么从发动机与传动系开始

上一节「整车参数」回答车「够不够格」，这一节看车「跑不跑得动、传不传得动」。发动机状态直接影响**动力性、排放性与可靠性**；传动系（离合器、变速器、传动轴）则决定动力能否平稳、可靠地传递到车轮。<span class="marginnote">发动机漏油、运转异响、尾气冒烟，常常是排放超标与动力下降的先兆——年检里发动机检查与《排放检测与噪声检验》是前后呼应的两道关。</span>

发动机与传动系的检验以**静态检查**为主（动态部分见《底盘动态检验与道路试验》），本节能动的有：核对信息、检查渗漏与运转、检查传动连接。

## 1 发动机检查

### 与公告/登记信息核对

发动机型号、出厂编号应与公告（注册登记）或行驶证（在用）记载一致。发动机号打刻在发动机缸体上，须清晰可辨、无打磨重打痕迹。<span class="marginnote">发动机号与 VIN 一样是「唯一性」的一环：发动机更换属于变更登记事项，未办理变更、擅自更换发动机，在检验中会被记录并按异常处置。</span>

### 运转状态检查

启动发动机，检查：

- **怠速是否平稳**：无熄火、无剧烈抖动、转速无异常波动；
- **有无异响**：敲缸、金属摩擦等异常声响应记录；
- **有无渗漏**：发动机下部、油底壳、缸盖结合面有无机油、冷却液渗漏；
- **排气管状态**：连接是否牢固、有无破损，尾气有无冒黑烟/蓝烟（冒烟异常转排放检验环节深查）。

### 燃油与排气系统

燃油管路、燃油箱应无渗漏、无老化龟裂；排气管、消声器应安装牢固、无破损、无漏气。汽油车还应检查加油口与油箱盖状态，柴油车注意高压油管有无渗漏。

## 2 传动系检查

传动系把发动机的动力逐级送到驱动轮，静态检查覆盖离合器、变速器、传动轴三块：

**离合器**：踏下离合器踏板应平顺、无沉重或异响；液压离合器检查油液液位与管路，无渗漏。

**变速器**：检查变速器壳体有无裂纹、渗漏，油液液位正常；换挡机构在静态下应能正常挂入各挡（结合动态确认换挡顺畅）。

**传动轴**：万向节、中间支承应无松旷、无裂纹，防尘套完好；传动轴螺栓连接紧固，无明显变形。<span class="marginnote">传动轴是「看不见的危险件」：松旷的万向节在高速下可能引起剧烈振动甚至甩脱。年检的传动检查要「看得细」——举升后逐段目视+晃动检查，是最可靠的静态手段。</span>

### 传动系与其他系统的衔接

传动系检查与**制动系**、**行驶系**在检验台上是分开的工位，但实车中相互耦合：传动轴振动可能被误判为车轮问题，离合器打滑则直接拖累制动与加速性能。检验记录时应注明异常部位与现象，便于维修人员准确定位。

## 3 核心对比表：发动机与传动系检查要点

| 检查对象 | 静态检查要点 | 常见不合格项 |
| --- | --- | --- |
| 发动机 | 型号编号核对、怠速平稳、无渗漏、无异响 | 擅自更换、渗漏、运转异响 |
| 燃油系统 | 管路无渗漏、无老化 | 漏油、油管龟裂 |
| 排气系统 | 安装牢固、无破损 | 漏气、冒黑烟 |
| 离合器 | 踏板平顺、液压无渗漏 | 打滑、分离不彻底 |
| 变速器 | 壳体无裂纹、油液正常 | 渗漏、壳体破损 |
| 传动轴 | 万向节/中间支承无松旷、螺栓紧固 | 松旷、变形、防尘套破损 |

这张表的本质是「**看得见、摸得着**」：传动系的多数隐患靠目视、晃动、听音就能发现，是检验员动手能力的基本功。

## 4 实务要点：动力系统检查的现场控制

**运转检查的安全**：启动发动机前确认挡位在空挡、驻车制动可靠；检查渗漏时防止烫伤（排气管、增压器高温）；燃油系检查时严禁明火。

**异常信号的分级**：发动机怠速不稳、冒烟、异响等属于**车辆故障信号**，检验记录应如实描述现象；现象与排放、动力相关的，转到对应检验环节深查，不要「一判了之」。<span class="marginnote">「怠速不稳 + 冒蓝烟」几乎可断定烧机油；「怠速熄火」则可能累及转向助力与制动真空——这些现象在记录里写清楚，比直接判不合格对维修更有价值。</span>

**新能源与混动的差异**：纯电动车无发动机，检查重点转向驱动电机、动力电池与高压系统（见《新能源汽车专项检验》）；插电混动同时保留发动机，两套系统都要查。

**与动态检验衔接**：静态检查发现的问题，动态检验（《底盘动态检验与道路试验》）中重点验证——离合器打滑、传动轴振动都要在行驶工况下确认。

| 环节 | 重点 | 衔接 |
| --- | --- | --- |
| 静态发动机 | 渗漏、异响、编号 | 排放检验 |
| 静态传动 | 松旷、紧固 | 底盘动态检验 |
| 新能源 | 电机、高压、电池 | 新能源专项检验 |

**动力系统常见故障现象速查**：把「看到/听到的现象」与「可能的成因」对上，是动力检查的经验积累：

| 现象 | 可能成因 | 处置方向 |
| --- | --- | --- |
| 怠速不稳 | 点火/喷油/真空漏气 | 深查后转排放检验 |
| 冒蓝烟 | 烧机油（活塞环/气门油封） | 记录、提示维修 |
| 冒黑烟 | 混合气过浓、喷油过量 | 转排放检验 |
| 离合器打滑 | 摩擦片磨损、压盘失效 | 建议更换 |
| 传动轴振动 | 万向节松旷、动平衡破坏 | 举升复核 |
| 变速器异响 | 轴承磨损、齿轮损坏 | 记录、建议检修 |

**动力系统的「体检思维」**：发动机与传动系的静态检查，本质是给动力链做一次「体检」——编号信息对身份，运转状态对功能，渗漏异响对隐患。检验员看到的不只是「一个漏油的发动机」，而是「这台车的动力链还能支撑多久」。<span class="marginnote">「现象—成因」对照表不是死记硬背的，而是在一次次检验里积累的——今天记下「冒蓝烟=烧机油」，明天听到异响就多了一分判断力。经验就是这样长出来的。</span>

**与整车的联动**：动力系统状态影响的不只是动力本身——怠速不稳可能拖累排放与制动真空，离合器打滑会削弱加速与坡道起步能力。检验记录把动力现象写全，后续环节才能联动判断。

## 5 小结

- 发动机检查三件事：**编号信息核对、运转状态（怠速/异响/渗漏）、燃油排气系统**。
- 传动系检查三块：**离合器（踏板/液压）、变速器（壳体/油液/挂挡）、传动轴（万向节/中间支承/螺栓）**。
- 发动机号与 VIN 一样是唯一性一环，擅自更换发动机属异常，须按变更登记处置。
- 动力系统异常多用**目视、晃动、听音**发现，是检验员动手基本功。
- 纯电动车无发动机，检查重心转向电机、电池与高压系统，见新能源专项。
- 「现象—成因」对照是经验核心：怠速不稳查点火喷油、冒蓝烟疑烧机油、传动轴振动查万向节。
- 动力检查「对身份、对功能、对隐患」三步走，静态现象为排放与动态检验提供线索。
- 检查先空挡+驻车制动、防烫防明火，安全是动力检查的前提。

- 冒烟类型辨成因：冒蓝烟烧机油、冒黑烟混合气过浓、冒白烟含水/冷却液。
- 离合器三查：踏板平顺、液压无渗漏、接合不打滑。
- 传动三查：万向节无松旷、中间支承无异响、螺栓紧固。
- 燃油系检查严禁明火，排气管高温部位防烫伤。
- 发动机检查与排放检验前后呼应：现象在前、数据在后。

- 发动机与传动静态检查是动力链「体检」，现象记录为排放与动态检验提供线索。

**拓展思考**：为何「烧机油」要写进记录而不直接判不合格？烧机油本身不直接威胁结构安全，但它累及排放、积碳与催化器寿命——记录现象、提示维修，比「一刀切」更负责任。传动轴振动「只在某个车速区间出现」，因为动平衡失效的共振点在特定转速——记录「哪个车速抖」，维修就有方向。
