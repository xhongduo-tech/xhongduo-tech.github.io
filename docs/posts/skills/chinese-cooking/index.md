# 中式烹饪工艺（中式烹调师）

中式烹饪工艺是以刀工、火候、调味与烹制技法为核心的完整工艺学体系，支撑着中式烹调师职业技能的养成与进阶。以国家职业技能标准《中式烹调师》、《中国烹饪工艺学》、《中国烹饪百科全书》为纲，系统重建从原料加工、刀工成型、火候运用到调味勾芡、烹制技法、装盘成品的完整工艺链条。学完这些章节，就写完了中式烹饪工艺的全部内容。

## 对标教材

- 国家职业技能标准《中式烹调师》
- 中国商业出版社《中国烹饪工艺学》
- 中国大百科全书出版社《中国烹饪百科全书》
