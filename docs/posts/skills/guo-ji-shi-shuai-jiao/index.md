# 国际式摔跤

摔跤是最古老的奥运会竞技项目之一，以古典式与自由式两大体系为核心，融合力量、技巧与战术的对抗性搏击运动。以UWW《摔跤竞赛规则》、《摔跤运动教程》与中国摔跤协会竞赛培训体系为纲，系统重建从竞赛规则、站立与跪撑技术、古典式与自由式专项技术到训练战术与竞赛组织的完整知识体系。
