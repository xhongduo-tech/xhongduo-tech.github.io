# 家庭急救与应急救护（心肺复苏/AED/海姆立克）

以中国红十字会《救护员》教材、AHA《心肺复苏与心血管急救指南》与国家卫健委《院前急救管理办法》为纲，系统构建从现场评估、心肺复苏（CPR）、AED 使用、海姆立克急救法到创伤救护与家庭应急准备的完整院前急救技能体系。学完这些章节，就掌握了公民必备的院前急救素养与红十字会救护员认证的核心内容。

## 对标教材

- 中国红十字会总会《救护员》
- AHA《心肺复苏与心血管急救指南》
- 国家卫健委《院前急救管理办法》
