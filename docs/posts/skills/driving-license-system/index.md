# 机动车驾驶证体系与考试制度

以公安部令第162号《机动车驾驶证申领和使用规定》、行业标准《机动车驾驶人考试内容和方法》（GA 1026）与《道路交通安全违法行为记分管理办法》为纲，系统梳理从准驾车型分类、科目一至科目四考试、记分周期到换证审验与法律责任的完整驾驶证制度。学完这些章节，就理解了机动车驾驶证的申领、考试、管理与使用的全过程。

## 对标教材

- 公安部令第162号《机动车驾驶证申领和使用规定》

- 《道路交通安全违法行为记分管理办法》
