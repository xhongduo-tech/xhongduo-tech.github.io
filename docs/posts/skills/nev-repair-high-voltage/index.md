# 新能源汽车维修与高压电安全

新能源汽车高压电气系统带高压与储能风险，维修作业对持证与安全规范有强制要求。以 GB/T 18384-2020《电动汽车安全要求》、GB 38031-2020《电动汽车用动力蓄电池安全要求》及应急管理部《特种作业人员安全技术培训考核管理规定》为纲，系统建立从高压系统认知、维修安全作业、动力电池检修到整车测试验证的完整安全技能体系。

## 对标教材

- GB/T 18384-2020《电动汽车安全要求》
- GB 38031-2020《电动汽车用动力蓄电池安全要求》
- 应急管理部《特种作业人员安全技术培训考核管理规定》
