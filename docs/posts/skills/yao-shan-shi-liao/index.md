# 药膳与食疗

药膳与食疗以「药食同源」为根基，融合中医基础理论与烹饪技艺，通过对食材与中药材性味归经的合理配伍，实现日常养生、体质调理与病症辅助治疗。学完这些章节，就写完了从理论基础、药食原料、制作工艺到食疗应用、特殊人群调养的全部内容。
