## 为什么从儿童与老年药膳开始

人生的「一头一尾」——儿童与老年，是药膳最需要「因人施膳」的两个阶段。儿童**「脾常不足」**（消化弱）、**「肝常有余」**（易上火），老人**肾气日衰、脾胃运化亦弱**。给这两个人群配膳，不是「少吃一点」这么简单，而是有完全不同的法则。<span class="marginnote">给儿童配膳要防「过补」，给老人配膳要防「过腻」——看似相反，实则同源：都是「脾胃承受力」这个变量在主导。小儿脾常不足、老人运化亦弱，脾胃是两头共同的「短板」。</span>

本节分儿童与老年两大板块，讲透各自体质特点、食疗要点与禁忌。

## 1 儿童药膳：脾常不足，以养为主

**儿童体质特点**：
**脏腑娇嫩、形气未充**——「纯阳之体」但阴阳皆未充盛；
**脾常不足**——运化力弱，易积食、易腹泻；
- **肝常有余、心常有余**——易惊、易热、易动。

**儿童食疗四原则**：

**第一，以「平补、清补」为主，忌峻补。** 儿童不需要人参、鹿茸之类峻补——「纯阳之体」误补反生内热。宜**平补脾胃**：山药、莲子、茯苓、小米。<span class="marginnote">「小儿慎补」是儿科铁律：孩子身体在「生长」而非「亏耗」，正常饮食足够支撑发育，峻补反而拔苗助长（性早熟、内热、积滞）。儿童药膳的核心词是「养」不是「补」——养脾胃、养气血，顺应生长之势。</span>

**第二，健脾消食，防积化热。** 儿童最常见的病是「积食」（食积化热→发热、口臭、夜卧不宁）。宜常备**消食导滞**：山楂、麦芽、萝卜；「若要小儿安，常带三分饥与寒」——**七分饱、莫追喂**，是儿童食疗第一要义。

**第三，荤素搭配、五味平和。** 儿童脾胃娇嫩，忌过甜（伤脾生湿）、过咸（伤肾）、过辛（动火）、过油腻（碍脾）。均衡多样，少食多餐。

**第四，药食宜「轻、薄、软、温」。** 儿童药膳宜药量轻、滋味薄、质地软烂、温度温热——粥、羹、蒸蛋、软面是儿童药膳的最佳载体。

**儿童常见问题的食疗**：

| 问题 | 表现 | 食疗 |
| --- | --- | --- |
| 积食 | 口臭、腹胀、夜卧不宁 | 山楂麦芽水、萝卜汤、焦米粥 |
| 脾虚泄泻 | 便稀、面黄、食少 | 山药莲子粥、芡实茯苓粥 |
| 睡眠不安 | 惊惕、夜啼 | 莲子百合粥、红枣小米粥 |
| 食欲不振 | 挑食、消瘦 | 山药小米粥、麦芽茶、鸡内金（少量，须辨证） |

<span class="marginnote">给儿童用药膳，还有一个「口味」问题：孩子抗拒苦味，所以儿童药膳几乎都是甘甜可口之品——山药粥、红枣羹、山楂水。这也符合药膳「味以适口为度」的原则。但甜要控量，用红枣、枸杞、山楂的自然甜味，少用精制糖。</span>

**重点：儿童药膳的三条红线。** ①**不峻补**（人参、鹿茸、蜂王浆——含激素类成分者尤忌）；②**不过量**（儿童食量小，药量更小，宁少勿多）；③**不盲目**（孩子生病先就医，食疗只是辅助，不替代治疗）。

## 2 老年药膳：肾衰脾弱，以「润、软、温」为纲

**老年体质特点**：
**肾气渐衰**——肾精亏耗，骨质、耳窍、发齿皆随之而衰；
**脾胃运化弱**——消化吸收力下降，易便秘、易虚不受补；
- **气血阴阳皆亏**——多虚多瘀、多兼痰湿。

**老年食疗四原则**：

**第一，以「平补阴阳、重在养肾」为本。** 老年人宜缓补、平补，重点在**肾**：黑芝麻、核桃、枸杞、桑葚、黑豆（色黑入肾、填补肾精）。

**第二，以「润」为要，防燥防干。** 老人津液易亏，常见皮肤干、大便干——宜滋阴润燥：银耳、百合、蜂蜜、芝麻；防「虚火」。

**第三，以「软、温」为形，顾护脾胃。** 老人咀嚼消化力弱，宜烂软温热——粥、羹、炖菜、蒸品；**忌生冷、坚硬、油腻**。

**第四，少食多餐、细嚼慢咽。** 老人胃纳渐小，宜「少食多餐」——三餐七分饱、上下午可加小食（粥、糊、羹）。

**老年常见问题的食疗**：

| 问题 | 表现 | 食疗 |
| --- | --- | --- |
| 肾虚腰膝酸软 | 腰酸腿软、夜尿多 | 核桃黑芝麻糊、枸杞桑葚粥、板栗炖鸡 |
| 老年便秘 | 大便干结、排便费力 | 蜂蜜水、核桃芝麻糊、红薯粥、决明子茶 |
| 失眠健忘 | 入睡难、记性差 | 桂圆莲子粥、酸枣仁粥 |
| 气血亏虚 | 乏力、面白、气短 | 黄芪当归炖鸡、红枣桂圆汤 |
| 骨质疏松 | 易骨折、腰背痛 | 虾皮豆腐汤、牛奶、黑豆猪骨汤 |

<span class="marginnote">老年便秘是「润」字诀的最佳应用：老人便秘多因<strong>津亏肠燥</strong>（非实热积滞），故用蜂蜜、芝麻、核桃「润肠通便」，而非大黄、番泻叶「泻下」——润与泻，一个养正、一个伤正，老年便秘误用泻药最伤元气。</span>

**辨析｜易错点：老人「虚不受补」，进补要「小步慢走」。** 老年人体质多「虚中夹实」——进补稍猛即上火、腹胀。正确策略是：**从平补开始、量小渐增、配理气之品（陈皮、砂仁）防滋腻**；且先顾脾胃（吃得下、化得开）再谈补肾填精。所谓「补不嫌迟、嫌其峻」——老年进补，慢即是快。

## 3 儿童与老年药膳的「同」与「异」

两个看似相反的人群，药膳原则却「异中有同」：

| 维度 | 儿童 | 老年 |
| --- | --- | --- |
| 核心短板 | 脾常不足（运化弱） | 肾气衰 + 脾运弱 |
| 补泻取向 | 以养为主，忌峻补 | 以平补为要，防虚不受补 |
| 食物形态 | 轻、薄、软、温 | 烂、软、温、润 |
| 主要防忌 | 过补、过甜、积食 | 滋腻、生冷、泻药 |
| 共同铁律 | **顾护脾胃、七分饱、循序渐进、食疗辅助不替代医疗** | |

<span class="marginnote">把这张表记成一句话：<strong>「一头一尾，都以脾胃为轴」</strong>——儿童防积（消化不过来）、老人防虚（吸收不进去），殊途同归地落在「养好脾胃」上。这也再次印证了本节开篇的判断：脾胃是两头共同的短板，也是药膳共同的抓手。</span>

## 4 儿童老年药膳的现代视角

一头一尾两个人群，现代营养学给出了与中医高度呼应的指导：

| 中医要点 | 儿童现代对应 | 老年现代对应 |
| --- | --- | --- |
| 脾常不足、忌峻补 | 儿童营养宜均衡充足，勿过度进补 | 老年人消化吸收下降，宜少食多餐 |
| 七分饱、莫追喂 | 规律进餐、控制零食，防超重 | 控制总量，防「三高」与肥胖 |
| 食宜软温 | 咀嚼消化能力未成熟，宜软烂 | 咀嚼吞咽退化，宜软烂易化 |
| 肾气渐衰、填精补髓 | 儿童不必补肾，均衡即可 | 老人重视钙、蛋白、维生素 D |
| 以脾胃为轴 | 关注肠道健康与食欲 | 关注消化吸收与肠道菌群 |

<span class="marginnote">现代视角的启示：儿童的「脾常不足」对应消化系统未成熟，老人的「脾弱肾衰」对应消化吸收与骨代谢退化——中医的「以脾胃为轴」，与现代的「消化吸收与肠道健康是营养基础」完全同构。两套语言，一个焦点。</span>

**重点：儿童与老人的现代食疗底线，都是「营养均衡优先」。** 儿童处在生长发育期，营养需求高；老人存在吸收率下降——两者都不能靠「一两味补品」解决问题。**均衡膳食打底、药膳作辅助、体检作监测**，才是科学的「一头一尾」食疗观。

## 5 儿童老年药膳的常见误区

两个人群的食疗误区最多，因为「爱之深、补之切」，选六条辨析：

| 误区 | 真相 |
| --- | --- |
| 「孩子长个子要猛补钙」 | 钙过量反有害，重在维生素 D 与均衡 |
| 「儿童吃补品长得快」 | 峻补致性早熟、内热，儿童宜养不宜补 |
| 「老人瘦一点就好」 | 老年消瘦是肌少症风险，需保证优质蛋白 |
| 「老人喝粥最养胃」 | 长期只喝粥，胃功能退化、营养不足 |
| 「骨头汤补钙」 | 骨头汤钙含量极低，补钙要靠奶、豆、绿叶菜 |
| 「儿童老年药膳一样做」 | 儿童防积、老人防虚，方向完全不同 |

<span class="marginnote">六个误区里，「骨头汤补钙」与「老人喝粥最养胃」流传最广、误导最深：骨头汤的钙远不如一杯牛奶，长期纯粥又让老人营养失衡。给老人配膳的正确姿态是「<strong>软而不素、烂而不寡</strong>」——既要好消化，也要保证蛋白质、钙、维生素全面。</span>

**辨析｜易错点：儿童与老年的食疗，都要「以体检为依据」。** 儿童生长曲线、老人骨密度与生化指标，是判断「缺什么、补什么」的硬依据——食疗不该「凭感觉」，而该「看数据」：体检发现问题，再针对性食疗配合，才是负责任的「一头一尾」调养。

## 6 小结

- **儿童**「脾常不足、纯阳之体」：以养为主、忌峻补；健脾消食防积热；食宜轻薄软温。
- 儿童三红线：**不峻补、不过量、不盲目**（病先就医）。
- **老人**「肾衰脾弱」：平补养肾、以润为要、软温为形、少食多餐。
- 老人进补要「**小步慢走**」：防虚不受补，先顾脾胃再谈填精。
- 儿童与老年异中有同：**都以脾胃为轴、七分饱、食疗辅助不替代医疗**。
