## 为什么瓦工是「面子工程」的基石

瓦工工程（泥瓦工程）承担三件大事：**砌筑**（砌新墙）、**抹灰**（墙面找平打底）、**贴砖**（墙地砖铺贴）。它是硬装里「最可见、最考验手艺」的部分——瓷砖铺得平不平、对缝齐不齐、有没有空鼓，一眼可见，且返工极难。<span class="marginnote">瓦工与前面的隐蔽工程是「承上启下」的关系：<strong>隐蔽工程（水电、防水）的成果，要靠瓦工「封存」并「覆盖」</strong>——瓦工贴砖，既保护了防水层，又为后续木工、油漆提供了基准面。瓦工做得好，后面工种都省心；瓦工返工，前面工序全白干。</span>

## 1 砌筑工程：从新墙到抹灰

**砌筑**（砌新墙）在第 4 篇《拆改》讲过要点，这里补施工细节：

**砌筑材料**：轻质砌块（加气块）或红砖。砌块墙体较轻、隔音略差；红砖隔音好但重、需结构验算。
**砌筑工艺**：**错缝砌筑**（上下皮砖错开 1/2 以上），灰缝饱满、横平竖直；顶部与梁底交接处**斜砌或留缝后填实**（防沉降开裂）。
**构造要求**：墙长超过一定长度要**加构造柱**，门洞上方加**过梁**（承托门洞上方墙体重），新砌墙与旧墙**植筋连接**。

**抹灰（粉刷）**：砌筑/基层找平的工序——用水泥砂浆在墙面抹一层「打底层」。抹灰的作用：**找平基层、保护墙体、为后续饰面（乳胶漆、贴砖）提供平整基面**。<span class="marginnote">抹灰的「平」决定后面一切的「平」：<strong>墙面乳胶漆要平、瓷砖要平、柜子要能严丝合缝</strong>，都靠抹灰找平这层「地基」。验收用 <strong>2 m 靠尺 + 塞尺</strong>：靠尺贴墙，缝隙 ≤ 3 mm 为合格——这是墙面平整度的「硬指标」。</span>

**抹灰工艺要点**：基层湿润 → 找平冲筋（做标筋控制平整度）→ 分层抹灰（每层 ≤ 8–10 mm，一次抹太厚易开裂）→ 压实收光。新老墙交接、水电开槽处**挂网**（防裂）。

## 2 贴砖：从基层到空鼓

贴砖是瓦工的核心手艺，决定墙地面「好不好看、耐不耐用」：

**贴砖前的基层准备**：
墙面基层**坚实、平整、干燥**（贴砖前浇水湿润，但防水层上不能积水）。
**瓷砖泡水**（釉面砖铺前泡水 2 小时，吸足水分、避免上墙后吸浆过快空鼓）；**全瓷砖（低吸水率）不泡水，需用瓷砖背胶**。
**排版**：贴砖前按设计**排版**——从显眼处（门口、窗边）起铺，把「半砖」排到不显眼处（墙角、柜后）；墙地砖**对缝**（墙砖缝与地砖缝对齐，更整体）。

**贴砖工艺**：两种主流方法——**水泥砂浆铺贴**（传统，厚贴）与**瓷砖胶薄贴**（现代，薄贴）：
- **水泥砂浆铺贴**：传统工艺，用水泥砂浆做粘结层（厚 15–25 mm）。成本低、适用广，但**空鼓率偏高**（砂浆收缩、工人手法影响大）。
- **瓷砖胶薄贴**：用瓷砖胶（成品粘结剂）薄涂（厚 3–8 mm），**粘结强度高、空鼓率低、施工快**，但成本高、对基层平整度要求高（基层不平要先找平）。**大规格瓷砖、全瓷砖、地砖上墙，必须用瓷砖胶（薄贴）+ 背胶**。<span class="marginnote">为什么大砖必须「薄贴」？<strong>瓷砖规格越大、自重越大，水泥砂浆厚贴的粘结力越难「抓」住它</strong>——大砖上墙用水泥砂浆，空鼓脱落风险显著增加。<strong>600×1200 以上的墙砖、地砖上墙，一律瓷砖胶薄贴 + 瓷砖背胶</strong>，这是近年贴砖的主流升级。</span>

**留缝**：瓷砖铺贴必须**留缝**（砖缝 1.5–3 mm）——瓷砖与水泥砂浆都会热胀冷缩，不留缝则「顶砖」起拱。留缝后用**十字卡**控制缝宽，后期用**美缝剂**填缝（比白水泥耐污、防水）。

## 3 空鼓的检测与处理

**空鼓**是贴砖最典型的质量通病——瓷砖与基层之间「脱开」，敲击有空响。空鼓的危害：**瓷砖松动脱落（高处掉砖伤人）、积水渗漏（卫生间墙地面空鼓处渗水）、地板异响**。

**空鼓检测**：贴砖完工后，用**空鼓锤（或小棍）逐个敲击**瓷砖，听声音——**清脆「当当」声是实贴，空洞「咚咚」声是空鼓**。<span class="marginnote">空鼓检测的「土办法」很灵：<strong>用硬币或小铁锤轻轻敲击每块砖</strong>，声音实的没问题，声音空的就有空鼓。规范要求：<strong>单块砖空鼓面积 ≤ 15%，全墙空鼓砖数 ≤ 5%</strong>——小面积边角空鼓可接受，大面积空鼓必须返工（起砖重贴）。</span>

**空鼓的处理**：
**边角小空鼓**（面积 < 砖面 15%）：可注浆（打孔注入粘结剂）补救。
**大面积空鼓 / 地砖空鼓**：必须**起砖重贴**——地砖空鼓长期踩踏会碎裂。

**辨析｜易错点：** 墙面空鼓与地面空鼓的「容忍度」不同：**地砖空鼓要求更严**（天天踩、易碎），墙砖空鼓若在「高处、危险位置」（如淋浴墙顶、厨房吊柜后方）也要返工。**贴砖后 48 小时再做空鼓检测**（粘结层需时间硬化），太早检测不准确。

## 4 核心对比：两种贴砖工艺

| 维度 | 水泥砂浆铺贴（厚贴） | 瓷砖胶薄贴 |
| --- | --- | --- |
| 粘结层厚度 | 15–25 mm | 3–8 mm |
| 粘结强度 | 中（依赖工人手法） | 高（成品粘结剂） |
| 空鼓率 | 偏高 | 低 |
| 施工速度 | 慢 | 快 |
| 基层要求 | 低（可借砂浆找平） | 高（基层须平整） |
| 成本 | 低 | 中—高 |
| 适用 | 中小砖、地面 | 大砖、全瓷砖、地砖上墙 |

**选工艺的逻辑**：**小砖、地砖可厚贴；大规格砖、全瓷砖、墙砖上墙用薄贴**。预算允许时，全屋贴砖都建议「薄贴」——省心、空鼓少、节省空间（薄贴省出的 1–2 cm 层高在层高紧张的户型里很珍贵）。

## 5 瓦工验收清单

贴砖完工、填缝完成后，按清单验收：

1. **平整度**：2 m 靠尺检查，墙面 ≤ 2 mm、地面 ≤ 2–3 mm。
2. **空鼓**：逐块敲击，单砖 ≤ 15%、全墙 ≤ 5%。
3. **对缝**：砖缝横平竖直、宽窄一致；墙地砖对缝对齐。
4. **坡度**：卫生间、阳台地面**向地漏找坡**（坡度 1–2%，泼水测试排水顺畅、无积水）。
5. **阴阳角**：墙砖阴阳角方正（90°），用角尺检查。
6. **磕碰破损**：砖面无划痕、无崩角、无色差（同批次砖色差应极微）。<span class="marginnote">卫生间「泼水测试」是验收的隐藏项：<strong>贴完砖向地面泼水，看水是否都流向地漏、墙角有无积水</strong>。地漏是「最低点」的标准就靠这一泼——坡没找好，洗澡水积在角落，长年累月就发霉。这是「坡度」验收最直观的土办法。</span>

## 6 瓷砖规格与空间搭配

瓷砖规格不只是「大小问题」，它直接影响**视觉、损耗与人工费**——选对规格，省钱又好看；选错规格，多花钱还显乱。

**瓷砖规格的「空间搭配」**：

| 空间 | 推荐规格 | 理由 |
| --- | --- | --- |
| 客餐厅地面 | 600×1200、750×1500 | 砖大缝少、显大气 |
| 卧室地面 | 木纹砖 200×1200 | 木地板质感、防水耐磨 |
| 厨房墙面 | 400×800、300×600 | 中规中矩、损耗低 |
| 卫生间墙面 | 300×600、400×800 | 竖贴显高 |
| 卫生间地面 | 300×300（防滑） | 小砖找坡好 |
| 玄关地面 | 600×600、拼花 | 耐磨、好清理 |

**规格与「视觉」**：**砖越大，空间越显「整」**（缝隙少、连续感强）；砖越小，越显「繁复」（缝隙多）。**小空间用大砖**反而显大（少缝），**大空间可用小砖**做分区或点缀。

**规格与「损耗」**：**砖越大，切割损耗越大**——大砖切一刀就废（第 3 篇讲过损耗率 5–10%、异形 10–15%）。**「规格越大，损耗率要预留越高」**。

**规格与「人工费」**：**大砖铺贴人工费更高**（重、难搬、对基层要求高），**异形铺贴（人字铺、斜铺）人工费翻倍**。预算紧张时，**「常规规格 + 常规铺法」**是省钱正道。

**「墙地对缝」的规格配合**：墙地砖**对缝**要好看，墙砖与地砖规格最好成**整数倍关系**（如墙砖 300×600、地砖 600×600）——否则「对不齐缝」，整体感打折。

**辨析｜易错点：** 「大砖一定显大」是误区——**大砖在「小房间」可能显局促**：2.5 m 宽的卫生间铺 750×1500 大砖，切得七零八落，反而显乱。**「砖的大小要与空间匹配」**：客餐厅大砖显大气，厨卫小空间用中砖即可——**「宁小勿大」在狭小空间成立**。

**「瓦工验收的时机」**：空鼓检测要在**贴砖 48 小时后**做（粘结层硬化后检测才准），太早检测会误判；美缝则要等**瓷砖完全干透**（约 3–7 天）再做，否则美缝剂与潮湿基层粘结不牢。

## 7 小结

- 砌筑：**错缝砌筑、门洞过梁、新旧墙植筋挂网**；抹灰用 2 m 靠尺验平整（≤ 3 mm）。
- 贴砖：**排版起铺**（半砖藏角落、墙地对缝）、大砖全瓷**瓷砖胶薄贴 + 背胶**。
- 瓷砖必须**留缝**（1.5–3 mm），后期美缝；不留缝会「顶砖」起拱。
- 空鼓检测用**空鼓锤逐块敲**：单砖 ≤ 15%、全墙 ≤ 5%；大面积空鼓必须返工。
- 瓦工验收六项：**平整、空鼓、对缝、坡度、阴阳角、无破损**；泼水测试验排水。
