# 模具制造（工具钳工与模具工）

模具制造是冲压与注塑模具从加工、装配、调试到修复的完整技能链条，是汽车、家电与塑料制品制造业的核心支撑工种。以《国家职业技能标准—工具钳工》、《模具设计与制造》与《模具工实用技术手册》为纲，从模具结构与材料基础到型腔加工、装配调试与缺陷修复，系统写完整套模具制造实操技能。
