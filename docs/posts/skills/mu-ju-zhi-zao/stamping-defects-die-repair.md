## 为什么从冲压缺陷开始

试模暴露的问题，不会自己消失——**要么修模具，要么调工艺**。本节专门面对冲压件的质量缺陷：它们长什么样、病根在哪、怎么修。<span class="marginnote">冲压件的缺陷诊断，是模具工「<strong>手艺含金量</strong>」最高的环节之一：毛刺、断面粗糙、尺寸超差、回弹、起皱——<strong>每一个症状背后都对应着一组候选病因，而且「同一个症状可能有两个相反的病根」</strong>（如毛刺既可能间隙过大也可能间隙过小）。诊断的关键，是「症状 → 病因 → 对策」的对应表——先看对病，再下药。</span>本节用「缺陷-原因-对策」的框架，把冲压件常见缺陷一网打尽。

## 1 冲压件缺陷诊断的基本思路

冲压件缺陷分析有一套通用的思路，先立方法论：

**第一步，看症状**：毛刺、断面、尺寸、形状、表面——先「看清」缺陷长什么样。
**第二步，找归属**：缺陷是**模具原因**（间隙、刃口、结构）还是**工艺原因**（压力、送料、材料）——分不清归属就乱修。
**第三步，对病因**：用「缺陷-原因」对应表缩小范围——一个症状列出一组候选病因，按概率与可检查项逐个排查。
**第四步，下对策**：修模或调机——**先易后难、先调机后修模**（调机快、修模慢）。

**诊断的难点在「一症多因、一因多症」**：毛刺既可能间隙过大也可能间隙过小；间隙不当既造成毛刺也造成断面粗糙——**诊断要靠「症状组合」**：看毛刺方向、断面四带比例、毛刺大小，综合判断。<span class="marginnote">「一症多因」的诊断，是「<strong>用症状组合缩小病因空间</strong>」的推理：单个症状无法确诊，但「毛刺方向 + 断面光亮带比例 + 毛刺大小」组合起来，就能定位到间隙偏大还是偏小。这像「多特征联合诊断」——<strong>单特征不充分，特征组合才够用</strong>。</span>

## 2 毛刺与断面缺陷：间隙的「镜子」

**毛刺**是冲压件最常见的缺陷，断面缺陷（光亮带比例、双重光亮带）是间隙的直接反映：

**毛刺过大且带方向**：**毛刺方向是判断间隙大小的关键**——毛刺偏向哪一侧，哪一侧的间隙就偏大。凸模侧毛刺大 → 凸模侧间隙过大；凹模侧毛刺大 → 凹模侧间隙过大。
**间隙过大**：断面断裂带扩大、光亮带缩小、塌角带增大——毛刺大而厚、带拉断痕迹。
**间隙过小**：断面出现**二次光亮带**（双重光亮带）——毛刺尖而薄、刃口磨损加剧。
**间隙不均**：一侧光亮带、一侧断裂带，毛刺忽大忽小——间隙「一边大一边小」，装配时没调匀（呼应装配篇的间隙均匀性）。<span class="marginnote">「毛刺方向指向间隙大的一侧」，是冲压诊断里最实用的「<strong>判向</strong>」技巧：不用拆模，看毛刺方向就知道哪边间隙大——这像「<strong>从错误信息定位代码行</strong>」：症状自带定位信息，就看你会不会读。</span>

**修整对策**：间隙过大——补焊/更换凹模或凸模、重新配间隙；间隙过小——研大间隙（修磨刃口侧面）；间隙不均——重新调整间隙（垫片法/透光法复查）。

## 3 尺寸超差与变形缺陷

尺寸超差与变形，是冲压件质量的另一大类问题：

**尺寸超差（偏大/偏小）**：冲压件尺寸不在公差内——原因可能是**刃口尺寸磨损**（越冲越大/小）、**回弹**（弯曲件角度回弹，尺寸偏差）、**定位不准**（送料步距、定位件磨损）。修整：**磨损→刃磨/换刃口**，回弹→修正模具角度或加整形工序（呼应弯曲篇的回弹补偿），定位→修/换定位件。

**翘曲与扭曲**：平面件冲出后不平——原因可能是**材料内应力**（轧制方向、残余应力）、**冲裁力不对称**、**卸料不畅**。修整：调整模具让受力对称、改善卸料压料、材料换方向/整平。

**弯曲件回弹偏大**：弯曲角度达不到图纸——**高强钢、薄板回弹大**（呼应弯曲篇的回弹公式 $\Delta\alpha \approx 3\sigma_s r/(Et)$）。修整：**模具角度过弯补偿**（做小回弹角）、矫正弯曲、拉弯——回弹靠「模具先过做、制品回弹到位」。

**拉深件起皱与拉裂**：凸缘起皱（压边力不足）、底部拉裂（拉深系数过小、圆角过小）——修整：**调压边力、加大圆角、多次拉深**（呼应拉深篇的起皱与拉裂）。<span class="marginnote">冲压变形的「<strong>回弹、起皱、拉裂、翘曲</strong>」各有各的物理根源：回弹是弹性恢复、起皱是受压失稳、拉裂是受拉超限、翘曲是应力不均——<strong>根因不同，修法各异</strong>。这像「不同类型 bug 要不同的修法」——定位到根因，才能对症下药。</span>

## 4 核心对比表：冲压件常见缺陷-原因-对策

纯概念主题，用一张**核心对比表**把常见缺陷集中收束：

| 缺陷 | 主要表现 | 常见原因 | 修整对策 |
| --- | --- | --- | --- |
| 毛刺大 | 断面边缘尖刺 | 间隙不当/刃口磨损 | 调间隙、刃磨刃口 |
| 二次光亮带 | 断面双重光亮 | 间隙过小 | 研大间隙 |
| 断面粗糙 | 断裂带过大 | 间隙过大 | 补焊/配间隙 |
| 尺寸超差 | 偏大/偏小 | 刃口磨损/回弹/定位 | 刃磨、补偿、修定位 |
| 弯曲回弹 | 角度不达标 | 弹性恢复 | 过弯补偿、矫正弯曲 |
| 凸缘起皱 | 凸缘波纹 | 压边力不足 | 加大压边力 |
| 底部拉裂 | 圆角处裂纹 | 系数小/圆角小 | 多次拉深、加大圆角 |
| 翘曲扭曲 | 平面不平 | 内应力/受力不均 | 整平、受力对称 |

**读表要领**：每个缺陷的「对策」都指向「模具修整」或「工艺调整」——**先判归属、再选对策**，是这张表的使用方法。

## 5 模具修整的常用手段

修整冲压模，用到的钳工手段与第3篇加工技能环环相扣：

**刃磨（磨刃口）**：凸凹模刃口磨钝后，在平面磨床/工具磨床上磨刃口平面恢复锋利——直筒刃口磨刃口平面即可（呼应冲裁模篇的直筒刃口）。刃磨量要小、每次磨去最少，磨后重新配间隙。
**补焊修磨**：间隙过大、刃口局部崩损——用**堆焊**（补焊刃口）恢复尺寸，再修磨成形。补焊要预热、控制变形，焊后精修。<span class="marginnote">补焊修刃口，是「<strong>缺什么补什么、再精修成形</strong>」的修复逻辑：磨损掉的材料用堆焊「长」回来，再按图纸修磨到尺寸。这像「热修复 + 重新验证」——补丁打上，还得回归测试。</span>
**修配研配**：间隙不均、配合不良——钳工锉削、研配修整配合面（呼应钳工修配篇的染色修配）。
**换件**：磨损严重、结构损坏——**直接更换易损零件**（凸模、定位件、卸料板弹簧），比反复修更经济——模具的易损件常做成镶件/标准件，坏了就换（呼应失效修复篇）。

**修整的精度要求**：修整后要**恢复原设计精度**——间隙、刃口尺寸、导向精度都要复核，不是「修到能冲就行」。

## 6 修模的流程与验证

修模不是「拆开修完装上就完」，要按流程走、用试冲验证：

**修模流程**：**停机隔离**（模具从设备上拆下、挂维修牌）→ **诊断定位**（分析缺陷根因）→ **拆解修整**（修刃口/调间隙/换件）→ **装配复位**（重新装配）→ **试冲验证**（上机试冲、首件检验）。<span class="marginnote">修模「<strong>停机隔离 → 诊断 → 修整 → 装配 → 试冲验证</strong>」的流程，是「<strong>受控变更</strong>」的工程实践：修模是有风险的操作（修错更糟），所以每个环节有章法、最后有验证。这像「<strong>变更管理 + 回归测试</strong>」——改动要记录、要验证，不能黑箱操作。</span>
**修模记录**：修了什么、为什么修、修后效果——记录让经验沉淀、让下次诊断更快。
**验证标准**：修模后试冲，冲压件尺寸、断面、毛刺合格——**验证合格，修模才算完成**。

**易错点｜修一处坏两处**：修模只盯着目标缺陷，修完不检查周边——间隙调了，导向没查；刃口磨了，卸料没试——修完必须**全项复核**：间隙、导向、卸料、推件一起查，防止「修一处坏两处」。

**修模的诊断记录与经验积累**：模具工的「诊断力」靠**记录与复盘**沉淀：

**建立缺陷记录**：每次修模记录「缺陷 → 症状 → 诊断 → 对策 → 效果」——**同样的缺陷第二次出现，翻记录就能秒判**。模具厂的「修模记录本」就是模具工的「经验库」。
**统计分析缺陷**：统计一段时间内的高发缺陷（如「毛刺大」占了六成），倒查根因（间隙标准、刃口材料）——**从「修个案」到「治规律」**，是技师级的升级。

**易错点｜「凭感觉诊断」**：不看记录、不查数据，凭「以前这么修」的经验直接动手——经验有价值，但**经验 + 记录 + 数据才是可靠的诊断**。修模是「技术活」，不是「感觉活」。

**冲压缺陷的预防性思维**：与注塑模的「从修到防」一样，冲压缺陷也可以在设计/制造阶段提前防：

**间隙与材料匹配**：设计阶段按材料与板厚查标准间隙，制造阶段装配到位——**间隙的「一次做对」胜过「多次修对」**。
**刃口材料与表面处理**：刃口用耐磨材料 + 表面处理（TiN 涂层），磨损周期延长、毛刺出现得晚。
**修模频率统计**：统计一副模具的修模间隔——修得太勤说明「设计或材料」有系统问题，要倒查根因，而不是反复修同一个点。<span class="marginnote">「修得太勤就倒查根因」，是「<strong>从治标到治本</strong>」的工程思维：同一点反复修，说明修的是「症状」不是「病因」。这像「<strong>同一 bug 反复出现，就要怀疑是不是架构问题</strong>」——频率本身就是诊断信号。</span>

**常用修模工具清单**：修模钳工的「手术包」要备齐——**锉刀、刮刀**（修配研配）、**油石**（刃口修光）、**砂轮机**（刃磨钻头与小型刃口）、**塞尺**（测间隙）、**红丹粉**（研配检查）、**堆焊设备**（补焊修复）、**百分表**（复查精度）。工具与量具呼应量具篇与钳工篇——**修模的每一刀，都要用工具与量具把关**。

## 7 小结

- 冲压缺陷诊断四步：**看症状 → 找归属（模具/工艺）→ 对病因 → 下对策**；难点在「一症多因」。
- **毛刺方向**是间隙的「镜子」：毛刺偏向哪侧，哪侧间隙偏大；断面四带读出间隙大小。
- 尺寸超差三因：**刃口磨损、回弹、定位不准**；变形四类：回弹、起皱、拉裂、翘曲——各对根因下药。
- 修模手段：**刃磨、补焊修磨、修配研配、换件**——修后恢复原设计精度。
- 修模流程：**停机隔离 → 诊断 → 修整 → 装配 → 试冲验证**；修一处、全项复核。
- 修模手段：**刃磨、补焊修磨、修配研配、换件**——修后恢复原设计精度。
- 修模记录是经验库：**缺陷 → 症状 → 诊断 → 对策 → 效果**逐条记录，第二次遇到翻记录秒判。
- 修得太勤就倒查根因：**频率是诊断信号**——从「治标」走向「治本」。
- 常用修模工具：**锉刀、刮刀、油石、砂轮机、塞尺、红丹粉、堆焊设备**——手术包备齐，修模才顺手。
