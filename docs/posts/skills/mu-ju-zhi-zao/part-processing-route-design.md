## 为什么从工艺路线开始

前几篇认识了模具的材料、结构与成型系统，这一篇回答一个「串起来」的问题：一块毛坯钢，先干什么、后干什么，才能变成一件合格的凸模或型腔？这个「先干什么、后干什么」的安排，就是**工艺路线**。<span class="marginnote">工艺路线之于零件加工，相当于「流水线编排」之于软件交付：先格式化、再写代码、再测试、再部署——顺序错了或漏了环节，成品就有隐患。模具零件工艺路线的核心矛盾是：<strong>热处理会变形，变形要磨削修正，而磨削只能去掉少量余量</strong>——所以工序顺序由「热处理在中间、精加工在最后」这条铁律主导。</span>看懂工艺路线，你才知道为什么模具零件的加工不能「一步到位」，而要一环扣一环。

## 1 工艺路线：加工的「作战地图」

**工艺过程**：直接改变原材料形状、尺寸、性能，使其成为成品的过程。一个工艺过程由若干**工序**组成，工序是「一个工人在一台设备上连续完成的那部分加工」——工序的先后安排就是**工艺路线（process routing）**。

一张完整的工艺路线要交代清楚每道工序的**设备、内容、尺寸要求、装夹方式与检测方法**。模具工能读懂并执行工艺路线卡，是上岗的基本功。

**工艺规程**：把工艺路线写成文件（工艺卡片），作为车间生产的依据。模具零件的工艺规程通常包含：工序号、工序内容、设备、工装夹具、加工余量、检验要求。

模具制造是**单件小批量**生产（一副模具的零件基本不重复），所以工艺路线的设计原则与大批量生产不同：**不追求专机专线，追求「通用设备 + 合理顺序 + 精密工艺」**——模具工靠通用机床和手工修配，做出比大批量产品更高的精度。<span class="marginnote">模具是「用通用设备造高精度单件」的极端案例：同样的 0.005 mm 精度，大批量生产靠机床本身的精度保证，模具则要「机床 + 修配 + 研磨」三管齐下。这就像小批量模型用「微调 + 人工修正」达到精品效果，而不是靠大规模预训练。</span>

## 2 典型工艺路线：一块钢的变身之旅

模具零件的典型工艺路线可以概括为七个阶段，每个阶段解决一个矛盾：

**下料**：从钢棒/钢板上切出毛坯尺寸（留足后续余量），常用锯床、带锯。下料要按最终零件尺寸**放大余量**——锻造与加工都要吃掉材料。

**锻造（可选）**：Cr12MoV 等模具钢毛坯常先锻造，目的有二：**打碎铸态组织、改善碳化物分布**，让材料更致密均匀；同时锻出大致形状。锻造后需退火。

**退火/预备热处理**：降低硬度便于切削，消除锻造内应力。此时钢处于「软态」，加工性好。

**粗加工**：铣、车、钻，快速去除大部分余量，把零件加工到接近最终形状，留下 1–2 mm 余量。粗加工的目标是「快」——大刀量、大进给，不追求精度。<span class="marginnote">粗加工与精加工的分工是「快粗慢精」：粗加工负责去量大头（成本低），精加工负责保精度（成本高）。把大量材料在粗加工里去掉，是因为粗加工的单位成本远低于精加工——这对应「粗筛 + 精排」的两段式算法设计。</span>

**热处理（淬火+回火）**：把零件淬硬到工作硬度。**这是工艺路线的分水岭**——淬火后零件变硬，切削加工几乎做不动了，只能靠磨削与电加工。

**精加工（磨削/电火花/线切割）**：淬火后的精加工。磨削去除淬火变形与氧化皮，保证尺寸与表面质量；型腔、异形孔用线切割/电火花加工。余量从粗加工的 1–2 mm 降到精加工的 0.01–0.03 mm。<span class="marginnote">为什么精加工非要在热处理之后？因为淬火要变形——变形量可达 0.05–0.3 mm，若先精加工再淬火，精加工精度全被变形毁掉。所以规律是「热处理前留余量粗加工、热处理后磨削精加工」，把变形量让给磨削去吃掉。</span>

**精修与检测**：研磨、抛光、修配达到最终精度，用量具/三坐标检测。

## 3 公式解析：加工余量的分配

**加工余量**：为完成零件的加工而预留的、需要被切除的金属层厚度。总加工余量 = 各工序余量之和，按下式控制：

$$
Z_{\text{总}} = \sum_{i=1}^{n} Z_i = Z_{\text{粗}} + Z_{\text{半精}} + Z_{\text{精}} + Z_{\text{研}}
$$

- $Z_{\text{总}}$：毛坯到成品的总余量（mm）
- $Z_{\text{粗}}$：粗加工切除余量（占大头，1–2 mm 级）
- $Z_{\text{半精}}$：半精加工余量（0.3–0.8 mm）
- $Z_{\text{精}}$：精加工（磨削）余量（0.05–0.15 mm）
- $Z_{\text{研}}$：研磨抛光余量（0.005–0.02 mm）

**三步拆解**：

**第一步，看各工序的能力**：每道工序都有「加工精度极限」——铣削 IT9–IT11、磨削 IT5–IT7、研磨 IT4–IT5。上一道工序的误差要由下一道工序「吃」掉，所以每道工序余量 ≥ 上一道工序的误差。
**第二步，看热处理的位置**：淬火前的余量要**足够大**——淬火变形量（0.05–0.3 mm）必须被磨削余量覆盖，否则磨不到尺寸、零件报废。
**第三步，定总余量**：毛坯尺寸 = 成品尺寸 + 总余量。**余量不是越大越好**——余量过大会浪费材料、增加工时，还会让表面产生过深的加工硬化层；余量过小则上一道工序的误差「吃不完」。<span class="marginnote">余量分配的三级结构（粗 1–2 mm、精 0.05–0.15 mm、研 0.005–0.02 mm）是数量级递减的：每道工序只负责「修正上一级留下的误差，再留下一级能吃的余量」。这很像损失函数的多尺度优化——先大尺度收敛、再小尺度精修。</span>

**易错点｜精加工余量与淬火变形脱钩**：只想着「磨削余量按 IT 精度留 0.1 mm」，却忘了淬火变形可能到 0.3 mm——磨削余量没盖住变形量，磨到最后还有黑皮/尺寸不到位，零件报废。**模具精加工余量要先算淬火变形，再叠加磨削需求**，不是套通用加工余量表。

## 4 基准选择：工艺路线的「坐标原点」

**基准（datum）**：确定零件上其他点、线、面的位置所依据的点、线、面。模具零件的基准选择直接影响精度能否保证，两条原则：

**基准先行原则**：先加工基准面（作为后续所有工序的定位基准），再加工其它面。凸模的工艺路线通常是「先磨出基准端面与基准外圆，再以此为基准加工其它部分」。

**基准统一原则**：尽可能用**同一组基准**加工各表面，避免基准切换带来的定位误差。<span class="marginnote">基准统一的本质是「减少坐标转换次数」：每次换基准都引入一次定位误差，基准换得越多、累积误差越大。这与「避免频繁的单位/坐标系转换」同构——统一基准就是统一坐标系，误差最小。</span>

模具零件的关键基准：凸模的轴线与端面、凹模的刃口面与底平面、模板的安装大平面。装配时以这些基准找正，保证凸凹模对中。

## 5 模具零件工艺路线的典型实例

以一副冲裁模的凸模为例，典型工艺路线：

**下料 → 锻造 → 退火 → 粗车外圆与端面（留余量）→ 铣/钻固定台阶 → 淬火+回火 → 磨外圆与端面（精加工）→ 线切割/磨刃口成形 → 研磨刃口 → 检测**。

以注塑模型腔（型腔板）为例：

**下料 → 粗铣外形 → 铣/电火花粗加工型腔 → 半精加工 → 热处理（或 P20 预硬钢免淬火）→ 精铣/电火花精加工 → 研磨抛光型腔 → 检测**。<span class="marginnote">注塑模用预硬钢 P20 时，热处理环节「整段取消」——材料出厂已硬化，加工完直接用。工艺路线的设计自由度来自材料选择：选了预硬钢，路线就短一截、精度风险小一截。</span>

**工艺路线设计的取舍本质**：每加一道工序，精度更高但成本更高、周期更长。设计工艺路线的最高原则是——**在满足图纸要求的前提下，工序越少越好**。这与软件架构「在满足需求的前提下，系统越简单越好」是同一个工程美学。

## 6 工艺文件的种类与工艺纪律

工艺路线要写成**工艺文件**才能在车间落地，模具工必须会读会用。

**工艺文件的种类**：

**工艺过程卡（工艺路线卡）**：列出零件加工的全部工序及顺序、设备——是工艺路线的总纲。
**工序卡**：详细描述某一道工序的操作——装夹方式、切削用量、检验要求。
**检验卡**：规定各工序的检验项目与量具——尺寸、形位公差、表面粗糙度。
- **模具总装图与零件图**：工艺的依据——先有图、后有工艺、再加工。

**工艺纪律**：车间执行的纪律，保证工艺文件被严格执行：

- **按工艺加工**：按工艺卡规定的设备、工序、参数加工，不擅自改序、改参数。
- **工序自检**：每道工序加工后自检（按检验卡），不合格不流入下道工序。
- **首件必检**：每道工序首件必须检验合格后再继续（呼应第21篇的首件检验）。
- **异常报告**：发现工艺问题（图纸错误、工艺不合理）及时报告，不私自处理。<span class="marginnote">工艺纪律的「按工艺加工、不擅自改序」，是「流程即质量」的体现：模具是精密单件，一道工序改了序，后面全部连锁反应。这与「变更要走评审流程」同理——不是限制人，是防止「一个人改了、没人知道」的连锁事故。</span>

**工艺优化的思路**：工艺文件不是一成不变——**工艺优化**是技师级的能力：分析瓶颈工序、改进装夹、调整余量分配、引入新工艺（如高速铣替代电火花粗加工），让工艺更短、更稳、更省。**先严格按工艺执行，再基于数据优化工艺**——这是从「执行者」到「工艺师」的跃迁。

**易错点｜把「经验」当「工艺」**：老师傅凭经验加工、不写工艺文件——经验靠人传、离开人就断档。**成熟的经验要固化成工艺文件**——工艺文件是「把个人经验变成组织资产」，模具厂的工艺库就是它的「知识库」。

## 7 小结

- **工艺路线**是工序的先后安排；模具制造是**单件小批量**，靠通用设备 + 合理顺序 + 修配保精度。
- 典型七步：**下料 → 锻造 → 退火 → 粗加工 → 热处理 → 精加工（磨/电加工）→ 精修检测**。
- **热处理是分水岭**：淬火后只能磨削与电加工，淬火变形量必须被磨削余量覆盖。
- 加工余量 $Z_{\text{总}} = Z_{\text{粗}} + Z_{\text{半精}} + Z_{\text{精}} + Z_{\text{研}}$；**精加工余量要先算淬火变形再叠加磨削需求**。
- 基准选择守「**基准先行、基准统一**」两原则；工艺文件（工艺过程卡、工序卡、检验卡）是落地的依据。
