# 家政服务与家庭清洁收纳

以《家政服务员国家职业技能标准》为纲，结合家政服务员职业培训包与《家政服务业经营服务规范》，系统覆盖从职业道德、清洁保洁、收纳整理到洗涤熨烫、家居保养与客户服务的完整家政服务技能体系。家政服务是千万级就业职业，也是每个家庭日常生活的刚需能力，学完这些章节，就写完了从入门清洁到专业收纳、家居保养所需的全部内容。
