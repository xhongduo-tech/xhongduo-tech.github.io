## 为什么均衡是音色的「雕刻刀」

音量声像解决「在哪、多响」，均衡（EQ, equalization）解决「什么音色、冲不冲突」。同一段人声，EQ 不同，听起来可以是「闷」的、可以是「亮」的、可以是「有力」的——因为声音由不同频率的能量组合而成，**EQ 就是逐频段调节这份能量分布**。<span class="marginnote">EQ 是后期里使用率最高也最容易「用过头」的工具。它的双面性在于：小幅调整就能改变听感，大幅调整就会破坏音色、引入相位问题。专业混音的黄金习惯是「能用减法解决的不用加法」——先削掉浑浊的频段，而不是一味提升好听的频段。这一讲就把「削什么、加什么」讲清楚。</span>

## 1 频率的听感地图：人声全谱

把可听范围（约 20 Hz–20 kHz）按听感划分，人声主要分布在 80 Hz–10 kHz：

| 频段 | 听感特征 | 人声里的角色 |
| --- | --- | --- |
| 80–150 Hz | 低频「厚」「嗡」 | 胸腔共鸣、低频基频 |
| 200–400 Hz | 「闷」「糊」「浑浊」 | 口鼻耦合区，过多则发闷 |
| 500–1000 Hz | 「鼻音」「喇叭味」 | 元音主体，中低频力度 |
| 1–3 kHz | 「响」「清晰」 | 语音清晰度的核心区 |
| 3–5 kHz | 「明亮」「往前」 | 齿音前奏、存在感（presence） |
| 5–8 kHz | 「齿音」「咝」 | 辅音摩擦（sibilance） |
| 8 kHz+ | 「空气感」「透」 | 泛音尾气、空间感 |

这条谱对人声 EQ 的意义：**清晰度在 1–5 kHz，浑浊在 200–400 Hz，齿音在 5–8 kHz**——几乎所有人声 EQ 动作都能在这张表上找到落点。

## 2 四种滤波器类型

EQ 的每个频段点都是一种滤波器，播客常用四种：

**高通（High-pass, HPF）**：切掉某频率以下的能量。人声轨上几乎必挂：**把 80–100 Hz 以下的低频噪声、椅子摩擦、喷麦余波切掉**，人声立刻「干净」。
**低通（Low-pass, LPF）**：切掉某频率以上。用于削极高频噪声，人声上用得少。
**钟形（Bell / Peaking）**：在中心频率附近形成一个「鼓包」，可提升或衰减。用于「削浑浊」「加存在感」等定点调整，是 EQ 的主力。
**搁架（Shelf）**：从某频率开始整段提升或衰减（高频搁架/低频搁架）。用于「整体加一点空气感」或「整体去掉一点闷感」。<span class="marginnote">高通是播客 EQ 的第一动作，但注意别切太高：把高通切到 150 Hz 以上，男声的胸腔共鸣会被「腰斩」，声音立刻单薄。一般从 80 Hz 起步试听，往上微调，找到「浑浊消失但厚度还在」的那个点——这个「找点」的听力，是 EQ 操作的核心手感。</span>

## 3 公式解析：Q 值与带宽

每个钟形滤波的「宽窄」由 **Q 值（品质因数）**决定：Q 越高，影响的频带越窄。Q 与带宽的关系是：

$$
Q = \frac{f_0}{BW}, \qquad BW = f_2 - f_1
$$

其中 $f_0$ 是中心频率，$BW$ 是滤波器两侧衰减 3 dB 处的频率差（即带宽），$f_1$、$f_2$ 是这上下两个边界频率。做三步拆解：

- **第一步，认符号**：$f_0$ 是你要动的那一频点（比如削浑浊就选 250 Hz）；$BW$ 是这个 EQ 实际影响的频率宽度。
- **第二步，看关系**：$Q = f_0 / BW$，Q 越大、带宽越窄——**Q 高 = 手术刀（只动一个频点），Q 低 = 大扫帚（动一片）**。
- **第三步，代一个例子**：削 250 Hz 的浑浊，若把 $Q$ 设为 1，则 $BW = 250\ \text{Hz}$，从约 125 Hz 到 375 Hz 都在受影响范围内；若 $Q$ 设为 4，则 $BW \approx 62\ \text{Hz}$，只动 250 Hz 附近极窄一带。<span class="marginnote">给一个经验值：削浑浊用 Q ≈ 1–2（稍宽一点，连「闷感」周边一起削），加存在感用 Q ≈ 0.7–1（宽一点、更自然的亮度），而「精确拔掉某个刺耳频率」才用 Q ≥ 4（窄到不伤邻居）。Q 值越大越要小心，窄带大提升是失真与相位问题的温床。</span>

## 4 人声的常见 EQ 操作

把谱表和 Q 值落到实际操作，一套经典的人声 EQ 流程：

**高通 80–100 Hz**：Q 取陡斜率，切掉低频杂物。人声轨的第一动作。
**削 200–400 Hz**：若人声「闷」「糊」，在 250–350 Hz 用 Q≈1.5 衰减 2–4 dB。削完立刻「清」一层。
**加 3–5 kHz**：若人声「退后」「不清晰」，在 3–4 kHz 用 Q≈0.7 提升 1–3 dB，声音「往前走」。
**齿音处理**：若「咝」声刺耳，在 5–7 kHz 用 Q≈3–4 窄带衰减 2–3 dB（或交给下一讲的动态处理——去齿音器）。<span class="marginnote">EQ 操作的三条纪律：<strong>先听再动</strong>（不知道哪多了，就先别动）、<strong>小幅多次</strong>（每次 1–2 dB，来回对比，别一上来 6 dB）、<strong>加法克制</strong>（加 3 dB 听不出效果？那问题多半不在频率，而在音量或压缩）。音色的直觉判断力，来自「做一次、听一次、再撤回来听一次」的反复对比。</span>

辨析｜易错点：**EQ 不能替代音量。** 声音「听不清」时，第一反应不应该是加高频，而是先检查音量与声像。加 EQ 只是「换音色」，音量才是「给位置」。先问「响不响」，再问「亮不亮」——顺序错了，就会做出「又响又刺」的声音。

## 5 核心对比表：常见音色问题与 EQ 对策

| 听感问题 | 目标频段 | 典型动作 | 预期效果 |
| --- | --- | --- | --- |
| 闷、糊 | 200–400 Hz | 窄带衰减 2–4 dB | 声音「清」一层 |
| 单薄、没厚度 | 80–150 Hz | 轻微提升或高通点下移 | 胸腔感回归 |
| 退后、不清晰 | 3–4 kHz | 宽 Q 提升 1–3 dB | 声音「往前」 |
| 齿音刺耳 | 5–7 kHz | 窄带衰减 2–3 dB | 「咝」声收敛 |
| 声音发虚 | 无明显问题 | 检查混响与压缩，而非 EQ | 先别动手 |

把本讲出现的关键术语收拢成一张速查表，复习或查漏时直接对照：

| 术语 | 含义 |
| --- | --- |
| 均衡（EQ） | 逐频段调节能量分布 |
| 高通（HPF） | 切掉某频率以下，人声轨第一动作 |
| 钟形（Bell） | 中心频率附近定点提升/衰减 |
| 搁架（Shelf） | 从某频率开始整段提升/衰减 |

## 7 小结

- 人声全谱：**清晰度在 1–5 kHz、浑浊在 200–400 Hz、齿音在 5–8 kHz**。
- 四种滤波器：**高通（切低频）、低通、钟形（定点调）、搁架（整段调）**。
- Q 值公式 $Q = f_0/BW$：**Q 高 = 手术刀、Q 低 = 大扫帚**；削浑浊 Q≈1.5、加亮度 Q≈0.7、拔刺音 Q≥4。
- 经典流程：**高通 80–100 Hz → 削 200–400 Hz → 加 3–5 kHz → 窄带去齿音**。
- 三纪律：**先听再动、小幅多次、加法克制**；EQ 不替代音量。
