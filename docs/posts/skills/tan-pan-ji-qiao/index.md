# 谈判技巧与说服

谈判与说服是商务、职场与人际交往中的核心生存技能。以《谈判力》《影响力》与《哈佛谈判课》为纲，系统重建从原则谈判法、谈判准备与策略设计到说服心理学、实战场景与跨文化谈判的完整能力体系。学完这些章节，就写完了从建立双赢思维、精通说服原理到驾驭真实谈判场景所需的全部内容。

## 对标教材

- 《谈判力》（罗杰·费希尔 / 威廉·尤里）
- 《影响力》（罗伯特·西奥迪尼）
- 《哈佛谈判课》
