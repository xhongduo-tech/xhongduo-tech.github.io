# 插花与花艺设计

花艺是以植物花材为核心载体、融合造型、色彩与空间美学的系统化生活职业。以《插花花艺师国家职业技能标准》为纲，从花材处理、基础造型到东方式与西方式设计体系、商业应用，逐步建立完整的插花花艺师职业技能，可支撑国家职业技能等级考核与从业进阶。
