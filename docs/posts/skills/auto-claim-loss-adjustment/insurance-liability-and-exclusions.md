## 为什么先读免责条款

「保险责任」和「责任免除」是一枚硬币的两面：前者告诉我们**什么情况下保险公司赔**，后者告诉我们**什么情况下不赔**。绝大多数理赔纠纷，争的其实是免责条款的适用。<span class="marginnote">查勘定损人员的职业习惯与车主相反：<strong>先看责任免除，再看保险责任</strong>。因为「是否属于保险责任」多数时候一目了然，而「是否触发免责」才是需要证据判断的关键——酒驾检测、驾驶证状态、行驶证年检，都是免责核查的动作。</span>

2020 版《示范条款》对免责体系做了重要调整：取消事故责任免赔率（按责免赔）、扩大车损险责任、细化驾驶人资质要求。读懂这些变化，才能解释今天理赔实务里的很多「为什么」。

这里先立一个贯穿全篇的框架：**「属于保险责任」与「不触发免责」是赔付成立的两个前提**——事故既要在保险责任范围内，又不能落入责任免除情形，两者同时满足才赔。查勘定损的第一步，就是把这两个前提分别对号入座：先问「这算不算保险事故」，再问「有没有免责情形」。多数的拒赔争议，就发生在第二个问题的判断上。

## 1 保险责任：什么情况赔

**机动车损失保险的保险责任**：被保险机动车在被保险人或其允许的驾驶人使用过程中，因下列原因造成损失，保险人负责赔偿——**碰撞、倾覆、坠落；火灾、爆炸；外界物体坠落、倒塌；雷击、暴风、暴雨、洪水、龙卷风、冰雹、台风、暴雪等自然灾害；地震及其次生灾害；载运被保险机动车的渡船遭受自然灾害**。<span class="marginnote">2020 版把「地震及其次生灾害」首次纳入车损险，是顺应自然灾害频发的现实调整。过去「地震免责」让震后车辆无险可赔，如今这一缺口被补上。</span>

这里要重点理解「**使用过程中**」这个定语：保险责任限于车辆在行驶、停放、作业等使用场景下的损失。停在楼下被砸、行驶中追尾、修理厂里维修时受损——前两者属于使用过程，第三者在维修期间通常有专门的约定。

另一个关键词是「**被保险人或其允许的驾驶人**」：借给有证的朋友开，朋友出的事故，在「允许」范围内，车损险与三者险照赔；**未经允许擅自驾驶（盗开）造成的损失**，则不属于保险责任，甚至涉及刑事追责。驾驶人的「合法性 + 授权性」，是查勘定损核查的重点之一。

**机动车第三者责任保险的保险责任**：被保险人或其允许的驾驶人在使用被保险机动车过程中发生意外事故，致使**第三者遭受人身伤亡或财产直接损毁**，依法应当由被保险人承担的损害赔偿责任，保险人按合同约定赔偿。核心在「依法应当承担」五个字——保险赔的是**法律责任**，不是道德责任。<span class="marginnote">「依法应当承担」意味着：假如事故因不可抗力或第三者全责造成，被保险人无法律责任，三者险就不触发。责任险的赔偿以「被保险人负有法律赔偿责任」为前提，这是责任保险与财产损失保险的本质差异。</span>

这一界定带来两个实务推论：**一是三者险的赔付以「责任成立」为前提**，被保险人与第三者自行「私了」的金额，若没有法律责任依据，保险公司并不当然照赔；**二是赔偿范围以「依法应负」为限**，超出法定赔偿标准的「人情赔款」「精神安抚费」，同样不在保险责任内。

## 2 责任免除：什么情况不赔

免责条款是理赔争议的集中地。2020 版《示范条款》的免责情形可以归为五类：

**第一类，驾驶人主观恶意**：故意制造保险事故、酒驾、醉驾、吸食或注射毒品、服用国家管制的精神药品、无证驾驶、驾驶证被依法扣留/暂扣/吊销/注销期间驾驶、驾驶与准驾车型不符的车辆、交通肇事逃逸、故意犯罪行为。<span class="marginnote">这类免责不仅适用于商业险，交强险里同样存在——区别在于<strong>交强险对酒驾、无证情形并不当然拒赔全部项目：保险公司须在责任限额内垫付抢救费用，垫付后向致害人追偿</strong>。商业险则是直接不赔。这个「垫付后追偿」机制，第 4 篇会专门展开。</span>

**第二类，标的车辆异常状态**：被保险机动车被转让给他人但未办理批改、且危险程度显著增加的；发生保险事故时未按规定检验或检验不合格的。年检问题在改革后处理更精细化——长期不年检导致的风险，保险人可主张免责。

**辨析｜易错点：** 免责情形的「判断时点」要看清楚——多数免责以「发生保险事故时」的状态为准：酒驾是事故时的状态，无证是事故时的状态，年检也是事故时是否有效。投保时合法、事故时已违法（如驾驶证过期、行驶证脱检），同样落入免责。

**第三类，法定不可抗力与公权行为**：战争、军事冲突、恐怖活动、暴乱、污染、核反应、核辐射；被保险机动车被扣押、收缴、没收、征用期间的损失。

**第四类，磨损与固有缺陷**：自然磨损、朽蚀、腐蚀、故障、本身质量缺陷造成的损失——保险保的是「意外」，不保「老化」。

**第五类，特殊损失形态**：轮胎单独损坏、车轮单独损坏、车身划痕（无碰撞痕迹）等，2020 版从车损险主险中剔除，需附加险保障。<span class="marginnote">这里藏着新手最容易踩的坑：<strong>车损险保「玻璃单独破碎」和「自燃」，但不保「轮胎单独爆掉」和「无痕划痕」</strong>。想保全，就要加车轮单独损失险、车身划痕险等附加险——这与第 2 篇《机动车商业险险种与保障体系》讲过的附加险清单正好呼应。</span>

**辨析｜易错点：** 免责情形「列举 + 兜底」的结构要看清——条款明确列举的免责情形之外，还有「依照法律、行政法规或保险合同的约定，保险人不应承担赔偿责任的其他情形」这类兜底条款。所以免责判断不能只看列举，还要回到保险法理：**凡是违背「意外、突发、非本意」特征的损失，都可能落入免责**。

## 3 核心要点对比表：交强险与商业险免责的差异

本节为纯条款概念，用对比表替代公式解析，把最容易混淆的免责适用差异摆出来：

| 免责情形 | 交强险 | 商业三者险 / 车损险 |
| --- | --- | --- |
| 酒驾、醉驾 | 垫付抢救费后向致害人追偿 | 不赔 |
| 无证驾驶 | 垫付抢救费后向致害人追偿 | 不赔 |
| 故意制造事故 | 不赔，情节严重构成骗保 | 不赔 |
| 交通肇事逃逸 | 按条款处理（通常垫付后追偿） | 不赔 |
| 车辆未年检 | 可能影响三者险赔偿 | 可主张免责 |
| 自然磨损 / 故障 | 与责任险无关 | 不赔 |
| 轮胎 / 车轮单独损坏 | 与责任险无关 | 车损险不赔（附加险除外） |

这张表揭示了交强险的「**先行垫付 + 追偿**」机制：在酒驾、无证等情形下，交强险并不像商业险那样一拒了之，而是先保障受害人（垫付抢救费），再向致害人追回。**社会保护优先、追偿为手段**，是交强险与商业险免责逻辑的根本分水岭。

## 4 公式解析：三者险赔款中的责任比例

理解免责之后，还要理解「赔多少」。三者险赔款计算的核心公式：

$$
\text{三者险赔款} = \left( \text{损失总额} - \text{交强险赔偿} \right) \times \text{责任比例}
$$

对公式做三步拆解：

- **第一步，定损失总额**：把对方车辆损失、财产损失、人伤各项相加，得出本次事故对第三者造成的全部损失。
- **第二步，扣交强险已赔**：交强险在分项限额内先行赔付的部分先扣掉。交强险死亡伤残 18 万、医疗 1.8 万、财产 2 千的分项限额，是理算的第一道扣减。
- **第三步，乘责任比例**：我方全责取 100%，主责取 70%—80%，同责 50%，次责 20%—30%。例如对方总损失 50 万、交强险已赔 18 万、我方全责：$(50 - 18) \times 100\% = 32$ 万，在三者险保额内赔付。<span class="marginnote">这个公式是三者险理赔的主干：<strong>先交强、后商业、乘责任</strong>。它与第 10 节《事故责任认定与交管处理》、第 22 节《赔款理算与支付方式》里的公式一脉相承——理解免责之后，赔款计算才真正开始。</span>

## 5 免责条款的「提示说明」义务

免责条款能不能对投保人生效，法律设了一个程序门槛：《保险法》第 17 条规定，保险人对**免除保险人责任的条款**，订立合同时应当在投保单、保险单上**作出足以引起投保人注意的提示**，并**对该条款的内容以书面或者口头形式向投保人作出明确说明**——未作提示或明确说明的，该条款**不产生效力**。

这三层要求逐条拆开：

**提示义务**：免责条款要在单证上以显著方式（加粗、字体、颜色、单独列示）呈现，让投保人「看得见」。

**说明义务**：保险人要就免责条款的内容向投保人作出明确说明，让投保人「听得懂」。实务中常见做法是投保人声明栏签章——但「签过声明」不等于「履行了说明义务」，司法实践中对保险人的证明责任要求很高。

**不生效的后果**：未履行提示说明义务的免责条款对投保人不发生效力——保险人不能据此拒赔。这是投保人维权的重要武器，也是保险人合规的必修课。<span class="marginnote">「免责条款要提示说明才生效」是车险纠纷里最常被引用的规则之一：<strong>保险公司拿「酒驾免责」拒赔，若无法证明已明确提示说明，法院可能不支持免责</strong>。查勘定损员也要留意：理赔人员以免责拒赔时，先看保单与投保文件里有没有规范的提示说明记录。</span>

## 6 术语速查表

保险责任与免责环节的高频术语：

| 术语 | 含义 |
| --- | --- |
| 保险责任 | 保险人按约定承担赔偿责任的范围 |
| 责任免除 | 保险人不承担赔偿责任的情形 |
| 免赔率 | 按责任比例自担的比例（2020 版取消） |
| 提示义务 | 对免责条款作出显著提示 |
| 说明义务 | 就免责条款内容作出明确说明 |
| 保险法第17条 | 免责条款提示说明义务的法律依据 |
| 使用过程 | 行驶、停放、作业等车辆使用场景 |
| 第三者 | 本车人员与被保险人以外的对象 |

## 7 小结

- 保险责任与责任免除是「一枚硬币的两面」，查勘定损**先看免责、再看责任**。
- 车损险保「使用过程中」的碰撞、自然灾害等损失；三者险赔「依法应当承担」的赔偿责任。
- 免责情形分五类：**主观恶意、标的异常、不可抗力、磨损缺陷、特殊损失**。
- 交强险对酒驾无证等情形**垫付后追偿**，商业险直接拒赔——两者免责逻辑根本不同。
- 三者险赔款 $= (\text{损失总额} - \text{交强险赔偿}) \times \text{责任比例}$。
- 免责条款须**提示并说明**才生效，未履行的条款不产生效力。

在下一节，我们将把「赔不赔」落地为「赔多少」——这就是**绝对免赔额、保险金额与赔偿计算**。
