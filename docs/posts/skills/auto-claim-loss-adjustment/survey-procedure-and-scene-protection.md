## 为什么查勘员是理赔的「第一证人」

上一节我们讲了当事人该怎么做，这一节进入专业人员的主场：**查勘（survey）**。查勘员到场，是理赔证据链正式启动的起点。他的一双脚、一部手机、一份查勘记录，决定了后面定损、理算、核赔全部环节的证据基础。<span class="marginnote">查勘的核心任务可以概括为一句话：<strong>用最快速度、最规范的方式，把「事故是什么样」固定成可复用的证据</strong>。查勘记录写不清、照片拍不齐，后面每一个环节都会为此买单。</span>

这一节讲查勘的作业流程与现场保护：从接到任务到撤离现场，查勘员每一步该做什么、保护什么、记录什么。

## 1 查勘作业的前置准备

查勘不是到了现场才开始，而是从**接到报案**就开始了：

**核对案件信息**：报案号、事故时间地点、报案人联系方式、涉及车辆与人员、损失大致情况。先期判断案件类型——小额快处、常规车损、人伤、还是疑似欺诈。<span class="marginnote">查勘前的「案件预判」能显著提效：<strong>核对保单是否在保险期间、事故时间是否异常、报案时间与事故时间间隔是否合理</strong>——这些在出发前就能看出端倪。迟报案、深夜报案、次日才报的「延迟报案」，是欺诈核查的第一信号。</span>

**准备装备**：查勘单、记录本、测量工具（卷尺）、拍照设备、反光背心、三角警示牌、手套。野外或特殊场景（水淹、翻车）还要带相应防护。

**出发与联系**：联系当事人确认位置、告知预计到达时间，必要时提示当事人不要移动车辆、不要自行协商处理。这一步是「远程查勘」的前奏——许多小额案件在电话或视频里就能完成初步查勘。

## 2 到达现场：安全与保护先行

到达现场后的第一件事不是拍照，而是**安全布控**：

**安全布控**：开启警灯/双闪，按规定在来车方向设置三角警示牌，穿反光背心作业。高速公路上尤其要快——二次事故的风险远高于车辆本身损失。<span class="marginnote">「安全优先于查勘」是查勘作业的铁律：<strong>没有哪笔赔款值得用查勘员的命去换</strong>。规范的动作是：先控场，再问话，最后才围着车转。</span>

**现场保护确认**：确认当事人是否已移动车辆、是否破坏了痕迹。已移动的，询问并记录移动前的状态；未移动的，立即着手固定证据。

**了解事故经过**：分别询问双方驾驶人（如有），记录各自陈述的事故经过、时间、方向、速度、碰撞部位。询问要客观，不做倾向性引导，也要注意当事人陈述间的矛盾点——矛盾本身就是后续核查的线索。

## 3 查勘作业的完整流程

一次规范的现场查勘，走一条固定的流程：

**观察与定位**：先远观全局，判断现场类型（碰撞、刮擦、翻车、涉水、火烧）、车辆相对位置、道路环境，确定查勘重点。

**痕迹固定**：对地面痕迹（制动拖印、轮胎侧滑痕、散落物）、车辆痕迹（撞击点、变形方向、油漆转移）、环境痕迹（护栏、树木、路缘石损坏）逐项固定。痕迹怎么固定，第 9 节《现场拍照取证与痕迹固定》专门展开。<span class="marginnote">痕迹是查勘记录的核心资产：<strong>刹车痕长度、散落物分布、油漆颜色转移，都是还原碰撞过程的第一手物证</strong>。查勘员要养成「痕迹优先、车辆其次」的习惯——车辆可以被移动，地面痕迹稍纵即逝。</span>

**车辆查勘**：核对车牌、车型、VIN 码与保单是否一致；检查碰撞部位、损坏程度、新旧伤；记录仪表里程、油箱、轮胎状况；检查是否有改装。对怀疑碰撞前就存在的旧损，逐一标注。

**证人与其他证据**：询问目击证人、调取周边监控与行车记录仪（当事人车辆及社会车辆）、记录路况与天气。

**查勘记录**：按查勘单格式填写事故经过、损失部位、痕迹情况、当事人陈述，**拍照后及时上传归档**。查勘记录是理赔档案的核心文件，必须规范、完整、可读。

## 4 现场保护：查勘员的责任与技巧

现场保护不仅是当事人的义务，更是查勘员的专业动作：

**拍照先行**：任何移动动作之前，先完成全景与局部拍照。原则是「先取证、后移动」。

**标记位置**：确需移动车辆或物品的，先在地面用粉笔、标尺或参照物标记原始位置。

**保留物证**：散落物、碎片、液体泄漏等，在拍照与取样前不得清理。涉及人伤的，保护伤员位置与血迹分布。<span class="marginnote">有一个常被忽略的细节：<strong>事故散落物的分布范围，可以反推碰撞角度与速度</strong>——碎片散得越远越广，碰撞能量越大。查勘时别急着清扫，先让散落物「说话」。</span>

**防止二次破坏**：提醒当事人与围观者不要触碰车辆与痕迹，必要时拉设警戒范围。

## 5 核心要点对比表：现场查勘 vs 远程查勘

本节为作业方式概念，用对比表替代公式解析：

| 维度 | 现场查勘 | 远程/视频查勘 |
| --- | --- | --- |
| 适用 | 常规及复杂案件 | 小额、快处案件 |
| 证据质量 | 高（直面现场） | 中（依赖当事人配合） |
| 时效 | 取决于到达时间 | 快（即时连线） |
| 人力成本 | 高 | 低 |
| 防欺诈能力 | 强（现场感知） | 较弱（需交叉验证） |
| 留存 | 查勘单 + 照片 | 视频 + 截图 + 当事人声明 |

## 6 公式解析：查勘出勤的时效考核

查勘质量的重要指标是**到达时效**，行业里常用「报案—到达」时间考核。可用一条式表述查勘的时效压力：

$$
T_{\text{total}} = T_{\text{接案}} + T_{\text{出发}} + T_{\text{路程}} + T_{\text{作业}}
$$

其中 $T_{\text{total}}$ 为从报案到查勘完毕的总时长，$T_{\text{接案}}$ 为案件分配耗时，$T_{\text{出发}}$ 为准备出发耗时，$T_{\text{路程}}$ 为交通耗时，$T_{\text{作业}}$ 为现场作业耗时。三步拆解：

- **第一步，压缩 $T_{\text{接案}} + T_{\text{出发}}$**：这是查勘员自己能掌控的部分——快速判断案件类型、带齐装备、及时出发。行业对到达时效常有硬性考核（如市区 30—60 分钟内到达）。
- **第二步，压缩 $T_{\text{路程}}$**：依赖调度与路线规划。远程查勘的出现，正是为了把大量小额案件的 $T_{\text{路程}}$ 直接归零。
- **第三步，控制 $T_{\text{作业}}$**：作业时间不是越短越好——查勘完整度是质量底线。**省时间要省在流程上，不能省在证据上**。<span class="marginnote">时效与质量的平衡，是查勘员的第一课：<strong>到得快但查得糙，等于白跑；查得细但到得慢，可能现场已失</strong>。成熟的查勘员用「标准化清单」保证查勘质量，用「分级响应」控制时效。</span>

## 7 术语速查表

查勘环节的高频术语，是阅读查勘记录与理赔文书的基础：

| 术语 | 含义 |
| --- | --- |
| 查勘 | 到现场核实事故、固定证据的环节 |
| 查勘单 | 查勘员填写的现场记录单据 |
| 报案号 | 报案后系统生成的案件编号 |
| 远程查勘 | 通过电话/视频在线完成的查勘 |
| 现场复勘 | 对疑点案件再次到现场核实 |
| 痕迹固定 | 对事故痕迹的拍照、测量、记录 |
| 散落物 | 碰撞散落的碎片、零件等物证 |
| 二次事故 | 现场未控导致的新碰撞 |
| 行车记录仪 | 可调取行驶影像的车载设备 |
| 定损 | 核定损失项目与金额的环节 |

**辨析｜易错点：** 查勘与定损是**两个环节**——查勘解决「事故是不是真的、现场是什么样」，定损解决「修要多少钱」。查勘单不写定损金额，定损单不负责还原现场。两者顺序固定：**先查勘、后定损**，证据不清的定损站不住脚，这也是查勘质量直接决定定损质量的原因。

## 8 小结

- 查勘前置四件事：**核对案件、预判类型、备好装备、联系当事人**。
- 到现场**先安全布控、再保护现场、后开始查勘**。
- 查勘作业走固定流程：**观察定位、固定痕迹、查勘车辆、收集证据、填写记录**。
- 现场保护三原则：**拍照先行、标记再移、物证保留**。
- 远程查勘以时效换深度，现场查勘以深度换时效，两者互补。
- 查勘时效公式 $T_{\text{total}} = T_{\text{接案}} + T_{\text{出发}} + T_{\text{路程}} + T_{\text{作业}}$：省时间要省在流程上，不省在证据上。
