## 为什么现场的第一小时如此关键

理赔的第一现场，往往不是查勘员的，而是**当事人**的。从碰撞发生到查勘员到场之间的一小时，现场有没有保护、有没有报警、有没有留证，直接决定了后面责任怎么认定、损失怎么核定。<span class="marginnote">事故现场是「一次性的证据库」：<strong>车流一碾、当事人一挪车、一清扫，碰撞痕迹、散落物、刹车痕就消失了</strong>。查勘员再专业，也修不回一个被破坏的现场——所以现场处理的第一责任人，永远是当事人自己。</span>

这一节讲事故发生后当事人应当怎么做：停不停车、报不报警、动不动车、留不留证。它是查勘定损工作的「上游」，也是每个驾驶人应有的基本素养。

## 1 事故后的三个「第一」

碰撞发生后的瞬间，当事人应按顺序做三件事：

**第一，停车并开启危险报警闪光灯**：立即停车、熄火，打开双闪，在来车方向按规定距离设置三角警示牌（高速公路上通常为 150 米以外，一般道路 50—100 米）。**逃逸是民事责任加重、刑事责任与终身禁驾的入口，绝不能碰**。

**第二，抢救伤员并报警**：有人受伤的，第一时间拨打 120 急救，同时拨打 122（交通事故报警）、110 或保险公司报案电话。<span class="marginnote">报警电话别记错：<strong>122 是交通事故报警台、110 是公安报警、120 是急救、12122 是高速公路事故报警救援</strong>。人伤事故里「先救人是义务、先报警是程序」，两者并行不悖。</span>

**第三，保护现场**：在不妨碍救护的前提下，固定车辆与散落物位置。需要移动车辆的（救人、疏导交通），先拍照或标记原始位置再移动。

## 2 报警义务：何时必须报交警

并非所有事故都要等交警处理。是否报警，按损失与伤亡程度分档：

**必须报警的情形**：造成人员伤亡的；驾驶人无有效驾驶证的；机动车无号牌、无检验合格标志、无保险标志的；载运危险物品的；碰撞建筑物、公共设施或者其他设施的；驾驶人疑似酒驾、毒驾的；当事人对事实或成因有争议的。这些情形，交警会到场勘验、出具《道路交通事故认定书》。

**可以自行协商的情形**：仅造成轻微财产损失、且基本事实清楚的，当事人可**先撤离现场再协商处理**——这是《道路交通安全法》第 70 条确立的「快处快赔」制度。<span class="marginnote">「轻微事故快撤快处」的立法本意是<strong>避免小事故占用道路、造成二次事故</strong>。判断标准不是「车辆损坏程度」，而是「无伤亡、无涉牌涉证违法、基本事实清楚」——凡符合这三条的，原则上应当撤离。</span>

**辨析｜易错点：** 「轻微事故可以撤离」不等于「可以不报警、不报案」。撤离前要拍照留证，撤离后仍要向保险公司报案（通常 48 小时内）。只撤不报、只协商不报案，会直接损害后续理赔——证据没了、责任说不清，保险公司有权对无法核实部分不赔。

## 3 快处快赔：小额事故的高效路径

无人伤、无重大违法的小额事故，正确的处理姿势是「快处快赔」：

**第一步，现场拍照**：全景（含两车相对位置与道路环境）、碰撞部位特写、车辆号牌。照片是撤离后的第一证据。

**第二步，撤离现场**：将车辆移至不妨碍交通的地点（如路边、应急车道安全区）。

**第三步，协商或报警**：能协商一致的，填写自行协商记录或使用交管 App 的「快处快赔」流程在线定责；协商不成的，报警处理。

**第四步，向保险公司报案**：取得报案号，按保险公司的指引进行后续定损理赔。现在多数地区已实现「交管 12123 在线快处 + 保险一键理赔」的数据打通。<span class="marginnote">在线快处是近年事故处理的重大变化：<strong>当事人用手机 App 拍照上传，交管在线生成事故认定，保险公司同步接单理赔</strong>——「不跑交管、不跑保险公司」成为小额事故的新常态。查勘定损员大量接手的就是这类线上快处的案件。</span>

## 4 当事人需要固定的证据

即使交警或查勘员即将到场，当事人也应主动留存关键证据：

**时间证据**：事故发生的确切时间，行车记录仪时间戳是重要佐证。

**位置证据**：事故发生地点、车道、路口信号灯状态。拍照时把路牌、地标拍进画面。

**人员证据**：对方驾驶人信息（驾驶证、车牌）、联系方式，以及**双方是否存在酒驾、毒驾迹象**的即时观察记录。

**损失证据**：对方车辆的损坏部位、我方车辆的损坏部位，趁现场拍清「事故前已有旧伤」与「本次新伤」的区分。<span class="marginnote">「旧伤新伤」是定损里的高频争议：<strong>车身上既有本次碰撞的新痕，也有往日的旧痕、旧修痕迹</strong>。当事人在现场多拍几张特写，能把「哪些是本事故造成的」说清楚，避免定损时被认定为陈旧伤。</span>

## 5 核心要点对比表：报警 vs 自行协商

本节为流程概念，用对比表替代公式解析：

| 维度 | 报警处理 | 自行协商（快处） |
| --- | --- | --- |
| 适用 | 人伤、违法、争议 | 无人伤、无违法、无争议 |
| 交管动作 | 出警勘验、出具认定书 | 可线上定责、不出警 |
| 证据 | 交警勘验记录 | 当事人照片 + 协商记录 |
| 时间 | 较慢（按流程） | 快（当场解决） |
| 保险 | 报案后正常理赔 | 报案后按协商责任理赔 |
| 风险 | 程序合规 | 证据不足时理赔受阻 |

## 6 公式解析：报警必要性的判断

把「要不要报警」变成一道可判断的题，可以设一个简单规则：

$$
A = \left( \text{有人伤亡} \right) \lor \left( \text{涉牌涉证违法} \right) \lor \left( \text{事实争议} \right) \lor \left( \text{危险品/设施} \right)
$$

其中 $\lor$ 表示「或」——四个条件任一为真，$A = 1$，应当报警。三步拆解：

- **第一步，查伤亡**：有人受伤或死亡，$A = 1$。这是最高优先级，无论如何都要报警并先救人。
- **第二步，查违法**：无证、无牌、无年检、酒驾嫌疑、运危险品，$A = 1$。这类案件伴随行政处罚，自行协商没有法律效力。
- **第三步，查争议**：双方对成因或责任有分歧，$A = 1$。有争议靠自行协商解决不了，只能由交警定性。<span class="marginnote">这条规则查勘定损员也用得上：<strong>接手案件时先按「伤亡、违法、争议」三问扫一遍</strong>，就能判断案件是该走快处还是常规流程，也预判责任认定的复杂程度。</span>

## 7 术语速查表

现场处理环节的高频术语，是与交警、保险公司沟通的基础：

| 术语 | 含义 |
| --- | --- |
| 122 | 道路交通事故报警电话 |
| 12122 | 高速公路事故报警救援电话 |
| 快处快赔 | 轻微事故快速处理、快速理赔 |
| 道路交通事故认定书 | 交警出具的定责文件 |
| 自行协商 | 无争议轻微事故双方自行处理 |
| 三角警示牌 | 停车后防止二次事故的警示工具 |
| 行车记录仪 | 记录行驶影像的电子设备 |
| 二次事故 | 事故后未及时撤离导致的再次碰撞 |
| 肇事逃逸 | 发生事故后驾车或弃车逃离现场 |
| 保全 | 为固定证据对车辆采取的扣留/停放 |

**辨析｜易错点：** 「报警」与「报案」是两件事。**报警**是打给交警（122），解决责任认定；**报案**是打给保险公司，启动理赔。两者可以先后发生，但**理赔必须报案**——只报警不报案，保险公司可能因未及时报案而对无法核实部分不赔。

## 8 小结

- 事故后三个「第一」：**停车警示、抢救报警、保护现场**。
- 有人伤、涉违法、有争议的，**必须报警**；轻微事故可快处快赔。
- 快处快赔四步：**拍照、撤离、协商、报案**，缺一不可。
- 当事人应固定**时间、位置、人员、损失**四类证据，分清旧伤新伤。
- 报警必要性判断式：$A = \text{伤亡} \lor \text{违法} \lor \text{争议}$，任一为真即应报警。
- 现场是「一次性的证据库」，当事人是现场证据的第一保护人。
