# 汽车保险理赔与事故定损

车险理赔与事故定损是机动车拥有者绕不开的高频场景，也是保险公估、查勘定损等职业的核心技能。本专题以《机动车交通事故责任强制保险条例》《机动车商业保险示范条款》与《机动车辆保险查勘定损实务》为纲，系统覆盖从车险投保、现场查勘、损失定损、赔款理算到理赔争议处理与公估职业规范的完整闭环。

## 对标教材

- 国务院《机动车交通事故责任强制保险条例》
- 中国保险行业协会《机动车商业保险示范条款（2020版）》
- 《机动车辆保险查勘定损实务》
