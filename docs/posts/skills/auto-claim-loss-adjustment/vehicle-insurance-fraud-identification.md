## 为什么查勘员也是「侦探」

保险欺诈自古与保险相伴。车险赔付金额大、频率高、证据易造假，一直是欺诈的重灾区。<span class="marginnote">车险欺诈不是「个别坏人钻空子」的小问题：<strong>业内估计车险欺诈与渗漏占理赔支出的比例相当可观，这些成本最终都会摊进保费</strong>——查勘定损员既是理赔的执行者，也是防欺诈的第一道闸门。</span>

这一节讲车险欺诈的常见类型、识别信号与调查方法。它不是教人「怀疑一切」，而是教人**在正常与异常之间建立敏感度**——把「不对劲」的案子识别出来，交给专业调查。

## 1 车险欺诈的主要类型

车险欺诈按形态，可分为四类：

**故意制造事故（骗赔型）**：人为制造交通事故骗取赔款——低价值车辆故意碰撞、把事故车反复「碰」出赔偿、虚构单方事故骗车损。<span class="marginnote">故意制造事故的典型画像：<strong>事故刚买保险就出险、出险车辆多为老旧低值车、当事人对理赔流程异常熟悉</strong>。这类欺诈往往不是单打独斗，而是有「人伤黄牛」「汽修厂」等职业团伙参与。</span>

**夸大损失（渗漏型）**：真实事故但夸大损失——虚报维修项目、虚增工时、以旧件换新件、伪造发票抬价。这是最普遍、也最难界定的一类——它介于「合理索赔」与「骗保」之间，是定损核价环节要重点压缩的空间。

**虚构事故（谎报型）**：根本没有发生的事故——伪造事故现场、顶替真实受损车辆、把旧伤说成新伤、套用他人事故（骗保团伙之间互相对碰）。

**身份与单证欺诈**：伪造保单、伪造证件、冒用他人名义理赔、一车多保重复索赔。<span class="marginnote">「一车多保」是单证欺诈的典型：<strong>同一辆车在多家保险公司投保，同一事故向多家索赔</strong>。行业已建立车险信息共享平台，重复报案会触发系统预警——这也是为什么「买多份车损险就能多拿钱」在实务上根本不成立。</span>

还有一个隐蔽的变体值得警惕：**「二手事故」顶替**——车险欺诈团伙把已经碰撞过的旧伤车辆，在另一场事故里「再撞一次」，把旧伤损失并入新事故索赔，实现「一伤两赔」。这类手法对查勘员的痕迹分析能力要求极高：旧伤新痕的分辨，靠的就是碰撞形态与痕迹走向的专业判断（第 11 节）。

## 2 欺诈的识别信号：查勘端的「红旗」

查勘员不需要证明欺诈，只需要**发现异常**。以下信号是行业公认的「红旗」：

**时间异常**：刚投保即出险（尤其车损险投保后几天内）、深夜或节假日出险、报案时间距事故时间过长、出险时间与保险公司营业时间高度契合（配合内鬼）。

**地点异常**：事故地点偏远、监控稀少、同一地点多次出险。重复出险地点的数据，系统可以自动比对。

**对象异常**：老旧低值车高频出险、事故车恰是刚过户车辆、修理厂推荐指定查勘点。

**陈述异常**：当事人对事故经过记忆「过于清晰」或「完全说不清」、双方口径矛盾、拒绝提供行车记录仪、对细节过度回避。

**关系异常**：肇事双方是熟人、修理厂与车主联动、同一人反复出险。<span class="marginnote">查勘员要记住：<strong>单一信号不构成欺诈结论，但多个信号叠加，就值得上报反欺诈部门</strong>。成熟的做法是「信号计分」：把时间、地点、对象、陈述、关系五类信号各自打分，累计到阈值即触发调查。</span>

一个现实的提醒：**查勘员的「直觉」值钱，但必须落地成证据**。看到一个「不对劲」的案子，正确的动作不是当面质疑当事人（容易激化矛盾、也打草惊蛇），而是把疑点逐条写进查勘记录、附上对应的照片与问询内容——让「直觉」变成「可被复核的异常记录」。反欺诈体系的运转，依赖的就是这些一线记录。

## 3 调查与取证的方法

识别出疑点后，理赔人员要做的是**规范取证**，而不是当面质问当事人：

**现场复查**：回到事故现场复查——痕迹是否与陈述吻合、碰撞点是否对得上、是否有重建现场的迹象（如人为制造的散落物）。

**单证核验**：发票验真、维修清单与定损单比对、医疗票据核验（人伤案件）、行驶记录核查。

**信息交叉**：比对车辆历史出险记录、驾驶人记录、公安交管数据、修理厂关联数据。行业反欺诈系统会输出「关联图谱」，显示车辆、人员、修理厂之间的网络关系。<span class="marginnote">数据反欺诈是近年的大变化：<strong>保险公司建起「黑名单+关联图谱+异常模型」的风控体系</strong>，把单个人的经验判断，升级成系统化的信号网络。查勘员的价值在于给系统提供高质量的原始数据。</span>

**问询记录**：对当事人做规范问询，记录陈述矛盾点。问询不是逼供，而是「让陈述自然展开、记录前后差异」——陈述前后不一致，本身就是证据。

**留存轨迹**：调取车辆 GPS、ETC、通行记录、手机位置等客观数据，与当事人的陈述交叉核对。**「人证不如物证、陈述不如轨迹」**——在客观数据面前，精心编造的陈述常常不攻自破。

## 4 公式解析：欺诈嫌疑的量化评分

把「疑似欺诈」从感觉变成可量化判断，常用加权评分：

$$
S_{\text{fraud}} = \sum_{i} w_i \times x_i
$$

其中 $x_i$ 为第 $i$ 项异常信号（取 0 或 1），$w_i$ 为该项的权重，$S_{\text{fraud}}$ 为欺诈嫌疑总分。三步拆解：

- **第一步，列出信号项 $x_i$**：时间异常、地点异常、对象异常、陈述异常、关系异常，各取 0/1。
- **第二步，设定权重 $w_i$**：不同信号对欺诈的预测力不同——「刚投保即出险」「当事人回避记录仪」权重高，「出险地点偏远」权重低。权重由历史欺诈数据训练得出。
- **第三步，累计阈值判断**：$S_{\text{fraud}}$ 超过设定阈值（如 3 分）即触发人工调查，低于阈值继续正常流程。<span class="marginnote">这套思路在理赔系统里已产品化：<strong>反欺诈引擎对每笔赔案实时评分，高分案件自动转人工复核</strong>。定损员要理解的不是算法细节，而是「哪些输入变量是有效的」——把异常记录清楚、字段填准确，才能喂出有效的模型。</span>

## 5 反欺诈的边界与伦理

反欺诈必须守住几条边界：

**证据确凿才定性**：怀疑不等于定论。没有确凿证据不得武断拒赔，更不能冤枉正常客户——拒赔错了，保险公司要承担法律责任与声誉损失。

**辨析｜易错点：** 反欺诈最容易犯的错，是「疑罪从有」——凭几个红旗信号就拒赔。正确的姿势是「**疑罪上报、证据定案**」：发现疑点上报反欺诈部门，由专业调查收集证据；证据不足的，按正常案件赔付。宁可放走一个漏网之鱼，也不冤枉一个正常客户——这是反欺诈的铁律。

**程序正当**：调查要依规进行，不侵犯当事人合法权益。问询记录、证据采集、结果告知，都要留痕、规范。

**法律后果**：查实的欺诈案件，保险公司拒赔并移交司法机关——骗保金额较大可能构成**保险诈骗罪**，面临刑事处罚。<span class="marginnote">欺诈的代价远高于「拿不到赔款」：<strong>虚构保险事故、故意造成保险事故骗取保险金，达到数额标准即触犯刑法，可处有期徒刑并处罚金</strong>。防欺诈不仅是「省钱」，更是维护整个保险市场的公平秩序。</span>

## 6 术语速查表

反欺诈环节的高频术语，是风控体系与理赔文书的共同语言：

| 术语 | 含义 |
| --- | --- |
| 欺诈 | 以非法占有为目的骗取保险金的行为 |
| 渗漏 | 无主观恶意但虚增、虚报导致的赔付损耗 |
| 红旗信号 | 提示欺诈风险的异常特征 |
| 骗赔型欺诈 | 故意制造事故骗取赔款 |
| 渗漏型欺诈 | 真实事故中夸大损失 |
| 关联图谱 | 车辆/人员/修理厂的关联网络分析 |
| 黑名单 | 有欺诈记录的机构与人员名单 |
| 反欺诈引擎 | 自动识别欺诈嫌疑的系统 |
| 保险诈骗罪 | 骗取保险金数额较大的犯罪行为 |
| 风控模型 | 用历史数据训练出的欺诈识别算法 |

**辨析｜易错点：** 「欺诈」与「渗漏」程度不同。**欺诈**是主观故意的骗保，性质恶劣、触犯刑律；**渗漏**更多是「夸大一点」「多报一点」的灰色行为——它们都推高赔付，但处理方式不同：欺诈移交司法，渗漏靠核价与核赔压缩。定损员日常对抗的主要是渗漏，识别的重点是欺诈。

## 7 小结

- 车险欺诈四类：**故意制造事故、夸大损失、虚构事故、身份单证欺诈**。
- 五类红旗信号：**时间、地点、对象、陈述、关系异常**，多信号叠加才触发调查。
- 调查靠**规范取证**：现场复查、单证核验、信息交叉、规范问询。
- 欺诈评分 $S = \sum w_i x_i$：把「疑似」变成「可量化的嫌疑」。
- 反欺诈守边界：**证据确凿才定性、程序正当、移交司法**。
- 车险欺诈的成本最终摊进每一位诚实投保人的保费——查勘员是第一道闸门。
