## 为什么从行驶系统开始

行驶系统是汽车「站」在地上的部分：它承担全车重量、吸收路面冲击、保证车轮与路面的附着。由**车架、车桥、悬架、车轮与轮胎**四部分组成。

行驶系统直接决定三件事：**舒适性**（颠不颠）、**操控性**（稳不稳）、**安全性**（抓不抓得住）。悬架老化、减振器失效、轮胎偏磨、定位失准——这些问题不修，轻则坐着难受，重则高速失控。<span class="marginnote">行驶系统是「<strong>弹簧上的学问</strong>」：减振器管「跳不跳」，弹簧管「软不软」，定位管「直不直」——三者各司其职，一起决定车辆的「底盘质感」。</span>

## 1 行驶系统的构成

| 组成 | 部件 | 作用 |
| --- | --- | --- |
| 车架 | 承载式车身/梯形车架 | 承载全车载荷 |
| 车桥 | 转向桥、驱动桥 | 连接车轮与车身 |
| 悬架 | 弹簧、减振器、控制臂 | 传力并缓冲振动 |
| 车轮轮胎 | 轮毂、轮胎 | 支承与附着 |

现代轿车多为**承载式车身**（车身本身作为车架），独立悬架（每个车轮独立运动）成为主流。悬架按导向机构分**麦弗逊式**（前悬常用）与**多连杆式**（后悬/高级前悬常用）。<span class="marginnote">麦弗逊悬架把减振器兼作导向支柱，结构紧凑；多连杆用多根控制臂精确约束车轮运动——<strong>结构越复杂，车轮的运动轨迹越可控</strong>，操控与舒适越好平衡。</span>

## 2 悬架系统检修

**弹性元件**：螺旋弹簧、钢板弹簧、扭杆弹簧、空气弹簧。检查弹簧是否断裂、下沉、疲劳（车身高度下降）；空气弹簧还要查气囊泄漏与气泵。

**减振器（shock absorber）**：衰减弹簧的往复振动，把颠簸能量转化为热能。检查方法：

**按压法**：用力按压车身一角，松手后车身上下晃动 1–2 次即稳定为正常；晃动不止说明减振器失效。
**外观**：减振器筒体渗油说明油封失效，阻尼下降。
- **路试**：过减速带或坑洼时车身余振多、轮胎抓地感差，多为减振器老化。<span class="marginnote">「<strong>减振器不是弹簧</strong>」——弹簧负责支撑，减振器负责收尾。减振器坏了，车像船一样「晃悠」，高速变道发飘。</span>

**控制臂与衬套**：检查控制臂变形、球头松旷、橡胶衬套开裂。球头松旷会造成行驶异响、定位失准；衬套老化让车轮定位随载荷变化。举升后双手把车轮上下、左右晃动，感受球头与轴承间隙。

**稳定杆（防倾杆）**：连接左右悬架，抑制车身侧倾。检查稳定杆连杆（竖拉杆）球头磨损——松旷会在过减速带时发出「咯噔」声。

**空气悬架**：高端车型用空气弹簧代替螺旋弹簧，高度与刚度可调。检修重点是气囊裂纹泄漏（车身高低不平、气泵频繁工作）、高度传感器与气泵/电磁阀。空气弹簧漏气严重时车辆会趴下，需谨慎用千斤顶支撑——**悬架在无气压状态下的支撑点与正常不同**，作业前先查手册。

## 3 车轮与轮胎检修

**轮胎**是汽车唯一与地面接触的部件，检查四件事：

**花纹深度**：磨损到磨耗标记（花纹沟内的小凸台）即需更换；法定最小花纹深度约 1.6 mm。
**气压**：按手册规定值充气，冷态检查；气压不足费油偏磨、过高抓地下降。
- **异常磨损**：轮胎磨损形态是悬架与定位的「病历本」。
- **老化**：胎侧裂纹、鼓包（帘线断裂，爆胎前兆），鼓包轮胎必须立即更换。

**异常磨损的判读**：

| 磨损形态 | 原因 |
| --- | --- |
| 胎肩两侧磨损 | 气压长期不足 |
| 胎冠中部磨损 | 气压长期过高 |
| 单侧磨损 | 外倾角失准 |
| 羽毛状磨损 | 前束失准 |
| 锯齿状磨损 | 悬架松动、定位失准 |

**车轮动平衡**：轮胎与轮辋组装后质量分布不均，高速时会引起方向盘抖动。用平衡机检测，在轮辋对应位置贴平衡块。**轮胎拆装后或补胎后必须做动平衡**。<span class="marginnote">高速（约 80–120 km/h）方向盘抖，多半是动平衡问题；低速抖多为轮胎变形或轮辋失圆。<strong>「高速抖查平衡，低速抖查圆度」</strong>是定位抖动故障的口诀。</span>

**轮胎换位**：按手册周期（如 1 万公里）交叉换位，均衡磨损、延长寿命。换位后注意胎压监测（TPMS）的传感器位置——有些车型需要重新学习匹配。

## 4 车轮定位（四轮定位）

**车轮定位**：悬架系统各部件相对位置的角度参数，决定车轮与路面、车身的关系。主要参数：

**前束（Toe）**：从上方看，两前轮前端与后端的距离差。前束失准造成羽毛状磨损、方向发飘。
**外倾（Camber）**：从前方看，车轮顶部相对垂直线的倾斜角。外倾失准造成单侧磨损、跑偏。
- **主销后倾（Caster）**：从侧面看，主销轴线的倾斜角，影响方向盘回正。
- **主销内倾**：从前方看，主销向内倾斜，影响回正与转向轻便。

**四轮定位检测**：用定位仪测量各角度，与厂家标准值对比，通过调整悬架部件（偏心螺栓、垫片等）恢复。**碰撞维修、更换悬架部件、轮胎偏磨、跑偏后都应做四轮定位**。<span class="marginnote">定位参数是悬架的「<strong>出厂配置</strong>」：撞过、换过臂、换过减振器，配置就变了。定位不准的代价是偏磨轮胎+跑偏+方向回正差。</span>

## 5 公式解析：轮胎规格与直径

看懂轮胎规格是行驶系统的基本功。以 `205/55 R16` 为例：

$$
D = 2 \times (\text{断面宽} \times \text{扁平率}\%) + \text{轮辋直径}
$$

- **第一步，读规格**：`205` 是断面宽 205 mm，`55` 是扁平率 55%（胎侧高 = 断面宽 × 55%），`R` 是子午线轮胎，`16` 是轮辋直径 16 英寸。
- **第二步，算胎侧高**：胎侧高 $= 205 \times 0.55 = 112.75$ mm。
- **第三步，算直径**：轮辋直径换算为 $16 \times 25.4 = 406.4$ mm，轮胎总直径 $D = 2 \times 112.75 + 406.4 \approx 632$ mm。<span class="marginnote">换轮胎要保总直径一致：<strong>换大轮辋就配低扁平胎，总直径变了，车速表与 ABS 都会失真</strong>。DIY 换胎前先算直径。</span>

**辨析｜易错点：** 轮胎不是「越宽越好、越扁越帅」。扁平率低的轮胎路感强但舒适差、轮辋易受伤；宽度增加油耗上升。换胎以手册允许的规格为准，**左右轮胎必须同规格、同花纹、同品牌**——混装轮胎是安全大忌。

## 6 常见故障诊断

| 故障 | 典型原因 | 排查方向 |
| --- | --- | --- |
| 行驶跑偏 | 定位失准、胎压不均、制动拖滞 | 测胎压、四轮定位 |
| 方向盘抖动 | 动平衡、轮胎变形、轮辋失圆 | 平衡机、查轮胎 |
| 车身晃动 | 减振器失效、弹簧疲劳 | 按压法、查渗油 |
| 底盘异响 | 球头、衬套、稳定杆连杆松旷 | 举升晃动检查 |
| 轮胎偏磨 | 定位失准、气压不当 | 看磨损形态、定位 |

**减振器是否成对更换**：减振器、弹簧建议**左右成对更换**——只换一边会造成左右支撑与阻尼不均，行驶跑偏、晃动。

## 7 小结

- 行驶系统四部分：**车架、车桥、悬架、车轮轮胎**；承载式车身+独立悬架是轿车主流。
- 悬架检修：弹簧查下沉、减振器查渗油与阻尼、球头衬套查松旷、稳定杆查连杆。
- 空气悬架查气囊与高度传感器，无气压状态下支撑点与正常不同。
- 轮胎看**花纹、气压、磨损形态、老化鼓包**；动平衡解决高速抖动。
- 四轮定位四参数：**前束、外倾、主销后倾、主销内倾**；碰撞与换悬架件后必须定位。
- 轮胎直径 $D = 2\times\text{断面宽}\times\text{扁平率} + \text{轮辋直径}$
