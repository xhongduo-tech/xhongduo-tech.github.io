## 为什么从配气机构开始

发动机的呼吸由**配气机构**掌管：按曲轴转角的规定时刻开闭进排气门，让混合气进得来、废气出得去。门开早了、关晚了、关不严，发动机的动力、油耗、排放全都跟着垮。

配气机构的检修有两大任务：**修件**（气门、导管、弹簧、凸轮轴、正时机构的磨损与损坏）和**调间隙**（气门间隙的测量与调整）。这两件事都要求极高的精确性——气门开闭相差一个齿，正时全乱；气门间隙差 0.05 mm，发动机就响给你听。<span class="marginnote">配气机构是「毫厘定成败」的典型：<strong>正时差一齿、间隙差几丝</strong>，异响、无力、顶气门随之而来。拆装前先找准一缸上止点与正时记号，是铁律。</span>

## 1 配气机构的构成

**配气机构**按气门布置分**顶置气门（OHV）**与**顶置凸轮轴（OHC，分单顶置 SOHC 与双顶置 DOHC）**，现代轿车以 DOHC 为主。它由两大部分组成：

**气门组**：气门、气门座、气门导管、气门弹簧、气门锁片与油封——负责「开与关」的密封。

**传动组**：凸轮轴、挺柱（液压挺柱或机械挺柱）、推杆（OHV 才有）、摇臂、正时链条/皮带与张紧器——负责「按时开」的驱动。

工作链条：曲轴 → 正时机构 → 凸轮轴旋转 → 凸轮凸起顶动挺柱/摇臂 → 气门克服弹簧力开启；弹簧回弹使气门关闭。<span class="marginnote">正时链条/皮带把曲轴与凸轮轴「绑」成固定转速比：曲轴转两圈、凸轮轴转一圈。<strong>绑错一圈，进气门可能撞上活塞</strong>——这就是「顶气门」事故的根源。</span>

## 2 气门组的检修

**气门**检查三处：

**气门杆磨损**：用千分尺测杆部直径，磨损超限更换；气门杆与导管的间隙可用百分表测摆动量判断。
**气门头部**：检查烧蚀、裂纹、变形；气门工作面（与座圈贴合的面）烧蚀会漏气。
**气门密封性**：常用**渗漏法**——把气门装回座圈，气道内注煤油或做气压测试，观察是否渗漏。也可用染色检查接触带。

**气门座圈**磨损或烧蚀后，用**铰刀铰削**修复：先铰出正确的锥面角，再用气门与研磨砂**对研**，使接触带连续、均匀、位于工作面中部。铰削量要控制，避免气门下沉量过大（上一章已强调）。<span class="marginnote">对研是用气门「磨」座圈，磨到接触带发亮成环即可。<strong>研磨过度会造成气门头边缘变薄、下沉超限</strong>，所以「见好就收」。</span>

**气门弹簧**检查：测量自由长度与垂直度，弹簧座在平面台上检查端面是否歪斜；弹簧弹力下降会导致高速时气门漂浮（关闭不及时），引发功率下降与顶气门风险。弹簧拆装用专用压缩器，防止弹飞伤人。

**气门油封**是常被忽视却常坏的件：橡胶油封老化后机油沿气门杆渗入燃烧室，造成**冷车起动冒蓝烟**、火花塞积碳。更换气门油封是常见的免拆缸盖维修项目——用压缩空气顶住气门，拆弹簧即可更换。判断「烧机油是油封还是活塞环」的经典方法就是看烟色出现的时机：油封磨损多发生在冷车与减速后，活塞环磨损则匀速行驶时持续冒烟。

## 3 凸轮轴与正时机构检修

**凸轮轴**检查：

**凸轮磨损**：凸轮桃尖磨损造成升程减小、配气量下降；用千分尺测凸轮高度与手册对比。
**轴颈与轴承**：测轴颈圆度、圆柱度，检查轴瓦磨损。
**轴向间隙**：用百分表测凸轮轴轴向窜动量，超限换止推件。

**正时机构**检查：

**正时皮带**：检查齿面裂纹、磨损、缺齿，皮带**按里程/年限强制更换**（通常 6–10 万公里），断裂会顶气门。
**正时链条**：检查链条伸长（用专用工具测）、张紧器是否失效；链条伸长会造成配气相位滞后。
- **张紧器**：液压张紧器检查密封与油压，机械张紧器检查弹簧力。<span class="marginnote">正时皮带是「定时炸弹」式的部件：平时看不出问题，断了才知贵。<strong>到期就换、连张紧轮一起换</strong>，是性价比最高的预防性维修。</span>

**正时对正**：把曲轴转到一缸压缩上止点，凸轮轴记号与缸盖记号对齐，然后装正时皮带/链条并张紧。装完必须**手动转曲轴两圈**复核，确认无顶缸、正时记号仍对齐。

## 4 气门间隙的调整

**气门间隙**：冷态下气门杆端与传动件（摇臂/挺柱）之间的预留间隙。作用是补偿气门、气门座及传动件受热后的膨胀，保证热态时气门仍能**关闭严密**。

间隙**过大**：气门晚开早关，进气不足、排气不尽，且撞击声明显（嗒嗒声）；间隙**过小**：热态时气门关不严，漏气、烧蚀气门。所以间隙必须在规定值。

调整方式分两类：

- **摇臂调整螺钉式**：用塞尺测间隙，松开锁紧螺母、转动调整螺钉，使塞尺拉动有轻微阻力，再锁紧。两遍测量（第一遍粗调、第二遍复核）。
- **垫片式（顶置凸轮直接压气门）**：拆下调整垫片，实测间隙，按下式计算选垫片。
- **液压挺柱式**：挺柱内腔靠机油压力自动补偿间隙，**无需调整**。它的优点是免维护、噪声小；缺点是依赖机油压力，机油不足或挺柱内进空气时会出现「冷车响、热车好」的异响。液压挺柱本身磨损或堵塞时需更换。

现代发动机越来越多采用**可变气门正时（VVT）**，通过油压控制凸轮轴相位调节器，在低速与高速分别优化配气相位。VVT 系统检修的重点是机油油路清洁、相位调节器与电磁阀的动作测试——这属于电控范畴，后面《发动机电控系统与传感器故障诊断》会涉及。

## 5 公式解析：垫片式气门间隙的选配

垫片式气门间隙调整的核心公式：

$$
h_{\text{新}} = h_{\text{旧}} + (\delta_{\text{实测}} - \delta_{\text{标准}})
$$

- **第一步，测旧垫**：拆下旧调整垫片，用千分尺测其厚度 $h_{\text{旧}}$。
- **第二步，量间隙**：用塞尺实测当前气门间隙 $\delta_{\text{实测}}$。
- **第三步，求新垫**：间隙实测值比标准值大，说明垫片薄了，要加厚——$h_{\text{新}} = h_{\text{旧}} + (\delta_{\text{实测}} - \delta_{\text{标准}})$。反之减薄。<span class="marginnote">公式的直觉是「<strong>垫片厚度与间隙此消彼长</strong>」：垫片加厚，间隙变小；垫片减薄，间隙变大。</span>

- **第四步，选件与复核**：按计算结果挑选最接近的标准垫片规格，装回后再用塞尺复核，直至落在标准范围内。

**辨析｜易错点：** 调气门间隙必须先确认**该缸处于可调状态**（凸轮基圆对准挺柱，气门处于关闭位），否则量出来的是「假间隙」。按发火顺序逐缸调整，或采用「两次调整法」按 1-3-4-2 等顺序一次调多个气门——这些方法都以「气门关闭」为前提。

## 6 常见故障与装配要点

| 故障 | 典型原因 |
| --- | --- |
| 气门嗒嗒响（冷车明显） | 气门间隙过大 |
| 气门关闭不严、回火/放炮 | 间隙过小、座圈烧蚀 |
| 动力下降、进排气不足 | 凸轮磨损、正时滞后 |
| 顶气门（严重异响后熄火） | 正时皮带断裂、跳齿 |
| 烧机油（经气门油封） | 气门导管、油封磨损 |
| 冷车嗒嗒响、热车消失 | 液压挺柱内空气或磨损 |

**装配要点**：气门锁片必须到位（防气门脱落掉入气缸）；气门油封换新；正时记号对正后张紧；装完手动盘车两圈复查。

**配气相位的一个直觉**：气门并非在上下止点「准点」开闭，而是进排气门各有提前角与迟后角，甚至出现**气门重叠**——排气门还没关、进气门已开的一小段，利用气流惯性改善扫气。重叠角过大则低速怠速不稳、废气倒灌；过小则高速进气不足。配气相位由凸轮型线决定，维修中我们「动不得凸轮」，但必须保证正时机构把它还原到设计位置——这再次说明正时对正的极端重要性。

## 7 小结

配气机构检修可以概括为两句话：**件要修到「关得严」，时要对到「开得准」**——密封靠气门组，正时靠传动组。

- 配气机构 = **气门组**（密封）+ **传动组**（驱动）；正时把曲轴与凸轮轴绑成 2:1 转速比。
- 气门检修看**杆磨损、头部烧蚀、密封性**；座圈铰削+对研，控制下沉量。
- 正时皮带**到期强制更换**，断裂即顶气门；装后盘车两圈复核。
- 气门间隙过大响、过小漏，须按手册标准值调整。
- 垫片式调整公式 $h_{\text{新}} = h_{\text{旧}} + (\delta_{\text{实测}} - \delta_{\text{标准}})$
