# 汽车发动机与底盘维修（汽车机械维修）

面向国家职业资格目录中的法定职业「汽车维修工」，对标《汽车维修工国家职业技能标准（2018年版）》与职业技能鉴定培训教材，系统重建从拆装、故障诊断、大修到调试的发动机与底盘完整维修技能体系。学完这些章节，就写完了汽车发动机与底盘维修的全部内容。

## 对标教材

- 《汽车维修工国家职业技能标准（2018年版）》
- 人民交通出版社《汽车维修工职业技能鉴定培训教材》
- 《汽车发动机维修技术》
- 《汽车底盘构造与维修》
