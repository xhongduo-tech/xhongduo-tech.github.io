## 为什么从总装与启动调试开始

前面所有章节的终点，是这一刻：把修好、装好的发动机**装回车上**，接通油电水气，**第一次点火**，并把它调校到最佳状态。总装与启动调试，是发动机维修的「交卷时刻」——前面任何一道工序的疏漏，都会在点火瞬间集中暴露。

这一章既是技能的收束，也是**质量的门槛**：怠速稳不稳、加速顺不顺、有没有异响渗漏、排放达不达标，都在启动调试中见分晓。会修不会调，等于只会做菜不会尝味。<span class="marginnote">启动调试的本质是「<strong>让发动机在试运行中自证健康</strong>」：点火成功只是及格线，调到位才算优秀。</span>

## 1 发动机装车的步骤与要点

发动机装车是拆车吊装的逆过程，要点同样在「顺序与防护」：

1. **落机**：吊装发动机入机舱，对正发动机支座（机脚），先穿螺栓但不锁死，留出调整余量。
2. **接传动**：连接变速器/驱动半轴，注意花键与导向轴承对正，不可硬撬。
3. **接外围**：依次连接散热器与水管、进排气歧管、燃油管（先检查密封圈）、线束插头、传动皮带与附件。
4. **加注油液**：机油、冷却液按标准加注，冷却系统排空气。
5. **检查**：环绕检查所有插头、卡箍、螺栓是否就位，**重点确认无工具遗落**。

**易错点**：装车后漏接某根线束、漏装某个卡箍，是启动调试翻车的最常见原因。规范做法是**对照拆车时的清单逐项打勾**，吊装前再绕车一周目检。<span class="marginnote">「<strong>工具遗落在发动机舱</strong>」是维修界的老事故：一块抹布、一把扳手卡进皮带轮，启动瞬间就是一场灾难。装车后清点工具，是保命动作。</span>

## 2 首次起动前的检查清单

点火之前，把「油电水气」四件事逐一确认：

**机油**：液位达标、油压传感器正常；新装的机油泵与滤清器应已建立油压预润滑（或转动曲轴建立油压）。
**冷却液**：液位达标、无泄漏，**已排气**（气阻会导致水温虚高甚至开锅）。
- **燃油**：管路接好、无泄漏，供油系统已建压。
- **点火与电控**：各传感器插头到位、正时记号正确、蓄电池电压充足、搭铁线紧固。
- **安全**：变速器在空挡/驻车挡、车轮挡好、周围无火源。

**预润滑**是老规矩：拔下点火线圈或燃油泵保险，用起动机带动曲轴运转数秒，让机油泵先把油压建立起来，再接通点火试机——这能显著减少干磨损伤。<span class="marginnote">大修后的第一次起动，<strong>预润滑就像手术前的「先输血」</strong>：让轴瓦在油膜建立后再受力，是对新零件的最大保护。</span>

**检查清单速查表**：

| 项目 | 确认内容 |
| --- | --- |
| 机油 | 液位、油压、无泄漏 |
| 冷却液 | 液位、排气、无泄漏 |
| 燃油 | 管路、建压、无泄漏 |
| 电控 | 插头、正时、电瓶、搭铁 |
| 安全 | 挡位、车轮挡、无工具遗落 |

## 3 起动与初次运转调试

**首次起动**的节奏：点火钥匙转起动位，发动机应在数秒内起动；若起动机转但不着车，**连续起动不要超过 15 秒**，间隔冷却起动机，防止过热烧毁。

**起动后的调试项目**按顺序推进：

1. **听异响**：怠速听有无金属敲击声（气门、轴承、活塞），异响应立即熄火排查。
2. **看仪表**：机油压力灯应在起动后数秒内熄灭，水温表正常上升。
3. **查渗漏**：发动机运转后检查油、水、气三漏，重点看油底壳、缸盖周边、水管接头。
4. **调怠速**：读取数据流，怠速转速应在目标值附近，怠速控制阀/电子节气门工作正常。
5. **校正时**：用正时灯或数据流确认点火提前角正常。
6. **验排放**：尾气分析仪检查 CO、HC 是否达标，氧传感器闭环正常。
7. **路试**：试车检查加速、回油、爬坡、高速工况，确认无失火、无力与异响。

**冷车快怠速**是正常的：冷机时节气门开大、怠速自动升高（约 1000–1500 r/min），随水温上升逐渐回落到标准怠速。若冷车怠速不升高或回落过慢，查水温信号与怠速控制执行器。<span class="marginnote">「<strong>冷车高怠速、热车稳怠速</strong>」是电控发动机的标配行为。怠速不按规律变化，往往指向水温传感器或节气门积碳。</span>

**怠速不稳的调试顺序**：先读数据流确认目标怠速与实际怠速的偏差，再查**进气管路泄漏**（真空管脱落、进气道破损会导致怠速偏高且波动），再查**节气门积碳**（清洗后需做节气门复位/学习），最后查**各缸工作一致性**（断缸测试）。怠速调试的「由外到内」顺序，能避免一上来就怀疑电控元件。

**排放初检**：怠速与中速下用尾气分析仪测 HC（未燃烃）与 CO（一氧化碳）。HC 高多为缺火或烧机油，CO 高多为混合气过浓——排放数值是燃烧质量的「化学天平」，把点火、喷油与机械故障综合显形。

## 4 公式解析：起动电压降

起动无力的诊断常与蓄电池有关。起动机运转时的大电流会在内阻上产生压降：

$$
U_{\text{起动}} = U_{\text{空载}} - I_{\text{起动}} \cdot r_{\text{内阻}}
$$

- **第一步，看变量**：$U_{\text{空载}}$ 是蓄电池开路电压，$I_{\text{起动}}$ 是起动机电流（可达数百安培），$r_{\text{内阻}}$ 是蓄电池内阻。
- **第二步，理解压降**：电流越大、内阻越大，起动时电压被拉得越低。内阻随电量下降、低温与老化而增大。
- **第三步，看诊断**：用电压表夹在蓄电池两端看**起动瞬间电压**——低于约 9.5 V（视车型）说明电压跌落过大，指向亏电、内阻过大或接线不良；电压正常却起动无力，则查起动机本身与主电路接触电阻。<span class="marginnote">「<strong>起动瞬间电压是蓄电池的体检报告</strong>」：数字会说话——亏电还是内阻大、接线松还是起动机坏，一测便知。</span>

**辨析｜易错点：** 起动无力≠起动机坏。按顺序排查：**蓄电池电量与内阻 → 主电路接线（正负极桩头、搭铁）→ 起动机电磁开关 → 起动机本身**。桩头腐蚀、搭铁松动造成的大电流接触电阻，往往比起动机磨损更常见。

## 5 常见起动与调试故障

| 故障 | 典型原因 | 排查方向 |
| --- | --- | --- |
| 起动机转但不着车 | 无火、无油、正时错、压缩不足 | 试火、测油压、查正时记号 |
| 起动机不转/无力 | 亏电、接线不良、起动机故障 | 测起动电压、查主电路 |
| 起动后立即熄火 | 防盗、油压未建立、怠速阀卡滞 | 查防盗、油压、数据流 |
| 怠速不稳 | 漏气、节气门积碳、传感器 | 读数据流、查真空泄漏 |
| 加速无力 | 点火/喷油异常、排气堵塞 | 路试、读失火计数 |
| 冒烟 | 蓝烟烧机油、黑烟过浓、白烟进水 | 分烟色查原因 |
| 冷却液消耗快 | 缸垫、水套渗漏、散热器 | 压力测试、查乳化 |

**不着车诊断的顺序**是「**火油压正时**」四字诀：先试火花（有火吗），再查燃油（有油吗），后测缸压（压够吗），最后对正时（时序对吗）——四步走完，十有八九能定位。若起动时排气管有放炮声，多指向点火错乱或正时错位。<span class="marginnote">「放炮」是点火时序错乱的警报——<strong>排气门开启时还在点火</strong>，混合气在排气管内爆炸。见到放炮先查分缸线顺序或正时记号。</span>

## 6 小结

启动调试是发动机维修的「毕业答辩」：它把前面十几章的知识一次性考一遍，而考官就是发动机本身。

- 装车是拆车逆过程，**对照清单打勾、工具清点**是防事故铁律。
- 首次起动前查「**油电水气**」，先预润滑再点火，连续起动不超 15 秒。
- 起动后按「**听异响 → 看仪表 → 查渗漏 → 调怠速 → 校正时 → 验排放 → 路试**」推进。
- 第一次起动前先预润滑，起动机连续运转不超过 15 秒。
- 冷车高怠速、热车稳怠速是正常行为；怠速异常查水温信号与节气门。
- 起动电压降公式 $U_{\text{起动}} = U_{\text{空载}} - I\cdot r$
