# 汽车美容与车身钣喷修复

以《汽车车身修复技术》与《汽车维修工国家职业技能标准》（车身整形、涂装工种）为纲，结合汽车美容装潢工职业标准，系统覆盖从钣金整形、喷漆涂装到漆面养护、内饰装潢的完整车身美容与修复技能体系。汽车美容与钣喷修复是汽车维修七大工种中的独立分支，市场需求与就业空间广阔，学完这些章节，就写完了车身整形、涂装与美容装潢所需的全部内容。

## 对标教材

- 《汽车维修工国家职业技能标准》（车身整形、涂装工种）
- 人民交通出版社《汽车车身修复技术》
