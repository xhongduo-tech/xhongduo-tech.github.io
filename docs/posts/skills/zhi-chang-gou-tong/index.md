# 职场沟通与情商

以《非暴力沟通》《情商》与《关键对话》为纲，系统建立从情绪认知与自我管理、非暴力沟通四要素，到关键对话技巧与向上/平级/向下沟通、职场冲突化解的完整职场沟通与情商体系。学完这些章节，就掌握了在职场中高情商表达、倾听与解决冲突的核心能力。

## 对标教材

- 《非暴力沟通》（马歇尔·卢森堡）
- 《情商》（丹尼尔·戈尔曼）
- 《关键对话》（科里·帕特森等）
