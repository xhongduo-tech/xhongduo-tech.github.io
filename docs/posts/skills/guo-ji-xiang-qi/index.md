# 国际象棋

国际象棋是一项全球最普及的智力对抗项目，集规则理解、战术计算与局面战略于一身，从开局、中局战术到残局技艺层层递进，是训练逻辑思维与心理素质的经典载体。以《国际象棋入门》、FIDE 等级分体系与《国际象棋战术与战略》为纲，系统重建从基础规则、胜负判定、开局理论到中局攻杀与残局精确着法的完整知识体系。
