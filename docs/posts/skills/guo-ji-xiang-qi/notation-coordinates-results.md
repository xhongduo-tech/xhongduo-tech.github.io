## 为什么从棋谱开始

前面五节已经把「下棋」本身讲完了，本节讲「记录棋局」——**代数记谱法（algebraic notation）**。它把每一步棋翻译成一行紧凑的符号，让棋局可以被书写、被保存、被千年之后的人重演。<span class="marginnote">国际象棋的记谱法经历过漫长的演化，从描述记谱法（Descriptive Notation）到今天的代数记谱法。代数记谱法之所以胜出，是因为它足够紧凑、足够无歧义——「Nf3」四个字符就完整描述了一步棋。今天 FIDE 规定的比赛记录，一律使用代数记谱法。</span>学会记谱，你就获得了三个能力：看懂棋书、复盘自己的对局、与全世界的棋手共享同一套「棋语」。

记谱不只是一项「记录技能」，它还是**计算的载体**：职业棋手在脑内推演变化时，用的就是这套符号语言。你的记谱越熟练，「脑内棋盘」就越清晰。

## 1 代数记谱法：把一步棋写下来

代数记谱法的核心是「**棋子字母 + 目标格**」。第一步先记住棋子的字母：王 `K`、后 `Q`、车 `R`、象 `B`、马 `N`、兵（省略字母，直接写格名）。

一条基本记谱由三部分组成：

**棋子字母**（兵省略）；
**目标格**，如 `d5`、`e4`；
**附加符号**（吃子、将军、易位等，见下）。

例如：

| 记谱 | 含义 |
| --- | --- |
| `e4` | 兵走到 `e4` |
| `Nf3` | 马走到 `f3` |
| `Bxe5` | 象吃掉 `e5` 上的棋子 |
| `O-O` | 王翼易位（短易位） |
| `O-O-O` | 后翼易位（长易位） |
| `exd5` | 兵从 `e` 线斜吃到 `d5` |
| `e8=Q` | 兵升变为后 |
| `Qg7#` | 后到 `g7` 将杀 |

**易错点｜兵的记谱**：兵是唯一不写棋子字母的。`e4` 一定是兵走——因为别的子都要先写 `K/Q/R/B/N` 再写格子。<span class="marginnote">遇到 `e4`、`d5` 这种「裸格名」，心里要立刻反应：这是兵在走。而兵吃子时写「出发线字母 + x + 目标格」，如 `exd5`，因为一个兵可能同时斜吃左右两个方向，必须注明它来自哪条线。</span>

## 2 记谱的细节：吃子、将军、升变与同名棋子

**吃子**用 `x` 表示：`Nxe5` 是马吃 `e5` 上的子。**将军**用 `+` 表示：`Qg7+` 是后到 `g7` 将军。**将杀**用 `#` 表示：`Qg7#` 是将杀。**升变**用 `=` 加棋子字母：`e8=Q`、`e8=N`（升马）。

**同名棋子的区分**——棋盘上可能有两个车、两个马、两个象都能走到同一个格子，此时记谱必须说明「哪一个」：

**加列名**：`Nbd2` 表示 b 线的马走到 `d2`（另一个马在 f 线）。
**加行名**：`N1f3` 表示第 1 行的马走到 `f3`（另一个马在第 3 行）。
**列行都加**：`Qh4e1` 表示从 `h4` 出发的后走到 `e1`（极端情况）。<span class="marginnote">加列还是加行，取决于「哪个信息能唯一区分」。若两个马一个在 `b1` 一个在 `f3`，都能到 `d2`，则写 `Nbd2`——用列名区分。只有当列名相同时（比如同一列有两个车），才改用行名。记谱的黄金原则是「<strong>最小必要信息</strong>」。</span>

**对局中的注释符号**（非 FIDE 强制，但棋书普遍使用）：`!` 好棋、`!!` 妙着、`?` 坏棋、`??` 败着、`!?` 有趣、`?!` 可疑。这些符号把棋手的主观评价写进棋谱，让记录从「事实」升格为「观点」。

**对局起始的记谱**：整局棋按「回合」记录——白棋一步、黑棋一步合成一个回合。写谱从第 1 回合开始，如：

```
1. e4 e5  2. Nf3 Nc6  3. Bb5 a6
```

读谱时，先找回合号，再按「白、黑」顺序翻译。这就是职业棋谱的标准格式。

## 3 对局结果的判定：三种结局的符号

对局只有三种结果，用三个符号记录在棋谱末尾：

| 结果 | 符号 | 含义 |
| --- | --- | --- |
| 白胜 | `1-0` | 白方将杀或黑方认输/超时 |
| 黑胜 | `0-1` | 黑方将杀或白方认输/超时 |
| 和棋 | `½-½` | 双方同意或规则判和 |

**分出胜负的途径**：将杀、对方认输、对方超时（棋钟倒完）。**和棋的途径**则丰富得多，FIDE 规则里常见六种：

1. **逼和（stalemate）**：上一节已讲，无合法着法且未被将军。
2. **三次重复（threefold repetition）**：同一局面出现三次（或即将出现第三次），轮走方可要求和棋。
3. **五十回合规则（50-move rule）**：连续 50 个回合没有吃子、没有动兵，可要求和棋。<span class="marginnote">与三次重复一样，五十回合是「可要求」的权利：不要求就不判和。2014 年起 FIDE 新增了<strong>七十五回合规则</strong>与<strong>五次重复规则</strong>——达到 75 回合无吃子/动兵或同一局面第 5 次出现时，裁判<strong>自动</strong>判和，无需任何一方提出。</span>
4. **不足以将杀的子力**：双方都只剩「不可能将杀」的子力时判和，例如王对王、王单象对王、王单马对王、双方都只剩同色格象等。
5. **协议和棋**：双方同意和棋，通常由优势方权衡后主动提出。
6. **超时且对方无杀棋子力**：一方超时，但对方剩余子力不足以将杀，判和而非判负。

## 4 读一局棋：从记谱到看懂「愚人杀」

记谱最直接的用途，是看懂「最短的将杀」——**愚人杀（Fool's mate）**，它一共只有两步：

```
1. f3  e5
2. g4  Qh4#
```

逐回合翻译：白方 `f3`、黑方 `e5`；白方 `g4`（这是自毁防线的一步——把 `g1` 前的兵推走，白王 `e1` 到 `h4` 的对角线彻底裸露）、黑方 `Qh4#`（后走到 `h4`，沿 `e1`–`h4` 斜线直击白王，且 `g2`、`f2` 都没有白子能挡，将杀）。<span class="marginnote">愚人杀里后走到 `h4` 将军的路线是 `e1`→`h4` 的对角线：`g2` 的兵已被 `2.g4` 推走，`f2`、`g2` 再无人可垫，白王无路可逃——这就是「开放线」害死自己的极端例子。读谱时把每一步对应的格子、走线在脑内过一遍，整盘棋就「活」了。</span>

**读谱训练方法**：先读慢棋谱（古典大师对局），每步在脑内棋盘落子；读不下去时摆真实棋盘核对。每天读 15 分钟，记谱速度与棋感会同步提升。

## 5 核心对比表：可要求判和 vs 自动判和

| 和棋类型 | 触发条件 | 判法 |
| --- | --- | --- |
| 逼和 | 无合法着法且未被将军 | 自动（自然和棋） |
| 三次重复 | 同一局面第 3 次出现 | 轮走方**要求**才判 |
| 五十回合 | 50 回合无吃子/动兵 | 轮走方**要求**才判 |
| 五次重复 | 同一局面第 5 次出现 | 裁判**自动**判和 |
| 七十五回合 | 75 回合无吃子/动兵 | 裁判**自动**判和 |
| 子力不足 | 双方无杀棋子力 | 自动判和 |
| 协议和棋 | 双方同意 | 须双方共同提出 |

**「可要求」与「自动」的差别是本节最重要的辨析**：三次重复与五十回合是权利，你不提就继续下；逼和与子力不足是事实，谁来了都判和。<span class="marginnote">实战里最常见的误判是「五十回合是自动的」——其实规则要求轮走方在走棋前（或走棋后）声明要提出三次重复或五十回合和棋，否则对局继续。很多业余棋手在这里吃了亏：明明局面重复三次，忘了提和，结果局面又变了。</span>

## 6 小结

- **代数记谱法**：棋子字母 + 目标格；兵省略字母；`x` 吃子、`+` 将军、`#` 将杀、`=` 升变、`O-O`/`O-O-O` 易位。
- **同名棋子区分**：按「最小必要信息」原则，优先加列名，必要时加行名或两者都加。
- **结果符号**：`1-0` 白胜、`0-1` 黑胜、`½-½` 和棋。
- **和棋六途**：逼和、三次重复、五十回合、子力不足、协议和棋、超时且对方无杀棋子力。
- 三次重复与五十回合是**可要求**的权利，逼和与子力不足是**自动**成立的事实。
- **读谱**是记谱能力的实战检验——从愚人杀这类短对局入手，逐步过渡到完整棋谱。
