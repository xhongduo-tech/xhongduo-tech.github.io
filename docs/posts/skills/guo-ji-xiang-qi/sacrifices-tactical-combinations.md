## 为什么从弃子攻杀开始

前面几节学了「单点战术」，本节把它们组装成**完整武器系统**——**弃子攻杀（sacrifice）** 与 **战术组合（combination）**。它们是中局战术的「高潮时刻」：弃掉子力、连招不断、将死对方。<span class="marginnote">弃子与「送子」只在一线之隔：弃子是有计划的「投资」（用子力换攻势），送子是没算清的计算失误。判定一个弃子「成不成立」，标准只有一个——<strong>弃子之后，对方的王能不能逃过你后续的强制连招</strong>。成立则弃子，不成立则送子，这一线之差就是棋力的分水岭。</span>本节先讲弃子的原理与经典构图，再讲如何把散落的战术串成组合。

## 1 什么是弃子攻杀

**弃子攻杀（sacrifice）** 指：**主动放弃子力（通常是轻子或重子），换取攻击对方王的主动权或直接杀棋**。它与开局的「弃兵开局」（见《后翼弃兵与王翼弃兵》）同源，但更极端——开局弃兵换的是「中心与出子」，弃子攻杀换的是「王的生命」。

弃子的「投资逻辑」：

> **弃 3–5 分（马/象/车）→ 换「王被将杀」或「必然赢回更多」。**

判断弃子值不值，看两个回报：**杀棋**（直接将杀，回报是整盘棋）或 **物质回收**（弃 3 分、后续赢回 5 分）。<span class="marginnote">为什么弃子经常成立？因为「王的生命」在价值表上是无穷大（见《棋盘、棋子与初始布局》）。当一个弃子能把对方的王拖入无法脱身的包围圈，任何物质上的「赚」都失去意义——你弃掉一个马，换来的是一场胜利，这笔交易划算到无法拒绝。</span>

### 弃子的三种回报

| 回报类型 | 内容 | 典型场景 |
| --- | --- | --- |
| 杀棋 | 直接将杀 | 攻王组合的收尾 |
| 物质回收 | 弃小赢大 | 弃马换回车或后 |
| 局面优势 | 换持久主动权 | 弃子打开对方王翼 |

**三者的优先级**：杀棋 > 物质回收 > 局面优势。一个弃子若能换到杀棋，物质上多亏都值得；只能换到「局面优势」的弃子，则要看优势能否兑现——**弃子之后赢不了，就是送子**。

## 2 经典攻王弃子：希腊礼物

**希腊礼物（Greek gift）** 是攻王弃子里最著名的一招，发生在对方**王翼易位后**的局面：

**构图**：白方有象在 `d3`（或 `c4`、`b5` 等 `h7` 斜线上的位置）、马在 `f3`/`f4`、后有参与攻王的可能，黑王在 `g8`、`h7` 兵只有王单独防守。

**着法**：

1. **`Bxh7+!`**：象吃 `h7` 兵将军——如果黑王贪吃 `Kxh7`，就落入圈套。
2. **`Ng5+`**：马跳 `g5` 双将式将军，王无处可逃，被迫退回。
3. **`Qh5+`** 或 `Qh4` 等，后跟上，配合马形成将杀网络。<span class="marginnote">希腊礼物的核心是「诱王离位」：`Bxh7+` 是一枚「有毒的诱饵」——黑王吃下它，就踏上了白方布置好的 `Ng5+` 与 `Qh5+` 的连环雷区。这套弃子的成立条件（马能跳 `g5`、后能跟进）一旦满足，黑王几乎必死。它也因此成为每一位战术爱好者的必修课。</span>

**易错点｜希腊礼物的前提条件**：不是所有局面都能 `Bxh7+`——必须满足「马可跳 `g5` 且受保护、后能及时跟进、黑方 `f6` 无马防守 `h7`」等前提。**在条件不成熟时强行弃子，往往只是送子**。

## 3 战术组合：把散落的招连成一条龙

**战术组合（combination）** 指：**一连串强制着法（将军、吃子、威胁）构成的有计划进攻序列**，通常以弃子开路、以将杀或赢子收尾。它是「击双 + 牵制 + 闪击 + 过门」等战术的「串烧」。

一个标准组合的骨架：

1. **弃子开路**：用弃子打破对方防线（如弃子引离 `f7` 的防守者）。
2. **强制将军**：用连串将军压缩对方王的活动空间，不让对方喘息。
3. **引入收网**：把对方的王「引」到将杀格，最后一击将杀。

**组合的可怕之处在于「强制性」**：每一步都是将军或致命威胁，对方没有「不回应」的自由，只能一路被你牵着鼻子走。<span class="marginnote">计算组合的关键是「找强制着法」：将军（check）、吃子（capture）、威胁（threat）是三类「强制分支」。高手算组合时，把每一步都展开成「对方所有可能的应对」，然后在分支里找「每一条路都将杀或赢子」的必然线——这条线就是组合。组合不是「灵感」，而是「穷举 + 筛选」的结果。</span>

**易错点｜组合中途放弃**：组合的每一步都必须验证「对方最佳应对后仍然成立」——很多人算了 3 步就停，结果第 4 步被对方反将，前功尽弃。**算组合要算到「对方无路可走」为止，差一步都可能从妙着变败着**。

## 4 如何寻找弃子：攻王检查清单

面对一个「王翼易位的对方王」，按清单逐条检查，能高效地找到弃子攻杀的机会：

| 检查项 | 说明 |
| --- | --- |
| 王前兵是否松动 | `f7/g7/h7` 是否已被削弱、少兵 |
| 马的落点 | `g5`/`f6` 等攻王格是否可跳且受保护 |
| 后的参与 | 后能否快速到达 `h5`/`h4`/`g4` 等攻击线 |
| 象的斜线 | 象是否在指向 `h7`/`g8` 的斜线上 |
| 防守者是否过载 | 对方防守 `h7`/`f7` 的子是否「身兼数职」 |

**清单的用法**：五条中满足两三条，就可以考虑启动弃子攻杀；满足全部五条，几乎必有杀棋。<span class="marginnote">这张清单浓缩了攻王的「侦察逻辑」：攻王不是「灵光一现」，而是「按图索骥」——先看王前防线（兵），再看攻击火力（马、后、象），最后看防守漏洞（过载的防守者）。把清单练成习惯，你在对局里会发现攻王机会「自动浮现」。</span>

### 弃子攻杀的实战纪律

**纪律一：先算后弃。** 弃子之前，必须把「弃子之后的强制连招」算到「对方无路可走」为止——至少算 3 步，最好算到将杀。算不清的弃子，宁可先压着。

**纪律二：留好退路。** 弃子攻杀一旦被对方「化解」（比如对方找到了唯一防守着法），你要有「弃子失败后的止损方案」——至少不要让局面从「小优」变成「大劣」。

**纪律三：弃子要「一气呵成」。** 攻杀组合中断一次（对方抢到喘息），攻势就衰竭。所以组合里的每一步都要强制（将军/致命威胁），不给对方「换口气」的机会。

### 何时不该弃子

| 情形 | 原因 |
| --- | --- |
| 对方防守者充足 | 弃子攻不进去 |
| 你的王不安全 | 弃子后反被攻王 |
| 强制连招算不清 | 弃子等于送子 |
| 局面已稳赢 | 弃子是多余的风险 |

**这张「不该弃子」表，比「该弃子」表更重要**——新手最大的问题不是「不会弃子」，而是「乱弃子」。记住：**弃子是「算出来的」，不是「冲动出来的」**。

## 5 小结

- **弃子攻杀**：用子力换攻势或杀棋；回报是「王的生命」或「物质回收」，成立与否看强制连招。
- **希腊礼物**：`Bxh7+` → `Ng5+` → `Qh5+` 的经典攻王组合，前提是马、后、象都能跟上。
- **战术组合**：将军、吃子、威胁串成的强制序列，以弃子开路、以将杀收网。
- **寻找弃子**：用「攻王检查清单」（兵松动、马落点、后参与、象斜线、防守过载）系统侦察。
- **计算纪律**：组合要算到「对方无路可走」为止，差一步都可能从妙着变败着。
- 弃子与送子只在一线之隔——**先算清强制连招，再决定弃不弃**。

### 训练建议

**入门**：先做「希腊礼物」的专项题（20 道），吃透 `Bxh7+` 的构图与前提条件。

**进阶**：做「弃子攻杀」标签的组合题，每道题要求「算到将杀或明显赢子」才看答案——中途翻答案的训练无效。

**高阶**：把「攻王检查清单」背下来，在实战对局里每盘至少用一次——用它侦察攻王机会，把清单变成肌肉记忆。**每天 15 分钟，坚持一个月，你对「弃子值不值」的判断力会脱胎换骨**。

最后强调一次：本节所有的「清单」「纪律」「步骤」，目的只有一个——**把「弃子」从「赌博」变成「计算」**。职业棋手弃子时并不比你有更多「勇气」，他们只是比你先算清了后续。勇气来自计算，这是攻王弃子最深的秘密。
