## 为什么从将军与将杀开始

前两节学会了「怎么走」，本节回答「怎么结束」：一盘棋如何分出胜负、又如何握手言和。国际象棋里王不能被真正「吃掉」——它一旦受攻就必须立即化解，化解不了就输。由此引出三个核心概念：**将军（check）**、**将杀（checkmate）** 与 **逼和（stalemate）**。<span class="marginnote">这三者共享同一个「王受威胁/无路可走」的家族相似，却有着完全不同的结局：将军是要化解的威胁、将杀是输、逼和是和。初学者最容易在「将杀」与「逼和」之间栽跟头——把对方将死了当然赢，但把对方「逼到无路可走」却是和棋，这两者的差别往往决定胜负。</span>本节把三个概念拆开讲透，并给出辨析表。

这三者的理解深度决定你的残局水平：**会判断「这是将杀还是逼和」，是新手与进阶者的第一道分水岭**。所以本节会给出具体的判断流程，而不只是概念定义。

本节从「被将时怎么办」出发，先建立将军的三法化解，再讲将杀的判定流程与经典模式，最后辨析逼和——并给出三者的对照表。

## 1 将军：王被攻击的时刻

当一枚棋子（或兵）在攻击王的格子时，王就处于**被将军（check）** 状态，简称「被将」。被将军的一方**必须在下一步立即解除威胁**，不能置之不理，更不能走其他棋。

解除将军只有三种手段，至少满足其一：

1. **移动王**：把王走到一个不被攻击的格子上。
2. **吃掉攻击子**：用任意棋子（包括王自己）吃掉正在将军的对方棋子。
3. **垫将（block）**：在攻击者的攻击线上放一个棋子，挡住它——但只有「直线攻击」（车、象、后）才能被垫，马和兵的攻击无法阻挡。<span class="marginnote">马的将军只能「躲王」或「吃马」，因为马的攻击是跳跃式的，中间没有「线」可挡；兵斜着攻击王时同样不能垫。而「双将」（两个棋子同时将军）时，唯一解药是移动王——吃掉其中一个，另一个仍将着王。</span>

三种手段都做不到，就意味着将杀。另外要记住：**被将军时不能王车易位**（上一节已经讲过）；同一手棋里，己方王被将着时，也不能走任何「不解除将军」的着法——即使那步棋能把对方的王将死，只要自己的王还暴露在攻击下，就不合法。<span class="marginnote">这条规则常常制造「妙着」与「败着」的一念之差：新手容易只顾着「我要将死对方」，却忘了自己王还站在火线上。对局中先检查自己的王，再检查对方的王，是每个棋手都要养成的顺序。</span>

**补充｜「将军」要不要喊出来**：休闲对弈中口头喊「将军」是惯例，方便提醒对方；正式规则并不要求喊出，但记谱时用 `+` 标注将军、用 `#` 标注将杀。

## 2 将杀：游戏的终点

**将杀（checkmate）** 指的是：王处于被将军状态，且没有任何合法手段可以解除——不能移、不能吃、不能垫。此时攻击方获胜，对局立即结束。

将杀是一个「组合判定」，需要同时满足两条：

**王被将军**（正在被攻击）；
**王的所有逃生路线全部被封锁**（相邻格不安全、无法吃攻击子、无法垫将）。<span class="marginnote">「将杀」与「死局」在中文里有时被混用，但严格区分：将杀是攻方主动构造的终局，是「无处可逃」；死局泛指任何败定局面。比赛中常见「死局认输」——明知必败、只差几步被将杀，就主动停钟认输，这是对局礼仪的一部分。</span>

### 判断将杀的三步流程

拿到一个「看似要把死对方」的局面，按以下三步走，不会漏判：

1. **问「王被将了吗」**：有没有棋子攻击着王？没有 → 不是将杀，可能是逼和（见下节）。
2. **问「能移王吗」**：王的每个相邻格（以及原地）是否都被攻击或占满？
3. **问「能吃攻击子吗 / 能垫将吗」**：若攻击子是直线子，能否垫？若攻击子无保护，王能否吃掉它？

三步全被否定，就是将杀。<span class="marginnote">这条流程最容易被跳过的是第 3 步——新手常以为「王周围都是攻击格」就必然是将杀，却忘了王可以直接吃掉那个「没被保护的攻击子」。检查攻击子有没有保护，是判断的关键。</span>

### 三种最经典的将杀模式

**底线杀（back-rank mate）**：对方的王被自己的兵困在底线，车或后在底线上给将，王无处可退。这是新手最常见的杀法，也最容易死于粗心。

**闷杀（smothered mate）**：对方的王被自己棋子团团围住，只剩一个马能攻击到的缺口，马跳入落子将杀。「马在 `g7` 闷杀角落里的王」是最著名的构图。

**阿拉伯杀（Arabian mate）**：车控制王所在的行/列，马封锁王的唯一逃生格，两者配合完成将杀。

一个重要的直觉：**王不能吃「有保护」的棋子**。比如对方一个兵挡在王旁边将军，王想去吃它，但那个兵被对方另一个子保护着——王吃掉它后仍然会被攻击，所以那不是合法着法。这个「保护」概念是计算将杀的核心工具，也是下一节残局、中局战术反复使用的基础。

### 攻方与守方的视角

将杀是攻守双方视角的较量，两个视角要分开训练：

**攻方视角**：把对方王的逃生格「逐格清点」——先控制它左右、前方、后方所有相邻格，再落下一击。**不要急着把后冲到王脸上**，先封锁逃跑路线，往往比直接将军更有效。
**守方视角**：被攻击时先别慌，按「移、吃、垫」三法逐一排查；尤其要检查「攻击子是否无保护」——若它孤军深入，王可以直接吃掉它反杀。<span class="marginnote">一个实用的守方心法：<strong>每一个看似凶猛的将军，都要先问一句「这个攻击子自己安全吗」</strong>。许多「妙着将军」其实是送吃，因为攻击子没带保护。反过来，攻方每落一个将军，也要确认「我的子被保护吗」，防止被对方王反吃。</span>

这个「先清点逃生格、再确认保护」的双视角训练，是从「会判断将杀」走向「会制造将杀」的必经之路。

## 3 逼和：最反直觉的平局

**逼和（stalemate）** 是最容易让新手捶胸顿足的规则：**轮到走棋的一方不在被将军状态，却没有任何合法着法可走**——对局立即以和棋结束。

逼和与将杀的差别只在一个字：**被将与否**。

被将军 + 无路可走 = **将杀**，攻方胜。
未被将军 + 无路可走 = **逼和**，双方和棋。

想象一个典型局面：你多一个后，对方只剩光杆王。你一步步把对方王逼到角落，最后得意地走后到它面前——结果它「无路可走」了，你高兴地宣布胜利，裁判却宣布和棋。这正是逼和：**你把对方逼到死角，却没让它「正在被将军」**。<span class="marginnote">为什么规则要保底这一条？历史上逼和曾被当作「被将死」判负，后来才改判和棋。它防止了「优势方靠最后一击过度索取」——优势方必须真的完成将杀，而不是把对方「挤死」。这条规则也制造了大量经典的防守奇迹：弱势方在绝境中主动把自己逼到逼和，把败局救成和棋。</span>

**如何避免逼和**：多子攻孤王时，给将的每一步都要先确认「对方王还有没有别的合法着法」。一个实用技巧是**永远别把对方的王逼到「无格可退」的死角才动手**——先让王有喘息空间，再逐步收紧绞索。

**三个自查问题**，攻杀前逐一过一遍：

1. **我的这步棋将军了吗？** 没有将军的「最后一击」，若恰好封死对方，就是逼和。
2. **对方的王还有别的着法吗？** 若无路可走且未将军，立即停手，改走一步「留活口」的棋。
3. **我送掉的子会让对方有喘息吗？** 既要防逼和，也要防「假将军真送子」。

### 把逼和变成防守武器

逼和不是只属于攻方的「失误陷阱」，更是弱势方的**救命稻草**。残局里子力大幅落后、看似必败的一方，可以主动放弃大量子力，把自己逼成「无路可走但不被将军」的状态，从而把败局救成和棋。

经典构图：弱势方只剩王与一个兵，强势方有后与王，正要升变获胜。弱势方把王走到角落、让兵恰好「堵死」自己所有逃生路——如果此时强势方走出一步「没有将军」的着法，就触发逼和。这个「绝境自救」在残局章节会反复出现，是**劣势方最锋利的心理武器**。<span class="marginnote">国际象棋史上无数经典对局以「逼和逃生」收场：优势方在最后一步没注意「对方的王无路可走」，把到手的一分变成了半分。学会在绝境中寻找逼和，等于给失败加了一层保险——这也解释了为什么高手从来不在优势局面「贪那一步」。</span>

## 4 核心对比表：将军 / 将杀 / 逼和

| 概念 | 王是否被攻击 | 是否有合法着法 | 结果 |
| --- | --- | --- | --- |
| 将军 | 是 | 有（至少一种） | 对局继续，必须立即化解 |
| 将杀 | 是 | 无 | 攻方胜，对局结束 |
| 逼和 | 否 | 无 | 和棋，对局结束 |
| 正常局面 | 否 | 有 | 对局继续，轮走方自由行棋 |

这张表是本节的核心。**把「被攻击」与「无路可走」两条轴拆开**，三种状态的归属就一目了然：只有「被攻击」为真时，结果才是攻方胜；只有「被攻击」为假时，无路可走才会送给你一场和棋。

## 5 小结

- **将军**：王被攻击，必须用「移王 / 吃攻击子 / 垫将」三法之一解除；马与兵的攻击不能垫，双将只能移王。
- **将杀**：被将军且无合法着法，攻方获胜；判定时要检查王的所有相邻格与「吃、垫」两种可能。
- **逼和**：未被将军却无合法着法，和棋；它与将杀仅一字之差，是残局攻杀中必须精确区分的概念。
- 王不能吃**有保护的棋子**——「保护」是计算将杀与战术的基础工具。
- 判定顺序口诀：**先查自己的王，再查对方的王；先看是否被将，再看有无路可走。**
