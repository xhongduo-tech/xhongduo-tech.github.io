## 为什么从责任认定的规则与划分开始

事故调查取证的全部努力，最终都汇到一句话上：**谁的责任？各担几分？**

道路交通事故责任认定，就是公安交管部门根据证据，判断各方行为对事故发生的作用与过错程度，进而划分责任。它是事故处理的「判决书式的中间产品」——直接影响赔偿比例、行政处罚与保险理赔。

<span class="marginnote">责任认定遵循<strong>过错责任原则</strong>：看「行为 + 过错 + 因果」，而不是「谁伤得重谁有理」。这是交通法区别于「结果责任」的核心——没有过错的合法驾驶方，即使碰撞了也未必担责；反而伤情重但违法的一方，可能因过错承担主要甚至全部责任。</span>

本篇把认定规则讲清，下一篇再讲承载它的文书——事故认定书及其复核。

## 1 认定规则：过错是责任的唯一来源

责任认定的基本公式是：**当事人的行为 + 该行为对事故所起的作用 + 过错的严重程度 → 责任等级**。

据此，责任划分为四档：**全部责任、主要责任、同等责任、次要责任**。规则如下（《道路交通事故处理程序规定》第 60 条）：

- 因**一方**当事人过错导致事故的，该方承担**全部责任**；
- 因两方以上当事人过错导致事故的，按各自行为对事故发生的作用及过错严重程度，分别承担**主要、同等、次要**责任；
- 各方均无过错、属于**交通意外事故**的，各方均**无责任**；
- **一方故意**造成事故的，他方无责任。

有两类情形会触发**推定责任**：发生事故后**逃逸**、或者**故意破坏、伪造现场、毁灭证据**，导致事故事实无法查明的，通常推定该方承担全部责任——法律用「逃逸即全责」倒逼当事人留下配合调查。

<span class="marginnote">「交通意外事故」（如突发的轮胎爆裂、突发的机械故障且无过错）是一个容易误读的情形：无责任不等于不赔偿——在民事赔偿上，机动车与行人、非机动车之间即使机动车无责，也要承担不超过 10% 的赔偿责任。「责任」与「赔偿」在这里是两个概念。</span>

## 2 机动车之间的责任划分

机动车之间发生事故，适用最纯粹的过错比例分担。常用参考比例如下（司法实践通行标准）：

| 责任等级 | 赔偿比例 |
| --- | --- |
| 全部责任 | 100% |
| 主要责任 | 70% |
| 同等责任 | 50% |
| 次要责任 | 30% |

常见情形的责任判断：**追尾**一般由后车承担全部或主要责任（未保持安全车距）；**变道**引发的事故，变道方通常承担全部或主要责任（未确认安全即变更车道）；**转弯与直行**相撞，转弯方负主要以上责任；**倒车**、**逆行**、**掉头**方制造冲突，一般承担主要以上责任。

<span class="marginnote">这些「习惯性判断」并非法定条文，而是法院与交管部门长期实践形成的裁量惯例——具体到个案，仍须回到现场证据重新衡量。记住这一点，你就不会把「追尾必后车全责」之类的经验当作不可推翻的定律。</span>

## 3 机动车与非机动车、行人的特殊规则

机动车与非机动车驾驶人、行人之间发生事故，适用《道路交通安全法》第 76 条的特殊规则，体现「倾斜保护」：

**非机动车、行人无过错的**，由机动车一方承担赔偿责任。

**非机动车、行人有过错的**，根据过错程度适当减轻机动车一方的赔偿责任——即「过错相抵」。

**机动车一方没有过错的**，承担**不超过 10%** 的赔偿责任。

**损失系非机动车、行人故意碰撞机动车造成的**，机动车一方不承担赔偿责任——这就是「碰瓷」不赔的法律依据。

<span class="marginnote">「机动车无责也要赔不超过 10%」常让人困惑：既然无责为何还赔？原因是行人、非机动车是弱势方，机动车运行本身带有风险，法律让机动车承担一个「无过错下的有限责任」作为社会风险的再分配。而「故意碰撞不赔」则切断了把交通事故当获利工具的链条。</span>

## 4 公式解析：责任比例如何换算成赔偿承担

责任认定的结果最终要落到赔偿数额上，换算公式可以拆成三步：

$$P_{\text{自担}} = P_{\text{损失总额}} \times r_{\text{责任比例}} - P_{\text{保险先行赔付}}$$

- **第一步，定责任比例 $r$**：机动车之间按 100%/70%/50%/30% 取档；机动车与行人之间，机动车方在实践中的常用档位为全责 100%、主责 80%、同责 60%、次责 40%、无责不超 10%。
- **第二步，先让保险赔付**：优先由交强险在限额内赔付，不足部分由商业三者险按责任比例承担，仍不足的由责任人自担。
- **第三步，算自担额**：用损失总额减去保险已赔部分，再乘以剩余的责任比例，即得最终自担金额。

举一个算例：机动车与行人事故，损失总额 20 万元，机动车负主要责任（实践比例 80%）。交强险在死亡伤残、医疗费用等限额内先行赔付约 10 万元后，剩余 10 万元由机动车按 80% 承担 8 万元，其余 2 万元由行人自担——这就是「责任比例 + 保险优先」的完整链条，后续《损害赔偿范围》《调解、诉讼与保险理赔》两篇会分别展开两端。

## 5 术语速查表：责任认定术语

| 术语 | 定义要点 |
| --- | --- |
| 过错责任 | 依行为、过错、因果定责 |
| 全部责任 | 一方过错，担 100% |
| 主要责任 | 实践中机动车之间担 70% |
| 同等责任 | 实践中担 50% |
| 次要责任 | 实践中担 30% |
| 交通意外事故 | 各方无过错，均无责任 |
| 推定责任 | 逃逸、破坏现场致事实不明推全责 |
| 过错相抵 | 弱势方有过错则减轻机动车责任 |
| 无责 10% | 机动车无责也承担不超 10% |
| 故意碰撞 | 碰瓷不赔的依据 |

## 6 辨析与常见误区

**误区一：以为「责任就是赔偿」。** 责任认定是行政判断，赔偿是民事责任，二者可分离（无责也赔 10%）。

**误区二：以为「逃逸顶多罚钱」。** 逃逸可推定全责、记分、罚款拘留，构成犯罪还终生禁驾。

**误区三：以为「追尾必后车全责」。** 前车违法变道、急刹等原因导致的追尾，责任可能在前车。

**误区四：以为「比例是铁律」。** 70%/30% 等是实践惯例，个案仍按证据重新裁量。

## 延伸阅读与实务提示

理解责任认定，最实用的是把它当「证据游戏」来看：谁的主张有证据支撑，谁就占据主动。行车记录仪、监控录像、现场照片、刹车痕鉴定、车速鉴定，每一样都是影响责任划分的砝码。平时养成保留行车记录的习惯，关键时刻价值千金。

还有一个观念值得校正：责任认定不是「定对错」，而是「分风险」。即使是双方都有过错的碰撞，法律也要按过错程度分出主次，让赔偿有据可依。这种「过错相抵」的精细划分，正是交通法与「谁伤谁有理」的朴素观念最大的不同。

- 责任认定是证据游戏，行车记录与现场证据是关键砝码。
- 责任认定不是定对错，而是按过错程度分风险。
- 双方都有过错也要分出主次，避免「谁伤谁有理」。

## 7 小结

- 责任认定遵循**过错责任原则**，依据行为作用与过错程度划分全部、主要、同等、次要责任。
- 交通意外事故各方无责任；一方故意造成的，他方无责任；**逃逸或破坏现场导致事实不明，推定全责**。
- 机动车之间按 100%/70%/50%/30% 比例分担；机动车与行人之间，无责也须承担不超过 10%。
- 非机动车、行人故意碰撞机动车的，机动车不承担赔偿责任。
- 责任比例最终通过「保险先行赔付 + 按比例自担」落实到赔偿数额。
- 「责任」与「赔偿」是两个概念，无责不等于不赔。
