## 为什么从职责分工开始

上一篇我们确立了这部法律的坐标与原则，但要理解一条路、一辆车、一个路口背后到底谁在管，必须回答「谁来管、怎么分工」。

行政法有个基本命题叫**职权法定**：行政机关的权力边界由法律规定，越权无效、缺位失责。

<span class="marginnote">《道路交通安全法》第五条正是职权法定的具体化：国务院公安部门负责全国道路交通安全管理工作，县级以上地方各级人民政府公安机关交通管理部门负责本行政区域内的道路交通安全管理工作。注意「公安机关交通管理部门」是专门机关，与「公安机关」是隶属而非同一概念。</span>

把职责分工理清，后面读处罚、读事故处理时，你才能判断某个环节该由谁负责、程序是否合法——这是把交通法当「可检验的系统」来读的关键一步，也是与《宪法》关于国务院职权的规定、《行政诉讼法》被告资格判断一脉相承的知识点。

## 1 谁是最主要的执法主体

**国务院公安部门**（公安部）负责**全国**的道路交通安全管理工作，制定部门规章与全国统一的执法标准——例如 2022 年 4 月 1 日施行的《道路交通安全违法行为记分管理办法》就是公安部制定并发布的。

**县级以上地方各级人民政府公安机关交通管理部门**负责**本行政区域内**的道路交通安全管理工作。

这里的「县级以上」是硬性资格门槛：乡镇派出所、街道警务室不是独立的交通管理执法主体，不能以自己的名义作出吊销驾驶证这类处理决定。

<span class="marginnote">执法主体资格在行政复议与行政诉讼中是首查项：处罚决定书必须盖有具备主体资格的机关印章，主体不适格，处罚即告无效。这与我们后期《行政处罚的救济》一篇中「程序违法即可撤销」的判断逻辑直接相连。</span>

## 2 交通警察的现场职责

《道路交通安全法》第八十条至第八十五条勾勒了交通警察执行职务时的具体职权与义务，核心包括：

**指挥与疏导**：维护道路交通秩序，在易堵点、高峰时段进行疏导。交通警察现场指挥与交通信号不一致时，**应当服从交通警察的指挥**——这是通行规则里「人优于信号」的例外条款。

**违法查处**：发现交通违法行为，有权当场纠正、警告、罚款，或依法采取扣留车辆、扣留驾驶证等行政强制措施。

**事故处理**：接到事故报警后，立即赶赴现场，组织抢救受伤人员、勘查现场、收集证据、制作事故认定书。

**登记与检验**：负责机动车的注册登记、变更登记、抵押登记等车辆业务，以及驾驶证的申领、审验、换证、记分管理。

同时法律也对执法者设了硬约束：佩戴人民警察标志、持有人民警察证件，亮证执法。

对车辆实施检查、处罚时不得违法扣留车辆证件；严禁下达罚款指标、以罚代管。这些约束是《道路交通安全法》第六章「执法监督」的制度内容。

## 3 其他部门的协同职责

道路交通安全管理从来不是交警一家的事。法律和相关规章把「齐抓共管」写成了明确的职责清单：

**交通运输主管部门**：负责公路建设、养护、标志标线等公路设施的规划与维护，以及道路运输经营、驾驶员培训机构的行业管理。公路损毁未及时修复导致事故，交通部门要承担相应管理责任。

**住房城乡建设部门**：负责城市道路及其附属设施的建设与维护，包括城市道路、桥梁、隧道的规划建设。

**教育、市场监管、应急管理等部门**：校车安全管理由教育、公安、交通运输等部门协同；机动车生产企业与产品准入由市场监管部门把关；危险品运输的源头监管涉及应急管理部门。

**卫生健康部门**：负责事故伤员的院前急救与医疗救治，交通事故救助基金垫付抢救费用的审核也与之衔接。

此外，乡镇人民政府、村（居）民委员会在乡村道路安全宣传、隐患排查中也承担协助义务——乡村道路交通安全治理正越来越依赖这种「行政主导 + 基层协同」的模式。

<span class="marginnote">一辆校车从生产到上路，至少横跨市场监管（合格证）、公安（注册登记与年检）、教育（校车使用许可）、交通运输（驾驶人资质）四个部门——多部门分工意味着事故调查时要分辨「管理失职发生在哪个环节」，这正是《道路交通事故处理程序规定》里调查取证需要查清的内容。</span>

## 4 核心对比表：各管理环节的职责主体

把车辆从「出厂」到「报废」的生命周期摊开，每一环对应不同的主管机关：

| 管理环节 | 主管机关 | 典型事项 |
| --- | --- | --- |
| 车辆生产准入 | 工业和信息化、市场监管部门 | 车型公告、合格证、缺陷召回 |
| 车辆登记与检验 | 公安机关交通管理部门 | 注册登记、转移登记、安全技术检验 |
| 驾驶人管理与记分 | 公安机关交通管理部门 | 驾驶证申领、审验、记分、满分学习 |
| 道路建设与养护 | 交通运输、住房城乡建设部门 | 公路与城市道路建设、标志标线维护 |
| 道路运输经营 | 交通运输部门 | 营运许可、驾驶员从业资格、驾培机构 |
| 事故处理与责任认定 | 公安机关交通管理部门 | 现场处置、调查取证、认定书制作 |
| 伤员救治 | 卫生健康部门 | 院前急救、抢救费用审核 |
| 校车管理 | 教育、公安、交通运输部门 | 校车使用许可、校车标牌核发 |

这份表格说明：交通管理是一个**多主体协同**的系统。如果某个环节失管，责任并不必然落在交警身上，而要看法定职责落在谁的名下——这是行政责任认定与内部追责的前提。

还需要留意**综合执法改革**带来的边界调整：在部分城市，人行道违法停车、占道经营等事项的执法已划归城市管理综合执法部门，与交警执法形成互补。遇到具体纠纷，先确认「这一事项当时归哪个部门管」，再谈责任归属。

## 5 术语速查表：执法主体相关术语

| 术语 | 定义要点 |

| 公安部 | 国务院公安部门，负责全国道路交通安全管理 |
| 公安机关交通管理部门 | 交警系统，负责本辖区道路交通管理的专门机关 |
| 县级以上 | 执法主体资格门槛，乡镇派出所不具独立主体资格 |
| 职权法定 | 行政权须有法律依据，越权无效、缺位失责 |
| 交通警察 | 交警系统执法人员的通称，须亮证执法 |
| 行政强制措施 | 扣车、扣证、拖移等临时性管控手段 |
| 执法监督 | 《道路交通安全法》第六章，约束执法行为 |

## 6 辨析与常见误区

**误区一：以为交警就是唯一管理者。** 道路、运输、校车、救援分别由不同部门负责，「出事只找交警」有时找错了对象。

**误区二：以为乡镇派出所也能独立处罚。** 没有独立主体资格，越权作出的处罚在行政复议、行政诉讼中可能被撤销。

**误区三：混淆「执法机关」与「执法者个人」。** 处罚决定以机关名义作出、盖机关公章，行政复议与诉讼的被告是机关而非交警个人。

**误区四：把强制措施当成处罚。** 扣车是调查与制止的手段，不是最终处罚；最终处罚还要看是否有违法行为及相应罚则。

## 7 小结

- 公安部负责全国道路交通管理，县级以上地方公安机关交通管理部门负责本辖区管理，**主体资格以「县级以上」为界**。
- 交通警察的现场职权包括指挥疏导、违法查处、事故处理、车辆与驾驶人管理四项。
- 交通警察现场指挥与信号灯不一致时，**以现场指挥为准**。
- 交通运输、住建、教育、应急、卫生健康等部门在各自职责范围内协同管理，形成多主体体系。
- 理解职责分工，是判断执法主体适格、处罚程序合法、行政救济对象正确的前提。
- 执法监督与便民措施，是「依法管理 + 方便群众」两项原则的制度落地。
