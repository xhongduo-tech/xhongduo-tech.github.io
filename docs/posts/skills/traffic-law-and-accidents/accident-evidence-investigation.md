## 为什么从调查、勘验与取证开始

事故处理最核心的问题只有一个：**事发时到底发生了什么？**交警不在现场、当事人各执一词、证人记忆模糊，还原真相只能靠证据。

调查、勘验与取证，就是把散落在现场、车辆、仪器、记忆里的证据系统性地收集、固定、检验的过程——它是责任认定的原料车间。

<span class="marginnote">交通事故调查遵循「全面、客观、及时」三原则：痕迹会消失、伤情会变化、记忆会模糊，所以现场勘查必须第一时间进行，取证必须覆盖尽可能多的证据类型。对于逃逸案件，还要通过排查车辆、调取监控把「谁撞的」追查出来——这决定了整个调查阶段的节奏。</span>

作为当事人，理解取证规则不仅能配合调查，更能在事故处理中维护自身合法权益。

## 1 现场勘验：把现场「搬进」卷宗

现场勘验是调查的第一步，目标是**把稍纵即逝的现场状态完整固定下来**。交警到达现场后，会进行一系列固定动作：

**现场勘查**：查看道路状况、车辆相对位置、撞击痕迹、刹车痕、散落物、血迹等，确定碰撞点与车辆行驶轨迹。

**现场照相、摄像**：多角度、多距离拍摄现场全景与局部特写，是最直观的现场证据。

**现场绘图**：绘制现场图，标注道路、车辆、痕迹的尺寸与相对位置——现场图是事故卷宗的「三维地图」。

**提取痕迹物证**：提取车辆漆片、散落物、轮胎印模、纤维等微量物证，为技术鉴定提供样本。

<span class="marginnote">为什么当事人被要求「保护现场」？因为痕迹是易失的证据：一场雨、一次车辆移动、围观者踩踏，都可能抹掉碰撞点的原始状态。现场勘查报告据此认定的事实，在事故认定书中具有很高的证明力。</span>

现场勘验完毕后，应当制作现场勘查笔录，由勘查人员与相关当事人签名确认。

## 2 调查询问：向人要证据

除了「向物取证」，调查还要「向人取证」：

**询问当事人**：分别询问各方当事人事发经过、行驶状态、操作动作，制作询问笔录；笔录由被询问人核对后签名。

<span class="marginnote">询问笔录是言词证据中证明力较强的一种。当事人在笔录中的陈述前后矛盾，往往会被认定为陈述不实，从而影响对其过错的认定。所以交警常提示当事人「实事求是，有就是有、没有就是没有」。</span>

**询问证人**：寻找目击者取证，证人证言可以交叉印证各方陈述。

**收集视听与电子数据**：调取行车记录仪视频、道路监控录像、ETC 通行记录、GPS 轨迹、手机通话记录等电子数据——在现代交通里，这些「机器记忆」往往比人的记忆更可靠。

## 3 检验鉴定：让数据说话

许多争议焦点无法用肉眼判断，必须交给专业鉴定：

**车速鉴定**：根据制动痕迹长度、车辆变形、监控视频帧分析，推定事发时车速——超速与否常常靠它定案。

**酒精检测**：现场呼气式酒精检测；涉嫌醉驾的，抽血送检，以血液酒精含量为准。这是酒驾、醉驾认定的法定证据链。

**车辆安全性能检验**：检测车辆制动、转向、灯光等是否合格——机械故障引发的事故，车辆鉴定是定责前提。

**人体损伤与伤残鉴定**：评估伤情严重程度，为责任与赔偿提供依据。

检验、鉴定由具备资质的鉴定机构进行，一般应当在 **30 日内**完成；特殊情况经批准可以延长至 **60 日**。检验鉴定期限直接影响事故认定书的制作时间，这也是为什么有些事故认定书要等较长时间才能拿到。

<span class="marginnote">「等鉴定结果」往往是事故处理中最难熬的阶段：认定书要等检验鉴定结论确定后才出具。对当事人来说，耐心配合鉴定、留存自己的证据（行车记录仪原视频、现场照片），是这段时间最该做的事。</span>

## 4 核心对比表：事故证据的七大类

诉讼与行政程序中对证据实行「分类管理」，各类证据的取证要点各异：

| 证据类型 | 典型形式 | 取证要点 |
| --- | --- | --- |
| 物证 | 车辆残件、散落物、血迹 | 提取时保持原状、封存保管 |
| 书证 | 驾驶证、行驶证、保险单 | 核实真伪与时效 |
| 证人证言 | 目击者陈述 | 分别询问、交叉印证 |
| 当事人陈述 | 各方陈述笔录 | 核对签名、记录矛盾 |
| 鉴定意见 | 车速、酒精、伤残鉴定书 | 鉴定机构须具备资质 |
| 勘验、现场笔录 | 现场勘查笔录、现场图 | 由勘查人、当事人签名 |
| 视听资料、电子数据 | 行车记录仪、监控、GPS | 保留原始载体、提取完整 |

所有证据**必须查证属实**，才能作为认定事实的根据——这是证据规则的底线，也是当事人对不实证据提出异议的法律依据。

## 5 术语速查表：证据与取证术语

| 术语 | 定义要点 |
| --- | --- |
| 现场勘查 | 对事故现场的检查与记录 |
| 现场图 | 标注车辆、痕迹位置的图纸 |
| 痕迹物证 | 漆片、散落物、轮胎印等 |
| 询问笔录 | 对当事人、证人的记录 |
| 电子数据 | 行车记录仪、监控、GPS 等 |
| 车速鉴定 | 推定事发时车速的鉴定 |
| 酒精检测 | 呼气初筛、抽血定案 |
| 鉴定时限 | 一般 30 日、最长 60 日 |
| 查证属实 | 证据可作定案根据的前提 |

## 6 辨析与常见误区

**误区一：以为「行车记录仪是拍违法用的」。** 它是事故定责最有力的证据之一，应保留原始存储并备份。

**误区二：以为「笔录签了就不能改」。** 笔录须如实，事后发现与事实不符可申请补充说明，但反复改口会影响可信度。

**误区三：以为「鉴定结果一定准」。** 对鉴定意见有异议可申请重新鉴定，但要有合理依据。

**误区四：以为「证据只有人证」。** 电子数据、痕迹物证往往比人证更客观可靠。

## 7 小结

- 现场勘验通过**勘查、照相、绘图、提取痕迹**把现场状态完整固定下来。
- 调查取证覆盖**当事人、证人、视听资料、电子数据**四路来源，笔录须核对签名。
- 车速、酒精、车辆性能、伤残等争议点靠**专业鉴定**解决，检验鉴定一般 30 日内完成、最长 60 日。
- 证据分七大类，全部须**查证属实**方可作为定案根据。
- 理解取证规则，当事人在配合调查时才能保护自己的合法权益。
- 「全面、客观、及时」三原则贯穿调查取证全程。
