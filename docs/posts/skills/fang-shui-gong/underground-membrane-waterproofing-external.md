# 地下卷材防水层：外防外贴与外防内贴施工

<div class="epigraph">
<p>把防水层贴在结构外面，让水连结构的边都摸不着——这是地下防水最朴素也最有效的智慧。</p>

## 为什么地下卷材要「外防」

上一篇的砂浆防水层做在结构内侧，是「背水面设防」——结构已经泡水，砂浆只是兜住渗漏。而**卷材防水层**的主流做法是「**外防**」：把卷材贴在结构外侧（迎水面），让水在接触结构之前就被挡住。<span class="marginnote">GB 50208 第6章「卷材防水层」规定了地下卷材的铺贴。外防分两种做法——<strong>外防外贴</strong>（先做结构再做卷材）与<strong>外防内贴</strong>（先做卷材再做结构）。名字只差两个字，施工顺序完全不同，是地下防水最经典的「同词反义」。</span>这一节把两种做法讲清。

## 1 外防外贴法：先结构、后卷材

**外防外贴法**：在地下结构（底板、侧墙）施工完成后，在结构**外侧表面**铺贴卷材防水层的施工方法。

**施工顺序**：

1. 浇筑底板垫层，在垫层上铺贴**底板卷材**。
2. 底板卷材外留出**甩槎**（预留搭接边），做保护层。
3. 浇筑底板、侧墙混凝土。
4. 拆模后，在侧墙外侧**由下向上铺贴卷材**，与底板甩槎搭接。
5. 卷材外侧设**保护层**（如砖砌保护墙或砂浆），防止回填土损伤卷材。

**外防外贴的优点**：

- 卷材在结构外表面，**迎水面设防**，最可靠。
- 结构侧墙平整度好，卷材铺贴质量有保证。
- 便于检查、便于修补。

<span class="marginnote">「甩槎」是外防外贴的关键手艺：底板卷材先铺，侧墙卷材后铺，两者在<strong>转角处搭接</strong>——底板卷材要留出足够的搭接余量（甩槎）并做临时保护，待侧墙卷材铺贴时接上去。<strong>甩槎留不足，转角搭接不够，就是地下渗漏的高发点</strong>。</span>

**辨析｜易错点：** 外防外贴的侧墙卷材铺贴方向**由下向上**：先贴底部再贴上部，让上层卷材压住下层，雨水沿卷材表面下流时不钻进搭接缝。**铺贴方向反了，水会沿缝倒灌**——这与屋面「顺水搭接」是同一个原理。

## 2 外防内贴法：先卷材、后结构

**外防内贴法**：在基坑支护结构（或垫层、围护墙）内表面先铺贴卷材防水层，再浇筑结构混凝土的施工方法。

**施工顺序**：

1. 在基坑支护结构（围护桩、挡土墙）内表面铺贴卷材。
2. 卷材表面做保护层（或直接在卷材上浇筑结构）。
3. 浇筑底板、侧墙混凝土，混凝土紧贴卷材形成结构。

**外防内贴的优点**：

- 卷材铺贴在支护结构上，**无需侧墙外侧留作业面**，适合**深基坑、场地狭小**的情况。
- 卷材先做，支护结构防水与结构防水合一。

**外防内贴的代价**：

- 支护结构表面不平整，卷材铺贴质量难保证。
- 卷材在结构外侧但**与结构之间隔了支护**，一旦结构沉降变形，卷材易被撕裂。
- 卷材被混凝土「埋」在支护与结构之间，**无法检查与修补**。

<span class="marginnote">一句话区分两种方法：<strong>外防外贴是「结构先把形，卷材来打扮」；外防内贴是「卷材先站岗，结构来填充」</strong>。外贴质量好、可修补；内贴省场地、深基坑适用。<strong>能用外贴就外贴，场地不允许才内贴</strong>——这是地下卷材选法的总原则。</span>

**辨析｜易错点：** 外防内贴的卷材**与结构之间要隔离**：卷材铺在支护结构上，浇筑混凝土时混凝土直接压贴卷材，可能把卷材顶起、损坏。做法是卷材外设**保护层**或使混凝土与卷材脱离——**「贴」的是支护，不是结构**，这个关系别搞混。

## 3 两种方法对比与选择

把两种外防做法摆在一起，差异一目了然：

| 对比项 | 外防外贴 | 外防内贴 |
| --- | --- | --- |
| 施工顺序 | 先结构、后卷材 | 先卷材、后结构 |
| 卷材位置 | 结构外表面（迎水面） | 支护结构内侧 |
| 基层 | 结构表面，平整 | 支护表面，难平整 |
| 可检修性 | 好，可检查修补 | 差，埋藏无法检修 |
| 适用场景 | 场地开阔、浅基坑 | 深基坑、场地狭小 |
| 可靠性 | 高 | 较低（受支护影响） |

**选择逻辑**：**场地条件允许时，优先外防外贴**——迎水面设防、质量可控、可检修。外防内贴是深基坑、场地受限时的「妥协方案」，使用时靠加强构造弥补其不可检修的短板。<span class="marginnote">如果把防水比作「穿雨衣」：外防外贴是「把雨衣穿在外面」，外防内贴是「把雨衣穿在衣服里面」——<strong>穿在外面挡雨，穿在里面防潮</strong>。地下卷材能「穿外面」就绝不「穿里面」。</span>

**辨析｜易错点：** 无论外贴内贴，**底板卷材与侧墙卷材的转角搭接、阴阳角附加层**都要做好——这是地下卷材渗漏最集中的地方。地下室的漏水，十有八九在「角」上，附加层与搭接是角上的两条命门。

## 4 核心要点：地下卷材速查

本节为纯概念工艺主题，用「核心对比表」替代公式解析（按编辑章程第 5 条）。

| 控制项 | 要求 |
| --- | --- |
| 设防位置 | 优先外防（迎水面） |
| 外防外贴 | 先结构后卷材，侧墙由下向上铺，留甩槎搭接 |
| 外防内贴 | 先卷材后结构，用于深基坑，卷材与结构隔离 |
| 转角/阴阳角 | 做附加层，卷材转折顺滑 |
| 搭接 | 底板甩槎与侧墙接槎严密 |
| 保护层 | 卷材外侧设保护层，防回填土损伤 |

一句话记忆：**外贴先结构、内贴先卷材；能用外贴就外贴，转角附加层、甩槎接槎要严密，保护层兜底。**

### 常见问题速答

**问：外防外贴的「甩槎」是什么意思？**
答：底板卷材先铺，侧墙卷材后铺，两者要在转角处搭接——底板卷材伸出一段搭接余量（甩槎）做临时保护，待侧墙卷材铺贴时接上去。**甩槎留不足，转角搭接不够，就是地下渗漏的高发点**。

**问：为什么侧墙卷材要由下向上铺？**
答：让上层卷材压住下层——雨水沿墙面下流时，顺着搭接缝往外走，不钻进缝里。**铺贴方向反了，水会沿缝倒灌**，这与屋面「顺水搭接」是同一个原理。

**问：外防内贴的卷材和结构之间要不要隔离？**
答：要。卷材贴在支护结构上，浇筑混凝土时直接压贴卷材会顶起、损坏——卷材外设保护层或使混凝土与卷材脱离。**「贴」的是支护，不是结构**，这个关系别搞混。

**问：地下卷材渗漏为什么多半在「角」上？**
答：转角处卷材要转折、要搭接、要受力——底板与侧墙的转角是几何与工艺的双重薄弱点。**转角做附加层、转折顺滑、搭接严密**，是地下卷材防水的三条命门。

### 地下卷材外防的做法选择

| 条件 | 推荐 |
| --- | --- |
| 场地开阔、浅基坑 | 外防外贴 |
| 深基坑、场地狭小 | 外防内贴 |
| 要求可检修 | 外防外贴 |

一句话记忆：**外贴先结构、内贴先卷材；能用外贴就外贴，转角附加层、甩槎接槎要严密，保护层兜底。**

## 5 小结

- 地下卷材防水层做在**迎水面（结构外侧）**最可靠，这是地下防水第一原则。
- **外防外贴**：先结构、后卷材，侧墙**由下向上**铺贴，底板留甩槎与侧墙搭接，可检查可修补。
- **外防内贴**：先卷材、后结构，用于**深基坑、场地狭小**，但卷材埋藏不可检修、受支护影响大。
- 选择逻辑：**场地允许优先外贴**；内贴时卷材与结构之间做隔离保护。
- 转角、阴阳角附加层与底板甩槎、侧墙接槎是地下卷材渗漏高发点，必须重点把守。
