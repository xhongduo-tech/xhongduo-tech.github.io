# 防水工（建筑防水施工）

以《国家职业技能标准—防水工》为纲，结合 GB 50207《屋面工程质量验收规范》与 GB 50208《地下防水工程质量验收规范》，系统重建从防水材料、屋面与地下防水施工、卫生间等室内节点处理到质量验收与渗漏治理的完整建筑防水技能体系。学完这些章节，就写完了屋面、地下与室内防水施工所需的全部内容。

## 对标教材

- 《国家职业技能标准—防水工》
- GB 50207《屋面工程质量验收规范》
- GB 50208《地下防水工程质量验收规范》
