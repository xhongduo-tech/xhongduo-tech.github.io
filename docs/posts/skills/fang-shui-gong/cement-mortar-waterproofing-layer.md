## 为什么砂浆也能防水

地下防水的「柔」字辈——卷材、涂料——前几篇讲了不少，这一篇看「刚」字辈的另一种做法：**水泥砂浆防水层**。它不用卷材、不刷涂料，而是把水泥砂浆通过**外加剂与层层抹压**做得足够密实，靠「自身致密」来防水。它便宜、施工简便、与结构同材性（同为水泥基，粘结好），多用于**结构内侧、背水面**的防水与修补加固。<span class="marginnote">GB 50208 第5章「水泥砂浆防水层」规定：掺外加剂或掺合料的水泥砂浆防水层厚度一般为 18~20 mm，掺聚合物的水泥砂浆防水层厚度一般为 6~8 mm。砂浆防水的底气在于「<strong>压实、压光、压出密实度</strong>」——它不是刷上去的，是压出来的。</span>

## 1 水泥砂浆防水层的原理与类型

**水泥砂浆防水层（cement mortar waterproofing layer）**：以水泥、砂、水并掺入外加剂（防水剂、膨胀剂）或聚合物乳液，经拌合、分层抹压形成的刚性防水层。

它防水的三条机理：

**降低孔隙**：掺外加剂（如防水剂）改善砂浆和易性、减少多余水分蒸发留下的孔隙。
**补偿收缩**：掺膨胀剂产生微膨胀，补偿砂浆硬化收缩，减少开裂裂缝。
**压密实**：分层抹压、反复压实压光，把砂浆「压」得致密，毛细通道被挤压闭合。

**两种类型**：

- **掺外加剂水泥砂浆**：掺防水剂/膨胀剂，性能均衡、造价低，是主流。
- **聚合物水泥砂浆**：掺聚合物乳液（如苯丙乳液），粘结强、抗裂好、厚度薄（6~8 mm），用于修补与要求较高的部位。

<span class="marginnote">砂浆防水层与卷材涂料最大的不同是「<strong>同材质、无接缝、贴得牢</strong>」：它和混凝土结构都是水泥基，粘结如一体，不空鼓、不翘边。但它也「刚」——<strong>结构一变形开裂，砂浆跟着裂</strong>，所以它适合变形小的部位，不能用于有较大变形或受振动的部位。</span>

**辨析｜易错点：** 水泥砂浆防水层不是「抹一层普通砂浆就行」：普通砂浆孔隙多、干缩大，根本不防水。**必须掺外加剂或聚合物，并按工艺分层抹压**——「普通砂浆冒充防水层」是刚性防水最典型的偷工减料。

## 2 材料与配合比要求

水泥砂浆防水层的材料，把关比普通抹灰严：

**水泥**：宜用普通硅酸盐水泥，强度等级不低于 42.5；不得使用过期、受潮结块水泥。
**砂**：宜用中砂，含泥量不大于 1%，颗粒级配良好。
**水**：洁净水，不含油污与杂质。
**外加剂**：防水剂、膨胀剂等，品种与掺量按试验确定，与水泥适应性要检测。

**配合比**：水泥砂浆防水层的配合比，一般**水泥:砂 ≈ 1:2.5~1:3（体积比）**，水灰比 0.5~0.6（视稠度）。外加剂掺量按产品要求并经试配——**先试配、后施工**，是外加剂砂浆的铁律。<span class="marginnote">砂浆防水的配合比「宁稠勿稀」：水灰比太大，砂浆收缩大、孔隙多，防水性能直接打折。<strong>砂浆防水是「稠着做」的活</strong>——现场为图好抹而多加水，等于亲手把防水层做成「漏水层」。</span>

**辨析｜易错点：** 外加剂不能「想掺多少掺多少」：防水剂掺少了没效果，掺多了影响强度与和易性。**外加剂掺量以产品说明与试配结果为准**，且要复检其与所用水泥的适应性——不同水泥对外加剂的响应不同，盲目套用别处的掺量会出事。

## 3 分层抹压施工：经典五层做法

水泥砂浆防水层的工艺核心是**分层抹压**。传统「五层做法」是刚性防水的经典：

**第一层：素灰层**——刷 2 mm 左右纯水泥浆（素浆），填实基层孔隙，与结构粘结。
**第二层：水泥砂浆层**——抹 4~5 mm 水泥砂浆，压实。
**第三层：素灰层**——再刷一层素浆，封闭砂浆层表面孔隙。
**第四层：水泥砂浆层**——再抹一层水泥砂浆，压实。
**第五层：素灰层**——抹压最后一层素浆并压光，形成光滑致密的面层。

**施工流程六步**：

1. **基层处理**：结构表面凿毛、清理浮渣、充分湿润（砂浆防水要求基层湿润无明水）。
2. **阴阳角做圆弧**：阴阳角做成圆弧，避免砂浆在直角处开裂。
3. **分层抹压**：素灰与砂浆交替，一层压实后再做下一层。
4. **压光**：最后一层素浆压光，表面密实光滑。
5. **养护**：抹压完成后**保湿养护不少于 7 天**，防止早期失水开裂。
6. **验收**：检查厚度、空鼓、裂缝。

<span class="marginnote">「五层做法」的奥秘在「<strong>素灰夹砂浆</strong>」：素灰填孔、砂浆承力，交替分层让每层都致密。<strong>现代施工常简化为「三遍素浆 + 两遍砂浆」的组合，但交替分层、逐层压实的原理不变</strong>——层数可以变，交替压实的规矩不能丢。</span>

**辨析｜易错点：** 砂浆防水最怕「一层抹完等干透再抹下一层」：层间失水粘结不良，会出现「夹层」，一敲就空鼓。**各层要在前一层「收水」后随即抹压**——趁湿衔接，层间才能融为一体，这是「分层」工艺的命门。

## 4 核心要点：砂浆防水层速查

本节为纯概念工艺主题，用「核心对比表」替代公式解析（按编辑章程第 5 条）。

| 对比项 | 掺外加剂水泥砂浆 | 聚合物水泥砂浆 |
| --- | --- | --- |
| 防水机理 | 外加剂降孔+压实 | 聚合物成膜+抗裂 |
| 厚度 | 18~20 mm | 6~8 mm |
| 粘结/抗裂 | 较好 | 强 |
| 造价 | 低 | 较高 |
| 主要用途 | 地下结构内侧防水 | 修补、高要求部位 |

| 施工要点 | 要求 |
| --- | --- |
| 配合比 | 水泥:砂 ≈ 1:2.5~3，先试配 |
| 基层 | 凿毛、清理、湿润无明水 |
| 分层 | 素灰与砂浆交替，趁湿抹压 |
| 阴阳角 | 做圆弧 |
| 养护 | 保湿养护 ≥7 天 |

一句话记忆：**砂浆防水靠压实，素灰夹砂浆、一层压一层；配合比先试配，基层湿润做圆弧，养护七天莫失水。**

### 常见问题速答

**问：砂浆防水层能替代卷材防水层吗？**
答：不能。砂浆防水层是刚性、抗裂能力弱，适合变形小的部位与结构内侧；卷材防水层柔性、适应变形，用于迎水面与大面。两者是「分工」不是「替代」——刚柔结合才是地下防水。

**问：砂浆防水层刷多厚才算防水？**
答：掺外加剂砂浆 18~20 mm、聚合物砂浆 6~8 mm——这是「防水层」的厚度，不是抹灰的厚度。普通抹灰 5 mm 厚不防水，抹再厚没掺外加剂也不防水。

**问：砂浆防水层要不要养护？**
答：必须养。砂浆防水层靠「压密实」防水，早期失水就收缩开裂、孔隙增多——**保湿养护不少于 7 天**是底线。赶工期不养护，等于亲手把防水层做成漏水层。

**问：砂浆防水层空鼓了怎么办？**
答：查出空鼓范围，铲除空鼓部分，重新凿毛、湿润、分层抹压——空鼓处砂浆与基层脱离，不防水还藏水。修补用同配比、同工艺，别「贴个补丁」糊弄。

### 刚性防水与柔性防水对比

| 对比项 | 刚性（砂浆） | 柔性（卷材/涂料） |
| --- | --- | --- |
| 适应变形 | 弱 | 强 |
| 施工 | 抹压 | 铺贴/涂刷 |
| 常用部位 | 结构内侧 | 迎水面 |
| 造价 | 低 | 较高 |
| 共同点 | 都要养护/保护 | 都要养护/保护 |

一句话记忆：**砂浆防水靠压实，素灰夹砂浆、一层压一层；配合比先试配，基层湿润做圆弧，养护七天莫失水。**

## 5 小结

- **水泥砂浆防水层**是刚性防水：掺外加剂/聚合物 + 分层抹压，靠自身密实挡水，多用于结构内侧与背水面。
- 两种类型：**掺外加剂砂浆 18~20 mm**、**聚合物砂浆 6~8 mm**；普通砂浆冒充防水层是典型偷工减料。
- 材料把关：水泥不低于 42.5、中砂含泥量 ≤1%、**外加剂先试配再施工**。
- **五层做法**：素灰与砂浆交替分层抹压，各层**趁湿衔接**，避免空鼓夹层；阴阳角做圆弧。
- 养护：抹压完成**保湿养护 ≥7 天**——砂浆防水的密实度是「养」出来的。
