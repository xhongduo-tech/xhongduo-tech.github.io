## 为什么室内节点要专门开一篇

上一篇讲了室内防水的整体流程，这一篇把最见功力的部分——**细部节点处理**——单独拆开。卫生间里藏着密密麻麻的渗漏隐患：竖着穿越楼板的管道根部、排水的地漏、墙面与地面交界的阴角、墙面的阳角。统计室内渗漏，**管根、地漏、阴角占了大半**——因为水往低处流、往缝里钻，而这些节点恰恰是「缝」和「孔」最集中的地方。<span class="marginnote">《国家职业技能标准—防水工》把管道根部、地漏与阴阳角等细部节点处理列入实操技能。室内节点处理的逻辑与屋面细部一脉相承——<strong>「附加层先行、密封嵌缝、厚度加厚」</strong>，只是尺度更小、要求更精细。</span>这一节把室内三大节点逐个拆开。

## 1 管道根部处理

穿楼板的上下水管道根部，是室内渗漏的「头号现场」：管道与楼板之间留缝、管子热胀冷缩、振动，水顺着管壁往下渗。

**管根处理的完整做法**：

1. **凿槽**：在管根周围把楼板面层凿出环形凹槽（宽深各约 20~30 mm），给密封材料留出嵌填空间。
2. **嵌填密封**：凹槽内嵌填**密封材料或堵漏材料**（堵漏王），封住管与楼板之间的缝隙。
3. **根部附加层**：管根周围 **直径 500 mm 范围**内做「一布三涂」附加层——刷涂料、铺增强布、再覆涂，把管根包严实。
4. **大面衔接**：管根附加层与地面大面涂膜**连续搭接**，不得留缝。

<span class="marginnote">管根附加层的「直径 500 mm」不是随口数字：这个范围足够覆盖管周渗漏可能波及的区域。<strong>附加层要「包住根、连上大面」</strong>——只做管周一圈、不连大面，管根与大面之间会有一条「断层缝」，水照样从断层钻出去。</span>

**辨析｜易错点：** 管根最容易犯「不凿槽直接刷」：管与楼板之间是光滑缝隙，涂料刷不进去、填不实，表面的涂膜一裂就漏。**先凿槽、再嵌填、后附加**——把缝隙「堵实」是管根防水的第一步，涂膜只是第二道保险。

## 2 地漏处理

地漏是卫生间的「排水口」，也是防水的薄弱点：地漏与楼板之间的缝隙、地漏周边的低洼积水，都是渗漏通道。

**地漏处理的要点**：

1. **地漏周密封**：地漏与楼板交接处嵌填密封材料，封严缝隙。
2. **周边附加层**：地漏周围做「一布三涂」附加层，重点加厚。
3. **排水顺畅**：地漏周边找坡，地漏处于最低点，水能排净、不积水。
4. **与大面连续**：地漏附加层与地面涂膜连续搭接。

**辨析｜易错点：** 地漏周边**坡度反向**是常见错误：地漏处反而垫高，水积在周围，长期泡着地漏附加层，迟早渗漏。**做地漏先做坡——地漏最低、排水顺畅**，防水+排水同时解决。

## 3 阴阳角与墙地交界处理

**阴角**（墙面与地面的凹角）与**阳角**（突出墙面/地面的凸角）是涂膜的「转弯处」，最容易开裂与堆料：

**阴角处理**：

- 阴角做成**圆弧或钝角**（用水泥砂浆抹出圆弧），避免涂膜在直角处因收缩开裂。
- 阴角处做附加层，加厚设防——墙角是水最容易「窝」的地方。
- 墙地交界处是阴角的典型，墙面涂膜与地面涂膜在此连续。

**阳角处理**：

- 阳角用**角条或圆弧处理**，防止涂膜在凸角处被磕碰破损。
- 阳角处的涂膜要刷匀，不能过厚堆积（堆积处干燥慢、易开裂）。

**墙地交界（阴角）是室内防水的关键**：墙面防水与地面防水在墙角衔接，若此处断开或搭接不足，水沿墙根渗到墙另一侧。做法是**墙面涂膜下返、地面涂膜上翻，在阴角处连成一体**。<span class="marginnote">阴角是「水最想待的地方」：洗澡水顺墙流下，在墙角积着、泡着。<strong>墙角做圆弧，就是给涂膜一个「平滑的转身」，不让它在直角处绷断</strong>——圆弧的半径看似小，却是阴角防水的命根。</span>

**辨析｜易错点：** 墙地交界的涂膜最怕「两遍分开刷、接口不搭」：先刷完墙面再刷地面，两者在墙角没有重叠，留一条看不见的「接槎缝」。**墙地交界要「一并刷、搭接够」**——墙面下返一段与地面涂膜搭接，接口用附加层覆盖，墙角才浑然一体。

## 4 门槛、门口与其他节点

卫生间还有一个容易被忽略的「出口」——**门口**：

- **门槛石下做防水**：门槛石安装前，门槛下方做防水与挡水处理，防止水沿地面漫出卫生间。
- **门口设挡水条**：门槛石内侧设挡水条，地面蓄水时水被挡在卫生间内。
- **门口墙面防水**：门洞两侧墙面防水上翻，防止潮气外渗。

其他节点还有：**墙面开槽回填处**（水电开槽的槽口先回填再防水）、**排气孔/通风孔**（孔周做防水）。

| 节点 | 关键处理 | 通病 |
| --- | --- | --- |
| 管根 | 凿槽嵌填 + 附加层 | 不凿槽、附加层不连大面 |
| 地漏 | 周密封 + 附加层 + 找坡 | 坡度反向积水 |
| 阴角 | 圆弧处理 + 附加层 | 直角开裂 |
| 阳角 | 角条/圆弧，刷匀 | 堆料开裂 |
| 墙地交界 | 一并刷、搭接够 | 接槎断缝 |
| 门口 | 门槛下防水 + 挡水条 | 水漫出卫生间 |

<span class="marginnote">室内节点处理有一个统一的口诀：<strong>「嵌缝要堵实、转角要圆弧、附加层要包严、搭接要连续」</strong>。四句话放之任何节点皆准——<strong>节点处理不是「记工艺」，是「懂逻辑」</strong>，逻辑通了，没见过的节点也能临场应对。</span>

**辨析｜易错点：** 门槛石下的防水最容易被忽略：装修队做完整间防水，唯独门槛石下漏做，水沿门槛渗到门外走廊、泡坏地板。**「门口也是防水部位」**——门槛下做防水、设挡水，是室内防水的收尾关键。

## 5 核心要点：室内节点速查

本节为纯概念工艺主题，用「核心对比表」替代公式解析（按编辑章程第 5 条）。

| 节点 | 附加层范围 | 关键工序 |
| --- | --- | --- |
| 管根 | 周围直径 500 mm | 凿槽 → 嵌填 → 附加层 → 连大面 |
| 地漏 | 周围加厚 | 密封 → 附加层 → 找坡 |
| 阴角 | 转角做圆弧 | 圆弧 → 附加层 → 墙地连续 |
| 阳角 | 转角做圆弧 | 角条 → 刷匀 |
| 门口 | 门槛下防水 | 防水 → 挡水条 |

一句话记忆：**管根凿槽加附加，地漏密封找好坡；阴角圆弧阳角匀，墙地交界搭接够，门槛石下莫忘记。**

### 常见问题速答

**问：管根凿槽的槽要凿多深多宽？**
答：一般宽深各约 20~30 mm——这个尺寸够嵌填密封材料，又不会破坏楼板结构。槽太浅嵌料不足，槽太深影响结构——「够用就好」，别凿过头。

**问：地漏处的防水是「越厚越好」吗？**
答：不是。地漏处重在「密封 + 附加层 + 找坡」的组合——附加层做足、缝隙封严、坡度让水排净。光堆厚度不找坡，水照样积在地漏周围泡坏防水。

**问：墙地交界的涂膜为什么最容易出问题？**
答：墙面和地面常分两遍刷，两遍在墙角没有搭接，留一条「接槎缝」——水沿墙根渗到墙另一侧。**墙地交界要一并刷、搭接够**，接口处用附加层覆盖，墙角才浑然一体。

**问：室内节点处理这么多，有没有统一的口诀？**
答：有——**嵌缝要堵实、转角要圆弧、附加层要包严、搭接要连续**。四句话放之任何节点皆准，逻辑通了，没见过的节点也能临场应对。

一句话记忆：**管根凿槽加附加，地漏密封找好坡；阴角圆弧阳角匀，墙地交界搭接够，门槛石下莫忘记。**

## 6 小结

- 室内渗漏大半在**管根、地漏、阴阳角**——节点是室内防水的主战场。
- **管根**：凿槽嵌填密封 + 周围直径 **500 mm**「一布三涂」附加层，与大面连续搭接。
- **地漏**：交接处密封 + 周边附加层 + **找坡排水**（地漏最低点）。
- **阴阳角**：阴角做**圆弧**并加附加层，阳角用角条/圆弧并刷匀；**墙地交界一并刷、搭接够**。
- **门口**：门槛石下做防水、设挡水条——「门口也是防水部位」，收尾关键别忘。
