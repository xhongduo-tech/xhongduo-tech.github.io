# 防水工程常见质量通病防治与渗漏治理

<div class="epigraph">

## 为什么通病要「防在施工前」

前几篇讲了验收与试验，这一篇讲「已经出问题怎么办」——**质量通病防治与渗漏治理**。防水工程的通病，翻来覆去就那么几样：空鼓、开裂、翘边、渗漏。它们不是「防不胜防」，而是**防在施工前**——绝大多数通病，根子都在施工工艺上。而一旦渗漏已经发生，治理的思路是**先找原因、再堵源头**，不是「哪湿补哪」。<span class="marginnote">《国家职业技能标准—防水工》把质量通病防治与渗漏治理列入质量要求。通病防治的核心是「<strong>预防为主、工艺为本</strong>」：空鼓源于排气不净、开裂源于基层未处理、翘边源于滚压不实——<strong>每一个通病都有对应的工艺动作</strong>，把动作做对，通病自然消失。</span>这一节把通病与治理讲透。

## 1 常见质量通病

防水工程的高频通病，集中在六种：

| 通病 | 表现 | 主要原因 |
| --- | --- | --- |
| 空鼓 | 卷材/涂膜与基层脱离鼓包 | 基层不净、排气不净 |
| 开裂 | 防水层表面或细部开裂 | 基层裂缝、涂膜过厚 |
| 翘边 | 卷材边缘翘起 | 滚压不实、收头不牢 |
| 搭接不良 | 搭接缝开口、渗水 | 搭接不足、烤熔不匀 |
| 起泡 | 涂膜表面鼓泡 | 基层有明水、一次刷厚 |
| 渗漏 | 雨水/地下水进入结构 | 上述通病的最终结果 |

**辨析｜易错点：** 通病不是「独立事件」：空鼓日久开裂、开裂引导渗漏、渗漏又加速翘边——**通病之间会「滚雪球」**。治理通病要趁早，等它滚成渗漏，代价翻几倍。

## 2 通病防治：预防为主

通病防治的原则是「**工艺做对、问题自消**」，六大通病各有对策：

**防空鼓**：基层清扫干净、涂刷处理剂；卷材滚压排气、逐段压实；涂膜薄涂多遍——空鼓的根子在「气」和「脏」。

**防开裂**：基层裂缝先处理（嵌填密封、贴增强布）；涂膜薄涂多遍、不一次刷厚；找平层分格缝先做好——开裂的根子在「基层」和「厚度」。

**防翘边**：卷材收头固定牢（压条+密封）；自粘卷材撕膜即贴、一次到位——翘边的根子在「收头」。

**防搭接不良**：弹线定位保证搭接宽度；热熔烤匀、滚压压实；搭接缝封边——搭接不良的根子在「宽度」和「火候」。

**防起泡**：基层干燥无明水；涂膜薄涂多遍、遍间表干——起泡的根子在「水」和「厚度」。

**防渗漏**：上述五防做到，渗漏自然无从发生——渗漏是「结果」，防的是「原因」。

<span class="marginnote">通病防治的最高境界是「<strong>把问题消灭在工艺里</strong>」：空鼓在滚压时排掉气、开裂在基层时处理缝、起泡在涂刷时控厚度——<strong>每一个通病都有一个「手术式」的工艺动作对应</strong>。防水工的高下，就在这些动作做得到不到位。</span>

**辨析｜易错点：** 通病防治「重施工、轻基层」是本末倒置：基层不净、裂缝不处理，防水层做得再认真，空鼓开裂照样来。**基层是通病的「土壤」**——把土壤治理好，防水层才能健康生长。

## 3 渗漏治理

渗漏已经发生，治理要**按程序走**，不能「哪湿补哪」：

**第一步，找水源**：先弄清水的来源——是屋面雨水、地下压力水、还是管道漏水？水源不同，治理思路完全不同。

**第二步，找渗漏点**：按「节点 → 搭接 → 大面」的次序排查，逆流而上找源头（见上篇渗漏排查）。

**第三步，定方案**：根据渗漏点与水源定治理方案：
- **局部翻修**：屋面局部渗漏，翻开局部保护层与防水层，处理基层后重做防水层。
- **补缝封堵**：裂缝渗漏，嵌填密封材料、贴增强布或注浆封堵。
- **注浆治理**：地下渗漏，采用**注浆**（化学注浆、聚氨酯注浆）把水堵在结构外或裂缝中。
- **结构补强**：结构自身缺陷（施工缝渗漏、混凝土蜂窝），先补强结构再恢复防水。

**第四步，恢复与验证**：治理后恢复防水层与保护层，重新做蓄水/淋水试验验证。

<span class="marginnote">渗漏治理的次序是「<strong>先定水源、再找点、后堵漏</strong>」——水源定错了，在屋面上补了三个月，其实漏的是隔壁的排水管。<strong>治理渗漏，一半是排查，一半是修补</strong>：排查不清，修补全是白费。地下渗漏的注浆治理，是把浆液注入渗水通道「把水挤走、把缝堵死」——治水的思路，是「让水无路可走」。</span>

**辨析｜易错点：** 渗漏治理最怕「治标不治本」：内墙湿了就刷内墙防水，地下渗了就堵表面——水还在源头，换个位置又冒出来。**治理要「迎水面治本」**：屋面从上面修、地下从迎水面堵——**治本的方向，永远对着水来的方向**。

## 4 核心要点：通病与治理速查

本节为纯概念工艺主题，用「核心对比表」替代公式解析（按编辑章程第 5 条）。

| 通病 | 工艺对策 | 治理手段 |
| --- | --- | --- |
| 空鼓 | 清基层、滚压排气 | 切开排气重贴 |
| 开裂 | 处理基层缝、薄涂多遍 | 嵌填密封、贴增强布 |
| 翘边 | 压条固定、收头密封 | 重压、补粘 |
| 搭接不良 | 弹线保宽、烤匀压实 | 补贴加固 |
| 起泡 | 基层干燥、控厚度 | 割泡修补 |
| 渗漏 | 五防做到位 | 局部翻修/注浆治理 |

一句话记忆：**防在工艺、治在源头——空鼓排气、开裂治基层、渗漏先找水源再堵点，迎水面治本。**

### 常见问题速答

**问：防水层空鼓了，是不是一定要返工？**
答：不一定看位置与大小。大面空鼓会随温度变化发展、甚至渗漏，宜切开排气重贴；局部小空鼓可注浆或监测观察。但空鼓是「隐患的种子」，能修就修，别拖成渗漏。

**问：裂缝在防水层上出现了，补一层涂料行不行？**
答：治标。防水层裂缝的根子在基层——基层裂缝不处理，防水层补了再裂。要「基层嵌缝 + 贴增强布 + 重做防水层」三层一起处理，才叫治本。

**问：注浆治理地下渗漏，是怎么「堵水」的？**
答：把化学浆液（如聚氨酯注浆料）通过注浆孔压入渗水通道，浆液遇水发泡膨胀，把缝隙堵死、把水挤走——「让水无路可走」。注浆的关键是找准渗水通道，不是乱打孔。

**问：屋面局部渗漏，掀开重做还是整面翻修？**
答：看渗漏范围与防水层老化程度。局部点漏可局部翻修；防水层整体老化、空鼓开裂遍布，局部修补是「拆东墙补西墙」，宜整面翻修。先查后定，别急着动手。

**问：通病防治最有效的手段是什么？**
答：过程自检。每一道工序做完自己先查——基层验收、附加层检查、滚压排气、厚度测量。**把问题发现在当下，比日后治理便宜十倍**——这是「预防为主」的落地。

### 通病防治的「三查」制度

把通病防治落到制度上，靠施工中的「三查」：

| 检查点 | 检查时机 | 查什么 |
| --- | --- | --- |
| 施工前查 | 基层完成后 | 基层坚平干净、裂缝处理 |
| 施工中查 | 每道工序后 | 附加层、排气、厚度、搭接 |
| 施工后查 | 保护层前 | 空鼓、翘边、渗漏检验 |

一句话记忆：**防在工艺、治在源头——空鼓排气、开裂治基层、渗漏先找水源再堵点，迎水面治本。**

## 5 小结

- 六大通病：**空鼓、开裂、翘边、搭接不良、起泡、渗漏**——通病之间会「滚雪球」。
- 通病防治原则：**预防为主、工艺为本**——每个通病都有一个「手术式」工艺动作对应。
- 基层是通病的「**土壤**」：基层不净、裂缝不处理，防水层再认真也白搭。
- 渗漏治理四步：**找水源 → 找渗漏点 → 定方案（局部翻修/注浆/补缝）→ 恢复验证**。
- 治理方向：**迎水面治本**——治本的方向，永远对着水来的方向。
