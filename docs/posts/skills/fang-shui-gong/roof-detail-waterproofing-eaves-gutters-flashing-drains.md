# 屋面细部节点防水：檐口、天沟、泛水与水落口

<div class="epigraph">
<p>屋面漏水的十处有八处不在大面，而在那些转折、收头、穿管的小地方——细部才是真正的战场。</p>

## 为什么把细部单独列一章

屋面大面的卷材、涂膜铺得再漂亮，如果檐口、天沟、泛水、水落口这些**细部节点**处理不好，照样渗漏。行业里流传一句话：**「十漏九细」**——屋面渗漏十处有八九处在细部。原因很朴素：大面是「平面」，铺贴工艺成熟；细部是「转折、收头、穿孔」，卷材要收口、要转折、要开洞，每处都是防水的薄弱点。<span class="marginnote">GB 50207 第9章「细部构造」专门规定檐口、天沟、泛水、水落口、伸出屋面管道等节点的防水构造。细部工程不是「大面的缩小版」，而是「另一种构造」——<strong>每一处细部都有自己的附加层、收头与密封做法</strong>，是防水工区分高手与新手的分水岭。</span>这一节把屋面四大细部逐个拆开。

## 1 檐口与泛水

**檐口（eaves）**：屋面与外墙交接处的挑出部位，是雨水流向水落口的「第一道出口」。

檐口防水的关键在**收头**：

- 卷材在檐口处应**收头严密**：卷材端头固定在檐口压条下，压条用水泥钉固定，钉距均匀。
- 收头处用**密封材料**封严，防止雨水从收头端钻入。
- 檐口排水要顺畅：檐口部位的坡度与天沟衔接，不积水。

**泛水（flashing）**：女儿墙与屋面交接处、突出屋面结构四周的防水收头构造，也叫**女儿墙泛水**。

泛水防水的关键在**上翻高度**：

- 卷材在女儿墙上**上翻高度不应小于 250 mm**——翻低了，积水没过卷材上口就渗。
- 卷材上翻端头用**金属压条**钉固，端头用密封胶封严。
- 女儿墙顶部用**压顶**（混凝土或金属）覆盖，防雨水从墙顶渗入。<span class="marginnote">泛水的「250 mm」是经验结晶：雨滴溅起、风力抬水、积雪融化都可能让水没过墙根。<strong>250 mm 是「够得着防」的基准线</strong>——低于它，风把雨吹上墙面就危险。上翻收头「压条+密封」双保险，是泛水不渗的标配。</span>

**辨析｜易错点：** 泛水收头最容易犯「只压条不密封」：压条钉住了卷材，但端头露着，雨水沿端头缝隙钻进去。**收头必须「压条固定 + 密封胶封端」双管齐下**——压条防「卷材滑落」，密封防「端头进水」，缺一不可。

## 2 天沟、檐沟与水落口

**天沟（gutter）**：屋面中部用于集中排水的沟槽；**檐沟（eaves gutter）**：檐口处的排水沟。两者都承接大面雨水，是「水集中的地方」——防水要求比大面更高。

天沟/檐沟防水的要点：

- **纵向坡度不小于 1%**：保证雨水向水落口流动，不积水。
- **附加层**：天沟/檐沟与屋面交接处、转角处设附加层。
- **与卷材衔接**：沟内卷材与大面卷材**连续铺贴**，搭接顺水，不得在沟内断头。

**水落口（drain outlet）**：屋面雨水排入水落管的出口，是屋面「泄洪的闸门」。

水落口防水的要点：

- **水落口周围 500 mm 直径范围内，坡度不应小于 5%**：保证雨水向水落口汇集、排空。
- **水落口周围设附加层**：做「一布三涂」涂料附加层或附加卷材，加厚设防。
- **水落口杯与屋面连接处密封**：水落口杯四周用密封材料封严，防止渗漏。<span class="marginnote">水落口是屋面「最集中的水口」，也是「最容易被忽视的薄弱点」：积水常泡在这里，附加层不做、坡度不足，水就从水落口杯与屋面的缝隙渗进保温层。<strong>水落口是「重点部位重点做」的教科书</strong>——500 mm 范围、5% 坡度、附加层，三条少一条都漏。</span>

**辨析｜易错点：** 天沟内卷材搭接「逆向」是大忌：沟内水流方向与大面不同，卷材搭接必须**顺着沟内水流方向**，下一幅压上一幅——搭接方向反了，水沿缝爬进卷材下层，渗漏在坡屋面上「上爬」，最难排查。

## 3 伸出屋面管道与其他节点

屋面上常有各种「伸出物」：排气管、通风管、太阳能支架——每一处穿孔都是防水的考验。

**伸出屋面管道**防水的要点：

- 管道根部做**附加层**：卷材或「一布三涂」涂料附加层，加厚设防。
- 卷材在管道上**上翻高度不应小于 250 mm**，与泛水同理。
- 管道上翻收头用**金属箍（卡箍）**箍紧，端头用密封胶封严。
- 管道根部周边坡度**不小于 5%**，不积水。

**其他节点**：

| 节点 | 关键做法 |
| --- | --- |
| 变形缝 | 缝内填弹性密封材料 + 缝上做盖缝卷材 + 附加层 |
| 分格缝 | 缝内嵌密封材料、贴增强布 |
| 排气道出口 | 出口根部附加层 + 上翻收头密封 |
| 天窗/出屋面门口 | 四周泛水 + 上翻收头 |

<span class="marginnote">细部节点的共同逻辑是「<strong>转折加附加、收头上翻封</strong>」：转折处（转角）加厚设防，收头处（端头）上翻并密封。把这句话记住，任何没见过的细部都能照方抓药——<strong>细部不是「背图纸」，是「懂原理」</strong>。</span>

**辨析｜易错点：** 管根附加层「先做」与「后补」差之千里：先做的附加层被大面防水层覆盖、层层保护；后补的附加层贴在大面外面，暴露老化还易脱落。**细部附加层必须在大面施工之前完成**——这与第1篇《职业守则》里「附加层前置」的作业流程是同一个规矩。

## 4 核心要点：屋面细部防水速查

本节为纯概念工艺主题，用「核心对比表」替代公式解析（按编辑章程第 5 条）。

| 细部 | 关键要求 | 收头/加强做法 |
| --- | --- | --- |
| 檐口 | 收头严密 | 压条固定 + 密封 |
| 泛水 | 上翻 ≥250 mm | 金属压条 + 密封，压顶覆盖 |
| 天沟/檐沟 | 纵向坡度 ≥1% | 附加层、连续铺贴、顺水搭接 |
| 水落口 | 周围 500 mm 内坡度 ≥5% | 附加层 + 杯口密封 |
| 伸出管道 | 上翻 ≥250 mm、根部坡度 ≥5% | 附加层 + 金属箍 + 密封 |
| 变形缝 | 缝内密封 + 盖缝 | 附加层 + 弹性密封 |

一句话记忆：**转折加附加，收头上翻二百五，压条加密封；水落五百五坡度，天沟纵向一百分。**

### 常见问题速答

**问：泛水高度为什么定 250 mm？**
答：这是「够得着防」的经验值——雨滴溅起、风力抬水、积雪融化都可能让水没过墙根，250 mm 足以覆盖这些情况。低于它，风把雨吹上墙面就危险；高于它，造价浪费。

**问：檐口卷材收头只打密封胶行不行？**
答：不行。密封胶是「堵端头」，但卷材没有固定，长期受风力与自重会滑落、卷边——**压条固定 + 密封胶封端**才是完整收头。只打胶不固定，胶老化了卷材就掉了。

**问：水落口周围坡度做到 5%，为什么这么陡？**
答：水落口是「泄洪闸」，雨水在这里汇聚、最易积水——周围 500 mm 内做 5% 的陡坡，让水快速流向水落口、不在杯口周围滞留。坡度不足，杯口周围长期泡水，渗漏从这里开始。

**问：细部附加层为什么必须在大面之前做？**
答：附加层被大面防水层覆盖才有「加厚设防」的意义——后做在大面外面，暴露老化还易脱落。**先附加、后大面**，是屋面细部防水的工序铁律。

### 屋面细部渗漏排查次序

| 排查次序 | 部位 |
| --- | --- |
| 1 | 水落口、天沟 |
| 2 | 泛水收头、檐口 |
| 3 | 管根、变形缝 |

## 5 小结

- **十漏九细**：屋面渗漏多发生在檐口、天沟、泛水、水落口、管根等细部——细部是防水主战场。
- **檐口**收头压条固定 + 密封；**泛水**卷材上翻 **≥250 mm**，压条 + 密封 + 压顶。
- **天沟/檐沟**纵向坡度 **≥1%**，与大面连续铺贴、顺水搭接；**水落口**周围 500 mm 内坡度 **≥5%**，做附加层并封严杯口。
- **伸出屋面管道**根部做附加层、上翻 **≥250 mm**、金属箍收头密封。
- 细部总逻辑：**转折加附加、收头上翻封**——附加层必须在大面施工前完成。
