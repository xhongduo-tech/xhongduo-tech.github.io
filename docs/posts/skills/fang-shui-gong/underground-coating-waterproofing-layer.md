## 为什么地下也要做涂料防水层

上一节的卷材防水层贴大面、强度高，但遇到转角、管根、阴阳角这些「七扭八拐」的地方，卷材要裁剪、要搭接、要贴平——费劲又容易出缝。**防水涂料**恰好补这个短板：液态涂布、无缝成膜，任何形状都能贴合。地下工程里，涂料防水层常与卷材**复合设防**，或独立用于转角、管根等部位。<span class="marginnote">GB 50208 第7章「涂料防水层」规定地下涂料防水的材料与施工。地下涂料多用聚氨酯、JS 等，其核心工艺与屋面涂膜相通，但多了一条「<strong>迎水面设防、耐水久性要求更高</strong>」——地下涂料常年泡在压力水里，选材与厚度比屋面更严格。</span>这一节把地下涂料防水的施工讲透。

## 1 地下涂料防水层的适用与材料

**涂料防水层（coating waterproofing layer）**：以防水涂料在结构表面固化成连续防水膜的防水层，可用于结构迎水面或背水面。

**地下涂料选材**，比屋面多几分讲究：

| 涂料 | 地下适用性 | 说明 |
| --- | --- | --- |
| 聚氨酯涂料 | 优 | 高弹致密、耐水久，地下迎水面主流 |
| JS 涂料 | 良 | 环保便宜，用于背水面、潮湿基面 |
| 丙烯酸涂料 | 一般 | 耐水性弱，少用于地下 |
| 沥青基涂料 | 可 | 用于防水等级较低部位 |

**适用部位**：

- **转角、阴阳角、管根**：形状复杂处优先涂料，无缝贴合。
- **复合设防**：与卷材复合，涂料做第一道或第二道。
- **背水面**：结构内侧加固防水，常用涂料。<span class="marginnote">地下涂料防水的选材第一原则是「<strong>耐水久性</strong>」：涂料常年泡在压力水里，水乳型、耐水性差的涂料会「返乳」、失粘。<strong>长期泡水的部位，聚氨酯优先</strong>——高弹致密，是地下涂料里的「老大哥」。</span>

**辨析｜易错点：** 涂料防水的厚度是「刷」出来的，最容易「刷不够」：地下涂料防水层的厚度有硬指标（如聚氨酯涂料不小于设计厚度，一般 1.5~2.0 mm），现场靠遍数保证。**「刷一遍意思意思」在屋面都过不了关，在地下压力水面前更是形同虚设**——厚度不足是地下涂料渗漏的头号原因。

## 2 施工工艺：薄涂多遍

地下涂料防水的施工，核心是「薄涂多遍、逐遍表干」：

1. **基层处理**：结构表面坚实、平整、干燥（或按涂料要求湿润）、洁净；阴角阳角做圆弧。
2. **节点附加层**：转角、管根、阴阳角先做「一布三涂」附加层，加厚设防。
3. **分层涂布**：大面积薄涂多遍，一般分 3~5 遍；每遍不宜过厚，待前一遍**表干**后再涂下一遍。
4. **胎体增强**：需要增强的部位（如变形集中处）夹铺胎体增强材料（玻纤布/聚酯布），被涂料完全包裹。
5. **收头与保护**：涂层收头处封严；涂料固化后设保护层（砂浆或混凝土），防回填土与后续工序损伤。

**施工条件**：环境温度宜 5~35℃，雨雪天、五级风以上不得施工；双组分涂料（聚氨酯）现场按配比搅拌，拌后限时用完。<span class="marginnote">「薄涂多遍」的物理道理：涂料一次刷太厚，表层先干结成「皮」，内层溶剂/水分挥发不出，起泡、开裂。<strong>每一遍都是「薄薄一层、等它表干」</strong>——薄了没风险，厚了全是毛病。<strong>赶工想「一遍刷够」，等于亲手给防水层埋雷</strong>。</span>

**辨析｜易错点：** 双组分涂料（聚氨酯）的配比是命门：A 料与 B 料比例错、搅拌不匀，成膜强度大打折扣。**严格按说明书配比、充分搅拌、拌后限时用完**——配比错，涂料「白刷」。

## 3 涂料与卷材的复合与互补

地下工程里，涂料与卷材常「联手设防」：

| 设防思路 | 做法 |
| --- | --- |
| 涂料打底+卷材盖面 | 转角部位先刷涂料附加层，大面再铺卷材 |
| 卷材+涂料双道 | 两道独立防线，错位设防 |
| 涂料独立设防 | 小面积、异形部位独立使用 |

**复合设防的优势**：涂料无缝堵住转角与管根，卷材强度盖住大面——「涂料管细、卷材管面」，各补短板。<span class="marginnote">复合设防不是「多刷一层涂料」：<strong>涂料与卷材是两道独立的防线，层间要有可靠的界面与搭接</strong>。转角处涂料附加层被卷材覆盖，卷材大面铺在涂料之上——先涂料后卷材，顺序不能反。</span>

**辨析｜易错点：** 涂料层与卷材层**直接密贴**时，两层之间可能起鼓（涂料未干透就铺卷材）。复合设防要等涂料**完全固化**后再铺卷材，必要时设隔离层——**层间界面处理不当，复合变「互拆台」**。

## 4 公式解析：湿膜厚度换算干膜厚度

涂料刷上去时是「湿膜」，固化后变成「干膜」——验收量的是干膜，施工看的是湿膜。两者怎么换算？

$$
d_{\text{干}} = d_{\text{湿}} \times C_v
$$

其中：

- $d_{\text{干}}$：**干膜厚度**（μm 或 mm）——固化后的有效防水厚度。
- $d_{\text{湿}}$：**湿膜厚度**（μm 或 mm）——刚涂布时的厚度。
- $C_v$：**体积固体含量**——涂料中成膜物质占湿涂料的体积比例（如 0.8）。

**三步拆解这条公式：**

**第一步，代入数值**：某聚氨酯涂料体积固含量 $C_v = 0.8$，每遍刷湿膜厚 0.5 mm，则单遍干膜 $d_{\text{干}} = 0.5 \times 0.8 = 0.4\ \mathrm{mm}$。

**第二步，读结论**：设计干膜厚 1.5 mm，需要 $1.5 / 0.4 = 3.75$ 遍，即刷 **4 遍**才能达标。<span class="marginnote">这个换算让「刷几遍」变成算术：<strong>设计干膜厚度 ÷ 单遍干膜厚度 = 最少遍数</strong>。用湿膜测厚仪现场抽查湿膜厚度，反推干膜是否达标——「遍数够了」不等于「厚度够」，因为每遍的湿膜厚度可能忽厚忽薄。</span>

**第三步，注意变数**：实际成膜受基层吸料、施工损耗影响，**干膜厚度往往略低于理论值**——所以规范与产品说明会要求「遍数取整后加一遍」，并实测干膜厚度验收。

## 5 核心要点：地下涂料速查

本节以「核心要点表」归纳工艺要领（工艺类主题，以表代公式，按编辑章程第 5 条）。

| 控制项 | 要求 | 通病 |
| --- | --- | --- |
| 选材 | 泡水部位聚氨酯优先 | 用耐水性差的涂料 |
| 基层 | 坚实平整、节点做圆弧 | 基层不净起鼓 |
| 涂布 | 薄涂多遍、逐遍表干 | 一遍刷厚起泡 |
| 厚度 | 干膜厚度达设计值 | 刷不够、厚薄不均 |
| 配比 | 双组分严格配比搅拌 | 配比错强度差 |
| 复合 | 与卷材先涂料后卷材 | 未固化就铺卷材 |

一句话记忆：**选材看耐水，涂布薄多遍，干膜靠换算，配比莫出错，复合先涂料。**

### 常见问题速答

**问：地下涂料为什么优先选聚氨酯？**
答：地下防水层长期泡在压力水里，材料的「耐水久性」是第一位的——聚氨酯高弹致密、耐水久性好，是地下迎水面的主流；JS 环保便宜但耐水久性弱，多用于背水面。

**问：涂膜厚度够了，是不是地下防水就稳了？**
答：厚度是必要条件，不是充分条件——还要搭接连续、节点做足、与卷材层界面处理好。**厚度不够必漏，厚度够了也不一定稳**——地下涂料防水看的是「整体」，不是「单点」。

一句话记忆：**选材看耐水，涂布薄多遍，干膜靠换算，配比莫出错，复合先涂料。**

## 6 小结

- 地下**涂料防水层**无缝贴合异形部位，常与卷材**复合设防**；选材以**耐水久性**为准，泡水部位聚氨酯优先。
- 施工核心**薄涂多遍、逐遍表干**：一般 3~5 遍，每遍不厚，节点先做「一布三涂」附加层。
- **双组分严格配比**、充分搅拌、拌后限时用完；环境温度 5~35℃，雨雪大风不施工。
- 复合设防**先涂料（固化）后卷材**，层间界面处理不当会起鼓。
- 厚度换算：**干膜 = 湿膜 × 体积固含量**，设计干膜 ÷ 单遍干膜 = 最少遍数，实测干膜验收。
