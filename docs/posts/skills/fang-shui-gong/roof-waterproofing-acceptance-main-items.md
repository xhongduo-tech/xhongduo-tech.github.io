## 为什么验收是质量的最后一道闸

前面从材料、基层到卷材、涂膜、细部，把屋面的「做法」讲完了。这一篇转向「怎么看质量」——**质量验收**。防水工程是隐蔽工程：卷材被保护层盖住、涂膜被面层遮住，施工时做得好不好，只有验收这一关能当场抓住。GB 50207 第10章的质量验收分**主控项目**与**一般项目**，主控项目是「一票否决」的硬杠杠——不合格就得返工。<span class="marginnote">GB 50207《屋面工程质量验收规范》第10章「质量验收」是整本规范最后收口的一章。主控项目与一般项目的分野很关键：<strong>主控项目是「底线」，不合格即返工；一般项目是「细节」，允许有偏差</strong>。分清主次，验收才有章法。</span>这一节讲主控项目与验收程序。

## 1 主控项目与一般项目

**主控项目（main control items）**：对材料、工序、构造等直接决定工程质量、必须全部合格的项目。屋面防水的主控项目不合格，**必须返工处理**，没有商量余地。

**一般项目（general items）**：对工程质量有影响、但不直接决定基本功能的项目，允许有一定的偏差范围，可按规范要求判定。

**辨析｜易错点：** 主控项目与一般项目不能「混着判」：主控项目有一个不合格，检验批评定不合格；一般项目可以有少量偏差，但偏差超限也要处理。**主控项目是「考试必答题」，一般项目是「附加题」**——别把主控的硬要求当一般项糊弄过去。

## 2 屋面防水验收的主要主控项目

屋面防水工程的主控项目，集中在以下几类：

**材料质量**：
- 卷材、涂膜、密封材料等**品种、规格、性能**符合设计要求与相关标准。
- 进场材料有**合格证、检验报告**，按规定抽样复验。

**防水等级与设防**：
- 屋面的**防水等级、设防道数**符合设计——Ⅰ级屋面必须是两道设防，做不到就是主控不合格。

**搭接与铺贴质量**：
- 卷材的**搭接宽度**符合规范（热熔/冷粘长边短边 100 mm、自粘 80 mm 等）。
- 卷材**铺贴方向、粘结牢固**、无空鼓、无皱折。
- 涂膜厚度、遍数符合设计。

**细部构造**：
- **檐口、天沟、泛水、水落口、伸出屋面管道**等细部按设计做附加层、收头、密封。
- 细部防水是主控的重点——「十漏九细」，细部不达标，大面做得再好也是白搭。

**防水功能试验**：
- 屋面防水层完成后做**淋水试验**或**蓄水试验**（天沟、檐沟可做淋水），无渗漏为合格。
- 蓄水试验水深、时间符合要求。

<span class="marginnote">主控项目的逻辑是「<strong>用关键项卡住关键风险</strong>」：材料不对，全盘皆输；等级不足，省的是命门；搭接不够，水从缝钻；细部不做，十漏九细；试验不过，无从证明。<strong>五类主控项，就是屋面的「五道保险」</strong>。</span>

**辨析｜易错点：** 验收最怕「只验结果、不验过程」：防水层被盖住后，光看表面无法判断搭接、厚度、附加层。所以**隐蔽工程验收**要在被覆盖之前进行——基层、附加层、防水层分别验收合格后，才允许做保护层。**过程验收不到位，竣工验收就是「盲人摸象」**。

## 3 检验批与验收程序

**检验批（inspection lot）**：按同一施工部位、同品种材料、同工艺划分的验收单位——屋面防水按面积或部位划分检验批，逐批验收。

**验收程序**分四步：

1. **施工自检**：施工班组按工序自检，填写记录——基层、附加层、大面、细部逐项自查。
2. **报验**：自检合格后，向监理（建设单位）**报验**，申请验收。
3. **现场验收**：监理（建设单位）检查主控项目与一般项目，核查**验收记录、隐蔽验收记录、试验记录**。
4. **签发结论**：验收合格签发验收记录；不合格的**返工重做后重新报验**。

**验收资料**（竣工档案的核心）：
- 材料合格证、进场复验报告。
- 隐蔽工程验收记录。
- 淋水/蓄水试验记录。
- 主控项目、一般项目检验记录。

<span class="marginnote">验收资料的逻辑是「<strong>让过程可追溯</strong>」：几年后屋面渗漏，翻开档案能查「当时用什么材料、谁做的、验没验过」——<strong>记录是质量责任的「账本」</strong>。资料不全，验收就是「无凭无据」。</span>

**辨析｜易错点：** 验收程序不能「倒着走」：先做保护层、后补验收记录——这是本末倒置。**「先验收、后覆盖」是隐蔽工程的铁律**；补签、代签验收记录属于弄虚作假，一旦渗漏责任难逃。

## 4 核心要点：屋面验收速查

本节为纯概念主题，用「核心对比表」替代公式解析（按编辑章程第 5 条）。

| 验收类别 | 主控项目 | 判定 |
| --- | --- | --- |
| 材料 | 品种规格、性能、复验 | 不符合即不合格 |
| 等级设防 | 等级、设防道数 | 不符合设计即返工 |
| 铺贴 | 搭接宽度、粘结、无空鼓 | 实测不达标即处理 |
| 细部 | 附加层、收头、密封 | 细部不达标全批评定 |
| 功能试验 | 淋水/蓄水试验 | 渗漏即返工 |

一句话记忆：**材料等级要主控，搭接细部不放松；试验泡水见分晓，隐蔽先验后覆盖。**

### 常见问题速答

**问：主控项目不合格，能不能「整改一下就过关」？**
答：要分清性质。搭接不足、局部空鼓可以整改后重验；材料不合格、等级设防不足这类「根子」问题，整改就是返工——主控项目是硬杠杠，不是可以讨价还价的一般项。

**问：隐蔽工程验收为什么要赶在覆盖之前？**
答：防水层一盖保护层就看不见了——搭接、厚度、附加层全藏在里面。隐蔽验收是被覆盖前的「最后一眼」，错过了就只能靠试验间接推断，甚至只能赌。

**问：屋面验收资料是不是「补一补就行」？**
答：不行。验收资料是质量责任的「账本」——几年后渗漏，翻档案要能查「当时用了什么材料、谁做的、验过没有」。补签、代签是弄虚作假，出了问题责任难逃。

**问：检验批是怎么划分的？**
答：按同一施工部位、同品种材料、同工艺划分——屋面按面积或部位分批，逐批验收。批划得太粗，一处不合格会连累整批；划得太细，验收次数翻倍。

**问：淋水/蓄水试验做了就代表防水一定好？**
答：试验能抓住「当前」的渗漏，挡不住「将来」的老化——材料合格、施工到位、试验通过，是「当下合格」；长期不渗还要靠合理使用年限内的耐久性。试验是验收，不是保险。

| 材料记录 | 合格证、进场复验报告 |
| 过程记录 | 隐蔽验收、工序检查 |
| 试验记录 | 淋水/蓄水试验数据 |
| 检验记录 | 主控/一般项目逐项判定 |

一句话记忆：**材料等级要主控，搭接细部不放松；试验泡水见分晓，隐蔽先验后覆盖。**

## 5 小结

- 屋面防水验收分**主控项目**（一票否决）与**一般项目**（允许偏差）——主控不合格必须返工。
- 五大主控项：**材料、等级设防、搭接铺贴、细部构造、功能试验**——屋面的五道保险。
- 细部构造是主控重点：**十漏九细**，檐口、天沟、泛水、水落口、管根逐一验收。
- **隐蔽工程先验收、后覆盖**；检验批按部位划分，逐批验收。
- 验收程序：**自检 → 报验 → 现场验收 → 签发结论**；资料（合格证、复验、试验记录）齐全可追溯。
