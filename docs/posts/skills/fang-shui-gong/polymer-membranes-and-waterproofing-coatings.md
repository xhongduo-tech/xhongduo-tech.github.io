## 为什么接着讲这两类材料

上一节的 SBS/APP 卷材统治了传统屋面，但有两个它搞不定的场景：一是**大面积轻质屋面**（钢结构厂房、体育馆）需要轻、耐老化、可焊接的材料；二是**卫生间、地下室等异形小空间**，卷材铺不贴合，需要能刷的液态涂料。于是高分子卷材与防水涂料登场。<span class="marginnote">材料选择的两条基本路线：**卷材=工厂预制成膜、现场拼接**，**涂料=现场成膜、无缝一体**。一个胜在厚度均匀强度高，一个胜在无缝贴合异形。后面章节会反复用到这对矛盾。</span>这一节认识四种主力材料：PVC、TPO 卷材与聚氨酯、JS 涂料。

## 1 高分子防水卷材：PVC 与 TPO

**高分子防水卷材（polymer waterproofing membrane）**：以合成高分子材料为基材制成的柔性防水卷材，强度高、耐老化、可热风焊接，代表品种有 PVC、TPO、EPDM、HDPE。

### PVC 防水卷材

**PVC（聚氯乙烯）防水卷材**：以聚氯乙烯树脂为主要原料，加入增塑剂、稳定剂等加工而成。

特点：柔韧性好、强度高、耐化学腐蚀，采用**热风焊接**连接——用焊枪把相邻卷材的搭接边熔融压合，形成与母材同强度的焊缝。<span class="marginnote">「焊接」是高分子卷材区别于沥青卷材的最大工艺特色：SBS 卷材靠热熔沥青自粘搭接，PVC/TPO 靠焊枪吹热熔融塑料、压辊压实成一体。焊缝强度甚至能超过母材，这是它在大面积屋面抗风揭上的底气。</span>适用：种植屋面、地下、水池、大面积工业厂房屋面。

### TPO 防水卷材

**TPO（热塑性聚烯烃）防水卷材**：以聚烯烃类热塑性弹性体为基材，不含增塑剂，是 PVC 的「环保升级版」。

特点：不含增塑剂所以**不迁移、不变脆**，耐候性极好；白色 TPO 面层反光率高，能**反射阳光降温**，配合种植屋面和光伏屋面很受欢迎；同样可热风焊接。适用：大跨度金属屋面、种植屋面、暴露式屋面。

**辨析｜易错点：** PVC 与 TPO 都能焊接，但**增塑剂是关键差异**：PVC 靠增塑剂变软，时间久了增塑剂会挥发迁移，材料变硬开裂；TPO 靠分子结构本身柔韧，无需增塑剂，因此更耐老化。选材时记住「TPO 是更贵但更耐久的 PVC 替代者」。

## 2 防水涂料：聚氨酯与 JS

**防水涂料（waterproofing coating）**：施工前为液态、施工后在基面固化成连续防水膜的材料。它没有接缝，能贴合各种异形面，是室内与节点防水的主力。

### 聚氨酯防水涂料

**聚氨酯（PU）防水涂料**：以聚氨酯预聚体为主要成分，固化后形成高弹性、高强度的连续膜。

特点：**弹性好、强度高、耐穿刺**，成膜致密；分单组分与双组分，双组分需现场按比例拌匀；部分产品遇水固化更快（湿固化），在潮湿基面也能施工。<span class="marginnote">「遇水固化」是把双刃剑：基面有明水时聚氨酯会起泡、鼓包，所以规范要求基面应干燥、无明水。潮湿基面「能施工」不等于「有明水也能刷」——这个细节后面施工章节还会反复强调。</span>适用：卫生间、地下室、屋面节点，涂膜厚度一般要求 ≥ 1.5 mm。

### JS 聚合物水泥防水涂料

**JS 防水涂料（polymer cement waterproof coating）**：由聚合物乳液（丙烯酸酯等）与水泥、填料按一定比例配成的双组分涂料，全称「聚合物水泥基防水涂料」。

特点：**环保无毒、粘结力强、施工方便**，成膜兼具水泥的刚性粘结与聚合物的柔性变形，可直接在其上贴砖。适用：卫生间、厨房、阳台等室内防水——是家装防水的主力材料。<span class="marginnote">JS 涂料里水泥不是简单的填料：水泥提供与基层（砂浆、混凝土）的牢固粘结和一定刚性，聚合物乳液提供柔性防渗。两者比例不同，产品的「柔性/刚性」倾向就不同——柔型 JS 用于变形部位，刚型 JS 用于粘结要求高的部位。</span>

**辨析｜易错点：** 聚氨酯与 JS 的区别，重点不在「哪个更好」而在「用对地方」：聚氨酯强度高、弹性大，适合地下室、水池等**水压大**的部位；JS 环保、可贴砖，适合卫生间厨房等**与人体接触**的室内部位。把聚氨酯刷进饮用水池、把 JS 刷上高水压地下室，都是选材错位。

## 3 核心对比：卷材与涂料

把两类材料放到同一张桌面上，它们的互补关系就清楚了：

| 对比项 | 高分子卷材（PVC/TPO） | 防水涂料（聚氨酯/JS） |
| --- | --- | --- |
| 形态 | 工厂预制卷状，现场拼接 | 液态，现场固化成膜 |
| 接缝 | 有搭接缝（焊接/胶粘） | 无缝，连续一体 |
| 厚度控制 | 出厂定厚，均匀可靠 | 靠遍数与用量控制，易厚薄不匀 |
| 异形贴合 | 差（需裁剪、节点处理） | 好（刷涂/滚涂贴合异形面） |
| 抗拉强度 | 高（有胎基或分子链） | 聚氨酯较高，JS 一般 |
| 施工环境 | 需焊接设备，受风力影响 | 需干燥成膜，受湿度影响 |
| 典型场景 | 大屋面、地下、水池、种植屋面 | 卫生间、厨房、节点、异形部位 |

**复合防水的组合逻辑**：屋面一级防水常做「涂料打底 + 卷材面层」——涂料先填平基层并贴合异形节点，卷材再提供主防水层的强度。两种材料机理不同、破坏路径不同，一道失效另一道仍能扛住，这才是真正意义上的「多道设防」。

## 4 小结

- 高分子卷材两大主力：**PVC**（柔韧、耐腐蚀、可焊接）与 **TPO**（无增塑剂、耐老化、可焊接、白色反光节能）。
- 防水涂料两大主力：**聚氨酯**（高弹高强、耐穿刺、潮湿基面可施工）与 **JS**（环保无毒、可贴砖、室内主力）。
- 卷材与涂料的根本差异：**卷材胜在厚度均匀强度高，涂料胜在无缝贴合异形面**——两者组合成复合防水，是「多道设防」的经典实现。
- 选材口诀：**大面平整用卷材，异形室内用涂料；怕冷用 SBS，怕热用 APP，要耐久上 TPO**。

在下一节，我们把目光从「主材」移到「配角」——**防水辅材、密封材料与配套材料**，看卷材涂料之外，那些决定防水层能不能立住的小材料。
