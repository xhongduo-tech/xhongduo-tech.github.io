# 地下工程变形缝、施工缝与后浇带等细部防水

<div class="epigraph">

## 为什么地下细部专门开一章

地下结构与屋面不同，它几乎不可避免要有「缝」：施工要分段浇筑（施工缝）、结构要适应变形（变形缝）、早期收缩要释放（后浇带），还有穿墙管道、桩头这些「孔洞」。**每一道缝、每一个孔，都是压力水最想钻的地方**——地下渗漏十有八九在缝和孔上。<span class="marginnote">GB 50208 第11章「细部构造」专门规定变形缝、施工缝、后浇带、穿墙管道、桩头等的防水构造。第4章《防水混凝土结构施工》里我们把三种「缝」的性质讲了一遍，<strong>本节把每道缝的具体防水做法展开</strong>——性质决定做法，做法兑现性质。</span>这一节把地下细部逐一拆开。

## 1 施工缝防水：施工的不得已

**施工缝（construction joint）**：因施工工艺需要分段浇筑混凝土而在结构上形成的接缝。它不是结构「想要的」，是施工「不得已」的。

施工缝是抗渗的薄弱环节：新旧混凝土两次浇筑，接缝处粘结不良、容易形成渗水通道。防水的核心是「**把接缝做密实、把水绕过去**」：

- **凿毛清理**：浇筑新混凝土前，施工缝表面凿毛、清理浮渣、充分湿润。
- **铺浆接缝**：先铺一层同配合比水泥砂浆，再浇筑新混凝土，增强新旧结合。
- **设置止水**：施工缝处设置**止水条**（遇水膨胀橡胶止水条）或**止水带**（中埋式），让水无法沿缝直穿。
- **位置选择**：施工缝应留在结构受力较小、便于施工的部位，避开剪力最大处。

<span class="marginnote">遇水膨胀止水条是施工缝的「常客」：平时软软的，一遇水就膨胀，把缝胀紧。<strong>它的安装要点是「固定牢、不被提前泡胀」</strong>——安好后不能先遇水（会提前膨胀失效），浇筑时要用专用胶或钉子固定。</span>

**辨析｜易错点：** 施工缝「凿毛」不是「意思一下」：浮浆不凿净、不湿润，新旧混凝土之间就是一层「两张皮」，止水条也白设。**凿毛、清理、湿润、铺浆、止水**五步缺一不可——施工缝防水是「细节里的细节」。

## 2 变形缝防水：结构的需求

**变形缝（deformation joint）**：为适应结构因温度变化、沉降、地震等产生的变形而设置的永久性接缝。它不是施工的不得已，是结构「需要的呼吸缝」。

变形缝防水的核心是「**能变形、不漏水**」：

- **中埋式止水带**：在缝的中部埋设**橡胶止水带**或钢边止水带，随结构变形而伸缩，始终挡水。
- **填缝密封**：缝内填充弹性密封材料，缝口用密封胶封严。
- **外侧附加防水**：变形缝外表面再做附加防水层（卷材或涂料），加强设防。
- **构造型式**：变形缝宽度按结构设计，构造上做成「可伸缩」的榫槽式或平接式。

<span class="marginnote">变形缝的止水带是「缝的灵魂」：它被浇筑在混凝土里，中间部分骑在缝上，随缝开合而伸缩。<strong>止水带安装是「一次性的艺术」</strong>——浇进去就取不出来了，位置偏了、方向反了、接头没接好，都是永久缺陷。<strong>中埋止水带要「先固定、后浇筑、多检查」</strong>。</span>

**辨析｜易错点：** 变形缝与施工缝的防水思路完全不同：施工缝靠「**接**」（凿毛铺浆连成一体），变形缝靠「**让**」（止水带伸缩适应变形）。**把变形缝当施工缝处理（硬接）、或把施工缝当变形缝处理（设缝），都是概念错误**——缝的性质决定防水做法。

## 3 后浇带防水：应力的出口

**后浇带（post-cast strip）**：在结构较长区段中预留的、待两侧混凝土收缩基本稳定后再浇筑的窄带，用于**释放早期收缩应力**、防止结构开裂。

后浇带防水的核心是「**等时机、两侧止水**」：

- **两侧止水**：后浇带两侧设止水条或止水带，防水在后浇之前就布好。
- **后期浇筑**：按设计时间（一般待两侧混凝土收缩稳定，约 60 天后）浇筑**补偿收缩混凝土**（掺膨胀剂），填实带体。
- **接缝处理**：浇筑前凿毛、清理、湿润，与施工缝工艺一致。
- **带体防水**：后浇带部位的附加防水层与大面连续，接槎严密。

<span class="marginnote">后浇带是「<strong>给混凝土留的退路</strong>」：整段混凝土收缩时会开裂，先留一条带让它「缩」，缩稳了再补上——<strong>补的时机（60 天左右）比补的材料更关键</strong>。赶工期提前浇筑，收缩应力没释放完，补了也白补。</span>

**辨析｜易错点：** 后浇带混凝土**不能用普通混凝土代替补偿收缩混凝土**：不掺膨胀剂，补浇的混凝土自身又收缩，与两侧形成新的缝隙。**后浇带「等时机 + 掺膨胀剂 + 两侧止水」三件事，一件不能少**。

## 4 穿墙套管与桩头等其他细部

地下结构穿墙的管道、打入地下的桩，都是防水的「孔洞」关卡：

**穿墙管道防水**：

- 管道穿越外墙处设**预埋套管**，套管上焊**止水翼环（止水环）**——水沿管外壁渗入时被翼环挡住。
- 管道与套管之间用**弹性密封材料**填实。
- 套管根部做附加防水层（卷材或涂料），与大面防水层搭接连续。

**桩头防水**：

- 桩头与底板交接处是防水的薄弱点：桩头凿毛、清理。
- 桩头根部做**遇水膨胀止水条**或密封膏，堵住桩与混凝土的接缝。
- 桩头周边做附加防水层，与大面底板防水层搭接。

| 细部 | 关键构造 |
| --- | --- |
| 施工缝 | 凿毛铺浆 + 止水条/止水带 |
| 变形缝 | 中埋止水带 + 弹性密封填缝 |
| 后浇带 | 两侧止水 + 补偿收缩混凝土 |
| 穿墙套管 | 止水翼环 + 弹性密封 |
| 桩头 | 止水条 + 附加防水层 |

<span class="marginnote">把地下所有细部归成一句话：<strong>「缝里设止水，孔周加附加」</strong>——缝（施工缝、变形缝、后浇带）里埋止水带/止水条，孔（套管、桩头）周围做附加防水层。<strong>记住这句话，地下细部防水就有了总纲</strong>。</span>

**辨析｜易错点：** 穿墙套管的止水翼环必须在**预埋阶段**焊好——结构浇筑后再补，套管与混凝土之间的缝已经存在。**止水构造要「先埋后浇」**，所有预埋件的止水处理都赶在浇筑混凝土之前，这是地下细部防水的工序铁律。

## 5 核心要点：地下细部防水速查

本节为纯概念工艺主题，用「核心对比表」替代公式解析（按编辑章程第 5 条）。

| 缝型 | 性质 | 防水做法 | 关键 |
| --- | --- | --- | --- |
| 施工缝 | 施工不得已 | 凿毛铺浆 + 止水条 | 五步缺一不可 |
| 变形缝 | 结构需求 | 中埋止水带 + 密封 | 先固定后浇筑 |
| 后浇带 | 应力出口 | 两侧止水 + 补偿收缩混凝土 | 等时机、掺膨胀剂 |
| 穿墙套管 | 孔洞 | 止水翼环 + 密封 | 先埋后浇 |
| 桩头 | 孔洞 | 止水条 + 附加层 | 凿毛清理 |

一句话记忆：**施工缝靠接、变形缝靠让、后浇带等时机；缝里设止水，孔周加附加。**

### 常见问题速答

**问：施工缝的遇水膨胀止水条，安装有什么讲究？**
答：固定牢、不被提前泡胀——用专用胶或钉子固定在缝内，安装后不能让水先泡到（提前膨胀就失效了）。**先浇筑、后遇水**，是止水条的时序要求。

**问：后浇带为什么强调「等时机」？**
答：后浇带是给混凝土收缩留的「退路」——两侧混凝土收缩稳定了（一般约 60 天）再补浇，收缩应力才释放完。赶工期提前浇筑，补了也白补，照样开裂。

一句话记忆：**施工缝靠接、变形缝靠让、后浇带等时机；缝里设止水，孔周加附加。**

## 6 小结

- 地下细部防水的总纲：**缝里设止水、孔周加附加**——缝与孔是压力水的突破口。
- **施工缝**：凿毛、清理、湿润、铺浆、止水五步；遇水膨胀止水条勿提前泡胀。
- **变形缝**：**中埋止水带** + 弹性密封，止水带先固定后浇筑，是「一次性的艺术」。
- **后浇带**：两侧止水 + 等时机（约 60 天）+ **补偿收缩混凝土**，三件事不能少。
- **穿墙套管**：止水翼环预埋焊接 + 弹性密封；**桩头**：凿毛清理 + 止水条 + 附加防水层。
