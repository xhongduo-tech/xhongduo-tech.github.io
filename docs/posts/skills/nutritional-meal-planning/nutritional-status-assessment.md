## 为什么从人体测量开始

前三篇问「吃了什么、吃了多少」，得到的是一份**膳食证据**。但膳食不等于身体——吃进去的，身体吸收了多少、利用得如何、是否失衡？这需要另一路证据：**人体测量、实验室检查与临床体征**。膳食调查与人体评价就像同一案件的两种线索，相互印证才能下结论。

对配餐者而言，人体评价的实用价值直接而强烈：减重方案要定目标体重，得先量身高体重算 BMI；腹型肥胖要评估心血管风险，得量腰围；营养不良筛查要看上臂围与皮褶厚度。**不会人体测量，配餐就只是纸上谈兵**——你连「这个人该减到多重」都说不准。<span class="marginnote">营养评价的完整体系有「五套证据」：膳食调查、人体测量、实验室检查（生化）、临床体征、以及个人史与生活方式。本分类第2篇前四篇已讲膳食调查，这一篇补上人体测量与实验室检查两大块。</span>

本篇的叙述逻辑也遵循一条主线：**先量（人体测量）→ 再查（生化检验）→ 后看（临床体征）→ 最后合（综合评价）**。每一级证据都在为上一级纠偏——测量说超重，生化说血脂高，体征说脂肪肝，综合才敢开干预处方。只取其中一级就下结论，是营养评价里最常见的「盲人摸象」。

## 1 人体测量：身高、体重与 BMI

**人体测量（anthropometry）**是营养状况评价最基础、最经济的手段。核心指标有三项：

**身高与体重**：一切评价的起点。测量体重要「清晨、空腹、排空大小便、赤足、着轻衣」，多次测量取稳。身高对儿童与青少年尤为重要——生长曲线是儿童营养状况最敏感的长时段指标，这会在《婴幼儿与学龄前儿童膳食》里展开。

测量的规范性直接决定数据的价值：体重秤要校准、放平，测量时身体站直、两臂自然下垂；身高用立式身高计，枕部、肩胛、臀部、足跟四点贴柱。**同一人在不同时间、不同秤上的数字可能有 1–2 kg 波动**——所以减重随访强调「同一时段、同一台秤、同样衣着」，把测量噪声压到最低。这一细节看似琐碎，却是长期随访数据可比性的命门。

**体质指数（BMI）**：把身高体重合成一个可比指标，是世界通用的体格评价基准：

$$\text{BMI} = \frac{\text{体重(kg)}}{\text{身高(m)}^2}$$

中国成人 BMI 分组（沿用《中国超重/肥胖医学营养治疗指南》标准）：**BMI < 18.5 为消瘦，18.5–23.9 为正常，24–27.9 为超重，≥ 28 为肥胖**。

**理想体重**：配餐中常用来估算目标值的快捷公式，最简单的一式是：

$$\text{理想体重(kg)} = \text{身高(cm)} - 105$$

例如身高 170 cm 者，理想体重约 65 kg；实际体重在理想体重 ±10% 以内视为正常范围。

## 2 腰围、臀围与体脂分布

BMI 有它的盲区：**它不区分脂肪与肌肉**。一个肌肉发达的健身者 BMI 可能 27（被归为超重），一个四肢纤细但肚子很大的「瘦胖子」BMI 可能只有 22。于是需要看脂肪的**分布**：

- **腰围（waist circumference, WC）**：反映腹部脂肪（内脏脂肪）堆积程度。中国成人标准：男 **< 90 cm**、女 **< 85 cm**，超过即为**中心性肥胖**。
- **腰臀比（WHR）**：腰围 ÷ 臀围，男 ≥ 0.90、女 ≥ 0.85 提示中心性肥胖。
- **皮褶厚度**：用皮脂卡尺测量三头肌、肩胛下等部位，可估算体脂率。常用**三头肌皮褶厚度（TSF）**反映皮下脂肪储备，再与**上臂围（MAC）**合成**上臂肌围（MAMC）**：$\text{MAMC} = \text{MAC} - \pi \times \text{TSF}$，近似反映肌肉量，是营养不良筛查的经典组合。
- **上臂围（MAC）**：营养筛查的经典指标，反映肌肉与皮下脂肪的储备，常在营养不良评估中与「三头肌皮褶厚度」联用。

**体脂率**也可以从皮褶厚度推算（如根据 TSF 与年龄查公式），但卡尺测量的操作一致性要求高——不同人测同一部位误差可以很大。因此社区筛查常用 BMI + 腰围快速分层，皮褶与上臂围更多用于医院营养科与科研；**工具越精细，对操作者的要求也越高**，选什么量具取决于你能否保证测量质量。

为什么「分布」如此重要？因为**内脏脂肪是代谢危险分子**——它比皮下脂肪更容易释放游离脂肪酸入肝，引发胰岛素抵抗、血脂异常。临床上「腹型肥胖」比「全身均匀超重」的心血管风险更高，所以腰围被单列为一项独立的风险指标。<span class="marginnote">「苹果型（中心性）vs 梨型（外周性）」是脂肪分布的经典比喻：苹果型脂肪集中在腰腹，代谢风险高；梨型脂肪堆在臀腿，风险相对低。量一次腰围，比纠结 BMI 小数点更能说明问题。</span>

除了成人的人体测量，**儿童与青少年的生长评价**是人体测量在生命周期另一端的应用：身高体重对照生长曲线（WHO/中国标准）看百分位与 Z 分数——**曲线沿自身百分位平稳上行即正常，偏离两个主要百分位则提示问题**。这个人群的评价还要看身高别体重、BMI-for-age，区分「瘦长型正常」与「生长迟缓」。**生长曲线是儿童营养状况最敏感的长时段指标**——它与《婴幼儿与学龄前儿童膳食》《学龄儿童与青少年膳食》直接衔接，也是配餐者给家长做「孩子长没长好」判断的工具。

## 4 实验室检查与临床体征

## 3 公式解析：BMI 与体脂的局限

BMI 是全场公式，但用它必须知道它的边界。把 BMI 公式拆开看：

$$\text{BMI} = \frac{\text{体重(kg)}}{\text{身高(m)}^2}$$

对这条式子做三步拆解：

- **第一步，理解分子分母**：分子是体重（kg）、分母是身高的平方（m²）——**BMI 的数学本质是「每平方米身高的体重」**，它把「胖不胖」压缩成一个与身高无关的指标，便于横向比较。
- **第二步，理解中国的切点**：中国成人标准 **< 18.5 消瘦、18.5–23.9 正常、24–27.9 超重、≥ 28 肥胖**——中国切点低于 WHO（≥ 25 超重、≥ 30 肥胖），因为亚洲人群在更低 BMI 时就出现代谢风险。
- **第三步，认识两大盲区**：其一，**BMI 不区分脂肪与肌肉**——健身者 BMI 27 可能体脂正常，肌肉发达者会被误判「超重」；其二，**BMI 不反映脂肪分布**——「四肢纤细、肚子很大」的瘦胖子 BMI 可能只有 22，代谢风险却高。**所以 BMI 必须与腰围、体脂分布联用**，这正是第2节「先量 BMI、再看腰围」的原因。

## 4 实验室检查与临床体征

人体测量的「外部」证据之外，还要「内部」证据——**实验室检查（生化）**与**临床体征**：

**常用生化指标**：血红蛋白（贫血，缺铁性贫血的确认手段）、血清白蛋白与前白蛋白（蛋白质营养不良）、血清铁与铁蛋白（铁储备）、血清钙磷、维生素 D、血脂血糖（代谢状态）。**生化检查把「营养状况」从「看得见的体型」推进到「看不见的血液」**——许多营养问题在体征出现前，生化指标已先亮红灯。

**临床体征**：缺铁性贫血的指甲苍白、嘴角开裂；维生素 C 缺乏的牙龈出血；蛋白质缺乏的水肿（凹陷性水肿）；碘缺乏的甲状腺肿大；钙缺乏的抽筋——**体征是营养缺乏的「体表信号」**，但多数缺乏早期无体征，不能等体征出现才干预。

**综合评价（综合评价法）**：把膳食调查 + 人体测量 + 生化 + 体征 + 个人史五路证据合起来下结论——**单一路证据只能提示，多路证据吻合才能确诊**。例如：膳食调查显示铁摄入不足 + 血红蛋白偏低 + 面色苍白，三者吻合，才敢下「缺铁性贫血」的判断；只凭「脸色白」不能诊断，只凭「铁摄入低」也不能。**「盲人摸象」式地只取一级证据，是营养评价最常见的错误。**

## 5 人体营养评价的实用流程

把上述工具组装成一套可操作的流程，配餐者按序执行：

**第一步，膳食调查**（第2篇）：摸清「吃了什么、吃了多少」——这是评价的第一路证据。

**第二步，人体测量**：量身高体重算 BMI，量腰围看腹部脂肪，必要时刻皮褶与上臂围——这是「身体怎样」的路标。

**第三步，实验室检查与体征**：看血常规、蛋白、铁等关键指标，观察皮肤黏膜体征——这是「内部真相」与「体表信号」。

**第四步，综合分析**：把五路证据对照 DRIs 与临床标准，识别「营养不足、营养过剩、营养不均衡」三类问题，输出「问题清单 + 优先干预项」。

**第五步，干预与复查**：按问题开膳食处方（食谱编制），设定复查节点（如减重 4 周后复查体重与腰围、贫血 3 个月后复查血红蛋白）——**评价不是一次性的体检，而是「评 → 干 → 再评」的闭环**，这与《社区营养管理》的「调查 → 干预 → 再调查」完全同构。

## 6 小结

- 营养评价五路证据：**膳食调查、人体测量、实验室检查、临床体征、个人史**——相互印证才能下结论。
- 不会人体测量，配餐就只是纸上谈兵——连「这个人该减到多重」都说不准，评价是配餐的事实基础。
- BMI 公式：$\text{BMI} = \dfrac{\text{体重(kg)}}{\text{身高(m)}^2}$；中国切点 **< 18.5 / 18.5–23.9 / 24–27.9 / ≥ 28**。
- BMI 的数学本质是「每平方米身高的体重」——它把「胖不胖」压缩成与身高无关的指标便于比较；中国切点低于 WHO，因为亚洲人群在更低 BMI 即出现代谢风险。
- 量体重要「清晨、空腹、排空大小便、赤足、着轻衣」，多次测量取稳——测量规范直接决定数据价值。
- BMI 两大盲区：**不区分脂肪肌肉、不反映脂肪分布**——必须与腰围、体脂分布联用；「瘦胖子」是被 BMI 掩盖的真实问题。
- 中心性肥胖切点：**男腰围 < 90 cm、女 < 85 cm**；上臂肌围 $\text{MAMC} = \text{MAC} - \pi \times \text{TSF}$ 反映肌肉储备。
- 腰臀比提示中心性肥胖：男 ≥ 0.90、女 ≥ 0.85；「苹果型（中心性）vs 梨型（外周性）」是脂肪分布最经典的比喻。
- 内脏脂肪是代谢危险分子：比皮下脂肪更易释放游离脂肪酸入肝，引发胰岛素抵抗与血脂异常——腰围被单列为独立风险指标。
- 生化与体征：血红蛋白、白蛋白、铁等先亮红灯；体征（贫血、牙龈出血、水肿）多数是「晚期信号」，不能等出现才干预。
- 常用生化速查：**血红蛋白查贫血、白蛋白/前白蛋白查蛋白质营养、血清铁与铁蛋白查铁储备、血脂血糖查代谢**——生化把「看得见的体型」推进到「看不见的血液」。
- 体征实例：缺铁性贫血指甲苍白嘴角开裂、维生素 C 缺乏牙龈出血、蛋白质缺乏凹陷性水肿、碘缺乏甲状腺肿大——多数缺乏早期无体征，不能等体征出现才干预。
- 综合评价法：**单路证据只能提示、多路吻合才能确诊**——「评 → 干 → 再评」是营养评价的闭环。
- 五步流程：**膳食调查 → 人体测量 → 生化与体征 → 综合分析 → 干预与复查**——评价不是一次性体检，而是「评 → 干 → 再评」的闭环。
- 干预与复查示例：减重 4 周后复查体重腰围、贫血 3 个月后复查血红蛋白——每个问题都要有复查节点。
- 「盲人摸象」式只取一级证据就下结论，是营养评价最常见的错误——五路证据相互印证是铁律。
- 理想体重速算：身高(cm) − 105，实际体重在理想体重 ±10% 内视为正常——配餐中常用来估算减重目标值。
- 测量规范决定数据价值：**同一时段、同一台秤、同样衣着**，把测量噪声压到最低——长期随访可比性的命门。
- 体脂率可从皮褶厚度推算（TSF 查公式），但卡尺操作一致性要求高——社区筛查用 BMI + 腰围快速分层，皮褶与上臂围用于医院营养科。
- 儿童生长评价：**身高体重对照生长曲线看百分位与 Z 分数**，曲线沿自身百分位平稳上行即正常，偏离两个主要百分位提示问题。
