## 为什么从一日三餐与一周食谱开始

前两节解决了「怎么编一天」，但生活是以「周」为节律的：上班族周中与周末的饮食完全不同，食堂要提前排出每周菜单，家庭要按周采购。**从「一天」跨到「一周」，不是简单的七倍复制**——它要解决轮换、均衡、采购、季节四个新问题。

本篇先讲一日三餐各自的定位与设计要点，再讲把七天连成一周的轮换原则，最后给出一周食谱的模板与评价方法。学完这一篇，配餐才算从「会编一天」进阶到「会管一周」——这也是营养配餐技术在家庭与食堂落地的主要形态。<span class="marginnote">营养评价讲「看多日平均、不较真单日」，一周食谱正是这一理念的落地载体：单日某营养素略高略低没关系，只要一周平均达标、结构不偏，就是一份合格的一周膳食。</span>

## 1 一日三餐：三种定位、三种节奏

三餐的能量分配我们在《食谱编制的基本原则与步骤》里定了 3:4:3，这里补上每一餐的「功能定位」：

**早餐：补一夜的亏空，定一天的血糖基调**。经过一夜禁食，肝糖原接近耗尽，早餐是一天第一次供能。营养质量上，理想早餐应包含「**主食 + 优质蛋白 + 奶或豆 + 蔬果**」四要素；现实中中式早餐最常见的缺口是「只有主食（粥+包子）或只有主食加咸菜」，蛋白质与蔬菜严重不足。<span class="marginnote">「早餐吃得像皇帝」是有代谢依据的：规律早餐与更好的体重控制、血糖平稳相关。跳过早餐会让午前血糖波动、午间报复性进食——配餐者给上班族与学生的第一条建议，往往就是「把早餐吃全」。</span>

**午餐：承上启下的能量主力**。承担全天 40% 的能量，要同时兼顾上午的消耗与下午的续航。上班族午餐最大的两个问题——**外卖高油高盐**与**蔬菜不足**，是《上班族、在外就餐与外卖配餐指导》的重点。

**晚餐：清淡、适量、不拖沓**。晚餐宜少而精，主食减量、蔬菜足量、荤菜适量，且不宜过晚——睡前 2–3 小时结束进食，让消化与睡眠互不干扰。把全天没吃够的蔬菜放在晚餐补齐，是常见且合理的策略。

三餐之间的**间隔以 4–5 小时为宜**，两餐间隔过短（零食不停）或过长（饥一顿饱一顿）都会扰乱血糖与食欲节律。

「**晚餐过饱、过晚**」是中国家庭膳食里最普遍的三个字组合：晚餐能量占比常冲到 50% 以上，而且睡前才吃。调整的办法不是粗暴减餐，而是「**早餐午餐补足、晚餐顺势减压**」——早餐与午餐吃够，晚餐自然不需要报复性进食；若三餐中间有加餐垫底，晚餐少而精就更容易执行。把晚餐从「一天的主餐」挪回「一天的收尾」，是三餐节奏管理的核心。

把三餐要点落到对比，一份「理想 vs 常见」的三餐观察能快速建立判断力：早餐「燕麦牛奶 + 鸡蛋 + 黄瓜」是四要素齐全，而「油条 + 豆浆（加糖）」是主食+油脂、缺蛋白与蔬果；午餐「杂粮饭 + 清蒸鱼 + 双色菜」是满分结构，而「盖浇饭 + 奶茶」是碳水超载、蔬菜不足；晚餐「杂粮粥 + 凉拌菜 + 少量瘦肉」宜人，而「烧烤 + 啤酒」是高脂高盐且过晚。**配餐者的日常训练，就是把每一餐自动翻译成这张结构表**——无需上秤，一眼即判。

学生与上班族常在午晚餐间隔太长，需要**加餐**作缓冲：上午 10 点或下午 3 点，一份水果、一杯酸奶、一小把坚果即可。加餐的能量从相邻正餐「匀」出来（前面已讲），而不是另加——这样既防止两餐间过度饥饿导致的暴食，又不破坏全天能量框架。**加餐的落点优先级：奶 > 水果 > 坚果 > 全谷点心 > 甜点**，按这个顺序选，加餐就变成了营养的补丁而非能量的漏洞。

## 2 一周食谱的轮换原则

把七天排成一周食谱，核心是四个轮换维度：

**食材轮换**：同一类食物在不同日子换品种——今天猪肉、明天鱼、后天鸡肉；今天菠菜、明天西兰花、后天番茄。这既是食物多样（每周 25 种）的要求，也避免营养素的单调。

**烹调轮换**：同一食材换做法——同样一条鱼，清蒸、红烧、做汤轮流来。烹调方式的差异直接影响油盐用量与营养素保留，轮换烹调也是口味不腻的关键。

**颜色轮换**：把「红、黄、绿、白、黑」五种颜色的蔬菜水果排进一周——深色蔬菜过半的原则，落实到具体天数就是「每天至少一种深绿/红/橙蔬菜」。

**口味轮换**：酸甜苦辣咸、清淡与浓郁搭配，让一周菜单有起伏。完全清淡的七天和连续重口味的七天，都难以为继。

轮换背后还有一个不易察觉的均衡保障：**把「高脂高蛋白日」与「清淡高纤日」交叉排布**。比如周二有红烧排骨，周三就配清淡的蒸鱼与大量蔬菜；周五外食概率高，周四晚餐就可以先清淡一些。这种「肥瘦相间」的排布让一周的脂肪与钠摄入不至于堆积在某几天——**单看一天也许略高，连起来看七天却始终在合理区间内摆动**，这正是轮换高于「每天雷同」的营养价值。

轮换的副产品是**采购的节奏化**：肉类与耐储蔬菜（根茎、蛋奶）可一次采购数日，叶菜类少量多次。一周食谱排好了，采购清单、成本预算、烹饪计划都随之确定——这是家庭与食堂都受益的「食谱杠杆」。

一个采购模板能说明这份杠杆：周初一次性采购**耐储品**（鸡蛋、牛奶、豆腐、根茎类土豆胡萝卜、冷冻鱼虾、杂粮）；**叶菜与鲜活水产**按 2–3 天一次补购；**调味品与干货**（木耳、海带、干香菇）按月储备。这样一周只需出门采购 2–3 次，既保证食材新鲜，又避免「天天买菜做饭却天天凑合」。**食谱先排、采购后行**，是家庭膳食管理效率的关键。

## 3 公式解析：一周食谱的七日平均评价

一周食谱「合不合格」，不能只看某一天，要看七天平均。评价公式就是平均数：

$$\bar{X}_i = \frac{\sum_{d=1}^{7} X_{i,d}}{7}$$

其中 $X_{i,d}$ 是第 $d$ 天某种营养素的摄入量，$\bar{X}_i$ 是这种营养素一周的平均每日摄入量。

对这条式子做三步拆解：

- **第一步，逐日核算**：把七天各自的食谱分别核算出能量与关键营养素（至少能量、蛋白质、脂肪、碳水，以及钙、铁等关注项）。
- **第二步，求平均**：把同一营养素七天相加除以 7，得平均每日摄入。这一步正是「看多日平均」的量化实现——单日 85% 或 115% 的波动，在平均值里被平滑。
- **第三步，与目标对照**：把七天平均值与 RNI/EER 比较，并检查七天里**没有连续多日同方向偏离**（如天天都少蔬菜）。平均达标 + 结构均衡，一周食谱即判合格。

实践中还有个简化指标：**一周内各类食物的「份数合计」是否落在推荐范围**。用交换份法排的一周食谱，直接数七天各类份数总和再除以 7，比对「每日应吃份数」，比逐营养素核算更快——这也是交换份法适合一周食谱的原因。

**辨析｜易错点**：排一周食谱最常踩的坑是「前紧后松」——周一到周四排得精致，周五到周日放任自由（聚餐、外卖、火锅）。这种模式让七天平均看起来「还行」，实则周末两天大幅超标、周中两天凑合，血糖与体重的波动反而更大。**一周食谱的合格线不是「平均对」，而是「每天都大体对」**——周末可以略宽，但不能用「一周平均」给自己开脱。这也是为什么评价要看「结构均衡」而不只看均值。

设计一周食谱时，还应把**作息与社交**写进变量：周一早晨常常匆忙，早餐就要「快而全」（隔夜燕麦、煮蛋、牛奶）；周三常有加班，晚餐宜预留「应急健康餐」（冷冻杂粮饭、速冻蔬菜、即食鸡胸）；周五晚上聚餐概率高，白天两餐可适当清淡留出弹性。**食谱不是贴在墙上的教条，而是随一周真实节律微调的基线**——排一周食谱的本事，一半在排，一半在「留缝」。

## 4 一周食谱模板与实操

给一个「一周食谱怎么搭」的骨架模板（以 2000 kcal、轻体力成人为例，仅列每餐主结构，供套用）：

| 星期 | 早餐 | 午餐 | 晚餐 |
| --- | --- | --- | --- |
| 一 | 燕麦牛奶 + 鸡蛋 + 拌黄瓜 | 杂粮饭 + 青椒肉丝 + 菠菜汤 | 全麦馒头 + 清蒸鲈鱼 + 凉拌木耳 |
| 二 | 全麦面包 + 酸奶 + 番茄 | 米饭 + 土豆炖牛肉 + 蚝油生菜 | 小米粥 + 芹菜炒香干 + 拌三丝 |
| 三 | 菜肉馄饨 + 豆浆 | 米饭 + 香菇鸡块 + 蒜蓉西兰花 | 玉米 + 虾仁豆腐 + 紫菜蛋花汤 |
| 四 | 小米南瓜粥 + 茶叶蛋 + 苹果 | 杂粮饭 + 番茄牛腩 + 清炒茼蒿 | 荞麦面 + 凉拌鸡丝 + 白灼菜心 |
| 五 | 玉米 + 牛奶 + 鸡蛋 + 猕猴桃 | 米饭 + 糖醋里脊(少油) + 炒合菜 | 山药粥 + 清蒸带鱼 + 蒜蓉蒿子秆 |
| 六 | 鸡蛋灌饼(少油) + 豆浆 + 橙子 | 米饭 + 红烧排骨(去油) + 木耳炒山药 | 杂粮粥 + 白切鸡 + 上汤娃娃菜 |
| 日 | 燕麦粥 + 牛奶 + 核桃 + 圣女果 | 三鲜水饺 + 凉拌莴笋 | 杂粮饭 + 番茄蛋汤 + 蒜香空心菜 |

读这张模板的三条心法：其一，**同类食物在七天里轮流换**——鱼虾、禽、猪牛、蛋、豆制品各占几天，避免天天红肉；其二，**每餐都有蔬菜，深色（菠菜、西兰花、生菜、茼蒿）过半**；其三，**烹调方式轮换**——蒸、煮、炖、炒、凉拌搭配，油盐自然降下来。套用模板时，把每一格替换成当地当季食材即可。

**季节调整**是实操的最后一笔：夏季汤羹多、清淡、补水分与钾；冬季适当增加温热炖煮；春秋按应季蔬果轮换。**因时因地制宜**从原则落到了一周模板里。

模板还要适配「**用餐人数**」。一人食或小家庭做饭，批量做一次吃两顿是常见策略：一次炖一锅杂粮饭、卤一锅鸡蛋与豆干，分装冷藏，随取随用——既省时间又避免「一人吃饭难做菜」导致的凑合。食堂与多人家庭则相反，重点在「**分工与标准化**」：每周菜单固定框架、每日按清单执行，采购与烹饪都成流水线。**食谱的颗粒度要匹配用餐规模**，这是模板落地时最容易忽略的变量。

**成本控制**是食堂与家庭都要算的账。三个省钱的营养学做法：其一，**优质蛋白梯度选材**——鱼虾贵时用豆腐、鸡蛋、禽肉替代，蛋白质量照样够；其二，**耐储 vs 鲜食搭配**——根茎类与冻品做底，鲜叶菜点缀，既省成本又保新鲜；其三，**应季采购**——当季蔬果量大价低、营养也不差。**省钱的第一原则不是「吃得差」，而是「换得巧」**——同类内替换，营养不掉队、预算降下来。

## 5 小结

- 三餐定位：**早餐补亏空（主食+蛋白+奶豆+蔬果四要素）、午餐承上启下（40%）、晚餐清淡适量且不拖沓**；间隔 4–5 小时。
- 一周轮换四维度：**食材、烹调、颜色、口味**；轮换带来采购与成本的节奏化。
- 七日平均评价：$\bar{X} = \sum X_i / 7$
