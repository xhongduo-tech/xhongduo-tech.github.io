## 为什么从学龄儿童与青少年膳食开始

学龄儿童（6–17 岁）处于**生长发育的第二个高峰**：青春期前的稳步生长、青春期的突增、大脑与骨骼的快速发育，都压在这十几年里。同时，这个阶段也是**饮食行为独立化**的时期——孩子开始自己买零食、点外卖、参加聚餐，「家长喂什么吃什么」变成「他自己选择吃什么」。

对配餐者而言，这个人群最特殊的一点是**「高需求 + 高自主」并存**：营养需要量接近甚至超过成人（钙、铁、蛋白质），但进食行为却更难管控。策略要从「设计食谱」转向「设计环境 + 培养能力」——把健康食物放在伸手可及处，把选择权逐步交给孩子，同时教他读懂零食与饮料的代价。<span class="marginnote">青少年期还是「骨量储备」的最后窗口：人体骨量峰值大约在 20–30 岁达到，青春期是骨量增长最快的阶段。<strong>成年后的骨质疏松风险，很大一部分在少年时喝下去的牛奶量里就定了</strong>——这是「钙」在这个人群被反复强调的根本原因。</span>

## 1 生长突增与营养需求

学龄儿童与青少年的营养需求，随生长节奏分两段：

**学龄期（6–11 岁）**：生长平稳，但学习任务重、活动量大。能量与蛋白质需要量稳步上升；钙每日 **800–1000 mg**；铁的需求已开始分化（女孩因月经初潮渐至，铁需要量上升）。

**青春期（12–17 岁）**：生长突增，身高体重快速增长，能量与蛋白质需要达到高峰——**部分青少年的能量需要甚至超过其父母**（男孩尤甚）。此时营养素需要全面上调：钙 **1000–1200 mg**、铁（男孩约 16 mg、女孩约 18 mg）、锌、碘、维生素 D。

青少年的能量需要高，但**「高能量」不等于「高垃圾」**：突增期需要的是充足的蛋白质、钙与微量营养素来「长骨头长肉」，而不是用薯片奶茶的「空能量」填饱。供能比仍应守住 AMDR，只是总量大了、餐次可以灵活。

「**长个子是不是要多吃**」是家长的常见疑问，答案是「多吃但要吃对」：生长突增确实需要能量盈余，但这个盈余应来自**主食、优质蛋白与奶类**，而非甜食与油炸。判断孩子吃没吃对，可以看一条简单规律——**正餐吃饱 + 加餐有奶有水果，比「零食管够」更能支持长高**。身高主要由遗传与生长激素决定，营养是「别拖后腿」的保障，而不是「多吃就能长得更高」的开关；配餐者要同时传递这两层真相，避免家长陷入「喂得越多越好」的误区。

**体重管理**在学龄期是个敏感话题：儿童期超重肥胖会「轨迹追踪」到成年，但**儿童减重不能照搬成人节食**——必须保证生长所需的能量与营养，用「控制增重速度、改善体成分」的思路替代「掉秤」。这一差异在《吃动平衡与体重管理》里会专门展开。

学龄儿童还有两个「时段」值得专门安排：**考试季**——大脑高强度运转，早餐与加餐要保证平稳供能，零食选坚果、水果与酸奶，避开高糖甜食（血糖大起大落反而不利专注）；**运动训练日**——体育生或运动量大的孩子，运动前后要补能补水，训练后 1 小时内补充「碳水 + 蛋白」（牛奶燕麦、面包加鸡蛋）促进恢复。**把营养按「脑力日」与「体力日」微调**，是青少年配餐比成人更精细的一层。

## 2 关键营养素：钙、铁、锌与视力保护

青少年膳食里有四个「盯住不放」的营养素：

**钙（1000–1200 mg/d）**：骨量峰值期的第一建材。来源仍是奶及奶制品优先——**「每天 300 mL 奶 + 一份酸奶/奶酪」是青少年钙的底子**；豆制品、绿叶菜补充。青春期钙摄入不足，成年后骨折风险上升，且无法完全补偿。

把 1200 mg 的钙目标翻译成食物：300 mL 牛奶（约 310 mg）+ 一杯酸奶（约 160 mg）+ 一块北豆腐（约 150 mg）+ 一小碟芝麻酱拌菠菜（约 100 mg）+ 其他食物零星凑齐，基本能摸到目标。**「奶 + 豆 + 绿菜」三位一体**是青少年补钙最可执行的公式；只靠其中一样，很难凑足量。乳糖不耐受者可用酸奶、无乳糖奶或奶酪替代——目标是「钙够」，载体可以灵活。

**铁**：青春期缺铁性贫血高发，女孩尤甚（月经失血 + 生长快）。红肉、动物血、肝脏是高效来源；配合维生素 C 提升吸收。**「青春期女孩要特别盯铁」**——这是很多人忽略的人群细节。

缺铁的青少年常表现「没精神、上课走神、面色偏白」，家长与老师容易误判为「懒」或「不爱学习」。**一次血红蛋白检查就能分辨**；膳食上给青春期女孩每周安排 1–2 次动物血或肝脏，配合维生素 C 丰富的蔬果，是成本最低的预防。男孩虽无月经失血，但生长突增期血容量扩张同样推高铁需要，不能掉以轻心。

**锌**：参与生长激素相关代谢与性发育，缺锌影响身高增长与食欲。贝类、红肉、坚果来源充足。

**维生素 A 与视力**：近视是学龄儿童的高发问题，营养上**维生素 A 维护视网膜健康**，深色蔬果（胡萝卜、菠菜、南瓜）与蛋黄是来源；但**营养不能逆转已经形成的近视**，户外活动（每天 ≥ 2 小时）才是被证据支持的近视防控手段——这已超出「营养配餐」，却是青少年膳食建议里绕不开的一条。<span class="marginnote">「护眼食物」宣传常夸大功效——维生素 A 缺乏确实影响视觉，但「多吃胡萝卜治近视」没有依据。配餐者要诚实：营养保障视力健康的基础，户外活动才是近视防控的主力，两者不冲突但要分清主次。</span>

**锌与身高食欲**：锌参与生长激素相关代谢与性发育，缺锌影响身高增长与食欲——贝类、红肉、坚果是来源，植酸多的粗粮会抑制锌吸收。把钙、铁、锌、维 A 四样「盯住不放」合起来看，**青少年膳食的核心是「营养密度优先」**：突增期需要的是「长骨头长肉」的原料，而不是薯片奶茶的「空能量」——供能比仍守住 AMDR，只是总量大了、餐次可以灵活。

**校园营养的现实落点**：学龄儿童一半的餐在校园解决，因此**学校食堂与配餐是青少年营养的重要战场**——午晚餐要保证「主食 + 优质蛋白 + 足量蔬菜」的结构、限制油炸与含糖饮料、提供奶与水果。配餐者与学校营养师的工作，是把《一日三餐与一周食谱设计》的模板落到校园场景，并借《社区营养管理》的知信行模型做学生营养教育——**青少年营养，一半在家庭、一半在校园**。

## 3 公式解析：早餐能量占比与「营养早餐」

早餐与学龄儿童的表现直接相关——**不吃早餐或早餐质量差的儿童，上午注意力与学习效率下降**。早餐的量化要求是能量与质量双达标：

$$E_{\text{早餐}} = (0.25\sim0.30) \times E_{\text{全天}}$$

对这条式子做三步拆解：

- **第一步，取能量占比**：早餐应占全天能量的 25%–30%——略高于成人的 30% 或接近它，因为学生上午用脑负荷重、且午餐前间隔长。以 2000 kcal 的中学生为例，早餐约 500–600 kcal。
- **第二步，配「营养早餐」四要素**：**主食（供能）+ 优质蛋白（蛋/奶/豆）+ 奶或豆（钙与蛋白）+ 蔬果（维生素纤维）**——四要素齐全才算「营养早餐」，只有「粥 + 包子 + 咸菜」这类「纯碳水 + 高盐」组合不算。
- **第三步，读执行落点**：一份达标早餐如「牛奶燕麦 + 煮蛋 + 苹果」，约 400–500 kcal、四要素齐全；对比「白粥 + 油条 + 咸菜」——能量相近，但蛋白、钙、蔬果全缺，血糖还先升后跌。**早餐的「质量」比「有没有吃」更关键**，这是配餐者给家长最重要的早餐信息。

## 4 零食与加餐：把「零食」变成「营养补给」

学龄儿童几乎天天吃零食，与其禁止，不如**把零食纳入膳食设计**：

**加餐定位**：正餐之外的上下午加餐，能量从相邻正餐「匀」出（一日三餐两点），总量不增——加餐防止两餐间隔过长导致的暴食，也让全天营养更均匀。

**零食「红绿灯」**：**绿灯**（放心吃）——水果、原味坚果、酸奶、全麦面包、牛奶；**黄灯**（限量）——饼干、蛋糕、含糖酸奶；**红灯**（尽量不碰）——薯片、糖果、含糖饮料、油炸小食。<span class="marginnote">「零食红绿灯」是给家长与孩子共用的工具：<strong>让孩子自己把零食分成红黄绿灯三堆，比家长单方面禁止更有效</strong>——因为判断力内化，比规则外施加更持久。这也是《社区营养管理》「知识要变成行为」在家庭里的缩影。</span>

**喝水替代含糖饮料**：含糖饮料是青少年添加糖的主要来源——一瓶 500 mL 含糖饮料约 40–50 g 糖，几乎抵一天上限。**用白水、淡茶、无糖奶替代饮料**，是青少年控糖的第一招。

## 5 一日膳食与特别提示

把学龄儿童与青少年要点落成一日膳食（14 岁男孩，约 2400 kcal）：

- **早餐**：牛奶燕麦 + 鸡蛋 + 香蕉——四要素齐全；
- **上午加餐**：酸奶 + 一小把核桃;
- **午餐**：杂粮饭 + 土豆炖牛肉 + 蒜蓉西兰花——蛋白质、铁、蔬菜齐备;
- **下午加餐**：苹果 + 全麦面包;
- **晚餐**：米饭 + 清蒸鱼 + 凉拌菠菜 + 豆腐汤——晚餐适量、鱼虾补 DHA;
- **饮水**：白水为主，约 1500 mL。

设计逻辑：**三餐两点分散能量与营养素、每餐有优质蛋白与蔬菜、加餐用绿灯零食、全天无含糖饮料**——高需求（钙铁锌、能量）与高自主（零食、饮料）在方案里同时被照顾。

**特别提示三则**：其一，**运动少年**要运动前后补能补水、训练后 1 小时内「碳水 + 蛋白」（牛奶燕麦、面包加蛋）促恢复；其二，**考试季**要保证早餐与加餐平稳供能，零食选坚果水果酸奶、避开高糖甜食；其三，**视力保护**靠每天户外活动 ≥ 2 小时，深色蔬果补维 A 是辅助而非主力——营养不能逆转已成形的近视。

## 6 小结

- 学龄期与青春期两段：**学龄期钙 800–1000 mg、青春期钙 1000–1200 mg**；青春期能量需要甚至超过父母，但「高能量」不等于「高垃圾」。
- 学龄期（6–11 岁）生长平稳、学业重；青春期（12–17 岁）生长突增、能量蛋白质需要达高峰——「高需求 + 高自主」并存是这个人群最特殊的点。
- 策略从「设计食谱」转向「设计环境 + 培养能力」：健康食物放伸手可及处、选择权逐步交给孩子、教他读懂零食与饮料的代价。
- 骨量储备的最后窗口在青春期：**成年后的骨质疏松风险，很大一部分在少年时喝下去的牛奶量里就定了**——「每天 300 mL 奶 + 一份酸奶/奶酪」是青少年钙的底子。
- 乳糖不耐受者用酸奶、无乳糖奶或奶酪替代——目标是「钙够」，载体可以灵活。
- 锌参与生长激素相关代谢与性发育：贝类红肉坚果来源，粗粮植酸会抑制锌吸收——补锌配蛋白、别配浓茶。
- 青春期的铁与锌：**女孩盯铁（月经失血 + 生长快），男孩也别掉以轻心（血容量扩张）**；贝类红肉坚果补锌。
- 缺铁青少年常「没精神、上课走神、面色偏白」，易被误判为「懒」——一次血红蛋白检查即可分辨；每周 1–2 次动物血或肝脏 + 维 C 蔬果是最低成本的预防。
- 早餐公式：$E_{\text{早餐}} = (0.25\sim0.30) \times E_{\text{全天}}$；四要素「主食 + 蛋白 + 奶豆 + 蔬果」齐全才算营养早餐。
- 早餐「质量」比「有没有吃」更关键：「牛奶燕麦 + 煮蛋 + 苹果」vs「白粥 + 油条 + 咸菜」——能量相近，但蛋白钙蔬果全缺、血糖还先升后跌。
- 「长个子是不是要多吃」的答案是「多吃但要吃对」：盈余来自主食、优质蛋白与奶类，而非甜食与油炸。
- 1200 mg 钙的翻译：「300 mL 奶 + 一杯酸奶 + 一块北豆腐 + 一小碟芝麻酱拌菠菜」——「奶 + 豆 + 绿菜」三位一体是青少年补钙最可执行的公式。
- 零食红绿灯：**绿灯水果奶坚果放心吃、黄灯甜点限量、红灯薯片糖果饮料尽量不碰**——把「零食」变成「营养补给」。
- 含糖饮料是青少年添加糖的主要来源：一瓶 500 mL 含糖饮料约 40–50 g 糖——**用白水、淡茶、无糖奶替代饮料**，是青少年控糖第一招。
- 青少年期是「骨量储备」的最后窗口：人体骨量峰值约在 20–30 岁达到——成年后的骨质疏松风险，很大一部分在少年时喝下去的牛奶量里就定了。
- 视力保护靠户外活动每天 ≥ 2 小时，深色蔬果补维 A 是辅助而非主力——营养不能逆转已成形的近视，配餐者要诚实传达这一主次。
- 儿童减重不能照搬成人节食：**控制增重速度、改善体成分**，保证生长所需的能量与营养——「轨迹追踪」到成年。
- 青春期能量需要甚至超过父母（男孩尤甚），但「高能量」不等于「高垃圾」——突增期需要的是蛋白、钙与微量营养素来「长骨头长肉」。
- 身高主要由遗传与生长激素决定，营养是「别拖后腿」的保障而非「多吃就能长高」的开关——「长个子要多吃」的答案是「多吃但要吃对」。
- 学生与考试季/运动日微调：脑力日零食选坚果水果酸奶，体力日训练后 1 小时「碳水 + 蛋白」促恢复——按「脑力日」与「体力日」微调是青少年配餐的精细层。
- 青少年四大「盯住不放」：**钙、铁、锌、维生素 A**——「奶 + 豆 + 绿菜」补钙、动物血肝补铁、贝类坚果补锌、深色蔬果蛋黄补维 A。
- 校园营养是青少年膳食的另一半：学校食堂要保证「主食 + 优质蛋白 + 足量蔬菜」结构、限制油炸与含糖饮料、提供奶与水果——配餐者的工作一半在家庭、一半在校园。
