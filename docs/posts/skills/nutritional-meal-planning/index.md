# 营养配餐与膳食设计

把《中国居民膳食指南（2022）》落到一日三餐，以《公共营养师》职业技能标准为纲，结合《营养配餐技术》的方法论，系统重建从营养学基础、膳食调查与评价、食谱编制、人群配餐到慢病膳食干预的完整职业技能体系。学完这些章节，就写完了公共营养师营养配餐与膳食设计的全部内容。
