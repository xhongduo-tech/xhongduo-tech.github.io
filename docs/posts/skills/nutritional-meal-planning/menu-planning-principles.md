## 为什么从食谱编制开始

前两篇都在「读」：读一个人的膳食、读他的身体、读 DRIs 标尺。从第3篇起，工作翻转成「写」——**为一个人或一群人设计出具体的一日三餐**，让这张食谱在能量、营养素、食物多样性上都站得住脚。这一步，就是**食谱编制**，营养配餐技术的核心技艺。

食谱编制不是凭感觉排菜，而是有原则、有步骤、有计算的工作。本篇先立住六条基本原则，再给出从「定目标」到「落餐桌」的标准步骤，最后讲如何用营养素计算对食谱做「出厂质检」。这一篇是第3篇的总纲，后面《营养素计算法》《食物交换份法》《一周食谱设计》都是在它的框架里展开的两种算法。<span class="marginnote">把食谱编制想成「倒推工程」：膳食调查是「吃进去 → 算出来」，食谱编制是「目标值 → 设计吃什么」。第2篇的 DRIs、宝塔、食物成分表，在这里全部变成图纸上的工具。</span>

食谱按用途分两类，编制时先要明确做哪一种：**普通食谱**面向健康人群，目标是「满足 RNI、结构均衡」；**治疗食谱**面向患病人群（糖尿病、高血压、肾病等），在普通食谱基础上叠加疾病约束（限糖、限盐、限蛋白）。本篇讲的是普通食谱的通用框架，第5篇各慢病膳食就是在它之上加「治疗约束」。**先把通用框架做扎实，再学叠加约束**——这是本专题刻意安排的进阶顺序。

## 1 食谱编制的六条基本原则

**食谱（dietary menu）**：为特定对象设计的一日或一段时间内各餐食物的种类、数量与烹调方式的安排。优秀的食谱要同时满足六条原则：

先给一个「长什么样」的直觉。一份标准的一日食谱，通常包含三张表：**食物清单**（按餐次列出食材与克数）、**烹调方式说明**（蒸煮炒炖的选择）、**营养素分析表**（能量、蛋白、脂肪、碳水及若干重点维生素矿物质与目标对照）。这份「清单 + 做法 + 核算」的三件套，是食谱的完整形态——少了任何一张，都只是不完整的食谱。

**营养平衡原则**：能量与各营养素满足目标对象的需要，供能比落在 AMDR 内。这是第一原则——食谱可以不够精致，但不能营养失衡。

**食物多样原则**：每日 ≥ 12 种、每周 ≥ 25 种食物，五大类齐全，粗细、荤素、深浅搭配。多样化是营养素「覆盖度」的保证。

**三餐合理分配原则**：能量按比例分给早、午、晚三餐（常规 3:4:3），两餐间隔适宜，晚餐不过饱。

**促进食欲原则**：色、香、味、形、器兼顾，品种与烹调方法在一周内轮换，避免单调。营养再好的食物，吃不进去等于零——这是食谱的「可接受性」。

**因人、因时、因地原则**：结合对象的年龄、性别、生理状况、劳动强度与健康状况，结合季节（夏季清淡、冬季暖补）与地域食材供应，结合经济条件。

**安全卫生原则**：食材新鲜、生熟分开、避免高油高盐高糖与反式脂肪，特殊人群避开过敏原与禁忌食物。

六条原则不是并列的装饰，而是有主次的约束：**营养平衡是第一约束，其余是在满足它的前提下做优化**——若「好吃」与「营养」冲突，好吃必须让步。

原则之间的冲突在真实配餐里天天发生，处理办法是「分级妥协」：**对象条件**（疾病、禁忌）优先于**多样化**，多样化优先于**口味偏好**，口味偏好优先于**成本**。比如给糖尿病老人配餐，营养平衡与安全卫生不可让步，但可以在满足降糖目标的前提下，尽量选他爱吃的烹调方式——**在约束内优化可接受性，而不是在口味内迁就营养**。这一「约束分层」的思维，是配餐从「会算」走向「会配」的标志。

## 2 编制步骤：从目标到餐桌的六步

把原则变成操作，公共营养师通常走六步：

**第一步，确定对象与目标**：明确就餐者的年龄、性别、身高体重、劳动强度与健康状态，计算出目标能量（EER）与营养素目标（RNI）。这是全部后续工作的输入。

**第二步，分配三大营养素**：按 AMDR 把能量拆成碳水、蛋白质、脂肪的供能比，再除以能量系数得克数。这一步我们在《能量与宏量营养素》的公式解析里已经练过。

**第三步，确定食物种类与数量**：把克数翻译成食物——按宝塔各类食物的配额，选主食、蔬菜、水果、动物性食物、奶豆的品种与数量。

**第四步，分配三餐**：把全天食物按 3:4:3 的能量比（或 2:4:4）分配到早午晚三餐，加餐并入相邻餐次。

**第五步，落成食谱**：为每餐设计菜品组合与烹调方式，写出「食材 + 重量 + 做法」的清单，兼顾色香味形与轮换。

**第六步，核算与调整**：用食物成分表把食谱折算成能量与营养素，与目标比对；偏差大就调整食材种类或重量，直到各项达标。<span class="marginnote">第六步是「质检关」。一张食谱不经过核算，就像没有测试的软件——看起来漂亮，一跑（吃）就崩。专业配餐的食谱附带的营养素分析表，就是这步的产出。</span>

把六步压进一张「编制工作表」，是新手快速上手的方式。工作表的列是**餐次、食物、重量、可食部、能量、蛋白质、脂肪、碳水、钙、铁**，行是三餐与加餐，底部是合计与目标对照。每填入一个食物就同步折算营养素，编完即得核算表——**编制与核算在同一张表里完成**，正是「边设计边质检」的工程习惯。这样的表格模板，在《营养配餐技术》与公共营养师教材中都直接提供，可直接套用。

## 3 公式解析：三餐能量分配

六步中的第四步需要一个可量化的分配规则。三餐能量分配最常见的公式是「3:4:3」：

$$E_{\text{早}} = 0.3E,\qquad E_{\text{午}} = 0.4E,\qquad E_{\text{晚}} = 0.3E$$

其中 $E$ 是全天目标能量，0.3、0.4、0.3 分别是早、午、晚餐的能量占比。

对这条式子做三步拆解：

- **第一步，为什么要按比例分**：全天营养目标必须落到每餐才能执行。按比例分配，保证「每餐都营养、三餐合起来才完整」，而不是「午餐大吃、早晚凑合」。
- **第二步，比例从哪来**：3:4:3 假设午餐承担一天最大能量、早晚餐均衡——符合多数上班族的进食节奏。若对象有加餐习惯或早餐占比应更大（如学生、体力劳动者），可调整成 2:4:4 或 3:4:3+加餐。
- **第三步，算例**：目标能量 $E = 2000$ kcal，则早餐 $600$、午餐 $800$、晚餐 $600$ kcal。把能量比例再折成各类食物：若早餐 600 kcal，主食约 80 g 生米 + 1 个蛋 + 250 mL 奶 + 一份蔬果，正好凑成「主食 + 蛋白 + 奶豆 + 蔬果」的四要素早餐——**能量比例落到食物，是食谱从「数学」变「饭菜」的一步**。

## 4 食谱的合理搭配与多样化

六步法的第三步「确定食物种类与数量」，是合理搭配落进食谱的关键环节，配餐者要同时看四层：

**按宝塔配额选食物**：谷薯、蔬果、动物性食物、奶豆、油盐五类各有配额（见《食物多样》与《膳食宝塔》），食谱先保证五大类齐全，再谈其他。

**三餐各有侧重**：早餐重「快而全」（主食 + 蛋白 + 奶 + 蔬果）、午餐重「能量与结构」（承上启下、蔬菜足量）、晚餐重「清淡适量」（少油少盐、不拖沓）——三顿不是复制三遍，而是分工。

**一周内轮换**：同一类食物换品种（鱼禽蛋肉轮流、蔬菜深色换浅色）、烹调方式轮换（蒸炒煮炖凉拌搭配）——食谱的可接受性与多样性，都靠轮换。

**因人因时因地**：按对象的劳动强度、健康状况微调总量；按季节调结构（夏季清淡多汤、冬季暖补）；按地域与预算选食材——**食谱不是模板的照搬，而是模板的适配**。

**辨析｜易错点**：食谱编制最常见的错误是「先想菜、后算营养」——从「今天吃什么」出发，容易做出「看起来合理、算起来超标」的食谱。正确顺序是**「先定能量与营养素目标，再选食物与重量」**——从目标倒推，而不是从菜名正推。这与第2篇膳食调查的「先算摄入、再对目标」正好是同一个「目标导向」方法论的两面。

## 5 食谱的质检：营养素核算与评价

食谱编完不核算，等于没有质检。营养素核算与评价分三步：

**第一步，用成分表折算**：把食谱的每种食物按《食物成分表应用》的公式折算出能量与关键营养素（至少能量、蛋白质、脂肪、碳水、钙、铁）。

**第二步，与目标对照**：能量与 RNI/EER 比较——能量偏差 ±10% 以内可接受，超过 ±10% 需调整；蛋白质、脂肪、碳水供能比落在 AMDR 内；重点矿物质（钙、铁、锌）尽量接近 RNI。

**第三步，多日平均再验**：单日食谱难免波动，用 3 天或一周平均再对照一次（《一日三餐与一周食谱设计》会展开）——**「看多日平均、不较真单日」**是食谱评价的又一准则。

**评价的快捷指标**：食物种类数（≥ 12 种/日）、深色蔬菜占比、优质蛋白占比（≥ 1/3）、油盐用量是否符合宝塔——这四条不用查成分表也能粗检，是配餐者在食堂与家庭场景里「一眼过」的质检清单。**质检的意义在于「发现问题就调整」**：能量偏高则减主食或油、钙不足则加奶豆、蔬菜不足则加菜——调整后再次核算，直到各项达标。这张「编 → 算 → 调 → 再算」的循环，正是营养配餐技术的日常。

## 6 小结

- 食谱编制六原则：**营养平衡（第一）、食物多样、三餐合理分配、促进食欲、因人因时因地、安全卫生**；冲突时按「疾病约束 > 多样 > 口味 > 成本」分级妥协。
- 六步法：**定目标 → 拆营养素 → 定食物 → 分三餐 → 落成食谱 → 核算调整**；编制与核算在同一张表里完成。
- 三餐能量公式：$E_{\text{早}} = 0.3E,\ E_{\text{午}} = 0.4E,\ E_{\text{晚}} = 0.3E$；可调整为 2:4:4 或加餐。
- 食谱编制想成「倒推工程」：膳食调查是「吃进去 → 算出来」，食谱编制是「目标值 → 设计吃什么」——第2篇的 DRIs、宝塔、成分表在这里全部变成图纸上的工具。
- 合理搭配四层：**宝塔配额、三餐分工、一周轮换、因人因时因地**——食谱是模板的适配而非照搬。
- 六条原则不是并列的装饰而是有主次的约束：**营养平衡是第一约束，其余是在满足它的前提下做优化**——「好吃」与「营养」冲突时，好吃让步。
- **辨析｜易错点**：先想菜后算营养是食谱编制最常见错误——正确顺序是「先定目标、再选食物」。
- 六步压进一张「编制工作表」：列是餐次、食物、重量、可食部、能量与营养素，行是三餐与加餐，底部合计对照目标——编制与核算同表完成。
- 食谱按用途分普通与治疗两类：普通食谱满足 RNI 与结构均衡，治疗食谱在普通基础上叠加疾病约束——先做扎实通用框架，再学叠加约束。
- 质检三步骤：**成分表折算 → 与目标对照（±10% 内）→ 多日平均再验**；快捷指标「种类数、深色菜、优质蛋白、油盐用量」一眼过。
- 一份标准食谱的三件套：**食物清单（餐次 + 食材 + 克数）、烹调方式说明、营养素分析表**——少了任何一张都只是不完整食谱。
- 「编 → 算 → 调 → 再算」的循环是营养配餐的日常：发现问题就调整，调整后再核算，直到各项达标。
- 质检关的比喻：第六步核算之于食谱，如测试之于软件——「看起来漂亮，一跑（吃）就崩」的食谱，都是跳过核算的结果。
