## 为什么从素食人群开始

素食在中国既古老又新兴：宗教性素食传统深厚，近年的健康与环保素食也迅速增长。对配餐者而言，素食人群是个「高专业要求」的群体——**素食不是简单的「去肉」，而是「重新设计」**：动物性食物提供的优质蛋白、血红素铁、维生素 B₁₂、高吸收率钙与 n-3 脂肪酸，在纯素膳食里全部缺位，必须靠食物组合与补充剂补上。

本篇先分清素食的类型，再逐一拆解五大营养风险点，用「谷豆互补」与关键营养素对策表给出配餐工具，最后落成一份素食一日食谱。<span class="marginnote">素食配餐的立场要中立而专业：素食在膳食纤维、饱和脂肪与植物化学物上有优势，但<strong>「纯素且设计不当」确实存在明确的营养缺乏风险</strong>——尤其是维生素 B₁₂，纯素者几乎必须依赖补充剂或强化食品。配餐者的职责是让「想吃素的人吃对」，而不是劝人或反对。</span>

## 1 素食的类型与人群

**素食（vegetarian diet）**：以植物性食物为主、限制或排除动物性食物的膳食模式。按排除程度分档：

**纯素（vegan）**：完全不含任何动物性食物（肉、蛋、奶、蜂蜜均除外）。营养风险最高，需要最精细的设计。

**蛋奶素（lacto-ovo）**：不吃肉鱼，但吃蛋与奶。**蛋奶提供了优质蛋白、钙与 B₁₂**，营养风险显著低于纯素，是素食里最容易配好的类型。

**奶素 / 蛋素**：分别只保留奶或蛋，介于两者之间。

**鱼素（pescatarian）**：不吃畜禽肉但吃鱼。常被视为「半素食」，n-3 脂肪酸来源较充足。

从配餐难度看，蛋奶素接近普通膳食，纯素最难。**配餐者面对纯素者时，专业责任最重**——因为设计不当的纯素膳食可能在数月内就出现 B₁₂ 缺乏的神经症状，而这类风险不能靠「多吃蔬菜」化解。

中国的素食人群还有一层文化背景：**佛教素食传统上是「全素」**（部分流派连蛋奶也戒），寺庙素食与在家信众的斋戒是重要的现实场景。配餐者在服务这类人群时，既要尊重信仰约束，也要如实告知营养风险——**「只吃素」与「吃对素」之间的距离，正是营养配餐能提供的专业价值**。同时，近年「弹性素食」（以植物为主、偶尔吃肉）兴起，它营养风险低、易坚持，常被作为减重与健康饮食的推荐起点。

## 2 素食的五大营养风险点

素食者最容易缺五样东西，配餐要逐一设计对策：

**蛋白质**：植物蛋白的必需氨基酸谱不如动物蛋白完整，且消化率略低。对策是**谷豆互补**（详见第3节）与**豆制品多样化**（豆腐、豆干、腐竹、豆浆轮流）。部分指南还建议**素食者的蛋白质目标按体重略上调**（如 1.0 g/kg 起步、偏高一点），以补偿植物蛋白较低的消化吸收率——这个「略上调」在纯素者身上更有意义。

**铁**：植物只有非血红素铁，吸收率仅 3%–5%，约为血红素铁的三分之一。对策是**植物铁 + 维生素 C 同餐**（菠菜配橙子、豆腐配青椒），并避开浓茶咖啡与正餐同饮。

**钙**：奶类缺席后，钙要靠**豆制品（北豆腐、豆腐干）、绿叶菜（但注意草酸）、芝麻酱**补，必要时用强化豆浆或钙剂。

**维生素 B₁₂**：**只存在于动物性食物**（微生物发酵产物除外），纯素者几乎必然缺乏。对策是**补充剂或强化食品（强化植物奶、营养酵母）**，这是纯素配餐不可妥协的一条。

**锌与 n-3 脂肪酸**：植物锌受植酸抑制；纯素的 n-3（α-亚麻酸）来源有限且转化为 EPA/DHA 效率低。对策是**坚果种子（核桃、亚麻籽）**与必要时 DHA 藻油补充。

关于 **B₁₂** 再多说两句——它是素食里唯一「完全无法靠植物食物解决」的营养素：蔬菜、水果、谷物、豆类都不含它（除非被微生物发酵污染）。**藻类与发酵食品（腐乳、豆豉）含的 B₁₂ 类似物，多数缺乏人体可利用的活性形式**，不能作为可靠来源。因此纯素者的 B₁₂ 来源只有两条：**补充剂**（最常见，如甲钴胺片）或**强化食品**（强化植物奶、营养酵母）。这一条写进配餐建议时要用词明确，避免含糊的「多吃海藻」式误导。

## 3 公式解析：谷豆互补与蛋白质质量

素食配餐里，蛋白质是绕不开的核心问题。单吃谷类，赖氨酸不足；单吃豆类，蛋氨酸相对偏低——两者互补后，混合蛋白的氨基酸评分向理想模式靠拢。用《蛋白质》一节已建立的氨基酸评分公式：

$$\text{混合蛋白 AAS} = \min_i \frac{\text{混合蛋白中第 } i \text{ 种必需氨基酸}}{\text{参考蛋白中第 } i \text{ 种必需氨基酸}}$$

对这条式子做三步拆解：

- **第一步，理解「短板决定评分」**：AAS 取「比值最低的那一种必需氨基酸」——谷类以赖氨酸为短板，豆类以蛋氨酸相对偏低。单一谷物的 AAS 往往不高，因为短板拖累全局。
- **第二步，理解互补的原理**：把谷与豆**按适当比例混合**（如米豆 7:3、面豆 6:4），谷的赖氨酸短板由豆补足、豆的蛋氨酸短板由谷补足——**混合后各氨基酸比值都被抬高，短板不再那么短，AAS 明显上升**。
- **第三步，读「同时进食」的落点**：互补效果在**同一餐内**最充分——「米饭 + 豆腐」「面条 + 豆干」「粥 + 豆浆」这类中式组合，正是谷豆互补最自然的实现。**素食者不必顿顿算评分，只要养成「谷 + 豆同餐」的习惯，蛋白质质量就稳住了。**

## 4 核心对比表：素食五大营养风险与对策

把素食者的五大风险点收进一张「风险 → 对策」表，配餐者照表设计：

| 营养风险 | 缺乏后果 | 素食对策 |
| --- | --- | --- |
| 蛋白质 | 肌肉不足、氮平衡负 | 谷豆互补 + 豆制品多样化 |
| 铁 | 缺铁性贫血 | 植物铁 + 维 C 同餐，避浓茶咖啡 |
| 钙 | 骨密度风险 | 北豆腐、豆腐干、芝麻酱、强化豆浆 |
| 维生素 B₁₂ | 神经症状、巨幼细胞贫血 | **补充剂或强化食品（纯素不可妥协）** |
| 锌与 n-3 | 免疫下降、DHA 不足 | 坚果种子、必要时 DHA 藻油 |

读这张表的关键判断在「**对策的强度分层**」：蛋白质、铁、钙、锌靠**膳食组合**能基本解决，唯独 **B₁₂ 几乎必须靠补充剂或强化食品**——它是纯素膳食唯一「膳食无法可靠补足」的营养素。配餐者给纯素者的第一提醒永远是 B₁₂，其次是「谷豆互补」与「植物铁配维 C」——这四条，是纯素配餐的「安全底线」。

## 5 素食一日膳食示例

把对策落成一份蛋奶素一日膳食（约 2000 kcal）：

- **早餐**：豆浆 + 全麦面包 + 鸡蛋 1 个 + 苹果——蛋奶素靠蛋补 B₁₂，豆 + 谷互补；
- **上午加餐**：酸奶 + 一小把核桃（α-亚麻酸）;
- **午餐**：米饭 + 麻婆豆腐 + 凉拌菠菜（配维 C 促铁吸收）+ 芝麻酱拌菜（补钙）;
- **下午加餐**：水果 + 杏仁;
- **晚餐**：荞麦面 + 豆腐干 + 蒜蓉西兰花 + 紫菜汤（补碘）;
- **饮水**：白水 1500–1700 mL。

拆开看的设计逻辑：**每餐「谷 + 豆」蛋白质互补、奶蛋提供 B₁₂ 与钙、坚果供 α-亚麻酸、菠菜配维 C 促铁、紫菜补碘**——五大风险点逐一落位。若是纯素，把蛋奶换成强化植物奶 + 强化豆制品，并明确加 B₁₂ 补充剂——**蛋奶素与纯素的差距，就在这「奶蛋的 B₁₂ 与钙」上**。

## 6 小结

- 素食类型分档：**纯素（风险最高）、蛋奶素（最易配好）、奶素/蛋素、鱼素**；蛋奶素接近普通膳食，纯素需最精细设计。
- 配餐难度与专业责任：**蛋奶素接近普通膳食，纯素最难、专业责任最重**——设计不当的纯素膳食可能在数月内出现 B₁₂ 缺乏的神经症状，且不能靠「多吃蔬菜」化解。
- 中国素食有宗教背景：佛教素食传统上是「全素」，寺庙斋戒是现实场景——既尊重信仰约束，也如实告知营养风险。
- 五大风险与对策：**蛋白靠谷豆互补、铁靠维 C 同餐、钙靠豆制品与芝麻酱、锌靠坚果种子、n-3 靠亚麻籽核桃与 DHA 藻油**。
- 对策强度分层：蛋白铁钙锌靠膳食组合基本解决，唯独 B₁₂ 几乎必须靠补充剂或强化食品——**纯素配餐的安全底线是「谷豆互补 + 植物铁配维 C + B₁₂ 补充剂」**。
- 素食不等于「吃素减肥」：素食者同样可能高能量（坚果油过量）或低蛋白（主食+蔬菜没有豆）——**素食配餐同样要守能量与结构**。
- 一日膳食（蛋奶素 2000 kcal）：豆浆 + 麻婆豆腐 + 凉拌菠菜 + 酸奶 + 荞麦面豆干——谷豆互补、奶蛋供 B₁₂ 钙、坚果供 α-亚麻酸、紫菜补碘，五大风险逐一落位。
- **B₁₂ 是纯素不可妥协的一条**：只存在于动物性食物，藻类与发酵食品的 B₁₂ 类似物多数不可靠——来源只有补充剂或强化食品。
- 素食者 B₁₂ 来源两条：**补充剂（最常见，如甲钴胺片）或强化食品（强化植物奶、营养酵母）**——写进配餐建议时用词要明确，避免含糊的「多吃海藻」式误导。
- 素食铁的唯一来源是非血红素铁（吸收率 3%–5%）：**植物铁 + 维 C 同餐**（菠菜配橙子、豆腐配青椒），并避开浓茶咖啡与正餐同饮。
- 谷豆互补公式：混合蛋白 AAS 取短板比值；**「谷 + 豆同餐」养成习惯，蛋白质质量即稳住**。
- 谷豆互补的典型中式组合：**米饭 + 豆腐、面条 + 豆干、粥 + 豆浆**——「谷 + 豆同餐」是最自然的互补实现，素食者不必顿顿算评分。
- 佛教素食传统上是「全素」：配餐者要尊重信仰约束、如实告知营养风险——「只吃素」与「吃对素」的距离正是专业价值。
- 纯素者 B₁₂ 缺乏的神经症状（感觉异常、记忆力下降）可能在数月内出现——这不是「多吃蔬菜」能化解的，必须靠补充剂或强化食品兜底。
- 素食配餐的立场要中立而专业：素食在膳食纤维、饱和脂肪与植物化学物上有优势，但「纯素且设计不当」确实存在明确的缺乏风险——既不一味推崇也不妖魔化。
- 素食在纤维、饱和脂肪与植物化学物上有优势，但「纯素且设计不当」确实有明确的缺乏风险——配餐者的职责是让「想吃素的人吃对」。
- 立场要中立而专业：既不一味推崇素食，也不妖魔化素食——**「纯素且设计不当」的风险要如实告知，「素食的好处」也要客观呈现**。
- 「痛风不能吃豆腐」等传统认知近年被修正：植物嘌呤对血尿酸影响有限，适量豆制品利大于弊——素食配餐也要敢于传递反直觉但循证的结论。
- 纯素的 n-3 来源有限且转化为 EPA/DHA 效率低：核桃亚麻籽提供 α-亚麻酸，不常吃藻油补充剂者可考虑 DHA 藻油。
- 素食者的锌受植酸抑制：**贝类（非纯素）、红肉（非纯素）外，坚果种子与豆类是纯素锌的来源**——配餐时注意植酸与蛋白的搭配。
- 素食者的蛋白质目标可略上调（1.0 g/kg 起步）：补偿植物蛋白较低的消化吸收率——「略上调」在纯素者身上更有意义。
- 弹性素食（以植物为主、偶尔吃肉）营养风险低、易坚持，常作为减重与健康饮食的推荐起点——是「全素」与「普通膳食」之间的务实中间带。
- 素食钙的另一条来源：北豆腐（卤水点制含钙较高）、豆腐干、芝麻酱、强化豆浆——奶类缺席后，钙要靠豆制品与深加工大豆补上。
- 素食一日示例（蛋奶素 2000 kcal）把五大风险逐一落位：谷豆互补、奶蛋供 B₁₂ 钙、坚果供 α-亚麻酸、菠菜配维 C 促铁、紫菜补碘。
