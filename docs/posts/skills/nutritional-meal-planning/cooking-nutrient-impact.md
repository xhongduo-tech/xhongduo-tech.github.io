## 为什么从烹饪加工开始

食谱编得再精确，最终要经厨房的手落到餐桌上。而烹饪是一把双刃剑：它让食物**更安全**（杀菌、灭酶、去抗营养因子）、**更好消化**、**更好吃**，同时也带来**营养素损失**——水溶的维生素溶于汤汁，怕热的维生素被高温分解，脂肪在高温下氧化。**「算得对」的食谱，若「做得不对」，营养素兑现率可能打七折。**

这一篇先讲各营养素「怕什么」，再给一条可量化的保留率公式，接着对比不同烹调方式的得失，最后落到「合理烹饪」的原则清单。它是从「纸上食谱」走向「餐桌现实」的最后一环，也与《会烹会选、会看食品标签》直接衔接。<span class="marginnote">烹饪对营养的影响常被两极化：一端是「食物生吃才健康」的极端，另一端是「随便怎么煮，吃了就行」。真相居中——适度加工利大于弊，但烹调方式确实决定营养素兑现率。配餐者要传递的，是「会烹饪」而不只是「会计算」。</span>

## 1 营养素「怕什么」：三类损失机制

营养素的烹饪损失，主要来自三类机制，各有各的「杀手」：

**水溶损失**：维生素 C、B 族维生素（尤其 B₁、B₂）、钾、部分矿物质易溶于水。切得越碎、泡得越久、煮得越久、汤汁倒得越多，损失越大。**水是第一个杀手。**

**热降解**：维生素 C、B₁、叶酸怕热，温度越高、时间越长损失越大。长时间炖煮、油炸、反复加热都会放大损失。**温度与时间是第二个杀手。**

**氧化与光解**：维生素 A、E 与必需脂肪酸怕氧气与光，长时间暴露、反复高温油炸会氧化变质。**氧气与光是第三个杀手。**

三大宏量营养素相对「皮实」：蛋白质、脂肪、碳水化合物在常规烹调下基本稳定，但蛋白质遇高温（如烤焦）会损失赖氨酸等必需氨基酸，脂肪高温油炸会产生有害氧化产物。**越「娇气」的营养素（VC、B₁），越需要精细的烹调；越「皮实」的（淀粉、蛋白），越经得起折腾。**

烹调还有一个正向作用常被忽略：**它提高了许多营养素的生物利用率**。胡萝卜中的 β-胡萝卜素经加热后更易吸收；番茄加热使番茄红素溶出增加；豆类加热破坏了抗营养因子，蛋白利用率显著上升。**「损失」与「释放」并存**——这提醒配餐者不要用「保留率」一个指标定乾坤，要看营养素最终被身体利用了多少。

## 2 各营养素的敏感度速查

不同营养素对烹饪的敏感程度差异极大，一张速查表是配餐者与厨师的共同语言：

| 营养素 | 主要损失方式 | 敏感度 |
| --- | --- | --- |
| 维生素 C | 水溶 + 热解 | 极高 |
| 维生素 B₁（硫胺素） | 水溶 + 热解 | 高 |
| 维生素 B₂ | 光解（日光） | 中高 |
| 叶酸 | 水溶 + 热解 | 高 |
| 维生素 A、E | 氧化、光解 | 中 |
| 维生素 D | 较稳定 | 低 |
| 钾、部分矿物质 | 水溶（溶于汤汁） | 中 |
| 蛋白质、脂肪、碳水 | 常规烹调基本稳定 | 低 |

读这张表的实操含义：**补充维生素 C 靠「急火快炒、现做现吃、连汤带汁」，而不是靠长时间炖煮**；B 族维生素爱藏在谷物的糊粉层与胚芽，所以「淘米不过度」比买贵米更重要；脂溶性维生素怕氧化，所以「新鲜烹调、避光储存」比什么都关键。

## 3 公式解析：营养素保留率

「损失多少」需要一个统一指标。**营养素保留率（retention rate）**是最常用的度量：

$$R = \frac{\text{烹调后食物中某营养素的含量}}{\text{烹调前食物中某营养素的含量}} \times 100\%$$

对这条式子做三步拆解：

- **第一步，明确分子分母**：分子是「做成成品后吃进嘴那部分」的营养素含量，分母是「生原料（可食部）」的含量。两者都按同样的食物重量口径（或折算到同一生重）比较，否则没有意义。
- **第二步，理解保留率的两个去向**：营养素「没保留」的部分去了哪？主要是**进入汤汁**（水溶，汤没喝就损失）与**被分解**（热解、氧化）。所以「保留率低」可能是煮丢了，也可能是炖进了汤里——喝汤的人其实吃回来了。
- **第三步，读典型数值**：清炒蔬菜维生素 C 保留率约 60%–80%，长时间炖煮可能降到 30% 以下；蒸的根茎类保留率普遍高于水煮；油炸因高温与长时间，保留率最低。有了这些基准，配餐者就能预判「这份菜实际兑现了多少营养」。

保留率把「做法对错」变成了「可比较的数字」——这也解释了为什么营养配餐软件会内置「烹调方式修正系数」：同样 100 g 蔬菜，炒与煮的营养素贡献在软件里是两个数。

## 4 烹调方式对比：谁最能留住营养

常见烹调方式按「营养保留友好度」大致排序：

**蒸**：温度 100℃ 左右、不接触大量水，维生素与矿物质保留率高，是蔬菜与鱼类的黄金烹调法。

**急火快炒**：短时高温，水溶损失小，配合「少水快熟」，维生素 C 保留率优于长时间炖煮，是中式厨房性价比最高的方式。

**煮/炖**：营养大量溶入汤汁——**「喝汤」让损失变成转移**；若只吃料不喝汤，水溶营养素损失明显。煮菜汤是「汤里有菜的营养」的经典例证。

**煎/烤**：表面高温、内部温和，蛋白损失小；但表面过度褐变（烤焦）会损失氨基酸，且常用油偏多。

**油炸**：高温 + 长时间 + 大量油，维生素损失最大，还引入过量油脂与氧化产物——**营养保留最不友好**，且油反复使用风险更大。

主食烹调有两条被低估的细节。其一，**淘米**：过度淘洗（用力搓、反复冲）会损失大量 B 族维生素与矿物质，正确的做法是**轻淘 1–2 次、不用热水泡、不搓洗过久**；如今精米本身维生素已少，更经不起反复搓洗。其二，**煮粥加碱**：老一辈「加碱让粥更稠更香」的习惯，会让粥里的 B 族维生素几乎被摧毁殆尽——**营养学上明确反对煮粥加碱**，现代替代办法是改用糯米或燕麦等自带黏性的谷物。

<span class="marginnote">「蒸 > 炒 > 煮（喝汤）> 炖 > 煎烤 > 炸」是一般的营养保留排序，但「好吃」也要考虑。合理烹饪不是「只准蒸」，而是「蒸炒为主、炖汤连喝、炸烤偶尔」——把高频烹调方式落在营养友好的区间，把不友好的方式降频。</span>

## 5 合理烹饪七原则

把上述机制收拢成可执行的原则，公共营养师通常强调七条：

**一、先洗后切，切后即烹**：先整洗再切，减少水溶损失；切后不及时烹调，切口氧化又失水。

**二、现做现吃，少做剩菜**：现做现吃保留率最高，剩菜反复加热使 VC、B₁ 进一步损失。

**三、急火快炒，旺火短时**：缩短受热时间，是保住维生素 C 的厨房第一招。

**四、焯水适度，沸水入锅**：需焯水的蔬菜沸水下锅、时间从短，焯后过凉水（注意 VC 也会溶入焯水）。

**五、蒸煮优先，油少为佳**：烹调方式向蒸、炖、快炒倾斜，控制用油量。

**六、汤菜同食，连汤带汁**：煮炖的汤汁富含水溶营养，别倒掉——汤菜同食等于把「损失」吃回来。

**七、加醋保维，保护维生素**：酸性环境能稳定维生素 C 与 B 族，凉拌与炒菜酌量加醋；但煮豆类加碱、煮粥加碱会大量破坏 B 族维生素，应避免。

**辨析｜易错点**：许多人以为「生吃最营养」。但生吃有风险——四季豆、鲜黄花菜等含天然毒素或抗营养因子，必须彻底加热；十字花科蔬菜生吃影响甲状腺。**「营养保留」与「食品安全」要平衡**：该熟食的必须熟食，营养保留率是「煮熟前提下」的优化，而不是「为保留而吃生」。

肉类的合理烹调同样有讲究：**低温慢煮（炖、蒸、水浴）比高温煎炸更能保住 B 族维生素与必需氨基酸**，且不会产生大量有害的晚期糖基化终产物（AGEs）。「外焦里嫩」是口感追求，但频繁把肉烤到焦糊，损失的不仅是营养，还叠加了致癌物风险。**肉类烹调的原则是「熟透而不焦糊、汤肉同食」**——这与蔬菜的「急火快炒」一起，构成完整厨房的营养守则。

## 6 小结

- 三类损失机制：**水溶、热解、氧化光解**；VC、B₁ 最娇气，宏量营养素最皮实。
- 保留率公式 $R = \dfrac{\text{熟后含量}}{\text{生前含量}} \times 100\%$；保留率低可能是「煮丢了」，也可能是「炖进了汤里」——汤菜同食等于吃回来。
- 配餐软件内置「烹调方式修正系数」：同样 100 g 蔬菜，炒与煮的营养素贡献是两个数——「算得对」的食谱还必须「做得对」才兑现。
- 烹调方式按营养保留排序：**蒸 > 快炒 > 煮（喝汤）> 炖 > 煎烤 > 油炸**；油炸保留率最低还引入过量油脂。
- **合理烹饪七原则**：先洗后切、现做现吃、急火快炒、沸水焯菜、蒸煮优先、汤菜同食、加醋保维。
- **辨析**：营养保留与食品安全要平衡——该熟食的（四季豆、鲜黄花菜）必须彻底加热，「生吃最营养」不等于「生吃最安全」。
- 烹饪对营养是「损失 + 释放」并存：加热提高 β-胡萝卜素、番茄红素的利用率，豆类蛋白吸收率因抗营养因子被破坏而上升——别用「保留率」一个指标定乾坤。
- 主食烹调两细节：**淘米轻淘 1–2 次、不用热水泡**；**煮粥加碱会摧毁 B 族维生素**，营养学明确反对。
- 肉类烹调原则：**熟透而不焦糊、汤肉同食**；高温煎炸烤焦不仅损营养，还叠加晚期糖基化终产物与致癌物风险。
- 营养素的烹调损失不是「要不要做菜」的理由，而是「怎么做菜」的理由——适度加工利大于弊，关键在烹调方式的选择。

在下一节，我们把目光从「厨房怎么做」移到「超市怎么选」——**会烹会选、会看食品标签**，用配料表与营养成分表读懂预包装食品。
