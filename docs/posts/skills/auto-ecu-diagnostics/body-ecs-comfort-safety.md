## 为什么从车身电控开始

前面几课讲的是「让车跑起来、停下来」的系统，本课讲「让人舒服、让车安全」的系统：门窗、座椅、空调、灯光、门锁，以及最关键的安全气囊。车身电控最大的特点是**系统多、单点成本低、但维修面广**——它直接决定用户每天的用车体验，也占了售后维修投诉的大头。<span class="marginnote">车身电控与动力系统的技术风格截然不同：动力系统要实时、要安全冗余，车身系统更多是<strong>开关、状态、时序</strong>的逻辑控制。它大量使用 LIN 总线挂载从属模块（见第 1 篇车载网络课），一个车身电脑（BCM）就能管理几十个功能。</span>本课分舒适与安全两条线：舒适系统讲「怎么控制」，安全系统（气囊）讲「怎么保护」，最后给出车身电控的维修安全须知。

## 1 车身电脑：舒适系统的总调度

**车身控制模块（BCM）**是车身电子的中央大脑，负责中央门锁、车窗、天窗、后视镜、雨刮、灯光、喇叭、座椅记忆、防盗等功能的控制与调度。它的硬件架构与发动机 ECU 同构（CPU + 输入输出 + 网络），但软件逻辑是**事件驱动**的：收到遥控解锁信号 → 点亮迎宾灯 → 驱动门锁电机 → 展开后视镜 → 通过 LIN 通知各门窗模块。

**核心概念：集中控制 + 局部从属。** BCM 是主节点，各个车门内的**车门模块（door module）**、座椅模块是 LIN 从节点：BCM 只下命令（如「左前窗升到顶」），具体驱动电机、检测防夹由从模块完成。<span class="marginnote">这套架构带来明显的诊断规律：<strong>单个车门所有功能失灵 → 查该门模块的 LIN 线、供电与模块本身；多个车门同时失灵 → 查 BCM 或共享总线。</strong> 车窗「一键升降失灵但能点动」这类半死不活的故障，往往指向从模块内的防夹逻辑（霍尔传感器）或电机位置记忆丢失，需要做「车窗初始化」——把窗降到底再升到顶，让模块重新记录行程。</span>

## 2 舒适系统：门窗、座椅与自动空调

**电动车窗**：直流电机通过升降器驱动玻璃。现代车窗普遍带**防夹功能**：电机上的霍尔传感器检测转速与电流，玻璃遇到阻力（如夹到手指）时电机反转退回。**易错点：** 防夹功能过于灵敏导致「升窗到顶又自动降」，常见原因是玻璃导轨脏污、胶条老化阻力变大，让模块误判为「夹住」——先清洁润滑导轨，别急着换模块。

**电动座椅**：多组电机（前后、高低、靠背、腰部）通过座椅模块控制，带记忆功能时还有位置传感器。座椅模块同样是 LIN 从节点。

**自动空调**：不只「开空调」，而是**闭环控温**——车内温度传感器、日照传感器、出风口温度传感器反馈，空调 ECU 通过调节鼓风机 PWM 风速、混合风门电机位置、压缩机占空比，把车内温度稳定在设定值。<span class="marginnote"><strong>诊断特点：</strong>自动空调的故障很多不是「不制冷」，而是「温度控制不准」——出风一侧热一侧冷，往往是<strong>混合风门电机（执行器）</strong>卡滞或反馈电位器漂移。诊断时用诊断仪做「风门位置动作测试」并读各风门位置数据，能快速定位是哪只风门电机的问题，避免拆整个仪表台。</span>温度「永远最热/最冷」通常是风门位置反馈与命令不一致。

## 3 安全系统：安全气囊与安全带预紧

**SRS（辅助乘员保护系统）**包括安全气囊、安全带预紧器、碰撞传感器与 SRS 控制单元。它的工作逻辑是**平时静默、碰撞瞬间毫秒级引爆**：

**传感器**：前碰撞传感器（加速度式）与 SRS 控制单元内部的中央加速度传感器，检测碰撞减速度。
**决策**：SRS 控制单元比较减速度与阈值，判定碰撞严重度，决定点爆哪些气囊（前气囊、侧气囊、侧气帘）与预紧器。
**执行**：点火器（电爆管）通电，产生气体，气囊在约 30 ms 内充气展开，保护乘员。

**重点：安全气囊系统采用「失效静默（fail-silent）」策略**（见第 1 篇第 6 课）：任何故障（传感器异常、点火回路开路、供电异常）都会让系统**禁用整个气囊回路并点亮 SRS 警告灯**——宁可碰撞时气囊不弹，也绝不在正常行驶中误弹。<span class="marginnote">气囊误弹是灾难性的，所以设计上把「不误触发」看得比「必须触发」更重。<strong>诊断含义：</strong> SRS 灯亮意味着系统已自我禁用，属于「已失效状态」；而系统在工作时你是测不到任何动作的——它一直在静默自检。读 SRS 故障码（B 字头，如 B0010 驾驶员前气囊回路）时，重点是查点火回路的开路/短路与传感器的合理性。</span>

## 4 公式解析：碰撞判定与气囊触发

SRS 控制单元的触发判定基于碰撞减速度的时间积分，简化的判定条件：

$$
\Delta v = \int_0^{T} a(t)\, dt, \qquad \Delta v > \Delta v_{\text{th}} \; \text{且} \; a_{\max} > a_{\text{th}}
$$

分三步拆解：

- **第一步，看减速度 $a(t)$**：碰撞瞬间车辆快速减速，加速度传感器测得负向加速度（减速度）。软碰撞减速度小、硬碰撞减速度大，但峰值大不一定就弹——还要看持续。
- **第二步，看速度变化量 $\Delta v$**：把一段短时间 $T$（如 20–50 ms）内的减速度积分，得到速度变化量。**$\Delta v$ 综合了「撞得多狠」与「持续多久」，比单点峰值更可靠**——短促尖峰（如路面颠簸）速度变化量小，不会误触发；真正的碰撞速度骤减，$\Delta v$ 会迅速超过阈值。
- **第三步，看双重条件**：峰值加速度 $a_{\max}$ 超阈值**且**速度变化量超阈值，才触发。两个条件互相印证，进一步降低误触发概率。**易错点：** 低速碰撞（如追尾前的急刹）减速度可能很大但 $\Delta v$ 有限，是否触发取决于该车型的标定——不要用「我感觉撞得很重」判断气囊该不该弹，一切以诊断仪读到的碰撞数据为准。

**安全警告：气囊系统维修必须断电作业。** 拆装气囊、座椅（侧气囊）前先断开蓄电池并等待数分钟（让 SRS 控制单元的储能电容放电）；**绝不可用万用表测点火器的电阻**（表内电流可能引爆气囊），也绝不可直接给点火器通电。引爆过的气囊要按规范处理，未引爆的旧气囊有延时引爆风险。

## 5 防盗与无钥匙系统

**发动机防盗（immobilizer）**与**无钥匙进入/启动**是车身电控里与「安全」相关但属于防盗类的系统：钥匙芯片（或手机数字钥匙）通过射频与车身模块双向认证，认证通过才允许起动（解除发动机起动禁止）。<span class="marginnote"><strong>易错点：防盗系统故障和起动机故障要分清。</strong> 「钥匙转不动、发动机没反应」可能是起动系统故障，也可能是防盗没认证通过——诊断仪读防盗模块故障码（通常含「钥匙未认证」「无钥匙信号」）即可区分。换钥匙、换 BCM 后必须按厂家流程做<strong>钥匙匹配</strong>，否则车照样打不着。这类系统对「原厂数据」依赖极强，是维修中「必须查维修手册」的典型场景。</span>

## 6 车身电控故障诊断与维修安全须知

车身电控故障的诊断，遵循「先外后内、先电气后机械」：

1. **先做功能测试**：用开关或诊断仪动作测试（锁门/开锁、升降窗、风门电机），确认「命令有没有执行」——这决定了故障在控制侧还是执行侧。
2. **看故障码与数据流**：BCM 与各从模块都有自诊断。门窗、座椅模块的故障码能直接指向电机、霍尔传感器或 LIN 通信。
3. **查电源与搭铁**：车身模块分布广、线束长，供电与搭铁接触不良是高发故障（呼应第 1 篇电源管理课）。
4. **查 LIN 通信**：单个从模块失联 → 查 LIN 线；多模块失联 → 查主节点与共享线。
5. **最后查机械**：电机坏、导轨卡、执行器磨损。

**维修安全红线**：气囊系统断电作业、点火器禁止万用表测量；高压混动车车身维修还要避开高压部件（衔接下一课新能源汽车高压安全）。

## 7 灯光、胎压与智能车身系统

车身电控还延伸到一批「看不见但天天用」的智能系统：

**核心概念：灯光控制的智能化。** 自动大灯（光线传感器）、自适应远近光、转向辅助照明，由灯光模块根据光线传感器、车速、转向角自动控制。**大灯「关不掉」或「不自动亮」**，先看光线传感器数据流与灯光模块故障码，再查开关与线路。

**胎压监测（TPMS）**是安全相关的车身系统：直接式靠轮内气压传感器无线传输，间接式靠 ABS 轮速差推算。**易错点：** 直接式换轮胎/轮辋后需要做**胎压传感器学习/匹配**；间接式补气后要在仪表上做**胎压复位**——不做复位，系统沿用旧数据，报警不准。

| 车身系统 | 关键传感器 | 常见故障 |
| --- | --- | --- |
| 自动大灯 | 光线传感器 | 传感器脏污/遮蔽导致误动作 |
| 胎压监测 | 气压传感器/轮速 | 传感器电池耗尽、学习失败 |
| 倒车雷达 | 超声波传感器 | 探头脏污/损坏误报 |
| 无钥匙进入 | 低频/高频天线 | 钥匙电池弱、天线故障 |

**重点：车身智能系统故障的「先软件后硬件」原则。** 换传感器/执行器前，先做**初始化、复位、匹配**（车窗防夹学习、胎压复位、无钥匙匹配）——很多「刚换的件还是不好」，其实是没做配套的软件初始化。

**车身电控「按症状找入口」速查**，把常见投诉对应到首查环节：

| 症状 | 首查入口 |
| --- | --- |
| 车窗不动 | 从模块/LIN 线/电机供电 |
| 门锁乱跳 | 门锁电机/BCM 输出 |
| 空调不制冷 | 压缩机离合/制冷剂/风门 |
| 气囊灯亮 | SRS 故障码/点火回路 |
| 胎压报警 | 胎压传感器/学习状态 |
| 无钥匙失灵 | 钥匙电池/天线/模块匹配 |
| 灯光不灭 | 灯光模块/光线传感器 |
| 座椅记忆失效 | 座椅模块/位置传感器 |
| 雨刮乱刮 | 雨刮模块/雨量传感器 |
| 后视镜不折叠 | 后视镜电机/H 桥驱动 |
| 防盗报警乱响 | 门开关/振动传感器/BCM |
| 车窗防夹误动 | 导轨阻力/霍尔传感器 |

**车身电控的排查顺序永远是「先功能测试、再故障码、后机械」**——命令没出去还是执行不了，这两件事先分清，问题就解决了一半。

## 8 小结

- BCM 是**车身电子总调度**，车门/座椅等从模块挂 LIN，故障诊断按「单点 vs 多点」定位。
- 舒适系统常见故障：车窗防夹误判（导轨阻力）、风门电机卡滞（出风温度不准）、模块失联。
- SRS 安全气囊用**失效静默**策略，SRS 灯亮 = 系统已禁用；触发判定用 $\Delta v = \int a\,dt$
