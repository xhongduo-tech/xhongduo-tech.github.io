# 汽车电控系统与故障诊断

现代汽车已全面电控化，发动机、变速器、底盘与车身均由电控单元（ECU）协调控制，OBD车载故障诊断是电控维修的核心技术。以博世《汽车工程手册》为原理之纲、《汽车维修工国家职业技能标准》为职业之纲、ISO 15031 / SAE J1979为诊断之纲，系统重建从电控系统原理、传感器执行器检修到OBD数据流读取与故障码诊断的完整技能体系。学完这些章节，就写完了汽车电控系统与故障诊断的全部内容。

## 对标教材

- 博世《汽车工程手册》（Bosch Automotive Handbook）
- 《汽车维修工国家职业技能标准》
- ISO 15031 / SAE J1979 OBD诊断标准
