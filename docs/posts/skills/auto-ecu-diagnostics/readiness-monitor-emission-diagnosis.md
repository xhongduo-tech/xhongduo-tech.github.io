## 为什么从就绪监测开始

前几课讲的故障码、冻结帧、数据流，都是「车辆出问题后的记录」。但法规还需要回答另一个问题：**车辆有没有能力证明自己排放是好的？** 答案就是**就绪监测（readiness）**——ECU 对各项排放相关部件持续做自检，每项自检在特定工况下完成，完成情况被记录成一张「就绪清单」。年检时，检测站先看这张清单，再决定要不要细查排放。<span class="marginnote">就绪监测是 OBD 体系里「防作弊」的关键设计：<strong>没有它，车主清掉故障码就能蒙混过年检。</strong> 有了它，清码后就绪状态被清零，车辆必须重新跑完自检才能证明自己健康——而一个「跑不完自检」的车，本身就是诊断线索。本课讲清监测项、驾驶循环与两大核心监测（催化器、失火）的原理。</span>

## 1 就绪监测：车辆的「体检清单」

OBD 对排放相关系统定义了一组**监测项（monitor）**，每项监测一个部件或功能。常见的监测项包括：

| 监测项 | 监测对象 | 状态含义 |
| --- | --- | --- |
| 失火监测 | 各缸是否失火 | 完整 = 已完成失火自检 |
| 燃油系统监测 | 燃油修正是否超限 | 完整 = 已完成燃油自检 |
| 综合部件监测（CCM） | 各传感器/执行器合理性 | 完整 = 已跑完合理性检查 |
| 催化器监测 | 三元催化转化效率 | 完整 = 已完成催化效率评估 |
| 氧传感器监测 | 氧传感器响应 | 完整 = 已评估响应特性 |
| 氧传感器加热器监测 | 加热器电路 | 完整 = 已评估加热回路 |
| EVAP 监测 | 燃油蒸发系统泄漏 | 完整 = 已完成泄漏测试 |

**核心概念：监测项状态不是「通过/不通过」，而是「完成/未完成」。** 一个监测项显示「未完成（not complete）」，只说明「自检还没跑完」，不代表「部件坏了」。但**正常使用下长期未完成**，本身就是线索——见第 4 节。<span class="marginnote"><strong>年检视角：</strong> 排放年检（I/M 检测）要求「足够多的监测项已完成」。若清码后立刻来检、或车长期短途低速行驶，很多监测项没机会跑完，年检会以「就绪状态不完整」为由拒检或让车辆先跑足工况。这也是「年检前先去高速跑一圈」这句老话的技术依据。</span>

## 2 驾驶循环：让监测跑起来

每个监测项都有各自的**完成条件**——需要在特定的行驶工况下运行一段才能完成，这一组工况合起来叫**驾驶循环（driving cycle）**。典型的 OBD 驾驶循环包括：

**冷起动**：发动机从冷态起动，水温从低升高。
**怠速**：稳定怠速若干时间（让氧传感器加热、进入闭环）。
**加速**：缓加速到中速（触发失火、燃油监测）。
- **巡航**：以稳定中速行驶（催化器监测需要较长稳定工况）。
- **减速**：松开油门减速（某些监测在减速阶段完成）。

**重点：一个监测项未完成，未必是坏了，可能是「工况不够」。** 长期短途代步的车，催化器监测（需要较长时间稳定工况）最容易「未完成」。<span class="marginnote"><strong>诊断含义：</strong> 年检前或修车后，让车按驾驶循环完整跑一遍，各监测项才会逐一变「完成」。读诊断仪的就绪页面，能看到每个监测项是「完成」还是「未完成」——这既是年检准备，也是维修后「验证自检通过」的手段（呼应冻结帧课的「判断修好三件事」）。</span>

## 3 公式解析：催化器效率监测

催化器监测是排放诊断的核心，原理是**比较催化器前、后两个氧传感器的信号活跃度**：

$$
\eta = \frac{\sigma_{\text{rear}}}{\sigma_{\text{front}}}
$$

分三步拆解：

- **第一步，看两个氧传感器**：三元催化器前端有**前氧传感器**（看空燃比），后端有**后氧传感器**（看催化器出口氧浓度）。ECU 分别计算两路信号的**活跃度 $\sigma$**（切换频率或信号方差）。
- **第二步，理解健康时的关系**：健康催化器能**储存/释放氧**，把上游的空燃比波动「抹平」——所以**后氧信号应明显比前氧平缓、幅值小、切换少**，即 $\eta$ 远小于 1。
- **第三步，看劣化信号**：催化器老化失效后，储氧能力下降，后氧信号开始跟着前氧「一起跳」，$\eta$ 趋近 1。**当 $\eta$ 超过标定阈值（各车型不同），ECU 判定催化器效率不足，报 P0420（催化器效率低于阈值）**。**易错点：** P0420 可能由后氧传感器本身误报引起（后氧传感器老化、线路问题让信号异常活跃），所以报 P0420 时先确认后氧传感器信号可信，再判催化器死刑——换一个催化器前先验后氧，能避免昂贵的误修。

## 4 失火监测与燃油系统监测

**失火监测**的原理是「转速波动法」：气缸正常工作时有规律的做功脉冲让曲轴转速均匀波动；某缸失火时，该缸不做功，曲轴在对应转角出现**转速跌落**。ECU 通过曲轴位置传感器的高分辨率信号计算每次做功间的转速变化，发现异常跌落即判失火，并统计到对应气缸。<span class="marginnote"><strong>失火监测的巧妙与敏感：</strong> 它不靠额外传感器，只用曲轴信号就能「听」出哪缸不干活。但也因此敏感——<strong>道路颠簸、负载突变、缺齿信号毛刺都可能被误判为失火</strong>。所以 OBD 对失火分为两档：轻微失火只记录、不立即报；<strong>严重失火</strong>（可能损坏催化器——未燃混合气进入排气管燃烧）会<strong>闪烁故障灯</strong>警告驾驶员，并要求立即停车检修。失火监测与催化器监测的联动，正是排放法规的环环相扣。</span>

**燃油系统监测**则直接使用**长期燃油修正（LTFT）**作为判据：闭环中持续观察修正量，**长期修正超过阈值（如 ±25%）就判定燃油系统异常**——这是第 2 篇燃油喷射课 P0171/P0172 故障码的直接来源，也是「监测 = 记账本查账」的典型例子。

## 5 就绪状态的诊断意义

就绪状态不只是年检的门槛，它本身是**诊断工具**：

**多个监测项长期未完成 + 无故障码**：可能是「故障让监测无法启动」。例如氧传感器加热器失效，氧传感器监测永远无法完成；催化器前温度不够，催化器监测无法进行。**未完成的监测项指向「卡住它的那个部件」。**
**清码后就绪清零**：模式 04 清码会清零就绪状态。**如果清码后不久就绪状态部分变「完成」，说明系统在正常工作**；如果某个监测项跑了很多工况仍未完成，查它对应的部件。
**就绪 + 故障码配合读**：已确认故障码 + 对应监测未完成，二者互相印证；无码 + 监测未完成，则要把「未完成」当线索深挖。

<span class="marginnote"><strong>诊断实战：</strong> 一辆车「年检不过、但没故障码」，先读就绪页面看哪个监测项未完成。例如 EVAP 监测长期未完成而无码——可能 EVAP 系统存在微小泄漏但没达到报码阈值，或炭罐电磁阀卡滞让泄漏测试无法进行。就绪状态把「无码故障」变成「有方向的排查」，是疑难诊断的重要入口。</span>

## 6 排放诊断在年检中的应用

把整条 OBD 排放诊断链串起来，就是年检的完整逻辑：

1. **读就绪状态**：监测项完成数是否达标？不达标 → 先跑驾驶循环。
2. **读故障码**：有无排放相关确认码/永久码？有 → 排放判不合格。
3. **读数据流/监测结果**：用模式 06 的监测数值评估「在恶化但还没报码」的部件。
4. **修复后复检**：修复 → 清码 → 跑驾驶循环 → 确认码不复发、永久码清除、就绪全完成 → 复检通过。

**核心概念：排放诊断的目标不是「让尾气暂时合格」，而是「让车辆自证长期合格」。** 这正是 OBD 制度的设计哲学——用持续自检 + 不可作弊的永久码 + 就绪门槛，把排放责任从检测站的一次性检测，转嫁到车辆自身的持续监督上。

## 7 EVAP 与氧传感器加热器监测

两个常被忽略、但年检必查的监测项，值得单独讲透：

**EVAP 监测（燃油蒸发泄漏）**：ECU 通过**压力传感器**监测油箱蒸发系统是否泄漏。检测时系统封闭并抽真空/加压，观察压力衰减——**压力衰减过快判泄漏**。**易错点：** 加完油没拧紧油箱盖、EVAP 炭罐电磁阀卡滞、管路接头松动，都会导致 EVAP 泄漏监测失败。**EVAP 监测需要特定工况（燃油液位、温度、车速条件）才能运行**，所以它常常是最晚「完成」的监测项。

**氧传感器加热器监测**：氧传感器冷态时无法工作，加热器（陶瓷加热元件）通电升温让它尽快进入闭环。ECU 监测加热器电流/电阻，**加热器断路、短路或加热不足都会报码**（如 P0030–P0038 系列）。

| 监测项 | 完成条件（典型） | 失败指向 |
| --- | --- | --- |
| EVAP 泄漏 | 特定油位/温度/车速下的封闭测试 | 油箱盖、炭罐电磁阀、管路泄漏 |
| 氧传感器加热器 | 起动后加热器电流/温度达标 | 加热器断/短、供电搭铁 |
| 催化器 | 前氧闭环稳定后的前后氧对比 | 催化器老化、后氧误报 |

**重点：监测项「完成」与「通过」不是一回事。** 完成（complete）说明自检跑完了，通过（pass）说明结果合格——**监测完成但判定不合格，就会报故障码**。年检看的是「完成 + 无码」，即自检跑完且没发现问题。

**就绪状态的「年检提示」**：年检前跑一趟完整的驾驶循环，让各监测项完成；若某个监测项反复无法完成，那本身就是需要排查的线索——「跑不完的自检」常常指向卡住它的部件。

| 年检场景 | 就绪判断 |
| --- | --- |
| 清码后立刻检 | 就绪清零，可能拒检 |
| 长期短途 | 催化器监测常未完成 |
| 完成但报码 | 自检通过，部件不合格 |

## 8 小结

- **就绪监测**是一组排放部件的自检清单：失火、燃油、综合部件、催化器、氧传感器、EVAP 等。
- 每个监测项有各自**完成条件**，组合成**驾驶循环**（冷起动→怠速→加速→巡航→减速）。
- 催化器监测 = **前后氧传感器活跃度之比** $\eta = \sigma_{\text{rear}}/\sigma_{\text{front}}$
