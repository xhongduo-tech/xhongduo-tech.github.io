## 为什么从故障码结构开始

上一课建立了一个观念：OBD 是法规驱动的「车辆自检报告」，而**故障码（DTC）就是这份报告里的条目**。维修工每天打交道最多的就是故障码——但很多人只会「读码—查表—换件」，不会「读码—理解—推理」。<span class="marginnote">会读故障码是操作工，会解读故障码是技师。<strong>解读的第一步是理解编码结构</strong>：五字符里每一位都携带信息，读懂了结构，你看到 P0171 不需要翻手册就能猜到「动力系统—通用—燃油/空气计量—系统过稀」的大方向。本课把编码规则拆开讲透，并给出高频码速查表。</span>

## 1 五字符结构：把故障分类编码

OBD-II 故障码是**一个字母 + 四位数字**的标准结构，例如 `P0171`：

$$
\underbrace{\text{P}}_{系统} \; \underbrace{0}_{通用性} \; \underbrace{1}_{子系统} \; \underbrace{71}_{具体故障}
$$

## 2 第一位字母：系统归属

故障码的第一个字符是**字母**，表示故障所属的系统大类，共四类：

| 字母 | 系统 | 含义 |
| --- | --- | --- |
| P | Powertrain | 动力总成（发动机、变速器） |
| C | Chassis | 底盘（制动、转向、悬挂） |
| B | Body | 车身（气囊、空调、车窗等） |
| U | User Network / CAN | 车载网络与通信 |

**重点：字母是「系统检索」的第一步。** 看到 P 开头，先想动力总成；看到 U 开头，先想网络通信（很多「模块失联」正是 U 码）。把字母与系统绑定，读码的第一反应就快了一半。

## 3 第二位数字：通用性标识

第二位数字表明该码是**通用码**还是**制造商码**：

| 数字 | 含义 |
| --- | --- |
| 0 | SAE 通用码（J2012 统一定义，全球通用） |
| 1 | 制造商扩展码（各厂自定义，需查厂家资料） |
| 2 | SAE 通用码（用于更精细的通用定义） |
| 3 | 制造商扩展/预留 |

所以 `P0171` 的第二位 0 表示「SAE 通用码」——任何品牌、任何诊断仪读到的含义一致；而 `P1xxx`、`P3xxx` 是厂家扩展码，必须查对应品牌的资料才能解读。**易错点：把制造商码当通用码去猜，十猜九错。**

## 4 第三位数字：子系统范围

第三位数字把动力总成内部再细分（对 P 码而言）：

| 第三位 | 子系统 | 典型范围 |
| --- | --- | --- |
| 1 | 燃油/空气计量 | P0100–P0199 |
| 2 | 燃油/空气计量（喷油器） | P0200–P0299 |
| 3 | 点火/失火 | P0300–P0399 |
| 4 | 辅助排放控制 | P0400–P0499 |
| 5 | 车速与怠速控制 | P0500–P0599 |
| 6 | 计算机与输出电路 | P0600–P0699 |
| 7–8 | 变速器 | P0700–P0899 |
| A–C | 混合动力/高压电池 | P0A00–P0C99 |

<span class="marginnote"><strong>记忆锚点：</strong> P01xx = 进气燃油、P03xx = 失火点火、P04xx = 排放、P06xx = 电脑内部、P07xx 起 = 变速器。<strong>读码时看第三位，就能把故障归到子系统</strong>——P0300 先想到点火失火，P0420 先想到排放，思路立刻收敛。</span>

## 5 后两位：具体故障编号

后两位是**具体故障编号**，与前面的范围组合成完整含义。读码时「系统 → 子系统 → 具体故障」三层叠加，正是本节开头的结构式：

例如 `P0171` = 动力系统 + 通用码 + 燃油/空气计量 + 系统过稀（Bank 1）；`P0300` = 动力系统 + 通用码 + 点火/失火 + 随机多缸失火。

**重点：后两位的语义要查标准或手册。** SAE J2012 / ISO 15031-6 定义了通用码的完整含义表；维修时「P01xx 查燃油空气、P03xx 查失火」按子系统归位，再按具体编号查故障现象与监测逻辑，五字符就变成了完整的技术信息。

## 6 核心对比表：通用码 vs 制造商码（纯概念主题）

本课是编码结构主题，不含数值公式，用**核心对比表**厘清两类故障码：

| 维度 | 通用码（P0xxx/P2xxx） | 制造商码（P1xxx/P3xxx） |
| --- | --- | --- |
| 定义者 | SAE J2012 / ISO 15031-6 | 各整车厂 |
| 通用性 | 跨品牌通用 | 只在本品牌有效 |
| 解读依据 | 标准速查表 | 厂家维修资料 |
| 举例 | P0171 系统过稀 | P1xxx 变速器内部参数 |
| 诊断仪 | 通用仪可读 | 需品牌专用仪或资料 |

**易错点：通用码读出了扩展含义。** 通用码只保证「码的含义」通用，不保证「该车确实如此」——同一 P0171，不同车的具体成因（油压、真空、MAF 漂移）仍需按车排查。**通用码给方向，制造商码给细节，两者配合才完整。**

## 7 常见故障码速查表

把最高频的通用码整理成速查表，是读码诊断的第一张「牌」：

| 故障码 | 含义 | 优先侦查方向 |
| --- | --- | --- |
| P0171 | 系统过稀（Bank 1） | 真空泄漏、油压低、MAF 偏低 |
| P0300 | 随机/多缸失火 | 公共点火/燃油供应、曲轴信号 |
| P0301–P0308 | 第 N 缸失火 | 该缸火花塞/点火线圈/喷油器 |
| P0420 | 催化器效率低（Bank 1） | 催化器本体、前后氧传感器、排气泄漏 |
| P0442 | EVAP 小泄漏 | 油箱盖、EVAP 管路 |
| P0101 | MAF 范围/性能 | 空气滤清器、MAF 积垢、进气泄漏 |
| P0335 | 曲轴位置传感器电路 | 传感器、线束、信号盘间隙 |
| P0507 | 怠速高 | 怠速空气旁路、节气门积炭 |
| P0113 | 进气温度过高 | 进气温度传感器、线束 |
| P0130 | 氧传感器电路故障（Bank 1） | 氧传感器、加热电路、线束 |

<span class="marginnote">这张速查表对应第 4 篇《典型故障码诊断案例分析》的完整案例。<strong>记住「优先侦查方向」这一列，比背码更有用</strong>——故障码告诉你方向，方向上的排查才见真功夫。</span>

**读码的正确姿势**：先看字母定系统、再看第二/三位定通用性与子系统、后两位定具体故障，最后查速查表与厂家资料——五步下来，故障码就从「一个代号」变成了「一张侦查地图」。这与上一课「OBD 是法规化的自检报告」一脉相承：报告里的每条条目，都靠这套编码规则被全世界读懂。

## 8 小结

- 故障码 = **字母 + 四位数字**：字母定系统（P/C/B/U），第二位定通用性（0/2 通用，1/3 厂家），第三位定子系统，后两位定具体故障。
- 通用码（P0xxx）全球通用，制造商码（P1xxx）须查厂家资料——**别拿通用思路猜厂家码**。
- 读码三层叠加：**系统 → 子系统 → 具体故障**，P03xx 想点火失火、P04xx 想排放。
- 高频码速查：P0171 过稀、P0300 随机失火、P0420 催化器、P0442 蒸发泄漏等。
- 故障码是「侦查地图」不是「判决书」：给方向，不代替排查——方向上的数据流与量测见真章。
