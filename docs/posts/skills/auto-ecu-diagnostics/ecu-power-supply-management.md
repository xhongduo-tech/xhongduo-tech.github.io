## 为什么从供电开始

传感器靠 ECU 供电才能工作，执行器靠电池能量才能动作，ECU 靠稳定的电源才能运算——**电源是电控系统的生命线**。然而供电故障恰恰是最会「伪装」的故障：蓄电池端子松动，可以表现为「怠速不稳」「偶发熄火」「车窗时好时坏」甚至「多个系统同时报失去通信」——修车师傅查了一圈传感器，最后发现只是地线接触不良。<span class="marginnote">行业里有句经验之谈：<strong>「十个奇怪故障，三个是搭铁问题，两个是供电问题。」</strong> 供电与搭铁是电控诊断的「第 0 步」——在怀疑任何传感器、执行器、ECU 之前，先确认电源与地是干净的。本课讲清供电架构、电源管理逻辑与电压降测试，这是之后所有系统检修的公共前提。</span>

## 1 供电架构：从蓄电池到 ECU

汽车低压电气系统以 **12V 蓄电池**为储能核心，**发电机（交流发电机）**在运行中充电并维持系统电压约 13.5–14.8V。从蓄电池到 ECU，电源分几路：

| 供电端子 | 来源 | 用途 |
| --- | --- | --- |
| 常电（30 端子） | 蓄电池直接、不经点火开关 | ECU 记忆保持、防盗、门锁 |
| 点火电（15 端子） | 经点火开关 | 运行时才通电的部件 |
| 主继电器供电 | 点火开关控制主继电器，再给 ECU 主电源 | 防止 ECU 一直带电 |
| 搭铁（31 端子） | 车身地 | 所有回路的电流返回路径 |

**重点：ECU 通常有「常电 + 点火电」两路输入。** 常电保持 EEPROM 中的学习值与故障码，点火电告诉 ECU「发动机要工作了」；两路电压的**顺序**也很重要——先上常电、再上点火电，ECU 才能正确初始化。诊断中「丢码」「学习值清零」，先查常电是否持续供电。<span class="marginnote">主继电器是供电管理的关键件：点火开关只控制继电器线圈的小电流，继电器触点接通 ECU 主电源的大电流。继电器触点烧蚀、线圈失效，会让 ECU「偶尔上电、偶尔不上电」。听继电器吸合声、量继电器输出端子电压，是排查 ECU 不上电的第一动作。</span>

## 2 电源管理：运行、休眠与唤醒

现代汽车大量 ECU 不能一直满功率运行，否则静态电流会耗尽蓄电池。电源管理把 ECU 的状态分为几档：

**运行模式**：点火电接通，ECU 全速采集、计算、输出。
**睡眠模式（sleep）**：车熄火锁车后，ECU 关闭大部分外设，只保留唤醒电路，静态电流降到毫安级。
- **唤醒（wake-up）**：点火、开门、遥控解锁、CAN/LIN 总线上的唤醒帧，都能把 ECU 从睡眠中唤醒。

**重点：整车静态电流的「正常」与「异常」。** 锁车休眠后整车静态电流一般应小于 50 mA（不同车型有标准值）。若某个 ECU 没有进入睡眠（例如网关没收到「已锁车」信号），静态电流偏大，蓄电池几天内亏电。<span class="marginnote">诊断「停驶几天后没电」，先测静态电流：把万用表串联在蓄电池负极，锁车后观察电流是否降到标定值。若电流持续偏高，再逐个拔保险丝、观察电流回落——拔到哪个保险电流骤降，元凶就在那一路。这是电控时代「查漏电」的标准手法。</span>

## 3 ECU 内部的电源处理

ECU 收到的 12V 电源不会直接进 CPU，而是要经过内部电源管理电路：

**稳压**：把波动的 12V 稳压成 CPU 需要的 5V/3.3V 逻辑电压。
**5V 参考电压输出**：为传感器供电（见第 1 篇第 2 课）。这个 5V 一旦异常，挂在这路的所有传感器读数都会漂移——所以先量 5V 参考，再量传感器。
- **掉电保持**：主电源断开后，用内部电容或常电维持 RAM 一小段时间，让 ECU 完成「关机关书」操作。
- **电压补偿**：ECU 用当前电池电压修正控制量——电压低时延长喷油、点火闭合时间、提高怠速，补偿因电压低导致的能量不足（见第 1 篇第 3 课的点火闭合时间）。

**起动瞬间的考验**：起动机大电流让蓄电池电压在起动瞬间跌到 9V 甚至更低，ECU 必须扛过这个电压跌落不重启、不失忆。<span class="marginnote"><strong>易错点：</strong> 起动时电压跌落过低（低于约 7–8V）会导致 ECU 复位，表现为「起动时仪表闪、系统初始化、故障码偶发」。测起动瞬间电压，能判断蓄电池内阻与线路压降是否超标——这比单纯量「静止电压 12.6V 正常」更能反映真实健康度。</span>

## 4 公式解析：电压降测试

供电故障里，**接触不良**最难查——用万用表量端子两端电压可能都是 12V，但带负载后电流流过氧化、松动的接点产生压降，设备就「吃不饱」。**电压降测试**就是专门揪这种隐性故障的方法。

$$
V_{\text{drop}} = I \times R_{\text{contact}}
$$

分三步拆解：

- **第一步，理解压降**：$I$ 是通过线路的负载电流，$R_{\text{contact}}$ 是接点的接触电阻。接触电阻随氧化、松动增大，压降随之增大。**负载电流越大，接触不良的压降越明显**——所以电压降测试必须在「带负载」状态下进行，空载测不出问题。
- **第二步，正确测量**：万用表置于电压挡，红表笔接供电端（如蓄电池正极），黑表笔接负载端（如起动机端子），**在负载工作（如起动、开大灯）时读表**。读数就是该段线路的总压降。
- **第三步，对照标准**：一般要求蓄电池正极到 ECU/执行器端压降小于 0.5V，单个连接点（保险、端子、开关）压降小于 0.1V；搭铁回路同理，负极到车身各搭铁点压降也应小于 0.5V。压降超标，说明该段有接触不良或线径不足。

**易错点：把「测电压」当「测压降」。** 测某点有没有 12V 只是「通不通」，测压降才是「够不够」。同一个搭铁点，空载量 0V（以为没问题），带负载量可能压降 1V——设备已经「饿」得没法正常工作了。

## 5 供电故障的典型表现与诊断

供电故障的症状五花八门，但诊断路线很固定：

1. **量静止电压**：蓄电池静止电压约 12.6V（满电）。低于 12.4V 说明亏电，低于 12V 说明严重亏电或蓄电池老化。
2. **量起动电压**：起动瞬间电压不应低于约 9.5–10V。跌得太狠，查蓄电池内阻、桩头接触、起动机电流。
3. **量发电机输出电压**：运行中应在 13.5–14.8V。过高（过充）或过低（欠充）都要查发电机与调节器。
4. **量 ECU 各供电端子**：常电、点火电、主继电器输出，逐路确认有电、压降合格。
5. **量搭铁回路**：对每一个「怪异故障」，先把相关回路的搭铁点压降测一遍——**搭铁不良是间歇性故障的头号元凶**。

<span class="marginnote">供电诊断有个好处：它不依赖诊断仪的高级功能，一支万用表足矣。而它排除的，恰恰是故障树里最底层的干扰项——先把供电与搭铁证伪，后面所有传感器/执行器/网络诊断才有意义。这也是维修行业把「先查供电搭铁」列为铁律的原因。</span>

## 6 蓄电池与负载管理

现代车辆对蓄电池的管理越来越「智能」，这是电源管理在整车层面的延伸：

**核心概念：蓄电池不只是储能件，还是整个电源系统的「缓冲池」。** 发电机的电压调节、起动时的大电流、熄火后的静态电流，全部落在蓄电池上。不同技术等级的蓄电池特性不同：

| 蓄电池类型 | 特点 | 典型应用 |
| --- | --- | --- |
| 普通铅酸 | 便宜、耐过充一般 | 老旧车型 |
| EFB（增强型富液） | 耐高温、支持起停 | 启停系统标配 |
| AGM（玻璃纤维隔板） | 内阻低、循环寿命长 | 启停 + 能量回收车型 |

**重点：换蓄电池必须匹配原车规格。** 带起停系统的车必须用 EFB 或 AGM 蓄电池——普通蓄电池扛不住起停系统的高频大电流，几个月就坏。更换后还需用诊断仪做**蓄电池注册/编码**（让电源管理系统重新学习新电池的参数），否则充电策略错配，新电池也短命。

**易错点：电压正常不等于电源健康。** 静止电压 12.6V 只能说明「还有电」，蓄电池内阻升高后带负载能力大幅下降——**测起动电压（不应低于约 9.5–10V）与充电电压（13.5–14.8V）才是判断蓄电池/发电机健康的可靠手段**（呼应本课第 5 节的供电诊断五步）。

**供电故障的「症状伪装」清单**，帮你在看到这些怪症状时先想到电源：

| 伪装症状 | 常见电源根因 |
| --- | --- |
| 偶发熄火 | 搭铁接触不良、继电器触点烧蚀 |
| 多个系统同时报警 | 共享供电/搭铁异常 |
| 起动时系统复位 | 起动电压跌落过深 |
| 怠速不稳 | 电源电压波动影响修正 |
| 记忆丢失、码清零 | 常电（30 端子）断路 |
| 无法唤醒/沉睡 | 唤醒线或电源管理异常 |
| 充电灯亮 | 发电机或调节器故障 |
| 大灯随怠速闪动 | 充电电压不稳、搭铁不良 |

**先证伪电源，再谈其他**——供电与搭铁是电控诊断的「第 0 步」，这一步走稳了，后面的传感器、执行器、网络诊断才有意义。

## 7 小结

- 供电架构分**常电、点火电、主继电器供电、搭铁**四路；ECU 靠常电保记忆，靠点火电感知工作状态。
- 电源管理有**运行、睡眠、唤醒**三态；锁车静态电流超标是「停驶亏电」的常见原因，用「拔保险看电流回落」定位。
- ECU 内部做**稳压、5V 参考、掉电保持、电压补偿**；起动瞬间电压跌落过深会导致 ECU 复位。
- 电压降测试公式 $V_{\text{drop}} = I \times R_{\text{contact}}$
