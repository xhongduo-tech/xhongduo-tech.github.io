## 为什么从避险原则开始

上一节讲了「黄金 12 秒」——地震的第一波晃动里，时间只够做一个动作。这个动作是什么、怎么做、在哪做，就是本节的全部内容。它不需要你有多大力气、多快速度，只需要一个**预先练熟的条件反射**。<span class="marginnote">地震避险与火灾逃生有一个本质区别：火灾需要「向外跑」，地震的多数伤亡恰恰来自「慌乱的奔跑」——门窗变形让人困在楼内、楼梯拥挤导致踩踏、坠物砸中奔跑者。所以地震的第一课，是学会「不动、找掩护、护住自己」。</span>

## 1 国际通行的避险口诀：伏地、遮挡、手抓牢

全球地震高发国家（尤其美国、日本、新西兰）的主流避险指南，都推荐同一个动作组合，英文是 **Drop, Cover, Hold On**，中文可记为「**伏地、遮挡、手抓牢**」：

1. **伏地（Drop）**：地震摇晃时双脚难以站稳，主动下蹲、趴下，降低重心——防止被晃动甩倒摔伤。
2. **遮挡（Cover）**：躲到坚固的桌子底下、床沿或承重墙墙角，用手臂、书包、枕头护住**头颈**——头部与颈部是地震中最致命、最脆弱的部位。
3. **手抓牢（Hold On）**：抓住桌腿等固定物，防止身体被晃动甩出掩体；掩体会移动时，跟着它一起动，始终把自己藏在里面。

**辨析｜易错点：** 网上流传甚广的「生命三角理论」（躲在沙发、床等大型家具旁形成的三角形空隙）有很大争议，国际主流机构并不推荐——因为**你无法预判哪面墙会倒、三角空间会不会被压垮**，而「伏地、遮挡、手抓牢」是经过大量实战检验、适用于绝大多数场景的通用方案。**记住：宁可躲进桌下，不要赌墙角的「三角」**。

## 2 核心对比表：躲还是跑？

地震时最纠结的问题：「待在原地躲，还是往外跑？」判断依据是场景与时机：

| 场景 | 正确选择 | 理由 |
| --- | --- | --- |
| 晃动刚开始（第一波） | **立即就地躲避** | 奔跑中被坠物砸中、被晃动摔倒的风险更高 |
| 位于底层、出口近在咫尺 | 可快速撤离到室外开阔地 | 前提是出口畅通、距离短、无坠物风险 |
| 位于中高层 | **不向楼梯冲** | 楼梯在震中易塌、易拥堵踩踏，门窗变形可能困住 |
| 晃动停止后 | 有序撤离到户外集合点 | 警惕余震，不再留在室内 |
| 任何时段的电梯 | **绝不乘电梯** | 断电困梯 + 电梯井坠落，是最危险的「死胡同」 |

**辨析｜易错点：** 「躲还是跑」没有绝对答案，但有两条铁律：**第一，震中附近几乎无时间差，第一反应永远是就地躲避；第二，不要把「往外跑」当成默认动作**——无数伤亡发生在奔跑途中。稳妥的策略是「先躲过首波，再评估撤离」。

## 3 室内安全点与危险点

在家里，哪些位置是避震的「安全岛」，哪些是「死亡区」？提前记住这张图，地震时不用现场思考：

| 类别 | 位置 | 原因 |
| --- | --- | --- |
| 安全点 | 承重墙墙角 | 承重墙不易倒塌，墙角结构最稳固 |
| 安全点 | 坚固桌子、床沿之下 | 可遮挡坠物，形成保护空间 |
| 安全点 | 卫生间角落 | 空间小、管道多、支撑强，且有水源 |
| 危险点 | 窗户与玻璃门 | 玻璃震碎飞溅，形成利刃 |
| 危险点 | 吊灯、吊扇下方 | 悬挂物坠落 |
| 危险点 | 高大家具（书柜、衣柜）旁 | 家具倾倒砸人 |
| 危险点 | 阳台与外墙附近 | 非承重墙与栏板易塌、易坠 |

**易错点：** 睡床的位置尤其重要——**床不要正对窗户或大型吊灯**；床头不要挂镜子、相框等重物。如果床旁恰好有大型衣柜，睡前确保柜门关好，并考虑把衣柜固定到墙上。

## 4 震时动作的细节清单

在「伏地、遮挡、手抓牢」的大框架下，还有几个细节决定生死：

**护头颈**：双手抱头、低头，或用枕头、书包、坐垫护住头颈；背部可背对窗户，减少玻璃溅伤。
**顺手关火（条件允许时）**：若就在厨房、燃气灶前，顺手关闭灶火与气阀——可以避免震后燃气泄漏引发次生火灾；但不要为关火而跑动。
- **不跳楼**：**三层以上绝不跳楼**——跳楼死亡率极高，而只要待在室内找掩护，生还概率大得多。
- **不乘电梯**：任何时候都走楼梯；晃动中绝不使用电梯。
- **远离易倒物**：不在书柜、冰箱、空调外机、吊顶下方停留。

<span class="marginnote">家中可为每个成员准备一个「护头枕」或头盔（骑行头盔、安全帽均可），放在床头或办公桌旁——地震时随手抓起来扣在头上，头颈保护立刻到位。这个小物件，是成本极低的保命投资。</span>

## 5 第一次晃动停止后：撤，还是留？

地震往往是「主震 + 余震」的序列。第一次剧烈晃动停止后：

- **判断环境**：若所在房间结构明显受损（墙裂、楼板下沉、闻到燃气味），立即准备撤离。
- **有序撤离**：走疏散通道下楼，**不拥挤、不推搡、不逆行**；用随手物品护住头，留意头顶坠物。
- **关闭火源气源**：撤离前若方便，关掉燃气总阀、电闸，防止次生灾害。
- **到集合点会合**：到户外的开阔集合点与家人会合，清点人数；远离建筑物、电线杆、高架桥、山体边坡。
- **警惕余震**：主震后余震可能在几分钟到几天内陆续发生，**不要因为「停了」就急着返回室内取物**。

### 震后撤离与余震防范

主震停息后的撤离与余震防范，是避震的「下半场」：

- **不急于撤离**：先观察周围——墙体有无继续开裂、楼板有无沉降；确认相对安全再行动，**避免在晃动未完全停止时冲进通道**。
- **撤离带物**：顺手带上床头的手电、鞋和应急包（若在门口附近）——赤脚、摸黑逃生是震后常见的二次伤害源。
- **余震不断**：主震后余震可能持续数小时到数天，**远离已受损的建筑与外墙**，不要在楼下逗留观望。
- **观察次生灾害**：撤离途中留意燃气味（可能有泄漏）、电线掉落（可能带电），绕行避开。

**易错点：** 震后最常见的「放松过头」——晃动一停就回屋取东西、或站在楼下看热闹。**余震和次生灾害在晃动停止后才真正发威**，撤离到开阔处后，不要急着返回。

### 「伏地、遮挡、手抓牢」的三个常见误区

口诀人人会背，但执行时有三处最容易走样：

- **误区一：伏地太「快」，遮挡太「敷衍」**——蹲下就以为完成，手没护头、也没找掩体。**完整的动作是三件都做**：下蹲 + 躲到掩体下/旁 + 双手护住头颈，缺一不可。
- **误区二：藏在「看似安全」的家具旁却没抓牢**——躲到桌子旁却站在桌外，晃动一来人被甩出去。**要「躲进去」而不是「站在旁边」**，并抓住桌腿固定自己。
- **误区三：把「护头」理解成「抱头趴地就完」**——趴地是基础，但还要**选择掩体**：趴在开阔地中央，天花板坠物照样砸头。**护头 + 掩体，两者结合才算「遮挡」。**

**易错点：** 演练时最容易看出误区——让人模拟地震蹲下，大多数人只完成「蹲」而忘了「躲」和「抓」。**用演练纠偏，比背口诀更有效。**

### 不同人群的伏地遮挡差异

口诀要因人调整，不能「一刀切」：

- **老人**：下蹲困难者，**坐在床边、椅旁，低头护住头颈**，用椅背、床沿作为遮挡；不强行要求「伏地」。
- **孕妇**：**侧卧护住腹部**，或坐在墙角用双手护住腹与头，避免俯卧压迫腹部。
- **幼儿**：大人将其抱入怀中，**用自己的身体包裹孩子**，护住其头颈——孩子躲进大人怀里，比单独教孩子做动作更可靠。
- **行动不便者**：卧床者用被子护住头颈；坐轮椅者锁定轮椅、低头护头。

**易错点：** 「伏地遮挡手抓牢」是通用原则，不是「所有人的标准姿势」——**老人、孕妇、幼儿、残疾人都要提前想好「自己的动作版本」**，真震时才不会手足无措。

## 6 小结

- **黄金动作**：伏地、遮挡、手抓牢（Drop, Cover, Hold On）——下蹲、护头颈、抓固定物。
- **躲优于跑**：第一波晃动立即就地躲避，不盲目向外冲；中高层绝不冲楼梯。
- **安全点与危险点**：承重墙墙角、桌下、卫生间角落是安全岛；窗、吊灯、高大家具、阳台是死亡区。
- **细节保命**：护头颈、顺手关火、不跳楼、不乘电梯。
- **震后不放松**：晃动停止后有序撤离、关燃气、到集合点、警惕余震。

在下一节，我们把「室内避震」单独拎出来放大——**室内避震要点**，把卧室、客厅、厨房、卫生间各自该怎么做讲透，因为你的第一反应取决于你当时在哪个房间。
