## 为什么从疏散演练开始

前面十几篇讲了大量的知识：怎么防火、怎么灭火、怎么逃生、怎么避震。但知识与能力之间，隔着一道必须靠「练」跨过的坎——**火灾或地震来袭时，人几乎不会「现场思考」，只会「按记忆里的动作」行动**。<span class="marginnote">应急管理领域有个共识：危机中人的反应不是「想出来的」，而是「练出来的」。没演练过的家庭，火灾时可能在门口犹豫、找不到集合点、面罩开封都来不及；演练过的家庭，动作是自动的、配合是默契的——这就是演练的价值。</span>

这一节教你把「知识」变成「家庭流程」：先制定疏散计划，再按灾种演练，最后用讲评持续改进。

## 1 家庭疏散计划三要素

演练之前，先有一份「纸上的计划」——它由三部分组成：

**逃生路线。** 为**每间房规划两条逃生路线**：主路线走门、经楼道到户外；备用路线走窗户或阳台（前提是低层可安全使用、或配有逃生绳）。把路线画成**家庭逃生图**，标出门、窗、楼梯、灭火器位置与户外集合点，贴在家门内侧与床头，让每个家庭成员都看过、指过。

**户外集合点。** 选一个离家不远、开阔、不易被火烟波及的地点（如小区广场、路口标志物旁）作为集合点。**约定「到集合点报到」的规则**——无论从哪条路逃出来，都先到集合点清点人数，防止「逃出来了又回去找人」。

**应急联系人。** 选定一位**不在本地的亲友**作为外部联系人（如外地的亲戚）——灾时本地电话可能拥堵，外地号码更容易接通，全家都记住这个号码，由一人负责拨出报平安。<span class="marginnote">「本地失联、外地可通」是灾害通讯的常见规律——基站受损、线路拥堵时，跨地域的通话成功率往往更高。这也是为什么应急计划要把「外部联系人」设为外地亲友，而不是楼下的邻居。</span>

## 2 核心对比表：分灾种的演练脚本

不同灾害的动作完全不同，演练要「分灾种、练对动作」：

| 灾种 | 听到警报/察觉信号 | 核心动作 | 撤离时机 | 集合后 |
| --- | --- | --- | --- | --- |
| 火灾 | 烟雾报警器响、闻到烟味 | 低姿、捂口鼻、摸门把 | 确认通道安全立即撤 | 清点人数、报 119 |
| 地震 | 上下颠簸（P 波） | 伏地、遮挡、手抓牢 | 晃动停止后有序撤 | 远离建筑、清点人数 |
| 燃气泄漏 | 臭鸡蛋味 | 关阀、开窗、不动电器 | 立即撤离到室外 | 室外报警、不返回 |

**辨析｜易错点：** 最常见的演练错误是「把所有灾害都练成同一套动作」——听到警报就低头往外跑。但地震的「往外跑」恰恰是危险的（晃动中奔跑易伤），燃气泄漏又要求「先关阀再撤离」。**分灾种练，才能在真灾时做对第一反应。**

## 3 演练的步骤与方法

一份完整的家庭演练，走五步：

1. **家庭会议讲计划**：全家围坐，由一人讲解逃生图、两条路线、集合点、分工（谁负责老人小孩、谁负责拿应急包）。
2. **宣布并计时**：选择一个时段（周末白天），宣布「演练开始」，用手机计时——记下从警报响起到全员到达集合点的时间。
3. **真实执行**：按灾种脚本执行动作。火灾演练要**真正低姿、摸门把、走路线**，不能「说说而已」；地震演练要真正躲到桌下护头；燃气演练要走到户外集合点。
4. **讲评**：回到集合点后，讨论——哪里慢了？路线有没有被堵？有没有人忘了动作？把问题记下来。
5. **改进再练**：针对讲评出的问题调整计划（清杂物、挪家具、换集合点），**隔一段时间再练一次**，直到全家动作流畅。

**演练频率与条件：** 建议**每半年一次**，并刻意安排一次**夜间演练**——火灾多发于夜间，睡梦中被警报惊醒时的反应，才是真实水平。演练时还可以制造点「障碍」（如把主路线标为「被烟封锁」），考验备用路线的熟练度。<span class="marginnote">夜间演练对儿童尤其重要：睡梦中被叫醒后，孩子容易慌乱哭闹。提前告诉孩子「这是演习」，用游戏化的口吻带他们走一遍，能显著降低真实火灾时的恐慌。</span>

### 演练记录与复盘模板

演练后的复盘要「有据可依」，一份简单的记录表就够了：

| 复盘项 | 记录内容 |
| --- | --- |
| 演练时间与灾种 | 2026-08-14，夜间火灾演练 |
| 用时 | 从警报响到全员到集合点：4 分 20 秒 |
| 顺利项 | 主路线畅通、全员低姿捂口鼻、无跌倒 |
| 问题项 | 老二忘了拿防烟面罩；楼道转角被纸箱挡路 |
| 改进措施 | 面罩移到床头；清楼道杂物并立规则 |
| 下次复查 | 1 个月后加练一次夜间场景 |

**易错点：** 复盘最忌「说两句就散」——问题列了、下次却不复查，等于没复盘。**把「下次复查」写进记录，并在下次演练前先核对上次问题是否已整改**，让演练真正形成「练—查—改—再练」的闭环。

## 4 演练暴露的问题与改进

演练最大的价值，是**暴露平时看不见的问题**。常见问题与对策：

| 演练中暴露的问题 | 对策 |
| --- | --- |
| 楼道堆物挡路 | 立即清理，并定「楼道不留物」规则 |
| 防烟面罩不会用/找不到 | 放到床头，全家实操一遍开封佩戴 |
| 集合点选得不好（太远/被烟波及） | 更换集合点并更新逃生图 |
| 小孩慌乱哭闹 | 增加演练频率，游戏化引导 |
| 逃生时间过长 | 清障、精简路线，必要时换门锁（更易开启） |
| 有人差点返回火场取物 | 重申「绝不重返」铁律 |

**易错点：** 演练后最常见的松懈是「演完就忘」——计划贴了墙，但从不更新、从不复练。**把演练写进家庭日历（半年一次 + 换季加练）**，让「演练」和「检查燃气」一样成为家庭惯例，而不是一次性的活动。

### 夜间演练与特殊成员演练

演练要「贴近真实」，两个方向最值得投入：

**夜间演练。** 火灾多发于夜间，睡梦中被警报惊醒的反应，才是真实水平。夜间演练要刻意安排：**拉上窗帘、关灯，在黑暗中按记忆完成全流程**——摸黑找鞋、摸黑走楼梯、摸黑到集合点。它能暴露白天演练看不到的问题：逃生路线在黑暗中认不认得出、手电放在哪、孩子夜里会不会慌乱。

**特殊成员演练。** 家有老人、幼儿、行动不便者时，演练要「为最弱的人设计」：

- **幼儿**：用游戏化方式（「我们玩消防员出发的游戏」）带其走路线，让孩子**不惧警报声、不怕黑暗**。
- **老人**：重点练「听到警报怎么反应、走楼梯怎么扶扶手、集合点怎么走」，并确认其身体状况能完成撤离。
- **行动不便者**：提前规划**专人协助撤离**的分工，演练时实际走一遍「扶抱/轮椅转运」流程。

**易错点：** 演练最怕「糊弄」——全家穿着睡衣、开着灯、慢悠悠地走到集合点，演练就失去了意义。**演练的目标不是「走一遍」，而是「在接近真实的条件下，让全家达到熟练**」——每次演练都当一次「真灾」来对待。

### 演练的「真实性」原则

让演练真正有用，三条原则缺一不可：

- **突然性**：不要提前一周通知「周六演练」——在某个全家都在的周末，突然拉响警报（用手机放警报声或真人喊「演练开始」），测试真实反应。
- **障碍性**：演练时人为制造障碍——把主路线标成「被烟封锁」，考验备用路线；把一处通道标为「被堵」，考验灵活应变。
- **计时性**：每次演练都计时，记录「从警报响到全员到齐」的时间；下次演练的目标是「比上次快、且零失误」。

**易错点：** 「突然性」演练要注意别吓到老人小孩——提前和孩子说「这周可能有一天会突然演练，到时候你要像小消防员一样反应」，既保留突然性，又避免过度惊吓。

## 5 小结

- **计划三要素**：每间房两条逃生路线 + 户外集合点 + 外地应急联系人，画成逃生图贴床头。
- **分灾种练**：火灾低姿捂口鼻、地震伏地遮挡手抓牢、燃气关阀再撤离——动作别练串。
- **五步演练法**：讲计划、计时、真实执行、讲评、改进——半年一次 + 夜间演练。
- **问题即财富**：演练暴露的每个问题都是改进的机会，清理、更新、复练。
- **演练是惯例**：写进家庭日历，让「练」和「查」「备」一样成为家庭的固定动作。
- **演练要真实**：突然性、障碍性、计时性三原则，让每次演练都当一次「真灾」来对待。

在下一节，我们把「备」落到实处——**家庭应急物资与急救准备**，细讲应急包里该装什么、急救能力该怎么练，让全家的应急准备从「有概念」变成「有实物、有技能」。
