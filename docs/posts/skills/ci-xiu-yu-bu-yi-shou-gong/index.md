# 刺绣与布艺手工

刺绣与布艺手工是以非遗中国刺绣技艺为核心的工艺美术体系，贯通苏绣、湘绣、蜀绣等名绣针法与拼布缝纫实用工艺。学完这些章节，就写完了从绣线针法、名绣流派到拼布作品创作的系统化手工技艺全部内容。

- 《刺绣工艺与技法》
