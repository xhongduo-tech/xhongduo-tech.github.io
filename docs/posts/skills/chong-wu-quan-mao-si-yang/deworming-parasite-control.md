## 为什么从寄生虫防控开始

疫苗挡病毒，驱虫挡寄生虫——两者合起来才是完整的「预防医学」双翼。寄生虫比病毒更「可见」：跳蚤会在被毛里跳动，蛔虫会随粪便排出，蜱会吸在皮肤上。<span class="marginnote">「从极限到大模型」的主线训练我们<strong>把系统拆开看</strong>：寄生虫防控也是一套系统——宿主（犬猫）× 寄生虫 × 环境三者构成传播环，任何一环断掉，循环就转不起来。灭虫不如断环。</span>

但「可见」不等于「无害」：许多体内寄生虫（心丝虫、钩虫）在早期几乎无症状，等出现症状往往已造成不可逆损伤；更有**人兽共患**风险——蛔虫、弓形虫、棘球绦虫都能感染人，儿童尤其危险。这一节讲清寄生虫的分类、生活史与驱虫程序，属于《宠物健康护理员职业技能标准》中级技能。

## 1 寄生虫的「敌人画像」：体内与体外两大阵营

**寄生虫（parasite）**：寄居在宿主体表或体内、以宿主为食并造成损害的生物。按寄生部位分为**体内寄生虫**与**体外寄生虫**，防控策略截然不同。

**核心对比表（纯概念主题，以对比表替代公式解析）：**

| 维度 | 体内寄生虫 | 体外寄生虫 |
| --- | --- | --- |
| 代表 | 蛔虫、钩虫、绦虫、鞭虫、心丝虫 | 跳蚤、蜱、螨、虱 |
| 寄生部位 | 肠道、血液、心脏、肺 | 皮肤、被毛、耳道 |
| 传播途径 | 粪口、经胎盘/乳汁、蚊媒（心丝虫） | 接触、环境、草丛、宿主间直接转移 |
| 主要危害 | 营养不良、贫血、肠梗阻、心衰 | 瘙痒、皮炎、贫血（蜱）、传播疾病 |
| 典型药物 | 芬苯达唑、吡喹酮、米尔贝肟 | 塞拉菌素、非泼罗尼、阿福拉纳 |

理解生活史是防控的关键：**驱虫药只能杀死「当前体内」的虫，防不住「明天从环境里新感染」的虫**。所以驱虫必须「按规律重复」，而不是「想起来才驱一次」。

## 2 体内寄生虫：蛔虫、钩虫、绦虫与心丝虫

**蛔虫（roundworm）**：犬弓首蛔虫（*Toxocara canis\*）与猫弓首蛔虫（*Toxocara cati\*）。经粪口传播，**幼崽可经胎盘与乳汁获得感染**——这就是为什么幼犬幼猫的第一次驱虫要早在 2 周龄就开始。轻度感染无症状，重度则腹胀、营养不良、呕吐出活虫。蛔虫是人兽共患的**幼虫移行症**病原：人误食虫卵后，幼虫在人体内游走，可致肝、眼损伤（眼幼虫移行症），儿童是高危人群。

**钩虫（hookworm）**：犬钩虫（*Ancylostoma caninum\*）。幼虫可**直接经皮肤钻入**——赤脚踩过被污染的土壤就可能感染人（皮肤幼虫移行症）。在宿主体内吸血，导致贫血、黑便（柏油样便）、幼犬急性死亡。

**绦虫（tapeworm）**：最常见的是瓜实绦虫（*Dipylidium caninum\*），以**跳蚤为中间宿主**——犬猫舔毛时误食感染跳蚤而染病。粪便中可见会蠕动的「米粒状」孕节。棘球绦虫（*Echinococcus\*）是人兽共患的囊型包虫病病原，牧区风险高，属重大公共卫生隐患。

**心丝虫（heartworm）**：犬心丝虫（*Dirofilaria immitis\*），经**蚊子叮咬**传播，成虫寄生于右心室与肺动脉，可致心衰与肺损伤。猫也可感染但成虫数量少、症状多为突发性。**心丝虫预防是每月一次的口服/外用/注射长效制剂，而非「一年驱一次」**——因为蚊虫活跃期长，且治疗已经发病的心丝虫病本身危险且昂贵。<span class="marginnote">心丝虫是「预防远优于治疗」的极端例子：预防药每月十几元，而治疗要多次深部注射砷制剂、强制静养数周，且有猝死风险。这是典型的「高方差风险」——罕见但后果严重，用规律预防去对冲。</span>

**弓形虫（*Toxoplasma gondii\*）**：猫是**终末宿主**，随猫粪排出卵囊；人（尤其孕妇）感染可致胎儿畸形。但日常养猫感染风险被高估：室内猫、喂熟食/商品粮的猫几乎不排卵囊，且卵囊排出 1–2 天后才具感染性——**每天清理猫砂、孕妇避免直接接触猫砂**，风险即可控。

## 3 体外寄生虫：跳蚤、蜱与螨虫

**跳蚤（flea）**：猫栉首蚤（*Ctenocephalides felis\*）最常见，也是犬的「客串」宿主。生活史分卵→幼虫→蛹→成虫四期，**成虫只占群体的 5%，其余 95% 藏在环境里**（地毯、沙发、床缝）。所以治跳蚤必须「宠物 + 环境」双管齐下：宠物用药杀成虫，环境用吸尘器+环境杀虫剂断幼虫与蛹。跳蚤还是瓜实绦虫的中间宿主，驱绦虫与防跳蚤要联动。

**蜱（tick）**：硬蜱科，吸附于皮肤吸血，可传播**蜱传疾病**——犬巴贝斯虫（溶血性贫血）、埃里希体、莱姆病（人兽共患）。发现蜱后**不要用手拽**：撕断口器留在皮肤里会引发感染与肉芽肿，应用镊子紧贴皮肤夹住口器、垂直缓慢拔出，或使用专用蜱钩旋转拔出。

**螨虫（mite）**：三类常见——**耳螨**（*Otodectes cynotis\*）寄居耳道，致黑色蜡样分泌物与剧烈甩头；**疥螨**（*Sarcoptes scabiei\*）钻隧道于皮肤，致剧烈瘙痒、丘疹，可传人；**蠕形螨**（*Demodex\*）寄居毛囊，正常动物少量携带，仅在免疫低下时暴发为局部/全身性脱毛。

**易错点：** 「我家猫不出门，不需要体外驱虫」是个高危误区——跳蚤卵可被人鞋底、裤脚、快递箱带回家；蚊虫会飞进室内传播心丝虫；蜱可随外出犬带回家再爬到猫身上。**室内猫同样需要规律体外驱虫，只是频率可按暴露风险调整。**

## 4 公式解析：驱虫药剂量计算

驱虫药的毒性窗口窄：剂量不足杀不死虫，剂量过高可能中毒（幼龄、肝肾疾病个体尤其危险）。正确剂量由体重决定：

$$
D = W \times c
$$

- **$D$**：单次给药剂量（mg）。
- **$W$**：当前体重（kg）。
- **$c$**：该药对目标寄生虫的推荐剂量系数（mg/kg），每种药、每个靶标不同。

分三步拆解：

- **第一步，称准体重**：幼崽体重变化快，每 2 周就可能差一档剂量，**每次给药前都重新称重**，不要按上月体重给药。
- **第二步，查系数**：例如芬苯达唑对犬蛔虫的推荐量为 50 mg/kg，连用 3 天；一只 4 kg 的犬，$D = 4 \times 50 = 200$ mg/次。
- **第三步，核对安全边际**：多数驱虫药的安全范围是治疗剂量的 5–10 倍，但**伊维菌素类在柯利犬（牧羊犬系）存在 MDR1 基因突变敏感**，常规剂量即可中毒——柯利犬及其杂交后代应选用阿福拉纳、米尔贝肟等替代药，或做 MDR1 基因检测。

**实操红线**：切勿「凭经验估算剂量」；猫与犬用药不通用（猫对许多犬用菊酯类滴剂高度敏感，误用可致死）；妊娠期驱虫需选安全性高的药物（如孕期专用方案），并与疫苗一样遵循「健康才用药」原则——**严重贫血、营养不良的个体应先纠正状态再驱虫**。

## 5 驱虫程序与人兽共患防线

**犬的典型程序**：2、4、6、8 周龄起每 2 周驱蛔虫/钩虫一次至 12 周龄，此后每 3 个月一次广谱驱虫（体内）；体外驱虫（跳蚤+蜱）每月一次（依产品与地域），心丝虫预防每月一次（蚊虫活跃区全年）。<span class="marginnote">「体内 3 个月一次 + 体外每月一次」是多数地区的主流推荐，但具体频率应<strong>结合当地流行病学与兽医建议</strong>：心丝虫高发区全年预防，干燥寒冷区可季节化——规律比「固定日历」更本质。</span>

**猫的典型程序**：幼猫 6、8、12 周龄各驱一次体内，此后每 3 个月一次；体外每月一次；户外猫、多猫家庭风险更高，频率可上调。

**人兽共患的「防人」清单**：每天清理猫砂并洗手（弓形虫）→ 幼儿游玩区远离动物粪便（蛔虫）→ 户外归来检查全身有无蜱（莱姆病）→ 处理宠物粪便戴手套（钩虫经皮）→ 宠物定期驱虫是**家庭公共卫生**的一部分，而非「只对它好」。

**环境控制闭环**：体内寄生虫靠「规律驱虫 + 及时清理粪便」断粪口环；体外寄生虫靠「宠物用药 + 环境消杀 + 床上用品高温洗涤」断生活史环。两条环都断了，寄生虫才真正出局。

## 6 术语速查表

**寄生虫与驱虫常用术语（纯概念补充）：**

| 术语 | 含义 |
| --- | --- |
| 体内寄生虫 | 寄生于肠道、血液、脏器的寄生虫，如蛔虫、心丝虫 |
| 体外寄生虫 | 寄生于皮肤被毛的寄生虫，如跳蚤、蜱、螨 |
| 蛔虫 | 经粪口传播的肠道线虫，幼崽可经胎盘乳汁感染 |
| 钩虫 | 吸血性肠道线虫，幼虫可经皮肤钻入人体 |
| 绦虫 | 节片状肠道寄生虫，瓜实绦虫经跳蚤传播 |
| 心丝虫 | 寄生于心脏肺动脉的线虫，经蚊虫叮咬传播 |
| 弓形虫 | 以猫为终末宿主的原虫，孕妇感染可致胎儿畸形 |
| 跳蚤 | 猫栉首蚤最常见，成虫仅占群体的 5%，其余在环境 |
| 蜱 | 吸血的硬蜱，可传播巴贝斯虫、莱姆病等 |
| 耳螨 | 寄居耳道引起黑色蜡样分泌物的螨虫 |
| 生活史 | 寄生虫从卵到成虫的完整发育过程，驱虫要按生活史断环 |
| 中间宿主 | 寄生虫幼虫期寄居的宿主，如跳蚤之于瓜实绦虫 |
| 人兽共患 | 可在人与动物间传播的疾病，驱虫是家庭公共卫生 |

**常见误区：**

- 猫不出门就不用驱虫——不对，跳蚤卵可被人鞋底带回，蚊虫可飞入室内。
- 驱一次管一年——不对，驱虫药只杀当前的虫，需按规律重复。
- 看到成虫才驱——不对，多数寄生虫早期无症状，规律驱虫才防患于未然。
- 犬猫驱虫药通用——不对，猫对许多犬用菊酯类成分高度敏感。
- 用手直接拽蜱——不对，应夹住口器垂直拔出，防止口器残留。
- 孕妇不能养猫——不对，室内猫风险极低，避开猫砂清理并洗手即可。

## 7 小结

- 寄生虫分**体内与体外**两大阵营，防控策略不同；驱虫药只杀「当前的虫」，规律重复才能防「明天的虫」。
- 蛔虫可经胎盘/乳汁感染幼崽、可致人幼虫移行症；钩虫可经皮肤钻入；瓜实绦虫经跳蚤传播；心丝虫经蚊媒传播且预防远优于治疗。
- 体外寄生虫**成虫只占 5%、环境占 95%**，宠物与环境必须双管齐下；拔蜱用镊子垂直拔出，勿手拽。
- 公式解析剂量 $D = W \times c$：每次给药前称重、按系数计算、注意柯利犬伊维菌素敏感与猫犬药不通用。
- 驱虫是**家庭公共卫生**的一环：弓形虫、蛔虫、钩虫、莱姆病都需「宠物驱虫 + 人防」双线闭环。
