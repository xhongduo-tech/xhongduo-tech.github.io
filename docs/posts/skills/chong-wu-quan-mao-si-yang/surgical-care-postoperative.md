## 为什么从外科护理开始

内科靠识别、外科靠处置。绝育、异物取出、肿瘤切除、骨折固定——这些手术之后，宠物的大半恢复时间是在家里度过的，护理质量直接决定「手术成功」能否兑现为「完全康复」。术后感染、切口裂开、镇痛不足，多数不是手术本身的失败，而是护理环节的失误。<span class="marginnote">「从极限到大模型」的主线教我们看<strong>系统的末端</strong>：一套系统再优秀，输出质量取决于最薄弱的环节。手术是系统的前端，术后家庭护理就是那个常被低估的末端——许多「术后出问题」其实出在末端没接住。</span>

这一节属于《宠物健康护理员职业技能标准》高级技能，覆盖伤口处理基础、术后监护、家庭护理与并发症识别四个层面，目标是让护理员成为「兽医之外的第二双眼睛」。

## 1 伤口处理基础：清洁、消毒与包扎

**伤口分类是处理的第一步**：清洁伤口（新鲜切割、无异物）可以直接清创缝合；污染伤口（咬伤、泥土污染）必须**彻底清创 + 开放引流**——咬伤尤其危险，犬猫口腔细菌多，看似小孔，皮下往往是腔隙性坏死，**必须由兽医评估是否需要放置引流管**。

**清洁与消毒的正确顺序**：

**① 冲洗**：用**生理盐水**或清水低压冲洗伤口，冲走异物与细菌。**不要用酒精、双氧水直接冲洗**——酒精刺激剧烈且损伤肉芽组织，双氧水（过氧化氢）在开放伤口上反而破坏新生组织。<span class="marginnote">「消毒力越强越好」是伤口护理的最大误区：理想的伤口清创是<strong>冲走而非烧灼</strong>。医用双氧水与碘伏的适用场景不同——皮肤完整时消毒用碘伏没问题，但进入开放性创面，温和冲洗 + 抗菌敷料才是正解。</span>
**② 消毒**：周围皮肤用**稀释的聚维酮碘（碘伏）**或氯己定擦拭，注意**猫对碘伏与氯己定的耐受都弱于犬**，浓度要更低、擦拭后可用生理盐水再拭一遍。
**③ 包扎**：三层结构——内层**接触层**（不粘伤口的无菌敷料或抗菌凝胶）、中层**吸收层**（纱布）、外层**固定层**（自粘绷带）。**松紧是生命线**：太紧阻断血运（肢体远端肿胀、发凉=过紧），太松脱落无效。观察指征：**趾端/爪垫是否发凉肿胀**。

**换药频率**：清洁小伤口可 1–2 天换一次；渗出多的伤口每天换。每次换药都要观察「渗液颜色气味」——清亮淡黄为正常渗出，黄绿脓性伴臭味提示感染。

## 2 术后即刻监护：麻醉苏醒与疼痛管理

手术结束后到完全苏醒，是最需要专业监护的几小时。

**苏醒期监护三件事**：**保温**（麻醉后体温调节中枢受抑，铺加热垫/暖水袋，但防烫伤）、**气道**（侧卧、头低位、防舌根后坠与呕吐物误吸）、**观察**（呼吸频率与黏膜颜色，黏膜发紫=缺氧）。

**疼痛管理是术后护理的核心，不是「矫情」**。动物不会说「疼」，但会表达：

行为信号：**不进食、躲藏、攻击性（不让碰）、呻吟、弓背、反复舔切口**。
量化信号：心率呼吸上升、血压升高。
- 品种差异：猫的疼痛常表现为「**安静蜷缩、瞳孔放大、拒绝抚摸**」，与「怕人」极难区分——术后突然变「乖」也可能是在忍痛。

**镇痛用药红线**：术后镇痛必须**遵医嘱**。犬常用非甾体抗炎药（NSAIDs）如美洛昔康，但**猫对 NSAIDs 极度敏感，误用犬用 NSAIDs 可致急性肾衰**——「人的布洛芬、犬的药给猫」都是错误。猫的术后镇痛多用丁丙诺啡等阿片类。**任何情况下，不要自行给宠物喂人类的止痛药**（对乙酰氨基酚对猫剧毒、布洛芬对犬猫均伤肾）。

## 3 术后家庭护理：伊丽莎白圈、活动与喂食

出院不是结束，家庭护理才是主战场。三件套：**圈、静、餐**。

**伊丽莎白圈（耻辱圈）**：**必须戴到拆线或伤口完全愈合**，绝不能「看它可怜就摘」。宠物舔切口会让缝线进水感染，严重者**自舔致切口裂开、甚至咬断缝线导致内脏脱出**。圈的大小要「比头长出 5–8 cm」，太短够得着切口等于白戴。<span class="marginnote">「摘圈睡觉、戴圈出门」是术后护理最常见的翻车操作——猫狗在夜间无人看管时最执着于舔伤口。实在要短暂摘圈（进食），必须全程盯着。替代方案（软圈、手术服/背带）也能防舔，但同样要「全程监护」才可。</span>

**活动限制**：术后 **7–14 天**严格限制跑跳，拴绳短遛、上下楼抱行、跳跃面封闭（防切口张力性裂开）。**绝育后两周内的「蹦跳」是切口裂开与阴囊血肿的高发原因**。笼养/围栏限制是「不残忍」，是「负责任」。

**喂食**：麻醉苏醒后先给少量水，无呕吐再给少量易消化食物（术后肠胃功能弱）。**术后 24–48 小时食欲差是正常**，但超过 48 小时仍不吃、或进食即吐，要复查。**绝育术后个别动物食欲大增，注意控制，防止「术后肥胖」**——这直接衔接营养章节的体重管理。

## 4 切口并发症识别与处理

每天检查切口是护理员的必修课。用「**红、肿、热、痛、液**」五字诀对照：

| 表现 | 可能问题 | 处理 |
| --- | --- | --- |
| 红肿 + 发热 + 压痛 | 感染 | 就医，可能需拆线引流 + 抗生素 |
| 切口边缘裂开、渗血 | 切口裂开 | 立即就医，压迫止血 + 重新缝合 |
| 局部隆起、波动感 | 血清肿/血肿 | 小者自行吸收，大者抽吸 |
| 大量黄绿脓性渗液 | 深部感染/脓肿 | 就医清创引流 |
| 缝线处有「线结鼓起」 | 缝线反应 | 通常无害，观察即可 |

**血清肿（seroma）** 是术后最常见的「虚惊」：切口下方皮下积存清亮液体（尤其绝育、乳腺切除后），触之软、波动感、无红肿热痛。小的血清肿数周自行吸收；**鉴别关键是与感染的区分——血清肿不伴发热与红肿**，但拿不准就拍照问兽医。

**切口裂开的处理**：**不要试图自己缝合**，用无菌纱布压迫止血、安抚宠物、立即就医；如见**肠管或组织脱出**，用生理盐水纱布覆盖保护，**不要回塞**，急诊处理。

**拆线时间**（核心对比表，纯概念主题，以时间表替代公式解析）：

| 部位 | 拆线时间 |
| --- | --- |
| 头面部 | 5–7 天 |
| 躯干/腹部 | 7–10 天 |
| 四肢/关节 | 10–14 天 |
| 皮肤张力大处 | 12–14 天或皮内缝线（免拆） |

愈合期间**保持切口干燥**：术后 7–10 天内**不洗澡**，防水护具只用于必要情况。

## 5 公式解析：估计血容量与失血评估

术后最凶险的并发症之一是**术后出血**（内出血或切口出血）。评估失血对循环的影响，先要知道动物「一共多少血」：

$$
BV = W \times k
$$

- **$BV$**：估计全血容量（mL）。
- **$W$**：体重（kg）。
- **$k$**：每公斤体重血容量系数——犬约 **90** mL/kg，猫约 **66** mL/kg。

分三步拆解：

- **第一步，估总血量**：一只 20 kg 的犬，$BV = 20 \times 90 = 1800$ mL——「相当于两大瓶矿泉水」是临床的直觉锚点。
- **第二步，算失血百分比**：若术后发现切口持续渗血并测得失血约 300 mL，失血比例 $= 300 / 1800 \approx 17\%$。
- **第三步，对照危险线**：急性失血 < 15% 机体可代偿（心率稍快）；**15–30% 出现代偿性休克**（心率显著加快、黏膜苍白、CRT 延长——还记得日常评估节的 CRT 吗？）；**> 30% 危及生命，需紧急补液甚至输血**。

**护理实操**：术后一旦见**黏膜持续苍白、精神迅速萎靡、伤口渗血量增多**，先压迫止血，同时记录「大概失血量」与体重，**带着数字去急诊**——「他出了好多血」没有「5 分钟内浸透 3 块纱布」有用。这个「数量化描述」的能力，正是高级护理员区别于初级的关键。

## 6 术语速查表

**外科护理常用术语（纯概念补充）：**

| 术语 | 含义 |
| --- | --- |
| 清洁伤口 | 新鲜切割、无污染，可一期缝合的伤口 |
| 污染伤口 | 咬伤、泥土污染，需彻底清创并开放引流 |
| 清创 | 去除坏死组织与异物的伤口处理步骤 |
| 三层包扎 | 接触层—吸收层—固定层的标准包扎结构 |
| 血清肿 | 术后皮下积存清亮液体，无红肿热痛，多可自愈 |
| 麻醉苏醒期 | 手术结束到完全清醒的监护窗口 |
| 伊丽莎白圈 | 防舔咬切口的头圈，需戴到拆线或愈合 |

**常见误区：**

- 摘圈睡觉、戴圈出门——不对，夜间无人看管时宠物最执着舔伤口。
- 切口看起来干就万事大吉——不对，每天要按「红肿大痛液」五字诀检查。
- 术后一周就能放开跑跳——不对，7–14 天内需严格限制活动。

## 7 小结

- 伤口处理**顺序**：生理盐水冲洗 → 稀释碘伏消毒 → 三层包扎；咬伤必须清创引流；「消毒力越强越好」是误区。
- 麻醉苏醒期护好**保温、气道、观察**三件事；疼痛管理要读行为信号，**猫痛会「装乖」**。
- 镇痛红线：**猫禁用犬用 NSAIDs、禁用一切人类止痛药**。
- 术后家庭护理三件套：**伊丽莎白圈戴到愈合、限制跑跳 7–14 天、循序恢复喂食**。
- 切口五字诀「红肿大痛液」识别并发症；血清肿与感染要分清；切口裂开不自己缝。
- 公式解析 $BV = W \times k$：血容量估算 + 失血百分比判断，学会**带数字去急诊**。

在下一节，我们把护理能力推向最紧急的关头——**常用急救措施与应急处理**。当心跳停止、窒息、中毒发生时，前几分钟的处置质量决定了生死。
