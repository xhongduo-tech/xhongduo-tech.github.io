## 为什么从传染病识别开始

疫苗建立了主动免疫，驱虫清除了寄生虫，但传染病依然每年夺走大量未免疫宠物的生命——犬瘟、细小、猫瘟对幼龄动物的致死率可以高达 50%–90%。传染病与寄生虫最大的不同在于**传染性**：一只感染动物可以波及一窝、一栋楼的宠物，防控必须上升为「群体」而非「个体」问题。<span class="marginnote">这正是「从极限到大模型」里反复出现的<strong>规模效应</strong>：单个体的治疗是常数成本，群体传播是指数成本。疫苗之所以是「性价比之王」，就在于它在传播的<strong>源头</strong>就把指数掐断。</span>

这一节的核心任务有三个：**认得出**（识别常见传染病的关键症状）、**分得清**（与相似疾病鉴别）、**防得住**（隔离、消毒、疫苗联动）。它属于《宠物健康护理员职业技能标准》中级技能，也是「识别 → 预防 → 护理」三级链条的中间环节。

## 1 传染病的传播三要素与防控逻辑

任何一种传染病要流行，都离不开三个要素：**传染源**（感染动物）、**传播途径**（直接接触、气溶胶、粪口、媒介）、**易感动物**（未免疫个体）。防控就是「断三环中任何一环」：

**断传染源**：隔离病宠、不散养、新宠到家的 2 周观察期。
**断传播途径**：环境消毒、粪尿及时清理、病宠用品的单独管理。
**断易感动物**：按时免疫——这是最核心的一环，因为前两环在家庭场景很难做到绝对。

**易错点：** 很多人以为「病宠痊愈后家里就安全了」。实际上许多病毒在环境中存活极久：犬细小病毒在含氯消毒剂之外的多数组分中可存活数月甚至更久，猫瘟病毒对许多消毒剂也不敏感。**痊愈后必须用含氯消毒剂（次氯酸钠）或宠物专用高效消毒剂彻底环境消毒，未免疫的幼崽至少要等 4 周以上再进家。**

## 2 犬常见传染病：犬瘟、细小、传染性肝炎与窝咳

**犬瘟热（CDV）**：由犬瘟病毒引起，经**气溶胶**传播，传染性极强。典型病程呈**双相热**：首发热 1–3 天退热，数日后再次高热并出现眼鼻脓性分泌物、咳嗽、呕吐腹泻；约半数病例出现**神经症状**（抽搐、共济失调、咀嚼肌阵挛），一旦出现神经症状预后极差。幼犬致死率可高达 80%。<span class="marginnote">犬瘟的「双相热」是个教科书级识别要点：很多饲主在第一次退烧后以为「好了」，放松警惕，结果第二次发热直接把病程推向重症。识别双相热，需要的就是上一节教的<strong>连续体温记录</strong>。</span>

**犬细小病毒病（CPV）**：经粪口传播，有两个型：**肠炎型**以剧烈呕吐、腹泻转血便（番茄酱样）为特征，腥臭味极重；**心肌炎型**见于 4–8 周幼犬，可无明显前驱症状突然死亡。细小的关键识别点是**幼犬 + 急性血性腹泻 + 白细胞骤降**。

**传染性肝炎（CAV-1）**：犬腺病毒 1 型，发热、腹痛、肝损伤，约 20% 病例出现特征性**「蓝眼」**（角膜水肿）——恢复期可自行消退。

**犬窝咳（犬传染性气管支气管炎）**：多病原复合感染（犬副流感病毒 + 博代氏菌等），以**干咳、咳后像要呕出东西**为特征，精神状态与食欲通常正常，多为自限性；但幼犬、老年犬可能继发肺炎。属于「症状吓人、预后较好」的一类。

## 3 猫常见传染病：猫瘟、猫杯状、猫疱疹与猫艾滋

**猫瘟（FPV，猫泛白细胞减少症）**：经粪口/接触传播，高热、呕吐、脱水、**白细胞显著下降**（名字即来源），幼猫致死率极高。是猫最核心的必打疫苗靶标。

**猫杯状病毒（FCV）**：**口腔溃疡与舌面水疱**是标志症状，伴打喷嚏、流涎、发热；部分毒株引起跛行。以支持治疗为主，多数可恢复，但口腔溃疡疼痛剧烈，需保证进食（可喂软食）。

**猫疱疹病毒（FHV-1）**：即猫鼻支，**结膜炎、打喷嚏、浆液性鼻分泌物**为特征，角膜溃疡是严重并发症。猫疱疹病毒**终身携带**，应激时可复发——这就是「猫一换环境就打喷嚏流眼泪」的常见原因。<span class="marginnote">猫疱疹与杯状的复发机制是「应激—复发」循环，与人类单纯疱疹病毒同源同机理。管理的关键不是追求「彻底清除」（做不到），而是<strong>降低应激 + 及时干预复发</strong>——这与第3篇行为管理里的环境丰容直接相关。</span>

**猫白血病（FeLV）与猫艾滋（FIV）**：都属于免疫缺陷类。FeLV 经唾液/亲密接触传播（舔舐、共用食盆），可致免疫抑制、淋巴瘤与再生障碍性贫血；FIV 主要经**咬伤**传播，户外打架的公猫高危。两者都无治愈手段，管理核心是**定期体检、营养支持、减少继发感染**。

**猫传染性腹膜炎（FIP）**：由猫冠状病毒（FCoV）在体内突变而来，分**湿性**（腹腔/胸腔积液、腹围增大）与**干性**（肉芽肿、神经症状）。多猫家庭、应激、幼猫高发。过去近乎绝症，近年已有获批的抗病毒药物，但仍是需要专业兽医全程管理的重病。

## 4 核心对比表：一眼分清单猫三病

猫的呼吸道症状最容易混淆，一张对比表帮你快速鉴别：

**核心对比表（纯概念主题，以对比表替代公式解析）：**

| 症状 | 猫瘟 FPV | 猫杯状 FCV | 猫疱疹 FHV-1 |
| --- | --- | --- | --- |
| 发热 | 高热明显 | 轻中度 | 轻中度 |
| 呕吐腹泻 | 剧烈 | 少见 | 少见 |
| 口腔溃疡 | 无 | **有（标志）** | 偶见 |
| 眼结膜炎 | 无 | 轻 | **重（标志）** |
| 白细胞 | **显著下降** | 正常或略降 | 正常 |
| 关键防法 | 疫苗 | 疫苗 + 环境消毒 | 疫苗 + 降低应激 |

犬侧也有类似的「三病鉴别」：犬瘟（双相热 + 神经症状）、细小（血便 + 白细胞降）、窝咳（干咳 + 精神好）。**识别时先问三个问题**：是否免疫完全？年龄多大？症状是「全身性」（发热、精神差）还是「局部性」（咳、喷嚏但精神好）？全身性 + 未免疫 = 高度警惕重症传染病。

## 5 公式解析：基本再生数 R₀ 与「为什么疫苗要覆盖率」

传染病为何能在群体里大流行，用流行病学的基本再生数可以定量理解：

$$
R_0 = \beta \times D
$$

- **$R_0$**：基本再生数——在无免疫群体里，一个感染者平均能传染几个易感者。
- **$\beta$**：有效传播速率——单位时间内每个感染者成功传染的易感者数量，取决于接触频率与每接触的感染概率。
- **$D$**：传染期长度——感染者能够排出病原的天数。

分三步拆解：

- **第一步，看 $R_0$ 的判据**：$R_0 > 1$，传染病在群体中扩散；$R_0 < 1$，扩散自然消退。犬瘟、犬细小在未免疫幼犬群体中 $R_0$ 明显大于 1，所以一窝里只要有一只发病，很快全窝中招。
- **第二步，找高 $R_0$ 的来源**：犬瘟靠气溶胶（接触频繁、$\beta$ 高）、细小靠病毒环境存活久（相当于 $D$ 被环境延长）——两者都推高 $R_0$。
- **第三步，回到疫苗**：疫苗降低的是群体里的「易感者比例」，当易感者足够少，即使 $R_0 > 1$ 也无法扩散（有效再生数 $R_e < 1$）。这就是**群体免疫（herd immunity）**的本质——每一针疫苗，都在给整个宠物群体「降挡」。

这个公式也解释了为什么「我家狗不出门，不打了」的想法危险：疫苗保护的不仅是自家个体，还有它接触到的每一只幼犬、每一只流浪动物——**免疫是利他行为**。<span class="marginnote">$R_0$ 在这里是简化表达：真实流行病学里 $R_0$ 由接触矩阵与世代间隔决定。但这个「$\beta \times D$」的直觉——传播越快、传染期越长、越危险——已经足够指导日常决策，也是第二级《流行病学》会严格展开的起点。</span>

## 6 术语速查表

**传染病防控常用术语（纯概念补充）：**

| 术语 | 含义 |
| --- | --- |
| 传染源 | 排出病原的感染动物，防控第一环是隔离病宠 |
| 传播途径 | 病原从传染源到易感动物的通路，如气溶胶、粪口、媒介 |
| 易感动物 | 未免疫、无抵抗力的个体，疫苗降低的正是这一比例 |
| 双相热 | 发热—退热—再发热的病程，犬瘟的标志性表现 |
| 犬细小 | 幼犬急性血性腹泻+白细胞骤降，环境抵抗力极强 |
| 犬窝咳 | 多病原引起的干咳，精神状态通常正常、预后较好 |
| 猫瘟 FPV | 猫泛白细胞减少症，高热呕吐+白细胞显著下降 |
| 猫杯状 FCV | 猫呼吸道病毒，标志症状是口腔溃疡与舌面水疱 |
| 猫疱疹 FHV-1 | 猫鼻支，结膜炎为主，终身携带、应激复发 |
| FeLV / FIV | 猫白血病与猫艾滋，免疫缺陷类，无治愈手段 |
| FIP | 猫传染性腹膜炎，冠状病毒突变所致，分湿性与干性 |
| 基本再生数 R₀ | 无免疫群体中一个感染者平均传染的易感者数 |
| 群体免疫 | 当易感者比例足够低，传染链自然中断的群体保护状态 |

**常见误区：**

- 病宠痊愈后家里就安全——不对，细小、猫瘟病毒在环境中存活极久，需含氯消毒剂彻底消杀。
- 只要精神好就不是大病——不对，传染病早期可能只有发热或食欲下降。
- 犬猫疫苗通用——不对，犬猫疫苗种类完全不同，不能互用。
- 打一次疫苗终身免疫——不对，需按程序加强，且疫苗有效率非 100%。
- 驱虫能替代疫苗——不对，疫苗防病毒、驱虫防寄生虫，两套防线缺一不可。

## 7 小结

- 传染病传播靠**三要素**，防控 = 断三环；环境消毒（尤其含氯消毒剂）是细小/猫瘟等强环境抵抗力病毒的关键。
- 犬侧重点识别：**犬瘟双相热 + 神经症状、细小血便 + 白细胞骤降、窝咳干咳但精神好**。
- 猫侧用对比表鉴别：**猫瘟（呕吐+白细胞降）、猫杯状（口腔溃疡）、猫疱疹（结膜炎+应激复发）**。
- 免疫缺陷病（FeLV/FIV）无治愈手段，管理核心是体检、营养与减少继发感染。
- 公式解析 $R_0 = \beta \times D$：理解群体免疫，疫苗接种是**利他**的公共卫生活动。
