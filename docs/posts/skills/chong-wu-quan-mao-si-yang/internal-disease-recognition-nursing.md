## 为什么从内科疾病开始

疫苗、驱虫、皮肤与口腔护理管住了「可预防」的那部分，但疾病仍会到来——呕吐、腹泻、尿频、消瘦，这些内科症状占宠物门诊量的一半以上。内科病的特点是**病因藏在体内**，看不见摸不着，早期表现又往往只是「精神差一点」「吃得慢一点」，极容易被归为「矫情」。<span class="marginnote">内科识别需要的是<strong>模式匹配</strong>能力：把「多饮多尿」匹配到肾/内分泌，「咳嗽夜重」匹配到心，「进食惨叫」匹配到口腔——这正是「从极限到大模型」主线里训练的<strong>从特征到假设</strong>的推理，只是特征换成了体征。</span>

这一节属于《宠物健康护理员职业技能标准》中级技能，目标不是把饲主培养成医生，而是建立「**认得类型 → 会做基础护理 → 知道何时必须就医**」的三级判断力，重点覆盖消化、泌尿、心肺与内分泌四大系统。

## 1 消化系统：呕吐、腹泻与胰腺炎

**呕吐（vomiting）与反流（regurgitation）必须先分清**：呕吐是主动过程，呕吐前有恶心前驱（流涎、干呕、不安），吐出的是部分消化的食糜伴黄绿色胆汁；反流是被动过程，食物刚吃下、未经消化直接「掉」出来，无前驱动作。反流指向食道问题（巨食道、异物），呕吐指向胃与肠道——两者的护理方向完全不同，这是兽医问诊第一问。

**急性胃肠炎**：呕吐 + 腹泻，病因多为饮食不当、换粮过急、应激、异物刺激。护理原则：**短时禁食不禁水**（6–12 小时让胃肠道休息）、之后少量多次喂易消化食物（白水鸡胸、处方肠胃粮）、监测脱水状态。多数 1–3 天自愈，但「呕吐超过 24 小时」「腹泻带血」「幼崽/老年个体」「伴发热精神差」任一情况都应就医——**幼犬细小、猫瘟的首发症状也是呕吐腹泻**，未免疫个体必须优先排查传染病。

**胰腺炎（pancreatitis）**：剧烈腹痛（犬表现为「前肢撑地、弓背祈祷姿势」）、持续呕吐、发热。**高脂肪饮食是头号诱因**——过节喂一块肥肉、偷吃剩菜都可能引爆。治疗需住院禁食 + 静脉输液 + 镇痛，护理重点是**终身低脂饮食与「人食绝对不给」**。

**异物与肠梗阻**：反复呕吐 + 食欲废绝 + 无大便，要高度怀疑异物（骨头、玩具、线绳）。线状异物尤其危险（可致肠套叠、穿孔），**发现猫狗吞线，千万别往外拽**——线可能已在体内牵拉损伤肠壁。影像学（X 光/超声）确诊，多需手术。

## 2 泌尿系统：从尿路感染到慢性肾病

**下泌尿道疾病（犬猫通用）**：尿频、血尿、尿淋漓、乱尿（在砂盆外排尿是疼痛信号而非「报复」）。**猫下泌尿道综合征（FLUTD）**是猫侧急诊之王——尤其**公猫尿闭**（尿道堵塞、完全尿不出）：蹲厕频繁但无尿、痛苦嚎叫、腹部胀大，**24–48 小时内可因尿毒症与膀胱破裂死亡，属一线急诊**。<span class="marginnote">公猫尿道窄细，结晶或栓子极易堵塞。识别尿闭只需记住一句话：<strong>猫进了砂盆蹲了很久却一滴没尿，就是急症</strong>。日常预防靠充足饮水（湿粮、流动水）、低应激环境与合适的猫砂——这又与第3篇《猫咪行为管理与环境丰容》的环境设置互为表里。</span>

**慢性肾病（CKD）**：**猫的高发老年病**，犬也常见。早期表现是**多饮多尿（PU/PD）**、食欲减退、消瘦、被毛粗乱，晚期出现尿毒症性口臭（氨味）、呕吐、贫血。CKD 不可逆，管理核心是「分期治疗 + 减慢进展」：肾脏处方粮（低磷低蛋白）、充足饮水、定期复查肌酐与 SDMA（更灵敏的肾指标）、控制血压与蛋白尿。

**膀胱结石**：尿频、血尿、反复泌尿感染。结石成分不同（鸟粪石、草酸钙）对策不同——**鸟粪石可尝试处方粮溶解，草酸钙必须手术**，所以「先分析成分再决定」比盲目换粮重要。影像学（超声）可确诊。

## 3 呼吸与心血管：咳嗽与心衰

**犬心衰（最常见为二尖瓣退行性病变）**：好发于小型老年犬（如贵宾、吉娃娃、博美）。特征信号是**夜间或凌晨咳嗽加重、运动不耐受、呼吸急促**——早期咳嗽容易被误当「感冒/支气管炎」，但心源性咳嗽的要点是**躺下时加重、坐起时缓解**，且常伴呼吸次数上升。<span class="marginnote">一个可在家执行的筛查：宠物安静睡眠时数<strong>每分钟呼吸次数</strong>，连续记录——正常 < 30 次/分；若睡眠呼吸 > 35 次/分且持续升高，提示肺水肿可能，需立即就医。这就是上一节《犬猫健康状态日常评估》教的「记录趋势」在心脏病上的具体应用。</span>

**猫肥厚型心肌病（HCM）**：猫最常见的原发性心脏病，**早期常无症状**，首次表现可能就是血栓栓塞——**后肢突然瘫痪、脚垫冰凉、惨叫**，属急诊。布偶猫、缅因猫等品种高发，建议定期心脏超声筛查。护理核心：限制应激（应激可诱发肺水肿与血栓）、控制体重、遵医嘱用药。

**猫哮喘与支气管炎**：阵发性咳嗽、呼气性呼吸困难（「咳完像要吐毛球」但吐不出）。诱因多样（尘螨、烟雾、香水），管理是避因 + 必要时吸入激素，**绝对禁烟**（二手烟对猫哮喘是直接加重因素）。

## 4 内分泌：糖尿病与甲状腺疾病

**犬糖尿病**：最经典表现是**「三多一少」**——多饮、多尿、多食、体重下降，**犬还易并发白内障**（高血糖致晶状体混浊，可短期失明）。治疗以**胰岛素注射**为主，护理核心是**定时定量喂食 + 定时注射 + 规律血糖监测**（曲线测定），「先吃饭后打针」的顺序不可颠倒。未经治疗的重症会进展为**酮症酸中毒**（呕吐、脱水、呼吸深快），属急症。

**猫糖尿病**：同样「三多一少」，但部分猫（尤其肥胖猫）通过**减重 + 低碳水饮食**可实现「临床缓解」甚至停药——「先生活方式干预」在猫比犬更有效。

**犬甲状腺功能减退（甲减）**：**嗜睡、怕冷、肥胖、对称性脱毛、皮肤变黑**是典型组合，中老年犬高发（金毛、拉布拉多、杜宾易感）。治疗为口服甲状腺素终身补充，用药后需定期复查血药浓度调整剂量——**护理要点是「规律服药 + 定期复查」，不能自行停药**。

**猫甲状腺功能亢进（甲亢）**：中老年猫高发，表现**与甲减相反**：消瘦、食欲大增、躁动、呕吐、被毛粗乱。治疗有口服药、碘饮食、放射性碘、手术多选项，护理核心是**控制体重下降与心血管负担**，遵医嘱复查甲状腺素水平。<span class="marginnote">「一只猫吃得越来越多却越来越瘦」是甲亢的经典画像，也可见于糖尿病与肠道肿瘤——三者鉴别要靠血液检查。老年猫一旦出现「多食消瘦」，不要高兴地以为「胃口好」，要查血。</span>

## 5 公式解析：脱水补液量的估算

多数内科病（呕吐腹泻、肾病、糖尿病）都会遭遇脱水，而补液量的计算是护理员最该掌握的定量技能之一：

$$
V_{补} = W \times p \times 1000
$$

- **$V_{补}$**：需要补充的液体量（mL）。
- **$W$**：当前体重（kg）。
- **$p$**：脱水百分比（以小数表示，如 5% 脱水写 0.05）。
- **$1000$**：把升换算成毫升。

分三步拆解：

- **第一步，估脱水率**：用上一节的皮肤回弹试验——回弹 2–3 秒约脱水 5%，> 3 秒约 8%，结合牙龈干粘综合判断。
- **第二步，代公式**：一只 10 kg 的犬，皮肤回弹 2.5 秒（$p = 0.05$）：$V_{补} = 10 \times 0.05 \times 1000 = 500$ mL。
- **第三步，加上维持量**：补液量之外，动物每天还有「维持需水量」（见日常评估节的 $V = k \times W$），临床补液通常是「补充缺失量 + 每日维持量」合计，且**静脉补液要分速滴注**——一次性快速推注会造成心脏负荷与肺水肿。

**护理红线**：这个公式是**评估与就医沟通的工具**，不是居家静脉补液的许可——中重度脱水必须由兽医静脉补液；居家能做的是「口服补液」（少量多次喂电解质水或处方口服补液盐），且**呕吐持续时口服补液会加重呕吐**，此时应禁食水并就医。判断补液有效的标志：**尿量恢复、皮肤回弹 < 2 秒、精神好转**。

## 6 术语速查表

**内科疾病常用术语（纯概念补充）：**

| 术语 | 含义 |
| --- | --- |
| 呕吐 | 主动的、有恶心前驱的胃内容物排出 |
| 反流 | 被动的、无前驱的未消化食物吐出，提示食道问题 |
| 急性胃肠炎 | 呕吐+腹泻的短期消化道炎症，多数自限 |
| 胰腺炎 | 胰腺炎症，剧烈腹痛，高脂饮食是头号诱因 |
| 肠梗阻 | 异物堵塞肠道，反复呕吐+食欲废绝+无大便 |
| FLUTD | 猫下泌尿道综合征，尿频血尿乱尿的总称 |
| 尿闭 | 尿道堵塞完全尿不出，公猫急诊，24–48 小时致命 |
| 慢性肾病 CKD | 猫高发老年病，不可逆，靠处方粮与复查延缓 |
| 肌酐 | 肾功能的血液指标，犬 0.5–1.5、猫 0.8–2.4 mg/dL |
| SDMA | 比肌酐更早反映肾功能下降的指标，< 14 μg/dL |
| 多饮多尿 PU/PD | 饮水与排尿同时增多，指向肾/内分泌问题 |
| 二尖瓣退行 | 小型老年犬最常见的心脏病，夜间咳重是信号 |
| HCM | 猫肥厚型心肌病，可首发后肢瘫痪血栓 |
| 三多一少 | 多饮多尿多食+体重下降，糖尿病的经典画像 |
| 酮症酸中毒 | 糖尿病严重并发症，呕吐脱水呼吸深快，属急症 |
| 甲减 | 甲状腺功能减退，犬表现为嗜睡肥胖脱毛 |
| 甲亢 | 甲状腺功能亢进，猫表现为消瘦多食躁动 |
| 口服补液盐 | 含电解质与糖的口服补水制剂，呕吐持续时禁用 |

**常见误区：**

- 呕吐就禁食到它自己好——不对，超过 24 小时或带血必须就医。
- 公猫尿闭等它自己尿出来——不对，尿闭是急症，24–48 小时内可致命。
- 猫应激血糖高就是糖尿病——不对，需结合症状与多次测量确诊。
- 先打针后吃饭没关系——不对，糖尿病注射顺序「先饭后针」不可颠倒。
- 老年猫能吃能喝就是健康——不对，多食消瘦要警惕甲亢与糖尿病。
- 补液公式可以居家静脉输液——不对，静脉补液必须由兽医操作。
- 肾病就只能低蛋白——不对，需按肾功能分期，健康老年动物要适量优质蛋白。
- 一次化验正常就不用再查——不对，慢性病需定期复查对比趋势。

## 7 小结

- 内科识别是**模式匹配**：先分呕吐/反流、再分急性/慢性、最后定位系统。
- 消化系统：**呕吐超 24 小时、血便、未免疫幼崽**要就医；胰腺炎终身低脂，异物线状物勿外拽。
- 泌尿系统：**公猫尿闭是急诊**；猫 CKD 靠低磷肾处方粮 + 足量饮水 + 定期复查 SDMA。
- 心肺：犬心衰「夜间咳重、睡时呼吸 > 35 次/分」要警惕；猫 HCM 首发可能是后肢瘫痪血栓。
- 内分泌：**「三多一少」指向糖尿病**；犬甲减（胖+脱毛）、猫甲亢（瘦+多食）是老年动物两大镜像。
- 公式解析补液 $V_{补} = W \times p \times 1000$：评估工具而非居家输液许可，中重度脱水必须就医。

在下一节，我们转向**外科护理**——当疾病需要手术介入时，伤口怎么处理、术后怎么照顾、拆线与引流如何观察，是高级护理员要掌握的硬技能。
