## 为什么从故障诊断讲起

机器早晚会出故障，区别只在于：**你在故障「萌芽」时发现它，还是等它「趴窝」在田里才面对它。** 会诊断故障的机手，能从异响、烟色、仪表异常里提前读出问题，在农忙时节保住机器的作业时间；不会诊断的机手，只能等机器彻底坏了再花钱请人修。故障诊断不是维修工的专利，而是每个驾驶员应有的基本功。<span class="marginnote">故障诊断的思维，与学到的原理直接挂钩：<strong>懂原理，才能从「现象」倒推「原因」</strong>——冒黑烟要想到「燃烧不完全」，想燃烧就要查喷油与进气，一步步从原理往下推，诊断就不会乱。</span>

本节按「**诊断思路 → 发动机故障 → 底盘故障 → 作业装置故障 → 排除原则**」组织。

## 1 故障诊断的基本思路

诊断故障，不是「拆开看看」，而是有一套**从现象到原因**的推理：

**第一步，弄清现象**：故障表现在哪——**异响、振动、冒烟、跑偏、掉转速、漏油漏水、作业质量差**？把现象描述准确，诊断就成功了一半。

**第二步，结合原理与工况**：想这个现象在什么工况下发生（冷机/热机、轻载/重载、刚起动/作业中），联系部件工作原理，列出可能原因。

**第三步，先简后繁、先外后内**：先查**最容易、最常见**的原因（油、电、滤芯、皮带、螺栓），再查复杂的（泵、阀、内部件）。多数故障是「小事」——滤芯堵、皮带松、螺栓脱。<span class="marginnote">诊断的「先外后内」铁律：<strong>先查看得见的（油位、滤芯、皮带、接线、紧固件），再查看不见的（内部磨损、密封件）</strong>。翻山越岭拆到发动机内部，结果发现只是空滤堵了——这种事在维修里屡见不鲜。</span>

**第四步，验证**：按推测调整/检修后**试运转验证**，确认故障排除；一次只动一项，别「乱枪打鸟」。

**用好仪表与感觉**：听（异响）、看（烟色、泄漏、松动）、摸（温度、振动）、闻（焦味、油味），四感并用，加上仪表读数。

## 2 发动机常见故障

发动机故障是农机故障的「重头」，按现象归类：

**起动困难或不能起动**：原因集中在**油、电、压**三方面——缺油（油箱没油、油路进气、滤芯堵）、电弱（蓄电池亏电、起动机无力、接线松）、压缩不足（气缸漏气、气门间隙不对）。诊断顺序：**查油位油路 → 查蓄电池起动 → 查预热与压缩**。<span class="marginnote">起动困难的排查顺序要记牢：<strong>先油后电再压缩</strong>——先看油箱与油路（最常见）、再看电（蓄电池、起动机）、最后才怀疑压缩与机械。多数「起不来」就是没油或没电。</span>

**冒黑烟**：燃烧不完全——喷油量过大、喷油压力不当、喷油器雾化差、空气滤芯堵塞、超负荷。诊断：先清/换空滤，再查喷油器与供油量。<span class="marginnote">烟色是发动机的「黑匣子」：<strong>冒黑烟是燃烧不完全（进气不足、喷油过多、超载），冒蓝烟是烧机油（油环磨损、气门油封漏），冒白烟是温度低或柴油含水</strong>——看到烟色，先对号入座，再动手查。</span>

**冒蓝烟**：烧机油——机油油面过高、活塞环磨损、气门油封失效。检查油位与机油消耗，必要时检修活塞环与油封。

**冒白烟**：温度不足或柴油中有水——冷机时轻微白烟正常，持续白烟查预热、喷油与油中含水。

**功率不足、掉转速**：供油不畅（滤芯堵、油路进气）、进气不足（空滤堵）、喷油压力低、压缩不足、超负荷。结合冒黑烟一起查。

**水温过高（开锅）**：散热不良——散热器堵塞、风扇皮带松、冷却液不足、节温器卡死。水温高要**立即减负荷或停机**，别硬顶。

**机油压力过低**：机油不足、油泵故障、滤芯堵、轴承磨损。**油压掉零立即停机**，这是保命的警告。

## 3 底盘常见故障

**离合器打滑**：起步无力、上坡没劲、离合器发热有焦味——离合器片磨损、调整不当、摩擦片沾油。对策：调整、清洗或更换摩擦片。

**离合器分离不彻底**：挂挡打齿、起步窜车——自由行程过大、压盘故障。调离合器踏板自由行程。

**变速器挂挡困难/脱挡**：挂挡费力、行驶中自动脱挡——同步器磨损、换挡机构调整不当、齿轮磨损。先调整，再检修。

**制动失灵/偏刹**：制动距离变长、踩刹跑偏——制动液不足、制动器磨损、左右制动力不平衡。**制动故障必须先修再用**。

**转向沉重/旷量大**：转向费力或方向盘虚位大——液压转向压力不足、转向机磨损、拉杆球头松旷。转向故障同样必须先修再用。

**跑偏**：行驶自动偏向一侧——左右轮胎气压不等、轮距调整不当、制动器单边发咬。查轮胎、查制动、查悬挂。<span class="marginnote">「跑偏」三查的顺序：<strong>一查轮胎气压（最常见）、二查制动（单边发咬）、三查转向悬挂</strong>。多数跑偏，放个气、补个胎就解决了——别急着怀疑「车架弯了」。</span>

## 4 作业装置常见故障（收割机）

**割台故障**：割刀不切割（刀片钝、护刃器变形、驱动机构松动）、割台抬不起（液压油不足、油泵故障）、拨禾轮不转（皮带松、链条断）。<span class="marginnote">割台的常见病多出在「钝与松」：<strong>割刀钝了割不断、拨禾轮皮带松了不转、液压油少了抬不起</strong>——先查这三样，再往深处找。</span>

**滚筒堵塞/卡阻**：喂入过大、作物过湿、滚筒转速不足、皮带打滑。对策：**停机清堵**、查喂入与传动、调整滚筒间隙。

**脱粒不净**：排草夹带籽粒——滚筒转速不足、凹板间隙过大、喂入不均。提转速、缩间隙、稳喂入。

**破碎率高**：滚筒转速过高、间隙过小。降转速、加间隙。

**清选不良**：粮箱含杂高（风量不足、筛孔小、筛堵）或清选损失大（风量过大、筛孔大）。调风量、调筛、清筛面。

**输送堵塞**：过桥、搅龙缠草堵塞——喂入不均、缠草。停机清理，调整喂入。

## 5 核心要点：故障「现象—原因—排除」速查表

把高频故障收成一张诊断速查表：

| 现象 | 常见原因 | 排除步骤 |
| --- | --- | --- |
| 起动困难 | 缺油、电弱、压缩不足 | 油→电→压缩 |
| 冒黑烟 | 空滤堵、喷油多、超载 | 清滤芯→查喷油→减载 |
| 冒蓝烟 | 烧机油（油面高、环磨损） | 查油面→查环 |
| 水温高 | 散热堵、皮带松、缺水 | 清散热器→紧皮带→补水 |
| 油压低 | 缺油、滤芯堵、磨损 | 补油→换滤芯→检修 |
| 离合器打滑 | 片磨损、调整不当 | 调整→清洗→更换 |
| 制动失灵 | 油不足、片磨损、偏刹 | 必须修好再用 |
| 脱粒不净 | 转速低、间隙大 | 提转速→缩间隙 |
| 破碎率高 | 转速高、间隙小 | 降转速→加间隙 |
| 清选含杂 | 风小、筛堵 | 加风→清筛 |

这张表的规律：**现象 → 原因 → 排除，是一条「从果到因再回到果」的闭环。** 会背这张表是起点，会用推理方法才是真功夫。

## 6 故障排除的原则与安全

排除故障时，有几条必须守住的原则与安全底线：

**安全第一**：检修、清理**必须停机熄火、切断动力、确认部件停转**；液压系统检修要**卸压**（高压液压油喷出会刺伤人）；架高机体要**支撑牢靠**。

**按章操作**：按说明书拆装，**不盲目乱拆**；拆下的零件按序摆放，安装时原样装回。

**一次只动一项**：同时改多项，问题解决不知道是谁的功劳、没解决不知道是谁的过错——**一项一项试，才能积累出真经验**。<span class="marginnote">「一次只动一项」既是诊断方法，也是学习之道：<strong>每动一项，试一次机，观察变化</strong>——这样修一次，你就真正懂了一台机器。乱枪打鸟式的瞎调，永远学不会诊断。</span>

**备件与记录**：常用易损件（滤芯、皮带、刀片、灯泡、保险）随车备着；**维修记录**（何时、何故、换了什么）记入台账，为下次诊断提供线索。

**求助时机**：故障超出自身能力（涉及精密部件、内部结构、安全件）时，**及时联系专业人员**，不要硬拆硬修——拆坏了，小修变大修。

## 7 小结

- 诊断思路四步：**弄清现象 → 结合原理工况 → 先外后内先简后繁 → 验证排除**。
- 发动机故障看**烟色与仪表**：黑烟查燃烧、蓝烟查机油、白烟查温度与水；油压掉零立即停机。
- 底盘故障看**跑偏与失灵**：查轮胎→制动→转向；制动转向必须先修再用。
- 作业装置故障看**质量与声音**：脱粒不净、破碎率高、清选含杂，各对应滚筒、间隙、风量的调整。
- 排除原则：**停机断电卸压、按章拆装、一次只动一项、及时求助**。
- 用好「**听、看、摸、闻 + 仪表**」四感一表，故障在萌芽就发现它。
