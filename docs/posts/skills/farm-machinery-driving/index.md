# 农机驾驶与田间作业（拖拉机/联合收割机）

农业机械化是粮食安全与乡村振兴的重要支撑，拖拉机与联合收割机的田间作业技能是国家职业技能标准认定的专门工种。以《拖拉机驾驶员》《联合收割机驾驶员》国家职业技能标准为纲，结合 GB 16151《农业机械运行安全技术条件》与国务院《农业机械安全监督管理条例》，系统重建从农机基础、驾驶操作到田间作业、安全维护的完整技能与安全规范体系。学完这些章节，就写完了农机驾驶与田间作业的全部内容。

## 对标教材

- 《拖拉机驾驶员》《联合收割机驾驶员》国家职业技能标准
- GB 16151《农业机械运行安全技术条件》
- 国务院《农业机械安全监督管理条例》
