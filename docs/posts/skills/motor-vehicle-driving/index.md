# 机动车驾驶（驾驶技能与道路交通安全）

以人民交通出版社《机动车驾驶培训教材》为纲，结合公安部令第162号《机动车驾驶证申领和使用规定》与《中华人民共和国道路交通安全法》，系统覆盖从交通法规、车辆构造到场地技能、道路驾驶与应急处置的完整驾驶知识与技能体系。学完这些章节，就写完了从学车考证到安全上路所需的全部内容。
