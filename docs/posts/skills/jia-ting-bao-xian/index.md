# 家庭保险规划与风险管理

家庭保险规划与风险管理是一门把保险原理、人身/健康/财产保险配置与投保理赔实务落到家庭场景的应用学科。它以《保险原理与实务》、银保监会《人身保险销售行为管理办法》和《家庭风险管理》为纲，学完这些章节，就能识别家庭风险缺口、设计保障方案并走通投保理赔全流程。

## 对标教材

- 《保险原理与实务》
- 银保监会《人身保险销售行为管理办法》
- 《家庭风险管理》
