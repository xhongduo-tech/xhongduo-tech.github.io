# 遗产继承与家庭财富传承

遗产继承与家庭财富传承是一门围绕遗嘱、法定继承、信托与保险传承等工具，研究家庭财富代际转移规则的法律实务学科。它以《中华人民共和国民法典》继承编、《中华人民共和国信托法》和《中华人民共和国保险法》为纲，学完这些章节，就能厘清继承顺序、起草有效遗嘱，并借助信托与人寿保险完成家庭财富的有序传承与风险隔离。

## 对标教材

- 《中华人民共和国民法典》继承编
- 《中华人民共和国信托法》
- 《中华人民共和国保险法》
