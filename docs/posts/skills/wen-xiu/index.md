# 纹绣

半永久纹绣是以针刺将色料植入皮肤浅层、塑造自然精致眉眼唇妆容的美容技术，涵盖纹眉、纹唇、美瞳线与全套操作规范，既可自我精进也是可职业化的服务型技能。学完这些章节，就写完了纹绣理论、眉唇实操、操作规范与纹绣师职业的全部内容。
