## 为什么第一种技法选 Build

调制技法按「是否借助摇壶/搅拌杯」分两大类，**直接注入法（Build）**是最基础也最「露怯」的一类——它不用摇壶、不用搅拌杯，直接在出品杯中依次注入原料即可。金汤力、螺丝锥子、自由古巴、龙舌兰日出、莫斯科骡子……吧台出杯量最大的长饮几乎全是 Build。它看似简单，实则藏着「加冰顺序、层序、气泡管理」三道看不见的门槛。把 Build 学透，你就理解了「不借助外力，靠秩序与时机调酒」的全部逻辑。

## 1 什么是直接注入法

**直接注入法（build / straight build）**：把配方中的各原料**直接加入出品杯中**，在杯内完成混合的调制技法。与摇和、搅拌不同，Build 不做杯外混合，依赖「倒酒的顺序、冰块与搅拌的次数」完成匀化。

Build 的适用场景有三类：

- **高球长饮（highball）**：基酒 + 大量气泡水/果汁 + 冰，如金汤力、螺丝锥子、自由古巴。
- **加冰短饮（on the rocks）**：基酒直接加冰，如威士忌加冰、白俄罗斯。
- **直接兑和饮品（direct mix）**：两种以上原料直接兑和，如苏格兰苏打、金巴利苏打。

**核心要点：Build 的「混合」靠的是「重力分层 + 冰块搅动 + 搅拌次数」**，而不是外力旋转。这意味着**注入顺序**成了最重要的变量——先倒什么、后倒什么，直接决定混合是否均匀、气泡是否保持。

## 2 加冰顺序与稀释控制

Build 的第一道门槛是**冰**。什么时候加冰、加多少，决定了稀释度与口感：

- **先加冰，后注酒**：冰先入杯，再倒基酒与气泡水。冰在酒液中缓慢融化，提供「渐进稀释」——先浓后淡，口感随饮用时间推移，这是长饮的标准做法。
- **后加冰**：先把酒液混合再补冰，混合更均匀但冰会快速融化造成过度稀释——仅用于个别需要「先混后冰」的配方。
- **冰量**：标准高球杯约加满 2/3 的冰。冰太少稀释过快、冰太多饮品「冰冷但寡淡」——**冰的本质是「稀释的定时器」**，控制它就是在控制风味随时间的变化曲线。<span class="marginnote">这与第 3 篇搅拌法、摇和法里「冰是冷却+稀释双重角色」的论断一脉相承：Build 的长饮靠「杯中冰」持续稀释，短饮则靠摇/搅一次性稀释到目标水量。三种技法的差异，本质是「稀释发生的时机与烈度」的差异。</span>

**高杯先冰、汤力后倒、轻搅一次**——这是金汤力的 Build 铁律：冰块先入，汤力水最后倒，用吧勺**顺着杯壁轻搅一圈**让酒与汤力水初步混合，又不过度扰动气泡。**搅拌次数是 Build 里的隐藏变量**：搅太多，气泡全跑；搅太少，酒水未匀——「一次」是经验值。

## 3 层序：酒在下、汽水在上

Build 的注入顺序有普遍规律：**基酒先入杯，气泡水/果汁后倒入**。原因有二：

**混合效率**：先倒基酒（密度较大），再倒气泡水，液体自然下沉翻转，轻微的自重力搅拌帮助混合。
**气泡保持**：气泡水后倒，气泡在杯中停留的时间最短、受到的扰动最小，出品时气泡最足。

但也有反例——**分层 Build**。白俄罗斯（White Russian）的做法是：先倒伏特加与咖啡利口酒、加冰，**再沿吧勺背缓缓倒入奶油**，让奶油浮在上层形成分明的「黑白分界」。这种「用密度差做视觉分层」的手法，会在第 3 篇《分层法》专门展开。<span class="marginnote">层序的底层逻辑是「密度」：奶油、糖浆等比酒液密度低会浮在上层。Build 与 Layer 的边界就在于此——Build 默认「倒完会自己混匀」，Layer 则刻意「倒完不混、保持分层」。先判断要不要分层，再决定用哪种手法。</span>

## 4 直接注入的三大变体

Build 不是「一招」，而是一个家族，按出品方式分三类：

| 变体 | 做法 | 典型饮品 |
| --- | --- | --- |
| 标准 Build | 杯内依次注入，轻搅 | 金汤力、螺丝锥子、自由古巴 |
| Build + 捣压 | 先捣压水果/薄荷再注入 | 莫吉托（先捣薄荷青柠，再倒朗姆苏打） |
| 分层 Build | 沿吧勺背分层注入 | 白俄罗斯、彩虹酒（B-52） |

<span class="marginnote">莫吉托严格说是「Build + 捣压」的复合技法：先在杯底捣压薄荷与青柠出香，加碎冰，再倒朗姆与糖浆，最后以苏打水补满轻搅。它没有进摇壶——捣压的动作与杯内混合就是它的「混合方式」。这提醒我们：技法分类是工具，配方可以跨类组合。</span>

**辨析｜易错点：** 最常见的 Build 错误是**「先倒汽水再倒酒」**——气泡水先入杯，基酒再倒进去时会把气泡压出来，且酒液浮在表面难以混匀。另一个高频错误是**「过度搅拌」**：把金汤力搅到气泡尽失，整杯「塌」成一碗甜水。**气泡是长饮的生命线，轻搅是底线动作。**

## 5 6 Build 的常见误区与进阶清单
Build 看似简单，却是「错得最多」的技法之一。把常见误区与进阶动作一并收齐：

**Build 六大误区**：

| 误区 | 错误后果 | 正确做法 |
| --- | --- | --- |
| 先倒汽水后倒酒 | 气泡被打散、酒难混匀 | 先酒后汽水 |
| 过度搅拌 | 气泡尽失、整杯「塌」 | 轻搅一圈即止 |
| 冰量不足 | 温度不够、汽水升温发闷 | 冰加至约 2/3 杯 |
| 用温水兑汽水 | 气泡快速逃逸 | 汽水与原料都冰镇 |
| 不冰镇杯子 | 入杯即升温 | 长饮杯提前冰镇或加冰洗杯 |
| 忽略「挤角」 | 青柠角不挤、香气缺失 | 挤油雾后入杯 |

**进阶清单：三件事让 Build 从「能喝」到「好喝」**：

**控制「最后的搅拌」**：金汤力、莫吉托的轻搅，用吧勺「沿杯壁提拉一次」而非「画圈猛搅」——**提拉的目的是把上下层液体「翻」匀，而不是把气泡「搅」走**。
**用「冰的层序」制造口感变化**：先加几块大冰、再加碎冰，让饮品「上层凉得快、下层稀释慢」——这是长饮的「分层稀释」玩法。
**「挤皮」是免费的香气**：柑橘类装饰（青柠角、橙片）在入杯前「拧挤一下」，让油雾喷上杯面——**这是零成本、高回报的香气增量**。

<span class="marginnote">「挤皮」与第 3 篇装饰节的「拧皮条」是同一个动作的不同强度：<strong>皮条是「拧出油雾、皮条入杯」，装饰角是「挤一下、整角入杯」</strong>——目的都是释放柑橘精油。这个动作练熟了，你的长饮会立刻「高级」半档。</span>

**一个自检清单（出品前默念）**：冰够不够？汽水新不新鲜？青柠挤没挤？搅了几下？——**四问过后再送酒**，是 Build 出品稳定的肌肉记忆。

## 6 7 Build 的家庭与商用要点
Build 无论在家还是商用，都有各自的「要点清单」：

**家庭 Build 的四个要点**：

- 用「好的冰」——用纯净水冻冰，避免「冰箱味」。
- 汽水「现开现倒」——开瓶越久气泡越少，这是家庭版最大的提升点。
- 青柠「现挤现投」——瓶装青柠汁会毁了金汤力。
- 轻搅「一次到位」——多搅几下，气泡就没了。

**商用 Build 的三个标准**：

| 要点 | 标准 |
| --- | --- |
| 用量 | 每杯用量酒器，spec 不手抖 |
| 气泡 | 汤力水/苏打现开现用，高峰备足 |
| 出品 | 先冰后酒、汽水后倒、轻搅一次、装饰现做 |

**家庭与商用的共同规律**：Build 的成败九成在「冰、气泡、新鲜」三件事——**家用输在「懒得换新汽水」，商用输在「忙乱中降低标准」**。把这三件事当铁律，Build 就不会翻车。

## 7 7 术语速查：直接注入
Build 相关的术语速查：

| 术语 | 含义 |
| --- | --- |
| Build | 直接注入法（杯内混合） |
| Highball | 高球（烈酒 + 大量气泡水/果汁） |
| On the rocks | 加冰（杯内加冰） |
| Straight up | 滤冰上杯（无冰） |
| Top up | 补满（用气泡水等补至杯口） |
| Garnish | 装饰 |
| Muddle | 捣压（Build + 捣压的复合） |
| Fizz | 菲士（摇和后补苏打） |
| Layer | 分层（密度差堆叠） |

**一句话**：**Build 是「最基础也最考验秩序」的技法**——术语记住「先冰后酒、汽水后倒、轻搅一次」就抓住了它的灵魂。

## 8 小结

- **直接注入法**：原料直接入杯、杯内混合，靠层序、冰块与轻搅完成匀化。
- 适用三类：**高球长饮、加冰短饮、直接兑和**；吧台出杯量最大的长饮多属此类。
- **先冰后酒、汽水后倒、轻搅一次** 是标准动作；搅拌次数是隐藏变量，气泡是生命线。
- 层序的底层逻辑是**密度**：默认混匀 vs 刻意分层，决定了 Build 与 Layer 的分界。
- 三大变体：标准 Build、Build + 捣压（莫吉托）、分层 Build（白俄罗斯）。
