# 调酒与鸡尾酒

以《调酒师国家职业技能标准》的职业能力框架为纲，从六大基酒、调制技法到经典与创意鸡尾酒配方、吧台运营，系统构建调酒与鸡尾酒的专业知识体系。鸡尾酒文化风靡全球，掌握调酒既是实用的职业技能，也是品味与创意表达。

## 对标教材

- 《调酒师国家职业技能标准》
- IBA 国际调酒师协会鸡尾酒手册
- 《经典鸡尾酒大全》
