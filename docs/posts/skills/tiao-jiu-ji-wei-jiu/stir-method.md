## 为什么搅拌是「烈酒系」的御用技法

上一节 Build 讲「杯内混合」，本节进入「杯外混合」的第一种——**搅拌法（Stir）**：把基酒与配料倒进搅拌杯，加冰，用吧勺匀速搅拌，然后滤冰倒出。马天尼、曼哈顿、尼格罗尼——所有「纯烈酒 + 味美思/苦精」的经典短饮几乎都要求 Stir。为什么不用摇？因为**搅拌的物理过程「克制」**：冷却充分而稀释温和、充气极少，保住烈酒的清澈与锋芒。本文讲清搅拌的物理、稀释控制与手法。

## 1 搅拌法的定义与适用

**搅拌法（stir / stirring）**：在搅拌杯中放入冰块，加入配方原料，用长柄吧勺在冰间匀速搅动，通过**冰的接触冷却与融化稀释**完成混合，再用过滤器滤冰倒入出品杯。

搅拌的适用对象高度规律——**只含烈酒与调味料的「纯酒系」配方**：

- 马天尼（金酒 + 干味美思）
- 曼哈顿（威士忌 + 甜味美思 + 苦精）
- 尼格罗尼（金酒 + 金巴利 + 甜味美思）
- 老式（威士忌 + 方糖 + 苦精）
- 萨泽拉克、法国联系等

**为什么纯酒系选 Stir 而不选 Shake？** 答案在「充气」与「稀释」两个物理维度。搅拌只产生极微弱的充气（气泡很少），让酒液**保持清澈透明**；而摇和会把空气打进液体，制造浑浊与泡沫。<span class="marginnote">马天尼若用摇和法（Shaken Martini，即「James Bond 式」），酒液会因充气变得微浊、口感更「水」更冰——这是风味取向，不是错误。但经典 IBA 马天尼标准是 Stir，因为搅拌保留烈酒的「丝滑」与透明。理解这一点，你就能解释为什么电影里 Bond 的「shaken」在专业吧台常被调侃。</span>

## 2 冰处理：搅拌效果的第一变量

搅拌的物理核心是**冰与液体的接触面积与时间**。职业搅拌有严格讲究：

**用大块冰，不用碎冰**：大块冰表面积小，融化慢，能在搅拌的 20–30 秒内提供「渐进而可控」的稀释；碎冰融化太快，30 秒内就会把酒液冲淡。
**冰先入杯「洗杯」**：许多调酒师先用冰在搅拌杯里转一圈（wash），倒掉融化水，再入料搅拌——这去除了冰面的「附着水」，让第一次接触就是干净的冷却。
**搅拌时间**：经验标准约 **20–30 秒**，直到搅拌杯外壁出现明显冷凝水珠（frost）——这是「冰与液体温度已充分交换」的视觉信号。**时间过短则不冷，时间过长则稀释过度**。<span class="marginnote">「杯壁起霜」是搅拌手的经验标尺：霜的出现说明杯内温度已降到冰点附近。更精确的做法是数吧勺转数——常见推荐 30–40 转。无论哪种，目标是一致的：把 70 mL 左右的酒液冷却到 0–5°C，同时让冰融化出约 20% 的水。</span>

**核心要点：搅拌的「目标稀释量」远低于摇和。** 搅拌约稀释最终体积的 15%–25%，摇和约稀释 25%–35%——这是两类技法最本质的差别。

## 3 公式解析：搅拌的稀释量计算

搅拌最重要的可量化参数是**稀释量**——冰融了多少水进入酒液。基本关系：

$$V_{\text{final}} = V_{\text{liquor}} + V_{\text{melt}}$$

其中 $V_{\text{liquor}}$ 是配方原料体积，$V_{\text{melt}}$ 是搅拌中融化的水量，$V_{\text{final}}$ 是滤冰后的成品体积。稀释比例：

$$D = \frac{V_{\text{melt}}}{V_{\text{final}}} \times 100\%$$

以标准**马天尼**为例逐步拆解：

- **第一步，写清原料**：金酒 60 mL + 干味美思 10 mL，即 $V_{\text{liquor}} = 70$ mL。
- **第二步，搅拌后实测成品**：滤冰倒出，成品约 85–90 mL，即 $V_{\text{final}} \approx 87$ mL。
- **第三步，反推稀释量**：$V_{\text{melt}} = 87 - 70 = 17$ mL，稀释比例 $D = 17/87 \approx 19.5\%$。

**这个数字说明了什么？** 搅拌 30 秒，冰只贡献约 17 mL 的水——马天尼的酒精度从混合前的约 37%（第 3 篇算过）进一步降到约 30% vol 出头。**搅拌的意义在于「把酒冷却到近乎冰点、同时几乎不稀释它的烈度」**，这正是烈酒系短饮「冰而烈」的秘密。

换一个视角：若用摇和法，$V_{\text{melt}}$ 常超过 25 mL，稀释比例突破 25%——酒液更水、更淡。**同一个配方，Stir 与 Shake 的成品是两杯酒**，这不是玄学，是水分子的数量差异。

## 4 搅拌手法与出品

正确的搅拌手法强调「稳」而非「快」：

- **握法**：拇指与食指轻夹吧勺螺旋柄上段，让勺子悬在杯中——**靠柄端的螺旋在指间滑动产生旋转，而不是整臂画圈**。
- **轨迹**：吧勺贴杯壁下行，把冰从杯底翻起，让液体在冰间循环——这是「搅拌」与「捣压」的区别，**搅拌不碰冰、只搅液体**。
- **收尾**：搅拌到位后，用**霍桑过滤器**滤冰倒入出品杯；马天尼杯需事先冰镇（用冰水或入冰桶），否则热杯会让成品升温。

**出品细节**：马天尼倒入冰镇的杯，装饰柠檬皮条（拧一下让油雾喷上酒面）或橄榄；曼哈顿装饰酒渍樱桃。**装饰不是点缀，是风味的一笔**——柠檬皮油的清新与曼哈顿樱桃的甜，都是配方设计的一部分。（第 3 篇《装饰物制作》详解。）

**辨析｜易错点：** 搅拌的常见错误是「**把吧勺当捣棒**」——用力压冰、把冰捣碎，反而让碎冰面积暴增、稀释失控；以及「**搅拌后不滤冰**」——直接把冰带入出品杯，马天尼会越喝越淡。搅拌的目标是「混合 + 冷却 + 定量稀释」，不是「把冰弄碎」。

## 5 6 搅拌的进阶：冰球、老式与「搅」的哲学
搅拌法的进阶，从「把酒搅好」走向「把冰搅出学问」：

**冰球（ice ball）与大块冰的搅拌**：老式（Old Fashioned）这类「加冰短饮」，搅拌时杯里是**整块大冰球**而非碎冰——冰球表面积小、融化极慢，能让「威士忌 + 糖 + 苦精」在 15–20 分钟里保持浓度稳定。**对比搅拌杯里的「大块冰」，老式杯里的冰球是「慢释稀释」的终极形态**——它把第 3 篇「冰是稀释定时器」的道理做到极致。

**「搅」的哲学：为什么烈酒系坚持 Stir**：搅拌派调酒师有个著名的信条——「**烈酒该被温柔对待**」。搅拌的温柔体现在三个层面：充气极少（酒体保持清澈）、稀释温和（烈度不被冲垮）、动作克制（不破坏液体的「丝滑」）。**摇和是「打开」液体，搅拌是「抚摸」液体**——同一杯金酒与味美思，Stir 与 Shake 的成品是两种性格，这是第 3 篇反复强调的物理事实。<span class="marginnote">把「搅」与「摇」放上一条光谱：<strong>从最克制（纯搅拌）到最激烈（硬摇）再到最彻底（调和机打碎）</strong>——技法对应的是「你想让这杯酒被处理到什么程度」。烈酒系选最克制，果汁蛋清系选激烈——这个光谱是「选技法」的总地图。</span>

**搅拌的两个进阶动作**：

- **「杯壁洗冰」**：搅拌前，用冰在搅拌杯里转一圈（wash），倒掉附着水再入料——去除「冰面首层水」，让冷却更干净。
- **「离心收尾」**：搅拌结束前，让吧勺沿杯壁快速提拉一次，把杯底沉下的「重液」翻上来——确保混合均匀、不留「味觉分层」。

**自检清单（出品前）**：冰是整块吗？搅拌到起霜了吗？糖化开了吗？（老式）滤冰了吗？杯冰镇了吗？——**五问过后，一杯合格的搅拌系短饮才成立**。

## 6 7 搅拌法的家庭练习法
在家练搅拌法，不需要完整吧台——几个要点就能练出「手感」：

**练习清单**：

- **工具**：搅拌杯（可用高杯替代）、吧勺（可用长柄勺替代）、大块冰（用冰格冻的整块或大冰块）、霍桑过滤器（可用细漏勺替代）。
- **动作**：拇指食指夹勺柄上段、让勺子靠螺旋在指间转动；勺贴杯壁下行、翻起杯底液体；**搅拌是「搅液体」不是「捣冰」**。
- **信号**：搅拌 20–30 秒，杯壁起霜 = 温度达标；倒出时液体顺滑不「水」= 稀释得当。

**练什么**：用「金酒 + 水」做「无酒练习」（避免浪费烈酒）——按「马天尼的比例 + 搅拌 + 滤冰」，练习「起霜的信号、转数的控制、滤冰的手感」。**每次记录「转数」与「口感」**，找到自己的「最佳转数区间」——这就是你的「私人搅拌参数」。

**易错点自查**：搅拌时勺子在「画圈」而非「螺旋转」？冰是碎冰导致稀释过快？没滤冰就倒出？——**三问自查，练三次就能明显进步**。

## 7 8 术语速查：搅拌法
搅拌相关的术语速查：

| 术语 | 含义 |
| --- | --- |
| Stir | 搅拌法 |
| Ice wash | 杯壁洗冰（去除附着水） |
| Twist | 柠檬皮条（拧油） |
| Dilution | 稀释（冰融化的水量） |
| Chilled glass | 冰镇杯（出品前冰镇） |
| On the rocks | 加冰上杯 |
| Straight up | 滤冰上杯 |
| Bar spoon spin | 吧勺螺旋转动 |

**一句话**：**搅拌的术语围绕「克制」展开——洗冰、冰镇杯、轻转**——每一个词都在追求「冷却而不稀释、清澈而不充气」。

## 8 小结

- **搅拌法**用于纯酒系配方（马天尼、曼哈顿、尼格罗尼），靠冰冷却 + 吧勺混合 + 滤冰出品。
- 与摇和的关键差别：搅拌**充气极少、稀释温和**（15%–25%），保住烈酒的清澈与锋芒。
- **大块冰 + 20–30 秒 + 杯壁起霜**是经验标尺；搅拌时间直接决定稀释量。
- 稀释量可量化：$V_{\text{final}} = V_{\text{liquor}} + V_{\text{melt}}$，搅拌目标约 20% 左右。
- 搅拌是「克制」——目标是冰而烈，不是水而淡。

在下一节，我们进入物理过程完全相反的**摇和法（Shake）**：用剧烈的震荡把空气打进液体，为含果汁、蛋清与奶油的配方创造清爽与泡沫。
