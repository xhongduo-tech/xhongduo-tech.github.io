## 为什么调酒师要懂运营

前 28 篇的调酒师是「艺术家」，本节要加上「经营者」的身份——**吧台不是只出杯，它是一盘生意**：酒水成本占销售额的比例、库存压了多少资金、损耗在哪里流失，直接决定一家酒吧能不能活下去。国家职业技能标准把**库存管理、采购与成本控制**列为技师（二级）与高级技师（一级）的核心能力——**会调酒决定你能不能当调酒师，会算账决定你能不当多久**。本文讲清库存、采购与成本三件事，并用一节公式解析把「倒酒成本率」算明白。

## 1 库存管理：从盘点到先进先出

**库存管理（inventory management）**：对吧台酒水、原料的存量、周转与保质进行系统管理，目标是「**够用不积压、新鲜不浪费**」。

三个核心动作：

**定期盘点（inventory count）**：分每日、每周、每月三档——每日盘「高价值/高流动」酒（基酒、利口酒），每周盘全库存，每月做完整盘点。**盘点的目的不是「数数」，而是「对账」**：期初库存 + 本期进货 − 期末库存 = 本期耗用，与营业额交叉验证。<span class="marginnote">「账面 vs 实际」的差额就是「损耗」——损耗包括倒洒、过度倒酒、员工赠饮、盗窃与蒸发。<strong>损耗超过 3%–5% 就需要警惕</strong>：是手法问题（倒酒手抖）、标准问题（spec 没执行），还是管理漏洞？盘点是对损耗的「体检」。</span>

**先进先出（FIFO）**：先入库的先用——尤其对鲜果汁、奶制品、开瓶味美思等保质期短的原料。**「先进先出」与第 2 篇「冷藏保鲜」是同一件事的两面**：前者是库存秩序，后者是卫生底线。

**保质期管理**：开瓶烈酒（味美思、利口酒）开封后风味会逐渐氧化，通常建议 1–3 个月内用完；鲜果汁当日用尽；糖浆按需现调。**「大瓶囤积」是库存大忌**——省了采购频次，亏了风味与资金。

**核心要点：库存管理的目标函数是「在『断货』与『积压』之间取最优」**——断货丢生意，积压占资金、耗风味。职业吧台用「再订货点（reorder point）」控制：某酒库存低于「安全线」就补货，高于「最大线」就不进。

## 2 采购：供应商、批量与验收

**采购（purchasing）** 的目标是「在品质、价格、供应稳定性之间取平衡」：

**供应商选择**：比价 + 比品质 + 比服务。烈酒与利口酒品牌集中、价格透明，核心是选「供货稳定、批次可靠」的渠道；鲜果与果汁则讲究「本地、新鲜、可追溯」。
**批量决策**：大批量采购单价低，但占用资金、风险是风味退化（鲜料）与资金积压（长库龄）。**决策依据是周转率**——高周转酒（基酒）可批量，低周转料（特色利口酒）小批量。
- **验收标准**：到货验收核对**品名、数量、规格、保质期**；破损、过期、不符立即退换。**验收是采购的「最后一道闸」**——不验货就入库，损耗会从采购环节开始漏。<span class="marginnote">采购与库存联动看，「<strong>周转率</strong>」是最关键的运营指标：周转率高说明资金用得活、货鲜；周转率低说明压货、费钱、风味在退化。职业吧台用「月周转次数 = 月销售额 / 月平均库存成本」来衡量，与库存盘点互为表里。</span>

**辨析｜易错点：** 采购最常见的错误是「**只看单价不看周转**」——为省一点点单价大批囤货，结果鲜料过期、资金积压，实际成本反而更高。**采购的本质是「成本 + 资金 + 风味的三角博弈」，单价只是其中一个变量。**

## 3 公式解析：倒酒成本率（Pour Cost）

成本控制的核心指标是**倒酒成本率（pour cost）**——酒水成本占酒水销售额的百分比：

$$\text{Pour Cost} = \frac{\text{酒水成本}}{\text{酒水销售额}} \times 100\%$$

以一杯马天尼为例逐步拆解：

- **第一步，算单杯成本**：一杯马天尼用金酒 6 cl、味美思 1 cl。金酒整瓶 750 mL 进价 240 元，则每 mL 成本 0.32 元，6 cl = 60 mL 成本 19.2 元；味美思 1 cl 成本约 1.5 元；加装饰、杯具分摊约 1 元。**单杯总成本 ≈ 21.7 元**。
- **第二步，定单杯售价**：设售价 80 元。
- **第三步，代入公式**：Pour Cost = 21.7 / 80 ≈ **27.1%**。

**这个数字说明什么？** 行业惯例中，**鸡尾酒吧的 pour cost 通常控制在 18%–25%**，过高（>30%）说明成本失控或定价过低，过低（<10%）说明定价过高、可能吓跑客人。27% 略高，说明这杯酒定价需上浮或配方需更「省」——**pour cost 是酒吧「定价 + 配方 + 用量」三者的体检表**。<span class="marginnote">「倒酒成本率」的反面是「毛利」：毛利 = 100% − pour cost。27% 的成本率意味着 73% 的毛利——酒吧是典型的高毛利行业，但毛利高不代表赚钱：房租、人工、水电、损耗都从毛利里扣。<strong>pour cost 管的是「酒水这一项的进出」，是成本控制的第一道闸。</strong></span>

**成本控制的三个抓手**：

**标准用量（spec 严格执行）**：用量随手一倒，成本率立刻失控——**spec 不但是风味保证，还是成本保证**。
**损耗监控**：盘点对账，把损耗压到 3% 以内。
- **定价与配方联动**：用 pour cost 反推「该卖多少钱」或「该用什么价位的酒」。

## 4 吧台运营的日常闭环

把库存、采购、成本串成一个「运营闭环」：

- **每天**：盘点高流动酒、检查鲜料保质期、记录损耗、核对当日营业额。
- **每周**：完整盘点、对比「账面 vs 实际」、计算 pour cost、生成补货清单。
- **每月**：全面财务复盘、淘汰滞销酒、优化酒单、与供应商议价。

**核心要点：运营不是「额外的工作」，而是「让吧台活着的工作」**——调酒师的手艺解决「客人想不想来」，运营解决「店能不能开下去」。技师与高级技师等级的能力差异，很大程度上就是「能不能把这两件事同时做好」。

## 5 6 酒单设计与利润分析：把成本翻译成菜单
吧台运营的最终呈现，是「酒单（drink menu）」——它把成本、风味与定价翻译成一页纸。设计酒单是一门「运营 + 创意」的综合课：

**酒单的三大结构原则**：

- **按「风味/烈度」分区**：清爽长饮区、烈酒短饮区、甜点区、无酒精区——客人一眼能定位，也方便推荐（呼应第 28 篇点单沟通）。
- **控制 SKU 数量**：酒单上的「鸡尾酒 SKU」不宜过多——**每一款都对应一种库存与损耗**。经典 + 特色各占一半，是常见配比。
- **设置「利润锚点」**：高毛利款（如冷冻饮品、无酒精调饮）放在视觉中心位，用低价款「锚定」感知——**酒单设计本身就在影响客单价**。<span class="marginnote">酒单设计里有个常用手法叫「<strong>利润率排序</strong>」：把「高毛利 + 高人气」的款放中间（视线焦点）、「高毛利 + 低人气」的款放在角落前一位（引导视线顺移）——用酒单布局「推」客人点高毛利款，是运营的精细活。</span>

**单杯利润的算法**（与第 29 篇 pour cost 联动）：

| 项目 | 计算 |
| --- | --- |
| 单杯成本 | 各原料用量 × 每 mL 成本之和 |
| 单杯售价 | 按 pour cost 目标（18%–25%）反推 |
| 单杯毛利 | 售价 − 成本 |
| 月贡献 | 单杯毛利 × 预计月销量 |

**酒单迭代的节奏**：**每季度微调、每半年大改**——按「销量排名 + 毛利排名」淘汰滞销款、优化配方成本；按季节上新（夏冰沙、冬热托蒂）。**酒单不是静态菜单，而是「运营的仪表盘」**——它反映库存、成本与客群偏好的全部信息。

**给新手的起步建议**：先做「一页酒单」——6–8 款经典 + 2–3 款特色 + 2 款无酒精，配好 spec 与成本表，就足够撑起一个小吧台的运营骨架。

一句话总结：**酒单是成本与风味的翻译器——分区清晰、SKU 克制、利润锚点、季度迭代**，把第 29 篇的成本控制落成一页纸。

## 6 7 损耗的六个常见来源
把「损耗」拆开看，才能堵住它：**① 手抖**——倒酒不用量酒器，凭手感倒多倒少；**② 赠饮**——员工随意请客、吧台试酒无记录；**③ 蒸发**——开瓶烈酒不盖盖，酒精挥发（尤其烈酒）；**④ 变质**——鲜料过期、开瓶利口酒氧化；**⑤ 破损**——玻璃杯、整瓶酒摔碎；**⑥ 盗窃**——员工私拿、客人顺手牵羊。**六个来源的对策**：用量酒器（防①）、赠饮登记（防②）、随手盖盖（防③）、FIFO + 保质期管理（防④）、小心搬运（防⑤）、盘点对账（防⑥）——**损耗不是「难免」，是「可管理」**。

## 7 7 吧台的财务仪表盘
把库存、采购、成本的数据汇成「财务仪表盘」，运营才不靠拍脑袋。**四个核心指标**：**pour cost**（倒酒成本率，18%–25% 为健康，第 29 篇）、**月周转率**（月销售额 ÷ 月平均库存成本，越高资金越活）、**损耗率**（实际耗用与账面对账的差额，应 <3%）、**客单价与翻台**（单人消费与座位周转，决定营收天花板）。**仪表盘的价值在「环比」**——单一数字没意义，本月 vs 上月、旺季 vs 淡季的对比，才暴露趋势：pour cost 突然升高→查用量与损耗；周转率骤降→查滞销库存。**「用数字管吧台」是技师与高级技师（第 1 篇）的核心能力**——会算账，才能当好家。

## 8 8 库存的数字管理
库存管理可以「数字化」得更精细：**用「再订货点」公式**——某酒再订货点 = 日均销量 × 补货周期天数 + 安全库存；**用「ABC 分类」**——A 类（高价高流动，如高端威士忌）每日盘，B 类（常规基酒）每周盘，C 类（低值辅料）每月盘。**数字管理的目标不是「算出精确值」，而是「让补货与盘点有依据、不靠拍脑袋」**——把库存从「感觉够不够」升级为「数字说了算」，是运营成熟的第一步。

## 9 9 术语速查：吧台运营
吧台运营相关的术语速查：

| 术语 | 含义 |
| --- | --- |
| Pour cost | 倒酒成本率（成本 ÷ 销售额） |
| Inventory | 库存盘点 |
| Turnover rate | 周转率 |
| Shrinkage | 损耗（盘点差额） |
| Reorder point | 再订货点（补货触发线） |
| SKU | 库存单品（Stock Keeping Unit） |
| Spec | 配方规格（原料、用量、技法、杯型、装饰） |
| Gross margin | 毛利率（1 − pour cost） |
| FIFO | 先进先出 |
| ABC analysis | ABC 分类管理（按价值分优先级） |

**一句话**：**运营术语都是「数字的语言」**——pour cost、周转率、损耗率三个数字，就能看出吧台的经营健康状况。

## 10 小结

- **库存管理**三动作：定期盘点（对账查损耗）、先进先出（鲜料保质）、保质期管理（风味与资金）。
- **采购**是「成本 + 资金 + 风味」三角博弈：看周转率而非只看单价；验收是最后一道闸。
- **倒酒成本率** pour cost = 酒水成本 ÷ 酒水销售额，行业标准 18%–25%，过高或过低都要调整。
- 成本控制三抓手：**标准用量、损耗监控、定价配方联动**。
- 运营闭环：**日盘高流动、周盘全库存、月盘复盘**——手艺管「来」，运营管「活」。
