## 为什么曼哈顿与罗伯罗伊放在一起

上一节马天尼是「金酒 + 味美思」，本节是「**威士忌 + 甜味美思 + 苦精**」——鸡尾酒史上另一座丰碑。**曼哈顿（Manhattan）**诞生于 19 世纪纽约，**罗伯罗伊（Rob Roy）**则是它的苏格兰「变体」——把波本/黑麦换成苏格兰威士忌，其余几乎不变。把它们并排讲，是为了让你亲眼看到「**换一种基酒，一杯酒的气质如何整体改写**」——这正是从「背配方」走向「懂配方」的关键一步。本文先拆曼哈顿的苦甜平衡，再对比罗伯罗伊。

## 1 曼哈顿：威士忌的苦甜二重奏

**曼哈顿（Manhattan）**：威士忌 + 甜味美思（sweet vermouth）+ 苦精，搅拌滤冰，装饰酒渍樱桃。

IBA 标准配比：

| 原料 | 用量 |
| --- | --- |
| 黑麦威士忌（或波本） | 5 cl |
| 甜味美思 | 2 cl |
| 安高天娜苦精 | 1 dash |
| 技法 | 搅拌（Stir），滤冰 |
| 装饰 | 酒渍樱桃 |

**平衡逻辑**：威士忌提供烈与辛，甜味美思提供甜与草本，苦精提供一丝苦——**「苦甜」是曼哈顿的名字**。甜味美思（红色、含糖较高）与干味美思（白色、不甜）是两种完全不同的原料，曼哈顿用的是**甜**味美思，所以整体比马天尼「甜润」得多。

**基酒的选择是风格之争**：

- **黑麦威士忌**：辛香、干、棱角分明——黑麦的辛与甜味美思的甜互搏，是「传统纽约味」，也是 IBA 的首选。
- **波本威士忌**：焦糖甜、圆润——波本的甜与味美思的甜叠加，整体更柔更甜，是「新手友好版」。

<span class="marginnote">「黑麦 vs 波本」在曼哈顿里是经典之争：黑麦让酒「立」起来（辛香对抗甜），波本让酒「躺」下去（甜上加甜）。选哪个，取决于你想让「苦甜」里的「苦/辛」站多高——这就是第 2 篇威士忌一章里「甜系选波本、苦甜系选黑麦」口诀的实际应用。</span>

**核心要点：曼哈顿的平衡轴是「甜」与「苦/辛」的对抗。** 味美思给甜、苦精给苦、威士忌给辛——三股力量缺一则塌，多则冲。这是搅拌类「烈酒 + 味美思 + 苦精」配方的通用平衡模型。

## 2 技法与细节：搅拌与樱桃

曼哈顿的技法与马天尼同源——**搅拌而非摇和**：纯烈酒 + 味美思 + 苦精，无需乳化，搅拌保住清澈与烈度。<span class="marginnote">曼哈顿若摇和，会充气变浊、稀释过多，甜味美思的糖被水冲淡后整杯发「水」——所以 IBA 曼哈顿标准是搅拌。记住这条规律：<strong>凡「烈酒 + 味美思/苦精」的配方，默认搅拌</strong>。</span>

**装饰樱桃**：酒渍樱桃（cocktail cherry）提供甜与酒感，与味美思的甜呼应——**樱桃不是点缀，是「甜」的最后一笔**。讲究的做法用浸在樱桃利口酒或马拉斯奇诺酒里的樱桃，而非廉价糖水樱桃。

**冰与杯**：搅拌约 20–30 秒，滤入冰镇的鸡尾酒杯（coupe 或马天尼杯）。**杯不冰则温度失控**——这是搅拌类配方的共同铁律。

**辨析｜易错点：** 新手曼哈顿常见失误：**把「甜味美思」误用成「干味美思」**（整杯从甜润变干涩）、**苦精用量过猛**（超过 2 dash 苦味压过一切）、**装饰用错樱桃**（糖水樱桃的廉价甜感破坏整体）。

## 3 罗伯罗伊：苏格兰版的「曼哈顿」

**罗伯罗伊（Rob Roy）**：苏格兰威士忌 + 甜味美思 + 苦精，搅拌滤冰，装饰酒渍樱桃——**把曼哈顿的基酒从美式威士忌换成苏格兰威士忌**。

IBA 标准配比：

| 原料 | 用量 |
| --- | --- |
| 苏格兰威士忌 | 4.5 cl |
| 甜味美思 | 2.5 cl |
| 安高天娜苦精 | 1 dash |
| 技法 | 搅拌（Stir），滤冰 |
| 装饰 | 酒渍樱桃 |

**变化在基酒，气质跟着变**：苏格兰威士忌（尤其是调和型）带**麦芽香、果干与烟熏**——换成它之后，整杯从美式的「焦糖甜辛」变成苏格兰的「麦芽烟熏甜」。**同一个配方骨架，基酒一变，风味叙事全变**——这是「基酒决定配方气质」最直观的演示。<span class="marginnote">注意罗伯罗伊的配比中味美思比例略高（2.5 cl）——因为苏格兰威士忌的风味比黑麦更「沉」，需要稍多的甜来托起。细节里的比例微调，正是调酒师「依基酒调平衡」的职业直觉。</span>

**罗伯罗伊的选择**：用苏格兰**调和威士忌**作基酒最常见（麦芽与谷物的平衡）；用**单一麦芽**则烟熏与果干更重，是高端变体。烟熏感重的艾雷岛威士忌会让整杯偏向「泥煤烟熏」——除非刻意追求，一般不建议用重泥煤款。

## 4 配方解析：曼哈顿家族的一棵「替换树」

把曼哈顿与罗伯罗伊放进一棵「替换树」，就能看到整个家族的逻辑：

| 配方 | 基酒 | 味美思 | 苦精 | 气质 |
| --- | --- | --- | --- | --- |
| 曼哈顿 | 黑麦/波本 | 甜 | 安高天娜 | 甜美 + 辛香 |
| 罗伯罗伊 | 苏格兰威士忌 | 甜 | 安高天娜 | 麦芽果干 + 烟熏 |
| 马天尼 | 金酒 | 干 | 无（或柠檬皮油） | 清冽草本 |
| 老式 | 威士忌（无味美思） | 无 | 安高天娜 + 方糖 | 醇厚极简 |

**核心要点：曼哈顿家族的骨架是「烈酒 + 味美思 + 苦精」，所有变体都是「换基酒」或「调味美思」**。看懂这张表，你就能预测：把金酒放进曼哈顿骨架会得到什么？——那正是马天尼的「堂兄弟」；把味美思换成利莱白会怎样？——那接近维斯珀。**配方世界没有孤立的酒，只有一张「骨架 × 参数」的网格。**

## 5 6 曼哈顿家族的变体地图：从一杯到一片
曼哈顿的成功在于它「骨架简单、参数可换」——理解了它，整个「烈酒 + 味美思 + 苦精」家族都为你敞开：

**曼哈顿家族变体速查**：

| 变体 | 基酒 | 味美思 | 装饰/特别 |
| --- | --- | --- | --- |
| 曼哈顿（经典） | 黑麦或波本 | 甜 | 樱桃 |
| 罗伯罗伊 | 苏格兰威士忌 | 甜 | 樱桃 |
| 布朗克斯（Bronx） | 金酒 | 甜+干各半 | 橙汁（摇和） |
| 马天尼（堂亲） | 金酒 | 干 | 柠檬皮/橄榄 |
| 完美曼哈顿（Perfect） | 威士忌 | 甜+干各半 | 柠檬皮+樱桃 |
| 黑曼哈顿（Black） | 波本 | Averna 苦味利口酒 | 樱桃 |

<span class="marginnote">「Perfect Manhattan」的「Perfect」是行业术语，指<strong>「甜味美思与干味美思各半」</strong>——不是「完美」的意思。同理「Perfect Martini」也是甜干各半。这个「perfect = 两种味美思混合」的用法，在点酒与配方里高频出现，是又一个「行业暗语」。</span>

**变体的两条演化轴**：**换基酒**（黑麦→苏格兰→金酒）改变风味气质；**换味美思**（甜→干→各半→苦味利口酒）改变甜苦平衡。**两轴交叉，就是一张可无限生成的配方网格**——这不是「乱改」，而是「在同一骨架内做参数替换」的创作方法（呼应第 26 篇）。

**点曼哈顿的几个词**：

| 说法 | 意思 |
| --- | --- |
| 黑麦曼哈顿 | 黑麦为基（传统纽约味） |
| 波本曼哈顿 | 波本为基（更甜更柔） |
| 完美曼哈顿 | 甜干味美思各半 |
| 脏曼哈顿 | 加橄榄盐水（少见但存在） |

**曼哈顿家族的共同点**：搅拌、滤冰、樱桃装饰、杯型用鸡尾酒杯——**骨架的「不变项」比「变项」更重要**：懂了不变项，变项就是选择题。这也是从「背一杯酒」到「读懂一个家族」的关键跃迁。

一句话总结：**曼哈顿家族 = 同一骨架（烈酒+味美思+苦精）× 基酒与味美思的可换参数**——学会读骨架，一片酒海向你敞开。

## 6 小结

- **曼哈顿**：威士忌 + 甜味美思 + 苦精，搅拌滤冰，酒渍樱桃——「苦甜」是名字也是平衡轴。
- 基酒之争：**黑麦**辛香干爽（传统）、**波本**焦糖甜美（圆润）。
- 技法铁律：**搅拌而非摇和**；樱桃是「甜」的最后一笔。
- **罗伯罗伊** = 苏格兰威士忌版的曼哈顿：麦芽果干 + 烟熏，味美思比例微调至 2.5 cl。
- 整个「烈酒 + 味美思 + 苦精」家族是同一棵**替换树**：换基酒、调味美思，就得到新的经典。

在下一节，我们走出「纯烈酒搅拌」，进入**尼格罗尼与老式**——一个靠「苦」立身，一个靠「极简」立身，却是当代烈酒爱好者的两大入口。
