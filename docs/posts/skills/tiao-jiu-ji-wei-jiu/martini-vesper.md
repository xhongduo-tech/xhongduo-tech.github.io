## 为什么经典配方从马天尼开始

如果把鸡尾酒比作一门语言，**马天尼（Martini）就是这门语言的「诗」**——原料只有两样，技法只有一个「搅」，却承载了最多的话题：干度之争、摇与搅之争、橄榄与柠檬皮之争。IBA 把它列入 The Unforgettables（难忘系列），因为它是一切的试金石：**基酒品质、冰与稀释的控制、调酒师的手法，全在一杯马天尼里现形**。维斯珀（Vesper）则是它的著名「改编」——007 邦德专属配方。本文从这两款出发，把「搅拌法 + 装饰 + 干度光谱」串成一条完整的配方思维链。

## 1 马天尼：两原料一杯酒的极致

**马天尼（Martini）**：金酒 + 干味美思（dry vermouth），搅拌后滤冰，装饰柠檬皮条或橄榄。

IBA 标准配比（经典比例）：

| 原料 | 用量 |
| --- | --- |
| 金酒 | 6 cl |
| 干味美思 | 1 cl（可调） |
| 技法 | 搅拌（Stir），滤冰 |
| 装饰 | 柠檬皮条或橄榄 |

**「干」是马天尼的灵魂变量**：所谓干度，指「味美思用量」——味美思越少，酒越「干」（dry 此处是「不甜」，不是「不湿」）。干度光谱从「超干」到「湿」：

- **超干（Extra Dry）**：金酒 : 味美思 ≈ 5:1 甚至 8:1——酒体近乎纯金酒，味美思只提供一点草本骨架。
- **标准干（Dry）**：约 4:1 到 5:1——金酒的植物香与味美思的草本微苦互衬。
- **湿（Wet）**：约 2:1——味美思比例提高，酒体更甜润、更柔和。<span class="marginnote">点酒时「Martini, dry」的「dry」是「味美思少一点」的意思；「Martini, wet」则是「味美思多一点」。这个「干」的用法常让新手困惑——马天尼的「干」是调节剂比例，不是口感干涩。</span>

**核心要点：马天尼的配比没有「唯一正确」，只有「风格光谱」。** 读懂「干度」这个变量，你就掌握了马天尼的整个表达系统——这也是为什么懂调酒的人聊马天尼总能聊出花样。

## 2 技法与装饰：为什么是搅拌 + 皮条

马天尼的**技法选择是「搅拌而非摇和」**（第 3 篇已论证）：纯烈酒 + 味美思无需乳化，搅拌保住清澈与锋芒。<span class="marginnote">邦德的「Shaken, not stirred」是个著名的反例——摇和马天尼会充气变浊、稀释更多，专业吧台把它当作风味取向而非标准。IBA 官方马天尼是搅拌。</span>

**装饰的二选一**是另一种风格题：

**柠檬皮条（twist）**：拧出油雾喷上酒面，提供清新柑橘香，与金酒的杜松子香呼应——「干派」首选。
**橄榄（olive）**：提供咸鲜，与金酒的草本香和「干」的骨架互补——「咸派」首选。

**冰与杯**：搅拌约 20–30 秒至杯壁起霜，滤入**冰镇的马天尼杯**——杯若不冰，成品入杯立即升温，香气大打折扣。

**辨析｜易错点：** 新手马天尼三大失误：**削皮条削进白瓤**（苦味毁酒）、**搅拌过度**（稀释成水）、**杯未冰镇**（温度失控）。每一处都是「细节决定成败」——马天尼是全世界最「容不下错误」的鸡尾酒。

## 3 维斯珀：邦德式的「加码」

**维斯珀（Vesper）**：以金酒为底、加入伏特加与利莱白葡萄酒（Lillet Blanc），**摇和**后滤冰，装饰柠檬皮条。

IBA 标准配比：

| 原料 | 用量 |
| --- | --- |
| 金酒 | 6 cl |
| 伏特加 | 1.5 cl |
| 利莱白（Lillet Blanc） | 1.5 cl |
| 技法 | 摇和（Shake），滤冰 |
| 装饰 | 柠檬皮条 |

维斯珀出自伊恩·弗莱明 1953 年的小说《皇家赌场》，邦德在小说里专门命名了这杯酒——**「Vesper」正是邦德心仪的女主角的名字**。它把马天尼的「两原料极简」改成了「三原料加码」：伏特加让酒体更纯净硬朗，利莱白（一种加香葡萄酒，带蜂蜜与苦橙气息）比干味美思更甜润，所以维斯珀整体比马天尼更「顺、甜、烈」。

**为什么维斯珀用摇和？** 因为利莱白含一定糖分与香草成分，摇和能让其充分乳化、口感更圆润；同时摇和带来的更多稀释也平衡了高酒精度（金酒 + 伏特加合计 7.5 cl 纯烈酒）。<span class="marginnote">维斯珀的三原料设计透露了一个配方原理：<strong>当基酒总量提高时，用「更甜、更重」的加香葡萄酒替代「更干」的味美思，再用摇和的稀释来平衡</strong>——这不是炫技，而是让一杯高烈度酒「喝得下去」的工程。</span>

## 4 配方解析：从维斯珀读「平衡」

把维斯珀的平衡拆开看，正好复习前几篇的全部工具：

**酒感**：金酒 6 + 伏特加 1.5 = 7.5 cl 烈酒，度数约 40%——**这是「烈度上限」的配方**，体感强烈。
**甜**：利莱白 1.5 cl 提供蜂蜜与甜润，是唯一甜源——比例低，所以「微甜」。
- **酸/苦**：柠檬皮条的油雾提供香气与微苦，但无果汁——**维斯珀几乎没有酸味维度**，它靠「酒精 + 甜」撑起口感。
- **稀释**：摇和约 30% 稀释，把 40% 的烈度降到约 28% vol 左右——「烈而不烧」。

**对比马天尼**：马天尼的味美思是「干而草本」，维斯珀的利莱白是「甜而蜂蜜」——**同一个「金酒 + 加香葡萄酒」骨架，味美思选干与甜，直接决定整杯是「清冽」还是「圆润」**。这就是配方思维：看懂骨架，一切变体都是调参。

## 5 6 马天尼的点酒语言：如何点一杯「合你心意」的马天尼
马天尼的「点酒语言」是一门微型语言——听懂它，你就能精准描述自己想要的那杯：

**马天尼的四个可调参数**：

- **基酒**：金酒马天尼（经典）还是伏特加马天尼（更纯净）？——「Vodka Martini」即指定伏特加。
- **干度**：「Dry」= 味美思少一点；「Extra Dry」= 味美思极少量（仅涮杯）；「Wet」= 味美思多一点；「50/50」= 金酒与味美思各半。<span class="marginnote">点酒时「超干」的说法是<strong>「Very, very dry」或「In and out」</strong>——后者指「味美思只在杯里涮一圈就倒掉」，几乎是纯金酒。这是老派吧台的暗语，懂的人一听就知道你是行家。</span>
- **装饰**：「Twist」= 柠檬皮条；「With a twist」= 皮条；「Olive」= 橄榄；「Dirty」= 加少量橄榄盐水（脏马天尼）。
- **温度与冰**：默认搅拌滤冰；「Up」= 滤冰上杯（默认）；「On the rocks」= 加冰上杯（少见）。

**几个点酒例句**：

| 说法 | 意思 |
| --- | --- |
| 金酒马天尼，超干，柠檬皮 | 金酒为主、味美思极少、皮条装饰 |
| 伏特加马天尼，脏，三颗橄榄 | 伏特加 + 橄榄盐水 + 橄榄 |
| 马天尼，50/50，皮 | 金酒与味美思等量、皮条 |
| 维斯珀 | 金酒 + 伏特加 + 利莱白，摇和 |

**「点得明白」本身就是品鉴力**：能说清「干度 + 装饰 + 基酒」，说明你理解了这杯酒的骨架（第 1 节）与变量（干度光谱）。**调酒师听到精准的点酒语言，会把你当行家对待**——这就是「懂酒」在点单环节的外显。

**点酒的常见误区**：「Dry」≠「干爽口感」，而是「味美思少」；「Dirty」≠「脏」，而是「加橄榄盐水」；「Shaken」≠「更好」，而是「更水更浊」——**每一个词都有明确的行业含义**，别按字面猜。

一句话总结：**马天尼的点酒语言 = 基酒 + 干度 + 装饰三个参数的精确组合**——会点马天尼，是你学会「用行话点酒」的第一课。

## 6 7 马天尼的家用练习法
在家练好一杯马天尼，比在吧台更容易专注手法：**先冰镇杯子（冰水泡 1 分钟）、用大块冰、数着转数搅拌（约 30 转）、滤冰入杯、拧皮条**——每一步单独练熟再合起来。练习时记录每次的「味美思用量」与「搅拌转数」，找到自己的「最佳干度」——**把参数记下来，就是你的私人 spec**。

## 7 小结

- **马天尼**：金酒 + 干味美思，搅拌滤冰，「干」是可调的味美思比例（超干 5:1 → 湿 2:1）。
- 技法铁律：**搅拌而非摇和**；装饰在柠檬皮条（清新）与橄榄（咸鲜）之间二选一。
- **维斯珀**：金酒 + 伏特加 + 利莱白，摇和滤冰，装饰柠檬皮条——邦德原创、更顺更甜更烈。
- 维斯珀用摇和的理由：利莱白含糖需乳化 + 高烈度需更多稀释——**配方参数互相关联**。
- 两者共用「金酒 + 加香葡萄酒」骨架，**选干与甜，就选定了整杯的气质**。
