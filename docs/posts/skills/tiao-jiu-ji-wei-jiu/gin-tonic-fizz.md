## 为什么把「汤力」与「菲士」并排

金汤力与金菲士都以金酒为基、都以气泡为魂，但**技法正好相反**：金汤力是「直接注入」的标杆——不摇不搅，杯中分层；金菲士是「摇和 + 补气泡」的经典——先摇出风味，再以苏打水收尾。把它们并排讲，恰好把第 3 篇的两种技法放进同一杯金酒里对比：**同一种基酒，注入 vs 摇和，产出的是完全两种性格的长饮**。本文先拆金汤力的「气泡管理」，再讲金菲士的「摇和 + 发泡」。

## 1 金汤力：直接注入法的教科书

**金汤力（Gin Tonic）**：金酒 + 汤力水 + 青柠角，直接注入（Build），高杯长饮。

IBA 标准配比：

| 原料 | 用量 |
| --- | --- |
| 金酒 | 4 cl |
| 汤力水 | 补满 |
| 青柠角 | 1 角（装饰） |
| 技法 | 直接注入（Build） |

**为什么它是 Build 的教科书？** 因为金汤力同时考验了 Build 的三个关键（第 3 篇 Build 一节）：**先冰后酒、汽水后倒、轻搅一次**。具体动作：高杯加满冰块 → 倒入金酒 → 沿杯壁轻倒入冰镇汤力水 → 挤入青柠角并投入 → 用吧勺**顺着杯壁轻搅一圈**。搅拌「一圈」的用意是：让金酒与汤力水初步混合，却不扰动气泡。<span class="marginnote">金汤力的「汤力水」是核心变量：汤力水含<strong>奎宁（quinine）</strong>，带来标志性的微苦；现代汤力水还分「干型、芳香型、低糖型」。汤力水一旦开瓶，气泡会持续流失——<strong>「现开现倒、冰镇后再倒」是气泡管理的铁律</strong>。</span>

**核心要点：金汤力的灵魂是「清冽 + 微苦 + 气泡」的三角**。金酒的杜松子清冽、汤力水的奎宁微苦、青柠的酸与油香——三者互衬，缺一则塌。而让三角「站住」的，是**气泡的新鲜度与青柠的现挤**。

**选酒与温度**：金汤力对基酒的宽容度很高，但**伦敦干金酒 + 优质汤力水 + 大量冰块**是默认公式；青柠角要「现挤现投」，挤出的青柠油雾也是香气的一部分。**整杯用「冷」立起来**——冰不够多，汤力水升温后苦味发闷、气泡快速逃逸。

**辨析｜易错点：** 金汤力三大失误：**汤力水提前开瓶**（气泡跑光、整杯发甜发闷）、**先倒汤力水再倒酒**（气泡被酒液冲击打散、且酒水难匀）、**搅拌过度**（气泡尽失、「塌」成甜水）。记住 Build 铁律：**先冰、后酒、再汽水、轻搅一次**。

## 2 金菲士：摇和与发泡的双重奏

**金菲士（Gin Fizz）**：金酒 + 柠檬汁 + 糖浆，摇和滤冰后补入苏打水，可加蛋清（银菲士 Silver Fizz）。

IBA 标准配比：

| 原料 | 用量 |
| --- | --- |
| 金酒 | 4.5 cl |
| 鲜柠檬汁 | 3 cl |
| 单糖糖浆 | 1 cl |
| 苏打水 | 8 cl（补满） |
| 技法 | 摇和（Shake），滤冰，补苏打水 |
| 装饰 | 柠檬片 |

**金菲士的结构是「酸酒 + 气泡」**：金酒、柠檬、糖浆三者先摇匀（这是标准「酸酒公式」：1 份基酒 + ¾ 酸 + ¼ 甜），滤入高杯，最后**补入苏打水**——气泡只在出品前一刻进入，保证「咝咝」的新鲜感。<span class="marginnote">金菲士的「补气泡」与金汤力的「后倒汽水」是同一个逻辑：<strong>气泡要在出品前最后一刻才进入液体</strong>，最大程度保留碳酸。这也是「气泡原料绝不进摇壶」原则的正向应用——苏打水永远「后补」，不进摇壶不搅拌。</span>

**蛋清与「银菲士」**：在金菲士的配方中加入**蛋清**摇出泡沫，就得到「银菲士（Silver Fizz）」。蛋清需**干摇**（先无冰摇发泡、再加冰摇冷却），倒出时细筛过滤——顶部那层绵密奶泡是「银」字的来源。<span class="marginnote">蛋清奶泡让菲士从「清爽气泡饮」升级为「丝绒气泡饮」——口感更圆润、表面覆一层细泡。这是第 3 篇摇和法「干摇」与「双重过滤」两节的实际演示，也呼应了第 2 篇卫生规范里「蛋类用巴氏杀菌蛋清」的要求。</span>

## 3 金汤力 vs 金菲士：同基酒，两种性格

| 维度 | 金汤力 | 金菲士 |
| --- | --- | --- |
| 技法 | 直接注入（Build） | 摇和 + 补苏打水 |
| 气泡来源 | 汤力水（带奎宁微苦） | 苏打水（中性气泡） |
| 风味主角 | 清冽 + 微苦 + 青柠 | 酸 + 甜 + 酒（柠檬主导） |
| 口感 | 清爽、气泡足、略苦 | 酸爽、可带奶泡、更「厚」 |
| 甜度 | 低（汤力水微甜） | 中（糖浆 1 cl） |

**核心要点：金汤力是「把气泡作为风味的一部分」（奎宁的苦），金菲士是「把气泡作为口感的外衣」（中性苏打）。** 同是金酒，一个让苦味立住整杯，一个让酸甜唱主角——**基酒相同，技法与配料一换，就是两杯完全不同的酒**。这就是「配方思维」：看懂骨架与变量，一切组合皆可预测。

**品鉴提示**：金汤力宜「趁冰趁气泡」大口喝，金菲士宜「先看奶泡、轻搅后小口」——气泡饮都有「时间窗口」，这也是长饮与短饮在饮用节奏上的共同规律。

## 4 6 金汤力与金菲士的「品质三要素」
两杯气泡长饮的品质，都由三个要素决定——掌握它，你就能稳定出品：

**金汤力的品质三要素**：

**汤力水的新鲜度**：开瓶后的汤力水气泡持续流失，**「现开现倒」是铁律**——一瓶开了半小时的汤力水，气泡已散大半。讲究的吧台用单瓶装（200 mL）汤力水，一杯一瓶，最大程度保气。
**金酒与汤力水的比例**：常见推荐 1:2 到 1:3（金酒 4 cl 对汤力水 8–12 cl）——酒太少是「甜的苏打水」，酒太多是「加气的烈酒」。**比例是这杯酒的「第一道平衡」**。<span class="marginnote">金汤力的比例没有唯一答案：<strong>「干型汤力水」更苦更干，适合提高金酒比例；「芳香型汤力水」自带香草与辛香，金酒比例可略降</strong>——先尝汤力水，再定比例，是选配的底层逻辑。</span>
- **冰与青柠**：冰要足（约 2/3 杯）、青柠要「挤一下」——**「冷 + 鲜」是气泡长饮的两条腿**，缺一条整杯就「塌」。

**金菲士的品质三要素**：

- **酸糖平衡**：柠檬汁的酸与糖浆的甜，是菲士的「骨架」——IBA 的 3:1（柠檬 3 cl 对糖浆 1 cl）偏酸，口味偏甜的可加到 1.5 cl 糖浆。**「酸糖平衡」决定菲士是「清爽」还是「齁甜」**。
- **摇和是否到位**：摇 10–15 秒至壶壁起霜——**蛋清版（银菲士）要「干摇发泡」**，摇不够则奶泡塌、口感糙。
- **苏打水后补**：摇好的酒液滤入高杯，**最后补苏打水、轻提一次**——苏打水是「最后一秒」的生命线。

**两杯的「时间窗口」**：气泡长饮都有「最佳饮用窗口」——金汤力约 15 分钟、金菲士约 10 分钟（奶泡会消）。**「趁冰趁气泡」是气泡长饮的饮用纪律**，也是侍酒时提醒客人的一句话。

| 要素 | 金汤力 | 金菲士 |
| --- | --- | --- |
| 第一要素 | 汤力水新鲜度 | 酸糖平衡 |
| 第二要素 | 酒水比例 | 摇和到位 |
| 第三要素 | 冰与青柠 | 苏打水后补 |

一句话总结：**气泡长饮的品质 = 新鲜度 + 平衡 + 时机**——现开的汽水、调好的比例、趁冰的出品，三者缺一不可。

## 5 7 两杯酒的服务细节
金汤力与金菲士的出品细节：**金汤力**——高杯冰足、汤力水最后倒、轻搅一次、青柠挤油入杯；杯垫吸冷凝水、配吸管或吧勺。**金菲士**——摇好的酒液滤入高杯、苏打水后补、轻提一次；蛋清版（银菲士）顶部要有一层绵密奶泡，用细筛过滤保证「丝滑」。**服务的共同点**：两杯都「趁冰趁气泡」上桌，上桌时告诉客人「请趁冰饮用」——**气泡长饮的「时间窗口」是服务话术的一部分**（第 4 节），提醒客人及时喝，既是专业也是体贴。

## 6 7 两杯酒的杯型选择
杯型对气泡长饮的体验影响很大：**金汤力**——标准用**高球杯（highball）**：直筒高身，气泡上升路径长、保持更久，杯口适中便于闻香与握持；讲究的用「金汤力专用杯」杯口略收。**金菲士**——用**科林斯杯（collins glass）**：比高球杯更高更窄，奶泡与气泡的「层次」更分明。**一个规律**：**杯身越高越窄，气泡保持越久、视觉层次越清晰**——这是「杯型服务风味」的又一例。家用没有专用杯时，用任意直筒高杯即可，但别用矮胖杯——气泡散得快。

## 7 8 两杯酒的气泡科学
气泡长饮的口感，其实是一堂物理课：**碳酸（CO₂）在低温下溶解度更高**——所以「冰镇后再倒汽水」不只是口感偏好，而是物理规律：冰镇汽水的气泡更足、更持久；**气泡在液体里以小气泡形式上浮，携带香气分子到杯口**——所以金汤力「闻起来」就很有存在感。**两个应用**：倒汽水时沿杯壁缓倒（减少气泡破裂）、出品后「轻提一次」而非猛搅（保留气泡）——**「气泡管理」不是玄学，是碳酸的物理课**。

## 8 8 术语速查：金汤力与金菲士
两杯酒相关的术语速查：

| 术语 | 含义 |
| --- | --- |
| Quinine | 奎宁（汤力水苦味来源） |
| Tonic water | 汤力水（含奎宁气泡水） |
| Soda water | 苏打水（中性气泡水） |
| Collins | 科林斯杯（菲士用高杯） |
| Dry shake | 干摇（先无冰摇蛋清） |
| Silver Fizz | 银菲士（加蛋清的菲士） |
| Sour mix | 酸糖混合液（柠檬汁+糖浆） |
| Fizz | 摇和后补苏打的长饮 |

**一句话**：**金汤力讲「汤力水的新鲜」，金菲士讲「酸糖平衡 + 后补气泡」**——两个关键词，就是两杯酒的全部秘诀。

## 9 小结

- **金汤力**：金酒 + 汤力水 + 青柠角，**直接注入**——「先冰、后酒、再汽水、轻搅一次」是铁律。
- 金汤力的灵魂是**清冽 + 奎宁微苦 + 气泡**三角；汤力水现开现倒、青柠现挤现投。
- **金菲士**：金酒 + 柠檬汁 + 糖浆，**摇和滤冰后补苏打水**——酸酒公式 + 后补气泡。
- 加蛋清的**银菲士**用「干摇 + 双重过滤」做出绵密奶泡。
- 气泡管理共通原则：**气泡原料永远「后补」、绝进摇壶、现开现倒**。
