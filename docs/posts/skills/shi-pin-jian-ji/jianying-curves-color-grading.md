## 为什么剪映也能讲「调色」

前两课在 Premiere 里学了完整的一级、二级调色体系。这一课回到剪映，看它如何把调色能力做成轻量形态——**滤镜**与**曲线**。

你可能会想：剪映的调色「够专业吗」？答案是：剪映的「调节」面板几乎覆盖了 Premiere 一级调色的全部参数，曲线功能则摸到了二级调色的边——它只是用更友好的交互封装了同样的原理。<span class="marginnote">带着 Premiere 的调色理论进剪映，你会发现「原来都是老朋友」：亮度=曝光、对比度=对比度、饱和度=饱和度、色温=白平衡、曲线=S 曲线。理论在前两课已经打好，本课做的是「同一套原理，第二套工具」的映射练习。</span>

## 1 剪映的滤镜体系：预设的一级调色

剪映的「滤镜」在时间线工具栏里，按风格分类（清新、胶片、美食、黑白等）。在第3篇第4课讲过它的基础用法（套用、强度），本课从「调色理论」的角度重新理解它：

**滤镜 = 预设的一级调色方案**。每个滤镜内部就是一组「曝光/对比度/饱和度/色温/色调」的预设组合。你看到的「复古滤镜」，本质是「降饱和 + 提阴影 + 色温偏暖」的打包。<span class="marginnote">把滤镜拆成「参数组合」来理解，你就知道怎么「用对」滤镜：先看画面缺什么，再找补什么的滤镜。画面发灰 → 找「对比度高」的滤镜；画面太冷 → 找「色温偏暖」的滤镜。不看原理只看预览，容易选到「看着好看但不对症」的滤镜。</span>

**滤镜的分层使用**：剪映的滤镜可以只作用于一段素材（选中素材再套），也可以「应用到全部」。分段套不同滤镜 = 分段做一级调色；全片统一滤镜 = 全片风格统一。

**滤镜 + 强度**：强度滑杆就是「滤镜作用多少」的旋钮——降强度让滤镜「若有若无」，是避免滤镜感太重的手法（第3篇第4课讲过）。

## 2 调节面板：手动的一级调色

如果滤镜不够用（或你想完全自己控制），剪映的「调节」面板提供手动参数。它对应 Premiere 的「基本校正」区：

**亮度 / 对比度**：对应曝光与对比度。亮度调整体明暗，对比度调亮暗差距。

**饱和度 / 锐化**：饱和度调颜色浓淡；锐化让画面边缘更清晰（注意别拉过头，会出现「白边」）。

**色温 / 色调**：对应白平衡双轴——色温管黄蓝，色调管品红绿。

**高光 / 阴影**：分段调光——压高光、提阴影，对应 Premiere 的分段精修。<span class="marginnote">剪映调节面板的参数顺序（亮度→对比度→饱和度→色温→高光阴影），与 Premiere 一级调色的标准流程几乎一一对应。如果你在剪映里也按「先白平衡、再亮度、再对比度、再分段」的顺序走，就能复现完整的「干净化」流程——原理相通，工具不同。</span>

| 剪映调节参数 | Premiere 对应 | 控制什么 |
| --- | --- | --- |
| 亮度 | 曝光 | 整体明暗 |
| 对比度 | 对比度 | 亮暗差距 |
| 饱和度 | 饱和度 | 颜色浓淡 |
| 色温/色调 | 色温/色调 | 白平衡 |
| 高光/阴影 | 高光/阴影 | 分段调光 |

## 3 曲线调色：手动画「亮度映射」

剪映的「曲线」功能是它调色能力的进阶点。入口在「调节」里，点「曲线」，出现亮度曲线——横轴是输入亮度（左暗右亮），纵轴是输出亮度，你可以在曲线上打点、拖动，把直线弯成想要的形状。

曲线的三种基础玩法：

**S 曲线（对比度）**：把曲线中段拉陡，两端放平——中间调对比增强，高光阴影保持安全。这是「让画面通透」的曲线版。

**提亮/压暗**：把曲线整体上抬 = 提亮；整体下压 = 压暗。相当于手动画「亮度映射」。

**分区调光**：在曲线左侧（暗部）打点抬高 = 提阴影；在右侧（亮部）打点压低 = 压高光。分段调光的曲线实现。<span class="marginnote">曲线是「亮度映射的图形界面」——上一课那条 $L' = f(L)$ 的公式，在这里变成了一条可拖动的线。拖曲线的过程就是「设计 $f$」：每打一个点、拖一下，都是在告诉软件「这个亮度要变成多亮」。理解了「曲线 = 亮度映射」，你就不会再对着曲线工具发呆。</span>

**RGB 曲线**：剪映的曲线还支持分通道——分别调红、绿、蓝三条曲线。单通道曲线 = 给特定亮度区染对应颜色：红曲线上抬=偏红、蓝曲线压低=偏黄……这正是二级调色「分域染色」的轻量实现。

## 4 核心对比表：剪映调色 vs Premiere 调色

剪映与 Premiere 的调色能力对比，用一张表彻底理清「什么能做、什么做不了」：

| 调色能力 | 剪映 | Premiere |
| --- | --- | --- |
| 滤镜（预设） | 丰富、一键 | 需装 LUT 或手调 |
| 一级调色（曝光/对比/饱和） | 有，参数简化 | 完整，可精细 |
| 曲线（亮度映射） | 有，基础 | 完整，可复杂 |
| 分通道曲线 | 有（RGB） | 有（更多通道） |
| HSL 辅助（按颜色选） | 无（或简化版） | 完整 |
| 遮罩局部调色 | 有（关键帧+蒙版） | 完整（可跟踪） |
| 示波器 | 无 | 完整 |
| LUT 导入 | 支持部分 | 完整支持 |

**辨析｜易错点：** 从这张表能看到剪映调色的边界：**它覆盖了一级调色和部分二级调色，但没有示波器、没有完整的 HSL 辅助**。这意味着在剪映里「靠眼睛调」的成分更高——如果你发现画面偏色但调不准，不是你不会调，而是工具缺少「数据验证」的手段。这时把素材拿到 Premiere 用示波器看一眼，就能定位问题。<span class="marginnote">「剪映快、Premiere准」是两套工具的现实分工：日常短视频、快速出片用剪映；对色彩要求高、需要精确控制的用 Premiere。成熟创作者的流程往往是「剪映打底出快稿，Premiere 精修定终版」——工具按需选用，而不是被工具绑架。</span>

## 5 局部调节：剪映的「二级调色」

剪映虽然简化了 HSL 辅助，但提供了另一条局部调色路径——**蒙版调节**：用「蒙版」圈出画面的一块区域，对这一块单独做调节（亮度、对比度、颜色等）。

操作方式：选中素材 →「蒙版」→ 选形状（矩形、圆形、线性、自定义），调整蒙版的位置、大小与**羽化**，然后在蒙版区域内施加调节。

蒙版调节与 Premiere 的遮罩调色原理相同，只是交互更轻。典型应用：

**提亮面部**：用圆形蒙版圈住脸部，提亮，羽化拉大让过渡自然。
**压暗背景**：用线性蒙版把天空圈住，压暗或改色，突出主体。
**局部去色**：圈住画面中碍眼的杂物，降饱和让它「退后」。

| 局部调整工具 | 剪映 | Premiere |
| --- | --- | --- |
| 按颜色选 | 受限 | HSL 辅助完整 |
| 按区域选 | 蒙版 | 遮罩 |
| 跟随运动 | 有限 | 遮罩跟踪完整 |

**辨析｜易错点：** 蒙版调节最容易露馅的是**边缘生硬**。解决办法与 Premiere 相同——**羽化拉大**：羽化越大，圈内与圈外的过渡越柔和。判断标准：关掉蒙版再看一遍，如果「看不出哪里被调过、只觉得整体更好了」，局部调节才算成功。这与上一课「局部调色的目标是看不出调了哪里」完全一致。<span class="marginnote">剪映把「二级调色」简化成「蒙版+调节」，牺牲了精确性，换来了易用性。这个取舍值得记住：<strong>轻工具不是不能做局部调色，而是用不同的方式做</strong>——理解「蒙版=局部选区」的本质，你在任何工具里都能做局部调色。</span>

## 6 公式解析：从滤镜到曲线的「同一件事」

把滤镜与曲线放在同一个理论框架里看，它们本质是同一件事：**亮度/颜色映射**。

- **滤镜** = 一组预设映射 $F$ 直接套用（用户不可见内部细节）。
- **曲线** = 用户手动设计映射 $f$（可见、可改、可复用）。
- **调节参数** = 一组更简单的映射（每个滑杆一个参数）。

三者关系可以表达为：

$$\text{滤镜} \; F_{\text{预设}} \;\approx\; \text{调节参数组合} \;\approx\; \text{曲线} \; f_{\text{手绘}}$$

它们都在做「输入像素 → 输出像素」的变换，只是**抽象层级不同**：滤镜是最黑盒的（点一下就有），曲线是最透明的（自己画）。<span class="marginnote">「同一件事、不同抽象层级」是理解软件功能的最强框架：不是「滤镜和曲线是两个功能」，而是「一个功能（颜色变换）的三层封装」。理解抽象层级，你就能在任何软件里快速「找到老朋友」——看到新工具时先问：它在做哪一层变换？</span>

由此得到的实操结论：

- **想要快**：用滤镜（预设映射），改强度微调。
- **想要可控**：用调节参数（组合映射），逐个滑杆调。
- **想要精确**：用曲线（手绘映射），自己画 S 形、分通道染色。
- **熟练者路径**：滤镜打底 → 调节参数修正 → 曲线精修——从黑盒走向透明，逐层逼近「想要的画面」。

## 7 小结

- 剪映的**滤镜**是预设的一级调色方案，强度滑杆控制作用多少。
- **调节面板**手动做一级调色：亮度、对比度、饱和度、色温、高光阴影，与 Premiere 基本校正一一对应。
- **曲线**是亮度映射的图形界面，S 曲线提对比、分区调光、RGB 分通道染色。
- 剪映调色覆盖一级与部分二级，但**没有示波器、HSL 辅助受限**——「剪映快、Premiere 准」。
- 滤镜、调节、曲线是**同一颜色变换的三层抽象**：黑盒→组合→透明，按需取用。
