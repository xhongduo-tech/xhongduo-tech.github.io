## 为什么字幕如此重要

短视频时代，字幕从「可选」变成了「必须」——多数观众在静音状态下刷视频，没有字幕的内容会被直接划走。字幕不再只是「把台词打上去」，而是**信息传达的第二条通道**、**画面构图的一部分**、**风格表达的手段**。

这一课讲 Premiere 的字幕制作：从最基础的文本工具，到「基本图形（Essential Graphics）」面板的样式设计，再到字幕的排版原则。<span class="marginnote">字幕在 Premiere 里有两套系统：<strong>文本工具</strong>（Type Tool）适合做画面里的标题字、花字；<strong>字幕工作区（Captions）</strong>适合做逐句对白字幕。本课先讲文本工具与样式设计，因为它覆盖了「字幕」的绝大部分实际需求。</span>

## 1 文本工具：字幕的基本形态

在 Premiere 里添加文字，用工具栏的「文本工具（T）」。在节目监视器里点一下，输入文字，就会出现一个文本图层，自动落到新的视频轨道上。

文本的四个基础属性：

**内容**：文字本身，随时可以修改。

**位置**：拖动文本即可移动。这里要引入一个重要的概念——**安全边距（Safe Margins）**。电视与部分平台的边缘会被裁切，字幕应放在「标题安全区」内（画面四周 10% 以内的边距），否则可能被裁掉或离边缘太近。<span class="marginnote">安全边距来自广播电视时代：老式电视机对画面四周有不同程度的裁切，字幕放太靠边会被切掉。如今手机竖屏虽然裁切少，但「字幕不贴边、留有余量」仍是好习惯——尤其在适配不同平台时（有的平台有 UI 遮挡底部）。</span>

**时长**：文本图层在时间线上有长度，决定文字显示多久。拖动边缘即可调整。

**图层属性**：选中文本后，在「效果控件」面板里可调整字体、字号、颜色、描边、阴影、对齐等。

## 2 样式设计：让字幕「好看」的五要素

字幕好看与否，取决于五个样式要素的组合：

**字体**：中文字幕一般用黑体类（思源黑体、微软雅黑）保证清晰，标题可用更有个性的字体。同一视频里**字体种类不超过两种**——一种正文字体、一种强调字体，多了就乱。

**颜色**：字幕颜色要与画面有对比度，保证在任何背景上都看得清。深色画面用浅色字，浅色画面用深色字；不要用与背景相近的颜色。

**描边与阴影**：给文字加描边或阴影，让它与背景「分离」。描边通常 2–4 像素，黑色半透明描边是「百搭安全牌」。阴影制造立体感与层次。<span class="marginnote">描边与阴影的作用是「对比度管理」：文字要与背景区分，靠的不是「更亮的字」，而是「文字边缘与背景的边界」。黑色描边几乎适配所有背景，这就是为什么「白字黑边」成了字幕的经典配方。</span>

**字号与行长**：字幕字号要大到「一眼能看清」，行长控制在一行 10–20 字，太长观众读不完。短视频字幕通常「短句、大字、快切」。

**排版对齐**：文本居中还是靠左，取决于用途——对白字幕常居中，列表型信息常靠左。字号层级（主标题>副标题>正文）用「字号差」建立视觉层级。

| 要素 | 原则 | 常见做法 |
| --- | --- | --- |
| 字体 | 全片 ≤2 种 | 正文黑体 + 强调字体 |
| 颜色 | 与背景高对比 | 白字黑边 / 深字浅底 |
| 描边/阴影 | 保证边缘分离 | 2–4px 半透明黑描边 |
| 字号/行长 | 一眼看清、短句 | 一行 10–20 字 |
| 对齐 | 按用途选择 | 对白居中、信息靠左 |

## 3 基本图形面板：从「单个字」到「样式模板」

Premiere 的「基本图形（Essential Graphics）」面板，是字幕样式设计的进阶工具。它解决了两个问题：**批量统一**与**模板复用**。

**批量修改**：多段字幕选中后，在基本图形面板统一改字体、颜色、字号——不用逐段改，一次改全片。这是字幕样式效率的核心。

**样式保存**：把调好的字幕样式存为「样式」，下次直接套用，保证全片风格统一。

**模板库**：基本图形面板内置一批「动态图形模板（MOGRT）」——字幕条、标题动画、下三分之一（Lower Third）等。拖入时间线改文字即可，适合快速做出专业感。

**辨析｜易错点：** 新手最常见的字幕问题是「每段字幕一个样式」——字号不同、位置乱放、颜色随心情。字幕的样式设计第一原则是**一致性**：全片字幕是一个「系统」，字体、颜色、位置、字号应该统一。观众不会注意「每段字幕都一样整齐」，但会立刻注意到「有一段字幕不一样」。<span class="marginnote">「系统一致性」这个观念，是设计领域的基础原则——不管做字幕、做 PPT 还是做网页，统一的视觉系统都比单个元素的精致更重要。它和「从极限到大模型」主线里模型「一致性」的思想遥相呼应：系统的可靠性来自规则统一。</span>

## 4 对白字幕：从「打字」到「自动识别」

Premiere 里做逐句对白字幕，有手动与自动两条路：

**手动制作**：用文本工具逐句输入，拖动时长与声音对齐。精确但费时，适合短对白。

**自动字幕**：Premiere 提供「自动转录（Transcription）」功能——选中含人声的素材，自动把语音转成文字并生成字幕。之后校对错别字、调整断句即可。这与剪映的「识别字幕」是同一类功能（第1篇第5课讲过），底层都是语音识别（ASR）。<span class="marginnote">自动字幕的底层是语音识别技术（ASR）——从「语音 · ASR 与 TTS」专题的角度看，Premiere 和剪映的自动字幕都是把 ASR 封装成了「一键」功能。理解底层是 ASR，你就知道它哪里会错：口音、专业术语、同音字。校对是必须的。</span>

| 方式 | 效率 | 精度 | 适用 |
| --- | --- | --- | --- |
| 手动输入 | 低 | 高 | 短对白、强调设计感 |
| 自动识别 | 高 | 中（需校对） | 长对白、口播、采访 |
| 两者结合 | 中 | 高 | 自动识别 + 手动精修 |

**辨析｜易错点：** 自动字幕生成后，**必须逐句校对**。ASR 对同音字、多音字、专业术语的错误率不低（「就位」写成「就味」）。更重要的是断句——字幕按「能读顺的语义单位」断行，而不是按语音停顿。改字幕时先改断句、再改错字。

## 5 公式解析：字幕的可读性判断

字幕设计的核心目标只有一个——**可读性**。它可以用一个简单的关系式表达：观众能否在字幕显示时间内读完字幕。设字幕显示时长为 $T$，观众阅读该行字幕所需时间为 $t_{read}$，则可读性条件为：

$$t_{read} \le T$$

其中 $t_{read}$ 与字幕字数 $N$ 和阅读速度 $v$（字/秒）有关：$t_{read} = N / v$。普通人阅读速度约 **4–6 字/秒**。由此推出实用规则：<span class="marginnote">把「阅读速度 4–6 字/秒」记在心里，你就不会写出「观众读不完」的字幕。这条规则在短视频里尤其关键——很多字幕只有 1–2 秒，却塞了十几个字，观众根本来不及读。判断标准：先自己默读一遍字幕，看看能否在显示时间内读完。</span>

**每行字数上限**：假设显示 2 秒，则一行最多 8–12 字（按 4–6 字/秒）。短视频字幕要「短句、大字」，一屏一句话的片段。
**保证 T 充足**：字幕显示时长要 ≥ 朗读时长；关键信息（数字、人名、结论）适当延长显示时间。
**关键信息单独成行**：把最想强调的词（数字、结论）单独一行、加长显示——观众的眼球会被「短句」抓住。

这条公式的实践价值在于：**它把「字幕读不读得完」从一个模糊的担忧，变成了可计算、可检查的规则**。每次做完字幕，过一遍「2 秒内能不能读完」，就知道哪里要拆分。

## 6 字幕与画面的配合：位置与遮挡

字幕不是「悬浮在画面上的一块字」，它是画面构图的一部分。三个配合原则：

**避开信息主体**：字幕不要遮挡人脸、产品、关键文字。常见做法：人像居中时字幕放底部或顶部；画面主体在下方时字幕挪到上方。判断标准：**关掉字幕，画面核心信息是否完好？打开字幕，字幕是否没有盖住它？**<span class="marginnote">「字幕不遮挡主体」是对摄影师与剪辑师的双重要求：拍摄时给画面底部留出「字幕安全区」（人物头部以上构图、下方留空），剪辑时字幕才能有地方放。这解释了为什么专业采访画面通常「人物偏上、下方留白」——那正是给字幕留的位置。</span>

**跟人物位置移动**：人物在画面里左右移动时，字幕跟着移动（或换到不挡人的一侧）。这需要给字幕加位置动画——下一课「关键帧动画」正好解决。

**适配不同平台**：不同平台的 UI（点赞栏、进度条、平台 Logo）会遮挡画面底部，字幕位置要考虑平台差异。竖屏短视频常用「居中偏上」或「中偏下」的字幕位置，避开底部被 UI 遮挡的区域。

| 配合原则 | 做法 | 判断标准 |
| --- | --- | --- |
| 避开主体 | 字幕远离人脸/产品 | 字幕不盖核心信息 |
| 跟人移动 | 字幕随人物位置调整 | 始终不遮挡人物 |
| 平台适配 | 按平台 UI 调整位置 | 发布前各平台检查 |

**辨析｜易错点：** 「字幕放在画面正中央」在竖屏短视频里很流行，但它有两个前提——中央区域没有重要画面内容，且不会被平台 UI 遮挡。如果中央是人物面部或产品展示，字幕居中就是灾难。**位置没有绝对标准，只有「不挡信息」的相对标准。**

## 7 小结

- 字幕有两条通道：**文本工具**做画面标题字，**自动转录**做逐句对白字幕。
- 字幕样式五要素：**字体（≤2 种）、颜色（高对比）、描边/阴影、字号/行长、对齐**。
- **基本图形面板**实现批量统一与模板复用，样式设计第一原则是**一致性**。
- 自动字幕的底层是 **ASR**，必须逐句校对错字与断句。
- 可读性条件 `$t_{read} \le T$`，阅读速度约 4–6 字/秒，短视频字幕要「短句、大字、留够时长」。
