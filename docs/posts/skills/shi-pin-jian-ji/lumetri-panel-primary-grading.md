## 为什么从「一级调色」切入

上一课建立了色彩理论：RGB/HSL、白平衡、示波器、色轮。这一课把这些理论装进 Premiere 的调色主战场——**Lumetri 面板**，并完成调色的第一个阶段：**一级调色（Primary Grading）**。

一级调色是「全画面统一调整」：曝光、对比度、白平衡、饱和度——影响的是整幅画面，而不是某个局部。它的目标是「让画面干净、正确」，为下一课「二级调色」的风格化做准备。<span class="marginnote">「一级 vs 二级」是调色的两条腿：一级管全局（整幅画面的明暗、颜色），二级管局部（某个区域、某个颜色范围）。本课把一级调色的「全局思维」立住，下一课在它之上叠加「局部控制」——两级配合，才构成完整的调色工作流。</span>

## 1 Lumetri 面板：调色的「控制台」

在 Premiere 里做调色，先在「颜色」工作区打开 **Lumetri 颜色（Lumetri Color）面板**。它按功能分区，从上到下是「基本校正」「创意」「曲线」「色轮与匹配」「HSL 辅助」「晕影」等。一级调色主要用「基本校正」区。

「基本校正」区从暗到亮排列，对应上一课讲的「亮度/对比度线性变换」：

**曝光（Exposure）**：整体亮度，对应公式里的偏移 $b$——调它让画面整体变亮或变暗。

**对比度（Contrast）**：亮暗差距，对应公式里的增益 $g$——调大让画面更有层次，调小让画面发灰。

**高光 / 阴影 / 白色 / 黑色**：分段控制亮度——只压高光、只提阴影，比整体调曝光更精细。这四者是「先分段、再整体」的调光思维。

**饱和度（Saturation）**：整体颜色的浓淡，对应 HSL 的饱和度分量。

**色温 / 色调**：白平衡的双轴——色温管黄蓝（暖冷），色调管品红绿。

| 基本校正参数 | 控制什么 | 对应概念 |
| --- | --- | --- |
| 曝光 | 整体亮度 | 偏移 $b$ |
| 对比度 | 亮暗差距 | 增益 $g$ |
| 高光/阴影 | 亮部/暗部分段 | 分段线性 |
| 饱和度 | 颜色浓淡 | HSL 饱和度 |
| 色温/色调 | 白平衡 | 互补色校正 |

## 2 一级调色的标准流程：从「灰」到「干净」

一级调色有一套可以照抄的标准流程，按顺序走，画面基本就「干净」了：

**第1步：白平衡校正**。先用吸管在画面里找中性灰/白采样，或用色温色调手动校正，让白色还原成白。

**第2步：调曝光**。看波形图，整体曝光不足就加曝光，过曝就减曝光。目标是画面主体（肤色）亮度适中、明暗层次可见。

**第3步：调对比度**。画面发灰就加对比度，让暗部更实、亮部更亮。注意别把高光压死、暗部沉底。

**第4步：分段精修**。用高光/阴影/白色/黑色微调：亮部太刺眼就压高光，暗部太闷就提阴影。这一步让画面「透气」。

**第5步：饱和度**。把饱和度调到「自然」——不过浓也不过淡。肤色尤其要自然，过饱和的肤色会发「塑料感」。

**第6步：对照示波器检查**。打开波形图与 RGB 分量图，确认曝光安全、三通道平衡、不偏色。<span class="marginnote">这六步可以压缩成一句话：<strong>先白、再亮、再对比、再分段、再饱和、最后看示波器验证</strong>。按固定顺序走，你不会漏掉任何一环，也不会因为「凭感觉调」而反复横跳。调色的专业感，一半来自「流程的确定性」。</span>

## 3 核心对比表：一级调色 vs 二级调色

一级调色与二级调色的区别，是理解调色体系的关键。用一张表彻底分清：

| 对比维度 | 一级调色 | 二级调色 |
| --- | --- | --- |
| 作用范围 | 整幅画面 | 局部区域/颜色范围 |
| 目标 | 校正、干净、还原 | 风格、强调、分离 |
| 工具 | 基本校正区 | 色轮、HSL 辅助、遮罩 |
| 典型操作 | 调曝光、白平衡 | 把天空压蓝、把肤色提亮 |
| 何时做 | 先做 | 后做 |

**辨析｜易错点：** 新手最容易跳级——还没做一级调色就直接上风格化（加滤镜、拉色轮），结果画面「又脏又风格」。**一级是地基、二级是装修**：地基不平（曝光乱、偏色、肤色脏），再好的风格也撑不起来。判断标准：你的一级调色做到「关掉示波器、肉眼觉得画面干净自然」了吗？没有，就先别碰二级。<span class="marginnote">「先一级后二级」的顺序，和第1篇「先粗剪后精剪」、第2篇「先节奏后包装」是同一个方法论：<strong>先解决「对不对」，再追求「好不好」</strong>。这个顺序观贯穿整个视频剪辑体系——它保证了每一步都在稳固的地基上前进。</span>

## 4 公式解析：分段调光与「S 曲线」

一级调色里最精细的手段是**分段调光**：把亮度分成「高光、中间调、阴影」三段分别调整。它的数学本质，是**曲线（Curve）**——亮度映射。

设输入亮度为 $L$，输出为 $L'$，二者关系用映射曲线 $f$ 表示：

$$L' = f(L)$$

线性调光时 $f$ 是直线（上一课的 $L' = gL + b$）；分段调光时 $f$ 是一条「S 形」曲线——中间段斜率变大（提对比），两端变缓（保护高光阴影不溢出）。<span class="marginnote">「S 曲线」是调光的高级直觉：它让中间调更有层次（斜率>1），同时把高光、阴影「按在」不会溢出的范围内（两端变平）。Lumetri 基本校正里的「高光/阴影」滑杆，其实就是内置了一段 S 曲线；「曲线」面板（下一课会讲）则让你手动画这条 $f$。理解了「曲线 = 亮度映射」，分段调光就不再是玄学。</span>

由此得到分段调光的三条直觉：

**提阴影** = 把 $f$ 的下段往上抬：暗部变亮，高光不受影响。
**压高光** = 把 $f$ 的上段往下压：亮部收敛，暗部不变。
- **S 形** = 让 $f$ 在中段更陡：整体对比增强，两端保持安全。

**一级调色的完成标准**：波形图在安全范围内铺开、无死黑死白、肤色自然、三通道平衡——做到这些，画面「干净」，可以进入风格化。

## 5 镜头匹配：让相邻镜头颜色一致

一级调色除了「单镜头变干净」，还有一个更日常的任务——**镜头匹配（Shot Matching）**：让相邻镜头的颜色一致。现实中，同一场景的不同机位素材，白平衡、曝光常常不同；剪辑后相邻镜头「跳色」，观众会感到违和。

镜头匹配的流程：

1. **选基准镜头**：在一组相邻镜头里，挑一个画面最自然、颜色最正的作为「基准」。
2. **逐个对齐**：对每个相邻镜头做一级调色，目标是让它与基准镜头在亮度、白平衡、饱和度上一致。
3. **对照检查**：把相邻两镜头的波形图并排对比——亮度分布接近、三通道平衡接近，就算匹配完成。<span class="marginnote">「以相邻镜头为参照对齐颜色」是匹配的关键：不用追求「绝对正确」，只要相邻镜头之间「互相一致」。用示波器对比相邻镜头，比用眼睛对比可靠得多——眼睛会记住「这镜头偏暖」，但分不清偏了多少；示波器给出精确的数值差异。</span>

**Lumetri 的匹配辅助**：Premiere 的「颜色匹配（Color Match）」功能，可以用吸管在基准镜头里点一个参考色，软件自动把当前镜头向基准镜头对齐。它适合快速打底，但精细的匹配仍需手动微调——自动工具处理「大方向」，人工修正「小细节」。

| 匹配步骤 | 做法 | 检查方式 |
| --- | --- | --- |
| 定基准 | 选最自然的镜头 | 肉眼判断 |
| 对齐曝光 | 亮度向基准靠拢 | 波形图对比 |
| 对齐白平衡 | 色温向基准靠拢 | RGB 分量图对比 |
| 对齐饱和度 | 浓淡向基准靠拢 | 矢量示波器对比 |

**辨析｜易错点：** 镜头匹配不是「把每个镜头都调成一样的颜色」——如果基准镜头本身偏黄，全片跟着偏黄就错了。匹配的前提是**基准镜头先被一级调色调正确**，然后其他镜头向它对齐。「先校基准、再匹配全组」，顺序不能反。

## 6 小结

- **Lumetri 面板**是 Premiere 的调色控制台，「基本校正」区是一级调色的主战场。
- 基本校正参数对应亮度线性变换：**曝光=偏移、对比度=增益**，另有高光/阴影/白色/黑色做分段精修。
- 一级调色标准六步：**白平衡 → 曝光 → 对比度 → 分段精修 → 饱和度 → 示波器验证**。
- **一级调色管全局、二级调色管局部**；先一级后二级，先「正确」后「风格」。
- 分段调光的本质是亮度映射曲线 `$L' = f(L)$`，S 曲线让中间调有层次、两端保安全。
