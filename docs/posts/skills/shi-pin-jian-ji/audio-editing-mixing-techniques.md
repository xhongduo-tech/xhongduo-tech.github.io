## 为什么音频剪辑值得「一整章」

第1篇第4章讲了音频处理基础——多轨、音量、混音台。这一课在它之上进入**混音技巧（Mixing）**：把人物声、配乐、音效多条声音混成「干净、有层次、不刺耳」的成品。

你可能觉得「混音是音乐制作的事」，但视频里的混音同样关键：旁白被配乐盖住、音效突然炸耳、整体声音忽大忽小——这些「声音事故」都源于不会混音。本课要建立的是三件事：**混音的工作流、三大音频处理器（EQ/压缩/限幅）、响度的目标值**。<span class="marginnote">把本课与第1篇第4章区分开：第4章是「单个声音怎么调」（音量、淡化、降噪），本课是「多个声音怎么混」（分层、避让、平衡）。前者是单轨操作，后者是多轨整合——混音才是「让声音成为整体」的环节。</span>

## 1 混音的工作流：从「叠」到「让」

混音的起点是时间线上堆了多条声音：人声轨、配乐轨、音效轨。混音的目标不是「让它们都响」，而是「让它们各司其职」。一套标准的三步流程：

**第1步：定主次**。先确定这条片子「谁的声音是主角」——通常是人声（旁白/对白）。混音的第一原则是**主声优先**：主角声音清晰、突出，其他声音退后。

**第2步：定音量层级**。给每个声音轨定一个相对音量：人声 0 dB 左右（基准），配乐在 -18 到 -10 dB（人声的陪衬），音效按需在 -6 到 0 dB（点缀）。

**第3步：做避让（Ducking）**。当人声出现时，自动压低配乐；人声停顿时，配乐回升。这就是**闪避（Ducking）**——混音里最常用的「让路」技巧。<span class="marginnote">闪避的本质是「动态让位」：声音的响度不是静态的，而是随着其他声音的出现而自动调整。Premiere 的「音频剪辑混合器」里有 Ducking 功能，或手动给配乐加音量关键帧。为什么闪避重要？因为<strong>人声与配乐抢同一片频谱空间</strong>，同时都响就都听不清——先让一边，两边都清楚了。</span>

| 混音步骤 | 做什么 | 目标 |
| --- | --- | --- |
| 定主次 | 确认主角声音 | 主声优先 |
| 定音量层级 | 各轨相对音量 | 层次分明 |
| 做避让 | 人声时压配乐 | 主声清晰 |

## 2 三大音频处理器：EQ、压缩、限幅

Premiere 的效果面板里有大量音频效果，其中三个是混音的核心武器：

**EQ（均衡器）**：分频段调节音量。混音里 EQ 的目标不是「让声音更好听」，而是**「让声音不打架」**——人声主要在中频（300Hz–3kHz），配乐的低频（贝斯、鼓）和高频（弦乐）容易盖人声；用 EQ 把配乐与人声重叠的频段适当衰减，两者就「分开」了。<span class="marginnote">EQ 背后的原理是「频谱分离」：声音在不同频段占据不同的能量。混音的核心矛盾是人声与配乐<strong>抢中频</strong>——都在 1kHz 附近，同时响就互相掩盖。用 EQ 给配乐「挖掉」中频一小块，人声就「透」出来了。这个「给配乐留出人声的位置」的手法，是混音里最实用的技巧。</span>

**压缩（Compressor）**：把声音的「动态范围」压小——响的压低、弱的保持，整体响度更平稳。压缩让声音「不忽大忽小」，是让人声稳定、不破音的关键。

**限幅（Limiter）**：设定一个输出上限，超过上限的瞬间被「挡住」，防止爆音。限幅是混音最后的「保险丝」——保证任何瞬间都不会过载失真。

| 处理器 | 做什么 | 混音中的作用 |
| --- | --- | --- |
| EQ | 分频段调音量 | 频谱分离、不打架 |
| 压缩 | 压小动态范围 | 响度平稳、不忽大忽小 |
| 限幅 | 设输出上限 | 防爆音、最后保险 |

## 3 响度：用数值替代「感觉」

混音的最终验证，不能只靠耳朵——要参考**响度（Loudness）**的数值标准。响度的单位是 **LUFS**（Loudness Units Full Scale），它衡量的是「人耳感知的整体音量」，比简单的峰值 dB 更接近真实听感。

行业通用目标：**成片响度目标约为 -14 LUFS**（流媒体平台标准）或 -16 LUFS（广电标准）。Premiere 的「响度表」（在音频剪辑混合器或音轨混合器里）实时显示当前音频的响度。

**混音时的响度直觉**：

峰值 dB 管「会不会爆」（看波形顶没顶到红区），LUFS 管「整体听着多响」（看响度表）。
目标是把整体响度控制在 -14 LUFS 附近，同时峰值不超 0 dB——**「够响但不爆」**。
不同平台会自动把视频响度归一化到各自标准，所以「按 -14 左右调」基本适配大多数平台。<span class="marginnote">响度标准的本质，是给「多响算合适」一个可复现的数值定义。第1篇第4章讲过 dB 是对数单位（3 dB=能量翻倍），LUFS 是更贴近听觉的响度计量——它考虑了对不同频率的敏感度。理解「峰值（不爆）与响度（整体音量）是两个维度」，你就不会再「靠感觉把声音调大」了。</span>

## 4 核心要点表：混音问题的诊断

混音的问题千奇百怪，但大多能归入几张「症状清单」。用诊断表快速定位：

| 症状 | 原因 | 对策 |
| --- | --- | --- |
| 人声听不清 | 配乐太响/频率打架 | 降配乐、EQ 避让、闪避 |
| 整体忽大忽小 | 动态范围大 | 加压缩 |
| 某个瞬间破音 | 峰值超 0 dB | 加限幅 |
| 声音闷 | 高频缺失 | EQ 提升高频（谨慎） |
| 声音刺耳 | 高频过冲 | EQ 衰减高频 |
| 结尾突兀 | 无淡出 | 加音频淡出 |

**辨析｜易错点：** 混音最容易犯的错是「每个声音都单独听着挺好，合在一起就糊」。原因往往是**没做避让与 EQ**——每个声音单独响没问题，但合在一起频谱互相掩盖。混音的精髓不是「把每个声音调好」，而是**「在整体里让每个声音找到位置」**。判断标准：关掉任何一轨，其他声音是否仍然清晰？混得好，关掉配乐，人声依然完整。

## 5 公式解析：混音的音量叠加直觉

混音时你经常需要估算「几个声音合起来多响」。第1篇第4章讲过 dB 的对数性质，这里给出更实用的「加法直觉」。

设两路声音的功率分别为 $P_1, P_2$，则合成功率 $P = P_1 + P_2$。用分贝表示：

$$L_{sum} = 10\log_{10}\frac{P_1 + P_2}{P_0} = 10\log_{10}\left(10^{L_1/10} + 10^{L_2/10}\right)$$

这条公式看起来复杂，但推出两个常用近似：<span class="marginnote">记住两个「加法锚点」就够了：<strong>两个相同响度的声音叠加，总响度 +3 dB</strong>；<strong>一个声音比另一个小 10 dB 以上时，几乎不影响总响度</strong>。第一条告诉你「叠音轨会变响多少」，第二条告诉你「配乐比人声低 10 dB 时，人声就是绝对主角」。这两个锚点，覆盖了混音里 80% 的音量估算。</span>

**两路相同响度叠加 → +3 dB**：功率翻倍。所以「把两条相同的声音叠起来」，响度增加 3 dB。
**一路比另一路低 10 dB → 几乎无贡献**：$10^{L_2/10}$ 在 $L_2 = L_1 - 10$ 时约为 $L_1$ 的十分之一，对总和影响很小。

这两个锚点的实操价值：

配乐比人声低 10 dB 以上，人声清晰不被盖——这就是「人声 +3 到 +10 dB」音量差的理论依据。
- 想验证混音平衡，看响度表：人声段的整体响度应主要来自人声，配乐段的整体响度来自配乐。

## 6 混音的最后检查：用耳朵 + 用数值

混音收尾时，按一套检查清单过一遍，能避免绝大多数「发布后才发现」的声音事故：

**用耳朵检查**：在安静环境里完整听一遍成片，重点检查——人声全程清晰吗？有没有哪句被配乐盖住？音效会不会突然炸耳？音乐结束是否自然？

**用数值检查**：打开响度表看全程响度是否稳定在目标附近；看波形有没有顶到红区的瞬间（峰值超限）；用耳机与手机外放各听一遍（不同播放设备的听感差异很大）。<span class="marginnote">「耳机+外放各听一遍」是混音检查的黄金组合：耳机能听出细节问题（频率打架、破音），外放能听出整体平衡（人声是否被环境声淹没）。观众的使用场景千差万别，多设备试听是「以用户视角验收」的混音版。</span>

**检查单速查**：

| 检查项 | 用耳朵 | 用数值 |
| --- | --- | --- |
| 人声清晰 | 每句都听清 | 响度表人声段突出 |
| 不破音 | 无刺耳瞬间 | 峰值不超 0 dB |
| 响度合适 | 整体不轰不弱 | 约 -14 LUFS |
| 多设备一致 | 耳机+外放 | 高低频平衡 |

**辨析｜易错点：** 混音检查最容易犯的错是「只在大音量下听」——音量拉大时一切声音都清晰，但观众日常音量下配乐可能盖住人声。**用接近观众的日常音量（手机外放的正常音量）检查**，而不是「越大声越专业」地猛开音量。混音是为「观众的耳朵」调的，不是为「你的监听音箱」调的。

## 7 小结

- 混音是**多声音整合**：定主次 → 定音量层级 → 做避让（闪避），让主声清晰。
- 三大音频处理器各司其职：**EQ 分频段避让、压缩稳动态、限幅防爆音**。
- 响度用 **LUFS** 衡量，成片目标约 **-14 LUFS**，配合峰值 0 dB「够响但不爆」。
- 混音的精髓是**让每个声音在整体里找到位置**，而不是把每个声音单独调好。
- 音量叠加的两个锚点：相同响度叠加 +3 dB，低于 10 dB 的声音几乎无贡献。
