## 为什么在多轨剪辑里学音频

前几课的时间线都只有「画面+单条声音」的基本形态。这一课把时间线从「单层」升级到「多层」——**多轨剪辑**——同时解决一个此前被忽略的大问题：**声音**。

你可能已经注意到一个反直觉的事实：观众可以忍受画面粗糙，却很难忍受声音糟糕。一个画面模糊但有清晰旁白的视频，远比画质精美但声音刺耳的视频「能看」。这就是为什么 Premiere 的音频处理能力值得单独一章。<span class="marginnote">把本课放在第1篇的最后，逻辑是这样的：多轨是 Premiere 时间线的高级形态，音频则是通往第2篇「音画关系」的技术地基。学完本课，你既有「多轨操作」的手感，也有「声音分层」的意识，下一专题才能讨论「音画如何配合表达」。</span>

## 1 多轨剪辑：把声音和画面分开组织

「多轨」指时间线上同时存在多条轨道。最简单的多轨结构是「三轨起步」：

**V1**：主画面轨，放主要视频素材。
**A1**：人物原声轨，放说话声。
- **A2**：配乐与音效轨，放背景音乐、环境声、音效。

为什么要分层？因为不同声音需要**分别控制**。人物的说话声要能单独调音量、静音、修口误；背景音乐要能压低（让位给说话声）、淡入淡出。如果所有声音混在一条轨里，任何调节都会互相影响。<span class="marginnote">多轨的本质是「把不同类型的声音放进不同的抽屉」。这个观念来自混音（Mixing）：不同声源先各自处理，最后再合流。声音工程里的「轨道（Track）」概念，就是从混音台（Mixing Console）沿用下来的。</span>

拖入素材时，Premiere 会自动把视频的「画面部分」放到目标视频轨、「声音部分」放到目标音频轨。你也可以在时间线空白处右键 → 「添加轨道」，增加额外的视频/音频轨。

## 2 音频剪辑的基本动作

音频在时间线上也是「素材」，可以像视频一样剪切、移动、删除。四个基础动作：

**分割音频**：用剃刀工具或 `Ctrl+K` 切开音频素材，删除其中的口误、杂音段落。这和视频剪切完全同构。

**调节音量**：选中音频素材，在「效果控件」面板里调整「音量 → 级别」，单位是分贝（dB）。`0 dB` 是原始音量，负值变小，正值变大（可能失真）。<span class="marginnote">分贝是对数单位，每增加 10 dB 声音能量约变为 10 倍。因此「音量条 -6 dB」并不是「小了一半」，而是明显减弱但未到一半。理解分贝的对数性质，是调音量不「靠感觉乱拉」的前提。</span>

**淡化（淡入淡出）**：拖动音频素材左上角/右上角的小圆点，可以快速添加「淡入」或「淡出」——声音从无到有、从有到无的平滑过渡。视频素材边缘也有同样的圆点，做画面淡入淡出。

**静音**：选中音频 → 「音频」面板里勾选「静音」，或直接用 `V` 键（在「启用/禁用」模式下）临时关闭片段。

## 3 混音台：多轨声音的总控

当轨道变多时，逐条点击素材调音量太繁琐。Premiere 提供了「音频剪辑混合器（Audio Clip Mixer）」面板——一个虚拟的**混音台**，每条轨道对应一路「推子（Fader）」。

在混音台里：

每条轨道的**推子**控制该轨整体音量，可以实时拖动并在播放时「写」入音量变化（自动化）。
每个轨道有**声像（Pan）**旋钮，控制声音在左/右声道的位置——人声居中，环境声可稍偏。
- 底部有**静音（M）**与**独奏（S）**按钮：独奏某轨后只播放该轨，用于单独检查一条声音。

| 混音台元素 | 功能 | 类比 |
| --- | --- | --- |
| 推子 | 控制某轨整体音量 | 水龙头开多大 |
| 声像旋钮 | 声音在左右声道的位置 | 声音从哪个方向来 |
| 静音 / 独奏 | 关掉某轨 / 只留某轨 | 乐队里让谁别出声 / 只听谁 |
| 音量自动化 | 记录播放时推子的移动 | 音量随时间变化 |

**辨析｜易错点：** 混音台控制的是「轨道」，效果控件控制的是「片段」。两者会叠加：片段的音量×轨道的推子=最终听到的音量。如果声音偏小，先检查是片段音量低还是轨道推子低——很多新手只调其一，调了半天没效果。

## 4 核心要点表：音频处理的四类基本操作

本主题不涉及复杂公式，用一张「操作—目的—入口」表把音频处理的操作体系化：

| 操作 | 目的 | 入口 |
| --- | --- | --- |
| 调节音量 | 让某段声音更大/更小 | 效果控件 → 音量 |
| 淡入淡出 | 声音平滑出现/消失 | 素材边缘圆点拖动 |
| 静音 | 临时关闭声音 | 选中 → 音频 → 静音 |
| 分割删除 | 去掉口误与杂音 | 剃刀工具 + 删除 |
| 声像调节 | 声音在左右声道的位置 | 混音台声像旋钮 |
| 独奏 | 单独听某条轨 | 混音台 S 按钮 |

## 5 常见音频问题的处理

实际素材的音频几乎从不完美。三个最高频的问题与对策：

**底噪（环境噪声）**：手机录的素材常有持续的电流声、空调声、马路声。对策：一是「降噪」，Premiere 自带「降噪（DeNoise）」效果，在效果面板搜索「降噪」拖到音频素材上，调整强度——但降噪过度会让声音发闷、失真，目标是「噪声小到不碍事」而非「完全听不见」。<span class="marginnote">降噪的本质是「把噪声频率削掉」：算法估算噪声的特征，再把人声之外的部分压低。理解这一点就能明白为何降噪会牺牲音质——削掉噪声的同时，人声的高频细节也被削弱。所以优先靠「录音时安静的环境」解决问题，软件降噪只是补救。</span>

**人声过小或爆音**：素材录音电平不对。人声过小，把音量提升到合适位置即可；爆音（波形顶到「红区」，声音破音）则很难修复，只能尽量减少破音段的使用。

**风噪与突发噪声**：户外拍摄的风声、快门声、拍手声。对策：在波形上找到噪声段，用剃刀切掉或用音量关键帧把它压低；声音干净的原则是「能切就切、不能切就压」。

| 问题 | 成因 | 处理方式 |
| --- | --- | --- |
| 底噪 | 环境声持续混入 | 降噪效果 / 尽量更换素材 |
| 人声过小 | 录音电平低 | 提升音量 / 增益 |
| 爆音 | 录音电平过高 | 很难修复，换素材最实际 |
| 突发噪声 | 快门、风噪 | 切开删除 / 音量关键帧压低 |

**辨析｜易错点：** 处理音频时最容易犯的错是「一把梭」——把降噪、音量提升、均衡一次全加上，结果声音被处理得又闷又假。原则是**最小干预**：只处理必须处理的问题，每加一个效果就问一句「不加行不行」。

## 6 公式解析：音量叠加与「0 dB」直觉

音频处理里有一个值得精确化的点：**多条声音叠加后总音量不是简单相加**。设人声音量为 $L_1$、配乐音量为 $L_2$（单位 dB），则直觉上「总音量 = $L_1 + L_2$」是**错的**——分贝是能量比的对数，叠加要回到线性域去算。

先记住分贝定义：

$$L = 10 \log_{10}\frac{P}{P_0}$$

其中 $P$ 是声音的功率，$P_0$ 是参考功率。从这条定义可推出一个实用的近似规则：**功率每变为 2 倍，分贝约增加 3 dB**（因为 $10\log_{10}2 \approx 3.01$）。于是混音时的「音量加减」就有了直觉：

- 想让配乐比人声**低约一半的响度感**，把人声设为 `-0 dB`、配乐设为 `-6 dB` 到 `-10 dB`——配乐明显退后，但不至于听不见。<span class="marginnote">这正是「人声压配乐」的常用范围：-6 dB 让配乐退到背景，-10 dB 更轻。记住「3 dB 是能量翻倍」这把尺子，调音时你就知道「动 3 格」与「动 6 格」在物理上意味着什么，而不是凭感觉乱推。</span>

- 两条完全相同的声音叠加，总音量 +3 dB（能量翻倍）——这就是为什么「叠音轨」时声音会明显变响。

**这条公式的意义**在于：它把「推子往下拉多少」从玄学变成了可以计算的工程决策。你不需要每次真的去算 $10\log_{10}$，只需要记住两个锚点：**3 dB = 能量翻倍**，**说话声与配乐之间留 6–10 dB 的落差**。专业混音对「响度」有更精确的标准（如目标响度 `-14 LUFS`，在《Premiere 视频剪辑》第11章展开），但理解分贝的对数本质，是这一切的起点。

## 7 小结

- 多轨剪辑的核心思想是**按声音类型分层**：人声一轨、配乐一轨、音效一轨，分别控制。
- 音频剪辑的基础动作：**分割、调音量、淡入淡出、静音**——与视频剪辑同构。
- **混音台**是轨道级的总控：推子管音量、声像管方位、静音/独奏管监听。
- 片段音量与轨道推子**会叠加**，调声音要分清调的是哪一层。
- 分贝是对数单位，**3 dB = 能量翻倍**；人声与配乐之间常用 6–10 dB 落差。
