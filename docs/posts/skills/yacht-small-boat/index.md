# 游艇与小型船舶驾驶

游艇驾驶是与机动车驾驶并行的小型船舶适任制度，游艇驾驶证由海事管理机构核发，是合法驾驶游艇的基本资质。以海事局《游艇操作人员培训、考试和发证办法》《游艇安全管理规定》《游艇操作人员培训大纲》为纲，系统重建从游艇分类、船舶结构、驾驶操纵到航行安全、应急救助与适任考试的完整实操与考试体系。学完这些章节，就写完了游艇与小型船舶驾驶的全部内容。

## 对标教材

- 交通运输部《游艇安全管理规定》
