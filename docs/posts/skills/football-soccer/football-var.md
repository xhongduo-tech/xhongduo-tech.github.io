## 为什么 VAR 值得单独一章

规则第 5 章在 2018 年迎来了一次革命性补充——**VAR（视频助理裁判，Video Assistant Referee）**。它把摄像机、回放、通讯耳机引进了裁判系统，让足球判罚从「肉眼决断」迈向「技术复核」。但 VAR 也带来了新的争议：回放线怎么画？「清晰明显错误」怎么定义？为什么有的球 VAR 看了半天还不判？理解 VAR，不是背几个「VAR 可介入的情形」，而是理解一套**「人机协同的决策协议」**——它设定了技术介入的边界、触发条件与纠错逻辑。<span class="marginnote">本站「从极限到大模型」里反复出现「人在回路」（human-in-the-loop）的概念——VAR 正是足球场上的「人在回路」：机器提供回放与数据，但最终决策仍由裁判员作出。技术与人的边界如何划定，在这里得到了最直观的展示。</span>

## 1 VAR 是什么：一套「场外复核系统」

VAR 并不是「一个人」，而是一个**技术团队 + 软件 + 回放协议**的整体：

**视频助理裁判（VAR）**：坐镇场外视频操作室，持续观看比赛，**不主动干扰**裁判的正常执法，只在出现「清晰明显错误」或「被遗漏的严重事件」时介入。
**助理视频助理裁判（AVAR）**：协助 VAR 处理回放、操作机位。
- **重放操作员（RO）**：操控多路摄像机回放与画面合成。
- **场边回看监视器（RSO）**：位于场边的专用回放屏，供主裁判现场查看。

VAR 的核心设计原则是**「最低干预、最大收益」（minimal interference, maximum benefit）**：它不是一个「重新执法」的系统，而是对裁判的**明显误判**进行纠正的**安全网**。<span class="marginnote">「最低干预」原则是 VAR 的灵魂：VAR 不能因为「我觉得另一个判罚更合理」而推翻裁判，只有当原判罚是<strong>清晰明显错误</strong>时才能介入。这把「主观争议」挡在 VAR 之外，只保留「客观错误」的纠正空间。</span>

## 2 VAR 可介入的四种情形

VAR 并非对场上所有判罚都复核。规则明确规定，**只有四种「比赛改变性决定」可以触发 VAR 介入**：

1. **进球 / 不进球**：核查进球前是否存在犯规、越位、手球、球是否出界等。
2. **罚球点球判罚 / 不判罚**：核查点球决定是否正确。
3. **直接红牌**（不含第二张黄牌）：核查红牌是否正确。
4. **错误身份**（裁判将犯规队员认错）：纠正出示给错误队员的黄牌/红牌。

这四种情形之外，VAR **不介入**——比如普通的界外球、角球、黄牌等细节错误，VAR 不会管。<span class="marginnote">记住这四种情形（进球、点球、直红、身份错认），就抓住了 VAR 的边界。设计者刻意把 VAR 限制在「最能改变比赛结果」的决定上，避免它变成对每个小判罚的反复纠缠。</span>

## 3 「清晰明显错误」与「回放协议」

VAR 介入的门槛是**「清晰明显错误」（clear and obvious error）**或**「被遗漏的严重事件」（serious missed incident）**。这是什么意思？

**清晰明显错误**：原判罚在回放下明显站不住脚——例如明显越位却被判进球有效、球明显出界却被判进球。
**被遗漏的严重事件**：裁判没看见、但回放显示应当判罚的严重犯规（如禁区内未被发现的推人）。

当 VAR 认为存在上述情况时，会通过耳机向主裁判**「推荐」**复核。随后有两条路径：

- **VAR 建议 + 主裁采纳**：主裁通过耳机确认后直接改判。
- **主裁亲自回看（OFR，On-Field Review）**：主裁走到场边监视器前亲自查看，再作最终决定。

规则还规定，**所有 VAR 介入的决定都必须通过扬声器或大屏向现场观众播报**，这就是为什么我们在电视转播里常看到「Checking…」的字幕。<span class="marginnote">VAR 的「推荐 + 主裁终决」结构，本质是把「机器给出证据」与「人类保留终审权」分开。这与自动驾驶的「辅助驾驶 vs 全自动驾驶」分级、以及 AI 辅助诊断的「医生终审」逻辑完全同构。</span>

## 4 半自动越位与门线技术：VAR 的「姊妹系统」

VAR 并非孤军奋战，它和另外两项技术协同：

**门线技术（GLT，Goal-Line Technology）**：用高速摄像机或磁场传感器判断球是否**整体越过球门线**，在 1 秒内把「进球/不进球」的信号发送给裁判的手表。<span class="marginnote">门线技术的哲学是「全自动、零延迟」：裁判的手表会震动提示「GOAL」或「NO GOAL」，不需要回放也不需要人工判断。它与 VAR 的分工是：GLT 管「球过没过线」这个纯客观事实，VAR 管「进球前有没有犯规」这类综合判断。</span>
**半自动越位识别（SAOT）**：2022 世界杯首次全面启用，通过追踪球员骨骼点 + 球内芯片，在传球瞬间自动生成越位线，把 3D 画面发给 VAR，缩短越位复核时间（平均约 25 秒）。

这两项技术把 VAR 的「人找证据」升级为「系统给证据」——但**最终决定权仍在裁判员**。

## 5 公式解析：VAR 决策的「必要性」判定

VAR 是否介入，可以抽象成一个简单的逻辑判据：<span class="marginnote">本主题为技术协议型内容，虽无数值公式，但 VAR 介入条件可用布尔逻辑精确表达，故用逻辑式替代传统公式解析。</span>

$$
\text{VAR 介入} \iff \text{属四种情形} \ \wedge\ (\text{存在清晰明显错误} \ \vee\ \text{存在严重遗漏事件})
$$
