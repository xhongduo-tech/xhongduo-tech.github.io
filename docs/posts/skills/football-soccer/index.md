# 足球运动

足球是全球参与度最高、影响力最大的运动项目。以 FIFA《足球竞赛规则》、中国足协《中国青少年足球训练大纲》和《足球运动教程》为纲，系统重建从竞赛规则、基本技术到攻防战术、青少年训练与教练员分级培训的完整足球知识与执教体系。学完这些章节，就写完了从看懂足球、踢好足球到带好一支球队所需的全部内容。

## 对标教材

- FIFA《足球竞赛规则》
- 中国足协《中国青少年足球训练大纲》
