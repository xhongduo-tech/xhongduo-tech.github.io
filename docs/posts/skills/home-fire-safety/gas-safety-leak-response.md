## 为什么从燃气安全开始

电与燃气，是现代家庭的两大能源，也是两大火灾源头。如果电气火灾是「看不见的慢火」，燃气事故就是「来不及反应的爆燃」——燃气泄漏后，在密闭空间里与空气混合达到爆炸极限，只需一个电火花或明火，就是瞬间的爆燃。它留给判断的时间，往往以秒计。<span class="marginnote">燃气事故与电气火灾的时序完全不同：电气火灾多有阴燃与蔓延过程，燃气爆燃则几乎无预警。因此燃气安全的核心不是「会处置」，而是「防泄漏」——把泄漏发生的概率压到最低，把泄漏后的处置动作练成条件反射。</span>

《道德经》讲「慎终如始」——用开始时的谨慎坚持到最后。燃气使用的每一天，都值得用「第一次点火」时的警惕来对待。上一节我们认识了燃烧三要素，燃气正是「可燃物」的极端代表：它易燃、易爆、且常与灶火（引火源）近在咫尺，三要素天然凑齐。

本专题的编排有一条隐藏的线索：从法（消防法）到理（燃烧原理）再到具体的「源」——电气、燃气、厨房。燃气这一篇，是「源」的第二个重点：它既有爆燃的突然性，又有中毒的隐蔽性，是家庭里最需要「慎终如始」对待的能源。

## 1 认识燃气：天然气与液化石油气

家庭燃气主要有两类，它们的物性差异直接决定了安装与泄漏处置的不同，务必分清楚：

| 项目 | 天然气 | 液化石油气 |
| --- | --- | --- |
| 主要成分 | 甲烷（$\ce{CH4}$） | 丙烷（$\ce{C3H8}$）、丁烷（$\ce{C4H10}$） |
| 气态密度 | 比空气轻 | 比空气重 |
| 泄漏后去向 | 向上飘散、易通风排出 | 沉积在低处、不易散开 |
| 爆炸极限（体积分数） | 约 5%–15% | 约 1.5%–9.5% |
| 储存方式 | 管道直供 | 液化气钢瓶、集中供气 |
| 典型使用场景 | 城市管道燃气 | 瓶装液化气家庭、餐饮商户 |

**核心差异在于密度**：天然气比空气轻，泄漏后会向上飘散，开窗通风即可较快排出；液化石油气比空气重，泄漏后会沉积在地面、地下室、下水道等低洼处，不易散去——所以液化气泄漏更危险，也更强调「先关阀、不产生任何电火花」。<span class="marginnote">两个爆炸极限数值值得记住：天然气约 <strong>5%–15%</strong>，液化石油气约 <strong>1.5%–9.5%</strong>。数值越低，说明达到爆炸下限越容易——液化气只要泄漏少量就进入危险区间。</span>

**辨析｜易错点：** 有人以为「燃气都一个样，处置方法通用」。其实恰恰相反：天然气泄漏应**立即开窗通风**（让它上飘散掉），液化气泄漏除了通风，更要警惕**沉积低处**——地下室、地漏、下水道都可能积聚，因此绝对不要在地下室使用液化气，也不要把液化气钢瓶放倒使用。

再补一组现实案例：多起居民楼燃气爆燃事故，事后复盘几乎都能追溯到同一个链条——**胶管老化或接口松动泄漏 → 密闭空间浓度积累 → 开关电器的微小火花引爆**。链条的每一环都可以被日常检查打断：定期换软管、用肥皂水检漏、人离火熄，都是在「防泄漏」上做功。

## 2 燃气使用的日常守则

把「防泄漏」落到实处，是一组可执行的日常守则：

**用气不离人**：烧水、炖煮时人不能离开灶台，防止汤水溢出浇灭火焰导致燃气空放。**保持通风**：使用燃气时开窗或开排风扇，避免密闭空间。**定期换软管**：连接灶具的燃气软管有使用年限，橡胶软管老化、龟裂、被老鼠咬坏都会漏气，应按要求定期更换为合格的燃气专用软管。<span class="marginnote">燃气灶具的判废年限是 <strong>8 年</strong>（燃气燃烧器具安全管理相关规则），超期灶具密封件老化、熄火保护失灵，都是隐患。家里灶具「服役」超过 8 年，该换就换。</span>

**灶具要带熄火保护**：合格的燃气灶在火焰被意外浇灭时会自动切断燃气，这是防止「忘关火」酿祸的关键装置。**钢瓶直立存放**：液化气钢瓶必须直立，远离火源与热源，不暴晒、不卧放。**用后关阀**：睡觉前、出门前，确认灶前阀与钢瓶角阀都已关闭。

还有一类常被忽略的风险在**燃气热水器**：如果安装在通风不良的浴室或密闭阳台，燃气不完全燃烧会产生一氧化碳，导致中毒。热水器排烟管道要保持通畅、使用时开窗通风——**燃气安全从来不止「防爆」，还包括「防中毒」**。这两件事，本专题《烧伤、烟雾中毒等现场急救》还会从急救角度再讲一次。

## 3 泄漏的识别：一嗅、二听、三查

燃气泄漏在发生初期是有「蛛丝马迹」的，学会识别，就是抢出处置的时间：

**一嗅**：天然气与液化石油气本身无色无味，但燃气企业会加入**加臭剂**（如四氢噻吩），使其带有刺鼻的臭鸡蛋味——闻到异味，第一时间警惕。**二听**：接口处或软管破损处可能有「嘶嘶」的漏气声，夜深人静时格外清晰。<span class="marginnote">加臭工艺让「闻味识漏」成为可能：<strong>只要闻到持续不退的燃气臭味，就按泄漏处置流程来</strong>，宁可虚惊一场，不可放过一次。这也是为什么「闻到气味先别开灯」被反复强调。</span>

**三查**：用肥皂水或洗洁精水涂抹在软管接口、阀门处，若出现持续冒泡，即为漏点所在。**严禁用明火查漏**——打火机、火柴靠近漏点，等于在泄漏现场点火引爆。

**辨析｜易错点：** 用肥皂水查漏，发现气泡后又「用布擦干接着用」——这是把「发现」当成了「解决」。检漏的目的是定位漏点，发现问题应尽快报修更换，而不是擦干了事。软管接口处若反复冒泡，多半是密封圈老化，必须更换。

## 4 公式解析：爆炸极限与燃气浓度

燃气泄漏为什么危险？因为燃气与空气混合后，浓度落在一个「危险区间」内，遇火即爆。这个区间用公式表达就是：

$$
\text{LEL} \le C = \frac{V_{\text{gas}}}{V_{\text{room}}} \le \text{UEL}
$$

- $C$：燃气在空气中的体积分数（浓度）；
- $V_{\text{gas}}$：泄漏燃气的体积；
- $V_{\text{room}}$：所在空间的体积；
- LEL 与 UEL：**爆炸下限**与**爆炸上限**——低于下限浓度太低点不着，高于上限氧气不足也点不着，只有落在两者之间才具备爆燃条件。

**逐步拆解这条「危险区间」逻辑**：

- **第一步，记住数值**：天然气 LEL 约 5%、UEL 约 15%；液化气 LEL 约 1.5%、UEL 约 9.5%。**下限越低，越早进入危险区**。
- **第二步，算一个实例**：一间 20 m³ 的厨房里漏入 1.5 m³ 天然气，$C = 1.5 / 20 = 7.5\%$，落在 5%–15% 之间——此时一个火花就足以爆燃。
- **第三步，理解通风的意义**：开窗通风就是**稀释 $V_{\text{gas}}$**，让 $C$ 尽快降到 LEL 以下，脱离危险区间。通风越早、越快，$C$ 下降越急——这就是泄漏应急里「先开窗」排在首位的数学理由。

**辨析｜易错点：** 浓度「太低」和「太高」都不爆，会让人误以为「泄露多了反而安全」——这是致命误读。密闭空间里浓度会持续上升，从「点不着」走到「危险区间」往往只需要几分钟；而且空间并非均匀混合，局部浓度可能早已落在危险区间。**永远按「已经达到危险浓度」来处置，才是最安全的假设。**

这个公式还有一个推论：**泄漏处置要「快」，但不要「慌」**。浓度随时间线性累积，处置每提前一分钟，$C$ 就低一截、危险就小一分；但慌乱中的错误动作（如开灯、打电话、跑动产生静电）反而可能瞬间引爆。冷静、按序、迅速，是唯一正确的节奏。

## 5 泄漏应急五步法：关、开、禁、撤、报

发现或疑似燃气泄漏时，按五步行动，动作要快、要稳：

**关**：立即关闭灶前阀、钢瓶角阀，切断气源。**开**：轻轻打开门窗，让空气对流稀释浓度。**禁**：禁止一切可能产生火花的行为——不开关电器、不按门铃、不用明火、不穿脱产生静电的化纤衣物。**撤**：人员迅速撤离到室外上风向的安全地带。<span class="marginnote">「禁」字最难也最关键：一进门闻到气味，<strong>先在门外停住，别急着开灯</strong>——开关面板的微小火花，就是引爆的导火索。撤到室外再处理，永远安全。</span>**报**：在室外拨打燃气公司客服电话或 119 报警，说清地址与泄漏情况，并到路口引导。

**核心对比：能做什么 / 不能做什么**

| 该做的动作 | 坚决不做的动作 |
| --- | --- |
| 关阀门、开窗通风 | 开关任何电器、按电灯开关 |
| 人员撤离到室外 | 在室内拨打手机或电话 |
| 在室外报警并等待 | 用明火、火柴去「检查」漏点 |
| 提醒邻居撤离 | 回到室内去「收拾东西」 |

这五步法本专题还会在《油锅、电器、燃气等场景化灭火处置》里再次出现——**应急动作的价值，在于平时练成条件反射**，事发时不假思索。

最后补一个「安全阀」：家中可安装**燃气泄漏报警器**，它能在浓度接近下限前发出声光警报，等于给「人耳闻味」加了一层电子兜底。报警器应安装在厨房顶部（天然气）或靠近地面处（液化气），按说明书定期自检、到期更换。

**特别提醒老人家庭**：独居老人对气味的敏感度下降，也常因行动不便在泄漏时犹豫。为老人家庭安装报警器、把燃气公司电话贴在灶台旁、定期帮忙检查软管，都是子女能做的「慎终如始」。

## 6 小结

- 天然气比空气轻（向上飘），液化石油气比空气重（沉积低处），两类燃气的泄漏处置不同。
- 天然气爆炸极限约 **5%–15%**，液化气约 **1.5%–9.5%**，下限越低越危险。
- 日常守则：**用气不离人、保持通风、定期换软管、灶具 8 年判废、用后关阀**。
- 泄漏识别：**一嗅（加臭剂臭味）、二听（嘶嘶声）、三查（肥皂水）**，严禁明火查漏。
- 泄漏浓度公式 $\text{LEL} \le C \le \text{UEL}$，通风的本质是稀释浓度、脱离危险区间。
- 应急五步法：**关、开、禁、撤、报**——先切断气源，再稀释，再撤离，在室外报警。
- 燃气安全延伸到一氧化碳中毒：热水器要保证通风，防爆之外还要防中毒。
- 燃气安全的两条主线：**防泄漏**（日常守则＋定期检漏）与**会处置**（五步法练成条件反射）。
- 可加装燃气泄漏报警器作为电子兜底，注意按气体密度选择安装位置；老人家庭更需要报警器与定期检查。

在下一节，我们把燃气放回它最常出没的地方——厨房。灶台、油烟机、燃气软管，那里是家庭火灾的第一现场。这就是《厨房用火安全与烹饪防护》。
