## 为什么从 RCD 安装开始

上一篇讲了 RCD 的原理（零序互感器监测剩余电流），这一篇讲**怎么把它装对、接对**。原理简单，安装却处处是坑：装的位置不对、N 线没穿进去、负荷侧 N 线重复接地……任何一处错误，都会让 RCD 变成「摆设」或「误跳王」。**RCD 是保护人身安全的最后一道自动闸，接线错误等于把这道闸焊死**。这一篇把安装位置、接线路径、测试验收讲透，让你装的每一只 RCD 都真正「守得住」。<span class="marginnote">RCD 安装是低压电工考证与实操的重点。规范（GB 50303、GB 50054）对 RCD 的安装位置、接线方式、负荷侧中性线处理都有明确规定，是验收检查的必查项。</span>

## 1 RCD 在配电箱中的位置

RCD 装在哪里，决定了它能保护哪些回路：

**总保位置**：总开关之后、分路之前，保护全屋。好处是一处保护全部；缺点是任一回漏电全屋跳闸。
**分路位置**：装在某一路（如插座回路）的断路器之后，只保护该回路。故障隔离好，是住宅推荐做法。
**组合形式**：RCD 与 MCB 合装为 **RCBO**，一只开关兼具过载、短路、漏电三种保护，分路使用最方便。

**重点：RCD 只能装在它要保护的那些回路的电源侧，且必须串在相线与中性线上。** 配电箱的接线顺序是：进线 → 总开关 → （RCD 总保）→ 分路断路器 →（分路 RCBO）→ 出线。RCD 装错位置（比如装在总开关之前），保护对象就变了，甚至自己都得不到过载保护。<span class="marginnote">「总保 + 分路保」可以同时存在，形成分级保护：总保用 100 mA/300 mA 防火灾，分路用 30 mA 防人身电击。分级保护的原则——分路先动、总保后动——在《漏电保护原理》一篇已详述。</span>

## 2 接线路径：L 与 N 必须「同进同出」

RCD 接线的核心，是让**相线 L 与中性线 N 一起穿过零序互感器**，这是它测量剩余电流的前提：

**电源侧接线**：L、N 分别接到 RCD 上端的 L、N 端子（电源侧）。
**负载侧接线**：L、N 分别从 RCD 下端的 L、N 端子引出，接到负载回路。
**关键**：RCD **负荷侧引出的 N 线，绝不能再与其他回路的 N 线相连，也绝不能再与 PE 线相接**。

**接线铁律清单**：

1. **L、N 必须同进同出**——漏接 N 线，RCD 测不到不平衡电流，形同虚设。
2. **负荷侧 N 线不得重复接地**——N 线在负荷侧接地，会分流一部分电流，造成 RCD 误跳或动作灵敏度下降。
3. **负荷侧 N 线不得与其他回路 N 线共用**——共用后 RCD 无法区分本回路电流，误动作。
4. **负荷侧 N 与 PE 必须严格分开**——两者相接，等于人为制造漏电回路。
5. **电源侧与负载侧不得接反**——接反后 RCD 的检测线圈失测，保护失效。

**辨析｜易错点：** 新手最常见的错误是「**RCD 只接了相线，没接零线**」——以为零线走 N 排直通就行。但 RCD 必须让 L 和 N 都穿过互感器，N 线不经过 RCD，它就永远测不到「去回不平衡」。**判断接线对不对，看 N 线是否也经过了 RCD 的 N 端子**。<span class="marginnote">还有一个极易混淆的概念：RCD 上标「N」的端子接的是中性线，不是保护地线。接线时把地线接到 RCD 的 N 端子上，是严重的接线错误——地线应接 PE 排，绝不进 RCD。</span>

## 3 安装步骤与要点

RCD（或 RCBO）的安装步骤：

1. **断电验电**：先断开总开关，验电确认无电。
2. **卡装导轨**：将 RCD 卡装到 35 mm 标准导轨上，位置在总开关之后（或作为分路）。
3. **接线**：按「上进下出、L/N 同进同出」接线，端子螺丝拧紧；多股线压端子。
4. **检查**：确认负荷侧 N 线独立、无重复接地、N 与 PE 分开。
5. **送电测试**：合闸送电，按 RCD 的「T」测试按钮，确认能可靠跳闸。
6. **标识**：在 RCD 旁标注所保护的回路。

**接线前的检查**是安装质量的保障：

核对 RCD 额定电流 ≥ 回路计算电流，额定剩余动作电流符合设计要求（30 mA）。
检查接线端子处导线无氧化、绝缘剥切长度合适。
确认 RCD 型号与系统制式匹配（TN-S 系统用 2P/4P 等）。

**重点：装完必须做「测试按钮」自检，这是 RCD 安装的收尾动作。** 按下测试按钮，RCD 应立即跳闸；不跳说明 RCD 本身故障或接线错误，必须排除后再投入使用。<span class="marginnote">测试按钮只能在 RCD 带负载或空载时验证脱扣机构是否正常，它检验的是「RCD 能不能跳」。要验证「漏电时会不会跳」，要用漏电保护测试仪注入真实的剩余电流——那是验收阶段的进阶测试。</span>

## 4 RCD 的选型核对

安装前要核对 RCD 的几个关键参数（呼应《漏电保护原理》一篇）：

**额定剩余动作电流 $I_{\Delta n}$**：人身保护用 **30 mA**；防火灾用 100/300 mA；特殊场所（浴室、医疗）用 10 mA。
**额定电流 In**：≥ 回路计算电流，且 ≤ 导线载流量。
**额定电压 Un**：与系统电压匹配（230/400 V）。
**分断能力 Icn**：与短路电流匹配。
**极数**：单相回路用 2P（或 1P+N），三相回路用 4P（或 3P+N）。
- **动作特性**：AC 型（交流漏电）、A 型（含脉动直流）、F 型、B 型——**含电子设备的回路建议选 A 型或更高**，因为部分电器（变频空调、充电器）会产生脉动直流漏电，AC 型可能检测不到。

**辨析｜易错点：** 「30 mA 的 RCD 用在所有回路」不一定正确——**有电子变频设备的回路（变频空调、洗衣机、充电桩）建议用 A 型 RCD**，AC 型对脉动直流漏电不敏感。选型不是只看动作电流，还要看动作类型。<span class="marginnote">A 型 RCD 能检测 AC 型的所有波形，还能检测脉动直流剩余电流；B 型更进一步，能检测平滑直流。家庭电子设备越来越多，A 型是比 AC 型更稳妥的选择，差价很小。</span>

## 5 常见接线故障与排查

RCD 装好后最常见的两类问题：

**① 误跳（不该跳时跳）**：

负荷侧 N 线重复接地或与其他回路共用——检查 N 线是否独立。
- 回路自然泄漏电流过大（潮湿、线路长、设备多）——用钳形漏电流表测剩余电流，判断是否接近 30 mA。
- 电子设备启动浪涌——换更高动作电流或 A 型，或调整负载分配。

**② 拒动（该跳时不跳）**：

- RCD 接线错误（N 线未进 RCD、电源负载接反）——核对接线。
- RCD 机构故障——按测试按钮验证，坏了即换。
- 动作电流选得过大——核对 $I_{\Delta n}$，按设计值选小一档并确认铭牌与设计一致。
- 误跳与拒动的排查都从「先看接线」开始：N 线是否同进同出、是否重复接地、电源负载是否接反——接线错误占了 RCD 故障的大半。

## 6 安装后的自检清单

RCD 装完，先别急着交工，用一张清单自查一遍：

**核对位置**：RCD 装在电源侧，总保在总开关之后、分路在对应回路断路器之后。
**核对接线**：L、N 同进同出；负荷侧 N 线独立、未重复接地、未与 PE 相接。
**核对型号**：$I_{\Delta n}$ 30 mA（人身保护）、额定电流 ≥ 回路计算电流、A 型优于 AC 型。
**测试按钮**：按下「T」跳闸即合格；不跳先查接线再查机构，坏即更换。
**回路标识**：箱内标注每只 RCD 所保护的回路，方便日后检修。

**重点：RCD 是「装好不算好，测过才算好」。** 一只接错线的 RCD 会给住户「有保护」的安全错觉，比没有更危险。竣工验收用漏电保护测试仪注入真实剩余电流验证脱扣时间，是比按测试按钮更严格的一道把关。

## 7 小结

- RCD 安装的核心是**接线**：L、N 必须同进同出，负荷侧 N 线独立、不重复接地、N 与 PE 严格分开。
- 位置选对：**总保管全屋、分路管单路**；组合形式 RCBO 一只开关兼具过载、短路、漏电三重保护。
- 选型核对四参数：**额定电流、额定剩余动作电流、额定电压、动作类型（AC/A/F/B）**；电子变频设备用 A 型。
- 三相 RCD 靠四线矢量求和测漏电，单相对地漏电同样能检测到剩余电流。
- 潮湿场所（浴室、厨房）可用 10 mA 或 30 mA 的 RCD，动作更灵敏、保护更早。
- 误跳先查 N 线是否重复接地或共用，拒动先按测试按钮再核接线——两类故障都从「接线」入手排查。
- 装完必做测试按钮自检，验收用漏电保护测试仪注入真实剩余电流，确认「该跳时必跳」。
- RCD 是最后一道自动防线，接错线等于焊死这道闸——安装的每一步都值得慢下来核对。
