# 电工（低压配电与建筑电气安装维修）

家庭与建筑低压线路安装、配电箱接线、照明检修关系日常用电安全与建筑电气质量。以《国家职业技能标准—电工（2018年版）》、《电工手册》与 GB 50303《建筑电气工程施工质量验收规范》为纲，系统建立从安全操作、低压线路安装、配电箱接线到照明检修的完整低压配电技能体系。

## 对标教材

- 《国家职业技能标准—电工（2018年版）》
- 《电工手册》
- GB 50303《建筑电气工程施工质量验收规范》
