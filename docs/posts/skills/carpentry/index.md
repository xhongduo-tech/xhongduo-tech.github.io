# 木工（手工木工与家具制作）

手工木工与家具制作是融传统榫卯智慧与现代木作于一体的手作学科，从材料、工具到榫卯结构与室内木装修，系统构建从入门到精进的完整知识体系。以国家职业技能标准、明式家具经典研究与建筑工程施工职业技能标准为纲，学完这些章节，就写完了手工木工与家具制作的全部内容。

## 对标教材

- 《国家职业技能标准—手工木工》（人力资源社会保障部）
- 王世襄《明式家具研究》（生活·读书·新知三联书店）
- JGJ/T 314-2016《建筑工程施工职业技能标准》（住房和城乡建设部）
