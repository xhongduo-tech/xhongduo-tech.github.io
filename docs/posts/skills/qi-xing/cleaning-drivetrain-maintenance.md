## 为什么从清洁与保养开始

前19篇，我们把人从「会骑车」练到了「会训练」；从这一篇起，转向「车」。自行车是一台精密的机械，而机械的天敌是**污垢、磨损与干涩**——泥水混进链条加速磨损，沙砾卡进变速器让它失灵，干燥的链条让每一次踩踏都「吱吱」作响。**日常清洁与传动保养，是整车维护里性价比最高的一项**：投入的是每次骑行后的一二十分钟，回报的是传动系统寿命成倍延长、骑行效率与体验的持续在线。<span class="marginnote">一组直观的数据：<strong>一条清洁润滑的链条，传动效率可达 97% 以上；而一条干涩沾泥的链条，效率会掉到 95% 以下</strong>——看似只有 2% 的差别，在每小时 200 W 的输出下，意味着每小时白白浪费 4–6 W，还让飞轮齿盘加速磨损。清洁保养不是「爱干净」，是「省功率、省钱」。</span>

这一篇讲三件事：**清洁的频率与工具、传动系统的清洗方法、链条润滑的油品选择与上油技术**。

先建立「维护观」：**自行车的维护是「预防性」的，不是「修复性」的。** 真正的维护高手不是「坏了能修好」，而是「在坏之前就发现并处理」。清洁保养最大的价值，正在于它给了你一个**「规律地检查车」的窗口**——每次清洁时顺手看一眼链条拉伸、刹车皮磨损、螺丝松动，绝大多数故障都能在萌芽期被拦截。所以本篇虽然标题是「清洁」，它的深层含义是「**以清洁为载体的定期体检**」。

## 1 清洁的频率与场景

清洁不是「脏了就洗」，而是按骑行场景定频率：

**日常通勤（柏油路，天气晴）**：每周简单清洁一次（擦车架、清链条表面）。
**周末训练/长途**：每次骑完做「快速清洁」（链条 + 传动 + 车架重点部位）。
- **雨骑 / 泥地越野**：每次必洗——**泥水是传动系统最大的敌人**，沾了泥的传动系统若隔夜不处理，沙砾会像研磨膏一样磨穿链条与飞轮。
- **换季 / 长期存放**：深度清洁 + 全面上油 + 检查。

**重点：清洁的黄金时间是「骑行后尽快」。** 泥水与汗液干了以后会结壳、附着更牢；越早清洁，越省力、对车的伤害越小。**「趁湿洗」永远比「干透抠」轻松得多**——这是清洁工作最重要的一条时间原则。<span class="marginnote">「快速清洁」可以控制在 10 分钟以内：湿布擦车架 → 干布擦链条表面 → 检查胎压与刹车 → 完事。不必每次大动干戈，<strong>关键是「高频、及时」而非「低频、彻底」</strong>——很多车友就是「要么不洗、要么大洗」，反而让传动系统长期处于干涩状态。</span>

## 2 清洁工具：一套就够了

清洁工具不需要太多，一套基础工具就够：

| 工具 | 用途 |
| --- | --- |
| 两把刷子（硬/软） | 硬刷清传动，软刷刷车架细节 |
| 链条刷（三面刷） | 深入链条节缝清污 |
| 脱脂剂/专用链条清洁剂 | 溶解链条与飞轮上的油泥 |
| 水桶与两桶水 | 一桶清洁、一桶漂洗 |
| 干布与微湿布 | 擦干车身、擦干传动 |
| 链条油（湿性/干性/蜡性） | 见第3节 |

**辨析｜易错点：** 清洁车有三大「禁忌」——**不要用高压水枪直冲花鼓、中轴与五通**（高压水会打进轴承，冲刷掉润滑脂）；**不要用强碱性清洗剂**（会腐蚀车架漆面与轴承密封圈）；**不要把脱脂剂喷到刹车面**（圈刹的刹车边与碟片沾油后，制动力骤降）。记住：**「水往车身上冲，别往轴承里冲」**——清洁的目标是表面污垢，不是把车「泡」在水里。

## 3 传动系统清洗：链条、飞轮与齿盘

传动系统是清洁的重点，按「链条 → 飞轮 → 齿盘」的顺序处理：

1. **链条**：用脱脂剂喷湿链条，链条刷沿链条刷洗每一节，转几圈踏板让链条转动，让每一节都过一遍刷子。
2. **飞轮**：硬刷蘸脱脂剂，逐个齿缝刷洗飞轮；把后轮拆下清洗飞轮会更彻底（拆轮方法见第4篇《轮胎修补、更换与内胎处理》）。
3. **齿盘**：用布或软刷擦拭齿盘齿面，清理卡在齿间的油泥。
4. **冲洗擦干**：用清水冲洗掉脱脂剂，干布擦干，**晾一会儿再上油**——残留的水分会被链条油「锁」进链条，导致锈蚀。

**重点：清洗后必须「彻底擦干再上油」。** 链条上残留的水分是链条锈蚀与异响的根源——**「洗完就上油」是常见错误**，正确顺序是「洗 → 擦干 → 晾干 → 上油 → 擦掉多余油」。

## 4 链条润滑：油品与上油技术

链条油分三大类，各有适用场景：

| 油品 | 特点 | 适用场景 |
| --- | --- | --- |
| 干性油 | 干得快、不易沾灰 | 干燥天气、公路骑行 |
| 湿性油 | 防水抗冲、耐久 | 雨天、泥地、长途 |
| 蜡性油 | 最干净、摩擦最低 | 室内骑行台、干燥洁净环境 |

上油的技术要点：

**滴在链条内侧**：油滴在内侧链节（靠近齿盘侧），而不是外侧表面——内侧才是摩擦面。
**每节一滴**：转动踏板让链条走完一圈，每节链节滴一滴（或滴在转动的链条上）。
- **静置 + 擦干**：上油后静置几分钟让油渗入链节，再用干布**把链条表面的油擦掉**——链条只需要「内部润」，不需要「表面油亮」；表面多余的油只会沾灰。

**辨析｜易错点：** 上油的两大错误——**「上得越多越好」**（油多只会沾灰，形成黑色油泥，反而加速磨损；正确的状态是「摸起来略润、看起来不油」）与**「只上油不清洁」**（在脏链条上直接上油，等于把沙砾也润滑进去，加速磨损）。**「先清洁、后上油、再擦干」三步曲**，是链条保养的全部秘密。

## 5 保养周期与检查

传动系统的保养建议一个「里程周期表」：

| 里程 | 保养动作 |
| --- | --- |
| 每 200–300 km 或每周 | 快速清洁 + 链条上油 |
| 每 500–800 km | 深度清洁传动，检查链条磨损 |
| 每 1500–2500 km | 用链条尺测链条拉伸，考虑更换 |
| 每 3000–5000 km | 检查飞轮与齿盘磨损，视情更换 |

**重点：链条是传动系统里「先磨损、先更换」的消耗件**——它比飞轮和齿盘便宜得多，**定期换链条（而非等它断裂）能大幅延长飞轮与齿盘寿命**。用链条尺测量：当链条拉伸超过 0.5%（新链条 12 节约 12 英寸，拉伸超过 0.75% 就该换）时，就该换链条了。

除了里程，还有几个「该保养/该换」的直观信号值得记住：**链条异响**（干涩或磨损）、**踩踏跳齿**（链条或飞轮磨损严重）、**变速迟钝**（传动系统阻力大或变速器需要调整，见下一篇《变速系统调试与保养》）、**链条表面发黑结壳**（油泥过多，该深度清洗了）。**把「症状」与「该做什么」对应起来，你就不需要等到车「趴窝」才动手**——大多数传动问题，都是在「还能骑但不对味」的阶段就该处理。<span class="marginnote">一个「换链条还是换全套」的判断：<strong>链条磨损到 0.75% 才换，往往链条已经「磨坏了」飞轮齿盘</strong>——新链条挂上旧飞轮会跳齿。所以最佳策略是「链条在 0.5% 磨损时就换」，此时飞轮齿盘还健康；若已经磨到很晚才换，可能得连飞轮一起换——「早换链条」是最省钱的维护。</span>

### 5.1 清洁保养常见错误自查

| 错误现象 | 可能原因 | 纠正方法 |
| --- | --- | --- |
| 链条没多久就锈 | 洗后没擦干就上油 | 洗后擦干晾干再上油 |
| 链条沾满黑泥 | 上油太多、没擦表面 | 上油后擦掉表面多余油 |
| 花鼓/中轴异响 | 高压水枪冲进了轴承 | 别直冲轴承、改用水桶+布 |
| 刹车变软 | 刹车面沾了油/脱脂剂 | 清洁时避开刹车面 |
| 传动还是卡 | 只上油不清洁 | 先清洁、后上油、再擦干 |

这张自查表把「清洁保养的常见翻车」对应到纠正动作。**清洁的本质是「去污 + 保护」两道工序**——只去污（洗）不保护（上油），链条会锈；只保护（上油）不去污，链条会被油泥糊住。**两道工序缺一不可，顺序也有讲究**：先清洁、后润滑，这是传动保养唯一的正确顺序。

## 6 小结

清洁保养是进入「车辆维护」世界的第一扇门——它门槛低、见效快，却会让你迅速建立「机械感」：什么该上油、什么不能沾水、哪个螺丝会松。这种「机械感」正是后续刹车、变速、轮胎等所有维护章节的共同基础。**先把车洗明白，才谈得上把车修明白**——每一台状态良好的车，都从一次次认真的清洁开始。

- 清洁按场景定频率，**「趁湿洗」永远比「干透抠」轻松**；快速清洁 10 分钟即可完成。
- 清洁三大禁忌：**不冲轴承（花鼓/中轴）、不用强碱、不让刹车面沾油**。
- 传动清洗顺序：**链条 → 飞轮 → 齿盘 → 冲洗 → 擦干晾干**。
- 上油三步曲：**先清洁、滴内侧、擦表面**；链条「内部润、表面不油」才正确。
- 保养周期：每周快速清洁、500–800 km 深度检查、**链条在 0.5% 拉伸时更换**最省钱。
- 把「异响、跳齿、变速迟钝、链条结壳」当作保养信号，别等车「趴窝」再动手。
- 清洁保养是「省功率、省钱」的投资：一台干净的传动系统，让每一脚踩踏都物有所值。
- 维护是「预防性」而非「修复性」：把清洁当作定期体检，故障在萌芽期就被拦截。

在下一节，我们处理整车最关键的安全部件：**刹车系统调整与维护**。传动保养让车「走得顺」，而刹车保养让车「停得住」——制动系统，是永远不能等到坏了才修的部分。
