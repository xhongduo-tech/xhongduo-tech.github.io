## 为什么从变速系统继续

刹车让车「停得稳」，变速则让车「骑得省」。一篇好的变速系统，会让链条在每一个齿比间「咔哒」一声精准到位；一套失调的变速，则表现为**跳齿、拖链、变速慢半拍**——骑起来像在跟一台闹脾气的机器搏斗。<span class="marginnote">变速系统失调的代价不只是烦人：<strong>链条在大盘与飞轮间反复摩擦、跳齿，会加速链条与飞轮齿片的磨损</strong>，传动寿命可能缩短一半。调变速省下的，是整套传动系统的人民币。</span>

这一篇讲变速系统的完整维护链条：**变速机构的认识与工作原理、前拨与后拨的调试方法、变速系统的日常保养**。上一章《日常清洁与传动系统保养》管的是「干净」，这一章管的是「精准」——两者配合，传动才既长寿又好用。

## 1 变速系统怎么工作：从拨杆到齿片的力与线

**核心概念：拨链器（derailleur）**。现代自行车的变速系统由四个环节构成：**变速拨杆**（指拨或手变）→ **变速线** → **前拨/后拨** → **齿盘/飞轮**。车手拨动指拨，拉动变速线，后拨的平行四边形机构推动导轮把链条拨到相邻的飞轮齿片，完成换挡。

**重点：后拨的「限位」与「张力」是两套独立机构。** 后拨上有两枚限位螺丝——**H 螺丝**（高速位，限制链条向外，对应最小飞轮齿片）与**L 螺丝**（低速位，限制链条向内，对应最大飞轮齿片）——它们决定后拨移动的**两个端点**；而张力螺丝决定链条的松紧。调变速的第一步永远是「用限位螺丝定住端点，再用微调旋钮调中间」，顺序颠倒就会越调越乱。<span class="marginnote">把限位螺丝想象成两堵墙：<strong>H 墙挡住链条不让它掉到飞轮外侧（掉链侧），L 墙挡住链条不让它卷进辐条</strong>。墙的位置错了，链条要么掉到车架侧，要么卡进辐条——所以限位螺丝也叫「防掉链螺丝」。</span>

**辨析｜易错点：** 很多人一遇到变速不准就拧限位螺丝，这是最常见的误区。**限位螺丝只在「变不到最大/最小齿片」时才有用**；如果变速问题是「中间齿片不准、上不去下不来」，那属于**线张力**问题，该调的是微调旋钮，而不是限位螺丝——动错地方，等于把门框拆了去修门的铰链。

## 2 后拨调试：一套标准的五步流程

后拨是变速系统里最常需要调整的部分，调试有一套标准流程：

1. **检查前提**：变速线与导轮干净无油泥；后拨吊耳（连接车架的金属片）不变形。**吊耳弯曲是「变速怎么调都不准」的头号隐藏原因**——它歪了，整个后拨的几何就歪了。
2. **调 H 限位**：把链条手动放到最小飞轮齿片，松开变速线，转动 H 螺丝使导轮与最小齿片精确对齐。
3. **调 L 限位**：把链条放到最大齿片，转动 L 螺丝使导轮与最大齿片对齐，保证链条不上不下的位置没有异响。
4. **拉紧变速线**：锁紧变速线锚固螺丝，此时链条应在最大齿片上（线最短的位置），保证张力基准正确。
5. **微调张力**：逐挡拨动指拨，用小半圈为单位调整微调旋钮——**上挡（从小齿片往大齿片）不利，逆时针旋松线管（增加线张力）；下挡（从大齿片往小齿片）不干脆，顺时针旋紧（减小线张力）**。<span class="marginnote">记忆口诀：「上不去，松线管；下不来，紧线管。」上挡需要更大的线张力把后拨往内侧拉，下挡则靠后拨弹簧回弹，张力过大反而拖泥带水。<strong>每次都只调小半圈，调完骑两下验证，再决定是否继续</strong>——微调的原则是「小步快跑」。</span>

**重点：变速线张力随使用会变化。** 新线在最初几百公里会「拉伸」（实际是外套管头被压紧、内线稍微伸长），所以新车/新线装好后头几次变速不准是正常现象，用微调旋钮补张力即可，不必怀疑调整流程错了。

## 3 前拨调试：变速的「第二道门」

前拨（控制链条在大盘/小盘间切换）的调整逻辑与后拨不同——它不追求「精确到位」，而是追求「不蹭链、能切换」。

**高度与角度**：前拨外导板下沿与大盘齿尖的间隙约 1–2 mm；导板应与牙盘平面平行，否则会蹭链。
**H/L 限位**：L 限位保证链条从小盘切上大盘时不掉向内侧；H 限位保证链条从大盘切下时不会被导板推到外侧。<span class="marginnote">前拨限位的一个实用判断法：<strong>切到最大盘后，外导板与链条之间应留出约 1 mm 空隙</strong>——太贴会蹭链发出「嗒嗒」声，太远则上盘不干脆。空隙对了，前拨就安静了。</span>
**半档与微调**：许多公路车手变有「半档」功能，用于大盘配飞轮两端时微调前拨位置、消除蹭链。变速时若听到蹭链声，先想到半档，再想限位。

**辨析｜易错点：** 前拨蹭链最常见的误判是「限位没调好」，其实大部分蹭链发生在**大盘配最大飞轮（大对大）或小盘配最小飞轮（小对小）** 的交叉齿比下——这不是故障，而是变速的固有几何限制。**正确的应对是换挡避开交叉齿比**，而不是反复调前拨去对抗物理规律。

## 4 变速系统的日常保养

变速系统的保养与传动系统保养一脉相承，重点在「线」与「关节」：

**变速线**：内线定期上轻质润滑油（或使用特氟龙涂层线）；线管老化、折弯处发涩时，变速会「变重」，此时应更换线管而非加更多油。
**导轮与关节**：后拨导轮是传动里最容易积泥的部分，清洁后上油，保证转动顺畅。
- **检查磨损**：飞轮与链条是同步磨损的——链条拉长后会「咬坏」飞轮齿片。用链条磨损尺测量，链条拉伸超过 0.75% 即应更换；**若飞轮齿片已磨成钩状，单换链条反而会导致跳齿**，需连飞轮一起换。<span class="marginnote">「链条磨损尺」的 0.75% 与 1% 两档：<strong>0.75% 是公路车/山地车的换链线，1% 是极限</strong>。等到 1% 才换，飞轮多半已经跟着报废——换链条的时机越早，整组传动的总花费越省。</span>

**重点：变速「不准」与「不响」是两个不同的维修目标。** 精调之后，变速应当「安静、干脆、到位」三者兼备。如果变速过程中发出持续摩擦声，说明链条与导板/邻片有干涉；如果变速后链条没完全咬合齿片，会有「咔咔」的滑齿声——**这两类声音都说明变速没调到位，不要用「骑快了就不响」自我安慰**。

## 5 公式解析：齿比与变速的「省力逻辑」

变速系统的最终目的，是把踩踏功率输出在最合适的转速（踏频）上。这里的关键量是**齿比**：

$$\text{齿比} = \frac{T_{\text{牙盘}}}{T_{\text{飞轮}}}$$

- $T_{\text{牙盘}}$：牙盘（曲柄侧）齿数，如 52 T。
- $T_{\text{飞轮}}$：飞轮（后轮侧）当前齿片的齿数，如 12 T。
- 齿比 52/12 ≈ 4.33：曲柄转一圈，后轮转 4.33 圈——**省力换速度**，适合平路高速。

而**踏频**（每分钟曲柄圈数）与速度的关系是：

$$v = 2\pi r \cdot \frac{\text{踏频} \cdot T_{\text{牙盘}}}{60 \cdot T_{\text{飞轮}}}$$

- $v$：车速（m/s）。
- $r$：车轮半径（m），约 0.34 m（700c 公路车）。
- 踏频：推荐区间 80–100 rpm，经济巡航约 90 rpm。

**看懂这条式子的意义**：同样的踏频下，齿比越大速度越快；同样的速度下，齿比越小、踏频越高、肌肉负担越轻。**变速系统就是在「随时切换齿比、把踏频维持在舒适区间」**——所以变速调得准不准，直接影响你能否一直踩在 90 rpm 的「甜点」上。若齿比跳档、链条打滑，踏频被迫忽高忽低，做功效率与膝盖负担都会恶化。<span class="marginnote">这个「甜点」区间也解释了为什么变速系统值得精调：<strong>踏频从 90 掉到 70，同样的功率下每一脚都要多踩大约 30% 的力</strong>——膝盖承受的负荷直线上升。调好变速，是性价比最高的「护膝工程」。</span>

## 6 术语速查表

变速系统的术语常被混淆，这里一次理清：

| 术语 | 含义 | 一句话要点 |
| --- | --- | --- |
| 拨链器 | 拨动链条换挡的机构总称 | 分前拨与后拨 |
| 前拨 | 控制链条在大盘/小盘间切换 | 追求「不蹭链、能切换」 |
| 后拨 | 控制链条在飞轮齿片间切换 | 调试的核心部件 |
| H 限位 | 限制后拨向外（最小飞轮） | 防链条掉到外侧 |
| L 限位 | 限制后拨向内（最大飞轮） | 防链条卷进辐条 |
| 微调旋钮 | 细调变速线张力的旋钮 | 「上不去松线管，下不来紧线管」 |
| 张力螺丝 | 调整链条松紧的螺丝 | 与限位螺丝是两套机构 |
| 吊耳 | 连接后拨与车架的金属片 | 弯曲是「怎么调都不准」的头号元凶 |
| 导轮 | 后拨上引导链条的小轮 | 易积泥，需定期清洁上油 |
| 齿比 | 牙盘齿数 ÷ 飞轮齿数 | 齿比越大，同踏频下速度越快 |
| 踏频 | 每分钟曲柄转数 | 甜点区间 80–100 rpm |
| 交叉齿比 | 大对大、小对小的大偏斜组合 | 蹭链是几何限制，应换挡避开 |
| 半档 | 公路手变的中间档位 | 用于消除大齿比下的蹭链 |
| 链条磨损尺 | 测量链条拉伸量的工具 | 拉伸超 0.75% 应换链 |

**常见误区速查**：

| 误区 | 正确的认知 |
| --- | --- |
| 变速不准就拧限位螺丝 | 中间齿片不准调微调，限位只管两个端点 |
| 新线装好就一劳永逸 | 新线最初几百公里会拉伸，需微调补张力 |
| 蹭链就是前拨没调好 | 交叉齿比蹭链是物理限制，应换挡而非硬调 |
| 链条磨坏了才换 | 0.75% 就换，等 1% 飞轮多半也报废 |
| 变速「响」但「能骑」就没事 | 滑齿声说明没咬合到位，长期会加速磨损 |

## 7 小结

- 变速系统 = 拨杆 + 线 + 拨链器 + 齿片，后拨有两套独立机构：限位螺丝定端点、微调旋钮调张力。
- 后拨调试五步：查前提（吊耳）→ H 限位 → L 限位 → 锁线 → 微调；口诀「上不去松线管，下不来紧线管」。
- 前拨追求「不蹭链、能切换」：高度 1–2 mm、限位留 1 mm 空隙、善用半档。
- 交叉齿比（大对大、小对小）蹭链是物理限制，应换挡避开而非硬调。
- 传动保养三件事：线上油、导轮清洁、链条磨损测量（0.75% 换链）。
- 齿比与踏频是变速的数学内核：变速的目的就是把踏频锁在 80–100 rpm 的甜点区。
