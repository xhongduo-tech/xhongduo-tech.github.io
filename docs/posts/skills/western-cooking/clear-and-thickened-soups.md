## 为什么从汤品开始

前几课备好了高汤与酱汁，本课把它们端上桌——**汤品（soup）**。西式汤品按「清与浓」分成两大类：清亮见底的 **consommé（清汤）** 与浓稠顺滑的 **velouté、奶油汤** 等。汤是西餐菜单的前菜主力，也是检验高汤功底的第一道考场。<span class="marginnote">Escoffier《Le Guide Culinaire》的汤品篇从「基础高汤」出发，把整个汤的世界分成「清汤」（potages clairs）与「浓汤」（potages liés）两大族——<strong>理解了这两族，你就能理解几乎所有西式汤品的配方骨架</strong>。</span>本课从分类讲起，重点落在「澄清」与「增稠」两个技术核心上。

## 1 汤品的两大族谱

西式汤品先按「是否澄清、是否增稠」分成两大族，再往下细分：

| 汤型 | 代表 | 基底 | 特征 |
| --- | --- | --- | --- |
| 清汤 | Consommé、清鸡汤 | 澄清高汤 | 透明见底、鲜味集中 |
| 浓汤—velouté 型 | 鸡蓉汤、鱼汤 | 白高汤 + roux/蛋黄 | 细腻浓稠、顺滑 |
| 浓汤—奶油型 | 奶油南瓜汤 | 蔬菜泥 + 奶油 | 浓郁绵密 |
| 浓汤—蔬菜泥型 | 蔬菜浓汤（purée） | 蔬菜打成泥 | 厚重、原味 |

<span class="marginnote">判断一碗汤属于哪一族，看两点：<strong>是否「见底」（清）与是否「挂勺」（浓）</strong>。清汤考验「提取与澄清」，浓汤考验「增稠与平衡」——两种功夫，两条路线。</span>本课聚焦清汤（尤其 consommé）与最常见的浓汤类型。

## 2 公式解析：清汤澄清的「蛋清比例」

清汤（consommé）的核心是**澄清（clarify）**：把浑浊的高汤变得晶莹剔透，同时浓缩鲜味。CIA 教材的经典手法是用**蛋清澄清法**，配比是理解它的钥匙：

$$蛋清 : 汤 = 约 1 : 8 \quad \text{（每 4 升汤约用 4–6 个蛋清）}$$

把澄清动作拆成三步：

- **第一步，打散蛋清**：蛋清与少量冷水打匀，可加一点蔬菜丁（洋葱、胡萝卜、西芹）帮助「吸附」。
- **第二步，注入热汤**：把蛋清液倒入微沸的高汤中，轻轻搅动后停止。加热中蛋清逐渐凝固成絮状「蛋白筏」（raft）。
- **第三步，吸附过滤**：蛋白絮在漂浮过程中像「磁铁」一样吸附汤中的悬浮杂质与脂肪，把浑浊物裹住沉底。用细筛滤出，即得清亮的清汤。

**为什么是约 1:8**：蛋清太少吸附力不足，汤仍浑浊；太多则蛋白味过重、成本浪费。**温度也很关键**——汤必须热（90°C 上下）但不可剧烈沸腾，否则蛋白打散混入汤中反而更浑。澄清后的清汤风味比原汤更集中，因为杂质与脂肪被一并带走，鲜味却留在汤里。

## 3 Consommé：清汤的「皇冠」

**Consommé（清汤）**：澄清、浓缩、调味后的透明汤品，被视为清汤的极致。它的关键是「浓缩」——澄清后常需再收一下，让鲜味更集中、质感更「有分量」。

经典清汤的层次感来自加料：**鸡清汤（consommé de volaille）**、**牛肉清汤（consommé de boeuf）**、**鱼清汤**等，各有风味。上桌前配以精细的装饰料（garnish）：切得极细的鸡丝、胡萝卜细丝、香草、小馄饨等——**清汤的装饰讲究「少而精」**，漂浮物太多反而破坏清亮。

<span class="marginnote">一份完美的 consommé 是西餐前菜基本功的「试金石」：它没有酱汁遮挡、没有浓稠掩盖，<strong>一眼就看得出高汤与澄清的功夫</strong>。许多高级餐厅把「双澄清」或「反复过滤」作为卖点——清汤越清，越见功力。</span>

## 4 浓汤：从 velouté 到奶油汤

浓汤（thickened soup）是与清汤相对的大家族，靠**增稠**获得「挂勺」的质感。三种常见路线：

**Velouté 型浓汤**：白高汤 + roux 增稠 + 配料煮软打匀。例：鸡蓉汤——鸡高汤、黄油 roux、熟鸡蓉与蔬菜，最后加奶油收尾。它既有高汤的鲜又有糊化的滑。

**奶油汤（cream soup）**：在 velouté 或菜泥基础上加**奶油**。例：奶油蘑菇汤——蘑菇炒香、加高汤煮、打碎、加奶油。判断标准是「丝滑」与「浓郁」的平衡。

**蔬菜泥汤（purée soup）**：把蔬菜直接煮软打成泥，本身自带增稠（利用蔬菜中的淀粉与纤维）。例：南瓜汤、豌豆汤——更「原味」、更低脂。<span class="marginnote">区分三类浓汤有个小诀窍：<strong>velouté 靠「roux + 高汤」、奶油汤靠「奶油 + 乳化」、蔬菜泥汤靠「蔬菜自身打泥」</strong>——看它「为什么稠」，就知道它是哪一类。</span>

## 5 浓汤的配方逻辑：食材 : 液体 : 增稠剂

浓汤做得好不好，往往不是配方复杂与否，而是**三要素的比例**。用一条「平衡式」概括：

$$浓汤质感 = \text{食材（主体）} + \text{液体（载体）} + \text{增稠（roux/奶油/菜泥）}$$

拆开看三个旋钮：

- **食材**是主角：决定风味方向。蘑菇、南瓜、芦笋、土豆……选料决定汤的性格。
- **液体**是载体：多用高汤（比水鲜）、部分用牛奶（比水滑）、也可用蔬菜水（保留营养）。液体太多汤稀，太少汤稠如粥。
- **增稠**是质感：roux 给「糊感」、奶油给「滑感」、菜泥给「厚重感」。增稠不足汤「像水」，过度则「像酱」。

**调味的节奏**：浓汤通常「**先淡后咸**」——高汤本身带味，加盐要克制；出锅前用奶油或黄油「点亮」（round off）口感，再加一勺酸（柠檬汁、醋）平衡油腻。**「淡可救，咸难救」**在这里同样成立。

## 6 汤品的上桌与保存

汤品的呈现与保存也有讲究：

**上桌温度**：清汤宜烫（滚热上桌），浓汤温润（微烫不烫嘴）。餐具先温盘，汤凉了风味大打折扣。
**装饰**：清汤饰以细丝与香草，浓汤饰以奶油涡纹、香草油、脆面包丁（croutons）——装饰要「点睛」而非「盖味」。
**保存**：汤类含高汤与奶油，易变质。冷藏 ≤4°C、尽快使用；含奶油/蛋黄的汤**忌反复加热**（乳化破裂、质地变稀），最好当日制作当日用。

<span class="marginnote">浓汤反复加热会「越热越稀」：奶油与淀粉体系在反复煮沸中破乳化、断裂——这就是为什么高档餐厅的奶油汤都是<strong>「订单现做」</strong>，而不是提前一大锅。汤的「新鲜度」是品质的一部分。</span>

## 7 汤品的菜单角色与搭配

汤在西餐菜单里不只是「一碗汤」，它有自己明确的「段落角色」：

**作为前菜（Starter）**：正式菜单里汤常是「前菜之后、主菜之前」的过渡——「清汤开场、浓汤垫场」。法式菜单「汤（potage）常在主菜前」，既暖胃又为味蕾「调音」。

**作为主菜（Main）**：加足料的重型浓汤（炖菜汤、海鲜汤）本身就是一餐——配面包即可成「一顿饭」，是午餐与简餐的常客。

**汤与面包的搭配**：西餐「汤 + 面包」是经典组合——法棍蘸浓汤、蒜香面包配清汤。面包的麦香中和汤的浓淡，也能「吸汁」（呼应面包课）。

<span class="marginnote">汤品还有一条「<strong>温度即呈现</strong>」的讲究：清汤「滚烫上桌」才显鲜、浓汤「微烫不烫嘴」才显滑、冷汤（西班牙番茄冷汤 gazpacho）「冰凉」才是它——<strong>温度错了，汤的性格就错了</strong>。</span>

**经典汤品的地域代表**：法式洋葱汤（洋葱焦糖化 + 牛肉高汤 + 芝士烤面包）、意式蔬菜汤（minestrone）、美式奶油蛤蜊汤（clam chowder）、西班牙番茄冷汤（gazpacho）——**每个地域的汤，都是它高汤与食材文化的浓缩**。研究汤，也是研究一个菜系的「底味」。

**汤品的一个「新手最易翻车」的点：盐的时机**。汤在熬制中会「浓缩」——如果一开始就调到「正好咸」，收汁后就会偏咸；如果到最后才加盐，又可能「不入味」。正确的节奏是：**「先淡后调、出锅前定味」**——煮制中保持「略淡」，起锅前尝味补盐，并预留「收汁后的咸度增量」。<span class="marginnote">「<strong>汤会越煮越咸</strong>」（水分蒸发、咸味浓缩）——这是新手最常踩的坑。专业做法是「<strong>咸度跟着浓度走</strong>」：汤浓了就淡、汤稀了就咸，用「浓度 × 咸度」的联动思维调整，而不是死守一开始的调味。</span>记牢「先淡后调」，你的汤就少了一半的「翻车」可能。

## 8 小结

- 西式汤品分**清汤**（consommé 等）与**浓汤**（velouté、奶油汤、蔬菜泥汤）两大族。
- 清汤靠**蛋清澄清**，经典比例 **蛋清 : 汤 ≈ 1:8**，蛋白筏吸附杂质后过滤。
- **consommé** 是清汤的极致：澄清 + 浓缩 + 精细装饰。
- 浓汤三路线：**velouté 靠 roux、奶油汤靠奶油、蔬菜泥汤靠打泥**。
- 浓汤三要素是**食材、液体、增稠剂**的比例平衡，「淡可救、咸难救」。
- 汤品讲究**烫热上桌、点缀克制、当日现做**，奶油汤忌反复加热。

**汤品课的一个「系统性观察」：汤是「高汤 + 增稠 + 调味」的组合**。回顾本课，你会发现汤没有「新原理」——它只是把已学的**高汤（作为基底）、增稠（roux/奶油/菜泥）、乳化（奶油）、澄清（蛋清）** 重新组合：清汤 = 澄清的高汤，velouté 汤 = 高汤 + roux，奶油汤 = 高汤 + 奶油乳化，菜泥汤 = 蔬菜自身的「增稠」。**「汤是酱汁的姊妹」**：汤与酱共享同一套「液体 + 增稠」语法，只是「稀一点、当汤喝，浓一点、当酱用」。看懂这一点，你就掌握了整个「液体调味」世界的骨架。

**汤品课最后，说一个「汤的治愈感」**：在西方饮食文化里，汤不只是食物，更是「治愈的象征」——病中的鸡汤、冬天的热汤、家里的例汤，都承载着「温暖与关怀」。「<span class="marginnote">「<strong>汤是厨房的温柔</strong>」：它不需要炫技，却最能抚慰人——一碗好汤，是厨师能给出的最朴素的关怀。这也提醒我们：烹饪的终极目的，不只是「好吃」，更是「让人感到被照顾」。</span>」所以学做汤，别只把它当「前菜的技术」，也把它当「传递温暖的手艺」——带着这份「温度」做汤，你的汤会多一层「无法量化」的好。

回顾本课：清汤靠「澄清」，浓汤靠「增稠」，汤品是「高汤 + 增稠 + 调味」的组合——带着这张「汤的地图」，你做任何汤都有「谱」。
