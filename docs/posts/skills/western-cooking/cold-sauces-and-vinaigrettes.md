## 为什么从冷酱开始

上一课学了五种热母酱，这一课轮到「不用火」的酱汁家族：**冷酱（cold sauce）**。冷酱的主角是沙拉、冷盘、三明治、炸物蘸酱，而它的技术核心是两个字——**乳化**。你可能已经吃过无数次蛋黄酱（mayonnaise）与油醋汁（vinaigrette），但未必想过：**油和水明明不相溶，为什么蛋黄酱能把它们「焊」在一起？**<span class="marginnote">乳化（emulsion）是「不相溶液体均匀混合」的物理状态：油滴被包裹在一层「表面活性剂」里，稳定地悬浮在水中，宏观上就成了均匀顺滑的酱。蛋黄酱是「油滴分散在水里」（o/w），黄油是「水滴分散在油里」（w/o）——两种都是乳化，方向相反。</span>理解乳化，你就同时理解了蛋黄酱、油醋汁、Hollandaise，乃至黄油与牛奶的本质。

## 1 冷酱的两大家族

冷酱按「是否乳化」分成两大类，先建立全局观：

| 家族 | 代表 | 乳化? | 质地 |
| --- | --- | --- | --- |
| 乳化型冷酱 | 蛋黄酱、油醋汁 | 是 | 顺滑、浓稠、一体 |
| 非乳化型冷酱 | 番茄沙司、芥末酱、酸奶油酱 | 否 | 由原料本色决定 |

<span class="marginnote">这个划分的实用价值：<strong>乳化型冷酱需要「技术」，非乳化型只需要「调和」</strong>。考试和实操里，蛋黄酱做得好不好，几乎成了冷菜基本功的代名词——它既是酱，又是许多衍生酱的「母酱」。</span>本课重点在乳化型：蛋黄酱（永久乳化）与油醋汁（临时乳化），二者代表两种不同的乳化深度。

## 2 蛋黄酱：油在水中乳状液的标准答案

**蛋黄酱（Mayonnaise）**：蛋黄、油、酸（醋或柠檬汁）与调味料，在搅打中形成的**油在水中乳状液（oil-in-water emulsion）**。

配方比例是理解它的钥匙：

$$1 \text{ 份蛋黄} : 约 6\text{–}8 \text{ 份油} : \text{适量醋/柠檬汁} \quad \text{（体积比）}$$

蛋黄酱成功的三个关键：

- **乳化剂是蛋黄里的卵磷脂（lecithin）**：卵磷脂分子一端亲水、一端亲油，像「双面胶」一样把油滴表面包住，让油滴互相不合并、稳定悬浮。
- **加油要「先慢后快」**：开始时一次只加几滴油，等乳化建立（酱体变稠）后，才能加快加油速度。一开始就猛加油，油滴来不及被包裹，立即破乳。
- **酸是稳定剂也是味道**：醋或柠檬汁让酱体变稀一点、乳化更稳定，同时提供清爽的酸味平衡油腻。

失败时酱体会「油水分离」（broken）——稀薄的、像水一样的液体。急救方法与 Hollandaise 相同：**另取蛋黄，把破乳的酱一滴滴打回去**，乳化被「重新引导」回来。<span class="marginnote">蛋黄酱的乳化其实是一个「自我强化」的循环：油滴越多、酱体越稠，就越稳定——所以「开始慢、中间快、最后猛」是它的节奏口诀。这道物理直觉，和本站《物理化学》里「胶体稳定与表面活性剂」的内容是同一件事。</span>

## 3 蛋黄酱的衍生：一酱变一桌

蛋黄酱是冷菜厨房的「冷母酱」，加上不同加料就变出整桌酱汁：

**Aïoli（蒜泥蛋黄酱）**：蛋黄酱 + 大量蒜泥，地中海风，配炸物与蔬菜。
**Rémoulade（雷莫拉德汁）**：蛋黄酱 + 酸黄瓜粒、刺山柑、芥末、香草，配海鲜与冷肉。
- **Tartar sauce（塔塔酱）**：蛋黄酱 + 酸黄瓜粒 + 洋葱 + 香草 + 柠檬，炸鱼薯条的灵魂蘸酱。
- **Thousand Island（千岛酱）**：蛋黄酱 + 番茄酱 + 酸黄瓜 + 洋葱，沙拉与汉堡。
- **Ranch（牧场酱）**：蛋黄酱 + 酸奶/酪乳 + 蒜 + 洋葱粉 + 香草，美式蘸酱之王。

衍生逻辑与热母酱完全同构：**母酱 + 特征加料 = 新酱**。这印证了上一课的判断——掌握母酱，就掌握了整个酱汁体系。<span class="marginnote">蛋黄酱 + 番茄酱 = 千岛酱这个公式尤其出名，因为它常被戏称为「俄罗斯酱」（Russian dressing）的远亲。记住派生规则，考试时你甚至可以「现场发明」新酱——考官要的是逻辑，不是死记。</span>

## 4 油醋汁：临时乳化的轻盈美学

**油醋汁（Vinaigrette）**：油与醋（或其他酸）混合而成的酱汁，靠**临时乳化（temporary emulsion）**维持。

经典比例是 **3 份油 : 1 份醋**，再加盐、胡椒、芥末与香草：

$$油 : 酸 = 3 : 1 \quad \text{（体积比）}$$
