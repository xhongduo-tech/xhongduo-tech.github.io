## 为什么从冷酱开始

上一课学了五种热母酱，这一课轮到「不用火」的酱汁家族：**冷酱（cold sauce）**。冷酱的主角是沙拉、冷盘、三明治、炸物蘸酱，而它的技术核心是两个字——**乳化**。你可能已经吃过无数次蛋黄酱（mayonnaise）与油醋汁（vinaigrette），但未必想过：**油和水明明不相溶，为什么蛋黄酱能把它们「焊」在一起？**<span class="marginnote">乳化（emulsion）是「不相溶液体均匀混合」的物理状态：油滴被包裹在一层「表面活性剂」里，稳定地悬浮在水中，宏观上就成了均匀顺滑的酱。蛋黄酱是「油滴分散在水里」（o/w），黄油是「水滴分散在油里」（w/o）——两种都是乳化，方向相反。</span>理解乳化，你就同时理解了蛋黄酱、油醋汁、Hollandaise，乃至黄油与牛奶的本质。

## 1 冷酱的两大家族

冷酱按「是否乳化」分成两大类，先建立全局观：

| 家族 | 代表 | 乳化? | 质地 |
| --- | --- | --- | --- |
| 乳化型冷酱 | 蛋黄酱、油醋汁 | 是 | 顺滑、浓稠、一体 |
| 非乳化型冷酱 | 番茄沙司、芥末酱、酸奶油酱 | 否 | 由原料本色决定 |

<span class="marginnote">这个划分的实用价值：<strong>乳化型冷酱需要「技术」，非乳化型只需要「调和」</strong>。考试和实操里，蛋黄酱做得好不好，几乎成了冷菜基本功的代名词——它既是酱，又是许多衍生酱的「母酱」。</span>本课重点在乳化型：蛋黄酱（永久乳化）与油醋汁（临时乳化），二者代表两种不同的乳化深度。

## 2 蛋黄酱：油在水中乳状液的标准答案

**蛋黄酱（Mayonnaise）**：蛋黄、油、酸（醋或柠檬汁）与调味料，在搅打中形成的**油在水中乳状液（oil-in-water emulsion）**。

配方比例是理解它的钥匙：

$$1 \text{ 份蛋黄} : 约 6\text{–}8 \text{ 份油} : \text{适量醋/柠檬汁} \quad \text{（体积比）}$$

蛋黄酱成功的三个关键：

- **乳化剂是蛋黄里的卵磷脂（lecithin）**：卵磷脂分子一端亲水、一端亲油，像「双面胶」一样把油滴表面包住，让油滴互相不合并、稳定悬浮。
- **加油要「先慢后快」**：开始时一次只加几滴油，等乳化建立（酱体变稠）后，才能加快加油速度。一开始就猛加油，油滴来不及被包裹，立即破乳。
- **酸是稳定剂也是味道**：醋或柠檬汁让酱体变稀一点、乳化更稳定，同时提供清爽的酸味平衡油腻。

失败时酱体会「油水分离」（broken）——稀薄的、像水一样的液体。急救方法与 Hollandaise 相同：**另取蛋黄，把破乳的酱一滴滴打回去**，乳化被「重新引导」回来。<span class="marginnote">蛋黄酱的乳化其实是一个「自我强化」的循环：油滴越多、酱体越稠，就越稳定——所以「开始慢、中间快、最后猛」是它的节奏口诀。这道物理直觉，和本站《物理化学》里「胶体稳定与表面活性剂」的内容是同一件事。</span>

## 3 蛋黄酱的衍生：一酱变一桌

蛋黄酱是冷菜厨房的「冷母酱」，加上不同加料就变出整桌酱汁：

**Aïoli（蒜泥蛋黄酱）**：蛋黄酱 + 大量蒜泥，地中海风，配炸物与蔬菜。
**Rémoulade（雷莫拉德汁）**：蛋黄酱 + 酸黄瓜粒、刺山柑、芥末、香草，配海鲜与冷肉。
**Tartar sauce（塔塔酱）**：蛋黄酱 + 酸黄瓜粒 + 洋葱 + 香草 + 柠檬，炸鱼薯条的灵魂蘸酱。
**Thousand Island（千岛酱）**：蛋黄酱 + 番茄酱 + 酸黄瓜 + 洋葱，沙拉与汉堡。
**Ranch（牧场酱）**：蛋黄酱 + 酸奶/酪乳 + 蒜 + 洋葱粉 + 香草，美式蘸酱之王。

衍生逻辑与热母酱完全同构：**母酱 + 特征加料 = 新酱**。这印证了上一课的判断——掌握母酱，就掌握了整个酱汁体系。<span class="marginnote">蛋黄酱 + 番茄酱 = 千岛酱这个公式尤其出名，因为它常被戏称为「俄罗斯酱」（Russian dressing）的远亲。记住派生规则，考试时你甚至可以「现场发明」新酱——考官要的是逻辑，不是死记。</span>

## 4 油醋汁：临时乳化的轻盈美学

**油醋汁（Vinaigrette）**：油与醋（或其他酸）混合而成的酱汁，靠**临时乳化（temporary emulsion）**维持。

经典比例是 **3 份油 : 1 份醋**，再加盐、胡椒、芥末与香草：

$$油 : 酸 = 3 : 1 \quad \text{（体积比）}$$

与蛋黄酱的「永久乳化」不同，油醋汁的乳化是**临时的**：剧烈搅打时油滴暂时分散在醋里，静置几分钟又会分层。所以油醋汁要么现拌现用，要么加一点乳化剂让它持久些——**芥末（mustard）是油醋汁的秘密武器**，它含的黏液质与卵磷脂类似，能显著延长乳化寿命。<span class="marginnote">分辨两者的最简单办法：<strong>蛋黄酱放冰箱隔夜依然一体，油醋汁放一会儿就分层</strong>——分层不是做坏了，而是「临时乳化」的本性。上桌前再摇一摇、拌一拌，又是一杯新酱。</span>

**油醋汁的变体**非常丰富：换醋（红酒醋、苹果醋、雪利醋）、换油（橄榄油、核桃油、芝麻油）、加香草与香料、加蜂蜜或糖（蜂蜜油醋汁）、加番茄膏或蒜（意式油醋汁）。按「3 油 1 酸 + 调味」的骨架自由组合，是西餐冷菜最常用的即兴酱。

## 5 公式解析：乳化比与「破乳」的温度窗口

油醋汁与蛋黄酱看似简单，背后有一组值得量化的关系。以蛋黄酱为例，它的稳定性可以用「油相比例」来刻画：

$$油相体积分数 = \frac{V_{\text{油}}}{V_{\text{油}} + V_{\text{蛋黄}} + V_{\text{酸}}} \quad \text{（蛋黄酱约 0.6\text{–}0.8）}$$

逐项拆解：

- **分子是油的体积**：油越多，酱越稠越浓郁——但超过约 80% 油相，油滴过度拥挤，反而失稳破乳。
- **分母是总相体积**：蛋黄与酸虽占比小，却是「乳化剂 + 稳定剂」的存在，缺了它们油水立刻分离。
- **为什么有上限**：乳化体稳定需要每颗油滴都被乳化剂包裹；油相比例过高时，乳化剂不够「包全」，油滴开始合并——这是破乳的物理学。
- **温度窗口**：乳化反应虽不需加热，但**太冷**（<15°C）油脂结晶、乳化困难；**太热**（>35°C）卵磷脂失活。室温（约 20°C）是乳化最舒服的温度。

同理，油醋汁的 3:1 也是一个「口感平衡点」：油多太腻、酸多太呛。**比例的本质是「风味与稳定性的妥协」，不是玄学。**

## 6 冷酱的安全与保存

冷酱多为生食直接入口，安全格外重要：

**冷藏保存**：蛋黄酱、油醋汁制作后立即冷藏，温度 ≤4°C。
**保质期**：自制蛋黄酱冷藏可存 3–4 天；含大量生蛋黄的酱汁不宜久放，避免沙门氏菌风险——这也是为什么「当日做当日用」是专业厨房的默认规则。
**卫生细节**：用干净无水的器具与容器，避免「以勺回舀」污染整瓶酱；酸能抑制部分细菌，但不能替代冷藏。

<span class="marginnote">一个务实建议：家庭做蛋黄酱，可以选用经巴氏杀菌的蛋黄（pasteurized egg）来降低沙门氏菌风险——风味几乎无差，安全却大不相同。</span>

## 7 冷酱的进阶：风味变体与地域特色

冷酱不只蛋黄酱与油醋汁，它的变体遍布各地——掌握「基底 + 加料」语法，就能看懂整个冷酱家族：

**地中海风**：**希腊酸奶黄瓜酱（tzatziki）**——酸奶 + 黄瓜 + 蒜 + 莳萝；**中东鹰嘴豆泥（hummus）**——鹰嘴豆 + 芝麻酱 + 柠檬 + 蒜；**西班牙蒜味酱（romesco）**——烤红椒 + 杏仁 + 蒜 + 橄榄油。

**亚洲风**：**日本芥末蛋黄酱**——蛋黄酱 + 芥末（wasabi）配炸物；**泰式甜辣酱**——糖 + 醋 + 辣椒 + 蒜（非乳化型冷酱的代表）；**韩国蛋黄酱**——蛋黄酱 + 韩式辣酱配炸鸡。

**拉美风**：**鳄梨酱（guacamole）**——牛油果 + 洋葱 + 番茄 + 青柠；**莎莎酱（salsa）**——番茄 + 洋葱 + 辣椒 + 香菜。

<span class="marginnote">冷酱变体最值得记的启示：<strong>「乳化剂不只有蛋黄」</strong>——酸奶、芝麻酱（芝麻富含卵磷脂类）、芥末都能帮助乳化或直接构成酱体。「基底 + 加料」的语法，在冷酱家族里同样处处适用——这也是本站反复强调的「<strong>用规则生成变体</strong>」在酱汁世界的回响。</span>

**冷酱的「一酱多用」**：一份蛋黄酱或油醋汁，加不同料就能适配前菜、主菜、小吃——这是冷菜厨房「少备多配」的节省之道，也是成本管理在酱汁上的体现。

## 8 小结

- 冷酱分**乳化型**（蛋黄酱、油醋汁）与**非乳化型**两大类，核心是乳化原理。
- 蛋黄酱是**油在水中乳化**，靠蛋黄卵磷脂稳定，加油「先慢后快」。
- 蛋黄酱是「冷母酱」，加料即得 Aïoli、塔塔酱、千岛酱等整桌酱汁。
- 油醋汁按 **3 油 : 1 酸** 即兴组合，属**临时乳化**，加芥末可延长乳化寿命。
- 乳化稳定有量化窗口：油相 60–80%、温度 15–35°C。
- 冷酱生食直入口，**现做现用、冷藏 3–4 天**是安全底线。
