## 为什么从菜单设计开始

进入第 5 篇「出品管理与考核鉴定」，我们从「做菜」走向「定菜单」。**菜单设计（menu design）**是餐厅经营的核心：它既是给客人的「点餐清单」，也是给厨房的「生产计划」，还是给老板的「成本预算」——一份菜单同时是**承诺、排程与账本**。<span class="marginnote">《西式烹调师》职业技能标准把「菜单设计、营养配餐、成本核算」列为高级与技师等级的核心能力：<strong>会做菜的厨师只能守住炉台，会设计菜单的厨师才能掌控一家餐厅</strong>——这是从「厨工」到「主厨」的分水岭。</span>本课讲菜单的构成、配餐平衡原则与设计实操。

## 1 菜单的构成：从单点到套餐

先看一份西式菜单的「段落结构」，它决定配餐的逻辑：

**单点菜单（À la carte）**：每道菜单独定价，客人自由组合。构成按顺序：**前菜 → 汤 → 沙拉 → 主菜（肉/禽/鱼） → 配菜 → 甜点 → 饮品**。单点菜单讲究「每道都能独当一面」。

**套餐菜单（Table d'hôte / Set menu）**：固定价格的完整套餐，通常含「前菜 + 主菜 + 甜点」三至五道。套餐讲究「整体搭配」——从开胃到收尾，口味要有「起承转合」。

**特价菜单（Menu du jour / Specials）**：当日特供，利用当日新鲜食材与库存，灵活调整。

<span class="marginnote">单点与套餐的差别，是「<strong>单点考验每道菜，套餐考验整餐节奏</strong>」。套餐的「起承转合」：前菜清淡开场 → 汤品过渡 → 主菜浓郁高潮 → 甜点甜蜜收尾——这就是配餐的「戏剧结构」。</span>

## 2 配餐的平衡原则：味、质、色、量

配餐不是「把好吃的放一起」，而是「让整餐平衡」。五个维度：

**味型平衡（Taste）**：酸、甜、咸、苦、鲜的节奏——前菜开胃（酸/鲜）、主菜浓郁（咸/鲜）、甜点收尾（甜）。**避免「同一味型连续轰炸」**——两道都辣、两道都甜，会让味觉疲劳。

**质地平衡（Texture）**：脆、嫩、糯、滑的交替——配菜给脆、主菜给嫩、酱汁给滑、淀粉给糯。**「一软一脆」比「全软全脆」高级**。

**颜色平衡（Color）**：白、红、绿、金、棕的搭配——盘有色彩、桌有色彩，视觉先于味觉。

**温度平衡（Temperature）**：冷前菜 + 热主菜 + 冷热兼备的甜点——温度的起伏本身就是节奏。

**分量平衡（Portion）**：前菜少、主菜足、甜点巧——**「一多一少」让客人既吃饱又不被撑**，也控制成本。

<span class="marginnote">配餐的黄金法则：「<strong>每道菜有自己的性格，整餐有自己的弧线</strong>」。单看每道要「立得住」，合看整餐要「有起伏」——这是配餐设计与摆盘「单盘秩序」最大的不同：摆盘管「一盘」，配餐管「一桌」。</span>

## 3 营养配餐：从好吃到「吃对」

菜单设计还要考虑**营养平衡**。西式配餐的「营养三段」：

**三大营养素的比例**：一份均衡套餐大致满足「碳水 50%–60%、蛋白质 15%–20%、脂肪 20%–30%」的能量结构——主菜给蛋白质、配菜与淀粉给碳水、酱汁与油脂给脂肪。

**五类食物搭配**：**蛋白质（肉/鱼/蛋/豆）+ 蔬菜水果 + 谷物（面/饭/面包）+ 奶制品 + 适量油脂**——套餐里最好「样样都有」。

**特殊需求**：素食、低盐、低糖、无麸质、过敏原（坚果、乳、蛋、海鲜）——菜单要标注过敏原，配餐要能灵活替换。<span class="marginnote">过敏原是菜单设计的「红线」：<strong>花生、坚果、蛋、乳、小麦、大豆、鱼、甲壳类</strong>是国际通认的八大过敏原——菜单标注、出品询问、厨房分开储存，是安全责任。本站《食品安全》与《营养学》专题对过敏与配餐有更系统的讨论。</span>

## 4 菜单设计的成本视角

菜单不只是「吃」，还是「账」。设计菜单时，成本与利润直接决定菜品取舍：

**成本率与定价**：上一课《食材成本核算》的公式在这里生效——每道菜的食材成本率控制在 **28%–35%**，定价 = 每份成本 ÷ 目标成本率。

**高毛利菜品的位置**：菜单的「右上角黄金区」放高毛利菜品——顾客视线先落在那里；「招牌菜」用醒目标注与引导语提升点单率。

**少而精的原则**：菜单菜式过多，备货与损耗剧增、出品速度下降——「**菜单越长，毛利越低**」是餐饮管理的经验之谈。<span class="marginnote">「少而精」的成本逻辑：<strong>菜式少 → 备货集中 → 损耗低 → 食材新鲜 → 出品稳定 → 翻台快</strong>——菜单精简不是「不会做」，而是「经营智慧的克制」。</span>

## 5 公式解析：菜单的「结构平衡」

把配餐原则量化，可以用一条「菜单结构」公式把握：

$$\text{菜单平衡度} \approx \frac{\text{高毛利招牌菜}}{1} + \frac{\text{成本合理家常菜}}{2} + \frac{\text{引流低价菜}}{3} \quad \text{（约 1:2:1 配比）}$$

拆开给三条直觉：

- **约 1 份招牌菜**：撑起餐厅印象与高价——毛利最高、品质最好、最能「说故事」。
- **约 2 份家常菜**：撑起日常营业额——客人常点的「安全牌」，成本与口味平衡。
- **约 1 份引流菜**：低价吸引客流——利润薄但带来人气，靠「薄利多销」带动其他菜。
- **组合的直觉**：菜单不是「全部贵」或「全部便宜」，而是「**用 1 道招牌定高度、2 道家常撑销量、1 道引流拉人气**」——三种角色的配比，就是菜单的结构平衡。

菜单设计是第 5 篇的「承上启下」，它与本专题前面内容紧密相连：

## 7 菜单的呈现与营销

菜单设计不只「配餐」，还有「卖菜」——同样的菜，菜单怎么「写」和「排」，直接影响点单率。

**菜单的「阅读次序」**：客人的视线通常先落在菜单的**右上角、再扫向左**（像读书一样）——右上角与首位放「招牌菜」与「高毛利菜」，引导客人先看到它们。<span class="marginnote">「<strong>黄金角</strong>」是菜单设计的常识：右上角的菜最容易被点。把招牌菜放在黄金角 + 用「主厨推荐」标签强化，是成本率与点单率的双赢。</span>

**描述的「诱人化」**：一道菜写「煎牛排」与「炭火煎烤美国西冷配红酒酱汁」，后者的「画面感」更能勾起食欲。**具体的地域、技法、酱汁名**比抽象形容词更能卖菜——但**描述必须如实**，不得夸大（呼应职业守则的「诚信出品」）。

**价格与「锚定」**：菜单上放一两个「高价菜」，能让中价菜显得「划算」——这是「锚定效应」。但高价菜必须真材实料，否则伤害口碑。

**更新与季节**：菜单定期更新——「当季特供」给常客新鲜感，也消化应季食材（呼应蔬菜课的季节观）。**「菜单是活的」**——它随季节、库存、客群不断调整，而非一成不变。

**菜单设计的一条「自检清单」**：设计完菜单，对照这些问题自查——**配餐平衡了吗？**（味型、质地、颜色、温度、分量五维）**成本可控吗？**（每道成本率 28–35%）**厨房做得出吗？**（设备、人手、技能是否匹配）**客人会点吗？**（招牌菜放对位置了吗）**过敏原标了吗？**<span class="marginnote">「<strong>做得出、卖得掉、赚得到、吃得安</strong>」是菜单设计的四把尺子：做不出（能力不符）、卖不掉（定位不符）、赚不到（成本失控）、吃不安全（过敏隐患）——任何一把尺子没过，这道菜就不该上菜单。</span>用这张清单反复推敲，菜单才能从「一张纸」变成「一份可靠的生产计划」。

## 8 小结

- 菜单分**单点、套餐、特价**三种，套餐讲究整餐的「起承转合」。
- 配餐五个平衡维度：**味型、质地、颜色、温度、分量**。
- 营养配餐：**三大营养素比例 + 五类食物搭配 + 过敏原标注**。
- 菜单是账本：成本率 28–35%、黄金区放高毛利菜、**「菜单越长毛利越低」**。
- 菜单结构约 **招牌 : 家常 : 引流 = 1:2:1**，三种角色各司其职。
- 菜单设计连接成本、出品、现代技法与职业考核，是「掌厨」能力的入口。

**菜单设计与「厨师成长」的连接**：菜单设计是「厨师」到「管理者」的分水岭——会做菜的厨师思考「这道菜怎么做好吃」，会设计菜单的厨师思考「这家店怎么持续赚钱、客人为什么再来」。**菜单设计的本质，是把「厨艺」翻译成「生意」**：每一道菜都要同时回答「好吃吗」「贵吗」「做得出吗」「有人点吗」四个问题。掌握了这份「从厨艺到生意」的视角，你就不再只是「掌勺的」，而是「掌店的」——这正是本专题最后一课《等级工考核》里「技师以上」所要求的能力。

**菜单课最后，说一个「菜单的灵魂」**：菜单设计的「技术」（配餐、成本、排版）都学得会，但菜单真正的「灵魂」，是「**定位**」——这家店是给谁吃的？是家庭聚餐、商务宴请，还是年轻人轻食？菜单的风格、价位、菜式都要围着「定位」转。「<span class="marginnote">「<strong>定位对了，菜单就成功了一半</strong>」：给商务宴请设计「轻食菜单」、给社区家庭设计「分子料理菜单」，都是「定位错位」——再好的菜也卖不动。先想清「给谁」，再设计「给什么」。</span>」技术让你「把菜单做对」，定位让你「把菜单做对的人」——两者结合，才是完整的菜单设计。

**菜单课最后，再补一条「小菜一碟」**：设计菜单时，别忽视「小菜」——餐前面包、开胃小菜、佐餐饮品，虽是「配角」，却常常决定「客人对餐厅的第一印象」，也是「低成本高毛利」的利润点。<span class="marginnote">「<strong>小菜不小，利润不小</strong>」：一份成本几分钱的小菜，可能卖出几元，毛利极高——把「小菜」也用心设计，既提升体验又增加利润，是「菜单经营的巧思」。</span>「连小菜都认真」，是一家餐厅「专业」的体现。
