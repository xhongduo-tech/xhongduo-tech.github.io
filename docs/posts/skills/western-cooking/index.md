# 西式烹饪工艺（西式烹调师）

以 CIA《The Professional Chef》与 Escoffier《Le Guide Culinaire》为纲，结合《西式烹调师国家职业技能标准》，系统重建从高汤母酱、基础技法到主菜烹调、出品管理的完整西式烹饪体系。法式/西式烹调是国际餐饮职业教育基石，学完这些章节，就写完了从专业厨房基本功到宴会出品所需的全部内容。

## 对标教材

- CIA《The Professional Chef》（专业厨师）
- Escoffier《Le Guide Culinaire》（烹饪指南）
