## 为什么从收音与解码开始

组合音响里有两类「信号进来」的入口：一类是**收音**（把空中的电波收下来），一类是**数字音源解码**（把 CD、USB、蓝牙里的数字流变成模拟声音）。它们的故障现象都极具特色——收音是「收不到台」「有噪声」「灵敏度低」，解码是「读不出碟」「无声」「爆音」。<span class="marginnote">这一篇是模拟与数字的分界线：<strong>收音电路是纯模拟的高频处理，解码电路是纯数字的逻辑处理</strong>——两类故障的检修语言完全不同，是理解「模拟维修」与「数字维修」差异的好教材。</span>

## 1 收音电路：从天线到检波

### 收音的流程

**天线 → 高频放大/混频（变频）→ 中频放大 → 检波 → 音频输出**。收音机把高频电波搬到一个固定的中频（调幅 AM 465 kHz、调频 FM 10.7 MHz），在中频上集中放大、检波，抗干扰能力强、灵敏度高。

### 收音电路的关键点

**高频头/调谐**：选台与变频，受调谐电压控制；
**中频放大器**：收音性能的核心，决定灵敏度与选择性；
**检波器**：AM 检波、FM 鉴频，把调制信号还原成音频；
- **锁相环（FM）**：FM 立体声解码依赖 38 kHz 副载波恢复。

### 收音常见故障

| 现象 | 故障方向 | 检查点 |
| --- | --- | --- |
| 收不到台 | 高频/本振 | 调谐电压、本振 |
| 灵敏度低、台少 | 高放/中放 | 中放增益、AGC |
| 有噪声 | 天线/接触 | 天线输入、接地 |
| 声音失真 | 检波/鉴频 | 中频失调、鉴频线圈 |
| 收台飘移 | 本振不稳 | 本振电容、电压 |

**易错点｜「收不到台」先查天线**：收音机的天线（或外接天线插口）接触不良，会表现为「收不到台」或「噪声大」。**修收音先确认天线没问题，再查高频电路**——别把天线松脱当成高频头损坏。

## 2 音频解码电路：从数字到模拟

### 解码的流程

组合音响的 CD、USB、蓝牙、光纤等数字音源，都要经过**解码**：**数字信号 → 解码芯片 → 数模转换（DAC）→ 模拟音频 → 前置放大**。解码芯片负责把压缩/编码的数字流还原成 PCM，DAC 再把 PCM 数字流变成模拟电压。

### 解码电路的关键点

- **解码芯片**：如 CD 解码、MP3 解码，负责数字信号处理；
- **DAC 数模转换**：把数字变成模拟，其供电与参考电压决定音质；
- **时钟晶振**：解码的「节拍器」，晶振坏则完全无声或爆音；
- **数字接口**：光纤/同轴/USB 的接收电路。

### 解码常见故障

| 现象 | 故障方向 | 检查点 |
| --- | --- | --- |
| 读不出碟 | 光驱/伺服 | 激光头、主轴电机 |
| 有数字信号但无声 | DAC/解码 | DAC 供电、时钟 |
| 声音爆音 | 时钟/缓冲 | 晶振、数据缓冲 |
| 某输入无声 | 该输入接口 | 接口电路、选择开关 |
| 有杂音/失真 | 电源/接地 | 解码供电、地线 |

**检修解码电路**：先查**供电、时钟、复位**三件套（数字电路的通用入口），再沿「解码 → DAC → 输出」逐级测信号；用示波器看数字接口与 DAC 输出，哪里断了修哪里。<span class="marginnote">数字电路检修与模拟电路最大的不同是「非 0 即 1」：<strong>信号要么完整、要么完全没有，很少「半好半坏」</strong>——所以数字故障查起来更「干脆」，但也更容易被误判为「芯片坏」。</span>

## 3 音频处理电路：DSP 与音效

中高端音响里有一块**音频处理 DSP**，负责环绕声、均衡、动态处理等音效。它的检修要点：

- 供电与时钟（三件套）；
- 数字音频输入输出接口；
- 与主控的 I²C/SPI 控制通信；
- 软件配置（DSP 程序/参数）。

**DSP 故障表现**：无声、只有一路声道、音效失效、机器「卡死」。检修思路与主控板类似——先软后硬、先三件套后芯片。

## 4 核心要点：收音与解码故障速查

| 现象 | 环节 | 第一检查 |
| --- | --- | --- |
| 收不到台 | 高频/天线 | 天线、调谐电压 |
| 灵敏度低 | 中放/AGC | 中放增益 |
| 收台飘移 | 本振 | 本振电容、电压 |
| 读不出碟 | 光驱伺服 | 激光头、电机 |
| 数字无声 | DAC/解码 | 供电、时钟 |
| 爆音 | 时钟/缓冲 | 晶振 |
| 音效失效 | DSP | 三件套、控制总线 |

## 5 公式解析：数字音频的采样与位深

数字音频解码的质量由两个数决定：**采样率**与**位深**。CD 标准是 44.1 kHz / 16 bit。

**每秒数据量**

$$
\text{Bitrate} = f_s \times \text{bits} \times \text{channels}
$$

以 CD 立体声为例：

$$
44.1 \times 10^3 \times 16 \times 2 \approx 1.41\ \text{Mbit/s}
$$

拆解三层含义：

- **第一步，看采样率**：每秒采 44 100 个点，由奈奎斯特定理决定——要还原最高 20 kHz 的音频，采样率至少 40 kHz；
- **第二步，看位深**：每点用 16 bit 表示，决定动态范围（理论约 96 dB）；
- **第三步，看检修含义**：解码电路的时钟必须精确——采样率偏差会让播放**变调或爆音**；晶振精度因此是数字音频的生命线。<span class="marginnote">奈奎斯特定理来自信号与系统：<strong>要无失真地还原一个信号，采样率必须大于其最高频率的两倍</strong>——人耳最高约 20 kHz，所以 CD 采样率定在 44.1 kHz，留了余量。这是数字音频的「第一原理」。</span>

## 6 小结

- 收音链路：**天线 → 变频 → 中放 → 检波 → 音频**；收不到台先查天线，再查高频。
- 解码链路：**数字输入 → 解码芯片 → DAC → 模拟输出**；无声先查供电、时钟、复位三件套。
- DSP 音效：检修「先软后硬」，三件套与控制总线是重点。
- 公式层面：数字音频码率 $= f_s \times bits \times ch$
