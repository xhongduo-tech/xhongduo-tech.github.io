# 家用电子产品维修（电视/投影/音响/机顶盒）

家用电子产品维修是针对电视、投影、音响、机顶盒等消费电子设备的电源、显示与音频电路检修的专门技能。以《国家职业技能标准—家用电子产品维修工》、《彩色电视机维修技术》与《音响设备维修》为纲，从安全规范、开关电源原理到显示电路、音频放大与数字化设备检修，系统建立从结构认知、故障诊断到规范维修作业的完整能力。学完这些章节，就掌握了电视、投影、音响与机顶盒整机检修的核心知识与实操技能。

- 《彩色电视机维修技术》
