## 为什么从视频处理开始

扫描单元解决了「光栅从哪来」，这一篇解决「图像怎么画上去」。视频信号处理链——从视频检波出来的复合信号，到显像管三枪被驱动发光——决定了一台电视**画面亮不亮、颜色对不对、细节清不清晰**。它的故障现象也最有「观赏性」：偏色、无色、图像淡、拖尾、回扫亮线、雪花噪点。<span class="marginnote">视频处理链是「色彩世界的翻译官」：<strong>发射端把彩色信息压缩编码进信号，电视这边再解码还原</strong>。链路任何一环翻译出错，画面就会出现对应的色彩/亮度症状。</span>

这一篇同时讲「视频处理」与「显像管附属电路」，因为两者在检修上是不可分割的——视频链最终把 RGB 信号送到显像管阴极，而显像管能否正确发光，还取决于加速极、聚焦、灯丝这些附属电路。

## 1 视频信号处理流程：从复合信号到 RGB

彩色视频信号进机后，要经历一条完整的处理链：

| 环节 | 功能 | 输出 |
| --- | --- | --- |
| 视频检波 | 从图像中频解出复合视频信号 | 视频信号（含亮度、色度、同步） |
| 亮度/色度分离 | 把亮度和色度分道处理 | Y（亮度）、C（色度） |
| 色度解码 | 从色度信号解出两个色差信号 | R−Y、B−Y |
| 矩阵电路 | 由亮度与色差合成三基色 | R、G、B |
| 末级视放 | 放大 RGB、驱动显像管阴极 | 三枪阴极驱动 |

这条链的每个环节都对应明确的故障症状：**亮度通道坏 → 图像暗、模糊但有色**；**色度通道坏 → 图像明亮但无彩色**（黑白图像正常）；**矩阵电路坏 → 彩色异常或偏色**；**末级视放坏 → 单色缺失或整屏偏色**。

## 2 亮度通道与色度通道

### 亮度通道（Y）

亮度信号代表图像的明暗层次，经亮度延迟线、勾边电路（提升清晰度）、对比度控制后送入矩阵。**亮度通道故障的典型表现**：

亮度信号丢失 → 图像黑暗、只看到彩色轮廓；
对比度失控 → 图像过浓或过淡；
- 勾边电路异常 → 图像轮廓出现镶边、振铃。

### 色度通道（C）

色度信号由色副载波（我国 PAL 制为 4.43 MHz）承载。色度通道内含**色带通、色解码、色同步**，其故障表现：

- 色副载波晶振损坏 → **无彩色**；
- 色同步电路异常 → 彩色失真、色相乱；
- 色度信号弱 → 彩色淡、噪点多。<span class="marginnote">「有彩色，但彩色不稳定、偏紫偏绿」指向色同步；「完全无彩色」指向色解码或晶振。区分两者，是色度故障诊断的第一步。</span>

## 3 显像管附属电路：让三枪好好发光

显像管本身是「没有脚的显示器」，全靠附属电路喂给它各种电压：

**灯丝电压**：约 6.3 V，由 FBT 提供。灯丝不亮，显像管完全没有光栅（但整机其他功能正常）。
**加速极电压**：几百伏，控制电子束起始速度。加速极异常 → 屏幕亮度不足或全黑。
- **聚焦电压**：几千伏，把电子束聚焦成细点。聚焦不良 → 图像模糊、散焦。
- **阳极高压**：20～30 kV，由 FBT 升压。高压不足 → 图像暗淡、尺寸变大。
- **消磁电路**：开机瞬间用消磁电阻给消磁线圈大电流，消除地磁对色纯的影响。**消磁电阻失效 → 屏幕出现彩色斑块**。<span class="marginnote">屏幕一角出现固定色斑，第一怀疑就是消磁失效：<strong>消磁电阻（PTC）冷态导通、热态断开，开机瞬间给线圈冲击电流去磁</strong>。它损坏时屏幕色斑是「印」上去的，换件后开机即消。</span>

### 末级视放与白平衡

末级视放把矩阵送来的 R、G、B 小信号放大到几十上百伏，直接驱动显像管三枪阴极。三枪的放大特性不完全一致，需要在维修中做**白平衡调整**：

- **暗平衡**：调三枪静态工作点，让低亮度时屏幕不偏色；
- **亮平衡**：调三枪增益比例，让高亮度时屏幕保持纯白。

**白平衡失调 → 屏幕偏色，且亮度越低偏色越明显**（暗平衡问题）或越亮越偏（亮平衡问题）。

## 4 核心要点：视频与显像管故障速查

把这条链的常见故障做成速查表：

| 故障现象 | 故障环节 | 优先检查 |
| --- | --- | --- |
| 无图像但有光栅（黑白正常） | 色度通道 | 色副载波晶振、色解码 IC |
| 无图像、黑暗但有彩色轮廓 | 亮度通道 | 亮度延迟线、亮度放大 |
| 整屏偏色（暗处偏） | 暗平衡 | 末级视放静态点 |
| 整屏偏色（亮处偏） | 亮平衡 | 三枪增益、视放管 |
| 图像模糊散焦 | 聚焦电路 | 聚焦电位器、聚焦电压 |
| 屏幕亮度低 | 加速极/高压 | 加速极电压、高压 |
| 屏幕彩色斑块 | 消磁电路 | 消磁电阻、消磁线圈 |
| 图像淡、噪点多 | 视频检波/中放 | AGC、检波电路 |

**易错点｜先分清「光栅问题」还是「视频问题」**：无图像时先看光栅——若光栅正常（有亮底），是视频链问题；若光栅都无，回到扫描与电源篇。**光栅是视频信号的「画布」，画布没了谈何画面**，这个先后顺序不能乱。

## 5 公式解析：亮度公式与色彩矩阵

彩色电视能压缩带宽，靠的是「人眼对亮度敏感、对色彩不敏感」的特性。亮度信号 Y 由三基色加权合成：

$$
Y = 0.30\,R + 0.59\,G + 0.11\,B
$$

拆解三层含义：

- **第一步，看加权系数**：绿色分量占 0.59 权重最高，红色 0.30 次之，蓝色 0.11 最低——这反映人眼对绿光最敏感、蓝光最不敏感。
- **第二步，看公式用途**：发射端用这个公式从 RGB 算出 Y，再传 Y 与两个色差（R−Y、B−Y）；接收端矩阵电路反过来由 Y、R−Y、B−Y 还原出 RGB。
- **第三步，看故障推理**：如果亮度公式里的某一支（比如 R 通道）在矩阵或视放中丢失，屏幕上该基色成分就缺失——**偏色故障，正是某个基色通道增益异常的宏观表现**。<span class="marginnote">这套「亮度 + 色差」的编码，就是今天 HDMI 里 YCbCr 色彩空间的鼻祖：<strong>把 RGB 转成亮度+色差，用更少带宽传同样视觉质量</strong>——学视频处理，其实是在学现代视频编码的第一课。</span>

## 6 检修方法与案例

### 检修路径

1. 先确认光栅正常（亮底存在）——否则回扫描篇；
2. 分清症状类型：无彩色 → 色度链；图像暗 → 亮度链；偏色 → 矩阵/视放/白平衡；模糊 → 聚焦；
3. 用示波器沿链测量：视频检波输出 → 亮度/色度分离 → 矩阵输入 → 视放输出，信号在哪一级消失，故障就在哪一级；
4. 显像管附属电压逐项核对：灯丝、加速极、聚焦、高压，哪项缺失修哪项。

### 一个案例

**案例**：一台彩电，光栅正常，图像清晰但完全无彩色，黑白图像正常。

现象定位：无色但黑白正常 → 色度通道故障，与亮度、扫描无关；
测量：示波器测色度解码 IC 输入端有色度信号，输出端无色差信号；
- 聚焦：查色副载波恢复电路，测 4.43 MHz 晶振两端无振荡波形；
- 处理：更换色副载波晶振，彩色恢复，故障排除。

这个案例再次演示「沿链测量，锁定断点」：输入有、输出无，故障就被卡在解码 IC 及其外围，最终落在晶振上。<span class="marginnote">晶振是「有则秒好、坏则全无」的二元件：<strong>它要么起振要么不起振，几乎没有中间状态</strong>。用示波器一测便知，是色度故障检修里性价比最高的检查点。</span>

## 7 小结

- 视频处理链：**检波 → 亮色分离 → 色解码 → 矩阵 → 末级视放 → 显像管**，每级对应特定症状。
- 亮度通道坏 → 图像暗；色度通道坏 → 无彩色；矩阵/视放坏 → 偏色；聚焦坏 → 模糊。
- 显像管附属电路：灯丝、加速极、聚焦、高压、消磁，各司其职，各有典型症状。
- **白平衡**分暗平衡与亮平衡，对应低亮度/高亮度偏色。
- 公式层面：$Y = 0.30R + 0.59G + 0.11B$
