## 为什么从话筒放大开始

卡拉 OK 是家用音响的核心场景之一，而它的一切都建立在**话筒放大**与**混响**之上：话筒拾到的人声只有毫伏级，必须先放大；干巴巴的直声不好听，要靠混响「润色」。这套电路故障时，最常见的症状是「唱歌没声」「话筒啸叫」「没有回音效果」——都是维修单上高频出现的项目。<span class="marginnote">话筒通道是音响里的「特殊公民」：<strong>它信号最弱、增益最高、离喇叭最近，最容易自激啸叫</strong>——修话筒通道，一半在修电路，一半在修「声学环路」。</span>

这一篇讲清话筒放大、混响与卡拉 OK 电路的组成、故障与检修。

## 1 话筒放大电路：最弱信号的第一站

### 话筒的类型与信号特点

**动圈话筒**：不需要供电，输出信号弱（约 1 mV），阻抗低；
**电容话筒**：需要幻象供电（常见 48 V），信号稍强、灵敏度高。

话筒信号的特点是**微弱、不平衡**，极易拾取噪声，因此话筒放大器（话筒前置）是音响里**增益最高**的一级，常常需要 60 dB 以上的放大能力。

### 话筒放大电路结构

**话筒放大级**通常由两级构成：第一级做低噪声前置放大（把 mV 级放大到百 mV 级），第二级做增益控制与驱动。核心要点：

**低噪声运放**：话筒前级对噪声极其敏感，用低噪声运放；
- **幻象供电**：电容话筒需要 48 V 幻象电源，缺失则电容话筒无声；
- **增益控制**：话筒音量电位器，常与卡拉 OK 音量调节共用。

**话筒无输出的检修**：先查话筒本身（换一只话筒试）→ 查幻象供电（电容话筒）→ 查话筒插座与线缆 → 查话筒放大级供电与运放 → 查增益控制。<span class="marginnote">「换话筒试」是话筒通道检修的第一招：<strong>动圈话筒的引线极易断，电容话筒的电池/幻象供电是薄弱点</strong>——花几秒钟换话筒，能排除一半的「假故障」。</span>

## 2 混响电路：让声音「有余韵」

### 混响的原理

**混响（reverb）**模拟声音在空间中的多次反射，让人声「丰满、有空间感」。卡拉 OK 里，人声经过混响处理后与直达声混合，听起来像是在音乐厅里演唱。

### 混响的实现方式

| 实现方式 | 原理 | 特点 |
| --- | --- | --- |
| 模拟延时（BBD） | 电荷耦合器件延时 | 老式卡拉 OK，噪声较大 |
| 数字混响（DSP） | 数字信号处理算法 | 现代主流，效果丰富 |
| 弹簧混响 | 机械弹簧振动 | 吉他功放常见 |

**数字混响**的核心是一个 DSP 芯片：话筒信号经 A/D 采样 → DSP 处理（产生延时与多次反射）→ D/A 还原 → 与直达声混合。检修数字混响，重点是查**DSP 供电、时钟晶振、A/D-D/A 电路**。

### 混响电路故障表现

**无混响效果**：人声干巴巴——混响通道没工作，或混合比例为零；
**混响有噪声**：BBD 混响噪声大，DSP 电路则查电源纹波；
**混响时有时无**：虚焊、电位器接触不良。

## 3 卡拉 OK 电路：人声与伴奏的「合唱」

卡拉 OK 电路把**话筒人声**与**伴奏音乐**两路信号混合输出，其关键环节：

- **人声通道**：话筒放大 → 混响 → 人声音量控制；
- **伴奏通道**：音源伴奏（CD/MP3）→ 伴奏音量控制；
- **混合电路**：两路信号叠加后送入功放；
- **原唱消音**：部分机型有消原唱功能（把中置声道消除），其开关电路易故障。

### 卡拉 OK 常见故障

| 故障现象 | 故障方向 | 优先检查 |
| --- | --- | --- |
| 话筒无声 | 话筒链 | 话筒、幻象供电、话筒放大 |
| 伴奏无声 | 音源/伴奏通道 | 音源选择、伴奏音量 |
| 无混响效果 | 混响通道 | DSP 供电、晶振、混合比例 |
| 话筒啸叫 | 声学环路 | 增益过高、话筒位置 |
| 唱声与伴奏不同步 | 混响延时 | DSP 延时设置 |

**易错点｜「话筒啸叫」不是电路故障**：啸叫是**声学正反馈**——话筒拾到喇叭放出的声音再次放大，形成自激。它与电路好坏无关，而是**增益过高 + 话筒离喇叭太近**。修「啸叫」的答案在增益与摆位：调低话筒增益、拉远话筒与喇叭的距离、必要时用话筒防啸叫器（陷波器）。<span class="marginnote">啸叫的数学本质是闭环增益超过 1：<strong>喇叭→话筒→放大→喇叭的回路里，只要总增益 ≥ 1 且相位凑到 360°</strong>，就自激。这也是为什么话筒增益旋钮是防啸叫的第一道闸。</span>

## 4 核心要点：话筒与混响故障速查

| 现象 | 故障环节 | 第一检查 |
| --- | --- | --- |
| 话筒无声 | 话筒输入 | 换话筒、查插座 |
| 电容话筒无声 | 幻象供电 | 48 V 幻象电源 |
| 话筒声小 | 增益/话筒 | 话筒增益、话筒灵敏度 |
| 无混响 | 混响通道 | DSP 供电、晶振 |
| 混响噪声 | 电源/延时芯片 | 电源纹波、BBD 芯片 |
| 啸叫 | 增益/摆位 | 降增益、移话筒 |
| 混响时有时无 | 虚焊/电位器 | 补焊、清洗 |

## 5 公式解析：话筒放大增益与信噪比

话筒前级的增益常用 dB 表示，两级放大叠加：

$$
G_{total} = G_1 + G_2 \quad (\text{dB})
$$

例如第一级放大 40 dB、第二级 20 dB，总增益 60 dB——换算成电压倍数约 1000 倍（$60 = 20\log_{10}(1000)$）。拆解三层含义：

- **第一步，看叠加**：两级增益的 dB 值相加，等价于电压倍数相乘——$G_{total} = G_1 + G_2$（dB）对应 $A_{total} = A_1 \times A_2$（倍）；
- **第二步，看换算**：由 $60 = 20\log_{10}(A)$ 解得 $A = 10^{60/20} = 1000$ 倍——把 mV 级话筒信号放大一千倍，正是话筒前级 60 dB 增益的物理含义；
- **第三步，看信噪比**：话筒前级最怕的不是增益不够，而是**噪声跟着一起放大**。信噪比 $SNR = 20\log_{10}(V_{signal}/V_{noise})$，前置级噪声会被同样的增益放大，所以低噪声运放、干净供电是话筒通道的命根。

## 6 检修方法与实战

话筒与混响通道的检修，几个实用方法：

1. **换话筒交叉验证**：话筒无声先换话筒、换线，排除「外设假故障」；
2. **信号注入法**：沿「话筒 → 话筒放大 → 混响 → 混合 → 功放」逐级注入信号，声音消失在哪一级，故障就在哪一级；
3. **供电优先**：话筒放大与混响 DSP 都要多路供电，先量供电再查芯片；
4. **啸叫的现场处理**：降增益、移话筒、拉开与喇叭距离，必要时用陷波器——先解决声学环路，再查电路。

**易错点｜「话筒有噪声」别急着换芯片**：话筒通道噪声常来自三处——话筒线与插座接触、电源纹波、增益过高。先排查这三处外围，再怀疑运放或 DSP，能省很多冤枉钱。<span class="marginnote">修噪声的次序是「先外围、后芯片」：<strong>接触不良、电源脏、增益过猛都造噪声，唯独芯片坏是最后才怀疑的</strong>——这条次序在音响各通道通用。</span>

## 7 小结

- 话筒信号**最弱（mV 级）、增益最高（60 dB 级）**，是音响里最易受噪声与啸叫影响的一级。
- 话筒放大：低噪声运放 + 幻象供电（电容话筒 48 V）+ 增益控制；无输出先换话筒、查幻象供电。
- 混响三实现：BBD 模拟延时、DSP 数字混响、弹簧混响；数字混响检修查供电、晶振、A/D-D/A。
- 啸叫是**声学正反馈**（环路增益 ≥ 1），处理在增益与摆位，不在电路。
- 公式层面：总增益 $G = G_1 + G_2$（dB），60 dB ≈ 1000 倍电压放大。
