# 机修钳工（机械设备维修与装配）

面向国家职业资格目录中的法定职业「机修钳工」，对标《国家职业技能标准—机修钳工》《机修钳工工艺学》与《机械修理手册》，系统重建从钳工基础、设备拆装与零部件修理、装配工艺与精度调整到机床大修与设备管理的机械设备维修与装配完整技能体系。学完这些章节，就写完了机械设备维修与装配的全部内容。
