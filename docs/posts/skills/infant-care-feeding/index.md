# 婴幼儿照护与喂养

以《育婴员国家职业技能标准》、WHO《婴幼儿喂养全球战略》和《中国居民膳食指南》7-24月龄喂养为纲，系统掌握新生儿喂养、洗澡、睡眠、抚触与辅食添加等育儿核心技能。学完这些章节，就写完了从生活照料、喂养膳食到睡眠安全与早期发展的完整婴幼儿照护能力体系。
