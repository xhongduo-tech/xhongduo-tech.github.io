## 为什么从 CPU 选型开始

第 2 篇进入「部件选型」，而选型的第一个决定就是 CPU——因为它**决定了整机的定位与平台**：选 Intel 还是 AMD，选哪一代、哪个插槽，直接锁定了你接下来能买什么样的主板、装什么样的内存。这就像盖房子先定地基：地基定了，上面的结构都得跟着它走。更妙的是，CPU 是整机里与「从极限到大模型」主线咬合最紧的部件——**大模型的每一次推理，最终都编译成 CPU 上的一条条指令**；理解 CPU 的选型参数，就是理解算力如何被量化。

## 1 CPU 的核心参数：读参数表的能力

选 CPU 前，先学会读它的参数表。核心参数有五项：

**核心数（cores）与线程数（threads）**：核心是 CPU 里真正干活的计算单元；线程是操作系统看到的「逻辑处理器」。**超线程（Hyper-Threading）**让一个核心同时处理两个线程，提升并行吞吐。<span class="marginnote"><strong>核心数决定「同时能干几件事」，主频决定「每件事干得多快」</strong>。打游戏重主频（单核性能），视频剪辑、编译代码、跑 AI 训练重核心数（多核并行）。一 CPU 参数表里最常见的错误，就是只看核心数不看单核性能。</span>

**主频与睿频（base / boost clock）**：主频是基础运行频率，睿频（Intel Turbo Boost / AMD Precision Boost）是负载加大时的自动加速频率，单位 GHz。比如「3.5GHz，睿频 5.0GHz」。

**缓存（cache）**：CPU 内置的高速小容量存储，分 L1/L2/L3 三级，离核心越近越快、越小。缓存命中可以避免频繁访问慢速内存。

**TDP（Thermal Design Power）**：散热设计功耗，单位瓦特（W），代表 CPU 满载时需散走的热量，是选散热器的直接依据。<span class="marginnote">TDP 不是「实际功耗」，而是「散热设计参考」——65W TDP 的 CPU 需要压得住 65W 的散热器。第 2 篇「散热方案」会用它做选型：TDP 决定风冷还是水冷、用多大的散热器。</span>

**制程工艺（process node）**：晶体管栅极的最小尺寸（如 5nm、7nm）。制程越小，同样面积塞下的晶体管越多、同性能下功耗越低——这是「每年换代更快」的物理根源。

## 2 两大阵营：Intel 与 AMD

当前桌面 CPU 市场由两家主导，它们的命名规则是选型第一课：

**Intel（酷睿系列）**：命名如 `i5-13600K`。`i` 后数字（3/5/7/9）是定位等级，数字越大越高端；短横线后第一位数字是**代际**（13 = 第 13 代），后三位是具体型号；后缀字母有含义：`K` 不锁倍频可超频，`F` 无核显（必须配独显），`KF` 两者兼备，无后缀默认带核显。

**AMD（锐龙系列）**：命名如 `Ryzen 5 7600X`。`Ryzen` 后数字（3/5/7/9）是定位等级；数字前两位是**代际**（7000 系列 = 第 7 代，对应 Zen 4 架构）；后缀 `X` 高频版，`G` 带较强核显（如 5600G），无后缀默认带核显。

**核心对比表：两家的「对应关系」**

| 定位 | Intel | AMD |
| --- | --- | --- |
| 入门办公 | i3 | Ryzen 3 |
| 主流家用 | i5 | Ryzen 5 |
| 高性能/游戏 | i7 | Ryzen 7 |
| 顶级/工作站 | i9 | Ryzen 9 |

**选阵营不是选信仰，是选「你需要的特性 + 主板平台的生态」**：同价位段两家互有胜负，具体看预算、看是否有核显需求、看主板价格，而不是品牌偏好。<span class="marginnote">一句实用建议：<strong>预算有限且不打算买独显的，选带核显的型号（Intel 无 F 后缀 / AMD G 后缀）</strong>；已经有独显或游戏需求明确的，选同价位无核显的型号，把省下的钱加到显卡上——核显的钱花在刀刃上才是聪明配机。</span>

## 3 插槽与主板兼容性：选 CPU 之前先看「脚」

CPU 与主板靠**插槽（socket）**连接，不同代际、不同阵营的 CPU 使用不同插槽。**买 CPU 前先查主板插槽是否匹配，是兼容性的第一课**：

**Intel 插槽（以 LGA 为主）**：**LGA（Land Grid Array）**——针脚在主板插座上，CPU 底部是触点。主流如 `LGA 1700`（第 12/13/14 代酷睿）、`LGA 1851`（第 15 代及更新）。

**AMD 插槽（PGA / LGA 并存）**：早期 **PGA（Pin Grid Array）**——针脚在 CPU 底部（如 AM4）；新一代 **AM5** 改用 LGA 设计，触点换到主板上。<span class="marginnote"><strong>LGA 与 PGA 的哲学差异</strong>：LGA 针脚在主板（换 CPU 时主板针脚易弯、成本贵），PGA 针脚在 CPU（CPU 针脚易弯）。所以 LGA 时代「主板别乱丢、CPU 别乱压」。AM4 是 AMD 的长寿插槽，一代插座用了四代 CPU，是平台兼容性的经典案例。</span>

**选型铁律：CPU 的插槽型号必须与主板的插槽型号一字不差**。即使形状看起来像，插槽不同就插不进去（或插错烧毁），这属于「物理兼容性」。除了插槽，还有**芯片组兼容**：同一插槽也可能需要特定芯片组才能点亮新 CPU，购买前查主板厂商的「CPU 支持列表」（CPU Support List）。

**解析｜易错点：** 有些新手以为「Intel 和 AMD 的主板能通用」，这是最大的误区——**两大阵营的插槽完全不互通**，Intel 主板只能配 Intel CPU，AMD 主板只能配 AMD CPU。选 CPU 的同时，主板平台就跟着定了。

## 4 公式解析：为什么 CPU 越超频越热

CPU 功耗的核心公式，是选散热与理解超频的钥匙：

$$
P = C \cdot V^2 \cdot f
$$

- **$P$**：CPU 的动态功耗（瓦特）。
- **$C$**：晶体管的等效电容（由制程决定，几乎不可改）。
- **$V$**：核心电压（伏特）。
- **$f$**：运行频率（赫兹）。

三步拆解这条公式：

- **第一步，看 $V^2$**：功耗与电压的**平方**成正比——电压从 1.2V 提到 1.3V，功耗直接变成 $(1.3/1.2)^2 \approx 1.17$ 倍，即 +17%。
- **第二步，看 $f$**：功耗与频率成正比——频率从 4.0GHz 提到 4.5GHz，功耗约 +12.5%。
- **第三步，合起来**：超频通常**同时提高电压与频率**，于是功耗近似按「平方 × 一次」的速度暴涨——这就是为什么超频一点点、温度却飙升，必须配更强散热器的原因。

**这条公式还解释了芯片设计的一个反直觉结论**：降低一点电压，省电效果远大于降低频率——现代 CPU 的「降频省电」「睿频加速」都建立在这条公式之上。<span class="marginnote">回头看 TDP：65W 的 CPU 与 105W 的 CPU，功耗差距主要来自频率与电压设定的差异。这也是为什么「同样制程，低频版本能塞进笔记本、高频版本必须上台式机」——散热上限决定性能上限。</span>

## 5 选型实战：三张典型需求清单

把参数知识落到选型决策，最有效的是「按需求配清单」。以下三张典型配置，覆盖最常见的装机场景：

**办公/家用清单**：CPU 选 i3/Ryzen 3 或 i5/Ryzen 5 入门档，带核显（省独显钱）。插槽随平台，主板配入门芯片组（H 系 / A 系）。**核心思路：够用、稳定、便宜**。

**游戏清单**：CPU 选 i5/Ryzen 5 或 i7/Ryzen 7，重点预算给显卡。无核显版本（Intel F 后缀）省下的钱加到显卡上。主板配主流芯片组（B 系）即可，**不必上最贵的 Z 系/X 系**。

**AI 计算/工作站清单**：CPU 选 i7/i9 或 Ryzen 7/9 多核型号，重点在**大内存 + 大显存显卡 + 高速 NVMe 存储**。主板配顶级芯片组（Z 系 / X 系）以支持更多 PCIe 通道与多卡扩展。

**核心对比表：三种需求的 CPU 定位**

| 需求 | 推荐 CPU | 核显 | 主板芯片组 | 预算重心 |
| --- | --- | --- | --- | --- |
| 办公家用 | i3 / Ryzen 3 | 需要 | H / A 系 | CPU 足够，省预算 |
| 游戏 | i5 / Ryzen 5 | 无所谓 | B 系 | 显卡优先 |
| AI/工作站 | i7+ / Ryzen 7+ | 不需要 | Z / X 系 | 内存 + 显卡 + 存储 |

<span class="marginnote"><strong>选型的「反向验证」</strong>：清单列完后，用两个问题校验——<strong>CPU 与主板插槽是否一字不差匹配？芯片组是否支持你要的内存频率与超频需求？</strong> 这两问能挡掉大多数「买回来才发现不匹配」的悲剧。</span>

CPU 定了，整机平台就定了——接下来的内存、主板、电源都围绕它展开。**选 CPU 不是选一个芯片，是选一个平台**。

**选型一句话**：先定需求 → 再定阵营与插槽 → 后定具体型号——**插槽匹配是底线，代际与后缀决定平台**。把这句话贴在选型清单的第一行，能避免大多数「买回来装不上」的悲剧。

**选 CPU 的「最后检查」**：下单前再核一遍——**插槽匹配、代际支持、散热与电源够不够**。三问通过，这颗 CPU 才算「配对了」。

## 6 小结

- CPU 五大参数：**核心/线程数、主频与睿频、缓存、TDP、制程**——核心数管并行，主频管单核速度。
- Intel 命名：`i5-13600K`，代际 + 定位 + 后缀（`K` 可超频 / `F` 无核显）；AMD 命名：`Ryzen 5 7600X`。
- 插槽兼容性是第一铁律：**Intel 用 LGA 插槽、AMD 用 PGA/AM5**，两大阵营互不通用。
- 同一插槽还要查**芯片组与 CPU 支持列表**，避免买回来点不亮。
- 功耗公式 $P = CV^2f$：电压按平方影响功耗，超频一点、功耗与热量却暴涨。
- 选型一句话：**先定需求 → 再定阵营与插槽 → 后定具体型号**——插槽匹配是底线。
