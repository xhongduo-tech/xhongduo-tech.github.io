## 为什么从内存规格开始

CPU 运算再快，也得先从内存里取数据和指令。第 1 篇我们说过「内存是易失的临时记事本」，现在要回答选型问题：**内存怎么挑、怎么配，才能不拖 CPU 后腿？** 内存是整机里最容易「买错」的部件——不是买少就是买错代际，或者明明买了两条却只插在一条通道上，白白浪费一半带宽。看懂 DDR 代际、频率、时序与双通道，是配机性价比的关键一环，也是「瓶颈思维」的一次实战。

## 1 DDR 代际：物理上的「一代一槽」

**内存（RAM）**按代际演进，主流是 **DDR4** 与 **DDR5**。**DDR（Double Data Rate，双倍速率）**的含义是：在时钟的上升沿和下降沿都传输数据，同样频率下比单速率内存快一倍。<span class="marginnote">DDR 的「双倍速率」是它命名与频率数字的根源：标称「DDR5-5600」的 5600 指的是 <strong>MT/s</strong>（每秒百万次传输），而基础时钟只是它的一半——这也是「为什么内存标称频率比 CPU 主频还高」的误解来源。</span>

**代际之间物理不兼容**：DDR4 与 DDR5 的**防呆缺口位置不同**，插槽不同，**插不进去也插不上**——选内存第一件事，是确认主板支持哪一代。

**核心对比表：DDR4 与 DDR5**

| 对比项 | DDR4 | DDR5 |
| --- | --- | --- |
| 起始频率 | 2133–3200 MT/s | 4800–6400 MT/s |
| 单条容量 | 最高 32GB 常见 | 最高 64GB 常见 |
| 工作电压 | 1.2V | 1.1V（更低更省电） |
| 内存通道 | 每通道 1 位宽 64bit | 每通道分两路（效率更高） |
| 支持平台 | 较老 Intel/AMD | 新一代 Intel/AMD 平台 |

**「买新不买旧」的例外**：DDR5 平台整体更贵；若预算紧张或平台较老，DDR4 依然够用。**内存代际由主板平台决定，不由喜好决定**——先定 CPU+主板，再定内存代际。

## 2 频率与时序：内存参数怎么读

内存条上写着「DDR5-5600 CL40」这类参数，逐项拆开：

**频率（MT/s）**：每秒传输次数，如 5600 MT/s。频率越高，理论带宽越大。主板通常默认以**保守频率**运行，需在 BIOS 开启 XMP/EXPO 才能跑到标称频率（第 5 篇详述）。

**时序（CL，CAS Latency）**：内存收到读指令到输出数据的**延迟**，单位是时钟周期。CL 越小延迟越低。<span class="marginnote"><strong>频率管「吞吐」，时序管「延迟」</strong>——高频率 + 高 CL 与低频率 + 低 CL，实际性能可能打平。粗看参数不能只看频率：真实体验是「带宽 × 延迟」的综合结果。这也是为什么同频率内存，贵一档的往往赢在时序上。</span>

**容量（GB）**：装多少数据。**容量不够会造成「爆内存」——系统被迫用硬盘当虚拟内存（swap），速度暴跌到机械硬盘级别**。办公 8–16GB，游戏 16–32GB，AI/视频剪辑 32–64GB。

**选容量的铁律：容量优先于频率。** 16GB 高频内存永远跑不过 32GB 普通频率——因为「有得用」永远好过「用得快但不够用」。

## 3 双通道：为什么两条内存更优

**单通道（single channel）**：内存只用一个通道与 CPU 交换数据，位宽 64bit。

**双通道（dual channel）**：两条内存插在配对槽，同时工作，位宽翻倍到 128bit——**理论上带宽翻倍**，是提升内存性能最便宜的手段。<span class="marginnote"><strong>通道数量由主板决定，不是由内存条数决定</strong>：两条内存必须插在「配对槽」（同色或同通道标记）才构成双通道；都插在奇数位或偶数位，只是「两条单通道」而已。主板说明书上的「A1/A2/B1/B2」标记，A 与 B 各占一通道，正确插法是 A2+B2 或 A1+B1。</span>

**内存带宽公式**：

$$
\text{内存带宽} = \text{频率（MT/s）} \times \text{位宽（bit）} / 8
$$

代入：单条 DDR5-5600：$5600 \times 64 / 8 = 44.8\ \text{GB/s}$；双通道两根则翻倍为约 **89.6 GB/s**。<span class="marginnote">注意位宽单位换算：64bit = 8 字节，所以除以 8。这个公式与上节 PCIe 带宽公式思路一致——<strong>带宽 = 频率 × 位宽</strong>，是计算机里最通用的带宽原型，后面显卡显存带宽、总线带宽都会复用。</span>

**双通道的实战收益**：游戏与日常应用中，双通道相比单通道有约 5%–15% 的提升，对核显性能影响尤其显著（核显共享内存带宽）。**配机默认「两条小容量」优于「一条大容量」**——如 16GB（8GB×2）优于 16GB（单条），为双通道留出空间。

**解析｜易错点：** 双通道要求两条内存**容量一致（最好同型号）**。混插不同容量时，系统仍可运行但只能以较小容量组成双通道、其余容量单通道运行——所以尽量一次买两条「套条」（同批次同规格），最省心。

## 4 公式解析：内存带宽决定什么

把带宽公式再展开一层，看它如何决定实际体验：

$$
\text{总带宽} = \underbrace{\text{频率}}_{\text{MT/s}} \times \underbrace{\text{通道位宽}}_{64\ \text{bit} \times \text{通道数}} / 8
$$
