# PC组装与电脑硬件

台式机组装与电脑硬件是动手实践性极强的核心技能，涵盖硬件选配与兼容性判断、整机装配、BIOS 设置与点亮测试全流程。以《计算机及外部设备装配调试员》国家职业技能标准和《计算机装调与维修实用技术》教材为纲，对照 CompTIA A+ 国际认证体系，从部件认知、选配到装机、调优与排障，系统写完整门装机技能。

## 对标教材

- 《计算机及外部设备装配调试员》国家职业技能标准
- 《计算机装调与维修实用技术》（中职/高职计算机应用专业教材）
- CompTIA A+（220-1101 Core 1 / 220-1102 Core 2，国际硬件工程师认证）
