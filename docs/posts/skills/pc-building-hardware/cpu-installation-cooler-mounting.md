## 为什么从 CPU 安装开始

第 2 篇我们把 CPU 选定了，本小节开始真正动手——**把 CPU 装进主板**，再为它装上散热器。这一步是整机装配里「容错率最低」的一步：CPU 针脚或触点一旦损伤，轻则点不亮，重则整颗报废；散热器装不好，CPU 一开机就高温降频甚至烧毁。<span class="marginnote">CPU 是全机最贵的单件之一，而它的安装手法却「一学就会、一错就伤」——<strong>温柔 + 对齐 + 不蛮力</strong>三个关键词，是本小节的全部心法。</span>同时，这一步也是后续「内存、显卡安装」的起点——先装 CPU，是因为它处在主板的「中心位」，周围空间最局促，必须最先装。

## 1 安装前的准备：防静电与识别

动手前先做两件「看不见」的准备：

**防静电**：戴上防静电手环、夹到机箱金属（或接地的金属物体）上；拿 CPU 时**捏住 PCB 边缘**，不碰触点、不碰芯片顶盖。<span class="marginnote">CPU 顶盖与引脚是最脆弱的静电入口。回看《装机准备、工具与静电防护》的公式 $E = \tfrac{1}{2}CV^2$——人体几千伏的静电足以在看不见的情况下击穿 CPU 内部极薄的栅极氧化层，<strong>所以「捏边缘、先放电」不是矫情，是保命</strong>。</span>

**识别方位**：CPU 一角有**金色三角标记（golden triangle）**，主板插座一角也有对应的三角或缺口——**三角对三角**是防呆对齐的第一依据。

**核心对比表：Intel LGA 与 AMD AM5 的识别**

| 识别点 | Intel LGA | AMD AM5 |
| --- | --- | --- |
| 触点位置 | CPU 底部是触点 | 主板插座是触点 |
| 对齐标记 | 底部缺口 + 三角 | 三角标记 |
| 防呆结构 | 插座上的防呆口 | 插座缺口 |

## 2 安装 Intel LGA CPU：轻轻放入，缓缓压下

Intel 的 **LGA（Land Grid Array）** 插槽，针脚在主板上，CPU 底部是平整触点。安装步骤：

**第一步，打开插槽**。按下插槽旁的金属杆，翻开压盖——压盖下的插座上有一排排细密的针脚，**手指绝对不要碰**。

**第二步，放入 CPU**。捏住 CPU 边缘，让 CPU 底部的两个防呆缺口对准插座上的防呆凸点，**垂直轻轻放入**——放不平说明没对齐，**绝不可硬压**。<span class="marginnote"><strong>LGA 的温柔</strong>：CPU 放上去后应该是「自己贴平」的，如果有一边翘起，八成是方向不对或没对准。硬压下去的结果，是主板插座上一排弯针——<strong>修一根弯针的费用，比绝大多数 CPU 都贵</strong>。</span>

**第三步，压下压盖**。确认 CPU 放平后，盖上压盖，压下金属杆锁紧——CPU 被压盖稳稳压在触点上。

**第四步，检查**。轻碰 CPU 确认无晃动、压盖扣紧。LGA 安装到此完成。

## 3 安装 AMD CPU（AM4/AM5）：三角对三角

AMD 的 **AM5** 与 Intel LGA 类似（触点在主板上）；早期 **AM4** 则是 PGA——**针脚在 CPU 底部**。两者对齐要点一致：

**第一步，打开插座**。AM4 抬起金属拉杆，AM5 打开压盖，露出插座。

**第二步，对齐三角**。CPU 一角的**金色三角**对准主板插座上的三角标记，**垂直轻放**。<span class="marginnote"><strong>PGA 的「垂直」铁律</strong>：AM4 的 CPU 底部是一排针脚，只要有一根弯了，插槽就进不去。<strong>放入时务必垂直、轻放、不加力</strong>——若 CPU 落不平，宁可拿出来重新对齐，也不要按压。</span>

**第三步，锁紧**。AM4 压下金属拉杆，AM5 盖上压盖并压下。CPU 与主板对齐完成。

**辨析｜易错点：** 新手最常见的问题是把 CPU **方向放反**。记住「**三角对三角 + 垂直轻放 + 落平再锁紧**」三连，方向、对齐、力度三关就都过了。装好后 CPU 与主板表面齐平、无翘角，才是「装对了」。

## 4 公式解析：散热器为什么必须「压紧 + 涂硅脂」

散热器与 CPU 顶盖之间，靠**硅脂**填补微观空隙。为什么硅脂必不可少？用热传导公式说清：

$$
Q = \frac{k \cdot A \cdot \Delta T}{d}
$$

- **$Q$**：单位时间导走的热量（瓦特）。
- **$k$**：材料的导热系数——硅脂约 5–10 W/(m·K)，空气约 0.026 W/(m·K)，**差了三百倍**。
- **$A$**：接触面积。
- **$\Delta T$**：温差。
- **$d$**：传热路径长度（厚度）。

**关键在 $k$ 与 $d$ 的配合**：CPU 顶盖与散热器底座在微观上凹凸不平，两者之间的空隙若被**空气**填满（$k$ 极小），热量就「传不过去」；涂上**硅脂**（$k$ 大三百倍）填平空隙，导热立刻顺畅。<span class="marginnote"><strong>「涂硅脂」与「压紧」是一对</strong>：压紧让两金属面尽量贴合、把硅脂压到很薄——硅脂本身的导热性不如金属，<strong>越薄越好</strong>，厚涂反而变成隔热层（$d$ 变大，$Q$ 变小）。这就是「硅脂要薄、散热器要压紧」的物理来源。</span>

**正确手法**：在 CPU 顶盖中央挤**一粒米大小**的硅脂，靠散热器压力压平即可（多数散热器已预涂，直接装）。

## 5 散热器装配：风冷塔式与一体水冷

散热器分两类，安装要点不同：

**风冷塔式（air cooler）**：把散热器底座对准 CPU 顶盖放平，用扣具/背板固定，最后接上风扇。

**一体水冷（AIO）**：把**冷头**对准 CPU 放平、扣紧，再把**冷排**装到机箱顶部或前部风扇位，接好水泵供电与冷排风扇线。

**核心对比表：两类散热器的装配要点**

| 步骤 | 风冷塔式 | 一体水冷 |
| --- | --- | --- |
| 底座固定 | 扣具 + 背板 | 冷头扣具拧紧 |
| 与 CPU 贴合 | 压力由扣具保证 | 压力由冷头螺丝保证 |
| 风扇 | 接 CPU_FAN 插座 | 冷排风扇接 CPU_FAN |
| 装位 | 机箱内、朝后吹 | 冷排装顶/前部 |

**装机后的验证**：装完散热器，通电进 BIOS 看 **CPU 温度**——待机 30–50°C 说明贴合良好；若飙到 80°C+，多半是散热器没压紧或硅脂异常，**回炉重装，别硬撑**。<span class="marginnote"><strong>「开机即高温」= 安装失败</strong>：散热器没压紧（接触面积 $A$ 变小）、硅脂没涂（空气隔热），都会让 $Q$ 骤降、温度暴涨。<strong>第一次装机者最大的「翻车点」就是散热器——务必确认四角都扣紧、风扇线接对</strong>。</span>

### 散热器安装的常见错误速查

把本节最容易出错的地方集中成表，装前看一眼：

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| CPU 方向放反 | 无法安装/触点错位 | 三角对三角、垂直轻放 |
| 硅脂厚涂 | 隔热、温度更高 | 米粒大小、压平即可 |
| 散热器没压紧 | 开机即高温 | 确认四角扣具到位 |
| 风扇线没接 CPU_FAN | 风扇不转、报警 | 接 CPU_FAN 插座 |
| 水冷冷排装反 | 散热效率大减 | 冷排风扇朝机箱外吹 |

**「开机即高温」是最常见的翻车信号**——它直接指向散热器没压紧或硅脂异常。把这张表贴在心口，装机时照着核对，散热这关就稳了。

## 6 小结

- 安装前**防静电、捏 PCB 边缘**；识别「**三角对三角**」防呆标记。
- Intel **LGA** 与 AMD **AM5**：CPU/主板触点轻放、压盖锁紧；AMD **AM4** 针脚垂直轻放、绝不硬压。
- 散热公式 $Q = kA\Delta T / d$：**硅脂填空气（$k$ 差三百倍）、压紧压薄硅脂（$d$ 最小化）**——「薄涂 + 压紧」是散热的黄金组合。
- 风冷扣具与背板、水冷冷头与冷排，各按规格装好，风扇线接 **CPU_FAN**。
- 装完进 BIOS 看温度：**待机 30–50°C 为健康，异常高温回炉重装**。
