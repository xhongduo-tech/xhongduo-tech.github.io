## 为什么从显卡开始

前面我们把 CPU 定为「大脑」、内存定为「粮仓」，现在轮到整机里最贵的单件——**显卡**。它是「从极限到大模型」主线最直接的硬件交点：**大模型的训练与推理，靠的就是 GPU 的并行算力**；显卡不仅是打游戏的玩具，更是 AI 计算、视频剪辑、3D 渲染的通用加速器。本小节讲清三件事：显卡与 CPU 的分工、显卡的参数怎么读、以及画面最终如何通过接口送到显示器。

## 1 概念先分清：CPU、GPU、核显、独显

**显卡（Graphics Card / GPU）**：负责图像渲染与并行计算的部件。但「显卡」这个词在不同语境下指代不同层次，先分清：

**GPU（Graphics Processing Unit）**：显卡上的核心芯片，是真正的「计算引擎」。**GPU 的设计哲学与 CPU 相反**——CPU 是几个「大力士」处理复杂任务，GPU 是成千上万个「小工」同时处理简单任务，专为大规模并行而生。<span class="marginnote"><strong>为什么大模型训练必须用 GPU？</strong> 神经网络的核心运算是矩阵乘法，而矩阵乘法是「成千上万个点积并行算」。CPU 一次算一个点积，GPU 一次算几万份——所以同样的训练任务，GPU 能快几十上百倍。这是 GPU 成为 AI 时代硬通货的根本原因。</span>

**核显（iGPU，集成显卡）**：集成在 CPU 内部的 GPU，共享系统内存，性能够日常办公与轻娱乐，不占独立显卡的预算。

**独显（discrete GPU）**：独立 PCB、自带**显存（VRAM）**的显卡，插在主板的 PCIe x16 槽上，性能远强于核显，是游戏与 AI 计算的必需品。

**显存（VRAM, Video RAM）**：显卡自带的专用内存，存放帧缓冲、纹理与模型权重。<span class="marginnote">显存是「显卡的粮仓」：显存不够，大模型权重装不下就只能等数据在显存与内存之间反复搬运，速度骤降。<strong>显存容量与显存带宽，是判断一块显卡能不能跑大模型的头两个指标</strong>——这比单纯看「频率多高」更本质。</span>

## 2 显卡的核心参数

**流处理器 / CUDA 核心（shader cores）**：显卡里的「小工」数量。NVIDIA 叫 CUDA 核心，AMD 叫流处理器（Stream Processors）。数量越多，并行能力越强——是显卡性能最直观的指标之一。

**显存容量与位宽**：显存大小（如 8GB / 16GB / 24GB）决定能装多少数据；位宽（如 128bit / 192bit / 256bit / 384bit）决定每次存取多少数据。两者结合显存频率，算出**显存带宽**（下节公式）。

**核心频率（MHz）**：GPU 芯片的运行频率，影响单次计算速度，但重要性不如「核心数 × 带宽」。

**核心对比表：核显 vs 独显**

| 对比项 | 核显 | 独显 |
| --- | --- | --- |
| 物理位置 | 集成在 CPU 内 | 独立板卡插 PCIe |
| 显存 | 共享系统内存 | 自带独立显存 |
| 性能 | 办公、4K 视频、轻游戏 | 游戏、渲染、AI 计算 |
| 功耗/发热 | 极低 | 较高，需独立供电 |
| 选配时机 | 无游戏/无独显需求 | 游戏、创作、AI 必选 |

**选卡逻辑一句话**：**先问「拿来干什么」，再问「显存要多大」**。只办公——核显足够；玩 3A 游戏——按游戏分辨率选显卡档位；跑 AI 与渲染——把显存容量放第一位。

## 3 显示输出接口：画面怎么到显示器

显卡与显示器通过**显示接口**连接。主流接口有四种，新旧并存：

**HDMI（High-Definition Multimedia Interface）**：最普及的接口，电视、显示器、投影通用。同时传输**音视频**，支持高分辨率与高刷新率（HDMI 2.1 支持 4K 144Hz）。<span class="marginnote">HDMI 常被误以为「只传视频」——实际上它设计之初就<strong>同时传音频</strong>，所以接显示器时声音也会跟着走（若显示器带音箱）。DP 与 HDMI 都支持音视频，DVI/VGA 则只传视频。</span>

**DisplayPort（DP）**：PC 显示器的标准接口，带宽通常高于 HDMI，支持高分辨率高刷与**多屏串联（Daisy-chain）**，是电竞与专业用户首选。

**DVI（Digital Visual Interface）**：数字接口，分 DVI-I（兼容模拟）与 DVI-D（纯数字），常见于较老设备，正被 HDMI/DP 取代。

**VGA（Video Graphics Array）**：纯模拟接口，抗干扰差、清晰度有限，只能传视频，老投影与古董显示器还在用。<span class="marginnote"><strong>接线口诀</strong>：电脑连显示器，<strong>优先 DP，其次 HDMI</strong>；只有老设备才用 DVI/VGA。同时注意<strong>转接线</strong>：DP 转 HDMI 常见，但 HDMI 转 VGA 需要「数模转换芯片」的主动转接线，普通线插了没信号。</span>

**接口与分辨率的匹配**：要跑 4K 高刷或 8K，必须 HDMI 2.1 或 DP 1.4/2.0 以上；老接口（VGA/DVI 老版本）跑不动高分辨率。买线买卡时，**接口版本决定分辨率上限**。

## 4 公式解析：显存带宽

显存带宽是判断显卡「喂数据能力」的核心指标，公式与内存带宽同源：

$$
\text{显存带宽} = \frac{\text{显存频率} \times \text{位宽}}{8}
$$

- **显存频率**：有效传输速率（MT/s），GDDR6 常在 12000–20000 MT/s。
- **位宽**：一次读写的数据宽度（bit），如 256bit。
- **/8**：bit 转字节。

代入一块常见显卡：显存频率 14000 MT/s、位宽 256bit，则带宽 $= 14000 \times 256 / 8 = 448\ \text{GB/s}$
