## 为什么从内存与显卡安装开始

CPU 和散热器就位后，下一步是把「数据通路」插满——**内存**是 CPU 的粮仓，**显卡**是画面的引擎，**M.2 固态与各类扩展卡**是存储与外设的入口。这一节是三组「插板卡」的操作，共同特点是：**金手指对插槽、防呆对齐、均匀施力**。它把第 2 篇的选型知识（双通道插法、PCIe x16 槽位、M.2 协议）变成手上的动作——**选对了还插不对，等于白选**。

## 1 内存安装：防呆缺口 + 对角线压入

**内存条（DIMM）**插入主板内存插槽。要点：

**第一步，打开插槽卡扣**。主板内存插槽两端有白色卡扣，向外按下打开。

**第二步，对齐防呆缺口**。内存条底部有**防呆缺口**，插槽内有对应的凸起——缺口位置决定了方向，**反了插不进去**。<span class="marginnote">DDR4 与 DDR5 的防呆缺口位置不同，<strong>插槽物理上互不相通</strong>——这也再次印证了「内存代际由主板平台决定」。拿内存条时<strong>捏住两端边缘，不碰金手指</strong>，金手指的镀金层最怕汗渍与静电。</span>

**第三步，双通道插法**。选对**配对槽**（如 A2+B2），先插通道 A 再插通道 B——回看《内存规格、频率与双通道选配》的插法，插错槽就退化成单通道。

**第四步，垂直均匀压入**。两手各按内存条两端，**同时垂直向下压**，听到「咔嗒」两声（两端卡扣回弹）即为到位。<span class="marginnote"><strong>「咔嗒」两声是成功信号</strong>：两端卡扣都弹起锁紧，说明内存完全插入。只响一声说明一端没到位——重新垂直压下，<strong>不要斜着硬压</strong>，否则可能压伤金手指或插槽。</span>

**第五步，验证**。轻拔确认卡扣锁紧；装完开机若「滴滴」报警，多半是内存没插到位或插错槽。

## 2 显卡安装：PCIe x16 槽与挡板

**显卡**插入主板的 **PCIe x16 长槽**，并固定到机箱后部挡板位：

**第一步，确认挡板**。拆掉机箱后部对应位置的**挡板片**（金属片），显卡的 I/O 挡板将占据这个开口。

**第二步，对齐插槽**。显卡**金手指对准 PCIe x16 槽**，垂直插入；插槽末端有**卡扣**，显卡插入到位后卡扣自动弹起锁住显卡后端。<span class="marginnote"><strong>显卡「插没插到底」看卡扣</strong>：插槽尾端的卡扣弹起，说明显卡后端被锁住——只插一半的显卡，通电后花屏、黑屏的元凶。拆显卡时<strong>先按下卡扣再拔出</strong>，硬拽会拉坏插槽。</span>

**第三步，固定挡板**。用机箱螺丝把显卡 I/O 挡板拧到机箱后部，防止显卡下沉。

**第四步，接供电**。大功率显卡需接 **6-pin / 8-pin 供电线**（来自电源）——供电不接，显卡不亮或降频（回看《电源安装与供电接线规范》）。

**核心对比表：内存与显卡安装的共同点**

| 环节 | 内存 | 显卡 |
| --- | --- | --- |
| 防呆 | 缺口防呆 | 金手指 + 卡扣 |
| 施力 | 两端垂直同时压 | 垂直插入 |
| 到位信号 | 两端「咔嗒」 | 卡扣弹起 |
| 常见错误 | 斜插、插错槽 | 没插到底、漏供电 |

## 3 扩展卡安装：M.2 固态与无线网卡

除内存显卡外，主板还有其他扩展位：

**M.2 SSD**：撕开散热片贴纸，把 M.2 固态**斜 30° 插入 M.2 槽**，压下末端，拧上固定螺丝。<span class="marginnote"><strong>M.2 安装是「斜插 + 压下」</strong>：先把金手指斜着插进槽口到底，再顺势压下到与主板平行，用螺丝固定。<strong>别用力过猛</strong>——M.2 槽和固态都很脆弱；若主板上没有预留螺丝，固态尾端就「悬空翘起」，长期可能接触不良。</span>

**无线网卡（Wi-Fi 卡）**：同样插 M.2 槽（走 CNVio/PCIe 协议），天线接到机箱后部。

**其他扩展卡（声卡、采集卡、转接卡）**：插 **PCIe x1 短槽**或 x16 槽，固定挡板、接供电（如需要）。

**辨析｜易错点：** M.2 插槽**协议要先核对**——有的 M.2 槽只支持 NVMe、有的只支持 SATA，插错协议会「不识别」（回看《存储设备：SSD/HDD 与 NVMe/SATA 接口》）。同时注意 M.2 与 **SATA 接口的共享关系**：部分主板某个 M.2 槽占用后，会禁用某个 SATA 口——说明书里写得很清楚，插满前先读一遍。

## 4 公式与要点解析：金手指的「接触即电阻」

板卡安装的底层物理，是**金手指与插槽触点的可靠接触**。用电阻概念说清：

$$
R_{contact} \propto \frac{\rho}{A_{effective}}
$$

- **$R_{contact}$**：触点接触电阻——接触不良时剧增。
- **$\rho$**：接触面的杂质/氧化层电阻率——灰尘、汗渍、氧化都会放大它。
- **$A_{effective}$**：有效接触面积——**接触压力不足或没插到底，有效面积骤减**。

**结论**：金手指**要干净、要插到底、要有足够的接触压力**。这就是「捏边缘防汗渍、垂直压入到位、卡扣锁紧」三个动作的物理依据——**每一步都在保护 $A_{effective}$、抑制 $\rho$**，从而让数据信号稳定传输、供电压降最小。<span class="marginnote"><strong>「插到底」的另一个名字是「低接触电阻」</strong>：插一半的金手指，接触电阻大，信号衰减、发热增加——这不只是「会不会坏」的问题，是「信号质量好不好」的工程问题。用接触电阻的思维看所有板卡安装，动作就自然规范了。</span>

## 5 安装后的检查清单

板卡全部就位，做一次系统性检查再通电：

- 内存两端卡扣**咔嗒**锁紧、插在配对槽。
- 显卡**插到底、卡扣弹起、挡板螺丝固定、供电线接牢**。
- M.2 固态**斜插到位、螺丝固定不翘起**。
- 所有板卡**金手指无指纹、无杂物**。
- 检查无误后再接电源、通电点亮。

**一句话**：板卡安装 = **防呆对齐 + 垂直均匀施力 + 到位信号确认**——把这三步做成肌肉记忆，装任何板卡都不慌。

### 板卡安装的「静置检查」与冷启动纪律

板卡插完，别急着通电——做一个「静置检查」，再决定是否「冷启动」：

**静置检查**：装机完成后、通电前，依次轻按每块板卡确认无松动；看一眼金手指与插槽的贴合——**「静置检查」是通电前最后的确认**。

**冷启动纪律**：第一次通电测试，不接硬盘、不接外设，只保留核心部件——**先验证主板 + CPU + 内存 + 显卡能点亮，再加回其余**（回看《点亮测试与开机故障排查流程》的最小系统法）。

**为什么「先核心后扩展」**：把「最小可开机系统」点亮的瞬间，若花屏、蓝屏，问题集中在核心四件；若再加扩展卡才出问题，嫌疑就锁定在扩展卡上——**冷启动纪律让排障范围最小化**。

**一句话**：板卡安装不只「插上」，还要「**检查 + 分级验证**」——插得对、验得稳，才叫装到位。

**金手指清洁的「法宝」**：接触不良时，用**橡皮擦**轻擦金手指（勿用湿布、勿上手摸），再重插——多数「接触不良」就此解决；这招也用于内存、显卡的排障（回看《常见硬件故障识别与维修》）。

**「插拔有度」**：板卡不必频繁插拔——每次插拔都磨损金手指与插槽，确认到位即可，不折腾。

**一句话**：金手指是板卡的「命门」，也是排障的「第一现场」——保护好它，就是保护好整块板卡。

## 6 小结

- 内存安装：**缺口防呆、两端垂直同时压、双通道配对槽、「咔嗒」两声到位**。
- 显卡安装：**PCIe x16 槽、卡扣弹起、挡板螺丝固定、接独立供电**。
- M.2 固态：**斜 30° 插入、压下固定、先核对槽位协议**。
- 接触电阻 $R_{contact} \propto \rho / A_{effective}$：**金手指干净、插到底、压力足**，信号才稳定。
- 装完按检查清单走一遍：**到位信号全确认，再通电**。
