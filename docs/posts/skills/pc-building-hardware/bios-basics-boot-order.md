## 为什么从 BIOS 基础设置开始

整机装配完成、屏幕点亮的那一刻，你会看到主板 LOGO 和一个「按 Del 进 BIOS」的提示——**BIOS 是硬件装配与软件世界之间的第一道门**。系统安装之前，必须先进 BIOS：把启动顺序指向 U 盘、确认硬件识别、必要时开启内存 XMP。<span class="marginnote">BIOS 的角色是「<strong>硬件的初始化官</strong>」：它检测 CPU、内存、显卡、硬盘是否就位，再把这些硬件交给操作系统。从架构看，BIOS 把「硬件清单」逐一点名，确认后才把「指挥权」移交给系统——<strong>没有 BIOS 的点名，就没有操作系统的登场</strong>。</span>本小节讲清：**BIOS 是什么、怎么进、核心设置改哪些**，重点是**启动顺序**——这是装系统的第一前提。

## 1 BIOS 是什么：固件与硬件的「点名官」

**BIOS（Basic Input/Output System，基本输入输出系统）**：主板上的**固件（firmware）**，开机时最先运行的软件，负责硬件检测、初始化与引导操作系统。<span class="marginnote">BIOS 存储在主板上的 <strong>闪存芯片</strong>里，断电不丢——这就是「改错设置还能重进 BIOS」的原因。现代主板普遍用更先进的 <strong>UEFI</strong> 取代传统 BIOS（回看《UEFI 引导模式与固件更新》），但「进入方式与基本设置」一脉相承。</span>

**BIOS 的三大职责**：

**硬件初始化（POST）**：开机自检，检测 CPU、内存、显卡、硬盘是否就位——任一缺失以蜂鸣/错误码报警。

**基础配置**：时间日期、启动顺序、内存频率、风扇曲线、供电设置等。

**引导操作系统**：把启动权交给指定设备（U 盘、SSD、光驱）上的系统。

**核心对比表：BIOS 与现代 UEFI**

| 对比项 | 传统 BIOS | UEFI |
| --- | --- | --- |
| 界面 | 蓝底白字键盘操作 | 图形化、可鼠标 |
| 分区表 | MBR | GPT（支持大硬盘） |
| 启动速度 | 较慢 | 较快 |
| 安全性 | 无安全启动 | Secure Boot |
| 现代主板 | 已淘汰 | **默认** |

## 2 进入 BIOS：开机时机与按键

**进入方法**：开机自检画面提示按 **Del 或 F2**（主板厂商不同，多为 Del / F2 / F10 / F12）进入 BIOS。<span class="marginnote"><strong>「进不去 BIOS」的解法</strong>：多数新主板在 Windows 里可通过「设置 → 恢复 → 高级启动」重启进入固件设置。<strong>按键要趁早</strong>——自检阶段就连续按，错过就重启再来。</span>

**常用导航**：方向键切换、Enter 进入、Esc 返回、F10 保存退出、F7 切换高级/简易模式。UEFI 图形界面可直接鼠标操作。

**注意**：改完设置要**保存并退出（Save & Exit）**才生效——不保存直接关机等于没改。

## 3 核心设置项：装机必改的几项

进入 BIOS 后，按装机的实际需求改这几项：

**启动顺序（Boot Order）**：把 **U 盘（安装介质）** 或 **SSD（系统盘）** 设为第一启动项——装系统时 U 盘优先，装完后 SSD 优先（下节详解）。

**内存 XMP/EXPO**：在「内存超频 / 内存设置」里开启 **XMP（Intel）或 EXPO（AMD）**，让内存跑标称频率（回看《内存 XMP/EXPO 与 BIOS 调优》）。<span class="marginnote"><strong>内存默认「跑不满」</strong>：内存条标称 5600 MT/s，主板默认只跑保守频率（如 4800）——<strong>必须手动开 XMP/EXPO 才解锁标称性能</strong>。装机后跑分偏低的第一排查项，就是「XMP 开了没」。</span>

**CPU 风扇与散热**：确认 CPU_FAN 转速正常；开启「CPU 风扇停转报警」防止风扇故障无人知。

**时间与日期**：主板电池（CMOS 电池）没电会导致时间错乱——顺带检查。

**启动模式**：确认 **UEFI 模式**开启（新装机标配，回看下一节）。

## 4 启动顺序配置：装系统的第一步

启动顺序是本小节最实操的部分，分两个阶段：

**装系统阶段**：把 **U 盘装进 USB 口 → 进 BIOS → 把 U 盘设为第一启动项 → 保存退出** → 重启后从 U 盘引导，进入系统安装界面。<span class="marginnote"><strong>启动顺序的两难</strong>：U 盘不设第一，重启后直接进硬盘；设了 U 盘第一，装完系统忘了改回来，每次开机都会「先尝试 U 盘、再进系统」——<strong>装完系统记得把 SSD 调回第一启动项</strong>，顺带拔掉 U 盘。</span>

**装完系统阶段**：把**系统 SSD 设为第一启动项**，其余设备置后——开机直接从 SSD 引导，进入操作系统。

**核心对比表：两个阶段的启动顺序**

| 阶段 | 第一启动项 | 目的 |
| --- | --- | --- |
| 装系统 | U 盘 | 从安装介质引导 |
| 装完后 | 系统 SSD | 直接进入系统 |

**辨析｜易错点：** 「**启动顺序设错了**」的典型症状——插着 U 盘开机会进 U 盘界面，拔掉 U 盘又提示「No bootable device」。**正确做法：装系统时 U 盘优先，装完后 SSD 优先**，并把 U 盘从第一启动项拿掉。

## 5 实战：一次完整的装机 BIOS 设置流程

把本节内容串成一次标准操作：

1. 插好 U 盘安装介质，开机狂按 **Del** 进 BIOS。
2. 确认 BIOS 识别到 **CPU、内存容量、SSD、U 盘**（「硬件盘点」）。
3. 确认 **UEFI 模式**开启、时间日期正确。
4. 把 **U 盘设为第一启动项**，保存退出（F10）。
5. 重启从 U 盘引导，进入系统安装（下一节继续）。
6. 系统装完重进 BIOS，**把 SSD 调回第一启动项**。

**一句话**：BIOS 设置 = **硬件盘点 + 启动顺序 + 内存与风扇配置**——装机阶段只需改这几点，其余保持默认即可。

### BIOS 安全与恢复：设置改坏了怎么办

BIOS 设置改坏是新手会遇到的第一道坎，记住两条「退路」：

**进不去 BIOS 怎么办**：关机 → 再开机连续按 Del/F2；仍不行则用主板的「一键进入 BIOS」快捷键（有些主板开机时按 F11 可进引导菜单）。

**设置改坏进不了系统怎么办**：**清 CMOS**——拔电源、找到主板上的 CMOS 电池或跳线，放电几秒后恢复出厂（回看《UEFI 引导模式与固件更新》）；或用主板上的 **BIOS Flashback** 按钮重刷。

**设置密码忘了**：CMOS 电池放电同样能清掉 BIOS 密码（台式机）。

**核心对比表：BIOS 常见问题与退路**

| 问题 | 退路 |
| --- | --- |
| 进不去 BIOS | 连续按 Del/F2，或用引导菜单键 |
| 设置改坏黑屏 | 清 CMOS / BIOS Flashback |
| 忘 BIOS 密码 | 清 CMOS（台式机） |

**一句话**：BIOS 是「**改不坏、删不掉**」的固件——再怪的问题，清 CMOS 都能回到起点，别怕改设置。

## 6 小结

- BIOS/UEFI 是**固件**，负责硬件初始化与引导系统——开机最先运行、断电不丢。
- 进入 BIOS：**Del / F2** 等按键，趁自检阶段连续按；改完要**保存退出**。
- 装机必改：**启动顺序、内存 XMP/EXPO、CPU 风扇、时间日期、UEFI 模式**。
- 启动顺序两阶段：**装系统 U 盘优先，装完 SSD 优先**。
- BIOS 是硬件与系统的「桥」——设好它，装系统才顺畅。
