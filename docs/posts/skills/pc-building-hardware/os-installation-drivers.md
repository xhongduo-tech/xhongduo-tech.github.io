## 为什么从系统安装与驱动配置开始

上一节我们把机器「点亮」了，但亮着的 BIOS 界面还不是「能用的电脑」——要让它真正干活，需要安装**操作系统（OS）**，再为硬件装上**驱动程序**。<span class="marginnote">从架构看，这一步是把「硬件平台」交给「软件世界」：操作系统接管硬件管理，驱动则让系统「认识」每一块具体硬件——<strong>没有驱动，显卡只能显示 1024×768、声音出不来、Wi-Fi 连不上</strong>。</span>本小节讲清：**怎么做一个 U 盘安装盘、系统怎么装、驱动装哪些、装完怎么验证**——这是「从硬件到可用」的最后一道工序。

## 1 安装介质准备：做一个 U 盘系统盘

**安装介质**：存放系统安装文件的 **U 盘（8GB+）**，通过官方工具把安装文件「烧录」进 U 盘。

**制作方法**：Windows 用**官方媒体创建工具**（Media Creation Tool）或 Rufus；Linux 用官方镜像 + Rufus/balenaEtcher 写入。<span class="marginnote"><strong>「烧录」≠「拷贝」</strong>：U 盘系统盘不是把安装文件「复制」进 U 盘，而是把 U 盘制作为<strong>可引导的启动盘</strong>——所以要用官方工具烧录，直接拖文件进去是无法引导的。<strong>制作时注意 U 盘数据会被清空</strong>，先备份。</span>

**制作要点**：U 盘容量 8GB 以上；制作工具选**UEFI 引导模式**（配合上一节的 UEFI + GPT）；制作完成后验证 U 盘能引导。

## 2 系统安装流程：从引导到桌面

有了 U 盘，按流程安装：

**第一步，引导进入**：U 盘插好，进 BIOS 把 U 盘设为第一启动项（回看《BIOS 基础设置》），重启进入安装界面。

**第二步，选择安装类型**：选「**自定义安装**」（全新安装），而不是升级。

**第三步，分区**：选择系统盘（目标 SSD），若有提示 MBR/GPT 转换则按要求处理（回看《UEFI 引导模式》）；系统盘建议整盘给系统，安装程序自动建所需分区。<span class="marginnote"><strong>分区「一删二建三装」</strong>：若目标盘有旧系统或旧分区，安装界面里<strong>删除旧分区、重建新分区（选未分配空间直接「下一步」也行）</strong>——安装程序会按 UEFI 自动创建 ESP/MSR/系统分区。<strong>删除分区会清空数据</strong>，动手前确认盘选对了。</span>

**第四步，安装过程**：复制文件 → 展开 → 重启，全程自动；重启后进入「首次设置」（用户名、密码、网络）。

**第五步，进入桌面**：系统装完，进入桌面——但这只是「半成品」，还差驱动。

## 3 驱动程序：系统认识硬件的「翻译官」

**驱动程序（driver）**：让操作系统与硬件通信的软件。硬件种类千千万，系统不可能内置所有驱动——于是由厂商提供驱动，告诉系统「这块硬件怎么用」。

**驱动装哪些（按优先级）**：

**芯片组驱动**：让系统认识主板芯片组，是一切外设正常工作的基础——**最先装**。
**显卡驱动**：解锁显卡分辨率、刷新率与 3D 性能——**不装则画面粗糙、性能极低**。
**声卡 / 网卡驱动**：声音与网络——不装则无声、无网。
**外设驱动**：打印机、手柄、摄像头等，按需安装。<span class="marginnote"><strong>驱动的「两条渠道」</strong>：<strong>厂商官网驱动</strong>（精准匹配）与<strong>Windows Update / 驱动管理工具</strong>（自动识别）。<strong>推荐「芯片组与显卡去官网，其余交给系统更新」</strong>——显卡驱动官网版最稳，芯片组驱动官网版最全。</span>

**核心对比表：驱动类别与优先级**

| 驱动 | 不装的后果 | 获取方式 | 优先级 |
| --- | --- | --- | --- |
| 芯片组 | 外设异常 | 主板官网 | ★★★ |
| 显卡 | 低分辨率、性能差 | 显卡官网 | ★★★ |
| 声卡/网卡 | 无声/无网 | 主板官网或系统更新 | ★★ |
| 外设 | 功能缺失 | 厂商官网 | ★ |

## 4 驱动安装的正确姿势与验证

**安装顺序**：先系统 → 再芯片组 → 显卡 → 声卡网卡 → 外设。**每装一类重启一次**（或按提示重启），避免驱动冲突。

**验证安装成功**：打开「**设备管理器**」——若所有设备「无感叹号」，说明驱动装全；有黄色感叹号/问号的设备，就是还缺驱动的硬件。<span class="marginnote"><strong>设备管理器是驱动的「体检表」</strong>：<strong>没有感叹号 = 驱动齐了</strong>；有感叹号的设备「更新驱动」即可。<strong>显卡装好后分辨率应自动升至显示器原生分辨率</strong>（回看《外设、显示器与整机装配》）——分辨率上不去，就是显卡驱动没装好。</span>

**辨析｜易错点：** 「**驱动越多越好**」是误区。**装配套驱动、不装多余驱动**——乱装「驱动大师」「万能驱动」可能引入捆绑软件甚至驱动冲突。优先官网与系统更新，第三方工具只在官网找不到时谨慎使用。

## 5 装完系统后的「第一课」清单

系统与驱动就位后，做这几件事：

- **检查设备管理器**：无感叹号 = 驱动齐。
- **验证分辨率与刷新率**：设为显示器原生参数。
- **连接并验证网络与声音**：网卡、声卡驱动生效。
- **备份**：装好驱动、配置好系统后做**第一个系统镜像**——「机器可以重装，数据不能重来」（回看《存储设备》）。
- **跑性能测试**：为后续验收留基线（回看《整机性能测试与稳定性验证》）。

**一句话**：系统安装 = **做好 U 盘 → 引导分区安装 → 装驱动 → 验证无感叹号 → 备份镜像**——这条流程走完，这台电脑才算「真正能用」。

### 驱动更新的纪律与双系统安装

**驱动更新的纪律**：驱动不是「越新越好」——

- **显卡驱动**：玩新游戏时可更新（性能优化）；**旧平台稳定运行则不必追新**。
- **主板/芯片组驱动**：只在厂商修复了具体问题或支持新硬件时更新。
- **更新方式**：官网下载对应版本 → 卸载旧版（可选）→ 安装 → 重启验证。
- **「更新出问题」的退路**：设备管理器里**「回滚驱动程序」**可退回上一个版本。

**双系统安装（进阶）**：一台机器装 Windows + Linux（或其他系统），要点是**先装 Windows、后装 Linux**——Linux 的引导程序（GRUB）能识别并加入 Windows 启动项；顺序反了，Windows 会覆盖引导，需要手动修复。

**核心对比表：双系统安装顺序**

| 步骤 | 系统 | 说明 |
| --- | --- | --- |
| 先 | Windows | 先装，分区预留 |
| 后 | Linux | 后装，GRUB 引导接管 |

**一句话**：驱动遵循「**需要才更、更新有退路**」；双系统遵循「**先 Windows、后 Linux**」——两条纪律，让系统安装之路少踩坑。

**装完系统的长期主义**：系统装好只是起点——**定期更新补丁、定期备份镜像、保持驱动与固件版本可控**，这台机器才能「长久好用」。把装机学到的方法，用在「养机」上，才是完整的闭环。

**驱动安装失败的通用退路**：驱动装不上或装完系统异常，先卸载再重装官方版；仍不行则回滚系统还原点——**驱动与系统互为因果，别在驱动上死磕**。

**「装完系统必做」的心智模型**：把「U 盘制作 → 引导安装 → 分区 → 驱动 → 验证 → 备份」当成一条流水线——每一步都有「验收信号」（引导界面出现、进入桌面、设备管理器无感叹号、镜像生成）。**每一步有信号，整条流程才闭环**，这也是《整机性能测试与稳定性验证》「验收记录」思想的延续。

**给初学者的贴心提醒**：第一次装系统不必追求「一次成功」——装坏了重装即可，系统安装是「练出来的」；但**分区那一步的「删除分区」要谨慎**，选对目标盘再动手。

整条「U 盘 → 系统 → 驱动 → 备份」的流程走通一次，你就完成了从「装机匠」到「装系统师傅」的跨越——而这套「流程化 + 验收信号 + 留档」的方法，正是后续一切系统运维工作的共同底座。

## 6 小结

- 安装介质：**U 盘 8GB+，用官方工具烧录为可引导启动盘**——不是简单拷贝。
- 安装流程：**引导 → 自定义安装 → 分区（GPT）→ 自动安装 → 首次设置**。
- 驱动是「翻译官」：**芯片组最先装、显卡其次**；官网优先、系统更新兜底。
- 验证驱动：**设备管理器无感叹号**、分辨率达原生值。
- 装完三件事：**备份镜像、跑性能基线、联网验证**。
