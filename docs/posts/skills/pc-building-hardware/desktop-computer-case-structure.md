## 为什么从机箱结构开始

上一节我们从架构图认识了「一台电脑由哪些部件构成」，本小节回答「这些部件被装进怎样的一个壳子里」。**机箱（case）**是整机最容易「最后才考虑」、却影响全局的一环：它决定你能装多大的主板、多长的显卡、几块硬盘，决定散热风道怎么走，也决定走线顺不顺、拆装顺不顺手。看懂机箱结构，你就知道**为什么主板规格、电源规格都围着机箱转**——选机箱不是「挑个好看的外壳」，而是「给整机定好户型的图纸」。

## 1 机箱规格：从「户型」说起

机箱按大小分几种规格，与主板规格一一对应：

**全塔（Full Tower）**：最高最大的机箱，容纳 E-ATX/ATX 主板、长显卡、多硬盘、360 水冷，扩展性最强，适合工作站与发烧配置。

**中塔（Mid Tower）**：最常见的机箱，容纳 ATX 与 M-ATX 主板、主流长显卡，空间与体积平衡，是绝大多数装机的选择。<span class="marginnote">中塔之所以「主流」，是因为它同时装得下 ATX 大板（扩展多）与 M-ATX 小板（省钱），散热与体积也平衡。买机箱时「中塔」二字几乎覆盖了 90% 的装机需求。</span>

**M-ATX 机箱（紧凑中塔）**：略小的中塔，装 M-ATX/ITX 主板，适合桌面空间有限的场景。

**ITX 迷你机箱（Mini-ITX case）**：最小的规格，只装 ITX 主板，体积小巧、桌面极简，但空间局促、散热与走线难度高。

**核心对比表：四种机箱规格**

| 规格 | 容纳主板 | 显卡长度 | 水冷 | 体积 | 适合场景 |
| --- | --- | --- | --- | --- | --- |
| 全塔 | ATX/E-ATX | 长（420mm+） | 360 冷排 | 最大 | 工作站、发烧 |
| 中塔 | ATX/M-ATX | 长 | 240–360 | 主流 | **绝大多数装机** |
| M-ATX | M-ATX/ITX | 中 | 240 | 紧凑 | 桌面空间有限 |
| ITX | ITX | 短 | 120–240 | 最小 | 极简、小体积 |

**选机箱第一问：你的主板是什么规格？** 机箱规格必须「大于等于」主板规格——ATX 主板装不进 M-ATX 机箱。**先定主板，再定机箱**，这条顺序与选主板时「先量机箱」并不矛盾：二者互相校验，最终取「兼容 + 够用」。

## 2 机箱的结构件：认识机箱的「五脏六腑」

一台标准中塔机箱，从内到外有这些结构件：

**主板托板（motherboard tray）**：机箱侧板内侧的金属大板，主板通过铜柱固定在它上面。托板背面是**背线仓**——走线的空间（回看《主板安装与机箱内部走线》）。<span class="marginnote">主板托板与背线仓是现代机箱的分水岭：老机箱没有背线空间，线只能全堆在正面；新机箱背面留 2–3cm 空腔，电源线从背面走，正面整洁、风道畅通。<strong>买机箱时留意「支持背线」</strong>，这是装机的舒适度分水岭。</span>

**电源仓（PSU bay）**：多数现代中塔把电源放在**底部**，独立仓室，与主板区隔开——底部进风、后部出风，还能充当机箱配重。

**硬盘位**：**3.5 英寸位**装机械硬盘，**2.5 英寸位**装 2.5 寸 SSD 或笔记本硬盘，另有**M.2 直插位**在主板上（SSD 直接插主板，不占机箱硬盘位）。

**散热位**：前置风扇位、后置风扇位、顶部水冷位、底部进风位——具体布置在《散热方案与机箱风道设计》详述。

**穿线孔与扎线位**：托板上的穿线孔、骨架上的扎线孔，供走线固定。

**电源键与前面板接口**：开关键、复位键、USB、耳机麦克风——通过跳线与排针接往主板（回看《前置面板跳线、USB 与音频接口接线》）。

## 3 前面板与接口布局：机箱的「门面」

机箱前面板（或顶部 I/O 区）的接口，是你每天都要用的「门面」：

**USB 接口**：前置 USB-A 与 USB-C，数量与版本（USB 3.0/3.1/3.2）决定日常插拔速度。<span class="marginnote">前置 USB 的版本要看机箱「接口版本」而非「外形」：同样是 USB-A 口，3.0（蓝色芯）与 2.0（黑色芯）速度差几十倍。<strong>装完机插 U 盘发现很慢，先看是不是插在了 2.0 口上</strong>。</span>

**音频接口**：耳机 + 麦克风 3.5mm 口，接主板音频排针（HD Audio）。

**开关键 / 复位键**：电源键、重启键，对应主板跳线区。

**防尘与散热**：前面板进风口的**防尘网**、侧板钢化玻璃/侧透面板——「侧透」好看但需注意风道（回看「风道」一节）。

**核心对比表：前面板接口与主板接线**

| 前面板接口 | 机箱内部连线 | 接往主板 |
| --- | --- | --- |
| 电源键 / 复位键 | 跳线（PWR/Reset） | 跳线针脚区 |
| 电源 / 硬盘指示灯 | 跳线（LED） | 跳线针脚区 |
| 前置 USB 3.0 | 蓝色 19-pin 排线 | USB 3.0 排针 |
| 前置 USB-C | Type-E 排线 | USB-C 排针 |
| 耳机 / 麦克风 | HD Audio 排线 | 音频排针 |

## 4 核心对比表：机箱选型的「八项核对」

把机箱知识串成一张选型核对表，下单前逐项打勾：

| 核对项 | 核对要点 |
| --- | --- |
| 主板规格 | 机箱支持 ≥ 你的主板规格 |
| 显卡长度 | 机箱显卡限长 ≥ 显卡长度 |
| 散热器高度 | CPU 风冷塔高 ≤ 机箱限高 |
| 水冷冷排 | 顶/前部能否装下你的冷排规格 |
| 电源规格 | ATX 电源位、长度（含模组线） |
| 硬盘位 | 够装你的 3.5/2.5 寸盘数量 |
| 背线空间 | 是否支持背线、走线孔是否齐全 |
| 前面板接口 | USB 版本、是否有 USB-C |

**辨析｜易错点：** 买机箱最容易「买错三样」——**主板装不进、显卡太长顶到硬盘位、CPU 散热器太高盖不上侧板**。这三样在选机箱时必须与主板、显卡、散热器同时核对，缺一不可。<span class="marginnote"><strong>「兼容性三角」</strong>：机箱、主板、散热器三者的尺寸必须一起算——主板定了板型，散热器定了高度，显卡定了长度，机箱再反过来校验这三者。把「显卡限长 ≥ 显卡长」写成一句核对口诀，装机前念一遍，能挡掉大半悲剧。</span>

## 5 机箱与整机的关系：结构决定体验

机箱不是被动容器，它主动决定整机的三个体验维度：

**散热体验**：风道设计、风扇位数量、防尘网密度——决定整机「凉不凉、脏得快不快」。

**拆装体验**：背线仓、免工具硬盘位、可拆卸防尘网——决定日后升级与清灰「顺不顺手」。

**静音与外观**：板材厚度、侧透、RGB 光效——决定「稳不稳、好不好看」。

**一句话总结**：机箱是整机的「**户型图 + 骨骼 + 风道 + 门面**」——选对机箱，装机顺一半；选错机箱，后面的散热、走线、升级全都别扭。

### 机箱选择的一句话口诀

机箱是「**买大不买小、留余量不将就**」——主板、显卡、散热器的尺寸都留点余量，日后升级时才会从容。一台机箱用五六年，当初多留的几厘米，就是日后少换一次机箱。

## 6 小结

- 机箱按规格分**全塔、中塔、M-ATX、ITX**，与主板规格对应——**先定主板，再定机箱**。
- 机箱结构件：**主板托板、背线仓、电源仓、硬盘位、散热位、穿线孔**——认识了它们，就认识了装机的「战场」。
- 前面板接口靠**排线与跳线**接往主板：电源键、USB、音频、指示灯各有一根线。
- 选型八项核对：**主板、显卡长、散热器高、水冷、电源、硬盘、背线、前面板**。
- 机箱决定整机的**散热、拆装、静音与外观**三维体验——它是户型图，不是装饰品。
