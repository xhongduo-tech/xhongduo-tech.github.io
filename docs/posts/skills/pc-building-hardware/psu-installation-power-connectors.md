## 为什么从电源安装开始

第 2 篇我们用功率计算选好了电源，本小节把它**装进机箱、接到每一块硬件**。这一步是整机装配的「供电中枢」环节：主板、CPU、显卡、硬盘都要从电源取电，**线接错、没接牢、接头混用**都可能造成开机无响应甚至烧件。安全上，电源是唯一直接连接 220V 市电的部件，**先断电再操作**的铁律在这里最要紧（回看《安全用电与作业环境要求》）。本小节讲清：**电源怎么固定、每根线接哪里、按什么顺序接、如何自查**。

## 1 电源固定：装进机箱电源仓

多数中塔机箱把电源装在**底部电源仓**，固定要点：

**第一步，确认朝向**。电源风扇朝**机箱外**（底部或侧面进风，看机箱设计），电源背面（电源开关与插头）朝机箱后部开口。

**第二步，固定电源**。用机箱附带的**电源螺丝**（圆头粗螺纹）从机箱外侧拧紧电源——**四颗都拧**，保证稳固。

**第三步，理出线材**。把需要接的线（主板 24-pin、CPU 8-pin、显卡线、SATA 线）从最近的穿线孔引出，多余线材收进背线仓——为后面的走线留好伏笔。<span class="marginnote"><strong>模组电源 vs 非模组</strong>：<strong>全模组电源</strong>的线可以按需插拔，只接需要的线，走线最清爽；<strong>非模组电源</strong>所有线都从机箱里引出，多余的线要妥善收纳。<strong>首次装机建议「半模组」起步</strong>——既有按需插线的便利，又比全模组便宜。</span>

## 2 供电线缆识别：一图认清每根线

电源线种类不多，但接头多样，先逐一识别：

**主板 24-pin 供电**：最大的扁平接头，接主板右侧 24-pin 插座——整机的主供电。**注意：老主板是 20-pin，多数 24-pin 接头可拆成 20+4 兼容**。<span class="marginnote"><strong>24-pin 的防呆</strong>：接头与插座都有卡扣，插反了进不去。<strong>插入时对准卡扣、均匀用力，听到「咔嗒」即到位</strong>——24-pin 是最常被「没插牢」的接头，开不了机第一查它。</span>

**CPU 8-pin 供电**：4+4 或 8-pin，接主板**左上角**（CPU 插槽旁）——给 CPU 供电。**它和显卡 8-pin 外观相近但线序不同，不要混用**。

**显卡 6/8-pin 供电**：接独立显卡，6-pin / 8-pin / 双头，线序与 CPU 线不同。

**SATA 供电**：扁平的 L 形接头，接 SATA 硬盘、SATA SSD、部分机箱风扇 hub。

**Molex（大 4-pin）**：老式硬盘/风扇接头，多为兼容遗留。

**核心对比表：常见供电接头**

| 接头 | 用途 | 插到哪 |
| --- | --- | --- |
| 24-pin | 主板主供电 | 主板右侧插座 |
| CPU 8-pin (4+4) | CPU 供电 | 主板左上角 |
| 显卡 6/8-pin | 显卡供电 | 显卡尾部 |
| SATA 供电 | 硬盘/SSD | SATA 硬盘 |
| Molex | 老设备/风扇 | 兼容设备 |

## 3 接线顺序与规范：先主后次，逐个确认

接线顺序有讲究，原则是**先接关键、再补齐，每根都确认到位**：

**第一步，接主板 24-pin**。对准卡扣插入，确认卡扣锁住。

**第二步，接 CPU 8-pin**。在主板上方，把 4+4 合成 8-pin 插入——若主板只有一个 4-pin 位，只插一组即可。

**第三步，接显卡供电**。显卡插好后，把显卡供电线插入显卡尾部 6/8-pin 口。<span class="marginnote"><strong>接线顺序的智慧</strong>：先接主板和 CPU（关键路径），再接显卡（空间大、好操作），最后接 SATA 等小线——<strong>先难后易、先主后次</strong>，避免后接的线挡住先接的位置。这与《主板安装与机箱内部走线》的走线顺序是同一套思想。</span>

**第四步，接 SATA 供电**。给硬盘、SATA SSD 供电，线从背线仓走。

**第五步，逐一检查**。开机前用手轻拉每根线确认「**拔不出来**」——接牢的线在卡扣下是拔不动的。

**辨析｜易错点：** 两个高频错误——**CPU 8-pin 与显卡 8-pin 混插**（线序不同，可能导致供电异常）和**接头没插到底就开机**（接触不良、发热甚至烧接头）。**认准接头形状与卡扣，插到底听到「咔嗒」**，是供电接线的全部要领。

## 4 公式解析：为什么要「线材足、接头牢」

电源接线的本质，是让电源以正确的**电压与电流**送给每个部件。用基本电学关系看：

$$
P = U \times I
$$

- **$P$**：部件功耗（瓦特）。
- **$U$**：供电电压——+12V 供 CPU/显卡，+5V 供 USB，+3.3V 供主板与内存。
- **$I$**：电流——由接头与线材承载。

**代入看设计**：一块 300W 的显卡走 +12V，电流 $I = 300/12 = 25\ \text{A}$——这么大的电流需要**粗线材 + 多个 8-pin 接头并联**分流（单个 8-pin 通常承载 150W 左右）。所以：**高功耗显卡要接够接头数**，少接一个就等于让剩余接头过载发热。<span class="marginnote"><strong>「接头够不够」就是「电流撑不撑得住」</strong>：显卡 150W 用单 8-pin 刚好，250W 就要双 8-pin——电源厂商按接头数标了承载上限。<strong>别用转接头硬凑</strong>（如 6-pin 转 8-pin），转接只是物理兼容，线材载流没有变粗，仍有风险。</span>

**这条公式还解释了「接牢」的必要性**：接头接触不良会增大接触电阻，局部发热甚至烧蚀——**接触电阻最小化**（插到底、卡扣锁）是供电安全的前提。

## 5 供电接线的自查清单

通电前按清单走一遍，把「看不见的风险」都排查掉：

- 24-pin、CPU 8-pin、显卡供电、SATA 供电**全部接上**（缺一根 = 某部件没电）。
- 每根接头**插到底、卡扣锁住、轻拉不动**。
- **CPU 8-pin 与显卡 8-pin 未混用**。
- 电源开关在 **O（关）** 位，插好市电线再开机。
- 通电后机箱风扇、CPU 风扇、显卡风扇**都转**——供电接线成功的直观信号。

### 模组电源的接线规划

使用**模组电源**时，接哪些线、留哪些线，是值得规划的：

**先规划，再接线**：通电前，把需要的线列出来——主板 24-pin、CPU 8-pin、显卡（按功耗定接头数）、SATA（按硬盘数）。**只接需要的线**，多余的收进配件袋——走线清爽、风道畅通。

**模组接口别插错**：模组电源的线材接口有防呆，但**不同规格的接口仍可能混淆**——对照说明书确认「这根线插这个口」，别凭感觉。

**核心对比表：模组电源的接线选择**

| 设备 | 必接线 | 说明 |
| --- | --- | --- |
| 主板 | 24-pin | 必接 |
| CPU | 8-pin | 必接 |
| 显卡 | 6/8-pin ×N | 按功耗接头数 |
| 硬盘 | SATA 线 | 按数量 |
| 外设 | Molex/其他 | 按需 |

**模组电源的「先留线」哲学**：为将来升级留一两个模组接口与线材——换显卡、加硬盘时，不必重新理线。

**一句话**：模组电源 = **先规划、按需接、留余量**——它的便利，只有规划过的人才能享受到。

## 6 小结

- 电源装进**底部电源仓**，风扇朝外、开关朝后、螺丝四颗拧紧。
- 供电线缆认全：**24-pin 主板、CPU 8-pin、显卡 6/8-pin、SATA、Molex**。
- 接线顺序：**先主板与 CPU、再显卡、后 SATA**，每根插到底听「咔嗒」。
- 公式 $P = UI$：**高功耗部件要多接头分流**，别用转接头硬凑。
- 通电前自查：**线全接、卡扣锁、CPU/显卡线不混用**——风扇都转，供电就成功了。
