## 为什么从外设与整机装配开始

前面几节把主机内部装完了——CPU、内存、显卡、电源、跳线全部就位。本小节做两件事：把**外部设备**接上（键盘、鼠标、显示器、音箱），并把整机**合拢、理线、收尾**。外设是冯·诺依曼架构里「输入输出设备」的实体：没有显示器，你看不见计算结果；没有键盘鼠标，你无法发出指令。<span class="marginnote">从架构的视角看，本小节是「输入输出」环节的收官——<strong>架构图里那个「输出设备」，此刻真正变成了你眼前的屏幕</strong>。接好外设、合拢机箱，这台电脑就从「一堆零件」变成了「一台可用的机器」。</span>

## 1 外设认知：输入输出设备的完整拼图

**外设（peripheral）**分两类，对应架构的输入与输出：

**输入设备**：键盘（字符输入）、鼠标（指针操作）、麦克风（语音）、摄像头（图像）、游戏手柄（指令）。<span class="marginnote"><strong>输入设备的「接口世代」</strong>：老设备用 PS/2 圆口（键盘鼠标专用），现代设备统一走 USB——USB 键盘鼠标即插即用，装系统前就能用，这是「U 盘装系统」的前提。</span>

**输出设备**：显示器（画面）、音箱（声音）、打印机（纸质输出）。外设的接线方向，决定了「数据从主机流向哪」。

**核心对比表：常见外设与接口**

| 外设 | 接口 | 即插即用 |
| --- | --- | --- |
| 键盘 / 鼠标 | USB（或无线） | 是 |
| 显示器 | DP / HDMI | 是 |
| 音箱 | 3.5mm / USB / 蓝牙 | 是 |
| 打印机 | USB / 网络 | 装驱动后 |
| 摄像头 | USB | 是 |

## 2 显示器连接：把画面送上屏幕

显示器是「输出设备的头号主角」，连接有讲究：

**接口选择**：优先 **DP**（带宽高、支持高刷），其次 **HDMI**——回看《显卡与显示输出接口》的接口知识。独显装好后，**显示器线要插显卡的接口**（而不是主板的核显接口），否则画面走核显、独显白装。

**分辨率与刷新率设置**：接好后在系统设置里把分辨率调到**显示器原生分辨率**（如 2560×1440）、刷新率调到**支持的最高值**（如 144Hz）——**默认 60Hz 不一定是显示器的最佳状态**。<span class="marginnote"><strong>「买 144Hz 却跑 60Hz」</strong>：高刷显示器默认可能只有 60Hz，<strong>要到系统设置里把刷新率改成 144Hz</strong>；同时在 NVIDIA 控制面板确认输出位深与颜色格式。这一步是显示器「物尽其用」的关键，也呼应了《显卡与显示输出接口》里「接口版本决定分辨率上限」的判断。</span>

**多屏扩展**：办公或剪辑场景常用双屏——第二屏接另一接口，系统里选择「扩展这些显示器」。

**辨析｜易错点：** **显示器不亮 ≠ 主机坏了**。先查：显示器电源是否开、线是否插在显卡口、输入源（HDMI/DP）是否选对——这三项占了「显示器不亮」的绝大多数原因。

## 3 整机装配收尾：合拢、理线、开机自检

外设接好，做整机收尾三件事：

**第一步，合上侧板**。确认内部无遗留螺丝、线材未压住散热器与风扇，再合上侧板拧紧螺丝。<span class="marginnote"><strong>合侧板前最后检查</strong>：<strong>线有没有压到 CPU 散热器</strong>、有没有伸进显卡风扇、侧板能否盖平（太高散热器会顶侧板）。<strong>「先裸机点亮，再合侧板」</strong>是稳妥做法——亮机后再合，出问题好排查。</span>

**第二步，整理桌面端**：主机放在通风位置（别贴墙堵风道）、桌面线材理顺，显示器、键盘鼠标线各就各位。

**第三步，开机自检（POST）**：通电 → 按电源键 → 观察——风扇转动、屏幕出现主板 LOGO、进入 BIOS——**这就是「点亮」成功**，整机装配环节完成。<span class="marginnote"><strong>自检（POST）是硬件的「自我体检」</strong>：BIOS 检测 CPU、内存、显卡、硬盘是否就位正常，<strong>任一部件缺失或故障，会以「蜂鸣声 + 错误码」报警</strong>（如内存报警音）——听懂蜂鸣，是排障的第一课（回看《点亮测试与开机故障排查流程》）。</span>

## 4 公式与要点解析：为什么「外部连接」也讲究匹配

外设连接同样适用「匹配思维」——用显示器带宽公式看接口选择：

$$
\text{带宽需求} = \text{分辨率像素} \times \text{刷新率} \times \text{色深位数}
$$

- **分辨率像素**：如 2560×1440 ≈ 370 万像素。
- **刷新率**：每秒刷新次数，如 144Hz。
- **色深位数**：每像素的位数（如 8bit × RGB = 24bit）。

代入 2K@144Hz@8bit：$370万 \times 144 \times 24 \approx 12.8\ \text{Gbit/s}$——**必须用 DP 1.4 或 HDMI 2.1 才够**。这条公式把「接口选择」从经验变成计算：**分辨率、刷新率越高，需要的接口代数越新**。<span class="marginnote"><strong>「接口版本决定体验上限」再验证</strong>：4K@60Hz 与 2K@144Hz 的带宽需求相近，但都远超老接口（HDMI 1.4）的承载——<strong>显示器、显卡、线材三者的接口版本要一起看</strong>，一条老线就锁死整条链路。</span>

## 5 整机装配检查清单

整机合拢前，走一遍「终检」：

- 内部无遗留螺丝、无散落扎带。
- 线材未压住散热器与风扇、未横跨风道。
- 侧板能盖平、螺丝拧紧。
- 外设线材接对（显示器插显卡口、USB 设备插 USB 口）。
- 电源插头接好、电源开关拨到 **I（开）**。

全部通过，按电源键——**点亮成功，就是整机装配的毕业礼**。

### 外设的日常维护与升级扩展

整机交付后，外设还有「长期经营」：

**显示器维护**：定期清洁屏幕（专用清洁剂 + 无绒布，勿用酒精）；**避免长时间静态画面**（OLED 尤其注意烧屏）；专业用户可做色彩校准。

**键盘鼠标**：机械键盘定期清灰、键帽可拆卸清洗；鼠标传感器除尘、滚轮润滑。

**音箱与耳机**：避免长期大音量（保护听力也保护单元）；线材勿过度弯折。

**扩展思路**：外设可以「先简后繁」——先接键盘鼠标显示器（必需），再加音箱摄像头（体验），最后接打印机、NAS（效率）——**外设按需升级，是成本与体验的平衡**。

**核心对比表：外设维护周期**

| 外设 | 维护动作 | 周期 |
| --- | --- | --- |
| 显示器 | 清洁屏幕 | 每月 |
| 机械键盘 | 清灰、拆洗键帽 | 每季度 |
| 鼠标 | 除尘、检查滚轮 | 每季度 |
| 音箱 | 检查线材 | 每半年 |

**一句话**：外设是「天天用、时时维护」的伙伴——**善待外设，就是善待你与电脑相处的每一天**。

**整机交付的「仪式感」**：装机收尾后，把配件包装、说明书、保修卡整理好，连同「配置清单」一起交给用户——**交付的不只是机器，还有一份清晰的档案**，这也是《装配调试员职业认知与作业规范》「可追溯」的延伸。

## 6 小结

- 外设分**输入**（键盘鼠标等）与**输出**（显示器音箱等），对应架构的输入输出设备。
- 显示器连接：**DP 优先、HDMI 其次，线插显卡口**；设置原生分辨率与最高刷新率。
- 收尾三件事：**合侧板前终检、桌面理线、开机自检（POST）点亮**。
- 带宽公式 $\text{带宽} = \text{像素} \times \text{刷新率} \times \text{色深}$：**分辨率与刷新率越高，接口代数越新**。
- 点亮成功 = 硬件装配环节完成——下一阶段进入「软件世界」：BIOS 设置与系统安装。
