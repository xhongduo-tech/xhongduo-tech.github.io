# 击剑

击剑是一项以剑的刺劈对抗为核心、兼具速度、技巧与战术的格斗型运动，涵盖花剑、重剑、佩剑三个剑种，是锻炼专注力、反应力与心理博弈的绝佳项目。以《击剑运动教程》、FIE 竞赛规则与击剑教学体系为纲，系统重建从运动基础、三剑种攻防技术到竞赛规则与训练方法的完整知识体系。
