# 冰球运动

冰球运动是一项在冰面上进行的快速对抗性冬奥团体项目，融合滑行技巧、杆上技术、冲撞强度与团队攻防战术，是速度与智慧高度结合的竞技运动。以IIHF《冰球竞赛规则》、《冰球运动教程》与中国冰球协会培训体系为纲，系统重建从竞赛规则、滑行与杆上技术到攻防战术、体能训练与教练员认证的完整知识体系。
