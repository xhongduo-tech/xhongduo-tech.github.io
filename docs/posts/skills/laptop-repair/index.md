# 笔记本电脑维修

笔记本电脑的 BGA/显卡、键盘、屏幕、电池、散热等模块维修是独立职业方向，市场需求大、技术门槛清晰。以《国家职业技能标准·计算机维修工》、CompTIA A+ 认证教材及 iFixit 笔记本电脑维修指南为纲，系统建立从拆装规范、供电诊断、显示与显卡返修到散热与整机检修的完整维修技能体系。

## 对标教材

- 《国家职业技能标准·计算机维修工》
- CompTIA A+ 认证教材（Core 1 / Core 2）
- iFixit 笔记本电脑维修指南
