# 高效学习与记忆术

高效学习与记忆术是以认知科学和脑科学为基础的方法体系，融合记忆宫殿等经典记忆术与间隔重复、刻意练习等科学练习策略，帮助你学得更快、记得更牢。学完这些章节，就掌握了让学习事半功倍、让记忆经久不忘的底层方法。

## 对标教材

- 《学习之道》（芭芭拉·奥克利）
- 《记忆宫殿》（琳恩·凯利）
- 《认知天性》（彼得·C·布朗、亨利·L·罗迪格三世、马克·A·麦克丹尼尔）
