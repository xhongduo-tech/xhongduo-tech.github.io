## 为什么从工具开始

前面讲了皮肤、结构、色彩，都是「纸上谈兵」的知识；从这一节开始，知识要落到手上。而手要落地，先得有一件称手的工具。**化妆工具的差别，往往比产品贵贱更能决定妆效**：一支松散的刷子上粉底会留刷痕，一支密实的刷子却能把粉底推开得毫无边界。<span class="marginnote">本站讲数学时强调「概念要先于计算」，这里同理：先认识工具的分类与功能，再谈具体手法，手法才有载体。</span>

## 1 化妆工具的分类

化妆工具按功能可分为五大类：

**底妆工具**：粉底刷、粉扑（海绵）、美妆蛋、散粉刷。负责粉底的铺开、按压与定妆。
**眼妆工具**：眼影刷（分大、中、小与晕染刷）、眼线刷、眉刷、睫毛夹。负责眼部的精细描绘。
- **眉妆工具**：螺旋眉刷、斜角眉刷。负责眉粉、眉膏的上色与梳理。
- **颊妆工具**：腮红刷、修容刷、高光刷。负责面颊的铺色与立体塑造。
- **唇妆工具**：唇刷。用于精确勾勒唇形与均匀上色。<span class="marginnote">一把好唇刷能把口红涂得边界清晰、量薄而匀，尤其适合新娘妆与唇形修正场景——这是后面《唇妆技术》的伏笔。</span>

## 2 刷具的选择：毛质与形状

选择刷具，核心看两个变量：**毛质**与**刷头形状**。

### 毛质：天然毛 vs 人造毛

| 毛质 | 特点 | 适用 |
| --- | --- | --- |
| 天然毛（动物毛） | 柔软抓粉、晕染自然 | 粉状产品：眼影、腮红 |
| 人造毛（纤维毛） | 不吃粉、易清洗、性价比高 | 膏状/液体产品：粉底、口红、遮瑕 |

**重点：干湿分开用。** 沾液体、膏体的刷子（粉底刷、唇刷）应选人造毛，因为膏体容易渗入天然毛内部，清洁不彻底会滋生细菌；沾粉状产品的刷子（眼影刷、腮红刷）可选天然毛，抓粉与晕染更柔和。<span class="marginnote">「人造毛配膏体、天然毛配粉体」是刷具选择的第一条铁律，比看品牌和价格更重要。</span>

### 刷头形状：决定上色方式

**扁平头**：适合铺色与按压，如平头粉底刷。
**圆头/球形**：适合打圈晕染，如散粉刷。
- **尖头/锥形**：适合细节与精确上色，如眼影细节刷、眉刷。
- **斜角头**：贴合面部曲线，适合修容与眉形勾勒。

## 3 化妆工具的保养

工具的寿命与卫生，取决于保养。保养分日常与定期两个层次：

**日常保养（每次使用后）**：粉扑、美妆蛋用后清洗，挤干水分阴干；刷具用后可用刷网或纸巾擦去余粉，保持刷毛不板结。<span class="marginnote">美妆蛋「湿用」前要吸水挤干，八分干状态上妆最服帖——这个细节直接关系到底妆质量，第2篇《底妆技术》会再强调。</span>

**定期清洗（每周 1–2 次）**：刷具用专用清洗液（或温和皂液）顺着毛流冲洗，洗后平放阴干，**切勿刷头朝上插杯晾干**——水会倒流进刷管，导致刷毛脱落、金属件生锈。

**辨析｜易错点：** 新手最常见的毁刷操作是「用热水烫刷具杀菌」。热水会破坏刷毛的纤维结构与胶水粘合，**刷具清洗必须用常温水或温水**。清洁的意义是除油除菌，不是「烫」——就像本站讲实验方法时强调的：手段要匹配目的，过度手段反而破坏对象。

## 4 核心要点对比：工具、用途与清洁频率

把主要工具、用途与清洁节奏整理成一张表，作为「工具台账」使用：

| 工具 | 主要用途 | 清洁频率 | 备注 |
| --- | --- | --- | --- |
| 粉底刷 | 铺开液体粉底 | 每周 2 次 | 膏体易滋生细菌 |
| 美妆蛋 | 按压底妆、去刷痕 | 每次用后 | 湿用更服帖 |
| 散粉刷 | 全脸定妆 | 每周 1 次 | 大而蓬松 |
| 眼影刷（组） | 眼影铺色与晕染 | 每周 1 次 | 深浅色分开用 |
| 眉刷 | 眉粉上色 | 每周 1 次 | 斜角更精确 |
| 腮红/修容刷 | 面颊铺色 | 每周 1 次 | 避免混色 |
| 唇刷 | 唇形勾勒 | 每次用后 | 与口红膏体接触 |

**工具管理的本质，是「卫生 + 功能 + 成本」三者的平衡**：刷具是化妆师的固定资产，保养得当能用数年，保养失当几个月就报废。这与职业技能标准中「工具用品管理」的模块要求一一对应。

## 5 术语速查表

| 术语 | 含义 |
| --- | --- |
| 粉底刷 | 铺开液体/膏体粉底的刷具 |
| 美妆蛋 | 按压式上妆的海绵，湿用更服帖 |
| 散粉刷 | 全脸定妆的大而蓬松的刷具 |
| 天然毛 | 抓粉柔和、适合粉状产品的动物毛 |
| 人造毛 | 不吃粉、易清洗、适合膏体的纤维毛 |
| 斜角刷 | 贴合面部曲线的刷形，适合修容与眉形 |
| 刷网 | 收纳刷具、防止刷毛变形的护套 |
| 湿用 | 美妆蛋吸水挤干至八分干再使用的用法 |

## 6 小结

- 化妆工具分**底妆、眼妆、眉妆、颊妆、唇妆**五大类，各司其职。
- 刷具选择看**毛质与刷头形状**：人造毛配膏体、天然毛配粉体。
- 工具保养分**日常清洁**与**定期清洗**两层；清洗用常温水、平放阴干。
- 工具管理是**卫生、功能、成本**的平衡，也是职业化妆师的基本功。
