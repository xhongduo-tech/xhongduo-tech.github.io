## 为什么从皮肤开始

上一节认识了面部结构，这一节转向最表面的器官——**皮肤**。化妆师的技术再高，也改变不了「皮肤状态决定底妆上限」这个事实：干燥起皮的脸，粉底必然浮粉；油光满面的脸，底妆必然脱妆。因此，**认识皮肤类型、做好妆前护理，是底妆技术之前必须打通的一环**。<span class="marginnote">这与本站「先修地基再盖楼」的治学顺序一致：皮肤是底妆的地基，底妆是彩妆的地基。</span>

## 1 皮肤的层次与功能

**皮肤**是人体最大的器官，分三层：**表皮**（最外层，直接与化妆品接触）、**真皮**（含胶原与弹性纤维，决定皮肤的紧致与弹性）、**皮下组织**（脂肪层，缓冲与保温）。<span class="marginnote">化妆品的绝大部分只作用于表皮角质层，几乎不进入真皮。这一点对「妆前护理」很重要：妆前保湿做的是表皮层的工作，指望一瓶粉底去「深层滋养」是不现实的。</span>

**重点：角质层是化妆品的「主战场」。** 角质层含水量与皮脂膜的完整度，决定了底妆是否服帖。角质层缺水，粉底颗粒失去「湿润的着陆面」，就会结块、起皮——这就是为什么妆前保湿是底妆不可省略的前置步骤。

## 2 皮肤类型的判断

皮肤类型按皮脂分泌量与含水状态，大致分四类：

| 类型 | 特征 | 妆前护理要点 |
| --- | --- | --- |
| 干性皮肤 | 肤质细腻、易起皮，T区也少油 | 重保湿，妆前乳选滋润型 |
| 油性皮肤 | 出油快、毛孔粗，易脱妆 | 控油+适度保湿，妆前乳选控油型 |
| 混合性皮肤 | T区油、两颊干 | 分区护理，T区控油两颊保湿 |
| 敏感性皮肤 | 易泛红、刺痛、对成分敏感 | 成分精简，先做局部测试 |

**自我判断的方法**：温水洁面后不涂任何护肤品，等待 30 分钟观察——全脸紧绷为干性；仅T区出油为混合性；全脸泛油为油性；若有泛红、刺痛感，须考虑敏感性皮肤。<span class="marginnote">判断皮肤类型和上一节判断脸型是同一套方法：先定观察条件（清洁后、静止30分钟），再分类归入——「先建模、再归类」在护肤里同样成立。</span>

## 3 妆前护理流程

妆前护理的标准流程，按顺序走四步：

**第一步，清洁**：用温和洁面洗去油脂与灰尘，为后续产品扫清障碍。敏感肌避免过度清洁。
**第二步，水**：用化妆水（爽肤水）补充角质层水分，轻拍或按压吸收。
**第三步，乳/霜**：用乳液或面霜锁水，建立皮脂膜的替代层。干性皮肤可叠加，油性皮肤选轻薄质地。
- **第四步，防晒与隔离**：日间必须防晒；隔离/妆前乳则在粉底之前打底，调节皮肤状态（控油、保湿、填毛孔）。

**辨析｜易错点：** 新手最常见的错误是「妆前护理越厚越好」。实际上**过厚的护肤品会让粉底「打滑」、搓泥**。妆前护理的原则是「够润而不腻」：涂抹后等 2–3 分钟，摸上去微润而不油亮，才是理想的底妆前置状态。<span class="marginnote">「等待吸收再上粉底」是关键细节——护肤品没有充分成膜就叠加粉底，两者会互相排斥，搓泥几乎必然发生。</span>

## 4 妆前护理与妆效的因果关系

把妆前护理的每个环节，和它对应的妆效问题连成一张「因果表」，是化妆师诊断脱妆、浮粉的思路：

| 妆效问题 | 最可能的妆前原因 | 修正方向 |
| --- | --- | --- |
| 浮粉、起皮 | 角质层缺水 | 加强保湿，先敷水膜再上底妆 |
| 脱妆、斑驳 | 出油过多且未控油 | 控油妆前乳 + 分区定妆 |
| 搓泥 | 护肤品层叠过厚 | 减量、减层，充分吸收后再上妆 |
| 卡粉、发干 | 粉底与肤质不匹配 | 换滋润型粉底或混合精华使用 |

**把「妆效问题」反向翻译成「护理方案」，是职业化妆师的核心能力**——会画只是第一步，会诊断才能应对不同皮肤的真实情况。这与本站贯穿各学科的方法论一致：出了问题先定位原因，再对症下药，而不是盲目加码。

除了这四类常见问题，还有两类「季节变量」值得注意：

- **夏季**：气温升高、皮脂分泌加快，油性倾向增强——原定妆前乳与定妆步骤要相应加强控油。
- **冬季**：空气干燥、角质层含水量下降，干性倾向增强——原保湿步骤要加量，必要时在妆前叠一层保湿精华。

季节变化会临时改变皮肤类型的「表现」，所以职业化妆师不会把肤质判断当成一次定死的结果，而会在换季、换城市、熬夜后重新评估——**皮肤状态是动态的，护理方案也要跟着动态调整**。

### 动手练习：判断并记录自己的肤质

把判断方法落地成一次「自我诊断」，可以这样做：

- **第一步**：晚上用温和洁面洗脸，不涂任何护肤品。
- **第二步**：睡前与次日清晨各观察一次：T 区是否出油、两颊是否紧绷、有没有泛红刺痛。
- **第三步**：对照四类肤质表，写下自己的判断，并说明依据（出油位置 / 紧绷程度 / 敏感表现）。
- **第四步**：选一款合适的妆前护理流程（清洁→水→乳/霜→防晒隔离），列出自己会用到的产品类型。

这个练习的意义在于「建立皮肤档案」：肤质不是一次性的标签，而是一条需要持续更新的记录。**每次换季、每次熬夜后重新评估一次，皮肤档案就会越来越准确**——这也是职业化妆师「按肤质动态调整方案」的日常操作。

### 妆前护理的时间轴案例

把妆前护理放进一次「早八点出门」的时间轴，能看清各步骤如何配合：

- **7:20 洁面**：温和洁面，避免过度清洁带走过多油脂。
- **7:22 拍水**：化妆水轻拍至吸收，补充角质层水分。
- **7:25 乳/霜**：按肤质涂乳液或面霜，等待 2 分钟基本成膜。
- **7:30 防晒与隔离**：先防晒，再上妆前乳调节皮肤状态。
- **7:35 上粉底**：此时皮肤「微润不油」，正是上底妆的最佳窗口。

这个案例的要点，是**每步之间留出吸收时间**——护肤品逐层叠加，每一层都要等前一层基本成膜，才能发挥各自功能。**妆前护理的质量，不只取决于「用了什么」，还取决于「每步之间的节奏」**。<span class="marginnote">「等吸收」是妆前护理最容易被忽略的细节：护肤品需要时间与皮肤结合，不等就叠下一层，不仅吸收差，还容易搓泥——节奏本身就是质量。</span>

| 干性皮肤 | 油脂少、易起皮、需重保湿的肤质 |
| 油性皮肤 | 出油快、易脱妆、需控油的肤质 |
| 混合性皮肤 | T 区油、两颊干的常见肤质 |
| 敏感性皮肤 | 易泛红刺痛、需成分精简的肤质 |
| 妆前乳 | 粉底前调节皮肤状态的打底产品 |

| 表皮 | 皮肤最外层，化妆品的主要作用层 |

## 6 小结

- 皮肤分**表皮、真皮、皮下组织**三层，角质层是化妆品的直接作用层。
- 皮肤类型分**干性、油性、混合性、敏感性**四类，用「清洁后观察 30 分钟」判断。
- 妆前护理四步：**清洁 → 水 → 乳/霜 → 防晒隔离**。
- 妆前护理的原则是**够润而不腻**；学会把「妆效问题」翻译成「护理方案」，才算真正掌握这门手艺。
