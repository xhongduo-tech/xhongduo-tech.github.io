## 为什么从面部结构开始

化妆是在「脸」上作画，而脸是骨骼、肌肉与皮肤共同搭出的立体结构。如果不认识这个结构，粉底只会「涂在表面上」，修容只会「画错位置」。这一节建立两个坐标系：**解剖坐标系**（骨骼与肌肉决定明暗）与**美学坐标系**（三庭五眼决定比例）。二者合起来，就是后面所有妆容设计的底层图纸。<span class="marginnote">这就像本站从极限、函数这些基础出发再进入大模型一样：先有一张准确的地图，才谈得上在图上作画。</span>

## 1 面部的骨骼与肌肉结构

### 骨骼：妆容的支架

面部骨骼决定了五官的位置与轮廓的基本形态。需要记住的关键结构有：

**颧骨**：决定面中部宽度，是修容时「提亮」还是「压暗」的参照。
**下颌骨（下颌角）**：决定脸型下方轮廓，腮红与修容常围绕它收线。
**眉弓**：眼眶上缘的隆起，是眉形设计的骨骼基础。
- **鼻骨**：决定鼻梁高低，影响鼻影的画法。<span class="marginnote">「额头→眉弓→鼻骨→下颌」这条骨骼曲线，直接决定了面部侧面光影的分布——修容时压暗哪里、提亮哪里，全由这条曲线说了算。</span>

### 肌肉：表情与皮肤张力

面部表情肌收缩产生表情，也让皮肤产生褶皱。化妆师关心肌肉，是为了理解**表情纹与皮肤走向**：笑纹、法令纹、抬头纹都沿肌肉收缩方向分布。底妆若在表情区堆得太厚，一笑就开裂。<span class="marginnote">「笑起来测试底妆」是职业化妆师的惯例：让模特微笑，观察粉底是否在法令纹处积粉，是检验底妆持妆性的简单方法。</span>

## 2 三庭五眼：审美比例坐标

**三庭五眼**是东方审美中最基础的面部比例学说。它把正面脸放入一张可测量的网格，用来判断五官分布的和谐程度，也是化妆调整的「理想目标」。

**三庭（三等分纵向）**：从发际线到下巴，用两条水平线分成三等分：

**上庭**：发际线 → 眉线（眉心）。
**中庭**：眉线 → 鼻底线。
**下庭**：鼻底线 → 下巴尖。

**五眼（五等分横向）**：脸的宽度约等于五个眼睛的宽度。以眼宽为度量单位，从左到右依次为：左眼外角至左眼内角、左眼宽、两内眼角间距、右眼宽、右眼外角至右眼外缘——正好五等分。

![三庭五眼面部比例示意图](/images/zao-xing-yu-hua-zhuang/facial-structure-three-fifths-aesthetics-1.svg)

**重点：三庭五眼是「参考系」而非「镣铐」。** 绝大多数人的脸并不严格满足五眼比例，但这恰好是化妆的用武之地——中庭偏长就用修容视觉缩短，眼距偏宽就用眼线内眼角拉近。**化妆的本质，就是在三庭五眼的坐标上做「视觉矫正」。**<span class="marginnote">三庭五眼主要针对正面。侧面审美还看「四高三低」：额、鼻尖、唇珠、下巴尖为高，眼窝、人中、唇下为低——这是侧面轮廓修容的依据。</span>

## 3 脸型分类与对应修正

用「长宽比」与「轮廓特征」两个维度，正面脸型可分为六类：

| 脸型 | 特征 | 化妆修正方向 |
| --- | --- | --- |
| 椭圆脸（鹅蛋脸） | 长宽比约 3:2，线条流畅 | 各画法基本通用，是理想脸型 |
| 圆脸 | 长宽比接近 1:1，颧骨宽 | 修容纵向拉长，眉形挑高 |
| 方脸 | 下颌角明显，轮廓硬朗 | 修容柔化下颌角，眉形圆润 |
| 长脸 | 中庭/下庭偏长 | 横向扩大色彩，缩短中庭 |
| 心形脸 | 额宽颧窄，下巴尖 | 强调下庭宽度，弱化额头 |
| 菱形脸 | 颧骨最宽，额与下巴窄 | 两侧提亮，颧骨压暗 |

**辨析｜易错点：** 判断脸型最忌「只凭第一印象」。正确做法是**把头发全部拢到耳后，正面平视镜子**，先量长宽比，再观察额、颧、下颌三处最宽点，最后才归入某一类。很多新手把圆脸误判成方脸，就因为没把头发拢干净——观察方法错了，后面一切修正都是空谈。<span class="marginnote">脸型判断与数学里的分类讨论同构：先定维度（长宽比、轮廓特征），再逐类归入，而不是凭感觉猜——这是本站反复强调的「先建模、再计算」思维在化妆里的翻版。</span>

## 4 三庭五眼的测量与运用

把三庭五眼从「概念」变成「工具」，需要一次可操作的测量流程。以「中庭偏长」为例做三步分析：

- **第一步，定位**：找到发际线、眉线、鼻底线、下巴线四条水平基准线，以及两侧外眼角、内眼角四个点。
- **第二步，测量**：比较上、中、下三庭是否各占 $\tfrac{1}{3}$；用眼宽度量脸宽是否约 5 等分。这一步可以用「目测 + 指宽」粗测，不必精确到毫米。
- **第三步，矫正**：哪一庭偏长，就减少那一庭的纵向色彩并向下/向上转移视觉焦点。中庭偏长，把眉形略下压、鼻影在鼻头处收短，视觉上中庭就「短」了。

**三庭五眼的学习路径，与数学里的「单位换算」异曲同工**：先建立标准单位（眼宽、庭），再测量偏差，最后用化妆手段修正偏差。这套「标准—测量—修正」的循环，会贯穿本专题每一篇妆容设计。

## 5 术语速查表

| 术语 | 含义 |
| --- | --- |
| 三庭 | 发际线到下巴纵向三等分：上庭、中庭、下庭 |
| 五眼 | 以眼宽为单位，脸宽约五等分 |
| 四高三低 | 侧面审美标准：额、鼻尖、唇珠、下巴高；眼窝、人中、唇下低 |
| 颧骨 | 决定面中部宽度，修容的关键参照 |
| 下颌骨 | 决定脸型下方轮廓，含下颌角 |
| 眉弓 | 眼眶上缘隆起，眉形设计的骨骼基础 |
| 椭圆脸 | 长宽比约 3:2 的理想脸型 |
| 视觉矫正 | 通过化妆调整五官比例的审美目标 |

## 6 小结

- 面部结构以**骨骼为支架、肌肉为动力**，颧骨、下颌骨、眉弓、鼻骨是妆容设计的关键参照。
- **三庭**纵向三等分面部（上庭、中庭、下庭）；**五眼**横向以眼宽五等分脸宽。
- 六类脸型（椭圆、圆、方、长、心形、菱形）各有对应的修容修正方向。
- 判断脸型要**拢发平视、先量后判**；三庭五眼是参考系，不是镣铐。

在下一节，我们将从「静态的结构」转向「动态的皮肤」：认识皮肤类型，学会妆前护理——这是所有妆容能否服帖、持久的起点。
