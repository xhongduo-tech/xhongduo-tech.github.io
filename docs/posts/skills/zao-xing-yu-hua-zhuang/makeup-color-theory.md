## 为什么从色彩开始

底妆解决了「皮肤干不干净」，色彩解决的是「整个妆有没有气质」。一支口红、一盘眼影的差别，本质上是色彩的差别；而为什么「红唇配红眼影会显得俗气」「大地色怎么搭都不会出错」，背后是一套可学习的配色规律。<span class="marginnote">色彩规律并不神秘——它源于光与眼睛的物理，又与审美心理相连。本站从物理学的光的色散到美学的色彩观感之间，都有这条线索可循。</span>

## 1 色彩的三要素

要讨论配色，先要精确描述「一个颜色」。任何颜色都可用三个属性刻画，称为**色彩三要素**：

**色相（Hue）**：颜色的种类，如红、黄、蓝。色相决定了「这是什么颜色」。<span class="marginnote">色相环（色轮）把色相按光谱顺序排成环形，是配色的基本地图：红橙黄绿蓝紫，加上相邻色之间的过渡。</span>

**明度（Value）**：颜色的明暗程度。明度高接近白，明度低接近黑。同一色相可以有不同的明度，如粉红（高明度）与暗红（低明度）。

**饱和度（Saturation / 纯度）**：颜色的鲜艳程度。饱和度高鲜艳刺眼，饱和度低灰浊柔和。

**重点：三要素中，化妆师最先要掌握的是「饱和度」。** 大红与砖红是同一色相、不同饱和度的颜色；「浓妆」与「淡妆」的区别，常常不是色相变了，而是饱和度与用色面积变了。把饱和度降下来，浓色也能变日常。

## 2 配色原理：色相环上的关系

以 12 色相环为工具，配色关系主要有几类：

| 关系 | 色相环位置 | 效果 | 化妆应用例 |
| --- | --- | --- | --- |
| 同色系 | 同一色相的深浅 | 和谐统一、安全 | 大地色眼影（棕→深棕→浅棕） |
| 邻近色 | 色环上相邻 | 柔和、层次丰富 | 橘色+金棕色眼影 |
| 对比色 | 色环上相隔较远 | 鲜明、活泼 | 蓝色眼影配暖肤色 |
| 互补色 | 色环上正对（180°） | 强烈、互相凸显 | 绿色眼影与红调肤色 |

**辨析｜易错点：** 初学者常把「同色系」与「邻近色」混为一谈。同色系是**同一个色相只变明暗**，邻近色是**相邻的不同色相**。画大地色眼影时若只用深浅棕，是同色系；若加入金棕、橘棕，则是邻近色——后者的层次更丰富，也更考验配色的把控力。<span class="marginnote">互补色的「互相凸显」在遮瑕里特别有用：绿色遮红痘印、紫色调黄气，正是「用互补色中和」的经典应用，下一节遮瑕技术会展开。</span>

## 3 冷暖色与肤色搭配

颜色还有冷暖之分：红、橙、黄偏暖，蓝、绿、紫偏冷。**冷暖是配色里最有「气质」的一维**——冷色显清冷理智，暖色显温暖亲和。

选择妆容主色调，要以**肤色冷暖**为基准：肤色偏暖（血管偏绿、戴金饰更搭）适合橘调、金棕、珊瑚色；肤色偏冷（血管偏蓝紫、戴银饰更搭）适合玫瑰、粉调、冷棕。这并非绝对规则，却是「怎么搭都不出错」的起点。<span class="marginnote">判断肤色冷暖可用「腕部血管观察法」：自然光下看手腕内侧血管，偏绿为暖，偏蓝紫为冷。方法简单，却是色彩入门的第一课。</span>

## 4 核心要点对比：色彩三要素与质感

把色彩三要素，与妆容常用的「质感」维度合并，就构成完整的妆容色彩工具箱：

| 维度 | 变量 | 妆容意义 | 控制手段 |
| --- | --- | --- | --- |
| 色相 | 颜色种类 | 决定风格主题 | 选眼影、口红、腮红色号 |
| 明度 | 明暗程度 | 决定立体与轻盈 | 高光（高明度）、修容（低明度） |
| 饱和度 | 鲜艳程度 | 决定浓淡与气场 | 少量多次叠加控制 |
| 质感 | 哑光/珠光/闪片 | 决定光感与场合 | 哑光显专业，珠光显活泼 |

**「色相定风格、明度定立体、饱和度定浓淡、质感定光感」**——一句话概括了妆容配色的全部变量。设计一个妆容，就是在这四个维度上做组合决策：例如通勤妆选择低饱和度、哑光质感、中高明度，而舞台妆选择高饱和度、闪片质感、对比强烈。

把四个维度再合成一张「配色决策顺序」：

- **先定色相**：按场合与气质选主色系（大地、玫瑰、正红……）。
- **再调饱和度**：按浓淡需求降饱和或提饱和——这是「淡妆与浓妆」的第一开关。
- **然后定明度**：按立体需求安排高光与阴影的明度差。
- **最后选质感**：哑光显专业、珠光显活泼，按场合收尾。

**这条顺序，是妆容配色的「标准求解流程」**：先锁定风格（色相），再逐项调参（饱和度、明度、质感）。有了流程，配色就不再是「灵感驱动」，而是一次可重复的设计决策。

### 三要素的实战：把一支口红拆成三个参数

用色彩三要素分析一支口红，就能明白「同样的红为什么气质不同」：

- **色相**：正红、玫红、橘红是不同色相，决定「风格方向」。
- **明度**：酒红（低明度）与粉红（高明度）明度不同，决定「轻重与年龄感」。
- **饱和度**：正红（高饱和）与砖红（低饱和）饱和度不同，决定「浓淡与气场」。

同一色相、不同明度与饱和度的口红，气质完全不同——这解释了为什么「同样是红色系口红」，有人涂着显成熟，有人涂着显年轻。**理解三要素，就能「拆开」任何一支产品的气质密码**，也能反过来组合出自己想要的妆效。<span class="marginnote">把色彩拆成「色相—明度—饱和度」三个可调参数，与本站「把复杂对象分解成可调变量」的建模思路一致：会拆，才谈得上设计。</span>

### 动手练习：色彩三要素的识别

找一个眼影盘，做三分钟识别练习：

- **第一步**：从中挑出两个「同一色相、不同明度」的颜色。
- **第二步**：再挑出两个「同一色相、不同饱和度」的颜色。
- **第三步**：指出哪些颜色构成「邻近色组合」、哪些构成「互补色组合」，并预想画出来的效果。

这个练习能快速建立「色彩的眼睛」——识别色相、明度、饱和度是配色能力的第一步，也是后续所有眼影、腮红、口红选色的基础。

## 5 术语速查表

| 术语 | 含义 |
| --- | --- |
| 色相（Hue） | 颜色的种类，如红、黄、蓝 |
| 明度（Value） | 颜色的明暗程度 |
| 饱和度 | 颜色的鲜艳程度 |
| 色相环 | 按光谱顺序排成环形的配色地图 |
| 同色系 | 同一色相只变明暗的配色 |
| 邻近色 | 色环上相邻的色相 |
| 互补色 | 色环上正对的色相，可互相中和 |
| 冷暖色 | 红橙黄偏暖、蓝绿紫偏冷的气质维度 |
| 对比色 | 色环上相隔较远的色相，鲜明活泼 |
| 中性色 | 黑、白、灰、米等低饱和过渡色 |
| 腕部血管观察法 | 看手腕内侧血管偏绿/偏蓝紫判断肤色冷暖 |
| 色调 | 一个妆容或形象统一的色彩倾向 |
| 提亮 | 用高明度颜色让区域视觉向前 |
| 压暗 | 用低明度颜色让区域视觉后退 |

## 6 小结

- 色彩三要素为**色相、明度、饱和度**；化妆师先掌握饱和度对浓淡的控制。
- 配色关系分**同色系、邻近色、对比色、互补色**四类，由色相环上的位置决定。
- 妆容主色调要与**肤色冷暖**搭配：暖皮配暖调，冷皮配冷调。
- 妆容配色是**色相、明度、饱和度、质感**四维决策：定风格、定立体、定浓淡、定光感。
