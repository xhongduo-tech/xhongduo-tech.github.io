## 为什么从腮红与修容开始

前面处理了底妆、眉眼、睫毛——它们让脸「干净、有神」。但一张干净的脸还缺两样东西：**气色**与**立体感**。腮红负责气色，修容负责立体；两者都建立在同一个底层逻辑上——**用色彩与明暗在脸上塑造「光影」**。化妆师常说「脸是一张画布，修容是素描」，指的就是这一步。<span class="marginnote">光影塑造在化妆里的地位，恰如函数图像里的「凹凸性」分析：不仅要知道「有什么」，还要知道「哪里亮、哪里暗、为什么」。</span>

## 1 腮红：位置与脸型的配合

**腮红（blush）**：涂在面颊的粉色系产品，作用是提升气色、让肤色健康红润，同时通过位置微调脸型。

### 腮红的常见位置

**颧骨腮红（经典位）**：从颧骨最高点向太阳穴方向斜扫，显瘦提气，适合多数脸型。
**圆形腮红（可爱位）**：在苹果肌上打圈，位置偏中、偏下，显年轻可爱，适合长脸。
- **修容式腮红（侧扫位）**：沿颧骨下方斜向上扫，兼具修容效果，适合圆脸与方脸。<span class="marginnote">腮红位置的选择逻辑是「补脸型之不足」：长脸需要横向的面积感（圆形位），圆脸需要纵向的收缩感（斜扫位）。</span>

### 腮红用量与晕染

**易错点｜辨析：** 腮红最大的失败是「高原红」——画得太重、边界太硬。对策是**少量多次 + 充分晕染**：刷子蘸取后抖粉，从苹果肌向外轻扫，最后用干净刷把边缘晕开，让腮红像「皮肤里透出的血色」，而不是「涂上去的两团」。

## 2 修容：明暗塑造立体

**修容（contouring）**：用深色（阴影）与浅色（高光）调整面部明暗，从视觉上改变轮廓——这是「立体感」的核心来源。

### 修容的基本法则

**阴影（暗色）**：涂在「想让它后退/变窄」的位置——颧骨下方、下颌角、鼻梁两侧。暗色让视觉上凹陷、收缩。
**高光（亮色）**：涂在「想让它前进/变高」的位置——额头中央、鼻梁、眼下三角、下巴尖。亮色让视觉上凸起、饱满。
- **过渡**：明暗交界处必须晕染自然，否则会留下「两撇棕线」的修容痕迹。<span class="marginnote">「阴影后退、高光前进」是修容的第一性原理，它来自人眼对光影的直觉判断：亮的地方近、暗的地方远——这正是透视与素描的共同基础。</span>

### 不同脸型的修容方向

| 脸型 | 重点压暗 | 重点提亮 |
| --- | --- | --- |
| 圆脸 | 下颌角、颧骨下方 | 额头中央、下巴尖（纵向拉长） |
| 方脸 | 下颌角最重点 | 下巴中央（柔化方形） |
| 长脸 | 额头上下缘、下巴 | 脸颊横向（视觉缩短） |
| 心形脸 | 额角两侧 | 颧骨下方、下巴（平衡上宽下窄） |

**重点：修容是「按需压暗与提亮」，不是「全脸打阴影」。** 新手最容易犯的错是把整圈轮廓都扫上深色——结果脸变脏、妆感重。正确做法是先分析这张脸「哪一处需要变窄、哪一处需要变高」，再精准落笔。

## 3 腮红与修容的配合

腮红与修容是同一套明暗体系的两个成员，顺序与位置要协调：

**顺序**：先修容后腮红——先把「骨骼感」画出来，再用腮红为面颊上色，腮红会落在修容与高光之间，形成自然的「红润地带」。
**位置配合**：腮红一般落在「修容（颧骨下阴影）与高光（颧骨上）之间的过渡带」，三者从上到下是「高光 → 腮红 → 阴影」，像一条自然的色带。<span class="marginnote">「高光—腮红—阴影」三色带的位置关系，是立体妆容的固定结构：亮部、色彩部、暗部在颧骨区各司其职。</span>

## 4 公式解析：修容的明暗「三分区」

把修容位置抽象成一张「明暗分区图」，颧骨区从高到低分三段：

$$
\text{颧骨区} = \underbrace{\text{高光}}_{\text{颧骨最高点}} \oplus \underbrace{\text{腮红}}_{\text{过渡带}} \oplus \underbrace{\text{阴影}}_{\text{颧骨下方}}
$$

- **第一步，定位高光点**：颧骨最高点是全脸最该「亮」的位置之一，打高光让它向前凸出。
- **第二步，定位阴影带**：颧骨下方凹陷处是「暗」的位置，打阴影让它向后收缩。
- **第三步，中间上腮红**：在亮与暗之间上腮红，三色平滑过渡，形成自然的立体色带。

**修容的本质，是在脸上画一张「亮度梯度图」**：亮的地方近、暗的地方远，中间用腮红过渡色彩。理解了这张梯度图，无论脸型如何变，都能把「该亮、该暗、该上色」的位置找出来——这是从「背位置」到「懂原理」的关键一跃。

## 5 术语速查表

| 术语 | 含义 |
| --- | --- |
| 腮红 | 涂于面颊、提升气色的粉色系产品 |
| 修容 | 用深色阴影与浅色高光塑造立体感 |
| 高光 | 涂在凸出处的浅色，让区域向前 |
| 阴影 | 涂在凹陷处的深色，让区域后退 |
| 颧骨腮红 | 从颧骨最高点向太阳穴斜扫的经典位置 |
| 苹果肌 | 微笑时面颊隆起的部位 |
| 亮度梯度 | 明暗过渡的层次关系 |
| 少量多次 | 分次薄涂、逐层叠加的防重手法 |

## 6 小结

- **腮红**提升气色，位置配合脸型：经典位、圆形位、修容位。
- **修容**用阴影（后退）与高光（前进）塑造立体，交界必须晕染自然。
- 腮红与修容配合：**先修容后腮红**，颧骨区形成「高光—腮红—阴影」色带。
- 修容的本质是**画亮度梯度**：先分析「哪里需窄、哪里需高」，再精准落笔，反对全脸扫阴影。
