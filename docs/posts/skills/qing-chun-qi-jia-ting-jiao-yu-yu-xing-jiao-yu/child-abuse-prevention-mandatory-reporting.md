## 为什么从制度开始

上一篇讲的是「孩子遭受侵害后，家庭如何应对」。但家庭的应对，依赖一个前提——**有人先发现**。谁会发现？如果侵害发生在家庭内部、发生在熟人之间，孩子不敢说，父母不知道，谁来打破这个沉默？

答案是一套近年在中国快速成型的制度防线：**强制报告制度**。它的核心逻辑是：把「发现侵害」从「道德责任」升级为「法定义务」——学校老师、医生、社区工作者等**密切接触未成年人的人员，在工作中发现孩子可能受侵害时，必须立即报告**，否则要承担法律责任。这一篇就把这套制度讲清楚：它保护什么、谁在执行、家庭如何与之衔接。

## 1 强制报告制度：一项「看见即报告」的义务

强制报告制度的法律依据有两层：

**《未成年人保护法》第 11 条**：任何组织或者个人发现不利于未成年人身心健康或侵犯其合法权益的情形，都有权劝阻、制止或向有关部门检举、控告；**国家机关、居委会、村委会、密切接触未成年人的单位及其工作人员，在工作中发现未成年人身心健康受到侵害、疑似受到侵害或面临其他危险情形的，应当立即向公安、民政、教育等部门报告。**

**《关于建立侵害未成年人案件强制报告制度的意见（试行）》（2020 年，最高检等九部门联合印发）**：把「应当报告」细化为可操作清单，明确报告主体、报告情形与不报告的责任。

这套制度要解决的核心困境是：**侵害未成年人案件最大的特点是「隐蔽」**——孩子不敢说、家里藏着掖着、外人以为「管闲事」。强制报告的意义，是让最可能看见伤害的人（老师、医生、社工），有义务开口。

<span class="marginnote">很多家长对强制报告有误解，以为它是「抢走孩子」的制度。恰恰相反——<strong>强制报告针对的是「施害者」，保护的是「孩子」，而非惩罚「家庭」</strong>。多数报告最终的结果是家庭得到支持与干预，而非孩子被带走；只有当家庭本身构成危险且无力改善时，才涉及监护权变更。制度的靶心从来不是普通家庭。</span>

## 2 谁必须报告：主体与情形

强制报告的主体，是**密切接触未成年人的单位及其工作人员**，主要包括：

**学校、幼儿园、托育机构**的教职员工。
- **医疗机构**的医生、护士。
- **儿童福利机构、未成年人救助保护机构**的工作人员。
- **旅馆、宾馆、网吧**等经营场所的从业人员（发现未成年人单独开房、疑似被控制时应报告）。
- **村（居）民委员会**工作人员，以及**基层公安、民政、妇联、共青团**等系统中的一线人员。

需要报告的典型情形（九部门意见列举，含以下类别）：**性侵害**、**虐待（含身体、精神、性、疏忽）**、**家庭暴力**、**遗弃或长期无人照料**、**被组织乞讨或强迫劳动**、**被拐卖或绑架**、**离家出走失联**、以及**儿童自杀、自残、被群体性事件伤害**等。

把「谁报告、报告什么」对应起来，理解会更直观：

| 报告主体 | 最容易接触到的侵害情形 |
| --- | --- |
| 教师、班主任 | 身体伤痕、情绪突变、性语言/性知识异常、被同学孤立排挤 |
| 校医、医生、护士 | 隐私部位异常、反复受伤、发育迟滞、疑似性侵的体征 |
| 村（居）委会、社工 | 儿童长期无人照料、辍学流浪、家庭暴力迹象 |
| 旅馆、网吧从业者 | 未成年人独自开房、深夜滞留、疑似被成年人控制 |
| 基层民警、妇联干部 | 报警求助、被家暴、被遗弃的未成年人线索 |



<span class="marginnote">九部门意见有一个容易被忽视的细节：<strong>「疑似」也要报告</strong>。制度要求的是「发现疑似侵害」，不是「查实侵害」——把查实的责任交给公安与司法机关，报告者只需报告「可疑的迹象」。这条规定是为了降低报告门槛，避免「我不敢确定所以没说」的集体沉默。</span>

## 3 公式解析：保护生效的三个乘数

强制报告制度的成效，可以用一条乘法公式理解：

$$
\text{保护生效} = \text{及时发现} \times \text{立即报告} \times \text{专业处置}
$$
