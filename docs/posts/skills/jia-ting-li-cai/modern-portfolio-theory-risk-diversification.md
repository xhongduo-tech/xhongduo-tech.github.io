## 为什么从现代投资组合理论开始

第 3 篇结束时我们留下了一个问题：各类资产各配多少？答案的数学根基，是**现代投资组合理论（Modern Portfolio Theory，MPT）**——马科维茨（Markowitz）在 1952 年创立的理论，它用一个看似简单的思想改变了金融世界：**组合的风险，不是各资产风险的简单加权，而是由资产间的相关性决定**。这意味着「分散投资」不只是朴素的避险智慧，而是一条有严格数学依据的规律：**只要资产不完全正相关，组合就能在收益基本不变的前提下降低风险——这几乎是投资里唯一的「免费午餐」**。本节讲清风险分散的机制，为下一节的均值-方差与有效前沿做铺垫。

## 1 组合的两维：期望收益与风险

任何投资组合都可以用两个数字概括：**期望收益**（能赚多少）与**风险**（波动多大）。组合的期望收益很简单——它是各资产期望收益的加权平均：

$$\mathbb{E}[R_p] = \sum_i w_i \mathbb{E}[R_i] = w_1 \mathbb{E}[R_1] + w_2 \mathbb{E}[R_2]$$

其中 $w_i$ 是资产 $i$ 在组合中的权重（$\sum_i w_i = 1$）。对这条式子做三步拆解：

- **第一步，权重 $w_i$**：组合里每个资产占的比例，所有权重之和必须等于 1。
- **第二步，期望收益 $\mathbb{E}[R_i]$**：各资产长期的平均回报。
- **第三步，加权平均**：组合收益 = 各资产收益按权重平均。**注意：收益是「线性加权」的——组合收益总是各资产收益的加权平均，不存在「1+1>2」。**

如果收益只是简单加权，那组合的意义何在？关键在于**风险不是简单加权**——这正是下一节的主题。

## 2 组合的风险：相关性的魔法

组合的方差（风险的平方）由三部分组成：各资产的方差，加上**资产之间的协方差**。两只资产的组合方差为：

$$\sigma_p^2 = w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2 w_1 w_2 \rho_{12} \sigma_1 \sigma_2$$

其中 $\sigma_1, \sigma_2$ 是两只资产的标准差，$\rho_{12}$ 是它们的**相关系数**。对这条式子做四步拆解：

- **第一步，看前两项 $w_i^2 \sigma_i^2$**：每只资产自身风险的贡献。注意权重是**平方**——这意味着一只资产占比太高时，它的风险贡献会被平方放大。
- **第二步，看第三项 $2 w_1 w_2 \rho_{12} \sigma_1 \sigma_2$**：两只资产「共同波动」的贡献，由**相关系数 $\rho_{12}$** 决定。这是组合理论最关键的一项。
- **第三步，读相关系数**：$\rho_{12}$ 在 -1 到 +1 之间。+1 表示完全同步波动（同涨同跌），-1 表示完全反向（一涨一跌），0 表示互不相关。
- **第四步，得出核心结论**：当 $\rho_{12} < 1$（即两只资产**不完全正相关**）时，组合风险**小于**各资产风险的加权平均——这就是**分散化效应（diversification effect）**。$\rho$ 越低，分散效果越强；$\rho = -1$ 时理论上可以把组合风险降到接近零。

<span class="marginnote">为什么「分散投资」是免费午餐：<strong>组合收益是权重的线性平均（损失很小），而组合风险在资产相关性 < 1 时是「亚加性」的（降低明显）</strong>。用数学语言说：收益函数是线性的、风险函数是二次的，相关性越低越赚——这正是马科维茨拿诺贝尔奖的原因。</span>

## 3 分散化的边界：系统风险与个别风险

分散化是不是越多越好？不是。当资产数量增加，分散化的收益**递减**，最终收敛到一个下限——这个下限就是**系统风险**。

把风险分成两类：**非系统性风险（个别风险）**——单个公司、单个行业的特有风险（如公司暴雷、行业政策），**可以被分散化消除**；**系统性风险（市场风险）**——整个市场共同面临的风险（如经济衰退、利率上升），**无法通过分散化消除**。

持有 1 只股票，你同时承担系统风险 + 全部非系统风险。
持有 10 只不同行业的股票，个别风险大幅摊薄，剩下主要是系统风险。
持有整个市场指数（如沪深 300、标普 500），个别风险几乎消除，你承担的只是市场本身的系统风险。

<span class="marginnote">分散化递减的直觉：<strong>第一只股票消除的风险最多，第二只少一些，第十只几乎不再有贡献——30 只以上的股票组合，非系统风险基本被摊平</strong>。因此「多买几个产品」不如「买覆盖面广的指数」：指数的价值不在数量，而在「把系统风险之外的部分全部摊掉」。</span>

这给出家庭配置的实操结论：**别为「分散」而买一堆相似产品**——买 10 只同涨同跌的股票基金，相关性几乎为 1，分散效果接近于零。真正有效的分散，是**跨大类**（股票 + 债券 + 黄金）、**跨市场**（A股 + 海外）、**跨风格**（成长 + 价值）的分散。

## 4 核心要点：风险分散速查表

| 概念 | 定义 | 关键结论 |
| --- | --- | --- |
| 组合收益 | 各资产收益的加权平均 | 线性，无「1+1>2」 |
| 组合方差 | 含协方差项的三部分 | $\rho<1$ 时风险亚加性 |
| 相关系数 $\rho$ | 资产间联动程度 | $\rho$ 越低分散效果越强 |
| 非系统风险 | 个别资产特有 | 可被分散消除 |
| 系统风险 | 市场整体风险 | 无法分散，只能承担 |
| 有效分散 | 跨大类、跨市场、跨风格 | 买相似产品≈没分散 |

## 5 小结

- 组合用**期望收益**与**风险**两维刻画，收益是线性加权，风险不是。
- 组合方差含**协方差项**，资产相关性 $\rho<1$ 时组合风险低于加权平均——**分散化是免费的午餐**。
- 风险分**系统风险**（不可分散）与**非系统风险**（可分散），分散的边际收益递减。
- 持有**宽基指数**即可基本摊平非系统风险，承担的是市场系统风险。
- 有效分散要**跨大类、跨市场、跨风格**，而非堆叠相似产品。
