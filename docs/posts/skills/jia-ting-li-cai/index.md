# 家庭理财规划与资产配置

家庭理财规划与资产配置是面向家庭的实用理财学科，系统覆盖从记账预算、储蓄管理到投资工具认知与资产配置落地的完整流程。学完这些章节，就掌握了从家庭财务诊断、预算储蓄落地到投资组合构建与配置调整的全过程。

## 对标教材

- AFP《金融理财原理》
- 中国银行业协会《个人理财》
- 《资产配置理论与实践》
