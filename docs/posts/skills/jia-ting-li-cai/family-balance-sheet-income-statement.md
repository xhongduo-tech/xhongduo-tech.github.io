## 为什么从两张报表开始

记账是逐笔流水，预算是对流水的约束，而真正能「一眼看懂家庭财务全貌」的，是**财务报表**。企业的三大报表——资产负债表、利润表、现金流量表——搬到家庭场景，就是两张：**家庭资产负债表**回答「现在有多少家底、欠多少债」，**家庭收支表**回答「一段时间内赚了多少、花了多少、结余多少」。前者是**存量视角**（某个时点的照片），后者是**流量视角**（一段时间内的电影）。两张报表配在一起，家庭财务才第一次有了可被分析的「全貌」。

## 1 家庭资产负债表：某一时点的快照

**家庭资产负债表（balance sheet）**：反映家庭在**某一特定日期**（通常为每月最后一天或年末）的资产、负债与净资产状况的报表。它的恒等式与企业的完全一致：

$$\text{资产（Assets）} = \text{负债（Liabilities）} + \text{净资产（Net Worth）}$$

这个恒等式告诉我们一个关键事实：**净资产不是「算出来的另一个东西」，而是资产减去负债之后的剩余权益**。它衡量的是「如果今天把所有资产变现、把所有债务还清，家里还剩下多少」。

### 资产端的分类

家庭资产按**变现能力**分为三类，这是编制资产负债表最重要的口径：

**流动性资产（liquid assets）**：现金、活期存款、货币基金等随时可变现、且不会因变现而大幅贬值的资产。它是家庭应急能力的基础。
**投资性资产（investment assets）**：股票、债券、基金、银行理财、贵金属、投资性房产等，持有目的是保值增值。它们变现需要一定时间，且价值随市场波动。
**自用性资产（personal-use assets）**：自住房、自用车、家电家具等，用于满足家庭生活需要。它们通常不产生现金流，变现有折价，但也是家庭净资产的重要组成部分。

<span class="marginnote">辨析｜易错点：自住房既是资产也是「居住消耗品」。<strong>把自住房算进净资产没错，但它不能算作「可投资资产」</strong>——你不会为了投资把它卖了去租房。因此衡量「钱生钱」能力时，只看投资性资产，别把自住房混进去。</span>

### 负债端的分类

负债按**期限**分两类：**流动负债（current liabilities）**指一年内要还的债务，如信用卡未还账单、消费贷；**长期负债（long-term liabilities）**指一年以上的债务，如房贷、长期经营贷。把负债按期限分列，是为了配合后面的偿债能力分析：流动负债的规模直接决定家庭的短期流动性压力。

## 2 家庭收支表：一段时间的流量

**家庭收支表（income statement / cash flow statement）**：反映家庭在**某一时间段**（通常为一个月或一年）内收入、支出与结余状况的报表。它的恒等式同样简单：

$$\text{收入} - \text{支出} = \text{结余（Surplus）}$$

这里要注意收支表的**记账口径**：家庭收支表与企业利润表不同，家庭几乎都采用**收付实现制**——以现金实际收付为准。比如房贷月供里的本金部分，是企业会计里的「投资」（不进利润表），但在家庭收支表里它是当月的现金支出、计入结余的减项。<span class="marginnote">口径辨析：家庭收支表不区分「本金偿还」与「利息支出」，统统计入支出。<strong>这样做虽然不够「会计准确」，但贴近家庭的真实现金流体验</strong>——因为可花的现金确实减少了；至于房贷本金同时增加了净资产，那是在资产负债表中体现的。</span>

收支表的编制直接复用前两节的分类成果：收入分主动/被动、按来源列示；支出按固定/可变必要/自由三分类、再细到记账科目。把月收入、月支出、月结余三行拉出来，就得到了家庭现金流管理的最小分析单元。

## 3 从两张报表到「财务全景」

单独一张报表的信息有限，两张报表**配合**起来，家庭的财务健康状况才立体：

- **净资产看家底**：资产负债表告诉你「存量」——家底厚不厚、杠杆高不高。
- **结余看造血**：收支表告诉你「流量」——每个月能新增多少净资产。结余为正，净资产每月增加；结余为负，就是在吃老本。
- **两者联动看趋势**：把每个月末的资产负债表连起来，净资产曲线的斜率应该约等于当月结余。**若净资产增长明显慢于累计结余，说明钱可能漏在了贬值资产（如过度消费）或坏账上**——这是财报联动分析最有价值的一个观察。

## 4 公式解析：净资产增长等式

两张报表之间的桥梁，可以写成一条可操作的增长等式：

$$\Delta \text{净资产} = \text{结余} + \text{投资损益} + \text{资产市价变动}$$

对这条式子做三步拆解：

- **第一步，看 $\Delta \text{净资产}$**：期末净资产减去期初净资产，即这个月「家底」增加了多少。
- **第二步，看收入项**：结余（储蓄）来自收支表，是主动攒出来的；投资损益来自卖出资产实现的盈亏；市价变动是持有资产没卖、但账面价值涨跌的部分（如房价、股价波动）。
- **第三步，理解差距**：净资产增长 = 攒下的钱 + 资产增值。**如果你的净资产增长长期大幅低于「结余」这个数，就要警惕两类泄漏：一是结余算错了（支出没记全），二是钱变成了贬值消费品**（买了很快跌价的东西，账面上资产没增加）。

<span class="marginnote">这条等式的实践含义：想要净资产快速增长，只靠「多结余」是一条腿走路。<strong>在结余稳定的前提下，提升投资性资产的占比，让「投资损益」成为第二增长引擎</strong>——这是本专题后面第4篇「资产配置」全部内容的伏笔。</span>

## 5 核心要点：两张报表的编制清单

把编制要点收敛成**核心要点表**，直接照着做即可：

| 项目 | 家庭资产负债表 | 家庭收支表 |
| --- | --- | --- |
| 视角 | 存量（时点快照） | 流量（期间累计） |
| 恒等式 | 资产 = 负债 + 净资产 | 收入 − 支出 = 结余 |
| 编制频率 | 每月末 / 每年末 | 每月 / 每年 |
| 资产端口径 | 流动性 / 投资性 / 自用性 | 主动 / 被动收入 |
| 负债端口径 | 流动 / 长期 | 固定 / 可变必要 / 自由支出 |
| 最关心指标 | 净资产、资产负债率 | 月结余、储蓄率 |

<span class="marginnote">执行建议：编制频率上，<strong>收支表必须按月编（数据来自记账），资产负债表按季或按年编即可</strong>——因为房产、股票等价值不会一个月大变，按季更省力也不失准确。</span>

## 6 小结

- 资产负债表是**存量快照**：资产 = 负债 + 净资产，资产按流动性、负债按期限分类。
- 收支表是**流量累计**：收入 − 支出 = 结余，家庭采用收付实现制。
- 净资产看家底，结余看造血，**两张报表联动看趋势**。
- 净资产增长 = 结余 + 投资损益 + 市价变动，警惕「结余高、净资产却不涨」的泄漏。
- 编制节奏：收支表按月、资产负债表按季或按年。

在下一节，我们将拿着这两张报表做「体检」：把净资产、负债、月结余换算成一组**财务比率**，用数字判断家庭财务是否健康、偿债是否有压力。
