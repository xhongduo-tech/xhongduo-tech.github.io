## 为什么从理财规划书开始

前面几节把理财规划的「分析」部分做完了：诊断、目标、风险测评都有了结论。但结论如果只停在脑子里或口头上，等于没有结论。**理财规划书（financial plan）** 就是把分析结论固化成的正式文件，而**方案执行**则是把文件转成动作。两者合起来，才完成六步流程里的「开方」与「吃药」。规划书的意义不只在「写给别人看」——它对家庭自己同样关键：**书面方案是对未来的承诺书，是防止冲动决策的护栏**。本节给出规划书的标准结构、核心内容，以及让方案真正落地的执行机制。

## 1 理财规划书的标准结构

一份专业的理财规划书，通常包含七个部分，顺序与六步流程一一对应：

**一、声明与免责**：说明规划基于现有信息与假设，市场变化需定期更新——为方案的时效性划界。
**二、家庭基本情况与财务现状**：人员结构、收入支出、资产负债两张报表——对应「收集信息」。
**三、理财目标与约束条件**：SMART 目标清单、目标优先级、风险承受等级、期限约束——对应「设定目标」与「评估」。
**四、财务诊断与问题分析**：四比率、问题画像、风险点——对应「分析评估」。
**五、财务方案**：这是核心，通常包含五个子方案——储蓄方案、保障方案、投资方案、税务方案、养老规划。
**六、执行计划**：把方案拆成「谁、何时、做什么」的行动清单。
**七、监控与调整机制**：复盘频率、触发调整的条件、再平衡规则。

<span class="marginnote">对家庭自己编制规划书，建议简化但别省略：<strong>至少要写清「目标、现状、方案、行动清单、复盘时间」五块</strong>。规划书的第一读者是自己，写下来的过程本身就是一次「把模糊想法逼成清晰决策」的思维训练。</span>

## 2 核心内容：五大子方案

规划书的灵魂是「财务方案」部分，它由五个子方案构成，彼此独立又互相衔接：

**储蓄方案**：月结余如何分配（应急基金、目标账户、自由储蓄），沿用第 1 篇的资金漏斗。
**保障方案**：需要哪些保险、保额多少、保费预算占收入比例（经验值 5%–10%）。保障先于投资，是规划的防线。
**投资方案**：基于风险承受等级，给出资产配置建议——各类资产占比区间、投资工具选择、定投计划。这一部分将在第 3、4 篇展开成完整的方法论。
**税务方案**：合法利用税收政策（专项附加扣除、养老金税优账户等）降低税负。合规是底线，偷漏税是红线。
**养老规划**：目标替代率反推所需本金，再反推每月储蓄额与投资节奏。

五个子方案不是并列的五个独立任务，而是一个**整体**：储蓄方案为所有目标提供资金来源，保障方案守住下限，投资方案负责增长，税务方案提高效率，养老方案统筹长期目标。<span class="marginnote">方案间的资源分配有优先级：<strong>当资金不足以同时满足五个子方案时，按「保障 → 储蓄 → 养老 → 投资 → 税务」的顺序分配</strong>——先保护、再积累、后进攻，这个顺序与第 1 篇的资金漏斗完全一致。</span>

## 3 假设与敏感性分析：方案可信度的检验

规划书里的所有数字都依赖**假设**：收入增长率、投资收益率、通货膨胀率、目标替代率。因此一份严谨的规划书必须做**敏感性分析**——测试「假设变了，方案还成不成立」。

方法很简单：对最关键的假设取「乐观 / 基准 / 悲观」三档，分别重算核心结果。比如投资收益率的敏感性：

| 情景 | 年化收益率假设 | 退休时养老金缺口 |
| --- | --- | --- |
| 悲观 | 4% | 缺口 60 万 |
| 基准 | 6% | 刚好覆盖 |
| 乐观 | 8% | 盈余 40 万 |

敏感性分析的产出不是「更准确的预测」（没人能预测），而是一个判断：**方案在悲观假设下还能不能接受？** 如果不能，就要调整方案本身——提高储蓄额、延长期限、或降低目标——而不是假装悲观不会发生。<span class="marginnote">这是规划书与「拍脑袋」的本质区别：<strong>规划书不追求「猜对」，而是追求「在多种未来下都活得下去」</strong>。把「如果收益只有 4% 会怎样」提前想清楚，比执着于「收益到底会是多少」有价值得多。</span>

## 4 方案执行：从文件到动作

规划书写完，真正的挑战才开始。执行力的三个关键机制：

**机制一，行动清单化**：把方案拆成具体动作，每个动作带上「责任人、截止时间、所需金额」。例如「本月 15 日前：开通指数基金定投，每月 3000 元，扣款日设为发薪次日」。**没有时间与责任人的动作，不叫执行计划，叫愿望清单。**

**机制二，自动化**：能自动的绝不手动——工资到账自动转储蓄、定投自动扣款、保费自动代扣。自动化的原理与第 1 篇相同：**把执行从「每月一次的意志力决策」降级为「一次设置、长期运行」的系统行为**。

**机制三，定期复盘**：规划书不是一次性的，而是滚动文件。建议**至少每年一次全面复盘**，并在以下「触发事件」出现时**随时修订**：收入大幅变化（升职、失业）、家庭结构变化（结婚、生子、离婚）、大额支出发生（购房、大病）、风险承受变化、市场发生重大变化。

## 5 执行阻力与克服：为什么好方案总被拖延

方案写得再专业，执行不下去也是零。家庭理财方案最常见的执行阻力有三类，提前识别并设好对策，比事后补救有效得多：

**阻力一，启动拖延**：「等忙完这阵再开户/再定投」——拖延的根源是「任务模糊 + 没有期限」。对策是**设「启动日」而不是「启动期」**：把「本月开通定投」写死成「本月 15 日 14:00 完成开户并设自动扣款」，具体到日期与动作。

**阻力二，情绪冲击**：刚建仓就遇市场大跌，恐慌想撤。对策是**事前写好「应对预案」**：在规划书里明确「组合下跌 20% 时的操作是『再平衡而非清仓』」，并把这条写进 IPS——情绪上来时，照预案执行而不是临时决定。

**阻力三，家庭不一致**：夫妻双方理财观不同，一人激进一人保守，方案难以坚持。对策是**把方案变成家庭共识**：召开一次家庭财务会，共同确认目标与风险等级，方案写成「全家约定」而非「一人决定」。

<span class="marginnote">执行的心理机制：<strong>方案执行的对手不是「能力」而是「启动摩擦」</strong>——第一笔定投、第一份保单往往最难，一旦系统跑起来，后续靠自动化的惯性即可维持。所以执行阶段的核心是「降低启动成本」：能自动就自动、能当天就当天、能简化就简化。</span>

这三类阻力的共同解法是同一个思路：**把「决定」与「执行」分离**——决定在冷静时做（写进规划书），执行在情绪中照做（靠自动化与预案）。规划书的价值，正在于它是那个「冷静时做下的决定」。

规划书还要有一个**时间轴**：把六步流程落到日历上，方案才不会被遗忘。一份家庭级规划书建议配上这样的执行节奏：

| 频率 | 动作 | 对应环节 |
| --- | --- | --- |
| 每季度 | 检查储蓄进度、投资组合偏离 | 监控 |
| 每半年 | 复核目标进度与假设变化 | 监控 / 修正 |
| 每年 | 全面复盘：重测风险等级、修订方案 | 复查 |
| 触发事件时 | 结婚、生子、购房、失业、大病 → 立即修订 | 修正 |

把「何时做什么」写进规划书，是防止「方案被搁置」的关键——**没有时间轴的规划书只是文档，配了时间轴的规划书才是行动指南**。规划书的最终形态，是「决策」与「日历」合二为一：决策在冷静时定下，日历保证它们在忙碌中被执行。

再给一条「**规划书该有的温度**」：规划书不只是数字与表格，还应写进家庭真正在意的东西——为什么要存这笔教育金、退休后想过的生活、哪些钱「绝不冒险」、哪些风险「愿意承担」。**把「人生」写进「规划书」，方案才会被全家认同并坚持**；一份只有数字、没有价值观的方案，遇到波动时最容易被动摇。

规划书与执行，是理财规划流程的「出口」——**前五步的一切分析，都要靠这一步变成动作**。一份落地的规划书 + 一套自动化的执行机制，才是把「想法」转成「生活」的桥梁。

## 6 核心要点：规划书编制与执行检查清单

| 环节 | 检查项 |
| --- | --- |
| 结构完整 | 现状 / 目标 / 诊断 / 方案 / 执行 / 复盘 六要素是否齐全 |
| 假设明确 | 收入增长率、收益率、通胀率是否写明 |
| 敏感性分析 | 悲观假设下方案是否仍可接受 |
| 方案完整 | 储蓄、保障、投资、税务、养老五子方案是否齐备 |
| 行动清单 | 每个动作是否有责任人、时间、金额 |
| 自动化 | 储蓄、定投、保费是否已设自动执行 |
| 复盘机制 | 是否定了年度复盘日与触发修订的条件 |

## 7 小结

- 理财规划书把分析结论**固化**，标准结构七部分，家庭自用可精简为五块。
- 核心是**五大子方案**：储蓄、保障、投资、税务、养老，按「保障→储蓄→养老→投资→税务」分配资源。
- 所有数字依赖假设，必须做**敏感性分析**，确保悲观情景下方案仍可接受。
- 执行靠三机制：**行动清单化、自动化、定期复盘**。
- 规划书是滚动文件，**收入/家庭/大额支出变化时随时修订**。
