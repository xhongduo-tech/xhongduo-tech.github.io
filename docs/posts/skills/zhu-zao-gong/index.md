# 铸造工（砂型与特种铸造操作）

铸造工是机械制造基础工种，涵盖砂型造型、制芯、金属熔炼、浇注与铸件清理等铸造操作技能，是装备制造业成形工件的核心工艺通道。以《国家职业技能标准——铸造工》为框架，结合《铸造工艺学》与《铸造工技师手册》，从职业认知、砂型造型、熔炼浇注、特种铸造到铸件清理与质量检验，系统写完整门铸造操作技能。

## 对标教材

- 《国家职业技能标准——铸造工》（人力资源社会保障部颁布）
- 《铸造工艺学》（机械工业出版社，普通高等教育铸造专业教材）
- 《铸造工技师手册》（机械工业出版社）
