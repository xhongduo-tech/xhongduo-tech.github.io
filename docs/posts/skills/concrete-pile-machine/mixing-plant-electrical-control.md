## 为什么电气控制决定搅拌站的「自动」

搅拌站每小时要重复几十次同样的动作：称料、投料、搅拌、卸料。靠人工操作不仅慢，而且**人不可能每次都以同一精度判断「够没够」**。<span class="marginnote">搅拌站电气控制的核心价值是把「人工判断」换成「程序判断」：<strong>称重传感器读数到位 → PLC 发出停止给料指令 → 同一流程每小时重复几十次，次次一致</strong>。精度从「老师傅手感」变成「可复现的程序行为」。</span>这一节讲清搅拌站电气控制系统由什么组成、自动循环怎么跑通、以及维修工最常做的「配料精度调整」到底在调什么。

## 1 电气控制系统的组成

搅拌站电气控制系统，可分成五个层次：

**主控层**：**PLC（可编程控制器）**，系统的「大脑」。按程序扫描输入信号、执行逻辑、输出控制指令，实现配料、搅拌、出料的全自动循环。<span class="marginnote">PLC 的工作方式是「扫描循环」：<strong>读输入 → 执行程序 → 写输出 → 如此循环，一次扫描仅需几毫秒</strong>。它天然适合「按顺序重复做同一件事」的搅拌工艺。</span>
**人机界面层**：**计算机 + 搅拌站管理软件 + 触摸屏**。操作员在此设定配合比（每立方米的砂石水泥水用量）、查看生产数据、打印发货单。<span class="marginnote">配合比以「每立方米各组分用量（kg）」录入，系统自动换算成「每罐各组分设定重量」：<strong>设定重量 = 单方用量 × 罐容</strong>——这就是「配方管理」的实质。</span>
**检测层**：称重传感器及其变送器、料位计（仓内余料）、限位开关、电机热保护、故障报警触点。
**执行层**：接触器（启停电机）、电磁阀（驱动气缸开斗门）、**变频器**（调节皮带给料机与螺旋输送机转速，实现快慢给料）。
**电源层**：进线配电、隔离变压器、开关电源（给 PLC 与仪表供电）、UPS 或不间断电源（防断电丢数据）。

## 2 自动循环：一次配料怎么跑通

以骨料为例，一次自动配料循环的程序逻辑是「顺序 + 判断」：

**第一步**，PLC 读到「配料启动」信号，输出接触器吸合，启动皮带与给料机**快速给料**。
**第二步**，称重仪表实时把重量送入 PLC。当重量接近设定值（如达 90%），PLC 切换为**慢速给料**。
**第三步**，当重量达到「设定值 − 落差」，PLC 输出停止给料，等待空中的料落入斗内。
**第四步**，PLC 判断实际重量在允差内，启动输送带把料送向主机，同时开放主机待料斗门。
**第五步**，各组分到齐后，PLC 启动搅拌主机计时搅拌，到时间开卸料门出料，一个循环结束，进入下一罐。

**重点：** 这个循环里每个「判断点」都可能出故障——传感器信号异常、变频器不调速、接触器不吸合。**读懂循环是读懂故障的前提**：知道「卡在哪一步」，就锁定了排查范围。这也是电气维修与机械维修最大的不同——机械看「哪里坏了」，电气问「程序走到哪了」。

## 3 配料精度调整：零点是地基

「配料精度调整」在维修工手里，主要做三件事：**校零点、校量程、调落差**。其中**零点校准**是地基。

**零点校准（去皮）**：空斗状态下，把称重仪表读数清零。若空斗就显示不为零，后面所有称量都带着这个偏置。<span class="marginnote">零点漂移的常见原因是<strong>传感器上有积料、斗体与周围结构摩擦或卡滞（如落料斗与称量斗之间有料搭接）</strong>——秤「蹭」到了别的东西，读数就不准了。</span>

**量程校准（标定）**：用标准砝码（或已知重量）挂在称量斗上，把仪表读数校到与实际重量一致。校正系数

$$k = \frac{W_{\text{std}}}{W_{\text{read}}}$$

- $W_{\text{std}}$ 为标准砝码重量；$W_{\text{read}}$ 为仪表当前读数；把仪表增益调到使读数等于标准值，量程即校准。<span class="marginnote">量程校准的实质是<strong>校准「传感器输出电压 → 重量」的换算系数</strong>。传感器用久后弹性体蠕变、应变片老化，换算系数会漂移，所以要定期用砝码复标。</span>

**调落差**：按上一节讲的动态落差修正，把「设定值 − 落差估计」调准。落差不准的表现是「**每批都向同一方向超差**」——超多就增大落差值，超少就减小落差值。

**辨析｜易错点：** 配料波动大时，维修工最容易犯的错是**只校仪表不查机械**。传感器正常时，波动多来自给料机构（门卡滞、皮带打滑）或料仓（起拱、含水分变化）。先看给料是否平稳、再看落差、最后校仪表——「**机械 → 落差 → 仪表**」是精度调整的铁顺序。

## 4 核心要点：常见电气故障速查

| 故障现象 | 可能原因 | 检查顺序 |
| --- | --- | --- |
| 某秤无读数/读数跳变 | 传感器线断、信号受干扰、传感器损坏 | 测传感器电阻 → 查屏蔽接地 → 换传感器 |
| 配料不停止（超称） | 给料机构失控、变频器不停、PLC 输出卡住 | 先急停 → 查执行层 → 查程序输出点 |
| 电机不启动 | 保险断、接触器线圈坏、热保护动作、PLC 无输出 | 查保险 → 测接触器 → 查 PLC 输出 |
| 称量斗放料后不复零 | 斗门卡滞、积料、传感器支撑蹭碰 | 清斗 → 查斗门 → 校零点 |
| 触摸屏无显示 | 开关电源坏、屏排线松、屏损坏 | 查电源 → 查屏背光 → 查排线 |

**重点：** 电气故障排查的统一入口是「**先安全断电、再查电源、后查信号**」。搅拌站的动力回路是三相 380 V，与上一节讲的 24 V 低压系统不同——**检修主回路必须断电上锁挂牌**，防止他人误送电。

## 5 PLC 程序的备份与恢复

PLC 是搅拌站电控的大脑，**程序一旦丢失或损坏，整站瘫痪**。因此程序管理是电控维护的必修课：

**备份时机**：新站验收、程序调试完成、每次程序修改后，都应立即备份。备份介质**至少两份**（U 盘 + 电脑各存一份），标注版本与日期。<span class="marginnote">程序备份是「看不见的保险」：<strong>PLC 电池没电、模块损坏、误操作覆盖，都可能让程序「人间蒸发」</strong>。没有备份，恢复靠厂家上门，停机以天计；有备份，半小时就能恢复。</span>
**恢复流程**：连接编程软件 → 选择正确机型与程序版本 → 上传/下载程序 → 核对配方数据 → 试运转验证联锁与动作。**恢复后必须空载试车确认，不能恢复完就仓促投产。**

**配方与数据管理**：配合比数据存在计算机管理软件或 PLC 数据区，**定期导出备份**；修改配方要双人核对（一人改、一人复核），防止误改导致配比错误。<span class="marginnote">配方数据出错比程序丢失更隐蔽：<strong>程序是「怎么干」，配方是「干什么」——配方错一个数字，整批混凝土配比全错</strong>，而程序还「看起来正常」。</span>

**常见误区**：维修工常用「恢复出厂设置」来「修」PLC 故障——**这是最后手段，不是第一手段**。恢复出厂会清空程序与参数，没有备份就是灾难。PLC 故障先查电源、电池、模块指示灯、程序运行状态，最后才考虑恢复。

**重点：** 程序与数据的管理原则归结为八个字——「**常备份、双介质、验恢复**」。这与维护保养制度里的记录档案是同一种管理哲学：**把不可再生的东西提前存好，是设备管理最便宜的投资。**

## 6 电控维护的周期与防雷防尘

搅拌站电控系统处在「粉尘 + 雷雨 + 振动」的恶劣环境，维护要按节奏、抓重点：

**维护周期**：

| 项目 | 周期 | 要点 |
| --- | --- | --- |
| 控制柜除尘 | 每月 | 断电后压缩空气吹灰，检查端子紧固 |
| 插接器检查 | 每季 | 逐个按压、清洁、涂防氧化脂 |
| 传感器校准 | 每季 | 零点、量程复核 |
| 程序与配方备份 | 每次修改后 | 双介质备份、标版本 |
| 接地与防雷检查 | 雨季前 | 接地电阻测试、避雷器检查 |

**防雷与防尘是搅拌站电控的两大专项**：<span class="marginnote">搅拌站多为钢结构露天建筑，<strong>雷电感应与直击雷都可能损坏 PLC 与仪表</strong>——接闪、引下、接地、浪涌保护（SPD）四件套要齐全有效。</span>**粉尘**则直接威胁接插件与散热——控制柜密封、正压防尘、定期除尘是「看不见的保养」。

**重点：** 电控维护最容易被忽略的是**接地与防雷**——它平时看不出问题，雷雨季节一来就「团灭」控制设备。**雨季前专项检查接地电阻（一般 ≤ 4 Ω）与浪涌保护器状态**，是搅拌站电控维护的年度必修课。

## 7 小结

- 搅拌站电控分**主控（PLC）、人机（计算机）、检测、执行、电源**五层，PLC 按扫描循环工作。
- 自动循环是「顺序 + 判断」：快给料 → 慢给料 → 停料 → 判断允差 → 投料搅拌 → 出料。
- 配料精度调整三件事：**校零点、校量程（$k = W_{\text{std}} / W_{\text{read}}$）、调落差**，顺序是「机械 → 落差 → 仪表」。
- 电气故障排查统一入口「**先安全断电、再查电源、后查信号**」，主回路检修必须上锁挂牌。
- PLC 程序「**常备份、双介质、验恢复**」；电控环境抓**防雷防尘**，雨季前查接地电阻（≤ 4 Ω）。
- 自动循环每个「判断点」都可能出故障：**读懂循环是读懂故障的前提**——知道卡在哪一步，就锁定了排查范围。
- 程序与配方是「看不见的资产」：**常备份、双介质、验恢复**，配方修改双人核对，防误改导致整批配比错误。
- 配电与接地是「看不见的维护」：**雨季前查接地电阻（≤ 4 Ω）与浪涌保护器**，雷击与粉尘是电控环境的两大专项。

**一句话记忆**：搅拌站电控 = PLC 扫描循环 + 快慢给料 + 误差三分；精度靠「零点-量程-落差」，安全靠「断电-上锁-挂牌」。

**延伸思考：从电控看维修思维**。搅拌站电控与机械维修最大的不同，是机械看「哪里坏了」，电气问「程序走到哪了」。当故障表现为「某一步不动作」，第一反应不是拆零件，而是对照自动循环查「卡点」——是传感器没给信号、变频器没调速、还是 PLC 输出没到？

这种「按流程定位」的思维，正是第 5 篇综合诊断「分层排除」的雏形：把整站电控当作一条可循的程序链，故障就是链上断了的那一环。读懂循环的人，维修快一倍；只背故障表的人，每次都是从零开始猜。

**再进一步：电控与机械的合流**。搅拌站故障常常「机电合流」——传感器读不准、变频器不调速，根源却在给料机构的机械卡滞。**机电一体，诊断才完整**：先分清是「指挥不到」还是「执行不到」，再决定修电还是修机械。
