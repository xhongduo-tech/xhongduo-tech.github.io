# 混凝土与桩工机械使用维护

混凝土泵车、搅拌站与桩基施工机械是工程机械的独立细分领域，广泛服务于房屋建筑、市政交通与桥梁桩基工程，属于机械化施工的高价值专用装备。以《工程机械维修工国家职业技能标准》混凝土/桩工方向、《混凝土泵车使用与维护》与《桩工机械》教材为纲，系统重建从基础作业、混凝土搅拌机械、混凝土泵车、桩工机械到整机维护与技能考核的完整使用与维护体系。学完这些章节，就写完了混凝土与桩工机械使用维护的全部内容。
