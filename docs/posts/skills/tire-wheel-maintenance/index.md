# 汽车轮胎与车轮维护技术

换胎、动平衡、四轮定位、胎压监测是每一位车主与轮胎工必须掌握的基础高频维护技能，直接关系行车安全、轮胎寿命与燃油经济性。以 GB 9743-2015《轿车轮胎》、GB/T 9768-2008《轮胎使用与保养规程》为规范依据，结合《轮胎修补与四轮定位》实操教材，学完这些章节，就写完了从轮胎选配、使用保养到换胎修补、动平衡与四轮定位的全部内容。
