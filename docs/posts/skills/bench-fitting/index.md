# 钳工（基础钳工操作技能）

钳工是以手工操作为主、借助台虎钳与各种工具对金属工件进行划线、锯削、锉削、钻孔、攻丝、刮削等加工的机械制造与维修入门技能。以《钳工工艺学》为纲，配合《钳工技能训练》与《国家职业技能标准—装配钳工》，学完这些章节，就写完了基础钳工从工量具使用到装配技能的完整实操链条。

## 对标教材

- 《钳工工艺学》
- 《钳工技能训练》
