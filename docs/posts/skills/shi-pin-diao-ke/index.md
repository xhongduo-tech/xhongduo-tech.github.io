# 食品雕刻与盘饰艺术

食品雕刻与盘饰艺术是烹饪美学在餐台上的完整技艺链，涵盖果蔬雕刻、盘饰设计与摆盘美化三大核心技能。以《食品雕刻技法》《盘饰与摆盘艺术》与烹饪工艺美术教材为纲，从刀具与原料基础、花卉禽鸟雕刻到盘饰构图、中西式摆盘与主题展台设计，系统写完整门"以刀为笔、以盘为纸"的餐桌艺术。

## 对标教材

- 《食品雕刻技法》
- 《盘饰与摆盘艺术》
- 烹饪工艺美术教材
