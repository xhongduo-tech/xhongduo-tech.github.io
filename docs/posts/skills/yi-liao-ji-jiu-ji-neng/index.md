# 医疗急救技能

以 AHA《心肺复苏指南》、中国红十字会《救护员》教材与《院前急救》为纲，系统构建从现场评估、心肺复苏（CPR）、AED 使用、海姆立克急救法到止血包扎与骨折固定的完整院前急救技能体系。学完这些章节，就掌握了在心跳骤停、气道梗阻、大出血等危急时刻自救互救的核心本领。

## 对标教材

- AHA《心肺复苏指南》
- 中国红十字会《救护员》
- 《院前急救》
