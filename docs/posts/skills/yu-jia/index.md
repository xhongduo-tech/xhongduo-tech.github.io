# 瑜伽

瑜伽是一门源于古印度、融合体位法、呼吸法与冥想的古老身心修炼体系，其价值在于通过体式、调息与专注的训练同时改善身体机能、稳定心绪并通向自我认知。以艾扬格《瑜伽之光》、《帕坦伽利瑜伽经》与《中国健身瑜伽段位制》为纲，系统重建从瑜伽哲学、体位法与呼吸冥想，到段位考核与教学体系的完整知识框架。学完这些章节，就写完了瑜伽学科的核心内容。

## 对标教材

- 艾扬格《瑜伽之光》（Light on Yoga）
- 《帕坦伽利瑜伽经》（Patanjali's Yoga Sutras）
- 《中国健身瑜伽段位制》
