## 为什么先学电气系统

压缩机是冰箱制冷循环的「心脏」，而让它启动、运行、保护、按温度启停的，是整套**电气系统**。上一节讲了循环四步，这一节回答「压缩机怎么转起来、怎么停下来、怎么不被烧掉」。<span class="marginnote">电气系统与温控是冰箱故障的高发区：压缩机不启动、不停机、启动后嗡嗡不转，十有八九出在启动继电器、过载保护器、温控器或电脑板这几环。学完本节，就具备了独立分析冰箱电气故障的电路视角。</span>本节从单相电机讲起，梳理启动电路、保护电路与温控方式三类核心电路。

## 1 压缩机电机与启动原理

冰箱压缩机用的是**单相感应电机**，它只有一个绕组接单相电，本身无法自行启动——单相电流产生的磁场是交变的，没有旋转方向，电机只会停在原地「嗡嗡叫」。

要让单相电机转起来，需要**在定子上再建一个相位不同的磁场**，办法是给电机增加一组**启动绕组**，并在启动绕组回路里串入一个能「移相」的元件，让启动绕组与主绕组的电流产生相位差，合成旋转磁场。冰箱里最常见的移相启动方案有两种：

**电阻分相（RSIR）**：启动绕组匝数少、电阻大，与主绕组自然形成相位差。结构简单，是直冷冰箱最常见的方案。
- **电容启动**：在启动绕组回路串入启动电容，相位差更大，启动转矩更大，多用于风冷冰箱与大功率压缩机。

**启动继电器（PTC 或重锤式）** 负责在启动瞬间接通启动绕组、启动后自动断开。PTC 启动器利用正温度系数热敏电阻的特性：冷态电阻小、启动绕组得电；通电发热后电阻骤增，相当于断开启动绕组，压缩机转入运行。<span class="marginnote">PTC 启动器是「一次通电即完成启动—运行切换」的自动开关，没有运动部件。它有一个维修要点：刚断电后 PTC 仍高温，立即再启动会因电阻大而启动无力，所以冰箱断电后要等 3–5 分钟再通电，这也是「压缩机保护」的原因之一。</span>

## 2 保护电路：过载保护器

**过载保护器（过流过热保护）** 串联在压缩机主回路中，贴在压缩机外壳上，用双金属片感知两种异常：

**过流保护**：电机电流异常增大（堵转、绕组短路），电流通过双金属片加热使其变形、触点断开，切断压缩机电源。
- **过热保护**：压缩机外壳温度过高（散热不良、长期过载），双金属片受热变形断开。

保护器断开后需冷却一段时间才能复位，这就是冰箱「启动一下又停、过几分钟又能启动」的典型表现。**如果保护器频繁动作，说明压缩机或其负载存在真故障**，不能靠换一个大电流保护器来「治标」——那会让压缩机在保护失效的状态下烧毁。

## 3 温控电路：从机械温控到电脑板

温控电路负责「温度到了就停、温度升了就开」，是压缩机启停的「指挥中心」。冰箱温控有两代技术：

**机械温控（温控器）**：利用**感温包**内制冷剂的压力随温度变化，推动开关触点。感温包贴在蒸发器上，箱温变化导致感温包压力变化，带动触点闭合/断开，直接串接在压缩机回路里控制启停。旋钮调节的是「停机温度点」。<span class="marginnote">机械温控的感温包是「温压转换器」：温度 → 液体/气体压力 → 膜片位移 → 触点动作。看懂这条链，就理解为什么感温包漏气后温控器失灵、压缩机不停机——压力传不到了，触点永远闭合。</span>

**电子温控（电脑板）**：用**热敏电阻（NTC 温度传感器）** 检测箱温，把温度变成电阻值，再由单片机（MCU）读取、判断、输出控制信号驱动继电器启停压缩机。风冷冰箱还叠加了**化霜控制**：定时器或 MCU 周期性启动化霜加热器，融化蒸发器上的结霜。

| 对比项 | 机械温控 | 电子温控 |
| --- | --- | --- |
| 测温元件 | 感温包（压力式） | NTC 热敏电阻 |
| 控制主体 | 机械触点 | 单片机 + 继电器 |
| 故障特征 | 触点粘连、感温包漏气 | 传感器漂移、继电器损坏 |
| 可调性 | 旋钮调停机点 | 面板设定温度、多传感控温 |

## 4 公式解析：热敏电阻的测温原理

电子温控的测温核心是 NTC 热敏电阻，它的阻值与温度的关系近似：

$$
R_T = R_0 \cdot e^{B\left(\frac{1}{T} - \frac{1}{T_0}\right)}
$$

- **$R_T$ 与 $R_0$**：温度为 $T$（开尔文）与 $T_0$ 时的电阻值。NTC 的阻值随温度升高**指数下降**，故名「负温度系数」。
- **$B$ 是材料常数**（约 3000–4000K），决定阻值对温度的敏感度。$B$ 越大，温度变化引起的阻值变化越大，测温越灵敏。
- **维修直觉**：万用表量到的「传感器阻值」能反推温度。例如常温 25°C 时传感器约 5kΩ，若量到 20kΩ，说明温度低（或传感器开路性漂移）；若量到几百欧，说明温度高或传感器短路性漂移。**传感器阻值异常，是电子温控冰箱「不停机/不启动」的常见根因**。
- **测温电路**：MCU 用电阻分压把 $R_T$ 变成电压 $V = \frac{R_T}{R_T + R_{\text{固定}}} \times V_{\text{CC}}$，再经 ADC 数字化。阻值大→电压高→MCU 判为低温；阻值小→电压低→判为高温。电路虽简单，却是电子温控「不停机/不启动」故障链条上的一环。

## 5 电气系统检修：从「转不转」入手

电气系统检修从「压缩机转不转」入手，分三种现象：

**不启动（完全无声）**：查电源有没有送到压缩机回路。用万用表量温控器两端、启动继电器、过载保护器是否导通，逐级排除。短接温控器试验（临时短接确认压缩机能否启动）是常用的定位手法，但**短接后必须恢复**，不能长期短接运行。
- **嗡嗡响不转**：电机得电但启动不了。重点查启动回路：PTC 启动器阻值（冷态几十欧）、启动电容是否失容、启动绕组是否断路。把启动器拆下短接主绕组，若电机能转则启动器坏。
- **转但不制冷**：电气正常，问题回到制冷循环——查制冷剂、毛细管、干燥过滤器。

<span class="marginnote">「启动继电器」是冰箱电气故障的头号高发件：PTC 启动器冷态阻值小、通电发热后阻值骤增完成切换。PTC 坏（开路/碎裂）时压缩机完全无声；重锤式启动器触点烧蚀则「嗡嗡不转」。量 PTC 阻值、敲击重锤式启动器听触点声音，能快速定位。</span>

## 6 易错辨析：电气系统的三个陷阱

**辨析｜易错点：** 冰箱电气检修最容易在三处翻车。

- **断电立即再启动**：PTC 启动器刚断电仍高温，阻值大，立即再启动会启动无力甚至不启动。所以冰箱断电后要等 3–5 分钟再通电——这既是用户常识，也是检修时试机的等待规范。
- **短接保护器长期运行**：过载保护器频繁动作时，有人为图省事短接它。**这等于拆掉压缩机的保险**——一旦堵转或过流，压缩机直接烧毁，代价远大于换保护器。
- **把「保护器动作」当故障本身**：保护器频繁跳说明系统存在真问题（堵转、绕组短路、散热不良），要查根因，不是换个大的保护器「扛住」。

| 术语 | 含义 | 要点 |
| --- | --- | --- |
| 单相感应电机 | 单相供电的电机 | 需启动绕组移相 |
| 电阻分相 | 靠绕组电阻差启动 | RSIR，直冷冰箱常用 |
| 电容启动 | 串启动电容移相 | 启动转矩大 |
| PTC 启动器 | 正温度系数元件 | 冷态小阻、热态断开 |
| 重锤式启动器 | 靠重力触点的启动器 | 触点易烧蚀 |
| 过载保护器 | 过流/过热保护 | 贴在压缩机上 |
| 温控器 | 机械温控核心 | 感温包 + 触点 |
| 感温包 | 温压转换元件 | 漏气则不停机 |
| NTC 传感器 | 负温度系数热敏电阻 | 阻值随温指数下降 |
| 化霜系统 | 风冷冰箱除霜 | 定时器/加热器/熔断器 |
| ADC | 模数转换 | 把电压变数字量 |

### 易错速查

| 场景 | 常见误判 | 正确处理 |
| --- | --- | --- |
| 断电后马上试机 | 直接通电 | 等 3–5 分钟再通电 |
| 保护器频繁跳 | 换大电流保护器 | 查堵转/短路根因 |
| 不停机 | 直接换温控器 | 先查感温包/传感器 |
| 传感器阻值异常 | 判断正常 | 对照阻值表反推温度 |
| PTC 坏 | 换压缩机 | 先量 PTC 启动器 |

### 速记口诀

- 电机启动三要素：启动绕组 + 移相元件 + 启动开关。
- PTC 一通电就切换：冷态通、热态断。
- 断电等 3–5 分钟再通电，保护压缩机。
- 保护器动作是结果不是原因，先查根因。
- 电子温控的「五官」是 NTC 传感器。
- 感温包漏气 = 温控失灵 = 不停机。

## 8 小结

- 压缩机是**单相感应电机**，靠启动绕组 + 移相元件（电阻分相或电容启动）建立旋转磁场。
- 启动继电器（PTC 或重锤式）完成「启动—运行」切换；PTC 冷态通、热态断。
- 过载保护器串联主回路，双金属片感知**过流与过热**，是压缩机的安全阀。
- 温控两代技术：**机械温控**（感温包）与**电子温控**（NTC + MCU）；传感器阻值漂移是电子温控常见根因。
- NTC 测温公式 $R_T = R_0 e^{B(1/T-1/T_0)}$：阻值随温度指数下降，量阻值能反推温度。
- 电气检修从「转不转」入手：完全无声查电源，嗡嗡不转查启动回路，转不制冷回到制冷循环。
