## 为什么单独讲电气控制

空调的机械系统（循环）与冰箱同源，但电气系统复杂得多：**压缩机、内风机、外风机、四通阀、摆风电机、传感器群**，都由一块主控板统一调度，还叠加了过载保护、相序保护（三相）、压力保护等安全机制。<span class="marginnote">定频空调的电气系统是理解变频空调的跳板：定频机的「继电器通断 + 简单传感」与变频机的「变频模块 + 通讯总线」在故障表现上差异很大，但基本电气常识（供电、电容、继电器、传感器）通用。先定频后变频，是职业培训的标准路径。</span>本节按「供电 → 负载 → 传感器 → 保护」四层梳理空调电气系统。

## 1 供电与电源电路

空调（分体式）由室外机供给主要电力，内机通过连接线缆为外机供电与控制。整机供电链路：

**市电 220V → 电源线 → 内机主控板（电源部分） → 内风机、摆风、显示；→ 连接线 → 外机（压缩机、外风机、四通阀）。**

主控板的**电源电路**把 220V 交流变换成多路低压直流：**变压器（或开关电源）→ 整流 → 稳压 → 5V/12V**。5V 供单片机（MCU），12V 供继电器线圈、风机等。

电源电路故障的表现：整机不通电、显示屏不亮、遥控无反应。排查顺序：**查电源插座有电 → 查保险管 → 查变压器/开关电源输出 → 查稳压输出 5V**。<span class="marginnote">「整机没反应」先别拆机板：先确认插座供电、插头接触、漏保是否跳闸。空调是大功率电器，插座老化、线路过细导致的「电压不足」也会让整机工作异常——电压问题往往不在机内，在供电环境。</span>

## 2 负载电路：压缩机、风机与四通阀

**压缩机**（定频）：主回路经**压缩机接触器或继电器**接 220V。启动时大电流，需**启动电容**（PTC/电容启动，同冰箱思路但容量更大）。定频压缩机一旦启动即全速运行，靠启停控制温度。

**内外风机**：内机用**贯流风机**、外机用**轴流风机**，都是单相电机 + 启动/运转电容，多挡调速靠继电器切换绕组抽头或可控硅调压。

**四通阀**：电磁阀线圈得电换向。制热时主控板给四通阀线圈通电；线圈开路、阀芯卡滞都导致换向失败。

| 负载 | 驱动方式 | 常见故障件 | 故障表现 |
| --- | --- | --- | --- |
| 定频压缩机 | 继电器/接触器 + 电容 | 电容、继电器触点 | 不启动、启动即停 |
| 内风机 | 继电器多挡/可控硅 + 电容 | 电容、可控硅 | 不转、只有高速/低速 |
| 外风机 | 继电器 + 电容 | 电容、电机 | 外机不散热、过热保护 |
| 四通阀 | 电磁线圈 | 线圈、阀芯 | 制热出冷风 |

## 3 传感器群：空调的「五官」

空调主控板依赖多个传感器采集环境与系统状态：

**室温传感器（内机）**：检测室内温度，决定启停与设定温差。阻值漂移会导致「制冷不停机」「制热不启动」。
- **管温传感器（内/外机盘管温度）**：检测蒸发器/冷凝器盘管温度，用于防结霜、防过冷、除霜控制与故障判断。管温异常是变频空调常见故障源。
- **外机环境温度传感器**：判断室外温度，控制除霜与制热运行。

传感器多为 **NTC 热敏电阻**（冰箱专题讲过原理）：阻值随温度指数变化，分压后送 ADC 给 MCU。<span class="marginnote">传感器故障的经典表现是「显示故障代码」（如 E1/E2）或「运行逻辑错乱」。检修时先量传感器在常温/冰水/热水下的阻值是否合理变化，再查插头接触与线路。<strong>传感器阻值表</strong>是维修手册里的常备数据，不同阻值对应不同温度。</span>

## 4 保护电路：空调的自卫系统

空调电气系统有多重保护：

- **过载保护器（压缩机）**：双金属片，感知压缩机电流与温度，过热过流断开。
- **保险管与熔断器**：整机过流保护。反复烧保险说明存在短路或过载，先查根因。
- **压力保护（高压/低压开关）**：监测系统压力，压力异常（过高/过低）切断压缩机，防止损坏。压力异常背后是制冷剂过多、管路堵塞或制冷剂泄漏。
- **除霜控制**：制热时管温传感器判断室外换热器结霜，自动进入除霜循环。
- **过流/过压保护（变频机）**：变频模块监测母线电压与电流，异常时停机报警。

**辨析｜易错点：** 保护电路动作是「结果」不是「原因」。保险丝断了、过载保护跳了，是系统在告诉你「有异常」，**要查异常根因，而不是换个大保险丝让它继续烧**。这条逻辑在冰箱、微波炉、空调所有专题里反复出现，是维修思维的分水岭。

## 5 公式解析：压缩机启停的功率逻辑

定频空调的温控本质是「启停控制」，用一个简单的功率/温度关系理解：

$$
Q_{\text{制冷}} = \dot m \cdot c_p \cdot (T_{\text{回}} - T_{\text{送}})
$$

- **$Q_{\text{制冷}}$ 是实际制冷量**：由风量 $\dot m$、空气比热 $c_p$、送回风温差 $(T_{\text{回}} - T_{\text{送}})$ 三者相乘。这是空调运行时真正从室内搬走的热量。
- **维修用途**：量送风温差是判断制冷效果的快速手段。正常制冷时送风温度应比回风低 8–12°C（温差不足：制冷剂不足、风量不足、蒸发器脏堵）。一台「制冷量虚标」的空调，量温差就能戳穿。
- **与名义制冷量的关系**：名义制冷量是标准工况下的标称值，实际制冷量随环境温度、风量变化。EER = 实际制冷量/实际功率，才是这台空调当下的真实能效。

## 6 故障代码与检修流程

现代空调把常见故障编码成「故障代码」显示在面板上，是检修的第一张地图。常见代码（各品牌含义有差异，以手册为准）：

| 代码族 | 含义 | 检修方向 |
| --- | --- | --- |
| E1（各品牌含义不同） | 常见为传感器/通讯类 | 查对应传感器阻值、插头、线路 |
| 室温传感器故障 | 内机室温传感异常 | 量阻值、对比阻值表 |
| 管温传感器故障 | 盘管温度传感异常 | 量阻值、查插头 |
| 压缩机保护 | 过流/过压/过热 | 查负载、电压、散热 |
| 通讯故障（变频） | 内外机通讯中断 | 查连接线、干扰、通讯芯片 |

<span class="marginnote">故障代码不是「诊断结论」，而是「诊断入口」。代码指向传感器或某回路，<strong>但根因可能是插头松、线路断、传感器漂移或主控板坏</strong>。沿着代码进入对应回路，按「供电 → 输入 → 输出 → 元件」逐级查，才能从「代码」走到「元件」。</span>

**检修流程**：报代码 → 查代码含义 → 进入对应回路 → 量供电、量传感器阻值、量执行件 → 定位元件更换 → 清除代码试机。代码只能缩小范围，不能替代测量。

## 7 易错辨析：空调电气检修的三个误区

**辨析｜易错点：** 空调电气故障最容易在三处判断错。

- **「保险丝断了就换保险丝」**：反复烧保险说明存在短路或过载，要先查根因（压缩机堵转、电容击穿、线路短路）。换个大的保险丝让它继续烧，等于拆掉保护。
- **「传感器坏了看阻值对不上」**：先看阻值是否随温度**合理变化**——常温、冰水、热水各量一次，阻值明显变化说明传感器是好的，问题在插头、线路或主控板。
- **「外机不启动就换外机板」**：先确认内机有没有给外机供电、连接线是否正常、有无通讯。内外机之间的连接线与通讯，是变频空调检修最常被忽略的一环。

| 术语 | 含义 | 要点 |

| 故障代码 | 故障编码 | 诊断入口非结论 |

### 易错速查

| 场景 | 常见误判 | 正确处理 |
| --- | --- | --- |
| 反复烧保险 | 换大保险丝 | 查短路/过载根因 |
| 传感器报错 | 直接换传感器 | 先量阻值变化规律 |
| 外机不启动 | 换外机板 | 先查供电与连接线 |
| 制冷不停机 | 换压缩机 | 先查室温传感器与设定 |
| 保护动作 | 清代码了事 | 查代码指向的回路根因 |

### 速记口诀

- 四层结构：供电 → 负载 → 传感器 → 保护。
- 整机没反应先查电源环境，再拆机板。
- 传感器看「变化」不看「绝对值」。
- 故障代码是入口，不是结论。
- 反复烧保险必有根因，先查再换。
- 变频先查内外机通讯，别急着换板。

## 9 小结

- 空调电气四层：**供电 → 负载（压缩机/风机/四通阀）→ 传感器群 → 保护电路**。
- 电源电路：**变压器/开关电源 → 整流 → 稳压 → 5V/12V**；整机没反应先查供电环境。
- 负载驱动：定频压缩机靠继电器/接触器 + 启动电容；风机多挡调速；四通阀电磁线圈换向。
- 传感器是空调「五官」：室温、管温、外机环境温度，多为 NTC；阻值漂移是变频空调常见故障源。
- 保护电路动作是「结果」不是「原因」：**先查根因，别换大保险丝让它继续烧**。
- 实际制冷量 $Q = \dot m c_p (T_{\text{回}} - T_{\text{送}})$，量送风温差是判断制冷效果的最快手段。
