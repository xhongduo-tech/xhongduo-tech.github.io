## 为什么最后学综合诊断

前几节把彩电拆成八大功能块逐一讲透，本节把它们**拼回去**：面对一台故障电视，不再按章节找答案，而是用「**症状 → 故障区 → 电路 → 元件**」四层映射做整机排障。<span class="marginnote">综合诊断是职业能力的试金石：师傅和学徒的差别，往往不在会不会量某一个电路，而在「面对没见过的新故障，能不能按逻辑拆解」。这节把散落的知识点收拢成一套可复用的方法论——这套方法不止管彩电，也管冰箱、空调、洗衣机，甚至任何带电源带主板的机器。</span>本节讲诊断原则、症状定位表、综合排障流程与实战案例。

## 1 综合诊断的三大原则

**原则一：先电源、后信号。** 整机不通、全无反应，先查电源；电源正常再进信号链。电视所有功能块都要供电，电源坏了其他全免谈——这是最优先的一步。

**原则二：先外部、后内部。** 天线/信号源、设置、遥控，先排除「不是故障的故障」；再开盖查机内。很多「电视坏了」其实是信号源没选对、静音按了、亮度调成 0。

**原则三：先外围、后芯片。** 查 IC 前先量它的供电、地、输入输出与周边元件。IC 是「最后怀疑对象」，因为换 IC 成本高且外围故障常被误判成 IC 故障。

这三条原则串成一句口诀：「**外源 → 电源 → 信号链 → 外围 → 芯片**」。<span class="marginnote">把口诀展开就是完整的排障流程：确认外部输入与设置 → 量电源各路输出 → 按「有声无图、有图无声、无图无声、图声都乱」圈定功能块 → 在该块量供电、输入、输出 → 最后怀疑并替换芯片。五步走完，绝大多数故障都已定位。</span>

## 2 症状定位表：从现象到故障区

| 症状族 | 首要怀疑区 | 快速验证 |
| --- | --- | --- |
| 整机无反应 | 电源、CPU | 量 +B、5V；查 CPU 三要素 |
| 无光栅有声 | 行扫描、高压、显像 | 量行管、行变、灯丝 |
| 无光栅无声 | 开关电源 | 量 300V、启动、各路输出 |
| 有光栅无图像 | 视放、解码、中频 | 碰视放输入、量视频 |
| 有图无声 | 伴音中放、鉴频、功放 | 碰功放输入、量扬声器 |
| 有声无图 | 视放、显像管 | 量三枪电压、灯丝 |
| 黑白正常无彩 | 色度通道、晶振 | 量色度输入、4.43MHz 晶振 |
| 图像扭曲/不同步 | 同步分离、AGC、中频 | 量 AGC、同步输出 |
| 遥控失灵 | 遥控器、接收头、CPU | 看发射、量接收头、CPU 三要素 |
| 功能错乱 | I²C 总线、存储器 | 量总线波形、试重写数据 |

<span class="marginnote">这张定位表是综合诊断的「查表工具」：拿到故障，先对号入座找到首选故障区，再进入该区按「供电 → 输入 → 输出 → 元件」细查。<strong>查表不是终点，是起点</strong>——表的价值是把「十个可能」收敛成「一个优先」，剩下的交给仪表。</span>

## 3 综合排障的仪表组合

综合诊断的仪表配合：**万用表**量电压、电阻、通断；**示波器**看波形；**钳形表**量整机/行电流；必要时**显像管再生仪、扫频仪**做专项测试。

三个高频测量组合：

- **「无光栅」三件套**：量 +B 主电压 → 量行管集电极电压 → 量灯丝电压。三处一量，电源、行扫描、高压有没有问题立刻清楚。
- **「无声」三件套**：量扬声器阻值 → 量功放供电 → 量中点电压。再配合碰触注入，前后端一分为二。
- **「无彩色」三件套**：量色度输入 → 看晶振波形 → 量色度输出。三处一量，色度通道是否工作见分晓。

## 4 公式解析：整机功率与行电流的估算

综合诊断里，「电流」是最会说话的量，用功率关系估算：

$$
I_{\text{行}} = \frac{P_{\text{行}}}{U_{+B}}, \qquad I_{\text{总}} = \frac{P_{\text{总}}}{220\,\mathrm{V}}
$$
