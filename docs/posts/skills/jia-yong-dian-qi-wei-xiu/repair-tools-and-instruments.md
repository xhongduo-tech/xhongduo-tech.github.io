## 为什么先配置工具

上一节我们认识了元件，但「看」不出坏没坏，得靠**仪表去量**。维修诊断链是「观察现象 → 推断故障区 → 测量定位 → 更换元件」，其中测量这一步全靠工具。工具选错，轻则读数不准、白忙一场，重则触电、损坏设备。<span class="marginnote">工具配置和「家庭组网与路由器配置」里的测线器、网络分析仪是同一逻辑：先确定「我要判断什么量」，再选能量到那个量的仪表。方向反了，工具箱再贵也救不了你。</span>本节把一套家用电子产品维修的**标准工具包**讲清楚：每件工具量什么、怎么用、何时不能用。

## 1 万用表：维修的第一仪表

**万用表（multimeter）**：能测量电压、电流、电阻等多种电量，是维修工的「听诊器」。分数字万用表与指针（模拟）万用表两类。

| 对比项 | 数字万用表 | 指针万用表 |
| --- | --- | --- |
| 读数 | 液晶数字，精确直接 | 表针摆动，看刻度 |
| 输入阻抗 | 高，对被测电路影响小 | 低，可能改变电路工作点 |
| 测电阻 | 无需调零，直接读 | 需先欧姆调零 |
| 测电容 | 大多有电容挡 | 一般不测电容 |
| 动态观察 | 数字跳变，不适合 | 表针摆动直观，适合看充放电、看振荡 |

<span class="marginnote">维修实战中两支表常配合使用：数字表测静态值（供电、阻值、二极管压降），指针表看动态过程（电容充放电、启动瞬间、电解电容漏电）。条件有限时优先备数字表。</span>

数字万用表的常用挡位必须练熟：**直流电压挡**（测供电，如冰箱温控电路 5V、彩电电源 12V）、**交流电压挡**（测市电 220V、变压器次级）、**电阻挡**、**二极管挡**、**通断挡**（蜂鸣响则导通，查保险、查线路断点极方便）。测电压时表笔**并联**接入被测两点，测电流时表笔**串联**接入回路——并联与串联一字之差，接反轻则烧保险，重则损坏表内电路。

## 2 钳形表与兆欧表：电流与绝缘的专用仪表

**钳形电流表（clamp meter）**：钳口套住一根导线就能测出其中电流，**无需断开电路**。<span class="marginnote">钳形表测的是「穿过钳口的磁通换算成的电流」，所以只能钳单根线——同时钳住火线与零线，两个磁场互相抵消，读数会归零。这个原理本身就是一个常考易错点。</span>它适合测电机启动电流、整机功耗电流、压缩机工作电流。测电流时，读数要等到电机稳定后再记，启动瞬间的冲击电流可比运行电流大数倍。

**兆欧表（megohmmeter，绝缘电阻表）**：输出 500V 或 1000V 高压，专门测量电器对地的**绝缘电阻**。家用电器的绝缘电阻应不小于 $0.5\,\mathrm{M\Omega}$（兆欧，$10^6\,\Omega$）。它用于：怀疑漏电时测火线对地、电机绕组对地、加热管对地。**严禁**用普通万用表电阻挡测绝缘——普通表的电池电压太低，量不出高压绝缘的真实状态。使用兆欧表时被测设备必须断电，且测试后要对被测部位放电。

## 3 示波器：把看不见的波形「画」出来

**示波器（oscilloscope）**：把电压随时间变化的曲线显示在屏幕上。开关电源的开关波形、晶振的振荡波形、遥控信号的编码波形，只有示波器能看到。

示波器的三个核心参数是**带宽**（如 100MHz，决定能观察多快的信号）、**采样率**、**通道数**。家用电子产品维修中 50–100MHz 双通道数字示波器足够。使用方法四步：**接地夹接地 → 探头接被测点 → 选电压挡（V/div）与时间挡（s/div）→ 调触发电平**。<span class="marginnote">示波器是「图」的语言，与数字表是「数」的语言互补。比如彩电行输出不工作，用示波器看行激励波形有没有、幅值够不够，比盲目换件快得多。学示波器不必一步到位，先学会「看有没有波形、看幅值、看频率」三件事就够入门。</span>测电源纹波、测行场同步信号、测遥控编码，都是示波器的主场。

## 4 电烙铁、热风枪与拆装工具

仪表负责「诊断」，焊接工具负责「治疗」。

**电烙铁（soldering iron）**：焊接与拆卸元件的核心工具。家用电子产品维修建议 30–60W 恒温电烙铁，配尖头烙铁头。使用要点：烙铁头要**先上锡保护**，焊接时间控制在 2–4 秒，避免长时间烫坏铜箔与元件；焊点要求光亮、饱满、成小山丘状。焊锡用含铅松香芯焊锡或环保焊锡，温度约 350°C。

**热风枪（hot air gun）**：拆卸多脚集成电路的利器。用风嘴对 IC 四周均匀加热，锡熔化后即可取下；装回时对准引脚、加热到位。热风枪风力与温度要配合，温度一般 300–380°C，**风力先小后大**，防止把周边小元件吹飞。

其他必备拆装工具：**螺丝刀组**（一字、十字、内六角，注意防磁）、**镊子**（尖头、弯头）、**吸锡器或吸锡带**（清理旧焊点）、**剥线钳**、**斜口钳**、**防静电手环**（修电路板时佩戴，防止静电击穿 MOS 管与 IC）。

## 5 公式解析：挡位选择与读数换算

万用表读数不是拿来就用，常要换算，公式只有一步：

$$
\text{读数} = \text{表盘刻度} \times \text{所选量程的倍率}
$$

以指针表为例：拨到「$\times 100$」电阻挡，指针停在刻度「22」处，则阻值 $= 22 \times 100 = 2200\,\Omega$。数字表更省事：拨到 `200k` 挡显示 `2.20`，单位就是 kΩ，即 $2.20\,\mathrm{k\Omega}$。<span class="marginnote">选挡原则：<strong>先大后小</strong>。不知道被测值大小就先拨到最大量程，读数太小再逐挡缩小，避免指针打表或数字超量程显示 `OL`。</span>

测电压时的换算同理：数字表 `20V` 挡显示 `5.03`，就是 $5.03\,\mathrm{V}$；`200mV` 挡显示 `50.0`，是 $50.0\,\mathrm{mV}$，千万别把量程后缀当成单位。

## 6 易错辨析：工具的五个红线

**辨析｜易错点：** 工具用错的后果比没工具更糟。

- **测电阻不断电**：在线带电测电阻，轻则读数全错，重则烧表。任何电阻测量前先确认电路已断电、电容已放电。
- **电流挡当电压挡用**：把表笔并联到电源两端去「测电流」，等于把表内低值分流电阻短路接电源，瞬间烧表。测电流永远串联。
- **钳形表钳两根线**：火零同钳，磁通抵消读数归零，误判「没电流」。
- **兆欧表当万用表**：兆欧表输出高压，只能测绝缘，绝不能测工作电路；测完必须放电。
- **热风枪一开最大风**：小元件被吹飞、邻近塑料件被烤变形。风量从小到大、温度适中、边吹边观察。

## 7 术语速查表

| 术语 | 含义 | 使用要点 |
| --- | --- | --- |
| 万用表 | 测电压/电流/电阻等多功能表 | 测电压并联、测电流串联 |
| 数字万用表 | 液晶读数，输入阻抗高 | 测静态值首选 |
| 指针万用表 | 表针摆动，看动态直观 | 看充放电、看摆动 |
| 钳形表 | 免断线测电流 | 只能钳单根导线 |
| 兆欧表 | 测绝缘电阻，输出高压 | 只能测绝缘，测后放电 |
| 示波器 | 显示电压波形的仪表 | 看有没有、幅值、频率 |
| 电烙铁 | 焊接工具 | 30–60W，恒温更佳 |
| 热风枪 | 拆多脚 IC 工具 | 温度 300–380°C，风力先小后大 |
| 吸锡器 | 吸取熔锡 | 配合烙铁拆直插件 |
| 吸锡带 | 编织铜网吸锡 | 清理 IC 引脚缝隙 |
| 绝缘电阻 | 电器对地绝缘，应 ≥ 0.5MΩ | 用兆欧表测量 |
| 通断挡 | 蜂鸣判断导通 | 查保险、线路断点 |
| 静电防护 | 防静电手环接地 | 保护 MOS 管与 IC |

### 易错速查

| 操作 | 常见误判 | 正确处理 |
| --- | --- | --- |
| 测电阻 | 不断电直接测 | 断电放电后测量 |
| 测电流 | 表笔并联到电源 | 表笔串联进回路 |
| 钳形表 | 火零线一起钳 | 只钳单根线 |
| 兆欧表 | 当万用表用 | 只测绝缘，测后放电 |
| 选挡 | 不知道量程就乱拨 | 先大后小逐挡缩小 |

### 速记口诀

- 万用表：电压并联、电流串联，一字之差分生死。
- 钳形表：单根线、免断线，火零同钳读数归零。
- 兆欧表：专测绝缘，测后必放电。
- 示波器三问：有没有波形？幅值够不够？频率对不对？
- 烙铁：先上锡、短时焊、恒温更稳。
- 热风枪：风先小后大，防吹飞小件。
- 静电手环：上板前戴上，保护 MOS 与 IC。

## 8 小结

- **万用表**是核心，数字表测静态、指针表看动态；测电压并联、测电流串联。
- **钳形表**免断线测电流，只能钳单根线；**兆欧表**测绝缘电阻，绝缘值 ≥ $0.5\,\mathrm{M\Omega}$
