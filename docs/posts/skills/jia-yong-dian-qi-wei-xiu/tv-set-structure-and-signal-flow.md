## 为什么先画整机框图

彩色电视机是家用电子产品里**电路最复杂**的一类：它同时处理射频信号、视频信号、音频信号、同步与扫描、电源与显像，还要响应遥控指令。面对一块密密麻麻的电路板，维修的第一步不是「哪个元件」，而是「**信号从哪来、到哪去、在哪一环断掉**」。<span class="marginnote">彩电维修有一句行话：「<strong>先框图后电路</strong>」。整机框图把整机拆成几个功能块，每一块完成一件事；故障时先判断「哪个功能块坏了」，再进入该块查具体电路。这比在成千上万个元件里乱找高一个维度——也是从《维修接待》贯穿至今的「先圈区、再定位」在复杂系统上的终极形态。</span>本节画出彩电整机的结构骨架与信号流程。

## 1 彩电的两大信号：视频与音频

电视台发射的信号是**全电视信号（视频）** 与 **伴音信号（音频）** 的组合：

**视频信号**：包含图像信息、行/场同步脉冲、色同步信号。彩电视频信号里还有**色度信号**（在亮度信号上调制）。
- **伴音信号**：独立的音频载波，与视频载波相差一个固定频率（我国制式为 6.5MHz）。

彩色电视制式决定信号格式：我国与欧洲大部分地区用 **PAL 制**（逐行倒相），北美用 NTSC，法国用 SECAM。PAL 制行频 15625Hz、场频 50Hz，视频带宽 6MHz。<span class="marginnote">「制式」是电视信号的「语法规则」。PAL、NTSC、SECAM 在色度编码与扫描参数上不同，维修时换主板、接信号源都要注意制式匹配。老式彩电的「制式切换故障」在今天的维修里已少见，但理解制式仍是读懂电路的底层知识。</span>

## 2 彩电整机的功能块划分

一台传统彩电（CRT 显像管时代）按信号路径分成八大功能块：

1. **高频调谐器（高频头）**：选台、变频。把某频道的高频电视信号变成固定的中频信号。
2. **图像中频通道**：中频放大、检波。把中频信号还原成视频信号。
3. **伴音通道**：伴音中频放大、鉴频、音频功放，最后推动扬声器。
4. **彩色解码电路**：从视频信号中解出亮度信号与 R、G、B 三基色信号。
5. **同步与扫描电路**：分离行场同步信号，驱动行/场偏转线圈，让电子束扫描出光栅。
6. **开关电源**：把 220V 市电变成整机需要的各路直流电压。
7. **遥控系统与总线控制**：接收遥控指令，通过 I²C 总线调整各电路。
8. **显像管及其附属电路**：CRT 显像、聚焦、高压。

<span class="marginnote">现代液晶电视用「数字板 + 背光系统 + 液晶屏」取代了 CRT 的扫描与显像部分，但<strong>信号处理链条依然是「高频/输入 → 中频/解码 → 视频处理 → 显示驱动」</strong>。学 CRT 彩电的信号流程，是理解一切电视机的通用骨架。</span>

## 3 信号流程：从天线到屏幕

把整条视频信号路径走一遍：

**天线/AV 输入 → 高频调谐器 →（中频信号 38MHz）→ 图像中频通道 →（视频信号）→ 彩色解码 →（R/G/B）→ 视频放大 → 显像管。**

音频路径并行：**伴音中频 → 鉴频 → 音频功放 → 扬声器。**

每一步都有对应的检修测量点：

| 环节 | 测量点 | 正常信号特征 |
| --- | --- | --- |
| 高频调谐器输出 | 中频输出脚 | 38MHz 中频信号 |
| 中频通道输出 | 视频输出脚 | 有同步脉冲的视频波形 |
| 解码电路输出 | R/G/B 输出脚 | 三路基色信号 |
| 伴音功放输出 | 扬声器端子 | 音频信号 |

## 4 公式解析：中频频率与频道划分

电视信号进高频头后要统一变成**中频**，这是因为中频放大容易做高增益。我国电视中频标准：

$$
f_{\text{图像中频}} = 38\,\mathrm{MHz}, \qquad f_{\text{伴音中频}} = 31.5\,\mathrm{MHz}
$$

- **中频是「搬移」而非「删除」**：高频头本振频率 $f_{\text{本振}}$ 与接收频道载波 $f_{\text{信号}}$ 差频，得中频 $f_{\text{中频}} = f_{\text{本振}} - f_{\text{信号}}$
