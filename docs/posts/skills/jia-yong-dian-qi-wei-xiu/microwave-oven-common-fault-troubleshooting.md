## 为什么故障集中在几处

微波炉电路相对单一，故障规律性强：**不加热、转盘不转、灯不亮、打火、漏电、程序失灵**——每一类都对应固定的排查链。上一节讲过高压电路，这一节把各类故障的「症状 → 故障区 → 元件」映射关系讲透，并给出每类故障的排查顺序。<span class="marginnote">微波炉检修有个特点：<strong>部件少、逻辑直</strong>。排查时顺着「市电 → 保险 → 联锁 → 控制 → 高压链 → 磁控管」往下走，一次能走完。把这条链记熟，比背一百个「案例」更管用——这也是从《维修接待》一路贯彻的「先圈区、再定位」方法论。</span>

## 1 不加热：最常见的工单

「灯亮、转盘转、就是不热」——这是微波炉最典型的故障，说明控制与低压部分正常，问题出在**高压链**。排查顺序：

1. **查磁控管灯丝**：量磁控管灯丝阻值（两脚之间约 0.2–1Ω），开路则磁控管损坏。
2. **查高压变压器**：量初级/次级绕组阻值，开路或短路则更换。变压器初级得电与否，用万用表交流挡测。
3. **查高压电容**：放电后量容量（约 1μF），失容则更换；同时查电容是否击穿短路。
4. **查高压二极管**：用电池串联法测单向导通性，短路或断路则更换。

| 检查项 | 正常值（参考） | 失效表现 |
| --- | --- | --- |
| 磁控管灯丝 | 0.2–1Ω | 开路 → 不加热 |
| 高压变压器次级 | 百欧级 | 开路/短路 → 不加热 |
| 高压电容 | 约 1μF | 失容/击穿 → 不加热、打火 |
| 高压二极管 | 单向导通 | 短路/断路 → 不加热 |

<span class="marginnote">高压链四件套的检修顺序是「<strong>由易到难、由便宜到贵</strong>」：先量灯丝（拆磁控管连线即可量）、再量高压电容、二极管，最后才怀疑并更换昂贵的磁控管与变压器。多数「不加热」的元凶其实是高压电容失容或二极管击穿，这两件换起来又便宜又简单。</span>

## 2 灯亮转盘不转 / 转盘不转

「转盘不转」分两种：

**灯亮、能加热、转盘不转**：问题在转盘电机或传动。转盘电机是低压小电机（同步电机），量阻值（几百欧）开路则更换；传动齿轮磨损、转盘卡滞也需检查。
- **灯不亮、转盘不转、不加热**：整个低压回路没得电。查保险管、门联锁开关、电源线。

「能加热、但转盘不转」其实不影响加热功能（微波仍工作），但受热不均，需修复转盘。

## 3 打火与拉弧

「炉内打火、有火花、噼啪响」是微波炉危险故障，常见原因：

- **炉腔内金属物**：金属餐具、锡纸、带金属边的餐具在微波中感应产生大电流，尖端放电打火。**先让用户取出金属物**，多数「打火」是使用错误。
- **云母片（微波挡板）污损**：炉腔侧壁的云母片长期吸附油污，碳化后在高频场下打火烧穿。云母片烧穿要更换，否则微波直接打到机芯。
- **高压链打火**：高压变压器/电容/二极管绝缘老化、连接松动，在高压下爬电打火。伴随「吱吱」声与焦糊味，需检查绝缘与接线。

<span class="marginnote">打火故障要按「<strong>先使用、后机芯</strong>」排查：先让用户排除金属物，再查云母片，最后才查高压绝缘。把用户操作问题修成换件工单，既冤枉又没解决根因——这条顺序在几乎所有家电故障里都成立。</span>

## 4 漏电与门联锁

- **机壳带电（麻手）**：多为接地不良或绝缘损坏。检查电源地线是否可靠接地、高压电容是否对地击穿、磁控管是否对地短路。**机壳带电必须查绝缘与接地，不能靠「用绝缘垫」掩盖**。
- **门联锁失灵**：微波炉有多重门联锁（通常 3 个微动开关串联），门开必须立即切断微波。联锁开关接触不良或顺序错误，会导致「门关了也不加热」或更危险的「门开着也能加热」。
- **门关不上/门封条老化**：门钩变形、门铰链松、门封条破损。门封条破损会增大微波泄漏风险，需更换并测泄漏。

**辨析｜易错点：** 门联锁的调整要格外谨慎——微波炉的门联锁开关是安全关键件，**不能用短接的方法「修好」它**。为图省事短接门开关，等于拆掉安全气囊，一旦门开着工作，后果是微波直接照射人体。这类「修复」绝对禁止。

## 5 公式解析：断电后的放电估算

高压电容的危险性可用 RC 放电时间常数估算：

$$
\tau = R C, \qquad V(t) = V_0\, e^{-t/\tau}
$$

- **$\tau = RC$ 是放电时间常数**：高压电容约 $1\,\mu\mathrm{F}$，若无放电回路，理论上电荷保持极久——这就是「断电后仍带电」的原因。
- **$V(t) = V_0 e^{-t/\tau}$**：电压随时间按指数衰减。若电容经人体电阻（$1\,\mathrm{k\Omega}$）放电，$\tau = 1\,\mathrm{ms}$，看似很快——但初始 $V_0$ 高达 4000V，即便衰减到 1% 仍有 40V 残留；且实际放电回路电阻远大于人体电阻时，电荷能保持数小时。所以**断电后必须主动放电**，不能等它自己放完。

## 6 高压链的测量技巧

高压链四个件的测量各有讲究，是「会量」和「不会量」的分水岭：

**磁控管灯丝**：两脚之间量，正常 0.2–1Ω。量的是灯丝是否开路——灯丝断则磁控管报废，只能换。
- **高压电容**：先放电，再量容量（约 1μF）与漏电。容量明显偏小是失容，需更换；电容对地击穿则整机短路、烧保险。
- **高压二极管**：串联一节 9V 电池再量（普通挡 1.5V 测试电压不够），看单向导通性。正反都不通或都通，都是坏管。
- **高压变压器**：量初/次级绕组阻值判断开路或短路；初级得电与否用交流挡测。

<span class="marginnote">高压链检修的顺序是「<strong>由易到难、由便宜到贵</strong>」：先量灯丝（拆连线即可量）、再量电容二极管、最后才怀疑昂贵的磁控管与变压器。多数「不加热」的元凶是高压电容失容或二极管击穿，换起来便宜又简单。</span>

### 易错速查

| 场景 | 常见误判 | 正确处理 |
| --- | --- | --- |
| 不加热 | 直接换磁控管 | 先量灯丝/电容/二极管 |
| 打火 | 怀疑机芯 | 先取金属物、查云母片 |
| 门联锁失灵 | 短接修复 | 短接等于拆安全气囊 |
| 机壳带电 | 垫绝缘垫掩盖 | 查接地与高压绝缘 |
| 转盘不转 | 换转盘电机 | 先分清灯亮不亮 |

### 速记口诀

- 故障规律：不加热查高压链，打火查云母，漏电查绝缘。
- 高压链从便宜查起：灯丝 → 电容 → 二极管 → 变压器/磁控管。
- 断电、放电、再动手，微波炉的铁律。
- 门联锁是安全件，禁止短接。
- 空载试机必放水，云母油污易打火。
- 高压电容失容是微波炉的「老毛病」，先量它。

## 8 小结

- 微波炉故障集中两类：**高压链**（不加热）与**联锁门**（安全失灵），先摸清这两块就修好一大半。
- 不加热排查顺序：**灯丝 → 高压电容 → 高压二极管 → 变压器/磁控管**，由易到难、由便宜到贵。
- 打火按「先使用、后机芯」：取出金属物、查云母片、再查高压绝缘。
- 漏电查**接地与高压绝缘**，机壳带电不能靠垫绝缘垫掩盖。
- 门联锁是安全关键件：**短接等于拆掉安全气囊，绝对禁止**。
- 放电估算：$\tau = RC$，断电后必须主动放电，不能等电荷自己衰减。
