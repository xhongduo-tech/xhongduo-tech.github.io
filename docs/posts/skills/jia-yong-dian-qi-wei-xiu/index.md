# 家用电器维修（家用电子产品维修工）

以《国家职业技能标准—家用电子产品维修工》为纲，系统覆盖冰箱、洗衣机、空调、彩电、微波炉等家用电子产品的结构原理、故障检测与维修工艺。从元器件识别、安全防护到制冷循环检修、彩电解码电路与综合排障，逐步建立可支撑国家职业技能等级考核与上门维修服务的完整能力。
