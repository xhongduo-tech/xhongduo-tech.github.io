## 为什么遥控与总线要一起讲

遥控系统是电视机的「输入大门」，总线（I²C）是电视机的「内部神经」——遥控器把指令送进 CPU，CPU 再通过总线把调整参数发给各个功能芯片。<span class="marginnote">理解「遥控输入 → CPU → I²C 总线 → 各芯片」这条链，就理解了现代电视机的控制骨架。老式彩电的「机械按键 + 电位器调整」已被「编码遥控 + 总线软件调整」取代——维修上最大的变化是：很多「毛病」不是硬件坏，而是<strong>总线数据错乱</strong>，重写数据就好。</span>本节讲遥控发射/接收、CPU 控制、I²C 总线与相关故障。

## 1 红外遥控系统：从按键到指令

**遥控器（遥控发射器）** 把按键编码成红外信号发射。系统分三环：

1. **编码**：遥控器内的编码 IC（或 MCU）把按键位置编码成串行脉冲序列（遥控码）。
2. **调制与发射**：遥控码对 38kHz 载波进行调制（ASK 键控），驱动红外发光二极管（LED）发射 940nm 红外光。<span class="marginnote">遥控器用的红外是「调制光」：38kHz 载波把遥控码「背」出去。电视机里有一个 38kHz 的接收解调器，只认这个频率的红外——这就是为什么遥控器要对准、且节能灯等强干扰源会让遥控失灵（干扰 38kHz 频段）。</span>
3. **接收与解码**：电视机面板上的红外接收头接收、解调、还原遥控码，送 CPU 识别执行。

遥控故障三问：**遥控器发射吗？（摄像头/手机看红外灯亮不亮）→ 接收头收到吗？（量接收头输出有无波形）→ CPU 识别吗？（总线动作正不正常）**。遥控器电池、晶振、红外管，接收头供电与输出，是两大故障区。

## 2 CPU 与系统控制

电视机的 **CPU（微控制器）** 是整机的「大脑」，它负责：

接收遥控/按键指令，解析执行（选台、调音量、换制式）。
- 通过 **I²C 总线** 向各芯片写控制字（频道、音量、亮度、几何参数）。
- 监测面板按键、指示灯、保护信号，上报故障状态。

CPU 正常工作三条件：**供电（5V）正常、晶振起振、复位正常**。三者缺一，CPU 死机，表现为「按遥控没反应、指示灯异常」。<span class="marginnote">CPU 的「三要素」——电源、晶振、复位——是所有微控制器系统的通用开机检查项，冰箱电脑板、变频空调外机板、洗衣机电脑板全都一样。学会查 CPU 三要素，就掌握了所有「带电脑的家电」的启动检修。</span>

## 3 I²C 总线：电视机的内部高速公路

**I²C 总线（Inter-Integrated Circuit）** 是飞利浦发明的双线串行总线，彩电用它连接 CPU 与各功能芯片：

**SDA（数据线）**：双向传输数据。
- **SCL（时钟线）**：CPU 输出时钟，同步数据传输。
- **地址寻址**：每个芯片有唯一地址，CPU 按地址读写，一根总线挂多个芯片。

I²C 总线的维修特征：**两线都是高电平（上拉电阻接电源），有数据时产生脉冲**。量 SCL/SDA 波形，能看到一串串脉冲；总线被拉低（某芯片短路、上拉电阻坏），CPU 无法通讯，表现为「功能紊乱、某功能失灵」。<span class="marginnote">I²C 总线故障的典型场景：一台电视「图像声音都正常，但某个菜单项乱跳、某项功能失灵」，十有八九是总线某芯片挂死把 SDA 拉低。逐片断开挂载芯片排查，或用示波器看总线波形是否被拉死，是总线检修的基本功。</span>

## 4 总线数据与「软件故障」

彩电在出厂时把大量**调整数据**（白平衡、几何、AGC、菜单选项）写入存储器的总线数据中。这些数据由维修模式（总线调试模式）读写。**总线数据错乱是 CRT 彩电的经典「软故障」**：

| 故障表现 | 可能的数据/硬件问题 | 处理 |
| --- | --- | --- |
| 图像偏色、行幅不对 | 总线数据被改错 | 进维修模式重调 |
| 菜单选项缺失 | 存储数据损坏 | 重写/更换存储器 |
| 功能失灵、按键错乱 | CPU/存储器/总线故障 | 查 CPU 三要素、总线、存储器 |
| 开机即进入「工厂模式」 | 存储器数据丢失 | 初始化存储器 |

**辨析｜易错点：** 总线数据故障要先分清「硬件」与「软件」：量总线波形正常 → 多为存储器数据坏，重写即可；总线被拉低 → 查硬件短路。**别一上来就换 CPU/存储器**，先量总线波形与电平，再决定是「重写数据」还是「换硬件」——重写数据可能一分钱不花就修好一台电视。

## 5 公式解析：遥控编码与 38kHz 调制

遥控系统的频率关系很简单但很关键：

$$
f_{\text{载波}} = 38\,\mathrm{kHz}, \qquad T = \frac{1}{f} \approx 26\,\mu s
