# 起重吊装作业（起重工与起重机械操作）

起重吊装作业是建筑、港口、物流、制造业通用的特种作业工种，涵盖起重指挥、司索挂钩、吊装方案编制与塔式/桥式/流动式起重机械操作，属必须持证上岗的特种设备作业人员职业通道。以《国家职业技能标准—起重工》、TSG Z6001《特种设备作业人员考核规则》和《起重吊装作业安全技术》为纲，从法规资质、吊装基础知识到指挥司索、机械操作与安全管理，系统写完整门持证技能。
