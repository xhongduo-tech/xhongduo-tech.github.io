# 田径运动

田径运动是以走、跑、跳跃、投掷为基本运动形式，由速度、力量、耐力、柔韧与协调能力共同决定的"运动之母"，也是世界田联统一规则下的竞技项目体系与大众健身基础。以《田径运动教程》、世界田联《竞赛规则》与中国田径协会教练员培训体系为纲，系统重建从项目认知、技术原理到走跑跳投六大类专项技术、竞赛规则与教练员认证的完整知识链条。学完这些章节，就写完了田径运动入门与教练员培养的全部核心内容。
