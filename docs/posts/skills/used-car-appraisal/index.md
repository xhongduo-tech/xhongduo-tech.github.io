# 二手车鉴定与评估

二手车鉴定与评估是依据国家标准对二手车技术状况、事故损伤与特殊车况进行法定鉴定，并对其市场价值作出合理评估的职业活动。本专题对标《鉴定估价师国家职业技能标准》、GB/T 30323-2013《二手车鉴定评估技术规范》与商务部《二手车流通管理办法》，按学科内在逻辑从行业制度框架、静态与动态鉴定技术到评估作价与执业实务，系统建立二手车鉴定评估的完整能力。
