## 为什么从基础图案开始

上一课我们建立了拉花的两段式框架：先高后低、先融合后作画。这一课把它落到两个**必须会**的基础图案——**心形（heart）**与**郁金香（tulip）**。<span class="marginnote">心形与郁金香是全世界拉花教学的「第一课」：心形练「单一注入 + 收尾」，郁金香练「分次注入 + 叠层」。两个图案覆盖了拉花的两大核心动作——会了它们，进阶图案只是「更多次重复」的组合。</span>

本课以「动作分解 + 常见错误」的方式讲透这两个图案。请一边读，一边想象奶缸在手里的动作。

## 1 心形：单一注入 + 收尾

**心形（heart）**是入门第一图，因为它只需要一个连续动作：**低角度注入一个「白点」，在液面快满时把白点向前推进，最后高收切断**。

**步骤分解**：

1. **融合**：高角度细水流，把奶液与浓缩融合到约七分满。
2. **起白点**：压低奶缸，贴近液面，在杯心持续注入，让奶泡浮起、形成一个白色圆点。
3. **推进**：保持低角度、稳定流速，让白点随奶量增长逐渐向前（向杯柄方向）扩散。
4. **收尾**：当白点扩到想要的「心形」大小，**迅速抬缸 + 收水**，奶泡被「切」断，白点被推出一条竖线，形成心形的「尖」。

**关键原理**：心形的「上圆下尖」完全由**收尾动作**创造——**收尾时奶泡从中心被推出，形成心尖**。收尾越利落，心形越标准。

**易错点：** 新手最常见的失败是「收尾前白点已经散开」——因为**注水太久、奶量太多**，白点失去支撑。**心形的秘诀是「白点要小、收尾要快」**，宁可早收，不要晚收。

## 2 郁金香：分次注入 + 叠层

**郁金香（tulip）**是心形的进阶版，核心变成「**分次注入、叠出花瓣**」：

1. **融合**：同上，融合到约七分满。
2. **第一瓣**：低角度注入一个白点，推进成「圆」后**高收切断**——这是第一层花瓣。
3. **第二瓣**：再次低角度注入，把新的白点**顶进**第一层花瓣里，再高收切断——第二层。
4. **第三瓣**：重复，让花瓣从杯柄侧向杯口侧「叠」出去。
5. **收尾**：最后一瓣之后，沿中心线向杯口方向高收，拉出花茎。

**关键原理**：郁金香的「层层叠叠」来自**「注入—切断—再注入」的循环**——每一层都是新注入的白点「顶」着前一层向前。**层数越多、花瓣越多，图案越华丽**（三到四层最常见）。

**易错点：** 新手容易把每一瓣都做得太大，导致杯子装不下、花瓣挤成一团。**郁金香的诀窍是「每瓣都比前一瓣小一点」**——花瓣由近及远逐渐缩小，才有层次感。

## 3 核心对比表：心形与郁金香

| 维度 | 心形 | 郁金香 |
| --- | --- | --- |
| 注入方式 | 单次连续注入 | 分次「注入—切断」循环 |
| 核心动作 | 推进 + 收尾 | 叠层 + 收尾 |
| 难度 | 入门 | 初级进阶 |
| 失败主因 | 收尾太晚、白点散开 | 花瓣过大、层次糊掉 |
| 收尾要点 | 高收切出心尖 | 每瓣收一次，最后拉花茎 |

<span class="marginnote">把两个图案并排看，规律就浮出来了：<strong>心形是「一次注入」，郁金香是「三次注入」</strong>。心形练「一次到位」，郁金香练「分次控制」——它们正好覆盖了拉花的两类核心节奏。会了这两个，叶子和玫瑰就有了骨架。</span>

## 4 公式解析：注入次数与图案复杂度

拉花图案的复杂度，可以用一个朴素的「信息量」视角来理解。定义图案的**操作次数** $N$：

$$
N = \text{注入次数} + \text{收尾次数}
$$

- **心形**：$N = 1 + 1 = 2$。
- **郁金香（三层）**：$N = 3 + 1 = 4$。
- **叶子（下节课）**：注入 + 摆动，$N$ 更大。

拆解三步：

- **第一步，看定义**：注入次数是「白点起了几次」，收尾次数是「高收切了几次」。
- **第二步，理解规律**：**N 越大，需要的奶泡量越多、杯内容量越紧张、手部控制越精细**。所以练习路径天然从 N 小到 N 大——心形 → 郁金香 → 叶子。
- **第三步，落到训练**：**N 每增加 1，就要单独练「那一次注入」的准确度**。郁金香的每一瓣，本质上都是在重复心形的「起白点 + 收尾」，只是位置不同。**把心形练到肌肉记忆，郁金香就学了一半**。

**易错点：** 不要「跳级」。**叶子不是郁金香的「加大版」**，它引入「摆动」这个新动作（下节课讲），操作次数与难度陡增。**先把 N = 2 和 N = 4 练稳，再碰叶子**——这是拉花进阶最稳妥的顺序。

## 5 常见失败诊断

| 失败表现 | 归因 | 修正 |
| --- | --- | --- |
| 心形散成一片 | 白点太大 / 收尾太晚 | 小白点、早高收 |
| 心形没「尖」 | 收尾未沿中心推进 | 收尾时保持中心线 |
| 郁金香花瓣糊在一起 | 层与层间没「切断」 | 每瓣之间明确高收 |
| 花瓣大小不一 | 每次注入量不均 | 控制每次注入的奶量 |
| 图案偏在杯边 | 注水点没对准杯心 | 回到「对准杯心」 |

**易错点：** 诊断时要记得**先查奶泡**——**奶泡太稀，心形白点撑不住；奶泡太稠，郁金香瓣推不动**。图案失败别急着改手法，先确认奶泡纹理在第 16 课的「稠度刻度」上处于合适区间。

## 6 练习路径与自评标准

拉花练习最怕「闷头倒一百杯，却不知道好坏」。给心形与郁金香各设一组**自评标准**，倒完一杯先自己打分：

**心形自评三问**：① 心形是否**左右对称**？② 心尖是否**居中、清晰**？③ 整体是否**大小合适**（约占杯面 2/3）？三个「是」才算合格。

**郁金香自评三问**：① 花瓣是否**层次分明**（没糊在一起）？② 花瓣是否**由大到小、由近及远**排列？③ 花茎是否**居中、干净**？

**练习节奏建议**：

- **每次练习定一个「唯一目标」**——比如「这十杯只练收尾的利落度」，不要同时改十个问题。
- **一杯一记**：倒完立刻看一眼、记一句（如「心尖偏右」），再倒下一杯。**用「记录」逼出「观察」**，观察才是进步的前提。
- **同一参数固定**：奶泡稠度、杯子、奶量尽量保持一致，让变量只有「手法」——这正是前面反复强调的单变量原则。

<span class="marginnote">把「自评」做成清单，本质是把抽象的「好看」拆成可检查的<strong>「可判定的子目标」</strong>——这与第三级《软件工程》里的「验收标准」是同一思路：不可判定的目标无法被练习逼近。拉花训练需要的是「能打勾」的标准，而不是「感觉还行」。</span>

**易错点：** 练习时不要「追求完美的杯子」——**浪费材料与挫败感是拉花练习的最大敌人**。用水模拟奶泡（第 16 课提过）先把动作练熟，再上真奶；一次练 20–30 杯而不是「练到好看为止」，更容易保持手感稳定。

## 7 小结

- **心形**：单次注入 + 推进 + 高收，核心是「白点要小、收尾要快」，收尾切出心尖。
- **郁金香**：分次「注入—切断」叠层，核心是「每瓣都比前一瓣小」，最后沿中心高收拉花茎。
- 两个图案并排看：**心形是「一次注入」，郁金香是「三次注入」**；前者练一次到位，后者练分次控制。
- 复杂度 $N = \text{注入次数} + \text{收尾次数}$：**N 越大，所需奶泡越多、杯内空间越紧、控制越精细**——练习路径天然从 N 小到 N 大。
- 自评标准：心形看「对称、心尖清晰、大小合适」，郁金香看「层次分明、由大到小、花茎居中」；**倒完一杯先打分再倒下一杯**。
- 练习纪律：每次只定一个目标、一杯一记、参数固定——**把「好看」拆成可打勾的子目标，进步才可见**。
