# 咖啡技艺（咖啡师）

以詹姆斯·霍夫曼《世界咖啡地图》、SCA 精品咖啡协会认证体系与国家职业技能标准《咖啡师》为纲，系统建立从咖啡生豆认知、冲煮萃取原理、浓缩咖啡与拉花艺术到职业认证与门店运营的完整咖啡师能力链，学完即可覆盖从入门到专业咖啡师应具备的核心理论与实操技能。

## 对标教材

- 《世界咖啡地图》（詹姆斯·霍夫曼 著）
- SCA 精品咖啡协会认证体系（咖啡师技能、感官、萃取模块）
- 国家职业技能标准《咖啡师》
