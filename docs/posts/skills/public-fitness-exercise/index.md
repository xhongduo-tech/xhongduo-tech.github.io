# 大众健身与科学锻炼

以国家体育总局《全民健身指南》为纲，结合《国民体质测定标准》与《社会体育指导员国家职业技能标准》，系统重建从体质健康评估、力量/有氧/柔韧训练规划、不同人群运动处方到健身指导实践的完整科学锻炼体系。学完这些章节，就写完了大众健身与科学锻炼的全部内容。
