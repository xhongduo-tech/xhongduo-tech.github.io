# 浓香型白酒工艺与风味特点

## 为什么从浓香开始

如果说酱香是十二香型里最「复杂」的一支，那浓香就是最「普及」的一支——**全国白酒产量的七成左右是浓香型**。从国宴的五粮液、泸州老窖，到寻常百姓餐桌上的大众浓香，浓香的身影无处不在。

浓香型也称「泸香型」，因泸州老窖为最早定型代表而得名；后来五粮液影响力日增，行业更多用「浓香型」统称。<span class="marginnote">它与酱香、清香并称三大主流香型，市场盘子最大。上一节的酱香我们用「时间」做主线，这一节的主线是「窖池」——一口泥窖决定了浓香的半部历史。</span>

上一节我们领略了酱香「用时间换香气」的极端；这一节要看的，是浓香「用窖池养微生物」的另一种极致。**决定浓香命运的，不是时间，而是一口泥窖。**

## 1 浓香型家族与风格画像

**浓香型白酒**：以四川五粮液、泸州老窖、剑南春、沱牌，江苏洋河，安徽古井贡酒等为代表，以高粱为主要原料、小麦中温大曲为糖化发酵剂、泥窖固态发酵续糟配料，具有窖香浓郁风格的白酒。

浓香的标准风格画像，可以用四句话概括：

**窖香浓郁，绵甜甘冽，香味谐调，尾净余长。**<span class="marginnote">「甘冽」是浓香味的点睛之笔：甜味要有「冽」（清爽利落）托底，甜而不腻。相比酱香的「醇厚回味」，浓香更强调「绵甜顺口、一喝到底」的愉悦感——这也是它受众最广的原因。</span>

逐句拆开看：

**窖香浓郁**：以己酸乙酯为主体的酯香扑面而来，香气奔放。
**绵甜甘冽**：入口绵柔、甜味清爽不腻。
**香味谐调**：窖香、粮香、曲香、陈香比例得当，不冲不散。
- **尾净余长**：落口干净，余味悠长不带杂味。

浓香型的「窖香」来自窖池与窖泥：窖泥微生物在长期发酵中代谢出以**己酸乙酯**为主体的酯类香气，这种「老窖特有的复合香」被称作窖香。<span class="marginnote">己酸乙酯是浓香的「身份证」：品评时闻一口，若有明显的果香般甜酯香，第一反应就应是「浓香」。清香主打乙酸乙酯（更轻盈）、酱香无单一主体，三者一闻可辨。</span>

## 2 泥窖与老窖：浓香风味的「地基」

浓香与酱香、清香最醒目的工艺分野，是**发酵容器**。

酱香用条石窖。
清香用地缸。
浓香则用**泥窖**——窖壁与窖底抹上厚厚的窖泥，酒醅直接在泥窖中发酵。

为什么「泥」这么重要？因为**窖泥是微生物的「家」**。发酵过程中，窖泥中的**己酸菌、丁酸梭菌等厌氧细菌**持续代谢，把糟醅里的乙醇与有机酸转化为己酸、丁酸，再进一步酯化为己酸乙酯、丁酸乙酯等香气成分。

**泥窖的窖泥越老，其中的有益微生物群落越丰富、越稳定，产香越足**——这就是「酒好全凭窖池老」的科学内涵。<span class="marginnote">泸州老窖拥有始建于明代万历元年（1573 年）的「国宝窖池群」，连续使用四百多年从未间断——窖泥中的微生物早已形成「活化石」级的生态。这类老窖是不可再生资源，也是浓香名酒最深的护城河。</span>

**辨析｜易错点：**「老窖」不是把泥巴放旧就有用。窖泥中的功能菌是经过数十年、上百年持续发酵「驯化」累积的；新建窖池即使故意抹上老窖泥，微生物群落密度与结构也远不如连续使用的老窖。消费者面对「百年老窖」的宣传，应以窖池的**连续使用历史**为据。

## 3 续糟配料与混蒸混烧：循环的智慧

浓香工艺的第二大特征是**续糟配料（续渣法）**。与清香「清蒸二次清」——蒸完一次清一次、粮醅用完即弃——不同，浓香的糟醅是**循环使用**的。

每轮蒸酒之后，酒醅并不废弃，而是取出部分，重新加入新粮与曲粉，再入窖发酵。如此周而复始，窖内始终保留着上一轮的「母糟」。行话说「**千年老窖万年糟**」——糟醅代代相传，每一轮都从上一轮那里继承微量的酸、酯与微生物代谢物，风味越积越厚。<span class="marginnote">续糟配料的本质是「用时间做复利」：单轮发酵只有几十天，但母糟携带的历史风味累积让成品远超「几十天的发酵结果」。这与酱香用「一次完整的一年周期」堆风味，是两条完全不同的时间策略。</span>

**混蒸混烧**则是与续糟配套的蒸馏方式：把新粮、母糟与曲粉拌匀后上甑，蒸煮糊化与蒸酒提香**在同一口甑里同时完成**——先蒸出酒，再让粮食蒸透。如此粮食在蒸煮时便吸收了糟醅的香气，酒醅在蒸馏时也带出新粮的清新，彼此「交换信息」。

## 4 中温大曲、发酵周期与多粮配方

浓香用**小麦制的中温大曲**，制曲品温 50–60℃，介于酱香高温曲与清香低温曲之间。中温曲兼顾出酒率与香气，微生物以霉菌、酵母为主，酯化能力强。

**发酵周期**一般 60–90 天，明显长于清香的 28 天、短于酱香的一年。部分名酒厂还使用**双轮底工艺**：把窖底那部分糟醅连续发酵两轮（120–180 天以上），让窖底微生物充分作用，所产「双轮底酒」酯香特别浓郁，常被用作勾调的调味酒。

**多粮配方**是浓香的重要变量。五粮液以五种粮食按传统比例配比——高粱、大米、糯米、小麦、玉米，业界常记作「高粱 36、大米 22、糯米 18、小麦 16、玉米 8」。每种粮食贡献不同的风味骨架：

高粱出香。
大米出净。
糯米出绵。
- 小麦出曲香。
- 玉米出甜。

**辨析｜易错点：**单粮浓香（如泸州老窖以高粱为主）与多粮浓香（如五粮液五粮并用）由此分出「浓净」与「丰满」两种气质——单粮更纯净挺拔，多粮更丰满协调，没有高下之分，只是风格取向不同。<span class="marginnote">这也是下一节流派分野的原料根基：川派多粮（五粮液）偏丰满，江淮派偏单粮、绵柔。</span>

## 5 浓香酒的品评要点

浓香是三大主流里**最容易入门、也最容易误判**的香型，品评抓住三个要点：

**闻香看「放香」**。浓香的香气释放快、冲鼻感强，俗称「喷香」。杯口初闻即有明显的酯香扑面，这与酱香的「幽雅内敛」、清香的「轻盈纯净」形成鲜明对比。放香的强弱与快慢，是判断浓香基酒质量与年份的窗口。

**品味看「绵净」**。入口绵甜是浓香的招牌，但真正的名优浓香是**甜而不腻、净而不寡**——甜感来得快、去得净，落口爽利。若甜得发闷、黏喉，往往是糖分或酯类失衡的次酒。

**空杯看「留香」**。浓香的空杯留香不如酱香持久，但优质浓香空杯仍有明显的粮香与陈香残留；劣质浓香空杯要么无香，要么只剩酒精味。<span class="marginnote">三种主流香型空杯一对比，层次立现：酱香留香最久（数小时），浓香次之（约一小时），清香最短——这个梯度是盲评时判断香型等级的快速依据。</span>

**辨析｜易错点：**38 度、42 度等低度浓香并不等于「掺了水」。低度浓香是高度基酒经**降度、过滤、吸附**等工序处理而成，工艺得当同样绵甜谐调；但降度会损失部分酯香与口感，所以同一品牌通常「高度更值钱」。

## 6 核心对比：川派浓香与江淮派浓香

浓香内部流派林立，最经典的是**川派**与**江淮派**之分。本主题是概念型内容，无核心公式，用一张表代替公式解析，把两大流派的差异钉清：

| 对比项 | 川派浓香 | 江淮派浓香 |
| --- | --- | --- |
| 代表 | 五粮液、泸州老窖、剑南春 | 洋河、古井贡酒、双沟、今世缘 |
| 原料 | 多粮为主（五粮等） | 单粮或多粮，配比趋简 |
| 窖池 | 老窖泥，窖龄深 | 窖龄相对较短，注重窖泥养护 |
| 发酵 | 跑窖法或原窖法 | 工艺相对温和，周期略短 |
| 风格 | 窖香浓郁、喷香强烈 | 绵柔淡雅、甜净顺口 |
| 代表词 | 浓、喷、爽 | 绵、柔、净 |

**辨析｜易错点：**不要以为「浓香都一个味」。川派浓香入口「喷香」扑面、窖香霸道；江淮派浓香以洋河「绵柔型」为代表，香气内敛、口感顺滑——**同是浓香，一个像川剧高腔，一个像评弹慢板**。<span class="marginnote">此外还有「跑窖法」与「原窖法」的工艺流派：跑窖法（五粮液）让窖池轮换使用、糟醅串窖，取酒更丰；原窖法（泸州老窖）固定每口窖的糟醅，风格更稳定统一。两者都是川派浓香的正宗。</span>

品评训练中，用一瓶五粮液与一瓶洋河梦之蓝做「同香型辨流派」对照，是进入中级品酒师的门槛练习。

## 7 小结

- 浓香型是**市场占有率最高**的香型，代表为五粮液、泸州老窖、剑南春、洋河、古井贡酒等。
- 风格画像：**窖香浓郁、绵甜甘冽、香味谐调、尾净余长**。
- **泥窖**是浓香的「地基」：窖泥中的己酸菌等微生物代谢生成**己酸乙酯**——浓香的主体香气成分；窖池越老，微生物群落越丰富，酒越好。
- **续糟配料**让母糟代代相传，风味「复利」累积；**混蒸混烧**让粮香与糟香在同一甑中交换。
- 工艺参数：小麦中温大曲（50–60℃）、发酵周期 60–90 天（双轮底更长）、五粮或多粮配方、成品常为 52%vol。
- 流派分野：**川派**（浓、喷、爽）与**江淮派**（绵、柔、净），工艺上还有跑窖法与原窖法之分。
- 品评要点：闻香看「放香」，品味看「绵净」，空杯看「留香」；低度浓香不是「掺水」，而是降度工艺的产物。
- 单粮（泸州老窖）与多粮（五粮液）浓香各有所长，无高下之分，只有风格取向之别。

对比酱香再看浓香，两条产香路径的对照已经清晰：酱香用「长周期堆时间」，浓香用「老窖泥养微生物 + 续糟循环」——一个贵在复杂，一个贵在普适。在下一节，我们转向十二香型里最「干净」的一支——**清香型**。同样是三大主流，清香却用最简的工艺、最短的周期，讲一个「一清到底」的故事。
