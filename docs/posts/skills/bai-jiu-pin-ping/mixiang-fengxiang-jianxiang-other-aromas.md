## 为什么从三大主流之外开始

前面三节把浓、清、酱三大主流香型讲透了——但十二香型的版图，三大主流只占了三席。剩下九种香型虽然市场体量远不如三巨头，却**各占一方水土、各有一批忠实的舌头**：桂林人的米香、陕西人的凤香、广东人的豉香、江西人的特香……它们共同构成了中国白酒「一香一世界」的丰富肌理。

对品酒师而言，这九种香型是「必须认得、不必天天喝」的存在——中级品酒师要求能辨认全部十二香型，这一节就是那块「拼图」。<span class="marginnote">本专题第 3 篇会把「全香型识别」写进中级品酒师的职业功能。这里先把九种香型「认个脸」，后面讲职业标准时就能对上号。</span>

## 1 米香型：南方小曲的蜜香

**米香型白酒**：以广西桂林三花酒为代表，以大米为原料、小曲为糖化发酵剂，经半固态发酵、液态蒸馏而成的白酒。

米香型的风格画像：

**蜜香清雅，入口绵柔，落口爽净，回味怡畅。**<span class="marginnote">「蜜香」是米香最传神的词：以乳酸乙酯与 β-苯乙醇为主体香，后者带来类似玫瑰、蜂蜜的优雅花香。米香是最接近「甜酒」气质的主流香型，绵柔顺口，适合初次接触白酒的人。</span>

米香的工艺关键词是「小曲、大米、半固态」：

**大米原料**：米香不用高粱，只用大米——酒体因此清亮、甜净。
**小曲**：以米粉（或米糠）为曲料，接种根霉与酵母，用量小、糖化发酵快。
**半固态发酵**：先固态培菌糖化，再加水进行液态发酵，是米香的特色工艺。
- **液态蒸馏**：发酵醪液直接蒸馏取酒，酒体纯净。

桂林三花酒的名字也暗含工艺：据说「蒸煮三次、酒花三起三落」，故称「三花」。米香型是我国南方小曲酒的代表，广西、广东、湖南一带分布广泛。

## 2 凤香型：酒海里的过渡香

**凤香型白酒**：以陕西西凤酒为代表，风格介于浓香与清香之间，自成一格。

凤香型的风格画像：

**醇香秀雅，甘润挺爽，诸味谐调，尾净悠长。**<span class="marginnote">「挺爽」二字是凤香的题眼：香气挺立、口感爽利，不似浓香缠绵、不似清香单薄。凤香常被形容为「浓而不艳、清而不淡」，是两种主流风格之间的「第三条路」。</span>

凤香两个最独特的工艺符号：

**新窖泥窖**：凤香也用泥窖，但刻意**不用老窖泥**，而是每年更新窖泥。因为老窖泥会带来浓香型的窖泥味——凤香要的是「干净的窖香」，而非浓香的「老窖香」。这恰恰与浓香「越老越好」的理念相反。<span class="marginnote">浓香求「老窖」，凤香求「新窖」——同一容器，理念相反。这是品评凤香时理解其「既不浓又不清」的关键。</span>
**酒海贮存**：西凤酒用「酒海」存酒。酒海是荆条（或柳条）编成的巨型酒篓，内壁用猪血、石灰调成涂料，再糊以桑皮纸、白布，多层涂抹而成。酒海容量大（有的可容数吨）、透气不透液，在漫长的贮存中赋予酒体独特的「酒海味」——一种淡淡的、近似竹木与海盐的气息。<span class="marginnote">酒海是凤香型「地域风味」的最重要来源之一，类似酱香依赖赤水河微生物。西凤酒的酒海工艺已被列入国家级非物质文化遗产名录。</span>

凤香的香气构成也印证了它的「过渡」身份：**以乙酸乙酯为主、己酸乙酯为辅**，两种酯的比值介于清香与浓香之间——清香乙酸乙酯独大，浓香己酸乙酯独大，凤香则是「两者相安」。

## 3 兼香型：浓与酱的调和

**兼香型白酒**：以湖北白云边、安徽口子窖为代表，兼具浓香与酱香（或清香）风格的香型。

「兼香」的核心是**调和**：不追求单一香型的纯粹，而追求多种风格在一杯酒里和谐共处。兼香内部又分两支：

**酱浓兼**：以白云边为代表，酱香为主、浓香为辅，风味丰满厚重，香气层次递进。
**浓酱兼**：以口子窖为代表，浓香为主、酱香点缀，再以芝麻香提味，绵甜爽净。<span class="marginnote">同为兼香，一支偏「酱」、一支偏「浓」——盲评时靠「谁主谁次」即可分辨。口子窖的「浓酱芝三位一体」在兼香里独树一帜。</span>

**辨析｜易错点：**「兼香」不等于「勾兑拼凑」。好的兼香是把两种风格的工艺**有机融合**——比如在发酵、蒸馏环节就让浓、酱的微生物与工艺互相渗透，而非简单地把两种基酒兑在一起。前者是「熔」，后者是「拼」，品评高下立判。

## 4 五种特色香型速览

除了米、凤、兼，还有五种香型各具鲜明个性，用一张表代替公式解析快速认识：

| 香型 | 代表酒 | 工艺关键词 | 风味关键词 |
| --- | --- | --- | --- |
| 芝麻香型 | 山东景芝 | 高温堆积、细菌代谢 | 芝麻香幽雅、醇和绵柔 |
| 豉香型 | 广东石湾玉冰烧 | 小曲大米、肥肉浸泡 | 豉香独特、醇和甘滑 |
| 特香型 | 江西四特酒 | 大米原料、红褚条石窖 | 幽雅舒适、柔绵醇和 |
| 老白干香型 | 河北衡水老白干 | 地缸发酵、高度 | 醇香清雅、甘冽丰柔 |
| 馥郁香型 | 湖南酒鬼酒 | 大小曲并用、多粮 | 前浓中清后酱 |

逐个点出记忆锚点：

**芝麻香型**：芝麻香与芝麻无关——是枯草芽孢杆菌等细菌在高温堆积发酵中产生的呋喃、吡嗪与含硫化合物，共同呈现烘炒芝麻的联想。<span class="marginnote">「香型名是象形不是配方」：芝麻香不加芝麻、豉香不加豆豉——记住这一点，能少闹很多「原料误会」。</span>
**豉香型**：小曲大米发酵后，酒液注入**肥猪肉**坛中浸泡陈化数月——脂肪缓慢氧化溶解，生成油酸乙酯等物质，带来独特的「油豉香」。玉冰烧之名，源自浸泡后酒液晶莹如冰、清亮如玉。
**特香型**：江西四特酒以大米为料、**红褚条石窖**发酵，香气介于浓、酱、米之间，号称「一口三香」。
**老白干香型**：衡水老白干以地缸发酵、**高酒度**著称（常见 67%vol），「老白干」三字即「历史悠久、酒体纯净、干爽不甜腻」。
- **馥郁香型**：湖南酒鬼酒独创「前浓、中清、后酱」——入口是浓香的绵甜，中段是清香的爽净，回味是酱香的醇厚，一口喝完三种体验。

## 5 董香型：百草入曲的孤例

**董香型（药香型）白酒**：以贵州董酒为代表，因在制曲中添加上百种本草而得名，是十二香型里最「特立独行」的一支。

董酒的工艺核心是**大小曲并用、百草入曲**：

- **大曲**：用小麦加大曲所需本草制成，用于窖内发酵产香。
- **小曲**：用大米加小曲所需本草制成，用于糖化发酵。
- 两曲相加，本草多达**一百三十余味**——既有增香的，也有抑菌、调和的，形成董酒独有的「药香」。

董香型的风格画像：

**药香舒适，香气典雅，酸味适中，香味谐调。**<span class="marginnote">董香的「药香」不是中药汤味，而是本草参与发酵后形成的复合香——草本香、陈香、酯香交融，酸度在十二香型里偏高，是它「去腻开胃」的口感来源。</span>

董酒的历史也颇具传奇：它曾三度入选中国名酒，其配方与工艺长期保密，被称作中国白酒的「活化石」之一。因工艺复杂、产量有限，董香型在全国分布极窄，几乎是「一瓶酒撑起一个香型」。

## 6 次要香型的识别要点

这些香型市场见得不那么多，品评时更需要「锚点」记忆——每种香型抓一个最特征的气味，就够完成辨认：

| 香型 | 识别锚点 |
| --- | --- |
| 米香 | 玫瑰蜜糖般的 β-苯乙醇花香 |
| 凤香 | 淡淡的酒海「竹木海盐」气息 |
| 兼香 | 判断浓、酱谁主谁次 |
| 芝麻香 | 烘炒芝麻的焦香联想 |
| 豉香 | 肥肉浸泡的油豉味 |
| 特香 | 「一口三香」的复合跳跃感 |
| 老白干香 | 高酒度下的清冽刚劲 |
| 馥郁香 | 入口、中段、回味的三段变化 |
| 董香 | 药草与酸感的独特组合 |

**训练建议**：集齐九种香型的代表酒各一瓶，用「闻香 → 写出锚点 → 对照标签」的方式盲练。每种香型只需建立一两个「气味锚点」，识别准确率就能大幅提升——这也是中级品酒师「全香型识别」考核的核心训练法。<span class="marginnote">市面上有专门的「白酒标准闻香样」套装（含各香型特征单体香精），比买整瓶酒更便宜、更适合反复闻嗅训练。本专题第 2 篇《感官品评的生理学基础》会解释为什么「气味锚点」能被大脑牢固编码。</span>

## 7 小结

- 三大主流之外的九种香型**各占一方水土**：米香看广西、凤香看陕西、豉香看广东、特香看江西、老白干看河北、馥郁看湖南。
- **米香型**以小曲、大米、半固态发酵见长，主体香为 β-苯乙醇与乳酸乙酯，蜜香清雅。
- **凤香型**介于浓清之间，靠「新窖泥窖 + 酒海贮存」自成一格，主体香乙酸乙酯为主、己酸乙酯为辅。
- **兼香型**以白云边、口子窖为代表，是浓酱（或浓清）工艺的「熔合」而非「拼凑」。
- 芝麻、豉、特、老白干、馥郁五种香型各有记忆锚点：芝麻香不靠芝麻、豉香靠肥肉浸泡、特香「一口三香」、老白干以高度著称、馥郁「前浓中清后酱」。
- **董香型**是百草入曲的孤例，大小曲并用、一百三十余味本草，药香舒适，全国分布极窄。

至此，十二香型全部认识完毕。在下一节，我们把视线从「香型」转向「成因」——**原料、曲药与发酵贮存如何共同塑造酒体**，打通从工艺参数到风味结果的因果链。
