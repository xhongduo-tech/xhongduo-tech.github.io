## 为什么从评语开始

上一节我们讲了四要素「评什么」，这一节要回答「怎么把评价写下来」——也就是**评语**。品酒师的工作产出，最终是一段评语：它要被酒厂的技术员、质检员、勾调师、同行品酒师读懂并采信。

所以评语不是「写作文」，而是一门**受控语言**：用词有标准、结构有套路、表达有边界。「好喝」「不错」「真香」这类日常表达，在评语里是**禁用**的——因为每个人对「好喝」的理解不同，评语必须靠行业统一的术语来传递「无歧义的信息」。<span class="marginnote">本专题对标教材《中国白酒品评》第11章即专门规范评语与术语。术语体系的建立，让白酒品评从「个人经验」升级为「行业语言」——这是品酒师职业化的基石，也是本专题第 3 篇《品酒师职业标准》考核评语能力的依据。</span>

## 1 评语的结构：四段式

专业评语采用**四段式**，顺序固定：

**色泽 → 香气 → 口味 → 风格。**

一段标准评语长这样：

> 无色透明，无悬浮物，无沉淀；清香纯正，香气谐调；绵甜爽净，回味悠长；具有本品风格。

拆开看，四段各司其职：

**色段**：透亮度、色泽、有无异物——三五个词即可。
**香段**：香型特征 + 香气质量（纯、谐、强、长）。
- **味段**：滋味 + 口感 + 余味——评语里信息量最大的一段。
- **格段**：风格典型性结论，通常一句话收口。<span class="marginnote">四段之间用分号或句号分隔，各段独立成组、互不掺混。这段结构不是惯例，而是约定——考试阅卷、同行交流都按此结构解析，段序错乱会被视为「评语不规范」。</span>

**辨析｜易错点：**评语不是越长越好，而是**信息密度**越高越好。能用一个准确的术语说清，就不要用三个模糊的词绕圈子；同时也不能漏段——漏了「色」或「格」，评语就不完整。

## 2 色泽与香气术语

**色泽术语**相对简单，常用的是：

无色透明——新酒、清香、米香的常见形态。
微黄透明——陈年酱香、浓香老酒的特征。
- 清亮透明——强调亮度。
- 失光——透明度下降、光泽暗淡，是缺陷。
- 有悬浮物、有沉淀——明确缺陷。

**香气术语**是最丰富的术语家族，按用途分三类：

描述**香型特征**的：酱香突出、窖香浓郁、清香纯正、蜜香清雅、醇香秀雅（凤香）、浓酱谐调（兼香）。

描述**香气质量**的：

- 喷香——香气喷放、冲鼻感强，浓香多用。
- 溢香——杯口香气四溢。
- 陈香——老熟后的醇厚香气，多用于老酒。
- 曲香——曲药带来的香气。
- 糟香——糟醅发酵的香气，正常则为底香，过重则成缺陷。
- 香气暴——香得过分、失去谐调，负面。
- 香气粗——香气不细腻，负面。<span class="marginnote">同一个「香」字，术语的褒贬清晰分层：喷香、溢香是褒义或中性，香气暴、香气粗是贬义。评语用词必须「站队明确」，不许含糊其辞。</span>

## 3 口味与风格术语

**口味术语**分三组。

**滋味组**（味觉）：

绵甜——绵柔的甜感，浓香好评语。
醇甜——醇和的甜。
- 回甜——咽后返上来的甜。
- 酸——适量是骨架，过重是缺陷。
- 苦、涩、辣——多为负面，但微量可平衡风味。

**口感组**（触觉）：

- 绵柔——柔和绵长。
- 醇厚——酒体丰满有厚度。
- 爽净——清爽干净。
- 丰满——酒体充实。
- 单薄、糙——负面描述。

**余味组**（后味）：

- 回味悠长——后味持久。
- 余味爽净——后味干净利落。
- 后味短——后味不足，负面。
- 尾净——结尾干净。

**风格术语**相对固定，是一句话的「判决」：

- 风格典型、风格突出——最高评价。
- 具有本品风格——合格线。
- 风格一般、典型性差——负面结论。<span class="marginnote">风格术语的本质是「符合度判断」：评语最后一句是在回答「这酒像不像它的名字」。考核中，风格段写错方向（比如把浓香评成酱香风格）属于硬伤。</span>

## 4 术语使用规范与常见错误

评语术语有三个铁律：**客观、准确、规范**。对应的常见错误也最典型：

**主观化**：写「好喝」「难喝」「真棒」——这是个人偏好，不是行业信息。评语描述事实（什么香、什么味），不做个人价值宣判。
**模糊化**：写「还行」「不错」「一般般」——信息量为零。评语要求给出可比较的具体描述。
- **臆断化**：写「这酒有故事」「入口很江湖」——文学修辞不属于评语。评语是技术文档，不是散文。<span class="marginnote">一个判断标准：把评语交给另一位品酒师，如果他能凭这段文字在盲评中认出这杯酒，就是好评语；如果读完还是一头雾水，就是失败评语。</span>

**辨析｜易错点：**「用高级词显得专业」是新手常犯的错。术语的价值在于**精确**，不在于**生僻**。把「绵甜」写成「甘冽绵长」未必更专业，反而可能失真；与其堆砌，不如老老实实把每一段写准。

## 5 核心对比：评语常用术语速查表

本主题是概念型内容，无核心公式，用一张速查表代替公式解析，把四大段的常用术语与含义钉清：

| 评语段 | 常用术语 | 含义 |
| --- | --- | --- |
| 色泽 | 无色透明 / 微黄透明 / 失光 | 无杂透亮 / 陈年微黄 / 光泽暗淡（缺陷） |
| 香气 | 喷香 / 溢香 / 陈香 / 香气暴 | 香喷放 / 香四溢 / 老熟醇香 / 香过度（负面） |
| 口味 | 绵甜 / 醇厚 / 爽净 / 回味悠长 | 甜绵柔 / 酒体厚 / 清干净 / 后味久 |
| 风格 | 风格典型 / 具有本品风格 / 典型性差 | 高度符合 / 合格 / 不符合（负面） |

评语生成的完整流程随之固定：**四段结构 → 段内选准术语 → 整体通读检查**。先保证结构完整，再追求用词精准，最后通读一遍确认没有主观、模糊、臆断之词。

## 6 小结

- 评语是**四段式**：色泽 → 香气 → 口味 → 风格，段序固定、信息密度优先。
- 色泽术语少而清晰；香气术语最丰富，按**香型特征**与**香气质量**两类使用。
- 口味术语分**滋味、口感、余味**三组；风格术语是一句话的「符合度判决」。
- 术语三铁律：**客观、准确、规范**；禁用「好喝」「不错」等主观、模糊、臆断之词。
- 术语的价值在**精确**不在**生僻**；好评语的标准是「同行能凭它认出这杯酒」。
