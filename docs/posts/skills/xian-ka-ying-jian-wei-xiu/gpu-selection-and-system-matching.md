## 为什么从选购开始

前五篇把显卡的「身体构造」讲透了：芯片、显存、PCIe、供电。这一篇把它们拧成一次**决策**——花多少钱、买哪张卡、配什么电源、装不装得进机箱。选购不是「越贵越好」，而是「需求 × 预算 × 整机约束」三者的交集。<span class="marginnote">本站很多专题都会在「学完原理」后接一篇「落地决策」：原理给你判断力，决策帮你把判断力换成真金白银。这张卡的选购逻辑，与第二级《概率论》里「期望收益」的思维一脉相承——先算清楚自己的需求分布，再下单。</span>本篇是纯决策主题，我们用**核心决策对比表**代替公式解析来收束要点。

## 1 先问需求：显示器决定档位

选购的第一步不是看显卡，而是看你的**显示器与用途**。分辨率、刷新率、用途三件事决定需要多强的卡：

**1080p 60Hz**：中低端卡足够（如 RTX 4060 级别），预算重点放在稳定与静音。
**1080p 144Hz+ / 1440p 60Hz**：中端主力（RTX 4060 Ti / 4070 级别），追求高帧率的甜点区。
- **1440p 144Hz+ / 4K 60Hz**：高端（RTX 4070 Ti Super / 4080 级别），高分辨率对显存容量与带宽都敏感。
- **4K 高刷 / 光追全开**：旗舰（4080 Super / 4090 级别），此时**显存带宽与容量**的权重高于核心数。
- **AI 推理 / 视频剪辑**：优先看**显存容量**与 CUDA/编解码器生态，而不是游戏帧率。

<strong>选购第一定律：先定显示器，再定显卡。</strong>给 4K 屏配低端卡，钱花不出去；给 1080p 屏配旗舰卡，一半性能永远睡大觉。<span class="marginnote">「瓶颈」思想在这里第一次登场：整机性能由最弱一环决定。CPU 太弱时，显卡帧率上不去；显示器太低时，显卡高帧率无处发挥。这条「短板定律」与第三级《计算机体系结构》的 Amdahl 定律是同一思想的两个侧面。</span>

## 2 认型号：品牌、系列与后缀

主流三家——NVIDIA、AMD、Intel——的型号都有命名规律，学会拆名字就拿到了选购地图。

**NVIDIA GeForce**：前缀数字越大代际越新，如 RTX 40 系；第三位区分定位，**80/90 高端、70 中高端、60 主流、50 入门**；后缀 Ti/Super 表示同芯片加强版。**NVENC** 编码器对直播与剪辑友好，是 NVIDIA 的生态卖点。

**AMD Radeon**：RX 7000 系类似分层，**7900 旗舰、7800/7700 中高、7600 主流**；同价位往往核心算力更高，但光追与生态（驱动、编码器、AI 软件兼容）是短板。<span class="marginnote">同价位 NV vs AMD 的选择题通常归结为：要生态与光追选 NVIDIA，要纯光栅性价比选 AMD。没有「绝对更好」，只有「更匹配需求」——这也呼应第二级《微观经济学》的预算约束下的效用最大化。</span>

**Intel Arc**：入门与中端价位搅局者，驱动仍在追赶，适合预算敏感、用途固定的用户。

## 3 避坑：参数与市场的陷阱

选购时的常见陷阱，逐条拆开：

**显存容量陷阱**：8G 与 12G 差价明显，但**容量≠速度**。先看位宽与带宽是否够你的分辨率，再看容量是否超需求。
**「同型号」不同散热**：同芯片的品牌卡，散热好的 boost 高、更安静——**看评测的温控与噪音，别只看价格最低**。
- **二手与矿卡**：长期满载挖矿的卡，**供电与显存老化严重**，花屏、黑屏概率高。二手卡要查「成色、跑分、温度、是否拆修」，显卡拆修痕迹是砍价与避雷的重要信号。
- **小卡/刀卡**：公版 PCB 精简版，散热与供电缩水，长期高负载易降频——**想要稳定别选刀卡**。<span class="marginnote">「矿卡避雷」与后文《芯片级维修典型案例》直接相关：矿卡最常见故障就是显存颗粒虚焊或过热老化——理解了显存通道与 BGA 工艺，你就知道为什么矿卡偏爱在某个显存位上报错。</span>

## 4 整机搭配：电源、机箱与 CPU

显卡不是孤岛，搭配三件事必须核对：

**电源瓦数**：用「显卡建议电源」反推：整机峰值功耗 ≈ CPU 峰值 + 显卡 TGP + 外设余量，再留 20%~30% 余量。**650W 带中端、850W 带高端**是常见起点；电源功率不足会导致关机重启、花屏。
**机箱长度与厚度**：旗舰卡长 300mm+、厚 3 槽，先量机箱显卡位，再量散热器高度是否顶侧板。
- **CPU 瓶颈**：低分辨率高帧率下，CPU 跟不上会导致 GPU 占用率上不去。判断方法：游戏中看 GPU 占用率，**长期 <90% 且 CPU 满载，就是瓶颈**。<span class="marginnote">搭配建议：1080p 高刷配中端 CPU + 中端卡，4K 配高端卡 + 够用的 CPU——分辨率越高，CPU 相对越不重要。这条经验法则在《显卡超频》一节还会以「GPU 占用率」的形式再次出场。</span>

## 5 核心决策对比表（本主题以表代式）

| 需求场景 | 建议档位 | 显存底线 | 注意点 |
| --- | --- | --- | --- |
| 1080p 网游 / 办公 | 入门~主流 | 8G | 静音与功耗优先 |
| 1080p 高刷 / 1440p 甜品 | 主流~中高端 | 8~12G | 位宽看 192 bit 起 |
| 1440p 高刷 / 4K 入门 | 高端 | 12~16G | 带宽与容量并重 |
| 4K 高刷 / 光追全开 | 旗舰 | 16G+ | 电源 850W 起、机箱尺寸 |
| AI 推理 / 视频剪辑 | 中高端+ | 16G 起 | 生态（CUDA/NVENC）优先 |

## 6 易错辨析与术语速查

选购时的三个决策误区：

**误区一：先定预算再定需求。** 正确顺序是「先定显示器与用途，再算预算」。给 1080p 屏配旗舰卡，多花的钱换不回体验；给 4K 屏配低端卡，帧率根本带不动——需求决定档位，预算只是约束。

**误区二：迷信「同型号 = 同性能」。** 同芯片的不同品牌卡，散热与供电缩水程度不同：散热差的 boost 低、噪音大。**看评测的满载温度与噪音分贝，别只看最低价**——差价往往就是散热与用料差价。<span class="marginnote">「同芯片不同性能」的根源在散热与功耗墙：散热好的卡能长期维持高 boost。这也解释了为什么「旗舰型号的入门品牌」往往不是好选择——芯片一样，散热跟不上。</span>

**误区三：为「大显存」多花钱。** 显存容量只要够用就行，多出来的容量在需求内用不上。先判断你的分辨率和纹理需求需要多少显存（1080p 主流 8G、1440p 12G 起），再决定要不要为 16G 加钱。

### 术语速查

| 术语 | 英文 | 一句话含义 |
| --- | --- | --- |
| 瓶颈 | Bottleneck | 限制整机性能的最弱一环 |
| GPU 占用率 | GPU Utilization | GPU 被利用的比例 |
| NVENC | NVIDIA Encoder | NVIDIA 硬件视频编码器 |
| 矿卡 | Mining Card | 长期满载挖矿的二手卡 |
| 刀卡 | Low Profile | 精简散热与供电的小卡 |
| 光追 | Ray Tracing | 光线追踪渲染技术 |
| 建议电源 | Recommended PSU | 厂商建议的整机电源瓦数 |

## 7 实操清单与自查

选购显卡前，把这份决策清单走一遍：

1. **定显示器**：写下分辨率与刷新率——这是选卡的起点。
2. **定用途**：游戏 / 剪辑 / AI 推理，不同用途权重不同。
3. **估需求档位**：按对照表圈出大致的性能档位。
4. **定显存底线**：按分辨率与纹理需求定容量与带宽底线。
5. **核品牌生态**：需要 CUDA/NVENC 选 NVIDIA，纯光栅性价比考虑 AMD。
6. **拆解型号**：读懂型号命名，别被营销后缀绕晕。
7. **比同型号散热**：看评测的满载温度与噪音，不是只看最低价。
8. **核电源**：用「建议电源」反推整机瓦数，留 20%~30% 余量。
9. **量机箱**：显卡长度、厚度、供电接口方向三件套核对。
10. **防矿防刀**：二手查成色/跑分/温度/拆修痕；拒绝刀卡缩水散热。
11. **确认瓶颈**：用 GPU 占用率确认瓶颈不在 CPU 或显示器。

### 快速自查表

| 维度 | 核对内容 | 常见坑 |
| --- | --- | --- |
| 需求 | 分辨率/用途 | 需求与预算倒置 |
| 显存 | 容量+带宽 | 只看容量不看带宽 |
| 散热 | 满载温度/噪音 | 同型号不同散热 |
| 电源 | 瓦数+接口 | 电源功率不足 |
| 机箱 | 长度/厚度 | 装不进去 |

一句话收尾：**「最好的显卡」不存在——存在的是「匹配你需求清单的那一张」**。

## 8 小结

- **先定显示器与用途，再定显卡档位**——需求驱动，不是预算驱动。
- 学会拆型号：**前缀定代际、数字定位、后缀定版本**；品牌取舍看生态与性价比。
- 避开三大陷阱：**容量≠带宽、同型号不同散热、矿卡/刀卡**。
- 整机搭配三核对：**电源瓦数、机箱尺寸、CPU 瓶颈**；GPU 占用率是判断瓶颈的仪表。
- 没有「最好的显卡」，只有「最匹配你需求清单的显卡」。
