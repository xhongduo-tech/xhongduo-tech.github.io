# 显卡硬件与维修

显卡是 PC 图形计算的核心硬件，选购搭配、散热改造、BIOS 与超频以及供电、显存、BGA 等芯片级维修，是玩家与维修从业者最常面对的实际需求。以 NVIDIA/AMD 官方技术资料为架构之纲、iFixit GPU 维修指南为动手之纲、《显卡维修与芯片级维修》为芯片级维修之纲，系统重建从显卡架构与选购、散热改造、BIOS 与超频到故障诊断、供电显存维修与 BGA 芯片级维修的完整技能体系。学完这些章节，就写完了显卡硬件与维修的全部内容。
