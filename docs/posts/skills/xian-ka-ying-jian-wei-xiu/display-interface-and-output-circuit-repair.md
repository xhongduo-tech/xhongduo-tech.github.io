## 为什么从显示接口开始

诊断思路里的「点不亮」，排查到供电与显存都正常后，还有最后一个嫌疑域：**输出**。GPU 把画面算好，只是完成了前半程；后半程要通过**显示引擎 → 输出电路 → 接口 → 线材 → 显示器**一路送出去，任何一环断了都是「无显示」。而输出域常被忽视——很多「显卡坏了」的卡，其实只是**接口损坏或保护器件击穿**，换个接口就能救活。<span class="marginnote">显示输出链路与通信原理同构：数据从源（GPU）经编码、传输、解码到宿（显示器），每一段都有协议（HDMI/DP）与物理层（差分信号、热插拔检测）。读过第六级《通信原理》的调制与信道概念，会更容易理解输出信号为何要用差分对。</span>

## 1 输出链路：从 GPU 到屏幕

显卡输出是一条完整链路：

$$
\text{GPU 显示引擎} \rightarrow \text{输出驱动电路} \rightarrow \text{接口（HDMI/DP）} \rightarrow \text{线材} \rightarrow \text{显示器}
$$

- **显示引擎**：GPU 内部把帧缓冲转成像素流，按接口协议打包。
- **输出驱动电路**：把信号整形、驱动、滤波，经**差分对**传输；同时负责**热插拔检测（HPD）**与 **DDC/EDID** 通道。
- **接口**：HDMI、DisplayPort 的物理插座与引脚。
- **保护器件**：ESD 防护、共模电感、串阻——**防止热插拔与静电击穿 GPU**，是输出域最容易「牺牲自己保护主芯片」的元件。<span class="marginnote">「接口先坏、GPU 无恙」不是巧合：厂商在接口与 GPU 之间专门放 ESD 保护器件，静电来了先击穿保护件。维修时「某接口无信号但 GPU 正常」的高频原因，就是保护器件击穿或接口虚焊——换掉保护件或补焊接口即可。</span>

## 2 HDMI 与 DisplayPort：两种主流协议

**HDMI（High-Definition Multimedia Interface）**：消费电子主流，音视频同传。引脚含 TMDS 数据对（或 HDMI 2.1 的 FRL 通道）、**HPD（热插拔检测）**与 **DDC（显示数据通道）**。

**DisplayPort（DP）**：PC 与高刷主力，更高的带宽与更灵活的多流（MST）。数据走 4 对高速差分线，含 **AUX 通道**（传 EDID 与链路训练）与 **HPD**。

两协议的公共诊断点：

**HPD 引脚**：显示器插上后给显卡高电平，通知「有显示器了」。**HPD 无信号 → 显卡以为没接显示器 → 输出关闭**。
**DDC/AUX**：显卡通过它读显示器的 **EDID**（显示器身份信息）。**EDID 读不到 → 显卡不知道显示器支持什么分辨率 → 无信号或分辨率错乱**。<span class="marginnote">「HPD 与 EDID」是接口无信号的两位主角：HPD 管「连接检测」，EDID 管「能力协商」。一根转接线若把 HPD/DDC 脚短路或虚接，画面就出不来——这也是为什么「换一根好线」常能解决接口问题。</span>

## 3 常见故障与检修

输出域故障按由外到内排查：

**线材与转接**：最便宜嫌疑——先换线、换接口、换显示器验证。**HDMI→DP 方向转接有兼容坑**，方向错了直接无信号。
**接口物理损坏**：针脚弯、插座开裂、金手指氧化——目测 + 用正常线材插拔测试。
- **保护器件击穿**：ESD 器件或串阻短路/断路——万用表量接口引脚到 GPU 之间的导通，异常则换保护件。<span class="marginnote">「接口量阻值」的基本动作：断电后量接口各数据脚对地阻值，与完好接口对比。数据脚阻值明显偏低（被保护件拉低）或开路（保护件断），就锁定了问题点。接口维修七成靠「对比测量」。</span>
- **输出芯片/滤波损坏**：驱动芯片或共模电感损坏，波形异常——示波器量差分信号（需显卡工作且接显示器）。
- **GPU 输出通道损坏**：一个接口无信号、其他接口正常 → 大概率接口电路问题；**所有接口全无信号** → 才怀疑 GPU 显示引擎或核心损坏。

## 4 公式解析：接口带宽与分辨率

判断「接口够不够推某个分辨率/刷新率」，用的是带宽账：

$$
\text{所需带宽} = \text{分辨率像素数} \times \text{刷新率} \times \text{每像素位数（含开销）}
$$

- **第一步，像素数**：4K = 3840 × 2160 ≈ 830 万像素。
- **第二步，刷新率**：144Hz。
- **第三步，计算**：830 万 × 144 × 约 20 bit（RGB+开销）≈ 24 Gbps。

对照：HDMI 2.0 只有 18 Gbps，**跑不动 4K144**；HDMI 2.1 达 48 Gbps、DP 1.4 达 32.4 Gbps，才够。所以「显示器 4K144，接老接口只有 4K60」不是显卡性能问题，而是**接口带宽不够**。<span class="marginnote">「接口带宽决定分辨率/刷新率上限」这条线，把第 1 篇的 PCIe 带宽、第 3 篇的显存带宽、这里的显示接口带宽串成了同一套「带宽三连」：每条通道都有它的吞吐上限，瓶颈在哪，性能就在哪打折。</span>

## 5 易错辨析与术语速查

输出域维修的三处易错点：

**误区一：接口无信号就怀疑 GPU。** 单接口无信号 → 大概率接口电路问题（保护器件击穿、接口虚焊）；**所有接口全无信号**才该怀疑 GPU 显示引擎。先用「换线、换接口、对比量阻值」把接口域排除干净。<span class="marginnote">「单接口 vs 全接口」的分诊把输出域搜索空间砍掉一半：单接口坏查接口电路，全接口坏才往上怀疑。这条二分法在案例篇的 HDMI 案例里实战过。</span>

**误区二：忽略 HPD 与 EDID。** 插上显示器无信号，先查 HPD（连接检测）与 DDC/AUX（EDID 读取）。一根转接线把 HPD/DDC 脚短路，画面就出不来——**换一根好线常能解决接口问题**，因为转接线的兼容坑多在信号脚上。

**误区三：用超规格转接方向。** HDMI→DP 与 DP→HDMI 方向有兼容差异，转接方向错了直接无信号。买转接线先确认「源与宿」的方向，别指望双向通用。

| 术语 | 英文 | 一句话含义 |

| HDMI | High-Definition Multimedia Interface | 消费电子显示接口 |
| DisplayPort | DP | PC 高刷显示接口 |
| HPD | Hot Plug Detect | 热插拔检测信号 |
| DDC | Display Data Channel | 显示器数据通道 |
| EDID | Extended Display Identification Data | 显示器身份信息 |

## 6 实操清单与自查

显示输出故障按这份清单从外到内排查：

1. **换线材**：换一根已知良好的线，先排除线材与转接。
2. **换接口**：换到另一个接口，判断是「单接口」还是「全接口」故障。
3. **换显示器**：把显示器接别的设备验证，排除显示器自身。
4. **查 HPD**：接显示器后量 HPD 脚电平，确认显卡「知道」有显示器。
5. **查 EDID**：显卡是否读到显示器 EDID——读不到则分辨率识别错乱。
6. **量接口阻值**：断电后量接口数据脚对地阻值，与正常接口对比。
7. **查保护件**：ESD 器件、串阻击穿/断路是单接口故障的高频原因。
8. **补焊接口**：接口虚焊用烙铁/热风补焊，是常见可修复项。
9. **量输出芯片**：示波器量差分信号，判断驱动/滤波是否正常。
10. **再上 GPU**：以上都正常仍无信号，才怀疑 GPU 显示引擎。

### 快速自查表

| 检查项 | 做法 | 判定标准 |
| --- | --- | --- |
| 线材 | 换线 | 故障消失则线坏 |
| 接口 | 换接口 | 单接口 vs 全接口 |
| HPD | 量电平 | 插入后有高电平 |
| EDID | 读显示器信息 | 能读出正确分辨率 |
| 保护件 | 量阻值对比 | 与正常口一致 |

一句话收尾：**输出域从线材量到芯片，每前进一步都要先排除更便宜的可能**。

## 7 小结

- 输出链路：**显示引擎 → 输出电路 → 接口 → 线材 → 显示器**，每一环都可能断。
- 两个协议主角：**HDMI（消费）与 DP（PC 高刷）**；公共诊断点是 **HPD（连接检测）与 DDC/EDID（能力协商）**。
- 排查由外到内：**线材 → 接口物理 → 保护器件 → 输出芯片 → GPU**；「单接口无信号」多半是接口电路问题。
- 保护器件是「牺牲自己保护 GPU」的前哨，静电先坏它们。
- 接口带宽决定分辨率上限：**4K144 需要 HDMI 2.1 / DP 1.4+**。
