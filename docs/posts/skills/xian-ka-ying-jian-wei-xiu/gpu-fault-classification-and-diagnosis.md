## 为什么从诊断思路开始

维修的第一步不是动烙铁，而是**回答「这卡到底坏在哪」**。同样的「花屏」，可能是显存虚焊、可能是核心损坏、也可能是驱动问题——修错方向，白拆一遍甚至越修越坏。这一节把显卡故障「分类」+「分诊」的完整思路立起来：现象怎么归类、故障域怎么判断、诊断顺序怎么定。<span class="marginnote">诊断思维贯穿整个技术生涯：医学叫「鉴别诊断」，软件叫「二分定位」，维修叫「分域排除」。它的核心都是<strong>把不确定的大问题，拆成确定的小判断</strong>——这与第二级《逻辑学》里的「命题二分」是同一结构。</span>

## 1 故障分类：先按现象，再按故障域

**现象（symptom）**是用户看到的表面症状，**故障域（fault domain）**是出问题的子系统。同一现象可能对应多个故障域，同一个故障域可能产生多种现象。

常见现象五类：

**点不亮（no display）**：开机无显示、风扇转不转各异。
**花屏（artifact）**：画面出现横线、色块、图案错乱。
- **掉驱动（driver crash）**：运行中黑屏一下、驱动重启，或「显卡已停止响应」。
- **温度高 / 风扇狂转**：满载温度破百、风扇全速仍压不住。
- **噪音 / 异响**：风扇轴承磨损、电感啸叫（线圈共振）。

对应到**故障域**，显卡可分成五大子系统：**供电、显存、核心、输出、散热**。<span class="marginnote">「现象→故障域」不是一一对应：花屏大概率是显存，但也可能核心损坏；点不亮可能是供电，也可能是输出电路。诊断的价值就在于<strong>用最小代价缩小候选域</strong>——先排软后硬、先外后内，正是为了少拆卡。</span>

## 2 诊断思路：四步走

一套可复用的诊断流程，按「由易到难、由软到硬、由外到内」排序：

**第一步，先软后硬**：先排除软件与外部因素——换驱动版本、换接口线、换显示器、查系统事件日志（是否有驱动崩溃记录）。**很多「显卡故障」其实是驱动或线材问题**，先软后硬能省掉大半拆卡。<span class="marginnote">「先软后硬」不是怕动手，而是成本控制：换一根 HDMI 线 5 分钟，拆卡检查 1 小时。维修的第一原则是<strong>以最低成本缩小故障域</strong>——软件、线材、接口、供电顺序排查，都排除才轮到芯片级。</span>

**第二步，替换法（swap test）**：把嫌疑卡换到另一台正常电脑，或把正常卡换到这台电脑——**一次替换，故障跟着谁走，故障域就锁定在哪边**。这是最有力的分诊工具。

**第三步，最小系统法**：只保留「主板 + CPU + 显卡 + 单条内存 + 电源」开机，排除外设、内存、硬盘的干扰。

**第四步，仪器实测**：万用表测供电电压、示波器看波形、显存测试软件定位颗粒——进入芯片级诊断（后文展开）。

## 3 现象→故障域映射表（本主题以表代式）

| 现象 | 首查故障域 | 次查故障域 | 快速验证手段 |
| --- | --- | --- | --- |
| 开机点不亮 | 供电 | 核心 / 显存 | 测 12V、量核心供电、换机测 |
| 花屏（规律图案） | 显存 | 核心 | 显存测试软件定位颗粒 |
| 花屏（随机噪点） | 核心 | 显存 | 换机测、降压验证 |
| 掉驱动 / 黑屏重启 | 供电 | 核心 | 查日志、烤机、量电压 |
| 满载温度破百 | 散热 | 供电 | 拆开看硅脂/风扇 |
| 风扇狂转不降速 | 散热 / BIOS | — | 查风扇曲线、传感器 |
| 开机无显示但风扇转 | 输出 | BIOS | 换接口、刷 BIOS |

## 4 易错辨析与术语速查

诊断思路的三处易错点：

**误区一：现象与故障域「对号入座」想当然。** 花屏不一定显存，掉驱动不一定核心——同一现象可对应多个故障域。**用「先软后硬、替换法」一步步缩小候选域**，别凭直觉直接拆卡。<span class="marginnote">「想当然对号入座」是维修新手最大的效率杀手：花屏卡直接拆显存，结果换了三颗还花——其实驱动问题。诊断的价值恰恰在于<strong>先排除便宜的可能</strong>，把昂贵的操作留到最后。</span>

**误区二：跳过「先软后硬」直接拆卡。** 换根线、换驱动、换接口，五分钟就能排除的外部因素，被直接跳过就白拆一遍。**成本最低的排查永远排最前**。

**误区三：没有「故障跟着谁走」的意识。** 替换法是最有力的分诊工具：把嫌疑卡换到正常电脑，或把正常卡换到这台——故障跟着谁走，问题就在谁。一次替换，胜过十次猜测。

## 5 实操清单与自查

把诊断思路落成一套可照着做的动作，拿到故障卡按顺序执行：

1. **复现故障**：先让故障稳定复现——能稳定复现的故障才谈得上诊断。记录复现条件（冷机/热机、待机/满载）。
2. **先软后硬**：换驱动版本、换线材、换接口、换显示器，把软件与外部因素排除干净。
3. **查系统日志**：Windows 事件查看器查「显示适配器」相关错误——掉驱动往往有日志线索。
4. **替换法**：把嫌疑卡换到正常电脑（或把正常卡换过来），观察故障是否跟随移动。
5. **最小系统**：只留「主板 + CPU + 单条内存 + 显卡 + 电源」，排除外设与内存干扰。
6. **分域判断**：根据现象对照映射表，圈定供电 / 显存 / 核心 / 输出 / 散热中的嫌疑域。
7. **先测后拆**：能用显存测试、GPU-Z 读数、测温判断的，先别拆散热器。
8. **逐级收窄**：每做一步就重测一次，确认故障域是否缩小——缩小了继续，没缩小换方向。
9. **记录过程**：每一步的现象与结果记下来，避免重复劳动。
10. **保守修复**：从最便宜的手段（重装驱动、重刷、换线）开始，逐步升级到拆卡与换件。
11. **验收再交付**：修复后按原复现条件反复验证，确认故障不再出现。

### 快速自查表

| 检查项 | 做法 | 判定标准 |
| --- | --- | --- |
| 驱动状态 | 设备管理器查显卡 | 无感叹号、无禁用 |
| 线材接口 | 换线换接口 | 故障消失则原线/口坏 |
| 系统日志 | 事件查看器 | 无持续驱动崩溃记录 |
| 替换结果 | 换机测试 | 故障跟随移动则卡坏 |
| 供电电压 | 万用表量 VCore | 该有却无则供电域 |
| 显存状态 | MATS 测试 | 有错误地址则显存域 |

一句话收尾：**诊断不是一次猜中，而是一次次把候选域减半**——每步验证，都在缩小答案的范围。

## 6 小结

- 故障分两层：**现象**（用户所见）与**故障域**（损坏子系统）；同一现象可对应多个故障域。
- 五大故障域：**供电、显存、核心、输出、散热**。
- 诊断四步：**先软后硬 → 替换法 → 最小系统法 → 仪器实测**。
- 替换法是分诊神器：**故障跟着谁走，问题就在谁**。
- 核心口诀：**以最低成本缩小故障域**——能不动烙铁就别动。
- 「先软后硬」不是怕动手，而是把最贵的操作（拆卡）留到最必要的时刻。
- 判断「花屏归属」最快的一步是替换法：故障跟随卡移动则卡坏，不移动则查平台。
