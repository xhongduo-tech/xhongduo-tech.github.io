## 为什么从案例分析开始

前五篇把诊断、供电、显存、BIOS、BGA 的工具箱备齐了，这一篇把它们装进真实的故障场景。**知识只有落到「现象 → 判断 → 动作 → 验收」的完整链条里，才算真正会用。**下面五个案例覆盖了显卡维修的典型故障域：显存、供电、散热、BIOS、接口——每个都按同一种「四步法」拆解。<span class="marginnote">「案例分析」是工程学习的最高效形式：它把零散知识串成「模式识别」。医生看病例、律师读判例、工程师复盘事故——都是同一件事：<strong>把特征与对策绑定</strong>。读完这五个案例，你该能对号入座地处理大部分常见故障。</span>

## 案例一：矿卡规律花屏——显存故障

**现象**：二手矿卡开机正常，进入系统后屏幕出现固定位置的色块条纹。

**诊断**：规律花屏 → 显存嫌疑优先。跑 MATS 显存测试，错误报告指向某颗显存颗粒的地址段；对照通道映射表，定位到 PCB 上第 3 颗颗粒（A3）。

**动作**：按「先重焊后更换」流程——先对该颗粒回流一次，重跑测试仍报错 → 判定颗粒损坏，拆旧、清盘、换同型号新颗粒、回流。<span class="marginnote">为什么矿卡偏爱显存故障？矿场 7×24 满载 + 高温，显存长期工作在极限温度下，焊点疲劳与颗粒老化比游戏卡快得多。回收矿卡的第一站往往就是「显存测试」——花屏卡里十个有八个是显存问题。</span>

**验收**：重跑 MATS，错误地址归零；满载烤机 30 分钟，规律花屏不再出现。

## 案例二：通电点不亮——供电故障

**现象**：显卡插上后风扇不转、无显示、整机能开机但屏幕无信号。

**诊断**：先软后硬（换槽、换机）无效 → 量供电。上电量 12V 正常，量 VCore 为 0 → 核心 VRM 不工作；断电量核心供电对地阻值**趋近 0 欧** → 输出短路。

**动作**：短路源排查——断开各相电感逐相量，发现某相下管 MOSFET 击穿（D-S 正反都通）。换掉该 MOSFET，再量对地阻值恢复正常。<span class="marginnote">「先量阻值再上电」在这里救了整板：若带着 MOSFET 击穿的短路直接上电，12V 会直灌核心，把昂贵的 GPU 一起烧掉。<strong>短路先于一切上电排查</strong>，是供电维修的第一纪律。</span>

**验收**：上电量 VCore 恢复约 1V，烤机正常，点不亮解除。

## 案例三：越热越花屏——显存虚焊

**现象**：冷机开机正常，玩 30 分钟后开始花屏、死机；重启后冷机又正常。

**诊断**：「温度相关花屏」 → 虚焊嫌疑高于颗粒损坏。跑 MATS 在冷机时可能无错——先满载烤机到出故障温度，再跑测试定位。

**动作**：对目标颗粒整体回流（reflow），冷却后重跑测试；再满载验证温度升高后不再花屏。**若复发，升级为换颗粒**。<span class="marginnote">「热了才坏」是热胀冷缩的直接证据：温度升高，BGA 焊点受热膨胀，虚焊处接触变差或断开。这类故障<strong>回流是首选</strong>——它把焊点重新熔化连接，专治「接触不良」这类机械性问题。</span>

**验收**：满载 2 小时，温度拉满无花屏；MATS 全程无错。

## 案例四：刷 BIOS 变砖——固件救援

**现象**：刷入修改 BIOS 后重启黑屏、风扇狂转、无显示。

**诊断**：近期有刷写操作 + 黑屏 → BIOS 损坏或校验失败。**先查双 BIOS**：拨到另一片 BIOS 能否点亮。

**动作**：双 BIOS 卡拨到救援位点亮 → 确认主 BIOS 损坏 → 在系统里用亮机卡 + 副槽刷回备份镜像；无双 BIOS 的卡，用亮机卡引导或编程器离线刷写。<span class="marginnote">「刷前备份、刷后验证」两个动作，能把 90% 的变砖事故变成 5 分钟的还原操作。这起案例的教训不是「不该刷」，而是「刷之前该做的那两件事没做」——备份与校验。</span>

**验收**：刷回原厂镜像后正常点亮，跑分与温度恢复正常。

## 案例五：HDMI 无信号——接口故障

**现象**：DP 接口正常，HDMI 接口插上显示器无信号（线材与显示器已确认正常）。

**诊断**：单接口无信号 → 接口电路问题优先。量 HDMI 数据脚对地阻值，与正常 DP 接口对比，发现某数据脚阻值异常偏低 → 保护器件（ESD/串阻）击穿。

**动作**：更换击穿的保护器件（或补焊接口虚焊点），再量阻值恢复正常；上电接 HDMI 验证。<span class="marginnote">「单接口故障」与「全接口故障」的分诊：单接口坏 → 接口电路/保护件；全接口坏 → 才怀疑 GPU 显示引擎。这个二分法把输出域维修的搜索空间砍掉一半——先量接口，量不动再往上怀疑。</span>

**验收**：HDMI 正常出画面，4K 分辨率识别正确，热插拔正常。

## 7 易错辨析：案例背后的共同纪律

五个案例表面各不相同，背后是四条贯穿始终的纪律：

**纪律一：先便宜后昂贵。** 换线、重刷、回流，永远排在换芯片、换板之前。成本递增的排查顺序，是案例一显存「先重焊后更换」、案例三虚焊「先回流」的共同逻辑。

**纪律二：先软后硬。** 案例四「先查双 BIOS」、案例一「先跑显存测试」，都是先动软件/固件、后动烙铁。**能用电子的手段定位的，别急着上物理手段**。<span class="marginnote">「先软后硬」不是怕动手，而是成本控制：跑一次显存测试几分钟，拆一次卡一小时。五个案例里最贵的操作永远排在最后。</span>

**纪律三：验收看最坏工况。** 案例一「满载烤机 30 分钟」、案例三「满载 2 小时」，都要求「跑够时长、跑到温度上来」才算过。**「看着能跑」不是验收，「测试通过」才是**。

**纪律四：修什么验什么。** 修显存重跑显存测试，修供电量各路电压，修接口逐接口实测——**定向验收，不留死角**。

这四条纪律，是五个案例从「个案」升华为「方法」的钥匙。记住现象与对策的映射，更记住背后的成本顺序——前者让你会修这一张卡，后者让你能修所有卡。

## 8 实操清单与自查

把五个案例的共性动作收成一张维修操作清单：

1. **先复现**：冷机/热机各测一遍，确认故障现象与触发条件。
2. **软硬分流**：换线、重刷、换驱动这些「软手段」先走一遍。
3. **量电定位**：点不亮先量 12V 与 VCore，供电域先排除。
4. **测显存**：花屏先跑 MATS，把显存域从怀疑里划掉或锁定。
5. **温度分离**：越热越坏优先怀疑虚焊，先回流再更换。
6. **固件排查**：近期刷过 BIOS 的先查双 BIOS 与刷回。
7. **接口二分**：单接口坏查接口电路，全接口坏才疑 GPU。
8. **成本排序**：回流 < 换件 < 换芯，永远从便宜的开始。
9. **逐级验收**：每修一步，用原复现条件重测，故障不除不往下。
10. **满载长验**：修复后满载烤机 + 温度循环，确认最坏工况稳定。
11. **留档**：记录现象、根因、动作、验收，返修时有据可查。

### 案例模式速查表

| 现象特征 | 首查方向 | 对应案例 |
| --- | --- | --- |
| 规律花屏 | 显存测试定位颗粒 | 案例一 |
| 点不亮 + 对地阻值趋零 | 供电 MOSFET | 案例二 |
| 越热越花 | 显存虚焊回流 | 案例三 |
| 刷完 BIOS 黑屏 | 双 BIOS / 刷回 | 案例四 |
| 单接口无信号 | 接口保护件 | 案例五 |

一句话收尾：**案例的价值不在背答案，而在把「特征 → 对策」的模式存进直觉**。

## 9 小结

- 五个案例覆盖**显存、供电、散热、BIOS、接口**五大故障域，共用同一四步法：**现象 → 诊断 → 动作 → 验收**。
- 规律花屏先测显存，点不亮先量供电，**越热越花先回流**，刷黑先查双 BIOS，单接口坏先查保护件。
- 每条诊断都遵循「**先便宜后昂贵、先软后硬**」的成本顺序。
- 验收标准始终是**「测试通过」而非「看着能跑」**。
- 案例的价值在模式识别：**把特征与对策绑定，形成直觉**。
