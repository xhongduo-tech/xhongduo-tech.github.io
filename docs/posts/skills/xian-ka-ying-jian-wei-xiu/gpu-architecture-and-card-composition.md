## 为什么从 GPU 架构开始

显卡（graphics card）是一台电脑里最复杂的单一部件：一块巴掌大的 PCB 上，焊着一颗集成了上百亿晶体管的 GPU 芯片、十几颗显存颗粒、几十路供电电路和一套散热系统。维修显卡的第一步不是拿烙铁，而是**看得懂这张卡由哪些子系统组成、每个子系统负责什么**。拿到一张卡，能指着芯片说出「这是流处理器阵列、这是光栅单元、这是供电相位」，故障时才知道该怀疑哪里。<span class="marginnote">本站体系里，显卡是 CPU 之后的第二大脑：CPU 擅长少量高复杂度任务，GPU 擅长海量并行任务——这条「并行 vs 串行」的分工主线，在第三级《计算机组成原理》与《计算机体系结构》中会反复出现。</span>

## 1 GPU 芯片：并行计算的发动机

**GPU（Graphics Processing Unit）**：专为大规模并行计算设计的处理器芯片。它把晶体管的大部分预算押在「运算单元」上，用大量小核心（shader / CUDA core / stream processor）同时算几千个像素或线程。

GPU 芯片内部的核心部件按「渲染流水线」的职责分为几类：

**流处理器阵列**：由许多流处理器（NVIDIA 叫 CUDA core，AMD 叫 stream processor）按组构成。NVIDIA 以 128 个为一组叫**SM（Streaming Multiprocessor）**，AMD 以 64 个为一组叫**CU（Compute Unit）**。<span class="marginnote">流处理器数量是营销数字的重灾区：NVIDIA 与 AMD 的「核心数」口径不同，跨品牌直接比数字没有意义——同代同规模下 AMD 的流处理器往往「看起来更多」，但单核吞吐与频率不同。我们只在本品牌代际内比较。</span>

**纹理单元（TMU，Texture Mapping Unit）**：负责采样与过滤纹理贴图，决定「贴图快不快」。

**光栅单元（ROP，Render Output Unit）**：负责把像素写入显存、执行抗锯齿与颜色混合，决定「像素写得快不快」。<span class="marginnote">ROP 数量直接决定像素填充率，也是高分辨率下帧率的关键；NVIDIA 的 ROP 通常少于 AMD 的绝对数量，但靠更高的每 ROP 效率扳回一城——这就是「规格数字不等于性能」的又一例证。</span>

**二级缓存（L2 cache）**：GPU 与显存之间的中转仓库，命中 L2 就无需访问显存，能大幅降低显存带宽压力。

## 2 显存与显存控制器

**显存（VRAM）**：GPU 专用的存储颗粒，存帧缓冲、纹理、几何数据，相当于 GPU 的「工作台」。当前主流是 GDDR6 / GDDR6X / GDDR7，旗舰 HPC 卡用 HBM。

**显存控制器（memory controller）**：GPU 芯片内的接口电路，管理显存颗粒的读写。它决定两块硬指标——**位宽（bit width）**与**带宽（bandwidth）**：

- 位宽：单周期内能传输的数据线根数，主流卡 128~384 bit；
- 带宽：单位时间能搬运的数据量，单位 GB/s。

显卡上焊几颗显存、焊在芯片两侧还是单侧，都受位宽设计约束。例如 256 bit 位宽常用 8 颗 32 bit 颗粒并联，8 × 32 = 256。<span class="marginnote">「位宽 ÷ 每颗颗粒位宽 = 颗粒数」是维修时判断显存缺件的常识：256 bit 配 8 颗 32 bit 颗粒，焊少了必然导致整条通道失效，开机花屏或点不亮。</span>

## 3 显卡 PCB：把芯片变成一张卡

GPU 芯片只是「心脏」，PCB（印刷电路板）把它与供电、显存、接口连成整体。一块标准显卡的主要组成：

- **供电电路（VRM）**：多相并联的降压电路，把电源送来的 12V 降到核心需要的约 0.8~1.1V，并把电流分到几十上百安培。相数越多、单相用料越好，供电越稳越凉。
- **电源管理芯片（PWM controller）**：VRM 的「大脑」，接受 GPU 核心的电压请求，输出驱动信号控制每一相 MOSFET 的通断。
- **视频输出接口**：HDMI、DisplayPort，把显存里的帧缓冲转成视频信号送出。
- **外接供电接口**：6 pin / 8 pin / 12VHPWR，从电源引入额外电流（核心功耗几十到几百瓦，PCIe 插槽的 75W 远不够）。
- **散热系统**：散热器 + 风扇 + 热管 + 背板，把核心与显存的热量带走。
- **监控与调控**：温度传感器、风扇调速、功耗监控，配合 GPU 内的电源管理逻辑，按负载动态调节频率与电压。

## 4 公式解析：填充率把规格变性能

GPU 的「算得快不快」由几个公式串联，先把最直观的**像素填充率（pixel fill rate）**拆开：

$$
\text{像素填充率} = \text{ROP 数量} \times \text{核心频率}
$$

- **第一步，认识 ROP 数量**：ROP 是负责把像素写进显存的单元，规格表里是固定数字，如 96。
- **第二步，认识核心频率**：核心每秒钟跳多少下，单位 GHz，如 1.8 GHz = 每秒 18 亿周期。
- **第三步，相乘**：每个周期每个 ROP 写一个像素，则 $96 \times 1.8 \times 10^9 \approx 1.73 \times 10^{11}$，即约 173 GPixel/s。

同理，**纹理填充率（texture fill rate）** = 纹理单元数量 × 核心频率，衡量贴图吞吐；**单精度浮点算力（FP32 TFLOPS）** = 流处理器数量 × 2 × 核心频率，衡量通用计算能力。<span class="marginnote">「×2」来自 FMA（乘加）指令一次完成一次乘法与一次加法——这是现代 GPU 算力口径（NVIDIA 宣传 TFLOPS）的依据，也解释了为何同一颗核心算力会随频率线性变化。</span>这三个公式共同构成「看规格表估性能」的第一课：**频率相同看单元数量，单元数量相同看频率。**

## 5 核心概念对比表

| 部件 | 英文 | 职能 | 对应性能指标 |
| --- | --- | --- | --- |
| 流处理器 | CUDA core / Stream Processor | 执行着色与计算指令 | 浮点算力 TFLOPS |
| 纹理单元 | TMU | 采样与过滤纹理 | 纹理填充率 |
| 光栅单元 | ROP | 写像素、抗锯齿 | 像素填充率 |
| 显存控制器 | Memory Controller | 管理显存读写 | 位宽 / 带宽 |
| 二级缓存 | L2 Cache | 显存与核心的中转 | 命中率相关 |
| 供电相位 | VRM Phase | 12V 降压供电 | 供电能力 / 温度 |

## 6 小结

- 显卡由** GPU 芯片、显存、供电、散热、接口**五大子系统组成，各司其职。
- GPU 芯片的核心是**流处理器阵列**（SM / CU），配以**纹理单元**与**光栅单元**，分别决定计算、贴图、像素三档速度。
- **显存控制器**决定位宽与带宽，颗粒数量受位宽约束：$位宽 = 颗粒数 \times 单颗粒位宽$。
- 三张性能公式——**像素填充率 = ROP × 频率、纹理填充率 = TMU × 频率、FP32 = 流处理器 × 2 × 频率**——是读规格表的第一步。
- 跨品牌不比流处理器绝对数字，**口径不同，只能同代同品牌比较**。

在下一节，我们将逐个读懂规格表里的每一项——核心频率、显存带宽、TDP、PCIe 版本，学会把一张显卡的「身份证」翻译成真实性能。
