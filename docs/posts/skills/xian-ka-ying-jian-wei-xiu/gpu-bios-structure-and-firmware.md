## 为什么从 BIOS 开始

显卡上电后、驱动加载前，一切行为都由一块只读程序决定——**显卡 BIOS（VBIOS）**。它藏在一颗 SPI Flash 芯片里，平时无人注意，却是整卡「出厂设置」的存档：频率能跑多高、功耗墙在哪、风扇怎么转、开机自检显示什么，全由它说了算。维修时刷错 BIOS 点不亮、超频时改功耗墙、买卡时看「是不是矿 BIOS」，都绕不开它。<span class="marginnote">显卡 BIOS 与主板 BIOS、CPU 微码是同一类东西：都是「硬件上电后最先运行的固件」。读过第三级《计算机组成原理》的「上电自检」一节，会在这里看到熟悉的影子——显卡也在 POST 阶段完成初始化和自检。</span>

## 1 BIOS 是什么：藏在 Flash 里的固件

**显卡 BIOS（Video BIOS / VBIOS）**：存储在显卡板载 SPI Flash（串行闪存）芯片中的固件程序，负责显卡上电初始化、设备枚举、频率/电压管理、输出初始化与自检。

它平时不参与渲染，但在两个时刻举足轻重：

**开机瞬间**：GPU 上电 → BIOS 从 Flash 加载 → 初始化显存、输出接口、时钟 → 向系统报告设备信息（设备 ID、显存大小）→ 显示开机画面。
**驱动未加载时**：安全模式、系统安装界面、无驱动环境，全靠 BIOS 提供的**基础显示功能**（VGA 兼容模式或 GOP 模式）撑场。<span class="marginnote">「刷错 BIOS 点不亮」的机理就在这里：BIOS 里写死了显存颗粒类型与配置（GDDR6 还是 6X、颗粒数、时序），用错颗粒的 BIOS 初始化显存失败，GPU 无法工作，自然黑屏。所以 BIOS 与硬件必须严格匹配。</span>

BIOS 芯片通常是一颗 8-pin 的 SPI Flash（如 Winbond、Macronix），容量 8~32 MB，焊在 PCB 上，可通过编程器（烧录器）离线读写——这是维修时恢复「刷死」显卡的最后手段。

## 2 BIOS 里存了什么

BIOS 不是一段「程序」那么简单，而是一个包含多个数据表的结构。核心内容：

**设备信息**：厂商 ID、设备 ID、子系统 ID、显存配置——驱动靠它识别「这是哪张卡」。
**频率-电压表（V-F table）**：不同负载档位（P-states）对应的核心频率、显存频率、电压。显卡按负载在这些档位间动态切换，这就是「核心频率会变」的出处。
- **功耗墙与电流墙**：TGP 上限、最大电流、温度墙——超过就降频。
- **风扇曲线**：温度与转速的对应表，决定散热策略。
- **输出初始化**：HDMI/DP 接口的初始化配置、输出优先级。
- **UEFI GOP 驱动**：让显卡在 UEFI 启动下工作的驱动模块，老卡刷了不支持 GOP 的 BIOS 在 UEFI 下会黑屏。<span class="marginnote">「GOP」是理解老卡升级的钥匙：UEFI 启动需要 GOP 驱动，纯 Legacy（VBIOS 传统模式）卡在纯 UEFI 主板上不亮。二手老卡装新电脑点不亮，先查 BIOS 是否带 GOP——这既是兼容问题，也常常是「刷 BIOS 后解决了」的案例。</span>

## 3 双 BIOS 与物理开关

部分显卡（尤其高端卡与部分矿卡）设计有**双 BIOS**：PCB 上焊两片 Flash，或一片 Flash 分两区，通过物理拨码开关切换。

**性能模式（OC）/静音模式（Silent）**：同一芯片两套配置，性能模式放开功耗墙，静音模式压低风扇曲线。
**备份与救援**：一个 BIOS 刷坏了，拨到另一个还能开机——**双 BIOS 是刷写失败的最后保险**。
- **矿卡常见操作**：矿工刷「挖矿 BIOS」（砍输出、调时序），回收后常需刷回游戏 BIOS。<span class="marginnote">双 BIOS 拨码是维修时的免费「急救开关」：判断「是不是 BIOS 刷坏」最快的方法，就是拨到另一片 BIOS 看能否点亮。能点亮 → 原 BIOS 坏了；都不亮 → 问题在硬件而非 BIOS。</span>

## 4 核心结构对比表（本主题以表代式）

| BIOS 内容 | 作用 | 被谁读取 | 改动的后果 |
| --- | --- | --- | --- |
| 设备 ID / 子系统 ID | 驱动识别卡型 | 操作系统驱动 | 驱动不识别、功能缺失 |
| 频率-电压表 | 决定各档频率与电压 | GPU 电源管理 | 频率上限改变 |
| 功耗墙 / 电流墙 | 限制整卡功耗 | GPU 电源管理 | 性能与发热的边界 |
| 温度墙 | 触发降频 | GPU 热管理 | 散热不足时性能下降 |
| 风扇曲线 | 温度→转速映射 | 风扇控制器 | 噪音与散热取舍 |
| 显存配置表 | 初始化显存颗粒 | GPU 显存控制器 | 颗粒不匹配即黑屏 |
| GOP 驱动 | UEFI 启动显示 | UEFI 固件 | 纯 UEFI 下黑屏 |

## 5 易错辨析与术语速查

BIOS 结构的三处易错点：

**误区一：以为 BIOS 是「一段程序」。** 显卡 BIOS 更像「程序 + 一堆数据表」的复合体：设备信息、频率-电压表、功耗墙、风扇曲线都是数据。理解成数据，才理解「为什么改 BIOS 能解锁功耗」——改的就是数据表。

**误区二：把「刷 BIOS 点不亮」一律当硬件故障。** 显存配置表与颗粒严格绑定，刷入不匹配的 BIOS（如 GDDR6 颗粒配 GDDR6X 配置）初始化失败 → 黑屏。**先回忆最近是否刷过 BIOS**，再动手拆硬件。<span class="marginnote">「刷完 BIOS 才黑屏」是强信号：问题八成在 BIOS 而非硬件。拨到双 BIOS 另一片或刷回原镜像验证，比拆卡量电压快得多——这是「先软后硬」原则在固件层的体现。</span>

**误区三：忽略 GOP 兼容性。** 纯传统（Legacy）BIOS 的卡在纯 UEFI 主板上黑屏。老卡装新电脑点不亮，先查 BIOS 是否带 GOP——这是兼容问题，不是硬件故障。

## 6 实操清单与自查

认识 BIOS 之后，把「看懂固件」落成可检查的动作：

1. **找 BIOS 芯片**：目检 PCB，找 8-pin 的 SPI Flash（常见 Winbond / Macronix 丝印），这是固件存放处。
2. **看 BIOS 版本**：用 GPU-Z 读 BIOS 版本与日期，判断是否为出厂版本。
3. **确认显存配置**：对照 BIOS 的显存配置表与板上颗粒型号是否一致——不一致就是「刷错 BIOS」的伏笔。
4. **识别双 BIOS**：看 PCB 有无 BIOS 拨码开关；有则分清 OC / Silent 两档。
5. **读 V-F 与功耗墙**：用工具读频率表与功耗墙上限，了解这张卡的「出厂预算」。
6. **查 GOP**：老卡进 UEFI 主板前，确认 BIOS 是否带 GOP 驱动，否则黑屏。
7. **记录原厂信息**：把设备 ID、子系统 ID、BIOS 版本记入维修档案，作为日后对照基准。
8. **评估兼容**：刷 BIOS 前先确认新 BIOS 与你的颗粒、输出、板型匹配。

### 快速自查表

| 检查项 | 做法 | 判定标准 |
| --- | --- | --- |
| BIOS 芯片位置 | 目检 8-pin Flash | 能找到且型号可辨 |
| 版本信息 | GPU-Z 读取 | 与官网版本可比对 |
| 显存配置 | 对照颗粒型号 | 完全匹配 |
| 双 BIOS | 目检拨码开关 | 有开关则有第二片 |
| GOP 支持 | 查 BIOS 说明 | UEFI 下能点亮 |

一句话收尾：**读得懂 BIOS 的数据表，才谈得上动它——先读后改，先备份后刷写**。

## 7 小结

- **显卡 BIOS** 是存储在 SPI Flash 里的固件，负责上电初始化、设备枚举、频率/电压/风扇管理与自检。
- BIOS 内容核心是**数据表**：设备信息、V-F 表、功耗墙、温度墙、风扇曲线、显存配置、GOP 驱动。
- 显存配置表必须与颗粒**严格匹配**——这是「刷错 BIOS 点不亮」的根因。
- **双 BIOS**（OC/Silent 或救援位）是刷写失败的保险，也是维修时的免费急救开关。
- 刷 BIOS 前**先备份**，刷死用编程器离线重写（后文详解）。
- 设备 ID 与子系统 ID 决定驱动识别——刷错卡型会导致驱动不认、功能缺失。
