## 为什么从 GPU 拆焊开始

上一节认识了 BGA 工艺，这一节把它做成「换 GPU 芯片」的完整手艺：**把坏的核心拆下来、把焊盘清理干净、给新芯片植好锡球、再精确贴回去**。GPU 是显卡上最大、最贵、引脚最多的 BGA，对它的任何操作都是「高成本、低容错」——拆坏一次，核心报废；焊盘掉了，整板报废。这一节把每一步的关键动作与风险讲透。<span class="marginnote">「高成本操作」的共性是不确定性管理：芯片级维修的每一步都要「确认了再继续」——确认温度到位了再取芯片、确认焊盘干净了再植球、确认对准了再回流。这与第四级《大模型训练》里「检查点后再继续训练」是同一类工程纪律。</span>

## 1 拆芯片：温度到位再动手

拆 GPU 芯片的流程与要点：

1. **预热 PCB**：下部预热台把整板加热到 100~150°C，减少温差、防翘板。
2. **上部加热**：热风加热头对准核心，按温度曲线加热到锡球熔化（核心 BGA 峰值约 220~245°C 无铅）。
3. **判断熔化时机**：**轻推芯片边缘，能微微滑动 = 锡球已熔化**，此时用镊子（或真空吸取器）轻轻取起。
4. **防损伤**：取芯片的瞬间保持水平，**不要硬撬**——锡球没完全熔化时用力，会撕扯焊盘。

<strong>「锡球熔化再取」是拆芯片的唯一安全时机：过早伤焊盘，过晚烧芯片。</strong><span class="marginnote">判断熔化时机是新手最难的功课：返修台高手凭「芯片边缘一圈助焊剂冒烟」「轻推有微动」判断。稳妥做法是配合红外测温枪盯着芯片表面温度，到峰值区间再试推——<strong>宁可慢半拍，不要早一拍</strong>。</span>

## 2 清理焊盘：决定成败的一步

拆下芯片后，PCB 上残留旧锡与助焊剂，必须清干净：

**除锡**：用烙铁 + 吸锡带（铜编织带）沿焊盘方向拖，把残锡吸走。
**检查焊盘**：**逐一目检焊盘是否完整**——掉焊盘（pad 脱落）是致命伤，缺失的焊盘意味着该网络从此无法连接。
**清洁**：用助焊剂 + 酒精清洁，让焊盘光亮、平整，利于新球润湿。

<strong>焊盘清理是「一次做对」的工序：清不干净，植球后虚焊；清过头，焊盘脱落。</strong><span class="marginnote">「掉焊盘」是 BGA 维修的终点站之一：PCB 上的焊盘是铜箔 + 树脂粘接，暴力除锡或反复返修会让它剥离。焊盘掉了，绝大多数情况下只能飞线或报废。这也是为什么「预热充分、温度控制、手法轻柔」被反复强调——都是保护焊盘。</span>

## 3 植球：给新芯片装上新脚

**植球（reballing）** 是把锡球按网格排列重新焊到芯片底面：

1. **涂助焊剂**：芯片底面焊盘薄涂助焊剂，帮助锡球定位与润湿。
2. **放钢网（stencil）**：用与芯片球距匹配的**钢网**盖在芯片上，网孔对准焊盘。
3. **布球**：把锡球倒上钢网，摇晃让球落进网孔；**锡球尺寸必须匹配**（直径按球距，如 0.6mm 球配 0.8mm 间距）。
4. **热风固定**：低温热风让助焊剂粘住锡球，取下钢网，检查球位是否整齐、缺球。
5. **检查**：缺球、连球（桥连）必须返工——**一个连球，上机就短路**。<span class="marginnote">植球质量决定成败：缺一颗球 → 该网络开路；连两颗球 → 短路。植球后要用放大镜或显微镜<strong>逐区检查</strong>，不能凭手感。专业植球台有真空吸球、自动排球，手工作业则拼细心。</span>

## 4 贴装回流：对准与固定

新芯片植好球后贴回 PCB：

1. **对准标记**：芯片一角有**丝印圆点/斜角**，PCB 上也有对应标记——方向绝对不能错。
2. **辅助对准**：用返修台的光学对准（若支持）或目测芯片边缘与 PCB 丝印框对齐。
3. **回流**：按温度曲线加热，让新锡球熔化、润湿焊盘，形成连接。
4. **冷却**：自然冷却到室温再移动，**热态移动会导致焊点应力开裂**。

<strong>回流完成后先目检：芯片是否水平、四周锡球是否有溢锡（连桥迹象），再上电测试。</strong><span class="marginnote">「方向装反」的代价是致命的：GPU 芯片引脚有电源与地，装反可能直接烧芯片与周边。装前把「丝印角对准 PCB 丝印角」这一动作练成肌肉记忆——这一步错了，前面所有功夫清零。</span>

## 5 拆焊风险对照表（本主题以表代式）

| 步骤 | 关键风险 | 防错动作 |
| --- | --- | --- |
| 拆芯片 | 焊盘撕裂、芯片过热 | 预热 + 熔锡后再取、控温 |
| 清焊盘 | 掉焊盘 | 低温烙铁、轻柔拖吸锡带 |
| 植球 | 缺球、连球 | 检查球位、逐区目检 |
| 对准 | 方向反 | 核对丝印标记 |
| 回流 | 超温、连桥 | 按曲线控温、冷却后再动 |
| 上电 | 短路烧板 | 先量对地阻值再上电 |

## 6 易错辨析与术语速查

GPU 拆焊植球的三处易错点：

**误区一：锡球没熔化就硬撬。** 取芯片的唯一安全时机是「轻推能微动」——此时锡球已熔化。过早用力会撕扯焊盘；过晚则芯片过热。**宁可慢半拍，不要早一拍**。<span class="marginnote">「判断熔化时机」是拆焊的核心手感：看助焊剂冒烟、轻推微动、红外测温到峰值区间——三个信号凑齐再取。经验不足时配合测温枪，比凭手感稳妥得多。</span>

**误区二：植球后不目检。** 缺一颗球 → 该网络开路；连两颗球 → 短路。植球后必须用放大镜**逐区检查球位**，缺球、连球一律返工——「植球质量」决定上机成败。

**误区三：忽略方向标记。** GPU 芯片一角有丝印圆点/斜角，PCB 上有对应标记。方向装反，电源与地接错，可能直接烧芯片。**装前核对丝印标记**，这一步错了前面全清零。

| 术语 | 英文 | 一句话含义 |
| --- | --- | --- |
| 拆焊 | Desoldering | 取下已焊接的芯片 |
| 植球 | Reballing | 重新排列锡球 |

## 7 实操清单与自查

GPU 拆焊植球按这份清单执行：

1. **烘干芯片**：吸潮的芯片先烘干，防爆米花。
2. **预热 PCB**：下部预热到 100~150°C，防翘板。
3. **控温加热**：按曲线加热，盯实时温度。
4. **判断熔化**：轻推微动再取，过早伤盘、过晚烧芯。
5. **清焊盘**：吸锡带除锡，目检焊盘完整。
6. **检查网络**：掉焊盘评估飞线可能，不可行则评估报废。
7. **涂助焊剂**：薄涂芯片底面焊盘。
8. **植球检查**：钢网布球后逐区目检，缺球连球返工。
9. **对准丝印**：芯片与 PCB 方向标记核对，装反即烧。
10. **回流冷却**：按曲线回流，冷却到室温再动。
11. **上电回检**：量对地阻值无短路再上电，跑测试验证。

### 快速自查表

| 检查项 | 做法 | 判定标准 |
| --- | --- | --- |
| 熔化时机 | 轻推微动 | 可安全取放 |
| 焊盘 | 目检 | 完整无脱落 |
| 植球 | 逐区目检 | 无缺球连球 |
| 方向 | 丝印标记 | 对准无误 |
| 对地阻值 | 上电前量 | 无短路 |

一句话收尾：**GPU 拆焊是「高成本、低容错」操作——每一步确认了再继续**。

## 8 小结

- 拆芯片铁律：**锡球熔化再取，过早伤盘、过晚烧芯**。
- 焊盘清理是成败关键：**除锡、目检焊盘完整、清洁**；掉焊盘多致报废。
- 植球四步：**涂助焊剂 → 放钢网布球 → 热风固定 → 目检缺球/连球**。
- 贴装回流：**对丝印方向、按曲线回流、冷却后再动**。
- 高成本操作纪律：**每一步确认了再继续**；上电前先量对地阻值。
