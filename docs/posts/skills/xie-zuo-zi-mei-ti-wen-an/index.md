# 写作与自媒体文案

以《文案训练手册》《爆款文案》《写作是最好的自我投资》三本书为主线，系统掌握从文案底层心法、爆款标题与正文结构，到自媒体选题、运营与个人品牌建设的完整写作能力，覆盖公众号、小红书、头条等主流平台。

## 对标教材

- 《文案训练手册》约瑟夫·休格曼
- 《爆款文案》关健明
- 《写作是最好的自我投资》粥左罗
