## 为什么从航向、方位与罗经开始

前六节解决「船怎么开」，现在开始回答更基础的问题——**船在哪里、朝哪个方向、往哪个目标走**。这是航海学的第一块基石，也是整个定位体系的出发点。地球上没有路标，方向必须由「北」来定义，而「北」竟然不止一个：地球自转轴指向的真北、地磁场指向的磁北、罗经指针指向的罗北，三者各不相同。<span class="marginnote">「三个北」的困惑是每个航海新手的第一道坎，但正是这三个北之间的夹角（磁差、自差、罗经差），构成了地文航海向位换算的全部内容。把三个北的关系理清，罗经误差、向位换算、海图作业就都通了。</span>本课先建立方向基准，再讲透罗经系统，最后用一条公式打通航向、方位与罗经差。

## 1 三个北：方向世界的基准坐标系

航海上的一切方向都以「北」为基准，但地球上有三个北：

**真北（true north, $N_T$）**：地球地理北极方向，即地球自转轴指向的方向。它是地图、海图的基准方向，也是真航向、真方位定义的依据。

**磁北（magnetic north, $N_M$）**：地磁场水平分量指向的方向，即磁针静止时所指。磁北极并不在地理北极，而位于加拿大北部北极群岛附近，并且逐年漂移——所以磁差随时间缓慢变化。

**罗北（compass north, $N_C$）**：磁罗经罗盘（或陀螺罗经）上 000° 所指方向。磁罗经的罗北受船体磁性干扰而偏离磁北；陀螺罗经的罗北则接近真北但仍有仪器误差。

三个北两两之间的夹角，定义了三类「差」：

| 名称 | 含义 | 符号约定 |
| --- | --- | --- |
| **磁差（variation）** | 真北与磁北的夹角 | 磁北偏东为正（E），偏西为负（W） |
| **自差（deviation）** | 磁北与罗北的夹角 | 罗北偏东为正，偏西为负 |
| **罗经差（compass error）** | 真北与罗北的夹角，等于磁差 + 自差 | 罗北偏东为正，偏西为负 |

**海图上的罗经花（compass rose）**：每张海图上都印有同心圆环的罗经花，外圈标注真北（对应真方位），内圈标注磁北（对应磁方位），并注明磁差与年差。海图作业时先用罗经花上的磁北圈量方位、再修正磁差，或直接用真北圈量算——**罗经花是「把三个北的关系直接画在海图上」的便利工具**，也是向位换算时磁差的查取位置。

**向位换算的实操检查**：换算完成后，用「反向验算」自查——把算出的真航向减回罗经差，应能回到原罗航向；方位同理。**一次换算若不能反向还原，说明符号或加减弄错了**。这条「可逆检查」是海图作业防错的第一道保险，也是考试与实船都反复强调的规范。

**重点：磁差是「地球给的」，自差是「船自己产生的」。** 磁差由地磁场决定、只随船位与年份变化，海图上直接标注（如「磁差 4°30′W，年差约 +2′」）；自差由船体钢铁磁性产生、随航向变化，每艘船配一张**罗经自差表**，按航向查取。<span class="marginnote">自差随航向变化的根源是船体磁场方向相对罗经的投影随航向改变——船头转向时，船体钢铁磁场在罗经方向的投影重新分配。因此自差表是一张「按航向查表」的函数表，本质与第六级《控制科学与工程》里「随工况变化的系统参数」同构。</span>

## 2 航向与方位：把方向变成数字

**航向（course）**：船首向与北的夹角，从北顺时针量取 0°—360°。按所用北的基准分为：

**真航向（true course, TC）**：与真北的夹角；
**磁航向（magnetic course, MC）**：与磁北的夹角；
- **罗航向（compass course, CC）**：与罗北的夹角，即罗经盘上直接读到的数值。

**方位（bearing）**：观测者到目标的连线与北的夹角，同样分真方位（TB）、罗方位（CB）。**舷角（relative bearing）**则是目标方向与船首向的夹角（右舷为正、左舷为负）——它随船转向而变，不是固定的方向量。

**辨析｜易错点：** 航向与方位是「方向角」不是「角度位移」。**航向永远指船首向**，方位永远指「目标在哪个方向」，两者都以正北为 0° 起算、顺时针增大，但一个是「船朝哪」，一个是「目标在哪」。混用两者会直接导致海图作业画出错误的船位线。<span class="marginnote">「航向 vs 方位」的区分，在第七级《地理学》的测量里同样重要：航向是「前进方向」，方位是「目标方向」。把「方向」当作可加减的角，就进入下一节的向位换算——整个地文航海的计算基础。</span>

### 舷角与方位的换算

观测目标时，有时得到的是舷角（雷达舷角或目视舷角），需要换算成方位才能画海图。换算关系很简单：**真方位 = 真航向 + 舷角**（右舷为正、左舷为负）：

$$
TB = TC + q
$$

- $TB$：真方位；$TC$：真航向；$q$：舷角（右正左负，取值 −180° 到 +180°）。

例如船向真航向 050° 航行，雷达测得右舷 30° 处有一灯塔，则其真方位 $TB = 050° + 30° = 080°$。**这条换算在雷达标绘与目视定位中天天用到**——它把「相对船头多少度」翻译成「相对地球多少度」，是连接罗经语言与海图语言的桥梁。若算出的方位超过 360° 则减去 360°，为负则加上 360°，保证方位落在 0°—360° 区间内。

## 3 罗经系统：磁罗经与陀螺罗经

**罗经（compass）**是测定方向的仪器，商船驾驶台上通常同时装备两类：**磁罗经（magnetic compass）**与**陀螺罗经（gyrocompass）**。

### 磁罗经

磁罗经靠磁针在地磁场中指向磁北来工作，结构上包括罗盆、罗盘（刻度盘）、磁针组与支承系统。它的优点是结构简单、不依赖电源、永远可用——**即使全船断电，磁罗经仍在工作**，这正是它至今不可或缺的原因。缺点是要受磁差与自差影响，需要定期校正自差、编制自差表。

### 磁罗经的自差校正

自差是船体磁性造成的，但它并非不可管理。**罗经校正（compass adjustment）**通过调整罗经附近的磁棒与软铁片，把各航向上的自差压到最小，校正后残余的自差记录成自差表。<span class="marginnote">校正自差的做法是「转圈校准」：船舶依次停在 8 个或 16 个罗经航向上，逐一对照已知真方位测出自差，再调整校正磁棒。这与第三级《数值分析》里「用一组观测点拟合误差函数」的思路同源——只是这里的「拟合对象」是船体磁场，工具是磁棒。</span>**重点：自差会随船位纬度、装载磁性货物的多少而改变**——大修后、装载大量钢铁货物后、长期停靠同一方向码头后，都应及时重新校差。一本过期的自差表比没有自差表更危险，因为它让人产生「已校正」的错觉。

### 陀螺罗经

陀螺罗经利用高速旋转的陀螺仪寻找真北。其核心物理是**陀螺的定轴性**（角动量守恒使转子轴保持空间方向）加上**重力控制力矩**：陀螺轴被重力力矩拉向地平面与子午面，最终稳定在真北方向附近。<span class="marginnote">陀螺仪找北的原理依赖两件事：地球自转（让「指向空间某固定方向」的陀螺轴相对地球转动）与重力（提供恢复力矩把轴拉回子午面）。这与第一级《物理》里的角动量守恒、第六级《惯性导航》里的陀螺仪应用一脉相承——航海陀螺罗经本质是「把角动量守恒做成一台指向真北的仪器」。</span>它不受地磁影响、精度高，但有**速度误差**（航行时因地球曲率产生）与**纬度误差**，且依赖电力与正常工作环境。

**辨析｜易错点：** 磁罗经与陀螺罗经不是「谁更准」的竞争，而是**互为备份**：陀螺罗经供电准确、磁罗经断电仍可用。驾驶台的标准做法是两者对照使用——陀螺罗经给出的航向与磁罗经给出的航向之差，正好可以用来校核罗经差是否异常。

## 4 公式解析：向位换算

罗经上读到的航向是罗航向，海图上画的是真航向，两者必须互相换算。一条公式贯穿全部：

$$
TC = CC + C, \qquad C = \mathrm{Var} + \mathrm{Dev}
$$

- $TC$：真航向（要画到海图上的值）；
- $CC$：罗航向（罗经盘直接读到的值）；
- $C$：罗经差 = 磁差 $\mathrm{Var}$ + 自差 $\mathrm{Dev}$；
- 符号约定：**东（E）为正，西（W）为负**——罗北偏东时，罗航向小于真航向，须加上偏东的罗经差。

分步理解：

- **第一步，查磁差**：从海图罗经花（compass rose）上读磁差与年差，换算到当前年份。例如海图标「磁差 3°W，年差 +4′」，五年后磁差约 3°20′W。
- **第二步，查自差**：按当前罗航向在自差表上查取自差。自差随航向变化，所以这一步必须用「将要走的航向」查，而不是用旧的航向。
- **第三步，求和定号**：$C = \mathrm{Var} + \mathrm{Dev}$，注意符号。例如磁差 5°W（−5°）、自差 2°E（+2°），则 $C = -3°$，即罗经差 3°W。
- **第四步，换算**：罗航向 045° 加罗经差 −3°，得真航向 042°——海图上就该画 042°。
- **反向换算**：要把真航向变成罗航向（告诉舵工走多少度），则 $CC = TC - C$。**符号规则永远一致：东正西负，加罗经差得真，减罗经差得罗。**

**实例检验**：真航向 180°、罗经差 4°E，则罗航向 = 180° − 4° = 176°——因为罗北偏东 4°，罗盘上「看起来」的北比真北偏右，舵工要把船头对准罗盘 176° 才真正指向真南。**这条公式是海图作业的第一运算，算错符号，差之毫厘、谬以数海里。**

## 5 小结

- **三个北**：真北（地理北极）、磁北（地磁北极）、罗北（罗经所指）；两两夹角定义磁差、自差、罗经差。
- **磁差**由地磁决定、随船位与年份变化，海图标注；**自差**由船体磁性产生、随航向变化，查自差表。
- **航向**是船首向、**方位**是目标方向，都从北顺时针量 0°—360°，另有舷角表示目标相对船首的角度。
- **罗经系统**：磁罗经简单可靠断电可用，陀螺罗经精度高找真北、有速度与纬度误差，两者互为备份。
- **向位换算** $TC = CC + \mathrm{Var} + \mathrm{Dev}$：东正西负，加罗经差得真、减罗经差得罗，是海图作业的第一运算。
- **舷角换算** $TB = TC + q$
