## 为什么从货物积载与系固开始

上一节的吃水差、载重线与强度，管的是「船壳这条梁」；本节管的是「梁上装的每一件货」——**积载（stowage）与系固（securing）**。货装得对不对，直接决定稳性、强度与航行安全：货物移位会瞬间改变重心、酿成倾覆；超堆会压坏货与船；危险货物混装可能引发火灾爆炸。<span class="marginnote">货物事故在海上伤亡中占显著比例：散货船「货物液化」（矿石含水在横摇中变成泥浆般流动）可导致整船快速倾覆，集装箱船大浪中堆箱倒塌会丢箱甚至危及稳性。<strong>配载与系固，是船运安全里「人祸」占比最高的环节之一</strong>——多数货物事故本可避免。</span>本课讲透货物分类、积载原则与系固实务，最后用受力公式讲清「为什么要绑得那么牢」。

## 1 货物分类与积载原则：把货装成「稳」

### 主要货类

| 货类 | 典型货物 | 特殊风险 |
| --- | --- | --- |
| 干散货（dry bulk） | 谷物、矿石、煤 | 货物移动、液化、平舱 |
| 液体货（liquid） | 原油、化学品、液化气 | 自由液面、膨胀、挥发 |
| 杂货（general cargo） | 件货、袋货、钢卷 | 混装相容、系固 |
| 集装箱（container） | 各色箱货 | 堆重、绑扎、重心 |
| 危险货物（dangerous goods） | 爆炸品、易燃液体、腐蚀品 | 隔离、相容、应急 |
| 冷藏货（refrigerated） | 冷冻食品 | 温度控制、堆码 |

### 积载的黄金原则

**重货在下、轻货在上**：把重的货放底舱、轻的货放上层，能降低整船重心 $KG$、改善稳性——这与《船舶主要尺度、结构与浮性稳性》里 $GM = KB + BM - KG$ 的公式直接对应：重心低，稳性好。<span class="marginnote">「重货在下」不是经验之谈，而是稳性公式的直接推论：$KG$ 每降低一档，$GM$ 就增加一档。配载员看稳性计算书决定每层装什么，本质上是在「用公式优化重心高度」——积载口诀的背后是物理定律。</span>

**均匀分布、避免集中载荷**：货物沿船长与船宽方向尽量均匀，防止局部超压与总纵弯矩过大——呼应《吃水差、载重线与船舶强度》的强度要求。

**各舱按配载计划**：装货前先做**配载计划（stowage plan）**，算好每舱装什么、装多少、吃水差与稳性是否满足。**「先计划、后装货」是铁律**——临时改舱可能破坏整个配载平衡。<span class="marginnote">配载计划是「装货的施工图」：它同时约束稳性、强度、吃水差与卸货顺序。卸货也要按计划——先卸后部舱、再卸前部，避免卸货过程中船体应力过大。配载与卸货的「顺序」，与第六级《物流》里的「出库顺序优化」是同一个问题。</span>

### 配载计划的完整流程

一次规范装货的流程大致如下：**收货载信息**（各港各舱的货量、重量、体积、特殊要求）→ **编制配载计划**（分配舱位、核算稳性/强度/吃水差）→ **装货实施**（按计划逐舱装、边装边核吃水）→ **平舱与系固**（散货平舱、件货绑扎）→ **开航前检查**（核对吃水、稳性、绑扎）。<span class="marginnote">配载流程与《航线规划》的「评估—设计—执行—监控」四阶段同构——都是「先计划、后执行、持续核对」的工程纪律。配载不是一次性的表格，而是从装货到离港的持续过程。</span>**每一港的装卸都会改变整船状态**——多港装货时，后港的配载必须建立在前港装完后的实际浮态上，不能「一张计划用到底」。

### 装卸作业安全

装货与卸货本身就是高风险作业：吊机作业、人机交叉、货件坠落、舱内作业。要点包括：**装卸前后核对配载图与实装**（防止「计划是一套、实装是另一套」）、**装卸中监测吃水与横倾**（两侧装卸不均会突然横倾）、**舱内作业通风检测**（封闭舱室缺氧、有毒气体）、**危险货物装卸的专门程序**。<span class="marginnote">「装卸中持续监测吃水与横倾」是配载流程的实时环节——一次不对称装货可能让船在几分钟内横倾数度，严重时危及稳性。这与第八级《应急管理》里「作业过程持续监控」的原则一致：风险不只存在于开航后，也存在于装卸的每一吊。</span>**装卸作业的指挥权明确**：码头装卸由装卸工头与船方大副协调，口令与信号必须清晰，防止误操作。

## 2 特殊货物的积载：各有各的「脾气」

**危险货物**：依《国际海运危险货物规则》（IMDG Code）分为 9 大类，按**隔离表**决定不同类别之间能否同舱、隔离距离多远。危险货物积载的核心是**相容与隔离**——氧化剂不能与易燃品同舱，腐蚀品要远离食品。<span class="marginnote">IMDG 的隔离表是一个「两两相容」矩阵——它与第四级《图论》里的「着色问题」、与第三级《数据库》里的「约束表」同构：用一张表把所有「不能放一起」的组合枚举出来，按表执行即可。危险品事故多发生在「忽视隔离表」的侥幸里。</span>

**干散货与液化风险**：谷物、矿石在横摇中会**移动（shifting）**甚至**液化（liquefaction）**。散货船装含水量高的矿石，航行中货物可能从固态变成泥浆状流动，瞬间改变重心、导致倾覆。对策是**平舱**（把货堆平、消除空隙）与**控制含水量**（装货前检验）。

**散货的平舱**：货舱装不满时，货物表面留有空隙，横摇中货物就会从一侧「滑」到另一侧，重心来回移动、横摇加剧，最终可能倾覆。**平舱（trimming）**就是把货堆平、把空隙填实，让货物表面尽量平整——《国际海运固体散货规则》（IMSBC Code）对散货平舱有强制要求。**「装散货必须平舱」不是建议，而是防止货物移动的法定措施**。

**重大件与钢材**：大型机械、钢卷、重设备等**重大件（heavy lift）**，体积重量大、单位面积载荷高。积载要点是**分散放置、均匀承压、加垫木、专向系固**——钢卷要「立放」（卷轴垂直于船长方向）并楔紧，防止滚动；重大件要算清局部强度，必要时放在舱底强结构上。<span class="marginnote">钢卷「立放」还是「卧放」是系固的经典考题：立放（卷轴沿船长）使钢卷与横摇方向垂直，不易滚动，但绑扎要求高；卧放易滚但好绑。不同船型、不同海区有不同选择——<strong>系固方案的合理与否，直接影响钢卷在横摇中会不会「滚起来」</strong>。</span>

**冷藏货**：冷藏货要求全程温控，装舱时**货物预冷、舱室预冷、留通风道**，避免堆码过密堵死冷气循环。冷藏货积载的关键词是「温度一致性」——不同温区的货不能同舱，测温记录要全程留存。

**液体货与自由液面**：油舱、水舱未装满时，液体在舱内晃动产生**自由液面效应**，等效于抬高重心、降低 $GM$。液货船设**纵舱壁**把舱室变窄，就是为减小自由液面影响。<span class="marginnote">「自由液面效应」是液货船配载的头号大敌：同样多的油，装在一个大舱里比分成几个小舱，自由液面效应大得多。纵舱壁把大舱分成窄舱，正是用结构设计对抗物理效应——与《稳性》里「舱室分小」的思路一脉相承。</span>

## 3 货物系固：把货「焊」在船上

**系固（securing）**是防止货物在航行中移位的措施——移位不仅损坏货物，更会改变重心、危及稳性。海上货物始终承受着船体运动产生的**加速度力**：横摇把货物往舷侧甩、纵摇把货物往首尾甩、垂荡把货物往上抛再砸下。

**系固手段**：钢丝绳、绑扎带、链条、集装箱锁具（twistlock）、系固点（lash point）、木楔与垫木。系固方案的依据是《货物积载与系固安全实用规则》（CSS Code），它对非标准货物给出「加速度—绑扎力」的核算方法。<span class="marginnote">CSS Code 的系固核算，本质是「力平衡」：绑扎能提供的约束力 ≥ 货物受到的惯性力 − 货物与舱底/相邻货件间的摩擦力。它是《材料力学》里「静力平衡」在船上的应用——把「绑几道」从经验变成计算。</span>

**集装箱的积载与绑扎**：集装箱船甲板上，箱与箱之间用锁具互锁、再用绑扎杆与花篮螺丝拉到舷侧，形成「绑扎桥」结构。堆重与绑扎密度按配载图执行——**甲板堆箱越高，重心越高、绑扎要求越严**。此外，集装箱装载还要注意：**重箱在底、轻箱在上**（与散货同一条原则）、**危险品箱按隔离表布置**、**冷藏箱接电与监控**。<span class="marginnote">集装箱的「重箱在下」与散货的「重货在下」是同一物理的不同载体——都是通过垂向分布把重心压低。但集装箱还多一层约束：<strong>每列堆重不能超过底层箱与船体的承重上限</strong>，所以配载图要逐列核算堆重，而不是只看总重。</span>大件箱（超高、超宽、超重箱）还要专位专绑，并检查与船体结构、其他箱的干涉。

### 系固设备与检查清单

常见的系固设备各司其职：**钢丝绳与绑扎带**承受拉力、**链条与花篮螺丝**张紧、**集装箱锁具（twistlock）**互锁箱角、**系固点（lash point）**提供锚固、**木楔与垫木**防止滑动、**充气袋/止动装置**填充空隙。<span class="marginnote">「设备各有用途」的系固体系，与《系泊》里「缆绳各司其职」的结构一致——首缆管前、尾缆管后，同理绑扎带管拉、锁具管锁、垫木管撑。<strong>一套设备体系的可靠性，取决于每个环节都用在它的设计位置上</strong>。</span>

开航前的**系固检查清单**：核对系固点完好、锁具紧固、绑扎带无磨损、花篮螺丝到位、堆箱无超高超重、危险品已按隔离表布置。**检查不是「看一眼」，而是「逐项打勾确认」**——把检查清单与《航行值班》的纪律清单对照，会发现它们是同一种「把安全变成流程」的方法。

**重点：系固的验收标准是「能抵抗设计加速度」**。开航前，大副要检查所有绑扎是否到位、锁具是否紧固、压紧装置是否起作用，并在《系固检查记录》上确认。**绑扎不是「差不多就行」——一箱未锁紧的集装箱，在大浪中可能砸向全船。**

## 4 公式解析：货物受的惯性力

货物为什么必须绑牢？因为它始终受着船体运动施加的惯性力。横摇中的货物侧向受力：

$$
F_y = m \times a_y
$$

- $F_y$：货物受到的横向惯性力（N）；
- $m$：货物质量（kg）；
- $a_y$：货物处的横向加速度（m/s²）。

分步理解：

- **第一步，看加速度来源**：横摇、纵摇、垂荡使船体上各点产生加速度，离船中纵摇中心越远、离横摇中心越远，加速度越大——**甲板边缘、首尾的货物受力最大**。
- **第二步，看量级**：大风浪中横摇角加速度可达 $0.3\text{—}0.5\ \mathrm{m/s^2}$ 甚至更高。一个 20 t 的集装箱在 $0.4\ \mathrm{m/s^2}$ 的横摇加速度下，横向惯性力 $F_y = 20000 \times 0.4 = 8000\ \mathrm{N}$——相当于约 800 kg 的重物横着撞向绑扎。
- **第三步，看系固要求**：绑扎的约束力必须 ≥ $F_y$ 减去摩擦力。摩擦系数约 0.3—0.4（钢—木）时，摩擦力能帮不少忙，但大倾角时摩擦减小、惯性力增大——**这就是「绑扎要按最恶劣工况校核」的原因**。
- **第四步，理解 CSS Code**：CSS Code 给出不同船型、不同装载位置对应的设计加速度，系固方案据此计算需要的绑扎道数与规格。<span class="marginnote">「F = ma」是系固的物理核心，也是第七级《物理》里牛顿第二定律的船用版。理解它，才能理解「为什么集装箱要锁、钢卷要垫、大件要焊」——每一条系固规定，都是一道受力平衡题的答案。</span>

**一个具体场景**：集装箱船在北大西洋冬季遭遇横浪，横摇角 ±25°、甲板边缘横向加速度达 $0.45\ \mathrm{m/s^2}$。甲板上一只 30 t 的重箱，横向惯性力 $F_y = 30000 \times 0.45 = 13500\ \mathrm{N}$——约 1.4 t 的侧向力持续拉扯绑扎。若不按 CSS Code 的设计加速度配足绑扎道数，锁具可能在大浪中疲劳失效，重箱滑落砸向舷侧。**这就是「绑扎按最恶劣工况校核」的现实意义**——系固不是应付检查，而是对抗真实的物理。

## 5 小结

- **货类各不同**：干散货怕移动液化、液体货怕自由液面、危险货物要隔离、集装箱要堆重绑扎。
- **积载黄金原则**：重货在下、轻货在上（降重心）、均匀分布（护强度）、按配载计划装货。
- **危险货物**依 IMDG Code 分 9 类，按隔离表控制相容与间距。
- **系固**是防移位的保险：绑扎力 ≥ 惯性力 − 摩擦力，依据 CSS Code 按设计加速度校核。
- **惯性力公式** $F_y = m a_y$
