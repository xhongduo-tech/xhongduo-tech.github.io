# 航海技术（船舶驾驶与海员适任）

航海技术是研究船舶驾驶、航行安全与海员适任能力的应用学科，涵盖船舶操纵、航海学、气象水文与 STCW 公约所规范的培训发证体系。全球约 90% 的贸易量经海运完成，学完这些章节，就掌握了从船艺理论到远洋驾驶员值班适任的完整基础。

## 对标教材

- 《STCW 公约》——国际海员培训、发证和值班标准公约（含附则与规则）
- 交通运输部《海船船员培训大纲（2021 版）》
- 《海船船员适任考试、评估和发证规则》
