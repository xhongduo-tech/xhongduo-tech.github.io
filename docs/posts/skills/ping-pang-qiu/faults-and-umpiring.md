## 为什么从违例与判罚开始

规则学过前四篇，你已经知道球台多大、球多轻、发球怎么发、分怎么计。
但一场比赛真正运行起来，靠的是裁判在每一回合结束时说出那一声「**得分**」或「**重发**」——而支撑这一声的，是「哪些情形算得分、哪些算违例、犯规如何逐步升级」的完整判罚体系。<span class="marginnote">本篇是竞赛规则（第 1 篇运动概述与规则的收尾）的最后一环：前三篇讲「场地、器材、发球、计分」，本篇讲「边界在哪里、越界怎么办」。<strong>规则不只是限制，它同时定义了什么值得奖励</strong>——得分情形是「正确行为的奖赏」，判罚阶梯是「越界行为的代价」。</span>

**违例（fault）**：选手违反比赛规则、使本回合无效的行为，通常直接判对方得分。**判罚（penalty）**：对比赛中不当行为（如拖延、辱骂）的警告与罚分，由黄牌、红牌分级执行。

## 1 得分：回合怎样才算「打完」

乒乓球每一回合必有一方得分——「回合结束」的判定是裁判工作的核心。得分的情形可以归纳为两大类：

**第一类：对手回球不合法。** 包括：发球不合法；
回球未过网或未落对方台面（出界）；
球在未弹跳前被接住（凌空截击）；
球被击回本方台面；回球时球触到非持拍手；
回球被对方身体或衣服触及。

**第二类：对手在回合中违规。** 包括：非持拍手触及台面；
使台面移动；持拍手（含手臂）或身体任何部位触及球网装置；
球拍脱手后击中球；在球尚未越过球网或尚未触及本方台面时，用身体或球拍**阻挡（obstruction）** 来球。<span class="marginnote">「阻挡」是最容易误会的得分规则：对方来球还在飞行中、尚未落到本方台面，你就用手或拍把它拦下——这在规则里是失分，不是「救球」。正确做法是让球先落地弹一次再回击。看球时若见选手「空中拦截」，那多半已经是判罚对象了。</span>

**核心要点：** 得分情形的共同逻辑是「**对手破坏了回合的连续性**」——要么没把球合法送回，要么用违规动作干扰了回合。
把「得分 = 对方没做好回球 + 对方犯了规」记在脑子里，看任何球都能判。

## 2 重发球：不算分、不换发的「重新开始」

并非所有异常都判得分——有一类情况判**重发球（let）**：本回合无效，重新开始，不计分、不换发球权。
典型情形：

| 情形 | 说明 |
| --- | --- |
| **发球擦网** | 发球时球擦网顶后仍过网、落在对方台面 |
| **接发方未准备好** | 接发球方未作出接球准备时球已发出（接发方有权拒绝） |
| **球在回合中破裂** | 球在比赛状态中裂开、变形 |
| **外部干扰** | 有人闯入、球被意外打出场外、灯光故障等不可控因素 |
| **裁判原因** | 裁判失误（如报错分）导致回合无法正常进行 |

**辨析｜易错点：** 最常见的混淆是「发球擦网」与「发球落网」。**擦网后仍过网落台 = 重发**（let）；**擦网后未过网或落本方台面 = 发球失分**。
只有「擦网且过网落台」这一种情况才重发。<span class="marginnote">还有一种容易忽略的「重发」：接发球方在球发出时尚未准备好，可以举手示意重发。但注意，<strong>接发球方必须是在「未准备」的状态下</strong>才有效——若已经试图接球则不能再反悔。这条规则保护接发球方不被「偷袭发球」。</span>

## 3 判罚阶梯：从黄牌到红牌

得分与重发处理的是「回合内」的对错；
而选手的**不当行为**（故意拖延、辱骂、踢球拍、拒不服从裁判）走的是另一条判罚路径。
国际乒联采用**渐进式判罚**：

| 阶段 | 判罚 | 含义 |
| --- | --- | --- |
| 第一次 | **黄牌**（警告） | 口头警告，不计分 |
| 第二次 | **黄牌 + 红牌** | 判对方得 1 分 |
| 第三次 | **黄牌 + 红牌** | 判对方得 2 分 |
| 第四次（或严重行为） | **红牌** | 判本场负（取消比赛资格） |

**辨析｜易错点：** 黄牌和红牌不是「足球式」的累计警告——在乒乓球里，**黄牌 + 红牌同时出示表示罚分**，且罚分从 1 分、2 分逐级加重，严重行为可跳过警告直接判负。
裁判在出示判罚前会先向选手说明，但一旦出示即生效。<span class="marginnote">理解判罚阶梯的价值在于「预判红线」：<strong>故意拖延发球（每次发球准备超过规定时间）是最常见的黄牌触发点</strong>；把球拍摔在台上、用球拍击球发泄，则可能直接吃到罚分。对业余爱好者，记住「尊重裁判、控制情绪」就是最好的避罚策略。</span>

## 4 裁判员与执裁流程

一场比赛的执裁由**裁判员（umpire）**负责，大型赛事配备**副裁判员（assistant umpire）**与**记分员（scorer）**。
裁判的核心职责：

**判定每一回合**：报出「得分」或「重发」，并登记比分。
**报分（score calling）**：每得 1 分报一次，先报发球方比分再报接发球方比分。
- **管理比赛节奏**：计时（局间 1 分钟、暂停 1 分钟、轮换发球法计时）、监督换边与发球权轮换。
- **检查器材**：赛前检查球拍、用球，判定发球是否合规。
- **处理异议**：对判罚有异议时，选手可向裁判提出；涉及规则解释的重大争议，由裁判长（referee）裁决。

**执裁流程：** 赛前检查与挑边 → 宣布比赛开始 → 全程报分与判罚 → 局间管理 → 决胜局换边 → 赛后核对比分、双方签名。<span class="marginnote">裁判的权威建立在「即时性与一致性」上：判罚要当机立断，尺度要全场统一。这也是为什么职业比赛里裁判的判断极少被推翻——<strong>规则给了裁判最终解释权，而裁判的专业性决定了规则能否真正公平落地</strong>。</span>

**对选手的意义：** 懂裁判，才能打比赛——知道「哪一瞬间裁判会判分」、知道「什么时候可以叫暂停」，比赛才不会在规则层面吃暗亏。
对业余爱好者，自己动手当几次裁判，反而是理解规则最快的途径。

## 5 纯概念主题：违例与得分速查表

把前文全部「得分 / 重发 / 违例」情形浓缩成一张速查表：

| 情形 | 判罚 |
| --- | --- |
| 发球不合规（抛球低、遮挡等） | 对方得分 |
| 回球落网、出界 | 对方得分 |
| 球未弹跳即被击回 | 对方得分 |
| 连击（球拍连续触球两次） | 对方得分 |
| 非持拍手触台、手扶球台 | 对方得分 |
| 身体或球拍触网 | 对方得分 |
| 使球台移动 | 对方得分 |
| 球未落本方台面即被阻挡 | 对方得分 |
| 发球擦网后过网落台 | 重发 |
| 接发球方未准备时发球 | 重发 |
| 球破裂、外部干扰 | 重发 |
| 拖延、辱骂、摔拍等不当行为 | 黄牌 → 罚分 → 判负 |

**核心要点：** 这张表是裁判执裁的「快捷键」，也是选手自查的「避雷指南」。
把表里的「对方得分」情形全部避开、把「重发」情形正确对待，你的比赛就不会在规则层面吃亏。<span class="marginnote">规则部分的最后一课，送你一个总纲：<strong>乒乓球规则的全部设计，围绕「让回合尽可能公平、让比赛必须有结果」这两个目标</strong>——得分情形保证回合有胜负，重发情形保护异常公平，判罚阶梯保证比赛文明，轮换发球法保证比赛不无限拖延。规则不是束缚，而是这项运动能持续运转的骨架。</span>

### 裁判的报分与手势

裁判执裁的「门面」是**报分**——每一次得分，裁判都要清楚地报出比分，这是让选手与观众同步比赛进程的环节：

**报分规则**：先报**发球方**的比分，再报**接发球方**的比分。
例如发球方 3 分、接发球方 2 分时，报「3 比 2」。
报分时声音清晰、节奏稳定，让双方都听清。

**报分与判罚的衔接**：报分前先判「得分」还是「重发」——判得分时，先报分再记分；
判重发时，报「擦网」「重发」等提示，比分不变。<span class="marginnote">报分看似简单，实则是比赛节奏的一部分：<strong>报分快，比赛节奏紧凑；报分慢，给了选手喘息与思考的时间</strong>。有的裁判还会用手势配合报分（指向得分方、比划分数），让远端的选手与观众也能看清。理解报分的「规则」与「节奏」，是看懂比赛转播的细节之一。</span>

**选手对报分的反馈**：选手对判罚有异议时，应**立即向裁判提出**（而不是事后争执）——裁判可复核或维持原判；
涉及规则解释的重大争议，可申请裁判长介入。**尊重裁判的即时判罚，是乒乓球比赛的基本素养**，也是判罚体系能够顺畅运行的保障。

## 6 小结

- **得分 = 对手回球不合法（落网、出界、截击、连击）+ 对手回合内违规（触网、触台、阻挡等）**。
- **重发球**：发球擦网过网、接发方未准备、球破裂、外部干扰——不计分、不换发。
- **判罚阶梯**：黄牌（警告）→ 黄牌+红牌（罚 1 分）→ 黄牌+红牌（罚 2 分）→ 红牌（判负）。
- 裁判负责**判分、报分、计时、检查器材**；重大争议由裁判长裁决。
- 速查表是执裁与自检的核心工具：**避开「对方得分」情形，正确对待「重发」情形**。
