# 乒乓球

乒乓球是一项集速度、旋转与落点控制于一体的隔网对抗性球类项目，被誉为中国国球，其核心在于发球与弧圈球的旋转技术、快速灵动的步法移动以及严格的竞赛规则。以ITTF《乒乓球竞赛规则》、《乒乓球运动教程》与《中国青少年乒乓球训练教学大纲》为纲，系统重建从竞赛规则、基本技术与弧圈球高级技术、步法与实战战术到体能训练与教学训练体系的完整知识结构。
