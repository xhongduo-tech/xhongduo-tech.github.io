## 为什么从节流装置开始

在四大部件里，节流装置是最「小」也最「精」的一个——它可能只是一根几十毫米的管子、一个带感温包的阀体，却承担着两件大事：**把高压液态制冷剂节流降压降温**，以及**精确控制进入蒸发器的制冷剂流量**。流量给多了，蒸发不充分、回气管带液、压缩机液击；流量给少了，制冷量不足、出风不凉。膨胀阀（TXV）与节流管（OT）正是实现这一调节的两种流派，结构不同、维修方式完全不同。这一篇把两者讲透，并给出一套判断「该换阀还是该查别处」的思路。

<span class="marginnote">节流装置是循环里唯一的「可变部件」之一。压缩机、冷凝器、蒸发器基本都是「定型的硬件」，而节流装置承担着随负荷调节流量的任务。把它看成制冷循环的「油门」——油门开多大，取决于你想要的动力（冷量）与当前的路况（负荷）。</span>

## 1 节流的物理本质

**节流（throttling）**是流体流过突然缩小的通道时，压力降低、温度随之下降的过程。制冷剂在节流装置里发生的是**绝热节流**（近似等焓）：

$$
h_{\text{进}} \approx h_{\text{出}}, \qquad p_{\text{出}} \ll p_{\text{进}}, \qquad T_{\text{出}} \lt  T_{\text{进}}
$$

物理直觉：高压液体突然进入低压区，部分液体**闪发汽化**，汽化需要吸收潜热，热量只能从制冷剂自身「借」，于是温度骤降。节流后的制冷剂变成**低压低温的液/气两相混合物**，进入蒸发器继续吸热。

**重点：节流不制冷，只「降温准备」。** 第 1 篇强调过——节流后制冷剂温度已降，但还没有从外部吸热；真正把热量从车厢拿走，发生在蒸发器里。节流的使命是「把制冷剂送到合适的低压低温状态，并控制送多少」。

## 2 热力膨胀阀（TXV）：能自动调节的节流阀

热力膨胀阀是膨胀阀系统的核心，它的「聪明」在于能随负荷自动调节开度。

**结构**：阀体 + 阀针 + 弹簧 + 感温包（bulb）+ 毛细管。感温包贴在蒸发器出口管上，内部充有感温工质，通过毛细管与阀体膜片相连。

**工作原理**：感温包感知蒸发器出口温度 → 温度转化为膜片上的压力 → 压力推动阀针调节开度。这是典型的**反馈调节**：出口太热（过热度过大）→ 开度加大 → 多送制冷剂；出口太冷（可能带液）→ 开度减小 → 少送制冷剂。它维持的是**蒸发器出口的过热度**稳定在一个设定值（通常约 5 ℃）。<span class="marginnote">膨胀阀的「过热度过大」指蒸发器出口温度比饱和温度高出太多，说明制冷剂在蒸发器里不够用，早就蒸发完了还在被「干加热」——此时制冷量不足；「过热度为负」说明出口还有液滴，即将液击。膨胀阀就是在这两个极端之间维持平衡。</span>

**分类**：按感温包与阀体的平衡方式，分**内平衡式**与**外平衡式**。外平衡式从蒸发器出口引一根平衡管，补偿蒸发器压降，控制更精确，汽车空调多用外平衡式。

## 3 节流管（Orifice Tube）：固定的「孔」

节流管是节流管系统（OT）的核心，但它没有可动件、没有感温包——**就是一根内孔直径固定的短管**。

**结构**：一根细短管，内径约 1–2 mm，外壁有密封圈（O 形圈）与滤网。插在蒸发器入口的高压管里，靠固定孔径限制流量。

**工作原理**：无调节，流量只由孔径与上下游压差决定。系统依靠**气液分离器（accumulator）**来兜底——即使流量与负荷不匹配导致回气管带液，气液分离器会把液态制冷剂拦住，只让气体回压缩机，从而避免液击。<span class="marginnote">节流管的哲学是「用固定口径 + 下游兜底」代替「动态反馈」。它牺牲了精确调节，换来了极低故障率与极低成本。维修上，节流管坏了几乎没有「调节失灵」一说——要么堵（滤网脏），要么漏（密封圈失效）。</span>

**固定 vs 可调，谁更好？** 膨胀阀适应负荷能力强（怠速/高速、冷车/热车都能精确供液），但结构复杂、故障点多（感温包失准、阀芯卡滞）；节流管简单可靠、成本低，但负荷适应性差。两种流派各有拥趸，不存在绝对优劣。

| 项目 | 热力膨胀阀（TXV） | 节流管（OT） |
| --- | --- | --- |
| 可动件 | 有（阀针） | 无 |
| 反馈机制 | 感温包感知出口过热度 | 无 |
| 调节能力 | 随负荷自动调节 | 固定孔径 |
| 故障模式 | 卡滞/失准/泄漏 | 堵塞/密封圈失效 |
| 配套部件 | 储液干燥器 | 气液分离器 |

## 4 膨胀阀的调节与故障诊断

**膨胀阀故障的三个典型表现**：

**开度过大（供液过多）**：蒸发器出口带液 → 回气管结霜、压缩机液击异响、低压侧压力偏高。
**开度过小（供液不足）**：蒸发器出口过热、出风不凉、低压侧压力偏低、压缩机吸气过热度大。
**堵塞**：阀内脏堵或感温包失准，表现为「时好时坏」——温度高时感温包压力大、阀强行打开，温度低时又闭上，造成周期性制冷。

**诊断思路**：遇到「不凉 + 低压压力异常」，先排除制冷剂不足（加注/称重核对）再怀疑膨胀阀。膨胀阀的诊断要配合**压力表组**与**测温**：测蒸发器进出口温差、观察回气管是否结霜、对比高低压读数。<span class="marginnote">一个简易判断法：把膨胀阀拆下，用嘴吹——正常时阀体应能感知感温包温度变化而开闭（用热毛巾捂感温包，阀应打开可吹通；用冷毛巾捂，阀应关闭吹不通）。若感温包失准或阀芯卡死，吹气试验会露馅。这是维修间里验证膨胀阀是否卡滞的土办法。</span>

**易混辨析**：膨胀阀「感温包安装位置」影响极大——必须紧贴蒸发器出口管并保温，否则感应的不是真实出口温度，阀会误调节。维修中常见的「换了阀还是不行」，很多时候是感温包没贴好。

## 5 公式解析：过热度及其诊断意义

膨胀阀控制的最终变量是**过热度（superheat）**——蒸发器出口温度比对应压力下饱和温度高出的量：

$$
\text{SH} = T_{\text{出口}} - T_{\text{饱和}}(p_{\text{低压}})
$$

逐项拆解：

- **$T_{\text{出口}}$**：蒸发器出口管的实测温度（用温度计/夹式测温仪）。
- **$T_{\text{饱和}}(p_{\text{低压}})$**：在低压侧压力 $p_{\text{低压}}$ 下，制冷剂的饱和温度（查制冷剂压力-温度表可得）。这是「此刻制冷剂本应沸腾的温度」。
- **直觉**：SH > 0 表示出口制冷剂已全部汽化并继续升温；SH ≈ 0 或为负表示出口还带液态制冷剂。正常系统 SH 约 5 ℃。SH 过大 → 供液不足/制冷剂少；SH 过小 → 供液过多/有带液风险。

**重点：过热度是膨胀阀系统「调节质量」的读数。** 维修中同时量出口温度与低压压力，查表算 SH，就能判断供液是否匹配负荷——比单看压力或单看温度更可靠。

## 6 节流装置检修要点

**拆检前的判断流程**（避免误换）：
1. 确认制冷剂足量（称重/静压），排除「缺氟伪装成阀堵」。
2. 确认干燥器/储液器不堵（摸罐体进出口温差），排除「罐堵伪装成阀堵」。
3. 确认感温包安装正确（贴紧、保温、在出口管），排除「安装问题伪装成阀坏」。
4. 以上都正常，才拆检节流装置本体。

这个顺序对应第 3 篇的诊断理念——**先排除外围，再怀疑核心**。膨胀阀是「被冤枉最多」的部件，很多人没查清就换阀，结果问题依旧。

- **拆检信号**：低压异常 + 过热度大 + 回气管结霜，是拆检节流装置的直接信号；先确认制冷剂足量、干燥器无堵塞。
- **膨胀阀吹气试验**：拆下后用嘴吹，热毛巾捂感温包应能吹通，冷毛巾捂应闭死——不随温度变化即阀芯卡滞。
- **节流管检查**：拆下观察滤网是否被油泥、杂质糊住，孔径有无异物；O 形圈是否磨损、变形。
- **感温包保温**：膨胀阀装回后感温包必须重新包好保温层，卡箍固定到位——这是「换阀后仍然不凉」的头号原因。
- **系统洁净**：节流装置频繁堵塞，说明系统内杂质多——根源在干燥器失效、系统污染，只换节流装置不净系统，还会再堵。

**辨析｜易错点：** 节流装置堵塞与制冷剂不足的症状相似（都是低压低、不凉），区分靠高压侧：制冷剂不足时高压也低，节流堵塞时高压正常或偏高。用压力表把两者分开，再决定「加冷媒」还是「换阀」。

## 7 小结

- 判断节流装置问题，**先排除冷媒不足、干燥器堵塞、感温包安装不良**，再怀疑阀本体。

在下一节，我们认识两个「储液罐」——**储液干燥器与气液分离器**。它们在系统里的角色、结构、为何不能互换、何时更换，将一次讲清。

- 节流装置把高压液体**节流降压降温**并**控制流量**，是循环的「油门」，但不制冷本身。
- **热力膨胀阀（TXV）**：有感温包，靠出口过热度反馈自动调节开度，精确但复杂；**节流管（OT）**：固定孔径无调节，靠气液分离器兜底，简单可靠。
- 膨胀阀故障三表现：开度大→带液/液击、开度小→过热/不凉、堵塞→周期性制冷。
- 诊断配合**压力表 + 测温 + 过热度计算**；感温包安装位置是「换了阀还不凉」的常见原因。
- 过热度 $\text{SH} = T_{\text{出口}} - T_{\text{饱和}}(p)$
