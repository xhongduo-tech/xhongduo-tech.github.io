## 为什么从两种制冷剂对比开始

现在站在维修车间里的，是两代制冷剂同台的时代。老车用 R134a，新车上越来越多的是 R1234yf——它们名字相似（都是「R + 数字 + 字母」），罐口接头看似差不多，但**绝不能混用**。给 R134a 系统的车误加了 R1234yf，或者反过来，轻则制冷性能下降，重则密封件溶胀、压缩机报废、系统压力异常。这一篇把 R134a 与 R1234yf 的关键特性摆在同一张表上逐项对比，并把「怎么区分、能不能互换」落实到维修实操。

<span class="marginnote">两代制冷剂之争本质是「安全 × 环保 × 性能」的三角权衡：R134a 性能成熟、安全等级 A1，但 GWP 高达 1430；R1234yf 环保性极佳（GWP≈4），却付出了「微可燃」的代价。欧盟 2017 年起强制新车型 GWP`<150，直接把天平压向了 R1234yf。</span>`</span>

## 1 一张表看清两代制冷剂

先给出总览对比，后面逐项展开：

| 项目 | R134a | R1234yf |
| --- | --- | --- |
| 化学名称 | 1,1,1,2-四氟乙烷 | 2,3,3,3-四氟丙烯 |
| 分子式 | $\ce{C2H2F4}$ | $\ce{C3H2F4}$ |
| 安全分类 | A1 | A2L |
| 可燃性 | 不可燃 | 微可燃（LFL 约 6.2%） |
| ODP（臭氧破坏潜值） | 0 | 0 |
| GWP（全球变暖潜值） | 约 1430 | 约 4 |
| 常压沸点 | −26.1 ℃ | −29.4 ℃ |
| 压缩机排气温度 | 较高 | 略低（约低 5–10 ℃） |
| 制冷量（同排量压缩机） | 基准 | 略低（约低 5–8%） |
| 与矿物油相容性 | 不相容 | 不相容 |
| 与 POE/PAG 油相容性 | 相容 | 相容（选用不同 PAG） |
| 干燥剂要求 | 需 XH-7 / XH-9 型 | 需 XH-9 型（部分要求更高） |
| 系统接头 | R134a 专用快接头 | R1234yf 专用快接头（尺寸不同） |
| 泄漏检测 | 电子检漏仪 / 检漏液 | 电子检漏仪 / 检漏液 |

两行最扎眼：**GWP 从 1430 降到 4**，这是换代的全部动机；**安全从 A1 降到 A2L**，这是换代的代价。其他差异大多由此派生。

## 2 物理与热力特性：性能差多少

先看化学结构的差异根源：R134a 是**烷烃**（饱和，单键），R1234yf 是**烯烃**（含一个双键）。双键让分子更活泼、更易在大气中分解，所以 GWP 极低——这也是它「不太稳定」的另一面。

**沸点**：R134a 常压沸点 −26.1 ℃，R1234yf 为 −29.4 ℃，略低约 3 ℃。沸点越低，蒸发吸热能力越强，低温制冷潜力越好，但两者差距很小，实际体验差异有限。

**压力水平**：在相同温度下，两种制冷剂的饱和压力接近，R1234yf 略低。以 40 ℃ 冷凝温度为例，两者高压侧压力都在 1.0–1.1 MPa 附近，差异在 5% 以内。这意味着**如果误用，压力表读数看起来「大致正常」**——这正是混用不易被早期察觉的原因。<span class="marginnote">压力接近是「看起来能换」的假象根源。但压缩机、膨胀阀、密封圈都是按特定制冷剂标定的：R134a 系统的膨胀阀开度特性、压缩机排量、O 形圈材质，与 R1234yf 的要求并不匹配，短时运转「好像正常」，长期必然出问题。</span>

**制冷量**：同一台压缩机、同一工况下，R1234yf 的单位容积制冷量约比 R134a 低 5–8%。因此车型从 R134a 切换到 R1234yf 时，往往需要调整压缩机排量或膨胀阀开度来补偿，并非「换罐冷媒就完事」。

**排气温度**：R1234yf 压缩后的排气温度略低。排气温度低有利于压缩机油温控制，但对系统的意义在于：R134a 系统更依赖良好的冷凝散热，否则排气温度过高会加速油品劣化。

## 3 润滑油与材料兼容性

制冷剂不能单独在系统里跑，它必须和**冷冻油（润滑油）**一起循环，润滑压缩机并带走磨损碎屑。两种制冷剂与油的兼容规则，是维修选油的硬约束：

**R134a**：与矿物油/烷基苯油**不相容**，必须使用 **PAG（聚烷二醇）油** 或 POE（酯类）油。PAG 吸湿性强，所以 R134a 系统对水分极其敏感——这也是「必须抽真空、必须换干燥剂」这条工艺纪律的根源。<span class="marginnote">PAG 油是 R134a 时代的标配，但它极吸湿：打开油罐稍久就吸潮变浑浊。系统里的水分会与制冷剂、油反应生成酸和淤渣，腐蚀管路、堵塞膨胀阀。因此换 R134a 系统的压缩机时，只要管路开口过，就必须重换干燥剂并抽真空。</span>

**R1234yf**：与矿物油不相容，使用**专门配方的 PAG 油**或 POE 油。注意：**R1234yf 专用的 PAG 油与 R134a 的 PAG 油不能互换**，两种油的添加剂配方不同，混用可能引起润滑不良或与密封件反应。

**密封材料**：O 形圈、密封垫的材质也有讲究。R134a 系统常用的 NBR（丁腈橡胶）密封圈对 R1234yf 可能不适用，R1234yf 系统多用更耐烯烃的 HNBR 或专门配方。维修时**必须用系统标明的密封件**，不能图便宜混用。

## 4 维修实操：区分与禁混

维修中最危险的操作是把两种制冷剂**混入同一系统**。防混的核心是「接头物理隔离 + 工具专用」：

**接头不同**：R134a 与 R1234yf 的快接头尺寸/接口形状不同，低压侧、高压侧尺寸也不一样，这是第一道物理防线——正确的接头插不进错误的系统。但高压侧某些车型接头可能接近，维修时仍要核对标识。

**工具不通用**：回收机、充注机、压力表组必须分开专用，或用同一台但彻底清洗管路后再换制冷剂。残留的 R134a 混入 R1234yf 系统，会改变系统成分比例、污染油品。<span class="marginnote">识别车型用哪种制冷剂，最可靠的是看<strong>发动机舱内的标签</strong>：一般在防火墙附近或冷凝器上，注明「R134a」或「R1234yf」以及充注量。其次看快接头，R1234yf 低压接头通常比 R134a 更粗。拿不准时宁可不做，也不猜着加。</span>

**误加的处理**：一旦发现误加（例如 R134a 系统被加了 R1234yf），正确做法是：回收全部制冷剂（混合制冷剂回收后不可再充回使用）、更换干燥剂、清洗系统或按厂家要求更换相关部件、重新抽真空、按标签充注正确制冷剂。绝不能「放了再补」——残留的微量旧制冷剂仍会污染新系统。

## 5 公式解析：GWP 的时标含义

两种制冷剂环保差距的核心是 GWP（全球变暖潜值）。GWP 的定义是「释放 1 kg 该气体在给定时间跨度内造成的辐射强迫，相对 1 kg 二氧化碳的倍数」：

$$
\mathrm{GWP}(t) = \frac{\int_0^t a_i \cdot [C_i(s)]\, ds}{\int_0^t a_{\ce{CO2}} \cdot [C_{\ce{CO2}}(s)]\, ds}
$$

拆解：

- **$a_i$、$a_{\ce{CO2}}$**：制冷剂与二氧化碳各自的**辐射效率**——每单位浓度增量吸收红外辐射的能力。R1234yf 因含双键、分子在大气中很快分解，辐射效率贡献时间短。
- **$[C_i(s)]$、$[C_{\ce{CO2}}(s)]$**：随时间变化的浓度。二氧化碳在大气中停留上百年，浓度长期居高不下；R1234yf 大气寿命仅约 11 天，浓度迅速衰减，所以分母大、分子小，GWP 低。
