# 汽车空调与制冷系统维修

汽车空调与制冷系统维修是独立专业分工，核心在于制冷剂回收充注、系统压力检测与管路密封处理。以 GB/T 29620-2013《制冷剂编号方法和安全性分类》、《汽车空调系统结构与维修》与《汽车维修工国家职业技能标准》为纲，系统覆盖从制冷循环原理、制冷剂特性到压缩机、换热器、节流装置检修与制冷剂规范化回收充注的全流程知识与技能。学完这些章节，就掌握了汽车空调系统从结构认知、故障诊断到规范维修作业的完整能力。

## 对标教材

- 《汽车空调系统结构与维修》
- GB/T 29620-2013《制冷剂编号方法和安全性分类》
