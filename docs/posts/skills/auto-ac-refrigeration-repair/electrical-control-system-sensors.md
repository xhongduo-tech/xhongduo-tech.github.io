## 为什么从电气控制系统开始

现代汽车空调早已不是「一个开关 + 一根皮带」的简单机械，而是一套**传感器 + 控制器（ECU）+ 执行器**的闭环电控系统。面板上的温度设定只是一个「目标值」，系统靠温度传感器、压力传感器、转速信号感知实时工况，由空调 ECU 计算并指挥压缩机离合器、鼓风机、风门执行器动作。看懂这套电气架构，是诊断「空调不工作、时好时坏、温度不准」等电气类故障的前提——而这类故障占了现代空调维修的相当比例。

<span class="marginnote">「从极限到大模型」的知识树里，电气控制是机械部件的「大脑层」——上一节刚认识完机械部件（压缩机、换热器、节流阀），这一节就为它们装上「神经系统」。理解电控，等于理解部件如何被指挥、被保护。</span>

## 1 电气控制系统的架构

汽车空调电控系统是典型的**三层结构**：

**传感层**：各类传感器采集信号——温度、压力、转速、光照等，把物理量变成电信号。

**控制层**：**空调 ECU**（部分车型集成在车身控制器/发动机 ECU 中）接收信号、执行逻辑、输出指令。它是系统的大脑，也是诊断时「读数据流」的对象。

**执行层**：把 ECU 指令变成实际动作的部件——电磁离合器、鼓风机调速模块、风门伺服电机、压缩机排量控制阀、冷凝风扇继电器等。

**输入侧信号**（典型的传感器清单）：

| 传感器 | 位置 | 作用 |
| --- | --- | --- |
| 车内温度传感器 | 仪表台/面板 | 感知车厢当前温度 |
| 车外温度传感器 | 车头 | 感知环境温度 |
| 蒸发器温度传感器 | 蒸发器翅片 | 防结霜、控制压缩机启停/排量 |
| 制冷剂压力传感器 | 高压管 | 压力保护、风扇/排量控制 |
| 日照传感器 | 挡风玻璃下部 | 感知阳光强度修正制冷量 |
| 发动机转速/负荷信号 | 来自 ECU | 高负荷时降低压缩机负荷 |

## 2 关键传感器及其原理

**蒸发器温度传感器（evaporator temp sensor）**：贴在蒸发器翅片上或出口，通常是一只**负温度系数热敏电阻（NTC）**——温度越高电阻越小。ECU 通过它判断蒸发器是否接近结霜（约 0–3 ℃），若接近则断开压缩机或减小排量，防止结霜堵住风道。<span class="marginnote">NTC 热敏电阻的判读：阻值随温度降低而升高。维修中用万用表测其电阻，对照温度-电阻表即可验证好坏。常见故障是传感器开路（阻值无穷大）或短路（阻值近零），都会让 ECU 读到「异常温度」而误动作。</span>

**制冷剂压力传感器（refrigerant pressure sensor）**：装在高压侧管路或储液干燥器上，输出与压力对应的电压信号（如 0.5–4.5 V）。它替代了老式的压力开关，不仅做「过高/过低保护」，还参与**冷凝风扇高速控制**与**压缩机排量控制**——压力高 → 风扇高速、排量受限，防止系统过载。

**车内/车外温度传感器**：车内温度传感器在面板或仪表台，感知车厢温度作为闭环控制的反馈；车外温度传感器在车头，用于修正目标温度、控制内/外循环策略。

**日照传感器（sun sensor）**：光电传感器，感知透过挡风玻璃的太阳辐射强度。夏天暴晒时，即使车厢温度还没上来，它也会让系统提前加大制冷——这是「智能空调」体验的一部分。

## 3 控制策略：从开关到闭环

现代空调电控的核心策略分三层：

**压缩机控制**：
定排量系统：ECU 通过电磁离合器继电器控制接合/分离，依据是面板开关、蒸发器温度、压力保护信号。
变排量系统：压缩机常转，ECU 通过**排量控制阀**调节排量，依据蒸发器温度与目标温度之差。温度差大 → 大排量；接近目标 → 小排量。<span class="marginnote">变排量系统「压缩机不频繁吸合、风扇常转」是正常现象，别误诊为故障。判断它是否在调节，可看压缩机壳体上的控制阀是否在工作、听发动机负荷是否有随温差的变化。若怀疑排量控制阀故障，可用诊断仪读排量指令与蒸发器温度数据流。</span>

**鼓风机控制**：鼓风机由调速模块（或功率管）无级调速，ECU 根据温差与风量设定调节占空比。鼓风机不转或只有最高档，常是调速模块或鼓风机电阻损坏。

**风门控制**：温度混合风门、模式风门、内外循环风门都由**步进电机/伺服电机**驱动，ECU 通过位置反馈确认风门到位。风门卡滞或执行器损坏，会导致「一边热一边冷」「风量分配错误」。

## 4 故障诊断思路：电气故障的分层排查

「空调完全不工作」的电气排查，按信号流从执行端往传感端走：

1. **先确认物理前提**：鼓风机转吗？面板有电吗？压缩机皮带/离合器外观正常吗？——排除「根本没送电」。
2. **查保险丝与继电器**：空调保险丝烧断是最高频原因；用万用表测保险、听继电器吸合声。
3. **查离合器电路**：测压缩机电磁离合器线圈电阻（正常约 3–5 Ω）与供电电压，区分「离合器坏」与「没送电」。
4. **查压力保护**：高压/低压开关（或压力传感器）异常会切断压缩机。用压力表确认系统压力是否在保护阈值内。
5. **查传感器与 ECU**：读诊断仪数据流，看蒸发器温度、压力信号是否在合理范围；对比传感器实测值与读数。
6. **查执行器**：风门电机、调速模块是否动作，用诊断仪做「执行器测试」。<span class="marginnote">一个高性价比的排查技巧：<strong>用诊断仪看数据流而非盲目拆件</strong>。现代车 80% 的空调电气故障能从数据流里读出线索——蒸发器温度显示 −40 ℃ 或 200 ℃ 通常是传感器开路/短路；压力信号恒为 0 是传感器供电或线路断。先读数据再动手，能省下大量拆装时间。</span>

**辨析｜易错点：** 「压缩机不转」先别急着判断压缩机坏。数据流里若显示「ECU 请求压缩机接通」但离合器不吸合，说明故障在电气/执行端；若数据流显示「未请求」，说明是传感或控制逻辑端的问题（如蒸发器温度过低、压力过高保护）。**分清「请求」与「执行」是电控诊断的第一课。**

## 5 公式解析：NTC 热敏电阻的测温原理

蒸发器温度传感器用 NTC 热敏电阻测温，其电阻与温度的关系遵循**斯蒂恩哈特–哈特方程（Steinhart-Hart）**的简化形式：

$$
R(T) = R_0 \cdot e^{\beta\left(\frac{1}{T} - \frac{1}{T_0}\right)}
$$

- **$R(T)$**：温度 $T$（K）时的电阻值，是 ECU 读取的原始信号。
