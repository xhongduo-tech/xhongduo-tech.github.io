# 烹饪科学（食物与烹饪的原理）

烹饪科学以化学、物理与生物学的视角，系统拆解食物在加热、加工与储存中的变化机制——从美拉德反应、蛋白质变性到淀粉糊化，掌握这些底层原理，就能从"照着菜谱做"进阶为"理解为何这样做"，从而稳定复现并创造更好的烹饪结果。

## 对标教材

- 《食物与烹饪的科学》（On Food and Cooking，Harold McGee 著）
- 《烹饪化学》
- 《食物科学》（Food Science）
