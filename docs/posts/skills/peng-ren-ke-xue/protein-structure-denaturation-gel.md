## 为什么从蛋白质开始

碳水给了食材甜与稠，而**蛋白质给了食材「性格」**：肉有肉感、蛋会凝固、奶能凝乳、面筋有弹性、豆腐成凝胶——全是蛋白质的手笔。上一节讲淀粉，核心是「糊化—老化」的晶体拉锯；这一节讲蛋白质，核心则是「**折叠—变性—凝固—凝胶**」的结构变迁。<span class="marginnote">把蛋白质想成一根「会叠纸的链条」：氨基酸是链节，肽键是链节间的连接，而链节侧链之间微弱的作用力（氢键、疏水、离子、二硫键）把长链折成特定形状。<strong>折叠状态 = 蛋白质的「出厂设置」，变性 = 把折叠拆掉。</strong></span>

本节的三步曲：先看蛋白质怎么**叠**（结构），再看它怎么**散**（变性），最后看它怎么**聚**（凝固与凝胶）——三步决定了肉、蛋、奶、豆腐的质地逻辑。

## 1 从氨基酸到蛋白质的层级

**氨基酸（amino acid）**是蛋白质的构件，含氨基（-NH₂）与羧基（-COOH）。两个氨基酸脱水缩合成**肽键**，氨基酸依次连接成**多肽链**。蛋白质的「性格」由四个结构层级决定：

**一级结构**：氨基酸的线性序列，像一串字母的排列顺序。它是「图纸」，决定一切更高层级。

**二级结构**：肽链局部的规则折叠——α-螺旋（弹簧状）与 β-折叠（波浪纸状），靠主链氢键维持。<span class="marginnote">胶原蛋白的典型结构是<strong>三股螺旋</strong>：三条肽链像编辫子一样拧在一起，异常坚韧——这就是肉里胶原「耐炖」的结构根源，下一节还会专门展开。</span>

**三级结构**：整条链在空间中的整体折叠，侧链之间的疏水、离子、二硫键把链「钉」成球状或纤维状。球蛋白（肌肉蛋白、蛋清蛋白、乳清蛋白）多是球状，折叠紧凑、可溶。

**四级结构**：多条肽链（亚基）组装成复合体，如血红蛋白由四条链组成。四级结构解体也是变性的一种。

## 2 变性：把折叠拆开

**蛋白质变性（denaturation）**：在热、酸、碱、盐、机械搅打、酒精等作用下，维持二、三、四级结构的非共价键被破坏，肽链展开、失去原有构象。<span class="marginnote">关键在「变性 ≠ 分解」：变性的蛋白质仍是完整的肽链，只是形状散开、内部基团暴露；只有继续加热或加酶，肽键才会断裂成小肽与氨基酸。<strong>蛋清从透明变白是变性；肉炖到入口即化是水解。</strong></span>

变性是烹饪里最高频的反应，触发方式多样：

| 触发方式 | 实例 |
| --- | --- |
| 加热 | 煎蛋、煮肉、烤面包 |
| 酸 | 酸橘汁腌鱼、腌菜 |
| 碱 | 碱水面、苏打嫩肉 |
| 盐/高渗 | 腌鱼腌肉、卤水点豆腐 |
| 机械搅打 | 打发蛋清、打发奶油 |
| 酒精 | 醉虾、酒渍水果 |

**变性的可逆性**：多数变性不可逆（蛋清不能「再变透明」），因为展开的链随机再折叠回不到原样；少数温和变性可逆。这条「不可逆」正是「生熟不能互相转化」的分子基础。

## 3 公式解析：等电点与蛋白质的溶解度

蛋白质的净电荷随 pH 变化，在某一 pH 下净电荷为零，这个 pH 叫**等电点（isoelectric point, pI）**。对只有一个氨基与一个羧基的简单氨基酸：

$$\mathrm{pI} = \frac{\mathrm{p}K_{a1} + \mathrm{p}K_{a2}}{2}$$

- **$\mathrm{p}K_{a1}$**：羧基（-COOH）解离常数对应的负对数，约 2–3。
- **$\mathrm{p}K_{a2}$**：氨基（-NH₃⁺）解离常数对应的负对数，约 9–10。
- **平均**：把两个解离「临界点」取平均，得到净电荷为零的 pH。

**为什么等电点重要？** 在等电点时，蛋白质分子间不再互相排斥（净电荷为零），**溶解度最低、最容易沉淀**——这是「点豆腐」和「酸奶分层」的核心：**把 pH 调到蛋白质的等电点附近，蛋白就从溶液中析出凝集。**<span class="marginnote">酪蛋白的等电点约 4.6，所以牛奶变酸（乳酸使 pH 降到 4.6 附近）就凝成酸奶酪；豆腐点卤用盐析 + 调 pH 让大豆蛋白沉淀。<strong>「等电点」是蛋白质世界里「最脆弱的 pH」，酸碱一靠近它，蛋白质就「现出原形」。</strong></span>

**对烹饪的启示**：想让蛋白「凝得快」，先把环境 pH 调到等电点附近（加醋、加酸汤）；想让蛋白「多保水」，让 pH 远离等电点（腌制时保持中性偏碱），肉就能吸住更多水分——「熟成牛排多汁」与「等电点逃逸」是同一个道理。

## 4 凝固与凝胶：从溶液到固态

变性后的蛋白质分子展开，暴露的疏水基团互相靠拢，发生**聚集（aggregation）**。聚集的形态决定最终质地，分成两种典型：

**凝固（coagulation）**：无序、密集的聚集，形成**不透明、较硬的固体**。蛋清加热变成白色固体、肉的肌纤维蛋白变性收缩变紧，都是凝固。<span class="marginnote">鸡蛋的凝固温度在 62–70 ℃ 附近，蛋黄比蛋清高几度——所以「溏心蛋」靠的是让蛋清刚凝固而蛋黄仍流心，温度窗口只有短短几度，这就是为什么精确控温（低温慢煮）能做出完美的溏心蛋。</span>

**凝胶（gel）**：展开的蛋白质链先形成三维网络，水被「网」在网络间隙里，形成**半透明、有弹性、含水多的胶体固体**。肉冻、鱼糕、豆腐、果冻的「Q 弹」都来自凝胶网络。

**凝胶与凝固的区别**：凝胶保留了大量水分（含水可超 90%），网络有序、可回弹；凝固则挤出水、结构致密坚硬。**想得到凝胶，就不能让蛋白过度聚集**——要「温和展开 + 慢慢交联」，这就是煮肉冻要用小火、做豆腐要轻柔压制的化学原因。

**辨析｜易错点：** 「蛋白质加热都会变硬」不成立。**蛋白质溶液充分稀释时加热，形成的网络太稀薄，只会变成糊状而非硬固体**（如很稀的蛋花汤）；而高浓度蛋白加热则挤水变硬（煎老的鸡蛋）。**浓度与聚集程度，共同决定是「嫩凝」还是「老凝」。**

## 5 蛋白质在食材中的四副面孔

把变性—凝固—凝胶映射到常见食材：

**肉**：肌原纤维蛋白变性收缩，挤出水分，肉由生变熟；结缔组织胶原变性后水解为明胶，长时间炖煮形成凝胶网络，汤汁变浓（下一节展开）。

**蛋**：卵清蛋白（蛋清）与卵黄蛋白（蛋黄）在不同温度下逐级变性，成就溏心、全熟、老蛋的梯度。

**奶与乳**：酪蛋白被酸或凝乳酶聚集，形成凝乳（奶酪、酸奶）；乳清蛋白加热变性，形成奶皮与蛋奶冻的凝胶。

**大豆**：大豆蛋白在热豆浆中变性，再用盐卤或石膏「点」到等电点附近聚集，压制成豆腐——「卤水点豆腐，一物降一物」的背后，是蛋白质的等电点化学。<span class="marginnote">豆腐制作是「变性 → 聚集 → 凝胶 → 脱水」的完整教科书：煮豆浆让蛋白变性展开，点卤让展开的链在等电点附近靠拢交联成凝胶，压制挤出多余水分，就得到从嫩豆腐到老豆腐的连续质地谱。</span>

## 6 小结

- 蛋白质有**一至四级结构**：序列（一级）、局部折叠（二级）、整体折叠（三级）、亚基组装（四级）。
- **变性**是拆开折叠（不切断肽键），由热、酸、碱、盐、机械等触发，多数**不可逆**。
- **等电点公式** $\mathrm{pI} = \tfrac{1}{2}(\mathrm{p}K_{a1}+\mathrm{p}K_{a2})$
