## 为什么从乳开始

乳是哺乳动物为幼崽设计的**完整营养液**，也是厨房里最复杂的天然体系之一——它是**乳浊液**（脂肪）、**胶体**（酪蛋白）与**真溶液**（乳糖、矿物质、乳清蛋白）的复合体。<span class="marginnote">把牛奶拆开看，它是三层「天下」同时共存：脂肪球分散成 O/W 乳浊液、酪蛋白聚成微米级胶束悬浮、乳糖与矿物质溶解在水相——<strong>一种食材，三种胶体科学。</strong></span>

本节主线：**牛奶本身怎么稳（结构）、怎么被酸与酶拆开（凝乳）、又怎么重组为酸奶/奶酪/黄油（乳制品工艺）**。

## 1 牛奶的成分与微观结构

牛奶约 87% 是水，其余大致为：**乳糖约 4.8%、脂肪约 3–4%、蛋白质约 3.3%、矿物质约 0.7%**。蛋白质分两类，命运完全不同：

**酪蛋白（casein）**：约占乳蛋白的 80%，以**酪蛋白胶束（casein micelle）**形式存在——胶束内部是疏水核心，表面被 κ-酪蛋白的「毛发层」覆盖，靠电荷排斥维持稳定悬浮。**酪蛋白耐热但不耐酸、不耐凝乳酶**——它是凝乳的主角。

**乳清蛋白（whey protein）**：约占 20%，溶于水、球蛋白构象，**不耐热**——加热到约 70 ℃ 开始变性，是奶皮、蛋奶冻的凝胶来源。

**脂肪球**：被一层脂肪球膜包裹，是天然的 O/W 乳浊液；静置或离心时上浮成**奶油（cream）**。<span class="marginnote">「全脂奶」与「脱脂奶」的差别就是脂肪：脱脂奶把脂肪球离心分离走，剩下酪蛋白胶束与乳清——所以脱脂奶口感稀薄、颜色发蓝（脂肪少、酪蛋白胶束对光的散射减弱）。<strong>牛奶的「白」不是颜料白，是脂肪球与酪蛋白胶束散射光的「结构色」。</strong></span>

## 2 公式解析：乳糖发酵与酸奶的酸度

酸奶的诞生，是乳酸菌把乳糖变成乳酸的过程：

$$\ce{C12H22O11 + H2O ->[\text{乳糖酶}][\text{乳酸菌}] 2 C3H6O3 (乳酸)}$$

- **$\ce{C12H22O11}$**：乳糖（葡萄糖+半乳糖的二糖），牛奶的天然糖分。乳糖的甜度只有蔗糖的约 0.4 倍，所以牛奶「不太甜」。
- **$\ce{C3H6O3}$（乳酸）**：产物。乳酸使 pH 下降——每生成一份乳酸，环境就酸一分。
- **水的作用**：乳糖水解（乳糖酶把二糖拆成两分子单糖）后再发酵，水是反应的参与者，也是细菌生长的介质。
- **酸度与凝固的联动**：当乳酸把 pH 从约 6.7 压到约 4.6（酪蛋白等电点），酪蛋白胶束失稳、聚集成凝乳——**酸奶的「凝固」本质是「酸致等电点凝乳」**，这条链式反应是全部酸凝乳制品的核心。

**这条公式还解释了「牛奶为什么会变酸」**：乳酸菌无处不在（空气、容器、手），温度合适（约 30–40 ℃）时它把乳糖变成乳酸——**「牛奶坏了」的酸味，就是乳酸；而酸奶只是「被选定的乳酸菌」主导了这一过程**。

## 3 凝乳的三种方式

把牛奶的蛋白质「拆散重组」成凝乳，有三种途径，对应三类乳制品：

**酶凝乳（rennet）**：凝乳酶（通常来自小牛皱胃或微生物发酵）专一性地切断 κ-酪蛋白的「毛发层」，胶束失稳、聚集成凝乳——**这是奶酪（cheese）的制作基础**。酶凝乳比酸凝乳温和、可控，能保留更多钙，做成的奶酪弹性更好。

**酸凝乳（acid）**：乳酸菌产酸或直接加酸（柠檬汁、醋），把 pH 降到等电点附近，胶束聚合——**这是酸奶、酸奶油、农家奶酪（cottage cheese）的基础**。酸凝乳通常更细嫩、带酸味。<span class="marginnote">「点豆腐」与「做奶酪」是同一个原理的两张面孔：<strong>豆腐用盐卤/石膏把大豆蛋白调到等电点附近聚沉，奶酪用酸或凝乳酶把酪蛋白聚沉</strong>——蛋白质的「等电点凝乳」，是东方与西方共用的古老技艺。</span>

**热凝乳（heat）**：加热使乳清蛋白变性、在酪蛋白胶束表面聚合成膜——**这是奶皮、蛋奶冻（custard）、某些炖奶制品的机制**。热凝乳不「成块」，而是「成膜、增稠」。

**三种凝乳的区别在「动谁、靠什么」**：酶凝乳动 κ-酪蛋白，靠酶；酸凝乳动全胶束，靠 pH；热凝乳动乳清蛋白，靠热。理解这三种，就理解了一整张乳制品地图。

## 4 乳制品地图：一条奶、五条路

同一桶奶，走不同的工艺就得到不同的乳制品：

| 乳制品 | 关键工艺 | 核心机制 |
| --- | --- | --- |
| 酸奶 | 乳酸菌发酵 | 酸凝乳 |
| 奶酪 | 酶凝乳 + 排乳清 + 熟成 | 酶凝乳、微生物发酵 |
| 黄油 | 搅打奶油、脂肪球聚结 | 破乳（W/O） |
| 炼乳/淡奶 | 脱水浓缩 | 水分蒸发 |
| 奶粉 | 喷雾干燥 | 脱水 |
| 奶油 | 离心分离脂肪球 | 脂肪上浮/离心 |
| 奶皮 | 加热乳清蛋白变性 | 热凝乳 |

**奶酪的「熟成」**：凝乳排出乳清后，微生物与酶在盐与湿度控制下继续作用，把乳清蛋白与脂肪分解出氨基酸、脂肪酸与挥发性分子——**「奶酪越放越有味」的本质是发酵与水解的持续积累**。蓝纹奶酪的「蓝」是青霉菌的孢子，切达的「坚果味」来自特定菌种代谢。<span class="marginnote">「黄油 = 牛奶变黄油」的机制是<strong>「乳浊液类型翻转」</strong>：牛奶是 O/W，搅打时脂肪球不断碰撞、界面膜破裂、脂肪聚结成大团，最终连续相从水变成油——O/W 翻转成 W/O，就是黄油。<strong>乳化（第2篇）与破乳（此处）是同一对化学过程的双向操作。</strong></span>

**奶油的打发**：奶油（脂肪含量 30% 以上）搅打时，脂肪球聚结并包裹空气，形成泡沫——**打发的奶油是「脂肪稳定 + 空气分散」的复合体系**，脂肪含量越高越容易打发、也越稳定。

## 5 乳糖不耐受与乳制品选择

乳制品的化学，还牵涉一个常见的健康问题——**乳糖不耐受**：

**机制**：人体小肠分泌乳糖酶把乳糖分解为葡萄糖与半乳糖才能吸收。**部分人群成年后乳糖酶活性下降**，乳糖无法分解、进入大肠，被肠菌发酵产生气体与渗透性腹泻——这就是「喝牛奶拉肚子」的根源。

**哪些乳制品更「友好」**：发酵乳制品（酸奶、奶酪）的乳糖大多已被乳酸菌消耗——**酸奶比鲜奶更易耐受**；黄油几乎不含乳糖（乳糖溶于水相，随乳清排出）；而鲜奶、炼乳、冰淇淋的乳糖较高。

**辨析｜易错点：** 「乳糖不耐受 = 不能碰任何奶」过于绝对。**发酵乳、硬质奶酪、黄油的乳糖含量通常很低**，多数不耐受人群可以少量尝试。选品看「乳糖含量」而非「奶」这个标签。

## 6 乳品的营养与储存

**营养构成**：牛奶提供**优质蛋白**（酪蛋白 + 乳清蛋白）、**脂肪**（约 3–4%，以脂肪球形式）、**乳糖**（约 4.8%）与**钙、磷、维生素 A、D、B₂**。钙以与酪蛋白结合的「磷酸钙-酪蛋白」形式存在，吸收率好——**「喝奶补钙」有化学基础**。<span class="marginnote">乳清蛋白与酪蛋白的「去向」不同：<strong>乳清蛋白是「可溶的、易被吸收、含支链氨基酸」的功能蛋白</strong>，健身界流行的「乳清蛋白粉」就是从乳清中提取；酪蛋白则在胃中缓慢凝集，供能平缓。<strong>「乳清 vs 酪蛋白」不是好坏，而是释放节奏不同。</strong></span>

**储存与褐变**：鲜奶需冷藏；超高温灭菌（UHT）奶在无菌灌装下可常温保存数月。加热不当会带来两类变化——**褐变**（乳糖与赖氨酸的美拉德反应，久煮牛奶变黄）与**结皮**（乳清蛋白变性膜）。**「牛奶不能反复煮」**：反复加热加速褐变、结皮与营养流失。

**选乳的四问**：要脂肪风味选全脂、要低热量选脱脂（但脂溶性维生素随脂肪减少）、要耐受选发酵乳、要常温储存选 UHT。**乳制品的挑选，本质是「按需求选组分保留度」**——把「一桶奶」的组分按需取舍，就是全部乳品工艺的浓缩。

**「复原乳」「调制乳」「含乳饮料」要分清**：复原乳是奶粉加水还原；调制乳是牛奶 + 调味与强化剂；含乳饮料的「奶」含量常不足一半。**产品名称越精确，组分越接近「奶」的本来面貌**——「看清配料表」同样是乳品化学的日常应用。

## 7 术语速查

| 术语 | 含义 | 一句话 |
| --- | --- | --- |
| 酪蛋白胶束 | 牛奶中的胶体蛋白 | 耐热、不耐酸与凝乳酶 |
| 乳清蛋白 | 可溶性球状蛋白 | 不耐热、奶皮与凝胶的来源 |
| 脂肪球 | O/W 乳浊液的分散相 | 上浮成奶油、破乳成黄油 |
| 等电点（约 4.6） | 酪蛋白净电荷为零的 pH | 酸凝乳的关键 |
| 凝乳酶 | 切断 κ-酪蛋白的酶 | 酶凝乳、奶酪基础 |
| 乳糖 | 葡萄糖+半乳糖的二糖 | 乳酸菌的「燃料」 |
| 乳酸 | 乳糖发酵产物 | 压 pH、触发酸凝乳 |

**把这七格串起来**：牛奶的全部工艺，都在「酪蛋白胶束 + 乳清蛋白 + 脂肪球 + 乳糖」四种组分上做文章——用酸、用酶、用热、用离心，分别导出酸奶、奶酪、奶皮、黄油与奶油。**读懂这张表，就拿到了乳品科学的完整地图**。

## 8 小结

- 牛奶是**乳浊液 + 胶体 + 真溶液的复合体**：脂肪球（O/W）、酪蛋白胶束、乳糖与乳清蛋白溶解。
- 酪蛋白**耐热不耐酸、不耐凝乳酶**；乳清蛋白**不耐热**——两类蛋白的「脾气」决定了乳制品的全部工艺。
- 凝乳有三种途径：**酶凝乳（奶酪）、酸凝乳（酸奶）、热凝乳（奶皮）**——「动谁、靠什么」各不相同。
- **酸奶 = 乳酸菌把乳糖变乳酸**，把 pH 压到等电点附近触发酸凝乳。
- **黄油 = 破乳**（O/W 翻转为 W/O）；奶油打发 = 脂肪聚结 + 包裹空气。
- 乳糖不耐受的根源是**乳糖酶活性下降**；发酵乳与黄油通常乳糖较低。

在下一节，我们把目光从「动物蛋白的奶」转向「植物蛋白的谷」——**谷物、面筋网络与烘焙原理**：看小麦里藏着怎样的弹性网络，撑起了整个面包王国。

牛奶给了我们「胶体与凝乳」的范本，谷物则将展示「淀粉与面筋」的另一套结构语法——两种食材，同一套「组分 → 结构 → 工艺」的分析方法。

而在那之前，先记住牛奶这一课的钥匙：**看懂酪蛋白、乳清蛋白与脂肪球，就看懂了一半的乳品世界**。
