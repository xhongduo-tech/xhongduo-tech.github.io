## 为什么从油脂开始

三大营养素里，碳水供甜与稠、蛋白供结构与性格，**油脂则供「香、酥、脆、滑」**——以及热量密度最高的能量。更重要的是，油脂在高温下的行为（熔点、烟点、氧化）直接决定煎、炸、烤的成败。<span class="marginnote">把油脂看作「三条链 + 一个头」：一个甘油分子接三条<strong>脂肪酸链</strong>。脂肪酸链的「形状」（直不直、有没有双键）决定了油在室温下是液态还是固态——橄榄油是液态、黄油是固态，差别全在链上。</span>

本节围绕三个温度相关的关键词展开：**熔点**（固态还是液态）、**烟点**（能不能高温加热）、**氧化酸败**（为什么油会「哈喇」）。

## 1 三酰甘油与脂肪酸的构造

**油脂（三酰甘油）**：甘油 + 三分子脂肪酸酯化而成。油脂的性质几乎全由脂肪酸决定：

**饱和脂肪酸（saturated）**：碳链上全是单键，链可以伸直、紧密堆叠，分子间范德华力强，**熔点高，室温下呈固态**——猪油、黄油、椰子油的成分多是饱和脂肪酸。

**不饱和脂肪酸（unsaturated）**：碳链上有双键，双键让链「打弯」，分子无法紧密堆叠，**熔点低，室温下呈液态**——橄榄油、菜籽油、鱼油富含不饱和脂肪酸。

**单不饱和**（一个双键，如油酸）与**多不饱和**（多个双键，如亚油酸、α-亚麻酸）的区别，也影响熔点与氧化稳定性。<span class="marginnote">「氢化」就是给双键加氢把弯链拉直，让液态油变成固态起酥油——代价是可能产生<strong>反式脂肪酸</strong>：它熔点高、稳定性好，但增加心血管风险，如今食品工业已尽量回避。<strong>「反式」说的不是双键数目，而是双键两侧氢的方向。</strong></span>

**辨析｜易错点：** 「椰子油健康所以可以随便煎炸」是双重误解。椰子油虽以中链饱和脂肪酸为主、烟点尚可，但它仍是高饱和脂肪；而橄榄油虽「高级」，其多不饱和组分在高温下更容易氧化。**选油要同时看烟点与氧化稳定性，而不是只看「健康标签」。**

## 2 熔点与塑性：油脂的固体形态

油脂没有单一熔点，而是一个**熔点范围**——因为它是多种三酰甘油的混合物。固化过程是不同组分逐次结晶。

**塑性（plasticity）**：固态油脂在室温下呈现「可塑、可涂抹」的性质（黄油、起酥油），因为它内部是**液态油与固态脂肪结晶的混合体**——结晶像骨架，液态油填充其间，外力挤压时结晶滑动、整体变形而不碎裂。<span class="marginnote"><strong>酥皮与千层饼的灵魂就是油脂的塑性</strong>：起酥油在 15–25 ℃ 时保持「硬而不脆、软而不流」的塑性，擀压时把面团分出千万层薄片；温度一高油脂熔化成液体，层就被浸湿粘连，酥层消失——「开酥要在凉爽环境」是这条原理的直接推论。</span>

**烘焙里的油脂温度管理**：打发黄油要「软化」到塑性最佳的温度（约 20 ℃），太低则硬、太高则化成油——「软化黄油」不是「融化黄油」，一字之差，酥性全变。

## 3 烟点：高温加热的安全线与风味线

**烟点（smoke point）**：油脂持续加热到开始**连续冒烟**的温度。超过烟点，油脂开始热解，产生丙烯醛等刺激性气味与有害物，风味变差。

| 油脂 | 大致烟点 |
| --- | --- |
| 特级初榨橄榄油 | 约 160–190 ℃ |
| 黄油 | 约 150–175 ℃（奶固形物先焦） |
| 菜籽油、葵花籽油 | 约 200–230 ℃ |
| 精炼大豆油 | 约 230 ℃+ |
| 牛油（clarified butter / ghee） | 约 250 ℃ |

**烟点受什么影响？** 杂质（游离脂肪酸、磷脂、奶固形物）会显著拉低烟点——所以**澄清黄油比黄油烟点高得多**；反复使用的炸油游离脂肪酸积累，烟点不断下降，这也是「老油不能一直用」的原因。<span class="marginnote">「油炸用油」的选择逻辑：<strong>烟点 > 油炸温度（约 160–190 ℃）+ 稳定不易氧化</strong>。花生油、精炼菜籽油是常见选择；而黄油烟点低，只适合低温煎炒或加在最后提香。</span>

**辨析｜易错点：** 烟点不是「越高越好」。**初榨橄榄油烟点中等但风味极佳**，适合低温炒与凉拌；追求极高烟点的「油烟点油」往往是深度精炼的，风味寡淡。**选油 = 烟点 + 风味 + 氧化稳定性的三角平衡。**

## 4 公式解析：碘值与不饱和度

如何用数字衡量油脂的不饱和度？**碘值（iodine value, IV）**：100 g 油脂所能吸收碘的克数。双键能定量地与碘加成，所以碘值越高，双键越多。

$$\ce{-CH=CH- + I2 -> -CHI-CHI-}$$

- **$\ce{-CH=CH-}$**：脂肪酸链上的双键，是碘加成的靶点。
- **$\ce{I2}$**：一分子碘，被双键加成吸收。一个双键吸收一分子碘。
