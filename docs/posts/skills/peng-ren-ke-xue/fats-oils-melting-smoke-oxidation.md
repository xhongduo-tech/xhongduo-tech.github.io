## 为什么从油脂开始

三大营养素里，碳水供甜与稠、蛋白供结构与性格，**油脂则供「香、酥、脆、滑」**——以及热量密度最高的能量。更重要的是，油脂在高温下的行为（熔点、烟点、氧化）直接决定煎、炸、烤的成败。<span class="marginnote">把油脂看作「三条链 + 一个头」：一个甘油分子接三条<strong>脂肪酸链</strong>。脂肪酸链的「形状」（直不直、有没有双键）决定了油在室温下是液态还是固态——橄榄油是液态、黄油是固态，差别全在链上。</span>

本节围绕三个温度相关的关键词展开：**熔点**（固态还是液态）、**烟点**（能不能高温加热）、**氧化酸败**（为什么油会「哈喇」）。

## 1 三酰甘油与脂肪酸的构造

**油脂（三酰甘油）**：甘油 + 三分子脂肪酸酯化而成。油脂的性质几乎全由脂肪酸决定：

**饱和脂肪酸（saturated）**：碳链上全是单键，链可以伸直、紧密堆叠，分子间范德华力强，**熔点高，室温下呈固态**——猪油、黄油、椰子油的成分多是饱和脂肪酸。

**不饱和脂肪酸（unsaturated）**：碳链上有双键，双键让链「打弯」，分子无法紧密堆叠，**熔点低，室温下呈液态**——橄榄油、菜籽油、鱼油富含不饱和脂肪酸。

**单不饱和**（一个双键，如油酸）与**多不饱和**（多个双键，如亚油酸、α-亚麻酸）的区别，也影响熔点与氧化稳定性。<span class="marginnote">「氢化」就是给双键加氢把弯链拉直，让液态油变成固态起酥油——代价是可能产生<strong>反式脂肪酸</strong>：它熔点高、稳定性好，但增加心血管风险，如今食品工业已尽量回避。<strong>「反式」说的不是双键数目，而是双键两侧氢的方向。</strong></span>

**辨析｜易错点：** 「椰子油健康所以可以随便煎炸」是双重误解。椰子油虽以中链饱和脂肪酸为主、烟点尚可，但它仍是高饱和脂肪；而橄榄油虽「高级」，其多不饱和组分在高温下更容易氧化。**选油要同时看烟点与氧化稳定性，而不是只看「健康标签」。**

## 2 熔点与塑性：油脂的固体形态

油脂没有单一熔点，而是一个**熔点范围**——因为它是多种三酰甘油的混合物。固化过程是不同组分逐次结晶。

**塑性（plasticity）**：固态油脂在室温下呈现「可塑、可涂抹」的性质（黄油、起酥油），因为它内部是**液态油与固态脂肪结晶的混合体**——结晶像骨架，液态油填充其间，外力挤压时结晶滑动、整体变形而不碎裂。<span class="marginnote"><strong>酥皮与千层饼的灵魂就是油脂的塑性</strong>：起酥油在 15–25 ℃ 时保持「硬而不脆、软而不流」的塑性，擀压时把面团分出千万层薄片；温度一高油脂熔化成液体，层就被浸湿粘连，酥层消失——「开酥要在凉爽环境」是这条原理的直接推论。</span>

**烘焙里的油脂温度管理**：打发黄油要「软化」到塑性最佳的温度（约 20 ℃），太低则硬、太高则化成油——「软化黄油」不是「融化黄油」，一字之差，酥性全变。

## 3 烟点：高温加热的安全线与风味线

**烟点（smoke point）**：油脂持续加热到开始**连续冒烟**的温度。超过烟点，油脂开始热解，产生丙烯醛等刺激性气味与有害物，风味变差。

| 油脂 | 大致烟点 |
| --- | --- |
| 特级初榨橄榄油 | 约 160–190 ℃ |
| 黄油 | 约 150–175 ℃（奶固形物先焦） |
| 菜籽油、葵花籽油 | 约 200–230 ℃ |
| 精炼大豆油 | 约 230 ℃+ |
| 牛油（clarified butter / ghee） | 约 250 ℃ |

**烟点受什么影响？** 杂质（游离脂肪酸、磷脂、奶固形物）会显著拉低烟点——所以**澄清黄油比黄油烟点高得多**；反复使用的炸油游离脂肪酸积累，烟点不断下降，这也是「老油不能一直用」的原因。<span class="marginnote">「油炸用油」的选择逻辑：<strong>烟点 > 油炸温度（约 160–190 ℃）+ 稳定不易氧化</strong>。花生油、精炼菜籽油是常见选择；而黄油烟点低，只适合低温煎炒或加在最后提香。</span>

**辨析｜易错点：** 烟点不是「越高越好」。**初榨橄榄油烟点中等但风味极佳**，适合低温炒与凉拌；追求极高烟点的「油烟点油」往往是深度精炼的，风味寡淡。**选油 = 烟点 + 风味 + 氧化稳定性的三角平衡。**

## 4 公式解析：碘值与不饱和度

如何用数字衡量油脂的不饱和度？**碘值（iodine value, IV）**：100 g 油脂所能吸收碘的克数。双键能定量地与碘加成，所以碘值越高，双键越多。

$$\ce{-CH=CH- + I2 -> -CHI-CHI-}$$

- **$\ce{-CH=CH-}$**：脂肪酸链上的双键，是碘加成的靶点。
- **$\ce{I2}$**：一分子碘，被双键加成吸收。一个双键吸收一分子碘。
- **产物 $\ce{-CHI-CHI-}$**：双键加成碘后的饱和产物。**碘被双键「定量吸收」**——测出吸收了多少碘，就能倒推出双键的多少。
- **碘值的读数**：碘值越高 → 双键越多 → 越不饱和 → **熔点越低、越易氧化**。橄榄油碘值约 80，葵花籽油约 130，鱼油可到 170+——**「碘值」是油脂不饱和度的数字身份证**。

**碘值把「口感与保质」连在一起**：低碘值（饱和）油脂熔点高、稳定耐炸；高碘值（多不饱和）油脂熔点低、营养好但易氧化——**「越健康（多不饱和）越易酸败」是同一个化学的两面**。

## 5 氧化酸败：油脂「哈喇」的化学

油脂放置久了出现「哈喇味」，是**氧化酸败（oxidative rancidity）**：

**自动氧化链**：不饱和双键在氧、光、热、金属离子催化下，发生自由基链式反应——**引发（自由基生成）→ 传播（链式氧化）→ 终止（自由基结合）**。中间产物（氢过氧化物）继续分解，生成醛、酮、酸等**挥发性腥臭分子**——「哈喇味」就是这些分子的气味。<span class="marginnote">「哈喇味」的分子来源主要是<strong>醛类</strong>（如己醛、戊醛）——它们阈值低、气味刺鼻。<strong>抗氧化剂（维生素 E、迷迭香提取物、BHA/BHT）的「原理」就是抢走自由基、打断链式反应</strong>——「抗氧化」不是玄学，是自由基化学的工程应用。</span>

**加速氧化的因素**：**多不饱和度高**（双键多）、**温度高**、**光照**、**金属离子（铁、铜）**、**反复加热**（产生新自由基）。这也解释了「炸油不能一直用」：反复高温让氧化与聚合累积，氢过氧化物越积越多。

**氧化 vs 水解酸败**：氧化酸败靠氧、双键（不饱和油脂常见）；水解酸败靠水、酯酶把三酰甘油水解成游离脂肪酸（饱和油脂也发生）——**「油哈喇」与「油发酸」是两种不同的败坏**。

## 6 油脂的保存与选择

把油脂科学落成厨房操作：

**保存**：**避光、密封、阴凉**；金属容器（尤其铜铁）要避免；大瓶油分装成小瓶、少开盖（减少接触氧）；含多不饱和脂肪酸的油（亚麻籽油、鱼油）更娇贵，**宜冷藏、不宜久存**。

**选择**：**煎炸要「高烟点 + 氧化稳定」**（花生油、精炼菜籽油、棕榈油）；**炒菜要「中烟点 + 风味好」**（橄榄油、菜籽油）；**凉拌要「风味优、不需高温」**（初榨橄榄油、核桃油、亚麻籽油）——**选油 = 按烹饪温度与风味需求匹配**。<span class="marginnote">「初榨橄榄油不能高温炒」常被误解：<strong>初榨橄榄油烟点（约 160–190 ℃）虽不及精炼油，但热稳定性并不差</strong>；真正要避免的是「长期高温反复加热」。<strong>「烟点低 ≠ 有毒」，「长期过热 ≠ 健康」</strong>——选油看「用途」，更看「别过度加热」。</span>

**辨析｜易错点：** 「油越贵越好、越健康越耐炸」不成立。**高多不饱和油（亚麻籽油、鱼油）营养好但不耐高温**；耐炸的高温油往往饱和度高。**「营养」「耐炸」「风味」三者难兼得**——这正是油脂化学教给我们的「取舍」：按用途选油，而不是按标签选油。

## 7 术语速查

| 术语 | 含义 | 一句话 |
| --- | --- | --- |
| 三酰甘油 | 甘油 + 三分子脂肪酸 | 油脂的「本体」 |
| 饱和脂肪酸 | 全单键、可伸直 | 熔点高、室温固态 |
| 不饱和脂肪酸 | 含双键、链打弯 | 熔点低、室温液态 |
| 反式脂肪酸 | 双键两侧氢反向 | 起酥油副产物、尽量回避 |
| 烟点 | 开始冒烟的温度 | 高温加热的安全线 |
| 碘值 | 100 g 油吸收碘的克数 | 不饱和度的数字 |
| 塑性 | 固态油可塑可涂 | 酥皮与黄油的灵魂 |
| 氧化酸败 | 自由基链式氧化 | 「哈喇味」的化学 |

**把这八格串起来**：油脂的全部性格，都写在「脂肪酸链的形状」上——饱和则硬稳、不饱和则软嫩易氧化；烟点定用途、碘值定量级、氧化定保质。**一张表，就是油脂化学的完整坐标**。

## 8 小结

- 油脂 = **甘油 + 三分子脂肪酸**；脂肪酸的「饱和/不饱和」决定熔点与稳定性——饱和熔点高、不饱和熔点低。
- 油脂无单一熔点，是一个**熔点范围**；**塑性**（黄油、起酥油）来自「液态油 + 固态结晶」的混合。
- **烟点**是开始冒烟的温度：杂质降低烟点；**油炸选高烟点 + 稳定**，凉拌选风味好。
- **碘值**定量不饱和度：碘值越高，双键越多、熔点越低、越易氧化。
- **氧化酸败**是自由基链式反应：光、热、金属、反复加热加速；**避光、密封、分装**是保存三律。
- 选油是**营养、耐炸、风味的三角取舍**：煎炸选高烟点、炒菜选中烟点、凉拌选风味。
- 氧化酸败由**自由基链式反应**驱动：避光、密封、分装、少反复加热是保存四律。
- 氢化让液态油变固态起酥油，但可能产生**反式脂肪酸**——「反式」指双键两侧氢的方向。

在下一节，我们从「油脂的化学」转向「油脂与水的相遇」——**乳浊液：乳化原理与稳定性**，看让油水平共处的日常奇迹。

而在那之前，先记住油脂的钥匙：**饱和则硬稳、不饱和则软嫩易氧化；烟点定用途、碘值定量级、氧化定保质**——油脂的一切，都写在「脂肪酸链的形状」上。

**关于「好油」的最后一句**：没有「完美」的油，只有「匹配用途」的油——**理解油脂化学，就是为了在煎炸、炒菜、凉拌之间做出有理有据的选择**。
