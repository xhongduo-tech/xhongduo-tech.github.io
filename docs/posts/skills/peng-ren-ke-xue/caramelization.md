## 为什么从焦糖化开始

上一节的美拉德反应需要「糖 + 氨基酸」携手，而**焦糖化（caramelization）**是糖的独角戏：**纯糖（或高糖低蛋白体系）在高温下脱水、裂解、聚合**，生成焦糖色与焦糖香。做糖色、烤布蕾、熬焦糖酱、烤洋葱到微焦，靠的都是它。<span class="marginnote">把两种褐变放一起记：<strong>美拉德是「两个人的褐变」（糖+蛋白），焦糖化是「一个人的褐变」（纯糖）</strong>。美拉德从约 140 ℃ 开始，焦糖化通常要 160 ℃ 以上——<strong>焦糖化是褐变家族里「门槛最高」的一位。</strong></span>

本节主线：**焦糖化怎么发生（反应链条）、产物长什么样（色、香、味的渐变）、怎么控制它（温度、糖种、酸碱性）**。

## 1 焦糖化的反应链条

焦糖化不是一个反应，而是一连串**逐步加深**的热分解：

$$\ce{蔗糖 ->[160-180\,^\circ C] 葡萄糖/果糖 ->[脱水] 脱水糖 ->[裂解] 醛/酮/酸 ->[聚合] 焦糖色素(焦糖烷/焦糖烯/焦糖素)}$$

- **第一步，分解**：蔗糖先熔融、水解/热解为葡萄糖与果糖。
- **第二步，脱水**：单糖脱去水分子，生成脱水糖等中间体——**褐变从这一步开始出现浅金色**。
- **第三步，裂解**：中间体进一步断裂成小分子的醛、酮、有机酸——**这一步产生焦糖的「酸香」与挥发性香气**。
- **第四步，聚合**：小分子聚合成高分子量的棕黑色色素——**焦糖烷（caramelan）、焦糖烯（caramelene）、焦糖素（caramelin）**是颜色逐级加深的三兄弟。

**随着反应推进，颜色从浅金 → 琥珀 → 深棕 → 近黑，风味从甜 → 焦香 → 微苦**——焦糖化是一个「甜度递减、复杂度递增」的过程。<span class="marginnote">「炒糖色」的诀窍全在这条渐变带上：<strong>糖色要炒到「琥珀红亮」就加水停火，再炒就发黑发苦</strong>——深色段聚合成焦糖素，苦味与涩味占据主导。<strong>看见颜色，就是看见反应进度。</strong></span>

## 2 焦糖的香气：不只是「甜」

焦糖的香气来自裂解产生的小分子：

**甜香**：部分焦糖醛（如麦芽酚）带来甜香与焦香。
**坚果香/奶油香**：二乙酰等化合物贡献奶油般的香气。
**微苦**：裂解产物与聚合物带来苦味。

**「焦糖味」是甜、焦、苦、酸的复合体**——这也是为什么「焦糖」不能简单等同「更甜的糖」：它甜味减弱、复杂度大增。<span class="marginnote">把焦糖化与美拉德对照：<strong>美拉德有氨基酸参与，香气更「肉、烤、面包」；焦糖化无蛋白参与，香气更「糖、焦、奶油」</strong>——所以熬焦糖酱配牛奶（加蛋白）会同时触发两种褐变，风味层次更多。<strong>一锅焦糖酱里，两场褐变在联袂演出。</strong></span>

**辨析｜易错点：** 「焦糖色越深越香」不成立。**深色段的焦糖素主要贡献苦与涩，香气反而被焦糊味盖过**。最佳风味窗口通常在「琥珀色到浅棕色」之间——过了这个窗口，甜香让位于苦味。**想香，要停在「中段」，不是「最深处」。**

## 3 影响焦糖化的因素

焦糖化的速率与结果受几个变量控制：

**糖的种类**：果糖最易焦糖化（熔点低、约 110 ℃ 即开始），蔗糖居中，葡萄糖稍高。**果糖含量高的糖（蜂蜜、果葡糖浆）更早变色**——烤物用蜂蜜上色快，与果糖的低温焦糖化有关。

**温度**：温度越高越快，但也越难控制——**160–180 ℃ 是常用的焦糖化窗口**，快速翻动、及时离火是控制手段。

**酸碱**：**碱加速焦糖化**（促进脱水），酸抑制——加一点小苏打能让糖更快变褐；柠檬汁则延缓。

**其他溶质**：水会稀释并降低沸点，**「湿法熬糖」（先加水）比「干法炒糖」（直接干烧）需要更久**，但更易控制、不易烧焦。
