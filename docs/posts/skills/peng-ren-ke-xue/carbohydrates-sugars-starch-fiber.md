## 为什么从碳水化合物开始

第1篇建立了「组分—传热—水—pH—酶—生熟」的框架，第2篇开始逐类拆解三大营养素。第一个登场的**碳水化合物**，是地球上最丰富的有机分子，也是食材中「戏路最宽」的成员：**糖**提供甜味与褐变、**淀粉**提供黏稠与饱腹、**膳食纤维**提供结构与肠道健康。<span class="marginnote">把碳水化合物比作一场接力：单糖是「接力棒」（最小的糖单位），二糖是「两棒相连」，淀粉是「数百上千棒串成的长链」，而膳食纤维是「人体消化酶追不上的异形长链」。名称复杂，本质只是「糖单元的数量与连接方式」不同。</span>

## 1 糖的家族：单糖、二糖与多糖

按糖单元（单糖）的数量，碳水化合物分三档：

**单糖（monosaccharide）**：最简的糖，不能再水解。最常见的是**葡萄糖（glucose）**与**果糖（fructose）**，化学式都是 $\ce{C6H12O6}$，但结构不同——同分异构体。蜂蜜是果糖与葡萄糖的混合物，所以「甜得快、也齁得快」。

**二糖（disaccharide）**：两个单糖脱水缩合而成。**蔗糖（sucrose）** = 葡萄糖 + 果糖，是日常「白糖」；**乳糖（lactose）** = 葡萄糖 + 半乳糖，是奶里的糖；**麦芽糖（maltose）** = 葡萄糖 + 葡萄糖，是淀粉酶水解淀粉的产物、饴糖的主要成分。

**多糖（polysaccharide）**：许多单糖缩合成长链。**淀粉（starch）**是葡萄糖的直链（直链淀粉）与带分支（支链淀粉）聚合物；**纤维素（cellulose）**是另一种葡萄糖链，但连接方式不同，人体无法消化——这就是膳食纤维的主体。<span class="marginnote">淀粉与纤维素都由葡萄糖组成，性质天差地别：淀粉糊化后软糯可食，纤维素却硬韧难嚼。差别只在葡萄糖的<strong>连接键</strong>——α-1,4 键（淀粉）与 β-1,4 键（纤维素）——一个能被淀粉酶切断，一个不能。<strong>同一种原料，键的方向决定命运。</strong></span>

### 常见糖的相对甜度

不同糖的甜度差异很大，常用**蔗糖 = 1.0** 作基准的相对甜度：

| 糖 | 相对甜度 | 备注 |
| --- | --- | --- |
| 果糖 | 约 1.7 | 最甜，蜂蜜的甜来自它 |
| 蔗糖 | 1.0 | 基准 |
| 葡萄糖 | 约 0.7 | 甜度中等 |
| 麦芽糖 | 约 0.4 | 饴糖的甜 |
| 乳糖 | 约 0.4 | 奶的微甜 |

**甜度不是分子量的函数，而是受体亲和力的函数**：果糖比葡萄糖更易结合甜味受体，所以同样 1 g，果糖「显得」更甜。这解释了为什么蜂蜜、果葡糖浆能「少用就很甜」——以及「无糖饮料」里人工甜味剂的甜度为何能达蔗糖的数百倍。**「甜不甜」是分子与受体的关系，不是含糖量的直接翻译。**

## 2 公式解析：脱水缩合与糖的分子式

糖的多级结构，都源自同一个**脱水缩合（condensation）**反应：两个单糖各贡献一个羟基，脱去一分子水，形成糖苷键。

$$\ce{C6H12O6 + C6H12O6 ->[\text{脱水缩合}] C12H22O11 + H2O}$$

逐项拆解：

- **两个 $\ce{C6H12O6}$**：两个单糖（如葡萄糖 + 果糖）作为底物。
- **$\ce{C12H22O11}$**：生成的二糖（如蔗糖），碳原子数相加为 12，氢与氧各少了一个——因为脱去了 $\ce{H2O}$。
- **脱去的 $\ce{H2O}$**：这是「缩合」的字面含义。反向操作叫**水解**——加水把糖苷键打断，正是唾液淀粉酶把淀粉拆成麦芽糖、以及「加水熬糖浆」在做的化学。
- **通用规律**：$n$ 个单糖缩合成多糖，就脱去 $(n-1)$ 个水分子。淀粉的分子式常写为 $\ce{(C6H10O5)_n}$，就是「每个糖单元去掉一个水」的简写。

**这条公式是理解糖类一切的钥匙**：凡是糖，都由「单糖 + 缩合」生成；凡是「变糖」，几乎都是水解把长链拆短——甜度、黏度、褐变能力都随链长改变。<span class="marginnote">甜度与链长成反比：单糖最甜，二糖次之，淀粉完全不甜。所以「嚼馒头嚼久了有甜味」是真实的——唾液淀粉酶把淀粉水解出麦芽糖。厨房里的「甜」常常不是加的糖，而是酶把多糖「解放」成了甜味单糖。</span>

## 3 还原糖与非还原糖：褐变的入场券

按能否被氧化（能否与斐林试剂反应），糖分两类：

**还原糖（reducing sugar）**：分子中保留着可氧化的醛基或酮基，包括葡萄糖、果糖、乳糖、麦芽糖。**还原糖是美拉德反应与焦糖化的必要条件**——它们能提供参与反应的活泼基团。<span class="marginnote">为什么老抽上色快、而纯白糖上色难？老抽里的还原糖（葡萄糖浆）含量高，与氨基酸反应快；白糖虽然能焦糖化，但在含蛋白的菜肴里，还原糖才是「褐变引擎」。烘焙配方里用蜂蜜或葡萄糖浆代替部分砂糖，就是为了多给反应供「燃料」。</span>

**非还原糖（non-reducing sugar）**：蔗糖是典型代表，两个单糖的活泼基团都被糖苷键「锁死」，不能直接参与褐变。但加热或加酸可使蔗糖**水解**（转化）为葡萄糖与果糖——此时它就变成了还原糖。

**辨析｜易错点：** 「白砂糖 = 糖」没错，但「糖 = 还原糖」是错的。焦糖化需要蔗糖的高温直接脱水，而美拉德需要还原糖参与——两种褐变、两种糖、两种温度窗口。第四篇会详细区分。

## 4 膳食纤维：不被消化的结构多糖

膳食纤维包括**纤维素、半纤维素、果胶、木质素**等，共同点是人体消化酶无法水解，直接进入大肠：

**不可溶纤维**（纤维素、木质素）：不溶于水，增加粪便体积、促进肠蠕动，来源是全谷物、蔬菜筋、果皮。

**可溶纤维**（果胶、β-葡聚糖、魔芋葡甘聚糖）：溶于水形成黏稠凝胶，延缓胃排空、调节血糖与血脂，来源是燕麦、苹果、柑橘、秋葵。<span class="marginnote">果胶还是果酱「凝胶成型」的主角：果胶 + 糖 + 酸，三者缺一不可才能把果汁凝成果酱。果胶的凝胶能力在《果蔬》与《分子料理》里还会以「质地图」的身份反复出现。</span>

**厨房里的纤维作用**：纤维撑起植物细胞壁，决定蔬菜的脆韧；纤维吸水膨胀，让粗粮有「饱腹感」；纤维也是「久煮不烂」的元凶——炖芹菜永远不像炖土豆那样化为软泥，因为纤维骨架降解极慢。

## 5 碳水化合物的烹饪角色总览

把糖类放在烹饪坐标系里，各司其职：

| 角色 | 代表 | 温度窗口 | 关键行为 |
| --- | --- | --- | --- |
| 甜味 | 蔗糖、蜂蜜 | 室温即甜 | 溶解、配比 |
| 褐变 | 还原糖 | 140 ℃+ | 美拉德 / 焦糖化 |
| 增稠 | 淀粉 | 60–90 ℃ | 糊化 |
| 凝胶 | 果胶、琼脂 | 降温固化 | 形成凝胶网络 |
| 结构 | 纤维素、半纤维素 | 耐热 | 撑起细胞壁 |

**辨析｜易错点：** 「低糖 = 不褐变、不增稠」是常见误判。低糖点心里若用了大量淀粉，糊化照常发生、口感依旧黏糯；若用了还原糖浆，褐变照常发生。「糖」的角色是多重的，去掉它要同时评估甜、色、稠、结构四种功能。

## 6 小结

- 碳水化合物分**单糖、二糖、多糖**三档，由**脱水缩合**逐级生成，反向为**水解**。
- **脱水缩合公式** $\ce{C6H12O6 + C6H12O6 -> C12H22O11 + H2O}$：糖类全由「单糖 + 缩合」生成，反向为「水解」——甜度、黏度、褐变能力随链长改变。
- 还原糖（含醛/酮基）是**美拉德与焦糖化的必要条件**；蔗糖是非还原糖，加热/加酸水解（转化）后才可参与褐变。
- 膳食纤维分**可溶**（果胶、β-葡聚糖，凝胶控血糖）与**不可溶**（纤维素，增体积促肠动）。

## 7 术语速查

| 术语 | 含义 | 一句话 |
| --- | --- | --- |
| 单糖 | 最简糖（葡萄糖、果糖） | 甜、易褐变 |
| 二糖 | 蔗糖、乳糖、麦芽糖 | 两单糖缩合 |
| 多糖 | 淀粉、纤维素 | 长链聚合物 |
| 还原糖 | 含醛/酮基的糖 | 褐变的「入场券」 |
| 非还原糖 | 蔗糖（活泼基团被锁） | 转化后才可褐变 |
| 膳食纤维 | 不可消化的多糖 | 可溶/不可溶两类 |
| 淀粉 vs 纤维素 | α-1,4 vs β-1,4 | 键方向决定命运 |

**把这七格串起来**：碳水化合物 = 「糖单元的数量与连接方式」——单糖最甜、多糖不甜；还原糖管褐变、纤维管结构；淀粉糊化、果胶凝胶，各司其职。

## 8 糖类在烹饪中的角色

**「甜」与「褐」的分离**：甜味靠蔗糖/蜂蜜（室温即甜），褐变靠还原糖（140 ℃+）——「低糖点心不褐变」的说法要分情况。

**「嚼馒头有甜味」是真的**：唾液淀粉酶把淀粉水解出麦芽糖——**「甜」不一定是加的糖，可能是酶把多糖「解放」了**。
