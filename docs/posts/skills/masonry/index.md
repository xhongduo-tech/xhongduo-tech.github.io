# 瓦工（砌筑、抹灰与瓷砖铺贴）

砌筑、抹灰与瓷砖铺贴是建筑与家装施工中的核心工种，覆盖砌体结构施工到饰面装修的关键环节。以《国家职业技能标准—砌筑工》为纲，结合 GB 50203《砌体结构工程施工质量验收规范》与 JGJ/T 314-2016《建筑工程施工职业技能标准》，系统重建从砌体材料、砌筑工艺到抹灰饰面、瓷砖铺贴与质量验收的完整瓦工技能体系。学完这些章节，就写完了砌筑、抹灰与瓷砖铺贴所需的全部内容。

## 对标教材
