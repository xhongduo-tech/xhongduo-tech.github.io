# 游泳技能与水上安全

游泳是最重要的生存自救技能之一，掌握游泳技能与水上安全知识既能在水中自救，也是成为游泳社会体育指导员与救生员的起点。以国家体育总局《游泳社会体育指导员培训大纲》《游泳救生员国家职业技能标准》和中国游泳协会《游泳教学训练》为纲，系统重建从水中适应、基本泳姿到水上救生与职业规范的完整知识技能体系。学完这些章节，就写完了从入门学泳到持证上岗救生的全部内容。

## 对标教材

- 国家体育总局《游泳社会体育指导员培训大纲》
- 《游泳救生员国家职业技能标准》
- 中国游泳协会《游泳教学训练》
