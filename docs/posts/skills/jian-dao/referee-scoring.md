## 为什么从裁判判定开始

上一章我们定义了「什么样的打击算一本」——气势、姿势、部位、刃筋、残心，五条标准。但标准写在纸上是一回事，落到电光石火的比赛瞬间是另一回事：两个人同时出刀、竹刀交错的刹那，裁判凭什么判定这一击有效、那一击无效？这一章，我们走进裁判席，看**剑审**如何把规则执行成判罚。<span class="marginnote">把裁判制度比作第二级数学里的「多个证明者互相校验」：单个裁判可能看漏、看错，所以剑道用「三名裁判 + 多数一致」来降低误判——就像高风险的证明需要多个独立验证，比赛的关键判罚也要多个独立视角共同背书。这是「以制度对抗个体误差」的经典设计。</span>

这套制度依据**全日本剑道联盟《剑道裁判规则》**。它的核心可以用一句话概括：**三审制、旗判定、多数决**。下面逐一拆开。

## 1 三名裁判：主审与副审

每场剑道比赛配备 **3 名裁判**：

**主审（しゅしん）**：站在场地**中央**，负责主持比赛——发令（始め/待て）、控制节奏、宣告有效打突、处理反则、主持合议与判定。可以理解为比赛的「主持人 + 第一位裁判」。
**副审（ふくしん）**：站在场地**两个对角**，各持两面旗，负责从自己的角度独立判断有效打突与反则。<span class="marginnote">为什么副审站在对角而不站在两侧？因为剑道的打击瞬间极快，从正面看与从侧面看的结论可能完全不同——对角的视野能同时看到两名选手的正面与侧面，覆盖主审可能看不到的角度。三名裁判站位呈三角形，就是为了「多角度交叉验证」。</span>

**三审制的关键原则**：三名裁判**地位平等、独立判断**。副审不是主审的下属——在「是不是一本」这件事上，三人的判断权重完全相同，**不因主审「官大」而多一票**。主审的特殊性只在于「主持」职责，不在于「裁决」特权。这一点常常被误解，值得牢记。

## 2 有效打突的判定：五要素复核

裁判判定一本，靠的不是「感觉」，而是对上一章五条标准的**逐项瞬间复核**：

1. **气势**：打击瞬间有没有充实的气合与精神？
2. **姿势**：身体姿态是否正确、稳定、不失控？
3. **部位**：是否打中面/小手/胴/突这四个有效部位？
4. **刃筋与物打**：是否用竹刀的物打部分、以正确的刃筋击打？
5. **残心**：打击后是否保持戒备、能立即应对反击？

五个条件**缺一不可**——任一条件不满足，裁判就不会举旗。<span class="marginnote">裁判瞬间要在零点几秒内把五条全核一遍，靠的是长期训练形成的「模式识别」：看得多了，一眼就能看出「这一击的气势到了、刃筋偏了」「这一击全对但残心没了」。这就像第一级数学老师批改作业——看到过程就知道结果对不对，因为评判标准已经内化成了直觉。成为好裁判，本身就是一门「判例积累」的功夫。</span>

**常见的「差一点不算一本」**：力度不够的轻触、刃筋歪掉的斜砍、打完后立刻松懈丢掉残心、以及双方几乎同时打中（同时）的打击——这些都可能在「五要素」上扣分，导致不算一本。下一章《犯规行为与警告、罚则》里，还会看到「不被判一本的打击」与「被判犯规的行为」之间的边界。

## 3 旗判定与合议

**旗判定**：每名裁判手持**两面旗**——红色与白色，分别代表两名选手（由抽签或登记确定红方/白方）。当裁判判断某一方打出了有效打突，就**朝该方举起相应颜色的旗**，并喊出「**面あり**」「**小手あり**」等宣告。

**多数决**：**同一本需要至少 2 名裁判同时举旗才成立**。三人中只有一人举旗，不算一本——比赛继续。这个「2/3 多数」设计，是防止「一名裁判看走眼」的最直接保险。<span class="marginnote">有心的读者会发现：2/3 多数决意味着「少数派不会翻盘」，但也意味着「可能真的判错」（三人全看错时无法避免）。剑道接受这种不完美——因为它优先保障「判罚的一致性与可预期性」，而不是「每一次都绝对正确」。这提醒我们：规则的价值有时不在于永远正确，而在于让结果可解释、可接受。</span>

**合议（ごうぎ）**：当情况复杂、裁判们意见不一致或主审拿不准时，主审可宣布「合議」，召集两名副审到场边协商。合议后**重新举旗表决**，仍按多数决确定结果。合议不是「讨论出最优解」，而是「把分歧摆到台面上再表一次决」——它给裁判一个修正的机会，也让判罚过程更透明。

**判定（はんてい）**：这是「平局裁决」专用的举旗程序——上一章提过，规定时间内双方 0 比 0 且不延长（或延长后仍无胜负），主审宣布「判定」，三名裁判**同时举旗**指向自己认为胜的一方。判定依据是**技能优劣优先、试合态度次之**，不依据场面是否热闹。

## 4 裁判的口令与位置

裁判通过一套标准口令控制比赛，初学者第一次参赛或看比赛时，先认识这些口令就不会懵：

| 口令 | 罗马音 | 含义 |
| --- | --- | --- |
| 始め | hajime | 开始/继续比赛 |
| 待て | matte | 暂停比赛 |
| 分かれ | wakare | 让双方分开，回到开始线 |
| 続行 | zokko | 暂停后继续 |
| 面あり 等 | men ari | 宣告有效打突（部位 + あり） |
| 合議 | gōgi | 召集裁判合议 |
| 判定 | hantei | 平局时举旗裁决 |
| 反則 | hansoku | 宣告犯规 |

**裁判的站位与移动**：主审在场地中央，随比赛移动；两名副审在对角。裁判要保证**自己的视野不被遮挡**、随时能看清双方——如果选手攻到自己正前方挡住了视线，裁判要主动移步换位。这要求裁判本身有相当的剑道功底，能预判攻防走向。

## 5 主审与副审的分工

虽然三人在「判一本」上权利平等，但职责各有侧重：

**主审**：发令与控场——何时开始、何时暂停、计时与比分管理、反则宣告、合议主持、判定主持。主审是比赛的「交通警察」，保证比赛按规则流畅进行。
**副审**：专注判罚——从自己的角度观察有效打突与反则，举旗表达判断。副审是「计分员」，用自己的眼睛为比分负责。<span class="marginnote">一个好的副审要学会「只盯球不看戏」：不被场面的精彩带偏，只盯自己职责范围内的判罚。这就像做研究的审稿人——评审的是「方法是否成立」，而不是「故事是否好看」。裁判的「中立」，就是在训练这种「只对规则负责」的定力。</span>
- **共同职责**：三者都要观察**反则**（场外、倒下、危险动作等），任一裁判看到反则都有义务举旗或报告主审；三者都要对选手安全负责，发现危险情形可主动叫停。

**辨析｜易错点：被举旗不算得分 ≠ 被判犯规。** 选手最容易混淆两个概念：「这一击没算分」和「这一下犯规了」。没算分，只是「五要素没满足」，不惩罚；被判反则，才是「违反了规则」，要承担罚则（下一章讲）。很多选手在被举旗否定后以为「自己犯规了」，其实是两码事——分清这两者，是理解裁判制度的第一步。

## 6 裁判的养成：从选手到剑审

裁判不是天生的——每名裁判都先是选手，再经过系统训练走上裁判席。全日本剑道联盟对裁判的要求可以概括成三句话：**公正无私、熟悉规则、精通剑道**。

- **精通剑道**是前提：裁判本身要有相当的剑道水平（通常要求高段位），才能在零点几秒内看清打击的刃筋与时机——「看不懂的人」没法判「打得好不好」。
- **熟悉规则**是底线：对有效打突的五要素、反则的完整清单、判定的程序烂熟于心——这是可以通过讲习会、规则考试系统补课的。
- **公正无私**是品格：不偏袒、不怯场、敢举旗。裁判讲习会里常说一句话：「**判错不可怕，可怕的是因为怕判错而不敢判**」——犹豫不决的裁判，比偶尔判错的裁判更伤害比赛。

**裁判的进阶路径**：许多剑道人会在自己修行到一定段位后，同时走上「选手 + 裁判」双线——一边继续稽古，一边参加裁判讲习、在地区大会担任裁判，逐步从副审做到主审。这个「既当选手又当裁判」的视角，反过来会极大提升你自己的剑道：**判过别人的打击，你才真正懂得自己的打击差在哪里**。这与试合稽古里「自审」的练习一脉相承——裁判，是剑道修行的另一条路。

## 7 核心对比表：裁判体系速览

| 项目 | 主审 | 副审 |

| 位置 | 场地中央 | 场地两对角 |

## 8 小结

- 剑道比赛采用**三审制**：主审（中央，主持）+ 2 名副审（对角，判罚），三人**地位平等、独立判断**。
- 判定一本靠**五要素瞬间复核**：气势、姿势、部位、刃筋与物打、残心，缺一不可。
- **旗判定 + 多数决**：同一本需至少 2 名裁判同时举旗；一人举旗不算。
- **合议**：裁判意见分歧时由主审召集，重新表决，仍按多数决。
- **判定**：平局裁决时三名裁判同时举旗，技能优先、态度次之。
- 主审管「流程」，副审管「判罚」；三人都要观察反则、对选手安全负责。
- 分清「没算分」与「被判犯规」是两回事——前者是标准未满足，后者是规则被违反。
- 裁判本身通常先是高段位选手：**精通剑道、熟悉规则、公正无私**——「判错不可怕，怕的是不敢判」。
- 裁判进阶常走「选手 + 裁判」双线：判过别人的打击，才更懂自己的打击差在哪里。
- 裁判要主动移步换位：视野被遮挡时要移动，保证随时看清双方——「好裁判是站出来的，不是站出来的位置」。
- 有效打突的判定是「零点几秒内的五要素复核」——判得多，五条标准就内化成直觉。
- 裁判的口令是比赛的「通用语」：始め、待て、分かれ、あり、反則——选手与观众都该认得。
- 合议是「把分歧摆上台面再表一次决」——它给裁判修正的机会，也让判罚更透明。
- 三审制 + 多数决是「以制度对抗个体误差」的经典设计：三个视角交叉验证，2/3 才成立。

在下一节，我们从「什么算一本」转向「什么算犯规」：**犯规行为与警告、罚则**——场外、倒下、危险动作、不尊重对手，哪些行为会被判反则？两次反则为什么等于送对手一分？判罚的阶梯，正是剑道比赛价值观的另一半。
