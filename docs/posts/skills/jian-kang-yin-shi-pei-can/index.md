# 健康饮食与营养配餐

健康饮食与营养配餐是以均衡膳食、营养素配比为核心的实用科学，支撑着家庭日常膳食的健康化与科学化。以《中国居民膳食指南（2022）》、《营养与食品卫生学》、《公共营养师》为纲，系统重建从膳食指南、营养素基础、营养评价到食谱编制与家庭营养配餐实践的完整链条。学完这些章节，就掌握了从读懂膳食指南到为全家设计一周健康餐单的全部基础。

## 对标教材

- 《中国居民膳食指南（2022）》（中国营养学会）
- 《营养与食品卫生学》（人民卫生出版社，全国高等学校教材）
- 《公共营养师》（国家职业资格培训教程）
