# 中华饮食文化史

中华饮食文化史研究从先秦到当代中华饮食的发展脉络、烹饪技术演进与饮食观念，涵盖食制、食礼、饮食民俗、饮食审美与饮食思想，是理解中华文明的独特入口。以王学泰、赵荣光的两本《中国饮食文化史》及《饮食文明》为纲，从史前熟食到当代饮食文明，系统写完整门学科。

## 对标教材

- 王学泰《中国饮食文化史》（广西师范大学出版社）
- 赵荣光《中国饮食文化史》（上海人民出版社）
- 《饮食文明》
