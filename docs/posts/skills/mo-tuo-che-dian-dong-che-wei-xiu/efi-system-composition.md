## 为什么从电喷开始

电喷（EFI，电子燃油喷射）是现代摩托车的标配。它用**ECU（电子控制单元）**根据传感器采集的工况，精确控制喷油量与点火时刻，比化油器更省油、更环保、动力响应更好。<span class="marginnote">上一节学的化油器是「纯机械计量」，电喷是「电子计量」：<strong>同一套「空燃比」概念，从物理结构搬进了程序</strong>。理解电喷，关键看三件事——ECU 怎么「看」（传感器）、怎么「想」（计算）、怎么「做」（执行器）。</span>

这一节讲电喷的骨架：系统组成、燃油供给、喷油与进气控制，最后用喷油量计算把「传感器数据如何变成喷油指令」串起来。

## 1 电喷系统组成：感知—决策—执行

电喷系统分三大块：

**传感器（感知）**：把工况翻译成电信号。核心传感器见下表：

| 传感器 | 测量对象 | 信号特点 |
| --- | --- | --- |
| 进气压力/流量 | 进气量 | 电压/频率变化 |
| 节气门位置（TPS） | 油门开度 | 电压随转角变化 |
| 曲轴位置（CPS） | 转速与曲轴角 | 脉冲信号 |
| 冷却水温（ECT） | 发动机温度 | 负温度系数电阻 |
| 进气温度（IAT） | 进气温度 | 负温度系数电阻 |
| 氧传感器（O₂） | 排气含氧量 | 电压约 0.1–0.9V |
| 车速传感器 | 车速 | 脉冲 |

**ECU（决策）**：接收传感器信号，查表+计算，输出喷油脉宽与点火提前角。ECU 里存有**标定脉谱图（MAP）**——转速×负荷→喷油量的二维表，是电喷的「化油器曲线」。

**执行器（执行）**：把电信号变成机械动作——**喷油器**（电磁阀，通电喷油）、**点火线圈**（点火）、**怠速控制阀**（调节怠速进气）等。<span class="marginnote">理解电喷的一句话：<strong>ECU 是个「查表器」</strong>。表是工程师标定好的，传感器的任务是把车况翻译成表的下标，执行器的任务是把表的结果翻译成动作。修电喷，就是查这张表的「输入」和「输出」谁出了错。</span>

## 2 燃油供给系统

燃油供给由**燃油泵、燃油滤清器、燃油压力调节器、喷油器、油管**组成。

**燃油泵**：装在油箱内的电动泵，通电后建立油压（一般 250–350 kPa）。泵不转 → 无油压 → 不能启动。燃油泵靠汽油冷却，**长期低油位行驶会让泵过热、缩短寿命**。

**燃油压力调节器**：保持油轨油压与进气歧管压力的差值恒定（恒压差），这样喷油量只由喷油脉宽决定。调节器回油管堵塞 → 油压偏高 → 混合气偏浓。

**喷油器**：电磁阀式。通电时间（**喷油脉宽**）决定喷油量。喷油器堵塞 → 喷油雾化差 → 怠速抖、动力差；密封不严滴油 → 热车难启动、冒黑烟。

**供油回路**：燃油泵 → 滤清器 → 油轨 → 喷油器 → 压力调节器 → 回油箱。检修时先查泵压（用油压表接在油轨测试口），无油压先从泵的供电/搭铁查起。

## 3 喷油控制：开环与闭环

ECU 决定喷多少油，分两种模式：

**开环控制**：ECU 根据转速、负荷（进气压力/节气门开度）、水温等查表算出喷油量，不参考排气反馈。用于冷启动、急加速、大负荷等工况。

**闭环控制**：氧传感器监测排气含氧量，反馈给 ECU 修正喷油量，使空燃比收敛到理论值附近（约 14.7:1）。用于怠速、巡航等稳定工况。<span class="marginnote">闭环是「带反馈的自动控制」：<strong>O₂ 电压偏浓（≈0.8V），ECU 就减油；偏稀（≈0.1V），ECU 就加油</strong>，形成振荡收敛。氧传感器坏了或加热器断，闭环退化为开环，油耗会上升。</span>

**喷油正时**：曲轴位置传感器提供曲轴角信号，ECU 在进气冲程某一相位喷油；多点喷射（MPI）每缸一个喷油器，顺序喷射。

## 4 进气控制：节气门与怠速

进气量决定基本喷油量。电喷用两种方式测进气：**进气道压力（MAP）+ 转速**推算（速度-密度法），或**空气流量计（MAF）**直接测（质量流量法）。摩托车上 MAP 法更常见。

**节气门位置传感器（TPS）**：装在节气门轴上的电位器，ECU 用它判断「怠速、部分负荷、全负荷」三种状态——急加速时依据 TPS 变化率额外加浓（加速修正）。

**怠速控制**：冷车时 ECU 开大怠速阀（或步进电机）增加进气，自动提高怠速（快怠速）；热车后逐步关小。怠速不稳除了节气门脏，还有可能是怠速阀卡滞或 TPS 未校准。<span class="marginnote">电喷车节气门脏是「通病」：<strong>积碳改变了节气门关闭位置，怠速进气量异常</strong>。清洗节气门后通常要做 TPS 复位/怠速学习，让 ECU 重新记忆基准。</span>

## 5 公式解析：喷油量怎么算

喷油器的喷油量由**喷油脉宽**决定，脉宽由三部分构成：

$$
T_{\text{inj}} = T_{\text{base}} \times C_{\text{temp}} \times C_{\text{corr}} + T_{\text{bat}}
$$

- $T_{\text{base}}$：基本喷油脉宽——由转速与进气量查标定表得到；
- $C_{\text{temp}}$：温度修正系数——冷车时 >1（加浓），热车时 ≈1；
- $C_{\text{corr}}$：其他修正（加速加浓、氧反馈修正、海拔修正等），闭环时由氧传感器输出实时调整；
- $T_{\text{bat}}$：无效喷射时间补偿——喷油器开启存在机械延迟，电压低时补偿加大。

**公式解析**：基本脉宽是「标定的骨架」，修正系数是「根据实况微调」，补偿项是「扣除机械延迟」。闭环修正 $C_{\text{corr}}$ 在 1 附近小幅振荡，说明空燃比被控制在理论值附近；若 $C_{\text{corr}}$ 长期偏离 1 很多，说明基础标定或硬件出了偏差——比如进气漏气，ECU 要持续加大喷油去补偿。<span class="marginnote">看数据流时，<strong>长期燃油修正（LTFT）持续偏大，提示有「漏气/缺油」类硬故障</strong>，不是 ECU 程序问题——它已经补偿到极限了。</span>

**易错点**：喷油脉宽的单位是毫秒（ms），怠速约 2–4 ms，大负荷可达 8 ms 以上；脉宽「看着正常」不代表喷油器雾化好——堵塞的喷油器同样脉宽喷出的油更少，动力会下降。

## 6 电喷系统的电源与搭铁基础

电喷系统对供电质量极其敏感，维修时先确认「电源三路」都正常：

**常电**：电池直接供电给 ECU 记忆电源（保存故障码与学习值）与燃油泵继电器。常电断路 → 故障码丢失、学习值清零，但车还能启动。

**钥匙电（ON 电）**：钥匙打开后供 ECU 主电源、喷油器、点火、传感器。钥匙电断 → ECU 不工作，启动不了。

**搭铁**：ECU 与各传感器需要干净的搭铁参考。**搭铁不良是电喷系统最难查的隐性故障**——信号电压漂移、数据流「看着不对又查不出」、偶发熄火，常常是搭铁螺丝松动或锈蚀。<span class="marginnote">查搭铁的规范动作：<strong>测 ECU 搭铁脚与电池负极之间的电压降</strong>——怠速时压降应接近 0V；压降大说明搭铁回路接触不良，要清洁、紧固搭铁点。</span>

**ECU 供电检查顺序**：电池电压 → 主保险 → 继电器 → ECU 插头各电源脚（常电/ON 电）→ 搭铁压降。**换 ECU 前，这五步必须全部确认**——很多「ECU 坏了」其实是供电或搭铁问题。

**检修实操**：测 ECU 插头时用探针或细铜丝从插头尾部插入（不要退针），对照电路图量各脚电压；拆 ECU 插头先断电池，防止热插拔损坏 ECU。**插头端子氧化退针是电喷「疑难杂症」的高发源头**，排查顺序永远排在换件之前。

### ECU 各电源脚快速判定

接到一台电喷车，先给 ECU 的「电源三路」做个快速体检：

| 测试点 | 正常值 | 异常指向 |
| --- | --- | --- |
| 电池电压 | 12V 上下 | 电池/充电系统 |
| ECU 常电脚 | 电池电压 | 常电保险、线束 |
| ECU ON 电脚 | 钥匙开后 = 电池电压 | 钥匙开关、继电器 |
| ECU 搭铁压降 | <0.2V | 搭铁点接触不良 |
| 传感器参考电压 | 5V | ECU 电源/参考电路 |

**易错点**：参考电压（5V）异常时，先把传感器全部拔下再测——**某只传感器内部短路，会把 5V 参考电压拉垮**，导致所有传感器信号异常。拔下恢复正常，就找到了元凶。

## 7 小结

- 电喷三块：**传感器（感知）、ECU（决策）、执行器（执行）**；ECU 本质是「查表器」。
- 供油链路：**燃油泵→滤清器→油轨→喷油器→压力调节器→回油箱**；先查泵压再查喷油器。
- 两种模式：**开环（查表不反馈）**与**闭环（氧反馈修正）**；闭环坏则油耗升。
- 进气控制：MAP/MAF 测进气量，TPS 判工况，怠速阀管冷车快怠速。
- 喷油量 = **基本脉宽 × 修正系数 + 补偿**；长期修正偏大提示硬故障。
