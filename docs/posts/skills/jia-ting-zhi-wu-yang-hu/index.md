# 家庭植物养护与庭院园艺

家庭植物养护与庭院园艺是让居所与绿色自然相融的实用技艺，系统覆盖室内绿植、阳台菜园与庭院花园的种植、养护与设计全流程。学完这些章节，就掌握了从土壤、光照、浇水到繁殖与病虫害防治的完整养护基础，以及从阳台到庭院的园艺规划能力。
