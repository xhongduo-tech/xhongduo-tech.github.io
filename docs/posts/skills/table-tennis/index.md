# 乒乓球运动

乒乓球是中国的国球，集速度、旋转与战术智慧于一身，是全球普及度最高的球类运动之一。以 ITTF《乒乓球竞赛规则》、《乒乓球运动教程》与《中国青少年乒乓球训练教学大纲》为纲，从场地器材、基本技术、发球接发球与弧圈技术，到 11 分制竞赛规则与青少年训练体系，系统学完这项运动的全部核心内容。

## 对标教材

- ITTF《乒乓球竞赛规则》
- 《乒乓球运动教程》（体育院校通用教材）
