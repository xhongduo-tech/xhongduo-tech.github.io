# 马拉松与长跑

马拉松与长跑是参与人数增长最快的全民耐力项目，涵盖路跑竞赛规则、有氧训练体系与配速策略。以 World Athletics《路跑赛事规则》、《丹尼尔斯经典跑步训练法》与中国田径协会《马拉松赛事管理办法》为纲，系统重建从看懂比赛、组织赛事到科学训练、稳定完赛并提升个人成绩的完整能力链。

## 对标教材

- World Athletics《路跑赛事规则》
- 《丹尼尔斯经典跑步训练法》
- 中国田径协会《马拉松赛事管理办法》
