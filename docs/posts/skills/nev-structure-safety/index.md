# 新能源汽车结构与维修安全

以 GB 18384-2020《电动汽车安全要求》、GB/T 18488《电动汽车用驱动电机系统》与工信部《新能源汽车生产企业及产品准入管理规定》为纲，系统学习新能源整车高压电气结构与维修安全规范。新能源车年销超千万辆，掌握高压电气结构与安全维修，是新兴亟需规范化的职业技能。

## 对标教材

- GB 18384-2020《电动汽车安全要求》
- GB/T 18488《电动汽车用驱动电机系统》
