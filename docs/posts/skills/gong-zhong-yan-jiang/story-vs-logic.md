# 讲故事还是讲道理：观点、主张与论据

<div class="epigraph">

## 为什么从故事与论据开始

观点定了、角色定了、主线也有了，接下来是整场演讲的「血肉」问题：**用什么材料去支撑那个核心观点？** 多诺万在《TED演讲的秘密》第 2 章给出一个看似简单的选择——讲故事，还是讲道理？但问题远不止「二选一」。这一节我们要拆清楚两件事：故事与论据各自擅长什么，以及**观点、主张、论据**三者如何咬合成一个说服的链条。

这个问题为什么值得单独一节？因为它是演讲者最早遇到的「技术分岔口」：写稿时第一反应往往是「我要不要先讲个段子开场」，或者「我要不要先甩数据镇场」。这两个冲动都对，也都不全对——**用错的场合，故事显得煽情，数据显得冷硬**。<span class="marginnote">故事与论据不是「选哪个」，而是「怎么配比」。心理学里的「双通道说服」研究（ELM）指出：人们既走<strong>中央路径（理性评估论据）</strong>，也走<strong>外周路径（被情感与叙事打动）</strong>——成熟的演讲者两条路都铺。这一话题与第八级《社会心理学》的「说服」研究紧密相连。</span>

## 1 两种支撑材料的分工

**故事（story）**：一段有主角、有冲突、有转折、有时间推进的具体经历。故事的作用是**把听众「带进去」**——让听众以第一人称的视角「经历」一次你的经验，从而在感受层面相信你说的东西。

**论据（evidence）**：数据、事实、逻辑推理、权威结论。论据的作用是**把「带进去」升级为「站得住」**——让听众在理性层面确认：这个故事不是孤例，这个观点有更硬的支撑。

两者的分工可以概括为一句话：**故事负责「让人信」，论据负责「让人确认」**。故事先行，听众「愿意信了」；论据随后，听众「确信自己没有信错」。<span class="marginnote">「先故事后论据」之所以高效，是因为它顺应了听众的接受顺序：<strong>人先被情感打开，才肯让理性接手</strong>。你一上来就甩 40 页数据，听众的第一反应是防御；先讲一个具体的人遇到了具体的麻烦，听众才会问「后来呢？」——这时再给论据，是「解答疑问」，而不是「强加结论」。</span>

## 2 观点、主张与论据：说服的三层结构

多诺万把「说服材料」拆成三个层次，很多人把它们混成一团，这正是说服无力的根源：

**观点（opinion）**：你「认为」的东西，是最宽泛的一层。「我认为睡眠很重要」——这是观点，但它只是起点。
**主张（claim）**：观点被「收窄成一句可检验的断言」，具备「可以被支持或被反驳」的性质。「睡眠不足会显著损害工作记忆」——这是主张，它比观点小，但比观点强。<span class="marginnote">观点与主张的区别，是「有没有长出可检验的形状」。观点是「我觉得重要」，主张是「我可以证明它造成这些后果」。<strong>可检验性是主张的身份证</strong>——无法检验的断言，只能停留在「观点」的层次。</span>
**论据（evidence）**：支撑主张的事实与逻辑。「一项对照实验显示，连续 5 天睡眠不足的受试者，工作记忆得分平均下降 18%」——这是论据，它让主张从「你说得对」升级为「数据确实如此」。

三层的关系是：**观点收窄成主张，主张靠论据落地**。演讲中只说观点，是「空谈」；只说主张不给论据，是「断言」；给了论据而不收束成主张，是「数据倾泻」。完整的说服链是：**观点 → 主张 → 论据 →（回到）主张**——用论据把一个收窄了的主张「顶住」。

## 3 怎么选：主题的性格决定材料的配比

故事和论据不是 1:1 平均分配，而是**看你的观点「是什么性格」**。多诺万的建议是：先判断观点属于「价值型」还是「实证型」，再定配比。

**价值型观点**（应该做什么、什么是好的/对的）：这类观点天然靠近故事。因为价值问题没有「唯一正确答案」，说服它靠的是「共鸣」——而共鸣只能通过具体的人物与经历抵达。「应该给医护人员更好的待遇」——你最好先讲一位护士的夜班故事，再谈制度分析。

**实证型观点**（世界是什么样、机制如何运作）：这类观点天然靠近论据。因为听众想知道「你怎么知道」，你得给出可验证的证据。「大语言模型的幻觉源于自回归的目标函数」——你需要实验、数据、机制推演，故事只是引子。<span class="marginnote">当然，真实演讲里两者常常混编：实证型观点用故事开场降低门槛，价值型观点用论据收尾增加分量。<strong>配比没有死公式，但有一根准线：主菜决定配菜</strong>——你的观点靠什么立足，就把资源的大头投给什么。</span>

实际操作可以这样走一遍：

1. 写下核心观点，问它是「价值型」还是「实证型」。
2. 如果是实证型：先想「有哪些论据」，再用一个故事做入口。
3. 如果是价值型：先想「有哪段经历最能代言」，再补一条论据防止「只是感动」。

## 4 核心对比表：故事与论据的取舍

把两者的特性摊开，方便写稿时对着配比：

| 维度 | 故事 | 论据 |
| --- | --- | --- |
| 核心作用 | 让人信（带进去） | 让人确认（站得住） |
| 单位 | 一段有冲突的经历 | 一个数据/事实/逻辑 |
| 打动的通道 | 情感、共情 | 理性、逻辑 |
| 适用观点 | 价值型为主 | 实证型为主 |
| 风险 | 煽情、以偏概全 | 冷硬、数据倾泻 |
| 最佳位置 | 开场、关键节点 | 主张之后、反驳之时 |
| 失效症状 | 「讲得真好，但真的吗？」 | 「数据很多，但跟我有关吗？」 |

这张表的最后两行最值得琢磨：**故事失效在「真实性质疑」，论据失效在「相关性缺失」**。所以一个完整的说服段往往是「故事引路 → 论据确认 → 回到听众」——故事建立信任，论据建立确信，最后一句把两者拉回听众的处境。

## 5 辨析｜易错点：把「讲道理」做成了「报流水账」

选「讲道理」的演讲者，最常见的错误是把论据当清单：第一条数据、第二条数据、第三条数据……听众听着听着就丢了「为什么这些数据在支持同一个主张」。

**辨析｜易错点：** 论据不是「罗列」，而是「论证」。论证要求每一条论据都**指向同一个主张**，并且**条与条之间有逻辑递进**——比如「先讲个体危害（工作记忆下降），再讲群体成本（生产力损失），最后讲机制根源（清除废物不足）」，三条数据像三块砖，砌成一面墙；而流水账是三条数据像三颗散沙，堆不成任何形状。<span class="marginnote">「砌墙」与「堆沙」的区别，在于<strong>砖与砖之间有没有「灰浆」——那层连接每一块的逻辑说明</strong>。每丢出一个数据，都要立刻补一句「这说明什么、跟上一条什么关系」。这一技巧在《金字塔原理》里叫「以上统下」：所有论据都向同一个结论归拢。</span>

同理，选「讲故事」的演讲者也有一忌：只讲故事、不给收束。故事讲完要「点题」——用一句话把故事「翻译」成观点，否则听众记住了故事，却没接住观点。

## 6 本节演练：为你的观点配「双通道」材料

「故事还是论据」的选择，不该靠拍脑袋，而该走一条可执行的材料流程。拿出你正在准备的演讲，做一次「材料配比」：

- **第一步，判性格**：写下核心观点，判断它是「价值型」还是「实证型」。判据：如果它回答「该做什么/什么是好的」，是价值型；如果它回答「世界是什么/机制如何」，是实证型。
- **第二步，配主菜**：价值型观点，主材料选「故事」，但要配一条「论据」防止只感动不确信；实证型观点，主材料选「论据」，但要配一个「故事」做入口降低门槛。
- **第三步，写三层链**：把你的观点写成「观点 → 主张 → 论据」三层。检查「主张」是不是一句「可检验的断言」——不可检验，先收窄它；「论据」是否真的支撑主张——不支撑，换一条。
- **第四步，排顺序**：把材料排成「故事引路 → 论据确认 → 回到听众」的段落。故事在前建立信任，论据在中建立确信，最后一句把两者拉回听众处境。
- **第五步，查两忌**：给每个故事补一句「点题」（把故事翻译成观点）；给每条论据补一句「连接」（说明它说明什么、跟上一条什么关系）。两者缺一，就补上。

五步走完，你的每个支撑段都同时有了「让人信」与「让人确认」的两只脚。**单脚站立的材料，在听众那里站不稳。**

在下一节，我们把「讲故事」放大成一个可复用的骨架——一段能打动听众的经历，往往长着同一种形状。

## 7 本节速记卡

故事与论据的配比，是说服的「双通道」设计：

| 关键概念 | 一句话记住它 |
| --- | --- |
| 故事的作用 | 让人信——把听众带进去 |
| 论据的作用 | 让人确认——让听众站得住 |
| 接受顺序 | 先故事引路，再论据确认 |
| 三层结构 | 观点 → 主张 → 论据 |
| 主张的身份证 | 可检验性 |
| 配比依据 | 价值型偏故事，实证型偏论据 |

**一句话行动**：给每个支撑段配「故事 + 论据」两只脚，按「引路→确认→回到听众」排序。

**防错口诀**：论据不是罗列是论证——每条都要回答「它支撑哪个主张」。

**延伸一问**：你的观点是价值型还是实证型？判断错了，材料就配反了。

## 8 小结

- 故事与论据的分工：**故事让人信，论据让人确认**；先故事后论据是高效的接受顺序。
- 说服的三层结构：**观点 → 主张 → 论据**——观点收窄成主张，主张靠论据落地。
- 配比看观点性格：**价值型观点偏故事，实证型观点偏论据**，但常混编。
- 论据不是罗列而是论证：每条论据指向同一主张，条与条之间有逻辑递进。
- 故事讲完要点题，论据丢出要连接——**材料服务于主张，而不是各说各话**。

在下一节，我们把「讲故事」放大成一个可复用的骨架：一段能打动听众的经历，往往长着同一种形状。这就是**英雄之旅：故事编排的基础模式**。
