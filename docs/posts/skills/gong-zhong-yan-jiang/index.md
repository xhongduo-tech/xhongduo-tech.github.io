# 公众演讲与表达

以《演讲的力量》《TED演讲的秘密》与《金字塔原理》为纲，系统掌握从演讲稿写作、故事与逻辑设计，到声音、肢体与舞台呈现，再到即兴表达的完整公众演讲能力。学完这些章节，就能写出一场有主线、有感染力、能打动听众的演讲，并自信地站上舞台。

## 对标教材

- 《演讲的力量》（克里斯·安德森）
- 《TED演讲的秘密》（杰瑞米·多诺万）
- 《金字塔原理》（芭芭拉·明托）
