# 视觉资料：远离有害的幻灯片

<div class="epigraph">

## 为什么从视觉资料开始

前面几节都在讲「人」——你的声音、你的身体。这一节转向「屏幕」：当演讲需要幻灯片辅助时，怎么让它们成为「助力」而不是「敌人」。安德森在《演讲的力量》第 10 章的标题用词很重——**「远离有害的幻灯片」**：他直言，绝大多数演讲的幻灯片，不是没帮上忙，而是在「帮倒忙」。

为什么视觉资料这么容易变成「有害」？因为幻灯片太容易做坏了：把讲稿要点往上一贴、字体一放大，就以为完成了「视觉化」——结果做出来的是「文字墙（text wall）」，听众的眼睛忙于读屏，耳朵自动关闭，你的声音成了背景音。<span class="marginnote">「文字墙」的危害机理是「双通道竞争」：人类处理视觉文字与处理听觉语言的资源部分重叠，<strong>当屏幕满是文字时，听众的「读」会抢占「听」的带宽</strong>——你越卖力讲，听众越忙着读，两边都顾不上。这与第二级《认知科学》里「选择性注意」的研究直接相关：人很难同时深度处理两个高负荷的信息流。</span>

## 1 有害幻灯片的三大形态

安德森与多诺万都总结过「有害幻灯片」的典型形态，归纳起来是三类：

**文字墙型**：一页上贴满完整句子，甚至整段话。听众的反应只有两种：要么低头逐行读（你的声音作废），要么扫一眼就放弃（你的要点作废）。**一页超过 20 个字的幻灯片，多半已经在危害演讲了。**

**目录/大纲型**：把「今天讲三点：一、二、三」做成一张张「标题页」。大纲幻灯片不是「视觉资料」，是「文字便签」——它只告诉听众「接下来要发生什么」，没有提供任何「视觉增量」。

**装饰过度型**：花哨的动画、水印、剪贴画、渐变背景。装饰不是「视觉化」，是「视觉噪音」——它不承载信息，只抢夺注意。听众记住的是「那只会转的小地球」，而不是你的观点。<span class="marginnote">「装饰过度」之所以有害，是因为它的「注意成本」远超「信息收益」：<strong>每一个与内容无关的视觉元素，都是向听众征收的一笔「注意力税」</strong>。判断标准很朴素：删掉它，演讲会变差吗？不会——那它就是噪音。</span>

三类的共同病根，是**把幻灯片当成了「演讲者的提词卡」或「讲稿的复读机」**，而它本该是「听众的视觉辅助」。

## 2 好的视觉资料做什么：转移认知负荷

明白了「有害的是什么」，再看「有益的是什么」。好的视觉资料只做一件事：**把一部分「只能靠听觉理解的负担」，转移到视觉上，让理解变省力。**

具体地说，视觉资料擅长「翻译」三类内容：

**抽象结构**：复杂的关系、流程、层级——一张图胜过千言。讲「注意力机制」时，一张「哪些词在看哪些词」的连接图，比口头描述高效得多。

**真实画面**：讲「南极的企鹅」不如放一张南极的企鹅照片；讲「产品的设计」不如放产品的实物图。**当「眼见」比「耳闻」更直接时，就用图。**

**数据关系**：一列数字不如一张趋势图。讲「收入连续五年下降」时，一张向下的折线图让听众「一眼看见趋势」，而不是「逐个比较数字」。<span class="marginnote">「图优于表、表优于句」的排序，本质是「认知负荷」的排序：图把「比较与推断」的大部分工作交给视觉系统（人脑的视觉处理极强），只给语言留下「解读」的工作。<strong>好的视觉资料，是把「理解」重担从「听觉/语言」挪到「视觉」</strong>——挪得越多，听众听你讲的压力越小。</span>

一个自检原则：**你的幻灯片离了你，听众能读懂吗？** 如果一张幻灯片「离了你也能完全读懂」，那它多半是「文字墙」（在替你做演讲）；如果「离了你读不懂，但你在讲的时候一看就懂」，那它才是真正的「视觉辅助」——它服务于「你+屏幕」这个组合，而不是「屏幕」独自工作。

## 3 设计原则：一页一想法、图优先、关键词

把「有益」落到实处，是三组可执行的设计原则：

**一页一想法**：每张幻灯片只承载「一个」信息点。一个想法一张图/一句话，听众的注意力集中、不被分心。判断标准：如果一页上有「两个都重要」的东西，就拆成两页。**一页装三个想法，等于三个想法都没被看见。**

**图优先、文为辅**：能用图表达，就不用文字；图 + 极简标注 > 大段文字。一张好的示意图 + 一个关键词短语，是黄金组合。文字在幻灯片里的角色是「注释」，不是「正文」。

**关键词而非句子**：如果非要写字，写「关键词」，不写「完整句子」——**关键词是「给听众的提示」，完整句子是「给听众的阅读任务」**。比如「注意力机制」这一页，写「聚焦关键」「加权求和」「可学习」，而不是「注意力机制是一种根据输入不同部分的重要性分配权重并加权求和的技术」。<span class="marginnote">「关键词而非句子」的底层逻辑，是「留出讲述空间」：幻灯片给「骨架」，你的口述给「血肉」。<strong>如果幻灯片把血肉也写满了，你的口述就「无事可做」，听众也「无话可听」</strong>——整场演讲变成了「我读你听」的朗读课。好的幻灯片，是让你「有得讲」的。</span>

## 4 核心对比表：有害幻灯片与有益幻灯片

把「有害」与「有益」并排，是设计幻灯片时最实用的对照：

| 维度 | 有害幻灯片 | 有益幻灯片 |
| --- | --- | --- |
| 文字量 | 整句、整段、整页 | 关键词、短语 |
| 信息密度 | 一页多个想法 | 一页一个想法 |
| 视觉角色 | 文字便签/复读机 | 图解结构、画面、数据 |
| 离了演讲者 | 完全能读懂 | 读不懂、配合演讲才懂 |
| 装饰 | 动画、水印、剪贴画 | 无噪音、内容即设计 |
| 听众行为 | 低头读屏、耳朵关闭 | 看屏一眼、听你讲解 |
| 一句诊断 | 「他在放 PPT」 | 「他在讲，PPT 在帮」 |

这张表最后两行的对比，是幻灯片好坏的最快诊断：**听众到底是「在听你讲、顺带看一眼屏」，还是「在读屏、顺带听你讲」？** 前者是好幻灯片的证据，后者是有害幻灯片的证据。

## 5 辨析｜易错点：把「少字」做成「无内容」

「远离文字墙」很容易被极端理解成「幻灯片越少字越好」——于是有人做出一页只有一个大图、零标注的幻灯片，听众看了完全不知道它要说明什么，全靠演讲者「硬讲」。

**辨析｜易错点：** 「少字」的目的是「让听众听你讲」，不是「让听众什么都看不懂」。**关键词的「精」与「够」要平衡**：一个字不写，听众失去「锚点」；写满整句，听众失去「听讲」。好的做法是「一个关键词 + 一张图」——图给「视觉」，关键词给「标注」，你的口述给「连接」。<span class="marginnote">「少字」的正确理解，是「<strong>字少到恰好是『提示』而不是『正文』</strong>」。关键词的作用是「防止听众在图里迷路」——它是视觉资料的「路标」。完全没有路标的幻灯片，听众要么没看懂图、要么看图走神，两种都背离了「辅助」的本意。</span>

另一个易错是「图与口述脱节」：幻灯片放了一张图，你讲的内容却与图无关——听众盯着图，耳朵里飘着话，两者对不上，认知负荷不降反升。**每张幻灯片出现时，你的口述要「指着它讲」**——图与话要「对齐」，否则图就成了装饰噪音。

## 6 本节演练：给旧幻灯片做「减法手术」

改善幻灯片最快的方法，不是「重做」，而是「给旧版做减法」。拿出一套你以前的幻灯片，按下面的流程「手术」：

- **第一刀，数文字**：逐页数「每页字数」。超过 20 字的页，是「文字墙」重灾区，全部标红。目标：每页压到 5 个字以内（关键词级别）。
- **第二刀，拆一页一想法**：把「一页讲了好几个点」的页拆开——一个想法一页。判断标准：如果一页上有两个「都重要」的东西，就拆成两页。
- **第三刀，换表达形式**：对每一页问「能不能用图/表代替字？」——讲流程的改流程图，讲趋势的改折线图，讲结构的改示意图。能用图就不写字。
- **第四刀，做「离了你能不能读」测试**：请一位同事（或假想）只看你的幻灯片、不看你的讲稿，问「这页讲什么」。如果对方「完全读懂」，说明这页在「替你说话」——删到只剩关键词，让它「离了你读不懂、配合你才懂」。
- **第五刀，清装饰**：删掉所有「不承载信息」的动画、水印、剪贴画、渐变背景。删的时候问一句「删掉它，演讲会变差吗？」不会——它就是噪音。

五刀做完，你的幻灯片会「瘦」一大圈——**瘦下来的幻灯片，才装得下听众的注意力。**

在下一节，我们把「视觉」再往前推一步：幻灯片只是工具的一种，道具、视频、讲台——每一件「工具」都有它的用法与陷阱。

## 7 本节速记卡

幻灯片，只该是「听众的视觉辅助」：

| 关键概念 | 一句话记住它 |
| --- | --- |
| 有害三形态 | 文字墙、目录大纲、装饰过度 |
| 好幻灯片的职责 | 转移认知负荷：结构、画面、数据关系 |
| 设计三原则 | 一页一想法、图优先文为辅、关键词而非句子 |
| 自检原则 | 离了你读不懂、配合你才懂 |
| 关键词的定位 | 给听众的提示，不是阅读任务 |
| 图与口述 | 要「对齐」，指着图讲 |

**一句话行动**：给旧幻灯片做「减法手术」——每页压到 ≤5 个关键词，能改图就改图。

**防错口诀**：一页超过 20 个字，多半已经在危害演讲了。

**延伸一问**：你的幻灯片「离了你」能被读懂吗？能——它就在替你做演讲。

## 8 小结

- 有害幻灯片的三大形态：**文字墙、目录大纲、装饰过度**——共同病根是「替演讲者说话」。
- 好幻灯片的职责是**转移认知负荷**：把抽象结构、真实画面、数据关系从「听觉」挪到「视觉」。
- 设计三原则：**一页一想法、图优先文为辅、关键词而非句子**。
- 自检：「离了你读不懂、配合你才懂」才是视觉辅助；「离了你也能读」就是文字墙。
- 少字 ≠ 无内容：**关键词是路标，图与口述要对齐**。

在下一节，我们把「视觉」再往前推一步：幻灯片只是工具的一种，道具、视频、讲台——每一件「工具」都有它的用法与陷阱。这就是**善用工具：幻灯片、视频、道具与讲台**。
