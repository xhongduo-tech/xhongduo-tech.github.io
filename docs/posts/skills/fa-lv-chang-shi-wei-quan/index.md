# 法律常识与维权

法律常识与维权以《中华人民共和国民法典》《中华人民共和国消费者权益保护法》和《中华人民共和国劳动法》为纲，覆盖合同、劳动、消费、婚姻家庭等日常生活中的核心法律常识与维权途径。学完这些章节，就能识别常见法律风险、守住权利底线，并在纠纷发生时走通协商、投诉、仲裁与诉讼的完整维权路径。

## 对标教材

- 《中华人民共和国民法典》
- 《中华人民共和国消费者权益保护法》
- 《中华人民共和国劳动法》
