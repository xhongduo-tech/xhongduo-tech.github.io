# 篮球运动

以 FIBA《篮球规则》、《篮球运动教程》与中国篮协教练员认证体系为纲，系统建立从竞赛规则、进攻防守技术、战术配合到教练员等级培训与球队管理的完整篮球能力链，学完即可覆盖从看懂比赛到执教一支球队应具备的核心理论与实践技能。

- 《篮球运动教程》
