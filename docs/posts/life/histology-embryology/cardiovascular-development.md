## 为什么心脏是第一个「开工」的器官

在器官形成期，没有哪个器官比心脏更性急：第 3 周末（约 21—22 天）心管就开始搏动，此时胚胎还只是三片胚层加一层薄胚膜。心脏如此「抢跑」，是因为胚胎一旦超过弥散供氧的尺寸，就必须建立自己的循环系统——**血液、血管、心脏几乎同时出现**，构成胎儿的「第一套基础设施」。上一节胚层表里提到「心血管来自侧中胚层」，这一节就展开全过程：一对内皮管如何融合成一根直管、直管如何弯环、如何隔出四腔、出生时又如何切换循环路线。这不仅是胚胎学最精密的「折纸术」，也是理解**先天性心脏病**的解剖地图。

## 1 从血岛到心管：血管的诞生

第 3 周，卵黄囊壁与胚体侧中胚层的细胞聚集成**血岛（blood island）**：外周的细胞变扁形成内皮，中央的细胞变成造血干细胞。血岛互相连通，就铺出最早的毛细血管网——这一过程叫**血管发生（vasculogenesis，新血管自原位长出）**；随后从已有血管上再「发芽」长出新血管，叫**血管生成（angiogenesis，从旧血管分支）**。<span class="marginnote">血管发生/血管生成的分野后来被肿瘤学借用了：肿瘤要靠「血管生成」给自己接上血供才能长大（于是有了抗血管生成的靶向药）。一条胚胎学概念，直接长成了抗癌药的靶标。</span>

与此同时，两侧的**心源性中胚层**各形成一根**心内皮管（endocardial tube）**，第 3 周中两管在腹侧靠拢融合，成为**原始心管（primitive heart tube）**。心管外面再包上**心肌外套层（myocardial mantle）**，这就是心肌的前身。至此，「一管内皮 + 一层心肌」的雏形已经敲定——此后心脏发育全部是对这根管的「加工」。

## 2 心管的分段与弯环：一根直管如何「打结」

原始心管从头到尾依次分段（一个著名的顺口溜）：

**动脉干（truncus arteriosus）→ 心球（bulbus cordis）→ 原始心室（primitive ventricle）→ 原始心房（primitive atrium）→ 静脉窦（sinus venosus）**

第 4 周，心管比胚体长得快，只能「折叠」，于是发生**心环（cardiac looping）**——原始心管向右弯成一个 U 形（正常为 **D 环**，向右环）。这次弯环极其关键：它把心房的相对位置搬到心室上方、把「下游的静脉端」挪到头端，四腔心脏的「户型」就是从这弯一下定下来的。<span class="marginnote">心环方向是左右不对称的经典例子。弯错方向（左环，L 环）会导致心室位置反转等复杂畸形；而它由一连串左右的基因（Nodal、Pitx2 等）控制——「左右对称的躯体，内脏却不对称」，原因就藏在心环这一步。</span>

**核心要点：** 心脏形态发生的大思路是**「先成管、再弯环、再分隔」**。隔一步去看「房间怎么分」之前，必须先把「管子怎么弯」在脑子里立起来。

心环还带来一个「管壁分工」的副产品：心管由外向内分为**心外膜层、心肌层、心内膜（内皮 + 胶样结缔组织）**三层，弯环与分隔之后，这些层次分别发育成心外膜、心肌与心内膜/瓣膜——与组织学心壁三层一一对应。

## 3 分隔：四腔心脏的「隔墙工程」

心脏从单腔到四腔，要完成四道「隔墙」，每道都有各自的「施工顺序」：

**房室分隔**：房室管（心房与心室之间）长出**心内膜垫（endocardial cushion）**——背侧与腹侧两垫相向生长、融合，把房室管分成左右两口，并参与瓣膜形成。

**心房分隔**：第一道隔板**原发隔（septum primum）** 从上往下长，下面留下**原发孔（ostium primum）**；原发隔与心内膜垫融合时孔先闭合，但顶部的细胞逐渐溶解又开出**继发孔（ostium secundum）**。随后右侧长**继发隔（septum secundum）**，覆盖继发孔但不完全闭合，留下**卵圆孔（foramen ovale）**。这套「一推一让」的复杂工序，目的是给胎儿期留一条**右心房→左心房**的捷径。

**室间隔**：下部由肌性隔向上长，顶部与心内膜垫、动脉干间隔汇合形成**膜部**——膜部是室间隔最薄、最常缺损的部位。

**流出道分隔**：动脉干与心球内的**嵴**相对生长形成**主肺动脉隔（conotruncal septum）**，把流出道分成**主动脉**与**肺动脉**，并旋转对位。

四道隔墙不是「同时施工」的：房室垫与房隔在先（第 4—5 周），室隔与流出道在后（第 5—8 周）。施工的先后决定了畸形的组合——同一批致畸因子打在第 5 周，可能同时破坏室隔与流出道，这正是法洛四联症常常「四件事一起错」的原因。

**辨析｜易错点：** 卵圆孔与房间隔缺损不是一回事。卵圆孔是**胎儿期生理性存在**的右向左通道，出生后压力反转而功能性关闭（卵圆窝），多数人终生只留一个浅浅的窝；真正「缺损」是隔墙本身有洞（原发孔/继发孔型房间隔缺损）。同样，**室间隔膜部缺损**是最常见的先天心病类型之一。

## 4 胎儿循环与出生时的「改道」

胎儿无法用肺呼吸，血氧全靠胎盘。胎儿循环是精心设计的「绕肺 + 绕肝」系统：

**胎盘（氧合）→ 脐静脉 → 肝 → 静脉导管（ductus venosus）绕肝 → 下腔静脉 → 右心房**。含氧血进入右心房后，经**卵圆孔**直接到左心房 → 左心室 → 主动脉 → 头颈部（最优先保证大脑供氧）。身体回流的乏氧血（上腔静脉）到右心室 → 肺动脉 → 大部分经**动脉导管（ductus arteriosus）** 绕过未扩张的肺，直接进降主动脉 → 脐动脉回胎盘。

胎儿期的血氧还有个「优先分配」的设计：来自胎盘的含氧血经静脉导管绕肝后，大部分被卵圆孔直接导向左心 → 主动脉 → 头颈；而回流的乏氧血经右心 → 肺动脉 → 动脉导管 → 降主动脉 → 脐动脉回胎盘。大脑永远分到最「新鲜」的氧——这就是胎儿循环的分配原则。

出生时发生三处关键「关闸」：

**卵圆孔**关闭 → 卵圆窝（因为肺通气后左房压升高、超过右房压，隔膜被压上）。
- **动脉导管**收缩关闭 → **动脉韧带（ligamentum arteriosum）**。
- **静脉导管**与**脐静脉**关闭 → 静脉韧带与肝圆韧带；脐动脉闭锁成内侧脐韧带。

<span class="marginnote">「三条导管三条韧带」是妇产科与新生儿科的高频考点：静脉导管→静脉韧带、动脉导管→动脉韧带、脐静脉→肝圆韧带、脐动脉→内侧脐韧带。出生即是「改管为韧带」的时刻——血液循环从胎儿模式切换到成人模式，只需几分钟到几天。</span>

## 5 先天性心脏病：隔墙施工的「返工单」

先天心病的发生率约 0.5—1%，多数可归因于上面某一堵墙没隔好：

**室间隔缺损（VSD）**：最常见，膜部或肌部留洞，左室血漏向右室。
**房间隔缺损（ASD）**：继发孔型多见。
**法洛四联症（tetralogy of Fallot）**：四个特征——**肺动脉狭窄 + 室间隔缺损 + 主动脉骑跨 + 右心室肥厚**。本质是流出道分隔与室间隔对位错乱，患儿常「青紫」。
**大动脉转位（transposition）**：主动脉起自右室、肺动脉起自左室，系统性循环与肺循环串不成线，出生后靠动脉导管与卵圆孔维持短暂存活。

**辨析｜易错点：** 卵圆孔与动脉导管在出生后是「功能关闭」还是「解剖闭锁」要看月龄：卵圆孔功能性关闭（卵圆窝）多能终生；动脉导管则于数周内解剖闭锁成韧带。若该关不关——动脉导管未闭（PDA）——成人反而要靠它存活（某些大动脉转位），闭合时机的「对错」完全由循环需要决定。

<span class="marginnote">法洛四联症的四条是一条逻辑链：流出道偏转 → 肺动脉窄、主动脉「骑」到室缺上 → 右室排血受阻而肥厚。背四联症时若能连起这条因果，比死记四个词可靠得多。</span>

## 6 核心要点：心管发育时间线

| 孕龄 | 事件 |
| --- | --- |
| 第 3 周初 | 血岛、血管发生、成对内皮管 |
| 第 3 周末（21—22 天） | 心管融合、开始搏动 |
| 第 4 周 | 心环（D 环），房室初步分位 |
| 第 4—7 周 | 心内膜垫、房室隔、心房间隔 |
| 第 5—8 周 | 室间隔、流出道分隔 |
| 出生时 | 卵圆孔、动脉导管、静脉导管关闭 |

## 7 小结

- 血管先以**血管发生**（血岛）铺底，再以**血管生成**分支；心脏由成对内皮管融合成单根心管。
- 心管分段（动脉干-心球-心室-心房-静脉窦）后经**心环**向右弯折，奠定四腔户型。
- 四道隔墙（心内膜垫、房隔、室隔、流出道）依次施工；膜部室隔最薄弱。
- 胎儿循环靠**卵圆孔 + 动脉导管 + 静脉导管**绕肺绕肝供氧；出生后三者关闭成韧带/窝。
- 先天心脏病（VSD、ASD、法洛四联症、大动脉转位）都能在分隔工序里找到「返工点」。
- 四道隔墙按「先房室、后室隔与流出道」的顺序施工，施工次序解释了先天心病的畸形组合。
- 三条导管三条韧带：静脉导管→静脉韧带、动脉导管→动脉韧带、脐动脉→内侧脐韧带。
