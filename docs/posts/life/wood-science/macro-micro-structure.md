# 木材的宏观与微观结构

## 为什么从结构开始

木材的一切行为——强度、收缩、干燥、耐久、胶合——最终都能追溯到它的**结构**。木材不是「一根匀质的棍子」，而是一个由几十亿个细胞按严格几何秩序堆叠成的层级材料：年轮是树历年的生长记录，早晚材是季节的对照表，细胞壁里的微纤丝是承重的钢筋。<span class="marginnote">把木材看作「层级复合材料」是理解它的钥匙：分子 → 微纤丝 → 细胞壁 → 细胞 → 组织 → 树干，每一层都为上一层贡献性质。这与《材料科学基础》里对金属多晶组织的分层看法同源。</span>先建立结构这张地图，后面每一节的物理、力学、干燥、防腐知识才有落点。

## 1 从树皮到髓心：横断面上的一圈圈记录

把一棵树齐根锯断，横断面（**横切面**）从外到内依次是：**树皮（bark）**、**形成层（cambium）**、**木质部（xylem）**、**髓心（pith）**。

**树皮**：死去的韧皮部与周皮构成，起保护作用。
- **形成层**：一薄层分生组织，向内分裂产生木质部，向外产生韧皮部——树木长粗的唯一来源。
- **木质部**：即我们日常所说的「木材」。分**边材（sapwood）**与**心材（heartwood）**：边材靠外、含水多、承担输导与储藏；心材靠内、颜色深、由边材逐渐转化而来——转化中薄壁细胞死亡、纹孔闭塞，单宁与色素等**抽提物（extractives）**沉积。<span class="marginnote">同一棵树，心材往往更耐腐、更稳定，但可加工性下降——这些差异几乎全部来自抽提物，而不是细胞壁本身。我们会在《木材耐久性》一节再次遇到它。</span>
**髓心**：树干中央疏松的小髓，是树木最早形成的组织。

每年形成层向内产生一圈新木质部，称为一个**生长轮（growth ring）**。在温带，一个生长轮一般对应一年，故俗称**年轮**。每一轮内又分两部分：生长季早期形成的**早材（earlywood）**细胞腔大、壁薄、色浅，材质疏松；生长季后期形成的**晚材（latewood）**细胞腔小、壁厚、色深，材质致密。**晚材率**（晚材占年轮的比例）直接影响木材强度，是分级的重要依据。

把生长轮当成「记录」来读，能读出很多信息：**数轮子可以估树龄**，轮宽的变化反映当年的气候与水肥条件，而**晚材率是强度预报员**——松木晚材率从 10% 提高到 30%，抗弯强度大致可提升三成。<span class="marginnote">在热带，全年都能生长，一圈不再是「一年」的可靠刻度，于是木材学改用「生长轮」而回避「年轮」的叫法；在旱雨季交替的地区，一圈也可能只对应一个雨季。</span>

年轮也并非永远可靠的日历：严重干旱、火灾或虫害过后，树木可能在一年内形成**伪年轮（false ring）**；而某些针叶树早材与晚材界限模糊，也会让年轮计数出错。所以在精确测定树龄时，要沿半径交叉对比多条序列、剔除这些「假刻度」——这门手艺叫**树木年代学（dendrochronology）**，它既用来给古建梁柱断代，也用来重建千百年的气候序列。

**树皮与形成层值得单独看清**：韧皮部把叶子的光合产物（糖）沿茎向下运输，是树木的「静脉」；形成层则是一层永远保持分裂能力的分生细胞，树木的长粗全靠它每年向内添一层木质部、向外添一层韧皮部——**大树年年在长粗，靠的不是木质部自己，而是这条夹在树皮与木头之间的「生长带」**。

## 2 三个基本切面：读木材必须三把尺子

木材是各向异性的，同一个树种，从不同方向切下去看到的花纹与测得的性质都不同。为了交流，木材学规定三个**基本切面（principal planes）**：

- **横切面（transverse / cross section）**：垂直于树干主轴。看到完整的生长轮、心边材、髓心，是判识结构的第一现场。
- **径切面（radial section）**：沿直径方向、平行于髓心。生长轮在这里呈平行直线，木射线被纵切成长条形。
- **弦切面（tangential section）**：与髓心保持一定距离、相切于年轮的切面。生长轮在这里呈山峰形或V形弧线——所谓「山形纹」的来源。

同样的细胞，在三个切面上呈现不同形态，这就是为什么木材识别必须同时对照三个切面。径切面与弦切面的差异还导致**弦向收缩大约是径向的两倍**，这个问题我们留到《木材物理性质》一节展开。

三个切面的选择还直接决定**商业价值**：径切板纹理直、收缩小、价格高，适合桌面与门板；弦切板花纹活泼、出材率高，适合装饰面板。同一棵树，切法不同，售价能差出一大截——这是《木材产品加工工艺》里「下锯方案」博弈的伏笔。

![木材的三个基本切面](/images/wood-science/macro-micro-structure-1.svg)

三个切面不只是「看图」，更是**操作规范**：判识别要把木块先磨平、再分别开出横、径、弦三面；判纹理要在弦切面看山形纹、在径切面看直纹；判木射线要在径切面找光泽条纹。<span class="marginnote">同一块料在径切面与弦切面「长得不像」，是因为观察方向不同、切到的细胞形态不同——这不是木材不均匀，而是你切的位置不同。理解这点，你就不会再被「同一根木头的两张脸」搞糊涂。</span>

## 3 微观结构：针叶树与阔叶树的两套方案

用显微镜看横切面，木材由两类基本组织构成：**轴向系统**（平行树轴，负责输导与支撑）与**径向系统**（垂直于树轴，即**木射线 rays**，负责横向输导与储藏）。在这个骨架里，针叶树与阔叶树走出了两套方案。

**针叶树（软木，softwood）**的结构最简单：90% 以上是**轴向管胞（longitudinal tracheids）**——一种既输导又支撑的狭长细胞，两端封闭、侧面有纹孔连通。此外有**木射线**与**树脂道（resin canals）**（松、云杉、落叶松等有）。没有导管，是针叶树与阔叶树最根本的解剖区别。

管胞的尺寸值得记住：一根针叶树轴向管胞长约 2–6 mm、宽约 30–60 µm，像一支两端封闭、侧壁开窗的细长铅笔。它**一身兼二职**——输导靠纹孔之间的贯通，支撑靠厚实的次生壁。<span class="marginnote">「一种细胞同时干输导和支撑两件事」是针叶树结构简洁的本质；代价是输导效率不高，所以针叶树长不出阔叶树那种大口径输导通道，这解释了针叶树通常长得慢、结构规整、纹理均匀。</span>

**阔叶树（硬木，hardwood）**的结构更分化，至少含四类细胞：

- **导管（vessels）**：大口径的输导细胞，在横切面上呈现为孔洞，即**管孔（pores）**。<span class="marginnote">「导管 = 管孔」只是同一结构在不同切面上的名字：三维上是导管，横切面上的切迹就是管孔。管孔的大小、排列（环孔材 / 散孔材）是识别阔叶树的第一判据。</span>
**纤维（fibers）**：细长的厚壁支撑细胞，管胞的「专职化版本」。
- **轴向薄壁组织（axial parenchyma）**：储藏养分的细胞，围绕或散布于管孔之间。
- **木射线**：比针叶树更发达，甚至肉眼可见（如栎木的宽射线）。

**核心概念：环孔材与散孔材。** 阔叶树若早材管孔明显大于晚材管孔、形成一圈孔带，称**环孔材（ring-porous）**（如白蜡、栎、榆）；若管孔大小、分布全年相近，称**散孔材（diffuse-porous）**（如枫木、桦木、杨木）。这一判据肉眼用放大镜就能确认。介于两者之间还有**半环孔材（semi-ring-porous）**（如胡桃）：早材孔偏大、晚材孔渐小，过渡缓和。<span class="marginnote">环孔材与散孔材不只是形态标签，还预告力学与干燥行为：环孔材晚材比早材致密得多、顺纹强度高但干燥更易开裂；散孔材结构均匀、干燥平稳。从《力学》到《干燥》，这个分类会反复出现。</span>

**轴向薄壁组织（axial parenchyma）的排列方式**是阔叶树的另一组判据：围绕管孔分布（环管，paratracheal）还是独立于管孔（离管，apotracheal）、呈带状还是散生。白蜡与栎以环管为主，椴木与桦木混有离管薄壁组织——这个细节到《木材识别》的微观判据里还会以更细的形态出现。

## 4 细胞壁：微纤丝的层次堆叠

单个木材细胞并不厚，它的力学性能全靠**细胞壁**。细胞壁从外到内分三层：

- **胞间层（middle lamella）**：把相邻细胞粘在一起，富含**木质素（lignin）**，相当于混凝土中的胶浆。
- **初生壁（primary wall）**：细胞生长阶段形成的薄层，微纤丝排列松散。
- **次生壁（secondary wall）**：细胞成熟后增厚的主体，又分三层 S1、S2、S3，其中 **S2 层最厚，几乎决定细胞壁的力学行为**。

次生壁里承重的骨架是**微纤丝（microfibrils）**——由纤维素分子链平行排列而成的微丝，像钢筋一样埋在木质素基体里。S2 层微纤丝与细胞长轴大约成 10°–30° 的夹角，这个**微纤丝角（microfibril angle）**是木材力学性质的第一个调节旋钮：早材、幼龄材的微纤丝角大，木材偏柔；晚材、成熟材微纤丝角小，木材偏刚。<span class="marginnote">微纤丝角的变化直接解释了「幼龄材力学性能差、变形大」的现象——造纸与结构用材都希望微纤丝角小。这个「骨架 + 基体」的构型，正是后续《木材力学性质》理解弹性与强度的细胞学根源。</span>

S1 与 S3 层虽然薄，作用却不小：S1 层微纤丝接近横向缠绕，像一圈「束带」把细胞箍紧，防止 S2 层受压时向外屈曲；S3 层紧贴细胞腔，参与决定腔面光滑度与渗透性。细胞壁的力学行为，其实是这三层微纤丝角度与厚度共同调制的结果——S2 层定「刚度」，S1 层定「稳定」，缺一不可。

**辨析｜易错点：** 别把「针叶树 = 软木」与「针叶树 = 软」划等号。软木、硬木是商业俗称，依据的是**解剖类型**（有无导管）而非硬度：北美红豆杉是针叶树，却比很多阔叶树硬。同理，「早晚材」与「心边材」是两套完全独立的维度——心材不一定色深，边材也未必浅（如杨木心边材同色）。

| 对比维度 | 针叶树（软木） | 阔叶树（硬木） |
| --- | --- | --- |
| 导管 | 无 | 有（横切面呈管孔） |
| 主要轴向细胞 | 管胞（输导 + 支撑） | 导管（输导）+ 纤维（支撑） |
| 木射线 | 窄而细 | 可宽可窄，常更发达 |
| 解剖结构复杂度 | 简单、规整 | 分化复杂、变异性大 |
| 典型代表 | 松、云杉、冷杉、落叶松 | 栎、枫、桦、白蜡、椴 |

## 6 从裸子到被子：两套方案的演化位置

把两套结构放进植物演化史，答案更清晰：**针叶树是裸子植物，阔叶树是被子植物（多为双子叶）**。导管是演化中较晚出现的结构——它把输导功能从管胞里「独立」出来，让支撑交给纤维专职，输导效率大增，这是被子植物能长出宽叶、快长、高产的解剖基础。<span class="marginnote">「把一件多功能工具拆成几件专用工具」的分工策略，在植物演化里重现了一次效率革命。反过来，裸子植物保留的「管胞一身兼」换来结构规整、纹理均匀——两套方案各有所长，也就各有其用武之地。</span>

这层演化视角还解释了另一个现象：**针叶树种类远少于阔叶树，却贡献了全球木材产量的大头**。云杉、松、冷杉成片分布、树干通直、加工简单，是建筑与纸浆的主力；阔叶树材种多样、花纹丰富，更多用于家具、地板与装饰。<span class="marginnote">把「解剖类型」「商业俗称」「演化位置」三层概念叠在一起看，木材的世界就从「软硬两种木头」升级成一张有秩序的谱系图——这也是《木材识别》一节的认知地基。</span>

## 7 小结

- 横断面自外向内为**树皮、形成层、木质部、髓心**；木质部分**边材与心材**，差异主要来自抽提物。
- **生长轮**是逐年形成的；**早材**疏松、**晚材**致密，晚材率影响强度；数轮可估树龄、轮宽记录气候。
- 三个基本切面——**横、径、弦**——是描述与识别木材的三把尺子。
- 针叶树无**导管**、以**管胞**为主；阔叶树有**导管**与**纤维**，并分**环孔材 / 半环孔材 / 散孔材**。
- 细胞壁分层（胞间层、初生壁、次生壁 S1/S2/S3），**S2 层微纤丝角**是木材力学性能的关键旋钮。
- 针叶树 = 裸子植物、阔叶树 = 被子植物，「有无导管」既判类型、也讲演化。
- 轴向薄壁组织（环管/离管）、伪年轮是识别与树龄测定中的细节判据，也提醒「生长记录」需要交叉验证。
- 三个切面既是认识结构的三把尺子，也是决定板材商业价值的锯切选择。

在下一节，我们拿着这三把尺子和放大镜，去实践木材的**识别与解剖**——看形态特征如何变成一张判定表。
