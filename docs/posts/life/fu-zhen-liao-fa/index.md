# 腹针疗法

腹针疗法是薄智云教授创立的新针灸流派，以神阙布气假说为核心，在腹部特定穴位施以浅刺分层针刺，具有进针无痛、取穴少而精、操作规范、可复制性强的特点，对多种内科、妇科及骨伤疾病疗效显著。学完本专题，就系统写完了从神阙布气理论基础、腹部穴位体系、标准化操作规范到临床各科应用的完整内容。
