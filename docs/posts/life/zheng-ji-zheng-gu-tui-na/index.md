# 整脊正骨推拿（中医整脊/美式整脊）

整脊正骨推拿是以脊柱与骨盆的复位矫正为核心、治疗脊柱相关疾病的独立学科，以脊柱病因学说与筋骨辨证为理论基础，融合中医整脊（正骨推拿）与美式整脊（脊椎矫正）两大技术体系，已形成系统的行业诊疗指南。学完本专题，就系统写完了从脊柱解剖生物力学、整脊手法操作规范到常见脊柱疾病诊疗与临床进阶的全部内容。
