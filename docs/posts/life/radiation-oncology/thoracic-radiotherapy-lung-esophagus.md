## 为什么从胸部开始

胸部肿瘤是中国发病率与死亡率最高的肿瘤家族，而放疗在其中扮演三重角色：早期肺癌的根治性替代（SBRT）、局部晚期肺癌与食管癌的同步放化疗、以及术后/术前的辅助治疗。这一篇把外照射技术、运动管理（IGRT 篇）与放射生物（4R 篇）全部调动起来，是技术篇到病种篇之间第一次「全家桶」式的实战应用。<span class="marginnote">胸部放疗的核心矛盾是「给足剂量 vs 保住肺心」：肺是并联器官（局部损伤可代偿）但怕大面积受照，食管与脊髓是串联器官（一处超量即全器官失灵）——两种损伤模式的差异，决定了剂量约束的写法。</span>

胸部也是**综合治疗**的主战场（第11篇详述）：III 期肺癌「同步放化疗 + 免疫巩固」、食管癌「新辅助放化疗 + 手术」——放疗在这里既是根治主力，又是系统治疗链条上不可或缺的一环。

## 1 肺癌的放疗：从早期 SBRT 到局部晚期同步放化疗

肺癌按组织学分两大类：**非小细胞肺癌（NSCLC）**（约占 85%，鳞癌、腺癌等）与**小细胞肺癌（SCLC）**（恶性度高、生长快、对放化疗敏感）。

**胸部放疗术语速查表**：

| 术语 | 含义 |
| --- | --- |
| NSCLC | 非小细胞肺癌（占约 85%） |
| SCLC | 小细胞肺癌（恶性度高、对放化疗敏感） |
| SBRT | 立体定向体部放疗（早期肺癌根治） |
| CCRT | 同步放化疗（III 期标准） |
| PCI | 预防性全脑照射（局限期 SCLC） |
| BED | 生物等效剂量（分次方案横向比较） |
| V20 / MLD | 肺受 ≥20 Gy 体积比例 / 平均肺剂量 |
| DIBH | 深吸气屏气（运动+心剂量的双重对策） |

**早期 NSCLC**：能手术者手术；不能手术或拒绝手术者，**SBRT** 是根治性替代，典型方案 48–60 Gy/3–5 次，局部控制率可达 90% 以上，与手术相当。<span class="marginnote">SBRT 治疗早期肺癌之所以敢用大分次，靠的是放射生物篇的 BED 逻辑：单次高剂量把等效生物剂量推到 150–200 Gy10，远高于常规分次的 60 Gy10——代价是周围肺、胸壁的限量必须极严。</span>

SBRT 对早期肺癌的「战果」让放疗科自己都惊讶：过去「不能手术就姑息」的时代被改写——如今早期肺癌的 SBRT 局部控制率与手术相当，且对**毛玻璃样/磨玻璃样早期腺癌**（影像上模糊、浸润性低的病灶）效果尤为突出。**早期肺癌的治疗决策已从「能不能手术」转向「手术还是 SBRT 哪个更合适」**——这标志着放疗在肺癌版图里从「配角」升格为「主角之一」。

**局部晚期 NSCLC（III 期）**：不可手术，标准治疗是**同步放化疗**（60–66 Gy/30–33 次 + 含铂双药），近年来在巩固阶段加入免疫检查点抑制剂（度伐利尤单抗），显著延长生存。

**局限期 SCLC**：同步放化疗为主，放疗 45 Gy/30 次（每日两次超分割）或 60–66 Gy 常规分次；有效者在全脑预防照射（PCI）中获益——小细胞肺癌脑转移风险极高。

**小细胞肺癌的分期驱动**：局限期（LD）与广泛期（ED）的决策完全不同——LD 用同步放化疗 + 预防性全脑照射（PCI），ED 以系统治疗为主、放疗用于症状缓解或 PCI 降颅内复发；小细胞肺癌对放化疗敏感但极易复发，化疗与放疗的衔接时序（「早放疗 vs 晚放疗」）一直有争议，多数证据支持尽早开始胸部放疗。

## 2 食管癌放疗与 CROSS 方案

食管癌放疗高度依赖「放疗与手术/化疗的顺序设计」。**CROSS 方案**（卡铂 + 紫杉醇同步放化疗 41.4 Gy/23 次）是目前局部晚期食管癌新辅助治疗的经典：术前放疗缩小肿瘤、提高 R0 切除率，明显延长生存。<span class="marginnote">CROSS 的 41.4 Gy 远低于根治性剂量——它不是要「放疗单独根治」，而是与手术配合的「降期手术」：这说明同一器官在不同治疗策略里，放疗的处方逻辑完全不同。</span>

**根治性放化疗**（不做手术）适用于不能耐受手术或要求保喉（颈段食管癌）者，剂量提高到 50–60 Gy。**辨析｜易错点：** 食管癌根治性放化疗的剂量并非越高越好——多项随机试验把剂量从 50.4 Gy 提到 64.8 Gy，生存未获益反而毒性增加。「加量=更好」在放化疗里并不总是成立。

食管癌放疗的技术要点是**顺着食管的长轴勾画靶区**：食管是长管状器官，靶区往往长达 10–20 cm，横跨颈、胸、腹三个区域；同时它紧贴心脏、肺与气管，两侧肺的 V20 极易因「长靶区」而超限。<span class="marginnote">食管癌是「长靶区 + 多器官毗邻」的教科书：越长的靶区越考验 IMRT 的剂量雕刻，也越容易在「给足肿瘤剂量」与「保住肺心」之间把物理师逼到墙角。</span>运动管理上，食管随吞咽与呼吸移动，常采用 4D-CT 定位 + 门控或 DIBH（深吸气屏气），把运动不确定性压下去。

**食管癌的靶区勾画与剂量设计**：根治性放疗的 GTV 由影像与内镜（EUS）共同定义，CTV 沿食管纵轴外扩并包绕区域淋巴引流区，纵隔与胃左动脉旁淋巴结常被纳入；由于食管紧贴心包与气管，计划常要求「纵轴剂量充足、横断面上快速跌落」——长靶区 + 短跌落，是对 IMRT 剂量雕刻最苛刻的要求。

## 3 胸部危及器官与剂量约束

胸部放疗主要守三个器官：**肺**、**心脏**、**食管**（外加脊髓——这是所有部位的共同底线）。

| 器官 | 常用约束 | 对应毒性 |
| --- | --- | --- |
| 肺 | V20 ≤ 30%（两侧肺总 V20），MLD ≤ 20 Gy | 放射性肺炎 |
| 心脏 | 平均心剂量（MHD）尽量低，V30 ≤ 40% | 心包炎、缺血性心脏病 |
| 食管 | 平均剂量 Dmean < 34 Gy | 放射性食管炎 |
| 脊髓 | Dmax ≤ 45–50 Gy | 脊髓病 |

**放射性肺炎**是肺癌放疗最需警惕的毒性：肺是**并联器官**——关键在于「受照体积」而非「局部峰值」，所以用 **V20（≥20 Gy 的肺体积比例）与平均肺剂量（MLD）** 衡量。<span class="marginnote">对比一下：脊髓是串联器官，一句「Dmax ≤ 45 Gy」就够；肺必须看体积分布，一句 Dmax 毫无意义——「并联看体积、串联看峰值」是放疗剂量约束的第一直觉。</span>

肺约束的「剂量-体积响应」有明确的临床阶梯：**V20 ≤ 30% 且 MLD ≤ 20 Gy 时，症状性肺炎（≥2 级）风险约 10–20%**；V20 升高到 35–40%，风险攀升到 25% 以上。这也解释了为什么同步放化疗后的肺特别「娇气」——化疗的肺损伤与放疗的 V20 效应叠加，让同一套约束在综合治疗里更要死守。<span class="marginnote">「V20 多一个百分点，肺炎风险就多一分」——物理师把 V20 看成肺的「红线刻度」，每压下一个百分点，都是在为患者的远期呼吸储备买单。</span>

**心脏保护**在胸部放疗里日益受重视：放疗相关性心脏毒性（心包炎、冠心病、瓣膜病）在生存期延长的肺癌/食管癌患者中越来越常见——计划里用平均心剂量（MHD）、V30 与 V40 约束，左侧病灶常借 DIBH 把心脏推离照射野。**「保肺 + 保心」是现代胸部放疗的两条生命线**，也是 V20 与 MHD 并列写进约束表的根本原因。

## 4 公式解析：生物等效剂量 BED

SBRT 的「大分次」与常规分次的「小剂量多次」怎么放在同一把尺上比？答案是**生物等效剂量（BED）**：

$$BED = n \cdot d \cdot \left(1 + \frac{d}{\alpha/\beta}\right)$$

- **第一步，$n$ 与 $d$**：分次次数与单次剂量，$n \cdot d = D$ 是总物理剂量。
- **第二步，$(1 + d/(\alpha/\beta))$**：单次剂量对组织的「相对加重因子」——$d$ 越大，这个因子越大，对低 α/β 组织尤其明显。
- **第三步，算一例（肿瘤 α/β=10）**：常规 60 Gy/30 次，BED10 = 60×(1 + 2/10) = 72 Gy10；SBRT 48 Gy/4 次，BED10 = 48×(1 + 12/10) = 105.6 Gy10——**总剂量少 20%，生物等效剂量却高出 47%**，这正是 SBRT 敢说「等效根治」的数学根据。
- **第四步，注意 α/β 要按组织取**：同一个 SBRT 方案对肺（α/β=3）算 BED3，数值会更高，提醒肺组织的风险更敏感。<span class="marginnote">BED 与 EQD2 同源于 LQ 模型（上篇），二者只差一个归一化参照：EQD2 折成 2 Gy/次，BED 是绝对的生物剂量标尺。做胸部放疗的物理师两个公式随手换算。</span>

**辨析｜易错点：** BED 的 α/β 取值一变，结论可能反转。同一个 SBRT 方案，按肿瘤（α/β=10）算 BED10 很好看，按肺（α/β=3）算 BED3 可能高到吓人——**报 BED 必须注明 α/β，否则数字没有意义**。文献里「BED10 150 Gy」与「BED3 200 Gy」说的是同一个方案的两副面孔。

## 5 呼吸运动与反应管理

肺癌与食管癌都在呼吸运动与消化道蠕动的持续扰动中，**运动管理**是胸部放疗质量的生死线：4D-CT 勾 ITV、门控、屏气、实时追踪（如金标追踪）都是选项。左侧肺癌/食管癌还要尽量降低心剂量。<span class="marginnote">深吸气屏气（DIBH）让肺扩张、心脏下移——既把心剂量降下来，又让运动幅度趋近于零，是胸部放疗「一石二鸟」的运动管理策略。</span>

选择哪种运动管理取决于**肿瘤移动幅度**：中央型病灶或移动 > 1 cm 的周围型病灶，常需门控或追踪；移动小（< 5 mm）且位于下叶后部者可仅用 4D-CT 外扩。运动管理不是「越高级越好」，而是「匹配病灶特性、可被患者执行」——屏气要求患者配合，门控延长治疗时间，追踪依赖金标——**每一个选择都是精度、耗时与耐受性的权衡**。

急性反应：放射性食管炎（吞咽痛）、肺炎（干咳、发热）；晚期：肺纤维化、心包炎、食管狭窄。**辨析｜易错点：** 放射性肺炎多发生在放疗后 1–6 个月，常在疗程结束后才出现——疗程顺利不代表可以提前庆祝，随访窗口在疗程后而非疗程中。

## 6 胸部放疗的姑息与寡转移场景

放疗在胸部不只是根治手段，更是重要的**姑息武器**：

**骨转移疼痛**：单次 8 Gy 或 20 Gy/5 次即可缓解大部分骨痛，2 周内起效，是「性价比最高」的放疗之一；
**脑转移**：SRS（第4篇）治疗少数脑转移灶，全脑放疗（WBRT）用于多发或预防；
**上腔静脉综合征（SVC）**：纵隔压迫导致的呼吸困难、面部水肿——放疗是紧急缓解手段之一；
- **咯血 / 气道梗阻**：支气管内肿瘤出血或堵塞，放疗可快速止血、复通气道。

还有近年最热的**寡转移（oligometastasis）**概念：少数（如 ≤5 个）转移灶不再被当作「晚期绝症」，而用 SBRT 逐一「消灶」——对 EGFR/ALK 靶向治疗稳定后的肺癌寡转移，消灶可能显著延长无进展生存。<span class="marginnote">「寡转移」颠覆了「转移 = 全身系统治疗为主」的旧范式：当转移灶少且小，局部消灶（SBRT、手术）与全身治疗并行，形成「系统控制 + 局部清除」的双轨——这背后是对「转移不是终点」的重新定义。</span>

## 7 小结

- 肺癌放疗分道而行：早期 **SBRT**（根治替代）、局部晚期 **同步放化疗 + 免疫巩固**、局限期 **SCLC** 同步放化疗 + PCI。
- 食管癌的 **CROSS 方案**（41.4 Gy + 卡铂/紫杉醇）体现「放疗配合手术」的新辅助逻辑。
- 肺是并联器官用 **V20/MLD** 限，脊髓是串联器官用 **Dmax** 限——「并联看体积、串联看峰值」。
- **BED** = $nd(1 + d/(\alpha/\beta))$，SBRT 靠它「少剂量拿等效」——48 Gy/4 次的 BED10 ≈ 105.6 Gy，远高于常规分次的 72 Gy。
- **CROSS**（41.4 Gy + 卡铂/紫杉醇）与根治性放化疗是食管癌「两条腿」：前者配合手术、后者保喉保食管。
- 小细胞肺癌看分期：局限期同步放化疗 + PCI、广泛期以系统治疗为主——「早放疗」对 LD-SCLC 更有利。
- 运动管理按「移动幅度」选工具：移动 < 5 mm 用 4D 外扩，> 1 cm 用门控/追踪，DIBH 同时解决心剂量与运动。
- 胸部放疗的「两生命线」是保肺（V20/MLD）与保心（MHD/V30），左胸病灶常用 DIBH 推开心脏。
- 胸部放疗的运动管理（4D-CT/门控/DIBH）与反应管理（食管炎、肺炎）构成「从定位到随访」的完整闭环。
