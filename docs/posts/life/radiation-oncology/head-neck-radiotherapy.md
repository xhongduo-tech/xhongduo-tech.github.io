## 为什么从头颈部开始临床篇

技术篇讲完了工具，从这一篇开始进入**病种篇**。头颈部肿瘤（鼻咽癌、喉癌、口咽癌、下咽癌等）是放疗的「试金石」：这里器官密集、靶区常常呈 C 形包绕脊髓，且功能（吞咽、发音、唾液、视力）寸土寸金。可以说，**IMRT 的诞生很大程度上就是为了头颈部**——反过来，学会了头颈部放疗，就掌握了靶区勾画、剂量约束与反应管理的完整方法论，后续病种篇都会反复调用这套框架。

本篇与全树的关系一句话：**头颈部是放疗「手艺」的集大成者**——它同时考验解剖知识（靶区勾画）、技术能力（IMRT/SIB）、剂量学（EQD2）与综合治疗（同步放化疗），是前面所有技术篇的一次「总复习式实战」。

## 1 头颈部：放疗难度最高的舞台

头颈部集中了脊髓、脑干、视交叉、腮腺、下颌骨、耳蜗等一串**要害器官（OAR）**，而肿瘤又常贴着它们生长。这里放疗的三大挑战：**解剖复杂**（几十块小肌肉与间隙，勾画判读难）、**功能脆弱**（一次误伤就可能是终身失语或失明）、**靶区形态刁钻**（包绕性靶区要求剂量雕刻）。<span class="marginnote">鼻咽癌靶区常呈「倒 C 形」绕过脊髓与脑干——这正是 IMRT 的经典演示病例：没有调强，这类靶区几乎无法在不伤脊髓的前提下根治。</span>

头颈癌的**病理谱**也值得先立住：绝大多数是鳞状细胞癌（SCC），按原发部位分鼻咽、口腔、口咽、喉、下咽等亚区；此外还有淋巴瘤、甲状腺癌、涎腺肿瘤等少见类型。**不同亚区的淋巴引流方向、放射敏感性、治疗策略差异巨大**——鼻咽癌对放疗高度敏感且 EBV 相关，喉癌与吸烟高度相关，口咽癌近年 HPV 相关者暴增——「同一个头颈，五种病」是初学时最该记住的话。

头颈癌的另一特点是**病种与生活方式高度相关**：吸烟、饮酒、槟榔与 EBV/HPV 病毒感染是主要病因——不同病因对应的解剖部位、生物学行为与预后各不相同（HPV 阳性的口咽癌预后明显好于吸烟相关者）。这让头颈癌成为「病因-解剖-分子」三线交织的复杂病谱，也让它天然是**个体化放疗**的实验场。

放疗在头颈部的角色分两种：**根治性放疗（definitive）**——以放疗为主、可联合化疗，治疗早期喉癌、鼻咽癌等；**辅助放疗（adjuvant）**——手术后杀灭残存灶，降低局部复发。对多数早期喉癌，放疗与手术疗效相当，而**保喉**（保住发音）使放疗成为首选。

**头颈部放疗术语速查表**：

| 术语 | 含义 |
| --- | --- |
| definitive RT | 根治性放疗（放疗为主） |
| adjuvant RT | 辅助放疗（术后清灶） |
| CCRT | 同步放化疗 |
| SIB | 同步推量（一疗程内不同靶区给不同剂量） |
| EQD2 | 等效 2 Gy 分次剂量 |
| Dmax | 最大剂量（点剂量） |
| xerostomia | 口干症（唾液腺受损） |
| mucositis | 口腔黏膜炎 |

## 2 三大代表病种与治疗策略

**鼻咽癌（NPC）**：与 EB 病毒相关，对放疗高度敏感，是「放疗根治」的典型病种。早期单纯放疗即可；局部晚期行**同步放化疗**（IMRT 70 Gy/33–35 次 + 顺铂），5 年生存率可达 80% 以上。<span class="marginnote">鼻咽癌在中国南方高发，放疗是绝对主力；它包绕脊髓与脑干生长的解剖，让每一条剂量约束都像走钢丝。</span>

**喉癌**：早期声门型（T1–T2）单纯放疗即可根治，且保住嗓音；晚期则选择「保喉综合治疗」——同步放化疗与全喉切除权衡，方案取决于肿瘤范围与患者意愿。

**口咽癌（HPV 相关）**：人乳头瘤病毒相关的口咽癌预后显著更好，治疗正在探索「降级（de-escalation）」——在保证疗效的前提下适当减量，减轻长期毒性。<span class="marginnote">HPV 阳性的口咽癌对放化疗更敏感，年轻患者多、生存期长，因此「远期生活质量」成为与疗效同等重要的考量——这也是个体化治疗的风向标。</span>

**化疗的角色**：局部晚期头颈癌的标准是**同步放化疗**——放疗期间每 3 周一次大剂量顺铂（100 mg/m²），显著提高器官保留率与总生存（第11篇详述）。对不能耐受顺铂者，靶向药物西妥昔单抗（EGFR 抑制剂）是增敏替代方案——它比顺铂的黏膜炎轻，但疗效也略逊，选谁取决于肾功能、体能状态与肿瘤负荷。<span class="marginnote">「同步放化疗 + 顺铂」之所以是头颈癌的基石，不只是增敏：顺铂的 DNA 交联与放疗的 DSB（第2篇）形成「双重打击」，让肿瘤细胞的修复路径双线崩溃——增敏机制落实到分子层面就是这个意思。</span>

**下咽癌与口腔癌**的放疗策略同样个体化：下咽癌早期可选放疗保喉、晚期常需「同步放化疗 ± 挽救性手术」；口腔癌因牙齿、下颌骨相邻，放疗前常需牙科评估（必要时拔除患牙、预留骨坏死风险）。「同一部位的同一分期，因功能诉求不同而方案不同」——头颈放疗的个体化程度，几乎与乳腺癌的内分泌选择一样精细。

## 3 危及器官与剂量约束

头颈部放疗成败，一半看剂量是否给足，一半看器官是否守住。这些约束不是拍脑袋——它们大多来自**剂量-毒性研究汇总（如 QUANTEC）**：例如脊髓 < 50 Gy 罕见瘫痪、> 60 Gy 风险陡增，视交叉超过 55 Gy 失明风险显著升高。物理师把这些「证据数字」写进计划系统的约束表，医生评审时逐条核对。<span class="marginnote">「约束是证据的浓缩」：脊髓、视交叉这类不可逆器官的限值偏保守，因为一旦超限就是永久功能丧失——宁可让靶区剂量略降，也不拿不可逆器官冒险。</span>常用剂量约束（临床近似值，具体依方案而定）：

| 危及器官 | 常用约束 | 主要毒性 |
| --- | --- | --- |
| 脊髓 | Dmax ≤ 45 Gy（小体积 ≤ 50 Gy） | 脊髓病（截瘫） |
| 脑干 | Dmax ≤ 54 Gy | 脑干损伤 |
| 视交叉/视神经 | Dmax ≤ 54–55 Gy | 失明 |
| 腮腺 | 平均剂量 ≤ 26 Gy | 口干（口干症） |
| 下颌骨 | Dmax ≤ 70 Gy（避免热点） | 骨坏死 |
| 耳蜗 | 平均 ≤ 45 Gy | 听力下降 |

**口干症（xerostomia）**是头颈放疗最常见的长期困扰：唾液腺受照即功能受损。IMRT 保护腮腺的策略，使「至少一侧腮腺平均剂量 ≤ 26 Gy」成为计划设计的硬指标。<span class="marginnote">26 Gy 这个数字来自「腮腺平均剂量与口干程度」的剂量-效应研究：平均剂量从 26 Gy 升到 40 Gy，中重度口干的比例几乎翻倍——一个具体数字背后是数百名患者的生活质量数据。</span>

IMRT 对腮腺的保护还讲究「剂量雕刻的取舍」：腮腺常紧贴高危靶区，强行把平均剂量压到 26 Gy 以下可能牺牲靶区覆盖。临床折衷是「保一侧」策略——允许患侧腮腺受照，把**对侧腮腺**的平均剂量压下去，因为只要一侧唾液腺功能尚存，口干就能明显减轻。这又是一次「约束谈判」：靶区优先还是器官优先，由解剖关系与肿瘤风险共同决定。

**脊髓与脑干的保护是硬底线**：它们是真正的「一次性器官」，超限即不可逆。头颈 IMRT 计划里，脊髓与脑干常以「绝对禁区」对待——计划系统里设刚性约束（如脊髓 Dmax < 45 Gy），若某次优化尝试突破，宁可重做计划也不越线；复发后再程放疗时，脊髓的累积剂量评估更是决策的核心。

**视交叉与耳蜗**是头颈放疗里另两个「不可逆」器官：视交叉超 54–55 Gy 有失明风险，耳蜗平均剂量高则导致听力下降——对鼻咽癌这类解剖深在的肿瘤，计划时要在「覆盖鼻咽」「护住视交叉」「压低耳蜗」三线之间反复权衡，这也是头颈 IMRT 目标函数里最常见的三组约束。

## 4 公式解析：EQD2 等效剂量换算

临床常遇到一个问题：不同分次方案之间怎么比？比如「60 Gy/30 次」与「50 Gy/20 次」哪个对晚期反应更狠？**等效 2 Gy 分次剂量（EQD2）**把任何分次方案折算成「按 2 Gy/次等效」的剂量，由 LQ 模型导出：

$$EQD2 = D \cdot \frac{d + \alpha/\beta}{2 + \alpha/\beta}$$

- **第一步，$D$**：总剂量，$d$ 为单次剂量（Gy）。
- **第二步，$\alpha/\beta$**：组织参数。晚期反应组织取 **3 Gy**，肿瘤与早期反应取 **10 Gy**——同一个方案，对两类组织算出的 EQD2 不同。
- **第三步，直观理解**：分子「$d + \alpha/\beta$」衡量单次剂量对这类组织的伤害权重；除以「$2 + \alpha/\beta$」把结果归一化到「以 2 Gy/次为参照」的等效刻度——EQD2 的答案天然是「按 2 Gy/次换算后的等效总剂量」。
- **第四步，算一例**：比较「60 Gy/30 次」与「50 Gy/20 次」。对晚期反应（α/β = 3）：前者 $EQD2 = 60 \times (2+3)/(2+3) = 60$ Gy，后者 $EQD2 = 50 \times (2.5+3)/(2+3) = 55$ Gy；对肿瘤（α/β = 10）：后者 $50 \times 12.5/12 \approx 52$ Gy。**同一个 50 Gy/20 次方案，对肿瘤等效 52 Gy、对晚期组织等效 55 Gy**——它用「单次剂量更大」换肿瘤增益、却牺牲晚期组织，这正是头颈选分次方案时的核心权衡。

**辨析｜易错点：** EQD2 只在「α/β 取对组织」时才有意义。把肿瘤的 10 拿去评估脊髓，会得到完全误导的结论——**报 EQD2 必须注明 α/β 与所针对的组织**。

## 5 靶区勾画与同步推量（SIB）

头颈部靶区勾画是放疗「手艺」的巅峰：**GTV**（可见肿瘤，CT/MRI/PET 融合勾画）→ **CTV**（GTV + 显微浸润与淋巴引流区，按解剖亚区外扩）→ **PTV**（CTV + 摆位误差外扩，通常 3–5 mm）。头颈的 CTV 勾画尤其讲究「按淋巴引流解剖」而非「均匀外扩」——颈部淋巴结按分区（level I–VII）逐个判断，正常组织（腮腺、脊髓）再单独勾画。<span class="marginnote">「按解剖勾画」是头颈放疗的基本功：淋巴结分区不是画同心圆，而是跟着颈动脉鞘、胸锁乳突肌、椎前肌的解剖走——勾画水平的高低，直接决定 PTV 是「精准雕刻」还是「粗放外扩」。</span>

**同步推量（SIB，simultaneous integrated boost）**是头颈 IMRT 的标志性技术：同一疗程内，高危靶区（GTV 所在）与低危靶区（预防性淋巴区）用**不同的分次剂量**同时照完——例如高危区 70 Gy/33 次、低危区 54 Gy/33 次。相比「先照大野再缩野加量」（SEQ），SIB 一次计划完成全部剂量、总疗程更短，是头颈 IMRT 的主流。<span class="marginnote">SIB 的「同一次出束、两套剂量」只有 IMRT 做得到——多叶准直器在同一个射野里就能让不同区域吃不同的剂量，这正是逆向计划的威力所在。</span>

**影像在勾画中的角色**：头颈勾画几乎总是 **CT + MRI/PET 多模态融合**——MRI 对舌根、咽旁间隙等软组织细节远优于 CT，PET 则提示代谢活跃的病灶与淋巴结；融合影像让 GTV 的边界从「猜」变成「看」。定位时的体位固定（热塑膜）与吞咽/颈部位置的重复性，同样直接影响勾画的可信度。

**辨析｜易错点：** SIB 的 70 Gy/33 次与「先 54 Gy 再 16 Gy 推量」并不完全等效——前者是「同步给」、后者是「序贯给」，二者在靶区几何与正常组织受量上都有差异。比较不同方案必须回到 EQD2/BED 语言，不能只比名义剂量。

## 6 放射反应与支持治疗

头颈放疗的急性反应几乎是所有部位中最重的，因为口腔、咽喉黏膜是「每天都在磨损」的快速增殖组织：**口腔黏膜炎（mucositis）**从疗程第 2–3 周出现，吞咽痛、进食困难随之而来；**口干症（xerostomia）**来自唾液腺受损，会持续多年甚至终身；喉咙、声带反应则带来声音嘶哑。<span class="marginnote">头颈放疗的急性反应不是「副作用」而是「治疗的代价」：黏膜炎最重时几乎无法进食，但这一关正是「肿瘤被同步摧毁」的侧面证据——支持治疗的目的，是让患者扛过这一段而不至于中断疗程。</span>

**支持治疗**因此是头颈放疗方案里不可分割的一部分：口腔护理（含漱、保持湿润）、营养支持（鼻饲/胃造瘘保证热量）、疼痛管理与止痛药、必要时暂停治疗给黏膜喘息——但**中断要越短越好**，因为放射生物篇的「加速再增殖」在头颈癌尤其明显，疗程拉长会显著降低局部控制。<span class="marginnote">「能扛就扛、不能扛就休但不恋战」——放疗科对头颈急性反应的态度，本质是 4R 里「再增殖」与「再修复」在时间维度上的精算。</span>

**晚期反应**则包括口干、吞咽障碍、放射性骨坏死（下颌骨）、听力下降、内分泌轴损伤（垂体）与颈部纤维化。随着 HPV 相关口咽癌患者生存期越来越长，「远期生活质量」成为与疗效并列的评审标准——这也是为什么「降级治疗（de-escalation）」成为热门的临床试验方向：疗效不降的前提下，把长期毒性减到最小。

## 7 小结

- 头颈部是放疗「手艺」的集大成者：解剖复杂、功能脆弱、靶区常呈 C 形包绕脊髓——IMRT 很大程度上为它而生。
- 代表病种三分法：鼻咽癌（EBV 相关、放疗敏感）、喉癌（早期放疗保音）、口咽癌（HPV 相关、预后好、探索降级）。
- 剂量约束来自证据（QUANTEC 等）：脊髓 Dmax ≤ 45 Gy、腮腺平均 ≤ 26 Gy——「证据数字」是计划系统约束表的来源。
- **EQD2** 把不同分次方案折到 2 Gy/次参照：同一方案对肿瘤与晚期组织的等效剂量不同，必须注明 α/β。
- **SIB** 让高危与低危靶区在同一次出束中各得其所；反应管理（黏膜炎、口干、营养支持）是方案的组成部分。
- 头颈放疗的长期生活质量（保音、保唾液、防骨坏死）是疗效之外的第二个评审维度。
- **同步放化疗**（大剂量顺铂）是局部晚期头颈癌的标准，增敏的分子本质是「顺铂 DNA 交联 + 放疗 DSB」的双线打击。
- 头颈放疗的**随访**长期关注保音、吞咽、口干与继发肿瘤；HPV 状态已进入分期系统，并驱动降级治疗的探索。

在下一节，我们将顺着头颈部继续向下，进入**胸部肿瘤放疗（肺癌 / 食管癌）**——那里没有黏膜炎，却多了「会呼吸的肺」与「不停蠕动的食管」，运动管理成为新的主战场。
