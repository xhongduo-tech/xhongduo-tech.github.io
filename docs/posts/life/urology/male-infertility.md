## 为什么从男性不育症开始

这是本专题的最后一篇，也为泌尿外科学收尾。**男性不育症（male infertility）**是男科学的核心临床问题：约 15% 的夫妇在无避孕一年后仍未怀孕，其中男方因素占约 50%。它横跨泌尿、内分泌与生殖医学，把前面学过的解剖（精索、附睾）、内分泌（睾酮轴）与显微手术（显微镜下精索静脉结扎）全部串起来——是一个完美的「综合复习题」。

**男性不育症**：指婚后规律性生活未避孕一年以上而未能使女方怀孕，经男方检查发现异常。**诊断的第一步永远是问「是哪一方的因素」**——夫妇双方同查。<span class="marginnote">「不育检查是『夫妻二人组』检查」：女方因素约占 1/3、男方约 1/3、双方共因约 1/3——所以<strong>先同查、再分诊</strong>，别让任何一方单方面背锅。</span>

## 1 精子生成的「生产线」

精子在**睾丸曲细精管**内生成，依赖**下丘脑-垂体-睾丸轴**的精确调控。这条内分泌轴的每一环都可以「出故障」：

| 环节 | 分泌物质 | 主要作用 |
| --- | --- | --- |
| 下丘脑 | GnRH（促性腺激素释放激素） | 启动整条轴的「总开关」 |
| 垂体前叶 | FSH（卵泡刺激素） | 刺激精原细胞、促生精 |
| 垂体前叶 | LH（黄体生成素） | 刺激 Leydig 细胞产睾酮 |
| 睾丸 Leydig 细胞 | 睾酮 | 维持精子生成与性征 |
| 睾丸 Sertoli 细胞 | 抑制素等 | 负反馈抑制 FSH |
| 附睾 | 促进精子成熟获能 | 让精子获得活力 |

「FSH 管精子『数量』、LH 管睾酮、睾酮管『质量』」——内分泌轴的任何一环异常（如垂体瘤、Kallmann 综合征），都会体现在精液报告上。**精子生成需要适宜温度**：睾丸位于体外、阴囊可调节温度，**隐睾、精索静脉曲张、发热**都会因温度升高损害生精——这是很多不育病因的物理基础。

## 2 病因分类：梗阻、生精障碍与内分泌

男性不育的病因分三大类：

- **生精障碍（睾丸因素）**：**精索静脉曲张（varicocele）**——最常见可手术纠正的因素，约占原发性不育的 35%；染色体异常（**克氏综合征 XXY**、Y 染色体微缺失）；感染后（腮腺炎性睾丸炎）；药物与毒物。
- **梗阻性因素**：输精管道梗阻，如**先天性双侧输精管缺如（CBAVD）**——与 **CFTR 基因突变（囊性纤维化相关）**密切相关；附睾梗阻、输精管结扎术后。<span class="marginnote">「无精子症先分清『堵了』还是『不产』」：梗阻性无精子症（OA）睾丸能生精，只是运不出来——只要穿刺能取出精子，辅助生殖就有望。</span>
- **内分泌因素**：**低促性腺激素性性腺功能减退（如 Kallmann 综合征）**、高泌乳素血症、甲状腺与肾上腺疾病。

### 病因速查 | 常见病因一览

| 病因 | 常见表现 | 可纠正性 |
| --- | --- | --- |
| 精索静脉曲张 | 阴囊坠胀、精液异常 | 手术可纠正 |
| 隐睾 | 单侧/双侧睾丸缺如 | 早期固定可防 |
| CBAVD | 无精子、精液量少 | 手术取精 |
| 克氏综合征 | 小而硬睾丸、FSH 高 | 不可逆，靠供精/取精 |
| 腮腺炎性睾丸炎 | 腮腺炎后睾丸萎缩 | 多不可逆 |
| 低促性腺激素 | 嗅觉异常、性征不足 | 激素可恢复生精 |

这张表说明：「不育能否治」取决于**病因类别**——梗阻可以绕过去，激素可以补回来，而生精上皮一旦破坏则多为不可逆。

## 3 精液分析：WHO 参考值

**精液分析**是不育评估的金标准，WHO 第 5 版（2010）给出了参考下限：

| 参数 | 参考下限 |
| --- | --- |
| 精液量 | ≥1.5 mL |
| 精子浓度 | ≥1500 万/mL |
| 精子总数 | ≥3900 万/次 |
| 前向运动 | ≥32% |
| 精子活力 | ≥40% |
| 正常形态 | ≥4% |
| 白细胞 | <100 万/mL |

**判读要点**：一次异常不能定论，需**间隔复查 2–3 次**；无精子症者还须区分「真无精」（生精障碍）与「假无精」（梗阻）。<span class="marginnote">「精液分析是『第一块多米诺骨牌』」：异常了，再按激素与遗传层层深入——但数值临界者先复查，别急着扣帽子。</span>

## 4 诊断流程：层层深入

诊断走「从无创到有创」的阶梯：

- **病史**：婚育史、隐睾手术史、腮腺炎史、药物史、职业暴露。
- **查体**：睾丸体积、精索静脉曲张程度、输精管触诊。
- **精液分析**：核心检查，见上节。
- **激素测定**：FSH/LH/睾酮/泌乳素，判断是睾丸源还是垂体源。
- **遗传检测**：克氏综合征核型、Y 染色体微缺失、CFTR 突变。
- **影像与功能**：阴囊超声、输精管造影、附睾穿刺评估梗阻。<span class="marginnote">「先分清大方向，再做昂贵检查」：FSH 显著升高多提示生精衰竭，做再多造影也无益；FSH 正常伴无精子，则更可能梗阻——激素指导下一步。</span>

## 5 治疗：从药物到显微手术再到辅助生殖

治疗按「能否恢复自然生育 → 是否需要辅助生殖」推进：

- **内分泌治疗**：低促性腺激素者用 **hCG/hMG** 或 GnRH 恢复生精；高泌乳素血症用多巴胺激动剂（溴隐亭）。
- **手术**：**显微镜下精索静脉结扎（micro-varicocelectomy）**是精索静脉曲张的金标准——在显微镜下结扎曲张静脉、保留动脉与淋巴管，改善精液质量；梗阻者行**显微输精管附睾吻合**或**输精管再通**。<span class="marginnote">「显微手术把『粗活』做成『细活』」：显微镜下精索静脉结扎能避开动脉与淋巴管，复发与并发症远低于高位结扎——「看得到才动得了」。</span>
- **辅助生殖技术（ART）**：**宫腔内人工授精（IUI）**、**体外受精（IVF）**与 **ICSI（胞浆内单精子注射）**——1992 年 Palermo 等开创的 ICSI 只需**一条精子**即可受精，彻底改变了严重少弱精症与梗阻性无精子症的治疗。
- **取精手术**：**睾丸精子提取（TESE）**与 **micro-TESE** 用于无精子症者取精；**精子库保存**适用于化疗/放疗前的肿瘤患者——与睾丸肿瘤章节呼应。

### 治疗阶梯速查

| 层级 | 手段 | 适用 |
| --- | --- | --- |
| 一线 | 内分泌 / 显微手术 | 病因明确可纠者 |
| 二线 | IUI | 轻度少弱精、宫颈因素 |
| 三线 | IVF / ICSI | 中重度精子异常 |
| 四线 | 手术取精 + ICSI | 无精子症 |
| 补充 | 供精 / 收养 | 不可逆生精衰竭 |

**生育力保存**是男科常被忽视却意义重大的一环：对肿瘤（如睾丸癌、淋巴瘤）患者在化疗放疗前，以及面临高风险职业暴露者，**精液冷冻保存**是成本低、操作易的「生育保险」——先把精子存进银行，治疗后再决定怎么用。

**辅助生殖的伦理与知情**：ICSI 等技术的使用要考虑遗传传递风险（如 CBAVD 患者的 CFTR 突变），必要时行植入前遗传学检测；同时要如实向患者讲清成功率、费用与代际风险——**技术越强，责任越重**。

## 6 小结

- **男性不育约占不孕夫妇的一半**；检查要**夫妇同查**。
- 精液分析参考值以 WHO 第 5 版为准，需间隔复查确认。
- 无精子症先分清「梗阻」与「生精障碍」，再决定取精方式。
- 化疗/放疗前建议**精子库保存**，为生育留后路。
- 精子生成靠**下丘脑-垂体-睾丸轴**，睾丸温度、激素、血管均影响生精。
- 病因分**生精障碍、梗阻、内分泌**三大类；**精索静脉曲张**与 **CBAVD（CFTR 突变）**是两个标志性病因。
- 诊断核心是**精液分析**（WHO 参考值）+ 激素 + 遗传检测，按阶梯层层深入。
- 治疗从**内分泌/显微手术**到 **ICSI 与手术取精**层层递进——「一条精子也能成家」。
