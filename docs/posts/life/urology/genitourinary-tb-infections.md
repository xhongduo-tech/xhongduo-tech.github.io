## 为什么从泌尿生殖系结核开始

前面的感染都来自「普通细菌」。但泌尿外科还须警惕一类**特异性感染**——以**结核**为代表，其临床表现狡猾、诊断常被延误、破坏却不可逆。结核杆菌经血流播散到肾，在肾内形成病灶，随后沿尿路下行蔓延，造成输尿管狭窄、膀胱挛缩——**它是「无菌性脓尿 + 血尿」最经典的答案**。这一篇讲结核如何从肾「殖民」到膀胱，并顺带介绍其他特异性感染。

**泌尿生殖系结核（genitourinary tuberculosis）**：由**结核分枝杆菌**经血行播散所致，通常继发于肺或身体其他部位的原发结核，但**原发灶可能早已钙化、无症状**。<span class="marginnote">「肺是最初的战场，肾是最后的宿营地」：结核菌经血行到达肾皮质形成微小病灶，多数自行愈合，只有少数进展——所以泌尿结核可发生在「从没得过大病」的人身上。</span>

## 1 发病机制：从肾到膀胱的「下行之路」

结核菌经血行到达**肾皮质**形成结核灶，灶内细菌可长期潜伏。当病灶进展，细菌进入**髓质与肾盂**，破坏肾实质，并在尿中下行：

- **肾**：干酪样坏死、空洞形成，晚期可发生**自截肾（autonephrectomy）**——肾被破坏并钙化、完全失去功能，影像上呈「油灰肾」。
- **输尿管**：结核性肉芽肿与纤维化导致**多发狭窄**，造成肾积水。
- **膀胱**：结核性膀胱炎可导致**膀胱挛缩（contracted bladder）**——容量锐减、尿频严重。<span class="marginnote">「一条尿路、三种命运」：肾被吃空（自截肾）、输尿管被掐细（狭窄积水）、膀胱被箍小（挛缩）——结核在整条尿路上留下的都是「纤维化 + 破坏」。</span>

**男性生殖系**：结核可累及附睾（附睾结核——**串珠样硬结**）、前列腺与精囊，表现为阴囊慢性肿物与不育。

## 2 诊断：抓住「无菌性脓尿」

**最经典的线索是「无菌性脓尿」**：尿常规见大量白细胞，但普通培养阴性——此时必须想到结核。<span class="marginnote">「脓尿 + 血尿 + 普通培养阴性」三件套是泌尿结核的教科书信号：普通培养基养不出结核菌，所以「培养阴性」不等于「没有感染」——要主动查抗酸杆菌与核酸。</span>

**确诊检查**：**连续多次晨尿找抗酸杆菌（涂片）、结核菌培养（金标准）与核酸扩增（PCR）**；**IVU 或 CTU** 显示肾盏破坏、输尿管多发狭窄、自截肾；**膀胱镜**见结核性黏膜充血与溃疡、挛缩膀胱。<span class="marginnote">「CTU 上的肾盏边缘『虫蚀样』改变」是肾结核的经典影像：肾乳头被破坏后肾盏边缘参差不齐——多发性狭窄 + 钙化 + 小膀胱，是泌尿结核的影像三连。</span>

**鉴别**：与非特异性肾盂肾炎、肾肿瘤、血吸虫病等区分。

## 3 治疗：抗结核为主，手术为辅

**药物治疗是主体**：标准**四联抗结核方案——利福平、异烟肼、吡嗪酰胺、乙胺丁醇（RIPE）**，强化期 2 个月 + 巩固期 4–7 个月，总疗程 **6–9 个月**（泌尿结核常需更长）。治疗期间监测肝功能、肾功能与视神经毒性（乙胺丁醇）。<span class="marginnote">「手术是配角、药物是主角」：现代泌尿结核的治疗以抗结核药物为绝对核心，多数患者无需手术——手术只留给「已造成的破坏」（如狭窄、自截肾、挛缩膀胱）。</span>

**手术指征**：**无功能自截肾**行患肾切除（术前抗结核至少数周）；**输尿管狭窄**行狭窄段切除再吻合或支架；**膀胱挛缩**容量过小者行**膀胱扩大术（肠代膀胱）**。<span class="marginnote">「先吃药、后手术」是泌尿结核的铁律：术前一-数月抗结核，防止手术导致结核播散与切口不愈合——即使切除无功能肾，也必须在抗结核「掩护」下进行。</span>

## 4 其他特异性感染

**血吸虫病（schistosomiasis）**：埃及血吸虫卵沉积膀胱壁，引起慢性炎症、纤维化与钙化，并与**膀胱鳞癌**密切相关——故有「血吸虫膀胱」之称。治疗用吡喹酮，膀胱挛缩与癌变需手术。<span class="marginnote">「寄生虫也能致癌」：血吸虫与膀胱鳞癌、华支睾吸虫与胆管癌，都是慢性炎症驱动的癌变——特异性感染的长期后果，往往比急性期更可怕。</span>

**淋病与衣原体尿道炎**（性传播感染）可致尿道狭窄；**放线菌病、棘球蚴病**等罕见感染亦有泌尿表现，诊断依赖影像与病理。

## 5 泌尿系结核的诊断线索速查

| 线索 | 提示 | 检查动作 |
| --- | --- | --- |
| 无菌性脓尿 | 结核首选怀疑 | 连续晨尿抗酸杆菌 |
| 血尿 + 尿频 | 膀胱结核 | 膀胱镜 + 尿检 |
| 肾盏虫蚀样破坏 | 肾结核 | CTU/IVU |
| 输尿管多发狭窄 | 结核性狭窄 | 尿路成像 |
| 自截肾（油灰肾） | 晚期肾结核 | 评估分肾功能 |
| 附睾串珠样硬结 | 附睾结核 | 查体 + 影像 |
| 膀胱挛缩 | 结核性膀胱炎 | 膀胱容量评估 |
| 培养阴性反复 UTI | 非结核耐药感染 | 全面排查 |

「先想到，才查得到」：无菌性脓尿 + 血尿 + 培养阴性这三件套，就是泌尿结核的『报警组合』。

## 6 抗结核治疗与手术的配合

- **四联方案（RIPE）**：利福平、异烟肼、吡嗪酰胺、乙胺丁醇，总疗程 6–9 个月。
- **监测**：肝功能、肾功能、视力（乙胺丁醇）、血尿酸。
- **手术指征**：自截肾切除、狭窄修复、挛缩膀胱扩大——术前需抗结核「掩护」。
- **术后**：继续完成全疗程抗结核，防止播散与复发。
- **随访**：定期查尿、影像与肾功能，警惕对侧受累。<span class="marginnote">「药物是主角、手术是配角」：现代泌尿结核绝大多数靠药物治愈，手术只处理已造成的破坏——先吃药、后手术是铁律。</span>

## 7 泌尿结核的预后与随访

- **疗程依从**：全程完成抗结核，漏服可致耐药。
- **影像随访**：观察狭窄、积水与钙化变化。
- **肾功能监测**：结核性肾损伤可进展，需定期复查。
- **对侧受累**：双侧病变者更需密切随访。
- **生活质量**：膀胱挛缩者可考虑膀胱扩大术改善容量。

「泌尿结核是一场持久战」：药物治疗 6–9 个月只是开始，影像与肾功能的长期随访才是真正的收尾。

## 8 特异性感染的鉴别与预防

| 感染 | 病原/来源 | 特点 |
| --- | --- | --- |
| 泌尿结核 | 结核分枝杆菌 | 无菌性脓尿、破坏性 |
| 血吸虫病 | 埃及血吸虫 | 膀胱钙化、鳞癌风险 |
| 淋病/衣原体 | 性传播 | 尿道炎、狭窄 |
| 放线菌病 | 厌氧菌 | 慢性脓肿、瘘管 |
| 棘球蚴病 | 绦虫幼虫 | 囊性占位 |

「特异性感染的共同点：狡猾、破坏、可防」——多数可通过公共卫生与规范治疗加以控制。

## 9 泌尿结核的管理要点

- **多学科**：结核专科 + 泌尿外科 + 影像科协作。
- **传染防控**：有活动性肺结核者先隔离与规范治疗。
- **营养支持**：结核是消耗性疾病，营养是治疗的一部分。
- **并发症**：狭窄、积水、无功能肾按需处理。
- **患者教育**：坚持全疗程、规律复查，勿自行停药。

「泌尿结核的现代治疗，是内科与外科的接力」：药物打底、手术补漏、随访收尾，环环相扣才能治愈。

## 10 小结

- **泌尿生殖系结核**由结核菌血行播散而来，典型信号是**无菌性脓尿 + 血尿 + 培养阴性**。
- 病灶沿尿路「下行」，造成肾破坏（自截肾）、输尿管狭窄与膀胱挛缩。
- 确诊靠**连续晨尿找抗酸杆菌、结核培养与 PCR**，影像见肾盏虫蚀样改变。
- 治疗以 **RIPE 四联抗结核 6–9 个月**为主；手术仅处理已造成的破坏，且需抗结核掩护。
- **血吸虫病**与膀胱鳞癌相关，是慢性特异性感染的癌变示范。

- 无菌性脓尿 + 血尿 + 培养阴性是泌尿结核的报警组合。
- 抗结核药物是主角、手术是配角，先吃药后手术。

- 泌尿结核的典型信号是「无菌性脓尿 + 血尿 + 培养阴性」。
