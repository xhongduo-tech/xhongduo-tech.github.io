# 睾丸肿瘤

<div class="epigraph">

## 为什么从睾丸肿瘤开始

前面三篇讲的肾癌、上尿路癌与膀胱癌多是中老年疾病。**睾丸肿瘤**则相反：它是 15–35 岁男性最常见的恶性肿瘤，却也是**治愈率最高的实体肿瘤之一**——局限期治愈率超过 95%，即使发生转移，现代综合治疗仍能挽救大多数患者。它把「肿瘤学三大支柱——手术、化疗、放疗」用到了极致，是理解「癌症并非必死」的最佳案例。

**睾丸肿瘤（testicular tumor）**：绝大多数为**生殖细胞肿瘤（germ cell tumor, GCT）**，起源于精原干细胞。其「青春与快愈」双标签，都来自它独特的生物学与对化疗的高度敏感。<span class="marginnote">「早期是肿瘤学里最值钱的一个词」：睾丸位于体表、易于自查，<strong>早期发现</strong>让多数睾丸肿瘤在局限期即被治愈——这也让它成为「体检摸一摸就能救命」的罕见癌症。</span>

## 1 分类与病因：精原细胞瘤与非精原细胞瘤

**生殖细胞肿瘤**按是否含精原细胞瘤成分分为两大类，治疗策略完全不同：

- **精原细胞瘤（seminoma）**：占约 50%，对**放疗特别敏感**，好发于 30–40 岁。
- **非精原细胞瘤（nonseminoma）**：含胚胎癌、卵黄囊瘤、绒毛膜癌与畸胎瘤等成分，好发于更年轻的 20–30 岁，对**化疗高度敏感**，但对放疗不如精原细胞瘤敏感。<span class="marginnote">「精原细胞瘤吃放疗、非精原细胞瘤吃化疗」是两类肿瘤最关键的分野——所以病理报告里的「是不是精原」直接决定治疗路径。</span>

**危险因素**：**隐睾（cryptorchidism）**是最明确的危险因素——未下降的睾丸患癌风险升高数倍，**睾丸固定术（orchiopexy）**应在儿童早期完成以降低风险；其他因素包括家族史、对侧睾丸曾患癌、克氏综合征（Klinefelter）等。<span class="marginnote">隐睾既增加患癌风险、又让睾丸「摸不到」而延误发现——6–12 个月内及早手术固定，是泌尿外科少有的「预防癌症」操作。</span>

## 2 诊断：肿瘤标志物三剑客

**无痛性睾丸肿块**是典型表现，需与附睾炎、鞘膜积液鉴别——**阴囊超声**是首选影像，能区分实质肿块与囊性病变。**诊断性金标准是经腹股沟根治性睾丸切除术（radical inguinal orchiectomy）**：经腹股沟切口整块切除患睾与精索，而不是经阴囊切口——阴囊切口会打乱淋巴回流，增加腹股沟区复发。

**肿瘤标志物**是睾丸肿瘤的「三剑客」：

- **AFP（甲胎蛋白）**：卵黄囊瘤分泌，**精原细胞瘤不升高**——AFP 升高提示含非精原成分。
- **hCG（人绒毛膜促性腺激素）**：绒毛膜癌分泌，精原细胞瘤亦可轻度升高。
- **LDH（乳酸脱氢酶）**：反映肿瘤负荷，是分期与预后的非特异指标。<span class="marginnote">三剑客的作用有二：术前帮助判断成分与分期，术后随访监测复发——标志物「降而复升」是复发的最早警报。</span>

**分期**：TNM 分期结合标志物（S 分期）与淋巴结/肺转移情况。腹膜后淋巴结（RPLN）是睾丸肿瘤最先转移的站点——这决定了后续手术的靶区。

## 3 治疗：手术、化疗与放疗的组合拳

**局限期**以**根治性睾丸切除**为基础：**精原细胞瘤**术后可行放疗或化疗或监测；**非精原细胞瘤**低危可监测，高危行**腹膜后淋巴结清扫（retroperitoneal lymph node dissection, RPLND）**或化疗。<span class="marginnote">RPLND 不是「随便掏淋巴结」：睾丸的淋巴回流第一站就是腹膜后大血管旁——把这条「淋巴公路」沿路扫清，才能杜绝复发。现代机器人 RPLND 已大幅减少创伤。</span>

**转移性**以**化疗**为核心：**BEP 方案（博来霉素 + 依托泊苷 + 顺铂）**是标准——以铂类为主的化疗让转移性睾丸癌的治愈率从 1970 年代之前的不足 20% 跃升到 80% 以上。<span class="marginnote">顺铂把睾丸癌从「死刑」变成「可治」的传奇，始于 1970 年代印第安纳大学 Einhorn 的研究——化疗后仍可残留畸胎瘤成分，需手术切除，即「化疗后 RPLND」。</span>

**预后与随访**：睾丸癌总体 5 年生存率约 95% 以上；但治疗（化疗、放疗）有远期心血管与第二肿瘤风险，需长期随访。**对侧睾丸与生育**：不少患者可保留生育功能，必要时术前**精子库（sperm banking）**保存。

## 4 肿瘤标志物与成分对应速查

| 标志物 | 提示成分 | 临床含义 |
| --- | --- | --- |
| AFP 升高 | 卵黄囊瘤（非精原） | 精原细胞瘤不升高 |
| hCG 显著升高 | 绒毛膜癌 | 恶性度较高 |
| hCG 轻度升高 | 精原细胞瘤 | 少数精原亦可 |
| LDH 升高 | 肿瘤负荷 | 分期与预后指标 |
| 三者均正常 | 纯精原/畸胎瘤 | 不能排除肿瘤 |

「AFP 一票否决精原」：若 AFP 升高，哪怕病理像精原，也要按非精原治疗——标志物是病理的重要补充，两者结合才能定准治疗方案。

## 5 治疗决策与随访要点

- **局限期**：根治性睾丸切除为主，精原按风险选放疗/化疗/监测，非精原按风险选监测/化疗/RPLND。
- **转移期**：BEP 化疗是基石，残留肿块行手术切除（化疗后 RPLND）。
- **随访**：按方案定期复查标志物、胸片与腹部影像——「标志物降而复升 = 复发警报」。
- **生育保护**：治疗前建议**精子库保存**，化疗可能影响生精。
- **心理支持**：年轻患者对性功能与生育的担忧，需坦诚沟通。<span class="marginnote">「睾丸癌是『医学征服癌症』的范例」：从 1970 年代的近乎绝症到今天的 >95% 治愈率，靠的是手术 + 铂类化疗 + 放疗的组合——它证明「癌症不等于死刑」。</span>

## 6 分期与治疗路径速查

| 情形 | 标准处理 |
| --- | --- |
| 精原 I 期（低危） | 根治性切除 + 放疗/化疗/监测 |
| 精原 II 期 | 放疗或化疗 |
| 非精原 I 期（低危） | 根治性切除 + 监测 |
| 非精原 I 期（高危） | 辅助化疗或 RPLND |
| 转移性 | BEP 化疗 + 残留灶切除 |
| 复发/难治 | 挽救化疗 + 大剂量 + 干细胞 |

「分期决定强度」：I 期以手术 + 监测为主，避免过度治疗；转移期以化疗为核心——睾丸癌的治疗阶梯清晰而高效，是「该少就少、该狠就狠」的典范。

## 7 睾丸肿瘤的「预防」与患者教育

睾丸肿瘤虽无法完全预防，但有两件事可以显著改善结局：

- **隐睾及早手术固定**：6–12 个月内行睾丸固定术，降低患癌风险——这是泌尿外科少有的「预防癌症」操作。
- **自我检查**：每月洗浴后自查睾丸，发现无痛性硬结及时就医——**早期发现让治愈率超过 95%**。
- **对侧健康**：一侧患癌者对侧睾丸需定期自查与超声随访。
- **症状认知**：不要等到疼痛才就医——无痛性肿块更要警惕。
- **治疗后的生活**：随访与生育力管理（精子库）是康复的一部分。<span class="marginnote">「睾丸癌是为数不多『摸一摸就能救命』的癌症」：位置表浅、易于自查，一次及时的就医可能就换来根治——患者教育是性价比最高的「治疗」。</span>

## 8 睾丸肿瘤的综合治疗路径再梳理

把手术、化疗与放疗的配合关系再理一遍，是理解睾丸癌的关键：

- **手术是前提**：根治性腹股沟睾丸切除是诊断 + 治疗的第一步，经阴囊切口是禁忌。
- **化疗是利器**：BEP 方案（博来霉素 + 依托泊苷 + 顺铂）对生殖细胞肿瘤高度敏感，是转移期的核心。
- **放疗是配角**：主要用于精原细胞瘤的局部与区域控制。
- **RPLND 是清扫**：清除腹膜后转移站，可分「治疗性」与「分期性」。
- **残留灶处理**：化疗后残留肿块需手术切除，病理决定后续方案。

「手术定盘、化疗攻坚、放疗补漏」——三件武器的配合，让睾丸癌成为治愈率最高的实体肿瘤之一，也为「综合治疗」提供了最好的教科书范例。

## 9 小结

- **睾丸肿瘤**是 15–35 岁男性最常见的恶性肿瘤，绝大多数为**生殖细胞肿瘤**。
- 分**精原细胞瘤**（吃放疗）与**非精原细胞瘤**（吃化疗）两大类，治疗路径完全不同。
- **隐睾**是最明确的危险因素，早期睾丸固定术可降低风险。
- 诊断靠**阴囊超声 + 根治性腹股沟睾丸切除**；**AFP/hCG/LDH 三剑客**用于分期与随访。
- **BEP 化疗**把转移性睾丸癌治愈率提升到 80% 以上；总体 5 年生存率 >95%。

- 根治性睾丸切除必须经腹股沟切口，经阴囊切口是禁忌。

- 分期决定治疗强度：I 期以手术+监测为主，转移期以化疗为核心。

- 自我检查与隐睾及早固定，是睾丸癌最重要的「预防」手段。
