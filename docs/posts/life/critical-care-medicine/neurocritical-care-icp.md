# 神经重症：颅内压增高与脑损伤

## 为什么神经重症自成体系

前面的章节处理「身体」的器官，神经重症处理的是「意识与大脑」。大脑有两点使它区别于所有其他器官：**它的能量消耗极高却几乎没有储能**（缺血几分钟就不可逆），以及**它被装在一个容积固定的硬壳（颅骨）里**——颅内的任何占位（血肿、水肿、肿瘤）都会挤压脑组织，甚至把脑干压出枕骨大孔。因此神经重症的全部核心，浓缩成一条公式：**CPP = MAP − ICP**。上一节在肝衰竭里我们首次遇见它，这一节把它展开成神经重症的完整作战体系：颅内压增高的机制、监测、阶梯治疗，以及重症脑损伤（TBI）与卒中的管理原则。

## 1 颅内压增高的病理：Monroe–Kellie 学说

**颅内压（intracranial pressure，ICP）**：颅腔内容物（脑组织、脑脊液、血液）对颅壁产生的压力，正常成人约 5–15 mmHg。

**Monroe–Kellie 学说**是理解 ICP 的第一性原理：**颅腔容积固定，颅内三种内容物（脑组织约 80%、脑脊液约 10%、血液约 10%）的体积之和必须恒定**。任何一种内容物增多（脑水肿、脑积水、占位出血），必须挤压其他内容物来代偿——先是脑脊液被挤出颅腔、静脉血被压缩，当这些「可压缩空间」用完，ICP 开始陡峭上升。<span class="marginnote">Monroe–Kellie 学说像「一个满罐子装不下更多水」：罐子（颅骨）容积固定，先能挤掉的是 CSF 与静脉血（缓冲），缓冲耗尽后，任何再增加一点内容物都会让压力急剧飙升——这就是「压力—容积曲线」的陡峭段，也是脑疝发生的临界区。</span>

**脑疝（herniation）**：ICP 过高把脑组织从硬壳的缺口挤出。最常见、最致命的是**小脑幕裂孔疝**（海马回钩疝）与**枕骨大孔疝**。临床警报信号：**瞳孔不对称（一侧散大）+ 对侧偏瘫 + 意识恶化**，以及 Cushing 三联征（高血压、心动过缓、呼吸不规则）——这是脑疝濒临的信号，必须立即处理。

## 2 脑损伤的病理生理：缺血的恶性循环

重症脑损伤（TBI、卒中、缺氧性脑病）共享一条缺血的恶性循环：

**能量衰竭 → 细胞毒性水肿 → ICP 升高 → CPP 下降 → 缺血加重 → 能量更衰竭**。

拆开看：

**原发性损伤**：撞击/缺血/出血本身造成的即刻结构损伤（不可逆，但可防其扩大）。
**继发性损伤**：损伤后数小时到数天内发展的病理过程——缺血、水肿、炎症、氧化应激、兴奋性毒性。**神经重症管理的一切努力，都是在防止继发性损伤**——把「可预防的恶化」压到最低。<span class="marginnote">「原发性损伤是命运，继发性损伤是战场」——这句话是神经重症的座右铭。医生无法逆转撞击那一瞬的损伤，但能通过维持 CPP、控制 ICP、防低氧低血压，阻止「本来能好的脑组织」继续坏死。这也是为什么神经重症如此强调「时间」与「细节」。</span>

**脑血流自动调节**：正常脑在 MAP 60–150 mmHg 范围内维持恒定血流（自动调节）。脑损伤后自动调节受损，脑血流随 MAP 被动波动——低血压直接缺血，高血压直接加重水肿。因此**维持 MAP 稳定**是神经重症的底线。

## 3 颅内压监测：直接测还是间接看

ICP 监测的指征：**重度 TBI（GCS ≤ 8 + 影像异常）**是经典指征；其他如大面积卒中、脑积水、开颅术后也常监测。

监测方式：

**脑室内导管（EVD）**：金标准，置入侧脑室，可测压也可引流脑脊液降压——「既是压力计又是泄压阀」。
**脑实质探头**：置入脑组织，测压准确但无法引流。
- **间接指标**：床旁超声视神经鞘直径、CT 中线移位、瞳孔与意识状态——无创但不如直接测压精确。<span class="marginnote">EVD 是「一箭双雕」的典型：它既是监测（读数）又是治疗（引流 CSF 降 ICP）。但所有侵入性监测都有感染风险（脑室炎），置管越久风险越高——「监测的必要性每日评估」的纪律在这里同样适用。</span>

**CPP 目标**：成人 TBI 通常 CPP 60–70 mmHg。ICP > 22 mmHg 持续升高，需启动降颅压阶梯。

## 4 降颅压阶梯：从体位到去骨瓣

ICP 增高的治疗是一个**阶梯式升级**的过程，从低成本低风险开始：

| 层级 | 措施 | 机理 | 说明 |
| --- | --- | --- | --- |
| 0 | 床头抬高 30°、颈部中立位 | 促进静脉回流，降低颅静脉压 | 零成本、持续做 |
| 1 | 镇静镇痛、避免发热/抽搐 | 降脑代谢与脑血流 | 躁动与高热都升 ICP |
| 2 | 高渗治疗：甘露醇 / 高渗盐水 | 渗透性脱水，把脑组织水分拉出 | 监测渗透压与钠，警惕反跳 |
| 3 | 脑脊液引流（EVD） | 直接减压 | 有脑室置管者 |
| 4 | 目标温度管理 / 巴比妥昏迷 | 降代谢率 | 难治性 ICP 的深度手段 |
| 5 | 去骨瓣减压术（DC） | 打开颅骨给脑组织「扩容」 | 顽固性颅内高压的最后手段 |

辨析｜易错点：**降颅压治疗要看「颅内容积」而非只盯数值**。甘露醇的渗透性脱水效果是暂时的，若原发病（血肿扩大、进行性脑水肿）未控制，几小时后 ICP 会反跳。降颅压不是「把数字压下去」，而是「给原发病治疗争取时间」——所以每一步阶梯都必须同步处理病因（清血肿、抗凝逆转、去水肿病因）。<span class="marginnote">降颅压是「治标为治本服务」的缩影：甘露醇、引流、去骨瓣都只是把 ICP 这个「症状」压住，真正决定预后的是原发病的可逆性。重症里「症状管理」与「病因管理」从来是并行而非先后。</span>

## 5 重型颅脑损伤（TBI）的管理：从急诊到 ICU

**重型颅脑损伤（severe TBI）**：GCS ≤ 8 的创伤性脑损伤，是神经重症最常见的入口。

TBI 管理的 ICU 要点：

**避免二次打击**：低血压（SBP < 90）与低氧（SpO₂ < 90）是 TBI 最致命的二次打击，必须第一时间纠正——「先保命再护脑」。
**气道与通气**：GCS ≤ 8 需插管保护气道；通气目标 PaCO₂ 35–40 mmHg（**避免过度通气**致脑血管收缩，除非有脑疝紧急征象）。
- **血压目标**：维持 MAP 高一些（保证 CPP），常用去甲肾上腺素滴定；避免高血压加重出血。
- **体温**：避免发热（发热升高脑代谢与 ICP）。
- **血糖**：控制但不偏低（低血糖直接损伤脑）。
- **深静脉血栓预防**：TBI 有出血风险，DVT 预防时机需权衡，通常伤后 24–48h 后低分子肝素。
- **手术指征**：急性硬膜外/硬膜下血肿、凹陷性骨折、颅内高压顽固者需手术。<span class="marginnote">TBI 是「时间敏感型」疾病的最佳教材：硬膜外血肿有一个经典的「清醒间期（lucid interval）」，随后因血肿扩大迅速恶化——从能说话到脑疝可能只有几十分钟。CT 与手术的响应速度，直接决定这类患者的生死。</span>

## 6 卒中与蛛网膜下腔出血的神经重症

**急性缺血性卒中（AIS）**：静脉溶栓（4.5h 窗）与取栓（大血管闭塞，6–24h 窗）是治疗核心；ICU 关注出血转化、脑水肿、血压管理（溶栓前 BP < 185/110，溶栓后 24h 内 < 180/105）。大面积半球梗死的**恶性脑水肿**需去骨瓣减压（有明确获益证据）。
**脑出血（ICH）**：早期控制血压（SBP < 140 有争议但常被采用）、逆转抗凝（维生素 K、凝血酶原复合物）、控制 ICP、警惕血肿扩大。
- **蛛网膜下腔出血（SAH）**：最大的威胁是**血管痉挛/迟发性脑缺血（DCI）**（出血后 3–14 天）：处理用「3H 疗法」演化而来的精化方案——维持血容量（防低容量）、维持血压（防低血压）、必要时钙拮抗剂（尼莫地平）与血管内干预。

<span class="marginnote">不同卒中的血压目标「南辕北辙」：缺血性卒中溶栓后要<strong>控在 180/105 以下</strong>，脑出血早期要<strong>积极降压到 140</strong>，而 SAH 的血管痉挛期要<strong>维持较高血压</strong>保证灌注。同样是「脑卒中」，血压策略却随病因与阶段大相径庭——这再次说明「机制决定治疗」在神经重症里的分量。</span>

## 7 公式解析：脑灌注压与脑血流

神经重症的所有干预最终都收束到脑灌注：

$$
CPP = MAP - ICP
$$

- **第一步，看结构**：有效驱动脑血流的压力 = 平均动脉压 − 颅内压。ICP 是「上游的背压」，MAP 是「下游的驱动」，两者之差才是脑组织的净灌注压。
- **第二步，算目标区间**：成人 TBI 目标 CPP 60–70 mmHg。CPP < 60 → 脑缺血（自动调节已受损时尤其危险）；CPP 过高（> 70）可能加重水肿。
- **第三步，看两条干预线**：维持 CPP 有两条路——抬 MAP（血管活性药、扩容）与压 ICP（高渗、引流、镇静）。神经重症的「滴定艺术」就是在这两条线上同时拧，找到稳定区间。
- **第四步，脑血流的欧姆式表达**：$CBF = CPP / CVR$——脑血流 = 脑灌注压 ÷ 脑血管阻力。它把「维持 CPP」翻译成「维持 CBF」：CPP 是驱动，CVR 是闸门。CO₂ 是最大的 CVR 调节旋钮（过度通气使脑血管收缩降 CVR 代偿 ICP，但过度则脑缺血），所以 PaCO₂ 目标是 35–40 mmHg 而不是「越低越好」。这条公式把神经重症的「滴定艺术」压缩成一个可计算的物理系统。

## 8 小结

- **Monroe–Kellie 学说**：颅腔容积固定，内容物增多先挤脑脊液与静脉血，缓冲耗尽后 ICP 陡升——这是理解脑疝的物理基础。
- 脑损伤分原发性（不可逆）与继发性（可防的战场）；**神经重症的一切努力都是防止继发性损伤**。
- 脑血流自动调节受损后，脑血流随 MAP 被动波动——**维持 MAP 稳定是神经重症的底线**。
- ICP 监测金标准是**脑室内导管（EVD）**（测压 + 引流一箭双雕）；重度 TBI（GCS ≤ 8 + 影像异常）是经典指征。
- 降颅压阶梯从零成本（床头抬高）到终极手段（去骨瓣减压），每一级都要同步处理病因——「治标为治本服务」。
- 神经重症的核心公式 **CPP = MAP − ICP**：目标 CPP 60–70 mmHg，CBF = CPP/CVR 给出维持灌注的两条干预线。
- 卒中的血压策略「南辕北辙」：缺血性溶栓后控 180/105、脑出血积极降压、SAH 血管痉挛期维持较高血压——机制决定治疗。

神经重症是「一切为了脑」的极限管理：颅骨里那一点点可压缩空间，决定了脑组织能否存活；CPP = MAP − ICP 与 CBF = CPP/CVR 两条公式，就是这场管理的全部几何。把它与《肝衰竭》里的脑灌注公式对照着看，你会发现同一套物理在不同原发病里反复登场。

神经重症的每一步都踩在「时间」与「细节」上：瞳孔不对称、Cushing 三联征、清醒间期——这些床边 10 秒就能捕捉的信号，往往是脑疝前最后的报警。把它与「降颅压阶梯」一起背熟，就握住了「大脑保卫战」的全部弹药。

在下一节，我们将从大脑转向「血管内的大脑」——**凝血功能障碍与弥漫性血管内凝血**，看凝血系统的双向深渊：既到处堵、又到处漏的总崩溃。

从「颅内的压力」到「血管内的凝血」，器官系统的保卫战在继续——每一个系统失守，都有它的专属对策与极限，而支持它们的，永远是那几条守恒与灌注的基本公式。

神经重症的尽头常常通往伦理学的问题——当脑已经不可逆地损伤，技术的边界就该让位给价值的判断（见本专题《伦理与终末期决策》一篇）。
