# 内分泌危象：血糖、肾上腺与甲状腺

## 为什么内分泌危象是「隐形杀手」

内分泌危象在 ICU 里有个共性：它们**像脓毒症、像休克、像脑病，却都不是**。一个肾上腺危象的患者可以表现为低血压、恶心、低钠——跟感染性休克几乎一模一样；一个甲亢危象可以表现为高热、心动过速、谵妄——跟脓毒症、恶性高热难以区分。正因如此，内分泌危象常被**漏诊**，而它们的治疗往往简单直接（补激素、补糖、降温），一旦确诊常常立竿见影。这一节聚焦三个最要命的轴：**血糖（DKA/HHS 与低血糖）、肾上腺（肾上腺危象）、甲状腺（甲亢危象与黏液性水肿昏迷）**，并提炼「何时要想到内分泌危象」的判断直觉。

## 1 高血糖危象：DKA 与 HHS

**糖尿病酮症酸中毒（diabetic ketoacidosis，DKA）**：胰岛素极度缺乏 → 血糖升高 + 脂肪分解 → 酮体生成 → 高阴离子隙代谢性酸中毒。

**高渗性高血糖状态（hyperosmolar hyperglycemic state，HHS）**：胰岛素相对不足 → 严重高血糖（常 > 33 mmol/L）+ 重度脱水 + 高渗 → 意识障碍，但通常**无显著酮症与酸中毒**。

两者是一个谱系的两端：DKA 常见于 1 型糖尿病（年轻），HHS 常见于 2 型老年患者（感染/应激诱发）。临床对比：

| 维度 | DKA | HHS |
| --- | --- | --- |
| 血糖 | 常 > 13.9 mmol/L | 常 > 33 mmol/L |
| 酮体/酸中毒 | 显著 | 轻微/无 |
| 脱水与渗透压 | 中等 | 严重（高渗） |
| 意识障碍 | 取决于酸中毒程度 | 常明显 |
| 诱因 | 胰岛素中断、感染、新发 | 感染、应激、脱水 |

**治疗三件套**：**补液（生理盐水，先快后慢）、胰岛素（小剂量静脉泵，纠酮优先）、补钾**。治疗节奏的几个要点：

- **先补液后胰岛素**：先恢复灌注再降糖——胰岛素前必须确认血钾足够（胰岛素把钾驱入细胞，血钾低时先补钾防致命低钾）。
- **血糖下降勿过快**：DKA 血糖降到 13.9 mmol/L 左右时改用含糖液，防脑水肿（尤其儿童）。
- **纠酸的节奏**：DKA 一般不需要补碱，酮体代谢后酸中毒自解；pH < 6.9 时才谨慎考虑。<span class="marginnote">DKA 治疗「先钾后糖」的顺序常被记错：胰岛素一进，血钾立刻内移，若原本就低钾（呕吐、利尿），可能在几分钟内诱发生命危险的心律失常。所以「看钾再上胰岛素」是 DKA 的第一纪律——又是「先算清账再动作」。</span>

**计算渗透压**（HHS 的核心指标）：

$$
\text{有效渗透压} = 2 \times Na^+ + \frac{Glucose\,(mmol/L)}{1}
$$

HHS 的渗透压常 > 320 mOsm/kg，渗透压高 → 脑细胞脱水 → 意识障碍。治疗上 HHS 比 DKA 更强调**大量缓慢补液**，血糖下降同样要控制速度。

## 2 低血糖：比高血糖更急的杀手

**低血糖（hypoglycemia）**：血糖 < 3.9 mmol/L（< 70 mg/dL），伴或不伴交感症状（心慌、出汗、震颤）与神经缺糖症状（意识模糊、抽搐、昏迷）。

为什么低血糖在 ICU 格外凶险？因为**大脑几乎只能靠葡萄糖供能**，缺糖几分钟即不可逆损伤。危重患者低血糖的常见原因：胰岛素/磺脲类过量、脓毒症肝糖原耗竭、肝衰竭、肾衰（胰岛素清除下降）、肾上腺功能不全、营养中断。

**处理原则：「先给糖再找原因」**。意识清醒者口服糖；昏迷/不能吞咽者静脉推注 50% 葡萄糖，随后持续输注防复发，并复查血糖。对口服降糖药（磺脲类）导致的低血糖，需延长观察——它可持续低血糖 24 小时以上。<span class="marginnote">低血糖是《初始评估》里「先测血糖」那个本能的由来：任何意识改变的患者，10 秒钟排除低血糖——因为它是极少数「一次纠正即完全可逆」的神经急症。而「先给糖再找原因」的铁律，则是「诊断未明时先处理可逆致命因素」的极致。</span>

**ICU 的血糖控制**：血糖高（应激性高血糖）要控，但过严（< 4.4 mmol/L）会显著增加低血糖风险，近年研究（NICE-SUGAR 试验）提示目标血糖 **140–180 mg/dL（7.8–10 mmol/L）** 比激进控糖（80–110）更安全。又是一次「适度优于极端」的循证修正。

## 3 肾上腺危象：低血压的隐藏原因

**肾上腺危象（adrenal crisis）**：肾上腺皮质功能不全急性失代偿，皮质醇（与醛固酮）严重缺乏 → 低血压休克、低钠、高钾、低血糖、恶心呕吐。

**机制**：皮质醇缺乏 → 血管对儿茶酚胺反应性下降（血压撑不住）+ 糖异生下降（低血糖）；醛固酮缺乏 → 保钠排钾能力丧失 → 低钠高钾。诱因：长期激素治疗者**突然停药**、感染/手术等应激、双侧肾上腺出血/梗死、脓毒症相对肾上腺功能不全。

**如何想到**：对「血管活性药依赖却找不到原因的休克」「难以解释的低钠 + 高钾 + 低血糖」「正在用激素或刚停激素的患者出现低血压」——都要怀疑肾上腺危象。<span class="marginnote">肾上腺危象是最典型的「想到才诊断得出来」的疾病：它的检验（血皮质醇、ACTH 兴奋试验）要等结果，但治疗（静脉氢化可的松）应该<strong>在结果出来前就启动</strong>——对可疑者先给激素，若诊断被排除再停，代价远低于漏诊的代价。这是「诊断性治疗」在 ICU 的经典应用。</span>

**治疗**：静脉**氢化可的松**（紧急替代）+ 补液（生理盐水纠正低容量与低钠）+ 处理低血糖与高钾。注意：氢化可的松有盐皮质激素作用，可同时补醛固酮的缺失。

## 4 甲亢危象与黏液性水肿昏迷

**甲亢危象（thyroid storm）**：甲亢急性失代偿 → 高热、心动过速（常 > 140）、房颤、震颤、烦躁甚至昏迷，可伴心力衰竭。诱因：感染、手术、停用抗甲状腺药、碘造影剂等。

治疗是「控制甲状腺的四面出击」：

**抑制新激素合成**：丙硫氧嘧啶（PTU）或甲巯咪唑。
**阻断已合成激素释放**：碘剂（在 PTU 之后 1 小时给，否则碘会被用于合成新激素）。
- **阻断外周效应**：β 阻滞剂（普萘洛尔）控制心率与交感症状。
- **支持与降温**：补液、对乙酰氨基酚（**避免阿司匹林**，它把 T₄ 从结合蛋白上置换下来加重病情）、必要时 ICU 镇静。
- **寻找诱因**：抗感染、处理应激。

<span class="marginnote">甲亢危象药物顺序的细节很苛刻：<strong>先 PTU 后碘</strong>——PTU 先阻断新激素合成，1 小时后碘才阻断释放；顺序反了，碘反而成为合成新激素的原料。这种「顺序即疗效」的细节，是内分泌急症区别于一般重症的独特之处。</span>

**黏液性水肿昏迷（myxedema coma）**：严重甲减的终末状态 → 低体温、低通气、低钠、心动过缓、昏迷，是「代谢全面减速」。治疗：静脉甲状腺素（左甲状腺素，常需加用 T₃）+ 支持（复温、通气、激素——甲减可合并肾上腺功能不全，先补激素防「甲状腺素诱发肾上腺危象」）。

## 5 公式解析：纠正高渗与补液

高血糖危象的液体与钠管理，常需要「**校正钠**」这个计算：

$$
Na^+_{corrected} = Na^+_{measured} + 2 \times \frac{Glucose - 5.6}{5.6}
$$

- **第一步，看为什么校正**：血糖是渗透活性物质，每升高 5.6 mmol/L（100 mg/dL），水被从细胞内拉出、稀释血钠约 2 mmol/L。所以 HHS/DKA 的实测钠是「假性偏低」——不校正就会把「正常钠」误判为「低钠」而错误补钠。
- **第二步，代入例算**：血糖 33.6 mmol/L（6 倍于 5.6）、实测钠 128 → 校正钠 = 128 + 2×5 = 138——实际上并不低钠。
- **第三步，看临床动作**：HHS 的核心是补液（稀释血糖、恢复灌注），而不是补钠。血糖降下来后「假性低钠」自然缓解，补液速度远比补钠重要——这是「先补对方向」的又一次验证。

## 6 临床整合：何时要「想到内分泌危象」

内分泌危象最大的敌人是「没想到」。给三条临床触发器：

1. **休克找不到解释**：低血压 + 升压药依赖 + 恶心呕吐 + 低钠高钾 → 先想到**肾上腺危象**，在化验出来前就静脉给氢化可的松——「诊断性治疗」的代价远低于漏诊。
2. **高热 + 心动过速 + 意识紊乱**：像脓毒症但血培养阴性、退热药无效 → 想到**甲亢危象**（尤其有甲亢史、近期停用抗甲状腺药、碘造影暴露者），按「PTU → 碘 → β 阻滞 → 降温」四路并进。
3. **意识改变 + 无法解释的代谢紊乱**：任何意识改变先测血糖（排除低血糖）；血糖高 + 高渗 + 脱水 → 判断 DKA/HHS，按「先液后糖、先钾后胰岛素」的纪律处理。

辨析｜易错点：**内分泌危象的处理「重开头、不重化验」**——氢化可的松、葡萄糖、胰岛素、降温都是「想到就可以立刻做」的动作，而化验（皮质醇、ACTH、甲状腺功能）是「确认」而非「启动」。在重症里，「先救可能的病」优于「等确诊了再救」。<span class="marginnote">把内分泌危象放进本专题的更大图景，它们都服从同一个决策结构：<strong>「表现相似、机制不同、治疗相反」</strong>——脓毒症与肾上腺危象都休克，但一个抗菌、一个补激素；脓毒症与甲亢危象都发热，但一个抗菌、一个抗甲状腺。重症鉴别诊断的成熟，就是学会「用机制而非表象」。</span>

## 7 小结

- **DKA 与 HHS**是同谱系两端：DKA 酮症酸中毒（1 型多见），HHS 高渗脱水（2 型老年多见）；治疗三件套是**补液、胰岛素、补钾**，顺序「先钾后糖」不可颠倒。
- **低血糖比高血糖更急**：「先给糖再找原因」；ICU 血糖目标 140–180 mg/dL，过严控糖（NICE-SUGAR）弊大于利。
- **肾上腺危象**：皮质醇 + 醛固酮缺乏 → 低血压、低钠高钾、低血糖；治疗是**氢化可的松 + 生理盐水**，可疑即启动、不等化验。
- **甲亢危象**：高热 + 心动过速 + 谵妄；药物顺序「先 PTU 后碘」是关键；黏液性水肿昏迷则要左甲状腺素 + 支持，且先补激素防「甲状腺素诱发肾上腺危象」。
- 内分泌危象的识别靠「触发器」：无法解释的休克想肾上腺危象、高热伴心动过速想甲亢危象、意识改变先测血糖——「想到才诊断得出来」。

内分泌危象教会我们一件 ICU 里最值钱的本领：**当表象可疑时，先按「最危险且可治疗」的假设行动**。激素、糖、甲状腺素的「诊断性治疗」，常常比等化验更救命——这是「先救可能的病」原则在代谢领域的最清晰体现。

三条触发器值得反复默念：**无法解释的休克想肾上腺、高热伴心动过速想甲亢、意识改变先测血糖**——它们把「想到才诊断得出来」的疾病，变成「想起就立刻行动」的本能。

在下一节，我们将从「激素」转向「微生物」——**重症感染与抗菌药物合理应用**，把抗菌药从一次给药展开成一套策略系统：广谱、精准、降阶梯。
