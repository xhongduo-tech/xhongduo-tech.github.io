## 为什么从 MDS 讲起

前几篇我们讨论了「原料不足」（缺铁）与「破坏过多」（溶血）——这两类贫血里，骨髓本身是好的，是上游或下游出了问题。**骨髓增生异常综合征（myelodysplastic syndromes, MDS）**则第一次把矛头指向骨髓自己：血细胞生成这条路还在走，但走歪了——细胞造得出来，却「又少又坏」，这就是**无效造血（ineffective hematopoiesis）**。<span class="marginnote">MDS 翻译成大白话是「骨髓造血的发育不良」。它的名字里同时写着两个警示：髓系（myelo）增生异常（dysplastic）——细胞形态畸形，最终可能滑向急性髓系白血病（AML），这就是「白血病前期」这一旧称的来源。</span>

理解 MDS 需要抓住三个关键词：**克隆性**（是干细胞的一支突变了）、**无效造血**（增殖但早夭）、**风险梯度**（向 AML 转化的概率高低可分层）。这一篇我们就按这三个关键词展开。

## 1 MDS 的三大特征

**MDS**：一组起源于造血干细胞的克隆性髓系疾病，以血细胞减少（一系或多系）、骨髓病态造血（dysplasia）、以及向急性髓系白血病转化的高风险为特征。

它有三个互相咬合的特征：

1. **克隆性**：一个 HSC 获得体细胞突变后，通过自我更新优势逐渐「胜出」，形成单一克隆。衰老、化疗、射线暴露是驱动因素，因此 MDS 多见于老年人（中位年龄 70 岁左右），且可有「治疗相关」亚型。
2. **无效造血**：克隆内细胞增殖分裂并不慢，但在骨髓内**大量凋亡**（成熟前死亡），成熟血细胞「出不了货」，于是外周血全面减少（贫血最常见，也可见白细胞、血小板减少），而骨髓却是增生的——**「外围的少」与「里面的多」构成 MDS 最核心的矛盾**。<span class="marginnote">骨髓活检里，MDS 常表现为「hypercellular bone marrow」（骨髓增生极度活跃）却伴外周血细胞减少。这种「里面热闹、外面冷清」的反差，是无效造血最直观的解剖证据。</span>
3. **高风险转化**：克隆内的突变不断积累，终有一天突破到「原始细胞爆量」的状态，转化为 AML。MDS 因此被看作**AML 的前体状态**。

## 2 病态造血：显微镜下的「残次品」

**病态造血（dysplasia）**是 MDS 在显微镜下的签名——造血细胞的形态学畸形，要求一个髓系谱系中畸形细胞 ≥ 10%：

**红系**：环形铁粒幼细胞、核碎裂、巨幼样变。
- **粒系**：核分叶过多或过少（假性 Peiger-Huet）、胞质颗粒异常。
- **巨核系**：小巨核细胞、单圆核巨核、分叶异常。

这些形态不是理论教条——**它们是「克隆 + 无效造血」在光学显微镜下的投影**：同一个畸形克隆在重复生产畸形细胞，而畸形细胞大多活不到成熟。<span class="marginnote">血涂片与骨髓涂片是 MDS 诊断不可替代的一环，尽管分子检测越来越精确，形态学仍是一切 MDS 分类的底座——病理医生在显微镜下用眼睛「数」出来的东西，现代测序仍无法完全替代。</span>

## 3 分类：风险越分越细

MDS 的分类经历了几代演化，最新 WHO 与 ICC 标准都强调**遗传学 + 形态学**联合分层。几个骨干类型：

| 亚型 | 核心特征 |
| --- | --- |
| MDS-SLD / MDS-MLD | 一系 / 多系病态造血，原始细胞 < 5% |
| MDS-5q | 孤立 del(5q)，特点是对来那度胺反应好 |
| MDS-EB-1 / EB-2 | 骨髓原始细胞 5–9% / 10–19%，转化风险陡增 |
| MDS 伴 SF3B1 突变 | 常伴环形铁粒幼细胞，预后相对较好 |

**辨析｜易错点：** MDS 与 AML 的边界在传统标准里划在**骨髓原始细胞 20%**——≥ 20% 是 AML，< 20% 是 MDS。这个阈值是历史约定而非生物学断层：一个 MDS-EB-2（原始细胞 15%）和一个低原始细胞 AML（原始细胞 25%）之间的生物学差异可能比它们和邻居的差异都小。<span class="marginnote">正因为这条边界如此人为，2016 年后 WHO 引入了「MDS/AML 伴特定基因突变」的过渡类别——生物学终于开始修正教科书的分界线。</span>

## 4 预后评分：IPSS-R

MDS 最大的临床意义之一是**预后分层**——同样是 MDS，有人活 10 年，有人 6 个月。分层工具是 **修订版国际预后评分系统（IPSS-R）**，它把六个指标折算成总分：

| 指标 | 权重 |
| --- | --- |
| 细胞遗传学分组 | 0–5 分 |
| 骨髓原始细胞比例 | 0–3 分 |
| 血红蛋白 | 0–3 分 |
| 血小板计数 | 0–2 分 |
| 中性粒细胞计数 | 0–1 分 |

总分 0 分为极低危，> 6 分为极高危。**分层决定治疗策略**：低危 MDS 以改善血细胞减少、减少输血依赖为主；高危 MDS 以改变自然病程为目标（去甲基化药物、移植）。<span class="marginnote">「低危治症状、高危治病程」是 MDS 治疗的铁律：给低危患者上移植是过度治疗，给高危患者只输血是延误治疗。这种「按风险选强度」的决策框架，与第五级《肿瘤内科》的「分期决定方案」同一逻辑。</span>

## 5 治疗与预后

治疗主线分三档：

**支持治疗**：输血、EPO/G-CSF、抗感染——所有患者的基础，改善生存质量。
- **疾病修饰**：去甲基化药物（阿扎胞苷、地西他滨）逆转异常甲基化，是低危中高危的主流；**来那度胺**对 del(5q) 伴贫血患者有标志性疗效。
- **根治手段**：异基因造血干细胞移植是目前唯一可能治愈 MDS 的手段，适用于高危且体能允许的患者。<span class="marginnote">MDS 的移植时机选择是血液科最难的决策之一——「移植相关死亡率」与「疾病进展风险」两架天平反复权衡，这正是第四级《最优化》里的经典权衡问题。</span>

## 6 公式解析：IPSS-R 为什么要算分

预后评分是「把多维风险压缩成一个数」的典型范例，值得拆解它的思想：

$$S = w_1 c_1 + w_2 c_2 + w_3 c_3 + w_4 c_4 + w_5 c_5$$

- **$c_i$**：五个维度的离散得分（细胞遗传学、原始细胞、Hb、血小板、中性粒细胞），每个维度内部先按临界值分段给 0–3 或 0–5 分。
- **$w_i$**：各维度权重——细胞遗传学权重最高（0–5），因为它是**最硬**的预后信息，不随治疗波动。
- **$S$**：总分，查表落到 5 个风险层（极低、低、中、高、极高）。

**为什么不用单一指标？** 因为 MDS 的结局是多维因素共同决定的——一个 Hb 很低的患者，如果染色体正常、原始细胞 < 5%，预后仍好；反之一个染色体高危的患者，即使血常规好看，风险也高。**评分系统的本质是「用可加的权重模型，把高维预后信息压成一维排序」**——这个思想与第二级《线性代数》的投影、与第一级《概率统计》的加权平均一脉相承。

## 7 鉴别诊断：MDS 不是「一种贫血」

MDS 因「外周血减少 + 骨髓增生」的表现，常与多种疾病纠缠，鉴别是诊断的关键战役：

| 需鉴别 | 与 MDS 的区分点 |
| --- | --- |
| 巨幼细胞性贫血 | 维生素 B12/叶酸缺乏，补充后病态造血可逆 |
| 再生障碍性贫血 | 骨髓增生低下而非活跃，无克隆性遗传学异常 |
| 溶血性贫血 | 网织红细胞显著升高，骨髓代偿而非无效造血 |
| 化疗/药物反应 | 有明确暴露史，停药后多可恢复 |
| 老年克隆性造血（CHIP） | 有体细胞突变但无血细胞减少，多无需治疗 |

**辨析｜易错点：** MDS 与 CHIP 的边界尤其微妙——都是老年人中克隆性突变，但 MDS 必须有「血细胞减少 + 病态造血」，CHIP 只有突变而无形态学与血象异常。**基因突变不能单独诊断 MDS，形态学仍是金标准**。<span class="marginnote">「有突变 ≠ 有疾病」是分子医学时代的第一课：克隆是「风险因子」，症状才是「疾病」。这条思想贯穿整个血液肿瘤——MDS、MPN、MM 的 MGUS 阶段都是「克隆先于疾病」。</span>

## 8 去甲基化药物：给「沉默的基因」解锁

MDS 治疗的明星药物是**去甲基化药物（HMA）**——阿扎胞苷与地西他滨，它的机制值得单独拆开：

**MDS 的关键分子异常之一是高甲基化**：启动子区的异常 DNA 甲基化「静默」了抑癌基因与分化基因，让细胞停在不成熟状态。HMA 抑制 DNA 甲基转移酶，降低甲基化水平，「重新唤醒」被沉默的基因。<span class="marginnote">「表观遗传学修复」是血液肿瘤治疗的新维度：不改 DNA 序列，只改「开关状态」。阿扎胞苷对 MDS-EB 的生存获益，让「表观遗传修饰」从实验室概念变成了能改写临床指南的药物类别。</span>

**临床要点**：

- 对 MDS-EB（原始细胞 10–19%）、不耐受移植的老年患者，阿扎胞苷能改善生存（超越支持治疗）。
- 起效慢（常需数个疗程），以「输血减少、血象改善」为评价。
- 对高危 MDS 的作用是「改善生存、推迟转化」，**根治仍靠移植**——「HMA 是延缓器，移植是根治器」。

## 9 小结

- MDS = 克隆性 + 无效造血 + 高风险向 AML 转化；关键矛盾是「骨髓增生、外周血减少」。
- **病态造血**（畸形细胞 ≥ 10%）是形态学签名；诊断靠血涂片 + 骨髓 + 遗传学三方会诊。
- 分类强调遗传学；**del(5q)** 对来那度胺敏感，**SF3B1** 突变常伴环形铁粒幼细胞。
- MDS 与 AML 的边界传统上划在**原始细胞 20%**，但这只是历史约定。
- **IPSS-R** 把细胞遗传学等五维信息压成分数，指导「低危治症状、高危治病程」。
- 移植是唯一治愈手段；去甲基化药物是主流疾病修饰治疗。
