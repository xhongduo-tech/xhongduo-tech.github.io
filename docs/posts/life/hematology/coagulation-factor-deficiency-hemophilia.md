## 为什么从凝血因子讲起

过去八篇我们处理的是「血细胞」，而血液系统还有另一半世界——**止血**。受伤后血液如何在几秒内由流动转为凝固？答案是一场由十几种**凝血因子**精密编排的级联反应。**血友病（hemophilia）**就是这条级联里最著名的两处「断路」——VIII 因子缺乏（血友病 A）或 IX 因子缺乏（血友病 B），这是人类认识最早的遗传性凝血病之一，也是「皇家病」。<span class="marginnote">「皇家病」指的是维多利亚女王的 X 连锁缺陷传遍欧洲王室的历史——从维多利亚女王到西班牙、俄国罗曼诺夫王朝的阿列克谢皇储，血友病在贵族通婚史里留下了清晰的血缘图，是遗传学上最著名的家系故事之一。</span>

这一篇先建立**凝血级联**的完整地图，再讲血友病的遗传学、临床与治疗，最后辨析它最常被混淆的近亲——**血管性血友病（VWD）**。

## 1 凝血级联：一场被「折断」成三段的接力

凝血是一条**酶级联（cascade）**：每一个被激活的因子再去激活下一个因子，信号被逐级放大。经典模型把它分成三段（现代「细胞模型」更强调表面组装，但三段框架仍是临床语言的基础）：

**外源通路**：组织因子（TF，因子 III）在血管损伤后暴露，激活 FVII → TF-FVIIa 复合物。
- **内源通路**：接触激活启动 FXII → FXI → FIX → 与 FVIII 协同。
- **共同通路**：两条通路汇合到 FX 的激活 → 凝血酶（FIIa）生成 → 纤维蛋白原 → 纤维蛋白。<span class="marginnote">「瀑布学说」由麦克法兰（Macfarlane）与达维（Davie）在 1964 年分别独立提出。它把「一个信号放大成千万个」的生物学事件翻译成了连锁接力——这本质上是第四级《系统与控制》里的「正反馈放大级联」，而凝血又靠抗凝血酶、蛋白 C/S 构成负反馈刹车，一正一负才是稳态。</span>

临床检验正是按这两条通路的完整性设计的：**PT（凝血酶原时间）**反映外源+共同通路；**APTT（活化部分凝血活酶时间）**反映内源+共同通路。**血友病缺的是 FVIII/FIX——内源通路成员，所以 APTT 延长而 PT 正常**，这是它最重要的实验室「指纹」。

## 3 血友病：遗传学与临床

**血友病 A（缺乏 FVIII）**与**血友病 B（缺乏 FIX，Christmas 病）**均为 **X 连锁隐性遗传**——基因位于 X 染色体，男性（XY）一个拷贝即发病，女性（XX）需两个拷贝才发病、多为携带者。全球患病率约 1/5000（A 型为主，占 80–85%）。

按凝血因子活性分级：

| 分度 | 因子活性 | 出血表型 |
| --- | --- | --- |
| 重型 | < 1% | 自发性出血，关节/肌肉反复出血 |
| 中型 | 1–5% | 轻微外伤后明显出血 |
| 轻型 | 5–40% | 手术/外伤后出血，平时可正常 |

**重型血友病的标志性损伤是关节出血（hemarthrosis）**——反复关节内出血导致慢性滑膜炎、关节毁损（血友病性关节病），这是最致残的并发症。<span class="marginnote">约 1/3 的血友病 A 由新发突变所致，家族史可阴性。约 2/3 的新生男婴患儿在出生时即被发现（包皮环切、脐部出血）。</span>

## 4 治疗：从「血淋淋的替代」到「长效因子与基因疗法」

血友病的治疗核心是**替代治疗**——把缺的因子补回去：

**按需治疗**：出血发作时输注 FVIII/FIX 浓缩物。
- **预防治疗（prophylaxis）**：定期输注维持因子谷浓度，是现代标准——把关节出血消灭在发生之前。<span class="marginnote">预防治疗把血友病患儿从「反复出血-关节残毁」的轨道上解救出来——这是血友病管理从「救火」到「防火」的范式转变，与《预防医学》的「一级预防」思想一脉相承。</span>
**旁路制剂**：对产生 FVIII 抑制物的患者，用重组 FVIIa 或活化凝血酶原复合物（aPCC）绕过被中和的 FVIII。
- **非因子药物**：艾美赛珠单抗（双特异性抗体，模拟 FVIII 的桥接功能）——不补因子，直接「克隆」FVIII 的功能，是近年最轰动的突破。<span class="marginnote">艾美赛珠单抗把 FXa 和 FIXa「像 FVIII 那样」桥接到磷脂膜上，等于给没有 FVIII 的患者装了一个「功能仿生件」。一个抗体的两条臂分别抱住两个因子——这种「双特异性」设计是抗体工程史的一座里程碑。</span>
**基因治疗**：AAV 载体递送 FVIII/FIX 基因，让患者自己长期产生因子。首个 FIX 基因疗法已获批，一针或可摆脱终身输注。

**辨析｜易错点：** 血友病治疗里最危险的敌人是**抑制物**——患者对输注的因子产生中和抗体，使替代治疗失效。抑制物患者出血时只能用旁路制剂，「因子无效」时一定要想到它，而不是盲目加量。

## 5 血管性血友病：最常被误诊的出血病

**血管性血友病（von Willebrand disease, VWD）**是最常见的遗传性出血病（患病率约 1%），却是最常被忽视的：它是 **vWF（血管性血友病因子）**量的或质的异常——vWF 既帮助血小板黏附，又是 FVIII 的「运载和保护蛋白」。<span class="marginnote">vWF 的多聚体越大越能有效桥接血小板，而超大多聚体需要 ADAMTS13 酶切割——这条「vWF-ADAMTS13」的平衡在下一篇《血小板疾病》的 TTP 里将再次登场，两条主线在这里首次交汇。</span>

VWD 与血友病的鉴别要点：

| 维度 | 血友病 A/B | VWD |
| --- | --- | --- |
| 遗传 | X 连锁隐性（男发病） | 常染色体显性（男女均可） |
| 缺什么 | FVIII / FIX | vWF（常伴 FVIII↓） |
| 出血表型 | 关节、深部肌肉出血 | 皮肤黏膜出血（鼻衄、瘀斑、月经过多） |
| APTT | 延长 | 可延长（FVIII 降低时） |
| 检查 | FVIII/FIX 活性 | vWF:Ag、vWF 活性、瑞斯托霉素辅因子 |

**一句话鉴别：** 血友病「往深处流」（关节、肌肉），VWD「往表面渗」（黏膜、皮肤）。

## 6 公式解析：从因子活性百分比到临床表现

血友病分级用的「因子活性 %」是一个相对单位——患者血浆让正常血浆凝血的能力。

$$\text{因子活性}\% = \frac{\text{患者血浆纠正 APTT 的能力}}{\text{正常血浆纠正 APTT 的能力}} \times 100\%$$

- **第一步**：用 APTT 作为「计时器」——把不同比例的患者血浆与正常血浆混合，看 APTT 被纠正多少。
- **第二步**：测得患者血浆的 FVIII 活性后，与正常血浆（定义为 100%）比较。
- **第三步**：按活性落档——<1%（重型）、1–5%（中型）、5–40%（轻型）。

**直觉：** 这个百分比的生物学意义是「患者还剩下多少堵漏能力」。**重度与中度的差异不是 1% 与 5% 的算术差，而是「自发出血」与「外伤才出血」的质变**——<1% 意味着体内几乎没有可用因子，止血系统对日常磨损的防御全线失守。<span class="marginnote">这条「阈值决定表型」的思想在全医学通用：只要产能低于某个非线性阈值，表现就从「亚临床」跳变到「临床」——和第一篇造血篇里「贫血 = 产量-寿命等式」的临界思维完全一致。</span>

## 7 血友病的关节管理与多学科协作

血友病的治疗早已超越「出血了再输因子」，进入了**以关节为中心、多学科协作**的时代：

**预防治疗 + 规律运动**：维持因子谷浓度 + 适度运动（游泳、骑车）增强肌肉与关节稳定性，是防止关节毁损的「一防」。<span class="marginnote">过去人们误以为血友病患者应「卧床养病」，现代观点恰恰相反——<strong>规律运动保护关节</strong>，因为强壮肌肉是关节的天然护具。从「限制活动」到「主动康复」，是血友病管理的又一次观念革命。</span>
**关节出血的早期处理**：冰敷、制动、关节腔穿刺（大量积血时）+ 足量替代因子——「早处理、足替代」能显著降低慢性滑膜炎与关节病的发生率。
- **牙科与手术管理**：任何侵入操作前必须预防性补充因子，口腔卫生维护是减少牙龈出血与拔牙风险的基础。
- **综合关怀团队**：血液科、骨科、物理治疗师、心理、口腔与遗传咨询协同——血友病是「需要一整支队伍」的慢性病，也是慢性病管理「team-based care」的模板。

## 8 获得性血友病：一个「老人突然出血」的警报

血友病未必都是遗传的——**获得性血友病（AHA）**是抗 FVIII 自身抗体（抑制物）在成年期新发所致，机制完全不同但同样凶险：

- **人群**：多见于**老年人与产后女性**、自身免疫病、肿瘤、妊娠相关；也见于「特发」。
- **临床**：既往无出血史的成年人突然出现广泛皮下血肿、深部出血，APTT 延长且**不被正常血浆纠正**（混合试验不纠正 = 存在抑制物，区别于遗传性因子缺乏）。<span class="marginnote">「APTT 延长能否被正常血浆纠正」是鉴别「缺因子」与「有抑制物」的分水岭：缺因子时正常血浆补上了就好了；有抑制物时抗体把补进去的也中和了。一个简单的混合试验，区分两种天差地别的处理。</span>
- **治疗**：止血用旁路制剂（重组 FVIIa、aPCC）；根除抑制物用免疫抑制（激素 + 环磷酰胺/利妥昔单抗）——「先把抗体消掉，再谈止血」。

**AHA 的核心教学点**：**任何既往健康的成人突然出血 + APTT 延长 + 混合试验不纠正，都要想到它**——它与遗传性血友病的鉴别，是从「补充缺的」转向「消除多的」的治疗哲学切换。

## 9 小结

- 止血 = 血管收缩 + 血小板 + **凝血级联**；级联分**内源/外源/共同**三段，汇合于 FX、终结于纤维蛋白。
- **血友病 A/B** = FVIII/FIX 缺乏，X 连锁隐性遗传，**APTT 延长、PT 正常**是实验室指纹。
- 按因子活性分**重/中/轻型**；重型 <1% 有自发性关节出血。
- 治疗核心是**替代 + 预防**；抑制物、艾美赛珠单抗（双特异性）、基因疗法是三大前沿。
- **VWD** 是最常见遗传性出血病，vWF 异常，表型是黏膜皮肤出血；与血友病「深层出血」不同。
- 因子活性 % 是「还剩多少堵漏能力」的量化，阈值（1%）决定表性质变。
