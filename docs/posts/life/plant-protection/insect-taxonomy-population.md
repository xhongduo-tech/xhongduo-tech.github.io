## 为什么从昆虫分类与种群动态开始

上一篇看清了单个昆虫的构造，这一篇要回答农业决策真正关心的两个问题：**它是哪一种害虫？它会不会爆发？** 分类学给出第一个答案——不同的「户口」预示不同的为害方式与防治思路；种群生态学给出第二个答案——把马尔萨斯的预言翻译成数学，就是昆虫种群可以按指数爆炸式增长，而环境与天敌会踩下刹车。两者一结合，就诞生了农业昆虫学最核心的计算：**何时出手最划算**。

这也是数学与经济学在农业上的一次正面对话。指数函数、逻辑斯蒂方程、级数求和，我们在一二三级打下的数学功底，将在这里变成实实在在的田间决策。

## 1 昆虫分类：六足的族谱

生物分类的阶梯是**界、门、纲、目、科、属、种**，由林奈确立的双名法（属名 + 种名，斜体）给每个物种一个国际通用的「姓名」。昆虫纲内部以**翅、口器、变态类型**为主要判据分目，农业上最常碰到的八个目：

| 目 | 代表 | 口器 / 为害 |
| --- | --- | --- |
| 鞘翅目（Coleoptera） | 甲虫、天牛、象鼻虫 | 咀嚼式，食叶、蛀茎、蛀木 |
| 鳞翅目（Lepidoptera） | 蛾、蝶 | 幼虫咀嚼式食叶/钻蛀 |
| 双翅目（Diptera） | 蝇、蚊、潜叶蝇 | 舐吸 / 幼虫钻蛀 |
| 膜翅目（Hymenoptera） | 蜂、蚁 | 许多是寄生蜂（天敌） |
| 半翅目（Hemiptera） | 蚜虫、飞虱、叶蝉、蝽 | 刺吸式，吸汁、传毒 |
| 直翅目（Orthoptera） | 蝗虫、蟋蟀 | 咀嚼式，暴食 |
| 缨翅目（Thysanoptera） | 蓟马 | 锉吸式 |
| 双尾/缨尾等原始类群 | 衣鱼等 | 咀嚼式 |

<span class="marginnote">鉴定口诀举例：蚜虫腹末有一对「腹管」、尾部有尾片；蓟马体细长、翅边缘缀长毛；飞虱后足胫节有可动的端距。识别到目乃至科，才能预判它取食什么、传播什么病、该请哪种天敌。</span>

**核心要点：** 分类不是「起名字」的学问，而是**预测系统**——知道它是鳞翅目幼虫，就知道用咀嚼式害虫的防治法、警惕叶面取食与钻蛀；知道它是半翅目刺吸式，就要同时防范它传毒。<span class="marginnote">膜翅目是植保的「友军集中营」：寄生蜂把卵产进害虫体内，幼虫以害虫为食。赤眼蜂、茧蜂是重要的生物防治资源，我们到《植物检疫与生物防治》篇再展开。</span>

## 2 种群与生命表：给种群记账

**种群（population）**：同一时间占据同一空间、能相互交配的同种个体的集合。农业昆虫学的核心单位不是「一只虫」，而是「一个种群」。

**生命表（life table）**是把一个种群从出生到死亡的「账本」逐龄期记下来：对每个龄期 $x$，记录存活率 $l_x$（活到该龄期的比例）与平均生殖力 $m_x$（该龄期平均产雌数）。从这张表可以算出关键的世代参数：

- **净增殖率 $R_0 = \sum l_x m_x$**：一个世代后每个雌虫平均产下的雌性后代数。$R_0 > 1$ 种群增长，$R_0 < 1$ 种群衰退。
- **世代时间 $T$**：从出生到再生的平均时间。
- **内在增长率 $r_m$**：稳定年龄结构下种群每头每单位的净增长率，与 $R_0$、$T$ 的关系近似 $r_m \approx \ln R_0 / T$。

生命表把「害虫多不多」变成「增速几何」——后者才是预测爆发的钥匙。

**生命表的数据从哪来**：室内人工饲养 + 田间罩笼观察，逐龄记录死亡与产卵，再汇总成表。饲养条件与田间差异越大，$R_0$ 与 $r_m$ 越失真——所以可靠的生命表数据，宁可来自田间罩笼，也不全信温室。

## 3 种群增长模型：指数、饱和与爆发

把生命表的参数放进增长方程，就得到种群动态的主干模型。最简单的假设是每头都有不变的增殖能力：

**离散世代模型（世代不重叠）**：

$$N_{t+1} = \lambda\, N_t, \qquad N_t = N_0\, \lambda^{t}$$

**连续世代模型（世代重叠）**：

$$\frac{\mathrm{d}N}{\mathrm{d}t} = r\, N, \qquad N(t) = N_0\, e^{rt}$$

- **$\lambda$**：世代间每头的倍率；**$r$**：连续时间下的瞬时增长率，$\lambda = e^{r}$，即 $r = \ln \lambda$。
- 现实中 $N$ 不会无限增长：食物、空间、天敌构成**环境容纳量 $K$**，于是加上 $(1 - N/K)$ 的刹车项，得**逻辑斯蒂模型** $\frac{dN}{dt} = rN(1 - N/K)$。<span class="marginnote">这条 S 形曲线我们在《植物病害发生与流行》里见过——流行学与昆虫学用同一个数学骨架，只换了主角。跨专题的联系正是这个网站的主题之一。</span>

**大发生（outbreak）**就是刹车失灵的时刻：气候适宜使 $r$ 飙高、天敌缺失使 $K$ 形同虚设，指数段持续拉长。东亚飞蝗的群居型转变、麦蚜的春季暴发，都服从这套「$r$ 大而刹车松」的机制。

## 4 密度制约与非密度制约：谁在踩刹车

种群调节的因子分两类，理解它们的区别才知道为什么「该出手时未必是虫最多时」：

- **非密度制约因子**：气候、温度、降雨。其作用与虫口密度无关——一场倒春寒无论虫多虫少都冻死同样比例。
- **密度制约因子**：天敌、寄生、食物、拥挤、疾病。其作用**随密度升高而增强**——虫越多，寄生蜂的寄生率越高，这是种群回归平衡的负反馈。

**辨析｜易错点：非密度制约因子不能把种群「校准」到平衡，只有密度制约因子能。** 气候只能造成波动，密度制约才提供「回中力」。所以防控上：**靠气候判断年景，靠天敌与密度判断趋势**——把生态学记错为「气候决定论」，就会在真该防治的密度爬坡期袖手旁观。

## 5 公式解析：从生命表到爆发判据

把前两节的参数串成一条可用的计算链：

$$R_0 = \sum_{x} l_x m_x, \qquad r_m \approx \frac{\ln R_0}{T}, \qquad N(t) = N_0\, e^{r_m t}$$

分步拆解：

- **第一步，生命表求 $R_0$**：把每个龄期的存活率与生殖力乘起来求和。$R_0 = 2$ 意味着一个世代雌虫翻倍，$R_0 = 0.5$ 则一个世代腰斩。
- **第二步，转成瞬时速率**：$r_m = \ln R_0 / T$。世代越短（$T$ 小）、净增殖越高（$R_0$ 大），$r_m$ 越大。蚜虫世代只要一周出头，$r_m$ 自然可观——这就是「一周不看田，满田是蚜虫」的数学根源。
- **第三步，代入指数模型**：$N(t) = N_0 e^{r_m t}$。给出任意时刻的预测密度，与防治阈值比对，就得到**防治的决策时刻**。

**实战含义**：这条链把「虫情调查 → 生命表 → 预测 → 决策」串成一条流水线。现代农业已把它做成诱虫灯计数 + 温度模型 + App 预警的自动化系统，本质仍是这三步。<span class="marginnote">举例：假设 $r_m = 0.2/\text{天}$，虫口从经济阈值的 1/10 爬到阈值约需 $\ln 10 / 0.2 \approx 11.5$ 天——这个数字就是「侦察间隔」的下限。</span>

## 6 为害损失与经济阈值（预告）

种群增长模型回答「会不会爆发」，还差最后一块拼图：**爆发到多少才值得花钱**。损失随虫口上升，防治费却是一笔固定支出；两者相交的地方，就是农业昆虫学的核心公式——**经济危害水平（EIL）**与**经济阈值（ET）**。它的完整推导与四个参数（防治成本、单位价格、单头损失、防治效果）的逐一拆解，是下一篇《害虫综合治理》的主角，这里先记住一句话：**防治不是消灭所有害虫，而是把密度压到「多花钱比多遭损更亏」的那条线以下。**

## 7 虫情调查：给种群「量体温」

模型再漂亮，也要有数字喂进去。**虫情调查（sampling）** 就是把「田里有多少虫」变成可计算数据的田间操作，方法各有适用场景：

- **扫网法**：挥动捕虫网扫过作物表层，适合善跳、善飞的害虫（蝗虫、蝽），单位以「网次」计。
- **目测法**：直接数单位面积或单位植株上的虫数，适合蚜虫、螨等静止型害虫，是最便宜的基础方法。
- **诱捕法**：黄板、诱虫灯、性诱剂诱捕器，反映**迁飞与羽化动态**，是测报的主力。
- **吸虫器（D-Vac）**：小马达抽吸田间昆虫，适合隐蔽于叶丛的微小害虫。

**空间分布决定取样方案**：害虫在田间的分布有随机、聚集、均匀三种型。蚜虫、叶螨多呈**聚集分布**（先在一块发生再扩散），取样时若只查「平均每株」，会严重低估——必须**分块随机取样**，多取几个点，再用方差判断分布型。<span class="marginnote">取样有个朴素法则：虫子越聚集，抽样误差越大，样点要越多。合理样点数可查统计用表，或用「累计平均曲线」确定——当加入新样点的平均虫数不再明显变化时，样点数就够用了。这是把统计学直接搬进田间。</span>

**核心要点：** 调查数据的质量，决定预测与决策的质量——**垃圾数据喂不出好模型**。一次规范的调查（方法统一、样点随机、记录完整），抵得上十次潦草的目测。现代农业的虫情监测站（自动计数 + 气象 + 云端预警）正是把这条「量体温」流水线自动化了。

**采样与决策的闭环**：现代虫情监测站把「量体温」做成了流水线——诱虫灯自动计数、气象站实时回传、云端按 $r_m$ 模型推算爆发日期并推送预警。但再自动的监测，也取代不了「分块取样 + 分布型判断」的基本功：机器给的是平均数，而平均数会掩盖聚集分布——这份警惕必须留给人。

## 8 小结

- **分类是预测系统**：目级特征（口器、翅、变态）决定为害方式与防治思路；膜翅目寄生蜂是生物防治富矿。
- **生命表**逐龄期记账，得净增殖率 $R_0 = \sum l_x m_x$；$R_0>1$ 种群增长。
- **增长模型**：离散 $N_{t+1}=\lambda N_t$ 与连续 $N(t)=N_0 e^{rt}$ 是指数骨架，逻辑斯蒂 $+\ (1-N/K)$ 给出饱和；$\lambda=e^r$。
- **大发生**是指数段延长而刹车失灵的产物；**密度制约因子**（天敌、寄生、食物）才提供回中力。
- $r_m \approx \frac{\ln R_0}{T}$ 把生命表换算成瞬时增长率，从而预测爆发时间、确定侦察间隔。

在下一节，我们把损失、成本与生态放进同一个天平：经济危害水平 EIL 如何计算，天敌、抗虫品种与化学农药又如何各司其职——这就是**害虫综合治理（IPM）**。
