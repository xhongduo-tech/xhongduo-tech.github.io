## 为什么从机器学习开始

前十七篇里，机器学习已经反复出场：HMM 训练、差异表达建模、AlphaFold、GENIE3 的随机森林、PWM 的朴素贝叶斯。这一篇把这些线索收拢成一条主线：**机器学习如何系统性地解决生物问题**——以及生物数据给它出的特殊难题。<span class="marginnote">你在第四级《机器学习》《深度学习》《大模型原理》学过的全部模型，在这里都有生物学舞台：SVM 分类癌症样本、CNN 识别 DNA 基序、图神经网络预测药物副作用、Transformer 预测蛋白结构。但生物数据有几个「行业特产」：样本少、特征多、标签噪声大、类别极不平衡——这一篇专治这些。</span>

## 1 生物信息中的 ML 任务地图

先给「问题类型 → 生物例子」建立对应：

| ML 类型 | 任务 | 生物例子 |
| --- | --- | --- |
| 分类 | 二分/多分类 | 肿瘤 vs 正常（表达谱）、变异是否致病 |
| 回归 | 连续预测 | 药物 IC50、基因表达水平 |
| 聚类 | 无监督分组 | 细胞类型、基因模块 |
| 降维 | 压缩表征 | PCA/t-SNE 可视化 |
| 序列建模 | 处理顺序数据 | 启动子识别、RNA 剪接预测 |
| 图学习 | 关系数据 | PPI 上的蛋白功能预测 |

**为什么 ML 在生物里这么有用**：生物信号高维（两万基因）、非线性（调控级联）、有交互（基因 × 环境）——手写规则模型力不从心，而 ML 恰好擅长从高维数据里学非线性函数。

## 2 特征工程：从原始生物数据到特征

ML 不能直接吃「序列」或「表达矩阵」，得先变成特征。生物信息的特征工程是半壁江山：

**序列特征**：把 DNA 序列转成特征——

- **k-mer 频率**：统计每个长度为 $k$ 的子串的出现次数（如 4-mer 有 $4^4=256$ 种）——把「序列」变成「256 维向量」；
- **编码**：one-hot（4 碱基 → 4 维）、整数编码、嵌入向量（DNABERT 用 BERT 学 DNA 嵌入）；
- **蛋白特征**：氨基酸组成、理化性质（疏水性、电荷）、结构域标注。

**表达特征**：直接是「基因 × 样本」矩阵，但**特征数量（两万基因）远超样本数（几十个）**——必须降维或正则化，否则过拟合是必然。

**变异特征**：突变类型、所在功能域、人群频率、保守性分数（PhyloP/GERP）——致病性预测（如 ClinVar 的 ACMG 机器学习打分）就靠这些。

<span class="marginnote">特征工程的黄金法则：<strong>特征要有生物学可解释性</strong>。k-mer、结构域、保守性都有明确意义——黑盒特征（如随机位点）即便有预测力也难以发表和落地。好的生物 ML 论文，「特征为什么这么选」占据一半篇幅。</span>

## 3 经典模型：小数据时代的利器

生物数据常常**样本量小**（几十到几百个样本），此时复杂模型过拟合、简单模型反而是王者：

- **SVM**：小样本、高维下的经典选择，核技巧处理非线性——癌症分子分型早期主力；
- **随机森林（RF）**：对特征交互与噪声稳健，给特征重要性（可解释），广泛用于变异分类；
- **梯度提升树（GBDT/XGBoost/LightGBM）**：当前「表格数据」的首选——绝大多数基因表达/临床表格类预测的冠军基线。

**经验法则**：样本 < 1000 时，先把树模型/SVM 做扎实；样本上万再考虑深度学习。**「先强基线，再谈深模型」**是生物 ML 的第一纪律——很多论文「深度模型比基线好 2%」的结论，换个强基线就消失了。

## 4 深度学习：序列与结构的主场

当数据足够多、且任务在序列/图像/图上，深度学习全面接管：

- **CNN（卷积）**：扫描 DNA 序列找基序（**DeepSEA** 预测染色质、**DeepBind** 预测蛋白结合）——卷积核学到的就是「位置权重矩阵」的自动化版本；
- **RNN/LSTM**：建模序列长程依赖，用于剪接位点、RNA 结构预测；
- **Transformer**：**DNABERT / Nucleotide Transformer** 用预训练 + 微调范式处理基因组，AlphaFold 的 Evoformer 也是 Transformer 变体；
- **图神经网络（GNN）**：在 PPI、化合物分子图上做预测——**药物分子性质预测**（图里节点是原子、边是化学键）、蛋白互作预测。

**预训练范式在生物里复刻**：像大模型「预训练 + 微调」一样，先用海量无标注基因组/蛋白组做自监督预训练（预测 mask 掉的 token），再在小标注数据上微调——这解决了生物标注数据稀缺的问题。

## 5 公式解析：交叉熵损失

大多数生物分类模型用**交叉熵**做损失函数。设真实标签为 one-hot $y$（真类为 1、其余 0），模型预测概率为 $\hat{y}$，则

$$
L = -\sum_{c=1}^{C} y_c \log \hat{y}_c
$$

四步拆解：

- **第一步，看 $y_c$**：one-hot 标签——只有真类的 $y_c = 1$，其余为 0，所以求和里**只有真类那一项活着**：$L = -\log \hat{y}_{\text{true}}$；
- **第二步，看 $-\log \hat{y}_{\text{true}}$**：模型对真类的预测概率越接近 1，$\log$ 越接近 0，损失越小——「预测对了损失低，预测错了损失大」；
- **第三步，看多分类的求和**：$C$ 个类别时遍历所有类，但 one-hot 让求和退化成一类——等价于最大化真类的对数似然（**最大似然估计**）；
- **第四步，看它与熵的联系**：交叉熵 = 熵 + KL 散度；当 $y$ 固定时，最小化交叉熵 = 最小化「预测分布与真分布」的 KL 距离——你在大模型训练里看到的公式，一字不差。

## 6 生物 ML 的三条生死线

**类别不平衡**：致病变异在数百万变异里只占一小撮，癌症样本远少于正常——**不处理不平衡，模型会学成「永远预测多数类」**。对策：欠采样/过采样（SMOTE）、类别权重、F1/PR-AUC 代替准确率评估。

**交叉验证与独立测试**：用**分层交叉验证**（保持类别比例）评估；更严格的是**外部独立数据集验证**——在别的研究中心的数据上验证泛化。只在自己数据上报告 AUC 的论文，迁移时往往崩。

**可解释性**：SHAP 值、特征重要性、注意力权重——不只是「模型为什么这么判」，更是在找**新的生物学假设**。生物 ML 的产出常常不是「分类器」，而是「模型发现的重要特征」——那才是论文的生物学价值。

<span class="marginnote">最危险的错误：<strong>数据泄漏</strong>。把测试集的信息混进训练——比如先用全部样本做特征选择/归一化，再划分训练测试，会让验证 AUC 虚高得离谱。生物数据常带样本归属（同一个病人的多个样本），<strong>必须按个体划分</strong>，否则「同源样本互相泄漏」会让评估完全失真——这是审稿人最常抓的硬伤。</span>

## 7 小结

- ML 在生物的任务谱系：**分类/回归/聚类/降维/序列建模/图学习**，各有对应生物问题。
- **特征工程**是半壁江山：k-mer、理化性质、保守性分数；特征要**可解释**。
- 小样本时代**先强基线**（SVM/RF/GBDT），大数据与序列/图任务再上深度学习（CNN/RNN/Transformer/GNN）。
- **交叉熵** $L = -\sum y_c \log \hat{y}_c$ 是分类标准损失，等价于最大化真类对数似然。
- 三条生死线：**类别不平衡、独立验证、可解释性**；数据泄漏（按个体划分）是最大硬伤。
