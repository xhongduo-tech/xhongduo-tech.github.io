## 为什么从 RNA-seq 开始

基因组是静态的蓝图，**转录组（transcriptome）** 是动态的执行：每个细胞里哪些基因在表达、表达多少，决定了这个细胞是心肌、神经元还是癌细胞。**RNA-seq** 把转录组数字化——测序的是 RNA 反转录后的 cDNA，读数就成了「每个基因说了多少话」的量化依据。<span class="marginnote">RNA-seq 与 DNA 测序的最大差别：RNA 要先反转录成 cDNA，还要<strong>丢失内含子</strong>（成熟 mRNA 已剪接）——这带来 DNA 测序没有的麻烦：读长可能<strong>跨越剪接位点</strong>，直接比对回基因组会失败。于是 RNA-seq 有专门的剪接感知比对器。</span>这一篇从实验设计到表达定量，把整条流水线走通。

## 1 从实验到数据：RNA-seq 的诞生

RNA-seq 实验的流水线：

1. **RNA 提取与质控**：从组织/细胞提取总 RNA，评估完整性（RIN 值）；
2. **mRNA 富集**：用 poly-A 尾巴富集 mRNA（去核糖体 RNA——它占总量 90% 以上却毫无信息）；
3. **片段化与反转录**：把长 mRNA 打碎成短片段，反转录成 cDNA；
4. **加接头、扩增、测序**：两端接上接头，Illumina 测序，产出 paired-end 150 bp 读长；
5. **数据量**：一个转录组样本通常 20–50M 读长（百万条读长），约 5–15 Gb。

实验设计里 **RNA-seq 是「数字」不是「模拟」**：它不像基因芯片那样输出荧光强度，而是输出**计数（count）**——比对到每个基因的读长条数。计数是离散整数，这直接决定了差异表达分析要用泊松/负二项等计数模型（下一篇的主角）。

<span class="marginnote">一个反复被踩的坑：<strong>文库制备会引入偏倚</strong>。片段化位置偏好、GC 偏倚、PCR 扩增偏倚都会扭曲「读长数」与「真实表达量」的比例。RNA-seq 的定量工具因此必须做归一化（见第四节），把偏倚从计数里剔除——否则你看到的「差异表达」可能是「测序偏倚」。</span>

## 2 比对：剪接感知的独特挑战

RNA-seq 读长比对回基因组，比 DNA 读长难得多——因为**内含子已剪接**：

- 一条读长可能横跨**外显子-外显子连接**（junction），中间隔着几千碱基的内含子；
- 线性比对（BWA）会失败，需要**剪接感知（splice-aware）**比对器。

**STAR** 与 **HISAT2** 是主流。核心策略：

- **STAR**：先找读长的**最大可映射种子（maximal mappable prefix）**，再允许「种子之间跳过一段（内含子）」拼接起来——一次比对就能处理跨剪接位点；
- **HISAT2**：用全基因组的剪接位点索引（图索引）指导比对，速度快。

比对输出 SAM/BAM 里，跨剪接读长会带 `N`（reference skip）操作（跳过内含子）。**比对后的 QC** 看几个指标：比对率（通常 >80%）、外显子内读长比例、剪接读长比例——这些判断文库质量与污染。

## 3 定量：从比对到基因计数

比对完成后，把读长分配到基因。两种策略：

**基于注释的定量（alignment + count）**：用 **HTSeq-count / featureCounts** 把与基因外显子重叠的读长数出来。规则简单（`union`/`intersection_strict`），但处理**多比对读长**（重复区）与**多基因重叠**（反义转录）时各有取舍。

**基于转录本组装**：**Salmon / kallisto** 走「伪比对（pseudoalignment）」路线——不精确比位置，只判断「这个 k-mer 属于哪些转录本」，用 EM 算法估计每个转录本的丰度。快一到两个数量级，直接输出转录本水平定量。

**剪接异构体（isoform）定量**是最难的一层：同一个基因的多个转录本共享外显子，读长无法唯一归属。工具（RSEM、Salmon）用「转录本组的似然」把读长按概率分配——你在大模型里熟悉的「期望最大化」在这里是定量引擎。

## 4 公式解析：从计数到 TPM

原始计数不能直接用于跨样本比较，因为**测序深度不同**、**转录本长度不同**。归一化的黄金标准是 **TPM（transcripts per million）**：

$$
\text{TPM}_i = \frac{r_i / l_i}{\sum_j r_j / l_j} \times 10^6
$$

其中 $r_i$ 是基因 $i$ 的读长计数，$l_i$ 是基因 $i$ 的转录本长度（kb）。

四步拆解：

- **第一步，看 $r_i / l_i$**：**按长度归一**——基因越长，被随机打断得到的读长越多；不除以长度，长基因会被系统性高估；
- **第二步，看分母 $\sum_j r_j / l_j$**：**按深度归一**——把所有基因的长度校正值加起来，作为该样本的「总表达量」；
- **第三步，看乘 $10^6$**：把比例放大成「每百万转录本」，使不同样本的 TPM 可直接比较；
- **第四步，理解 TPM 的性质**：TPM 是**相对丰度**——样本内所有 TPM 之和恒为 $10^6$，因此它反映「这个基因占全部转录本的份额」，而非绝对分子数。

**辨析**：早期指标 **RPKM / FPKM**（每千碱基每百万读长）的分子分母顺序与 TPM 不同，导致它们在**跨样本比较时不公平**（样本的总 RPKM 不同）。当代标准是 **TPM**——看到老文献用 RPKM，理解上要打折扣。<span class="marginnote">顺带一句：定量单位从「原始计数 → CPM/TPM」的演进，本质是<strong>标准化</strong>问题——与大模型里把 logits 归一化成概率分布是同一种数学直觉：先消除「长度/深度」这些无关变量，再比较「份额」。</span>

## 5 下游起点：表达矩阵

定量的最终产物是一张**表达矩阵**：行是基因，列是样本，值是表达量。这张矩阵是后文所有分析的起点：

**差异表达**（下一篇）：比较两组样本，找「显著变化的基因」；
**聚类与降维**：用 PCA/t-SNE/UMAP 看样本分组（如肿瘤 vs 正常）、找异常样本；
**共表达网络**：算基因间相关，找功能模块（第十八篇）；
**通路富集**：把差异基因映射到 GO/KEGG，找「哪些通路被扰动」。

**样本质量是矩阵的灵魂**：生物重复（biological replicates）至少 3 个、批次效应（batch effect）要用 PCA 检查、离群样本要早期发现——这些「分析前的分析」往往决定整个研究的成败。<span class="marginnote">批次效应是转录组学的头号敌人：同一天测的样本比不同天测的相似——即使它们生物学上更远。ComBat、limma 的 removeBatchEffect 等工具在正式分析前校正批次——这是「confound 控制」在数据科学里的标准实践。</span>

## 6 数字算例：TPM 的完整计算

用两个基因、一个样本把 TPM 公式算到底。设基因 A 计数 $r_A = 500$、长 $l_A = 2$ kb；基因 B 计数 $r_B = 200$、长 $l_B = 1$ kb：

- 长度校正：$r_A/l_A = 250$，$r_B/l_B = 200$；
- 分母：$250 + 200 = 450$；
- TPM：$\text{TPM}_A = \frac{250}{450}\times 10^6 \approx 5.56\times 10^5$，$\text{TPM}_B = \frac{200}{450}\times 10^6 \approx 4.44\times 10^5$。

**读这张数**：A 的计数是 B 的 2.5 倍，但 TPM 只有 1.25 倍——因为 A 更长（2 kb vs 1 kb），被随机打断产生的读长本来就多。**不做长度校正，长基因会被系统性高估**；同时注意所有 TPM 之和恒为 $10^6$，它是「份额」不是「绝对量」。

**RNA-seq 质控速查表**（比对完成后必看）：

| 指标 | 健康范围 | 低了说明 |
| --- | --- | --- |
| 比对率 | >80% | 污染、接头残留、参考不匹配 |
| 唯一比对率 | >60% | 重复区多或文库质量差 |
| 外显子内读长比例 | 高（>60%） | 内含子污染（DNA 残留） |
| 5'/3' 偏倚 | 无 | RNA 降解（RIN 低） |
| rRNA 比例 | <5% | 富集失败 |

**一条纪律**：先跑质控再谈分析。很多人直接跳到差异表达，回头发现比对率只有 60%——前 30 分钟的 QC，能省掉后面一整个月的返工。

**RNA-seq 的「一页纸总结」**：实验上富集 mRNA → 反转录 → 测序；分析上剪接感知比对 → 定量（TPM）→ 表达矩阵；下游差异表达、聚类、共表达、富集。整条流水线的每一次选择——比对器、定量工具、归一化方法——都会改变最终基因列表，**所以记录「工具 + 版本 + 参数」与记录结果同样重要**。这正是可复现性在组学分析里的最低要求。

## 7 小结

- **RNA-seq** 数字化转录组：富集 mRNA → 反转录 → 测序 → 计数；输出是**离散计数**。
- 剪接让比对变难：**STAR/HISAT2** 是剪接感知比对器，处理跨外显子连接读长。
- 定量两路线：**计数（featureCounts）** 与 **伪比对（Salmon/kallisto）**；isoform 定量靠 EM。
- **TPM** $= \frac{r_i/l_i}{\sum r_j/l_j}\times 10^6$ 同时消除长度与深度偏倚，是跨样本比较的黄金标准。
- 产物是**表达矩阵**，是差异表达、聚类、共表达、富集分析的共同起点；批次效应必须检查与校正。
