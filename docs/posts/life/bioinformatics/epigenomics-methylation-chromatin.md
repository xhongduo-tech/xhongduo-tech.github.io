## 为什么从表观组学开始

两个遗传相同的细胞——同一个人的肝细胞与神经元——读着同一份基因组，却奏出完全不同的音乐。差异来自**表观遗传（epigenetic）**：不改变 DNA 序列的化学标记与结构状态，决定了哪些基因被打开、哪些被关闭。<span class="marginnote">表观组学（epigenomics）在「全基因组规模」测量这些标记。它与前几篇的数据形态同族：又是「基因组坐标 × 信号强度」的矩阵。但信号来源各异——甲基化看化学修饰比例、ChIP-seq 看蛋白结合量、ATAC-seq 看染色质开放度、Hi-C 看三维接触频率。四种实验，四种「读数」，共同的挑战是信号解读。</span>这一篇逐一拆解四大表观组实验及其计算分析。

## 1 表观遗传的三层「开关」

表观调控主要在三个层面：

- **DNA 甲基化**：胞嘧啶 C 上加一个甲基（5mC），多出现在 **CpG 二核苷酸**上；启动子 CpG 岛高度甲基化通常**沉默**基因；
- **组蛋白修饰**：DNA 缠绕的组蛋白尾巴上可被加乙酰基/甲基等——乙酰化（H3K27ac）标志激活，三甲基化（H3K27me3）标志沉默；
- **染色质结构**：DNA 在核内折叠成高级结构，**开放染色质**可被转录机器访问，**紧密异染色质**则封存基因。

三个层面互相联动：甲基化招募去乙酰化酶 → 染色质收紧 → 基因沉默。**表观组学测量这三层在全基因组的分布**。

## 2 DNA 甲基化测序：亚硫酸氢盐的秘密

**DNA 甲基化测序**的标准方法依赖一个化学反应：**亚硫酸氢盐（bisulfite）处理**把未甲基化的 C 变成 U（测序时读作 T），甲基化的 C **保持不变**。于是——

- 全基因组亚硫酸氢盐测序（**WGBS**）直接测全基因组甲基化，精度最高但贵；
- **450K / EPIC 芯片**只探针覆盖 ~85 万个 CpG 位点，便宜、适合大队列；
- 分析的核心输出是每个 CpG 位点的**甲基化比例**。

**公式解析：β 值**

甲基化水平最常用的量化是 β 值：

$$
\beta = \frac{M}{M + U + 100}
$$

其中 $M$ 是甲基化 C 的信号（读长数/荧光强度），$U$ 是未甲基化 C 的信号，加 100 是防除零的平滑项。

四步拆解：

- **第一步，看 $M$ 与 $U$**：同一位置，一部分分子是甲基化的（M），一部分不是（U）——肿瘤/正常组织的甲基化常是**部分甲基化**，不是全有全无；
- **第二步，看比值 $M/(M+U)$**：甲基化**比例**，范围 [0,1]——1 是全甲基化，0 是全未甲基化；
- **第三步，看平滑项 +100**：低覆盖位点的比例估计极不稳定，平滑项把 β 值向 0 收缩，稳定低信号的估计；
- **第四步，看解读**：β 值 > 0.7 通常视为「甲基化」，< 0.3 视为「未甲基化」；**DMP（差异甲基化位置）/ DMR（差异甲基化区域）**分析就是在两组之间找 β 值显著不同的位点/区域。

**DMR 分析**是甲基化研究的核心输出：肿瘤里的启动子超甲基化（沉默抑癌基因）与基因体低甲基化，都要先找出 DMR，再做功能注释（落在哪个启动子？哪个 CpG 岛？）。

<span class="marginnote">易错点：<strong>β 值 ≠ 甲基化分子的百分比</strong>。β 值混入了亚硫酸氢盐转换效率、探针结合效率等系统偏倚；同一数据集内可比，跨数据集要用 M 值（logit 变换）做统计检验。芯片数据的跨平台整合至今仍是活跃方法学问题。</span>

## 3 组蛋白修饰与转录因子：ChIP-seq

**ChIP-seq**（染色质免疫沉淀 + 测序）测量「某个蛋白在基因组的哪些位置结合」。流程：

1. 甲醛**交联**：把蛋白与 DNA 冻在一起；
2. **剪切**：把染色质打成 200–600 bp 片段；
3. **免疫沉淀**：用目标蛋白的抗体把「该蛋白结合的 DNA 片段」拉下来；
4. 解交联、测序。

计算分析三步：

**比对**（同 RNA-seq，但无需剪接感知）；
**峰检测（peak calling）**：找信号显著高于背景的区域——工具 **MACS2** 用「Poisson 分布 + 局部背景」判断哪里是**结合峰**；
**注释与基序**：把峰映射到最近基因/启动子，用 **HOMER / MEME** 找峰内的**序列基序**（转录因子结合 motif）。

ChIP-seq 的信号解读要点：**峰的位置**（启动子？增强子？）与**峰的宽度**（转录因子是尖锐峰，组蛋白修饰是宽峰）各含信息。<span class="marginnote">ChIP-seq 的质控看两个数：<strong>FRiP</strong>（reads in peaks 比例，抗体效力的代理）与<strong>峰数量</strong>。没有 input/IgG 对照的 ChIP-seq 无法可靠判峰——背景噪声会被当成结合位点。好的 ChIP-seq 分析报告必须含对照。</span>

## 4 染色质可及性：ATAC-seq

**ATAC-seq**（转座酶可及染色质测序）测量**开放染色质**：用高活性的转座酶 Tn5 优先插入开放的染色质区域，把「开放区」切下来加接头测序。一次实验，几小时，几千个细胞即可——比 DNase-seq 更快更灵敏。

分析流程与 ChIP-seq 类似：比对 → 峰检测（MACS2）→ 注释。**峰 = 潜在调控元件**（启动子、增强子、绝缘子）。

ATAC-seq 的关键生物学读数：

**峰位置**：开放区在启动子/增强子的分布，指示「哪些调控元件正被使用」；
**足迹分析（footprinting）**：转录因子结合处，Tn5 无法插入，在峰的内部形成一个小凹陷——**足迹**。足迹的位置与深度直接反映「哪个转录因子此刻占着这块 DNA」，无需抗体。

**单细胞 ATAC-seq** 把这一套推到单细胞分辨率，与 scRNA-seq 联合（多组学），是当前研究热点。

## 5 三维结构：Hi-C

**Hi-C** 测量染色质在**三维空间**的接触频率：交联 → 剪切 → 连接 → 测序，把「空间上靠近的 DNA 片段」物理上连在一起再测序。输出是「片段 × 片段」的**接触矩阵**。

从接触矩阵读出的结构：

**A/B 区室**：染色质被分成「活性」A 区室与「非活性」B 区室（对应开放/封闭染色质）；
**TAD（拓扑关联结构域）**：几百 kb 的「自我交互」区块，TAD 内基因共调控——边界常由 CTCF 蛋白锚定；
**环（loop）**：增强子与启动子通过染色质环「物理接近」，实现远程激活。

**Hi-C 还帮组装**：在基因组组装（第九篇）里，Hi-C 接触信号把 contig 按「染色体内高频接触」排序挂载——这已是端到端基因组的标准工序。<span class="marginnote">Hi-C 接触矩阵是「图」的又一形态：节点是 DNA 片段、边是接触频率。TAD 边界检测用「方向性指数 + 隐马尔可夫」——你学过的 HMM 又出现了。跨尺度的复用（接触频率、共表达、PPI）是网络生物学（后两篇）的前奏。</span>

## 6 小结

- 表观遗传三层面：**DNA 甲基化、组蛋白修饰、染色质结构**，共同决定「哪段基因组被使用」。
- **亚硫酸氢盐测序**把甲基化 C 与未甲基化 C 区分开；**β 值** $= M/(M+U+100)$ 量化甲基化比例；DMR 是核心输出。
- **ChIP-seq** 用抗体拉下目标蛋白结合的 DNA，**MACS2 峰检测**找结合位点；质控看 FRiP 与对照。
- **ATAC-seq** 用 Tn5 测开放染色质，峰 = 调控元件；**足迹分析**无需抗体读出转录因子占据。
- **Hi-C** 测三维接触频率，读 A/B 区室、TAD、染色质环，还参与基因组组装挂载。
