## 为什么从全人评估开始

第 1 篇里我们认识了桑德斯的**全人痛苦（total pain）**：痛有躯体、心理、社会、灵性四个维度。前面几篇把「怎么沟通、怎么定目标」讲完了，这一篇回答「怎么把一个'人'完整地看清」——这就是**心理-社会-灵性综合评估**。<span class="marginnote">本专题的骨架里，它是「第 1 板块（学科基础、伦理与沟通）」的收官篇：前五篇给的是理念与工具，这一篇把「全人」理念变成一套可以执行的评估流程，为第 2 板块的症状控制提供「为什么这个人会痛」的背景。</span>

**一个反复出现的临床真理**：同样的骨转移痛，为什么有人咬牙挺住、有人痛不欲生？因为痛感被心理状态、社会支持、灵性困扰实时放大或缩小。**只评估躯体而不评估全人，等于只听尖叫而不问尖叫从哪来。**

## 1 全人评估的四维框架

姑息医学的全人评估，通常从四个维度入手，每一维都要追问「这个人在哪一层」：

1. **躯体维度（physical）**：症状负荷——疼痛、疲乏、恶心等；功能状态——还能走多远、自理程度。工具如 ESAS、PPS。
2. **心理维度（psychological）**：焦虑、抑郁、恐惧、失去控制感；对「改变了的自己」的接受程度。<span class="marginnote">心理痛苦有时藏在躯体后面：反复说「痛」的患者，可能是「怕」或「不甘」。评估的功课之一，是分辨「真的是痛」还是「痛在替别的情绪说话」——这一点在《谵妄、抑郁与焦虑》一篇会再展开。</span>
3. **社会维度（social）**：谁在陪、家庭经济能否撑住、照护者的负担、未了的人际事务（和解、交代）。
4. **灵性维度（spiritual）**：生命意义感、对死亡的看法、信仰资源、悔恨与未竟之事。

**重点：** 四维不是四个独立抽屉，而是互相连通的。一个经济崩盘（社会）的患者会失眠（躯体）、暴躁（心理）、怀疑人生意义（灵性）。评估的价值，正在于找出「哪一维在牵动全局」。

## 2 心理-社会评估的常用工具

把抽象的「心理社会状况」落到可操作的工具，姑息文献常用的有：

| 工具 | 评估对象 | 形式 |
| --- | --- | --- |
| 心理痛苦温度计（Distress Thermometer） | 心理痛苦程度 0–10 分 | 单题量表，肿瘤科常用 |
| PHQ-9 / GAD-7 | 抑郁 / 焦虑症状 | 自评问卷 |
| 医院焦虑抑郁量表（HADS） | 住院患者的焦虑抑郁 | 14 题自评 |
| 照护者负担量表（Zarit Burden Interview） | 家庭照护者压力 | 22 题访谈 |
| 临终前精神痛苦评估 | 灵性/存在困扰 | 临床访谈 + FICA/HOPE |

**辨析｜易错点：** 姑息患者的抑郁常被躯体症状掩盖——食欲差、乏力、失眠，究竟是疾病还是抑郁？分辨线索是「**快感缺失（anhedonia）**」：如果连「今天天气好、孩子来看我」这样的小事都无法唤起一丝愉悦，要高度警惕抑郁，而不只是把它归为「病重了自然这样」。

## 3 灵性评估：FICA 与 HOPE

灵性评估最容易被人忽略，却是临终照护里最影响「生死感受」的一环。两个被广泛使用的框架：

**FICA 框架**：Faith（信仰/信念）— Importance（重要性）— Community（社群）— Address（如何回应）。<span class="marginnote">FICA 不预设宗教：一个无神论者的「信仰」可能是对自然、对家人的信念。灵性评估问的是「支撑你活下去的东西是什么」，而非「你信什么教」。</span>

**HOPE 框架**：Hope（希望的来源）— Organized religion（有无宗教社群）— Personal spirituality（个人灵性实践）— Effects（这些信念如何影响医疗决策）。

**重点：** 灵性困扰（spiritual distress）有典型信号：追问「为什么是我」「这辈子白活了吗」「死后会怎样」，或持续的愤怒、绝望、意义感崩解。**识别灵性困扰并转介灵性照护师/宗教人士，是姑息团队的必要职责——这比硬给一句「会好的」更有用。**

## 4 核心对比表：症状导向评估 vs 全人评估

**本主题为纯概念主题，以核心对比表替代公式解析。**

| 维度 | 症状导向评估 | 全人综合评估 |
| --- | --- | --- |
| 提问 | 哪里痛？几分？ | 除了痛，你最担心什么？ |
| 目标 | 找到并对症处理 | 找到「牵动全局的那一维」 |
| 工具 | ESAS、VAS | ESAS + 温度计 + FICA/HOPE + 家庭访谈 |
| 时间 | 快，几分钟 | 慢，可能分几次 |
| 结果 | 止痛方案 | 止痛方案 + 心理支持 + 家庭干预 + 灵性陪伴 |
| 对应哲学 | 症状控制 | 全人痛苦（total pain） |

**辨析｜易错点：** 全人评估不是「把问卷做满」——它是**一次有目的的对话**。最高效的全人评估，常常是在床边的家常话里完成的：「今天谁来看你了？晚上睡得着吗？在想什么？」三个问题，四维全亮。**工具是拐杖，对话才是腿。**

还有一个务实提醒：全人评估**要分次做，别一口气问完**。重病患者的耐受度有限，一次谈话十几分钟已是极限。好的做法是「每次查房补一块拼图」——今天听他说说家里，明天问问他对未来的想法，几天下来，一个人的轮廓就完整了。把评估做成「档案」，不如把它做成「关系」。

## 5 一个全人评估的完整演示

用一个案例把四维串起来。设想一位 70 岁晚期胰腺癌男性李某：

1. **躯体**：ESAS 显示痛 7 分、疲乏 8 分、恶心 4 分，PPS 70%。止痛药在加量，但总是不理想。
2. **心理**：痛苦温度计 8 分。进一步交谈发现，他整夜睡不着，反复想「女儿还没成家」——这不是痛，是放不下。
3. **社会**：妻子全天照顾，已出现严重睡眠不足与血压升高；家里为治疗已动用积蓄，女儿在外地工作，往返奔波。
4. **灵性**：李某一度问「我这辈子对得起谁」，有强烈的未竟感；后经一次与女儿的彻夜长谈，心愿了了大半，疼痛评分随之下降。

**重点：** 注意第 4 步的变化——**心愿了了，痛就轻了**。这就是全人评估的临床价值：它常常发现，真正的「镇痛药」不是吗啡，而是「把没说完的话说完」。这个案例也预告了第 21 篇《安宁疗护实践：心理、社会与灵性支持》的具体手法。

## 6 家庭系统评估：患者不是孤岛

全人评估必须包含**家庭系统**——因为中国语境里，患者几乎从不单独生病。家庭评估要点：

1. **照护结构**：谁是主要照护者？是否有轮换？照护者自身健康状况如何？
2. **经济与资源**：医保、自费负担、是否已出现「因病致贫」。
3. **关系质量**：有无未和解的冲突、隐瞒的病（见第 4 篇）、对「治不治」的分歧。
4. **知识与技能**：家属懂不懂怎么翻身、喂药、识别紧急信号——这是《临终照护流程与病人家属照护》的伏笔。

<span class="marginnote">照护者负担是家庭评估里最常被低估的项。一个全天候照顾重病老人的中年子女，往往正在经历「预感性哀伤」——还没失去就开始悲伤。识别并支持照护者，等于间接保护患者。</span>

## 7 术语速查表

| 术语 | 含义 |
| --- | --- |
| 全人痛苦 | 躯体、心理、社会、灵性四维痛苦的总和 |
| 心理痛苦 | 心理层面的痛苦，可独立于躯体疼痛存在 |
| 灵性困扰 | 意义感、信念或对死亡的困扰所致的痛苦 |
| 预感性哀伤 | 在失去发生前的哀伤，常见于照护者 |
| FICA/HOPE | 灵性评估的两种框架 |
| 快感缺失 | 对日常愉悦失去感受力，抑郁的重要线索 |
| 照护者负担 | 照护者承担的身心与经济压力 |
| 意义感 | 灵性维度中「活着为何值得」的核心感 |

## 8 小结

- 全人评估的四维：**躯体、心理、社会、灵性**；四维连通，常有一维牵动全局。
- 工具分层：**ESAS/PPS（躯体）→ 痛苦温度计/HADS（心理）→ 家庭访谈（社会）→ FICA/HOPE（灵性）**。
- 抑郁的辨识线索：**快感缺失**——连小事都不再愉悦，要警惕抑郁而非归咎于「病重」。
- 灵性评估问的是「支撑你的是什么」，不是「你信什么教」；灵性困扰要转介，别硬安慰。
- 全人评估的本质是**对话而非问卷**；家庭系统是中国语境下不可或缺的评估对象。
- 收官提示：第 1 板块结束，从下一篇起，我们将进入「手上有武器」的症状控制板块。
- 全人评估的临床回报：**心愿了了，痛就轻了**——四维中任何一维的松动，都可能缓解整个痛苦系统。
