# 药用植物栽培学

药用植物栽培学是研究药用植物生长发育规律、栽培管理技术及其与产量品质关系的应用学科，是园艺学/植物生产与中药学的交叉领域。它以药用植物学和中药材规范化种植（GAP）为理论依托，为优质道地药材的生产提供从选地、繁殖、田间管理到采收加工的全流程技术支撑，是保障中药源头质量的核心学科。

## 对标教材

- 《药用植物栽培学》（中国中医药出版社）

- 《中药材规范化种植技术》（中国农业出版社）
