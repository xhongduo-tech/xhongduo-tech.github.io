## 为什么把根茎叶单列一篇

上一节我们在显微镜下看了细胞与组织，这一节回到肉眼层面，把药用植物最常用的三个**营养器官**——根、茎、叶——逐一讲透。它们不仅是植物生存的三大「工作站」（吸收、输导、光合），更是**入药的大头**：根及根茎类、皮类、叶类药材占了药典的大半壁江山。<span class="marginnote">入药部位不同，栽培与采收的规律就完全不同——<strong>根类药材看「地下部膨大期」，茎皮类看「剥皮适期」，叶类看「叶色与生长盛期」</strong>。看懂三大器官的形态结构，才能把「该采哪个部位、何时采」落到形态判据上（第16篇采收期篇的形态学基础）。</span>

学这一篇还有一层鉴定意义：**根茎叶的形态特征（根的类型、叶脉、叶序、托叶等）是植物分类与药材鉴定的第一手证据**。同样叫「参」，人参（五加科）是直根，麦冬（百合科）是须根——形态差异一句话就能分家。形态学是「认药」的起点。

同时要建立「变态器官」的概念：**许多入药器官是「变态」的**——山药入药的是块茎（茎的变态）而非根，半夏入药的是块茎，百合入药的是鳞茎——**「看起来像根」的不一定是根**，只有看懂来源，才不会被外观骗（第5篇分类篇的形态基础）。

<span class="marginnote">「外观相似 ≠ 来源相同」这个坑，在工程里叫「<strong>同形异源陷阱</strong>」：第3级《数据结构》里「链表与数组都能存线性序列但存取特性迥异」、第4级大模型里「同样输出流利的模型可能由完全不同的架构产生」——<strong>判断一个对象，要看出身（来源），不能只看长相</strong>。</span>

阅读本篇时，请带着「三个器官、三套功能、三类入药」的框架进场：根管吸收（入药多为根皮、根肉）、茎管输导（入药多为皮、髓、木）、叶管光合（入药多为叶表、叶肉）——器官、功能、入药三线合一。

## 1 根的形态：直根系与须根系

**根（root）**是植物吸收水分与矿质营养的器官，兼有固定与储藏功能。按根系形态分两大类：

**直根系（taproot system）**：主根发达、向下生长，侧根从主根发出——**双子叶植物**典型。入药的根类药材多属直根：人参、黄芪、甘草、当归。直根类药材的品质看「主根粗壮、侧根少、表皮光滑」——栽培上控水、深耕、去侧根都是为了养成漂亮的直根。

**须根系（fibrous root system）**：主根早期停止生长，由茎基部发出大量不定根形成须状——**单子叶植物**典型。入药如麦冬、百部、半夏（块茎）。须根类药材采收时整丛挖取，加工时去泥去须。

**根按形态还有变态之分**：

| 变态根 | 特征 | 代表药材 |
| --- | --- | --- |
| 圆锥根 | 主根肥大呈圆锥状 | 萝卜、丹参 |
| 块根 | 侧根/不定根肥大 | 何首乌、麦冬 |
| 须根 | 细长如须 | 麦冬、百部 |
| 气生根 | 生于空气中 | 石斛（附生根） |

**辨析｜易错点：块根 ≠ 块茎。** 块根是**根**的变态（何首乌、甘薯），块茎是**茎**的变态（山药、马铃薯）——两者表面都有芽痕/节的区别，来源不同、入药部位与栽培方式也不同。**认器官先辨来源**。

## 2 茎的形态：地上茎与地下茎

**茎（stem）**连接根与叶，承担输导与支撑。按生长习性分**直立茎**（大多数）、**攀援茎**（金银花藤）、**缠绕茎**（五味子）、**匍匐茎**（草莓）。茎还是很多药材的入药部位：

- **皮类药材**（牡丹皮、黄柏、肉桂）：入药的是茎皮（周皮 + 韧皮部）；
- **木类药材**（沉香、檀香）：入药的是木材（木质部）；
- **髓类药材**（通草、灯心草）：入药的是茎髓。

**地下茎的变态**是药用植物最丰富的形态类型，且**常被误认为根**：

| 地下茎类型 | 形态特征 | 代表药材 |
| --- | --- | --- |
| 根状茎（根茎） | 横卧地下、有节和芽 | 生姜、黄连、玉竹 |
| 块茎 | 短缩肥厚、表面有芽眼 | 山药、半夏、天麻 |
| 鳞茎 | 鳞片叶包裹的短缩茎 | 百合、大蒜、贝母 |
| 球茎 | 圆球状、节明显 | 荸荠、慈姑 |

**重点：地下茎与根的根本区别在于「有节有芽」**——茎不管多变态，都保留着「节、节间、芽」三件套；根没有节也没有芽。**抓住「有节有芽」这把钥匙，地下茎与根就永不混淆**。

## 3 叶的形态：叶序、叶形与叶脉

**叶（leaf）**是光合作用的器官。叶的形态特征极丰富，是分类与鉴定最常用的指标：

**叶序（phyllotaxy）**：叶在茎上的排列方式——**互生**（每节一叶，多数植物）、**对生**（每节两叶，唇形科）、**轮生**（每节三叶以上）、**簇生**（节间缩短成丛）。叶序常是科属特征：唇形科对生叶、伞形科互生叶。

**叶形与叶缘**：针形（松）、披针形（柳）、卵形、心形、掌状（人参）、羽状——叶形描述有一套规范术语，是检索表的主要依据之一。

**叶脉（venation）**：**网状脉**（双子叶）与**平行脉**（单子叶）是两大类（第5篇分类篇已用）。叶脉还分羽状脉、掌状脉等，掌状脉常伴随掌状裂叶（人参叶五出掌状复叶）。

**托叶与复叶**：**托叶**是叶柄基部的附属物（蔷薇科常有）；**复叶**是总叶柄上着生多个小叶——**复叶与「叶序」要分清**：复叶的所有小叶都在同一个总叶柄上，脱落后是一整片叶。

**辨析｜易错点：复叶 ≠ 一株植物的多片叶。** 判断「一片复叶还是几片单叶」看一个关键：**总叶柄基部有无腋芽/托叶**——复叶的总叶柄基部才有腋芽，每片小叶基部没有。识别错了，叶序、叶数、鉴定全跟着错。

## 4 营养器官的形态与栽培采收的对接

把三大器官的形态知识落到栽培与采收上：

**根类药材**（人参、黄芪）：栽培重点是**养直根**（深耕、控水、去侧根），采收看「地上部枯黄、根皮充实」——形态指标是地下部分是否成熟的镜面。

**茎皮类药材**（牡丹皮、黄柏）：**剥皮适期**多在春夏形成层活动旺盛、树皮易离时——剥早了皮薄、剥晚了难剥，形态与季节双重把握。

**叶类药材**（薄荷、艾叶）：采**叶色浓绿、未现蕾或初现蕾**时——此时挥发油与有效成分含量高，采晚了叶老油减。

**块茎/鳞茎类**（半夏、百合）：采收看**地上部枯萎、鳞片紧实**——地下膨大已完成，趁休眠期采收最耐贮。

**一句话原则：看形态读成熟度**——器官的外观变化（枯黄、饱满、色泽）是采收的「物候信号」，形态学让「何时采」从经验变成可判断的形态标准。

## 5 营养器官形态与分类鉴定的连接

根茎叶的形态特征不仅是栽培的对象，更是**分类与鉴定的第一手证据**（第5篇分类篇）：同科植物常共享根型（豆科直根）、茎型（唇形科四棱茎）、叶型（伞形科复叶）——**认对了根茎叶，就等于摸到了科属的门**。

**形态术语是识别的「通用接口」**：直根、须根、根状茎、鳞茎、叶序、叶脉——**每一组术语都是一类「可核对的特征」**，检索表（第5篇）正是靠这些特征逐对二歧。形态学掌握得越牢，检索表用得越顺。

**栽培与鉴定的双向赋能**：栽培中选品种、定采收看形态（第16篇「看形态读成熟度」）；鉴定中辨真伪、验正品看形态——**形态学是栽培与鉴定的共同底座**。

**辨析｜易错点：形态鉴定要「看全株」，不能只看局部。** 单看一片叶可能误判，**要看根、茎、叶、花的综合形态**（第4篇花果实种子）——**「全株特征比对」比「单一特征判断」可靠得多**，这是形态鉴定与检索表「逐对核对」的一贯纪律。

## 6 术语速查表

| 术语 | 含义 |
| --- | --- |
| 直根系 / 须根系 | 双子叶主根发达 / 单子叶须根发达 |
| 变态根 | 块根等由根变态而来 |
| 地下茎 | 根状茎、块茎、鳞茎、球茎，有节有芽 |
| 叶序 | 互生、对生、轮生、簇生 |
| 网状脉 / 平行脉 | 双子叶 / 单子叶叶脉类型 |
| 复叶 | 总叶柄上着生多个小叶 |
| 托叶 | 叶柄基部的附属物 |

**重点：术语是「形态语言」**——会说直根、块茎、复叶，才能精确描述、检索、鉴定。**形态学的力量，一半在观察，一半在「用术语精确表达观察」**。

## 7 小结

- **根**分直根系（双子叶）与须根系（单子叶），**块根**是根的变态，看「主根发达」判断品质。
- **茎**分地上/地下茎，皮类、木类、髓类药材各取茎的一部分；**地下茎有节有芽**，是与根区分的钥匙。
- **叶**的形态最丰富：叶序、叶形、叶脉是分类鉴定的第一手证据；**复叶 vs 单叶**看总叶柄基部有无腋芽。
- **变态器官**是药用植物的大类（根茎、块茎、鳞茎、球茎），**认器官先辨来源**，别被外观骗。
- **看形态读成熟度**：根皮充实、叶色浓绿、鳞片紧实都是采收的物候信号。
