# 产后康复（含盆底康复）

产后康复是围绕分娩后女性身体与心理全面恢复的学科，涵盖产褥期生理恢复、形体重塑与以盆底功能障碍诊疗为核心的康复医学分支。盆底健康直接关系女性一生的排尿、排便与性生活质量，且已形成诊疗指南与专家共识，是兼具临床价值与产业规模的领域。以《产后修复指南》《产后盆底功能障碍诊疗指南》《孕产期盆底健康手册》三部权威文献为纲，按学科内在逻辑逐节写成博文，学完即可贯通从产后整体恢复到盆底评估、诊断、治疗与全周期管理的完整知识体系。

## 对标教材

- 《产后修复指南》（中国医药科技出版社）
- 《产后盆底功能障碍诊疗指南》（中华医学会妇产科学分会）
- 《孕产期盆底健康手册》（人民卫生出版社）
