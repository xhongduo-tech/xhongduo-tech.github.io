# 特种医学

特种医学是研究高空、太空、深海、高原、高压等特殊环境中人体生理反应、疾病发生与防治保障的医学学科，也是我国医学门类下的独立一级学科（1009）。它以特殊环境生理学为基础，把航空航天医学、航海与潜水医学、高原医学和高压氧医学融为一体，既深化对正常与异常环境适应的理解，也为航空、航天、航海、高原作业与临床高压氧治疗提供系统的理论与实践支撑。
