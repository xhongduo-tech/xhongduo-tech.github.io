## 为什么从CT开始

上一篇我们停在普通 X 线摄影的先天缺陷：三维身体被压成一张二维影子，前后结构永远重叠。**计算机断层扫描（Computed Tomography, CT）**把这一缺陷直接拆除——让 X 线管与探测器绕着身体转一整圈，在几百个角度各拍一张「影子」，再用计算机解出一个数学问题，重建出身体某个横断面的「切片」。1971 年亨斯菲尔德把第一台 EMI 扫描仪装进伦敦医院时，一台机器要花约 4 分钟扫一个层面；今天的多排螺旋 CT 能在一次屏气里扫完整个胸部。<span class="marginnote">亨斯菲尔德与科马克（A. Cormack）共享 1979 年诺贝尔生理学或医学奖——这是诺贝尔奖第一次颁给「图像重建」这类数学物理工作，也是唯一一次。</span>

在「从极限到大模型」的课程线上，CT 是**线性代数第一次以工业级规模服务医学**：断层图像就是解一个巨型线性方程组 $Ax = b$，$A$ 是数百万行的投影矩阵。本篇把 CT 讲透，下一篇 MRI 的原理叙述就只需把「X 线投影」换成「磁共振信号」即可。

## 1 从投影到断层：一幅 CT 图像怎么来

CT 的采集是一个圆周运动：X 线管与探测器阵列在患者两侧相对而置，绕身体转 360°，每转一小角度就记录一束「投影」——即沿该方向的 X 线衰减总和。把这些投影按角度排成一张二维数组，叫**正弦图（sinogram）**。

重建的核心定理要上溯到 1917 年奥地利数学家拉东（Johann Radon）：

**拉东变换：一个二维函数 $f(x,y)$ 的所有「线积分」可以唯一反推出 $f$ 本身。** X 线投影恰是人体衰减系数分布 $\mu(x,y)$ 的线积分，因此「已知所有投影 → 反演 $\mu(x,y)$ → 得到断层图像」在数学上成立。<span class="marginnote">「用所有方向上的影子重建物体」的思想在断层成像之外同样开花结果——PET 的湮灭符合探测、天文合成孔径、地震层析都用同一套拉东反演。这是本博客《傅里叶分析》与《线性代数》最直接的医学落脚点。</span>

工程上的经典算法是**滤波反投影（filtered back-projection, FBP）**：把每条投影「抹回」它原来的射线路径上（反投影），再把各角度的抹痕叠加——但直接叠加会产生星芒状模糊，于是先用一个**卷积核（filter/kernel）**对投影做高通滤波抵消模糊。如今更先进的是**迭代重建（iterative reconstruction, IR）**：先猜一张图，把它的正投影与实际测得投影比较，反复修正直到两者一致。IR 在相同剂量下噪声更低，已成为剂量优化的主力。

**辨析｜易错点：** 反投影 ≠ 重建。反投影只是把数据「涂回去」的直觉操作，直接反投影得到的是被星芒模糊污染的图；FBP 之所以能重建，是因为它先用高通卷积核「预补偿」了反投影自带的模糊——滤波与反投影是配套的两步。而迭代重建换了一条路：它不追求一次公式解出，而是「猜 → 投影 → 比差 → 修正」反复逼近，每一步都在压缩与真实测量的差异。这个「迭代逼近」的思想，与第四级《机器学习》里梯度下降优化目标函数是同一个数学骨架。<span class="marginnote">对读者来说不必记住每种核的数学细节，但要知道一个选择：骨算法核锐利、噪声大，软组织算法核平滑、噪声小。技师为「看骨」与「看软组织」各重建一版——同一份原始数据可以派生出多套图像，这正是「图像 = 数据 + 重建参数」这一观念的起点。</span>

## 2 公式解析：CT值（Hounsfield单位）

X 线吸收本是连续物理量，临床却需要一个**以水为基准的相对标尺**。CT 值定义：

$$\mathrm{HU} = 1000 \times \frac{\mu_{\text{组织}} - \mu_{\text{水}}}{\mu_{\text{水}}}$$

- **第一步，先做差**：$\mu_{\text{组织}} - \mu_{\text{水}}$ 度量「该组织比水更能挡射线还是更能放行」，正数代表更致密。
- **第二步，归一化**：除以 $\mu_{\text{水}}$，把机器的管电压、设备差异抹掉，得到与能量大体无关的相对量。
- **第三步，放大 1000 倍**：让刻度落到「空气 −1000、水 0、皮质骨 +1000」这种易读的整数区间——本质上是一次坐标缩放。

$$\mu_{\text{空气}} \approx 0 \Rightarrow \mathrm{HU} = -1000; \qquad \mu_{\text{骨}} \gg \mu_{\text{水}} \Rightarrow \mathrm{HU} \approx +1000$$

**CT 值是 CT 成像的「货币」**：任何一帧 CT 图像都只是一张 HU 的矩阵，而窗宽窗位决定怎么把它画成灰度。软组织与水的差往往只有 20–40 HU，肉眼在满刻度下根本分不出来，所以要用**窄窗**（如脑窗 WW 80 / WL 40）把一小段 HU 范围拉伸到全灰度——这正是上一篇「窗宽窗位」在 CT 里的完整形态。

### HU 数值算例：读出「一串数字」的含义

临床判读的第一步就是把图像里的数字念出来。人体常见组织的 HU 大致如下：

| 物质 | 典型 HU | 在窗宽窗位下的表现 |
| --- | --- | --- |
| 空气 | −1000 | 全黑 |
| 脂肪 | −100 ~ −50 | 深灰偏黑 |
| 水 / 囊液 | 0 | 中灰 |
| 软组织 / 实质 | 20–70 | 浅灰 |
| 钙化 / 骨 | +300 ~ +1000 | 亮白 |

**辨析｜易错点：** 同一种组织在不同管电压下 HU 会轻微漂移，所以「某病灶 HU 是不是脂肪（<−20）」这类判断要结合同层面的大血管与皮下脂肪对照——机器之间、扫描参数之间的差异，正是为什么增强前后、同一层面内的相对比较永远比绝对数字可靠。<span class="marginnote">读 CT 有个口头禅叫「血是白、囊是黑、实性是灰」——急性血肿 HU 60–80、囊肿 HU 0–20、实性肿块 20–60。这一串数字是腹盆腔、头颅、胸部的通用尺子，背熟它，绝大多数「这团影是什么」的问题就成功了一半。</span>

## 3 螺旋CT与多排探测器：从「一层一层」到「一卷」

早期 CT 是「停一下扫一层」的步进式扫描。**螺旋CT（helical/spiral CT）**让患者匀速前进、X 线管同时连续旋转，扫描轨迹成一条螺旋线，器官被「卷」着扫完，再在电脑里切回任意位置的横断面。<span class="marginnote">螺旋扫描的价值在于速度与连续性：一次屏气扫完全胸、一个心动周期内完成冠状动脉成像，都依赖它。它把「层」的离散概念变成了「连续体积数据」，三维重建从此成为标配。</span>

螺旋 CT 的关键参数是**螺距（pitch）**：

$$p = \frac{\text{扫描架每转一圈床的前进距离}}{\text{探测器总覆盖宽度}}$$

$p = 1$ 表示床速恰好等于覆盖宽度（无重叠）；$p > 1$ 提速但牺牲采样，$p < 1$ 重叠采样提高精度。螺距是速度与图像质量之间的拨盘。

**多排探测器与时间分辨率**：从单排到 64 排、256 排乃至双源 CT，本质是在同一个转速里多「同时收集」几层数据，或用两套管球交替旋转把一次心跳的采集时间压进半圈。冠状动脉 CTA 之所以可行，正是因为 64 排以上机型能在 0.3 s 内完成整个心脏的覆盖——时间分辨率直接决定「运动的心脏能不能拍清楚」。<span class="marginnote">时间分辨率是 CT 家族里被低估的指标：同一台机器「快不快」决定了它是只能做静态躯干扫描，还是能进入冠脉、颅脑灌注这类需要「冻结运动」的任务。这与第四级《计算机体系结构》里「时钟频率决定能跑什么程序」的思路如出一辙。</span>

**层厚与重建间隔**也别混淆：层厚（slice thickness）决定每个切片的「厚薄」，重建间隔（reconstruction interval）决定相邻重建切片的步距——间隔可以小于层厚（重叠重建），得到更平滑的矢状/冠状面重排图，但不增加真实分辨率。这组概念是理解「三维重建图像质量从哪来」的第一步。

## 4 剂量与时相：CT的两大临床功课

CT 是当前人工辐射暴露的最大单一来源，因此剂量管理比任何模态都严格。常用量：**CTDI（剂量指数）**描述单次旋转的剂量，**DLP（剂量长度乘积）**乘以一个器官权重系数即估算有效剂量，单位 mSv——一次胸部 CT 约 5–8 mSv，约为一次普通胸片（0.02 mSv）的 300 倍。**ALARA 在这里不是口号，而是每份协议的默认设置**：低剂量扫描、儿童专用协议、自动管电流调制、迭代重建，全是「少辐射而不少信息」。

对比剂时相则决定诊断的敏感度。静脉团注碘剂后，按时间分动脉期（注射后约 20–30 s）、门静脉期（60–70 s）、延迟期（>3 min）。**同一个病灶在不同时相里的 HU 变化就是它的「光谱指纹」**：肝血管瘤是典型的「周边向心性强化」，肝癌则是动脉期快速强化、门脉期快速洗脱——时相序列本身就是诊断语言。

几种常见病灶的「时相指纹」值得提前记住，后面腹部篇会逐个展开：

| 病灶 | 动脉期 | 门脉期/延迟期 | 结论方向 |
| --- | --- | --- | --- |
| 肝血管瘤 | 周边结节状强化 | 向心性充填（灯泡征） | 良性 |
| 肝细胞癌 | 快速富血供强化 | 快速洗脱 | 恶性 |
| 肝囊肿 | 无强化 | 无强化 | 良性 |
| 肾细胞癌 | 明显强化 | 延迟洗脱 | 恶性倾向 |

<span class="marginnote">这套「时间—密度曲线」语言是整个腹部影像学的核心语法：不只肝、肾，胰腺、肾上腺、卵巢的病变定性都靠它。它与第五级《药代动力学》里「浓度—时间曲线决定分布半衰期」的推理模式同构——把「一个量随时间怎么变」读出来，结论自然浮现。</span><span class="marginnote">这篇讨论把「一次扫描」升级成「一个时间序列」，与第五级《生物化学》中酶动力学「追踪一个量随时间的变化」是同构的思维模式；动态增强 CT 正是把动力学曲线做成了图像。</span>

做个剂量小算例：一次腹部 CT 的 DLP 约 800 mGy·cm，乘以腹部器官权重系数 0.015 mSv/(mGy·cm)，有效剂量约为 $800 \times 0.015 = 12$ mSv。对照一次胸片约 0.02 mSv，两者相差约 600 倍。因此「能用 X 线解决的不用 CT、能用低剂量协议解决的不用标准剂量」是放射科的第一纪律——剂量不是抽象概念，它是每个病人实实在在接受的数字。<span class="marginnote">把「剂量」当「成本」来理解最直观：CT 是用较高「信息成本」换高敏感度的检查。与第三级《经济学》里「成本收益权衡」同构，放射科每开一张 CT 单，都在问同一个问题——多花这 12 mSv，能换回多大把握的诊断收益？</span>

## 5 常见的CT伪影与陷阱

CT 并非无失真。三类伪影要认识：**金属/骨束硬化伪影**（高衰减物体使射线硬化，产生黑白条纹）、**部分容积效应**（一个体素内混合了两种组织，HU 被平均——小钙化灶因此可能被漏掉）、**运动伪影**（呼吸/心跳使结构模糊或出现鬼影）。<span class="marginnote">部分容积效应是「离散采样」的必然代价：任何图像都是对连续世界的网格抽样，这与信号处理里的奈奎斯特采样定理、数字图像里的混叠是同一个原理，只是受害者换成了病人。</span>读片时「结合 HU 数值与形态、警惕伪影位置」是最基本的判读纪律。

**辨析｜易错点：** 束硬化条纹是「伪影」却不是「故障」——它恰恰是 X 线物理（低能光子先被吸收、剩余谱变硬）的直接结果。股骨金属假体周围的黑白条纹、后颅窝的亨氏暗区（两侧岩骨之间），都是束硬化的常客。判读时看到这类几何规律的重影，先想到「这是伪影」而不是「这是病灶」，能避免大量误诊；需要时用双能 CT 或 MAR（金属伪影去除）重建来压制。

## 6 术语速查：CT读片高频词

| 术语 | 含义 |
| --- | --- |
| HU（CT值） | 以水为基准的相对衰减刻度：$\mathrm{HU} = 1000(\mu - \mu_{\text{水}})/\mu_{\text{水}}$ |
| 窗宽 WW / 窗位 WL | 决定把哪一段 HU 映射到全灰度；窄窗看软组织、宽窗看骨 |
| 层厚 / 螺距 pitch | 扫描与采样的几何参数；$p$ 大提速、$p$ 小保精度 |
| 平扫 / 增强 | 不打对比剂 vs 团注碘剂后按时相采集 |
| 动脉期 / 门脉期 / 延迟期 | 增强后 20–30 s / 60–70 s / >3 min 的三个采集时间窗 |
| CTDI / DLP | 剂量描述量；DLP × 器官权重 ≈ 有效剂量（mSv） |
| FBP / IR | 滤波反投影（经典）vs 迭代重建（低噪声、剂量友好） |

## 7 小结

- CT 从多角度 X 线投影出发，靠**拉东反演**重建断层图像；**滤波反投影**与**迭代重建**是两条技术路线。
- **CT 值** $\mathrm{HU} = 1000(\mu - \mu_{\text{水}})/\mu_{\text{水}}$，水 0、空气 −1000、骨 +1000，是读片的定量语言。
- **窗宽窗位**把一小段 HU 拉伸到全灰度；**螺旋扫描 + 螺距**实现体积采集。
- 剂量管理遵循 **ALARA**；**多期增强**（动脉/门脉/延迟）用 HU 时间曲线给病灶定性。
- 认识**束硬化、部分容积、运动**三类伪影，是判读的基本功。

在下一节，我们换一种完全不同的物理原理——不用电离辐射，而是用磁场与射频脉冲把质子「叫醒」再「听回音」：**MRI成像基础**。
