## 为什么从牙拔除术开始

拔牙是口腔外科最基础、最常用的手术，也是每位口腔医生必须精熟的操作。它看似简单——「把牙拔下来」——实则涉及**适应证判断、术前评估、手术技巧、并发症防治**一整套决策体系。<span class="marginnote">「拔牙是最后的选择」是口腔医学的伦理底色：任何能保留的牙都应先尝试治疗（充填、根管、牙周、修复）。拔牙意味着承认「这颗牙已无法为患者继续服务」，同时也意味着要为后续修复（种植、义齿）留好「接口」。</span>本节沿「适应证与禁忌 → 术前评估 → 基本步骤 → 并发症」展开。

## 1 拔牙的适应证与禁忌证

**适应证（何时该拔）**：

牙体病：严重龋坏、残根残冠无法修复；
牙髓病/根尖周病：根管治疗失败且无法再治者；
牙周病：**重度牙周炎、骨吸收超过根长 2/3、III 度松动**，无法保留者；
**阻生牙**：智齿反复冠周炎、导致邻牙龋坏或牙槽骨吸收、妨碍修复或正畸者；
多生牙、错位牙影响功能或美观者；
外伤牙无法保存（牙根纵裂、牙体大部分缺失）；
正畸治疗需要（减数拔牙）；
病灶牙（疑为全身疾病病灶者，需权衡）。

**禁忌证（何时不能拔或需缓拔）**——拔牙是「全身风险评估」的手术：

**心血管疾病**：未控制的高血压、近期心肌梗死（6 个月内）、不稳定心绞痛、严重心律失常——需内科评估后择期。
**血液病**：血友病、严重血小板减少、白血病——禁拔或备血制品后处理。
**糖尿病**：血糖控制差者易感染、愈合差——控制后拔牙，术前术后抗感染。
**甲亢**、**肝肾功能不全**、**妊娠**（孕早期与晚期尽量避免，急症除外）、**放疗后颌骨**（放射性骨坏死风险）等。

<span class="marginnote">「禁忌证不是绝对不做，而是『在合适的时机、合适的条件下做』」——多数禁忌可通过控制基础病、调整用药、麻醉选择与预防性抗生素来「转危为安」。核心原则：<strong>拔牙前必须问病史，问不清不拔</strong>。</span>

## 2 术前评估：X 线与全身

**术前影像学评估**：

**根尖片/全景片（曲面断层片）**：牙根形态（数目、弯曲、肥大）、牙根与邻近结构的关系（下颌管、上颌窦）、根尖病变、埋伏牙位置。
**CBCT（锥形束 CT）**：复杂拔牙（阻生智齿、牙根与下颌管紧邻）三维评估——术前看「牙根和神经管贴多近」是避免下牙槽神经损伤的关键。

**全身与局部检查**：血压、心率、既往史、过敏史；术区有无急性炎症（**急性炎症期尽量延期拔牙**，但脓肿引流例外）、张口度、邻牙与对𬌗牙状态。

**知情同意**：向患者说明拔牙的**必要性、风险（出血、干槽症、神经损伤、断根等）与替代方案**——外科手术的「同意」不是签字仪式，而是信息充分后的理性选择。

## 3 拔牙的基本步骤与器械

**拔牙基本操作流程**：

1. **麻醉**：局部麻醉（见上节），必要时补充浸润。
2. **分离牙龈**：用牙龈分离器把牙龈从牙颈部分离，防止撕伤牙龈。
3. **挺松牙体**：用**牙挺（elevator）**楔入牙周膜间隙，利用**杠杆与楔力**逐步挺松牙体——「先挺松、后拔出」是拔牙的灵魂。
4. **安放牙钳**：用**牙钳（forceps）**夹持牙冠/牙颈部，**沿牙长轴方向**拔除——以**摇动、旋转、牵引**三力组合脱位。<span class="marginnote">「摇动」适用于多根牙（磨牙）、「旋转」适用于锥形单根牙（前牙、尖牙）、「牵引」沿牙长轴方向用力。方向错误的暴力牵引是断根与邻牙损伤的第一原因——拔牙是「巧力」而非「蛮力」。</span>
5. **检查与止血**：检查牙是否完整、牙槽窝有无遗留，棉卷压迫止血。

**各类牙的拔除要点**：上前牙直拔（旋转）、上磨牙向颊侧脱位（颊根多）、下磨牙向舌侧脱位（舌侧骨板薄）、下前牙与下前磨牙旋转或直拔。**牙根折断**（断根）时用小牙挺或根尖挺分根取出。

## 4 拔牙并发症及处理

**术中出血**：牙槽窝渗血多为正常，压迫止血；持续出血需缝扎、填塞（碘仿纱条）或处理血管损伤。
**牙根折断**：断面取出；残根过小且无法取出时，视情况保留观察（但根尖周病变者必须取净）。
**邻牙与对𬌗牙损伤**：操作不当所致——用挺时以邻牙为支点易伤邻牙，需以牙槽嵴为支点。
**上颌窦穿通**：上颌磨牙拔除时根尖穿入上颌窦——小的穿通（<2 mm）可自愈，大者需修补，术后避免擤鼻。
**下牙槽神经损伤**：埋伏下颌阻生智齿拔除时神经受损——多为一过性麻木，可恢复；术前 X 线评估根管关系可预防。
**干槽症（dry socket）**：拔牙窝血凝块脱落、骨面暴露，术后 2–3 天出现**剧烈疼痛并放射**，搔刮见骨面无血凝块——治疗为清创 + 碘仿纱条填塞 + 止痛，属**牙槽窝愈合不良**。<span class="marginnote">干槽症是拔牙术后最常见并发症（好发于下颌阻生智齿），疼痛在术后 2–3 天达到高峰、持续数日，口服止痛药效果差。预防要点：保护血凝块（术后勿漱口刷牙、勿吸吮）、避免吸烟、减少创伤。</span>
**术后出血**：多数因血凝块脱落——重新加压或缝合，嘱避免热食与剧烈运动。

**术后医嘱（拔牙后「三不一注意」）**：术后 **24 小时内不漱口、不刷牙、不吸吮创口**，2 小时后可进温凉软食，避免用患侧咀嚼；出现持续出血、肿胀加剧、发热及时复诊。<span class="marginnote">拔牙窝的愈合是「血凝块 → 肉芽 → 骨样 → 骨成熟」的过程，约需 3–6 个月才能完全改建——这为后续种植/修复的时机选择提供了「时间表」（见《牙槽外科与牙种植》）。</span>

## 5 核心要点：拔牙决策与并发症速查表

| 项目 | 要点 |
| --- | --- |
| 适应证 | 无法修复的龋/髓/根尖/牙周病、阻生、外伤、正畸需要 |
| 禁忌证 | 未控高血压/心梗近期、血液病、未控糖尿病、妊娠早期晚期等 |
| 术前评估 | 全景片/CBCT 看牙根与下颌管、上颌窦关系；问全身病史 |
| 三步操作 | 挺松 → 牙钳 → 沿长轴脱位 |
| 常见并发症 | 断根、邻牙损伤、上颌窦穿通、下牙槽神经损伤、干槽症 |

## 6 小结

- 拔牙是「最后的选择」，适应证与禁忌证要严格权衡；多数禁忌可择期创造条件。
- 术前必须**问病史、看影像**，复杂牙用 CBCT 评估与下颌管关系。
- 拔牙三步：分离牙龈 → 挺松 → 牙钳沿牙长轴脱位，巧力而非蛮力。
- 干槽症是术后最常见并发症，2–3 天剧痛、血凝块脱落，需清创填塞。
- 术后「24 小时不漱口不刷牙不吸吮」，拔牙窝 3–6 个月改建完成。
