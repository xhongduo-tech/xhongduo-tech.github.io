## 为什么从涎腺疾病开始

涎腺的炎症、结石与肿瘤占据了颌面外科门诊的一角。第一篇讲过涎腺解剖（腺体在哪、导管往哪走），第二篇讲过涎腺组织学（腺泡导管、细胞来源），本节把两者用于**临床**：如何判断「腮腺肿大是炎症、结石还是肿瘤」，如何选择治疗。<span class="marginnote">涎腺疾病的诊断有一条「第一原则」：<strong>肿块的良恶性判断</strong>。腮腺区肿块，良性以多形性腺瘤为最常见，恶性以黏液表皮样癌、腺样囊性癌为常见——但良恶性鉴别常需影像 + 细针穿刺，不可凭「不痛」就断定良性。</span>本节沿「炎症与结石 → 舍格伦综合征与口干 → 涎腺肿瘤 → 治疗」展开。

## 1 涎腺炎症：从流行性腮腺炎到细菌性腮腺炎

**涎腺炎（sialadenitis）**按病原分两类：

**病毒性涎腺炎**：**流行性腮腺炎（流行性腮腺炎病毒）**——儿童多见，腮腺肿痛，可伴脑膜炎、睾丸炎（青春期男性）；属**自限性**，对症支持为主，需隔离。<span class="marginnote">「痄腮」（流行性腮腺炎）是儿童最常见的病毒性腮腺炎：以「耳垂为中心」的腮腺肿大、张口咀嚼时疼痛、可伴发热。它与细菌性腮腺炎的鉴别点是「多为双侧、无脓、腮腺导管口无脓液」——病因不同，治疗迥异。</span>
**细菌性涎腺炎**：多为**逆行感染**——导管口细菌沿导管上行，常见于**唾液分泌减少**者（脱水、术后、老年、口干）。急性细菌性腮腺炎：腮腺红肿胀痛、导管口溢脓、发热——治疗为**抗生素 + 促进唾液分泌 + 保持导管通畅**。

**慢性涎腺炎**：多因导管狭窄或结石引起，反复发作、腺体肿大、进食时肿痛加重。治疗为去除病因（取石、扩张导管）、促进引流，必要时**腺体切除**（反复发作、功能丧失者）。

**涎腺炎的解剖学诱因**：任何使唾液分泌减少、导管狭窄或局部滞留的因素都可促成感染——**唾液是「天然抗菌剂」**（含溶菌酶、SIgA、乳铁蛋白），分泌减少即防线失守。老年、脱水、头颈放疗、舍格伦综合征、药物（抗胆碱）患者均为高危人群，预防核心是「多饮水、勤咀嚼、保持导管通畅」。

## 2 涎石症：导管里的「石头」

**涎石症（sialolithiasis）**是涎腺或其导管内形成结石：

**好发部位**：**下颌下腺（约 80%）**及其导管——因下颌下腺唾液黏稠、导管长而迂曲、位置低（重力与黏稠双重因素），见第一篇《涎腺解剖》。<span class="marginnote">为什么下颌下腺结石最多？三个「地利」：分泌物黏稠（混合性腺泡、黏蛋白多）、导管走行向上（Wharton 管开口于舌下肉阜，导管自下向上开口，分泌物逆重力流动）、导管长且迂曲（局部滞留）——三个条件叠加，钙盐易沉积成石。</span>
**临床表现**：进食时（尤其酸性食物刺激分泌）腺体**肿痛（涎绞痛）**，食后渐消；结石大时可触及硬块，导管口红肿溢脓（合并感染）。
**诊断**：触诊、**X 线（下颌横断片/咬合片，阳性结石显影）**、B 超；导管口小口结石可直视。
**治疗**：小结石（近导管口）可**按摩挤压或切开取石**；深部或腺体内结石、反复感染者行**腺体切除**。<span class="marginnote">「唾液腺内镜」是现代微创取石工具：内镜进入导管直视下取出结石或碎石，创伤小、保留腺体——对位置合适的结石，已成为首选。治疗目标始终是「尽量保留腺体功能」。</span>

**涎石的影像分类**：X 线显影者为**阳性结石**（含钙盐多，下颌下腺结石中约占 80–90%），不显影者为**阴性结石**（含蛋白多，腮腺多见）——阳性结石靠 X 线即足够，阴性结石需涎腺造影或 CBCT 检出。**「查不到结石 ≠ 没有结石」**，要结合症状与影像手段综合判断。

## 3 舍格伦综合征与口干症

**舍格伦综合征（Sjögren's syndrome, SS）**是**自身免疫性**涎腺炎，淋巴细胞浸润破坏涎腺与泪腺：

**表现**：**口干（眼干）+ 涎腺肿大**（反复腮腺肿大为常见主诉）；可为原发性或继发于类风湿关节炎、SLE 等。
**诊断**：症状 + **自身抗体（抗 SSA/SSB）** + **唇腺活检**（灶性淋巴细胞浸润）——「唇腺活检是金标准」。
**治疗**：无根治手段——对症为主：**唾液替代（人工唾液）、刺激分泌（毛果芸香碱）、口腔护理（防龋、抗真菌）**，全身用免疫调节剂。<span class="marginnote">舍格伦综合征患者的口腔问题远不止「干」：唾液减少导致<strong>猛性龋</strong>（釉质快速脱矿）、念珠菌感染、黏膜溃疡——「口干症的口腔管理」是这类患者的核心，防龋与口腔清洁优先于一切。</span>

**口干症（xerostomia）的其他原因**：药物（抗胆碱药、抗抑郁药、利尿剂）、**头颈部放疗**（腺体损伤，不可逆口干）、糖尿病、脱水、精神因素。处理：去除诱因、唾液替代、含氟防龋、咀嚼无糖口香糖刺激分泌。

**舍格伦综合征的 AECG 诊断标准**把「干」与「客观证据」结合：

| 项目 | 客观证据 |
| --- | --- |
| 眼干症状 | 持续眼干、异物感 |
| 口干症状 | 持续口干、需水伴食 |
| 客观检查 | Schirmer 试验、唾液流率下降 |
| 自身抗体 | 抗 SSA/SSB 阳性 |
| 组织学 | 唇腺灶性淋巴细胞浸润 |

符合 ≥4 项（或组织学 + 抗体等）可确诊——**「症状 + 客观 + 抗体 + 病理」缺一不可**，避免把药物性口干误诊为舍格伦。

**口干的口腔连锁伤害可以量化**：正常人静止唾液流率约 0.3 mL/min，低于 0.1 mL/min 即显著口干；唾液减少使龋病风险数倍上升、义齿固位下降、味觉减退。**衡量口干不靠「感觉」，靠客观流率与症状问卷**——这也是评估治疗效果的标尺。

## 4 涎腺肿瘤：临床与治疗

涎腺肿瘤约占头颈部肿瘤的 3–10%，**约 80% 发生于腮腺**；腮腺肿瘤中**良性约占 80%**（以多形性腺瘤最常见），恶性约占 20%。

**临床鉴别要点**：

**良性**：生长缓慢、边界清、质软或韧、活动、**无面瘫**。
**恶性**：生长快、边界不清、质地硬、**粘连固定**、**可伴面神经麻痹**（面瘫是恶性征象）、疼痛、区域淋巴结肿大。

**影像与病理**：B 超（初步）、**MRI**（腮腺深叶与面神经关系）、**细针穿刺活检（FNA）**（细胞学定性）——「影像定位 + FNA 定性」是涎腺肿块的术前常规。

**手术原则**（见第二篇《肿瘤病理》）：

多形性腺瘤：**腮腺浅叶/全叶切除**，解剖并保护面神经（防复发 + 防面瘫）。
恶性肿瘤：扩大切除 + 面神经处理（受侵犯则切除并移植修复）+ **颈部淋巴结清扫** + 术后放疗。<span class="marginnote">腮腺手术的「护神经」是灵魂：面神经五支穿行于腮腺实质，手术沿神经分支逐支解剖分离——<strong>解剖面神经是腮腺手术的第一步</strong>。术中可用<strong>神经监测仪</strong>实时刺激探测，把面瘫风险降到最低。面神经一旦受损，表情瘫痪的代价是终身的。</span>

**术后管理与随访**：腮腺术后加压包扎 5–7 天防涎瘘；观察面神经功能恢复；恶性肿瘤术后定期复查局部与颈部淋巴结。涎瘘（切口渗涎）多可自愈，持续者行二次缝合或小剂量放疗。

## 5 数值算例：三大涎腺的解剖—疾病对照

三大涎腺的解剖差异直接决定疾病谱（第一篇《涎腺解剖》已讲结构，这里看临床后果）：

| 腺体 | 导管 | 分泌类型 | 常见病 |
| --- | --- | --- | --- |
| 腮腺 | Stensen 管（长、开口于颊黏膜） | 浆液性为主 | 流行性腮腺炎、多形性腺瘤 |
| 下颌下腺 | Wharton 管（长而迂曲、开口于舌下肉阜） | 混合性、黏稠 | **涎石症（约 80%）** |
| 舌下腺 | 多支小管（Rivinus 管） | 黏液性为主 | 舌下腺囊肿（蛤蟆肿） |

**两个「80%」记牢**：涎石症中约 80% 发生在下颌下腺，涎腺肿瘤中约 80% 发生在腮腺。前者因「黏稠 + 导管长 + 逆行」，后者因腮腺是最大腺体、组织量多——「解剖决定疾病」在本节体现得最彻底。

## 6 核心要点：涎腺疾病鉴别速查表

| 疾病 | 主要表现 | 关键诊断 | 治疗 |
| --- | --- | --- | --- |
| 流行性腮腺炎 | 双侧耳垂肿痛、发热 | 多为病毒性、导管口无脓 | 对症支持、隔离 |
| 细菌性腮腺炎 | 单侧红肿、导管口溢脓 | 导管口脓液 | 抗生素、促分泌 |
| 涎石症 | 进食肿痛、涎绞痛 | X 线/内镜见结石 | 取石、必要时腺切除 |
| 舍格伦综合征 | 口干眼干、反复腺肿 | 抗体 + 唇腺活检 | 替代、刺激、防龋 |
| 多形性腺瘤 | 缓慢无痛肿块 | FNA 良性 | 腺叶切除保面神经 |
| 涎腺恶性肿瘤 | 快长、固定、可面瘫 | FNA 恶性 + 影像 | 扩大切除 + 颈清 + 放疗 |

## 7 术语速查

- **涎石症（sialolithiasis）**：涎腺或导管内结石，约 80% 发生于下颌下腺。
- **涎绞痛**：进食时腺体肿痛的「石头」信号。
- **舍格伦综合征（Sjögren's syndrome）**：自身免疫性涎腺/泪腺破坏，口干眼干。
- **唇腺活检**：诊断舍格伦的金标准，查灶性淋巴细胞浸润。
- **FNA（细针穿刺活检）**：涎腺肿块的术前细胞学定性。
- **Stensen 管**：腮腺导管，开口于上颌第二磨牙相对的颊黏膜。
- **蛤蟆肿（ranula）**：舌下腺黏液外渗形成的囊肿，形似蛙鸣囊。
- **阳性/阴性结石**：按 X 线是否显影分类，决定影像检查手段。
- **涎瘘（salivary fistula）**：唾液经创口渗出，术后加压包扎预防。

## 8 小结

- 涎腺炎分病毒性（流行性腮腺炎，自限）与细菌性（逆行感染，需抗生素），以导管口有无脓液鉴别。
- **涎石症好发于下颌下腺**（黏稠 + 导管长 + 逆行），进食肿痛为特征，微创取石优先。
- 舍格伦综合征是自身免疫性腺体破坏，唇腺活检为金标准，治疗以对症与口腔管理为主。
- 涎腺肿瘤多位于腮腺，良性以多形性腺瘤为多；**面瘫、固定、快长提示恶性**。
- 腮腺手术核心是解剖保护面神经；恶性肿瘤需扩大切除 + 颈清 + 放疗。
