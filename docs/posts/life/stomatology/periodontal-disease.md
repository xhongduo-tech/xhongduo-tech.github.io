## 为什么从牙周病开始

龋病破坏牙齿本体，牙周病则破坏牙齿的「地基」——**牙周组织**。牙龈炎与牙周炎是最常见的牙周病，也是成年人失牙的第一大原因。<span class="marginnote">牙周病学有个著名的判断：「如果只看牙龈出血，牙周病可能已经存在多年。」因为牙周炎早期常无症状，多数患者因「刷牙出血」「牙松动」就诊时，骨吸收已相当可观——这正是牙周病「沉默」的可怕之处。</span>本节沿「病因 → 分类 → 临床表现 → 诊断与预后」展开，治疗见下节《牙周治疗》。

## 1 牙周病的病因：菌斑是主线

牙周病是**多因素疾病**，核心病因链是：

- **始动因子——牙菌斑（dental plaque）**：菌斑是细菌生物膜，其内的**牙龈卟啉单胞菌（Porphyromonas gingivalis）、伴放线杆菌、福赛坦氏菌**等**牙周致病菌**是牙周破坏的元凶。
- **局部促进因素**：**牙石（calculus）**——钙化的菌斑，表面粗糙更利于菌斑堆积；**食物嵌塞、不良修复体、牙列拥挤、咬合创伤**等加重菌斑滞留与损伤。
- **全身促进因素**：**吸烟**（最重要的环境危险因素）、**糖尿病**（血糖控制差者牙周炎更重）、**免疫缺陷**、**精神压力**与**遗传易感性**。

**菌斑 → 牙龈炎 → 牙周炎**的进程：菌斑堆积 → 牙龈炎症（可逆）→ 若持续，结合上皮根移、附着丧失、牙槽骨吸收（不可逆的牙周炎）。<span class="marginnote">「菌斑是病因、牙石是帮凶、宿主反应是放大器」——这个三角关系解释了牙周治疗的逻辑：去除菌斑（洁治）、去除牙石（刮治）、控制宿主反应（戒烟、控糖、维护）。</span>

## 2 牙龈炎：可逆的第一站

**牙龈炎（gingivitis）**是局限于牙龈的炎症，特征是**无附着丧失、无骨吸收**。

**临床表现**：

- 牙龈**充血发红、水肿**，龈缘圆钝、乳头肥大；
- **刷牙或探诊出血**是最常见的主诉；
- 牙龈可有痒胀感，但**多无自发性疼痛**；
- 炎症局限、可逆，去除菌斑后牙龈恢复正常。

**分类**：慢性龈炎（最常见）、青春期龈炎、妊娠期龈炎（激素相关）、药物性牙龈增生（苯妥英钠、硝苯地平）、急性坏死性溃疡性龈炎（ANUG，伴疼痛、口臭、龈乳头坏死）等。

**牙龈炎与牙周炎的关键区别**：前者**探诊无附着丧失、X 线无骨吸收**，后者有。<span class="marginnote">「探诊出血（BOP）」是牙龈炎症最敏感的标志——健康牙龈探诊不出血，出血即提示炎症。而「探诊深度 >4 mm」则提示可能存在附着丧失与真性牙周袋，需进一步拍片确认骨吸收程度。</span>

## 3 牙周炎：不可逆的第二站

**牙周炎（periodontitis）**在牙龈炎基础上进展，特征为**附着丧失 + 牙槽骨吸收 + 真性牙周袋形成**。

**临床表现**：

- **牙周袋**：探诊深度 >4 mm，袋内溢脓、探诊出血；
- **牙槽骨吸收**：X 线示牙槽嵴顶降低、硬板消失，分**水平吸收**（骨嵴水平降低）与**垂直吸收**（局限骨下袋）；
- **牙龈退缩**：牙根暴露、牙颈部敏感；
- **牙松动与移位**：骨吸收超过根长 1/2 时出现明显松动，甚至牙齿脱落；
- **其他**：口臭、食物嵌塞、牙周脓肿反复发作。

**分类（2017 年国际新分类）**：

- **慢性牙周炎（最常见）**：成人多见，进展缓慢，与菌斑牙石直接相关；按骨吸收与附着丧失程度分轻、中、重度。
- **侵袭性牙周炎**：青年发病，进展快，家族聚集性，常伴特定菌感染；特征为「早期骨吸收与菌斑量不成比例」。
- **牙周炎的全身/局部相关表现**：与糖尿病、吸烟、免疫功能等相关。

<span class="marginnote">「牙周炎与全身疾病的双向关系」是近年热点：糖尿病与牙周炎互为危险因素（糖尿病加重牙周炎，牙周炎也影响血糖控制），心血管病、不良妊娠结局也与牙周炎相关——这使牙周治疗的意义超出了「保牙」本身，成为全身健康管理的一部分。</span>

## 4 牙周炎的诊断与预后判断

**诊断流程**：

1. **探诊**：**牙周探针**测量**探诊深度（PD）**、**附着水平（AL）**、**探诊出血（BOP）**——六点法记录每牙六个位点。
2. **X 线**：根尖片/曲面断层片评估**牙槽骨吸收程度与形态**（水平/垂直、根分叉受累）。
3. **牙松动度**：按动度分 I、II、III 度。
4. **其他**：菌斑指数、龈炎指数、咬合检查。

**预后判断要素**：骨吸收程度与形态、根分叉病变、牙周袋深度、牙松动度、患者依从性（能否戒烟、维护口腔卫生）。<span class="marginnote">「垂直骨吸收（骨下袋）预后优于水平吸收」是临床经验：垂直吸收多与局限深袋相关，可通过手术（骨再生）修复；水平吸收是弥漫性支持丧失，治疗重在「止损」而非「长回骨头」。</span>

## 5 核心要点：牙龈炎 vs 牙周炎对比表

| 对比项 | 牙龈炎 | 牙周炎 |
| --- | --- | --- |
| 炎症范围 | 限于牙龈 | 累及牙周膜、牙槽骨 |
| 附着丧失 | 无 | 有（真性牙周袋） |
| 牙槽骨吸收 | 无 | 有 |
| 可逆性 | 可逆 | 不可逆（可控制） |
| 典型症状 | 刷牙出血、牙龈红肿 | 深袋、溢脓、松动、退缩 |
| 治疗目标 | 恢复正常 | 控制炎症、阻止进展 |

**辨析｜易错点：**「牙龈出血 = 牙周炎」是常见误判。牙龈出血主要是牙龈炎的表现，而牙周炎常以「牙松动、牙缝变大、牙龈退缩」为主诉，出血反而可能不明显。反过来，「不流血 = 牙周健康」也错——吸烟者牙龈血管收缩，出血减少但牙周破坏更重。**诊断以探诊与 X 线为准，不凭出血感觉。**

## 6 小结

- 牙周病病因主线：菌斑（始动）→ 牙石/局部因素（促进）→ 宿主反应（放大）；吸烟与糖尿病是重要全身因素。
- 牙龈炎：限于牙龈、可逆，探诊出血是标志，无附着丧失与骨吸收。
- 牙周炎：附着丧失 + 骨吸收 + 真性牙周袋，分慢性（最常见）与侵袭性等类型。
- 诊断靠探诊（PD/AL/BOP）+ X 线（骨吸收）+ 松动度评估。
- 牙周炎与糖尿病、心血管病的双向关系，使牙周治疗纳入全身健康管理。
