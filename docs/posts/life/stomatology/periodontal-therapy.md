## 为什么从牙周治疗开始

上节认识了牙周病，本节回答「怎么治」。牙周治疗遵循**系统分阶段**的策略：**基础治疗（洁治、刮治、根面平整）→ 手术治疗（必要时）→ 修复治疗（恢复功能）→ 维护期（长期维持）**。<span class="marginnote">牙周治疗的哲学是「从非手术到手术、从简单到复杂」：绝大多数患者通过基础治疗即可控制病情，手术只在基础治疗不彻底或存在深袋、骨缺损等特殊情形时才介入——「能非手术则不手术」是现代牙周治疗的基本原则。</span>本节沿「基础治疗 → 手术 → 修复与维护 → 疗效标准」展开。

## 1 基础治疗：洁治与刮治

**基础治疗（initial therapy）**是牙周治疗的基石，目标是**去除菌斑与牙石、消除炎症**。

**洁治（scaling，洗牙）**：用**超声洁治器**与手工器械去除**龈上牙石**与菌斑。适用于所有牙龈炎与牙周炎患者的起始治疗。<span class="marginnote">「洗牙会伤牙」是最流行的误解。规范洁治只去除牙石与菌斑，不伤釉质（器械硬度低于釉质）；洁治后牙缝变大、牙根暴露的「错觉」，其实是牙石长期占据牙缝后暴露了本已存在的萎缩——洁治是「还原真相」而非「制造问题」。</span>
**刮治与根面平整（scaling and root planing, SRP）**：用**龈下刮治器**深入牙周袋内，去除**龈下牙石**与病变的牙骨质，使根面光滑（根面平整），利于牙龈重新附着。
**辅助治疗**：局部用**抗生素（缓释剂）**、氯己定漱口液、咬合调整（调𬌗）。

**SRP 的疗效**：对轻中度牙周炎，SRP 可显著减轻炎症（探诊出血减少、袋深变浅），是**非手术牙周治疗（NSPT）**的核心。牙周袋越浅、牙石越易去净，疗效越好；深袋（>5 mm）、根分叉区则常需手术。

**辨析｜易错点：**「洁治 = 刮治」是常见混淆。**洁治**管龈上，**刮治**管龈下、需局部麻醉且技术要求更高；龈下牙石是牙周炎的主要「弹药库」，只洁治不刮治，等于只扫了客厅没扫地下室。

**探诊袋深 → 治疗决策**是牙周治疗的「路线图」：

| 袋深（mm） | 治疗路径 |
| --- | --- |
| ≤3 | 洁治 + 口腔卫生指导 |
| 4–5 | SRP（刮治 + 根面平整） |
| 6–7 | SRP 为主，深袋考虑翻瓣 |
| ≥7 / 根分叉 | 翻瓣术 / 骨手术 / GTR |

**「探诊是牙周的听诊器」**——袋深、附着丧失、出血指数三项数值决定每一步走法，也是疗效评估的硬指标。

## 2 牙周手术：当基础治疗不够时

**牙周手术（periodontal surgery）**的适应证：深牙周袋（>5 mm）经 SRP 后仍不消退、根分叉病变、牙周脓肿反复、骨缺损需再生、需评估或拔除重度患牙等。

主要术式：

**牙龈切除术（gingivectomy）**：切除肥大的牙龈组织与浅袋，恢复牙龈外形。
**翻瓣术（flap surgery）**：切开翻起牙龈黏骨膜瓣，**直视下刮治根面与骨面**，消除深袋、修整骨缘，再复位缝合——深袋治疗的金标准术式。<span class="marginnote">翻瓣术的意义在于「看见」：龈下牙石与根面病变在盲视下难以彻底清除，翻开瓣后直视操作，清创彻底、骨面修整到位，术后袋深显著降低。现代还可在瓣下做「微创」（MIST）切口，减少创伤与牙龈退缩。</span>
**骨手术（osseous surgery）**：修整牙槽骨形态（骨成形/骨切除），配合翻瓣术改善骨外形。
**引导性组织再生术（GTR）**：用**屏障膜**隔绝牙龈上皮，引导**牙周膜细胞**优先向骨缺损区生长，配合**骨移植材料**促进牙槽骨再生——目标是「长回骨头」。
**牙周再生（regeneration）**：GTR + 骨替代材料 + 生长因子（如 Enamel Matrix Derivative 釉基质蛋白衍生物）。
**牙冠延长术（crown lengthening）**：切除部分牙龈与牙槽骨，暴露更多牙体——用于修复（重建生物学宽度）或美容（改善露龈笑）。

**翻瓣术与再生术的目标不同**：翻瓣术重在「清创 + 修整」（去除深袋、平整根面、修整骨缘），结果是消除病变但不增加骨量；GTR/再生重在「长回骨头」（屏障膜引导 + 骨移植），目标是骨量恢复。**深袋未必都适合再生**——骨缺损形态（三壁骨袋再生潜力最好）、患者菌斑控制、全身状况都影响再生效果。

**手术后的管理**：术区保护、口腔卫生维护、抗生素与镇痛、定期复查——手术只是「重新开始」的契机，术后维护决定长期疗效。

**牙周脓肿的处理**：深袋引流不畅、急性感染时形成。处理为切开引流 + 抗生素 + 去除病因（刮治），急性期缓解后再评估手术。**鉴别要点**：牙周脓肿是「深袋里的脓」，根尖周脓肿是「根尖的脓」——前者侧向叩痛不著、牙髓活力常正常，后者多伴深龋或牙髓坏死。

## 3 修复、调𬌗与维护期

**牙周治疗的另一半在治疗之后**：

**调𬌗（occlusal adjustment）**：消除**𬌗创伤**——通过选择性磨改牙尖与窝沟，建立协调的咬合关系，减少对牙周组织的侧向力。
**松动牙固定**：用牙周夹板把松动牙与邻牙相连，分散咬合力。
**修复治疗**：牙周病导致失牙后，通过**种植、固定桥或活动义齿**恢复咀嚼（见第五篇）；但前提是**牙周炎症已控制**，否则修复体在炎症环境下很快失败。

**牙周修复的「先治后修」铁律**：牙周炎症未控制前不做永久修复——修复体边缘在炎症环境中会加速菌斑滞留与进一步附着丧失。临床顺序是「牙周稳定 3–6 个月后再考虑种植或固定修复」，必要时先行牙冠延长术重建生物学宽度。
**维护期（supportive periodontal therapy, SPT）**：**定期复诊（3–6 个月一次）洁治**、评估菌斑控制、监测袋深与骨吸收。**牙周炎是慢性病，需终身维护**——「一次治好永不复发」是幻想。<span class="marginnote">「患者的菌斑控制是治疗成败的最终裁决者」——牙周病病因在菌斑，而菌斑的生长每天 24 小时进行。医生能做的（洁治、刮治、手术）都是「清零」与「重置」，真正长期的控制靠患者<strong>每天有效的自我清洁</strong>（正确刷牙 + 牙线/牙缝刷）。</span>

## 4 牙周治疗与全身健康

牙周治疗不仅关乎牙齿，也影响全身：

**糖尿病**：有效牙周治疗可改善血糖控制（HbA1c 下降），而糖尿病控制差者牙周炎更难治——**双向管理**。
**心血管疾病**：控制牙周炎可降低炎症负荷，虽不能直接逆转动脉粥样硬化，但作为系统性炎症管理的一部分有积极意义。
**妊娠**：孕期牙周炎与不良妊娠结局相关，孕期可安全进行基础治疗（避免不必要的药物）。
**放疗/化疗患者**：牙周评估与处理是肿瘤治疗前口腔准备的一部分。

**全身状况对牙周治疗的调整**：未控制的高血压、严重心脏瓣膜病、抗凝治疗等，需调整操作方案与用药（如预防性抗生素）。<span class="marginnote">「牙周-全身对话」让口腔医生从「牙匠」变为「全科健康管理者」——这与《公共卫生与预防医学》视角的衔接，也是口腔预防从「防龋」走向「防全身病」的新图景。</span>

## 5 数值算例：SRP 的疗效数字

SRP 的疗效可以用一组数字说明（轻中度慢性牙周炎的典型结果）：

| 指标 | SRP 后典型变化 |
| --- | --- |
| 探诊出血（BOP） | 显著下降，炎症消退 |
| 袋深 | 平均减少 1–2 mm |
| 附着获得 | 平均 0.5–1 mm |
| 袋深 ≥7 mm 者 | 减少有限，常需手术 |

**两组数字记牢**：SRP 对 ≤5 mm 的袋疗效最好，对 ≥7 mm 的深袋效果有限（深袋刮不净、愈合差）——「轻袋靠刮治、深袋靠手术」是选择路径的刻度。

**抗生素在牙周治疗中的位置**：局部缓释剂（四环素类、米诺环素）用于局限深袋；全身抗生素（甲硝唑 + 阿莫西林）用于侵袭性牙周炎或伴全身疾病者。**抗生素是辅助不是主力**——不清理牙石光吃药，等于「只消毒不扫地」，菌斑生物膜保护下的细菌会卷土重来。

## 6 核心要点：牙周治疗阶梯表

| 阶段 | 主要内容 | 目标 |
| --- | --- | --- |
| 基础治疗 | 洁治、SRP、口腔卫生指导、调𬌗 | 去除病因、控制炎症 |
| 手术治疗 | 翻瓣、骨手术、GTR/再生、牙冠延长 | 消除深袋、促进再生 |
| 修复治疗 | 种植、固定桥、活动义齿 | 恢复咀嚼与美观 |
| 维护期 | 定期复诊洁治、监测 | 长期稳定、防止复发 |

## 7 术语速查

- **洁治（scaling）**：去除龈上牙石与菌斑，「洗牙」。
- **刮治与根面平整（SRP）**：龈下刮治 + 根面平整，非手术牙周治疗核心。
- **翻瓣术（flap surgery）**：翻开牙龈瓣直视清创，深袋金标准术式。
- **GTR（引导性组织再生术）**：屏障膜引导牙周膜细胞再生骨组织。
- **SPT（支持性牙周治疗）**：牙周炎维护期的定期复诊洁治。
- **调𬌗（occlusal adjustment）**：消除𬌗创伤的咬合调整。
- **牙周脓肿（periodontal abscess）**：深袋内急性感染化脓，切开引流。
- **菌斑控制**：患者每日自我清洁，牙周治疗的最终裁决者。

## 8 小结

- 牙周治疗策略：基础治疗 → 手术 → 修复 → 维护，能非手术则不手术。
- **洁治管龈上、刮治（SRP）管龈下**，深袋与根分叉常需翻瓣手术。
- 牙周手术核心为翻瓣术（直视清创）、骨手术、GTR 骨再生与牙冠延长术。
- 牙周炎是慢性病，**维护期（SPT）终身复诊**是长期疗效的保障。
- 牙周治疗与糖尿病、心血管病、妊娠结局双向相关，兼具全身健康意义。
