## 为什么需要土壤分类

上一节我们讲了土壤如何发生——五个因素叠加出千姿百态的土。现在问题来了：地球上到底有多少种土？没人能逐块命名，于是必须**分类**。<span class="marginnote">分类是科学的元工具：生物学有林奈双名法，化学有元素周期表，土壤学也需要一张「周期表」。分类的目的不是堆名词，而是把无数个体压缩成有限类型，让经验可以迁移——这与机器学习里「聚类的目的」同构，第四级《数据科学》会见到同款逻辑。</span>有了分类，土壤调查才能把「这张地图涂上颜色」，农业与工程才能把「这块地适合什么」翻译成可查询的语言。

## 1 从发生学分类到诊断学分类

土壤分类走过两条路线，理解其分野很重要：

**发生学分类（genetic classification）**：按「怎么形成的」来分——依据母质、气候、植被等成土因素推断土壤类型。它的优点是直觉强，缺点是「成因靠推断」导致分类不稳定：同一块土，换个人推断，可能就换了类。
- **诊断学分类（diagnostic classification）**：按「现在是什么样」来分——依据可实测的**诊断层（diagnostic horizon）**与**诊断特性**判定类型。<span class="marginnote">「测出什么就是什么」而非「推测成因」，这是 20 世纪土壤分类的科学化革命，与医学从「凭经验」走向「按化验单诊断」是同一次观念跃迁。</span>

美国土壤分类系统（Soil Taxonomy）是诊断学分类的集大成者，1975 年正式出版，至今仍是全球影响力最大的体系。

## 2 USDA 土壤分类：层级与十二土纲

Soil Taxonomy 采用六级层级，从粗到细依次是：**土纲（order）→ 亚纲（suborder）→ 土类（great group）→ 亚类（subgroup）→ 土族（family）→ 土系（series）**。每个级别都在名字里加一个音节，所以完整的土系名读起来像一长串暗语——其实每个音节都有严格含义。

举一个完整的例子：Ultisol（土纲）→ Udult（亚纲，湿润）→ Hapludult（土类）→ Typic Hapludult（亚类）→ fine-loamy（土族质地）→ 某地名（土系）。每一段都是检索键走出来的证据链，名字里藏着测定值。

最高层的**十二个土纲**是入门必修：

| 土纲 | 核心诊断特征 |
| --- | --- |
| Entisols（新成土） | 剖面发育微弱，几乎无诊断层 |
| Inceptisols（始成土） | 发育刚开始，仅具雏形层 |
| Andisols（火山灰土） | 火山灰母质，含铝硅酸盐短程有序矿物 |
| Gelisols（冻土） | 永久冻土，表层以下出现冻层 |
| Histosols（有机土） | 有机质极度积累（泥炭、腐泥） |
| Spodosols（灰土） | 酸性砂质土，B 层淀积铝、铁与腐殖质 |
| Alfisols（淋溶土） | 湿润地区，B 层黏粒淀积、盐基饱和度中等以上 |
| Ultisols（老成土） | 高度风化的湿润土，B 层黏粒淀积、盐基饱和度低 |
| Mollisols（软土） | 草原黑土，表层富含有机质、盐基饱和 |
| Oxisols（氧化土） | 湿热地区深度风化的铁铝氧化物土 |
| Aridisols（旱成土） | 干旱气候，水分亏缺、常有钙积层 |
| Vertisols（变性土） | 富含膨胀性黏土，干湿交替时强烈胀缩 |

判定顺序遵循「检索键（key）」：从第 1 条（新成土）开始逐条排除，遇到「是」就命中——这实质上是一棵**决策树**。<span class="marginnote">检索键「按顺序、遇真即止」的结构与编程里的 if-else 链、与信息论的二分决策树完全一致；土壤分类也因此天然可被计算机检索，是标准的 AI 用武之地。</span>

## 3 公式解析：旱成土的水分亏缺判据

旱成土（Aridisols）是整个检索键里最有「定量味」的一纲——它不只是看有没有钙积层，还要看**水分收支**。其判别基于土壤水分控制段中的水分状态，而宏观上对应一个简单的气候指标：

$$\frac{P}{ET_p} < 0.5 \text{（半干旱~干旱过渡区可放宽判据）},\quad \text{且根系层常年存在水分亏缺}$$

逐项拆解：

- **第一步，认识 $P$**：$P$ 是年平均降水量。它在干旱区可能只有几百毫米甚至更少。
- **第二步，认识 $ET_p$**：$ET_p$ 是**潜在蒸散量（potential evapotranspiration）**——当地水汽条件允许时，地表与植被能蒸散掉的最大水量，主要由太阳辐射、温度与风决定。
- **第三步，理解比值**：当 $P / ET_p < 1$ 时，降水已经不够「喂饱」蒸发需求，土壤必然向干燥方向发展；旱成土要求的比值更低，保证水分亏缺是常态而不是偶发。
- **第四步，回到土壤**：水分亏缺 → 淋溶微弱 → 可溶性盐与钙质在剖面中累积 → 出现钙积层 → 土壤被诊断为旱成土。一条定量判据，把气候与土壤剖面串成因果链。

## 4 中国土壤分类系统

中国先后采用过两套系统，教学时都要认识：

- **发生学分类（1978《中国土壤分类系统》）**：按成土过程分土纲、土类等，常见土类有砖红壤、红壤、黄壤、棕壤、黑土、黑钙土、栗钙土、荒漠土等。这套体系地名色彩浓，便于与景观对应，但存在「成因推断」的不稳定问题。
- **中国土壤系统分类（CST，1990s 至今）**：吸收 Soil Taxonomy 的诊断学思想，用**诊断层与诊断特性**重新组织，下设 14 个土纲，如：有机土、人为土、灰土、火山灰土、铁铝土、变性土、干旱土、盐成土、潜育土、均腐土、富铁土、淋溶土、雏形土、新成土。<span class="marginnote">注意「人为土」纲：被长期耕作改造的土壤（如水稻土）被单列一纲，这是中国分类对全球土壤学的重要贡献——人类活动已经是可以诊断的成土因素。</span>

两套系统对同一块土可能给出不同名字：华南一块湿热红土，发生学叫「红壤」，CST 里若符合铁铝层判据则叫「铁铝土」。考试与科研中务必标明用的是哪套系统。

## 5 土壤调查：把分类落到地图上

分类是「命名」，调查是「找分布」。**土壤调查（soil survey）** 的完整流程是：

1. **踏勘**：从地形图、卫片与植被信息预判土壤格局，选定典型剖面。
2. **剖面挖掘与描述**：挖剖面、记录土层颜色、质地、结构、pH 等，取土样送实验室。
3. **制图单元划分**：以**土系**为最小制图单元，按景观边界聚合为**土组、土相**等制图单元。
4. **成图与报告**：输出**土壤图（soil map）**与调查报告，附上每类土壤的利用建议。

制图单元内部的「纯度」用**杂斑（inclusions）**表示——一块制图单元里总含少量别类土壤，这是地图综合的必然取舍。调查成果最终汇入**土地利用能力分级（land capability classification）**：从 I 级（几乎无限制、宜于耕作）到 VIII 级（不适宜耕作、只宜保护），农田、牧场、林业、野生动物与休闲五类用途各有限制。这套分级至今仍是区域规划的底图。

## 6 案例：用检索键给一块土定土纲

把检索键完整走一遍，胜过背十遍土纲名单。设我们挖到这样一块土：

- 湿润亚热带气候下的老红土，B 层黏粒明显淀积；
- 土壤盐基饱和度仅 25%（很低）；
- 无永久冻层、无火山灰特性、无泥炭化累积；
- B 层有黏化层，但不符合灰土（Spodosol）的铁铝腐殖淀积判据。

按 Soil Taxonomy 检索键自上而下逐条排除：

- 不是冻土（无永冻层）→ 排除 Gelisols；
- 不是有机土（无厚有机层）→ 排除 Histosols；
- 不是火山灰土（无火山灰特性）→ 排除 Andisols；
- 未深度风化到铁铝氧化物富集 → 排除 Oxisols；
- 不是干旱气候（无常年水分亏缺）→ 排除 Aridisols；
- B 层黏粒淀积、盐基饱和度低（< 35%）→ **命中 Ultisols（老成土）**。

假如同一块土盐基饱和度更高（> 35%），检索会落在 Alfisols（淋溶土）——土纲之差，只隔一组化学指标。这就是诊断学分类「测什么算什么」的公正与高效：它不追问「这土是怎么来的」，只要求「按现在的测定值，走完这条键」。这也让它天然适合计算机化——事实上，全球土壤数据库（如 SoilGrids）正是把检索键编程后逐像元跑分类的。

用这套命名对照中国系统：同一检索路径下，那块土在发生学《中国土壤分类系统》里多半被叫「红壤」；两套语言描述同一块地，只有标注清楚用的是哪个系统，跨系统比较才有意义。

## 7 小结

- 土壤分类有**发生学**与**诊断学**两条路线，现代主流是依据可实测**诊断层/诊断特性**的诊断学分类。
- USDA Soil Taxonomy 六级体系（**土纲→…→土系**）以 12 个土纲打头，用**检索键**判定，本质是决策树。
- 旱成土等土纲的判据含定量水分指标，如 $P/ET_p$ 比值反映水分亏缺。
- 中国有**发生学分类**与**中国土壤系统分类（CST）**两套体系，CST 含独特的**人为土纲**。
- **土壤调查**把分类落到地图上：踏勘→剖面→制图单元→土壤图，最终汇入**土地利用能力分级**。
- 中国系统的发生学「红壤」与 CST 的「铁铝土/老成土」常指同一块地；跨系统比较必须先标注系统。
- 土壤图精度受**制图比例尺**约束：1:5 万分辨土组，1:100 万只能分辨土纲——画多细取决于用途。
