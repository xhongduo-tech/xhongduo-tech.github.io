# 养老护理员职业技能（老年照护）

养老护理员是面向 2.5 亿老年人日常生活照护与健康照护需求的核心职业技能工种，覆盖生活照护、基础照护、康复服务、心理照护等专业方向。以《养老护理员国家职业技能标准（2019年版）》、民政部《养老护理员培训大纲》和《养老护理员职业技能等级认定培训教材》为纲，从职业认知到等级认定考核，系统写完整门照护技能。

## 对标教材

- 《养老护理员国家职业技能标准（2019年版）》（人社部/民政部）
- 民政部《养老护理员培训大纲》
- 《养老护理员职业技能等级认定培训教材》
