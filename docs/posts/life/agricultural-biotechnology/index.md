# 农业生物技术

农业生物技术是以分子生物学、基因工程与基因组学为核心手段改良作物遗传性状、提升产量品质与抗逆性的现代作物科学前沿方向，涵盖分子标记辅助育种、基因工程育种、基因编辑与组学育种四大核心。学完这些章节，就系统掌握了从基因到新品种的完整生物育种工具箱。

## 对标教材

- 张献龙《植物生物技术》（科学出版社）
- 黎裕《植物分子育种技术及其应用》（科学出版社）
- 《农业生物技术》（中国农业出版社）
