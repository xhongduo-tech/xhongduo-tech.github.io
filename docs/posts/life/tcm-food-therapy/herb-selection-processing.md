## 为什么从中药的选择与炮制开始

第八篇收官了理论板块，从本篇开始进入「原料与工艺」。药膳的原料一半是食物、一半是中药——而「中药」是药膳区别于普通菜肴的关键变量。选错药、炮制不当、犯了配伍禁忌，轻则无效，重则伤身。所以讲原料，先从「中药」这一半讲起。

本篇回答三件事：**选什么**（选择原则）、**怎么炮**（炮制工艺）、**忌什么**（配伍禁忌）。三者层层递进：选对了，才有资格谈炮制；炮制好了，才能谈配伍。这是药膳从「纸上谈方」走向「实操下锅」的第一道门槛。<span class="marginnote">本篇与第五篇《药食同源与既是食品又是中药材的物质目录》呼应：第五篇讲「哪些能吃」的制度边界，本篇讲「在边界之内如何选、如何炮、如何避忌」的技术操作。</span>

## 1 药膳用中药的选择原则

药膳用中药与处方用中药有相同处、也有不同处，选择上遵循五条原则：

- **药食两用优先**：首选《既是食品又是中药材的物质目录》内品种，安全、可久服、符合药膳定位。
- **性味平和为贵**：药膳重缓补、忌峻猛，宜选性味平和、毒副作用小的药物；峻猛之品（附子、大黄等）非专业指导不可入膳。
- **辨证对证为准**：再好的药，与证不合就不用。补虚也要看是气虚、血虚、阴虚还是阳虚——第五篇的辨证框架在此落地。
- **道地与品质**：优选道地产区、性状优良、无霉变虫蛀的药材，「药材好，药膳才好」。
- **新鲜适量**：尽量用新鲜、当季之品；用量依第七篇「药量约为汤剂 1/3～1/2」的规则控制。

**重点：** 五条原则的优先级值得反复强调——**先安全（药食两用、性味平和），再对症（辨证选药），后品质（道地新鲜）。** 顺序颠倒，就可能用「很对症但很危险」或「很安全但不对症」的药。

### 1.1 道地药材：一方水土一方药

「道地药材」指在特定产区、用特定生产方式产出、品质与疗效俱佳的药材。道地与否，直接决定药膳疗效与口感。几个耳熟能详的例子：**宁夏枸杞**粒大肉厚、滋补肝肾之效佳；**怀山药**（河南焦作一带所产）健脾益肾，优于其他产区；**甘肃岷县当归**补血活血著称；**云南茯苓**、**广东新会陈皮**亦各领风骚。<span class="marginnote">「道地」观念与现代的「地理标志产品」高度相似：产地的气候、土壤、海拔共同塑造了药材的品质差异。买药膳药材时，认准道地产区标志，是性价比最高的品质把关。</span>

选购道地药材还有一套简便的「四看」：**看性状**（大小、色泽、质地）、**闻气味**（是否纯正）、**尝味道**（是否浓郁）、**观断面**（粉性、油性）。家庭选材不必苛求行家水平，但「四看」能筛掉相当一部分劣品。

## 2 常用药膳中药举要

把最常用的一批药膳中药按功效分组，建立直观印象：

| 功效方向 | 常用药膳中药 |
| --- | --- |
| 补气 | 黄芪、党参、太子参、山药、大枣 |
| 养血 | 当归、桂圆（龙眼肉）、阿胶、枸杞子 |
| 滋阴 | 沙参、麦冬、玉竹、百合、枸杞子 |
| 助阳 | 鹿茸（慎）、杜仲、肉桂、核桃仁 |
| 健脾消食 | 茯苓、薏苡仁、山楂、麦芽、鸡内金 |
| 清热 | 金银花、菊花、薄荷、蒲公英、荷叶 |
| 理气化痰 | 陈皮、桔梗、莱菔子、白芥子 |

这一批约三十味，几乎覆盖了药膳最常用的「主力阵容」。它们在药食同源目录内、性味平和、用途明确——第十五到二十篇的具体方剂，大部分选材都落在这一批里。<span class="marginnote">注意「鹿茸（慎）」的标注：鹿茸虽有补阳之效，但药性温燥、价格昂贵、非人人适宜，入膳须专业指导，一般家庭不主张自行使用。</span>

## 3 核心对比表：十八反

配伍禁忌是药膳选药的安全红线。最经典的禁忌歌诀是「十八反」与「十九畏」。先看**十八反**——两药相反，同用会产生毒害或剧烈反应：

| 相反药对 | 歌诀句 |
| --- | --- |
| 甘草 反 甘遂、大戟、海藻、芫花 | 本草明言十八反，半蒌贝蔹及攻乌 |
| 乌头（川乌、草乌）反 半夏、瓜蒌、贝母、白蔹、白及 | 藻戟遂芫俱战草，诸参辛芍叛藜芦 |
| 藜芦 反 人参、沙参、丹参、玄参、细辛、芍药 | 半蒌贝蔹及攻乌（乌头类） |

**辨析｜易错点：** 十八反最容易被忽视的是「甘草反海藻」——药膳中有人做海带（昆布类）汤时顺手加甘草调味，实属违反「甘草反海藻、昆布」的禁忌。虽然药膳食疗剂量小，争议尚存，但**学习阶段以「宁避勿犯」为原则**，不碰为妙。

## 4 十九畏：相畏之品亦须回避

「十九畏」指十九味药之间存在相互制约、需避免同用的关系。药膳中主要记住与常用食材相关的几组：

| 相畏药对 | 说明 |
| --- | --- |
| 硫黄 畏 朴硝 | 二者相畏，勿同用 |
| 水银 畏 砒霜 | 剧毒之品，药膳中根本不涉 |
| 狼毒 畏 密陀僧 | 毒性药，药膳不涉 |
| 巴豆 畏 牵牛 | 峻下药，药膳不涉 |
| 丁香 畏 郁金 | 药膳偶用，须避 |
| 人参 畏 五灵脂 | 人参常见，五灵脂为活血药，须避 |

**补充：** 十九畏中多数涉及峻猛、毒性之品，本就不属药膳选材范围，实际威胁不大；真正需要日常留意的是**丁香畏郁金、人参畏五灵脂**这两组——它们都可能在药膳或补益方中出现。其余各组记住「药膳根本不碰」即可。

## 5 炮制：从药材到膳材的转化

**炮制（processing）**：依据中医药理论，按临床用药与调剂的需要，对药材进行加工处理的方法总称。炮制的目的是**减毒、增效、改性、矫味、便于贮存与制剂**。<span class="marginnote">炮制的经典目的可概括为「七字诀」：减毒、增效、改性、矫味、便于用。对药膳而言，炮制还多一重意义：<strong>让药材口感更好、更适口</strong>——毕竟药膳首先得「好吃」。</span>

常用炮制方法，按大类分：

- **炒**：清炒（炒黄、炒焦）、加辅料炒（麸炒、土炒）。如炒麦芽增消食之功。
- **炙**：加液体辅料拌炒，如蜜炙（蜜炙黄芪增补气润燥）、醋炙（醋炙香附增强疏肝）。
- **煅**：高温煅烧，使药材质地疏松，如煅龙骨、煅牡蛎。
- **蒸、煮、炖**：水火共制，如蒸制地黄（熟地）由寒转温、补血力增。
- **其他**：发芽、发酵（如神曲）、水飞、制霜等。

## 6 炮制在药膳中的特殊意义

炮制对药膳的意义，比一般处方用药更突出，有三点值得专门强调：

- **减毒保安全**：部分药食两用品含一定毒性成分，炮制可降低之——如苦杏仁炒后减毒，山药生品与炒品（炒山药）健脾止泻之力不同。
- **改味适口性**：药膳「先好吃、后有效」，蜜炙、酒制、醋制等不仅改药性，还改味道——蜜炙后甜润、醋制后微酸，更易入口。
- **性效分档**：同一味药，生用与制用功效不同。如「生麦芽升胃气、炒麦芽消食积」；「生地凉血、熟地补血」。药膳选生品还是制品，取决于治法的需要。

**一句话总结：** 炮制是「把合格药材变成合格膳材」的桥梁。选对药是前提，炮制对是保障——两者都做好了，配伍才谈得上安全有效。

### 6.1 药膳炮制的三个误区

家庭制作药膳时，炮制最容易犯三个错误，逐一辨析：

- **误区一：药膳不需要炮制**。有人认为「药食同源目录内的药都安全，洗洗就能下锅」。实则许多药材生品与制品的性效差异显著（如生地凉血、熟地补血），生品入膳可能偏性过强。
- **误区二：炮制越久越好**。过度炮制会破坏有效成分——如久煮致香气尽失的陈皮、过火焦化的山楂，疗效反降。炮制讲「适度」，不讲「过头」。
- **误区三：凡药皆需蜜炙**。蜜炙只适用于需润肺止咳、补气益中且质地粘腻之品（黄芪、甘草等）；苦寒清泄之品（苦瓜、蒲公英）蜜炙反失本功。**炮制方法要与治法匹配，不能一刀切。**

记住这三点，「炮制」就不会成为家庭药膳的盲区。

## 7 小结

- 选药五原则：**药食两用优先、性味平和为贵、辨证对证为准、道地品质、新鲜适量**；顺序是「先安全、再对症、后品质」。
- 常用药膳中药约三十味，覆盖补气、养血、滋阴、助阳、消食、清热、理气七类。
- **十八反、十九畏**是配伍红线；日常尤须留意「甘草反海藻（昆布）」「丁香畏郁金」「人参畏五灵脂」。
- 炮制七字诀：**减毒、增效、改性、矫味、便于用**。
- 药膳炮制还多一重「适口」意义：生用/制用功效分档，选品要看治法需要。
- 炮制三误区：不需炮制、炮制越久越好、凡药皆需蜜炙——方法须与治法匹配。
