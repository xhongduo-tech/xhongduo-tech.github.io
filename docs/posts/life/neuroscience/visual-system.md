# 视觉系统（视网膜/视通路/视皮层）

## 为什么从视觉开始

在人的所有感觉里，视觉承载的信息量最大——大脑皮层约一半的区域参与视觉加工。它也是最「计算机视觉化」的感觉：从光子到物体识别，每一步都有清晰的算法结构。

理解视觉系统，你等于同时拿到了两把钥匙：一把通向神经科学的「感受野—特征检测—层级表征」范式，另一把通向第四级《计算机视觉》与《深度学习》里卷积网络的生物学源头——Hubel 与 Wiesel 的视觉皮层研究直接启发了 CNN 的局部感受野与层级结构。<span class="marginnote">「CNN 模仿视觉皮层」不是营销话术：Hubel-Wiesel 在 1960 年代发现视皮层存在「简单细胞」（检测朝向）与「复杂细胞」（对位置平移容忍），正是卷积层+池化的原型。视觉系统的研究史，就是深度学习的史前史。</span>

## 1 视网膜：把光子变成神经信号

眼睛的成像层——**视网膜（retina）**，是大脑的「外翻部分」，结构高度分层。关键有三类细胞：

- **感光细胞**：**视杆细胞（rod）** 负责暗视觉（对单光子敏感、无颜色、分辨率低），**视锥细胞（cone）** 负责明视觉与色觉（分 L、M、S 三种，分别对红、绿、蓝光敏感，集中在中央凹）。<span class="marginnote">视杆细胞能响应单个光子——这是生物灵敏度极限；但它会饱和，所以白天几乎不工作。视锥细胞少得多（约 600 万 vs 视杆 1.2 亿），却集中在中央凹提供高分辨率。这与相机「高灵敏低分辨率 vs 高分辨率低灵敏」两种模式的分工如出一辙。</span>
- **双极细胞（bipolar cell）**：把感光细胞的信号传给神经节细胞，是「中间层」。
- **神经节细胞（ganglion cell）**：视网膜的**输出神经元**，轴突汇成视神经。它的感受野是**同心圆式**：中央 ON（光增时兴奋）或中央 OFF（光减时兴奋），周围相反——这是侧抑制的直接体现。

**关键机制**：感光细胞在**暗处持续去极、释放谷氨酸**，光照后超极化、释放减少。光信号经过感光→双极→神经节三层，从「分级电位」变成神经节细胞的动作电位序列。

视网膜不是简单「转照片」，它已经在做**边缘增强、颜色对立、亮度适应**等预处理。

换句话说，视网膜是一个「边缘/对比检测器」而非「像素拷贝机」——它提取的信息早已超出原始光强，这也是「视觉是建构」的最早证据。

## 2 视通路：两眼的信号如何合并

视神经的纤维在**视交叉（optic chiasm）** 处部分交叉：来自**鼻侧视网膜**的纤维交叉到对侧，**颞侧视网膜**的纤维不交叉。结果是**左侧视野的信息全部进入右半脑**，反之亦然。<span class="marginnote">视野（被看到的外部世界）与视网膜（眼睛内部）是左右镜像关系。记住「左视野→右半球」这一句，就理解了视交叉的布局，也解释了特定部位损伤导致的视野缺损类型（同名性偏盲等）。</span>

信号路径：视网膜→视交叉→**外侧膝状体（LGN，丘脑）**→初级视皮层（V1，纹状皮层）→更高层级。

LGN 仍是「中继+门控」：它接受来自视觉皮层与脑干的下行纤维，根据注意状态选择放行哪些信号。

LGN 还接收**视觉运动与节律相关输入**——它把「是什么时间、在什么背景下看到」的信息也纳入放行判断，视觉从来不是「裸数据」输入。

### 视野缺损的一课

不同部位损伤产生不同视野缺损，是定位诊断的经典工具：

- 左视神经损伤 → 左眼全盲。
- 视交叉中部损伤 → 双眼颞侧偏盲（鼻侧纤维受损）。
- 左侧视束/视辐射损伤 → 右侧同名性偏盲（右眼颞侧 + 左眼鼻侧）。

## 3 视皮层：感受野的层级建构

V1 是皮层视觉的入口，Hubel-Wiesel 在这里发现了**朝向选择性**：

- **简单细胞（simple cell）**：感受野是**条状**的，对特定朝向的亮暗边界/条带反应，有明确的 ON/OFF 子区域——相当于「边缘检测器」。
- **复杂细胞（complex cell）**：对同一朝向的边缘反应，但**不苛求位置**（有一定平移容忍）——相当于「边缘加位置不变性」。
- 简单细胞汇聚成复杂细胞，复杂细胞再汇聚成更高级的**超复杂细胞（hypercomplex）**，感受野越来越大、对特征的要求越来越抽象。

从 V1 出发，视觉分两条并行通路：**腹侧通路（what 通路）** 走向颞叶，识别「是什么」（物体、面孔）；**背侧通路（where/行动通路）** 走向顶叶，定位「在哪里」并支持空间引导的动作。<span class="marginnote">腹侧/背侧的分离有经典证据：颞叶损伤患者能看见物体却认不出（视觉失认症）；顶叶损伤患者能认出物体却够不准确（视空间障碍）。「是什么」与「在哪里」由不同硬件负责——这在大模型多模态里也对应「语义识别」与「空间关系」两套能力。</span>

## 4 公式解析：感受野的同心圆模型

视网膜神经节细胞的感受野可用**高斯差（difference of Gaussians, DoG）** 模型近似。对中央 ON、周围 OFF 的细胞，其响应权重为：

$$
w(r) = A_c\,e^{-r^2/2\sigma_c^2} - A_s\,e^{-r^2/2\sigma_s^2}
$$

- **$r$**：距感受野中心的距离。
- **第一项（中央）**：中心高斯，幅度 $A_c$、宽度 $\sigma_c$，取正号——中央光增→兴奋。
- **第二项（周围）**：外周高斯，幅度 $A_s$、宽度 $\sigma_s$（更大），取负号——周围光增→抑制。
- **净效果**：均匀照明时中央与周围抵消，细胞几乎不反应；只有**明暗对比**跨越边界时才强烈反应——这就是「视觉系统传对比、不传绝对值」的定量刻画。<span class="marginnote">DoG 模型与图像处理的拉普拉斯算子、以及 CNN 里 learnable 的卷积核本质同源：都是在空间上做「中心—周围」的差分。生物视觉用硬接线实现，人工视觉用学习得到，但数学结构殊途同归。</span>

## 5 核心对比表：视杆 vs 视锥

| 维度 | 视杆细胞 | 视锥细胞 |
| --- | --- | --- |
| 数量 | 约 1.2 亿 | 约 600 万 |
| 分布 | 视网膜周边 | 中央凹最密 |
| 光敏度 | 高（单光子） | 低 |
| 色觉 | 无（单种视色素） | 有（L/M/S 三种） |
| 空间分辨率 | 低 | 高 |
| 暗适应 | 强 | 弱 |

**辨析｜易错点：** 「暗处靠视杆、亮处靠视锥」容易记成「感光细胞在暗处不工作」。

正确说法是：感光细胞**暗处活跃**（持续释放递质），光越强越超极化；「视杆负责暗视觉」指的是它**负责暗光下的视知觉**，而不是「暗处才工作」。

夜盲源于视杆的视紫红质合成受阻，黄昏时视锥已失灵、视杆又供不上，即「中间视觉」的尴尬地带。

色觉的另一面：**色盲/色弱**多为 L/M 视锥色素基因异常（红绿色觉障碍），X 连锁遗传、男性多见——这是「视锥分工」在人群中的自然变异。

## 6 延展：视觉层级与深度网络的同构

视觉系统的「简单→复杂→超复杂→语义」层级，与 CNN 的「边缘→纹理→部件→物体」层级高度同构：

- **局部感受野**：V1 细胞只对局部图像敏感——卷积核的局部性。
- **层级汇聚**：低层特征汇聚成高层特征——卷积层逐层抽象。
- **不变性**：复杂细胞的平移容忍——池化/平移等变的对应物。
- **自上而下**：皮层反馈对应注意力/上下文调制。

**辨析｜易错点：** 视觉皮层不是「单向前馈」——反馈连接几乎与前馈等量。深度网络若只做前馈，就缺了大脑「用预期解释输入」的一半。现代视觉大模型正在加入这种「反馈/上下文」机制。

同样地，「感受野」在人脑里不是固定的：注意可以**动态缩小感受野**（聚焦细处），预期可以改变响应增益——感受野是「可调谐的」，这与固定卷积核很不一样。<span class="marginnote">「深度网络≈视觉皮层」是启发式类比，不是严格对应：皮层还有侧抑制、振荡、神经调质、局部计算等网络没有的结构。但「层级特征提取」这一核心组织原则，确实是生物视觉给深度学习最重要的礼物——这也是「从极限到大模型」主线中「生物→算法」的一条关键输血通道。</span>

## 7 小结

- 视网膜三层把光子变为神经信号：**感光细胞（视杆/视锥）→双极细胞→神经节细胞**，并已做对比增强预处理。
- 视神经在**视交叉**部分交叉，左视野信息进入右半球。
- V1 的**简单细胞/复杂细胞**层级检测朝向与位置不变特征，是 CNN 的生物原型。
- 视觉分**腹侧（what）** 与**背侧（where）** 两条并行通路。
- 视网膜本身已是「对比检测器」，在传入皮层前就完成边缘增强。
- 神经节细胞感受野用 **DoG（高斯差）** 模型刻画，核心是「传对比、不传绝对值」。
- 视觉层级组织与 CNN 同构，但皮层还含反馈与侧抑制等深度网络缺少的结构。
- 感受野是「可调谐的」，注意与预期能动态改变其大小与增益。

在下一节，我们切换一个完全不同编码策略的感觉——**听觉系统**。如果说视觉靠「空间上的感受野」，听觉则靠「时间上的频率分解」，耳朵把声波变成音调地图。
