## 为什么从系统性硬化症开始

前几篇的终点都是「炎症」；**系统性硬化症（systemic sclerosis，SSc）**把终点换成了**纤维化（fibrosis）**——组织被结缔组织「结疤」取代。这是一条从微血管损伤、经免疫异常、最终走向成纤维细胞失控的流水线，也是理解「免疫病如何变成器官硬化」的最佳标本。<span class="marginnote">「硬化症」（scleroderma）一词源自希腊语 *skleros\*（硬）+ *derma\*（皮肤），1842 年被首次描述时只被当作「皮肤变硬的怪病」。今天我们知道它可能以皮肤为主（局限型）或累及全身（弥漫型）——「系统性」三个字是几代临床观察换来的。</span>

SSc 是风湿病里**预后分化最大**的病之一：局限皮肤型患者可平稳生活数十年，而弥漫型伴内脏受累者中位生存显著缩短，死亡主要来自**间质性肺病（ILD）**与**肺动脉高压（PAH）**。女性:男性约 3–5:1，发病高峰 30–50 岁。

## 1 发病机制：血管损伤 → 免疫激活 → 纤维化

SSc 的三部曲已被反复确认，顺序大致是：

**第一步，微血管损伤**：血管内皮细胞受损、凋亡，毛细血管密度下降。这解释了最早期且几乎人人皆有的症状——**雷诺现象（Raynaud phenomenon）**：手指遇冷或情绪激动时血管痉挛，变白→变紫→变红三色变化。<span class="marginnote">雷诺现象是 SSc 的「哨兵症状」：约 95% 的 SSc 患者以此起病，往往早于皮肤变硬数年。但雷诺现象绝大多数是良性的「原发性雷诺」（年轻女性、无组织损伤），只有伴随指端溃疡、甲襞毛细血管异常、自身抗体时才警惕「继发性」——见下文鉴别表。</span>

**第二步，免疫激活**：T 细胞、B 细胞活化，产生特征性自身抗体：**抗 Scl-70（抗拓扑异构酶 I）**见于弥漫型，**抗着丝点抗体（ACA）**见于局限型，**抗 RNA 聚合酶 III**与肾危象、肿瘤相关。抗体谱与临床亚型高度相关，是分型的「分子标签」。

**第三步，成纤维细胞失控**：TGF-β、PDGF 等细胞因子驱动成纤维细胞活化，转化为**肌成纤维细胞（myofibroblast）**，过量合成 I 型胶原并减少降解——胶原堆积，器官「结疤」。<span class="marginnote">纤维化是「伤口愈合程序的永动化」：正常的伤口愈合是「炎症→修复→停止」，SSc 里「停止」信号失效，修复程序无限运行。这个视角把 SSc 从「罕见病」提升为一个普遍原理的极端版——器官修复失调，也是心血管、肝、肾慢性病的共同终局。</span>

## 2 临床分型与内脏受累

SSc 按皮肤受累范围分两大临床亚型，预后差异显著：

| 特征 | 局限皮肤型（lcSSc） | 弥漫皮肤型（dcSSc） |
| --- | --- | --- |
| 皮肤受累 | 肘/膝以下 | 躯干 + 四肢近端 |
| 特征抗体 | 抗着丝点（ACA） | 抗 Scl-70（拓扑异构酶 I） |
| 雷诺 | 早期、突出 | 可后发 |
| 内脏风险 | **肺动脉高压**更突出 | **ILD、肾危象**更突出 |
| 预后 | 较平缓 | 更快进展 |

内脏受累是 SSc 的死神所在，三件事必须盯紧：

**间质性肺病（ILD）**：弥漫型最常见死因，肺底网状影、肺功能限制性通气障碍。**肺功能检查 + HRCT**是常规随访。
- **肺动脉高压（PAH）**：血管增殖导致肺血管阻力升高，右心衰。**超声心动图估肺动脉压**定期筛查，确诊靠右心导管。
- **硬皮病肾危象（SRC）**：急进性恶性高血压 + 急性肾衰竭，是 SSc 的急症。**治疗要点：一旦血压骤升，立即用 ACE 抑制剂（卡托普利）**——这是 SSc 治疗中少有的「保命药」。

**消化道受累同样常见但常被低估**：食管下括约肌功能不全导致**胃食管反流**与吞咽困难，胃排空延迟，小肠细菌过度生长可致吸收不良——约 90% 的 SSc 患者有消化道受累。局限型的经典集合常被记为 **CREST 综合征**：钙质沉着（Calcinosis）、雷诺（Raynaud）、食管受累（Esophageal）、指端硬化（Sclerodactyly）、毛细血管扩张（Telangiectasia）——它是 lcSSc 的一个描述性别名，不是独立疾病。<span class="marginnote">「CREST 五个字母好记」，但要警惕它只是「局部皮肤型」的拼图之一：CREST 患者同样可能发生 PAH（若忽略则致命）。缩略词是记忆工具，不是安全保证——诊断时仍要按「内脏是否受累」重新评估，而不仅是套 CREST 标签。</span>消化道管理的核心是 PPI 抑酸 + 生活方式调整 + 营养支持，别让它静悄悄地造成营养不良。

**消化道管理的「工具箱」值得展开**：**PPI（质子泵抑制剂）**是食管反流的一线，常需长期维持（SSc 的食管蠕动减弱不可逆）；吞咽困难明显者需**少食多餐 + 抬高床头**；胃排空延迟用促动力药；小肠细菌过度生长（SIBO，表现为腹胀、腹泻、吸收不良）用轮换的肠道抗生素；营养状况差者评估**肠内营养甚至肠外营养**。消化道受累对生活质量的影响常被皮肤变硬「抢戏」而忽视，但它实实在在决定患者能否吃好、长胖、维持体力——**把消化道管理放进 SSc 的核心治疗清单**，是「全器官管理」而非「只看皮肤」的重要一步。<span class="marginnote">「SSc 患者体重下降」常被误当「正常老化」，其实多半是消化道受累的信号：反流、吞咽困难、SIBO 都在「偷走」营养。定期称体重、问进食，是与「抗纤维化」同等重要的基础管理——大病管理里，最朴素的生命体征往往最说明问题。</span>

**辨析｜易错点：** **原发性 vs 继发性雷诺**是门诊最常见的判别题。原发性：年轻女性、无组织损伤、抗核抗体阴性、甲襞毛细血管正常、对称发作；继发性（尤其 SSc）：年龄更大、有指端溃疡/凹陷瘢痕、抗体阳性、甲襞毛细血管扩张缺失。<span class="marginnote">甲襞毛细血管镜是一个「免费神器」：把指甲根部皮肤滴一滴油、在放大镜下看毛细血管形态。SSc 患者可见毛细血管扩大、缺失、无血管区——一个低成本床边检查就能把原发性雷诺和 SSc 拉开差距。</span>

## 3 诊断：2013 年 ACR/EULAR 分类标准

2013 年标准按加权计分 ≥9 分分类：

| 条目 | 权重 |
| --- | --- |
| 双手指皮肤增厚超过 MCP（足够确诊：9 分） | 9 |
| 手指皮肤硬化（远端到 MCP） | 4 |
| 指端病变（溃疡 / 凹陷性瘢痕） | 2–3 |
| 毛细血管异常 | 2 |
| 雷诺现象 | 3 |
| 甲襞毛细血管镜异常 | 2 |
| 肺动脉高压 / ILD | 2 |
| 相关抗体（抗着丝点/抗 Scl-70/抗 RNA Pol III） | 3 |

结构特点：**「手指皮肤增厚超过 MCP 关节」本身即达 9 分、单独可确诊**——因为这是 SSc 最具特征、最不易混淆的表现；其余条目按特异度赋权。<span class="marginnote">这个「单一条目即可确诊」的结构在风湿病分类标准里很罕见，因为它指向的临床表现特异性极高。对比 SLE 2019 标准要求「临床 + 免疫学」多域凑分——不同病的分类标准结构差异，本身就是对疾病特征的压缩编码。</span>

## 4 治疗：纤维化难逆转，重在「防与守」

SSc 治疗的首要原则是现实主义的：**已经形成的纤维化很难逆转，因此治疗的战场前移**——控制血管事件、抑制炎症、监测器官、延缓纤维化。

**血管系统**：雷诺与指端溃疡用钙通道阻滞剂（硝苯地平）、静脉用前列环素（伊洛前列素）、内皮素受体拮抗剂（波生坦）预防新溃疡；PAH 用内皮素拮抗剂、磷酸二酯酶-5 抑制剂、前列环素类似物。

**雷诺的非药物管理是「第一线治疗」**：防寒保暖（手套、暖手宝、避免接触冷水与冷食）、戒烟（尼古丁收缩血管）、避免精神紧张、避免长时间暴露于低温环境。**吸烟是 SSc 血管病的重要加重因素**——烟草不仅加重雷诺，还增加指端溃疡与 PAH 风险，戒烟是 SSc 患者「成本最低、获益最确定」的干预之一。钙通道阻滞剂（硝苯地平缓释）是雷诺的一线药物，可减少发作频率与严重度；反复指端溃疡或 PAH 者则升级到内皮素拮抗剂/前列环素类。<span class="marginnote">「保暖 + 戒烟 + 扩血管药」三件套构成 SSc 血管管理的基底。雷诺虽然「只是手指变白变紫」，但它是指向系统性血管病变的「窗口」——管好它，就是在管 SSc 的整体血管健康。这也是为什么「关注小症状」常常就是「预防大并发症」。</span>

**指端溃疡（digital ulcers）值得单独强调**：它是 SSc 最常见的「血管事件」之一，疼痛剧烈、愈合缓慢、易继发感染，反复发作可致指端坏死甚至截指。管理要点：**预防为主**（内皮素受体拮抗剂如波生坦被证实能减少新溃疡）、**处理促发因素**（保暖、戒烟、避免外伤）、**局部护理**（清创、防感染、缓痛）与**升级治疗**（前列环素类静脉/口服用于难治或活动性溃疡）。对反复溃疡者，还需评估是否并存「指端钙质沉着」（见下）——把「每一个手指头」当成 SSc 血管健康的晴雨表，是血管管理落到实处的关键。

**钙质沉着（calcinosis）的处理是「经验多于证据」**：皮下钙化结节可疼痛、破溃、继发感染，目前**没有特效溶解药**；处理以对症为主——钙通道阻滞剂/秋水仙碱等效果有限，难治者可考虑外科切除、冲击波或激光治疗。对患者而言，钙质沉着是「看得见的病」：它让 SSc 的「隐蔽内脏受累」多了一个「皮肤上的实锤」，也提醒我们要把它纳入生活质量评估。<span class="marginnote">SSc 的「钙化、溃疡、毛细血管扩张」这些皮肤表现，不只是美观问题——它们是血管病变与纤维化的「体表投影」。皮肤科与风湿科对同一批皮损的观察视角不同，联合评估才能既治「表」又治「里」。</span>

**SSc 的「患者教育」是长期管理的粘合剂**：因为 SSc 是「慢性、进展但可控」的病，患者需要学会——**识别雷诺的触发并主动保暖、每日自测血压（防肾危象）、戒烟、坚持随访肺功能与超声、理解「纤维化不可逆所以重在防」**。患者越了解自己的病，越能配合「防」的哲学而非追求「治」的奇迹。把「你该注意什么、多久复查一次、什么信号要急诊」写进患者手册，比任何单次医嘱都更有力量——**慢病管理的本质，是教会患者与疾病长期共处**。

**SSc 的预后分层与「希望」**：局限型患者的中位生存显著长于弥漫型；即使弥漫型，随着 ILD 治疗（MMF/尼达尼布）与 PAH 治疗（内皮素拮抗剂等）的进步，预后也在持续改善。**「SSc 曾经是预后最差的结缔组织病之一，如今却是治疗进展最活跃的领域之一」**——把「可治性在提高」的实情告诉患者，既诚实又给希望，是医患信任的基础。这也是 SSc 治疗从「束手无策」走向「分类分层、主动监测、靶向干预」的现代叙事：纤维化难逆转，但「防」可以改写结局。

**SSc 收束了本专题的「纤维化」主线**：从免疫耐受失守、到血管损伤、到成纤维细胞失控，SSc 把「炎症如何变成结疤」这条路径走得最彻底。读懂 SSc，就理解了纤维化作为「多种慢性病共同终局」的普遍意义——这不仅是风湿病学的问题，也是理解「组织修复失控」这一现代医学大主题的钥匙。
- **免疫抑制**：MTX 用于早期皮肤与关节炎；吗替麦考酚酯（MMF）对早期 ILD 可延缓肺功能下降；环磷酰胺用于进展性 ILD。<span class="marginnote">值得注意的是：SSc 的免疫抑制靶点是「早期炎症」，而纤维化晚期免疫抑制无效——「免疫药打炎症期、血管药守血管期、纤维化只能监测」。这再次印证治疗时序 = 病理分期。</span>
**抗纤维化新药**：**尼达尼布（nintedanib）**（酪氨酸激酶抑制剂）已被批准用于 SSc-ILD，延缓肺功能下降——首个在 SSc 中获批的抗纤维化靶向药，标志着 SSc 治疗从「免疫抑制」扩展到「直接抗纤维化」。<span class="marginnote">尼达尼布原本是特发性肺纤维化（IPF）的药物——同一个「纤维化程序」在不同病种间共享靶点，是「跨病种靶向」的典范，也让 SSc 与呼吸科的对话空前密切。</span>
- **肾危象急救**：血压骤升即用 ACE 抑制剂，长期维持；必要时透析。

**SSc 的随访是「制度化」的**：因为内脏受累可以静默进展，指南建议**每 3–6 个月**复查肺功能（FVC/DLCO）、每年行 HRCT 与超声心动图估肺动脉压、监测血压与尿蛋白（筛肾危象）、评估消化道症状与营养。随访的意义在于「抢在器官损伤不可逆之前发现」：**FVC 下降 10% 就应启动 ILD 评估与干预**——数值化的随访阈值，让「病情进展」不再是模糊感觉。<span class="marginnote">SSc 是「随访密度决定预后」的典型病：同样的治疗，监测到位的患者能更早换药、更早识别 PAH/SRC。慢性病管理里「监测本身就是治疗的一部分」——这句话在 SSc 里近乎字面成立。</span>妊娠期 SSc 需谨慎（SRC 与 PAH 风险升高），孕前应完成心肺评估。

**肾危象的急救细节值得单独强调**：SRC 的处理原则是「**一旦怀疑，立刻上 ACE 抑制剂，等血压数据与诊断齐备就晚了**」——临床用短效卡托普利，起始 12.5–25 mg 每 8 小时，随后根据血压滴定，**即使肾功能已恶化也不应轻易停药**（停药是 SRC 死亡的主要可纠正因素之一）。同时注意：**糖皮质激素（尤其泼尼松 >15 mg/d）与 SRC 风险升高相关**，弥漫型患者大剂量激素使用需格外谨慎。<span class="marginnote">这是风湿科「用药矛盾」的又一例：别的病用激素是主药，SSc 里激素反而可能「点火」肾危象。临床决策永远要放进疾病亚型与病理阶段这个坐标系里看——同一句话（「用激素」）在不同病里含义完全相反。</span>SRC 高危者应教育患者每日自测血压，把「血压骤升」的警报前置到居家。

## 6 小结

- SSc 发病三部曲：**微血管损伤 → 免疫激活 → 成纤维细胞失控/纤维化**；雷诺现象是 95% 患者的哨兵症状。
- 两大临床亚型：**局限型**（ACA、PAH 突出）vs **弥漫型**（抗 Scl-70、ILD/肾危象突出），抗体是分子标签。
- 内脏三大死点：**ILD、PAH、硬皮病肾危象（SRC）**；SRC 用 **ACE 抑制剂** 保命。
- 诊断用 **2013 ACR/EULAR 标准**：手指硬化超 MCP 单条即确诊。
- 治疗原则：**纤维化难逆转，战场前移**——血管药守血管、免疫药打炎症、尼达尼布直接抗纤维化、肾危象抢时间。

在下一节，我们把视野从「结疤」转向「血管壁被攻击」——一组以血管壁炎症为共同分母的疾病群：**血管炎**。
