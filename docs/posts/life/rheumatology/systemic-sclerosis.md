## 为什么从系统性硬化症开始

前几篇的终点都是「炎症」；**系统性硬化症（systemic sclerosis，SSc）**把终点换成了**纤维化（fibrosis）**——组织被结缔组织「结疤」取代。这是一条从微血管损伤、经免疫异常、最终走向成纤维细胞失控的流水线，也是理解「免疫病如何变成器官硬化」的最佳标本。<span class="marginnote">「硬化症」（scleroderma）一词源自希腊语 *skleros\*（硬）+ *derma\*（皮肤），1842 年被首次描述时只被当作「皮肤变硬的怪病」。今天我们知道它可能以皮肤为主（局限型）或累及全身（弥漫型）——「系统性」三个字是几代临床观察换来的。</span>

SSc 是风湿病里**预后分化最大**的病之一：局限皮肤型患者可平稳生活数十年，而弥漫型伴内脏受累者中位生存显著缩短，死亡主要来自**间质性肺病（ILD）**与**肺动脉高压（PAH）**。女性:男性约 3–5:1，发病高峰 30–50 岁。

## 1 发病机制：血管损伤 → 免疫激活 → 纤维化

SSc 的三部曲已被反复确认，顺序大致是：

**第一步，微血管损伤**：血管内皮细胞受损、凋亡，毛细血管密度下降。这解释了最早期且几乎人人皆有的症状——**雷诺现象（Raynaud phenomenon）**：手指遇冷或情绪激动时血管痉挛，变白→变紫→变红三色变化。<span class="marginnote">雷诺现象是 SSc 的「哨兵症状」：约 95% 的 SSc 患者以此起病，往往早于皮肤变硬数年。但雷诺现象绝大多数是良性的「原发性雷诺」（年轻女性、无组织损伤），只有伴随指端溃疡、甲襞毛细血管异常、自身抗体时才警惕「继发性」——见下文鉴别表。</span>

**第二步，免疫激活**：T 细胞、B 细胞活化，产生特征性自身抗体：**抗 Scl-70（抗拓扑异构酶 I）**见于弥漫型，**抗着丝点抗体（ACA）**见于局限型，**抗 RNA 聚合酶 III**与肾危象、肿瘤相关。抗体谱与临床亚型高度相关，是分型的「分子标签」。

**第三步，成纤维细胞失控**：TGF-β、PDGF 等细胞因子驱动成纤维细胞活化，转化为**肌成纤维细胞（myofibroblast）**，过量合成 I 型胶原并减少降解——胶原堆积，器官「结疤」。<span class="marginnote">纤维化是「伤口愈合程序的永动化」：正常的伤口愈合是「炎症→修复→停止」，SSc 里「停止」信号失效，修复程序无限运行。这个视角把 SSc 从「罕见病」提升为一个普遍原理的极端版——器官修复失调，也是心血管、肝、肾慢性病的共同终局。</span>

## 2 临床分型与内脏受累

SSc 按皮肤受累范围分两大临床亚型，预后差异显著：

| 特征 | 局限皮肤型（lcSSc） | 弥漫皮肤型（dcSSc） |
| --- | --- | --- |
| 皮肤受累 | 肘/膝以下 | 躯干 + 四肢近端 |
| 特征抗体 | 抗着丝点（ACA） | 抗 Scl-70（拓扑异构酶 I） |
| 雷诺 | 早期、突出 | 可后发 |
| 内脏风险 | **肺动脉高压**更突出 | **ILD、肾危象**更突出 |
| 预后 | 较平缓 | 更快进展 |

内脏受累是 SSc 的死神所在，三件事必须盯紧：

**间质性肺病（ILD）**：弥漫型最常见死因，肺底网状影、肺功能限制性通气障碍。**肺功能检查 + HRCT**是常规随访。
- **肺动脉高压（PAH）**：血管增殖导致肺血管阻力升高，右心衰。**超声心动图估肺动脉压**定期筛查，确诊靠右心导管。
- **硬皮病肾危象（SRC）**：急进性恶性高血压 + 急性肾衰竭，是 SSc 的急症。**治疗要点：一旦血压骤升，立即用 ACE 抑制剂（卡托普利）**——这是 SSc 治疗中少有的「保命药」。

**辨析｜易错点：** **原发性 vs 继发性雷诺**是门诊最常见的判别题。原发性：年轻女性、无组织损伤、抗核抗体阴性、甲襞毛细血管正常、对称发作；继发性（尤其 SSc）：年龄更大、有指端溃疡/凹陷瘢痕、抗体阳性、甲襞毛细血管扩张缺失。<span class="marginnote">甲襞毛细血管镜是一个「免费神器」：把指甲根部皮肤滴一滴油、在放大镜下看毛细血管形态。SSc 患者可见毛细血管扩大、缺失、无血管区——一个低成本床边检查就能把原发性雷诺和 SSc 拉开差距。</span>

## 3 诊断：2013 年 ACR/EULAR 分类标准

2013 年标准按加权计分 ≥9 分分类：

| 条目 | 权重 |
| --- | --- |
| 双手指皮肤增厚超过 MCP（足够确诊：9 分） | 9 |
| 手指皮肤硬化（远端到 MCP） | 4 |
| 指端病变（溃疡 / 凹陷性瘢痕） | 2–3 |
| 毛细血管异常 | 2 |
| 雷诺现象 | 3 |
| 甲襞毛细血管镜异常 | 2 |
| 肺动脉高压 / ILD | 2 |
| 相关抗体（抗着丝点/抗 Scl-70/抗 RNA Pol III） | 3 |

结构特点：**「手指皮肤增厚超过 MCP 关节」本身即达 9 分、单独可确诊**——因为这是 SSc 最具特征、最不易混淆的表现；其余条目按特异度赋权。<span class="marginnote">这个「单一条目即可确诊」的结构在风湿病分类标准里很罕见，因为它指向的临床表现特异性极高。对比 SLE 2019 标准要求「临床 + 免疫学」多域凑分——不同病的分类标准结构差异，本身就是对疾病特征的压缩编码。</span>

## 4 治疗：纤维化难逆转，重在「防与守」

SSc 治疗的首要原则是现实主义的：**已经形成的纤维化很难逆转，因此治疗的战场前移**——控制血管事件、抑制炎症、监测器官、延缓纤维化。

**血管系统**：雷诺与指端溃疡用钙通道阻滞剂（硝苯地平）、静脉用前列环素（伊洛前列素）、内皮素受体拮抗剂（波生坦）预防新溃疡；PAH 用内皮素拮抗剂、磷酸二酯酶-5 抑制剂、前列环素类似物。
- **免疫抑制**：MTX 用于早期皮肤与关节炎；吗替麦考酚酯（MMF）对早期 ILD 可延缓肺功能下降；环磷酰胺用于进展性 ILD。<span class="marginnote">值得注意的是：SSc 的免疫抑制靶点是「早期炎症」，而纤维化晚期免疫抑制无效——「免疫药打炎症期、血管药守血管期、纤维化只能监测」。这再次印证治疗时序 = 病理分期。</span>
**抗纤维化新药**：**尼达尼布（nintedanib）**（酪氨酸激酶抑制剂）已被批准用于 SSc-ILD，延缓肺功能下降——首个在 SSc 中获批的抗纤维化靶向药，标志着 SSc 治疗从「免疫抑制」扩展到「直接抗纤维化」。<span class="marginnote">尼达尼布原本是特发性肺纤维化（IPF）的药物——同一个「纤维化程序」在不同病种间共享靶点，是「跨病种靶向」的典范，也让 SSc 与呼吸科的对话空前密切。</span>
- **肾危象急救**：血压骤升即用 ACE 抑制剂，长期维持；必要时透析。

## 5 小结

- SSc 发病三部曲：**微血管损伤 → 免疫激活 → 成纤维细胞失控/纤维化**；雷诺现象是 95% 患者的哨兵症状。
- 两大临床亚型：**局限型**（ACA、PAH 突出）vs **弥漫型**（抗 Scl-70、ILD/肾危象突出），抗体是分子标签。
- 内脏三大死点：**ILD、PAH、硬皮病肾危象（SRC）**；SRC 用 **ACE 抑制剂** 保命。
- 诊断用 **2013 ACR/EULAR 标准**：手指硬化超 MCP 单条即确诊。
- 治疗原则：**纤维化难逆转，战场前移**——血管药守血管、免疫药打炎症、尼达尼布直接抗纤维化、肾危象抢时间。

在下一节，我们把视野从「结疤」转向「血管壁被攻击」——一组以血管壁炎症为共同分母的疾病群：**血管炎**。
