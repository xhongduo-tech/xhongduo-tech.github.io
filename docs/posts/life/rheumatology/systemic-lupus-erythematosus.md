## 为什么从系统性红斑狼疮开始

如果说类风湿关节炎是「关节炎为主」的器官特异型自身免疫病，**系统性红斑狼疮（systemic lupus erythematosus，SLE）**则是「全器官型」：从皮肤、关节到肾脏、中枢神经系统，几乎无处不可侵犯。SLE 的核心免疫学特征是**免疫复合物 + 补体**的 III 型损伤，直接对应第一篇里那套 III 型超敏机制。它还是自身抗体谱最丰富的病种——ANA、抗 dsDNA、抗 Sm、抗 Ro/SSA、抗 La/SSB、抗磷脂抗体……理解 SLE，等于练习「把抗体检索引图」的能力。

SLE 流行病学特征鲜明：90% 为女性，育龄期高发，非裔、亚裔患病率高于白人。<span class="marginnote">性激素是 SLE 的重要驱动：雌激素能增强 B 细胞活化和自身抗体产生。女性高发 + 育龄期发病高峰 + 妊娠加重，构成 SLE 临床学的核心线索之一（见第12篇《儿童风湿病与妊娠期风湿病》）。</span>这病名来自 19 世纪皮肤科医生对「蝴蝶样面颊红斑」的观察——拉丁语 *lupus\*（狼），因其斑块状皮损状似狼咬。

## 1 发病机制：免疫复合物的「海啸」

SLE 的起点是**耐受失守 + 凋亡碎片清除障碍**：凋亡细胞释放的核抗原（DNA、核小体、RNA 结合蛋白）本应被清道夫细胞迅速清除，SLE 患者普遍存在清除缺陷，于是核抗原持续暴露，驱动**抗核抗体（ANA）**产生。<span class="marginnote">这是「垃圾清运失灵」模型：凋亡碎片是免疫原性极强的「核废物」，清运不及时，免疫系统就把它当「入侵者」处理。补体早期成分（C1q、C4）本身参与凋亡碎片清除——这解释了一个反常现象：SLE 患者的补体是「低的」，因为大量补体被消耗在清除战场上了。</span>

ANA 结合核抗原形成免疫复合物，沉积于肾小球、皮肤、血管壁等处，激活补体、招募中性粒细胞，产生 III 型损伤。中性粒细胞还会释放 **中性粒细胞胞外陷阱（NET）**，其内含的双链 DNA 又成为抗 dsDNA 的靶——形成「NET 生成 → 自身抗体 → 更多 NET」的恶性循环。<span class="marginnote">NET 是中性粒细胞「自杀式」排出的网状结构，本是困住细菌的陷阱，在 SLE 里却成了自身抗原的弹药库。近年研究还发现紫外线可诱导角质细胞 NET 样死亡——这从分子层面解释了 SLE 的经典现象：光敏感。</span>

两条关键的临床推论，直接指导随访策略：

**抗 dsDNA 滴度随疾病活动（尤其肾活动）起伏**——是随访的「晴雨表」，活动期升高、缓解期回落。
- **补体 C3/C4 下降提示活动**——补体被免疫复合物持续消耗，下降本身就是「战场消耗」的信号。

## 2 临床表现：多器官的「点状分布」

SLE 的症状是「同病不同貌」的典范，几乎每个患者的表现都不一样，但有几个高频区块：

- **皮肤黏膜**：蝶形红斑（颧部跨越鼻梁的红斑）、盘状红斑（瘢痕性）、光敏感、口腔溃疡、脱发。
- **关节肌肉**：非侵蚀性、非畸形性多关节炎——这是与 RA 的关键鉴别点（RA 会侵蚀骨，SLE 的关节炎不破坏关节）。
- **肾脏**：**狼疮肾炎（lupus nephritis）**是 SLE 最重要的脏器受累与死亡原因之一，从无症状血尿到肾病综合征、肾功能衰竭。
- **血液**：白细胞减少、溶血性贫血、血小板减少、淋巴减少。
- **神经精神**：癫痫、精神病、卒中、认知障碍（NP-SLE）。
- **浆膜**：胸膜炎、心包炎（积液）。

**辨析｜易错点：** 蝶形红斑必须与**玫瑰痤疮**、**接触性皮炎**鉴别；而 SLE 的关节炎是「痛而耐受、不侵蚀、不畸形」——把它当成 RA 去用生物制剂，方向就错了。**同一位病人的抗核抗体（ANA）是诊断的入场券，但 ANA 阴性也不能完全排除 SLE**（抗 Ro/SSA 阳性的 ANA 阴性狼疮约占 5%）。

### 2.1 从「狼咬样皮损」到系统性自身免疫病

「狼疮」（lupus）之名来自 13 世纪外科医生 Rogerius 的观察：患者面颊的盘状皮损形似被狼咬过的痕迹。19 世纪皮肤科医生 Cazenave 首次用「红斑狼疮」描述红斑性皮损，而「系统性」三字要等到 20 世纪中叶：1948 年 Hargraves 发现 **LE 细胞**（吞噬了自身抗体调理过的细胞核的中性粒细胞），1957 年 **抗 dsDNA 抗体**被发现，1960–70 年代 **ANA 免疫荧光检测**普及——狼疮才从「皮肤病」变成「可检测的系统性自身免疫病」。

这条命名史藏着一个方法论教训：**病名是历史的锚点，不是认知的终点**。检测手段每前进一代，疾病边界就被重画一次——今天的 SLE 由 ANA、抗 dsDNA、抗 Sm 等分子标签支撑，与「狼咬样皮损」的初始命名已相距甚远。名称留存，含义迁移，正是科学命名的常态。

**核心要点**：SLE 的诊断史是「免疫检测技术史」的缩影——LE 细胞 → 免疫荧光 ANA → 特异性自身抗体谱，每一步都让「狼疮」从模糊的临床印象变成可重复判定的实体。

## 3 诊断：2019 年 EULAR/ACR 分类标准

2019 年标准采用「入门 + 计分」结构：**先决条件**是 ANA 阳性（≥1:80），然后按临床与免疫学条目累计 ≥10 分，且至少一条临床条目：

| 临床域（权重） | 条目 | 免疫学域（权重） |
| --- | --- | --- |
| 全身（2） | 发热 | 抗磷脂抗体（2） |
| 血液（3–4） | 白细胞减少 / 血小板减少 / 溶血 | 低补体 C3/C4（3） |
| 神经精神（2–5） | 癫痫 / 精神病 / 脊髓炎等 | 特异性抗体（6）：抗 dsDNA、抗 Sm |
| 皮肤黏膜（2–6） | 蝶形红斑 / 盘状红斑 / 口腔溃疡等 | |
| 浆膜（5–6） | 心包积液 / 胸膜积液 | |
| 肌肉骨骼（6） | 滑膜炎 | |
| 肾脏（8–10） | 蛋白尿 / 狼疮肾炎 | |

免疫学域里**抗 dsDNA 与抗 Sm 单列 6 分**，权重极高——因为它们是 SLE 的「专属指纹」；抗 Ro/SSA、抗 La/SSB 则未进入 2019 标准计分（它们更多用于干燥综合征，见第6篇）。

## 4 狼疮肾炎：把病理分型当作战地图

肾活检的分型直接决定治疗强度，值得单独一节。国际肾脏病学会（ISN/RPS）把狼疮肾炎分为六型：

| 型 | 名称 | 病理 | 治疗原则 |
| --- | --- | --- | --- |
| I / II | 系膜型 | 系膜沉积，临床轻微 | 观察或轻处理 |
| III / IV | 局灶 / 弥漫增殖型 | 毛细血管内增生、新月体 | **强化免疫抑制**（激素+环磷酰胺或霉酚酸酯）+ 羟氯喹 |
| V | 膜型 | 上皮下沉积，肾病综合征样 | 免疫抑制 ± 激素 |
| VI | 硬化型 | 广泛硬化 | 肾保护、透析/移植 |

**重点结论：III/IV 型（增殖型）是预后最凶险、也最需积极治疗的类型**——新月体意味着肾功能在「按周恶化」。<span class="marginnote">狼疮肾炎的诊断常靠血尿、蛋白尿筛查触发；指南推荐 SLE 患者无论有无症状，都应定期查尿常规与尿蛋白/肌酐比——「化验驱动的早期干预」在 SLE 里是标准动作。</span>

## 5 治疗：羟氯喹是基石，激素是救火

SLE 治疗的核心逻辑是「分层」：把治疗强度与器官受累的严重度对齐。

**所有患者**：**羟氯喹（HCQ）**——抗疟药，通过抑制 TLR 信号、减少自身抗原提呈发挥免疫调节，能降复发率、改善存活，是 SLE 治疗的「永远基石」，也应用于妊娠期。
- **轻中度（皮肤/关节为主）**：HCQ + 必要时低剂量激素；氨甲蝶呤、硫唑嘌呤作为助减激素的药物。
- **中重度/内脏受累**：激素冲击 + **环磷酰胺（CYC）** 或 **霉酚酸酯（MMF）** 作为诱导缓解，随后用 MMF 或硫唑嘌呤维持。
- **难治 / 特定场景**：利妥昔单抗（抗 CD20）、贝利尤单抗（抗 BLyS，首个获批的 SLE 靶向生物制剂）、阿尼鲁单抗（抗 IFN-α 受体）。<span class="marginnote">贝利尤单抗靶向 B 细胞存活因子 BLyS/BAFF——思路是「饿死」自反应性 B 细胞而不是杀死它们。这是从「细胞毒免疫抑制」走向「精准调控免疫微环境」的标志性转变，与第六级《免疫学》里免疫检查点、细胞因子网络的视角一脉相承。</span>

**糖皮质激素是双刃剑**：它是 SLE 最有效的急性期药物，但长期大剂量导致骨质疏松、感染、心血管风险——SLE 患者的死亡原因已从疾病本身转向**感染与心血管事件**。

因此现代治疗原则被浓缩为一句话：「用最少激素换取最低疾病活动」——把羟氯喹与免疫抑制剂当作「激素替身」，撑起长期管理。

## 6 小结

- SLE 的核心机制：**凋亡碎片清除障碍 → 抗核抗体 → 免疫复合物 + 补体消耗 → III 型损伤**；抗 dsDNA 与补体 C3/C4 是活动度的晴雨表。
- 临床表现是「多器官点状分布」：蝶形红斑、光敏感、非侵蚀性关节炎、狼疮肾炎、血细胞减少、NP-SLE。
- 诊断：2019 EULAR/ACR 标准，ANA 为入场券，临床 + 免疫学计分 ≥10；抗 dsDNA、抗 Sm 权重最高。
- **狼疮肾炎分六型，增殖型（III/IV）最凶险**，靠肾活检定分型、定治疗强度。
- 治疗：**羟氯喹为全员基石**，激素按需救火，重症用环磷酰胺/MMF，靶向时代有贝利尤单抗、阿尼鲁单抗；目标是「最少激素、最低活动」。

在下一节，我们把视线从「免疫复合物攻击全身」移向「血栓与流产」——一个抗体直接改写凝血命运的疾病，以及把它装进口袋的武器库：**抗磷脂综合征与生物制剂治疗**。
