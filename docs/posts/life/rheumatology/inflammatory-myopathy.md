## 为什么从炎症性肌病开始

本专题此前的战场是关节、血管、腺体；**炎症性肌病（inflammatory myopathy）**把战场移到**骨骼肌**——一组以「肌肉无力 + 肌酶升高 + 肌肉炎症」为核心的特发性肌病，其原型是**皮肌炎（dermatomyositis，DM）**与**多发性肌炎（polymyositis，PM）**。<span class="marginnote">凯尔苏斯在两千年记录的四征（红、肿、热、痛）之后，还差第五个——功能丧失（*functio laesa\*）。肌病恰好是「功能丧失」最典型的表现：肌肉被炎症攻击，最直接的症状不是痛，而是「没力气」。</span>

这个病族的独特之处有三：其一，**皮肤与肌肉是「同一场战争的两块阵地」**——皮肌炎的特征性皮疹几乎和肌无力同样重要；其二，**与恶性肿瘤的关联**是风湿病里最强的之一；其三，近年依靠**肌炎特异性抗体（MSA）**完成了从「临床表现分型」到「免疫学分型」的升级，治疗和预后判断因此更精准。

## 1 发病机制：肌肉不是被「直接杀掉」的

「多发性肌炎」这个病名容易让人误以为肌肉是被炎症细胞直接溶解的，其实机制更微妙：

**皮肌炎**：以**补体介导的微血管损伤**为起点——膜攻击复合物沉积于肌内毛细血管，血管闭塞导致肌纤维**缺血性坏死**；坏死区周围出现特征性的**束周萎缩（perifascicular atrophy）**，是皮肌炎的病理标志。<span class="marginnote">束周萎缩是「血管病 → 缺血 → 肌纤维萎缩」的空间证据：肌束边缘离血供最远、缺血最重，所以最先萎缩。病理切片上看到束周萎缩，几乎可以直接指向皮肌炎——它是补体介导微血管病变的形态学指纹。</span>

**多发性肌炎**：以**细胞毒性 T 细胞（CD8⁺）直接攻击肌纤维**为主——T 细胞钻进肌纤维间，释放穿孔素、颗粒酶。有趣的是，真正「纯 PM」在规范病理下越来越少，许多原诊断为 PM 的病例实为**免疫介导坏死性肌病（IMNM）**或**包涵体肌炎（IBM）**——肌病学的近十年是一部「从临床表现向免疫学/病理学重新命名」的历史。

**肌炎特异性抗体（MSA）**（抗 Jo-1 等氨酰-tRNA 合成酶抗体、抗 Mi-2、抗 SRP、抗 MDA5…）对应着不同临床亚型：**抗合成酶综合征**（Jo-1 等）= 肌炎 + 间质性肺病 + 关节炎 + 技工手 + 雷诺；**抗 MDA5** 与快速进展性 ILD 强相关——抗体分型已直接驱动治疗决策。<span class="marginnote">「技工手」（mechanic's hands）是抗合成酶综合征的标志性体征：手指桡侧皮肤角化、皲裂，像常年修车工人的手。一个皮肤表现能预测一种抗体、一群并发症——这就是「抗体分型」的临床价值。</span>

**免疫介导坏死性肌病（IMNM）**近年被单独分出：以**抗 SRP** 或**抗 HMGCR** 抗体为标志，病理上是肌纤维坏死而几乎没有炎症浸润（「无炎症的坏死」），临床起病急、肌无力重、CK 常达数千至上万。**抗 HMGCR** 与他汀暴露相关——少数使用他汀者会「对自身 HMGCR 产生免疫攻击」，形成「他汀相关的免疫性肌坏死」；这部分患者停药他汀往往仍不能缓解，反而需要免疫抑制治疗。<span class="marginnote">「他汀伤肌」其实分两种：常见的是<strong>他汀毒性肌病</strong>（剂量相关、停药可逆、无抗体），少见的是<strong>免疫介导坏死性肌病</strong>（抗体驱动、停药不缓解、需免疫抑制）。把「吃药肌痛」一律当作毒性反应而继续观察，可能漏掉后者——这提醒临床：同一症状要有「常见但良性」与「少见但危险」的双通道思维。</span>IMNM 的治疗对激素相对抵抗，常需较长期免疫抑制。

## 2 临床表现：无力 + 皮疹 + 肌酶

炎症性肌病的核心表现是**对称性近端肌无力**：上肢抬臂困难（梳头、举物费力）、下肢起立/上楼困难（蹲下起不来是经典自述）、颈屈肌无力（抬头费力）；远端肌力通常保留，这与神经病（远端为主）形成对照。

**皮肌炎的特征性皮疹**：

**Gottron 丘疹**：指/掌指关节背面的紫红色鳞屑性丘疹——皮肌炎特异性最高的皮疹。
- **向阳性皮疹（heliotrope rash）**：眼睑紫红色水肿斑。
- **甲周红斑、披肩征**（肩背部 V 形紫红斑）、**技工手**。

**肌酶**：**肌酸激酶（CK）**是主力指标，活动期常明显升高（可达数千 U/L）；ALT/AST、乳酸脱氢酶（LDH）、醛缩酶也可升高。<span class="marginnote">CK 升高的解读有个易错点：CK 也存在于心肌与平滑肌——但肌病患者的 CK 主要来自骨骼肌；而「CK 升高」的鉴别谱很宽：他汀类药物、甲减、剧烈运动、肌营养不良都可致 CK 升高。所以「CK 高 ≠ 肌炎」，要看伴随的无力与肌电图/活检证据。</span>

**皮肌炎的皮肤不只是「皮疹」，更是「诊断与分类的窗口」**：Gottron 丘疹与向阳性皮疹是特异性极高的皮损，它们的出现往往**先于肌无力**——这给了「早诊断」一个机会：一个只有皮疹、尚无无力的患者，若被识别为「无肌病性皮肌炎」，可以更早启动监测与干预，避免发展到肌无力和 ILD。<span class="marginnote">「皮疹先于肌无力数月到数年」是 DM 的常见时间线：很多患者先看皮肤科，才被转诊到风湿科。皮肤科医生识别 Gottron 丘疹、向阳疹、披肩征的意义，不亚于风湿科医生识别关节肿胀——跨学科的「识别接力」，是早期诊断的关键一环。</span>此外，**光敏感**在 DM 中常见（皮疹在日晒后加重），防晒是重要的非药物干预；披肩征、V 形征（前胸暴露区红斑）都提示光暴露部位的皮肤受累。

**肌炎抗体的「临床综合征」是真正的记忆主线**：抗 Jo-1（最常见的合成酶抗体）对应抗合成酶综合征（肌炎 + ILD + 关节炎 + 技工手 + 雷诺 + 发热）；抗 Mi-2 对应经典型皮肌炎（皮疹突出、预后较好）；抗 MDA5 对应**快速进展型 ILD**（肌炎可以很轻甚至缺如，但肺可数周内衰竭）；抗 TIF1-γ 与**肿瘤相关皮肌炎**相关。把「抗体 → 临床拼图 → 治疗与筛查策略」连起来读，比背十种抗体名有用得多——抗体不是装饰，是治疗与预后的「导航」。

## 3 诊断与鉴别：肌电图、磁共振与活检

诊断路径是「临床表现 → 肌酶/肌电图 → 影像 → 活检」的逐步取证：

**肌电图（EMG）**：可见自发电位（纤颤波、正锐波）与肌源性损害（低幅、多相、短时限运动单位电位）。
- **肌肉 MRI**：T2/脂肪抑制序列显示肌肉水肿——既辅助诊断，又指导活检部位。
- **肌肉活检**：确认炎症浸润与病理亚型，是「把名字钉在墙上的最后一把锤子」。<span class="marginnote">活检选肌的原则很重要：选<strong>中度无力、而非完全瘫软或完全正常</strong>的肌肉——完全瘫软的肌肉已无炎症可看（都被纤维化替代了），正常肌肉则可能采不到病灶。这个「选中间地带」的原则，也是影像引导活检的常规策略。</span>

**辨析｜易错点：** 肌无力+肌酶高的鉴别谱：

| 原因 | 关键线索 |
| --- | --- |
| 他汀相关性肌病 | 用药史，停药可逆 |
| 甲减性肌病 | TSH 升高 |
| 包涵体肌炎（IBM） | 50 岁后、**非对称、远端/屈指**受累、进展慢 |
| 糖皮质激素性肌病 | 激素使用史，病理无炎症 |
| **炎症性肌病（DM/PM/IMNM）** | 近端无力 + 皮疹（DM）+ 肌酶高 + 炎症病理 |

**包涵体肌炎（IBM）值得单独提一句**：它是 50 岁后最常见的「炎症性肌病」，却以**非对称、累及远端**（尤其手指屈肌与股四头肌）为特征，进展缓慢但**对免疫抑制治疗几乎无效**——这使它成为肌病领域「名不副实」的尴尬分子（病理上有炎症，但免疫抑制打不动它）。把 IBM 从 PM 中识别出来极重要：误把 IBM 当 PM 长期用大剂量激素，患者既得不到收益，还白白承受激素副作用。<span class="marginnote">「有炎症的肌肉病 ≠ 免疫抑制有效的肌肉病」——IBM 是这一原则的最好教材。识别 IBM 的钥匙是临床（年龄、非对称、远端/屈指受累）+ 病理（镶边空泡、淀粉样沉积）。这也再次说明：<strong>诊断分类不是「贴标签」，而是直接决定治疗方案的有效性</strong>。</span>

## 4 与恶性肿瘤的关联：一份必须面对的「保单」

皮肌炎是风湿病里**副肿瘤关联**最显著的病之一：成年皮肌炎患者伴发恶性肿瘤的风险约为一般人群的 **2–4 倍**，诊断前后 1–3 年内风险最高，常见肿瘤有肺癌、胃癌、卵巢癌、淋巴瘤等。<span class="marginnote">「皮肌炎查肿瘤」不是过度医疗：指南建议确诊后对高危人群做年龄与风险适配的肿瘤筛查（胸部影像、腹部超声、肿瘤标志物等），并随访数年。机制上认为肿瘤抗原与肌细胞抗原存在交叉——「免疫应答」被肿瘤启动后误伤肌肉。</span>PM 的肿瘤风险较低，IMNM 亦需警惕。这是皮肌炎诊治中「治病之外还要找病」的独特一环。

**哪些线索提示「副肿瘤性皮肌炎」要更积极查肿瘤？** 几个「红旗」值得记住：**起病年龄 > 40 岁、皮疹与肌无力症状快速进展、治疗反应差、伴发**抗 TIF1-γ **或**抗 NXP2 **抗体、出现吞咽困难/呼吸困难等重症表现**。对这些患者，初始筛查（胸部 CT、腹部盆腔影像、肿瘤标志物、乳腺/妇科/胃肠按年龄适配）若阴性，还需在发病后 2–3 年内保持警惕并复查。<span class="marginnote">「抗体预测肿瘤」是这里最有意思的线索：抗 TIF1-γ 阳性的皮肌炎患者伴发肿瘤的比例显著升高。一个血液指标就能提示「重点查哪里、查多久」——把免疫学、肿瘤学、风湿病学三张地图叠在一起，正是交叉学科的魅力。</span>

## 5 治疗与预后：激素打头，靶向跟上

**一线**：糖皮质激素（泼尼松 0.75–1 mg/kg/d）——多数患者 4–8 周内肌力开始恢复；激素不响应或需减量时加**免疫抑制剂（甲氨蝶呤或硫唑嘌呤）**。<span class="marginnote">激素是「灭火器」而免疫抑制剂是「防火墙」：灭火器要快、要够量；防火墙要在灭火器撤走时接住防线。肌病治疗失败的第一原因是「激素减得太快」，第二是「从未加免疫抑制剂」。</span>
- **难治/重症**：静脉丙种球蛋白（IVIG，对皮肌炎尤其有效）、利妥昔单抗、钙调磷酸酶抑制剂（他克莫司/环孢素，抗合成酶综合征伴 ILD 时常用）。

**ILD 是炎症性肌病的第一杀手，值得单独讲**：肌病相关 ILD 在**抗合成酶综合征**里最常见，表现为进行性气促、限制性通气障碍；**抗 MDA5 阳性的快速进展型 ILD**可在数周内致命，是风湿科的「肺部急症」。处理需「抢时间」：激素冲击 + 环磷酰胺/他克莫司 + 必要时 IVIG 的组合治疗，肺功能与 HRCT 密切随访。<span class="marginnote">肌病与肺病看似「两个器官」，实则被同一批自身抗体连在一起——抗合成酶抗体既打肌肉也打肺。这提示临床：<strong>肌炎患者都要问呼吸、查肺功能</strong>，ILD 往往比肌无力更早、更凶。把「肌病」当成「肌-肺综合征」来看，是近年最重要的观念更新之一。</span>对肌病的疗效评价，永远要同时看「肌力、肌酶、肺」三个面板。
- **疗效监测**：CK 随病情回落是客观标志；但**肌力改善滞后于 CK 下降**——不要把「CK 正常」当成「病好了」，要等肌力恢复。

**肌力评估的方法论**：评估肌力不能只靠「感觉」，临床常用**医学研究理事会（MRC）肌力分级**（0–5 级，5 级为正常肌力）与**徒手肌力测试（MMT）**对近端肌群（肩外展、屈髋、颈屈）逐项打分，并结合**起立-行走计时测试（TUG）**等客观功能指标。肌力的「曲线」比单次数值更有信息量——**定期记录「能上几层楼、能提多重的菜」这类生活化指标，往往比化验更直观**。这也呼应全书的主题：把「主观感受」翻译成「可追踪的量化指标」，是慢性病管理共通的方法论。<span class="marginnote">肌病康复有一个容易踩的坑：<strong>急性期过度活动会加重肌纤维损伤</strong>——炎症未控制时「咬牙锻炼」反而使 CK 升高、恢复更慢。合理的节奏是「急性期以休息与抗炎为主，缓解期才逐步开始力量康复」。治疗与康复的时序，和 RA「先控炎、后练功」的逻辑同源。</span>
- 预后：未经治疗的 DM/PM 可致严重功能障碍；规范治疗后多数可恢复日常功能，但间质性肺病（尤其抗 MDA5 阳性快速进展型）仍是主要死因。

**康复与「吞咽安全」是肌病管理的隐藏章节**：近端肌无力同样累及**咽喉肌**，可致**吞咽困难与误吸**（呛咳、肺炎反复）——约 1/3 的肌病患者有吞咽受累，这是比肌力下降更隐蔽、却更危险的并发症。治疗与随访中应主动询问「喝水呛不呛、吞咽有没有变慢」，必要时做吞咽评估，调整食物性状（软食、稠液）并尽早安排康复吞咽训练。**把「能不能安全进食」放进肌病的常规评估**，常常比「肌力评几分」更能决定患者的安全与生活质量。<span class="marginnote">肌病管理容易「只盯着化验和肌力」，忽略吞咽、呼吸（膈肌受累可致呼吸衰竭）这类「保命」的指标。一个实用的提醒：<strong>肌病患者新出现声音嘶哑、饮水呛咳，要优先排查吞咽与呼吸</strong>——这些「非典型」信号，往往是危象的先行者。</span>

**激素的「撤退艺术」是治疗成败的分水岭**：肌病的激素治疗有鲜明的「阶梯」——急性期足量（泼尼松 0.75–1 mg/kg/d），病情稳定后**每 4–8 周缓慢减量**（如每 2–4 周减 5–10%），总疗程常需 1–2 年以上，过早过快减量是复发最常见的原因。同时要监控激素副作用：骨质疏松（补钙与维生素 D、必要时双膦酸盐）、血糖升高、体重增加、感染。**「激素减得对不对」直接决定肌病能不能真正稳定**——这也呼应 RA 章节反复出现的「慢性病治疗是马拉松，不是百米冲刺」。

**缓解期的康复是「重建而非代偿」**：炎症控制后，肌病康复的目标是「重新训练被炎症弱化的肌肉」——从**被动/辅助活动**（防挛缩）逐步过渡到**温和的抗阻训练**（如渐进式负重），配合呼吸训练与有氧运动改善整体体能。康复的节奏要「跟着病情走」：炎症活动期以「保护与抗炎」为主，缓解期才加大「训练量」——把「治（药）」与「练（康复）」错开节奏、互相衔接，是肌病长期管理成熟的标志。肌力恢复往往以「月」计，患者教育与预期管理（「别指望几周就恢复正常」）是提高依从性的重要一环。

**难治性肌病与「分层升级」**：对激素 + 一种免疫抑制剂仍不缓解的患者，需「重新审视诊断」（是 IBM？是 IMNM？还是合并 ILD 需优先处理肺？），然后分层升级——IVIG（皮肌炎尤其有效）、利妥昔单抗、钙调磷酸酶抑制剂或联合方案。肌病的「难治」常是「没找对亚型或没顾上肺」的信号——**把「难治」当作「需要重新分类」的提醒**，比盲目加药更有价值。肌病治疗的全程，都建立在「准确的分类 + 主动的监测 + 耐心的节奏」这三根支柱之上。

**炎症性肌病把「从临床到分子」的现代分型演给我们看**：从「皮肌炎/多发性肌炎」的临床表现二分，到 MSA 抗体谱、IMNM/IBM 的病理细分，肌病学近二十年的历史就是「分子分型不断改写疾病地图」的缩影。学肌病，学的不只是一种病，更是「分类如何决定治疗与预后」这一医学方法论的活教材。

**肌病收束的「主旋律」**：它把「皮肤、肌肉、肺、肿瘤」四张地图叠在一张诊断网络上——皮疹指向抗体、抗体指向 ILD、年龄与抗体指向肿瘤。读懂这张网络，就读懂了现代风湿病学「以机制为纲、以多系统为目」的读法。

## 7 小结

- 炎症性肌病以**对称性近端肌无力 + CK 升高**为核心；DM 伴特征性皮疹（Gottron 丘疹、向阳性皮疹）。
- 机制分两型：**DM 为补体介导微血管损伤**（束周萎缩），**PM/IMNM 为 T 细胞直接攻击**；近年以**肌炎特异性抗体**重新分型（抗合成酶、抗 MDA5…）。
- **CK 升高 ≠ 肌炎**：须鉴别他汀、甲减、IBM、激素性肌病；诊断靠肌酶 + 肌电图 + MRI + 活检逐步取证。
- **皮肌炎与恶性肿瘤相关（2–4 倍）**，确诊前后 1–3 年需肿瘤筛查。
- 治疗：**激素打头 + 免疫抑制剂跟随**，难治用 IVIG/利妥昔单抗；CK 回落先于肌力恢复，监测勿只看化验。
