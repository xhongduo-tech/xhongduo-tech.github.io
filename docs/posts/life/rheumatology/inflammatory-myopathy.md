## 为什么从炎症性肌病开始

本专题此前的战场是关节、血管、腺体；**炎症性肌病（inflammatory myopathy）**把战场移到**骨骼肌**——一组以「肌肉无力 + 肌酶升高 + 肌肉炎症」为核心的特发性肌病，其原型是**皮肌炎（dermatomyositis，DM）**与**多发性肌炎（polymyositis，PM）**。<span class="marginnote">凯尔苏斯在两千年记录的四征（红、肿、热、痛）之后，还差第五个——功能丧失（*functio laesa\*）。肌病恰好是「功能丧失」最典型的表现：肌肉被炎症攻击，最直接的症状不是痛，而是「没力气」。</span>

这个病族的独特之处有三：其一，**皮肤与肌肉是「同一场战争的两块阵地」**——皮肌炎的特征性皮疹几乎和肌无力同样重要；其二，**与恶性肿瘤的关联**是风湿病里最强的之一；其三，近年依靠**肌炎特异性抗体（MSA）**完成了从「临床表现分型」到「免疫学分型」的升级，治疗和预后判断因此更精准。

## 1 发病机制：肌肉不是被「直接杀掉」的

「多发性肌炎」这个病名容易让人误以为肌肉是被炎症细胞直接溶解的，其实机制更微妙：

**皮肌炎**：以**补体介导的微血管损伤**为起点——膜攻击复合物沉积于肌内毛细血管，血管闭塞导致肌纤维**缺血性坏死**；坏死区周围出现特征性的**束周萎缩（perifascicular atrophy）**，是皮肌炎的病理标志。<span class="marginnote">束周萎缩是「血管病 → 缺血 → 肌纤维萎缩」的空间证据：肌束边缘离血供最远、缺血最重，所以最先萎缩。病理切片上看到束周萎缩，几乎可以直接指向皮肌炎——它是补体介导微血管病变的形态学指纹。</span>

**多发性肌炎**：以**细胞毒性 T 细胞（CD8⁺）直接攻击肌纤维**为主——T 细胞钻进肌纤维间，释放穿孔素、颗粒酶。有趣的是，真正「纯 PM」在规范病理下越来越少，许多原诊断为 PM 的病例实为**免疫介导坏死性肌病（IMNM）**或**包涵体肌炎（IBM）**——肌病学的近十年是一部「从临床表现向免疫学/病理学重新命名」的历史。

**肌炎特异性抗体（MSA）**（抗 Jo-1 等氨酰-tRNA 合成酶抗体、抗 Mi-2、抗 SRP、抗 MDA5…）对应着不同临床亚型：**抗合成酶综合征**（Jo-1 等）= 肌炎 + 间质性肺病 + 关节炎 + 技工手 + 雷诺；**抗 MDA5** 与快速进展性 ILD 强相关——抗体分型已直接驱动治疗决策。<span class="marginnote">「技工手」（mechanic's hands）是抗合成酶综合征的标志性体征：手指桡侧皮肤角化、皲裂，像常年修车工人的手。一个皮肤表现能预测一种抗体、一群并发症——这就是「抗体分型」的临床价值。</span>

## 2 临床表现：无力 + 皮疹 + 肌酶

炎症性肌病的核心表现是**对称性近端肌无力**：上肢抬臂困难（梳头、举物费力）、下肢起立/上楼困难（蹲下起不来是经典自述）、颈屈肌无力（抬头费力）；远端肌力通常保留，这与神经病（远端为主）形成对照。

**皮肌炎的特征性皮疹**：

**Gottron 丘疹**：指/掌指关节背面的紫红色鳞屑性丘疹——皮肌炎特异性最高的皮疹。
- **向阳性皮疹（heliotrope rash）**：眼睑紫红色水肿斑。
- **甲周红斑、披肩征**（肩背部 V 形紫红斑）、**技工手**。

**肌酶**：**肌酸激酶（CK）**是主力指标，活动期常明显升高（可达数千 U/L）；ALT/AST、乳酸脱氢酶（LDH）、醛缩酶也可升高。<span class="marginnote">CK 升高的解读有个易错点：CK 也存在于心肌与平滑肌——但肌病患者的 CK 主要来自骨骼肌；而「CK 升高」的鉴别谱很宽：他汀类药物、甲减、剧烈运动、肌营养不良都可致 CK 升高。所以「CK 高 ≠ 肌炎」，要看伴随的无力与肌电图/活检证据。</span>

## 3 诊断与鉴别：肌电图、磁共振与活检

诊断路径是「临床表现 → 肌酶/肌电图 → 影像 → 活检」的逐步取证：

**肌电图（EMG）**：可见自发电位（纤颤波、正锐波）与肌源性损害（低幅、多相、短时限运动单位电位）。
- **肌肉 MRI**：T2/脂肪抑制序列显示肌肉水肿——既辅助诊断，又指导活检部位。
- **肌肉活检**：确认炎症浸润与病理亚型，是「把名字钉在墙上的最后一把锤子」。<span class="marginnote">活检选肌的原则很重要：选<strong>中度无力、而非完全瘫软或完全正常</strong>的肌肉——完全瘫软的肌肉已无炎症可看（都被纤维化替代了），正常肌肉则可能采不到病灶。这个「选中间地带」的原则，也是影像引导活检的常规策略。</span>

**辨析｜易错点：** 肌无力+肌酶高的鉴别谱：

| 原因 | 关键线索 |
| --- | --- |
| 他汀相关性肌病 | 用药史，停药可逆 |
| 甲减性肌病 | TSH 升高 |
| 包涵体肌炎（IBM） | 50 岁后、**非对称、远端/屈指**受累、进展慢 |
| 糖皮质激素性肌病 | 激素使用史，病理无炎症 |
| **炎症性肌病（DM/PM/IMNM）** | 近端无力 + 皮疹（DM）+ 肌酶高 + 炎症病理 |

## 4 与恶性肿瘤的关联：一份必须面对的「保单」

皮肌炎是风湿病里**副肿瘤关联**最显著的病之一：成年皮肌炎患者伴发恶性肿瘤的风险约为一般人群的 **2–4 倍**，诊断前后 1–3 年内风险最高，常见肿瘤有肺癌、胃癌、卵巢癌、淋巴瘤等。<span class="marginnote">「皮肌炎查肿瘤」不是过度医疗：指南建议确诊后对高危人群做年龄与风险适配的肿瘤筛查（胸部影像、腹部超声、肿瘤标志物等），并随访数年。机制上认为肿瘤抗原与肌细胞抗原存在交叉——「免疫应答」被肿瘤启动后误伤肌肉。</span>PM 的肿瘤风险较低，IMNM 亦需警惕。这是皮肌炎诊治中「治病之外还要找病」的独特一环。

## 5 治疗与预后：激素打头，靶向跟上

**一线**：糖皮质激素（泼尼松 0.75–1 mg/kg/d）——多数患者 4–8 周内肌力开始恢复；激素不响应或需减量时加**免疫抑制剂（甲氨蝶呤或硫唑嘌呤）**。<span class="marginnote">激素是「灭火器」而免疫抑制剂是「防火墙」：灭火器要快、要够量；防火墙要在灭火器撤走时接住防线。肌病治疗失败的第一原因是「激素减得太快」，第二是「从未加免疫抑制剂」。</span>
- **难治/重症**：静脉丙种球蛋白（IVIG，对皮肌炎尤其有效）、利妥昔单抗、钙调磷酸酶抑制剂（他克莫司/环孢素，抗合成酶综合征伴 ILD 时常用）。
- **疗效监测**：CK 随病情回落是客观标志；但**肌力改善滞后于 CK 下降**——不要把「CK 正常」当成「病好了」，要等肌力恢复。
- 预后：未经治疗的 DM/PM 可致严重功能障碍；规范治疗后多数可恢复日常功能，但间质性肺病（尤其抗 MDA5 阳性快速进展型）仍是主要死因。

## 6 小结

- 炎症性肌病以**对称性近端肌无力 + CK 升高**为核心；DM 伴特征性皮疹（Gottron 丘疹、向阳性皮疹）。
- 机制分两型：**DM 为补体介导微血管损伤**（束周萎缩），**PM/IMNM 为 T 细胞直接攻击**；近年以**肌炎特异性抗体**重新分型（抗合成酶、抗 MDA5…）。
- **CK 升高 ≠ 肌炎**：须鉴别他汀、甲减、IBM、激素性肌病；诊断靠肌酶 + 肌电图 + MRI + 活检逐步取证。
- **皮肌炎与恶性肿瘤相关（2–4 倍）**，确诊前后 1–3 年需肿瘤筛查。
- 治疗：**激素打头 + 免疫抑制剂跟随**，难治用 IVIG/利妥昔单抗；CK 回落先于肌力恢复，监测勿只看化验。
