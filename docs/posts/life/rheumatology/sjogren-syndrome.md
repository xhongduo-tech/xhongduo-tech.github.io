## 为什么从干燥综合征开始

风湿病里很多「大魔王」以凶险著称，**干燥综合征（Sjögren syndrome，SS）**却以「温和」的面孔出场：口干、眼干、疲惫——听起来像亚健康。但这是一张伪装：它是最常见、又最常被漏诊的自身免疫病之一，患病率可达 0.1%–0.6%，且背后潜伏着两件大事——**淋巴瘤风险**与**内脏受累**。<span class="marginnote">这个病名来自瑞典眼科医生亨利克·舍格伦（Henrik Sjögren，1899—1986），他在 1933 年把「干燥性角结膜炎 + 口干 + 关节炎」命名为一个综合征。此前它一直被当作更年期或神经衰弱处理——「被当成别的小毛病」恰是 SS 至今的现实。</span>

SS 的病理原型是**外分泌腺的淋巴组织浸润**：淋巴细胞在唾液腺、泪腺里筑巢，腺体逐渐被淋巴细胞「置换」而丧失功能。理解了这个病理，就理解了口干的本质——不是「水喝少了」，而是「腺体坏了」。

## 1 病理与免疫：腺体里的「淋巴细胞殖民」

SS 的核心病变是**灶性淋巴细胞性涎腺炎**：小唾液腺活检中可见以 T 细胞为主、夹杂 B 细胞与浆细胞的密集浸润灶。<span class="marginnote">病理上用一个数字量化浸润强度：<strong>聚焦评分（focus score）</strong>= 每 4 mm² 腺体组织中的淋巴细胞灶数，≥1 即阳性（一个灶 ≈ 50 个以上淋巴细胞）。这个「数细胞计数」的评分把组织病理变成可重复的诊断证据——与 DAS28、SLEDAI 一样，是「把主观现象数字化」的临床科学实践。</span>

浸润细胞分泌的细胞因子（IL-21、BAFF 等）驱动 B 细胞活化，产生两种标志性自身抗体：**抗 Ro/SSA** 与**抗 La/SSB**。抗体靶向细胞内的 RNA 结合蛋白（Ro60、Ro52、La/SS-B），这些蛋白在凋亡细胞表面「被翻出来」暴露——再次呼应第一篇「凋亡碎片暴露自身抗原」的主题。

**为什么唾液腺会持续浸润？** 学界认为是「腺体自身的遗传易感性 + 外源性触发（病毒感染如 EBV、CMV 的分子模拟）+ 凋亡清除障碍」三者叠加。浸润一旦建立，就进入「淋巴细胞堆积 → BAFF 升高 → B 细胞克隆扩张 → 更强烈的自身免疫」的正反馈。

**BAFF 是这个正反馈的「燃料」**：B 细胞活化因子（BAFF/BLyS）在 SS 患者的唾液腺与血清中显著升高，它延长自反应性 B 细胞的存活、促进其克隆扩张——这也解释了为什么 SS 会走向淋巴瘤，以及为什么靶向 BAFF 的贝利尤单抗（在 SLE 中已获批）是 SS 最有希望的候选靶点之一。浸润的淋巴细胞还会在腺体内形成**异位淋巴组织（生发中心样结构）**——「腺体里长出了淋巴结」，这一步让「免疫器官化」的概念落到实体：它既是自身免疫持续的原因，也是淋巴瘤转化风险升高的结构基础。<span class="marginnote">SS 研究把「自身免疫 → 淋巴增殖 → 淋巴瘤」串成一条连续谱：正常腺体 → 灶性浸润 → 异位生发中心 → 克隆性 B 细胞 → MALT 淋巴瘤。理解这条谱，就理解了为什么 SS 患者要长期随访、为什么「良性」的干燥会演变成「恶性」的肿瘤。</span>

## 2 临床表现：干燥是表面，系统受累是里子

**口干燥症（xerostomia）**：口干需频繁饮水、干食难咽、舌面裂纹、猖獗龋齿（牙釉质快速破坏是 SS 的标志性后果）。**眼干燥症（xerophthalmia）**：眼干、异物感、畏光、泪液减少。

但 SS 绝不止于「干燥」：

**系统表现（约 1/3 患者）**：关节痛/关节炎、雷诺现象、间质性肺病、肾小管酸中毒（远端肾小管受累）、周围神经病变、紫癜（提示高丙种球蛋白血症或血管炎）。
- **淋巴瘤风险**：SS 患者发生 B 细胞非霍奇金淋巴瘤的风险约为一般人群的 **10–15 倍**，是 SS 最重要的长期风险。<span class="marginnote">风险线索就在前面那条正反馈里：持续的 B 细胞克隆扩张有可能「越线」成为真正的肿瘤。腮腺持续肿大、淋巴结肿大、紫癜、冷球蛋白、补体低——都是预示淋巴瘤转化的警示信号，临床要定期随访筛查。</span>
**继发性 SS**：SS 可与 RA、SLE、系统性硬化症等共存——称「继发性干燥综合征」，约 1/3 的 RA 与 1/4 的 SLE 患者有继发干燥。

**腺体功能如何客观测量？** 三个床边/门诊检查把「主观口干眼干」变成数据：**泪液分泌试验（Schirmer 试验）**——滤纸条置于下睑，5 分钟湿润长度 ≤5 mm 为异常；**非刺激全唾液流率**——静息时收集 5 分钟唾液，≤0.1 mL/min 为异常；**唾液腺显像**或唇腺活检则提供结构证据。<span class="marginnote">Schirmer 试验要先把表面麻醉剂滴入结膜囊再做——否则泪腺受刺激分泌增加，会得到「假正常」的假阴性结果。「操作细节决定结果可信度」，这也是诊断学里反复强调的：任何检查都有它看不见的前提条件。</span>这些检查既是诊断依据，也是评估「病情是否真的在进展」的随访基线。

**辨析｜易错点：** 口干≠SS。**药物性口干**（抗胆碱能药、抗抑郁药）、**放疗后**、**糖尿病**、**更年期**、**衰老**都是更常见原因。<span class="marginnote">「口干的原因排个序，SS 排在药物、放疗、糖尿病之后」——这是临床思维的排序题：先排除常见、可逆的原因，再考虑自身免疫。SS 的确诊需要客观证据（抗体、活检、腺体功能检查），不能凭主观口干。</span>

## 3 诊断：2016 年 ACR/EULAR 分类标准

2016 年标准采用「加权计分 ≥4」结构，且需排除头颈部放疗、HCV、HIV、淋巴瘤、结节病等继发干燥因素：

| 条目 | 权重 |
| --- | --- |
| 唇腺活检：聚焦评分 ≥1 | 3 |
| 抗 Ro/SSA 阳性 | 3 |
| 眼染色评分 ≥5（角膜荧光素染色） | 1 |
| 泪液分泌试验 ≤5 mm / 5 分钟 | 1 |
| 非刺激全唾液流率 ≤0.1 mL/min | 1 |

有趣的结构：**活检与抗 SSA 各占 3 分，其余客观功能检查各 1 分**——「组织学与特异性抗体」是诊断的两大支柱，主观症状（口干眼干）只作入选前提、不计分。这体现了诊断学的一条原则：**用客观证据说话，主观感受只负责把病人带进门。**<span class="marginnote">2016 标准里值得注意的取舍：<strong>抗 La/SSB 不再单独计分</strong>（它几乎总伴随抗 SSA 出现，特异性冗余）。抗体谱设计的「去冗余」思路，与特征工程里剔除共线性特征的做法异曲同工。</span>

## 4 治疗：无「根治」，但有「管理」

SS 目前没有能「治愈」的靶向药，治疗是分层管理：

**局部替代**：人工泪液、泪点栓、口服刺激（含片）、唾液替代剂——「器官坏了就体外补充」。

**局部管理也有「方法论」**：眼干首选不含防腐剂的人工泪液（频繁使用时不伤角膜上皮），严重者用**泪点栓**（堵住泪液排出口，让泪液留在眼表）；口干则强调**口腔护理**——勤刷牙、用含氟牙膏、嚼无糖口香糖刺激唾液，定期牙科随访，因为 SS 的「猖獗龋齿」一旦发生就不可逆。**「器官替代 + 症状管理」的精细程度，决定了 SS 患者的生活质量**——这提醒我们，免疫病管理不只有「药」，还有大量非药物工程。<span class="marginnote">SS 里「牙医是半个风湿科医生」：猖獗龋齿、口腔念珠菌、反复腮腺炎是 SS 的常见麻烦，都需要牙科与口腔黏膜科协同。一个「干燥综合征」的诊断，牵动的科室可能比许多「大病」还多。</span>抗胆碱能药物、某些抗抑郁药会加重口干，用药时要注意「加药前问口干」。
- **全身免疫调节**：羟氯喹改善关节痛与疲乏；关节/内脏受累者用 MTX、硫唑嘌呤；重症或血管炎用激素、利妥昔单抗。

**疲乏是 SS 最被低估的负担**：约 70% 的 SS 患者报告显著的疲乏——它不是「累了」，而是一种持续的、休息后不缓解的耗竭感，常伴睡眠障碍、抑郁与认知模糊（「脑雾」），对生活质量的打击往往超过口干眼干本身。疲乏的处理没有特效药，靠**整体管理**：治疗可纠正的睡眠问题与抑郁、规律的低强度运动（研究显示运动对免疫病疲乏有效）、控制疾病活动度、合理安排精力。把「疲乏」纳入 SS 的评估与随访（而不只盯干燥），是现代 SS 管理的重要转向。<span class="marginnote">「疲乏」在风湿病里几乎人人都有，却常常没被正式问诊。它是疾病活动度、心理、睡眠共同作用的结果——把它当「症状」而非「抱怨」来管理，患者体验会完全不同。这也是「以患者为中心」的医学观在 SS 里的具体体现。</span>
- **新靶点**：BAFF/IL-21 通路、共刺激阻断正在临床试验——SS 的靶向时代仍在前夜。<span class="marginnote">SS 的靶向研发比 RA 慢，一个原因是疾病异质性大（「干燥为主」与「系统受累为主」是两个亚群，对药物反应可能相反）。异质性越高，随机试验越难做出阳性结果——这也是第四级《数理统计》里「方差大→检验力低」的临床现实版。</span>
- **癌变监测**：对持续腮腺肿大、淋巴结病、紫癜等高危征象保持警惕，适时行淋巴结活检。

**妊娠是 SS 的一个特殊章节**：由于抗 Ro/SSA 在 SS 中阳性率高，**育龄 SS 女性备孕前应查抗 Ro/SSA、抗 La/SSB**——阳性者需按新生儿狼疮风险管理（见第12篇），孕期监测胎儿心律。SS 本身在孕期多数较平稳，但干燥症状可能加重（激素波动、饮水习惯改变）；常用药中羟氯喹、糖皮质激素妊娠期可用，MTX/MMF 禁用。**把「孕前抗体筛查 + 孕期胎儿监测」写进 SS 的常规随访**，是避免「抗体阳性却未提前预防」这一遗憾的关键。<span class="marginnote">SS 与产科的交汇点就是「抗 Ro/SSA」：它既定义疾病，也定义胎儿的风险。一个简单的孕前抽血，就能让「抗体阳性」从「事后才知道」变成「提前规划」——筛查的意义，正在于把不可预见变为可管理。</span>

**SS 的随访节奏：干燥要管、淋巴瘤要防**。稳定的 SS 通常**每 6–12 个月**随访一次：复查血常规（白细胞/血小板）、免疫球蛋白、补体、肝肾功能，问诊干燥症状变化、腮腺/淋巴结肿大、乏力与新发系统症状。**补体 C4 持续降低 + 单克隆球蛋白 + 腮腺持续肿大**，是提示淋巴瘤转化的「化验三角」，出现时需警惕并考虑进一步检查。把「随访 = 治干燥 + 查淋巴瘤」的框架讲给患者，能避免「以为复查只是看口干」的误区——SS 的随访是一张「双任务清单」。

**干燥症状的「客观分级」同样重要**：诊断与随访中，用**眼染色评分**（角膜荧光素/丽丝胺绿染色评估角结膜上皮损伤）、**泪膜破裂时间**、**唾液流率**与**唾液腺超声**等客观指标量化「干燥程度」，而不是只靠「口干不口干的自我感觉」。客观指标的价值在于：它既能确认「治疗是否真的改善了腺体功能」，也能在「主观感觉变化不明显」时发现「客观上其实在好转」——把干燥从「主观不适」变成「可追踪的客观数据」，是 SS 管理精细化的方向。

**眼部的「湿而不干」陷阱值得警惕**：SS 眼干燥若长期不治，可进展为**角结膜干燥症（keratoconjunctivitis sicca）**，出现角膜上皮点状缺损、丝状角膜炎，严重者角膜溃疡、穿孔——「感觉只是眼干」的患者，裂隙灯下可能已有明显角膜损伤。因此**定期眼科裂隙灯检查**（评估角膜与泪膜）是 SS 随访的组成部分，不能只凭「眼干不干」的主观询问。眼睛是 SS 里「容易被低估却后果实在」的靶器官——把眼科随访制度化，是 SS 管理「防患于未然」的关键一环。**SS 的整体形象由此清晰：它温和起病，却要求「全器官、全生命期」的随访纪律。**

**SS 的「温和」正是它的陷阱，也是它的教学价值**：它是自身免疫病里最「像亚健康」的一个——干燥、疲乏、关节隐痛，样样都不「吓人」。正因如此，它教会我们两件事：其一，**慢性病的危害不在于「发作时有多凶」，而在于「沉默时拖多久」**（淋巴瘤、内脏受累都在沉默中酝酿）；其二，**「把主观不适变成客观随访」**（聚焦评分、Schirmer、抗体、随访清单）是驾驭慢性病的通用方法。SS 是一面镜子，照出风湿病学「化整为零、长期主义」的底色。

**SS 与免疫学的深层连接**：它是「B 细胞过度活化」的标本病——BAFF 驱动、生发中心样结构、克隆扩张、最终走向淋巴瘤。理解 SS，等于理解「免疫系统从正常应答滑向淋巴增殖」这条连续谱，这为后面学习免疫耐受、免疫检查点与淋巴瘤的发生提供了最直观的临床入口。

**淋巴瘤转化的风险信号值得单列**：SS 患者的淋巴瘤以**黏膜相关淋巴组织淋巴瘤（MALT 淋巴瘤）**居多，好发于腮腺、唾液腺。预示转化风险升高的「红旗」包括：**腮腺持续单侧肿大、淋巴结进行性增大、紫癜、冷球蛋白血症、低补体 C4、CD4 淋巴细胞减少、脾大**。<span class="marginnote">注意一个常见误区：<strong>淋巴结肿大 ≠ 淋巴瘤</strong>——SS 的淋巴结病多数是反应性增生（良性）。判断靠的是「肿大是否持续、进行性、质地变硬、伴随全身症状」以及活检时机。随访策略不是「见淋巴结就怕」，而是「看到红旗组合才行动」。</span>若疑诊，需超声引导下淋巴结/腮腺活检确认。

**核心要点表——「干燥」的鉴别诊断**：

| 原因 | 关键线索 | 与 SS 的鉴别 |
| --- | --- | --- |
| 药物（抗胆碱能） | 用药史、停药可逆 | 无抗体、无腺体损害 |
| 放疗（头颈部） | 病史明确 | 腺体萎缩但无炎症灶 |
| 糖尿病 | 血糖高 | 常伴多饮多尿 |
| HCV 感染 | HCV 抗体阳性 | 可有冷球蛋白、肝病 |
| 衰老 | 年龄相关 | 程度轻、进展慢 |
| **干燥综合征** | **抗 SSA/SSB、活检灶性浸润、系统表现** | **自身免疫性腺体损害** |

## 6 小结

- SS 的核心病理是**外分泌腺的淋巴细胞浸润**（聚焦评分 ≥1），免疫学标志是**抗 Ro/SSA、抗 La/SSB**。
- 临床表现分三层：**口/眼干燥**（表面）、**系统受累**（关节、肺、肾、神经——里子）、**淋巴瘤风险**（约 10–15 倍——底线）。
- 口干 ≠ SS：需先排除药物、放疗、糖尿病等常见可逆原因。
- 诊断用 **2016 ACR/EULAR 标准（≥4 分）**：活检与抗 SSA 各 3 分为两大支柱，客观功能检查各 1 分。
- 治疗是**局部替代 + 免疫调节 + 癌变监测**三层管理；靶向药仍在前夜。

在下一节，我们将进入一个与 SS 共享免疫病理词库、却以「纤维化」为终点的疾病——**系统性硬化症**，看「炎症」如何在更深处变成「结疤」。
