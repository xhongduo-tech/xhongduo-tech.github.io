## 为什么从干燥综合征开始

风湿病里很多「大魔王」以凶险著称，**干燥综合征（Sjögren syndrome，SS）**却以「温和」的面孔出场：口干、眼干、疲惫——听起来像亚健康。但这是一张伪装：它是最常见、又最常被漏诊的自身免疫病之一，患病率可达 0.1%–0.6%，且背后潜伏着两件大事——**淋巴瘤风险**与**内脏受累**。<span class="marginnote">这个病名来自瑞典眼科医生亨利克·舍格伦（Henrik Sjögren，1899—1986），他在 1933 年把「干燥性角结膜炎 + 口干 + 关节炎」命名为一个综合征。此前它一直被当作更年期或神经衰弱处理——「被当成别的小毛病」恰是 SS 至今的现实。</span>

SS 的病理原型是**外分泌腺的淋巴组织浸润**：淋巴细胞在唾液腺、泪腺里筑巢，腺体逐渐被淋巴细胞「置换」而丧失功能。理解了这个病理，就理解了口干的本质——不是「水喝少了」，而是「腺体坏了」。

## 1 病理与免疫：腺体里的「淋巴细胞殖民」

SS 的核心病变是**灶性淋巴细胞性涎腺炎**：小唾液腺活检中可见以 T 细胞为主、夹杂 B 细胞与浆细胞的密集浸润灶。<span class="marginnote">病理上用一个数字量化浸润强度：<strong>聚焦评分（focus score）</strong>= 每 4 mm² 腺体组织中的淋巴细胞灶数，≥1 即阳性（一个灶 ≈ 50 个以上淋巴细胞）。这个「数细胞计数」的评分把组织病理变成可重复的诊断证据——与 DAS28、SLEDAI 一样，是「把主观现象数字化」的临床科学实践。</span>

浸润细胞分泌的细胞因子（IL-21、BAFF 等）驱动 B 细胞活化，产生两种标志性自身抗体：**抗 Ro/SSA** 与**抗 La/SSB**。抗体靶向细胞内的 RNA 结合蛋白（Ro60、Ro52、La/SS-B），这些蛋白在凋亡细胞表面「被翻出来」暴露——再次呼应第一篇「凋亡碎片暴露自身抗原」的主题。

**为什么唾液腺会持续浸润？** 学界认为是「腺体自身的遗传易感性 + 外源性触发（病毒感染如 EBV、CMV 的分子模拟）+ 凋亡清除障碍」三者叠加。浸润一旦建立，就进入「淋巴细胞堆积 → BAFF 升高 → B 细胞克隆扩张 → 更强烈的自身免疫」的正反馈。

## 2 临床表现：干燥是表面，系统受累是里子

**口干燥症（xerostomia）**：口干需频繁饮水、干食难咽、舌面裂纹、猖獗龋齿（牙釉质快速破坏是 SS 的标志性后果）。**眼干燥症（xerophthalmia）**：眼干、异物感、畏光、泪液减少。

但 SS 绝不止于「干燥」：

**系统表现（约 1/3 患者）**：关节痛/关节炎、雷诺现象、间质性肺病、肾小管酸中毒（远端肾小管受累）、周围神经病变、紫癜（提示高丙种球蛋白血症或血管炎）。
- **淋巴瘤风险**：SS 患者发生 B 细胞非霍奇金淋巴瘤的风险约为一般人群的 **10–15 倍**，是 SS 最重要的长期风险。<span class="marginnote">风险线索就在前面那条正反馈里：持续的 B 细胞克隆扩张有可能「越线」成为真正的肿瘤。腮腺持续肿大、淋巴结肿大、紫癜、冷球蛋白、补体低——都是预示淋巴瘤转化的警示信号，临床要定期随访筛查。</span>
**继发性 SS**：SS 可与 RA、SLE、系统性硬化症等共存——称「继发性干燥综合征」，约 1/3 的 RA 与 1/4 的 SLE 患者有继发干燥。

**辨析｜易错点：** 口干≠SS。**药物性口干**（抗胆碱能药、抗抑郁药）、**放疗后**、**糖尿病**、**更年期**、**衰老**都是更常见原因。<span class="marginnote">「口干的原因排个序，SS 排在药物、放疗、糖尿病之后」——这是临床思维的排序题：先排除常见、可逆的原因，再考虑自身免疫。SS 的确诊需要客观证据（抗体、活检、腺体功能检查），不能凭主观口干。</span>

## 3 诊断：2016 年 ACR/EULAR 分类标准

2016 年标准采用「加权计分 ≥4」结构，且需排除头颈部放疗、HCV、HIV、淋巴瘤、结节病等继发干燥因素：

| 条目 | 权重 |
| --- | --- |
| 唇腺活检：聚焦评分 ≥1 | 3 |
| 抗 Ro/SSA 阳性 | 3 |
| 眼染色评分 ≥5（角膜荧光素染色） | 1 |
| 泪液分泌试验 ≤5 mm / 5 分钟 | 1 |
| 非刺激全唾液流率 ≤0.1 mL/min | 1 |

有趣的结构：**活检与抗 SSA 各占 3 分，其余客观功能检查各 1 分**——「组织学与特异性抗体」是诊断的两大支柱，主观症状（口干眼干）只作入选前提、不计分。这体现了诊断学的一条原则：**用客观证据说话，主观感受只负责把病人带进门。**<span class="marginnote">2016 标准里值得注意的取舍：<strong>抗 La/SSB 不再单独计分</strong>（它几乎总伴随抗 SSA 出现，特异性冗余）。抗体谱设计的「去冗余」思路，与特征工程里剔除共线性特征的做法异曲同工。</span>

## 4 治疗：无「根治」，但有「管理」

SS 目前没有能「治愈」的靶向药，治疗是分层管理：

**局部替代**：人工泪液、泪点栓、口服刺激（含片）、唾液替代剂——「器官坏了就体外补充」。
- **全身免疫调节**：羟氯喹改善关节痛与疲乏；关节/内脏受累者用 MTX、硫唑嘌呤；重症或血管炎用激素、利妥昔单抗。
- **新靶点**：BAFF/IL-21 通路、共刺激阻断正在临床试验——SS 的靶向时代仍在前夜。<span class="marginnote">SS 的靶向研发比 RA 慢，一个原因是疾病异质性大（「干燥为主」与「系统受累为主」是两个亚群，对药物反应可能相反）。异质性越高，随机试验越难做出阳性结果——这也是第四级《数理统计》里「方差大→检验力低」的临床现实版。</span>
- **癌变监测**：对持续腮腺肿大、淋巴结病、紫癜等高危征象保持警惕，适时行淋巴结活检。

**核心要点表——「干燥」的鉴别诊断**：

| 原因 | 关键线索 | 与 SS 的鉴别 |
| --- | --- | --- |
| 药物（抗胆碱能） | 用药史、停药可逆 | 无抗体、无腺体损害 |
| 放疗（头颈部） | 病史明确 | 腺体萎缩但无炎症灶 |
| 糖尿病 | 血糖高 | 常伴多饮多尿 |
| HCV 感染 | HCV 抗体阳性 | 可有冷球蛋白、肝病 |
| 衰老 | 年龄相关 | 程度轻、进展慢 |
| **干燥综合征** | **抗 SSA/SSB、活检灶性浸润、系统表现** | **自身免疫性腺体损害** |

## 5 小结

- SS 的核心病理是**外分泌腺的淋巴细胞浸润**（聚焦评分 ≥1），免疫学标志是**抗 Ro/SSA、抗 La/SSB**。
- 临床表现分三层：**口/眼干燥**（表面）、**系统受累**（关节、肺、肾、神经——里子）、**淋巴瘤风险**（约 10–15 倍——底线）。
- 口干 ≠ SS：需先排除药物、放疗、糖尿病等常见可逆原因。
- 诊断用 **2016 ACR/EULAR 标准（≥4 分）**：活检与抗 SSA 各 3 分为两大支柱，客观功能检查各 1 分。
- 治疗是**局部替代 + 免疫调节 + 癌变监测**三层管理；靶向药仍在前夜。
