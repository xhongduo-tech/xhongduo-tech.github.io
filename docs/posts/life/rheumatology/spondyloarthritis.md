## 为什么从脊柱关节炎开始

前几篇的主角是自身抗体（ACPA、抗 dsDNA、aPL）——体液免疫的「叛变」。**脊柱关节炎（spondyloarthritis，SpA）**却走了一条完全不同的路：它基本没有特征性自身抗体，核心遗传线索是 **HLA-B27**（MHC-I 分子），炎症的舞台不在滑膜而在**附着点（enthesis）**——肌腱、韧带与骨相连接的地方。<span class="marginnote">SpA 与 RA 形成风湿科的经典对照：RA 是「滑膜主导 + 自身抗体 + 女性偏多」；SpA 是「附着点主导 + 无自身抗体 + 男性偏多」。把这两个病放一起读，风湿病学的坐标系就立起来了。</span>

「脊柱关节炎」不是单一病种，而是一族互相重叠的疾病：**强直性脊柱炎（ankylosing spondylitis，AS）**（原型病）、**银屑病关节炎（PsA）**、**反应性关节炎（ReA）**、**炎症性肠病相关性关节炎（IBD-SpA）**与**未分化 SpA**。它们共享遗传背景、临床表型与治疗策略，故合并论述。

## 1 附着点：炎症的新坐标

SpA 的标志性病理部位是**附着点炎（enthesitis）**：肌腱/韧带插入骨处的无菌性炎症，表现为局部肿痛（跟腱炎、足底筋膜炎即最常见形态）。显微镜下，炎症细胞、新生血管与骨反应交织，最终走向**新骨形成（bony spur）**与**骨性强直**。<span class="marginnote">一个意味深长的对照：RA 的关节破坏以「骨侵蚀」为终点（骨被吃掉），SpA 却以「新骨形成 + 骨性强直」为终点（骨长出来把关节焊死）。同一套炎症级联，在两类病里走出完全相反的骨结局——治疗靶点也因此不同。</span>

中轴（脊柱、骶髂关节）与外周（关节）都可受累。**中轴受累**是 AS 的命门：骶髂关节炎从骶髂关节起步，向上沿脊柱蔓延，椎体间韧带骨化形成「竹节样脊柱」，腰椎前凸消失、胸椎后凸增加——患者脊柱逐渐「板结」。

脊柱影像的演变可以当成「时间轴上的化石」来读：早期只是骶髂关节面的毛糙与侵蚀，随病程出现关节面硬化、间隙狭窄，最终骶髂关节融合；椎体层面，先是**方形椎**（椎体前缘骨炎吸收后轮廓变方），再是 **Romanus 病灶**（椎角骨炎）、**韧带骨赘**（椎体间的骨桥），斑块状骨桥连成一片时就是「竹节样脊柱」。**这个演变序列是「炎症→骨化」的教科书演示**：它解释了为什么治疗要早——炎症期可逆，骨化期不可逆。<span class="marginnote">「竹节样脊柱」这个名字很形象：脊柱像一根被竹子节节包裹的竹竿。临床上它常在 X 线全脊柱片上「一眼」认出来，但那时骨化已经发生——所以现代影像学更看重 MRI 的骨髓水肿（BME），那是在骨化之前就能捕捉到的「活动性炎症」信号。</span>

**外周表现同样常见**：下肢为主的**寡关节炎**（膝、踝）、**指趾炎**（「香肠指」，整个指节均匀肿胀，而非 RA 的关节肿胀）、跟腱附着点炎、足底筋膜炎。把「中轴 + 附着点 + 外周非对称性下肢关节」三件套放在一起，SpA 的临床画像就完整了——它和 RA「上肢对称性小关节」的画像几乎处处相反。

## 2 遗传：HLA-B27 的故事

HLA-B27 是风湿病学里最著名的 HLA 关联：汉族人群约 4%–6% 携带，而 AS 患者中约 90% 阳性。但这个关联「强而不完美」——携带者中仅约 2%–5% 发病。<span class="marginnote">这里要做一个严谨的概率辨析：HLA-B27 阳性把患病风险提高约 50–100 倍（相对风险 RR≈50–100），但绝对风险仍低——「风险大」与「必患病」是两回事。这就是流行病学里「相对风险 vs 绝对风险」的经典教学案例，与第四级《概率论与数理统计》的 RR/OR 概念直接相连。</span>

HLA-B27 致病的分子机制尚未定论，主流假说包括：**关节源性肽假说**（HLA-B27 把某种微生物肽呈递给 T 细胞）、**错误折叠假说**（HLA-B27 重链错误折叠触发内质网应激与 IL-23/IL-17 通路）、**游离重链假说**。<span class="marginnote">「错误折叠假说」尤其有趣：HLA-B27 蛋白天生容易在折叠时出错，内质网应激直接驱动炎症。这提示 SpA 的启动点可能不在「免疫识别错误」而在「蛋白稳态失败」——一个从分子生物学跨界到免疫学的故事，也是第六级《免疫学》与《分子生物学》的交汇点。</span>IL-23/IL-17 轴是 SpA 炎症的核心效应通路，这也解释了为何 IL-17 抑制剂对 SpA 高度有效。

**数字背后的两层风险值得分开看**：假设汉族人群 AS 患病率约 0.2%，HLA-B27 携带者中约 2%–5% 发病，则携带者与非携带者相比，患病风险从约 0.02% 级跳到约 3%——绝对风险提高约百倍（这正是流行病学 RR≈50–100 的来源），但 **97% 的携带者一生不会得 AS**。临床沟通时这两句话必须同时说出口：既不能「阳性=安心」误导筛查，也不能「阳性=恐慌」制造焦虑。这与第一篇「抗体阳性 ≠ 患病」是同一个概率哲学。

## 3 临床识别：炎症性背痛与 ASAS 标准

SpA 的识别入口是**炎症性背痛（inflammatory back pain，IBP）**——与机械性背痛判然有别：

| 特征 | 炎症性背痛 | 机械性背痛 |
| --- | --- | --- |
| 发作年龄 | < 40 岁 | 任何年龄，常见 40+ |
| 起病 | 隐匿、缓慢 | 常急性、与劳损相关 |
| 晨僵 | > 30 分钟 | 短暂 |
| 活动 | **活动后减轻** | 活动加重、休息减轻 |
| 夜间痛 | 后半夜痛醒，需起身活动 | 少见 |

**重点结论：炎症性背痛「休息加重、活动减轻」，机械性背痛恰好相反**——这与 RA 的炎症性关节痛规律同构，是风湿科贯穿始终的第一条判别定律。

2009 年 **ASAS 中轴 SpA 分类标准**：影像（骶髂关节炎）或 HLA-B27 阳性 + 至少 2 项 SpA 特征（炎症性背痛、关节炎、附着点炎、葡萄膜炎、指趾炎、银屑病、炎症性肠病、对 NSAIDs 疗效好、家族史、CRP 升高）。<span class="marginnote">「对 NSAIDs 疗效好」被列为正式分类特征，这一点很实用：如果患者的背痛对 NSAIDs 反应立竿见影，就多一条支持 SpA 的证据——治疗反应本身能反过来当诊断线索，这是临床思维的特色。</span>

影像上，X 线可见骶髂关节炎（关节面侵蚀、硬化、融合）；**MRI 的骨髓水肿（BME）**是活动性骶髂关节炎的敏感标志，可在 X 线改变前多年出现——所谓「非放射学中轴 SpA」。

## 4 治疗：运动是药物，靶向是主力

SpA 的治疗金字塔与 RA 不同——**没有「锚定免疫抑制药」，物理治疗地位极高**：

**所有患者**：**规律运动**（尤其伸展性锻炼）是 AS 管理的基石——因为新骨形成无法逆转，治疗目标是「保持活动度」而非「修好骨」。NSAIDs 用于症状控制。

NSAIDs 在中轴 SpA 里的地位被反复低估：**在 AS 中，NSAIDs 不仅是止痛药，还被多项研究认为可延缓影像学进展（尤其持续规律使用者）**。这与 RA 里「NSAIDs 只是对症」的定位完全不同——同一类药，在两类病中地位悬殊。选择上注意消化道与心血管风险分层（老年人、肾功能不全者慎用），必要时联用质子泵抑制剂；NSAIDs 效果不佳是「升级生物制剂」的正当理由之一，而不必等到骨化发生。<span class="marginnote">「对 NSAIDs 反应好」之所以能进 ASAS 分类标准，正因为中轴 SpA 对 NSAIDs 的反应是「特征性」的——对 NSAIDs 毫无反应的中轴痛，要重新怀疑是不是 SpA。治疗反应反哺诊断，这条思路在风湿科反复出现。</span>
- **生物制剂**：**抗 TNF**（英夫利西单抗、阿达木单抗、依那西普）对中轴 SpA 疗效确切，是第一线生物制剂；**抗 IL-17**（司库奇尤单抗、依奇珠单抗）对有银屑病表现者尤其合适。
- **小分子**：JAK 抑制剂（托法替布、乌帕替尼）在 PsA 与 AS 中获批，提供口服选择。

**银屑病关节炎（PsA）的「皮肤 + 关节」双线管理**是 SpA 治疗里的特色课题：PsA 的外周关节受累（常为非对称性寡关节炎）、指趾炎、附着点炎与银屑病皮损/指甲病变并存，治疗需要「一箭双雕」——**抗 IL-17 与抗 IL-23 等药物在抑制关节炎症的同时也能改善银屑病皮损**，而抗 TNF 家族中依那西普对皮肤改善相对较弱。选药时的「皮肤病反应」因此成为重要考虑因素：**同一种药，可能对「关节」与「皮肤」的疗效不同步**——这要求风湿科与皮肤科协作，把「皮损评分（如 PASI）」与「关节活动度」一起纳入疗效评估。<span class="marginnote">PsA 是「一个病、两个专科」的典型：皮肤科管皮损、风湿科管关节，但它们是同一个免疫轴（IL-23/IL-17）在皮肤与关节的两种表现。跨专科的协同用药，比任何单科「单打独斗」都更高效——这也是现代风湿病学越来越强调「联合门诊」的原因。</span>

**辨析｜易错点：** 抗 TNF 在**炎症性肠病（IBD）**相关的关节炎里需谨慎——依那西普（融合蛋白）可能加重 IBD 肠病，而单抗类（英夫利西单抗）可治疗 IBD。同一家族药物对同一疾病谱的不同成员反应迥异，再次印证「选药 = 选靶点 + 看亚型」。<span class="marginnote">另一个临床难点：<strong>骶髂关节炎与腰椎间盘退变都可表现为腰痛</strong>。MRI 的骨髓水肿 vs 椎间盘退变信号完全不同——影像读片是 SpA 诊断中「机器替人省不了心」的环节。</span>

**「规律运动」具体练什么、怎么练**：AS 的运动处方核心是**脊柱活动度训练**（前屈、后伸、侧弯、旋转的温和拉伸）与**姿势训练**（抗「驼背」的代偿姿势）、**深呼吸/扩胸**（对抗胸廓活动受限）、以及**有氧与肌力训练**（游泳尤其适合——浮力减负且全脊柱活动）。每日 20–30 分钟规律练习优于「偶尔猛练」；目标不是「练得多」，而是「维持活动度、对抗强直趋势」。<span class="marginnote">一个常被忽略的细节：<strong>睡眠姿势也影响 AS 的脊柱曲度</strong>——建议尽量仰卧平躺、睡偏硬床垫、避免长时间蜷缩侧卧，这些「非处方」的日常细节，叠加起来对保持脊柱伸展位同样重要。慢病管理里，「处方外的生活管理」常常与药物同等分量。</span>

## 5 预后与「从脊柱到全身」

AS 的预后高度个体化：多数患者保持工作能力，但未治疗者中轴强直、畸形、骨折风险升高；**葡萄膜炎**（急性前葡萄膜炎）是常见伴随表现，可反复发作。SpA 家族还常与银屑病、IBD 相互交织——同一个免疫背景在不同器官轮流「点火」。

**葡萄膜炎值得单独一提**：急性前葡萄膜炎（单侧、红眼、畏光、视力下降）约见于 1/4 的 AS 患者，且常常先于脊柱症状出现——**一个年轻男性反复「红眼」，要想到查骶髂关节与 HLA-B27**。它多为自限、可用激素眼药水处理，但反复发作可致虹膜粘连、青光眼等后遗症，需眼科与风湿科协同管理。这个「眼睛→脊柱」的关联，是 SpA「多系统疾病」属性的又一注脚。<span class="marginnote">「一病牵多器官」是风湿病学的常态：SpA 连着眼（葡萄膜炎）、皮肤（银屑病）、肠道（IBD）。看到任何一个器官的「异常信号」，都要顺着疾病谱去排查其他器官——这也是为什么风湿科医生要「眼观六路」。</span>

**治疗窗口期的观念**：AS 的骨化不可逆，因此「早期诊断 + 早期干预」的意义在于**在骨化发生之前控制炎症**——生物制剂时代的共识是，中轴症状持续活动、NSAIDs 应答不佳者应及早升级抗 TNF/抗 IL-17，而不是等到 X 线上出现竹节样脊柱才「追悔莫及」。治疗的目标函数是「维持活动度 + 阻止新骨形成 + 保护生活质量」三者的平衡，而非单一的「不痛」。

**SpA 与妊娠：一个常被问到的临床问题**。AS 多见于男性，但女性患者同样不少（比例约 2–3:1）；多数 AS 女性在妊娠期病情相对平稳甚至改善，但**产后常见复发加重**，需产后及时评估是否恢复/调整治疗。妊娠期用药需谨慎：NSAIDs 孕晚期避免、抗 TNF 单抗类孕中晚期可考虑、MTX 与 JAK 抑制剂禁用——与第12篇妊娠期风湿病的用药框架一致。**对育龄 SpA 女性，备孕前的「疾病活动 + 用药规划」评估**与孕期/产后随访，是完整风湿病管理的一部分。

**银屑病关节炎（PsA）的「DIP 豁免」提醒**：与 RA 的 DIP 豁免相反，PsA 恰恰**好累及 DIP（远端指间关节）**并伴指甲病变（凹陷、甲剥离）——「DIP + 指甲 + 银屑病皮损」三件套，几乎可以直接指向 PsA。记住这条「DIP 归属」口诀：RA 豁免 DIP、OA 好发 DIP、PsA 也好发 DIP——**同一个关节，在不同病里的「命运」完全不同**，这正是风湿病鉴别诊断的魅力所在。

**ReA（反应性关节炎）的「感染-关节炎」时间线**也值得一提：它在肠道或泌尿生殖道感染后 1–4 周起病，常为下肢非对称性寡关节炎，可伴尿道炎与结膜炎（Reiter 三联征）。多数 ReA 在数周至数月内自愈，但部分慢性化并与 HLA-B27 相关——「一次感染点燃一簇关节炎」，是「感染与免疫」交织的又一实例。多数治疗以 NSAIDs 与休息为主，慢性者按 SpA 处理。这条「先感染、后关节」的因果线索，也再次呼应第1篇的分子模拟主题——**SpA 家族既是「遗传-免疫」的产物，也是「感染-免疫」的窗口**。

**SpA 与 RA 的「镜像对照」是记忆的锚**：RA 是「滑膜 + 自身抗体 + 女性多 + 骨侵蚀」，SpA 是「附着点 + HLA-B27 + 男性多 + 新骨形成」。把这两个「坐标系端点」背熟，中间的所有炎症性关节病都能找到位置——这正是风湿病学「用对照立体系」的方法。

**核心要点表**（把本章家族成员一次记清）：

| 亚型 | 中轴/外周 | 特征线索 |
| --- | --- | --- |
| 强直性脊柱炎 | 中轴为主 | HLA-B27、骶髂关节炎、竹节样脊柱 |
| 银屑病关节炎 | 外周+中轴均可 | 银屑病皮损/指甲、指趾炎（香肠指） |
| 反应性关节炎 | 外周为主 | 肠道/泌尿生殖道感染后 1–4 周起病 |
| IBD 相关性关节炎 | 外周或中轴 | 溃疡性结肠炎/克罗恩 |
| 未分化 SpA | 不定 | 有 SpA 特征但不满足任一具体诊断 |

## 7 小结

- SpA 是**附着点炎 + 中轴/外周受累 + 无自身抗体**的炎症性关节病家族，与 RA 形成「滑膜 vs 附着点、抗体 vs HLA-B27」的对照。
- **HLA-B27** 关联极强（AS 中 90% 阳性）但绝对风险仍低；IL-23/IL-17 轴是核心效应通路。
- **炎症性背痛**「休息加重、活动减轻」，与机械性背痛相反，是识别 SpA 的第一把钥匙。
- 诊断用 **ASAS 标准**：影像或 HLA-B27 + SpA 特征；MRI 骨髓水肿可早于 X 线多年发现活动性骶髂关节炎。
- 治疗：**运动是基石、NSAIDs 控症、抗 TNF/抗 IL-17 为生物主力**；新骨形成不可逆，故目标是保活动度。

在下一节，我们从「骨骼的强直」转向「腺体的干燥」——一个以口干、眼干为名、却暗藏淋巴瘤风险的病：**干燥综合征**。
