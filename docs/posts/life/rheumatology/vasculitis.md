## 为什么从血管炎开始

前几篇都是「单一诊断」；**血管炎（vasculitis）**则是一整族「以血管壁炎症为共同分母」的疾病。血管是全身的「管道系统」，任何一段管壁发炎都会造成双重后果：**缺血**（管腔狭窄/闭塞，下游器官挨饿）与**破裂/渗漏**（管壁被削弱，出血或瘤样扩张）。因此血管炎的症状像「满天星」——发热、乏力、皮疹、肾脏、肺、神经、关节都可以登场，也是最容易被误诊为感染或肿瘤的病。<span class="marginnote">「血管炎是模仿大师」——它可以装扮成肺炎、肾炎、紫癜、卒中、周围神经病……临床一线几乎每个专科都会遇到它。识别血管炎的诀窍，是在「多系统同时出问题 + 炎症指标高」的组合面前想到它，然后找组织证据（活检或影像）锁定它。</span>

治疗的可及性让这门学问格外重要：**ANCA 相关血管炎从「几乎必死」变成了可长期缓解的慢性病**，靠的正是糖皮质激素 + 免疫抑制/靶向药的诱导-维持方案。

## 1 血管壁炎症的三种「弹药」

血管壁发炎由三种机制驱动，分别对应不同的血管炎：

**免疫复合物沉积**：抗原-抗体复合物沉于血管壁，激活补体、招募中性粒细胞。IgA 血管炎（过敏性紫癜）、冷球蛋白血症性血管炎即属此类——呼应第一篇的 III 型超敏。
- **ANCA（抗中性粒细胞胞浆抗体）**：抗体结合中性粒细胞表面的蛋白酶（PR3 或 MPO），激活中性粒细胞、促其脱颗粒并释放 NET，攻击自身血管壁。<span class="marginnote">ANCA 致病的核心事件是「中性粒细胞被自身抗体反向武装」：本该杀敌的粒细胞，转而破坏自身血管。抗 PR3（c-ANCA 主要靶）与抗 MPO（p-ANCA 主要靶）是 ANCA 相关血管炎的分子指纹。</span>
**直接血管壁损伤（大血管炎）**：巨噬细胞与 T 细胞在血管壁内形成肉芽肿性浸润，如巨细胞动脉炎、大动脉炎——以血管壁的细胞免疫损伤为主。

三种「弹药」可以收成一张对照表，便于记忆与鉴别：

| 机制 | 代表病种 | 组织学/血清学线索 |
| --- | --- | --- |
| 免疫复合物沉积 | IgA 血管炎、冷球蛋白血症 | 血管壁颗粒状免疫沉积；冷球蛋白、低补体 |
| ANCA 介导 | GPA、MPA、EGPA | 坏死性小血管炎、少免疫沉积；抗 PR3/抗 MPO |
| 肉芽肿性血管炎 | GCA、大动脉炎 | 巨细胞/肉芽肿浸润、内膜增厚；影像示大血管增厚 |

**辨别机制不只为「求知」，更为了「对药」**：免疫复合物型常在感染或药物背景下触发，治疗先找诱因；ANCA 型对环磷酰胺/利妥昔单抗反应好；大血管肉芽肿型则以激素与 IL-6 阻断为主。同一个「血管炎」名字下，机制不同、靶点不同、用药不同。

## 2 分类：2012 年教堂山共识（CHCC）按血管大小分

血管炎的第一条分类轴是**受累血管的尺寸**，因为它直接对应临床图景。2012 年 CHCC 按大、中、小血管划分（见下图）：

![血管炎按受累血管大小分类（2012 教堂山共识）](/images/rheumatology/vasculitis-chcc-classification.svg)

**重点结论：分类不是「清单背诵」，而是「看图定位」**——主动脉瘤、无脉、肢体跛行提示大血管炎；皮肤梗死、多发性单神经炎提示中血管；血尿、蛋白尿、肺泡出血（肺肾综合征）提示小血管。<span class="marginnote">「按血管大小分类」背后是解剖决定论：血管大小决定了它能供给什么器官、炎症表现长什么样。把解剖学当成血管炎分类的底层坐标系，读表就从背诵变成了推理。</span>

各类血管炎的代表性特征：

| 类别 | 代表疾病 | 典型线索 |
| --- | --- | --- |
| 大血管 | GCA、TAK | 50 岁以上新发头痛+颞动脉压痛 / 年轻女性无脉症 |
| 中血管 | PAN、川崎病 | 微动脉瘤、肾脏缺血性高血压 / 儿童高热+结膜充血+杨梅舌 |
| 小血管-ANCA | GPA、MPA、EGPA | 鼻窦/肺/肾三联征；哮喘+嗜酸性粒细胞增多 |
| 小血管-免疫复合物 | IgA 血管炎、冷球蛋白血症 | 可触性紫癜+关节痛+腹痛；乙肝相关 |

血管炎也需要「把病情数字化」的工具：**BVAS（伯明翰血管炎活动度评分）**覆盖耳鼻喉、肺、肾、神经、皮肤等九大系统，按症状是否为「新发/恶化」计分，数值高表示活动性强。它既是治疗反应的监测尺，也是临床试验的终点指标。<span class="marginnote">BVAS 与 DAS28、SLEDAI 是一家人：都是「把多系统症状编码成数字」。血管炎的多系统属性最强，所以 BVAS 的器官维度最全——这也解释了为何血管炎的随访最依赖「表单化管理」：器官太多，不表格化必然漏项。</span>影像（CT 血管造影、MRI）与病理（活检）则负责「定位病灶」。

## 3 ANCA 相关血管炎（AAV）：三个病，一套疗法

AAV 包含三种高度重叠的疾病，是血管炎里治疗获益最显著的一组：

**肉芽肿性多血管炎（GPA，原韦格纳肉芽肿）**：上呼吸道（鼻窦炎、鼻出血、鞍鼻畸形）+ 肺（结节/空洞）+ 肾脏（肾炎）三联征；抗 PR3 常见。耳鼻喉的「鞍鼻畸形」最直观：鼻中隔软骨被肉芽肿破坏后鼻梁塌陷，是 GPA 极具特征的体征；而「声门下狭窄」则可危及气道。
- **镜下多血管炎（MPA）**：以肾炎和肺泡出血为主，无明显肉芽肿；抗 MPO 更常见。它的「镜下」指病理上只有微小血管炎、没有大肉芽肿，是相对 GPA 而言的「沉默版」。
- **嗜酸性肉芽肿性多血管炎（EGPA，原 Churg-Strauss）**：**哮喘 + 嗜酸性粒细胞增多 + 血管炎**；抗 MPO 可见。EGPA 常分「前驱期（哮喘/鼻炎数年）→ 嗜酸性粒细胞浸润期 → 系统性血管炎期」三阶段，早期极易被当成「难治性哮喘」。

**辨析｜易错点：ANCA 阳性 ≠ 血管炎。** 药物（肼苯哒嗪、丙硫氧嘧啶）、感染性心内膜炎、结核、HIV 均可导致 ANCA 阳性或肺肾综合征样表现。<span class="marginnote">一个经典的临床陷阱：感染性心内膜炎可以完全模拟 ANCA 血管炎（发热、血尿、ANCA 阳性）——若按血管炎上大剂量免疫抑制，反而会杀死病人。因此 AAV 诊断前必须排除感染，组织活检（肾/肺/鼻窦）是金标准。</span>AAV 确诊靠**组织活检**（坏死性小血管炎 + 肉芽肿）+ 临床特征 + 血清学共同判断。

**AAV 的活检「去哪里取」有讲究**：最常取**肾**（经皮肾穿刺，显示坏死性新月体肾炎，检出率高）、**肺**（经支气管镜/CT 引导，可见结节与毛细血管炎）、**鼻窦**（黏膜活检）；而皮肤紫癜虽然好取，特异性较低。**「活检阴性也不能完全排除 AAV」**——血管炎是「灶性」分布，一块阴性组织不代表全身没事，需要结合临床与影像综合判断。<span class="marginnote">活检的「抽样误差」是诊断学里反复出现的主题：取样点是「样本」，疾病是「总体」，样本不代表总体时会漏诊。临床的应对是「多部位、重复取、结合整体证据」——这也再次说明：诊断是贝叶斯式的证据累积，不是一次性的一锤定音。</span>ANCA 滴度本身不用于监测活动度（治疗中可长期阳性），随访靠临床与 BVAS。

## 4 治疗：诱导缓解 → 维持缓解

血管炎治疗的现代范式是「两阶段」，与肿瘤化疗有同构之处：

**诱导缓解（初始 3–6 个月）**：**糖皮质激素 + 利妥昔单抗（抗 CD20）或环磷酰胺**，迅速扑灭炎症。重症（肺泡出血、急进性肾炎）加血浆置换。
- **维持缓解（1.5–3 年或更长）**：用毒性更低的药物（甲氨蝶呤、硫唑嘌呤、利妥昔单抗重复疗程）防复发，激素逐步减停。<span class="marginnote">诱导用「重炮」（CYC/利妥昔单抗）打歼灭战，维持用「轻骑」（MTX/AZA）打持久战——与第四级《强化学习》里「探索阶段用高随机、利用阶段用高确定性」的策略切换逻辑遥相呼应。医学治疗方案的时序设计，本质是一种控制策略。</span>

**EGPA 的「哮喘底色」需要单独的管理线**：EGPA 患者常年有哮喘与嗜酸性粒细胞增多，血管炎只是其病程的「后段」。治疗上除血管炎的诱导-维持方案外，还需管理**哮喘与嗜酸性粒细胞**：口服激素对哮喘与血管炎「一箭双雕」，近年**抗 IL-5（美泊利珠单抗）**获批用于 EGPA，能在减激素的同时控制嗜酸性粒细胞相关表现。把 EGPA 当作「哮喘 + 嗜酸性粒细胞病 + 血管炎」的三元复合体来管理，才不会被「只看血管炎」所局限。

**血管炎家族里还有「儿童专属」与「药物诱发」两种面孔**：川崎病（详见第12篇）是儿童最常见血管炎，用药（如丙硫氧嘧啶、肼苯哒嗪）可诱发 ANCA 或免疫复合物型血管炎——停药常是关键。把血管炎看作「一个病理机制、多种临床面孔」的谱系，正是本篇贯穿始终的读法：分类是为了「对药」，机制是为了「溯源」。

**复发监测的「红绿灯」**：维持期随访中，「红灯」信号包括新发血尿/蛋白尿、咯血、紫癜、单神经病变、ESR/CRP 复升——出现任何一项都提示复发可能，需及时复查 BVAS 并考虑重新诱导；「绿灯」则是数月稳定、BVAS 归零、炎症指标正常。**给患者一张「复发红灯清单」**，让他们知道什么症状要提前就诊，是血管炎长期随访里最实用的患者教育。
- **大血管炎**：GCA 用糖皮质激素（疗程常需 1 年以上，配合 Tocilizumab 助减激素）；TAK 同法加抗 TNF。

**大动脉炎（TAK）与 GCA 的一处关键不同**：TAK 好发于 **40 岁以下**（尤其年轻女性），又称「无脉症」——因锁骨下动脉受累，患者一侧上肢摸不到脉搏、测不出血压，可伴肢体跛行、头晕（锁骨下窃血）、肾动脉狭窄性高血压。TAK 是「血管壁的慢性进行性炎症」，诊断靠血管影像（CTA/MRA 显示动脉壁增厚、管腔狭窄）；治疗以糖皮质激素为基础，常联合抗 TNF 或甲氨蝶呤，必要时对狭窄段做血管介入/搭桥。**把「年轻女性的难治性高血压 + 上肢无脉」想到 TAK**，是避免漏诊的第一步——这也是「以血管大小分类」的实践价值所在。

**巨细胞动脉炎（GCA）值得单独讲透**：它好发于 **50 岁以上**，典型表现是**新发头痛 + 颞动脉压痛/变硬 + 咀嚼肌间歇性跛行**（咬东西时下颌疲劳），并可伴**风湿性多肌痛（PMR）**——肩、髋带近端肌痛僵硬。GCA 最危险的并发症是**失明**：眼动脉受累可致前部缺血性视神经病变，常在数天内致盲。<span class="marginnote">GCA 是「治疗先行于诊断」的教科书案例：<strong>疑似 GCA 一旦考虑即应开始大剂量激素，不等颞动脉活检结果</strong>——因为迟一天用药就多一天失明风险，而激素治疗几天内不会明显掩盖活检的巨细胞病理。等结果完全确认再治，是拿视力做赌注。</span>诊断靠临床 + 颞动脉超声/活检；治疗是大剂量激素逐步减量，常需 12–18 个月以上。

治疗带来的巨大转变值得单独强调：**AAV 的 1 年死亡率曾高达 80%+，今天诱导-维持方案下完全缓解率约 75%–90%**，死亡主因已从疾病本身转为感染与心血管并发症——这再次验证「少用激素、多用靶向」的现代原则。

**诱导-维持方案里的「抗生素预防」是细节但重要的一环**：因为免疫抑制强烈，AAV 诱导期常用**复方磺胺甲噁唑（SMZ-TMP）预防卡氏肺孢子菌肺炎（PCP）**——PCP 是免疫抑制患者的高致死性机会性感染，预防成本极低而收益极大。这再次说明：重症免疫抑制治疗的成功，不只靠「主力药」，更靠「配套的安全网」（感染预防、疫苗接种、骨保护）。把「治疗」想成「一场需要后勤保障的战役」，是现代风湿免疫治疗的真实写照。

**缓解不等于治愈：复发是血管炎管理的常态。** AAV 缓解后 2 年内的复发率可达 30%–50%（维持期可降低），复发表现可能与首发不同（如首发作肾脏，复发可作肺部）。因此维持期要**规律随访 BVAS、监测血尿/蛋白尿/肾功能、警惕 PR3 滴度回升的「复发预兆」**；一旦复发，常需「重新诱导 + 更换/加强维持药」。血管炎的长期管理，本质上是一场「与复发赛跑」的拉锯战——这正是为什么它需要数年甚至终生的专科随访。<span class="marginnote">复发管理里最实用的教训：<strong>维持期减停药物必须「慢慢来」</strong>——激素与免疫抑制剂的快速撤药是复发最常见的诱因。AAV 的维持常持续 18–24 个月以上，随后逐渐拉长给药间隔，而不是「好了就停」。慢性病管理的节奏感，在这里体现得淋漓尽致。</span>

**IgA 血管炎（过敏性紫癜）值得单列**：它好发于儿童，典型四联征为**可触性紫癜 + 关节痛 + 腹痛/消化道出血 + 肾受累**（血尿、蛋白尿），常在上呼吸道感染后 1–2 周出现。多数病例自限（数周缓解），但**肾脏受累者需长期随访**——约 1/3 患者有肾脏受累，少数进展为慢性肾病。治疗以对症为主，重症（明显消化道出血、肾炎）用激素/免疫抑制。IgA 血管炎是「儿童最常见的血管炎」，「多数良性、少数伤肾」的预期管理尤其重要。

## 6 小结

- 血管炎是「**血管壁炎症 + 缺血/破裂**」的疾病家族，临床表现多系统、极易误诊；识别入口是「多系统病变 + 炎症指标高」。
- 分类第一轴是**血管大小（2012 CHCC）**：大/中/小血管各有代表病与典型线索，解剖决定临床。
- **ANCA 相关血管炎**（GPA/MPA/EGPA）由抗 PR3/抗 MPO 驱动，肺肾综合征是其典型图景；**ANCA 阳性 ≠ 血管炎**，须排除感染并以活检为金标准。
- 治疗范式是**诱导缓解 → 维持缓解**：激素 + 利妥昔单抗/环磷酰胺歼灭炎症，MTX/AZA 维持防复发。
- AAV 从「几乎必死」到「可长期缓解」，是风湿科靶向时代最具戏剧性的胜利之一。

在下一节，我们从血管壁转向骨骼肌——一组以肌力下降与肌酶升高为标志的疾病：**炎症性肌病（皮肌炎/多发性肌炎）**。
