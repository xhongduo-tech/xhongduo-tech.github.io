## 为什么从类风湿关节炎开始

类风湿关节炎（rheumatoid arthritis，RA）是风湿免疫科的「标准模型病」：它有明确的自身免疫靶点（瓜氨酸化蛋白）、可复现的动物模型、可量化的疾病活动度指标，也是靶向生物制剂革命最先登陆的战场。理解 RA 的发病链条，等于拿到了解读后续所有炎症性关节病的钥匙。

RA 也是上一篇《风湿病免疫学基础》的第一个落地案例：耐受失守 → 自身抗体 → 滑膜炎症 → 关节破坏，一条链在临床上被完整兑现。全球患病率约 0.5%–1%，女性约为男性的 2–3 倍，发病高峰在 40–60 岁。<span class="marginnote">女性高发的现象在几乎所有自身免疫病中复现（SLE 约 9:1，干燥综合征约 9:1）。雌激素对 B 细胞与 Treg 的调控、X 染色体免疫基因剂量效应是主流解释，仍是活跃的研究方向。</span>

## 1 发病链：从瓜氨酸化到滑膜「战场」

RA 的自身免疫靶点是被**瓜氨酸化（citrullination）**修饰的蛋白——精氨酸被肽基精氨酸脱亚氨酶（PAD）转化为瓜氨酸。吸烟、牙龈卟啉单胞菌感染（牙周炎）都会增加肺部/黏膜的瓜氨酸化负荷，把「新抗原」暴露给免疫系统。<span class="marginnote">这是一个极漂亮的「环境 × 遗传」故事：HLA-DRB1「共享表位」（shared epitope）等位基因携带者呈递瓜氨酸化肽段的效率更高——遗传给了「枪」，环境（吸烟）给了「弹」。</span>

免疫系统针对瓜氨酸化蛋白产生两种标志性自身抗体：**类风湿因子（RF）**（针对 IgG 的 Fc 段）与**抗瓜氨酸化蛋白抗体（ACPA）**。ACPA 可在临床发病前数年就出现——免疫异常先于症状，这为「预防窗口」理论提供了依据。

**为什么诊断更偏爱 ACPA 而非 RF？** 关键在特异性：RF 在健康人群中阳性率可达 5%–10%（随年龄升高），也见于感染（结核、心内膜炎）、其他自身免疫病（SLE、干燥综合征）——敏感性高但特异性低；ACPA 的特异性约 90% 以上，正常人或非 RA 者极少阳性。因此 **ACPA 阳性比 RF 阳性「信息量大得多」**：它既是 RA 诊断的强证据，也预示更高的骨侵蚀风险与更差的活动度结局——这是「特异性决定临床价值」的又一课。

当滑膜被浸润的 T 细胞、巨噬细胞、B 细胞占领，炎症进入正反馈：巨噬细胞分泌 **TNF-α**、**IL-6**，滑膜成纤维细胞增殖，新生血管形成。

炎症的集结点是**血管翳（pannus）**——一层富含炎症细胞与新生血管的肉芽组织，像「苔藓」一样贴着软骨表面蔓延，分泌基质金属蛋白酶（MMP）降解软骨与骨。<span class="marginnote">血管翳是 RA 破坏力的直接执行者：它分泌的 MMP-1、MMP-3 分解软骨中的 II 型胶原，RANKL 则把破骨细胞激活成「拆迁队」。理解血管翳，就理解了为什么 RA 的影像学损伤一旦出现就难以逆转——所以治疗要「抢在破坏之前」。</span>

**骨侵蚀是 RA 破坏的影像学指纹**。滑膜中的 **RANKL**（破骨细胞分化因子）与 M-CSF 共同驱动单核巨噬细胞分化为破骨细胞，在骨表面「啃」出哈氏陷窝；而**护骨素（OPG）**本应作为 RANKL 的「诱饵受体」中和它——RA 里 RANKL 显著压过 OPG，天平彻底倒向骨吸收。这条通路的量化后果很直观：未经治疗的 RA，影像学骨侵蚀可在起病后 1–2 年内出现，且一旦出现基本不可逆；而抗 TNF 治疗能在数月内显著减缓侵蚀进展速率——这就是第 5 节「抢在破坏之前」的影像学依据。

## 2 临床表现：对称性多关节炎

RA 的经典表型是**对称性、多关节、累及小关节**的炎症性关节炎：

最常受累：双手掌指关节（MCP）、近端指间关节（PIP）、腕关节、跖趾关节（MTP）；**远端指间关节（DIP）通常豁免**——这是与骨关节炎鉴别的关键之一。
- 晨僵：晨起关节僵硬持续 **> 30 分钟**，是炎症性（而非机械性）关节痛的标志。
- 关节外表现：类风湿结节、间质性肺病、继发干燥（Sjögren 样）、血管炎、Felty 综合征（RA + 脾大 + 白细胞减少）。

**类风湿结节**：皮下质硬、多无痛、可活动的结节，好发于受压部位（肘后伸侧、指伸肌腱、枕部、跟腱）。它本质上是「肉芽肿」，中央为纤维素样坏死。结节多数无害，但出现时往往提示 RF 高滴度阳性、病程偏长；约 1/5 患者可见，是 RA 最具辨识度的关节外体征之一。<span class="marginnote">一个反向的警示：若患者在启用甲氨蝶呤后结节「加速增多」（尤其加在肺部），要考虑 <strong>MTX 结节病样反应</strong>——这是「治疗本身制造出新病灶」的罕见陷阱，停用 MTX 后常可消退。</span>

**辨析｜易错点：** 炎症性疼痛 vs 机械性疼痛是风湿科第一条分界线。炎症性疼痛**休息加重、活动减轻、晨僵明显、伴有肿胀**；机械性疼痛则**活动加重、休息缓解、晨僵短暂**。<span class="marginnote">问诊「晨僵多久」是比问「哪里疼」信息量大得多的一个问题——它是把炎症性关节炎从退行性关节病中切出来的第一把刀。</span>RA 的影像学特征（关节间隙狭窄、骨侵蚀、骨质疏松）虽在诊断中重要，但**类风湿关节炎的诊断本质上是临床诊断**，影像只是佐证。

## 3 诊断：2010 年 ACR/EULAR 分类标准

RA 的诊断现采用 2010 年 ACR/EULAR 分类标准，按四大项计分，≥ 6 分即可分类为 RA（需排除其他诊断、且至少一个关节有临床滑膜炎）：

| 项目 | 内容 | 得分 |
| --- | --- | --- |
| 受累关节（1–3 分） | 1 大关节 / 2–10 大关节 / 1–3 小关节 / 4–10 小关节 / >10 关节（含≥1 小） | 0 / 1 / 2 / 3 / 5 |
| 血清学（0–3 分） | RF、ACPA 均阴性 / 低滴度阳性 / 高滴度阳性 | 0 / 2 / 3 |
| 急性期反应物 | CRP、ESR 正常 / 升高 | 0 / 1 |
| 症状持续时间 | < 6 周 / ≥ 6 周 | 0 / 1 |

## 4 公式解析：DAS28 疾病活动度评分

治疗 RA 不能只凭「感觉」，要有一个可重复的数字。最常用的活动度指标是 **DAS28**（Disease Activity Score in 28 joints）：

$$\mathrm{DAS28} = 0.56\sqrt{T28} + 0.28\sqrt{S28} + 0.70\ln(\mathrm{ESR}) + 0.014(\mathrm{GH})$$

分三步拆解：

- **第一步，认识三个输入**：$T28$ = 28 个指定关节的压痛关节数，$S28$ = 肿胀关节数，$\mathrm{ESR}$ = 血沉，$\mathrm{GH}$ = 病人总体健康评估（0–100 mm 视觉模拟标尺）。它把「医生的手」「化验室」「病人的感受」三者编码进一个数。
- **第二步，看变换形式**：$\sqrt{\cdot}$ 与 $\ln(\cdot)$ 都是压缩函数——关节数多时边际贡献递减，ESR 从 20 升到 100 的增幅远小于从 1 升到 20。这保证了量表的「敏感区」集中在轻中度炎症，而不是被极端值绑架。<span class="marginnote">这种「对偏态数据做非线性压缩」的思想，与机器学习里对长尾特征取对数、开根号的预处理完全同构——临床量表是「特征工程」的先驱。第四级《机器学习》里你会看到 log 变换、标准化，思路同源。</span>
**第三步，读结果**：$\mathrm{DAS28} \le 2.6$ 为缓解，2.6–3.2 低活动，3.2–5.1 中活动，$>5.1$ 高活动。治疗的目标是「达标治疗」（treat-to-target）：每 1–3 个月复查 DAS28，据此增减药物，直到缓解。<span class="marginnote">「达标治疗」把 RA 管理从「对症」改造成「盯住一个数字迭代」——临床实践与强化学习里「设定 reward、闭环迭代」的思想惊人地相似。</span>

## 5 治疗：从甲氨蝶呤到生物制剂

RA 治疗遵循「金字塔倒转」的现代路线：早期积极、达标治疗、阶梯升级。

**锚定药物**：**甲氨蝶呤（MTX）** 是 RA 治疗的金标准基石，每周一次小剂量口服，抑制嘌呤/嘧啶合成并上调腺苷抗炎通路。单药起始，是「锚」（anchor）——几乎所有联合方案都挂在它上面。<span class="marginnote">MTX 的「每周一次」给药是药理学上的反常之美：它需要长半衰期代谢物（多聚谷氨酸化 MTX）在细胞内蓄积起效，故不按常规每日给药。这是「给药频率由 PK/PD 决定而非惯例」的活例子。</span>
- **联合传统改善病情抗风湿药（csDMARD）**：加用柳氮磺吡啶、羟氯喹、来氟米特。
- **生物制剂（bDMARD）**：抗 TNF（依那西普、英夫利西单抗、阿达木单抗）、抗 IL-6（托珠单抗）、抗 CD20（利妥昔单抗）、共刺激阻断（阿巴西普）——详见第4篇《抗磷脂综合征与生物制剂治疗》。
- **JAK 抑制剂（tsDMARD）**：托法替布、巴瑞替尼等小分子口服药，靶向 JAK-STAT 通路。
- **糖皮质激素**：桥接治疗（低剂量短期），不做长期依赖。

RA 的预后差异极大：约 10% 轻症自限，多数需持续治疗；未经治疗的 RA 在 10–20 年内出现不可逆关节破坏与功能丧失。

**早期诊断 + 达标治疗 + 生物制剂时代的药物升级，已把「残毁性关节炎」从默认结局改写为罕见结局。**

### 5.1 生物制剂前的「安全检查」

生物制剂的疗效建立在「精确熄灭」之上，但代价是**拆掉特定防线**。因此启用前有一组固定的安全检查，相当于「手术前的知情同意清单」：

- **潜伏结核筛查**：TNF 是肉芽肿形成的关键，抗 TNF 会显著升高结核再激活风险——必须先做 TST/IGRA 与胸部影像，阳性者预防性抗结核治疗后再上药。
- **乙肝/丙肝筛查**：利妥昔单抗清除 B 细胞可致乙肝再激活，HBsAg 或 HBcAb 阳性者需抗病毒预防。
- **感染与恶性肿瘤史评估**：活动性感染、近期恶性肿瘤通常列为相对禁忌。
- **疫苗接种**：灭活疫苗全程可用，减毒活疫苗需在治疗前完成或在停药窗口接种。

**重点结论：前面「净获益」公式的左边再大，右边若藏着未被发现的结核或乙肝，也要先把风险清为零、再谈收益**——生物制剂的安全边界，靠的正是这套前置筛查。

**「缓解」不是「治愈」**：现代 RA 的缓解指「几乎无关节肿胀压痛、化验正常、功能恢复」的临床缓解（如 DAS28 < 2.6 或布尔标准），而非「根除疾病」。达标治疗后可以尝试**逐步减药但很少停药**——多数患者在减停后数月内复发。理解「缓解 vs 治愈」的差别，是接受慢性病长期管理的心理起点，也是治疗目标设定（treat-to-target）的现实依据。

## 7 小结

- RA 的核心机制是**抗瓜氨酸化蛋白免疫应答**：瓜氨酸化 → ACPA → 滑膜炎症 → 血管翳破坏软骨骨。
- 临床表型：**对称性小关节多关节炎 + 晨僵 > 30 分钟**；DIP 豁免是与 OA 鉴别的抓手。
- 诊断用 2010 ACR/EULAR 评分（≥6 分），**本质是临床诊断**，影像/血清学为佐证。
- 活动度用 **DAS28** 定量，公式由压痛/肿胀关节数、ESR、GH 非线性压缩而来；治疗目标是 DAS28 ≤ 2.6 的达标治疗。
- 治疗从**甲氨蝶呤**起始，按「传统 DMARD → 生物制剂 → JAK 抑制剂」升级；早诊早治已改写预后。
