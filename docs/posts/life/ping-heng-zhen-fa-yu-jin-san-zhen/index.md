# 平衡针法与靳三针

平衡针灸与靳三针均为列入国家技术规范推广的现代针灸流派，分别以王文远的脑穴靶点理论、靳瑞的三针组穴体系为核心，在军旅及临床实践中积累了大量的标准化操作与优势病种方案。以《平衡针灸学》《靳三针疗法》与国家中医药管理局百项中医诊疗技术为纲，系统重建从流派渊源、理论基础、取穴手法到标准化规范与临床应用的完整知识框架。

## 对标教材

- 《平衡针灸学》（王文远 主编）
- 《靳三针疗法》（靳瑞 著）
- 国家中医药管理局《百项中医诊疗技术》（平衡针灸、靳三针相关技术规范）
