## 为什么从补体与凝血开始

GTKO 猪消灭了超急性排斥，但临床前实验很快暴露了下一个敌人：**即使没有 α-Gal，猪器官在人体内仍会遭遇补体攻击与凝血紊乱**。原因在于一个经常被忽视的事实——**猪细胞自己的补体调节蛋白和凝血调节蛋白，管不住「人的补体」和「人的凝血酶」**。这在移植学里叫**分子不兼容（molecular incompatibility）**：分子都还在，但「跨物种失灵」了。<span class="marginnote">这与《跨物种免疫屏障》的逻辑互为表里：免疫屏障是「多了敌人」（预存抗体），补体凝血问题是「少了朋友」（调节蛋白失效）。</span>

这一篇是《基因编辑供体猪》里「敲入人类基因」的具体展开：为什么补体调节蛋白 CD46/CD55/CD59 必须敲入？为什么血栓调节蛋白（hTBM）是长生存的关键？回答这些问题，才能理解 2022 年贝内特的心脏为何「先活得好、后死于微血栓」，也才能接住《免疫抑制方案》里「光压免疫不够，还得改供体」的核心论断。

## 1 分子的不兼容：猪的「刹车」拦不住人的「油门」

人体内，每个细胞都靠自身的**补体调节蛋白**给「随时自燃」的补体瀑布踩刹车。但猪的这些蛋白是在猪的进化里被塑形的——**它们识别猪的补体成分很熟练，遇到人的补体却效率低下**。

具体到机制，人的补体一旦在猪内皮表面被激活，会得到以下「绿灯」：

- **C3 转化酶（C3 convertase）**在表面不断生成并裂解 C3 为 C3b；
- 缺少有效的**衰变加速**与**辅因子**作用，C3b 继续沉积、级联放大；
- 最终 C5b-9 **膜攻击复合物（MAC）**在细胞膜上打孔，内皮细胞坏死、脱落。

「为什么不兼容」的根源在于**蛋白序列的跨物种差异**：猪的 CD46/CD55 等蛋白与人补体成分（C3b、C4b）的相互作用面由各自序列决定，猪版本结合人 C3b 的亲和力远低于人版本结合人 C3b。简单说，**调节蛋白与底物的「配对」是物种特异的**——跨物种时配对失准，刹车就失灵了。这种「同源蛋白却互相认不出」的现象，在移植免疫学里处处可见，是理解异种排斥的一把总钥匙。

**重点结论：** 内皮损伤是补体与凝血的分水岭——一旦内皮破损、胶原暴露，血小板与凝血因子立刻被激活。于是「补体失控」很快就升级为「凝血风暴」，器官从「免疫攻击」转入「血栓坏死」。这也是为什么补体与凝血必须放在同一篇讨论：**它们共享同一个引爆点——血管内皮**。

临床上这一点有极其直观的印证：贝内特（2022 猪心）在术后第 49 天出现**舒张期心室壁突然增厚、心脏迅速衰竭**，尸检显示心脏重量近乎翻倍、心肌水肿伴广泛微血管病变——这正是「补体与凝血在移植物内持续对话」酿成的终局。它告诉我们：即使排除了超急性排斥，**补体-凝血这根暗线仍在数周的时间尺度上悄悄侵蚀移植物**，《临床里程碑》一篇会完整复盘这段经过。

## 2 人源补体调节蛋白：给猪装上人的刹车

解决办法非常直接：把人的补体调节蛋白基因敲入猪细胞，让猪内皮表面「换成」能管住人补体的蛋白。核心「三件套」：

| 人源蛋白 | 别称 | 功能 | 补体哪一步被按住 |
| --- | --- | --- | --- |
| CD46 | MCP（膜辅因子蛋白） | 作为 I 因子辅因子，降解 C3b/C4b | C3 层面 |
| CD55 | DAF（衰变加速因子） | 加速 C3/C5 转化酶解离 | C3 转化酶层面 |
| CD59 | Protectin | 阻断 MAC（C5b-9）组装 | 末端通路 |

三者在补体级联的不同高度各挡一道：CD46 与 CD55 拦在 C3 的大放大关卡，CD59 拦在最终的打孔器。<span class="marginnote">临床供体猪大多同时表达 CD46 与 CD55（有时加 CD59），因为只表达一个往往不够——补体瀑布的多级放大意味着「只堵住一处，其他通路照样冲过来」。</span>

**GTKO + hCD46/hCD55 的组合**正是 2000 年代异种移植「黄金标准」：敲掉 α-Gal 阻断天然抗体，装上人补体调节蛋白拦住补体，两者叠加让猪器官在狒狒体内的存活从「天」跃升到「月」。

## 3 公式解析：净补体活性 = 激活 − 调控

补体对猪内皮的实际伤害，取决于激活与调控的**净差值**。用一个最朴素的平衡式表达：

$$A_{\text{net}} = A_{\text{act}} - A_{\text{reg}}$$

- **第一步，读式子**：$A_{\text{act}}$ 是补体在表面的激活强度（由抗体结合、表面 C3b 沉积驱动），$A_{\text{reg}}$ 是调节蛋白压制补体的强度。
- **第二步，代入「分子不兼容」**：猪细胞自身调节蛋白面对人补体时 $A_{\text{reg}} \approx 0$，于是 $A_{\text{net}} \approx A_{\text{act}}$——激活多少就伤害多少。
- **第三步，理解敲入的作用**：敲入人 CD46/CD55/CD59 后，$A_{\text{reg}}$ 从 0 升到与 $A_{\text{act}}$ 相抵，$A_{\text{net}}$ 回落，内皮损伤显著下降。**「装刹车」的本质，是把净伤害从正数压向零**。

这个「激活 − 调控」的框架同样适用于凝血：**促凝（procoagulant）与抗凝（anticoagulant）的平衡一旦被跨物种不兼容打破，血栓就会失控**——这正是下一节的病态。

## 4 凝血失调与血栓性微血管病

补体失守后，凝血系统的跨物种不兼容会接手制造伤害。两个关键环节最典型：

**血栓调节蛋白（thrombomodulin，TBM）不兼容**：人的凝血酶结合猪的血栓调节蛋白后，激活人蛋白 C 的效率极低——而激活蛋白 C 是人体最重要的天然抗凝通路。结果：内皮表面的促凝天平严重失衡，局部不断形成微血栓。

**跨物种的消耗性凝血病**：猪器官释放的促凝因子进入血液循环，持续触发血小板与凝血因子消耗，受者出现血小板减少、纤维蛋白原下降——**消耗性凝血病（consumptive coagulopathy）**。当微血栓广泛堵塞器官内的小血管，就形成**血栓性微血管病（thrombotic microangiopathy，TMA）**：这是异种移植后移植物慢性丢失的头号机制，表现如「肾脏里的小血管被一处处堵死」。

TMA 的微观图景值得记住：**小动脉与毛细血管里布满血小板-纤维蛋白微血栓，内皮肿胀、管腔狭窄，供血区域的实质细胞缺血坏死**。它不像急性排斥那样「大张旗鼓」，而是像「细水长流地憋死器官」——这正是为什么它的诊断常常延迟，等发现时移植物已经大面积不可逆损伤。在异种肾移植的猴实验中，TMA 是导致移植物丢失最常见的病理表现之一。

对策同样是「换刹车」：给猪敲入**人血栓调节蛋白（hTBM）**、人 CD39/CD73（降解促凝的 ATP/ADP，生成抗血小板的腺苷）、组织因子途径抑制剂（TFPI）与内皮蛋白 C 受体（EPCR）。把凝血侧的「刹车件」也列成速查表：

| 人源蛋白 | 抗凝作用 | 靶点环节 |
| --- | --- | --- |
| hTBM（血栓调节蛋白） | 辅助凝血酶激活蛋白 C | 蛋白 C 抗凝通路 |
| CD39/CD73 | 降解 ATP/ADP 为腺苷，抑制血小板 | 血小板活化 |
| TFPI | 抑制组织因子途径 | 外源凝血通路 |
| EPCR | 增强蛋白 C 激活 | 蛋白 C 抗凝通路 |

**狒狒模型里，GTKO + hCD46 + hTBM 的组合配合抗 CD40 方案，心脏移植物中位存活达到 298 天，个别超过 900 天**——这个数字之所以重要，是因为它证明「补体 + 凝血两层刹车都装上」才能支撑长期存活。<span class="marginnote">反过来说，光靠免疫抑制药（即使是最强的新型药物）也无法救活一个「凝血系统在内部不断自毁」的移植物——这就是《免疫抑制方案》里反复强调的「供体遗传学与药物缺一不可」。</span>

## 5 核心对比表：补体与凝血障碍的对照

把两套系统的问题与对策并列，能看清异种移植「工程化供体」的完整逻辑：

| 系统 | 失败原因（跨物种不兼容） | 后果 | 供体工程对策 |
| --- | --- | --- | --- |
| 补体 | 猪调节蛋白管不住人补体 | 内皮损伤、MAC 打孔 | 敲入 CD46/CD55/CD59 |
| 凝血 | 猪 TBM 激活人蛋白 C 效率低 | 微血栓、TMA | 敲入 hTBM、CD39/CD73、TFPI、EPCR |
| 巨噬细胞 | 猪 CD47 不被人 CD47 受体识别 | 吞噬破坏移植物 | 敲入人 CD47 |
| 内皮损伤 | 缺血再灌注、损伤反应 | 器官功能延迟恢复 | 敲入 HO-1 等保护基因 |

这张表的每一行，都对应着临床供体猪里「一个人源转基因」的存在理由。**理解异种移植的供体设计，就是理解这张表为什么会一行一行地变长。**

## 6 延迟异种排斥：超急性之后的第二波

在补体与凝血之间，还夹着一层常被一并讨论的排斥类型——**延迟异种排斥（delayed xenograft rejection）**，又称**急性体液性异种排斥（acute humoral xenograft rejection，AHXR）**。它发生在移植后数天到数周，机制上是**预存与新生抗猪抗体 + 补体 + 巨噬细胞 + NK 细胞**共同作用的复杂混合体：

- 抗非 Gal 表位的抗体结合内皮，激活补体但未达超急性毁灭的强度；
- 内皮损伤诱发凝血激活，微血栓逐步累积；
- 巨噬细胞与 NK 细胞通过 CD47 不兼容、天然杀伤信号识别猪细胞并杀伤。

**要点是：延迟异种排斥不是「一种机制」，而是免疫 + 凝血在同一器官内的协同恶化**。这也解释了一条临床经验——即便用强效免疫抑制，只要供体猪缺乏凝血侧的调节蛋白，移植物仍会因微血栓慢慢「憋死」。因此，GTKO + 人补体调节蛋白 + 人凝血调节蛋白的「三合一」供体，才是支撑长期存活的最小配置。

从宏观结构看，这篇与《基因编辑供体猪》构成一个完整的闭环：**免疫篇回答「删什么」，本篇回答「装什么」**。理解了「装什么」背后的「为什么不兼容」，你就能反过来推断任何一只临床供体猪的每一处编辑存在的理由——这是读临床新闻时最有用的内功。

## 7 小结

- 即使 GTKO 消除了超急性排斥，**补体与凝血仍会因「分子不兼容」持续伤害猪器官**——猪的调节蛋白管不住人的补体与凝血酶。
- 补体对策是敲入人源**CD46/CD55/CD59**：分别拦在 C3 层面、C3 转化酶层面与 MAC 层面，把净补体活性压向零。
- 用平衡式 $A_{\text{net}} = A_{\text{act}} - A_{\text{reg}}$ 可理解「装刹车」的本质：把跨物种不兼容导致的净伤害拉回正常。
- 凝血对策的核心是敲入**人血栓调节蛋白（hTBM）**等，恢复蛋白 C 抗凝通路，防止微血栓。
- **血栓性微血管病（TMA）**与消耗性凝血病是异种移植移植物丢失的主要机制。
- 狒狒模型证明：GTKO + hCD46 + hTBM 叠加抗 CD40 方案，心脏可存活 **298 天（中位）、个别超 900 天**——供体遗传学与免疫抑制缺一不可。

在下一节，我们将把所有技术拼图放进真实的病人身体里，回看那些改变了异种移植历史的**临床里程碑**：从贝内特的 60 天，到 Slayman 的无排斥之死。
