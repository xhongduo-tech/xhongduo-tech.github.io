# 中医地域医学流派（新安/孟河/岭南/海派）

中医地域医学流派以特定地域的自然环境、人文积淀与师承传统为根基，在长期临床实践中形成各具特色的学术思想与临证经验；新安、孟河、岭南、海派四大地域流派拥有系统的医案、医籍与传承工作室，是理解中医各家学说谱系与当代临床传承的重要门径。

## 对标教材

- 王乐匋《新安医学》
- 《孟河医派传承系列》丛书
- 邓铁涛主编《岭南医学史》
- 《海派中医流派传承系列》丛书
- 《中医各家学说》全国中医药行业高等教育规划教材（中国中医药出版社）
