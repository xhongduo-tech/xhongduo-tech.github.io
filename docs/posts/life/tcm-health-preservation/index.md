# 中医养生学（起居/情志/运动/饮食养生总论）

中医养生学是以《黄帝内经》为源头、研究生命规律与衰老机理并指导养生实践的学科，涵盖起居、情志、运动、饮食四大养生领域。学完本专题，即系统掌握中医养生的基础理论、基本原则与四季四时、因人而异的实用养生方法。

## 对标教材

- 《中医养生学》（全国中医药行业高等教育"十四五"规划教材，中国中医药出版社）
- 《黄帝内经·素问》
- WHO《传统医学战略》（2014-2023）
