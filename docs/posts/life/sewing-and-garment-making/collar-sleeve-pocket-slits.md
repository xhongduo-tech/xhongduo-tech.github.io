# 部件工艺：领、袖、口袋、开衩

## 为什么从部件工艺开始

衣服可以看作「衣身 + 若干个部件」的组装：领子、袖子、口袋、开衩。每一个部件，都是「小衣服做一次」——它有自己独立的里外两层、自己的衬、自己的缝制顺序。部件工艺之所以单独成篇，是因为**部件的难点不在缝合，而在定型与对位**：领子要翻折挺括、袖子要圆顺、口袋要方正、开衩要平服。这些细节决定了成衣的「档次感」。学会一个部件，就等于学会了一套「先准备、后组装、再整烫」的工艺模板，而这套模板正是后续整件成衣制作的微缩版。<span class="marginnote">部件工艺在工业上是<strong>工序分解</strong>的产物：一件衬衫被拆成领、袖、身、袋四组工序，分别由不同工人流水完成。理解部件，就理解了流水线的「零件划分」逻辑——和软件工程里「模块拆分、接口对接」是同一思想。</span>

## 1 领子工艺

**领子**是服装的「脸面」，按结构分三大类：**立领**（中式领、旗袍领，领直立不翻）、**翻领**（衬衫领、运动服领，领翻折在外）、**驳领**（西装领，领与驳头相连向外翻折）。<span class="marginnote">领型的决定因素是<strong>领底线弧长与领口的配合</strong>：领底线比领口弧线长，翻折后领就外翻贴服；两线长度关系一变，领型就变。制版时领子的「领底线」与衣身的「领窝弧线」必须匹配，这是装领对位的前提。</span>

**立领**的工艺要点：领里领面都加衬，领口弧线与领窝贴合；立领的**领口弧线**决定领子「立」还是「倒」——弧线直则领直立，弧线弯则领贴颈。<span class="marginnote">立领是「没有翻折」的领：它的合身全靠领口弧线与颈部的配合。<strong>领口弧线的曲率，就是立领的灵魂</strong>——旗袍领的优雅，正在这一道弧线里。</span>

**领座与领面的比例**：领座高度（约 2.5–3 cm）决定领子「包脖子」的程度；领面翻折后的宽度比领座宽约 1 cm，形成「里窄外宽」的层次。<span class="marginnote">领座与领面的宽度关系是「<strong>领座矮、领面宽</strong>」的经典比例——里矮外宽，翻折自然、不勒颈。<strong>比例是领子的第二语言</strong>。</span>

工艺要点有三步：

**第一步，领衬与归拔**：领子要挺括，必须在领面（或领里）烫上**领衬**（粘合衬）。翻领的**领面**要比**领里**大一点（约 0.2–0.3 cm），这样翻折后里层不外露、领子自然内卷贴颈——这叫「**面紧里松**」。

**第二步，缉领**：领面领里正面相对，沿领外口车缝一圈，留出领底线；在弧线处**打剪口**（见裁剪篇），让翻转后弧线平服不起皱。领尖处要**修角**——把领尖的缝份斜剪到离角点 0.2 cm，翻转后领尖才尖挺不鼓。

**第三步，装领**：领子的**领嘴**（领尖处）与衣身领窝的**对位点**（剪口）一一对上，把领底线与领窝弧线缝合，再把缝份修整、压烫。装领失败的最大原因是**领嘴左右不对称**——装领前先在领子上标好中心对位点，两边对称找齐。<span class="marginnote">领子翻折后是否「贴颈」，还取决于<strong>翻折线</strong>的位置：翻折线（领外翻的折痕）定得偏低，领子就「飘」起来不服帖。专业上通过微调领底线弧长来控制翻折线——弧长加长，翻折线下移、领更贴颈。这是领子制版里「差之毫厘、失之千里」的典型。</span>

领子装好后还要**定型整烫**：翻折线处压烫出折痕（领子自然内卷的「窝势」），领面用蒸汽轻烫、领尖垫布防亮。<span class="marginnote">领子的「窝势」是高级感的关键——领子要「往里卷」，而不是「往外翻」或「平趴」。窝势靠两件事：<strong>面紧里松的吃量 + 翻折线处的压烫定型</strong>。整烫时把领子按穿戴状态摆好再压，才能烫出自然的弧度。</span>整烫领子是熨烫工艺里最能看出功力的一个细节（熨烫原理见《熨烫与定型工艺》）。

### 驳领：领与驳头的连体工艺

**驳领**（西装的翻驳领）是领子工艺的进阶：领子与**驳头**（前胸翻折出来的那片）连成一体，翻折线从前领口一路斜到前胸。驳领的难点在**串口线**（领子与驳头拼接的缝线）与**驳头翻折点**。<span class="marginnote">驳领的翻折有一个「止点」：翻折线止于第一颗扣的位置，扣位越低、驳头开得越低。制版时驳头宽窄、串口线高低都要与胸围、肩宽联动——驳领是「领子 + 前片」联合制图的产物。</span>缝制时，驳领的领面、驳头面与挂面（前片里层的延伸）三片要拼合，翻折处**打剪口**、压烫定型，翻折线处的里布要略收（面紧里松），驳头才挺而不翘。

## 2 袖子工艺：袖山与吃势

袖子按结构分**一片袖**（衬衫、T 恤，前弧后弧一体）与**两片袖**（西装、大衣，大小袖片拼接，更贴臂弯）。无论哪种，装袖的核心都在**袖山**——袖片顶端的弧线。

关键概念是**吃势（ease）**：袖山弧线比袖窿弧线**长出一段**，装袖时把多出的量均匀「吃」进袖窿，让袖山微微隆起，肩部圆顺饱满。<span class="marginnote">吃势不是多余的误差，而是设计好的「蓄量」：没有吃势，袖山与袖窿一样长，装出来肩部绷平、抬手受限；吃势太大，肩部鼓包。控制吃势的分布——前后袖山吃多少、袖中吃多少——是装袖技术分水岭。</span>

**装袖顺序**：先在袖山边缘用**疏缝线**抽皱出吃势，把多量均匀分布到袖山弧线上；再把袖子与衣身袖窿正面相对，从袖中点对位（袖中点剪口对肩缝）向两边缝制；缝完检查**袖山圆顺、袖型自然下垂**，再压烫。

### 装袖的四个对位点

装袖要对四个点：**袖中点对肩缝**、**袖前弧对袖窿前剪口**、**袖后弧对袖窿后剪口**、**袖底点对腋下**。<span class="marginnote">四个对位点就是「装袖的接口协议」：每个点都定好「谁对谁」，装出来的袖子才不会前后拧。缝之前先把四个点用珠针或疏缝固定，再机缝——<strong>先定位、后缝合</strong>是装袖不歪的唯一可靠顺序。</span>对位点对不齐，袖子就会「偏前」或「偏后」——穿在身上，袖身扭转、袖口不贴腕，这是装袖最典型的质量问题。

袖口宽度（克夫围度）比腕围**大 2–3 cm**（放松量），扣上扣子后手腕能自由活动又不松垮。<span class="marginnote">袖口宽度是「合腕而不勒」的平衡：太紧勒腕、太松漏风。<strong>袖口的放松量是整件衣服放松量的缩影</strong>——每处都是「净尺寸 + 放松量」的组合。</span>

### 袖口工艺：克夫与袖衩

有克夫的衬衫袖，袖口要做**袖衩**（开口）再装**克夫**（袖头）。顺序：先在袖口后侧开衩、包衩条（见开衩工艺），再把克夫对折加衬，夹住袖口缝合，翻转折边压明线。<span class="marginnote">克夫的里外面长度关系与领子相同：<strong>面大里小</strong>，翻折后克夫自然内卷、不露里布。克夫与袖口长度差一点就会「挤」出皱褶——所以装克夫前，先在袖口均匀抽吃势，让周长匹配。克夫是「小一号的领子」，学会了领子就学会了克夫。</span>克夫上钉扣的位置，与袖衩开口的扣眼对应，扣上后袖口服帖不勒腕。

## 3 公式解析：袖山吃势

吃势多少才合适？它由面料厚度与款式决定，用一条减法式定义：

$$E = L_{\text{袖山}} - L_{\text{袖窿}}$$

式中 $E$ 是袖山吃势，$L_{\text{袖山}}$ 是袖山弧线长，$L_{\text{袖窿}}$ 是衣身袖窿弧线长。以一件女装衬衫为例：

- **第一步，量两段弧长**：纸样上量得袖山弧线 $L_{\text{袖山}} = 42\,\text{cm}$，袖窿弧线 $L_{\text{袖窿}} = 39.5\,\text{cm}$。
- **第二步，求吃势**：$E = 42 - 39.5 = 2.5\,\text{cm}$。
- **第三步，分布吃势**：袖山分三段——袖前弧吃 0.8 cm、袖顶吃 1.2 cm、袖后弧吃 0.5 cm；装袖时把前段多量顺着臂根方向**归**入，后段多量自然放下。

经验区间：**衬衫类 2–3 cm，西装类 3–4 cm，厚料取大值、薄料取小值**。吃势太大时，把袖窿适当开深一点来「吃」掉多余量——这也是袖窿开深能提升活动度的原理。<span class="marginnote">「归」是熨烫工艺里的手法：用熨斗把布「推缩」进一段弧线里，让弧线变短、立体起来。吃势靠「归」来塑形，而不是靠强行拉扯——强拉会破坏布纹，成衣肩部起斜绺。熨烫手法见本专题《熨烫与定型工艺》。</span>

吃势分配完成后，**检验方法**：把袖山与袖窿对位后，用珠针每隔 3–4 cm 固定一点，翻到正面看袖山弧是否圆顺无皱——有皱说明吃势分布不均，拆开重新抽。<span class="marginnote">吃势的检验靠「<strong>珠针固定 + 目测圆顺</strong>」：皱在袖前说明前段吃多了，皱在袖顶说明顶段吃多了。<strong>分布不均的吃势，会在缝合后以皱褶的形式「讨债」</strong>。</span>

## 4 口袋工艺

口袋按结构分三类：**贴袋**（patch pocket，袋布直接贴在衣身表面）、**挖袋**（welt pocket，在衣身上开口，袋口镶袋牙）、**插袋**（inserted pocket，开在缝缝里的口袋，如裤侧袋）。

**贴袋**最容易上手：袋布上口折边，其余三边折出缝份，熨出袋形（袋底两角可做成小圆角），再沿边车缝到衣身上。要点是**袋口折边要加衬或双层**，否则装东西久了袋口松弛变形；车缝到袋口转角处**倒针加固**。<span class="marginnote">贴袋袋布的丝绺要与衣身一致——袋布歪斜，装重物时口袋会「吊角」。还有一个细节：贴袋下口两角要留<strong>袋角加固</strong>（回针多缝两遍），因为这里是受力集中点。贴袋虽基础，却最能检验「对位、熨烫、压线」的基本功。</span>

贴袋的位置用**袋口线**标注：袋口线与胸围线齐平（或按款式下移），左右袋对称。<span class="marginnote">贴袋定位的诀窍：<strong>先定袋口中点、再定左右</strong>——以胸骨中点为基准，袋口左右对称，误差不超过 2 mm。<strong>对称是贴袋的第一观感</strong>。</span>

**挖袋**最见功力：在衣身开口处车缝袋牙（两条布条）与袋布，剪开袋口、翻出袋牙，袋口四角**打剪口到止点**、再车缝固定。挖袋的两个高发问题：**袋角没剪到位导致翻不出直角**，以及**袋牙宽窄不一**。<span class="marginnote">挖袋剪口的止点位置是精度生死线：剪过头，袋角毛边外露；剪不到，袋牙翻不出。专业上常用「剪到离止点 0.1 cm 再补一刀」的两步剪法——先粗剪、再精确到位，避免一步到位剪过头。</span>

挖袋的**袋牙宽度**常规 0.8–1.2 cm，两牙等宽、间距约 1–2 cm；袋牙太宽显笨、太窄易翻出毛边。<span class="marginnote">袋牙是挖袋的「门面」：<strong>两牙等宽、止口齐平</strong>是挖袋的观感底线。车袋牙前先画好等宽标记线，再沿线车缝。</span>

**插袋**开在缝合线上：把袋布夹在两片衣身之间，随缝纫一并缝合，再翻转固定。裤侧袋、西服袋多用此法，工艺隐蔽、外观干净。袋布一般用**薄而滑**的里布（涤纶绸），耐磨且不显厚。

### 袋布：口袋的「里子」

袋布虽看不见，却决定口袋好不好用。袋布选**薄而滑**的里布（涤纶绸），顺手且不显厚；袋布尺寸要**比袋口大一圈**，深度约 15–18 cm（够放进手掌）。<span class="marginnote">袋布的两个硬指标：<strong>尺寸够深、边角圆顺</strong>——太浅放手机容易掉，直角袋底容易钩破。口袋的「内胆」质量，往往比外观更影响一件衣服的耐穿程度。</span>挖袋与插袋的袋布接缝处，都要**锁边**防脱纱，袋口两侧**倒针加固**。

## 5 开衩工艺

**开衩（slit / vent）**是在衣片边缘开一个口子，便于活动与造型，常见于袖口、下摆、侧缝、后中。开衩工艺的核心是**衩口止点**与**衩贴边**。

衩条的长度要**盖过开衩长度 + 2 cm**（上下各留 1 cm 固定余量）；衩条缝制后止口平齐、不露毛边。<span class="marginnote">衩条的余量是「保险段」：<strong>止口处的固定需要额外布料</strong>——余量不足，衩口易开。这与裁剪篇「给缝份和错误留出余量」是同一原则。</span>

开衩处的**缝份处理**：衩口以上的侧缝缝份向衩的方向「分叉」——上段缝份倒向两侧，衩口处缝份各折入衩内，衩口才平服不鼓。<span class="marginnote">开衩的缝份是「<strong>三角分叉</strong>」：在衩口止点处，缝份向两边分散，像裤衩的分叉。<strong>缝份的分叉方向，决定衩口是否平服</strong>。</span>

**袖口开衩**（衬衫袖）：在袖口后侧开衩，用一条**衩条（袖衩条）**包住开口。工艺顺序：先把衩条车在开口一侧，翻转后包住另一侧，衩口止点处**倒针加固**。衩条要裁成斜丝绺（有弹性、易翻折），包好后衩口平整、不毛边。<span class="marginnote">衩条裁斜丝绺的原因：斜丝绺伸缩性大，包过衩口转弯时能「让」出余量、不勒紧；直丝绺的衩条转弯处会起翘、不服帖。这与滚边条必须斜裁是同一个道理。</span>

**下摆开衩**（西装后中开衩）：开衩两侧衣片在衩口上方重叠，衩口处用**暗线**固定止点，衩里衬以**衬条**防止衩口拉裂。<span class="marginnote">开衩止点是受力集中点——坐下、抬手时衩口被反复拉扯。工业上在衩口内加<strong>衬条</strong>或<strong>三角加固</strong>，相当于给应力集中点做补强；这个「应力集中处加垫片」的思路，在结构工程里同样成立。</span>

**开衩的常见位置**：**袖衩**（衬衫袖口）、**后中衩**（西装后摆）、**侧衩**（大衣侧缝）、**前开衩**（旗袍）。<span class="marginnote">开衩的位置就是「活动需求最大的地方」：手臂要抬所以有袖衩，走路要迈步所以有侧衩，坐下要放松所以有后中衩——<strong>开衩是给人体活动预留的余量</strong>，开在哪个方向，取决于那个方向最需要活动量。</span>不同位置的开衩工艺大同小异，掌握「衩条 + 止点加固」这一套，就能举一反三。

**辨析｜易错点**：开衩与省道、剪口一样，都是「给布料开口」，但三者用途完全不同——**省道**开口后缝合（吸收曲面差），**剪口**开口后翻折（让弧线平服），**开衩**开口后保留（供活动）。初学者常把剪口误剪成开衩深度，导致缝合时留出破洞；剪口深度 ≤ 3 mm，开衩长度则按款式定（5–15 cm），两者相差一个数量级。

## 6 小结

- **领子**靠「面紧里松」的吃量翻折，装领对位看领嘴与领窝剪口；翻折线位置决定领子是否贴颈。
- **袖子**的核心是**袖山吃势**：$E = L_{\text{袖山}} - L_{\text{袖窿}}$，衬衫 2–3 cm、西装 3–4 cm，靠「归」塑形不靠硬拉。
- **装袖四对位点**：袖中 → 肩缝、前弧 → 前剪口、后弧 → 后剪口、袖底 → 腋下；先珠针定位、后机缝。
- **口袋**三类：贴袋（最基础，袋角加固）、挖袋（袋牙等宽、剪口到止点）、插袋（开在缝里、袋布用薄滑里布）。
- **开衩**三宝：衩条长度盖过衩口 + 2 cm、止点倒针加固、衩口缝份三角分叉；剪口 ≤ 3 mm、开衩按款式 5–15 cm。
- **开衩与省道、剪口的区别**：省道缝后吸收曲面、剪口翻折让弧线平服、开衩保留供活动——三者「开口」用途完全不同。
- **领子窝势**靠「面紧里松」的吃量 + 翻折线压烫定型；装领失败多半是领嘴左右不对称。
- **克夫是「小一号的领子」**：布条 + 衬 + 对折 + 翻转，学会领子就学会克夫。

在下一节，我们将把部件组装成整件——学习**裙装与裤装制作**：从腰到腿，直筒裙、A 字裙与三种裤型如何走通「量体 → 制版 → 缝制 → 整烫」的完整闭环。
