# 服装纸样基础（原型法/比例法）

## 为什么从纸样开始

测量给出了一组数字，而**纸样（pattern）**把这些数字翻译成可以裁剪的平面图形。这是整个制衣流程的「设计图」：没有纸样，裁布就是盲人摸象；有了纸样，每一片布的轮廓、每一条线的走向都有了依据。纸样制图的流派很多，但万变不离其宗——**都要解决同一个几何问题：把有曲率的人体表面，展开成没有褶皱的平面**。这个「展开」的数学本质，与地图投影、把地球曲面画到平面地图是同一类问题：曲率无法被完全保真，只能靠**省道**与**分割线**去吸收多余的量。理解纸样，就理解了服装设计的发动机。

## 1 省道：平面变立体的秘密

一块平布本是一个平面矩形，怎么才能贴合有胸有腰的人体？答案是**省道（dart）**：在平面上剪去一个三角形（或梭形），再把两条边缝合，平面就被「折」成了曲面。<span class="marginnote">省道的工作原理可以亲手验证：在一张纸上剪下一个楔形口，把剪口两边对齐粘合，纸就从平面鼓成了圆锥面——胸部、肩部的隆起都是这样「省」出来的。剪去的量越大，隆起越高。</span>

**省道（省）**按位置命名：**胸省**（从侧缝或肩线指向胸高点）、**腰省**（在腰围线上收腰）、**肩省**、**领省**、**袖窿省**。省道的**省尖**指向人体最凸的部位，如胸高点；省尖处不能车死，要留 2–3 cm 的「省尖余量」自然消失，否则正面会凸起一个尖点。

省道在缝制时也有讲究：**省缝从宽头缝向省尖**，省尖处针距渐疏、留线尾打结；薄料省缝劈开烫（省量向两边分），厚料省缝倒向一侧。<span class="marginnote">省尖的处理是「不显山露水」的关键：如果省尖缝死成硬点，正面会顶出一个小尖。所以省尖最后 2–3 cm 要<strong>逐渐收小针距、自然消失</strong>——这既是工艺细节，也是「柔化过渡」的通用技巧。</span>

### 省的转移

省道可以移动：**胸省**可以从侧缝、肩线、袖窿、领口任何一个方向打向胸高点，外形随之变化，但立体效果等价——这叫**省的转移（dart manipulation）**。<span class="marginnote">省转移的数学依据是「省量守恒」：无论省开在哪条线上，只要省尖仍指向胸高点、省量不变，折出的锥面就相同。制版时常用「剪开 + 旋转」来移省：沿新省位剪开，把旧省合并（旋转），新省自然张开——这很像机械里的「铰接旋转」，是款式设计的基本手法。</span>把省转移到袖窿，就成了公主线的上半段；转移到领口，领口就服帖。移省是原型法最强大的变形工具。

**分割线（princess seam 公主缝）**也能吸收曲面差：沿曲线把衣片切开再拼合，每一片的平面性更好、线条更流畅。可以说，**省道与分割线，就是纸样处理三维曲面的两件武器**。

公主线之所以「显瘦」，是因为它在视觉上把前片分成两条竖线，腰线被收成两段——竖线拉长了视觉，腰省的量被分割线吸收。<span class="marginnote">分割线是省道的「升级版」：它既吸收曲面差，又提供装饰线条。制版上把省转移到分割线里，等于<strong>用结构线做设计</strong>——这是从「省道的功能」走向「省道的美学」。</span>

## 2 原型法：先立基础，再改款式

**原型（basic block / 原型版）**是人体最基本的立体展开图——不含任何款式因素，只有胸、腰、臀的合体轮廓。**原型法**的流程是：先画出精确的净体原型，再在原型上做加放松量、移省、加长、拼接等改动，得到各式款式的纸样。<span class="marginnote">原型法像编程里的「基类」：先写好一个稳定的基类（原型），款式变化只是子类继承与覆写（改省、改长、改型）。改动都在基类上做，所以比例稳、变形小——日本文化式、登丽美式都是原型法体系。</span>

以女装**半身原型**为例，绘制时以**背长**为纵轴、**半胸围**为横轴建立直角坐标系，再在坐标网格里定出**胸宽线**、**背宽线**、**胸围线**（袖窿深的位置）、**颈侧点**、**肩端点**。原型完成后，衣片上有几个标志性元素：

**袖窿**：前后片合起来构成的弧形开口，是袖子与衣身的分界；
**胸省与腰省**：分别吸收胸部隆起与腰部的差量；
**前中心线与后中心线**：作为对折基准，布纹方向与之一致。

### 制版的工具与步骤

制版工具不多：**比例尺**（按比例放大缩小）、**曲线板/云形尺**（画领窝、袖窿弧线）、**直角尺**、**铅笔与橡皮**（画线用 2H 硬铅，改稿用 HB）。绘图步骤统一为：**定基准线 → 画主要结构线 → 画弧线 → 标注尺寸与布纹 → 加放缝份**。<span class="marginnote">弧线（领窝、袖窿、裆弯）是制版里「画功」所在：曲线板要顺着弧的走势一段段挪动，让弧线圆顺无折点。画弧线最忌「一段弯、一段直」——眼睛要在整条弧线的尺度上判断曲率是否连续。</span>原型的优点是**精确、款式变化自由**；缺点是画起来慢，初学者要先背下一套原型制图数据。

### 纸样上的标注

一张完整的纸样要有**四类标注**：**名称**（哪片布、正反），**布纹线**（带箭头的直线），**对称/对折标记**（虚线或「对折」字样，表示这片布要对折裁剪），**净样/毛样说明**（是否已含缝份）。<span class="marginnote">纸样的标注是「施工图」的图例——没有标注，裁缝只能猜。职业打板师还会标注<strong>省位、剪口、对位点</strong>，以及「归拔方向」的提示，让缝制工人照图施工不出错。</span>

**辨析｜易错点**：纸样分**净样**（不含缝份，轮廓线=成衣线）与**毛样**（已含缝份，轮廓线=裁剪线）。<span class="marginnote">两者的区别直接决定「下剪时要不要加缝份」：毛样照着剪就行，净样必须外放缝份。很多成品纸样自带缝份（毛样），但制版教材的图是净样——<strong>下剪前先看清纸样类型</strong>。</span>

### 缩放与纸样储存

制版图常按 **1:5** 或 **1:10** 缩小绘制，实际使用用**比例尺**放大到 1:1。<span class="marginnote">比例尺的三棱尺上有六种刻度（1:1、1:2、1:5 等），一尺多用途。<strong>放大制图的关键是「先放大基准线，再描弧线」</strong>——弧线直接缩放会失真，要在放大后的坐标里重画。</span>做好的纸样要**标注日期与号型**，折好收存——纸样可反复用，但用久了边缘磨损要复描。

## 3 比例法：直接按比例推算

**比例法**不画原型，而是直接根据**净胸围、领围等主要尺寸**，用一套经验公式把各个制图点一步推算出来。<span class="marginnote">比例法像「写死参数的函数」：把领宽、肩斜、袖窿深都表达成主尺寸（胸围 B、领围 N）的分数或小数倍，代入即得，画图快、适合大批量套用——中式服装传统的「三围一统」结构、职业装打板常用此法。</span>

常用的比例法公式（以衬衫类上衣为例，各家教材系数略有差异）：

**后领宽（横开领）** $\approx \dfrac{N}{5} - 0.5\,\text{cm}$，**前领深** $\approx \dfrac{N}{5} + 0.5\,\text{cm}$；
**袖窿深** $\approx \dfrac{B}{6} + (3\sim7)\,\text{cm}$，宽松衣身取大值、合体取小值；
**前肩斜**约 $20°$，**后肩斜**约 $18°$，也可以用「前后肩端点各下落一个固定量」来定。

用比例法画图时，先定**后中心线**与**上平线**（领口基准线），从上平线往下量出领深、袖窿深，画出领窝弧线与袖窿弧线，再连肩线、侧缝。所有弧线的弧度，教材里都有配套的「定寸」数据，照表取值即可。<span class="marginnote">比例法的系数不是普适常数，而是「用大量人体数据回归出来的经验参数」——不同地区、不同年代的体型，系数要微调。所以老裁缝常说「系数是死的，人是活的」，套公式只是起点。</span>

比例法也有它的**适用边界**：它按标准比例推算，对**特殊体型**（驼背、大肚、溜肩）误差较大——比例公式是「平均值」，平均值的背面就是「不适合特殊值」。<span class="marginnote">所以比例法适合标准体、常规款；遇到特殊体型或合体要求高的款式，还是要回到原型法。<strong>选方法不是看哪个「高级」，而是看哪个「匹配」</strong>——这是贯穿全篇的判断原则。</span>

比例法的公式与定寸，最好**记成自己的「打板速查表」**——不同教材系数有差异，实践后把「最适合自己体型」的系数记录下来，越用越准。<span class="marginnote">速查表是「<strong>个性化的参数库</strong>」：教材给的是平均值，你要的是「自己的值」。<strong>记录是经验的开始</strong>。</span>

## 4 原型法与比例法对照

| 比较项 | 原型法 | 比例法 |
| --- | --- | --- |
| 制图基础 | 先画净体原型，再改款式 | 直接按主要尺寸一步成图 |
| 精确度 | 高，曲面差处理细致 | 中，依赖公式与定寸 |
| 画图速度 | 慢（多一步原型） | 快（代入即得） |
| 款式变化 | 灵活，可自由移省变形 | 受公式结构限制 |
| 适合对象 | 女装、礼服等合体款式 | 衬衫、工装、批量成衣 |

两者的关系不是对立，而是**精度与速度的权衡**：熟练的打板师常「比例起图、原型修正」——用比例法快速起出大形，再用原型思维检查弧线与省道的合理性。<span class="marginnote">两法互补的<strong>实际流程</strong>：先按比例法算出关键点（领宽、袖窿深、肩斜），画出大形；再用原型法的「胸围三分」核对衣片宽度、用弧线板修顺领窝与袖窿。方法不是教条，<strong>以结果为目标，方法只是路径</strong>。</span>

**辨析｜易错点**：原型不是「死版」——它是按标准体画的基础型，个人体型有差异时要**微调原型**（如溜肩体调低肩端点、挺腹体调大前腹省）。<span class="marginnote">微调原型的思路是「先把基础型画对，再按个人差量改」：测量篇的补量数据（落肩、腹围等）就是微调的依据。原型法之所以强大，正因为它在基础型上改——<strong>改的是增量，不是整体</strong>。</span>

## 5 公式解析：胸围的三分天下

纸样制图的一切，几乎都从**胸围怎么分**开始。以半身原型为例，胸围净尺寸 $B$ 加上放松量后，被分给**前片、后片、袖窿**三块：

$$W_{\text{半身}} = \frac{B}{2} + \frac{\Delta}{2} = W_{\text{前片}} + W_{\text{袖窿}} + W_{\text{后片}}$$

式中 $B$ 为净胸围，$\Delta$ 为全围放松量，$W_{\text{半身}}$ 是半身原型所占的横向宽度。以文化式原型为例，取 $B = 84\,\text{cm}$、$\Delta = 12\,\text{cm}$：

- **第一步，求半身宽度**：$W_{\text{半身}} = \dfrac{84}{2} + \dfrac{12}{2} = 42 + 6 = 48\,\text{cm}$。
- **第二步，分配袖窿**：袖窿宽约占半身的 $1/5$ 左右，取 $10\,\text{cm}$，它决定手臂活动的松紧。
- **第三步，分给前后片**：剩余 $48 - 10 = 38\,\text{cm}$，再按「前宽略大于后宽（因胸乳凸起）」分配，约前片 $19.5\,\text{cm}$、后片 $18.5\,\text{cm}$，差值正是被胸省吸收的量。

<strong>核心直觉：袖窿是「挖」出来的，前后片是「包」上去的</strong>。袖窿宽一分，前后片就窄一分——所以修身款把袖窿开小、衣身包紧，宽松款把袖窿开大、衣身放开。理解这道分配式，纸样上每一条竖线的位置就都有了来由。<span class="marginnote">胸围分配的比例并非固定值：不同原型体系、不同胖瘦体型，袖窿占比在 19%–23% 之间浮动。瘦体袖窿占比相对大（体窄），胖体相对小。制版时按体型微调，而不是死记一个数。</span>

**辨析｜易错点**：初学常把「半身胸围」误当成「胸围」，直接在净胸围上取 $B/4$ 当作衣片宽——这一算就把前后片画小了。记住：**净胸围 $B$ 对应的是整件衣服，半身原型只占 $\dfrac{B}{2}$**，分给前后片时用的是半身胸围，而不是整胸围。以 $B=84$ 为例，半身是 $42$，前后片各约 $19\text{–}20$；若误取 $B/4=21$ 当半片宽，前后片就整整小了一半，成衣必然勒身。

### 纸样的复核与试制

纸样画完不等于能用——**复核**看三点：各衣片**对位剪口是否齐全**（肩缝、侧缝、袖窿、装领点）、**布纹线是否标全**、**缝份加放是否一致**。复核无误后，用廉价坯布（白棉布）**试制一件**：假缝试穿，检查松紧与各部位贴服度，再把问题带回纸样修正——这就是工业上的「样品试制」，张文斌《服装工艺学：成衣工艺分册》把它列为生产准备的最后一道工序。<span class="marginnote">试制是「<strong>先小成本试错、再大规模投产</strong>」：做衣服如此，写代码、做产品都是同一个道理——花小代价验证假设，比直接上正片省得多。</span>

## 6 小结

- 省道是「剪去三角形再缝合」，把平面折成曲面；**省尖指向凸点、留 2–3 cm 余量自然消失**。
- **省的转移**靠「省量守恒」：省尖仍指凸点、省量不变，移到哪条线立体效果都等价。
- **原型法**先画净体原型再改款式（精确、灵活、慢）；**比例法**按主尺寸一步成图（快、依赖公式、适合标准体）。
- 原型像「基类」、款式是「子类继承」；比例法是「写死参数的函数」——选方法看「匹配」而非「高级」。
- 制版五步：**定基准线 → 画结构线 → 画弧线 → 标注 → 加缝份**；纸样四标注：名称、布纹、对折、净毛样。
- **胸围三分天下**：半身 $=\dfrac{B}{2}+\dfrac{\Delta}{2}$ 分给前片、袖窿、后片；袖窿是「挖」的，前后片是「包」的。
- **1:5/1:10 缩图 + 比例尺放大**：弧线要在放大后的坐标里重画，别直接缩放。
- 画完**复核三看**、再用坯布**试制一件**——把问题留在坯布上，而不是留在成衣上。
