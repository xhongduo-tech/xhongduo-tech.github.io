## 为什么从适用范围开始

技法可以学得快，但**「什么时候绝不能做」比「怎么做」更重要**。学刮痧、拔罐、艾灸、耳穴、贴敷之前，先学的是边界——哪些人不能碰、哪些部位不能碰、出现什么信号必须停手并就医。<span class="marginnote">《中医养生保健服务规范》第3章之所以单列「禁忌与注意事项」，是因为保健领域的伤害几乎都来自「该停没停」：方向错了尚可纠正，红线破了就不可逆。</span>

本篇是家庭应用的「安全总纲」，后续每一技法还有各自的专项禁忌，但都建立在本篇的通用框架之上。先立住总纲，再学细则。

## 1 适用范围：哪些情况可以做

**中医养生保健**的定位是「治未病」——面向未病、欲病（亚健康）、慢性病稳定期的调理与维护，而不是急性期治疗。落到家庭场景，大致分三类：

**第一类，亚健康状态**：疲劳、失眠、颈肩腰背酸痛、食欲不振、畏寒怕冷等西医体检「查不出问题」却明显不舒服的状态。这是五大技法最擅长的领域。

**第二类，慢性病稳定期的辅助调理**：如哮喘缓解期、慢性胃炎稳定期、痛经、慢性腰肌劳损，在医生确认病情稳定、且本人明确「这是保健而非治疗」的前提下，可辅助调理。<span class="marginnote">「稳定期」三个字是门槛：急性发作期、血糖血压明显波动期，一律不属家庭保健范围，先就医。</span>

**第三类，日常养生维护**：体质平和者的季节性调理、节气保健（如三伏贴、三九贴）、运动后的放松刮痧。

**三个「不」**是适用范围的总括：**不替代治疗**（确诊疾病以医嘱为准）、**不处理急症**（高热、剧痛、出血、昏厥立即就医）、**不做诊断**（只做保健操作，不下疾病判断）。

## 2 禁忌人群：谁绝对不能做

禁忌是本章的核心。先把「绝对禁忌人群」列成对照表，这是硬红线：

| 人群 | 原因 | 处理 |
| --- | --- | --- |
| 孕妇 | 腹部、腰骶部穴位刺激可致流产风险 | 孕期全面停用五大技法（耳穴贴压可咨询医生） |
| 急症患者 | 高热、剧痛、出血、意识障碍 | 立即送医，不操作 |
| 出血性疾病患者 | 血小板减少、血友病、正服抗凝药 | 刮痧拔罐禁做，易致出血难止 |
| 皮肤病患者 | 感染、溃疡、过敏、传染性皮肤病 | 病灶及邻近部位禁做 |
| 恶性肿瘤患者 | 肿瘤部位及体表转移处刺激有扩散疑虑 | 肿瘤区禁做，调养须医生指导 |
| 严重心脑血管病 | 心衰、急性心梗、血压急骤波动 | 慎用，重手法一律禁用 |
| 极度虚弱者 | 大出血后、久病卧床、空腹过久 | 先补益、轻手法或暂停 |
| 醉酒、过饱、过饥、情绪激动者 | 气血躁动，操作易晕厥 | 休息至状态平稳再做 |

**相对禁忌**则要看状态：体质辨识中阴虚火旺者慎灸，特禀质者慎贴敷，月经量大的女性经期暂停刮痧、拔罐于腰腹。相对禁忌不是「绝不可以」，而是「必须权衡、手法从轻、时间从短」——拿不准时，按「不做」处理。

## 3 禁忌部位：哪些地方不能碰

除了人群，还有部位红线。五大技法的操作部位各有禁区，通用规律如下：

**危险三角区与血管浅表处**：头面、颈部两侧、腋窝、腹股沟等血管神经丰富处，刮痧、拔罐一律慎重；面部美容刮痧须专业培训，家庭不做。**胸腹内脏区**：心前区、胁肋部禁重手法刮痧拔罐；腹部以轻揉、艾灸为主，不做走罐。**骨突与凹陷处**：锁骨、肩胛骨、棘突、踝部等骨面突出处不宜拔罐，易吸附不牢或损伤。<span class="marginnote">「皮薄肉少、血管密布」是判定危险部位的八字口诀：耳朵、眼周、乳头、肚脐（神阙可灸不可刺）、会阴，都属此列。</span>

**脊柱正中线**：督脉行于脊柱棘突上，棘突尖处皮薄、不宜直接重刮，刮痧应在脊柱两侧的膀胱经进行——这也是「刮两侧、不刮正中」的通行做法。**体表痣、疣、疤痕处**：凸起的痣与疣不宜直接操作，防止破溃感染。

## 4 操作安全通则：六大注意

进入实际操作前的通用注意事项，来自《中医养生保健服务规范》第3章对操作安全的要求：

- **操作前**：询问既往史、过敏史、出血史；检查皮肤有无破损感染；交代操作过程中的体感（酸胀热为正常，剧痛要停）。
- **环境**：温暖避风，室温保持 22–26 ℃，避免操作时受风着凉。
- **清洁**：刮痧板、罐具、艾灸工具一人一用或严格消毒；操作部位先用温水清洁。
- **手法**：由轻到重、循序渐进，先试探性操作 1–2 分钟观察反应，再决定强度。
- **时间与频率**：各技法都有建议时长与间隔（具体见各篇），宁少勿多、宁疏勿密。
- **操作后**：避风保暖、适当饮温开水；出痧后 4–24 小时内不宜立刻洗冷水澡，灸后避免立即喝冷饮。

## 5 危急信号：停手并就医的五个「必须」

这是本章最重要的内容。操作中或操作后出现下列信号，必须**立即停止**并视情况就医，不能「再看看」：

1. **晕厥先兆**：面色苍白、出冷汗、头晕心慌、恶心——立即平卧、松开衣领、饮温糖水，休息观察。
2. **剧痛或明显不适**：操作部位出现撕裂样痛、锐痛，或远隔部位放电样麻感，立即停手。
3. **皮肤异常**：起大疱、破溃化脓、水疱超过 3 厘米或感染迹象，冷处理并就医。
4. **全身反应**：呼吸困难、皮疹广泛、发热、心悸明显——可能是严重过敏或刺激反应，就医。
5. **原有症状加重**：保健后原有不适不轻反重、甚至出现新症状，说明方向或力度有误，停手求医。<span class="marginnote">把这五条抄在家庭药箱盖上也不为过：它们覆盖了晕厥、烫伤、感染、过敏、误判五类最常见的家庭操作风险。</span>

## 6 家庭操作前问询清单

把全篇的禁忌浓缩成一张「**操作前逐项问询清单**」，每次动手前过一遍，能拦住绝大多数风险：

| 问询项 | 通过标准 | 不通过则 |
| --- | --- | --- |
| 孕妇？ | 否 | 停做，腹部腰骶绝不做 |
| 正在发热或急症？ | 否 | 立即就医 |
| 有出血性疾病或服抗凝药？ | 否 | 刮痧拔罐禁做 |
| 皮肤有破损、感染、过敏？ | 否 | 病灶及邻近禁做 |
| 有肿瘤或严重心脑血管病史？ | 明确告知并遵医嘱 | 重手法禁用 |
| 空腹、过饱、醉酒？ | 进食后 1 小时、未饮酒 | 休息至状态平稳 |
| 情绪激动或极度疲劳？ | 情绪平稳 | 先休息 |
| 被操作者保持清醒？ | 清醒、能随时反馈体感 | 不施灸、不操作 |
| 操作环境温暖避风？ | 室温 22–26 ℃、无穿堂风 | 调好再开始 |
| 工具清洁、介质齐备？ | 一人一用或已消毒 | 消毒后再用 |

这十条不是流程主义——它把「该不该做」从「感觉」变成「可勾选」。**任何一条不满足，最安全的答案都是「今天先不做」**。保健操作晚做一天没有损失，做错了却可能伤身。

**问询的艺术**：问询不是审问。家人之间要坦诚——尤其「出血史、慢性病、正在服用的药」这类信息，往往被当作「小事」忽略，却恰恰是决定禁忌的关键。**把问询变成例行程序，比记住十条禁忌更有用**。

再补一张**「哪些情况先别做、先做什么」**的决策表，把总纲落到场景：

| 情况 | 正确处理 | 原因 |
| --- | --- | --- |
| 皮肤有瘀青但无破损 | 避开瘀青处，可做其他部位 | 瘀青区血管脆弱 |
| 感冒初起（风寒） | 可轻刮大椎、肺俞 | 解表散邪 |
| 发热、咽痛明显 | 停做，就医 | 风热之证忌刮罐 |
| 空腹或刚吃饱 | 饭后 1 小时再操作 | 气血波动易晕 |
| 经期 | 暂停腰腹操作，可轻刮四肢 | 经期气血下行 |
| 刚运动完大汗 | 休息 30 分钟、补水后再做 | 汗出腠理开，易受寒 |
| 服药期间 | 先问医生是否可做保健 | 部分药物影响出血凝血 |

这张表的价值在于「**把禁忌变成可执行的判断**」：遇到情况先查表，而不是凭记忆硬闯。家庭保健的安全，就是这样在「一次决策一次谨慎」中积累起来的。

## 7 小结

- **适用范围** = 亚健康、慢性病稳定期、日常养生三类；三个「不」：不替代治疗、不处理急症、不做诊断。
- **绝对禁忌人群**：孕妇、急症、出血倾向、皮肤病、肿瘤、严重心脑血管病、极度虚弱、醉酒过饱过饥。
- **禁忌部位**：头面颈侧、胸腹内脏、骨突凹陷、脊柱正中、痣疣疤痕——「皮薄肉少、血管密布」八字判断。
- **操作通则**：问史、避风、消毒、渐进、控时、保暖，六条逐项落实。
- **五个「必须」**：晕厥、剧痛、皮肤异常、全身反应、症状加重，任一出现即停手就医。
