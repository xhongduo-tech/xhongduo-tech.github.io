## 为什么从贴压与按摩开始

耳穴疗法的刺激方式有很多种——针刺、埋针、贴压、按摩。家庭场景下，**贴压与按摩**是无创、无痛、可自学的两个主力：贴压用「王不留行籽」持续刺激数日，按摩随时可做、无需任何耗材。<span class="marginnote">针刺耳穴需专业医师且耳廓软骨处针刺风险高，埋针有感染顾虑——《中医养生保健技术操作规范》耳穴部分对家庭最友好的正是贴压与按摩两类，这也是本专题只教这两法的原因。</span>

这一篇把贴压的完整操作步骤、按压的方法与频次、以及一套耳穴按摩法讲清楚。

## 1 贴压材料：王不留行籽与磁珠

**耳穴贴压**：用胶布将药籽或磁珠固定于耳穴上，通过按压刺激穴位的一种疗法，也称「埋豆」「压丸」。

贴压的核心材料是三样：

**药籽**：最常用的是**王不留行籽**（中药，直径约 1.5 毫米的小圆籽），硬度适中、取材方便、刺激性温和，是家用首选。其次有绿豆、决明子等替代。

**磁珠**：小磁珠（直径约 1 毫米），借磁力与压力双重刺激，适合需要更强刺激者；有心脏起搏器者禁用磁珠。

**胶布**：医用透气胶布，剪成 **0.5–0.6 厘米见方**的小方块，用于固定药籽。皮肤敏感者可用防敏胶布。

**自制贴压丸**：取一小方块胶布，中央放一粒王不留行籽，将胶布四角向籽内收拢捏实即可——这就是一个「耳穴贴」。成品耳穴贴市面亦有售，自制更卫生可控。<span class="marginnote">自制耳穴贴的要点：胶布别剪太大（0.6 厘米见方足够）、籽要粘牢在胶布中央、贴前双手与耳廓用酒精棉清洁消毒——卫生是贴压安全的第一前提。</span>

## 2 贴压操作步骤

耳穴贴压的规范流程分六步：

1. **选穴**：按上篇的取穴规律选定 3–5 穴，主穴 + 配穴组合。
2. **找点**：用探棒在选定穴区找敏感点（压痛明显的点），做好标记。
3. **消毒**：用 75% 酒精棉球清洁耳廓皮肤，待干。
4. **贴压**：用镊子夹取准备好的耳穴贴，对准敏感点贴牢，稍用力按压片刻使其粘实。
5. **按压**：贴好后当场按压每穴 30–60 秒，以**酸、胀、麻、热感**（得气感）为度。
6. **交代**：告知被操作者保留时间与自我按压方法（见下节）。

**保留时间**：一般**每侧贴压保留 3–7 天**；夏季出汗多、易脱落，可缩短至 2–3 天。**左右耳交替**：先贴一侧，3 天后换对侧，让皮肤与穴位都有恢复期。<span class="marginnote">贴压保留时间不是越久越好：胶布长期贴同一处皮肤，汗液浸渍易致皮疹。3–5 天一换、双耳交替，是兼顾刺激持续性与皮肤健康的通行做法。</span>

## 3 按压方法与频次

贴压之后，真正的刺激来自**每天多次的自我按压**，方法比贴上更重要：

**按压方法**：以拇、食两指分置耳廓前后，**食指在贴压籽上垂直按压、拇指在耳背抵住**，两指相对用力，按至酸胀感出现。每穴按压 **20–30 下（约 1 分钟）**。

**按压频次**：**每天按压 3–5 次**，早中晚各一次或想到就按；急性症状（如疼痛发作）可随时加按。

**按压强度**：以**能耐受的酸胀感**为度，不求剧痛——「有感觉才有效，痛到受不了反而伤耳」。按压后局部微红属正常，红肿疼痛说明刺激过度，应减轻力度或减少频次。

**常见错误**：贴完就不管、每天只贴不按（刺激量不足）；或一按按到红肿起泡（刺激过度）。正确做法是「贴上常按压、每次 1 分钟、每天三五回」。

## 4 耳穴按摩：随时随地的保健

耳穴按摩不依赖任何耗材，双手就是工具，是**把耳穴保健融入日常**的最佳方式。一套完整的家庭耳穴按摩分四步：

**全耳揉搓**：双手掌摩擦发热后，捂住双耳做前后搓揉，自耳廓根部向耳垂方向反复 20–30 次，至耳廓发热发红。这一步相当于「预热」整个耳廓，激活全部穴位。<span class="marginnote">「以掌搓耳至热」是中医养生里最普及的耳保健法之一，常与「鸣天鼓」（掌心压耳、手指弹枕骨）配合做，可用于晨起醒神、睡前安眠。</span>

**重点穴位点按**：按上篇的常用穴表，用拇食指对捏或圆头笔帽点压神门、皮质下、心、肝、肾等穴，每穴 20–30 下，以酸胀为度。这是「精准刺激」环节，与贴压的选穴逻辑一致。

**捏提耳尖与耳垂**：拇食指捏住耳尖（耳轮顶端）向上提拉 10–15 下，再捏耳垂向下轻拉 10–15 下。耳尖主清热、耳垂主头面，这一提一拉是简易的「醒脑明目」法。

**搓耳背**：耳背分布有降压沟等穴位，用食指指腹沿耳背自上而下搓 10–20 下，对血压偏高、头目不爽者尤佳。

**按摩频次**：每天 1–2 次，每次 5 分钟左右，睡前、晨起、工作间隙皆宜。耳廓有破损、冻疮、炎症时暂停按摩。

## 5 常见误区与安全

耳穴贴压与按摩看似温和，仍有几条必须守住的边界：

**误区一：贴得越多越好**。耳廓就那么大，贴满几十个穴既不舒服也无效。家庭贴压**单耳 3–5 穴**足够，主穴配穴搭配即可。

**误区二：越痛越有效**。耳穴刺激以酸胀为度，剧痛、锐痛不是「通了」而是「伤了」。按至红肿甚至起疱，说明强度过头，应立即减轻。

**误区三：贴一次管一辈子**。耳穴刺激是「累积调节」，需要按疗程规律使用；慢性症状（如失眠、痛经）应连续 2–4 个疗程（每疗程 3–5 天、中间休息 1–2 天），再评估效果。

**安全红线**：

- **耳廓皮肤破损、冻伤、湿疹、感染者**禁贴压禁按摩。
- **孕妇**慎用耳穴，尤其避开子宫、卵巢、内分泌等敏感穴，须医生指导。
- **晕厥先兆**（头晕、心慌、面色苍白）立即停按、停贴，平卧休息。
- **胶布过敏**者换防敏胶布，出现瘙痒皮疹立即揭去。
- 磁珠贴压**装有心脏起搏器者禁用**。<span class="marginnote">耳穴贴压的「得气感」是判断刺激是否到位的标尺：酸、胀、麻、热感兼有，说明刺激量合适；只有痛感而毫无酸胀，往往提示位置或力度不对。</span>

## 6 贴压与按摩的自查清单

操作是否规范，用一张自查清单逐项打钩：

| 项目 | 规范要求 | 自查结果 |
| --- | --- | --- |
| 选穴 | 单耳 3–5 穴、主穴配穴组合 | 是 / 否 |
| 找点 | 探棒轻压、找敏感点并标记 | 是 / 否 |
| 消毒 | 75% 酒精棉清洁耳廓、待干 | 是 / 否 |
| 贴压 | 药籽对准敏感点、贴牢不翘边 | 是 / 否 |
| 按压 | 每穴 20–30 下、酸胀为度 | 是 / 否 |
| 频次 | 每天 3–5 次、急性可加按 | 是 / 否 |
| 保留 | 3–5 天、左右耳交替 | 是 / 否 |
| 观察 | 红肿瘙痒即揭、异常即停 | 是 / 否 |

这张表可以作为**每次贴压后的 30 秒复盘**：哪一项没做到，下一次就改进。耳穴疗法的效果，很大程度上来自这种「把操作标准化」的认真劲——它把「贴了」变成「贴对了」。

**给新手的一条建议**：第一次尝试只贴 2–3 穴（如失眠贴神门 + 心），全程按清单执行，连续贴 3 个周期再评估。**小处着手、按规范执行、坚持周期**，比一次贴满十个穴更容易见效，也更安全。

## 7 小结

- **贴压材料**：王不留行籽或磁珠 + 医用胶布，自制耳穴贴卫生可控。
- **贴压六步**：选穴 → 找敏感点 → 消毒 → 贴压 → 按压 → 交代；保留 3–5 天、左右耳交替。
- **按压方法**：拇食指相对垂直按压，每穴 20–30 下、每天 3–5 次、酸胀为度。
- **耳穴按摩四步**：全耳搓热 → 重点点按 → 提拉耳尖耳垂 → 搓耳背，每天 1–2 次。
- **三条安全红线**：皮肤破损感染者禁做、孕妇慎用、起搏器者禁磁珠；晕厥先兆立即停手。
