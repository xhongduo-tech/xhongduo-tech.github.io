## 为什么从免疫低下宿主开始

前面三篇都在讲「正常防御下」的感染。但感染病学一半的智慧，藏在**防线被拆掉**之后——这时「谁在感染」由「缺了什么」决定。HIV 把这种「由免疫缺陷反推病原体」的逻辑讲得最干净：CD4 细胞数每跌过一个台阶，就有一批新的病原体排队登场。这也正是第一/三篇反复强调的机制、PK/PD 与败血症逻辑的**放大镜**：免疫力缺失时，抑菌药不够用、机会菌反客为主、诊断窗口被压缩。

HIV 感染也贯穿全书：它与病毒性感染、真菌感染、结核、性传播感染四篇直接交织。读懂这一篇，等于拿到理解「免疫缺陷相关感染」的通用框架——它同样适用于化疗、移植、生物制剂导致的免疫低下。

## 1 免疫缺陷的「四缺」分类法

判断免疫低下宿主的感染，先回答一个问题：**缺的是哪一支军队？** 按缺陷类型分四类，各自的病原体谱几乎不重叠：

1. **T 细胞缺陷（细胞免疫）**：HIV/AIDS、移植后、淋巴瘤。常见机会性感染：肺孢子菌肺炎（PJP）、结核、隐球菌、巨细胞病毒（CMV）、弓形虫。<span class="marginnote">T 细胞管的是「细胞内病原体」——它们躲在细胞内靠细胞免疫清除，体液免疫鞭长莫及。所以 T 细胞缺陷对应的病原体全是胞内型，这是靠机制推理病原体的第一条规则。</span>
2. **B 细胞/体液免疫缺陷**：多发性骨髓瘤、慢性淋巴细胞白血病、切脾。常见：荚膜菌（肺炎链球菌、流感嗜血杆菌、脑膜炎奈瑟菌）——荚膜菌主要靠调理吞噬与抗体清除。
3. **中性粒细胞缺乏（粒缺，neutropenia）**：化疗后。常见：革兰阴性杆菌（铜绿假单胞菌、大肠埃希菌）、金黄色葡萄球菌、念珠菌。
4. **补体缺陷 / 脾切除**：脾是清除荚膜菌的滤器，切脾后脑膜炎球菌、肺炎球菌暴发风险骤增。

**重点：** 临床上遇到免疫低下发热，第一反应不是「开广谱药」，而是先问「哪种免疫缺陷」——粒缺发热首推革兰阴性菌覆盖，切脾病人盯着荚膜菌，移植患者防病毒与真菌。病原体是免疫缺陷的「指纹」。

### 非 HIV 的免疫低下：移植与化疗

「四缺」框架同样适用于非 HIV 场景：**造血干细胞移植（HSCT）**的时间线几乎就是一张「感染日历」——移植前粒缺期（革兰阴性菌、念珠菌）、植入期（CMV、EBV、曲霉）、移植后期（肺炎球菌、带状疱疹）；**实体器官移植（SOT）**则靠**免疫抑制方案**决定风险窗口（激素 + 钙调磷酸酶抑制剂 + 抗代谢药），CMV 是移植后最常见的病毒威胁之一，常用「预防性更昔洛韦」与病毒载量监测。<span class="marginnote">移植感染的病原体谱不是随机的，而是<strong>由免疫抑制的「时间 × 类型」决定</strong>：粒缺期盯细菌与念珠菌，细胞免疫压制期盯 CMV 与真菌，体液免疫不足期盯荚膜菌。看懂时间线，就理解了移植病房的预防策略。</span>

## 2 HIV 的时间线：CD4 计数是时钟

HIV 之所以是教科书级的免疫缺陷模型，因为它的免疫损伤**进程清晰、可量化**。HIV 以 CD4+ T 细胞为主要靶点，感染的自然史大致三段：

**急性期**：感染后 2–4 周，病毒大量复制，可呈单核细胞增多症样表现，CD4 一过性下降。
- **慢性期（无症状期）**：病毒与免疫「拉锯」，CD4 缓慢下降，可持续数年。
- **艾滋病期（AIDS）**：CD4 < 200 个/µL，或出现艾滋病定义性疾病（AIDS-defining illness），机会性感染与肿瘤登场。<span class="marginnote">AIDS 的中文全称「获得性免疫缺陷综合征」——注意三个词各有分工：获得性（非遗传）、免疫缺陷（CD4 崩坏）、综合征（表现多样）。1981 年最早报告的病例正是「年轻男性患肺孢子菌肺炎」这一反常事件。</span>

CD4 计数与机会性感染的对应关系，是一张必须刻在脑中的表：

| CD4 阈值 | 高危机会性感染 |
| --- | --- |
| < 500/µL | 结核、带状疱疹、口腔念珠菌 |
| < 200/µL | **肺孢子菌肺炎（PJP）**、弓形虫、隐球菌、进行性多灶性白质脑病（PML） |
| < 100/µL | 播散性鸟分枝杆菌复合群（MAC）、CMV 视网膜炎 |
| < 50/µL | CMV、隐孢子虫、微孢子虫 |

**辨析｜易错点：** 免疫功能低下的**影像与实验室表现常不典型**——PJP 患者胸片可接近正常（要靠 HRCT 与诱导痰），结核可播散而不形成典型空洞。在免疫低下宿主，「症状轻 ≠ 病不重」，诊断阈值必须整体下调。

## 3 治疗原则：防、治、重建的三层结构

免疫低下宿主感染的管理，永远分三层同时推进：

1. **预防（prophylaxis）**：CD4 < 200 用复方新诺明预防 PJP；< 100 加阿奇霉素预防 MAC；CD4 低 + 既往脑炎预防弓形虫。接种疫苗补足体液免疫（注意活疫苗禁忌）。
2. **治疗**：机会性感染的药都是「杀菌 + 覆盖特有病原体」的组合。PJP 首选复方新诺明；隐球菌脑膜脑炎用两性霉素 B + 氟胞嘧啶诱导期；CMV 用更昔洛韦；弓形虫用乙胺嘧啶 + 磺胺嘧啶。这部分与真菌、结核、病毒各篇的用药体系直接对接。
3. **免疫重建（ART，抗逆转录病毒治疗）**：抗 HIV 药物把病毒压下去，CD4 回升，免疫自己接管清除。这是与「对症杀敌」完全不同的策略——**治疗病因**。<span class="marginnote">免疫重建不是一路绿灯：CD4 快速回升时可出现「免疫重建炎症综合征（IRIS）」——免疫恢复后对潜伏抗原过度反应，症状反而加重，如隐球菌 IRIS、结核 IRIS。治疗的目标是把 CD4 恢复到「机会性感染阈值」之上，而不是瞬间杀光所有病原体。</span>

**重点：** 三层缺一不可。只治机会性感染不抗 HIV，是「只救火不关闸」；只抗 HIV 不做 PJP 预防，是「门开着时不给锁」。

**补充：** 预防层还有一剂容易被忽略的「疫苗」：活疫苗（麻腮风、水痘）在深度免疫抑制时**禁忌**（可能致病），灭活疫苗（流感、肺炎球菌、HPV）则**强烈推荐**——「疫苗禁忌」与「疫苗指征」的边界，取决于免疫缺损的类型与深度。这与免疫重建（ART）并列，是同一条预防主线的两个支点。

## 4 公式解析：CD4 恢复的驱动力与预测

为什么 ART 能救命？用最简的动力学模型看 CD4 的**崩坏-恢复**逻辑。设 CD4 计数随时间的变化率，粗略写作：

$$\frac{dC}{dt} = \lambda - \delta C - \alpha V$$

- **$\lambda$**：胸腺与外周对 CD4 的补充率——免疫系统的「产能」。
- **$\delta$**：CD4 的自然凋亡/损耗率。
- **$\alpha V$**：病毒载量 V 造成的额外杀伤，HIV 病毒血症是这部分的来源（$\alpha$ 是每个病毒的杀伤系数）。

三步读法：**先看**基线 CD4 由 $\lambda$ 与 $\delta$ 的平衡决定；**再看** HIV 的 $\alpha V$ 项把平衡往下压，压过 200/µL 就进入机会性感染区；**最后**，ART 让 V → 0，$\alpha V$ 项消失，CD4 以接近「产能 − 自然损耗」的速率回升——这就是「治疗目的 = 消除 $\alpha V$ 项」的数学表达。<span class="marginnote">模型告诉我们为什么「一查出来就治」：CD4 恢复的速度赶不上免疫衰竭时，一次机会性感染就可能致命。今天的指南主张「确诊即启动 ART」，正是让 $\alpha V$ 项尽早清零。</span>

举一组数字：若 CD4 基线由「产能 − 自然损耗」决定约为 800/µL，HIV 把平衡压到 150/µL——正落入 <200 的机会性感染区；ART 后病毒项归零，CD4 以每年约 100–150/µL 的速度回升，数月内回到安全线上方。这就是「确诊即启动 ART」的量化依据。

## 5 一个统一的临床框架：发热 + 免疫低下

把三层原则收束成一个临床决策顺序，这就是「免疫低下宿主发热」的思维模板：

1. **定类型**：粒缺 / T 细胞缺陷 / B 细胞缺陷 / 脾切除——直接决定病原体清单。
2. **抢时间**：粒缺伴发热（中性粒细胞 < 500/µL 且体温 ≥ 38.3℃）是急症，评估后 1 小时内启动广谱抗菌药（通常覆盖铜绿假单胞菌）。
3. **找病灶与培养**：血培养、尿、影像、必要时支气管镜/脑脊液——免疫低下者病灶常隐藏。
4. **分层用药**：先广谱救命，再按病原体降阶梯，同时启动预防与 ART。

**辨析｜易错点：** 粒缺发热不能用「观察等结果」策略——粒缺患者中性粒细胞缺乏，炎症反应弱，可能不化脓、不发热显著，但病情已深。这是「无反应 ≠ 无事」的另一面：免疫低下宿主的发热，永远按最坏可能启动。

## 7 小结

- 免疫缺陷**四型**（T 细胞、B 细胞、粒缺、脾切除/补体）决定病原体谱；病原体是免疫缺陷的「指纹」。
- HIV 是量化模型：**CD4 < 200 入 AIDS 期**，PJP、弓形虫、隐球菌依次登场；CD4 越低，病原体越凶。
- 管理分三层：**预防、治疗、免疫重建（ART）**；只治机会菌不抗 HIV 是「只救火不关闸」。
- CD4 动力学 $\frac{dC}{dt} = \lambda - \delta C - \alpha V$：ART 让病毒项 $\alpha V$ 归零，CD4 才有机会回到安全线上。
- 免疫低下宿主**症状与影像常不典型**，发热按最坏可能启动，诊断阈值整体下调。

在下一节，我们将深入免疫低下宿主最常撞见的三大真菌对手——**念珠菌、曲霉、隐球菌**，看真菌为什么偏爱残缺的防线。
