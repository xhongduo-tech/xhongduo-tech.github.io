## 为什么从败血症开始

前面的原理给了疾病三角，抗生素给了武器。但感染最凶险的结局，是把局部战争升级为全身战争——这就是**败血症**。它每年在全球夺走上千万条生命，是 ICU 的头号死因，也是「感染病学」与「重症医学」的接合部。这篇要回答：感染如何变成全身性的？如何在一小时内识别并抢救？抗生素在这里扮演什么角色？

这也是抗生素 PK/PD 一节第一次实战——败血症是**「时间窗」**的教科书：患者死亡风险随时间每小时上升，抢在窗口内给药与补液，是唯一被证实能扭转结局的干预。

## 1 定义演变：从「细菌入血」到「宿主反应失调」

败血症的现代定义经历过一次革命。老定义（1991 年，Sepsis-1）把**菌血症（bacteremia，血培养阳性）**几乎等同于败血症，并把**SIRS 标准**（体温、心率、呼吸、白细胞四项）当成门槛。2016 年的 **Sepsis-3** 定义彻底改写：

**败血症（sepsis）**：因宿主对感染的**失调反应（dysregulated host response）**导致的**危及生命的器官功能障碍**。菌血症既不必要也不充分——败血症可以是任何部位感染（肺炎、尿路、胆道）引起的全身性失调。

**败血性休克（septic shock）**：败血症的亚型，在充分液体复苏后仍存在**持续性低血压**（需血管活性药物维持 MAP ≥ 65 mmHg）且**乳酸 > 2 mmol/L**，代表深层循环与细胞代谢障碍。<span class="marginnote">Sepsis-3 最大的观念转变：不再问「血里有没有菌」，而是问「器官有没有坏」。血培养阴性也可能死于败血症；血培养阳性也可能只是短暂的菌血症——器官功能障碍才是主裁判。</span>

**辨析｜易错点：** SIRS 标准仍常被当作败血症筛查，但它极不特异——烧伤、术后、胰腺炎都能凑满四项。Sepsis-3 建议用 **qSOFA**（收缩压 ≤100 mmHg、呼吸 ≥22 次/分、意识改变）在床旁快速识别高危患者：三项中占两项及以上，提示预后不良，应启动完整评估。注意 qSOFA 是**预后工具**而非诊断工具。

器官功能障碍的量化靠 **SOFA 评分（序贯器官衰竭评估）**：呼吸、凝血、肝、循环、神经、肾六系统各按功能下降程度给 0–4 分，败血症诊断要求 SOFA 较基线升高 ≥2 分。三套标准的定位要分清：

| 工具 | 定位 | 内容 | 一句话 |
| --- | --- | --- | --- |
| SIRS（1991） | 曾经的筛查门槛 | 体温/心率/呼吸/白细胞 | 敏感但极不特异 |
| qSOFA（2016） | 床旁快速识别 | 血压/呼吸/意识 | 预后工具，非诊断 |
| SOFA（2016） | 器官功能障碍量化 | 六系统逐项 0–4 分 | 败血症的诊断依据 |

**辨析｜易错点：** qSOFA 阳性提示预后差，但**阴性不排除败血症**——它牺牲灵敏度换取床旁可行性；重症监护里真正用于「定义器官衰竭」的是完整 SOFA 或其快速版。三把尺子各管一段，不能混用。

## 2 病理生理：一场炎症的雪崩

败血症的本质，是先天免疫的**防御性炎症被自身放大**成失控状态。致病级联大致四步：

1. **病原体信号触发**：病原相关分子模式（LPS、肽聚糖、鞭毛蛋白）被模式识别受体（TLR4 等）识别，激活单核/巨噬细胞。
2. **细胞因子风暴**：TNF-α、IL-1β、IL-6 大量释放，招募更多免疫细胞，正反馈放大。<span class="marginnote">这本是第一篇里「炎症解决感染」的剧本，但败血症里剧本失控了：促炎与随后代偿性抗炎（免疫麻痹）叠加，导致「两头烧」——早期死于过度炎症，晚期死于免疫瘫痪后的继发感染。</span>
3. **内皮与凝血激活**：血管内皮受损、血管扩张、通透性增加，微血栓形成（弥散性血管内凝血 DIC 的起点），组织灌注下降。
4. **细胞缺氧与代谢衰竭**：有氧代谢转向无氧，乳酸堆积；线粒体功能障碍；多器官衰竭（ARDS、急性肾损伤、DIC）成形。

## 3 识别：一个小时决定生死

败血症抢救的胜负手是**识别速度**。国际指南（Surviving Sepsis Campaign）的「1 小时集束化治疗」是最关键的执行清单：

1. **查乳酸**；若初始 >2 mmol/L，复查。
2. **血培养**后再启动抗菌治疗（采血与用药间隔以分钟计，不可颠倒顺序太久）。
3. **广谱抗菌药**尽快使用——按上一节的逻辑，这是时间依赖型 β-内酰胺占主力、再按感染灶与宿主状态补位（如抗 MRSA、抗铜绿假单胞菌）。
4. **补液**：低血压或乳酸 ≥4 mmol/L 时，30 mL/kg 晶体液。
5. **血管活性药物**：补液后仍低血压，启动去甲肾上腺素。

**重点：** 败血症的抗生素给药遵循「**抽完培养立即给，绝不能等结果**」——病原体不明时用**广谱**覆盖最可能病原体，结果回来后**降阶梯**（de-escalation）到窄谱。这与「能窄谱则窄谱」不矛盾：先覆盖救命，再精准缩窄。

**补充：** 乳酸不仅是诊断阈值，也是复苏的「罗盘」——乳酸下降提示组织灌注在改善；持续不降或上升，提示复苏不足或病灶未清，应回头重新评估**源头控制**。

## 4 公式解析：平均动脉压 MAP 与灌注逻辑

败血性休克的治疗目标中反复出现「MAP ≥ 65 mmHg」。MAP 不是收缩压，它是**器官灌注压**的近似值：

$$\mathrm{MAP} = \mathrm{DBP} + \frac{1}{3}(\mathrm{SBP} - \mathrm{DBP})$$

- **SBP / DBP**：收缩压与舒张压。
- **（SBP − DBP）= 脉压**：反映每次心跳的射血幅度；取 1/3 是经验加权，因为心脏周期里舒张期更长。
- 结果 MAP：整个心动周期的平均驱动压——它是肾、脑、冠脉灌注的**上游条件**，所以休克时盯 MAP 比盯 SBP 更可靠。

而 MAP 又由两个「旋钮」决定，这是补液与血管活性药的物理依据：

$$\mathrm{MAP} = \mathrm{CO} \times \mathrm{SVR}$$

- **CO（心输出量）**：补液扩容提升的正是它（前负荷 → 每搏量）。
- **SVR（全身血管阻力）**：败血症早期 SVR 塌陷（血管麻痹），去甲肾上腺素收缩血管、把 SVR 拉回来。

**重点：** 先补液（调 CO），仍不行再升压药（调 SVR），顺序不能反——脱水的病人一上来就用血管收缩药，等于在「空管子里加大水压」，只会进一步牺牲组织灌注。乳酸 >2 mmol/L 且补液后仍依赖升压药，即为败血性休克、需进 ICU。

## 5 治疗的三条时间线

败血症治疗可压缩成三条并行的时间线：

- **黄金小时**：识别 + 血培养 + 广谱抗菌药 + 液体复苏，目标是「把氧送到组织」。
- **源头控制（source control）**：引流脓肿、拔除感染导管、清除坏死组织——这是抗生素无法替代的「拆掉病灶」环节。一个没引流的腹腔脓肿，再好的药也白给。<span class="marginnote">抗生素与外科是盟友：脓腔里细菌密度高、生物膜形成、pH 低，β-内酰胺活性大打折扣（接种量效应，见第二篇）——「用药 + 引流」才能把细菌负荷压到药能打赢的水平。</span>
- **复苏评估与降阶梯**：24–48 小时内按培养结果缩窄抗生素、停用不必要药物、评估液体是否过量。

**辨析｜易错点：** 「广谱抗生素」不等于「永远用广谱」。临床上最大的两个败血症用药错误是：该果断广谱时（休克首小时）犹豫用窄谱，和培养结果明确后（48 小时后）仍不降阶梯——前者送命，后者催生耐药。

## 6 术语速查：败血症的关键词

| 术语 | 一句话定义 | 关键提醒 |
| --- | --- | --- |
| 菌血症 | 血培养阳性 | 不等于败血症 |
| 败血症（Sepsis-3） | 感染 + 失调宿主反应 + 器官功能障碍 | 器官功能是主裁判 |
| 败血性休克 | 复苏后仍低血压 + 乳酸 >2 mmol/L | 需血管活性药维持 MAP ≥ 65 |
| SIRS / qSOFA / SOFA | 三套评估工具 | 各管一段，定位不同 |
| 细胞因子风暴 | 促炎级联正反馈放大 | 早期炎症、晚期免疫麻痹 |
| 降阶梯 | 培养明确后缩窄用药 | 48 小时内完成 |
| 源头控制 | 引流 / 拔管 / 清创 | 药物不可替代 |
| MAP | 平均动脉压 = CO × SVR | 先补液再升压 |
| 液体复苏 | 晶体液扩容提升 CO | 30 mL/kg 起 |
| 去甲肾上腺素 | 首选升压药 | 收缩血管拉回 SVR |
| 器官功能障碍 | Sepsis-3 的主裁判 | SOFA ≥2 分 |

败血症是「时间 + 机制」双重敏感的疾病：时间决定生存，机制决定用药。记住这张表，就是记住 ICU 里争分夺秒的每一环。

## 7 小结

- 现代定义（**Sepsis-3**）：败血症 = 感染 + **失调宿主反应** + **器官功能障碍**；败血性休克 = 复苏后仍低血压 + 乳酸升高。
- 病理级联：**识别 → 细胞因子风暴 → 内皮/凝血激活 → 组织缺氧与多器官衰竭**。
- **1 小时集束化**：乳酸、血培养、广谱抗菌药、补液、血管活性药。
- MAP = DBP + (SBP−DBP)/3 = CO × SVR：先补液调 CO，再升压调 SVR。
- **源头控制**不可被药物替代；48 小时后必须**降阶梯**。

在下一节，战场从「健康人的感染」转向「免疫力残缺者的感染」——**免疫功能低下宿主**，看当先天防线被拆掉时，病原体如何乘虚而入。
