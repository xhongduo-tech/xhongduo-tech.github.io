## 为什么从局部感染综合征开始

前三篇讲了全身性的败血症与免疫低下宿主，这一篇要下钻到**器官**。同样一个「感染」，落在脑膜、心内膜、骨骼还是泌尿道，病原体谱、诊断路径、给药方式完全不同。这四类综合征是临床感染病学最常照面的四个「副本」：**脑膜炎**拼的是速度与脑脊液，**心内膜炎**拼的是血培养与心脏超声，**骨髓炎**拼的是血供与病灶清除，**尿路感染（UTI）**拼的是解剖与复发管理。

它们共享同一套底层逻辑——前面几篇建立的「机制 → 病原体 → 药代」链条，在这四个器官上各演一遍。学会这套「按器官重写感染学」的方法，就学会了感染病学的临床思维。

## 1 脑膜炎：与时间赛跑的脑脊液战役

急性细菌性脑膜炎（ABM）是内科急症——延误几小时就可能死亡或遗留神经后遗症。发病机制：病原体（多为鼻咽部携带）经血行播散，穿越血脑屏障进入脑膜下腔；细菌在缺乏有效免疫防御的蛛网膜下腔繁殖，释放炎症介质。

病原体谱按年龄分档：**新生儿**（B 群链球菌、大肠埃希菌、李斯特菌）；**儿童与青年**（脑膜炎奈瑟菌、肺炎链球菌）；**老年人/免疫低下**（肺炎链球菌、李斯特菌）。病毒性脑膜炎（多为肠道病毒）通常良性，但**必须在细菌性脑膜炎被排除之后才能放松**——这是鉴别诊断的铁律。<span class="marginnote">「发热 + 头痛 + 颈强直 + 意识改变」是脑膜炎四联征，但不是每次齐全。快速鉴别工具：脑脊液细胞数、蛋白、糖——细菌性常为多核细胞升高、糖显著降低（细菌与白细胞都在消耗糖）。</span>

治疗铁律：**怀疑即治，不等腰穿结果**——先经验性覆盖最常见病原（成人：头孢曲松 + 万古霉素，加地塞米松减炎症），腰穿后按培养降阶梯。地塞米松在肺炎球菌性脑膜炎中减少听力损失，但必须在抗生素之前或同时给予。

脑脊液分析是定位病原类型的第一手资料，「发热 + 头痛 + 颈强直」时看三项：细胞数、蛋白、糖：

| 指标 | 细菌性 | 病毒性 | 结核性 |
| --- | --- | --- | --- |
| 白细胞 | 显著升高（多核为主） | 轻度升高（淋巴为主） | 中度升高（淋巴为主） |
| 蛋白 | 显著升高 | 正常或轻度升高 | 中度升高 |
| 糖 | 显著降低 | 正常 | 明显降低 |
| 涂片 / 培养 | 阳性率高 | 多为阴性 | 抗酸染色可阳性 |

**辨析｜易错点：** 脑脊液「糖低」是细菌性与结核性脑膜炎的共性——细菌和白细胞都在消耗糖；「糖正常」更倾向病毒性。但这张表只是倾向，治疗决策仍以「怀疑即治」为准，腰穿更多是回填诊断与降阶梯依据。

## 2 心内膜炎：血流的赘生物战争

**感染性心内膜炎（IE）**是心内膜、瓣膜表面的感染，形成**赘生物（vegetation）**——由血小板、纤维蛋白与细菌构成的团块，细菌藏在深处、血流难达、抗生素难入。<span class="marginnote">赘生物就是第二篇「接种量效应」的完美案例：细菌密度高、生长慢、被生物膜样基质保护，β-内酰胺单打独斗常常不够——所以 IE 需要长程、高剂量、常联合用药。</span>

病原体分两类：**急性 IE**（金黄色葡萄球菌，常累及正常瓣膜，可迅速破坏）；**亚急性 IE**（草绿色链球菌、肠球菌，多累及已有病变瓣膜）。高风险人群：人工瓣膜、既往 IE 史、先天性心脏病、静脉药瘾者（右心受累）。

诊断靠**改良 Duke 标准**——把临床、微生物、影像证据加权打分：**主要标准**：血培养两次阳性（典型病原）、超声心动图见赘生物/瓣膜脓肿；**次要标准**：易感因素、发热、血管/免疫现象（Osler 结节、Janeway 损害、Roth 斑）等。满足「2 主 + 1 次」即确诊。治疗：长程静脉抗生素 + 必要时的瓣膜手术（脓肿、心衰、真菌性 IE 需外科干预）。

心内膜炎按「宿主状态 × 受累瓣膜」猜病原体，是经验选药的快捷方式：

| 情形 | 最可能病原体 | 经验用药方向 |
| --- | --- | --- |
| 急性、正常瓣膜、皮肤感染灶 | 金黄色葡萄球菌 | 抗 MRSA 覆盖 |
| 亚急性、已有瓣膜病变、牙科操作 | 草绿色链球菌 | 青霉素类 |
| 人工瓣膜、术后 1 年内 | 凝固酶阴性葡萄球菌 | 抗 MRSA + 联合 |
| 静脉药瘾者、右心受累 | 金黄色葡萄球菌 | 抗 MRSA 覆盖 |

## 3 骨髓炎：血供是命门

**骨髓炎（osteomyelitis）**是骨的感染，途径三：血行播散（儿童多见，长骨干骺端血供丰富）、直接接种（外伤、手术后）、邻近播散（糖尿病足溃疡）。成人中**糖尿病足**是最常见的入口——血供差的组织对感染的抵抗和药物输送都差。

病原体：金黄色葡萄球菌占绝对多数（血行与直接接种），社区获得性 MRSA 也不少见；糖尿病足常为**混合感染**（多种革兰阳性、阴性、厌氧菌）。诊断：局部红肿热痛 + 影像（X 线早期多阴性，MRI 敏感）+ 骨活检培养——**骨的培养是金标准，软组织培养易被皮肤菌污染**。<span class="marginnote">「骨显像阳性 + 软组织培养阳性 ≠ 骨髓炎确诊」——软组织菌会污染骨标本。要确诊必须有骨组织学或骨培养，这也是骨活检地位高的原因。</span>

**重点：** 骨髓炎的治疗是「抗菌药 + 外科清创 + 改善血供」三线并进。抗生素要长程（4–6 周起），因为死骨与低灌注区药物难达；不引流脓、不切除死骨，光靠抗生素治骨髓炎，如同把水泼进漏桶。β-内酰胺类入骨良好，但**骨内药物浓度低、且需要手术配合**是两条临床常识。

## 4 尿路感染：解剖决定宿命

**尿路感染（UTI）**是解剖结构的直接映射：病原体经尿道逆行进入膀胱（膀胱炎）、再上行至肾盂（肾盂肾炎）。**大肠埃希菌占 70%–80%**，其他肠杆菌、肠球菌次之。分型与治疗强度直接挂钩：

- **单纯性膀胱炎**：女性多见，短程（3–5 天）口服呋喃妥因/磷霉素即可。
- **急性肾盂肾炎**：发热 + 腰痛 + 脓尿，需覆盖大肠埃希菌的疗程 7–14 天。
- **复杂性 UTI**：存在解剖/功能异常（结石、留置导尿管、前列腺增生、妊娠）——病原体更多样、更耐药，需培养指导。
- **导尿管相关 UTI（CAUTI）**：导管表面生物膜，是第十三篇「医院感染」的重要来源。

**辨析｜易错点：** 「无症状性菌尿 ≠ 需要治疗」——多数无症状菌尿（尤其老年人、长期导尿者）治疗无益反增耐药；只有妊娠、拟行泌尿手术等少数情况才需处理。过度治疗无症状菌尿，是抗生素滥用里最常见的类型之一，也是第二篇「能不用则不用」原则的实践样本。

**补充：** UTI 的复发要区分**再感染（reinfection）**与**细菌学复发（relapse）**：前者是不同菌株反复出现，常需排查解剖异常与卫生行为，短程治疗即可；后者是同一菌株快速复发，提示上尿路感染未清或前列腺、结石等病灶存留（reservoir），需更长疗程与影像评估。

## 5 公式解析：肌酐清除率——按肾功能定剂量的基础

局部感染综合征的用药（尤其是氨基糖苷类、万古霉素等肾毒性药物）几乎都绕不开**肾功能剂量调整**。估算肾小球滤过率最常用的床旁公式是 **Cockcroft–Gault** 计算的肌酐清除率：

$$\mathrm{CrCl} \; (\text{mL/min}) = \frac{(140 - \text{年龄}) \times \text{体重} \; (\text{kg})}{\text{血肌酐} \; (\text{mg/dL}) \times 72} \times (\text{女性 } 0.85)$$

- **140 − 年龄**：肾功能随年龄自然下降的校正项——年龄越大，同样的血肌酐代表的滤过功能越差。
- **体重**：反映肌肉量与药物分布容积；肌酐主要来自肌肉分解，所以体重越大、基线肌酐产生越多。
- **血肌酐 × 72**：分母上的血肌酐是「排不出去的废物浓度」，浓度越高提示滤过越差。
- **女性 ×0.85**：女性肌肉量较低，肌酐产生少，同样的血肌酐对应更低真值——所以乘 0.85 校正。

三步读法：**先估**患者的肾功能基线（年龄与体重校正），**再读**当前血肌酐反映的滤过状况，**最后**对照药物说明书把剂量与给药间隔按 CrCl 打折——肾功能减半，排泄型药物的剂量就要减半或拉长间隔。<span class="marginnote">这是「药代动力学」最直接的落地：氨基糖苷、万古霉素、氟喹诺酮几乎都靠肾脏排泄，CrCl 一低，血药浓度就会「只升不降」，毒性（肾毒性、耳毒性）风险陡增。剂量调整不是可选项。</span>

算一个具体的数：70 岁、70 kg、血肌酐 1.0 mg/dL 的男性，CrCl ≈ (140−70)×70 / (1.0×72) ≈ 68 mL/min——已低于青年正常水平，若使用氨基糖苷，剂量与给药间隔必须按说明书折减，否则谷浓度上升、耳肾毒性风险随之陡增。

## 6 术语速查：四个器官战场的对照

| 术语 | 一句话定义 | 关键提醒 |
| --- | --- | --- |
| 脑脊液（CSF） | 蛛网膜下腔的液体 | 细胞 / 蛋白 / 糖三分诊断 |
| 赘生物 | 血小板 + 纤维蛋白 + 细菌团块 | 抗生素难达 → 长程联合 |
| 改良 Duke 标准 | IE 加权诊断工具 | 2 主 + 1 次确诊 |
| 死骨（sequestrum） | 无血供的坏死骨片 | 必须手术清除 |
| 无症状性菌尿 | 尿中带菌但不致病 | 多数不必治 |
| 复杂性 UTI | 解剖 / 功能异常背景 | 病原多样、需培养 |
| 再感染 / 复发 | 不同菌株 vs 同一菌株 | 决定疗程与排查方向 |
| CrCl | 肌酐清除率 | 肾排泄药剂量依据 |
| 脑膜刺激征 | 颈强直、布氏征 / 克氏征 | 脑膜炎体格检查 |
| 骨活检培养 | 骨髓炎确诊金标准 | 软组织培养易污染 |

四个器官，一套逻辑：先猜病原、再选穿透力合适的药、最后盯住「血供差 / 生物膜 / 死腔」这些让药失效的结构。这张表把四场战役拧成一张速查图。

## 7 小结

- 四类局部综合征共享「机制 → 病原体 → 药代」链条，但各有战场：**脑脊液、赘生物、死骨、泌尿道**。
- **脑膜炎**：怀疑即治，先覆盖再降阶梯；腰穿是金标准但不该拖住用药。
- **心内膜炎**：赘生物里的细菌难杀 → **长程、高剂量、常联合**；改良 Duke 标准加权诊断。
- **骨髓炎**：血供是命门，**抗菌药 + 清创 + 改善血供**三线并进。
- **UTI**：解剖决定病原与疗程；**无症状性菌尿多数不必治**。
- 肾功能剂量调整的数学基础是 **CrCl（Cockcroft–Gault）**：按肾功能打折，否则肾毒性药「只升不降」。
