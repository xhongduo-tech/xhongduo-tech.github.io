## 为什么从真菌感染开始

上一节把「免疫低下宿主的感染」讲成一张病原体谱，而谱上排得最密的一族，就是真菌。真菌是进化树上离动物最近的真核微生物，这带来一个残酷的事实：**因为太像我们，反而最难杀死**——像第二篇强调的「选择性毒性」，在真菌上最难实现。三大致病真菌——念珠菌、曲霉、隐球菌——分别统治着「住院患者」「气道」与「脑」三个战场，也是免疫低下宿主的头号机会性感染来源。

这篇与前面的败血症（念珠菌血症是最常见的血流感染之一）、免疫低下宿主、后面的病毒与结核各篇直接咬合。读懂真菌，就是读懂「如何与一个慢得多、也狡猾得多的敌人作战」。

## 1 真菌：真核身份带来的难题

真菌是**真核生物**，细胞有核膜、有 80S 核糖体、细胞膜含**麦角固醇（ergosterol）**而非哺乳动物的胆固醇。这意味着两点：

- 真菌有完整的细胞骨架、线粒体与复杂的基因调控——它不是细菌那种「结构简单、漏洞百出」的对手。
- 抗真菌药物的靶点必须选在真菌**独有或差异大**的位置：细胞壁（β-葡聚糖）、麦角固醇合成/结合、核酸合成、微管蛋白。<span class="marginnote">「像我们」导致「难杀」：如果药物以真菌的某种蛋白质为靶，而该蛋白与人的同源蛋白高度相似，选择性毒性就塌了——这是抗真菌药比抗生素毒性更大的根本原因。</span>

真菌感染分两大家族：**浅部感染**（皮肤癣菌，侵犯角质层，好治）与**深部/侵袭性感染**（念珠菌、曲霉、隐球菌、毛霉，侵犯组织与血流，凶险）。本篇专注后者。感染来源上，念珠菌是**内源机会性**（本是宿主正常菌群，防线破时反客为主），曲霉与隐球菌是**外源环境性**（孢子吸入）。

## 2 三大真菌的诊断与临床画像

### 念珠菌（Candida）：ICU 的常客

正常存在于皮肤、消化道、阴道黏膜。**侵袭性念珠菌病**的易感因素：粒缺、广谱抗生素（杀光细菌把生态位让给真菌）、中心静脉导管、全肠外营养、腹部手术。最常见临床形态是**念珠菌血症（candidemia）**，血培养阳性率不高，发热往往「抗生素无效却查不到细菌」。诊断武器：血培养、β-D-葡聚糖（BDG）试验、眼部检查（眼底视网膜念珠菌绒毛状浸润）。<span class="marginnote">念珠菌血培养灵敏度低，所以「高度怀疑即经验性治疗」在念珠菌上比细菌更激进——等培养阳性往往已播散。这正是「有准备的头脑」：把风险因素当诊断线索。</span>

### 曲霉（Aspergillus）：气道的入侵者

吸入空气中孢子，免疫健全者靠巨噬细胞与中性粒细胞清除；粒缺、移植、长期激素患者防御失灵，菌丝侵入肺血管与组织，形成**侵袭性肺曲霉病（IPA）**。影像特征：结节伴「晕轮征」（出血围绕）、后期「新月征」。诊断靠**宿主因素 + 影像 + 微生物证据**（痰培养、半乳甘露聚糖 GM 试验）三件套，肺曲霉病是最典型的「免疫低下宿主感染」（见第四篇）。

### 隐球菌（Cryptococcus）：脑的征服者

隐球菌随鸽粪污染的土壤尘埃吸入，免疫正常者多被清除或局限。T 细胞缺陷者（HIV CD4<100、移植）中，孢子出肺入血、穿越血脑屏障，引起**隐球菌脑膜脑炎（CM）**——HIV 相关机会性感染最常见的脑感染之一。表现：头痛、发热、脑膜刺激征可轻；**脑脊液墨汁染色可见荚膜包裹的酵母**，抗原检测（CrAg）灵敏快速。<span class="marginnote">隐球菌的荚膜是多糖，本身是强烈的免疫逃逸工具：抑制吞噬、遮蔽抗原。荚膜让它在脑脊液里「隐身」，也解释了为什么 CrAg（荚膜抗原检测）是诊断主力——直接找被荚膜藏起来的东西。</span>

**重点：** 三大真菌的识别词分别是——念珠菌「导管 + 广谱抗生素 + 粒缺」，曲霉「肺 + 晕轮征 + GM」，隐球菌「脑 + 头痛 + CrAg」。抓住这个词，病史与影像就能把真菌对号入座。

三大真菌的诊断还依赖一组**血清学标志物**，它们各有分工、也各有陷阱：

| 标志物 | 对应真菌 | 机制 | 陷阱 |
| --- | --- | --- | --- |
| 半乳甘露聚糖（GM） | 曲霉 | 曲霉细胞壁成分释放入血 | 某些 β-内酰胺可假阳性 |
| β-D-葡聚糖（BDG） | 念珠菌、曲霉、肺孢子菌 | 真菌细胞壁共同成分 | 广谱，不能定种 |
| 隐球菌抗原（CrAg） | 隐球菌 | 荚膜多糖抗原 | 脑脊液 / 血清均可查 |

**辨析｜易错点：** BDG 是「广谱真菌阳性信号」而非「某种真菌的确诊」——它受透析、输注白蛋白等干扰，阳性只提示「该去查真菌」，定位到种还要靠培养、抗原或核酸。血清学标志物是「报警器」，不是「判决书」。

## 3 抗真菌药：四大武器与它们的靶点

对照第二篇的「机制地图」，真菌药家族正好是另一张地图：

| 药物 | 靶点 / 机制 | 备注 |
| --- | --- | --- |
| 多烯类（两性霉素 B） | 结合麦角固醇，破坏真菌细胞膜 | 广谱、杀菌；肾毒性与输注反应大，常需监测 |
| 唑类（氟康唑、伏立康唑、泊沙康唑） | 抑制 14α-脱甲基酶，阻断麦角固醇合成 | 广谱但药敏差异大；CYP450 相互作用多 |
| 棘白菌素类（卡泊芬净、米卡芬净） | 抑制 β-1,3-葡聚糖合酶，破坏细胞壁 | 对念珠菌强效、耐受好；对隐球菌天然无效（壁薄依赖低） |
| 嘧啶类（氟胞嘧啶 5-FC） | 抑制核酸合成（掺入 RNA/DNA） | 单用易耐药，常与两性霉素 B 联用（如隐球菌诱导期） |

**辨析｜易错点：** 棘白菌素是「念珠菌首选级」却是「隐球菌的盲区」——因为隐球菌细胞壁的 β-葡聚糖含量低、主要靠荚膜与细胞膜生存。这再次印证机制决定选择：**选药不能只看「抗真菌」三个字，要看具体药打在哪个靶点、靶点在目标真菌上是否可打。**

## 4 公式解析：Candida 评分的临床决策价值

念珠菌血症的经验性治疗需要「算概率再出手」。一个被临床验证的量化工具是 **Candida 评分（León 等）**：用危险因素加权，判断 ICU 患者是否为侵袭性念珠菌病高危：

$$C_{\text{score}} = 0.908\,(\text{念珠菌定植}) + 1.112\,(\text{手术}) + 1.954\,(\text{肠外营养}) + 2.038\,(\text{脓毒症})$$

- 每个括号是 0/1 变量：是否**多部位念珠菌定植**、是否**近期手术**、是否**全肠外营养**、是否**脓毒症**。
- 系数（0.908、1.112、1.954、2.038）来自多中心队列的 logistic 回归——每个因素对「侵袭性念珠菌病」的贡献权重不同，**脓毒症权重最高**。

判定：$C_{\text{score}} > 2.5$ 提示侵袭性念珠菌病高危，应启动经验性抗真菌治疗。<span class="marginnote">Candida 评分是「加权求和」在临床的活例子——它与你在第三级《机器学习》里见过的 logistic 回归打分同构：风险 = 特征 × 权重的线性叠加再配阈值。医学里的评分系统（qSOFA、Duke 标准）全是这个模板。</span>

**重点：** 临床评分 ≠ 诊断。Candida 评分把「经验性治疗的启动时机」从一个直觉问题变成一个可重复、可验证的阈值问题——这正是「把抽象风险量化」的医学化表达。

## 5 治疗策略与免疫重建的联合

真菌治疗常是「多药 + 长程 + 源控制」的联合战：

- **隐球菌脑膜脑炎（HIV 相关）**：诱导期两性霉素 B + 氟胞嘧啶 ≥2 周，巩固期氟康唑，维持期继续氟康唑；同时按第四篇原则启动 ART，但注意**隐球菌 IRIS**——诱导期过早加 ART 可能诱发颅内压危象。
- **念珠菌血症**：棘白菌素一线，稳定后可用唑类降阶梯；**拔除中心静脉导管是源控制关键**——导管不拔，药物难清。
- **侵袭性肺曲霉病**：伏立康唑一线（比两性霉素 B 疗效更优），重症联合棘白菌素；粒缺恢复是能否存活的关键变量。

**辨析｜易错点：** 「免疫重建是治疗真菌的终极武器」是对的，但「越早越好」是错的。隐球菌 CM 诱导期同时猛上 ART，颅内压与 IRIS 可能让患者死于治疗而非感染——真菌的清除依赖「先压真菌负荷、再让免疫接管」，时序本身就是治疗的一部分。

### 别忘了毛霉：时机比药更关键

除三大真菌外，**毛霉目（Mucorales）**是粒缺与糖尿病酮症酸中毒患者里最凶险的侵袭性真菌之一——鼻眶脑型与肺型进展极快，血管侵犯导致组织梗死。治疗三件套：**两性霉素 B + 手术清创 + 逆转基础病**（控制血糖、停用免疫抑制）。「越早切越活」是毛霉病的铁律——药物与清创缺一不可，与第五篇骨髓炎「清创不可替代」的逻辑同源。<span class="marginnote">毛霉与曲霉影像上都可出现「晕轮征」，但毛霉更多见于<strong>糖尿病酮症酸中毒与铁超载</strong>患者，且曲霉 GM 常阴性。遇到「进展极快的肺 / 鼻眶病灶」，先想毛霉，别让 GM 阴性耽误了手术窗口。</span>

## 6 术语速查：真菌战场的关键词

| 术语 | 一句话定义 | 关键提醒 |
| --- | --- | --- |
| 麦角固醇 | 真菌细胞膜特有固醇 | 多烯 / 唑类的靶点 |
| 侵袭性真菌病 | 真菌侵犯组织与血流 | 区别于浅部皮肤癣菌 |
| 念珠菌血症 | 念珠菌入血 | 血培养灵敏度低，须经验治疗 |
| IPA | 侵袭性肺曲霉病 | 晕轮征、GM 阳性 |
| 隐球菌脑膜脑炎 | 隐球菌穿越血脑屏障 | CrAg 快速灵敏 |
| 棘白菌素 | β-葡聚糖合酶抑制剂 | 对隐球菌天然无效 |
| 两性霉素 B | 多烯类，结合麦角固醇 | 肾毒性需监测 |
| 毛霉病 | 毛霉目血管侵袭性感染 | 酮症酸中毒高危，手术清创 |

真菌是「像宿主」的敌人，所以用药先看靶点、再看时机。这张表是第五篇的选药与诊断速查。

## 7 小结

- 真菌是**真核生物**，因「像宿主」而选择性毒性最难——抗真菌药毒性大、靶点少。
- 三大真菌各有画像：**念珠菌（导管+广谱抗生素+粒缺）、曲霉（肺+晕轮征+GM）、隐球菌（脑+头痛+CrAg）**。
- 四大药族：**多烯（膜）、唑类（麦角固醇合成）、棘白菌素（壁）、氟胞嘧啶（核酸）**；棘白菌素对隐球菌天然无效。
- **Candida 评分**把经验性治疗变成可重复的加权阈值决策（>2.5 高危启动）。
- 真菌治疗常为**多药 + 长程 + 源控制 + 免疫重建**，且重建时机本身参与疗效。
