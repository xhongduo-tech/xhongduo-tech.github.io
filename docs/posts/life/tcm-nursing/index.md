# 中医护理学

中医护理学是在中医整体观与辨证施护指导下，将中医理论与护理实践相结合的独立专业方向。学完本专题，即掌握中医护理的基础理论、常用护理技术与常见病证的辨证施护方案。

## 对标教材

- 《中医护理学基础》（全国中医药行业高等教育"十四五"规划教材，中国中医药出版社）
- 《中医护理方案》（国家中医药管理局，52 个病种护理方案）
- 《中医护理技术操作规范》（中华中医药学会团体标准）
