## 为什么从耳穴贴压开始

耳朵只有拳头大小，中医却认为它是**全身的微缩地图**——「耳者，宗脉之所聚」，十二经脉都直接或间接上达于耳。**耳穴贴压（耳穴压豆）**就是在耳廓的相应穴位上贴敷王不留行籽等小颗粒，通过按压刺激调理脏腑、防治疾病。<span class="marginnote">最著名的耳穴理论是「倒置胎儿」说：耳垂对应头面部，对耳屏对应咽喉，耳甲腔对应胸腔，耳甲艇对应腹腔，耳轮脚周对应消化道——人体在耳朵上呈倒置投影。这一分布规律与全息论不谋而合，使耳穴贴压成为一项「看图施术」、易学易用的技术。</span>它对失眠、疼痛、情志病、便秘等尤效，是中医护理使用率最高的微刺激技术。

## 1 耳穴的概念与分布规律

**耳穴（Auricular Points）**：分布在耳廓上与脏腑、组织器官相关联的特定刺激点。当脏腑或躯体发生病变时，常在相应耳穴出现压痛点、变形、变色等反应——护士可利用这种反应**以耳查病、以耳治病**。

耳穴分布遵循「倒置胎儿」规律，从耳垂到耳轮脚呈头部到躯干、内脏的倒置排列：

- **耳垂**：对应头面部——眼、面颊、内耳、扁桃体。
- **对耳屏、耳屏**：对应咽喉、鼻、额。
- **耳轮脚及周围**：对应消化道——口、食道、贲门、胃、脾、大肠、小肠。
- **耳甲腔**：对应胸腔脏器——心、肺、三焦。
- **耳甲艇**：对应腹腔脏器——肝、肾、脾、膀胱、胰胆。
- **三角窝、耳舟、对耳轮**：对应盆腔（子宫、神门）与上肢、下肢（肩、肘、腕、指、膝、踝）。

## 2 常用耳穴的定位与主治

| 耳穴 | 定位 | 主治 |
| --- | --- | --- |
| 神门 | 三角窝后上部 | 镇静安神、止痛，失眠、焦虑、痛证 |
| 内分泌 | 耳甲腔底部 | 调节内分泌，糖尿病、月经不调 |
| 心 | 耳甲腔中央凹陷处 | 心悸、失眠、神经衰弱 |
| 肝 | 耳甲艇后下方 | 情志不舒、眩晕、胁痛 |
| 脾 | 耳甲腔后上方 | 消化不良、腹胀、水肿 |
| 肺 | 耳甲腔前上方 | 感冒、咳嗽、皮肤病 |
| 肾 | 对耳轮下脚后下方 | 腰痛、耳鸣、夜尿多 |
| 胃 | 耳轮脚消失处 | 胃痛、恶心、呃逆 |
| 耳背沟 | 耳廓背面凹陷处 | 降压（常用于高血压辅助） |

**辨证选穴思路**：按脏腑辨证取主穴，按症状对症取配穴。如失眠：主取**神门、心**（宁心安神），配**皮质下、枕**；胃痛：主取**胃、脾**（和胃健脾），配**神门**（止痛）。

## 3 耳穴贴压的操作方法

**操作程序**：

1. **选穴**：辨证确定主穴配穴，一般**每耳 3—5 穴**。
2. **探查**：用探棒在耳穴区寻找**最痛点**——压痛明显的点即是治疗点；或用耳穴探测仪探查低电阻点。
3. **消毒**：用 75% 酒精棉签擦拭耳廓皮肤。
4. **贴压**：将王不留行籽（或磁珠、莱菔子）置于 0.5 cm×0.5 cm 胶布中央，对准穴位贴敷。
5. **按压**：用拇指、示指对捏贴压穴，以患者**感酸、麻、胀、热（得气）**为度，每穴按压 1—2 分钟。<span class="marginnote">「得气感」是耳穴贴压有效的关键：单纯贴上不按效果有限。应教会患者自行按压——每日按压 3—5 次，每次每穴 1—2 分钟，两耳交替贴压。</span>

**疗程**：一般**每贴 3—7 天**，两耳交替；5—10 次为一疗程。夏季汗多易脱落，可缩短至 3 天。

## 4 耳穴贴压的适应证与禁忌证

**适应证**：失眠、疼痛（头痛、痛经、牙痛）、情志病（焦虑、抑郁）、便秘、高血压、糖尿病、肥胖、戒烟、晕车等。对慢性病与功能性疾病尤为适用。

**禁忌证**：

- 耳廓**冻伤、感染、湿疹、破损**者禁贴。
- 孕妇**妊娠期慎用**，尤其有流产史者**禁用耳穴贴压（刺激宫缩）**。
- 严重器质性疾病急性期、精神疾患不宜自行贴压，须遵医嘱。

## 5 耳穴贴压的护理要点

- **清洁与卫生**：贴压前耳廓须清洁干燥，胶布过敏者改用防敏胶布或缩短贴压时间。
- **按压指导**：教会患者自行按压的方法与频率，避免用指甲重掐破皮。
- **观察反应**：贴压期间观察耳廓有无红肿、过敏、感染；一旦发痒红肿即取下，局部消毒。
- **防感染**：胶布潮湿或脱落及时更换；洗头洗澡时注意防水防潮。
- **记录**：记录选穴、贴压日期、按压反应与疗效，评估辨证是否准确、是否需要调整穴位。

## 6 耳穴贴压与其他中医技术的关系

耳穴贴压常与**艾灸、拔罐、穴位贴敷、情志护理**配合使用。例如失眠患者，白天耳穴贴压神门、心（持续刺激），晚间配合睡前艾灸涌泉或温水足浴，再辅以情志疏导——「多技术组合」比单一技术更贴合「整体调护」的理念。护士掌握各技术的适应证后，可据证灵活配伍。

## 6 耳穴贴压的常见问题与处理

| 问题 | 常见原因 | 处理 |
| --- | --- | --- |
| 胶布过敏 | 个体敏感 | 换防敏胶布、缩短贴压时间 |
| 耳廓红肿感染 | 卫生不佳、抓挠 | 取下、消毒、必要时就医 |
| 贴豆脱落 | 出汗多、胶布不粘 | 及时更换、夏季缩短周期 |
| 按压过度 | 用力过大 | 教正确手法、以酸胀为度 |
| 无感觉 | 未贴准穴位 | 重新探查痛点、调整位置 |

**处理原则**：贴压前充分沟通、讲清按压方法；每日自查耳廓皮肤；异常即取并处理；保持耳廓干燥清洁是防感染的关键。

## 7 耳穴贴压的家庭自护指导

耳穴贴压的最大优势是**可教会患者自护**，护士的指导要点：

- **教会按压**：示范拇指示指对捏按压法，嘱每日按压 3—5 次、每穴 1—2 分钟，睡前加强。
- **教会观察**：耳廓红肿瘙痒即取下；胶布潮湿脱落即更换。
- **教会记录**：记录贴压穴位、日期、按压反应，复诊时供辨证参考。
- **注意事项**：洗头洗澡防水；孕妇、耳廓破损者遵医嘱慎用；疗效不佳者及时复诊调整。

**辨证提示**：耳穴贴压属「微刺激」调节法，作用温和、重在长期调理——失眠、疼痛、慢性病尤其适合，急症仍须按规范急救处理。

## 7 耳穴的常用配穴速查

| 病症 | 主穴 | 配穴 |
| --- | --- | --- |
| 失眠 | 神门、心 | 皮质下、枕、交感 |
| 头痛 | 神门、枕 | 额、颞、肝 |
| 胃痛 | 胃、脾 | 神门、交感 |
| 便秘 | 大肠、便秘点 | 脾、三焦 |
| 痛经 | 子宫、内分泌 | 神门、肝、肾 |
| 高血压 | 降压沟、肝 | 肾、神门、心 |
| 减肥 | 内分泌、饥点 | 脾、胃、三焦 |

**配穴逻辑**：主穴针对病位病机，配穴随症加减、兼顾兼证；辨证选穴是耳穴贴压取效的前提。

## 8 小结

- 耳穴是耳廓上与脏腑相关联的刺激点，分布遵循「**倒置胎儿**」规律。
- 常用穴有**神门、心、肝、脾、肾、胃、内分泌**等，辨证选穴、按痛取穴。
- 操作五步：**选穴→探查→消毒→贴压→按压**，得气为度。
- 每贴 3—7 天、两耳交替；适应证广（失眠、疼痛、情志病等）。
- **孕妇慎用禁用、耳廓破损禁贴**；教会患者按压，观察防感染。
