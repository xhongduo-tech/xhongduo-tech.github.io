## 为什么从并发症与管理收尾

前面九节讲了各种介入技术，但临床真正区分「好医生」与「平庸医生」的，往往不是会把手术做得多漂亮，而是**会不会把并发症管住**。介入操作虽微创，风险并不微小：穿刺点出血、对比剂肾损伤、造影剂过敏、抗凝管理失误——每一项都可能从「小插曲」演变成「大事故」。<span class="marginnote">围手术期管理是介入的「全程伴随」：术前评估把高危患者筛出来，术中监护把风险按住，术后随访把隐患及时处理。这套「术前—术中—术后」的闭环，正是第五级《麻醉学》《护理学》与《药理学》知识的临床集合——介入医生不仅会「插管」，更要是「内科医生 + 外科医生」的合体。</span>本节把这十节的临床思维收拢成一套可执行的框架。

## 1 术前评估：把高风险患者筛出来

术前评估回答三件事：**这个病人能不能做？做什么方案？需要什么准备？**

**凝血功能**是血管介入的第一道门槛：血小板、INR/PT、APTT 是常规检查。动脉穿刺后止血依赖自身凝血，血小板过低（< 50×10⁹/L）或 INR 过高（> 1.5）时，穿刺点出血风险显著升高，需先纠正或选择创伤更小的入路。<span class="marginnote">不同操作对凝血的要求不同：<strong>诊断性血管造影最宽松，栓塞、TIPS、神经介入最严格</strong>——栓塞会把「出血风险」变成「缺血风险」，一旦误栓或血栓形成，后果是器官梗死。术前把凝血、肾功能、用药史问清楚，是最便宜的安全投资。</span>

**肾功能**决定对比剂策略：评估 eGFR，肾功能不全者需水化、停用肾毒性药物、限制对比剂总量。

**药物管理**是术前最常见却最易出错的一环：华法林通常术前停用并以低分子肝素「桥接」，新型口服抗凝药（DOAC）按半衰期停用；抗血小板药（阿司匹林、氯吡格雷）在出血风险高或急诊时权衡。**「停不停、停多久、用不用桥接」必须写入操作记录**。

| 药物 | 常规术前停药时间 | 备注 |
| --- | --- | --- |
| 华法林 | 术前 5 天，视 INR 桥接低分子肝素 | INR ≤ 1.5 才安全 |
| 利伐沙班 / 阿哌沙班等 DOAC | 术前 1–2 天（按肾功能调整） | 急诊可用逆转剂 |
| 阿司匹林 | 出血高风险操作停 3–5 天 | 冠状动脉支架者需权衡 |
| 氯吡格雷 / 替格瑞洛 | 停 5–7 天 | 支架内血栓风险优先时不停 |

| 操作类型 | 必查项目 |
| --- | --- |
| 诊断性血管造影 | 血常规、凝血、肾功能 |
| 栓塞 / TIPS / 神经介入 | 血常规、凝血、肾功能、肝功能 |
| 穿刺活检 / 引流 | 凝血（血小板、INR）为第一优先 |
| 长期抗凝患者的任何操作 | 凝血全套 + 血栓/出血风险双评估 |

**知情同意**：把获益、风险、替代方案讲清，这是医患共同决策的起点，也是并发症发生时的信任基石。

## 2 术中监护与辐射防护

介入手术室是「导管 + 影像 + 生命监护」的三合一战场。

**镇静与镇痛（conscious sedation）**：多数介入在中度镇静下完成，术者要同时盯影像、盯病人生命体征（血氧、血压、心律），并准备镇静过深时的气道管理与拮抗剂。**肝素化管理**：动脉栓塞、神经介入等需术中肝素，术后依情况中和（鱼精蛋白）或等待代谢，防血栓也防出血。

**辐射防护**是介入医生「用健康换技术」的隐性代价：遵循 **ALARA 原则**（在合理可达到的范围内尽量低），缩短透视时间、降低帧率、使用铅衣/铅屏/剂量监测、减少不必要的放大与旋转采集。<span class="marginnote">介入医生的职业病风险——晶状体混浊、甲状腺/皮肤辐射损伤——来自日积月累的透视剂量。<strong>「能不减就不加」的辐射纪律</strong>，与第五级《医学影像学》中的剂量优化一脉相承：影像学关心患者剂量，介入医生还要关心自己。</span>新生儿、孕妇等高敏人群更要压缩剂量。

## 3 公式解析：对比剂肾病的剂量红线

**对比剂诱导的急性肾损伤（CI-AKI）** 是介入最常见的系统性并发症之一。预防的核心之一是**控制对比剂总量**，临床常用 Cigarroa 经验公式估算单次操作的「安全上限」：

$$V_{\max}\,(\mathrm{mL}) = \frac{5 \times \mathrm{体重}\,(\mathrm{kg})}{\mathrm{血清肌酐}\,(\mathrm{mg/dL})}$$

- $V_{\max}$：建议的对比剂总量上限（mL）。
- 体重：以 kg 计；血清肌酐：以 mg/dL 计。
- 上限值：一般**不超过 300 mL**（无论计算值多大）。

**拆解两步**：

- **第一步，算**：60 kg 患者肌酐 1.5 mg/dL，则 $V_{\max} = (5\times60)/1.5 = 200$ mL——一次复杂介入（多次造影 + 栓塞）很容易逼近甚至超过这个值，所以要「边做边记账」。
- **第二步，配**：肾功能不全患者还要**术前水化**（等渗盐水）、**停用二甲双胍与 NSAIDs**、优先选等渗或低渗对比剂。**「算、记、省、补」四字诀**，是 CI-AKI 预防的完整闭环。

## 4 术后管理：把并发症摁在萌芽里

术后管理的核心是「把该来的并发症早发现、早处理」。

**穿刺点止血**：手动压迫（动脉压迫 10–15 分钟再加压包扎）、血管闭合装置（缝合/封堵）、桡动脉压迫带。术后卧床制动时间按入路与止血方式而定。<span class="marginnote">术后护士的观察清单基本是「穿刺点五查」：<strong>血肿、假性动脉瘤（搏动性包块+杂音）、动静脉瘘（连续性杂音）、远端肢体缺血（皮温皮色感觉）、腹膜后出血（腰痛+血压下降+血红蛋白骤降）</strong>。每一条都对应第 1 节讲过的并发症，术后随访是它们的「最后一道闸门」。</span>

**肾功能与过敏观察**：术后监测肌酐、鼓励饮水，观察迟发过敏反应（皮疹、血管性水肿）。**静脉血栓预防**：术后长时间卧床者评估血栓风险，必要时预防性抗凝或物理预防。

把术后的「盯什么」列成一张核对表，交班不易遗漏：

| 观察项 | 警示信号 |
| --- | --- |
| 穿刺点 | 血肿扩大、搏动性包块、杂音 |
| 远端肢体 | 皮温皮色改变、感觉运动异常 |
| 生命体征 | 血压骤降、心率骤升（疑出血） |
| 造影剂相关 | 皮疹、气促、尿量减少 |
| 栓塞/支架后 | 靶器官剧烈疼痛、发热不退 |

**急诊并发症处理原则**：穿刺点活动性出血→立即压迫 + 重新评估止血；造影剂过敏→肾上腺素、糖皮质激素、抗组胺药按分级处理；空气栓塞、导管断裂等罕见但致命的事件，要有应急预案。<span class="marginnote">介入室的应急预案不是「纸面文件」：<strong>导管断裂、栓塞材料反流、气道衰竭</strong>这类事件几分钟内就会决定生死，反复演练与抢救药品（肾上腺素、鱼精蛋白、阿托品）的定点配置，是每个介入团队的底线能力。</span>

## 5 公式解析：并发症分级（SIR 分级）

要管理并发症，先要统一「怎么描述严重度」。介入放射学会（SIR）的**不良反应分级**是通用语言：

| 分级 | 类型 | 描述 |
| --- | --- | --- |
| 1 | 轻度（minor） | 无需治疗，无临床后果 |
| 2 | 轻度（minor） | 需名义上治疗，住院仅留观过夜 |
| 3 | 重度（major） | 需要治疗、住院时间延长（< 48 h） |
| 4 | 重度（major） | 需加强监护或介入/外科处理（> 48 h） |
| 5 | 重度（major） | 永久性不良后遗症 |
| 6 | 重度（major） | 死亡 |

**拆解两步**：

- **第一步，学会「如实分级」**：把一个出血并发症标成「需要输血住院」的 3 级而不是「观察即可」的 1 级，不是小题大做——**分级决定记录、随访与质量改进的方向**。
- **第二步，用分级倒逼预防**：回顾性统计各级并发症的发生率，是介入质控（对每一例并发症复盘）的基础。**「没记录就等于没发生」——并发症管理的第一步是诚实记录。**

### 临床小场景：一次「迟到的过敏反应」

一位 60 岁女性做冠脉造影，术中输注低渗对比剂，一切顺利，回病房 2 小时后却开始**全身荨麻疹伴面部肿胀、气促**。护士立即呼叫，诊断考虑迟发性过敏样反应，予抗组胺药与糖皮质激素，症状缓解，留观 24 小时无再发。

这个病例提醒两件事：**过敏反应不一定「当场发生」**——对比剂相关反应可分速发（数分钟内）与迟发（数小时至数天），术后观察期不能放松；**预案要「放在手边」**——造影室与病房都要备好肾上腺素、糖皮质激素与气道管理设备。围手术期的「警惕」，从术前延续到术后很久，才是完整的闭环。

## 6 小结

- **术前**评估凝血、肾功能、用药与知情同意，把高危患者筛出来；栓塞与神经介入对凝血要求最严。
- **术中**镇静监护、肝素管理、**ALARA 辐射防护**并重。
- **CI-AKI 预防**用 Cigarroa 公式 $V_{\max} = 5 \times 体重/肌酐$（mL），一般不超过 300 mL，「算、记、省、补」四字诀。
- **SIR 并发症分级**（1–6 级）是描述严重度的通用语言，「如实分级 + 诚实记录」是介入质控的基础。
- **围手术期管理是全专题的「闭环」**：术前筛风险、术中按风险、术后盯隐患，贯穿本专题全部十节。

至此，从一根针、一条导丝的 Seldinger 技术出发，我们走完了「看清血管—堵住血管—开通血管—撑开管腔—穿刺引流—急诊止血—静脉分流—神经介入—肿瘤治疗」的介入地图，最后以并发症管理收束。这十节并不只是十种技术，更是一套统一的临床思维：**影像做导航、介入做治疗、管理做保障**。带着这套思维再去读《介入放射学》与 Handbook 的任何一章，你都只会更从容。
