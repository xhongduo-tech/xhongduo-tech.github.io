## 为什么从头颈肿瘤开始

前面十篇讲的都是「炎症、功能障碍与重建」，这一篇换成耳鼻喉科最沉重的主题——**恶性肿瘤**。头颈肿瘤（head and neck cancer, HNC）覆盖从颅底到锁骨上窝的全部黏膜与器官，其中**鳞状细胞癌（SCC）**占 90% 以上。

但头颈肿瘤又是理解「肿瘤学如何驱动外科学」的最佳窗口：它把**器官保留**（larynx 不切喉）、**病毒致癌**（HPV/EBV）、**多学科联合**（外科+放疗+化疗+免疫）三个当代肿瘤学的核心命题集于一身。对于「从极限到大模型」的主线，HPV 相关口咽癌的爆发更像一个「流行病学的拐点检测」案例——吸烟相关头颈癌在下降，而 HPV 相关的在年轻人群里上升。

先看体量：头颈癌全球每年新发约 90 万例，其中**口咽与口腔**是西方最常见的部位，**鼻咽**在东非与**中国南方**高发；男性发病约为女性的 2–4 倍。在中国，鼻咽癌的地域聚集（广东、广西、福建、台湾）与其说是一个数字，不如说是一条「地理 × 病毒 × 遗传 × 饮食」四条证据链交汇的流行病学标本。把「哪些部位、哪些人、哪些诱因」这三问记住，头颈癌的临床地图就立住了：**它是一组「暴露决定部位」的癌**——烟酒作用于整个上呼吸消化道，HPV 特攻口咽，EBV 特攻鼻咽。

## 1 两种病因学：烟草酒精与病毒

头颈癌的病因学可以粗分成「两块大陆」，预后天差地别：

**传统型（烟草 + 酒精）**：口腔、喉、下咽等部位的鳞癌，多见于中老年男性吸烟饮酒者。烟草与酒精有**协同致癌**作用（不只是叠加）。这部分人群的头颈癌正随吸烟率下降而下降。<span class="marginnote">烟草的致癌机制是多环节的：多环芳烃与亚硝胺形成 DNA 加合物 → TP53 基因突变（头颈癌约半数有 TP53 突变）→ 抑癌功能丧失。<strong>饮酒协同</strong>则通过乙醇代谢产物乙醛直接损伤 DNA，并增加黏膜对烟草致癌物的通透性——「烟酒不分家」在分子层面是真的。</span>

**病毒型**：
**HPV 相关口咽癌**（扁桃体、舌根）：主要 HPV16 型，经口传播，患者**更年轻、多为非吸烟者**，p16 免疫组化阳性。预后显著好于传统型——放化疗敏感性高。这是过去 20 年头颈癌流行病学最大的变化。
- **EBV 相关鼻咽癌（NPC）**：**在中国南方（尤其广东）与东南亚高发**，与腌制品（亚硝胺）摄入、EBV 感染相关，以鳞癌的非角化型为主。治疗以放化疗为主，**疗效好、可治愈**——是「放疗主导」的头颈癌代表。<span class="marginnote">NPC 与华人地域的关联是肿瘤流行病学的著名现象：广东裔人群移居海外后发病率仍高，提示遗传易感 + EBV + 饮食三因素叠加。EBV 血清学（VCA-IgA、EBV DNA 拷贝数）是筛查与监测的指标——这是「病毒标志物驱动随访」的模板。</span>

两大病因学还决定了**预防**的策略不同：烟酒型靠**戒烟限酒**（传统头颈癌正在随吸烟率下降而下降）；病毒型里的 HPV 相关口咽癌则可以靠**HPV 疫苗**预防——「疫苗防癌」从宫颈癌延伸到头颈癌，是下一代头颈肿瘤学最值得期待的增量。而 HPV 阳性的生物学还改写了预后：同一分期，p16 阳性者治愈率高、复发率低，这让「分子分型决定治疗强度」成为现实。

## 2 解剖部位与临床表现：警惕「能自己走的肿瘤」

头颈癌按解剖分站，各自有「报警信号」：

| 部位 | 典型报警症状 |
| --- | --- |
| 口腔 | 不愈合的溃疡/白斑（黏膜白斑=癌前）、肿物 |
| 口咽 | 咽痛、吞咽痛、**颈部肿块**、耳痛 |
| 喉 | **声嘶 >3–6 周**、吞咽痛 |
| 下咽 | 吞咽困难、声音改变、**耳痛** |
| 鼻咽 | 单侧鼻塞/血涕、**分泌性中耳炎**、颈部肿块 |
| 鼻窦 | 单侧鼻塞、血涕、面部肿胀、牙痛 |

（细看这张表会发现一个共性：**单侧性**。鼻窦癌单侧鼻塞血涕、鼻咽癌单侧耳鸣耳闷、声带癌单侧声嘶——「单侧、进行性、不消退」是头颈癌报警信号的共同基因，而炎症多为双侧或可消退。这个「单侧 vs 双侧」的速判，在门诊一分钟内就能完成。）

三个「不能漏」的信号值得单独强调：<span class="marginnote"><strong>易错点一：耳痛（otalgia）</strong>。下咽、喉、扁桃体肿瘤通过舌咽神经（CN IX）与迷走神经（CN X）<strong>牵涉性放射</strong>到耳——「耳朵疼，病灶在喉咙」。凡是不明原因的耳痛，尤其伴吞咽不适或声嘶，必须查咽喉，不能只查耳朵。</span>**易错点二：成人颈部肿块 >2 周不消退，先当癌查**——头颈癌的最初表现常常就是「脖子上长个包」（转移淋巴结），原发灶可能还很小。**易错点三：声嘶超过 6 周必须喉镜**——喉癌的早期信号就是「哑」，而早期喉癌治愈率高达 80–90%。

**未知原发（unknown primary）**是另一个必须记住的场景：患者以颈部肿块就诊，活检证实为鳞癌转移，但喉镜、影像、扁桃体活检都找不到原发灶。处理办法是「盲区排除法」：扁桃体切除术（常见隐匿原发灶）、PET-CT、以及**经口机器人手术（TORS）**取舌根/扁桃体——分子标志（p16）常提示原发在口咽。**颈部的肿块是线索，找到原发是目标，找不到也要按已分期方案治疗**——这是头颈外科最考验系统性思维的情形之一。

## 3 诊断与分期：TN M 系统的决策语言

**癌前病变**值得一提：口腔的**白斑（leukoplakia）**是最常见的癌前病变（约 5–20% 恶变），**红斑（erythroplakia）**恶变率更高（可达 50%）——凡是口腔里「不痛的、不消退的、性质改变的白斑红斑」，都要活检而不是观察。HPV 相关口咽癌则常以「单侧扁桃体不对称肿大」或「颈部肿块」起病，没有典型黏膜白斑——因为它的「原发」常常很小甚至看不见。

**诊断工作流**：临床体检（触诊颈部淋巴结）→ **内镜评估**（喉镜/鼻咽镜）→ **影像**（CT/MRI 判断局部侵犯，PET-CT 判断远处转移）→ **活检**（病理金标准；颈部肿物用细针穿刺 FNAC 或切开活检）→ 麻醉下**全上消化呼吸道内镜（panendoscopy）**评估多灶。

影像在头颈癌里的角色是「看清边界」：**CT 看骨质破坏与淋巴结坏死，MRI 看软组织侵犯与神经播散（腺样囊性癌的嗜神经性是 MRI 的舞台），PET-CT 看远处转移与复发**。其中「**淋巴结坏死**」是影像上的恶性信号——良性肿大淋巴结不坏死，坏死基本指向转移癌。一条简单的读片规则：**颈部淋巴结短径 >1 cm 或出现坏死，就要按转移癌对待**。

**分期用 TNM 系统**（T=原发灶，N=淋巴结，M=远处转移），以喉癌为例感受「T」的分级：

| T 分期 | 喉癌（声门型）定义 |
| --- | --- |
| T1 | 肿瘤限于声带（黏膜下），声带活动正常 |
| T2 | 累及声门上/声门下，声带活动受限 |
| T3 | 声带固定 或 侵犯喉旁间隙 |
| T4 | 穿透甲状软骨/侵犯喉外结构 |

**辨析｜易错点：** TNM 的 N 不看淋巴结「大小」看「**部位、个数与大小**」的组合——颈部淋巴结分级（N1/N2a/N2b/N2c/N3）决定清扫范围；**而 p16（HPV）阳性对分期有「降期」意义**：同样的 T4N3 口咽癌，p16 阳性者按新分期规则降为 IV-A，因为预后完全不同。

**分期是决策的语言，也是预后的预言**：同一种喉癌，T1 的 5 年生存率可超过 85%，而 T4 伴颈部转移者可能不足 40%。这张「一分期一天壤之别」的落差，正是「早诊断 = 治愈」这句话在头颈癌上的量化版本——也解释了为什么「声嘶 6 周」「颈部肿块 2 周」这些红线被写得如此绝对。<span class="marginnote">这就是「分子分期」开始改写「解剖分期」：HPV 阳性口咽癌的 TNM 在 AJCC 第 8 版单独立章（不同的 N 分级、不同的预后层）。分子标志物进分期系统，是当代肿瘤学「从解剖到分子」的标志性一步。</span>

## 4 治疗策略：器官保留与多学科

头颈癌治疗的基本原则是「**以治愈为目标的器官功能保留**」，核心工具三件套：手术、放疗、化疗/靶向/免疫。按部位与分期，主流策略可先概览成一张表：

| 部位/情形 | 主流治疗 | 器官保留要点 |
| --- | --- | --- |
| 早期声门喉癌（T1–T2） | 激光显微手术或放疗 | 声音基本保留 |
| 局部晚期喉癌 | 诱导化疗+放化疗（chemoRT） | 保留喉（不行则全喉切除） |
| 早期口腔癌 | 手术 + 颈清扫 | 重建皮瓣修复缺损 |
| HPV+ 口咽癌 | 放化疗（或降级试验） | 长期毒性最小化 |
| 鼻咽癌 | 同步放化疗 | 放疗主导、疗效好 |
| 复发转移 | 免疫（PD-1）/靶向 | 姑息与生活质量 |

**早期（I–II 期）**：单用手术或放疗即可，目的在「切得干净且保住功能」。早期喉癌用激光显微手术或放疗，声音基本保留；口咽、口腔的早期病灶多用**经口手术**（经口激光显微手术或机器人 TORS）——从口腔进，不在颈部留切口，是「微创」在头颈癌里的正解。
- **局部晚期（III–IV 期）**：需要多学科组合。**喉器官保留**的经典路径：诱导化疗 + 放化疗（chemoRT），或同步放化疗——用「化疗让肿瘤对放疗更敏感」换回患者的喉咙。切喉（全喉切除术）只用于保喉治疗失败或病变太重者。
- **HPV 阳性口咽癌**：因放化疗效果好，正在做**降级（de-escalation）试验**——减少治疗强度以减少长期毒性（吞咽困难、口干），前提是不损治愈率。降级试验是「预后好的癌少治」的代表作：同一分子分型（p16+）给了我们「少治的底气」，这是分子肿瘤学对患者最实在的善意。
- **免疫/靶向**：PD-1 抑制剂（pembrolizumab）用于复发转移一线或顺铂不适合者；EGFR 单抗（cetuximab）在放疗中的增敏角色。

免疫治疗的兴起也改变了「复发转移」的预后叙事：过去复发转移头颈癌的中位生存以月计，如今 PD-1 抑制剂把一部分患者的生存拉长到以年计——「免疫哨卡」是头颈癌过去五年最大的治疗突破。
- **鼻咽癌**：以**同步放化疗**为核心，局部控制率与生存率高，即使局部晚期也有相当一部分可治愈。<span class="marginnote">放化疗的物理基础可回溯到辐射生物学的经典模型：肿瘤细胞的辐射杀伤遵循「剂量-存活」的指数关系（线性-平方模型 $S = e^{-\alpha D - \beta D^2}$），联合化疗的作用之一是把 $\alpha$ 项「垫高」——即让同样的剂量杀死更多细胞。理解 LQ 模型，是理解「为什么同步放化疗」的钥匙（详见《肿瘤放射治疗学》专题）。</span>

**核心要点**：头颈癌的治疗不再是「外科一刀切」，而是**多学科团队（MDT）**在同一张桌上排布手术、放疗、药物与康复——器官保留率是衡量团队水平的指标，而「保留功能」与「根治肿瘤」的平衡，永远是临床上最难的取舍。这也是为什么现代头颈肿瘤中心都要求「手术 + 放疗 + 肿瘤内科」三位一体：单科思维既保不住器官，也根治不了肿瘤。

**颈部转移淋巴结的处理**是头颈癌的另一条主线：早期口咽/口腔癌常伴隐匿性颈转移（触诊阴性但病理有），故不少「早期」病例也要做**选择性颈清扫（elective neck dissection）**。清扫的原则是「**清扫 N 的解剖分区，而不是摘单个淋巴结**」——颈部按 Level I–V 分区，清扫范围由原发部位与临床 N 分期决定。头颈癌的「癌」经常是「颈部的癌」——先摸脖子，往往比查原发更有信息量。

治疗后的**长期随访与功能康复**同样重要：放疗会带来不可逆的**口干（唾液腺损伤）、吞咽困难、下颌骨放射性坏死**；喉保留手术后的**吞咽训练**与气管切开患者的沟通，都需要专门的康复团队。头颈癌患者还是**第二原发癌**的高危人群（上呼吸消化道多部位同时受烟酒致癌物暴露）——随访时要同时盯住第二原发的筛查。

## 5 小结

- - 头颈癌以**鳞癌**为主，病因学分两块：**烟酒型**（口腔/喉/下咽，TP53 突变，预后一般）与**病毒型**（HPV 口咽癌预后好、EBV 鼻咽癌华南高发）。
- 预防的两大杠杆：**戒烟限酒（传统型头颈癌）与 HPV 疫苗（HPV 相关口咽癌的下一代预防）**——病毒型头颈癌的上升正在让「疫苗防癌」成为头颈肿瘤学的新战场。
- 三个必记报警信号：**不明原因耳痛（牵涉痛）、成人颈部肿块 >2 周、声嘶 >6 周**；口腔白斑红斑要活检而非观察。
- 诊断工作流：**癌前病变识别 → 内镜 → 影像 → 活检 → 分期（TNM）**，颈部淋巴结坏死是影像上的恶性信号。
- 诊断流程：**内镜 + 影像 + 活检（金标准）**；分期用 **TNM**，p16（HPV）阳性有独立分期与更好预后。
- 治疗原则是**以治愈为目标的器官保留**：早期单用手术/放疗，局部晚期放化疗联合，HPV+ 口咽癌探索降级治疗，NPC 以放化疗治愈。
- 头颈癌的现代范式是**多学科 MDT**：外科、放疗、化疗、免疫与康复在同一张决策桌上协作。
- 头颈癌的核心思维一句话：**「单侧、进行性、不消退」先当癌查，颈部分区清扫，器官保留优先**。
- 治疗后的**随访与康复**是治疗的组成部分：口干、吞咽困难、第二原发癌的长期筛查，与肿瘤复查同样重要。

- 颈清扫按**解剖分区（Level I–V）**实施；颈部转移淋巴结伴坏死是影像上的恶性信号。

- 分期是「一分期一天壤之别」：T1 与 T4 的生存率差距，就是「早诊断 = 治愈」的量化版本。

在下一节，我们进入本专题的「内分泌外科」篇——**甲状腺与甲状旁腺外科**：一个只有几十克、位于颈前的内分泌器官，如何把精细的手术、致命的神经保护与严密的激素调节编织成一体。它也是「过度诊断」与「精确治疗」之争的最典型战场。
