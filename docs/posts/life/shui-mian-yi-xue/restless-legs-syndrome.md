## 为什么从不宁腿开始

睡眠相关运动障碍是 ICSD-3 的一大类，而其中最常见的两种是**不宁腿综合征（restless legs syndrome，RLS）**与**周期性肢体运动障碍（periodic limb movement disorder，PLMD）**。<span class="marginnote">RLS 的体验常被患者描述为「<strong>腿里像有蚂蚁在爬、说不出的难受，必须动一动才缓解</strong>」——它极易被误诊为「缺钙」「神经衰弱」甚至「焦虑」，但实际上有明确的诊断标准、机制与有效治疗。<strong>「夜里腿不安」是它最典型也最容易被忽视的求救信号。</strong></span>

从「从极限到大模型」的主线看，这一节是「**多巴胺系统 × 铁代谢 × 睡眠**」的交汇课：RLS 的发病与**脑内铁缺乏、多巴胺功能障碍**密切相关，而它又通过扰乱睡眠结构，成为「白天困倦、睡眠差」的幕后推手。**看懂 RLS，等于看懂一个「神经化学障碍如何伪装成睡眠问题」的完整案例。**

## 1 不宁腿综合征：四条核心诊断标准

RLS 的诊断依靠国际不宁腿综合征研究组（IRLSSG）的**四条必需标准**：

**（1）腿部（或其他部位）难以忍受的不适感与活动冲动**：酸、麻、胀、爬行感、烧灼感——患者必须**动腿**（走动、伸展、揉搓）才能缓解。<span class="marginnote">关键是「<strong>活动冲动</strong>」——RLS 不只是「不舒服」，而是「有一股要动的冲动」。<strong>「静不下来、必须动」是把 RLS 与单纯的「腿麻」区分开的试金石。</strong></span>

**（2）休息/静止时加重**：坐下、躺下、久坐时症状出现或加重——**静止是 RLS 的放大器**。

**（3）活动后部分或完全缓解**：走动、伸展、揉搓后症状减轻——缓解在活动**持续期间**有效，活动停止后又可能回来。

**（4）傍晚/夜间加重**：症状呈明显的**昼夜节律**——黄昏到午夜最重，清晨相对缓解。<span class="marginnote">这四条的顺序有讲究：<strong>冲动 + 静重 + 动缓 + 夜重</strong>——四条全符合才诊断 RLS。<strong>「夜里腿难受得睡不着、起来走走就好」的叙述，几乎就是 RLS 的标准画像。</strong></span>

**鉴别要点**：RLS 需与**夜间腿抽筋**（疼痛性痉挛、肌肉紧张）、**周围神经病**（麻木、刺痛、无活动冲动）、**静坐不能**（抗精神病药引起、无昼夜节律）区分——**「有无活动冲动 + 有无昼夜节律」是快速鉴别尺**。

## 2 流行病学与危险因素

**RLS 的规模**：患病率约 5%–10%，**女性约为男性的 1.5–2 倍**；患病率随年龄上升，中老年常见，但任何年龄均可起病。<span class="marginnote">「腿不安在晚上」如此常见，却长期被忽视——一项观察显示 RLS 患者在确诊前平均经历了数年甚至更久的「说不清哪里不舒服」的就医。<strong>「问一句『晚上腿有没有不舒服』」，是识别大量 RLS 的最低成本动作。</strong></span>

**核心危险因素**：

**铁缺乏（最重要且可治疗）**：血清**铁蛋白 < 50–75 ng/mL** 时 RLS 风险明显升高——脑内铁缺乏影响多巴胺合成。**「查铁蛋白」是 RLS 的必查项目**，缺铁者补铁是基础治疗。<span class="marginnote"><strong>铁与多巴胺的关联</strong>：铁是多巴胺合成（酪氨酸羟化酶）的辅助因子，脑内铁不足 → 多巴胺系统功能下降 → RLS。<strong>「补铁」有时比「上药」更治本</strong>——这也是为什么 RLS 治疗前必查铁蛋白（不仅看贫血，更看铁储备）。</span>

**妊娠**：孕晚期 RLS 常见（患病率可达 20% 以上），与血容量扩张、铁需求增加有关——多数产后自行缓解。

**终末期肾病/透析**：尿毒症患者 RLS 患病率高，与贫血、铁缺乏、尿毒症毒素相关。

**遗传**：RLS 有家族聚集性，多个易感基因（MEIS1、BTBD9 等）已确认——**「家族里好几个人晚上腿难受」是常见家族史**。

**其他**：帕金森病、贫血、糖尿病、某些药物（抗抑郁药、抗组胺药、多巴胺拮抗剂）可诱发或加重 RLS。

**药物诱发的 RLS**：**SSRI/SNRI**（氟西汀、舍曲林、文拉法辛等）与**抗组胺药**（苯海拉明、氯苯那敏）是两类最常见的诱发者——**「吃抗抑郁药后腿开始难受」并不少见**。识别药物因素的意义在于「能停则停、能换则换」，比加用 RLS 药物更治本。**「问一句用药史」是 RLS 问诊的必修课。**

## 3 发病机制：多巴胺 × 铁 × 昼夜节律

RLS 的机制目前认为与**中枢多巴胺系统功能障碍**与**脑内铁缺乏**两大因素相关，并被**昼夜节律**调制：

**多巴胺假说**：脑内**间脑 A11 多巴胺能通路**（下行到脊髓的抑制性多巴胺通路）功能障碍，导致对感觉与运动信号的下行抑制减弱——腿部的异常感觉「不被压住」。<span class="marginnote">RLS 与帕金森病共享「多巴胺能缺陷」的线索，但 RLS 的多巴胺问题更局限（A11 下行通路）、更与铁相关——<strong>「RLS 是 '铁-多巴胺' 特异的神经化学问题，不是帕金森病的前兆」</strong>，两者不可混为一谈。</span>

**铁假说**：脑内铁缺乏 → 多巴胺合成与受体功能下降 → 症状出现；脑内铁水平与症状严重度相关，且**补铁可改善部分患者**——铁是「上游的根」。

**昼夜节律调制**：RLS 症状在**傍晚-夜间加重**，与多巴胺能活动、铁相关蛋白的昼夜节律一致——**「夜重」不是心理作用，而是有昼夜节律的生理基础**，这也把 RLS 与第 1 篇的节律框架接上了线。

**一句话机制**：**脑内「铁→多巴胺」轴的功能不足 + 昼夜节律在夜间放大 → 腿部异常感觉与活动冲动在夜里失控。**

## 4 周期性肢体运动：RLS 的「表亲」

**周期性肢体运动（periodic limb movements，PLMs）**：睡眠中下肢（多为胫前肌）出现**周期性、重复性的抽动/伸展**，每次约 0.5–5 秒，间隔 5–90 秒（常约 20–40 秒一次），多见于 NREM。<span class="marginnote">PLMs 的判读靠<strong>胫前肌电（EMG）</strong>：PSG 记录到「连续 ≥ 4 次、间隔规律、时长 0.5–5 s」的腿部运动，就计为一次「PLM 序列」。<strong>它是睡眠监测里的「腿动计数」，普通手环测不到。</strong></span>

**PLM 指数（PLMI）**：每小时 PLM 次数。**成人 ≥ 15 次/小时、儿童 ≥ 5 次/小时**常被认为「显著」，但**仅有 PLMs 而无症状不构成疾病**。<span class="marginnote"><strong>关键区分</strong>：<strong>PLM 是「现象」，PLMD（周期性肢体运动障碍）是「疾病」</strong>——只有当 PLMs 引起睡眠破碎、日间困倦/疲劳，且排除了其他原因时，才诊断 PLMD。<strong>「测得腿动多 ≠ 有病」，要看它是否真的打扰了睡眠与日间功能。</strong></span>

**RLS 与 PLM 的关系**：约 80%–90% 的 RLS 患者合并 PLMs，但 PLMs 也可见于无 RLS 者、OSA 患者（呼吸觉醒触发）及药物（抗抑郁药）相关——**PLM 是 RLS 的常见伙伴，但不是 RLS 的必要条件**。

## 5 公式解析：PLM 指数与睡眠的「碎片化账」

把「腿动怎么影响睡眠」量化，靠 **PLM 指数**：

$$
\text{PLMI} = \frac{N_{\text{PLM}}}{\text{总睡眠时间（小时）}}
$$

逐项拆解：

- **$N_{\text{PLM}}$（PLM 序列次数）**：整夜判读出的周期性肢体运动次数（每次 ≥ 4 个连续腿动算一次序列）。
- **分母（总睡眠时间）**：与 AHI 同理，用实际睡眠时长。<span class="marginnote">PLMI 与 AHI 是睡眠监测「两个计数维度」：AHI 数呼吸事件、PLMI 数腿动。<strong>两者都可能高、且可互相触发</strong>（OSA 的觉醒可诱发腿动，PLM 的觉醒又可加重睡眠破碎）——报告要「双指数同看」。</span>
- **临床意义**：PLMI ≥ 15 且伴睡眠/日间症状 + 排除其他 = 考虑 PLMD。**「腿动多」本身不是诊断，必须有「它打扰了你」的证据。**

**睡眠碎片化的链条**：PLM → 反复觉醒 → 睡眠效率下降、深睡减少 → 白天困倦疲劳——**「腿动不重，但睡眠结构被它切碎了」**。治疗 RLS/PLMD 的目标，不只是「腿别动」，更是「把睡眠结构修好」。

## 6 核心对比表：RLS 与 PLMD 一表看清

| 特征 | RLS | PLMD |
| --- | --- | --- |
| 核心症状 | 腿部不适 + 活动冲动（清醒时） | 睡眠中周期性腿动 |
| 发生时间 | 清醒静坐/躺卧时、夜间 | 睡眠中（NREM 为主） |
| 患者感受 | 明确的不适与冲动 | 多无自觉（床伴发现） |
| 诊断工具 | 问诊（四标准） | PSG（PLMI） |
| 治疗 | 补铁 + 非药物 + 药物 | 同 RLS（药物为主） |

**辨析｜易错点：** 三大易错——**①「RLS = 缺钙/腿抽筋」**：RLS 是不适 + 冲动、无痛性痉挛，与缺钙抽筋机制不同；**②「PLM 多 = PLMD」**：现象 ≠ 疾病，须有睡眠/日间症状；**③「先上药再查铁」**：不查铁蛋白就用药，可能漏掉「补铁可治」的根本因素。**「先查铁、再谈药」，是 RLS 治疗的第一原则。**

## 7 治疗

**第一层：非药物与病因处理**。**查铁蛋白**，若 < 75 ng/mL 则**补铁**（口服硫酸亚铁 + 维生素 C 或经评估静脉补铁）；**避免诱因**（咖啡因、酒精、抗组胺药、部分抗抑郁药）；**适度运动**（傍晚中等强度）与**腿部按摩/拉伸**；**规律作息**（睡眠剥夺加重 RLS）。<span class="marginnote">非药物干预的意义常被低估：<strong>「补铁 + 避诱因 + 规律作息」能解决一部分轻症 RLS</strong>——先走完这条「免费的路」，再考虑药物。<strong>「上来就开药」的处方，常忽略了最可治疗的上游因素（铁）。</strong></span>

**第二层：药物治疗**。**多巴胺能药物（普拉克索 pramipexole、罗匹尼罗 ropinirole）**曾是一线，但因**症状加重（augmentation）**——长期用药后症状提早出现、范围扩大、加重——其一线地位已被调整；**α2δ 钙通道配体（加巴喷丁恩那卡比 gabapentin enacarbil、普瑞巴林 pregabalin）**因加重风险低、更适合作一线，尤其对合并失眠与疼痛者。<span class="marginnote"><strong>加重（augmentation）是多巴胺能药物治疗 RLS 的头号陷阱</strong>：用药数月后，症状从傍晚提前到下午、从腿扩展到手臂、剂量越加越高却越压不住。<strong>「罗匹尼罗/普拉克索要谨慎、要随访、要防加重」</strong>——这是 RLS 治疗里最重要的用药纪律。</span>

**第三层：特殊人群**。妊娠 RLS 以非药物 + 补铁为主（多数药物避免）；肾衰患者注意剂量与铁管理；儿童 RLS 谨慎用药、优先行为与铁。

**疗效随访**：RLS 治疗以「症状严重度评分（IRLS 量表）+ 睡眠改善 + 生活质量」为随访目标；用药者还需**定期监测加重（augmentation）信号**（症状提前、范围扩大、剂量攀升）——**「有效 ≠ 一直有效」，加重的识别需要患者与医生的共同警觉**。

## 8 小结

- **RLS 四标准**：活动冲动 + 静止加重 + 活动缓解 + 夜间加重；「夜里腿难受、动动才好」是画像。
- **流行病学**：5%–10%，女性多；危险因素含**铁缺乏（可治）**、妊娠、肾衰、遗传、药物。
- **机制**：脑内「铁→多巴胺」轴功能不足 + 昼夜节律夜间放大；RLS 不是帕金森病前兆。
- **PLM vs PLMD**：PLM 是现象（PSG 计数），PLMD 是疾病（须伴睡眠/日间症状）；RLS 常合并 PLM。
- **治疗阶梯**：查铁补铁 → 避诱因 + 非药物 → 药物（优先 α2δ 配体、多巴胺能药防加重）→ 特殊人群个体化。
