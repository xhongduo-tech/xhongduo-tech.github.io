## 为什么从分类学开始

形态学告诉你"一条鱼由什么构成"，分类学回答下一个问题：**"这条鱼是谁？它和谁是亲戚？"** 分类学（taxonomy）是生物学的"图书管理员"——全球现存鱼类约 3.4 万种，若没有一套统一的命名与归类系统，任何人谈起"鲈鱼"都可能各说各话。更重要的是，分类不是死记硬背的标签游戏：**一个科学的分类系统，是对演化关系的最大胆假设**。同属一个类群，往往意味着共享祖先、共享生理与生态习性，从而共享养殖与管理的方法。因此水产学的每一步——选什么鱼养、用什么药、怎么防病——都要从"认准鱼、找对类群"开始。<span class="marginnote">分类学与系统学（systematics）稍有分工：前者侧重命名与归类的规则，后者侧重推断演化谱系。今天许多教材把它们合称"系统分类学"，本书按此口径使用。</span>

## 1 分类等级与双名法

生物分类有一套通用的等级阶梯，从上到下逐级细分：**界（Kingdom）、门（Phylum）、纲（Class）、目（Order）、科（Family）、属（Genus）、种（Species）**。口诀"界门纲目科属种"像套娃一样层层嵌套——相邻两级之间还可插入"亚纲、总目"等过渡等级。**种**是基本单位，指能自然交配、产生可育后代的群体；**属**是相近种的集合。

给每个物种命名，用的是林奈创立的**双名法（binomial nomenclature）**：**属名＋种加词**，斜体书写，后面常附命名人姓氏与年份。例如鲢的学名：

$$Hypophthalmichthys \ molitrix \ (Valenciennes, 1844)$$

**属名** $Hypophthalmichthys$ 首字母大写，意为"眼下"（下位的眼，形容其眼位于头部腹侧），**种加词** $molitrix$ 小写，意为"碾磨者"（指其以鳃耙滤食、像碾磨一样不停进食）。括号表示该种最初曾被放在别的属名下。学会读学名，就掌握了全球鱼类信息互通的"通用语言"——中文俗名常一地一名，而学名全球唯一。<span class="marginnote">鲢在长江中下游叫"白鲢"，两广叫"跳鲢"，英文叫 silver carp，无论俗名多乱，学名 $Hypophthalmichthys\ molitrix$ 只有一种写法。这也是为什么水产品国际贸易、检疫与执法都必须以学名为准。</span>

**辨析｜易错点：** 书写学名有四条易错规则——**属名首字母必须大写、种加词全小写、整体斜体**（手写时下划线）、命名人与年份正体不斜。写成"hypophthalmichthys Molitrix"、不斜体、或把命名人写进斜体，都是规范错误。**"品种（variety）"与"种（species）"也常被混淆**：种是分类单位，品种是人工选育的变体（如鲤的荷包红鲤、锦鲤），品种名不用斜体双名法。

## 2 鱼类的"三大纲"框架

传统鱼类分类把现存鱼类归入三大类群，它们代表了脊椎动物入水的三次浪潮：

**圆口纲（Agnatha）**：最原始的无颌鱼类。无真正的颌、无成对附肢，体表裸露无鳞，营寄生或腐食生活。代表是七鳃鳗与盲鳗。它们不是"退化"，而是**保留着脊椎动物最早的祖先形态**——约 5 亿年前的奥陶纪，最早"有脊索、无颌"的脊椎动物就是这副模样。

**软骨鱼纲（Chondrichthyes）**：内骨骼全为软骨，具颌、具成对鳍，鳞片为盾鳞。代表是鲨、鳐、魟。软骨不是"低级"的证据——鲨的软骨骨片间已出现钙化，比硬骨更轻，反而利于悬浮游泳。它们的成功之道是：**个体大、寿命长、繁殖力低、寿命期内长期处于海洋食物链顶端**。

**硬骨鱼纲（Osteichthyes）**：内骨骼骨化，绝大多数现生鱼类属此，约占总数的 96%。从淡水的鲤、鲫到深海的灯笼鱼，从体长不足 1 cm 的微鲤到体重 2 吨的翻车鲀，都在这一纲里。硬骨鱼之所以"霸占"水体，靠的是**鳔**（调浮力，摆脱硬骨的重压）与**鳃盖**（保护鳃并支持口咽部抽吸呼吸），这两项发明让硬骨鱼得以在水中三向机动。

> **核心要点（纯概念主题，以对比表替代公式解析）：三大纲对比**

| 特征 | 圆口纲 | 软骨鱼纲 | 硬骨鱼纲 |
| --- | --- | --- | --- |
| 颌 | 无 | 有 | 有 |
| 骨骼 | 软骨、无椎体 | 软骨（可钙化） | 硬骨 |
| 鳞片 | 无 | 盾鳞 | 硬鳞或骨鳞 |
| 鳃 | 鳃囊，鳃孔裸露 | 鳃裂外露，无鳃盖 | 鳃盖保护 |
| 鳔 | 无 | 无 | 多数有 |
| 生殖 | 体外受精，产卵 | 体内受精为主，胎生或卵胎生 | 体外受精为主，产卵 |
| 代表 | 七鳃鳗、盲鳗 | 鲨、鳐、魟 | 鲤、鲈、鲱 |

读这张表抓住一条主线：**从圆口纲到硬骨鱼纲，是"颌的出现—骨骼硬化—鳔与鳃盖的发明"三连进化**。每多一项"设备"，鱼类就多占领一片生态位。

硬骨鱼纲内部还藏着一条通往"陆地"的进化支线：它分**辐鳍鱼亚纲**（鳍条呈辐射状排列，绝大多数现生硬骨鱼属此）与**肉鳍鱼亚纲**（鳍内有肌肉与骨骼支撑，如同"四肢的雏形"）。肉鳍鱼中现存的肺鱼与腔棘鱼，是"鱼类登上陆地、演化为两栖类"的关键旁证——**四足动物（包括人类）的四肢，正是从肉鳍鱼的肉质鳍演化而来**。所以分类学不仅回答"谁是谁"，还回答"我们从哪里来"。

## 3 硬骨鱼纲的主要类群

硬骨鱼纲之下，真正决定水产实践的是几个"大目"：

**鲤形目（Cypriniformes）**：淡水鱼类第一大目，多为鲤科。特征是无颌齿而有咽齿（咽喉齿）、有韦伯氏器、常有口须。**鲤、鲫、草、鲢、鳙、青**这六大家鱼全在这里。养殖产量占中国淡水养殖的绝对大头。<span class="marginnote">六大家鱼其实各有分工：草鱼吃草、鲢鳙滤食浮游生物、鲤鲫杂食刮底、青鱼吃螺蚌。混养时它们各占一个生态位、几乎不抢食——这是中国池塘养鱼最精妙的设计，我们在《池塘养鱼》篇会专门展开。</span>
**鲱形目（Clupeiformes）**：多数为集群性中上层海洋鱼类，是全世界捕捞量最大的鱼类类群。代表为沙丁鱼、鲱、鳀——它们处于海洋食物链的中下层，把浮游动物转变成人类蛋白质的效率极高。
**鲈形目（Perciformes）**：硬骨鱼中种类最多的目（超过一万种），几乎占现生鱼类的三分之一。代表为鲈、石斑、黄鱼、罗非鱼。其关键特征是**腹鳍胸位或喉位、鳍通常具硬棘**——石斑鱼的背鳍棘有毒腺，鲈的刺是钓者最熟悉的存在。
**鲶形目（Siluriformes）**：体表无鳞或鳞极小，具发达的须，多为底栖。代表为鲶、鳢（乌鳢，也称黑鱼）、黄颡鱼（黄辣丁）。它们耐低氧、适应性强，是养殖中的"皮实型"品种。
**鲑形目（Salmoniformes）**：冷水性鱼类，代表为大麻哈鱼（鲑）、虹鳟、哲罗鲑。著名的"三文鱼"多为大西洋鲑与虹鳟，市场潜力巨大，但养殖要求高溶氧、低水温。

把中国最常见的养殖对象与学名对起来，是学习分类学的第一张实用表：

| 中文名 | 学名（属名＋种加词） | 所属目 |
| --- | --- | --- |
| 青鱼 | *Mylopharyngodon piceus\* | 鲤形目 |
| 草鱼 | *Ctenopharyngodon idella\* | 鲤形目 |
| 鲢 | *Hypophthalmichthys molitrix\* | 鲤形目 |
| 鳙 | *Aristichthys nobilis\* | 鲤形目 |

记住几个规律：鲤形目的六大家鱼学名都以"鲤科"为大宗；鲈形目明星众多，鲈、罗非鱼、大黄鱼都属此目；而"三文鱼"其实是商品名，对应大西洋鲑与虹鳟两个不同种——**看学名，才能识破"商品名混淆"**。

## 4 检索表：分类学的"路线图"

认识了类群还不够，野外/塘边拿到一条鱼，怎么确定它是谁？工具是**检索表（identification key）**。它把特征做成二选一的分叉问题，一步步缩小范围：

1. 有颌 → 进入 2；无颌 → 圆口纲。
2. 内骨骼为软骨 → 软骨鱼纲；内骨骼为硬骨 → 进入 3。
3. 鳞为硬鳞 → 软骨硬鳞鱼（如鲟）；鳞为骨鳞 → 进入 4。
4. 腹鳍腹位、具韦伯氏器 → 鲤形目；腹鳍胸位或喉位 → 鲈形目……

这种"是/否"的逐级二分法，本质是**决策树**。用二分检索表认鱼时，两条路必须"非此即彼"地准确互斥——若写检索表的人把"咽齿有无"与"口须长短"混在一起，检索就失效。这也提示：**分类特征是必须精确定义、稳定可测的性状**，这正是形态学为分类学提供的弹药。<span class="marginnote">检索表的"逐级二分"结构，与计算机里的二分查找、决策树分类同构——给定一个未知样本，用一组判别规则把它归入某一类。所以《鱼类学》的检索表训练，也是在训练一种最朴素的算法思维。</span>

现代分类学已经引入分子手段：**DNA 条形码（barcoding）**——测一段线粒体 COI 基因序列，与数据库比对即可"刷码认鱼"。它解决了形态相近、幼鱼难辨的难题，也让水产品掺假鉴定（用便宜鱼冒充名贵鱼）有了铁证。分子数据还不断改写传统分类：许多按形态归为一类的鱼，在基因树上被拆开或重新聚拢——**分类系统一直在被修订，这正是它作为"演化假设"的正常状态**。

**分类学的现代价值已经溢出"认鱼"本身**：海关检疫靠 DNA 条形码识别走私鱼类；生态调查用环境 DNA（eDNA）——从水样里提取鱼体脱落的微量 DNA，就能检测该水域存在哪些鱼种，不必真把鱼捞上来。分类学的知识，正通过分子工具变成保护、执法与监测的利器。

## 5 中国的鱼类资源版图

把分类知识落到地图上，中国是全球鱼类多样性最高的国家之一：

- **淡水鱼**：中国淡水鱼类超过 800 种，鲤形目占主导。长江水系有青草鲢鳙、中华鲟、胭脂鱼，珠江与黄河各有特色类群。
- **海洋鱼**：中国近海记录鱼类约 2000 种，以暖水性、暖温性种为主，鲈形目、鲱形目、鲽形目（比目鱼）常见。南海珊瑚礁区是种类最多的"热区"。
- **特色类群**：中华鲟（溯河洄游、被称为"水中大熊猫"）、长江江豚虽非鱼类但同受关注；大麻哈鱼每年秋季溯黑龙江而上产卵，是典型的溯河洄游鱼。

**分布格局的背后是温度与地形**：纬度越低种类越多，长江水系支流众多、生境多样，故种类冠绝全国。这也提醒我们，谈"中国水产"不能笼统——同样是养鱼，长江流域的混养模式与南海的网箱养殖几乎是两门技术。

**分类学在保护中的角色同样关键**：中华鲟、长江江豚（虽非鱼）等珍稀物种的"身份认定"，直接决定保护等级与保护措施；而"外来入侵种"（如清道夫、食蚊鱼）的识别，则是生态防控的第一道关卡——没有准确分类，保护与防控都会"找错对象"。

## 6 小结

- **分类等级**：界门纲目科属种逐级嵌套，**种**为基本单位；**双名法**（属名＋种加词，斜体）保证全球唯一命名。
- **三大纲**：圆口纲（无颌）、软骨鱼纲（软骨、盾鳞）、硬骨鱼纲（硬骨、鳔、鳃盖），主线是"颌—硬骨—鳔鳃盖"的进化三连。
- **重要类群**：鲤形目撑起中国淡水养殖（六大家鱼），鲱形目是海洋捕捞的产量担当，鲈形目种类最繁，鲶形目皮实耐低氧，鲑形目是冷水养殖明星。
- **检索表**是逐级二分的认鱼路线图，现代分类引入 DNA 条形码，分类系统随分子证据不断修订。
