# 抗逆育种（抗病/抗虫/抗旱）

## 为什么从抗逆育种开始

前面的章节都在优化「把产量推向极限」，但所有产量都建立在一个前提上：作物**活着**。稻瘟病可以在几周内毁掉一片稻田，棉铃虫可以啃光一季收成，一场干旱可以让多年育种成果颗粒无收。抗逆育种做的是「守住底线」的工作——让品种在被病、虫、旱围攻时依然存活。<span class="marginnote">数字的残酷：全球每年因病害损失作物产量的约 10–15%，虫害再加约 10–18%。爱尔兰 1845 年马铃薯晚疫病大饥荒证明，当遗传脆弱性遇上病原演化，文明也要付出代价。抗病育种因此有远超经济账的意义。</span>

## 1 抗病性：垂直抗性与水平抗性

植物对病原的抗性分为两种基本策略：

**垂直抗性（vertical resistance）**：由单个主效基因（R 基因）控制的**专化抗性**，对特定小种有效且强烈，但病原一变异（新小种出现）就失效——「一招鲜，但会翻车」。
- **水平抗性（horizontal resistance）**：由多个微效基因控制的**非专化抗性**，对所有小种都「部分有效」，病原很难突破——「没有绝招，但很稳」。

二者的动力学完全不同：垂直抗性像「锁与钥匙」，弗洛尔的 **基因对基因（gene-for-gene）假说** 给出了精确模型——寄主的每个抗病基因 $R$，对应病原的每个无毒基因 $Avr$；只有 $R$ 存在且病原携带匹配的 $Avr$ 时，才触发过敏性坏死反应（HR）产生抗性。<span class="marginnote">弗洛尔用亚麻与锈菌的经典实验确立了「一对一」关系：寄主每有一个显性抗病基因，病原就有一个对应的显性无毒基因。这套「识别—反应」模型后来被证明同样适用于细菌、病毒与真菌病害，成为植物免疫学（PTI/ETI）的源头。</span>

分子层面的对应已经相当清晰：多数 R 基因编码 **NBS-LRR 类蛋白**（核苷酸结合位点—富亮氨酸重复蛋白），它们在胞内充当「哨兵」，识别无毒蛋白 Avr 后触发**过敏性坏死反应（HR）**与系统获得抗性（SAR）。这套「识别—警戒—杀伤」机制与动物先天免疫高度同源，正是「基因对基因」假说在现代分子植物病理学里的落地形态。

把两种抗性放进同一张表对比，育种决策的依据就一目了然：

| 维度 | 垂直抗性 | 水平抗性 |
| --- | --- | --- |
| 遗传基础 | 单主效 R 基因 | 多微效基因 |
| 抗性谱 | 针对特定小种 | 广谱、部分有效 |
| 持久性 | 易被新小种突破 | 持久、难突破 |
| 选择策略 | 聚合/轮换 | 轮回选择、GS 累加 |
| 典型场景 | 锈病小种特异性 | 多数叶部病害 |

## 2 抗病育种策略

针对两种抗性，育种策略也分成两派，且常组合使用：

**利用 R 基因**：通过杂交、回交、MAS 导入主效抗病基因。优点是见效快、抗性强；缺点是**易被病原新小种突破**，必须**基因聚合**（同时导入多个 R 基因）或**基因轮换**（不同品种携带不同 R 基因）来延缓失效。
- **利用水平抗性**：选择多基因微效抗性，通过轮回选择、基因组选择（GS）逐步累加。见效慢但持久，是「可持续抗病性」的主流追求。<span class="marginnote">这与「抗生素耐药」的问题同构：专化抗性像单一靶点的抗生素，病原一突变就耐药；水平抗性像多靶点联合用药，病原难以同时突破。抗病育种的智慧本质上是「让防线多元化」。</span>

**关键配套**：抗病性不是品种单方面的事，而是**寄主—病原—环境**三方互动的结果。育种家靠三个要素协同管理：抗病品种 + 病原监测（小种普查）+ 栽培措施（轮作、播期）。单靠品种，抗性迟早被演化击穿。

病原监测（小种普查）是抗病育种体系里「看不见却最关键」的一环：每年从产区采集标样、鉴定小种组成，才能知道现有品种的抗谱还够不够、下一个要聚合哪个 R 基因。**没有监测，抗病育种就是盲打**——这与流行病的病原监测在方法上同构。

**辨析｜易错点：** 基因聚合不是「R 基因堆得越多越好」。多个 R 基因会带来选择压力叠加、也可能存在上位互作；聚合的实质是「在同一遗传背景下叠加识别不同小种的 R 基因」，其效果要靠病原小种组合的接种谱检验，而不是只数基因个数。**数量 ≠ 抗谱，验证才算数。**

## 3 抗虫育种：三类机制

植物抗虫机制经典地分三类：

**抗生性（antibiosis）**：品种对害虫的发育、繁殖产生不利影响——如含抗虫物质，害虫吃了长不大。典型的分子实现是 **Bt 抗虫蛋白**：苏云金芽孢杆菌的晶体蛋白基因转入棉花、玉米后，害虫取食即中毒。<span class="marginnote">Bt 棉是抗虫育种史上最大规模的产业化：中国自 1997 年推广 Bt 棉后，棉铃虫防治用药大幅下降。而「抗虫性 = 害虫毒药」的思路也带来生态约束——必须种植非 Bt 的「庇护所」来延缓抗性害虫的演化，这是进化博弈写进农业规程的罕见案例。</span>
- **耐害性（tolerance）**：品种虽受害虫取食，但能补偿，产量损失小——「打不死，还能长」。
- **拒虫性（antixenosis）**：品种不吸引害虫或不适合其产卵取食，靠形态或化学信号「劝退」。

**抗虫育种的关键**：单基因抗虫（Bt）效果猛但选择压巨大，需庇护所管理；多基因/多机制组合（如抗生 + 耐害 + 拒虫叠加）才是持久之道。

**庇护所的量化逻辑**：设抗性等位基因初始频率为 $q$，若田间全部种植 Bt，抗性个体将持续被正选择放大；保留一定比例的非 Bt 庇护所，能让敏感个体存活并与抗性个体交配、稀释抗性频率。经典估算下，5%–20% 的庇护所面积通常足以把抗性演化推迟数代——**这是把进化论写成农业规程的罕见案例**。

## 4 抗旱与其他非生物胁迫

干旱、盐碱、高温、涝渍属于**非生物胁迫（abiotic stress）**，由环境直接造成。抗旱育种远比抗病复杂，因为**没有「抗早基因」那样的单一靶点**，而是根系、气孔、渗透调节、生育期等多个性状的组合：

- **根系深度与水分利用效率**：深根、节水型材料在旱季仍能吸水。
- **避旱（escape）**：选**早熟**品种，在旱季到来前完成关键生育期——「躲开旱」比「扛住旱」更实用。
- **渗透调节与耐旱（tolerance）**：积累脯氨酸等渗透调节物质，维持细胞膨压。
- **鉴定方法**：干旱棚、抗旱指数（产量在旱/灌溉条件下的比值）、分子标记与 GS 预测。

非生物胁迫不止干旱：**盐碱胁迫**通过渗透压与离子毒害双重伤害，育种上要靠耐盐基因（如 NHX、HKT 家族的离子转运体）与排盐机制；**高温**则威胁花期授粉与灌浆——抗逆育种正从「单因子抗旱」走向「多胁迫复合抗性」的整合思路。

抗旱鉴定的数量化工具常用**抗旱系数与抗旱指数**：

$$
\text{抗旱系数} = \frac{\text{干旱胁迫下产量}}{\text{正常灌溉产量}}, \qquad \text{抗旱指数} = \frac{\text{胁迫产量}}{\text{全部参试品种平均胁迫产量}}
$$

抗旱指数以「对照群体平均水平」为基准，比抗旱系数更能区分材料间的相对强弱，是旱区育种筛选的标准指标。

**辨析｜易错点：** 抗旱 ≠ 抗所有旱。同一品种在不同干旱时期（苗期/花期/灌浆期）的抗性可能完全不同；把「前期抗旱」外推成「全生育期抗旱」是常见误判。育种上要按**关键需水期**精准设定胁迫处理。

## 5 抗逆育种的现代方法论

无论抗病抗虫抗旱，现代抗逆育种共享一套方法论升级：

1. **种质发掘**：从野生近缘种、地方品种中筛抗源——种质资源一节说的「库里挖宝」在抗逆上体现最直接。
2. **精准鉴定**：人工接种/诱虫/旱棚，保证选择压力均匀可控；分子标记做前景筛选。
3. **基因聚合与 GS**：把多个抗性基因聚合，或用全基因组选择累加多基因抗性。
4. **持续监测**：对病原小种、害虫抗性做长期监测，反向指导品种布局。

方法论升级背后有一个共同理念：**抗逆性很难「一步到位」，只能「步步为营」**。垂直抗性会被病原演化击穿，水平抗性要多年累加，抗旱则要多个生理性状协同——抗逆育种更像一场「育种家与逆境的军备竞赛」，需要种质、鉴定、聚合、监测四个环节闭环运转。

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| R 基因 | 抗病主效基因，多编码 NBS-LRR 哨兵蛋白 |
| Avr 基因 | 病原无毒基因，触发宿主防御的「钥匙」 |
| HR | 过敏性坏死反应，局部细胞程序性死亡 |
| PTI / ETI | 病原相关分子模式免疫 / 效应子触发免疫 |
| 抗生性 | 品种对害虫发育繁殖不利 |
| 耐害性 | 受害后能补偿、减产少 |
| 拒虫性 | 不吸引、不适合害虫取食产卵 |
| 抗旱指数 | 胁迫产量相对参试群体平均的比值 |

## 6 小结

- 抗病性分**垂直抗性**（单主效基因、强而脆）与**水平抗性**（多微效基因、弱而稳）；弗洛尔**基因对基因**假说解释专化抗性的分子基础。
- 抗病育种靠 R 基因**聚合/轮换**与水平抗性累加的组合策略，并依赖品种 + 监测 + 栽培三方协同。
- 抗虫三机制：**抗生性（Bt）**、耐害性、拒虫性；单基因抗虫需庇护所管理。
- 抗旱没有单一靶点，靠**避旱（早熟）、深根、渗透调节**等多性状组合，须按关键需水期精准鉴定。
- 现代抗逆育种统一方法论：**种质发掘 → 精准鉴定 → 聚合/GS → 持续监测**。
