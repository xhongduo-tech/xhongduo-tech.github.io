## 为什么从 GWAS 开始

分子标记一节讲到 MAS 只对主效基因有效，那数量性状（产量、抗逆）背后的微效多基因在哪里？答案隐藏在「群体历史上长期积累的重组」里。如果我们取一群表型各异的材料、在全基因组铺上几十万 SNP，再问「哪个位点的等位基因与性状显著相关」——这就是 **GWAS（genome-wide association study，全基因组关联分析）**。它把「定位基因」从人工杂交家系的实验室问题，变成了「自然群体 + 统计学」的野外问题。<span class="marginnote">GWAS 的思想渊源是人类遗传学：2005 年前后人类 GWAS 爆发，作物遗传学随后大规模采用。它不需要为每个性状做专门的杂交家系，同一批基因型数据可以反复关联任何表型——这是它效率的根本优势。</span>

## 1 关联映射的原理：连锁不平衡

GWAS 能工作，依赖群体中的**连锁不平衡（linkage disequilibrium, LD）**——不同位点等位基因的非随机组合。若目标基因 $B$ 与标记 $A$ 处于 LD，则材料中 $A$ 的频率会随 $B$ 的有利与否而系统性变化，关联检验就能捕获它。

两个标准度量：

$$
D = f_{AB} - f_A f_B, \qquad r^2 = \frac{D^2}{p_A\, p_a\, p_B\, p_b}
$$

其中 $f_{AB}$ 是 $A$、$B$ 同配单倍型频率，$p_A, p_a$ 是位点 A 的等位基因频率。<span class="marginnote">$r^2$ 是 0 到 1 的「LD 强度」，$r^2 \to 1$ 意味两个位点几乎等同。LD 衰减距离（$r^2$ 降到一半时对应的物理距离）决定了「标记要多密」：LD 衰减快的物种（如玉米）需要极密的 SNP，LD 长的自交作物（如小麦）则稀疏些也能覆盖。</span>

用一组具体数字建立直觉：设某两位点 A、B 的等位基因频率均为 $0.5$，群体中观测到 $A$、$B$ 同配单倍型频率 $f_{AB} = 0.4$，则 $D = 0.4 - 0.5 \times 0.5 = 0.15$，代进 $r^2$ 得 $r^2 = 0.15^2 / (0.5^4) = 0.36$——一个中等偏弱的 LD。若 $f_{AB}$ 升高到 $0.47$，$r^2$ 逼近 $0.8$，说明这两个位点在群体里几乎「手拉手」遗传，标记 A 就足以代表基因 B。

## 2 公式解析：混合线性模型

GWAS 的核心统计工具是**混合线性模型（mixed linear model）**，它在关联检验的同时校正群体结构与亲缘关系这两个最大的假阳性来源：

$$
\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \mathbf{Z}\mathbf{u} + \mathbf{e}
$$

对这条式子做逐项拆解：

- **第一步，$\mathbf{y}$**：$n$ 个材料的表型向量。
- **第二步，$\mathbf{X}\boldsymbol{\beta}$**：固定效应部分——包括要检验的候选 SNP 效应，以及**群体结构**（PCA 主成分、结构矩阵 Q）的校正项。不校正结构，亲缘近的群体差异会被误读为「关联」。
- **第三步，$\mathbf{Z}\mathbf{u}$**：随机效应部分——$\mathbf{u} \sim N(0, \mathbf{K}\sigma^2_g)$，$\mathbf{K}$ 是**亲缘关系矩阵**（kinship matrix，由全基因组标记估算个体间亲缘度）。它把「亲戚长得像」的冗余方差吸走，让剩下的信号才是真正的位点效应。
- **第四步，$\mathbf{e}$**：残差。全模型做完，对候选 SNP 的效应做假设检验，得 $p$ 值。

**关键直觉：GWAS 的统计难点不是「找到显著位点」，而是「别把群体结构、亲缘背景误当因果」**。混合模型用一个亲缘矩阵同时完成了校正与降噪，是当前作物 GWAS 的标准做法。

（模型选择也影响结果：除 GBLUP 类混合模型外，还有把主成分/结构作为固定效应、亲缘作为随机效应的「PC + K」方案。多数作物实践中，先做 PCA 可视化确认群体结构，再据此选择模型层次——结构简单用固定效应校正即可，结构复杂则必须上亲缘矩阵。）

**辨析｜易错点：** GWAS 显著位点解释的方差通常远低于遗传力——这就是著名的**缺失遗传力（missing heritability）**问题。微效位点效应太小、通不过显著阈值，但其总和恰恰贡献了大部分遗传方差。这提醒我们：GWAS 找到的是「能站出来的峰」，不是「全部遗传变异的清单」。

**辨析｜易错点：** 候选 SNP 的效应不能「双重吸收」。若把被检验的位点同时放进固定效应 $\mathbf{X}\boldsymbol{\beta}$ 又计入亲缘矩阵 $\mathbf{K}$，该位点自身的方差会被 $\mathbf{K}$ 吸走、检验功率骤降。实际操作通常用「剔除候选染色体后的其余标记」来计算 $\mathbf{K}$（即 leave-one-chromosome-out 策略）——这个细节直接决定检验是否灵敏。

## 3 结果怎么读：曼哈顿图与 QQ 图

GWAS 结果的两张标准图，是所有读者必须会看的第一眼：

- **曼哈顿图（Manhattan plot）**：x 轴是基因组位置，y 轴是 $-\log_{10}(p)$。超过显著阈值（如 Bonferroni 校正后的线）的位点如高楼般凸起，就是候选关联位点。<span class="marginnote">Bonferroni 校正把阈值除以标记数：若测了 50 万个 SNP，阈值 $p < 0.05/500000 = 10^{-7}$。严格但保守；当位点间高度连锁时，更常用的是「有效检验数」或置换检验来定阈值。</span>
- **QQ 图**：比较观测 $p$ 值与理论均匀分布 $p$ 值。若点整体压在 $y=x$ 线上，说明无系统性偏差（结构校正成功）；若低 $p$ 端翘起而其余在线上，说明有真实关联信号。

把两张图连起来读有一套固定动作：**先看 QQ 图确认整体无偏差，再看曼哈顿图找超过阈值线的峰**；当峰的数量远少于显著标记数时，多半是同一 LD 区块的连锁信号——要按「峰 / LD block」计数候选位点，而不是按标记点计数。读图口诀：**QQ 验整体，曼哈顿找局部；数峰不数点。**

还有一个常被忽略的量：**效应量与样本量的权衡**。GWAS 检出概率随「等位基因效应 × 样本量」增大：微效位点（解释 0.5% 方差）要稳定检出，往往需要数千个体；主效位点（解释 10% 方差）数百个体即可。**把「测了多少标记」与「样本多大」分开看，是读懂 GWAS 文献的第一课。**

**辨析｜易错点：** 曼哈顿图上「一座塔」≠「一个基因」。LD 会让邻近多个标记同时显著，形成的峰里哪个才是因果位点，需要结合候选基因、功能注释与后续验证判断——GWAS 的产出是「候选区间」，不是「定论」。

## 4 GWAS 的研究设计：样本量、标记密度与表型

GWAS 的成败一半在统计模型，一半在试验设计。四个参数决定「真实信号能否浮出水面」：

- **样本量**：样本越大、群体越纯，主效位点越易检出。玉米这类 LD 短、多态性极高的作物，关联分析常需数百至上千份材料；样本不足时，频率低于 5% 的稀有等位基因几乎不可能过关。
- **标记密度**：相邻标记间距必须小于物种 LD 衰减距离的一半，才能保证每个因果位点都被至少一个标记「牵连」。玉米需要百万级 SNP，自交作物小麦因 LD 长、几十万即可覆盖。
- **表型质量**：数量性状必须**多年多点**评价，用**最佳线性无偏估计（BLUP）**把基因型均值与年份、地点噪音分离；单一年份的表型混入大量基因×环境互作，真实信号会被淹没。
- **亲缘与结构控制**：群体内部亲缘过近时，混合模型的假阳性控制会失效——先做群体结构分析（PCA、STRUCTURE），剔除或校正极端冗余个体，再进关联检验。

**LD 衰减的测量**是设计前的必修课：取一群材料计算两两位点 $r^2$ 随物理距离的衰减曲线，$r^2$ 降到 0.2 左右对应的距离就是「关联半径」。玉米 1–2 kb 内 $r^2$ 即衰减到 0.2，而小麦可延伸到 5–10 Mb——LD 越短，标记要越密、关联分辨率越高。

这四条的共同主题一句话：**GWAS 要的是「干净的群体 + 可靠的表型 + 足够的标记」**。任何一个短板，都会让曼哈顿图要么一马平川、要么假峰林立。

## 5 从 GWAS 到育种应用

GWAS 的成果如何落地？有三条路径：

- **定位主效基因用于 MAS**：峰值位点开发成标记，进入上上节的基因聚合与回交流程。
- **挖掘优异等位基因**：同一基因在不同材料中有多个等位基因，GWAS 能分辨哪个等位基因效应最好，供定向改良选择。
- **作为全基因组选择的输入**：GWAS 的显著位点可作固定效应加入 GS 模型，或直接用于构建「候选基因—功能—表型」的知识链。

局限也要诚实说明：**GWAS 的分辨率受 LD 结构与群体规模限制**，稀有等位基因难以检出，基因×环境互作常被单一年份表型掩盖——因此好 GWAS 需要多年多点表型、足够大的群体与良好的结构校正。

落到具体流程，一次作物 GWAS 的完整流水线是：**材料收集 → 全基因组分型 → 多年多点表型 → 结构/亲缘估计 → 混合模型关联 → 候选基因挖掘 → 田间验证**。最后一步最容易被跳过——GWAS 筛出的候选区间里，真正经得起「近等基因系 + 多年重复试验」检验的位点通常只占少数，验证是区分「信号」与「噪音」的临门一脚。

候选基因的挖掘路径也有套路：取显著峰内的基因，看它是否编码已知与性状相关的蛋白（NBS-LRR、转运蛋白、转录因子），再查表达数据与文献；**「峰内基因 × 功能注释 × 表达模式」三线交叉**，通常能把候选从几十个缩到一两个。

**术语速查表**

| 概念 | 一句话 |
| --- | --- |
| LD（连锁不平衡） | 不同位点等位基因的非随机组合 |
| $r^2$ | 0–1 的 LD 强度，越大越近似等同 |
| 曼哈顿图 | 按位置画 $-\log_{10}(p)$，看峰 |
| QQ 图 | 观测 vs 理论 $p$，验整体偏差 |
| 混合线性模型 | 检验 SNP 同时校正结构与亲缘 |
| Bonferroni 校正 | 阈值除以标记数，保守防假阳 |

## 6 小结

- **GWAS** 利用自然群体的**连锁不平衡**，全基因组关联 SNP 与性状，无需专用家系。
- LD 强度 $r^2$ 决定标记密度需求；$r^2 \to 1$ 意味位点近等同。
- **混合线性模型** $y = X\beta + Zu + e$ 同时检验 SNP 并校正**群体结构**与**亲缘矩阵**，是两个假阳性来源的克星。
- **曼哈顿图**看显著性峰值，**QQ 图**验系统偏差；峰值是候选区间而非定论。
- 成果落地：开发标记进 MAS、挖掘优异等位基因、供 GS 模型使用。
- 研究设计四参数：**样本量、标记密度、多年多点表型、亲缘/结构控制**；显著峰值必须经田间验证才能兑现为「候选位点」。
- 效应量与样本量共同决定检出率；显著峰解释方差常远低于遗传力——**缺失遗传力**是 GWAS 与全基因组选择的接缝所在。
- 读图先验整体（QQ）、再找局部（曼哈顿），数峰不数点；候选区间须经功能注释与田间验证才能定论。

在下一节，我们把「关联定位」推进到「全基因组预测」——不再关心单个位点，而用全部标记同时预测每个个体的育种值，这就是**全基因组选择（GS）与双单倍体加速育种**。
