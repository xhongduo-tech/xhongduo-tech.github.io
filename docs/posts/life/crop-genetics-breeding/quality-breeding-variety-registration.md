## 为什么从品质育种开始

一个品种「高产」但磨不出好面粉、煮不出好米饭、榨不出好油，农民与加工商都不会要。现代育种中**品质（quality）** 与产量并列为两大目标，而且品质的定义随**终端用途**而变：同一株小麦，做面包要的是高蛋白强筋，做面条要的却是中等蛋白的良好延展性。<span class="marginnote">品质育种的一个关键教训来自绿色革命的「高产低质」困境：高产品种曾因籽粒氮素向产量倾斜而蛋白质含量下降。此后育种把品质指标纳入筛选目标，才逐渐扭转。它提醒我们：育种目标从来是「多目标优化」而非单点极值。</span>

## 1 品质的构成与度量

**品质（quality）**：品种满足特定用途要求的综合属性。作物不同、用途不同，品质内涵完全不同：

| 作物 | 主要品质指标 | 典型测定 |
| --- | --- | --- |
| 小麦 | 蛋白质含量、面筋强度、沉降值、出粉率 | 蛋白质 %、沉降值（SDS） |
| 水稻 | 直链淀粉含量、胶稠度、垩白度、食味 | 直链淀粉 %、食味品评 |
| 玉米 | 籽粒淀粉/油分/蛋白、饲用赖氨酸 | 近红外（NIR）快速测定 |
| 大豆 | 油分、蛋白含量、脂肪酸组成 | 油 %、蛋白 %、油酸 % |
| 油菜 | 含油量、芥酸、硫苷含量 | 含油量 %、芥酸 %（双低标准） |

**品质的遗传学特点**：多数品质性状是**数量性状**，受多基因控制、受环境影响，但部分（如直链淀粉含量受 $Wx$ 蜡质基因控制）存在主效基因，可被分子标记直接选择。<span class="marginnote">「双低油菜」是品质育种教科书案例：把油菜籽的芥酸（≤3%）与硫苷（≤30 µmol/g）两个指标压下去，菜籽油从工业用油变成健康食用油。育种家通过诱变与回交，把两个隐性位点逐一改良，成就了全球油菜产业的品质革命。</span>

用数字理解「指标是区间化」的含义：水稻直链淀粉分三档——低（<20%，粳稻偏黏软）、中（20%–25%，多数籼稻）、高（>25%，口感硬散）；小麦面筋强度用沉降值（SDS 沉降体积）快速分级，沉降值大说明面筋强、宜做面包。**品质指标往往不是「越高越好」，而是落在终端用途要求的区间里最好**——这是品质育种与产量育种在思维上的最大差别。

品质测定的方法学也在演进：从实验室湿化学分析，到**近红外光谱（NIR）**快速无损检测，再到分子标记直接选择基因型。NIR 把「测品质」从「破坏籽粒、等几天出结果」变成「几分钟、无损、批量」——这让品质筛选可以进入高世代大规模选择，是品质育种提速的关键配套。

（顺带一提：品质测定的单位与基准也很讲究——蛋白质含量有「干基/湿基」之分，含油率有「烘干/风干」之别，跨机构比较数据前必须先统一基准，否则数字对不上。）

**辨析｜易错点：** 品质与产量常常此消彼长。籽粒氮素「一头沉」——往蛋白质倾则淀粉产量下降，反之蛋白质下降；同化产物总量有限时，品质与产量是同一笔碳/氮预算的两端。正因如此，「高产高质兼得」要靠突破同化产物上限或提高氮利用效率，而不是简单地把品质指标调高。

## 2 品质育种的策略

品质育种没有脱离一般育种框架，但有几条特殊策略：

**主效基因直接选择**：蜡质玉米（$wx$ 基因，糯性）、高油酸大豆等，用 MAS 精确导入主效品质基因。
- **多指标综合评价**：品质是多目标，需**加权综合评分**——把蛋白质、沉降值、出粉率等标准化后加权，避免「单项冠军、全面废材」。
- **品质 × 环境交互**：品质性状受年际与地点影响大（同一品种不同产地蛋白质不同），评价必须**多年多点 + 品质与产量平行测定**。
- **加工适宜性评价**：从「种得好」到「用得好」——面包烘焙试验、米饭食味品评等终端评价是最终裁判。

**关键理念：品质指标必须回到「最终用途」定义**——小麦好不好，由面包/面条/饼干的需求决定；玉米好不好，由饲料能量或淀粉加工决定。育种目标越早绑定终端，弯路越少。

**加权综合评分的一个算例**：设小麦按用途给蛋白质（权重 0.4）、沉降值（0.3）、出粉率（0.2）、千粒重（0.1）加权，先把各性状标准化到 0–100 分再乘权重求和。这样「单项冠军、全面偏科」的材料总分必然吃亏，能自动筛出「均衡偏优」的品种——这是多目标育种决策的通用做法，也是品质评价避免「拍脑袋定优劣」的统计基础。

加工适宜性评价把「种得好」翻译成「用得好」：小麦做面包要看面团醒发体积与烘焙评分，做面条要看延展性与色泽；稻米看食味品评（蒸煮口感、香气、冷饭回生）。**同一品种在两类用途里评价可能天差地别**——评价标准永远绑定终端产品。

## 3 品种审定：从育成到合法上市

一个材料选育成功后，并不能直接推广——必须通过**品种审定（variety registration / release）**，即国家或区域品种审定委员会对其进行的法定评价。审定逻辑分三层：

- **丰产性（yield）**：区域试验（多年多点）中产量须显著优于对照品种。
- **稳定性与适应性（adaptation）**：各试验点表现一致、特定生态区适应，避免「一年好、换地差」。
- **品质与抗性（quality & resistance）**：品质达到相应用途标准，抗病抗逆达到区域要求。

审定的核心技术支撑是**区试（regional trials）**：统一方案、统一对照、多点多年随机区组试验，用方差分析评估品种×环境交互，筛选既高产又稳定的品种。<span class="marginnote">区试就是「品种的临床试验」：对照组是现役品种，试验点是医院，方差分析是统计裁判。育种家选出的材料只有通过这道大考，才获得「准字号」推向市场。</span>

区试的统计分析是典型的**品种×环境互作（G×E）分解**：把总方差拆成品种、地点、年份及各级互作，计算品种在各环境中的回归系数与离差，据此判断「高产稳产」——高产是均值高，稳产是互作方差小。一个品种若在某地显著优于对照、在别处却低于对照，其适应性就有问题，审定时往往被一票否决。

区试还要讲究**对照设置**：对照必须是该生态区现役主栽品种，品种只有显著优于对照才有审定价值；若对照多年提升，审定的门槛也水涨船高——这就是为什么「高产」是一个相对概念，必须与「当下最好的」比。

## 4 种子法规与品种权

审定的背后是一整套种子法律体系，保护农民与育种者双方：

**DUS 测试（特异性、一致性、稳定性）**：新品种要获得保护，必须证明它**区别于**已有品种（Distinctness）、群体内**一致**（Uniformity）、世代间**稳定**（Stability）。DUS 是「新品种的身份证」，由官方指定测试机构完成。
- **植物品种权（plant variety rights, PVR）**：育种者对其品种享有排他性商业繁殖权，类似专利但针对品种。它是育种产业创新激励的核心——没有品种权，新品种一经推广便被无偿繁殖，育种无利可图。<span class="marginnote">中国的植物品种保护制度 1999 年加入 UPOV 公约 1978 年文本后逐步建立。品种权与专利、地理标志并列为农业知识产权三支柱。杂交种因其「不能留种」的天然属性，还额外获得了事实上的市场保护。</span>

品种权保护的边界也值得分清：它保护的是**商业繁殖与销售**，不阻止科研利用与农民自留种（许多国家设有「农民特权」条款）；且保护期有限（如中国 20 年）。**品种权是「有限期的排他」，不是永久的垄断**——这是知识产权制度在农业上的基本设定。
- **种子质量法规**：规定种子的纯度、净度、发芽率、含水率等质量门槛，保障农民买到合格种子。

**种子质量门槛（以粮食作物为例）**：

| 指标 | 常规要求 |
| --- | --- |
| 纯度 | ≥ 96%（杂交种要求更高） |
| 净度 | ≥ 98% |
| 发芽率 | ≥ 85%（因作物而异） |
| 水分 | 安全水分以下（如 ≤ 13%） |

这些门槛由种子检验机构按国家标准检测，是农民买到「合格种子」的最后防线——低于门槛的种子即使品种再好，也不能进入市场。

## 5 辨析：审定 ≠ 推广终点

**辨析｜易错点一：** 审定通过的是「品种」，推广还要靠**良种繁育**——建立原原种—原种—良种的三级繁育体系，保证大面积用种的质量与数量。育种成功 ≠ 产业成功，繁育推广体系缺一不可。

**辨析｜易错点二：** DUS（区别性、一致性、稳定性）与 **VCU（价值栽培与使用，丰产性/品质/抗性）** 是两套不同性质的考核：DUS 决定「能不能成为新品种」，VCU 决定「值不值得推广」。许多国家两者分离管理，混为一谈是外行常见的误解。

**辨析｜易错点三：** 审定是「区域性的准入门槛」。中国按生态区划设省级与国家两级审定，同一品种在南方稻区审定通过，不代表能在北方旱区推广——审定意见里注明的**适宜种植区域**是法律边界，超区推广属于违规用种。这也是「审定 ≠ 万能通行证」的另一层含义。

**术语速查表**

| 术语 | 含义 |
| --- | --- |
| DUS | 特异性、一致性、稳定性测试 |
| VCU | 价值栽培与使用（丰产/品质/抗性） |
| 区试 | 区域试验，多年多点比较 |
| PVR | 植物品种权 |
| 良种繁育 | 原原种—原种—良种三级繁殖 |
| 双低油菜 | 低芥酸（≤3%）低硫苷（≤30 µmol/g） |

## 6 小结

- **品质**依终端用途定义，小麦看面筋、水稻看直链淀粉、油菜看芥酸硫苷；多数品质性状是数量性状。
- 品质育种策略：主效基因 MAS、多指标**加权综合评分**、多年多点品质评价、**加工适宜性**为最终裁判。
- **品种审定**以区域试验（多年多点）考核丰产、稳定、品质与抗性，是品种上市的法律门槛。
- **DUS 测试**保证品种的区别性/一致性/稳定性，**品种权（PVR）** 保护育种者商业利益。
- 审定通过后还需**良种繁育**三级体系才能大规模推广；DUS 与 VCU 是两套性质不同的考核。
