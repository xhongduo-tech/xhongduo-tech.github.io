# 全基因组选择（GS）与加速育种

<div class="epigraph">
<p>当标记密度足够高时，所有基因都与某个标记连锁——于是整个基因组就是预测工具。</p>

## 为什么从全基因组选择开始

GWAS 一节的结论带着遗憾：主效基因能定位，但微效多基因大多「够不到显著性门槛」。Meuwissen 等人在 2001 年提出一个颠覆性的替代方案——**放弃定位单个基因，把所有标记同时纳入模型，直接预测每个个体的育种值**。这就是**全基因组选择（genomic selection, GS）**：与其找「哪几根柱子承重」，不如训练一个「用全部柱子预测整栋楼」的模型。<span class="marginnote">GS 与 GWAS 的哲学分叉很像机器学习的「可解释 vs 预测」之争：GWAS 要解释（稀疏、显著、可定位），GS 只要预测（稠密、全位点、不做显著性筛选）。育种生产要的是后者。</span>

## 1 GS 的流程：训练群体与预测群体

GS 是一个标准的「训练—预测」两阶段流程：

1. **建训练群体（training population）**：取一批材料，既测表型（多年多点）又做全基因组 SNP 分型。
2. **训练模型**：以 SNP 为特征、表型为响应，拟合 $\mathbf{y} = \mathbf{W}\mathbf{g} + \mathbf{e}$，估计每个标记的效应 $\hat{\mathbf{g}}$。
3. **预测群体（prediction/breeding population）**：只做基因分型、不做田间表型，用模型预测其**基因组估计育种值（GEBV）**，按 GEBV 选种。

**关键：预测群体不需要表型**——这打破了「先种了才知道好不好」的循环，育种家可以在苗期甚至种子期就完成初选。<span class="marginnote">GEBV 的育种学意义：传统选择靠「亲本的田间表现」，GS 靠「基因型直接打分」。等于把育种从「考后估分」变成「入学前预测」，群体周转率大幅提升。</span>

## 2 公式解析：GEBV 的核心模型

GS 的标准模型（GBLUP）形式与 GWAS 的混合模型同源，但角色反转——随机效应现在是**全部标记的聚合**：

$$
\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \mathbf{Z}\mathbf{g} + \mathbf{e}, \qquad \mathbf{g} \sim N(\mathbf{0}, \mathbf{G}\,\sigma_g^2)
$$

对这条式子做逐项拆解：

- **第一步，$\mathbf{g}$ 的含义**：不再是单个候选 SNP 的效应，而是所有个体遗传值的向量，由全基因组标记估算的**基因组关系矩阵 $\mathbf{G}$** 刻画个体间亲缘。
- **第二步，$\mathbf{G}$ 怎么来**：由 SNP 计算个体间的基因型相似度，$\mathbf{G}$ 的第 $ij$ 元素反映个体 $i,j$ 共享基因的比例——它用标记重新定义了「亲属关系」，让无系谱记录的材料也能互相借力。
- **第三步，预测**：解出 $\hat{\mathbf{g}} = \mathbf{G}\mathbf{Z}'\mathbf{V}^{-1}(\mathbf{y} - \mathbf{X}\hat{\boldsymbol{\beta}})$，对未测表型的新个体，用它的基因型在 $\mathbf{G}$ 里的位置直接给出 **GEBV**。数学上等价于一个带遗传协方差结构的岭回归。

**关键直觉：GS 的聪明之处在于「用亲缘矩阵把全部标记的信息打包成一个协方差结构」**——不是去分辨每个 SNP 有多大效应，而是承认「相似的基因型 → 相似的表现」，用相似性外推预测。模型本身不过度拟合，因为它不追求单个效应精确。

## 3 模型家族与选择

GS 模型按对标记效应的先验假设分为几派：

| 模型 | 假设 | 适用 |
| --- | --- | --- |
| GBLUP / RR-BLUP | 所有标记效应等方差 | 多数微效多基因性状，稳健默认 |
| BayesA | 标记效应异方差 | 性状由少数大效应 + 多小效应构成 |
| BayesB / BayesCπ | 大量标记效应为 0（稀疏） | 存在主效基因的性状 |
| 机器学习类（RF、BayesLASSO 等） | 非线性 / 变量选择 | 复杂互作、高维数据 |

**预测准确性**的经典度量是**预测精度（predictive ability）**：用交叉验证（把训练群体分成 k 份轮流验证）估计 GEBV 与真实表型的相关系数。<span class="marginnote">交叉验证的流程与机器学习毫无二致：训练集拟合、验证集测泛化、最后评估。作物 GS 文献里反复出现的「预测能力 0.3–0.7」就是这样测出来的——数值高低取决于遗传力、训练群体规模与标记密度。</span>

## 4 加速育种：双单倍体（DH）技术

GS 缩短了「选的时间」，**双单倍体（doubled haploid, DH）**缩短了「纯合的时间」，两者叠加构成现代加速育种的双引擎。

**DH 技术**：取杂种的花药或微孢子离体培养，获得只含一套染色体组的**单倍体**植株（不表现显隐性、基因型完全暴露），再用秋水仙碱加倍成纯合**双单倍体**——一代就得到完全纯合的株系，替代系谱法 6–8 年的自交纯化。

![双单倍体（DH）加速纯合示意图](/images/crop-genetics-breeding/doubled-haploid.svg)

DH 的价值不止快：每个 DH 系是一个**永久固定的纯合基因型**，可多年多点重复评价，为 GS 提供精确的训练表型；DH 群体无显性效应干扰，遗传力估算更干净。<span class="marginnote">「GS × DH」的组合拳是当前主流育种公司的标准流水线：杂交 → 生成 DH 系 → 苗期 DNA 分型 + GS 打分 → 只有高分 DH 系进入田间多年多点试验。变异、纯合、预测三步全部工业化。</span>

## 5 辨析：GS 与 MAS、GWAS 的关系

**辨析｜易错点一：** GS、MAS、GWAS 不是三选一，而是**同一链条上的不同粒度**——MAS 选主效基因，GWAS 定位主效基因，GS 用全基因组预测微效多基因性状。实践中常组合：GWAS 发现的大效应位点作为固定效应放入 GS 模型（如 BayesB），兼顾可解释与预测力。

**辨析｜易错点二：** GS 的预测能力会**衰减**：模型是用特定群体训练的，应用于血缘较远的新群体或换了环境，准确度下降。因此需要定期**更新训练群体**（把新表型数据回灌模型）——这是把 GS 当作一个「持续学习的预测系统」而非「一次性公式」来维护。

## 6 小结

- **GS** 放弃定位单个基因，用全部 SNP 预测每个个体的 **GEBV**，预测群体无需表型。
- 核心模型 **GBLUP** $\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \mathbf{Z}\mathbf{g} + \mathbf{e}$ 用**基因组关系矩阵 $\mathbf{G}$** 打包全部标记信息，等价于带协方差结构的岭回归。
- 模型家族（GBLUP、BayesA/B、机器学习）按对标记效应的先验分派，预测精度靠**交叉验证**评估。
- **DH 技术**花药/微孢子培养 + 染色体加倍，一代纯合，与 GS 组成「变异—纯合—预测」的工业流水线。
- GS 能力会随群体/环境变化衰减，需**持续更新训练群体**。
