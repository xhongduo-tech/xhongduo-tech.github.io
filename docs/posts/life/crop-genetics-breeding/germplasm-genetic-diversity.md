## 为什么从种质资源开始

上一节我们建立了选择响应的公式 $R = h^2S$，并反复提到「变异耗尽时必须引入新变异」。那么变异存到哪里？答案就是**种质资源库**——全世界育种工作者的公共原料仓。若没有它，1970 年美国玉米大斑病、1970 年代中国水稻矮化病式的灾难，将没有「外援基因」可救。种质资源不是档案室里的摆设，而是应对未来气候与病害的保险单。<span class="marginnote">一个广为引用的数字：目前全球种质库保存约 740 万份作物种质，最大的是挪威「末日种子库」与中国国家作物种质资源库。每份材料都是一份尚未兑现的基因保险。</span>

一个让种质价值具象化的例子：20 世纪中叶美国玉米生产高度依赖少数杂交种，遗传基础极窄；1970 年玉米小斑病（Southern corn leaf blight）来袭造成大范围减产，正是种质库里长期无人问津的古老玉米材料提供了抗病基因，才避免了更重的损失。这件事后来被反复引用为「种质库不能等到危机才想起来」的教科书证据。

## 1 种质资源及其类型

**种质资源（germplasm）**：具有潜在利用价值的全部遗传材料，包括栽培品种、野生近缘种、地方品种、育种中间材料与突变体。按血缘与利用价值可分为：

- **地方品种（landrace）**：长期自然与人工选择形成的古老群体，适应性广、遗传多样，但产量低——是「遗传多样性的露天金矿」。
- **野生近缘种（wild relative）**：栽培种的野生亲戚，携带抗病虫、耐逆等栽培种丢失的基因，如野生稻的抗病基因。
- **改良品种与育成材料**：现成可用但遗传基础相对狭窄。
- **突变体与特异材料**：诱变产生的稀有类型，如矮秆、高蛋白。

**辨析｜易错点：** 地方品种 ≠ 「落后品种」。恰恰相反，地方品种是历经数百年环境与病害筛选的「适应型基因库」，其劣势仅在单一产量指标；而现代育种的遗传基础狭窄（绿色革命品种高度同质化），正需要回头从地方品种中找回抗性、品质与适应性基因。把地方品种当「旧东西」丢弃，等于烧掉未来的保险单。

另外值得了解的是「基因库（gene bank）」这个更广的概念：它不只存种子，还存离体组织、DNA 文库、花粉与试管苗，甚至田间活体（田间基因库）。对以营养器官利用为主的作物（马铃薯、甘薯、香蕉），种子保存几乎不可行，田间库与离体库才是主角——这说明「种质库」从来不是单一设施，而是一整套按繁殖方式定制的保存体系。

## 2 遗传多样性的度量

**遗传多样性（genetic diversity）**：群体内个体间遗传组成的差异程度。它是一切选择与进化的原料，可以用多种指标量化。基于 DNA 或蛋白标记，最常用的是**多态性信息含量（PIC）**与 **Shannon 多样性指数**：

$$
\mathrm{PIC} = 1 - \sum_{i=1}^{k} p_i^2, \qquad H' = -\sum_{i=1}^{k} p_i \ln p_i
$$

其中 $p_i$ 是第 $i$ 个等位基因的频率。<span class="marginnote">PIC 直观地解读为「随机挑两个等位基因，它们不同的概率」——值越接近 1 说明标记信息量越大；$H'$ 则来自信息论，衡量频率分布的均匀度，与熵同构。数据科学里的熵、信息增益，与遗传多样性指数是同一套数学。</span>

遗传多样性还可从三个层面看：**种内多样性**（同一物种内个体差异）、**种间多样性**（不同物种间差异）、**遗传距离**（群体间差异的度量，用于聚类分析亲缘关系）。

三个层面并不等价：种内多样性是「一个物种内部的可选范围」，种间多样性是「不同物种间的差异」，遗传距离则是「两个材料/群体之间的亲缘远近」。在育种里，由分子标记算出的遗传距离常被用来给种质聚类、画亲缘树，帮助育种家避开「血缘过近」的陷阱——亲本差异太小，后代就缺乏可分离的空间，这正是杂交育种要亲本遗传差异「适中」的原因。

算一个具体的 PIC。设某标记位点有 3 个等位基因，频率分别为 $p_1=0.5$、$p_2=0.3$、$p_3=0.2$，则

$$\mathrm{PIC} = 1 - (0.5^2 + 0.3^2 + 0.2^2) = 1 - 0.38 = 0.62$$

直觉：随机抽两个等位基因，它们不同的概率是 62%，说明这个标记区分能力不错。若频率更均匀（如各 $1/3$），PIC 会升到 $1 - 3 \times \tfrac{1}{9} \approx 0.667$——等位基因越多、分布越均匀，标记越「有用」。这正是筛选核心种质时优先选高 PIC 位点的原因：信息量大的位点才能把材料之间的差异摊开来看清。

顺带一提，Shannon 指数 $H'$ 与 PIC 各有侧重：PIC 看「区分能力」，$H'$ 看「分布均匀度」。若一个位点只有单一等位基因（单态），两者都取 0；若等位基因完全等频，$H'$ 达到最大。用它们给整批材料逐一算一遍，就能得到一张「多样性热点清单」——哪些材料组合携带的信息量最高，一目了然，后续抽样与评价都可以围绕它展开。

## 3 多样性的中心：瓦维洛夫起源中心

苏联遗传学家**瓦维洛夫**在 1920–1930 年代走遍五大洲，发现作物多样性并非均匀分布，而是高度集中在几个「起源中心」：中国、印度、中亚、近东、地中海、埃塞俄比亚、墨西哥—中美洲、南美洲。<span class="marginnote">瓦维洛夫的人生充满悲剧：他因与李森科学派对抗被苏联当局逮捕，1943 年死于狱中。而他在列宁格勒留下的种子库，在二战围城期间被研究人员视为生命般守护——这段历史正是「种质即文明资产」的写照。</span>

| 起源中心 | 代表性作物 |
| --- | --- |
| 中国 | 水稻、大豆、粟、茶 |
| 印度 | 稻、棉、芝麻、芒果 |
| 近东 | 小麦、大麦、燕麦、鹰嘴豆 |
| 地中海 | 油橄榄、甜菜、甘蓝 |
| 埃塞俄比亚 | 高粱、咖啡、非洲粟 |
| 墨西哥—中美洲 | 玉米、菜豆、南瓜、辣椒 |
| 南美洲 | 马铃薯、番茄、烟草 |

理解起源中心的意义在于：**到多样性中心去收集种质，往往是寻找新基因最快的路线**——这正是今天「全球种质收集、交换与分享」运动（如《粮食与农业植物遗传资源国际条约》）的历史源头。

这些中心的作物并非均匀「散落」，而是呈现清晰的**多样性梯度**：离起源中心越远，等位基因被瓶颈效应剔除得越多，代表性材料就越「瘦」。育种家据此设计引种与收集策略——优先回到中心及其周边采集，比在次生栽培区大海捞针高效得多。今天国家作物种质资源库的收集清单，相当程度就是按这些中心的历史与地理逻辑勾画出来的。

## 4 种质资源的保存与核心种质

保存有两种互补策略：**原地保存（in situ）**，在自然生境或农民田间保存生态系统与共同进化关系；**迁地保存（ex situ）**，把种子放入低温低湿的种质库长期保存，或保存在田间基因库、离体试管库、DNA 库。<span class="marginnote">种子保存的通行标准是「3-3-3 原则」的现代版：在 $-18\,^\circ\mathrm{C}$、相对湿度约 5% 的条件下，多数作物种子可保存数十年至上百年。定期发芽率监测与更新（regeneration）是种质库日常管理的核心。</span>

种质库规模巨大，若全部用于田间评价成本惊人，于是提出**核心种质（core collection）**概念：从全库中按遗传代表性挑选 5–10% 的材料，使其尽量覆盖全库的遗传变异——相当于对种质库做一次「主成分意义上的降维」，用最小材料代表最大多样性。这与机器学习里的代表性采样、mini-batch 思想完全同构。

两种保存策略的取舍可以并排比较：

| 维度 | 原地保存（in situ） | 迁地保存（ex situ） |
| --- | --- | --- |
| 地点 | 自然生境 / 农民田间 | 种质库、田间基因库、离体库 |
| 保存对象 | 生态系统与共同进化关系 | 种子、离体组织、DNA |
| 优点 | 动态进化、基因持续更新 | 集中、可控、便于评价利用 |
| 缺点 | 易受开发与灾害威胁 | 静态保存、脱离选择压力 |
| 代表 | 保护区、社区种子银行 | 国家种质库、末日种子库 |

现代体系两者互补：原地保存保住「活着的进化」，迁地保存保住「可用的备份」。

另一个常被问的问题：种质库里能放多久？在 $-18\,^\circ\mathrm{C}$ 与低湿条件下，多数禾谷类种子理论寿命可达数十年至百年，但实验室必须定期做发芽监测——当发芽率跌破阈值（如 85%）就启动更新繁殖。这就是种质库的「保质期管理」：把种子的衰老进程纳入可预测的监控，而不是等它彻底失去活力才补救。

种质更新的成本并不低：每 5–10 年就要把发芽率下降的材料重新播种繁殖一代，繁殖过程本身还可能悄悄引入选择或漂变。为此现代种质库采用「低温 + 干燥 + 密封」的标准三件套，尽量拉长繁殖周期；少数多年生与无性繁殖作物则转入离体试管库或超低温（液氮，$-196\,^\circ\mathrm{C}$）保存——对这类材料，「种子库」根本装不下，必须靠组织培养续命。

## 5 从多样性到育种价值

收集种质的最终目的是**利用**，价值链条是：**收集 → 编目 → 鉴定评价 → 发掘优异基因 → 导入育成品种**。其中「鉴定评价」是关键瓶颈——材料藏在库中若不被评价，等于沉睡。<span class="marginnote">现代分子技术正在改写这个链条：通过大规模基因分型与表型组学（phenomics），可以直接从种质库材料中挖掘优异等位基因，再通过分子标记或基因编辑导入现代品种——「从库里直接调基因」成为可能，种质资源正在变成「可查询的基因数据库」。</span>

**辨析｜易错点：** 保存多样性 ≠ 保存全部个体。种质库保存的是「等位基因的组合样本」，因此追求的是遗传代表性而非材料数量最大化；过度追求数量而忽视代表性与活性的库，只是「种子坟墓」。另一个常见误区是把「收集」当终点——未经评价的种质对育种毫无贡献。

核心种质也讲究数字：若全库有 3 万份水稻材料，按 10% 取约 3000 份作核心种质，再对核心种质做全基因组测序与重点性状鉴定，就能以约十分之一的成本覆盖全库绝大部分的等位基因组合。多国实践表明，核心种质通常能捕获全库 80%–95% 的常见等位基因——这是「少而精」策略在数据维度的确凿回报，也是后文 GWAS 与全基因组选择能从小样本起步的数据前提。

容易再补一条：核心种质不是一次抽样就完事。全库新材料入库后，核心种质会周期性「更新」——重新计算遗传代表性、剔除冗余、吸纳新优材料。这与数据库里的「重新索引」同构：种质库是活的数据资产，核心种质就是它的动态索引。

## 6 小结

- **种质资源**是一切育种的原料库，包括地方品种、野生近缘种、改良品种与突变体。
- 多样性可用 **PIC 与 Shannon 指数 $H'$** 量化，它们与信息论的熵同构；遗传距离用于聚类与亲本选配。
- 瓦维洛夫**起源中心**揭示了多样性地理分布的规律，指引种质收集方向。
- 保存分**原地与迁地**两种策略，核心种质用 5–10% 材料代表全库变异，相当于多样性降维；种质库用发芽监测做「保质期管理」。
- 起源中心之外的次生区也有丰富变异，收集策略要同时兼顾中心与多样性地理梯度。
- 种质价值链条为收集→评价→利用；分子技术让「从库里直接发掘优异基因」成为现实。
- 多样性梯度与遗传距离指导引种与亲本选配；种质库按繁殖方式定制保存体系（种子 / 离体 / 田间 / 液氮）。

一句话收束：种质资源是「变异的总仓库」，多样性指标是「清点仓库的尺子」，核心种质是「仓库的精装索引」——三者合起来，回答的是育种开工前最根本的问题：原料够不够、在哪里、怎么用。

在下一节，我们将进入育种的操作核心——用杂交把不同材料的优良基因组合到同一个体，并用杂种优势把它推向极致，这就是**杂交育种与杂种优势**。
