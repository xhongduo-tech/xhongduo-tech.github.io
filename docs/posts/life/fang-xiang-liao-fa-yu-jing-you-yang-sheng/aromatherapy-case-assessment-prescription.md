## 为什么从个案评估开始

前面 24 篇，我们从历史学到化学、从手法学到各系统应用。现在到了「**把一切合起来，为一个具体的人开一份具体配方**」的时候。个案评估（case assessment）与处方设计（prescription design）是芳疗从「知道」走向「会用」的临门一脚，也是 NAHA 临床篇的核心。<span class="marginnote">「从极限到大模型」里，这一篇是芳疗的「临床思维」接口：类似「先诊断、后开方」的推理流程，但芳疗师的「诊断」是「评估需求」，不是「诊断疾病」——这个边界要时刻清楚。</span>

学完这一篇，你会有能力走完「问诊 → 评估 → 设计 → 反馈」的完整流程。

## 1 个案评估的定位与边界

先立边界：**芳疗师的「评估」是评估「健康需求与适合的芳疗支持」，不是「疾病诊断」。**

- **能做的**：了解症状、情绪、睡眠、生活方式，判断「芳疗能否提供支持、怎么支持」。
- **不能做的**：不做医学诊断、不开药、不替代医生；遇到疑似疾病信号，明确转介。

**重点：** 这个边界的实操提示是「话术」：不说「你得了焦虑症」，而说「你最近焦虑感比较明显，芳疗可以做情绪支持」；不说「这油能治好你的胃痛」，而说「这配方帮你缓解胀气不适」。用词的谨慎，就是边界的体现。

**核心概念**：NAHA 临床篇强调的「holistic assessment（整体评估）」——不只问「哪里不舒服」，也问「睡得好吗、压力大吗、皮肤状态如何」，把一个人当「整体」而非「症状」看待。

这个「整体观」落到操作上，就是评估表的「多栏结构」：身体、情绪、睡眠、皮肤、生活方式各占一栏。填完这份表，处方师看到的不是「一个失眠的人」，而是「一个入睡困难 + 睡前焦虑 + 皮肤偏干 + 每天加班到十点的人」——后者的处方，自然比前者更具体、更贴合。

## 2 问诊清单：问什么、怎么问

一份基础评估表，至少包含七项：

1. **基本信息**：年龄、性别、是否孕期/哺乳（见第21篇特殊人群）。
2. **主诉**：想解决什么（睡眠、情绪、酸痛、皮肤……），持续多久。
3. **生活方式**：作息、压力、运动、睡眠。
4. **健康状况**：慢性病、正在服用的药物。
5. **皮肤状态**：肤质、有无破损/过敏/湿疹。
6. **气味偏好**：喜欢什么香型、闻到什么会不适（第9篇）。
7. **既往芳疗经验**：用过什么油、反应如何。

**重点：** 问诊是「倾听」不是「审讯」。用开放式问题引导，让对方说重点；同时**如实记录**——这份记录既是处方依据，也是第26篇《个案记录》的开端。

问诊也有「访谈节奏」可循：先寒暄建立信任，再问开放题（「最近睡得怎么样？」），最后追问细节（「大概几点躺下、几点睡着？」）。让对方感到「被听见」，比高效地「填完表单」更重要——信任本身就是疗效的一部分。

## 3 评估→处方的思考框架

拿到信息后，按「五步」设计处方：

1. **定目标**：把「睡不好」拆成「入睡困难 + 睡前焦虑」等具体目标。
2. **定方式**：按场景选吸嗅/扩香/按摩/泡浴（第11、17篇）。
3. **定主油**：按化学家族与人格（第8、9篇）选 1–2 支主角油。
4. **定浓度**：按剂型与人群（第6、21篇）算滴数。
5. **定疗程**：明确用多久、何时复评、何时轮换。

**核心对比表｜评估信息 → 处方要素**：

| 评估信息 | 对应处方要素 |
| --- | --- |
| 主诉目标 | 选油方向、方式 |
| 人群/孕期 | 浓度档位、禁忌油 |
| 皮肤状态 | 载体油、剂型 |
| 气味偏好 | 香型选择、配方微调 |
| 用药/病史 | 安全筛查、转介判断 |

## 4 公式解析：一份配方的完整计算

以「成人、睡前放松、按摩油」为例走一遍：

$$
n = V \times C \times 20, \qquad V=20\,\mathrm{mL}, \ C=1\%
$$

- **第一步**：$V=20$（基础油）、$C=1\%$（睡前低浓度）→ $20 \times 0.01 \times 20 = 4$ 滴。
- **第二步**：4 滴分配——薰衣草 2 滴（主）+ 甜橙 1 滴 + 洋甘菊 1 滴（辅）。
- **第三步**：疗程建议——睡前使用 2–3 周，第 3 周末复评：有效则轮换配方避免疲劳，无效或不适则调整或转介。

**重点：** 剂量不是「算完就固定」。疗程中的复评是处方的「下半场」——好处方是「设计 → 试用 → 调整」的动态过程。

## 5 处方的「减法」原则

- **油要少**：2–4 支足矣，多则互相掩盖、难以归因。
- **浓度要低**：从最低档起步，「宁淡勿猛」。
- **目标要单一**：一次解决一个主要问题，别「全都要」。
- **变化要慢**：一次只改一个变量（换一支油、调一个浓度），才看得出因果。

**辨析｜易错点：** 「一次调一个变量」是处方设计的黄金纪律——同时改三支油，出了问题无法判断是谁的问题。专业处方师「一次一动」，像做实验一样严谨。

给家庭自用场景的落地方案：如果不想做复杂评估，至少守住「三问」——**给谁用、想解决什么、有没有禁忌**。这三问过一遍，就能避免绝大多数「想当然用油」的安全隐患。

**辨析｜易错点：** 「效果不明显就加倍」是最常见的处方失误——效果不好，先想「方向对不对、方式对不对」，而不是先加浓度。浓度不是效果的旋钮，方向与匹配才是。

## 6 反馈、调整与转介

- **反馈**：用 1–2 周后回访，问「有没有改善、有无不适、闻着还喜欢吗」。
- **调整**：有效 → 轮换或巩固；效果平平 → 调整油/浓度/方式；出现不适 → 立即停用、记录。
- **转介**：症状持续、加重，或出现需要医疗处理的情况——给出转介建议（见第26篇伦理），而不是继续调油。

**重点：** 一份好处方，是有「开始、复评、收尾」的生命周期。处方师的成熟，体现在「知道什么时候该调整、什么时候该停手、什么时候该转介」。

**辨析｜易错点：** 「一次性给个案十支油」是最常见的执业失当——不是显得专业，而是显得失控。好的处方「少而准」，并把「怎么用、用多久、何时复评」讲清楚；处方背后是「评估」的功夫，不是「油多」的排场。

## 7 小结

- 个案评估的边界：**评估「健康需求」，不诊断「疾病」**；NAHA 强调「整体评估」。
- 问诊七项：**基本信息、主诉、生活方式、健康用药、皮肤、气味偏好、既往经验**。
- 处方五步：**定目标 → 定方式 → 定主油 → 定浓度 → 定疗程**。
- 剂量计算：$n = V \times C \times 20$；睡前按摩油 20 mL、1% → 4 滴。
- 处方「减法」：**油少、浓度低、目标单一、一次一动**。
- 处方有生命周期：**设计 → 试用 → 复评 → 调整 → 转介**；好处方是动态的。
- 效果不好先想「方向与方式对不对」，不是先加浓度——浓度不是效果旋钮。
- 家庭自用至少守住「三问」：**给谁用、想解决什么、有没有禁忌**。
