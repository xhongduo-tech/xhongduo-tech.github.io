# 中医体质养生（九种体质辨识与调养）

中医体质学由国医大师王琦院士创立，以"体质可分、体病相关、体质可调"为核心，将人群分为九种基本体质类型。以王琦《中医体质学》为纲，结合 GB/T 46939-2025《中医体质分类与判定》国家标准及中华中医药学会体质标准，系统重建从体质理论、九种体质辨识判定到个性化调养与治未病应用的完整体系。学完这些章节，就写完了中医体质养生的全部内容。

## 对标教材

- 王琦《中医体质学》（人民卫生出版社）
- GB/T 46939-2025《中医体质分类与判定》（国家标准）
- 中华中医药学会 ZYYXH/T 157-2009《中医体质分类与判定》标准
