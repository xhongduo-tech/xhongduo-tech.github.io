# 健身气功功法（八段锦/五禽戏/易筋经/六字诀）

健身气功功法是国家体育总局健身气功管理中心审定推广的四套传统导引养生功法——八段锦、五禽戏、易筋经、六字诀，以中医经络气血理论与形气神合一为内核，是官方认可的群众健身养生体系。学完本学科，就系统写完了从功法源流、逐式动作要领、呼吸吐纳到辨证选功与科学健身的全部内容。
