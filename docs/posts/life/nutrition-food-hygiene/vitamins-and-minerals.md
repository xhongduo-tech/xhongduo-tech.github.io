## 为什么单独为微量营养素开一篇

宏量营养素为机体供能与构架，而**维生素与矿物质**的量级要小得多——以毫克甚至微克计——却承担着「一锤定音」的催化与调节功能。它们不供能，却是能量代谢流水线上一环扣一环的**辅酶与辅助因子**：少了硫胺素，糖代谢的第一站就卡壳；少了铁，氧气的运输全线停摆。学习这一篇的意义还在于一个独特的历史视角：营养学这门学科，很大程度上正是从「坏血病」「脚气病」「糙皮病」这些由微量营养素缺乏导致的经典疾病中诞生的。<span class="marginnote">1929 年诺贝尔生理学或医学奖授予艾克曼（Christiaan Eijkman），表彰他证明米糠中的「抗脚气病因子」可治愈脚气病——维生素被发现前，人们长期把这类疾病归因于细菌感染。</span>

## 1 维生素概述：水溶性与脂溶性的分水岭

**维生素（vitamins）**：维持机体正常生理功能所必需、但机体不能合成或合成不足、必须由食物供给的一类微量有机化合物。它们的首要分类依据不是化学结构，而是**溶解性**——这一性质决定了吸收、储存与缺乏的风险模式。

**水溶性维生素**：B 族维生素（$B_1, B_2, B_3, B_5, B_6, B_7, B_9, B_{12}$）与维生素 C。水溶、吸收依赖载体、过量部分经尿排出，**体内储存有限，需经常摄入**，缺乏症状出现较快。
- **脂溶性维生素**：维生素 A、D、E、K。溶于脂肪、需胆汁与乳糜微粒参与吸收，**体内（尤其肝与脂肪组织）可大量储存**，缺乏发展缓慢，过量反而易蓄积中毒。<span class="marginnote">水溶性的「富余」只意味着排出快、耐受高，并不意味着可以无上限补充；脂溶性的「储存」则意味着同样存在毒性风险——维生素 A 与 D 过量中毒都是真实存在的临床事件。</span>

## 2 水溶性维生素巡礼：B 族与维生素 C

**B 族维生素**几乎全部以**辅酶**身份参与能量代谢、造血与神经功能，缺一即对应一个经典病名：

| 维生素 | 辅酶形式 / 角色 | 缺乏症 |
| --- | --- | --- |
| 硫胺素 B₁ | 焦磷酸硫胺素，糖代谢 α-酮酸脱羧 | 脚气病（beriberi）、韦尼克脑病 |
| 核黄素 B₂ | FAD/FMN，氧化还原载体 | 口角炎、舌炎 |
| 烟酸 B₃ | NAD/NADP，氧化还原载体 | 糙皮病（pellagra）：皮炎、腹泻、痴呆 |
| 泛酸 B₅ | 辅酶 A，脂肪酸代谢 | 罕见 |
| 吡哆醇 B₆ | 磷酸吡哆醛，氨基酸代谢 | 皮炎、周围神经炎 |
| 生物素 B₇ | 羧化酶辅酶 | 皮炎、脱发（生蛋清大量摄入可致） |
| 叶酸 B₉ | 一碳单位转移，核酸合成 | 巨幼细胞性贫血、神经管缺陷 |
| 钴胺素 B₁₂ | 甲基转移，造血与髓鞘 | 巨幼细胞性贫血、亚急性脊髓联合变性 |

**维生素 C（抗坏血酸）**：胶原合成的辅因子、强抗氧化剂，促进铁吸收。缺乏导致**坏血病（scurvy）**——牙龈出血、伤口不愈、皮下淤血。<span class="marginnote">坏血病是营养学史上最著名的一次「实验流行病学」：英国海军外科医生詹姆斯·林德（James Lind）1747 年在船上把病人分组试验，发现柑橘类水果有效——这是世界上最早的对照临床试验之一。</span>

## 3 脂溶性维生素：A、D、E、K

**维生素 A（视黄醇）**：视觉（视紫红质）、上皮分化、免疫功能。缺乏致夜盲症与干眼病；过量致肝毒性。膳食来源有两套：动物性（视黄醇）与植物性（β-胡萝卜素等类胡萝卜素前体）。
- **维生素 D（钙化醇）**：钙磷代谢核心激素前体，经皮肤光照合成或膳食补充。缺乏致佝偻病（儿童）与骨软化症（成人）。<span class="marginnote">维生素 D 严格说是「激素前体」，因为人体在日光下可自行合成足量。现代室内生活方式让「晒太阳不足」成为普遍问题，因此它是各国补充剂市场最大的品类之一。</span>
**维生素 E（生育酚）**：脂溶性抗氧化剂，保护细胞膜多不饱和脂肪酸免受氧化。缺乏罕见，见于脂肪吸收不良者。
- **维生素 K**：凝血因子（II、VII、IX、X）的 γ-羧化辅因子，也参与骨钙蛋白活化。缺乏致出血倾向；新生儿常规注射以防维生素 K 缺乏性出血。<span class="marginnote">维生素 K 有叶绿醌（K₁，绿叶蔬菜）与甲萘醌（K₂，肠道菌群合成）两种来源——「肠道细菌能造维 K」是 K 族缺乏少见的原因之一。</span>

## 4 矿物质：常量元素与微量元素

**矿物质（minerals）**：构成机体与参与代谢的无机元素。按每日需要量分为两类。

**常量元素**：每日需要量大于 100 mg，包括**钙、磷、镁、钠、钾、氯、硫**。钙构建骨骼并参与神经肌肉兴奋与凝血；钠钾维持体液平衡与神经电生理；镁是 300 余种酶的辅因子。
- **微量元素**：每日需要量不足 100 mg，包括**铁、锌、碘、硒、铜、锰、氟、铬、钼**等。各有独特功能：铁在血红蛋白中运氧，碘合成甲状腺激素，锌参与酶与免疫，硒是抗氧化酶谷胱甘肽过氧化物酶的组分，氟强化牙釉质。<span class="marginnote">微量元素功能谱与缺乏症几乎一一对应：铁缺→缺铁性贫血，碘缺→甲状腺肿与克汀病，锌缺→生长迟缓与味觉异常，硒缺→克山病（心肌病）。记住「元素—功能—缺乏症」三件套是复习矿物质的高效路径。</span>

「元素—来源—缺乏表现」三件套同样是矿物质的复习主线：

| 矿物质 | 主要食物来源 | 常见缺乏表现 |
| --- | --- | --- |
| 钙 | 乳制品、豆制品、深绿叶菜 | 骨质疏松风险 |
| 铁 | 红肉、动物肝、豆类、强化谷物 | 缺铁性贫血 |
| 锌 | 牡蛎、红肉、坚果、全谷物 | 生长迟缓、味觉减退 |
| 碘 | 海产品、碘盐 | 甲状腺肿 |
| 硒 | 巴西坚果、海产品、肉类 | 克山病（心肌病） |
| 镁 | 绿叶菜、坚果、全谷物 | 肌肉痉挛、疲劳 |

## 5 缺乏与过量：一枚硬币的两面

维生素与矿物质的膳食谱是一条「U 形曲线」：摄入不足走向缺乏，摄入过量走向毒性，中间才是健康区间。这有两个实操含义：

**缺乏**是发展中国家最常见的营养问题：铁、碘、维生素 A 缺乏并称「三大微量营养素缺乏」，全球范围内分别导致贫血、甲状腺疾病与夜盲的高发。
- **过量**则多见于滥用补充剂：脂溶性维生素 A/D 蓄积中毒、高剂量硒致脱甲症、过量铁致氧化损伤。<span class="marginnote">「水溶性维生素过量无害」是常见误区——大量烟酸可致皮肤潮红与肝损伤，大剂量 B₆ 长期服用可致不可逆周围神经病。任何「越多越好」的直觉都违背这条 U 形曲线。</span>

用 U 形曲线读一个具体的例子：维生素 C 的参考摄入量约 100 mg/d，长期严重缺乏（数月低于 10 mg/d）才会走到坏血病，而一次性大量摄入多以尿排出、耐受上限高——曲线两端分别对应「缺乏」与「安全上限」两个问题。铁则是反例：它的可耐受最高摄入量（成人约 45 mg/d）与参考摄入量（成年男性 12 mg/d）之间的空间较小，过量补铁造成的氧化损伤风险是真实存在的——**「曲线两端相距多远」本身就因营养素而异**。<span class="marginnote">铁是最需要谨慎对待的补充剂之一：人体缺乏铁时吸收率会代偿性上升，因此「不缺还补」叠加「高吸收」，极易走向过量。这也是婴幼儿误服补铁药片导致急性中毒的毒理学背景——过量铁在儿童中可以是急症。</span>

## 6 公式解析：视黄醇当量 RAE

维生素 A 的难点在于它有两种来源、且换算率不同，于是需要统一的**计量单位**。现行国际通用的是**视黄醇活性当量（RAE）**：

$$RAE(\mu g) = \text{膳食视黄醇}(\mu g) + \frac{\text{β-胡萝卜素}(\mu g)}{12} + \frac{\text{其他维生素A原类胡萝卜素}(\mu g)}{24}$$

- **第一步，认清两种来源**：动物性食物提供现成的视黄醇，直接计 1:1；植物性食物提供 β-胡萝卜素等前体，人体需先在小肠将其裂解为视黄醇。
- **第二步，看换算系数**：β-胡萝卜素约 12 μg 折合 1 μg RAE，其他类胡萝卜素因转化率更低按 24:1 折算。系数反映的是「转化效率」而非化学当量。<span class="marginnote">旧文献常用「视黄醇当量 RE」（β-胡萝卜素按 6:1 折算），RAE 标准把植物来源的价值评估得更保守——两种单位并读时务必先确认用的是哪一套，否则膳食评估会系统性偏离。</span>
**第三步，相加得总量**：把两路来源折算后相加，与参考摄入量比较即可评估是否达标。

以「一根胡萝卜（约 6000 μg β-胡萝卜素）」为例：$RAE = 6000/12 = 500$ μg RAE。成人男性 RAE 参考摄入量约 800 μg/d，说明**光靠胡萝卜补足维 A 需要相当大的量**——这也是「素食者注意维 A 状态」建议的由来。<span class="marginnote">叶酸的膳食叶酸当量（DFE）采用同样的「不同来源折算」逻辑：合成叶酸吸收率高于天然叶酸，故合成叶酸 × 1.7 折算为 DFE。理解 RAE，就理解了所有「×折算系数」式营养素计量。</span>

## 7 微量营养素的三问工作法

维生素与矿物质数量多、条目琐碎，死记「每种功能 + 缺乏症」容易糊成一团。把本篇内容压缩成一个可迁移的「三问」框架，比背表更接近学科思维：

**它是水溶还是脂溶？** 决定储存特性与中毒风险：水溶（B 族、C）体内储备有限、需经常摄入、过量多随尿排出；脂溶（A、D、E、K）可储存于肝与脂肪组织、缺乏发展缓慢、过量易蓄积中毒。
- **它参与「结构、能量、还是调节」？** 宏量营养素的三大功能在微量层面同样适用：钙铁是结构（骨与血红蛋白），B 族是能量代谢的辅酶，维生素 A、D 与激素类矿物质则偏调节。
- **它最容易在哪些人群里缺？** 铁与叶酸在孕妇、碘在内陆山区居民、维生素 D 在室内工作者与高纬地区、维生素 B₁₂ 在素食者与老年人——把「人群」与「营养素」配对，比孤立记缺乏症更贴近临床。

把这些条目做成一张「常考」对照表，就是本篇最好的复习卡：

| 问题 | 答案 |
| --- | --- |
| 脂溶性维生素有哪些 | A、D、E、K |
| 缺乏致脚气病 | 维生素 B₁（硫胺素） |
| 缺乏致糙皮病 | 维生素 B₃（烟酸） |
| 缺乏致巨幼细胞性贫血 | 叶酸、维生素 B₁₂ |
| 缺乏致夜盲症 | 维生素 A |
| 缺乏致佝偻病/骨软化 | 维生素 D |
| 全球三大微量营养素缺乏 | 铁、碘、维生素 A |
| 过量最易蓄积中毒 | 维生素 A、D |

**易错点辨析：**「复合维生素补一下总没错」是把 U 形曲线忘在脑后的典型心态。对不缺的人，补充剂大多只是「制造昂贵尿液」；对缺的人，关键在「补什么、补多少、补多久」。真正该做的第一步是评估与筛查，而不是开一瓶保健品——这与《营养状况评价》的「先评估再干预」一脉相承。<span class="marginnote">判断「该不该补」最实用的信号：特殊生理状态（孕、哺乳、老年）、长期严格素食、消化道吸收障碍、以及日照不足的居住环境。符合其中任何一条，才值得在医生或营养师指导下考虑补充。</span>

## 8 小结

- 维生素按**溶解性**分水溶（B 族、C）与脂溶（A、D、E、K），决定储存特性与中毒风险模式。
- B 族维生素几乎全是**辅酶**，各自对应一个经典缺乏症病名：脚气病、糙皮病、巨幼细胞性贫血等。
- **维生素 C** 缺乏致坏血病，**维生素 D** 缺乏致佝偻病/骨软化，**维生素 K** 缺乏致出血倾向。
- 矿物质分**常量元素**（钙、磷、镁、钠、钾…）与**微量元素**（铁、锌、碘、硒…），铁/碘/维 A 是全球三大微量营养素缺乏。
- 摄入-健康的**U 形曲线**意味着：不足有缺乏症，过量有毒性，「越多越好」是错误直觉。
- **RAE** 把维 A 两种来源统一计量：视黄醇 1:1，β-胡萝卜素 12:1，其他类胡萝卜素 24:1。
- 学微量营养素用「三问工作法」：水溶还是脂溶、参与结构/能量/调节、最容易缺在哪些人群。
