## 为什么从心内膜炎开始

本专题以「心脏的机器」开篇，到这一篇讲**细菌如何入侵这台机器的心脏部件**——**感染性心内膜炎（infective endocarditis, IE）**：细菌在心脏内膜、瓣膜上定植形成**赘生物**，边破坏瓣膜边向血流播散。它把本专题的许多线索收拢在一起：超声心动图（TEE 见赘生物）、瓣膜病（急性瓣膜毁损）、先天性心脏病（易感人群与预防）、药理学（长程抗生素）。<span class="marginnote">这或许是最「反直觉」的心脏病：心内膜炎的原始病灶在心脏，但病人最先见到的症状往往是发热与栓塞——<strong>心脏只是战场，全身都是伤兵</strong>。临床医生靠「想到」才能诊断它。</span>

## 1 三个条件：病原、受损的膜与机会

细菌要「安家」，需要三件事同时发生——这与血栓形成的 **Virchow 三联征**结构同构：

1. **内膜损伤**：湍流或异物（人工瓣膜、先心畸形）让内膜粗糙，为细菌提供黏附「锚点」。
2. **菌血症**：口腔操作、拔牙、注射吸毒、导管置入，让细菌入血。
3. **黏附与定植**：链球菌的葡聚糖、葡萄球菌的黏附素把细菌「焊」在内膜上，随后增殖成**赘生物（vegetation）**——血小板+纤维蛋白+细菌的「堡垒」，抗生素难以渗入。

**核心概念**：病原体与**「从哪条门进来」**高度相关——社区口腔链球菌（草绿色链球菌）→ 自体瓣膜；**金黄色葡萄球菌** → 人工瓣膜、注射吸毒与院内感染（最凶险，破坏快）；肠球菌 → 泌尿生殖道操作。**问清楚「怎么得的」，病原谱就猜中了一半。**<span class="marginnote">自体瓣膜 IE 里链球菌仍是主角，但院内与吸毒相关 IE 中金黄色葡萄球菌已居首位——病原谱随「感染途径」漂移，这正是「流行病学决定经验用药」的活例。</span>

## 2 临床谱：发热、杂音与栓塞

经典三联是**发热 + 新出现的/变化的杂音 + 栓塞**。发热几乎是必有的（少见的是老年、免疫抑制者可不发热）；新杂音提示瓣膜正在被破坏。

外周体征是「心脏病的全身证据」，几乎每个都带名字：

**Osler 结节**：指（趾）腹的痛性紫红色小结节——免疫介导。
- **Janeway 损害**：掌跖无痛性红斑——栓塞性。
- **甲下裂片状出血、Roth 斑**（视网膜）——微栓塞。

**最危险的是并发症**：瓣膜急性毁损（连枷瓣 → 急性反流 → 急性心衰）、**脑栓塞**（最常由瓣膜赘生物脱落）、瓣周脓肿与传导阻滞。<span class="marginnote">赘生物是「会走路的石头」：随血流脱落到脑、脾、肾、肢端。<strong>栓子去哪，症状就出现在哪</strong>——青年卒中+发热，第一个要想到的就是心内膜炎。</span>

## 3 诊断：改良 Duke 标准（核心要点表格）

诊断采用**改良 Duke 标准**：≥ 2 条主要标准、或 1 主要 + 3 次要、或 5 次要，即临床确诊。

| 主要标准 | 次要标准 |
| --- | --- |
| ① 血培养阳性：2 套以上分次抽血培养出典型病原（草绿色链球菌、金黄色葡萄球菌等）；或持续菌血症 | 易感基础：心脏瓣膜病、先心病、人工瓣膜、静脉吸毒 |
| ② 心内膜炎证据：TEE/TTE 见**赘生物**、瓣周脓肿或新的人工瓣膜裂开 | 发热 ≥ 38 ℃ |
| | 血管现象：主要动脉栓塞、肺栓塞（右侧 IE）、真菌性动脉瘤 |
| | 免疫现象：肾小球肾炎、Osler 结节、Roth 斑 |
| | 微生物学证据但未达主要标准 |

**辨析｜易错点：** Duke 标准的核心价值是「把散落的证据放进同一张表格」，但它的首要前提是**「先怀疑、再送检」**——血培养必须在**用抗生素之前**、不同时间点多套采集；一旦先用抗生素再培养，菌血症转阴、主要标准立减一半。**「没培养就用药」是心内膜炎最常见的可预防失误**——经验性用药永远要排在两次血培养之后。

## 4 治疗与预防

治疗的两条腿是**长程杀菌抗生素**与**及时手术**：

1. **抗生素**：先抽血培养，随后经验性覆盖（草绿色链球菌→青霉素/头孢曲松；金葡菌→苯唑西林/万古霉素；人工瓣膜或 MRSA 风险→万古霉素）；病原明确后**目标治疗**。疗程长（自体瓣膜 2–6 周、人工瓣膜 ≥ 6 周），因为赘生物内的细菌代谢低、需长程血药浓度维持——这正是「药代动力学」的现实版（见《心脏药理学》）。<span class="marginnote">赘生物是细菌的「防空洞」：越深层的细菌代谢越慢、对抗生素越不敏感。所以疗程不是「症状好了就停」——<strong>杀菌要按赘生物的物理规律来，4–6 周是物理，不是习惯</strong>。</span>
2. **手术指征**：心衰（急性反流）、无法控制的感染（持续菌血症、脓肿）、反复大栓塞、真菌性 IE——「内科治菌、外科治结构」，两者不是二选一而是接力。

**预防**：抗生素预防仅限于**最高危**人群与操作（人工瓣膜、既往 IE、特定先心病；行口腔有创操作前）——不是人人拔牙都吃药。**预防的核心其实是「无菌操作 + 口腔卫生」**，而非抗生素滥用。<span class="marginnote">预防性抗生素的「限缩」是全球指南的共同趋势：对低危人群，抗生素预防的获益被耐药风险与过敏抵消——<strong>少用药，也是一种进步</strong>。这与《心脏药理学》中「多用药 ≠ 多获益」的哲学一脉相承。</span>

## 5 小结

- IE = **内膜损伤 + 菌血症 + 细菌黏附定植**，病原谱随感染途径漂移。
- 临床谱：**发热 + 新杂音 + 栓塞**；外周体征（Osler 结节、Janeway 损害等）是全身证据。
- 改良 Duke 标准以**血培养 + 超声赘生物**为主标准，**抗生素前先送培养**是铁律。
- 治疗：长程杀菌抗生素（2–6 周）+ 手术（心衰、难控感染、栓塞、真菌）。
- 预防限缩至最高危人群；**口腔卫生与无菌操作**才是日常防线。
