## 为什么从心内膜炎开始

本专题以「心脏的机器」开篇，到这一篇讲**细菌如何入侵这台机器的心脏部件**——**感染性心内膜炎（infective endocarditis, IE）**：细菌在心脏内膜、瓣膜上定植形成**赘生物**，边破坏瓣膜边向血流播散。它把本专题的许多线索收拢在一起：超声心动图（TEE 见赘生物）、瓣膜病（急性瓣膜毁损）、先天性心脏病（易感人群与预防）、药理学（长程抗生素）。<span class="marginnote">这或许是最「反直觉」的心脏病：心内膜炎的原始病灶在心脏，但病人最先见到的症状往往是发热与栓塞——<strong>心脏只是战场，全身都是伤兵</strong>。临床医生靠「想到」才能诊断它。</span>

先给一个流行病学的坐标：IE 的年发病率约 3–10 例/10 万人，男性略多，发病中位年龄约 60 岁；它虽「少见」，却因高致死率（住院死亡率约 15–20%）而值得每个心血管医生警惕。理解它，需要同时握住**微生物学**（谁感染了）、**血流动力学**（感染毁坏了什么）与**药理学**（如何长程杀灭）三把钥匙——这与本专题《心脏药理学》《心脏瓣膜病》用的是同一套工具。

## 1 三个条件：病原、受损的膜与机会

细菌要「安家」，需要三件事同时发生——这与血栓形成的 **Virchow 三联征**结构同构：

1. **内膜损伤**：湍流或异物（人工瓣膜、先心畸形）让内膜粗糙，为细菌提供黏附「锚点」。
2. **菌血症**：口腔操作、拔牙、注射吸毒、导管置入，让细菌入血。
3. **黏附与定植**：链球菌的葡聚糖、葡萄球菌的黏附素把细菌「焊」在内膜上，随后增殖成**赘生物（vegetation）**——血小板+纤维蛋白+细菌的「堡垒」，抗生素难以渗入。

**核心概念**：病原体与**「从哪条门进来」**高度相关——社区口腔链球菌（草绿色链球菌）→ 自体瓣膜；**金黄色葡萄球菌** → 人工瓣膜、注射吸毒与院内感染（最凶险，破坏快）；肠球菌 → 泌尿生殖道操作。**问清楚「怎么得的」，病原谱就猜中了一半。**<span class="marginnote">自体瓣膜 IE 里链球菌仍是主角，但院内与吸毒相关 IE 中金黄色葡萄球菌已居首位——病原谱随「感染途径」漂移，这正是「流行病学决定经验用药」的活例。</span>

按起病速度，IE 又分**急性**与**亚急性**两类：急性 IE（常为金黄色葡萄球菌）数天至数周内破坏瓣膜、毒血症显著、死亡率高；亚急性 IE（草绿色链球菌为主）起病隐匿，以低热、乏力、体重下降为主，可迁延数月。**「急与缓」背后是病原的毒力**——细菌破坏瓣膜的速度，就是病程的速度，也是经验性用药激进程度的依据。

把「感染途径」与病原对应起来，是经验用药的第一张地图：

| 临床情境 | 最常见病原 | 常见来源 |
| --- | --- | --- |
| 自体瓣膜、牙科来源 | 草绿色链球菌 | 口腔菌血症 |
| 人工瓣膜（早期） | 表皮葡萄球菌 | 院内手术期污染 |
| 人工瓣膜（晚期） | 链球菌、金黄色葡萄球菌 | 社区感染 |
| 注射吸毒相关 | 金黄色葡萄球菌 | 皮肤菌血症 |
| 泌尿生殖道操作后 | 肠球菌 | 肠道 / 泌尿菌群 |
| 结直肠肿瘤相关 | 牛链球菌 | 肠道屏障受损 |

**辨析｜易错点：** 「心脏有杂音」不等于「感染在心脏」。无数健康人存在良性杂音（血流湍流所致），IE 的特征是**杂音的新出现或性质改变**（瓣膜在急性破坏）+ 发热 + 栓塞证据。把「老杂音」误读为「新病变」，或反过来漏掉新杂音，都是常见偏差——**杂音要和「既往的杂音」比，而不是和「正常」比**。

## 2 临床谱：发热、杂音与栓塞

经典三联是**发热 + 新出现的/变化的杂音 + 栓塞**。发热几乎是必有的（少见的是老年、免疫抑制者可不发热）；新杂音提示瓣膜正在被破坏。

外周体征是「心脏病的全身证据」，几乎每个都带名字：

**Osler 结节**：指（趾）腹的痛性紫红色小结节——免疫介导。
- **Janeway 损害**：掌跖无痛性红斑——栓塞性。
- **甲下裂片状出血、Roth 斑**（视网膜）——微栓塞。

**最危险的是并发症**：瓣膜急性毁损（连枷瓣 → 急性反流 → 急性心衰）、**脑栓塞**（最常由瓣膜赘生物脱落）、瓣周脓肿与传导阻滞。<span class="marginnote">赘生物是「会走路的石头」：随血流脱落到脑、脾、肾、肢端。<strong>栓子去哪，症状就出现在哪</strong>——青年卒中+发热，第一个要想到的就是心内膜炎。</span>

把并发症按「机制」排比，就明白 IE 的凶险来自三条途径：**机械性**（瓣膜毁损 → 急性反流 → 急性心衰，是 IE 死亡的首要原因）、**栓塞性**（赘生物脱落 → 脑/脾/肾/肢体栓塞，左心 IE 更常栓塞脑部）、**免疫性**（免疫复合物沉积 → 肾小球肾炎、Osler 结节）。**同一株细菌，机械、栓塞、免疫三条战线同时开火**——所以 IE 的处置不能只盯「感染」，要同步盯瓣膜与远端器官。

## 3 诊断：改良 Duke 标准（核心要点表格）

诊断采用**改良 Duke 标准**：≥ 2 条主要标准、或 1 主要 + 3 次要、或 5 次要，即临床确诊。

| 主要标准 | 次要标准 |
| --- | --- |
| ① 血培养阳性：2 套以上分次抽血培养出典型病原（草绿色链球菌、金黄色葡萄球菌等）；或持续菌血症 | 易感基础：心脏瓣膜病、先心病、人工瓣膜、静脉吸毒 |
| ② 心内膜炎证据：TEE/TTE 见**赘生物**、瓣周脓肿或新的人工瓣膜裂开 | 发热 ≥ 38 ℃ |
| | 血管现象：主要动脉栓塞、肺栓塞（右侧 IE）、真菌性动脉瘤 |
| | 免疫现象：肾小球肾炎、Osler 结节、Roth 斑 |
| | 微生物学证据但未达主要标准 |

**辨析｜易错点：** Duke 标准的核心价值是「把散落的证据放进同一张表格」，但它的首要前提是**「先怀疑、再送检」**——血培养必须在**用抗生素之前**、不同时间点多套采集；一旦先用抗生素再培养，菌血症转阴、主要标准立减一半。**「没培养就用药」是心内膜炎最常见的可预防失误**——经验性用药永远要排在两次血培养之后。

超声是诊断的另一只眼：**经食管超声（TEE）比经胸超声（TTE）敏感得多**——赘生物检出率 TTE 约 60%、TEE 超过 90%，对人工瓣膜与 < 5 mm 的小赘生物尤其明显。TTE 阴性而临床高度怀疑者应升级 TEE（见《心脏影像学诊断》）；TEE 还能量化瓣膜毁损程度，为「何时手术」提供解剖证据。

## 4 治疗与预防

治疗的两条腿是**长程杀菌抗生素**与**及时手术**：

1. **抗生素**：先抽血培养，随后经验性覆盖（草绿色链球菌→青霉素/头孢曲松；金葡菌→苯唑西林/万古霉素；人工瓣膜或 MRSA 风险→万古霉素）；病原明确后**目标治疗**。疗程长（自体瓣膜 2–6 周、人工瓣膜 ≥ 6 周），因为赘生物内的细菌代谢低、需长程血药浓度维持——这正是「药代动力学」的现实版（见《心脏药理学》）。<span class="marginnote">赘生物是细菌的「防空洞」：越深层的细菌代谢越慢、对抗生素越不敏感。所以疗程不是「症状好了就停」——<strong>杀菌要按赘生物的物理规律来，4–6 周是物理，不是习惯</strong>。</span>
2. **手术指征**：心衰（急性反流）、无法控制的感染（持续菌血症、脓肿）、反复大栓塞、真菌性 IE——「内科治菌、外科治结构」，两者不是二选一而是接力。

经验性抗生素方案，可先按「感染途径」对号入座：

| 临床情境 | 常见病原 | 经验方案 |
| --- | --- | --- |
| 自体瓣膜、牙科来源 | 草绿色链球菌 | 青霉素 G 或头孢曲松 |
| 人工瓣膜 / 院内感染 | 金黄色葡萄球菌、表皮葡萄球菌 | 万古霉素 ± 利福平 |
| 注射吸毒相关 | 金黄色葡萄球菌 | 苯唑西林 / 万古霉素 |
| 泌尿生殖道操作后 | 肠球菌 | 氨苄西林 + 庆大霉素 |

**治疗监测**：疗效看三条线——体温、血培养转阴、赘生物与瓣膜结构（复查 TEE）。「热退就停药」是危险的错觉：即使临床好转，赘生物核心的细菌仍需长程杀菌；疗程不足的复发率显著上升。**疗程的终点不是「症状消失」，而是「病原根除」**——这正是《心脏药理学》里「稳态思维」的临床延伸。

**预防**：抗生素预防仅限于**最高危**人群与操作（人工瓣膜、既往 IE、特定先心病；行口腔有创操作前）——不是人人拔牙都吃药。**预防的核心其实是「无菌操作 + 口腔卫生」**，而非抗生素滥用。<span class="marginnote">预防性抗生素的「限缩」是全球指南的共同趋势：对低危人群，抗生素预防的获益被耐药风险与过敏抵消——<strong>少用药，也是一种进步</strong>。这与《心脏药理学》中「多用药 ≠ 多获益」的哲学一脉相承。</span>

## 5 特殊类型与临床陷阱

三种「变体」值得单独认识，它们的病原、部位与病程各不相同：

**右侧心内膜炎（右心 IE）**：多见于注射吸毒者，赘生物常长在**三尖瓣**，特征性表现是**反复肺栓塞与肺部感染**（栓子沿静脉入肺），而全身栓塞少见，预后相对较好。<span class="marginnote">「同样叫心内膜炎，左心 vs 右心的栓塞去向完全不同」——左心赘生物顺动脉到脑、脾、肾，右心赘生物顺静脉进肺。病灶位置决定了「病历会往哪写」。</span>

**人工瓣膜心内膜炎（PVE）**：术后一年内的**早期 PVE** 以院内污染（表皮葡萄球菌为主），一年后以链球菌等社区病原为主。赘生物常隐蔽在瓣环与缝合线周围，TEE 几乎不可或缺；治疗常需**长程抗生素 + 再次手术**并举。

**培养阴性的心内膜炎**：约 5% 的 IE 血培养持续阴性——原因包括**先用抗生素**（最常见）、**HACEK 组群**（生长缓慢的革兰阴性杆菌，需延长培养 1–3 周）与 **Q 热立克次体**（Coxiella burnetii）。**「培养阴性 ≠ 没有 IE」**——阴性结果要回溯「是不是用药太早」，而非放弃诊断。

**辨析｜易错点：** IE 的「伪善」细节常被忽略。其一，**发热可能是唯一症状**，老年与免疫抑制者尤其如此，须凭「心脏危险信号」（新杂音、栓塞、先心史）主动想到 IE；其二，**皮肤黏膜体征一过性出现**，错过了就查不到，查体要「反复找」；其三，**青年卒中 + 发热**几乎默认要排查 IE——栓子不会说谎，它指向病灶所在的瓣膜。

## 6 数值速查：核心数字一表打尽

心内膜炎的管理，散落着十几个必须记牢的数字，集中列成一张表：

| 项目 | 数值 / 要点 |
| --- | --- |
| 年发病率 | 约 3–10 例 / 10 万人 |
| 血培养采集 | 用抗生素前，不同部位 2–3 套 |
| Duke 确诊 | ≥ 2 主要，或 1 主要 + 3 次要，或 5 次要 |
| TEE 赘生物检出 | 灵敏度 > 90%（TTE 约 60%） |
| 自体瓣膜疗程 | 2–6 周静脉杀菌抗生素 |
| 人工瓣膜疗程 | ≥ 6 周 |
| 手术指征 | 心衰、难控感染、反复栓塞、真菌性 IE |
| 预防人群 | 人工瓣膜、既往 IE、特定先心病 + 有创口腔操作 |

## 7 小结

- IE = **内膜损伤 + 菌血症 + 细菌黏附定植**，病原谱随感染途径漂移。
- 临床谱：**发热 + 新杂音 + 栓塞**；外周体征（Osler 结节、Janeway 损害等）是全身证据。
- 改良 Duke 标准以**血培养 + 超声赘生物**为主标准，**抗生素前先送培养**是铁律。
- 治疗：长程杀菌抗生素（2–6 周）+ 手术（心衰、难控感染、栓塞、真菌）。
- 病原谱随「感染途径」漂移：社区链球菌→自体瓣膜、金葡菌→人工瓣膜与吸毒、肠球菌→泌尿道。
- 机械 / 栓塞 / 免疫三条并发症战线：急性心衰、脑栓塞、肾小球肾炎同时开火。
- 右心 IE 栓塞进肺、人工瓣膜 IE 需 TEE 与再手术、培养阴性要回溯「是否用药太早」。
- 疗程终点是「病原根除」而非「症状消失」；**热退就停药是复发的最常见入口**。
- 预防限缩至最高危人群；**口腔卫生与无菌操作**才是日常防线。
