## 为什么从主动脉开始

心脏射出血液的第一站是**主动脉**——全身最大的动脉，直径约 3 cm，承担着把每一次搏动能最平顺地转递到全身的任务。当这条「生命主干道」自身出问题——内膜撕裂（夹层）、管壁膨出（动脉瘤）——往往就是灾难性的。而离开心脏的四肢动脉（外周动脉），则是动脉粥样硬化最容易被触摸到、也最容易被忽略的战场。

这一节把「血管病」分成三类讲：**夹层**（急性撕裂）、**动脉瘤**（慢性膨出）、**外周动脉病**（四肢缺血），并用一个物理公式贯穿前两者：**直径越大，越危险**。

还有一个把本篇与「从极限到大模型」主线相连的角度：血管病是**流体力学与材料力学**的活教材——泊肃叶定律管「流量」、Laplace 定律管「壁张力」、湍流决定斑块好发位置（见《动脉粥样硬化发病机制》）。看懂主动脉与外周血管病，等于在血管这棵树上复习了整棵物理树的枝干。

## 1 主动脉夹层：最凶险的「撕裂样胸痛」

**主动脉夹层（aortic dissection）**：内膜撕裂后，高压血流钻入中膜，把主动脉壁「劈成两层」，形成**真腔与假腔**。它是最凶险的急性胸痛之一，不处理死亡率以小时计。

典型表现是**突发撕裂样或刀割样胸痛**，放射至背部，伴**双侧脉搏/血压不对称**、晕厥、以及夹层延伸导致的并发症（心包压塞、主动脉瓣反流、心肌梗死样表现、脑卒中）。<span class="marginnote">「痛感的性质」比「痛的位置」更重要：心梗的痛是压迫性，夹层的痛是撕裂性——这一字之差，决定病人进导管室还是进手术室。</span>

按 Stanford 分型：**A 型累及升主动脉**（占多数、最凶险，需急诊外科手术），**B 型不累及升主动脉**（可内科治疗：控制心率血压、β 受体阻滞剂）。头号危险因素是**高血压**——这再次把《高血压》一篇的「降压」抬到保命的高度。<span class="marginnote">影像上夹层的诊断金标准是 CT 血管成像或经食管超声（见《心脏影像学诊断》）：真腔、假腔与内膜片一眼可辨。CT 的「快」正是它成为急诊首选的原因。</span>

**辨析｜易错点：** 疑似夹层的病人**禁用溶栓**——若把夹层误当心梗溶栓，后果是灾难性的大出血。所以胸痛的鉴别顺序中，「先排除夹层」是介入前不可省略的一步。

按病变范围还有 **DeBakey 分型**（I 型全程、II 型仅升主动脉、III 型仅降主动脉），与 Stanford 分型互为补充：临床决策习惯用 Stanford（累不累及升主动脉），解剖描述常用 DeBakey。**决定生死的不是「几型」，而是「升主动脉是否受累」**——升主动脉是心包与冠脉的邻居，累及它就意味着心包压塞、冠脉开口撕裂等灾难随时可能发生。

**危险因素与易患状态**：高血压是第一位的可治疗因素；**马凡综合征**（结缔组织病，主动脉壁薄弱）、二叶式主动脉瓣、主动脉炎（大动脉炎、梅毒）、妊娠与创伤次之。**「高血压 + 剧烈胸痛」就应想到夹层**——鉴别诊断里夹层必须在心梗之前被「先排除」，因为溶栓对夹层是灾难。

**夹层的并发症谱**（「夹层走到哪，症状就到哪」）：累及冠脉开口 → 心梗样表现；累及头臂动脉 → 脑卒中；累及肾动脉 → 急性肾衰竭；累及肠系膜动脉 → 肠缺血；撕裂入心包 → 心包压塞（猝死主因之一）。**「胸痛 + 任何器官缺血的迹象」都要把夹层放在最前面**——它是一场沿动脉游走的灾难。

**影像与诊断**：急诊 CT 血管成像（CTA）是首选，数分钟内给出真腔、假腔、内膜片与撕裂范围；经食管超声（TEE）可在床旁快速评估升主动脉并同步排除心包积液。**胸片正常不能排除夹层**（纵隔增宽只见于约半数病例）——「影像阴性但高度怀疑」者仍要按夹层路径管理直到排除。

**急性处理**：控制心率与血压——先 β 受体阻滞剂（目标心率 < 60 次/分）再加血管扩张剂（目标收缩压 100–120 mmHg）；A 型转外科手术，B 型合并并发症（破裂、脏器灌注不良、顽固高血压）同样要介入或手术。**「镇静止痛 + 降心率 + 降压」是夹层的急诊三板斧**，随后才是决定「开刀还是支架」。

## 2 主动脉瘤：不断膨胀的定时炸弹

**主动脉瘤（aortic aneurysm）**：主动脉局部扩张，直径超过正常值 50% 以上。它不是肿瘤，而是「管壁薄弱处的气球」。最常见于**腹主动脉（AAA，尤其吸烟老年男性）**与**胸主动脉（TAA）**。

绝大多数动脉瘤**无症状**，却在悄悄长大。它的危险在**破裂**：一旦破裂，腹腔内大出血，院前死亡率极高。因此现代管理的关键是**筛出、随访、择期干预**——超声筛查（男性 65 岁以上吸烟者）与定期影像随访，正是「把炸弹找出来再拆」的预防医学范例。<span class="marginnote">夹层与动脉瘤常被混淆：夹层是「壁撕裂、有真假腔」，动脉瘤是「壁膨出、管腔单腔」。但二者可并存——动脉瘤管壁张力大，本就易从薄弱点撕开。物理上都指向同一个压力与直径的乘积。</span>

AAA 的自然病程是**不断扩张直至破裂**：直径 4.0–5.5 cm 年扩张约 0.2–0.5 cm，直径越大扩张越快（扩张速度与张力同源，见 §4）。症状性动脉瘤（腹痛、搏动性包块、背痛）即使直径不大也提示破裂前兆。

**筛查与随访**：超声是无创的金标准，男性 65–75 岁吸烟者建议一次筛查（USPSTF）；已确诊者按直径随访——< 4 cm 每 1–2 年、4–5.5 cm 每 6 个月复查。**随访的节律由张力曲线决定**：直径越大，留给干预的窗口越窄。

把最容易混淆的两种大血管急症并排对照：

| 特征 | 主动脉夹层 | 主动脉瘤 |
| --- | --- | --- |
| 病理本质 | 内膜撕裂、真假腔 | 管壁膨出、单腔 |
| 急性 / 慢性 | 常急性起病 | 常慢性隐匿 |
| 典型表现 | 撕裂样胸痛、脉搏不对称 | 多无症状、搏动性包块 |
| 最凶险结局 | 破裂出血、心包压塞 | 破裂出血 |
| 诊断首选 | 急诊 CT 血管成像 | 超声 / CT 随访 |
| 处理 | A 型手术、B 型内科 | ≥ 5.5 cm 择期手术 |

胸主动脉瘤（TAA）与腹主动脉瘤（AAA）的病因与伴随病不同：TAA 更多与**结缔组织病**（马凡、Loeys-Dietz）、二叶式主动脉瓣、主动脉炎相关，直径 ≥ 5.5 cm（有结缔组织病或二叶瓣者更低）考虑干预；AAA 与**吸烟、年龄、男性、家族史**最相关，干预线为 ≥ 5.5 cm。**「同样的球，长在不同位置，病因与阈值都不相同」**——先分位置，再谈处理。

## 3 外周动脉疾病：被忽视的下游战场

**外周动脉疾病（peripheral artery disease, PAD）**：下肢动脉的粥样硬化性狭窄，典型症状是**间歇性跛行**——行走一段距离后小腿酸痛、休息缓解。它是「全身动脉粥样硬化的冰山一角」：**PAD 患者的冠脉与脑血管病风险显著升高**，常被称为「心梗与卒中的预警器」。<span class="marginnote">跛行的「距离阈值」很有信息量：跛行距离逐月缩短，提示狭窄在进展。医生会把跛行距离当作随访指标——症状是病人自己的无创传感器。</span>

床边无创诊断是**踝臂指数（ABI）**：

$$
\text{ABI} = \frac{P_{\text{ankle}}}{P_{\text{brachial}}} = \frac{\text{踝部收缩压}}{\text{肱动脉收缩压}}
$$

正常 ABI ≥ 0.9；< 0.9 提示下肢动脉狭窄，< 0.4 提示严重缺血。测量原理极简：**下肢血压应不低于是上肢血压；若踝部血压显著低于臂部，说明中间有狭窄在「降压」**——这是用血压计做的「血管造影」，也是流体力学的直白应用。

治疗：戒烟与**结构化的步行训练**（利用缺血刺激侧支循环）是一线；症状重者行腔内成形或旁路手术；同时**务必用他汀与抗血小板药管理全身粥样硬化风险**——治 PAD 却只盯着腿，是常见视野错误。

按严重度，PAD 走一条「跛行 → 静息痛 → 组织坏死」的下坡路：间歇性跛行（运动痛、休息缓解）→ **静息痛**（夜间卧床痛、下垂肢体缓解）→ **组织缺损**（溃疡、坏疽）。后者合称**严重肢体缺血（CLI）**，是截肢的高危状态，也是「再不通血管就要丢腿」的警报。<span class="marginnote">「夜间痛、下垂腿缓解」是 CLI 的特征：卧位时灌注压最低、肢体平心脏，下垂靠重力抬高灌注压，症状缓解——体位本身就是一次血流动力学实验。</span>

踝臂指数的解读，是一个连续的梯度：

| ABI 范围 | 含义 | 建议 |
| --- | --- | --- |
| > 1.3 | 血管钙化（假性升高） | 需趾压等校正，糖尿病常见 |
| 0.9–1.3 | 正常 | 定期复查 |
| 0.5–0.9 | 轻度—中度缺血 | 生活方式 + 药物治疗 |
| < 0.5 | 重度缺血 | 评估血运重建 |
| < 0.4 | 严重肢体缺血 | 紧急评估 |

**药物治疗**：PAD 的治疗与冠心病同源——**他汀（所有 PAD 患者都应使用，降 LDL + 稳定斑块）、抗血小板（阿司匹林或氯吡格雷）、戒烟与严格控血压血糖**（见《血脂异常与调脂治疗》《高血压与肺动脉高压》）。血运重建（腔内成形 + 支架，或旁路）用于 CLI 或药物治疗失败的跛行。**PAD 是「全身粥样硬化的哨兵」**——发现 PAD，等于给冠脉与脑血管发出了预警。

**辨析｜易错点：** 股动脉搏动减弱 + 下肢血压低于上肢，是查体就能做「简易 ABI」；但**钙化的动脉压不扁**——糖尿病或肾衰竭患者 ABI 可能「假性正常」（> 1.3），此时要测**趾臂指数（TBI）**或足趾压力，否则会漏掉真实缺血。**「ABI 正常」在钙化人群中可能是假象**。

## 4 公式解析：为什么「越大越危险」

动脉瘤破裂风险与尺寸的关联，由 Laplace 定律支配：

$$
\sigma = \frac{P \cdot r}{2h}
$$

$\sigma$ 为动脉壁的**环向张力**，$P$ 为腔内血压，$r$ 为动脉半径，$h$ 为壁厚。三步拆解它如何「预言」破裂：

- **第一步，看线性**：壁张力与血压、半径**成正比**——血压升高 50% 或直径增大 50%，张力同样升高 50%。
- **第二步，看非线性**：更大的直径 → 更大的张力 → 加速扩张 → 更大的直径。这是一个**正反馈**，所以动脉瘤的生长常呈「先是缓坡，后是陡崖」的加速曲线。
- **第三步，得到干预阈值**：正因张力随 $r$ 增大，临床定出「择期修复线」——腹主动脉瘤直径 ≥ 5.5 cm（或年扩张 > 1 cm）即建议干预，< 5.5 cm 则随访观察。**尺寸不是教条，而是张力物理学的临床投影。**

**辨析｜易错点：** 血压管理对动脉瘤患者是「双刃剑」：降压降低张力、延缓扩张（好），但**血压过低会影响重要器官灌注**。对夹层急性期要「快降压、降心率」，对慢性动脉瘤则要「稳降压、缓随访」——同是降血压，节奏完全不同。

## 5 不止腿：颈动脉、肾动脉与肠系膜缺血

动脉粥样硬化是「全身性的」，除了下肢，三处血管床同样常见：

**颈动脉狭窄**：粥样斑块在颈总动脉分叉处狭窄，脱落或原位血栓致**脑梗死**。听诊可闻**颈动脉杂音**（湍流），超声测内膜中层厚度（IMT）与狭窄度，是卒中风险的无创指标；症状性重度狭窄（> 70%）多需内膜剥脱或支架。

**肾动脉狭窄**：缺血激活 RAAS，表现为**顽固性高血压 + 肾功能波动**（见《高血压与肺动脉高压》）；双侧重度狭窄需评估血运重建，但盲目支架并不总优于药物。

**肠系膜缺血**：慢性者进食后腹痛、体重下降（「肠绞痛」）；急性者突发剧烈腹痛 + 腹胀，是**急性肠系膜缺血**，不及时开通血管则肠坏死，死亡率极高。

## 6 数值速查：干预阈值一表打尽

大血管与下肢血管的决策，最终都落在几个数字上：

| 指标 | 阈值 | 依据 |
| --- | --- | --- |
| 夹层急性期目标心率 | < 60 次/分 | 降 dp/dt、减剪切 |
| 夹层急性期目标收缩压 | 100–120 mmHg | 降壁张力 |
| AAA 择期手术 | ≥ 5.5 cm | Laplace 张力线 |
| AAA 快速扩张 | 年扩张 > 1 cm | 破裂风险陡增 |
| ABI 诊断 PAD | < 0.9 | 下肢缺血 |
| ABI 重度缺血 | < 0.4 | CLI / 截肢风险 |

## 7 小结

- 主动脉夹层：**内膜撕裂、真腔假腔**；A 型急诊手术、B 型内科控制；**疑似夹层禁用溶栓**。
- 主动脉瘤：**管壁膨出、单腔**；破裂风险随直径增长；AAA ≥ 5.5 cm 考虑择期干预。
- PAD：跛行 + **ABI < 0.9**；一线是戒烟与步行训练，同时管理全身粥样硬化。
- Laplace $\sigma = Pr/2h$：**张力与血压和半径成正比，越大越危险**，这是所有血管「尺寸决策」的物理根。
- 夹层与动脉瘤是「撕裂」与「膨出」之辨，但共享同一物理宿命。
- 夹层并发症沿血管游走：冠脉、脑、肾、肠系膜、心包——**胸痛 + 任一器官缺血迹象都先排夹层**。
- 三处「隐性」血管床：颈动脉狭窄致卒中、肾动脉狭窄致顽固高血压、肠系膜缺血致肠绞痛——**动脉粥样硬化是全身病，治 PAD 不能只盯腿**。
- ABI > 1.3 要警惕血管钙化的假性升高，糖尿病患者尤其。

在下一节，我们把时间轴拨回出生前：当心脏在发育途中「跑偏」，从胎儿到成人的血流就要改道——这就是**先天性心脏病**。
