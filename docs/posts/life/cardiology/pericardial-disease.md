## 为什么从心包开始

心包（pericardium）是包在心脏外面的**纤维浆膜囊**，平日几乎不被人注意——但恰恰是这位「低调的邻居」，急性发炎时能伪装成心梗的胸痛，积液时能掐住心脏的脖子（压塞），慢性纤维化时能变回一个「铁壳」（缩窄）。心包疾病的核心主题是**空间与压力**：这层壳里的压力一旦失控，泵再有力也无处施为。

这一节要建立两条主线：**炎症**（急性心包炎）与**压力**（积液、压塞、缩窄）——前者靠药，后者靠放液或手术。它们是心血管内科「少见但致命、识别即救命」的典型。

给一个流行病学的坐标：急性心包炎是急诊胸痛的重要成因之一，约占急诊胸痛的 5%；它多数预后良好，但约 1/3 会复发、少数走向压塞或缩窄。「少见却致命」与「常见却自限」在这组疾病里同时存在，正是它值得单独成篇的原因。

理解心包病，也把「压力」这个主题推向了极致：本专题前面反复出现「血压」「肺动脉压」「充盈压」，而心包病把「压力」从生理量变成了**生死量**——心包腔压力每升高几毫米汞柱，都可能跨过一条致命的分界线。它与《高血压与肺动脉高压》一脉相承：**心血管病学，很大程度上就是「压力管理」的学问**。

## 1 心包的结构与功能

**心包（pericardium）**：由外层纤维心包与内层浆膜心包构成，两层之间是含约 15–50 mL 液体的心包腔。它的功能常被低估：

- **固定心脏**：把心脏悬吊在纵隔，防止过度移位。
- **防止过度扩张**：急性容量超负荷时，心包限制心室过度扩张，保护收缩效率（借助 Frank-Starling 的中段，见《心力衰竭》）。
- **物理屏障**：阻止邻近感染直接蔓延。

**核心概念**：心包的力学特征是**非线性的压力-容积关系**——正常情况下心包腔顺应性很好，但积液量一旦超过临界点，压力随容积**陡峭上升**。这张「先平后陡」的曲线，是理解压塞「量少即可致命」的关键。<span class="marginnote">正常心包腔能容纳 50–100 mL 而无压力上升；但快速积聚 150–200 mL 就可能压塞，而缓慢积聚 1000 mL 也可无症状。<strong>决定生死的是「蓄积速度×心包顺应性」，而不是积液总量本身</strong>——急性大出血式积液比慢性癌性积液凶险得多。</span>

心包的力学可量化：**心包腔压力-容积曲线呈「J 形」**——低容积段几乎水平（顺应性大），超过临界容积后近乎垂直（顺应性趋零）。这条曲线决定了两个临床规律：**缓慢积液可被代偿**（心包慢性拉伸、顺应性增加，1000 mL 也未必压塞）；**快速积液必然压塞**（心包来不及拉伸，200 mL 就致命）。<span class="marginnote">「同样 500 mL 积液，是恶魔还是旁观者？」——蓄积速度就是那个分界变量。急诊里一个胸外伤后 150 mL 的血性积液就能压塞，而癌性心包积液常常到 800 mL 以上才引起注意，机制全在这条 J 形曲线上。</span>

解剖上有两个「隐秘角落」值得知道：**横窦（transverse sinus）**在主动脉与肺动脉后方，是心外科阻断血管的入路；**斜窦（oblique sinus）**在左房后方。此外**心包积液常先积聚在重力低处**（后下方），大量时才出现「烧瓶心」（心影普遍增大）。理解解剖方位，才能解释超声上积液先出现在哪个切面。

## 2 急性心包炎：胸痛的另一种脸

**急性心包炎（acute pericarditis）**：心包脏壁两层发炎。病因谱很宽：**病毒性**（最常见）、**尿毒症**、**自身免疫**（狼疮、类风湿）、**肿瘤**（肺癌、乳腺癌转移）、**心梗后**（Dressler 综合征）与药物等。

典型表现是**尖锐的胸膜炎性胸痛**：随深呼吸、咳嗽、平卧加重，**前倾坐位缓解**；可伴发热。听诊可闻**心包摩擦音**（抓刮样，呼气相最清）。心电图的经典改变是**广泛导联 ST 段弓背向下抬高 + PR 段压低**——这与心梗的弓背向上抬高形成对比，是急诊鉴别的心电图考点。<span class="marginnote">「深呼吸痛、坐起缓解」是心包炎 vs 心梗的第一直觉差；ST 抬高的「弓背朝下 vs 朝上」是第二眼鉴别。两者都指向同一句话：<strong>急性胸痛要先问体位与呼吸，再看 ST 形态</strong>。</span>

治疗：主要是**非甾体抗炎药（NSAIDs）+ 秋水仙碱**（减少复发），激素仅用于顽固或自身免疫性病例。<span class="marginnote">秋水仙碱对急性心包炎的复发预防，是「老药新用」的经典：一个治痛风的药，成了心包炎的基石——药理学的适用边界常常比说明书更宽。</span>

**心电图的分期演变**是经典考点：急性期（数小时—数天）广泛 ST 段弓背向下抬高 + PR 段压低；随后 ST 回落、T 波逐渐倒置；最后 T 波恢复正常。与之对照，心梗的 ST 抬高有节段定位、ST-T 变化伴病理性 Q 波。**「心包炎的心电图会『搬家』，心梗的不会」**——动态复查两份心电图，比单看一张更可靠。

**复发与慢性化**：急性心包炎有约 15–30% 的复发率，反复复发可走向**复发性心包炎**（自身免疫参与、常对 NSAIDs 敏感）甚至缩窄。**秋水仙碱的最大价值恰在降低复发**——急性期开始联用并维持 3–6 个月，是减少复发的关键策略。<span class="marginnote">「为什么一个痛风的药成了心包炎的基石？」——秋水仙碱抑制中性粒细胞的趋化与黏附，恰好卡住心包炎症的核心环节。药理学的妙处常在于「机制重合」。</span>

**辨析｜易错点：** 心包摩擦音是「三心音」——收缩期、舒张期两个成分合成一个来回摩擦的抓刮音，坐位前倾、呼气末最清楚；它**多变、一过性**，可能随体位与呼吸改变，反复听才不漏。另一个易错点是：**心包炎早期也可能有 ST 段压低或无明显 ST 改变**（尤其心包积液已形成时），「没抬高 ≠ 不是心包炎」。

## 3 心包积液与心脏压塞：被自己的外壳扼住

当心包液快速增多、心包内压升至临界，就进入**心脏压塞（cardiac tamponade）**——心脏舒张充盈受阻，心输出量骤降。

压塞的临床表现是一个「三联征+两体征」的组合：**Beck 三联征**（低血压、颈静脉怒张、心音遥远）+ **奇脉（pulsus paradoxus）** + 心电图**电交替**（心脏在心包液中摆动致 QRS 振幅交替）。急诊超声上可见大量积液与**右房/右室舒张期塌陷**——这是「超声即诊断」的教科书场景。

压塞的抢救是**心包穿刺（pericardiocentesis）**放液，常立竿见影。**辨析｜易错点：** 压塞患者**禁用**利尿剂与扩血管药「降前负荷」——压塞的本质是心室「装不进血」，再降充盈压只会更糟；正确的方向是**立即放液**。这与《心力衰竭》中「用利尿剂减负荷」的方向相反，是「负荷管理」里少见的例外。

**压塞的血流动力学**：心包内压升高 → 舒张期心室充盈受阻 → 每搏量下降；机体靠加快心率（代偿性心动过速）维持心输出量，直到失代偿。心导管可见**左右心舒张压「均等化」**（右房、右室舒张末、肺动脉楔压、心包压趋向同一数值）——「四腔压力皆等」是压塞的导管学标志。<span class="marginnote">均等化是「空间被占满」的直接证据：心脏四周的压力都一样，说明没有一个腔能「多装一口血」。这也是为什么压塞时心音遥远、心影扩大而肺野清晰。</span>

**穿刺放液**的细节值得记住：通常在超声引导下**剑突下或心尖入路**，引流同时注意两件事——**首次放液不宜过急**（骤然减压可能诱发急性肺水肿与再扩张性心包积液），并留取积液送检（细胞学、病原学、结核培养）。**压塞解除后要找到「为什么积液」**：放液只是拆弹，病因（肿瘤、结核、感染、自身免疫）才是后续的主战场。

心包积液的病因谱与心包炎大致重叠：**肿瘤性**（肺癌、乳腺癌转移，恶性积液常大量、反复）、**结核性**（发展中国家主因，常伴缩窄）、**尿毒症性**、**感染性**（化脓性少见但凶险）、**心脏术后**与**甲减**。**「大量积液 + 全身状况差」要想到恶性**；「青年 + 慢性积液 + 低热」要想到结核——积液的颜色与成分只是线索，病理与培养才是定论。

**辨析｜易错点：** 术后患者可能出现**局限型（区域性）压塞**——血块把心包腔分成几个「小室」，仅局部受压。此时经典 Beck 三联征可不出现，超声所见积液也不多，但病人血压低、心率快、充盈压高。**「术后低血压 + 少量积液」也要想到区域性压塞**，这类情况单靠放液不够，往往需再次手术清除血块。

## 4 公式解析：奇脉的度量

压塞最有特征的体征是**奇脉（pulsus paradoxus）**——吸气时收缩压的异常下降。它的度量很简单：

$$
\Delta \text{SBP} = \text{SBP}_{\text{呼气}} - \text{SBP}_{\text{吸气}} > 10\ \mathrm{mmHg}
$$

三步拆解它为何出现在压塞：

- **第一步，看正常呼吸**：吸气使胸腔负压增大，右心回流增多、肺静脉血回流略减，收缩压本就轻度下降 3–10 mmHg——这是「生理性呼吸变异」。
- **第二步，放大机制**：压塞时心包内压已接近心室充盈压，吸气增加的右心回流只能「借走」室间隔，把空间从左侧挤走——**左室充盈进一步受限，每搏量骤降**，收缩压跌幅被放大到 > 10 mmHg。
- **第三步，临床测量**：用袖带血压计缓慢放气，记下吸气时听到第一音与呼气时听到第一音的收缩压差。**记住：奇脉不只见于压塞**——重度哮喘、COPD 的「肺过度充气」同样可致奇脉；它敏感但非特异，还需结合超声确认。

**一个测量细节**：袖带测奇脉时，应在**缓慢放气**中分别记录吸气相与呼气相首次闻及 Korotkoff 音的收缩压差；体位、呼吸幅度会显著影响读数，需标准化操作。数值 > 10 mmHg 才判为奇脉，3–10 mmHg 属生理变异。

## 5 缩窄性心包炎：变硬的外壳

长期慢性炎症（结核、放疗、手术后）使心包增厚、钙化，形成**缩窄性心包炎（constrictive pericarditis）**。增厚的心包像铁壳一样限制心脏舒张充盈，但收缩功能正常。特征：**Kussmaul 征**（吸气时颈静脉压不降反升）、**舒张早期叩击音**、心包钙化（胸片可见「蛋壳心」）。<span class="marginnote">Kussmaul 征的机制是「吸气时胸腔负压无法传进被铁壳禁锢的心脏」——右房压不随吸气下降，颈静脉反而因回流增多而更鼓。一个体征，就是整段呼吸循环力学的浓缩。</span>

**辨析｜易错点：** 缩窄性心包炎与**限制型心肌病（RCM，见《心肌病与心肌炎》）**临床表现几乎一样（都是舒张受限），鉴别是经典难题：缩窄是「外壳问题」（心包），RCM 是「内壁问题」（心肌）。超声可见心包增厚钙化、**呼气时室间隔反向移动**（缩窄特异）；必要时心导管测「双室舒张压相等」鉴别。**同样是「装不进血」，病因在壳还是在内壁，决定了内科保守还是外科剥脱。**

**病因与治疗**：发达国家以特发性、心脏术后为主；结核是发展中国家的主因，也是「可治愈缩窄」的代表——抗结核后炎症消退、钙化却常遗留。治疗是**心包剥脱术（pericardiectomy）**：把钙化的铁壳整块剥掉，舒张受限即可解除。**手术时机**：等得太久心肌会萎缩（收缩力受损），太早又可能在炎症活动期复发——「壳剥得掉，心肌萎缩却回不来」。

临床上还常遇到**渗出性缩窄性心包炎（effusive-constrictive）**：心包同时积液又增厚，穿刺放液后「看似解除压塞」，但舒张受限依旧——因为真正的限制来自已僵化的壁层心包而非积液。**「放了液还不缓解」要想到这层**：它提示单纯穿刺不够，仍需走向剥脱或系统治疗。

## 6 压塞与缩窄：一表分清两类「壳病」

压塞（急性）与缩窄（慢性）常被混淆，两者都是「心包作祟」，但一个要紧急放液、一个要择期剥脱：

| 特征 | 心脏压塞 | 缩窄性心包炎 |
| --- | --- | --- |
| 起病 | 急（积液） | 慢（纤维钙化） |
| 核心病理 | 心包内压↑、充盈受阻 | 心包僵硬、舒张受限 |
| 典型体征 | Beck 三联征、奇脉 | Kussmaul 征、叩击音 |
| 心电图 | 电交替 | 低电压、房颤常见 |
| 处理 | 心包穿刺（急） | 心包剥脱（择期） |
| 陷阱 | 忌利尿扩血管 | 需与 RCM 鉴别 |

## 7 数值速查：心包疾病关键数字

| 项目 | 数值 / 要点 |
| --- | --- |
| 正常心包积液量 | 约 15–50 mL |
| 快速积液的压塞量 | 150–200 mL |
| 缓慢积液可耐受量 | 可达 1000+ mL |
| 奇脉诊断界值 | ΔSBP > 10 mmHg |
| 心包炎复发率 | 15–30% |
| 秋水仙碱疗程 | 3–6 个月 |

## 8 小结

- 心包的**压力-容积曲线先平后陡**：决定压塞的是蓄积速度而非总量。
- 急性心包炎：**前倾缓解、摩擦音、广泛 ST 弓背向下抬高**；NSAIDs + 秋水仙碱。
- 心脏压塞：**Beck 三联征 + 奇脉**；处理是**立即穿刺放液**，忌利尿扩血管。
- 奇脉度量 $\Delta\text{SBP} > 10$ mmHg，见于压塞与重度肺过度充气。
- 缩窄性心包炎与 RCM 同为舒张受限，**「外壳 vs 内壁」**决定手术还是内科。
- 压塞导管学标志是**四腔舒张压均等化**；放液后要找病因（肿瘤/结核/感染）。
- 渗出性缩窄「放了液也不缓解」；术后要警惕**区域性压塞**（局部血块所致）。
- 心包炎治疗 NSAIDs + 秋水仙碱，激素仅限顽固/自身免疫；缩窄靠心包剥脱。

在下一节，也是本专题的收尾之篇，我们将面对「细菌进入心脏内膜」的凶险场景：发热、杂音、栓塞与瓣膜毁损——这就是**感染性心内膜炎**。
