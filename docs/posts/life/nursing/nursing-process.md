## 为什么从护理程序开始

理论回答了「护理为何有效」，但护士每天真正要面对的问题是「**下一个八小时班，我该按什么顺序做什么**」。**护理程序（nursing process）**就是答案：它是护理学的**标准工作方法**，把护理实践从「凭感觉做事」升级为「有输入、有处理、有反馈的闭环流程」。<span class="marginnote">护理程序与第三级《计算机组成原理》里的「取指—译码—执行—写回」CPU 流水线同构：都是循环结构，每一轮结束后的状态又成为下一轮的输入。</span>它由五步组成——评估、诊断、计划、实施、评价——前一步的输出是后一步的输入，而评价的结果又回到评估，形成一个**环形而非线形**的流程。

## 1 评估（Assessment）：收集与核实资料

**评估**是护理程序的第一步，也是后续所有步骤的数据基础。它回答「**这个患者现在处于什么状态**」。

**资料来源**：**主观资料**（患者自述：主诉、感受、既往史）与**客观资料**（护士观察、体格检查、实验室数据）。<span class="marginnote">「主观 vs 客观」是护理评估的第一课：患者说「我疼得厉害」（主观）与护士测得血压 180/110 mmHg（客观）性质完全不同，两者都要记录，但用途与可信度有别。</span>
**收集方法**：交谈、观察、体格检查、阅读病历；系统化方法常按 **Gordon 功能性健康型态**或身体系统逐项扫描，避免遗漏。
**核实与组织**：对矛盾数据（如患者说「不吸烟」但病历记载吸烟史）必须**重新核实**，再用某个框架（Maslow 需要层次或功能性健康型态）把零散资料组织成结构。

**重点：** 评估不是「一次性的入院登记」。它贯穿整个住院过程——**再评估（reassessment）**在每次交接班、每次病情变化时都应发生。护理评估的「持续刷新」特性，正是它与医疗「病史采集」的显著区别。

## 2 护理诊断（Nursing Diagnosis）：给问题命名

**护理诊断（nursing diagnosis）**：在评估资料的基础上，判断患者现存的或潜在的健康问题与反应，并用规范的名称表达。它回答「**问题是什么**」。

与医疗诊断的区别：医疗诊断给**疾病**命名（「肺炎」），护理诊断给**人对疾病的反应**命名（「清理呼吸道无效」）。
标准格式为 **PES 结构**：**P**（problem，问题）+ **E**（etiology，相关因素）+ **S**（signs/symptoms，诊断依据）。例：**清理呼吸道无效（P） 与 痰液黏稠、咳嗽无力 有关（E），依据 呼吸音粗、SpO₂ 下降（S）**。<span class="marginnote">PES 结构的力量在于强制护士写清「依据」——没有 S 的护理诊断只是猜测，这与中国古代刑法「无证据不定罪」同理。</span>
诊断分三类：**现存的**（此刻正在发生，如「皮肤完整性受损」）、**危险的/潜在的**（风险因素存在但尚未发生，如「有跌倒的危险」）、**健康的**（促进健康，如「母乳喂养有效」）。

**辨析｜易错点：** 新手最常犯的错误是把**护理诊断写成医疗诊断**或**写成护理措施**。例如「需要吸氧」是措施，「低效性呼吸型态」才是诊断；「肺炎」是医疗诊断，对应护理诊断应是「气体交换受损」或「清理呼吸道无效」。

## 3 计划（Planning）：设定目标与措施

**计划**把护理诊断转化为可执行、可衡量的行动方案。它包含三件套：

1. **排列优先级**：按 Maslow 需要层次与危险程度排序——先处理威胁生命的「气体交换受损」，再处理「焦虑」。<span class="marginnote">优先级排序的本质是资源分配，与操作系统里的「任务调度」是同一个问题：紧急且重要的先占 CPU。</span>
2. **设定目标**：要满足 **SMART** 原则——**S**（specific，具体）、**M**（measurable，可测量）、**A**（achievable，可实现）、**R**（relevant，相关）、**T**（time-bound，有时限）。例：「3 日内患者能自主咳出痰液，呼吸音清」。
3. **拟定措施**：措施分为**依赖性措施**（执行医嘱，如给药）、**独立性措施**（护士自主决策，如翻身拍背、健康教育）、**协作性措施**（与其他专业人员合作，如与营养师制定食谱）。<span class="marginnote">「独立性措施」是护理专业自主性的证据：不需要医嘱，护士也有权且应当执行的护理行动——拍背排痰、压疮预防、心理疏导都在此列。</span>

## 4 实施（Implementation）与评价（Evaluation）

**实施**是把计划变成行动。这一步要求护士同时具备**操作技能**（注射、导尿、吸氧）与**沟通技能**（向患者解释、指导、安抚），并在实施中持续观察反应、必要时**修订计划**——计划不是僵死的。

**评价**是闭环的关键：把实施后的结果与目标对照，判断目标是**完全达到、部分达到**还是**未达到**。评价结果产生三种去向：

目标达到 → 护理问题解决，可终止该项护理诊断；
目标部分/未达到 → **回到评估**，重新收集资料，找出是诊断不准、目标过高还是措施不当，然后修订计划。<span class="marginnote">这正是「环形流程」的关键一步：评价不是终点，而是下一轮护理程序的起点。它对应软件工程里的「迭代」与「复盘」。</span>

## 5 核心对照：护理程序与问题解决法

护理程序本质是科学问题解决法（problem-solving）在护理现场的实例化。把两者放在一起看，结构一目了然：

| 护理程序步骤 | 通用问题解决步骤 | 一句话任务 |
| --- | --- | --- |
| 评估 | 收集信息 | 现在发生了什么？ |
| 护理诊断 | 界定问题 | 真正的问题是什么？ |
| 计划 | 提出与选择方案 | 打算怎么做、做到什么程度？ |
| 实施 | 执行方案 | 开始做，边做边调整 |
| 评价 | 检验结果 | 达到了吗？没达到就重新来 |

**重点：** 护理程序的五个字母可以记作 **ADPIE**（Assessment、Diagnosis、Planning、Implementation、Evaluation）。它让护理「可记录、可追溯、可评价」——一份好的护理记录，就是一份可审计的**决策日志**，这一点与第二级《软件工程》要求的可追溯需求管理完全同构。

## 6 Gordon 功能性健康型态：评估的系统化框架

护士怎么保证评估「不遗漏」？答案是使用系统框架。Gordon 的**功能性健康型态**把人的健康拆成 11 个维度逐一扫描：

| 型态 | 关注内容 |
| --- | --- |
| 健康感知-健康管理 | 对健康的认识与保健行为 |
| 营养-代谢 | 饮食、体重、皮肤黏膜 |
| 排泄 | 排便、排尿 |
| 活动-运动 | 活动能力、日常活动 |
| 睡眠-休息 | 睡眠质量 |
| 认知-感知 | 意识、感觉、疼痛 |
| 自我感知-自我概念 | 自我价值感 |
| 角色-关系 | 家庭、社会角色 |
| 性-生殖 | 性健康 |
| 压力-应对 | 应对方式 |
| 价值-信念 | 信念与价值观 |

**重点：** 框架的价值在于**「强制性扫描」**——护士逐个型态过一遍，就不会漏掉「睡眠」或「自我概念」这类容易忽视的维度。这与软件测试里的「覆盖清单」同理：凭记忆容易漏，照单逐项打钩才可靠。

## 7 案例分析：一次完整的护理程序推演

把五步程序套在一个具体患者身上，比背定义有效得多。设患者张某，术后第 2 天，体温 38.5 ℃，主诉伤口疼痛、咳痰费力，SpO₂ 93%。

**评估**：主观资料——「伤口疼、痰咳不出来、心里发慌」；客观资料——T 38.5 ℃、SpO₂ 93%、呼吸 24 次/分、双肺可闻及湿啰音、伤口敷料清洁干燥。<span class="marginnote">注意评估的「主客观并录」：疼痛与心慌是主观的，体温与 SpO₂ 是客观的——两者都要记，但后续诊断依据主要靠客观指标。</span>
**护理诊断**：清理呼吸道无效（P）与痰液黏稠、疼痛致咳嗽无力有关（E），依据呼吸音粗、SpO₂ 下降、咳痰费力（S）；急性疼痛（P）与手术创伤有关（E），依据主诉与面部表情（S）。
**计划**：优先级上「清理呼吸道无效」排在前（威胁气体交换）。SMART 目标：**「24 小时内患者能自主有效咳痰，SpO₂ ≥ 95%」**。措施：半卧位、定时翻身拍背、雾化吸入、镇痛后鼓励咳痰（独立+协作措施）、遵医嘱抗生素（依赖措施）。
**实施与评价**：实施雾化与拍背后复测，SpO₂ 升至 96%，患者咳出痰液——目标部分达到；若 24 小时仍无效，则回到评估，检查是否有痰液过稠、镇痛不足等新因素，修订措施。

这个案例展示的是护理程序的「肌肉记忆」：**评估打底、诊断定性、计划定量、实施反馈、评价闭环**——熟练之后，这些步骤在护士脑中是一气呵成的。

## 9 小结

- 护理程序五步：**评估 → 护理诊断 → 计划 → 实施 → 评价**，首尾相接成环。
- 评估分**主观/客观**资料，必须持续**再评估**，并用框架组织。
- 护理诊断用 **PES 结构**命名「人对疾病的反应」，区别于医疗诊断的疾病命名。
- 计划要**排优先级 + SMART 目标 + 三类措施**（依赖/独立/协作）。
- 评价未达标时**回到评估**修订计划——闭环而非终点的思维是护理程序的核心。
