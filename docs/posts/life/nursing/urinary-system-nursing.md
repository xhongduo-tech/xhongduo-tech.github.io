## 为什么从泌尿系统开始

肾脏的功能远超「排尿」：它过滤血液、调节水电解质与酸碱平衡、分泌促红细胞生成素（EPO）与活性维生素 D、排泄代谢废物。当肾脏衰竭，整个机体的「内环境稳态」随之崩盘——毒素蓄积（尿毒症）、水肿、贫血、骨病、电解质紊乱。<span class="marginnote">把肾脏理解成「全自动净水厂 + 内分泌工厂」，就抓住了泌尿系统护理的双线任务：一是「管路维护」（泌尿系感染、结石、导尿），二是「功能代偿」（肾衰时的饮食、药物、透析管理）。后者是内科护理的高地。</span>本篇以肾小球肾炎、慢性肾脏病（CKD）与终末期透析为主线，讲清「保肾」与「代偿」两大护理策略。

## 1 泌尿系统的症状评估与常见问题

**泌尿系统护理评估的特殊性**在于「看不见的量」：症状很多藏在**尿液**里。

- **尿液评估**：**血尿**（镜下 vs 肉眼）、**蛋白尿**（泡沫尿——尿中蛋白使表面张力增大，泡沫细密持久）、**脓尿**（感染）、**尿量异常**（少尿 < 400 ml/24h、无尿 < 100 ml/24h、多尿 > 2500 ml/24h）。<span class="marginnote">「泡沫尿」是患者的自我预警：正常尿液泡沫大而快消，蛋白尿的泡沫细密如啤酒沫且持久不散。虽然泡沫尿不等于蛋白尿（需化验确认），但它是最早的「家庭哨兵」。</span>
- **水肿**：肾脏病水肿多**晨起眼睑水肿**（肾源性，疏松组织先肿）→ 全身性；与心源性水肿（低垂部位先肿，如下肢）形成对照。
- **高血压**：肾性高血压（肾脏缺血激活肾素-血管紧张素系统）——**肾病患者血压控制至关重要**。

**泌尿系感染（UTI）**是泌尿外科/内科最常见问题，尤其**女性**（尿道短、直、靠近肛门）。护理要点：**多饮水**（冲刷尿道）、注意会阴清洁（**由前向后**擦拭防肛周菌上行）、不憋尿、按疗程用抗生素。**「女性 UTI 的预防教育」是社区护理与内科护理的交汇点**——卫生习惯本身就是治疗。

## 2 肾小球肾炎的护理

**肾小球肾炎（glomerulonephritis）**：免疫介导的肾小球炎症。急性链球菌感染后肾炎（儿童/青年多见）与慢性肾炎是两类代表。

**急性肾炎的评估**：**血尿、蛋白尿、水肿、高血压**四联征；多继发于上呼吸道感染（链球菌）后 1–3 周；尿液呈**洗肉水样/浓茶色**（肉眼血尿）。

**护理措施**：

1. **休息**：急性期**绝对卧床**（减轻肾脏负荷），待水肿消退、血压正常后逐步恢复活动。
2. **饮食**：**限盐限水**（水肿与高血压）、**低蛋白 + 优质蛋白**（肾功能受损时）、记录出入量、每日测体重。
3. **血压与尿监测**：每日测血压、观察尿色尿量、记录 24 小时尿量。
4. **预防与随访**：防治链球菌感染（上呼吸道感染早治疗）、慢性肾炎需长期随访——**多数慢性肾炎缓慢进展为慢性肾衰竭**。<span class="marginnote">急性肾炎多数预后良好，但<strong>慢性肾炎</strong>像一场「静默的蚕食」——蛋白尿持续存在、肾功能逐年下降，最终走向终末期肾病。护理的长期任务是把「延缓进展」的每一个动作（降压、控蛋白尿、避肾毒性药）坚持到以年为单位。</span>

**重点：** 肾炎护理的底层逻辑是**「给肾减负 + 阻止免疫伤害持续化」**——卧床减负荷、限盐控水减容量、降压控蛋白减滤过压。这三件套在慢性肾病全病程都适用。

## 3 慢性肾脏病（CKD）与终末期肾病

**慢性肾脏病（chronic kidney disease, CKD）**：肾损伤或肾功能下降持续 ≥ 3 个月。按**eGFR（估算肾小球滤过率）**分 5 期，**CKD 5 期即终末期肾病（ESRD）**，需肾脏替代治疗。<span class="marginnote">eGFR 是衡量肾功能的核心指标，由血肌酐（Scr）、年龄、性别估算。eGFR < 60 ml/min/1.73m² 持续 3 个月即诊断 CKD——它把「肾功能」变成一个可分期、可追踪的数字，与第四级《机器学习》里「用一个综合指标做状态分级」的建模思路同构。</span>

**尿毒症的表现（毒素蓄积 + 内分泌紊乱）**：消化系统（恶心呕吐、口中尿味）、血液系统（**肾性贫血**——EPO 分泌不足）、骨骼（**肾性骨病**——活性维生素 D 不足、钙磷代谢紊乱）、神经（疲乏、失眠、周围神经病变）、心血管（高血压、心衰——尿毒症第一死因）。

**非透析期护理（延缓进展）**：

- **饮食治疗**（「五低二高」的精简版）：**低蛋白（优质蛋白）、低盐、低磷、低钾、低嘌呤 + 高热量、高维生素**。低磷是关键（磷蓄积→骨病与血管钙化）；**低钾**——肾功能差排钾障碍，高钾血症可致心脏骤停。<span class="marginnote">「高钾 → 心脏骤停」是 CKD 患者最致命的电解质风险：血钾 > 6.5 mmol/L 即可引起严重心律失常。患者常因「多吃几口香蕉/橘子」而进急诊——含钾高的水果（香蕉、橘子、枣、坚果）是 CKD 患者的「隐形地雷」。</span>
- **用药与监测**：降压、纠正贫血（注射 EPO）、降磷（磷结合剂餐中服）、定期复查血肌酐、eGFR、电解质、尿蛋白。

**透析护理（替代治疗）**：

- **血液透析（HD）**：每周 2–3 次，经**动静脉内瘘**（首选通路，需**保护患肢**——不测血压、不抽血、不提重物，教会患者每日触摸震颤）将血液引出体外透析后回输。<span class="marginnote">动静脉内瘘是透析患者的「生命线」：医生把动脉与静脉吻合，让静脉动脉化、增粗，便于反复穿刺。患者要学会「每日摸震颤」——震颤消失提示瘘管血栓形成，需紧急处理。这是「把自我监测交还给患者」的又一例证。</span>
- **腹膜透析（PD）**：利用腹膜作半透膜，经腹透管定期灌入腹透液交换——可居家进行，患者自主性更强，但需严格无菌操作防腹膜炎。
- **透析患者护理重点**：**体重管理**（两次透析间体重增长 < 干体重的 3%–5%）、**血管通路保护**、**饮食**（限盐限水限钾限磷）、**并发症观察**（失衡综合征、低血压、出血）。<span class="marginnote">「透析间期体重增长限制」是透析患者的水盐管理红线：体重长太多意味着体内水钠潴留多，透析时超滤过快会导致低血压、抽筋。这本质是「两次处理之间的缓冲余量」管理。</span>

**辨析｜易错点：** 慢性肾病患者最常见的用药误区是**「乱吃偏方/中草药伤肾」**与**「漏报非处方药」**。很多止痛药（NSAIDs）、抗生素、造影剂都有肾毒性——**「医生不知情的用药」本身就是肾病恶化的危险因素**。护士的健康教育必须包含「每次就医都要主动告知自己是肾病患者」。

## 4 核心对照：血液透析与腹膜透析

| 维度 | 血液透析（HD） | 腹膜透析（PD） |
| --- | --- | --- |
| 场所 | 透析中心 | 可居家 |
| 通路 | 动静脉内瘘 | 腹膜透析导管 |
| 操作者 | 专业护士 | 患者/家属（经培训） |
| 优势 | 清除效率高、医护监督 | 自主灵活、血流动力学平稳 |
| 风险 | 内瘘血栓、失衡综合征、低血压 | 腹膜炎、超滤不足 |
| 适合人群 | 依从性差、病情重者 | 有居家条件、愿自我管理者 |

## 5 小结

- 泌尿系统护理双线：**管路维护**（感染、结石、尿评估）+ **功能代偿**（肾衰、透析）。
- **肾小球肾炎**：急性期绝对卧床 + 限盐限水 + 低蛋白；长期任务是把「延缓进展」坚持到年。
- **CKD** 用 eGFR 分期；尿毒症是毒素蓄积 + 内分泌紊乱的全身综合征。
- 非透析期饮食「**低蛋白低磷低钾 + 优质蛋白**」；高钾血症是致命风险。
- 透析护理：**内瘘保护（每日摸震颤）**、透析间期体重控制 < 3%–5%、通路与饮食管理。
