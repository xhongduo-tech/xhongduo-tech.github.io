## 为什么从护理研究开始

护理学要成为独立学科，必须有自己的知识生产方式——**护理研究**。而研究产出的证据要真正改变临床，还需一座「从证据到行动」的桥梁——**循证护理（evidence-based nursing, EBN）**。<span class="marginnote">对熟悉第四级《机器学习》的读者，这一节会有强烈的既视感：循证护理 = 「用数据驱动决策」在临床的落地，样本量、效应量、偏倚控制这些词在这里全部复用。</span>本篇先把研究的基本方法讲清，再讲证据如何被分级、评价与转化，最后落到「一项传统的护理操作，如何被证据推翻或巩固」。

## 1 护理研究的类型与方法

**护理研究（nursing research）**：以系统的方法探究护理实践中的问题、形成或验证护理知识的活动。研究设计的两大谱系：

- **量性研究（quantitative）**：用数字测量现象、检验假设。常见设计包括：**随机对照试验（RCT，证据强度最高）**、**类实验研究**（无随机分组）、**队列研究**（随访比较暴露与结局）、**横断面调查**、**相关性研究**。<span class="marginnote">RCT 的「随机分组」之所以是金标准，在于它把已知与未知的混杂因素一并均匀分配——相当于把机器的随机种子固定后做对照实验。</span>
- **质性研究（qualitative）**：用文字理解现象的意义，适合回答「患者如何看待疾病」「何种体验构成照护」这类问题。常见方法有**现象学**（研究体验本质）、**扎根理论**（从资料中生成理论）、**民族志**（研究文化群体）。

**重点：** 量性回答「**是什么、差多少**」，质性回答「**为什么、体验如何**」。二者不是高低之分，而是**互补的两把尺子**——先用量性确认「循证压疮敷料能降低发生率」，再用质性了解「患者为什么不愿换这种敷料」。

## 2 研究的基本流程与伦理

一项护理研究的完整流程是一条标准流水线：**提出问题 → 文献综述 → 设计研究 → 收集资料 → 分析资料 → 撰写报告**。这条流程与第四级《机器学习》项目的「定义问题 → 基线 → 建模 → 评估」结构同构，但护理研究多一道极其重要的关卡——**研究伦理审查**。

涉及人的研究必须通过**伦理委员会（IRB）**审批，核心伦理要求：

- **知情同意**：参与者充分了解研究目的、风险、获益后自愿参加，可随时退出。
- **风险最小化**：研究方案给参与者带来的风险不得超过获益，且应低于临床常规。
- **隐私与保密**：数据去标识化、匿名化处理。
- **公平选择受试者**：不得用弱势群体（囚犯、认知障碍者、儿童）做「方便样本」。

**辨析｜易错点：** 「循证」与「研究」不是一回事。**研究是生产证据，循证是消费证据**。护士临床一线的常规任务不是自己做 RCT，而是**批判性地评价他人的研究**并判断能否用于自己的患者——「没做过研究的人照样能循证」，这句话是理解 EBN 的关键。

## 3 证据金字塔：从个人经验到系统评价

循证护理把证据按可信度排列成**金字塔**，自上而下可信度递增：

| 层级 | 证据类型 | 说明 |
| --- | --- | --- |
| 最高 | 系统评价 / Meta 分析 | 汇总多项 RCT，统计合并效应 |
| 高 | 随机对照试验（RCT） | 随机、对照、盲法 |
| 中 | 队列研究 / 类实验 | 观察性但设对照 |
| 中低 | 病例对照研究 | 回顾性比较 |
| 低 | 病例报告 / 专家意见 | 经验性、易受偏倚 |
| 最低 | 个人临床经验 / 习惯 | 未经检验的传统 |

**证据等级越高，越接近「平均真理」，但离「眼前这个患者」可能越远**——这是循证最大的陷阱：Meta 分析回答「平均患者有效」，而你的患者可能正处在分布边缘。<span class="marginnote">这正呼应第一级《概率论与数理统计》的置信区间直觉：证据给出的是群体的分布，不是个体的确定性。循证护理因此强调三要素整合：最佳证据 + 护士临床判断 + 患者意愿。</span>

## 4 循证护理的三要素与实施步骤

**循证护理（EBN）**：将**最佳研究证据、护士的临床专业判断、患者的意愿与价值观**三者结合，做出护理决策的过程。缺一不可：

- **最佳证据**：来自金字塔顶部的系统评价与 RCT。
- **临床判断**：证据要落到具体情境——患者的合并症、资源条件、护士的经验。
- **患者意愿**：同样的证据，不同患者的偏好可能相反（例如对副作用耐受的差异）。

实施循证护理的经典步骤是 **5A**：**Ask**（提出可回答的临床问题）→ **Acquire**（检索证据）→ **Appraise**（批判性评价证据质量）→ **Apply**（结合临床判断与患者意愿应用）→ **Assess**（评价实施效果）。<span class="marginnote">5A 与护理程序（ADPIE）其实是一对镜像：Ask 对应评估、Assess 对应评价——循证护理不是另起炉灶，而是给护理程序装上「证据引擎」。</span>

## 5 一个循证改变的经典案例：压疮预防

**压疮（压力性损伤）**的预防史是循证护理的缩影：

- **旧传统**：长期以来护士习惯「每 2 小时翻身 + 对受压部位**按摩**」，按摩一度被写进护理常规。
- **新证据**：系统评价发现，对已发红的皮肤进行按摩**不能预防压疮、反而可能加重局部组织损伤**（增加剪切力）；而「使用减压床垫 + 定时翻身 + 营养支持 + 皮肤评估」才有效。
- **循证行动**：各国指南据此**废止按摩作为预防措施**，改为「风险评估（Braden 量表）+ 减压 + 营养」。

这个案例展示了循证护理最锋利的一面：**一项做了几十年的「熟练操作」，可能因为没有证据而必须被放弃**。<span class="marginnote">Braden 量表由六个维度（感觉、潮湿、活动、移动、营养、摩擦剪切力）评分，总分越低风险越高——它本质是一个手写的「风险分类器」，与机器学习里的评分卡模型同源。</span>对护士而言，「我一直这么做」不再是继续做下去的理由。

## 6 小结

- 护理研究分**量性**（检验假设）与**质性**（理解意义）两脉，RCT 是量性证据的金标准。
- 涉及人的研究必须过**伦理审查**：知情同意、风险最小化、隐私保密、公平选择。
- **证据金字塔**从个人经验到系统评价逐级升高，等级越高越接近群体平均、越需结合个体判断。
- 循证护理 = **最佳证据 + 临床判断 + 患者意愿**，用 **5A 步骤**落地。
- 压疮按摩的废弃史证明：**没有证据支撑的「传统操作」，应当被质疑与替换**。
