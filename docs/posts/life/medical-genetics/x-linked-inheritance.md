## 为什么从 X 连锁遗传开始

常染色体遗传「男女平等」，但 X 染色体打破了这份平等：女性有两条 X，男性只有一条。这个「剂量差」衍生出完全不同的遗传语法——**男性半合子（hemizygous）**只需一个突变即发病，女性杂合子却常被第二条 X「救场」。血友病、Duchenne 肌营养不良、红绿色盲，这些人类最著名的遗传病，全都遵循 X 连锁规律。<span class="marginnote">X 连锁遗传是系谱分析中最有辨识度的模式，也是「遗传咨询里最常被追问性别概率」的情形。上一节已经介绍 X 失活（Lyon 化）的分子机制，本节把同一机制翻译成系谱语言。</span>

## 1 X 染色体的特殊传递方式

要读懂 X 连锁系谱，先钉死三条「传递铁律」：

**儿子从母亲得到 X，从父亲得到 Y**——父亲的 X 只传给女儿，不传给儿子；
**女儿从父亲得到一条 X**——因此**父亲会把 X 连锁基因传给他所有的女儿**；
- **男性只有一个 X**——他 X 上的等位基因「没有备份」，直接决定表型，称为**半合子（hemizygote）**。<span class="marginnote">从这三条推出最著名的系谱判据：X 连锁病<strong>绝无「父→子」传递</strong>（父亲不会把 X 传给儿子）。若系谱中见到父传子的病例，基本可以排除 X 连锁——这是鉴别 AD 与 X 连锁的最快捷方法。</span>

**重点：** X 连锁病与性别相关：男患者远多于女患者（XR）或女患者多于男患者（XD）。性别比例的异常是 X 连锁在人群统计上的指纹。

## 2 X 连锁隐性遗传（XR）

**X 连锁隐性遗传（X-linked recessive, XR）**：致病基因位于 X 染色体、以隐性方式起作用——**半合子男性发病，纯合子女性发病（罕见），杂合子女性多为携带者**。

### 系谱特征

**男性患者为主**，女患者罕见（仅当父母均为携带者或父患母携带时）；
**交叉遗传（criss-cross inheritance）**：致病 X 由母亲传给儿子（母→子），男性患者把 X 传给女儿（父→女）——系谱上常呈「隔代」现象，患者之间往往隔着一代携带者女性；
- **患者的兄弟、外甥、舅父可能患病**，父亲一般不患病；
- 女性携带者通常无症状，但因 **X 失活偏倚**可能出现轻度表现（如血友病携带者出血倾向、DMD 携带者肌酸激酶轻度升高）。<span class="marginnote">经典 XR 例子：<strong>血友病 A</strong>（F8 基因）、<strong>Duchenne 肌营养不良</strong>（DMD 基因）、红绿色盲（OPN1LW/OPN1MW）、G6PD 缺乏症。维多利亚女王家族的血友病是历史上最著名的 XR 系谱——致病基因经其女儿们传入欧洲多个王室。</span>

### 遗传风险（携带者母亲）

**携带者母亲（X^A X^a）× 正常父亲（X^A Y）**：子女中——

- 儿子：1/2 患病（X^a Y），1/2 正常；
- 女儿：1/2 携带者，1/2 正常（非携带）。

**患病父亲（X^a Y）× 正常母亲（X^A X^A）**：儿子全部正常（得母方 X^A），女儿全部为携带者（必得父方 X^a）。

**重点：** 「患病父亲」不会生患病的儿子，却会把致病 X 传给**所有**女儿——这是 XR 与 AD 最核心的鉴别点，也是咨询时「性别决定风险」的关键。

## 3 公式解析：X 连锁风险的「性染色体棋盘」

把 XR 的传递画成一张性染色体棋盘，以**携带者母亲 × 正常父亲**为例：

$$
\begin{aligned}
& \text{母亲} \ X^A X^a \quad \times \quad \text{父亲} \ X^A Y \\
& \text{配子：} X^A,\ X^a \qquad \qquad X^A,\ Y \\
& \text{子女：} X^A X^A,\ X^A Y,\ X^a X^A,\ X^a Y
\end{aligned}
$$

三步拆解：

- **第一步，写母方配子**：两条 X 各含一个等位基因，$X^A$ 与 $X^a$ 各 1/2；
- **第二步，写父方配子**：$X^A$ 与 $Y$ 各 1/2；
- **第三步，按性别分组**：四个格子中——男孩（得父方 Y）只有两种可能 $X^A Y$（正常）与 $X^a Y$（患病，1/2）；女孩（得父方 X^A）只有 $X^A X^A$（正常）与 $X^A X^a$（携带者，1/2）——**男孩患病风险 1/2、女孩均不患病（但半数携带）**。

**重点：** 棋盘读法的关键——**先分性别，再数格子**。X 连锁的「性别差异」恰恰来自父方：父亲给 X 则生女儿、给 Y 则生儿子，而致病基因只在 X 上，所以「儿子从母亲得病、女儿从父亲得 X^A 保底」——这是 XR 与 AD 最根本的差异。

## 4 X 连锁显性遗传（XD）

**X 连锁显性遗传（X-linked dominant, XD）**：致病基因位于 X 染色体、以显性方式起作用——**杂合子女性即可发病**，半合子男性发病且通常更重（或致死）。

**系谱特征**：<span class="marginnote">XD 系谱与 AD 的鉴别要点——<strong>① 患者男性所生女儿全部患病（父亲必把致病 X 给所有女儿）、儿子全部正常（儿子得父方 Y）</strong>；② 女性患者多于男性（女性有两份 X 机会多）；③ 男性患者病情常更重甚至致死（如某些 XD 病男性胎儿多流产）。「父传女、不传子」是 XD 与 AD 最快捷的鉴别。</span>

**女性患者**（杂合子）可发病但常较男性轻——因 X 失活使部分细胞表达正常等位基因；**男性患者**（半合子）只有一个致病等位基因、无失活补偿，病情重或致死。

**代表病**：抗维生素 D 佝偻病（PHEX）、色素失调症（IKBKG，男性多致死）、Rett 综合征（MECP2，X 连锁显性、几乎只见于女性，因男性半合子多数致死）。<span class="marginnote">Rett 综合征是 XD「男性更重」的极致例证：MECP2 突变男性常严重或致死，女性杂合子因 X 失活偏倚而存活并表现典型发育倒退——「女性发病、男性致死」是 X 连锁显性病特有的系谱指纹。</span>

**重点：** XD 把「显性」与「性别」两个维度叠加——**发病与否看显性、轻重看性别**。这使 XD 在系谱上既像 AD（连续传递、男女均有患者）又像 XR（父传女不传子、男性更重）——「男性患者不传子、却传所有女儿」是 XD 的破绽。

## 5 X 失活与女性携带者的表型

X 失活（Lyon 化）使女性成为 X 基因的「嵌合体」，这带来两个重要的临床现象：

**X 失活偏倚（skewed X-inactivation）**：正常情况下失活随机（约 50:50），但某些女性因「选择性」——携带致病等位基因的细胞被选择清除（如携带者细胞增殖劣势）或优势——而呈偏倚失活。**偏倚可使携带者女性表现为无症状或症状明显**：<span class="marginnote">X 失活偏倚的临床意义：血友病 A 携带者可有出血倾向、DMD 携带者肌酸激酶升高或轻度肌无力、肾上腺脑白质营养不良（ALD）携带者可出现痉挛性截瘫——「携带者不是绝对无症状」是 X 连锁咨询的重要提醒。反之，有利偏倚（正常 X 为主）可使携带者几乎无症状。</span>

**多因子计数**：女性有两条 X，男性只有一条——X 连锁基因的剂量差异由 X 失活补偿，但**失活不随机分配到全身**，女性呈「马赛克」表达。这在皮肤（如色素失调症的女性条带状皮肤）、血细胞（载体检测）中可观察。

**重点：** X 失活让「携带者」一词变得模糊——**同一基因型（X^A X^a）的女性，因失活偏倚不同而表型可从无症状到明显受累**。咨询「女性携带者是否会发病」时，答案不是简单的「否」，而是「取决于失活偏倚与基因功能」。

## 6 小结

- **X 连锁的三条铁律**：儿子从母得 X、父亲 X 只传女儿、男性半合子无备份——**「父传子」是鉴别 X 连锁与 AD 的最快判据**。
- **XR**：男性患病为主、交叉遗传（母→子、父→女）、携带者母亲儿子风险 1/2、患病父亲不传子但传所有女儿。
- **XD**：女性也可发病（杂合子）、患者男性所有女儿患病、儿子正常；男性病情更重或致死（如 Rett、色素失调症）。
- 风险计算用**性染色体棋盘**：先分性别、再数格子——「男孩患病 1/2、女孩不患病但半数携带」是携带者母亲的标准答案。
- **X 失活偏倚**使携带者女性可从无症状到明显受累——「携带者不一定无症状」，咨询须个体化。
- 代表病：**血友病 A、DMD、红绿色盲、G6PD**（XR）；**抗维生素 D 佝偻病、Rett**（XD）。

### 复习要点（三分钟速览）

- **鉴别三问**：① 有无「父→子」传递？（有则排除 X 连锁）；② 男性患者是否远多于女性？（是则倾向 XR）；③ 患者父亲的女儿是否全部受累？（是则倾向 XD）；
- **交叉遗传的系谱指纹**：患病外祖父 → 携带者女儿 → 患病外孙（母系传递、隔代出现）——「舅舅和外甥可能同病」是 XR 的经典场景；
- **维多利亚女王家族**：血友病 A 经其女儿传入欧洲多个王室——历史上最著名的 XR 系谱，也是「遗传学 × 历史」的交汇；
- **携带者母亲的风险数字**：儿子 1/2 患病、1/2 正常；女儿 1/2 携带者、1/2 正常——「男孩患病、女孩携带」是咨询的核心话术；
- **X 失活偏倚的临床后果**：血友病携带者出血倾向、DMD 携带者肌酸激酶升高、ALD 携带者痉挛性截瘫——「携带者不一定无症状」；
- **与 AD 的鉴别**：XD 的「父传所有女儿」与「男患者更重」是区别于 AD 的两个破绽——「同样连续传递，但性别比例异常」；
- **X 连锁检测的提示**：家系中「舅舅与外甥同病、父亲正常」时优先考虑 X 连锁——「母系男性患者链」是 X 连锁的系谱指纹；
- **X 失活的治疗启示**：部分 X 连锁病（如 ALD）的造血干细胞移植与基因治疗，正是利用「有正常 X 的细胞被选择扩增」的失活优势——「失活偏倚也是治疗杠杆」；
- **X 连锁携带者筛查**：有家族史女性的携带者检测（症状前 + 生育决策）——「先咨询后检测」，阳性者生育风险可量化；
- **男性半合子的「无备份」提醒**：X 连锁病男性一旦携带致病等位基因即发病——「男性是 X 连锁病的『直接暴露』者」；
- **X 失活偏倚的检测方法**：血细胞雄激素受体基因（AR）甲基化分析可评估失活偏倚程度——「偏倚比例」是可测量的临床信息；
- **X 连锁病的治疗窗口**：血友病 A 的凝血因子替代、DMD 的外显子跳跃疗法、ALD 的移植/基因治疗——「X 连锁病是遗传治疗的重要靶标」；
- **X 染色体上的基因密度**：X 含约 1,100 个基因、含许多剂量敏感基因——「X 失活保护了女性，却让男性暴露于单拷贝风险」；
- **X 连锁咨询的「性别双轨」**：同一家族中，男性算「患病风险」、女性算「携带者风险 + 失活偏倚」——「同一张系谱，两种算法」。
