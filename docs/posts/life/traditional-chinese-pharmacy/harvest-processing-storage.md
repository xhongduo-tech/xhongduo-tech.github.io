## 为什么从采收与贮藏开始

道地药材讲「长在哪」，采收与贮藏讲「何时采、怎么制、怎么存」。前者决定药材的**先天禀赋**，后者决定药材的**后天成色**。同一株人参，秋末地上枯萎时采，皂苷含量最高；早采则浆气不足。<span class="marginnote">《千金翼方》早就总结：「夫药采取，不知时节……虽依药名，而实非药。」现代研究证实：金银花在花蕾期绿原酸含量最高，盛开后骤降——采收时机就是化学成分的「时间窗口」。</span>从本课起，中药学开始与植物生理学、分析化学正面相交：采收看的是次生代谢的积累规律，贮藏防的是成分的氧化分解与霉变虫蛀。

## 1 采收时机：跟着有效成分走

不同药用部位的有效成分随生长周期波动，采收原则因此分部位而定：

- **根及根茎类**：以**秋冬地上部分枯萎后或早春萌发前**采收为佳，此时养分回收入根，有效成分含量高。例：人参、天麻、地黄。
- **全草类**：多在**枝叶茂盛、花未全开**时采收。例：薄荷（挥发油含量高峰期）、益母草。<span class="marginnote">少数例外：茵陈「正月茵陈二月蒿」，幼嫩期才有效，采收早了或晚了都不对——这就是「春采茵陈」谚语的由来。</span>
- **花类**：多在**含苞待放或初开**时采收。例：金银花采花蕾，辛夷采花蕾，菊花初开采。
- **果实种子类**：多在**果实近成熟或成熟**时采收。例：枸杞成熟红透时采，五味子深红时采。
- **皮类**：多在**春末夏初**（植物生长旺盛、皮易剥离、有效成分高）采剥。例：黄柏、杜仲。
- **叶类**：多在**花前期或盛花期**采，此时叶片老嫩适中。例：枇杷叶、艾叶。

**核心逻辑**：采收时间 = 该部位**有效成分（或经验药效）含量峰值**的对应时间。<span class="marginnote">这条「有效成分导向」原则，是古代经验与现代植化的接合点：古代靠代代相传的节气口诀，现代用 HPLC 测含量-时间曲线，结论常常高度一致。</span>

## 2 产地加工（初加工）

采下的鲜药含大量水分，须及时加工，否则霉烂变质。**产地加工**：药材离开产地前就地进行的初步处理，目的是**纯净药材、便于干燥、减毒增效、利于贮藏**。

主要工序：

| 工序 | 目的 | 典型药材 |
| --- | --- | --- |
| 清洗 | 去泥沙杂质 | 多数根茎类 |
| 干燥 | 去水分、防霉变 | 所有药材 |
| 去皮 | 便于干燥、纯净外观 | 桔梗、白芍（趁鲜去皮） |
| 切片 | 利于干燥与调剂 | 山药、茯苓（趁鲜切） |
| 蒸、烫（杀酶保苷） | 破坏酶活、固定成分 | 天麻（蒸）、白芍（煮） |
| 发汗 | 内部水分外渗，促成分转化、增色 | 厚朴、杜仲、茯苓 |
| 硫熏 | 增白、防霉、杀虫（现已受限） | 山药、白芍（古代） |

**辨析｜易错点：** 「发汗」不是出汗，而是**将鲜药材堆置，利用自身水分与热量使内部成分转化、药材变软变色**的工艺——厚朴经发汗后酚类成分含量提高，气味更浓。而「硫熏」虽能增白防虫，但二氧化硫残留超标危害健康，**现行药典对残留量严格限量**，多数药材已改用无硫干燥工艺。<span class="marginnote">含苷类药材（如天麻、黄芩）采后须立即蒸或烫，目的在「杀酶保苷」：酶能将苷分解为苷元，不及时灭活则有效成分在干燥过程中即被破坏。</span>

## 3 贮藏：药材的六大变质方式

干燥后的药材仍要在库房中与时间赛跑。变质主要有六种：

- **虫蛀**：淀粉、糖分、蛋白质丰富的药材最易生虫（党参、黄芪）。
- **霉变**：含水超标时霉菌滋生，产生毒素（黄曲霉毒素），不可再入药。
- **变色**：花类、叶类见光氧化褪色或变褐。
- **走油（泛油）**：含油脂、挥发油、糖类的药材受热析出表面，如杏仁、柏子仁、当归。
- **潮解**：矿物盐类吸湿溶化，如芒硝。
- **风化与气味散失**：含挥发油药材久存香气变淡，如薄荷、藿香。

## 4 养护方法（核心对比表）

本节无公式，以**核心对比表**对比主流养护技术：

| 养护方法 | 原理 | 适用对象 |
| --- | --- | --- |
| 干燥养护 | 控制水分（库房湿度 ≤ 70%） | 一切药材 |
| 密封养护 | 隔绝空气与水分 | 贵重药材（人参、鹿茸） |
| 冷藏养护 | 低温抑制虫霉与氧化（0–10℃） | 易走油、易霉变药材 |
| 气调养护 | 充氮或降氧，杀灭虫霉 | 大批量仓库药材 |
| 对抗同贮 | 利用芳香药材驱虫（如花椒与肉豆蔻同贮） | 中小量药材 |

**防霉防虫的根本仍是水分**：控制入库含水量（一般根茎类 9%–13%）、保持库房通风低温干燥，比任何事后补救都有效。<span class="marginnote">「对抗同贮」是最有智慧的土法——牡丹皮与泽泻同贮，泽泻不生虫，牡丹皮不变色，彼此互护。现代气调养护则是把这种经验升级为工业化可控的环境工程。</span>

## 5 一个完整例子：从采到存走一遍「附子」

把全流程串成一条链，看剧毒药附子的一生：

1. **采收**：夏至至立秋间，挖取乌头母根旁的子根（附子），此时乌头碱类生物碱积累完成。
2. **产地初加工**：洗泥后盐渍成「盐附子」，或水浸漂去毒性再蒸煮成「白附片/黑顺片」。
3. **炮制减毒**：水漂+蒸煮使剧毒的乌头碱**水解为毒性大降的乌头次碱、乌头原碱**，这是《中药炮制学》的核心战场。<span class="marginnote">乌头碱水解是中药炮制化学的经典方程：双酯型乌头碱（剧毒）→ 水解去掉一个酯基 → 单酯型乌头次碱（毒性为 1/200）→ 再水解 → 醇胺型乌头原碱（毒性近失）。每一级水解就是一级减毒。</span>
4. **贮藏**：干燥品密封防潮，避光防变色，控制水分防霉。

**辨析｜易错点：** 附子的毒性与功效同源——**温阳之力与剧毒都来自乌头碱类生物碱**，「减毒」不能「减效」到零。炮制追求的是把双酯型毒性降到安全阈值，同时保留足够的温阳作用。这提醒我们：**中药的「毒性」与「药效」往往共享同一物质基础**，这也是《中药毒理与安全性》一篇将反复出现的主题。

## 6 采收加工的标准与现代化

经验要变成标准，标准要能落地——采收加工正在从「代代相传」走向「规程化、机械化、数据化」。

### 药典与 GAP 的规定

- **药典**：多数药材注明「采收加工」项，规定采收季节与初加工方式，作为质量标准的起点。
- **GAP**（中药材生产质量管理规范）：把采收时机、采收工具、产地加工、干燥温度、包装贮藏写成可执行的规程。<span class="marginnote">GAP 的核心理念是「把经验固化为规程」：何时采、采多少、怎么晾、怎么存，每条都能量化——这正是《中药质量与药典标准》一篇里「过程控制」思想在源头端的落地。</span>

### 三类药材的采收标准示例

| 药材 | 采收标准 | 加工标准 |
| --- | --- | --- |
| 金银花 | 花蕾期、绿原酸含量最高时采 | 立即摊晾、低温烘干 |
| 丹参 | 秋季茎叶枯萎后采根 | 洗净切片、阴干 |
| 薄荷 | 开花初期、挥发油高峰采全草 | 阴干、忌暴晒失香 |

### 机械化的双刃

- **利**：采收机、烘干机、切片机提高效率与一致性，减少人工损耗。
- **弊**：过度机械化若参数不当，反而损伤性状与成分——烘干温度过高会使含挥发油药材失香。

**辨析｜易错点：** 「机械化」不等于「现代化」：现代化是把**经验参数化**（温度、湿度、时长有据可依），而盲目机械加工可能破坏道地工艺（如硫熏、暴晒的旧弊）。先固化参数，再上设备，顺序不能反。

## 7 小结

- 采收时机**分部位而定**，本质是「有效成分含量峰值」导向：根茎秋冬采、全草花前期、花类含苞采、果实在成熟。
- 产地加工承担**纯净、干燥、减毒、增效**四责；含苷类药材须**杀酶保苷**（蒸/烫）。
- 六大变质：虫蛀、霉变、变色、走油、潮解、气味散失，根子在**水分与温度**。
- 养护四法：干燥、密封、冷藏、气调，对抗同贮是经典土法。
- 附子案例说明：**减毒与保效同源**，炮制是安全与疗效的平衡术。
