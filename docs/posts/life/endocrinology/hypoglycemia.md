## 为什么从低血糖症开始

上一节讲血糖太高，这一节讲血糖太低——而低血糖是内分泌学里**最危险的急症之一**：大脑没有能量储备，严重低血糖可以几分钟内造成不可逆脑损伤。它也是糖尿病治疗最常遇到的并发症，与「用胰岛素治病」如影随形。<span class="marginnote">对治疗中的糖尿病患者，低血糖比高血糖更致命：一次严重低血糖的死亡率与心血管事件风险，可能超过数年温和高血糖的代价。这就是为什么「平稳控糖」而非「拼命压糖」才是现代糖尿病管理的核心。</span>

伍德沃德的话提醒我们：**绝大多数低血糖来自最常见的原因（降糖药），而不是罕见的胰岛素瘤**。但恰恰是那个罕见原因，藏着内分泌诊断最漂亮的逻辑。

## 1 血糖的保障机制：人体的「备用电网」

正常人的血糖不会随便掉，因为身体有一整套反调节（counterregulation）机制，按优先级出牌：

1. **胰岛素下降**（第一道，也是核心）：血糖一降，β 细胞立刻停喷胰岛素——光这一条就足以撑住大多数情况。
2. **胰高血糖素升高**（第二道）：几分钟内启动，肝糖原分解 → 释放葡萄糖。
3. **肾上腺素升高**（第三道）：几秒—分钟级，既直接升糖，又制造出汗、心慌等「报警症状」。
4. **皮质醇与生长激素**（第四道）：数小时级，抗胰岛素、促进糖异生。

**重点：大脑是纯葡萄糖消费者**，自己不能造糖，也几乎不储糖。它依赖血液持续供糖，一旦血糖跌破阈值，先出现交感报警（出汗、心慌、手抖、饥饿），再进展为**神经低血糖症状（neuroglycopenia）**——思维迟钝、胡言乱语、抽搐、昏迷。<span class="marginnote">这套「先报警、后失能」的顺序非常像系统里的分级告警：交感症状是 warning，神经低血糖是 critical。反复低血糖会让大脑「报警阈值」下移（低血糖感知缺失），患者直接进入神经低血糖——这解释了为何严格控制血糖者反而可能「无症状低血糖」。</span>

## 2 低血糖的定义：从切点到 Whipple 三联征

**分级**（ADA 共识）：
**1 级（警示）**：血糖 < 3.9 mmol/L（70 mg/dL），无论有无症状。
- **2 级（临床重要）**：血糖 < 3.0 mmol/L（54 mg/dL），需要干预。
- **3 级（严重）**：血糖低到需要他人帮助、患者无法自救，可伴意识障碍。

**诊断的金标准是 Whipple 三联征**，三条缺一不可：
1. 有符合低血糖的症状；
2. 发作时血糖确实低；
3. 补糖后症状迅速缓解。

**辨析｜易错点：** 只有「症状 + 血糖低」但补糖后症状不缓解，不算低血糖；只有血糖低但无症状，也不算「症状性低血糖」。Whipple 三联征逼着临床同时验证**症状、化验、干预**三个环节，专治「凭感觉说自己低血糖」的误判——这也是为什么很多「反应性低血糖」的自我诊断经不住检验。

## 3 低血糖的原因：先想常见，再想罕见

按发生情境分两大类：

**空腹低血糖**（餐后 5 小时以上）：提示内源性「造糖过多」或「拆仓能力不足」——
- **药物**：胰岛素、磺脲类（促分泌剂）——所有低血糖里最常见，尤其肾功能不全者。
- **胰岛素瘤**：β 细胞肿瘤自主分泌胰岛素（详见下节）。
- **肝衰竭、肾功能不全、心力衰竭**：糖原储备或糖异生能力不足。
- **肾上腺皮质功能不全**：缺皮质醇，糖异生缺「加速器」。
- **酒精**：抑制肝糖异生，且掩盖交感症状。
- **非胰岛细胞肿瘤**：分泌 IGF-2 前体，引起「假性胰岛素」效应。

**餐后（反应性）低血糖**（餐后 2–4 小时）：血糖先冲高、胰岛素后手慢脚大地喷发，把血糖拖到谷底——见于糖尿病前期（早相胰岛素分泌延迟）、倾倒综合征（胃切除后快速排空）、特发性。<span class="marginnote">反应性低血糖的病理是一段「过冲—回弹」动力学：先超调再下坠，像控制理论里没有阻尼的阶跃响应。治疗靠低碳水、少食多餐、加纤维，而不是确诊了什么了不起的肿瘤。</span>

关于酒精性低血糖补一句：酒精抑制肝糖异生，且**糖原储备耗尽后才发作**（多在饮酒后数小时至次晨），此时补糖 + 输注含糖液体并观察 24 小时，同时警惕酒精中毒本身与低体温的掩盖——「酒后的低血糖」常常没有交感报警，直接进入神经低血糖，是院外猝死的隐蔽原因之一。

**重点：诊断的次序就是发生率的次序**——先排药源性，再查内源性高胰岛素，最后才考虑那些罕见病。

## 4 胰岛素瘤：一个「自主分泌」的罕见标本

**胰岛素瘤（insulinoma）**：胰岛 β 细胞肿瘤，多为良性（约 90%）、单发、常见于 40–60 岁，约 10% 与 MEN1 相关（见第十二篇）。它的特征是**空腹低血糖 + 内源性高胰岛素**。

**确诊的黄金试验：72 小时禁食试验**。让患者禁食直到低血糖发作，在发作时抽血查四项：
血糖低（< 3.0 mmol/L 或 55 mg/dL）；
- **胰岛素**高（> 3 μU/mL，或随 C 肽同高）；
- **C 肽**高（提示胰岛素是自身 β 细胞造的，不是外源注射）；
- **胰岛素原**高（肿瘤分泌不成熟的胰岛素原比例更高）。

这套「低血糖 + 胰岛素 + C 肽 + 胰岛素原」四联，等于给诊断装了一台**溯源器**：它问的不是「血糖多少」，而是「多余的降糖力量从哪来」——胰岛 B 细胞自己、还是注射器。<span class="marginnote">可以把这四项想成一个「归属判断」：血糖把总账记在「体内降糖力量太大」，胰岛素是「降糖力量的规模」，C 肽是「是否自家生产」的防伪标记，胰岛素原是「是否生产畸形」的质量标记。四条信息合起来，答案几乎没有歧义。</span>

**鉴别一张表说清**：

| 情形 | 血糖 | 胰岛素 | C 肽 | 其他 |
| --- | --- | --- | --- | --- |
| 胰岛素瘤 | 低 | 高 | 高 | 胰岛素原高，磺脲筛查阴性 |
| 磺脲类过量 | 低 | 高 | 高 | **血中检出磺脲** |
| 外源胰岛素过量 | 低 | 高 | **低** | 胰岛素抗体可升高 |
| 非胰岛素介导（肝衰等） | 低 | **低** | 低 | 无高胰岛素证据 |

**治疗**：定位（超声内镜、CT/MRI）后手术剜除，多数可治愈；不能手术者用**二氮嗪**（抑制胰岛素分泌）或奥曲肽，并少食多餐防发作。<span class="marginnote">注意到没有：胰岛素瘤的「自主分泌」与垂体 ACTH 瘤、肾上腺醛固酮瘤完全同构——都是「工厂不听上游指挥、自己开足马力」。本专题反复出现的这种「自主性（autonomy）」概念，是贯穿全部内分泌肿瘤的核心。</span>

## 5 低血糖的处理：15-15 法则与胰高血糖素

**意识清醒的患者**：采用 **15-15 法则**——摄入 15 克快糖（葡萄糖片 3–4 片、含糖饮料 150 mL、蜂蜜一勺），15 分钟后复测血糖；仍 < 3.9 mmol/L 则再喂一轮，随后补充慢糖（面包、主食）防再降。

**意识不清或无法吞咽**：
院内：**静脉 50% 葡萄糖** 25–50 mL，随后输注含糖液体维持。
- 院外 / 无法输液：**胰高血糖素肌注**（1 mg），它把肝糖原放出为血糖「续命」。
- 若低血糖由**磺脲类**引起：即使补糖恢复，也需持续观察数小时到一天，因为药物还在——这是最常见的「复发性低血糖」陷阱。<span class="marginnote">「补了糖就回家」对磺脲过量是危险的：磺脲的促分泌作用持续存在，血糖可能几小时后再次崩盘。这也对应了第一节「药物半衰期 ≠ 药效半衰期」的临床化。</span>

**预防**：教育患者识别早期症状、随身携带糖、规律进餐；调整胰岛素方案（减量、换剂型、胰岛素泵）；对反复严重低血糖者，把血糖控制目标放宽。

糖尿病患者还会陷入一个特殊困境：**低血糖相关的自主神经功能衰竭（HAAF）**——反复低血糖让交感报警阈值下移，患者越来越「感觉不到低血糖」，反而更容易陷入神经低血糖昏迷。这是「严格控糖导致严重低血糖」恶性循环的机制解释，也解释了为何对反复严重低血糖者要**放宽目标 + 纠正诱因 + 教育识别**三者并施——这几乎是把第一篇的「负反馈设定点」概念在临床上做了一次反向操作。

## 6 核心要点：低血糖诊疗的「先常见后罕见」

- **最常见原因**：降糖药（胰岛素、磺脲）——先问药、先排除药。
- **金标准**：**Whipple 三联征**（症状 + 血糖低 + 补糖缓解）三缺一不可。
- **空腹 vs 餐后**：空腹查内生机制，餐后多属反应性/倾倒。
- **胰岛素瘤四联**：低血糖 + 高胰岛素 + 高 C 肽 + 高胰岛素原；磺脲筛查阴性；定位后手术。
- **处理**：清醒者 15-15 法则，昏迷者静注葡萄糖或肌注胰高血糖素；磺脲过量需持续观察。
- 反复低血糖会**下移报警阈值**，导致无症状低血糖——危险的「静默失守」。

## 7 小结

- 血糖保障靠**四道反调节防线**：胰岛素降→胰高血糖素→肾上腺素→皮质醇/GH，大脑无储备、最脆弱。
- 低血糖分级：**1 级 < 3.9、2 级 < 3.0、3 级需他人帮助**。
- 诊断走 **Whipple 三联征**；原因排查次序 = 发生率次序：**药源性 → 内源性高胰岛素 → 罕见病**。
- **胰岛素瘤**靠 72 小时禁食 + 胰岛素 / C 肽 / 胰岛素原四联确诊，手术可治愈。
- 处理靠 15-15 法则与静脉葡萄糖 / 胰高血糖素；磺脲过量要防复发。
- 「自主分泌」是内分泌肿瘤的共性——它将在之后的 MEN 综合征篇章再次出现。
