## 为什么从糖尿病开始

糖尿病是当代内分泌学的「主战场」：全球患者已超过 5 亿，且仍在增长。它是前面所有知识的交汇点——负反馈、受体信号、游离激素、并发症里的血管与神经，全在一张血糖表里体现。<span class="marginnote">对学编程的读者还有一个特殊角度：血糖稳态是人类身体里「可观测、可干预」最彻底的生理系统——连续血糖监测（CGM）每分钟都在采样，胰岛素泵在闭环给药。<strong>人工胰腺，本质上是一台穿戴式 PID 控制器</strong>，这正是第四级《控制系统》与生理学的交界。</span>

班廷的话说得残酷而准确：胰岛素是治疗，不是治愈。理解这句话，需要先理解血糖稳态的两环设计。

## 1 胰岛与血糖稳态：一对天生的对头

胰岛是胰腺里的「小岛」，其中 α 细胞分泌**胰高血糖素**（升糖），β 细胞分泌**胰岛素**（降糖），δ 细胞分泌生长抑素。

**胰岛素的作用三步**：① 肝脏——促进糖原合成、抑制糖异生；② 肌肉——通过 **GLUT4 转运体**摄取葡萄糖、合成糖原与蛋白质；③ 脂肪——促进脂肪合成、抑制脂肪分解。一句话：**胰岛素是「把能量存起来」的激素**，也是体内唯一的降糖激素。

**胰高血糖素**与它针锋相对：促进肝糖原分解与糖异生，把葡萄糖从仓库里放出来。

**分泌调控**：β 细胞天生是「血糖计」——葡萄糖经 GLUT2 进入 β 细胞被代谢，关闭 K-ATP 通道 → 去极化 → 钙内流 → 胰岛素胞吐。**肠道激素（incretin）GLP-1、GIP 在进餐后放大胰岛素分泌**，且 GLP-1 还能抑制胰高血糖素、延缓胃排空、抑制食欲——这就是今天的明星降糖药 GLP-1 受体激动剂（司美格鲁肽等）的生理学起源。

![血糖稳态：胰岛素与胰高血糖素的双环调节](/images/endocrinology/diabetes-metabolic-syndrome-1.svg)

**重点：高血糖时两环同开，低血糖时两环同开，正常时两环被设定点钳制**——任何一环失灵，稳态就偏斜。

## 2 糖尿病分型：两大主型 + 特殊类型

**1 型糖尿病（T1DM）**：自身免疫破坏 β 细胞（抗体 GAD、IA-2、ZnT8；HLA 易感），**胰岛素绝对缺乏**。多在青少年起病，体型偏瘦，易发**糖尿病酮症酸中毒（DKA）**。治疗：终身胰岛素。<span class="marginnote">T1DM 是「免疫系统把自家工厂误判为入侵者」的经典自身免疫病——前三篇学的「识别与攻击」机制在此反转成病因。病毒感染、遗传共同参与扳机。</span>

**2 型糖尿病（T2DM）**：**胰岛素抵抗 + 相对分泌不足**。与肥胖、久坐、遗传强相关，成年居多但年轻化严重。早期胰岛素往往并不低——问题是「信号失灵」（受体后通路受损），β 细胞最终代偿衰竭。治疗：生活方式 → 口服药 → 胰高血糖素样肽 → 胰岛素。

**妊娠期糖尿病（GDM）**：妊娠中晚期胎盘激素造成胰岛素抵抗，糖耐量异常，产后多数恢复，但远期 T2DM 风险升高。

**特殊类型**：**MODY**（单基因突变，常染色体显性，成年起病）、**LADA**（成人隐匿性自身免疫糖尿病，抗体阳性）、胰腺疾病（胰腺炎、囊性纤维化）、药物（糖皮质激素）、内分泌病（库欣、肢端肥大）。

**辨析｜易错点：** 「年纪轻 = 1 型，年纪大 = 2 型」是被人口学偷换了的临床判断。**真正的分型依据是「是不是自身免疫、是不是绝对缺乏胰岛素」**——成人可患 LADA，肥胖青少年可患 2 型，分型决定治疗方案（胰岛素 vs 口服药）与并发症节奏。

## 3 诊断标准与监测

诊断只看四条，满足任一即可（需除外急性应激等高血糖诱因）：

| 指标 | 糖尿病切点 | 说明 |
| --- | --- | --- |
| 空腹血糖（FBG） | ≥ 7.0 mmol/L | 空腹 ≥ 8 小时 |
| OGTT 2 小时血糖 | ≥ 11.1 mmol/L | 口服 75 g 葡萄糖后 |
| 糖化血红蛋白 HbA1c | ≥ 6.5% | 反映近 2–3 个月平均血糖 |
| 随机血糖 + 症状 | ≥ 11.1 mmol/L | 伴多饮多尿多食消瘦等症状 |

**糖尿病前期**（风险预警区间）：空腹血糖 5.6–6.9、OGTT 2 小时 7.8–11.0、HbA1c 5.7–6.4%——此时干预可以逆转或延迟发病。

**监测**：糖化血红蛋白（3 个月一次）评估总体控制；自我血糖监测（SMBG）与**连续血糖监测（CGM）**评估日内波动，指标是**目标范围内时间（TIR，通常要求 > 70%）**。<span class="marginnote">TIR 把「控糖好不好」从「测几次瞬时值」升级成「看一整天的分布」——这是用分布思维替换点估计，与第二级《概率论》里用分布而不是期望刻画随机现象是同一个思路。</span>

## 4 急性与慢性并发症

**急性并发症**：
**糖尿病酮症酸中毒（DKA）**：胰岛素极度缺乏（多见于 T1DM），脂肪分解产生酮体，代谢性酸中毒 + 高血糖 + 脱水。处理：补液、胰岛素、补钾、纠酸，警惕脑水肿。
- **高血糖高渗状态（HHS）**：T2DM 重症脱水，血糖极高但多无酮体，渗透性利尿导致重度脱水、昏迷。<span class="marginnote">DKA 与 HHS 都是「血里糖太多、细胞里没糖」的极端——一个快速燃脂产酮、一个慢慢脱水成高渗。掌握这对双子，就掌握了高血糖急症的骨架。</span>
**低血糖**：见下一篇。

**慢性微血管并发症**（糖尿病特有的三件套）：
- **视网膜病变**：微血管瘤、出血、新生血管 → 失明，需每年眼底筛查。
- **肾病**：微量白蛋白尿 → 蛋白尿 → 肾功能衰竭，需查尿白蛋白/肌酐比。
- **神经病变**：远端对称性多神经病变，袜套手手套样感觉减退、疼痛、自主神经受累（体位性低血压、胃轻瘫、阳痿）。

**大血管并发症**：冠心病、脑卒中、外周动脉病——糖尿病使心血管病风险升高 2–4 倍，是首要死因。足部溃疡与感染（糖尿病足）是微血管 + 大血管 + 神经三因叠加的后果。

**重点：并发症是可预防的**——DCCT/UKPDS 两大经典试验证明，严格控制血糖显著降低微血管并发症；而大血管并发症还要靠控血压、调脂、戒烟协同。

## 5 代谢综合征

代谢综合征不是单一疾病，而是**一组互相捆绑的危险因素簇**（NCEP-ATP III 标准，满足 ≥ 3 项）：

- 中心性肥胖：腰围男 ≥ 90 cm、女 ≥ 80 cm（亚洲切点，民族差异）。
- 甘油三酯 ≥ 1.7 mmol/L 或已治疗。
- HDL 胆固醇男 < 1.0、女 < 1.3 mmol/L 或已治疗。
- 血压 ≥ 130/85 mmHg 或已治疗。
- 空腹血糖 ≥ 5.6 mmol/L 或已治疗。

它的底层是**胰岛素抵抗 + 内脏脂肪堆积 + 慢性低度炎症**——胰岛素抵抗让胰岛素升糖、升脂、升压（高胰岛素血症促进钠潴留与交感兴奋）。代谢综合征是 T2DM 与心血管病的共同「上游」，也是干预的最佳窗口。<span class="marginnote">把代谢综合征看成「胰岛素抵抗的五个下游出口」——糖、脂、压、肥、炎。它把单病种思维改写成系统思维，这正是本专题一直在训练的「从一个信号追到整个网络」的能力。</span>

糖尿病管理的另一根支柱是**糖尿病教育**：学会识别低血糖、正确使用胰岛素、处理生病日——「给患者装上决策能力」的效果，有时胜过换更好的药。内分泌科医生一半是药剂师、一半是老师：把「如何在变化中决策」教给患者，才是慢性病管理的底层能力。

## 6 公式解析：HOMA-IR 与胰岛素抵抗

用一次空腹采血就能粗略估计胰岛素抵抗程度，公式叫 HOMA-IR：

$$HOMA\text{-}IR = \frac{\text{空腹胰岛素}[\mu U/mL] \times \text{空腹血糖}[mmol/L]}{22.5}$$

- **空腹胰岛素**：基础状态的胰岛素浓度。
- **空腹血糖**：基础状态的血糖浓度。
- **常数 22.5**：由健康人群「稳态模型」（HOMA）标定而来，使得健康人 HOMA-IR 以 1 为中心。

分三步理解：

- **第一步，看逻辑**：HOMA 的前提是「基础状态下，血糖 × 胰岛素的乘积反映 β 细胞需要多大努力才能稳住血糖」。血糖正常而胰岛素很高 → 机体必须靠更多胰岛素才能维持 → **胰岛素抵抗**；胰岛素低而血糖高 → **分泌不足**。
- **第二步，算一笔**：空腹胰岛素 15 μU/mL、血糖 5.6 mmol/L，则 HOMA-IR = (15×5.6)/22.5 ≈ 3.7——显著高于正常（通常 < 2.0），提示胰岛素抵抗。正常人该值低，是因为只需少量胰岛素就能稳住血糖。
- **第三步，看边界**：HOMA-IR 是科研与流行病学指标，**不用于临床诊断糖尿病**——诊断靠第三节的硬切点。它教给我们的是「抵抗」这个看不见的中间状态可以如何被量化——把两个临床量合成一个复合指数，这在第四级《机器学习》里叫特征工程。

控糖目标也要个体化：对年轻、病程短、无并发症者，HbA1c 常定在 < 7.0%，甚至更严格；对老年、反复低血糖、合并症多者，放宽到 7.5%–8.5%。**「达标」不是一条固定的线，而是在「微血管获益」与「低血糖风险」之间找平衡点**——这与在收益与风险之间权衡的最优化思想完全一致。理解了这条，再看「为什么医生不给所有人开一样的胰岛素方案」，答案就不言自明。

## 7 小结

- 血糖稳态是**胰岛素（唯一的降糖）与胰高血糖素（首要的升糖）**的双环拮抗，β 细胞自带血糖计，GLP-1 是进餐放大器。
- **T1DM** 是自身免疫性胰岛素绝对缺乏，易发 DKA；**T2DM** 是胰岛素抵抗 + 相对不足——分型看机制，不看年龄。
- 诊断四条硬切点：**空腹 ≥ 7.0、OGTT 2h ≥ 11.1、HbA1c ≥ 6.5%、随机 ≥ 11.1（伴症状）**。
- 慢性并发症分**微血管**（眼、肾、神经）与**大血管**（心、脑、外周），严格控制可防微血管病变。
- **代谢综合征**是胰岛素抵抗的五出口簇，满足 ≥ 3 项即成立，是 T2DM 与心血管病的共同上游。
- **HOMA-IR = 空腹胰岛素 × 空腹血糖 / 22.5**，是量胰岛素抵抗的复合指数，科研常用、临床不用于诊断。
