# 浮针疗法

浮针疗法是符仲华教授创立的现代针灸新技术，以一次性浮针在皮下浅筋膜层扫散并配合再灌注活动处理病理性患肌，具有进针无痛、操作便捷、即时取效的特点。它拥有患肌理论、气血新论等独立理论体系、专属针具与中国针灸学会浮针专委会，已传播至全球多个国家和地区，是中医药现代化与国际化的重要代表。学完本专题，就系统写完了从患肌理论、浮针操作技术到临床各科治疗与标准化国际化的全部内容。
