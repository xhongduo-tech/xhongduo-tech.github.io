## 为什么从头面与躯干牵涉痛继续

四肢关节的病，「痛」和「病根」通常在同一片区域；而头面与躯干却是另一番景象——**这里的疼痛常常「声东击西」**：头痛的病根在颈后，面痛的病根在咬肌，胸痛的病根在胸壁肌筋膜，这就是**牵涉痛（referred pain）**。它把「痛点 ≠ 病根」这条患肌理论的核心命题推向了极致。<span class="marginnote">牵涉痛在传统针灸里用「病在上取之下」等远端取穴应对，在西方医学里是内脏-体表投射与激痛点放散痛的研究对象；浮针则直接落在「引起牵涉的患肌」上——头痛查颈肌、面痛查咀嚼肌，靶点清晰可触。</span>

## 1 什么是牵涉痛：疼痛的「声东击西」

**牵涉痛**：疼痛的实际感受部位远离真正的病灶或病理来源部位的现象。肌肉源性牵涉痛最常见的形式是**激痛点/患肌的放散痛**——一块紧张的肌肉，其激痛点被刺激时，疼痛会按固定的模式放散到远处。

头面躯干部最经典的牵涉关系：

- **斜方肌上束**紧张 → 颞部头痛、后头痛。
- **胸锁乳突肌**紧张 → 前额痛、眼周不适、耳鸣感。
- **咬肌 / 颞肌**紧张 → 面部痛、颞下颌关节区痛。
- **胸壁肌（胸大肌、前锯肌、肋间肌）**紧张 → 胸痛、乳下痛、背痛。
- **膈肌 / 腹壁肌**紧张 → 上腹痛、季肋部不适。

**重点：牵涉痛提醒我们，主诉「头痛」「胸痛」的患者，病根完全可能不在头、不在胸**——这正是浮针「顺着患肌找源头」的用武之地，也要求临床医生保持鉴别诊断的警惕（尤其胸痛要先排除心肺急症）。

## 2 头面部的浮针应用：以紧张性头痛为例

紧张性头痛是浮针在头面部的代表性病证，多与颈肩肌群的慢性紧张相关。

**患肌排查**：查斜方肌上束、胸锁乳突肌、头夹肌、颈夹肌、枕下肌群——按压这些肌肉是否诱发或加重头痛。

**治疗流程**：在患肌近端或旁的浅表安全区（如斜方肌上缘、颈后旁侧）进针 → 送管留皮 → 扫散后让患者做**缓慢转头、耸肩、仰头**等再灌注动作，循环数轮。<span class="marginnote">头面部浮针有个特别之处：进针点多在颈肩部「远端」，而不是直接在头部扎——头皮下浅筋膜薄、血管丰富且靠近颅内结构，直接头部进针风险大；「病在头、针在颈」既安全又符合患肌逻辑。</span>

**疗效特征**：颈源性头痛与紧张性头痛常在数次治疗内明显缓解；但需结合姿势纠正，否则复发率高。

## 3 躯干部的浮针应用：胸痛与上腹痛的「肌筋膜解」

胸痛、上腹痛是门诊最需谨慎的主诉。在排除心肺急症（心梗、肺栓塞、主动脉夹层等）之后，相当一部分胸痛源于**胸壁肌筋膜**：

- **胸大肌 / 胸小肌紧张** → 胸前痛、乳房下痛。
- **前锯肌、肋间肌紧张** → 侧胸痛、呼吸时加重。
- **腹直肌上段、膈肌相关紧张** → 上腹痛、剑突下不适。

浮针处理以患肌旁进针、扫散 + 呼吸配合的再灌注活动为主（如深呼吸、扩胸、耸肩），常可显著缓解这类「非心源性胸痛」与功能性上腹痛。<span class="marginnote">胸背部浮针始终要绷紧一根弦：<strong>安全第一</strong>——进针严格控制在浅筋膜，胸壁薄处尤其小心，宁可少治、不可误伤。这一点与《浮针操作注意事项》里强调的「禁区地图」完全一致。</span>

**辨析｜易错点：** 头面躯干牵涉痛是「最容易误诊、也最需要警惕」的浮针领域——**绝不能在未排除急重症的情况下用浮针「止痛了事」**：急性剧烈胸痛、腹痛伴发热、神经系统体征、意识改变等，一律先走急诊排查流程。浮针处理的是肌筋膜性牵涉痛，不是所有疼痛。

## 4 核心对比表：头面躯干牵涉痛的患肌溯源

| 主诉部位 | 常被怀疑的患肌 | 再灌注动作 |
| --- | --- | --- |
| 后头痛/颞部痛 | 斜方肌上束、头夹肌、枕下肌群 | 缓慢转头、仰头、耸肩 |
| 前额痛/眼周不适 | 胸锁乳突肌、额肌 | 转头、抬头 |
| 面部痛/颞下颌痛 | 咬肌、颞肌 | 张闭嘴、磨动下颌 |
| 胸痛/乳下痛 | 胸大肌、前锯肌、肋间肌 | 扩胸、深呼吸 |
| 上腹痛/季肋痛 | 腹直肌、膈肌相关 | 深呼吸、腹式呼吸 |

这张表的读法：**头痛、面痛、胸痛、腹痛，最后都指向一群「可触诊的患肌」**——把这张表背下来，等于掌握了一张「声东击西」的破案地图。

## 5 典型病例：颞下颌关节紊乱的面痛

头面躯干牵涉痛最典型的例子之一是颞下颌关节紊乱（TMD）相关的面痛。

**病例概况**：28 岁女性，右侧面颊与颞下颌关节区痛半年，张口受限，咀嚼时加重，牙科检查未见明显咬合问题，先后按「牙痛」「三叉神经痛」治疗无效。

**浮针排查**：触诊右侧咬肌、颞肌紧张压痛明显，嘱其做张闭口动作时疼痛可被诱发并加重——患肌与主诉相关成立。

**浮针处理**：在右侧咬肌近端安全区进针，扫散后让患者做缓慢张闭口、轻磨下颌等再灌注动作，循环数轮，面部疼痛明显减轻、张口幅度增大。

**复盘**：这个病例的典型之处在于「痛点（关节/面颊）与病根（咬肌、颞肌）分离」——牙科与神经科都没找到的问题，浮针从咀嚼肌的患肌入手解决了。它再次印证牵涉痛的破案逻辑：**顺着肌肉链找源头，而不是在痛点死磕。**<span class="marginnote">面痛的鉴别要谨慎：除了 TMD 相关肌痛，还需排除牙源性、神经血管性（三叉神经痛）甚至颅内病变。浮针处理的是「咀嚼肌患肌」这一环，鉴别诊断始终在治疗之前。</span>

## 6 术语速查：牵涉痛与头面躯干病证的关键名词

| 术语 | 含义 |
| --- | --- |
| 牵涉痛 | 疼痛感受部位远离真正病灶的现象 |
| 紧张性头痛 | 与颈肩肌紧张相关的头部绷紧样疼痛 |
| 颈源性头痛 | 源于颈椎或颈肌功能障碍的头痛 |
| 颞下颌关节紊乱 | 咀嚼肌与颞下颌关节功能异常引起的面痛与张口受限 |
| 非心源性胸痛 | 排除心脏病变后仍存在的胸痛，多源于胸壁肌筋膜 |
| 咬肌 / 颞肌 | 负责咀嚼的肌肉，TMD 面痛的常见患肌 |
| 胸壁肌筋膜痛 | 胸壁肌肉与筋膜紧张引起的胸痛 |
| 红旗征 | 提示急重症（心梗、肺栓塞等）的警示征象 |

**重点：头面躯干牵涉痛的本质是「痛点 ≠ 病根」**——头痛查颈肌、面痛查咀嚼肌、胸痛查胸壁肌，顺着肌肉链找源头，是浮针破案的核心思路。

**辨析｜易错点：** 牵涉痛领域最大的风险是**「未排除急症就止痛」**——急性胸痛、腹痛伴发热、神经系统体征等，必须先走急诊排查流程。**浮针处理的是肌筋膜性牵涉痛，不是所有疼痛；鉴别诊断永远在治疗之前。**

## 7 常见问题：头面躯干牵涉痛答疑

**问一：「头痛扎脖子，是不是弄错了？」**——没弄错，这正是牵涉痛。紧张性头痛、颈源性头痛的病根常在颈肩肌群（斜方肌、胸锁乳突肌、枕下肌群），「病在头、针在颈」符合患肌逻辑，也规避了头部直接进针的风险。

**问二：「胸痛也敢用浮针？」**——**前提是先排除心肺急症**。急性胸痛必须先心电图、排除心梗与肺栓塞；确认是非心源性胸痛（胸壁肌筋膜来源）后，浮针处理胸壁患肌才安全有效。**顺序不可颠倒：先急诊排查，再谈浮针。**

**问三：「面痛到底是牙痛、神经痛还是肌痛？」**——需要鉴别。牙源性痛看牙科、三叉神经痛有典型电击样特征、TMD 面痛则与咀嚼肌相关。浮针只处理「咀嚼肌患肌」这一环，**鉴别诊断始终在治疗之前。**

**问四：「为什么头痛浮针也要配合动作？」**——再灌注活动让患者做缓慢转头、仰头等动作，调动目标患肌、促使血流回流。**配合动作的浮针，效果更持久。**

## 8 补充：牵涉痛的「三辨」

**辨主诉**：头痛、面痛、胸痛、腹痛，先判断是否可能为急重症来源。
**辨病根**：顺着患肌链（颈、咀嚼肌、胸壁肌）找真正的病灶。
**辨层次**：分清「结构性」与「肌筋膜性」，前者转诊、后者浮针。

**重点：牵涉痛领域最忌「头痛医头」——三辨之中，辨主诉排第一，安全永远优先。**

## 9 小结

- **牵涉痛**是疼痛部位远离病灶的现象，头面躯干是「声东击西」的重灾区。
- 斜方肌、胸锁乳突肌、咬肌、胸壁肌、腹壁肌是头面躯干牵涉痛最常见的患肌。
- 紧张性头痛、颈源性头痛浮针多「病在头、针在颈」，在颈肩患肌处处理。
- 非心源性胸痛与功能性上腹痛常有肌筋膜来源，浮针可处理，但**必须先排除心肺急症**。
- 头面躯干是最需鉴别诊断的领域：先急诊排查，再谈浮针；安全永远第一。
