## 为什么从葡萄膜与眼眶开始

前几节我们走的是「结构—功能」的机械路径；
这一节转向**免疫与肿瘤**。
葡萄膜是血管最丰富的眼内组织，因此是**免疫反应与全身疾病的眼内舞台**——很多全身病（强直性脊柱炎、结节病、白塞病、结核、梅毒）第一次亮相就在眼睛里。
眼眶则是眼球以外的「后半战场」：炎症、内分泌与肿瘤在这里争夺有限的解剖空间。
这一节的主题词是**「红眼背后是谁」「突眼背后是谁」**——识别比治疗更能救命。

## 1 葡萄膜解剖与葡萄膜炎分类

**葡萄膜（uvea）**：虹膜 + 睫状体 + 脉络膜，血管丰富，是眼内免疫炎症的主要发生地。
**葡萄膜炎（uveitis）**按**解剖部位**分四类（国际 Uveitis Nomenclature 标准）：

| 类型 | 部位 | 常见疾病 |
| --- | --- | --- |
| 前葡萄膜炎 | 虹膜 / 睫状体 | 特发性、HLA-B27 相关、单纯疱疹 |
| 中间葡萄膜炎 | 玻璃体基底部 / 睫状体平坦部 | 扁平部炎（pars planitis）、结节病 |
| 后葡萄膜炎 | 脉络膜、视网膜 | 弓形虫病、弓蛔虫、梅毒 |
| 全葡萄膜炎 | 上述全部 | 白塞病、VKH 综合征、交感性眼炎 |

<span class="marginnote">记住葡萄膜炎的两个分类轴：解剖部位（前/中/后/全）决定检查与主诉方向，病因性质（感染性 vs 非感染性）决定治疗根本——非感染性用激素与免疫抑制剂，感染性必须先抗感染，激素反而火上浇油。这是全章最重要的分叉口。</span>

## 2 前葡萄膜炎

前葡萄膜炎（虹膜睫状体炎）是眼科最常见的「内源性」红眼之一。
症状：**眼红、眼痛、畏光、流泪、视力下降**；
体征：睫状充血（角膜周围紫红色充血）、**角膜后沉着物（KP）**（白细胞在角膜内皮上聚成小白点）、**前房闪辉与细胞**（房水蛋白渗出与白细胞——「闪光」和「细胞」是裂隙灯下的活动度定量指标）、虹膜粘连（前/后粘连）。

约一半前葡萄膜炎与 **HLA-B27** 相关（强直性脊柱炎、反应性关节炎、银屑病关节炎等脊柱关节病），另一半特发性或与感染（单纯疱疹、巨细胞病毒）、结节病、炎症性肠病相关。
<span class="marginnote">「HLA-B27 + 前葡萄膜炎」的临床联想链：反复发作的非肉芽肿性前葡萄膜炎，往往在清晨、单眼、男性青壮年——见到它要追问腰背痛（晨僵），那可能是强直性脊柱炎的第一信号。
眼科的炎症诊断，经常是风湿免疫科病史的起点。
</span>治疗核心是**睫状肌麻痹剂**（散瞳、防粘连、止痛）+ **局部激素**；
反复发作则要考虑全身免疫调节并筛查全身病。

## 3 中间与后葡萄膜炎

**中间葡萄膜炎**（扁平部炎）：主要炎症在睫状体平坦部，表现为**玻璃体浮游物、下方雪球样渗出**，病程慢性，症状常较轻（飞蚊、雾视）。与结节病、多发性硬化、莱姆病等相关。

**后葡萄膜炎（脉络膜视网膜炎）**：视力下降更直接。
**弓形虫病**是最常见的感染性后葡萄膜炎之一——先天性或获得性感染，眼底见**旧病灶旁出现新生病灶（卫星病灶）**，呈「头灯」样白色渗出。
<span class="marginnote">弓形虫病的经典图像是「陈旧疤痕旁的新鲜病灶」——复发是因为潜伏在视网膜色素上皮的虫体重新活跃。
它把「感染 + 免疫 + 潜伏」三个概念压缩在眼底一个画面上，也是《视网膜疾病》里「感染性眼底病」的预览。
</span>

## 4 全葡萄膜炎与全身关联

**白塞病（Behçet）**：血管炎性全葡萄膜炎，伴口腔/生殖器溃疡、皮肤损害；
眼内是「血管闭塞 + 反复炎症」，是严重致盲性葡萄膜炎。
**VKH 综合征（Vogt–小柳–原田病）**：双侧肉芽肿性全葡萄膜炎 + 脑膜刺激 + 听觉障碍 + 皮肤毛发改变（白癜风、白发、脱发）。
**交感性眼炎**：一眼穿通伤后，伤眼抗原暴露，对侧健眼发生双侧肉芽肿性全葡萄膜炎——所以穿通伤要尽早清创缝合，这是「保一眼即保双眼」的免疫学道理。
<span class="marginnote">交感性眼炎是眼科学里最著名的「免疫系统认错人」案例：一侧眼外伤暴露了以往「免疫豁免」的视网膜抗原，免疫系统学会攻击它，于是另一只健康的眼睛也被波及。
其治疗核心是及时缝合伤眼 + 强力免疫抑制。
这也是《角膜与外眼疾病》「免疫豁免区」概念的最戏剧化延伸。
</span>

## 5 眼眶疾病

眼眶是狭小的骨性腔隙，里面塞着眼球、视神经、眼外肌、血管与脂肪——任何占位都会「挤」出症状。

**眼眶蜂窝织炎（orbital cellulitis）**：最常见的眼眶急症，多由鼻窦炎蔓延（尤其儿童）。
表现为**眼睑红肿、眼球突出、眼球运动受限、眼痛、发热**，是**眼科急症**，需静脉抗生素并影像评估，警惕眶尖综合征与海绵窦血栓。
<span class="marginnote">眶隔前蜂窝织炎 vs 眼眶蜂窝织炎是急诊必辨：前者感染在眼眶外，眼睑红肿但眼球位置、运动、视力正常；
后者感染进入眼眶，出现突眼、眼球运动受限、视力下降——有无突眼与运动受限就是分界线。
儿童鼻窦炎、牙源性感染是常见源头。
</span>

**甲状腺相关眼病（Graves 眼病，TAO）**：成人最常见的眼眶病。
自身免疫性甲状腺疾病（常伴甲亢）导致眼外肌与眶脂肪增生水肿：**突眼、上睑退缩（凝视）、迟落、复视、眼睑/结膜水肿、压迫性视神经病变**。
<span class="marginnote">TAO 的机理是甲状腺与眼眶组织共享抗原：TSH 受体抗体刺激眼眶成纤维细胞分泌黏多糖，脂肪与肌肉增生。
它与内分泌治疗联动，吸烟显著加重，活动期用免疫抑制、静止期考虑减压手术。
内分泌科与眼科在这里握手。
</span>**眼眶肿瘤**：成人常见**泪腺肿瘤、淋巴瘤、视神经胶质瘤/脑膜瘤**；
儿童最重要的原发眼眶恶性是**横纹肌肉瘤**（可快速生长、突眼、可转移，须放疗/化疗）。
眼内肿瘤里还有**视网膜母细胞瘤**——儿童最常见的眼内恶性肿瘤，以**白瞳症（猫眼）**、斜视为首发，详见《视网膜疾病》一节对「白瞳症鉴别」的讨论。

**眼眶影像选择**：CT 对骨折与钙化最敏感（视网膜母细胞瘤的钙化点是诊断要点），MRI 对软组织与视神经病变分辨力最佳，B 超快速、无辐射、适合初筛。
一条口诀：**查骨折用 CT、查软组织用 MRI、初筛看 B 超**——影像学的物理原理（密度对比、磁共振弛豫、声学阻抗）在此转化为诊断武器。

## 6 核心辨析：红眼的鉴别

眼科急诊与门诊的最大挑战是「**红眼三兄弟**」——一眼充血，究竟是结膜炎、前葡萄膜炎还是急性闭角型青光眼？三者治法南辕北辙，误诊可致失明：

| 特征 | 急性结膜炎 | 前葡萄膜炎 | 急性闭角型青光眼 |
| --- | --- | --- | --- |
| 疼痛 | 异物感为主 | 中度眼痛、畏光 | 剧烈眼痛、头痛 |
| 视力 | 一般正常 | 中度下降 | 骤降、虹视 |
| 分泌物 | 有（水样/脓性） | 无 | 无 |
| 瞳孔 | 正常 | 缩小（可能后粘连） | 散大固定 |
| 角膜 | 清亮 | KP、角膜水肿 | 雾状水肿 |
| 眼压 | 正常 | 正常或偏低 | 显著升高（> 40 mmHg） |

一句话记忆：**结膜炎有分泌物、瞳孔正常；葡萄膜炎瞳孔小、KP 满；闭角青光眼瞳孔散大、眼压爆表**。红眼病不是一种病，而是一组「长得像」的急症。

## 7 小结

- 葡萄膜炎按**解剖**分前/中/后/全，按**病因**分感染性与非感染性——后者用激素，前者必须先抗感染。
- **前葡萄膜炎**常见，约一半与 **HLA-B27** 脊柱关节病相关，需追问腰背痛。
- **弓形虫病**是常见感染性后葡萄膜炎；**交感性眼炎**警示穿通伤必须及时处理。
- 白塞病、VKH、结节病等全身病都会在葡萄膜「登台」，眼部表现常是全身病首发。
- 眼眶病变核心是**突眼 + 运动受限**：蜂窝织炎是急症，Graves 眼病是成人最常见眼眶病。
- 儿童**视网膜母细胞瘤**以白瞳症为首发，须与白内障等鉴别。
- **红眼三兄弟**（结膜炎 / 前葡萄膜炎 / 急性闭角）按分泌物、瞳孔、眼压三步鉴别。
