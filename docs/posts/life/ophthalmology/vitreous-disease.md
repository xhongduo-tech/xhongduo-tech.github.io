## 为什么从玻璃体开始

玻璃体是眼球里最「低调」的成员：它占眼球容积约 2/3，却是近乎纯水的透明凝胶，没有血管、没有神经、几乎不参与成像。
但它一旦出问题——液化、剥离、出血、感染——就直通视网膜这个「屏幕」。
玻璃体疾病的核心难点是**鉴别「无害的飞蚊」与「危险的视网膜前兆」**：同是眼前黑影，有人只是衰老的尘埃，有人却是视网膜裂孔在敲门。
这一节我们学会读玻璃体发出的每一封「来信」。

## 1 玻璃体的解剖与「凝胶」本质

**玻璃体（vitreous body）**充满晶状体之后的眼球后段，含**约 99% 的水**，另 1% 是**胶原纤维**与**透明质酸**——正是透明质酸的持水网络让玻璃体呈「凝胶」而非「液体」。
它几乎没有细胞与血管，营养靠周边扩散；
它与视网膜之间通过**玻璃体基底部**（在锯齿缘）和视盘周围、黄斑区等处的粘连紧密相连。
<span class="marginnote">玻璃体是「最便宜的材料造出最精准的填充」：它既要维持眼内形状与压力，又要绝对透明不散射光线。
凝胶的流变学（弹性、粘性）决定了它随年龄「从果冻变水」的退化过程——这正是一个材料科学问题。
</span>

## 2 玻璃体液化与后玻璃体脱离

随年龄增长，透明质酸降解、胶原聚合，玻璃体从均质凝胶变成「液体池 + 胶原凝聚物」——**玻璃体液化（syneresis）**。
<span class="marginnote">高度近视的玻璃体液化发生得更早更快——眼轴拉长把玻璃体「撑稀」了。
这就是为什么高度近视者飞蚊症往往更早出现，也是视网膜脱离风险更高的原因之一（《视网膜疾病》会有更完整的连锁）。
</span>

当玻璃体与视网膜之间的粘附被剪应力克服，
玻璃体整体与视网膜分离，
即**后玻璃体脱离（posterior vitreous detachment, PVD）**——最常见于 50–70 岁，
常伴**闪光感（photopsia，周边视野的闪光，玻璃体牵拉视网膜所致）**与**飞蚊**。
完全 PVD 时可见 **Weiss 环**（玻璃体与视盘周围粘连撕脱后留下的环状混浊）。
<span class="marginnote">PVD 是「衰老的正常过程」，但它在完成前充满风险：玻璃体撕拉视网膜，可能撕出视网膜裂孔，裂孔渗液即孔源性视网膜脱离。
因此「闪光 + 飞蚊」是新发的、单侧的、持续存在的，就必须散瞳查周边眼底——把 PVD 与视网膜裂孔一次查清。
</span>

PVD 本身的处理很简单：**确认没有裂孔与脱离之后，观察即可**。
玻璃体混浊随时间逐渐「沉底」或被适应，绝大多数人最终不再注意到它们——真正的随访重点，是那一次「彻底、散瞳、看周边」的初查。

## 3 飞蚊症

**飞蚊症（floaters）**：视野中出现随眼球运动飘动的点状、线状、网状阴影——它们是玻璃体混浊在视网膜上投下的影子。
绝大多数是**生理性 / 年龄相关**（玻璃体液化、胶原凝聚），无需治疗，随时间习惯或淡出。
但以下情况要高度警惕：**新发、突然增多、伴闪光、或眼前有「窗帘 / 幕布」遮挡**——这些是视网膜裂孔与视网膜脱离的信号，应尽快散瞳检查。
<span class="marginnote">鉴别飞蚊「良恶」的临床口诀常是「一大片云一样的阴影突然出现、或像墨汁散开」= 玻璃体出血或视网膜脱离，赶紧就医；
「零星几个飘、多年不变、健康查体顺带发现」= 生理性，放宽心。
年龄、近视、外伤史是三大背景信息。
</span>

## 4 玻璃体出血

**玻璃体出血（vitreous hemorrhage）**：血液进入玻璃体腔。出血使视野出现**突然的黑影飘动、雾视，甚至仅存光感**。常见病因排序大致是：

| 病因 | 机制 | 背景 |
| --- | --- | --- |
| 增殖性糖尿病视网膜病变 | 新生血管破裂 | 糖尿病、血糖控制差 |
| 后玻璃体脱离撕裂血管 | PVD 撕破视网膜血管 | 老年人、突然发作 |
| 视网膜静脉阻塞 | 静脉压力高致出血 | 高血压、糖尿病 |
| 视网膜裂孔 / 视网膜脱离 | 撕裂处血管出血 | 闪光 + 飞蚊起病 |
| 眼外伤 | 直接挫伤 | 外伤史 |

<span class="marginnote">糖尿病患者「眼前突然红雾 / 黑影」，第一个要想到的就是增殖期糖尿病视网膜病变的玻璃体出血——这是眼科「最有名也最可防」的出血。查血糖、查眼底（做不了一线，就 B 超），急则玻璃体腔抗 VEGF 或玻切。糖尿病视网膜病变的完整面貌见《视网膜疾病》。</span>少量出血可自行吸收，量大、吸收慢或不吸收（尤其伴视网膜脱离风险）则需**玻璃体切除术**清除积血、同时处理病因。

吸收遵循一条简单规律：出血量小、玻璃体液化良好者吸收快，年轻人比老年人更快；
若 3–6 个月仍不吸收，或合并视网膜裂孔与脱离，就该考虑玻切干预，而不是无限期等待。

## 5 玻璃体手术与玻璃体腔注射

**玻璃体切除术（vitrectomy，经睫状体平坦部入路）**是现代眼底外科的核心平台：微创小切口（23/25/27G）伸入器械，切除混浊玻璃体、剥除视网膜前膜、处理视网膜脱离、注入硅油或气体等。
<span class="marginnote">玻切的入路都选睫状体平坦部——那是眼内唯一「血管少、又不碰视网膜和晶状体」的「安全走廊」。
在它出现之前，眼后段手术几乎是禁区；
平坦部三通道玻切的诞生（70 年代）把眼底手术从「不可能」变成「常规」，这是显微外科史的重要一章。
</span>适应证：玻璃体出血不吸收、孔源性视网膜脱离、黄斑前膜、黄斑裂孔、眼内异物与感染性眼内炎清创。

**玻璃体腔注射（intravitreal injection）**是药物直达眼后段的常规路径：**抗 VEGF 药物**（雷珠单抗、阿柏西普、康柏西普）治疗湿性黄斑变性、糖尿病性黄斑水肿、视网膜静脉阻塞继发黄斑水肿；
**抗生素**治疗眼内炎；
**抗真菌 / 抗病毒**用于相应感染。
<span class="marginnote">玻璃体腔注射让「药物到达眼内」从「高剂量全身用药换血-视网膜屏障」变成「针尖直达」。
它把眼科从「手术科」推向「药物科」的转变中扮演关键角色——也是视网膜血管病（《视网膜疾病》）现代治疗的主力军。
风险是出血、感染与眼压升高，好在均罕见且可控。
</span>

玻切术中常用**气体或硅油**作「眼内填充物」顶压视网膜：气体（如 SF6、C3F8）自行吸收、但术后需保持特定头位，硅油长效、却需二次手术取出。
**「填充物」的选择本质是「支撑强度 vs 生活便利」的权衡**——这也是孔源性视网膜脱离复位手术的收官之笔，我们将在《视网膜疾病》中细说。

## 6 核心辨析：飞蚊症「危险」与「不危险」的分界

玻璃体问题最常以「飞蚊」为主诉，判断标准列成下表，是门诊高频考题：

| 判断 | 良性（可观察） | 危险（需急诊 / 尽快就医） |
| --- | --- | --- |
| 起病 | 缓慢、多年 | 突然出现 / 突然增多 |
| 形态 | 少量点状、线状 | 大片云雾、墨汁样、纱幕样黑影 |
| 闪光 | 无或偶发 | 持续、单侧、尤其周边闪光 |
| 视野 | 无缺损 | 有固定黑影、视野缺损、视野「窗帘」 |
| 背景 | 年龄相关、无高危因素 | 高度近视、糖尿病、外伤、眼内手术史 |

一句话记忆：**「突然、大片、伴闪光、挡视野」四词之中占两个，就不该等。** 眼底检查（尤其散瞳周边）是唯一能确认「有没有裂孔/脱离/出血」的办法——不要靠「感觉」判断安全。

## 7 小结

- 玻璃体是**水凝胶**（99% 水 + 胶原 + 透明质酸），无血管无神经，占眼球容积约 2/3。
- 年龄与高度近视导致**玻璃体液化**，进而**后玻璃体脱离（PVD）**：闪光 + 飞蚊是典型信号，完成时可看到 **Weiss 环**。
- **飞蚊症**多数是良性老化，但「突然、增多、伴闪光、挡视野」必须排查视网膜裂孔与脱离。
- **玻璃体出血**最常见于增殖性糖尿病视网膜病变、PVD 撕裂血管、静脉阻塞、外伤；治疗从观察吸收到玻切。
- **玻璃体切除术**经睫状体平坦部入路，是眼后段外科平台；**玻璃体腔注射**是抗 VEGF 等药物直达眼内的常规路径。
- 飞蚊良恶之判，用「起病、形态、闪光、视野、背景」五问，占其二即就医。

在下一节，我们将揭开玻璃体后面那张「屏幕」的真实面貌——**视网膜疾病**。
