## 为什么从眼外伤开始

眼外伤是眼科唯一「不以病起、而以事起」的章节：健康人一瞬间就可能失明。
它检验的不是知识深度，而是**决策速度与次序感**——先做什么、绝不做什么，直接决定预后。
化学烧伤的黄金处理在「现场的头几分钟」，开放性眼球损伤的禁忌是「任何一次挤压」。
这一节我们建立一套清晰的「外伤处理操作系统」：分类 → 评估 → 各类型对策 → 禁忌清单。
它也是全书的收官：把前十二节的结构、压力、免疫与神经知识，全部投射到一个「遭受暴力的眼球」上。

## 1 外伤分类：闭合性 vs 开放性

世界通用的**伯明翰眼外伤术语（BETT）**把外伤一分为二，决定后续一切处理的基调：

| 大类 | 亚类 | 定义 | 示例 |
| --- | --- | --- | --- |
| **闭合性眼球伤** | 钝挫伤 | 无全层眼球壁伤口 | 拳击、球击 |
| | 板层裂伤 | 部分厚度伤口 | 金属屑擦伤角膜 |
| **开放性眼球伤** | 穿通伤 | 全层伤口 1 处 | 刀刺入眼球 |
| | 贯通伤 | 全层伤口进出 2 处 | 射穿伤 |
| | 球内异物（IOFB） | 异物穿入滞留眼内 | 打磨金属飞入 |
| | 破裂 | 钝力致眼球壁自内向外破裂 | 重物砸击 |

**辨析｜易错点：** 破裂与穿通的区别常被混淆——**破裂**是钝力把眼球「撑爆」（从内往外裂），**穿通/贯通**是利器「扎穿」（从外往内伤）。
两者处理原则相近（都按开放性处理：禁压、尽快闭合），但**破裂的预后更差**，因为它往往伴更严重的眼内容物脱出与更大暴力。
<span class="marginnote">BETT 分类是眼科外伤的「通用语言」：病历、统计、科研都必须用它。
记住它的意义不止分类——开放性伤口的正确处理顺序（不压、不冲洗、不探查、盖罩送手术）与闭合性伤（可系统检查）完全不同。
分类先行，行为随后。
</span>

## 2 急诊评估：问、看、测

外伤评估有固定的「问—看—测」次序：

**问**：什么时候、什么物体、什么力道？
「钉子崩进眼」与「羽毛球打中眼」的致伤物性质天差地别。
**看**：先不碰！
看有无明显穿通口、眼内容物（葡萄膜、玻璃体）脱出、结膜下出血（可疑巩膜破裂）、角膜伤口、前房积血。
**测**：视力（受伤眼与对侧眼都要）、瞳孔（RAPD 提示视神经损伤）、眼压（开放伤禁测或慎测）。

**禁忌清单是外伤处理的第一课**：<span class="marginnote">开放性眼球损伤的五条禁令——不压眼球、不冲洗伤口（以免把脏东西带进眼内）、不试图还纳脱出的眼内容物、不用眼压计压迫、不打局部麻药加压。
任何「好心帮忙」的按压、冲洗都可能把「可救」变成「不可救」。
盖一个硬性眼罩（不接触眼球）即可。
</span>可疑开放性损伤时做**眼罩保护 + 破伤风评估 + 全身/局部抗生素 + 影像（眶 CT 薄层扫描查异物与骨折）**，尽快转手术室清创缝合。

## 3 化学烧伤：碱比酸凶险得多

化学烧伤是眼科外伤里**唯一「现场抢救」决定生死**的情况——冲洗越早越好，千万别等眼科医生。

**碱烧伤（最凶险）**：碱（氨水、石灰、烧碱、水泥）与组织发生**皂化反应**，溶解细胞膜、不断向深层渗透，甚至达前房——角膜可数小时内变白、眼压升高、继发青光眼与角膜溃疡穿孔。
**酸烧伤**：酸使蛋白**凝固**，形成「结痂」屏障，大多停留在表层，相对「自限」。

处理铁律：**立即、大量、持续冲洗，直至 pH 恢复正常（6.8–7.4）**——现场自来水或生理盐水冲 30 分钟以上，检查并清除结膜囊内残余颗粒物。
<span class="marginnote">记忆口诀「碱渗酸凝」：碱溶解渗透、伤得深，酸凝固表面、伤得浅——所以「石灰进眼」比「醋进眼」危险得多。
冲洗时务必翻开眼睑冲洗上穹窿（颗粒物常藏在这里），并测结膜囊 pH 直至中性。
迟到的专业处理（抗炎、抗胶原酶、睑球粘连松解、角膜移植）都补不回现场被耽误的几分钟。
</span>后续处理：广谱抗生素、散瞳、抗炎、润滑，防睑球粘连，严重者评估羊膜移植等重建手段。

## 4 钝挫伤：前房积血与眼眶骨折

钝力冲击（拳、球、弹弓、车祸）引起闭合性眼伤：

**前房积血（hyphema）**：虹膜或睫状体血管破裂，血积于前房，轻则前房下方「血平面」，重则充满前房（黑球眼）。
处理：半卧位（让血液沉积、避免堵住房角）、散瞳、降眼压、避免再次外伤；
风险是**继发性再出血**（伤后 2–5 天，可致眼压骤升、角膜血染）。
<span class="marginnote">前房积血患者要「静养 + 半卧位」：卧床让血液沉积下方，避免反复出血；
同时警惕继发性青光眼（红细胞堵塞小梁网）与角膜血染。
镰状细胞病患者尤其危险——他们的红细胞更易堵塞房角，即使中等积血也要积极干预。
</span>

**眼眶爆裂性骨折（blowout fracture）**：钝力使眶内压骤升，眶壁最薄弱处（**下壁**最常见）向外爆裂，眶脂肪与下直肌/下斜肌可能嵌顿入上颌窦。
表现：**突眼→凹陷、复视（向上注视时）、眶下神经分布区（面颊、上唇）麻木、皮下气肿、眼球上转受限**。
治疗：多数保守观察，有肌肉嵌顿、复视持续或眼球明显凹陷则手术修复。
<span class="marginnote">爆裂骨折的「嵌顿」诊断靠被动牵拉试验（forced duction test）：麻醉后医生牵拉眼球，若上转受限是「机械性卡住」而非「肌肉无力」，则提示嵌顿——这正是《神经眼科学》里「限制性 vs 麻痹性」鉴别在眼外伤中的一次实战。
</span>

**其他钝挫伤**：外伤性白内障、晶状体脱位、玻璃体出血、**视网膜脱离与视网膜震荡（commotio retinae，一过性灰白水肿）**——钝力伤后要散瞳查眼底，警惕迟发的视网膜裂孔。

## 5 穿通伤与眼内异物

**穿通伤（penetrating injury）**：利器（刀、玻璃、金属、树枝）造成全层伤口。
处理次序：**眼罩保护 → 不冲不压不探查 → 破伤风 → 抗生素 → 手术清创缝合**。
缝合的目标是**恢复眼球壁的密闭性与形状**，为二期手术（摘除白内障、处理玻璃体出血、取异物）创造条件。
<span class="marginnote">穿通伤不只伤「这一处」——它可能撕破晶状体（外伤性白内障）、伤及视网膜、引起玻璃体出血，还埋着交感性眼炎的远期风险（《葡萄膜与眼眶疾病》讲过：一侧眼伤后暴露自身抗原，免疫系统可能攻击对侧健眼）。
这也是「缝好伤眼，其实在保双眼」的深层含义。
</span>

**球内异物（IOFB）**：打磨、锤击、爆炸时高速金属屑可穿入眼球。
**含铁异物长期滞留导致铁沉着症（siderosis）**——铁离子氧化损伤视网膜，进行性视力下降；
含铜异物则致铜沉着症。
诊断靠**薄层眶 CT**（金属异物显影清晰，非金属如玻璃/木屑需 B 超辅助），治疗为手术取出 + 防感染。
<span class="marginnote">「高速 + 金属 + 单眼」是 IOFB 的三件套：打磨工、焊工、爆破工都要想到它。
所有穿通伤病历必问「受伤时在干什么、飞了什么进来」——异物常比看上去深得多，若只缝伤口不找异物，铁沉着症会在数月后「秋后算账」。
</span>

## 6 核心辨析：碱烧伤 vs 酸烧伤

化学烧伤是外伤里「化学知识直接救命」的典型，二者对比一遍，终生受用：

| 特征 | 碱烧伤 | 酸烧伤 |
| --- | --- | --- |
| 化学机制 | **皂化溶解**（细胞膜溶解、可穿透） | **蛋白凝固**（形成结痂屏障） |
| 渗透深度 | 深（可及前房、眼内结构） | 浅（多局限表层） |
| 常见致伤物 | 氨、石灰、烧碱、水泥 | 酸液、酸雾 |
| 预后 | 差，角膜可白变、溃疡穿孔 | 相对好，相对自限 |
| 现场处理 | **立即大量冲洗至 pH 中性** | 同样立即大量冲洗 |

一句话记忆：**碱「溶解渗透」、酸「凝固封顶」——所以碱性烧伤更急、更深、预后更差**；而无论酸碱，**冲洗永远先于一切专业检查**。

## 7 小结

- 外伤先分**闭合性 vs 开放性（BETT）**：破裂是钝力撑爆、穿通是利器扎穿，开放性按「禁压、禁冲、盖罩、速缝」处理。
- 急诊评估按**问（致伤物与力度）→ 看（先不碰）→ 测（视力/瞳孔/眼压）**，开放性损伤做眼罩 + CT + 抗生素 + 破伤风。
- **化学烧伤以碱最凶**（皂化渗透）vs 酸（凝固自限）；**现场立即大量冲洗至 pH 中性**，碱烧伤预后看这几分钟。
- **前房积血**半卧位静养、防继发出血与青光眼；**眼眶爆裂骨折**查嵌顿（被动牵拉试验）、复视与眶下神经麻木。
- 穿通伤为**交感性眼炎**埋雷；**球内异物**（高速金属）须薄层 CT 定位取出，防铁沉着症。
- 禁忌口诀：**开放性眼球伤，不压、不冲、不还纳、不量眼压**。

到这里，我们走完了眼科学全书的一条主线：从解剖生理、检查、屈光，到角膜、青光眼、白内障、葡萄膜、玻璃体、视网膜、斜视弱视、神经眼科，最后在外伤的「暴力与分寸」中收束。
在下一门课里，我们将走向外科体系的下一个方向——把「眼」放进更大的躯体与健康图景。
