## 为什么从周围神经病开始

神经轴的五个站位里，前几课一路从大脑半球、脑干、脊髓走到了中枢白质，而**周围神经**是通往「皮肤与肌肉」的最后一站。它像一根从脊髓前角伸向远端的电缆：近段在神经根，中段在神经干，末梢在末梢神经——**离脊髓越远，症状越「手套袜套」**。<span class="marginnote">周围神经病是「最常见的神经科疾病」之一：糖尿病、酒精、维生素缺乏、化疗药物、免疫病都能伤到它。它的核心矛盾也最朴素——一边是「麻木与无力从脚趾开始往上爬」的远端型，一边是「要命的呼吸肌与球麻痹」的急进型。这一课教你读懂这台「身体末端的气象站」。</span>

本课连接第一课的反射检查（腱反射减弱是周围神经的标志）、第四课的脊髓节段（节段 vs 神经根 vs 周围神经的鉴别）、以及上一课的脱髓鞘概念（吉兰-巴雷综合征是周围神经的「脱髓鞘」）。

## 1 周围神经的解剖与分类框架

**核心概念**：**周围神经病（peripheral neuropathy）** 是周围神经（前角/后根神经节以远）损伤引起的综合征，表现为**运动 + 感觉 + 自主神经**症状按某种「分布规律」的组合。

周围神经病变按**分布**分成三大格局，这是第一把分类尺：

**多发性神经病（polyneuropathy）**：长度依赖性，**远端先受累**——「手套袜套样」感觉减退、远端肌萎缩与腱反射减弱，从脚趾开始向上蔓延。糖尿病、酒精、维生素 B12 缺乏的典型模式。
- **单神经病（mononeuropathy）**：单一神经受累，分布按该神经支配区，如正中神经（腕管综合征）、腓总神经麻痹。
- **多灶性单神经病（mononeuropathy multiplex）**：多支神经先后受累，提示血管炎、糖尿病多发神经病、麻风等。

按**病变性质**分第二把尺——**轴索型 vs 脱髓鞘型**，这把尺直接对应电生理检查的解读（见第五节）。

**按受累纤维类型**再分第三把尺，与症状一一对应：

| 纤维 | 特点 | 功能 | 受损表现 |
| --- | --- | --- | --- |
| Aα | 粗、有髓、快 | 运动、本体感觉 | 无力、腱反射减弱 |
| Aβ | 粗、有髓 | 触觉、振动觉、位置觉 | 麻木、「踩棉花感」 |
| Aδ | 中等、有髓 | 快痛、冷觉 | 锐痛、针刺感 |
| C | 细、无髓、慢 | 慢痛、温觉、自主神经 | 烧灼痛、自主神经障碍 |

「烧灼刺痛 = 小纤维（C）受累，踩棉花感 = 大纤维（Aβ）受累」——**症状的性质，先替你分好了纤维**。

## 2 病史的「五问」：把麻木听成定位学

面对「麻木无力」，神经科有经典的五问：

1. **分布**：手套袜套（多发性）？单根神经（单神经病）？多支（多灶性）？还是节段（神经根/脊髓，见第四课）？
2. **起病与病程**：急性（吉兰-巴雷、中毒）、亚急性（维生素缺乏、副肿瘤）、慢性（糖尿病、遗传性）。
3. **感觉性质**：烧灼刺痛（小纤维受累）？还是「踩棉花感」振动觉/位置觉差（大纤维受累）？——前者痛温觉、后者深感觉，对应不同的神经纤维直径。
4. **伴发症状**：自主神经（体位性低血压、出汗异常、便秘）、肌萎缩、夜间加重。
5. **背景病史**：糖尿病、酒精、肿瘤、化疗、重金属、家族史（遗传性神经病）。

**重点：** 分布 + 纤维类型，往往比辅助检查先锁定额外一小步。**「袜套样烧灼痛 + 夜间加重 + 足背动脉正常」几乎就是糖尿病周围神经病的临床处方**——此时先测血糖和糖化血红蛋白，往往比急着做肌电图更经济。但**任何快速进展、或近端起病、或呼吸/球部受累的神经病都是急症**——那几乎就是吉兰-巴雷综合征。

**电生理与血液学的分工**：怀疑周围神经病，神经传导检查（NCS/EMG）回答「轴索还是脱髓鞘、单神经还是多神经」，血液检查（血糖、糖化血红蛋白、维生素 B12、叶酸、甲状腺功能、血清蛋白电泳、ANA/ANCA、重金属）回答「病因」。**先定分布与性质，再定病因**——两条线各管一半，缺一不可。

## 3 吉兰-巴雷综合征：周围神经的「炎症风暴」

**吉兰-巴雷综合征（Guillain-Barré syndrome, GBS）** 是急性炎症性多神经根神经病（最常见亚型 AIDP），也是**周围神经病里唯一的神经科急症**。经典剧情：上呼吸道或消化道感染（如空肠弯曲菌）后 1–3 周，出现**对称性、进行性、由远端向近端（或由足向上）蔓延的弛缓性瘫痪**，伴腱反射消失、轻度感觉异常，严重者累及**呼吸肌与球部肌肉**（吞咽、构音）——需要气管插管与重症监护。

**病理本质是免疫介导的脱髓鞘**（周围神经版本的 MS）：分子模拟——病原表位与神经节苷脂结构相似，抗体攻击施万细胞/髓鞘。<span class="marginnote">Miller-Fisher 变异型是 GBS 的「精装版」：眼肌麻痹 + 共济失调 + 腱反射消失，血清<strong>抗 GQ1b 抗体</strong>阳性。眼肌麻痹加共济失调像脑干病变，但腱反射消失与对称性把线索拉回周围——这是第二课交叉体征与周围神经病鉴别的绝佳考题。</span>

**诊断三件套**：① 腰穿查脑脊液——**蛋白-细胞分离**（蛋白显著升高而细胞数正常），这是 GBS 的实验室签名；② 电生理示脱髓鞘改变（传导减慢、传导阻滞）；③ 排除其他（脊髓病、重症肌无力、低钾性麻痹）。

**治疗**：**静脉免疫球蛋白（IVIG）或血浆置换**，在发病 2 周内开始效果最佳。多数患者数月后显著恢复，但约 20% 遗留明显残疾、少数死亡——**「快速进展的对称性无力」就是呼叫神经科与重症的暗号**。

**GBS 不是单一疾病，而是「急性炎性多神经根神经病」家族**：最常见为急性炎性脱髓鞘性多神经根神经病（AIDP）；轴索变异型有急性运动轴索性神经病（AMAN，多与空肠弯曲菌感染及抗 GM1 抗体相关，亚洲多见）与急性运动感觉轴索性神经病（AMSAN）；另有 **Miller-Fisher 变异型**（眼肌麻痹 + 共济失调 + 腱反射消失，抗 GQ1b 抗体）。**分型的意义在预后**：轴索型恢复往往更慢、残留更多。

## 4 常见周围神经病「名片」

**糖尿病周围神经病**：最常见。典型为远端对称性感觉运动神经病（烧灼、麻木、夜间重），也可有自主神经受累；**糖尿病单神经病**（眼动、正中、腓总）与近端肌萎缩型也可见。控制血糖是基石，三环类/加巴喷丁/普瑞巴林对症止痛。
- **腕管综合征（正中神经）**：最常的嵌压性单神经病。拇指/示指/中指麻木 + 夜间麻醒 + 甩手缓解（Phalen 试验、Tinel 征），大鱼际萎缩提示晚期。**治疗：夹板、注射、必要时松解术**。
- **腓总神经麻痹**：跨坐久、石膏、盘腿后足下垂 + 足背感觉减退，「跨阈步态」——腿抬高避免拖足。
- **酒精性/维生素 B12 缺乏**：B12 缺乏还伴**后索型深感觉障碍 + 亚急性联合变性**（脊髓后索/侧索，见第四课后索综合征）——可逆，需早期补充。
- **血管炎性多灶性神经病**：多支神经急性受累 + 系统性症状，需警惕，治疗为免疫抑制。<span class="marginnote">一个容易忽略的「红牌」：<strong>化疗相关周围神经病</strong>（紫杉醇、铂类）常被误当「化疗副作用」而漏诊。神经科的价值在于早期识别、调整方案与对症管理，避免患者因「怕麻」而中断有效抗癌治疗。</span>

「急性/慢性 × 对称/不对称」的四格填法，是把鉴别谱系压缩成一张图的捷径：

| 组合 | 代表疾病 |
| --- | --- |
| 急性 + 对称 | GBS、中毒、卟啉病 |
| 慢性 + 对称 | 糖尿病、酒精、B12 缺乏、遗传性 |
| 急性 + 不对称（多灶） | 血管炎、多灶性 GBS |
| 慢性 + 不对称（单神经） | 腕管综合征、嵌压性神经病 |

## 5 公式解析：神经传导速度 v = d / t

电生理检查是周围神经病的「客观尺子」，它的物理核心只有一条公式：

$$
v = \frac{d}{t}
$$

即**神经传导速度 = 两个刺激点之间的距离 ÷ 传导时间**。具体操作与解读分三步：

- **第一步，测距离 $d$**：在神经走行上放置两个刺激点（近端与远端），量出两点间的体表距离。
- **第二步，测时间差 $t$**：分别从两点刺激，记录肌肉复合动作电位（CMAP）的潜伏期；用近端潜伏期减去远端潜伏期，得到**两点间传导时间**（减掉了远端末梢传导时间）。代入 $v=d/t$，得到神经干的中段传导速度。
- **第三步，判读「轴索 vs 脱髓鞘」**：**脱髓鞘型 → 传导速度显著减慢**（绝缘破损，冲动只能爬行），如 GBS、慢性炎性脱髓鞘性多发性神经病；**轴索型 → 传导速度基本正常，但 CMAP 波幅降低**（电缆芯断了，传导路径少了，速度不变但「响度」变小），如糖尿病、中毒。<span class="marginnote">口诀「慢 = 脱髓鞘，小 = 轴索」是肌电图阅读的基础。临床上常混合存在，但这条二分法决定了治疗方向：脱髓鞘型可免疫治疗（GBS、CIDP），轴索型以病因管理与对症为主。肌电图还能量到 F 波（近端传导）与 H 反射，把「测量卷尺」延伸到神经根。</span>

## 7 小结

- 周围神经病三格局：**多发性（手套袜套、远端优先）、单神经病（单支分布）、多灶性（多支先后）**；性质分**轴索型 vs 脱髓鞘型**。
- 病史五问（分布/病程/感觉性质/伴发症状/背景）是定位的第一步；**糖尿病周围神经病**最常见，**GBS** 是最急的周围神经病。
- **GBS**：感染后对称性上升性弛缓瘫 + 腱反射消失 + 脑脊液**蛋白-细胞分离**，治疗为 IVIG/血浆置换；呼吸肌受累立即重症监护。
- 常见名片：腕管综合征（正中神经嵌压）、腓总麻痹（足下垂）、B12 缺乏（亚急性联合变性）。
- 神经传导速度 $v=d/t$：**慢 = 脱髓鞘，小 = 轴索**，是肌电图阅读的钥匙。
- **任何呼吸或球部受累、快速进展的神经病都是急症**（GBS），IVIG/血浆置换在发病 2 周内开始效果最佳。

在下一节，我们到达神经肌肉接头的「最后一毫米」——那里只隔着一道突触间隙，却藏着重症肌无力的全部秘密：神经肌肉接头与肌肉疾病（重症肌无力/肌营养不良）。
