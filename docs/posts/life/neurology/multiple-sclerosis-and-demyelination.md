## 为什么从多发性硬化开始

沙尔科在 1868 年用「意图性震颤」这把钥匙，把多发性硬化（MS）与帕金森病「拧开」——这是神经内科历史上最漂亮的一次鉴别诊断。今天的多发性硬化是**中枢神经系统最常见的自身免疫性脱髓鞘病**，它的全部临床戏剧，都源于一个单词：**髓鞘（myelin）**。<span class="marginnote">髓鞘是包裹轴突的绝缘脂质层，让神经冲动「跳跃式」传导（朗飞结间的跳跃传导），速度可达非髓鞘传导的近百倍。脱髓鞘 = 绝缘层破损 = 冲动传导变慢或中断。一根健康的电缆，比一根裸露的电缆快得多、稳得多——这就是脱髓鞘病理生理的全部隐喻。</span>

本课把第二课的脑干体征（眼动、意向性震颤、构音）放到 MS 这个「多病灶、多时间」的舞台上重演，并连接第一课的反射检查与第四课的脊髓横贯性损害。它也是免疫学专题（自身免疫、炎症）在神经系统的一次实弹演练。

## 1 脱髓鞘：从「跳跃」到「爬行」

**核心概念**：**脱髓鞘（demyelination）** 是髓鞘破坏而轴突相对保留的病理过程。在中枢神经，髓鞘由**少突胶质细胞**生成；在周围神经，由**施万细胞**生成。MS 的脱髓鞘位于中枢（脑、脊髓、视神经），而吉兰-巴雷综合征的脱髓鞘位于周围（见《周围神经病》课）——**中枢还是周围，是脱髓鞘疾病的第一把分类尺**。

髓鞘破坏后，冲动从「朗飞结间的跳跃」退化为「爬行」，出现两个后果：**① 传导减慢**（症状的初始可逆部分）；**② 传导阻滞**（完全中断）。而急性炎症消退后，少突胶质细胞可部分再髓鞘化，这是复发后部分恢复的结构基础。<span class="marginnote">MS 症状还会随体温变化波动（Uhthoff 现象）：洗热水澡、运动发热时传导阻滞加重，症状一过性恶化。这个「热致传导阻滞」的小现象，是髓鞘生理学的活广告——也提醒患者避免诱发因素。</span>

## 2 多发性硬化的两个「多」

**多发性硬化（multiple sclerosis, MS）** 的诊断灵魂是**两个「多」**：

**时间上的多（dissemination in time, DIT）**：两次或以上的临床发作、或新病灶在不同时间出现。
- **空间上的多（dissemination in space, DIS）**：病灶分布在中枢神经系统两个以上不同部位。

**经典的首发综合征**，几乎都是「某一条通路被单点击中」：

- **视神经炎（optic neuritis）**：单眼视力下降、眼球转动痛、色觉减退；眼底可见视乳头水肿（球后视神经炎可正常）。是 MS 最常见首发症状之一。
- **横贯性脊髓炎（transverse myelitis）**：下肢无力、感觉平面、括约肌障碍（见第四课），但**多为部分性、不对称**——与特发性全横断有所不同。
- **脑干/小脑综合征**：核间性眼肌麻痹（INO——内侧纵束受损，表现为向一侧注视时患侧眼球内收不能而对侧外展眼震颤）、三叉神经痛样面痛、眩晕、意向性震颤、构音障碍、共济失调。
- **大脑半球病灶**：偏瘫、偏身感觉障碍、认知症状（尤其进展型）。

把首发表现与其典型体征列成速览表：

| 首发综合征 | 核心表现 | 提示线索 |
| --- | --- | --- |
| 视神经炎 | 单眼视力下降、眼球转动痛、色觉减退 | 相对性传入性瞳孔缺陷（RAPD） |
| 横贯性脊髓炎 | 双下肢无力、感觉平面、括约肌障碍 | 多为部分性、不对称 |
| 脑干/小脑综合征 | 核间性眼肌麻痹、眩晕、意向性震颤 | INO 对 MS 高度特异 |
| 大脑半球 | 偏瘫、偏身感觉障碍 | 较少见，但可为首发 |

**重点：** MS 的**时间特征**是「复发-缓解」——发作期数天到数周达峰，随后部分或完全缓解；反复发作后残留残疾累积。约 85% 首发为复发缓解型（RRMS），其中相当一部分数年后转为继发进展型（SPMS）。**MS = 时间上的「多」+ 空间上的「多」+ 解剖上「中枢白质」**，这三个条件缺一不可。

## 3 诊断工具：MRI 的「目击证词」

诊断依赖**麦克唐纳标准（McDonald criteria）**——它把临床发作、MRI 新发 T2/钆增强病灶、脑脊液寡克隆带（OCB）组合成一套「时间/空间多发」的判据：

| 证据 | 看什么 |
| --- | --- |
| 空间多发 | MRI 上 ≥2 个典型区域病灶（脑室旁、皮质下、幕下、脊髓） |
| 时间多发 | 出现新病灶（随访 MRI），或同时存在强化与非强化病灶 |
| 脑脊液 | 寡克隆带阳性（鞘内免疫合成标志） |

**核心概念**：**寡克隆带（oligoclonal bands, OCB）** 是脑脊液里出现的局限、重复的 IgG 条带而血清中不存在，反映中枢鞘内的局部抗体合成，是 MS 高度敏感（约 90%）的实验室标记。<span class="marginnote">OCB 不是 MS 的「独生子」——感染（神经梅毒、亚急性硬化性全脑炎）、自身免疫病（NMOSD、SLE）也可阳性。它提供的是「支持」，不是「判决」。诊断仍以临床 + MRI 的「两个多」为主。</span>

**辨析｜易错点：** **视神经脊髓炎谱系病（NMOSD）** 曾被归入 MS，如今独立——它由**抗 AQP4（水通道蛋白-4）抗体**介导，典型表现是**视神经炎 + 纵向广泛性横贯性脊髓炎（LETM，脊髓长节段 T2 信号 ≥ 3 个椎体）**，多无脑白质典型病灶、OCB 多为阴性。鉴别价值巨大：**NMOSD 用利妥昔单抗/依库珠单抗等治疗，而某些 MS 药物（如那他珠单抗、芬戈莫德）在 NMOSD 中无效甚至有害**。见到「双眼视神经炎 + 长节段脊髓炎」要先查 AQP4 抗体。

MS 与 NMOSD 的差异，列成表最能一次看清：

| 特征 | MS | NMOSD |
| --- | --- | --- |
| 血清抗体 | 无特异致病抗体 | 抗 AQP4 抗体（约 70–90%） |
| 脊髓病灶 | 短节段、多偏侧 | 长节段（LETM，≥3 个椎体） |
| 视神经 | 单眼为主 | 常双眼或反复双侧 |
| 脑脊液 OCB | 约 90% 阳性 | 多为阴性 |
| 治疗 | 各种 DMT | 利妥昔单抗/依库珠单抗/萨特利珠单抗 |

## 4 治疗：急性期「灭火」与长期「防火」

**急性发作期**：大剂量静脉甲泼尼龙（0.5–1 g/日 × 3–5 天）冲击——**抗炎灭火、加速恢复**。它对复发短期的恢复有帮助，但**不能改善长期预后**，也不改变病程。
- **长期疾病修正治疗（DMT）**：目的不是「治一次」，而是**减少复发、延缓残疾累积**。一线有干扰素-β、醋酸格拉替雷、特立氟胺；口服更强效的有芬戈莫德、富马酸二甲酯；更强效的（那他珠单抗、阿仑珠单抗、奥瑞珠单抗）用于高活动度患者。<span class="marginnote">DMT 的选择是「疗效 vs 风险」的权衡：那他珠单抗疗效强但罕见进行性多灶性白质脑病（PML，与 JCV 病毒再激活有关）；奥瑞珠单抗在 RRMS 与 PPMS 都有效。启动 DMT 越早、效果越好——这是「治疗窗口」思想在慢性免疫病中的体现。</span>

**DMT 按「疗效—风险」分层**，选药本质是一道权衡题：

| 层级 | 代表药物 | 适用人群 |
| --- | --- | --- |
| 一线 | 干扰素-β、格拉替雷、特立氟胺 | 低—中度活动度 |
| 口服强效 | 芬戈莫德、富马酸二甲酯 | 中—高度活动度 |
| 高强效 | 那他珠单抗、阿仑珠单抗、奥瑞珠单抗 | 高活动度，RRMS/PPMS |

越往上走疗效越强，但感染与 PML 等风险也越高——**先把疾病活动度评估清楚，再选梯级**，比「最新最贵」更接近循证。
- **对症与康复**：痉挛（巴氯芬）、膀胱症状、疼痛、疲劳、认知康复——MS 患者带病生活的能力，很大程度取决于对症管理做得好不好。

## 5 公式解析：复发-缓解的「开关模型」

理解 MS 的病程，可以借一个简化的「开关模型」。把每一次复发看成一次「开—关」脉冲：

$$
\text{残疾度 } D(t) = \sum_{\text{每次复发}} \big( \Delta \text{ 可逆部分} + \Delta \text{ 不可逆残留} \big) + \text{渐进进展项}
$$

- **第一步，拆解一次复发**：一次发作的残疾增量 = 炎症性、可逆的传导阻滞（激素可加速恢复）+ 轴索损伤的不可逆残留（再髓鞘化无法挽回的部分）。复发后「残留」的多寡，取决于炎症的强度与轴索的损伤。
- **第二步，看多次复发**：残疾度随时间做「阶梯式上升」——每次复发抬高一阶，缓解期平台略有回降，但回不到原水平。**复发次数越多，不可逆残留累加越多**，这就是「复发-缓解」型的残疾累积。
- **第三步，加入进展项**：进入继发进展期后，即使没有临床发作，残疾也持续缓升——反映持续的神经变性（轴索丢失、皮质萎缩）。「开关模型」到此失效，疾病从「间断风暴」变为「匀速退潮」。<span class="marginnote">这个模型解释了三个临床事实：① 为什么越早用 DMT 越好（减少复发 = 减少不可逆残留的累加）；② 为什么激素能「快一点好」但不能「避免残留」（它灭的是炎症，不是变性）；③ 为什么进展期 DMT 效果有限（变性不依赖炎症开关）。</span>

## 7 小结

- **髓鞘**让冲动跳跃传导；**脱髓鞘 = 绝缘破损 = 传导减慢或阻滞**，可伴 Uhthoff 现象（热致加重）。
- **MS 诊断灵魂是两个「多」**：时间多发 + 空间多发，中枢白质病灶；首发综合征多为视神经炎、横贯性脊髓炎、脑干/小脑综合征。
- 诊断靠 **McDonald 标准**：临床 + MRI（强化/新病灶）+ 脑脊液寡克隆带；**NMOSD（AQP4 抗体）必须鉴别**，治疗路线完全不同。
- 治疗分两线：急性期**甲泼尼龙灭火**，长期 **DMT 防火**（越早用越好，疗效-风险权衡）。
- 复发-缓解病程是**阶梯式残疾累积**，进入进展期后靠对症与康复管理。

在下一节，我们登顶神经内科的「老树」——**痴呆**。MS 在空间与时间上「多发」，痴呆则在记忆与认知上「弥漫」：痴呆与认知障碍。
