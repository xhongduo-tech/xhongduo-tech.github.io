# 运动障碍疾病

<div class="epigraph">

## 为什么从运动障碍开始

詹姆斯·帕金森在 1817 年用短短一段话，把「静止性震颤 + 肌力减退 + 前倾体态 + 慌张步态」打包成一个病——这正是两百年后我们仍在诊治的帕金森病。运动障碍疾病（movement disorders）共同的主角不是「无力」而是**「不自主或不协调的运动」**：有的太多（震颤、舞蹈、抽动），有的太少（动作迟缓、僵硬）。<span class="marginnote">运动障碍与上一课癫痫的对照很妙：癫痫是皮质同步放电的「风暴」，帕金森是黑质多巴胺能神经元凋亡的「退潮」。一个从电入手，一个从神经递质入手，它们是神经内科「功能异常」的两类典型。</span>

本课把第一课的「肌张力、震颤、姿势」三件套升级为定量工具，并首次讲清**基底节环路**——这是理解帕金森病、亨廷顿病、肌张力障碍的公共神经科学底座，也是后面痴呆课（路易体痴呆、亨廷顿痴呆）的病因入口。

## 1 运动障碍的「太多」与「太少」

运动障碍按表现分成两大谱系，记住这个二分，症状学就有了骨架：

**运动减少-僵硬谱系（hypokinetic）**：**帕金森病**为核心，表现为运动迟缓（bradykinesia）、肌强直、静止性震颤、姿势不稳。
- **运动增多谱系（hyperkinetic）**：震颤（tremor）、舞蹈症（chorea，快速无目的）、肌张力障碍（dystonia，持续性扭转/姿势异常）、抽动（tic）、肌阵挛（myoclonus）。

**核心概念**：**震颤（tremor）** 是节律性、振荡性不自主运动，神经内科先按**发生时机**分类：**静止性震颤**（肢体放松时出现，活动时减轻，帕金森病特征，频率 4–6 Hz，「搓丸样」）；**动作性/意向性震颤**（活动时出现，指鼻试验加重，提示小脑通路问题，见多发性硬化课）；**姿势性震颤**（保持姿势时出现，如举杯时，特发性震颤）。<span class="marginnote">「静止性 = 多巴胺通路，意向性 = 小脑通路，姿势性 = 特发性/生理性」是震颤定位的三联口诀。帕金森病的震颤在睡眠和随意运动时消失，被 Charcot 专门用来和意图性震颤（多发性硬化）鉴别——这正是第二课要留意的 Charcot 观察。</span>

## 2 帕金森病：黑质的多巴胺退潮

**帕金森病（Parkinson disease, PD）** 是第二常见的神经变性病，病理核心是**中脑黑质致密部多巴胺能神经元进行性丢失**，伴路易小体（α-突触核蛋白聚集体）。当黑质多巴胺丢失超过约 60–80%，运动症状才临床显现——**症状的出现晚于病理几十年**。

**运动四联征**（帕金森病的「招牌」）：

1. **运动迟缓（bradykinesia）**：动作启动与执行减慢、幅度减小，是**最具诊断核心性**的症状（写小字「小写症」、面容呆板「面具脸」、走路摆臂减少）。
2. **静止性震颤**：典型「搓丸样」，手为主，放松时出现。
3. **肌强直**：铅管样强直（全程均匀），叠加震颤则呈「齿轮样」强直。
4. **姿势不稳**：后倾跌倒倾向，是疾病中晚期标志，也是「姿势步态异常」亚型的主征。

**公式般的诊断要点**：**PD = 运动迟缓 + 至少一项（静止性震颤 / 肌强直）**，且**单侧起病、左旋多巴反应良好**。<span class="marginnote">「左旋多巴反应良好」是 PD 与多系统萎缩等帕金森叠加综合征鉴别的重要线索——真 PD 对左旋多巴几乎立竿见影，叠加综合征则反应差且进展快。做一个左旋多巴试验，比很多辅助检查更接近「金标准」。</span>

**治疗**：**左旋多巴（复方制剂，加卡比多巴防外周脱羧）** 是症状性治疗最有效的药物；多巴胺受体激动剂、MAO-B 抑制剂、金刚烷胺可用于早中期或辅助；晚期出现「剂末现象」与「开关现象」时可考虑脑深部电刺激（DBS）。**治疗改善症状，不改变病程**——这是变性病治疗的基本共识。

**非运动症状——帕金森病的「隐藏半场」**：嗅觉减退（可早于运动症状数年）、快速眼动期睡眠行为障碍（梦中挥打喊叫）、便秘、抑郁焦虑、体位性低血压，晚期还有认知下降与痴呆。它们常比运动症状更早出现、也更能拖垮生活质量。<span class="marginnote">「诊断 PD 前先看鼻子和睡眠」：特发性嗅觉减退 + 快速眼动期睡眠行为障碍 + 便秘，是帕金森病临床前期的经典三联线索——这些非运动症状正是神经变性先于黑质、向脑干与肠道神经系统扩散的证据（Braak 分期）。</span>

**辨析｜易错点：** 多系统萎缩（MSA）、进行性核上性麻痹（PSP）、皮质基底节变性（CBD）合称「帕金森叠加综合征」——起病像 PD，但对左旋多巴反应差、进展更快，且早期出现**对称性起病、早期跌倒、垂直性凝视麻痹（PSP）或严重自主神经障碍（MSA）**等红旗征。遇到「帕金森样」患者，**先问左旋多巴有没有效，再问有没有早期跌倒与眼球活动异常**。

**药物性帕金森综合征**：抗精神病药、甲氧氯普胺（胃复安）等多巴胺受体阻滞剂可以复制出全套帕金森样症状，**双侧起病、进展较快、停药可逆**——这是「帕金森样」鉴别里最廉价也最常被漏掉的一环。遇到新发帕金森样症状，**先查药单，再谈诊断**。

## 3 基底节环路：运动减少与增多的「电路图」

要理解为什么黑质病变导致运动减少、而纹状体其他部位病变导致舞蹈，需要一张**基底节环路的电路图**。简化版如下：

![基底节直接与间接通路](/images/neurology/movement-disorders-1.svg)

大脑皮质发出运动指令 → 传入**纹状体（壳核）**，纹状体经两条通路把信号送回**丘脑**，再由丘脑返回皮质辅助运动区：

**直接通路（促进运动）**：纹状体 → 苍白球内侧（Gpi）→ 丘脑。纹状体抑制 Gpi，Gpi 抑制丘脑，**两次抑制 = 去抑制**，丘脑被释放，运动被促进。
- **间接通路（抑制运动）**：纹状体 → 苍白球外侧（Gpe）→ 丘脑底核（STN）→ Gpi → 丘脑。**负负得正**，最后 Gpi 被激活、丘脑被抑制，运动被减弱。

黑质致密部（SNc）的多巴胺对两条通路作用相反：**兴奋直接通路（D1）**、**抑制间接通路（D2）**——总体上「油门踩到底」。帕金森病 SNc 多巴胺丢失 → 直接通路变弱 + 间接通路变强 → Gpi 过度抑制丘脑 → **运动全面「刹车」**。<span class="marginnote">亨廷顿病则是反向的故事：纹状体（尤其含脑啡肽的 D2 神经元）变性 → 间接通路变弱 → 丘脑被过度释放 → 出现舞蹈样过多运动。同一条环路，直接通路失灵 = 少动，间接通路失灵 = 多动——这就是「一张电路图解释两类病」的典范。</span>

## 4 运动增多：舞蹈症、肌张力障碍与抽动

**亨廷顿病（Huntington disease, HD）**：常染色体显性遗传（**HTT 基因 CAG 三核苷酸重复扩增**），纹状体进行性萎缩。表现**舞蹈症 + 认知障碍 + 精神行为异常**三联征，多在 30–50 岁起病，预后不良。CAG 重复次数与起病年龄负相关——**重复越多，起病越早**，是遗传学「动态突变」的教科书案例。<span class="marginnote">HD 是遗传咨询与神经心理的教科书：成年子女有 50% 概率遗传，症状前基因检测涉及复杂的伦理决策。它也是痴呆课（皮质下痴呆）与遗传学专题交叉的桥头堡。</span>
- **肌张力障碍（dystonia）**：持续性或间歇性肌肉收缩导致扭转、重复动作或异常姿势。如**眼睑痉挛**（频繁眨眼、睁眼困难）、**痉挛性斜颈**（头颈扭转）、书写痉挛（任务特异性）。起始多局灶，病因可为原发性（遗传性，如 DYT1）或继发性（药物、缺氧、肝豆状核变性）。
- **抽动障碍（tic disorders）**：突然、快速、反复、无目的的动作或发声。**抽动秽语综合征（Tourette）** 为多发性运动 + 发声抽动持续 >1 年，起病于儿童期，可伴注意缺陷多动障碍与强迫观念。

**辨析｜易错点：** 抽动与肌张力障碍和舞蹈症易混淆，鉴别要点：**抽动**可被短暂抑制、有「前驱冲动感」、动作刻板重复；**肌张力障碍**是持续的姿势异常、不呈抽动样爆发；**舞蹈症**是流动的、不可抑制的、像「弹钢琴」一样的动作。三者治疗也分道扬镳：抽动用 α 激动剂/习惯逆转训练，肌张力障碍用抗胆碱能药或肉毒素注射，舞蹈症用多巴胺耗竭剂（丁苯那嗪）。

把「哪里坏了导致哪种运动异常」浓缩成一张表，环路就变成查表工具：

| 病变部位 | 通路后果 | 典型症状 |
| --- | --- | --- |
| 黑质致密部（多巴胺缺失） | 直接通路弱、间接通路强 | 运动减少（帕金森病） |
| 纹状体 D2 神经元（亨廷顿） | 间接通路弱、丘脑过度释放 | 舞蹈样多动 |
| 丘脑底核（STN） | 间接通路反馈异常 | 运动障碍（也是 DBS 靶点） |
| 小脑及其通路 | 协调与运动学习受损 | 意向性震颤、共济失调 |

**特发性震颤（essential tremor, ET）** 是**最常见的震颤性疾病**（患病率约为帕金森病的数倍），表现为**双侧对称的姿势性/动作性震颤**（举杯、写字、持物时明显，频率 6–12 Hz），多有家族史，部分患者对酒精一过性缓解。**它常被误诊为帕金森病**——鉴别关键：ET 以动作性震颤为主、无运动迟缓、无肌强直、左旋多巴无效，治疗首选 β 受体阻滞剂（普萘洛尔）或扑米酮。<span class="marginnote">「手抖就是帕金森」是门诊最常见的误判：帕金森是「放松时抖」，特发性震颤是「做事时抖」。问一句「抖的时候手是放松的还是在拿东西」，比开药更有诊断价值。</span>

## 5 公式解析：药量—疗效—不良反应的三重奏

帕金森病治疗里最常见的临床问题，是「左旋多巴加量还是减量」。它的决策可以抽象成一条「症状谱」上的位置判断：

$$
\underbrace{\text{「剂末现象」}}_{多巴胺不足} \quad \longrightarrow \quad \underbrace{\text{稳定的「开期」}}_{剂量合适} \quad \longrightarrow \quad \underbrace{\text{异动症、幻觉}}_{多巴胺过多}
$$

- **第一步，先问「峰值效应」**：服药后 1 小时内症状是否明显改善（开期）、下次服药前是否症状回退（剂末现象）？改善明显 + 剂末明显 → **不足**，可缩短给药间隔或加缓释剂型。
- **第二步，再问「峰值不良反应」**：服药后是否出现不自主扭动（剂末异动症或峰值异动症）、幻觉、恶心、体位性低血压？有 → **过多或波动**，需减单次剂量或分次给药。
- **第三步，综合定位**：把症状放在「不足—合适—过多」的谱系上，就能避免「加药治头晕、减药治抖动」这类最典型的用药错误。**左旋多巴的疗效窗口很窄，靠的是精细滴定，而不是开处方便交差。**<span class="marginnote">这其实是一条「过量-不足」的通用权衡曲线，也适用于抗癫痫药与抗凝药：神经内科的长期用药管理，本质上都是「在疗效与毒性之间找平衡点」的工程问题。</span>

## 7 小结

- 运动障碍二分：**少动-僵硬谱系（PD）** vs **多动谱系（震颤、舞蹈、肌张力障碍、抽动）**。
- **PD = 运动迟缓 +（静止性震颤或肌强直）**，单侧起病、左旋多巴反应好；病理为黑质多巴胺神经元丢失伴路易小体。
- 基底节环路：**直接通路促运动、间接通路抑运动**，黑质多巴胺「踩油门」；PD 是刹车过紧（少动），亨廷顿是刹车失灵（多动）。
- 运动增多三兄弟靠「前驱冲动感 vs 持续性姿势异常 vs 流动样舞蹈」鉴别。
- 帕金森用药是「**不足—合适—过多**」三角上的滴定，避免加药治头晕、减药治抖动的经典错误。
- **特发性震颤**是动作性震颤、普萘洛尔有效，与帕金森病的鉴别关键是「放松时抖还是做事时抖」；PD 的非运动症状（嗅觉、睡眠、便秘）常先于运动症状出现。

在下一节，我们转向神经内科的「炎症战」——**多发性硬化**。帕金森病少的是递质，多发性硬化丢的是髓鞘，而它们共享一个枢纽：小脑与长束。多发性硬化与脱髓鞘疾病。
