# 疼痛医学（疼痛科诊疗）

疼痛医学是研究疼痛的病因、发病机制、诊断与治疗的临床学科，已从麻醉学与神经内科中独立成为三甲医院必设的疼痛科专科。系统掌握疼痛诊疗，是应对慢性疼痛这一"第五大生命体征"、满足日益增长的疼痛诊疗需求的关键能力。
