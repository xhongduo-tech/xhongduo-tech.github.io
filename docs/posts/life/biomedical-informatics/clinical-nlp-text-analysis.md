## 为什么从临床 NLP 讲起

第1篇就提到：EHR 里约 80% 的临床信息以**自由文本**存在——病程记录、出院小结、影像报告、手术记录。它们承载着结构化字段装不下的细节（病情演变、鉴别思路、患者偏好），却也是机器最难啃的骨头。**临床自然语言处理（Clinical NLP）** 的任务，正是把这段「沉睡的文本」变成可检索、可分析、可决策的结构化数据。它是医学大数据的「前处理器」——没有 NLP，第4篇后面的数据分析只能依赖稀疏的结构化字段。近十年来，从规则到深度学习、再到大型语言模型，临床 NLP 正经历范式跃迁。<span class="marginnote">对「从极限到大模型」主线：临床 NLP 是「NLP 技术 × 医学领域」的交汇处，大模型（LLM）正是从这里开始大规模进入医疗——但医学文本的特殊性（术语、缩略、否定、时间线）决定了它不能照搬通用 NLP。</span>

## 1 临床文本的独特性：为什么通用 NLP 不够

临床文本与新闻、维基有本质差异，这些差异构成了临床 NLP 的「领域墙」：

**术语与缩写密集**：`MI`（心肌梗死/二尖瓣关闭不全）、`DM`（糖尿病）、`CAD`（冠心病/计算机辅助诊断）——同一缩写多种含义，依赖语境消歧。<span class="marginnote">缩写的歧义是临床 NLP 的经典难题：`MI` 在「急性 MI 入院」里是心肌梗死，在「MI 术后」语境可能指二尖瓣。上下文感知的消歧（word sense disambiguation）是临床文本理解的基本功。</span>

**非标准表达与语法破碎**：病历常是电报式短语（「患者神清，对答切题」），省略主语、缺乏完整句法。

**否定与不确定表达**：「否认胸痛」「无发热」「疑似肿瘤」「不排除……」——**否定与不确定性**的识别直接关系医疗安全（把「无过敏史」当成「有过敏史」是灾难性的）。

**时间线复杂**：病历大量使用「三天前」「既往」「停用后」等相对时间表达，且同一事件可能有「发生、记录、有效」多个时间点（呼应第1篇数据建模的时间戳语义）。

**数值与单位**：`血压 138/92`、`HbA1c 7.2%`——量值提取要绑单位、绑语义。

## 2 临床 NLP 的处理流程

一条经典的临床 NLP 流水线（pipeline）从原始文本到结构化输出，经历若干环节：

**文本预处理**：分句、分词（tokenization）、归一化（全半角、大小写、常见拼写变体）。

**词法分析**：词性标注（POS）、词形还原/词干化（`monitor` 与 `monitoring` 归一）。

**句法分析**：依存/成分句法，为语义提取提供结构（如「否定」的修饰关系）。

**命名实体识别（NER）**：识别临床实体——疾病、药物、检查、症状、解剖部位，并映射到标准编码（SNOMED CT、RxNorm、LOINC 等，呼应第3篇）。<span class="marginnote">NER 是临床 NLP 的核心任务：把「患者因急性心肌梗死入院，予阿司匹林治疗」变成「&#123;急性心肌梗死 → SNOMED:…&#125;、&#123;阿司匹林 → RxNorm:…&#125;」的结构化事实。实体 + 编码映射 = 文本到标准术语的桥梁。</span>

**关系抽取与否定检测**：判断实体间的关系（药物-适应症、部位-病灶），以及实体的否定/不确定性状态——「否认胸痛」中的「胸痛」应标记为**否定**。

**归一化与结构化输出**：把抽取结果对齐到受控术语、时间线、文档结构，输出为可入库的结构化数据。

**重点：** 流水线的每一环都可能出错并向下传播——「分句错了，后面全错」。因此临床 NLP 的工程实践强调**模块可评测、错误可追溯**。

## 3 公式解析：序列标注的条件随机场（CRF）

临床 NER 与否定检测的经典模型是**序列标注**：给每个 token 打一个标签（如 `B-疾病`、`I-疾病`、`O`）。**线性链条件随机场（linear-chain CRF）** 是这一任务的经典统计模型。设输入词序列为 $x_1, x_2, \dots, x_n$，对应标签序列为 $y_1, y_2, \dots, y_n$，则标签序列的条件概率为：

$$
P(y \mid x) = \frac{1}{Z(x)} \prod_{t=1}^{n} \exp\Big(\sum_{k} \theta_k\, f_k(y_{t-1}, y_t, x, t)\Big)
$$

- **第一步，理解 $f_k$（特征函数）**：每个特征函数 $f_k$ 检查「当前位置与标签的组合」是否满足某个条件——例如「当前词是『否认』且标签是阴性标记」「当前词的词性为名词且标签为 B-疾病」。
- **第二步，理解权重 $\theta_k$**：每个特征的权重，从标注数据中学习——特征越有判别力，权重越大；模型据此决定「该打什么标签」。
- **第三步，理解连乘与指数**：对每个位置 $t$，把所有特征加权求和再取指数，得到「该位置标签的偏好打分」；全部位置的打分连乘，得到整个标签序列的联合偏好。
- **第四步，理解 $Z(x)$（配分函数）**：对**所有可能**的标签序列求和归一化，把打分变成真正的概率——$Z(x) = \sum_{y'} \prod_t \exp(\sum_k \theta_k f_k(y'_{t-1}, y'_t, x, t))$。CRF 的关键特性正是「全局归一化」：它联合考虑整个序列的标签，比逐 token 独立判断更能利用标签间的依赖（如 `I-疾病` 前面必然有 `B-疾病`）。<span class="marginnote">在深度学习时代，CRF 常作为<strong>神经网络之上的输出层</strong>：BiLSTM/Transformer 提取特征，CRF 层做标签序列的联合解码——「神经网络学表示，CRF 管序列约束」仍是许多临床 NER 系统的标配。</span>

**重点：** 这个公式的价值不在于手算，而在于理解**序列标注的建模思想**——标签不是独立决定的，而是整个序列联合推断的。否定检测（判断「胸痛」是否被「否认」修饰）也可以建模为序列标注或依赖关系分类，用同样的框架处理。

## 4 去标识化：NLP 的隐私防线

临床 NLP 有一个独特的必修任务——**去标识化（de-identification）**：自动识别并移除文本中的个人标识信息（姓名、身份证号、出生日期、地址、联系方式等），使文本可用于研究而不受隐私法规约束（呼应第3篇《安全隐私》）。<span class="marginnote">去标识化与 NER 同源：把「人名、日期、地点」当作需要识别的实体类型来标注。但它更严格——<strong>漏掉一个名字就可能再识别出患者</strong>，因此评价看重「召回率近乎 100%」，宁可多删不可漏删。</span>

**去标识化的标准数据**：如 i2b2 挑战赛构建的标注语料，成为学界训练与评测的基准。

**挑战**：上下文变体（「李主任查房」「患者儿子王某」）、非标准日期写法、跨句指代（前文提过名字后文只称「患者」）。

**与 LLM 的结合**：大模型可被微调用于去标识化，也可作为「识别 + 替换」的一体化工具，但必须保证「漏识别」的可控性——医疗场景里对失败的容忍度极低。

## 5 从规则到 LLM：临床 NLP 的范式演进

临床 NLP 的方法经历了四代演进，每一代都在「理解深度」上跃迁：

**词典与规则时代**：用术语词典匹配 + 语法规则（如 NegEx 用「无、否认、排除」等触发器词检测否定）。可解释、可维护，但覆盖有限、跨领域迁移差。<span class="marginnote"><strong>NegEx</strong> 是临床否定检测的开山规则算法：在目标实体前后若干词内查找否定触发器词，若命中则标为否定。它在很多系统里至今仍在服役——「简单规则在受限场景里依然高效」是临床 NLP 的务实传统。</span>

**传统机器学习时代**：特征工程（词、词性、词典、上下文窗口）+ CRF/SVM——性能提升，但依赖人工特征。

**深度迁移学习时代**：预训练语言模型（BERT 及其临床版 BioBERT、ClinicalBERT）做微调——把「通用语言理解」迁移到临床领域，NER、否定检测等任务达到新高。<span class="marginnote"><strong>BioBERT / ClinicalBERT</strong> 是在生物医学/临床语料上继续预训练的 BERT 变体——「领域预训练 + 任务微调」的范式让临床 NLP 不再从零学语言，也让「少样本迁移」成为可能。</span>

**大模型时代（LLM）**：指令微调与提示工程让模型直接「读病历、答问题、抽信息」——支持少样本甚至零样本抽取、生成摘要与结构化报告。但**幻觉、术语漂移、可核验性**成为新的风险：临床场景要求 LLM 输出「可溯源、可校对」，人机协同（医生复核）仍是落地前提。<span class="marginnote">LLM 临床 NLP 的现实定位：<strong>「LLM 起草 + 专家校对」</strong>——让模型做摘要、抽实体、填模板，医生审改后确认。完全自动化的临床文本理解在责任与安全上尚不成熟，半自动协同是当前的务实形态。</span>

## 6 临床 NLP 的评价基准与共享数据

临床 NLP 要进步，离不开「可比的评价」与「可用的数据」——这催生了领域特有的两大基础设施：

**共享评测语料（shared tasks）**：i2b2/n2c2 系列挑战赛是临床 NLP 的「奥运会」——组织方发布**带标注的临床文本**（如去标识化的出院小结），各团队用同一套数据训练与评测，任务涵盖 NER、否定检测、去标识化、时间关系、药物抽取等。共享任务的价值是双重的：**横向可比**（大家在同一数据上比成绩）与**方法迭代**（新方法在公开基准上被验证）。<span class="marginnote">i2b2（Informatics for Integrating Biology and the Bedside）从 2006 年起持续发起临床 NLP 评测，后改名 n2c2（National NLP Clinical Challenges）。它是临床 NLP「从各自为政到有标尺」的关键推手——今天的 BERT/LLM 临床模型，几乎都在这些基准上报过成绩。</span>

**可复用研究数据**：临床 NLP 最著名的公开数据是 **MIMIC**——重症监护数据库，含数万名 ICU 患者的去标识化 EHR（生命体征、化验、自由文本病程、影像报告）。它让研究者不必接触真实患者隐私，就能在「真实的临床文本」上开发模型。<span class="marginnote">MIMIC 是「去标识化 + 受控访问」的典范（呼应第3篇《安全隐私》与第4篇《临床研究》）：数据经彻底去标识化，研究者须完成培训与申请、签署协议才能访问——它在「开放研究」与「隐私保护」之间划出了一条可复制的路。</span>

**评价指标的领域特色**：临床 NLP 的评价除了通用指标（精确率、召回率、F1），还强调——**漏检的代价不对称**：去标识化「漏删一个名字」的后果远重于「多删一个词」，因此用「漏删率近乎零」来验收；否定检测「把阴性误判为阳性」可能危及用药决策，需要单独看这类错误。**指标要贴合「错误的临床代价」**，而非只看平均分。

**重点：** 数据与基准是临床 NLP 的「公共品」——没有它们，每个团队闭门造车、结果不可比，领域进步无从谈起。这也呼应第4篇《临床研究信息学》的数据共享主题：**开放的数据与可比的评测，是医学智能发展的双轮**。

### 常见疑问

**问：大模型出来后，传统临床 NLP 还有用吗？**
答：有，而且短期内不可替代。原因有三：**成本**（大模型推理贵，批量抽取文本成本高）、**可核验性**（规则与序列标注的每一步可审计，大模型的输出需人工核对）、**稳定性**（医疗场景对「同一输入同一输出」的要求高，大模型的随机性需要约束）。现实的形态是「混合」：规则/小模型跑高吞吐、低风险的抽取，大模型做高理解难度的生成与总结，两者各司其职。

**问：临床 NLP 最容易出错的是哪一环？**
答：通常是「把抽取结果当事实」——模型抽出了「患者否认胸痛」中的「胸痛」，但忽略了「否认」二字；抽出了「可能的肺癌」，却丢了「可能」这个不确定性。**否定与不确定性的丢失，是临床 NLP 错误的头号来源**，因为它直接改变语义方向（有→无、确定→可能）。这也是为什么本章强调否定检测是核心任务——它护住的是「语义的方向盘」。

## 7 小结

- 临床文本四大挑战：**缩写歧义、语法破碎、否定不确定、时间线复杂**。
- 经典流程：**预处理 → 词法 → 句法 → NER → 关系/否定 → 归一化**，模块可评测。
- **CRF** 是序列标注经典模型：全局归一化 $P(y\mid x) = \frac{1}{Z(x)}\prod_t \exp(\sum_k \theta_k f_k)$，标签是整段联合推断的。
- **去标识化**是临床 NLP 的隐私必修课：漏删一个名字可能再识别出患者，评价看重「漏删率近乎零」。
- **i2b2/n2c2 共享任务与 MIMIC 数据库**是领域的「公共品」：开放数据 + 可比基准，让临床 NLP 从各自为政走向有标尺。
- **四代范式**：规则（NegEx）→ 传统 ML（CRF）→ 预训练微调（BioBERT/ClinicalBERT）→ 大模型提示/微调；「LLM 起草 + 专家校对」是当前落地的务实形态。

在下一节，我们将把这些「抽出来的文本事实」交给算法去发现规律——这就是**医疗数据分析与机器学习**，看模型如何从结构化与半结构化的临床数据里学习决策与预测。
