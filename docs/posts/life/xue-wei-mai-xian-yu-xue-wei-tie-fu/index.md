# 穴位埋线与穴位贴敷（含三伏贴）

穴位埋线与穴位贴敷（三伏贴）是国家中医药管理局标准化推广的基层适宜技术：前者以可吸收性线体埋入特定腧穴，形成长期温和刺激以调理慢性病；后者借三伏天阳气充盛之机，以辛温走窜药物贴敷穴位防治冬病。二者操作简便、疗效确切、基层易行，是中医适宜技术推广的重要组成部分。学完本专题，就系统写完了从埋线与贴敷理论基础、操作技术规范到常见病临床应用与基层推广的全部内容。
