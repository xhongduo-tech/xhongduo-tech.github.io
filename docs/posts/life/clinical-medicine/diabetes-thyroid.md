## 为什么内分泌系统是「信号的科学」

内分泌系统通过**激素**（信号分子）与**受体**（接收器）组成全身的通信网络：下丘脑 → 垂体 → 靶腺 → 靶组织，每一级都受**负反馈**调控。内分泌疾病因此呈现出独特的「信号病」逻辑：激素分泌过多（亢进）、过少（减退）、或受体不敏感（抵抗）。<span class="marginnote">内分泌的负反馈调节是一个经典的控制论系统：甲状腺激素升高 → 抑制垂体 TSH → 抑制下丘脑 TRH——「输出反过来压输入」。这与《控制工程》里的反馈控制回路同构：设定点（调定点）、感受器、效应器、负反馈，内分泌系统就是体内的 PID 控制器。</span>

本篇聚焦两大最常见的内分泌疾病：**糖尿病**（代谢综合征的枢纽，全球数亿患者）与**甲状腺疾病**（甲亢、甲减、结节）。

## 1 内分泌总论与糖尿病概述

### 血糖调节的激素三角

**胰岛素**（胰岛 β 细胞）：降血糖——促葡萄糖摄取、糖原合成、蛋白质脂肪合成。**唯一降糖激素**。
**胰高血糖素**（α 细胞）：升血糖。
**糖皮质激素、肾上腺素、生长激素**：升血糖（应激激素）。

### 糖尿病（DM）的定义与分类

**糖尿病（diabetes mellitus）**：由胰岛素分泌缺陷和（或）作用障碍引起的，以**慢性高血糖**为特征的代谢性疾病。

**1 型糖尿病（T1DM）**：胰岛 β 细胞被**自身免疫破坏**——胰岛素绝对缺乏，多见于青少年，**必须终身胰岛素治疗**。
**2 型糖尿病（T2DM）**：胰岛素**抵抗 + 分泌相对不足**——占 90% 以上，多与肥胖、遗传、生活方式相关。
**其他特殊类型**：妊娠期糖尿病、MODY 等。

**易错点｜T1DM 与 T2DM 的鉴别**：T1 是「胰岛素没了」（绝对缺乏，瘦、酮症倾向、抗 GAD 抗体阳性）；T2 是「胰岛素不够用」（相对缺乏 + 抵抗，胖、隐匿起病）。**「酮症酸中毒倾向」与「自身抗体」是 T1 的标记，治疗上 T1 必须胰岛素、T2 可口服药**。

### 诊断标准（WHO/ADA）

符合以下任一条即可诊断：
1. **空腹血糖 ≥7.0 mmol/L**。
2. **口服葡萄糖耐量试验（OGTT）2 小时血糖 ≥11.1 mmol/L**。
3. **随机血糖 ≥11.1 mmol/L + 典型症状**（多饮多食多尿消瘦）。
4. **HbA1c ≥6.5%**。

**糖尿病前期**：空腹血糖受损（IFG 6.1–6.9）或糖耐量减低（IGT，OGTT 2h 7.8–11.0）——「血糖已经偏高但未达糖尿病」，是干预的黄金窗口。

## 2 糖尿病的并发症

糖尿病的危害不在血糖数值，而在**长期高血糖对血管与神经的慢性损害**。

### 急性并发症

**糖尿病酮症酸中毒（DKA）**：T1DM 多见——胰岛素严重缺乏→脂肪分解→酮体堆积→**代谢性酸中毒**。表现：口渴多尿加重、恶心呕吐、呼吸深大（Kussmaul）、呼气烂苹果味、脱水休克。治疗：**补液 + 胰岛素 + 补钾**（纠正酸中毒）。<span class="marginnote">DKA 的抢救顺序体现「先保命再治本」：大量补液（脱水是最大威胁）→ 小剂量持续胰岛素（抑制酮体生成）→ 补钾（胰岛素使钾进入细胞，血钾骤降）。「先盐水后胰岛素」的顺序错误会致命。</span>
**高渗高血糖综合征（HHS）**：T2DM 老年人多见——极度高血糖（>33.3 mmol/L）而无明显酮症，严重脱水、意识障碍。治疗以补液为主。

### 慢性并发症（血管 + 神经）

**微血管病变**（糖尿病特有）：
**糖尿病视网膜病变**：微血管瘤、出血、新生血管——**失明首位原因**。
**糖尿病肾病**：蛋白尿→肾衰——**透析的首位病因**。
**糖尿病神经病变**：周围神经（对称性手套袜套样感觉减退、疼痛）、自主神经（胃肠、心血管、泌汗异常）。

**大血管病变**（动脉粥样硬化加速）：冠心病、脑卒中、外周动脉疾病。

**糖尿病足**：神经病变 + 缺血 + 感染→溃疡、坏疽——**非创伤性截肢首位原因**。

**易错点｜微血管 vs 大血管病变**：微血管（视网膜、肾、神经——**糖尿病特有**）与大血管（心脑外周——与高血压高血脂共同加速）要分清。治疗并发症的关键是**「血糖达标 + 降压降脂 + 筛查」三管齐下**，单独控糖不能完全阻止大血管病变。

## 3 糖尿病的治疗

### 五驾马车

1. **糖尿病教育**：患者自我管理是基石。
2. **饮食治疗**：总热量控制、均衡营养、少糖少油——基础中的基础。
3. **运动治疗**：有氧运动改善胰岛素敏感性。
4. **血糖监测**：自我监测（指尖）、HbA1c（每 3 个月，反映 2–3 个月平均血糖）。
5. **药物治疗**：

**口服药**：
**二甲双胍**：T2DM 一线首选——减少肝糖输出、改善胰岛素抵抗，不增加低血糖。
**磺脲类**：促进胰岛素分泌（格列本脲等）——注意低血糖风险。
**DPP-4 抑制剂 / SGLT2 抑制剂**：SGLT2 抑制（达格列净）排糖利尿，兼心肾保护。
**GLP-1 受体激动剂**：降糖 + 减重 + 心血管获益。

**胰岛素**：T1DM 必须；T2DM 口服药失效、急性并发症、围手术期等使用。

**易错点｜低血糖 vs 高血糖**：治疗中最危险的是**低血糖**（<3.9 mmol/L）——心悸、出汗、震颤、意识障碍，可致昏迷死亡。低血糖的处理「先升糖再查因」：立即进食糖水/葡萄糖，清醒后复测。**「低血糖比高血糖更致命」**是糖尿病教育的头号警句。

## 4 甲状腺疾病：甲亢与甲减

### 甲状腺功能亢进症（甲亢）

**甲状腺功能亢进症（hyperthyroidism）**：甲状腺激素分泌过多。最常见病因为 **Graves 病**（自身免疫：TSH 受体抗体刺激甲状腺）。

**Graves 病三主征**：**高代谢症候群 + 甲状腺肿大 + 突眼**。

**高代谢**：怕热多汗、心悸、体重下降、食欲亢进、易激动、手颤、便次增多。
**甲状腺肿**：弥漫性对称肿大、质软、可闻及**血管杂音**。
**突眼**：浸润性突眼（眼球突出、眼睑水肿、复视）。

**实验室**：TSH ↓↓（最敏感）、FT3/FT4 ↑↑、TSH 受体抗体（TRAb）阳性。

**治疗三法**：
1. **抗甲状腺药物（ATD）**：甲巯咪唑、丙硫氧嘧啶——一线，疗程 1.5–2 年；注意**粒细胞缺乏**副作用（发热咽痛须查血常规）。
2. **放射性碘（¹³¹I）**：破坏甲状腺组织——简便，但多数最终甲减。
3. **手术**：甲状腺次全切除。

**易错点｜甲亢危象**：感染、应激诱发的**甲亢危象**——高热 >39℃、心动过速、烦躁、谵妄、呕吐腹泻，死亡率高。处理：抗甲状腺药 + 碘剂 + β 阻滞剂 + 糖皮质激素 + 对症降温。

### 甲状腺功能减退症（甲减）

**甲状腺功能减退症（hypothyroidism）**：甲状腺激素分泌不足。最常见原因为**自身免疫性甲状腺炎（桥本甲状腺炎）**。

**低代谢表现**：怕冷乏力、嗜睡、体重增加、便秘、皮肤干燥、**黏液性水肿**（非凹陷性）、反应迟钝、心率减慢。
**实验室**：TSH ↑↑（最敏感）、FT4 ↓↓。
**治疗**：**左甲状腺素（优甲乐）终身替代**；老年与冠心病患者小剂量起始。

**易错点｜黏液性水肿昏迷**：重症甲减的终末状态——低体温、昏迷、呼吸抑制，死亡率高。**甲减 vs 甲亢的症状几乎镜像**：一个怕冷一个怕热、一个便秘一个腹泻、一个心率慢一个心率快——「对照记忆」是最有效的学习方法。

### 甲状腺结节与甲状腺癌

甲状腺结节：触诊检出率 4%–7%，**超声检出率 20%–70%**，其中 **5%–10% 为恶性**。<span class="marginnote">甲状腺结节的评估看「TI-RADS 超声分级」：低回声、实性、微钙化、纵横比>1、边界不清——恶性特征越多分级越高，高度怀疑者做<strong>细针穿刺细胞学（FNA）</strong>。甲状腺癌多数（乳头状癌）预后极好，被称为「最温柔的癌症」。</span>

甲状腺癌分类：**乳头状癌**（最常见、预后最好）、滤泡状癌、髓样癌（RET 基因）、未分化癌（极差）。

## 5 公式解析：胰岛素抵抗与 HOMA-IR

评估胰岛素抵抗程度的经典指标是 **HOMA-IR**：

$$
\text{HOMA-IR} = \frac{\text{空腹胰岛素（μU/mL）} \times \text{空腹血糖（mmol/L）}}{22.5}
$$

拆解：

- **空腹胰岛素**：机体为维持正常血糖需要分泌的胰岛素量。
- **空腹血糖**：稳态血糖水平。
- **乘积除以 22.5**：归一化常数（正常人该值约 1）。
- **HOMA-IR >1**：提示胰岛素抵抗——血糖正常但需要「加倍努力」分泌胰岛素才能压住。

**直觉**：胰岛素抵抗 = 同样量的胰岛素降糖效果变差，于是身体分泌更多胰岛素代偿（高胰岛素血症）。HOMA-IR 把「血糖与胰岛素」这对互相博弈的量压缩成一个「抵抗指数」——高血糖而胰岛素不低，说明抵抗存在。<span class="marginnote">HOMA-IR 是「稳态模型」的产物：它假设空腹时肝脏糖输出与胰岛素分泌处于平衡，用一个快照数据估计全身胰岛素敏感性。这个「稳态假设 → 简化模型 → 单指数」的思路，与经济学里的均衡分析、与系统辨识里的模型拟合是同一类方法。</span>

## 6 小结

- 内分泌 = 激素 + 受体 + **负反馈**；疾病无非亢进、减退、抵抗三态。
- 糖尿病诊断：空腹 ≥7.0、OGTT 2h ≥11.1、随机 ≥11.1 + 症状、HbA1c ≥6.5%。
- **T1 胰岛素绝对缺乏（必须胰岛素）vs T2 胰岛素抵抗 + 相对不足（口服药可行）**。
- 糖尿病急性并发症（DKA、HHS）+ 慢性并发症（微血管：视网膜/肾/神经；大血管：心脑外周）。
- 甲亢（Graves 病）三主征：高代谢 + 甲状腺肿 + 突眼；甲减与甲亢症状镜像；甲亢危象、黏液水肿昏迷是急症。
- 治疗五驾马车；二甲双胍一线；**低血糖比高血糖更致命**；HOMA-IR 量化胰岛素抵抗。
