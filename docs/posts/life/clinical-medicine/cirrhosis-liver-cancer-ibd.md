## 为什么肝病需要「并发症思维」

肝脏是人体最大的实质器官，也是唯一有强大再生能力的脏器——正因如此，**慢性肝病可以在毫无症状的情况下进展多年，直到肝功能储备崩溃才以并发症的形式爆发**。肝硬化、肝癌正是这条「沉默之路」的终点站。<span class="marginnote">肝病学习有一个独特的方法论：用「功能」统领「形态」——黄疸（胆红素代谢）、腹水（白蛋白合成 + 门脉压力）、肝性脑病（氨解毒）、出血（凝血因子合成）。每一项症状都指向肝脏的一项具体功能，理解功能就理解了并发症。</span>

本篇同时覆盖**炎症性肠病**（克罗恩病与溃疡性结肠炎）——它代表消化系统的「自身免疫/慢性炎症」维度，与肝病的「纤维化-癌变」维度互为补充。

## 1 肝硬化：从纤维化到假小叶

**肝硬化（cirrhosis）**：各种慢性肝病发展的晚期阶段，以**肝细胞弥漫性坏死、再生结节形成、纤维组织弥漫增生**为特征，正常肝结构被破坏、代之以无正常功能的**假小叶**。

### 病因

1. **病毒性肝炎**：乙肝（HBV）、丙肝（HCV）——我国最常见病因。
2. **酒精性肝病**：长期大量饮酒。
3. **非酒精性脂肪性肝病（NAFLD）**：肥胖、代谢综合征。
4. **胆汁淤积性**：原发性胆汁性胆管炎。
5. **其他**：药物、自身免疫性肝炎、遗传代谢病（血色病、Wilson 病）。

### 临床表现：代偿期 vs 失代偿期

- **代偿期**：症状轻微，可有乏力、食欲减退、腹胀——肝功能储备仍可维持。
- **失代偿期**：肝功能减退 + 门脉高压两大症候群。

**肝功能减退的表现**：
- 全身：消瘦、乏力、面色晦暗（肝病面容）。
- 消化：食欲减退、腹胀、恶心。
- 出血倾向：牙龈出血、皮肤瘀斑（凝血因子合成减少 + 脾亢致血小板减少）。
- 内分泌紊乱：男性乳房发育、睾丸萎缩（雌激素灭活减少）；女性月经失调；蜘蛛痣、肝掌。

**门脉高压的表现**：
- **腹水**：门脉高压 + 低白蛋白血症 + 醛固酮增多——**肝硬化最突出的表现**。
- **侧支循环开放**：食管胃底静脉曲张（破裂出血是致命并发症）、腹壁静脉曲张（脐周海蛇头样）、痔静脉曲张。
- **脾大 + 脾功能亢进**：全血细胞减少（白细胞、血小板、红细胞下降）。

**易错点｜蜘蛛痣与肝掌的机制**：肝硬化时肝脏对雌激素灭活减少，血中雌激素升高→小动脉扩张→蜘蛛痣（上腔静脉引流区，颈部、前胸）、肝掌（大鱼际、小鱼际发红）。**这些是「内分泌紊乱」的表现，不是门脉高压的表现**——别把体征归错机制。

### 并发症

| 并发症 | 表现 | 机制 |
| --- | --- | --- |
| **上消化道出血** | 呕血黑便、休克 | 食管胃底静脉曲张破裂 |
| **肝性脑病** | 意识障碍、扑翼样震颤 | 氨等毒性物质入脑 |
| **自发性细菌性腹膜炎** | 发热、腹痛、腹水浑浊 | 肠菌移位感染腹水 |
| **肝肾综合征** | 少尿、无尿、肾衰 | 肾血管收缩、有效循环不足 |
| **肝肺综合征** | 低氧、杵状指 | 肺内血管扩张 |
| **肝癌** | 肝大、AFP 升高 | 肝硬化→肝癌级联 |
| **电解质紊乱** | 低钠低钾 | 利尿、醛固酮增多 |

**肝性脑病（hepatic encephalopathy）**值得单独注意：血氨升高（肝脏尿素循环障碍）→ 氨入脑 → 神经递质紊乱 → **意识障碍、性格改变、扑翼样震颤**。诱因：上消化道出血（肠内血液分解产氨）、高蛋白饮食、便秘、感染、利尿过度（低钾碱中毒）。<span class="marginnote">肝性脑病的诱因处理比治疗本身更重要：<strong>先止血、禁蛋白、通便（乳果糖酸化肠道减少氨吸收）、纠正电解质</strong>——「处理诱因」往往就能逆转脑病。这体现了危重病医学里「找诱因」的思维方式。</span>

## 2 原发性肝癌

**原发性肝癌（hepatocellular carcinoma, HCC）**：肝细胞或肝内胆管细胞发生的恶性肿瘤，我国最常见的恶性肿瘤之一。

**危险因素**：**慢性乙肝/丙肝、肝硬化、黄曲霉毒素、酒精、肥胖脂肪肝**——「乙肝 → 肝硬化 → 肝癌」三部曲是核心路径。

### 临床表现

- **早期**：常无症状，靠筛查发现（高危人群定期超声 + AFP）。
- **中晚期**：**肝区疼痛**（持续性胀痛）、**肝大质硬**（进行性肿大、表面结节）、黄疸、腹水、消瘦乏力、发热。

### 诊断

- **血清标志物**：**AFP（甲胎蛋白）>400 ng/mL 且持续升高**——高度提示 HCC。
- **影像**：超声（筛查）、增强 CT/MRI（动脉期强化、静脉期「快速快出」的典型血供特征）。
- **病理**：肝穿刺活检——确诊金标准。

**诊断标准**：影像学典型表现 + AFP 升高（或两项影像学检查均典型），临床即可诊断；不确定时活检。

### 治疗

- **手术切除**：早期、肝功能代偿良好者首选——唯一可能根治的手段。
- **肝移植**：符合米兰标准的早期肝癌。
- **局部消融**：射频消融（RFA）、无水酒精注射——小肝癌。
- **介入治疗（TACE）**：肝动脉化疗栓塞——中晚期肝癌的常用姑息手段。
- **靶向 + 免疫**：仑伐替尼、索拉非尼、PD-1 抑制剂。
- **预防**：乙肝疫苗（一级预防——肝癌是少数「可疫苗预防」的癌症）、抗病毒治疗、防霉变、戒酒。

**易错点｜AFP 升高的鉴别**：AFP 升高 ≠ 肝癌——活动性肝炎、肝硬化活动期、妊娠、生殖细胞肿瘤也可升高。**动态监测 + 影像学结合**才能下结论；同时约 30% 的 HCC 患者 AFP 正常，不能因 AFP 正常排除肝癌。

## 3 炎症性肠病（IBD）

**炎症性肠病（inflammatory bowel disease）**：一组原因未明的**慢性非特异性肠道炎症**，主要包括**溃疡性结肠炎（UC）**与**克罗恩病（CD）**。

### 溃疡性结肠炎 vs 克罗恩病

| 特征 | 溃疡性结肠炎（UC） | 克罗恩病（CD） |
| --- | --- | --- |
| 病变部位 | **结肠黏膜层**，直肠开始向近端连续蔓延 | **全消化道**（口→肛），回肠末端最常见，节段性、跳跃性 |
| 病变深度 | 黏膜层及黏膜下层 | **全层**（透壁性） |
| 内镜表现 | 连续弥漫、充血糜烂、溃疡、假息肉 | 纵行溃疡、鹅卵石样改变 |
| 主要症状 | **黏液脓血便**、腹泻、里急后重 | **腹痛**、腹泻、腹部包块、瘘管 |
| 并发症 | 中毒性巨结肠、癌变 | **瘘管、肠梗阻**、肛周病变 |
| 癌变风险 | 病程长者增高 | 相对较低 |

**易错点｜UC 与 CD 的「全或无」鉴别**：UC 是「结肠 + 黏膜层 + 连续 + 血便」；CD 是「全消化道 + 全层 + 节段 + 瘘管梗阻」。记住：**UC 局限在结肠黏膜（像皮肤病），CD 穿透肠壁（像贯穿伤）**——一个表浅连续、一个深层跳跃。

### 诊断与治疗

**诊断**：结肠镜 + 活检（金标准）——内镜下病变特征 + 病理。

**治疗（阶梯式）**：
1. **氨基水杨酸制剂**（美沙拉嗪）：轻中度 UC 一线。
2. **糖皮质激素**：中重度急性期诱导缓解。
3. **免疫抑制剂**：硫唑嘌呤、甲氨蝶呤——激素依赖/难治者。
4. **生物制剂**：抗 TNF-α（英夫利西单抗）、抗整合素等——中重度 CD/UC 的重要武器。
5. **手术**：UC 全结肠切除可根治；CD 手术只解决并发症（梗阻、瘘管）——**CD 术后易复发**，手术非根治。<span class="marginnote">UC 病变限于结肠黏膜，切掉结肠就能「根治」；CD 病变弥漫于全消化道，切除病灶后其他部位仍会发病——「可根治 vs 不可根治」的差别来自病变的分布范围，这也是治疗决策的底层逻辑。</span>

## 4 公式解析：Child-Pugh 肝功能评分

肝硬化的严重程度与手术/预后评估，用 **Child-Pugh 评分**量化：

$$
\text{Child-Pugh 总分} = A + B + C + D + E
$$

五项指标，每项 1–3 分：

- **A 肝性脑病**：无（1）、1–2 级（2）、3–4 级（3）
- **B 腹水**：无（1）、轻度（2）、中重度（3）
- **C 总胆红素（μmol/L）**：<34（1）、34–51（2）、>51（3）
- **D 白蛋白（g/L）**：>35（1）、28–35（2）、<28（3）
- **E 凝血酶原时间延长（秒）**：<4（1）、4–6（2）、>6（3）

**分级**：A 级 5–6 分（代偿良好）、B 级 7–9 分、C 级 10–15 分（失代偿、预后差）。Child-Pugh C 级是肝移植的主要指征之一，也是手术风险的重要评估工具。<span class="marginnote">Child-Pugh 是「用几项易测的指标加权求和，量化一个系统功能储备」的评分——与房颤的 CHA₂DS₂-VASc、ICU 的 APACHE 评分同一家族。它们本质都是「临床机器学习」：从历史数据中找出预测结局的变量，编成一张可手算的计分卡。现代已发展出 MELD 评分（连续变量、更精确，用于肝移植分配）。</span>

## 5 小结

- 肝硬化 = 肝功能减退 + 门脉高压；**假小叶**是病理标志，**腹水**是最突出表现。
- 门脉高压三表现：**腹水、侧支循环（食管静脉曲张）、脾大脾亢**；蜘蛛痣肝掌是雌激素灭活减少所致。
- 肝硬化并发症七连：上消化道出血、肝性脑病、自发性腹膜炎、肝肾综合征、肝肺综合征、肝癌、电解质紊乱。
- **肝癌**高危因素乙肝→肝硬化→肝癌；诊断靠 AFP + 影像「快速快出」；**可疫苗预防**。
- 炎症性肠病两兄弟：**UC**（结肠黏膜、连续、血便）vs **CD**（全层、节段、瘘管梗阻）。
- Child-Pugh 评分量化肝功能储备，指导预后与手术决策。
