## 为什么周围神经病与肌病「常被误诊」

周围神经病（peripheral neuropathy）与肌病（myopathy）是神经科里**表现重叠**的两大类疾病——都可能表现为**无力、麻木、萎缩**——但病变部位完全不同（神经 vs 肌肉）。鉴别它们靠**肌力分布模式 + 肌电图/肌酶**——**「无力是神经的还是肌肉的？」**是诊断的第一问。<span class="marginnote">周围神经病与肌病的鉴别要点：<strong>周围神经病</strong>——远端为主（手套袜套）、感觉障碍突出、腱反射减弱、肌萎缩明显、<strong>EMG 神经源性损害</strong>；<strong>肌病</strong>——近端为主（肩带骨盆带）、以无力为主感觉正常、腱反射相对保留、<strong>肌酶（CK）升高、EMG 肌源性损害</strong>。「远端+感觉=神经，近端+无力=肌肉」。</span>

本篇聚焦**多发性周围神经病（糖尿病性、吉兰-巴雷综合征）**、**面神经麻痹**与**常见肌病**（重症肌无力、周期性瘫痪）。

## 1 周围神经病总论

### 分类与临床表现

**周围神经病**：周围神经（颅神经、脊神经、自主神经）的病变。

**常见类型**：
- **多发性神经病（polyneuropathy）**：**对称性远端为主**——**手套袜套样**感觉障碍（麻木、刺痛）+ 远端肌力下降 + 腱反射减弱——糖尿病、酒精、中毒、营养缺乏（B12）。
- **单神经病（mononeuropathy）**：单一神经——腕管综合征（正中神经——拇指食指麻木、夜间加重）、面神经麻痹。
- **多发性单神经病**：多根神经先后受累。

**易错点｜糖尿病性周围神经病的「手套袜套」**：糖尿病最常见——**对称性远端感觉神经病**（足部麻木刺痛，夜间加重）——**「糖尿病足」的神经基础**；查体用 **10 g 尼龙丝试验**筛查足部保护性感觉丧失。

### 吉兰-巴雷综合征（GBS）

**吉兰-巴雷综合征（Guillain-Barré syndrome, GBS）**：**急性炎症性脱髓鞘性多神经病（AIDP）**——**自身免疫**攻击周围神经髓鞘——**「感染后急性弛缓性瘫痪」的代表**。

- **前驱**：**感染后 1–3 周**（上感、腹泻——空肠弯曲菌最常见）。
- **表现**：**对称性、进行性、上升性弛缓性瘫痪**——**从下肢向上蔓延**（足→腿→躯干→上肢→呼吸肌）；**感觉障碍较轻**（麻木感、疼痛）；**腱反射消失**。
- **危险**：**呼吸肌麻痹（呼吸衰竭）**、自主神经受累（心律失常、血压波动）。
- **诊断**：**脑脊液「蛋白-细胞分离」**（蛋白升高、细胞正常——GBS 特征）；EMG 脱髓鞘改变。
- **治疗**：**静脉免疫球蛋白（IVIG）或血浆置换**——尽早使用缩短病程；呼吸支持（机械通气）。
- **预后**：多数可恢复，但需数月；重症有后遗症。

**易错点｜GBS 的「上升性瘫痪 + 蛋白细胞分离」**：**急性弛缓性瘫痪 + 腱反射消失 + 脑脊液蛋白高细胞正常 = 想 GBS**——**与脊髓灰质炎（不对称、发热期瘫痪）、急性脊髓炎（传导束型感觉障碍、括约肌障碍）鉴别**。**「上升性软瘫 + 反射消失 = GBS，需住院监测呼吸」**。

## 2 面神经麻痹（面瘫）

**面神经麻痹（facial palsy）**：面神经（VII）损伤——**周围性面瘫**最常见（特发性面神经炎，Bell 麻痹）。

### 周围性 vs 中枢性面瘫

| 特征 | 周围性面瘫（Bell 麻痹） | 中枢性面瘫（脑卒中） |
| --- | --- | --- |
| 病变 | 面神经（同侧） | 皮质脊髓束（对侧） |
| 额纹 | **消失（抬眉不能）** | 存在（额纹保留） |
| 闭眼 | **不能（眼裂大）** | 可闭眼 |
| 口角 | 歪向健侧 | 歪向健侧 |
| 伴随 | 耳后痛、味觉减退 | **偏瘫、失语**（大脑症状） |

**易错点｜「额纹是否消失」是面瘫分类的关键**：**周围性面瘫——整个半边脸瘫（额纹消失、闭眼不能）**；**中枢性面瘫——只有下半面瘫（额纹保留、能闭眼）**——因为**额肌受双侧皮质支配**，一侧皮质损伤额肌仍能活动。**「额纹在 = 中枢性，额纹没 = 周围性」**。

### Bell 麻痹的处理

- **激素**：**尽早口服泼尼松**（48 小时内开始——改善恢复）。
- **保护角膜**：闭眼不全者——眼膏、眼罩（防角膜炎）。
- 多数 3 周–3 月恢复；部分留后遗症。

## 3 肌病总论与常见肌病

**肌病（myopathy）**：骨骼肌本身的疾病——**近端无力为主、无感觉障碍**。

### 重症肌无力（MG）

**重症肌无力（myasthenia gravis, MG）**：**自身免疫**攻击**神经肌肉接头突触后膜乙酰胆碱受体（AChR）**——神经冲动无法有效传递给肌肉。

**核心特征——「病态疲劳 + 晨轻暮重」**：
- **波动性肌无力**：**活动后加重、休息后缓解**。
- **晨轻暮重**：早晨好、傍晚差。
- **眼肌最先受累**：**上睑下垂、复视**（眼肌型 MG——最常见首发）。
- 可累及延髓肌（吞咽、构音）、四肢肌、**呼吸肌（肌无力危象——危及生命）**。

**诊断**：**新斯的明试验**（注射后症状改善）、**AChR 抗体**阳性、重复电刺激（递减）。

**治疗**：**胆碱酯酶抑制剂（溴吡斯的明）**、免疫抑制（激素、硫唑嘌呤）、胸腺切除（胸腺瘤相关）、**肌无力危象——IVIG/血浆置换 + 呼吸支持**。

**易错点｜MG vs 其他肌无力**：**MG 是「波动性」肌无力（晨轻暮重、劳累加重）**——与周期性瘫痪（突发双下肢瘫）、肌营养不良（进行性、近端萎缩）不同。**「上睑下垂 + 复视 + 晨轻暮重 = 想 MG」**。

### 周期性瘫痪（低钾性）

**周期性瘫痪（periodic paralysis）**：**阵发性弛缓性瘫痪**——**低钾性**（最常见，亚洲男性多见）——大量进食碳水化合物、剧烈运动、受凉后**突发对称性四肢无力**（近端为主）、血钾降低。

**治疗**：补钾（口服/静脉）；**预防**：避免诱因（高碳水、过劳）、长期补钾。

## 4 小结

- **周围神经病**：远端 + 感觉障碍（手套袜套）+ 反射减弱 + EMG 神经源性。
- **肌病**：近端 + 无力为主（无感觉障碍）+ CK 升高 + EMG 肌源性。
- **糖尿病性周围神经病**：足部麻木刺痛；**10 g 尼龙丝试验**筛查「糖尿病足」。
- **GBS**：感染后**上升性弛缓性瘫痪** + 腱反射消失 + **蛋白-细胞分离**——**IVIG/血浆置换 + 呼吸监测**。
- **面瘫**：**「额纹在 = 中枢性、额纹没 = 周围性」**——Bell 麻痹尽早激素。
- **重症肌无力**：**波动性无力（晨轻暮重）+ 上睑下垂复视 + AChR 抗体**——溴吡斯的明 + 免疫抑制；**肌无力危象需呼吸支持**。
- **周期性瘫痪（低钾）**：突发对称性四肢无力 + 血钾低——补钾 + 避免诱因。

**补充｜腕管综合征（最常见的单神经病）**：**正中神经在腕管受压**——**拇指、食指、中指麻木 + 夜间麻醒 + 甩手缓解**（Phalen 试验、Tinel 征阳性）——好发于**中年女性、长期腕部劳作、妊娠期**——治疗：**护腕制动、局部激素、严重者手术减压（腕管松解）**——「夜间麻醒、甩手好转 = 腕管综合征的经典信号」。

**补充｜GBS 的住院监测要点**：**GBS 必须住院**——监测**肺活量（VC）**（<20 mL/kg 需机械通气预警）、**吞咽功能**（防误吸）、**心率血压**（自主神经受累可致心律失常、血压波动）——**「上升性瘫痪过了腰，就要随时准备呼吸支持」**——「GBS 的凶险不在瘫痪本身，而在呼吸与自主神经并发症」。

临床速记｜「无力三问」：一问分布（远端 vs 近端）、二问感觉（有无麻木疼痛）、三问波动（晨轻暮重 vs 恒定）——远端+感觉=周围神经病、近端+无力=肌病、波动性=重症肌无力。三问把鉴别诊断浓缩成一张流程图。

再记一笔｜糖尿病足的「三级防护」：每天洗脚检查（看破溃）、穿合脚软鞋（防挤压）、定期尼龙丝检查（测保护性感觉）——「脚是糖尿病患者的第二生命」。
