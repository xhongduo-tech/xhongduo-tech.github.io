## 为什么儿童血液病「从贫血到白血病」

儿科血液系统疾病谱：**营养性缺铁性贫血**（最常见——营养问题）、**营养性巨幼细胞性贫血**（叶酸/B12）、**溶血性贫血**（地中海贫血、G6PD）、**再生障碍性贫血**、**白血病**（最常见儿童恶性肿瘤）。这条谱系从「营养缺乏」到「恶性增殖」，覆盖了血液病的全部机制。<span class="marginnote">儿童贫血的「营养主线」是儿科特色：<strong>快速生长对造血原料（铁、叶酸、B12）的需求高峰 + 辅食不足</strong>——所以儿童贫血绝大多数是「吃出来的」。而白血病是「造血干细胞的恶性克隆」——需要骨髓穿刺确诊、化疗为主。</span>

本篇聚焦**营养性缺铁性贫血**（儿童贫血代表）与**儿童白血病**（最常见儿童恶性肿瘤），并提及其他血液病。

## 1 营养性缺铁性贫血（IDA）

**营养性缺铁性贫血**：儿童最常见贫血——**6 月–2 岁高发**。

### 病因

1. **先天储铁不足**：早产儿、低出生体重（胎儿期储铁少）、双胎。
2. **铁摄入不足**：**辅食添加过晚/不足**（母乳 4–6 月后铁不足）、偏食。
3. **铁需求增加**：**生长迅速**（婴幼儿血容量扩大快）。
4. **铁丢失**：慢性失血（牛奶蛋白过敏致肠出血）。

### 临床表现

- **一般**：面色苍白（口唇、指甲）、乏力、易激惹、食欲减退。
- **髓外造血**：肝脾轻度肿大（代偿）。
- **神经**：注意力不集中、**异食癖**（吃泥土、墙皮）。
- **循环**：心率快、心脏扩大（重度贫血）。

### 实验室

- **血常规**：**小细胞低色素性贫血**（MCV↓、MCH↓、MCHC↓）、红细胞中央淡染区扩大。
- **铁代谢**：**血清铁蛋白↓**（铁储备不足——最敏感）、血清铁↓、总铁结合力↑。
- **鉴别**：小细胞低色素还见于**地中海贫血**（轻型——Hb 电泳鉴别）。

**易错点｜缺铁性贫血 vs 地中海贫血**：两者都小细胞低色素——缺铁（铁蛋白↓、补铁有效）；**地中海贫血（铁蛋白正常或高、Hb 电泳异常、补铁无效）**。**「补铁无效的小细胞低色素，要想到地中海贫血」**（尤其南方地区）。

### 治疗与预防

- **治疗**：**口服铁剂（元素铁 2–6 mg/kg/天）+ 维生素 C**；疗程——**Hb 正常后继续补铁 6–8 周**（补足储存铁）。铁剂治疗 2 周后网织红细胞上升（有效指标）。
- **预防**：**母乳喂养 + 满 6 月铁强化辅食**；早产儿 2 周龄起预防性补铁；定期儿保健筛查。

**易错点｜「补铁要补到储存铁」**：贫血纠正（Hb 正常）≠ 铁储备恢复——**Hb 正常后仍需继续补铁 6–8 周**以补足铁蛋白储存——「**好了还要再吃两个月**」防止复发。

## 2 营养性巨幼细胞性贫血

叶酸或维生素 B12 缺乏——**大细胞性贫血（MCV↑）**。

- **病因**：辅食添加过晚、单纯母乳（母亲素食）、长期羊奶喂养（叶酸低）。
- **表现**：面色蜡黄、虚胖、**神经系统症状**（B12 缺乏——精神差、反应迟钝、震颤、发育倒退）。
- **治疗**：叶酸 + 维生素 B12；**B12 缺乏的神经症状不能单用叶酸纠正**（会加重）。

## 3 儿童白血病

**儿童白血病**：**儿童最常见的恶性肿瘤**（约占儿童恶性肿瘤 1/3）——**急性淋巴细胞白血病（ALL）占 75% 以上**。

### 急性淋巴细胞白血病（ALL）

**ALL**：淋巴系原始细胞恶性增殖。

**临床表现**（贫血 + 出血 + 感染 + 浸润）：
- **贫血**：苍白、乏力。
- **出血**：皮肤瘀点瘀斑、鼻衄（血小板减少）。
- **感染/发热**：不明原因发热（粒细胞缺乏）。
- **浸润**：**肝脾淋巴结肿大、骨痛（可表现为「不愿走路/跛行」）、胸骨压痛**。
- **中枢浸润**：头痛、呕吐（脑膜白血病）。

**易错点｜「儿童腿痛不走路」的多重鉴别**：**学龄前儿童腿痛/跛行**——可能是生长痛、髋关节滑膜炎、**也可能是白血病骨浸润或神经母细胞瘤**。**「不明原因发热 + 面色差 + 骨痛 + 肝脾大 = 查血常规（原始细胞）+ 骨髓穿刺」**——白血病骨痛与外伤无关、夜间明显。

### 诊断

- **血常规**：白细胞可高/低/正常、**原始细胞可见**、贫血、血小板减少。
- **骨髓穿刺（金标准）**：原始细胞 ≥25%——确诊；免疫分型（B 系/T 系）、染色体/基因（危险分层）。
- **腰穿**：评估中枢神经系统浸润。

### 治疗（化疗为主）

1. **化疗**：**诱导缓解 → 巩固强化 → 维持治疗**——ALL 以长春新碱、泼尼松、门冬酰胺酶等方案。
2. **中枢预防**：鞘内化疗 + 放疗（防脑膜复发）。
3. **造血干细胞移植**：高危/复发者。
4. **支持治疗**：输血、抗感染、防出血、防肿瘤溶解综合征。

**预后**：**儿童 ALL 治愈率已达 80%–90%**——**儿童白血病是「最可能治愈的恶性肿瘤之一」**——「儿童白血病 ≠ 绝症」。

## 4 其他儿童血液病

### 特发性血小板减少性紫癜（ITP）

**ITP**：免疫性血小板破坏——**儿童最常见出血性疾病**。

- **表现**：**皮肤瘀点瘀斑、鼻衄、牙龈出血**（血小板 <100×10⁹/L），无肝脾淋巴结肿大，一般情况好。
- **发病**：多在前驱感染后（病毒感染→免疫紊乱→抗血小板抗体）。
- **治疗**：多数**自限性**（数月内缓解）；出血明显——丙种球蛋白、糖皮质激素；**重症出血（颅内出血）——急诊处理**。

**易错点｜ITP vs 白血病**：ITP——**只有血小板减少**（白细胞红细胞正常）、**无肝脾大**、一般情况好；白血病——**全血细胞减少 + 肝脾大 + 发热骨痛**。**「单纯血小板减少 + 一般情况好 = 先想 ITP」**（但需骨髓检查排除白血病等）。

### 血友病

**血友病（hemophilia）**：X 连锁隐性遗传——**凝血因子 VIII（血友病 A）/IX（血友病 B）缺乏**——**男性发病、女性携带**。

- **表现**：**自幼反复关节出血（血友病性关节病）、肌肉血肿、外伤后出血不止**。
- **诊断**：**APTT 延长、因子活性降低**。
- **治疗**：**补充凝血因子（Ⅷ/Ⅸ）替代治疗**；预防（规律输注）、止痛、关节保护。
- **易错点｜血友病禁用**：**阿司匹林、非甾体抗炎药（抑制血小板）**；肌注慎用；**「血友病患儿出血，首选补因子而不是压迫止血」**。

## 5 小结

- 儿童贫血以**营养性缺铁**最多——「6 月–2 岁、辅食不足」。
- 缺铁性贫血：**小细胞低色素 + 铁蛋白↓**；**补铁至 Hb 正常后再补 6–8 周**（补储存铁）。
- **缺铁 vs 地中海贫血**：补铁无效的小细胞低色素要查 Hb 电泳。
- 巨幼细胞性贫血：大细胞性贫血；**B12 缺乏的神经症状不能单用叶酸**。
- **儿童白血病 = ALL 为主**：贫血 + 出血 + 感染 + 肝脾大 + 骨痛；**骨髓穿刺确诊**。
- **儿童 ALL 治愈率 80%–90%**——化疗为主、非绝症。
- **ITP**：单纯血小板减少、一般情况好、多自限；血友病：X 连锁、**关节出血、补因子治疗、禁用阿司匹林**。
