## 为什么循环系统从高血压讲起

循环系统是内科学的另一大主战场，而高血压是其中最「基础」的疾病——它既是独立的病，又是心梗、脑梗、肾衰、心衰的**上游危险因素**，被称为「无声的杀手」。<span class="marginnote">中国成人高血压患病率约 27.5%，即每 4 个成人中约有 1 人患高血压，而知晓率、治疗率、控制率均不高。「三率」是流行病学与公共卫生的经典指标，见第五级《公共卫生与预防医学》。</span>

高血压还自带一个贯穿循环系统全篇的核心公式——**血压 = 心输出量 × 外周阻力**。读懂这个公式，就拿到了理解高血压病、心衰、休克、甚至瓣膜病的钥匙。它是整个循环系统篇章的「牛顿第二定律」。

## 1 循环系统总论：压力与流量的工程学

### 血液循环的泵-管-阻模型

循环系统是一个闭合的流体回路：

**泵**：心脏（右心泵肺循环、左心泵体循环）。
**管道**：动脉（弹性储器）、毛细血管（交换场所）、静脉（容量血管，容纳约 60%–70% 血量）。
**阻力**：小动脉与微动脉（外周阻力主要来源）。

**血压形成的三要素**：心脏射血（心输出量）、外周血管阻力、动脉壁弹性。**收缩压**反映心脏射血与大动脉弹性，**舒张压**反映外周阻力大小。

### 循环系统疾病总览

循环系统疾病按病位分：**血管病**（高血压、冠心病、动脉硬化）、**心脏结构病**（瓣膜病、先心病）、**心肌病**（扩张型/肥厚型心肌病）、**心衰**、**心律失常**。本篇先讲高血压，后续讲冠心病、心衰与心律失常。

### 心功能的量化

**心输出量（cardiac output）**与**射血分数（ejection fraction, EF）**是心功能的两个核心指标：

$CO = HR \times SV$——每分钟泵血量。
$EF = SV / \text{舒张末期容积}$——每次心跳泵出舒张期容积的百分比，正常 ≥50%。

EF 是超声心动图最常用的收缩功能指标——心衰患者 EF 下降（射血分数降低的心衰 HFrEF）。

## 2 高血压病的定义与分级

**高血压（hypertension）**：以体循环动脉压升高为主要表现的心血管综合征。**原发性高血压**（占 90%–95%，原因不明）与**继发性高血压**（占 5%–10%，由肾、内分泌等明确病因引起）之分是临床第一道选择题。

### 血压水平分类（中国高血压防治指南）

| 分类 | 收缩压（mmHg） | 舒张压（mmHg） |
| --- | --- | --- |
| 正常血压 | <120 且 <80 | |
| 正常高值 | 120–139 和/或 80–89 | |
| 1 级高血压（轻度） | 140–159 和/或 90–99 | |
| 2 级高血压（中度） | 160–179 和/或 100–109 | |
| 3 级高血压（重度） | ≥180 和/或 ≥110 | |
| 单纯收缩期高血压 | ≥140 且 <90 | |

**诊断要点**：在**非同日三次**测量，收缩压 ≥140 mmHg 和/或舒张压 ≥90 mmHg 即可诊断（排除应激、白大衣高血压等）。

**易错点｜一次测量 ≠ 诊断**：单次血压升高不诊断高血压——需非同日多次复测、排除白大衣效应（诊室测量升高而家庭自测正常）。家庭自测血压与动态血压监测能提供更真实的血压曲线。

### 危险分层与靶器官损害

高血压的危害不在血压数值本身，而在**心、脑、肾、血管**等靶器官损害：

**心脏**：左心室肥厚（压力负荷导致向心性肥厚）、冠心病、心衰。
**脑**：脑出血、脑梗死（腔隙性梗死）、短暂性脑缺血发作。
**肾脏**：高血压肾病（蛋白尿、肾小球硬化）、肾衰。
**血管**：主动脉夹层、动脉粥样硬化。

**危险分层**综合血压水平 + 危险因素（吸烟、血脂、血糖、肥胖）+ 靶器官损害，分为低危、中危、高危、很高危——**分层决定治疗启动的积极程度**。

## 3 发病机制

原发性高血压是多因素疾病，机制复杂，核心围绕「升高血压的三大杠杆」：

**肾素-血管紧张素-醛固酮系统（RAAS）激活**：肾素→血管紧张素 I→血管紧张素 II（强缩血管 + 促醛固酮分泌保钠）。<span class="marginnote">RAAS 是高血压与心衰治疗的「主靶点」：ACEI（普利类）、ARB（沙坦类）、醛固酮拮抗剂（螺内酯）都是阻断这条通路的药物。理解 RAAS 的每一环，就能理解一整类降压药的机制与副作用。</span>
- **交感神经系统过度激活**：儿茶酚胺升高，心率增快、血管收缩。
- **钠潴留与容量扩张**：钠摄入过多→血容量增加→血压升高（盐敏感性高血压）。

此外还有：血管内皮功能障碍（一氧化氮减少）、胰岛素抵抗、遗传因素。**肥胖、高盐、饮酒、缺乏运动、精神应激**是主要的环境危险因素。

## 4 公式解析：血压的「泵 × 阻」模型

高血压的定量理解建立在血流动力学基本方程上：

$$
BP = CO \times TPR
$$

拆解：

- **$BP$（血压）**：平均动脉压（MAP）≈ 舒张压 + 1/3（收缩压 − 舒张压）。
- **$CO$（心输出量）**：$CO = HR \times SV$——每分钟泵血量。
- **$TPR$（总外周阻力）**：小动脉、微动脉对血流的阻力，主要取决于血管半径：$R \propto 1/r^4$（Poiseuille 定律）。

**关键推论**：血压升高的两种工程学来源——**「流量型」**（心输出量升高，如年轻高血压早期、甲亢、运动）与**「阻力型」**（外周阻力升高，如老年高血压、血管硬化）。这也解释了两类降压药的针对性：β 受体阻滞剂降心率/心输出量，钙拮抗剂、RAAS 阻断剂扩血管降阻力。<span class="marginnote">Poiseuille 定律 $R \propto 1/r^4$ 意味着：血管半径缩小 10%，阻力升高约 46%——小血管管径的微小变化对血压影响巨大。这就是为什么「管好血管」比「管好血流」更能解释慢性高血压的维持机制。</span>

## 5 治疗与并发症

### 治疗原则

1. **生活方式干预是基石**：限盐（<6 g/天）、控制体重、戒烟限酒、规律运动（有氧为主）、心理平衡、充足睡眠。
2. **药物治疗**：五大类一线降压药——**ACEI/ARB（普利/沙坦）、钙通道阻滞剂（CCB，地平类）、β 受体阻滞剂（洛尔类）、利尿剂（噻嗪类）**。<span class="marginnote">常用降压药按机制分四大家族：普利/沙坦（抑制 RAAS）、地平类（扩血管）、洛尔类（减慢心率）、噻嗪类（利尿排钠）。选药策略：合并心衰选 ACEI/ARB+β 阻滞剂，合并冠心病选 β 阻滞剂/CCB，老年单纯收缩期高压选 CCB/利尿剂。</span>
3. **联合用药**：2 级及以上或高危患者常需两药联用，机制互补。
4. **目标血压**：一般 <140/90 mmHg；能耐受者进一步 <130/80 mmHg；老年患者个体化放宽。

### 高血压急症

**高血压急症**：血压急剧升高（通常 >180/120 mmHg）伴急性靶器官损害（脑、心、肾）。需**静脉降压、分秒必争**：高血压脑病、脑出血、急性左心衰、主动脉夹层。原则——**急剧的血压升高 + 器官损害 = 急诊，立即静脉用药控制血压**，但不可骤降（脑血流自主调节）。

**易错点｜高血压急症 vs 高血压亚急症**：无急性靶器官损害、仅血压重度升高（无症状或轻微症状）为**亚急症**——口服药调整、门诊处理即可；有器官损害才是**急症**。区分标准是「有没有正在发生的器官损伤」，而非血压数值本身。

## 6 小结

- 循环系统核心模型：**血压 = 心输出量 × 外周阻力**；心功能看心输出量与射血分数 EF。
- **高血压诊断**：非同日三次血压 ≥140/90 mmHg；分 1–3 级，危险分层决定治疗强度。
- 继发性高血压（5%–10%）要识别可治愈病因（肾性、内分泌性等）。
- 靶器官：**心、脑、肾、血管**；左室肥厚、脑出血、蛋白尿是典型损害。
- 治疗基石是**生活方式干预 + 五类一线降压药**；按合并症个体化选药。
- **高血压急症** = 血压骤升 + 急性靶器官损害，需静脉降压紧急处理。
