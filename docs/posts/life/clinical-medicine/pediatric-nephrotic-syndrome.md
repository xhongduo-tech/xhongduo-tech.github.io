## 为什么儿童肾病以「肾病综合征」为代表

儿科泌尿系统疾病以**肾小球疾病**为核心，而**肾病综合征（nephrotic syndrome, NS）**是儿童最常见的肾小球疾病之一（发病率约 2–7/10 万儿童）。它的一大特点是**病理类型与成人不同**——**儿童原发性肾病综合征约 80% 为微小病变型**，**对激素敏感**——所以「肾病综合征」在儿科有一句响亮的口号：**「激素敏感、预后良好」**。<span class="marginnote">儿童肾病综合征的治疗核心是<strong>糖皮质激素</strong>：多数患儿对激素敏感（激素敏感型 NS），2–4 周尿蛋白转阴。但约 1/3 会复发、少数激素耐药——「敏感、依赖、耐药」是肾病综合征对激素的三种反应，决定治疗策略与预后。</span>

本篇聚焦**肾病综合征**（诊断、并发症、激素治疗）与**急性肾小球肾炎**，并提及其他泌尿系统问题。

## 1 肾病综合征

**肾病综合征**：**大量蛋白尿 + 低白蛋白血症 + 水肿 + 高脂血症**——「三高一低」四大特征（见内科篇）。儿童诊断标准：**尿蛋白 >50 mg/kg/天**（或尿蛋白/肌酐 >2）+ **血浆白蛋白 <25 g/L**。

### 分类

- **原发性**（占多数）：病理多为**微小病变型**（儿童最常见）。
- **继发性**：狼疮性肾炎、过敏性紫癜肾炎、乙肝相关肾炎。
- **先天性**：出生后 3 个月内发病（遗传性）。

### 临床表现

- **水肿**：**首发与最突出症状**——眼睑、面部、下肢，**凹陷性**；重者腹水、胸水、阴囊水肿。
- **蛋白尿**：大量泡沫尿（尿蛋白 +++++）。
- **低白蛋白血症**：血浆白蛋白 <25 g/L。
- **高脂血症**：胆固醇、甘油三酯升高。
- 血压：多数正常（不同于急性肾炎——**肾病综合征以水肿蛋白尿为主，肾炎以血尿高血压为主**）。

**易错点｜肾病综合征 vs 急性肾炎**：

| 特征 | 肾病综合征 | 急性肾小球肾炎 |
| --- | --- | --- |
| 核心 | **大量蛋白尿 + 低白蛋白 + 水肿** | 血尿 + 高血压 + 水肿 |
| 水肿 | 凹陷性、全身性 | 眼睑颜面晨起 |
| 血尿 | 多无 | **有（洗肉水样）** |
| 高血压 | 多正常 | **有** |
| 前驱感染 | 多无明确 | 链球菌感染后 1–3 周 |
| 治疗 | **激素** | 休息对症（自限） |

**「肾病漏蛋白、肾炎出血压」**——一句口诀分清两大儿童肾病。

### 并发症

1. **感染**：**最常见并发症**——免疫功能低下（免疫球蛋白从尿丢失 + 激素）+ 水肿易感染（肺炎、腹膜炎）。
2. **血栓栓塞**：血液高凝（抗凝物质丢失、血液浓缩）——**肾静脉血栓**（腰痛、血尿、肾大）。
3. **电解质紊乱**：低钠、低钾、低钙。
4. **急性肾衰**：严重低血容量、利尿过度。

## 2 肾病综合征的治疗（激素为主）

### 治疗原则

1. **一般治疗**：**适度休息、低盐饮食（水肿时）、优质蛋白适量**、防治感染（**不常规预防性抗生素**但感染需积极处理）。
2. **利尿消肿**：水肿明显者——利尿剂（呋塞米）+ 白蛋白（低蛋白严重者先补白蛋白再利尿）。
3. **激素治疗（核心）**：
   - **初治方案**：**泼尼松**——足量诱导（2 mg/kg/天，≤60 mg/天，4–8 周）→ 减量维持（隔日顿服，6 个月左右）。
   - **疗效判断**：**激素敏感**（4 周内尿蛋白转阴——占 80%–90%）、激素依赖（减量/停药复发）、**激素耐药**（4 周不转阴——需肾活检、加免疫抑制剂）。
4. **免疫抑制剂**：激素耐药/频繁复发——环磷酰胺、他克莫司、霉酚酸酯。
5. **肾活检指征**：激素耐药、非微小病变疑诊、频繁复发。

**易错点｜激素治疗的「足量足疗程」**：**肾病综合征的激素治疗要「足量诱导 + 缓慢减量」**——过早过快减量易复发。**「激素敏感 ≠ 治愈」**——复发率约 1/3，需长期随访管理。**激素的副作用**（向心性肥胖、高血压、骨质疏松、感染风险）需监测与教育。

## 3 急性肾小球肾炎（急性肾炎）

**急性肾小球肾炎（acute glomerulonephritis, AGN）**：**急性链球菌感染后肾炎**（APSGN）最常见——β 溶血性链球菌感染（咽炎、皮肤脓疱疮）后 1–3 周，免疫复合物沉积肾小球。

### 临床表现

- **前驱感染**：上感/皮肤感染史。
- **水肿**：**眼睑颜面水肿**（晨起明显，非凹陷性为主）。
- **血尿**：**肉眼血尿（洗肉水样/茶色）**——首发症状之一。
- **高血压**、少尿。
- **实验室**：尿蛋白 + 血尿 + **ASO 升高、补体 C3 下降**。

### 治疗（自限性——「对症为主」）

1. **休息**：急性期卧床。
2. **饮食**：限盐限水、低蛋白（氮质血症时）。
3. **对症**：利尿（水肿明显）、降压（高血压）。
4. **抗生素**：清除链球菌感染（青霉素——治疗前驱感染，不治疗肾炎本身）。
5. **预后**：儿童**绝大多数自愈**（数周至数月恢复），预后良好——**「一般不使用激素」**（自限性疾病）。

**易错点｜急性肾炎的「三不一观察」**：**不用激素、不积极降压过度、不预防性抗生素**（针对肾炎本身），重点在**休息 + 对症 + 观察并发症**（高血压脑病、心衰、急性肾衰——重症表现需处理）。**「急性肾炎是自限病，治疗是对症不是治本」**。

## 4 其他儿童泌尿系统问题

### 泌尿道感染（UTI）

**儿童泌尿道感染**——女孩多见。婴儿表现不典型：发热、纳差、呕吐（**无尿频尿痛**——「发热查因要想到 UTI」）；年长儿才有典型尿路刺激征。

**易错点｜婴幼儿 UTI 的「隐匿发热」**：**<2 岁婴幼儿的泌尿道感染常仅表现为发热、纳差、烦躁**——无尿频尿急。**「婴儿不明原因发热要查尿常规」**——漏诊可致肾瘢痕（反流性肾病）。

### 膀胱输尿管反流（VUR）

儿童 UTI 的重要基础——**输尿管-膀胱连接部抗反流机制不成熟**→尿液反流入肾→**肾盂肾炎、肾瘢痕、高血压、肾衰**。诊断：**排泄性膀胱尿路造影（VCUG）**；治疗：轻度抗生素预防 + 随访，重度手术。

## 5 小结

- **肾病综合征**：大量蛋白尿 + 低白蛋白 + 水肿 + 高脂血症（「三高一低」）。
- 儿童 NS 多为**微小病变型、激素敏感**；**激素足量诱导 + 缓慢减量**是关键。
- NS 并发症：**感染（最常见）、血栓、电解质紊乱**。
- 激素疗效三分：**敏感 / 依赖 / 耐药**——耐药者肾活检 + 免疫抑制剂。
- **急性肾炎**：链球菌感染后 1–3 周；血尿 + 水肿 + 高血压 + C3 下降；**自限性、对症为主、不用激素**。
- 口诀：**「肾病漏蛋白、肾炎出血压」**。
- 婴幼儿 UTI 仅发热——**发热查因查尿常规**；膀胱输尿管反流防肾瘢痕。

临床速记｜肾病综合征的「激素反应三分」：敏感（4 周转阴）、依赖（减药复发）、耐药（4 周不转阴）——「反应决定预后与治疗路径」——敏感者继续激素、耐药者活检 + 免疫抑制剂。
