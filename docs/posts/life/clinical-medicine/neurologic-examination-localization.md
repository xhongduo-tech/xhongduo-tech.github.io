## 为什么神经病学以「定位」为核心方法

神经病学（neurology）是临床医学中最「逻辑化」的学科——它把**症状与体征翻译成神经系统的解剖坐标**，再通过**定位 + 定性**两步推理得出诊断：**先回答「病灶在哪里」（定位诊断），再回答「病灶是什么」（定性诊断）**。<span class="marginnote">定位诊断的思维方式与「逆向工程」相似：<strong>神经系统是一个由大量「通路」组成的网络</strong>——运动通路（上/下运动神经元）、感觉通路（脊髓丘脑束、内侧丘系）、视觉通路……当某条通路的功能异常（症状），逆着解剖图就能定位病灶。<strong>「体征 → 通路 → 部位」是神经科医生的推理链</strong>。</span>

本篇建立神经系统的检查方法（肌力、感觉、反射、共济）与定位诊断的框架（大脑、脑干、小脑、脊髓、周围神经）。

## 1 神经系统检查总览

### 意识评估：Glasgow 昏迷评分（GCS）

**GCS（Glasgow Coma Scale）**：睁眼（E，1–4 分）+ 语言（V，1–5 分）+ 运动（M，1–6 分），总分 3–15 分：

| 睁眼（E） | 语言（V） | 运动（M） |
| --- | --- | --- |
| 4 自动睁眼 | 5 回答正确 | 6 遵嘱动作 |
| 3 呼唤睁眼 | 4 回答错误 | 5 定位痛刺激 |
| 2 刺痛睁眼 | 3 说出单词 | 4 回缩躲避 |
| 1 不睁眼 | 2 只能发声 | 3 屈曲（去皮质） |
|  | 1 无反应 | 2 伸展（去脑） |
|  |  | 1 无反应 |

- **13–15 分**：轻型；**9–12 分**：中型；**≤8 分**：重型（昏迷）——**≤8 分提示意识障碍、需警惕气道保护**。

**易错点｜去皮质 vs 去脑强直**：**去皮质强直**（上臂屈曲、下肢伸展——**皮质/内囊病变**）vs **去脑强直**（四肢伸展、角弓反张——**脑干上段病变**）——「上肢屈下肢伸 = 皮质伤，四肢伸直 = 脑干伤」。

### 高级神经功能

- **失语（aphasia）**：语言障碍——**Broca 失语**（运动性——能理解不能说，额下回后部）、**Wernicke 失语**（感觉性——能说不能理解，颞上回后部）、完全性失语。
- **视野缺损**：视觉通路定位——**同向偏盲**（视束/视辐射/枕叶）、**双颞侧偏盲**（视交叉——垂体瘤）。

## 2 运动系统检查

### 上运动神经元 vs 下运动神经元（瘫痪的定位）

**瘫痪（paralysis）**按损伤部位分两大类——这是定位诊断的第一分水岭：

| 特征 | 上运动神经元（UMN） | 下运动神经元（LMN） |
| --- | --- | --- |
| 病变部位 | 皮质运动区、皮质脊髓束 | 前角细胞、神经根、周围神经 |
| 肌张力 | **增高（痉挛性）** | **降低（弛缓性）** |
| 腱反射 | **亢进** | **减弱/消失** |
| 病理征 | **Babinski 阳性** | 阴性 |
| 肌萎缩 | 不明显（废用性） | **明显**（神经性） |
| 举例 | 脑梗死、脊髓损伤 | 脊髓灰质炎、周围神经病 |

**易错点｜「上硬下软」的鉴别**：**「上运动神经元瘫痪 = 硬（肌张力高、腱反射亢进、病理征阳性）；下运动神经元瘫痪 = 软（肌张力低、反射消失、肌肉萎缩）」**——记住「上硬下软」四个字。

### 肌力分级（0–V 级）

0 级完全瘫痪 → V 级正常（见诊断学篇）。

## 3 感觉系统与共济失调

### 感觉的分类与传导

- **浅感觉**（痛温觉）：脊髓丘脑束——**交叉至对侧上行**。
- **深感觉**（位置觉、振动觉）：薄束/楔束→内侧丘系——**同侧上行至延髓交叉**。
- **精细触觉**：两者兼有。

**感觉障碍的定位**：
- **脊髓半切综合征（Brown-Séquard）**：**病灶侧深感觉障碍 + 同侧上运动神经元瘫痪，对侧痛温觉障碍**——脊髓半横断（外伤、肿瘤）。
- **传导束型**（病灶以下全部感觉障碍）：脊髓横贯损伤。
- **周围神经型**：手套袜套样（末梢神经病——糖尿病）、单神经分布（某一神经支配区）。

**易错点｜痛温觉与深感觉的「交叉位置不同」**：**痛温觉在脊髓内交叉（脊髓丘脑束）**，**深感觉在延髓交叉（内侧丘系）**——所以脊髓半切时痛温觉障碍在对侧（已交叉）、深感觉在同侧（未交叉）——「同深对浅」记忆。

### 共济失调（小脑）

**小脑性共济失调**：**指鼻试验不准、跟膝胫试验不稳、轮替动作笨拙、醉酒样步态（宽基底步态）、意向性震颤**——「越接近目标越抖」——小脑病变（肿瘤、遗传性）。

**易错点｜三种步态鉴别**：**小脑性共济失调**（醉酒样宽基底、不伴偏瘫）vs **感觉性共济失调**（深感觉障碍——闭眼加重、睁眼减轻）vs **痉挛性偏瘫步态**（画圈步态——上运动神经元损伤）。

## 4 定位诊断的框架

**定位诊断——按「部位」提问**：

| 部位 | 特征性表现 |
| --- | --- |
| **大脑皮质** | 失语、偏瘫、偏身感觉障碍、视野缺损、癫痫 |
| **内囊** | **「三偏综合征」**（对侧偏瘫 + 对侧偏身感觉障碍 + 对侧同向偏盲）——「小病灶、大表现」 |
| **脑干** | **交叉性瘫痪**（病灶侧脑神经瘫 + 对侧肢体瘫）——「同侧脑神经 + 对侧肢体」 |
| **小脑** | 共济失调、眼球震颤、肌张力低 |
| **脊髓** | 传导束型感觉障碍、截瘫/四肢瘫、大小便障碍 |
| **周围神经** | 手套袜套样/单神经分布感觉运动障碍 |

**易错点｜内囊 vs 脑干**：内囊——**对侧三偏**（无脑神经症状）；脑干——**交叉性瘫痪**（有脑神经症状，如病灶侧周围性面瘫 + 对侧偏瘫）——**「内囊纯对侧、脑干有交叉」**。

## 5 定性诊断与常用辅助检查

### 定性诊断（病灶的性质）

在定位之后，按「时间 + 发病方式 + 危险因素」判断性质：

- **急性起病（秒-分-时）**：**脑血管病**（脑梗、脑出血）。
- **亚急性（小时-天）**：炎症（脑炎、脊髓炎）、脱髓鞘。
- **慢性进行性（周-月-年）**：肿瘤、变性病（帕金森、痴呆）、代谢性。

### 常用检查

- **CT**：急性脑出血（首选）、脑卒中初筛。
- **MRI**：缺血、脱髓鞘、肿瘤——软组织分辨率高。
- **脑电图（EEG）**：癫痫。
- **肌电图/神经传导（EMG/NCV）**：周围神经病、肌病。
- **腰穿脑脊液**：脑膜炎、多发性硬化（寡克隆带）、蛛网膜下腔出血。

## 6 小结

- 神经病学两大推理：**定位诊断（病灶在哪）+ 定性诊断（病灶是什么）**。
- **GCS 评分**：E+V+M，**≤8 分=昏迷**；去皮质（上肢屈）vs 去脑（四肢伸）强直。
- **上运动神经元瘫痪「硬」**（张力高、反射亢进、Babinski 阳性）vs **下运动神经元「软」**（张力低、反射消失、萎缩）。
- **浅感觉脊髓交叉、深感觉延髓交叉**——Brown-Séquard 综合征「同深对浅」。
- 小脑共济失调：**醉酒步态 + 意向性震颤**。
- 定位框架：**内囊「三偏」、脑干「交叉瘫」、脊髓「传导束型」、周围神经「手套袜套」**。
- 定性按时间：**急性=血管、亚急性=炎症、慢性=肿瘤/变性**。
