## 为什么心境障碍是精神科最常见的疾病

**心境障碍（mood disorders）**——**抑郁障碍**（单相抑郁）与**双相障碍**（躁狂 + 抑郁交替）——是精神科门诊最常见、也最被低估的疾病群。**抑郁症的全球患病率约 3%–5%，是致残的主要原因之一**；双相障碍虽然患病率约 1%，却与最高的自杀风险相关。<span class="marginnote">心境（mood）是<strong>持久的情绪基调</strong>（区别于短暂的激情/情绪反应）——抑郁是「心境持续低落」，躁狂是「心境持续高涨或易激惹」。<strong>「心境病是'内分泌-神经递质'的失衡」</strong>：5-羟色胺、去甲肾上腺素、多巴胺的紊乱是药物治疗的靶点。</span>

本篇聚焦**抑郁症**（表现、诊断、治疗——精神科最经典的治疗模型）与**双相障碍**（躁狂发作、双相的治疗难点——「躁郁同体」的陷阱）。

## 1 抑郁症（重性抑郁障碍）

**重性抑郁障碍（major depressive disorder, MDD）**：**显著而持久的心境低落 + 兴趣丧失**，伴认知与躯体症状，持续 ≥2 周，影响功能。

### 临床表现（「三低 + 核心三联」）

**核心症状（必备其一）**：
1. **心境低落**：情绪低落、悲伤、无望——「高兴不起来」。
2. **兴趣/愉快感丧失（anhedonia）**：**对任何事都失去兴趣、原来喜欢的也不喜欢了**。

**其他症状（附加）**：
- **思维迟缓**、注意力不集中、无价值感/过度内疚。
- **睡眠障碍**（**早醒最典型**——比平时早醒 2 小时以上）、食欲体重改变。
- **精神运动迟滞或激越**、乏力。
- **自杀意念/行为**（最危险）。

**易错点｜抑郁的「躯体化」**：**中国抑郁患者常以躯体症状为主诉**（头痛、乏力、胃部不适、失眠）——而非直接说「情绪低落」——**「反复躯体不适 + 检查无异常 + 情绪低落 = 想到抑郁」**——「抑郁症是'披着躯体外衣'的情绪病」。

### 诊断标准（MDD）

**A. 核心（2 项中至少 1）+ 附加（至少 4）共 ≥5 项，持续 ≥2 周 + B. 功能损害 + C. 排除（躯体疾病、物质、双相）**。

### 治疗

**抗抑郁药（一线）+ 心理治疗 + 生活方式**：

1. **抗抑郁药**（起效 2–4 周）：
   - **SSRI（选择性 5-羟色胺再摄取抑制剂）**：**一线**——氟西汀、舍曲林、艾司西酞普兰——**副作用少、安全**。
   - SNRI（文拉法辛、度洛西汀）、NaSSA（米氮平）、TCAs（三环类——**副作用多、二线**）。
2. **心理治疗**：**认知行为治疗（CBT）**——识别并改变负性思维与行为——轻中度可单用。
3. **电休克治疗（ECT）**：**重度、伴自杀、难治性**——快速有效。
4. **难治性抑郁**：增效（锂盐、非典型抗精神病药）、换药、联合。

**易错点｜抗抑郁药的「起效窗与撤药」**：**抗抑郁药起效需 2–4 周**——早期可先出现副作用（恶心、焦虑）——**「告诉患者'两周后才见效'，防止过早放弃」**；**停药需逐渐减量**（骤停有撤药反应）；**SSRI 在青少年中注意自杀风险早期监测**。

### 自杀预防（抑郁是自杀的最主要疾病背景）

**抑郁患者的自杀风险最高**——**治疗抑郁本身就是最重要的自杀预防**；同时评估（既往企图、计划）、住院保护、危机干预。

## 2 双相障碍

**双相障碍（bipolar disorder）**：**躁狂/轻躁狂发作 + 抑郁发作交替**——「情绪的两极」。分 **双相 I 型**（有躁狂发作——重）与 **双相 II 型**（仅有轻躁狂 + 抑郁）。

### 躁狂发作的临床表现（「三高」）

- **心境高涨**：兴高采烈、易激惹——「情绪飞上天」。
- **思维奔逸**：**语速快、话题跳跃、联想丰富**（「话如泉涌」）。
- **活动增多**：精力旺盛、睡眠减少（**睡眠需要明显减少仍精力充沛**）、计划不断、**挥霍、冲动行为**（乱花钱、滥交、鲁莽驾驶）。

**易错点｜躁狂 vs 抑郁的「镜像」**：抑郁——低落、迟缓、失眠（早醒）、食欲差；躁狂——高涨、奔逸、睡眠减少但不困、食欲可大增。**「双相的核心特征是'两极交替 + 躁狂期的冲动行为'」**——**躁狂期自杀风险也高**（冲动性自杀）。

### 双相的治疗（难点：稳定心境）

**双相的治疗与单相抑郁完全不同——关键是「心境稳定剂」而非单纯抗抑郁药**：

1. **心境稳定剂（核心）**：
   - **锂盐**：**双相治疗的「金标准」**——抗躁狂、防复发、降低自杀风险——**治疗窗窄（需监测血锂浓度）、肾甲功副作用**。
   - **丙戊酸盐、拉莫三嗪**（防抑郁发作）。
2. **非典型抗精神病药**：喹硫平、奥氮平——急性躁狂与维持。
3. **抗抑郁药**：**双相抑郁使用需谨慎**——可诱发躁狂转相（「转躁」）——**仅在心境稳定剂保护下短期使用**。
4. **ECT**：重度躁狂/双相抑郁。
5. **心理 + 生活方式**：规律作息（睡眠节律是关键）、识别早期症状。

**易错点｜「单相抑郁」vs「双相抑郁」的识别**：**双相患者的抑郁发作与单相抑郁表现相似——关键区别在「有无（轻）躁狂史」**——**「抑郁患者必须问：有没有过一段时间'精力过剩、话多、睡眠少却精神好'？」**——漏诊双相而单用抗抑郁药可诱发躁狂、加速循环——**「先问躁狂史，再定抑郁药」**。

## 3 抑郁 vs 双相的诊断陷阱

| 特征 | 单相抑郁（MDD） | 双相障碍 |
| --- | --- | --- |
| 发作 | 仅抑郁发作 | 躁狂/轻躁狂 + 抑郁发作 |
| 年龄起病 | 各年龄 | 多青年起病 |
| 家族史 | 抑郁常见 | **双相家族史** |
| 抑郁特点 | 典型 | 可有非典型（睡眠多、食欲增、迟滞重） |
| 治疗 | 抗抑郁药为主 | **心境稳定剂为主，抗抑郁药慎用** |

## 4 小结

- **心境障碍**：抑郁（单相）与双相——精神科最常见疾病群。
- **抑郁症**：心境低落 + 兴趣丧失（核心）+ 早醒、无价值感、自杀意念；**常以躯体症状就诊**。
- 抑郁诊断：核心 + 附加 ≥5 项 + ≥2 周 + 功能损害；**先排除双相**。
- 抑郁治疗：**SSRI 一线（起效 2–4 周）** + CBT 心理治疗 + 重度 ECT。
- **双相障碍**：躁狂（心境高涨、思维奔逸、活动增多、睡眠减少）+ 抑郁交替。
- 双相治疗核心：**心境稳定剂（锂盐金标准）**——**抗抑郁药慎用（防转躁）**。
- **「抑郁患者先问躁狂史」**——漏诊双相、单用抗抑郁药是常见陷阱。

**补充｜锂盐的治疗窗监测**：锂盐是双相「金标准」但**治疗窗窄**——**血锂浓度 0.6–1.2 mmol/L**（维持）、急性期可至 1.2–1.4 mmol/L——**低于治疗窗无效、高于中毒**（震颤加重、恶心呕吐、共济失调→抽搐昏迷）。需**定期监测血锂 + 甲状腺功能 + 肾功能**（锂盐可致甲减、肾浓缩障碍）——「**用锂盐 = 用药 + 监测的捆绑套餐**」。

**补充｜抑郁的「共病」**：抑郁常与其他疾病并存——**焦虑障碍（约一半）、物质滥用（酒精）、躯体疾病（心梗后、卒中后、糖尿病、肿瘤）、睡眠障碍**——「**治抑郁要同时管共病**」——卒中后抑郁、心梗后抑郁不治疗，会显著恶化躯体疾病预后——「心身一体」在抑郁体现得最充分。

临床速记｜「抑郁五问」筛查：情绪低落吗？兴趣减退吗？睡眠食欲变了吗？容易累吗？有无自伤念头？——五问覆盖 PHQ-9 核心条目，门诊 1 分钟内完成初筛——「问出抑郁，是治疗抑郁的第一步」。

再记一笔｜ECT 的适应证记忆：重度抑郁伴自杀、精神病性抑郁、难治性抑郁、躁狂发作、紧张症——「药物无效时，ECT 不是最后手段而是有效手段」。
