## 为什么焦虑是「最普遍的精神痛苦」

**焦虑障碍（anxiety disorders）**是最常见的精神障碍类别——**终身患病率高达 25% 左右**。正常的焦虑是**适应性的**（面对威胁的警觉），而焦虑障碍是**过度的、失控的、功能损害的**焦虑。它的生物学基础是**杏仁核的过度激活 + GABA/5-羟色胺系统调节失衡**——「恐惧回路的灵敏度调得过高」。<span class="marginnote">焦虑的正常 vs 病理：<strong>正常焦虑——有现实威胁、适度、随威胁消失而消退、不影响功能</strong>；焦虑障碍——<strong>无相应威胁或过度反应、持续（≥数月）、影响工作生活</strong>。<strong>「焦虑是光谱，障碍是端点」</strong>——诊断看「过度、失控、损害」三要素。</span>

本篇聚焦**广泛性焦虑障碍、惊恐障碍、社交焦虑障碍**与**创伤后应激障碍（PTSD）**。

## 1 焦虑障碍总论

### 常见焦虑障碍一览

| 类型 | 核心表现 | 关键特征 |
| --- | --- | --- |
| **广泛性焦虑障碍（GAD）** | 对多种事件的**过度担忧** | 「担心的习惯」+ 紧张、失眠、肌肉紧张 |
| **惊恐障碍（PD）** | **反复突发的惊恐发作** | 心悸、窒息感、濒死感 + **害怕再发作** |
| **社交焦虑障碍** | 害怕社交/表现场合被评判 | 回避社交、脸红出汗 |
| **特定恐惧症** | 对特定对象/情境恐惧 | 动物、高空、封闭空间 |
| **分离焦虑障碍** | 与依恋对象分离时过度焦虑 | 儿童多见 |

### 焦虑障碍的共同机制

- **生物学**：杏仁核（恐惧中枢）过度反应、GABA 抑制不足、5-羟色胺/去甲肾上腺素失衡。
- **心理**：认知歪曲（灾难化、「万一……」）、行为回避（回避→强化恐惧——「习得性回避」）。
- **共同后果**：**回避行为**维持并加重焦虑（负强化循环）。

## 2 广泛性焦虑障碍（GAD）

**广泛性焦虑障碍（GAD）**：对多种事件或活动**过度、失控的担忧**，持续 ≥6 个月，伴躯体症状。

**表现**：
- **心理**：持续的紧张不安、担忧、易激惹、难以集中注意力。
- **躯体**：**肌肉紧张（颈肩痛）、心悸、出汗、口干、失眠、胃肠不适**（肠易激样症状）。

**易错点｜GAD vs 躯体疾病焦虑**：**GAD 的躯体症状常被误认为「身体有病」**——心悸想心脏、胃肠想想消化——**「反复检查无异常的'全身不舒服' + 过度担忧 = 想到 GAD」**——「躯体化 + 担忧」双线索。

**治疗**：
- **SSRI/SNRI**（帕罗西汀、艾司西酞普兰、文拉法辛）——一线。
- **普瑞巴林**（GABA 类似物——GAD 有效）。
- **CBT**：认知重构（挑战灾难化思维）+ 放松训练（渐进性肌肉放松、腹式呼吸）。
- **苯二氮䓬类**：**短期/按需**（快速缓解但易依赖——不宜长期）。

## 3 惊恐障碍（PD）

**惊恐障碍（panic disorder）**：**反复、突发的惊恐发作（panic attack）**——数分钟内达峰——伴**持续担心再次发作**或**回避**。

**惊恐发作的特征**（约 4 项以上）：
- **心悸、心慌、出汗、震颤**。
- **呼吸困难/窒息感**。
- **胸痛**。
- **头晕、眩晕、发冷发热**。
- **濒死感、失控感、发疯感**。

**易错点｜惊恐 vs 心梗（急诊鉴别）**：惊恐发作的心悸胸痛——**「像心梗却不是心梗」**——鉴别：**心电图、心肌酶正常 + 突发突止 + 反复发作 + 年轻 + 伴恐惧感**。**「胸痛患者，心梗与惊恐都要想——先查器质性、再评估心理」**——漏掉器质性危险、误诊器质性的过度治疗都不可取。

**治疗**：
- **SSRI**（一线长期）+ **CBT**（认知：识别「灾难化解释」——心悸≠心梗；行为：**暴露/逐级面对**）。
- **急性发作**：短效苯二氮䓬（按需）。
- **呼吸训练**：过度换气纠正。

## 4 社交焦虑障碍

**社交焦虑障碍（social anxiety disorder）**：对社交/表现情境**显著而持久的恐惧**——怕被审视、怕丢脸——**回避社交**。

- **表现**：演讲、聚会、进餐、接电话时——**脸红、出汗、心跳、声音颤抖**——「害怕暴露焦虑」本身加重焦虑。
- **影响**：回避上学、工作、人际——**社会功能损害**。
- **治疗**：**SSRI**（帕罗西汀、舍曲林）+ **CBT（认知重建 + 暴露 + 社交技能训练）**；β 阻滞剂（普萘洛尔——**演出/演讲前按需**——阻断心悸手抖）。

## 5 创伤后应激障碍（PTSD）与应激相关障碍

**创伤后应激障碍（PTSD）**：经历**严重创伤事件**（战争、性侵、灾难、严重事故）后出现的**延迟、持久**的精神障碍。

### PTSD 的核心症状（四簇）

1. **闯入性再体验（intrusion）**：**闪回**（创伤情境突然重现）、噩梦、痛苦回忆——「创伤不断回放」。
2. **回避**：回避与创伤相关的场所、人、话题。
3. **负性认知与情绪**：**认知与情绪的消极改变**——自责、疏离、兴趣丧失、失忆片段。
4. **警觉性增高**：**惊跳反应增强（易受惊）、失眠、易怒、过度警觉**。

**易错点｜PTSD 的「延迟与持久」**：**PTSD 在创伤后数周至数月才诊断（急性应激障碍——创伤后 3 天–1 月）**；**症状持续 >1 月**；**「不是所有经历创伤的人都会得 PTSD」**（约 1/10——女性、既往精神病史、缺乏支持者风险高）——「创伤是必要条件，但不是充分条件」。

### 治疗

- **心理治疗（一线）**：**创伤聚焦 CBT（TF-CBT）、眼动脱敏与再加工（EMDR）**——处理创伤记忆、重建安全感。
- **药物治疗**：**SSRI（舍曲林、帕罗西汀）**——减轻闯入与警觉症状。
- **支持**：社会支持、安全感重建、团体治疗。

### 急性应激障碍（ASD）与适应障碍

- **ASD**：创伤后 3 天–1 月内的急性应激反应——可发展为 PTSD。
- **适应障碍（adjustment disorder）**：**应激事件后 3 个月内出现的情绪/行为反应**（抑郁、焦虑、行为异常）——程度超过正常应激反应、但未达其他诊断——「生活事件压垮了适应力」。

## 6 小结

- **焦虑障碍最常见**：正常焦虑 vs 病理焦虑——看「过度、失控、功能损害」。
- **GAD**：过度担忧 + 躯体紧张——**常被误为躯体病**——SSRI/SNRI + CBT。
- **惊恐障碍**：突发惊恐发作（心悸、濒死感）+ 害怕再发作——**先排除心梗再诊断**。
- **社交焦虑**：怕被审视 + 回避社交——SSRI + 暴露 + β 阻滞剂（演出前）。
- **PTSD**：创伤后**闯入性再体验 + 回避 + 负性认知 + 警觉增高**（四簇）——**持续 >1 月**。
- PTSD 治疗：**TF-CBT/EMDR 心理治疗一线** + SSRI。
- 焦虑的共同循环：**回避 → 强化恐惧**——治疗的核心是「面对」（暴露）+「重构」（认知）。

临床速记｜焦虑的「躯体-心理双通道」：躯体症状（心悸、出汗、肌肉紧张）+ 心理症状（担忧、恐惧、回避）——只治一条腿不稳——「药物压躯体、心理疗认知、两者并举才治本」。

再记一笔｜惊恐发作的「急诊三查」：心电图（排心梗）、电解质（排低钙）、甲状腺功能（排甲亢）——「先排躯体，再谈心理」。
