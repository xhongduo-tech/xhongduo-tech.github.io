## 为什么从辅助检查开始

问诊与查体给出的是「线索」，辅助检查给出的则是「证据」。**实验室检查、心电图、影像与内镜**，是把感官向微观、向体内、向电信号三个方向延伸的手段。上一节的诊断学基础回答了「怎么问、怎么查、怎么写」，本节回答「怎么让数据开口说话」。

但辅助检查是一把双刃剑：用得对，它是金标准；滥用，它是过度诊断的源头。核心原则只有一条——**先有临床假设，再选检查**。本节把四类检查的「判读语言」各讲一层：血里的数字、心电的波形、影像的灰阶、内镜的镜下所见，并给出它们最常见的入门判读规则。<span class="marginnote">在「从极限到大模型」的体系里，本节与第五级《公共卫生》的筛检理论、与第八级《决策分析》的不确定性建模互为镜像：检查的意义永远要放在「先验概率 × 敏感性 × 特异性」的框架里评估。</span>

## 1 实验室检查：血里的数字

**实验室检查（laboratory tests）**：对血液、尿液、体液等标本进行理化与细胞学检测的方法。入门要抓三个层面：

**血常规**是最基础的一组：白细胞（WBC）计数与分类、红细胞（RBC）、血红蛋白（Hb）、血小板（PLT）。白细胞升高伴中性粒细胞为主提示细菌感染，淋巴细胞为主提示病毒感染；Hb 下降是贫血的直接证据；血小板减少提示出血风险。<span class="marginnote">血常规是「性价比之王」：一次抽血、几十个参数，却覆盖了感染、贫血、出血三大方向——它几乎是所有住院患者的「开场白」。</span>

**生化检查**：肝功能（ALT、AST、胆红素）、肾功能（肌酐 Cr、尿素氮 BUN）、血糖、血脂、电解质（钾钠氯钙）。ALT/AST 升高提示肝细胞损伤，肌酐升高提示肾小球滤过下降。

**凝血与心肌损伤标志物**：PT、APTT 反映凝血途径；肌钙蛋白（cTn）是心肌坏死的金标准——它把「心绞痛」与「心肌梗死」在生化层面分开了。

血液之外，**体液检验**同样常用：尿常规看蛋白、糖、红细胞与白细胞（肾病、糖尿病、尿路感染的线索），粪常规看隐血与寄生虫，**动脉血气分析（ABG）**看 $\ce{pH}$、$\ce{PaO2}$、$\ce{PaCO2}$、$\ce{HCO3^-}$——它是呼吸衰竭与酸碱失衡诊断的枢纽，一句「$\ce{pH}$ 低、$\ce{PaCO2}$ 高」就把呼吸性酸中毒与代谢性酸中毒分开。<span class="marginnote">动脉血气的判读是一个标准算法：先看 $\ce{pH}$ 定酸碱性质，再看 $\ce{PaCO2}$ 定呼吸因素，再看 $\ce{HCO3^-}$ 定代谢因素——一套三问，几乎不会走错路。</span>

判读的铁律是**结合临床背景**：孤立的指标异常不等于疾病，连续的趋势比单次数值更有意义。一次 ALT 轻度升高，与「肝硬化基础上进行性升高的 ALT」，临床分量完全不同。

## 2 心电图：把心脏电活动画出来

**心电图（ECG）**：记录心脏每一次电活动在体表投影的曲线。它不直接测「泵血」，而是测「指挥泵血的电信号」是否正常——这解释了它为什么擅长心律失常、缺血，却不擅长评价泵功能本身。

判读心电图有固定次序，叫「读图的八步」：**看心律、数心率、看电轴、看 P 波、看 PR 间期、看 QRS、看 ST 段与 T 波、看 QTc**。入门抓住三件事：

- **心律齐不齐**：窦性心律的标志是每个 QRS 前都有 P 波；P 波消失、代之以 f 波（基线不齐）提示**房颤**。
- **心率快慢**：标准走纸速度 25 mm/s 时，心率 = 1500 ÷ RR 间期的小格数。
- **ST 段**：ST 段抬高提示急性心肌梗死（尤其对应导联），压低提示心肌缺血——这是「时间就是心肌」这句话的电学依据。

**辨析｜易错点：** 心电图是**电学**诊断，不是**泵学**诊断。心梗早期心电图可正常，心衰晚期心电图可以很「漂亮」——所以心电图要与其他证据合并使用，而不是单独定罪或单独赦免。

## 3 影像学与内镜：看进身体内部

**医学影像**按「看结构还是看功能、代价多大」排成谱系：X 线（便宜、看骨与肺）、超声（无辐射、看软组织和血流）、CT（断层、密度分辨力高）、MRI（软组织对比最佳、无电离辐射）。

影像判读的起点是**灰度背后的物理**。X 线/CT 的灰度取决于组织对射线的衰减——含气的肺最黑，钙化的骨最白，软组织居中；MRI 的明暗则取决于组织里质子的驰豫特性。看懂一张片子，本质是「把灰阶翻译回组织成分」。<span class="marginnote">CT 图像的本质是「衰减系数的二维矩阵」——这正是「成像 = 求解反问题」的绝佳实例，其数学内核（Radon 变换与滤波反投影）在第三级《信号与系统》里有系统展开。</span>

**内镜（endoscopy）**把视野直接送进体腔：胃镜看食管胃十二指肠，结肠镜看大肠，支气管镜看气道。内镜的价值有二：一是直接看见黏膜病变（溃疡、糜烂、息肉、肿物），二是取活检——**病理活检是绝大多数肿瘤确诊的金标准**，影像只能「像」，病理才能「定」。

影像与内镜的选择策略：**先无创后有创、先便宜后昂贵、先解决临床问题再谈检查项目**。能用手摸到的，不急着开彩超；能用一次 CT 回答的问题，不安排三次不同部位的检查。

## 4 检查速查表：常见项目一表通

辅助检查种类繁多，初学者最大的困扰不是「不会读」，而是「记不住」。这里把最常用的一批项目按「项目 → 参考范围 → 异常的主要提示」三列收进一张表，作为临床实习期的口袋卡：

| 项目 | 参考范围（成人） | 异常的主要提示 |
| --- | --- | --- |
| 白细胞 WBC | 4–10 × 10⁹/L | 升高：感染/炎症/应激；降低：病毒/再障 |
| 中性粒细胞 | 50%–70% | 比例升高：细菌感染为主 |
| 淋巴细胞 | 20%–40% | 升高：病毒感染/淋巴细胞白血病 |
| 血红蛋白 Hb | 男 120–160、女 110–150 g/L | 降低：各类贫血；升高：真性红细胞增多 |
| 血小板 PLT | 100–300 × 10⁹/L | 降低：出血风险（ITP/白血病） |
| ALT / AST | < 40 U/L | 升高：肝细胞损伤（肝炎/药物/缺血） |
| 肌酐 Cr | 男 57–97、女 41–73 μmol/L | 升高：肾小球滤过率下降 |
| 血钾 K⁺ | 3.5–5.5 mmol/L | 过低：肌无力/心律失常；过高：可致命 |
| 肌钙蛋白 cTn | < 0.1 ng/ml | 升高：心肌坏死（心梗金标准） |
| D-二聚体 | < 0.5 mg/L | 升高：血栓事件（结合临床，假阳性多） |
| 尿蛋白 | 阴性或微量 | 阳性：肾小球疾病/肾病综合征 |
| 尿糖 | 阴性 | 阳性：糖尿病（需血糖证实） |
| 大便隐血 | 阴性 | 阳性：消化道出血/结直肠癌筛查线索 |
| 痰抗酸染色 | 阴性 | 阳性：肺结核的重要线索 |
| 空腹血糖 | 3.9–6.1 mmol/L | 升高：糖尿病/应激；降低：低血糖 |
| 糖化血红蛋白 HbA1c | 4%–6% | 升高：近 2–3 月平均血糖升高 |
| 乳酸 | 0.5–1.7 mmol/L | 升高：组织缺氧/休克/脓毒症 |
| 血氨 | 11–32 μmol/L | 升高：肝性脑病的重要线索 |
| 脑脊液常规 | 细胞数 < 10 × 10⁶/L | 细胞/蛋白异常：脑膜炎/脑炎线索 |
| 甲功（TSH） | 0.3–4.5 mIU/L | 升高：甲减；降低：甲亢 |
| BNP / NT-proBNP | < 100 pg/ml | 升高：心衰的重要线索 |
| C 反应蛋白 CRP | < 10 mg/L | 升高：急性炎症/感染（非特异） |
| 降钙素原 PCT | < 0.5 ng/ml | 明显升高：细菌感染/脓毒症线索 |

判读这张表有三条纪律。第一，**参考范围是「人群分布」，不是「个体判决书」**：年龄、性别、昼夜节律、药物都会影响结果，轻微越界不等于疾病，要结合临床再下结论。第二，**假阳性与假阴性永远存在**：一张「完全正常」的报告，不能推翻高度可疑的临床；一张「明显异常」的报告，也可能只是标本采集不当。第三，**异常值要与临床主线对得上**：对不上的异常，先怀疑标本与检验过程，而不是急着给病人扣诊断帽子。

**辨析｜易错点：** 肌钙蛋白升高**不等于**一定心梗——肾衰、肺栓塞、心肌炎、严重心律失常都可以使其升高。它提示的是「心肌损伤」，是「心梗」的必要证据而非充分证据。这就是「辅助检查辅助临床、不能取代临床」的又一例证。<span class="marginnote">这张表还有一层用意：把「数字」与「背后的器官」绑定——WBC 想的是骨髓与感染，Cr 想的是肾脏，cTn 想的是心肌。读表的过程，就是一次「从实验室回到病床」的思维训练。</span>

选检查还有一条「性价比」原则，可以概括成三问：**这问题有必要查吗？这检查真能回答问题吗？拿到结果能改变处理吗？** 三问都过不了，这项检查就不该开。盲目「全面检查」既浪费资源，又制造焦虑——正常报告常被当作「病根不在那」，异常报告又往往只是干扰项。真正成熟的检查策略，是**围绕一条临床主线，选择最少的、最能改变决策的项目**。

## 5 公式解析：CT 的 Hounsfield 值

影像判读里有第一条「可计算」的指标，就是 CT 的灰度——**Hounsfield 单位（HU）**：

$$
HU = 1000 \times \frac{\mu_x - \mu_{\text{water}}}{\mu_{\text{water}}}
$$

拆解三步：

- **$\mu_x$ 是组织的线性衰减系数**：射线穿过单位厚度物质被减弱的比例，取决于组织的密度与原子序数。
- **$\mu_{\text{water}}$ 是水的衰减系数**：把水作为基准零点，是所有 HU 刻度的锚点。
- **乘 1000 的作用**：把无量纲的比值放大成易读的整数刻度。规定水为 0，空气约为 −1000，骨约为 +1000。于是肺（含气多）在 −700 上下、脂肪约 −100、软组织约 +40、钙化与骨为数百到上千——**读 CT 片，就是认这些「数字区间」对应什么组织**。

这条公式的价值不在计算本身，而在于一个观念：**影像的每一级灰阶，背后都有一个可量化的物理量**。理解了这个「物理量 → 灰阶 → 诊断」的链条，你就不会再把影像当「玄学图片」，而会把它当数据来看——这也正是影像 AI 能从 CT 里「读出」病变的原理起点。

## 6 小结

- 辅助检查四类：**实验室、心电图、影像、内镜**，各用各的语言描述身体。
- 血常规看感染与贫血，生化看肝肾功能，肌钙蛋白把心梗从心绞痛里分出来；**判读必须结合临床背景**。
- 心电图读图八步的核心三看：心律、心率、ST 段；**它是电学诊断，不是泵学诊断**。
- 影像谱系：X 线、超声、CT、MRI 各有所长；**先无创后有创、先便宜后昂贵**。
- CT 灰阶背后是 Hounsfield 值 $HU = 1000 \times (\mu_x - \mu_{\text{water}})/\mu_{\text{water}}$，图像即数据。
- 辅助检查的总原则：**先有假设、再选检查、结合临床、避免撒网**——它与上节诊断学基础一脉相承。

从下一节开始，我们离开「工具」，进入「疾病」：先看内科第一大系统——**呼吸系统疾病**，COPD、哮喘、肺炎、肺栓塞，看看这些「咳、喘、热、痛」背后各是什么病理。
