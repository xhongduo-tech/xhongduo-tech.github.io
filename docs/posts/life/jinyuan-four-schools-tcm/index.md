# 金元四大家学术流派（河间/易水/攻邪/滋阴/补土）

中医各家学说以历代著名医家的学术思想与医学流派的传承演变为研究对象，金元四大家（刘完素、张从正、李杲、朱震亨）及其河间、易水、攻邪、滋阴、补土诸派，是中医理论在中古时期实现突破与重构的里程碑。学完这些章节，即系统掌握从火热论、攻邪论、脾胃论到滋阴说的完整学说脉络、代表方药及其临床运用。

## 对标教材

- 任应秋主编《中医各家学说》（人民卫生出版社）
- 刘完素《素问玄机原病式》及金元各家原典（《儒门事亲》《脾胃论》《格致余论》）
- 《中医各家学说》全国中医药行业高等教育规划教材（中国中医药出版社）
