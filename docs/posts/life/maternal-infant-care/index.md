# 母婴护理（月嫂）职业技能

母婴护理员（月嫂）是《中华人民共和国职业分类大典》中的正式国家职业工种，服务于产妇与新生儿（婴儿），覆盖产褥期照护、科学喂养、新生儿护理、早期教育与应急处置全流程。以人社部《家政服务员（母婴护理员）国家职业技能标准》《育婴员国家职业技能标准》与国标《家政服务 母婴护理服务质量规范》为纲逐章写成博文，学完即可掌握从岗位规范到实操照护的完整职业技能体系。

## 对标教材

- 中华人民共和国人力资源和社会保障部，《家政服务员（母婴护理员）国家职业技能标准》
- 中华人民共和国国家标准，《家政服务 母婴护理服务质量规范》（GB/T 31771）
- 中华人民共和国人力资源和社会保障部，《育婴员国家职业技能标准》
