## 为什么从脊柱感染与肿瘤讲起

脊柱感染与脊柱肿瘤是骨科里**诊断最凶险、延误代价最高**的两类疾病。<span class="marginnote">它们都表现为「背痛 + 影像异常」，却极易被当成普通腰背痛或退变处理——而一旦感染脓肿压迫脊髓、或肿瘤侵蚀椎体导致塌陷，可在数小时到数天内造成不可逆的瘫痪。脊柱感染与肿瘤的救治，是一场与「神经功能保存」的赛跑。</span>本篇先讲脊柱感染（重点是结核与化脓性脊柱炎），再讲脊柱肿瘤（原发与转移），最后讲共同的急症——脊髓压迫。

## 1 脊柱感染概论：为什么脊柱会被感染

脊柱感染可由血行播散、邻近蔓延或直接种植（手术/穿刺）所致。血行播散是主要途径，细菌经血到达**椎体终板下**（血供丰富、血流缓慢处）定植繁殖。

**临床表现**（两者相似）：**持续的背部疼痛**（休息不缓解、夜间加重）、发热（可不高）、脊柱僵硬、叩痛；神经症状（下肢无力、感觉障碍、括约肌障碍）提示硬膜外脓肿或脊髓受压。<span class="marginnote">脊柱感染的「狡猾」在于早期表现不特异：没有高热、血常规正常也不少见。当患者「背痛 + CRP/ESR 升高 + 危险因素（糖尿病、免疫抑制、近期感染史）」，即使体温不高，也要想到脊柱感染。</span>

**影像**：X 线早期可正常，数周后出现椎间隙变窄、终板破坏；**MRI 是金标准**——感染椎体在 T1 低信号、T2 高信号、增强强化，椎间盘破坏、椎旁脓肿形成。

## 2 化脓性脊柱炎

**化脓性脊柱炎（pyogenic spondylitis）**由化脓菌（金葡菌最常见，其次链球菌、革兰阴性菌）引起。典型影像：**椎间盘最先被破坏**（椎间隙变窄、消失），然后累及相邻椎体，可形成椎旁/腰大肌脓肿。

**治疗**：

1. **敏感抗生素**：根据培养（血培养 + 穿刺活检培养）选择，静脉 4–6 周后口服巩固，总疗程常达 6–12 周。
2. **制动**：支具/卧床。
3. **手术指征**：**硬膜外脓肿伴神经症状、椎体破坏不稳、保守治疗无效**。术式为清创 + 减压 + 内固定（现代观点主张一期后路内固定，即使有感染——因为稳定是控制感染的前提）。

**重点：脊柱感染治疗的三个支柱是「敏感抗生素 + 稳定 + 神经减压」。** 其中「稳定」常被低估：感染破坏椎体与间盘后脊柱不稳，不稳又加重感染扩散，故内固定与抗生素同样重要。<span class="marginnote">「感染区放内固定会不会加重感染？」是经典疑问。现代循证答案是否定的：彻底清创后，钛合金内固定能提供稳定、促进血运重建与抗感染环境，反而有利于感染控制——这是脊柱外科的一大观念转变。</span>

## 3 脊柱结核（Pott 病）

**脊柱结核**是结核分枝杆菌血行播散所致，是**最常见的脊柱感染**，也是发展中国家脊柱后凸畸形的主要病因。好发于**胸腰段**，可累及多个椎体。

与化脓性脊柱炎的关键区别：

**椎间盘相对保留**：结核常从椎体前缘/中央开始破坏，椎间盘可长期完好（化脓性则早期破坏间盘）——影像上「椎间盘保留」是结核的提示性特征。
**骨破坏 + 干酪样坏死 + 椎旁寒性脓肿**：结核脓肿不伴明显红热痛（「寒性」），可沿筋膜间隙流注（腰大肌脓肿、流注至腹股沟）。
- **进行性后凸**：椎体前柱破坏塌陷，形成角状后凸（Gibbus 畸形）。<span class="marginnote">脊柱结核的影像特征可概括为「一洞一脓肿一后凸」：椎体前缘/中央骨破坏（空洞）、椎旁寒性脓肿、角状后凸。与化脓性脊柱炎（间盘破坏 + 化脓性脓肿）鉴别主要靠病史、T-SPOT/γ干扰素释放试验与活检。</span>

**治疗**：以**抗结核化疗为主**（异烟肼、利福平、吡嗪酰胺、乙胺丁醇四联，全程 9–18 个月），辅以制动。手术指征：**神经功能障碍、脓肿大（需引流减压）、脊柱不稳或严重/进展性后凸、化疗耐药**。术式：病灶清除 + 减压 + 植骨融合 + 内固定。<span class="marginnote">脊柱结核的经典观念是「卧床 + 化疗 + 石膏」，现代则主张「化疗 + 早期内固定矫形」：稳定脊柱、纠正后凸、让患者尽早下床。抗结核治疗本身是根本，手术是「锦上添花」或「雪中送炭」。</span>

**辨析｜易错点：** 脊柱结核与**脊柱转移瘤**都可表现为椎体破坏，但结核常有椎间隙受累/脓肿、转移瘤多椎间隙保留 + 附件受累 + 中老年 + 原发癌史。**MRI + 活检**是鉴别金标准，单纯影像不可靠。

## 4 脊柱肿瘤：原发与转移

**转移性脊柱肿瘤**是成人脊柱肿瘤的绝大多数（> 90%），原发灶多为**肺、乳腺、前列腺、肾、甲状腺**癌。好发于**胸椎**（血供丰富、椎体容积大）。影像：溶骨性（肺、肾）或成骨性（前列腺、乳腺）椎体破坏，椎间隙多保留，可伴椎弓根破坏（「椎弓根征」）。<span class="marginnote">「椎弓根消失征」（winking owl sign）在正位片上提示椎弓根被破坏，是脊柱转移瘤的经典线索。中老年「背痛 + 椎弓根破坏」首先想到转移，而不是原发——这与骨肉瘤的年龄分布正好相反。</span>

**原发脊柱肿瘤**相对罕见，良性以**血管瘤、骨样骨瘤、嗜酸性肉芽肿**常见；恶性以**脊索瘤**（骶骨）、**软骨肉瘤**、**浆细胞瘤/多发骨髓瘤**为主。

**治疗**（转移瘤）：
- **综合治疗**：按原发癌病理采用系统治疗（化疗、靶向、内分泌）。
- **局部控制**：放疗（止痛、缩瘤）、双膦酸盐/地舒单抗（抑制骨破坏）。
- **手术**：用于**病理骨折不稳、脊髓受压、顽固疼痛、放疗不敏感**者，行**减压 + 内固定**，必要时椎体切除重建（全脊椎切除）。
