## 为什么从剂型概论开始

药物化学给了你一个完美的活性分子——但病人不能把粉末直接吞下去，也不能靠针头把结晶直接推进血管。
**药剂学**
回答的就是这个"最后一公里"问题：怎么把原料药（API）做成一个安全、稳定、好用、能精准释放的
**剂型（dosage form）**
。本章是药剂学的总纲：先建立"为什么要做成剂型""剂型怎么分类"的框架，再认识衡量一切剂型的最高标准——
**药典**。它是后面九节所有具体剂型讨论的共同坐标系。

## 1 为什么要做成剂型

**剂型（dosage form）**
：为适应治疗或预防需要而制备的药物应用形式，是"药物 + 辅料 + 制备工艺"的统一体。原料药几乎从不直
接使用，做成剂型有四个根本理由：

- **控制剂量精确**：一片阿司匹林含 0.3 g 主药，比让病人自己倒药粉可靠得多——剂型是"计量容器"。
- **保证吸收与起效路径**：口服药要过胃肠、注射药直接入血，不同剂型决定药物走哪条路、多快起效。
- **掩味、稳定、易用**：苦药做胶囊、怕光药做铝塑包装、难咽药做儿童口服液——剂型解决"能不能吃下去"。
- **实现特殊释放行为**：缓释、控释、肠溶、靶向——剂型本身可以是一个"智能投递系统"。

**重点：同一原料药，剂型不同则疗效与毒性都可能不同。**
 硝苯地平普通片（快速释放）用于急性心绞痛，而硝苯地平控释片（缓慢释放）用于长期降压——同一分子，因剂型
而"分裂"成两个不同用途的药。
<span class="marginnote">"同药不同剂型 ≠ 同药"是药剂学第一课。缓释与速释的适应证、剂量、禁忌完全不同，临床换用剂型必须重新评估——这会在《药房管理与处方调剂》里再展开。</span>

## 2 剂型的分类

剂型可按**形态、给药途径、分散系统**三种维度分类，各有用处：

| 分类维度 | 类别 | 举例 |
| --- | --- | --- |
| 按形态 | 固体 / 半固体 / 液体 / 气体 | 片剂；软膏；口服液；气雾剂 |
| 按给药途径 | 口服 / 注射 / 皮肤 / 黏膜 / 吸入 | 胶囊；注射液；贴剂；栓剂；吸入剂 |
| 按分散系统 | 真溶液 / 胶体 / 混悬 / 乳剂 / 固体 | 糖浆；胶浆剂；混悬剂；乳剂；散剂 |

三种维度互相正交：一支混悬型注射液，按形态是液体、按途径是注射、按系统是混悬。理解这个"三维坐标"，读后
面任何剂型章节都有了定位。
<span class="marginnote">分散系统分类的背后是物理化学：粒子大小从真溶液（< 1 nm）到混悬剂（> 0.5 μm），决定澄清度、稳定性与吸收行为。斯托克斯沉降定律、乳剂的界面性质都在《液体制剂》一节登场。</span>

分散系统分类的"粒子大小"维度值得再看深一层——它是一条连续的光谱：**真溶液**（
< 1 nm，分子分散，澄明）→ **胶体溶液**（1–100 nm，胶体粒子，丁达尔效应）→ **混悬剂**（>
 0.5 μm，固体粒子，浑浊）→ **乳剂**
（液滴分散）。粒子越大，体系越不稳定、越需要借助表面活性剂或增稠剂维持。
<span class="marginnote">粒子大小决定光学性质：真溶液透明、胶体溶液有丁达尔效应（一束光照过可见光路）、混悬乳剂浑浊。这个"由小到大"的谱系还决定了给药途径——纳米级胶体可注射、微米级混悬多口服外用，粒子大小与体内行为直接挂钩。</span>

**易错点：**
 分散系统分类看的是"分散相粒子大小"，与"剂型名称"不是一一对应。一支"混悬型注射液"按系统是混悬、按
途径是注射；"乳剂"可以是口服的鱼肝油乳、也可以是静脉的脂肪乳——分类维度不同，命名角度不同，别把两个分
类轴混为一谈。

## 3 辅料：看不见的功臣

**辅料（excipients）**
：剂型中除主药外的一切成分，本身无治疗作用，却决定剂型能否成立。按功能分：

- **稀释剂**（片剂填充）：淀粉、乳糖、微晶纤维素；
- **黏合剂**：把粉末黏成颗粒（羟丙甲纤维素 HPMC）；
- **崩解剂**：让片剂入水后散开（羧甲淀粉钠、交联聚维酮）；
- **润滑剂**：防黏冲、助流动（硬脂酸镁）；
- **防腐剂、抗氧化剂、矫味剂、着色剂**：保稳定、适口、易识别。<span class="marginnote">辅料并非完全惰性——它们能与主药反应、吸附主药、改变吸收。硬脂酸镁过量会疏水而延缓片剂崩解；一些辅料有潜在致敏性。药用辅料本身也有质量标准和"药用级"等级。</span>

辅料选择的一个反直觉原则是"越简单越好"——**辅料种类越少，潜在相互作用越少，质量风险越低**
。药企开发新制剂时，优先选择"经典、研究充分、有药用级标准"的辅料，新辅料（尤其合成高分子）需经过完整的
毒理与相容性评估才能引入。
<span class="marginnote">"辅料越少越安全"体现在处方设计里叫"精简处方"（minimal formulation）：能用一种黏合剂就不用两种，能水溶就不用有机溶剂。因为每多一种辅料，就多一分与主药反应、吸收变动的可能——处方简洁本身就是质量策略。</span>

## 4 给药途径与剂型选择全景

把剂型与给药途径对照起来看，就能理解"为什么有这么多剂型"——每一种途径都对应一套独特的剂型家族：

| 给药途径 | 常用剂型 | 起效特点 |
| --- | --- | --- |
| 口服 | 片剂、胶囊、颗粒、口服液、缓释片 | 最方便，有首过效应 |
| 注射 | 溶液、混悬、乳剂、冻干粉针 | 起效最快、生物利用度 100% |
| 皮肤 | 软膏、乳膏、凝胶、贴剂 | 局部或经皮全身给药 |
| 黏膜 | 滴眼液、滴鼻液、含片、栓剂 | 局部或经黏膜吸收 |
| 吸入 | 气雾剂、粉雾剂、雾化液 | 直达肺部，哮喘首选 |

**重点：剂型选择的第一原则是"治疗需要 + 药物性质"双决定。**
 急救要快（注射、舌下）、慢病要方便（口服缓释）、局部病要局部用药（软膏、滴眼液）——而药物的溶解性、稳
定性、半衰期又反过来限定剂型范围。
<span class="marginnote">"药物性质限定剂型"的例子很常见：胰岛素是蛋白质，口服会被消化酶破坏，只能注射或经鼻/经皮给药；硝酸甘油首过效应强，只能舌下含服避开肝脏。<strong>先看分子，再选剂型</strong>是药剂师的第一直觉。</span>

**易错点：**
 给药途径不是越"高级"越好。能口服不注射、能局部不全身，是合理用药的通行原则——注射虽然快，但感染风险
、技术要求、成本都更高。剂型选择是"疗效-安全-便利-成本"的四维权衡。

剂型家族还在不断扩张，几个"新成员"代表了现代给药技术的发展方向：

- **透皮贴剂**：把药贴在皮肤上持续释放，避开首过效应、平稳血药浓度（芬太尼贴剂、尼古丁贴剂）；
- **口腔崩解片**：入口即化、不需水送服，老人儿童友好；
- **缓释/控释制剂**：把一天三次减为一天一次（见《缓释控释制剂》一节）；
- **脂质体与纳米制剂**：把药"装进"纳米载体实现靶向递送（见《靶向制剂与纳米制剂》一节）；
- **3D 打印药片**：按个体需要定制剂量与释放曲线——个性化制药的前沿。<span class="marginnote">剂型演化的主线很清晰：从"把药做出来"到"把药送到该到的地方、按该有的速度释放"。传统剂型解决"能不能用"，现代剂型解决"用得更聪明"——这条主线贯穿《缓释控释制剂》《靶向制剂与纳米制剂》等后续章节。</span>

**重点：剂型创新是"老药新用"的重要引擎。**
 同一个药物分子，通过剂型改造获得新适应症、新给药途径或更好的安全性——如把难溶抗癌药做成纳米制剂解决给
药问题。**制剂技术有时比分子本身更能决定药物的临床价值。**

## 5 药典：药剂的最高法典

**药典（pharmacopoeia）**
：由国家药典委员会编撰、政府颁布的记载药品标准（真伪鉴别、纯度、含量、制剂规范）的法定典籍，是药品生产、
检验、使用与监督管理的法律依据。主要药典：

- **《中国药典》（ChP）**：现行版分三部——一部收载中药，二部收载化学药，三部收载生物制品，并附通则与药用辅料标准。
- **《美国药典》（USP）** 与 **《欧洲药典》（EP）**、**《日本药局方》（JP）**：国际上最具影响力的药典，药品出口常需符合对方药典标准。

**重点：药典标准是"最低合格线"，不是"最佳配方"**
——它规定每剂型的鉴别、检查、含量测定项，保证同一药品无论哪家厂生产，质量底线一致。质量标准体系（鉴别、
检查、含量测定）正是《药物分析》篇展开的骨架。
<span class="marginnote">药典从公元前 3 世纪《汉谟拉比法典》式的古代药方集一路演化：1858 年英国《伦敦药典》奠定现代药典形态，20 世纪各国药典走向国际协调（ICH 的统一指导原则）。药典的进化史就是药品监管从"经验"走向"科学"的历史。</span>

**辨析｜易错点：**
 药典 ≠ 药品说明书 ≠ 标准操作规程（SOP）。药典是法定通用标准（对所有同品种药生效）；说明书是针
对某一产品的临床使用信息；SOP 是药厂内部操作规程。三者的层级、对象与强制力各不相同。

## 6 小结

- **剂型**是药物、辅料与工艺的统一体，解决计量、吸收、稳定、特殊释放四大问题。
- 同一原料药做成不同剂型，疗效与适应证可能不同——**同药不同剂型 ≠ 同药**。
- 剂型可按**形态、给药途径、分散系统**三维分类；分散系统分类背后是物理化学。
- **辅料**决定剂型能否成立，并可能影响稳定性与吸收，并非完全惰性。
- **药典**是国家颁布的药品法定标准（ChP/USP/EP/JP），规定鉴别、检查、含量测定；它是"最低合格线"。
- 给药途径决定剂型家族：口服/注射/皮肤/黏膜/吸入各有对应剂型；剂型选择是"治疗需要+药物性质"双决定，并遵循"能口服不注射、能局部不全身"。
