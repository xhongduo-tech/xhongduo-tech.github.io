## 为什么从药物警戒开始

药品注册证明了"获益大于风险"，GMP/GSP 保证了"每批质量合格"——但还有一类风险无法在上市前完全
预见：**不良反应（adverse drug reaction, ADR）**
。再合格的药、再规范的生产，也无法消除个体对药物的异常反应；而罕见的不良反应，只有在大规模人群使用后才暴
露。**药物警戒（pharmacovigilance, PV）**
就是上市后对药品安全性持续的监测、评估与防控体系。它是药学"安全第一"理念的集中体现——前面所有环节都在
追求"做对"，而药物警戒承认"即使做对了，也可能有意外"。

## 1 不良反应的分类

**药品不良反应（ADR）**
：合格药品在正常用法用量下出现的与用药目的无关的、有害的反应。注意定义的三要素：
**合格药品、正常用法用量、有害**——排除了假药劣药、误用滥用造成的问题。
<span class="marginnote">定义为什么咬得这么死？因为只有符合"合格、正常、有害"三个条件，才属于 ADR 报告与监测的法定范围——药物警戒管的是"药本身的属性风险"，而非"药质量有问题"或"人用错了"。这在法律责任划分上至关重要。</span>

按机制与可预测性分三类：

**A 型（量变型）**：药理作用的延伸，可预测、与剂量相关——如阿司匹林的胃肠道出血、降糖药的低血糖。占 ADR 的大多数。
**B 型（质变型）**：与正常药理作用无关的异常反应，多与免疫/遗传相关，难预测——如青霉素过敏性休克、异烟肼的肝损伤。
**C 型**：长期用药后的蓄积性反应——如长期用糖皮质激素的骨质疏松。<span class="marginnote">A 型可预防（从小剂量开始、监测指标），B 型只能靠"问过敏史 + 警惕"来防范——这也是用药前"询问过敏史"如此重要的原因。分类的意义在于：不同类型有不同的预防策略。</span>

## 2 因果关系评价：谁惹的祸

发现一个不良反应事件，怎么判断"是不是这个药引起的"？这就是
**因果关系评价（causality assessment）**。常用 **Naranjo 评分量表**
，从十个问题打分：

| 考察维度 | 代表性提问 |
| --- | --- |
| 时间关系 | 用药后合理时间内发生吗？ |
| 停药反应 | 停药后反应是否减轻/消失？ |
| 再用药 | 再次用药是否复发？ |
| 有无其他原因 | 疾病本身或合并用药能否解释？ |
| 既往报道 | 该反应是否已知？ |

总分把关联程度分为**肯定、很可能、可能、可疑、不可能**五个等级。
<span class="marginnote">Naranjo 量表的意义在于"把主观判断变成可打分的客观流程"：同样一份病例报告，不同医生用同一张表，能得出相近的关联结论。它是信号评价的"标准化尺子"，也是不良反应报告规范化的基础。</span>

**易错点：** 时间上的先后（用药在前、反应在后）只是关联的必要条件，不是充分条件——
**先后 ≠ 因果**
。疾病自然进展、合并用药、安慰剂效应都可能解释"先用药后出现反应"。这就是为什么评价需要多维证据而非只看
时间线。

## 3 不良反应报告与信号检测

**ADR 报告系统**
是药物警戒的底层数据来源：医疗机构、药品上市许可持有人（MAH）、经营企业发现 ADR 后，向国家不良反
应监测中心**自发报告（spontaneous reporting）**
。各国据此建立数据库——中国的国家药品不良反应监测系统、WHO 的国际药物监测合作中心（乌普萨拉监测中心
，UMC）。

单个报告只能算"个例"，药物警戒的价值在于**信号检测（signal detection）**
：从成千上万条报告中，用统计方法找出"某药与某反应"超出预期的关联——即
**比值失衡分析（disproportionality analysis）**，如报告比值比（ROR）。
<span class="marginnote">信号检测是"大海捞针"的数据科学：在自发报告数据库里，若"药 X + 反应 Y"的报告数显著多于背景预期，就可能是个新信号——但信号只是"值得调查的线索"，不是结论，还需要病例评审、队列研究进一步确证。这与《生物信息学》里的富集分析思想异曲同工。</span>

信号检测的统计方法值得多看一眼——它是"数据科学在药监"的样本。**比值失衡分析**
计算"观察到的报告数"与"期望报告数"的比值：

**PRR（比例报告比）**：某药-某反应组合的报告占比 vs 背景占比；
**ROR（报告比值比）**：基于四格表的比值比，置信区间下限 > 1 常作为"失衡信号"的提示。

**重点：信号 ≠ 结论。**
 失衡分析只能提示"这个组合的报告比预期多"，但预期本身受报告偏倚（媒体关注、诉讼、季节）影响——所以信
号需经病例评审、剂量-反应分析、再暴露试验等**多步确证**才能上升为"风险"。
<span class="marginnote">比值失衡分析在方法上与《数据科学》里的关联规则、富集分析是近亲：从大规模事件数据里找"超过随机预期的共现"。但药物警戒多了关键一步——<strong>因果性</strong>：共现不等于因果，必须回到病例与机制去验证。这是统计信号与科学结论的分界线。</span>

**易错点：**
 不能直接用"报告数排名"判断药品安全性排名。报告数多可能只是因为使用量大或报告积极（"药物暴露越多，报
告越多"），而信号检测的价值正在于**校正这个分母效应**
——这也是为什么报告绝对数没有比值失衡指标可靠。

## 4 药物警戒与风险管控

**药物警戒（pharmacovigilance, PV）**
：与 ADR 发现、评估、理解和防范相关的科学和活动，比"不良反应监测"更广——它还包括用药错误、不合格
药品、药物相互作用等一切与用药安全相关的问题。

风险管控的措施阶梯：

**说明书修订**：新发现的风险写入说明书（警示、禁忌）；
**限制使用**：限定适应症、人群、处方权限；
**暂停销售与撤市**：风险远超获益时，果断下架。<span class="marginnote">中国近年多次对高风险中成药、含可待因儿童药、酚酞片等进行说明书修订或撤市，正是"风险管控阶梯"的实践。药物警戒不是"报喜不报忧"，而是主动发现风险、及时干预——哪怕这意味着承认"曾经的药有问题"。</span>

**重点：药物警戒的灵魂是"获益-风险动态评估"**
——新药上市时的"获益大于风险"只是一个时间点的判断；随着真实世界数据积累，这个天平随时可能倾斜，需要持
续重新评估。

**风险管理计划（RMP）**
是药物警戒的"主动出击"工具：新药上市时常要求持有人提交 RMP，内容包括——已识别风险（如某药的肝毒性
）、潜在风险（机制推测但未证实）、**缺失信息**（孕妇、儿童数据不足），以及对应的
**风险最小化措施**（监测肝功能、限制适应人群、患者教育卡片）。
<span class="marginnote">RMP 把"出了事再处理"变成"提前想好可能出什么事、怎么防"——它是药物警戒从"被动报告"走向"主动风险管理"的标志。审批有条件的药（附条件批准）尤其依赖 RMP 来兜底"先批后补"的安全风险。</span>

**易错点：**
 风险最小化措施 ≠ "多写几条说明书"。有效的最小化措施必须可执行、可验证——如"用药前必须查肝功能"
能通过处方记录核查，"医生应关注患者情况"则无法核实。监管会评估措施是否有"可操作性与可检验性"。

## 5 不良反应监测的制度要求

不良反应监测是一套有法律时限的制度，不是"发现了就上报"这么随意：

**谁报告**：药品上市许可持有人（MAH）、医疗机构、经营企业都是法定报告主体；医务人员发现疑似不良反应应主动报告。
**何时报告**：对**新的**与**严重**的不良反应，应在规定时限内上报（如严重 ADR 应在获知后 15 日内，死亡病例须立即报告）——"快报"是新风险的发现窗口。
**报什么**：可疑即报（不要求确定因果关系）——宁报勿漏，因为信号检测需要足够的"分母"。
**向谁报**：国家药品不良反应监测系统、当地监测机构、MAH 的药物警戒部门。<span class="marginnote">"可疑即报"是自发报告制度的设计精髓：如果要求"确认是药引起的才报"，绝大多数新信号（尤其罕见不良反应）就永远不会被报告——因为确认需要更多数据，而数据恰恰来自报告。所以制度刻意放宽了报告门槛。</span>

**重点：报告是"信号"的原料，不是"定论"。**
 每一份 ADR 报告只说明"疑似"，大量同类报告经统计处理后才形成信号，再经评估才可能变成说明书修订或
撤市决定。
<span class="marginnote">从"个例报告"到"监管行动"是一条长链：报告 → 数据整理 → 信号检测 → 信号评估 → 风险沟通 → 监管决策。每一个环节都有专门的方法与时限要求——药物警戒是一个"数据驱动的风险治理系统"。</span>

**易错点：**
 ADR 报告率高 ≠ 药品不安全。报告率反映的是"发现与上报的积极性"，不是"不良反应发生率"。这正是
自发报告的固有局限（漏报普遍），也是为什么要用"比值失衡"等方法校正，而不能直接比较报告绝对数。

## 6 公式解析：需要治疗/伤害多少人才见一例

评价药物不良反应的严重程度，有一个直观的指标——**需要伤害的例数（NNH）**：

$$
NNH = \frac{1}{p_{\text{药}} - p_{\text{对照}}}
$$

- **第一步，$p_{\text{药}}$ 与 $p_{\text{对照}}$**：用药组与对照组中不良反应的发生率（如用药组 5%、对照组 1%）。
- **第二步，做差**：$p_{\text{药}} - p_{\text{对照}}$ 是**归因于药物**的额外风险（绝对危险增加，ARI）。5% − 1% = 4%。
- **第三步，取倒数**：$NNH = 1/0.04 = 25$——意为"每治疗 25 个患者，就会有 1 例该不良反应可归因于药物"。NNH 越小，危害越突出。
- **第四步，与获益对比**：**NNH 与 NNT（需要治疗的例数）成对使用**——NNT 是"每治多少人有 1 人获益"。当一个药 NNT = 10、NNH = 25 时，获益大于风险；当 NNH 远小于 NNT，就该警惕了。**药物警戒的量化判断，本质上就是比较 NNT 与 NNH。**

## 7 小结

- **ADR** 定义三要素：合格药品、正常用法用量、有害；分 **A 型**（可预测、剂量相关）、**B 型**（难预测、免疫/遗传）、**C 型**（蓄积）。
- **因果关系评价**（Naranjo 量表）把关联判断标准化，但**先后 ≠ 因果**。
- **自发报告系统**是数据基础，**信号检测**（比值失衡分析）从海量报告中发现新信号。
- **药物警戒（PV）**比不良反应监测更广，风险管控阶梯：说明书修订 → 限制使用 → 暂停/撤市。
- **NNH = 1/ARI** 与 NNT 成对使用，是"获益-风险"量化的标尺。
- 不良反应监测有**法定时限与报告主体**（MAH、医疗机构），"可疑即报"放宽门槛保证信号原料充足；报告率 ≠ 发生率，不能直接比较绝对数。
