# 胸心血管外科

胸心血管外科（心胸外科）是外科学的主要亚专科，以手术手段治疗先天性心脏病、瓣膜病、冠心病、肺食管肿瘤、纵隔疾病及终末期心肺疾病，是技术密度最高、学科交叉最广的外科领域之一。学习它既需要掌握心脏与胸腔的精细解剖和病理生理，也离不开体外循环、心肌保护与重症监护的系统知识，是理解现代外科体系不可或缺的一环。
