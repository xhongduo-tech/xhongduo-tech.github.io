## 为什么从机械循环支持开始

**机械循环支持（mechanical circulatory support, MCS）** 是「机器替心」的完整谱系：从临时辅助的主动脉内球囊反搏（IABP）与体外膜肺氧合（ECMO），到可长期植入的心室辅助装置（VAD）与全人工心脏（TAH）。
它在四种场景里扮演主角：**心源性休克急救、移植前的桥（bridge to transplant）、心肌恢复期的桥（bridge to recovery）、以及不适合移植者的终身治疗（destination therapy）**。<span class="marginnote">把 MCS 与《体外循环》对照：体外循环是手术台上「暂时的机器心」，MCS 是「从小时到数年」的机器心。VAD 的进步（尤其连续流泵）让「带着人工心脏生活」从科幻变成常规——某些患者用 LVAD 活过十年。</span>理解 MCS 的谱系与每级装置的「任务」，是终末期心脏治疗的最后一块拼图。

## 1 机械循环支持的谱系

MCS 按支持强度与时长从低到高排列：

**IABP（主动脉内球囊反搏）**：经股动脉在降主动脉放置球囊导管。**舒张期球囊充气**（提高冠脉灌注压、增加心肌供氧），**收缩期球囊放气**（降低主动脉阻力、减轻后负荷、减少心肌耗氧）。是最早、最普及的 MCS，适合「轻度-中度」支持。
**ECMO（体外膜肺氧合）**：把血引出体外氧合再回输。**VA-ECMO**（静脉-动脉）同时支持心肺；**VV-ECMO**（静脉-静脉）只支持肺。用于**短期急救**（数天到数周）。
- **VAD（心室辅助装置）**：直接为左室（LVAD）、右室（RVAD）或双心室（BiVAD）提供泵血。**连续流 LVAD**（如 HeartMate 3）是当代主力，可支持数月至数年。
- **TAH（全人工心脏）**：切除双心室后植入的人工泵，用于**双心室衰竭且不适合 VAD**者（如复杂室壁瘤、严重室性心律失常）。<span class="marginnote">MCS 的<strong>选择逻辑</strong>按「支持多强、支持多久、要不要换心」三维度走：急救期上 ECMO → 评估能否恢复/移植 → 能恢复就撤，能移植就桥到移植，恢复不了又移不了就终身 LVAD 或 TAH。<strong>「先保命，再定方向」</strong> 是 MCS 的通用节奏。</span>

## 2 ECMO：心肺同时支持

**体外膜肺氧合（extracorporeal membrane oxygenation, ECMO）** 是体外循环的「便携民用版」，核心是离心泵 + 膜式氧合器。

**VA-ECMO**：静脉血（通常经股静脉）引出 → 氧合 → 经股动脉回输动脉。**同时替代心与肺**——适用于心源性休克、心肺复苏后、移植前后过渡。
**VV-ECMO**：静脉血引出 → 氧合 → 回输静脉。**只替代肺**——适用于严重呼吸衰竭（如重症肺炎、ARDS），保留自身心脏功能。

ECMO 的优势是**快速建立、全面支持、可在床边进行**；
代价是**并发症多、不可长期**（血栓、出血、溶血、感染、肢体缺血），通常只支持数周。<span class="marginnote">VA-ECMO 有一个独特的生理问题：<strong>Harlequin 综合征（南北综合征）</strong>——股动脉回输的氧合血与自身心脏的差血在降主动脉汇合，若自身肺功能差，上半身（脑、冠脉）得到的可能是「混血」，造成<strong>上半身缺氧而下半身氧合正常</strong>。处理是加一根「静脉回输支」改善上腔氧合，或过渡到 VV-VA 模式。</span>ECMO 是「桥」而非「终点」——它的任务是把患者安全送到「恢复、移植或 VAD」的下一站。

## 3 心室辅助装置：LVAD 与长期支持

**左室辅助装置（LVAD）** 是目前最成熟的长期 MCS。
当代主流是**连续流（continuous-flow）LVAD**：一个叶轮以恒定转速旋转，把左室血抽入泵、泵入升主动脉。
引流管置入左室心尖，流出管吻合到升主动脉，动力经**经皮驱动线（driveline）** 连接体外控制器与电池。<span class="marginnote">连续流泵的生理与搏动性心脏截然不同：它<strong>几乎不产生搏动</strong>，患者可能「摸不到脉搏」；泵的流量高度依赖<strong>前负荷与后负荷</strong>——前负荷不足（容量低）时流量骤降（吸壁），后负荷过高（高血压）时流量下降且易溶血。<strong>「管好前后负荷，泵才稳」</strong> 是 LVAD 随访的核心。</span>

**LVAD 的三种结局**：**桥到移植（BTT）**——支持到获得供心；**桥到恢复（BTR）**——心肌功能恢复后撤泵；**目的地治疗（DT）**——不适合移植者终身携带，是老年患者的现实选项。<span class="marginnote">LVAD 的「心脏」问题不止泵本身：<strong>主动脉瓣</strong>——连续流泵下主动脉瓣常长期不开放（瓣叶不动），易形成血栓；<strong>右心</strong>——LVAD 增加静脉回流而左心快速排空，右心若撑不住会「右心衰」。<strong>LVAD 不是换心，是给心配了个强力外援——自己的心还在，还要养好它。</strong></span>

## 4 公式解析：DPTI/SPTI——IABP 的供需比

IABP 为什么能改善心肌缺血？
它作用于心肌**氧供与氧耗的比值**。
心肌氧供需比可由**舒张期压力-时间指数（DPTI）**与**收缩期压力-时间指数（SPTI）**之比表达：

$$
\frac{DPTI}{SPTI} = \frac{\int_{\text{diastole}} (P_{diastolic} - P_{LV}) \, dt}{\int_{\text{systole}} P_{aorta} \, dt}
$$

四步拆解：

- **第一步，认识 $DPTI$**：舒张期主动脉压与左室压之差的积分——近似代表**冠脉灌注的总量**（冠脉血流主要在舒张期灌注，灌注压 = 主动脉舒张压 − 左室舒张压）。$DPTI$ 越大，心肌供氧越多。
- **第二步，认识 $SPTI$**：收缩期主动脉压的积分——近似代表**心肌耗氧的驱动**（收缩期室壁张力与压力成正比）。$SPTI$ 越大，心肌耗氧越多。
- **第三步，看 IABP 如何改变比值**：舒张期球囊充气 → **主动脉舒张压升高 → $DPTI$ 增大**（供氧↑）；收缩期球囊放气 → **主动脉收缩压与后负荷下降 → $SPTI$ 减小**（耗氧↓）。**分子增大、分母减小，供需比 $\dfrac{DPTI}{SPTI}$ 显著改善**——这就是 IABP 缓解心肌缺血的机制核心。<span class="marginnote">IABP 的双向改善是它「又经济又有效」的原因：<strong>充气养心（增供氧）、放气省心（减耗氧）</strong>。对比正性肌力药（如多巴胺）——它们在增加收缩力的同时也增加心肌耗氧，所以休克时 IABP 常比纯正性肌力药「性价比」更高。</span>
**第四步，临床判读**：$\dfrac{DPTI}{SPTI} \lt  0.7$ 时心肌易缺血；IABP 把比值拉回安全区，同时为后续（造影、PCI、移植或 VAD）争取时间。**IABP 依赖自身心脏的节律**——严重心律失常（室颤）时球囊无法同步工作，需 ECMO/VAD 级别支持。

```
直觉换算：DPTI/SPTI 是心肌的「收支比」——
舒张期「进账」（冠脉灌注），收缩期「开销」（泵血耗氧）。
IABP 在进账时多塞钱（充气提压），在开销时少花（放气减压）。
```

**易错点：** IABP 不是「心脏泵」，它**不增加心输出量**（不像 ECMO/VAD）——它只改善供需比。
对「泵功能彻底丧失」的心源性休克，IABP 支持不足，应升级到 ECMO 或 VAD。

## 5 适应证选择与并发症

**选择逻辑**：心源性休克 → 快速评估「心脏能否短时恢复」→ 能则 IABP/ECMO 短期支持；
不能恢复则评估移植资格 → 能移则 ECMO/VAD 桥到移植，不能移则 VAD 目的地治疗或 TAH。

**MCS 的共通并发症**：**出血**（抗凝 + 血小板消耗）、**血栓栓塞**（泵内血栓、脑卒中）、**感染**（尤其 LVAD 驱动线感染）、**溶血**（连续流泵剪切力）、**右心衰**（LVAD 后）、**多器官衰竭**（原有休克延续）。<span class="marginnote">MCS 的「抗凝天平」最考验管理：抗凝不足 → 泵血栓（可致卒中或泵停）；抗凝过度 → 出血（颅内出血最致命）。INR、血小板功能与泵参数（功耗、流量波动）是日常监测的三件套——<strong>泵血栓的早期信号是「功耗升高 + 溶血（LDH↑）」</strong>。</span>每台 MCS 的成功，都建立在并发症的精细管理之上。

## 6 机械循环支持的现代格局与争议

MCS 已经从「最后的挣扎」变成**心源性休克的常规武器与终末期心衰的长期方案**，但它的现代格局充满「平衡的艺术」：

**ECPR：心搏骤停中的 ECMO**。**体外心肺复苏（ECPR）**——在心搏骤停后短时间内快速建立 VA-ECMO——正在改写心脏骤停的救治。
对**可逆病因、目击倒地、高质量 CPR 下仍无自主循环**的年轻患者，ECPR 提供了「以时间换机会」的可能。<span class="marginnote">「ECPR 是给骤停的心脏一台备用泵」：常规 CPR 的生存率以个位数计，ECPR 在严格选择的患者中把生存率提升数倍。<strong>关键是「快」</strong>——从倒地到 ECMO 上机的时间窗以分钟计，这也是「休克团队」24 小时待命的意义。</span>

**LVAD 目的地治疗的长期结果**：连续流 LVAD 的**2 年生存率已超过 80%**，与心脏移植的早期生存接近——对不适合移植的老年患者，「带着 LVAD 生活」已是成熟选项。
但**器械相关不良事件（HRAE）**——泵血栓、卒中、出血、感染——仍是长期使用的主要代价。<span class="marginnote">「LVAD 的成功，被并发症打了折扣」：新一代磁悬浮泵（HeartMate 3）的泵血栓率大幅下降，但<strong>卒中与出血仍是悬顶之剑</strong>。<strong>「让机器更少伤人」</strong> 是 LVAD 迭代的主线——每一代泵都在改善血液相容性。</span>

**VA-ECMO 与 LVAD 的衔接**：VA-ECMO 是「急救泵」，不能长期使用；
病情稳定后应**撤 ECMO 或桥到 LVAD**。
现代流程强调**「ECMO 是入口，VAD 是出口」**——ECMO 期间就启动「能不能恢复、能不能移植、要不要 VAD」的评估。<span class="marginnote">「ECMO 拖得越久，并发症越多」：ECMO 的出血、血栓、感染与肢体缺血随天数累积。<strong>「早转 VAD 或早撤机」</strong> 是现代 MCS 的时间纪律——ECMO 不是安身之处，是中转站。</span>

**休克团队与分级响应**：现代医院建立**休克团队（shock team）**——重症、心内、心外、灌注与护理共同响应心源性休克，按「容量→药物→IABP→ECMO/VAD」的阶梯及时升级。**「休克是团队战，不是单兵战」** 是 MCS 时代的管理范式。

| 层面 | 现代实践 |
| --- | --- |
| 急救 | ECPR（骤停后快速 ECMO） |
| 长期 | LVAD 目的地治疗（2 年生存 > 80%） |
| 衔接 | ECMO → 评估 → 撤机/VAD/移植 |
| 组织 | 休克团队 24h 响应 |

## 8 小结

- **MCS 谱系**：IABP（供需比支持）→ ECMO（短期心肺支持）→ VAD（长期心室支持）→ TAH（双室替代）。
- **ECMO**：VA-ECMO 心肺双支持、VV-ECMO 仅肺支持；是「桥」而非终点，警惕南北综合征。
- **LVAD**（连续流）：桥到移植 / 桥到恢复 / 目的地治疗；流量依赖前后负荷，管好主动脉瓣与右心。
- **IABP** 改善心肌供需比：$\dfrac{DPTI}{SPTI}$ 是它的定量内核——舒张期增压（供氧↑）、收缩期减负荷（耗氧↓）双向获益。<span class="marginnote">MCS 的核心思维是「<strong>供需匹配</strong>」：IABP 调节氧供需，ECMO 接管心肺、VAD 替代泵血——选哪种，取决于「缺的是哪一环、缺多久、能恢复吗」。</span>
- **MCS 的终点思想**：每一次支持都要回答「桥到哪」——恢复、移植还是长期替代，没有终点的支持是失败的。
- **抗凝是 MCS 的双刃剑**：VAD/ECMO 都需要抗凝防血栓，却也带来出血风险——「血栓 vs 出血」的平衡是每个 MCS 患者的日常。
- **VAD 也有「自己的并发症」**：泵血栓、出血、主动脉瓣融合、右心衰竭与感染（经皮驱动线）——「把患者交给机器」之后，管理机器的并发症成了医生的新功课。
