## 为什么从并发症讲起

前 11 篇讲的是「麻醉如何成功」，这一篇讲「麻醉如何失败」——而且是**如何被及时识别与挽救**。麻醉安全是现代医学的奇迹之一：致命事件率已降到万分之一量级，靠的正是「**并发症清单 + 模拟演练 + 团队沟通**」这套制度。学习并发症的正确姿势不是背「吓人清单」，而是抓住一条主线：**每种并发症都有一个「最早的信号」，而那个信号几乎总藏在常规监测里**。学会「看信号」，就学会了处理的第一步。

## 1 术中知晓与反流误吸

**术中知晓（intraoperative awareness）**：患者在全麻中恢复意识却无法活动（肌松在身），可能感知疼痛与恐惧。发生率约 0.1%–0.2%（高危人群如心脏手术、创伤、急诊剖宫产更高）。**防范**：BIS/麻醉深度监测（第 5、7 篇）、避免「肌松有余、催眠不足」的失衡配方、用足够 MAC。<span class="marginnote">知晓的典型信号在麻醉单上：术中血压心率「不明原因」持续升高、体动。多数知晓是「催眠药不足」而非「药没了」——复合肌松下的「假平稳」是最危险的。</span>术后随访时温和地问「还记得手术中的事吗」，是麻醉医师的人文功课。

**反流误吸（aspiration）**：胃内容物进入下呼吸道，引发**化学性肺炎（Mendelson 综合征）**。风险最高的是「饱胃」患者（急诊、肠梗阻、妊娠、肥胖），防范就是第 4 篇的 RSI + 术前禁食；一旦发生：头低侧位、吸引、气管插管、支气管镜清理、必要时激素与抗生素（争议性）——**重点永远是预防**。Mendelson 综合征的本质是强酸胃液对肺泡的直接化学损伤，数小时内即可出现支气管痉挛、肺水肿与低氧，比细菌性肺炎来得更快更凶——这正是「为何禁食与 RSI 不容商量」的病理答案。

两个「意外苏醒类」意外放一起对比，信号与处置一目了然：

| 对比项 | 术中知晓 | 反流误吸 |
| --- | --- | --- |
| 本质 | 催眠不足、意识残留 | 胃内容物进入下呼吸道 |
| 危险人群 | 心脏/创伤/急诊剖宫产 | 饱胃、肠梗阻、妊娠、肥胖 |
| 最早信号 | 血压心率不明原因升高、体动 | 气道压升高、SpO₂ 下降 |
| 首要防线 | 深度监测 + 足够催眠药 | 禁食 + RSI |
| 发生后 | 术后随访与心理干预 | 头低侧位 + 吸引 + 插管清理 |

## 2 恶性高热：最典型的「信号型」急症

**恶性高热（malignant hyperthermia, MH）**是遗传性骨骼肌疾病（**RYR1 受体突变**）在挥发性麻醉药或琥珀胆碱触发下的**失控性肌浆内钙超载**：肌肉持续强直收缩 → 产热剧增、耗氧剧增、肌细胞溶解。它是一张教科书级的「由监测信号组成的暴风雨」：

**最早信号**：呼气末 CO₂（EtCO₂）**不明原因骤升**——肌收缩代谢产 CO₂，这是第 11 篇肺泡通气方程的活体演示（CO₂ 产得多，分压就高）；
- 体温每小时上升 1–2°C、咬肌痉挛、心动过速、混合性酸中毒、高钾血症、横纹肌溶解（血 CK、肌红蛋白升高）。

**处理是「全手术室动员」**，按清单逐项执行：

- **停**：立即停用触发药（吸入麻醉药 + 琥珀胆碱），改用非触发药维持；
- **通**：纯氧高流量过度通气，把 CO₂ 迅速排出去；
- **解**：静注丹曲林（dantrolene）2.5 mg/kg 起、可重复，直到 EtCO₂ 回落、肌肉松弛；
- **凉**：冰毯、冷生理盐水灌洗，目标 38°C 即止（避免过冷）；
- **纠**：纠酸、纠高钾、按心律失常处理（避免钙通道阻滞剂）。

丹曲林直接结合 RYR1 受体抑制钙释放，是 MH 的唯一特效药——**抢救 MH 的第一分钟拼的不是知识，是「手术室抽屉里有没有丹曲林」**。<span class="marginnote">MH 发病率约 1/100,000（麻醉中），有家族史者术前必须改「安全方案」：用 TIVA（丙泊酚 + 阿片 + 非去极化肌松）+ 清醒体温监测，同时备好丹曲林。DNA 检测 RYR1 可作确诊依据。</span>

**MH 的临床鉴别**：发热 + 肌强直 + 酸中毒的组合也见于抗精神病药恶性综合征（NMS）、脓毒症、甲状腺危象与神经阻滞剂过量。关键线索：MH 常在诱导后不久发生、EtCO₂ 与体温上升几乎同步、咬肌痉挛是特征性早期表现；NMS 多在药物剂量调整后数日缓慢起病，且没有「停触发药即缓解」的路径。**怀疑 MH 时不纠结于确诊，先按 MH 处理再鉴别**——丹曲林是唯一特效药，无害且救命。

**已确诊或高危者的「安全麻醉」方案**：

| 环节 | 触发药（禁用） | 安全替代 |
| --- | --- | --- |
| 吸入麻醉 | 七氟烷 / 地氟烷 / 异氟烷 | 纯静脉丙泊酚（TIVA） |
| 肌松 | 琥珀胆碱 | 非去极化肌松药 |
| 体温 | —— | 连续核心体温监测 |

## 3 公式解析：Q₁₀ 与「热失控」的正反馈

MH 的致命性在于一个**正反馈循环**，可用温度对反应速率的影响来量化——**Q₁₀ 效应**：

$$
Q_{10} = \left(\frac{R_2}{R_1}\right)^{\frac{10}{T_2 - T_1}}
$$

- **第一步，读符号**：$R_1$、$R_2$ 是温度 $T_1$、$T_2$ 下的反应速率；Q₁₀ 是「温度升高 10°C 反应速率扩大的倍数」。多数生化反应 Q₁₀ ≈ 2–3。
- **第二步，直觉**：体温从 37°C 升到 47°C，若 Q₁₀ = 2，则代谢产热翻 4 倍——**产热↑ → 体温↑ → 代谢更快 → 产热更多**，这是正反馈的自加速失控。<span class="marginnote">对比正常生理：下丘脑的体温调节是「负反馈」，散热随温度升高而加强；MH 中肌肉不受调控地产热，负反馈失效，唯一能打断循环的是丹曲林（关掉钙释放源头）+ 主动降温。</span>
**第三步，临床推论**：MH 的 EtCO₂ 骤升与体温每小时 +1~2°C 正是 Q₁₀ 的宏观表现；**这也解释了为什么一旦怀疑 MH，降温要「极积」**——每次拖延都让正反馈多转一圈，而体温 > 41°C 后蛋白变性不可逆。

**一个可感的数字**：若某肌肉代谢反应 Q₁₀ = 2.5，体温从 38°C 升到 41°C（仅 3°C），反应速率扩大约 $2.5^{0.3} \approx 1.32$ 倍——初看不大，但它是「每升高 3°C 就再放大三分之一」的复利过程，叠加几分钟就成指数级。这正是 MH 里「体温看起来才 39°C、代谢已全线失控」的原因。

**高钾血症**常与 MH 相伴（肌肉溶解释放 K⁺）：处理含葡萄糖 + 胰岛素 + 钙剂（拮抗心肌毒性）+ 碳酸氢钠，并警惕**琥珀胆碱 + 高钾**的组合（第 8 篇提过）——琥珀胆碱使血钾升 0.5–1 mmol/L，对已高钾患者可诱发室颤。

## 4 药物错误、过敏与手术室火灾

**药物错误**是麻醉不良事件里「最不该有却最常见」的一类：剂量错误、药名混淆（如顺阿曲库铵 vs 阿曲库铵）、输液泵设置错误。防线是**标准化**：核对「五对」（患者、药名、剂量、途径、时间）、药物标签显式标注、高危药（钾、肾上腺素、胰岛素）独立双核对。<span class="marginnote">手术室的「三读一核」与航空业的 checklist 同构——把「人一定会犯错」设为前提，用流程把错误挡在门外。这是安全科学（第一级《概率》里的条件概率思维）在医疗的移植。</span>

**过敏反应（anaphylaxis）**：严重者休克 + 支气管痉挛 + 荨麻疹。常见触发物：肌松药（罗库溴铵）、抗生素（头孢类）、乳胶、消毒液氯己定。处理：停可疑药 + 肾上腺素肌注（0.5 mg 成人）+ 补液 + 组胺拮抗 + 必要时气管插管。**识别要点**：术中不明原因「血压骤降 + 气道压骤升 + 皮肤潮红」三联征，先怀疑过敏。

**常见触发物速查**：

| 触发物 | 典型场景 | 备注 |
| --- | --- | --- |
| 肌松药（罗库溴铵） | 全麻诱导 | 琥珀胆碱亦可 |
| 抗生素（头孢类） | 切皮前预防用药 | 术中最常被忽略 |
| 乳胶 | 手套、尿管、止血带 | 多次手术者风险升高 |
| 氯己定 | 皮肤消毒 | 黏膜接触更易致敏 |

**过敏的分级应对**：按严重程度逐级升级——轻度（荨麻疹）停药观察；中度（气道压升、低血压）肾上腺素 0.5 mg 肌注 + 补液；重度（休克、支气管痉挛、喉水肿）气管插管 + 持续肾上腺素输注。**插管指征要放宽**：喉水肿是过敏死亡的主因之一，犹豫观望常常比药物更危险。

**手术室火灾**：三要素——氧化剂（纯氧/笑气）+ 燃料（酒精消毒液、纱布）+ 引燃源（电刀、激光）。酒精消毒液未干即用电刀是最常见成因——**让消毒剂挥发干燥**是成本最低的防火措施。火灾处置：停气、灭火、撤离。

**药物错误的三种典型长相与各自防线**：

| 错误类型 | 实例 | 防线 |
| --- | --- | --- |
| 剂量错误 | 肾上腺素 1 mg 误当 0.1 mg | 高危药独立双核对 |
| 药名混淆 | 顺阿曲库铵 vs 阿曲库铵 | 标签显式标注、读标签不凭记忆 |
| 泵速错误 | TCI 输注单位设错 | 复核泵速与稀释浓度 |

## 5 术后认知与残余肌松

**术后谵妄（POD）与术后认知功能障碍（POCD）**：老年人、低功能状态、深度麻醉（低 BIS 长时程）、苯二氮䓬类药物与低血压（脑灌注不足，第 7 篇 CPP）都是危险因素。防：**避免过深麻醉、维持脑灌注、减少抗胆碱药、早期活动与家属陪伴**。老年麻醉的「少即是多」原则在此集中体现。<span class="marginnote">POCD 的机制研究（神经炎症、突触可塑性改变）让「麻醉会不会伤脑」成为热点，但现代证据更支持「麻醉深度与低灌注」是可控因素——麻醉方案可以主动降低认知风险。</span>

**残余肌松**：第 5 篇已提 TOF ≥ 0.9 才能拔管，这里强调后果——拔管后呼吸道塌陷、误吸、缺氧延长。**逆转剂**：新斯的明（拮抗非去极化）或舒更葡糖钠（sugammadex，包裹罗库溴铵分子直接「吸走」）——后者是肌松逆转的范式革命，把「等药物自己代谢」变成「立刻清除」。

**为什么 TOF 是「功能」而非「时程」**：肌松药的消退时间个体差异巨大——肝功能、体温、酸碱状态、药物相互作用都会改写代谢速度。「术后 2 小时肯定退了」是危险假设，唯有把四个成串刺激的比值量出来才算数。残余肌松在未监测人群中发生率可高达 40%–50%，而拔管前常规 TOF 监测能把相关呼吸道并发症明显压低——这是「用仪器代替感觉」最成功的范例之一。

**老年患者的「三重易感」**：肝肾功能下降使药物清除变慢、脑对麻醉药更敏感（同等浓度意识恢复更慢）、肌肉质量下降使残余阻滞更明显——所以老年麻醉的苏醒标准要更严，拔管前除 TOF ≥ 0.9 外，还要看能否持续抬头 5 秒、潮气量是否足够。

**术后恶心呕吐（PONV）**是术后最常见的「不致命却最扰人」的并发症：危险因素包括**女性、不吸烟、晕动/晕船史、既往 PONV 史、术后阿片用量**。防：高危者预防性止吐（5-HT₃ 拮抗剂 + 地塞米松联合），术中减少笑气与阿片用量。发生率与患者满意度、住院时长直接挂钩，别把它当「小事」。

**PONV 危险因素速查**：

| 危险因素 | 说明 |
| --- | --- |
| 女性 | 风险约为男性 2 倍 |
| 不吸烟 | 吸烟者风险反而较低 |
| 晕动/晕船史 | 前庭易感 |
| 术后阿片 | 剂量越大风险越高 |

## 6 并发症速查：最早信号与第一步处置

| 并发症 | 最早信号 | 第一步处置 |
| --- | --- | --- |
| 术中知晓 | 血压心率不明原因升高、体动 | 加深麻醉，术后随访沟通 |
| 反流误吸 | 气道压升高、SpO₂ 下降 | 头低侧位、吸引、插管清理 |
| 恶性高热 | EtCO₂ 骤升、咬肌痉挛 | 停触发药 + 丹曲林 2.5 mg/kg |
| 过敏反应 | 血压骤降 + 气道压骤升 + 皮肤潮红 | 停可疑药 + 肾上腺素 0.5 mg 肌注 |
| 手术室火灾 | 电刀火花 + 酒精湿区 | 停气、灭火、撤离 |
| 残余肌松 | TOF < 0.9、抬头无力 | 新斯的明 / 舒更葡糖钠 |

这张表是「看信号 → 动手」的压缩：每种并发症都先被一个常规监测里的数字或波形抓住，处置动作高度模式化。把它当成「麻醉版的急救 checklist」来记，比孤立背每一条细节有效得多。

## 7 小结

- 并发症的共性：**最早的信号都在常规监测里**——知晓看「不明原因血压心率升高」，MH 看「EtCO₂ 骤升 + 咬肌痉挛」。
- **MH**：RYR1 突变 + 触发药 → 钙超载 → 正反馈产热；**处理 = 停触发药 + 丹曲林 + 降温纠酸**；Q₁₀ 效应解释了「热失控」的加速性。
- 反流误吸重在**预防**（禁食 + RSI）；知晓重在**深度监测与配方平衡**。
- **药物错误靠流程防**（五对核对 + 高危药双核）；过敏靠「三联征识别 + 肾上腺素」；火灾靠「酒精干透」。
- 残余肌松靠 **TOF ≥ 0.9** 把关，舒更葡糖钠可即时逆转；老年麻醉防谵妄 = 防过深 + 保灌注。
- PONV 别当小事：女性、不吸烟、晕动史、术后阿片是四大危险因素。
- 速查表的哲学：**信号在监测里，处置是流程**——把「怕」换成「先做哪一步」。

在最后一篇，把疼痛从「并发症」升级成「独立学科」——**疼痛医学**：从伤害性通路的机制到慢性疼痛的用药与治疗窗口。
