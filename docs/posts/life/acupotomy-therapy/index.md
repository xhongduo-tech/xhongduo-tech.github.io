# 针刀医学（小针刀疗法）

针刀医学由朱汉章教授创立，将中医针灸针与现代外科手术刀融为一体，以针刀闭合性手术松解慢性软组织损伤的粘连、瘢痕与卡压，是融合中医学、西医解剖学与生物力学的新兴交叉学科，现已发展为独立本科专业并设立执业资格。学完本学科，就系统写完了从针刀医学基础理论、应用解剖与生物力学，到操作技术规范与常见病临床诊疗的全部内容。

## 对标教材

- 《针刀医学原理》朱汉章主编，人民卫生出版社
- 《针刀医学》全国中医药行业高等教育规划教材（中国中医药出版社）
- 中华中医药学会针刀分会《针刀医学临床诊疗技术操作规范》
