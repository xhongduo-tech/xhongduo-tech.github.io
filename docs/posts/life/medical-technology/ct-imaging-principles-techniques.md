## 为什么从 CT 的数学本质开始

常规 X 线摄影的致命弱点是**组织重叠**：三维身体被压成一张二维片子，前后结构叠在一起，病灶可能被遮挡。1972 年，亨斯菲尔德把 X 线管装到旋转机架上，从**无数个角度**对同一层面采集投影，再用计算机重建出横断面图像——这就是**CT（Computed Tomography，计算机断层成像）**。它把「看图」变成了「解方程」：从一大堆投影数据里反算出每个体素的衰减系数。

对「从极限到大模型」的读者来说，CT 是理解「**从测量数据重建未知函数**」最直观的医学实例——它与第二级《数学分析》里的积分、第三级《数字信号处理》里的傅里叶变换直接相连。<span class="marginnote">CT 重建的数学本质是「由投影重建函数」，即 Radon 变换与其逆变换。傅里叶切片定理说明：某方向的投影经一维傅里叶变换，恰好等于图像二维傅里叶变换在该方向的一根「切片」——采集足够多角度，就能拼出完整的二维频谱。</span>

从 1972 年第一台 EMI 头颅扫描仪到今天的 320 排宽体 CT，五十余年间 CT 经历了「头颅扫描 → 全身扫描 → 螺旋 → 多层 → 双能量 → 光子计数」的快速演进，几乎每一代都在「扫得更快、切得更薄、剂量更低、信息更多」四个维度上同时推进。临床上的应用早已不限于横断面解剖：一次胸部 CT 可以同时看肺结节、纵隔淋巴结、胸壁与肋骨；CTA 让冠状动脉像解剖标本一样清晰；灌注 CT 能定量评估脑缺血组织的存活状态。CT 的辐射剂量问题始终伴随其发展，但「低剂量技术的进步」已让一次胸部 CT 的剂量大幅下降——这也是后面「影像质量控制」一节要专门展开的话题。

## 1 CT 的成像链：从扫描到重建

CT 的物理成像链分四步：

1. **X 线扇形束穿透人体**：机架一侧的球管发出扇形 X 线束，穿过人体层面后由对面弧形排列的探测器阵列接收。
2. **采集多角度投影**：机架绕人体旋转，每转过一个小角度就采集一组投影数据。扫描一周可获得数百个角度的测量。
3. **数字化与对数运算**：每个探测器测得的是透射强度 $I$，经对数变换转成「投影值」（与沿径线积分的 $\mu$ 成正比），这就是 Radon 变换意义上的投影数据。
4. **重建算法反算图像**：由全部角度的投影反推每个体素的 $\mu$ 值，形成横断面数字图像。<span class="marginnote">早期用「迭代重建」，因计算量大被「滤波反投影（FBP）」取代；如今计算能力回升，迭代与深度学习重建重新流行，能在更低剂量下保持图像质量。</span>

**CT 的图像本质是一张数字矩阵**：每个像素对应一个代表该处平均衰减的数值，这个值就是 **CT 值（Hounsfield 单位，HU）**。

## 2 公式解析：CT 值与窗宽窗位

**CT 值把「衰减系数」翻译成一张便于人眼判读的刻度表。**

$$
\text{HU} = \frac{\mu - \mu_{\text{water}}}{\mu_{\text{water}}} \times 1000
$$

- $\mu$：被测体素的线性衰减系数；$\mu_{\text{water}}$：水的线性衰减系数。
- 标尺约定：水为 0 HU，空气约为 $-1000$ HU，骨皮质约 $+1000$ HU，软组织约 $20 \sim 80$ HU，脂肪约 $-100 \sim -50$ HU。
- 人类的灰白质、肝脏、脾脏等软组织之间 HU 差只有几十甚至十几个单位，单靠一张灰度图无法分辨——于是需要**窗宽窗位（window width / window level）**技术。

**窗位（WL）**是显示的中心 CT 值，**窗宽（WW）**是显示的范围。落在窗口内的 CT 值被线性映射为 256 级灰阶，窗口之外的则一律为全黑或全白。<span class="marginnote">举例：肺窗（WW≈1500，WL≈-600）把空气到软组织的跨度压进灰阶，专门看肺纹理；纵隔窗（WW≈350，WL≈40）用窄窗拉开软组织差异，专门看心脏与大血管。同一组数据换几个窗，就能「看」出不同的组织层次——这是读 CT 的第一课。</span>

常用窗参数的量级值得作为常识记住：

| 窗类型 | 窗宽（WW） | 窗位（WL） | 用途 |
| --- | --- | --- | --- |
| 肺窗 | 1500 | -600 | 肺实质、气胸、肺纹理 |
| 纵隔/软组织窗 | 350–400 | 40–50 | 心脏、大血管、纵隔淋巴结 |
| 骨窗 | 1500–2000 | 400–500 | 骨骼、骨折、骨肿瘤 |
| 脑窗 | 80–100 | 35–40 | 脑实质灰白质对比、出血 |
| 腹部窗 | 350–400 | 30–50 | 肝脾胰肾实质 |

窗宽窗位是「数字到视觉」的映射参数，它不改变原始数据，只改变显示方式——因此**同一组 CT 数据可以「看」出无数种图像**。读片时漏掉病灶，最常见的原因之一就是「窗用错了」：气胸在纵隔窗下几乎看不见，细小骨折在软组织窗下会被淹没。理解窗的本质（线性灰阶映射的区间与中心），是读懂 CT 的数学起点。

## 3 扫描方式的演进

| 代际 | 扫描方式 | 特点 |
| --- | --- | --- |
| 早期序列扫描 | 每层旋转 1 圈后床停、扫下一层 | 层与层之间有空隙，易漏小病灶 |
| 螺旋 CT | 球管连续旋转 + 检查床匀速前进 | 一次屏气扫完整个脏器，无层间空隙 |
| 多层螺旋 CT（MSCT） | 探测器排数增至 16/64/320 排 | 亚毫米层厚、扫描时间秒级，支撑冠脉 CTA |
| 双源/能谱 CT | 两套球管-探测器系统 | 双能量分辨物质成分，心脏冻结运动伪影 |

**双能量 CT（能谱 CT）**值得单独说明：它用两个不同能量（如 80 kV 与 140 kV）的 X 线对同一组织成像，因为不同物质（钙、碘、尿酸、软组织）在不同能量下的衰减差异不同，可以「物质分离」——例如把造影剂与钙化分开（去骨 CTA）、识别痛风石的尿酸成分、虚拟平扫减少一次真实扫描。这是 CT 从「形态」走向「成分」的一步，也再次说明「多一个能量维度，就多一层信息」。

现代临床 CT 几乎全是**多层螺旋 CT**。衡量螺旋扫描的两个核心参数：

- **层厚（slice thickness）**：探测器准直与重建决定的图像厚度，越薄空间分辨率越高、噪声也越大。
- **螺距（pitch）**：等于每旋转一周检查床移动的距离除以准直束宽度。**螺距 = 1** 表示床速恰好使相邻螺旋紧贴无重叠；螺距增大扫描更快但层面更稀疏。<span class="marginnote">高螺距在心脏与儿科检查中特别有用——转速快、屏气时间短，代价是 z 轴采样变疏，需要重建算法补偿。</span>

扫描前还需设定一组常被人忽略的参数：

| 参数 | 作用 | 临床取舍 |
| --- | --- | --- |
| 扫描野（FOV） | 重建图像的范围 | 过小会截断解剖、过宽浪费像素 |
| 重建矩阵 | 像素网格大小（如 512×512） | 矩阵大则像素小、细节多但噪声增 |
| 滤波函数/算法 | 决定空间分辨率与噪声的平衡 | 骨算法锐利、软组织算法平滑 |
| 剂量参数（mAs/kV） | 决定噪声与剂量 | 按体质量调节、儿科用低剂量协议 |
| 对比剂流量与延迟 | 决定增强时相 | 动脉期/静脉期/延迟期各有所需 |

这些参数共同决定了「一张 CT 长什么样」：同样一个病人，用肺算法重建与用软组织算法重建，图像的锐利度和噪声质感完全不同。读片与后处理都依赖这些「重建前设定」，因此技师必须在扫描前想清楚「这个临床问题需要什么图像」，再选择参数组合。

## 4 CT 检查技术：平扫、增强与 CTA

CT 检查按是否使用造影剂分三类：

- **平扫**：不注射造影剂直接扫描，用于颅脑出血、肺结节筛查、骨折等天然对比充分的检查。
- **增强扫描**：静脉团注碘对比剂后在不同延迟时间扫描。对比剂随血流分布，病灶的血供特点决定其强化规律——动脉期、静脉期、延迟期各看什么，由病灶性质与临床问题决定。增强扫描能区分富血供与乏血供病变、判断血管是否被侵犯。<span class="marginnote">「强化」（enhancement）指病灶在注射对比剂后 HU 值升高，反映其血供丰富程度。肝癌的「快进快出」、血管瘤的「渐进性充填」，都是各病灶独有的强化曲线，读片者据此猜病理性质。</span>
- **CTA（CT 血管成像）**：在对比剂充盈动脉的峰值时刻快速扫描，配合三维重建显示血管树，广泛用于冠脉、脑动脉瘤、主动脉夹层的诊断。

此外还有两个不可忽视的专项技术。**低剂量 CT（LDCT）**是肺癌筛查的标准工具：用明显降低的 mAs 与迭代重建，在可接受图像质量下把剂量压到常规 CT 的 1/5 甚至更低，让「给无症状人群做筛查」成为可能。**儿科 CT** 则贯彻「儿童不是小大人」原则：按体重而非年龄设定专用低剂量协议，尽量减少辐照——儿童组织对辐射更敏感，其累积风险高于成人，因此儿科 CT 是剂量管理最严格的领域。

增强扫描的**时相选择**是技术方案的核心：以腹部增强为例，注射对比剂后约 20–30 秒为**动脉期**（看富血供病灶、动脉瘤），约 60–70 秒为**门静脉期**（看肝实质与门脉供血的转移灶），约 2–3 分钟后为**延迟期**（看造影剂廓清、纤维化）。「快进快出」的肝癌在动脉期强化、门脉期快速退出，血管瘤则呈「渐进性充填」——这些经典强化曲线，都依赖时相精准的扫描技术才能捕捉。因此技师要与影像医师共同商定「打药方案」，一次腹部增强检查常常要扫 3–4 个时相。

检查技术还包括**扫描参数选择**（kV 按体质量与部位、mAs 按噪声要求）、**重建方式**（软组织/骨算法）、**三维后处理**（MPR 多平面重建、VR 容积再现、血管追踪）。一次成功的 CT 检查，是物理、数学、解剖与临床问题四者的协同——这也正是「检查技术」区别于「成像原理」的地方：原理讲「为什么能成像」，技术讲「具体怎么扫出最有用的图像」。

## 5 小结

CT 检查技术的总纲可以浓缩为一句话：**先问临床问题，再定扫描方案**。是看肺结节（薄层+肺窗重建）、看骨折（薄层+骨算法）、看血管（CTA+动脉时相），还是看肿瘤分期（增强多时相+三维后处理）——方案完全由问题驱动。技术与原理的分界也正在于此：原理回答「这台机器为什么能成像」，技术回答「这次检查该怎么扫、用什么参数、选什么时相」。掌握这门「方案设计」的能力，需要把物理知识（kV/mAs 与噪声剂量的关系）、解剖知识（目标结构与周围关系）与临床知识（病灶强化特征）三者打通——这正是医学技术作为一门学科的核心素养。

- CT 用**多角度投影 + 计算机重建**消除组织重叠，是「由投影重建函数」的工程实现。
- **CT 值（HU）**以水为 0、空气约 −1000、骨约 +1000，是密度测量的统一标尺；窗宽窗位是把它映射成灰阶的「显示参数」。
- 扫描方式从序列、螺旋到多层、双能量演进；**层厚、螺距、矩阵、滤波函数**共同决定重建图像的特性。
- 增强扫描靠碘剂的血流动力学分布，**时相选择**（动脉期/静脉期/延迟期）决定能捕捉到什么强化模式。
- 低剂量 CT 与儿科专用协议是「剂量-图像质量」权衡的严格实践。
- 图像本质是**CT 值矩阵**，$\text{HU} = (\mu - \mu_{\text{water}})/\mu_{\text{water}} \times 1000$，水的 CT 值为 0。
- CT 检查方案设计遵循「原理-参数-时相-重建」四要素链，按临床问题组合成工程方案。
- **窗宽窗位**把窄动态范围的软组织差异映射进灰阶，同一数据换窗看不同组织。
- 扫描方式从序列、螺旋到多层螺旋演进，**螺距与层厚**是螺旋扫描的关键参数。
- 检查分**平扫、增强、CTA**，增强依赖碘对比剂的血流动力学分布。
- CT 检查方案按「原理-参数-时相-重建」设计，先问临床问题再定扫描方案。

在下一节，我们将深入 CT 的「幕后工程」——**CT 图像重建与后处理**：滤波反投影怎么算、为什么会有伪影、三维后处理如何把几百张断层片重组成看得懂的解剖结构。记住本节的两条主线：CT 值是「密度数字」，重建是「数字到图像的数学」；而检查技术的全部意义，在于让这两者恰好服务于当前的临床问题。
