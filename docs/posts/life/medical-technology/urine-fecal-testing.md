## 为什么尿液是「最容易得到的标本」

尿液与粪便没有创伤、取样方便、可反复采集，却承载着大量生理与病理信息。尿是血液经肾小球滤过、肾小管重吸收与分泌后的「滤液」，血液里的小分子改变常常先出现在尿里；粪便是消化道的「最终产物」，消化道出血、感染、寄生虫都会留下痕迹。<span class="marginnote">尿液检验与第五级《生理学》的肾单位功能直接对应：肾小球滤过膜有没有破（蛋白尿、血尿）、肾小管重吸收好不好（尿糖、尿比重）、集合管浓缩功能如何——「尿是肾的语言」。现代尿干化学把几十项生化指标压进一条试纸条，本质是把尿液变成可批量扫描的传感器阵列。</span>

## 1 尿干化学分析：十项试纸的物理学

尿干化学试纸条上按序排布若干反应垫，蘸尿后各垫显色，仪器按反射光度判读。核心项目及其意义：

| 项目 | 阳性提示 | 关键辨析 |
| --- | --- | --- |
| pH | 反映酸碱平衡 | 高蛋白饮食偏酸、素食偏碱 |
| 比重（SG） | 肾浓缩功能 | 固定于 1.010 提示肾小管损伤 |
| 蛋白质（PRO） | 蛋白尿 | 生理性（发热、运动）vs 病理性 |
| 葡萄糖（GLU） | 血糖超过肾糖阈 | 糖尿病；也见于肾性糖尿 |
| 酮体（KET） | 脂肪分解加速 | 糖尿病酮症、饥饿、剧烈运动 |
| 潜血（BLD） | 尿中红细胞/血红蛋白 | 血尿 vs 血红蛋白尿 |
| 白细胞酯酶（LEU） | 白细胞存在 | 尿路感染线索 |
| 亚硝酸盐（NIT） | 硝酸盐还原菌 | 大肠埃希菌等尿路感染 |
| 胆红素（BIL） | 肝胆疾病 | 结合胆红素升高 |
| 尿胆原（URO） | 肝/溶血状态 | 需结合尿胆红素共同判读 |

两个「最常用却最易误读」的项目值得专门辨析：

- **亚硝酸盐（NIT）与白细胞酯酶（LEU）**：两者联合是尿路感染的「双保险」——多数尿路致病菌（大肠埃希菌等）能把尿中硝酸盐还原为亚硝酸盐，白细胞酯酶则提示尿中有白细胞。但「NIT 阴性」不能排除尿路感染：产亚硝酸盐的菌才阳性，而肠球菌、淋球菌等不产酶，且尿在膀胱停留时间过短、细菌来不及还原。因此「LEU 阳性 + NIT 阴性」仍高度怀疑感染，需镜检+培养确认。
- **尿糖与酮体**：尿糖阳性是「血糖超过肾糖阈」的信号，但糖尿病肾病晚期肾糖阈升高，血糖很高而尿糖可阴性；生理性糖尿（妊娠、餐后）也非病理。酮体阳性提示脂肪分解加速，糖尿病酮症、饥饿、剧烈运动均可见——「看到酮体，先问病人饿不饿、是不是糖尿病」，这是急诊最常见的尿干化学判读场景。

**干化学是筛查而非诊断**：假阳性与假阴性都常见（如维生素 C 干扰糖与潜血、陈旧尿细菌繁殖改变 pH 与亚硝酸盐），异常结果必须**尿沉渣镜检**确认。<span class="marginnote">「干化学+镜检」的双轨制是尿液检验的基本原则：试纸给出广谱线索，显微镜给出形态学证据。两者互相印证，缺一不可——这正是检验医学「筛查-确认」两步法思想的缩影。</span>

尿液标本的采集规范是干化学结果可靠的前提，三条铁律值得记牢：

- **留中段尿**：先排尿弃去前段，接中段尿于无菌容器——前段尿含尿道口污染，中段尿更能代表膀胱内尿液。
- **晨尿最佳**：晨起第一次尿最浓缩、成分最稳定，适合蛋白、红细胞、管型等检出；随机尿便于随时留取，但浓度变异大。
- **及时送检**：尿在室温放置超过 1–2 小时，细菌繁殖会分解尿素升高 pH、消耗葡萄糖与酮体、溶解红细胞与管型——「放久的尿」会系统性「谎报」：糖低了、酮低了、pH 高了、管型没了。

这三条铁律的背后是「标本离体后仍在变化」的客观事实——检验医学对标本时效性的要求，本质上是「对检测对象稳定性的尊重」。尿液如此，血液、粪便、组织亦然。

## 2 尿沉渣镜检：把「阳性」变成「形态」

离心后的尿沉渣在显微镜下观察，是尿液检验的灵魂。**标准化操作**是镜检可重复的前提：定量取尿 → 恒定转速与时间离心 → 弃去上清 → 留定量沉渣 → 混匀后定量滴片 → 高倍镜下按顺序浏览，记录每个视野的平均数。看似机械的步骤，实际是在控制「浓度」这个变量——离心时间不足则成分丢失、滴片量过多则计数虚高。检验操作标准化的意义，正在于让「肉眼观察」也能定量、可比、可复核。

- **红细胞**：每高倍视野 >3 个为**血尿**。畸形红细胞（棘形、靶形）提示肾小球源性血尿，正常形态红细胞多提示泌尿道出血。
- **白细胞**：增多提示泌尿系感染；**白细胞管型**是肾盂肾炎的有力证据。
- **管型（casts）**：蛋白质在肾小管内凝聚成的柱状体。**透明管型**可偶见于正常人（运动后）；**颗粒管型**提示肾实质病变；**红细胞管型**几乎特异于肾小球肾炎。<span class="marginnote">管型是「肾小管的铸件」——它只在肾小管内形成，因此一旦出现，病变定位几乎锁定在肾实质而非下尿路。一个红细胞管型比一堆零散红细胞更能说明问题，因为它证明了红细胞是在肾单位内漏出的。</span>
- **结晶**：草酸钙（常见、意义需结合）、尿酸、磷酸盐结晶；胱氨酸结晶提示遗传性胱氨酸尿。

管型的种类与临床意义可以列成一张表，它是尿沉渣镜检最「值钱」的部分：

| 管型类型 | 形态特征 | 临床提示 |
| --- | --- | --- |
| 透明管型 | 无色透明、两端圆钝 | 正常可偶见；大量见于肾小管病变 |
| 颗粒管型 | 内含颗粒 | 肾实质病变、肾盂肾炎 |
| 红细胞管型 | 内含红细胞 | 肾小球肾炎（特异性高） |
| 白细胞管型 | 内含白细胞 | 肾盂肾炎、间质性肾炎 |
| 上皮细胞管型 | 内含肾小管上皮 | 急性肾小管坏死 |
| 蜡样管型 | 宽大、折光强 | 慢性肾衰（晚期） |
| 脂肪管型 | 内含脂肪滴 | 肾病综合征 |

管型的「形态递进」本身就有诊断线索：从透明、颗粒到蜡样，反映病变从急性、活动性走向慢性、终末期——蜡样管型几乎只在慢性肾衰竭中出现。一张尿沉渣片上的管型谱，就是一份「肾病进展的考古地层」。

## 3 蛋白尿与血尿：两个经典辨析

**蛋白尿**分两类：**生理性**（剧烈运动、发热、直立位，量少、一过性）与**病理性**。病理性又按成因分**肾小球性**（滤过膜损伤，白蛋白为主）与**肾小管性**（重吸收障碍，小分子蛋白为主）。**24 小时尿蛋白定量 > 3.5 g 称为肾病性蛋白尿**，是肾病综合征的诊断要素。<span class="marginnote">「微量白蛋白尿」是现代糖尿病肾病监测的窗口：在常规蛋白尿出现之前，尿中白蛋白排泄率已轻度升高——早发现、早干预可延缓肾衰竭。检验的价值有时不在诊断已病，而在预警未病。</span>

蛋白尿的定量与分型还涉及两个经典技术问题。其一是**「蛋白尿」与「尿蛋白试纸」的不完全对应**：试纸对白蛋白敏感、对球蛋白与本周蛋白（Bence-Jones 蛋白）不敏感，因此「试纸阴性」不能排除多发性骨髓瘤等本周蛋白尿——需要**尿蛋白电泳**或**免疫固定电泳**识别。其二是**「定性」与「定量」的鸿沟**：随机尿的蛋白定性（±、+、++）受尿浓度影响，同一蛋白量在高比重尿里「++」、在低比重尿里可能「±」——所以判断蛋白尿严重程度必须用 24 小时定量或「尿蛋白/肌酐比值」校正尿浓度。这两个技术细节说明：**尿干化学是「筛」，专门的蛋白分析才是「定」**，这也是检验「筛查-确认」双轨制在尿液检验中的再次体现。

**血尿**先看是真性还是假性：月经污染、剧烈运动、血红蛋白尿均可呈「尿潜血阳性」。确认真性血尿后，**红细胞形态**区分来源（肾小球 vs 下尿路），再结合尿蛋白量、管型与影像定位。

血尿的形态学分层是尿液检验的精华：**畸形红细胞比例 > 80%** 多提示肾小球源性（红细胞挤压通过受损滤过膜而变形），**正常形态红细胞为主** 多提示下尿路出血（结石、肿瘤、感染）。这个「红细胞形态学」判断把血尿的来源分成「内科性（肾实质）」与「外科性（泌尿道）」两条路径——前者去做肾内科检查（尿蛋白、肾活检），后者去做影像（泌尿系超声/CT）与膀胱镜。一次尿沉渣镜检的形态观察，直接决定后续的检查方向，这正是检验「引导决策」价值的体现。

## 4 粪便检验：消化道的「体检报告」

如果说尿液是肾脏的窗口，粪便就是消化道全程的「下游监测站」——从食管、胃、小肠到结直肠的出血、感染、肿瘤与吸收异常，最终都会以某种形式在粪便里留下痕迹。粪便检验「取材容易、信息广泛」，也因此更依赖规范的标本留取与及时送检。



粪便检验三大板块：

- **常规检查**：颜色（黑便提示上消化道出血，陶土色提示梗阻性黄疸）、性状（稀水便、黏液便）、镜下细胞（白细胞提示感染性肠炎、红细胞提示出血）与寄生虫卵。

粪便镜检的「细胞定位」是另一门学问：**脓细胞/白细胞**增多提示结肠感染性炎症（细菌性痢疾、溃疡性结肠炎），而**红细胞 + 白细胞**同见多提示出血性病变；**吞噬细胞**（巨噬细胞）见于细菌性痢疾；寄生虫卵（蛔虫、钩虫、蛲虫）各有特征形态，须低倍镜与高倍镜结合寻找。粪便镜检虽「便宜」，却是肠道寄生虫病与炎症性肠病诊断的第一现场——在现代检验高度自动化的今天，粪便镜检仍是少数必须靠人眼完成的项目之一。
- **隐血试验（FOBT）**：检测肉眼不可见的微量出血。**化学法**（愈创木脂）受食物（肉、维生素 C）干扰，**免疫法（iFOBT）**用抗体检测人血红蛋白，特异度更高、无需忌口，是结直肠癌筛查的主力。<span class="marginnote">结肠癌从腺瘤到癌变常伴间歇性出血，免疫法隐血试验连续筛查能把早期癌检出率显著提高。这使它成为「把检验用于人群预防」的经典案例——第五级《公共卫生》的癌症筛查策略与检验技术在这里合流。</span>
- **病原学**：粪便培养找志贺菌、沙门菌、霍乱弧菌等；轮状病毒/诺如病毒抗原检测用于婴幼儿腹泻。

粪便检验还有一个常被忽视的**标本要求**：隐血试验与寄生虫检查各有讲究——隐血试验（化学法）需停食肉类、动物血、维生素 C 数日（免疫法无需忌口）；寄生虫检查需新鲜标本（阿米巴滋养体离体后迅速死亡）且有时需连续多次送检（虫卵排泄间歇性）；粪便培养需「新鲜 + 无菌容器 + 及时送检」，否则杂菌过度生长会淹没致病菌。可以说，粪便检验的「标本环节」决定了一大半结果可信度——一份放置过夜的粪便标本，培养出的细菌已无法反映肠道的真实菌群。

粪便性状的「形态学」也是初筛利器：柏油样黑便提示上消化道出血（血液经消化液变黑）、鲜血便提示下消化道/肛门出血、陶土色便提示胆道梗阻（粪胆原缺乏）、水样便多见于感染或吸收不良。这些肉眼观察先于任何仪器，却常能最快地指向病灶所在节段——「先看、再测、后定」是粪便检验的方法学次序。

## 5 小结

尿液与粪便检验看似「简单标本」，却是检验医学「标本-方法-判读」全链条最完整的练兵场：尿干化学是典型的「筛查」，尿沉渣镜检是典型的「确认」，血尿的形态学分层是典型的「引导决策」，粪便的隐血试验则是典型的「人群筛查」。这三类标本加在一起，覆盖了内科（肾病）、外科（尿路结石）、感染（尿路/肠道感染）、肿瘤（结直肠癌筛查）、代谢（糖尿病酮症）与寄生虫病的广谱问题——「小标本，大信息」，正是检验医学最朴素的魅力。

- **尿干化学**用试纸筛查十余项指标，**尿沉渣镜检**确认形态，双轨制是基本原则。
- 尿蛋白分**生理性/病理性**，微量白蛋白尿是糖尿病肾病的预警窗口；血尿靠红细胞形态定位来源（畸形→肾小球性，正常→下尿路）。
- **管型**是肾小管内的柱状铸件，**红细胞管型**特异提示肾小球肾炎。
- 粪便常规看颜色性状与细胞，**免疫法隐血试验（iFOBT）**是结直肠癌筛查的利器。
- 「NIT 阴性」不能排除尿路感染（不产酶菌、停留时间短）；尿糖阴性不排除高血糖（肾糖阈升高）。
- 粪便培养与抗原检测用于肠道感染的病原学确诊。
- 粪便标本讲究新鲜与多次送检（虫卵间歇排泄、阿米巴离体速死），标本环节决定结果可信度。
- 尿液标本三铁律：**留中段尿、晨尿最佳、及时送检**——「放久的尿」会系统性谎报。
- 蛋白尿判读须注意**试纸对球蛋白/本周蛋白不敏感**，定量要用 24 小时尿或尿蛋白/肌酐比。
- 管型谱从透明、颗粒到蜡样，反映肾病从急性走向慢性终末期的「地层」。
- 尿沉渣镜检需**标准化操作**（定量离心、定量滴片），否则无法定量、可比、复核。

在下一节，我们进入检验医学的「生化大厦」——**临床生化检验（肝功/肾功/血糖血脂）**，从尿液的定性线索走向血液的定量指标。
