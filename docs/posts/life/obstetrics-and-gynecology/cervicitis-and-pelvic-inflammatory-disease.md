## 为什么从子宫颈炎与盆腔炎性疾病开始

上一节讲的是阴道炎症，这一节炎症继续**向上走**：先是宫颈，再进入宫腔、输卵管与盆腔——**盆腔炎性疾病（PID）**是妇科最常见的感染性急症之一，也是「慢性盆腔痛、不孕、异位妊娠」三大后遗症的源头。<span class="marginnote">理解 PID 的关键是记住它的「后果链」：<strong>上行感染 → 输卵管炎/粘连 → 输卵管性不孕与异位妊娠</strong>（第5篇「不孕症」、第2篇「异位妊娠」都会回来找它）。一次「不起眼」的盆腔炎，可能毁掉的是生育力。</span>这一篇把「炎症如何上行、为何会留后遗症、怎样防」讲成一条完整的因果链。

## 1 子宫颈炎：急性与慢性

**子宫颈炎（cervicitis）**分**急性**与**慢性**。急性宫颈炎多由**沙眼衣原体、淋球菌**等病原体感染引起，也见于滴虫、单纯疱疹病毒；表现为**宫颈管黏液脓性分泌物（MPC）**、宫颈口充血水肿、接触性出血，常伴阴道炎与尿道炎。慢性宫颈炎多为急性未彻底治疗迁延而成，或与**宫颈柱状上皮异位（旧称「宫颈糜烂」）**相关——后者是生理性柱状上皮外移，**不是病**。

**诊断与治疗**：黏液脓性分泌物 + 宫颈拭子查病原（衣原体/淋球菌核酸扩增试验，NAAT）；治疗针对病原——**衣原体用阿奇霉素/多西环素，淋病用头孢曲松**，且须伴侣同治、治疗期禁性生活。<span class="marginnote"><strong>「宫颈糜烂」是历史遗留的错误命名</strong>：所谓「糜烂」其实是柱状上皮外移的生理现象，绝大多数无需治疗——被推销「宫颈糜烂手术」的女性要警惕过度治疗；真正的病是「宫颈炎」，以病原学诊断为准。</span>

**HPV 相关**：宫颈炎与宫颈癌（第4篇）是不同的病——**宫颈炎是感染，宫颈癌是 HPV 致癌**；但两者都可表现「接触性出血」，所以「接触性出血」必须做宫颈癌筛查（TCT + HPV）排除恶性，而非默认就是「宫颈炎」。

**淋病与衣原体为何要「一起查」**：二者常混合感染（淋病感染可促进衣原体上行），且都通过性传播、都可能导致 PID 与不孕——所以**有性生活的下腹痛/宫颈炎，应同时筛查淋球菌与衣原体**（NAAT），「查一个不查另一个」会漏掉一半。

## 2 盆腔炎性疾病：定义与病因

**盆腔炎性疾病（pelvic inflammatory disease，PID）**指女性上生殖道（子宫、输卵管、卵巢、盆腔腹膜）的感染性疾病，主要由**上行感染**引起。<span class="marginnote"><strong>PID 是「妇科的沉默破坏者」</strong>：约 1/3 的 PID 症状轻微甚至无症状，却在悄然损伤输卵管；每发作一次，输卵管性不孕与异位妊娠风险就进一步累积。</span>

**病原**：最常见为**沙眼衣原体、淋球菌**（性传播），其次为内源性菌群（厌氧菌、肠道菌群、生殖道支原体等）混合感染。**高危因素**：**年轻（< 25 岁）、多个性伴侣、既往 STI/PID 史、宫内节育器（放置初期）、经期性行为、近期宫腔操作**（人流、诊刮、放环）。**「人流后盆腔炎」**是最常见且最可预防的临床路径之一。

**宫内节育器（IUD）与 PID 的时间窗**：IUD 放置后**前 3 周内** PID 风险轻度升高（与放置时细菌带入有关），此后风险回落至与不使用者相当——所以「放环后早期注意卫生、有不适及时就诊」很重要，但「放环 = 一直易感染」是不准确的。

## 3 盆腔炎性疾病的临床表现与诊断

**症状**：**下腹痛**（持续性、活动或性交后加重）是最常见主诉，伴**发热、异常分泌物（黏液脓性或脓性）、异常子宫出血**、尿频尿急；妇科检查见**宫颈举痛、子宫压痛、附件区压痛**——「三合诊压痛」是重要体征。<span class="marginnote">「下腹痛 + 宫颈举痛/附件压痛 + 发热」——PID 的最低诊断标准是<strong>「子宫压痛 + 附件压痛 + 宫颈举痛」三征中至少一项 + 下腹痛</strong>；无需等培养结果即可开始经验治疗（因延迟治疗损伤更大）。</span>

**「轻症与重症」的分层**：约 1/3 的 PID 症状轻微（仅有轻度下腹不适或无症状），却仍可造成输卵管损伤——这也是「不发热不等于没事」的医学解释。重症 PID 伴高热、寒战、腹膜刺激征，提示腹腔蔓延或脓肿形成，须住院治疗。

**诊断**：临床诊断为主（症状 + 体征），辅助查**宫颈/阴道分泌物病原**、血象与 CRP、**超声**（输卵管积水、盆腔积液、输卵管卵巢脓肿）；必要时**腹腔镜**确诊（可见输卵管充血水肿、脓性渗出、粘连）。**鉴别**：异位妊娠（须先查 hCG！）、阑尾炎、卵巢囊肿扭转、子宫内膜异位症——**育龄女性下腹痛，先验孕再谈 PID**。

**一个容易被漏的细节**：PID 的表现常与「泌尿系感染、胃肠炎、痛经」混淆，尤其**右侧 PID 与阑尾炎几乎无法靠症状区分**——都需要妇科检查与超声，必要时腹腔镜。**「反复『肠胃炎』的下腹痛」要提醒患者做妇科评估**，尤其伴异常分泌物或发热时。

## 4 盆腔炎性疾病的并发症与后遗症

**急性并发症**：**输卵管卵巢脓肿（TOA）**（包块 + 高热，可破溃致腹膜炎，抗生素无效时手术引流）、盆腔腹膜炎、肝周围炎（Fitz-Hugh-Curtis 综合征，右侧腹痛牵涉肩）。

**远期后遗症（PID sequelae）**——PID 最沉重的代价：

**先理解「为什么输卵管最受伤」**：输卵管黏膜的纤毛细胞负责运送受精卵，一旦炎症使其破坏、纤毛功能丧失、管腔粘连堵塞，卵子与精子就无法在正确时间相遇——**输卵管是 PID 的「重灾区」，也是生育力的「命脉」**。这解释了「PID 与不孕/异位妊娠」的直接关联。

| 后遗症 | 风险 | 后果 |
| --- | --- | --- |
| 输卵管性不孕 | 每次 PID 约 10–15% | 输卵管粘连/梗阻 |
| 异位妊娠 | 风险升高 6–10 倍 | 输卵管功能受损 |
| 慢性盆腔痛 | 约 20–30% | 粘连、神经痛 |
| 复发 | 约 1/4 再次发作 | 风险逐次累积 |

<span class="marginnote"><strong>「防 PID 就是防不孕」</strong>：一次重度 PID 后输卵管性不孕率约 10–15%，二次约 30%，三次高达 40% 以上——炎症次数与生育力损失成「阶梯式」关系，这是「PID 必须早诊断、彻底治」的根本理由。</span>

## 5 盆腔炎性疾病的治疗与预防

**治疗原则——「尽早、足疗程、广覆盖」**：

**抗生素**：经验性**广谱**治疗覆盖淋球菌、衣原体与厌氧菌，常用方案为头孢曲松 + 多西环素（± 甲硝唑）；**口服或静脉视病情**（住院标准：高热、TOA、妊娠、免疫抑制、口服无效）。**疗程足够**（多西环素 14 天），即使症状好转也不可提前停药。**伴侣同治**：近 60 天性伴侣须同时治疗，否则再感染。

**「TOA（输卵管卵巢脓肿）」的处置**：TOA 是 PID 的化脓性并发症——高热、附件包块、剧烈腹痛。处理以**广谱抗生素**为主，疗效不佳或脓肿增大者行**超声引导穿刺引流或腹腔镜手术**；脓肿破裂致弥漫性腹膜炎是急症，需急诊手术。「抗生素无效的盆腔包块 + 高热」，要第一时间想到 TOA。<span class="marginnote"><strong>PID 治疗的「三不」</strong>：不因「症状轻」而轻视、不因「症状消」而早停药、不「只治女方」。PID 是「一次治疗不彻底，后遗症终身背」的典型。</span>

**预防**：**安全性行为（安全套）是头号预防**；衣原体/淋病筛查（尤其 < 25 岁、多伴侣者）；**人流/宫腔操作术前筛查并治疗 BV 与宫颈炎**；术后合理抗感染；**避免经期性行为**。

**「慢性盆腔痛」的处理**：PID 后遗的慢性盆腔痛（> 6 个月）常与粘连、瘢痕有关，抗生素多无效——处理以**物理治疗、止痛、心理支持、必要时手术松解粘连**为主；但首先要**排除再次急性发作与子宫内膜异位症**（第4章），「慢性盆腔痛不是一盒抗生素能解决的」。

## 6 公式解析：PID 的诊断决策式

把 PID 的诊断与处理写成一条可执行的决策链：

$$
\text{下腹痛} + \text{宫颈举痛/宫体压痛/附件压痛}（\text{至少一项}）\Rightarrow \text{临床诊断 PID} \xrightarrow{\text{排除异位妊娠/卵巢扭转}} \xrightarrow{\text{立即广谱抗生素 + 伴侣同治}}
$$

分三步拆解：

- **第一步，抓住「压痛三征」**：宫颈举痛、宫体压痛、附件压痛——任一 + 下腹痛即可启动 PID 诊断；**「压痛」是 PID 的敲门砖**，不要等培养结果。
- **第二步，排除更凶险的**：**先查 hCG 排除异位妊娠**（PID 与异位妊娠均可下腹痛），再排除卵巢囊肿扭转、阑尾炎——「排除在先、诊断在后」。
- **第三步，治疗要「趁早 + 够狠」**：越早用广谱抗生素、越彻底，后遗症越少；口服无效或加重者升级住院静脉治疗。**PID 治疗的黄金窗口在「疼起来的第一时间」**。

## 7 核心要点表：本章速查

| 疾病 | 关键要点 |
| --- | --- |
| 急性宫颈炎 | 衣原体/淋球菌为主，NAAT 查病原，伴侣同治 |
| 慢性宫颈炎 | 多与「柱状上皮异位」混淆，生理性无需治 |
| PID 诊断 | 下腹痛 + 压痛三征；先验孕排除异位妊娠 |
| PID 治疗 | 广谱抗生素足疗程 + 伴侣同治 |
| PID 后遗症 | 不孕、异位妊娠、慢性盆腔痛，防重于治 |

**辨析｜易错点：** 「宫颈糜烂就是宫颈炎」是最大误区——「糜烂」多为生理性柱状上皮异位；「PID 不发热就不是 PID」也不对——**约 2/3 的 PID 无发热**，靠压痛三征诊断。「下腹痛 + 白带多」不能简单归为「盆腔炎自己买消炎药」——**明确诊断 + 规范治疗**才有效且不误诊。

## 8 生殖器结核：容易被忽略的「慢性盆腔炎」

**生殖器结核（genital tuberculosis）**是结核杆菌引起的女性生殖道感染，多由肺结核血行播散而来，是**慢性盆腔炎与不孕的重要原因之一**（在结核流行地区占比更高）。

**表现**：**不孕**（最常见就诊原因，输卵管结核粘连）、月经异常（月经量减少、闭经）、慢性下腹痛、盆腔包块；可**无发热等典型结核症状**——「原因不明的不孕 + 月经量少」要想到生殖器结核。<span class="marginnote">生殖器结核的「隐蔽性」：它可多年无症状，体检仅见<strong>附件区条索状包块、输卵管僵硬钙化</strong>（X 线/超声可见钙化影）。确诊靠子宫内膜活检找结核结节/抗酸杆菌、结核菌素试验、分子检测。</span>

**治疗**：**抗结核化疗**（标准 6–8 个月方案，多药联合），一般不需手术；输卵管破坏严重者预后差，常需辅助生殖（第5篇）。**预防**：卡介苗接种、控制活动性结核（抗结核治疗期间不建议妊娠）。

## 9 小结

- **急性宫颈炎**多为衣原体/淋球菌，黏液脓性分泌物 + NAAT 确诊，伴侣同治；「宫颈糜烂」多为生理性异位，勿过度治疗。
- **PID** 是上生殖道感染，由**上行感染**引起，最常见病原为衣原体/淋球菌。
- 诊断靠**下腹痛 + 压痛三征**（宫颈举痛/宫体压痛/附件压痛），**先验孕排除异位妊娠**。
- 后遗症链：**PID → 输卵管损伤 → 不孕/异位妊娠/慢性盆腔痛**，发作次数越多、损失越大。
- 治疗**早、广谱、足疗程、伴侣同治**；预防靠**安全套、STI 筛查、术前规范管理**。
