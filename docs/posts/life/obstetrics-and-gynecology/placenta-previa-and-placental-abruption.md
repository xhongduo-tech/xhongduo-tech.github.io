## 为什么从前置胎盘与胎盘早剥开始

妊娠晚期的**阴道出血**，绝大多数出自胎盘相关疾病——其中**前置胎盘**与**胎盘早剥**是两类性质完全不同的急症，却常被放在一起讨论。<span class="marginnote">两者的核心区别只有一句话：<strong>前置胎盘是「胎盘位置太低、挡住了出口」</strong>（出血来自胎盘与宫颈内口的分离，多为无痛出血）；<strong>胎盘早剥是「胎盘提前从宫壁剥离」</strong>（出血可藏在宫腔内，多有腹痛）。位置问题 vs 剥离问题——病因、表现、处理都不同。</span>理解这两者，是理解「妊娠晚期出血 + 急症处理 + 产科抢救」的枢纽。它也是「从极限到大模型」里「同一症状、不同机制」鉴别诊断的典范。

## 1 前置胎盘：定义与分型

**前置胎盘（placenta previa）**指胎盘附着于子宫下段，**下缘达到或覆盖宫颈内口**，位置低于胎儿先露部。发生率约 0.5%，按胎盘下缘与宫颈内口的关系分四型（或简化为完全性与部分性）：

**完全性前置胎盘**：胎盘完全覆盖宫颈内口；**部分性**：覆盖部分内口；**边缘性**：达内口边缘；**低置胎盘**：下缘距内口 < 2 cm 但未达。<span class="marginnote">分型的临床意义在于<strong>「能否阴道分娩」与「出血风险」</strong>：完全性与部分性通常需剖宫产，低置/边缘性可尝试经阴道分娩（须严格评估）。「前置状态」在早中期可随子宫下段拉长而「上移」（胎盘迁移），所以<strong>早孕期「前置」多在晚期复查后重新评估</strong>。</span>

**高危因素**：既往剖宫产/子宫手术（瘢痕子宫）、多产、多次人流、高龄、多胎、吸烟、辅助生殖。**「剖宫产次数越多，前置胎盘风险越高」**——瘢痕子宫前置胎盘且胎盘长入瘢痕者，即为最凶险的**凶险性前置胎盘（percreta 样）**。

**与「瘢痕子宫」的深度绑定**：近年剖宫产率升高，「前置胎盘 + 胎盘植入（placenta accreta 谱系）」显著增多——胎盘绒毛侵入甚至穿透子宫肌层与浆膜，剥离时大出血极难控制。**孕中晚期的超声/MRI 评估胎盘与瘢痕关系、制定多学科分娩计划**，是处理凶险性前置胎盘的现代范式：「术前备血、介入预置球囊、术中保留胎盘原位 + 必要时子宫切除」。

## 2 前置胎盘：临床表现、诊断与处理

**典型表现**：**妊娠晚期（28 周后）无痛性、反复性阴道出血**——初发多为少量、无痛、无诱因，可自止后复发；出血来自胎盘下缘与宫颈内口分离处的血管断裂。**「无痛」是前置胎盘与胎盘早剥鉴别的最重要线索**。<span class="marginnote">「无痛性出血」是前置胎盘的第一特征——孕妇睡梦中出血、不伴腹痛，很容易被忽视；<strong>任何妊娠晚期的阴道出血都应就医，即使不痛</strong>。</span>

**对母儿的影响**：反复出血致**贫血**与**胎儿窘迫/生长受限**；急性大出血可致**失血性休克**；产时出血来自子宫下段收缩力弱（该处肌层薄），胎盘剥离面止血困难。**预防贫血**（补铁）与**储备血源**是前置胎盘管理的重要部分。

**诊断**：超声定位胎盘下缘与宫颈内口关系，孕 28 周后诊断更可靠。**禁忌**：前置胎盘**禁止肛查与阴道指检**（触碰胎盘可致大出血），只能超声评估——「疑前置胎盘，绝不做阴道检查」是铁律。

**超声报告里的关键词**：产检超声常写「胎盘位于前壁/后壁/宫底」「胎盘下缘距宫颈内口 xx cm」。解读时注意——**「前壁胎盘」不等于「前置胎盘」**（前置指「下缘达到/覆盖内口」，与前后壁无关）；孕早中期「低置/前置状态」可能随孕周上移，<strong>28 周后复查再定论</strong>才是规范做法。

**处理**：无出血或少量出血、胎儿未成熟者**期待治疗**（卧床、监护、必要时住院）；**大出血或胎儿成熟者终止妊娠**，分娩方式以**剖宫产**为主（完全性/部分性）。**止血**：术中胎盘剥离面出血用宫缩剂、缝合、球囊填塞，凶险性前置胎盘（胎盘植入）需多学科团队（产科、麻醉、介入、血库）协作，甚至子宫切除。**Rh 阴性者出血后肌注抗 D**。

**期待治疗的具体内容**：住院或严密门诊随访，**绝对卧床、避免用力与性生活**、监测出血与胎儿状况；给予**糖皮质激素促胎肺成熟**（孕 34 周前早产风险时）、必要时补铁纠正贫血、小量出血用宫缩抑制剂。<span class="marginnote"><strong>促胎肺成熟（倍他米松/地塞米松）</strong>是产科「为了胎儿提前出生做准备」的标准操作：孕 34 周前有早产风险时给予，可显著降低新生儿呼吸窘迫综合征——前置胎盘、早剥、早产（下节）都会用到它。</span>

## 3 胎盘早剥：机制与分度

**胎盘早剥（placental abruption）**指妊娠 20 周后**正常位置的胎盘在胎儿娩出前部分或全部从子宫壁剥离**，是妊娠晚期严重的产科并发症，发生率约 0.5–1%，是导致胎儿死亡与孕产妇出血的常见原因。<span class="marginnote"><strong>胎盘早剥的出血「分显性（阴道流血）与隐性（宫腔积血）」</strong>——隐性出血血液积聚在胎盘后方，阴道流血不多但休克与胎儿窘迫更重；「外出血少 ≠ 病情轻」是早剥最易误判之处。</span>

**机制**：底蜕膜血管破裂出血，血肿使胎盘与宫壁分离；血肿扩大 → 剥离面增大 → 出血更多，形成恶性循环。**分度（Sher）**：Ⅰ度轻、Ⅱ度中（胎盘剥离约 1/3，母体休克+胎儿窘迫）、Ⅲ度重（剥离 > 1/2，胎儿多死亡）。

**早剥对胎儿「断氧」的机制**：胎儿所有氧与营养都来自胎盘——剥离部分的绒毛失去与母血的交换，等于胎儿「失血又失氧」。剥离面越大、胎儿缺氧越重；Ⅲ度早剥时胎儿多已死亡。「早剥的抢救黄金时间以分钟计」——这也是产科「一旦确诊重型早剥立即剖宫产」的原因。

**高危因素**：**子痫前期/高血压**（最重要，血管痉挛致底蜕膜缺血破裂）、外伤（车祸、摔倒）、胎膜早破、羊水过多快速放水、多胎分娩过快、吸烟、可卡因、子宫肌瘤。**「高血压孕产妇是胎盘早剥的高危人群」**——再次呼应第11章「妊娠期高血压疾病」的血管病理。

**外伤与早剥的现实警示**：腹部撞击（车祸、跌倒、受击打）可直接引起早剥——孕晚期应避免剧烈运动与重体力、乘车系好安全带（且安全带应位于腹部下方）。「腹部外伤后即使无明显不适也建议就医评估」——因为早剥的隐性出血可无阴道流血。

## 4 胎盘早剥：临床表现与诊断

**典型表现**：**妊娠晚期突发持续性腹痛**（多为持续性而非阵发性）、**板状硬腹**（子宫张力增高、触痛）、伴或不伴阴道流血、胎儿窘迫或胎心消失。<span class="marginnote">「子宫硬如板 + 持续性腹痛」是胎盘早剥的经典体征——即便阴道无血，也要高度警惕隐性早剥；<strong>「胎动消失/胎心异常」常是早剥的第一报警</strong>。</span>可伴**DIC**（凝血功能紊乱）、肾衰、子宫胎盘卒中（Couvelaire 子宫）。

**诊断**：主要靠**临床**（症状 + 体征）；超声可见胎盘后血肿（阴性不能排除早剥）；血常规、凝血功能、胎儿监护协助评估。**鉴别**：与前置胎盘（无痛出血）、先兆早产（有宫缩）、子宫破裂（多瘢痕子宫）区分——「有无腹痛」是第一步分诊线索。

**处理原则**：**一旦确诊或高度怀疑，立即终止妊娠**——轻型可阴道分娩但须严密监护，重型（胎儿窘迫、大出血、DIC）**立即剖宫产**；同时纠正休克、输注血液制品、处理 DIC。<span class="marginnote"><strong>胎盘早剥的「最紧急」之处</strong>：胎儿依赖胎盘供氧，剥离即断氧——重型早剥的胎儿死亡率极高，抢救以「分钟」计；母体则以控制出血与 DIC 为要。</span>

**术后与远期**：重度早剥后可能出现**子宫胎盘卒中**（子宫肌层被血浸润、收缩乏力）、产后出血、急性肾损伤（休克/肾灌注不足）；存活者远期再孕时早剥复发风险升高，需在下次妊娠高危管理、密切监测血压与胎盘情况。

**「为什么还要学习前置胎盘与早剥」**：它们不仅是考试重点，更是真实世界的「生死课题」——处理得当，母婴平安；处理延误，结局可以很惨烈。把它们与妊娠期高血压（第11章）、分娩期并发症一起串起来，就构成产科「出血、高血压、感染」三大抢救主题的两块拼图——理解得越深，越能在关键时刻「稳、准、快」。

## 5 公式解析：两者鉴别的一张决策表

把前置胎盘与胎盘早剥的鉴别要点量化成表，是本章的「考点核心」：

| 维度 | 前置胎盘 | 胎盘早剥 |
| --- | --- | --- |
| 出血性质 | 无痛性、反复、显性 | 痛性（持续性腹痛）、显性或隐性 |
| 腹部体征 | 腹软、无压痛 | 板状硬腹、子宫压痛 |
| 胎心 | 多正常（出血多时窘迫） | 常窘迫或消失 |
| 子宫张力 | 正常 | 增高 |
| 与高血压关系 | 不直接 | 密切相关（子痫前期） |
| 处理 | 期待/剖宫产 | 确诊即终止妊娠 |

**一步辨别的口诀**：**「痛 + 硬 = 早剥；不痛 + 出血 = 前置」**。当然，临床上两者可并存（前置胎盘可伴早剥），但这条口诀是急诊分诊的第一步。

**「公式解析」的临床版本**：这张鉴别表本质是一张**「症状→诊断」的决策式**——输入「出血性质、腹痛有无、子宫硬度、胎心」四个变量，输出「前置 / 早剥 / 其他」。产科急诊的分诊快慢，就取决于这套「特征匹配」跑得多快；记住表里加粗的判别项，就是掌握了决策式的核心权重。

**给孕妇的自我判断提醒**：妊娠晚期的阴道出血，无论有无腹痛都应就医——但途中可以先观察两点：**「有没有持续性腹痛」「肚子是不是发硬发紧」**。这两个信息能在电话里帮医生初步分诊：无痛 → 可能前置；痛 + 硬 → 可能早剥，需尽快、避免剧烈颠簸前往医院。

**一个容易忽略的细节**：前置胎盘与胎盘早剥都可能**在产前没有任何先兆**地突然发生——所以「定期产检时超声确认胎盘位置」与「知晓两种病的典型信号」是每个孕晚期家庭应有的准备；产检报告的「胎盘位置：前壁/后壁/子宫下段」值得留意，尤其是「胎盘下缘距宫颈内口」的距离数值。

## 6 产科出血的全身反应：DIC 与休克

前置胎盘与胎盘早剥的结局，往往取决于能否控制**产科出血的三个环节：止血、凝血、血容量**。

**DIC（弥散性血管内凝血）**：大量组织因子入血 → 消耗性凝血障碍 → 出血不止、微血栓。胎盘早剥是 DIC 的经典病因之一（剥离面释放促凝物质），表现**皮下瘀斑、穿刺点渗血、血尿**；查凝血功能（PT/APTT、纤维蛋白原、D-二聚体、血小板）并输注新鲜冰冻血浆、冷沉淀、血小板、纤维蛋白原。<span class="marginnote"><strong>DIC 是产科出血的「雪崩」</strong>：一旦触发，止血剂无效、靠「补凝血因子 + 解除病因（娩出胎盘）」双管齐下。早剥导致的 DIC 需要尽早终止妊娠以切断促凝物质来源。</span>

**其他产科出血病因的鉴别**：妊娠晚期出血除前置胎盘与早剥外，还需想到**子宫破裂**（多有瘢痕子宫 + 剧烈腹痛 + 胎心异常）、**阴道/宫颈病变出血**（宫颈息肉、宫颈糜烂样出血）、**边缘性血窦破裂**（少见、无痛、量少自止）。**「先按前置与早剥排查，再考虑少见病因」**——因为前两者最凶险、处理最紧急。

**休克的抢救**：大出血致低血容量休克时，**开放两条静脉通路、快速补液（晶体 + 血液制品）、纠正酸中毒、保暖**；监测生命体征与尿量。**「出血量 ≠ 可见量」**——隐性早剥内出血致休克，须按休克程度补液，而不是看外出血量。

## 7 核心要点表：妊娠晚期出血速查

| 情形 | 要点 |
| --- | --- |
| 任何晚期出血 | 立即就医，禁肛查/禁阴道检查（疑前置时） |
| 无痛性出血 | 先考虑前置胎盘，超声定位胎盘 |
| 痛性出血 + 板状腹 | 先考虑胎盘早剥，立即评估终止妊娠 |
| 疑似早剥 | 查凝血（DIC）、胎心监护，准备急诊剖宫产 |
| 凶险性前置胎盘 | 多学科团队、备血、介入/子宫切除预案 |

**辨析｜易错点：** 「前置胎盘出血都很多」不准确——早期可为少量「自限性」出血；「胎盘早剥阴道出血多才危险」更是误区——**隐性早剥外出血少而内出血重**，反而更易延误。判断靠「症状 + 体征 + 胎儿状态」，不靠「看得见的血」。

## 8 小结

- **前置胎盘**：胎盘覆盖/接近宫颈内口，**无痛性、反复性晚期出血**；禁肛查、多需剖宫产；期待治疗争取胎儿成熟。
- **胎盘早剥**：正常胎盘提前剥离，**持续性腹痛 + 板状硬腹**；隐性出血可掩盖病情，确诊即终止妊娠。
- 两者鉴别的口诀：**「痛 + 硬 = 早剥；不痛 + 出血 = 前置」**。
- 共同点：都需**快速识别 + 及时终止/抢救**，都是孕产妇出血与胎儿死亡的重要元凶。
- 高危人群：前置胎盘与剖宫产史/多产/高龄相关；胎盘早剥与**子痫前期、外伤**密切相关——管理好血压就是预防早剥。
