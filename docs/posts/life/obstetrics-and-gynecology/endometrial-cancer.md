## 为什么从子宫内膜癌开始

**子宫内膜癌（endometrial cancer）**是发达国家最常见的妇科恶性肿瘤，在我国发病率也逐年上升、部分大城市已超过宫颈癌。<span class="marginnote">它与宫颈癌形成鲜明对照：宫颈癌病因在外（HPV 感染），<strong>子宫内膜癌病因在内（长期无对抗雌激素）</strong>——一个靠疫苗防，一个靠体重与激素管理防。</span>约 90% 的患者以**绝经后出血**为首发症状，这让它成为「最容易早期发现的妇科肿瘤」——只要出血就查、查了就取内膜，多数能拿到很好的预后。这一篇的重点是：分清两种生物学类型的命运差异，理解「雌激素假说」，并掌握从出血到确诊到分期治疗的标准路径。

## 1 两种类型：雌激素依赖与非依赖

子宫内膜癌按发病机制与病理分两型，预后截然不同：

**Ⅰ型（子宫内膜样腺癌，约 85%）**：**雌激素依赖型**。长期无对抗雌激素刺激子宫内膜增生，经**子宫内膜增生（尤其不典型增生）**进展而来。病理多为子宫内膜样腺癌，分化好，病程缓慢，预后好，多发生于围绝经期与较年轻的肥胖女性。<span class="marginnote">子宫内膜增生分为无不典型与不典型两档；<strong>不典型增生</strong>是真正的癌前病变，约 30% 在多年内可进展为癌，需积极干预。</span>

**Ⅱ型（浆液性癌、透明细胞癌、癌肉瘤，约 15%）**：**非雌激素依赖型**。与 p53 突变相关，侵袭性强，易早期腹腔转移，预后差，多发生于年老、瘦削、无明确高危因素的女性。

**辨析｜易错点：** 「子宫内膜癌」不等于「子宫内膜样癌」——后两者是包含关系。浆液性癌即使局限也常需辅助化疗，因为它像卵巢癌一样有腹腔种植倾向；把 Ⅱ型按 Ⅰ型「保守处理」是临床大忌。

## 2 高危因素与雌激素假说

**雌激素假说**是理解 Ⅰ 型子宫内膜癌的钥匙：子宫内膜是雌激素的靶组织，**凡使雌激素相对过剩或孕激素缺乏的处境，都升高内膜癌风险**。

| 高危因素 | 机制 |
| --- | --- |
| 肥胖 | 脂肪组织芳香化酶把雄烯二酮转化为雌酮，雌激素持续增高 |
| 无排卵（PCOS、围绝经期） | 长期无孕激素对抗，内膜持续受雌激素刺激 |
| 绝经晚（> 52 岁） | 暴露于自身雌激素的年限延长 |
| 未产、不孕 | 妊娠/哺乳带来的孕激素「休整期」缺失 |
| 他莫昔芬（乳腺癌用药） | 对内膜有弱雌激素样作用 |
| 单用雌激素 HRT | 有子宫者未加孕激素的 MHT |
| 糖尿病、高血压 | 与肥胖常共存，代谢性风险 |

**保护因素**恰恰相反：多产、哺乳、复方口服避孕药（其孕激素成分对抗内膜增殖）、运动、维持正常体重。<span class="marginnote">口服避孕药使用 ≥ 5 年可使子宫内膜癌风险降低约 50%，且保护效应在停药后持续多年——这又是一个「避孕药抗癌」的教科书级例子。</span>

**遗传因素**：**林奇综合征（Lynch syndrome）**，因 DNA 错配修复基因（MLH1、MSH2 等）突变所致，子宫内膜癌风险高达 20–60%，且发病早（< 50 岁）；对年轻发病或家族史强阳性者应行错配修复蛋白检测。

## 3 临床表现与诊断

**症状**：**绝经后出血**是最典型表现（约 90%）；围绝经期女性表现为月经量增多、经期延长或经间出血；晚期可有下腹痛、排液、消瘦。
**体检**：子宫可增大、活动良好；晚期宫旁增厚或固定。
- **辅助检查**：
  - **经阴道超声**：测子宫内膜厚度。绝经后内膜 ≤ 4–5 mm 且无血流异常，恶性风险很低；增厚者进一步取样。
  - **子宫内膜活检**：门诊 Pipelle 负压抽吸是**确诊金标准**，诊断子宫内膜癌准确率高；失败或取样不满意时行诊断性刮宫（D&C）。
  - **MRI**：评估肌层浸润深度、宫颈受累与淋巴结，对分期与治疗决策有价值。

**诊断流程一句话：绝经后出血 → 阴道超声 → 内膜取样 → 病理确诊**。<span class="marginnote">「绝经后出血」是必须严肃对待的信号：虽然约 90% 由良性原因（萎缩、炎症、息肉）引起，但<strong>任何一次</strong>绝经后出血都应按恶性肿瘤排查流程走完，直至组织学排除。</span>

## 4 公式解析：绝经后出血的分层决策

把「出血要不要活检」变成一条量化的决策：

$$
\text{绝经后出血} \xrightarrow{\text{经阴道超声}} \begin{cases}
\text{内膜厚度} \le 4\text{–}5\ \text{mm} &\Rightarrow \text{恶性风险} \sim 1\% \Rightarrow \text{可保守观察/随访}\\
\text{内膜厚度} > 5\ \text{mm} &\Rightarrow \text{需内膜取样确认}\\
\text{内膜厚度} > 8\ \text{mm 或血流丰富} &\Rightarrow \text{恶性概率明显升高} \Rightarrow \text{尽快取样}
\end{cases}
$$
分三步拆解：

- **第一步，看内膜厚度**：经阴道超声测内膜——绝经后 **≤ 4–5 mm** 且无血流异常者恶性风险约 1%，多可观察；**> 5 mm** 需取样确认。
- **第二步，抓高危线索**：内膜 **> 8 mm、回声不均、血流丰富、或伴出血**——恶性概率明显升高，尽快内膜活检。
- **第三步，活检是关键一步**：**Pipelle 或诊断性刮宫**送病理——「超声只是看厚度，病理才定性质」；绝经后出血患者，病理阴性也要随访（部分病变局限、取材可能遗漏）。

## 5 子宫内膜癌的治疗

**手术是首选**：**全子宫 + 双附件切除**（Ⅰ型标准手术）——**为什么不保留卵巢**？因为卵巢是雌激素来源、且约 5% 合并卵巢转移；**淋巴结评估**（前哨淋巴结活检/清扫）用于分期。**高危者加**：大网膜切除、腹腔冲洗液细胞学。

**辅助治疗按分期与风险**：**Ⅰ期低危**（子宫内膜样、肌层浸润浅、高分化）多无需辅助治疗；**高危/进展期**——**放疗**（阴道近距离放疗防阴道复发）、**化疗**（紫杉醇 + 卡铂）、**激素治疗**（孕激素，用于不能手术者或复发 ER+ 者）。<span class="marginnote"><strong>「子宫内膜癌多数早期治愈」</strong>：因约 90% 以绝经后出血就诊、易早期发现——Ⅰ期 5 年生存率 > 90%——「出血就查，常常救命」。</span>

## 6 随访与预防

**随访**：术后定期复查（症状 + 妇科检查 + 影像），关注**阴道出血、盆腔痛、体重下降**等复发信号；**腹水、肺、骨转移**为远处复发部位。<span class="marginnote"><strong>「预防子宫内膜癌 = 管好雌激素与体重」</strong>：维持正常体重（脂肪是雌激素来源）、无排卵者孕激素转化内膜、围绝经期 MHT 有子宫者加孕激素、糖尿病高血压管理——「预防远好过治疗」。</span>

**遗传与筛查**：**林奇综合征**者（错配修复基因突变）子宫内膜癌风险 20–60%，建议**从 30–35 岁起每年内膜活检筛查**；有家族史者评估遗传咨询（第1篇「遗传咨询」）。

## 7 核心要点表：子宫内膜癌速查

| 项目 | 要点 |
| --- | --- |
| 两型 | Ⅰ型雌激素依赖（预后好）、Ⅱ型非依赖（预后差） |
| 高危 | 肥胖、无排卵、绝经晚、他莫昔芬、林奇 |
| 症状 | 绝经后出血（约 90%） |
| 诊断 | 经阴道超声 + 内膜活检 |
| 治疗 | 全子宫双附件 ± 淋巴结，高危加放化疗 |
| 预后 | Ⅰ期 > 90%，早发现是关键 |

**辨析｜易错点：** 「绝经后出血都是癌」不准确——约 90% 为良性（萎缩、息肉、炎症），但**必须先按恶性排查**；「子宫内膜癌 = 要放疗」不是——**多数早期手术即可、无需放疗**；「体检 CA-125 高就是内膜癌复发」不准确——应结合症状与影像。

## 8 小结

- **子宫内膜癌**是发达国家最常见妇科恶性肿瘤，分**雌激素依赖型（Ⅰ型，预后好）与非依赖型（Ⅱ型，预后差）**。
- 高危因素：**肥胖、无排卵（PCOS/围绝经期）、绝经晚、他莫昔芬、林奇综合征**；保护因素：多产、COC。
- **绝经后出血**是最典型信号（约 90%）——**先按恶性排查**（经阴道超声 + 内膜活检）。
- 治疗：**全子宫 + 双附件 + 淋巴结评估**，高危者放疗/化疗；孕激素用于不能手术者。
- **预防核心是管好雌激素与体重**——「出血就查、防在源头」。

在下一节，我们将从「子宫内膜」转向「卵巢」，看妇科死亡率最高的肿瘤如何被识别与治疗，这就是**卵巢癌**（对照第4篇）。

## 补充：子宫内膜增生的分层管理

**子宫内膜增生**是 Ⅰ 型内膜癌的「前奏」，按病理分**无不典型增生**与**不典型增生**——管理强度截然不同：

**无不典型增生**：多为长期无排卵所致，**孕激素治疗**（周期撤退或 LNG-IUS）多可逆转，随访复查；**不典型增生**：属**癌前病变**，约 30% 可进展为癌——**有生育要求者**用大剂量孕激素/LNG-IUS 逆转后尽快妊娠，**无生育要求者**（尤其年龄大）建议**全子宫切除**。「不典型增生 ≠ 癌，但必须认真对待」——它是最该被抓住的「可干预窗口」。

## 补充：子宫内膜癌的「保留生育力」例外

子宫内膜癌多数是绝经后疾病，但**年轻、早期（ⅠA、高分化、无肌层浸润）且有强烈生育要求**者，有「保留生育力」的选项：**大剂量孕激素治疗**（或 LNG-IUS）使病灶消退后，**尽快妊娠**（需辅助生殖），产后再评估全切。

**前提与风险**：须严格选择（ⅠA、G1、无高危因素）、密切随访（每 3 个月内膜活检）、充分知情——「保留生育力是给少数年轻早期患者的选择，不是常规」——「想生与防癌的权衡，需要医患共同决策」。
