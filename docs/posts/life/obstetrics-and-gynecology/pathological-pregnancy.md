## 为什么从病理妊娠开始

上一篇讲了正常妊娠的「理想剧情」，这一篇讲「剧本失控」的时刻。**病理妊娠**是产科的核心战场，它的三条主线恰好对应妊娠的三个阶段：**孕早期出血（流产、异位妊娠）、孕中晚期血压失控（妊娠期高血压疾病）、以及胎盘相关事件（前置胎盘、胎盘早剥、早产）**。本专题的《流产、异位妊娠与妊娠剧吐》《妊娠期高血压疾病》《前置胎盘与胎盘早剥》《早产、胎膜早破与多胎妊娠》四篇已分别细讲，这一篇把它们摆到同一张「危险地图」上：**同一个症状（阴道流血）在不同孕周指向完全不同的病，同一套血压指标在不同人群里有完全不同的风险**。<span class="marginnote"><strong>病理妊娠的共同方法论：按孕周分类 + 按凶险分级</strong>。早孕期出血先问「宫内还是宫外」（异位妊娠是致命急症）；中晚期出血先问「胎盘位置与剥离」（前置胎盘与胎盘早剥）；血压升高先问「有无靶器官损害」（子痫前期是系统性疾病）——「先分最凶险的，再谈最常规的」，是妇产科不变的安全排序。</span>

## 1 流产：早期妊娠的「自然淘汰」

**流产（abortion）**指妊娠不足 28 周（我国标准；WHO 为不足 20 周）或胎儿体重不足 1000 g 而终止者，其中**孕早期（12 周前）流产约占 80%**，多数与胚胎染色体异常有关——所以早期流产常被视为「自然淘汰」，是生育中难以避免的代价，而非母亲的过错。

按临床过程，流产分几型，处理完全不同：

- **先兆流产**：少量流血 + 腹痛轻，宫口未开，妊娠物未排出——可保胎观察（卧床、孕激素视情况）。
- **难免流产**：流血增多、腹痛加剧，宫口已开——妊娠无法继续，需清宫。
- **不全流产**：部分妊娠物排出，流血不止——需清宫 + 防感染。
- **完全流产**：妊娠物完全排出，流血渐止——可观察随访。
- **稽留流产（过期流产）**：胚胎已停止发育但未排出——需评估凝血功能后清宫。

**复发性流产（RSA）**：连续 **2–3 次**及以上自然流产（我国标准多为连续 2 次即应评估）。病因筛查包括**染色体异常、解剖异常（子宫畸形、宫腔粘连）、内分泌异常（黄体功能不足、甲状腺、PCOS）、免疫因素（抗磷脂综合征）与感染**。<span class="marginnote"><strong>复发性流产要「按图索骥」</strong>：一次流产多可观察等待，两次以上才启动系统排查——因为多数单次流产是「概率事件」，而过早、过度的检查反而增加焦虑。这是「先排除最高概率，再做地毯式筛查」的医学经济学。</span>

## 2 异位妊娠：着床在错误的地方

**异位妊娠（ectopic pregnancy）**指受精卵在子宫腔以外着床，**约 95% 发生在输卵管**（壶腹部最常见）。它是孕早期最重要的急症之一——输卵管壁薄、血供丰富，胚胎长大后可致**输卵管破裂、腹腔内大出血**，危及生命。

**典型三联征**：**停经 + 腹痛 + 阴道流血**。但现实常不典型——有的只表现为「月经推迟几天的少量出血伴下腹隐痛」，极易误诊为「先兆流产」或「月经不调」。诊断的金字塔是：**尿/血 hCG 阳性 + 阴道超声未见宫内孕囊** → 怀疑宫外孕；**血 hCG 倍增规律异常**（正常早孕期约 48–72 小时翻倍，宫外孕常上升缓慢或下降）。

**处理**：稳定者可用**甲氨蝶呤（MTX）**药物保守（要求肿块小、hCG 低、无破裂）；破裂或药物失败者行**腹腔镜/开腹手术**（保留输卵管或切除患侧）。**育龄女性出现腹痛 + 出血，验孕永远是第一步**——这条铁律在「异常子宫出血」篇也反复强调。

**一个容易被忽略的提醒**：异位妊娠破裂前的「预兆期」常只有短短几天——血 hCG 上升缓慢、附件区小包块、少量暗褐色出血，都是「先兆」信号。所以**宫外孕的关键不是「等痛到爆炸」，而是「早孕时 B 超确认为宫内」**；孕 5–6 周超声能看见宫内孕囊，就基本能排除大部分宫外孕风险。

## 3 妊娠期高血压疾病：从血压升高到子痫

妊娠期高血压疾病是妊娠与高血压并存的一组疾病，按严重程度递进为：**妊娠期高血压（妊娠 20 周后新发血压 ≥ 140/90 mmHg，无蛋白尿）→ 子痫前期（高血压 + 蛋白尿/靶器官损害）→ 子痫（子痫前期基础上发生抽搐）→ 慢性高血压并发子痫前期**。

**子痫前期（preeclampsia）**的诊断核心是「**血压升高 + 累及多系统**」：血压 ≥ 140/90 mmHg，加上**蛋白尿（≥ 0.3 g/24h）**或**无蛋白尿但伴靶器官损害**（血小板减少、肝功能异常、肾功能异常、肺水肿、神经系统症状）。**重度子痫前期**为血压 ≥ 160/110 mmHg 或出现严重器官受累——需要紧急处理。

**子痫（eclampsia）**：在子痫前期基础上发生**全身抽搐**，是孕产妇死亡的重要原因，典型表现为**产前、产时或产后抽搐 + 血压骤升**。处理的核心是**硫酸镁**——它是预防与控制子痫抽搐的一线药物，兼具降压辅助与神经保护作用。

**为什么会发生子痫前期？** 目前认为核心机制是**胎盘着床异常**：滋养细胞对螺旋动脉的重塑不足 → 胎盘灌注下降、缺血 → 释放抗血管生成因子 → 全身血管内皮损伤 → 高血压、蛋白尿、多器官损害。理解「胎盘起源、全身受累」这条链，就理解了为什么「**终止妊娠是唯一根治手段**」——胎盘一离开母体，疾病随之缓解。<span class="marginnote"><strong>为什么医生总在 37 周前「纠结」</strong>：子痫前期的处理本质是「<strong>在母亲安全与胎儿早产之间找平衡</strong>」——血压控制不住、器官受损时须提前终止妊娠（严重者 34 周前也可能终止），否则拖下去母亲风险更高；而 37 周后足月，则积极终止妊娠即可。这个「择期 vs 急诊」的权衡是产科决策的典型范例。</span>

## 4 妊娠剧吐：不只是「孕吐重一点」

**妊娠剧吐（hyperemesis gravidarum）**约见于 0.3–3% 的孕妇，严重程度远超「普通晨吐」：**持续呕吐 → 脱水、酮症、电解质紊乱 → 体重下降 ≥ 5%**。病因尚不完全清楚，与 hCG 峰值相关（所以多胎妊娠、葡萄胎时更常见）。

**处理要点**：补液纠正脱水与电解质紊乱、维生素 B₆ 与多西拉敏（一线止吐药）、严重者短期住院。**关键警示**：长期呕吐未控制可致**Wernicke 脑病**（维生素 B₁ 缺乏）——这虽罕见但严重，不可忽视。大多数妊娠剧吐孕 12–16 周后自行缓解，但少数可持续全程。

**辨析｜易错点：** 「孕吐重 = 怀得稳」没有依据——妊娠剧吐是疾病，不是「胎气好」；它与流产风险无关，但严重脱水、电解质紊乱本身就需要治疗。<span class="marginnote"><strong>妊娠剧吐的鉴别诊断</strong>：排除其他引起呕吐的疾病（消化道、甲状腺、肝病等），不能简单当「早孕反应」处理——尤其是有腹痛、发热、肝功能异常时，需警惕其他外科急腹症。</span>

**妊娠合并症的「叠加效应」**：病理妊娠之间常常互相叠加——子痫前期可致胎盘早剥、FGR；胎盘早剥可致早产；多胎妊娠升高子痫前期与早产风险。理解这些「叠加效应」，是产科医生面对复杂病例时的核心思维：**不能只处理一个病，要看到整张风险网络**。

## 5 早产、胎膜早破与多胎妊娠：产科的三重挑战

**早产（preterm labor）**指孕 28–37 周分娩，是新生儿发病与死亡的首要原因。早产的病因是多因素的：**感染/炎症（最常见）、宫颈机能不全、多胎妊娠、子宫过度膨胀（羊水过多）、胎盘异常、母体疾病**等。早产最重要的预测指标是**宫颈长度**（超声测量）——孕中期宫颈 < 25 mm 提示早产风险增高。

**胎膜早破（PROM）**：临产前胎膜破裂。足月者（≥ 37 周）多可自然临产或引产；未足月者（PPROM）需评估感染风险（绒毛膜羊膜炎）与胎肺成熟度，决定保胎还是促产。**PPROM 的核心矛盾是「延长孕周 vs 控制感染」**——时间拖得越长，感染风险越高。

**早产处理的三件套**：**宫缩抑制（宫缩抑制剂争取时间）、促胎肺成熟（地塞米松/倍他米松，孕 34 周前早产可显著降低新生儿呼吸窘迫综合征）、转诊至有条件的新生儿监护机构**。「保胎不是为了熬日子，而是为了给胎儿争取成熟的时间」，这是早产处理的核心逻辑。

**多胎妊娠（双胎及以上）**：双胎发生率约 1–2%（自然受孕与辅助生殖）。多胎妊娠是「高危妊娠」——**早产、子痫前期、GDM、贫血、FGR** 的发生率均显著升高。双胎按绒毛膜性分**双绒毛膜双羊膜囊（DCDA）与单绒毛膜（MCDA 或 MCMA）**，后者共用一个胎盘，有**双胎输血综合征（TTTS）**风险，需严密超声监护。

**中医/中西医结合视角**：本专题不涉及中医方剂，但需指出，早产保胎中的孕激素（如黄体酮）使用是循证医学确认的，与「中医安胎」的某些理念有交集——但临床决策必须以循证证据为准。

## 6 前置胎盘与胎盘早剥：出血的「有痛 vs 无痛」鉴别

前置胎盘（placenta previa）与胎盘早剥（placental abruption）都以孕晚期出血为共同表现，但**一个不痛、一个痛**，处理方向截然相反：

- **前置胎盘**：**无痛性**阴道流血，反复发作——胎盘位于子宫下段或覆盖宫颈口。**处理：禁肛查（防大出血）、择期剖宫产（孕 34–37 周视情况）。**
- **胎盘早剥**：**腹痛性**阴道流血（可内出血而不外流），起病急——胎盘提前从子宫壁剥离，可致弥漫性血管内凝血（DIC）。**处理：紧急评估、按母胎情况尽快终止妊娠。**<span class="marginnote"><strong>「无痛性出血」与「腹痛性出血」是鉴别诊断的第一对照点</strong>：产房急诊遇到孕晚期出血，第一个问题就是「肚子疼不疼」——痛与不痛，指向完全不同的病因与处理路径。</span>

## 7 公式解析：血压的「平均动脉压」与子痫前期风险分层

产科常把三次血压读数量化成一个更稳健的指标——**平均动脉压（MAP）**：

$$
\text{MAP} = \frac{\text{SBP} + 2 \times \text{DBP}}{3}
$$

分三步拆解：

- **第一步，理解权重**：舒张压占三分之二权重，因为心脏舒张期占心动周期的大部分，平均动脉压更接近舒张压——这与「高压和低压哪个更重要」的临床直觉一致。
- **第二步，代入计算**：如血压 160/110 mmHg，则 MAP = (160 + 220)/3 ≈ 126.7 mmHg——明显高于正常范围（正常 MAP 约 70–100 mmHg）。
- **第三步，用于分层**：MAP 持续偏高、波动大，是子痫前期风险评估与降压疗效监测的常用指标；配合尿蛋白、血小板、肝功能，构成「重度子痫前期」的量化判定——**不要只盯收缩压，多系统指标一起看**。

**降压治疗的「安全窗」**：重度子痫前期降压目标为收缩压降至 160 mmHg 以下（或 150 mmHg 左右），但**不能降得过低**——胎盘灌注需要足够的压力，过度降压会伤及胎儿。「既要压住血压，又要保住灌注」，是子痫前期治疗的核心张力。

## 6 核心要点表：病理妊娠速查

| 疾病 | 关键点 |
| --- | --- |
| 流产 | < 28 周终止；早期多因染色体异常；分先兆/难免/不全/完全/稽留 |
| 复发性流产 | 连续 2 次以上启动系统筛查（染色体/解剖/内分泌/免疫） |
| 异位妊娠 | 95% 在输卵管；停经+腹痛+流血；hCG + 超声确诊 |
| 子痫前期 | 妊娠 20 周后 BP ≥ 140/90 + 蛋白尿/靶器官损害 |
| 重度子痫 | BP ≥ 160/110 或器官受累；处理核心是硫酸镁 |
| 子痫机制 | 胎盘着床异常 → 血管内皮损伤 → 多系统损害 |
| 根治手段 | 终止妊娠（胎盘离开母体） |

## 7 小结

- **病理妊娠 = 正常妊娠的「失控分支」**：早孕期以流产、异位妊娠为主，中晚期以高血压疾病与胎盘事件为主。
- **同症异病靠孕周与症状细节区分**：孕早期出血先排异位妊娠（致命优先）；孕晚期出血先辨「痛 vs 不痛」（早剥 vs 前置）。
- **子痫前期是全身性疾病**：始于胎盘，终于全身血管内皮损伤；**硫酸镁**防子痫，**终止妊娠**是根治。
- **MAP 公式** $\text{MAP}=(\text{SBP}+2\,\text{DBP})/3$ 是量化血压负荷的常用工具。
- **病理妊娠常互相叠加**（子痫前期→早剥→早产→多胎→子痫前期），处理要看整张风险网络，而不是孤立的一个病。

在下一节，我们继续沿着「妊娠 + 疾病」的组合前进——这次是妊娠遇上母体原有的慢性病：**妊娠合并症（妊娠糖尿病、心脏病、血液病）**。
