## 为什么从听力学检测开始

上一节我们把听觉通路从外耳一路解剖到听皮层，现在要回答一个临床问题：**怎么知道这条通路断在哪一环？** 听力学检测就是听觉系统的「影像学」——只不过它不用射线，而是用精心设计的声刺激与测量探头，把通路的每一段「拷问」一遍。**纯音测听测「听力损失多少」，声导抗测「中耳通不通」，耳声发射测「外毛细胞活不活」，ABR 测「脑干传不传」。** 四件工具合起来，才能回答听力障碍分类那一篇的核心问题：病变在传导、感音还是中枢？

这套检测思路还有一层方法论的价值：**把复杂系统拆成可分别测量的环节，再组合判断**。这是医学诊断的通用范式，也是后续言语语言病理学各篇（失语症、构音障碍、吞咽障碍）评估的底层逻辑——先分环节，再定位，再下结论。

## 1 纯音测听：把听力损失画成一张图

**纯音测听（pure-tone audiometry）**是听力学最基础的检查。它让受试者戴上耳机，在 125、250、500、1000、2000、4000、8000 Hz 各频率分别测试**气导（air conduction, AC）**听阈；再把骨导耳机放在乳突或前额测**骨导（bone conduction, BC）**听阈。把各频率的 dB HL 连成线，就是**听力图（audiogram）**。<span class="marginnote">为什么要分气导与骨导？气导声要走「外耳→中耳→内耳」全程，骨导声直接振动颅骨让耳蜗「看到」声音——<strong>气骨导差是传导性聋的标记</strong>。骨导正常而气导下降，说明病变在传导段（外中耳）；两者同降，说明病变在耳蜗或之后。</span>

听力图是听力学的「母语」，读图有固定顺序：

**看形状**：平坦型、下降型（高频差）、上升型（低频差）、盆型（4000 Hz 凹陷）、陡降型。噪声性聋的 4000 Hz 凹陷、老年性聋的高频下降、梅尼埃病的低频波动，各有特征形状。
**看程度**：按 500、1000、2000 Hz 三个频率气导阈的平均值（PTA）分级——≤25 dB HL 正常，26–40 轻度，41–60 中度，61–80 重度，≥81 dB HL 极重度。
**看气骨导差**：气骨导差 > 10 dB 提示传导成分，是助听器 vs 手术决策的依据。

程度分级在临床上通常按如下对照表落地，配合 WHO 2019 年修订版使用：

| 分级 | PTA（dB HL） | 交流感受 |
| --- | --- | --- |
| 正常 | ≤ 25 | 无困难 |
| 轻度 | 26–40 | 安静下小声听不清 |
| 中度 | 41–60 | 正常对话明显困难 |
| 重度 | 61–80 | 大声喊才能听见 |
| 极重度 | ≥ 81 | 助听器效果有限，多需人工耳蜗 |

测听的「环境」同样重要：测试必须在**隔声室（sound booth）**内进行，本底噪声要低于标准（ISO 8253-1）；听力计需定期按 ISO 389 校准，0 dB HL 对应的物理声压随耳机型号而异。**一台没校准的听力计，测出的听力图再漂亮也不可信。**

**掩蔽（masking）**是纯音测听里最容易出错的环节：当测试耳听力差、非测试耳听力好时，气导声可能绕过颅骨被健耳听到（交叉听力）。此时要在非测试耳加噪声掩蔽，确保测的确实是「目标耳」。<span class="marginnote">掩蔽噪声的强度要足够压住交叉听力，又不能太强把噪声也传导过去——「平台法」在噪声强度与听阈不变的区间取真阈。听力师手上的掩蔽决策，很像信号处理里「信噪比」的权衡：掩蔽不足测出假好，掩蔽过度测出假差。</span>

## 2 言语测听：测「听得见」之外的「听得清」

纯音测听听的是「能不能听见」，而言语测听测的是「听不听得懂」——这是两件事。**言语识别阈（speech reception threshold, SRT）**：让受试者重复双音节词（如普通话「水杯」「电话」），测得能正确复述 50% 的强度；**言语识别率（word recognition score, WRS）**：在阈上舒适强度（通常 SRT + 40 dB）测试最大正确复述百分比。

SRT 与 PTA 的一致性是一个重要的诊断锚点：<span class="marginnote">正常时 SRT（dB）与 PTA（dB HL）应在 ±10 dB 内吻合。若言语识别率明显低于纯音听阈应有的水平——比如听力图只是中度损失，言语识别率却只有 30%——提示<strong>蜗后病变</strong>（听神经瘤、脑干病变）或中枢处理障碍。这个「纯音与言语不匹配」是听力学最经典的判别线索。</span>

言语识别率还有一层分诊价值：助听器验配前测 WRS，可以预判佩戴效果。**听阈差但识别率高的耳，助听器往往立竿见影；识别率已经崩掉的耳，单纯放大声音反而更糊**——这直接决定验配策略与是否该考虑人工耳蜗。后面《助听器验配》一篇会回头看这个数。

言语测听还能识破「伪聋」：故意装听不见的人，其 SRT 往往远差于其 WRS（识别率却很好），且行为反应极不稳定。**当客观测听（OAE、ABR、声反射）正常而主观测听一塌糊涂时，要考虑功能性听力损失或诈病**——听力师的「破案」常靠这种主观-客观对照。

## 3 声导抗：中耳与声反射的「压力表」

**声导抗测听（immittance audiometry）**用探头密封外耳道，鼓膜处给一个探测音（通常 226 Hz 或 1000 Hz 宽带），同时改变外耳道气压，测量鼓膜-中耳系统对声能的传导特性，画成**鼓室图（tympanogram）**。

| 鼓室图类型 | 峰值压力 | 声导纳 | 提示 |
| --- | --- | --- | --- |
| A 型 | 0 daPa 附近 | 正常 | 中耳正常 |
| B 型 | 无峰 | 低平 | 中耳积液、鼓膜穿孔、耵聍栓塞 |
| C 型 | 负压（< -100 daPa） | 正常 | 咽鼓管功能障碍、负压 |

**声反射（acoustic reflex）**：用较强声刺激（听阈上约 70–100 dB），通过镫骨肌收缩使鼓膜导纳短暂变化。声反射阈升高或缺失，是**耳蜗性听力损失**（重振）与**蜗后病变**（声反射衰减）的重要指标。声反射还有一条精巧用途——它可以间接估计听力损失程度：**听阈约等于「声反射阈 − 70 dB」**，适用于无法配合纯音测听的婴幼儿与智力障碍者。<span class="marginnote">声导抗测「鼓膜」，鼓室图看中耳，声反射看中枢——一件仪器覆盖了两段通路。给婴幼儿或无法配合者测听时，声反射是纯音测听的重要替代与补充。</span>

## 4 耳声发射：外毛细胞的「回音」

**耳声发射（otoacoustic emissions, OAE）**是外毛细胞主动运动的副产品：耳蜗在放大声音的同时，会反向向耳道辐射极微弱的声能。用耳道内微型麦克风可以录到这个「回音」。两种常用类型：**瞬态诱发 OAE（TEOAE）**用短声（click）刺激，**畸变产物 OAE（DPOAE）**用两个纯音刺激产生畸变频率成分。

OAE 的定位价值非常清晰：**OAE 正常 → 外毛细胞功能完好；OAE 消失 → 外毛细胞损伤或更下游（听神经/脑干）有问题。** 但 OAE 不能区分「毛细胞正常但听神经断」与「正常」——这是它与 ABR 互补的地方。

TEOAE 与 DPOAE 的分工值得记住：TEOAE 一次刺激覆盖宽频带，适合筛查「整体是否正常」；DPOAE 用两个纯音扫频，能逐频点测外毛细胞的功能，适合定位「哪个频率损伤」。重度聋时 OAE 通常消失，所以 OAE 也常用来确认「耳蜗死区」——人工耳蜗术前评估会看它。<span class="marginnote">OAE 是<strong>新生儿听力筛查</strong>的主力工具：新生儿睡觉时放个探头，几分钟出结果，无需配合。国家新生儿听力筛查「初筛-复筛-诊断」流程的第一步就是用 OAE。OAE 通过不代表全好——听神经病变（auditory neuropathy）OAE 可正常但行为听阈差，必须靠 ABR 兜底。</span>

## 5 ABR：把脑干「接线」画成波形

**听性脑干反应（auditory brainstem response, ABR）**记录短声（click）刺激后 10 ms 内的脑干电活动，用表面电极从头皮引出，得到一组波峰。临床上最常看三个波：

**波 I**：耳蜗与听神经起始段的放电；**波 III**：上橄榄复合体；**波 V**：下丘/外侧丘系。关键指标是**波间潜伏期（inter-peak latency, IPL）**——I–III 波间隔反映听神经到脑干低段，III–V 反映脑干高段。<span class="marginnote">ABR 的「精确性」来自<strong>平均叠加（averaging）</strong>：每个短声诱发的反应只有零点几微伏，被脑电背景淹没；重复数百次后，与刺激同步的信号同相叠加增强，随机噪声被平均掉。这就是信号处理里的「相干平均」——第三级《数字信号处理》里会系统讲它。</span>

ABR 的测试条件也值得提一句：受试者需安静放松，婴幼儿常在自然睡眠或镇静下测试；刺激用短声或短纯音，常用速率约每秒 11–37 次，叠加 1000–2000 次；电极按国际 10–20 系统放置于颅顶与乳突。测出的波形逐波判读，报告里给出各波潜伏期、波间期与反应阈。

ABR 的临床应用有三条主线：

- **新生儿与婴幼儿听阈估计**：V 波反应阈与行为听阈接近，配合骨导与分侧测试可判断单双侧；
- **蜗后病变筛查**：I–V 波间潜伏期延长、波幅比异常，提示听神经瘤等桥小脑角占位，需影像学确诊；
- **术中监测**：听神经瘤切除术中持续记录 ABR，保护残余听力。

**诊断鉴别**：OAE 正常 + ABR 异常 → 听神经病（auditory neuropathy spectrum disorder）；OAE 异常 + ABR 异常 → 耳蜗性病变；OAE 正常 + ABR 正常但行为听阈差 → 中枢或功能性听力问题。三种组合把病变定到「毛细胞、听神经、中枢」三个层面。

## 6 公式解析：PTA 平均听阈

**平均纯音听阈（pure-tone average, PTA）**是整个听力分级体系的数字根基，也是所有流行病学统计的基准：

$$
\text{PTA} = \frac{\text{HL}_{500} + \text{HL}_{1000} + \text{HL}_{2000}}{3} \;(\text{dB HL})
$$

三步拆解这条式子：

- **第一步，选三个频率**：500、1000、2000 Hz 覆盖了言语最核心的能量区，被世界卫生组织（WHO）与多数国家采用。我国听力残疾评定标准也以这三分频为准。
- **第二步，取平均**：三个气导阈的算术平均。它把一张二维听力图压缩成一个「程度数字」，便于分级、随访与人群比较。
- **第三步，注意局限**：PTA 只反映 500–2000 Hz。**高频陡降型损失 PTA 可能正常，但言语识别已严重受损**——所以 PTA 必须与听力图形状、言语测听联合解读。这也是为什么分级标准同时要求「PTA 达到 XX dB 且听理解明显受限」的双重条件。

这条公式是最简单的「降维」：把二维信息压成一维数字，必然有损，但换来了可操作性与可比性。临床决策永远在「数字」与「图形」之间来回参照。

**把五件工具合起来看，才是完整的诊断**：听力图回答「损失多少」，鼓室图回答「中耳通不通」，声反射回答「中枢接不接」，OAE 回答「毛细胞活不活」，ABR 回答「脑干传不传」——任何单一检查都可能被误导，唯有交叉印证才能定位病变。这正是听力学检测作为「听觉系统的影像学」的完整含义。

## 7 小结

- **纯音测听**（气导+骨导+掩蔽）画出听力图，是「损失多少」的基准；气骨导差定位传导段。
- **言语测听**（SRT 与 WRS）测「听得清」，纯音与言语不匹配提示蜗后或中枢病变。
- **声导抗**：鼓室图分 A/B/C 型看中耳，声反射看中枢，还能间接估听阈。
- **OAE** 测外毛细胞「活不活」，是新生儿筛查主力；**ABR** 测脑干「传不传」，可估听阈、筛蜗后。
- 四件工具组合鉴别：**OAE 正常 + ABR 异常 = 听神经病**；OAE 异常 = 耳蜗病变；全正常但听阈差 = 中枢或功能性。
- PTA 公式 $\frac{HL_{500}+HL_{1000}+HL_{2000}}{3}$（dB HL）是分级基准，须与听力图形状和言语测听联合解读。
- 交叉印证是诊断的灵魂：**单看一项会误判，五件工具合起来才能定位**。

在下一节，我们将把检测结果翻译成诊断与策略——**听力障碍分类与干预策略**：从传导性/感音神经性/混合性/中枢性的鉴别，到「医疗手术 → 助听器 → 人工耳蜗 → 听觉康复」的干预阶梯。
