## 为什么从听觉系统开始

这个专题叫「听力学与言语语言病理学」，而它的一切工作都从同一个器官开始：**耳朵**。听力师测量的是耳的功能，验配师补偿的是耳的损失，人工耳蜗绕开的是耳的病变，而语言治疗师面对的患者里，很大一部分的病因也藏在「听不见」这三个字里。不理解听觉系统，听力学就是一堆没有坐标的表格。**先看清声波如何变成神经冲动，才能理解为什么纯音测听要用 125 Hz 到 8000 Hz，为什么听力图能区分传导性聋与感音神经性聋。** 这一节是整个专题的解剖学与生理学底座。

还有一层更深的关系值得点破：这套从声波到频谱的转化，与大模型语音识别的第一层**梅尔频谱（Mel-spectrogram）**是同一件事。人耳用基底膜做频率分解，机器用短时傅里叶变换做频率分解——前者是 3000 万年的进化，后者是 50 年的工程，但数学同源。学听觉系统，等于学「大自然如何做语音识别」。

本节的路线图很直白：先立物理坐标（声学基础），再沿声波的行进路径从外耳走到皮层（解剖），最后把「损伤在哪一层」这件事对号入座（病理分类）。这三步正好对应后面听力学检测、听力损失分类与人工耳蜗三篇的结构——解剖是它们的共同语言。

## 1 声学基础：听觉系统在测量什么

在碰任何结构之前，先立住三根坐标轴——它们是听力学所有仪器与表格的物理依据。<span class="marginnote">频率、声压、相位这三根轴，正是数字信号处理里「频谱」的三要素。到第三级《数字信号处理》与大模型的梅尔频谱你会再次见到它们——人耳在做的频率分解，工程师后来用傅里叶变换重新发明了一遍。</span>

**频率（frequency）**：声波每秒振动的次数，单位赫兹（Hz）。人耳可听范围约 **20 Hz 到 20000 Hz**，而言语的主要能量集中在 250 Hz 到 4000 Hz——这就是为什么听力测试的常规频率范围取 125 到 8000 Hz。**声压（sound pressure）**：声波引起的空气压强变化，单位帕（Pa）。平静呼吸的言语约 0.02 Pa，而喷气式飞机起飞在耳边可达 200 Pa——跨越了四个数量级，所以用**分贝（dB）**的对数标度。**相位（phase）**：声波在周期中的位置，双耳定位与助听器方向性都依赖它。

这三个量到「听觉感知」的映射，是听力学反复用到的对照：

| 物理量 | 感知量 | 听力学用途 |
| --- | --- | --- |
| 频率（Hz） | 音高（pitch） | 听力图的横轴 |
| 声压 / 声强（dB） | 响度（loudness） | 听力图的纵轴 |
| 谐波成分 | 音色（timbre） | 言语识别材料设计 |
| 相位差 / 时间差 | 声源定位 | 双耳验配、助听器方向性 |

<span class="marginnote">这张表的第四行是「鸡尾酒会效应」的物理基础：双耳听到同一声源时存在微秒级的时间差与强度差，听觉中枢据此定位。助听器正是用双麦克风重造这个差异来实现方向性聚焦。</span>

分贝家族还有一个必须区分的地方：**dB SPL 是物理声压级，dB HL 是听力级**。听力图上 0 dB HL 代表「正常青年人的平均听阈」，它随频率变化——1000 Hz 处 0 dB HL 约对应 7 dB SPL，而 125 Hz 处 0 dB HL 约对应 45 dB SPL。临床报告里不写清是哪种 dB，数值就毫无意义。

听觉的感知量还有一个非线性的陷阱：**响度并不严格正比于声压级**。人耳在低频对声压更不敏感，同一声压级下 1000 Hz 听起来比 100 Hz 响得多——这就是**等响曲线（equal-loudness contours）**存在的理由。听力学家做掩蔽与耳鸣评估时，必须用「听阈之上的 dB SL（感觉级）」而不是绝对 dB，才能跨频率比较响度。

## 2 外耳与中耳：把空气声变成内耳液体的「传送带」

**外耳（external ear）**由**耳廓（auricle）**与**外耳道（external auditory canal）**组成。耳廓的褶皱有助声学聚焦，也帮助前后方向的声源判断；外耳道是一根长约 2.5 cm 的管道，其**共振频率约 2500–3000 Hz**——这正是言语中辅音能量集中的频段。<span class="marginnote">耳道共振是「外耳增益」的来源：2500 Hz 附近的声压在鼓膜处比外耳道口放大约 10–15 dB。这个频段恰恰是听辅音所必需的，所以高频听力损失会让「听得到、听不清」——后面助听器验配要重点补偿的就是这里。</span>

鼓膜本身是诊断的窗口：医生用电耳镜看到的**鼓膜标志（tympanic membrane landmarks）**——锤骨柄、脐部（umbo）、光锥（cone of light）——指示中耳的健康状态。鼓膜松弛部（pars flaccida）与紧张部（pars tensa）的区分也有临床意义：松弛部穿孔常提示慢性中耳炎胆脂瘤，这在耳鼻喉科的《中耳疾病》一篇会细讲。

**中耳（middle ear）**的使命是把空气的声振动传给内耳的液体。空气与内耳液体的声阻抗相差约 3500 倍——如果不做处理，声能绝大部分会被反射回去。中耳用三件机制解决这个**阻抗匹配（impedance matching）**问题：

**面积比**：鼓膜有效面积约 55 mm²，远大于卵圆窗的约 3.2 mm²，压强按面积比放大——这是最主要的增益来源；
**杠杆比**：锤骨与砧骨的听骨链杠杆作用再放大约 1.3 倍；
**鼓膜弯曲**：锥形鼓膜的「猫耳」效应提供额外的微小放大。

三者合计，**中耳把声压放大约 27–30 dB**——这个数字在助听器增益设计里反复被引用。听骨链由三块小骨构成：**锤骨（malleus）、砧骨（incus）、镫骨（stapes）**，镫骨底板嵌在卵圆窗上。鼓膜后方还有一个重要的管道——**咽鼓管（eustachian tube）**，它连接中耳与鼻咽，负责平衡中耳气压。感冒时咽鼓管肿胀，中耳形成负压，就会「耳朵发闷」——这是分泌性中耳炎的发病起点。

中耳还有两扇「安全阀」：**鼓室张肌与镫骨肌**，在巨大声响时反射性收缩，把听骨链锁紧以保护内耳（**声反射（acoustic reflex）**，约 70–100 ms 潜伏期）。声反射测听正是利用这条通路：声导抗仪测量镫骨肌反射来判断中耳与脑干功能。

## 3 内耳与耳蜗：把频率摊开成一条「频谱尺」

中耳把声波送进内耳，真正的分析从这里开始。**耳蜗（cochlea）**是一个约 35 mm、绕成蜗牛壳状的管道，沿纵轴有一根**基底膜（basilar membrane）**，把管腔分为前庭阶与鼓阶；中间的**蜗管**内是内淋巴，前庭阶与鼓阶内是外淋巴。<span class="marginnote">贝凯西（Békésy）因行波理论获 1961 年诺贝尔生理学或医学奖：声波在基底膜上激起行波，不同频率在膜上振幅最大处的位置不同——高频在基底（靠卵圆窗，窄硬）处最大，低频在蜗顶（宽软）处最大。这叫<strong>部位编码（place coding）</strong>。</span>

基底膜从基底到蜗顶，宽度渐增、刚度渐降，所以它像一串长度递增的琴弦。**频率拓扑（tonotopy）**由此建立：一条膜就是一根对数刻度排好的频谱尺。沿基底膜分布着**柯蒂氏器（organ of Corti）**，其上有两类毛细胞：

**内毛细胞（inner hair cells，约 3500 个）**：真正把机械振动转成神经冲动的感觉细胞，与听神经纤维一一对应，负责编码精细的时间与频率信息；**外毛细胞（outer hair cells，约 12000 个）**：负责主动放大，像微型马达一样「推」基底膜，让人耳能听见一个氢原子直径量级的位移。

毛细胞的换能机制简洁而工程化：基底膜振动使毛束（stereocilia）倾斜，牵拉**尖顶连接（tip link）**打开机械门控离子通道，内淋巴中高浓度的钾离子涌入细胞，去极化后释放递质，触发听神经冲动。内淋巴（高钾低钠）+80 mV 的内淋巴电位就是这台换能器的「电池」。

耳蜗的损伤方式留下了一张「签名照」：**噪声性听力损失通常在 4000 Hz 处出现一个凹陷（notch）**。原因是 4000 Hz 附近是外耳道共振与基底膜机械应力最集中的区域，长时间强声暴露先从这里的毛细胞开始损伤。这张 4000 Hz 凹陷的听力图，是职业健康与军事听力学反复见到的经典图形——下一节纯音测听会把它画出来。<span class="marginnote">外毛细胞的主动运动会反向在耳道里产生微小声音——<strong>耳声发射（OAE）</strong>。这既是新生儿听力筛查的原理，也意味着「外毛细胞是活的」：听神经病变时 OAE 仍在，蜗后病变时 OAE 正常但 ABR 异常——后面听力学检测一节会反复用这个「内外对照」。</span>

## 4 听觉中枢通路：从耳蜗到听皮层

听神经（第Ⅷ对脑神经的耳蜗支）携带电信号进入脑干，逐级上行，每级都做一次不同的加工：

**耳蜗核（cochlear nucleus）**：第一次分叉，分出背侧与腹侧两路——一路负责精确定位与调谐，一路负责时间信息；**上橄榄复合体（superior olive）**：双侧听神经的第一次会合，比较两耳的时间差与强度差，是声源定位的「计算中心」；**外侧丘系与下丘（inferior colliculus）**：整合反射与声源定位，参与声音的惊吓与注意；**内侧膝状体（medial geniculate body）**：丘脑的中继站，滤波与门控；**听觉皮层（auditory cortex）**：最终的分析——言语、音乐、环境声的辨识。

**频率拓扑从耳蜗一直保留到皮层**：听皮层上有一张「频谱图」，相邻的神经元对应相邻的频率。这正是「听觉系统是频谱分析仪」的神经学证据。<span class="marginnote">听皮层还按「What」与「Where」两条通路组织：颞上回前部处理「这是什么声音」（What），后部与顶叶处理「声音来自哪里」（Where）。这个双通路设计与视觉的腹侧/背侧通路同构——认知科学的「双通路」母题又出现了一次。</span>

**时间编码（temporal coding）**是部位编码的补充：对于低频音（约 1000 Hz 以下），听神经的放电与声波周期同步，称为**相位锁定（phase locking）**，用放电的时间间隔编码频率。两种编码并用的结果是：**低频靠时间，高频靠位置**——这条「分工」是理解耳蜗植入策略与助听器频响的基础。

声反射的完整弧线也在这里收束：声音刺激一侧耳，信号上行至双侧上橄榄复合体，再下行到双侧面神经核，引起两侧镫骨肌收缩。**单侧声刺激会同时引起双侧声反射**——所以用声导抗仪可以从「健侧」耳间接测量「患侧」耳的中耳与脑干通路，这在单侧重度聋的定位诊断中很有用。

### 辨析｜易错点：传导性聋、感音神经性聋与中枢性聋

把解剖与病变对上号，是本节最该拿下的考点：<span class="marginnote">这三类的鉴别正是纯音测听的核心输出：传导性聋气骨导差 > 10 dB，感音神经性聋气骨导同损，中枢性聋常规听力图可能完全正常——所以「听力图正常」不等于「听不见」，还要靠言语测听与中枢测听。</span>

**传导性聋**：病变在外耳或中耳——外耳道闭锁、鼓膜穿孔、听骨链中断、中耳积液。特点：**气导下降、骨导正常**，气骨导差明显，且听阈损失一般不超过 60 dB（因为中耳只放大约 30 dB）。**感音神经性聋**：病变在耳蜗或听神经——毛细胞损伤、听神经病变。特点：**气导与骨导同等下降**，无气骨导差。**中枢性聋**：病变在脑干或皮层，常规听力图往往正常，靠言语测听、ABR 与影像学诊断。

## 5 公式解析：dB SPL 与听阈标度

听力学的一切数值都在分贝标度上，必须把它的定义拆到骨子里。**声压级（sound pressure level, SPL）**：

$$
L = 20\log_{10}\frac{P}{P_0}, \qquad P_0 = 20\,\mu\text{Pa}
$$

四步拆解这条式子：

- **第一步，看分母 $P_0$**：$P_0 = 20\,\mu\text{Pa}$ 是人的听阈参考声压——正常人耳能听见的最小声压，约等于一个蚊子在三米外飞过的声音。它把「绝对声压」换成「相对某基准的分贝」。
- **第二步，看对数**：取 $\log_{10}$ 是因为声压跨越 10⁶ 倍的范围，对数把乘法变成加法：每 +20 dB 就是声压 ×10。
- **第三步，验端点**：$P = P_0$ 时 $L = 0\,\text{dB SPL}$——听阈定义为 0 dB SPL；$P = 200\,\text{Pa}$ 时 $L = 20\log_{10}(200/20\times10^{-6}) = 20\log_{10}10^7 = 140\,\text{dB SPL}$——痛阈附近。
- **第四步，注意 dB 家族**：听力图上用的是 **dB HL（听力级）**——以正常青年人的平均听阈为 0 dB HL，而不是 dB SPL。0 dB HL 在 1000 Hz 约对应 7 dB SPL，各频率各不相同。**dB HL 让「0」代表「正常听力」，这正是听力图能一眼看出听力损失程度的原因。**

这条公式连接了物理与临床：听力图纵轴正是 dB HL，横轴是频率，图上每一点都同时携带「物理声压」与「感知损失」两层信息。

从 dB SPL 到 dB HL 的换算还会引出第三个量：**dB SL（感觉级）**，定义为「刺激声压级减去该耳该频率的听阈」。言语测听里「阈上 30 dB SL」的陈述，意思就是「比这耳刚好能听见还响 30 dB」——它把每个个体的听力损失「归一化」掉了，让不同患者的测试结果可以互相比较。三个 dB 的换算，是听力师最基础的算术。<span class="marginnote">助听器验配软件里常出现「真耳分析」：在耳道内用探针麦克风实测到达鼓膜的 dB SPL，再与验配目标比对。目标曲线本身也是由 dB HL 换算回 dB SPL 得到的——这套换算从本节开始贯穿整个专题。</span>

## 6 小结

- 听觉系统测量三根轴：**频率（Hz）、声压（dB）、相位**；言语能量主要落在 250–4000 Hz。
- 外耳提供约 2500–3000 Hz 的耳道共振增益；**中耳用面积比+杠杆比实现约 27–30 dB 的阻抗匹配放大**。
- 耳蜗是**频谱分析仪**：基底膜行波产生频率拓扑（部位编码），内毛细胞编码、外毛细胞放大，外毛细胞的运动产生耳声发射。
- 中枢通路从耳蜗核到听皮层逐级加工，**频率拓扑全程保留**；低频另靠相位锁定（时间编码）补充。
- 三类病变对号入座：**传导性聋气骨导分离，感音神经性聋气骨导同损，中枢性聋常规听力图正常**。
- dB SPL 以 $20\,\mu\text{Pa}$ 为参考、用对数压缩跨度，dB HL 以正常青年平均听阈为 0，dB SL 以个人听阈为 0——**三个 dB 是听力师最基础的算术**。
- 声音的行进路径就是病变的定位地图：**外耳→中耳→耳蜗→听神经→脑干→皮层，每一站都有对应的检测工具与特征图形**。

在下一节，我们将回答一个临床问题——**怎么知道这条通路断在哪一环**：从纯音测听、言语测听、声导抗到耳声发射与 ABR，听力学检测把听觉系统的每一段「拷问」一遍。
