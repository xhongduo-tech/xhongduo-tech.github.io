## 为什么从分类系统开始

上一节我们拿到了厚厚一沓调查数据：每块地的质地、坡度、土层厚度、有机质含量……数据本身不能直接用于决策，必须**归类**。
这就是分类（classification）的价值：把连续变化的世界切分成有限的类型，让「这块地」可以同「那块地」比较，让同一个名字在全国乃至全球范围内含义一致。

分类问题我们在博客里已经遇过多次：生物学里林奈的界门纲目科属种、机器学习里的聚类与监督分类、图书馆里的分类号。<span class="marginnote">土地/土壤分类的特殊之处在于：它的分类对象是<strong>连续而不可见的</strong>——土壤在地表下连续渐变，你挖开才知道；而生物学分类对象是离散的物种。所以土壤分类「分出来的不是自然实体，而是人定的规则实体」，理解这一点是读懂一切分类系统的钥匙。</span>这一节讲土壤与土地的两套分类谱系：一套按**自然属性**（土壤分类），一套按**利用适宜性**（土地分类）。

## 1 土壤分类的两大传统：发生学与诊断学

土壤分类有两条路线，分歧近一个世纪：

**发生学分类（genetic classification）**：以成土过程与成土因素（气候、母质、生物、地形、时间）为主线，把土壤按「怎么形成的」来归组。苏联土壤学派（道库恰耶夫）是代表，中国的旧《中国土壤分类》也是发生学传统。优点是概念直观、便于理解地带规律；缺点是**同一类土壤在不同地区可能有不同属性**，因为成土因素组合复杂，难以统一判据。

**诊断学分类（diagnostic classification）**：以**可测量的诊断层与诊断特性**为判据，不管成因，只问「剖面里有没有这个层、满足不满足这个阈值」。美国土壤系统分类（Soil Taxonomy，1975）与联合国世界土壤资源参比基础（WRB，1998/2014）都属于这一传统。优点是可操作、可复制、判据统一，国际可比。

**辨析｜易错点：** 初学者常问「到底哪个分类更正确」。分类没有对错，只有**目的适配**：发生学分类擅长表达「地带规律」与宏观格局，适合全国/大区的成土规律研究；诊断学分类擅长「给任何一块具体的土精确命名」，适合制图与信息交换。当今国际主流已全面转向诊断学——因为**现代土地信息系统需要可验证、可全球通约的判据**，而这一点发生学给不了。

## 2 美国土壤系统分类的层级

Soil Taxonomy 用六级分类单元，自上而下逐级细分，命名采用「增缀法」：每往下一级，在名字上加缀词。

| 层级 | 名称 | 判据要点 |
| --- | --- | --- |
| 土纲（order） | 如 Mollisols, Aridisols, Ultisols | 诊断层类型 |
| 亚纲（suborder） | 如 Udolls, Ustolls | 水分/温度状况 |
| 土类（great group） | 如 Hapludolls | 诊断层组合 |
| 亚类（subgroup） | 如 Typic Hapludolls | 是否典型、附加特性 |
| 土族（family） | 颗粒大小级别、矿物学等 | 质地/矿物组合 |
| 土系（series） | 如 Miami series | 具体剖面性状 |

把「Mollisols → Udolls → Hapludolls → Typic Hapludolls」读一遍，就能体会到这套系统设计之精妙：**每一级都是对上级的限定，名字越长，信息越细**，而信息全部压缩在词缀里。这与编程里「命名空间逐级限定」、与生物分类的「学名 = 属 + 种加词」是同一种信息压缩策略。<span class="marginnote">诊断层的引入是 20 世纪土壤学的革命：道库恰耶夫时代靠「眼观成因」，Soil Taxonomy 靠「剖面内有/无某层、达/不达某阈值」——把定性判断换成布尔判据，土壤命名第一次做到了「任何人可复检」。这同第一级《基础数学》「用精确条件代替模糊描述」的精神一脉相承。</span>

## 3 世界土壤资源参比基础（WRB）

WRB 是国际土壤科学联合会推动的全球统一命名系统，兼容各国系统，分两级：**参考土类（Reference Soil Group，32 个）**与**诊断性状后缀（qualifier）**。
命名形如「Haplic Luvisols」「Calcic Kastanozems」——主词是参考土类，前缀词按「最细、次细」顺序列出限定性状。

WRB 与 Soil Taxonomy 是「两种都能精确命名」的并列系统，区别在于：Soil Taxonomy 层级更完整、信息量更大；
WRB 更简洁、更便于国际交流。

中国土壤分类走了一条「发生学 → 诊断学」的转型路：1978 年的《中国土壤分类》是典型的发生学系统，按成土条件与过程把土壤分为土纲、土类等单元；1999 年起正式建立**中国土壤系统分类**，采用「诊断层 + 诊断特性」判据，设土纲—亚纲—土类—亚类—土族—土系六级。<span class="marginnote">转型不是「把旧名字换成新名字」那么简单——同一块地，发生学叫「褐土」、系统分类可能叫「简育湿润淋溶土」，背后的判据体系完全不同。中国第三次全国土壤普查（2022 起）采用中国土壤系统分类，就是要让全国土壤数据可以放进统一、可验证的数据库里。</span>

## 4 土地分类：从自然谱系到利用谱系

土壤分类回答「这块地是什么」，**土地分类**回答「这块地能干什么」。Dent & Young 强调，这是两条不同的谱系，不能互相替代：

**土地的自然分类（如景观分类）**：按地貌、母质、水文等自然属性划分土地单元，服务于资源调查与生态研究。
- **土地的利用分类**：按对某种用途的**适宜程度**或**限制程度**分级，服务于农业区划与规划。最经典的是美国土地能力分类（Land Capability Classification，LCC）。

LCC 按**限制因素的严重程度**把土地从高到低分为八个能力级：

| 级 | 含义 | 典型限制 |
| --- | --- | --- |
| I | 限制很少，适耕性好 | 无明显限制 |
| II | 轻微限制，需一般水土保持措施 | 微坡、质地稍差 |
| III | 中等限制，需专门措施 | 中度坡度、排水不良 |
| IV | 严重限制，仅限部分作物与措施 | 强限制、需精细管理 |
| V | 不适宜耕作，仅限放牧/林地 | 涝洼、石砾、湿冷 |
| VI | 适宜放牧或林，限制中等 | 陡坡、浅薄土 |
| VII | 适宜放牧或林，限制严重 | 陡峭、侵蚀风险高 |
| VIII | 几乎无利用价值，宜作保护 | 裸岩、沼泽、流沙 |

I~IV 级通常可耕，V~VIII 级一般不宜耕作。这个「八级能力」框架是中国土地分等定级制度的直接思想源头。<span class="marginnote">注意 LCC 是「能力」而非「适宜性」：它按限制因素分级，不考虑具体作物；具体到「这块地种水稻行不行」要到《土地评价原理与方法》和《土地利用适宜性评价》两篇才解决。能力是静态底线，适宜性是动态匹配。</span>

### 从 LCC 到中国土地分等定级

美国 LCC 思想传入后，中国发展出自己的**农用地分等定级估价**体系，可以理解为「LCC + 定量化」的本土化：把土地按自然质量分为**等**（全国可比，靠标准耕作制度下的理论产量），按利用状况与收益分为**级**（县域可比，靠实际产出与区位），再在级的基础上评估价（见《土地经济与土地市场》一篇）。
这套「等—级—价」三层结构，正是把分类、评价、市场三条线拧在一起的制度设计。

## 5 分类与地图：从类型码到信息系统

分类的最终产物要落到地图与数据库里。每个制图单元的编码（如「Aquic Hapludalfs—细壤质—温湿」）把土壤类型、质地、水分状况压缩成一段可检索的字符串。
现代土地信息系统（LIS）正是建立在「分类码 + 属性表 + 空间位置」三者之上的。

**辨析｜易错点：** 类型码不能替代属性数据。两个分类完全相同的地块，坡度、水源、区位可能截然不同——分类只回答「种类」，属性与位置才是评价的输入。把「分类相同」误读为「条件相同」，是土地评价最常见的初级错误。Dent 为此专设一章：**分类是评价的起点，不是终点**。

### 检索表：把分类变成算法

分类成果在信息系统里要回答「这个码到底代表什么」——所以每个诊断学分类系统都配一本**检索表（key）**：像决策树一样，从诊断层开始逐层提问（有没有钙积层？有没有粘化层？水分状况是湿润还是干旱？……），每答一问收窄一次范围，最后锁定到具体类型。<span class="marginnote">检索表把分类从「专家记忆」变成「任何人可执行的判定流程」——这正是第一级《基础数学》「用规则代替记忆」、第三级《数据结构》「决策树检索」的土壤学版本。野外土壤学家的日常工作，很大程度上就是拿着检索表逐层判定；而这份检索表本质上就是一棵写死在纸上的决策树。</span>

由此得到一个重要推论：**诊断学分类的可靠性，不取决于分类者「懂不懂土壤」，而取决于诊断判定的正确性**——层认错了，检索表再准也没用。
所以分类的误差管理又回到《土地调查与制图》一篇的命题：野外识别诊断层需要训练、需要剖面记录、需要样本验证。
分类、调查、制图三者的咬合关系，在这里看得最清楚。

## 6 小结

- 土壤分类两大传统：**发生学**（按成因）与**诊断学**（按可测诊断层），当代主流是诊断学。
- 美国土壤系统分类六级：**土纲→亚纲→土类→亚类→土族→土系**，名字逐级加词缀、信息逐级增加。
- **WRB** 提供 32 个参考土类 + 限定词的全球通约命名系统，中国采用同源的**中国土壤系统分类**。
- 土地分类与土壤分类是**两条谱系**：LCC 按限制因素把土地分八级，I~IV 可耕、V~VIII 不宜耕。
- **分类是评价的起点**：类型码必须配合属性数据与空间位置一起使用，不可单独作决策依据。

在下一节，我们将回答：知道每块地「是什么类型」之后，如何**科学地判断它适宜做什么、不适宜做什么**？这就进入本专题的核心方法论——**土地评价原理与方法**。
