## 为什么从胃肠内镜开始

上一节我们认识了消化道的正常生理，而诊断学的第一课就是回答：**如何在不切开身体的情况下，亲眼看到这条九米管道？** 答案就是内镜（endoscopy）。内镜让「胃肠病学」这门学科从「盲人摸象」变成了「眼见为实」——胃镜、结肠镜、ERCP 与胶囊内镜，共同构成了消化内科最核心的技术栈。同时，内镜已从纯诊断工具演变为「内镜下治疗」的平台：镜下止血、息肉切除、支架置入、早癌切除。理解它的原理与局限，是后续每一篇临床主题（溃疡、出血、肿瘤）的必要前提。

## 1 光学与机械：内镜是怎么把图像送出来的

**内镜（endoscope）**：一种可弯曲的管状器械，经口或经肛门进入消化道，将内部影像实时传回体外。它的核心是三大系统：

- **光学成像系统**：前端光源照亮管腔，物镜成像。现代内镜用 CCD/CMOS 光电传感器把光信号转成数字信号——**这与数码相机是同一套物理**，只是镜头缩到了 1 cm 见方、又加装了弯曲控制。
- **操作与弯曲系统**：旋钮牵动钢丝，控制前端上下左右弯曲，让镜头能在弯曲的肠腔里「导航」。<span class="marginnote">机械上这是典型的「线驱动连续体机器人」：远端的自由度由体外绳索（钢丝）驱动，柔顺而安全。到机器人课程里，这几乎就是内镜、软镜手术机器人的原型。</span>
**工作通道**：一条旁路管道，可伸入活检钳、电凝钳、注射针、圈套器等工具——这正是「诊断变治疗」的通道。

**内镜对比影像学的意义**在于：影像学（CT、钡剂）看的是「影子」，内镜看的是「黏膜本体」，并且可以**当场取活检**。这是它不可替代的根本原因。

## 2 六大内镜平台：谁负责看哪一段

| 内镜 | 观察范围 | 标志性诊断动作 |
| --- | --- | --- |
| 胃镜（上消化道内镜） | 食管、胃、十二指肠 | 检查 Barrett 食管、溃疡，活检 |
| 结肠镜 | 全结肠 + 回肠末段 | 息肉切除、IBD 病变评估 |
| 小肠镜 / 胶囊内镜 | 小肠（普通内镜盲区） | 不明原因消化道出血的探查 |
| ERCP | 十二指肠乳头、胆胰管 | 结石取出、胆胰管支架 |
| EUS（超声内镜） | 管壁分层 + 邻近脏器 | 胰腺肿块、肿瘤分期 |
| 胶囊内镜 | 全小肠 | 摄像头胶囊随蠕动拍摄 |

其中 **ERCP 是「最高风险与最高收益并存」的技术**：它逆行向胆管、胰管注入造影剂，既能取结石又能放支架，但可诱发胰腺炎。而 **EUS 把超声探头装到镜头上**，能看穿管壁五层结构和紧邻的胰腺、淋巴结，是消化道肿瘤分期的金标准之一。

**按需选镜的一条主线**：

- **看黏膜** → 胃镜 / 结肠镜 / 胶囊镜；
- **看黏膜下与邻近脏器** → EUS；
- **看胆胰管并要治疗** → ERCP；
- **要整片切除早癌** → ESD 平台。

平台的组合不是「全都要」，而是「按需接力」——这与《胆道与胆囊疾病》里「US → MRCP → ERCP」的阶梯选择是同一套决策逻辑。

**核心概念**：**活检（biopsy）**：内镜通道伸出钳子夹取黏膜组织，送病理检查。活检让「内镜下看见的」升级为「病理学证实的」——这是内镜与病理两大诊断体系的分工接口。<span class="marginnote">黏膜下肿瘤、早期癌等常常「内镜看着可疑，病理才下结论」；反过来，萎缩性胃炎的内镜分型（Kimura–Takemoto）要与病理的 OLGA 分期配合使用——我们会分别在《胃炎与胃癌前病变》《消化道肿瘤》两篇用到这套分工。</span>

## 3 适应症、禁忌症与风险：什么时候不该做

内镜是侵入性检查，必须权衡收益与风险。常见**适应症**：不明原因上腹痛 / 贫血、消化道出血的定位与止血、溃疡病随访、息肉与早癌筛查、Barrett 食管监测。

常见**禁忌症与慎用情形**：

**血流动力学不稳定**（活动性大出血休克期，先复苏后内镜）；
- 严重心肺疾病无法耐受镇静；
- 疑有消化道穿孔；
- 肠道准备不充分（结肠镜）。

**风险**：穿孔（发生率约千分之一到万分之一级别）、出血（多发生于活检或息肉切除后）、镇静相关心肺事件。<span class="marginnote">穿孔与出血的概率虽小，却是「侵入性」二字的全部含义——这正是上一节《消化系统生理》里那道守恒账的病理版：内镜捅破了管壁，消化液与细菌就进入不该进入的腔隙，引发急腹症（见《肠梗阻与急腹症》）。</span>

## 4 公式解析：病变大小的判定与早癌风险

内镜下最常用的定量语言是「尺寸」与「巴黎分型」。病变大小 $d$（cm）直接决定治疗路径：

$$d \begin{cases} < 0.5\,\mathrm{cm} & \text{多可内镜下完整切除（息肉）} \\ 0.5{-}2\,\mathrm{cm} & \text{看形态与浸润深度} \\ > 2\,\mathrm{cm} & \text{倾向外科手术或分期先行} \end{cases}$$

**巴黎分型（Paris classification）**把早期消化道肿瘤按内镜形态分为隆起型（0-I）、平坦型（0-II）与凹陷型（0-III），其中 0-IIc（浅凹陷）内镜最难识别却浸润风险更高。

**为什么用「厘米」而不是「毫米」当刻度？** 因为内镜视野中参照物稳定（活检钳开径约 7 mm 常被用作标尺），而直径每增加 1 倍，息肉体积增加 8 倍——**病变不是「线性长大」，而是「立方长大」**。这一点与《集合的概念》里从元素个数到结构复杂度的「量变到质变」同理：>1 cm 的息肉恶变风险显著上升，构成了息肉切除策略的数学基础。

## 5 内镜下的诊断闭环：看见 → 活检 → 病理

内镜诊断是一条闭环流水线：

1. **看形态**：色泽、边界、微血管形态（NBI/放大内镜增强对比）；
2. **取活检**：可疑处多点取材；
3. **送病理**：明确炎症、异型增生（dysplasia）还是癌；
4. **给分期**：EUS 判断浸润深度 T 与淋巴结 N，决定内镜下切除还是外科手术。

**辨析｜易错点：** 内镜所见与病理结论可能不一致——「内镜下像溃疡癌」而病理报告「慢性溃疡」是常态，反之「内镜似乎正常」而病理报「萎缩」也常见。因此**内镜报告永远要写「内镜所见 + 病理结果」两栏，不能只写一栏**。这条临床铁律，正是把「视觉」与「组织学」两套证据分开登记的方法论，和我们在《概率论与数理统计》里强调「先设检验、再下结论」是同一精神。

## 6 内镜的清洗消毒：看不见的工序

内镜是一根「从身体里穿过的管道」，它既可能救命，也可能把上一个患者的细菌带给下一个患者。内镜相关感染（ERI）发生率不高，却是内镜质控的生死线。**软式内镜的再处理（reprocessing）有一套标准工序**：

1. **预清洗**：检查后立即擦拭、冲洗管腔，避免生物膜形成；
2. **酶洗**：酶溶液分解血迹与黏液；
3. **高水平消毒**：软式内镜不能高温高压灭菌，只能用消毒剂（邻苯二甲醛、过氧乙酸等）浸泡做「高水平消毒」；
4. **漂洗、干燥与储存**：彻底干燥，防止细菌在水膜里繁殖。

**辨析｜易错点：** 内镜「消过毒」不等于「无菌」。**软式内镜做的是「高水平消毒」而非「灭菌」**——它能杀灭绝大多数微生物，但无法保证杀灭芽孢。这决定了十二指肠镜（ERCP 用）这类「内部有抬钳器」的器械风险最高：抬钳器缝隙易藏生物膜，历史上曾多次暴发耐碳青霉烯肠杆菌（CRE）的 ERCP 相关感染。

**「看不见的工序决定看得见的结局」**：一条内镜的安全与寿命，一半取决于镜头前的技术，一半取决于镜头后的消毒。这与《医院感染学》的逻辑一脉相承——侵入性器械越多，院感防控的「感染率 × 器械使用量 = 感染负担」就越重要。

## 7 内镜下治疗：诊断内镜的「第二职业」

内镜早就不是「看一眼」的工具。它从工作通道伸出的每一件器械，都在把外科手术「微创化」：

| 治疗动作 | 原理 | 代表场景 |
| --- | --- | --- |
| 息肉切除术（EMR / 圈套） | 电凝切除隆起病变 | 结直肠息肉、早期癌 |
| 内镜黏膜下剥离术（ESD） | 整片剥离黏膜下病变 | 早期胃癌 / 食管癌（见《消化道肿瘤》） |
| 内镜止血 | 夹闭 / 热凝 / 注射 | 溃疡出血（见《消化道出血》） |
| 曲张静脉套扎 | 橡皮圈阻断血流 | 肝硬化静脉曲张（见《肝硬化与门脉高压》） |
| ERCP 取石 / 支架 | 经乳头逆行操作 | 胆总管结石、梗阻性黄疸 |

**核心概念**：**ESD（endoscopic submucosal dissection）**：用切开刀把早期病变连同其下黏膜完整剥离，实现「黏膜层内的根治」。它把「开腹切胃」变成「镜下剥一块黏膜」，是内镜从「诊断」跨向「外科」的标志性技术。

**认识论意义**：内镜的演进史，是「观察工具 → 活检工具 → 治疗平台」的三级跳。这提醒我们：**技术工具的边界是动态的**——今天的「诊断工具」，明天可能就是「治疗主力」，这与《介入放射学》的崛起是同一段历史。

## 8 小结

- 内镜 = **光学成像 + 弯曲操控 + 工作通道**三合一，让诊断与治疗合流。
- 六大平台各管一段：胃镜、结肠镜、小肠镜/胶囊镜、ERCP、EUS、胶囊内镜；**活检让「看见」升级为「证实」**。
- 侵入性带来**穿孔、出血、镇静风险**，适应症与禁忌症必须权衡。
- 病变尺寸用**立方增长**理解恶变风险，用**巴黎分型**统一描述形态。
- 诊断闭环是**看形态 → 活检 → 病理 → 分期**，报告必须「所见 + 病理」两栏并存。
