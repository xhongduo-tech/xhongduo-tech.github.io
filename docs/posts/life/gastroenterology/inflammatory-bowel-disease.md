## 为什么从炎症性肠病开始

**炎症性肠病（inflammatory bowel disease, IBD）**：一组以慢性、复发性肠道炎症为特征的疾病，主要包括**克罗恩病（CD）**与**溃疡性结肠炎（UC）**。它把前面学过的几样东西拧成一股：腹泻（《腹泻与吸收不良》）、腹痛急症（《肠梗阻与急腹症》）、肿瘤风险（《消化道肿瘤》）与内镜随访（《胃肠内镜诊断》）。同时，IBD 是「免疫-环境-遗传」三方博弈的典型：我们常说「免疫系统分不清敌我」，而 IBD 让我们看清「为什么分不清、后果是什么」。它也是「肠脑轴」与《免疫学》交叉最密集的疾病。

## 1 两张面孔：克罗恩病 vs 溃疡性结肠炎

UC 与 CD 是同族却不同的病，先分清是诊断第一步：

| 维度 | 溃疡性结肠炎（UC） | 克罗恩病（CD） |
| --- | --- | --- |
| 病变范围 | 仅结肠，自直肠向近端连续 | 全消化道「跳越式」，回肠末端最常见 |
| 累及层次 | 黏膜 + 黏膜下层 | **全壁性**（可穿孔、成瘘） |
| 形态 | 连续弥漫、隐窝脓肿 | 裂隙样溃疡、鹅卵石样、肉芽肿 |
| 并发症 | 中毒性巨结肠 | 狭窄、瘘管、穿孔 |
| 吸烟 | 少见 | 高发（吸烟是 CD 的危险因素） |

**「全壁性 vs 黏膜层」是两者的分水岭**：CD 的全壁炎症让它能穿透肠壁形成瘘管、脓肿，而 UC 局限在黏膜，重度发作时反而更怕「中毒性巨结肠」这种整段结肠麻痹扩张的暴发性事件。<span class="marginnote">有意思的是吸烟的相反效应：吸烟加重 CD 却似乎「保护」UC。机制未完全清楚，但这提示两种病即便症状相似，发病通路的偏置完全不同——同一种环境因子，在两条通路上作用相反，是「多因素疾病」的绝佳例证。</span>

## 2 病因三角：遗传、免疫、肠道菌群

IBD 的确切病因未明，但共识是「遗传易感 + 环境触发 + 菌群/免疫失衡」：

**遗传**：NOD2/CARD15 等基因位点与 CD 相关，一级亲属患病风险升高；
- **免疫**：Th1/Th17 通路过度激活，TNF-α、IL-23 等促炎因子失控——**免疫不是「缺」了，而是「过」了**；
- **菌群**：肠道菌群失衡（dysbiosis）被怀疑是持续刺激的来源，但「谁是因谁是果」仍是开放问题。

**治疗靶点的逻辑**因此转向「抗炎」而非「杀菌」：抗 TNF-α（英夫利西单抗）、整合素拮抗剂、JAK 抑制剂……每一类药物都在打断「免疫-炎症」环路的一个环节。<span class="marginnote">这里有一个认识论教训：IBD 的病因为何难定？因为它不是单因单果，而是「易感基因 × 环境 × 菌群」的高维组合。用《统计学习》的话说，这是特征之间强交互、样本异质的大问题——「寻找单一病因」的思路在这里天然失灵，转而追求「分层治疗」。</span>

## 3 诊断：四条证据链

IBD 诊断无金标准，靠四条证据合流：

- **临床**：慢性腹泻、腹痛、体重下降、肛周病变（CD 的强信号）；
- **内镜 + 病理**：结肠镜（UC 连续、CD 跳越 + 鹅卵石样）+ 病理（隐窝炎、肉芽肿）；
- **影像**：CTE/MRE（小肠钡剂/磁共振肠造影）看 CD 的小肠受累与并发症；
- **实验室**：炎症标志物（CRP、粪便钙卫蛋白）辅助监测。

**核心概念**：**粪便钙卫蛋白（fecal calprotectin）**：中性粒细胞颗粒蛋白，粪便中浓度反映肠道炎症程度。它是最实用的无创监测工具——**高则炎症活动，低则多为功能性（IBS）**，用一管大便把 IBD 与 IBS 分开，是「生物标志物 + 分类决策」的现代典范。

## 4 公式解析：Mayo 评分与 CDAI

IBD 活动的量化是治疗决策与临床试验的核心。**Mayo 评分**用于 UC，**CDAI（克罗恩病活动指数）**用于 CD。以 Mayo 为例：

$$\mathrm{Mayo} = \underbrace{S}_{\text{排便次数}} + \underbrace{R}_{\text{直肠出血}} + \underbrace{E}_{\text{内镜所见}} + \underbrace{P}_{\text{医师总体评估}}$$

**逐项拆解**：

- **四项子分**：每项 0–3 分（0 = 正常，3 = 最重），相加得 0–12；
- **阈值**：0–2 = 缓解，3–5 = 轻度，6–10 = 中度，11–12 = 重度；
- **为什么用「总分」而不用单一项**：排便次数受饮食、IBS 影响大，单看不可靠；四项加权合成后，单一维度的噪声被摊薄——**这与《概率论与数理统计》里「用多个弱指标合成一个强指标」的合奏思想一致**。

**CDAI** 更复杂：8 项症状/实验室指标，乘以各自权重再求和（范围 0–600+，>450 为重度）。注意这些评分的**主观项（患者自报腹痛、一般状况）**占权重很大——这正是 IBDeal 学「疾病活动度 ≠ 客观炎症」的原因：一个患者排便 6 次但内镜正常，可能不是 IBD 活动而是 IBS 重叠（见《功能性胃肠病》）。

## 5 治疗阶梯与外科原则

IBD 治疗走「阶梯策略」：

- **轻中度**：5-ASA（美沙拉嗪，UC 一线）、布地奈德、抗生素（CD 的活动性肛周病变）；
- **中重度**：糖皮质激素（急性控制）、免疫抑制剂（硫唑嘌呤）、**生物制剂（抗 TNF、整合素、IL-12/23）**；
- **难治/爆发**：联合免疫抑制 + 生物制剂，乃至手术。

**手术的角色**：UC 可全结肠切除「治愈」（但保留回肠储袋）；CD 手术**不能根治**（复发率高），只在并发症（狭窄、瘘管、穿孔、脓肿）时干预——**「能不动刀就不动刀，动了刀也不断根」**是 CD 与 UC 的根本区别。

**辨析｜易错点：** 激素是「灭火器」不是「长期药」。长期使用糖皮质激素副作用多（骨质疏松、糖尿病、免疫抑制），且对维持缓解无益——**IBD 的长期治疗应尽快过渡到「免疫调节 + 生物制剂」的维持方案**。这是「控制急性 vs 维持缓解」两个治疗目标的经典分野。

**治疗目标的两层含义**：控制急性（诱导缓解）与维持缓解是两个不同的战斗——前者要「快而猛」（激素、生物制剂诱导），后者要「稳而久」（免疫调节剂维持）。**把「诱导」与「维持」分开规划，是 IBD 全程管理的骨架**，也解释了为什么「激素有效却只能短期用」——它解决的是「现在」，维持方案解决的才是「以后」。

## 6 肠外表现：溃疡在肠，病在全身

IBD 不只伤肠道——**约 1/4 的患者出现肠外表现（extraintestinal manifestations, EIM）**，有些甚至先于肠道症状出现：

| 系统 | 常见表现 | 备注 |
| --- | --- | --- |
| 关节 | 外周关节炎、强直性脊柱炎 | 外周型随疾病活动起伏，中轴型相对独立 |
| 皮肤 | 结节性红斑、坏疽性脓皮病 | 结节性红斑常与活动度相关 |
| 眼 | 巩膜外层炎、葡萄膜炎 | 需眼科会诊 |
| 肝胆 | 原发性硬化性胆管炎（PSC） | 与 UC 强相关、独立于肠道活动，是胆管癌危险因素 |
| 口腔 | 阿弗他溃疡 | 常被忽视 |

**认识论要点**：肠外表现的存在，说明 IBD 的免疫失调是**系统性的**，而非局限在结肠——**「肠」只是主战场，不是全部战场**。原发性硬化性胆管炎尤其重要：它让 UC 患者多出「胆汁淤积 + 胆管癌」两条风险线，随访时肝酶与胆管影像不可缺席。

**临床铁律**：**关节、皮肤、眼的新症状，对 IBD 患者而言不一定是「并发症」，可能就是 IBD 本身**——把肠外表现认出来，是避免误诊漏诊的第一课。这与《风湿免疫病学》的「多系统受累」框架完全互通。

## 7 生物制剂的个体化：从「用药」到「调药」

抗 TNF 等生物制剂把 IBD 的治疗带入「靶向时代」，但也带来了新问题：**同一个药，为什么有人有效有人无效、有人打了几个月就「失效」？**

**药物浓度与抗药抗体（TDM）**：治疗性药物监测（therapeutic drug monitoring）回答两个数字：

- **谷浓度（trough level）**：下次给药前的药物血药浓度——太低提示「剂量不足」或「清除过快」，可能该加量或缩短间隔；
- **抗药抗体（anti-drug antibody）**：机体把「人源化抗体」当成外源蛋白攻击，抗体阳性常导致药物清除加速、疗效丢失——**「疗效下降时，先查浓度和抗体，而不是盲目换药」**。

**这是一个闭环反馈系统**：给药 → 测谷浓度 → 调剂量 / 换方案 → 再测——**和《控制系统》里的反馈调节是同一套「观测-比较-修正」循环**。它也解释了为什么「一药到底」的粗放模式正在被「达标治疗（treat-to-target）」取代：**目标是黏膜愈合（客观终点），手段是动态调药**。

**辨析｜易错点：** 药物「失效」未必是真失效——可能是**低浓度**（该加量）而非**免疫原性失效**（该换药）。不做 TDM 就换药，等于跳过诊断直接改方案，是生物制剂时代最贵的浪费。

## 8 小结

- IBD = UC（**连续、黏膜层、结肠**）+ CD（**跳越、全壁性、全消化道**），「层次」是分水岭。
- 病因是**遗传 × 环境 × 菌群**的高维互动，免疫「过度」而非「缺失」。
- 诊断靠**临床 + 内镜病理 + 影像 + 生物标志物（钙卫蛋白）**四条证据合流。
- **Mayo / CDAI 是「多弱指标合成为强指标」**，用总分做分度与疗效判定。
- 治疗阶梯：**5-ASA → 激素（短期灭火）→ 免疫抑制剂/生物制剂（长期维持）→ 手术（仅指征性）**。
