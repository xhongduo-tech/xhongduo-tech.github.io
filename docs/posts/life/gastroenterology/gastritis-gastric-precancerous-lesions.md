## 为什么从胃炎与胃癌前病变开始

如果说《消化性溃疡》讲的是胃黏膜的「急性冲突」，那么**胃炎**讲的就是胃黏膜的「慢性战争」。而胃炎的长期演化，可能沿一条可预测的阶梯走向胃癌——这就是著名的 **Correa 级联（Correa cascade）**。理解这条级联，是理解「癌症筛查」与「癌前病变管理」整个体系的钥匙：**癌症不是终点，而是一条可以由早期干预切断的路径的末端**。这一篇把「病理演变」与「内镜随访」两套工具放在同一张时间轴上。

## 1 急性与慢性胃炎：两场不同的战争

**胃炎（gastritis）**：胃黏膜的炎症。按病程分两型：

- **急性胃炎**：突发、多由药物（NSAIDs）、应激、酒精、放射等损伤因子引起，黏膜糜烂出血；根除诱因后多可修复。
- **慢性胃炎**：持续 ≥ 数月的炎症，最常见病因是 H. pylori 感染，其次为胆汁反流、自身免疫。<span class="marginnote">自身免疫性胃炎（A 型）攻击壁细胞，导致低胃酸与内因子缺乏——后者会引起维生素 B₁₂ 吸收障碍，进而发生恶性贫血。这是《血液病学》与消化科罕见而重要的接口。</span>

**急性与慢性的本质差别是「是否持续」**：急性是单次打击，慢性是稳态漂移——一旦炎症成为长期状态，黏膜就在「损伤—修复」的循环里消耗再生储备，为异型增生埋下伏笔。

## 2 Correa 级联：胃癌的「长征路线」

**Correa 级联（Correa cascade）**描述肠型胃癌发生的多步骤形态学序列：

$$\text{正常黏膜} \;\rightarrow\; \text{慢性非萎缩性胃炎} \;\rightarrow\; \text{慢性萎缩性胃炎} \;\rightarrow\; \text{肠上皮化生} \;\rightarrow\; \text{异型增生（dysplasia）} \;\rightarrow\; \text{胃癌}$$

**每一步都是一次「退化的累积」**：

- **萎缩**：胃腺体数量减少，壁细胞与主细胞丢失，泌酸能力下降；
- **肠上皮化生（intestinal metaplasia）**：胃黏膜出现本该在肠道才有的杯状细胞、吸收细胞——**胃「学会了肠子的样子」**，这是一个关键的可疑信号；
- **异型增生（dysplasia）**：细胞形态与排列出现明显异型，是「最后的癌前状态」，分低级别与高级别。<span class="marginnote">「肠上皮化生」这个名字自带隐喻：组织在慢性炎症压力下发生了「表型漂移」。理解它最好的类比是《系统科学》里的「相变」——系统在持续扰动下，从一种稳定态滑向另一种稳定态。化生到癌并不是必然，却是概率显著升高的一段「红区」。</span>

**关键事实**：这条级联并不是「必走之路」，每一步都可以停留甚至逆转——尤其根除 H. pylori 后，萎缩与化生的进展会被显著放缓，这正是「一级预防」的立足点。

## 3 分类系统：OLGA 与 OLGIM

要把级联「定位」到具体的患者身上，临床使用分期系统：

**OLGA（萎缩性胃炎分期）**：综合胃窦 + 胃体的萎缩程度与范围，分期 0–IV 期；
- **OLGIM**：用肠化生代替萎缩来分期，被认为与胃癌风险的关联更稳定。

内镜下用 **Kimura–Takemoto 分型**判断萎缩范围（闭合型/开放型）。<span class="marginnote">这些分期系统本质上都是《概率论与数理统计》里的「风险分层」：把连续的风险切成离散档位，每一档对应一套随访频率——III–IV 期建议 1–3 年复查胃镜，0–I 期则放宽。医学的管理决策，很多就是「给风险分档 + 给档位定频次」。</span>

## 4 公式解析：异型增生的随访决策树

高级别异型增生（HGD）是治疗决策的关键节点。随访策略可用一棵概率决策树描述：

$$\text{肠化生 + 家族史/持续萎缩} \xrightarrow{P(\text{HGD}) \approx 0.2\%/\text{人年}} \text{定期内镜 + 靶向活检} \xrightarrow{\text{HGD 确诊}} \text{内镜下切除（ESD）}$$

**逐项拆解**：

- **$P(\text{HGD})$**：肠化生进展为高级别异型增生（乃至早癌）的年发生率约 0.2%–0.3% 每人年——数字很小，但**乘上数十年病程就是不可忽略的风险**，这正是「低概率 × 长时间 = 高累积风险」的复利式思考；
- **靶向活检**：内镜用 NBI/放大观察 + 地图式多点活检，把取样误差压到最低——**「不活检，就不知道你现在站在这条级联的哪一级」**；
- **ESD（内镜黏膜下剥离术）**：对高级别异型增生与部分早癌，可用内镜整片切除，实现「胃里做手术、不开腹」——内镜诊断与治疗在这里合流。

**辨析｜易错点：** 活检阴性不等于无病变——取样误差让病理「阴性」可能只是「没抓到」。因此**内镜随访中，形态可疑而病理阴性时，不是「没事了」，而是「再确认」**。这提醒我们区分「统计意义上的安全」与「个体意义上的确认」，与《概率论》里「不拒绝原假设 ≠ 接受原假设」同构。

## 5 治疗与预防：级联的逆行者

- **根除 H. pylori**：对所有萎缩/化生患者，根除可延缓甚至部分逆转萎缩，是切断级联最有力的一步；
- **内镜监测**：按 OLGA/OLGIM 分期定制随访频率；
- **生活方式**：控制高盐、腌制食物、吸烟——这些是级联的「助推器」；
- **早期干预**：HGD/早癌用 ESD 整片切除，5 年生存率接近 100%，而进展期胃癌则显著下降——**「级联走得越早切断，代价越低」是这篇最核心的结论**。

**随访频率的「分档口诀」**：

| 风险档 | 建议随访 |
| --- | --- |
| 无萎缩 / 轻度局限萎缩（0–I 期） | 每 3 年胃镜 |
| 广泛萎缩 / 肠化生（II 期） | 每 1–2 年胃镜 |
| III–IV 期（重度 + 广泛） | 每 1 年胃镜，必要时放大内镜 |

**辨析｜易错点：** 随访频率不是「越勤越好」——胃镜本身有风险与成本，间隔过短并不能把「级联断裂」提前多少。**「按风险分档定频次」是医学从「一刀切」走向「精准」的日常形态**：把人群按风险切档，每一档匹配一组检查强度，这与《机器学习》里「分层抽样」、与《公共卫生》里「高危人群管理」是同一套思想。把「分档随访」与 OLGA / OLGIM 分期连起来看，就是一张完整的决策图：**病理分期决定风险档，风险档决定随访频率，随访频率决定「级联在哪里被截断」**——预防医学的整个闭环，就藏在这三行因果里。

**一级预防的另一半在餐桌**：从「盐与腌制」转向「新鲜果蔬」、控制 H. pylori 再感染（分餐制），都是级联上游的「刹车」——**越是上游的干预，越便宜也越有效**。

**诊断与筛查的分工**：胃镜负责「看见级联走到哪一级」，血清学与呼气试验负责「追查病因（H. pylori）在不在」。**把「追因」与「分级」两条线分开跑，随访才不至于顾此失彼**——这也是《消化内科》整门课反复出现的工作流：先找因，再分档，后定频。

## 6 内镜所见与病理报告：双轨记录怎么读

慢性胃炎的分级离不开「内镜 + 病理」两套系统配合——这正好用上《胃肠内镜诊断》里「所见 + 病理两栏并存」的铁律：

**内镜侧（Kimura–Takemoto 分型）**：按萎缩是否越过贲门分为**闭合型（C 型）**与**开放型（O 型）**，并分 1–3 级——开放型提示萎缩范围更广、随访要更密；**病理侧（悉尼系统, Sydney System）**：报告必须回答四个问题——部位（胃窦 / 胃体）、病因（H. pylori 感染 / 自身免疫 / 化学性）、形态（萎缩、肠化生、异型增生、活动性炎症）与程度（轻 / 中 / 重）。

**为什么这套「双轨」不可替代？** 因为内镜能看「范围」，病理能定「性质」：

- 内镜下的轻度萎缩，病理可能已是中重度肠化生——**「看起来轻」不等于「实际上轻」**；
- 病理的肠化生分型（完全型 / 不完全型）与异型增生分级，直接决定随访频率。

**辨析｜易错点：** 一块活检的病理报告只代表「针尖大的样本」。萎缩与肠化生常呈「地图状」分布，**单点活检可能漏掉最重的区域**——这就是为什么规范化随访要求「地图式多点活检」（胃窦 + 胃体至少各取 2 块，以小弯侧为主）。**取样策略的严谨程度，决定了分期系统的可靠性**——这是统计学「抽样代表性」在活检场景的直接应用。

## 7 胃癌的流行病学：谁在得病，能不能防

胃癌曾是全球癌症死亡的第一位，如今仍是东亚的重负。理解它的分布，就是理解「筛查资源该投给谁」：

| 地区 / 人群 | 风险水平 | 主要解释 |
| --- | --- | --- |
| 东亚（中、日、韩） | 高 | H. pylori 感染率高 + 高盐腌制饮食 |
| 北欧 / 北美 | 较低 | 感染率下降、冷链普及、分餐制 |
| 年轻 / 有家族史者 | 个体偏高 | 遗传（CDH1 等）+ 环境交互 |

**一级预防的着力点因此非常清晰**：**根除 H. pylori + 降低食盐 / 腌制食品 + 戒烟**——这三板斧几乎覆盖了胃癌可干预风险的大头。日本的全民胃镜筛查与韩国的幽门螺杆菌根除计划，都在用国家层面的证据证明：**胃癌是可以被「预防 + 早诊」推着下降的**。

**与《病毒性肝炎》的呼应**：胃癌与肝癌共享同一套预防逻辑——**先除掉慢性感染（H. pylori / 乙肝病毒），再监控癌前状态（萎缩化生 / 肝硬化）**。两条轴线殊途同归：**感染驱动的癌，预防的核心就是控制感染**。

## 8 小结

- **Correa 级联**：正常 → 慢性胃炎 → 萎缩 → 肠化生 → 异型增生 → 胃癌，是可逆可停留的形态学阶梯。
- 慢性胃炎的主因是 **H. pylori**；急性胃炎的主因是 NSAIDs / 应激 / 酒精。
- 分期工具 **OLGA / OLGIM / Kimura–Takemoto** 把风险切档，指导随访频率。
- 随访决策树 = **低年发生率 × 长病程 = 累积风险** + **靶向活检确认级联位置**。
- 预防即「逆行级联」：**根除 H. pylori、控制饮食、按期内镜、早癌 ESD 切除**。
