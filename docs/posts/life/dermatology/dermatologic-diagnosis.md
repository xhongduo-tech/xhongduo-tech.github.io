## 为什么从诊断方法开始

上一节拿到了皮肤的三层地图，但地图不是诊断。皮肤科医生看病与内科最大的差别在于：**皮损长在体表，看得见、摸得着**——诊断一半靠看，一半靠问。会看，是指能把一团「红、肿、痒、脱屑」翻译成精确的形态学语言；会问，是指能从「什么时候起的、怎么发展的、在哪里分布」中提取病因线索。<span class="marginnote">内科病常常藏在仪表读数后面，皮肤病则「当场给证据」：原发性皮损的形态几乎直接指向一大类病——比如「水疱 + 红斑」指向疱疹与免疫性大疱，「丘疹 + 脱屑」指向银屑病与皮炎。先学会分类形态，再谈鉴别诊断。</span>

这一节是全书的方法论章，也最像「医学的第一性原理」：**观察 → 描述 → 分类 → 缩小范围 → 用检查验证**。这套流程与科学方法同构，也与本站第三级《科学研究方法》里「现象—假说—检验」的循环互为镜像。

## 1 问病史：五个必答的问题

任何皮疹的病史都要回答**五个问题**：**何时起病**（出生即有还是后天获得）、**最初位置与扩散方式**（先手部后全身，还是始终局限一处）、**有没有诱因**（接触新衣物、服药、晒太阳、出差）、**伴随症状**（痒、痛、发热、关节痛、口腔溃疡）、**既往史与家族史**（过敏史、糖尿病、银屑病家族史）。

尤其不要漏掉**用药史**：药疹可以模仿几乎所有皮肤病，停药才是第一治疗。问一句「最近半个月吃过什么药，包括非处方药和中草药」，往往省下整个鉴别诊断。<span class="marginnote">皮肤科最经典的一句口头禅：<strong>Everything that itches doesn't have a rash; everything that rashes doesn't itch</strong>（痒的未必有疹，出疹的未必痒）。痒是炎症与组胺的信号，痛常提示病毒感染或血管炎累及神经。</span>

## 2 看皮损：形态学是皮肤科的普通话

把皮损分成两类：**原发性皮损**（疾病本身直接造成的改变）与**继发性皮损**（原发皮损演变或受搔抓摩擦后的结果）。这张表是皮肤科的「字母表」，必须背到条件反射：

| 原发性皮损 | 定义 | 典型例症 |
| --- | --- | --- |
| **斑（macule）** | 平坦、仅颜色改变，直径 < 1 cm | 雀斑、初期白癜风 |
| **斑片（patch）** | 同上但直径 ≥ 1 cm | 白斑、咖啡牛奶斑 |
| **丘疹（papule）** | 隆起、实性，直径 < 1 cm | 毛囊炎、扁平疣 |
| **斑块（plaque）** | 隆起、实性，直径 ≥ 1 cm | 银屑病、苔藓样变 |
| **结节（nodule）** | 更深、更大的实性隆起 | 皮下囊肿、纤维瘤 |
| **水疱（vesicle）** | 含液、隆起，直径 < 1 cm | 单纯疱疹、水痘 |
| **大疱（bulla）** | 含液、隆起，直径 ≥ 1 cm | 天疱疮、大疱性类天疱疮 |
| **脓疱（pustule）** | 含脓的隆起 | 脓疱型痤疮、脓疱疮 |
| **风团（wheal）** | 暂时性、瘙痒性水肿性隆起 | 荨麻疹 |

**继发性皮损**常见的有：**鳞屑（scale）**、**结痂（crust）**、**糜烂（erosion）**（表皮缺失，愈合不留疤）、**溃疡（ulcer）**（深达真皮，留疤）、**苔藓样变（lichenification）**（长期搔抓导致皮纹加深，如慢性湿疹）、**抓痕（excoriation）**、**萎缩（atrophy）**。

**辨析｜易错点：糜烂与溃疡一字之差，性质天差地别。** 糜烂只丢表皮，愈合不留瘢痕；溃疡穿透真皮，愈合必留瘢痕——且溃疡深达筋膜、肌肉时常提示血管性溃疡或恶性肿瘤，必须活检。同理，「斑丘疹」是一个连写术语，指兼具斑与丘疹的皮损，不是「斑＋丘疹的并集」那么简单。<span class="marginnote">分布模式也是诊断信息：接触性皮炎常在暴露部位「边缘清晰」，湿疹在屈侧「对称弥漫」，带状疱疹严格单侧沿神经节段分布——<strong>分布</strong>本身就是一条诊断线索。</span>

## 3 体检辅助与专科检查

**伍德灯（Wood's lamp）**：365 nm 紫外灯。白癫风在灯下呈亮白色，头癣呈苹果绿荧光，红癣（腋窝、腹股沟的类白喉杆菌感染）呈珊瑚红色——这是「眼睛看不见，灯下现原形」的第一课。
- **皮肤镜（dermoscopy）**：放大 + 偏振光看皮损内部结构。色素痣与黑素瘤的鉴别、甲病的血管形态，都依赖它。黑素瘤常显示**色素网、蓝白幕、不对称结构**。
- **玻片压诊（diascopy）**：用玻片压皮损，褪色说明是血管扩张（如血管瘤），不退色说明有出血或色素（如淤点）。<span class="marginnote">「压一压」这个小动作能区分红斑（血管性）与紫癜（出血性）——紫癜是血管炎和血小板减少的线索，属于内科急症范畴，见第五级《血液学》与《免疫学》。</span>
- **皮肤划痕 / 皮损刮擦**：刮除银屑病鳞屑可见针尖样出血点（**Ausptiz 征**）；挤压水疱、牵拉皮肤让疱扩散（**Nikolsky 征阳性**）提示表皮松解性疾病。
- **实验室检查**：**真菌镜检（KOH）**涂片找菌丝与孢子；**Tzanck 涂片**找棘层松解细胞（天疱疮）或多核巨细胞（疱疹）；**细菌培养**、**梅毒血清学**、**过敏原检测**（斑贴试验测Ⅳ型接触过敏，点刺试验测Ⅰ型速发过敏）。
- **皮肤活检**：切除、环钻（punch）或刮取一小块组织送病理。**注意：取材部位的选择本身是诊断的一环**——病变边缘（成熟而非坏死）最代表疾病真实状态。

## 4 核心要点：把「形态—分布—检查」串成鉴别路径

| 症状 + 形态 | 优先考虑 | 确诊检查 |
| --- | --- | --- |
| 红斑 + 水疱 + 口腔溃疡 + Nikolsky（+） | 天疱疮 | Tzanck + 免疫荧光 + 活检 |
| 红斑 + 大疱 + 老人 + 剧烈瘙痒 | 大疱性类天疱疮 | 直接免疫荧光（基底膜带线状） |
| 环状红斑 + 发热 + 关节痛 | 自身免疫 / 莱姆病 / 药物 | 血清学、风湿免疫全套 |
| 鳞屑性斑块 + Ausptiz（+） | 银屑病 | 临床即可，必要时活检 |
| 紫癜样丘疹 + 发热 | 血管炎 / 脑膜炎球菌血症 | 活检 + 免疫荧光 + 血培养 |

## 5 小结

- 诊断流程 = **问病史 → 看形态 → 找分布 → 用检查验证**。
- **原发性皮损**（斑、丘疹、斑块、结节、水疱、大疱、脓疱、风团）是分类的核心；**继发性皮损**（鳞屑、糜烂、溃疡、苔藓样变）反映病程与行为。
- **糜烂不留疤，溃疡留疤**；紫癜压之不褪色，是血管炎的报警信号。
- **伍德灯、皮肤镜、KOH、Tzanck、活检**是五大常用工具，取材位置与检查时机同样重要。
- **药疹模仿一切**——任何皮疹都要先问用药史。

在下一节，我们将用这套「形态学 + 分布」的武器，进入最见真功夫的鉴别题：**湿疹与接触性皮炎**——两个都「红、痒、脱屑」的对手。
