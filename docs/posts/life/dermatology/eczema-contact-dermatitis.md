## 为什么从湿疹与接触性皮炎开始

「湿疹」是皮肤科门诊出现频率最高的主诉之一。它不是一个病，而是一组**以红斑、丘疹、水疱、瘙痒、渗出、慢性期苔藓样变**为共性的「皮炎（dermatitis）」家族的统称。其中最重要、也最需要分清的两个成员是：**特应性皮炎（atopic dermatitis, AD）**——内因主导、与过敏体质相关的慢性炎症；**接触性皮炎（contact dermatitis, CD）**——外因主导、皮肤直接接触刺激物或致敏物引起。

为什么要先分清内外？因为**病因方向决定了治疗方向的根本差异**：AD 需要长期「护屏障 + 抗炎」的慢性管理，CD 的核心是「找出并离开那个东西」——找不到过敏原，涂再好的药膏都会复发。<span class="marginnote">这像极了医学里反复出现的「内因—外因」二分：就像第二级《流行病学》区分宿主易感性与暴露因素，皮肤科在这两个病上给了最直观的教科书级示范。</span>

还有一个「从极限到大模型」式的连接：**AD 与 CD 恰好站在「宿主因素 vs 环境因素」的两端**——AD 是「基因（FLG 屏障缺陷）+ 免疫（Th2）主导」的宿主病，CD 是「接触物（镍、油漆、常春藤）主导」的环境病。**「同一张皮，病因的天平可以完全偏向一侧」**——这正是「从极限到大模型」方法论里「先分清变量、再归因」在皮肤科的最小版本，也为后面《免疫学》《过敏反应》埋下接口。

**本节还承担一个「诊疗节奏」的教学**：湿疹的每一步都示范了「**先问清楚（病史与接触史）→ 再看清楚（形态与分布）→ 再选对工具（斑贴试验/评分）**」的完整闭环。**「湿疹是最常见、也最考验基本功的病」**——它门槛低到人人会治，却细到「是不是忘了问一句接触史」就能决定成败。把这一节学透，你其实是在练「诊断学」的本体。

## 1 特应性皮炎：屏障坏了，炎症就来了

**特应性皮炎（AD）**，俗称「湿疹」，是一种与**特应性（atopy）**相关的慢性、复发性、瘙痒性炎症。所谓特应性，是指个体对环境中常见抗原（尘螨、花粉、食物蛋白）产生 IgE 介导反应的倾向，因此 AD 常与**过敏性鼻炎、哮喘**并称「特应性三联征」，患者常常从婴儿期开始患病。

AD 的病理生理是一条完整的链：**遗传易感性 + 皮肤屏障缺陷 → 外界刺激物与变应原渗入 → 树突状细胞（朗格汉斯细胞）呈递抗原 → Th2 细胞驱动的炎症 → 剧烈瘙痒 → 搔抓 → 屏障进一步破坏**。这是一个恶性循环，医学上叫「痒—搔抓循环（itch–scratch cycle）」。

**关键分子事件是角质层屏障蛋白 FLG（丝聚蛋白，filaggrin）基因突变**：丝聚蛋白降解产生的天然保湿因子不足，皮肤角蛋白束排列紊乱，「砖墙」出现缝隙，水分流失、刺激物长驱直入。<span class="marginnote">FLG 突变是 AD 最强的已知遗传危险因素之一——但在欧洲人群中携带率也仅约 10%，说明 AD 是多基因 + 环境共同作用。这正是「基因给枪，环境扣扳机」的经典表述，详见第五级《医学遗传学》。</span>

**AD 的「年龄与流行病学」也值得记住**：全球儿童患病率约 **10–20%**、成人约 2–10%，多数在婴儿期起病、约半数到成年期缓解或减轻，但也有相当比例迁延为成人 AD。**「AD 的皮疹会走（随年龄换部位），但特应性体质未必走」**——许多 AD 患儿长大后转向过敏性鼻炎或哮喘，这正是「**特应性进行曲（atopic march）**」：湿疹、食物过敏、哮喘、过敏性鼻炎常在同一批人身上先后登场。**「把 AD 看作免疫系统发育的早期信号」**，是这个病留给全科医学最重要的视角。

**临床表现随年龄演变形变**：婴儿期好发于面颊、头皮（红斑、丘疹、渗出、结痂）；儿童期转移至肘窝、腘窝等**屈侧**，皮肤干燥、出现苔藓样变；成人期分布更弥漫，手部与眼睑是好发部位。**「屈侧分布 + 干燥 + 剧烈瘙痒 + 慢性复发性」四联征基本指向 AD。**

**「痒—搔抓循环」值得作为一个机制来理解**：AD 的瘙痒不仅来自炎症介质，还来自**屏障破坏后的神经敏化**——搔抓进一步破坏屏障、释放更多炎症因子、又把神经末梢「越挠越痒」地敏化，形成**正反馈闭环**。**打破这个环有两把钥匙：一是把炎症压下去（药物），二是把屏障补起来（保湿）**——这也解释了为什么「光涂药不保湿」常反反复复：**炎症被压、屏障仍破，环没有真正断开**。「**止痒不是目的，断环才是目的**」——这条思路与《银屑病》里「踩住通路」异曲同工。

## 2 接触性皮炎：刺激还是过敏？

**接触性皮炎（CD）**是皮肤接触外物后发生的局部炎症，分两型：

- **刺激性接触性皮炎（irritant contact dermatitis, ICD）**：强酸强碱、清洁剂、汗液浸泡等直接破坏角质层，**无需致敏**，任何人在足够浓度/时间下都会发病。多见于主妇手、清洁工与医护的反复洗手部位。
- **变应性接触性皮炎（allergic contact dermatitis, ACD）**：**Ⅳ 型超敏反应（迟发型）**。小分子半抗原（镍、染发剂中的对苯二胺、常春藤中的漆酚）渗入皮肤，被朗格汉斯细胞捕获、加工，致敏 T 细胞后**再接触时 24–72 小时内**出现红斑、水疱。同一批工人接触同一桶油，只有被致敏的人发病——这就是个体差异。

**辨析｜易错点：AD 与 ACD 的鉴别。** 两者都可能「红、痒、渗出」。关键看三点：**分布**——AD 屈侧对称，ACD 局限于接触部位、形状常「贴合致敏物」（手表带、项链下方正好一圈）；**起病**——ACD 与明确接触史相关，急性、边界清；**斑贴试验**——ACD 阳性、AD 往往阴性。临床上二者还会叠加（AD 皮肤屏障差，更容易被致敏），这就是**变应性接触致敏**风险高的原因。

**「谁在致敏」有一张高频名单值得背下**：**镍**（金属表带、耳环、牛仔裤扣）、**对苯二胺（PPD）**（染发剂）、**漆酚**（毒常春藤/橡树）、**橡胶促进剂**（手套）、**香料与防腐剂（甲醛释放剂、甲基异噻唑啉酮）**（护肤品、湿巾）、**新霉素/外用抗生素**。**「分布贴合接触物 + 斑贴试验定位」**，正是把这张名单变成个体诊断的流程——**治疗 ACD 的「根治」从来不是药膏，而是「找到并离开那个分子」**。

**「手部皮炎」是 ICD 与 ACD 叠加的经典现场**：主妇、清洁工、理发师、医护的双手被反复「水 + 清洁剂」浸泡（ICD 主力），又被手套、染剂、镍等致敏（ACD 叠加）——**手部皮炎常常是「刺激 + 过敏」的双引擎**。**处理原则因此是「先护手再查敏」**：戴内衬棉、外橡胶的手套，减少洗手频率与水温，保湿打底；若仍反复，再行斑贴试验排查隐藏的过敏原。**「一个部位的皮炎，可能是两种机制叠加」**——这条提醒，把手部皮炎从一个「小毛病」变成「鉴别诊断的微缩现场」。

## 3 治疗阶梯：护屏障、抗炎、止痒

| 阶梯 | 手段 | 说明 |
| --- | --- | --- |
| 基础 | 保湿剂（润肤霜） | 所有皮炎的基础，一天多次，修补砖墙 |
| 一线抗炎 | 外用糖皮质激素 | 按部位与严重度选强度；面部、间擦部位用弱效 |
| 替代抗炎 | 外用钙调神经磷酸酶抑制剂（他克莫司、吡美莫司） | 面部、长期用药部位，无激素副作用 |
| 系统治疗 | 口服抗组胺药、光疗（NB-UVB） | 中重度、瘙痒剧烈者 |
| 生物制剂 | 度普利尤单抗（dupilumab，抗 IL-4Rα） | 中重度 AD 的划时代选择，直接阻断 Th2 通路 |

**ACD 的根治永远比药膏更简单也更重要：找到并彻底回避致敏原**（斑贴试验帮你在几百种物质里锁定元凶）；ICD 则要改变行为——戴手套、减少洗手、及时保湿。**凡皮炎，先问「能不能离开这个刺激」，再谈用药。**

**「护屏障」的具体动作值得写清楚**：**洗澡水温低、时间短、用温和沐浴露**，洗完 **3 分钟内趁皮肤还湿就涂润肤霜**（锁住水分）；日常**一天多次**补涂、尤其洗手后。**「先保湿、再用药、最后穿柔软衣物」**是把「护屏障」翻译成每日动作的清单——**屏障管理不是「辅助」，而是 AD 治疗的地基**，没有它，药物再好也会在「环」上反复打转。

**外用激素的「强度分档」是另一条必须懂的尺**：按强度分**弱、中、强、超强**四级（如氢化可的松=弱、莫米松=中、氟轻松/丙酸氯倍他索=强/超强），**面部与间擦部位只用弱-中效、且疗程要短**，躯干四肢可用中-强效，掌跖厚皮才考虑超强效。**「按部位选强度、按疗程控用量」**——这条在《皮肤结构与功能》《痤疮》里反复出现的红线，在这里再次应验：**外用激素是把双刃剑，强度与时长永远是处方里最需要克己的两个旋钮**。

## 4 公式解析：SCORAD——把湿疹的严重程度算成数

判断疗效、比较研究，都需要一个可重复的严重度指标。国际通用的 **SCORAD（SCORing Atopic Dermatitis）** 综合了面积、强度与主观症状：

$$
\text{SCORAD} = \frac{A}{5} + \frac{7B}{2} + C
$$

- **第一步，$A$**：皮损面积占体表面积百分比（儿童按头颈/躯干/四肢比例加权），乘 $1/5$——面积虽重要，但不能喧宾夺主。
- **第二步，$B$**：强度分，对 6 项体征（红斑、水肿/丘疹、渗出/结痂、抓痕、苔藓样变、干燥）各评 0–3 分求和，上限 18；乘 $7/2$ 赋予强度更高权重。
- **第三步，$C$**：主观症状（瘙痒、睡眠影响）由患者自评 0–10 分。

三项权重为何这样配？这是临床流行病学通过「医生整体评估」反推的**回归权重**：让分值变化与病情整体变化尽量一致。<span class="marginnote">这种「把临床严重度编码成可计算数字」的思路，正是第一级《概率与统计》里量表与评分的原理，也是后续《临床研究》中结局指标设计的基础——循证医学的起点，就是把「好不好」变成「几分」。</span>

**一个把 SCORAD 算到底的例子**：设面积 $A = 30$，强度 $B = 12$（六项体征求和），主观 $C = 7$，则
$$
\text{SCORAD} = \frac{30}{5} + \frac{7 \times 12}{2} + 7 = 6 + 42 + 7 = 55
$$
对照分度：**< 25 为轻度、25–50 为中度、> 50 为重度**——本例 55 分落在重度，提示需要从「外用 + 保湿」升级到系统治疗评估。**「算出来是多少，治疗就踩到哪一级」**——这正是把评分用于「分诊」的日常用法：**不是替医生做判断，而是给判断一个可复现的起点**。

## 5 数值锚点与术语速查：湿疹的「数字记忆」

把本节关键数字与词汇收进一张「口袋表」：

| 数字 / 术语 | 含义 | 临床落点 |
| --- | --- | --- |
| 10% | 欧洲人群中 FLG 突变携带率 | 「基因给枪、环境扣扳机」 |
| 24–72 小时 | ACD 致敏后再接触的反应时间 | Ⅳ 型迟发超敏的时间刻度 |
| 3 分钟 | 洗澡后涂抹润肤霜的黄金窗口 | 护屏障的具体动作 |
| 一天多次 | 润肤霜补涂频率 | 屏障管理是治疗地基 |
| SCORAD | $A/5 + 7B/2 + C$ | 面积 + 强度 + 主观加权 |
| 斑贴试验 | 封闭贴敷 48–72 小时判读 | ACD 诊断金标准 |

**读表提示**：湿疹的数字几乎都指向「**时间与频率**」——24–72 小时（迟发反应）、3 分钟（护屏障窗口）、一天多次（保湿频率）。**「湿疹的护理是‘频率与坚持’的事」**——这与《银屑病》《皮肤感染》里「时间是剂量的一部分」完全同构：慢病管理，拼的是可持续的日常。

## 6 小结

- **湿疹（皮炎）**是形态学家族；两大主角是**特应性皮炎（内因）**与**接触性皮炎（外因）**。
- AD 的核心是 **FLG 屏障缺陷 + Th2 炎症 + 痒—搔抓循环**，表现为屈侧、干燥、慢性复发性。
- CD 分**刺激型（无需致敏）**与**变应型（Ⅳ 型超敏，48–72 小时反应）**；治疗之首是**回避致敏原**。
- 治疗阶梯：**保湿 → 外用激素/钙调神经磷酸酶抑制剂 → 光疗/系统药 → 生物制剂**。
- **SCORAD 指数** $=\frac{A}{5}+\frac{7B}{2}+C$ 把面积、强度、主观症状加权成可计算的严重度。
- **痒—搔抓循环是正反馈闭环**：「止痒不是目的，断环才是目的」——抗炎 + 保湿双管齐下。
- 高频致敏原名单（镍、PPD、漆酚、橡胶促进剂、香料防腐剂）要背下——「找到并离开那个分子」。
- **特应性进行曲**（湿疹→食物过敏→哮喘→鼻炎）说明 AD 是免疫系统发育的早期信号。
- 手部皮炎常是「刺激 + 过敏」双引擎——先护手（内棉外胶手套）再查敏。
- SCORAD 算例：$55$ 分 = 重度——「算出来是多少，治疗就踩到哪一级」。
- 外用激素按强度分档、按部位选档——「强度与时长是处方里最需要克己的两个旋钮」。
- 湿疹是「最常见、也最考验基本功」的病——「先问接触史」一句就能决定成败。

在下一节，我们转向一组「来得急、走得也急」的皮损——**荨麻疹与药疹**。风团、瘙痒、甚至窒息，是急性过敏反应在皮肤上的三种面孔。
