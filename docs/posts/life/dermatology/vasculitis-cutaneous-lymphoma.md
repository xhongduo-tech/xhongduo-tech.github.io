## 为什么从皮肤血管炎与皮肤淋巴瘤开始

本节把本专题两条最「系统」的线索合流：**血管炎**是血管壁本身的炎症（可波及任何器官），**皮肤淋巴瘤**是淋巴细胞在皮肤里的恶性增殖（可以播散为全身淋巴瘤）。它们共同证明皮肤科的另一个核心命题：**皮肤是全身疾病的一面镜子**——被怀疑血管炎的患者要查尿、查肾、查肺部；被诊断蕈样肉芽肿的患者要按淋巴瘤的分期去追查内脏。<span class="marginnote">与前面「皮肤本身的病」不同，这两类病是「内科学疾病长在皮肤上」：血管炎的终点站是肾衰竭与呼吸衰竭，淋巴瘤的终点站是骨髓衰竭。皮肤科医生在这里的真正角色，是<strong>全身疾病的第一报警器</strong>——皮肤常是首个、甚至唯一的可观察信号。</span>

从课程线看，本节承接《自身免疫性大疱病》的「自身抗体 + 组织损伤」，并把镜头转向**血管壁的免疫复合物沉积**与**T 细胞克隆性增殖**——为第五级《风湿免疫病学》与《肿瘤血液学》埋下接口。

还有一层「从极限到大模型」式的收获：这两类病都在提醒一个根本命题——**皮肤科看的「皮损」，常常只是系统免疫/肿瘤事件的冰山一角**。血管炎的皮损是一扇窗，窗后是肾、肺、神经；蕈样肉芽肿的斑片是一张牌，牌后是骨髓、淋巴结与全身 T 细胞。**「看皮而知全身」，是皮肤科作为「内科窗口」的核心价值**——这在《色素性皮肤病》里我们见过一次（咖啡牛奶斑提示神经纤维瘤病），本节则是它的重症版本。

**本节也是本专题「免疫线」的收官**：回顾这一路——银屑病是 T 细胞介导、大疱病是 B 细胞/自身抗体介导、血管炎是免疫复合物/ANCA 介导、淋巴瘤是免疫细胞本身的恶性转化。**「免疫系统在皮肤上的四种出场方式」凑齐了**：炎症（银屑病）、自身免疫（大疱病、血管炎）、肿瘤（淋巴瘤）。把这一条线串起来，你就拥有了一张「免疫皮肤病学」的完整地图。

## 1 皮肤血管炎：可触及性紫癜是名片

**血管炎（vasculitis）**是血管壁的炎症，可致血管闭塞、缺血与坏死。皮肤上最典型的信号是**可触及性紫癜（palpable purpura）**——出血性、可扪及（略隆起）的瘀点瘀斑，好发于下肢（重力性分布），常伴水肿、疼痛与溃疡。<span class="marginnote">紫癜的鉴别是「先辨血还是辨炎」：<strong>玻片压诊褪色 = 血管扩张（红斑）；不褪色 = 出血（紫癜）</strong>。而紫癜再分：血小板减少（瘀点、无隆起）、血管炎（可触及、伴炎症）。「可触及」这三个字，是把血管炎从单纯紫癜中捞出来的关键。</span>

**按受累血管口径分三档**（这正是本节的分类骨架）：

**小血管血管炎**：最常见，累及真皮浅层小静脉与毛细血管，病理为**白细胞破碎性血管炎（leukocytoclastic vasculitis, LCV）**——中性粒细胞浸润、核碎裂、纤维蛋白样坏死。代表疾病：**IgA 血管炎（旧称过敏性紫癜，HSP）**（儿童多见，紫癜 + 腹痛/关节痛 + 血尿，DIF 见血管壁 **IgA 颗粒沉积**）、**荨麻疹性血管炎**、**冷球蛋白血症性血管炎**，以及 **ANCA 相关血管炎**（肉芽肿性多血管炎 GPA、显微镜下多血管炎 MPA、嗜酸性肉芽肿性多血管炎）——皮肤表现 + **ANCA 血清学** + 内脏受累（肺、肾、鼻窦）是诊断三角。
- **中血管血管炎**：**结节性多动脉炎（PAN）**与 **Kawasaki 病**。皮肤表现：**皮下结节、网状青斑、溃疡坏死**，位于真皮深层与皮下。
- **大血管血管炎**：**巨大细胞动脉炎（颞动脉炎）**与 **Takayasu 动脉炎**，皮肤表现隐匿，以系统症状为主（头痛、视力障碍、跛行）。

**血管炎的「病理生理」值得用两句话讲透**：**①免疫复合物沉积型**——抗原抗体复合物沉积在血管壁，激活补体、招募中性粒细胞（IgA 血管炎、荨麻疹性血管炎、冷球蛋白血症性血管炎）；**②ANCA 介导型**——自身抗体直接激活中性粒细胞，导致小血管壁坏死（GPA、MPA）。**「免疫复合物型看 DIF 颗粒沉积、ANCA 型看血清学阳性」**——两条机制对应两套检查，这正是「先问哪种敌人、再选哪种工具」在免疫病上的落地。

**诊断与警示**：任何「紫癜 + 发热 + 多系统症状」都可能是**全身性血管炎或败血症（如脑膜炎球菌血症）**——**感染是必须第一个排除的**。检查套路：**皮肤活检（取新发、未破溃的紫癜，送 H&E + DIF）+ ANCA/ANA/补体 + 尿常规 + ESR/CRP**。治疗按病因与脏器受累：感染相关抗感染、药物相关停药、HSP 多为自限（对症 + 监测肾）、ANCA 相关需**糖皮质激素 + 环磷酰胺/利妥昔单抗**免疫抑制。**肾受累是预后决定因素——随访尿常规三个月是铁律。**

**「为什么要盯尿」有一个直观的理由**：IgA 血管炎（HSP）与 ANCA 相关血管炎的靶器官常是**肾小球**——免疫复合物或 ANCA 沉积在肾小球毛细血管襻，引起**血尿、蛋白尿、进行性肾功能下降**，若不干预可走向终末期肾病。**「皮肤紫癜 + 镜下血尿」同时出现时，肾脏已被拉进战局**——这就是为什么皮肤科医生会把「查尿」当成血管炎诊疗的默认动作，而不是可选项。**「皮肤是报警器，肾脏是计价器」**——这句口诀把「看皮而知全身」落到了最具体的一个检查上。

## 2 血管壁的三层，血管炎的三档

![血管壁三层与按血管大小分类的血管炎](/images/dermatology/vasculitis-cutaneous-lymphoma-1.svg)

**辨析｜易错点：血管炎「查不出原因」也很常见。** 约一半的皮肤小血管炎是**特发性**或由**药物/感染**一过性触发，多数自限、不进展为全身病。但**不能因此掉以轻心**：出现以下报警线要追查全身——**发热、体重下降、关节痛、腹痛、血尿/泡沫尿、咳嗽咯血、手足麻木**。皮肤科常做的第一步不是开药，而是「排雷」。

**「网状青斑」值得单独认识**：它表现为**肢体紫红色网纹**（像大理石纹理），是**血管痉挛或血管腔阻塞**的间接征象。它本身多为良性（尤其寒冷诱发的生理性网状青斑），但**当它伴随溃疡、结节、疼痛、系统症状出现时**，可能指向**中血管血管炎（PAN）、抗磷脂综合征、冷球蛋白血症或血管内淋巴瘤**——「**良性的网纹 vs 恶性的网纹**」，分水岭在「是否伴溃疡与系统症状」。这是「皮损形态本身不含善恶、要靠伴随线索定夺」的又一次示范。

## 3 皮肤淋巴瘤：蕈样肉芽肿

**皮肤淋巴瘤（cutaneous lymphoma）**是淋巴细胞在皮肤定居、克隆性增殖的恶性淋巴瘤，最主要是**蕈样肉芽肿（mycosis fungoides, MF）**——一种**皮肤归巢的 CD4+ T 细胞淋巴瘤**，占皮肤 T 细胞淋巴瘤（CTCL）的一半以上。

**临床三部曲**：**斑片期**（扁平红斑，可多年不进展，酷似湿疹/银屑病——**所以「难治性湿疹」要想到 MF**）→ **斑块期**（浸润增厚、边界不规则）→ **肿瘤期**（红色结节、破溃）。<span class="marginnote">MF 是「少见的伪装者」：斑片期皮损没有任何恶性特征，与湿疹在形态上几乎无法区分——<strong>早期诊断靠的是「长期抗湿疹治疗无效 + 活检病理 + T 细胞克隆性分析」</strong>。它教会皮肤科医生：疗效不佳的皮肤病，要敢于打破「第一诊断」。</span>组织病理见**真皮浅层带状淋巴细胞浸润 + 亲表皮现象**（淋巴细胞进入表皮）与**Pautrier 微脓肿**（表皮内成簇淋巴瘤细胞）；免疫组化示 **CD4/CD8 比例倒置、T 细胞受体克隆性重排**。

**Sezary 综合征**是 MF 的白血病变型：**全身红皮病 + 外周血见 Sezary 细胞 + 淋巴结受累**，预后差。**原发皮肤 B 细胞淋巴瘤（PCMZL、PCFCL、PCDLBCL）**按分子分型预后各异。

**把「皮肤淋巴瘤」的谱系串一遍，就懂了「克隆性」的分量**：从**惰性的**（斑片期 MF、PCMZL）到**侵袭性的**（PCDLBCL 腿型、Sezary 综合征），决定它们身份的是**单一克隆的 T 或 B 淋巴细胞**——T 细胞受体或免疫球蛋白基因重排分析，就是抓住这个「单克隆」的分子证据。**「多克隆 = 反应性炎症，单克隆 = 肿瘤」**——这条判别式，是皮肤淋巴瘤诊断与「良性炎症」分手的最后一道门，也是第五级《肿瘤病理学》里「克隆性」概念的临床现场。

**治疗按分期**：斑片/斑块早期——**外用糖皮质激素、氮芥、局部放疗、NB-UVB/PUVA 光疗**（表浅、光敏、无系统性毒性，可长期控制）；进展期/肿瘤期——**全身治疗**：维 A 酸（贝沙罗汀）、干扰素、**莫格利珠单抗（抗 CCR4，靶向皮肤归巢 T 细胞）**、组蛋白去乙酰化酶抑制剂（伏立诺他）、体外光分离置换，必要时造血干细胞移植。

**MF 的「病程节奏」值得单独体会**：**它往往在数年甚至数十年内缓慢演进**——斑片期可持续多年不进展，这让它既是「最温和的淋巴瘤」之一，也是最容易被当成湿疹而漏诊的淋巴瘤。**「慢」既是机会也是陷阱**：机会在于早期用光疗/外用就能长期控制，陷阱在于「看着不严重」让人放松警惕、拖到肿瘤期才就医。**「MF 教会皮肤科医生的一件事：别让『它看起来还好』耽误了该做的活检」**——这条「慢病也要早期确诊」的教训，比 MF 本身更有普适价值。

**MF 的随访同样「按分期设密度」**：早期患者定期皮损评估（面积、浸润度）+ 触诊淋巴结；进展期加**外周血流式（查 Sezary 细胞）、影像（CT/PET）**。**「一个淋巴瘤，看皮、看血、看淋巴结三件事都得盯」**——这与血管炎的「看皮、查尿、查血清」互为镜像，两类病在随访哲学上是同一套。

## 4 核心要点：两类病的一页鉴别

| 维度 | 皮肤血管炎 | 皮肤淋巴瘤（MF） |
| --- | --- | --- |
| 本质 | 血管壁炎症（免疫复合物/ANCA/感染） | T 细胞克隆性恶性增殖 |
| 经典皮损 | **可触及性紫癜**、结节、网状青斑、溃疡 | 慢性红斑→斑块→肿瘤（红皮病） |
| 部位 | 下肢（重力分布） | 躯干、臀部、「泳衣区」 |
| 报警症状 | 发热、血尿、咯血、腹痛 | 难治性「湿疹」、顽固瘙痒 |
| 诊断金标准 | 皮肤活检（H&E+DIF）+ ANCA + 尿检 | 活检（亲表皮/Pautrier）+ 克隆性 + 免疫分型 |
| 治疗核心 | 抗感染/停药/免疫抑制（激素+环磷酰胺/利妥昔单抗） | 早期光疗+局部，进展期全身靶向 |
| 报警信号 | 发热、血尿、咯血、腹痛 | 难治性湿疹、顽固瘙痒、红皮病 |

**读这张表的一条主线**：两列看似不同，**共享的却是同一套逻辑**——「皮损 × 系统线索 × 金标准检查 × 分级治疗」。**「先分级（血管炎分口径、淋巴瘤分期）、再选治疗」**，是这两类「皮损背后的系统病」共同的临床姿态，也把「看皮而知全身」落成了可操作的分步动作。

## 5 数值锚点与术语速查：两类病的「时间与数字」

血管炎与淋巴瘤的临床判断，高度依赖几组「时间与形态」的数字：

| 数字 / 术语 | 含义 | 临床落点 |
| --- | --- | --- |
| 24–48 小时 | 活检应取的新发紫癜时限 | 取晚了只剩修复痕迹 |
| 3 个月 | 随访尿常规的期限 | 肾受累监测铁律 |
| 2–8 周 | DRESS 类药疹的迟发时间 | 区分免疫介导 vs 速发反应 |
| 数年 | MF 斑片期的典型时长 | 「慢」既是机会也是陷阱 |
| 可触及性紫癜 | 略隆起的出血性瘀斑 | 血管炎名片 |
| Pautrier 微脓肿 | 表皮内成簇淋巴瘤细胞 | MF 组织学特征 |

**读表提示**：两类病共享一个思维——**「时间 + 层次」**：血管炎看「取了多久的紫癜、肾脏跟了几个月」，淋巴瘤看「斑片期拖了几年、克隆性重排查了没有」。**把时间轴画出来，这两类「皮损背后的系统病」就都有了坐标。**

### 术语速查

| 术语 | 含义 | 临床落点 |
| --- | --- | --- |
| 白细胞破碎性血管炎（LCV） | 中性粒细胞浸润 + 核碎裂 | 小血管炎的组织学模板 |
| ANCA | 抗中性粒细胞胞质抗体 | 与 GPA/MPA 等血管炎相关 |
| 亲表皮现象 | 淋巴细胞进入表皮 | MF 特征之一 |
| 克隆性 T 细胞重排 | 单一 TCR 克隆扩增 | 区分肿瘤 vs 反应性浸润 |
| Sezary 细胞 | 外周血中的脑回样淋巴瘤细胞 | Sezary 综合征的标志 |
| 网状青斑 | 血管痉挛/阻塞的紫红网纹 | 中血管血管炎、冷球蛋白血症 |

**读表要点**：这两张表叠起来就是「**血管炎靠活检 + 血清学 + 尿检，淋巴瘤靠活检 + 克隆性 + 免疫分型**」——「先问哪种敌人、再选哪种工具」又一次兑现。

## 6 小结

- **可触及性紫癜**是皮肤血管炎的名片；玻片压诊**不褪色** + **可扪及**指向血管炎而非血小板减少。
- 血管炎按口径分**小/中/大**：小血管（LCV、IgA 血管炎、ANCA 相关）最常累及皮肤；**肾受累决定预后**。
- **先排除感染（败血症）**是血管炎诊疗的第一顺序；「查不出原因」的皮肤小血管炎也很常见。
- **蕈样肉芽肿（MF）**是皮肤 T 细胞淋巴瘤：斑片→斑块→肿瘤，**早期酷似湿疹**，诊断靠病理 + 克隆性分析。
- Sezary 综合征 = 红皮病 + 血中 Sezary 细胞；治疗早期**光疗/局部**、进展期**靶向（莫格利珠单抗）+ 全身治疗**。
- **皮肤是报警器、肾脏是计价器**——「皮肤紫癜 + 血尿」时肾已被拉进战局。
- MF 的「慢」既是机会也是陷阱：**别让『看起来还好』耽误了该做的活检**。
- 血管炎看「活检 + ANCA/DIF + 尿检」，淋巴瘤看「活检 + 克隆性 + 免疫分型」——「先分级、再选治疗」。
- 免疫系统的四种出场方式在本专题凑齐：**炎症（银屑病）、自身免疫（大疱病/血管炎）、肿瘤（淋巴瘤）**。

在下一节，我们将走出皮肤病学的单项主题，回到总纲——从结构、诊断到各类疾病的全程回顾，为「皮肤性病学」这一专题画上句号。
