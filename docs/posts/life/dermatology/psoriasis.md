## 为什么从银屑病开始

银屑病（psoriasis），俗称「牛皮癣」，是全球约 1–3% 人口受影响的慢性炎症性皮肤病。它在皮肤科的份量，相当于呼吸科里的哮喘、心内科里的冠心病：**多基因遗传、慢性复发性、显著影响生活质量、并且是现代免疫靶向治疗的主战场。**<span class="marginnote">更深刻的是，银屑病揭示了皮肤科的一个根本观点：<strong>很多皮肤病不是「皮肤的病」，而是「免疫系统在皮肤上发作」</strong>。角质形成细胞的过度增殖只是下游结果，真正的司令部是 T 细胞与细胞因子网络——这个视角将贯穿本专题后面的大疱病、血管炎与淋巴瘤。</span>

在《皮肤的结构与功能》里我们记住了「表皮更替周期约 28 天」。银屑病的全部戏剧性，就浓缩在把这个数字压缩到 3–5 天这一点上——现在，让我们看它怎么发生。

## 1 临床表现：红斑、鳞屑与三个标志

**寻常型银屑病（psoriasis vulgaris）**是最常见类型，典型皮损是**境界清楚的红色斑块，上覆厚层银白色鳞屑**，好发于**肘、膝伸侧、头皮、骶尾部**，对称分布。<span class="marginnote">三个临床体征值得记住：<strong>Auspitz 征</strong>——刮除鳞屑后露出薄膜，再刮见点状出血（真皮乳头血管破裂）；<strong>Koebner 现象（同形反应）</strong>——外伤、搔抓部位新生银屑病皮损；<strong>脂滴样甲</strong>与甲板点状凹陷——指甲受累。</span>

其他类型：**点滴型（guttate）**多由链球菌咽炎触发，青年人多见、皮损小而多、撒胡椒面样分布；**脓疱型**分泛发型与掌跖型；**红皮病型**是全身广泛红斑脱屑的重症；**反向型（inverse）**分布在腋窝、腹股沟等间擦部位，因湿润而无明显鳞屑。

银屑病不只是皮肤病：**约 30% 患者合并银屑病关节炎（psoriatic arthritis）**，典型表现包括远端指间关节（DIP）受累、「腊肠指」（整个指节肿痛）、附着点炎、脊柱炎。此外，银屑病与**代谢综合征、心血管疾病**风险升高相关——这提醒我们，皮肤科的炎症是有「系统回声」的。

## 2 发病机制：增殖失控背后的免疫司令部

银屑病的病理有三大组织学特征：**角化过度与角化不全（鳞屑）**、**表皮突延长**、以及**真皮乳头的毛细血管扩张与炎症浸润**。

机制主线是一条明确的细胞因子通路：**树突状细胞产生 IL-23 → 激活 Th17 细胞 → 分泌 IL-17、TNF-α、IL-22 → 刺激角质形成细胞异常增殖并释放趋化因子/抗菌肽 → 形成自我放大的炎症环路**。角质形成细胞从「正常的 28 天更替」被推成「3–5 天一更替」，于是皮肤拼命产角质而来不及成熟——这就是银屑病大量脱屑的来历。

遗传上，银屑病与 **HLA-Cw6** 及 IL-23R、IL12B、TNIP1 等基因关联最强；环境触发因素包括**感染（链球菌）、精神压力、酒精、药物（β 受体阻滞剂、锂、抗疟药）**。<span class="marginnote">IL-23/IL-17 轴的发现是近 20 年皮肤病学最重要的突破之一：它把银屑病从一个「难缠的皮肤顽疾」变成「通路明确、可被精准阻断的疾病」，也让生物制剂的适应症从肿瘤学正式扩展到了自身免疫领域。</span>

## 3 治疗阶梯：从药膏到生物制剂

| 严重度 | 手段 | 关键点 |
| --- | --- | --- |
| 轻中度（局限） | 外用糖皮质激素 + 维生素 D3 衍生物（卡泊三醇） | 联用增效、避免长期滥用强效激素 |
| 中重度 | **窄谱中波紫外（NB-UVB）**、补骨脂素+长波紫外（PUVA） | 光疗有效但有累积剂量上限 |
| 中重度（系统） | 甲氨蝶呤、环孢素、阿维 A | 各有限制：肝毒性、肾毒性、致畸 |
| 中重度（靶向） | TNF 抑制剂（依那西普、阿达木单抗）、**IL-17 抑制剂（司库奇尤单抗）**、IL-23 抑制剂（古塞奇尤单抗） | 精准阻断通路、起效快、疗效持久 |

**治疗选择的关键是「界定严重度」**——这就需要一个可以客观计算的指标：PASI。

## 4 公式解析：PASI——把全身银屑病算成一张分

**PASI（Psoriasis Area and Severity Index）**是银屑病临床研究里最常用的严重度评分，按四个部位分别打分再加权：

$$
\text{PASI} = 0.1(E_h + I_h + D_h)A_h + 0.2(E_t + I_t + D_t)A_t + 0.3(E_u + I_u + D_u)A_u + 0.4(E_l + I_l + D_l)A_l
$$

- **第一步，四部位**：h（头颈）、t（躯干）、u（上肢）、l（下肢）。权重 0.1 / 0.2 / 0.3 / 0.4 对应体表面积占比（头 10%、上肢 20%、躯干 30%、下肢 40%）。<span class="marginnote">注意与常识的差异：下肢面积占最大头（40%），所以小腿大片皮损对 PASI 贡献最大——这也是为什么「面积估算法」（如九分法）是皮肤科的基本功，见第五级《烧伤》章节的体表估算。</span>
- **第二步，$E, D, I$**：每个部位分别评**红斑（Erythema）、脱屑（Desquamation）、浸润厚度（Infiltration）**，各 0–4 分，相加后乘该部位权重。
- **第三步，$A$**：该部位皮损面积占比，0–6 分（0 为 0%，6 为 90–100%）。
- **第四步，含义**：PASI 0–72 分。临床研究中通常以 **PASI 75（较基线下降 75%）** 作为「疗效达标」的金标准——它把「好不好」翻译成一个可比较的数字，这正是统计学里连续指标与结局定义的具体应用。

**辨析｜易错点：PASI 与 BSA。** BSA 只看面积（0–100%），PASI 同时看面积与严重度；红皮病型全身发红但单个皮损不明显时，PASI 可能反而低估病情，这时要看临床整体评估（如 PGA 与生活质量量表 DLQI）。**任何评分都只是工具，临床判断永远在数字之上。**

## 5 小结

- 银屑病是 **IL-23/IL-17 轴驱动的慢性免疫介导炎症**，角质形成细胞更替被压到 3–5 天，故大量脱屑。
- 典型皮损：**边界清楚的红斑块 + 银白鳞屑**，肘膝伸侧好发；**Auspitz 征、Koebner 现象、甲点状凹陷**是经典线索。
- 不只见皮：**银屑病关节炎（约 30%）**、代谢综合征与心血管风险升高。
- 治疗阶梯：**外用 → 光疗 → 系统药 → 生物制剂（抗 IL-17 / IL-23）**。
- **PASI** 按四部位、三项体征与面积加权，以 PASI 75 判定疗效。
