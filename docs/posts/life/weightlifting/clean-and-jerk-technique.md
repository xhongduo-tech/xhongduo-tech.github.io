## 为什么从挺举继续

抓举考技术，挺举考「技术 + 绝对力量」。挺举由两个子动作拼接而成：先**提铃至胸**（clean），把杠铃从地面翻到锁骨上；再**上挺**（jerk），把杠铃从锁骨上推过头顶。它是两项举重中能举起最大重量的一项——因为杠铃可以先「休息」在锁骨上，再发力上挺，两次发力各举一段，总成绩自然高于一次到顶的抓举。<span class="marginnote">挺举世界纪录在各级别都明显高于抓举：例如男子大级别挺举纪录比抓举纪录通常高出 40–50 公斤。两次发力的「接力」，正是挺举能举起更重杠铃的力学根源。</span>孔子说「工欲善其事，必先利其器」——挺举的两段式结构就是举重运动「分而治之」的利器。

## 1 挺举的整体结构

挺举的完整链条是**提铃至胸 + 上挺**两个子动作，中间以「杠铃停在锁骨上」为界：

**提铃至胸**：从地面拉起杠铃、翻转到锁骨前方，身体下蹲承接，再站起。它的前四个阶段与抓举几乎相同——预备、提铃、引膝、发力——区别只在握距更窄（与肩同宽或略宽），以及发力后的「接法」不同。
**上挺**：在锁骨上短暂稳定后，先做小幅预蹲，再爆发蹬伸，把杠铃推离肩部，同时分腿下蹲让杠铃被锁死在头顶，最后收腿站立。

两个子动作有一个共同的节奏基因：**先蓄力、后爆发、再下潜承接**。抓举把这三步压缩在一次动作里，挺举把它拆成两半，各给一次爆发。

从能量角度看，挺举两次发力让杠铃「分两段」上升，每段需要克服的重力功更小、留给发力的时间更充裕——这正是挺举成绩高于抓举的力学直觉。但反过来，翻站与上挺之间的两次「站稳」，也给了技术出错两次机会：挺举的容错窗口，其实比看上去更窄。

## 2 提铃至胸：翻站的技术要点

提铃至胸的前半段（预备到发力）与抓举共享力学原则：杠铃贴近身体、引膝蓄力、三关节伸展。它的独有之处在发力之后——**翻站**（rack / turnover）：<span class="marginnote">握距是两项最大的姿势差异：抓举宽握、杠铃过头，挺举窄握、杠铃落在锁骨前。窄握意味着手臂更接近身体，翻站时手肘更容易向前向上「钻」，把杠铃稳稳搁在三角肌前束上。</span>

发力后，杠铃获得向上的速度离手，运动员立即下蹲，同时**双手快速将杠铃「翻」到锁骨上方**——手肘向前上方顶起，杠铃落在三角肌前束与锁骨形成的「架」上，形成**前蹲（front squat）位**。翻站的成败取决于三个细节：

**肘部必须高**：肘尖指向前上方，杠铃才不会滑落；肘部下垂是翻站最常见的技术缺陷。
**杠铃贴近颈部**：杠铃越贴近喉咙与锁骨，越不容易前翻，前蹲起身也越省力。
**接铃时身体要「钻」下去**：用下蹲而不是弯腰去迎杠铃，保持躯干竖直。

翻站成功后，在前蹲位稳定，随后用股四头肌发力站起，完成提铃至胸。

**高翻（power clean）**是翻站的简化版：发力后接铃在浅蹲位甚至站姿完成，省去最深的一段下蹲，专练「发力—翻肘」的衔接。新手从高翻入手，能更快建立翻站的手肘感觉，再逐步过渡到完整提铃至胸——这也呼应了《举重技术教学法》一篇「先分后合」的进阶原则。

## 3 上挺：预蹲—蹬伸—分腿

上挺是把杠铃从锁骨推到头顶的爆发动作，可分为**预蹲（dip）—蹬伸（drive）—分腿下蹲（split）—起立**四拍。

**预蹲**是短暂的屈膝屈髋，幅度通常只有十几厘米，速度要快、制动要干脆。<span class="marginnote">预蹲不是「下蹲休息」，而是像压弹簧：预蹲把下肢肌肉拉长、储存弹性势能，随即反向蹬伸把能量释放。预蹲过深会让杠铃在肩膀上弹跳失控，过浅则蹬伸幅度不足。</span>**蹬伸**紧接预蹲的最低点爆发，三关节伸展、耸肩，把杠铃从肩部竖直推出。杠铃离肩后，双脚快速前后分开——**分腿下蹲**——前腿向前迈出、后腿向后滑动，躯干竖直，杠铃被锁死在头顶正上方。最后前腿后收、后腿前并，双脚平行站立，静止等待裁判亮灯。

分腿下蹲有三个易错点：**前腿膝盖不要超过脚尖过多**（否则重心前移）；**后腿膝关节接近地面但不要跪地**；**杠铃始终在头的正上方**，身体与杠铃形成一条竖直连线。

## 4 公式解析：上挺需要多快的推出速度

**上挺的关键不是「把杠铃推多高」，而是「推出后杠铃还能上升多高」——这由推出瞬间的速度决定。**

设杠铃离开肩膀瞬间的竖直速度为 $v$，此后它只受重力做匀减速运动，由竖直上抛公式，杠铃还能继续上升的高度为：

$$
h = \frac{v^2}{2g}
$$

- **第一步，读公式**：$g$ 是重力加速度（约 $9.8\ \mathrm{m/s^2}$），$v$ 是杠铃离肩速度。腾起高度 $h$ 与 $v$ 的平方成正比——速度翻倍，腾起高度变为四倍。
- **第二步，看需求**：上挺时运动员分腿下蹲，肩膀相对地面下降距离记为 $d$。只要杠铃腾起高度 $h$ 大于 $d$（再留出锁臂的余量），杠铃就能在头顶锁死。
- **第三步，反推策略**：深分腿 $d$ 越大，对 $v$ 的要求越低；推出速度 $v$ 越大，分腿可以越浅。所以「预蹲多深」与「推出多快」是一组需要匹配的参数——预蹲太浅导致 $v$ 不足、接不住杠铃，预蹲太深则浪费时间与能量。

一般建议预蹲深度取大腿与地面夹角约 110–140 度的范围，速度要快到「一蹲即起」；练习可借助节拍——下蹲一拍、蹬伸立刻衔接，中间不留停顿。上挺的高阶感觉是把预蹲当作「起跳的准备」：想象双脚要蹬离地面，而不是「先下蹲再站起」。

由此得到一个实用的训练结论：**上挺训练同时练「预蹲的反弹速度」与「蹬伸的爆发力」**，两者共同决定 $v$，进而决定杠铃能否稳定过头。<span class="marginnote">这与抓举的冲量分析一脉相承：$v$ 是两项举重共同的「货币」。抓举用宽握一次到顶，挺举用窄握分两次，但每一次发力的本质，都是把力量转化为杠铃的离手速度。</span>

一个实用的训练参考：**借力推举（push press）**正是把「蹬伸」与「推臂」串起来的半程上挺——它用比完整上挺更轻的重量，反复打磨这两拍的衔接，是全世界举重队的标配辅助练习，也是上挺技术教学的必经台阶。

## 5 上挺的两种下蹲方式：分腿挺与蹲挺

上挺的「下潜承接」有两种主流方式，运动员会依据自身体型与习惯选择：

**分腿挺（split jerk）**：蹬伸后一腿前迈、一腿后滑，形成前后分腿的支撑面。它的支撑面大、对平衡的要求相对低，是国际举坛的主流选择——绝大多数大级别选手都采用分腿挺。
**蹲挺（squat jerk）**：蹬伸后直接下蹲到全蹲位承接杠铃，类似抓举的接铃方式。它的支撑更「竖直」、杠铃路径更短，但对踝髋柔韧与核心稳定要求极高，一旦失稳便无从补救。<span class="marginnote">中国举重队历史上曾以「半蹲挺」闻名——用较浅的半蹲承接，介于分腿与全蹲之间。半蹲挺对发力速度要求极高、动作风险也大，如今已鲜少有人采用。</span>

两种方式的共同点是**「先蹬后潜」**：杠铃必须先被推出离肩，身体才能开始下潜；顺序颠倒（先下蹲再蹬）会使杠铃「粘」在肩上，上挺必然失败。

## 6 挺举的失败模式与应对

挺举的失败比抓举更「多样化」，因为它有两个承接点——锁骨与头顶。常见失败模式有：

**翻站掉铃**：发力不足或肘部未上翻，杠铃砸落胸前。应对：加练高翻与前蹲，强化翻站位稳定性。
**翻站后杠铃前翻**：杠铃离锁骨过远、肘部过低，前蹲起身时杠铃向前滚落。应对：收紧上背、抬高肘部，把杠铃「锁」在锁骨架上。
**上挺预蹲失控**：预蹲过深导致杠铃在肩上弹跳，或预蹲速度不足导致蹬伸乏力。应对：用架上挺单独练「预蹲—蹬伸」两拍。
- **分腿后失衡**：前脚过冲或后脚没滑到位，站起时身体摇晃。应对：空杠分腿练习，把前后脚的落点「画」出来。<span class="marginnote">挺举失败的共性是「节奏断裂」：翻站与上挺之间需要一次彻底的重新稳定，任何急躁的衔接都会让二次发力建立在晃动的根基上。</span>

## 7 术语速查表

| 术语 | 含义 |
| --- | --- |
| 提铃至胸 | 把杠铃从地面翻至锁骨前 |
| 上挺 | 把杠铃从锁骨推到头顶 |
| 翻站 | 发力后手臂上翻、杠铃落锁骨 |
| 前蹲 | 杠铃架在锁骨前的深蹲 |
| 预蹲 | 上挺前小幅屈膝屈髋 |
| 蹬伸 | 预蹲后爆发蹬直下肢 |
| 分腿挺 | 前后分腿承接的上挺方式 |
| 蹲挺 | 全蹲承接的上挺方式 |
| 锁臂 | 过头位双臂伸直锁死 |
| 高翻 | 从高处起拉的提铃至胸变式 |
| 架上挺 | 杠铃架在架上、单独练上挺 |
| 借力推举 | 蹬伸 + 推臂的半程上挺 |

初学者不必急于确定用分腿还是蹲挺：多数教练建议先学分腿挺——它的支撑面更大、容错更高，能让上挺的「蹬伸—下潜」节奏先建立起来；待蹬伸与柔韧都到位后，再评估是否改用蹲挺。分腿挺的后腿位置是常见难点：后腿应「滑」到位而非「跪」下，膝盖接近地面但不要触地。

无论选择哪种方式，上挺的练习都要从「慢动作分解」开始：先空杠练分腿落点，再轻重量练预蹲—蹬伸的节拍，最后才合成完整上挺——技术的正确性，永远优先于重量的大小。

## 8 小结

- 挺举 = **提铃至胸 + 上挺**，是两项举重中能举起最大重量的项目。
- 提铃至胸与抓举共享预备、提铃、引膝、发力四阶段，独有**翻站**：肘高、杠铃贴颈、下蹲承接。
- 上挺四拍为**预蹲—蹬伸—分腿—起立**，预蹲是「压弹簧」、蹬伸是爆发、分腿是下潜锁臂。
- 由 $h = v^2/(2g)$，上挺成败取决于**杠铃离肩速度 $v$** 与**分腿深度 $d$**——预蹲深度与推出速度是一组需要匹配的参数。
- 分腿挺与蹲挺的取舍：分腿挺支撑面大、容错高，蹲挺路径更短、要求更高——初学者宜先学分腿挺。
