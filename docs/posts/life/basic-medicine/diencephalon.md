## 为什么从间脑开始

**间脑（diencephalon）**位于中脑与端脑之间，几乎完全被大脑半球掩盖，由**背侧丘脑（丘脑）、上丘脑、下丘脑、后丘脑与底丘脑**五部分组成。它夹在"高级中枢"（大脑皮层）与"低级中枢"（脑干脊髓）之间，扮演着承上启下的角色。<span class="marginnote">间脑的中心是<strong>第三脑室</strong>（间脑内的腔隙）。间脑最重要的两大部分是：<strong>背侧丘脑</strong>——全身感觉（除嗅觉）传入大脑皮层前的"最后一站"；<strong>下丘脑</strong>——自主神经与内分泌的"总指挥"。</span>

"所有感觉为什么都要经过丘脑""下丘脑为什么被称为'神经内分泌的枢纽'""丘脑综合征为什么出现对侧感觉异常"——间脑的解剖回答这些问题。

## 1 背侧丘脑（丘脑）

**背侧丘脑（thalamus，简称丘脑）**是两个卵圆形灰质团块，位于第三脑室两侧，是**感觉传导路的第三级（最后一级）换元站**——除嗅觉外，所有感觉（痛温觉、触觉、本体觉、视觉、听觉）都在丘脑换元后投射到大脑皮层。<span class="marginnote">"嗅觉不经丘脑"是感觉系统的一条规律：嗅神经→嗅球→嗅皮层，是唯一直接到皮层的感觉通路（在脑神经与视器篇已提）。其余一切感觉都"丘脑中转"——所以丘脑被称为"皮层下的感觉中枢"。丘脑还参与维持意识、调节情绪（与边缘系统联系）。</span>

**丘脑的分部**：丘脑由**内髓板**分为前核群、内侧核群与外侧核群。外侧核群中与感觉关系最密切的是**腹后核**（又分腹后外侧核与腹后内侧核）：

**腹后外侧核**：接受脊髓丘脑束与内侧丘系（躯干四肢的痛温触压与本体觉），投射到大脑皮层**中央后回**（躯体感觉区）。
**腹后内侧核**：接受三叉丘系（头面部感觉），投射到中央后回下部。

**丘脑损伤（丘脑综合征）**：对侧肢体**感觉丧失或异常**（麻木、疼痛、感觉过敏），可伴自发痛（丘脑痛）。因丘脑还有纤维联系，可出现对侧轻偏瘫与共济失调。<span class="marginnote">丘脑综合征常由<strong>丘脑膝状体动脉</strong>（大脑后动脉分支）闭塞引起——对侧偏身感觉障碍（痛温觉、触觉都受累）+丘脑痛。丘脑痛的特点是"自发、剧烈、难以忍受、药物反应差"，是"中枢性疼痛"的典型。丘脑外侧损伤还可累及内囊后肢→对侧偏瘫。</span>

## 2 下丘脑

**下丘脑（hypothalamus）**位于丘脑前下方，是间脑中最小的部分，却是**神经内分泌与自主神经的总指挥**。它包含许多核团，其中最重要的是**视上核**与**室旁核**（分泌抗利尿激素 ADH 与催产素）。

**下丘脑的功能**（"六位一体"）：

**神经内分泌**：分泌**释放激素/抑制激素**（经垂体门脉系统控制垂体前叶）与 ADH、催产素（经垂体束运输到垂体后叶）。
**自主神经中枢**：调节体温、摄食、水盐平衡、血压、心率。
**体温调节中枢**：前部（散热）、后部（产热）。
**摄食中枢**（外侧区）与**饱中枢**（腹内侧核）。
**昼夜节律**：视交叉上核是"生物钟"。
**情绪与行为**：与边缘系统共同参与情绪反应。<span class="marginnote">下丘脑与垂体的关系是"神经内分泌的咽喉"：下丘脑分泌释放/抑制激素经<strong>垂体门脉系统</strong>到垂体前叶，调节其分泌；下丘脑视上核/室旁核合成的 ADH 与催产素沿<strong>下丘脑-垂体束</strong>运到垂体后叶储存释放。理解这套"门脉+束"的双通道，就理解了尿崩症（ADH 不足）、催产素（分娩哺乳）与垂体瘤的解剖背景——这在生理学《下丘脑-垂体系统》一篇还会细讲。</span>

## 3 后丘脑、上丘脑与底丘脑

**后丘脑（metathalamus）**：包括**内侧膝状体**（听觉中继站——听觉纤维在此换元后投射到颞叶听皮层）与**外侧膝状体**（视觉中继站——视束纤维在此换元后投射到枕叶视皮层）。<span class="marginnote">膝状体是"视听的中继站"：内侧膝状体管听、外侧膝状体管视。视觉通路：视网膜→视神经→视交叉→视束→外侧膝状体→视辐射→枕叶视皮层；听觉通路：耳蜗→蜗神经→蜗神经核→外侧丘系→内侧膝状体→听辐射→颞叶听皮层。两个膝状体是理解视听传导路的"必经关卡"。</span>
**上丘脑（epithalamus）**：含**松果体**（分泌褪黑素，调节昼夜节律）与缰三角。松果体钙化在影像上是颅内的"正常标志物"。
**底丘脑（subthalamus）**：含**底丘脑核**，属锥体外系，参与运动调节（底丘脑核病变→半身舞蹈症）。

## 4 第三脑室

**第三脑室（third ventricle）**是位于两侧丘脑与下丘脑之间的矢状裂隙，前经**室间孔（Monro 孔）**连两侧脑室，后经**中脑导水管**连第四脑室。脑脊液循环：侧脑室→室间孔→第三脑室→中脑导水管→第四脑室→正中孔与外侧孔→蛛网膜下腔。第三脑室受压或阻塞→梗阻性脑积水。<span class="marginnote">脑脊液循环是神经系统"液体动力学"的核心：脑脊液由侧脑室脉络丛产生，经室间孔→第三脑室→中脑导水管→第四脑室→出脑至蛛网膜下腔，最后经蛛网膜颗粒回流入静脉。<strong>任何一环阻塞都会导致脑积水</strong>（中脑导水管狭窄→第三脑室以上扩张；第四脑室出口受阻→全脑室扩张）。腰椎穿刺测的"脑脊液压力"反映颅内压。</span>

## 5 核心对比表：间脑的主要部分

| 分部 | 主要结构 | 功能 |
| --- | --- | --- |
| 背侧丘脑 | 腹后核、内髓板 | 感觉中继（除嗅觉）、意识 |
| 后丘脑 | 内侧/外侧膝状体 | 听觉/视觉中继 |
| 下丘脑 | 视上核、室旁核、摄食中枢 | 神经内分泌、自主神经、体温摄食 |
| 上丘脑 | 松果体 | 褪黑素、昼夜节律 |
| 底丘脑 | 底丘脑核 | 锥体外系运动调节 |

**辨析｜易错点：** "丘脑"与"下丘脑"是两个不同的结构——**丘脑是感觉中继站（与皮层联系），下丘脑是内分泌与自主神经中枢（与垂体、体温、摄食联系）**。二者虽然紧邻，但功能完全不同。另一个易错点：**下丘脑是"自主神经的皮层下中枢"但自身不是内分泌腺**——它分泌的激素经两条路（门脉与垂体束）调控垂体，是"神经—内分泌转换器"。

## 6 数值算例：间脑的定量与临床测量

**丘脑综合征的血供定位**：丘脑主要由**大脑后动脉**的分支供血，其中**丘脑膝状体动脉**闭塞引起丘脑综合征（对侧偏身感觉障碍+丘脑痛）。丘脑旁正中动脉闭塞则引起意识障碍与眼球运动异常。理解"哪条动脉灌哪片丘脑"，就理解了"同是丘脑梗死、症状为何不同"。<span class="marginnote">丘脑是"血管分水岭"的多发地：大脑后动脉、后交通动脉、脉络膜前动脉都参与供血。临床上丘脑出血/梗死的表现随受累核团不同而变——<strong>腹后核受累→感觉障碍，髓板内核受累→意识障碍</strong>。CT/MRI 上的"丘脑梗死"也要细分到具体核团。</span>

**下丘脑激素的两条通路**：

| 通路 | 结构 | 功能 |
| --- | --- | --- |
| 垂体门脉系统 | 下丘脑→门脉→垂体前叶 | 释放/抑制激素调控垂体前叶 |
| 下丘脑-垂体束 | 视上核/室旁核→束→垂体后叶 | 运输 ADH、催产素储存释放 |

**辨析｜易错点：** "垂体后叶分泌 ADH"是常见错误——**ADH 与催产素由下丘脑的视上核与室旁核合成，经下丘脑-垂体束运输到垂体后叶储存释放**，垂体后叶本身不合成，只是储存与释放的场所。同样，**释放激素也不是垂体前叶自己产的**，而是下丘脑经门脉送来的。"下丘脑是神经内分泌转换器"这句话，就浓缩了这两条通路。

**昼夜节律与褪黑素**：视交叉上核（SCN）是"主生物钟"，经交感神经支配松果体分泌褪黑素——夜晚褪黑素升高、白天降低，调节睡眠-觉醒节律。倒时差、熬夜紊乱的正是这条"光→SCN→松果体→褪黑素"的链。老年人松果体钙化增多、褪黑素分泌减少，睡眠变浅。<span class="marginnote">"褪黑素不是安眠药本身，而是'黑夜的信号'——它告诉身体'天黑了该睡了'，通过下调觉醒促进睡眠。白天服用褪黑素效果差、且会扰乱生物钟，这与松果体受光抑制的解剖学特点直接相关。"</span>

## 7 临床联系：间脑病变的表现

**间脑病变的"三看"**：一看感觉（丘脑综合征：对侧感觉障碍）、二看内分泌（下丘脑病变：尿崩症、体温异常、摄食异常）、三看睡眠意识（网状结构/丘脑非特异核受累：嗜睡、昏迷）。这三个维度把间脑的复杂结构归结为临床可查的线索。

**尿崩症（diabetes insipidus）**：下丘脑-垂体束或视上核/室旁核病变致 ADH 分泌不足→大量低比重尿（尿量 >4 L/日）、烦渴多饮。垂体瘤、颅咽管瘤、颅脑外伤是其常见病因。<span class="marginnote">尿崩症与糖尿病（尿糖高）都表现多尿，但机制完全不同：<strong>尿崩症是 ADH 不足→肾浓缩功能下降→稀释尿</strong>；糖尿病是高血糖→渗透性利尿。临床鉴别看尿比重与尿糖——"尿崩症比重低、糖尿病有尿糖"。理解 ADH 的合成运输储存部位，就理解了病变的定位。</span>

**腺垂体功能减退**：下丘脑或垂体柄（门脉）受压→垂体前叶激素分泌不足→继发性甲状腺功能减退、肾上腺皮质功能减退、性腺功能减退（三轴受累）。这与原发性（腺体自身病变）需要鉴别——"垂体柄病变→门脉阻断→前叶激素全降"是理解的关键。

**间脑癫痫与自主神经症状**：下丘脑病变可引起自主神经症状（血压波动、出汗、体温异常）与间脑性癫痫发作。边缘系统与下丘脑联系紧密，情绪反应异常也可源于间脑病变。

## 8 术语速查表

| 术语 | 定义 |
| --- | --- |
| 背侧丘脑（丘脑） | 感觉传导路最后一级换元站，除嗅觉外 |
| 腹后核 | 丘脑外侧核群，分腹后外侧/内侧核，接受躯干四肢/头面部感觉 |
| 丘脑综合征 | 丘脑损伤致对侧感觉障碍与丘脑痛 |
| 下丘脑 | 神经内分泌与自主神经总指挥 |
| 视上核 / 室旁核 | 合成 ADH（抗利尿激素）与催产素的核团 |
| 垂体门脉系统 | 下丘脑到垂体前叶的门脉（运送释放/抑制激素） |
| 下丘脑-垂体束 | 下丘脑到垂体后叶的神经束（运送 ADH、催产素） |
| 内外膝状体 | 听觉/视觉的中继站（后丘脑） |
| 松果体 | 分泌褪黑素，调节昼夜节律（上丘脑） |
| 第三脑室 | 间脑内的腔隙，脑脊液循环必经一环 |

**易错点复习：** 间脑五部用"一句话"串联——"丘脑中转感觉（除嗅觉），后丘脑管视听（内外膝状体），下丘脑管内分泌与自主神经（视上室旁核分泌 ADH 催产素），上丘脑管节律（松果体褪黑素），底丘脑管运动（底丘脑核）"。把这五句话记住，间脑的每个结构都有归属。

## 9 小结

- **间脑**由丘脑、后丘脑、下丘脑、上丘脑、底丘脑组成，中心为第三脑室。
- **丘脑**是全身感觉（除嗅觉）在皮层的"最后一站"；**丘脑综合征**致对侧感觉障碍与丘脑痛。
- **下丘脑**是神经内分泌与自主神经总指挥：视上核/室旁核分泌 ADH 与催产素，释放/抑制激素经垂体门脉管垂体前叶。
- **后丘脑**（内外膝状体）中继视听；**松果体**分泌褪黑素；第三脑室是脑脊液循环的必经一环。

**一句话总结本篇**：间脑是"夹在皮层与脑干之间的承上启下者"——丘脑是所有感觉（除嗅觉）上行的最后一站，下丘脑是神经内分泌与自主神经的总指挥（视上室旁核分泌 ADH 与催产素、门脉管垂体前叶），后丘脑管视听中继，松果体管昼夜节律，第三脑室是脑脊液循环的要道。五个部分、五条功能线，就是间脑的全部。
