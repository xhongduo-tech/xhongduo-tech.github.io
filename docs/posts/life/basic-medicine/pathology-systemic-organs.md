## 为什么从病理学各论开始

病理学总论给的是「通用语法」，病理学各论则是把它套进每个器官的「具体句子」。同一个凝固性坏死，在心脏是心肌梗死、在脑是脑梗死；同一种炎症，在肺是大叶性肺炎、在肝是病毒性肝炎。各论的价值，是把病理变化与临床症状、好发部位、预后一一对应起来——这是临床医学诊断的「形态学证据库」。<span class="marginnote">本篇综合本专题《动脉粥样硬化》《冠心病》《高血压病》《风湿病与心内膜炎》《慢阻肺》《肺炎》《肺硅沉着病与肺肿瘤》《胃炎与溃疡病》《病毒性肝炎与肝硬化》《消化道肿瘤与肝癌》《肾小球肾炎》《肾盂肾炎与肾肿瘤》《神经系统疾病病理》《结核病》等篇。</span>

从「从极限到大模型」的视角看，各论是在为每个器官建立「故障模式库」：好发部位（哪里先坏）、发病机制（为什么坏）、形态特征（怎么识别）、并发症（坏了会怎样）——一套可检索的知识索引。

## 1 心血管系统病理

**动脉粥样硬化（AS）**是心血管疾病的共同基础。好发于**大中动脉**（主动脉、冠状动脉、脑动脉），病变演进：**脂纹**（早期，泡沫细胞）→ **纤维斑块** → **粥样斑块**（脂质核心 + 纤维帽）→ **复合病变**（斑块内出血、溃疡、血栓、钙化）。危险因素：高血脂（LDL 升高）、高血压、吸烟、糖尿病、年龄。<span class="marginnote">「粥样斑块的三层蛋糕」：<strong>纤维帽在外、脂质核心在中间、基底部钙化或出血</strong>。不稳定的「易损斑块」纤维帽薄、脂核大，最容易破裂 → 血栓形成 → 急性事件，这是冠心病急症的病理基础。</span>

**冠心病**：冠状动脉粥样硬化导致心肌缺血。**心绞痛**是可逆性缺血；**心肌梗死**是不可逆坏死——透壁梗死最常见（左前降支受累最多），急性期见凝固性坏死，愈合靠瘢痕（心肌不能再生）。

### 心肌梗死的时间线并发症

心肌梗死的病理与时间强相关，是「时间就是心肌」的病理学基础：

- **4~12 小时**：大体无明显变化，镜下可见心肌纤维嗜酸性变、核浓缩碎裂；此期靠**心肌肌钙蛋白（cTnI/cTnT）升高**早期诊断。
- **12~24 小时**：梗死区明显，出现凝固性坏死、中性粒细胞浸润（急性炎症反应）。
- **3~7 天**：坏死灶软化、肉芽组织开始长入，「灰色梗死」。
- **2~3 周后**：肉芽组织机化，逐渐被**瘢痕**取代（心肌不能再生，只能纤维修复）。

**并发症**：心脏破裂（多见于梗死后 1~2 周，坏死软化期）、室壁瘤（愈合期）、附壁血栓（心内膜粗糙处）→ 栓塞、心源性休克、心律失常、梗死后综合征。把「时间-病理变化」对应表背下来，心肌梗死各期的表现与风险就全通了。<span class="marginnote">「心肌梗死是『按天演变的病变』」：<strong>1 天看坏死、3~7 天看肉芽、2~3 周看瘢痕、1~2 周防破裂</strong>——这条时间线直接决定临床的卧床、监护与抗凝策略。</span>

**高血压病**：原发性高血压的病理主要在**全身细小动脉**——细动脉玻璃样变（透明变性）、小动脉纤维化，管壁增厚管腔变窄。继发改变：**心脏**（向心性肥大→离心性肥大）、**脑**（脑出血，基底节最常见，豆纹动脉好发）、**肾**（原发性颗粒性固缩肾）、视网膜病变。

**风湿病**：A 组乙型溶血性链球菌感染后的**变态反应性**疾病，累及结缔组织，特征病变是**风湿小体（Aschoff 小体）**；心内膜炎（疣状赘生物）、关节炎（游走性，不留畸形）、皮肤环形红斑与皮下结节。

### 心瓣膜病与心肌病速览

| 瓣膜病变 | 血流动力学改变 | 临床表现 |
| --- | --- | --- |
| 二尖瓣狭窄 | 左房→左室受阻，左房压↑、肺淤血 | 舒张期隆隆样杂音、呼吸困难 |
| 二尖瓣关闭不全 | 收缩期血液返流入左房 | 收缩期吹风样杂音、左室肥大 |
| 主动脉瓣狭窄 | 左室射血受阻，左室压力负荷↑ | 收缩期喷射样杂音、晕厥、心绞痛 |
| 主动脉瓣关闭不全 | 舒张期血液返流入左室 | 舒张期叹气样杂音、水冲脉、脉压大 |

**心肌病**分三类：**扩张型心肌病**（心腔扩大、收缩差，最常见的类型）、**肥厚型心肌病**（室壁不对称肥厚，常流出道梗阻，可猝死）、**限制型心肌病**（心室壁僵硬，充盈受限，少见）。<span class="marginnote">「瓣膜病看杂音、心肌病看心腔」：<strong>狭窄听收缩期、关闭不全听舒张期；扩张型心腔大、肥厚型室壁厚、限制型腔不大但充盈差</strong>——三个「型」的正反对比，把心内结构与声学表现连起来。</span>

## 2 呼吸系统病理

**慢性阻塞性肺疾病（COPD）**：以持续气流受限为特征，含**慢性支气管炎**与**肺气肿**。慢支：黏液腺增生、杯状细胞增多、支气管壁炎症。肺气肿：终末细支气管远端气腔异常扩张伴破坏，分小叶中央型（吸烟者最多）与全小叶型（α1-抗胰蛋白酶缺乏）。<span class="marginnote">「慢支 + 肺气肿 = COPD」并常并发肺心病：<strong>缺氧与肺血管重构 → 肺动脉高压 → 右心室肥大衰竭</strong>。这条「肺 → 心」链条是呼吸与循环病理的交汇点，也是慢阻肺死因的主线。</span>

**肺炎**：**大叶性肺炎**（肺炎链球菌，累及整个大叶，分充血水肿期、红色肝变期、灰色肝变期、溶解消散期，纤维素性炎）多见于青壮年；**小叶性肺炎**（细菌性支气管肺炎，化脓性炎，多见于老人与小儿）；**间质性肺炎**（病毒、支原体，以间质炎症为主）。

**肺硅沉着病（矽肺）**：吸入游离二氧化硅粉尘所致，特征为**硅结节**（胶原纤维同心圆排列），晚期肺广泛纤维化，易并发肺结核与肺癌。**肺癌**：中央型（鳞癌、小细胞癌，与吸烟相关）与周围型（腺癌多见）；早期症状隐蔽，多经淋巴道转移。

## 3 消化系统病理

**胃炎与消化性溃疡**：慢性浅表性胃炎（最常见）→ 萎缩性胃炎（伴肠化生、异型增生，是胃癌前状态）。**胃溃疡**典型病变：黏膜缺损深达肌层，圆形或椭圆形，底部由炎性渗出层、坏死层、肉芽组织层、瘢痕层构成。并发症：**出血、穿孔、幽门梗阻、癌变**（胃溃疡癌变率低，十二指肠溃疡不癌变）。<span class="marginnote">「胃溃疡 vs 十二指肠溃疡」一句话：<strong>胃溃疡与胃酸不高有关、易癌变、进食后痛（餐后痛）；十二指肠溃疡胃酸高、不癌变、空腹痛或夜间痛</strong>。溃疡底部的「四层结构」是记忆锚点。</span>

**病毒性肝炎与肝硬化**：肝炎分型（甲、乙、丙等）；病变为肝细胞变性（气球样变、嗜酸性变）、坏死（碎片状、桥接坏死）、炎细胞浸润。**肝硬化**以**假小叶**形成为特征（正常肝小叶被纤维间隔分割的再生结节），门静脉高压（腹水、脾大、食管胃底静脉曲张）与肝功能不全（黄疸、凝血障碍、肝性脑病）是两大症候群。

### 肝硬化门脉高压的侧支循环

门静脉高压时，血液被迫绕道「侧支循环」回流上腔静脉，形成三个关键通路：

- **食管胃底静脉曲张**：胃左静脉 → 食管静脉丛 → 奇静脉 → 上腔静脉——破裂致**上消化道大出血**，是肝硬化致命并发症之一。
- **脐周静脉曲张（海蛇头）**：脐静脉重新开放，脐周腹壁静脉显现。
- **痔静脉曲张**：肠系膜下静脉 → 直肠静脉丛 → 髂内静脉 → 下腔静脉。

同时，**脾功能亢进**（脾大 + 白细胞/血小板减少）与**腹水**（门脉高压 + 低白蛋白 + 淋巴生成增多 + 醛固酮灭活减少）共同构成肝硬化「失代偿」的典型表现。<span class="marginnote">「门脉高压的三条侧支 = 三条出血/淤血路线」：<strong>食管胃底静脉曲张最危险，痔静脉曲张次之，脐周静脉曲张最不致命</strong>。记住「食管→上腔、脐周→胸壁、直肠→下腔」三条迂回路的终点，侧支循环的解剖就全了。</span>

**消化道肿瘤与肝癌**：**食管癌**（鳞癌为主，进行性吞咽困难）、**胃癌**（中老年高发，弥漫浸润呈「革囊胃」者预后差）、**大肠癌**（腺癌为主，右半结肠肿块型、左半结肠浸润型，便血与排便习惯改变）。**原发性肝癌**：与乙肝/丙肝、黄曲霉毒素、肝硬化相关，**肝细胞癌**为主，AFP 升高，肝内播散与血行转移。

## 4 泌尿与神经病理

**肾小球肾炎**：以肾小球损害为主的变态反应性疾病。**急性弥漫性增生性肾小球肾炎**（链球菌感染后，内皮/系膜增生，「大红肾」，红细胞管型，预后好）；**急进性肾炎**（新月体形成，预后差）；**膜性肾病**（基底膜增厚，「大白肾」，肾病综合征）；**微小病变性肾病**（肾病综合征，激素敏感，多见于儿童）。<span class="marginnote">肾小球肾炎的鉴别口诀看「光镜 + 电镜 + 免疫荧光」：<strong>大红肾、细胞增生看急性，新月体看急进性，基底膜钉突、增厚看膜性</strong>——「增生、新月体、基底膜」三词定位最常见的三类。</span>

**肾盂肾炎**：细菌（多为大肠埃希菌）经**上行感染**引起的化脓性炎症，累及肾盂与肾间质；慢性者肾瘢痕形成、肾缩小，与高血压、慢性肾衰相关。

**神经系统病理**：**脑血管病**——脑动脉粥样硬化、高血压是基础；**脑出血**（基底节好发，高血压常见）与**脑梗死**（动脉粥样硬化血栓形成、栓塞）。**颅内肿瘤**：胶质瘤（星形细胞瘤最多见，恶性程度分级）、脑膜瘤（多为良性）。**中枢神经系统感染**：化脓性脑膜炎（脑脊液脓性）、结核性脑膜炎、病毒性脑炎；**脱髓鞘病**（多发性硬化）。<span class="marginnote">「神经系统的特殊性」：神经元不能再生、血脑屏障限制药物进入——<strong>所以脑梗死只能靠抢救「缺血半暗带」，脑肿瘤手术要权衡功能区，神经病变修复能力极差</strong>，这是神经病理「预后差」的结构根源。</span>

### 脑出血与脑梗死的鉴别要点

同是脑血管意外，二者的病理基础、起病与处理截然不同：

| 鉴别点 | 脑出血 | 脑梗死 |
| --- | --- | --- |
| 病理基础 | 高血压致豆纹动脉破裂 | 动脉粥样硬化血栓形成/栓塞 |
| 好发部位 | 基底节（壳核多见） | 大脑中动脉供血区多见 |
| 起病 | 活动/用力时骤起，头痛呕吐 | 静息时起，数小时进展 |
| 影像（CT） | **高密度**（血肿） | **低密度**（缺血软化灶） |
| 处理 | 控制血压、必要时手术减压 | 溶栓/取栓（时间窗内） |

「CT 上高密度是血、低密度是梗」这一条影像直觉，是急诊快速分型的关键——分型错了，治疗方向就反了。<span class="marginnote">「出血禁溶栓、梗死抢时间」——<strong>先看 CT 分型，再看时间窗决定是否溶栓</strong>。把「出血高密度、梗死低密度」与「出血多突发、梗死多渐进」两句话记住，脑血管病急诊的基本功就到手了。</span>

## 5 核心对比：各系统主要病变要点

| 系统 | 代表疾病 | 特征病理变化 | 关键考点 |
| --- | --- | --- | --- |
| 心血管 | 动脉粥样硬化 | 脂纹→纤维斑块→粥样斑块 | 好发大中动脉；易损斑块破裂→血栓 |
| 心血管 | 高血压病 | 细动脉玻璃样变 | 脑出血好发基底节 |
| 呼吸 | COPD | 慢支 + 肺气肿 | 肺气肿分小叶中央型/全小叶型 |
| 呼吸 | 大叶性肺炎 | 纤维素性炎（四期） | 肺炎链球菌、青壮年 |
| 消化 | 胃溃疡 | 黏膜缺损深达肌层（四层底） | 出血、穿孔、癌变 |
| 消化 | 肝硬化 | 假小叶形成 | 门脉高压 + 肝功不全 |
| 泌尿 | 急性肾小球肾炎 | 内皮/系膜增生「大红肾」 | 链球菌感染后 |
| 泌尿 | 肾盂肾炎 | 化脓性、上行感染 | 大肠埃希菌 |
| 神经 | 脑出血 | 基底节出血 | 高血压相关 |

**辨析｜易错点：** ① 冠心病心绞痛（可逆）与心肌梗死（不可逆坏死）之分，在于缺血是否超过心肌耐受；② 大叶性肺炎是纤维素性炎、小叶性肺炎是化脓性炎——「大纤维、小化脓」；③ 十二指肠溃疡不癌变、胃溃疡可癌变——溃疡病与癌的关系因部位而异；④ 脑出血与脑梗死的鉴别在影像（CT 出血高密度、梗死低密度）与起病方式。

## 6 小结

- **心血管**：AS 是总根源（脂纹→斑块→血栓）；高血压累及细动脉；风湿病特征是 Aschoff 小体。
- **呼吸**：COPD = 慢支 + 肺气肿，可并发肺心病；大叶性肺炎纤维素性、小叶性肺炎化脓性；矽肺特征为硅结节。
- **消化**：胃溃疡四层底与四大并发症；肝硬化核心是假小叶；胃癌/肝癌与慢性肝病、乙肝相关。
- **泌尿**：肾小球肾炎看增生/新月体/基底膜；肾盂肾炎是上行化脓性感染。
- **神经**：脑出血好发基底节；胶质瘤与脑膜瘤是颅内常见肿瘤；神经元不可再生是预后差根源。
- 各论描述的是「已发生的病变」，而疾病从发生到临床之间还有功能性的动态过程——下一课进入**病理生理学**：水电解质紊乱、休克、缺氧与 DIC 这些功能与代谢的动态失衡。

在下一节，我们将回答：体液的量、成分与酸碱怎么失衡，休克时微循环如何一步步崩溃，DIC 如何让凝血系统失控——这就是**病理生理学**。
