## 为什么从前庭蜗器开始

**前庭蜗器（vestibulocochlear organ）**即耳，是听觉与前庭（平衡）的感觉器官。它分为三部分：**外耳**（收集声波）、**中耳**（传声、增压）与**内耳**（感受声音与平衡）。<span class="marginnote">"前庭蜗器"这个名字本身就在提醒：它包含两个功能模块——<strong>前庭</strong>（vestibule，司平衡）与<strong>蜗</strong>（cochlea，司听觉）。解剖上两者都藏在颞骨岩部内的"骨迷路"中。</span>

"中耳炎为什么容易在小儿发生""耳石症为什么一转头就晕""听力下降要分清传导性与感音神经性"——前庭蜗器的解剖回答这些临床问题。

## 1 外耳与中耳

**外耳（external ear）**包括**耳廓**（以弹性软骨为支架，收集声波）与**外耳道**（长约 2.5 cm，外 1/3 为软骨部、内 2/3 为骨部，外耳道皮肤含耵聍腺分泌耵聍）。外耳道内端有**鼓膜**。

**鼓膜（tympanic membrane）**是椭圆形半透明薄膜，介于外耳道与中耳之间，把声波振动传给中耳。鼓膜分紧张部与松弛部，中央略凹为**鼓膜脐**（锤骨柄末端附着处）。<span class="marginnote">鼓膜是"声波→机械振动"的换能器。正常鼓膜呈珠光灰色，中耳炎时充血发红、穿孔时可见穿孔。鼓膜非常薄（约 0.1 mm），掏耳、爆震或中耳炎脓液可致穿孔。鼓膜中央的锤骨柄附着点（鼓膜脐）是检查时的定位标志。</span>

**中耳（middle ear）**包括**鼓室、咽鼓管、乳突窦与乳突小房**：

**鼓室（tympanic cavity）**：颞骨岩部内的含气小腔，内有**三块听小骨**——**锤骨、砧骨、镫骨**，它们构成"听骨链"，把鼓膜的振动放大后传至内耳（卵圆窗）。<span class="marginnote">听骨链是人体最小的一组骨。声波振动鼓膜→锤骨→砧骨→镫骨→卵圆窗（内耳入口）。听骨链有"杠杆+面积"双重增压作用，把鼓膜的声压放大约 22 倍传入内耳——内耳液体声阻抗高，需要这个"阻抗匹配"。鼓室还有鼓膜张肌与镫骨肌两块小肌（保护内耳免受巨大声响损伤）。</span>
**咽鼓管（pharyngotympanic tube）**：连通鼓室与鼻咽，调节鼓室气压。**小儿咽鼓管短、宽、平直**，故上呼吸道感染易经咽鼓管上行引发**中耳炎**。<span class="marginnote">咽鼓管是"鼓室的通风管"：吞咽、打哈欠时咽鼓管开放，使鼓室内压与外界平衡（坐飞机耳闷就是咽鼓管调节不及时）。小儿咽鼓管短而平直，鼻咽部细菌易逆行入鼓室→急性中耳炎。成人咽鼓管长而倾斜，相对不易感染。鼻出血时捏鼻止血可能使血液经咽鼓管入鼓室。</span>
**乳突窦与乳突小房**：鼓室后方的含气腔，与鼓室相通——中耳炎可蔓延为乳突炎。

## 2 内耳：骨迷路与膜迷路

**内耳（internal ear）**位于颞骨岩部内，由**骨迷路**（骨质管道）与套在其中的**膜迷路**（膜性囊管）构成，膜迷路内充满**内淋巴**，骨迷路与膜迷路之间充满**外淋巴**。

**骨迷路**分三部：

**前庭（vestibule）**：中央，含**椭圆囊**与**球囊**（膜迷路）。
**骨半规管（bony semicircular canals）**：前、后、外三个半规管，互相垂直，内含**膜半规管**，其膨大部为**壶腹**，壶腹内有**壶腹嵴**（感受旋转运动）。
**耳蜗（cochlea）**：形似蜗牛壳，骨性蜗螺旋管绕**蜗轴**盘旋约 2.5 圈。蜗管内（膜迷路）有**螺旋器（Corti 器）**——听觉感受器，位于**基底膜**上。<span class="marginnote">内耳的"双淋巴"系统：内淋巴（膜迷路内）与外淋巴（膜迷路与骨迷路之间）。听觉传导路径：声波→外耳道→鼓膜→听骨链→卵圆窗→外淋巴振动→基底膜振动→螺旋器（毛细胞）受刺激→听神经。前庭觉传导：旋转→半规管壶腹嵴毛细胞受刺激；直线加速→椭圆囊/球囊的位觉斑（耳石膜）受刺激。</span>

## 3 听觉的传导与听力障碍分型

**空气传导（主要通路）**：声波→外耳道→鼓膜→听骨链→卵圆窗→内耳淋巴→螺旋器→听神经。

**骨传导（次要通路）**：声波→颅骨振动→内耳淋巴，不经鼓膜与听骨链（音叉放于乳突可检测）。

**听力障碍分两类**（临床诊断的核心框架）：

**传导性聋**：外耳或中耳病变（外耳道堵塞、鼓膜穿孔、听骨链中断、中耳炎）——病变在卵圆窗**以前**，骨传导正常、气传导下降。
**感音神经性聋**：内耳、听神经或中枢病变（噪音损伤、药物性耳聋、老年性聋、梅尼埃病）——病变在卵圆窗**以后**，气导与骨导都下降。<span class="marginnote">"传导性聋气导下降骨导正常，感音神经性聋气骨导都下降"是音叉试验（Rinne 试验、Weber 试验）的判读基础。临床鉴别要点：传导性聋病变在外中耳（可手术矫正，如鼓膜修补、听骨链重建），感音神经性聋病变在内耳/听神经（多不可逆，如噪声性耳聋——毛细胞不可再生）。</span>

**前庭的功能**：内耳的前庭（椭圆囊、球囊）感受**直线加速度**与重力，半规管（三个）感受**角加速度（旋转）**。前庭系统与眼、颈、四肢的协调共同维持平衡——前庭受刺激（如晕车）时出现眩晕、眼震、恶心。

**辨析｜易错点：** 初学者常把"中耳"与"内耳"混为一谈。**中耳是含气的鼓室（含听小骨），内耳是颞骨岩部内的骨迷路与膜迷路（含听觉与前庭感受器）**。中耳炎（常见、可治）≠内耳炎（少见、常致感音神经性聋）。另一个易错点：**耳蜗管听觉，前庭与半规管管平衡**——"前庭蜗神经（Ⅷ）"由蜗神经（听觉）与前庭神经（平衡）两支组成。

## 4 核心对比表：声波的传导与障碍分型

| 环节 | 结构 | 损伤后果 |
| --- | --- | --- |
| 集音 | 耳廓、外耳道 | 外耳道堵塞→传导性聋 |
| 传音 | 鼓膜、听骨链 | 穿孔、中断→传导性聋 |
| 入内耳 | 卵圆窗 | 镫骨固定（耳硬化）→传导性聋 |
| 感音 | 螺旋器（毛细胞） | 噪音损伤→感音神经性聋 |
| 传中枢 | 蜗神经→脑干→听皮层 | 听神经瘤→感音神经性聋 |

## 5 数值算例：听力的量级与测试判读

**听力阈值与声压**：人耳能听到的最轻声音（听阈）约 0 dB（对应声压约 20 μPa），日常谈话约 60 dB，**超过 85 dB 长期暴露可损伤听力**、120 dB 以上引起疼痛（痛阈）。**噪声性聋**：毛细胞不可再生，长期高分贝暴露（工厂、耳机大音量）→进行性听力下降。<span class="marginnote">"耳机音量 60/60 原则"：音量不超过最大音量的 60%、连续使用不超过 60 分钟——因为内耳毛细胞损伤不可逆。职业性噪声聋是我国常见的职业病之一。理解"毛细胞不可再生"这一结构事实，就理解了噪声防护的重要性。</span>

**音叉试验的判读**：

| 试验 | 方法 | 传导性聋 | 感音神经性聋 |
| --- | --- | --- | --- |
| Rinne 试验 | 气导 vs 骨导 | 气导<骨导（阴性） | 气导>骨导但两者都缩短 |
| Weber 试验 | 骨导偏向 | 偏向患侧 | 偏向健侧 |

**辨析｜易错点：** 音叉试验是耳科的基本功。**Rinne 试验**：正常人气导>骨导（阳性）；传导性聋时骨导>气导（阴性）。**Weber 试验**：音叉置于颅顶正中，传导性聋偏向患侧（患侧骨导好）、感音神经性聋偏向健侧（患侧感受差）。"Rinne 看气骨导对比、Weber 看偏向哪侧"是判读口诀。

**前庭的数值**：三个半规管互相垂直（前、后、外），分别感受不同平面的旋转。**前庭系统与视觉、本体感觉共同维持平衡**——前庭受损时出现眩晕、眼震、平衡障碍。**耳石症（良性阵发性位置性眩晕，BPPV）**：耳石（碳酸钙结晶）脱落到半规管→头位改变时刺激壶腹嵴→旋转性眩晕（<1 分钟）——手法复位（Epley 法）有效。

## 6 临床联系：常见耳病

**中耳炎**：急性中耳炎多为上呼吸道感染经咽鼓管上行（小儿多见）——耳痛、发热、听力下降、鼓膜充血。**分泌性中耳炎**（中耳积液，鼓室负压）：耳闷、听力下降，可见鼓膜内陷、液平面。慢性化脓性中耳炎可致鼓膜穿孔、听骨链破坏→传导性聋。<span class="marginnote">"小儿为什么易得中耳炎"的解剖学答案：<strong>咽鼓管短、宽、平直</strong>，鼻咽部病原易经此逆行入鼓室。成年人咽鼓管长而倾斜，有"自洁"作用。分泌性中耳炎治疗重点是恢复咽鼓管通畅（鼓室负压的根源）。化脓性中耳炎处理不当可继发<strong>乳突炎</strong>、甚至<strong>颅内并发症</strong>（脑膜炎、脑脓肿）——中耳与颅腔相邻。</span>

**耳聋的病因鉴别**：传导性聋（外中耳病变：耵聍栓塞、鼓膜穿孔、中耳炎、听骨链中断、耳硬化）多可治疗；感音神经性聋（内耳/听神经：噪声、药物性、老年性、梅尼埃病、听神经瘤）多不可逆。<span class="marginnote">"突发性耳聋"（突聋）是耳科急症：72 小时内突发感音神经性聋，需尽早激素等治疗，"越早治疗恢复越好"。<strong>药物性耳聋</strong>（氨基糖苷类抗生素、顺铂、袢利尿剂）损伤内耳毛细胞——用药需警惕。老年性聋（Presbycusis）以高频听力下降为主。人工耳蜗植入的原理是"替代内耳毛细胞"——直接电刺激听神经。</span>

**眩晕的鉴别**：**耳石症（BPPV）**——头位变化时短暂眩晕（秒级），Epley 复位有效；**梅尼埃病**——发作性眩晕+耳鸣+波动性听力下降（内淋巴积水）；**前庭神经炎**——急性严重眩晕（无耳鸣听力下降）；**中枢性眩晕**（脑干小脑病变）——常伴神经体征（复视、共济失调、构音障碍）。<span class="marginnote">"眩晕定位在周围还是中枢"是神经科/耳科的鉴别要点：<strong>周围性眩晕</strong>（内耳/前庭神经）——剧烈旋转性眩晕、眼震水平或旋转性、可伴耳鸣听力下降；<strong>中枢性眩晕</strong>（脑干小脑）——眩晕较轻但伴神经功能缺损（复视、吞咽困难、共济失调）。突然出现的眩晕+神经体征要警惕脑干卒中（"时间就是大脑"）。</span>

**听神经瘤**：前庭神经鞘瘤（听神经瘤）生长于内耳门→耳鸣、单侧听力下降、眩晕——压迫面神经可致面瘫、压迫脑干可致共济失调。MRI 可早期发现。<span class="marginnote">听神经瘤是"单侧进行性听力下降+耳鸣"的常见原因——<strong>成人单侧听力下降需排查听神经瘤</strong>（MRI 增强是金标准）。手术或放疗可处理。理解"前庭蜗神经走行于内耳门、与面神经相邻"，就理解了听神经瘤为什么同时影响听觉、平衡与面肌。</span>

## 7 术语速查表

| 术语 | 定义 |
| --- | --- |
| 耳廓 / 外耳道 | 收集声波 / 传导声波 |
| 鼓膜 | 外中耳之间薄膜，声波换能 |
| 听骨链 | 锤、砧、镫骨，传声并增压约 22 倍 |
| 咽鼓管 | 鼓室通鼻咽，调节气压（小儿短平直易中耳炎） |
| 乳突窦 / 乳突小房 | 鼓室后含气腔，中耳炎可蔓延 |
| 骨迷路 / 膜迷路 | 骨质管道 / 膜性囊管，外淋巴 / 内淋巴 |
| 耳蜗 | 蜗螺旋管约 2.5 圈，含螺旋器（Corti 器） |
| 螺旋器 | 听觉感受器，位于基底膜上 |
| 前庭 / 半规管 | 椭圆囊球囊（直线加速）/ 壶腹嵴（旋转） |
| 传导性聋 | 病变在外中耳，气导↓骨导正常 |
| 感音神经性聋 | 病变在内耳及以后，气骨导都↓ |
| 耳石症（BPPV） | 耳石脱落入半规管，头位性眩晕 |

**易错点复习：** 前庭蜗器的三组对比——"外耳集音、中耳传音（听骨链+咽鼓管）、内耳感音（耳蜗听觉、前庭半规管平衡）"、"传导性聋（外中耳、气导↓骨导正常、可治）vs 感音神经性聋（内耳后、气骨导都↓、多不可逆）"、"周围性眩晕（剧烈、伴耳鸣）vs 中枢性眩晕（轻、伴神经体征）"。把这三组记住，听觉与前庭的"结构-障碍-鉴别"就完整了。

## 8 小结

- **外耳**（耳廓、外耳道）集音；**鼓膜**把声波转为振动。
- **中耳**（鼓室）含**听骨链**（锤、砧、镫）传声并增压，**咽鼓管**连通鼻咽调节气压（小儿短平直→易中耳炎）。
- **内耳**含**骨迷路与膜迷路**：**耳蜗**（Corti 器司听觉）、**前庭与半规管**（位觉斑与壶腹嵴司平衡）。
- 听觉主要经**空气传导**（鼓膜→听骨链→卵圆窗）；病变在外中耳为**传导性聋**、在内耳及以后为**感音神经性聋**。

**一句话总结本篇**：耳是"听觉+前庭"的双功能器官——外耳集音、中耳传音（听骨链增压+咽鼓管调压）、内耳感音（耳蜗听觉、前庭半规管平衡）。把"传导性聋看外中耳（可治）、感音神经性聋看内耳后（多不可逆）"这一框架记住，耳科与神经科的听力/眩晕问题就有了结构坐标。

**自测三问**：①听骨链为什么能把声压放大？②小儿为什么易得中耳炎？③Rinne 与 Weber 试验如何鉴别传导性聋与感音神经性聋？——能答出这三点，前庭蜗器就掌握了。
