## 为什么从病理学总论开始

前面几课都在讲「正常人体如何工作」。但疾病才是医学真正要面对的对象——**病理学（pathology）**就是研究「正常如何走向异常」的学科，它是连接基础医学与临床医学的桥梁。病理学总论回答共性规律：细胞如何适应与损伤、炎症如何发生与演化、损伤如何修复、肿瘤的基本规律是什么。<span class="marginnote">本篇综合本专题《细胞适应》《可逆性细胞损伤与坏死》《凋亡与细胞死亡》《再生与修复》《纤维性修复与瘢痕》《炎症基本病理变化》《炎症类型》《炎症表现》《肿瘤形态与分化》《肿瘤生长与扩散》《良恶性肿瘤区别》诸篇。</span>

从「从极限到大模型」的视角看，病理学总论是在学习「异常检测系统」的分类法：什么算适应（正常边界内的调整）、什么算损伤（越界）、炎症（报警与反击）、修复（恢复与瘢痕）、肿瘤（失控的异常增殖）——每种状态都有明确的形态学标志。

## 1 细胞适应与可逆性损伤

细胞面对刺激，先尝试**适应（adaptation）**，代价最小：

- **萎缩（atrophy）**：已发育正常的细胞体积缩小、数量减少（如废用性肌萎缩）。
- **肥大（hypertrophy）**：细胞体积增大（如心肌肥大）；**增生（hyperplasia）**：细胞数量增多（如乳腺增生）。两者常同时发生。
- **化生（metaplasia）**：一种分化成熟的细胞转变为另一种成熟细胞（如吸烟者支气管假复层纤毛柱状上皮化生为鳞状上皮）。<span class="marginnote">「化生是防御性的、却可能成为肿瘤的温床」——<strong>鳞状化生常是保护性的，但反复刺激下的化生上皮可能异型增生进而癌变</strong>。记住化生的方向：多发生在「同源」的上皮之间，鳞状化生最多见。</span>

刺激超过适应能力，就进入**可逆性细胞损伤（变性）**：细胞水肿（水变性）、脂肪变性（脂肪肝）、玻璃样变、黏液样变——损伤尚可恢复。**脂肪变性**在肝最常见（酒精、营养障碍、中毒），心肌脂肪变性可致「虎斑心」。

## 2 不可逆损伤与细胞死亡

损伤加重则细胞死亡，分两类：

**坏死（necrosis）**是细胞被动、无序的死亡，伴随炎症反应。按形态分四型：**凝固性坏死**（蛋白变性凝固，最常见，如脾、肾梗死）、**液化性坏死**（组织溶解液化，如脑梗死、脓肿）、**纤维素样坏死**（结缔组织，见于风湿病、高血压）、**干酪样坏死**（结核病的特征，凝固与液化兼有）。特殊形式：**坏疽**（大块组织坏死伴腐败菌感染，分干性/湿性/气性）、**梗死**（血供中断所致）。

**凋亡（apoptosis）**是细胞主动、程序化的死亡，由基因调控，不引起炎症（细胞皱缩、核碎裂、形成凋亡小体），生理与病理均可见（如胚胎发育、病毒性肝炎的嗜酸性小体）。<span class="marginnote">「坏死 vs 凋亡」一句话分家：<strong>坏死是被动、破裂、发炎；凋亡是主动、皱缩、不发炎</strong>。临床上化疗药诱导肿瘤细胞凋亡、缺血致坏死——「主动的体面退场 vs 被动的狼狈解体」。</span>

## 3 炎症：组织的「警报与反击」

**炎症（inflammation）**是机体对损伤因子的防御反应，核心是**变质、渗出、增生**三大基本病变：

- **变质**：局部组织细胞的变性坏死。
- **渗出**：血管反应——血流动力学改变（先短暂收缩后扩张）→ **血管通透性增高**（血浆蛋白与液体渗出）→ **白细胞渗出**（边集、附壁、游出、趋化、吞噬）。这是炎症的核心与特征。
- **增生**：巨噬细胞、成纤维细胞、血管内皮细胞增殖，参与修复。

**炎症介质**是「传令兵」：组胺、前列腺素、白三烯、缓激肽、补体片段（C3a、C5a）、细胞因子（IL-1、TNF）等，负责血管扩张、通透性增高与趋化。<span class="marginnote">「红、肿、热、痛、功能障碍」五大局部表现，全是渗出的结果：<strong>红热 = 血管扩张充血，肿 = 渗出液积聚，痛 = 炎症介质刺激，功能障碍 = 结构与渗出共同所致</strong>。全身表现则有发热、白细胞增多。</span>

**炎症的类型**按渗出物与病变性质分：**浆液性**（渗出液稀薄）、**纤维素性**（纤维蛋白渗出，如大叶性肺炎、白喉）、**化脓性**（中性粒细胞大量渗出，分表面化脓/积脓、蜂窝织炎、脓肿）、**出血性**。按病程分急性与慢性（慢性以增生为主，可见肉芽肿性炎，如结核、梅毒）。**结局**：痊愈（完全恢复/纤维化瘢痕）、迁延为慢性、蔓延扩散（局部/淋巴/血行）。

### 炎症类型速览

| 类型 | 渗出物特点 | 代表疾病 | 记忆点 |
| --- | --- | --- | --- |
| 浆液性炎 | 稀薄浆液（低蛋白） | 烧伤水疱、浆膜腔积液 | 「水多、蛋白少」 |
| 纤维素性炎 | 纤维蛋白渗出 | 大叶性肺炎、白喉、细菌性痢疾 | 「膜状物」 |
| 化脓性炎 | 中性粒细胞 + 脓液 | 蜂窝织炎、脓肿、表面化脓 | 「脓」字当头 |
| 出血性炎 | 渗出物含大量红细胞 | 鼠疫、流行性出血热 | 「红」字当头 |

「炎症类型的判断先看渗出物」——浆液看稀薄、纤维素看膜状、化脓看脓液、出血看红染；每种类型都有代表性疾病，把「类型 ↔ 渗出物 ↔ 代表病」连成一线，炎症的形态学诊断就有了抓手。

### 炎症的全身反应与临床表现

炎症不只是局部的事，还有一套**全身反应（急性期反应）**：

- **发热**：内源性致热原（IL-1、TNF、IL-6）作用于下丘脑体温调节中枢，把调定点上移——适度发热有利于免疫（白细胞趋化与吞噬增强），过高则有害。
- **白细胞增多**：外周血白细胞升高，急性细菌感染以**中性粒细胞**增多为主、寄生虫与过敏以**嗜酸性粒细胞**增多为主、病毒感染常伴**淋巴细胞**增多——「看白细胞分类猜病原」是感染诊断的经典思路。
- **急性期蛋白**：肝脏合成 C 反应蛋白（CRP）、血清淀粉样蛋白 A 等升高，其中 CRP 是临床应用最广的炎症标志物。

**临床意义**：局部红、肿、热、痛与功能障碍（五大表现）提示炎症部位，全身反应提示炎症强度与范围——「局部定位 + 全身定性」是炎症评估的基本框架。<span class="marginnote">「发热 + 白细胞升高 + CRP 升高」是急性炎症的「全身三联」：<strong>三者都指向「有炎症、且比较活跃」</strong>，而「看白细胞分类」能进一步提示病原类别——这套思路贯穿感染性疾病的诊断全程。</span>

## 4 修复与肿瘤概论

**修复（repair）**：损伤后机体重建结构与功能，分**再生**（同种细胞修复，如表皮、肝细胞可完全再生）与**纤维性修复**（肉芽组织 → 瘢痕）。**肉芽组织**是新生的成纤维细胞 + 毛细血管 + 炎症细胞，是修复的「脚手架」；瘢痕由胶原构成，缺乏原组织的功能。再生能力分级：表皮、黏膜、肝、造血细胞强；心肌、神经元几乎不能再生。<span class="marginnote">「再生能力强弱」是修复的底层逻辑：<strong>不稳定细胞（表皮、黏膜、造血细胞）再生强，稳定细胞（肝、肾小管）再生中等，永久性细胞（神经元、心肌）再生极弱</strong>——心肌梗死之所以靠瘢痕愈合，就是心肌「不会再生」。</span>

**肿瘤（tumor）概论**：肿瘤是机体细胞异常增生形成的新生物。判断良恶性的核心在**分化**与**异型性**：良性瘤分化好、异型性小、膨胀性生长、有包膜、不转移；恶性瘤（癌/肉瘤）分化差、异型性大、浸润性生长、可转移。**命名**：上皮来源恶性 → 癌（carcinoma），间叶来源恶性 → 肉瘤（sarcoma），良性瘤一般加「瘤」字。

**肿瘤的生长与扩散**：生长方式（膨胀/浸润/外生）；**扩散途径**：直接蔓延、淋巴道转移（癌多见）、血道转移（肉瘤多见，常到肝肺）、种植性转移（体腔）。**分级（G）**反映分化程度，**分期（TNM）**反映解剖范围——两者是预后与治疗决策的量化基础。肿瘤的发生涉及**原癌基因**激活与**抑癌基因**失活（如 p53），是多步骤、多基因突变累积的结果。

### 常见肿瘤标志物与致癌因素

肿瘤是「多基因突变累积」的结果，因此有明确的**致癌因素**与可追踪的**标志物**：

- **物理致癌**：紫外线（皮肤基底细胞癌/黑色素瘤）、电离辐射（白血病、甲状腺癌）。
- **化学致癌**：吸烟（肺癌、膀胱癌等）、黄曲霉毒素（肝癌）、亚硝胺（胃癌、食管癌）、苯（白血病）。
- **生物致癌**：病毒（HPV→宫颈癌、HBV/HCV→肝癌、EBV→鼻咽癌/淋巴瘤）、细菌（幽门螺杆菌→胃癌）、寄生虫（华支睾吸虫→胆管癌）。
- **遗传与免疫因素**：BRCA 基因突变（乳腺癌/卵巢癌）、免疫缺陷（卡波西肉瘤等）。

**肿瘤标志物**是辅助诊断与随访的「生物指纹」：**AFP**（肝癌）、**CEA**（结直肠癌等）、**PSA**（前列腺癌）、**CA125**（卵巢癌）、**CA19-9**（胰腺癌）。标志物升高不等于确诊（良性病也可升高），但要警惕并进一步检查——它们更多用于**筛查提示、疗效监测与复发预警**。<span class="marginnote">「肿瘤标志物是『嫌疑线索』而非『判决书』」：<strong>AFP 升高 → 高度怀疑肝癌但需影像证实；术后 AFP 下降再回升 → 提示复发</strong>。把标志物当成「动态监测的仪表」，比当成「一锤定音的化验」更正确。</span>

## 5 核心对比：良恶性肿瘤与坏死类型

| 对比项 | 良性肿瘤 | 恶性肿瘤 |
| --- | --- | --- |
| 分化/异型性 | 分化好、异型性小 | 分化差、异型性大 |
| 生长方式 | 膨胀性（有包膜） | 浸润性（无包膜） |
| 生长速度 | 慢 | 快（可出血坏死） |
| 转移 | 不转移 | 可转移（淋巴/血道/种植） |
| 对机体影响 | 局部压迫为主 | 破坏组织、恶病质、致死 |
| 复发 | 少 | 常复发 |

| 坏死类型 | 形态特点 | 常见部位 |
| --- | --- | --- |
| 凝固性坏死 | 组织灰白干燥、结构尚存 | 心、脾、肾梗死 |
| 液化性坏死 | 组织溶解液化 | 脑、脓肿 |
| 干酪样坏死 | 灰黄细腻似干酪 | 结核 |
| 纤维素样坏死 | 结缔组织崩解 | 风湿病、恶性高血压 |

**辨析｜易错点：** ① 「肿瘤」≠「癌症」——肿瘤包括良性与恶性，癌只是恶性上皮源性肿瘤，肉瘤是恶性间叶源性肿瘤；② 判断良恶性不能只看生长快慢，**异型性与转移**才是金标准；③ 炎症渗出与漏出不同——渗出含蛋白与白细胞（通透性增高所致），漏出是单纯静水压失衡的低蛋白液体。

## 6 小结

- **适应**：萎缩、肥大、增生、化生；超过适应能力即损伤。
- **损伤**：可逆（变性：水肿、脂肪变）→ 不可逆（坏死四型：凝固/液化/干酪样/纤维素样；凋亡主动不伴炎症）。
- **炎症**：变质、渗出、增生三大病变；渗出是核心；介质驱动红肿热痛；分浆液/纤维素/化脓/出血性。
- **修复**：再生（不稳定细胞强、永久性细胞弱）与瘢痕（肉芽组织 → 纤维化）。
- **肿瘤**：良恶性看分化与异型性；恶性可浸润转移（癌走淋巴、肉瘤走血）；TNM 分期与分级是决策基础；多基因突变累积是发病本质。
- 病理总论给了「共性规律」，下一课进入**病理学各论**：把这些规律应用到心血管、呼吸、消化、泌尿、神经各大系统的具体疾病。

在下一节，我们将回答：动脉粥样硬化、慢阻肺、肝硬化、肾小球肾炎、脑血管病各自的核心病理变化是什么——这就是**病理学各论**。
