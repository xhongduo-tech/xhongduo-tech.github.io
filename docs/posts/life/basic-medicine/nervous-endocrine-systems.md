## 为什么从神经与内分泌系统开始

人体各器官能协同工作，靠的是两大调节系统：**神经系统**快而精确，**内分泌系统**慢而持久。它们的关系不是并列而是交织——下丘脑既是神经结构又是内分泌中枢，把「神经-体液调节」变成一张网。<span class="marginnote">本篇综合本专题《突触传递》《反射活动与中枢整合》《自主神经功能》《下丘脑-垂体系统》《甲状腺肾上腺胰岛》《钙磷代谢调节》等篇，回答「人体如何被指挥」。</span>

从「从极限到大模型」的视角看，神经系统是「硬接线」的实时控制系统，内分泌系统是「广播式」的全局状态调节——前者像 GPU 上的并行管线，后者像模型里的全局学习率与正则项。

## 1 神经元与神经信号：电与化学的双重语言

**神经元（neuron）**是神经系统的基本单位，由胞体、树突（接收）与轴突（传出）构成。信号传递分两步：轴突内是**电信号**（动作电位，见《细胞基本功能》），神经元之间则是**化学信号**（突触传递）。

**突触（synapse）**：神经元之间或神经元与效应器之间的连接处。经典化学突触的工作流程：动作电位到达突触前末梢 → 电压门控 $\ce{Ca^{2+}}$ 通道开放 → 突触小泡与前膜融合、释放**神经递质** → 递质跨突触间隙与后膜受体结合 → 产生兴奋性（EPSP）或抑制性（IPSP）突触后电位 → 突触后神经元整合后决定是否产生动作电位。<span class="marginnote">「EPSP 是去极化、IPSP 是超极化；EPSP 是局部电位、可叠加，动作电位是全或无」——<strong>整合（空间与时间总和）就是把无数个小的局部电位相加，决定阈值是否被跨过</strong>，这是神经网络「加权求和」的生物学原型。</span>

主要递质：乙酰胆碱（骨骼肌神经肌接头、自主神经节）、去甲肾上腺素、多巴胺、5-羟色胺、γ-氨基丁酸（GABA，抑制性）、谷氨酸（兴奋性）。递质与受体的化学正是药理学「传出神经药理」的基础——很多药物就是递质或受体的激动剂/阻断剂。

### 突触可塑性与学习记忆

突触不是固定的「接线点」，其传递效率会随使用而改变——这就是**突触可塑性**，也是学习记忆的神经基础：

- **长时程增强（LTP）**：高频刺激后突触传递效率长期增强，最经典的机制是海马 NMDA 受体依赖的 $\ce{Ca^{2+}}$ 内流——「用进废退」的分子体现，被视为「记忆的模型」。
- **长时程抑制（LTD）**：低频刺激使传递效率长期减弱，参与记忆清除与精细调节。
- **习惯化与敏感化**：简单学习形式，与递质释放量的增减有关。

可塑性的意义：记忆不是「存进某个盒子」，而是**改变神经元之间连接的权重**——这与人工神经网络「调整权重即学习」的思想惊人一致，也解释了为什么「重复练习」能强化记忆。<span class="marginnote">「LTP/LTD 是神经网络的权重更新」——<strong>Hebb 定律「一起放电的神经元连在一起」（fire together, wire together）就是最早的关联学习规则</strong>。从突触可塑性到深度学习，是「从极限到大模型」这条主线上最动人的类比之一。</span>

## 2 中枢整合与反射：从感觉到运动

神经系统的功能以**反射**为基本方式：感受器 → 传入神经 → 中枢 → 传出神经 → 效应器。

- **感觉传导**：感觉信号沿特异与非特异投射系统上行，丘脑是「中继站」，最终到大脑皮层产生感觉（定位、定性）。
- **运动控制**：皮层运动区发出指令，经锥体系与锥体外系下传，小脑负责协调、基底节负责运动的发起与程序化，脊髓是最后公路。<span class="marginnote">「上运动神经元损伤（痉挛性瘫痪、腱反射亢进）与下运动神经元损伤（弛缓性瘫痪、腱反射消失）」的鉴别，是神经病学最重要的基本功之一——<strong>上下之别看「肌张力与腱反射」，不看肌肉本身</strong>。</span>
- **自主神经**：交感（应对应激：心率增快、瞳孔扩大、支气管扩张、血压升高）与副交感（休养生息：心率减慢、消化增强）相互拮抗又协调，多数内脏受双重支配。

### 脑的高级功能速览

皮层之上的功能整合，是神经科学的「金字塔尖」：

- **语言**：经典模型是 Broca 区（运动性语言中枢，损伤致运动性失语——能听懂说不清）与 Wernicke 区（感觉性语言中枢，损伤致感觉性失语——能说但听不懂）；注意语言中枢多在优势半球（多数人左侧）。
- **学习记忆**：记忆按存储时间分瞬时、短时与长时记忆；**海马**是把短时记忆转化为长时记忆的「转换器」，海马损伤（如阿尔茨海默病早期）表现为近事遗忘。
- **睡眠与觉醒**：脑干网状结构维持觉醒；睡眠分非快动眼（NREM，深睡期分泌生长激素）与快动眼（REM，做梦）交替循环。
- **情绪与奖赏**：**多巴胺系统**与奖赏、动机相关——帕金森病是黑质多巴胺能神经元变性（运动症状），精神分裂症的多巴胺假说则涉及幻觉妄想，两个「多巴胺疾病」一正一反。

把高级功能与「哪个脑区坏了会怎样」对应起来，神经病学就从抽象变具体了。<span class="marginnote">「脑的定位思想」是神经病学的方法论：<strong>按「症状 → 定位 → 病因」三步走</strong>——失语定位皮层、遗忘定位海马、震颤定位基底节。这与「从极限到大模型」里「从行为反推结构」的逆向工程思路同构。</span>

## 3 内分泌系统总览：激素的「广播」

**激素（hormone）**：内分泌腺与散在内分泌细胞分泌、经血液运输、作用于远处靶细胞的高效生物活性物质。内分泌系统的基本单位是「**下丘脑-垂体-靶腺轴**」。

**下丘脑**分泌释放激素/释放抑制激素 → 调节**垂体**；垂体前叶分泌促激素（TSH、ACTH、FSH、LH、GH、PRL）→ 调节靶腺（甲状腺、肾上腺皮质、性腺）；靶腺激素再**负反馈**抑制下丘脑与垂体——形成三层「控制-反馈」环。<span class="marginnote">激素按化学本质分三类，决定了作用机制：<strong>肽类/蛋白质激素（胰岛素、GH）与胺类（肾上腺素）作用于膜受体，快；类固醇激素（皮质醇、性激素）与甲状腺激素进入胞内、作用于核受体，慢而持久</strong>——这就是《细胞基本功能》里「膜受体 vs 核受体」的落地。</span>

**激素分泌**有节律（如皮质醇清晨高、夜间低），并受反馈、神经与代谢物的共同调节。内分泌调节的量化眼光看**激素浓度**：正常值都有明确范围（如空腹血糖 3.9~6.1 mmol/L、血钙 2.25~2.75 mmol/L、TSH 0.27~4.2 mIU/L），偏离即病——检测的核心工具是免疫学方法（见《医学免疫学基础》）。

### 内分泌轴与负反馈调控

三层「下丘脑-垂体-靶腺」轴的基本结构如上，具体到每个轴：
- **下丘脑-垂体-甲状腺轴**：TRH → TSH → 甲状腺激素（T3/T4）。甲状腺激素负反馈抑制 TRH 与 TSH 分泌。最常见的异常是**甲状腺功能亢进**（TSH 降低、FT3/FT4 升高，伴心悸、消瘦、突眼）与**甲状腺功能减退**（TSH 升高、FT3/FT4 降低，伴乏力、怕冷、黏液性水肿）。
- **下丘脑-垂体-肾上腺皮质轴**：CRH → ACTH → 皮质醇。皮质醇是最重要的应激激素，长期过高（库欣综合征）致向心性肥胖、高血糖、骨质疏松；过低（艾迪生病）致低血压、色素沉着、低血糖。
- **下丘脑-垂体-性腺轴**：GnRH → FSH/LH → 性激素（雌激素、睾酮）。调控生殖周期与第二性征。

记住「释放激素 → 促激素 → 靶腺激素」的层级，以及「靶腺激素负反馈回去」的回路，整个内分泌学就变成了一个「三层串级 + 负反馈」的控制系统模型。<span class="marginnote">「轴 == 串级控制系统」：<strong>下丘脑是设定值、垂体是控制器、靶腺是执行器、靶腺激素是反馈信号</strong>。哪个环节出问题，轴的「闭合」状态就变了——这就是所有内分泌疾病诊断的「功能试验」逻辑（如 TRH 兴奋试验、地塞米松抑制试验）。</span>

## 4 三大调节实例：血糖、钙磷与应激

**血糖调节**：胰岛素（降糖，促葡萄糖摄取与合成）vs 胰高血糖素（升糖，促分解与糖异生）。进食后血糖升高 → 胰岛素分泌增加 → 血糖回落；空腹时反向。糖尿病即「胰岛素相对或绝对不足」导致血糖失控。

**钙磷代谢**：由甲状旁腺激素（PTH，升血钙、降血磷）、活性维生素 D（1,25-二羟维生素 D3，升血钙血磷）、降钙素（降血钙）三方协调，靶器官是骨、肾、肠。

**应激反应**：应激时下丘脑-垂体-肾上腺皮质轴激活，皮质醇升高动员能源、抑制炎症；同时交感-肾上腺髓质释放肾上腺素，快速调集心血管资源——「神经快 + 体液久」的典型合奏。

### 常见内分泌疾病速览

| 轴/腺体 | 激素 | 功能亢进 | 功能减退 |
| --- | --- | --- | --- |
| 甲状腺 | T3/T4 | 甲亢（TSH↓、FT3/FT4↑，心悸消瘦） | 甲减（TSH↑、FT3/FT4↓，乏力怕冷） |
| 胰岛 | 胰岛素 | 胰岛素瘤（发作性低血糖） | 糖尿病（1 型绝对缺乏 / 2 型相对不足） |
| 肾上腺皮质 | 皮质醇 | 库欣综合征（向心性肥胖） | 艾迪生病（低血压、色素沉着） |
| 肾上腺髓质 | 肾上腺素 | 嗜铬细胞瘤（阵发性高血压） | ——（临床罕见） |
| 甲状旁腺 | PTH | 甲旁亢（高钙、肾结石） | 甲旁减（低钙、手足抽搐） |
| 垂体 | 各种促激素 | 肢端肥大症（GH 过多） | 垂体功能减退（多激素缺乏） |

这张「一腺一病」对照表是内分泌学的考试主力，也是「激素-靶腺-负反馈」模型的具体应用——每一格都可以用轴的逻辑推出诊断思路。<span class="marginnote">「诊断内分泌病 = 判定轴上哪一环断了」：<strong>先看激素浓度（过高还是过低），再分「原发性」（靶腺自身）与「继发性」（垂体/下丘脑）</strong>——TSH 高低就是区分甲状腺原发/继发的关键，这是内分泌诊断的基本功。</span>

### 神经、体液与免疫的整合

两大调节系统之上，还有一个被日益认识的层面：**神经-内分泌-免疫网络**。三类系统共享信号分子与受体——神经递质可影响免疫细胞，免疫细胞释放的细胞因子（IL-1、TNF）能反馈影响下丘脑（发热即其表现），内分泌激素（皮质醇）又抑制免疫。这个「三角网络」解释了为何**应激会削弱免疫、情绪会影响疾病**，也是心身医学与神经免疫学的交汇点。

理解「神经快、体液久、免疫护」三者的分工与耦合，人体就从一个「各管一段」的零件清单，变成了一张彼此咬合、动态平衡的调节网。

## 5 公式解析：血浆渗透压与 ADH 的调节

内分泌对水的调节，核心指标是**血浆渗透压**，它与抗利尿激素（ADH）构成一个经典的负反馈系统。临床常用近似公式：

$$
\text{血浆渗透压（mOsm/L）} \approx 2[\ce{Na+}] + \frac{\text{血糖(mmol/L)}}{18} + \frac{\text{BUN(mmol/L)}}{2.8}
$$

三步拆解：

- **第一步，看主项**：$2[\ce{Na+}]$ 是绝对主力——$\ce{Na+}$ 及其伴随阴离子贡献了渗透压的大部分，正常约 $2\times140 = 280$。葡萄糖与尿素（BUN）是修正项，除以 18 与 2.8 是把 mmol/L 换算成渗透摩尔浓度单位。
- **第二步，定正常**：正常血浆渗透压约 280～310 mOsm/L。渗透压升高（高渗，如缺水）→ 下丘脑渗透压感受器兴奋 → ADH 分泌增加 → 肾集合管重吸收水增多 → 渗透压回落，同时产生渴觉促饮水；渗透压降低则反向。这是「**渗透压-ADH-水平衡**」负反馈环。
- **第三步，读临床**：血浆渗透压能区分脱水类型（低渗/等渗/高渗，见《病理生理学》），也是诊断尿崩症（ADH 缺乏，尿量大、尿比重低）与 SIADH（ADH 过多，水潴留低钠）的关键。<span class="marginnote">把「2×Na + 糖/18 + 尿素/2.8」当成一把尺子：<strong>主项抓钠、修正看糖与尿素</strong>。记住这个公式，水钠平衡与内分泌的关系就量化了。</span>

## 6 小结

- **神经系统**：神经元以电信号传导、以化学递质跨突触传递；EPSP/IPSP 经空间与时间总和决定是否发放。
- **反射**是基本方式；上/下运动神经元损伤的表现不同；交感与副交感拮抗协调。
- **内分泌**以「下丘脑-垂体-靶腺轴」为核心，靶腺激素负反馈回下丘脑与垂体；激素按化学本质分膜受体型（快）与核受体型（慢）。
- **三大实例**：血糖（胰岛素/胰高血糖素）、钙磷（PTH/维生素 D/降钙素）、应激（皮质醇 + 肾上腺素）。
- **公式锚点**：血浆渗透压 ≈ $2[\ce{Na+}]$ + 血糖/18 + BUN/2.8（280~310 mOsm/L），由 ADH 负反馈维持。
- 两大调节系统服务的目标是同一件事——维持内环境稳态；下一课进入最耗能的两大「泵」：**心血管与呼吸生理**，看循环如何把氧送到每一处、气体如何交换、酸碱如何平衡。

在下一节，我们将回答：心脏如何泵血、血压如何形成、肺泡如何换气、$\ce{O2}$ 与 $\ce{CO2}$ 如何运输——这就是**心血管与呼吸生理**。
