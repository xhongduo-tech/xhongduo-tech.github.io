## 为什么从免疫调节药与解毒药开始

**免疫调节药**（免疫抑制/免疫增强）用于移植排斥、自身免疫病与免疫缺陷；**解毒药**（antidotes）针对各类中毒"对症下药"。理解免疫抑制药（环孢素等）的机制与解毒药的对应关系，是移植、风湿与急诊中毒治疗的基础。<span class="marginnote"><strong>免疫抑制药</strong>：<strong>钙调磷酸酶抑制</strong>（环孢素、他克莫司——抑 T 细胞）、<strong>抗增殖</strong>（霉酚酸酯、硫唑嘌呤——抑嘌呤）、<strong>糖皮质激素</strong>（见肾上腺皮质激素篇）、<strong>生物制剂</strong>（抗 TNF、抗 CD20、抗 IL-6）。<strong>免疫增强药</strong>：干扰素、白介素、胸腺肽、疫苗（主动免疫）。<strong>解毒药</strong>：有机磷（阿托品+解磷定）、阿片（纳洛酮）、BZD（氟马西尼）、对乙酰氨基酚（NAC）、华法林（维生素 K）、肝素（鱼精蛋白）、地高辛（Fab 抗体）、甲醇（乙醇/甲吡唑）、重金属（螯合剂）。</span>

"环孢素怎么'免疫抑制'（钙调磷酸酶）""霉酚酸酯怎么'抑淋巴细胞'（嘌呤）""解毒药怎么'对症'（一毒一解）""NAC 怎么'解对乙酰氨基酚'（补谷胱甘肽）"——免疫调节药与解毒药回答这些问题。

## 1 免疫抑制药

**免疫抑制药（immunosuppressants）**（器官移植、自身免疫病）：

**糖皮质激素**：广谱免疫抑制+抗炎（见肾上腺皮质激素篇）——"激素'免疫抑制'"。
**钙调磷酸酶抑制剂**：**环孢素（cyclosporine）、他克莫司（tacrolimus）**——**抑制钙调磷酸酶→抑 T 细胞活化（IL-2 转录↓）**——"环孢素'抑 T 细胞'（移植一线）"；副作用：**肾毒性**、高血压、牙龈增生（环孢素）。
**抗增殖/抗代谢**：**霉酚酸酯（mycophenolate）**（抑嘌呤合成——淋巴细胞）、**硫唑嘌呤**（抑嘌呤）——"霉酚酸酯'抑嘌呤'（淋巴）"；副作用：骨髓抑制、感染。
**生物制剂**：**抗 TNF-α**（英夫利昔单抗——类风湿、克罗恩）、**利妥昔单抗**（抗 CD20——B 细胞病）、**抗 IL-6**（托珠单抗）。

**临床应用**：**器官移植（环孢素/他克莫司——抗排斥）**、自身免疫病（类风湿、SLE、炎症性肠病——激素+免疫抑制）。

**"免疫抑制的代价"**：**感染风险↑、肿瘤风险↑**（免疫监视↓）——"免疫抑制'感染肿瘤风险'"。<span class="marginnote"><strong>环孢素/他克莫司"钙调磷酸酶抑制"</strong>：抑钙调磷酸酶→<strong>T 细胞 IL-2 转录↓→T 细胞活化受阻</strong>——"环孢素'掐 T 细胞信号'（移植抗排斥一线）"；<strong>肾毒性</strong>（监测血药浓度）——"环孢素'肾毒'（TDM）"。<strong>霉酚酸酯"抑嘌呤"</strong>：抑制<strong>鸟嘌呤核苷酸从头合成</strong>（淋巴细胞依赖）→<strong>选择性抑淋巴细胞</strong>——"霉酚酸酯'淋巴嘌呤'（移植/狼疮）"（呼嘌呤代谢篇）。<strong>生物制剂（抗 TNF）</strong>：类风湿关节炎/克罗恩——"抗 TNF'生物制剂'（类风湿/克罗恩）"（副作用感染（结核筛查））。<strong>免疫抑制的"感染肿瘤"</strong>：免疫监视↓→<strong>机会性感染+肿瘤（移植后淋巴瘤、皮肤癌）</strong>——"免疫抑制'双风险'（感染+肿瘤）"（移植患者长期监测）。</span>

**治疗药物监测（TDM）与用药注意**：环孢素、他克莫司治疗窗窄，需监测血药浓度以平衡疗效与肾毒性；硫唑嘌呤用药前宜筛查 **TPMT** 基因型/活性（缺乏者骨髓抑制重）；糖皮质激素长期使用需防范骨质疏松、感染与血糖升高。<span class="marginnote"><strong>TDM 的意义</strong>：环孢素浓度过低→排斥、过高→肾毒，移植后需频繁监测——"免疫抑制剂'窄窗'（看血药浓度）"；TPMT 缺陷者（约 1/300）用硫唑嘌呤后严重骨髓抑制，故先筛基因型。</span>

## 2 免疫增强药

**免疫增强药（immunostimulants）**：

**干扰素（interferon）**：抗病毒+抗肿瘤+免疫调节——"干扰素'抗病毒免疫'"（乙肝/丙肝、肿瘤；丙肝被 DAAs 取代）。
**白介素-2（IL-2）**：激活 T/NK——肾癌、黑色素瘤（副作用多）。
**胸腺肽**：调节 T 细胞（辅助）。
**免疫球蛋白（IVIG）**：被动免疫（免疫缺陷、免疫性血小板减少 ITP）。
**疫苗**：主动免疫（预防——见免疫学篇）。

**"免疫增强 vs 免疫抑制"**：增强（免疫缺陷、肿瘤免疫治疗）vs 抑制（移植、自身免疫）——"免疫'双向调节'（按需）"。

**临床意义**：免疫缺陷（IVIG）、肿瘤免疫（干扰素、免疫检查点——见抗肿瘤篇）。<span class="marginnote"><strong>干扰素"广谱免疫"</strong>：抗病毒（流感/肝炎）+免疫调节——"干扰素'抗病毒免疫'（乙肝/丙肝传统用药，现丙肝 DAAs）"；副作用（流感样、骨髓抑制）。<strong>IVIG"被动免疫"</strong>：静脉免疫球蛋白→<strong>免疫缺陷补充+ITP（免疫调节）</strong>——"IVIG'被动免疫'（免疫缺陷/ITP）"（呼免疫学篇的抗体）。<strong>免疫"双向"</strong>：抑制（移植自身免疫——环孢素）vs 增强（免疫缺陷肿瘤——干扰素/检查点）——"免疫药'双向'（按病情方向）"。</span>

## 3 解毒药

**解毒药（antidotes）**——"一毒一解"对应：

| 毒物 | 解毒药 | 机制 |
| --- | --- | --- |
| 有机磷 | 阿托品+解磷定 | 拮抗 M+复活胆碱酯酶 |
| 阿片类 | **纳洛酮** | 阿片受体拮抗 |
| 苯二氮䓬 | **氟马西尼** | BZD 受体拮抗 |
| 对乙酰氨基酚 | **N-乙酰半胱氨酸（NAC）** | 补谷胱甘肽 |
| 华法林 | **维生素 K** | 补维生素 K 因子 |
| 肝素 | **鱼精蛋白** | 中和肝素 |
| 地高辛 | **地高辛抗体（Fab）** | 结合地高辛 |
| 甲醇/乙二醇 | **乙醇/甲吡唑** | 竞争醇脱氢酶 |
| 重金属（铅汞） | **螯合剂**（EDTA、二巯基丙醇） | 螯合排出 |

**"解毒'对号入座'"**：拮抗（纳洛酮/氟马西尼）、复活酶（解磷定）、中和（鱼精蛋白）、补充（维生素 K/NAC）、结合（地高辛抗体）、竞争（乙醇）。

**临床要点**：**早期、足量、对症+支持**——"解毒'早足快'"（急性中毒处理）。<span class="marginnote"><strong>解毒药的"六种机制"</strong>：<strong>拮抗受体</strong>（纳洛酮/氟马西尼——呼药效学拮抗药）、<strong>复活酶</strong>（解磷定——复活胆碱酯酶，呼传出神经药理）、<strong>中和</strong>（鱼精蛋白——结合肝素）、<strong>补充底物</strong>（维生素 K——华法林；NAC——谷胱甘肽）、<strong>抗体结合</strong>（地高辛 Fab）、<strong>竞争酶</strong>（乙醇——甲醇中毒竞争醇脱氢酶）——"解毒'对号'（一毒一解）"。<strong>NAC 的"双重"</strong>：化痰+解对乙酰氨基酚（补谷胱甘肽）——"NAC'化痰+解毒'"（呼呼吸药理与解热镇痛篇）。<strong>急性中毒"ABC"</strong>：气道呼吸循环支持+特异性解毒药——"中毒'支持+解毒'（早期足量）"。</span>

**两类常见中毒的处理要点**：**有机磷中毒**表现为胆碱能危象（M 样——流涎、瞳孔缩小、支气管痉挛；N 样——肌束颤动），处理用阿托品（对抗 M 样作用，直至"阿托品化"）+解磷定（尽早给药，复活被磷酰化的胆碱酯酶）。**对乙酰氨基酚中毒**早期仅有恶心呕吐，12~24 小时后出现肝损伤，须在 8~10 小时内开始 NAC，超过 24 小时仍可给予。<span class="marginnote"><strong>阿托品化</strong>：瞳孔散大、口干、皮肤潮红为阿托品足量标志——"阿托品'用足到口干'；NAC 越早越好，但 24 小时后给药仍可能获益——"NAC'抢时间'"。</span>

**免疫增强的循证应用**：干扰素仍在慢性乙肝与部分肿瘤中使用；IVIG 除替代补充外，还通过 Fc 受体调节发挥免疫抑制样作用（ITP、川崎病）——"被动免疫'一举两得'"。

## 4 公式解析：免疫抑制与免疫增强的"平衡"

**免疫调节的"平衡"**：

$$
\text{免疫监视}（\text{抗感染、抗肿瘤}）\xleftrightarrow{\text{平衡}} \text{免疫耐受}（\text{防自身免疫、防排斥}）
$$

- **免疫抑制**（环孢素/激素/抗 TNF）：压免疫→**移植排斥/自身免疫病控制**（代价：感染肿瘤↑）。
- **免疫增强**（干扰素/IVIG/检查点）：升免疫→**免疫缺陷/肿瘤治疗**（代价：免疫过度——自身免疫/irAE）。
- **免疫治疗**（PD-1 抑制剂）：解除免疫抑制（肿瘤免疫逃逸）→抗肿瘤——"免疫'平衡'（按需调节）"。
- **临床**：移植（抑制）、肿瘤（增强/解除抑制）——"免疫药'方向取决于病'"。

**辨析｜易错点：** 免疫抑制药（移植/自身免疫）与免疫增强/免疫治疗（肿瘤）方向相反——"免疫'按需'（抑或增）"。另一个易错点：**解毒药"对症"**（纳洛酮只解阿片、氟马西尼只解 BZD）——"解毒'专一'"（不是万能解毒）。

## 6 术语速查

| 术语 | 含义 |
| --- | --- |
| 钙调磷酸酶 | T 细胞信号通路的关键磷酸酶，环孢素/他克莫司靶点 |
| IL-2 | 白介素-2，T 细胞增殖的关键细胞因子 |
| 嘌呤从头合成 | 淋巴细胞依赖的核苷酸合成途径，霉酚酸酯靶点 |
| 抗 TNF-α | 中和 TNF-α 的生物制剂，用于类风湿/克罗恩 |
| 被动免疫 | 直接输入抗体（IVIG）提供的免疫 |
| 拮抗剂 | 竞争受体而阻断效应，如纳洛酮 |
| 胆碱酯酶复活 | 解磷定使被磷酰化的胆碱酯酶恢复活性 |
| TDM | 治疗药物监测 |
| TPMT | 硫唑嘌呤代谢酶，其缺乏致骨髓抑制加重 |
| 阿托品化 | 阿托品足量的临床标志（口干、瞳孔散大） |

## 7 小结

- **免疫抑制药**：环孢素/他克莫司（钙调磷酸酶——移植抗排斥）、霉酚酸酯（抑嘌呤）、糖皮质激素、抗 TNF——**免疫抑制'感染肿瘤风险'**。
- **免疫增强**：干扰素、IVIG（被动免疫）、疫苗——免疫"双向调节"。
- **解毒药**：纳洛酮（阿片）、氟马西尼（BZD）、NAC（对乙酰氨基酚）、维生素 K（华法林）、鱼精蛋白（肝素）、地高辛抗体、阿托品+解磷定（有机磷）——"一毒一解"。
- 免疫治疗（PD-1 解除免疫抑制——抗肿瘤）与免疫抑制（移植）方向相反——"免疫'按需调节'"。
