## 为什么从病理生理学开始

病理学回答「病变长什么样」，**病理生理学（pathophysiology）**则回答「功能和代谢为什么、怎么乱」。它的核心研究对象是几个「通行证式」的危重症环节：**水电解质紊乱、酸碱失衡、缺氧、休克、DIC**——它们不专属某个器官，而是任何重症都可能走向的共同通路。<span class="marginnote">本篇是把生理学（水盐、循环、呼吸、凝血）与病理学（血栓、休克器官）的知识「故障化」重组：先有正常调节，再看调节如何失守。它与《心血管与呼吸生理》《消化泌尿血液系统》《病理学总论》直接衔接。</span>

从「从极限到大模型」的视角看，重症的恶化是**正反馈失控**的典型：微循环障碍 → 组织缺氧 → 代谢性酸中毒 → 血管对儿茶酚胺反应下降 → 血压进一步下降 → 灌注更差。理解病理生理，就是学会识别并打断这类「恶性循环」。

## 1 水、电解质与酸碱平衡紊乱

**水钠代谢紊乱**：按血钠浓度与渗透压分三型（见《神经与内分泌系统》的渗透压公式）——**等渗性脱水**（最常见，呕吐腹泻，血钠正常）、**低渗性脱水**（丢钠多于丢水，细胞水肿，血钠低）、**高渗性脱水**（丢水多于丢钠，细胞脱水，血钠高）；另有**水中毒**（水潴留稀释性低钠）。<span class="marginnote">脱水补液的临床口诀：<strong>「低渗补高渗盐（3% 盐水）、高渗补低渗液、等渗补平衡盐」</strong>。低渗性脱水细胞水肿（脑水肿危险）、高渗性脱水细胞脱水（口渴最早）——「看钠定方向」是水电解质治疗的第一原则。</span>

### 脱水三型对比表

| 对比项 | 等渗性脱水 | 低渗性脱水 | 高渗性脱水 |
| --- | --- | --- | --- |
| 失水与失钠 | 等比例丢失 | 丢钠多于丢水 | 丢水多于丢钠 |
| 血钠 | 正常（135~145） | < 130 mmol/L | > 150 mmol/L |
| 细胞外液变化 | 减少（最早） | 明显减少（血管内容量↓最重） | 减少，但细胞内液也减少 |
| 细胞内液 | 基本不变 | **细胞水肿**（入胞） | **细胞脱水**（出胞） |
| 主要表现 | 尿少、皮肤弹性差 | 血压下降、休克倾向、脑水肿 | 口渴最早最重、尿少、高热 |
| 常见原因 | 呕吐、腹泻、烧伤 | 大汗后只补水、长期利尿 | 高热大汗、饮水不足、糖尿病 |

「等渗看细胞外、低渗怕脑水肿、高渗怕口渴脱水」——补液时「先看钠、再定张」，是水电解质紊乱处理的总纲。<span class="marginnote">三型脱水的本质是「失水与失钠的比例」不同：<strong>比例相等是等渗、钠丢得多是低渗、水丢得多是高渗</strong>——抓住「钠浓度」这个标尺，三型就能互相推导。</span>

**钾代谢紊乱**：**低钾血症**（血钾 < 3.5 mmol/L，肌无力、肠麻痹、心律失常、心电图 T 波低平 U 波）与**高钾血症**（血钾 > 5.5 mmol/L，心肌抑制、T 波高尖、心脏骤停——急症）。钾的跨膜分布受酸碱影响：酸中毒时 $\ce{H+}$ 入胞换出 $\ce{K+}$ → 血钾升高。

**酸碱平衡紊乱**（判读逻辑见《心血管与呼吸生理》的 Henderson-Hasselbalch 方程）：呼吸性酸中毒（$\ce{CO2}$ 潴留）、呼吸性碱中毒（过度通气）、代谢性酸中毒（$\ce{HCO3-}$ 丢失或 $\ce{H+}$ 增多，如糖尿病酮症、肾衰、腹泻）、代谢性碱中毒（呕吐丢酸）。**判读三步**：看 pH → 看原发变量（$P_{aCO2}$ 或 $\ce{HCO3-}$）→ 看代偿是否充分。

**常见临床对应**：慢性阻塞性肺疾病急性加重 → 呼吸性酸中毒（$\ce{CO2}$ 潴留，pH↓）；过度换气/焦虑 → 呼吸性碱中毒；糖尿病酮症、乳酸堆积、严重腹泻 → 代谢性酸中毒；剧烈呕吐 → 代谢性碱中毒。把「疾病 → 原发变量 → 酸碱类型」串起来，血气分析就不再是死记，而是「找最可能的那个变量变了」。<span class="marginnote">「代偿是身体在自我矫正」：<strong>肺管呼吸性、肾管代谢性，代偿方向永远是「把 pH 拉回正常」</strong>——看到 pH 异常先判断「谁先错」，再看「另一方是否已尽力补救」，这就是代偿分析的思路。</span>

## 2 缺氧：供氧链上的缺口

**缺氧（hypoxia）**指组织供氧不足或利用氧障碍，按「氧的旅程」分四型：

- **低张性缺氧**（动脉血氧分压低）：吸入气氧低、外呼吸障碍（如慢性阻塞性肺疾病）、静脉血分流——血氧指标：$PaO_2$、$SaO_2$、$CaO_2$ 均降低，发绀。
- **血液性缺氧**（血红蛋白量或质异常）：贫血、一氧化碳中毒（$\ce{CO}$ 与 Hb 亲和力强）、高铁血红蛋白——$PaO_2$ 正常但血氧容量降低，皮肤可呈樱桃红（$\ce{CO}$ 中毒）。
- **循环性缺氧**（组织血流减少）：休克、心力衰竭、动脉粥样硬化——动静脉血氧差增大，皮肤发绀。
- **组织性缺氧**（细胞利用氧障碍）：氰化物中毒（抑制细胞色素氧化酶）——静脉血氧含量升高，皮肤玫瑰红。<span class="marginnote">缺氧四型的鉴别核心看两个指标：<strong>动脉血氧分压 $PaO_2$（低张性才降低）与动静脉血氧差（循环性增大、组织性减小）</strong>。四型的皮肤颜色（发绀/樱桃红/玫瑰红）是临床速记法。</span>

氧供的计算（见《心血管与呼吸生理》）：$DO_2 = CaO_2 \times CO \times 10$。缺氧的后果：细胞代谢转为无氧酵解（乳酸堆积）、ATP 生成减少、离子泵失灵、细胞损伤坏死——缺氧是许多疾病的共同终末环节。

## 3 休克：微循环的进行性崩溃

**休克（shock）**是各种原因引起的**有效循环血量锐减、组织灌注不足、细胞缺氧**的危重状态。按病因分：**低血容量性**（失血、脱水）、**心源性**（泵衰竭）、**感染性**（脓毒症，最常见类型之一）、**过敏性**（I 型超敏反应）、**神经源性**（脊髓损伤）。

**微循环变化**是休克的核心，分三期：

- **缺血性缺氧期（代偿期）**：交感-肾上腺髓质兴奋，皮肤、腹腔内脏血管收缩，血流集中于心脑——血压可维持，但组织已开始缺氧。
- **淤血性缺氧期（失代偿期）**：酸中毒使血管对儿茶酚胺反应性下降，毛细血管前括约肌松弛而后的仍收缩，血液淤滞、血浆外渗——血压明显下降，**恶性循环启动**。
- **微循环衰竭期（难治期/DIC 期）**：血流停滞、微血栓形成（并发 DIC）、细胞坏死、多器官功能障碍（MODS）。<span class="marginnote">休克分期的本质是「代偿 → 失代偿 → 不可逆」：<strong>代偿期血压可正常（假象！）、失代偿期血压骤降、衰竭期并发 DIC</strong>。早期识别靠的是「皮肤湿冷、尿量减少、心率增快」这些灌注不足的信号，而非血压本身。</span>

休克的治疗原则：尽快恢复有效循环血量（补液、输血）、纠正酸碱失衡与缺氧、针对病因（抗感染、抗过敏）、支持重要脏器功能。

### 休克监测与分型速览

休克的早期识别与动态监测，靠一组「灌注指标」而非只看血压：

- **血压与脉压**：脉压变小（收缩压↓、舒张压不降）是早期信号；收缩压 < 90 mmHg 提示失代偿。
- **尿量**：< 30 mL/h 提示肾灌注不足——尿量是「内脏灌注的窗口」。
- **皮肤**：湿冷、苍白、花斑提示外周灌注差；暖休克（感染性休克早期）则皮肤温暖。
- **乳酸**：血乳酸升高反映组织缺氧与无氧酵解，是判断休克严重程度与预后的重要指标。

**分型**：低血容量性（补液最有效）、心源性（强心、减负荷）、感染性（脓毒症，感染源控制 + 液体复苏 + 血管活性药）、过敏性（肾上腺素 + 抗过敏）、神经源性（脊髓损伤，血管张力丧失）。

「血压是结果、灌注是本质」——监测的目的不是把血压「数字」拉上来，而是恢复组织灌注。<span class="marginnote">「休克监测四看：血压、尿量、皮肤、乳酸」——<strong>尿量最实用、乳酸最敏感</strong>。记住「休克不等于低血压，低血压也不一定是休克」，早期（代偿期）血压甚至可以正常——「组织灌注」才是休克的定义核心。</span>

## 4 DIC：凝血系统的「走火入魔」

**弥散性血管内凝血（disseminated intravascular coagulation, DIC）**：在某些致病因素（感染、产科意外、恶性肿瘤、严重创伤、休克）作用下，凝血系统被广泛激活，在微血管内**广泛微血栓形成**，同时消耗大量凝血因子与血小板，继发**纤溶亢进**，最终导致**出血、休克、器官功能障碍与贫血**并存。

发病机制：**组织因子大量释放**（启动外源性凝血）与**血管内皮损伤**（暴露胶原激活内源性）——两条通路同时点燃，级联放大失控。临床分期：**高凝期**（微血栓为主）→ **消耗性低凝期**（凝血因子与血小板耗竭，出血）→ **继发纤溶亢进期**（出血加重，FDP 增多）。<span class="marginnote">DIC 的实验室「三联征」：<strong>血小板减少 + 凝血酶原时间（PT）延长 + 纤维蛋白原降低</strong>，再加 FDP/D-二聚体升高。记忆角度：DIC 是「凝血系统的正反馈失控」——凝血级联本该被控制在局部，却被广泛点燃，这正是《生理性止血与血液凝固》章节「级联放大 + 抗凝调节」失灵的结果。</span>

DIC 的防治：处理原发病（最根本）、早期高凝期可用肝素抗凝（慎用于继发纤溶期）、补充凝血因子与血小板、抗纤溶药仅在纤溶亢进明确时使用。

### MODS：多器官功能障碍

重症的「最终出口」常常是**多器官功能障碍综合征（MODS）**——在严重感染、创伤、休克等打击下，两个以上器官序贯或同时发生功能衰竭。

**发病机制**（瀑布式）：全身性炎症反应失调（SIRS）→ 大量炎症介质（TNF、IL-1、IL-6）与氧自由基释放 → 内皮损伤、微循环障碍、细胞缺氧 → 器官功能相继受损。常见的受累顺序：**肺最先（ARDS）→ 肝 → 肾 → 肠道 → 中枢**，被称为「多米诺骨牌」。

**治疗要点**：控制原发病、器官功能支持（机械通气、血液净化、维持灌注）、营养支持与防治院内感染——MODS 是重症医学的核心战场。<span class="marginnote">「MODS 是 SIRS 失控的终点」：<strong>全身炎症反应（SIRS）本是防御，过度则自我损伤</strong>——「炎症介质风暴」正反馈放大，正是《病理生理学》开篇「正反馈失控」的最极端案例。</span>

## 5 公式解析：阴离子间隙与渗透压

病理生理的量化判断，常用两个公式，这里重点拆解**阴离子间隙（anion gap, AG）**：

$$
AG = [\ce{Na+}] - ([\ce{Cl-}] + [\ce{HCO3-}])
$$

正常约 $8\sim16\ \mathrm{mmol/L}$。三步拆解：

- **第一步，看逻辑**：血浆阳离子（主要是 $\ce{Na+}$）与阴离子（主要是 $\ce{Cl-}$、$\ce{HCO3-}$）电荷应相等。未测定的阴离子（蛋白、磷酸、硫酸、有机酸）与未测定阳离子之差，就是 AG——它代表「常规没测到的阴离子」的净余额。
- **第二步，算数字**：正常 $[\ce{Na+}]=140$、$[\ce{Cl-}]=104$、$[\ce{HCO3-}]=24$，则 $AG = 140 - (104+24) = 12$。
- **第三步，读意义**：AG 升高的代谢性酸中毒（**高 AG 型**）提示「体内多了未测定的酸」——乳酸酸中毒（缺氧、休克）、酮症酸中毒（糖尿病）、尿毒症、水杨酸/甲醇中毒；AG 正常的代谢性酸中毒（**正常 AG 型**）则提示 $\ce{HCO3-}$ 直接丢失（腹泻、肾小管酸中毒）。<span class="marginnote">AG 是把代谢性酸中毒「二分法」的钥匙：<strong>高 AG = 酸「生成」多了（乳酸、酮体、尿毒症毒素），正常 AG = 碱「丢」多了（腹泻）</strong>。结合《神经与内分泌系统》的渗透压公式（$2[\ce{Na+}]$ + 糖/18 + BUN/2.8），水盐酸碱的定量判断就齐了。</span>

## 6 小结

- **水电解质**：脱水三型看血钠（等渗最常见、低渗细胞水肿、高渗细胞脱水）；低钾心肌抑制、高钾心脏骤停；酸中毒使血钾升高。
- **酸碱**：四型失衡 + 三步判读（pH → 原发变量 → 代偿）；AG 区分代谢性酸中毒（高 AG 为酸生成多，正常 AG 为碱丢失多）。
- **缺氧**：四型（低张性看 $PaO_2$、血液性看 Hb、循环性看血流、组织性看利用）；$DO_2 = CaO_2 \times CO \times 10$。
- **休克**：三期微循环（缺血性代偿 → 淤血性失代偿 → 衰竭期并发 DIC）；治疗核心是恢复灌注与打断恶性循环。
- **DIC**：广泛微血栓 + 消耗性出血 + 纤溶亢进；处理原发病最根本，肝素用于高凝期。
- 疾病要诊断、要治疗，都离不开「用药」——下一课进入**药理学基础**：药效学与药动学如何共同决定「用什么药、用多大剂量、用多久」。

在下一节，我们将回答：药物如何起作用、如何在体内走一遭、半衰期与稳态浓度怎么算——这就是**药理学基础**。
