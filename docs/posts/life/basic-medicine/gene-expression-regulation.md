## 为什么从基因表达调控开始

人体所有细胞含相同基因组，但**表达不同的基因**（肝细胞表达白蛋白、红细胞表达血红蛋白）——这就是**基因表达调控（gene expression regulation）**。调控发生在**转录（主要）、转录后、翻译、翻译后**多个水平，是发育、分化、应激适应与疾病的分子基础。<span class="marginnote"><strong>基因表达调控的层次</strong>：①<strong>转录水平</strong>（最主要的开关——顺式元件+转录因子+表观遗传）；②转录后（剪接、mRNA 稳定性）；③翻译水平；④翻译后（蛋白降解/修饰）。<strong>原核的经典模型是乳糖操纵子</strong>，<strong>真核的调控靠染色质状态+转录因子组合</strong>。理解调控，是理解肿瘤（癌基因/抑癌基因）、发育与"细胞重编程"（iPS）的基础。</span>

"为什么细胞'分工'而基因组相同""乳糖操纵子怎么'开/关'""表观遗传怎么'记得'谁该沉默"——基因表达调控回答这些问题。

## 1 原核基因表达调控：乳糖操纵子

**乳糖操纵子（lac operon）**是原核转录调控的经典模型（Jacob-Monod）：

**结构基因**（lacZ、lacY、lacA）：编码 β-半乳糖苷酶、通透酶等（分解乳糖）。
**调控序列**：**启动子（P）**、**操纵基因（O）**。
**调节基因（lacI）**：编码**阻遏蛋白（repressor）**。

**双调控（负调控+正调控）**：

1. **无乳糖**：阻遏蛋白结合操纵基因→RNA 聚合酶不能转录→"关"。
2. **有乳糖**：**异乳糖（诱导物）**与阻遏蛋白结合→阻遏蛋白脱离操纵基因→"开"（转录乳糖代谢酶）。
3. **葡萄糖存在（分解代谢物阻遏）**：cAMP 低→CAP 不结合→即使有乳糖也低转录；**葡萄糖耗尽→cAMP 高→CAP-cAMP 激活转录**——"优先用葡萄糖，葡萄糖没了才用乳糖"。

**意义**：细菌"按需表达"——有底物才合成对应酶。<span class="marginnote"><strong>乳糖操纵子的"双开关"</strong>：<strong>诱导（负调控解除）</strong>——乳糖诱导物使阻遏蛋白失活→基因开；<strong>CAP 激活（正调控）</strong>——葡萄糖缺乏（cAMP 高）时 CAP-cAMP 促进转录。<strong>"葡萄糖优先"</strong>：细菌先用葡萄糖（易利用），葡萄糖耗尽才分解乳糖——"分解代谢物阻遏"（cAMP-CAP 信号）体现了"经济原则"。<strong>Jacob-Monod 操纵子模型</strong>奠定了基因调控的概念（1965 诺奖）。<strong>原核"组调控"</strong>：多顺反子（一个操纵子多个结构基因一起调控）——"原核按'组'开关基因"。</span>

**可诱导 vs 可阻遏操纵子**：乳糖操纵子是**可诱导**的（平时关闭、有底物乳糖才开——分解代谢基因）；**色氨酸操纵子（trp operon）**则是**可阻遏**的（平时开放、产物色氨酸多时关闭——合成代谢基因，产物足够就关）。两种模式方向相反，但都体现"按需表达"的节约原则。<span class="marginnote"><strong>trp 操纵子"产物阻遏"</strong>：色氨酸多时，色氨酸作为"辅阻遏物"结合并激活阻遏蛋白→关闭合成酶基因——"合成代谢基因'产物多就关'（反馈式阻遏）"。</span>

**操纵子的经典实验证据**：Jacob 与 Monod 用**部分二倍体（F' 质粒）**实验证明：阻遏蛋白是"可扩散"的**反式**因子（能作用于不同染色体上的操纵基因），而操纵基因是**顺式**序列（只影响同一条 DNA 上的基因）——"trans 因子可在染色体间移动、cis 序列只作用于自身"。

## 2 真核转录调控：顺式元件与转录因子

**真核基因表达的调控主要在转录水平**，靠两类"棋子"：

**顺式作用元件（cis-elements）**：DNA 上的调控序列——**启动子**（TATA box 等，聚合酶结合处）、**增强子（enhancer）**（远处增强转录）、**沉默子（silencer）**（抑制转录）。

**反式作用因子（trans-factors）**：**转录因子（TF）**——结合顺式元件的蛋白：

**通用转录因子**（TFⅡD 等）：所有基因转录需要（基础转录装置）。
**特异转录因子**：结合增强子/沉默子，激活或抑制特定基因（如 p53、NF-κB、类固醇激素受体、Myc）。

**组合调控**：一个基因的表达由**多个转录因子的组合**决定——"不同细胞有不同转录因子组合→表达不同基因"（细胞分化的本质）。<span class="marginnote"><strong>真核调控的"远程指挥"</strong>：增强子可远离启动子数 kb~Mb，经 DNA 环化（loop）把结合的激活因子"带到"启动子——"增强子远程激活基因"。<strong>转录因子的"模块结构"</strong>：DNA 结合域（识别序列）+激活域（招募共激活因子）——"TF 像'钥匙'（识别）+'开关'（激活）"。<strong>类固醇激素受体</strong>是"配体激活的转录因子"（激素结合→入核→结合激素反应元件→激活基因，呼应信号转导篇的胞内受体）。<strong>组合调控</strong>解释细胞分化：肝细胞表达肝特异 TF 组合→激活白蛋白基因；红细胞表达红系 TF（GATA-1）→激活珠蛋白基因——"分化=TF 组合的选择"。</span>

**转录因子的多样性**：人类基因组约有 1500~1900 个转录因子基因，占编码基因的 6%~8%。一个典型转录因子包含**DNA 结合域**（如锌指、亮氨酸拉链、螺旋-转角-螺旋等结构模体）与**激活/抑制域**——"识别序列 + 调控效应"是 TF 的两只手。许多转录因子是**疾病治疗靶点**（如雌激素受体是乳腺癌内分泌治疗的关键靶点）。

## 3 表观遗传调控

**表观遗传（epigenetics）**：不改变 DNA 序列但可遗传的基因表达调控：

**DNA 甲基化**：CpG 二核苷酸的胞嘧啶甲基化（甲基转移酶 DNMT）→**通常沉默基因**（启动子甲基化→转录关闭）。**基因组印记**（父/母源等位基因差异甲基化）。
**组蛋白修饰**：**乙酰化**（HAT 加、HDAC 去）→乙酰化通常**激活**（松染色质）；**甲基化**（H3K4me3 激活、H3K27me3 沉默）；磷酸化、泛素化等——"**组蛋白密码**"。
**染色质重塑**：核小体位置/组成改变影响转录因子可及性（SWI/SNF 复合体）。
**非编码 RNA**：miRNA、lncRNA 参与调控。

**表观遗传的意义**：细胞记忆（分化状态的维持）、X 染色体失活、印记；**表观遗传异常→肿瘤**（启动子高甲基化沉默抑癌基因）、发育疾病。<span class="marginnote"><strong>表观遗传是"可遗传的开关记忆"</strong>：DNA 甲基化（沉默）+组蛋白乙酰化（激活）是两大主流——"甲基化像'封条'、乙酰化像'开门'"。<strong>X 失活</strong>（女性一条 X 随机沉默）靠 Xist lncRNA+组蛋白修饰——"剂量补偿"的经典。<strong>肿瘤的表观遗传</strong>：抑癌基因启动子高甲基化（如 p16、MGMT）→沉默——<strong>去甲基化药（阿扎胞苷）与 HDAC 抑制剂</strong>（伏立诺他）是表观遗传抗癌药。<strong>印记</strong>：IGF2 等基因仅父源或母源表达（Prader-Willi/Angelman 综合征与 15q11 印记区相关）。<strong>表观遗传可逆</strong>（与基因突变不同）→是治疗靶点。</span>

**表观遗传的检测与应用**：甲基化特异性 PCR（MSP）、亚硫酸盐测序可检测启动子甲基化；组蛋白修饰用 ChIP-seq 定位。临床已用的表观遗传药：**去甲基化药**（阿扎胞苷、地西他滨——治疗骨髓增生异常综合征 MDS）与 **HDAC 抑制剂**（伏立诺他——皮肤 T 细胞淋巴瘤）——"表观遗传药'重新打开被沉默的基因'"。

**辨析｜易错点：** "表观遗传"不等于"基因突变"——前者不改变碱基序列、可逆、可被药物逆转；后者是序列改变、不可逆。另一个易错点：**增强子虽远离启动子，仍通过 DNA 环化作用于同一条染色体的自身基因**——"增强子'远程但不跨界'"。

## 4 转录后、翻译水平调控与疾病

**转录后调控**：**可变剪接**（组织特异）、mRNA 稳定性（poly(A) 尾、miRNA 结合 3' UTR 促降解/抑翻译）、RNA 编辑。

**翻译水平调控**：起始因子磷酸化（eIF2α 磷酸化→整体翻译抑制——应激时）、铁蛋白/转铁蛋白受体的**铁响应元件（IRE）**调控（铁多时铁蛋白翻译↑、受体降解）。

**基因表达异常与疾病**：

**肿瘤**：癌基因过表达（Myc 扩增）、抑癌基因失活（p53 突变、RB 缺失）——"癌症是基因表达失控的病"。
**发育异常**：Hox 基因（体节发育）、转录因子突变（先天性缺陷）。
**血液病**：血红蛋白基因表达切换（胚胎→胎儿→成人珠蛋白）异常→地中海贫血。**药物**：靶向转录/表观（表观遗传药）或转录因子（激素治疗）。<span class="marginnote"><strong>miRNA 的"调控后手"</strong>：miRNA 结合 mRNA 3' UTR→降解或抑翻译（"基因表达的微调"）——一个 miRNA 调控数百 mRNA，参与肿瘤（抑癌/致癌 miRNA）。<strong>铁代谢的 IRE 调控</strong>：铁缺乏时转铁蛋白受体 mRNA 稳定（多受体）、铁蛋白 mRNA 被抑制（少储铁）；铁多时相反——"一 '元素'（铁）同时调两个基因"。<strong>肿瘤的"基因表达失控"</strong>：癌基因（促进增殖的基因）被异常激活、抑癌基因（p53、RB）失活→增殖失控——"肿瘤是调控网络崩溃的疾病"（病理学肿瘤篇详述）。<strong>血红蛋白的珠蛋白转换</strong>（ε→γ→β）是"基因表达程序"的发育例（地中海贫血与 β-珠蛋白表达相关）。</span>

**可变剪接的组织特异性**：同一前体 mRNA 在不同组织可剪接出不同蛋白（如肌钙蛋白 T、神经细胞黏附分子 NCAM）——"一个基因多种蛋白"。剪接异常可致疾病（如脊髓性肌萎缩 SMA 的 SMN 基因剪接缺陷），而**反义寡核苷酸（ASO）调节剪接**（诺西那生治疗 SMA）正是"以剪接为靶"的疗法。

**以基因表达调控为靶的疾病治疗**：除表观遗传药与剪接调节剂外，**siRNA/miRNA 类药物**（如脂质体包裹的 siRNA 治疗转甲状腺素蛋白淀粉样变）直接在 mRNA 层面"关闭"致病基因——"调控 RNA 的药物治疗时代"。

## 5 核心对比表：原核 vs 真核基因表达调控

| 对比项 | 原核 | 真核 |
| --- | --- | --- |
| 主要调控水平 | 转录（操纵子） | 转录+表观+转录后+翻译 |
| 转录单位 | 多顺反子（操纵子） | 单顺反子 |
| 调控元件 | 启动子+操纵基因 | 启动子+增强子+沉默子 |
| 染色质 | 无 | 有（表观遗传） |
| 转录与翻译 | 偶联 | 分离（核/胞质） |
| 经典模型 | 乳糖操纵子 | TF 组合+表观遗传 |

## 6 术语速查

| 术语 | 含义 |
| --- | --- |
| 操纵子 | 原核多顺反子转录单元（结构基因+调控序列） |
| 阻遏蛋白 | 结合操纵基因、关闭转录的调节蛋白 |
| 诱导物 | 使阻遏蛋白失活、开启转录的小分子（如异乳糖） |
| 顺式元件 | DNA 上调控自身基因转录的序列（启动子、增强子） |
| 反式因子 | 结合顺式元件起调控作用的蛋白（转录因子） |
| 增强子 | 远离启动子、经 DNA 环化增强转录的序列 |
| DNA 甲基化 | CpG 胞嘧啶甲基化，通常沉默基因 |
| 组蛋白乙酰化 | 松解染色质，通常激活转录 |
| 可变剪接 | 同一前体 mRNA 剪出多种蛋白 |
| 表观遗传 | 不改变序列但可遗传、可逆的表达调控 |
| ChIP-seq | 定位组蛋白修饰/转录因子结合位点的技术 |
| 亮氨酸拉链 | 转录因子 DNA 结合域的结构模体 |
| 基因组印记 | 父/母源等位基因差异甲基化表达 |

## 7 小结

- **原核**：**乳糖操纵子**（诱导+CAP-cAMP 双开关）——"按需表达"。
- **真核转录调控**：**顺式元件**（启动子、增强子、沉默子）+**转录因子**（组合调控）——细胞分化的本质是 TF 组合选择。
- **表观遗传**：**DNA 甲基化**（沉默）、**组蛋白乙酰化/甲基化**（激活/沉默）、染色质重塑、非编码 RNA——可逆、可遗传，异常→肿瘤。
- 转录后/翻译水平也有调控（可变剪接、miRNA、IRE）；基因表达失控→肿瘤、发育异常、血液病。
- **trp 操纵子**（可阻遏）与乳糖操纵子（可诱导）方向相反——"产物多就关/底物来才开"。
- **表观遗传药**：去甲基化药（阿扎胞苷）、HDAC 抑制剂（伏立诺他）——"重新打开沉默基因"。
- **剪接也是靶点**：ASO 调节剪接（诺西那生治 SMA）；siRNA 类药物在 mRNA 层面关闭致病基因。

在下一节，我们看研究基因表达的"工具箱"——**分子生物学技术**：PCR、DNA 测序、克隆、印迹杂交、基因编辑与基因工程的应用。
