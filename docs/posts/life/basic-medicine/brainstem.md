## 为什么从脑干开始

**脑干（brain stem）**位于脊髓与间脑之间，自下而上由**延髓、脑桥、中脑**三部分组成。它同时承担三重任务：传导（脊髓与高级中枢之间的干线）、反射（生命中枢与多种反射中枢）、以及脑神经的根（第 Ⅲ～Ⅻ 对脑神经大多与脑干相连）。<span class="marginnote">脑干是"生命的底盘"：延髓内含心血管中枢与呼吸中枢（"生命中枢"），损伤可致心跳呼吸骤停。脑干同时也是脑神经核的集中地——脑神经的定位诊断（哪些核受损）几乎都要落到脑干。</span>

"脑干损伤为什么危险""中脑的动眼神经核损伤为什么瞳孔散大""延髓麻痹（球麻痹）与假性球麻痹如何区分"——脑干的解剖回答这些问题。

## 1 脑干的外形

**延髓（medulla oblongata）**：锥形，上接脑桥、下续脊髓。腹面正中为**前正中裂**，其两侧有锥体（皮质脊髓束所在），锥体下部纤维交叉形成**锥体交叉**（锥体束在此左右交叉——运动交叉的关键位置）。延髓背面上部构成菱形窝（第四脑室底）的下半。<span class="marginnote">延髓的"锥体交叉"是运动传导的咽喉：皮质脊髓束在锥体下部约 2/3 交叉，交叉后下行于外侧索。所以一侧大脑半球的运动支配对侧肢体——左侧脑卒中→右侧偏瘫。延髓还含薄束核、楔束核（本体觉第二级换元站）与下橄榄核。</span>

**脑桥（pons）**：腹面膨隆，为脑桥基底部（含皮质脊髓束与脑桥核），背侧面为菱形窝上半。脑桥与延髓交界处的横沟是**延髓脑桥沟**——第Ⅵ、Ⅶ、Ⅷ对脑神经由此出脑。

**中脑（midbrain）**：最短，腹面有**大脑脚**（含皮质脊髓束下行），背侧有**上丘**（视觉反射中枢）与**下丘**（听觉反射中枢），合称**顶盖**。中脑内有**中脑导水管**（连接第三、第四脑室）。<span class="marginnote">上丘与下丘分别是视、听反射的"快速通道"：上丘使眼球转向视觉刺激来源、下丘使头转向声源。中脑导水管狭窄（先天）→梗阻性脑积水。中脑的"红核"与"黑质"是锥体外系的重要核团——黑质（含多巴胺神经元）变性是帕金森病的病理基础（在间脑与基底核中还会展开）。</span>

## 2 脑干的内部结构：脑神经核

脑干内灰质团块排列成**脑神经核**（柱），按功能分**运动核**（躯体运动核、内脏运动核）与**感觉核**（躯体感觉核、内脏感觉核）。脑神经核与脑神经的对应是脑干学习的核心：

| 脑神经 | 起/止的核 | 功能 |
| --- | --- | --- |
| Ⅲ 动眼神经 | 动眼神经核（中脑）、E-W 核 | 眼外肌、缩瞳 |
| Ⅳ 滑车神经 | 滑车神经核（中脑） | 上斜肌 |
| Ⅴ 三叉神经 | 三叉神经运动核、三叉神经感觉核（脑桥） | 咀嚼肌、面感觉 |
| Ⅵ 展神经 | 展神经核（脑桥） | 外直肌 |
| Ⅶ 面神经 | 面神经核、上泌涎核、孤束核（脑桥） | 表情肌、腺体、味觉 |
| Ⅷ 前庭蜗神经 | 前庭神经核、蜗神经核（脑桥延髓） | 平衡、听觉 |
| Ⅸ 舌咽神经 | 疑核、下泌涎核、孤束核（延髓） | 咽肌、味觉 |
| Ⅹ 迷走神经 | 疑核、迷走神经背核、孤束核（延髓） | 咽喉、内脏 |
| Ⅺ 副神经 | 副神经核（延髓、脊髓） | 胸锁乳突肌、斜方肌 |
| Ⅻ 舌下神经 | 舌下神经核（延髓） | 舌肌 |

**脑干内的网状结构**：脑干中央区灰白质交织的网络，含**网状上行激动系统**（维持觉醒——损伤致昏迷）与心血管、呼吸中枢（延髓）。<span class="marginnote">脑干网状结构是"意识"的开关：网状上行激动系统把信号广泛投射到大脑皮层，维持清醒状态；巴比妥类中毒、脑干损伤抑制该系统→昏迷。呼吸中枢（延髓）与心血管中枢（延髓）合称"生命中枢"——延髓损伤（如枕骨大孔疝）立即危及生命。</span>

## 3 脑干的传导通路

脑干是上下行传导束的必经之路，也包含重要的**交叉**：

**皮质脊髓束**：经大脑脚→脑桥基底部→延髓锥体→**锥体交叉**（大部分交叉至对侧）→脊髓外侧索。
**皮质核束**：支配脑神经运动核（大部分双侧支配，但面神经核下部、舌下神经核只受对侧支配——这解释了中枢性面瘫"额纹保留"）。
**脊髓丘脑束**：上行经脑干外侧→**内侧丘系**（由薄束核、楔束核发出的本体觉纤维在延髓交叉后形成）→丘脑。
**三叉丘系**：头面部痛温觉与触觉经三叉神经→三叉神经脊束核/脑桥核→交叉→三叉丘系→丘脑。<span class="marginnote">脑干病变的定位靠"交叉综合征"：一侧脑干损伤出现<strong>同侧脑神经症状 + 对侧肢体症状</strong>（因脑神经核大多在同侧、而传导束已交叉或将要交叉）。如<strong>延髓背外侧综合征（Wallenberg 综合征，小脑后下动脉闭塞）</strong>：眩晕、吞咽困难、声音嘶哑（ⅨⅩ受损）+ 同侧面部痛温觉丧失 + 对侧肢体痛温觉丧失——这是脑干定位的经典病例。</span>

## 4 核心对比表：脑干三部

| 分部 | 位置 | 腹面标志 | 背面具标志 | 关键核团/结构 |
| --- | --- | --- | --- | --- |
| 延髓 | 最下 | 锥体、锥体交叉 | 菱形窝下半 | 生命中枢、薄束核楔束核 |
| 脑桥 | 中 | 脑桥基底部 | 菱形窝上半 | 三叉、展、面神经核 |
| 中脑 | 最上 | 大脑脚 | 上丘、下丘 | 动眼滑车核、黑质红核 |

**辨析｜易错点：** "锥体交叉"与"内侧丘系交叉"都在延髓但位置不同：**锥体交叉在延髓腹侧**（运动纤维交叉），**内侧丘系交叉在延髓中央**（本体觉纤维交叉）。另一个易错点：**脑神经核的"面神经核下部与舌下神经核只受对侧皮质核束支配"**——这是中枢性面瘫（额纹保留）与中枢性舌瘫（伸舌偏向病灶对侧）的解剖学原因。

## 5 数值算例：脑干损伤的定位逻辑

**"交叉综合征"的定量判断**：一侧脑干损伤时，同侧脑神经受累（因脑神经核在同侧），而对侧肢体与躯干受累（因传导束已交叉或在此交叉）。这条规律可以直接用来定位：

| 症状组合 | 损伤部位 | 典型例子 |
| --- | --- | --- |
| 同侧动眼神经麻痹 + 对侧肢体瘫痪 | 中脑（大脑脚） | Weber 综合征 |
| 同侧面神经麻痹 + 对侧肢体瘫痪 | 脑桥（基底部） | Millard-Gubler 综合征 |
| 同侧舌下神经瘫 + 对侧肢体瘫痪 | 延髓（锥体+舌下神经根） | 舌下神经交叉瘫 |
| 同侧面部痛温觉丧失 + 对侧肢体痛温觉丧失 + 眩晕吞咽困难 | 延髓外侧（小脑后下动脉） | Wallenberg 综合征 |

**辨析｜易错点：** "延髓损伤一定立刻死亡"是夸大的说法——延髓的生命中枢（呼吸、心血管）损伤确实致命，但延髓外侧（Wallenberg）损伤时生命中枢多可保留，患者虽症状重却未必立刻死亡。另一个易错点：**脑神经核的"躯体运动核"多在脑干内不交叉，接受皮质核束的双侧支配**——但面神经核下半与舌下神经核只接受对侧皮质核束，故一侧皮质核束损伤只出现对侧下半面瘫（额纹保留）与对侧舌瘫（伸舌偏对侧），这是"中枢性 vs 周围性面瘫"的鉴别点。

**生命体征的定量意义**：脑干受压（如脑疝）时出现呼吸节律改变（潮式呼吸→中枢性过度通气→呼吸暂停），血压升高、心率减慢（Cushing 反射）——"血压升、心率慢、呼吸乱"三联征提示颅内压急剧升高并压迫脑干，是神经外科急症的信号。

## 6 临床联系：脑干综合征与神经系统检查

**脑干损伤的常见原因**：脑外伤（脑干挫伤）、脑出血（脑桥出血）、梗死（椎基底动脉系统）、脑疝（枕骨大孔疝压迫延髓）。脑干出血/梗死的"针尖样瞳孔"（脑桥出血）与"针尖样瞳孔伴高热"是神经科急症的特征性表现。<span class="marginnote">"针尖样瞳孔"（<strong>脑桥出血</strong>损伤双侧交感下行纤维）与"一侧瞳孔散大"（<strong>中脑动眼神经损伤</strong>，见于颞叶钩回疝）形成鉴别——"瞳孔看脑干"是神经查体的第一课。脑疝压迫脑干是致死性的，抢救争分夺秒。</span>

**脑干的反射检查**：**角膜反射**（三叉神经传入+面神经传出，脑桥）与**瞳孔对光反射**（传入视神经+传出动眼神经，中脑）是判断脑干功能的重要反射。深昏迷时这些反射消失提示脑干功能衰竭——"脑干死亡"的判定要依据脑干反射消失。<span class="marginnote">脑死亡的临床判定包括：深昏迷、脑干反射全部消失（瞳孔对光、角膜、头眼、前庭眼反射等）、无自主呼吸（需呼吸机维持）——脑干反射检查是其中的核心。理解每个反射的"传入-中枢-传出"通路，就理解为什么这些反射能反映脑干功能。</span>

**延髓麻痹 vs 假性球麻痹**：**延髓麻痹（真性球麻痹）**——延髓运动核（ⅨⅩⅫ）本身受损，舌肌萎缩、咽反射消失；**假性球麻痹**——皮质核束双侧受损，舌肌不萎缩、咽反射存在或亢进、伴强哭强笑。两者的鉴别要点是"有无肌萎缩、咽反射是否消失"。

| 术语 | 定义 |
| --- | --- |
| 延髓（medulla） | 脑干最下段，含生命中枢与锥体交叉 |
| 脑桥（pons） | 脑干中部，腹面膨隆，含三叉展面神经核 |
| 中脑（midbrain） | 脑干最上段，含大脑脚、上丘下丘、动眼滑车核 |
| 锥体交叉 | 皮质脊髓束在延髓腹侧的交叉 |
| 内侧丘系 | 薄束核楔束核发出的本体觉纤维在延髓交叉后上行 |
| 菱形窝 | 第四脑室底，由脑桥背面与延髓背面构成 |
| 网状上行激动系统 | 脑干网状结构上行维持觉醒的系统 |
| 生命中枢 | 延髓内的心血管与呼吸中枢 |
| Wallenberg 综合征 | 延髓背外侧（小脑后下动脉）梗死的综合征 |

**易错点复习：** 脑干三段的记忆锚点——"锥体交叉在延髓、菱形窝上半归脑桥、上丘下丘属中脑"；脑神经核与脑神经的对应（ⅢⅣ在中脑、ⅤⅥⅦⅧ在脑桥、ⅨⅩⅪⅫ在延髓）是脑干定位的骨架。记不住时从"中脑管眼球（动眼滑车）、脑桥管面部（三叉展面）、延髓管咽喉舌（舌咽迷走副舌下）"这条功能线入手。

## 8 小结

- **脑干**由延髓、脑桥、中脑组成，是脑神经（Ⅲ~Ⅻ）的码头、传导束的干线、生命中枢（延髓呼吸循环中枢）的所在。
- **延髓**：锥体交叉（运动交叉）、薄束楔束核、生命中枢；**脑桥**：三叉展面神经核；**中脑**：动眼滑车核、上丘下丘、黑质红核。
- 脑神经核按功能分运动核与感觉核，其与脑神经的对应关系是脑干学习的骨架。
- 一侧脑干损伤呈**交叉综合征**（同侧脑神经症状+对侧肢体症状），是脑干定位诊断的核心。
- **数值与临床锚点**：锥体交叉在延髓腹侧、内侧丘系交叉在延髓中央；中脑管动眼滑车、脑桥管三叉展面、延髓管舌咽迷走副舌下；脑干受压时"血压升、心率慢、呼吸乱"（Cushing 反射）是急症信号。

**一句话总结本篇**：脑干是"生命底盘+神经码头"——延髓管生命（呼吸循环）与锥体交叉，脑桥管面部（三叉展面神经），中脑管眼球（动眼滑车）与视听反射（上丘下丘）；一侧脑干损伤呈"同侧脑神经+对侧肢体"的交叉综合征。把三段、三交叉、脑神经核分布这三张图记牢，脑干就掌握了。

**自测三问**：①锥体交叉与内侧丘系交叉分别在延髓哪一侧？②一侧脑桥损伤为什么出现"同侧脑神经+对侧肢体"症状？③延髓麻痹与假性球麻痹如何用"舌肌萎缩、咽反射"鉴别？——能答出这三问，脑干的核心考点就掌握了；答不出则回到"脑干三段、三交叉、脑神经核分布"三张图对照复习。
