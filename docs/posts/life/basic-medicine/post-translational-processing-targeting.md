## 为什么从翻译后加工与靶向开始

多肽链在核糖体合成后，还必须**折叠**成正确构象、接受**翻译后修饰**（糖基化、磷酸化、二硫键等）、并被**分拣运输**到正确位置（胞质、线粒体、内质网/高尔基体/分泌、膜）。这一"蛋白质的就业培训与派遣"即**翻译后加工与靶向（post-translational processing and targeting）**。<span class="marginnote">核心概念：<strong>蛋白质折叠</strong>（分子伴侣帮助）、<strong>翻译后修饰</strong>（磷酸化、糖基化、二硫键、蛋白水解）、<strong>信号肽（signal peptide）</strong>与<strong>蛋白质分拣</strong>（共翻译进入内质网 vs 翻译后进入线粒体）、<strong>错误折叠与质量控制</strong>（泛素-蛋白酶体、未折叠蛋白反应）。</span>

"分泌蛋白怎么'坐船'到细胞外""分子伴侣是干什么的""帕金森病为什么与蛋白降解有关"——翻译后加工与靶向回答这些问题。

## 1 蛋白质折叠与分子伴侣

**蛋白质折叠（protein folding）**：多肽链在合成过程中/后折叠成天然构象（一级结构决定高级结构）。**分子伴侣（molecular chaperone）**帮助正确折叠、防止错误聚集：

**热休克蛋白（HSP70、HSP90）**：结合未折叠蛋白、帮助折叠。
**伴侣素（chaperonin，如 GroEL/TRiC）**：提供"折叠笼"，隔离折叠中间体。
分子伴侣在**应激（热休克）**时上调（"热休克蛋白"）——保护细胞免受蛋白变性损伤。

### 折叠是"能量漏斗"，不是一步到位

**Anfinsen 实验**（核糖核酸酶复性实验）证明：去折叠的酶在适当条件下能**自发恢复天然构象**，说明折叠信息全在氨基酸序列里——"一级结构决定高级结构"。但细胞内蛋白浓度高、拥挤（分子拥挤效应），新生肽的**疏水区**极易彼此聚集，因此单靠自发折叠不够，必须靠分子伴侣"护航"。<span class="marginnote"><strong>能量地形图（folding funnel）</strong>：把折叠想象成一颗珠子滚进漏斗——纵轴是自由能，横轴是构象自由度。顶部是无数种去折叠构象，底部是唯一的天然构象；漏斗壁的"锯齿"是局部能量陷阱，分子伴侣的作用就是"把珠子从陷阱里捞回来"。拥挤的细胞环境让聚集成为主要风险，这正是<strong>分子伴侣必需存在</strong>的原因。</span>

**折叠失败→错误折叠蛋白→聚集→疾病**（见蛋白质结构与功能篇的构象病）。<span class="marginnote"><strong>分子伴侣是"蛋白折叠的辅导员"</strong>：新生肽链疏水区暴露→易聚集——HSP70 等"抱住"未折叠蛋白给折叠时间；伴侣素（GroEL "桶"）提供隔离空间让蛋白在笼内折叠。<strong>热休克反应</strong>：高温/应激→蛋白变性→热休克蛋白↑→"修复变性蛋白"（细胞应激保护）。<strong>错误折叠的后果</strong>：错误折叠蛋白积累→<strong>聚集/淀粉样变</strong>→阿尔茨海默（Aβ、tau）、帕金森（α-突触核蛋白）、亨廷顿（polyQ）——"蛋白稳态（proteostasis）失衡是神经退行的核心"（呼应蛋白质结构与功能篇的构象病）。</span>

## 2 翻译后修饰

**翻译后修饰（post-translational modification, PTM）**种类繁多：

**磷酸化**：蛋白激酶在 Ser/Thr/Tyr 加磷酸——**信号转导与酶活性调节**（最普遍的调节性修饰，见酶调节篇）。
**糖基化**：在内质网/高尔基体加糖链——分泌蛋白与膜蛋白（糖蛋白）；影响折叠、稳定性、识别（血型抗原）。
**二硫键形成**：半胱氨酸氧化形成 -S-S-——稳定分泌蛋白结构（胰岛素、抗体）。
**蛋白水解**：酶原激活（切除肽段）、前体蛋白加工（胰岛素原→胰岛素、前胶原→胶原）。
**脂酰化**（棕榈酰化、法尼基化）：膜锚定（Ras 蛋白）。
**泛素化**：标记蛋白→蛋白酶体降解（"蛋白的死刑标记"）。

### N-糖基化与 O-糖基化的分工

糖基化分两种主要类型，考点常考其区别：<span class="marginnote"><strong>N-糖基化</strong>：糖链连到<strong>天冬酰胺（Asn）</strong>侧链的 N 上，发生在<strong>内质网</strong>，是分泌/膜蛋白"共翻译"时的标配。<strong>O-糖基化</strong>：糖链连到<strong>丝氨酸/苏氨酸（Ser/Thr）</strong>的羟基 O 上，主要发生在<strong>高尔基体</strong>。记忆口诀："N 在 N 端附近（Asn）+ 内质网；O 在 Ser/Thr 侧链 + 高尔基"。</span>两者都影响糖蛋白的折叠稳定性与细胞识别，但发生位置、连接残基不同——糖基化是蛋白质的"身份证"（血型抗原 A/B 就是红细胞膜糖蛋白上糖链的差异）。

**信号肽的切除**：分泌蛋白合成时 N 端有**信号肽**（引导进入内质网），进入后被**信号肽酶**切除。<span class="marginnote"><strong>磷酸化</strong>是"开关"（激酶/磷酸酶）、<strong>糖基化</strong>是"身份证"（膜蛋白/分泌蛋白）、<strong>二硫键</strong>是"加固"（分泌蛋白）、<strong>蛋白水解</strong>是"激活"（酶原、胰岛素原→胰岛素——"前体加工"）、<strong>泛素化</strong>是"标记死亡"（→26S 蛋白酶体降解）。<strong>胰岛素原→胰岛素</strong>的加工（切除 C 肽）是"蛋白水解激活"的经典——C 肽是胰岛素合成的标志物。<strong>糖基化异常</strong>（IgA 肾病、糖化血红蛋白 HbA1c——血糖高时血红蛋白糖化）有临床意义。</span>

### 磷酸化为何能"一石激起千层浪"

磷酸化在信号转导中的威力来自**级联放大（cascade）**：一个上游激酶磷酸化并激活下游激酶，下游又磷酸化更多靶蛋白。<span class="marginnote"><strong>级联的数学</strong>：若每级放大 10 倍、走 5 级，信号可放大到 \(10^5\) 倍——一个激素分子结合受体，最终可激活海量效应分子。这就是"肾上腺素只需极低浓度就能调动全身"的生化基础。考点：<strong>激酶（kinase）加磷</strong>，<strong>磷酸酶（phosphatase）去磷</strong>——"加磷激活、去磷关闭"，是酶的调节章节与信号通路章节的公共语言。</span>由于磷酸基团带负电，磷酸化还能改变蛋白的电荷与构象，直接影响其活性或与配体的亲和力——"一价磷酸，多重后果"。

## 3 蛋白质的靶向运输

**蛋白质分拣（protein targeting）**——新合成蛋白去向何方：

**游离核糖体合成**（胞质蛋白）：留在胞质、入核（核定位信号 NLS）、入线粒体/过氧化物酶体（翻译后转运）。
**粗面内质网核糖体合成**（分泌/膜/溶酶体蛋白）：**共翻译转运**——N 端**信号肽（signal peptide）**被 **SRP（信号识别颗粒）**识别→核糖体停靠内质网→信号肽进入膜→蛋白边翻译边进入内质网腔→（信号肽切除）→内质网加工（糖基化、二硫键）→高尔基体→分泌囊泡→细胞外/膜/溶酶体。

**经典的"分泌路径"**：**内质网→高尔基体→囊泡→细胞外**（"分泌蛋白的流水线"）。<span class="marginnote"><strong>信号肽是"邮政编码"</strong>：N 端一段疏水序列（约 15~30 aa）被 <strong>SRP</strong> 识别→把核糖体"停靠"到内质网→新生肽进入内质网腔——<strong>共翻译转运</strong>（边翻译边进内质网）。<strong>核定位信号（NLS）</strong>让胞质蛋白进入核内（经核孔复合体）。<strong>线粒体蛋白</strong>是翻译后转运（信号肽引导、需分子伴侣）。<strong>内质网-高尔基体-分泌</strong>是分泌蛋白（抗体、胰岛素、消化酶）的"高速公路"——<strong>内质网是折叠与质检站</strong>（未折叠蛋白反应 UPR：错误折叠堆积→UPR 信号→折叠/降解/凋亡）。</span>

**分拣错误的临床案例——囊性纤维化**：CFTR 蛋白（氯离子通道）最常见的突变 **ΔF508** 使其**错误折叠**，被内质网质检扣留并降解，导致氯离子转运障碍、黏液稠厚。

**内质网不是单向流水线**：分泌路径存在"回收机制"。内质网驻留蛋白（如 BiP/GRP78）C 端带有 **KDEL 信号**，当它们被囊泡"误带走"到高尔基体时，会被高尔基体上的 KDEL 受体识别并**逆转运**回内质网。<span class="marginnote"><strong>KDEL 是"回程车票"</strong>：分泌是顺行（内质网→高尔基体），而 KDEL 回收是逆行（高尔基体→内质网）——这提醒我们"分拣"不是单向的，而是一套<strong>双向的物流系统</strong>。掌握"顺行=分泌、逆行=回收"这对概念，才真正理解内膜系统的循环本质。</span><span class="marginnote"><strong>ΔF508 的启示</strong>：CFTR 缺失第 508 位苯丙氨酸→蛋白折叠失败→被 ERAD 降解，细胞膜上<strong>几乎没有</strong>CFTR 通道。这提示"折叠+质检+降解"不是三个孤立过程，而是一条完整流水线——<strong>折叠是膜蛋白上膜的前提</strong>。I 细胞病（黏脂贮积症Ⅱ型）则是溶酶体酶缺乏"甘露糖-6-磷酸"分拣信号，被错误分泌到细胞外——"分拣信号丢了，货物送错了站"。</span>

## 4 蛋白质降解与质量控制

**蛋白质降解（protein degradation）**——"蛋白的寿命管理"：

**泛素-蛋白酶体途径（ubiquitin-proteasome）**：泛素（Ub）标记蛋白→26S 蛋白酶体降解——降解**胞质/核蛋白**（调控蛋白、错误折叠蛋白）。
**溶酶体途径（autophagy/内吞）**：长寿命蛋白、细胞器经溶酶体降解。

**质量控制（quality control）**：内质网中错误折叠蛋白被识别→返回胞质→泛素化→蛋白酶体降解（**内质网相关降解 ERAD**）——"质检不合格就销毁"。

**细胞自噬（autophagy）**是另一条"大件回收"路线：细胞器与长寿命蛋白被自噬体包裹→与溶酶体融合→降解。它既是饥饿时的营养动员，也是清除损伤线粒体、错误蛋白聚集体的手段——"泛素-蛋白酶体管小件，自噬管大件"。

**临床联系**：**多发性骨髓瘤**用**硼替佐米（蛋白酶体抑制剂）**（浆细胞高度依赖蛋白降解→抑制→凋亡）；帕金森病（α-突触核蛋白聚集+降解障碍）。<span class="marginnote"><strong>泛素-蛋白酶体是"蛋白的碎纸机"</strong>：泛素连成链标记蛋白（E1 激活-E2 结合-E3 连接）→26S 蛋白酶体把蛋白"切碎"（降解为肽）——<strong>调控蛋白（周期蛋白、转录因子）的定时降解</strong>是细胞周期与信号的关键。<strong>ERAD</strong>：内质网质检→错误折叠蛋白"回炉销毁"（逆转运到胞质→泛素化→降解）——"内质网的废品回收"。<strong>硼替佐米（万珂）</strong>抑制蛋白酶体→骨髓瘤细胞（大量分泌免疫球蛋白、依赖蛋白降解）→应激凋亡——"靶向蛋白降解的抗癌药"（一线治多发性骨髓瘤）。</span>

## 5 核心对比表：蛋白质的三种"去向"

| 合成位置 | 靶向 | 例子 | 机制 |
| --- | --- | --- | --- |
| 游离核糖体 | 胞质/核/线粒体 | 胞质酶、组蛋白 | 翻译后转运（NLS 等） |
| 粗面内质网 | 分泌/膜/溶酶体 | 抗体、胰岛素 | 信号肽+SRP 共翻译转运 |

## 6 术语速查表

| 术语 | 含义 |
| --- | --- |
| SRP | 信号识别颗粒，识别信号肽并停靠核糖体到内质网 |
| ERAD | 内质网相关降解，质检不合格蛋白逆转运回胞质降解 |
| UPR | 未折叠蛋白反应，内质网应激时的自救/凋亡信号 |
| Anfinsen 实验 | 核糖核酸酶复性实验，证明一级结构决定高级结构 |
| ΔF508 | CFTR 最常见突变，折叠失败被 ERAD 降解 |
| 分子拥挤 | 细胞内蛋白高浓度的物理环境，催生分子伴侣需求 |
| KDEL 信号 | 内质网驻留蛋白的"回程车票"，被逆转运回内质网 |
| 级联放大 | 激酶逐级磷酸化激活，信号可放大 \(10^5\) 倍 |
| 分子伴侣 | 帮助折叠、防止聚集的蛋白（HSP70、GroEL 等） |
| 蛋白稳态 | proteostasis，细胞维持蛋白正确折叠与浓度的总调控 |

**辨析｜易错点：** 共翻译转运（信号肽+SRP，入内质网）与翻译后转运（NLS 入核、线粒体蛋白）最常混淆——记忆"分泌/膜/溶酶体蛋白走 SRP 码头，核/线粒体蛋白自己买票进站"。另一易错点：**信号肽在进入内质网后被切除**，成熟蛋白里已无信号肽——"信号肽是临时的通行证"。

## 7 小结

- **蛋白质折叠**：分子伴侣（HSP70、伴侣素）帮助；错误折叠→聚集→构象病（阿尔茨海默、帕金森）。
- **翻译后修饰**：磷酸化（开关）、糖基化（身份）、二硫键（加固）、蛋白水解（激活，胰岛素原→胰岛素）、泛素化（降解标记）。
- **靶向运输**：分泌/膜蛋白经**信号肽+SRP**共翻译入内质网→高尔基体→分泌；核蛋白靠 NLS；线粒体蛋白翻译后转运。
- **蛋白质降解**：泛素-蛋白酶体（胞质蛋白、错误折叠）+溶酶体；蛋白酶体抑制剂（硼替佐米）治骨髓瘤。
- 折叠、质检、降解是一条流水线：ΔF508 因折叠失败而整体崩坏，是"加工与靶向"联动的缩影。
- 分拣是双向物流：顺行分泌（内质网→高尔基体）与 KDEL 逆行回收并存——"有去有回"才是完整的内膜系统。
- N-糖基化在内质网连 Asn、O-糖基化在高尔基体连 Ser/Thr——修饰"身份证"的两个常见考点。
- 硼替佐米抑制蛋白酶体杀骨髓瘤细胞——"蛋白质机器"是抗癌药的合法靶点。

在下一节，我们看基因如何被"开关"控制——**基因表达调控**：原核的乳糖操纵子、真核的转录调控与表观遗传、以及"细胞分化是基因表达的选择"。
