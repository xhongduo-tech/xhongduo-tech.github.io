## 为什么从癌与肉瘤开始

恶性肿瘤按组织来源分**癌（carcinoma，上皮）**与**肉瘤（sarcoma，间叶）**——两者在**发病率、年龄、生长转移方式、大体镜下形态**都有差异。理解癌与肉瘤的区别，是病理诊断与临床处理（癌淋巴转移、肉瘤血行转移）的基础。<span class="marginnote"><strong>癌（carcinoma）</strong>：上皮组织来源（皮肤、黏膜、腺体）——<strong>占恶性肿瘤 80% 以上</strong>，好发<strong>中老年</strong>，<strong>淋巴道转移为主</strong>。<strong>肉瘤（sarcoma）</strong>：间叶组织来源（纤维、脂肪、骨、肌肉、血管）——少见，好发<strong>青少年</strong>，<strong>血行转移为主</strong>（→肺）。<strong>"癌"与"肉瘤"的称呼</strong>即来源指示（见良恶性篇命名）。</span>

"为什么癌比肉瘤常见""骨肉瘤为什么'青少年+肺转移'""'癌肉瘤'是什么"——癌与肉瘤回答这些问题。

## 1 癌与肉瘤的详细对比

**癌（carcinoma）vs 肉瘤（sarcoma）**：

| 对比项 | 癌 | 肉瘤 |
| --- | --- | --- |
| 组织来源 | 上皮（表皮、腺上皮） | 间叶（纤维、骨、肌肉、脂肪） |
| 发病率 | 高（占恶性 80%+） | 低（约 1/10） |
| 好发年龄 | 中老年（40+） | 青少年（骨肉瘤） |
| 大体 | 质硬、灰白（纤维间质多） | 质软、鱼肉样（细胞丰富） |
| 镜下 | 癌细胞巢、间质分隔 | 肉瘤细胞弥漫分布 |
| 转移 | 淋巴道为主（晚期血行） | **血行为主**（→肺） |
| 常见 | 肺鳞癌、胃腺癌、乳腺导管癌 | 骨肉瘤、脂肪肉瘤、平滑肌肉瘤 |

**癌的"细胞巢"**：癌细胞聚集成**巢（nest）**状，被纤维间质分隔——"癌的镜下特征"。
**肉瘤的"弥漫"**：肉瘤细胞弥漫分布（细胞多、间质少）——"鱼肉样（sarco=flesh）"。

**癌前病变**是"癌的土壤"，值得单独列一张清单——它是筛查与早期干预的抓手：

| 器官 | 癌前病变 | 可防的癌 |
| --- | --- | --- |
| 宫颈 | 宫颈上皮内瘤变（CIN） | 宫颈癌 |
| 结肠 | 腺瘤性息肉 | 结直肠癌 |
| 胃 | 萎缩性胃炎伴肠化 | 胃癌 |
| 食管 | Barrett 食管 | 食管腺癌 |
| 肝 | 肝硬化 | 肝细胞癌 |
| 皮肤 | 日光性角化 | 鳞癌 |

把这张表与《消化道肿瘤》篇的"癌前病变各不同"对照看，会发现同一逻辑反复出现：**化生/增生/硬化都是"慢性损伤→癌变"的中间站**，而筛查的价值正在于"在中间站拦住它"。<span class="marginnote"><strong>癌与肉瘤的"四句对照"</strong>：<strong>癌上皮、肉瘤间叶；癌中老年、肉瘤青少年；癌淋巴、肉瘤血行；癌硬（巢+间质）、肉瘤软（弥漫细胞）</strong>。<strong>癌的"细胞巢"</strong>：上皮性肿瘤细胞聚集成巢（"癌巢"），间质分隔——病理镜下识别癌的关键。<strong>肉瘤的"鱼肉样"</strong>：肉瘤细胞弥漫、间质少、质软（"sarcoma"源自希腊语"肉"）——"骨肉瘤是青少年最常见的原发性骨恶性肿瘤（好发股骨下端、胫骨上端，血行转移肺）"。<strong>癌肉瘤（carcinosarcoma）</strong>：同一肿瘤含癌与肉瘤两种成分（罕见、恶性度高）。</span>

## 2 常见的癌

**癌**按上皮类型分：

**鳞状细胞癌（squamous cell carcinoma, SCC）**：皮肤、口腔、食管、宫颈、肺（鳞状上皮/化生鳞状上皮）——高分化者见**角化珠（keratin pearl）**、细胞间桥。
**腺癌（adenocarcinoma）**：腺上皮（胃、结肠、乳腺、肺、胰腺）——形成**腺管结构**。
**移行细胞癌**：泌尿道（膀胱）移行上皮。
**基底细胞癌**：皮肤基底细胞——局部浸润、**极少转移**（"恶性但'温和'"）。
**小细胞癌**：肺小细胞癌（神经内分泌，恶性度高，副肿瘤综合征）。

**癌前病变→原位癌→浸润癌**的演变在癌中常见（宫颈、结肠、乳腺）。

各型癌的"识别标志"一表收好：

| 癌的类型 | 典型部位 | 镜下/临床特征 |
| --- | --- | --- |
| 鳞状细胞癌 | 皮肤、食管、宫颈 | **角化珠**、细胞间桥 |
| 腺癌 | 胃、结肠、乳腺、肺 | **腺管结构** |
| 移行细胞癌 | 膀胱、肾盂 | 尿路上皮来源 |
| 基底细胞癌 | 皮肤 | 浸润不转移（"温和的恶性"） |
| 小细胞癌 | 肺 | 恶性度高、副肿瘤综合征 |<span class="marginnote"><strong>常见癌的"分型看组织"</strong>：鳞癌（角化珠——"鳞癌的成熟标志"）、腺癌（腺管——"腺癌的'排排坐'"）、移行细胞癌（膀胱——"尿路上皮癌"）、基底细胞癌（<strong>浸润不转移</strong>——"皮肤癌里的'温顺者'"，但破坏局部）、小细胞癌（<strong>恶性度最高</strong>的肺癌亚型+副肿瘤综合征——ACTH 库欣、SIADH）。<strong>癌的"原位-浸润"</strong>（宫颈癌模型）：CIN（癌前）→原位癌→浸润癌——"宫颈癌筛查（TCT）发现癌前病变→干预防癌"（"宫颈癌是可防可治的癌"）。</span>

## 3 常见的肉瘤

**肉瘤（sarcoma）**按间叶组织分：

**骨肉瘤（osteosarcoma）**：青少年，股骨下端/胫骨上端，**血行转移肺**——"青少年骨痛的警惕"。
**软骨肉瘤**：中老年，骨盆、长骨。
**脂肪肉瘤**：软组织，腹膜后/大腿。
**平滑肌肉瘤**：子宫、胃肠道。
**横纹肌肉瘤**：儿童，头颈/泌尿。
**纤维肉瘤**、**血管肉瘤**、**尤文肉瘤**（儿童骨，EWSR1 基因融合）。

**肉瘤的特点**：生长快、血行转移早（→肺）、预后较差（但化疗敏感者如尤文肉瘤、骨肉瘤可治愈）。<span class="marginnote"><strong>肉瘤的"青少年骨痛"</strong>：<strong>骨肉瘤</strong>好发 10~25 岁、股骨下端干骺端——"青少年不明原因骨痛+肿块要警惕骨肉瘤"（X 线"日光放射"骨膜反应）；<strong>尤文肉瘤</strong>（儿童骨，t(11;22) EWSR1-FLI1 融合基因——"分子诊断的肉瘤代表"）。<strong>肉瘤的转移</strong>：<strong>血行→肺</strong>（"肉瘤肺转移"是主要死亡原因）。<strong>软组织肉瘤</strong>（脂肪肉瘤、平滑肌肉瘤）：腹膜后/四肢深部——"深部巨大软组织肿块要考虑肉瘤"。<strong>肉瘤的治疗</strong>：手术+化疗（骨肉瘤新辅助化疗显著改善生存）——"肉瘤虽凶但部分可治愈"。</span>

## 4 癌的分子机制与分级分期

**癌变的分子机制**（呼应信号转导与基因表达调控篇）：

**癌基因激活**（Ras、Myc、EGFR 扩增）、**抑癌基因失活**（p53、RB、PTEN）、凋亡逃逸（Bcl-2）。
**多步骤突变累积**（结肠癌 APC→K-Ras→p53 序列）。
**微环境**（血管生成、免疫逃逸）。

**癌的分级（grading）**：按分化程度（Ⅰ级高分化低度恶性→Ⅲ级低分化高度恶性）。

**癌的分期（staging，TNM）**：T 原发、N 淋巴结、M 转移——决定治疗与预后（见肿瘤生长与扩散篇）。

**分子靶向与免疫治疗**：EGFR 突变→TKI；HER2 过表达→曲妥珠单抗；PD-L1→免疫检查点抑制剂。<span class="marginnote"><strong>"癌症是基因病"</strong>：癌基因（油门）+抑癌基因（刹车）的异常（"踩油门+坏刹车"）——<strong>K-Ras 突变（胰腺癌 >90%）、p53 突变（>50% 肿瘤）</strong>。<strong>多步骤癌变</strong>（结肠癌"腺瘤-癌"序列）：APC（起始）→K-Ras（增殖）→p53（失控）——"突变累积的'多米诺'"（呼应信号转导篇）。<strong>精准治疗</strong>：<strong>EGFR-TKI</strong>（肺腺癌 EGFR 突变）、<strong>HER2 靶向</strong>（曲妥珠单抗，乳腺癌）、<strong>免疫检查点抑制剂</strong>（PD-1/PD-L1 抗体——"解除免疫刹车"）——"从'病理分型'到'分子分型'的肿瘤治疗革命"（药理学抗肿瘤药篇详述）。</span>

## 5 核心对比表：癌与肉瘤总结

| 对比项 | 癌 | 肉瘤 |
| --- | --- | --- |
| 来源 | 上皮 | 间叶 |
| 比例/年龄 | 80%+、中老年 | 少见、青少年 |
| 大体 | 硬、灰白 | 软、鱼肉样 |
| 镜下 | 细胞巢+间质 | 细胞弥漫 |
| 转移 | 淋巴道→血行 | 血行（肺） |
| 代表 | 鳞癌、腺癌 | 骨肉瘤、脂肪肉瘤 |

**辨析｜易错点：** 癌与肉瘤的**转移途径**最常考：**癌淋巴转移为主、肉瘤血行转移为主**——"癌走淋巴、肉瘤走血"。另一个易错点：**"癌"指上皮性恶性肿瘤**，"肉瘤"指间叶性——**骨肉瘤是"肉瘤"不是"癌"**（骨不是上皮）。

## 6 小结

- **癌**（上皮）：常见、中老年、淋巴转移、细胞巢（硬）；**肉瘤**（间叶）：少见、青少年、血行转移（肺）、鱼肉样（软）。
- 常见癌：鳞癌（角化珠）、腺癌（腺管）、基底细胞癌（浸润不转移）、小细胞癌（恶性度高+副肿瘤）。
- 常见肉瘤：骨肉瘤（青少年、肺转移）、尤文肉瘤（基因融合）、软组织肉瘤。
- 癌变的分子机制（癌基因/抑癌基因/多步骤）与**分级分期**、**分子靶向免疫治疗**决定预后与方案。
