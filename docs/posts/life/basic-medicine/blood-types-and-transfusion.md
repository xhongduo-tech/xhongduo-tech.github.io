## 为什么从血型与输血开始

血液可以输注救人，但前提是**血型（blood group）**匹配——否则输入的血液会与受血者的抗体发生凝集反应，危及生命。**ABO 血型**与**Rh 血型**是临床最重要的两个血型系统。<span class="marginnote">血型的本质是<strong>红细胞膜上的抗原（凝集原）</strong>。ABO 系统按 A、B 抗原的有无分为 A、B、AB、O 四型；Rh 系统按 D 抗原的有无分为 Rh 阳性与 Rh 阴性。理解"谁的血里有哪种抗体"是安全输血的前提。</span>

"O 型血为什么是'万能供血者'但仍有风险""Rh 阴性母亲怀 Rh 阳性胎儿为什么危险""输血为什么必须交叉配血"——血型与输血回答这些问题。

## 1 ABO 血型系统

**ABO 血型**按红细胞膜上 **A 抗原**与 **B 抗原**的有无分四型：

| 血型 | 红细胞抗原（凝集原） | 血浆天然抗体（凝集素） | 可接受的血型 |
| --- | --- | --- | --- |
| A | A 抗原 | 抗 B | A、O |
| B | B 抗原 | 抗 A | B、O |
| AB | A+B 抗原 | 无抗 A、抗 B | A、B、AB、O（万能受血者） |
| O | 无 A、无 B | 抗 A + 抗 B | O |

**关键规律**：**自己的血浆里不含针对自己红细胞抗原的抗体**——A 型人血浆有抗 B（不能接受 B 型血）、B 型人有抗 A、O 型人兼有抗 A 与抗 B（不能接受 A、B、AB）、AB 型人无抗体（可接受任何型）。<span class="marginnote">ABO 抗体是<strong>天然抗体</strong>（IgM，出生后即存在，无需致敏）。<strong>凝集反应</strong>：输入的红细胞若带有受血者抗体对应的抗原，则红细胞凝集、溶血→输血反应。因此<strong>输血以"供血者的红细胞不被受血者抗体凝集"为原则</strong>——O 型血红细胞无抗原，理论上可输给任何血型（"万能供血者"），但 O 型血血浆含抗 A、抗 B，若大量输入 A 型受者，其血浆抗体会凝集受者红细胞——所以"万能供血者"只对浓缩红细胞适用，全血仍要同型。</span>

## 2 Rh 血型系统与新生儿溶血

**Rh 血型**按红细胞有无 **D 抗原**分：有 D 抗原为**Rh 阳性（Rh⁺）**，无则为**Rh 阴性（Rh⁻）**。中国汉族人群约 99% 为 Rh 阳性，Rh 阴性较罕见（约 0.3%）。

**Rh 抗体不是天然存在的**——Rh 阴性者需经**接触 Rh 阳性红细胞致敏**后才产生抗 D 抗体（IgG，可透过胎盘）。

**新生儿溶血病（HDN）**：Rh 阴性母亲怀 Rh 阳性胎儿时——

1. 分娩或流产时，胎儿 Rh 阳性红细胞进入母体，母亲致敏产生抗 D 抗体。
2. **第二胎**Rh 阳性胎儿时，母体 IgG 抗 D 经胎盘进入胎儿血循环。
3. 抗 D 抗体攻击胎儿 Rh 阳性红细胞→**胎儿/新生儿溶血**（贫血、黄疸，严重可致核黄疸、脑损伤）。<span class="marginnote">Rh 溶血"第一次怀孕通常没事、第二次以后才危险"——因为致敏需要时间，且抗体是 IgG（可穿胎盘）。预防措施：Rh 阴性母亲在分娩/流产 Rh 阳性胎儿后 <strong>72 小时内注射抗 D 免疫球蛋白</strong>（中和胎儿红细胞、阻止母体致敏）。ABO 血型不合导致的溶血较轻（因 ABO 抗体多为 IgM 不能穿胎盘），Rh 不合更严重——"第一胎不溶血、第二胎溶血"是 Rh 血型的经典考点。</span>

## 3 输血原则与交叉配血

**安全输血的原则**：

1. **同型输血**为首选：ABO 与 Rh 均同型。
2. **输血前必须交叉配血**：把**供血者红细胞**与**受血者血清**（主侧）以及**受血者红细胞**与**供血者血清**（次侧）混合，观察有无凝集。
3. 紧急情况且无同型血时，可考虑 O 型浓缩红细胞（主侧无凝集），但需谨慎。
4. **成分输血**：按需输注红细胞、血小板、血浆、凝血因子等，更安全高效。<span class="marginnote">交叉配血的"主侧"最关键：主侧（供者红细胞 + 受者血清）无凝集才可输——确保供者的红细胞不会被受者抗体破坏。次侧凝集（受者红细胞 + 供者血清）少见，但大量输血时也要考虑。<strong>输血反应的识别</strong>：发热、寒战、腰痛、血红蛋白尿（溶血反应）、荨麻疹（过敏）——一旦发生需立即停输并处理。<strong>自体输血</strong>（术前自体血回输）可避免同种免疫与传染风险。</span>

**辨析｜易错点：** "O 型是万能供血者"只在一定条件下成立：**O 型浓缩红细胞（去血浆）**可给任何血型，但 **O 型全血**含有抗 A、抗 B 抗体，输入大量会凝集受者红细胞——所以现代输血"尽量同型"。另一个易错点：**ABO 抗体是 IgM（天然、不能穿胎盘）、Rh 抗体是 IgG（获得性、能穿胎盘）**——这正是 ABO 溶血轻、Rh 溶血重的免疫学原因。

## 4 公式解析：凝集反应的判读

**交叉配血是否安全**的判读可归纳为一条规则：

$$
\text{安全输血} \iff \text{主侧不凝集} \wedge (\text{次侧不凝集或仅轻微凝集})
$$

- **主侧**：供血者红细胞 + 受血者血清。若凝集→供者红细胞被受者抗体破坏→**绝对禁忌**。
- **次侧**：受血者红细胞 + 供血者血清。若明显凝集→受者红细胞被供者抗体破坏→大量输血时危险。
- **配血合格**才可输血；急诊抢救需"先配血再输"（紧急时可先输 O 型红细胞）。

## 5 数值算例：血型的分布与输血安全

**中国人群 ABO 血型分布**：O 型约 30~34%、A 型约 25~28%、B 型约 24~28%、AB 型约 7~10%（不同地区略有差异）。**Rh 阴性约 0.3~1%**（汉族更低，少数民族如维吾尔族较高）——Rh 阴性在我国属"稀有血型"，Rh 阴性者输血需特别谨慎。<span class="marginnote">"Rh 阴性的临床困境"：Rh 阴性者一旦接触 Rh 阳性血液致敏，再输 Rh 阳性血可发生严重溶血反应；Rh 阴性孕妇怀 Rh 阳性胎儿需抗 D 免疫球蛋白预防。我国的"稀有血型库"（如熊猫血互助群）正是为这类人群建立。<strong>Rh 阴性本身不影响健康，只在输血与妊娠时才是"问题"</strong>。</span>

**输血量的安全上限**：急性失血时，失血量 <15%（约 <750 ml）多可代偿；>20~30%（约 1000~1500 ml）出现休克，需输液与输血。**输血不是越多越好**——大量输血（>10 单位红细胞）可致稀释性凝血病、枸橼酸中毒、高钾血症等"大量输血并发症"。<span class="marginnote">"输血的定量原则"：<strong>血红蛋白 <70 g/L（急性失血）多需输血</strong>，70~100 g/L 视患者情况；大量输血按"红细胞:血浆:血小板 ≈ 1:1:1"比例补充以维持凝血。输血的本质是"补氧运载体+凝血因子+容量"，不是"补营养"——"输血有风险、能不输就不输"是基本原则。</span>

**成分输血的构成**：一单位全血可分离为红细胞、血小板、血浆、冷沉淀（凝血因子Ⅷ、纤维蛋白原）——**成分输血让"缺什么补什么"**，提高疗效、减少不良反应。血小板的保存时间短（室温 5 天），血浆可冷冻保存（新鲜冰冻血浆 FFP）。

## 6 临床联系：输血反应与血型鉴定

**输血反应的类型**：

| 反应类型 | 原因 | 表现 | 处理 |
| --- | --- | --- | --- |
| 急性溶血反应 | ABO 不合（主侧凝集） | 寒战高热、腰痛、血红蛋白尿 | 立即停输、抢救 |
| 过敏反应 | 血浆蛋白过敏 | 荨麻疹、支气管痉挛 | 抗组胺、肾上腺素 |
| 发热反应 | 白细胞抗体 | 发热 | 对症、退热 |
| 细菌污染 | 细菌入血 | 高热、休克 | 抗感染 |

**急性溶血反应是最危险的输血反应**——多因 ABO 不合（人为差错），表现为寒战、高热、腰痛、血红蛋白尿（"酱油色尿"）、急性肾衰。**处理：立即停输、保留血袋与血样、补液利尿、碱化尿液、透析**。<span class="marginnote">"输血前的最后核查"：核对受血者与血袋的姓名、血型（床旁双人核对）、交叉配血结果——绝大多数急性溶血反应源于"拿错血"。<strong>延迟性溶血反应</strong>（输血后数日）多为 Rh 等次要不合，症状较轻。<strong>输血相关急性肺损伤（TRALI）</strong>与<strong>循环超负荷（TACO）</strong>也是需警惕的严重反应。"输血不是小事"——这正是为什么血库与配血流程如此严格。</span>

**血型鉴定的方法**：正定型（用已知抗体测红细胞抗原）与反定型（用已知红细胞测血清抗体），两者一致才确认血型。**Rh 定型**用抗 D 血清测 D 抗原。新生儿溶血病的产前评估包括父母血型、抗体效价、胎儿超声。

**自体输血**：术前采集自身血液或术中回收术中失血，回输给患者——避免同种免疫反应与经血传播疾病（肝炎、HIV、梅毒）。"自体血回输"在择期手术与大出血抢救中广泛应用。<span class="marginnote">"自体输血的三种方式"：<strong>储存式</strong>（术前采血储存）、<strong>稀释式</strong>（麻醉后采血、术后回输）、<strong>回收式</strong>（术中吸引回收冲洗后回输）。自体输血彻底避免了血型不合与传染病风险，是"最安全的输血"。但血液回收有禁忌（污染血、恶性肿瘤血不可回输）。</span>

## 7 术语速查表

| 术语 | 定义 |
| --- | --- |
| 凝集原 | 红细胞膜上的血型抗原（A、B、D） |
| 凝集素 | 血浆中针对缺失抗原的抗体 |
| 天然抗体 | ABO 的 IgM（出生即有、不能穿胎盘） |
| 获得性抗体 | Rh 的抗 D（IgG、致敏后产生、能穿胎盘） |
| 交叉配血 | 供者红细胞+受者血清（主侧）等混合检查 |
| 主侧 / 次侧 | 供红细胞+受血清 / 受红细胞+供血清 |
| 万能供血者 / 受血者 | O 红细胞（去血浆）/ AB（无抗体） |
| 新生儿溶血病（HDN） | Rh 不合致胎儿红细胞溶血 |
| 抗 D 免疫球蛋白 | 分娩后 72h 内注射防 Rh 致敏 |
| 成分输血 | 按需输注红细胞、血小板、血浆等 |

**易错点复习：** 血型的三大考点——"ABO 抗体是天然 IgM（不能穿胎盘）、Rh 抗体是获得性 IgG（能穿胎盘）→Rh 溶血重、ABO 溶血轻"、"O 型是'浓缩红细胞'的万能供血者（去血浆）、O 型全血含抗 A 抗 B 不可大量输"、"交叉配血以主侧（供红细胞+受血清）不凝集为准"。把这三组记住，血型与输血的"安全逻辑"就通了。

## 8 小结

- **ABO 血型**：A、B、AB、O 四型，血浆含针对缺失抗原的**天然抗体（IgM）**；AB 为万能受血者、O 红细胞为"万能供血"。
- **Rh 血型**：按 D 抗原分阳/阴性；Rh 阴性者需**致敏后**产生抗 D 抗体（IgG），可致**新生儿溶血病**（第二胎起）。
- 输血原则：**同型输血 + 交叉配血（主侧不凝集）**；急诊可用 O 型浓缩红细胞。
- ABO 抗体 IgM 不能穿胎盘、Rh 抗体 IgG 能穿胎盘——决定两种溶血病的严重程度差异。
- **数值锚点**：中国汉族 Rh 阴性约 0.3%、急性溶血反应多因 ABO 不合（核对血型最关键）、失血 >20~30%（约 1000~1500 ml）出现休克、Hb<70 g/L 多需输血——"分布、阈值、核对"是输血安全的量化与流程要点。
- **一句话收束**：血型 = "红细胞上有什么抗原（A/B/D）+ 血浆里有什么抗体"——输血的安全在于"供者的红细胞不被受者抗体凝集（主侧不凝集）"；Rh 的"致敏-二次应答"则是新生儿溶血与稀有血型管理的核心。

**一句话总结本篇**：血型与输血 = "抗原-抗体"的匹配问题——ABO 与 Rh 决定"谁的血能进谁的血管"，交叉配血保证主侧不凝集，成分输血与自体输血让输血更安全高效；Rh 的"致敏-二次应答"则解释了新生儿溶血与稀有血型的临床管理。

**自测三问**：①O 型血为什么是"万能供血者"又有何限制？②Rh 阴性母亲为什么"第一胎没事、第二胎危险"？③急性溶血反应如何处理、如何预防？——能答出这三点，血型与输血就掌握了。
