## 为什么从口腔与胃肠消化开始

消化生理讲"食物怎样被消化吸收"。**消化（digestion）**是把大分子食物分解为可吸收小分子的过程（机械消化+化学消化），**吸收（absorption）**是小分子进入血液与淋巴。本篇从口腔开始，介绍唾液与吞咽、胃肠道平滑肌的运动，并给出消化生理的总框架。<span class="marginnote">消化系统功能的总览：<strong>口腔</strong>（咀嚼、唾液淀粉酶）→<strong>胃</strong>（胃酸、胃蛋白酶、储存搅拌）→<strong>小肠</strong>（胰酶、胆汁、肠液——消化吸收主战场）→<strong>大肠</strong>（水分吸收、菌群发酵）。本篇先讲口腔与胃肠运动，为后续各篇铺垫。</span>

"为什么吃淀粉会感到甜味""胃肠道怎样把食物向前推""胃肠道的运动有哪些类型"——口腔与胃肠消化回答这些问题。

## 1 唾液与口腔内的消化

**唾液（saliva）**由三对大唾液腺与众多小唾液腺分泌，每天约 1.0~1.5 L。唾液的功能：

**湿润与润滑**食物（利于咀嚼、吞咽）。
**唾液淀粉酶**：把淀粉初步分解为麦芽糖——口腔内化学消化的第一步（食物入胃后酸使酶失活）。
**清洁与抗菌**：溶菌酶、免疫球蛋白 A（IgA）等。
**稀释与缓冲**：中和食物酸碱。

**唾液的分泌调节**：**副交感神经**（迷走→腺体）促进大量稀薄唾液（"望梅止渴"的反射）；交感促进少量黏稠唾液。<span class="marginnote">"<strong>望梅止渴</strong>"是条件反射分泌唾液的经典例子。副交感兴奋→唾液大量分泌（稀薄）；交感兴奋→少量黏稠唾液（紧张时口干，因交感抑制副交感且分泌黏稠液）。<strong>唾液 pH 约 6.6~7.1</strong>，含淀粉酶开始淀粉消化；唾液还有缓冲作用，保护牙釉质。</span>

**吞咽（deglutition）**分三期：口腔期（随意）→咽期（反射，关闭鼻咽与喉口）→食管期（蠕动推进）。食管下括约肌（LES）在吞咽时松弛放行（见解剖咽食管篇）。

## 2 胃肠平滑肌的运动

**胃肠道平滑肌**具有**自动节律性收缩**、伸展性大、对牵张敏感等特点。主要运动形式：

**蠕动（peristalsis）**：环形肌与纵行肌协调，形成"波"把食团向前推进——消化道各段都有（食管、胃、小肠、大肠）。
**分节运动（segmentation）**：小肠特有的运动，环形肌节律性收缩把食糜**分割又混合**——主要作用是**混合食糜与消化液**（促进消化与吸收），推进作用较弱。
**紧张性收缩**：维持消化道基础张力（如括约肌的关闭状态）。
**袋状往返运动**：结肠的运动，促进水分吸收与粪便形成。<span class="marginnote"><strong>蠕动与分节运动的区别</strong>是考点：<strong>蠕动是"推进"（向前移动），分节运动是"搅拌"（原地混合）</strong>。小肠以分节运动为主（混合消化液、接触吸收面），大肠以袋状运动为主（吸水成形）。肠梗阻时"高亢肠鸣音"是蠕动增强的表现；肠麻痹（术后）时蠕动减弱→腹胀。</span>

**胃肠道运动的调节**：**神经调节**（迷走副交感促进运动、交感抑制运动；肠壁内神经丛局部调节）与**体液调节**（促胃液素、缩胆囊素、促胰液素等胃肠激素）。

## 3 消化生理的总框架

消化吸收按营养物质分三大类，各有通路：

| 营养物质 | 消化产物 | 消化场所 | 吸收方式 |
| --- | --- | --- | --- |
| 淀粉 | 葡萄糖 | 口腔、小肠 | 小肠（继发性主动转运 SGLT） |
| 蛋白质 | 氨基酸、二肽三肽 | 胃、小肠 | 小肠（氨基酸转运体） |
| 脂肪 | 脂肪酸、甘油一酯 | 小肠（需胆汁乳化） | 小肠（乳糜微粒入淋巴） |

**消化吸收的总原则**：**大部分消化与几乎全部吸收都在小肠**——胰腺分泌胰酶（淀粉酶、蛋白酶、脂肪酶）、肝脏分泌胆汁（乳化脂肪）、小肠黏膜分泌肠液并承担吸收。<span class="marginnote">"小肠是消化吸收主战场"是消化生理的总纲：淀粉经唾液+胰淀粉酶→麦芽糖→双糖酶→葡萄糖；蛋白质经胃蛋白酶+胰蛋白酶→氨基酸/肽；脂肪经胆汁乳化+胰脂肪酶→脂肪酸与甘油一酯→形成乳糜微粒入淋巴。三大营养物质的"消化链条"在后续各篇逐一展开（胃液分泌、小肠内消化、吸收）。</span>

## 4 核心对比表：消化道各段的运动

| 部位 | 主要运动 | 功能 |
| --- | --- | --- |
| 口腔 | 咀嚼、吞咽 | 机械消化、推送 |
| 食管 | 蠕动 | 输送食团 |
| 胃 | 容受性舒张、蠕动 | 储存、搅拌、排空 |
| 小肠 | 分节运动、蠕动 | 混合、推进、吸收 |
| 大肠 | 袋状往返运动、集团蠕动 | 吸水、成形、排便 |

## 5 数值算例：消化系统的"量"与"速度"

**唾液的分泌量**：每日约 1.0～1.5 L，pH 约 6.6～7.1。唾液淀粉酶在口腔开始淀粉消化，但**入胃后因胃酸而失活**——所以淀粉消化在胃内几乎停止，直到小肠胰淀粉酶继续。这也是"细嚼慢咽利于消化"的生理学解释。<span class="marginnote">唾液分泌的"质与量"随刺激而异：<strong>副交感→大量稀薄唾液</strong>（含酶多），<strong>交感→少量黏稠唾液</strong>。紧张时交感占优→口干。此外唾液淀粉酶作用的"窗口期"很短——<strong>食物在口腔停留约 15～30 秒</strong>，之后酶在胃酸中失活，这解释了为什么"吃米饭觉得甜"只在咀嚼时明显。</span>

**吞咽的速度**：食团从口腔到胃约需 4～8 秒——口腔期 1 秒内（随意）、咽期约 1 秒（反射）、食管期 5～8 秒（蠕动+LES 松弛）。食管蠕动波速度约 2～4 cm/s。

**胃排空的速率**：胃排空食物约需 2～4 小时（液体快、固体慢，脂肪最慢）。排空速度受**十二指肠的负反馈抑制**（肠-胃反射：十二指肠内脂肪、酸、高渗刺激→抑制胃排空）——这是"脂肪餐耐饥"的生理学解释。<span class="marginnote"><strong>胃排空的调节是"十二指肠说了算"</strong>：十二指肠内的脂肪、酸性食糜、高渗液会抑制胃排空（肠-胃反射与缩胆囊素等激素），给小肠足够时间消化吸收。所以高脂餐后胃排空慢、饱腹感持久。胃排空的快慢直接决定"下一顿饿不饿"。</span>

**胃肠道的蠕动频率**：胃蠕动约 3 次/分，十二指肠约 11 次/分，回肠约 8 次/分——"上慢下快"为各段消化吸收留出时间。分节运动在小肠约 11～12 次/分。

## 6 临床联系：消化运动异常的表现

**呕吐（vomiting）**：延髓呕吐中枢受刺激→膈肌、腹肌收缩+胃食管反流+贲门开放→胃内容物排出。呕吐中枢对多种刺激敏感：胃肠刺激、前庭（晕车）、化学物质（化疗药、阿片）、颅内高压（喷射性呕吐）。<span class="marginnote"><strong>喷射性呕吐</strong>（无恶心先兆、强力喷出）提示<strong>颅内高压</strong>（如脑肿瘤、脑膜炎），是神经系统急症信号；而胃肠源性呕吐常先有恶心。<strong>晕动病</strong>的呕吐由前庭系统触发（见前庭篇）。理解呕吐中枢的多种传入途径，就理解呕吐的多种病因。</span>

**呕吐与电解质紊乱**：持续呕吐丢失胃酸（H⁺、Cl⁻）→低氯性碱中毒；同时丢失水与电解质→脱水、低钾。这是"呕吐伤胃更伤全身"的机制——临床补液时需考虑"丢多少、补什么"。

**腹泻的胃肠运动基础**：腹泻时小肠运动增强（分节减少、蠕动加快），食糜快速通过→吸收时间不足→水样便。**渗透性腹泻**（高渗物质不能吸收，如乳糖不耐受）与**分泌性腹泻**（肠毒素刺激分泌，如霍乱）机制不同。<span class="marginnote"><strong>霍乱毒素致分泌性腹泻</strong>：毒素激活肠上皮腺苷酸环化酶→cAMP↑→Cl⁻ 与水分大量分泌入肠腔→水样泻（"米泔水样便"）。乳糖不耐受是渗透性腹泻的典型（乳糖未被消化→肠内高渗→水被"吸"出）。"腹泻的两种机制"是内科常考点。</span>

**便秘与结肠运动**：结肠蠕动减弱、粪便停留过久→水分过度吸收→干硬便。**集团蠕动**（每日 3～4 次，多在餐后）把结肠内容物推向直肠，产生便意——"早餐后便意"与胃结肠反射相关。

## 7 术语速查表

| 术语 | 定义 |
| --- | --- |
| 消化 | 大分子食物分解为可吸收小分子的过程 |
| 吸收 | 小分子进入血液与淋巴的过程 |
| 唾液淀粉酶 | 口腔内把淀粉分解为麦芽糖的酶 |
| 蠕动 | 环形肌与纵行肌协调的"推进波" |
| 分节运动 | 小肠环形肌节律收缩，混合食糜与消化液 |
| 紧张性收缩 | 维持消化道基础张力的收缩 |
| 袋状往返运动 | 结肠运动，促进水分吸收与成形 |
| 肠-胃反射 | 十二指肠内容物抑制胃排空的反射 |
| 集团蠕动 | 结肠把内容物推向直肠的强烈蠕动 |
| 胃结肠反射 | 进食后结肠运动增强、产生便意 |

**易错点复习：** 消化生理最核心的两组对比——"蠕动管推进、分节运动管搅拌"、"唾液管淀粉、胃管蛋白、小肠管一切"。把"口腔淀粉、胃蛋白、小肠（胰酶+胆汁+肠液）三大类、大肠吸水"这张表背熟，消化系统的功能线就完整了。

## 8 小结

- **唾液**含淀粉酶（淀粉初步消化）、润滑清洁；副交感促分泌。
- 吞咽分口腔期、咽期、食管期，LES 协调放行。
- 胃肠运动：**蠕动**（推进）、**分节运动**（搅拌）、紧张性收缩、袋状运动；受神经与胃肠激素调节。
- **小肠是消化吸收的主战场**：胰酶、胆汁、肠液在此汇合，三大营养物质在此分解吸收。
- **数值锚点**：唾液 1.0~1.5 L/日、吞咽 4~8 秒、胃排空 2~4 小时、胃蠕动 3 次/分、分节 11~12 次/分——"量、速、率"三组数字是消化运动的时间标尺。
- **临床要点**：喷射性呕吐提示颅内高压；持续呕吐致低氯性碱中毒；腹泻分渗透性（乳糖不耐受）与分泌性（霍乱毒素）两型——"运动的异常就是症状的来源"。
- **自测三问**：①唾液淀粉酶为什么只在口腔起作用？②蠕动与分节运动的区别？③胃排空为什么受十二指肠抑制？——能答出，口腔与胃肠消化这一篇就过关了。

**一句话总结本篇**：消化生理的总纲是"口腔消化淀粉、胃消化蛋白、小肠消化一切（胰酶+胆汁+肠液）并几乎吸收一切"；胃肠运动"蠕动推进、分节搅拌"；唾液副交感分泌、胃肠神经体液双调。把这张"部位-酶-运动"对应表记住，接下来各篇（胃液、小肠消化、吸收）就都是在往这张表里填细节。

**再补一问**：为什么"细嚼慢咽"利于消化？——因为唾液淀粉酶的作用窗口只有口腔停留的十几秒，咀嚼越充分、酶接触越充分，且粉碎后的食物更易被胃酸与后续酶作用。这一问把"消化从口腔开始"落到了具体的酶与时间上。

在下一节，我们聚焦胃——**胃液分泌与胃运动**：胃液的成分与作用、胃酸分泌的细胞机制、胃液分泌的调节（头期、胃期、肠期），以及胃排空与胃运动的控制。
