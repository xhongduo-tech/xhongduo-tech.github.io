## 为什么从髋关节与膝关节开始

如果说肩、肘是"灵活优先"的上肢关节，那么**髋关节与膝关节**就是"承重优先"的下肢关节：它们支撑全身重量、传递行走奔跑的力量，还要在运动中保持稳定。这两个关节也是退变与损伤的重灾区——髋关节骨关节炎、股骨颈骨折、膝关节半月板损伤与交叉韧带断裂，是骨科与运动医学最常面对的问题。<span class="marginnote">髋关节是典型的"稳固型球窝关节"，膝关节则是全身最大、结构最复杂（含半月板与交叉韧带）的关节。对照学习"一稳一复杂"，正好复习关节学总论的辅助结构。</span>

## 1 髋关节：深窝与强力韧带

**髋关节（hip joint）**由**股骨头**与**髋臼**构成，是全身最稳固的球窝关节。它的稳固来自三重设计：

**髋臼深**：髋臼几乎包住股骨头的 2/3，髋臼周缘还有**髋臼唇**（纤维软骨环）进一步加深，使股骨头"嵌"在窝内。
**股骨头韧带**：髋臼内的**股骨头韧带**连于股骨头凹与髋臼横韧带之间，内含营养股骨头的血管，起少量固定作用。
**厚而紧张的关节囊与强韧韧带**：关节囊厚，前方有强大的**髂股韧带**（人体最强大的韧带，呈倒"Y"形，防髋过度后伸）、**耻股韧带**（防过度外展）、**坐股韧带**（防过度旋内）。<span class="marginnote">髂股韧带俗称"Y 韧带"，它紧张时会限制髋关节后伸——所以站立时髋关节处于轻度屈曲位（约 0°～10°），人体借韧带"被动悬挂"维持站立而几乎不用肌肉发力。股骨头坏死与髋关节置换术的解剖学重点都在股骨头的血供：它主要来自股骨颈基底部旋股动脉的分支，股骨颈骨折易切断这些血管。</span>

髋关节可做**屈伸、收展、旋转与环转**，但各方向的活动度都小于肩关节——这是"稳固优先"的代价。

## 2 髋关节脱位与先天性髋脱位

**髋关节脱位**：因髋臼深、韧带强，髋关节脱位需较大暴力（多为交通事故伤），且以后脱位为主（股骨头脱向坐骨大孔方向），常合并髋臼后缘骨折与坐骨神经损伤。<span class="marginnote">髋后脱位时可压迫坐骨神经，出现足下垂、小腿外侧感觉丧失。与肩关节"前脱位常见"恰成对照——肩浅故前脱，髋深故后脱，方向由窝的深浅与韧带的分布决定。</span>

**发育性髋关节发育不良（DDH）**：婴儿期髋臼发育浅、股骨头可滑出，若未及时治疗，成年后易继发髋关节骨关节炎。新生儿筛查（Barlow 试验、Ortolani 试验）利用的正是"髋臼唇能不能兜住股骨头"这一解剖原理。

## 3 膝关节：结构与两大辅助结构

**膝关节（knee joint）**是人体最大、最复杂的关节，由**股骨下端、胫骨上端与髌骨**构成。它其实是三个关节的复合：股骨内侧髁—胫骨内侧髁、股骨外侧髁—胫骨外侧髁两个胫股关节，加上股骨髌面—髌骨后面的**髌股关节**。膝关节主要做**屈伸**，半屈时可有轻度旋转。

膝关节的复杂性集中在两个辅助结构上：

**半月板（meniscus）**：股骨内、外侧髁与胫骨内、外侧髁之间的两块纤维软骨，**内侧半月板**呈"C"形、较大，**外侧半月板**近"O"形、较小。半月板的作用是"填平"股骨髁的圆形与胫骨平台的平面之间的不匹配，扩大接触面、分散压力、缓冲震荡。<span class="marginnote">半月板损伤是膝关节最常见的损伤之一：膝关节屈曲位旋转（踢足球转身、下蹲起立）时，半月板被股骨髁与胫骨平台夹住撕拉，可致撕裂。内侧半月板与内侧副韧带、前交叉韧带共同构成"恐怖三联征"（O'Donoghue 三联征）——屈膝外翻暴力同时撕裂这三者。</span>

**交叉韧带**：位于关节囊内、滑膜外，**前交叉韧带（ACL）**自股骨外侧髁内面斜向前下止于胫骨髁间隆起前方，**后交叉韧带（PCL）**自股骨内侧髁外面斜向后下止于胫骨后方。前交叉韧带防止胫骨**前移**，后交叉韧带防止胫骨**后移**。<span class="marginnote">ACL 是运动医学的明星结构：非接触性损伤（急停、变向、落地不稳）是它断裂最常见的方式。检查时"抽屉试验"（前抽屉阳性提示 ACL 断裂）和 Lachman 试验，检测的正是胫骨相对股骨的前移是否过大。ACL 重建术常用自体腘绳肌腱或髌腱，是膝关节镜外科最常做的手术之一。</span>

**侧副韧带**：**胫侧副韧带**（内侧）与**腓侧副韧带**（外侧）加固关节两侧，防止膝内外翻。**髌韧带**是股四头肌腱的延续，止于胫骨粗隆，是"膝跳反射"的敲击点。<span class="marginnote">膝跳反射检查敲的正是髌韧带——敲击使它被牵拉，刺激股四头肌的牵张感受器，经脊髓反射引起股四头肌收缩、小腿前踢。这个"反射弧"由 L2～L4 脊髓节段完成，是神经科体检判断腰段脊髓功能的经典试验。</span>

## 4 核心对比表：髋关节与膝关节

| 对比项 | 髋关节 | 膝关节 |
| --- | --- | --- |
| 类型 | 球窝关节（深窝） | 屈戌关节+旋转（复合） |
| 稳定来源 | 骨性深窝+韧带 | 韧带+半月板+肌肉 |
| 核心结构 | 髋臼、髋臼唇、股骨头韧带 | 半月板、交叉韧带、侧副韧带 |
| 易损结构 | 股骨头血供（颈骨折） | 半月板、ACL |
| 好发疾病 | 骨关节炎、股骨颈骨折 | 半月板撕裂、韧带断裂 |

**辨析｜易错点：** 初学者常把"膝关节内半月板撕裂"与"膝关节交叉韧带断裂"混为一谈。区分要点：**半月板损伤的痛在关节间隙、且有关节交锁或弹响**（半月板碎片卡住关节）；**ACL 断裂的痛在急性扭伤当下（"pop"声）、以关节不稳感为主**（"膝关节打软"）。一个伤在"垫片"，一个伤在"缆绳"。

## 5 数值算例：髋膝轴线与关节受力

**下肢力线（机械轴）**：正常情况下，从**股骨头中心**经**膝关节中心**到**踝关节中心**连一条直线（机械轴），通过膝关节中心附近；**股骨颈干角**约 127°（颈干角变小→髋内翻，变大→髋外翻），**股骨颈前倾角**约 12°～15°（前倾角异常与步态异常相关）。

**膝关节的受力数量级**：站立时膝关节承重约等于体重的一半，但**上下楼梯时髌股关节压力可达体重的 3～4 倍**，下蹲可达 7～8 倍。半月板的作用就是把胫股关节的接触压力分散——切除半月板后，接触面积减小、局部压强显著增大，这正是"半月板损伤/切除后易继发骨关节炎"的力学解释。<span class="marginnote">骨关节炎（OA）的发病与力学密切相关：<strong>肥胖增加关节载荷、半月板损伤破坏应力分布、韧带损伤改变运动学</strong>，三者都使软骨承受异常应力。理解"力线—接触应力—软骨磨损"这条链，是理解 OA 保守治疗（减重、支具、纠正力线）的第一步。</span>

**髌骨的杠杆作用**：髌骨使股四头肌的力臂增大（把力线移离膝关节轴），从而**用同样的肌力获得更大的伸膝力矩**——髌骨是"杠杆臂延长器"。切除髌骨后伸膝力量下降约 30%，所以髌骨骨折尽量保留。

**辨析｜易错点：** "股骨颈干角是 120°还是 127°"常被混淆——**正常约 127°**，成年后趋于恒定；**股骨颈骨折好发于老年人**，因骨质疏松+颈干角使应力集中在颈基底。另一个易错点：**膝关节承重不是"体重"而是"体重的若干倍"**——髋膝 OA 患者减重的获益远大于直觉。

## 6 临床联系：从关节解剖到常见病

**髋关节骨关节炎（OA）**：软骨磨损→关节间隙变窄→骨赘形成。患者主诉"起立痛、上楼痛、休息缓解"，活动受限以**内旋、屈曲**最先受限（因为髋关节运动被强韧带限制，骨赘最先卡在内旋方向）。晚期可行**人工髋关节置换**——置换术的关键解剖正是髋臼、股骨颈与髋臼唇的定位。

**股骨颈骨折**：老年人最常见骨折之一。股骨头的血供主要来自旋股动脉的分支（经股骨颈基底部），**骨折后血供中断→股骨头缺血性坏死**——这是"股骨颈骨折为何必须尽快手术（股骨头置换）"的解剖学依据。<span class="marginnote">股骨头血供的记忆要点：<strong>旋股内/外侧动脉→经股骨颈基底的颈动脉环→穿入股骨颈→供应股骨头</strong>；股骨头韧带的小血管只营养很小区域。股骨颈骨折部位越靠近股骨头（头下型），血供破坏越彻底、坏死率越高。临床上"老年人跌倒后髋痛、下肢外旋短缩、不能站立"要高度怀疑股骨颈骨折。</span>

**髌股疼痛综合征（PFPS，"跑步膝"）**：髌骨轨迹异常→髌股关节压力增大→膝前痛（上下楼、久坐后站起加重）。与**股四头肌内外侧头力量失衡、髌骨支持带松弛**有关——康复训练（加强股内侧斜肌）就是针对这一力学失衡。

**膝关节骨关节炎与置换**：重度膝 OA 行**全膝关节置换（TKA）**，术中要处理股骨、胫骨截骨与半月板、交叉韧带的取舍——理解胫股关节与髌股关节的结构是手术设计的解剖基础。

**辨析｜易错点：** 髋 OA 的"活动受限以旋转最先"与膝 OA 的"以屈伸受限为主"不同——**髋是"深窝球窝"、膝是"屈戌+旋转"**，运动轴不同，疾病表现也不同。把"髋内旋受限"记成"髋屈曲受限"是常见错误。

**膝关节四大特殊检查**（把"结构"转化为"检查动作"）：

**前抽屉试验**：屈膝 90°，固定足部、向前拉胫骨——胫骨前移增大提示 **ACL 损伤**。
**Lachman 试验**：屈膝约 30° 时前拉胫骨——是 ACL 断裂最灵敏的检查。
**后抽屉试验**：向后推胫骨——后移增大提示 **PCL 损伤**。
**McMurray 试验（麦氏试验）**：屈膝旋转+外翻，出现弹响或疼痛提示**半月板损伤**。

这些试验检测的正是本篇的结构知识：**交叉韧带管前后移（抽屉试验），半月板被股骨髁夹挤（麦氏试验）**。检查动作不是孤立的操作，而是对解剖功能的"反向验证"——这是解剖学走向临床的典型例子。<span class="marginnote">"体检动作是解剖的翻译"是骨科学习的诀窍：<strong>每一项特殊检查都能在解剖图上找到被牵拉/被挤压的结构</strong>。看懂结构再背动作，比死记"几度屈膝、往哪个方向拉"可靠得多——这也是我们从结构出发学关节的回报。</span>

## 7 术语速查表

| 术语 | 定义 |
| --- | --- |
| 髋臼（acetabulum） | 髋骨的深窝，容纳股骨头 |
| 髋臼唇 | 髋臼周缘的纤维软骨环，加深关节窝 |
| 髂股韧带 | 人体最强大的韧带（倒"Y"形），防髋过度后伸 |
| 半月板（meniscus） | 膝内纤维软骨垫，内"C"形外"O"形 |
| 前交叉韧带（ACL） | 防胫骨前移，自股骨外侧髁内面止于胫骨髁间隆起前方 |
| 后交叉韧带（PCL） | 防胫骨后移 |
| 髌韧带 | 股四头肌腱的延续，止于胫骨粗隆 |
| 股骨头韧带 | 连于股骨头凹与髋臼横韧带，含营养血管 |
| 提携角（属肘部） | 与髋膝无关，勿混入下肢记忆 |

**辨析｜易错点：** 半月板与交叉韧带"谁防前后移、谁防旋转"是高频考点：**ACL 防胫骨前移、PCL 防胫骨后移；半月板不直接防移位，而是分散压力**。把"旋转"归给交叉韧带是对的（ACL 还限制胫骨旋转），但半月板撕裂常在"屈膝旋转位"发生——受伤动作相同，受损结构不同。

## 8 小结

- **髋关节**是深窝球窝关节，靠髂股韧带等强韧带获得极大稳固性，后脱位常见、可伤坐骨神经。
- **膝关节**是全身最大关节，由胫股关节与髌股关节复合而成，主要做屈伸。
- 膝关节的两大辅助结构——**半月板**（垫片，C 形内/O 形外）与**交叉韧带**（ACL 防胫骨前移、PCL 防后移）——是理解膝损伤的核心。
- 髌韧带是膝跳反射的敲击点，检查的是 L2～L4 脊髓节段的反射弧。
- **力线决定受力**：机械轴、颈干角、髌骨杠杆决定髋膝的应力分布；上下楼时髌股关节压力可达体重数倍。
- **临床对应**：股骨颈骨折→股骨头缺血性坏死；膝特殊检查（前/后抽屉、Lachman、麦氏）分别验证 ACL、PCL 与半月板——体检动作是解剖的翻译。
- **对照记忆**：上肢肩肘"灵活优先、肌肉动态稳定"，下肢髋膝"承重优先、骨性/韧带静态稳定"——上下的设计哲学正好相反。
- **术语回顾**：髋臼唇、股骨头韧带、髂股韧带是髋的"三件套"；半月板、交叉韧带、侧副韧带、髌韧带是膝的"四件套"。
- **复习衔接**：关节学总论的"辅助结构"（韧带、软骨、滑膜）在此落地——髋膝正是这些结构最集中、最重要的实例。

在下一节，我们将抵达下肢末端——**距小腿关节与足关节**：内踝、外踝如何钳住距骨，以及足弓的构成与"崴脚"（踝扭伤）为什么总是内翻伤。
