## 为什么从奈瑟菌属开始

**奈瑟菌属（Neisseria）**是 G- 双球菌——**脑膜炎球菌**（流行性脑脊髓膜炎）与**淋球菌**（淋病）。理解它们的形态（G- 双球菌）、致病（荚膜、内毒素；菌毛）与所致疾病（流脑、淋病），是脑膜炎与性传播疾病诊治的基础。<span class="marginnote"><strong>脑膜炎球菌（N. meningitidis）</strong>：G- 双球菌、<strong>荚膜</strong>（抗吞噬）、<strong>内毒素</strong>（LPS——出血坏死）、菌毛。<strong>所致</strong>：<strong>流行性脑脊髓膜炎（流脑）</strong>——飞沫传播（鼻咽→血→脑膜）→高热、头痛、颈强直、<strong>皮肤瘀点瘀斑</strong>、脑膜刺激征。<strong>淋球菌（N. gonorrhoeae）</strong>：G- 双球菌（肾形）、菌毛（黏附）、无荚膜。<strong>所致</strong>：<strong>淋病</strong>（尿道炎——脓性分泌物；新生儿眼炎）。<strong>防治</strong>：流脑（疫苗+青霉素/头孢曲松）、淋病（头孢曲松）。</span>

"脑膜炎球菌怎么'致流脑'（鼻咽→血→脑膜）""流脑的'瘀点瘀斑'（内毒素）""淋球菌怎么'尿道炎'（菌毛黏附）""新生儿眼炎怎么'预防'（红霉素眼膏）""脑膜炎球菌怎么'疫苗'（荚膜多糖）"——奈瑟菌属回答这些问题。

## 1 脑膜炎球菌（流脑）

**脑膜炎球菌（N. meningitidis）**：

**形态**：G- 双球菌（肾形、成对）、**荚膜**（抗吞噬）、**内毒素（LPS）**、菌毛（黏附鼻咽）。
**传播**：**飞沫**（鼻咽部定植——人带菌率高）。
**致病**：鼻咽定植→**入血（菌血症）**→**血脑屏障→脑膜炎**——"流脑'鼻咽→血→脑膜'"。

### 流行病学：带菌率比发病率高得多

流脑最反直觉的一点是：**带菌者远比患者多**。<span class="marginnote"><strong>带菌率数字</strong>：流行期人群鼻咽部脑膜炎球菌带菌率可达 <strong>30%–50%</strong>，而发病者不足带菌者的 <strong>1%</strong>——绝大多数人只是无症状定植。我国流脑以 <strong>冬春季</strong>（2–4 月）高发，学龄前儿童与青少年为高发人群。</span>这解释了为什么流脑需要**疫苗+控制带菌者**双管齐下：单靠隔离患者拦不住飞沫传播，因为"看上去健康"的带菌者才是主要传染源。

**流行性脑脊髓膜炎（流脑）**：

**表现**：**高热、剧烈头痛、呕吐、颈强直（脑膜刺激征）**、**皮肤瘀点瘀斑**（内毒素血管损伤——出血坏死）——"流脑'瘀点+脑膜刺激征'"（呼病理学化脓性脑膜炎）。
**重症**：暴发型流脑（内毒素休克——华-佛综合征、DIC）。

**实验室诊断**：脑脊液涂片（G- 双球菌，中性粒细胞内）、培养（巧克力平板、5% CO₂）、乳胶凝集（荚膜多糖抗原）。<span class="marginnote"><strong>为何用巧克力平板</strong>：脑膜炎球菌与淋球菌都是<strong>营养要求高</strong>的苛养菌，普通血平板不长，需巧克力平板（加热血平板）+5% CO₂、37℃ 培养——这是奈瑟菌属培养的共同特点。</span>标本注意**保温速送**：奈瑟菌对低温与干燥敏感，脑脊液标本离体后应尽快接种，否则检出率大降。

### 防治

**疫苗**：**荚膜多糖疫苗（A/C 群）/结合疫苗**——"流脑'荚膜多糖疫苗'"（呼免疫学抗原篇多糖疫苗）。
**治疗**：**青霉素/头孢曲松**（三代——入脑）。

**"流脑'儿童高发+瘀点'"**：儿童鼻咽带菌率高、免疫弱→流脑多发；瘀点是内毒素血管损伤——"流脑'瘀点'"（呼补体缺陷——MAC 缺陷易奈瑟菌感染，呼免疫缺陷篇）。

**密切接触者药物预防**：流脑患者的**密切接触者**（家人、同宿舍、同教室者）即使无症状，也应口服**利福平**或**头孢曲松**清除鼻咽部带菌。<span class="marginnote"><strong>药物预防的原理</strong>：流脑以带菌者为主要传染源，疫苗产生免疫要数周，来不及阻断暴发；而<strong>利福平（4 日疗程）</strong>能快速杀灭鼻咽部细菌，切断传播链。这是"带菌者>患者"这一流行病学事实的临床落地。</span>这也再次强调：**流脑防控的钥匙在"清除定植"而非"治好患者"**。<span class="marginnote"><strong>"流脑的'瘀点瘀斑'"</strong>：脑膜炎球菌内毒素（LPS）→血管内皮损伤+血栓→<strong>皮肤瘀点瘀斑（出血坏死）</strong>——"流脑'瘀点'"（呼细菌感染篇内毒素——发热休克）。<strong>"脑膜炎球菌疫苗"</strong>：荚膜多糖（A/C 群）疫苗/结合疫苗（婴幼儿）——"流脑'疫苗'（荚膜多糖——呼免疫学抗原篇）"。<strong>"暴发型流脑（华-佛）"</strong>：内毒素休克（肾上腺出血——华-佛综合征）——"暴发型'内毒素休克'"（呼病理学休克/DIC）。<strong>"补体缺陷易奈瑟菌"</strong>：MAC（C5-9）缺陷→奈瑟菌感染——"补体缺陷'奈瑟菌'"（呼免疫缺陷篇/补体篇——MAC 溶菌）。</span>

**鉴别要点**：流脑需与病毒性脑膜炎、结核性脑膜炎鉴别。流脑的**瘀点瘀斑**与脑脊液**中性粒细胞增高**是其与病毒性脑膜炎（淋巴细胞为主、无瘀点）的关键区别——"化脓'中性粒'、病毒'淋巴'"。

### 荚膜分群与疫苗选择

脑膜炎球菌按**荚膜多糖抗原**可分为多个血清群，与临床最相关的有 **A、B、C、W135、Y** 五群。<span class="marginnote"><strong>为何分群重要</strong>：我国流脑长期以 <strong>A 群</strong>为主，故传统疫苗为 A 群（后扩为 A+C）荚膜多糖疫苗；<strong>C 群</strong>在部分国家高发；<strong>B 群</strong>荚膜多糖免疫原性差，需用反向疫苗学研制的<strong>蛋白疫苗</strong>（4CMenB）。分群直接决定接种何种疫苗——"疫苗'跟着群走'"。</span>婴幼儿对多糖疫苗应答弱，需用**多糖-蛋白结合疫苗**增强免疫记忆，这也是"结合疫苗为何专为儿童设计"的原因。

## 2 淋球菌（淋病）

**淋球菌（N. gonorrhoeae）**：

**形态**：G- 双球菌（肾形）、**菌毛**（黏附尿道黏膜）、无荚膜。
**传播**：**性接触**（淋病）、母婴（产道——新生儿眼炎）。
**致病**：菌毛黏附→侵入尿道/宫颈黏膜→**化脓性炎症**（中性粒细胞——脓性分泌物）。

**淋病（gonorrhea）**：

**男性**：**急性尿道炎**——**尿道脓性分泌物、尿痛**——"淋病'流脓尿痛'"（呼病理学性传播疾病篇）。
**女性**：宫颈炎（多无症状——可上行盆腔炎、输卵管炎→不孕）。
**新生儿**：产道感染→**新生儿眼炎**（脓性眼炎）——"新生儿眼炎'产道淋球菌'"。

### 未被及时治疗的下行并发症

淋病如果不治，感染会沿着黏膜"爬升"：<span class="marginnote"><strong>女性上行感染的代价</strong>：宫颈炎→子宫内膜炎→输卵管炎→盆腔炎（PID），反复发作可致<strong>输卵管粘连梗阻→宫外孕与不孕</strong>。这是淋病在女性身上"沉默而严重"的根本原因——多数女性感染者早期无症状，等到发现往往已形成不可逆损伤。</span>男性上行则多为**前列腺炎、附睾炎**。此外约 **0.5%–3%** 的患者可发生**播散性淋球菌感染（DGI）**：菌血症→关节、皮肤、心内膜炎，表现为关节炎-皮炎综合征——"淋球菌'入血'（DGI）"。

### 防治

**治疗**：**头孢曲松**（三代头孢——淋球菌）；**新生儿眼炎预防（出生时红霉素/硝酸银眼膏）**——"新生儿'眼膏预防'"。
性传播疾病防控（安全套、性伴同治）。

**耐药警示**：淋球菌是著名的"耐药银行"——历史上对**磺胺、青霉素、四环素、喹诺酮**相继耐药，如今一线方案被迫升级为**头孢曲松+阿奇霉素**。<span class="marginnote"><strong>淋病'多重耐药'</strong>：奈瑟菌可借<strong>质粒</strong>携带 β-内酰胺酶基因（TEM-型青霉素酶），对青霉素耐药；喹诺酮耐药由<strong>染色体 gyrA 突变</strong>所致。故临床不再用青霉素/喹诺酮治淋病，改以<strong>头孢曲松 250 mg 肌注</strong>为首选——"淋病'头孢曲松'"（呼药理三代头孢）。</span>

**"淋病'化脓性尿道炎'"**：淋球菌菌毛黏附尿道→中性粒细胞化脓——"淋病'脓性'"（呼病理学淋病——尿道炎）。<span class="marginnote"><strong>"淋病（尿道炎）"</strong>：淋球菌菌毛黏附尿道→中性粒细胞→脓性分泌物——"淋病'流脓'"（呼病理学性传播疾病篇淋病）。<strong>"新生儿眼炎（预防）"</strong>：产道淋球菌/衣原体→新生儿结膜炎——"出生'眼膏预防'（红霉素）"（呼儿科预防）。<strong>"淋球菌'头孢曲松'"</strong>：淋球菌耐药（青霉素/喹诺酮）→三代头孢——"淋病'头孢曲松'"（呼药理三代头孢）。</span>

| 对比项 | 脑膜炎球菌 | 淋球菌 |
| --- | --- | --- |
| 形态 | G- 双球菌（荚膜+） | G- 双球菌（无荚膜、菌毛） |
| 传播 | 飞沫 | 性接触、母婴 |
| 所致 | 流脑（脑膜炎） | 淋病（尿道炎）、新生儿眼炎 |
| 关键毒力 | 荚膜、内毒素 | 菌毛 |
| 疫苗 | 荚膜多糖疫苗 | 无 |
| 治疗 | 青霉素/头孢曲松 | 头孢曲松 |
| 耐药重点 | 少见 | 多药耐药（青霉素/喹诺酮） |

## 4 术语速查表

| 术语 | 含义 |
| --- | --- |
| 苛养菌 | 营养要求高、普通培养基不长的细菌（奈瑟菌属为典型） |
| 华-佛综合征 | 暴发型流脑的内毒素休克，伴双侧肾上腺出血 |
| DGI | 播散性淋球菌感染（菌血症+关节炎-皮炎） |
| 瘀点瘀斑 | 内毒素致血管内皮损伤出血，流脑特征性皮损 |
| 巧克力平板 | 加热血平板，供奈瑟菌等苛养菌生长 |
| 密切接触者 | 流脑患者的家人/同宿舍/同教室者，需药物预防清菌 |
| 血清群 | 按荚膜多糖抗原分群（A/B/C/W135/Y），决定疫苗选择 |

**辨析｜易错点：** 脑膜炎球菌"荚膜+内毒素"（流脑——瘀点）、淋球菌"菌毛"（淋病——尿道炎）——"脑膜'荚膜'、淋球'菌毛'"。另一个易错点：**新生儿眼炎是产道淋球菌**（出生时眼膏预防）——"新生儿'眼膏'"。第三个易错点：**流脑是飞沫+荚膜多糖疫苗，淋病是性接触+无疫苗**——传播与疫苗两个维度最容易记混。

## 5 小结

- **脑膜炎球菌**：G- 双球菌、荚膜+内毒素——**流脑**（鼻咽→血→脑膜；高热、颈强直、**瘀点瘀斑**）；荚膜多糖疫苗+青霉素/头孢曲松。
- **淋球菌**：G- 双球菌、菌毛——**淋病**（尿道脓性分泌物）、新生儿眼炎（产道）；头孢曲松+出生眼膏预防。
- 补体（MAC）缺陷→奈瑟菌易感——"补体缺陷'奈瑟菌'"（呼免疫缺陷篇）。
- 带菌者远比患者多（流行期 30%–50% vs 发病 <1%）——流脑防控靠疫苗而非只隔离患者。
- 淋球菌多重耐药（青霉素/喹诺酮）→一线已升级为头孢曲松；女性上行感染可致不孕。
- 流脑密切接触者需利福平/头孢曲松药物预防——清菌切断传播链，而非仅靠疫苗。
- 奈瑟菌属均为苛养菌，标本需保温速送、巧克力平板培养——诊断环节的隐性考点。
