## 为什么从转录开始

中心法则的第一步是**转录（transcription）**——以 DNA 一条链为模板，由 **RNA 聚合酶**合成 RNA。转录是**基因表达**的第一步，其调控决定细胞"何时表达哪个基因"。理解转录的机制（起始、延伸、终止）与原核/真核的差别，是理解基因表达调控与抗生素（利福平）的基础。<span class="marginnote">转录的要点：<strong>模板链</strong>（反义链，被转录）与<strong>编码链</strong>（有义链，序列与 mRNA 相同）；<strong>RNA 聚合酶</strong>（不需引物、5'→3'、无校对）；合成方向 5'→3'。<strong>转录单位</strong>：启动子→基因→终止子。真核转录在<strong>核内</strong>进行，产物是前体 mRNA（hnRNA）再加工（下篇）。</span>

"RNA 聚合酶为什么不需要引物""启动子怎么决定转录起点""利福平（抗结核）为什么有效"——转录回答这些问题。

## 1 RNA 聚合酶与转录的基本过程

**RNA 聚合酶（RNA polymerase）**：以 DNA 为模板合成 RNA（5'→3'），**不需引物**（与 DNA 聚合酶不同）、无 3'→5' 校对（RNA 合成错误率较高）。

**原核**：一种 RNA 聚合酶（核心酶+σ 因子）。
**真核**：三种——**RNA 聚合酶Ⅰ**（rRNA）、**Ⅱ**（mRNA，最重要）、**Ⅲ**（tRNA、5S rRNA）。

**转录三步**：

1. **起始**：RNA 聚合酶结合**启动子（promoter）**→DNA 局部解链→开始合成 RNA（第一个 NTP）。
2. **延伸**：聚合酶沿模板 3'→5' 移动，RNA 5'→3' 合成（模板链被转录）。
3. **终止**：遇到终止信号→RNA 释放、聚合酶解离。<span class="marginnote"><strong>模板链 vs 编码链</strong>：转录只用<strong>模板链（反义链）</strong>；编码链（有义链）序列与 mRNA 相同（只是 T→U）——"读编码链就知道 mRNA"。<strong>启动子</strong>是 DNA 上 RNA 聚合酶结合/起始的序列（原核 -10/-35 区；真核 TATA box 等）——"启动子决定转录起点与强度"。<strong>真核 RNA 聚合酶Ⅱ</strong>需<strong>通用转录因子（TFⅡD 等）</strong>协助结合启动子——"聚合酶不能自己识别启动子"。<strong>利福平</strong>：抑制<strong>原核 RNA 聚合酶</strong>（结合 β 亚基阻断起始）→抗结核——"选择性抑制细菌转录"。<strong>α-鹅膏蕈碱</strong>抑制真核 Pol Ⅱ。</span>

## 2 真核转录的特点

**真核转录**与原核的差别：

**在核内**，RNA 需加工后运到胞质。
**三种 RNA 聚合酶**（分工转录不同 RNA）。
**启动子复杂**（TATA box、增强子、沉默子——受转录因子调控）。
**前体 RNA 需加工**：5' 加帽、3' 加尾、**剪接**（去除内含子）（下篇详述）。
转录与翻译**分离**（原核转录与翻译偶联）。

**单顺反子 vs 多顺反子**：真核 mRNA 是**单顺反子**（一个 mRNA 编码一个蛋白）；原核 mRNA 常是**多顺反子**（一个 mRNA 编码多个蛋白，如乳糖操纵子）。<span class="marginnote"><strong>真核转录的"加工程序"</strong>：初级转录本（hnRNA）→加帽（5' 7-甲基鸟苷）→加尾（3' poly(A)）→<strong>剪接</strong>（去掉内含子、连接外显子）→成熟 mRNA 出核。<strong>顺反子（cistron）=基因</strong>：真核"一基因一 mRNA 一蛋白"（单顺反子），原核"一操纵子一 mRNA 多蛋白"（多顺反子，乳糖操纵子的结构基因共享一个启动子）——"原核的'组批生产'vs 真核的'单件加工'"。<strong>增强子/沉默子</strong>：远离启动子的调控序列，被转录因子结合→增强/抑制转录（"远程调控基因表达"）。</span>

## 3 转录的调控（概论）

**基因表达调控**主要发生在**转录水平**（"节流阀在转录"）：

**转录因子（transcription factor）**：与启动子/增强子结合的蛋白，激活或抑制转录（如 p53、NF-κB、类固醇激素受体）。
**顺式元件**：启动子、增强子、沉默子（DNA 上的调控序列）。
**反式因子**：转录因子（蛋白，结合顺式元件）。
**表观遗传**：DNA 甲基化、组蛋白修饰（乙酰化激活/甲基化沉默）影响染色质可及性→调控转录。

**临床意义**：肿瘤的转录异常（癌基因过表达/抑癌基因沉默）、激素的基因调控（类固醇受体→转录）、药物的转录效应。<span class="marginnote"><strong>"转录是基因表达的'总闸门'"</strong>：细胞分化、发育、疾病大多通过调控转录实现。<strong>转录因子</strong>（TF）是"开关执行者"：类固醇激素→胞内受体（TF）→入核结合激素反应元件→激活/抑制靶基因转录（信号转导篇的胞内受体机制）。<strong>表观遗传</strong>：DNA 甲基化（CpG 岛，常沉默基因）、组蛋白乙酰化（激活）/去乙酰化（沉默）——<strong>去甲基化/去乙酰化酶是抗癌药靶点</strong>（如 HDAC 抑制剂）。<strong>肿瘤的转录异常</strong>：MYC 过表达、p53 突变失活——"肿瘤是转录调控失控的病"（下篇基因表达调控详述）。</span>

## 4 核心对比表：转录 vs 复制

| 对比项 | 转录 | 复制 |
| --- | --- | --- |
| 模板 | DNA 一条链（模板链） | DNA 两条链 |
| 产物 | RNA（单链） | DNA（双链） |
| 聚合酶 | RNA 聚合酶（不需引物） | DNA 聚合酶（需引物） |
| 校对 | 无 | 有（3'→5' 外切） |
| 碱基 | A-U（U 替 T） | A-T、G-C |
| 范围 | 部分基因 | 全基因组 |

**辨析｜易错点：** **RNA 聚合酶不需引物、无校对**（与 DNA 聚合酶相反）——"转录快但粗、复制慢但准"。另一个易错点：**模板链 vs 编码链**：转录用模板链（反义链），编码链（有义链）与 mRNA 同序列——"模板链是'被读的'、编码链是'相同的'"。

## 5 数值算例：转录的效率与抗生素靶点

**转录的速度与错误率**：RNA 聚合酶合成 RNA 的速度约 **50~100 核苷酸/秒**（真核），远快于 DNA 复制。**转录的错误率约 10⁻⁴~10⁻⁵**（比复制高 2~3 个数量级）——因为 RNA 聚合酶无校对功能。这"快而粗"的代价可接受，因为 mRNA 是短暂的、错误的 mRNA 很快被降解。<span class="marginnote">"转录快、复制慢"的设计哲学：<strong>mRNA 寿命短（分钟~小时级）</strong>，转录错误很快被清除，所以"粗一点没关系"；而 DNA 是遗传蓝图、需长期保存，必须精确（校对）。"转录频率×mRNA 稳定性"决定蛋白产量——这也是基因表达调控的一个维度。</span>

**基因表达的"成本"**：一个基因可被反复转录（多个 mRNA）、一个 mRNA 可被反复翻译（多个蛋白）——"一个基因可以产生大量蛋白"的放大效应。转录调控决定"转录多少次"，是基因表达的主要控制点。<span class="marginnote">"转录是'节流阀'的经济学"：调控转录比调控翻译更"划算"（一个开关控制一条生产线）。这就是为什么<strong>大多数基因调控发生在转录水平</strong>——"在源头控制最省力"。</span>

**启动子的序列特征**：原核 -10 区（TATAAT，Pribnow box）与 -35 区（TTGACA）是 RNA 聚合酶识别的关键序列；真核 TATA box（约 -25~-30）由 TFⅡD（TBP 蛋白）识别。启动子序列保守性越高，转录效率越高——"启动子强弱决定基础转录水平"。

## 6 临床联系：转录异常与药物

**转录相关药物**：**利福平**抑制原核 RNA 聚合酶（结合 β 亚基，阻断转录起始）——抗结核一线药，选择性强（不抑制真核聚合酶）。**α-鹅膏蕈碱**（毒蕈毒素）抑制真核 Pol Ⅱ（mRNA 转录）——毒蘑菇中毒致肝衰竭的机制之一。<span class="marginnote">"选择性抑制转录的药"：<strong>利福平</strong>（抗结核）专打细菌转录；<strong>放线菌素 D</strong>（抗生素）嵌入 DNA 干扰转录（抗肿瘤）；α-鹅膏蕈碱毒蘑菇。"为什么抗生素能选择性杀伤细菌"——<strong>细菌与人类的 RNA 聚合酶结构不同</strong>（利福平只结合细菌酶），这是"选择性毒性"的分子基础（与 β-内酰胺类同理）。</span>

**转录因子与疾病**：**p53**（抑癌基因，转录因子）突变→失去抑癌功能→肿瘤；**类固醇激素受体**（转录因子）被激素激活→调控靶基因→治疗（激素治疗）；**MYC、RAS** 等癌基因过表达→转录失调→增殖失控。<span class="marginnote">"转录因子是疾病的枢纽"：<strong>p53 是"基因组卫士"</strong>（损伤时激活靶基因促修复/凋亡），突变使其失活→肿瘤（超过半数肿瘤有 p53 突变）。类固醇受体是"激素→基因"的桥梁（胞内受体机制，见信号转导篇）。<strong>靶向转录因子的药物</strong>（如 HDAC 抑制剂、蛋白酶体抑制剂）正在发展——"调控转录调控者是癌症治疗的新方向"。</span>

**表观遗传与肿瘤**：DNA 甲基化（启动子 CpG 岛高甲基化→抑癌基因沉默）、组蛋白修饰（去乙酰化→染色质关闭）——**去甲基化药（氮杂胞苷）与 HDAC 抑制剂**（伏立诺他）已用于血液肿瘤。<span class="marginnote">"表观遗传治疗的原理"：<strong>抑癌基因被异常甲基化/去乙酰化"静音"→逆转这些修饰可"重新打开"抑癌基因</strong>。氮杂胞苷（去甲基化）、伏立诺他（HDAC 抑制剂）治疗 MDS/皮肤 T 细胞淋巴瘤。"表观遗传是可逆的"——这正是它与基因突变（不可逆）的重要区别、也是药物设计的依据。</span>

**遗传病的转录基础**：β-地中海贫血（珠蛋白基因转录/剪接异常）、血友病等——"基因突变影响转录调控元件（启动子、剪接位点）"是许多遗传病的分子机制。

## 7 术语速查表

| 术语 | 定义 |
| --- | --- |
| 转录 | DNA 模板链→RNA（RNA 聚合酶） |
| 模板链 / 编码链 | 被转录链 / 与 mRNA 同序列的链 |
| RNA 聚合酶 | 不需引物、无校对、5'→3' |
| 启动子 | RNA 聚合酶结合起始的 DNA 序列 |
| 顺反子 | 一个基因（真核单顺反子、原核多顺反子） |
| 转录因子 | 结合启动子/增强子调控转录的蛋白 |
| 增强子 / 沉默子 | 远程激活 / 抑制转录的元件 |
| 表观遗传 | DNA 甲基化、组蛋白修饰调控表达 |
| 利福平 | 抑制原核 RNA 聚合酶（抗结核） |
| α-鹅膏蕈碱 | 抑制真核 Pol Ⅱ（毒蘑菇） |
| 单顺反子 | 一个 mRNA 编码一个蛋白（真核） |
| 多顺反子 | 一个 mRNA 编码多个蛋白（原核） |

**易错点复习：** 转录的三组辨析——"模板链（被读）vs 编码链（与 mRNA 同序）"、"RNA 聚合酶不需引物无校对 vs DNA 聚合酶需引物有校对（转录快粗、复制慢准）"、"真核 Pol Ⅰ/Ⅱ/Ⅲ（rRNA/mRNA/tRNA）分工 vs 原核一种聚合酶"。把这三组记住，转录的机制与调控就完整了。

## 8 小结

- **转录**以 DNA 模板链为模板，RNA 聚合酶合成 RNA（5'→3'、不需引物）；原核一种聚合酶、真核三种（Pol Ⅱ 转录 mRNA）。
- 三步：**起始**（启动子）、**延伸**、**终止**；利福平抑制原核聚合酶（抗结核）。
- **真核转录**在核内、需加工（加帽加尾剪接）、单顺反子；原核多顺反子、转录翻译偶联。
- **转录调控**是基因表达的"总闸门"：顺式元件+转录因子+表观遗传（甲基化、组蛋白修饰）。
- **数值锚点**：转录速度 50~100 nt/s、错误率 10⁻⁴~10⁻⁵（无校对）、mRNA 寿命分钟~小时级——"速度、错误、寿命"是转录效率与调控的量化指标。
- **一句话收束**：转录 = "DNA 模板链→RNA（不需引物、无校对）"，是中心法则与基因表达的第一步；"启动子定起点、转录因子定开关、表观遗传定可及性"，三者构成转录调控的三层——"转录是基因表达的'总闸门'"。

**一句话总结本篇**：转录 = "DNA 模板链 → RNA（RNA 聚合酶，不需引物、无校对）"，是中心法则与基因表达的第一步——原核一种聚合酶、真核三种（Pol Ⅱ 管 mRNA）；"启动子定起点、转录因子定开关、表观遗传定可及性"构成调控三层。理解转录，就理解了利福平抗结核、α-鹅膏蕈碱中毒、肿瘤的转录异常与表观遗传治疗。

**自测三问**：①模板链与编码链有何区别？②RNA 聚合酶与 DNA 聚合酶有何不同？③真核转录与原核转录的三大差别？——能答出这三点，转录就掌握了。
