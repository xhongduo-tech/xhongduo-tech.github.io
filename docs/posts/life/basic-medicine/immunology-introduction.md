## 为什么从免疫学概论开始

**免疫学（immunology）**研究免疫系统的结构与功能——**免疫防御、免疫监视、免疫自稳**。理解**固有免疫（innate）**与**适应性免疫（adaptive）**的区别、免疫应答的类型与免疫病理（超敏、自身免疫、免疫缺陷、肿瘤免疫），是理解疫苗、感染、移植与肿瘤免疫治疗的基础。<span class="marginnote"><strong>免疫系统的三大功能</strong>：<strong>免疫防御</strong>（抗感染）、<strong>免疫监视</strong>（抗肿瘤）、<strong>免疫自稳</strong>（清除衰老损伤细胞——防自身免疫）。<strong>免疫应答分两类</strong>：<strong>固有免疫</strong>（先天、非特异、快——屏障、吞噬、补体、NK 细胞）与<strong>适应性免疫</strong>（后天、特异、慢但记忆——T/B 细胞、抗体）。<strong>免疫学的核心"自我/非我"识别</strong>：免疫系统区分"自己"（耐受）与"非己"（攻击）——识别异常→<strong>自身免疫病</strong>。</span>

"固有免疫和适应性免疫怎么分工""什么是'免疫记忆'（疫苗原理）""免疫系统的'三大功能'是什么""免疫异常怎么'致病'（超敏/自身免疫/缺陷）"——免疫学概论回答这些问题。

## 1 固有免疫与适应性免疫

**固有免疫（innate immunity）**（先天、非特异、第一道防线）：

- **屏障**：皮肤黏膜（物理）、化学（胃酸、溶菌酶）、微生物屏障（正常菌群）。
- **细胞**：**吞噬细胞**（中性粒细胞、巨噬细胞——吞噬杀菌）、**NK 细胞**（杀病毒感染/肿瘤细胞）、树突状细胞（抗原提呈）。
- **分子**：**补体**（溶菌、调理、炎症）、急性期蛋白（CRP）、溶菌酶、干扰素。
- **特点**：**快（数小时）、非特异、无记忆**。

**适应性免疫（adaptive immunity）**（后天、特异、慢但记忆）：

- **细胞免疫**：**T 淋巴细胞**（CTL 杀伤、Th 辅助）。
- **体液免疫**：**B 淋巴细胞→浆细胞→抗体**。
- **特点**：**慢（数天）、特异（抗原特异）、记忆（再次快而强）**。

**"固有 vs 适应"的关系**：固有免疫（第一道+启动适应性）；适应性免疫（特异清除+记忆）——"固有'先遣'、适应'精锐'"（固有免疫提呈抗原→启动适应性免疫）。<span class="marginnote"><strong>"固有 vs 适应"（核心对比）</strong>：固有（先天、非特异、快、无记忆——屏障/吞噬/补体/NK）；适应（后天、特异、慢、<strong>记忆</strong>——T/B 细胞/抗体）——"固有'快而泛'、适应'慢而准'"（疫苗利用适应性免疫的记忆）。<strong>免疫记忆（疫苗原理）</strong>：初次接触抗原→产生记忆 T/B 细胞→再次接触→<strong>快速强应答（回忆应答）</strong>——"疫苗'人工诱导免疫记忆'（防感染）"（呼微生物学疫苗）。<strong>NK 细胞"固有免疫监视"</strong>：NK 杀病毒感染/肿瘤细胞（不需致敏）——"NK'固有免疫'（杀病毒感染/肿瘤）"。<strong>补体"固有免疫分子"</strong>：溶菌、调理（促吞噬）、趋化、炎症——"补体'固有免疫'（炎症与溶菌）"（免疫学补体篇详述）。</span>

## 2 免疫应答的基本过程

**适应性免疫应答**的基本过程：

1. **抗原提呈**：**树突状细胞/巨噬细胞**摄取抗原→经 **MHC** 提呈给 T 细胞——"APC'提呈抗原'"。
2. **T 细胞活化**：**CD4⁺ Th 细胞**（辅助——激活 B 细胞/CTL）、**CD8⁺ CTL**（杀伤病毒感染/肿瘤细胞）。
3. **B 细胞活化与抗体**：B 细胞识别抗原→（Th 辅助）→**浆细胞分泌抗体**（中和、调理、激活补体）+**记忆 B 细胞**。
4. **效应与记忆**：清除病原+形成记忆（再次快速）。

**免疫应答的"三阶段"**：**识别（提呈）→活化增殖→效应清除**——"免疫应答'识别-活化-效应'"。

**免疫器官**（呼应淋巴系统解剖篇）：**中枢**（胸腺——T 细胞成熟、骨髓——B 细胞成熟）、**外周**（淋巴结、脾、黏膜淋巴组织——免疫应答场所）。<span class="marginnote"><strong>免疫应答的"核心角色"</strong>：<strong>APC（树突状细胞）提呈→CD4⁺ Th 辅助→B 细胞产生抗体/CD8⁺ CTL 杀伤</strong>——"免疫应答'提呈-辅助-效应'"（Th 是"指挥中枢"——HIV 攻击 CD4⁺ Th 导致免疫缺陷，呼艾滋病篇）。<strong>MHC（组织相容性复合体）</strong>：抗原提呈的"展示架"（提呈肽给 T 细胞）——"MHC'提呈'（个体差异——移植排斥的基础，呼移植免疫篇）"。<strong>免疫器官的"分工"</strong>：胸腺（T 成熟）、骨髓（B 成熟）、淋巴结/脾（应答场所）——"免疫器官'中枢+外周'"（呼淋巴系统解剖篇的胸腺/脾）。</span>

## 3 免疫病理：免疫异常与疾病

**免疫应答异常→疾病（免疫病理）**：

1. **超敏反应（hypersensitivity）**：免疫应答过强——**Ⅰ型（过敏——IgE/肥大细胞）**、Ⅱ型（抗体介导细胞毒）、Ⅲ型（免疫复合物）、Ⅳ型（T 细胞介导迟发型）——"超敏'免疫过强'"（免疫学超敏篇详述）。
2. **自身免疫病（autoimmune disease）**：免疫耐受破坏→攻击自身——"自身免疫'自我攻击'（免疫耐受失败）"。
3. **免疫缺陷（immunodeficiency）**：免疫应答不足——**原发性**（遗传）与**继发性**（HIV——AIDS）——"免疫缺陷'防线失守'（感染肿瘤）"。
4. **肿瘤免疫**：免疫监视逃逸→肿瘤；免疫治疗（PD-1）——"肿瘤'免疫逃逸'"。

**免疫学的临床应用**：**疫苗**（预防）、**血清/IVIG**（被动免疫）、**免疫诊断**（抗体检测——血清学）、**免疫治疗**（免疫抑制/增强/检查点）。<span class="marginnote"><strong>免疫病理的"四大类"</strong>：超敏（过强）、自身免疫（自我攻击）、免疫缺陷（不足）、肿瘤免疫逃逸——"免疫异常'过强/失守/逃逸'"（免疫学各篇详述：超敏反应篇、自身免疫病篇、免疫缺陷病篇、肿瘤免疫篇）。<strong>疫苗"主动免疫"</strong>：减毒/灭活/亚单位疫苗→诱导免疫记忆——"疫苗'主动免疫'（防传染病）"（呼微生物学与公共卫生）。<strong>IVIG/血清"被动免疫"</strong>：直接给抗体——"被动免疫'现成抗体'（紧急预防/免疫缺陷）"（呼药理免疫调节篇）。<strong>免疫诊断"血清学"</strong>：抗体/抗原检测（ELISA——感染、免疫病诊断）——"免疫诊断'抗体抗原'（ELISA）"（呼免疫学检测篇）。</span>

## 4 核心对比表：固有免疫 vs 适应性免疫

| 对比项 | 固有免疫 | 适应性免疫 |
| --- | --- | --- |
| 出现 | 先天 | 后天 |
| 特异性 | 非特异 | 特异 |
| 速度 | 快（小时） | 慢（天） |
| 记忆 | 无 | **有**（疫苗原理） |
| 成分 | 屏障、吞噬、补体、NK | T 细胞、B 细胞、抗体 |
| 作用 | 第一道防线+启动适应 | 精准清除+记忆 |

## 5 小结

- **免疫系统三大功能**：免疫防御（抗感染）、免疫监视（抗肿瘤）、免疫自稳（防自身免疫）。
- **固有免疫**（非特异、快、无记忆——屏障/吞噬/补体/NK）；**适应性免疫**（特异、慢、**记忆**——T/B 细胞/抗体）——疫苗利用免疫记忆。
- **免疫应答**：识别（APC 提呈）→活化（Th 辅助）→效应（抗体/CTL）+记忆。
- **免疫病理**：超敏（过强）、自身免疫（自我攻击）、免疫缺陷（不足）、肿瘤免疫逃逸——免疫学临床应用（疫苗、IVIG、诊断、免疫治疗）。

在下一节，我们看免疫系统的"组织机构"——**免疫器官与组织**：中枢免疫器官（胸腺、骨髓）与外周免疫器官（淋巴结、脾、MALT），以及"淋巴细胞的归巢与再循环"。
