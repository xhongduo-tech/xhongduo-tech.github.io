## 为什么从胃开始

食管把食团送进**胃（stomach）**——消化管最膨大的部分，一个"J"形的囊袋。胃不是简单的储存袋：它通过容受性舒张容纳食物，通过蠕动搅拌研磨，并通过胃腺分泌的胃酸与胃蛋白酶启动蛋白质的消化。<span class="marginnote">胃位于左季肋区与腹上区，上接食管（贲门），下续十二指肠（幽门）。空虚时呈管状，充盈时呈"J"形——胃的形态、位置随体位与充盈程度变化很大。</span>

胃也是消化系统疾病的重灾区：慢性胃炎、胃溃疡、胃癌都发生在胃。理解胃的解剖分区、血供与毗邻，是理解这些疾病的基础。

## 1 胃的形态与分部

**胃**有**两口、两缘、两面**：

**两口**：入口为**贲门**（与食管相接，位于第 11 胸椎左侧），出口为**幽门**（与十二指肠相接，位于第 1 腰椎右侧）。
**两缘**：上缘短而凹，为**胃小弯**（其最低点弯曲处称**角切迹**）；下缘长而凸，为**胃大弯**。
**两面**：前壁与后壁。

**胃分四部**：

**贲门部**：贲门周围的小部分。
**胃底（fundus）**：贲门平面以上向左上膨出的部分，与左膈穹窿相对。
**胃体（body）**：自胃底向下至角切迹的大部。
**幽门部（pyloric part）**：角切迹至幽门之间，又被中间沟分为左侧的**幽门窦**（胃窦）与右侧的**幽门管**。<span class="marginnote">幽门窦与幽门管合称"幽门部"。幽门窦是胃溃疡与胃癌的高发区——因为幽门螺杆菌最易在此定植，且该处黏膜接触的刺激物（胆汁反流、食物摩擦）较多。胃的切口与影像分区都以这些解剖标志为界。</span>

## 2 胃壁的构造

胃壁同样分四层，但有鲜明的特点：

**黏膜**：空腹时胃黏膜形成许多纵行皱襞，充盈时展平。黏膜表面可见**胃小凹**，是胃腺的开口。
**胃腺**：黏膜内的腺体，主要三种——**贲门腺**（黏液）、**幽门腺**（黏液与 G 细胞分泌促胃液素）、**胃底腺**（主体，含多种细胞）。
**黏膜下层**：疏松结缔组织，血管神经丰富。
**肌层**：平滑肌分三层——**外纵、中环、内斜**。环形肌在幽门处增厚形成**幽门括约肌**。**内斜层**是胃特有的第三层肌，配合搅拌研磨。<span class="marginnote">消化道肌层一般是"内环外纵"两层，胃多了最内层的斜行肌——这让胃能像揉面一样三维搅拌食物。幽门括约肌是"解剖学括约肌"（肌层明显增厚），与食管的"生理性括约肌"形成对照。</span>

**胃底腺的细胞**（生理学的关键预告）：主细胞分泌胃蛋白酶原，壁细胞分泌盐酸与内因子，颈黏液细胞分泌黏液，内分泌细胞（G 细胞、D 细胞）分泌激素。<span class="marginnote">"主细胞—胃蛋白酶原、壁细胞—盐酸+内因子、G 细胞—促胃液素"是生理学胃液分泌的基础。内因子缺乏（萎缩性胃炎、胃大部切除）导致维生素 B₁₂ 吸收障碍→巨幼细胞贫血。血型抗原还提示胃与免疫的关联——壁细胞抗体见于自身免疫性胃炎。</span>

## 3 胃的毗邻与血供

**胃的毗邻**：胃前壁右侧邻肝，左侧邻膈与腹前壁（该区称"胃裸区"，叩诊呈鼓音）；胃后壁隔**网膜囊**邻胰、左肾、左肾上腺、脾、横结肠等——这些器官构成"胃床"。<span class="marginnote">"胃床"（stomach bed）是胃后壁后方的器官群：胰、脾、左肾、左肾上腺、横结肠及其系膜、膈脚。理解胃床，才能理解胃癌向后方侵犯时最先累及哪些器官（常见为胰腺），以及"胃后壁溃疡穿破入胰腺"引起后背痛。</span>

**胃的血管**：胃血供极其丰富，主要来自腹腔干的分支——胃左动脉（沿胃小弯，最重要）、胃右动脉（来自肝固有动脉）、胃网膜左/右动脉（沿胃大弯）、胃短动脉（至胃底）。<span class="marginnote">胃的血供是"多条动脉吻合"的典型：小弯侧胃左+胃右动脉弓，大弯侧胃网膜左+右动脉弓。这种吻合使胃的供血非常安全，但也意味着胃出血的止血点很多——胃溃疡出血若保守无效需手术结扎多处血管。胃左动脉也是肝移植时可能的副供血来源。</span>

## 4 核心对比表：胃壁四层 vs 消化道通用四层

| 层 | 胃的特殊性 | 与通用的差异 |
| --- | --- | --- |
| 黏膜 | 胃小凹、胃底腺 | 腺体最发达，分泌盐酸与酶 |
| 黏膜下层 | 血管神经丰富 | 溃疡侵蚀到此处即"出血" |
| 肌层 | 外纵+中环+内斜 | 多一层内斜肌 |
| 外膜 | 大部分为浆膜 | 与"胃床"器官形成毗邻 |

**辨析｜易错点：** 初学者常把"胃底"理解为胃的最下方。实际上**胃底在贲门平面的左上方**，是胃的最高部位（充盈时气体积聚于此，卧位 X 线片上的"胃泡"就是它）。把"胃底"当"胃的下部"是常见误解——"底"字在这里指"囊底"（上端膨出部），而非解剖位置最低处。**胃的最低点其实是胃大弯下缘**。

## 5 数值算例：胃的容量与排空

**胃的容量变化**：新生儿约 30～50 ml，成人**空腹约 50 ml，饱餐后可达 1.5～2 L**——胃能"撑大"近 40 倍，这正靠**容受性舒张**（进餐时胃底与胃体平滑肌舒张以容纳食物而不升高胃内压）。<span class="marginnote">"容量从 50 ml 到 2 L"对应的是生理学"胃的容受性舒张"——<strong>迷走神经反射使胃底胃体舒张</strong>，胃内压几乎不变，人才能一顿吃下几百克食物而不撑坏。理解"胃是 J 形囊袋+容受性舒张"，就理解"胃下垂"（胃位置低）、"急性胃扩张"（容受性舒张失代偿）的机制。</span>

**胃排空的速度**：液体排空快（约 10～20 分钟开始、2～3 小时排空），固体排空慢（需先研磨成食糜，约 2～4 小时）。**脂肪排空最慢**（抑制胃排空），蛋白质居中，糖最快——所以"高脂餐后腹胀、饱腹感持久"。

**溃疡的"疼痛规律"与胃排空**：十二指肠溃疡"空腹痛、进食缓解"与胃溃疡"进食后痛"的区别，正与胃排空和胃酸接触时机相关——十二指肠溃疡的痛在胃酸排入十二指肠时（空腹），进食后胃酸被稀释中和而缓解。

**辨析｜易错点：** "胃底在贲门上方、是最高的部位"常被误解为"胃的最下方"——**胃底是胃的最高膨出部（充盈时气体积聚，卧位 X 线"胃泡"即它）**。另一个易错点：**胃酸不消化蛋白质的"大分子"结构**——胃蛋白酶原被盐酸激活为胃蛋白酶，但主细胞分泌的是"胃蛋白酶原"，需酸性环境激活；把"主细胞直接分泌胃蛋白酶"记错是常见错误。

## 6 临床联系：胃的常见疾病

**慢性胃炎**：幽门螺杆菌感染（最常见）→黏膜慢性炎症→腺体萎缩（萎缩性胃炎）→胃酸减少、内因子减少→**巨幼细胞贫血**（B₁₂ 吸收障碍）与**胃癌**风险增加。萎缩性胃炎是"癌前状态"。

**消化性溃疡**：胃溃疡（胃小弯、胃窦多见）与十二指肠溃疡（球部多见）。**幽门螺杆菌**是最主要病因（占消化性溃疡的绝大部分），其余为 NSAIDs（非甾体抗炎药）损伤胃黏膜。溃疡的解剖基础：**胃酸与胃蛋白酶"攻击"超出黏膜"防御"**——攻击因子（酸、胃蛋白酶、幽门螺杆菌）与防御因子（黏液、HCO₃⁻、血供、前列腺素）失衡。<span class="marginnote">溃疡的"三角"：<strong>幽门螺杆菌、NSAIDs、胃酸</strong>——三者共同决定溃疡发生。胃溃疡（小弯）与十二指肠溃疡（球部）位置不同，但都与胃酸攻击黏膜屏障有关。理解"胃小弯是溃疡好发处"（该处血供相对少、黏膜较薄、受食物摩擦多），就理解溃疡的解剖偏好。胃溃疡出血若侵蚀到黏膜下层的血管即"出血"（黑便/呕血）。</span>

**胃癌**：好发于**胃窦部（幽门部）**，与幽门螺杆菌、腌制食品（亚硝胺）、慢性萎缩性胃炎相关。早期可无症状，进展期表现为上腹痛、消瘦、呕血/黑便、腹部包块。**胃癌的转移途径**：淋巴道转移（至胃周淋巴结、Virchow 淋巴结=左锁骨上淋巴结）、血行转移（肝）、种植转移（胃癌细胞脱落种植于腹膜、卵巢"Krukenberg 瘤"）。<span class="marginnote">"胃癌向左锁骨上淋巴结转移（Virchow 淋巴结）、向卵巢种植（Krukenberg 瘤）"是两个经典考点——<strong>前者经胸导管淋巴回流，后者经腹腔种植</strong>。理解胃的淋巴回流与腹腔种植途径，就理解这些"远处转移"的解剖通道。胃后壁癌可侵犯胰腺（胃床），引起持续性背痛。</span>

**胃穿孔与急性腹膜炎**：胃/十二指肠溃疡穿孔→胃内容物进入腹腔→急性弥漫性腹膜炎（板状腹、膈下游离气体）。"板状腹"源于腹膜受刺激后的腹肌强直。

**辨析｜易错点：** "胃溃疡痛=进食后、十二指肠溃疡痛=空腹"要配套记忆——但别把"溃疡位置"与"疼痛规律"的对应机械套用（少数不典型）。另一个易错点：**NSAIDs（阿司匹林等）抑制前列腺素合成→胃黏膜防御下降**——前列腺素本可促进黏液分泌与血供，被抑制后黏膜易受损，这是"止痛药吃出胃溃疡"的机制。

## 7 术语速查表

| 术语 | 定义 |
| --- | --- |
| 贲门 | 胃的入口（与食管相接） |
| 幽门 | 胃的出口（与十二指肠相接） |
| 胃底 | 贲门平面以上、胃的最高膨出部 |
| 胃小弯 | 胃上缘短凹缘，角切迹处 |
| 胃大弯 | 胃下缘长凸缘 |
| 幽门窦 | 幽门部左侧，胃溃疡与胃癌好发处 |
| 幽门括约肌 | 幽门处环层肌增厚 |
| 胃底腺 | 主细胞（胃蛋白酶原）、壁细胞（盐酸+内因子）、G 细胞（促胃液素） |
| 胃床 | 胃后壁后方的器官群（胰、脾、左肾等） |
| 容受性舒张 | 进餐时胃底胃体舒张以容纳食物 |

**辨析｜易错点：** "幽门窦"与"幽门管"同属幽门部，但**胃溃疡/胃癌好发于幽门窦**（黏膜接触刺激物多、幽门螺杆菌易定植）——别把好发部位记成"幽门管"。另一个易错点：**胃的"贲门"处有"贲门括约肌"吗？**——贲门处无明确的解剖学括约肌（是生理性括约肌），幽门处才有增厚的幽门括约肌（解剖学括约肌）。"生理性括约肌 vs 解剖学括约肌"是常见考点。

## 8 小结

- 胃有**两口两缘两面**，分贲门部、胃底、胃体、幽门部（幽门窦+幽门管）四部。
- 胃壁肌层有**外纵、中环、内斜三层**，幽门处环层增厚为幽门括约肌。
- **胃底腺**含主细胞（胃蛋白酶原）、壁细胞（盐酸+内因子）、G 细胞（促胃液素）。
- 胃后壁隔网膜囊与**胃床**（胰、脾、左肾等）毗邻；血供来自腹腔干的多条分支。
- **临床对应**：慢性胃炎/溃疡（幽门螺杆菌）、胃癌（胃窦好发，Virchow 淋巴结与 Krukenberg 瘤转移）、胃穿孔（急性腹膜炎）——胃的解剖分区与毗邻直接决定疾病表现与转移途径。
- **数值备忘**：胃容量空腹约 50 ml、饱餐 1.5～2 L（容受性舒张）；胃底是最高膨出部（"胃泡"）。
- **与生理衔接**：胃的解剖（胃底腺细胞、幽门括约肌、容受性舒张）是生理学《胃液分泌与胃运动》的解剖基础——"哪层黏膜、哪些细胞、什么括约肌"全部在这里。
- **一句话收束**："胃是 J 形囊袋、四部两口、三层肌、胃底腺四细胞、血供走腹腔干、后壁靠胃床"——解剖六要素，临床都能用（溃疡、胃癌、出血、穿孔、转移）。
- **检查即解剖**：胃镜观察贲门-胃底-胃体-幽门窦-幽门全程、钡餐看"J 形"与胃泡、超声/CT 看胃壁四层与胃床——影像与内镜的每一步都对应胃的解剖分区。
- **跨系统串联**：胃与食管（贲门）、十二指肠（幽门）、肝（前壁邻肝）、胰脾左肾（胃床）的毗邻关系，把消化、肝胆胰、脾肾各系统在"胃"这一站连成一张腹部地图。
- **记忆口诀**："两口两缘四面体，四部（贲门胃底体幽门），胃底最高是泡气"——一口诀收住胃的基本形态，再配"小弯溃疡胃窦癌、血供腹腔干、后壁靠胃床"的临床要点。
- **综合应用**：一个"胃痛+黑便+消瘦"的病例，就能串起本篇全部要点——胃窦好发（胃癌）、黏膜下层血管（出血）、胃床侵犯（胰腺→背痛）、Virchow 淋巴结（远处转移）。
