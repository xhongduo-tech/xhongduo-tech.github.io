## 为什么从脊髓开始

进入中枢神经系统，第一站是**脊髓（spinal cord）**。它是脑与躯干四肢之间的"信息主干道"：上传感觉、下传运动，同时本身就能完成许多反射。脊髓损伤（外伤、肿瘤、炎症）导致的截瘫与感觉丧失平面，是最重要的神经定位诊断场景。<span class="marginnote">脊髓位于椎管内，上端在枕骨大孔处连延髓，下端成人约平<strong>第 1 腰椎下缘</strong>（新生儿平 L3）——所以腰椎穿刺（腰麻、取脑脊液）选 L3~L4 或 L4~L5 间隙，不会伤及脊髓。</span>

"为什么腰穿在腰椎而不在胸椎""脊髓与脊柱为什么不等长""脊髓半横断为什么表现为对侧痛温觉消失"——脊髓的解剖回答这些核心问题。

## 1 脊髓的外形与节段

**脊髓**呈前后略扁的圆柱形，有两个膨大：**颈膨大**（C5～T1，发出臂丛、支配上肢）与**腰骶膨大**（L2～S3，发出腰骶丛、支配下肢），其下逐渐变细为**脊髓圆锥**，末端延续为**终丝**。

**脊髓节段**：每对脊神经相连的一段脊髓为一个节段，共 31 个节段（颈 8、胸 12、腰 5、骶 5、尾 1）。由于脊柱比脊髓长，**脊髓节段高于相应椎骨**：颈段脊髓节段比相应椎骨高 1 个椎体，上胸段高 2 个，下胸段高 3 个，腰骶段约平 T10～L1。<span class="marginnote">"脊髓与脊柱不等长"是理解神经定位的关键：脊髓下端只到 L1，而神经根要继续下行到各自椎间孔——腰骶神经根在椎管内下行形成<strong>马尾</strong>（cauda equina）。因此：<strong>腰椎间盘突出压迫的往往不是"同名脊髓节段"，而是下行的神经根</strong>；"脊髓圆锥综合征"（T12~L1 损伤）表现为鞍区麻木、二便障碍，而"马尾综合征"（L2 以下）表现为下肢弛缓性瘫痪+鞍区感觉障碍。</span>

**脊髓被膜**：脊髓表面有三层被膜——**硬脊膜、蛛网膜、软脊膜**。蛛网膜与软脊膜之间的**蛛网膜下腔**含脑脊液，**腰椎穿刺**即在 L3/L4 间隙抽取此腔的脑脊液（麻醉药也注入此腔）。

## 2 脊髓的内部结构：灰质与白质

**灰质**（中央，横断面呈"H"形）分**前角、后角、侧角**与**中央灰质**：

**前角**：含运动神经元（躯体运动），其轴突组成前根——损伤→弛缓性瘫痪（下运动神经元瘫痪）。
**后角**：含感觉神经元（接受后根传入）——是痛温觉传导路的第一级换元站。
**侧角**：仅见于胸 1～腰 3（交感低级中枢）与骶 2～4（副交感），是内脏运动的低级中枢。<span class="marginnote">"前角运动、后角感觉、侧角内脏"是灰质的基本分工。<strong>前角运动神经元</strong>（下运动神经元）损伤：弛缓性瘫痪（肌张力低、肌肉萎缩、腱反射消失）；而锥体束（上运动神经元）损伤是痉挛性瘫痪（肌张力高、腱反射亢进、Babinski 征阳性）——"上/下运动神经元瘫痪的鉴别"是神经科的看家本领。</span>

**白质**（外周）被前/后根分为**前索、外侧索、后索**，含上行（感觉）与下行（运动）传导束：

**上行传导束**（感觉）：**薄束与楔束**（后索，传导本体感觉与精细触觉——同侧上行）、**脊髓丘脑束**（外侧索，传导痛温觉——交叉后上行）、**脊髓小脑束**（本体感觉至小脑）。
**下行传导束**（运动）：**皮质脊髓束（锥体束）**（前索与外侧索，传导随意运动）、皮质核束、红核脊髓束、前庭脊髓束等。<span class="marginnote">"痛温觉交叉、本体觉不交叉"是脊髓传导的核心规律：<strong>脊髓丘脑束</strong>在脊髓内先交叉（白质前连合）再上行，所以脊髓半横断（如脊髓半切综合征 Brown-Séquard）表现为<strong>同侧本体感觉/精细触觉丧失 + 对侧痛温觉丧失</strong>。而<strong>薄束楔束</strong>（本体觉）同侧上行、不交叉（交叉在延髓薄束核楔束核之后）。</span>

## 3 脊髓的传导功能与反射

**传导功能**：脊髓是感觉上行与运动下行的"干线"。感觉传导路的一般模式：**第一级神经元（脊神经节）→ 第二级神经元（脊髓后角或脑干核团）→ 交叉 → 第三级神经元（丘脑）→ 大脑皮层**。运动传导路：**大脑皮层运动区 → 皮质脊髓束 → 交叉（锥体交叉）→ 脊髓前角 → 骨骼肌**。

**反射功能**：脊髓是许多反射的中枢，如**膝跳反射**（L2~L4）、**跟腱反射**（S1~S2）、**屈曲反射（缩腿）**、**排尿排便反射**（骶髓）。

**脊髓横断损伤的表现**（定位诊断的核心）：

**完全横断**：损伤平面以下**弛缓性瘫痪**（急性期"脊髓休克"）→ 数周后转为**痉挛性瘫痪**；损伤平面以下**全部感觉丧失**；自主神经功能障碍（尿潴留、体温调节障碍）。
**半横断（Brown-Séquard）**：同侧**本体感觉与精细触觉**丧失 + **痉挛性瘫痪**；对侧损伤平面以下 **痛温觉**丧失（差 1～2 个节段）。
**前角损伤**（脊髓灰质炎、前角梗死）：节段性弛缓性瘫痪。
**后索损伤**（亚急性联合变性，维生素 B₁₂ 缺乏）：深感觉障碍、共济失调、Romberg 征阳性（闭眼站立不稳）。<span class="marginnote">脊髓病变的"节段"与"传导束"两个层面要分开记：<strong>灰质病变（前角/后角/侧角）引起节段性症状</strong>（某节段支配的肌肉或皮节受累），<strong>白质传导束病变引起损伤平面以下症状</strong>（整个上下行通路中断）。这是脊髓定位诊断的框架——MRI 是确认手段。</span>

## 4 核心对比表：脊髓上行与下行传导束

| 传导束 | 位置 | 传导内容 | 交叉部位 | 损伤表现 |
| --- | --- | --- | --- | --- |
| 薄束/楔束 | 后索 | 本体感觉、精细触觉 | 延髓（内侧丘系交叉） | 同侧深感觉丧失 |
| 脊髓丘脑束 | 外侧索 | 痛觉、温觉 | 脊髓白质前连合 | 对侧痛温觉丧失 |
| 皮质脊髓束（锥体束） | 外侧索/前索 | 随意运动 | 锥体交叉 | 同侧痉挛性瘫痪 |

**辨析｜易错点：** 脊髓丘脑束的交叉在**脊髓内**（白质前连合），锥体束的交叉在**延髓**（锥体交叉），薄束楔束的交叉也在**延髓**（内侧丘系交叉）——"三个交叉三个地点"是传导路最易混的地方。另一个高频考点：**痛温觉传导是"先交叉后上行"，本体觉是"先上行后交叉"**——所以脊髓半横断时痛温觉对侧丧失、本体觉同侧丧失。

## 5 数值算例：脊髓节段与椎骨的"对位"

**脊髓节段与椎体的对应关系**（定位诊断的换算表）：
- **颈段**（C1~C8）：脊髓节段数 = 相应椎骨序数 + 1（C1 例外）。
- **上胸段**（T1~T6）：脊髓节段 = 椎骨序数 + 2。
- **下胸段**（T7~T12）：脊髓节段 = 椎骨序数 + 3。
- **腰骶段**（L1~S5）：约平对 T10~L1 椎骨。

所以"**L3 椎体水平**的脊髓损伤"实际损伤的是**腰骶脊髓（或马尾）**，而非腰段脊髓——这是"脊髓与脊柱不等长"的直接后果，也是 MRI 报告里"脊髓圆锥位于 L1"的意义。<span class="marginnote">"同序数对不上"是脊髓定位的核心换算：<strong>查体发现某皮节/肌节异常，要反推受损的脊髓节段，再换算出对应椎体</strong>（颈髓高 1 椎、上胸高 2、下胸高 3、腰骶约 T10~L1）。<strong>腰椎穿刺选 L3/L4 或 L4/L5</strong>（在脊髓下端 L1 以下、马尾区），取脑脊液或注入麻药——"在 L1 以下穿刺不伤脊髓"正是这条换算的应用。</span>

**皮节（dermatome）的定位意义**：每个脊髓节段支配一定体表区域——T4 平乳头、T10 平脐、L3 平膝、S2~S3 会阴。**感觉平面**（受损平面以下感觉丧失）据此定位；**鞍区（S2~S4）麻木**提示骶髓或马尾受累（脊髓圆锥综合征、马尾综合征的关键线索）。

**辨析｜易错点：** "脊髓损伤=脊柱同节段损伤"是误区——因不等长，**同一椎体水平的骨折脱位所伤的脊髓节段低于该椎体**（如 T10 椎体损伤伤的是腰骶髓）。另一个易错点：**皮节定位用"关键皮节"**（C5 肩、C6 拇指、C7 中指、T4 乳头、T10 脐、L4 膝内侧、S1 足外侧）——记住这几个关键点即可快速评估感觉平面。

## 6 临床联系：脊髓病变综合征

**脊髓半切综合征（Brown-Séquard syndrome）**：脊髓一侧半横断（刀伤、肿瘤）→**同侧**损伤平面以下**运动瘫痪（锥体束）+深感觉/精细触觉丧失（薄楔束）**，**对侧**损伤平面以下**痛温觉丧失（脊髓丘脑束）**（差 1~2 节段）——"同侧运动深感觉、对侧痛温觉"是最经典的脊髓综合征。

**脊髓前动脉综合征**：脊髓前 2/3 缺血（前动脉闭塞）→**脊髓丘脑束（痛温觉）与锥体束（运动）受累、薄楔束（后索，后动脉供血）保留**→"痛温觉与运动丧失、但深感觉保留"。

**脊髓中央综合征**：脊髓中央部受损（过伸伤、空洞）→**交叉的脊髓丘脑束纤维（在白质前连合交叉，最靠内）先受累**→"上肢痛温觉丧失重于下肢（上肢纤维靠内）"，运动障碍也上肢重。

**亚急性联合变性**：维生素 B₁₂ 缺乏→**后索+侧索（锥体束）**变性→深感觉障碍+共济失调+锥体束征（痉挛性瘫痪）+Romberg 征阳性。<span class="marginnote">脊髓病变的"四大综合征"（半切、前动脉、中央、联合变性）对应传导束的"哪个层面、哪个束"——<strong>半切=单侧全束、前动脉=前 2/3、中央=交叉纤维、联合变性=后索+侧索</strong>。每记住一个综合征，就把传导束的"空间排列"又复习一遍：后索靠内（深感觉）、脊髓丘脑束外侧交叉纤维靠内、锥体束在侧索/前索。</span>

**脊髓压迫症**（肿瘤、椎间盘突出、结核）：进行性脊髓受压→**运动、感觉、括约肌障碍逐步加重**——先受压的是浅感觉与运动，后累及深感觉；"感觉平面"逐日上移提示病变进展。

**马尾综合征（cauda equina）**：L2 以下马尾受压（中央型椎间盘突出、肿瘤）→**下肢弛缓性瘫痪（下运动神经元，因伤的是神经根而非脊髓）+鞍区麻木+大小便障碍+阳痿**——外科急症（需尽早减压）。

**辨析｜易错点：** "脊髓圆锥综合征"（L1~S3 脊髓损伤）与"马尾综合征"（L2 以下神经根）的区别——**圆锥：下肢多为上/下运动神经元混合（腰膨大以上仍正常）、早期二便障碍、鞍区麻木**；**马尾：下肢弛缓性瘫痪（纯下运动神经元）、二便障碍稍晚、多为不对称**。两者都累及鞍区与括约肌，靠"下肢瘫痪性质+对称性"鉴别。

## 7 术语速查表

| 术语 | 定义 |
| --- | --- |
| 颈膨大 | C5~T1，发出臂丛支配上肢 |
| 腰骶膨大 | L2~S3，发出腰骶丛支配下肢 |
| 脊髓圆锥 | 脊髓下端变细处（约 L1） |
| 终丝 | 圆锥向下延续的细丝 |
| 马尾 | 腰骶神经根在椎管内的下行束 |
| 前角 | 运动神经元（下运动神经元） |
| 后角 | 感觉神经元（第一级换元） |
| 侧角 | 内脏运动（T1~L3 交感、S2~4 副交感） |
| 薄束/楔束 | 后索，本体感觉（同侧上行） |
| 脊髓丘脑束 | 外侧索，痛温觉（先交叉） |
| 皮质脊髓束 | 锥体束，随意运动（锥体交叉） |
| 蛛网膜下腔 | 含脑脊液，腰椎穿刺处 |

**辨析｜易错点：** "前角损伤=弛缓性瘫痪（下运动神经元）"与"锥体束损伤=痉挛性瘫痪（上运动神经元）"要分清——**同一"瘫痪"二字，前角是节段性弛缓、锥体束是损伤平面以下痉挛性**。另一个易错点：**侧角只存在于 T1~L3 与 S2~4**——胸段才有交感侧角，颈/腰骶段无（副交感在骶段 S2~4）。

## 8 小结

- **脊髓**位于椎管内，下端平 L1（成人）；有颈膨大与腰骶膨大，分 31 个节段。
- **灰质**：前角（运动）、后角（感觉）、侧角（内脏）；**白质**：上行（薄楔束、脊髓丘脑束）与下行（锥体束）传导束。
- 脊髓与脊柱不等长，腰骶神经根下行成**马尾**——腰椎穿刺选 L3~L4 间隙。
- 脊髓横断：完全横断→截瘫；半横断（Brown-Séquard）→同侧深感觉+运动障碍、对侧痛温觉障碍。
- **换算表**：颈髓高 1 椎、上胸高 2、下胸高 3、腰骶约 T10~L1；关键皮节（C5 肩、C6 拇、C7 中、T4 乳、T10 脐、L4 膝、S1 足外）。
- **四大综合征**：半切（同侧运动深感觉+对侧痛温）、前动脉（痛温+运动丢、深感觉留）、中央（上肢重于下肢）、联合变性（后索+侧索）——传导束的空间排列全部映射到临床。
