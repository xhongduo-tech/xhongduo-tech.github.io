## 为什么从肌学总论开始

骨提供了杠杆，关节提供了支点，但让杠杆真正转起来的是**骨骼肌（skeletal muscle）**。肌学总论回答三个问题：肌肉长什么样（形态）、肌肉怎么附着（起止点）、肌肉靠什么装置与骨和腱摩擦（辅助装置）。<span class="marginnote">人体有 600 多块骨骼肌，约占体重的 40%。肌学总论不逐块讲肌肉，而是讲"肌肉的一般规律"——掌握了规律，后面头颈肌、躯干肌、上下肢肌就只是往规律里填名字。</span>

肌学还与前面学过的神经、血管交汇：每块肌肉都有神经支配，没有神经的肌肉只是"死肉"（瘫痪）。因此本篇的起止点、作用、神经支配三位一体，是后面《脊神经》《脑神经》章节的前置接口。

## 1 骨骼肌的形态与构造

**骨骼肌（skeletal muscle）**由**肌腹**与**肌腱**两部分构成：**肌腹**是中部能收缩的膨大部分，由肌纤维（肌细胞）组成，色红而柔软，有收缩能力；**肌腱**是两端致密结缔组织构成的索状或膜状结构，色白、坚韧而无收缩力，借它附着于骨。

按外形，骨骼肌可分为：

**长肌**：梭形，多见于四肢，收缩幅度大。
**短肌**：短小，多见于躯干深层，收缩幅度小。
**扁肌**：薄而宽，多见于胸腹壁，兼有保护内脏的作用。
**轮匝肌**：环形，围绕孔裂（如口轮匝肌、眼轮匝肌），收缩时关闭孔裂。

按肌腹的数量，还可分**二腹肌、二头肌、三头肌、四头肌**等（如肱二头肌有两个头）。<span class="marginnote">肌腱的形状也分两种：长肌的腱多呈圆索状（如跟腱）；扁肌的腱常呈薄膜状，称"腱膜"（如腹外斜肌腱膜、颅顶的帽状腱膜）。腱膜可以理解成"平铺的肌腱"，是扁肌附着的方式。</span>

**肌肉的起止点**：通常把接近身体正中或靠近肢体近端的附着点叫**起点（定点）**，远离者叫**止点（动点）**。肌肉收缩时，一般止点向起点移动。但起止点是相对的——例如胸大肌起点在胸壁、止于肱骨，做引体向上时肱骨固定，反而胸壁向上移动。<span class="marginnote">"起止点可互换"是肌学的一个重要观点：同一个动作，是止点动还是起点动，取决于哪一端被固定。理解这一点，才能理解"爬行与直立时同一块肌作用不同"这类问题。</span>

## 2 肌肉的辅助装置

肌肉的工作离不开三样辅助装置，它们与前面关节学的辅助结构呼应：

**筋膜（fascia）**：包绕全身肌肉的结缔组织膜，分**浅筋膜**（皮下，含脂肪、浅血管神经）与**深筋膜**（包被每块肌与肌群）。深筋膜在四肢增厚形成**肌间隔**，分隔肌群；在腕踝部增厚形成**支持带**，像"表带"一样固定肌腱。深筋膜还在特定部位形成**筋膜鞘**，是感染沿筋膜间隙扩散的通道。<span class="marginnote">筋膜间隙是外科的重要概念：手部、前臂的深筋膜围成密闭间隙，感染（如"间隙感染"）可在其中迅速蔓延并压迫神经血管。而"筋膜间室综合征"正是骨筋膜室压力过高、压迫组织缺血，是骨折后的急症。</span>
**滑膜囊（synovial bursa）**：结缔组织小囊，内含滑液，位于肌腱与骨面之间（如肩峰下囊），减少摩擦。
**腱鞘（tendinous sheath）**：包绕长肌腱的鞘管，外层为纤维层（腱纤维鞘），内层为滑膜层（腱滑膜鞘），滑膜层又分壁层与脏层，两层之间的腔含少量滑液。腱鞘在手指部最发达。<span class="marginnote">腱鞘炎是手腕与手指最常见的劳损性疾病之一："妈妈手"（桡骨茎突狭窄性腱鞘炎）与"弹响指"（扳机指，指屈肌腱腱鞘炎）都与腱鞘的反复摩擦、炎症增厚有关。腱滑膜鞘的壁层与脏层在腱系膜处相连，化脓性腱鞘炎时脓液沿腱鞘蔓延，可迅速波及整个手指。</span>

## 3 肌肉的命名与作用

肌肉的命名常依据形状、位置、起止点、作用、肌束方向等因素，掌握命名规则能显著降低记忆负担：

| 命名依据 | 例 |
| --- | --- |
| 位置 | 冈上肌、肋间肌、腰大肌 |
| 形状 | 三角肌、菱形肌、斜方肌 |
| 起止点 | 胸锁乳突肌、肱桡肌 |
| 作用 | 拇收肌、旋前圆肌、提睾肌 |
| 肌束方向 | 腹直肌、腹横肌、斜角肌 |

肌肉的作用总是围绕关节：**屈、伸、收、展、旋内、旋外、环转、对掌**——这些词我们在关节学已经学过，肌学只是把它们"指派"给具体肌肉。

**辨析｜易错点：** 初学者常以为"每块肌肉只有一个作用"。实际上**多数肌肉跨过两个以上的关节，在不同条件下作用不同**。例如肱二头肌既屈肘又使前臂旋后，还协助屈肩；股四头肌既伸膝又屈髋。判断肌肉作用的方法是"沿肌纤维走向、看它跨过哪些关节、在关节哪一侧"——跨过关节前面必屈、后面必伸。

## 4 核心对比表：肌的三种辅助装置

| 装置 | 位置 | 功能 | 病变 |
| --- | --- | --- | --- |
| 筋膜 | 包绕肌肉/肌群 | 分隔、约束、传导力 | 筋膜间室综合征 |
| 滑膜囊 | 腱与骨之间 | 减摩擦 | 滑囊炎 |
| 腱鞘 | 包绕长肌腱 | 引导肌腱、减摩擦 | 腱鞘炎（弹响指） |

这三样装置对应的三类常见病（间室综合征、滑囊炎、腱鞘炎），是肌学总论直接通向临床的接口。

## 5 数值算例：骨骼肌的力学与临床测量

**骨骼肌的数量与占比**：人体有 600 多块骨骼肌，约占体重的 40%（男性因肌肉多略高、女性略低）。一块肌肉通常含数百至数千条肌纤维，每块肌都有明确的**神经支配**——失神经支配（脊髓损伤、神经损伤）→肌肉萎缩瘫痪。<span class="marginnote">"肌肉与神经的依存"：<strong>每块肌肉有专属神经支配</strong>（运动终板），神经损伤后肌肉失去刺激→萎缩（约数周开始）。肌力分级（0~5 级：0 无收缩、1 轻微收缩、2 无重力活动、3 抗重力、4 抗阻力、5 正常）是神经科查体的核心。"一块肌一条神经一个功能"是理解瘫痪定位的基础。</span>

**肌腱的强度**：肌腱是人体最坚韧的组织之一，**抗拉强度可达 50~100 MPa**（接近甚至超过骨骼）。跟腱是最粗大的肌腱（长约 15 cm），断裂多发生于剧烈运动（跳、跑）时——"跟腱断裂"的突然剧痛与"被人踢一脚"感。<span class="marginnote">"肌腱 vs 韧带"的辨析：<strong>肌腱连接肌与骨、韧带连接骨与骨</strong>——这是最容易混淆的一对（跟腱是肌腱、前交叉韧带是韧带）。肌腱无弹性（传导力）、韧带有限弹性（限制关节）。<strong>跟腱断裂</strong>：常见于 30~50 岁运动者，Thomposon 试验（捏小腿腓肠肌，足不能跖屈）阳性，需手术或保守修复。"肌腱抗拉强于骨"解释了为何剧烈牵拉时多是"骨撕脱"而非"肌腱断裂"。</span>

**肌肉的横截面积与力量**：肌肉最大收缩力与**生理横截面积**成正比（约每 cm² 可产生 30~40 N 力）。肌肉力量可通过训练增大（肌纤维肥大）、失用则萎缩。"肌肉的肥大 vs 增生"：成人肌纤维数目固定，训练主要使**肌纤维肥大**（肌原纤维增粗），而非数目增多。

## 6 临床联系：肌肉与腱的常见损伤

**肌肉拉伤与撕裂**：运动时肌肉过度牵拉→肌纤维损伤。分度：轻度（拉伤，疼痛）、部分撕裂（血肿、功能障碍）、完全断裂。好发部位：腘绳肌、股直肌、腓肠肌。**处理"RICE"原则**（休息、冰敷、加压、抬高）。<span class="marginnote">"肌肉损伤的 RICE 原则"：<strong>Rest（休息）+ Ice（冰敷）+ Compression（加压包扎）+ Elevation（抬高）</strong>——急性损伤的标准处理，与韧带损伤相同。"肌肉拉伤 vs 断裂"的鉴别：断裂时肌肉收缩无力+局部凹陷+超声确诊。"肌肉损伤后的康复"需循序渐进，过早负荷可再损伤。</span>

**筋膜间室综合征**：骨筋膜室（骨+深筋膜围成的密闭空间）内压力增高→组织缺血→剧烈疼痛、感觉异常、肌肉无力。常见于小腿、前臂骨折后。**急性间室综合征是外科急症**（需紧急切开减压筋膜）——延误可致肌肉坏死（Volkmann 挛缩）。<span class="marginnote">"筋膜间室综合征的'6P'"：<strong>疼痛（Pain）、苍白（Pallor）、感觉异常（Paresthesia）、无力（Paralysis）、无脉（Pulselessness）、紧张（Pressure）</strong>。原因是骨折出血/水肿使密闭间室内压升高→压迫神经血管→缺血坏死。"切开减压"（筋膜切开术）是唯一有效治疗。"骨筋膜室是'密闭的盒子'、压力一高就出大事"。</span>

**滑囊炎与腱鞘炎**：滑囊炎（肩峰下滑囊、髌前滑囊）——局部肿胀疼痛、活动受限；腱鞘炎（手腕屈肌腱、桡骨茎突）——"弹响指""妈妈手"。二者都与反复摩擦、劳损相关，治疗以休息、抗炎、局部注射为主。<span class="marginnote">"滑囊炎 vs 腱鞘炎"：<strong>滑囊在腱与骨之间（减摩擦）</strong>、<strong>腱鞘包绕长肌腱（引导+减摩擦）</strong>——位置不同但都因摩擦发炎。桡骨茎突狭窄性腱鞘炎（妈妈手）用 Finkelstein 试验（握拳尺偏时腕痛）诊断。"劳损性疾病的解剖学解释"：都是"摩擦最多的部位先出问题"。</span>

## 7 术语速查表

| 术语 | 定义 |
| --- | --- |
| 肌腹 / 肌腱 | 可收缩的肌腹 / 不可收缩的肌腱 |
| 长肌 / 短肌 / 扁肌 / 轮匝肌 | 按形态分（四肢 / 躯干深 / 腹壁 / 孔裂周围） |
| 起点 / 止点 | 定点（近中） / 动点（远离），可互换 |
| 筋膜 | 浅筋膜（皮下）/ 深筋膜（包被肌群） |
| 肌间隔 | 深筋膜增厚分隔肌群的隔 |
| 支持带 | 腕踝部固定肌腱的深筋膜增厚 |
| 滑膜囊 | 腱与骨之间含滑液的小囊（减摩擦） |
| 腱鞘 | 包绕长肌腱的鞘管（纤维层+滑膜层） |
| 腱膜 | 扁肌的膜状肌腱 |
| 筋膜间室综合征 | 骨筋膜室压力↑→组织缺血（急症） |
| 肌力分级 | 0~5 级肌力评估 |
| 跟腱 | 最粗大肌腱（连接腓肠肌与跟骨） |

**易错点复习：** 肌学总论的三组辨析——"肌腱连肌骨、韧带连骨骨（跟腱是肌腱、前交叉韧带是韧带）"、"起点止点可互换（取决哪端固定）"、"滑膜囊在腱与骨之间、腱鞘包绕长肌腱（位置不同、都减摩擦）"。把这三组记住，肌学的"形态-附着-辅助装置"就完整了。

## 8 小结

- **骨骼肌**由能收缩的**肌腹**与不能收缩的**肌腱**构成；按形态分长肌、短肌、扁肌、轮匝肌。
- 肌肉有**起点（定点）与止点（动点）**，但二者可互换，取决于哪端固定。
- 辅助装置三种：**筋膜**（分隔与约束）、**滑膜囊**（减摩擦）、**腱鞘**（引导肌腱）。
- 肌肉的作用由"跨过哪个关节、位于关节哪一侧"决定，多数肌肉多功能、可互换起止。
- **数值锚点**：600 多块骨骼肌约占体重 40%、肌腱抗拉强度 50~100 MPa（近骨）、肌力 0~5 级分级、跟腱长 15 cm——"数量、强度、分级、尺寸"是肌学的量化要点。
- **一句话收束**：肌学总论 = "肌腹+肌腱（形态）、起止点（附着）、筋膜滑膜囊腱鞘（辅助）"三要素——"形态定长相、附着定方向、辅助定摩擦"，加上"跨过关节哪侧定屈伸"，后面每块肌肉都能用这套规律解析。

**一句话总结本篇**：肌学总论是"肌肉的通用规律"——肌腹收缩、肌腱附着（起止点可互换）、筋膜滑膜囊腱鞘减摩擦；肌肉的作用由"跨过哪个关节、位于关节哪一侧"决定。"形态-附着-辅助装置"三要素加上"跨关节定屈伸"的规律，后面头颈肌、躯干肌、上下肢肌都只是往这套框架里填名字。

**自测三问**：①肌腹与肌腱在结构与功能上有何不同？②起点与止点为何可互换、举一个例子？③筋膜、滑膜囊、腱鞘三个辅助装置各对应什么常见病？——能答出这三点，肌学总论就掌握了。
