## 为什么从动脉粥样硬化开始

**动脉粥样硬化（atherosclerosis, AS）**是**冠心病、脑卒中、外周动脉病**的共同病理基础——全球第一死因。它是在**大中动脉内膜**发生的慢性炎症性病变，以**脂质沉积、纤维增生、斑块形成**为特征。理解 AS 的发病机制与斑块演变，是理解心脑血管病防治（他汀、抗血小板）的基础。<span class="marginnote"><strong>动脉粥样硬化的好发部位</strong>：主动脉（腹主动脉）、冠状动脉、脑动脉（Willis 环）、肾动脉、下肢动脉。<strong>危险因素</strong>：高 LDL、高血压、吸烟、糖尿病、肥胖、遗传（"血脂+血压+糖+烟"）。<strong>核心病变</strong>：<strong>粥样斑块（atheroma）</strong>——脂质核心（坏死+胆固醇结晶）+纤维帽。<strong>AS 是"慢性炎症"</strong>（内皮损伤→脂质浸润→炎症→斑块）。</span>

"为什么'血脂高'会堵血管""斑块怎么从'脂纹'变成'粥样斑块'""易损斑块为什么'破裂'致心梗"——动脉粥样硬化回答这些问题。

动脉粥样硬化是「血管的慢性炎症」，与《炎症基本病理》的慢性炎症→纤维化一脉相承，又与代谢篇的血脂代谢（LDL/HDL）直接挂钩。它向下是所有心脑血管病——《冠心病》《高血压病》——的病理起点，向上是药理学他汀、抗血小板药的靶点基础。

把「脂质浸润 + 炎症」这条双线记住，整个心脑血管病防治的逻辑就通了：降脂是减少「燃料」，抗炎与稳定斑块是减少「引爆」，抗血小板是扑灭「火花」。

## 1 危险因素与发病机制

**危险因素（可控与不可控）**：

**不可控**：年龄、性别（男>绝经前女）、遗传家族史。
**可控**：**高血脂（高 LDL、低 HDL）**、**高血压**、**吸烟**、**糖尿病**、肥胖、缺乏运动。

**发病机制（内皮损伤-脂质浸润-炎症学说）**：

1. **内皮损伤**：高血压、吸烟、高血糖、ox-LDL 损伤内皮。
2. **脂质浸润**：LDL 进入内膜→被氧化成 **ox-LDL**。
3. **炎症反应**：单核细胞→巨噬细胞→吞噬 ox-LDL→**泡沫细胞（foam cells）**。
4. **纤维增生**：平滑肌细胞迁移增殖→合成胶原→纤维帽。
5. **斑块形成**：脂质核心+纤维帽→**粥样斑块**。<span class="marginnote"><strong>AS 的"四步"</strong>：内皮损伤→脂质浸润（ox-LDL）→巨噬细胞吞噬→泡沫细胞→纤维帽包裹脂质核心→粥样斑块——"<strong>AS 是'脂质+炎症'的双重奏</strong>"。<strong>泡沫细胞</strong>是 AS 的"细胞标志"（巨噬细胞吞噬 ox-LDL 形成的"泡沫样"细胞）——"斑块的'主角细胞'"。<strong>"内皮损伤-炎症"是 AS 的启动</strong>：高血压/吸烟/糖尿病损伤内皮→LDL 渗入→炎症（呼应炎症篇的慢性炎症→纤维化）。<strong>危险因素的"代谢连接"</strong>：高 LDL（脂代谢，见血脂篇）、高血压（血流冲击）、糖尿病（糖化损伤）——"代谢综合征是多因素叠加促 AS"。</span>

## 2 粥样斑块的形态与演变

**粥样斑块（atheromatous plaque）的形态**（从早到晚）：

1. **脂纹（fatty streak）**：内膜下泡沫细胞聚集——最早的病变（青少年即有，可逆）。
2. **纤维斑块（fibrous plaque）**：平滑肌增生+胶原+泡沫细胞→隆起。
3. **粥样斑块（atheroma）**：**纤维帽 + 脂质核心**（坏死物+胆固醇结晶）——成熟斑块（"粥样"=脂质呈粥状）。
4. **复合病变（complicated lesion）**：斑块内**出血、溃疡、血栓形成、钙化**——"晚期斑块的并发症"。

**斑块的两种命运**：

**稳定斑块**：纤维帽厚、脂质核心小——稳定（无症状或慢性狭窄）。
**易损斑块（vulnerable plaque）**：纤维帽**薄**、脂质核心大、炎症重——**易破裂**→血栓→**急性心梗/脑梗**。<span class="marginnote"><strong>斑块的"演化谱"</strong>：脂纹（早期、可逆——"青少年动脉的黄色条纹"）→纤维斑块→粥样斑块（纤维帽+脂质核心）→复合病变（出血/溃疡/血栓/钙化）。<strong>"粥样"的由来</strong>：斑块切面脂质呈"粥状"（坏死+胆固醇结晶）。<strong>稳定 vs 易损斑块</strong>：<strong>易损斑块（薄帽+大脂质核心+炎症）破裂</strong>→血栓→急性事件——"<strong>急性心梗多由'小斑块破裂'而非'大斑块堵塞'</strong>"（"斑块稳定比消退更重要"——他汀稳定斑块的作用）。<strong>钙化</strong>是晚期斑块的表现（影像上可见）。</span>

## 3 动脉粥样硬化的器官后果

**AS 的器官后果（供血器官）**：

**冠状动脉→冠心病**：心绞痛（狭窄）、心肌梗死（血栓闭塞）——"冠心病是冠状动脉 AS 的后果"。
**脑动脉→脑梗死/脑出血**：脑动脉粥样硬化→血栓/栓塞→脑梗死；微动脉瘤→脑出血。
**肾动脉→肾血管性高血压、肾硬化**。
**主动脉→主动脉瘤、夹层**（中膜破坏）。
**下肢动脉→间歇性跛行、坏疽**（下肢动脉硬化闭塞症）。

**AS 是全身性疾病**：一处的 AS 提示全身血管可能都有粥样硬化（"一处斑块，全身风险"）。<span class="marginnote"><strong>AS 的"器官地图"</strong>：冠脉（心梗）、脑动脉（脑梗）、肾动脉（肾性高血压）、主动脉（动脉瘤/夹层）、下肢（跛行坏疽）——"<strong>AS 是全身血管的'同一场病'</strong>"（心梗患者要防脑梗、下肢动脉病）。<strong>间歇性跛行</strong>（下肢 AS）：行走时腿痛（缺血）、休息缓解——"下肢动脉粥样硬化的典型症状"（糖尿病足与下肢 AS 相关）。<strong>主动脉夹层</strong>：AS 破坏中膜+高血压→内膜撕裂→血液进入中膜形成"假腔"——"胸痛'撕裂样'的急症"（心内科/急诊的危重鉴别）。</span>

## 4 防治的病理基础

**AS 防治（针对危险因素与机制）**：

**降脂**：**他汀**（抑制胆固醇合成+稳定斑块——"他汀的'斑块稳定'作用"）、依折麦布、PCSK9 抑制剂（见血脂篇）。
**降压**（ACEI/ARB、CCB）、**控糖**、**戒烟**、运动、减重。
**抗血小板**：**阿司匹林**（抑制血小板血栓——"心脑血管病的二级预防"）。
**抗凝**（房颤）与**溶栓/介入**（急性事件）。

**"治疗性生活方式改变（TLC）"**：饮食（低饱和脂肪）、运动、减重是 AS 防治的基石。<span class="marginnote"><strong>AS 防治的"三管齐下"</strong>：<strong>危险因素</strong>（降压、控糖、戒烟——防内皮损伤）、<strong>降脂</strong>（他汀——减脂质浸润+稳定斑块）、<strong>抗血栓</strong>（阿司匹林——防斑块破裂后血栓）。<strong>他汀的"稳定斑块"</strong>：降 LDL+抗炎→斑块纤维帽变厚→不易破裂——"他汀的获益不仅是降脂还有稳定斑块"（急性冠脉综合征早期他汀）。<strong>阿司匹林</strong>：抑制血小板 COX→TXA₂ 减少→抗血小板聚集——"心梗/脑梗后二级预防的标准用药"（药理学详述）。<strong>一级预防 vs 二级预防</strong>：无心血管病者防"首发病"（生活方式+危险因素）vs 已患病者防"复发"（他汀+阿司匹林）。</span>

## 5 易错点辨析

**辨析｜易错点：斑块「大小」与「危险性」不成正比。** 急性心梗常常不是由最狭窄、最大的斑块引起，而是由「小斑块破裂」触发血栓——易损斑块的关键在纤维帽薄、脂质核心大、炎症重，而非管腔狭窄程度。这解释了他汀「稳定斑块」为何比单纯「缩小斑块」更重要。

**辨析｜易错点：脂纹不是「老人才有」。** 脂纹在青少年（甚至儿童）期就可出现，是动脉粥样硬化的最早病变，理论上可逆；粥样斑块与复合病变才是中老年阶段逐渐发展而成的。所以「血管年轻化」不是危言耸听——危险因素从早年开始管理，才是真正的「治未病」。

**辨析｜易错点：间歇性跛行不是「腿抽筋」。** 下肢动脉粥样硬化引起的间歇性跛行，是行走一段固定距离后出现的小腿疼痛或酸胀、休息后缓解，本质是运动时肌肉缺血；它与缺钙性抽筋不同。若伴随足背动脉搏动减弱、皮肤变冷，提示下肢动脉闭塞，需要血管评估而非单纯补钙。<span class="marginnote">与检验交叉的要点：<strong>血脂四项</strong>（总胆固醇、LDL、HDL、甘油三酯）是筛查 AS 风险的一线指标，LDL 是「坏胆固醇」、HDL 是「好胆固醇」；<strong>颈动脉超声</strong>看内膜-中膜厚度与斑块，是评估全身 AS 负荷的窗口——「颈动脉是全身血管的窗口」。</span>

**辨析｜易错点：高脂血症不等于「胆固醇高」。** 血脂包括胆固醇与甘油三酯，其中 LDL 升高与动脉粥样硬化关系最密切；但甘油三酯极高（如急性胰腺炎阈值）的风险点在胰腺而非血管，HDL 降低也是独立危险因素。调脂治疗主要盯 LDL，目标值随危险分层而定——高危患者 LDL 目标更严格（<1.8 mmol/L 甚至 <1.4 mmol/L）。

**辨析｜易错点：动脉粥样硬化与「动脉硬化」概念层次不同。** 「动脉硬化」泛指动脉壁增厚变硬，包括三种：动脉粥样硬化（脂质斑块，本文主角）、细动脉硬化（高血压的玻璃样变，见《高血压病》）、中膜钙化（Monckeberg）。考试最爱把「细动脉硬化」误当成「动脉粥样硬化」——前者是高血压的病理，后者是脂质代谢相关的慢性炎症性病变。

## 6 术语速查表

| 术语 | 一句话解释 |
| --- | --- |
| ox-LDL | 氧化修饰的低密度脂蛋白，损伤内皮、被巨噬细胞吞噬 |
| 泡沫细胞 | 吞噬 ox-LDL 的巨噬细胞，AS 的细胞标志 |
| 脂纹 | 最早的 AS 病变，青少年期出现、可逆 |
| 纤维帽 | 覆盖脂质核心的胶原帽，其厚薄决定斑块稳定性 |
| 易损斑块 | 薄帽+大脂质核心+炎症重，易破裂 |
| 复合病变 | 晚期斑块的出血、溃疡、血栓、钙化 |
| 间歇性跛行 | 下肢缺血导致的行走痛，休息缓解 |
| TLC | 治疗性生活方式改变，AS 防治的基石 |

## 7 核心对比表：稳定斑块 vs 易损斑块

| 对比项 | 稳定斑块 | 易损斑块 |
| --- | --- | --- |
| 纤维帽 | 厚 | 薄 |
| 脂质核心 | 小 | 大 |
| 炎症 | 轻 | 重（巨噬细胞多） |
| 临床 | 慢性狭窄（心绞痛） | 易破裂→急性心梗/脑梗 |
| 治疗 | 控制危险因素 | 他汀稳定+抗血小板+介入 |

## 8 小结

- **AS 是慢性炎症性动脉疾病**：内皮损伤→脂质浸润（ox-LDL）→泡沫细胞→粥样斑块；危险因素（高脂、高压、烟、糖）。
- 斑块演变：**脂纹→纤维斑块→粥样斑块→复合病变**；**易损斑块**（薄帽大核心）破裂→血栓→急性事件。
- 器官后果：冠脉（心梗）、脑（脑梗）、肾（肾性高血压）、主动脉（瘤/夹层）、下肢（跛行坏疽）。
- 防治：危险因素控制+**他汀**（降脂+稳定斑块）+**阿司匹林**（抗血小板）——"预防>治疗"。
