# 音乐治疗

音乐治疗是以循证为基础的独立心理康复专业，通过音乐与治疗关系的共同作用促进个体在生理、心理、情绪与社交层面的健康与康复。无论你是想入门了解还是系统掌握这门交叉学科，都值得沿着权威教材走一遍。

## 对标教材

- 张鸿懿《音乐治疗学基础》（中国音乐治疗学会指定教材）
- 美国音乐治疗协会（AMTA）职业标准与循证实践指南
- 中国音乐治疗学会标准与本土临床实践规范
