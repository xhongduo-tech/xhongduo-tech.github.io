## 为什么从尿路感染开始

在肾内科门诊，尿路感染（UTI）是「流量王」之一：女性一生中约 50% 至少经历过一次；急性肾盂肾炎则是住院与发热的常见病因。它看似简单，却处处是坑——膀胱炎与肾盂肾炎是不同级别的战役、复杂性与非复杂性治疗方案完全不同、**孕妇的无症状菌尿必须治疗而普通人的不必**。这一课先建立「尿路防御—攻防」的图景，再厘清三张诊断清单：膀胱炎、肾盂肾炎、无症状菌尿，最后落到「按部位与按复杂性」的抗感染策略。<span class="marginnote">UTI 是「从微生物学一路打到药理学」的完美案例：大肠杆菌的菌毛、尿液的性质、抗生素的选择，三个学科在一场「膀胱保卫战」里会师。</span>

## 1 病原与进攻路线

**最常见的病原是肠杆菌科，尤其大肠杆菌（E. coli），约占社区尿感 75–90%**，其次为克雷伯菌、变形杆菌、肠球菌；年轻女性另见腐生葡萄球菌（S. saprophyticus）。

**进攻路线以「上行感染」为绝对主流**：会阴部定植菌 → 沿尿道逆行 → 膀胱（膀胱炎）→ 经输尿管上行 → 肾盂与肾实质（肾盂肾炎）。血行播散少见，主要见于新生儿与免疫力低下者（金黄色葡萄球菌、念珠菌）。

**变形杆菌的特别之处**：产脲酶，分解尿素产氨、碱化尿液——为磷酸铵镁（鸟粪石）结石的形成提供温床（还记得《肾结石》里的那只「鹿角形结石」吗？）。

## 2 尿路的「第一道防线」

尿液并不是「被动的脏水」，它自带一套防御系统：

**机械冲刷**：尿流本身是「河流」，每 4–6 小时把定植的细菌冲走；残余尿增多（前列腺增生、神经源性膀胱）等于给细菌修了水库。
**尿液的化学武器**：高尿素、高渗、酸性尿抑制细菌；Tamm–Horsfall 蛋白（uromodulin）结合并清除菌毛细菌；溶菌酶、乳铁蛋白、抗菌肽、SIgA 协同作战。
**黏膜屏障**：尿路上皮分泌黏蛋白形成「生物膜防护层」，细菌要先用菌毛黏附、再侵入上皮——**菌毛黏附是感染的第一张多米诺骨牌**。

**女性为何易感**：尿道短（约 4 cm，男性约 20 cm）、尿道口邻近阴道与肛门、雌激素影响黏膜状态、性交促进细菌上移。解剖即命运，在 UTI 这里体现得最直白。

## 3 三个诊断场景

**膀胱炎（下尿路感染）**：尿频、尿急、尿痛、耻骨上不适——典型「刺激征」。无发热，无腰痛，全身状态好。查尿见白细胞酯酶与亚硝酸盐（大肠杆菌等把尿硝酸盐还原为亚硝酸盐）阳性；确诊靠中段尿培养。

**急性肾盂肾炎（上尿路感染）**：膀胱刺激征 + **发热（> 38 ℃）、寒战、腰痛、肋脊角叩痛**、恶心呕吐。是「感染 + 全身炎症」的战役，需全身抗生素，必要时住院静脉给药。<span class="marginnote">区分要点：「发热 + 腰痛」是把肾盂肾炎从膀胱炎里拎出来的两个关键词。孕产妇与糖尿病患者的肾盂肾炎更重、更易并发败血症，处理要更积极。</span>

**无症状菌尿（asymptomatic bacteriuria, ASB）**：尿培养阳性（≥ 10^5 CFU/mL）但**无任何症状**。关键结论：**普通人群不需要治疗**——治疗不改善结局、还制造耐药；需要治疗的例外是**孕妇**（可致低出生体重与早产）、**拟行泌尿系手术者**（防术后脓毒症）。<span class="marginnote">「菌尿不等于感染」是 UTI 领域最容易越界的边界：同一个「阳性培养」，在有症状者是要命的线索，在无症状老人那里常常只是「化验单上的噪音」。</span>

## 4 公式解析：菌落计数的诊断阈值

为什么「≥ 10^5 CFU/mL」成了教科书上的分水岭？这来自 Kass（1956 年）的经典研究：他统计了大量女性的清洁中段尿培养，发现尿中细菌数呈**双峰分布**——正常妇女多在 10^3 以下，真性菌尿者常超过 10^5，中间隔着一道「几乎无人区」的深谷。于是：

$$
\text{真性菌尿} \iff \text{单次清洁中段尿培养} \geq 10^5\ \mathrm{CFU/mL}
$$

拆开理解：

- **第一步，看数量级**：10^5 与 10^3 之间隔着两个数量级。尿液静置在膀胱里数小时，真感染时细菌会以对数增长，量级差距就是「感染 vs 污染」的信号。
- **第二步，警惕污染的伪装**：尿道口与阴道分泌物会污染标本——所以**取中段尿、消毒外阴、晨尿**是前提；培养出多种菌、或菌种为阴道正常菌群，要考虑污染。
- **第三步，临床上更细的阈值**：有症状女性 + 单菌种 + ≥ 10^2–10^3 CFU/mL 也按感染处理（尤其肾盂肾炎）；留置导尿管者 ≥ 10^5 且无症状不处理。**阈值是「规则」，症状与宿主状态是「裁判」**。

## 5 治疗策略：按「部位 + 复杂性」开方

**非复杂性膀胱炎**：短疗程口服即可——呋喃妥因 5 天、磷霉素 1 次顿服、或 TMP-SMX 3 天（当地耐药率 < 20% 时）。原则：**疗程短、选「尿中浓度高」的药**（呋喃妥因正是尿中浓度高、血中浓度低的「泌尿专攻」药）。

**急性肾盂肾炎**：喹诺酮类（左氧氟沙星/环丙沙星）或头孢三代，7–14 天；重症者先静脉后口服「降阶梯」。注意：**有尿路梗阻证据（结石、前列腺、肿瘤）的肾盂肾炎 = 复杂性尿感**，要同时解除梗阻，否则抗生素「打不赢」。

**复杂性 UTI 的高危特征**：男性、妊娠、老年、免疫抑制、留置导尿管、尿路畸形/梗阻、院内获得、反复复发。此类「别按书上的简单方案走」——通常需更长疗程、联合用药、并处理基础结构问题。

**复发预防**：发作 ≥ 3 次/年的女性可考虑：充分饮水、排尿后擦干从前向后、性生活后排尿；必要时预防性抗生素（性生活后单剂或长期低剂量）、绝经后局部雌激素。<span class="marginnote">蔓越莓（原花青素 A 型）能部分阻断大肠杆菌菌毛黏附，证据级别有限但在「非抗生素预防」里属于最有希望的一员——机制还是那句「黏附是第一块多米诺骨牌」。</span>

## 6 核心要点表：一页分清三个场景

| 场景 | 症状 | 发热/腰痛 | 处理 |
| --- | --- | --- | --- |
| 无症状菌尿 | 无 | 无 | 仅孕妇与术前治疗 |
| 非复杂性膀胱炎 | 刺激征 | 无 | 短疗程口服 |
| 复杂性 UTI | 刺激征 ± 结构因素 | 可有 | 长疗程 + 处理基础病 |
| 急性肾盂肾炎 | 刺激征 + 发热腰痛 | 有 | 全身抗生素，重症住院 |

## 7 三类「特别战役」：导尿管、男性、孕妇

**导尿管相关尿感（CAUTI）**：留置导尿管是医院感染的最常见源头之一。菌尿在置管 48 小时后几乎不可避免，但**「菌尿 ≠ 感染」**——仅有细菌阳性而无症状时**不常规处理**（除非术前或免疫力极低者）。真正感染表现为发热、腰痛、导管周围脓性分泌物、谵妄等；处理：更换/拔除导管、留取新鲜尿培养、按药敏用药。**预防胜于治疗：严格适应证、尽早拔管、无菌操作**。<span class="marginnote">「长期置管者的尿培养阳性」是检验临床思维的一道题：很多初学者的冲动是「阳性就上抗生素」，但指南的答案是「无症状不动它」——处理一个化验单数字，常常反而制造耐药菌。</span>

**男性 UTI**：男性尿感相对少见，一旦出现常提示结构或功能异常——前列腺增生（残余尿）、前列腺炎（可致**慢性细菌性前列腺炎**的复发与难治）、尿路梗阻、结石。因此**男性 UTI 要按复杂性处理**：查残余尿、排查前列腺与梗阻，疗程更长（前列腺炎常需 4–6 周）。

**妊娠期 UTI**：这是「无症状菌尿必须治疗」的例外区——孕妇的无症状菌尿与早产、低出生体重相关，且妊娠期肾盂肾炎风险增高（孕激素致输尿管松弛 + 子宫压迫）。处理：确诊菌尿即治疗（呋喃妥因或 β-内酰胺类，孕早期与孕晚期药物选择不同）、治疗后复查确认清除、尿感反复者考虑预防用药。**孕产妇的尿感管理，是「无症状也治」原则的唯一常规例外。**

最后展开「耐药时代」与「结构异常」两条当代主线：

**抗生素耐药的现实**：大肠杆菌产 **ESBL（超广谱 β-内酰胺酶）** 的比例在许多地区持续上升——这类菌对头孢与青霉素类耐药，治疗被迫转向碳青霉烯类或新型组合（如头孢他啶-阿维巴坦）。**临床启示**：轻症膀胱炎尽量用「低压力」的老药（呋喃妥因、磷霉素——它们诱导耐药的能力相对弱），把「高压药」留给重症与耐药株——**「用药经济学」是抗菌药物管理（antimicrobial stewardship）在尿感上的直接体现。**<span class="marginnote">磷霉素的复兴是个好例子：这味「老而少用」的药，因为单剂口服、耐药率低、对产 ESBL 大肠杆菌仍有效，在耐药时代重新进入指南。</span>

**结构与反流（VUR）**：儿童反复发热性尿感要排查**膀胱输尿管反流**——返流让带菌尿逆流至肾盂，反复损伤肾实质（反流性肾病），是儿童肾瘢痕与后期高血压的成因。**处理从「轻→重」：预防性抗生素（轻度）→ 内镜下注射填充剂 → 手术再植（重度）**。

**一句话总纲**：UTI 的治疗从来不只是「选对一种抗生素」，而是「**评估部位（膀胱/肾）、评估复杂性（宿主/结构）、评估耐药风险（当地菌谱）、然后才开药**」——四步之后，那张处方才是负责任的处方。

再把「儿童」与「行为干预」补成最后两块拼图：

**儿童尿感**：发热性尿感（尤其 < 2 岁）要按肾盂肾炎对待并排查**尿路结构与反流**（超声、必要时排尿期膀胱尿道造影 VCUG）；儿童反复尿感与肾瘢痕、远期高血压相关——**「儿童的每一次发热性尿感，都是对肾实质的一次潜在啃噬」**，这正是儿科医生对发热 + 无其他来源感染保持高度警惕的原因。

**行为干预（非药物的力量）**：充分饮水（尿频冲刷）、排尿后擦拭方向（从前向后）、避免憋尿与紧身不透气内裤、性行为后排尿、围绝经期雌激素（局部）。这些「不花钱的预防」在复发女性中的累积效果不容小觑——**UTI 的预防是「药物 + 行为」的协奏，而不是单靠抗生素的独奏。**<span class="marginnote">尿感预防的金字塔底层其实是「行为」：多喝水、勤排尿、擦向正确——这些朴素的习惯，在复发防治中的长期贡献，常常被低估到「聊胜于无」，而它们正是最便宜、最安全的干预。</span>

**最后一句话**：UTI 从「膀胱的一阵灼热」到「肾盂的全身战役」，靠的是泌尿系统防御、宿主状态与抗生素策略的三方博弈——**本课的全部要点，都可以收进「评估部位、评估复杂性、评估耐药、再开药」这四步里。**

补上「发热性尿感的急诊处理」这条行动线，让本课以「能上手」收尾：

**疑似肾盂肾炎伴全身中毒表现**（高热、寒战、低血压、神志改变）：先留**血培养 + 尿培养**，随即**经验性静脉抗生素**（覆盖肠道革兰阴性菌：三代头孢或喹诺酮或碳青霉烯按耐药风险），评估容量与循环，排查梗阻（超声/CT）——**有梗阻者「引流优先」**，否则抗生素无法到达感染灶。<span class="marginnote">「发热 + 腰痛 + 肾积水 = 先引流」是尿路感染急诊的黄金三连：梗阻不除，抗菌药就像「隔着墙救火」。</span>

**降阶梯与疗程**：培养与药敏回报后，从广谱「降阶梯」到目标抗生素；单纯肾盂肾炎 7–14 天，复杂性/合并菌血症者适当延长——**「疗程」不是固定天数，而是「症状与影像缓解 + 培养转阴」的函数**。

**最后一层提醒**：发热性尿感在**糖尿病、免疫抑制、妊娠、老年**者中更易进展为脓毒症与肾脓肿——**「看似简单的尿路感染，在这些人身上永远不简单」**，这就是本课所有风险因素的汇总。

**辨析｜易错点：「尿培养阳性」与「尿路感染」不能画等号。** 无症状菌尿（尤其老年、导尿管患者）的阳性培养常被过度治疗，而真性感染有时培养阴性（已用抗生素或病原特殊）。**诊断的金标准是「症状 + 脓尿 + 培养」三位一体**——单凭一个阳性培养就开抗生素，是抗生素滥用的最常见入口。

## 8 小结

- **上行感染为主**，大肠杆菌占大头；菌毛黏附是第一块多米诺骨牌，变形杆菌的脲酶为鸟粪石结石铺路。
- 尿路自带防御：**尿流冲刷 + 酸性高渗 + Tamm–Horsfall 蛋白 + 黏膜屏障**；女性尿道短，解剖即易感。
- 三场景分治：**膀胱炎（无发热）短疗程口服；肾盂肾炎（发热 + 腰痛）全身抗生素；无症状菌尿普通人不动、孕妇必治**。
- 真性菌尿的阈值 ≥ 10^5 CFU/mL 来自 Kass 的双峰分布研究；**阈值是规则，症状与宿主是裁判**。
- 复杂性 UTI 的高危因素（男性、妊娠、梗阻、导管、复发）决定「更重更久 + 解除梗阻」的升级打法。

在下一节，我们终于来到肾脏病的终点站：**肾功能长期不可逆地丧失，尿毒症、透析与它的并发症**——这是《慢性肾脏病与透析》。
