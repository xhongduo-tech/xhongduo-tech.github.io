## 为什么从肾小管间质疾病开始

前面我们讲了肾小球——滤过的门。但肾实质还有一半江山：**肾小管与肾间质**。肾小管负责精细回收与分泌，间质负责支撑与交换；两者一旦慢性受损，就通向肾间质纤维化——**几乎所有慢性肾脏病通往终末期的最后一条共同道路**。这一课先把「急性间质性肾炎」这张急症牌打出去，再展开肾小管「特种兵」——肾小管酸中毒与各种遗传性转运病。<span class="marginnote">如果说肾小球病是「漏水漏水漏水」，肾小管病就是「丢钾丢钾、丢碱丢碱、丢氨基酸丢磷」——症状五花八门，化验单上却全是「丢」字。</span>

## 1 急性间质性肾炎：药物过敏的肾脏版

**急性间质性肾炎（acute interstitial nephritis, AIN）**：肾间质被炎症细胞浸润、伴肾小管损伤。最常见病因是**药物**——经典四天王：青霉素类及头孢类、NSAID、质子泵抑制剂（PPI）、利福平/别嘌呤醇等。此外感染与自身免疫也可引起。

临床特征是「**三重警示**」：用药后数天至数周出现——①肾功能急性下降；②无菌性脓尿、血尿（尿常规白细胞多但培养阴性）；③全身过敏表现（发热、皮疹、嗜酸性粒细胞增多——但**三者俱全者不足三分之一**）。<span class="marginnote">正因「发烧 + 皮疹 + 嗜酸」常常不全，AIN 极易漏诊。凡「肾功能不明原因急降 + 近期换过药」，都要把 AIN 列入排查。</span>

处理核心是**停掉可疑药物**，多数可恢复；重症者用激素缩短病程。NSAID 相关 AIN 有时合并肾病综合征，预后更差。诊断金标准是活检（间质炎症浸润、嗜酸性粒细胞），但临床常凭线索停药物观察。

## 2 肾小管酸中毒：排酸的四种失职

**肾小管酸中毒（renal tubular acidosis, RTA）**：GFR 正常或接近正常，但肾小管不能维持酸碱稳态。核心分类：

**Ⅰ型（远端 RTA）**：远端小管分泌 $\mathrm{H^+}$ 不力。特征是**尿 pH 不能低于 5.5**、低钾、低枸橼酸、尿路钙结石（高钙尿 + 低枸橼酸易成石）。治疗补碱 + 补钾。
**Ⅱ型（近端 RTA）**：近端小管回收碳酸氢盐失败，碳酸氢盐大量漏入尿中。常伴**范可尼综合征**（同时丢糖、丢磷、丢氨基酸）——一句话：近端小管「啥都收不回来」。治疗需大剂量碱（因为碱持续漏）。
**Ⅳ型（高钾性 RTA）**：醛固酮作用不足或抵抗，集合管既排钾受阻又排酸受阻。最常见于糖尿病肾病、梗阻性肾病、ACEI/ARB 后。特点是**高钾 + 轻度代谢性酸中毒**。治疗重点降钾，必要时氟氢可的松。

**辨析｜易错点：尿阴离子间隙（UAG）的读法。** UAG = $\mathrm{Na^+_{urine}} + \mathrm{K^+_{urine}} - \mathrm{Cl^-_{urine}}$。正常尿含大量 $\mathrm{NH_4^+}$（即「藏起来的酸」），UAG 为负值；**UAG 为正值说明尿里缺铵、远端排酸不力 → 支持远端 RTA**。初学者常把「尿 pH 高」当成 RTA 的唯一线索，但利尿剂、碱血症都会拉高尿 pH，UAG 才是分辨「肾到底有没有在排酸」的深层指标。

## 3 肾小管的「丢」字军团：范可尼、巴特、吉特尔曼

**范可尼综合征（Fanconi syndrome）**：近端小管全面转运障碍——糖尿（血糖正常却尿糖阳性）、氨基酸尿、磷尿、近端 RTA、低尿酸。见于遗传性（如 Wilson 病、胱氨酸贮积症）与获得性（多发性骨髓瘤的轻链损伤、过期四环素、顺铂）。**线索藏在一张「普通尿常规」里：血糖尿糖同时阳性，就要想到它。**

**巴特综合征（Bartter syndrome）**：髓袢升支粗段 NKCC2 或相关通道基因突变，钠钾氯转运失灵。临床像「用了袢利尿剂」：低钾、代谢性碱中毒、**高钙尿**、高肾素高醛固酮，血压却正常或偏低。婴儿期可严重脱水、生长迟缓。

**吉特尔曼综合征（Gitelman syndrome）**：远曲小管 NCC（钠氯共转运体）失活，临床像「用了噻嗪类」：低钾、低镁、**低钙尿**、碱中毒。<span class="marginnote">巴特 vs 吉特尔曼的经典对照：一个「像袢利尿剂 + 高钙尿」，一个「像噻嗪类 + 低钙尿」。凭血镁与尿钙两条就能把这对「孪生综合征」分开。</span>

这类「单基因交通病」是理解肾小管各段功能的天然实验：**巴特病坏在髓袢，吉特尔曼坏在远曲小管**——它们各自把教科书里的转运蛋白「演」成了活生生的症状。

## 4 慢性间质性肾病：纤维化的漫长啃噬

急性之外，还有一批**慢性小管间质疾病**：长期服用止痛药（止痛药性肾病，可致**肾乳头坏死**）、慢性尿路梗阻、重金属（铅、镉）、高尿酸/高钙、多发性骨髓瘤（轻链管型肾病）、干燥综合征。它们的共同终点是**肾间质纤维化**——成纤维细胞活化、细胞外基质沉积、肾小管萎缩。

间质纤维化是慢性肾脏病进展的核心病理学事件：**无论初始病因是糖尿病、高血压还是肾小球肾炎，最后都汇入同一条纤维化大河**。临床上表现「非特异性」：夜尿增多（浓缩能力先受损）、轻度蛋白尿（< 1 g/d）、GFR 缓降。治疗原则是「对因 + 延缓纤维化」：ACEI/ARB、控制血压血糖、避免肾毒性药物。

## 5 公式解析：尿阴离子间隙检验肾的「排酸功」

承接第 2 节，把 UAG 的原理算一遍：

$$
\mathrm{UAG} = [\mathrm{Na^+}]_{\mathrm{urine}} + [\mathrm{K^+}]_{\mathrm{urine}} - [\mathrm{Cl^-}]_{\mathrm{urine}}
$$

正常代谢性酸中毒者，肾拼命泌铵（$\mathrm{NH_4^+}$），尿氯随之升高以平衡铵盐，于是 UAG 为**负值**（约 −20 到 −50）。拆开看：

- **第一步，电中性**：尿中阳离子（钠、钾、铵、少量钙镁）总量等于阴离子（氯、磷、硫酸、有机酸）。把可测的钠、钾与氯拿出来，剩下的差就是「$\mathrm{NH_4^+}$ 与不可测离子」的净账。
- **第二步，隐含假设**：磷与硫酸等「不可测阴离子」大致守恒，那么 **UAG 主要由 $\mathrm{NH_4^+}$ 决定**——UAG 越负，排铵越多。
- **第三步，判读**：代谢性酸中毒 + **UAG 正值**（≥ 0 或阳性）→ 肾排铵不足 → 远端 RTA；UAG 强负 → 肾排酸有功，酸中毒多半来自肾外（腹泻等）。

尿阴离子间隙让「肾有没有在认真干活」第一次有了尿液化验就能读的数——它与血里的阴离子间隙（《酸碱平衡与电解质》）构成一对「内外呼应」的侦探组合。

## 6 骨髓瘤肾损害与其他「晶体毒」

**多发性骨髓瘤（multiple myeloma）**是肾内科必须识破的「偷肾者」之一：单克隆浆细胞大量分泌**游离轻链（FLC）**，轻链被近端小管重吸收后超载、形成**管理蛋白（cast nephropathy）**堵塞肾小管，也可沉积为轻链淀粉样变。临床画像：**中老年 + 骨痛 + 贫血 + 血沉极快 + 蛋白尿（尿蛋白电泳显示轻链，尿常规尿蛋白却「只有 +」）**——「尿常规蛋白少但实际蛋白漏得多」的落差，正是轻链的指纹。<span class="marginnote">轻链肾病的另一个特征是「蛋白尿与肾功能损害不成比例」：肾功能已经很差、尿蛋白却不多，因为漏的是测不出的轻链而非白蛋白。看到这种「错位」，就要想到免疫球蛋白电泳。</span>

**治疗**：以化疗减瘤为核心（硼替佐米等）、充分水化、必要时血浆置换（证据有限但部分中心用于急性管理），肾衰者按需透析。**早期识别直接决定肾脏能否挽回**——骨髓瘤肾病的肾脏预后取决于肿瘤控制。

**尿酸与草酸盐肾病**：肿瘤溶解综合征与急性尿酸性肾病（高尿酸结晶阻塞远端小管）已在《药物与造影剂肾病》谈过；**草酸盐肾病**是另一个「隐形杀手」——乙二醇中毒、胰腺/肠病（短肠综合征致草酸吸收过多）、高剂量维生素 C，草酸钙结晶沉积于肾小管与间质，可致进行性肾衰。**凡「肾功能急降 + 原因不明 + 晶体尿」者，把草酸、尿酸、轻链都列入嫌疑人名单。**

把「慢性小管间质病」的病因清单铺成一张速查表，是这一节最好的收束：

| 病因类别 | 代表 | 识别线索 |
| --- | --- | --- |
| 药物 | 止痛药、NSAID、锂 | 用药史 + 乳头坏死（止痛药） |
| 中毒 | 铅、镉、马兜铃酸 | 职业/环境/中草药史 |
| 代谢 | 高尿酸、高钙、低钾 | 血尿酸/钙/钾异常 |
| 免疫 | 干燥综合征、结节病 | 口干眼干、血管紧张素转换酶 |
| 肿瘤 | 多发性骨髓瘤（轻链） | 骨痛、贫血、血沉快 |
| 梗阻/反流 | 慢性梗阻、膀胱输尿管反流 | 影像 + 反复尿感 |

**马兜铃酸肾病（aristolochic acid nephropathy）**特别值得单独一提：含马兜铃酸的中草药（如某些「木通」制剂）可致**进行性肾小管间质纤维化 + 尿路上皮癌风险**，是全球范围的公共健康警示——「中草药也不天然无害」是这条最深刻的一课。<span class="marginnote">「巴尔干肾病」与马兜铃酸肾病在病理上几乎无法区分，都是典型的小管间质纤维化——这提醒我们：慢性间质纤维化的「最后共同道路」，可以由非常不同的毒物殊途同归地铺成。</span>

**识别慢性小管间质病的「三多一少」**：夜尿多（浓缩先受损）、尿液成分多（低分子蛋白尿、尿糖、氨基酸尿）、肾结石与钙化多、血尿少且蛋白尿轻——**当肾病「症状多但尿蛋白不多」时，别光盯着肾小球，把镜头拉向小管与间质**。

补一个「蛋白尿的来源鉴别」——它是把小管病从肾小球病里「拎」出来的关键化验思维：

**肾小球性蛋白尿**：以**白蛋白为主**（分子量约 66 kDa），量常大（可达肾病范围），见于肾小球疾病——还记得 UPCR 吗？它就是为这种蛋白尿准备的。
**肾小管性蛋白尿**：以**低分子蛋白为主**（β2-微球蛋白、α1-微球蛋白、视黄醇结合蛋白等，分子量 < 40 kDa）——**量不大（常 < 1–2 g/d）、白蛋白比例低**，但因近端小管回收失败而漏出。<span class="marginnote">临床实用口诀：「大分子蛋白尿 → 肾小球在漏；小分子蛋白尿 → 肾小管在漏。」当尿常规蛋白「只有 +」而尿蛋白电泳显示大量小分子蛋白时，诊断的镜头就该从肾小球移向肾小管与间质。</span>

**怎么查**：尿蛋白电泳（区分白蛋白 vs 小分子）、**尿 α1-微球蛋白或 β2-微球蛋白定量**（小管损伤标志）、**尿糖与氨基酸**（范可尼表现）。这三个「小分子窗口」，把肾小管间质病从「沉默」中暴露出来。

**一句话收束**：肾小管间质病的诊断学，是「用尿液里的小分子与电解质，重建一段肾小管的失职清单」——每一段肾小管都有它的「专属丢项」，而尿检就是那张清单。

补上「影像与活检」这两个工具在小管间质病诊断里的位置：

**影像**：超声可示**肾大小与皮质厚度**——慢性间质病常伴双肾缩小、皮质变薄、回声增强，但急性期（AIN、ATN）肾体积常**增大**；CT 可显示**肾乳头坏死**（止痛药肾病）的乳头钙化或「环形」征、以及梗阻与结石（反流性肾病）的线索。**「肾大小」是急性 vs 慢性最重要的一眼判断**：急性肾损伤伴肾大，慢性肾衰伴肾小。<span class="marginnote">一条实用直觉：「肌酐高 + 肾大 = 多为急性、可逆；肌酐高 + 肾小 = 多为慢性、难逆。」影像学把时间维度直接画在肾脏上。</span>

**活检的指征**：AIN 疑诊而停药后肾功能不恢复、不明原因的慢性间质病（要查重金属与毒物时）、骨髓瘤肾病需确认、以及「肾功能下降 + 无明确肾小球病因」的诊断困境——**活检回报的价值，常常是「把猜测换成诊断、把等待换成方案」。**

**一句话**：肾小管间质病是「化验（小分子蛋白、电解质、尿 pH）+ 影像（肾大小、钙化）+ 必要时活检」三方会诊的疾病——**线索越拼越全，诊断就越硬——而每一次「原来如此」的诊断背后，都站着一段被认真读完的病史与一叠被仔细看过的化验单。**

**最后再强调一次时间观**：急性间质性肾炎是可逆的（停可疑药、必要时激素），慢性间质纤维化是不可逆的（只能延缓）——**肾小管间质疾病的全部治疗策略，本质上都是「在可逆的阶段出手，在不可逆的阶段止损」。** 这个「时间观」，也是整个慢性肾脏病管理的灵魂。

## 7 小结

- **AIN** 以药物过敏为最常见病因，识别线索是「肾功能急降 + 无菌性脓尿 + 过敏三征（常不全）」，核心处理是停可疑药。
- **RTA 三型对号入座**：Ⅰ型远端排酸不力（尿 pH 降不下 5.5、结石）、Ⅱ型近端丢碱（常伴范可尼）、Ⅳ型高钾性（醛固酮失职）。
- **范可尼 = 近端全面丢；巴特 = 像袢利尿剂（高钙尿）；吉特尔曼 = 像噻嗪类（低钙尿、低镁）**。
- 慢性间质病（止痛药、梗阻、骨髓瘤等）殊途同归到**间质纤维化**——所有 CKD 的共同终点。
- 尿阴离子间隙（UAG）是检验「肾排铵功力」的尿液化学指标，与血的阴离子间隙内外呼应。

在下一节，我们从「肾的敌人是免疫与遗传」换到「肾的敌人是药单」：**哪些常用药正在悄悄伤害肾脏，造影剂怎么躲**——这是《药物与造影剂肾病》。
