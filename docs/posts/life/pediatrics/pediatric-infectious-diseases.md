## 为什么从「发热 + 皮疹」讲起

儿童感染病是儿科「门面」最重的学科——它既有常见的自限性病毒感染（手足口），也有致命却可预防的疫苗性疾病（麻疹），还有需要长期抗痨的慢性病（结核）与「像感冒却不是感冒」的 EB 病毒病（传单）。<span class="marginnote">本篇与已发布的《感染性疾病总论与出疹性疾病（麻疹、水痘、手足口病）》互补：那篇立起了出疹性疾病的皮疹鉴别框架；本篇补上感染病的另外半张地图——<strong>结核</strong>（慢性、潜伏、易被忽略）与<strong>传染性单核细胞增多症</strong>（「像感冒却拖得久」），并把「麻疹、手足口、传单」放进同一张「发热 + 皮疹/淋巴结」的鉴别网。<strong>感染病学的第一课是「谁在流行、谁打过疫苗、谁接触过谁」</strong>——流行病学常常先于实验室给出答案。</span>本篇主线：**疫苗可防的病靠疫苗（麻疹），自限的病靠观察（手足口），隐蔽的病靠警惕（结核），拖沓的病靠诊断（传单）**。

## 1 麻疹：疫苗时代仍要警惕的「发热 + 皮疹」

**麻疹（measles）**：麻疹病毒（RNA 病毒）引起的高度传染性出疹性疾病，**经空气飞沫传播，传染性极强**（一人感染可传染 12–18 个易感者）。虽然疫苗已把发病率压到极低，但**漏种疫苗的地区与人群仍会暴发**——「麻疹已被消灭」是危险的错觉。

**临床经过（三个期）**：
- **前驱期（2–4 天）**：发热、咳嗽、流涕、结膜充血（「**3C 征：咳嗽 Cough、鼻炎 Coryza、结膜炎 Conjunctivitis**」）+ 发热第 2–3 天出现**科氏斑（Koplik spots）**——颊黏膜上的白色小点，是麻疹的**特征性早期体征**。
- **出疹期（发热第 3–4 天）**：**先耳后、发际 → 面部 → 躯干 → 四肢**的**自上而下**红色斑丘疹，疹间皮肤正常；出疹时**体温更高**。
- **恢复期**：按出疹顺序消退，留**糠麸样脱屑与褐色色素沉着**。

**并发症（麻疹真正的危险所在）**：**肺炎（最常见死因）、喉炎/喉梗阻、中耳炎、脑炎（麻疹脑炎）、维生素 A 缺乏相关角膜损伤**——麻疹不是「出个疹子就好」，重症与营养不良儿童风险极高。<span class="marginnote">麻疹的「三合一策略」值得记住：<strong>隔离（呼吸道隔离至出疹后 5 天）、对症（退热、补液、补充维生素 A）、预防（易感接触者 72 小时内接种疫苗或被动免疫）</strong>。维生素 A 是麻疹治疗的常规组成部分——它能显著降低重症麻疹的死亡率，这一点在资源充足的今天仍常被遗忘。</span>

**预防**：**麻疹-腮腺炎-风疹（MMR）疫苗**按计划免疫于 8 月龄、18 月龄接种，是消灭麻疹的根本手段——**「疫苗是最划算的感染病干预」**，在麻疹这里体现得最彻底。

**出疹性疾病的「一张表鉴别」**——把麻疹放进儿童最常见的出疹病谱里对号入座：

| 疾病 | 前驱/伴随 | 皮疹顺序与特点 | 特征性体征 |
| --- | --- | --- | --- |
| 麻疹 | 发热 + 3C（咳嗽/鼻炎/结膜炎） | 耳后→面→躯干→四肢，斑丘疹，疹间正常 | **Koplik 斑** |
| 风疹 | 症状轻，耳后枕后淋巴结大 | 面部先发，迅速遍身，2–3 天退 | 淋巴结肿大显著 |
| 幼儿急疹 | 高热 3–5 天，热退疹出 | 热退后躯干颈项淡红疹 | **「热退疹出」** |
| 水痘 | 低热、乏力 | 躯干先发，向心性分布，**丘疹-疱疹-结痂同存** | 皮疹「三代同堂」 |
| 猩红热 | 高热、咽痛、草莓舌 | 全身弥漫性潮红，**帕氏线、口周苍白圈** | 草莓舌 |

**读表的口诀**：先看「热退疹出」还是「热中疹出」（幼儿急疹 vs 麻疹），再看「向心还是离心」（水痘 vs 手足口），最后看有没有特征体征（Koplik 斑、草莓舌）。**出疹病鉴别靠「顺序 + 分布 + 特征体征」三维定位**——这与前面呼吸病「先定位病灶层级」的推理如出一辙。

## 2 手足口病：自限为主，但要盯住「重症三关」

**手足口病（hand, foot and mouth disease, HFMD）**：肠道病毒（主要为**肠道病毒 71 型（EV71）与柯萨奇病毒 A16**）引起的急性传染病，经粪-口与呼吸道传播，**5 岁以下儿童高发**，常在托幼机构造成聚集性流行。

**典型表现**：发热 + **口腔疱疹/溃疡（咽峡部、颊黏膜、舌）+ 手足臀部斑丘疹/疱疹**——「四部曲」分布（口、手、足、臀）是它的「名片」。多数患儿**1 周左右自愈**，只需对症（退热、口腔护理、清淡流质饮食）。

**重症预警（EV71 相关脑炎/脑干脑炎的高危信号）**——这是手足口「区分自限与致命」的关键：

| 重症信号 | 含义 |
| --- | --- |
| 持续高热（> 39°C）不退 | 病毒血症重 |
| 精神差、嗜睡、惊跳、肢体抖动 | 累及神经系统 |
| 呼吸急促、心率快、末梢凉 | 循环受累/肺水肿前兆 |
| 频繁呕吐 | 颅高压可能 |

**凡出现「精神差 + 惊跳 + 肢体抖动 + 呼吸快」中的任意一条，都要立即住院**——EV71 重症可在数小时内从「看起来还好」恶化到脑干脑炎与肺出血。<span class="marginnote">手足口最容易被低估的是它的「伪装」：多数孩子只是发烧起泡，但 EV71 型的一小部分可快速进展为<strong>脑干脑炎、神经源性肺水肿</strong>，病死率高。<strong>「精神好 = 安全」是手足口最粗糙也最有效的初筛</strong>——孩子精神好不好，家长比医生更容易第一时间发现，这也是健康教育里「让家长学会看精神」的价值。</span>

**预防**：**EV71 灭活疫苗**（6 月龄–5 岁，2 剂）可有效预防 EV71 相关重症手足口；勤洗手、玩具消毒、隔离患儿（症状消失后再隔离 1 周）是控制传播的关键。**「洗手是最便宜的疫苗」**——这句话在粪-口传播的感染病里放之四海皆准。

**家庭护理**：口腔疱疹痛导致拒食时，给予**清淡流质/软食、避免酸辣烫**；高热对症退热；**多喝水防脱水**；皮疹一般无需特殊处理，保持清洁干燥即可。**家长要做的不是「每天数几个泡」，而是「每天看精神」**——精神好就是安全线，精神差就是就医信号，这一条比任何药物都重要。

## 3 结核：潜伏的「慢性杀手」

**儿童结核（tuberculosis, TB）**：结核分枝杆菌引起的慢性传染病，经呼吸道飞沫传播。**儿童结核绝大多数是原发性结核**——初次感染后形成**原发综合征**（肺部原发灶 + 淋巴结肿大 + 淋巴管炎），多数患儿**无症状或仅低热、咳嗽、食欲差**，极易被当作「反复感冒」。

**易感人群**：**有结核接触史（家中/密切接触者患活动性结核）是最强线索**；年龄越小、免疫力越差，发病与重症（粟粒性结核、结核性脑膜炎）风险越高——**婴幼儿结核性脑膜炎是儿科结核最凶险的形式，致残率致死率高**。

**诊断**：**结核菌素试验（PPD/TST）或 γ-干扰素释放试验（IGRA）阳性 + 接触史/影像（胸片示原发灶、肺门淋巴结肿大、粟粒影）**；确诊靠病原学（痰/胃液涂片、培养、核酸扩增）——儿童常因不会咳痰而用**晨胃液**查菌。<span class="marginnote">儿童结核的「隐蔽性」是最大敌人：症状像感冒、PPD 可能因卡介苗（BCG）接种而假阳性、肺门淋巴结肿大常被漏读。诊断的钥匙是<strong>「问接触史」</strong>——家里有没有人长期咳嗽？有没有结核接触？这一问，常常比一堆检查更先接近答案。卡介苗（BCG）能防重症结核（尤其粟粒性/结脑），但<strong>不能完全防肺结核</strong>——所以接种过 BCG 的孩子同样要警惕结核。</span>

**治疗**：**抗结核化疗**——初治多用**异烟肼 + 利福平 + 吡嗪酰胺**（±乙胺丁醇）强化期 2 个月，继续异烟肼 + 利福平巩固期 4 个月（总疗程 6 个月）；**规律、足量、全程**是抗痨的铁律（不规律用药是耐药结核的温床）。**潜伏结核感染（LTBI）**：PPD/IGRA 阳性而无活动性结核者，也需预防性治疗（异烟肼 6–9 个月）——**把「潜伏」治在「活动」之前，是结核防控的智慧**。

**预防**：BCG 接种（我国出生即种）+ **接触者筛查**（与活动性结核密切接触的儿童要筛查与预防性治疗）——**结核的预防不在疫苗一针，而在「把每个接触者查到位」**。

## 4 传染性单核细胞增多症：像感冒，却拖得久

**传染性单核细胞增多症（infectious mononucleosis, IM）**：**EB 病毒（EBV）**引起的急性自限性感染病，经唾液传播（「亲吻病」），青少年与学龄儿童多见。它不是细菌、不是普通病毒感冒，而是**淋巴系统被 EBV 激活后的全身反应**。

**典型三联征**：**发热（可 1–2 周）、咽峡炎（咽痛、扁桃体肿大伴渗出）、淋巴结肿大（颈后、腋下、腹股沟）**，常伴**肝脾肿大、乏力、眼睑水肿**。**它最容易被误认为「反复不愈的化脓性扁桃体炎」**——但抗生素（尤其氨苄西林/阿莫西林）常诱发**全身皮疹**，这是 IM 的一个特征性「药物陷阱」。

**诊断**：**血常规示淋巴细胞显著增多、异型淋巴细胞 > 10%** + **EBV 抗体（VCA-IgM 阳性提示近期感染）**；嗜异性抗体（单点试验）也可用。**「发热 + 咽痛 + 淋巴结 + 异型淋巴细胞」四件套，是传单的诊断拼图**。<span class="marginnote">传单的「别名」——「亲吻病」——点明了它的传播方式：唾液。青少年间亲密接触、共用餐具是常见途径。它最该被记住的三件事：<strong>一、别用氨苄西林/阿莫西林</strong>（会诱发全身皮疹）；<strong>二、脾大者 3–4 周内避免剧烈运动与接触性运动</strong>（防脾破裂）；<strong>三、多数 2–4 周自愈，以支持治疗为主</strong>。</span>

**EBV 抗体「组合拳」解读**——单查一个抗体容易误判，四件套一起看才准：

| 抗体 | 急性期 | 恢复期 | 临床意义 |
| --- | --- | --- | --- |
| VCA-IgM | 阳性 | 转阴 | 近期 / 现症感染 |
| VCA-IgG | 低 / 阳性 | 阳性（持续） | 既往或近期感染 |
| EA-IgG | 阳性 | 转阴 | 病毒复制活跃期 |
| EBNA-IgG | 阴性 | 阳性（延后出现） | 既往感染（免疫成熟） |

**读表要点**：**VCA-IgM 阳性 + EBNA-IgG 阴性 = 急性传单**；若 VCA-IgM 阴性而 EBNA-IgG 阳性，则是**既往感染**而非当前发病——这一区分避免了很多「复发传单」的误诊。

**治疗**：**以对症支持为主**——休息、退热、补水、止痛；咽痛明显者可用激素短程减轻症状；**重症（气道梗阻、血小板减少、神经受累）需住院与激素/抗病毒治疗**。**预防**：无疫苗，靠避免唾液接触、不共用牙刷餐具。

## 5 公式解析：感染病的「时间线 + 流行病学」思维

感染病学里最实用的「公式」不是数学公式，而是**时间线**——把「发热第几天 + 出疹顺序 + 接触史」当作解方程的三元组：

$$
\text{诊断线索} = f(\text{热程}, \text{皮疹/体征顺序}, \text{流行病学接触})
$$

- **第一步，看热程**：发热第 3–4 天才出疹 → 想麻疹（出疹时热更高）；发热与咽痛持续 1 周以上、抗生素无效 → 想传单；持续高热伴精神差、惊跳 → 手足口重症预警。
- **第二步，看顺序**：麻疹皮疹「耳后 → 面 → 躯干 → 四肢」自上而下；手足口「口、手、足、臀」四部曲；传单是「发热 + 咽 + 淋巴结」而无特征性皮疹——**「皮疹从哪开始、往哪蔓延」是出疹病的第二坐标**。
- **第三步，看流行病学**：有结核接触史 → 把结核放进最前面；托幼机构手足口聚集 → 高度怀疑 HFMD；未接种麻疹疫苗 + 暴露史 → 先想到麻疹。**流行病学是感染病诊断的「先验概率」**——它与贝叶斯思维同构：先验越强，后验越集中。
- **第四步，动态验证**：诊断不是一次完成——**复查血象（异型淋巴细胞）、补做抗体（EBV、麻疹 IgM）、追问接触史（结核）**，随着时间与检查推进，把「怀疑清单」逐步收敛到「确诊」。

**辨析｜易错点**：发热 + 皮疹 ≠ 麻疹；咽痛 + 淋巴结 ≠ 传单；PPD 阳性 ≠ 活动性结核。**每一条线索都是「倾向」而非「铁证」**——感染病学的高手，是用时间线 + 流行病学把「倾向」一步步转成「确诊」的人。

## 6 小结

- **麻疹**：发热 + 3C（咳嗽/鼻炎/结膜炎）+ Koplik 斑 + 自上而下皮疹；**并发症（肺炎、脑炎）才是危险**；隔离 + 对症 + 维生素 A；MMR 疫苗是根本预防。
- **手足口**：肠道病毒（EV71、CA16）；口、手、足、臀疱疹；**多数自限**；盯住重症信号（持续高热、精神差、惊跳、呼吸快）；EV71 疫苗可防重症。
- **结核**：原发性为主，症状像感冒；**接触史是最强线索**；PPD/IGRA + 影像诊断；6 个月规律抗痨；潜伏感染者预防性治疗；BCG 防重症不防肺结核。
- **传染性单核细胞增多症**：EB 病毒、经唾液传播；发热 + 咽炎 + 淋巴结 + 异型淋巴细胞四件套；**不用氨苄西林/阿莫西林、脾大防碰撞**；多自愈、支持治疗为主。
- **时间线 + 流行病学**是感染病的「解方程三件套」：热程、皮疹顺序、接触史——先验概率决定鉴别顺序，动态复查收敛诊断。
- 感染线的方法论：**感染病是一场「谁传播、谁易感、谁重症」的流行病学游戏**——问清接触史、分清自限与可防可治，儿科感染病就赢了一半。
- 与《儿童保健与营养》的呼应：麻疹、结核、手足口的预防都落在**疫苗与卫生**上——计划免疫表上的每一个名字，背后都是一类曾经可怕的疾病。

在下一节，我们从「感染」转向「免疫」——**免疫与风湿性疾病**：过敏性紫癜、幼年特发性关节炎，用「炎症攻击自身组织」的眼睛看儿童风湿病。
