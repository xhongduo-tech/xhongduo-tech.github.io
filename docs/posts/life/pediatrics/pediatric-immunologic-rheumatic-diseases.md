## 为什么从「卫兵叛变」讲起

儿童风湿病是儿科里最「反直觉」的一类病：孩子本应朝气蓬勃，却因自己的免疫系统攻击自身组织而发热、关节痛、皮疹、甚至伤及内脏。<span class="marginnote">本篇与已发布的《免疫与风湿性疾病（川崎病、幼年特发性关节炎）》互补：那篇的主角是<strong>川崎病</strong>（血管炎 + 冠脉损伤）；本篇把同一张「免疫攻击自己」的地图再往前推，补上两块高频拼图——<strong>过敏性紫癜</strong>（皮肤 + 消化道 + 肾的血管炎）与<strong>幼年特发性关节炎</strong>（儿童最常见慢性风湿病）。三者在「血管炎/滑膜炎/抗体介导」的坐标里各有位置，但共同点是：<strong>症状在器官，病根在免疫</strong>。</span>本篇主线：**先建立「免疫攻击自己」的总框架，再看过敏性紫癜与 JIA 如何在皮肤、关节、内脏上各写各的剧本，最后用一张「器官扫描」决策公式把两者放进同一套临床推理**。

## 1 儿童免疫系统的「刹车失灵」

**自身免疫与自身炎症（autoimmunity / autoinflammation）**：免疫系统将自身组织误认为异物并发动攻击的状态。儿童期免疫系统处于「学习期」——既要学会识别病原（免疫耐受的建立），又要避免过度反应；**当「识别自己人」的刹车失灵，就出现自身免疫病**。

儿童风湿病的三大病理类型，先给一张「坐标图」：

| 类型 | 代表病 | 攻击靶点 | 关键机制 |
| --- | --- | --- | --- |
| 血管炎 | 川崎病、过敏性紫癜 | 血管壁 | 免疫复合物沉积 / 炎症因子 |
| 关节炎 | 幼年特发性关节炎（JIA） | 滑膜 | 自身反应性 T 细胞 + 炎症因子 |
| 抗体介导 | 系统性红斑狼疮（SLE） | 多器官自身抗原 | 自身抗体 + 免疫复合物 |

**记住这张表**：儿童风湿病不是「一个病」，而是「一类病」——**共同点是免疫失调，不同点是攻击部位与机制**。这也解释了为什么诊断靠「症状组合」而非单一检查。<span class="marginnote">与前面《遗传代谢与内分泌疾病》呼应：那篇讲「基因给的病」，本篇讲「免疫发动的病」——两者都不是感染，却都能引起<strong>发热、皮疹、多系统受累</strong>。儿科医生面对「长期发热 + 多器官」时，鉴别清单里一定要有风湿免疫病这个抽屉。</span>

**诊断的「红绿灯」**：反复不明原因发热（> 1 周）、多关节肿痛、特征性皮疹、血尿/蛋白尿、持续炎症指标升高（ESR/CRP 升高而抗生素无效）——**「抗生素压不下的发热 + 多系统症状」，第一个想到的就不是感染，而是免疫**。

## 2 过敏性紫癜：皮疹长在皮肤，战场却在肠道与肾脏

**过敏性紫癜（Henoch–Schönlein purpura, HSP，现称 IgA 血管炎）**：以 **IgA 免疫复合物沉积于小血管壁**为特征的白细胞碎裂性血管炎，是儿童最常见的血管炎，**多见于 3–10 岁，冬春季高发，常继发于上呼吸道感染后**。

**四大经典表现（可以不全有，但排序有规律）**：
- **皮疹（几乎必有）**：**可触性紫癜**——四肢伸侧、臀部对称分布的红色丘疹/瘀点，压之不褪色，反复成批出现，这是 HSP 的「名片」。
- **关节（约 2/3）**：膝、踝等大关节肿痛，**一过性、不留畸形**。
- **腹部（约 1/2–2/3）**：**脐周绞痛、恶心呕吐、便血（黑便）**——严重者可发生肠套叠、肠穿孔，是 HSP 最危险的内脏并发症。
- **肾脏（约 1/3）**：血尿、蛋白尿，少数进展为 **HSP 肾炎**，可迁延甚至慢性肾衰——**远期预后由肾决定**。

**诊断**：典型四联征（皮疹 + 关节 + 腹痛 + 肾）+ 病史即可临床诊断，**皮疹活检示 IgA 沉积可确诊**。<span class="marginnote">HSP 最容易被误诊的场景：<strong>腹痛出现在皮疹之前</strong>——孩子先吐先痛，被当成急性阑尾炎 / 肠套叠开刀，术后才发现皮疹。记住这条铁律：<strong>「紫癜 + 腹痛」＝先考虑 HSP 肠套叠，而不是直接送手术室</strong>；腹部超声（肠壁增厚、靶环征）比剖腹探察更早更安全。</span>

**治疗与预后**：
| 表现 | 处置 |
| --- | --- |
| 仅皮疹 / 关节 | 卧床、对症，多自限（数周） |
| 明显腹痛 / 消化道出血 | 住院、禁食、激素（泼尼松）可减轻腹部症状 |
| 重症 HSP 肾炎（大量蛋白尿） | 激素 + 免疫抑制剂，肾科随访 |
| 并发肠套叠 | 空气灌肠复位，必要时手术 |

**预后总体良好**——多数患儿数月内痊愈，**但肾脏受累者需长期随访尿常规**（至少 6–12 个月），因为「皮疹好了 ≠ 肾好了」。

## 3 幼年特发性关节炎：儿童最常见的慢性风湿病

**幼年特发性关节炎（juvenile idiopathic arthritis, JIA）**：儿童期（< 16 岁）持续 ≥ 6 周的不明原因关节炎，**是儿童最常见的慢性风湿病**，也是儿童致残的重要原因。「特发性」三个字点明：病因未明，但**免疫介导的慢性滑膜炎**是核心病变。

**三种最常见亚型（分型决定治疗与预后）**：
- **少关节型（最常见，约占一半）**：≤ 4 个关节受累，多为大关节（膝、踝）；**女孩多见，常伴虹膜睫状体炎（可致盲，需裂隙灯筛查）**；预后相对好。
- **多关节型**：≥ 5 个关节受累，可呈对称性，类风湿因子（RF）可阳性；病程迁延。
- **全身型（sJIA，最凶险）**：**弛张热 + 皮疹（淡红色一过性）+ 关节痛 + 肝脾淋巴结大**；可并发**巨噬细胞活化综合征（MAS）**——危及生命的过度炎症状态。

**巨噬细胞活化综合征（MAS）——全身型 JIA 最凶险的并发症**：sJIA 患儿突然出现持续高热、肝脾淋巴结进行性肿大、全血细胞减少、凝血异常、肝功能显著异常、高铁蛋白血症——这就是「炎症瀑布」：巨噬细胞疯狂释放细胞因子，把整个免疫系统烧塌。

| MAS 早期识别要点 | 临床意义 |
| --- | --- |
| 持续高热不退、肝脾快速肿大 | 炎症爆发信号 |
| 血小板 ↓↓、纤维蛋白原 ↓↓↓ | 凝血被耗竭 |
| 血清铁蛋白 ↑↑↑ | 巨噬细胞激活的「金钥匙」 |
| 三系细胞减少（WBC + Hb + PLT） | 骨髓被浸润 |

MAS 是儿科 ICU 急症——一旦识别，立刻激素 + 环孢素 A 或托珠单抗（IL-6 受体拮抗剂）抢救，延误就是致命。

**诊断要点**：**持续 ≥ 6 周的关节炎 + 排除感染/其他风湿病/肿瘤**（尤其是白血病与神经母细胞瘤可伪装成骨痛）。实验室（ESR/CRP 升高、RF/ANA 阳性）只是辅助——**JIA 是「临床诊断」，靠的是「时间（≥ 6 周）+ 关节（肿胀/活动受限）+ 排除」三件套**。<span class="marginnote">JIA 最需要警惕的是「伪装者」：<strong>儿童白血病、神经母细胞瘤早期也可表现为发热 + 骨关节痛</strong>，血象可正常。所以初诊 JIA 前必须查血常规 + 外周血涂片，必要时骨髓——<strong>「先排除肿瘤，再诊断风湿」</strong>是儿童风湿病铁的纪律。</span>

**治疗（目标：达标治疗 treat-to-target）**：
- **一线**：非甾体抗炎药（NSAIDs）缓解关节症状 + 关节内激素注射。
- **二线**：甲氨蝶呤（MTX，慢作用抗风湿药）——JIA 治疗的「锚」。
- **生物制剂**：抗 TNF-α（依那西普）、抗 IL-6（托珠单抗，尤其 sJIA）、IL-1 拮抗剂——**「靶向细胞因子」是现代风湿病治疗革命的核心**。
- **辅助**：物理治疗、关节保护、眼病筛查（少关节型）——**治疗关节炎，更要治疗这个「人」**。

**HSP、JIA、川崎病「一张表对照」**——儿童风湿病三大主角放一起对号入座：

| 特征 | 过敏性紫癜（HSP） | 幼年特发性关节炎（JIA） | 川崎病 |
| --- | --- | --- | --- |
| 本质 | IgA 血管炎 | 慢性滑膜炎 | 全身性血管炎 |
| 典型年龄 | 3–10 岁 | 各年龄，女孩多 | 5 岁以下 |
| 特征表现 | 可触性紫癜 + 腹痛 + 关节 + 肾 | ≥ 6 周关节肿痛 | 发热 + 结膜充血 + 草莓舌 + 手足硬肿 |
| 危险并发症 | HSP 肾炎、肠套叠 | MAS、虹膜睫状体炎 | 冠状动脉瘤 |
| 治疗主线 | 对症 + 重症激素 | NSAIDs → MTX → 生物制剂 | 阿司匹林 + IVIG |
| 预后 | 多自限，看肾 | 慢性，需长期随访 | 冠脉随访，多良好 |

**读表结论**：三者都是「免疫攻击自身」，但**靶点（血管/关节/冠脉）不同、病程（急性/慢性/亚急性）不同、治疗（对症/慢病/免疫抑制）不同**——儿童风湿病的分型，本质是「免疫失调 + 靶器官 + 病程」的三元坐标。

## 4 公式解析：儿童风湿病的「器官扫描」决策公式

把过敏性紫癜与 JIA 放进同一套临床推理，核心公式是一个「**炎症负荷 × 受累器官**」的决策框架：

$$
\text{处理强度} = f(\text{炎症活跃度}, \text{关键器官受累}, \text{时间病程})
$$

**逐项拆解**：
- **第一步，看炎症活跃度**：持续发热 + ESR/CRP 显著升高 + 关节肿痛 → 炎症在「活跃期」；若是 sJIA 出现白细胞极高、铁蛋白飙升、血小板下降 → 警惕 **MAS**（炎症风暴）。
- **第二步，看关键器官**：HSP 的「关键器官」是**肾脏与肠道**——有血尿/大量蛋白尿或剧烈腹痛，处理立刻升级（激素/免疫抑制剂/住院）；JIA 的「关键器官」是**眼睛与关节**——虹膜睫状体炎可致盲，必须眼科随诊。
- **第三步，看时间病程**：HSP 多数是「**一过性**」病（数周自限）；JIA 是「**慢性**」病（≥ 6 周持续，需长期随访）——**时间维度把「急性血管炎」与「慢性关节炎」分开**，也决定了「短期对症」还是「长期达标治疗」。
- **第四步，动态调整**：治疗不是一次定终身——HSP 随访尿常规 6–12 个月，JIA 定期评估关节与炎症指标，**「以目标为导向（treat-to-target）」就是把这个公式里的变量持续求值**。

**辨析｜易错点**：紫癜 + 腹痛 ≠ 马上手术（先排除 HSP 肠套叠）；关节痛 + 发热 ≠ 一定感染（抗生素无效要想到风湿与肿瘤）；**皮疹消了 ≠ 病好了**（HSP 的肾、JIA 的眼都要长期盯）——**儿童风湿病的「战场」常常在看不见的地方**。

## 5 小结

- **儿童风湿病 = 免疫系统攻击自身组织**，分血管炎（川崎病、HSP）、关节炎（JIA）、抗体介导（SLE）三大类——**症状在器官，病根在免疫**。
- **过敏性紫癜（IgA 血管炎）**：可触性紫癜（四肢伸侧）+ 关节 + 腹痛 + 肾；**腹痛先于皮疹最易误诊**；重症靠激素；**远期预后看肾，随访尿常规**。
- **幼年特发性关节炎（JIA）**：≥ 6 周关节炎 + 排除肿瘤感染；分少关节/多关节/全身型（sJIA 可并发 MAS）；**先排除白血病，再诊断风湿**。
- **治疗分层**：NSAIDs → 甲氨蝶呤 → 生物制剂（抗 TNF/IL-6/IL-1）；JIA 走「达标治疗」，sJIA 盯 MAS。
- **决策公式**：处理强度 = f（炎症活跃度，关键器官受累，时间病程）——HSP 看肾与肠，JIA 看眼与关节，时间维度区分急性与慢性。
- 与《泌尿系统疾病》呼应：HSP 肾炎与肾病综合征共享「蛋白尿 + 血尿」的肾脏语言；与《感染性疾病》呼应：**「抗生素压不下的发热」是把风湿免疫病放进鉴别清单的信号灯**。

在下一节，我们把视野从「慢性风湿」转向「急性崩溃」——**儿科急危重症**：惊厥持续状态、脓毒性休克与液体复苏，用「时间就是生命」的逻辑，讲清儿科 ICU 的抢救主线。
