# 医疗美容技术（医美）

医疗美容技术是以美学与医学为基础、通过手术及光电注射等微创手段维护和塑造人体美的医疗执业类别，由国家卫生健康委单独监管并实行主诊医师资格制度。以规划教材与执业规范为纲，从医美概述与执业规范、美容外科、美容皮肤科与光电、注射微创到护理与并发症防治，系统重建医美的完整知识与技能体系。
