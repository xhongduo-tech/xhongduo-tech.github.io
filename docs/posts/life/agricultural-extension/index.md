# 农业推广学

农业推广学是研究农业科技推广与成果转化、农民科技教育与农村人力开发活动规律的应用学科，是农学门类的传统主干学科。它把农业科技创新成果从实验室送到田间地头，打通科技进村入户的"最后一公里"，对乡村振兴、粮食安全和农业现代化具有直接的支撑作用。

## 对标教材

- 《农业推广学》（高启杰主编，中国农业大学出版社）
- 《农业推广原理与方法》（中国农业出版社）
