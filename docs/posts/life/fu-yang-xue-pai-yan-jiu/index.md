# 扶阳学派（火神派）研究

扶阳学派（火神派）是清代医家郑钦安开创、以重视阳气与善用附子为标志的中医流派，其核心在于以阴阳辨诀辨识阳虚阴盛之证。学完这些章节，就能掌握阳虚证的辨证要领、四逆汤等温阳方药的变通运用，以及扶阳思想在临床各科的圆通治法。

## 对标教材

- 郑钦安《医理真传》
- 郑钦安《医法圆通》
- 卢崇汉《扶阳讲记》
