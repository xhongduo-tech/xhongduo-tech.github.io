# 特种经济动物饲养

特种经济动物饲养（090504）是畜牧学的二级学科，研究蚕、蜂、鹿、兔、貂、狐、貉、鹌鹑等具有特殊经济价值动物的生物学特性、繁殖育种、营养饲料、饲养管理与产品利用。学好该学科，能系统掌握从选种育种到产品初加工的全链条技术，支撑特色养殖产业与农户增收。

## 对标教材

- 《特种经济动物饲养学》（中国农业出版社）
- 《经济动物养殖学》（中国农业出版社）
