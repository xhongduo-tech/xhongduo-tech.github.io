## 为什么从糖尿病讲起

内分泌系统是全身的「指令网络」：激素经血液把命令送到每个器官。而糖尿病是内分泌病理的「样板间」——它发病率极高、机制清晰、急性并发症与慢性并发症俱全，把「激素 → 受体 → 效应」这条内分泌主线的每个环节都演示了一遍。阿雷提乌斯在 2000 年前就描写了尿甜、消瘦、口渴的「消融」，而我们今天将看到：胰岛素这把「开锁钥匙」一旦缺了或失灵，血糖这门「燃料」就进不了细胞。<span class="marginnote">糖尿病是现代医学最典型的「慢性病病理学」样本：急性期（DKA/HHS）考验对生化机制的理解，慢性期（微血管/大血管并发症）考验对「高糖→损伤」通路的理解。内分泌病理的许多原则，都能从糖尿病这棵树上长出来。</span>

本章主线：**激素如何工作（机制）→ 糖尿病两型（病因）→ 急慢性并发症（后果）**，再简要落到甲状腺与肾上腺两个常见病变。

## 1 激素如何工作：钥匙、门锁与反馈

激素按化学性质分三类：肽类/蛋白类（胰岛素、生长激素——靠膜受体，通过第二信使起作用）、类固醇类（皮质醇、性激素——脂溶性，穿过细胞膜与胞内受体结合，直接调节基因转录，慢而持久）、胺类（甲状腺激素、儿茶酚胺）。<span class="marginnote">激素的「快慢分工」很重要：膜受体激素（胰岛素）秒级起效、管能量；核受体激素（类固醇）小时级起效、管结构与表达。急救要快激素，慢病要慢激素——时间尺度决定了它们在病理中的角色。</span>

**内分泌疾病只有两种基本故障模式**：

**分泌过多（hyper-）**：激素或受体「油门卡死」——甲亢、库欣综合征、肢端肥大症。
- **分泌不足（hypo-）**：激素或受体「刹车失灵」——甲减、艾迪生病、1 型糖尿病。

外加一种「相对不足」：激素量正常，但**受体抵抗（resistance）**——胰岛素抵抗正是 2 型糖尿病的核心。**分泌、受体、反馈三环节任何一个出问题，就表现为「多/少」或「抵抗」的综合征。**

**反馈是内分泌的「恒温器」**：下丘脑-垂体-靶腺三级轴 + 靶腺激素的负反馈。理解反馈，才能理解诊断学里的「刺激/抑制试验」——病变在轴的上游还是下游，靠反馈反应来定位。

## 2 糖尿病：1 型与 2 型的机制分野

**糖尿病（diabetes mellitus）**诊断标准：空腹血糖 ≥ 7.0 mmol/L、糖负荷后 2h ≥ 11.1 mmol/L、或 HbA1c ≥ 6.5%。机制分两型：<span class="marginnote">诊断界的共识在近十年发生过一次「观念跃迁」：从「血糖偏高」转向「糖化血红蛋白（HbA1c）作为金标准」——因为 HbA1c 记录的是「过去三个月平均血糖的账本」，一次抽血胜过无数次偶然的血糖抽查。以时间为尺，疾病有了「积分」。</span>

**1 型糖尿病（T1DM）**：自身免疫破坏胰岛 β 细胞（呼应免疫篇的自身免疫）→ **胰岛素绝对缺乏**。发病早、体型偏瘦、易酮症。必须胰岛素治疗。
- **2 型糖尿病（T2DM）**：**胰岛素抵抗 + 相对分泌不足**。发病晚、常伴肥胖——脂肪组织分泌 TNF-α、游离脂肪酸等干扰胰岛素信号，β 细胞「越干越累」最终衰竭。

**胰岛素抵抗的机制链条**：受体酪氨酸激酶信号受阻 → 葡萄糖转运体（GLUT4）不向细胞膜迁移 → 细胞「门不开」→ 血糖进不了细胞、滞留在血液 → β 细胞代偿性多分泌 → 长期代偿走向 β 细胞衰竭。<span class="marginnote">把胰岛素抵抗想成「钥匙插进门锁但锁芯锈了」：胰岛素（钥匙）充足，GLUT4（门）却开不了。锻炼之所以是糖尿病的一线疗法，正因为肌肉收缩可以「绕过锁芯」直接动员 GLUT4——物理开锁。</span>

**重点：1 型是「没有钥匙」，2 型是「锁坏了」。** 治疗逻辑由此分流：T1DM 补钥匙（胰岛素），T2DM 先修锁（运动、减重、二甲双胍），后期也要补钥匙。

## 3 急性并发症：DKA 与 HHS

血糖失控的急性危机有两个面孔：

**糖尿病酮症酸中毒（DKA）**，多见于 T1DM：胰岛素极度缺乏 → 细胞「吃不进糖」→ 身体误以为在挨饿 → **脂肪大量动员 → 肝脏生成酮体（乙酰乙酸、β-羟丁酸）**→ 高酮体 → 代谢性酸中毒（阴离子间隙增高型，呼应水电酸碱篇的 AG）→ 渗透性利尿 → 脱水、电解质紊乱。**DKA = 胰岛素缺 + 酮体堆 + 酸中毒 + 脱水**的「四合一危机」。<span class="marginnote">DKA 的治疗三件套正是机制三连击：补液（补脱水）、补胰岛素（补钥匙，让细胞吃上糖、停止生酮）、补钾（酸中毒纠正时钾会回细胞，血钾骤降——处理酸中毒必须先想钾）。机制读懂，治疗顺序自然就排出来了。</span>

**高渗性高血糖状态（HHS）**，多见于 T2DM 老年患者：有少量胰岛素（不生酮）但高血糖极重 → 严重高渗 → 极度脱水、意识障碍，**酸中毒不明显**。

**辨析｜易错点：** DKA 与 HHS 的差别在「生不生酮」：有没有「几乎无胰岛素」这一条件。DKA 有酮体+酸中毒，HHS 无酮体但高渗更凶险。两者都是「高血糖危机」，但「酮 vs 渗」决定了补液与补胰岛素的节奏差异——切不可混为一谈。

## 4 公式解析：HbA1c 与平均血糖的换算

糖尿病的「时间积分」指标是**糖化血红蛋白（HbA1c）**——红细胞 120 天寿命里，血红蛋白被高血糖「糖化」的比例，恰好记录了过去约 3 个月的平均血糖账本。它与平均血糖的换算公式（ADAG 研究）:

$$
eAG\ (\text{mmol/L}) = 1.59 \times \ce{HbA1c}\ (\%) - 2.59
$$

（若用 mg/dL 记，则为 $eAG = 28.7 \times \ce{HbA1c} - 46.7$。）三步拆解：

- **第一步，认识 HbA1c 的物理意义**：它是「血红蛋白被糖化的百分比」——血糖越高、暴露越久，糖化比例越高，所以它是「浓度 × 时间」的积分。
- **第二步，看换算关系**：$\ce{HbA1c}$ 每升高 1%，平均血糖约升高 1.6 mmol/L（线性近似）——一个方便记忆的「换算率」。
- **第三步，理解为什么它比空腹血糖强**：空腹血糖是「瞬时快照」，HbA1c 是「三个月账单」——**诊断与监测慢性病，要的是积分而不是快照**，这正是它成为糖尿病管理金标准的原因。<span class="marginnote">HbA1c 的「积分思维」与训练曲线异曲同工：瞬时 loss 有噪声，平滑后的累计曲线才是真趋势。糖尿病的血糖管理目标（HbA1c < 7%）同样是以「积分不失控」为锚。</span>

**重点：HbA1c 反映平均血糖，但它掩盖「波动」**——一个「整天高低起伏」的糖尿病患者与一个「平稳」的患者可以有相同的 HbA1c，而血糖波动本身也是血管损伤的因素。**平均值掩盖方差，是统计盲区在医学里的又一次现身。**

## 5 慢性并发症：微血管、大血管与代谢综合征

糖尿病慢性并发症是「高糖损伤通路」在全身的清算：

**微血管并发症**（高糖 → 多元醇通路、AGEs 产物、PKC 激活 → 血管壁损伤）：**糖尿病肾病**（→ 蛋白尿、CKD——肾脏篇的探针在此闭环）、**糖尿病视网膜病变**（→ 失明）、**周围神经病变**（→ 麻木、溃疡、糖尿病足）。
- **大血管并发症**：加速动脉粥样硬化（呼应心血管篇）→ 冠心病、卒中、外周动脉病。

**代谢综合征（metabolic syndrome）**是糖尿病、高血压、血脂异常、腹型肥胖的「抱团取暖」：胰岛素抵抗 + 内脏脂肪 + 慢性炎症（TNF-α 等，呼应炎症篇）三者互相喂大。<span class="marginnote">代谢综合征是「多疾病共享同一机制根」的教科书案例：胰岛素抵抗是共同的「上游 bug」，下游同时输出高血糖、高血压、高脂、炎症——处理上游（减重、运动）能一箭多雕。这与「找准根因、一次修复多个下游」的系统调优思维同构。</span>

**甲状腺与肾上腺速览**：甲亢（甲状腺激素过多：高代谢、心悸、突眼；Graves 病是 II 型超敏的明星病例）与甲减（代谢低下、黏液性水肿）；库欣综合征（皮质醇过多）与艾迪生病（皮质醇不足）——它们全是「分泌多/少」两种故障模式的实例。

**重点：糖尿病的慢性并发症本质是「高糖这一持续的应激」——高糖本身就是一种慢性应激源**，它通过氧化应激、炎症与糖化改造血管与神经。控制血糖就是控制「应激的剂量」——又回到了应激与代偿那架天平。

## 6 小结

- 激素按**肽类（快）、类固醇（慢）、胺类**分工；内分泌病 = 分泌多、分泌少、受体抵抗。
- 糖尿病诊断靠**空腹血糖 / 糖负荷 / HbA1c**；**1 型=没有钥匙，2 型=锁坏了**。
- 急性危机：**DKA（胰岛素缺+酮症酸中毒）vs HHS（无酮、严重高渗）**；治疗=补液、补胰岛素、补钾。
- **HbA1c 是「三个月血糖积分」**：eAG ≈ 1.59×HbA1c − 2.59（mmol/L）；它掩盖波动。
- 慢性并发症：**微血管（肾/视网膜/神经）+ 大血管（粥样硬化）**；代谢综合征共享胰岛素抵抗根因。

在下一节，我们把「总指挥」换到代谢的工厂——肝脏。肝是合成、解毒、代谢的枢纽，肝坏了，全身的营养、凝血、排毒全线崩盘。这就是**肝功能不全与消化系统病理生理**。
