## 为什么把休克与 DIC 放一起

前几章分别讲心、肺、血各自的病；休克却是**它们同时出事的终局**——循环系统全面崩溃，组织灌注普遍不足，氧债越欠越多。而 DIC（弥散性血管内凝血）是休克最凶险的「并发症之一」，本质是凝血系统被「总体动员」到失控：全身各处微血管都堵，凝血因子被耗尽，于是反过来大出血。<span class="marginnote">格罗斯这句 19 世纪的描述至今仍是休克的最佳文学定义。现代病理学把「机器的粗鲁拆卸」翻译成机制语言：灌注不足 → 细胞缺氧 → 无氧代谢与乳酸 → 器官衰竭。休克是多器官功能障碍（MODS）的「起跑线」。</span>

本章是前面所有「供氧链」的终点站：心泵、血容量、血管张力、氧输送——一个环节断掉，其余全部陪葬。

## 1 休克的定义与四种类型

**休克（shock）**定义为**全身组织灌注不足，导致氧供与代谢需求严重失衡**的临床综合征。按「断在哪个环节」分四型：<span class="marginnote">四型休克的记忆法：血丢了（低血容量）、泵坏了（心源性）、血管被堵（梗阻性）、血管全松了（分布性）。前三种是「管道物理问题」，最后一种是「闸门失控问题」。</span>

| 类型 | 主要机制 | 典型原因 |
| --- | --- | --- |
| 低血容量性（hypovolemic） | 血量锐减 | 大出血、严重脱水、烧伤 |
| 心源性（cardiogenic） | 泵衰竭 | 大面积心梗、严重心律失常 |
| 梗阻性（obstructive） | 血流受阻 | 心包填塞、肺栓塞、张力性气胸 |
| 分布性（distributive） | 血管张力失控 | 脓毒症（最常见）、过敏性、神经源性 |

**四型有一条共同的下游**：有效循环血量下降 → 组织灌注不足 → 细胞缺氧。差异只在「血少了、泵弱了、堵住了、还是血管全松了」——所以休克治疗的黄金三问是：**补液够不够？泵强不强？血管紧不紧？**

## 2 休克的代偿与失代偿：从硬扛到崩溃

休克不是线性恶化，而是**代偿 → 失代偿 → 不可逆**三个阶段：

**代偿期（compensated shock）**：血压还没怎么掉，身体已进入总动员——交感兴奋（心率快、四肢冷、冷汗）、动脉收缩维持脑心灌注、RAAS 保水保钠。**此时最危险：血压「正常」是假象，组织其实已在缺血。**<span class="marginnote">「血压正常≠没事」是休克判断的第一课。靠血管收缩维持的「稳态」是把血从皮肤、肾、肠「挪用」到脑心——代偿期早识别、早补液，是休克死亡率的分水岭。</span>

**失代偿期（progressive shock）**：代偿耗竭，血压真正下降，组织缺氧加剧，乳酸堆积（无氧代谢），毛细血管通透性增加，血向组织间隙「漏」——有效血量进一步下降，恶性循环。

**不可逆期（irreversible shock）**：细胞不可逆损伤（前面细胞篇的生死线）、DIC、多器官衰竭——即便纠正血压也难以挽回。**休克的「时间窗」概念由此而来：救治的有效性随失代偿程度急剧衰减。**

## 3 公式解析：MAP 与灌注压——休克的血压算术

休克监测的「主仪表」是**平均动脉压（MAP）**：

$$
MAP = DBP + \frac{1}{3}(SBP - DBP)
$$

也可以用基础方程展开（心血管篇的公式在此复用）：

$$
MAP = CO \times SVR
$$

三步拆解：

- **第一步，MAP 是「时间平均」血压**：舒张期占心动周期的三分之二，所以 MAP 不是收缩压和舒张压的平均，而是「偏向舒张压」的加权平均——这就是公式里 $1/3$ 与 $2/3$ 的来源。
- **第二步，拆成泵与阻力**：$MAP = CO \times SVR$——血压高不高，看「泵了多少 × 管道多紧」。低血容量性休克两者都掉，分布性休克主要是 SVR 崩。
- **第三步，联系灌注**：真正决定器官生死的是**灌注压**，MAP 减去下游阻力与出口压力：

$$
CPP \approx MAP - ICP
$$

**对脑而言，灌注压 = 平均动脉压 − 颅内压**（神经篇会展开颅内压）。MAP 低于 65 mmHg 左右，脑、肾、冠脉的自主调节就失守，灌注直接随 MAP 塌方。

**重点：休克治疗的血压目标不是一个「好看的数字」，而是「够器官用的灌注压」**——MAP ≥ 65 mmHg 是临床通用门槛，而乳酸（组织缺氧的「账单」）下降才是复苏成功的金标准。<span class="marginnote">把乳酸当「组织缺氧的记账员」：乳酸越高、清得越慢，说明组织缺氧越深。复苏的目标不是血压好看，而是让乳酸这条「负债曲线」掉头向下——监测「负债」比监测「资产」（血压）更能反映真相。</span>

## 4 脓毒性休克与 MODS

**脓毒性休克（septic shock）**是最常见的分布性休克，也是当代重症医学的主战场：感染 → 病原产物（LPS 等）激活炎症风暴 → 大量一氧化氮、前列腺素释放 → **血管广泛扩张 + 毛细血管通透性骤增** → 有效血量剧降 + 心肌抑制 → 休克。<span class="marginnote">脓毒症是「免疫系统把火力开向自己」的极端：炎症介质（TNF-α、IL-1）在试图清除病原时把血管床「烧」到扩张失灵。这完美呼应炎症篇「介质网络」——介质的保护作用一旦放大失控，就成了损伤。</span>

脓毒性休克有两个区别于其他休克的标志：**暖休克（早期：四肢暖、皮肤潮红，血管扩张为主）**与 **冷休克（晚期：四肢冷，心排下降）**——早期「高排低阻」的悖论（泵反而快）常让人误判。

**MODS（多器官功能障碍综合征）**是休克的终点：肺（ARDS）→ 肾（急性肾损伤）→ 肝（肝衰）→ 凝血（DIC）→ 肠（菌群移位）。器官之间相互拖累——肺坏了肾缺氧、肾坏了排毒难、肠漏了再感染——这是全身「级联故障」的顶级标本。<span class="marginnote">MODS 像一台「串联电路」：一个器官断流，其他器官的毒素与氧债层层放大。重症监护的「器官支持」（呼吸机、CRRT、ECMO）本质是在电路里并联「备用电源」，为原发病治疗争取时间。</span>

## 5 DIC：凝血瀑布的失控

**DIC（弥散性血管内凝血）**是凝血系统被「总动员」到失控的综合征，特征是**微血管内广泛微血栓形成 + 凝血因子与血小板消耗性减少 → 出血**。听上去自相矛盾——又堵又漏——其实是一个过程的两面：

1. **触发**：感染、创伤、产科意外、恶性肿瘤 → 组织因子大量释放 → 凝血瀑布被「超载启动」。
2. **微血栓**：全身微血管布满纤维蛋白血栓 → 器官缺血坏死（肾、脑、肺）。
3. **消耗**：凝血因子、血小板被耗尽 → 继发纤溶亢进 → **凝血与出血同时存在**，呈现「微血栓 + 瘀斑 + 渗血」的怪象。<span class="marginnote">DIC 的「又堵又漏」是最考验机制理解的临床题：微血栓是「堵」，消耗性低凝与纤溶亢进是「漏」。治疗要标本兼顾——抗凝（处理堵）与补充（处理漏）的平衡，正是 DIC 处理的艺术与难点。</span>

**实验室三联征**：血小板下降 + PT/APTT 延长 + D-二聚体升高（继发纤溶的产物）。**DIC 的判断靠「消耗 + 激活」两个方向的证据同时在场**——单看血小板低不是 DIC，还要看凝血与纤溶被激活的痕迹。

**辨析｜易错点：** 原发性纤溶（纤维蛋白原溶解，无微血栓）与 DIC 的继发性纤溶不同：DIC 必须先有「凝血激活」这一环（微血栓 + 消耗），原发性纤溶没有微血栓。**DIC 是「先凝后溶」，不是单纯的「溶」**——这个顺序区分是诊断与治疗的分岔口。

## 6 小结

- 休克 = **全身灌注不足**；四型：低血容量、心源性、梗阻性、分布性（脓毒性最常见）。
- 代偿三阶段：**代偿（血压假正常）→ 失代偿（恶性循环）→ 不可逆**。
- **MAP = CO × SVR**，灌注压 = MAP − 出口阻力；复苏看**乳酸**而非血压表象。
- 脓毒性休克是**炎症风暴 + 血管失控**；MODS 是器官级联故障。
- **DIC = 微血栓 + 消耗 + 出血并存**；实验室三联征：血小板↓ + PT/APTT↑ + D-二聚体↑。

在下一节，休克最常波及的器官之一就是肾——肾既是最脆弱的受害者，也是全身水电酸碱平衡的总闸。肾的病理生理，我们放在**肾脏病理生理**。
