## 为什么从肝脏讲起

如果把全身器官比作一家公司，肝脏就是**代谢与解毒的「中央工厂」**：合成蛋白质与凝血因子、储存糖原、代谢药物与毒素、分泌胆汁、参与免疫。肝脏坏了，营养、凝血、排毒、消化全线崩盘。而消化系统则是这间工厂的「原料入口」——肝肠联动，互为因果。<span class="marginnote">肝脏的功能多到可以被戏称「全能器官」：血液篇的凝血因子、脂质篇的胆固醇、内分泌篇的激素灭活、甚至铁与铜的代谢，全在肝里中转。正因如此，肝功能不全的表现才会「多而不专」——黄疸、腹水、出血、脑病、消瘦，各归一条通路。</span>

本章主线：**肝脏的四大职能 → 衰竭的四大表现（黄疸、门脉高压、肝性脑病、凝血障碍）→ 再落到消化系统的两个高发病（溃疡、炎症性肠病）**。

## 1 肝脏的四大职能与肝衰竭

肝脏职能可以压缩成四句话：

1. **代谢**：糖代谢（糖原合成与分解）、脂代谢（脂蛋白、胆固醇）、蛋白代谢（白蛋白合成、尿素循环解毒氨）。
2. **合成**：白蛋白（维持血浆胶体渗透压）、凝血因子（I、II、V、VII、IX、X 等）、胆汁。
3. **解毒**：药物、毒物、氨（经尿素循环）、胆红素（结合并排出）。
4. **储存**：糖原、铁、脂溶性维生素。

**肝衰竭（liver failure）**是肝功能大幅丧失的终局，其典型表现是四大件：**黄疸、凝血障碍、门脉高压（→腹水/食管静脉曲张）、肝性脑病**——四件套正对应「合成、解毒、血流、排毒」的四大职能。<span class="marginnote">肝功能可以承受极大损失而「默默无闻」——肝有强大再生能力，切除 70% 仍能工作。因此肝衰竭往往等到「储备见底」才突然暴雷——这也是「代偿能力越强、报警越晚」的又一例。</span>

**肝硬化（cirrhosis）**是肝衰竭最常见的形态学背景：慢性损伤（病毒性肝炎、酒精、脂肪肝）→ 纤维化 → 假小叶形成、结构重塑 → 血流受阻 + 功能减退。**肝硬化是「肝的慢性炎症修复失序」**——把炎症篇的「纤维化是慢性炎症的终点」在此精准落地。

## 2 黄疸：胆红素的账本

**黄疸（jaundice）**是皮肤巩膜黄染，根源是**胆红素代谢账本**失衡。胆红素代谢分四站：

1. **来源**：衰老红细胞被脾脏吞噬 → 血红蛋白 → 胆红素（未结合型，间接胆红素）。
2. **运输**：未结合胆红素不溶于水，由白蛋白运到肝。
3. **肝内结合**：肝细胞把它与葡萄糖醛酸结合成**结合型胆红素（直接型）**——可溶于水。
4. **排泄**：经胆汁入肠 → 肠道细菌把它还原为尿胆素原 → 大部分随粪（粪胆素，粪便的棕色来源）、小部分重吸收经肾排出（尿胆素原）。

黄疸按「账本坏在哪一站」分三类，是临床分型的关键：

| 类型 | 关键特征 | 机制 |
| --- | --- | --- |
| 溶血性黄疸 | 未结合胆红素↑，粪色深 | 原料太多（来源站爆仓） |
| 肝细胞性黄疸 | 结合+未结合均↑ | 加工厂罢工（肝损伤） |
| 梗阻性黄疸 | 结合胆红素↑，**陶土色便**、尿深茶色 | 出口堵塞（结石/肿瘤） |

**重点：黄疸分型 = 定位「胆红素账本」断在哪一站。** 溶血看血、肝病看肝、梗阻看胆——**陶土色粪便 + 尿深茶色是梗阻性黄疸的「路标」**，因为胆红素进不了肠、改道从尿排。<span class="marginnote">黄疸的「账本思维」是个漂亮的系统模型：源头（脾）、加工（肝）、出口（胆）三个节点，测「未结合 vs 结合」两个变量即可定位。这与排查一条流水线「哪道工序堵了」是同构的推理。</span>

**辨析｜易错点：** 新生儿黄疸多为生理性（肝脏结合酶未成熟、红细胞寿命短），但若是病理性（Rh 血型不合溶血）需光疗——光疗把脂溶性未结合胆红素转成水溶性异构体排出，防止其进入脑（核黄疸）。**同一个「黄」，生理与病理的天壤之别，就在账本的「超没超阈值」。**

## 3 门脉高压：腹水、食管静脉曲张与脾大

肝内血流受阻（肝硬化纤维化压迫肝窦）→ 门静脉压力升高 → **门脉高压（portal hypertension）**。它是肝硬化最危险的并发症链的源头：

**侧支循环开放**：门体分流——食管胃底静脉曲张（破裂则大呕血，致命）、脐周静脉曲张、痔静脉曲张。
- **腹水（ascites）**：门脉高压 + 低白蛋白（合成差）→ 血浆胶体渗透压↓ + 静水压↑ → 液体漏入腹腔。低白蛋白是「拉水」不足，门脉高压是「推水」过强——**一推一拉，腹水成**。
- **脾大与脾功能亢进**：脾静脉回流受阻 → 脾充血增大 → 过度破坏血细胞 → 血细胞三系减少。

**门体分流的最大隐患**：肠道吸收的毒物（氨等）本该经肝解毒，却绕过肝直接入血 → 肝性脑病。**门脉高压不只是「血管问题」，它是肝功能不全与脑病的枢纽**。<span class="marginnote">食管静脉曲张破裂出血是消化科最凶险的急诊之一——门脉压力高到血管壁「吹气球」而爆。治疗思路（β受体阻滞剂降压力、内镜套扎、TIPS 分流减压）全部围绕「给这根血管减压」，又一次「物理方程决定治疗方案」。</span>

## 4 公式解析：门脉压力的流阻模型

门脉高压可以用一个物理方程说清——**流-阻模型（Poiseuille/Ohm 定律的血管版）**：

$$
\Delta P = Q \times R
$$

门静脉压力差 = 门静脉血流量（$Q$）× 肝内血流阻力（$R$）。三步拆解：

- **第一步，看变量**：$Q$ 是流入门静脉的血（主要来自肠、脾），$R$ 是血流穿过肝脏时的阻力——正常肝脏阻力很低，门脉压力约 5–10 mmHg。
- **第二步，看肝硬化**：纤维化与假小叶**把 $R$ 推高**，ΔP 随之飙升——这是肝硬化门脉高压的主因。
- **第三步，看两种解法**：降 $Q$（β受体阻滞剂减少内脏血流）或降 $R$（TIPS 分流、药物扩张）——**治疗即调节方程**。<span class="marginnote">这几乎就是电路里的「欧姆定律」：门脉系统是电阻网络，肝硬化的纤维化等于给回路加电阻。凡是「流量×阻力=压差」的地方（血管、气道、肾单位），病理学就用同一个方程语言——这是工程学思维在医学里最无违和的渗透。</span>

**重点：门脉高压治疗的一切目标都归结为「降压」——要么少送血（降 Q），要么通开道（降 R）。** 记住这个方程，食管静脉曲张、腹水、脾大的治疗逻辑就都能挂上去。

## 5 肝性脑病与消化系统的两个高发顽疾

**肝性脑病（hepatic encephalopathy）**：门体分流 + 肝功能衰退 → **血氨升高** → 氨进入脑 → 干扰神经递质与能量代谢 → 意识障碍、扑翼样震颤、昏迷。机制链：**肠道产氨（蛋白质分解）→ 肝解毒失灵（或分流绕过肝）→ 血氨↑ → 脑中毒**。治疗因此反着来：降肠内产氨（乳果糖酸化肠道、抗生素杀产氨菌）、限蛋白、纠正诱因。<span class="marginnote">血氨的「肝-脑轴」是全章最漂亮的机制闭环：肠道（生产）→ 肝（解毒）→ 脑（受害）。任何一环的「修门」都有效——这正是「机制图即治疗图」的活教材。</span>

**消化性溃疡（peptic ulcer）**：胃十二指肠黏膜被胃酸/胃蛋白酶「自蚀」——攻击因子（胃酸、Hp）与防御因子（黏液、HCO₃⁻、血流）失衡。**幽门螺杆菌（Hp）是主角**：它定居胃黏膜、分泌尿素酶分解尿素产氨中和胃酸「自保」，同时破坏黏液屏障 → 溃疡。治疗从「抑酸 + 杀菌（三联/四联）」，一改过去「只抑酸不除根」的时代。<span class="marginnote">消化性溃疡是现代医学「病原学胜利」的经典：从「压力大、饮食乱」的旧解释，到「Hp 感染」的微生物学新解释（Marshall 喝下 Hp 培养液自证）。一个机制认知的更新，让溃疡从「反复发作」变成「可治愈」——知识的直接生产力。</span>

**炎症性肠病（IBD）**：克罗恩病（Crohn，全消化道可受累、节段性、透壁炎症、肉芽肿）vs 溃疡性结肠炎（UC，限于大肠黏膜、连续性浅表溃疡、血便）。两者都是**免疫耐受崩溃 + 肠菌 + 遗传**共同作用——肠道免疫的「过度反应」，把炎症篇的自身免疫与超敏机制搬到了肠黏膜。<span class="marginnote">克罗恩 vs 溃疡性结肠炎的鉴别是经典「二选一」：透壁 vs 黏膜、全肠 vs 结肠、肉芽肿 vs 连续溃疡、瘘管 vs 无瘘管。两组「对位特征」背下来，IBD 分型就稳了。</span>

**辨析｜易错点：** 上消化道出血（呕血、黑便）与下消化道出血（便鲜血）别混淆；溃疡出血属前者（黑便 = 血经肠道消化变黑）。而肝硬化食管静脉曲张破裂的呕血是**大呕血、凶险**，与溃疡的慢性渗血在量与速度上完全不同——**同为呕血，来源与处置迥异**。

## 6 小结

- 肝四大职能：**代谢、合成（白蛋白/凝血因子）、解毒、储存**；肝衰竭四件套：黄疸、出血、门脉高压、脑病。
- 黄疸 = **胆红素账本定位**：溶血（原料爆仓）、肝细胞（工厂罢工）、梗阻（出口堵塞，陶土便）。
- 门脉高压 = **ΔP = Q×R**：肝硬化抬高 R；腹水 = 静水压推 + 低白蛋白拉。
- 肝性脑病 = **肠产氨 → 肝解毒失灵/分流 → 血氨↑ → 脑中毒**；治疗反向降氨。
- 消化性溃疡 = **攻击/防御失衡 + Hp 感染**；IBD：克罗恩（透壁）vs 溃疡性结肠炎（黏膜）。

在下一节，我们抵达这套教材的最后一座「指挥塔」——大脑。大脑的病理有它自己的语法：神经元的电活动、血脑屏障、神经递质。这就是**神经病理生理**。
