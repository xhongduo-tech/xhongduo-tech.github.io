## 为什么从五脏辨证开始

针法篇收官后，我们站在「会用针」的门槛上。但针下在哪，取决于**辨证**——不懂辨证，针再快也扎不准靶心。董氏奇穴的辨证，不玩空泛的「阴阳表里寒热虚实」全套八纲，而是**以五脏为纲**：先辨病在哪一脏，再按「一脏有一组穴」的映射直接取穴。这一节我们建立这套「五脏→穴组」的辨证-取穴管道，它是临床篇全部病种治疗的总开关。

## 1 五脏辨证的总框架

董氏辨证的核心，是**把复杂的病证归结为五脏的功能失衡**，再映射到对应穴组。其逻辑链条是：

**辨主证 → 定病脏 → 取该脏对应奇穴 → 配以补泻开阖。**

| 五脏 | 主症提示 | 董氏对应穴组 |
| --- | --- | --- |
| 肝 | 胁痛、目疾、情志抑郁 | 明黄、天黄、其黄 |
| 心 | 心悸、失眠、胸闷 | 心门、正会、神耳 |
| 脾 | 腹胀、纳差、乏力 | 通关、通山、通天 |
| 肺 | 气喘、咳嗽、易感 | 驷马上中下 |
| 肾 | 腰痛、耳鸣、夜尿 | 马金水、水通、水金 |

<span class="marginnote">董氏辨证的实用主义一目了然：穴名即主脏——「明黄」应肝、「心门」应心、「通关」应脾胃、「驷马」应肺、「水金」应肾。记住了五行与穴名，辨证就完成了一半。</span>

**重点：董氏五脏辨证「一脏一穴组」的高度对应，是它区别于十四经「一方多经配穴」的最大特色。** 辨证不必绕弯，定脏即可定穴。

## 2 五行穴性与脏腑的对应

董氏穴名里的五行字，是辨证时的快捷标尺：<span class="marginnote">五行制命名的穴，其穴性即五行之性——木主肝、火主心、土主脾、金主肺、水主肾，辨证取穴可反推。</span>

- **木行穴**（木火、木炎、木留等）→ 应肝胆，性偏升发疏泄。
- **火行穴**（火主、火硬、火腑海等）→ 应心与小肠，性偏温热通散。
- **土行穴**（土水等）→ 应脾胃，性偏和中运化。
- **金行穴**（手五金、足五金、金水等）→ 应肺与大肠，性偏清肃。
- **水行穴**（水曲、水相、水金等）→ 应肾与膀胱，性偏滋润下行。

**辨析｜易错点：** 五行穴性对应的是**穴的倾向**，不等于**病证的必然**。肝病可选木行穴，但若肝火旺盛，反而宜取水性凉润之穴以泻——辨证须看虚实，不能只看五行对应。

## 3 虚实开阖：补泻的辨证落点

「虚实开阖」是董氏辨证与针法的连接点：

- **虚证**：气弱力乏、面色萎黄、久病。**治法宜补**——取穴少而浅刺轻捻，久留温养，穴位取本脏穴的「补位」。<span class="marginnote">虚证取穴如同「文火慢炖」：穴少、刺浅、捻轻、留久，让气缓缓归位。</span>
- **实证**：痛剧拒按、烦躁、新病急病。**治法宜泻**——取穴多而深刺重捻，或点刺放血，以通为泻。
- **开阖**：指营卫气血的开阖出入与时令相应。开者，邪去正复、气血周流；阖者，邪留窍闭、气血壅滞。**开阖辨证决定针刺的方向与时机**——邪实宜「开」（放血、透刺、动气），正虚宜「阖」（浅补、温养、久留）。

## 4 核心对比表：董氏五脏辨证与八纲辨证的分工

| 维度 | 八纲辨证 | 董氏五脏辨证 |
| --- | --- | --- |
| 抓取重点 | 阴阳表里寒热虚实 | 病位在哪一脏 |
| 输出结果 | 证型（如肝气郁结） | 对应穴组（明黄天黄其黄） |
| 与取穴距离 | 需再配穴选穴 | 辨证即取穴，一步到位 |
| 补充关系 | 定性质 | 定靶点 |

**记住：八纲辨「性质」，五脏辨「靶点」。** 董氏把二者糅合——先用八纲辨虚实寒热，再用五脏辨证定穴组，最后用虚实开阖定手法，三层叠加构成完整辨证。

## 5 五脏辨证与「从极限到大模型」主线

「定脏即定穴」的映射表，是医学版的**「分类器直连决策」**：输入症状特征，跳过中间推理，直接输出治疗决策。这与大模型里的「端到端学习」同构——少做人为的中间表示，让「特征→决策」的映射在大量实践中被直接校准。董氏辨证的「粗暴直接」，恰恰是它高效的另一面：**在经验足够时，跳过中间层就是最快的路。**

## 6 五脏辨证的实战决策树

把五脏辨证整理成一张「决策树」，临床辨证就有了清晰的路径：

```
主证 → 问：病主要在哪个系统？
   ├─ 胁痛、目疾、情志 → 肝 → 明黄天黄其黄
   ├─ 心悸、失眠、胸闷 → 心 → 心门、正会、神耳
   ├─ 腹胀、纳差、乏力 → 脾 → 通关通山通天
   ├─ 气喘、咳嗽、易感 → 肺 → 驷马上中下
   └─ 腰痛、耳鸣、夜尿 → 肾 → 马金水、水通水金
之后 → 问：虚还是实？
   ├─ 虚 → 浅刺轻捻、久留温养
   └─ 实 → 深刺重捻、放血泻急
```

**决策要点一：主症不必求全。** 五脏辨证抓的是「第一主诉」——病人最难受的那个系统，往往就是病脏所在。<span class="marginnote">实战经验：取「最典型的一脏」先治，再随疗效调整，比一开始就五脏俱全稳妥得多。</span>

**决策要点二：虚实要辨清。** 同是肝病，肝郁气滞（实）宜泻、肝血不足（虚）宜补——虚实不辨，取穴再准也枉然。

**决策要点三：五行穴性辅助。** 穴名带五行字可直接作辅助判断——取穴时优先选与病脏相应的五行穴，再用虚实决定手法。

**重点：五脏辨证的实战价值，在于「定脏即定穴」——把辨证与取穴一步打通。** 决策树背熟，辨证不再凭感觉，而是有路可走。

**延伸：五行穴性的快速记忆歌诀。** 把五行穴性编成一句口诀：**「木肝火心土脾胃，金肺水肾莫相违」**——看到穴名带木，先想肝胆；带火，先想心与热；带土，先想脾胃；带金，先想肺肠；带水，先想肾与膀胱。穴性定，辨证就先走一半。

**易错辨析：五行穴性不等于病证五行。** 肝火旺盛之证，未必取木行穴——木行性升发，火证反宜取水性凉润之穴以泻；**穴性提示的是「穴的倾向」，辨证决定的是「取穴的选择」，二者须配合虚实判断，不可机械对应。**

**实践建议：** 遇到陌生穴名，先按五行筛法定穴性，再查主治核对——多练几次，「读名知性」就成了本能。
**延伸思考：五脏辨证是「分类器直连决策」的医学原型。** 主症→定脏→取穴，三步直达，中间不绕弯——这就像现代分类模型里的「端到端映射」：**特征（症状）直接映射到决策（穴组）**。董氏在数百年临床中把这条映射校准得足够准，才敢「定脏即定穴」。这是「经验积累 + 映射固化」的典范。

**易错辨析：五脏辨证与八纲辨证的配合。** 五脏辨证定「靶点」（病在哪一脏），八纲辨证定「性质」（虚实寒热）——**二者配合才是完整辨证**：先八纲辨虚实，再五脏定穴组，最后用虚实开阖定手法，三层叠加。

**操作提示：** 遇到「五脏皆可沾边」的复杂病，抓第一主诉——病人最难受的那个系统，往往就是病脏所在；先治一脏，再随疗效调整，比一开始就五脏俱全稳妥得多。
**五脏辨证的「五行联动」再深一层。** 五脏并非孤立——五行生克让脏腑互相影响：**肝木乘脾（肝郁则脾虚）、心火炎上（心热则失眠）**。董氏辨证虽「一脏一穴组」，但高手取穴常「见肝之病、知肝传脾」——**主穴治本脏，配穴顾其所胜所克**，辨证就从「单脏」升级为「五行联动」。

**易错辨析：五脏辨证的「抓主症」分寸。** 五脏皆可沾边的复杂病，抓第一主诉——**病人最难受的那个系统，往往就是病脏所在**；先治一脏，再随疗效调整，比一开始就五脏俱全稳妥得多。

**操作提示：** 五行穴性配合虚实判断使用——**穴性提示倾向，虚实决定取舍**：肝火旺未必取木行穴，反宜取水性凉润之穴以泻；机械对应，反失其效。
## 7 小结

- 董氏辨证以**五脏为纲**：辨主证→定病脏→取对应穴组。
- **五行穴性**是辨证标尺：木肝、火心、土脾、金肺、水肾。
- **虚实开阖**决定手法：虚则浅补久留，实则深泻放血，开阖定时机。
- 董氏辨证与八纲互补：**八纲辨性质、五脏辨靶点**。
