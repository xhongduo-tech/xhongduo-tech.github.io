# 董氏奇穴针灸

董氏奇穴针灸由董景昌先生创立，以七百余个循经与分布独特的奇穴、倒马针法、动气针法为特色，经杨维杰等传人系统整理传播，已成为立足台湾、风行全球的针灸体系。学完本学科，就系统写完了从董氏奇穴穴位体系、核心针法，到脏腑辨证、临床各科应用与全球化研究拓展的全部内容。
