# 民族医学（藏/蒙/维医学）

民族医学是中医学二级学科下研究我国各少数民族传统医药的学科，涵盖藏医、蒙医、维医等独立本科专业，各具自成体系的理论、诊断与用药特色，是中华传统医学不可或缺的组成部分。以《中国藏医学》《蒙医学》规划教材与《中国民族医药学概论》为纲，从总论到三大民族医体系逐篇展开。
