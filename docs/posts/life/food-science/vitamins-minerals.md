## 为什么从维生素与矿物质开始

碳水化合物、蛋白质与脂质供给了能量与结构， 
但人体还依赖一类「少量却不可或缺」的成分——**维生素与矿物质**。
 它们不提供能量，却几乎参与每一项代谢反应：维生素 C 
合成胶原、维生素 D 调节钙磷代谢、铁携带氧、 
钙维持神经肌肉兴奋性。对食品科学而言， 
这一章的意义在**加工视角**：
维生素是三类营养素中最脆弱的， 水洗、加热、光照、
氧气都会让它们流失。 理解各种维生素与矿物的化学性质， 
才能设计出「既好吃又保营养」的工艺——这与前面几章「微观结构决定宏观性质」的主线一脉相承。

## 1 维生素的分类与功能

**维生素（vitamin）**：人体代谢所必需、 
但多数不能在体内足量合成的微量有机化合物。 
按溶解性分两大类：

**水溶性维生素**包括维生素 C 与 B 族维生素（B1 
硫胺素、B2 核黄素、B3 烟酸、B5 泛酸、B6、B7 生物素、
B9 叶酸、B12 钴胺素）。它们过量时多随尿排出，
毒性较低，但体内储备有限， 
需经常摄入。<span class="marginnote">B 
族维生素多在谷物麸皮中富集——精制米面大量去除了 B 
族维生素，这就是「糙米比精米营养好」与「精白米需强化 
B1」的原因，见本专题《粮油食品工艺》。</span>

**脂溶性维生素**包括 A、D、E、K。它们溶于脂肪、 
随脂肪吸收，可在体内储存（主要在肝脏）， 
因此**过量摄入可能蓄积中毒**——这与水溶性维生素形成鲜明对比。

## 2 矿物质：宏量与微量

**矿物质（mineral）**：人体所需的必需无机元素， 
按需要量分**常量元素**与**微量元素**。

**常量元素**：每日需要量在 100 mg 以上，如钙、磷、镁、
  钾、 钠、氯、硫。钙是骨骼与牙齿的主要成分， 
  也是牛奶营养价值的核心。
**微量元素**：需要量很小但不可或缺，如铁、锌、碘、硒、
  铜、 锰、钼、铬。铁参与血红蛋白携氧，
  碘是甲状腺激素的原料， 硒是抗氧化酶的重要组成。

<span class="marginnote">缺铁性贫血是全球最常见的营养缺乏症，而食物中的铁分<strong>血红素铁（肉类）与非血红素铁（植物）</strong>两种：前者吸收率高，后者受植酸、草酸、多酚抑制，易被维生素 C 促进——膳食搭配对铁的生物利用度影响极大。</span>

## 3 加工对维生素与矿物质的影响

微量营养素在食品链中的流失是食品科学的核心关切：

**水洗与漂烫**：水溶性维生素（尤其维生素 C、B 族）
  溶于水， 清洗、漂烫、煮制汤汁会大量流失； 
  切块增大接触面积会加速流失。<span class="marginnote">「先洗后切、
   急火快炒、汤也喝掉」这些家常建议的背后， 
  就是维生素水溶性与热敏感性的化学事实——高温短时比低温长时更能保住维生素 
  C。</span>
**热**：维生素 C 与叶酸、B1 对热敏感；维生素 A、D、E  
  相对稳定但可被氧化。
**光与氧**：核黄素（B2）对光敏感， 
  牛奶在透明瓶中被光照会损失核黄素并产生「日光味」； 
  脂溶性维生素在氧气中氧化失活。
**pH 与金属**：维生素 C 在碱性下迅速破坏；铜、 
  铁离子催化其氧化，故烹饪避免使用铁锅久煮酸性食物。

**辨析｜易错点：** 
矿物质比维生素稳定得多——它不会被加热或氧化破坏， 
但会随水流失、被植酸等抗营养因子结合而降低吸收。 
所以「加工使矿物质的损失」主要是「溶出流失」与「吸收受阻」，
 而不是「被破坏」。

## 4 核心对比表：脂溶性与水溶性维生素

本主题是纯概念性的营养化学，用一张对比表代替公式解析，
 把最核心的差异钉死：

| 项目 | 脂溶性维生素（A/D/E/K） | 水溶性维生素（C 与 B 族） |
| --- | --- | --- |
| 吸收方式 | 溶于脂肪，随脂质吸收 | 溶于水，随水吸收 |
| 体内储存 | 大量储存于肝脏与脂肪 | 储备有限，需频繁摄入 |
| 过量后果 | 可蓄积中毒（如维生素 A） | 多随尿排出，毒性低 |
| 加工敏感性 | 对氧、光敏感，耐热较好 | 对热、氧、光、水洗均敏感 |
| 典型来源 | 鱼肝油、蛋黄、植物油、绿叶菜 | 果蔬、谷物麸皮、动物内脏 |

这张表的两行是关键：**储存方式决定「会不会中毒」， 溶解性决定「加工会不会流失」**。<span class="marginnote">维生素 
D 是例外中的例外：它可由皮肤经紫外线合成， 
属于「阳光维生素」，因此食物中普遍不足， 
常需强化（如强化牛奶），见《食品法规与标准》。</span>

## 5 生物利用度与营养强化

食物里含多少营养素，不等于人体能吸收多少。
 **生物利用度（bioavailability） **指营养素被消化吸收并发挥生理功能的程度，
 它受多种因素影响：

**抗营养因子**：植酸（谷物、豆类）结合钙、铁、锌， 
  草酸（菠菜）结合钙，单宁（茶）抑制铁吸收。
**促进因子**：维生素 C 促进非血红素铁吸收； 
  膳食脂肪促进脂溶性维生素吸收。
**加工的影响**：发酵、发芽可降解植酸； 
  蒸煮可提高某些矿物质的溶出率；研磨则可能去除富集部位。

**营养强化（fortification）**与**营养恢复（enrichment） **是应对流失的手段：
向面粉强化铁与 B 族维生素、 向食盐加碘、
向牛奶加维生素 D， 
都是改变公共营养状况的大规模工程。<span class="marginnote">食盐加碘是我国最成功的公共卫生干预之一，
 把「大脖子病」几乎消灭； 
但强化也必须防止过量——同一营养素「不足」与「中毒」之间隔着剂量，
 见本专题《食品毒理学》。</span>

## 6 小结

- **维生素**分水溶性（C、B 族）与脂溶性（A、D、E、K）； 
  前者加工易流失、过量低毒，后者可储积、过量会中毒。
- **矿物质**分常量（钙、磷、镁等）与微量（铁、锌、碘、
  硒等） ；稳定性高于维生素，但吸收受植酸、
  草酸等因素干扰。
- 加工流失主因：水溶、热解、光氧化、金属催化；维生素 C  
  是「加工敏感」的标尺。
- 生物利用度受抗营养因子与促进因子双重调控，**维生素 C  促铁吸收、植酸抑铁锌钙吸收**。
- 营养强化（加碘盐、强化面粉）是公共卫生工程， 
  但剂量是「不足」与「中毒」的分界线。
