# 对准传感器 SMASH / ORION

<div class="epigraph">
<p>对准传感器读的是标记衍射或成像，不是器件图形。SMASH、ORION 是公开产品名背后的通道：颜色、偏振、阶次怎么组合抗工艺。</p>
<footer>—— 对照 ASML SMASH / ORION 公开对准光学；[对准策略](/litho/alignment-spm)</footer>
</div>

[上一课](/litho/focus-sensor-topography)跟 Z。缺口是 XY 网格：相对上一层或零层标记把掩模场放对。主干对准策略课已有 SPM；本课落到传感器硬件名与通道，不重写套刻定义。

## 问题

标记被薄膜、CMP、不对称刻蚀损坏后，单色成像对准会偏。多波长、多阶衍射（公开叙述中 SMASH 一类）提高对工艺的稳健。把套刻坏了只写成台编码器，会漏掉标记不对称。

## 方法

传感器选波长/偏振/捕获阶次，拟合标记位置。配方按层选通道。ORION 等后续公开名强调对先进节点标记对比。与 [DBO](/litho/dbo-ibo) 分工：对准是曝光前放场，套刻计量是曝光后验残差。

<span class="marginnote">衍射级：光打在周期性光栅上不只直着走，还会按固定角度散开成一组亮线；±1 阶是紧挨直射光左右的两个一级方向。对准传感器读的就是这两束的相位差。</span>

```mermaid
flowchart TD
  MK["晶圆标记"] --> CH["多色 / 多阶通道"]
  CH --> XY["网格估计"]
  XY --> EXP["曝光场放置"]
```

<span class="marginnote">产品名会换代。本课用公开名指「多通道对准光学」这一类，不把某年手册当唯一实现。</span>

## 机制

衍射对准看 ±1 阶相位；不对称叠层让两阶不等，位置偏。多色可以把不同穿透深度的信息合起来压偏置。成像对准则吃对比度与焦。

```mermaid
flowchart TD
  ASYM["膜层 / 刻蚀不对称"] --> P1["色 A 读数偏 d1"]
  ASYM --> P2["色 B 读数偏 d2"]
  P1 --> W["差值是偏置的指纹"]
  P2 --> W
  W --> OCW["最优色加权 → 更钝的位移"]
```

<span class="marginnote">直觉类比：多色像用不同色光照水印——一种色浮在膜层表面，另一种看得更深。两色读数的差值本身就是膜层不对称的指纹；策略拿这个差值分离真位移与偏置，而不是把各色读数简单平均。</span>

## 边界

下一课标记怎么画：传感器再好，坏标记设计也救不回来。

<span class="marginnote">常见误区：通道越多不等于精度越高。通道的真正价值是互相校验偏置；配方若选了不匹配本层膜系的通道，多色只是把更多噪声加权进结果。</span>

## 小结

- 对准传感器用多通道抗工艺，读标记不读器件。
- 与曝光后套刻计量分时、分目的。
- 出处：对准策略课；SMASH/ORION 公开描述。
