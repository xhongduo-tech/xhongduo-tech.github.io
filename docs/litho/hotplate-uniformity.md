# 热板均匀性

<div class="epigraph">
<p>PEB 差一度，酸扩散差一截。热板地图会印到 CD 地图上，看起来像扫描仪场内剂量。</p>
<footer>—— 对照 PEB 热板多区控温与 CD 相关的工艺实践</footer>
</div>

[上一课](/litho/track-scanner-link)要求尽快 PEB。缺口是：到了热板，温度还是 $T(x,y)$。主干 [PEB 温度](/litho/peb-bake) 写过化学；本课写轨道热板的空间均匀与多区补偿。

## 问题

多区加热、边缘散热、接近式气隙、晶圆翘曲，使 PEB 不是一个数。CAR 的 CD 对 PEB 敏感度可以到 nm/°C 量级（依胶而定）。不量热板、只调扫描剂量，会把热地图补偿进光学，换胶或换热板就全塌。

<span class="marginnote">数字实例：若某胶的 PEB 敏感度是 1.5 nm/°C，热板边缘比中心冷 2°C，边缘芯片的 CD 就系统性偏 3 nm——对约 10 nm 量级的 CD 来说是三分之一以上的偏移，而且整片边缘一起偏，看起来极像镜头场内指纹。</span>

<span class="marginnote">常见误区：看到 CD 地图边缘异常，先去调扫描剂量。如果真凶是热板温度地图，剂量补偿会把热误差「烤」进光学模型；下次换胶或换热板，整套补偿全部作废甚至反号。</span>

## 方法

热板校准用测温晶圆或内嵌传感器，做空间图，调区功率。生产用「PEB 敏感度 × 允许 $\Delta T$」进 CDU 预算。接近式气隙必须受控，否则均匀性随片而变。软烤硬烤同样有地图，但 PEB 通常最毒。

```mermaid
flowchart TD
  HP["多区热板"] --> TXY["T(x,y)"]
  TXY --> DIFF["酸扩散地图"]
  DIFF --> CD["CD 地图"]
```

<span class="marginnote">边缘场更冷是常见模态。边缘 exclusion 与 EBR 已经切掉一部分，剩下的边缘芯片仍可能吃 PEB 梯度。</span>

## 机制

扩散长度 $\propto \sqrt{D(T)t}$，$D$ 对 $T$ 指数敏感。一度的空间差不是线性 CD 差的「一度」，而是 Arrhenius。所以热板规格用温度而不是用「看起来差不多」。

```mermaid
flowchart TD
  Q["1°C 的温差会带来多大 CD 差？"] --> LIN["线性直觉：一度=差一点点"]
  Q --> AR["Arrhenius 现实：D 随温度指数变化"]
  AR --> S1["温度略升：D 指数式变大"]
  AR --> S2["温度略降：D 指数式变小"]
  S1 --> L["扩散长度按 √(Dt) 跟着变"]
  S2 --> L
  L --> CD["脱保护量地图 → CD 地图"]
```

<span class="marginnote">术语翻译：Arrhenius（阿伦尼乌斯）规律就是「化学反应速率随温度指数式变化」的经验定律，写成 $D \propto \exp(-E_a/kT)$。它意味着温度误差不会按比例传给 CD，而是先被指数放大或缩小再传过去——这正是热板规格用 ±0.1°C 这类数字说话的原因。</span>

## 边界

下一课轨道缺陷：热板颗粒、升华物、背面接触，与温度地图是两条账。

## 小结

- PEB 热板地图会伪装成光学 CDU。
- 多区校准进预算，不要只调剂量。
- 出处：PEB 课；热板工艺通识。
