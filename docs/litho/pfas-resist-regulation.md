# PFAS 与光刻胶管制

<div class="epigraph">
<p>光酸发生剂与表面活性剂常含氟烷基；PFAS 管制若一刀切，先进胶配方会先于光学碰到法规墙。</p>
<footer>—— 对照半导体光刻中 PFAS 用途与 2020s 监管讨论的公开产业/SPIE 叙述</footer>
</div>

[上一课](/litho/supply-chain-single-source)谈工具集中。缺口是材料许可。本课钉 PFAS 与光刻胶管制。代工如何在法规与工具约束下选节点路径，留给[下一课](/litho/foundry-roadmap-compare)。

## 问题

化学放大胶的 PAG、猝灭剂、表面活性剂、底部抗反射，不少属于广义 PFAS 讨论范围。监管（欧盟等）若限制制造与进口，供应链会像工具一样窄。替代配方必须重新做窗口、随机、缺陷、与 OPC 版本——学习曲线时钟重启。

<span class="marginnote">PFAS（全氟/多氟烷基物质）是一大类碳链上的氢被氟替换的化合物：碳氟键极其稳定，既抗分解又低表面能。光刻恰好看中这两点——PAG 的酸强度、胶的透明度、表面活性剂的铺展都靠氟化学；但「极难分解」也正是环保管制盯上它的原因。</span>

缺口是**法规进 PDK**，不是再讲酸扩散。把胶当无限可购的化学品，规划会漏项。

### 不要把化学点名写成禁令清单

具体物质与豁免随法域与年份变。本课钉机制：先进节点胶高度依赖含氟功能，替代有周期。不把某公司退出当全球停产的完成时。

<span class="marginnote">湿法与管线里的表面活性剂同样受关注，不只是涂在晶圆上的那一微米。</span>

## 方法

跟踪：法规范围、豁免、时间表。工程：替代 PAG 的资格矩阵（E0、LER、随机、金属污染）。版本：胶换即模型换。与出口管制并列进风险登记，对象不同。

```mermaid
flowchart TD
  REG["法规限制某含氟组分"] --> SUB["候选替代配方"]
  SUB --> E0["窗口与灵敏度 E0"]
  SUB --> LER["LER 与随机"]
  SUB --> DEF["缺陷与金属污染"]
  SUB --> OPC["OPC 模型重标定"]
  E0 --> GATE{"全部通过?"}
  LER --> GATE
  DEF --> GATE
  OPC --> GATE
  GATE -->|"是"| VOL["量产爬坡"]
  GATE -->|"否"| SUB
```

## 机制

含氟基团提供酸强度、透明度、表面能，是配方自由度。去掉它们不是改浓度，是改一类化学。资格周期以年计，与节点爬坡重叠则直接进良率学习。

```mermaid
flowchart TD
  REG["PFAS 法规"] --> SUP["胶 / 表面活性剂供给"]
  SUP --> QUAL["重新资格 + OPC"]
  QUAL --> CLK["学习时钟"]
```

<span class="marginnote">为什么换胶等于换模型：显影阈值、酸扩散长度、LER 统计全部随配方变，之前调好的 OPC 模型与剂量网格建立在这些数字上。换一种 PAG 不是「换个供应商再验一下」，而是整套计算光刻参数重标，学习曲线从零再走。</span>

## 边界

不提供法律意见。不发明未公布的禁令日期。不把所有氟化学当同一监管对象。

<span class="marginnote">初学者容易以为「管制 PFAS 就是禁一种物质」。实际上 PFAS 是数千种分子的家族，各法域、各年份划定的范围与豁免不同：有的豁免半导体光刻胶，有的限期申报。把新闻标题直接当禁令日期写进规划，是最贵的错误。</span>

后课默认：材料许可是约束；下一课代工路线在工具、材料、节点名下如何分叉。

## 小结

- 先进胶与湿法含 PFAS 讨论对象；管制会重启资格与 OPC。
- 替代不是调浓度，是换化学自由度。
- 与工具集中并列，进风险登记。
- 出处：光刻 PFAS 用途与监管的公开产业/SPIE 讨论。
