# 背面与斜边清洗

<div class="epigraph">
<p>胶和 BARC 会爬到斜边和背面。夹盘看见的脏，下一台设备还要看见。清洗是接触面合同，不是图形合同。</p>
<footer>—— 对照 backside rinse / bevel clean 在轨道上的公开步骤</footer>
</div>

[上一课](/litho/wafer-edge-exposure)清正面边缘。缺口是光与 EBR 喷嘴够不着或故意留的斜边、背面。夹盘污染、热板接触不良、下一层 CVD 的边缘珠，都从这里起。

## 问题

旋涂时胶绕过斜边；搬运时正面液滴绕到背面。夹盘真空孔被堵、颗粒被压进背面再印到下一片正面。把这些写成「环境颗粒」，会漏掉可预测的爬胶路径。

## 方法

背面溶剂冲洗、斜边专用喷嘴、机械刷（谨慎，刮伤风险）。与 EBR 溶剂可能同一化学、不同几何。清洗后要检查夹盘残留与真空泄漏率。双面都有膜的工艺（某些堆积）不能乱冲——配方绑定层次。

<span class="marginnote">术语翻译：EBR（edge bead removal）处理的是正面边缘那一圈「胶圈」；本课的背面与斜边清洗是同一族化学、换了几何——喷嘴要绕到边沿和背面去，光照不到、机械手也夹不到的位置。</span>

<span class="marginnote">常见误区：以为机械刷最干净所以最好用。刷子去膜确实快，但斜边膜一旦被刮出锯齿，应力集中会让后续工艺剥离得更凶，反而制造更多颗粒。配方要绑定膜层与膜厚，不是越用力越好。</span>

```mermaid
flowchart TD
  WRAP["爬胶 / 绕液"] --> BS["背面冲洗"]
  WRAP --> BV["斜边清洗"]
  BS --> CHUCK["夹盘清洁"]
  BV --> CHUCK
```

<span class="marginnote">斜边是应力与剥离的起点，也是金属污染的高速公路。清洗过猛会在斜边留下锯齿膜，后续剥离更差。</span>

## 机制

离心与表面润湿把液体带到背面。毛细沿斜边缝爬。清洗是反向润湿+旋转甩出。残留膜在高温模块碳化成颗粒。

<span class="marginnote">直觉类比：把两块玻璃片贴在一起，中间留条细缝，插进水里水会自己往上爬——缝越细爬得越高，这就是毛细。斜边处胶与卡盘之间的微缝正是这种结构，液体不用外力就能自己钻进去；清洗则是反过来，用溶剂润湿加离心力把它请出来。</span>

```mermaid
flowchart TD
  SC["旋涂与搬运"] --> W["胶与液体爬上斜边和背面"]
  W --> C1["夹盘真空孔堵塞"]
  W --> C2["残留膜在高温模块碳化成颗粒"]
  C1 --> N["颗粒压进下一片晶圆"]
  C2 --> N
  N --> Y["夹持真空与良率同时受损"]
```

## 边界

下一课 BARC 开口：回到正面图形转印，假定背面已可夹。

## 小结

- 背面与斜边清洗保护夹盘与下游腔体。
- 与正面 EBR / WEE 几何不同，常被漏检。
- 出处：backside / bevel clean 通识。
