# 脉冲能量与重复频率

<div class="epigraph">
<p>剂量是脉冲能量乘脉冲数；产能是重复频率乘扫描时间。两个数不能合成一个「激光功率」就结束。</p>
<footer>—— 对照 [剂量控制](/litho/dose-control)、[扫描仪产能](/litho/scanner-throughput)</footer>
</div>

[上一课](/litho/laser-linewidth-narrowing)钉住带宽。缺口是能量怎么变成晶圆上的 mJ/cm²：单脉冲能量 $E_p$ 与重复频率 $f$。本课拆开这两项，不重写剂量传感器硬件（后课闭环）。

## 问题

平均功率 $P=E_p f$ 看起来够用，扫描时狭缝只看见有限脉冲数。$f$ 低则一场里脉冲少，剂量量化粗、斑纹平均差；$E_p$ 高则光学损伤与气体负担升。把「光源功率」写成一个广告数字，无法解释为何高剂量层要降速或加脉冲。

<span class="marginnote">数字实例：设某曝光点在狭缝下停留 200 μs、$f=5$ kHz，该点只接到 $N=1$ 个脉冲，剂量全押在这一次上；把 $f$ 提到 20 kHz，同一点落 4 个脉冲，抖动被平均掉一半以上。这就是高 $f$ 换剂量稳的算术。</span>

## 方法

剂量 $D \propto N E_p \times$ 照明透过率。扫描速度提高，$N$ 下降，必须升 $f$ 或升 $E_p$ 或加 [focus drilling](/litho/focus-drilling) 类的多次。脉冲能量稳定度进 CDU：脉冲间抖动直接是剂量噪声。本课只要求把 $E_p$ 与 $f$ 分列监控。

<span class="marginnote">常见误区：把「平均功率 $P=E_p f$」当成唯一指标。两台同样 100 W 的源，一台高 $E_p$ 低 $f$、一台低 $E_p$ 高 $f$，剂量粒度、斑纹平均与镜头损伤完全不同——买光源看的是两个数的组合，不是广告上的单一功率。</span>

```mermaid
flowchart TD
  EP["单脉冲能量"] --> DOSE["场剂量"]
  F["重复频率"] --> N["狭缝内脉冲数"]
  N --> DOSE
  F --> TPUT["扫描产能"]
```

<span class="marginnote">浸没头与工件台加速度限制扫描速度时，再升 $f$ 也灌不进更多脉冲——产能瓶颈会从激光挪到台。见后课工件台。</span>

## 机制

每个脉冲在胶里是一次曝光增量。CAR 积分这些增量；若脉冲间隔与淬灭/扩散时间尺度相近，理论上有脉冲结构效应，量产上通常仍当剂量积分。损伤：高 $E_p$ 打镜头镀膜与 CaF₂。

```mermaid
flowchart TD
  F["重复频率 f"] --> GAP["脉冲间隔 1/f"]
  GAP --> N["狭缝停留期内的脉冲数 N"]
  N --> SUM["胶积分 N 次增量"]
  SUM --> CD["脉冲抖动直通 CDU"]
  EP["提高 Ep"] --> SUM
  EP --> DMG["镀膜 / CaF2 损伤风险"]
```

<span class="marginnote">为什么重要：脉冲抖动若没被平均掉就原样进剂量。狭缝内脉冲数 $N$ 少时，剂量噪声约为单脉冲抖动除以 $\sqrt{N}$——$N=4$ 只把 1% 的抖动压到约 0.5%。扫描越快 $N$ 越小，对脉冲稳定度就越挑剔。</span>

## 小结

- 剂量看 $E_p\times N$，产能看 $f$ 与扫描。
- 脉冲抖动是剂量噪声，不是「平均功率不够」。
- 出处：剂量与产能课；准分子运行通识。
