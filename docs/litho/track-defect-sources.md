# 轨道缺陷来源

<div class="epigraph">
<p>扫描仪写潜像；轨道贡献颗粒、条纹、溅射和升华。缺陷检测要先问在哪一段机台。</p>
<footer>—— 对照 track defect 分类：涂胶条纹、显影溅射、热板升华、传送刮伤</footer>
</div>

[上一课](/litho/hotplate-uniformity)是热。缺口是颗粒与图案缺陷的**轨道源**，与 [浸没缺陷](/litho/immersion-defects)、掩模缺陷分开记账。本课分类，不写检测算法。

## 问题

[图形化检测](/litho/patterning-inspection-tools) 看见缺陷，不一定是曝光。涂胶条纹、气泡、 splatter、热板升华再沉积、机械手刮边、显影液干斑，都在 track。分错源会去调剂量或换掩模。

## 方法

按模块分账：涂胶杯（条纹、彗尾、 splatter）、热板（颗粒、升华）、显影碗（溅射、水印）、传送（刮伤、掉片边缘渣）。抽检：涂胶后、曝光前、显影后分步检测，才能定位。换胶与换杯清洗周期是缺陷率的一等参数。

```mermaid
flowchart TD
  COAT["涂胶杯"] --> D1["条纹 / 气泡"]
  HP["热板"] --> D2["升华再沉积"]
  DEV["显影"] --> D3["溅射 / 水印"]
  ROB["传送"] --> D4["刮伤"]
```

<span class="marginnote">胺污染是化学缺陷：CD 漂、不明欠曝。它走空气，不像颗粒走 SEM。监控要用化学传感器，不只缺陷机。</span>

## 机制

<span class="marginnote">卫星点可以类比甩干机甩水：旋涂把多余胶液甩出杯壁，高速气流再把液丝撕成小滴，回落的每一滴烘干后就是一颗点状缺陷——所以它偏向旋转下游方位，大小也和液滴谱一致。</span>

液滴在旋涂中被气流撕碎成卫星点；升华物在较冷盖上凝结再掉。显影溅射把未溶胶块打到邻区。机制不同，清洗配方不同。

<span class="marginnote">升华再沉积翻译成大白话：胶里的某些成分没等到烘干就直接变成气体飘走，撞上较冷的盖板又凝回固体，之后掉回晶圆成为颗粒。它与机械颗粒的区别在于「是工艺自己长出来的」，清洗盖板周期比换滤芯更对症。</span>

```mermaid
flowchart TD
  DROP["旋涂液滴"] --> TEAR["高速气流撕碎"]
  TEAR --> SAT["卫星点落回片上"]
  HOT["热板升温"] --> SUB["成分升华成气体"]
  SUB --> COND["较冷表面凝结"]
  COND --> REDEP["再沉积成颗粒"]
  DEV["显影喷淋"] --> SPL["溅起未溶胶块"]
  SPL --> NEI["落到邻近图形区"]
```

## 边界

下一课边缘曝光：有意用光清边，不是缺陷，但过曝会伤边缘器件。

## 小结

- 轨道缺陷按模块分账，分步检测定位。
- 不要默认缺陷来自扫描仪或掩模。
- 出处：track defect 工艺通识；检测课。

<span class="marginnote">常见误区：看见缺陷就调剂量或换掩模。轨道缺陷不随剂量变，也不跟着图形版图走——用分步检测看它在涂胶后、曝光前还是显影后冒出来，是定位源头的省时做法。</span>
