# X 射线与近场

<div class="epigraph">
<p>更短的波长在 1980–90 年代走过接近式 X 射线；掩模、间隙与源让它让位给延长寿命的 193 nm。近场则用倏逝波，焦深薄到几乎不是扫描机。</p>
<footer>—— 对照 X-ray lithography（IBM 等传统）与近场/倏逝光刻的公开历史</footer>
</div>

[上一课](/litho/interference-lithography)展示无透镜周期。缺口是短波接近式与倏逝。本课钉 X 射线与近场。封装尺度的激光直写，留给[下一课](/litho/laser-direct-write-packaging)。

## 问题

接近式 X 射线光刻：掩模贴近晶圆，用同步辐射或等离子源，分辨率好，工业上卡在掩模（吸收体、支架）、间隙控制、源与对准。193 浸没 + RET + 多重在成本上赢了，路线被放弃为逻辑主路径。近场/表面等离子体光刻：突破远场衍射，但工作距离纳米级，不适合晶圆扫描产能与形貌。

<span class="marginnote">「倏逝波」就是贴着结构表面、不向前传播的一层「贴地光」：强度随离开表面的距离指数衰减，几十纳米外几乎归零——所以近场光刻必须把基底贴到表面几十纳米以内，产线根本跑不了这个距离。</span>

缺口是**历史岔路**，不是再推瑞利去证明 X 射线「应该赢」。课程要记住：更短 λ 不是充分条件。

<span class="marginnote">常见误区：「波长更短就一定赢」。X 射线分辨率确实好，但产线要的是掩模、源、对准、颗粒容忍一整套都能量产——193 浸没靠在成熟投影光机上做加法，赢了整套推倒重建。</span>

### LIGA 与 MEMS

厚胶 X 射线在 MEMS/LIGA 仍有尼奇，对象是高 AR 金属结构，不是 CMOS 金属节距。后课 MEMS 会点到。

<span class="marginnote">EUV 是反射投影，不是 1990s 接近式 X 射线的复活。不要把两者混成「都是短波所以一样」。</span>

## 方法

读史：为何 157 nm 与 X 射线让位浸没。近场：实验室演示 vs 晶圆 wph 算术（工作距离、平整度）。评估替代技术时沿用同一算术。

```mermaid
flowchart TD
  Q["1980s：选下一代光刻路线"] --> X["接近式 X 射线"]
  Q --> DUV["193 nm + 浸没 + RET"]
  X --> B1["分辨率好，但掩模/间隙/源全要重建"]
  DUV --> B2["沿用投影光学与产业链，成本递进"]
  B1 --> W["退出逻辑主线，留 MEMS 尼奇"]
  B2 --> W2["成为量产主路"]
```

## 机制

接近式衍射与半影随间隙变；间隙要小，颗粒与形貌不可忍——pellicle 逻辑的反面。近场强度随距离指数衰减，台阶直接毁掉均匀性。投影光学把掩模放到远处共轭，正是为了躲这两者。

<span class="marginnote">数字实例：几何半影模糊约等于「间隙 × 源尺寸与源距之比」——间隙从 10 µm 放大到 40 µm，边缘模糊跟着变成四倍。这就是接近式曝光把间隙公差压到微米以下的算术来源。</span>

```mermaid
flowchart TD
  XR["接近式 X 射线"] --> MASK["掩模 / 间隙 / 源墙"]
  NF["近场倏逝"] --> GAP["工作距离墙"]
  PROJ["投影光学"] --> FAR["远场共轭 + 产能"]
```

## 边界

不宣布近场永远无用（存储、模板可能）。不把同步辐射当已死的科学。本课不重开 EUV 源物理。

后课默认：短波接近式不是先进 CMOS 主路；下一课波长更长、场更大的封装激光直写。

## 小结

- 接近式 X 射线卡在掩模、间隙与源，被 193 路径取代为逻辑主线。
- 近场破远场衍射，工作距离与形貌不适合扫描产线。
- EUV 投影 ≠ 接近式 X 射线。
- 出处：X-ray lithography 产业史；近场光刻实验室传统。
