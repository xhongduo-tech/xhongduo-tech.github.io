# 均光器与复眼

<div class="epigraph">
<p>激光近场并不均匀。复眼把光束切成子孔径再叠到光瞳上，均匀的是照明，不是把相干性抹成零。</p>
<footer>—— 对照照明均光 / fly's-eye integrator；[部分相干](/litho/partial-coherence)</footer>
</div>

[上一课](/litho/laser-gas-lifetime)停在激光出口。缺口是：出口光束有热点和椭圆，不能直接打掩模。本课钉均光器与复眼，接到 [离轴照明](/litho/off-axis-illumination)，不重做 σ。

## 问题

未均光的照明会把激光近场印到掩模上，CD 随狭缝位置变，像一台坏了的剂量机。均光要把空间均匀性做到百分比级，同时形成可调光瞳（环、偶极）。把均匀性写成「激光稳了就匀」，忽略积分器。

<span class="marginnote">常见误区：以为激光器功率稳了照明就自然均匀。实际上激光近场的热点和椭圆是光束结构性的问题，功率稳定消除不了它们；没有积分器，CD 会随狭缝位置漂移，晶圆上等于挨了一台坏掉的剂量机。</span>

## 方法

复眼（fly's-eye）：阵列透镜把入射切成许多通道，在后续光瞳面重叠。光棒（rod）积分是另一条路。下游可变光瞳（[FlexRay](/litho/flexray-pupil)）在已均光的场上整形。设计同时管：场均匀、光瞳填充、透过率。

<span class="marginnote">术语翻译：复眼（fly's-eye）就是一整排小透镜排成的阵列，像苍蝇的复眼把一束光切成几十个小通道，再让所有通道的像叠在同一处——单个通道里的不均匀在叠加时互相抵消。</span>

```mermaid
flowchart TD
  LAS["激光近场"] --> FE["复眼切分"]
  FE --> PUP["光瞳叠加"]
  PUP --> MASK["掩模面均匀照明"]
```

<span class="marginnote">通道数太少，均匀性有残纹；太多，透过率与对准公差变差。斑纹平均也依赖通道数与脉冲数。</span>

## 机制

每条通道带一部分空间相干结构。重叠后强度均匀，互相干不完全消失，所以 σ 与光瞳形状仍由后续光阑定义。这是 [空间相干](/litho/temporal-spatial-coherence) 在硬件上的实现，不是新的波动方程。

```mermaid
flowchart TD
  Q["强度匀了，相干性也归零了吗？"] --> A["通道 1：带自己的相干结构"]
  Q --> B["通道 2：结构位置不同"]
  Q --> C["通道 N：又一组独立斑点"]
  A --> D["同一光瞳面强度相加"]
  B --> D
  C --> D
  D --> E["叠加：强度均匀，起伏被平均"]
  D --> F["互相干未消失：σ 仍由光阑定义"]
```

<span class="marginnote">直觉类比：像把一杯有结块的可乐倒过几十个漏斗再汇进同一个杯子——每个漏斗里结块的位置不同，汇到一起总量就平了；但可乐还是可乐（相干性还在），并没有换成白水，所以 σ 还要靠后面的光阑来调。</span>

## 边界

下一课 REMA 刀片切的是已均光的场，不是激光腔。

## 小结

- 复眼把不均匀激光叠成均匀掩模照明，并预备光瞳。
- 均匀性与部分相干是两件事，不要互相替代。
- 出处：照明积分器通识；部分相干课。
