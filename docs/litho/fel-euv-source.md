## 问题

自由电子激光：相对论电子束在波荡器中辐射，波长可调，原则上高平均功率、窄带。吸引点：减轻锡碎片、提高功率天花板。墙：加速器规模与成本、运行、etendue 与扫描机照明匹配、时间结构（脉冲）与胶随机、厂内落地。LPP 已经与 NXE 集成、有学习曲线；FEL 是另一套设施型源。

```mermaid
flowchart LR
  EG["电子枪产生电子"] --> LINAC["直线加速器把电子提速到相对论速度"]
  LINAC --> UND["波荡器：交变磁场"]
  UND --> RAD["电子摆动并辐射相干光"]
  RAD --> MONO["光谱纯化得到窄带 13.5 nm"]
  MONO --> ILL["送入扫描机照明光学"]
```

这张图回答的问题是：FEL 怎么把「电」一步步变成扫描机能用的 13.5 nm 光。链条上任何一环（尤其是加速器规模和末端与照明光学的匹配）掉链子，源就交不了货。

<span class="marginnote">波荡器（undulator）就是一排磁极方向交替排列的磁铁：电子穿过时被磁场左右搓动，每摆一次甩出一小段光，这些光同相位叠加成相干辐射。波长由电子速度和磁铁周期共同决定，所以「调波长」其实是调电子能量——这也是 FEL 不必绑死在 13.5 nm 的原因。</span>

缺口是**源必须是可交货模块**，不是光谱更漂亮就赢。把 FEL 当「LPP 之后必然」，忽略加速器工业与扫描机光学合同。

### 与单一来源

FEL 若成功，可能改变源集中格局，但扫描机光学仍集中。供应链课的结构不会自动消失。

<span class="marginnote">同步辐射束线做过 EUV 研究曝光，那是实验站，不是 300 wph 工厂源。</span>

## 方法

评估：功率、dose 稳定性、etendue、占地、可用性、碎片。对照 LPP 的已知耗材（锡、collector）。研究项目可引用公开 FEL-EUV 设想，不把未建装置当量产。

<span class="marginnote">etendue 可以粗译成「光的体积守恒」：光源的大小乘以发光立体角，这个乘积在光学系统里不会变小。初学者容易以为源的功率高就行——实际上扫描机只收得下固定立体角内、固定大小的光，etendue 不匹配时多出来的光子根本进不了照明系统，功率数字再漂亮也白搭。</span>

## 机制

LPP 把激光能量耦合进锡等离子体；FEL 把电子束能量耦合进辐射。后者效率与束品质绑定，设施像光源实验室。扫描机要的是进入照明器的可用光子，不是源点的峰值亮度 alone。

<span class="marginnote">为什么时间结构重要：光刻胶响应的是落在单位面积上的累计光子数，但脉冲间隔太长时，每个「子脉冲」相当于一次独立的小曝光，散粒噪声导致的线宽随机会随之变化。换源不只是换功率等级，剂量控制的时间形状也要跟着重新设计。</span>

## 边界

不预测 FEL 取代年份。不发明装置功率数字。不贬低研究价值。

后课默认：量产源仍是 LPP 合同；下一课在投影光学与随机的物理极限上问 Hyper-NA 之后还剩什么。

## 小结

- FEL 是高功率 EUV 源概念，尚未替代已集成的锡 LPP。
- 墙在设施、etendue 匹配与交货，不只在波长。
- 研究束线 ≠ 工厂源。
- 出处：FEL-EUV 概念与 LPP 量产路径的公开讨论。
