# 减振与地基

<div class="epigraph">
<p>纳米套刻活在振动谱上。主动隔振把地脉动和泵声挡在台外，地基则决定厂里哪块地能放这台机器。</p>
<footer>—— 对照扫描机 isolation frame / 主动隔振公开描述</footer>
</div>

[上一课](/litho/alignment-mark-design)把标记画完。缺口是环境力学：地脉动、空调、真空泵、邻机扫描反作用。本课钉减振与地基，台加速度下一课。

## 问题

套刻 nm 对应台相对位移 nm。楼板模态若落在伺服带宽附近，闭环会放大。把残差全写成编码器，会去调错环。

## 方法

被动橡胶/气垫加主动惯性传感器反馈。机器要独立惯性块或指定地基刚度。厂务：邻近打桩、AGV 通道都进振动预算。验收用频谱，不只用「感觉不抖」。

<span class="marginnote">常见误区：验收时「站上去感觉不抖」不等于合格。套刻关心的是纳米级相对位移，很多有害扰动人根本感觉不到，必须看频谱和传递函数，而不是靠体感。</span>

<span class="marginnote">隔振可以类比给机器垫一层很软的弹簧床垫：地面晃得再欢，垫子上的人只跟着慢慢起伏；但床垫自己也有固有节奏，地面若恰好按这个节奏晃，反而越颠越高——这就是楼板模态必须避开的原因。</span>

```mermaid
flowchart TD
  GND["地脉动"] --> ISO["隔振"]
  PUMP["泵 / 空调"] --> ISO
  ISO --> STAGE["工件台伺服"]
```

<span class="marginnote">浸没头流体力是机内扰动，隔振挡不住，要靠台伺服与流体设计。分内外源。</span>

## 机制

隔振传递函数在低频硬、高频软；主动环补中间带。过隔振会让台「飘」，与对准捕捉冲突，要折中。

<span class="marginnote">数字直觉：设隔振固有频率约 1 Hz，高于它的扰动，传递率大致按频率比的平方往下掉——10 Hz 的泵声被衰减约百倍，而 1 Hz 附近不降反升。「低频硬、高频软」说的就是这条曲线的形状。</span>

```mermaid
flowchart TD
  F["扰动频率落在哪个带"] --> A["远低于隔振固有频率"]
  F --> B["主动环带宽内"]
  F --> C["高于隔振固有频率"]
  A --> RA["近刚性直接传递，靠地基刚度兜"]
  B --> RB["闭环可压，带宽附近增益抬峰反被放大"]
  C --> RC["气垫衰减，扰动被挡"]
  RB --> D["楼板模态要避开伺服带宽"]
```

## 小结

- 减振把厂频谱从套刻预算里抠掉一块。
- 验收看传递函数，不只看静标。
- 出处：扫描机 isolation 通识；套刻课。
