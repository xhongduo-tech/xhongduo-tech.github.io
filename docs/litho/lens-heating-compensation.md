# 透镜加热与补偿

<div class="epigraph">
<p>玻璃吃掉的那一小截 193 nm 变成热。折射率与面形随温度场变，像差跟着扫描历史走，不是一场一个常数。</p>
<footer>—— 对照投影物镜 lens heating 补偿的公开描述；[Zernike](/litho/zernike-aberrations)</footer>
</div>

[上一课](/litho/catadioptric-lens-design)给出冷态设计。缺口是运行：吸收 → 温度场 → $n(T)$ 与面形 → 波前。本课钉加热与补偿，不重写 Zernike 定义。

## 问题

透过率不是 100%。狭缝里的功率密度随光瞳与掩模透过率变，热场是「这场图形」的函数。刚开机与连扫一小时的像差不同。把套刻/CD 漂移全写成工件台，会漏掉镜头热时间常数（秒到十分钟）。

<span class="marginnote">数字实例：玻璃吸收哪怕只有百分之一二，狭缝里数百瓦照明也意味着瓦级热量持续注入。熔石英 $dn/dT$ 约 $10^{-5}$ /K，10 cm 玻璃的温场只要差 3 mK，光程就差约 $10^{-5}\times3\times10^{-3}\times10\,\text{cm}=3$ nm——纳米级波前预算就这样被吃掉。</span>

## 方法

模型：若干 Zernike 的加热系数 × 估计功率（剂量、光瞳、掩模开放率）。执行器：后课操纵器、调焦、波长微调。生产：idle 曝光或补偿表随 lot 更新。换高透过掩模等于换热负载。

```mermaid
flowchart TD
  ABS["玻璃吸收"] --> T["温度场"]
  T --> W["波前 / Zernike"]
  W --> CMP["补偿表 + 操纵器"]
```

<span class="marginnote">补偿是前馈为主：用即将曝光的场预测热，而不是等 CD 坏了再反馈。传感器在镜头里有限，模型误差会变成系统残差。</span>

## 机制

$dn/dT$ 与热膨胀改光程。非均匀热场激发球差、像散等轴对称或扫描向模态。时间上像一个低通：脉冲级看不見，场间与 lot 间看见。

<span class="marginnote">直觉类比：镜头热像一台低通滤波器——脉冲级的快抖动被热惯性滤掉，分钟级的场间漂移却原样通过。所以单发曝光看不出加热，连扫半小时的场间 CD 漂移才是它的脸。</span>

<span class="marginnote">常见误区：把连扫后的 CD/套刻漂移记到工件台或胶头上。镜头热像差随「刚才扫过什么图形」变——换一张高透过掩模，热负载立刻不同。这是图形相关的慢漂，台子不背这锅。</span>

```mermaid
flowchart TD
  LOAD["这一场的热负载"] --> PUP["光瞳内功率分布"]
  PUP --> MODE["激发哪些 Zernike 模态"]
  MODE --> SYM["球差 / 像散 / 焦漂"]
  TC["热时间常数 = 低通"] --> SYM
  SYM --> FF["前馈补偿表按场更新"]
```

## 边界

下一课操纵器是执行器细节。致密化（compaction）是剂量积分的永久损伤，不是可逆加热，再后一课。

## 小结

- 镜头热像差随图形与历史变，要前馈补偿。
- 时间常数在场–lot 之间，不在单个脉冲。
- 出处：lens heating 公开实践；Zernike 课。
