# ArF 准分子激光器

<div class="epigraph">
<p>193 nm 量产光来自 ArF 准分子放电，不是汞灯的 i 线尾巴。脉冲、气体和腔镜是剂量与带宽的上游。</p>
<footer>—— 对照 Cymer / Gigaphoton 公开的 ArF 准分子光源；波长台阶见 [litho-wavelengths](/litho/litho-wavelengths)</footer>
</div>

[上一课](/litho/complementary-euv)收在互补式 EUV：几何仍是 1D+cut，切孔的剂量与随机往往比长直线更苛刻。DUV 主干与胶、轨道补层到此；缺口转到**曝光机里面谁发光**。本课是「曝光机子系统」第一课：ArF 准分子激光器。不重推 [瑞利判据](/litho/rayleigh-litho)，也不把浸没水膜再讲一遍——[ArF 浸没](/litho/arf-immersion) 假定光源已经是 193 nm。后课带宽、脉冲能量、气体寿命都默认本课的放电结构。

## 问题

主干把 193 nm 写成波长台阶上的一个点。机台里它是稀有气体卤化物放电：氩与氟在高压脉冲下形成 ArF*，退激发出约 193.3 nm。汞灯连续谱滤不出这条线的亮度与窄带；准分子是脉冲、高峰值、可压窄的。缺口是把「193 nm」落到腔、放电和为什么后课要谈线宽。

<span class="marginnote">术语翻译：准分子（excimer）= excited dimer，『激发态的二聚体』——只存在于激发态的短命分子。ArF* 里的星号就代表激发态；它退激发时把能量以约 193 nm 的光子吐出来。</span>

<span class="marginnote">KrF 248 nm 是另一台准分子（KrF*），不是把 ArF 换滤光片。气体、镀膜、光路材料整套换。本课只钉 ArF 浸没量产这一条。</span>

## 方法

振荡级加放大级（MOPA 或同类主振–功放）是公开架构：振荡级出窄带种子，放大级出功率。光束再进照明均光。剂量按脉冲计数 × 单脉冲能量；重复频率进 [扫描仪产能](/litho/scanner-throughput)。本课不写具体 kHz 广告值当物理常数。

<span class="marginnote">把『剂量按脉冲计数』换成具体数：若单脉冲在像面贡献 10 mJ/cm²、胶要 30 mJ/cm²，同一处就要叠约 3 个脉冲；重复频率与扫描速度若失配，同一处多收一个脉冲，CD 立刻偏一截。</span>

```mermaid
flowchart TD
  DIS["ArF 放电"] --> SEED["窄带振荡"]
  SEED --> AMP["放大"]
  AMP --> ILL["照明 / 均光"]
```

## 机制

准分子寿命短，不能当连续波腔慢慢建场，必须脉冲放电。光谱天然比需要的成像带宽宽，所以下一课必须压窄，否则色差与焦深被吃掉。氟腐蚀光学件，气体寿命是运行成本，再后一课。

```mermaid
flowchart TD
  EX["ArF* 寿命 纳秒级"] --> PULSE["只能脉冲放电 不能连续建场"]
  PULSE --> CNT["剂量 = 脉冲数 × 单脉冲能量"]
  CNT --> SYNC["重复频率与扫描同步"]
  SYNC --> DRIFT["能量漂移 → CD 漂 → 能量反馈"]
  PULSE --> BW["光谱天然偏宽 → 下一课压窄"]
```

<span class="marginnote">常见误区：把激光器当『通电就亮的灯』。ArF* 寿命只有纳秒量级，来不及在腔里慢慢建连续振荡，只能每放电打一发脉冲——脉冲性是分子寿命逼出来的物理，不是工程偏好。</span>

## 边界

本课不写 EUV 锡滴 LPP——那是另一条波长的光源课。下一课只谈线宽压窄，不改放电化学。

## 小结

- 193 nm 量产光是 ArF 准分子脉冲，不是灯。
- 功率与光谱分属放大与压窄，后课拆开。
- 出处：准分子光源公开架构；波长台阶课。
