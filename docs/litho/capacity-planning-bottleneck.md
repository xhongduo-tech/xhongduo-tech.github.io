# 产能规划与瓶颈

<div class="epigraph">
<p>厂的月产能由最慢的那类约束机台决定；EUV、光化掩模检验和 e-beam 检测常常比浸没扫描机更先成为瓶颈。</p>
<footer>—— 对照 fab capacity planning 与约束理论在光刻区的应用通称</footer>
</div>

[上一课](/litho/tool-price-depreciation)给出小时成本。缺口是台数。本课钉产能规划与瓶颈。把扫描机采购放进整厂资本开支，留给[下一课](/litho/fab-capex)。

## 问题

需求：晶圆数 × 每片 EUV 层过机 × 1/有效 wph × 1/可用性 ≈ EUV 台数。浸没同理但层数更多。瓶颈可能在：EUV、轨道、刻蚀、掩模写入、AIMS、e-beam 检测、计量。加一台非瓶颈机不增加产出。多重图形把浸没与刻蚀同时变成瓶颈对。

<span class="marginnote">数字实例：月产 5 万片、每片 8 层 EUV 过机、有效 150 片/小时、可用性 80%——需求机时 = 50000×8÷(150×0.8) ≈ 3333 小时/月；一台每月可用约 576 小时，所以仅 EUV 就要 6 台起步。Mix 一变，这个数马上重算。</span>

缺口是**约束识别**，不是买最贵的机。把产能当「有几台 EUV」，会忽略掩模厂与检测。

### Mix 是一等变量

产品组合改 EUV 层数与开口率（刻蚀负荷），瓶颈会移动。规划必须用 mix 场景，不能用单一英雄产品。

<span class="marginnote">重工是对瓶颈的隐性需求。高重工率等于少买了几台扫描机。</span>

## 方法

建资源表：各机类小时需求 vs 供给。缓冲：维护、新品学习、掩模延迟。与交叉课：迁一层到 EUV 是把需求从浸没/刻蚀挪到 EUV/掩模。与学习曲线：爬坡期检测需求峰值。

<span class="marginnote">术语翻译：「WIP」就是还在线上、没完工的晶圆堆。WIP 越多，每片在厂时间越长，被搬运和触碰的机会越多，二次缺陷与返工跟着涨——所以「控制队列」本身就是产能管理的一部分，不只是买机器。</span>

```mermaid
flowchart TD
  M["列出 Mix 场景"] --> RT["建资源表：各机类需求 vs 供给"]
  RT --> Q{"哪类机台利用率顶到上限？"}
  Q -- "是" --> BN["该机类是瓶颈：加机/外协/重排层"]
  Q -- "否" --> NB["非瓶颈：利用率再高也只堆 WIP"]
  BN --> BUF["留缓冲：维护、爬坡、掩模延迟"]
  NB --> BUF
```

## 机制

约束理论：产出由瓶颈决定，非瓶颈的利用率高只是在堆 WIP。光刻区 WIP 增加周期与二次缺陷机会。因此规划不仅是买机器，还是控制队列。

<span class="marginnote">直觉类比：瓶颈像四车道里唯一剩下的单车道桥——在桥前后再加车道，车只会更堵在桥头；有效的只有拓宽桥本身（加瓶颈机台）或让一部分车绕行（重排 mix、外协）。非瓶颈机台闲置不是浪费，排队才是。</span>

```mermaid
flowchart TD
  DEM["晶圆 × 层 × 过机"] --> NEED["机时需求"]
  NEED --> BN["瓶颈资源"]
  BN --> OUT["月产出"]
  REW["重工"] --> NEED
```

## 边界

不预测某厂台数。不把理论 wph 当供给。规划不含劳动力细节。

后课默认：产出由瓶颈机类决定；下一课这些机台的买价如何堆成 fab capex。

## 小结

- 产能由瓶颈资源决定；EUV、掩模检验、e-beam 常入围。
- Mix 与重工移动瓶颈。
- 非瓶颈加机只堆 WIP。
- 出处：fab capacity 与约束理论通称。
