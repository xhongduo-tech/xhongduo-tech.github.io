我是徐鸿铎，软件工程师。这个站点不是按日期堆词条的博客，而是把五条学习路径收成知识树：每一课接上一课留下的缺口，后课默认已经读完先修。

读法按深度优先：课程 → 单元 → 课序 → 课。同一课序内严格递进；课序的第一课接上一课序的最后一课；课程的第一课接上一课程的最后一课。加深课插在对应基础课之后，不整块堆在末尾。论文、型号、审计与前沿放在附录，不插入主干。五栏互不吞并——大模型写 Transformer 与训练推理，量化写金融微观结构与定价，金融接到限价簿为止，光刻写成像与产线，计算机写从比特到系统栈。
