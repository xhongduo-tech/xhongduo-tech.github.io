# 正弦位置编码

<div class="epigraph">
<p>用一组几何级数频率上的正弦和余弦，把下标写成没有参数的坐标。</p>
<footer>Vaswani 等，Attention Is All You Need，2017</footer>
</div>

Vaswani 等人不用位置表，而用一组几何级数频率上的正弦与余弦，把下标写成没有参数的曲线。公式对任意 $pos$ 有定义，并附带一个线性代数命题：相对位移对应编码空间里与起点无关的线性映射。后来的外推实验表明，「有定义」和「训练过的相位」不是一回事。本篇只展开这套 2017 年的公式，以及它作为绝对编码的限度。

## 问题

Transformer 需要位置，又不希望位置表随 $L_{\max}$ 引入大量参数，更希望任意长度在公式上「有定义」。Vaswani 等给出的方案是固定的正弦位置编码：每个下标 $pos$ 映射到一组 $\sin/\cos$，频率按维度呈几何级数。没有嵌入表，没有随长度增长的参数，理论上 $pos$ 可以取任意正整数。

问题于是从「位置怎么学」变成「这组函数是否把相对位移暴露给线性注意力」。论文给出一个线性代数上的希望：存在与 $pos$ 无关的线性变换，能把 $PE_{pos}$ 映到 $PE_{pos+k}$。若注意力能利用这个结构，模型就可以在绝对公式里读出相对距离。本篇只讨论这套公式本身：它如何构造、希望在哪里、以及它作为绝对编码为何仍然外推失败。

<span class="marginnote">正弦 PE 是绝对的：向量仍由单个下标生成，不是由 $(i-j)$ 生成。相对性只是一个关于线性映射的命题。</span>

### 要一条对任意长度有定义的曲线

可学习表在 $L_{\max}$ 处截断。若目标是机器翻译里偶发的更长句，表必须提前开得足够大，或测试时截断。正弦曲线没有截断点，这是它被选中的工程动机之一，独立于后来是否真的能外推。

## 方法

对维度 $d_{\mathrm{model}}$ 的偶数下标，定义

$$
PE_{(pos,\,2i)} = \sin\bigl(pos / 10000^{2i/d}\bigr),\qquad
PE_{(pos,\,2i+1)} = \cos\bigl(pos / 10000^{2i/d}\bigr),
$$

其中 $i = 0, \ldots, d/2-1$，$d = d_{\mathrm{model}}$。基数 $10000$ 把最低频的周期拉到大约 $2\pi \times 10000$ 个位置，最高频接近每个位置一个弧度。相邻维度构成一对 $(\sin \theta, \cos \theta)$，等价于平面上的一个点，角度 $\theta = pos \cdot \omega_i$，$\omega_i = 10000^{-2i/d}$。

编码与 token 嵌入相加后进入第一层。公式在训练中不更新——这是「编码」而不是「嵌入」的本意。整张模型对位置的利用，完全来自后续线性层与注意力如何读这组固定坐标。

### 几何级数而不是线性频率

若频率均匀排布，相邻位置在所有维度上的相位差接近，表示会高度相关。几何级数让不同维度对应差几个数量级的周期：低维变化慢，编码粗粒度的位置；高维变化快，编码局部次序。这与傅里叶特征、与后来 RoPE 的频率谱是同一类构造，差别在用法：正弦 PE 把 $(\sin,\cos)$ **加到内容上**；RoPE 用同样的角度去**旋转** QK。

## 机制

### 相对位移的线性论证

固定 $k$，考虑平面 $i$ 上从角度 $pos\cdot\omega_i$ 转到 $(pos+k)\cdot\omega_i$。二维旋转矩阵

$$
R(k\omega_i) = \begin{pmatrix} \cos k\omega_i & -\sin k\omega_i \\ \sin k\omega_i & \cos k\omega_i \end{pmatrix}
$$

满足 $R(k\omega_i)\, PE^{i}_{pos} = PE^{i}_{pos+k}$。块对角地拼起来，就存在与 $pos$ 无关的线性映射 $T_k$，使得 $T_k\, PE_{pos} = PE_{pos+k}$。这是 Vaswani 等写下正弦（而不是随机绝对向量）的理论理由：相对位移对应位置编码空间里的同一线性变换。

注意力并不直接乘 $T_k$。它乘的是学出来的 $W_Q, W_K$。论证给出的是**表示里存在相对几何**，不是优化会把它当成相对位置来用。实践中模型可以把正弦当绝对名字用，忽略 $T_k$。

<span class="marginnote">$10000$ 与 $d$ 一起决定频谱。改基数等于改「第几维对应多长的周期」，与 RoPE 改 base 是同一旋钮，作用点不同。</span>

### 外推承诺落在绝对契约上

公式对 $pos > L_{\mathrm{train}}$ 有定义，不等于模型见过对应的相位组合。高频维在训练长度内可能已经转过多圈，低频维在超长 $pos$ 上才进入新的区间。Press 等的短训长测里，正弦绝对 PE 与可学习绝对表一样，在超出训练长度后崩溃。有定义的曲线没有带来可用的长度外推。失败应记在「绝对相加」上，而不是记在 $\sin$ 函数上——后来 RoPE 用旋转而不是相加，同一类频率可以工作得完全不同。

## 边界与工程取舍

正弦 PE 的优点：零位置参数、实现极简、与深度解耦、对固定长度任务足够。缺点：作为绝对编码，长度一变就要面对未训练相位；与内容相加会污染语义通道，位置与词向量抢同一组维度；没有门控，无法按层或按头关闭位置。

工程上，2017 年的 $10000$ 是启发式，不是最优周期。翻译任务的长度分布集中，频谱够用。把它原样搬到四千、三万上下文的 Decoder 上，低频维几乎不转、高频维转得过密，都可能发生。调基数会改善频谱覆盖，但调的仍是绝对曲线，不能把它变成相对注意力。要相对几何，需要改注入方式（偏置、旋转），而不是只改 $10000$。

<span class="marginnote">不要把正弦 PE 与 RoPE 写成「都是 sin/cos」。一个加在嵌入上，一个乘在 QK 的二维平面上；外推行为因此分叉。</span>

与可学习表相比，正弦少参数、多归纳偏置。在训练长度内，可学习表往往拟合得稍好，因为可以吸收数据里非傅里叶的位置统计。在需要任意 $pos$ 有定义时，正弦是绝对方案里唯一不改表形状的选择——尽管「有定义」不等于「能外推」。机器翻译那种长度分布窄、偶发超长句需要公式兜底的场景，正弦的原始动机仍然成立；百万上下文的 Decoder 已不是那个场景。

## 小结

正弦位置编码（Vaswani 等，2017）用 $\sin(pos\cdot\omega_i)$ 与 $\cos(pos\cdot\omega_i)$、$\omega_i = 10000^{-2i/d}$ 把下标写成无参数的绝对坐标，并证明相对位移对应编码空间中的固定线性映射。它解决的是「位置公式化、不占表」，没有解决绝对坐标的长度外推。Press 等后来的实验把这一点测死。理解后续 RoPE 时，应把正弦当作同一频谱的**相加版祖先**，而不是已经相对化的位置方案。基数 $10000$ 是这条曲线的默认尺子，不是外推开关。
