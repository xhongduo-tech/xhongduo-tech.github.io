# 空间智能：感知、推理、在三维中行动

<div class="epigraph">
<p>空间智能把看见变成去做，把感知变成推理，把想象变成创造。</p>
<footer>—— World Labs 对空间智能的纲领表述</footer>
</div>

李飞飞与 World Labs 把下一代人工智能的主线写成空间智能：系统要能在三维世界里感知、推理，并据此行动——虚拟的或物理的。这与「把一段提示渲染成好看的二维视频」不是同一句话。视频模型可以在像素时间轴上采样下一帧，却不必承诺物体在相机转过去之后仍然占据同一位置，也不必让智能体在其中规划一条可执行的轨迹。空间智能要求表示对几何、占据和关系负责，使感知结果能进入推理，推理结果能进入行动。本篇只澄清这条纲领：三维里的感知、推理与行动各指什么，以及为何不能把它收缩成二维生成的口号。

## 问题

大规模语言模型把符号序列上的预测做成了通用接口。视觉侧近年的生成模型把「下一帧、下一像素块」做成了同样好用的接口。两者都很强，但默认工作空间是一维 token 或二维像素网格。人与机器人所处的工作空间是三维的：遮挡后面仍有物体，力沿接触传递，路径必须绕过占据。若智能只停在生成一张好看的图，系统可以「看见」却无法「在其中做事」。

空间智能要补的缺口可以写成三个动词。感知：从像素、深度、触觉或语言中恢复场景里有什么、在哪里、如何朝向。推理：在恢复出的空间关系上做预测与规划——这条走廊通不通、杯子在桌沿会不会掉、相机再右移十度会看见什么。行动：把推理落到控制或编辑上，无论是机械臂、游戏角色，还是创作者在场景里移动物体。缺任何一环，剩下的就仍是看图说话或看图生视频。

### 口号与可检验能力

「世界模型」一词近年被用得很宽，有时只表示「视频看起来像真的」。空间智能给出更硬的判据：表示是否在三维中可查询，查询结果是否能支撑决策。可查询不必等于导出三角网格，但必须让「同一物体在不同时刻、不同视角」是同一实体，而不是每次重新发明的纹理。World Labs 把自己写成空间智能公司，产品线（生成可漫游的三维世界、实时出帧、后续的全能世界模型）都挂在这条判据上，而不是挂在「视频更长、分辨率更高」这一维竞赛。

<span class="marginnote">二维视频可以非常「三维看起来对」：透视、遮挡、光影都像。那是投影一致性，不是空间智能本身。一旦允许相机或智能体离开训练过的轨迹，没有三维承诺的模型会形变、遗忘或改写已经看过的角落。</span>

## 方法

把三个动词落到可实现的接口上。感知接口输出的是带空间坐标的观测：图像要绑到位姿，深度要绑到射线，物体要有可跟踪的身份。推理接口消费这些观测，估计未看见的部分、未来的运动和可行动作的后果。行动接口把估计变成执行：在仿真里施加力，在生成世界里编辑几何，在机器人上发出关节指令。世界模型是把三接口连在同一套表示上的系统，而不是三个互不通信的专用网络。

形式上一组观测 $\mathcal{O}=\{(I_i, T_i)\}$（图像与相机位姿）应支撑一个可查询的世界状态 $W$，使得新位姿 $T_\ast$ 上的预测

$$
\hat{I}(T_\ast)=R(W, T_\ast)
$$

与真实或可接受的渲染一致，并且存在规划算子 $\pi$，在 $W$ 上选择行动 $a$，使世界按动力学更新。空间智能强调 $W$ 与 $\pi$ 都存在，而不是只存在 $R$ 的像素采样器。生成式世界产品把 $W$ 做成可导出的三维资产；实时帧模型把 $W$ 隐式留在带位姿的记忆里——那是实现差异，纲领要求的仍是三维中的可查询性。

```mermaid

  OBS["观测 像素/深度/语言"] --> PER["感知 恢复三维状态"]
  PER --> REA["推理 关系 预测 规划"]
  REA --> ACT["行动 控制或编辑"]
  ACT --> WLD["三维世界"]
  WLD --> OBS
```

### 与语言智能的分工

语言智能处理的是可写下来的命题。空间智能处理的是必须占地方的实体。二者交叉：语言可以命名「左边那把椅子」，但「左边」只有在当前坐标系里才有真值。World Labs 的表述把感知推进到推理、把想象推进到创造，指的是这条交叉：没有空间底座，语言对物理世界的指称是空的；没有语言与语义，纯几何也难以支撑有目标的行动。纲领并不要求先有完美网格再谈智能，而要求任何生成或理解过程最终能在三维里被问责。

<span class="marginnote">把空间智能说成「再做一个更大的视频扩散模型」会漏掉行动。视频模型的损失函数通常不惩罚「智能体走过去之后门还在不在」。机器人与仿真关心的恰恰是后者。</span>

## 机制

感知在三维中成立，依赖于观测与位姿一起进入同一上下文。缺位姿的视频是一条像素流，模型只能学到时间相关，学不到「这是同一房间的另一次注视」。把相机当作一等输入，感知才从「描述画面」变成「登记到空间」。推理则是在登记之后做未观测推断：墙后、未来、反事实。它可以用几何约束，也可以用从数据里学到的物理先验，但查询的对象应是世界状态，而不是某一帧的隐向量碰巧长得像。

行动把梯度或策略接到状态上。创作者的行动是编辑与漫游；机器人的行动是力矩与开合。两者都要求世界在行动后仍然是同一世界，只是局部改变。这与一次性出片不同：出片可以每条镜头重新采样，行动必须在同一实例上累积效果。空间智能把「实例同一性」当成机制，而不是事后用人工剪辑去圆。

### 为何二维生成不够

设生成模型学习 $p(I_{t+1}\mid I_{\le t})$。它可以对齐训练视频的观感，却不保证存在流形 $W$ 使各 $I_t$ 都是 $W$ 的投影。没有 $W$，谈不上在其中规划。即使加入光流或深度作为辅助头，若它们只服务于更好的下一帧，行动所需的占据与碰撞仍可能是假的。纲领因此把三维行动写成目标，而不是把更高的视频指标写成目标。更高的视频指标可以是感知的副产品，不能代替行动接口。

<span class="marginnote">李飞飞把空间智能写成认知的脚手架：被动观察与主动创造、抽象推理与环境交互都靠它。机器若只有语言没有空间，就缺了这块脚手架；若只有视频生成没有行动，脚手架只搭了半边。</span>

## 边界与工程取舍

纲领不是一张产品清单。今天能交付的生成式三维世界，主要覆盖感知与生成式「想象」；高保真物理仿真与闭环机器人行动仍是中期议程。把现状说成已经具备完整空间智能，会把演示里的可漫游与真正的可规划混为一谈。可漫游证明表示允许新视角，可规划还要求动力学与目标函数。

工程上有两条常见的收缩。一条是只用二维生成冒充三维智能：交互时每一帧都在改写历史，用户以为在「一个世界」里走，实际在看一段永不结束的幻觉视频。另一条是只用静态网格冒充智能：几何持久，但没有对未观测的推理，也没有行动后果。World Labs 同时做可导出的持久世界和实时出帧，本身就说明两条实现都朝三维可查询靠拢，只是把显式几何和隐式记忆分成不同产品。选型时应问：我要的是可下载的资产，还是可交互的帧；不要问「哪一个才算空间智能」——空间智能是能力目标，产品是逼近它的装置。

科学应用被放在更长的时间线上：理解真实世界的几何与动力学，而不是先服务娱乐。这不降低纲领的强度，只说明评测不能只看生成观感。能在三维中感知、推理并行动的系统，最终应在机器人、科学可视化与人机协作里被检验，而不是只在社交媒体的镜头里被检验。

## 小结

- 空间智能是在三维中感知、推理并行动，不是把二维视频生成说成世界模型。
- 感知要登记到空间，推理要在世界状态上做未观测与后果估计，行动要在同一实例上累积。
- 可查询的世界状态 $W$ 是三个动词的共同对象；只有下一帧采样器不够。
- 语言智能与空间智能分工：命题对不占地方的关系负责，空间对占地方的实体负责。
- 当前产品多覆盖漫游与生成，完整仿真与机器人闭环仍是议程而非已经交付的定义。
