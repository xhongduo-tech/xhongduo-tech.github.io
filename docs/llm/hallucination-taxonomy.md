# 幻觉分类

<div class="epigraph">
<p>不是所有假话都是一类病。事实编造、错误引用、无根据的推理，对应不同的持有集和不同的训练补丁。</p>
<footer>—— 对照 Ji 等幻觉综述的分类习惯；事实轴见 [SimpleQA](/llm/simpleqa-freshqa)</footer>
</div>

[上一课](/llm/faithful-cot)把「说得像推理」从「算得对」里拆开。本课把**假内容**再拆开：幻觉分类。主干已有诚实与引用课；缺口是产品上把一切错误叫幻觉，导致检索、拒答、解码温度被当成同一味药。

## 问题

[虚构引用](/llm/honesty-citations) 是幻觉的一种：有来源形态、无来源事实。另一些是封闭书知识错误、过时知识、工具返回被改写、以及推理链上的非法步骤。若只用「幻觉率」一个数，RAG 系统会与纯参数模型比错对象：前者的错更常是检索未命中后的脑补，后者是记忆与校准。

<span class="marginnote">术语翻译：RAG（检索增强生成）就是「答题前先去资料库翻一页，把翻到的内容贴进上下文再作答」。它的错误因此分两段——没翻到（检索未命中）和翻到了却自己脑补（生成不忠）；混进一个「幻觉率」里就治不了。</span>

本课钉三类，后课弃权只处理「知道自己不知道」那一类。

## 方法

三类。**事实幻觉**：可核验命题为假。**归因幻觉**：命题或许可真，但引用、页码、链接是编的。**忠实性幻觉**（对源文本）：摘要/RAG 中添加源里没有的约束。评测必须分列：封闭书 QA、引用可解析率、忠实度（源约束）。不要把数学算错算进事实幻觉——那是推理错误，走可验证奖励。

<span class="marginnote">归因幻觉的典型样子：结论「Transformer 是 2017 年提出的」没错，配的引用却是「Vaswani et al., 2019，第 42 页」——年份页码全是编的。模型学到的是「学术论文都带引用」这个形态，而不是去核实那条引用本身。</span>

<span class="marginnote">「幻觉」在临床是感知，在 LLM 是生成。词已经用滥。写报告时宁可写「封闭书错误 / 归因错误 / 对源不忠」，把幻觉留作口头统称。</span>

```mermaid
flowchart TD
  ERR["错误生成"] --> F["事实：命题假"]
  ERR --> A["归因：引用假"]
  ERR --> S["对源不忠"]
  ERR --> R["推理非法步骤"]
```

## 机制

事实错误来自参数里的错误相关与过自信解码。归因错误来自「学术文风」先验：人类文本常带引用形态，语言模型会补全形态。对源不忠来自上下文与参数记忆的混合——[长上下文是否取代 RAG](/llm/long-context-vs-rag) 没有取消混合，只是把源放进窗口。分类的用处是选补丁：事实走检索与校准，归因走强制引用解析，对源走抽取约束。

每一类对应各自的补丁，互不通用：

```mermaid
flowchart LR
  F["事实幻觉: 命题为假"] --> P1["检索 + 校准 / 拒答"]
  A["归因幻觉: 引用编造"] --> P2["强制引用可解析、逐条核验"]
  S["对源不忠: 添加源外内容"] --> P3["抽取式约束，只准抄源"]
  R["推理非法步骤"] --> P4["可验证奖励 / 逐步检查"]
```

## 边界

本课不给越狱式「诱导编造」的提示。下一课弃权是事实轴上的动作，不是归因解析器。版权与记忆化是另一条法律/提取轴，再后一课才写。

<span class="marginnote">为什么分类值得较真：把归因幻觉当事实幻觉治，会拼命加检索——可引用是模型自己编的，翻多少资料都没用。先判类、再选补丁，才不会把三个病塞给同一个温度旋钮。</span>

## 小结

- 幻觉要分事实、归因、对源不忠；推理错误单列。
- 单指标幻觉率会让 RAG 与闭书模型比错。
- 补丁按类选，不共用一个温度旋钮。
- 出处：幻觉综述的分类习惯；SimpleQA / 引用课。
