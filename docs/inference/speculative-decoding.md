# 投机解码的正确性与代价

::: info 专题提纲
研究与实验尚未完成。本页定义问题、资料和验收，不声称已有个人实测结果。

## 要解决的问题

投机解码把草稿生成与目标模型验证分开。研究时需要同时检查概率正确性与运行代价：正确实现的接受和校正可以保持目标采样分布，但不等于固定种子下每次得到完全相同的文本。[原始论文](https://arxiv.org/abs/2211.17192)

## 阅读与实验顺序

1. 明确自回归采样分布与草稿分布。
2. 用一个很小的词表实现接受、拒绝与校正，比较理论概率和采样频率。
3. 改变草稿质量和验证长度，观察接受长度及额外计算。
4. 有匹配模型与硬件时，再分别测草稿、验证、延迟与吞吐。

CPU小词表实验属于机制验证，不能作为真实模型吞吐复现。速度结论需要记录实际模型、批量、硬件和测量条件。
