## 关于这棵树

全人类知识按领域划分为 **13 棵知识树**：哲学、数学、物理、化学、生命科学、地球与空间科学、计算机与 AI、工程技术、医学与健康、农学、社会科学、人文与艺术、交叉与前沿。每棵从 **基础 → 核心 → 进阶 → 专业 → 前沿** 逐级展开。

- **博文（技术专题）**：我的技术研究，可点击进入对应博文专题（以「博文」标注）。
- **知识条目（非技术专题）**：哲学、人文、社科、医学、农学等领域，作为知识树结构完整保留，点击进入对应专题页。
- **引用**：跨树重合的学科以「引用」呈现，不重复建专题。

这棵树是全人类知识的**完整界面**：技术领域的博文挂在对应节点上；非技术领域的内容同样在这里完整呈现，可通过右上角「我的技术研究 / 全人类知识」切换视角，只查看我的技术博文。
