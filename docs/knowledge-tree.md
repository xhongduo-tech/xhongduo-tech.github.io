## 关于这棵树

全人类知识按领域划分为 **13 棵知识树**：哲学、数学、物理、化学、生命科学、地球与空间科学、计算机与 AI、工程技术、医学与健康、农学、社会科学、人文与艺术、交叉与前沿。每棵从 **基础 → 核心 → 进阶 → 专业 → 前沿** 逐级展开。

- **已有专题**：本站已建目录、可点击进入的学科。
- **待建**：当前缺失、规划补充撰写的学科（以橙色「待建」标注）。
- **引用**：跨树重合的学科以「引用」呈现，不重复建专题。

本站博文唯一呈现**技术相关内容**（计算机 / AI / 工程 / 数理基础等）；哲学、人文、社科、医学、农学等非技术领域作为知识树结构保留，以构建全人类知识图谱的完整图景，相关专题以「待建」标注。
