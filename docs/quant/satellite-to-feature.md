# 卫星到特征

<div class="epigraph">
<p>像素不是 alpha。从轨道影像到证券特征，要经过传感器校准、云与缺失、设施检测、映射与 vintage；每一步都在改写你实际交易的对象。</p>
<footer>—— Henderson, Storeygard and Weil, Measuring Economic Growth from Outer Space, AER, 2012；Donaldson and Storeygard, The View from Above, JEP, 2016</footer>
</div>

[卫星与地理](/quant/satellite-geo)已经说明夜灯、NDVI、设施影像各自测什么。[面板构造](/quant/alt-panel-construction)要求映射与缺失机制。本课的缺口是中间那一段：**栅格 → 物体 → 数量 → 特征**，以及传感器世代与处理延迟如何进入可交易时钟。不要重讲夜灯与 GDP 的宏观回归，只补生产特征管道。下一课合规会限制高分辨率影像能识别到什么粒度。

## 问题

原始输入是带时间戳的栅格或商业供应商的「车辆计数」。研究若直接拿计数对收益回归，跳过了：几何校正、云掩膜、传感器切换（DMSP→VIIRS）、检测模型版本、以及计数到公司的归属。每一跳都有回填：新检测模型重跑历史影像，计数被改写。本课把管道显式化，使[回填](/quant/alt-data-backfill-bias)有可版本化的节点。

设施检测把像素变成物体。物体计数的误差在繁忙停车场与空旷矿区不同，异方差会进入截面。特征若用「相对上年同期」，还依赖当时是否已有上年同期的**当时版本**计数，而不是终版。

### 公开传感器与商业计数不是同一管道

VIIRS 夜灯可复现、延迟和算法有文献。商业停车场计数不可完全复现，必须把供应商模型版本写进 vintage。把两者混成「卫星因子」，无法验证。公开宏观代理适合国家/区域 nowcast；商业设施适合公司层面，也更贵、覆盖更偏、回填更严重。

<span class="marginnote">云层与季风相关，缺测不是随机。面板课已禁止把 NA 当零；卫星管道必须把云掩膜作为一等输出，而不是只输出一个计数。</span>

## 方法

管道节点：(1) 影像 ingest 与传感器元数据；(2) 云/质量掩膜；(3) 校准与跨卫星交叉校准；(4) 检测或指数计算（NDVI、夜间灯光、物体计数）；(5) 空间聚合到当时门店/设施多边形；(6) 映射到证券；(7) 延迟对齐到决策日。每个节点输出存档，禁止只存最终特征。特征建议用相对量：同比、相对同业、相对自身滚动中位，并控制覆盖（有效像素比例）。Addoum、Ng 与 Ortiz-Bobea 一类工作把温度对齐到经营场所，精神是空间到公司的可审计映射，而不是「我们有图」。

验证：与公开披露的同店、产量、USDA/EIA 对照，看的是代理质量，不是看能否在样本内预测股价。能预测股价但与物理量无关，更像数据挖掘或回填。

### 从特征到持有期

卫星重访可能是数日一次。特征的自然 $H$ 不是日内。硬做成日频信号，信息来自填充规则。体制卡应把卫星策略标成中低频，执行可以在财报窗加密，但信号时钟仍是重访时钟。这与持有期课的 $\tau$ 对齐一致。

## 机制

测量误差进入收益回归，像错误变量，把系数拉向零；回填则把系数拉向虚假显著。两者方向相反，终版回归无法诊断。节点存档才能做：用当时检测模型 vs 今日模型重跑的差。传感器切换造成水平跳动，若不交叉校准，体制切换会被当成经济断点。Donaldson–Storeygard 强调这一点，金融应用同样适用。

价格发现：若 USDA 已发布，NDVI 的增量信息下降。特征应标明信息集对照——相对官方统计的残差，才可能是增量。否则卫星只是把已公开信息换一种采样。

<span class="marginnote">高分辨率屋顶与车辆可以接近个人识别。特征必须停在设施统计量。下一课把这条写成合规约束，而不是写成精度目标。</span>

```mermaid

  IMG["影像 + 传感器元数据"] --> QA["云与质量掩膜"]
  QA --> DET["指数或物体检测"]
  DET --> FAC["当时设施多边形"]
  FAC --> SEC["映射到证券"]
  SEC --> PIT["决策日特征"]
```

### 同比特征仍依赖当时版本的上年计数

相对上年同期看起来消除了水平，但若上年计数是今日模型重跑的，同比仍含回填。每个滞后期都要取当时 vintage，而不是取终版再差分。

## 边界

SAR、光学、夜灯物理不同，不能同一套云规则。本课不涉及如何购买或处理未授权影像。加密与宏观商品期货对农业特征的定价已部分有效，增量 IC 可能接近零，这是边界不是失败。

<span class="marginnote">公开夜灯与商业停车场计数不是同一管道。混成「卫星因子」之后，无法验证传感器校准，也无法把回填定位到节点。</span>

## 小结

- 卫星特征管道必须节点存档，才能版本化、才能测回填。
- 云掩膜与覆盖是特征，不是麻烦。
- 传感器世代要交叉校准，否则水平跳动像体制。
- 信号时钟跟重访走，不要假日频。
- 增量信息相对官方统计来定义。
