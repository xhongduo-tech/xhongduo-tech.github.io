# 报价填塞

<div class="epigraph">
<p>报价填塞是在极短时间内提交并撤销大量订单，占用撮合与行情通道，使别人看到的簿延迟或残缺。它攻击的是别人的信息集与速度，而不必完成成交。</p>
<footer>—— Egginton, Van Ness and Van Ness, Quote stuffing, Financial Review, 2016；技术背景见 Hasbrouck and Saar 对低延迟订单流的讨论</footer>
</div>

[闪电崩盘](/quant/flash-crash-2010)是供给撤退的价格路径。缺口是另一种伤害流动性的技术：不一定把簿撤空，而是用消息洪水让对手的状态机变慢。Egginton、Van Ness 与 Van Ness（2016）度量报价填塞时段的市场质量。本课写机制与识别，严格区别于下一课有虚假意向的幌骚，也区别于正当的高频改价。

## 问题

正常做市已经有高撤单率。填塞的额外特征是：消息率相对成交异常高、集中在极短窗口、往往不改变对提交者自己有用的队列位置，却造成行情拥堵。别人的「看见的簿」变成过时状态，其撤单与狙击决策基于错的 $\rho$，被捡与误吃上升。问题是如何在数据里把拥堵攻击从「新闻到达时大家一起改价」分开：后者是公共信息的合法同步更新，前者是制造人为延迟。

Budish 竞赛假设每个人看见同一条新闻。填塞破坏这个共同信息集，是对透明的攻击，回到 Bloomfield–O'Hara 的谁看见什么。

### 通道是稀缺资源

撮合引擎、行情组播、参与者的解析队列都有容量。先到者通吃的协议里，让别人的队列变长，等价于让自己相对变快。填塞因此可以是速度竞赛的阴暗技术：不投资更短的线，而增加别人的 $d$。社会成本是全市场状态变差，不只是租金再分配。

<span class="marginnote">监管与交易所后来用消息比、撤单费、节流来对通道定价。本课只把通道写成稀缺，具体规则表留在市场设计。不要把未经验证的「某年某所某算法」写成事实。</span>

## 方法

度量：在毫秒窗内计数新增+撤销，相对成交、相对该证券的历史分位。识别：窗口内价差、深度、中点波动、其他参与者的消息延迟（若有时间戳质量）。Egginton 等人报告填塞窗内质量恶化。因果仍难：也许是同一新闻引起填塞状改价与质量恶化。工具可以用意外的引擎减速、或只影响行情不改变价值的纯消息事件。

与 Hasbrouck VAR：填塞期报价新息充满噪声，信息含量估计应切开这些窗，否则暂时成分被高估。

## 机制

填塞改变的是条件信息集的时钟。Easley–O'Hara 的学习假设每笔方向被同时看见；拥堵时一部分人看见，一部分人看见延迟序列，信念分叉，Glosten 曲线对慢的人错误开口。快的填塞者可以在自己制造的过时上交易——这已经接近操纵的经济定义（制造虚假市场状态并从中交易），即使订单曾经「真实」存在过几个微秒。

正当高频做市的改价通常跟随中点或库存，订单在附近价位重挂。填塞更常扫过大量远离成交的价位，或在同一档反复增撤而不改变净深度。行为特征比消息率阈值更有内容。

## 边界

没有成交的高消息率也可能是测试、错误环路、或 pro-rata 堆量。执法需要模式与意图，本课不给法律标准。加密与某些外汇平台的通道更脆，同构现象更频繁，但文献样本以美股为主。把所有闪单叫做填塞，会把撤单博弈课的理性寿命选择一网打尽。

<span class="marginnote">回测若在填塞窗用官方 L2 当真实可成交，你比当时的慢参与者还乐观——你在用事后干净的重建，他们当时没看到。</span>

下一课的幌骚攻击的是可见供需的内容，填塞攻击的是别人看见该内容的时钟。两者可以叠用，识别上仍应先分开：一个改延迟，一个伪造深度。

## 小结

- 报价填塞用消息洪水占用通道，使对手信息集过时，是对速度与透明的攻击。
- 须与新闻同步改价、理性短寿命做市区分；远离成交价的无效增撤是更强特征。
- 通道稀缺时，制造别人的延迟等价于相对加速。
