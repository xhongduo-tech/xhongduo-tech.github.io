# Functional Analysis

Functional analysis is the study of infinite-dimensional spaces and the linear operators acting on them, and it forms the core framework of modern analysis. This post follows the chapter structure of the textbook *Functional Analysis* (by Cheng Qixiang and Zhang Gongqing), covering all the introductory material from metric spaces up to a first look at spectral theory.
