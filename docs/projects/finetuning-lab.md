# 数据与监督微调实验

## 问题

选择一个有明确验收规则的小任务，检查数据质量、模板、loss mask及LoRA配置怎样影响模型学习。

## 计划交付

- 训练、开发与保留测试集，以及合理提示基线。
- 一次真实的小规模SFT与adapter保存、重载记录。
- 至少一项有依据的数据或配置变化及受控对照。
- 训练损失、任务质量、退化、用量和失败分析。

目前实验尚未执行。跑通训练脚本、理解训练机制和证明某项改善分别验收。
