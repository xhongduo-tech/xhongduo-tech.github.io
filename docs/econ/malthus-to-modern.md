# 马尔萨斯到现代增长

<div class="epigraph">
<p>土地固定时，技术改善先变成人口，而不是人均收入；现代增长从这条人口反馈断开的那一刻才开始。</p>
<footer>—— 据 Malthus《人口原理》的土地约束；对照 Galor 统一增长理论</footer>
</div>

[上一课](/econ/institutions-acemoglu)把制度写成比较发展的根本原因：产权与约束进入投资激励。制度解释**谁**能占有剩余，还不解释**何时**人均收入脱离生存水平。本课的缺口是对照两套动态：马尔萨斯——技术或制度改善被人口吃掉；现代增长——人力资本与人口转变让 $g$ 留在人均上。错配与发展核算下一课才回到截面 $A$；本课先把时间上的阶段钉住。

## 问题

索洛与内生增长都在现代增长已经发生的世界上写 $n$ 与 $g$。工业革命前的数百年，技术并非完全停滞，人均收入却几乎不动——改善表现为更多人，而不是更高的 $y$。Malthus 的缺口是土地（或固定资源）使人均产出对人口递减。统一增长（Galor 与 Weil 一类）要回答的是：同一套模型如何先复制马尔萨斯稳态，再内生地进入人口转变与持续 $g$。本课不是人口史综述，只关闭「制度一好，人均立刻永久上升」这句跳跃。

<span class="marginnote">马尔萨斯稳态不是「没有技术」，而是技术的水平效应被 $n$ 吃掉。这与索洛里 $s$ 只有水平效应、增长靠 $g$ 的分工同构，对象换成人口。</span>

## 方法

马尔萨斯块：生产含固定土地，$y$ 随人口上升而下降；收入高于生存则生育或存活上升，$n$ 内生，把 $y$ 拉回生存。制度改善或一次性技术跳升，短期 $y$ 升，长期人口更多、$y$ 回来。现代块：人力资本回报上升 → 生育率下降、对每个孩子的教育上升 → 劳动力质量进入内生 $g$，人口不再吃掉人均。两块之间的触发可以是技术跨过阈值、或技能偏向使教育变得值得。

```mermaid
flowchart TD
  TECH["技术或制度改善"] --> MALT["马尔萨斯：人口↑，人均回来"]
  TECH --> MOD["现代：教育↑，生育↓"]
  MOD --> G["人均 g 持续"]
  MALT --> WAIT["仍在生存附近"]
```

上一课的包容制度，在马尔萨斯块里主要改变人口规模与城市化，不一定改变长期人均。这不是否定 AJR，而是限制它适用的阶段：殖民起源样本已经是现代增长世界里的截面。

### 不要把 $n$ 当索洛参数抄过来

索洛的 $n$ 是摊薄资本的外生率。本课的 $n$ 对人均收入有反馈。黄金律、Ramsey 都默认已经离开生存约束。把工业革命前的停滞读成「储蓄率太低」，是用错了阶段。

### 生存约束与 $y^*$ 不是同一个对象

自然率课的 $y^*$ 是充分就业潜在产出，已经在现代增长世界里。马尔萨斯的生存水平是人口反馈钉住的人均，对象是长期发展，不是周期缺口。

把当代衰退中的低收入写成「回到马尔萨斯」，会取消 Okun 与参与课已经钉住的松弛账户。

## 机制

土地递减使边际人口的产出落到生存线附近，技术的租被新人口分掉。一旦人力资本在生产中变得足够重要，父母用「少生优育」替代数量，劳动力质量与研发互补——接到内生增长与有偏技术：技能偏向可以正是人口转变的推手。脱离之后，制度才主要表现为截面 $A$ 与 $K$，而不是再被人口完全吸收。

经验对照只点一句：人口转变与持续人均增长大致同期，先后在各国不同。本课不编年份因果。统一增长是对照装置，不是已经识别了每一个触发。

土地约束松开之后，索洛的 $n$ 才重新像参数：摊薄资本，而不是吃掉全部剩余。内生增长的研发部门也才站得住——马尔萨斯块里，研发的租同样会被新人口摊薄。AJR 的殖民截面已经位于现代块：人均收入差可以持久，正是因为人口反馈不再把 $y$ 钉回生存。把工业革命前的停滞与当代穷国的低 $A$ 写成同一句马尔萨斯，会取消发展核算。

<span class="marginnote">疾病、战争可以暂时抬高人均（人口下降），仍是马尔萨斯机制，不是现代增长。看 $y$ 的水平是否能在人口恢复后保住。</span>

## 边界

本课不估计生育方程，不把马尔萨斯写成当代贫困的唯一理论——当代穷国已部分进入现代增长，发展核算更贴。也不把 CIP 或资本流动当人口转变的原因。量化栏没有这条长期人口动态。

统一增长有多套触发（人力资本阈值、性别工资、结构转型），本课不选唯一。要禁止的只是：用现代索洛比较静态去读生存约束还在的经济。黄金律在马尔萨斯块里会被人口吃掉，计划者问题必须重写生育，不能把 $s$ 当唯一按钮。

后课默认：增长主干里的 $n$、$g$ 默认现代阶段；谈到工业革命前或极低收入，先问人口反馈是否还在。下一课回到截面：错配如何表现为同一个残差 $A$。

## 小结

- 制度课解释激励；本课解释人均为何长期钉在生存线。
- 马尔萨斯：技术与制度的改善被人口吸收。
- 现代增长：人力资本与生育转变让 $g$ 留在人均上。
- 索洛的外生 $n$ 不适用于生存约束还在的阶段。
- 出处：Malthus《人口原理》；Galor 统一增长（与 Weil 等）的阶段对照。
