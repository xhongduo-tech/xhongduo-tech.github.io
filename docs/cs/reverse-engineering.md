# 逆向工程

<div class="epigraph">
<p>没有源码时，行为仍在指令与数据里。逆向是恢复类型、协议与不变量，用来做兼容、审计与补丁理解。它不是默认的利用课。</p>
<footer>—— 据 Cifuentes 的反编译；Hex-Rays/Ghidra 类工具的公开文档；对照版权与许可边界</footer>
</div>

上一课[补丁](/cs/patch-management)有时只有二进制差分。缺口是**如何读差分**：反汇编、控制流图、字符串。本课讲方法与合法用途，不提供破解授权或写恶意载荷。

后课默认已经读完本课钉下的合同，只补差，不从该领域第一性原理重开。

## 问题

供应商闭源、固件、恶意软件（下一课）。静态：反汇编；动态：调试器。缺口是抽象恢复，不是绕过付费墙。

### 许可

拆自己的产物、授权审计、恶意软件分析是常见合法语境。拆他人保护机制可能违法——本课不指导后者。

<span class="marginnote">Ghidra 是 NSA 开源逆向套件。本课不给破解练习。</span>

## 方法

列视图：CFG、交叉引用、系统调用。<span class="marginnote">反汇编是把机器码一对一翻回汇编指令，无损；反编译则更进一步试图翻回近似 C 代码，一对多、靠猜。Ghidra 反编译窗口显示的是后者——读起来像源码，但每行都可能和原始逻辑有出入。</span>对照符号执行辅助理解。<span class="marginnote">初学者容易以为一个函数在二进制里是完整连续的一段；内联、尾调用等优化常把逻辑打散到多处。交叉引用和 CFG 才是把散落代码重新拼起来的手段。</span>下一课恶意软件分析：同样的工具，目标是分类与遏制。

```mermaid
flowchart TD
  BIN["二进制"] --> DIS["反汇编"]
  DIS --> CFG["控制流图"]
  CFG --> SEM["恢复协议/类型"]
  DIFF["补丁差分"] --> SEM
```

## 机制

理解闭源是防御的输入。<span class="marginnote">读补丁差分就像玩「找不同」：两张几乎一样的图，只有几处笔画不同——那几处往往正是厂商修漏洞的位置，也是安全研究者定位 N-day 的入口。</span>下一课把对象换成恶意软件样本。

```mermaid
flowchart TD
  V1["旧版本二进制"] --> F1["提取函数列表与签名"]
  V2["新版本二进制"] --> F2["提取函数列表与签名"]
  F1 --> DIFF["相似度配对，圈出改动函数"]
  F2 --> DIFF
  DIFF --> CFGD["对比两个 CFG，看新增与改动的边"]
  CFGD --> HYP["形成假设：此处修了什么漏洞"]
  HYP --> DYN["动态调试验证假设"]
```

## 边界

本课不写 DRM 绕过。恶意软件分析下一课。

## 小结

- N-day 理解常要读二进制差分。
- 逆向恢复行为，服务审计与兼容。
- 不指导破坏他人保护机制。
- 下一课恶意软件分析。
