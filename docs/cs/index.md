# 计算机

按课程读，不是按课本目录堆词条。先把组成、体系结构、数据与算法、编译、操作系统、网络、数据库、安全各自的知识点铺开，再归并成递进课序——操作系统单独就是百级叶子，覆盖内核边界、进程、调度、同步、虚存、文件、IPC 与隔离。后课默认已经读完比特与 ISA，不再从「计算机是什么」起笔。本栏停在系统栈，不重写 [Transformer](/llm/) 或 [限价簿](/quant/lob-structure)。附录是经典论文对照。
