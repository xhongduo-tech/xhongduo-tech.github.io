# 抽象数据类型

<div class="epigraph">
<p>先约定对象上允许哪些操作以及它们的代价，再选一种比特布局去实现；布局可换，合同不能偷换。</p>
<footer>—— 据 Liskov and Zilles, Programming with Abstract Data Types, SIGPLAN 1974；Cormen, Leiserson, Rivest and Stein, Introduction to Algorithms 整理</footer>
</div>

[上一课](/cs/cache-side-channel)把微结构进阶收到 Prime+Probe：组相联的占用能当信道，性能机制即安全边界，不能单靠 ISA 正确性。本课不重讲 MESI，也不从「计算机是什么」另起。缺口是：还没有给**可复用的布局**命名——栈、表、图在 ISA 里都只是 load/store。[比特作为区分](/cs/bit-as-distinction)给出串，[渐近记号](/cs/asymptotic-notation)给出步数怎么写。本课只钉抽象数据类型：操作集合加代价，实现另选。后课默认已经读完本课。

## 问题

体系结构课结束时，程序员仍每次用手排寄存器和地址。同一套「后进先出」可以是数组顶指针，也可以是链表，调用约定已经用过其中一种，却没有把它写成可替换的合同。缺口不是新的特权级，而是把对象从具体指令里抽出来：**构造、插入、查找、删除各允许做什么，最坏或摊还各多少步**。

没有这层，后课无法比较数组与链表：它们会混成「都是一串元素」。代价必须进合同，否则局部性与 $O(1)$ 下标会被说成同一件事。

<span class="marginnote">ADT 不是 OOP 课。Liskov 强调的是接口与表示分离；本栏用它连接 ISA 与 CLRS 里的结构。</span>

<span class="marginnote">术语翻译：ADT 就是用「只写允许哪些操作、各花多少步，不写内存里怎么摆」的手段，来做「换掉实现而不改调用代码」的事。合同里连代价都写明，是为了防止有人换个实现后把 $O(1)$ 悄悄换成 $O(n)$ 还叫同一个名字。</span>

## 方法

指定一个对象类型 $T$ 和有限个操作，每个操作给出前置条件与渐近代价（最坏、平均或摊还，须声明）。正确性相对抽象状态（序列、集合、全序映射），不相对某次 `sw` 的地址。同一 $T$ 可以有多种表示，后课逐个给。

```mermaid
flowchart TD
  ISA["指令已能执行"] --> ADT["操作 + 代价合同"]
  ADT --> ARR["后课：数组表示"]
  ADT --> LIST["后课：链表表示"]
```

本课不引入任何一种具体结构的不变式细节。只要求：换表示不得偷偷改合同——若查找从 $O(1)$ 变成 $O(n)$，那是另一种 ADT 或另一种实现承诺。

## 机制

有了合同，[局部性原理](/cs/locality-principle)变成实现层的注释：同一「取第 $i$ 个」在数组上吃空间局部性，在链表上可能每次 cache 缺失。渐近记号数的是步，步的常数含命中与缺失；后课会把两者拆开写，但合同先写步数。

NUMA 上远程节点是又一层常数。ADT 课默认分析单处理器 RAM 模型，需要时再加一句「布局破坏局部性则常数爆炸」，不把每课重写成体系结构。后课的每一种结构，都先写合同再写一种表示，不从晶体管另起。

方法一节的图回答「合同从哪里来、通向哪些表示」，下面这张回答另一个问题：同一个调用「查找第 $i$ 个」，穿过两种表示时代价分别怎么兑现。

```mermaid
flowchart TD
  C["调用方: 查第 i 个"] --> K{"合同承诺的代价"}
  K --> A["表示一: 数组"]
  K --> B["表示二: 链表"]
  A --> A1["基地址 + i x 步长 直接寻址, O(1)"]
  B --> B1["从表头逐个走 i 步, O(n)"]
  A1 --> D["调用方代码不变"]
  B1 --> D
  D --> E{"宣称的代价与实现一致?"}
  E -- "否" --> F["合同被偷换, 不许"]
  E -- "是" --> G["合法替换"]
```

<span class="marginnote">直觉类比：合同像墙上的插座标准——电器（算法）不管墙里电线怎么走（表示），只认插座形状和电压电流规格（操作与代价）。只要规格不变，重排墙内布线，电器插上就能用；但把 220 V 换成 110 V 还标着 220 V，就是偷换合同。</span>

<span class="marginnote">数字实例：同样是「查找」，数组 $O(1)$ 与链表 $O(n)$ 在 $n=10^6$ 时是「一步」与「一百万步」的差距——这正是为什么合同必须声明代价：调用方要拿它做工程决策，而不只是接口形状。</span>

## 边界

本课不把类、继承、虚函数请进来。也不把「抽象」写成无代价：没有代价的接口无法在后课做选择。形式化代数规范（ADT 作为等式理论）不在主干。

后课默认：谈到栈、队列、字典、图，先有操作与代价，再谈表示。第一份表示是数组。

## 小结

- 机器会执行了；本课开始命名操作合同，而不是某次 load 的地址。
- ADT = 操作 + 代价；表示可换，合同不可偷。
- 数组随机访问是下一课的第一种表示。
- 本课不把类与继承请进来；没有代价的接口无法选择表示。
- 出处：Liskov and Zilles, 1974；Cormen et al., *Introduction to Algorithms*。
