# CMOS 反相器

<div class="epigraph">
<p>一个 pMOS 上拉、一个 nMOS 下拉，中间那根线才是稳定的 0 与 1；静态 CMOS 几乎不在稳态耗直流。</p>
<footer>—— 据 Harris and Harris, Digital Design and Computer Architecture 整理</footer>
</div>

上一课[插值与龙格现象](/cs/interpolation-runge)把数值计算收到多项式拟合的边界。信息与离散更早已经结束。本课不重讲条件数，也不从半导体物理的能带另起。缺口是：程序与比特已经会写，布尔课的「非」还没有**器件**。数字逻辑与计算机组成从这里开始：先实现一个反相器。

## 问题

布尔 $\bar x$ 是函数。硅上要把电压映射回两个区间。缺口因此不是新的公理，而是一对互补晶体管：输入高则 nMOS 导通把输出拉到地，pMOS 截止；输入低则相反，输出拉到电源。互补使得稳态没有从电源到地的直流通路（忽略漏电）。<span class="marginnote">术语翻译：nMOS 是「输入高才导通」的开关，专职把输出往下拉到地；pMOS 正相反，「输入低才导通」，专职把输出往上拉到电源。两管极性互补、永远一开一关——「互补金属氧化物半导体」（CMOS）的名字就是这么来的。</span>

本课只钉这一格。与非、或非、万能门是[下一课](/cs/nand-universal)。阈值、传输特性画到「有噪声容限」为止，不把短沟道模型展开。

### 反相器不是「一个晶体管」

单 nMOS 加电阻上拉是 NMOS 逻辑，稳态有电流。CMOS 用 pMOS 代替电阻，极性相反。把反相当成开集电极或模拟放大器，会把后课的恢复性电平说错：数字要的是把中间电压推回轨。

<span class="marginnote">Harris 第 1 章用 CMOS 反相器当数字抽象的物理锚。本课只承认有 p 管 n 管两种开关，不把工艺步骤当内容。</span>

## 方法

符号：pMOS 源接 $V_{DD}$，nMOS 源接地，栅接在一起为输入，漏接在一起为输出。转移曲线中间有高增益区，两边饱和到轨。噪声容限定义为输入还能被当成合法 0/1 的余量。<span class="marginnote">直觉类比：转移曲线中间的高增益区像陡坡——电压一旦被噪声蹭进这一段，就被迅速推向最近的轨道。这就是「恢复性」：走样的信号过几级门自动回到干净的 0 或 1，数字信号因此能一级级传递而不腐坏。</span>

  BIT["逻辑非"] --> CMOS["pMOS 上拉 + nMOS 下拉"]
  CMOS --> RAIL["输出靠近电源或地"]

## 机制

恢复性：被噪声推离轨的电压，经过一级（或奇数级）反相器可以拉回。这是第一课「判决」的电路实现。延迟来自对负载电容的充放电，下一课以后的门时延把这一格量化；本课只承认电容存在，不写 $t_{pd}=RC$。

功耗：动态是 $CV^2f$，静态理想为零。漏电使静态非零，本课承认但不建模。

```mermaid
flowchart TD
  IN{"输入是高还是低？"} -->|"高"| NC["nMOS 导通，pMOS 截止"]
  NC --> LOW["输出经 nMOS 放电到地：0"]
  IN -->|"低"| PC["pMOS 导通，nMOS 截止"]
  PC --> HIGH["输出经 pMOS 充电到电源：1"]
  LOW --> NOPATH["截止的那管挡住电源到地的直流通路"]
  HIGH --> NOPATH
```

<span class="marginnote">这张图回答「两种输入下电流各走哪条路、为什么稳态不耗直流」。数字实例看动态功耗：负载电容 10 fF、电压 1 V、每秒翻转 10 亿次，这一根线的功耗约 $10\times10^{-15}\times 1^2\times 10^9 = 10$ µW——单根不起眼，亿万个翻转节点攒起来就是芯片热量的主要来源。</span>

## 边界

本课不讲工艺节点纳米数、FinFET。模拟偏置、差分对不属于主干。时序电路仍没有时钟。

后课默认：逻辑门的原子是 CMOS 复合物；稳态输出在轨附近；非由反相器实现。

## 小结

- CMOS 反相器：p 上拉 n 下拉，稳态几乎无直流。
- 高增益区提供噪声容限与电平恢复。
- 与非/或非网络、延迟公式是后课。
- 出处：Harris and Harris, *Digital Design and Computer Architecture*。
