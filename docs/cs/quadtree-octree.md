# 四叉树与八叉树

<div class="epigraph">
<p>正方形一分为四、立方体一分为八；空块不再切。分辨率跟物体走，不跟数据页扇出走。</p>
<footer>—— 据 Finkel and Bentley, Quad Trees: A Data Structure for Retrieval on Composite Keys, Acta Informatica 1974；Samet, Foundations of Multidimensional and Metric Data Structures 整理</footer>
</div>

[上一课](/cs/r-tree) 的 MBR 自适应且可重叠。[k-d 树](/cs/kd-tree) 按数据中位数切。若域是固定包围盒、物体是图像像素或体素，用规则分裂更简单。本课不写页分裂启发式。缺口是四叉树 / 八叉树：几何中点切，到容量或深度停止。

## 问题

平面区域或点集，反复把方块分成四象限，块内点少于阈值或到达最大深度则成叶。<span class="marginnote">可以把它想象成地图缩放：世界先是一整张图，哪里点密集就把哪一格放大成四格，稀疏处一格到底——分辨率跟着数据密度走，而不是全图平均用力。</span>八叉树对立方体八分，用于三维场景、体素。查询：与询问区相交的块才下钻。缺口是**规则四/八分**，编码可用象限位，邻接查找有经典算法（Samet）。

<span class="marginnote">Finkel and Bentley 1974。点四叉树与区域四叉树（黑白像素合并）是两种合同，本课都点名：前者叶存点，后者叶存均质块。</span>

## 方法

插入点：从根走到含该点的叶，溢出则分裂再插。删除可能合并兄弟（若都变稀）。范围查询与 k-d 类似剪不相交方块。最近邻可优先探近的象限。

```mermaid
flowchart TD
  SQ["正方形"] --> Q0["象限 00"]
  SQ --> Q1["象限 01"]
  SQ --> Q2["象限 10"]
  SQ --> Q3["象限 11"]
```

与 R 树：无 MBR 重叠问题，但空区域仍占树路径，偏斜数据会不平衡。与网格：四叉树是自适应分辨率网格。

## 机制

深度 $O(\log(1/\varepsilon))$ 于最小特征尺寸，不是 $O(\log n)$。<span class="marginnote">数字实例：要把最小可分辨块边长压到原边长的千分之一，深度约 $\log_2 1000 \approx 10$ 层——即使块里塞了一百万个点，深度也由几何精度决定，与点数基本无关。</span>最坏一条链（点挤在角上反复切）。<span class="marginnote">初学者容易以为四叉树和平衡二叉树一样「深度 $O(\log n)$、天然平衡」；实际上深度由最小特征尺寸决定，所有点挤在一个角上时会退化成一条长链——「到容量就切」的规则对偏斜数据毫无防御。</span>三维八叉同构，只是扇出 8。本课不把 GPU 层次包围盒（BVH）写完，只承认同族。

空间填充曲线把四叉块序线性化，便于外存与缓存——下一课专门收 Hilbert / Morton。

```mermaid
flowchart TD
  Q["范围查询矩形 R"] --> ROOT["从根块出发"]
  ROOT --> HIT{"块与 R 相交？"}
  HIT -->|否| SKIP["整块剪掉"]
  HIT -->|是| LEAF{"已到叶块？"}
  LEAF -->|否| SUB["四分下钻子块"]
  SUB --> HIT
  LEAF -->|是| OUT["收集叶内点入结果"]
```

<span class="marginnote">这张图回答的问题是：一次范围查询的代价从哪来——只与「和询问框相交的块」有关，查询的剪枝发生在块级而不是点级；查询框越小，被剪掉的子树越多，代价越接近 $\log$ 而非全扫。</span>

## 边界

本课不写压缩四叉树的全部指针消除。高维 $2^k$ 叉爆炸，勿把八叉推广到 20 维。字符串与后缀不是空间树。

后课默认：规则空间层次用四叉/八叉。要把块序变成一维局部性，用空间填充曲线。

## 小结

- 四叉/八叉：规则中点分裂，叶达容量或深度。
- 平衡不保证；偏斜退化。
- 下一课用曲线把多维块排成一维。
- 出处：Finkel and Bentley, 1974；Samet 的多维结构综述与专著。
