# Shamir 秘密共享

<div class="epigraph">
<p>把秘密当成多项式在 0 处的值，发给每人一个点；$t$ 个点能插值，$t-1$ 个点在信息论上什么都不知道。阈值由多项式次数决定。</p>
<footer>—— Shamir, How to Share a Secret, Communications of the ACM, 1979</footer>
</div>

上一课[承诺与 Merkle](/cs/commitment-merkle-tree)把一个值绑进公开根。缺口是**不公开、但要多人共管**：任何少于阈值的集合不应得到秘密。HSM 备份常走这条，而不是把根钥复印 n 份。

后课默认已经读完本课钉下的合同，只补差，不从该领域第一性原理重开。

## 问题

把密钥切成 n 段明文，任何一段都可能泄漏部分比特。Shamir：在有限域上随机 $t-1$ 次多项式，$f(0)=s$，份额是 $(i,f(i))$。完善保密：少于 $t$ 个点时 $s$ 仍均匀。缺口是阈值方案，不是再讲 HKDF。

### 份额也是密钥材料

存份额的主机被全拿仍达阈值。分发信道要保密且认证，否则份额被换（主动敌手）。

<span class="marginnote">Shamir 1979。Feldman/Pedersen 可验证共享防经销商作恶，本课点名，细节留给 MPC。不要与「把文件 zip 分卷」混淆。</span>

<span class="marginnote">直觉类比：次数 1 的多项式是条直线——两点定线、一点不定。秘密 $s$ 就是直线与 $y$ 轴的交点 $f(0)$；每人拿走线上一个点，手里只有一个点时，那条线可以在平面上「晃来晃去」，交点有无穷多种可能，等于什么都不知道。</span>

## 方法

用次数 1 的直线在黑板上点名「两点定线、一点不定」。推广到 $t$。指出重构是拉格朗日插值，实现要在域上算，并防份额编号重复。

<span class="marginnote">数字实例：$t=3, n=5$ 时随机取二次式 $f(x)=s+ax+bx^2$，5 位托管人各拿一个点；任何 3 人到齐即可插值出 $s$，2 人凑一起对 $s$ 的知识与瞎猜无异。运算要在有限域上做（如大素数域 GF(p)），在普通整数上算会让「点」退化解密。</span>

```mermaid
flowchart TD
  S["秘密 s=f(0)"] --> POLY["随机多项式"]
  POLY --> SH["n 份份额"]
  SH --> T["任意 t 份可重构"]
  SH --> LT["少于 t 份无信息"]
```

## 机制

信息论安全的拆分服务托管与灾难恢复。它不提供计算：份额持有人如何**一起签名还不重构明文私钥**，是下一课门限与 MPC。重构后的 $s$ 又回到单点，策略上应在 HSM 内完成重构。

```mermaid
flowchart TD
  C["收集到 k 份份额"] --> Q{"k \lt 阈值 t ?"}
  Q -->|是| NO["信息论上零泄露, 流程终止"]
  Q -->|否| V{"每份都验证过来源?"}
  V -->|否| REJ["可能混入假份额, 拒绝重构"]
  V -->|是| L["拉格朗日插值求 f(0)"]
  L --> H["在 HSM 内得到 s, 不出安全边界"]
```

<span class="marginnote">常见误区：初学者容易把它当成「文件加密分卷」。zip 分卷少一卷只是打不开，剩下的卷并没有什么「保密性」保证；Shamir 的「少于阈值零信息」是信息论级别的——攻击者有无限算力，也推不出关于 $s$ 的任何一个比特。</span>

## 边界

本课不写主动攻击下的份额注入步骤。下一课门限签名与 MPC 直觉：计算发生在秘密共享之上。

## 小结

- 承诺藏一个值；共享把值拆给多人。
- Shamir：$t$ 点重构，$t-1$ 无信息。
- 份额信道要保密认证；重构点仍是 TCB。

- 出处：Shamir, 1979；对照 Stinson 的密码学教材章节。
