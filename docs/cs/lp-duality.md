# LP 对偶

<div class="epigraph">
<p>每个约束一张对偶变量；弱对偶给目标上界，强对偶在最优处相等，互补松弛刻画最优基。</p>
<footer>—— 据 Dantzig, 1963；von Neumann 的对偶观察；CLRS 第 29 章整理</footer>
</div>

上一课[单纯形](/cs/simplex)在原问题上转轴。缺口是对偶 LP：$\min b^\top y$，$A^\top y\ge c$，$y\ge 0$（形式随标准形变）。弱对偶：$c^\top x\le b^\top y$ 对任意可行对。强对偶：都可行则最优值相等（有限时）。不重写转轴表。后课整数规划对偶间隙可正。

## 问题

原 $\max c^\top x$，$Ax\le b$，$x\ge 0$。对偶 $\min b^\top y$，$A^\top y\ge c$，$y\ge 0$。最大流最小割是对偶的组合影子。匹配顶标（KM）是指派问题的对偶。缺口是这张表，不是再跑单纯形。

无界原问题 $\Rightarrow$ 对偶不可行，反之亦然（弱对偶）。

<span class="marginnote">直觉类比：对偶变量 $y_i$ 是「影子价格」——第 $i$ 种资源多给一个单位，最优目标值大约涨 $y_i$。例：$b=(100, 80)$ 表示工时与原料限额，解出 $y=(2, 3)$ 就是在说「多 1 小时工时值 2 元、多 1 份原料值 3 元」，收购价低于这个数就不该扩产能。</span>

### 不是拉格朗日乘数课的重写

对偶可从拉格朗日来，本课认 LP 教科书构造：约束 $\leftrightarrow$ 变量，右端 $\leftrightarrow$ 目标。内点法用障碍，后课。

<span class="marginnote">CLRS 29.4–29.5。最大流最小割、König 是强对偶实例。后课分支定界：整数使对偶间隙出现。</span>

## 方法

写出对偶。用弱对偶证界。用互补松弛检查 $(x,y)$：松弛约束对应零对偶，正变量对应紧约束。

```mermaid
flowchart TD
  PR["原可行 x"] --> W["c^T x ≤ b^T y"]
  DU["对偶可行 y"] --> W
  W --> STR["最优则相等"]
```

单纯形最优基同时给对偶解。

<span class="marginnote">常见误区：初学者容易把对偶当成「把 min 写成 max 的记号游戏」。实际上对偶变量是可解释的价格或势，最大流最小割、KM 匹配顶标等组合定理都是对偶的化身；许多「原–对偶算法」就是在增量地维护一组对偶可行解。</span>

## 机制

弱对偶：把约束加权 $y$ 与目标比。强对偶：多面体几何或单纯形终止时检验数给出 $y$。与 KM：顶标即 $y$，相等子图即互补松弛。与最小割：割容量是对偶可行。

<span class="marginnote">直觉类比：互补松弛像市场出清——有正价的资源（$y_i \gt 0$）绝不闲置（约束取等），有闲置（约束松弛）就必须免费（$y_i = 0$）。检查一组 $(x,y)$ 是否双最优，就是把这两条「物尽其用、闲者无价」逐项核一遍。</span>

```mermaid
flowchart TD
  CS["互补松弛检查 (x, y)"] --> P{"x_j > 0 ?"}
  P -->|"是"| TIGHT["对偶第 j 条约束必须取等"]
  P -->|"否"| FREE["该约束可松弛"]
  CS --> D{"第 i 条对偶约束松弛?"}
  D -->|"松弛 > 0"| ZERO["y_i = 0"]
  D -->|"取等"| ANY["y_i 允许为正"]
  TIGHT --> OPT["全部满足 ⇒ (x, y) 同时最优"]
  ZERO --> OPT
```

## 边界

本课不证强对偶的 Farkas 全文。非线性对偶不写。后课默认：LP 有强对偶；组合算法常是原–对偶。下一课整数规划与分支定界。

## 小结

- 弱对偶始终给界；强对偶最优相等。
- 互补松弛连接原与对偶。
- 流–割、顶标是实例。
- 出处：Dantzig, 1963；CLRS 第 29 章。
