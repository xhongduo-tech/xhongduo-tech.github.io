# 高精度算术

<div class="epigraph">
<p>机器字装不下时，把整数当基 $B$ 的多项式；加减 $O(n)$，小学乘 $O(n^2)$，除法用规范化试商。</p>
<footer>—— 据 Knuth, The Art of Computer Programming, 卷 2；CLRS 第 31 章整理</footer>
</div>

上一课[快速幂](/cs/fast-exponentiation)假定一次乘是 $O(1)$ 或 $O(k^\omega)$。大整数的一次乘本身随位数涨。缺口是**表示与小学算法**：基 $10^9$ 或 $2^{32}$ 的数组，符号、进位、比较。后课 Karatsuba 才拆乘。不重写模意义下的小模运算。

## 问题

$n$ 位（基 $B$ 下 $n$ 个数字）加减从低位进位，$O(n)$。乘法：每位对每位，$O(n^2)$。除法：Knuth 的规范化除（D 算法），试商，最坏每位常数次修正。比较、移位、gcd 用欧几里得，代价由除法主导。

<span class="marginnote">数字实例：取基 $B=10^9$，每个数组元素存 9 位十进制数，一个 100 位数只占约 12 个元素；乘法累加的单项最大约 $(10^9)^2=10^{18}$，恰好装进 64 位整数不溢出——这正是工程上偏爱这个基的原因。</span>

缺口是正确进位与试商，不是 FFT。负数用符号–幅度或补码数组，全程一种。

### 基不是十进制的审美

选 $B$ 使 $B^2$ 不溢出机器字，或用宽寄存器。十进制只为 I/O。不要每位用 `char` 存 0–9 当高性能默认。

<span class="marginnote">常见误区：初学者爱用 `char` 一位一位存十进制，好写但常数大得多；工程实现把多位压进一个机器字，十进制只在最后打印时才换回来。</span>

<span class="marginnote">Knuth TAOCP 卷 2 是大数算术的标准出处。后课 Karatsuba $O(n^{\log_2 3})$，再后 FFT 近 $n\log n$。</span>

## 方法

约定小端或大端。乘：结果 $2n$ 位。除法先对齐被除数。模幂：平方乘 + 本课乘。输出再转十进制。

```mermaid
flowchart TD
  DIG["基 B 数字数组"] --> ADD["加减 O(n)"]
  DIG --> MUL["小学乘 O(n^2)"]
  DIG --> DIV["试商除法"]
```

前导零、零的符号要约定。

## 机制

进位是基 $B$ 的多项式加法。乘法是卷积，小学即朴素卷积。除法是乘法的逆，试商来自最高位估计。与浮点：大整数精确，位数由输入决定；浮点是近似。

小学乘的「错位相加」到底怎么落到数组上：

```mermaid
flowchart TD
  A["a 的数字数组（基 B）"] --> P["对每对 (i,j)：c[i+j] += a[i]*b[j]"]
  BB["b 的数字数组"] --> P
  P --> M["逐位取模：本位 = c[i] mod B"]
  M --> CA["进位：carry = c[i] div B 传给下一位"]
  CA --> R["得到 2n 位的结果"]
```

<span class="marginnote">直觉类比：竖式乘法那张「错位相加」的草稿就是卷积——第 $i$ 位乘第 $j$ 位永远贡献到结果的第 $i+j$ 位；后面的 FFT 乘法快，正是因为卷积可以借频率域整体加速。</span>

## 边界

本课不写 Montgomery 模乘细节（密码实现）。不写任意精度浮点。后课默认：大整数 = 数组 + 小学四则；乘可被更快算法替换。下一课 Karatsuba。

## 小结

- 大整数是基 $B$ 多项式。
- 加减线性；小学乘平方；除法试商。
- 一次「乘」的代价从此不再 $O(1)$。
- 出处：Knuth TAOCP 卷 2。
