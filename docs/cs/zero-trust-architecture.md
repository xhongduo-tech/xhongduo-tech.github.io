# 零信任架构

<div class="epigraph">
<p>零信任架构把每请求的认证、授权与加密当默认，网络位置降为弱信号。策略引擎、身份、设备姿态组成控制平面。它是 NIST 的架构语言，不是某厂商产品名。</p>
<footer>—— Rose et al., NIST SP 800-207</footer>
</div>

## 问题

隐式信任区过大。缺口：PE/PA、持续评估、微分段。身份来自本课程身份单元。

### 遗留

不能一次关掉 VPN。迁移是并行控制。


<span class="marginnote">SP 800-207。纵深防御下一课把多层写进同一画面。</span>
