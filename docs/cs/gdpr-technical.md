# GDPR 的技术含义

<div class="epigraph">
<p>GDPR 把个人数据的合法基础、目的限制、最小化、删除权写成义务。技术含义是：访问控制、留存、可删除架构、跨境、记录处理活动——不是贴合规徽章。</p>
<footer>—— Regulation (EU) 2016/679；对照 Article 29/EDPB 对技术措施的意见点名</footer>
</div>
