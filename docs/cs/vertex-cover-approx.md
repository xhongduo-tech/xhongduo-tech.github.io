# 顶点覆盖 2 近似

<div class="epigraph">
<p>极大匹配的两端点构成顶点覆盖，大小 $\le 2\,\mathrm{OPT}$；贪心按度没有常数比。</p>
<footer>—— 据 CLRS 第 35.1 节；Garey and Johnson, 1979；[近似比](/cs/approximation-ratio) 整理</footer>
</div>

上一课[UCB](/cs/bandit-ucb)收束不确定输入。主干已定义 $\rho$-近似。缺口是顶点覆盖的匹配 2-近似。不重写 $\rho$ 定义。后课集合覆盖 $\ln n$。顶点覆盖 NPC，精确回分支定界。

## 问题

最小顶点覆盖：每边至少一个端点在 $C$。极大匹配 $M$：每条匹配边两端都进 $C$。$C$ 覆盖：未匹配边的端点必与 $M$ 关联否则 $M$ 可扩。$|C|=2|M|$，而 OPT $\ge|M|$（每条匹配边至少一个点），故 $|C|\le 2\,\mathrm{OPT}$。

按剩余度贪心：无常数比（可任意差）。不要用那条当 2-近似。

<span class="marginnote">术语翻译：极大匹配（maximal）就是用「一条条选不相交的边、直到没有任何一条边能再加进来」的手段来做「找一组互不共享端点的边」的事——它不保证边数最多（那是最大匹配），但「加不进新边」这个性质就够推出 2 倍上界。</span>

### 不是独立集 2-近似

独立集与覆盖互补，但近似比对最大化独立集不能这样翻（$n-|C|$ 相对 OPT 独立集可很差）。

<span class="marginnote">CLRS 35.1。U. Vazirani 教材。后课集合覆盖贪心 $H_n$。</span>

## 方法

求极大匹配（任意极大，不必最大）。两端进覆盖。可再删冗余点（可选，不改善最坏 2）。

```mermaid
flowchart TD
  M["极大匹配"] --> C["两端点进 C"]
  C --> TWO["|C| ≤ 2 OPT"]
```

二分图可精确（König），不必近似。

<span class="marginnote">数字实例：星形图（中心连 100 片叶子）的最小覆盖是 1（只取中心）；若极大匹配偏偏选中某条叶子边，$C$ 取两端共 2 个点，$2 \le 2 \times 1$ 成立——算法最坏情形确实能差到 2 倍，这就是上界紧的原因，也是不能指望它实际更准的原因。</span>

## 机制

匹配下界 OPT。两端点上界 2。与 LP：分数覆盖松弛 + 舍入也 2，后课 LP 舍入。与花匹配：最大匹配给出更好下界但不改善这个 2-算法的最坏。

## 边界

本课不写 Unique Games 下的 2-$\varepsilon$ 硬度。不写加权覆盖（可 LP）。后课默认：无向顶点覆盖有 2-近似。下一课集合覆盖贪心。

```mermaid
flowchart TD
  M["极大匹配 M"] --> LB["下界: OPT ≥ |M|"]
  M --> C["取 M 每条边两端, |C| = 2|M|"]
  LB --> RATIO["|C| ≤ 2 OPT"]
  C --> RATIO
  ALT["按剩余度贪心"] --> BAD["无常数比: 可任意差"]
  COMP["独立集 = n - |C|"] --> TRAP["近似比不能如此翻转"]
```

<span class="marginnote">常见误区：初学者容易以为「挑度数大的点先覆盖」一定不差，实际上按剩余度贪心没有任何常数保证——可以构造让它的解比最优大任意多倍的图；2-近似的可信度恰恰来自匹配下界这把尺子，而不是「看起来很贪心」。</span>

## 小结

- 极大匹配两端点：2-近似。
- 度贪心无常数比。
- 独立集不能同样翻。
- 出处：CLRS 第 35.1 节。
