# 匿名页对文件页

<div class="epigraph">
<p>文件页扔掉还能从文件再读；匿名页没有文件副本，脏了就必须进交换区，否则内容消失。</p>
<footer>—— 据 Silberschatz et al.；Bovet and Cesati 对 Linux 页来源的整理</footer>
</div>

[上一课](/cs/thrashing)把所有页算进工作集。[缺页路径](/cs/page-fault-path)已经能从文件填页或填零。[置换](/cs/page-replace)说只读文本可丢弃。缺口是钉死两类**后备**：文件页（inode + 偏移）与匿名页（堆、栈、匿名 mmap、COW 私有副本）。CLOCK 扫描到它们时，写回目标不是同一个设备。

## 问题

若把文本页写进 swap，浪费交换槽且与可执行文件重复。若把改过的堆页只标无效而不写出，进程稍后读到的是空洞或别人的帧。缺口不是再讲 VMA，而是页描述符上的来源：文件映射指向 [VFS](/cs/vfs) 之后才完全展开的 inode；匿名页指向交换槽或「尚无槽的脏匿名」。干净文件页：解映射即可。脏文件页：写回文件。脏匿名页：写 swap。

<span class="marginnote">术语翻译：「后备」（backing store）指页被挤出内存后内容的容身之处。匿名页就是「没有名字」的页——不对应任何文件，堆、栈、匿名 mmap、写时复制的私有副本都是；它们的后备只能是交换区，因为没有第二个地方能重新读出这些内容。</span>

本课不把 shmem/tmpfs 的全部特例写完，只承认它们像「有文件外形的匿名」。

<span class="marginnote">同一物理页可被文件映射共享。淘汰时要看映射类型与脏位，不能只看 CLOCK 指针。后课 mmap 会把共享/私有写清楚；本课先分后备设备。</span>

## 方法

缺页填页时记录 mapping。置换选中：查来源。文件且干净 → 丢；文件且脏 → 加入对文件系统的回写（缓冲课）。匿名且干净（如未写过的零页）→ 丢；匿名且脏 → 分配交换槽、写交换设备。之后 PTE 改为「不在内存」，编码里带槽号或再缺页时查换出表。

<span class="marginnote">直觉类比：干净文件页像图书馆的书——用完直接还回书架（丢弃），谁要再借随时有；脏匿名页像你的手写草稿——世上没有第二份，想腾桌面就必须先拍照存档（写 swap），之后要看再调出来。两者「归还成本」天差地别。</span>

```mermaid
flowchart TD
  VIC["牺牲页"] --> F{"文件?"}
  F -->|干净| DROP["丢, 再读文件"]
  F -->|脏| FB["写回文件"]
  VIC --> A["匿名脏"]
  A --> SW["写 swap 槽"]
```

## 机制

分类让抖动对策更细：优先丢干净文件页，等于用磁盘文件当免费后备；匿名压力才真正吃 swap。工作集里的堆页因此「更贵」。不要在此展开 ext4 布局；文件只是可再次 `readpage` 的对象。[分页](/cs/paging-vm) 仍然只看见有效位；来源在内核页框数据结构里。

两类页从出生到被淘汰走的路完全不同，淘汰代价也随之分档：

```mermaid
flowchart TD
  ANON["匿名页：堆 / 栈 / COW 私有副本"] --> ZF["缺页时填零或复制"]
  ZF --> D1["一旦写入即脏：内存里是唯一副本"]
  D1 --> SW["被淘汰必须写 swap：4 KB 一次 I/O"]
  SW --> RB["进程再访问：再花一次 I/O 读回来"]
  FILE["文件页：代码 / 只读数据"] --> CL["没改过：直接丢弃，零 I/O"]
  FILE --> WB["改过：写回原文件，内容仍有名字"]
```

<span class="marginnote">为什么重要：淘汰一页干净文件页的 I/O 代价是零（解映射即可），而淘汰一页脏匿名页至少两次 I/O——现在写出去、将来读回来。所以内核内存紧张时先回收页缓存里的干净文件页，swap 被真正动用往往意味着物理内存已经见底。</span>

## 边界

本课不引入交换分区的条带与优先级全文。不把设备页（framebuffer）混进匿名。文件空洞与稀疏文件在缺页时可能填零，仍算文件来源。下一课才问 swap 设备长什么样、槽如何分配。

后课默认：匿名脏页必须有交换去处。槽在哪、如何成设备，下一课 swap。

## 小结

- 文件页以文件为后备；匿名脏页以 swap 为后备。
- 淘汰代价不同，工作集会计应分开看。
- 交换槽与设备是下一课。
