# 秘书问题

<div class="epigraph">
<p>$n$ 个候选人依次出现、比较只见相对序；看过约 $n/e$ 个后录用下一个纪录，成功概率趋于 $1/e$。</p>
<footer>—— 据 Dynkin；Gilbert and Mosteller, Recognizing the Maximum of a Sequence, 1966；标准最优停止整理</footer>
</div>

上一课[租买](/cs/ski-rental)是买断阈值。秘书：选最大，不可悔。缺口是 $1/e$ 规则。不重写竞争比的 $\rho$ 定义——本课是成功概率（随机排列）。后课老虎机另一不确定。排列均匀随机，不是对手任意权。

## 问题

见过 $i$ 后只知是否当前最大。拒绝不能再召回。最优：阈值 $r\sim n/e$，拒绝前 $r$，之后第一个超过前 $r$ 最大值的就选。$P(\text{选中全局最大})\to 1/e$。

缺口是最优停止，不是排序。若值为 i.i.d. 连续，等价于秩。<span class="marginnote">数字实例：$n=100$ 时，$100/e \approx 37$，所以先看满前 37 位只记「目前最高分」，从第 38 位起第一个打破纪录的立刻录用——无论最后挑没挑中全局最大，这套规则下的成功概率都稳定在约 $1/e \approx 37\%$，而且这个数几乎不随 $n$ 变。</span>

### 不是招聘的人力资源课

模型是随机排列。对手指定顺序可让任何算法失败。不要当确定性竞争比 $O(1)$——确定性看完才能保证最大。

<span class="marginnote">Gilbert–Mosteller 1966。$1/e$ 古典。后课 UCB 是多臂，可重复拉。</span>

## 方法

证明 $r$ 最优：成功 = 最大在 $j\gt r$ 且 $j$ 前缀最大在前 $r$。求和 $\approx \int_{r/n}^1 -\ln x\,dx$ 在 $r/n=1/e$ 最大。

```mermaid
flowchart TD
  SEE["观察前 n/e"] --> THR["阈值纪录"]
  THR --> HIRE["其后第一个纪录"]
```

$n$ 未知时另有策略，点名。

## 机制

信息与机会的折中：观察太少阈值差，太多已过最大。与 ski-rental：都是阈值；一个代价竞争，一个成功概率。与顺序统计。

把规则落到单次面试的决策上，失败其实有两种口子：观察期结束前最大已出现，或者一路没有新纪录等到看尽。

```mermaid
flowchart TD
  C["第 j 位候选人到场"] --> P{"j 是否仍在前 n/e 观察期?"}
  P -- "是" --> U["只更新纪录, 不录用"]
  U --> N["看下一位"]
  P -- "否" --> B{"打破观察期最高分?"}
  B -- "是" --> H["当场录用"]
  B -- "否" --> R["跳过继续找"]
  R --> L{"候选人已看尽?"}
  L -- "是" --> F["失败: 全局最大已错过"]
```

可以想象成夜市挑摊位：<span class="marginnote">直觉类比：只逛不买太久，好摊位早就走过了；见摊就买又几乎注定吃亏。$1/e$ 规则就是「先空手逛掉约三分之一的摊位校准行情，再买第一家明显更好的」——观察与出手各占其位的折中。</span>

## 边界

本课不写多选、不写折扣。后课默认：秘书 $n/e$ 规则，$1/e$。下一课多臂老虎机 UCB。

<span class="marginnote">常见误区：初学者容易把 $1/e$ 读成「选中全局最大只有 $37\%$，太差了」——但要记住你面对的是随机到达且不可回头的顺序，任何算法在这个设定下都不可能保证 $100\%$；$1/e$ 已经是所有停止规则里的最优者，参照系是「不可能做得更好」，不是「必然成功」。</span>

## 小结

- 随机排列下 $n/e$ 后录用纪录。
- 成功概率 $1/e$。
- 对抗顺序无常数保证。
- 出处：Gilbert and Mosteller, 1966。
