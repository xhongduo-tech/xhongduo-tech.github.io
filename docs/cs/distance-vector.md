# 距离向量

<div class="epigraph">
<p>每个路由器只告诉邻居：我到各前缀的距离；邻居取最小，像分布式的松弛。</p>
<footer>—— 据 Ford, Fulkerson 与 Bellman 的最短路松弛；RFC 2453 RIP Version 2 整理</footer>
</div>

[上一课](/cs/ipv6-ndp)假定转发表已在。[LPM](/cs/lpm) 只查找不填表。缺口是控制平面的一种：邻居交换「到某前缀多远」，本地做松弛。图课的 [Bellman-Ford](/cs/bellman-ford) 已给出边权松弛；本课把它放到路由器上，并点出无穷计数。

## 问题

静态配下一跳不能跟故障。距离向量：周期性或触发地，把向量 $(前缀, 距离)$ 发给邻居。收到后，经该邻居的距离 = 通告距离 + 链路代价，比现有更好则更新。缺口不是 ICMP，而是这套分布式 BF。RIP 把无穷定为 16，跳数当代价，只适合小域。

本课不把 RIP 认证头写完。

<span class="marginnote">无穷计数：链路断了，A 与 B 互相以为对方仍通，距离加到无穷。毒性逆转、水平分割是补丁，不是证明消失。</span>

<span class="marginnote">术语翻译：距离向量里的「向量」就是一张迷你价目表——每个路由器定期向邻居喊话：「到前缀 P 我这儿距离 3，到前缀 Q 距离 7……」。邻居收到后做一道小学算术：3 加上你到我这条链路的代价，跟我自己表里的数比一比，谁小填谁。</span>

## 方法

初始化：直连前缀距离 0。通告整个向量（或增量）。失效：超时未刷新则置无穷并通告。与[生成树](/cs/spanning-tree)不同：DV 在三层，键是 IP 前缀，允许任意拓扑上的多路径候选，转发仍只装一条或 ECMP。

```mermaid
flowchart TD
  ADV["邻居通告向量"] --> RELAX["经该邻居松弛"]
  RELAX --> TAB["更新 LPM 表"]
  RELAX --> LOOP["坏消息慢: 无穷计数"]
```

## 机制

DV 实现简单，内存只存向量，符合早期线路贵的环境。坏消息慢，是因为没有全局拓扑：断边之后仍可能引用彼此的旧好消息。端到端：路由震荡期间 IP 仍尽力转发，可能环到 TTL 尽，于是 [ICMP 超时](/cs/icmp)出现。传输层看见丢包。

与进程调度无关：这是路由器进程（或内核协议）之间的消息，可用后课 UDP（RIP 正是如此）。

```mermaid
flowchart TD
  OK["A—B 链路正常：A 经直连到网 N 距 1"] --> CUT["链路断：A 本应把 N 置无穷"]
  CUT --> HEAR["A 却收到 B 的旧通告：B 经 A 到 N 距 2"]
  HEAR --> UP1["A 更新：经 B 距 3；B 下一轮学到距 4"]
  UP1 --> CLIMB["两人互相抄作业，每轮各 +2：5、7、9……"]
  CLIMB --> CAP["RIP 上限 16：约 16 个周期后才承认 N 不可达"]
```

这张图回答「无穷计数是怎么滚起来的」：断链后 A 本该宣布距离无穷，但它手里还有 B 的旧好消息——而那条「好消息」当初恰恰是经过 A 学的。两人拿着互相推导出来的旧数继续松弛，每交换一轮距离就涨一截。数字实例：RIP 每 30 秒一轮、上限 16，最坏要 7 分多钟全网才认账，这期间数据包就在两个路由器之间转圈到 TTL 耗尽。

<span class="marginnote">常见误区：初学者容易以为「只要表收敛过，断链后会自动快速收敛到新状态」。距离向量没有全局图，它无法区分「经邻居中转的好消息」和「邻居早就过期的回声」；水平分割、毒性逆转只是挡住最典型的回声路径，环多于两个节点时照样慢。</span>

## 边界

本课不把 EIGRP 的 DUAL 写完，不引入路径向量——那是 BGP 用 AS 路径防环。也不把负权当互联网代价：链路代价为正。全局拓扑与更快收敛是下一课链路状态。

度量若用带宽或延迟，必须保证正且无震荡；RIP 用跳数正是为了简单。触发更新比定期全表更快送出坏消息。

不等间隔的定时器抖动，用来避免同步通告造成的周期性拥塞。

后课默认：邻居向量可填表，但环与慢收敛是代价。通告整图、本地跑最短路，下一课链路状态。

<span class="marginnote">直觉类比区分两族协议：距离向量像只靠邻居转述的传言——你从不知道整张地图，只知道「听说离这儿 5 站」；链路状态像人手一份完整地图，各自在本地跑 Dijkstra。传言便宜但会以讹传讹（无穷计数），地图费带宽但收敛有据——这正是下一课的动机。</span>

## 小结

- 距离向量是分布式 Bellman-Ford，填 LPM。
- 无穷计数；水平分割只是缓解。
- 链路状态用整图对照，下一课。
- 出处：Bellman-Ford；RFC 2453；Kurose and Ross。
