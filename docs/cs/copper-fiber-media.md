# 铜缆、光纤与衰减

<div class="epigraph">
<p>电缆的插入损耗随频率上升，光纤的损耗按波长窗口计价；同一 $C=B\log(1+\mathrm{SNR})$ 里，$B$ 和 SNR 都是介质给的。</p>
<footer>—— 据 TIA/EIA 568 类缆规范；ITU-T G.652 / G.655；Kurose and Ross 物理介质节整理</footer>
</div>

[上一课](/cs/clock-recovery-scrambling)假定符号已经过介质到达 CDR。缺口是**介质本身**：双绞线衰减、串扰、长度；光纤的窗口、色散、弯曲。本课不把可插拔光模块的电气约定写完。

## 问题

香农公式里的 $B$ 不是「我想要的带宽」，而是电缆在可接受损耗下还能用的频段。Cat5e/Cat6A 用类别钉串扰与回波；长度 100 m 是信道模型，不是欧姆定律的推论。光纤：1310/1550 nm 窗口损耗低，多模有模态色散限制距离，单模被色散与非线性限制。铜缆上 PAM-4 对回波敏感，所以要回波抵消——这是 SNR 工程，不是新的 MAC。

无线后课的路径损耗换介质，公式同类：距离吃 SNR。

<span class="marginnote">「光纤无限带宽」是口号。窗口有限，放大器有噪声系数，相干光还有相位噪声。本课只钉衰减与带宽谁在约束 $C$。</span>

<span class="marginnote">dBm 是以 1 mW 为基准的对数功率单位：0 dBm 就是 1 mW，−20 dBm 是它的百分之一。链路预算全程用对数加减，是因为功率从发射到接收动辄差几个数量级，线性数字写不动也算不便。</span>

<span class="marginnote">初学者容易以为 Cat6A「支持 10G」是线芯更粗、能扛更大电流；实际类别钉的是高频段的串扰与回波指标——10G 靠的是在同一根线里挤进更宽的可用频段 $B$，再靠 DSP 把损伤压回去。</span>

### 介质给 $B$ 与 SNR

类别与窗口不是营销标签，而是容量公式的输入。换介质不换 MAC 地址；PCS 把损伤挡在 PHY。延迟主要是距离，不是「光比电快」。

## 方法

对照三栏：介质、主导损伤、典型距离。双绞：衰减 + NEXT/FEXT。多模：模态色散。单模：损耗、色度色散、PMD。画：发射功率 − 损耗 − 余量 ≥ 接收灵敏度，剩余即 SNR 预算。

```mermaid
flowchart TD
  TX["发射功率"] --> LOSS["衰减与串扰"]
  LOSS --> RX["到达功率"]
  RX --> SNR["SNR 进容量"]
```

## 机制

主干[帧](/cs/frame-mac)不关心是铜还是光：PCS 把介质差异挡在 PHY。换介质会换调制与 FEC，MAC 帧格式可保持。这是分层：物理损伤不上浮成 IP 选项。

选择：机房内短距用铜便宜；跨楼用多模；跨城用单模。类别升级是为了给更高 $R_s$ 留 $B$，否则只能降阶或缩短。

```mermaid
flowchart TD
  Q["要选介质"] --> CU["铜缆双绞"]
  Q --> MM["多模光纤"]
  Q --> SM["单模光纤"]
  CU --> CUI["主导损伤：衰减与串扰 · 约 100 m"]
  MM --> MMI["主导损伤：模态色散 · 跨楼数百米"]
  SM --> SMI["主导损伤：色散与非线性 · 跨城公里级"]
```

<span class="marginnote">模态色散可以想象成宽走廊里的人群斜穿：沿中线走的先到，斜着折返的后到，光脉冲被自己「拉宽」，前一个码元就糊进后一个。单模纤芯细到只留一条路径，脉冲形状保得住，距离因此能拉到公里级。</span>
