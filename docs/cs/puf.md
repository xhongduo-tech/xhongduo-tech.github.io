# PUF

<div class="epigraph">
<p>物理不可克隆函数把制造差异变成挑战–响应：像指纹，难复制。它可作设备身份与密钥派生，但可靠性、老化与建模攻击要进合同。</p>
<footer>—— Gassend, Clarke, van Dijk and Devadas, Silicon Physical Random Functions, CCS 2002</footer>
</div>

上一课[故障注入](/cs/fault-injection)用物理手段扰动计算；本课反过来看：**把制造时的物理差异本身当作身份**，替代把密钥存进存储器。本课讲 PUF 直觉，不写建模攻击的步骤。

后课默认已经读完本课钉下的合同，只补差，不从该领域第一性原理重开。

## 问题

密钥存进非易失存储就有被读出的一天——拆封、探针、冷启动都能碰它。PUF 不存：施加挑战，硅片的制造差异（走线延迟、SRAM 上电偏好）决定响应，同一芯片给出稳定输出而其他芯片无法复制；再经模糊提取把含噪响应收成稳定密钥。缺口有三类：响应误码随温度电压漂移、芯片老化改变响应、公开挑战–响应对喂给机器学习后被建模仿冒。

### 不是完善保密

PUF 是硬件身份的候选方案，不是完善保密：没有模糊提取与限次公开挑战，响应表迟早被学穿。

## 方法

方法是把挑战–响应图画清楚，再对照 HSM 存钥：HSM 把密钥封进抗拆外壳，代价是管一个「读不出」的黑盒库存；PUF 的密钥按需从物理派生，不上电就不存在，代价是管误码率与老化。下一课 Spectre 缓解与代价。

## 机制

机制的核心是「身份可以不上电存在」：制造差异在断电时也在，密钥只在需要的一刻被提取，攻击面从「读出存储」变成「预测物理」。模糊提取由纠错与哈希两截组成——辅助数据帮纠偏但不泄露密钥本身；老化则要在生命周期里重登记。微结构泄漏下一课是另一条物理/共享硬件轴。

## 边界

不写建模攻击的步骤；边界要点名：PUF 的可靠性用片内误码率衡量，典型为个位数百分比，正是这个量级的噪声决定了必须配模糊提取。Spectre 缓解下一课。

## 小结

- 故障扰计算；PUF 用差异当指纹。
- 模糊提取把噪声响应收成密钥。
- 老化与建模要进威胁模型。
