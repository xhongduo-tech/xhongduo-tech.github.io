# 率失真

<div class="epigraph">
<p>允许平均失真 $\le D$ 时，每符号最少仍要约 $R(D)=\min I(X;\hat X)$ 比特；$D=0$ 退回熵，JPEG 一类有损从这里量。</p>
<footer>—— 据 Shannon, 1959；Cover and Thomas 整理</footer>
</div>

[上一课](/cs/ldpc-turbo)把逼近容量的码钉到直觉。无损路径从信源定理到 LZ、信道从容量到 LDPC。缺口是**有损**：像素不必精确复原。率失真函数 $R(D)$。本课钉定义与高斯例子，不写编解码器。

## 问题

失真 $d(x,\hat x)$（平方、汉明）。$R(D)=\min_{p(\hat x|x):\ \mathbb{E}d\le D}I(X;\hat X)$。$D=0$ 且 $d$ 为汉明时 $R(0)=H(X)$。高斯、平方失真：$R(D)=\frac12\log(\sigma^2/D)$（$D\le\sigma^2$）。反向：给速率 $R$ 能达到的最小失真。存在性仍随机码；JPEG 量化是启发式逼近，不是 $R(D)$ 的证明。<span class="marginnote">数字实例：取高斯源方差 $\sigma^2=10000$、允许平方失真 $D=100$，则 $R(D)=\frac12\log_2(10000/100)=\frac12\log_2 100\approx 3.32$ 比特/样本。也就是说允许 1% 的相对误差，速率就从「无限」砍到约 3.3 比特——有损压缩的红利主要来自头几个比特。</span>

<span class="marginnote">直觉类比：把 $R(D)$ 想成一条「预算换保真度」的价目表——预算 $D$ 是你愿意忍受的模糊程度，$R(D)$ 是照这个模糊度做买卖的理论最低价。实践编解码器（JPEG、Opus）是这个价目表的采购报价，只会贵、不会低于它；报价低于价目表，说明合同（失真度量）被偷换了。</span>

与容量：信道是固定 $p(y|x)$ 选 $p(x)$；率失真是固定 $p(x)$ 选「试验信道」$p(\hat x|x)$。对偶。

### 失真不是「看起来差不多」

必须先约定 $d$。感知上好的图可能平方误差大。本课不进视觉模型。

<span class="marginnote">Shannon 1959 率失真。Cover–Thomas 第 10 章。Berger 的书。本课不证着色、高分辨近似全文。</span>

## 方法

画 $R(D)$ 下降曲线。指出：量化器 + 熵编码是实践上界，未必等于 $R(D)$。向量量化以块逼近。不要把压缩比写成 $R(D)$——缺 $D$ 的数。

```mermaid
flowchart TD
  X["信源 X"] --> D["允许失真 D"]
  D --> RD["R(D)=min I(X;X̂)"]
  RD --> LOSSY["有损码速率下界"]
```

## 机制

信息单元的无损/有噪/有损三块至此齐：下界分别是 $H$、$C$、$R(D)$。下一课 KL 把「用错模型」的额外比特钉成相对熵，给交叉熵与最大熵铺路。

$R(D)$ 不可计算一般形式；构造性仍难。本课当尺子。

反向水灌：高斯独立分量把速率分给方差大的轴。高分辨量化：$R(D)\approx h(X)-\log D+$ 常数。实践：变换 + 量化 + 熵编码给出 $R(D)$ 的上界。没有 $d(\cdot,\cdot)$ 的数，谈不上「压了多少信息」。

```mermaid
flowchart TD
  S["高斯独立分量：方差有大有小"] --> B["给定总失真预算 D"]
  B --> C{"该分量方差是否超过 D？"}
  C -->|"否，方差小于等于 D"| N["该轴直接置零，不花比特"]
  C -->|"是，方差大于 D"| W["该轴吸收失真 D，只留 σ²-D"]
  W --> R["该轴速率 ½ log(σ²/D)"]
  R --> T["大方差轴拿走绝大部分比特"]
```

<span class="marginnote">常见误区：初学者容易把「压缩比 10:1」当成信息论结论。压缩比只说了输出/输入的比特数之比，没说失真 $D$ 是多少、也没说 $d$ 是什么——同一压缩比下，压人脸和压噪声图的信息含量完全不同。只有带上失真度量的 $R(D)$ 才是有意义的下界。</span>

## 边界

本课不写 JPEG 标记，不引入感知编码标准。不把大模型的重建损失当 $R(D)$。后课默认：有损的信息下界是 $R(D)$。下一课 KL 与交叉熵。

$D=0$ 回到无损 $H$；允许失真后 $R(D)$ 下降。没有事先约定的 $d$，有损比没有信息论意义。实践编解码是上界，高斯平方给出少数闭式。

## 小结

- $R(D)$ 是失真 $D$ 下的最小互信息速率。
- $D=0$ 回到无损熵；高斯平方有闭式。
- 实践编解码给出上界，不是定义。
- 出处：Shannon, 1959；Cover and Thomas。
