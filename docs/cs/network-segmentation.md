# 网络分段

<div class="epigraph">
<p>扁平二层让一次失陷走遍。分段把主体与客体放进不同可达性域：管理网、生产、用户、访客。零信任不取消分段，分段降低爆炸半径。</p>
<footer>—— 据 Saltzer 最小特权；NIST SP 800-207 与分段的关系；对照[VPN 对零信任](/cs/vpn-zero-trust)</footer>
</div>

上一课[扫描](/cs/port-scanning)列出开着的口。缺口是**即使口开着也不该从该区连到**。本课讲 VLAN、防火墙域、微分段，不写打通隔离的步骤。

后课默认已经读完本课钉下的合同，只补差，不从该领域第一性原理重开。

## 问题

ARP 课已说明同 L2 危险。生产数据库不应与访客 Wi-Fi 同域。缺口是策略：默认拒绝跨段，显式允许。

### 东西向

数据中心内部流量常被忘。微分段把策略落到工作负载。

<span class="marginnote">Anderson 对扁平网络。禁止逃逸分段教程。默认配置下一课是主机层。</span>

<span class="marginnote">直觉类比：分段像办公楼门禁——电梯谁都能坐（网络可达），但每层门口要刷卡（策略判定）。「口开着」只是电梯到了这层；刷卡不通过，依然进不了门。</span>

## 方法

画区：用户、应用、数据、管理。对照零信任：分段是网络实现最小特权的一种。下一课默认配置加固。

<span class="marginnote">术语翻译：微分段就是用「给每台工作负载单独规定谁能连它」的手段来做「把数据中心内部的东西向流量也管起来」的事——VLAN 分段只在大楼之间砌墙，微分段把墙砌到每个工位。</span>

## 机制

可达性是授权的物理近似。仍要应用 BOLA。默认口令下一课常让分段形同虚设。

```mermaid
flowchart TD
  A["访客区主机发起连接"] --> B["目标：数据区数据库"]
  B --> C{"匹配到跨段允许规则？"}
  C -->|"没有"| D["默认拒绝：丢弃"]
  C -->|"仅 5432 显式允许"| E["放行并记日志"]
  D --> F["爆炸半径被压在本段内"]
```

这张图回答：一条跨段连接是怎么被判定的。默认拒绝是底色，逐条匹配显式允许；没有规则就丢弃，把失陷后的横移堵在段边界上。

<span class="marginnote">常见误区：初学者容易以为「划了 VLAN 就等于安全」。若段内主机全是默认口令、段间又留着一条宽允许规则，攻击者照样先落脚再横移——分段缩小爆炸半径，并不消灭失陷本身。</span>

## 边界

不写跨 VLAN 攻击。扁平二层仍会把 ARP 课的映射问题放大。默认配置加固下一课。
