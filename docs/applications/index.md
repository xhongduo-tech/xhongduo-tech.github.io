# 检索、工具与多模态

这一组是待学习的横向主题，用来检验对模型、训练和服务系统的理解。通过有边界的小实验逐步深入，并复用共用的评测协议。接通API、搭建界面与掌握机制分别验收。

## 先区分增加了什么能力

| 方向 | 增加的环节 | 应掌握的问题 | 深入入口 |
| --- | --- | --- | --- |
| RAG | 在生成前获取外部证据 | 是没有检索到，还是拿到证据仍答错？ | [检索与工具调用](/applications/retrieval-agents) |
| 工具调用与agent | 让模型选择外部动作并读取反馈 | 参数是否正确、权限如何执行、何时停止？ | [检索与工具调用](/applications/retrieval-agents) |
| 视觉语言 | 把图像变为可被语言模型使用的表示 | 编码器、连接层、视觉token与监督怎样连接？ | [多模态机制与成本](/applications/multimodal) |
| 音频与视频 | 加入时间、采样与跨模态对齐 | 音频特征/帧数如何影响任务与成本？ | [多模态机制与成本](/applications/multimodal) |

RAG论文将参数化生成器与外部检索记忆结合，也包含查询编码器与生成器的联合微调。本路线的首个小实验采用冻结模型的检索增强推理，分别观察检索与生成，不把它称为原论文训练流程的复现。[原论文v4](https://arxiv.org/abs/2005.11401v4)提供机制起点，现代工程流水线的配置仍需单独实验。

## 学习依赖与实施顺序

1. 在[模型基础](/foundations/)和[评测方法](/evaluation/)中弄清输入token、输出与评分。
2. 用小型公开语料建立检索与生成分离的基线，先看逐题证据和错误。
3. 增加一个只读工具，记录参数、结果和终止状态；再比较固定工作流与模型选择动作的差异。
4. 理解SFT的模板和监督后，阅读视觉编码器与连接层，先做输入处理与形状实验。
5. 各分支完成自己的基础与小实验后再扩展：检索/工具走向多步任务，视觉/音频走向相应真实模型。不要求先做RAG或Agent才能学习VLM；训练和复杂多agent系统不作为入门门槛。

ReAct给出交替使用推理与动作的研究路径；Anthropic的工程文章区分固定工作流和模型自主控制流程，并提醒复杂度会增加延迟与成本。这里采用这些概念安排对照，不把任何一种模式预设为更优。[ReAct v3](https://arxiv.org/abs/2210.03629v3)、[Building effective agents](https://www.anthropic.com/research/building-effective-agents)

## 共享验收要求

每个主题至少留下一张数据流图、一份固定样本协议、一个消融对照和一类失败解释。对应用系统同时报告任务成功、证据或动作正确性、端到端延迟与资源消耗；必要时回到[质量与服务实验](/evaluation/quality-systems)统一口径。

只做CPU模拟时，结论限定为机制与程序行为；调用真实模型时，保存模型/接口版本和逐样本输出；租赁硬件时，追加实际硬件与费用。本站尚未记录这组主题的个人实验结果。

核验日期：2026-11-16。上述论文使用明确版本；Anthropic文章发布于2024-12-19，其页面已提示工具生态发生变化，这里仅引用其工作流与agent的架构区分，不把旧工具列表视作当前推荐栈。
