硬烤与 UV 固化 ​

硬烤提高模量、赶尽溶剂，让胶扛得住开口等离子体；UV 固化走交联，热预算可以更低。

—— 对照 post-develop hard bake / UV cure 在转印前的公开用途

上一课清完渣。缺口是膜还软：主刻蚀、真空、电子束量测都会流胶或放气。本课钉硬烤与 UV 固化，不写剥离灰化。

问题 ​

软烤只为曝光。显影后聚合物网络更开、溶剂和显影液残余仍在。不硬化：刻蚀中流、倒塌阈值低、SEM 收缩（CD-SEM 收缩）。烤太高：图形圆化、CD 涨、甚至裂。需要一条「转印前热/光」预算。

为什么重要：没赶尽的溶剂和显影液一旦进了真空腔（CD-SEM、电子束检测），会边抽边放气，既污染腔体与镜面，又让量测读数漂移。硬烤不只是「让胶硬点」，它是量测和刻蚀设备能吃饱干净活的前提。

方法 ​

热板硬烤：温度低于分解、高于软烤，时间分钟级。UV（宽带或 172 nm 一类，以设备公开能力为准）诱发交联，可降热。金属氧化物胶的硬化化学不同，不要套 CAR 的温度表。固化后再量 CD，才是给刻蚀的合同尺寸。

直觉类比：线性高分子像一袋煮熟的散面条，一推就互相滑动（流胶）；交联是把面条彼此勾成网兜，受力由整张网分担，形状就定了。硬烤用热、UV 用光子来「打结」，两条路通向同一张网。

UV 固化对深层胶的穿透有限，厚 SOC 不能指望一次 UV 烤透。分层固化或只固化成像层。

机制 ​

交联与致密化提高 \(E\)，毛细与等离子体下的变形变小。体积收缩改 CD 与应力。光酸若还在，高温会继续反应——与 PEB 不同，这是图形已形成后的二次反应，可能糊边。

术语翻译：模量 \(E\)（杨氏模量）就是「胶有多硬」的数值——越大越接近硬塑料，越不容易被毛细力或等离子体压弯。软烤后的胶像橡皮糖，硬烤交联后像塑料尺；图形敢下等离子体腔，靠的就是这一跳。

边界 ​

下一课轨道–扫描仪联机：硬化在 track 上，曝光在 scanner 上，时间线要对上。

小结 ​

  • 硬烤/UV 是转印前的力学与放气预算。
  • 过热糊边；过低流胶。合同 CD 应在固化后量。
  • 出处：hard bake / UV cure 工艺通识。
