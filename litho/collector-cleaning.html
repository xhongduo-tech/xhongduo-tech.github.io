收集镜清洁与恢复 ​

氢能把镀上的锡刻成氢化物抽走；溅射坑和中频粗糙补不回去。清洗是恢复反射率曲线上那一段可逆的脏，不是让收集镜永生。

—— 对照 ASML 对收集镜氢清洗与更换的公开讨论；Bakshi 污染化学

上一课把 IF 往更高瓦数推。缺口立刻落到第一面牺牲光学：功率越大，锡质量流和热负荷越大，\(R_{\mathrm{col}}(t)\) 掉得越快。 收集镜寿命 已经把镜子写成消耗品；本课补的是原位清洁与可恢复到哪一步。洗完仍留下的粗糙与散射，交给下一课。

问题 ​

寿命课区分「洗得动的累积」和「洗不动的累积」。功率路线把前者的速率加大：更多脉冲、更多蒸汽、更热的帽层。若只换镜不洗，可用性被更换吃掉，1 kW 广告没有意义。若只洗不换，微滴坑和周期损失把光瞳填变形，剂量环加激光也补不回对比。

缺口是清洗通道与恢复判据，不是再列一次离子/蒸汽/微滴。氢自由基把 Sn 变成 SnH₄、把碳变成 CH₄，这是 DGL 的化学；收集镜上还要问：流量、温度、EUV 自身解离如何构成闭环，以及何时宣布「恢复失败、整镜更换」。

收集镜可牺牲地洗；投影物镜以防为主。本课的恢复对象是椭球收集器，不要把同一套自由基流量灌进六镜 POB。

方法 ​

原位：光源舱维持足够氢分压，EUV 光子解离 H₂，帽层（常见钌）上的薄膜锡被刻走。镜子温度是第二执行器——太冷，反应慢；太热，膜系应力和周期漂。流量过大，\(T_{\mathrm{gas}}\) 吃带内功率，等于用透过率换干净。闭环观测量是 IF 带内功率、光瞳填充和剂量稳定度，不是「镜子看上去亮不亮」。

离线恢复属于供应商：再清洗、再镀、再抛。晶圆厂合同是更换窗口与再资格认证，把光瞳和杂散光重新纳入照明规格。磁场碎屑抑制、预脉冲碎屑谱是源头减载，不能被清洗替代；清洗减的是已经落到膜上的可反应层。

恢复成功的判据是光瞳，不只是瓦数 ​

剂量环加激光可以把平均 IF 拉回合同。径向污染洗不均时，椭球不同环带的贡献比变了，σ 图变形。SMO 用的照明设置随之失效。因此「洗完」必须同时过带内功率和光瞳传感器；只过功率，对比指纹会在下一层产品上出现。

机制 ​

可逆通道是化学：Sn + 4H → SnH₄。自由基主要来自 EUV 光解离和等离子体边缘，不是把整腔加热到热裂解。惰性缓冲可以减速离子，但不把锡变成可抽气体——只吹氦，镜子照样镀上。不可逆通道是物理：高速微滴的 splats、高能离子溅射把多层周期打乱、界面混杂，反射率的角谱和散射底座一起变。过激清洗还会氧化或剥蚀钌帽，把「洗锡」变成「洗镜子」。

恢复判据因此是光学合同，不是表面锡的 XPS 零。光瞳环带若因径向污染不均而变形，平均 \(R\) 看起来尚可，SMO 用的那张 σ 已经不是出厂图。功率越高，越要在「洗得勤」和「洗得过」之间取点。

ASML 把清洗写进光源可用性，不公布 SCCM 与缝宽。写机制即可：可逆化学、不可逆溅射、IF/光瞳双判据。

边界 ​

本课不重写 DGL 气锁几何，不编造更换小时数。下一课从「洗不动的那一层」进入多层粗糙与带内散射——投影镜同样有 MSFR，来源换成抛光和镀膜，不是锡坑。出处：ASML 收集镜清洗与可用性；Bakshi 氢刻锡/碳；寿命课的可逆/不可逆划分。

小结 ​

  • 清洗恢复薄膜锡和碳；微滴坑与溅射周期损失要靠换镜。
  • 氢流量是清洗与 \(T_{\mathrm{gas}}\) 的折中，温度和帽层化学是同一窗口。
  • 更高 IF 功率把清洗从可选项变成产能旋钮。
  • 出处：ASML 收集镜公开讨论；Bakshi；收集镜寿命。
