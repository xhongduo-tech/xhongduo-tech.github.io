Step-2 / StepFun ​

Step-2 是阶跃星辰 2024 年交出的万亿参数 MoE 语言旗舰：预览在 3 月，正式版在 WAIC；没有与 Hunyuan-Large 同规格的综合 arXiv，公开信息停在架构选择与评测名次。

—— 阶跃星辰 WAIC 2024 及后续官方/专访公开说明；Step-3 系统报告 arXiv:2507.19427 属后代开源线，不逆写进 Step-2

阶跃星辰（StepFun）的语言旗舰 Step-2 是国内创业公司较早公开的 万亿参数 MoE。2024 年 3 月预览，7 月世界人工智能大会发正式版，C 端「跃问」接入。团队在采访里强调：多数 MoE 是「从稠密改稀疏」；他们选择 从头训 MoE，并用部分专家共享、异构专家等自研设计，使 每次激活的参数量仍大于市面多数稠密模型。LiveBench 等公开榜上，正式版曾报国产基座第一、进入全球前列——这些是榜单快照，须钉日期。本篇只写 Step-2 已见诸发布会与报道的句子；后来开源的 Step-3（321B 总 / 38B 激活，MFA 注意力）另有系统报告，不能把 MFA / AFD 写成 Step-2 的模块。

问题 ​

万亿稠密训不起、也服不起。MoE 把总参数撑到万亿，理论上用激活换吞吐；但若专家切得像「小稠密拼盘」且从已有稠密热启动，上限会被稠密先验卡住。阶跃把问题定义成：在创业公司算力下，是否值得付 从零训 MoE 的稳定性代价，换更高的指令遵循与知识上限。

第二个问题是全家桶节奏：同一窗口还发 Step-1.5V（多模态理解）与 Step-1X（图像生成）。语言旗舰必须在数理、代码、中英知识、指令上「体感逼近 GPT-4」（WAIC 口径），而不能把多模态分数算进 Step-2。工程上，万亿 MoE 需要他们自称突破的 6D 并行、极致显存、自动化运维——这些是系统口号，没有开源实现细节。

万亿是总参数叙事 ​

公开材料反复说「万亿参数语言大模型」，没有给出与 Hunyuan-Large 那样的「总/激活/专家数」表。激活「大于多数 Dense」是相对语言，不是 52B 或 32B 那种可引用整数。写 Step-2 禁止填入未公布的专家个数。

Step-2-mini 等 API 档位出现在第三方价目表，官方未配套技术报告。本篇不以聚合站的「100B token」或单价反推结构。

方法 ​

能写的方法层来自发布叙事，不是公式。

架构选择：稀疏 MoE；部分专家共享参数；异构化专家，使每个专家得到充分训练；从头训练而非稠密改 MoE。共享专家的动机与混元 / DeepSeek 公开论文同类——捕获公共知识——但阶跃 没有 公布共享个数与 top-\(k\)。异构专家意味着不同专家容量或结构可以不同，具体差在哪一项未披露。

训练系统：专访称 Step-2 训练中突破 6D 并行、显存管理与全自动运维。6D 一般指数据/张量/流水/序列/专家/上下文等维度的组合，但阶跃未给出并行度表或 MFU。数据规模、清洗、是否合成、上下文窗口 未在 Step-2 专文中给出。不要用后来 Step-Audio / Step-3 的数据小时数或 64K 窗去填。

产品化与评测快照 ​

正式版对标的能力轴：数理逻辑、编程、中文知识、英文知识、指令遵循。载体：跃问 App 与网页。LiveBench 快照（报道当时）：国产第一、全球约第五，接近 o1-mini 一档、超过部分 GPT-4o / Gemini 1.5 Pro 日期版本。复述时必须保留「某日榜单」，因为 LiveBench 滚动。

同场发布的 Step-1.5V、Step-1X 说明公司走语言 + 理解 + 生成三条线，但评测不可加总。Step-2 预览到正式版间隔约百日，迭代发生在闭源侧，社区看不到中间检查点。

后代开源不能前向污染 ​

2025 年 Step-3 开源多模态推理 MoE：总参数约 321B（VLM）/ 316B（LLM）、激活 38B，48 专家选 3 + 1 共享，上下文 65536，注意力 MFA（Multi-Matrix Factorization Attention），并与 AFD 做系统共设计（arXiv:2507.19427）。这证明阶跃后来愿意开结构，也反衬 Step-2 当时选择不公开。读 Step-2 只可写「后续存在开源 MoE 线」，不可写「Step-2 使用 MFA」。

机制 ​

从头训 MoE 的机制主张是：路由与专家从随机初始化共同学习，避免「稠密 FFN 切开后专家同质」。共享专家降低每个 token 对路由运气的依赖；异构专家让容量分配可以非均匀——这在 GShard / DeepSeekMoE 公开文献里有同类思想，阶跃的增量是 规模到万亿且不给公式。激活大于稠密，意味着 decode 的矩阵乘并不便宜，万亿叙事卖的是总记忆，不是「比 7B 还快」。

6D 并行是把专家并行加进常规 3D，通信模式变成 All-to-All。没有他们的拓扑与容量因子，无法分析是否丢 token。因此机制节只能停在「这是大规模 MoE 的标准工程问题，官方声称解决了」，不能画他们的气泡图。

「体感逼近 GPT-4」是 WAIC 产品句，不是盲测论文。与 LiveBench 名次一起引用时要分开：一个是主观，一个是特定基准。

边界与工程取舍 ​

Step-2 权重未开源，API 以 platform.stepfun.com 当时目录为准。安全、上下文长度、tokenizer、是否 GQA 均未在 Step-2 材料中给出。音频线见 Step-Audio 2 报告（2507.16632），与语言旗舰无关。不要用极客公园转述替代论文；转述只用来还原官方已说的架构选择。

创业公司闭源旗舰的正确读法：把 LiveBench 当存在性证明（模型可被第三方测），把 MoE/万亿/从头训当设计宣言，把层表留给 Step-3。

若某次 API 更新把模型名改成 Step-2-mini 或思考版，没有新报告就不要继承万亿 MoE 那一套形容词。

小结 ​

  • Step-2：2024 年万亿参数 MoE 语言旗舰，从头训、共享 + 异构专家，正式版服务跃问。
  • 公开信息无总/激活对照表、无数据配方；评测须钉 LiveBench 等日期快照。
  • Step-3 的 MFA 与 38B 激活属于后代开源，不写入 Step-2 结构。
  • 出处：阶跃星辰 2024 WAIC 与官方访谈；Step-3 系统报告 arXiv:2507.19427 仅作世代边界。
