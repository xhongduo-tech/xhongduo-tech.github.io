大模型 · 2026-09-03

Self-Extend ​

也许现成的语言模型已经是长语言模型：不必调权重，只要把远处的相对位置按组折叠，短窗口里学到的几何就能覆盖更长的输入。

—— Jin 等，LLM Maybe LongLM: Self-Extend LLM Context Window Without Tuning，2024

位置插值把所有下标除以 \(s\)，高频邻域被压糊，通常还要短续训。LM-Infinite 把中间历史直接从可见集里拿掉。Jin 等人 2024 年的 Self-Extend 走第三条训练免费的路：近邻仍用真实相对位置，远处 token 共享分组后的位置，于是大跨度被映射回模型在训练长度 \(L\) 内见过的 \(\Delta\) 网格，而中间内容仍然参加注意力。标题里的 Maybe LongLM 是一个主张——长程能力有一部分已经写在短窗权重里，缺的是推理时的位置重编号，不是另一轮预训练。

问题 ​

RoPE 点积只看见相对距离 \(\Delta\)。训练时 \(\Delta\in\{0,\ldots,L-1\}\)。推理序列长度为 \(L'\gg L\) 时，中间与文首的 \(\Delta\) 出界，分数变成噪声，模型表现为重复或失忆。若用线性插值把所有 \(\Delta\) 除以 \(L'/L\)，出界消失，但「差 1」和「差 4」在高频维上挤在一起，精确复制、局部指代变差，且往往需要微调来适应被压慢的谱。

能否不改权重、也不丢掉中间键，只改 \(\Delta\) 的编号，让远端用低分辨率、近端用原分辨率？这就是 Self-Extend 的问题。它针对已经训好的 RoPE 解码器，在一次长前向里要同时保住局部流畅和「至少以粗粒度看见整篇」。不涉及流式 KV 常数化——默认仍是对当前可见集做注意力，只是位置 id 被重写。训练免费是约束：分组大小与邻窗是推理超参，不是学出来的压缩器。超参选错会要么仍然 OOD，要么把整篇折成太粗的几格，检索粒度直接坏掉。

方法 ​

邻窗真实、远处分组 ​

设邻窗 \(w\)、组大小 \(g\)。查询在 \(p\)，键在 \(k\le p\)，真实距离 \(d=p-k\)。映射后的相对位置为

\[\Delta'(d)=\begin{cases} d & d<w\\ w+\bigl\lfloor(d-w)/g\bigr\rfloor & d\ge w \end{cases} \]

\(d<w\) 的边与短窗训练完全同构。\(d\ge w\) 的边把 \(g\) 个连续 token 折成同一个阶梯，阶梯宽度为 1 个「分组位置」。只要

\[w+\bigl\lfloor(L'-w)/g\bigr\rfloor < L \]

所有 \(\Delta'\) 仍落在训练支撑内。\(g\) 越大，能覆盖的 \(L'\) 越长，远端分辨率越差。这是明确的交换，不是隐藏超参。

只改位置，不改掩码形状 ​

Self-Extend 默认仍允许 \(q\) 看见所有 \(k\le p\)（或实现里再叠滑窗）。它不是稀疏图案论文。计算量仍可到 \(O(t^2)\)，换来的是中间键以分组相位参与 softmax。工程上常与 FlashAttention 的自定义位置 id 接口接到一起：传入的是 \(\Delta'\) 对应的绝对位置重编号，而不是改 \(\theta_i\)。

两段邻居的直觉 ​

可以把序列看成「高分辨率当前句 + 低分辨率前文摘要轴」。摘要轴不是学出来的向量，而是位置通道上的分箱：同一组内的键相位相同，只能靠内容向量分出胜负。组边界对齐词、句还是任意 \(g\) 个 token，论文用固定 \(g\)；按语义切组会引入不可复现的预处理，一般不这么做。

机制 ​

机制是对相对位置轴做分段线性的不可逆压缩。近端斜率 1，远端斜率 \(1/g\)。RoPE 的每一维 \(\cos(\theta_i\Delta')\) 因此在远端变慢，类似于只对远距做了位置插值，近距完全没插。这比全局 PI 更护局部任务，又比 Λ 形多保留了中间键的内容通道。softmax 仍然在全部（或窗内全部）键上归一化，所以中间噪声键会来抢质量——分组并不自动等于检索。

与 YaRN 的分工：YaRN 改的是频率 \(\theta_i\) 与注意力温度，通常配合续训，可见集仍是全前缀；Self-Extend 改的是 \(\Delta\) 的整数编号，权重冻结。二者可以叠，但叠完很难归因，评测应先单独报 Self-Extend。与 Dual Chunk Attention 的差别是：Self-Extend 是全局一条阶梯函数；DCA 按块分别定义块内、块间、相邻块的位置，块内保持完整 \(L\) 分辨率，而不是一条从 \(w\) 开始的斜坡。\(g\) 与 \(w\) 要用 NIAH 深度维来扫。只看 PPL 会偏向更大的 \(w\)（局部更舒服），把针放在分组区时准确率可能已经随 \(g\) 恶化。超参选择应同时看近邻任务和中间针。

映射必须对 \(q\) 和 \(k\) 成对一致。若只改查询位置、键仍用真实 \(p\)，相对几何无定义。缓存里的位置 id 应存映射后的值或存原始 \(p\) 再在注意力时现算 \(\Delta'\)，两套不能混。

边界与工程取舍 ​

Self-Extend 不降低二次复杂度。128k 全注意力照样贵，只是相位不再随机。要常数 KV 仍需滑窗或压缩记忆。分组还引入对齐噪声：针若落在组内某处，位置通道无法告诉模型「是组里的哪一句」，只能靠内容匹配。\(g\) 很大时，行为接近「有一个很粗的远处桶」，检索退化为词重叠。

对已经用 YaRN 续训到 \(L'\) 的模型再套 Self-Extend，等于对已经缩放过的相位再折叠，容易过度压缩。应只在「权重停在原 \(L\)、今天就要吃更长输入」时启用。ALiBi、NoPE 没有同一套可折叠的 \(\Delta\) 旋转，方法不适用。

另一条边界是评测诚实：训练免费延窗很容易在 PPL 上好看——远端被折回熟悉的 \(\Delta\)，困惑度不会炸。RULER 的多跳和 ∞Bench 的篇章题仍可能失败，因为模型从未在那种距离上做过推理，只是现在「算得动」。Self-Extend 延长的是几何覆盖，不是自动延长算法能力。需要多跳时，应把它当成让模型「看得见」的补丁，再决定要不要检索或续训，而不是当成长程推理已经齐备。

实现时最常见的 bug 是把 floor 写成对绝对位置 \(p//g\) 再相减。那会让近邻也被分组，局部流畅一起糊掉。公式必须先分支 \(d<w\)，再对超出部分做 floor。

小结 ​

  • Self-Extend 在推理时把远相对位置按组折叠，近邻保持真实 \(\Delta\)，从而无需微调即可延窗。
  • 覆盖长度由 \(w\)、\(g\)、\(L\) 的不等式约束；\(g\) 换的是远端分辨率。
  • 中间键仍参加注意力，这是相对 Λ 形方案多出来的内容通道。
  • 不降低 \(O(t^2)\)，也不把长程推理能力凭空注入短窗模型。
  • 与全局 PI 相比更护局部；与 YaRN 相比不改频率、默认不续训。
  • 超参要用中间深度的检索任务来选，不能只看 PPL。
  • 出处：Jin 等，LLM Maybe LongLM: Self-Extend LLM Context Window Without Tuning，2024；对照 Chen 等位置插值（2023）、Han 等 LM-Infinite（2023/2024）。
