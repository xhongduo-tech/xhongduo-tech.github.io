指令数据来源与清洗 ​

指令数据不是「任何看起来像问答的文本」；来源决定题面分布，清洗决定哪些监督被允许进入交叉熵。

—— 对照 InstructGPT 的标注示范、Self-Instruct 的自举合成、LIMA 的精选、以及 ShareGPT 与 OpenHermes 两类公开混合物

基座会续写，不会按产品意图回答。SFT 把「题面→回答」写成可学习的条件，于是数据从哪里来、留下什么，直接变成模型的任务定义。Ouyang 等人的 InstructGPT 用标注员按指南写示范；Wang 等人的 Self-Instruct 用模型从种子任务生成指令与实例；Zhou 等人的 LIMA 只用约一千条人工精选。公开生态里，ShareGPT 提供真实用户与 ChatGPT 的多轮日志，OpenHermes 一类则把大量 GPT-4 合成与社区集拼成可下载的混合物。四条路不是互斥的，但混在一个目录里却不做来源标签与清洗，等于把标注指南、教师口吻、用户牢骚和种子任务的偏置平均进同一个损失。本篇谈来源分类与清洗该删什么；人写与合成的对比见 下一篇，多轮字段见 多轮格式。

问题 ​

指令题面的分布极不自然。网页预训练里少有「把这段改成正式邮件」「用三步证明」这类显式请求。若 SFT 只来自单一渠道，模型会把该渠道的题型当成「指令」的全部。标注示范覆盖产品用例，但贵、慢、容易写成标注员腔。社区日志覆盖真实措辞，但含 PII、越狱、残缺代码、教师拒绝模板。合成数据便宜、易扩覆盖，但句式重复、难度虚高或虚低、并继承教师的事实错误。LIMA 证明质量可以替代数量，并不证明随机抓一万条论坛帖与一千条精选等价。

清洗面对的不是预训练那种「这页是不是句子」，而是「这轮监督是否应当被模仿」。一条语法完美的谄媚回答、一条正确但泄露出标注员内部工具路径的回答、一条把用户隐私复读一遍的回答，启发式可读性过滤都不会挡。必须按来源设规则：对人写示范查指南符合度；对 ShareGPT 查结构与泄漏；对 Self-Instruct 查与种子的重复以及是否真是可执行的题面。

四类来源不要压成一个文件夹 ​

标注示范：InstructGPT 的 SFT 阶段。题面可来自真实用户，回答由受训标注员写。优点是与奖励模型、安全政策同一套指南，缺点是规模小、风格偏职业客服。社区会话：ShareGPT。优点是多轮、口语、真实追问；缺点是教师固定为当时的闭源助手，许可与隐私含糊，质量长尾极差。精选小集：LIMA 从社区问答、wikiHow、作者自写等处挑约一千条，强调多样性与示范质量。合成与汇编：Self-Instruct 从 175 条种子自举数万指令；OpenHermes 把多个合成集与公开指令集汇编，规模大、来源杂，适合做覆盖，不适合当金标准。训练清单里每条样本应带 source，否则出了谄媚或拒答过当，无法回溯该下调哪一个桶的采样率。

OpenHermes 不是一篇方法论文，是社区汇编；ShareGPT 也不是。把它们写进数据卡的方式应是「混合物、教师、大概领域」，而不是伪造一篇「OpenHermes: arXiv」。对照实验时，它们是来源锚点，不是算法锚点。

方法 ​

管道按层叠，先结构后语义。结构：解析为 messages，丢掉角色无法识别、助手轮为空、轮次交错错乱的记录；合并连发；统一语言字段。长度：过短的「好的」「谢谢」不提供监督；过长且无结构的粘贴（整本日志、整页 HTML）要么截断策略明确，要么丢弃。去重：题面近重复用 MinHash 或规范化后的字符串，避免 Self-Instruct 式生成把同一模板微扰成五千条、梯度被该模板霸占。LIMA 的精神在清洗里体现为：重复比缺失更有害，因为交叉熵会把高频示范当成任务定义。

语义与安全：PII（邮箱、电话、密钥、内部 URL）删除或丢样本；用户明显在做越狱且助手配合的，按安全政策丢掉或改写，不要靠事后 安全配比 去「平均掉」——配比处理的是比例，清洗处理的是单条是否可学。事实：对代码跑语法或单测，对明显过时的价格、版本号降权；合成数据里教师胡编的比例通常高于标注示范，抽检预算应向合成桶倾斜。模板：同一训练集只保留一种即将用于推理的角色渲染方式，或全部保持结构化、训练时再渲染，禁止一部分样本自带 ChatML、另一部分自带 Markdown「Human:」。

采样不要在清洗后变成均匀。标注与 LIMA 式精选可以上采样；ShareGPT 按对话做截断后仍可能很长，应按对话而不是按 token 风暴来计权重；OpenHermes 内若某一子源已经很大，要先在汇编内部降权再与其他桶混。InstructGPT 并未靠把互联网论坛一股脑倒进 SFT 取胜；公开复制若以 ShareGPT+OpenHermes 为默认，应承认这是成本约束下的近似，不是原论文配方。

清洗要删的不是「不像指令」的页 ​

预训练质量过滤删内容农场；指令清洗删的是错误的监督。用户题面可以像指令也可以像胡话——胡话题面若配有正确的拒绝或澄清，反而是有用样本。应删的是：助手轮与题面无关、助手轮教人做明确危害且政策不允许、助手轮只复读题面、题面与回答语言错配到不可学、以及教师指纹过重的套话（「作为人工智能语言模型」出现在每一条）。Self-Instruct 论文里用启发式过滤低质量生成（过短、重复、与种子过近），这是合成桶的最低标准，不能省略。对人写数据，过滤过严会把语气生动的示范删光，留下清一色的标注员腔，对齐税会变成「只会客服」。

机制 ​

清洗改变的是 SFT 的经验测度 \(p_{\mathrm{sft}}(x,y)\)。去重降低某些 \(x\) 的质量，使梯度不再被模板霸占；PII 规则把一部分 \(y\) 从可模仿集合里拿掉；来源采样改变各桶的混合比。模型学到的条件 \(p_\theta(y\mid x)\) 是这个测度下的下一 token 平均，不是「指令」这个抽象概念。因此「数据脏」的机制永远是：某个不想模仿的 \(y\) 在测度里质量太大。ShareGPT 里 ChatGPT 的拒绝模板若未降权，学生会在同类题面上复制那套拒绝，哪怕基座原本会直接回答。OpenHermes 里某类 GPT-4 思维链若占优，学生会在简单事实上也强制逐步推理。

Self-Instruct 的自举还有一层放大：生成器的偏置变成下一轮种子。未充分去重时，测度会塌缩到种子任务的邻域，表面上条数很多，有效任务族很少。LIMA 走相反机制：人为保证任务族覆盖，条数极少，每条在测度里的质量都高，模型学的是「如何像示范那样回答各类题」，而不是「如何复读一万条相近的邮件改写」。InstructGPT 在标注指南上花的成本，等价于在采样之前就把 \(p_{\mathrm{sft}}\) 的支撑限制在政策允许的回答上。

泄漏是清洗的隐形项。评测题面若出现在 ShareGPT 或合成集里，SFT 分数会虚高。去重应包含与评测集的近重复，而不是只在训练集内部做。教师模型若在评测榜上刷过同样的题，合成回答可能直接带着榜题答案进来。

来源标签使配比可调 ​

没有 source 字段，事后发现代码变差，无法判断是 OpenHermes 某子集的错误代码，还是 ShareGPT 里太少代码。机制上，分桶采样是在若干 \(p_k\) 之间做凸组合 \(\sum \lambda_k p_k\)。\(\lambda\) 只能作用在已定义的 \(k\) 上。清洗阶段的任务之一就是定义 \(k\)：语言、是否多轮、是否安全、是否代码、来源。桶定义得太粗，配比旋钮会空转。

边界与工程取舍 ​

清洗不能从无标签的互联网还原 InstructGPT 的指南。公开数据能逼近覆盖，不能逼近标注员训练。用 LIMA 的一千条当唯一数据，产品覆盖不够；用未清洗的 ShareGPT 当唯一数据，风格与安全都绑在旧版 ChatGPT 上。工程上的默认是：小金标（标注或 LIMA 式精选）定义格式与底线，合成与社区填覆盖，清洗规则按桶分开写。宣称「我们用了开源指令数据」而不写桶与过滤，无法复现。

许可与隐私是硬边界。ShareGPT 类日志可能含用户未同意再训练的内容；合成数据可能被教师条款限制。这不是算法问题，但决定某条清洗规则是「可学但不该学」。技术管道应能按来源一键剔除，而不是清洗之后来源信息已经丢了。

不要用困惑度当指令质量。教师模型对套话的损失很低，对学生未必有用；难但正确的推导损失高，却是该留的。质量应用抽检、执行（代码）、以及小规模下游探针，与预训练网页的质量分类器不是同一个头。

Self-Instruct 不能自动保证难度分布合理，那是 课程 的问题；清洗只保证单条可学。安全比例是另一旋钮，不要把所有拒答样本在清洗阶段删光，否则配比再调也没有安全支撑。

小结 ​

  • 指令来源应分标注示范、社区多轮、精选小集、合成汇编四类，每条带来源标签再混合。
  • InstructGPT 靠指南约束 \(p_{\mathrm{sft}}\)；LIMA 靠精选；Self-Instruct 靠自举扩覆盖；ShareGPT / OpenHermes 是公开对照锚点，不是论文方法。
  • 清洗先结构后语义：角色、去重、PII、越狱配合、空回答、模板统一。
  • 要删的是错误监督，不是不像指令的题面；澄清与拒绝可以是正例。
  • 分桶之后配比才有意义；与评测集去重，避免教师带榜。
  • 公开混合物逼近覆盖，不替代标注指南；许可与隐私可一键按来源剔除。
