大模型 · 2026-09-03

DoRA ​

把权重拆成幅度与方向，让低秩增量主要去改方向、用一条可学习向量去改幅度；这样更新的几何更接近全参微调，而可训练参数仍与 LoRA 同量级。

—— Liu 等，DoRA: Weight-Decomposed Low-Rank Adaptation，ICML 2024

LoRA 用 \(BA\) 去逼近 \(\Delta W\)，隐含假设「增量低秩」已经足够。Liu 等人把全参微调时权重的变化拆开看：矩阵的列（或行）既在转方向，也在改长度。LoRA 的加性更新把这两件事缠在同一个低秩乘积里，幅度往往被带得不足，或被方向更新误伤。DoRA（Weight-Decomposed Low-Rank Adaptation）显式写成「幅度向量 × 单位方向」，方向用 LoRA 去适配，幅度单独成可学习参数。它不是新的量化，也不是动态分配秩；它改的是低秩增量作用在权重上的几何。

问题 ​

把预训练矩阵 \(W_0\) 的每一列看成一个向量，可以写成

\[W_0 = m_0 \frac{V_0}{\|V_0\|_c}, \]

其中 \(\|{\cdot}\|_c\) 表示按列取欧氏范数，\(m_0\) 是这些范数排成的向量，与单位列相乘（广播）后复原 \(W_0\)。全参微调时，\(m\) 与方向都会动。经验观察是：幅度的相对变化并不小，而且与方向变化不完全同步。LoRA 只学习 \(W_0+BA\)，没有单独的幅度通道；列范数的变化必须由 \(BA\) 的加性分量碰巧提供。若低秩子空间更擅长转方向而不是均匀缩放一整列，幅度就会滞后于全参轨迹。

问题因此不是「秩够不够」，而是「同一套低秩参数是否在同时承担两种几何角色」。若把角色拆开，即使 \(r\) 不变，更新也可以更像全参。这与 AdaLoRA 按层分配秩、与 LoRA+ 给 \(A\)、\(B\) 不同学习率，针对的是不同瓶颈。

加性低秩改范数为什么别扭 ​

列 \(w\) 加上低秩向量 \(\delta\) 后，新范数是 \(\|w+\delta\|\)，既含 \(\delta\) 沿 \(w\) 的投影，也含正交分量通过勾股定理抬高的长度。小 \(\delta\) 对范数的一阶贡献只有平行分量；正交分量主要改方向。LoRA 初始化使早期 \(\delta\) 很小，幅度通道几乎没被打开；等到 \(\|\delta\|\) 变大，方向与幅度已经耦合进同一次更新，难以用一个全局学习率同时合适。需要一种参数化，让「拉长这一列」不必绕道低秩子空间。

分解是对权重矩阵的重写，不是对激活做归一化。DoRA 的幅度不是 LayerNorm 的 \(\gamma\)，也不在残差流上；它属于被注入 LoRA 的那张线性权重。

方法 ​

DoRA 把可训练权重写成

\[W' = m\,\frac{W_0 + BA}{\|W_0 + BA\|_c}. \]

\(B\)、\(A\) 与普通 LoRA 相同；\(m\) 是与列数同长的向量（若按行分解则与行数同长）。初始化令 \(m=\|W_0\|_c\)，且 \(BA=0\)，于是 \(W'\) 起步精确等于 \(W_0\)，不破坏预训练前向。训练时 \(m\) 与 \(A\)、\(B\) 一起更新。前向比 LoRA 多一次按列范数与一次按列缩放；推理可以把 \(m\) 与归一化后的方向合并回一张稠密矩阵，部署形态与合并后的 LoRA 相同。

Liu 等人在多种 PEFT 基准上显示：同样的 \(r\)，DoRA 更接近全参微调的幅度–方向更新比，任务指标也常优于原版 LoRA。额外参数只是每列一个标量，相对 \(r(d+k)\) 通常可忽略。计算开销在训练期的按列归一化，不在推理期的合并结果。

机制 ​

幅度与方向的梯度分工 ​

对 \(W'\) 的损失求导，\(m\) 的梯度沿当前方向聚集：它只问「这一列该更响还是更弱」，不承担旋转。\(A\)、\(B\) 的梯度在除以列范数的流形上走，更新被投影到与「纯缩放」更正交的方向。于是低秩预算主要买方向自由度，缩放由 \(m\) 以满秩但极瘦的方式提供——每列一个自由度，恰好覆盖「整列拉长」这一族变换。这与「先归一化再缩放」在优化上的常见好处同类：把尺度与角度分开，用更匹配的步长去走。

全参微调里，幅度更新与方向更新的相对大小随层、随训练阶段变化。LoRA 无法单独画这条曲线；DoRA 的 \(m\) 轨迹可以直接画出来，并与全参的列范数变化对照。Liu 等人用这类对照说明：DoRA 的分解不是为了好看，而是为了让 PEFT 的更新几何进入全参所在的那一类。

按列还是按行分解，应与线性层的约定一致：权重左乘 \(x\) 时，列对应输入基、行对应输出通道，选哪一侧取范数会改变「幅度」的含义。实现必须与初始化时用于复原 \(W_0\) 的那一侧相同，否则第一步就已经不等于预训练。

与 LoRA 合并、与 QLoRA 叠用 ​

训练结束后，把 \(m\) 乘进归一化方向，得到稠密 \(\Delta W_{\mathrm{eff}}=W'-W_0\)，再与 \(W_0\) 相加即可。合并后不再需要存 \(m\) 与 \(BA\)，推理内核无改动。可以与 4-bit 基座叠用：冻结的 \(W_0\) 仍按 QLoRA 的 NF4 存储，DoRA 的 \(A\)、\(B\)、\(m\) 留在 16-bit。量化误差落在方向的分母里，会轻微扰动单位化；实践上仍把 \(W_0\) 反量化后再做分解，而不是在 4-bit 格子上取范数。

边界与工程取舍 ​

按列归一化在宽度很大时有数值问题：范数接近零的列会放大噪声，\(\varepsilon\) 地板必须与半精度动态范围匹配。训练期多一次归约，吞吐略低于 LoRA，这是为更新几何付的税；若任务上 LoRA 已经贴全参，这笔税不必付。DoRA 不分配层间秩，也不给 \(A\)、\(B\) 设不同学习率；它与 AdaLoRA、LoRA+ 正交，可以组合，但组合后超参空间变大，应先单独确认分解本身有收益。

不是所有层都值得拆。嵌入与词预测头的「列」语义是词表方向，幅度变化可能意味着词频或校准，不一定与隐层投影同类。原论文主要针对 Transformer 线性投影。把 DoRA 套到每一个 nn.Linear 上，是实现图省事，不是定理。

若发现 \(m\) 几乎不动、收益全来自 \(BA\)，说明该任务的幅度通道不关键，退回 LoRA 更干净。若 \(m\) 动得很猛而 \(BA\) 范数很小，则是在用每列一个标量做低成本的校准，低秩子空间可能可以更小。

何时不必上 DoRA ​

数据少、秩已经较大、目标只是风格浅适配时，LoRA 的加性增量够用。DoRA 的价值出现在「同一 \(r\) 下 LoRA 与全参之间仍有可见缝」的时候。它不能修复错误的 chat template、不能替代足够的指令数据，也不改变冻结基座这一前提。把它写成「全面优于 LoRA 的默认」并不符合取舍：多一次归一化、多一组学习率（有人给 \(m\) 单独设 \(\eta\)），都是成本。

小结 ​

  • DoRA 将权重写成幅度向量乘单位方向；方向用 LoRA 更新，幅度单独学习。
  • 初始化使分解精确复原 \(W_0\)，不引入起步扰动。
  • 拆开后，低秩预算主要买旋转，列缩放不再挤占 \(BA\) 的容量。
  • 额外参数是每列一个标量；推理可合并成稠密权重，与 LoRA 部署同类。
  • 可与 QLoRA 叠用，范数应在反量化后的 16-bit 上计算。
  • 与动态秩、A/B 分学习率正交；并非所有层、所有任务都需要这条几何。
  • 出处：Liu 等，DoRA: Weight-Decomposed Low-Rank Adaptation，ICML 2024。
