国产浸没 DUV ​

193 nm 浸没把水的折射率加进数值孔径，单次曝光的量产舒适区落在 28 nm 一类节点；国产扫描仪要先在这一档证明套刻、产率与光学，而不是先宣称追上 EUV。

—— 对照浸没 ArF 的公开光学，以及国产工具以 28 nm 单次曝光为目标的公开表述

深紫外浸没光刻（immersion DUV）在 193 nm 氟化氩（ArF）干式光刻与晶圆之间注入纯水，把有效数值孔径从干式的约 0.93 抬到约 1.35。瑞利关系 \(CD \approx k_1 \lambda / \mathrm{NA}\) 里，分母变大，单次曝光能稳定量产的逻辑节点落到业界习惯称为 28 nm 的那一档（以及附近的 22/16 nm 过渡，视层与 \(k_1\) 而定）。ASML 的 TWINSCAN NXT 浸没系列是这一档的全球量产基准。国产浸没机要补的，是同一条物理曲线上的整机：光源、投影物镜、浸没头、双工件台、套刻与产率。公开产品目录里，上海微电子（SMEE）长期量产在列的是 SSA600 一类干式 / 较松分辨率机型；浸没 28 nm 档（媒体常写的 SSA800 系列）被当作国产单次曝光的目标机型反复报道，但交付状态、产率与是否已在晶圆厂替代 NXT，公开信息并不一致。本篇按光学与工程写 28 nm 单次曝光这一档，不把未核实的「全面替代」写成事实。

问题 ​

没有浸没时，193 nm 干式光刻的 NA 上不去，28 nm 逻辑的许多关键层单次曝光吃力，要靠更强的分辨率增强或直接放弃这一节点。全球晶圆厂在 2010 年代把浸没做成 28 nm 的工作马，再在同一类机台上用多重曝光往 14/10/7 nm 走。国产工具链若只有 KrF（248 nm）和干式 ArF，就停在 90/65/55 nm 一类公开展示过的能力附近，28 nm 及以下的产能仍然绑在进口浸没机的保有量与许可上，见 EUV 出口管制 对高端 DUV 的后续收紧。

28 nm 单次曝光不是「随便一台 193 nm 机器」。它要求：投影物镜的波前与杂散光达到浸没 NA 的设计；浸没头在扫描时维持均匀液膜、不留下水印缺陷；双工件台把曝光与计量重叠以提高每小时晶圆数；套刻（overlay）进到数纳米，否则后层对不齐前层。产率公开对照很硬：ASML 中段浸没机常见每小时二百片量级的标称，国产报道数字更低。差的不只是「能不能出图形」，而是能不能在晶圆厂的成本模型里当量产工具。

单次曝光与节点名不要画等号 ​

「28 nm」是产品世代名，包含晶体管结构、设计规则、多层金属，不是光刻机面板上的一个按钮。同一台浸没机，有的层单次过，有的层本来就要双重图形化。国产机「原生支持 28 nm 单次曝光」若属实，指的是关键层在设计规则下可以一次成像，并不自动等于这条产线的所有层都单次、更不等于 14 nm FinFET 已经就绪。把媒体标题里的 28 nm 写成整厂工艺已经国产化，是把工具能力当成了工艺平台。

浸没液是水，不是一种新波长。波长仍是 193 nm。增益全部来自 NA。EUV 才换波长。讨论国产浸没时不要写成「国产已经有某种短波长 DUV」。

方法 ​

浸没 DUV 的方法拆成光学与机台两块，国产替代必须两块一起过，见 光刻供应链。

光学：ArF 准分子激光、照明匀化、掩模台、投影物镜、浸没头。物镜是蔡司在 ASML 机台上的单点之一；国产要在高 NA 浸没物镜的镀膜、镜片材料、热像差补偿上达到可扫描的波前。光源侧，Cymer 与 Gigaphoton 是公开的准分子激光主供应商；国产准分子光源的脉宽、能量稳定性、频谱宽度必须配得上物镜的色差设计，否则套刻与 CD 均匀性一起漂。

机台：双工件台（一面曝光、一面上片与对准）是产率的核心。扫描同步——掩模台与晶圆台以缩比关系对跑——误差进套刻。浸没头要在 300 mm 晶圆边缘仍稳住液膜。计量与对准标记的算法决定套刻能不能进 2–3 nm 量级。公开报道里，把国产浸没机与 ASML NXT:1950i 一类较老的浸没机做套刻、产率对照，是合理的锚；拿去和 NXT:2050i / 2100i 或 EUV 比「谁更先进」，是错锚。

工艺侧的方法是：先把 28 nm 平面 / PolySiON 或早期高 K 金属栅一类成熟逻辑的关键层，在国产浸没机上打通单次曝光的 CD、套刻、缺陷，再谈是否把同一台机器当成多重曝光的平台往下推。后者见 多重曝光。顺序不能反：多重曝光是在单次已经稳的套刻预算上叠次数，单次不稳，次数一加只会更炸。

公开状态要写成「报道与目录不一致」 ​

SMEE 官网长期展示的量产机型停在 SSA600 系列（公开规格指向 90 nm 等较松节点）。28 nm 浸没机在中文产业媒体中多次出现「验收、展示、小批量交付、在某厂验证」等说法，也有报道指出状态媒体互相矛盾、官方目录未列、关键子系统仍依赖进口。同时，另有公开报道称相关团队与项目在不同公司主体间重组。对这些，工程上正确的写法是：国产浸没 28 nm 是明确的技术目标与在研/验证对象，不是已经可以按 ASML 年出货量去规划扩产的商品。 晶圆厂今天跑 28 nm 量产，公开事实仍大量建立在已进口的浸没机保有量上。

机制 ​

单次曝光能到 28 nm，机制就是浸没把 NA 抬到约 1.35 之后，\(k_1\) 在量产可用区间（大约 0.3 出头到 0.4）时，半节距落到这一世代的设计规则附近。分辨率增强技术（离轴照明、光学邻近效应校正、相移掩模）把 \(k_1\) 再压一截，但压到极限就会把工艺窗口收窄，缺陷变敏感。28 nm 之所以被选作国产浸没的第一档靶，是因为它仍在「单次 + 常规 RET」的舒适区，不必先把套刻预算全部交给双重图形化。

产率机制是扫描速度、曝光剂量、双台切换与浸没缺陷率的乘积。剂量来自光源功率与光刻胶灵敏度；国产光刻胶若更慢，为了够 CD 就要降速或加剂量，产率直接掉。套刻机制是对准光学、台子同步、热漂与镜头加热。报道中把国产套刻写到 2.3–2.5 nm 一类数字时，必须问清是专用卡盘套刻还是匹配套刻、是最佳还是量产分布——ASML 自己也把这些指标分开报。没有测量定义的数字不能拿来做产能模型。

中芯国际等厂的 28 nm 量产能力是公开的工艺平台事实，与「光刻机是哪一家的」不是同一句话。有 28 nm 产品，不等于曝光机已国产；有国产浸没样机，不等于 28 nm 产能已经切换。

与 EUV 的机制对比要写清：EUV 换的是 \(\lambda\)，浸没换的是 \(\mathrm{NA}\)。国产浸没再成功，也停在 193 nm 的物理里，先进节点只能靠多重曝光或等待国产 EUV，见 国产 EUV 原型。28 nm 单次曝光的意义是成熟制程自主与作为多重曝光的底座，不是替代 EUV。

边界与工程取舍 ​

把国产浸没写成已经追平 NXT 全系列，与公开的产品目录和第三方质疑不符。把国产浸没写成毫无进展，又与多年在研、反复出现的 28 nm 靶标及局部验证报道不符。合适的边界是：光学原理公开且无争议；整机作为量产工具的产率、缺陷、稳定性、原厂维保与备件，仍是未闭合的工程问题。规划 28 nm 扩产，仍应把进口机保有量、许可风险和国产机验证进度分成三行，而不是一行「国产已经能做 28 nm」。

子系统进口依赖是另一条边界。即便整机组装在国内，193 nm 激光器的腔镜、高 NA 物镜、浸没密封与同步控制若仍有单点在外，许可与禁运可以打在零件而不是整机上。供应链篇写这些单点。整机「国产化率百分之多少」的媒体数字，没有拆到可替换的合格供应商名单之前，不能当合规结论。

不要用手机芯片的「nm 营销名」去反推光刻机能力。一款标注 7 nm 的产品可以在进口浸没机上用多重曝光做出来；它既不证明国产浸没已达 7 nm 单次，也不证明 EUV 已经国产。

取舍上，先把 28 nm 单次做稳，再把同一平台的套刻余量拿去付双重/四重曝光，是成本最低的国产路径。跳过 28 nm 直接攻 EUV，会把光源、反射光学、真空与光刻胶三条更硬的瓶颈叠在尚未闭合的机台工程上。Chiplet 与封装可以在系统级补算力，见 Chiplet 与先进封装，但补不了晶圆上 28 nm 逻辑层的曝光本身。

产率与套刻要用同一口径去验收 ​

验收国产浸没机时，产率必须写明：300 mm 还是 200 mm、曝光剂量对应哪一款胶、是否含边上片与对准、缺陷是否计入停机。套刻必须写明：单机专用卡盘、还是与金机或金片的匹配套刻、是均值还是分布尾部。ASML 把这些拆开报，国产机用「2.5 nm、150 wph」两行海报去替代，会在进厂后的第一周对不上工艺窗口。28 nm 单次能否成立，看的是窗口中心与窗口宽度，不是分辨率试片上最细的那条线。

小结 ​

  • 浸没 DUV 用 193 nm 加水把 NA 抬到约 1.35，单次曝光的量产舒适区是 28 nm 一类逻辑。
  • 国产浸没机的公开靶标正是这一档；量产目录与媒体报道的交付状态并不一致，不能写成已经按 ASML 规模出货。
  • 28 nm 单次要求物镜、浸没头、双台套刻与产率同时达标，缺一块都只是能出图形的样机。
  • 晶圆厂现有 28 nm 产能，公开仍大量依赖已进口浸没机。
  • 这一档站稳，才是多重曝光往下走的底座；它不替代 EUV。
  • 子系统若仍进口，整机许可风险只是换一个海关税号。
  • 出处：浸没 ArF 与 NA 的标准光学；ASML 公开的 NXT 指标口径；SMEE 公开产品线；关于 SSA800 等机型的产业报道需标注争议，不以单一媒体数字为验收。
