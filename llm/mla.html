Multi-head Latent Attention ​

我们提出多头潜在注意力：对键值做低秩联合压缩；推理时把上投影吸收进权重，解码只需缓存压缩后的潜向量。

—— DeepSeek-AI, DeepSeek-V2: A Strong, Economical, and Efficient Mixture-of-Experts Language Model, 2024

GQA 靠减少 KV 头数来缩小缓存，代价是组内不再有独立的值子空间。若仍想保留很多头——每头一套路由和一套值方向——缓存又会回到与 \(h\) 成正比。DeepSeek-V2 的 Multi-head Latent Attention（MLA）走第三条路：不共享头，而把每个 token 的键值联合压进低维潜向量 \(c^{KV}\)，多头所需的满宽 \(K,V\) 由潜向量经上投影临时展开。训练时展开是显式的；推理时上投影可以吸收进对 \(c^{KV}\) 的线性运算，decode 阶段只缓存 \(c^{KV}\)（外加很小的解耦 RoPE 键）。于是头可以很多，缓存却跟潜变量宽度走，而不是跟 \(h d_k\) 走。

问题 ​

推理显存里，注意力的 KV 缓存往往压过参数。MHA 的每层每 token 要存 \(2 h d_k\) 个数；GQA 把它变成 \(2 h_{kv} d_k\)。继续减 \(h_{kv}\) 会伤质量，因为那是在砍记忆通道数。另一种自由度是通道本身的维数：键值在 \(d_k\) 里可能是低秩的，真正需要缓存的自由度数远小于 \(h d_k\)。若训练时就用低秩瓶颈去写 KV，推理就可以只存瓶颈激活。

目标有三条必须同时成立。第一，训练仍要能表达多头：分数按头算，值按头混，质量对标 MHA 而不是对标 MQA。第二，decode 不得物化并缓存满宽 \(K,V\)。第三，位置编码（RoPE）不能被低秩路径轻易消掉——旋转作用在头内坐标上，和共享的低秩潜变量并不自然相容。MLA 用联合压缩满足前两条，用解耦的 RoPE 分支满足第三条。

低秩的是 token 的 KV，不是头数 ​

GQA 的压缩轴是头；MLA 的压缩轴是每个 token 的表示。一个 token 先变成 \(c^{KV}\in\mathbb{R}^{d_c}\)，\(d_c\) 远小于 \(h d_k\)，再由 \(W^{UK},W^{UV}\) 展开到各头。头数可以取 128 这类对 MHA 来说缓存不可接受的值，因为缓存里没有这 128 头的 \(K,V\)，只有一份 \(d_c\)。对照要写清楚：同样追求「小 KV」，MQA/GQA 是少头，MLA 是多头加窄潜变量。

联合压缩指 \(K\) 与 \(V\) 共享同一份 \(c^{KV}\)，而不是各压各的。共享瓶颈强迫键方向与值内容从同一潜状态解码，参数和缓存都更省。若 \(K,V\) 需要几乎无关的信息，这个瓶颈会成为质量上限——那时应加宽 \(d_c\)，而不是再增加 KV 头数。

方法 ​

对隐状态 \(h_t\)，DeepSeek-V2 先做下投影

\[c_t^{KV}=W^{DKV}h_t\in\mathbb{R}^{d_c}. \]

内容键、值由上投影展开到多头：

\[k_t^{C}=W^{UK}c_t^{KV},\qquad v_t^{C}=W^{UV}c_t^{KV}. \]

查询侧也可先压到 \(c_t^Q\) 再上投影到多头内容查询 \(q_t^{C}\)，以省训练算力；查询不进入 decode 缓存。RoPE 走解耦分支：额外的小维度 \(q_t^{R},k_t^{R}\) 单独携带旋转位置，不经过会破坏旋转结构的那条低秩内容路径。注意力在拼接了内容与 RoPE 分量的查询、键上做缩放点积，值仍用 \(v_t^{C}\)。

推理吸收是关键一步。内容项的分数

\[(q^{C})^\top k^{C}=(W^{UQ}c^{Q})^\top(W^{UK}c^{KV})=(c^{Q})^\top(W^{UQ\top}W^{UK})c^{KV} \]

不必先形成 \(k^{C}\)。输出侧 \(W^O v^{C}=W^O W^{UV}c^{KV}\) 同样可以把 \(W^{UV}\) 并进输出投影。吸收之后，decode 逐步只追加并读取 \(c^{KV}\)，满宽 KV 不落缓存。RoPE 键 \(k^{R}\) 无法被同样吸收，必须按头缓存，但 \(d_R\) 远小于 \(d_k\)，体积是小头。

吸收改变的是推理图，不是训练图 ​

训练仍显式展开多头 \(q,k,v\)，以便 RoPE、因果掩码和标准注意力核工作在头坐标系里，梯度也流过完整的 \(W^{UK},W^{UV}\)。吸收是部署变换：把已经训好的矩阵乘在一起，得到对 \(c^{KV}\) 的等价线性函数。若在训练期就吸收，RoPE 与多头几何会变得难写。实现上应把「训练 MLA」和「推理融合 MLA」当成同一组权重的两种计算图。

机制 ​

MLA 能「头多、缓存小」，是因为缓存张量的形状从 \([T,h,d_k]\) 变成 \([T,d_c]\) 加 \([T,h,d_R]\)。取 DeepSeek-V2 报告的量级：\(d_c=512\)、\(h=128\)、\(d_k=128\)、\(d_R=64\)，满宽 MHA 每 token 每层约 \(2\times 128\times 128\) 个数，MLA 的 \(c^{KV}\) 只有 \(512\)，外加 RoPE 键 \(128\times 64\)。数量级下降来自 \(d_c\ll h d_k\)，而不是来自砍头。

低秩假设是：生成 \(K,V\) 的映射经过一个窄瓶颈仍然够用。联合瓶颈比分别压缩更强，相当于约束 \(\mathrm{rank}([K;V])\) 受 \(d_c\) 限制。多头上投影把这 \(d_c\) 维扩到不同头的坐标系，头间差异来自 \(W^{UK},W^{UV}\) 的不同行块，来自同一份 \(c^{KV}\) 的不同线性读出。这与 GQA「不同组读不同缓存向量」相反：MLA 每 token 只有一份内容缓存，头差异全在矩阵里，而矩阵是权重不是激活，不随 \(T\) 增长。

吸收成立的前提是内容路径为纯线性。中间若插入非线性、若 RoPE 打在展开后的满宽 \(k^{C}\) 上，就不能把 \(W^{UK}\) 从缓存路径里消掉。DeepSeek-V2 把 RoPE 拆到旁路，正是为了保住吸收。复现时若把旋转直接打在低秩内容键上，推理融合会悄悄算错位置。

与 MHA、GQA 的对照 ​

MHA：每头独立 \(K,V\)，缓存 \(O(T h d_k)\)，表达力上限高。GQA：每组独立 \(K,V\)，缓存 \(O(T h_{kv} d_k)\)，组内查询共享激活。MLA：每 token 一份 \(c^{KV}\)，缓存 \(O(T d_c + T h d_R)\)，头数可以保持 MHA 级。质量上 MLA 的设计目标是贴近 MHA 的多头，而不是贴近 MQA 的单库。代价是实现复杂：训练展开、推理融合、RoPE 旁路、以及需要支持「对潜向量做注意力」的融合核，不能假设现成 GQA 核直接能跑。

边界与工程取舍 ​

\(d_c\) 太窄时，联合瓶颈先伤的是需要高精度复制的记忆（精确实体、长数字、少见符号），表现为检索式能力下降，而不是立刻在语言模型损失上崩盘。加宽 \(d_c\) 线性增加缓存，是最直接的质量旋钮，类似 GQA 里加 \(h_{kv}\)。没有免费午餐：潜空间不是无损压缩。

算力上，训练期多了下投影与上投影，前填要展开或等价地做吸收后的大矩阵乘；decode 省的是内存流量。若服务是极短生成、极大前填，MLA 的优势缩小，融合核若写得差甚至慢于 GQA。MLA 的合理场景是长生成、大并发、愿意为缓存付工程复杂度。MoE 模型参数已很大、激活稀疏，KV 缓存更易成为墙，这也是它出现在 DeepSeek-V2 里的上下文。

不要把 MLA 理解成「对已经生成的 KV 做 PCA」。低秩是训练出来的写路径，不是推理时的后处理。对 MHA 缓存做事后压缩是另一类方法，误差来自逼近已有激活；MLA 的误差来自训练期瓶颈，权重已经按这个瓶颈做了补偿。

小结 ​

  • MLA 把每个 token 的键值联合压进 \(c^{KV}\)，用上投影恢复多头内容键值；decode 只缓存 \(c^{KV}\) 与小尺寸解耦 RoPE 键。
  • 推理可将上投影吸收进对潜向量的线性映射，不必物化满宽 KV 激活。
  • 压缩轴是每 token 的秩，不是头数；因此可以头很多而缓存很小，与 MHA/GQA 的对照在此。
  • RoPE 必须走旁路，否则旋转破坏吸收所需的纯线性。
  • 训练计算图与推理融合图不同，实现不能只用一套朴素注意力核。
  • \(d_c\) 是质量-缓存旋钮；过窄会先伤精确记忆，而不是均匀地轻微掉点。
