Sheared LLaMA ​

目标不是一张掩码，而是一台更小的稠密 LLaMA：层数、隐宽、头数、FFN 中间宽一并剪到目标形状，再继续预训练把伤口养平。

—— Xia et al., Sheared LLaMA: Accelerating Language Model Pre-training via Structured Pruning, ICLR 2024

上一课 依赖稀疏核才能把 50% 变成墙钟。本课走 结构化剪枝：留下的张量仍密，任意 GEMM 都加速。缺口是 LLM 上如何把 7B 剪成指定的 1.3B / 2.7B 架构，而不是按元素打孔。后课激活稀疏又把动态性接回来；本课是静态改形状。

问题 ​

从零训一个 1.3B 要付满数据预算。已有 7B 检查点里有可用的层与通道。一次性幅度剪到目标形状会把知识剪断；完全从头训又浪费。Sheared LLaMA 的问题是：在目标配置（层、\(d\)、头、中间宽）给定时，从大模型选哪些块留下，以及剪完后如何用远少于从头训的 token 恢复。这不是 SparseGPT 的 one-shot：必须继续预训练。

目标配置要像真的小模型，而不是「7B 去掉一半层」的畸形宽高比。否则继续预训练在错误归纳偏置上浪费。深度与宽度的取舍见主干缩放实践，本课不重开。

动态批数据（targeted / dynamic batch loading）按各域损失落后程度加采样，用来在短继续预训练里补被剪掉的领域，不是新的预训练配比理论。

方法 ​

两段。第一段：用梯度或激活给出的重要性，对层、头、中间通道做结构化掩码，投影到目标架构（不是任意稀疏度）。第二段：在目标形状上继续预训练，数据配比用动态加载——哪个域的损失相对目标掉得后，就多喂哪个域。报告里 7B → 1.3B / 2.7B 用的 token 明显少于同等规模从头训，下游可接近专门预训练的小模型。

不要用 Wanda 的按行配额冒充这一步。Wanda 不改 \(d\) 与层数，推理图仍是 7B。Sheared 改的是配置文件，推理就是小密模型。

LoRA 是在原形状上加低秩增量，不减小推理 FLOPs（合并后仍是原 \(d\)）。本课减小的是 \(W_0\) 本身。二者不要写成一种「参数高效」。

机制 ​

结构化删除去掉的是整块子空间。残差与层序被破坏后，下一层的激活分布移位，必须用继续预训练重新对齐。动态加载的假设是：剪枝对不同域的伤害不均，均匀配比会在已恢复的域上浪费步数。这与预训练课的 DoReMi 同类，但是愈合期的配比，不是从零的数据律。

重要性若只用短校准，会偏短上下文与校准域，长上下文层或代码通道被误删——和量化校准过拟合同一病，处方是愈合数据要覆盖部署域，而不是把校准条数加到 one-shot 能救命。

边界与工程取舍 ​

没有继续预训练预算时，不要走 Sheared 这条路，去 SparseGPT / 2:4。目标形状必须有现成训练配方（学习率、batch），否则愈合不稳。下一课把稀疏从权重转到激活：形状不变，前向按输入跳通道。

小结 ​

  • Sheared LLaMA：结构化剪到目标稠密架构，再继续预训练愈合。
  • 加速来自更小的密 GEMM，不依赖 2:4 核。
  • 动态加载补的是被剪偏的域，不是 one-shot。
  • 与 LoRA / Wanda 的推理图不同，检查点不互换。
  • 出处：Xia et al., ICLR 2024。
