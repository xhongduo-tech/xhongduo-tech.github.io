ReLU FFN ​

每个位置上独立经过两层线性变换，中间用 ReLU 截断负值；注意力混合 token，前馈混合通道。

—— Vaswani et al., Attention Is All You Need, 2017

Vaswani 等人 2017 年的 Transformer 把每一层写成「多头注意力 + 逐位置前馈」两段。注意力负责 token 之间的路由，前馈网络（FFN）负责在每个位置内部做非线性特征重组。原论文给出的就是 ReLU FFN：先把 \(d_{\mathrm{model}}\) 升到更大的中间维，ReLU 之后再投回 \(d_{\mathrm{model}}\)。这个模块看起来朴素，却占了 Transformer 里大约三分之二的参数和 FLOPs。后面的 GeLU、SwiGLU、MoE 都是在同一位置上替换激活或把这一层拆成专家，不理解 ReLU FFN，就说不清那些替换改了什么。

问题 ​

自注意力的输出在通道维上仍是线性组合：每个头做加权和，拼起来再乘 \(W^O\)。若块里只有注意力，模型对每个 token 能做的非线性变换非常有限，表达力会卡在「谁和谁说话」，而不是「这句话在这个位置被编码成什么特征」。序列模型还需要一个对位置共享、对通道不共享的非线性 MLP，把注意力送来的混合信号拆开、筛选、再编码。

为什么必须是逐位置的 ​

若 FFN 也在 token 之间耦合，就和第二套注意力重叠，计算立刻变成另一份二次项。Vaswani 的选择是：FFN 在序列长度 \(n\) 上完全并行、权重共享，复杂度 \(O(n\cdot d\cdot d_{\mathrm{ff}})\)，与 \(n^2\) 解耦。这样长度变长时，多出来的成本主要仍由注意力承担，FFN 只随 token 数线性涨。

另一个问题是中间宽度。隐藏维 \(d\) 通常 512 到几千，若 MLP 保持 \(d\to d\)，秩和非线性容量都不够。经验做法是中间维取 \(d_{\mathrm{ff}}=4d\)，用一次胖的升维换通道混合的空间，再压回去以免残差对不齐。「四倍」不是定理。原论文基础模型用 \(d=512\)、\(d_{\mathrm{ff}}=2048\)。后来的模型有时用 \(8d/3\) 再配门控，好让参数量和四倍 ReLU FFN 接近。宽度首先是容量旋钮，其次才是和激活函数绑定的惯例。

方法 ​

对位置 \(t\) 的隐状态 \(x_t\in\mathbb{R}^{d}\)，ReLU FFN 定义为

\[\mathrm{FFN}(x_t)=\mathrm{ReLU}(x_t W_1+b_1)W_2+b_2,\qquad \mathrm{ReLU}(z)=\max(0,z). \]

\(W_1\in\mathbb{R}^{d\times d_{\mathrm{ff}}}\)，\(W_2\in\mathbb{R}^{d_{\mathrm{ff}}\times d}\)。所有位置共用同一套权重，因此叫 position-wise。写成矩阵形式就是对 \(X\in\mathbb{R}^{n\times d}\) 做两次 GEMM，中间按元素截负值。原论文还把这一层放在 Post-LN 残差里：

\[x \leftarrow \mathrm{LN}\bigl(x+\mathrm{Dropout}(\mathrm{FFN}(x))\bigr). \]

当代 Pre-LN 块只是把 LN 挪到 FFN 前面，线性代数部分不变。

和注意力的分工 ​

注意力的有效计算是 \(n\times n\) 的相似度，再对 \(V\) 加权；FFN 的有效计算是每个 token 的 \(d\to d_{\mathrm{ff}}\to d\)。一个常见的直觉是：注意力做路由，FFN 做键值记忆——把输入投影到一组「键」（\(W_1\) 的列），ReLU 选中被激活的单元，再由 \(W_2\) 的行写出值。Geva 等人后来把 FFN 解释为键值记忆，依据仍是 Vaswani 这套两层 ReLU MLP，而不是某种新结构。

ReLU 的作用是硬门：负半轴梯度为零，正半轴原样通过。训练早期它能制造稀疏激活，使不同中间单元分工；训练后期一部分单元会「死掉」，输入几乎总为负，这是 ReLU 相对 GELU 的已知缺陷，也是后来换激活的动机之一。

机制 ​

一次前向里，FFN 的 FLOPs 约为 \(2n\,d\,d_{\mathrm{ff}}+2n\,d_{\mathrm{ff}}\,d=4n d d_{\mathrm{ff}}\)（忽略偏置）。取 \(d_{\mathrm{ff}}=4d\) 时，约为 \(16 n d^2\)。对比多头注意力里 \(Q,K,V,O\) 四份投影 \(8n d^2\) 外加 \(2n^2 d\) 的分数与加权：当 \(n\) 不太大时，FFN 已经比注意力更吃算力；当 \(n\) 到数万，注意力的 \(n^2\) 才反过来主导。所以「Transformer 慢」在短序列上常常是 FFN 慢，在长上下文上才是注意力慢。

稀疏激活与死神经元 ​

ReLU 输出的期望稀疏度和输入分布有关。若 \(W_1\) 的预激活均值偏负，中间层大量为零，\(W_2\) 对应列得不到梯度。残差和 LN 会缓解，但不能消除。实践中用偏置初始化、控制 LN 的 \(\gamma\)、或换成 GELU，都是在给负半轴留一点漏梯度。Vaswani 原配方能训起来，是因为层数浅（6/6）、热身充分、且 \(d_{\mathrm{ff}}\) 足够宽，死一部分单元仍有余量。

参数量上，FFN 约占 \(\,2d\cdot d_{\mathrm{ff}}\,\)，注意力投影约占 \(4d^2\)。\(d_{\mathrm{ff}}=4d\) 时 FFN 是注意力参数的两倍。这个比例解释了后来 MoE 为什么替换的是 FFN 而不是注意力：同样稀疏掉一块计算，省下的参数和 FLOPs 最大。把 FFN 换成专家，注意力仍然是稠密的。Switch、GShard、DeepSeek MoE 改的都是这一层的容量分配，ReLU 两层结构仍是专家内部的原型，只是激活变成了 SwiGLU。

边界 ​

ReLU FFN 是 2017 年的默认，不是 2024 年的默认。BERT 很快改用 GELU；GPT-2 同样；PaLM 与 LLaMA 用 SwiGLU。继续用 ReLU 的理由只剩下实现简单、INT8 友好、以及和某些蒸馏学生模型对齐。负半轴截断在生成任务里会被看成表达力损失：门控线性单元可以用连续门保留幅度信息，ReLU 不能。

宽度也不该迷信四倍。计算预算固定时，更宽的 FFN 意味着更少的层或更窄的注意力；更窄的 FFN 则让模型把容量留给深度。Vision Transformer 有时用更宽的 MLP，语言模型则在 MoE 里把「宽度」改成「专家数」。ReLU FFN 给出的是稠密基线：每个 token 走完整的 \(d_{\mathrm{ff}}\) 通道。

不要把 ReLU FFN 写成「已经过时所以不重要」。几乎所有 GLU 变体的消融，都以它或 GELU MLP 为对照；几乎所有 MoE 论文的稠密对照，也是这一层。读懂 \(W_1\)、ReLU、\(W_2\)，才能读懂后面每一层前馈改了哪一个矩阵。

实现上这一层几乎总是两次 GEMM 夹一次逐元素激活，和注意力不同，没有 \(n\times n\) 的中间矩阵要物化。训练时中间激活 \(n\times d_{\mathrm{ff}}\) 却很占显存：\(d_{\mathrm{ff}}=4d\) 时它比注意力的 \(Q,K,V\) 更大，激活检查点往往优先重算 FFN 而不是注意力分数。推理 decode 阶段 \(n=1\)，FFN 变成两次瘦矩阵乘，带宽绑定明显，于是有人把 \(W_1,W_2\) 量化到 INT8，而把注意力留在 BF16。ReLU 对量化友好：零点清晰，负半轴截断后稀疏可压缩；这是它在端侧小模型里偶尔复活的原因，不是质量上赢了 SwiGLU。不要把 ReLU FFN 的稀疏激活和 MoE 的稀疏专家混为一谈。前者是中间通道上的值稀疏，权重仍全部参与；后者是参数级稀疏，一次前向根本不读未选中专家。压缩比和系统栈都不一样。偏置 \(b_1\) 在当代实现里常被关掉，靠前面的 LN 提供平移；这与 2017 年原式略有出入，复现 Vaswani 数字时要把偏置开关写进配置。

小结 ​

  • ReLU FFN 是 Transformer 的逐位置两层 MLP：升维、ReLU、降维，权重在序列上共享。
  • Vaswani et al. 2017 取 \(d_{\mathrm{ff}}=4d\)，注意力混 token，FFN 混通道。
  • 短序列上 FFN 往往比注意力更耗算力；MoE 因此优先替换这一层。
  • ReLU 硬截断会造成死神经元，这是改用 GELU / SwiGLU 的直接动机。
  • 它仍是稠密前馈的基线，后续激活与稀疏专家都在同一槽位上替换。
  • 出处：Vaswani et al., Attention Is All You Need, NeurIPS 2017。
