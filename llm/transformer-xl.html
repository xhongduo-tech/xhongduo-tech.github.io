Transformer-XL ​

段与段之间不再切断隐状态：当前段的注意力可以读上一截冻结的记忆，相对位置则让这种读取在下标重启之后仍然合法。

—— Dai et al., Transformer-XL, ACL 2019

vanilla Transformer 语言模型把语料切成固定块，块与块之间没有隐状态传递，上下文在边界上碎掉。Dai、Yang、Yang、Carbonell、Le 与 Salakhutdinov 的 Transformer-XL 给出两件配套的东西：段级循环（把上一层、上一段的激活当记忆）和一套相对位置打分，使记忆里的位置不会因为每段从零编号而错乱。后继的 压缩记忆 在 XL 的无损记忆之外再加压实槽，那是另一篇；本篇只写 2019 年原文的贡献、它如何度量「有效上下文」，以及它不是无限记忆。

问题 ​

语言模型需要跨过远大于训练块长的依赖：维基文章的指代、小说里的人物、代码里的定义。把块长 \(n\) 加大，注意力按 \(n^2\) 涨，很快顶到 2019 年的显存。若保持 \(n\) 不大、块与块独立，则块首位置看不见块尾之前的任何 token，评估困惑度时还会在每块开头重复「冷启动」。这就是上下文碎片化。RNN 没有这个问题，因为它把状态压缩成一个向量传下去，但那正是 Transformer 想摆脱的递推瓶颈。

XL 要的是折中：计算图仍以段为单位并行，段与段之间只传递一截已经算好的激活，当作只读记忆。传递一旦发生，位置编码若仍用绝对下标，上一段的位置 \(1\ldots n\) 会与当前段的 \(1\ldots n\) 撞车。所以循环和相对位置必须一起出场；只做其中一件，记忆会读错距离。

段间断裂 ​

独立分块训练等于每 \(n\) 个 token 强制一个注意力隔断。层数再深，信息也不能跳到段外，因为根本没有边。评测若同样分块、不带记忆，困惑度会系统性高估长程模型、低估「会跨段」的模型。原文因此同时改训练与评测协议：评测时滑动窗口并带上记忆，使每个 token 的条件上下文尽量长。比较 XL 与 vanilla 时，必须确认基线是不是也在同一协议下评，否则数字不可比。

「XL」不是把窗口开到超长再做满注意力。当前段长度仍然有限，二次项写在 \(n\times(n+m)\) 上，\(m\) 是记忆长度。它延长的是 可复用的过去激活，不是单次 \(n\)。

方法 ​

训练时把序列分成段。算第 \(\tau\) 段第 \(\ell\) 层时，键值来自当前段激活与第 \(\tau-1\) 段第 \(\ell\) 层（或按实现来自上一段同层）缓存下来的记忆 \(M\)，查询只来自当前段。记忆上停梯度：不把 BPTT 展开进更早的段，训练才不会随文档无限变长。多层堆叠后，第 \(\ell\) 层的记忆间接携带更早段、更浅层的信息，论文用「有效上下文 ≈ 层数 × 记忆长度」来描述这条沿深度的阶梯，而不是声称 \(m\) 本身等于历史长度。

相对位置用来替换绝对正弦或位置表。打分拆成内容项与位置项：查询与键的内容点积、查询对相对距离嵌入的项、以及与内容无关的全局偏置。这样，同一个相对偏移 \(\Delta\) 在段边界两侧含义一致，记忆里的 token 不必重新编号成连续绝对下标。具体四项公式以 Dai 等论文为准；它与后来的 ALiBi（距离线性偏置、不学嵌入）、RoPE（旋转 QK）不是同一参数化，不要把 XL 的相对项写成 RoPE 的先驱公式。

段级循环与停梯度记忆 ​

记忆是缓存的隐状态，不是外部分词级 KV 的现代实现细节，但思想相同：过去已经算过的表示拿来当键值，不再重算。停梯度意味着模型不能通过记忆把监督信号送到 \(m\) 个 token 之外的参数更新里；长程依赖主要靠表示本身在训练分布里学会被后来的段读取。这与「可学习的无限记忆」不同。实现上 \(m\) 可与 \(n\) 不等；\(m\) 越大，读得越远，显存与 \(n\times m\) 项越贵。评测可以把 \(m\) 开到比训练更大，原文报告了这种不对称，但那是外推记忆长度，不是外推绝对正弦相位。

相对位置的四项打分 ​

四项里真正新的是：把相对偏移做成可学习的、与内容解耦的通道，并加上对「任意键」和「任意查询」的偏置，使模型可以学到「总是看最近」或「总是看某种内容」的头。没有相对项，循环记忆会在位置编码上自相矛盾。没有循环，相对项只是一种绝对编码的替代，解决不了段间无边。原文的消融应被读成「两件套」，而不是两个独立 trick 的菜单。

机制 ​

有效上下文沿深度放大，是因为第 1 层的记忆只含上一段 token 的浅表示，第 2 层的记忆已经是「看过上一段」之后的表示，于是第 \(L\) 层理论上能触及约 \(L\) 段之前的信息。这是一条 接力，每跳有损。字符级 enwik8、词级 WikiText-103 上，论文用更长的评测窗口和可视化来支持「比同样块长的 Transformer 读得更远」。它不是针测，当时也还没有 128k 指令协议。

停梯度使优化稳定，也封死了真正的跨文档 BPTT。若需要梯度穿过压缩后的更早历史，那是 Compressive Transformer 用辅助重构去补的方向。XL 自己的主张更窄：在不把计算图拉成整篇文档的前提下，打破段边界。

把 XL 记忆理解成今天服务里的 KV 缓存，方向对、合同不对。KV 缓存是逐步解码的实现；XL 记忆是训练期就存在的段间接口，且按层缓存激活。现代 LM 训练通常仍切包、用注意力掩码，并不默认启用 XL 式停梯度记忆。

有效上下文不是无限的 ​

\(L\cdot m\) 是上界式的口算，不是保证每条依赖都活着。中间层若把早期记忆写成均匀噪声，深层读到的只是近期。记忆队列仍会丢掉 \(m\) 之外的无损激活——这正是压缩记忆要接手的问题。相对位置的最大偏移若在实现里被截断到某桶，更远的距离会撞进同一个桶，长程分辨力下降。原文在字符与词级建模上把块长推到当时的「长」，并不是为指令模型的针测设计的。

边界与工程取舍 ​

主场是语言建模（enwik8、text8、WikiText-103、One Billion Word），不是编码器文档分类，也不是机器翻译交叉注意力。把它接到 BERT 式双向编码器，段级循环与因果记忆的故事要重写。相对位置增加了注意力打分的参数与实现复杂度，后来许多解码器改用 RoPE，并不表示 XL 的循环接口被 RoPE 替代——RoPE 不提供段间记忆。

硬件上，\(n\times(n+m)\) 仍是稠密注意力，只是 \(n\) 可以较小。2019 年这能打过「把 \(n\) 开到 \(n+m\) 做满注意力」。2024 年的长上下文更多走更长 \(n\)、滑窗、线性核或检索，而不是默认在预训练里加 XL 记忆。作为思想，它仍然是「状态沿段传递」的标准引用；作为默认架构，它没有成为 LLaMA 一类稠密解码器的层规范。

复现困惑度时，必须对齐分词、记忆长度、评测是否跨段带记忆、以及是否用相对打分。只抄「把过去 KV 拼上」而仍用每段重启的绝对位置，会得到一种既不是 vanilla 也不是 XL 的中间体。

小结 ​

  • Transformer-XL 的原文贡献是段级循环记忆加上相对位置打分，用来打破语言模型的块边界。
  • 记忆停梯度，有效上下文靠层间接力放大，不是无限可微的历史。
  • 相对四项与 ALiBi、RoPE 不是同一公式；循环与相对项须配套。
  • 主场是字符/词级语言建模；压缩更早历史是后继工作。
  • 评测协议必须带记忆，否则与 vanilla 分块比没有意义。
  • 它延长的是可复用激活，不是把单次注意力改成线性。
  • 出处：Dai et al., Transformer-XL: Attentive Language Models Beyond a Fixed-Length Context, ACL 2019。
