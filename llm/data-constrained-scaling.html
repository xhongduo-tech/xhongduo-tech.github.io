数据约束下的扩展 ​

独特 token 用尽之后，重复并不是立刻无用。重复几次几乎像新数据，再往后收益衰减，最终不如把计算改用于别的轴。

—— Muennighoff et al., Scaling Data-Constrained Language Models, 2023

Chinchilla 的计算最优默认数据够用：你需要的 \(D\) 都可以是独特的。真实预训练经常先撞上数据墙——高质量文本就那么多，再大的集群也不能把独特 token 变出来。Muennighoff 等人 2023 年系统问：若独特数据只有 \(U\)，而计算预算要求看到 \(D>U\) 的 token，多 epoch 重复该怎么折算成「有效数据」？他们发现，大约前四个 epoch 的重复仍接近新数据的收益，之后边际下降，需要用衰减公式把重复 token 打个折扣。本篇讲这条数据约束扩展，以及它和过训、混合代码、继续去重之间的关系。

问题 ​

给定计算 \(C\)，稠密最优想要 \(D_{\mathrm{opt}}\propto C^{1/2}\) 量级的 token。若 \(U<D_{\mathrm{opt}}\)，有三条路：把 \(N\) 加大、少看 token（回到欠训大模型）；把同一批数据重复看，使名义 \(D=U\times\) epochs；或降低有效计算，承认达不到 Chinchilla 点。第一条会浪费计算在容量上、数据仍不够喂饱；第三条放弃预算；第二条是实践中最常见的，却长期缺少标度。重复算不算 \(D\)？算多少折？

过拟合的直觉说「看第二遍就会背诵」。语言模型的训练目标是分布，不是单句记忆，轻度重复往往仍在降低损失。但无限重复终会把模型钉在有限语料的经验分布上，验证集若与训练高度重叠还会造成虚高。需要一条定量曲线，而不是「绝对不能重复」或「重复没关系」的口号。

独特数据与名义 token ​

记独特 token 为 \(U\)，训练中实际喂给模型的 token 为 \(D\)（含重复）。epoch 数 \(E=D/U\)。Chinchilla 会计用 \(D\)；数据约束会计必须同时保留 \(U\)。Muennighoff 等人要拟合的是 \(L(N,U,D)\)，而不是只写 \(L(N,D)\)。当 \(E=1\)，\(U=D\)，退回普通扩展律；当 \(E>1\)，多出来的 \(D-U\) 需要一个有效系数。去重改变的是 \(U\) 的定义。哈希去重、MinHash、子串去重，会把名义语料砍成更小的独特集。比较数据约束实验，必须声明去重强度，否则「四个 epoch」对应的真实重复度并不相同。污染到验证集的重复更危险，应单独从 \(U\) 里剔除评测文本。

方法 ​

他们训练一系列模型，扫 \(U\) 与 \(E\)，比较「新数据」与「重复数据」在同等名义 \(D\) 下的损失。经验图像是：前几个 epoch，重复几乎跟得上新数据；超过大约四次之后，继续加 epoch 的收益明显弱于继续加独特 token。拟合上，可以把有效数据写成对重复次数衰减的和：第一次看的 token 权重大，第 \(e\) 次看打一个小于 1 的系数，总有效 \(D'\le D\)，且 \(D'\) 随 \(E\) 饱和。计算最优此时应对 \(D'\) 而不是对名义 \(D\) 来算。

策略上还有混合：在文本 \(U\) 不够时掺代码、多语言或其他领域，把有效独特量做大。这会改变 \(E\) 的语义（领域不是简单重复），但常比把单一领域重复十遍更有用。另一条是把预算转向更大的 \(N\) 或更长的训练寿命以外的轴，例如检索、合成数据——那些已超出「重复自然数据」的范围，本文只标记为边界。

衰减之后如何分配计算 ​

一旦 \(D'\) 饱和，再增加步数主要是在同一有效数据上做多余的优化，损失下降变慢。此时给定剩余计算，加大 \(N\) 可能重新变得合理——因为数据项已经不是 Chinchilla 假设下那个还能靠 \(D\) 压下去的项。这看起来像退回 Kaplan 的「偏大模型」，但动机不同：不是欠测，而是 \(U\) 真的不够。Muennighoff 的建议应读成：先用重复把 \(U\) 吃到衰减拐点附近，再考虑把增量计算用于宽度或其他数据源，而不是无限 epoch。

机制 ​

从估计误差看，每个独特样本第一次出现，提供一份新的梯度信息；重复出现时，信息与已有梯度相关，有效样本量不是线性加一。衰减系数就是这份相关性的经验代理。模型越大、容量越高，越容易把有限 \(U\) 记死，衰减可能来得更早；模型太小，重复几次仍在学一般统计，衰减来得晚。因此「四个 epoch」是他们那次实验的读数，换 \(N\) 与数据多样性会移动拐点。

验证损失与训练损失在高重复区会分叉。训练损失仍可因记忆下降，验证若真正留出，会先于训练饱和。扩展拟合必须用留出集，且留出集不能是训练集的近重复。否则数据约束曲线会画出假的无限收益。合成数据与重复真实数据不是同一类 \(D\)。合成若提供新的组合与覆盖，更接近增加 \(U\)；若只是改写同一批语料，更接近高相关重复，衰减应更重。不能把「又生成了一万亿 token」自动记入独特 \(U\)。

与过训的关系 ​

过度训练可以发生在 \(U\) 仍大于 \(D\) 时：数据够，故意把小模型多看几遍独特数据。数据约束是 \(U\) 不够，被迫 \(D>U\)。两者都提高 \(D/N\)，会计不同。过训论文关心推理成本；数据约束论文关心有效 \(D'\)。配方上可以同时成立：小模型、数据不够、多 epoch——既在过训，也在数据约束区。此时应同时监控 \(E\) 是否过了衰减拐点，以及 \(N\) 是否已碰到容量墙。

边界与工程取舍 ​

重复不能修复领域缺口。缺代码、缺对话、缺某种语言，把网页再看五遍补不上。衰减公式假设重复的是同一分布的样本。分布漂移的新数据，哪怕量少，也比同分布的第 20 个 epoch 更接近加 \(U\)。

法律与许可约束同样限制 \(U\) 的可重复性：有的数据可以多 epoch，有的只能过一遍。这不是扩展律能回答的，但会硬切 \(E\) 的上限。评测污染则是技术上限：高重复配方必须更严地隔离测试集。

MoE 把约束投影到专家上。总 \(U\) 看起来够四个 epoch，每个专家分到的独特 token 可能已经不够。专家数很大时，数据约束拐点会提前。把 Muennighoff 的 \(E\approx 4\) 直接套到 Switch 式上百专家上，会过于乐观。报告数据约束实验时，至少写清：\(U\) 的去重定义、 \(D\)、\(E\)、模型 \(N\)、留出损失，以及重复是打乱后的多 epoch 还是按文档连续再读。连续再读更容易记文档顺序，和充分打乱的重复不是同一条衰减曲线。

拐点之后仍可能有一小段缓慢收益，是否要吃完取决于墙钟与电力，而不是曲线还在不在降。工程上常把最后一个 epoch 的学习率收得更低，避免在高重复区用过大学习率把已经学到的分布打散。

小结 ​

  • 独特数据 \(U\) 不够时，名义 token \(D\) 含重复，应用有效数据 \(D'\) 来规划。
  • Muennighoff 等人发现大约前四个 epoch 的重复仍接近新数据，之后收益衰减。
  • 衰减因模型容量与数据多样性而移动，「四」不是常数。
  • \(D'\) 饱和后，增量计算应更多考虑加独特源或改 \(N\)，而不是无限重复。
  • 过训是数据仍够时故意拉大 \(D/N\)；数据约束是 \(U\) 不够被迫重复。两者可叠加。
  • 评测去污染与去重定义决定 \(U\) 是否可信。
  • 出处：Muennighoff et al., Scaling Data-Constrained Language Models, 2023。计算最优对照见 Hoffmann et al., 2022。
