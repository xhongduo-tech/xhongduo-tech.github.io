离散扩散语言模型 ​

把生成写成逐步去噪而不是从左到右：掩码或随机替换把离散符号打乱，模型学习在任意位置同时改写。

—— Li et al., Diffusion-LM；以及离散扩散在掩码语言模型与当代并行解码上的延伸

交错训练 把图、文、音频码排成一条因果序列。因果 LM 的缺口是：双向约束（「这句话要包含这三个词、这段唇形要对上这句台词」）很难在已经写下的前缀上插入，只能靠重写整段。Li、Thickstun、Gulrajani、Liang、Hashimoto 的 Diffusion-LM 把连续扩散接到词嵌入上做可控生成；后续工作把前向过程直接定义在离散词表或 codec 码上。本课写 离散状态上的扩散 与自回归的差别，作为多模态单元的收束：音频码、视频 token 都可以被「并行改写」，而不只是续写。

问题 ​

自回归 \(p(z_t\mid z_{\lt t})\) 把任意全局约束变成「先写对前面，后面才有机会满足」。控制生成、填空、长度固定的编辑、以及非因果的音画对齐，都要与这个顺序作战。掩码 LM 能填空，但一次填多少、如何迭代，不是生成模型的完整前向。扩散提供一套带时间步 \(t\) 的迭代：从近乎噪声的离散序列 \(x_T\) 走到数据 \(x_0\)，每步可以改所有位置。

离散化带来技术缺口：高斯扩散的重参数在单纯型或 one-hot 上不成立。必须定义离散前向核 \(q(x_t\mid x_{t-1})\)——均匀随机替换、向掩码符号吸收、或在 codec 码本内打乱——以及对应的去噪网络 \(p_\theta(x_{t-1}\mid x_t)\)。Li 等人的 Diffusion-LM 选择先在嵌入空间做连续扩散再投影回词表；吸收态掩码扩散则更接近 BERT 式目标，但带显式时间表。本课关心的是：符号是离散的（词或码），迭代是并行的。

与 codec / 视频符号的接口 ​

音频 codec 的 RVQ 层有残差顺序；视频时序 的 token 有时间局部性。离散扩散若对各层码、各帧独立加噪，会拆掉这些结构。前向过程应能按层、按时间块相关地腐蚀，去噪网络才能利用结构。把交错序列当成普通文本扩散，多模态对齐会先于语义崩溃。「离散扩散」不是「非自回归机器翻译里的一次迭代解码」的新名字。它有明确的时间步与噪声日程；迭代解码可以是它的推理加速，但训练目标按扩散边际来写，而不是按一次平行预测所有 token 的 NAT 损失来写。

方法 ​

吸收、均匀替换与嵌入扩散 ​

吸收态（masking）扩散的一个常用前向是：每个位置以随 \(t\) 增加的概率变成 [MASK]，一旦吸收就停在掩码。去噪模型看 \(x_t\) 预测 \(x_0\) 或预测 \(x_{t-1}\)。推理从全掩码或纯噪声出发，按日程逐步降低掩码率。均匀替换扩散则把符号以一定概率改成词表内随机项，没有吸收，允许「改错了再改回来」。

连续嵌入扩散（Diffusion-LM）：对 one-hot 或可学习嵌入 \(e(x)\) 加高斯噪声，网络预测干净嵌入，再用 rounding 回词表。优点是能借连续扩散的工具；缺点是 rounding 误差与可控性梯度要穿过这个不光滑台阶，Li 等人用梯度更新嵌入再投影来做控制。

训练损失通常是某个 \(t\) 上的交叉熵或分数匹配，而不是完整似然。因此 不能直接拿 AR 的 perplexity 比扩散；应在同一套下游（条件生成、控制满足率、音画同步）上比。

机制 ​

每步并行改写，使「句子中部的约束」不必等待左侧生成完毕。控制项可以加在每步的能量上（把不满足约束的位置的 logits 压低），这是 Diffusion-LM 相对提示工程的理论优势。代价是步数：质量通常随去噪步增加，测试时计算从「一条长链」变成「若干次全序列前向」。与 test-time scaling 的 AR 搜索不是同一条曲线，不要把步数直接换算成 token 数。

因果 LM 天然适合无限续写与 KV 缓存；离散扩散每次看见（几乎）全序列，缓存策略不同，decode 的流式首 token 更差。对话系统里更常见的是 AR 主模型 + 扩散做局部编辑（改一句、修一段码、对一下唇形），而不是全程扩散对话。

掩码扩散在 \(t\) 接近 0 时很像 BERT；在 \(t\) 接近 \(T\) 时很像从空白写全文。日程把两种体制连成一条。只在中间 \(t\) 训练会得到既不会填空也不会从零生成的模型。重要性采样 \(t\) 与 AR 的 token 位置采样一样，是训练配方的一部分。

多模态交错上的噪声日程 ​

交错序列里文本与视觉码的熵不同，同一掩码率对文本可能过噪、对视觉可能欠噪。分模态日程、或按 codec 层设不同吸收速度，是结构先验。否则去噪网络会先学会「把图全猜成平均色、把字填成高频词」，再在后期来不及修补对齐。

边界与工程取舍 ​

似然、似然比、教师强制的工具链都为 AR 而建。扩散 LM 的选点、早停、与 RL（后面对齐课）接口都更绕：奖励模型如何对中间噪声态打分，没有标准答案。若任务主要是聊天续写，AR 仍是默认；本课的位置是可控生成、并行填充、以及把离散 codec 当成可双向改写的画布。

不要与连续潜空间扩散（图像 / 视频生成主路）混淆：那些模型的状态是 \(z\in\mathbb{R}^d\)，本课状态是词表下标。把 VAE 潜变量扩散完再解码，是另一门课。离散扩散的词表若来自 codec，还受码本崩溃约束——codec 课的死符号在扩散里同样不可被有意义地去噪。

Li 等 Diffusion-LM 是嵌入空间连续扩散；后续 LLaDA、Dream 一类工作把掩码离散扩散做到语言建模尺度。引用时分清前向核，不要用一篇的数字证明另一篇的日程。

小结 ​

  • 离散扩散在词或码序列上迭代去噪，并行改写，便于全局约束与编辑。
  • 前向核是掩码吸收、均匀替换或嵌入高斯再投影；不可与 AR perplexity 直接比。
  • 多模态码的结构（RVQ 层、时间块）应写进加噪，而不是当独立比特打乱。
  • 流式与 KV 缓存弱于 AR；产品上常作局部编辑器而非主对话环。
  • 训练必须覆盖噪声日程两端，否则既不会填空也不会从零写。
  • 出处：Li 等，Diffusion-LM；离散掩码扩散的后续语言建模工作。
