W4A16 与 W4A8 ​

4-bit 权重减的是每步要扫过的字节；激活仍用 16-bit 时，decode 吃带宽红利。若再把激活打到 8-bit，是在同一套粗权重上叠加第二条量化噪声，换的是 prefill 的算术密度。

—— 对照 Frantar et al., GPTQ, ICLR 2023；Lin et al., AWQ, MLSys 2024；与 W8A8 的激活精度权衡

W4A16 是端侧与单卡服务里最常见的权重量化落点：权重每参数 4 bit，激活与矩阵乘累加仍用 FP16 或 BF16。GPTQ 与 AWQ 的论文主线都在这条线上——它们要回答的是「4-bit 格子怎么选才不把层输出打崩」，不是「INT8 Tensor Core 怎么喂饱」。W4A8 把激活再降到 8-bit，试图同时拿走权重带宽与 8-bit 算术，误差预算却变成两份相乘。本篇把 W4A16 写成默认，把 W4A8 写成加激活量化之后的权衡，并与 W8A8 对照：真正在换的是激活精度，不是「4 比 8 更强」。

问题 ​

Decode 阶段查询极短，每步几乎要把全部权重从 HBM 搬进片上，见 Decode 的显存墙。FP16 的 70B 仅权重就超过 100GB 量级；4-bit 后体积大约四分之一，单卡容量与加载带宽同时松绑。激活在 batch=1 时只是一行，压不压 8-bit 对加载项几乎看不见，却要为每个 token 估尺度、插量化核。于是小 batch 生成的理性默认是：狠压权重、放过激活。这就是 W4A16。

困难在 4-bit 本身。均匀 16 档格子相对半精度是 4 倍信息损失，RTN 会在显著通道上放大误差。GPTQ 用校准 Hessian 补偿，AWQ 用激活感知缩放保护显著列，AutoRound 改取整边。它们共享前提：乘法的另一侧足够精细，能量得起权重的离散误差。一旦激活也量化，这个前提要重验。

W4A8 不是 W4A16 的免费升级 ​

W4A8 看起来像「两点都省」。权重仍 4-bit，激活 8-bit，prefill 的 \(X\) 可以走更窄的总线，部分硬件还提供 INT4×INT8 或「4-bit 权重解到寄存器再与 INT8 激活乘」。精度上却是 \((W+E_w)(X+E_x)=WX+E_wX+WE_x+E_wE_x\)。W4A16 只有 \(E_wX\)；W8A8 的 \(E_w\)、\(E_x\) 都较小。W4A8 让较大的 \(E_w\) 去乘已经带噪的 \(X\)，交叉项在深层残差里累积。没有新的补偿算法，只是把两种 PTQ 叠起来，生成质量往往先于吞吐到达产品线。

服务广告里的「4-bit 推理」多数指 W4A16。KV 仍可能是 16-bit 或另做 8-bit。读基准时要拆三项：权重点型、激活点型、KV 点型。缺任何一项，tokens/s 都无法复现。

方法 ​

W4A16 的离线步骤：用校准文本缓存各层输入，按 GPTQ / AWQ / AutoRound 之一（或级联）得到分组 4-bit 权重与尺度；推理核按组加载整数，在片上乘尺度得到与 FP16 激活相乘的有效权重，或使用硬件支持的 4-bit Tensor Core 路径。分组大小（如 128）是质量与元数据的折中：组越大越省尺度，越容易被组内动态范围伤害。注意力输出投影、MLP 门控、lm_head 是否留 8-bit，属于实现契约，换会改困惑度。

W4A8 在此之上对 \(X\) 做在线 8-bit。若激活仍有通道异常值，需要先做 SmoothQuant 一类迁移，再量化激活；权重侧的 4-bit 是在已经乘过 \(s\) 的 \(W'\) 上打的，顺序不能反。另一种做法是混合：prefill 用 W4A8 或 W8A8，decode 切回 W4A16，要求两套核、同一份权重能被两种反量化路径消费，工程成本高于单一 W4A16。

真正加速要求核按 4-bit 加载。先把全模型解成 FP16 再乘，只省磁盘与占用，decode 带宽与 FP16 相同。这是端侧演示里常见的假 4-bit。

机制 ​

为何 decode 偏爱 16-bit 激活 ​

算术强度粗略是 \(\mathrm{FLOPs}/\mathrm{Bytes}\)。Decode 一步，FLOPs 与 \(d_{\mathrm{model}}\) 成正比，Bytes 几乎等于权重体积。把权重从 16-bit 打到 4-bit，分母除以 4，强度上升，更接近算力屋顶——但通常仍远未打满 GPU 峰值，所以墙钟仍跟带宽走，加速接近体积比（再扣核开销）。激活 16-bit 在这一步的字节可以忽略。把激活改成 8-bit，分母几乎不变，分子若没有 INT4×INT8 的更高吞吐，墙钟不降，只多噪声。

Prefill 相反：\(X\) 的字节与 \(n\times d\) 同阶，激活量化开始改变分母，8-bit GEMM 开始改变分子。W4A8 的合理舞台是「权重已经被 4-bit 绑死、又要打 prefill SLA」的节点，不是 batch=1 聊天。

权重误差 \(E_w\) 经激活放大。W4A16 里 \(X\) 精细，\(E_wX\) 就是 GPTQ 在最小化的对象。W4A8 里 \(X\) 已含 \(E_x\)，最小化 \(\|WX-\hat{W}X_{\mathrm{fp16}}\|\) 的校准对不准真实推理路径 \(\|WX-\hat{W}X_{\mathrm{int8}}\|\)。正确做法是校准循环里用量化后的激活往下一层送，与 GPTQ 逐层量化同一纪律，只是对象多了激活。许多「把 AWQ 权重接到 INT8 激活上」的失败，来自校准与推理路径不一致。

分组 4-bit 的尺度是 FP16 还是 FP8、是否对称，会改变反量化在寄存器里怎么做。W4A8 若用整数管道，尺度还要能和激活尺度融合成一次乘。格式细节属于核，不属于「W4」这个名字。

边界与工程取舍 ​

4-bit 对嵌入与 lm_head 往往不值：词表宽、误差直接进 logits，常见做法是这两处留 8-bit 或 16-bit，体积增量相对 70B 可忽略。视觉-语言投影、MoE 路由门也是敏感点，AWQ 相对 GPTQ 更常被用来保护它们，因为不在校准句上做二阶过拟合。

W4A8 的硬件支持碎。有的 NPU 原生喜欢 INT8 激活配 INT8 或 INT4 权重；有的 GPU 上 INT4 核只为权重解码设计，激活仍要 FP16。没有核就不要为了表格里的 W4A8 去叠激活量化。FP8 激活配 4-bit 权重是另一条厂商路径，误差行为更接近「浮点激活略粗」，与 INT8 仿射不是同一套尺度算术，见 FP8 推理。

与 QLoRA 的 4-bit 不要互换 ​

QLoRA 的 NF4 是训练期存储码本，前向要反量化到 16-bit 再乘。GPTQ/AWQ 的 INT4 是推理期打包。把 QLoRA 检查点当 W4A16 服务，或把 GPTQ 权重当 QLoRA 基座接着训，都会在反量化表上对错。W4A16 是部署配方；QLoRA 是压缩微调配方，见 QLoRA 作为压缩微调。

同一 4-bit 文件在 llama.cpp、AutoGPTQ、AWQ 容器之间不能只改后缀。group_size、zero_point、是否 desc_act 重排，错一位就是通道错位，表现像随机初始化而不是「略掉点」。

小结 ​

  • W4A16 狠压权重、激活保持 16-bit，匹配小 batch decode 的带宽墙；GPTQ/AWQ/AutoRound 都主要服务这条线。
  • W4A8 再量化激活，交叉误差更大，校准必须沿量化激活路径走；收益主要在 prefill 与大 batch。
  • W8A8 与 W4A16 的核心差别是激活精度：前者换算术密度，后者换权重加载。
  • 假 4-bit（解回 FP16 再乘）只省占用，不省 decode 带宽。
  • 嵌入、lm_head、多模态投影常需更高比特；核与分组契约决定能否复现数字。
  • 训练用 NF4 与推理用 INT4 不是同一检查点。
  • 出处：Frantar et al., GPTQ, ICLR 2023；Lin et al., AWQ, MLSys 2024。W8A8 对照 Xiao et al., SmoothQuant, ICML 2023。
