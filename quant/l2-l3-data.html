Level-2 / Level-3 数据 ​

市场数据不是「价格」这一列，而是报价、深度与逐笔指令在不同聚合程度上的投影。你能重建的状态，不会细过你买到的那一层。

—— 据 Harris, Trading and Exchanges 对市场数据与透明性的论述整理

上一课讲完了指令。讨论 LOB 时默认状态是完整的。本课的缺口是观测：实际研究与交易用到的是分层出售的数据。业界口头上的 Level-1 / Level-2 / Level-3 指投影精度。名称在不同市场并不统一，但必须先锁定量是按价位加总的，还是按每一笔订单保留的。没有这层区分，后面的队列位置无法定义，事件时间也只是在错误的事件上打时间戳。

问题 ​

微观结构要回答的问题大多是条件期望：下一笔主动买之后中间价怎么走、某一档被撤空后冲击有多大、自己的限价单大概排在第几。这些问题的条件变量是簿的状态，而状态的可观测性取决于数据契约。Level-1 只给 BBO 与最新成交，看不见后面还有多少量，更看不见同价位有几张单。用它拟合价差模型可以，用它谈论「吃两档」或「取消队头」则信息不足。

更麻烦的是同名不同义。股票行情里 Level-2 常指各做市商或各档的报价列表；期货与许多电子盘里 L2 指按价格聚合的深度，L3 指每一笔订单的增、改、撤、成。Harris 讨论透明性时区分的是：你看见的是最优报价、是深度，还是指令流本身。问题不是选一个时髦的缩写，而是写明重建簿时丢失了什么：丢失订单边界，就丢失时间优先；丢失事件，只剩快照，就丢失两次快照之间的路径。

快照、增量与成交 ​

数据还有另一条正交的切分：周期快照还是逐笔增量。快照每隔固定时钟间隔拍一张各档价量，便宜、易对齐，但把间隔内的全部增撤成交压成净变化，事件时间被毁掉。增量馈送是一条消息流：每条消息改写簿的一个局部，本地重建后应与撮合引擎一致。成交报告有时是独立通道，有时嵌在订单消息的 execute 类型里。若成交通道与簿通道时钟不同步，你会看到「价格已经跳了、深度还没动」的假象。

Level-1 足够画日 K 线，不够做微观结构。Roll 模型只用成交价，是因为它在问价差的成交回跳，不是在问第 \(k\) 档深度。换问题就要换层次：同一篇 O'Hara 意义上的价格形成，落到数据上必须指定观测代数。

方法 ​

约定一套分析用的层次，避免和某个交易所的产品名绑死。Level-1：每条记录是最优买价、最优买量、最优卖价、最优卖量，加上成交价与成交量。状态维度极低，更新可以是报价修订或成交。Level-2：在 L1 之上给出前 \(K\) 档（或全部价位）的聚合量，\(q^b_k,q^a_k\) 是该价位上所有订单之和，没有订单编号，没有队内次序。Level-3：每笔订单有标识，消息类型至少包括增加、部分或全部成交、撤销、改价改量；本地按交易所优先规则插入与删除，价位聚合是派生出来的，不是原始字段。

重建 L2 簿：维护两侧价格到数量的映射，处理增则在该价位加量，撤则减量，成交则从该价位减量，价位数量归零则删除该键。重建 L3 簿：维护「订单编号 → {方向, 价格, 剩余量, 到达次序}」，同一价格下用队列保存次序；聚合深度等于该价位队列剩余量之和。L3 能回答「我前面还有几张单、共多少量」；L2 只能回答「这一档总共多少量」，对自己的名次只能做均匀或更粗的先验。

消息缺口与校对 ​

增量重建必须处理丢包。实务上馈送会定期给快照或校验和，本地状态与快照不一致则丢弃中间的增量、从快照重载。时间戳有交易所撮合时间、发送时间、本地接收时间三套，微观结构事件时间应以撮合时间为准，否则把网络延迟写进了价格形成。成交方向若数据商没有给，需要用相对 BBO 的规则去推断，推断误差会污染后续的不平衡与价差分解。这些不是「数据清洗的边角」，而是层次选择之后立刻出现的识别问题。

L2 的档位数 \(K\) 也是方法的一部分。只留五档，远处的缺口与隐藏补量都看不见；留全簿，存储和噪声都上升，且远处价位的经济含义弱。选择 \(K\) 应服务于冲击路径与不平衡定义，而不是越多越科学。

机制 ​

聚合一旦发生，时间优先就被积分掉了。L2 上看见某档 \(100\) 手，可能是 \(1\) 张 \(100\) 手的单，也可能是 \(100\) 张 \(1\) 手的单。前者被一笔中等主动单就能打穿该档并扫到下一价；后者需要许多事件才能把队头逐个消耗。价格冲击、撤单与队列 的填成概率，依赖的是队的结构而不是和。L3 的机制价值首先在这里：它把深度还原成可消耗的序列。

L3 还让「谁在动簿」可部分识别——不是身份，而是订单生命周期。同一编号的增加与随后的快速撤销，是撤单博弈；同一编号的部分成交后余量仍在，是队列被消耗；编号消失后几乎立刻在同一价位出现新编号，可能是改单被写成撤加。L2 只有净量变化，这些路径不可区分：净减 \(10\) 手，可能是成交，也可能是撤单，对信息含量的解释完全相反。Harris 强调事后成交与事前报价要分开看；在 L2 净变化里，这两件事已经被加在同一个差分里。

不同层次对同一事件的投影 ​

设想队头一张 \(5\) 手的单被市价吃掉，后面还剩 \(20\) 手。L1 可能完全不变——若该档仍是 BBO 且量仍为正，有的 L1 馈送甚至只在 BBO 价格变了才更新。L2 显示最优档量从 \(25\) 变为 \(20\)。L3 显示一笔 execute，队头编号消失，后面编号前移。若研究的是价差，L1 够了；若研究的是盘口不平衡对短时收益的预测，至少要 L2 的量；若研究的是自己挂单的预期等待，必须 L3，或在 L2 上承认不可识别并改用统计代理。

美国股票口语里的 Level 3 还曾指做市商向系统提交报价的终端权限，与「order-by-order 行情」不是同一句话。写数据说明书时应用「按价位聚合 / 按订单编号」这种操作性语言，少用未加定义的 L2、L3。

边界 ​

层次是投影，不是现实的替代物。即使 L3 也不含冰山隐藏余量、不含暗池里未打印的意向、不含未提交的人脑意愿。可见 L3 仍是可见簿的完整记录，不是市场全部流动性的完整记录。跨交易所时，每一家的 L3 只覆盖自己的撮合；全国最优报价可能来自另一张簿，本地 L2 的深度不能解释在别处成交的那一笔。

时钟与权限会进一步切薄数据。有的「L2」其实是每秒快照的十档，名义上有深度，事件结构已经没了。有的订单级馈送延迟明显高于 BBO 频道，拿延迟的 L3 去解释领先的成交，会造成虚假的预测力。费用使多数研究停在 L2，于是文献里大量「深度不平衡」应读作「聚合量不平衡」，不要写成已经控制了队列位置。监管与合约条款还会限制哪些字段可存、可再分发，复制别人的微观结构结果必须复制同一层数据，而不是同一段代码。

用 L1 成交价去估 Roll 价差是模型允许的；用同一列数据去画「五档深度」则是在伪造观测。层次错误不是估计误差，是把不可见的量当成了看见。

小结 ​

  • 分析上的 L1 / L2 / L3 是对撮合状态的投影：最优报价与成交、价位聚合深度、带编号的逐笔订单。
  • L2 丢失队内次序，成交与撤单在净量里不可分；L3 才能谈队列位置与订单生命周期。
  • 快照与增量正交于层次：快照毁掉事件时间，增量重建必须处理缺口与多套时间戳。
  • 同一物理事件在三层上的可见性不同，问题决定最低所需层次。
  • 即使 L3 也不含隐藏量、暗池与他市场；产品商品名不能代替「按价还是按单」的定义。
  • 复制研究必须复制数据层次，否则不平衡、冲击、排队概率都不在同一识别条件下。
  • 出处：Harris, Trading and Exchanges；价格形成对信息集的依赖见 O'Hara, Market Microstructure Theory。
