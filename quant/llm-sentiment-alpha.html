LLM 情绪 alpha ​

把当日新闻标题交给一个大语言模型，询问它对股价是好消息还是坏消息；模型给出的方向，能够预测随后的横截面收益，且增量超过传统词典情绪。

—— Lopez-Lira and Tang, Can ChatGPT Forecast Stock Price Movements? Return Predictability and Large Language Models, 2023

文本因子在词典与主题模型之后，进入了生成式大模型（LLM）打分的阶段。Alejandro Lopez-Lira 与 Yuehua Tang 在 2023 年的工作里，不训练分类器、也不改词表，只把新闻标题送进 ChatGPT，问「这则消息对该公司股价是正面、负面还是中性」，再把回答映射成隔日可交易信号。结果在美股横截面上显著，小盘与低关注名字更强，相对 舆情与文本 里的 Loughran–McDonald 词频有增量。本篇写这一 LLM 情绪 alpha 估什么、如何避免把模型的世界知识当成时间机器，以及它与监督词权、嵌入因子的分工；嵌入侧见 LLM embedding 因子。

问题 ​

词典把文档收成负面词占比，假设极性可加、领域词表稳定。LLM 直接对「是否利好股价」做条件判断，理论上能处理否定、比较级、行业惯例（「低于预期但仍指引上调」）以及事件类型（回购与诉讼不是同一符号）。问题从「词表是否金融专用」变成：「模型在新闻日 \(t\) 真正可获得的信息，是否被训练语料里 \(t\) 之后的价格与维基条目污染」。Lopez-Lira–Tang 的设计是标题级、日频、横截面，刻意避开长文与多跳推理；即便如此，闭源对话模型的知识截止日期通常晚于回测样本，前视是第一约束，见 前视偏差 与 时点基本面。

第二个问题是标签定义。问「对股价好不好」把基本面信息与市场已计价混在同一答案里：若标题只是复述已公布的财报数字，模型的「正面」可能只是在复读共识，没有增量。问「是否意外」又依赖模型是否知道共识。论文用相对朴素的正负中性，把「模型是否读得懂标题」与「市场是否尚未交易完」绑在一起检验。复制时必须把问题固定，不能在样本外改提示词再挑最好的 \(t\) 统计量，见 多重检验。

标题、正文与多源对齐 ​

Lopez-Lira–Tang 用新闻标题而非全文，一是为了与零售注意力更接近，二是为了控制长度与费用。标题有编辑选择偏差，也更干净。把同一事件的电讯稿、地方媒体与社交转发拼成「情绪爆发」而不去重，会把一次盈余公告计成多次。时间戳必须以首次可交易到达为准：美股用交易时段内到达的标题预测随后收益，收盘后到达的标题只能进次日信号。中文市场还要处理午休与涨跌停后的可成交日历。多语言模型对中英标题的极性校准不必相同，不能把英文提示词硬译后假设系数可迁移。

闭源 API 的温度、系统提示与模型别名会变。回测必须锁定模型快照与解码参数，并把原始输入输出存档。只存一个分数、不存提示词与模型版本，等于不可审计的因子。

方法 ​

打分。 对每只股票、每个交易日，收集当日（或可交易窗口内）标题，逐条询问 LLM：该消息对该公司股票是 good news / bad news / unsure。将 good 映射为 \(+1\)、bad 为 \(-1\)、其余为 \(0\)，再对当日标题等权或按源加权平均，得到公司日度分数 \(s_{i,t}\)。横截面上做 特征 rank，对行业与市值中性，隔夜或次日开盘形成多空。Lopez-Lira–Tang 报告的是这种有方向的预测，不是主题暴露，也不是波动预测。

对照。 同一标题上跑 LM 负面词占比、FinBERT 极性、以及把标题当词袋的正则线性，见 正则线性模型。增量来自 LLM 对句法与事件类型的处理，应在同一时间戳、同一去重规则下比较。不要用「全市场新闻拼成的提示」去做个股打分：上下文窗口会把别家公司的消息泄漏进分数。

费用与容量。 日频全宇宙标题的 API 成本随名字数线性增长。研究上可对标题去重后批处理；生产上要预算超时与限流。因子换手接近新闻到达频率，扣 有效价差 后小盘上的纸面 IC 会掉一截。衰减通常在数个交易日内，见因子换手与成本的一般约束。

知识截止日期与可复现实验 ​

可辩护的回测有三条路。其一，只用知识截止日期严格早于样本起点的开源模型（按发布日冻结权重），接受样本内语言分布与今日 GPT 不同。其二，用样本期内真实存在的 API 日志（当时请求当时响应），不事后重打。其三，把 LLM 当无未来参数的特征提取器：不让它「回忆」该公司后来的股价或维基结局，提示词只给标题文本，禁止检索。Lopez-Lira–Tang 讨论了模型可能见过后续价格这一批评；复制者不能假装问题不存在。用 2025 年的 GPT 给 2018 年的标题打标签，得到的不是 2018 年可交易 alpha。

开源指令模型可以本地跑、可存权重哈希，适合作为研究基线。闭源模型适合作为生产特征，但版本漂移会使因子在某次静默升级后改号。两种都要做 无未来函数 检查：特征在 \(t\) 日结束前必须能算完。

提示词里写「你是资深分析师」几乎不改变横截面排序，却增加随机性。真正改变 IC 的是：是否允许模型使用标题以外的知识、如何把 unsure 编码、以及是否对多条标题先摘要再打分。

机制 ​

有限注意：投资者不能即时消化全部标题，LLM 作为廉价的「阅读代理」提取的极性，对应尚未完全进入价格的信息。这与 Tetlock 的媒体悲观、Ke–Kelly–Xiu 的监督词权是同一通道，只是测量从词频换成了条件判断。小盘、低分析师覆盖、低机构持仓上更强，符合注意力而不是风险溢价叙事。若在大盘、高覆盖名字上仍然极强，更要怀疑前视或共同因子（全体科技股同一天的宏观标题）。

第二种机制是风险：模型把「不确定」「调查」「监管」打成负面，分数可能是尾部风险代理，期望收益补偿而不是误定价。应报告相对残差波动、换手、新闻数量的正交，以及空头腿是否不可交易。第三种是纯粹的风格暴露：LLM 对某些行业的语言更「懂」，分数在行业上不均衡，中性化之前会变成行业动量。

与词典、监督词权的分工 ​

词典可审计、可向委员会解释「负面词多了」。监督词权拟合力强，但词表随训练窗漂移。LLM 情绪介于二者之间：提示词可审计，内部计算不可审计。生产上合理的分层是：词典与主题做风险报告，LLM 极性做短持有 alpha，嵌入做「谈什么」的稠密特征。不要把三者加总成一个「NLP 综合分」再去做 GBDT——共线会让树随便挑一个，样本外改号。

发布后衰减：一旦标题级 GPT 分数成为拥挤特征，公开电讯的极性会被更快交易，剩余预测力转向更早的源（监管原文、地方语言、结构化事件码）或转向嵌入里的非极性维度。增量来自时间戳与模型冻结，不是来自把同一标题换成更大的模型。

边界与工程取舍 ​

不要用带浏览、带检索的代理在回测里「查该公司后来发生了什么」。不要把盈余电话会全文一次性塞进上下文再要一个分数——那是摘要任务，泄漏与费用都不同。不要在 A 股上直接用英文模型打中文标题而不做单独样本外。涨跌停使「新闻日当日收益」经常不可交易。多标签（同一公司同日正负标题并存）应保留为意见分歧特征，而不是平均掉；Antweiler–Frank 已区分极性与争议。

监管与版权：特征应是分数与计数，不要转载全文。对发行人的评价若进入组合，仍是公开信息上的量化，不是内幕。模型幻觉会把不存在的「收购」打成正面：可用源白名单与标题长度下限过滤，而不是事后用价格反证。

Lopez-Lira–Tang（2023）建立的是：在严格的时间戳与横截面设计下，LLM 对新闻标题的方向判断具有样本内可检验的预测力。它没有授权把任意聊天机器人的输出当成 alpha，也没有消除知识截止日期这一识别条件。

把 LLM 情绪当择时（全市场一个分数）与当选股（横截面）是两件事。论文的识别主要在横截面；市场级分数更容易变成宏观风险与媒体主题，评价应走风险溢价通道而不是隔夜夏普。

小结 ​

  • Lopez-Lira 与 Tang（2023）用 ChatGPT 对新闻标题做正负中性判断，得到可预测随后个股收益的横截面信号，相对词典情绪有增量。
  • 第一约束是知识截止日期与模型冻结：事后 GPT 打历史标签不是可交易回测。
  • 提示词、unsure 编码与去必须预指定；费用与换手使容量落在中小盘短持有。
  • 机制以有限注意为主，须对行业、波动与新闻密度正交，并与词典、嵌入分工。
  • 出处：Lopez-Lira and Tang, Can ChatGPT Forecast Stock Price Movements?, 2023；对照见 Tetlock, JF, 2007；Loughran and McDonald, JF, 2011；Ke, Kelly and Xiu, 2019。
