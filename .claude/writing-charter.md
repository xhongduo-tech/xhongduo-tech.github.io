# 编辑章程（写作工厂宪法）

本文件是「从极限到大模型」博客的写作宪法。**所有专家小组撰写任何博文都必须逐条遵守，优先级最高；与本文件冲突的指令一律以本文件为准。**

## 0. 先读再看

开始写作前，先精读两份标杆文件：

- `docs/posts/foundations/math/set-concept.md` —— 一篇完美博文的范本（结构、语气、公式解析、边注、小结）
- `docs/posts/style-demo.md` —— 本站全部排版能力清单（多级标题、MathJax、mhchem、表格、代码、epigraph、marginnote、sidenote）

## 1. 文章结构模板

每篇博文必须包含以下部分，顺序固定：

```markdown
---
title: <标题>
date: <今天日期，如 2026-08-07>
---

# <标题>

<div class="epigraph">
<p><与本主题相关的名言（中文翻译，注明英文原名与出处）></p>
<footer>—— <作者>（<原名>）</footer>
</div>

<div class="article-byline">
<p><第X级> · <专题名> ｜ <对标教材> <章节> ｜ <今天日期，如 2026-08-07></p>
</div>

## 为什么从……开始

（一段开场：说明这个主题为何值得学、在本专题与全课程体系中的位置，与「从极限到大模型」主线或已学/将学内容建立连接。）

## 1 <小节标题>
（正文分节……）

## N 公式解析：<具体公式>

（有公式的主题必须有公式解析：把一条核心公式拆成 2–4 步，逐项说明每个符号的含义、为什么成立、背后的直觉。）

## M 小结

- 要点复盘（3–6 条）

在下一节，我们将……（对下一课的引子，自然收尾）
```

## 2. 标注体系（重点 / 核心 / 辨析）

- **核心概念**：术语首次出现加粗，紧跟冒号和精确定义。例：**集合（set）**：……。
- **重点**：关键结论用独立段落加粗引导句标出，例：**元素与集合之间是「属于」关系，集合与集合之间才是「包含」关系**。
- **公式**：独立块级 `$$...$$`；核心公式用「公式解析」小节逐项拆解。
- **易错点 / 辨析**：独立段落以 **辨析｜易错点：** 引导，可配 marginnote。
- **补充 / 出处 / 旁白**：`<span class="marginnote">…</span>` 边注，宽屏下排入右侧页边。
  - ⚠️ **边注内部禁用 markdown 加粗 `**…**`**：`<span>` 是行内原始 HTML，markdown 强调在其内部会与整段的 `**` 配对错位，导致 `<strong>` 未闭合、构建失败。需要强调时改用 `<strong>…</strong>` 或纯文本。
- **编号脚注**：`<span class="sidenote-number"></span><span class="sidenote">…</span>`。
- **小结**：`## M 小结` 下用 `- ` 圆点复盘。

## 3. 数学公式

- 行内 `$...$`，块级 `$$...$$`（MathJax 渲染，无需插件）
- 化学用 `\ce{}`，例：`$\ce{2H2 + O2 -> 2H2O}$`（mhchem 已内置）
- 多行对齐用 `\begin{aligned} ... \end{aligned}`

## 4. 图片规范（实验 / 原理配图）

- 仅在示意图 / 原理图 / 实验装置确实提升理解时配图；**每篇最多 1 图**
- 图片必须是**手写内联 SVG**（不用外部截图、不用二进制、不用在线图床）
- 存放路径：`docs/public/images/<topic>/<slug>-<序号>.svg`
- 文章引用：`![<图题>](/images/<topic>/<slug>-<序号>.svg)`
- SVG 规范：
  - 自包含单文件，`<svg viewBox="0 0 W H" …>`，宽高比合理（如 4:3 或 16:9）
  - 文字用中文，`font-family="sans-serif"`，字号 ≥ 13px（保证可读）
  - 配色与站点一致：纸底 `#faf9f5`（或 `#fff`），墨色 `#333`，强调色 `#c0392b`（红）或 `#1f6f8b`（青）
  - 必须带 `<title>` 与 `<desc>` 元素
  - 关键部件用 `<text>` 直接标注，避免歧义

## 5. 质量底线

- **篇幅**：≥ 120 行 Markdown（实质内容 1200–3000 字），结构完整，不写空话
- **编号分节**：≥ 3 个 `## N` 分节
- **边注**：≥ 2 条 marginnote
- **公式**：有公式的主题 ≥ 1 处公式解析；无公式的主题（如纯史论）≥ 1 处「核心要点」表格或辨析
- **连接**：至少一处与博客其他层级 / 专题的交叉引用
- **准确性**：数值、定义、公式必须与权威教材一致；不确定处用开放源核实（每篇 ≤2 次搜索），**不得编造**

## 6. 发布登记（写完后必做）

1. 把文章写入 `docs/posts/<tier>/<topic>/<slug>.md`
2. 打开本专题 `index.md`，把对应条目 `- [ ] <标题>` 改为 `- [x] [<标题>](./<slug>)`
3. 若配图，SVG 已写入 `docs/public/images/<topic>/`
4. 返回主控一份简短报告：标题、slug、参考来源、是否配图
   （`progress.json` 由主控统一重生成，代理无需触碰）

## 7. 语气与风格

- 面向「聪明但有待引导」的读者：清晰、坦诚、有节奏
- 先给直觉，再给严格；避免照抄教材目录式罗列
- 用具体的数、具体的历史、具体的例子让抽象落地
- 段落短、句子短；一处一段意，不堆砌
- 中文学术写作规范：标点中文全角，「的/地/得」正确
